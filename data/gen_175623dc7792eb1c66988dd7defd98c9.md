# 二、如何创建自己的 GPTs

## ① 创建页面的核心要素

[PRE2]

*   Name 名称：给你的专属智能体起个名字
*   Description 描述：用一句话概括这个 GPT 用来干嘛
*   Instructions 指令：告诉它要做什么、怎么说话、要避开什么
*   Conversation starters 对话开场白：预设几个用户可能会问的问题，降低启动成本
*   Knowledge 知识库：可以上传文件，让它基于你的资料来回答
*   Capabilities 能力：勾选是否开启联网、DALL-E 绘图、代码解释器等 GPT-4 原生能力
*   Actions 行动：给它接入自定义工具或外部指令的能力

### （1）教材式投喂

公众号 / 航海手册里的内容就是现成教材。

【引用自圈友@谢不言《花 2.8 元成本批量生产浏览过万的小红书笔记，实现月变现 5 万？》】

一：简单聚合型

公式：情绪词 + 数字 + 全套价值承诺

用法：用情绪词抓人 + 数字做背书，让人感觉一篇就够了

举例1、吐血整理，10大互联网平台引流私域方法！

举例2、建议收藏，一张图告诉你7大类运营岗工作内容！

举例3、码住！写方案的万能模板，每次都被夸😎

二、干货型

公式：如何做 + 具体事件

用法：
1、把文案要解决的问题反问出来
2、要有明确的受众感
3、事件最好带冲突和稀缺性

举例1：如何在大一就实现经济独立🔥经验贴

举例2：新手创业 如何做到3天精准引流上百人

举例3：实体店惨淡，实体人应该如何支撑下去？

三：人群痛点型

公式：人群 + 痛点 + 如何 + 解决方案

用法：直击人群痛点提问，后续给出解法

举例：淘宝新店不刷单如何引流？你得想明白这件事

举例：做微商没有客源？如何精准引流？微商如何涨粉

举例：实体店生意惨淡怎么办？怎么引流客源最快？

四：结果呈现型

公式：关键词 + 如何 + 数字结果

用法：提炼核心成果，用数字制造好奇

举例：招生引流 | 我们是如何做到1个月1000人的

举例：开工作室一个月｜好友从0️⃣到3000➕！！

举例：饰品创业 新手如何做到3天精准引流上百人

## ④ 投喂资料 2：Knowledge 知识库

支持上传 PDF、PPT、Excel、Word、图片、EPUB、XMind、HTML 等各种格式作为知识。

思路可参考刀姐的《ChatGPT 投喂指南》，原理基本一致。

[PRE9]

上传后的资料会一直存在 Knowledge 里，持续影响模型的判断。

比如我有雅思备考需求，把相关资料全丢进去，就能得到一个专属雅思辅导员。

[PRE10]

## ⑤ 调试与反馈

注意，左侧调教区的内容不会自动保存！

我之前中途退出一次，所有设置直接清空，所以一定要及时保存。

[PRE11]

调试逻辑和用 ChatGPT 一样：左侧改规则，右侧测效果。

左边是地基，右边是装修。

遇到问题就回炉改底座。

比如右边没 emoji，就在规则里加上一句“适当加入少量 emoji”。

比如输出太啰嗦，就加规则“精简表达，别废话”。

本质上就是教小孩，哪里不对就指哪里。

# 四、最后的感悟

AI 工具的门槛已经降到“会打字就行”的级别。

过去定制模型要读论文、做 Embedding，现在只要会说话。

所以核心竞争力变成：对行业的真实经验沉淀，以及对 AI 输出的判断力，防止它给出看起来对的废话。

以前积累的内容，现在相当于数字资产，借着 AI 放大后能产生指数级价值。
