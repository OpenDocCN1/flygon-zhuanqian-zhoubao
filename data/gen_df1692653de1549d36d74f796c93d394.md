# AI 提示词入门（一）：不懂 Prompt 和 Token，别说你会用 GPT

很多人第一次用 ChatGPT 都会困惑：同样的问题，别人问出来条理清晰，自己问出来却答非所问。这未必是 AI 不行，更可能因为你还没掌握和它交流的“底层语法”。今天这篇零基础教程，先从四个关键词讲透：Prompt、Token、时效性和幻觉。看完你会明白，AI 到底是如何“理解”你的话，又为什么偶尔会一本正经地胡说八道。

## 一、Prompt：你说出的每一句话，都是指令

不妨把大模型想象成一位读过海量书籍、但必须依赖追问才能给答案的老朋友。你抛出的每句话——无论是提问、命令还是陈述，都是 Prompt。它像是两人对话中的“话头”，也是 AI 决定回答方向的依据。

Prompt 至少有三层作用：
- 开启回应：告诉模型“现在该你出场了”；
- 牵引话题：让它顺着你设定的方向思考；
- 影响输出质量：指令越具体，回答越精准；指令越模糊，AI 越容易跑偏。

下面这 10 类 Prompt，是新手最常遇到的场景。

- 描述性 Prompt：用来获取或描述某项具体信息。  
  例：“描述埃菲尔铁塔的历史。”  
  [PRE0]

- 创造性 Prompt：用来激发灵感、生成新内容。  
  例：“创造一个关于未来城市的故事。”  
  [PRE1]

- 指令性 Prompt：直接布置任务，让 AI 执行某个动作。  
  例：“将这段文本翻译成法语。”  
  [PRE2]

- 探索性 Prompt：用于研究一个主题、梳理复杂问题。  
  例：“探索全球变暖对极地生物的影响。”  
  [PRE3]

- 情感性 Prompt：让 AI 关注情绪、心境或感受。  
  例：“写一首表达失落情感的诗。”  
  [PRE4]

- 问题解答 Prompt：用来计算、解题或回应具体疑问。  
  例：“如果一个圆的半径是 5 米，那么它的面积是多少？”  
  [PRE5]  
  在新版界面中，点击最右边还能看到“执行分析步骤”的按钮，对数学题特别友好。  
  [PRE6]

- 编程/代码 Prompt：面向开发任务或技术问题。  
  例：“写一个 Python 脚本来排序一个数字列表。”  
  [PRE7]

- 咨询性 Prompt：请 AI 给建议、分析或专业见解。  
  例：“给一位希望提高时间管理技能的专业人士提供建议。”  
  [PRE8]

- 图像生成 Prompt：用来创建或修改图像。  
  例：“生成一幅描述太阳系的图像。”  
  [PRE9]

- 音频/视频 Prompt：用来生成或编辑音视频内容。  
  例：“创建一个关于太阳系的短视频。”

## 二、Token：AI 消化文字的“最小单位”

理解了 Prompt，还要认识 Token。它决定了你能问多长、模型能答多长，也决定了每次对话的“成本”。

你可以把 Token 想象成把一本书拆成一堆字卡，每个字卡都是一块积木。GPT 就是靠这些积木去“读”语言，再一块块拼出新内容。

它在模型中承担三种角色：
1. 理解语言：通过大量 token，模型逐步学会词义、句法和组合规律；
2. 生成回复：你提问后，模型把问题拆成 token，再推算后续 token，最终组织成回答；
3. 提高效率：把长文本切成小片段，处理起来更快，相当于用拼图快速还原整张画面。  
[PRE10]

更具体地说，GPT 并不能直接“看见”中文或英文。它先把文字转成 token，预测出需要输出的 token，最后再还原成文字给你。全过程可以概括为：文字 → token → 模型推理 → token → 文字。

不过还要注意：GPT 使用的是基于 BPE 算法的分词方式，和传统自然语言处理中的字级、词级、子词分类并不完全一致。新手可以先按以下三种近似理解，但别把它当成严格原理。

- 字级 Token：中文里一个汉字可能就代表一个 token。  
  [PRE11]  
  从截图能看到，每个汉字都被单独切分。

- 词级 Token：英文里一个单词可能是一个 token；中文里有时两个汉字也会合并成一个 token。  
  [PRE12]  
  比如“中国”两个汉字算一个 token；又比如“ red”（前面带空格），这 4 个字符也算一个 token。  
  [PRE13]

- 子词 Token：遇到生僻或复杂词汇时，会被进一步拆成更小片段。  
  [PRE14]  
  例如“老师”这两个汉字，实际可能被拆成 3 个 token，因为“师”字由两个更小的 token 拼出来。  
  [PRE15]

日常交流中，我们可以记住一个粗略换算：100 tokens 大约等于 75 个英文单词，或者 100 个汉字。

在 GPT 的实际计费中，用户输入的 token 和模型输出的 token 都要计算。比如你问问题花了 100 tokens，AI 回答用了 200 tokens，这一来一回就是 300 tokens。

- GPT-3.5 的 token 上限约 4096，大概对应 3072 个英文单词，或 4096 个汉字；

一旦对话超过这个上限，模型就不得不“丢三落四”。它无法同时保留超过上限的信息，只能把较早的内容忘掉，给新内容腾地方。这就像小孩子听一个很长的故事，听到后面，开头已经记不清了。

我试过中文输入：331 个汉字被换算成 337 个 token，几乎是 1:1；再试英文，700 个字母大约只产生 149 个 token，算下来约 4 个字母 ≈ 1 个 token。  
[PRE19]

Token 意识对写提示词很有帮助，尤其是长对话场景：
- 控制记忆长度：别在超过限制后继续追问最早的问题，模型很可能已经忘了；
- 表达要简洁：能一句话说清就不要写一大段；
- 关键信息可以重复：连续对话中，重要内容隔段时间再强调一次；
- 合理分段：长问题拆成几步，或定期总结，能帮模型更好消化。

## 三、时效性：GPT 的知识有“截止日期”

很多人误以为 GPT 能实时掌握世界动态，其实不然。它是在某个时间点之前的数据上训练出来的，知识存在“保质期”。  
[PRE20]  
比如某个版本的 GPT，训练数据截止到 2023 年 4 月左右，之后发生的新闻、热点和科技进展，它并不知道。

怎么办？最简单的方法是使用带联网功能的 AI 工具。以 GPT-4 为例，默认对话框已集成联网搜索，可以实时抓取最新信息。

但要清楚：这些内容来自外部搜索，属于“临时调用”，并不代表模型把新知识重新学进了大脑。

## 四、幻觉：AI 一本正经地“编故事”

最后这个话题很关键——幻觉。简单说，当模型生成的文本不忠于原文，或不符合客观事实，我们就可以说它出现了幻觉。它并不是在故意撒谎，而是在“脑补”。

常见的幻觉有三种：
- 输入冲突：生成内容和你给出的已知事实相矛盾。  
  [PRE24]

- 语境冲突：前后两个回答互相“打架”。  
  [PRE25]

- 事实冲突：输出与已知世界知识明显不一致。  
  [PRE26]  
  [PRE27]

幻觉到底从哪来？大致有四个源头：

1. 知识不足或错误内化。模型可能把训练数据中位置接近、经常一起出现等现象，误当成了真实因果或事实知识。
2. 过度自信。模型很难评估自己答案对不对，有时它犯错时和答对时一样理直气壮。
3. 对齐过程出问题。若预训练阶段缺少相关知识，后续做指令学习时容易诱导它生成幻觉；还有一种“谄媚”现象，即模型为了让用户满意，宁可迎合观点也不给真相。
4. 生成策略有风险。即使模型发现方向错了，也可能为了自圆其说而继续“滚雪球”，而不是主动纠正。

想减少幻觉，可以试试 7 个实用技巧：

1. 提供清晰的上下文和约束。比如问医疗问题，明确说“只依据 2023 年最新医疗指南回答，不要做无根据推测”。
2. 要求逐步推理。让它一步步思考，不要一步跳到结论。
3. 让模型“大声思考”。把推理路径完整写出来，方便你检查逻辑漏洞。
4. 生成多个版本后再筛选。比如让它从三个不同角度回答，再综合出最合理的结果。
5. 指定信息来源。要求它基于某份资料、某种数据作答，或标注引用来源。
6. 使用结构化 Prompt。比如 CO-STAR 这类框架，把背景、关键点、结论分段写清，模型不容易跑题。
7. 限制回答长度。短答案通常更靠谱，也能减少为了“凑字数”而产生的编造内容。

## 写在最后

Prompt 是对话的起点，Token 是理解的单位，时效性是知识的边界，幻觉是模型的盲区。把这几件事弄明白，你和 GPT 的沟通质量会有质的提升。这篇文章是系列入门第一篇，适合所有零基础小白。下一篇，我会继续带大家解锁更高级的提示词玩法。
