# 用 AI + 开源工具，把公众号历史文章全部梳理成可点开的清单

> 原文：[`www.yuque.com/for_lazy/zhoubao/sy02y3rf33wbbmlh`](https://www.yuque.com/for_lazy/zhoubao/sy02y3rf33wbbmlh)

## 借助 AI 和开源软件，方便的阅读公众号所有文章 -使用 AI 实现个人需求实例分享

作者： 彩笺

日期：2024-11-04

最近想系统性地回看某个公众号从创号至今的全部内容，我希望能按时间顺序正序阅读。微信本身的排版体验并不友好，只能倒叙浏览，而且每次中断后想接着看，都得自己记笔记找上次的断点，非常折腾。

于是花了大概半小时，用 AI 结合开源项目把这个痛点解决了。

在阮一峰科技周刊的往期内容里，我留意到一个开源项目：

[PRE0]

项目链接：[`github.com/jooooock/wechat-article-exporter`](https://github.com/jooooock/wechat-article-exporter)

点进仓库的 About 页面，看到作者提供了在线体验入口

[PRE1]

按照指引跑了一遍体验，发现离我想要的效果还有距离。

它只能逐篇导出，而且导出的是压缩包，里面是 html 文件。虽然能保存，但并不适合我想要的“把整套文章的链接集中起来，随时在线浏览”的需求。

我注意到页面上每篇文章旁边都有一个“复制链接”的按钮。思路就来了：能不能把整页的复制链接批量抓出来，形成一个可点击的清单？

[PRE2]

## 实操过程

先打开 GPT

[PRE3]

按 “F12” 打开开发者控制台

在控制台里粘贴运行一段提取代码

[PRE4]

结果返回空。结合代码注释的提示，我怀疑是按钮里没有直接暴露链接。于是回到浏览器里手动排查一下元素。

在控制台左上角点击选择工具，选择网页上的按钮，就能定位到对应的 DOM 节点

我们先定位“复制链接”这个按钮

[PRE5]

节点里似乎没看到可用的 href，先请教 AI 有什么办法

[PRE6]

跟随 AI 的思路继续排查，这时我注意到页面上除了“复制链接”之外，还有“查看原文”这个选项。

点开“查看原文”后发现，这个按钮背后其实是藏着真实链接的

[PRE7]

[PRE8]

[PRE9]

[PRE10]

经过几次来回沟通，AI 给出了一个可行的方案，用脚本把所有链接汇总成列表。示例里用了 shell 脚本，Windows 用户没有 shell 环境也可以让 GPT 换成 Python 脚本，逻辑一样

[PRE11]

最终得到一份 markdown 文件，里面全是可点击的链接，直接 Ctrl + 点击就能跳转阅读。

看了一会儿电脑觉得累，想换到手机上躺着看时，发现直接点链接体验也不够理想，于是继续寻求 AI 的帮助

[PRE12]

我把需求抛给了 Claude，算是随手切换了一下模型。它建议用 Python 脚本处理，但我的本机还没装 Python，就顺势让它教我怎么安装

安装完成后继续

[PRE13]

我把当前链接的格式和期望的输出结果详细描述了一遍，AI 分析后给了完整代码。

在本地执行 `py youcode.py` 之后，直接生成了我想要的版本

[PRE14]

这下所有文章都被推送到了我自己的聊天窗口里，手机上点一下就能自动打开对应的公众号原文。

最后再分享一个收纳小技巧：

在公众号文章页点击右上角的三个点

选择在微信读书打开

微信读书里会多出一本名为“文章收藏”的书

打开这本书就能看到所有通过此方式沉淀下来的文章，点击即可查阅
