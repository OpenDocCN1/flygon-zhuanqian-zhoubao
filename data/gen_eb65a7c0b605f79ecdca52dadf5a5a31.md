# 零基础、两周、一头扎进深海：一个编程小白的踩坑与复盘

大家好，我是李澹归。

前阵子我加入了深海圈，跟着小排老师学做网站。为此我放下了能快速拿到反馈的 YouTube，也把自己赚到第一块钱的周期拉得更长了。眼下看这选择未必聪明，但把眼光放远一点——做网站这件事，一份时间可以卖很多次。中间要付出什么、放弃什么，算总账是划算的。

读生财宝典也有些感触。多数老板会主动把赚钱的周期拉长，让企业走得更稳。巴菲特在告别秀上说过一句让我记很久的话：他希望长期持有一只股票，最好是五十年。我就想，一件事如果能干五十年，那除了你还有谁能干？别说五十年，能做上七年的事，也足够你赢得时间了。

YouTube 我才学了一个月就放下了，研究下来只悟到一个点：留存率。YouTube 的数据分析里有条线，数据低于某个百分比，平台就不再推流，这是视频能不能稳定拿到流量的关键指标。如果能再往深研究，把数据急速下滑的那一段优化好，爆款应该会更多。中间我试过自动化，结果自动化反而把我推进了一条红海赛道，又白费了五天。所以千万别一上来就追自动化，先判断这件事做了有没有结果、有没有持续的正反馈，再去优化流程。能被轻易自动化的东西，门槛一定低，那是人挤人的地方，别去，快跑。

这里很推荐读一读小排老师的帖子（https://scys.com/articleDetail/xq_topic/582855552858284），里面讲了守破离。还没赚到钱的时候，就按部就班地执行，哪怕操作很傻瓜。每个写帖子的人都有自己的经验，你想改流程，也得等熟了再说，因为你并不知道他为什么这样设计流程。我还停在“守”的阶段，分享不了更多。如果你有更多经验，欢迎来跟我聊聊。

每天真正能用的时间很少，得保证精力够用，所以时间规划要清楚：今天学什么、做什么，复盘并迭代自己的行为路径。

我在这上面大概卡了一个周，每天不知道该学什么，东学一点西学一点，还很焦虑。所以我想写篇帖子做个复盘，把这半个月学到的东西整理出来，也给还没走到这里的朋友留个路标，少踩坑，把宝贵的时间用好。

### 1. 先确定学习路径

按我最近读到的信息，做网站赚钱可以分成三个流派：

1. 新词新站 + 下手快（蹭热点词）
2. 长期 SEO + 不变的需求（稳定拿量）
3. 深耕好产品 + 自传播（做精）

如果简化成一条路径，就是：怎么让更多人看到、留下来反复体验、长期付费使用。

前辈们已经各自找到了舒服的路，我们在后面先学，再探。初期我会先熟悉流程，以上站为目标，先玩起来；技术慢慢精进，产品思维慢慢补全；然后再尝试做好的产品。

换成是你，你会怎么选？

### 3. 我遇到的有趣的事

第一件：在 GitHub 仓库刷到了系统提示词。

所有大模型出来第一件事就是设置初始提示词，姑且叫它系统提示词。这个系统提示词怎么写，决定了大模型的回复逻辑。

拿 Cursor 的系统提示词举例，这是 Cursor 调用 Claude 3.7 的系统提示词。拿到之后，我把它放进 Trae 海外版的规则里，就能和 Cursor 一样用了。因为 Cursor 也是套壳，系统提示词放在 VS Code 还是 Windsurf，差别不大。

所以产品初期，谁能用更低的 API 成本拿到更多用户，谁在提示词上多下功夫，谁就占了先机。
