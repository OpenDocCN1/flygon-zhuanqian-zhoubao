# 从30人审核小组到50国内容中台：一个老圈友的两年AI落地复盘

圈友大家好，我是陈亮，成都基地，已在生财待了6年。

这篇我想把2023年5月至今，用AI把公司业务拆解重组的经历摊开讲。重点讲两条主线：一条是用模型把近30人的小语种外包审核工作替换掉；另一条是把大模型埋进信息流内容体系，实现向50个国家自动化的内容运营。

篇幅不短，信息密度也高。如果你对全自动内容运营、业务流程的AI化改造感兴趣，能沉下心看完，应该能带走一些实操感。

# 最终体感

先说结果。

1. 小语种审核外包：在成都同类岗位月薪约8000，30人成本每月约24万。接入模型后，单日审核支出压到不足100美元，且审核量不再受人手、排班、沟通成本限制，理论上可以无限放量。人力管理的隐性成本被显著削掉。

2. 海外内容运营：过去拓展一个海外市场，必须先配本地团队。模型跑通后，多开一个国家的边际成本趋近于零，低成本即可复制。核心在于把基于模型的运营体系工程化、稳定化。

下面是我团队近两年的具体做法。

# 为什么要做AI工作流

2022年8月我加入一家面向非洲市场的信息流公司。终面时CEO问我：来这里你能为客户带来什么价值。生财教会我的利他思维在此刻生效，价值先行，后面才有成长空间。

我是全栈背景，进来后做了大量提效和自动化，但技术岗的边界很清楚：即便心里想做业务操盘，日常也只能提供技术视角。传统互联网里技术与业务合一的位子很少，基本要二选一。

2022年12月在生财风向标看到ChatGPT。第一感受是新能力在形成，但当时对其底层实现缺乏清晰认知。随后半年我补实现原理、看海外技术拆解，结合圈内老师的分享，才确信这次可以以业务操盘手的姿态入局。

新技术诞生必然重塑生态，生态位在空档期，行动快的人能吃到红利。

当时诉求很直接：学会出海本领，在公司练成业务操盘能力，实现双向赋能。2023年6月起，我开始用OpenAI接口在非核心主链路上试水，拿到初步正向反馈。迭代多次后接入企业级OpenAI服务通道，经国内Azure代理商签约，也完成了多次工业化尝试，认知逐步沉淀。公司随后给了我首席AI架构师的头衔，后续推进也更有名分。

# 业务的AI重塑

我们是信息流产品，DAU约4000万，可类比为非洲及中亚的今日头条。内容来源分散，涵盖英语、阿拉伯语、法语、葡萄牙语、阿姆哈拉语、斯瓦希里语等，覆盖多国。

风险在于内容可能触及宗教、信仰、涉政红线，导致应用商店下架。

因此公司保留了约30人的小语种审核团队，对高消耗内容做判定。同时早期只运营中非、东非部分国家，每个国家还需本地化运营。初创公司很难自研审核模型，第三方模型又难以适配各国细节。

问题集中在两点：

1. 风险不可控
即便30人满负荷，也只能覆盖头部内容。日入库文章4万篇、小视频5万条，人均日审文章约300篇或视频1000条，30人只能覆盖一小部分。审核是主观判断，标准越细，人差也会显现。

相当于始终有风险内容在线，被持续消费。达摩克利斯之剑悬在业务头上，很难受。

2. 拓展受阻
想多做一个国家，审核量随之上升，还要配本地运营。跨国团队搭建的痛点大家都懂，尤其在非洲人才供给不足的区域，合适人选更稀缺。

# 内容审核的自动化改造：用模型替代30人多语审核

2023年下半年，我以首席AI架构师身份持续和审核运营聊分担工作量的可能性。12月正式启动。

### 阶段一：最小可验证原型

当时最强通用模型是GPT4，仅支持文本与图像。所以先从文本入口切入，把4万篇文章的部分工作分流出来。验证可行再扩展到图像。

文章本质是文字+图片。拆分策略如下：

1. 按国家标准，把标题、导语、正文与审核提示词一并输入模型，判定是否违规。
2. 若文字违规，直接下线。
3. 若文字合规，人工工作流改造为只看图，判色情、暴力等。
4. 图违规则人工下线。

改动后需要持续调优提示词，调优依赖数据闭环。因此保留原人工审核并行，双轨运行，仅用于效果评估，不执行真实下线。核心指标看准确率与召回率。

准确率：模型判为违规的内容中，真正违规的占比，即误伤。
召回率：所有真正违规内容中，被模型抓到的占比，即漏放。

提示词设计我们测过三种路线：

1. 无规则：只告知国家，让模型判断。输入输出最小，成本最低，效果最差。
2. 有规则：给出判定规则，要求模型输出是否违规。输入多输出少，成本中等，效果较好。
3. 标签法：让模型输出命中标签集合，再由工程侧匹配判定。输入输出都多，成本最高，效果尚可。

综合后选择第二种：给规则与标准，让模型做判断。

业务可行性确认后算账。按团队总支出含社保公积金折算文字审核的人工单价，再按GPT3.5 1106的token单价算单篇文章AI审核成本。文字部分经济性成立，虽未极致便宜但可接受。

在成本与能力双满足的前提下，完成首个纯文字MVP。上线后用工程手段与用户反馈持续双轨，人工标注不计入上下线，以模型结果为主观察数据，持续稳定后正式切到文字审核自动化。过程中涉及并发、配额、效率、稳定性等工程细节，暂不展开。

### 阶段二：小范围试探，先通路后省钱

原型可用后，人工在文字侧的负担大幅下降，可腾挪到短视频侧。

2024年春节期间，外包团队需排班补岗，标准波动问题暴露。文字已模型化后，人员只需看图，问题明显缓解。收益开始显现。

年后启动图像审核调研。当时可选Claude3、Gemini1.5、GPT4V。实测GPT4V表现最好，但出现过模型返回“未发现可识别内容”的情况。

回溯发现是图片压缩过狠导致模糊。信息流下发多清晰度图，早期为省成本选了最狠压缩，导致偶发失效。

教训是：验证通路时可先不计成本优化，确保链路打通后再拆解优化、保证利润率。

换到中等与高质量图后问题消失，且准召率差异不大。

图像可用的前提下，流程升级为：

1. 文字模型审核，违规直接下线。
2. 文字合规后图像模型审核，违规下线。
3. 两项均合规则正常分发。

成本可控，继续双轨线上验证，流程同文字改造。

额外问题：GPT4V单次图片输入上限9张，文章常超此数。我们采用分批请求合并结果的方式解决。

2024年4月，高热文章审核全面模型化，日成本约150美元，远低于人力。释放的人力全部转向短视频审核。

这两年实践的核心是：AI不是裁掉某个岗位，而是重构整条工作流。希望这个复盘对你有参考价值，后续细节再逐步分享。
