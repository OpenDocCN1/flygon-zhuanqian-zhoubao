起点不清、想尽快看到回流的，先去做流量变现号；能承受长期静默、愿意做复利沉淀的，就打个人品牌。品牌不是想出来的，是养出来的，爆款同样需要养出来。不要追求一次把规划做死，先上线再校准，边发边复盘、边复盘边做。

入口敲定后进入生产流水线，按站点顺序推进。

**第一站 让模型先读懂你——人格档案**

许多人以为塞一段人设指令就能写出你的味道，这只是表层。档案建设与内容生产要分层：长效的人格档案负责整体理解，单次生产的写作内核负责当期输出。浅档案只能告诉模型你是谁，却说不清你卡在哪、什么状态会崩、偏好哪种沟通方式。模型读到的是简历，不是活人。

完整档案是上游可选工具，帮助模型把握你的经历、价值取向、优势与长期方向，再据此提炼定位与写作内核。进入工厂时默认调取的是写作内核、内容定位和当期原材料，无需每次把全部私密档案全量投喂。

基础信息、可用资源与能力、核心卡点、财务全景、时间构成、情绪心理、身体饮食、能力资产、副业转型进度、目标体系、执行风格、自我瓦解模式。

完整提示词见文末附录，可直接套用。也不必被这 12 个模块框死，可与自身的方法融合使用。参考图见下：[PRE0]

这套档案既可用于写作，也可用于长期规划与决策、IP 方向提炼，但边界要清晰。模型可以知晓，不等于可以公开。写作时只调用任务真正需要的信息。

重点拆三个易被忽略的模块。

财务全景必须如实填写。隐私注意：勿提交密码、证件号、精确住址及未经授权的第三方隐私，敏感信息先脱敏。人格信息按“可公开引用、仅作理解、脱敏后可用、禁止输入或保存”四类权限管理；未经许可，Agent 不得复制、转发或保存至他处。

目标体系越具体越好。目标模糊本质是逃避执行。“本月赚 100 元”比“做大做强”管用百倍。大脑对模糊目标默认可绕过，对具体数字无法装看不见。

自我瓦解模式最易被忽视，也最关键。工作描述：你运营公众号一个月阅读个位数，凌晨两点还在改稿，忽然冒出念头：这么拼图什么，一分钱没赚身体先垮，不如睡了。然后你就真停了。每个人都有这个开关，只是触发点不同。提前写入档案，模型识别到进入该状态，会提醒：先暂停，明天再写，别逼太紧。就这一句话，很多副业是在无人说这句话的那个夜晚夭折的。

配套还有一套天赋挖掘问答，置于附录。让模型像采访一样一次只问一个问题，关键在于区分两种能力：你主动热爱的，和为生存被迫学会的。后者往往更能打。我线下提过：都说兴趣是最好的老师？我更认同：生存才是最好的老师。

实操注意两点：使用 GPT、Claude 这类海外模型，档案可在三次对话内完成；使用豆包、DeepSeek 这类国内模型，务必拆成三次对话并本地留存，国产模型长对话易失忆，这是通病。

还有一条铁律：永远不要让单一模型主导全部生活。核心问题，至少咨询两个以上模型才算咨询过模型。于是我将内容工厂公开包拆成两层：中文阅读包保留完整人格提炼工具；机器安装包只保留写作内核模板、使用权限和缺失时的降级规则。

缺少内核也能继续生产，但任务必须标注“人格校准未完成”，模型不能虚构你的口吻和经历，最好补充 3-5 篇真实文章或口述材料再校准。

人格地基搭好，下一站让模型认识市场。

**第二站 找对标——占比约六成的关键动作**

档案解决像你，对标解决能不能出圈。IP 号亦或流量号都要过这一关。区别在于：IP 号找同赛道标杆内容，流量号找热点赛道的爆款基因。

四条铁律：

1. 别拿头部大号当参照。大号有原生推流、团队、品牌光环，新号照抄只能辛苦跑不动。
2. 找低粉高互动。起号千粉以内，就找三五千粉以下、阅读却做到一万、十万的号。目标比你高十倍即可，别找高百倍的。
3. 只看近半年新号。老号爆文靠多年积累或过时热点，抄不了。新号爆文才是当下规则打出来的。
4. 只找同领域、用户画像高度重合的。起号期跨领域对标无意义。

再给你一个概念：异常值。同一作者平均阅读两三千，突然一篇冲到两万，那篇就是异常值。别找“好文章”，好没有坐标，异常值有坐标，是市场筛过的。找到后拆解为何爆：标题抓住谁停下来？评论区反复出现哪句话？评论区常比正文值钱，痛点读者会自己说出来。

喂给模型前，先自己做判断。模型一晚能解析几百篇，但哪篇值得学，得你自己定。品味外包不出去。

顺序记住：不是先写再等爆，是先找已爆的照着做。你遇到的问题都有人遇到过而且有答案，别从零摸索。

去哪找：微信搜一搜切到文章，按最热排序输入赛道关键词。超过十万阅读排序会乱，介意可用易撰、新榜，易撰免费版一天查十篇，对新人够用。元宝等模型也能做竞品调研。

找到合适的，将标题、正文、账号名、粉丝量、阅读量记录下来，存飞书或备忘录，建立自己的低粉爆款库。凑够三篇风格相近的，进入下一站。

**第三站 素材整理与拆篇——工厂调度中心**

此前我把这站当前置动作，到第七稿才意识到它是调度中心，决定当日产量、主题、顺序。对应两个引擎：淘金引擎 + 布局引擎。

淘金引擎用于前置整理。你每天素材混杂：口述转写、备忘录、朋友聊天记录、看完有感的文章。直接丢模型它读不懂，原始素材混着停顿、重复、离题、识别错误。淘金引擎把杂乱输入整理成结构化素材包，区分事实、观点、案例、情绪并标注来源。它不会编造，素材里没有的标“待补充”，不瞎写。

IP 与流量侧重不同：IP 打法淘金时要筛选，哪些观点适合从你人设发出，人设、热点、技能三者要对齐；流量打法核心是拆对标，爆点是什么、核心卖点是什么、驱动点击的情绪是什么。

布局引擎接素材包做三件事：拆——能出几篇、每篇核心点；排——按发布节奏定优先级；去重——自动检索已发文章，撞点就跳过。去重很关键，我日更 1092 天，不去重上周观点这周又出现，读者会觉得车轱辘话。

IP 与流量拆篇逻辑也不同：IP 若内容池某方向过冗余就要稀释换方向，IP 是持续引流，读者想看同一个点的生长、延伸、不同面；流量则相反，点爆了要立刻追、持续追。爆过的内容会再爆。但流量热点变化快，不能用旧引擎打天下，需随实战调整。本篇开源的是 IP 类引擎，流量类未给，因会过时。但跑通 IP 后，流量核心步骤相同，按对标爆点调整即可。

如何自定义：淘金引擎里有素材来源表，可自行增加类型，如教培加“学员反馈”“家长提问”，电商加“客户评价”“退货原因”。布局引擎有去重检索范围，默认检索近期文章。号刚起步可关闭去重，已有几百篇建议拉到最近三个月。这一站结束，你会拿到一份拆篇计划。

**第四站 单篇生成——先学后写**

素材拆完才轮到模型动笔，对应铸文引擎，分两步：先学，再写。

IP 与流量差别最大。IP 核心是“像你自己说的话”：把你以前写的文章喂进去，融合喜欢且受众喜欢的博主拆解，铸文引擎按人格档案校准语感。流量核心是拆爆款基因：把之前找的 3 篇对标让模型解析，提取赛道爆款基因再写主题。

拆对标系统我命名为噬文引擎，完整版在文末，可复制给任意模型。它从七个维度解析：作者身份、读者是谁、来求什么、结构、语言风格、不用词、信息来源、情绪走向。情绪走向单独说：爆文是情绪过山车，低开或高开、转折在前三分之一还是中段、峰值靠冲突还是认知颠覆。把这条曲线扒出来，节奏感就有了。堆一万句“写生动点”也堆不出来。

学完后给主题，建议四行：主题、你的真实观点、目标读者画像、期望感受。第二行最值钱，有真实立场才不空；不填出来就是正确废话。第三行别糊弄，“宝妈”等于没写。哪个宝妈？几点刷手机？最愁什么？不解决睡不着？这叫活人画像。读者不是因喜欢看，是因卡点才看。

铸文引擎可调开关：脱敏对照表，我的版本里小红书→红薯，公众号→文章，抖音→某短视频平台，老板→领导，按需改。案例库路径指向本地目录，生成时按需读取。风格参考：IP 要像自己，可准备一段录音对话或投喂自己写的文章；流量则直接借鉴最热写法换表述。

实操心法：用对话框时，一篇一个新窗口，上下文别串味，标题正文下一篇分开写。真实案例必须手动加入。用 Agent 时上述问题会自动处理。不管哪种，别指望一次成型，800 字日更背后是上万字引擎、三套系统、20+质检，还要人工过。

模型相当于工作室，加速出文但不能完全替代。通用方案只能解短期问题，尤其流量必须随风口、爆点、热点实时调整。平台倾斜一直在变，别拿老引擎打天下。

模型选择：已有 Agent 基本不用纠结模型；仍用对话框需讲究。豆包擅长抖音口播稿，元宝语料偏公众号，点点适合小红书，千问偏淘宝带货，Kimi 上下文长适合长文，DeepSeek 算国产基线。原则：模型背后站哪家平台，就用它干哪家平台的内容。引擎一套通用。

**第五站 标题定生死——内容核心**

写完不等于完成 90%，只完成一半。用户给你的注意力是 3 秒，线下地推都知道街上拦人只有 3 秒，线上更残酷。标题没让人停下，正文再好也是零。标题定生死，好标题能破圈，好文章不能。

标题不是告知写了什么，是触发兴趣让人想点。先解决想点，再谈质量。

我用两层系统做标题，叫七罪引擎，完整版在文末。

第一层 开幕雷击七要素：金钱、异常、捷径、窥探、暴力、死亡、民族。金钱指具体数字；异常是反预期；捷径暗示更快路径；窥探是半遮半掩；暴力是冲突打脸；死亡指终结感。民族最易爆也最易出事，只讲概念，强烈建议不碰。前六个可自由组合，命中一个起效，命中两个以上点击明显提升。

第二层 人性七宗罪。贪婪：占有欲，标题触发收益、机会、损失。傲慢：优越感，可顺着读者或挑战自我判断。嫉妒：参照物要近，同起点的人产生的落差。愤怒：指出受害者与责任方。懒惰：对应 acedia，是逃避沉重但重要的事，非单纯想省力。暴食：用下一口填补不适。

把标题当钩子，先让用户想点，再用内容兑现。人性问题才是所有爆款的根。
