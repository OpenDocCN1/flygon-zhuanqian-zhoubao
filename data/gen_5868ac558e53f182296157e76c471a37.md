# 传统行业借力抖音起盘实录：从线下转线上，一年做到500万营收

> 来源：[https://p1m39y7kqh.feishu.cn/docx/Q76YdX281oFz0BxJnbicxnuTnZc](https://p1m39y7kqh.feishu.cn/docx/Q76YdX281oFz0BxJnbicxnuTnZc)

认识一下，我是河南做农村别墅施工的小王。今天把我们从纯线下干到线上引流，再用一年时间做到500万营收的经历摊开讲一下。

结合这段实操，我的结论是：90%的传统行业都可以用抖音获客，而且门槛比想象中低。

# 项目是怎么看出来的

1. 我家三代都在建筑圈子里，我爷爷当年是钢筋班长，计划经济年代的老手艺；我爸80年代北上，也一直干建筑，高中毕业就当上项目经理，算是国内经理制最早的一批人。
2. 但讽刺的是，正处在房地产和国家基建黄金期的那批人，反而没攒下该有的财富。看着我爸的人生反复起伏，我才明白一个道理：赚钱不难，难的是视野够不够看清全局。认知之外，你连钱的机会都看不见。
3. 2018年前我们主要做商品房大清包。2015到2018年，压款、垫资越来越严重，回款越来越慢，材料商也不肯垫资了。以前一栋楼能靠垫资干到封顶，现在三层都卖不了。行业疲态很明显。
4. 2019年开始承接一些政府乡村项目，比如乡村舞台、学校、村委会。
5. 就在乡镇上干一个乡村学校时，遇到一个县城医院的院长，他看了我们的工地，觉得比野队规范得多。后来请我们给他临街门面做两层。工程简单，但利润高，而且付款特爽快。业主当时就问“钱是先给你还是怎么着”。做工程的人都懂，大工地要交巨额保证金还要垫资，预付款都是奢望。他直接说给钱。我们最后拿了50%预付款，过程顺畅，业主很满意。这个单子让我种下了两个认知：大包工程顶好几个清包，乡村个人工程基本不用垫资。

有了这两个判断后，我开始留意这类活。2019到2022年我们又接了一些政府乡村项目，回款问题依旧存在，外欠账到现在还有一半。同时通过外地总包公司A转包，做了几栋农村别墅，积累了案例，也有了自己的判断。

当时我还在老东家上班，我爸在外面接转包。我自己在玩抖音，还剪过火影。我刷到A公司的号，发现他涨粉很快，而且真靠抖音接工程。

我就跟父母说，工地少操点心，多拍点视频发抖音试试。他们没当回事。我自己纠结了半年，2021年6月辞职全职入局。

# 第一阶段的撞墙

刚开始我觉得很简单，看别人发效果图配音乐文案就能几十万播放，我也去找对标。结果视频发出去播放500，折腾一个多月几十条下来还是那样，偶尔千把播放算好运了。我试过换发布入口、换发布时间、加话题、改标题，都没用。自我怀疑到了极点。

其实别人看起来简单的视频背后是有积累的。

从2021年6月到2022年初，整整七八个月，粉丝几乎没动。后来才慢慢转好。

# 方向的修正

买课、看教程、自己复盘后发现，我们行业内容大致分三类：

第一类是图片+配音，效果图切换，适合矩阵化，拼概率，成本低；
第二类是建筑模型动画，生长动画，讲解清楚，点赞转发高，当时头部有800多万粉；
第三类是真人出镜讲技术，有做的很不错的同行。

我们评估了一下：

第一类需要大量效果图，我们是施工队，图库不够；
第二类需要建模能力，我们当时没有；
第三类我爸干了几十年建筑，规范、工艺、工法都很熟，就是怕镜头。但这是我们最能复制的。

一个小提醒：做抖音别只看表面，要看对手看不见的地方花了多少功夫，也要从自己有什么出发。我也想过做动画，后来试了一个月放弃了，学习周期太长，正反馈太慢。

## 怎么找对标

1. 行业对标很好找，直接搜“农村别墅”。搜出来的就是能对标的清单，这是第一步。
2. 先定关键词。我们是农村别墅市场，就以“农村别墅”做基底。[PRE1]
3. 再延展长尾，比如农村别墅自建房、农村别墅施工队、农村别墅三层等等，用来找细分文案和领域。
4. 点进账号，把名字、电话、公司信息、店铺、位置都记下来，可以看出很多矩阵规律。比如名字很像的是一个集团，也有故意起名不像但背后是一家的。[PRE2]
5. 在搜索页按点赞最多+半年内筛选，能找到近期爆款，方便对标。[PRE3]
6. 观察分析：看粉丝量、营收体量。我的做法是刷100条视频，就能总结出内容形态。在我们行业，点赞几百算及格，几千算好，几万算运气爆棚。[PRE4]
7. 用考古工具看粉丝增长曲线，如果粉丝是早期积累的，现在不再涨，说明形式可能过时或用户疲劳了。
8. 最后结合自身。我们的优势是施工在行、现场实拍，模型动画不行、效果图也不行，所以现场口播讲解是成本最低、最快能出的。

# 实操细节

方向定了就开干。起初我把别人的稿子手抄到手机上，带到工地让我爸照着念，经常忘词。后来改成手抄到本子上，做问答形式。

刚开始用别人的普通话稿，河南市场接受度一般，我爸普通话也不标准。录了几条后改成家乡话，反而效果更好。原因有两个：目标客户就是河南人；用自己的话讲更自然，有感染力。

现在我们的工作流是：选题定了后，自己用大白话重写一遍，读一遍，通顺逻辑对就行，不求逐字稿。故意保留语气词和停顿。

一个小技巧：看到别人的文案，用自己的话复述一遍，通过微信转文字，再整理成文字，就是口语化稿。前期多手抄，能快速提升文案感觉。

分工上，我爸负责施工和部分直播，我负责拍摄剪辑、私信、电话成交、报价设计。出镜少，产出效率低。后来改成每周去一次工地，一次性拍一周的素材再慢慢发。[PRE5]

# 抖音的核心是什么

不断试错后发现，抖音最重要的是选题，几乎决定了80%的流量。开始为播放量而播放量，后来发现转化才重要。

我们把内容分四类：

1. 流量类 30%，解决客户普遍关心的问题，比如【农村建房要办哪些手续】。点赞收藏高，转化低，主要用来涨权重。
2. 实力+质量展示类 20%，讲工艺、工法、施工过程、完工效果。流量一般，但必须有。
3. 签单类 10%，客户证言为主，不能太多。
4. 引导客资类 40%，软广为主，最多最重要。曾有一个视频爆了，一上午电话接到关机。

引导客资的公式我们总结为：圈定人群+人群痛点+解决方案+购买理由+优惠活动+指令。

举例：河南有建房计划的朋友，如果没时间管、材料工艺不了解，可以找我们。我们专注农村别墅，包工包料包设计，保质保量保工期。现在金秋十月正是建房季，材料价低。现在只要xx就能起一套。十一期间到店送xx，签单送xx。点下面链接联系我，还能免费领一套图纸。

到2022年初，流量开始有起色。这时我加了抖加作为杠杆。

# 抖加的使用

花钱买首发流量是绕不开的门槛。2022年我们只投了不到一万，带来约5000个私信。

做法是：视频发出去后，到第二天早上能破万播放的，基本投100-200抖加测试反馈。反馈好就追投。投放时先找对标账号，尝试过点赞转发客资，后来直接用智能投放，效果也能接受。

注意：抖加是杠杆，不是救命稻草。

# 最难的是心态

2021年辞职后半年，我每天学知识做执行，却几乎没反馈。这个阶段最难的不是技术，是不知道哪些动作有用，哪些是废动作。即便偶尔破万播放，点赞只有几十，当时也没意识到这在我们阶段已经可以复制了。

有老师、有同行交流很重要。没有的话，内耗会非常严重。我们当时甚至想过把施工剩的钢材卖了再撑一个月。好在家里人支持，熬了过来。

# 意外收获

2021年下半年抖音没起色，我把内容同步到了视频号和快手。2022年某天登录公众号，发现粉丝已经四万多。因为视频号连着公众号，很多用户不知道怎么关注视频号，直接关注了公众号。现在公众号七万多，快手一万多。

但这也提醒我，如果只想做视频号，最好别和公众号绑定。我的视频号现在才一千多粉，我确信都是通过视频号被动关注公众号造成的。因为点关注时很多人分不清是关注视频号还是公众号。[PRE6]

# 流量风险

1. 流量起来前一定要把承接做好。2022年3月开始流量起来，两三个月引了3000-4000人，但因为运营销售只有我们两个人，回复跟不上，错失很多。
2. 不要把鸡蛋放一个篮子。抖音不能碰的红线别碰。
3. 2023年初直播时不小心说了句“两会期间砖厂不生产”，账号封了三个月，流量直接归零，后续一直起不来。
4. 那时就该多账号布局，我们是IP属性，应该好复制。封号后也没立刻转战当时已有起色的快手直播和视频号直播，导致直播完全停摆。现在回头看很亏。

# 现在还能做吗

全国新建乡村住房每年约200万栋，户均造价20-100万，是万亿级别市场。从今年起，我们县里进场做别墅的就有10家以上。建房有风气属性，我们考察别村小别墅占比60%左右，本地一个村一两家，市场空间很大。

但这个行业天花板大概在3000万左右。原因：

第一，目前没看到有到5000万体量的公司。有人想做全国化，但别墅面积小、项目分散、管理成本极高，最后暴雷转型。现在有尝试联营加盟，更多像收加盟费。

第二，乡村别墅无法集中建造，每一栋都是定制，一宅一设计，难以标准化。施工半径最好控制在50公里内，做到区域第一，集中交付才能降成本。如果能把50公里内的引流、成交、回款、交付跑通，再多点开花，才有可能突破3000万。

现在入局的人鱼龙混杂，有装修转行的、有开挖机的、几个人合伙开公司，也有老民房队。回款快让人误以为钱是自己的，花钱大手大脚，导致暴雷。做过商品房施工管理的人谨慎做是可以的，但一定要以客户满意交付为底线，发心不正会坏名声。

从抖音来看，现在依然能做，只是卷了。以前很少真人出镜，现在基本都是老板亲自上。以前一个手机开播，现在绿幕直播间都搭起来了。相比女装、数码，我们行业运营还算粗放。但即便如此，随手拍+留电话的粗糙方式依然能引流变现。短视频直播+传统行业，空间还很大。
