# 我是如何用半年时间把拼多多小店做到日进数百的

> 参考来源：[https://fizwc60vtp.feishu.cn/docx/UbhSdMtqdoW09vxGDL6cPnfengb](https://fizwc60vtp.feishu.cn/docx/UbhSdMtqdoW09vxGDL6cPnfengb)

大家好，我是XM。平时很少写东西，今天把自己在多多上从0起步到稳定变现的实操经历梳理一遍。绝对不是什么大神，单纯把踩过的坑和跑通的方法摊开，希望能给刚入场的人一点借鉴。文末会放我自己整理的起店流程。

# 七月：懵懂起步期

今年七月我才开始系统了解电商。五月时我参加过小红书航海计划，眼看要退店才拿到第一单，对电商兴趣不大，也没什么积累。转到多多开店纯属被朋友拉进来。

那会儿一窍不通，也没有成体系的流程。自己去注册、交了1000块保证金，朋友直接给了三款货，就这么上线了。最开始连采集软件都不懂，生怕操作错，硬着头皮上。结果一周左右就开单了，金额不大几十块，但当时已经激动到不行。

干到半个月左右，数据忽然起来了。

[PRE0]

回忆起来当时投入产出比非常好看，一天流水800，净赚大概五百多，自我感觉很不错。可我有个致命的毛病，就是对已经吃透的项目很容易疲惫。拆完流程、赚到钱后就觉得索然无味。所以七月我只做了半个月，收工5800多块就撤了，后面去折腾NFT和搬砖了。

七月做的品类是加密教程。那赛道确实暴利也明显违规，如今依然有人在做。加密课基本都是最新资源且强版权，和考公考研资料一样，分分钟被追责，纯小白千万别碰。我当时就是不懂瞎撞，运气成分居多。那段时间知识付费找渠道花了500，还差点被坑1200，后来碰到一个不错的同行，聊了他的盈利逻辑和品类，还介绍了上游。

# 八月到十月：矩阵铺店期

八月又被拽回来了。原因是看到朋友日入几千，羡慕得不行。他一直不肯透露具体做什么，闷声发财我也能理解。等他手上那批店封得差不多了，我提议我这边还能开店，先排个队。最终我们一起上了五家左右，单店最终收益在1万到3万区间。同一批店里，出单表现参差不齐，爆品概率肯定存在，但归根结底还是选品和运营。

整体看数据不算差，停止的原因比较多。合伙人不想继续了，家里也有事分心，时间精力不够。虽然店铺可以半自动化，但最关键的节点是合伙人退出。退出后我接手运营一周，店铺底子不错，超过一个月没上新，单店日净利还能稳定在600左右。对比九月下滑约一半，主要因为同行卷进来了，风险也在累积。这批店最后就关了。外人看来开店不容易，但我们做的这种品类，店铺更像是消耗品：不能长期卖，随时有被起诉风险；平台也会抽风随机封店，我们自己测试也被封了四五家。

八到十月主打的是考研考公资料。这个方向对新手来说也非常高危。电商平台取证很方便，一旦侵权，赔的可能比赚的多。身边有学员因为卖资料被起诉的，心理压力极大，睡都睡不好。当然，真被起诉也不必恐慌，对方基本要钱，一般都能协商解决。

如果你不想承担任何法律风险，又想靠卖资料赚大钱，基本不现实。哪怕只是网盘免费分享资料，也会有打假人盯上。

# 十一月：换赛道试水

十月底撤掉高风险项目后，十一月我转做竞争激烈但风险偏低的素材类。等于放弃了已跑通的高利润模型重新开始。

十一月开了五家店左右，日最高500多，月末累计8000多。但利润很薄，前期投入产出算下来是亏损的，前半月基本没赚，后半月才回血。

[PRE5]

我的总结是：这个赛道确实不好赚钱，和之前比差距明显，售后也很多，各种奇怪问题不断。

我没有直接放弃，蚂蚁腿也是肉，先当保底。想法有点消极，但很快被推翻。因为同样做这件事，有人赚有人亏，我说不好做，其实就是没选到好品。选品前期没经验很正常，但选够100个、1000个后，感觉就有了。

# 选品雷区

最要命的是版权风险。一般可以通过企查查、阿里商标、天眼查或官网检索，但大量未登记的作品照样能起诉，因为原创者能提供创作过程素材即具证明力。所以强版权课程要极度谨慎，一单赚的可能不够赔一单。

我有过被诉经历，也咨询过律师，给一点参考。

天眼查商标查询 https://shangbiao.tianyancha.com/
天眼查著作权查询 https://banquan.tianyancha.com/rj
天眼查专利查询 https://zhuanli.tianyancha.com/

一、强版权课程
东奥、正保等会计类课程，大机构的财务课，带名人名字的考公考研资料，影视版权、图书版权，被诉概率极高且赔偿高。部分机构+律师团队非常活跃，不管是否售卖先取证，或直接拍一单取证。

二、擦边类
平台上只要图片、视频或文案存在擦边，链接很容易被处理，进而导致封店、降权、限制。典型如写真、擦边私照、私房视频等。

三、低俗类
撩妹技巧、恋爱课等被归为低俗，网盘都难以放出，链接易被投诉，店铺易受限甚至封禁。

四、封建迷信
风水、易经、算命、国学等，投诉后容易被禁售下架，但从业者轮着做。

五、代办服务类
务必确认渠道货源合法。见过有人低价买京东卡，再用卡在京东买苹果机，最后机器被追回人被抓。自己提供的服务合规且可持续才OK。另外警惕客户提出不合理要求，比如加钱让你做违规操作、扫码、接收压缩包等，木马中招案例很多。

# 下一步规划

年尾快到了，十二月我报了大航海风向标和小红书店铺。五月没做成的小红书店，一月我回来了。风向标主要是提升信息挖掘能力，小红书店希望能直接变现。这次会用其他平台验证过的品先行测试，效果好就写一份小红书版SOP。最近还玩了两个小副业，红包封面和铭文打新。红包封面基本停了，没流量闲鱼还有人问。铭文打新一直没赶上，倒也没什么遗憾，打新有肉也有坑。
