说实话，从 Creem 突然被关停，到在 Waffo 上真正把收款跑通，这一路踩过的坑，比想象中多得多。今天把这些经验整理出来，希望能帮你少走点弯路。

先说商品接入。千万别偷懒，每个商品都要建独立的 Product ID。代码里不要用价格去反推商品，更不要在前端页面把 Product ID 直接暴露出来。正确的做法是：把你自家网站的套餐 ID 和 Waffo Product ID 做一层映射，后端悄悄对应好，这样才安全。

然后是服务端创建 Checkout。Waffo 官方提供了 TypeScript SDK，你需要在服务端用 Merchant ID 和 Private Key 发起创建请求，然后把托管收银台的 URL 扔给浏览器跳转。这里有一条铁律：Private Key 只能藏在服务端的 Secret 里，绝对不能泄露到前端。

接下来配置生产环境 Webhook。路径是 Pancake Dashboard 的设置 → Webhooks → Production，格式记得选 Raw。如果你卖的是一次性积分包，至少监听 `order.completed`；如果是订阅制，那 `subscription.activated`、`subscription.payment_succeeded`、`subscription.updated`、`subscription.canceling`、`subscription.uncanceled`、`subscription.canceled`、`subscription.past_due` 都得挂上。涉及退款的话，还要加上对应的退款事件。

别忘设置提款账户，然后再做验证、最后上线。提款账户要填的信息包括：姓名拼音、中文名、身份证号、国家地区。提款方式可以在支付宝和银行卡里选。
