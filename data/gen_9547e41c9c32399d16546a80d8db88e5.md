# 21 天航海，我靠 ChatGPT 撸了 20 个 Chrome 插件，这套方法你也能抄

一个人的航海 21 天，20 个 Chrome 插件上线。这件事放在一年前，我自己都不敢想。

它不是玄学，而是我把 ChatGPT 的用法从“聊天”升级成了“编程流水线”。核心就两个抓手：Code Interpreter 和 Custom Instructions。通过 10 条我自己总结的 ChatGPT 编程思路，我给它喂了一套专属指令集，让它能从零到一全程接管一个插件的生命周期。

具体怎么做到的？简单说就是让 ChatGPT 扮演一个完整的开发团队。

我只需要抛需求，它就能自动拆解成：需求分析 -> 开发步骤规划 -> 文件目录设计 -> 代码实操 -> 代码自审 -> 图标生成 -> 上线材料整理 -> 推广文案输出。一条龙，无需手把手。

更进一步，我把这 10 条编程思路固化成了可复用的 GPTs。现在它不只是能做 Chrome 插件，还能直接拉起 WordPress 插件、网站落地页、Python 小工具的开发。

如果你也想把 ChatGPT 变成你的外挂程序员，这篇文章里的思路可以直接拿走用。

全文拆解了以下几个关键点：

Code Interpreter 和 Custom Instructions 到底颠覆了我们什么认知

ChatGPT 的自动化编程和流程化编程有什么区别，怎么玩

如何用 Custom Instructions 秒启一个全新项目

如何用 Custom Instructions 对已有项目做二次开发和迭代

Code Interpreter 在编程实战中会遇到哪些坑

面对复杂产品，如何用更合理的思路引导 ChatGPT 出高质量代码

我是怎么把这套方法打包成 GPTs，帮你快速启动 Chrome 插件、WordPress 插件、落地页和 Python 应用的
