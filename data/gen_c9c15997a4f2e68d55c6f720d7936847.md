# 一、投放是趋势，且聚光依然有红利

## 1. 平台收紧，自然流量断崖

小红书从九月底开始，自然播放普遍腰斩。原本一百多播放的笔记，现在一二十播放是常态。这不是个例，我聊过的上百个做小红书的人都有同感。

平台商务团队现在天天给商家打电话猛推聚光开户，催着开通。这就是小红书商业化加速的信号。

官方之前发过一次公告，我当时以为只是警告，后来真执行了。最近违规率明显上来了，看这篇文章的你账号应该也有体会。

[PRE2]

## 2. 投放迟早要面对，而且门槛很低

平台越成熟，白嫖流量的难度越大。小红书如此，其他平台也一样。能做免费流量当然好，但投放不是高不可攀的技术活。

投放你不一定非要做，但一定要会。开个户就能起步，不是大公司的专属，小团队能投，一个人也能投，而且非常轻松。

如果你现在靠自然流就能获客，开上聚光不仅能降低封号风险，还能用杠杆把业务直接拉升数倍。

## 3. 聚光目前性价比极高

能投放获客的平台里，聚光的成本控制一直比较友好。产品迭代一年多，用户画像数据积累很厚，功能也越来越全，成熟度够了。

再加上小红书做素材成本低，适合拿来做投放的笔记也好找。从入门角度看，聚光几乎没有硬伤。

[PRE3]这张图的意思很直观，会用聚光的人，已经能干掉至少一半同行。

## 4. 投放的核心始终是内容

在任何信息平台，拿流量的底层能力都是做内容。投放只是把内容放大。投放过程中，你的内容判断力也会被倒逼出来。

当内容能力到位了，在各个平台获取流量就变得异常简单。

下面开始复盘我的实操。

# 二、模仿并优化，一篇笔记完成破局

## 1. 知乎、抖音、视频号都试了，最后选小红书

到武夷山后熟悉了茶品线，就开始琢磨互联网卖茶怎么玩。去各大平台找标杆，纠结平台选择。

抖音？我早期玩过很多项目，结果都不理想，而且我的号早在20年就被封了，被卷怕了，直接放弃。

视频号？人群是合适的，我却对视频号几乎零认知，没选。

知乎？我写了一篇，冲起来了，却卖不出去茶，回头一看纯属浪费时间。

小红书？能看到同行在卖茶，自己也有点经验，有把握。最后就定了。

现在回头看，选项目、选品类、选平台，第一准则是选自己熟悉的，尤其是资源有限时。没正反馈很难坚持。

当然也要顺应趋势，我再熟知乎也很难把茶卖好。

## 2. 只抄干货模板，涨粉不转化

确定做小红书后，天天研究同行，找近期低粉高播放的爆款，开始硬抄。火的是“每天认识一款茶”系列，几天涨粉上万。

[PRE5]这个模板到现在还有流量，发出来就能涨粉。

但粉是粉了，茶卖不出去，跟在知乎写文章一样，数据好看而已。好在练出了做爆款内容的方法论。

粉丝量、播放量这些指标大部分时候只是自嗨，对变现帮助不大。很多人被这些数字困住，我后来把它列进了小红书十大“谣言”。

## 3. 改抄带货笔记，来了第一个客户

幡然醒悟，我应该抄卖货笔记。前面那些数据好看但没用，卖货笔记数据可能不显眼，却能直接产生咨询。

## 4. 抄完优化，一月卖十多万

抄完有手感了，知道什么结构能转化。所有有效内容本质都是击中用户某个点。

买茶的用户到底在担心什么？正不正宗？价贵不贵？有无溢价？

我把小红书、淘宝、抖音、视频号所有茶叶相关的高互动内容和用户评论都翻了一遍，归纳出核心顾虑：

1. 价格是否透明实惠，有无高溢价
2. 是否源头直供
3. 品质和性价比
4. 是否打药，是否健康

把封面改成直击价格痛点，主图的文案就是“买一斤也是批发价”。

[PRE8]层图和标题里再补充茶厂直供、证书、评价、有机证明等信任状。

笔记直接爆了。后来同行人手一篇这个模板，但早已不如最初效果。

[PRE9]后来在街上看到茶叶店门口的标语“买一斤都是批发价”，才发现这些卖点在武夷山早已烂大街，只是没人搬到线上。

发布后一个月，微信新增1000多人，卖了10多万茶叶。紧接着账号被站外导流限流。

# 三、被迫开聚光，反而开了新局

## 1. 只是想买个“白名单”

账号被限只能想办法。彼时聚光很火，听说投了就能开白名单，留微信不违规。于是找销售开了户。

投放我几乎是零经验，只在抖音混过千川。心里其实排斥，觉得投放很高端。其实根本没有门槛。

当时目的很简单，花钱买平安，交保护费别封号。

## 2. 一投就爆，加不过来

开户后每月要消耗几千才保白名单，只好硬投。没想着赚钱，就用千川的记忆把爆款笔记直接拿去投。

结果直接起飞，原准备的两个微信号应付不过来，连夜又开几个号接单。

算下来当时获客成本约10元/人，对中高客单的茶来说非常低。最便宜的茶也要两三百一斤。小红书用户质量高，成交率高，复购也稳定。

## 3. 上瘾后加大投入

尝到甜头自然放开投。按爆款模板复刻多篇，开多个广告户，天天建计划跑。累计广告消耗约36万。

一年下来，私域加店铺的销售额达成目标，同时沉淀了4万左右高信任度的客户。

# 四、聚光投放踩过的坑

## 1. 别找官方销售开户

我第一个户是官方销售开的，没有返点。后来认识服务商才知道有返点。账号绑定后想换很麻烦，历史数据和模型会清空。

官方销售会要营业执照，一旦给就被锁定，之后只能找他开，没返点。现在服务商返点至少18%。投几十万，返点差出好几万，千万别理销售。

[PRE12]

## 2. 别信代运营

很多服务商会推代运营，统统别信。90%没含金量。真正厉害的团队不会靠代投赚钱，除非后端极强愿意做分成。只赚服务费的，大多是水货。

投放必须自己来，只有自己最懂业务和用户，才能做出有效素材，掌控节奏。

## 3. 电商投放目前很差

无论是聚光还是乘风，小红书电商投放效果都不理想。用户电商心智弱，GMV基数低，数据积累不足。获取客资还可以，直接投店内转化基本亏钱。

等到小红书电商GMV达到抖音十分之一时，或许才有机会。现在先沉淀。

[PRE13]

## 4. 别死磕爆款

一篇爆款出来后，我整年都在找下一个爆款。爆款可遇不可求，运气成分大。

更稳的做法是测出多篇中等效果的模板持续跑，细水长流，而不是非要一个万赞起飞。

# 五、精简高效的聚光投流SOP

复盘下来，核心就一步：做出一篇能打中用户需求的笔记模板，然后让聚光一直跑。其他都是锦上添花。

素材不行，策略再精细也没用。把精力放在素材。

## 1. 先做干货涨粉，养号冷启动

新号直接上硬广投流，前期浪费很高。先发行业干货内容涨粉，给账号积累用户画像。

比如我一开始发的茶知识、茶文化笔记，就是典型的干货，容易爆，能涨粉，虽不直接变现，却为投放打底，相当于低成本冷启动。

## 2. 找可投放模板，抄比原创快

这是最关键一步。

对用户洞察弱没经验，直接抄。找右下角带“赞助”标的投放笔记，直接复刻操作简单高效。

[PRE15]多找几篇，逮着抄，别有心理负担，不盗图就不会违规。

如果洞察力强，可以模仿并优化。像我当时的做法，把全平台用户提问、评价全部梳理一遍，找到核心诉求，再优化同行笔记。

## 3. 测试模板，有两种打法

第一种，自然流测。先发不投，看自然流下有没有评论私信咨询，有就说明模板可用。自然流跑出数据再投，转化率更高。周期约一周到一个月，金钱成本低。

第二种，直接投。懒得等自然流积累。笔记无数据，平台要时间找人，前期可能亏钱建模。只要亏损可控就让它跑，前期亏几百建模很正常。投放本质就是放大自然流跑得好的内容。
