# AI 绘图灵感与 Prompt 工具清单

> 原文：[`www.yuque.com/for_lazy/thfiu8/knpet848c7370wur`](https://www.yuque.com/for_lazy/thfiu8/knpet848c7370wur)

发布：教書将
时间：2023-03-22

这十款站点各有分工：有的负责找参考图，有的负责产出可执行的描述文本，有的则在中文环境里更好用。挑几个顺手的方向去试，或许能带来新的思路。

1、OpenArt.ai
它相当于一个跨模型的检索库。输入任意主题词，就能看到不同生成工具围绕同一主题给出的结果。官方介绍称其收录量超过一千万份，DALL·E2 是其中之一，Midjourney 与 Stable Diffusion 同样在列，并且每条结果都会附上它所用到的 prompt 参数。

2、arthub.ai
它更像一座灵感画廊，绝大多数作品都配有完整的文字描述；你可以像逛图站一样按分类浏览，也可以输入单词直达目标。碰到满意的成品，把它的描述填到出图工具里，往往能复现类似效果。

3、promptomania.com
它面向需要把想法转成标准格式的人。内置多套指令模板，Midjourney 与 Stable Diffusion 都在支持之列，DreamStudio 同样适用。选定目标模型后，它会引导你逐项设定色调、画风、参考画师、画面比例，最后拼出一段可直接粘贴的完整指令。

4、lexica.art
它存有百万级 Stable Diffusion 出图记录，每一条都配有文字说明和成品图。用它找方向非常轻松：搜索栏里写几个单词，或用一张现成图片作为钥匙，它就能返回风格跨度很大的结果。任选一张点开，右侧即为该图所用到的全套描述，旁边的一键复制按钮可以直接取用。

5、prompt Helper
一款配合 Midjourney 使用的轻量辅助工具。写作思路卡住时，它能帮你拉出一段可继续调整的描述草稿。

6、KREA.ai
它以百万级 Stable Diffusion 出图结果为基础，支持按主题词筛图。维护方还设计了点赞、收藏和分组功能，方便你日后回看此前标记的项目；代码库目前已经对外开放。

7、AI 画廊 aigallery.top/tool
它在国内用户圈里口碑不错。内部的 prompt 库覆盖了相当多主题，也允许直接查看热度较高的描述；出词模板同时支持 Midjourney 与 Novel，同时也能为 Stable 生成对应的指令，几乎一步就能得到可用的完整参数。

8、weirdwonderfulai.art
它用 Disco Diffusion 汇总了一批署名风格研究页。想弄清某位画师的署名会导向怎样的画面质感，可以来这里对照查看。

9、
这个站点更贴中文浏览习惯，头图区域以女性人物居多。

10、词图
它在中文指令上很在行，功能也十分顺手。
