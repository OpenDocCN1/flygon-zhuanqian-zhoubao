# 用六个维度给生意做体检

最近在生财社区保持连载的节奏里，我把注意力放在了更底层的判别模型上。上次聊盲盒时提过一个拆解手势，今天把它系统化。

任何能跑起来的商业模式，都可以用同一套坐标去测：获客投入产出、成交转化耗时、履约人力消耗、客单金额、利润空间、复购概率。六个维度串起来，就是从曝光到再次购买的完整链路。覆盖面越广，模型越稳健；能占到四个以上，通常就具备存活条件。

# 先把前三个效能拆清楚

**获客投入产出，本质是时长与制作难度换算成触达规模的结果。**
同一投入下，耗时越短、制作门槛越低、曝光越大，效能越强。
一条朋友圈，几分钟可发，覆盖上千熟人；一条口播短视频，半小时剪辑，播放数千；一次直播，四小时在线，观看过万；整理一套小说推广文案，分发给数百名推广者，每条带来数百阅读；花三天做一条拆解短片，播放破万；花一周写一篇购物笔记，阅读破万；花两周拍一条老板访谈，播放十万。
衡量点就是投入时长、内容门槛、回流流量的平衡。

**成交转化耗时，核心是专业门槛高低与能否批量处理。**
带货短视频自带购买入口，可以批量触达直接成交；购物笔记自带商品卡，检索即下单；资料类引流到私域商城，一键成交。
短视频、直播引流到私域再成交，朋友圈触达、群内营销、一对一电访、线下面谈、大型会销。线上成交基本可以做成标准流程，不依赖硬专业；线下场景才需要极强的现场能力。
设计师沟通需要长时间单人沟通；卖房需要带看多套，最后成交未必落在自己手中。
专业要求越低、覆盖面越广，成交耗时就越少，本质是销售时间的使用效率。

**履约人力消耗，看的是是否需要亲自干、需要多少人天。**
做佣金带货、带货文章，履约由商家完成；资料、低价课程，付款瞬间即完成交付；社群、知识星球需要持续运营、不断输入内容；训练营、陪跑、咨询需要设计方案、流程、答疑；做品牌、做工厂需要生产、质检、售后；装修一整套住宅需要一队人月余工期；盖一栋楼需要团队半年。
消耗时长越短、人力越少，履约效能越强。

客单、利润、复购这三项不必展开，理解的人自然明白。

# 六项叠加，业务画像立刻出来

**获客强 + 成交强 + 履约强 + 单笔低 + 利润高 + 复购弱**
小说分销类：月收益千到两万。搬运知乎片段引流，引导去知乎充会员拿佣金。
获客强：素材丰富、框架固定、搜索自带流量。成交强：搜暗号充会员即得佣金。履约强：无需履约。单笔低：十几二十元。利润高：五十以上。复购弱：一次性消费。

学习资料1.0：月收益千到两万。考研、高考资料等。
获客强：素材好找、模板化。成交强：导私域商城成交。履约强：资料自动发放。单笔低：十几到几十元。利润高：五十到百。复购弱：基本无。

**获客强 + 成交强 + 履约强 + 单笔高 + 利润中高 + 复购弱**
学习资料2.0：月收益两万到百万。资料引流后对接高客单陪伴课程。
获客、成交、履约与上同。单笔高：数千到十几二十万区间。利润约十。复购弱。

**获客强 + 成交强 + 履约中低 + 单笔中高 + 利润高 + 复购强**
减脂食谱：月收益十万到两百万。在笔记平台、抖音发食谱。
获客强：素材海量、框架化。成交强：流程化网销。履约中低：卖产品无需履约，陪跑营需专人监督。单笔：几百到上万。利润三十以上。复购强：减脂是循环需求。

**获客弱 + 成交强 + 履约弱 + 单笔高 + 利润高 + 复购中高**
商业IP拆解，例如小徐与我这类：月收益十万到两百万。
获客弱：拆解耗时、依赖信息源，不易批量。成交强：流程化网销。履约弱：社群、陪跑、合作均需专业时间投入。单笔高：数千到六位数。利润七十以上。复购：陪跑几乎无续费，社群能续费。

**获客强 + 成交强 + 履约强 + 单笔高 + 利润高 + 复购弱**
知识付费，以某头部主播为例：月收益十万到五百万。
获客强：口播门槛低。成交强：直播挂车。履约强：课程售出即完成交付，可连麦答疑。单笔高：小几千。利润百。复购弱：课程偶尔迭代。

# 复盘的逻辑

任一生意都能用这六项打分。
获客效能强，意味着内容可复用、可矩阵、可培训，可以单独放大做规模。
成交效能强+履约效能强，意味着销售和履约都能标准化，不需要高专业度，也不用创始人一直扛。
这就决定了，赚多赚少取决于流量来得多不多。学习资料、减脂食谱就是典型。

如果获客、成交、履约三者里有一项是短板，就很难靠复制放大，只能靠提单价、提利润、做回头来补。IP拆解类就是典型。

把现在做的生意，或未来想做的方向，用这六项打一遍分，短板自然现形。
搞清楚底层机理，才知道该把力气用在刀刃上。

本文先到这里。感兴趣的可以把身边生意按这六项拆一拆，评论区聊聊。
