# 先搞懂这些基础概念

## Colab

Colab 是 Google 提供的在线云端开发平台，可以把它当成一台远程云主机。链接上去后就能直接调用平台提供的 CPU、GPU 算力做各种任务。因为训练和绘图对显卡要求很高，普通本本往往扛不住，所以 Colab 在 AI 和机器学习圈里特别吃香。

本质上它就是一台搭载 Linux 系统的云服务器，现在用的是 Ubuntu 18.04，打开浏览器就能跑 Python 代码。

[PRE2]

Colab 分免费和付费两种。白嫖账号每天能用几小时，配置大概是 12GB 内存、15GB 左右显存、55GB 硬盘。同级别能带 GPU 的云服务器租金都很贵，Google 这波算是相当良心了，尝鲜和轻度使用完全够用。

小问题：
如果这几小时不够用怎么办？办法当然有，多注册几个 Google 账号就行，一个账号玩几小时，几个账号连起来就能玩更久了 :-)

## Github

Github 是程序员的聚集地，开源文化的核心阵地。大量的优质开源项目都在这里公开共享，找项目、学源码都特别方便。2018 年它被微软以高价收购。

## Hugging Face

Hugging Face 可以理解为 AI 领域的 Github。在这里能找到海量的模型、数据集、文档和免费教程，全部开源。开发者可以在前人成果的基础上继续迭代协作，做出更好的东西。

## Stable Diffusion

扩散模型是当前最顶尖的生成模型之一，能产出高质量多样化的图片。Stable Diffusion 正是由 Stability.ai、Runway、LAION 等机构联合打造的文本生成图像扩散模型。简单说，它提供了一整套把文字 prompt 转成图片的算法与实现。用它训练好的模型文件就能把你的描述变成本地风格的图像。没有 SD，就没有后面那么多模型。

Github 地址：https://github.com/CompVis/stable-diffusion

## Stable Diffusion WebUI

这是一款基于 Stable Diffusion 的网页界面，极大降低了使用门槛。没有它的话，只能靠代码或命令行操作，上手难度很高，这也是 AI 绘画快速流行的重要原因之一。

Github 地址：https://github.com/AUTOMATIC1111/stable-diffusion-webui

## NovelAI、Waifu1.3、Stable Diffusion1.4/1.5 等模型文件

这些都是在 Stable Diffusion 基础上训练出来的模型文件。网上模型很多，有官方的也有个人魔改的，不同模型带来的画风差异很大。比如 NovelAI 和 Waifu 系列偏二次元动漫风，Stable Diffusion 1.4/1.5 用 LAION-5B 这个最大可公开访问的多模态数据集训练，所以风格更广更写实。你可以根据喜好挑选，也可以自己尝试训练。

上图从左到右、从上到下，分别是 novelai、waifu1.3、sd1.4、sd1.5、midjourney-v4-diffusion、redshift-diffusion 用同一条 prompt、相同参数生成的效果。可以明显看出 novelai 和 waifu 的动漫味十足，其他模型则更偏向写实。

### 释放资源

用完记得释放，不然会受时长限制。点右上角 【连接】->【断开并删除运行时】。
