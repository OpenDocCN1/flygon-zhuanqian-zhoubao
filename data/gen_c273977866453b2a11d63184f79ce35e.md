我把一套“多专家并行审稿”的工作流跑了一遍，效果很直接。

让 5 个 Agent 分头审一个产品页：商业转化、文案高级感、视觉是否能卖货、合规漏洞、信任度，最后由一个 CPO 角色汇总过一遍。打分只有 3/10，笑死。审出来的问题却特别值钱：

AI 以前自己编的“已产出 12000+ 张、评分 4.9 星”这类假宣传，全被挑出来删掉，换成能核验的真实产品信息；用户评价改成口语化表达，还刻意保留一条 4 星带瑕疵的评价，全五星反而不像真的；“照片阅后即焚”这种说不准的绝对承诺，也改成了可兑现的表述。按清单改完才敢上线。

这套审改本身也是 AI 分工出来的：先拆成 5 个独立审查 Agent，各自出意见再互相沟通，最后由 AI 按产品营销的反馈做修改。

想真·变现，还得补最后一步，很多人卡在这儿：

- 支付必须走真实校验
- 收款账号、客服联系方式、经营主体，都得是实名可查的
费率和政策会变，签约前务必去官网核对一遍。验证期能简化的都简化，等要转正，这几项一个都不能少。

### 个人没执照，怎么接钱
问得最多的问题。产品能跑了，却被收款卡住。最快能用的个人通道我整理好了：

| 路线 | 代表 | 费率 | 备注 |
|---|---|---|---|
| 个人聚合支付 免执照 | XorPay | 微信 0.5%、支付宝 0.38% | 官方服务商模式，不碰资金，直清到卡，开发者口碑最好 |
| 个人聚合支付 免执照 | 虎皮椒 | 1–2% 左右 | 官方服务商模式 |

| 官方商户 | 微信支付/支付宝商户号 | 0.6% | 费率稳定、通道最稳，但需营业执照，是正规化终点 |

选法就一条：钱要由微信/支付宝官方直清到你名下银行卡，不经过平台二次结算。行话叫直清、不碰资金。凡是款先进平台账户再转给你，风险高。

拿到收款权限后，让 AI 参照支付平台的接入文档直接连上就行。

延伸玩法：同一套网页代码可让 AI 改成微信小程序。好处是能挂微信流量主赚广告，同时用户在小程序内一步唤起微信支付，下单不扫码，转化更顺。注意小程序的支付能力需要商户资质，个人主体不行，需个体户或企业。

## 八、真实市场验证：这类产品怎么卖、卖多贵

动手做表情包变现前，我先让 AI 带登录态去小红书扒现成的在卖案例：谁卖、定价、评论区在问啥。结论如下：

### 小红书高互动笔记的价格锚点
| 品类 | 市场价 |
|---|---|
| AI 写真电子照 | 9.9/张 |
| 写真 6 寸带相框 | 29.9 |
| 写真 A4 相框 | 49.9 |
| 证件照 对标线下照相馆 | 100–700 |
| 宠物拟人代做 | 100+/张 |
| 表情包 | 微信表情平台基本不赚钱，有从业者三套作品总收入约 700 元，多是亲友打赏，可作引流钩子 |

参考这个锚点，我给拾光肖像馆定的是 9.9。

### 评论区就是需求单
爆款笔记的评论区都在刷“怎么打印”“能做成年人吗”“水印怎么去掉”“软件在哪下”。博主只给提示词，裁剪、去水印、拼版打印全靠用户自己摸索。这就是工具的超越点。

例如 2000+ 赞的《0 元入园照》笔记，168 条评论里高频是“水印怎么去”“怎么打印”。这些未被满足的需求，正是工具要补齐的。

销售打法：国内能跑通的路子是免费内容当钩子、评论区引导进群，统一回复“进群领”，沉淀到私域再转化；轻产品可以直接挂链接“9.9 解锁”。我的几单就是朋友圈随手一晒，连笔记都没发，后续数据再跟进。

合规提醒：平台在打击纯 AI 批量笔记和无资质售卖虚拟资料。口径用“自用/电子纪念/入园/头像”即可，别承诺“官方认可的标准证件照”；引流笔记保留真人感，别做硬广。

## 九、线下实战验证到的几个判断

不再说“活动很成功”这种空话，写几件我亲眼看到的。

### 1. 11 个人 3 小时都做出成品
现场 11 位圈友用 Codex 实战，3 小时各自做出一个能跑的产品工具。方法不只在我身上成立，普通人上手，下午就能出东西。

一个规律很明显：先想清楚“为谁做、解决什么问题”的人推进最顺。动手前花 5 分钟明确目标，比急着写第一条 prompt 更重要。

具体产出大家都不同：有 TikTok 脚本文案生成器、有英语发音评分工具、有小红书热点挖掘工具，全是从自身真实需求出发。有的人会前就开发一半，现场继续推进。最猛的一位，我讲课时他就开干，讲完他的第一个小工具已经能跑了。

遗憾是当天忙着指导，没统一收集成品截图。下次一定沉淀。

### 4. 现场问得最多的问题及回答
反常识的是：3 小时里没人卡在工具本身，卡在“怎么问 AI”。工具会迭代，按钮会挪位，追按钮学不完；学会提问才是长效能力。我整场讲的是道不是术。

典型提问： “我要让 AI 在小红书抓到赚钱热点？” 我回问：下水道疏通算热点吗？灭虫呢？保姆看护呢？都算，但对你有用吗？问题太宽泛，AI 只能给表面答案。你嫌 AI 浅，可能是问题不够具体。

没人比你更懂业务，你描述不清，AI 补不出来。

老板说“给我做个高大上的网页”，“高大上”每个人理解都不同。AI 不会吐槽你的模糊需求，只会回给你不靠谱的结果。

现场教的就几条：把问题说具体、目标说清楚、背景素材给足、别过度限制 AI。核心是需求驾驭能力。

其他高频技术问题：

- **Codex 装不上？** Mac 一般很顺，Windows 问题多随机，有条件建议 Mac。
- **Codex 订阅怎么买？** ChatGPT 订阅方式：苹果商店美区 ID+礼品卡；Google Play 绑国内 Visa；虚拟卡充值；找不到就找靠谱代充。
- **Claude Code 怕封号？** 别用共享/低价号，老老实实官方订阅。
- **工具怎么收钱？** 见第七章，个人无执照也能接。
- **有了 AI 还要不要干活？** 方向、验收、拍板还是你，AI 是工具。
- 魔法问题私聊。

订阅渠道我常用的：
美区 Apple ID+礼品卡最稳；Pockyt Shop、MTCGAME、OYUNFOR 都有正规渠道。Google Play 绑双币 Visa 最省事。虚拟卡推荐飞扬卡、Roogoo、Bybit。代充选出海铺、书虫等，每月手动一次即可。

## 十、行动清单与时间表

先算成本：AI 编程订阅入门档每月百来块；生图类加图像 API 按量计费，验证期很便宜；域名一年几十，服务器年付约 99。整体两三百就能启动，比报课便宜。卡住人的往往是这点小钱，入场费别跟自己讲价。

清单：
1. 选题：先确认有人付费，再确认 AI 能做。
2. 和 AI 对话：别说“做个很厉害的产品”。要说“我要服务谁、什么场景的什么具体问题，先做最小版本解决这一步，请拆开发步骤”。
3. 先跑通 MVP：用假数据把输入-输出跑通，先完成再优化。
4. 分工：生图交给 API，精确的排版/计算/收款让 AI 写代码。
5. 卡住三步法：报错复制丢回 AI，重跑；同一错误卡两次就换路；对话太长用 `/compact`。
6. 能砍就砍：登录、支付后端、账号体系先全砍，先做出可演示 MVP。代码完成后让 AI 帮你部署到免费托管。

时间表：
| 阶段 | 产出 |
|---|---|
| 0 选题 | 一句话说清做的小工具 |
| 1 需求 PRD | 对齐的需求文档 |
| 2 定做法 | 技术方案+分步计划 |
| 3 MVP | 能跑通输入→按钮→输出的粗糙版 |
| 4 核心功能 | 真数据替换假数据 |
| 5 美化 | 成品感，适配手机 |
| 6 验收 | 对照验收单+可复制下载分享 |

选题不确定就回第三章参考表。出图类需先申请生图平台 API Key。需要登录、存数据、做 App 的，验证期先跳过。

别一开始就给自己上难度。
