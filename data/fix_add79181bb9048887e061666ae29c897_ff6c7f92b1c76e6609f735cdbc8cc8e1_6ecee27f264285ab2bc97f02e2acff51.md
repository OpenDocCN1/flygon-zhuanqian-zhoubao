# 同城相亲五年经营复盘

作者：黄老师  
日期：2023-03-22

三年前我写过一篇关于相亲的感想，时隔至今，判断已经有了不少变化。近期同行朋友频频私信询问同城相亲的实操，今天就把这几年的真实体感整理一下。

在生财有术里逛时发现，“相亲”搜索热度依然很高。不少做本地赛道的伙伴也在交流，所以才有了这篇笔记。文字功底有限，没有做精修，就按流水账来写。

星球内的精华内容其实已经把底层思维讲透了，后面拼的就是落地。同城相亲在我看来是非常适合做私域、做长期经营的品类。

圈内朋友对基本逻辑都已经熟知了，这次不写保姆式教程，聊聊经营上的收缩与变化。

# 赛道现状

市场：想脱单的人群规模还在持续扩大，这点无需赘述。

竞争格局：
传统头部平台：现行打法仍是线上注册后把资源派发到城市门店，靠电话跟进。信任壁垒高，故纷纷转向线下聚会，但重资产重运营，难以为继。

本地相亲团队：借助抖音、小红书等平台的流量窗口入场。典型做法是街头扫码加微信、线上投放资料。玩法新奇，获客快，但很难锁定真正有婚恋需求的人群。服务闭环没搭建，难以实现稳定存续。接触过不少转行的同行，获客可以，但交付跟不上，最后都退出。

我的判断关键词：#轻资产 #小而美 #长期主义 #入门门槛低 #情绪价值高

团队变化：
往昔：20余人，10多个产品线
现今：5人左右，3个核心项目

当前主力角色：
接待助理：微信端对接、初步筛选、建立信任感
销售顾问：负责高客单的一对一项目
交付顾问：负责一对一的撮合与跟进
活动执行、拍摄、账号运营等可由助理兼任

# 一、获客是怎么解决的

大家最在意的通常是获客，实则门槛并不高。核心思路是重复做简单的事，付费投放即可。相亲话题自带热度，抖音、小红书、微博、快手均可做内容。生财里的流量打法拿来复用，基本就能跑通。

平台人群特征差异明显：
小红书、微博偏女性，高质量女性占比可达九成
抖音、快手偏男性，男性占比可达八成

产品是前提。相亲生意要围绕“让真正想脱单的人脱单”这一核心做。流量要直指产品，别做泛娱乐号。用户一眼就能看出你是否专业。百个精准用户胜过千个泛用户。

我们粉丝尚未破万时，微信已积累过万联系人。很多人是默默私聊，或把内容转发给朋友、评论区@好友。

矩阵号先做模板化，自然流量可行就自然，跑不动就上投放。相亲行业毛利空间大，投放成本完全可承受。相比本地团队，几乎无人投放，降维打击。模板定好后，后续就是重复作业。

四类可复制的内容形态：

第一类，图文资料卡。卡片附头像，愿露脸则清晰，不愿则做轻度模糊。可辨轮廓即可。重点是资料完整：兴趣、择偶条件、学历等。照片选用生活照，切勿放网红精修照，否则易被误认为诈骗。

第二类，现场一分钟自我介绍。把活动现场嘉宾的自我介绍全程录制下来，必有搞笑或争议点。挑选爆点发布。相亲是线上虚拟服务，线下活动能极大补足信任。一个平台若能连续三年周末办线下聚会，信任问题可解决九成。

第三类，街头访谈。找颜值在线的男生女生询问单身状态与择偶要求，随后话术：我们这边有大量符合你条件的人，扫码加微信，按你的要求匹配。关键是画面里出现加微信动作，让人明白我们是做相亲的。

第四类，红娘口播讲解。讲述一个真实案例：今天有位小姐姐来找我，她的需求是什么，我的观察是什么。结尾留钩子：感兴趣可来索要联系方式。

细节：交付微信前，务必征得当事人本人同意。

同城起号方法很多，记住产品为先，别跑偏。流量不足时要建立付费意识。同城投放，百元换一个加微信就不亏。我们早期数据：资料填写后，平均到手客单三百以上，且是佛系成交，未做强营销，靠口碑沉淀。

# 二、我们的演进路径

相亲无实体交付，信任与服务是核心。

产品线：
入门款：低客单线下聚会，用于建立信任
互动款：低客单线上匹配群，保持活跃
高端款：一对一撮合，客单从数千到数万，自行定价

时间线：

2019年末：
我们跨界创业，获客已起来，后端承接跟不上。当时付费会员超一万，助理十余人，平均客单两百。传统大机构找我们合作。彼时他们做法是网站收资料分到门店，客户从未接触，信任未建立，成单难。我们正好互补。助理做微信邀约，对方红娘负责成交。三十人团队，从两百条数据里成交四十万，转化惊人。弊端是传统模式偏强势成交，套路多。我们不喜欢扯皮，合作一月即终止。恰逢过年，疫情爆发。记得武汉封城前三天外界已炸锅，当地却毫无察觉，我们还在办两百人年夜饭主题活动，回想至今仍心有余悸。

2020疫情反复：
团队开始补齐后端运营能力。第二大难题是人员流失。当时微信号开到十几个，好友总量两万以上。武汉薪资水平低，助理七八千上万也能招到。相亲本质是聊天，客户多带情绪、价值观问题，负能量高。年轻人扛不住，平均在岗半年左右，仅一人至今留存。账号交接极痛苦，一个号几千人，聊天记录上百G，交接需半个月。

2021-2022 转型期：
过往产品：脱单会员+朋友圈推广+全媒体维护+一对一，另有微信互换、线下套餐、分类群、区域群、情感咨询、穿搭服务、生活照拍摄等。还尝试过账号出租、合伙人、活动外包等。

彼时生财有术热议#小而美 #超级个体，团队开始反思。转介绍开始稳定供血，月入数十上百新客。

我们开始做减法：
人：招聘标准转向高情商、长续航
产品：精简流程
基础盘保留：
朋友圈推广，一直在做
线上匹配，客户喜欢先了解，保留
活动不以利润为目的，活动是信任基建。往昔周末一场百人，三天即满。现在做小型精准场。往昔一场活动需主持+签到+拍摄+助理，全天透支。

盈利核心：精准一对一推荐
现行配置：两名红娘兼售后，三名助理兼活动运营
公司无固定上下班制，三年线上协作成熟，同事产假期间也能正常办公。对女性友好，来客即接待，线下约见，平时手机在线即可。
一对一业务，一名红娘月产十万左右。

我们入行过久，心态已疲，目前不打算再向上扩张。

# 三、延伸思考

曾尝试情感、形象、婚礼等跨界，发现一个近乎零竞争的细分。

客户画像：武汉男性客户八成以上有房，六成以上有车有房，年收入区间三十至五十万。物质层面基本达标，短板在形象。常见上身西装下身运动鞋，上身卫衣下身皮鞋。

合作对象是两位懂穿搭的男生，一位三十岁，一位四十岁。

产品形态：
形象改造计划，对接外贸潮牌，陪同试衣购买。改造收服务费，销售另计，利润可观。
朋友圈内容打造。备齐四季服饰，带客户前往星巴克、网红店、周边景点，按春夏秋冬拍一年的素材。

市场上确实有“两月赚百万”的故事，但多为极致流量红利+个人能力+前期铺垫共同作用。能否持续才是关键。

可自问：若迎来一波大流量，你能否承接、转化、交付？信任与售后才是此赛道的护城河。

互联网从业者普遍焦虑，项目切换过快。其实可挑选一个天花板高、能深耕的赛道长期经营。

相亲行业能持久的核心是信任与服务。做到游刃有余才是最优状态。

主题小结：
流量：把简单动作重复做
信任：本地相亲先解决信任，后续问题自然迎刃而解，这门生意可做一生
适配人群：思维活跃、性格开朗、内心坚韧，能抗住各种奇葩
后端转化：情商高、会沟通，客户会把从未对人说的话告诉你

一线城市本地相亲团队不少，但多数停留在获客层，深度未做，一年即转行。有条件者不必担忧市场，做好深度，半年即可成长。

此赛道适合亲力亲为起步，小团队稳步进阶。据行业数据，天花板很高。在人口大市做一个小团队，年入三五百万是现实目标。

更有价值的是：相亲客户会把心交给你，那些从未向他人透露的情感都会说给你听。本地资源网络逐步铺开，客户是有温度的。做出规模后成就感强，后期转介绍形成稳定循环，无需过度焦虑。
