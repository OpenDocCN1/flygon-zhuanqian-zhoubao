# 一、GPT 好用却被配额卡住

在星球里，关于 RPA 叠加 ChatGPT 提升公众号运营效率的玩法已经讲得不少。方向是对的，实操起来痛点也很明显。最核心的卡点就是 GPT 的小时提问上限。账号多还能轮换着刷，账号少就只能干等配额重置，体验非常拖沓。

这篇内容的灵感来自圈友正在做的 GPT 镜像站点，免翻墙且没有每小时次数限制。于是就想，影刀能不能复用同样的思路？答案是可以。影刀底层是 Python，而 Python 完全能通过接口去调用大模型。

照此打通后，小时限制自然被绕开。但随之而来的是成本问题。OpenAI 的网络调用并不便宜，省了等待时间却把费用拉满，经济账并不划算。影刀自带的影刀 GPT 也能在流程里使用 AI，只是同样走付费通道。

写到一半差点弃坑，直到我在冲浪时看到有人分享清华智谱 AI，思路瞬间通了，这才有了下面的实录。

各位好，我是入坑影刀不到半年就被官方邀请参加线下优秀开发者分享会的影刀中级工程师 Leeka，今天继续分享干货。废话不多，直接开整。

# 二、在影刀里让 AI 提问更自由

## 2.1 智谱 AI 究竟是什么来头

外界普遍评价这是国内最有 OpenAI 味的团队。2023 年 7 月拿到美团注资，估值约 40 亿，美团持股 10.42%。

智谱聚焦打造中国顶级基座大模型，主导了 ChatGLM 与 ChatGLM2 两代系列，覆盖 6B 到 130B 的全尺度。同时运营国内大模型开源生态，已成开发者最活跃的社区之一。自 2023 年 3 月 14 日发布 ChatGLM-6B，6 月 25 日发布 ChatGLM2-6B 以来，两款模型在 Huggingface 上的累计下载量分别突破 300 万和 140 万，截至 2023 年 7 月底。ChatGLM 家族已孵化出数百个开源项目。

智谱是一家专注 AI 知识智能的技术商，构建了海量高质量知识图谱，并研发出深度隐关联挖掘算法与认知图谱等核心技术，知识产权完全自主，客户覆盖政府、企业与科研单位。作为悟道 2.0 的核心落地团队，与自建的高质量知识图谱结合，形成数据与知识双轮驱动的 AI 框架，意图突破第二代人工智能的天花板，引领第三代浪潮。

数据层面很亮，核心高管多为顶尖高校博士。但数据不等同于产品力，智谱的实际能力如何？能否与 GPT 相提并论？

ChatGLM 系列长期位居国产大语言模型第一梯队。首代 ChatGLM-6B 在 2023 年 3 月开源后迅速获得关注，三个月后上线的 ChatGLM2 再度引爆热度。

2023 年 10 月 27 日，智谱联合清华大学发布第三代基础大语言模型 ChatGLM3 系列，本次共推出 3 个版本：基础大模型 ChatGLM3-6B-Base、对齐调优版 ChatGLM3-6B、长文本对话版 ChatGLM3-6B-32K。

## 2.2 怎样达成持续提问

目前智谱的注册方式是手机号开通，中国计算机学会 CCF 会员可直接授权登录。新号注册即送 100 万 Token，实名后额外再送 200 万 Token。赠送额度有效期为 1 个月，需在过期前用完。换句话说，未实名时多准备几个手机号注册，就能循环获取额度，和 heygen 当初的玩法类似，轻松做到 Token 不断供。

Token 是什么？

在计算机语境里，它就是“令牌”。服务端在用户首次登录后生成一串字符串作为身份凭证，后续客户端只需携带该凭证请求资源，无需反复输入用户名密码。可简单理解为门禁卡，有卡才能进入小区使用内部服务。

## 2.3 用 Python 模块把智谱接入影刀

下面内容涉及影刀进阶课程，需要一定的代码基础。没有接触过也别担心，我会用最直白的说法解释实现原理。

### 2.3.1 新建 Python 模块管理依赖

影刀基于 Python 构建，Python 模块支持第三方包，而智谱 AI 在 PyPI 上就有官方包。因此可以在影刀里新建 Python 模块，直接安装智谱包，就能让影刀调用智谱进行提问。

要提醒的是，影刀里不同机器人的模块和包是隔离的，每个新机器人都需要重新安装。

什么是 Python 模块？

简单说，模块就是一个 Python 程序。任何 .py 文件都可以作为模块。模块像一盒积木，可以拼出多种玩具；函数则像一块积木。模块中可包含多个函数。

什么是 Python 第三方库？

指由社区开发并发布到 PyPI 上的可复用代码包，用于解决特定问题。它们是 Python 灵活高效的重要来源，能大幅加速开发。

弄懂概念后，进入影刀 RPA 的实操。

在新建 PC 自动化应用界面，右上角【流程】菜单的第二个选项即为【新建 Python 模块】。

新建后会生成一个名为【module.py】的文件，先放着，待会再写入代码。
