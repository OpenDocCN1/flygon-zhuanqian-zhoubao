# 新版 Cursor 0.49.x 实用功能全解析：编程门槛又双叒降低了

> 最近 Cursor 更新到了 0.49 版本，我实测了两周，发现这一版真的把“AI 编程”的易用性拉到了新高度。以前你得懂点编程逻辑，才能让 AI 帮你写出 70 分的代码；现在，只要你会说人话，基本就能让 AI 帮你干活了。这篇文章就聊聊我最推荐的几个新功能，以及它们到底怎么用。

## 版本升级小提示

这次说的所有功能，都只在 0.49 系列版本里才有。想体验的话，先升级一下：

- 打开 Cursor 的设置，找到 **Beta** 选项
- 把 **Early Access** 开关打开
- 然后点击 **检查更新** 就行

## 功能一：一键生成 Rules，再也不用手写规则了

以前用 Cursor 或者别的 AI 工具，第一件事是什么？得先告诉它“你是一位资深网页开发专家，有 20 年经验，帮一个不懂技术的小白做网站，干好了给一万美金”之类的身份设定。否则 AI 就不知道用什么思路帮你写代码。

之前我们的做法是去设置里写全局规则，把什么思维框架、测试方法、避免过早下结论这些通用约束都塞进去，让 AI 别跑偏。但这样还是麻烦——每换个项目类型，还得重新琢磨一套规则。

现在好了，Cursor 可以直接根据你的项目自动生成规则。

只要在对话框输入 `/`，找到 `/Generate Cursor Rules`，AI 就会自动分析项目结构，在项目根目录生成一个 `.cursor/rules` 文件夹，里面放着一堆规则文件。这些规则可以设置触发方式：

- **Always**：每次对话都生效
- **Auto Attached**：匹配某些特定文件类型时自动生效
- **Manual**：手动 @ 出来才生效

对于新项目，你可以先让它生成规则，它会给你梳理出项目概览、目录结构、技术栈规范、模块编写规则等等。对于老项目，你直接让它基于现有代码写规则就行，或者从历史对话里挑出那些 AI 经常犯错的地方，让它总结成 Always 规则，以后就不会再犯。

比如做网站时，前端展示代码（`.html`、`.css`、`.tsx`、`.astro`）和逻辑运算代码（`.ts`）的规范肯定不一样。前端讲究设计风格统一，后端逻辑讲究严谨。用 Auto Attached 按文件后缀匹配不同的规则，就很顺手。

这个功能，新手和老鸟都能受益。

## 功能二：项目结构自动进上下文

以前想让 AI 参考某块已有代码去写新功能，或者把代码写到指定位置，都得手动 @ 文件。现在只需要在设置里打开一个开关，AI 以后每次对话都会自动带着你的项目结构，拥有全局视角。

比如我在 Agent 模式下想写数据库读写操作，直接说“你找找哪里写过类似代码，参考着写”，它就能自己去翻项目，不再需要你指路。

## 功能三：新增“Review Changes”按钮

Agent 写完代码后，屏幕中间下方会多出一个 **Review Changes** 按钮，就在 Accept 旁边。点一下就能左右分屏查看具体改动了哪些地方，方便你审查代码，防止 AI 乱改、误删注释、引入不相关的改动。

## 功能四：MCP 支持图片了

以前要给 AI 看图片，我得手动用 Claude 3.7 去粘贴。现在 MCP 直接把图片传给 Agent，沟通效率高多了，处理样式、调视觉效果都非常方便。没用过 MCP 的朋友，强烈建议试试。

## 功能五：Agent 终端控制增强

这个偏专业向。现在 Agent 启动终端后，你可以在命令运行前编辑或跳过，原来的“Pop-out”也改成了更直观的“Move to background”。如果你懂命令行，能看清 Agent 每一步在执行什么操作，这个功能会很有用。

## 功能六：全局忽略文件

开发项目时，有些机密文件、中间缓存根本不需要让 AI 知道——机密文件有泄露风险，缓存文件纯属浪费上下文。你肯定不想自己花钱买的 GPT API key 被 AI 不小心吐出去吧？

打开设置（`Ctrl+,`），点击 **Add Item**，把要忽略的文件加进去就行。注意 `id_*` 这种写法，星号代表匹配任意字符，`id_123`、`id_3f3e` 都会被忽略。
