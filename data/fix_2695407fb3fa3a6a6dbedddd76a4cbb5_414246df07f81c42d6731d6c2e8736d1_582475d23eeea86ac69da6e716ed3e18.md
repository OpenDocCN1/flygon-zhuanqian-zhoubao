# 从对话式补全到自主代理与流程编排

聊聊我在 AI 编程辅助这条路上看到的东西、踩过的坑和真实用法。

下面内容来自零散记录整理，体系并不完整，仅供启发。文中所描述皆为某个时间点的快照，因为迭代极快，可能一周就过时了。整理于2024.12.24。

## 我亲身经历的演进脉络

### 2019年 提示补全与代码检索

当时的形态基本是补全加检索。

补全：偶尔比 IDEA 自带的手感更好。

检索：输入关键词就能在 GitHub、Stack Overflow 等平台拉出代码片段或讨论串。

### 2021 年 6 月 GitHub Copilot 技术预览

由 GitHub 与 OpenAI 合作的编程助手，通过机器学习模型为开发者输出代码建议，提升效率。

使用的底层模型是 OpenAI 当时推出的编程专用模型 Codex。

### 2022 年 11 月 ChatGPT 引爆

技术路线转向大语言模型。代码提示与聊天功能都开始依赖 LLM，相关产品爆发式增长。

### 2024年中 稳定爆发

出现了一个在价格、响应速度与综合能力上达到甜点的模型：Claude 3.5 Sonnet，它让自主代理和工作流开始真正好用。

整体处理复杂问题的能力，目前最强的是 OpenAI 的 o1，只是节奏慢，比如思考约一分钟后一次性给出完整结果，而不是逐字流式输出。

举例：让模型直接写单元测试，基本不可用。拆成两步会好很多：先梳理测试思路，再生成测试代码。

延伸思考：为什么许多 AI 商业项目难落地。顶尖模型价格高，能扛复杂任务；能力较弱的模型需要把任务拆得很细才能完成，拆得越细，复用性就越差。

## AI 编程辅助的四种表现形式

### Copilot 副驾/高级提示

* 定义：依据上下文实时完成代码的工具
* 代表产品：GitHub Copilot
* 特征：
* 实时按上下文给出建议
* 直接内嵌在 IDE
* 聚焦代码层面的微操作
* 典型用法：
* 代码补全
* 由注释生成方法
* 由方法生成注释
* 新增类属性后同步更新构造器
* 不同产品的差异：
* 是否主动触发提示
* 提示的响应快慢
* 上下文理解差异。比如提到端口，它能否对应到 IOPort
* 支持单行修改还是多行修改。多行修改示例：
* 是否具备光标预判。预判下一个光标位置以便无缝跳转
* 提示出现的时机。比如能否在新行末尾补全，能否在行内任意位置插入

补充：
GPT 家族基于 Transformer，自回归生成，擅长依据前文推导后文续写，架构本身并不天然支持“完形填空”。完形效果更多依赖各家的工程化实现。

### AI 对话助手

* 定义：通过自然语言对话提供编程支持的工具
* 代表产品：ChatGPT、Claude
* 特征：
* 支持自然语言交互
* 能解释代码与概念
* 提供更宽泛的编程建议
* 典型用法：
* 任意编程问题的对话
* 代码解读与排错
* 架构设计探讨
* 产品差异：
* 是否支持语音交互
* 自动感知上下文能力。根据鼠标位置、当前打开文件、历史浏览、工作区等收集上下文
* 是否支持手动指定上下文。指定上下文的案例：
* 是否支持图像输入。点聊天下方的图像按钮或拖入图片，把视觉内容纳入对话。比如给一个网页截图让其实现
* 是否可联网提问。从互联网获取最新信息并据此作答
* 是否可引用文档。引用流行库，或使用 @Docs → 添加新文档添加自有库
* 是否能一键写入代码。比如 ChatGPT 网页版生成后需手动复制。部分工具可在 Chat 框内以 Git 对比方式预览修改，还可一键拒绝或应用

### AI 代理

* 定义：具备一定自主决策能力的助手，是对话形式的进阶版
* 代表产品：Cursor agent
* 特征：
* 可主动执行任务
* 理解项目级上下文
* 具备工具使用能力
* 典型用法：
* 按需求实现小产品或小工具，自行选语言、设计布局、创建文件、写代码
* 编写文档，建立多文件的小型知识库

### AI 流程

* 定义：将 AI 能力接入开发工作流
* 代表产品：Windsurf、Devin
* 特征：
* 更强的上下文感知
* 多工具协同
* 自动化流程
* 更像是人辅助 AI，AI 执行任务遇到需要人工操作或确认时，会主动询问人类

# 大模型能力交流

* 最好的推理模型 o1
* 最好的代码模型 Claude 3.5 Sonnet
* 最好的多模态输入模型 Gemini flash 2.0
* 生产上性价比最高的模型 现在是 gpt-4o-mini
* 最强开源模型可能是 qwen 2.5 72B，至少中英文如此，但仍有差距。而国内一线顶尖模型基本也在 qwen 72B 这个水平，包括阿里自家的 qwen-max
* 国内的基础模型、高性价比模型、推理模型都还需要继续迭代
* 国产之光 DeepSeek 很便宜，能力尚可。AI 界的拼多多 DeepSeek
* VS Code 的 cline 插件 + DeepSeek 据说效果还可以（当然能力和使用体验跟付费的有差距）
* kimi：国产总结能力最强
* 秘塔：智能搜索+知识库。可用作对 AI 幻觉的交叉验证，像中国的 Perplexity AI
