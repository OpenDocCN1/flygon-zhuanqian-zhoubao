# 一、加入生财前，我在自媒体的试错

来生财的人多半一个目的：赚钱。躺平不现实，我选择硬干。那段时间身边都在传小红书很能赚钱。2023年底我下载小红书刷起来，算法很快判定我为励志人群，首页全是【早起100天副业】【重生之...】【提前布局2024】这类爆款。那时我还没有同行分析的概念，刷了大概一周就决定入局励志，拍短视频也发图文，还想尝试带货。选了个有纪念意义的日子发了首条笔记。

[PRE1]

连着早起31天，笔记更了31篇，粉丝却连50都不到。理想与现实的差距很扎心。

寒假回丽江老家，本来打算找一家有调性的清吧做直播学习，结果家人开了两家民宿，各种杂事把计划压没了。

## 专业不等于影响力，影响力也不等于变现

开学后我重新选方向，最后选了自己更熟的考研赛道。最大的顿悟是：知识本身不值钱，值钱的是流量。3、4月是我最拼的阶段，正好赶上考研复试期，平台给我了很强的正反馈。

一个月的产出：

视频号粉丝877，单条最高6万播放

可是，收入为零。数据好看却没有钱进来，才明白那是假繁荣。

# 二、初识生财的印象

### 名字很像成功学，但我还是进了

[PRE5]

【聂枭】听起来很成功学，我加入前对生财一无所知，公众号和视频号都没关注。为什么会进？一来朋友在参加体验营跟我讲了下，二来男朋友发了我一份《人生亏钱指南》，朋友又劝我可以边做内容边学习。于是就买了进去，下了知识星球。

### 信息爆炸又有点迷茫

进去第一眼很开眼界，自媒体项目资讯密密麻麻，像回到了早年论坛。最开始被【风向标】吸引，觉得要卡位风口，结果点开发现多数项目自己根本参与不了。

### 项目太多有点懵

第二天就去问鱼丸航海在哪看，打开网页版翻了往期航海手册，感觉教学非常细致，堪称保姆级。可那时刚到暑假，之前的冲劲被消耗得差不多了，就先养精蓄锐。

### 先搞清变现，再去做内容

我之前半年白干，就是先发笔记再想怎么赚钱。出发点错了。

同行常见的变现形态大致有：
1. 直接售卖资料
2. 赠资料+推荐课程
3. 赠资料+社群服务
4. 赠资料+对接本地机构

为什么要聚焦线下机构？我前期接了不少线上机构，咨询量有，但推了上百人零成交。一次与大学校友吃饭，她说自己是在学校附近的线下考研机构上课，体验好还带了几位小姐妹去。我立刻意识到，本地机构才是转化突破口。

### 跟商家谈合作容易踩的坑

新手最容易被低返点忽悠。

谈前准备：
1、准备沟通提纲
* 机构体量：覆盖区域，分校越多风险越低
* 机构差异：课程、环境、服务、校企合作、地理位置等优势
* 承接流量能力：转化弱我们就赚不到钱
* 主推产品与讲师：详细记录或索要资料
* 结算周期与方式：多家要求对公账户开票，开票会拉低返点
* 客户交接方式：通常拉微信群推名片，建议让商家做在线反馈表

[PRE17]

[PRE18]

[PRE19]

信息越全谈判越顺利。

2、核心指标参考
合作模式：
* 纯引流：只给线索
* 引流+筛选：给意向线索
* 引流+成交：自己成交，机构只负责收单服务

合作费用：
* 纯引流：返点通常10-20%
* 引流+筛选：线索费按行业一般10-100元/条，返点10-20%
* 引流+成交：前期不建议，专注做流量，转化交给专业团队。若自转可谈30-50%

结算方式：单笔或按月。

1. 基本功别丢

2. 为什么要人工刷小红书
* 养号：避免笔记异常
* 收敛关键词：看到最新内容，不掉进信息茧房
* 找对标：看话题、发布时间、主页排版，不只看赞藏
* 强化算法标签：让系统更快识别账号定位

3. 不建议直接AI洗稿
简单复制洗稿出来的文案很假。想用好AI先要会写提示词，不如自己输出口水话更有烟火气。小红书早期是素人真实分享，我就喜欢那种真实。

# 四、给航海新人的建议

1. 节奏：前一天准备好第二天早上发的笔记
2. 工具：够用就行，WPS、搞定、美图秀秀为主
3. 话术：能判断用户意向的话术才有价值
4. 好笔记标准：有私信就是好笔记，不看播放和赞藏

# 五、收尾

我从没想过能靠自己赚钱，更没想到能做到月入一万。但它真的发生了。很感恩生财指引方向，也感谢官方萌虎鼓励我开播分享，让我觉得经验能帮助新人。相信和生财一起，会越走越顺。
