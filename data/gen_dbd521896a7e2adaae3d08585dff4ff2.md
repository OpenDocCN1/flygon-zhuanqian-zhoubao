# 零基础怎么让ChatGPT帮你写出“值钱”的亚马逊选品分析工具？

完全不懂编程的人，也能让ChatGPT给自己打工，把Python工具开发出来吗？答案是，只要你方法对，写代码和调试这两件事都可以交给AI。

在Code Interpreter（现在叫Advanced Data Analysis）推出一周年的节点上，我重新想起了这个当年热度很高、但在生财圈里讨论得不太多的功能。最初拿到它的时候，我和几个朋友都挺意外：它既能写代码、分析数据，又能处理文件和图片，更关键的是，它会自己在一个临时环境里生成Python程序并跑起来；一旦运行出错，它还会自动改代码，再试一次，不断尝试各种解法——这几乎就是在模仿人做任务的方式。在我看来，它和去年7月同期出现的Custom Instructions，也许正是ChatGPT走向自动化执行任务的前奏。

顺着这个思路，我很自然地想到：CI能独立解决某个任务，跑通之后，它的背后就等于有一份可以运行的Python代码。那能不能让ChatGPT学习这份代码，再改写成符合我们需求的程序，然后拿到本地运行更大数据量、更复杂的同类任务？带着这个好奇，我在AI编程航海的收官阶段开始了新探索。说实话，前面两周我也按照教练指引和圈友的分享做过不少ChatGPT写Python工具的测试，后来把这些经历整理成了另一篇文章，讲的是怎么用ChatGPT写Python爬虫工具。

先向读者道个歉，这篇文章的标题有点标题党的味道。AI编程并不能算开发产品的最快路径，下面要聊到的工具也没有经历过真刀真枪的市场调研，绝对不敢说拿来就能赚一百万。之所以这样起名，是因为我刷到一个B站Up主的视频，题目就叫“价值百万美金！ChatGPT亚马逊Amazon选品”。他在视频里展示了如何从JungleScout导出的数据出发，靠ChatGPT Code Interpreter做分析，最终锁定了194个蓝海产品。作为一个懂一点编程、也用过CI的人，我必须说一句实话：这套筛选流程即使不借助ChatGPT也完全可以跑通，哪怕你只精通Excel，手动操作也能做到。AI真正的贡献不是不可替代，而是把门槛大幅度降低、把效率提上来。视频最值钱的部分其实是他的选品思路，而不是AI本身。我刚好和这位Up主有比较深的关系，早就知道他这套蓝海选品打法带来了远超百万的回报。

今天这篇文章，就是想把Up主用CI筛数据、找蓝海产品的思路，变成一套可以反复使用的Python选品工具。我会从下面几个角度展开：

*   尝试攻坚：解决Excel图片复制难题

我给它的任务很简单：“扮演一名资深的Python软件工程师。请把附件中的所有图片转换成一个包含这些图片的PDF文件，并提供下载链接。” [PRE2]

## 尝试攻坚：解决Excel图片复制难题

某个周日晚上，航海群里一位圈友遇到了麻烦：想从Excel表格里复制图片到另一个Excel表格，不知道该怎么操作。[PRE10] 那几天我正琢磨着把CI生成的代码改写成Python工具，看到这个问题顿时来了兴趣——CI本身应该就具备处理Excel文件和数据的能力，不如试试。

这里有一条很重要的经验要分享：CI是在ChatGPT分配的临时虚拟环境里工作的，存在容量限制和超时限制。如果你一上来就让它处理超大数据集或非常复杂的计算，大概率会失败。所以更聪明的做法是：让CI先跑一个数据量小、计算量小的任务；任务跑通后，让ChatGPT把相关代码改写成能在本地运行的版本；然后再用本地电脑去处理更大数据量、更高计算量的同类任务。

这次我换了一个同样带“代码解译器和数据分析”功能的GPTs——Excel GPT。当然，如果你习惯用GPT4或GPT4o，也可以直接在对话框里让它调用CI。我先准备了一个很小的data.xlsx，里面只放了两张图片，完全符合“小数据量”的原则。[PRE11]

然后向这个GPTs布置任务：“先识别附件data.xlsx中的所有图片，把每张图片复制到名为output.xlsx的Excel文件的D列对应单元格中；复制后，在保留原像素和宽高比例的前提下，把图片显示高度缩小到100px，同时把所在单元格的高度也调整为100px。” [PRE12]

ChatGPT迅速调用CI完成了操作，并生成一个新的Excel文件。[PRE13] 但我打开后发现一个问题：图片复制后所在的行和源文件不一致。[PRE14] 我把这个异常反馈给ChatGPT。[PRE15] 它随即又调用CI处理了一遍，这次图片位置终于和预期完全一致了。[PRE16]

我照例去点“Download PDF”右侧的展开按钮，查看执行任务所用的Python代码与结果。[PRE17] 可仔细一瞧，这部分代码里并没有包含“把Excel图片复制到另一个Excel”的完整流程。于是我又让ChatGPT把刚才执行过的完整代码重新输出一遍。[PRE18]

接着，还是同样的套路：让ChatGPT学习CI已经成功执行的代码，把它改写成能在本地运行的程序，并加上用户界面。[PRE19] 经过测试，程序确实能把Excel中的图片复制到另一个Excel的指定列，但有一些小毛病：图片尺寸不对、分辨率变低，程序目录下会生成临时图片，甚至偶尔会弹报错信息。我把这些问题一个一个抛给ChatGPT，让它逐一修复，最终得到了一份完整的Python程序。
