# 不会写代码也能扒小红书爆款？用Cursor从0到1做爆款分析，小白也能轻松上手

做自媒体的人都知道，想要流量就得追热点、抄爆款。有人把小红书几篇爆款笔记拼成一篇，有人把抖音热门文案扒下来重拍，还有人把公众号爆文拿来二创。可问题是，时间有限，靠人肉刷笔记效率太低。专业玩家里有人写脚本抓数据，但零基础小白看到代码就发怵。现在有了AI工具Cursor，哪怕你完全不懂编程，也能像那些技术大佬一样写出抓取数据的脚本并跑通。我今天就用小红书K12赛道做个示范，教你如何用Cursor提取6小时、12小时、24小时、近3天、一周内的爆款笔记，再分析它们的共同点，辅助你的内容创作。

这个方法不光适用K12，美妆、穿搭、美食、家装、宠物、母婴、科技、汽车、健身、减肥、旅游、职场……所有赛道都能用。

Cursor的官网是 https://www.cursor.com/，打开直接下载。它的定位是“The AI Code Editor”，目的就是让你用AI写出更高效的代码。咱们一般用Python写爬虫，不过Cursor支持任何编程语言，这里就用Python来演示。

## 一、总体流程

大方向就四步：先从平台获取数据、把详情文件导出、用脚本抓取数据、再到不同平台按目标深挖。写脚本这一步，你可以直接手写Python，也可以像我一样用Cursor，后者对小白最友好。

### 3.2 聚合榜单数据

如果你下载多份榜单，需要先把数据合并成一份；只有一个榜单就直接跳过。这里我用Cursor处理合并：按下Ctrl+K（Win）/ Cmd+K（Mac），在输入框里用大白话写明需求——本地某个目录下有一批格式相同的CSV，列分别是官方笔记地址、笔记标题、笔记标签、点赞数、收藏数、评论数、分享数、发布时间、笔记类型、达人名称、粉丝数、达人主页地址。帮我写一段Python代码，把这些文件全部合并成一个文件，按点赞数倒序排列，并且以“官方笔记地址”为准去重，最后保存排序后的前5000条数据。

代码生成后点Accept，把代码里的目录替换成你的实际目录，再运行，多个CSV就去重整合成了一份数据。

但这时表里只有基础信息，并没有笔记正文和话题。做小红书的人最需要的就是爆款的正文和话题来模仿。你可以把CSV里“官方笔记地址”这一列的链接一个个开在浏览器里，手动获取正文和话题。灰豚页面/接口本身其实也能看到详情内容，只是免费版一天只能看10条，而我们要处理几千条。所以最靠谱的办法还是写脚本去抓小红书笔记详情和话题。

### 3.3 抓取笔记详情和话题

终于到最关键的一步了。完全不会写代码也别怕，放心交给Cursor帮你写脚本。就算中间报错，直接扔给它改，改到能跑通为止。

这里需要提前知道：在网页版小红书笔记页的HTML上，笔记内容对应 `id="detail-desc"`，话题对应 `id="hash-tag"`。你只用记住这两个标签名就够。

接下来让Cursor写代码去抓笔记详情和话题，最后更新到Excel。按Ctrl+K（Win）/ Cmd+K（Mac），继续用大白话描述需求：读取路径为XX的CSV文件，第一列是小红书官方笔记地址，循环打开第一列的网址，取网页里 `id="detail-desc"` 和 `id="hash-tag"` 的数据，追加到每行后面作为新列。注意每篇的hash-tag可能有多个，要全部取完；detail-desc和hash-tag都可能为空，为空就写入空数据。最后把结果写入新文件。

### 3.5 爆款封面怎么参考？

封面图是一门学问。我们重点去看“小号爆款”使用的封面。比如粉丝数才100、400的小账号，如果某一篇突然爆了，多半是因为它“抄对了爆款”，抓到了某种好封面形式来模仿。

那我们自然也可以这样学习。思路是：

①先筛选出粉丝数小于500、点赞数大于1000的笔记；  
②抓取前50或20篇作品的封面，统一保存到一个文件夹里，比如放桌面。

### 3.6 笔记正文怎么写？仿写就行

正文部分我们主要做仿写。思路分两步：

①抓取相关标题的正文内容；  
②用文章仿写指令，让AI帮你生成一篇新的笔记。

正文内容我们前面已经抓取过了，直接拿来用即可。在之前下载的内容文件里选一篇笔记原文，比如那篇讲考研英语阅读的笔记，复制到一个新文件里，然后按Ctrl+K / Cmd+K，输入仿写指令。AI就会给出仿写结果——下图中红色是原文，绿色是仿写后的内容。
