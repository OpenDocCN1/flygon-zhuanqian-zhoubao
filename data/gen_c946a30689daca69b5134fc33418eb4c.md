## 你有没有想过，让 ChatGPT 帮你“搬运”整个网页？

今天一大早刷生财有术，就看到亦仁大佬分享了新动态，不禁让人感慨：大佬都这么拼，咱们更得想办法给自己“减负”啊。而且，AI 带来的效率提升，真的是实实在在看得见的。很多人可能觉得，抓取网页数据是高手的专利，得会写代码才行。其实不然，借助 ChatGPT 内置的一个神奇功能，哪怕你完全不懂编程，也能轻松搞定。

不卖关子，咱们直接进入正题，这个方法就是利用 GPT-4 的 **Advanced Data Analysis**（也就是早先大家熟知的“Code Interpreter”）。本质上，它相当于一个简化版的 AI 智能体，能自己动手写代码并执行，能力相当全面。除了咱们今天要讲的爬取网页，它还能处理文件、做数据分析、搞定图片编辑、读取 PDF 等等，这里就不展开说了。

回到正题，如何在不写任何代码的前提下，把网页上的数据“搬”下来为我所用呢？操作流程非常简单，请往下看：

**第一步，把网页“存”下来**
在你想抓取的网页上，点击鼠标右键，选择“另存为”，将文件格式选为 **mhtml** 即可。如果保存成普通的 HTML 文件也没问题，但两者有区别：mhtml 像是一个“打包”文件，会把页面所需的 CSS 样式、JS 脚本和图片都整合在一起，下次打开能完整还原页面；而 HTML 就只是纯粹的代码框架，不包含那些附加资源。

**第二步，把文件“喂”给 ChatGPT**
打开 ChatGPT，勾选启用 **Advanced Data Analysis** 选项，然后把刚才下载好的 mhtml 文件直接拖拽上传。

**第三步，精准“下单”你的需求**
在对话框里告诉 ChatGPT 你想要提取什么内容。为了让结果更精准，我们可以在提示词里给它一些提示，比如指出对应内容的 CSS 类（class）名称。这一步稍微需要一点“代码常识”，但不懂也没关系。有个笨办法：在页面上按一下 **F12** 键，打开开发者工具，然后点击左上角的“选择元素”图标，再点击网页中你想抓取的那部分内容，就能轻松看到对应的 class 值了，见下方动图演示：
