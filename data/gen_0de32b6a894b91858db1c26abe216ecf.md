## 一、三个底层心法：它喜欢的表达方式，和我们想的不太一样

### 1. 自然语言它听得懂，但计算机语言它更拿手

我们平时说话，天然带着歧义。

同一个词放在不同场景，意思能差出十万八千里。比如“冷”：可以是温度低，可以是态度冷淡，也可以是冷静；再比如“打开窗户”：可能是想透气，也可能是想翻窗进屋。这还没算上文化背景、生活经验、口语和书面语的差异——AI想理解自然语言，确实不容易。

但计算机语言完全不一样：语法严格、结构固定，几乎没有模糊和多义的空间。

由此可以得到第一条心法：它懂自然语言，但更擅长计算机语言的逻辑。

想用好这一点，可以用计算机的IPO方式来组织Prompt——背景、输入数据、指令、输出指示。背景尽量给足细节；输入数据要具体，比如问天气就带上城市和日期；指令要明确简洁；输出则说清楚要什么格式，比如纯文本、HTML还是JSON。如果还有余力，可以把目标受众、写作风格也一并写进去。

### 2. 大白话它听得懂，但专业术语更让它“上头”

专业术语负责准确，自然语言负责流畅，两者配合着用，效果最好。

举个例子，聊股票时你说“价格会上涨和下跌”，它给出来的回复可能很模糊；但如果你说“股价会波动”，它就知道你是在谈市场行情，回答自然也更内行。反过来，如果你堆了一堆“经济环境、企业业绩等多方面因素”这样的修饰语，它生成的回答又会显得臃肿、绕来绕去。

所以，术语要和自然语言结合：用术语锁定方向，用自然语言提升可读性。

这背后其实是两件事在起作用：

一是提问意识。你会不会把问题问具体？比如查天气，如果只丢一句“今天天气怎么样”，模型只能靠猜；但如果你说“北京今天天气怎么样”，得到的答案就完全不一样。

二是知识结构。一个人在某领域越懂行，越能判断ChatGPT给出的回答是否靠谱，也越能提出高质量的问题。

两者都跟上，ChatGPT才算是真正为你所用。

### 3. 中文没问题，但英文是它的主场

这个其实不用多解释——ChatGPT出生在英文环境里，英文自然是它最舒服的表达区。

所以遇到复杂指令时，不妨试着用英文提问，再让它把结果翻译成中文，有时候会比直接中文对话更高效。

三个心法说完了。这些东西有点抽象，但都属于真正的底层逻辑，值得你花时间琢磨。

## 二、六个能直接上手的调教技巧

### 1. 精准调教模板

想要高质量输出，可以试试这个Prompt公式：

[上下文/背景信息] + [角色] + [动词][任务和对象] + [输出与长度] + [数据/来源] + [写作风格] + [目标受众]

这些元素都有现成的词可以抄：

- 背景信息：当前事件 / 历史事件 / 科技发展 / 文化背景 / 社会问题 / 经济情况
- 角色：作者 / 顾问 / 老师 / 学生 / 销售 / 客户 / 设计师 / 投资人 / 管理者 / 技术人员 / 心理师 / 历史学家 / 讲述者
- 动词：描述 / 分析 / 解释 / 预测 / 比较 / 设计 / 创造 / 推荐 / 讨论 / 评估 / 演示 / 批判
- 输出格式：短篇 / 长文 / 报告 / 信件 / 列表 / 评论 / 演讲稿 / 提案 / 幻灯片 / 脚本
- 数据来源：统计 / 研究 / 专家观点 / 历史资料 / 案例 / 新闻 / 评论分析
- 风格：正式 / 随性 / 幽默 / 严肃 / 情感 / 客观 / 主观 / 故事化 / 学术 / 商业
- 受众：孩子 / 青少年 / 成年人 / 老年人 / 学生 / 专业人士 / 消费者 / 投资者 / 研究者 / 创业者 / 大众

记住，这7个元素不是每次都要集齐，按你的实际需求自由组合就好。

### 3. 顺着它的“脾气”来

不要指望ChatGPT第一次就给你满分答案。

更现实的做法是：在对话过程中不断给反馈。觉得输出不对，就立刻喊停，告诉它“我不喜欢这个版本，希望你改成这样”；觉得生成得不错，就大方夸奖，“不错”“我喜欢你这一段”。

你的每一次反馈，其实都是它在调整输出方向的信号。懒得打字夸，就用大拇指也可以。你的反馈真的很重要。

### 6. 反向生成优化Prompt

如果你不知道该怎么提问，可以试试倒着来：

1. 先明确你期望的答案是什么样的，把它写下来。
2. 从预期答案里提炼关键词和核心概念。
3. 用这些关键词组织成一个具体、清晰的问题。
4. 再对问题做减法，去掉多余信息，必要时补一点上下文。
5. 如果问题太复杂，就把它拆成几个小问题，一步步引导它回答。
