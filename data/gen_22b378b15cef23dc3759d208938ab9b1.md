折腾了一周，骥哥用 Cursor 把 YouTube Shorts 的对标分析玩出了新高度。

之前他写过一篇初版分享，说的是用 Cursor 生成 YouTube 短视频频道分析对标程序，当时那个脚本比较粗糙，能拿到的数据有限，部分功能还得靠 YouTube Data API，而那个 API 每天只有 10000 次额度，听着挺多，真跑起来很快就烧完了。

为了解决这些痛点，骥哥靠着 Cursor 的辅助编程能力，一路迭代，最终做成了一个 YouTube Shorts 工具集，并且直接部署成了网站，地址是 www.lworld.top。他说这版虽然上线仓促，可能还有些隐藏 bug，如果大家发现了，欢迎留言反馈。
