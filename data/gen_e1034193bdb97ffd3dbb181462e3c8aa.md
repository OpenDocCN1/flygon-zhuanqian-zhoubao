# 我的AI编程半年实战复盘：从Cursor小白到Windsurf上手

> 来源：[https://e13olyk8kby.feishu.cn/docx/Zd0yd7N4LosvQ8x4XwecDt51nuf](https://e13olyk8k8X4XwecDt51nuf)

## 起点

去年开始因为自媒体的推波助澜，我注意到Cursor的存在。心想如果能借助AI入个编程的门也不错。恰好生财有约的航海训练营在招人，我报了两次，一次是去年的12月Cursor专场，一次是今年4月的Web站构建。半年多的摸索下来，算是从零基础的状态慢慢上手了，今天把用到的工具、模型和踩过的坑一起梳理一下。

## 工具对比：Cursor 和 Windsurf

* **Cursor : https://www.cursor.com/**  
这是我接触的第一款AI编程工具，也是当初最火的那一个。初体验却不算友好，让我一度怀疑自己是不是不适合AI编程。交互上比较粗糙，提个需求它就开始一顿猛操作，代码刷出来一大堆。Chat模式还能对话调整，Composer模式一旦出错就很难再沟通，而且改动是全量覆盖的，好不容易调好的UI和交互，可能一下子就被改没了。早期还不能直接在里面执行终端命令，必须复制到本地Terminal去跑，感觉自己像个搬运工。订阅是每月20美元，国内信用卡也能充。用它我只做成了几个小玩意：Youtube视频下载插件、恋爱配对测试小工具、简单的游戏站和导航站。Vercel部署也尝试过，结果报错三十多遍，Cursor也拯救不了，最后只能放弃。好在最近版本有改进，已经支持运行终端命令了，应该是受到Windsurf的压力。

* **Windsurf : https://windsurf.com/**  
我早有耳闻，但因为Cursor刚充了费所以没换。今年5月听播客时嘉宾说他主要用Windsurf，觉得对非程序员更友好，回来就试了试。上手几乎零成本，和Cursor逻辑一模一样，但体验明显更顺滑。对话里可以直接执行终端指令，代码改动时会高亮标注，不会把项目改得面目全非。价格也更香，15美元/月，500 credits。起初我搭配Claude Sonnet 3.5，后来换成Sonnet 3.7 Thinking，每轮1 credit。整体开发流程我总结成三遍法则：第一版靠模糊想法和AI碰撞，想法在过程中不断澄清，代码也跟着乱成一锅粥；把问题点和明确需求记下来后开第二版，会顺很多但还是会冒出新bug；最后关掉窗口重开，把前两次的经验沉淀进第三版，才算成型。Claude系的挫败感依旧很强。真正的转折点是换成Gemini Pro 2.5之后，感觉像坐上了直达电梯，开发效率和质量直接跃升，不用每次都做心理建设。价格也更低，0.75 credits/轮。最近GPT 4.1更便宜，0.25 credits/轮，体验也不错，我现在就是Gemini Pro 2.5和GPT 4.1混着用。

## 模型使用感受

* **Claude Sonnet 3.5 / 3.7 Thinking：基本劝退，1 credit/轮**  
挫败感拉满，最后要去哪心里没底。

* **Gemini Pro 2.5：话痨型E人，0.75 credit/轮**  
内心戏非常多，每轮先放一堆Thinking过程，像在看它的大脑回放。对话里还会时不时塞情绪价值，比如“我最担心的情况出现了，让我看看怎么回事”、“我觉得非常frustrated，但我来想想办法”、“别慌，这是正常情况，现在你只要...”、“我向你再次道歉，我还没改好，这次一定改好”。做完后还会激动地说“来看看我们一起完成的工作，太了不起了！”每次都被逗笑。

* **Claude 4.0：专家级挂号费，Windsurf上10 credits/轮**  
感觉是Cursor为了防对手，让Windsurf用API价。太贵了，一轮对话的成本顶别人十轮，也解决不了十倍的问题。

* **GPT 4.1：I人型，0.25 credit/轮**  
人狠话不多。没有Thinking的碎碎念，直接上干货，速度快。默认不会自动改代码，会先问你是自己改还是它来改。同一天内如果一直让它改，后面会进入自动模式。但隔一天或刷新界面后，又恢复成客客气气的陌生人，前一天的默契仿佛只是梦一场。

## 我做过的项目

* **游戏站：strategicworldofgaming.top**  
四月航海期间做的，群友分享了H5游戏地址，我只需要搭一个index.html。重点花在页面排版上，参考几个大站的风格，调色加了缩略图和评分。域名太长且游戏不热门，基本没什么流量。

* **导航站**  
和游戏站类似，也是简单index.html。因为没时间筛选网站，后来把域名让给了别的项目。

* **AI图片站：https://snaptools.store/login**  
也是四月航海的项目。当时按手册用Vercel模板+Supabase开发，一直卡在用户登录，Cursor搭Claude 3.7 Thinking也搞不定，Vercel还频繁报错就搁置了。上周用Windsurf重启，终于跑通，但发现Vercel模板自带的astral lora训练API成本不低，部署问题还在犹豫。

* **图片站：https://www.loveanddeepspace.online**  
Windsurf后做的第一个站，下载游戏高清图，支持7种语言。也是走了三版路线，收获最大。从完全看不懂代码到能跟上Gemini的讲解。第一版尝试给图片打标签，后来发现按文件夹命名更省事。第二版改了标签识别方式，第三版参考Pinterest瀑布流重排页面，调排版花了很久。用GitHub Pages部署后Chrome提示不安全，后来切到Cloudflare托管。图片至今没被Pinterest收录，不知道原因。

* **淘宝抢购脚本**  
Windsurf做的Python脚本。起初想做抢票，发现大麦猫眼的热门票只能App抢，网页无用。转攻Labubu的淘宝抢购，脚本写出来了却一次也没抢到，估计淘宝有反机器人机制。看了很多人工抢购视频，想让程序模仿人操作，最后发现不如人手快，优势不明显，暂时搁置。

## 我的商业闭环思考：需求-开发-推广-变现

目前我只完成了前两步，后面两步还在学习。

* 找需求：Google Trends + 自身体验
* 找对标：搜同类产品看做法
* 写代码+本地测试：Windsurf，编码前先和AI把思路聊透越具体越好，讨论成熟后让AI整理成README
* 域名：ahrefs关键词生成器选词，spaceship购买
* 部署：代码推GitHub，发布用Vercel+Supabase或GitHub Pages
* 托管安全：Cloudflare
* 上线后：Google Search Console收录，Ahrefs做SEO外链
* 变现：还在探索

受刘小排老师启发比较深，产品开发要做到 the FIRST one, the BEST one, the ONLY one。

## 工具箱彩蛋

开发过程中顺手收集的一些站点：

Toolify集成AI工具导航，可对标。emojicombiner这种简单有趣的小工具流量极高，说明好玩的东西更容易传播。GitHub本身就是宝库，HelloGitHub、awesome-english-ebooks等清单值得刷。Product Hunt每天新品也适合找灵感。即刻也是信息来源。Chrome插件AITDK能看网站流量和SEO数据。

## 心路历程

挫折感 -> 慢慢上手 -> 用小项目练手 -> 持续学习对标交流 -> 做高价值应用 -> micro SaaS

和AI协作的经验：先把需求抛出来确认AI是否理解对，再开工；任何不懂的都直接问；代码改不通先换模型，不行就另开窗口，把之前的教训和更清晰的需求一起喂进去。编程现在成了我的time killer，自从用上AI编程，基本没有12点前睡觉的时候。
