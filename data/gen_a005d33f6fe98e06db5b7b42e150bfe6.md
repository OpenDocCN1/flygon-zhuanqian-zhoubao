和大家同步一下最近折腾 YouTube Shorts 的进展，还谈不上什么经验，YPP 到现在都看不到影子。

先交底：

完全的新手，既没碰过 YouTube，也没用过 Cursor。
账号 A：发了 11 条，累计播放约 20 万，粉丝 177，最高一条 11 万播放。
账号 B：发了 6 条，累计播放 3.5 万左右，粉丝 20，其中一条还是 0 播放。数据差距很大，不知道是养号没养好、内容不对，还是纯粹运气问题。

# 为什么最后选了科普解说

起初是被亦仁的推荐吸引，想做 AI 主题的 Shorts。长期赛道，大佬背书，AI 又是风口，感觉没问题。

后来在航海群里看教练拆解，又把圈友分享的近期经验都过了一遍，最后还是锁定科普解说。主要两个原因：

1. 我自知创造力有限。AI 类容易起量，但同质化也快，需要大量“抽卡”式创作，对新手来说前期消耗巨大。教练也说这是长期活，短期很难开 YPP，我怕坚持不下去。
2. 科普解说相对我更感兴趣，利于长期不掉队。而且老马教练的流程很清晰，直接照抄就能上手。

# 账号情况

一个是我日常刷的老号。
一个是新注册的号，养了两三天没动静，就放着十几天没碰。

为了控制时间成本，两个号都只做科普解说，避免自己被惰性拖死。

# 怎么找到对标账号

刚开始在平台里根本找不到方向。
我就先从教练分享的对标号入手，拿到号名后去 YouTube 搜，点赞、订阅。
之后首页开始出现相关解说视频，我就一路点赞，碰到没订阅的就顺手订阅。慢慢地，信息流就被训练成解说类内容了。

# 视频制作的原始流程

完全照搬老马的方法，爆款混剪。

大致步骤是：
找爆款科普解说视频 -> 用生财群里分享的 YouTube 下载网站下素材 -> 飞书妙记转文字 -> 丢给免费版 GPT 提关键词 -> 用关键词去搜素材，素材够了再定题 -> 改写原视频解说文案 -> ElevenLabs 配音 -> 找素材视频下载，音效在闲鱼买的 -> 导入 CapCut 剪辑。CapCut 也是闲鱼买的破解版，用着用着就各种功能被锁，头疼。

# 心力快被掏空了

这样纯手工干了大概 10 天，两个号一共 15 条视频。热情肉眼可见地在掉，每次剪一个视频都像在割肉。播放量起伏时有点沮丧，看 YPP 进度更是打击。
更关键的是重复劳动太多了，工具链卡顿也多，做着做着就想摆烂。
这时候就很急切地想要一个外力来把我拉住。

# 用 Cursor 破局

我照着航海手册装上了 Cursor，然后开始了一天一夜的硬刚。

过程记不清了，做出来的东西都很简陋，有各种小毛病，但能用就行，后面再迭代。
一开始想做一个大而全的控制台，后来发现 Cursor 在处理复杂功能时会容易改崩旧功能，也容易卡在局部问题上。主要是我水平有限，时间也不够。
最后拆成了 4 个小工具，按序号排列，方便我做视频时有流程感。比如 2.5 那个文件夹是空的，需要我手动去操作。

[PRE2]

每个文件夹都是代码文件加启动程序。
第一个是用 Python 的桌面界面，类似 PyQt，结果运行卡、开发慢。后面全换成网页形式，用 S 开头的那个库，Cursor 一问就懂，跑得快、写得也快。

## 工具三：批量下载 YouTube 素材工具

之前靠免费的在线下载站，一个链接一个链接复制，偶尔还要点几次跳转。付费的批量工具又要钱。
于是自己写了一个批量下载器。

把素材页面的链接粘进去，搜集够数量后一键统一下载。速度慢是硬伤，几分钟才能下完，但这段时间正好可以去分段音频。
我还顺手加了视频处理功能，下载时直接做锐化、高光等微调，省去 CapCut 里再调。问过 Cursor，说这已经在数字指纹层面改变了视频，不知道真假。

## 工具五：CapCut

最后还是得进 CapCut 剪辑。我一度想给它写插件，问过 Cursor，说需要企业开发者权限和 API 文档，门槛太高，先不折腾。

这样下来，工具一、二、四是串联的，可以在空闲时间批量处理爆款，存好文案和音频。每天的工作就变成找素材 + 直接用现成音频导入 CapCut 剪。

整体省了不少时间，还不算完美，但至少给了我后面收集信息、做分析的可能性。

# 一些感悟

1. YouTube 的流量是给的，用户也愿意互动。但第二个账号真的拉胯，0 播放的阴影还在，怕之后好号也会被 0 播或封号。
2. 开头几秒真的决定生死。
3. 内容尽量走真善美路线。
4. Cursor 做单一、简单的功能更顺手。
5. 网页界面比 PyQt 之类的桌面界面开发快很多。
6. 这条路注定是长期战，过程中迷茫、困难很正常，更需要氛围、同行者和小圈子互相打气。

希望这点记录能帮到也在路上的人，也希望在这条路上能互相看见、互相照亮。
