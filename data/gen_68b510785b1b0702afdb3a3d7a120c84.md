## 中转 API 网站推荐

目前我常用的中转出图站点有两个，自行对比价格选用即可，算下来麻雀 API 要更便宜，个人优先建议用麻雀。

麻雀 API：https://ismaque.org/ （现价约 2 分钱 / 张）

中转站充值汇率 0.6

GPT 逆向模型：sora_image 0.084 / 张，约合 5 分钱 / 张，出图速度稳定且很快。

GPT 官方模型：gpt-image-1 0.2 / 张，约合 1 毛 2 / 张。

[PRE19]

[PRE20]

综合价格来看麻雀 API 最划算，尤其是逆向模型的定价。

V3API：https://api.v3.cm/

站点汇率 2:1，充 600 元等于站内 300 额度。

GPT 逆向模型：gpt-4o-image，按成功请求计费 0.05 / 张，实测约 1 毛 / 张，但偶尔会触发循环，重试即可。

GPT 官方模型：gpt-image-1，按 token 实付，实测约 1~3 毛 / 张。
