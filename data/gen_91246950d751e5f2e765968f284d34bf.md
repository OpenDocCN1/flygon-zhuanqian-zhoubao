最近常有人问我：现在国内这些AI工具，到底哪个值得用？我自己实测了大半年，说说真实感受。

先说文心一言。它是第一个让我觉得“这不是玩具，而是趁手工具”的产品。用了这么久，整体满意。我的体会是，它对文字质感比较挑剔的人很友好，遣词造句专业，却不会硬凹辞藻。如果你写的东西偏文艺、偏精致，它在同类产品里优势非常明显。

最早我是拿它来帮我写文学评论和书评，原本只打算找点思路，结果发现它输出语言本身就很有味道，后来就离不开了。凡是需要一点专业深度或书面表达的内容，我第一反应就是打开文心一言。举个例子，我只给一句简单指令，让它写《乌合之众》的拆书稿，没喂任何额外资料。当时测了好几个工具，只有文心一言那篇读起来像样。尤其是你要写书评、面向“文化人”读者，或者文章需要术语而不只是大白话时，它特别好使。

## 从鸡肋到效率翻倍，新手怎么用AI？

别指望现在国内AI一把梭哈，或者让你当甩手掌柜——我以前就是这种心态，才觉得AI没一个能打的。可AI就真没用吗？不。我现在用AI就三条路：找金句、拆结构、打草稿。

**找金句**

想给文章填金句，除了去句子网站，也能直接让AI来找。比如想要“勇敢”主题的名言，一句话过去，它直接分好类送上来，帮你省掉大量筛选时间——做文案号的人体验极好。

**找选题（10分钟）**：从“赚钱”这个关键词，我找到了这个选题：赚钱就是每天持续不断练习这3种本事。

**拆框架（3分钟）**：提炼核心框架和观点。如果对标文章是总—分—总结构，就明确自己要写的三个分论点是什么——这就是你对选题本质的理解。实在不会拆，也可以让AI帮你拆。

**AI写初稿（3分钟）**：有了整体认知后，上网找些提示词模板，给AI发指令。比如：

> 假如你是一名资深公众号运营者，现在需要写一篇“赚钱就是每天持续不断练习这3种本事”的公众号推文，请围绕职场群体想要提升赚钱能力的需求，结合商业思维和创业心法，以“提升赚钱认知、找到优质项目、持续试错复盘”为核心点，写一篇适合在公众号推送的文章，要求符合公众号读者的阅读习惯，削弱AI味，符合人类的阅读和表达逻辑，适当引用网络热梗和名言金句，使文章触动人心，引发思考。

## 总结

再复习一下。以观点文为例，纯手搓和AI辅助手搓的差别：

| 环节 | 纯手搓 | AI辅助手搓 |
|---|---|---|
| 找选题 | 10分钟 | 10分钟 |
| 拆结构 | 3分钟 | 3分钟 |
| 写开头 | 3分钟 | AI写初稿：3分钟 |
| 写3个分论点 | 15分钟 | 手动改稿：5-10分钟 |
| 写结尾 | 3分钟 |  |
| 找金句润色 | 6分钟 |  |
| 整体体验 | 半小时完成纯手搓（不含找选题且脑子被掏空） | 半小时搞定AI辅助手搓（含选题且还能完善细节） |

这样，我们就把脑子飞速运转的半小时，变成了轻松愉快的半小时。以前写文章要关门、关音乐、关聊天窗；现在写文章，我还能边写边听播客。只要你对要写的文章有概念，有一套满意的提示词，又能改掉那些过于官方的表达，这篇文章就搞定了。

摸透这个过程，你会从哭唧唧的搬砖人，变成画龙点睛、点石成金的人。之前纠结用AI会不会没人味、被平台减少推荐。但实操下来，AI辅助手搓和我纯手搓的数据，没有明显差异。所以要真正去掉AI味，恰恰不是当甩手掌柜，而是让AI做基础工作，我们做有价值和意义的部分。

聪明的你应该已经发现了：AI辅助手搓的前提，是你对想写的文章心里有数——知道文章结构是怎么回事，知道自己是写故事文还是观点文，想用深情还是搞笑去打动人……这些是AI无法替代的。只有用你聪明的大脑把框架问题想清楚，AI才能帮上忙。这也是我们用上AI之后，还能继续打磨细节、提升收益的空间。

恭喜你，可以提速了！

## 避坑与提效小Tips

## 三大天坑，不看错万

### 新手错失四位数，原因居然是……

新手做公众号爆文项目，第一步是什么？我的答案：不是选赛道，不是找对标，甚至也不是通读航海手册。而是当你确定做这个项目、看到手册上写着“开通流量主”的时候，立刻、马上、想尽一切办法开通它。

22年我做头条，爆过一篇300W+阅读的内容，收益只有六百多块。因为那篇跑到一百多万流量时我还没开通收益权限——也就是说三百多万流量，我白扔了三分之一。很可惜。如果那一百多万流量放在现在的公众号上，错过的收益怎么都得有四位数了。所以这次我特别重视开通收益。后来才知道，不同方式开通流量主，等待时间长短不一样。新手一定要卡好时间，别等文章突然爆了才后悔。

### 为什么日更一个月还没入池？

我除了主账号，还运营了另一个号，也拿朋友的账号测过。有些账号迟迟起不来，是有原因的。有个朋友的号，我发了一周都没动静，后来发现她的粉丝大部分是中老年，而我选的是“强者思维”这类选题。选题本身数据不错，可对准备退休的中老年朋友没吸引力。后来把选题改成中老年相关，数据慢慢就上来了。所以数据起不来，先看看粉丝画像，看看选题和人群匹不匹配。

我还有个测试号，刚开始数据忽好忽坏，一直没入池。后来主账号出了爆款，复盘才发现：可能是选题太宽泛。比如想做读书博主，今天读《认知觉醒》，明天读《苏东坡传》，后天读《孙子兵法》，大后天读《乔布斯传》……很可能发一个月都起不来。因为这几本书的受众根本不是一波人——《认知觉醒》的读者可能是25岁左右的新职场人；《苏东坡传》的读者可能是35岁左右的文化爱好者；《孙子兵法》的读者可能是30岁左右的公司高层或创业者；《乔布斯传》的读者可能是一腔热血的大学生，18岁上下。

我也见过不少公众号作者说写了半年没入池，点进账号一看：今天发美食，明天发读书，后天发追剧——内容确实丰富，可读者找不到长期关注的理由。新手写作没有明确目标，系统根本不知道给你推给谁。按抖音和小红书的逻辑说，这叫打不上账号标签。这种写法，是给自己上难度，变相提高入池门槛。所以，选题不错、内容也符合爆文逻辑，却迟迟没有正反馈，一定要检查：选题和用户匹不匹配？方向垂不垂直？别给普通小学生讲高数，也别要求自己十项全能。

### 想赚钱必须有的两大狠人心态

做这个项目，常见两种吐槽。

第一，评论区什么人都有。第二，好不容易入池，单价怎么这么低？

给新手两个建议：

关于评论区：评论越狠，收益越稳。不管哪个平台，评论本身没有好坏，所有评论都在免费助推文章。我以前做抖音和小红书，无脑评论把账号弄得乌烟瘴气，笔记冲没了，一分钱没拿到，只剩一肚子怨气。而在公众号，至少你还能拿到收益。文章爆了，就会吸引各种人。我以前也会为好评开心半天，为差评心里别扭。可要是没有正负两种声音，你写得再好也没人看见，更不会有收益机会。与其被喜悦冲昏头脑、或陷在情绪里内耗，不如趁热打铁再写一篇，到手的收益比三天就忘的情绪实在多了。

关于文章收益：坚持做，就是捡钱。旱的旱死，涝的涝死。有人在纠结怎么入池，也有人在感叹入池了收益太低。如果你也有这种想法，可能还没意识到：直到现在，还有很多人在写5元/篇的文章，一篇300—500字。也就是说，很多新手写1000字，实际收益也就10—20块。但千字以上在微信，只要你开了流量主，就有至少3个广告位，能持续赚广告费。算一笔账：小白A，写千字20元的稿子，一周七篇，总收益140。除了到处找资源才能稳定接单，还要听编辑改稿。小白B，写千字爆文，想写多少写多少。一周写7篇，只要赚够了140块，其他收益都像捡钱，上不封顶。时间越长，差异越大。跑通项目之后，单账号每天赚140轻轻松松——一天的工作量能赚一周的收益，甚至更多。更别说做抖音和小红书的很多人，爆款出了一大堆，变现却是零。没有对比就没有伤害。公众号爆文收益，真的低吗？实在不想做也没关系，这个捡钱的项目，就让想捡的人去捡吧。

## 提效减压，三管齐下

### 找选题好累？因为你不会玩手机！

前面讲过找选题的方法和标准，但实际操作中还有件头疼事：一本正经找选题，又要搜索、又要查数据网站、又要飞书存档，来回切换麻烦死了，根本坚持不了半小时。但如果你把流程换成“刷手机—转发—集中整理”，顺畅多了。怎么做？在手机上建几个选题收集群，按大类分好。

平时刷手机，看到合适的直接转发进群，定期集中整理。这样玩手机时不用分心去整理，整理时又不怕没素材。有了分类群，你只需负责刷手机，随时都在玩，也随时都在找选题。刷出来的选题集中整理后，可以直接排进排期表；而不是刷手机—整理—刷手机—整理……等到某天做排期表，又把所有选题从头看一遍。两种方式我都试过，体验完全不同，试过就知道。

### 配图排版抓狂？试试项目流程分离！

你是不是也这样：好不容易把文章写完，卡在配图上。好不容易找到图，排版又崩了。更别提网络不稳定时发文章，页面打不开、图片加载不出来，做完一步下一步要刷新半小时，简直原地爆炸。

我优化流程的初衷是：写文章只要半小时，找图+排版+发布居然也要半小时，太浪费时间了。有没有更快的办法？有。思路和找选题一样：把A-B-C-D多个流程拆开，一段时间只做一类事。

比如每天上午10点集中找图。如果我的选题都是强者思维相关，就搜“自信”“风景”“动物”，能找出很多相关图片；如果我写情感文，就搜“伤心”“发怒”“争吵”，提前存好。要用的时候直接从我的图库里挑。如果你用AI生图，也可以集中生成一周甚至半个月的图。集中找图为什么省时间？因为你每次搜关键词，前面看到的很多图都一样。假设1秒看一张：分散找图，第一次搜开心，10秒找到第一张；第二次搜开心，20秒找到第二张；第三次搜开心，30秒找到第三张——60秒只找了3张。集中找图呢？搜开心，60秒能找6张。需要的图越多，集中找法省得越多。

排版同理。比如每天下午1—2点集中排版，一次排好5篇，同步到草稿箱，能定时的先定时，其他到点发就行。这比每次临时找模板、配色、排版、同步、发布，省太多时间了。

### 越做越焦虑？都是自找的！

项目起步期有两种常见焦虑，为什么说常见？因为我之前在抖音和小红书航海项目里也见过，甚至自己也有过一模一样的焦虑。

其一，对标太少很焦虑。说实话，我虽然把航海手册看了三遍，第一天找对标，找了一下午才找到一个账号，心里多少有点急。后来我猛刷这个账号，平台顺着推荐了其他账号，越刷越多，多到看不过来。但问题也跟着来了：推荐越多越容易看花眼，不知道做啥，也容易跑偏。这时候我停下来思考不同账号的目标人群和推送策略，发现有些号不适合对标。认真梳理后才意识到，最早找到那个账号，恰恰是整个航海期间价值最大的一个。所以，对标少不是问题，少而精准，反而能集中注意力，是件好事。

其二，把心理阻力降到最低。我以前做过小红书、抖音，也试过一些其他平台。凡是有成绩的，都是猛猛冲出来的。有大佬说公众号航海项目就是先发100篇，总有爆的时候。虽然不知道发100篇有没有结果，但做小红书的经验告诉我：新手没发够30篇，对数据根本没有真实感知。
