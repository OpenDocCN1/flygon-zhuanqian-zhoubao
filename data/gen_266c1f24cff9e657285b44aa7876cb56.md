现在网上教人用 Cursor、Trae 这类 AI 编辑器来生成 UI 的教程一抓一大把，可真正能让 AI 按着参考图稳定输出的经验却不多。今天我就把自己一直在用的这套工作流分享出来，主打一个“可控”。

我先拿了一张后台管理系统的设计稿当例子。目标很明确：让 AI 照着原图的风格和版面去生成 HTML，最好能像“复制粘贴”一样接近。

## 第四步：把风格沉淀成设计规范文档

如果你想把这种设计风格复用到其他项目，最好的方式就是让 AI 把刚才生成的网页直接变成一份设计规范文档。我这边用的是 Claude 3.7-sonnet：

[PRE8]

生成结果如下，先是 Tailwind 配置：

[PRE9]
```html
tailwind.config = {

    theme: {

        extend: {

            colors: {

                'card-green': '#40E0D0',

                'card-pink': '#FF69B4',

                'card-blue': '#1E90FF',

                'card-purple': '#9370DB',

            },

            gradientColorStops: {

                'green-start': '#40E0D0',

                'green-end': '#98FB98',

                'pink-start': '#FF69B4',

                'pink-end': '#FFB6C1',

                'blue-start': '#1E90FF',

                'blue-end': '#87CEEB',

                'purple-start': '#9370DB',

                'purple-end': '#DDA0DD',

            }

        }

    }

}
```
