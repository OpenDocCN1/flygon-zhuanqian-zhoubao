先报一下近况。折腾 Shorts 已经一段时间了，还算不上经验，YPP 的门槛现在看依旧很远。

自我介绍一下：
零基础，没碰过 YouTube，也没用过 Cursor。
A 号：累计发布 11 条，总播放接近 20 万，订阅 177，爆款一条破 11 万。
B 号：累计发布 6 条，总播放约 3.5 万，订阅 20，其中一条直接 0 播放。两个号表现差很多，原因不明，可能是养号、内容或单纯运气。

# 为什么最终定了科普解说

起初是被亦仁的点子启发，想做 AI 主题的短视频。长期赛道，有大佬带路，AI 又正处风口，看起来很稳。

后来在航海群里听教练拆解，又把近期圈子里关于 Shorts 的心得文章全部过了一遍，最终决定做科普向的解说。主要有两点考量：

1. 自知创作储备不足。AI 题材虽然容易出量，但同质化极快，而且创作过程像抽卡，需要大量灵感。对新手而言前期投入太大。教练也反复强调这是个马拉松，前期很难过 YPP，我担心自己坚持不下去。
2. 科普解说对我而言更有兴趣，更容易长期做下去。老马教练的制作思路非常清晰，照抄即可上手，门槛和预期都匹配。

# 如何找对标

刚上手时打开首页根本看不出方向。
我先从教练给的对标列表入手，拿着账号名去 YouTube 检索，然后点赞订阅。之后首页开始出现相关解说内容，我就持续点赞，没订阅的顺手订阅。时间久了信息流就被喂成了解说类内容。

# 最初的手工制作链路

完全照搬老马的混剪打法。

大致是：找爆款科普解说视频，用群里分享的在线下载站拉素材，飞书妙记转文字，丢给免费版 GPT 提炼关键词，用关键词去翻素材池，素材够了再定选题，改写原解说稿，用 ElevenLabs 配音，手动找 B-roll 素材下载，闲鱼买的音效挑几个能用的，最后进 CapCut 剪辑。CapCut 也是闲鱼买的破解版，用着用着就开始限功能，体验很糟。

# 热情被耗光的阶段

手工做了十来天，两个号一共 15 条。热情肉眼可见地下降，每剪一条都像被抽走时间。播放起伏时很沮丧，看着 YPP 进度条更是打击。
更致命的是重复性操作太多，工具切换卡顿，越做越想放弃。这时候特别需要一个外部助力把节奏撑住。

# 借助 Cursor 破局

按航海手册装好 Cursor，开启了一天一夜的堆砌。

过程已经记不清细节了，做出来的东西都很粗糙，毛病不少，但能跑就行，后续再优化。
起初想做一个大面板集成所有功能，后来发现 Cursor 在处理复杂需求时容易把旧功能改崩，也容易卡在局部问题上。主要是自己能力有限，投入时间也不够。
最后拆成了 4 个独立小工具，按序号排列，方便我在做视频时有明确顺序感。比如 2.5 那个目录是空的，需要我手动完成。

[PRE1]

每个目录下放源码文件加一个启动入口。

## 工具三：YouTube 素材批量下载

之前靠免费在线下载站，一个链接一个链接复制，偶尔还要点几次跳转。付费的批量站又要花钱。

## 工具五：CapCut

最终剪辑还是得进 CapCut。曾经问过 Cursor 能否写插件，回复是需要企业开发者资质和 API 文档，门槛太高，先不碰。

这样工具一、二、四形成链路，可以在空闲时批量处理爆款，存好稿子和音。日常工作简化为找素材 + 用现成音频导入 CapCut 剪。
整体省了不少时间，还不算完美，但为后续的数据收集和分析留下了可能。

# 一些心得

1. YouTube 的流量是愿意给的，用户互动也不差。但 B 号真的拉胯，0 播放的阴影还在，担心以后好号也会遇到 0 播或封号。
2. 开头几秒很重要，直接决定完播。
3. 内容尽量保持积极正向。
4. Cursor 做单一、简单的功能更可靠。
5. 网页界面比 PyQt 这类桌面框架开发效率高太多。
6. 这条路注定是长期战，迷茫和困难必然有，更需要氛围、同行者和小圈子互相支撑。

希望这点记录对同路人有帮助，也希望在这条路上能互相看见、互相照亮。
