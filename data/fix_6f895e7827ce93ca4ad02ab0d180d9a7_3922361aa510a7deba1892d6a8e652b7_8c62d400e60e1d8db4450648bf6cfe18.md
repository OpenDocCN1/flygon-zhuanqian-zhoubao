# N8N 云端搭建避坑指南：从海外主机到域名解析，一篇讲透

很多人一听到“自己搭 N8N”就感觉门槛很高，其实拆开来看就是四件事：选台海外主机、装好运行环境、启动服务、再绑个域名。本文按这个顺序走，每个环节的坑和捷径都给你标出来。

## 一、主机怎么选？先避开最大的坑

买机器之前，先记住一句话：别碰境内机房。

不是开玩笑，国内服务器硬性要求 ICP 备案。备案流程起步就是一周多，这段期间网站无法正常访问；备完之后还可能接到回访电话。对想快速做项目的人来说，这套流程太消磨耐心。而且各种支付和登录能力也受限制，比如微信支付、支付宝、公众号扫码登录等，不是不能解决，但比较绕。

解决办法也有：登录可以走公众号验证码，收款可以用发卡平台或者个人支付服务。至于网速，只要选对位置，基本感知不到差异。最推荐的区域是香港、日本、新加坡，离得近、延迟低。

另外，选海外主机还送一个隐藏福利：很多国外工具和服务不用再折腾代理，直接就能访问。

下单时也要留个心眼。平台经常搞“低价秒杀”，看着很香，但不少套餐的地域只能选国内，而且可选范围就几个，买完反而被绑在备案流程里。别因为省几十块给自己埋雷。[PRE0]

具体到阿里云，打开轻量应用服务器购买页面就行。[PRE1]

配置方面，内存至少 2G，再小跑不动服务。新手入门的月付档位就够了，没必要一上来就上高配。[PRE2]

机房位置优先香港；如果你有其他用途，新加坡、日本也可以。购买时长建议先选 30 天，跑顺了再按月续费，别一买就是三年。

下单完成，机器会出现在管理控制台里。[PRE3]

一开始状态是“准备中”，等它变成“运行中”就能进一步操作了。[PRE4]

第一次操作先设置 root 密码，设置完机器会自动重启，等重启结束就绪。[PRE5]

## 二、装 N8N：不搞花哨，直接 npm

在云主机上跑 N8N，不需要宝塔面板，也用不上 Docker。你只是要跑自动化流程，不是建网站，环境越简单越好，和本地用 npm 安装的思路一致。

### 2.1 登录云主机

本地按 Win + R 打开“运行”，输入 CMD 回车。然后执行：

```
ssh root@你的公网IP
```

公网 IP 在云控制台的机器列表里能看到。[PRE6]

第一次连接时，系统会问你是否确认连接，输入 yes 回车。[PRE7][PRE8]

接着会要密码。这里注意：输入密码时屏幕没有任何回显，别以为没输入，直接敲完回车就行。[PRE9][PRE10]

登录成功后，命令行提示符会变成 root@主机名，看到这个就代表连上了。[PRE11]

如果提示认证失败，多半是密码打错，重新输一次。实在不行，就去控制台重置密码再连。[PRE12]

### 2.2 安装 Node 环境

先安装 NVM，复制下面这条命令到终端执行：

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
```

等命令跑完、光标重新出现，就代表装好了。[PRE13]

然后输入 exit 断开连接，再重新 ssh 登录主机。[PRE14]

执行 nvm -v，能打印出版本号就说明 NVM 正常。[PRE15]

接着安装 Node.js 最新 LTS 版：

```
nvm install --lts
```

看到安装成功的提示即可。[PRE16]

再执行 nvm use --lts 切换到刚装的版本。[PRE17]

最后全局装好 N8N：

```
npm install n8n -g
```

这一步可能要等一段时间。终端里出现的 warning 可以直接无视，只有 error 才需要管。[PRE18]

如果卡住不动，最常见的处理办法就是把命令行窗口关掉，重新连上主机后再执行一次安装命令。[PRE19]

看到安装成功的输出，N8N 就算装完了。[PRE20]

### 2.3 启动 N8N 并放行端口

执行 n8n 启动服务，启动完成后，浏览器访问地址就是 你的IP:5678。[PRE21]

不过要先去云控制台的防火墙里把 5678 端口放行，否则外部无法访问。[PRE22][PRE23][PRE24]

首次访问时，N8N 会因为没有配置域名和 HTTPS 证书而拒绝进入，这是它的安全机制，不是 bug。[PRE25]

想先绕过这个限制的话，可以这样操作：

先查看当前 n8n 的进程：

```
ps aux | grep n8n
```

找到进程号后，用 kill -9 结束它。[PRE26]

然后用下面这个命令重新启动 N8N，跳过安全检查：

```
N8N_SECURE_COOKIE=false n8n
```

再次访问 IP:5678，就能进到 N8N 界面了。[PRE27][PRE28]

页面右下角如果出现报错提示，不用管，不影响正常使用。另外提醒一下，云端和本地的数据是隔离的，就算用同一个账号登录，也需要在云端重新激活。[PRE29]

### 2.4 用 PM2 防止服务“突然消失”

直接靠命令行跑 N8N，有个很现实的问题：终端一关，服务可能就断了，好不容易搭好的流程会跟着没。所以建议再加一层守护：

```
npm install -g pm2
```

安装完成后，先杀掉之前的 N8N 进程，然后用 PM2 来启动：

```
N8N_SECURE_COOKIE=false pm2 start n8n --name my-n8n
```

这里的 my-n8n 是任务名，可以改成任何你喜欢的名字，只要后续命令保持一致就行。

日常管理命令：

- 查看状态：pm2 list
- 停止：pm2 stop my-n8n
- 重新启动：pm2 start my-n8n
- 重启：pm2 restart my-n8n

如果发现服务访问不了，先看 pm2 list 的输出：没有任务存在，就重新执行启动命令；任务存在但状态不对，就 start；任务在线仍然异常，那就 restart。[PRE30]

## 三、域名购买：NameSilo 很省心

云主机搭好后，再配一个合适的域名，后续做 HTTPS 会方便很多。域名商推荐 NameSilo，理由有三：海外注册商事情少；支持支付宝；域名价格不贵。

购买流程如下。

注册并登录后，在搜索框输入想要的域名关键词，回车。[PRE31]

选一个后缀合适的域名，放入购物车。跑自动化流程的话，没必要买贵的后缀，最便宜的就行。[PRE32]

点击购物车后，页面会出现绿色按钮，继续往下走。[PRE33]

进入订单页时注意盯住付款金额，确保自己只买了域名本体，其他默认勾选的服务一律取消。[PRE34]

支付方式先点 see more，再选择支付宝。[PRE35][PRE36][PRE37]

地址栏可以不填真实信息，不确定写什么就搜一下“美国地址生成器”。[PRE38]

勾选同意条款后确认支付。[PRE39]

弹出二维码后，用支付宝扫码完成付款。[PRE40]

支付完成后回到网站首页，点击右上角头像，进入 My Account。[PRE41][PRE42]

在 My Account 中找到 Manage，点进去就能看到你买到的域名列表。[PRE43][PRE44]

## 四、用 Cloudflare 把域名绑到云主机

域名解析推荐用 Cloudflare，免费方案就能满足需求。注册/登录后，如果看英文界面不习惯，可以切换成中文。[PRE45]

在 CF 后台输入你的域名，选择快速扫描 DNS 记录，然后继续。[PRE46]

套餐选择免费计划即可。[PRE47]

接着按提示填写 DNS 记录，把域名解析到你的云主机公网 IP。[PRE48]

填写完保存，再点击“继续前往激活”。[PRE49]

接下来会进入等待激活的页面。[PRE50]

这时候需要回到 NameSilo 的域名管理后台，找到 Change Nameservers。[PRE51]

把原有的 NameServer 记录清空，改成 Cloudflare 提供的那两条。[PRE52]

确认无误后，点击提交。[PRE53][PRE54]

NameSilo 这边会显示“处理中”，再回到 Cloudflare 点击继续。[PRE55][PRE56]

域名生效时间不太固定，快的话 10 分钟，一般半小时内都能好。[PRE57][PRE58]

生效后访问域名，如果发现打开的并不是 N8N 页面，先别慌。原因很简单：N8N 跑在 5678 端口，而网址默认走 80/443 端口。想象你要进一栋房子，正门锁着，你又想从窗户翻进去，当然进不去。解决思路是把 80/443 的流量转发到 5678，并补上 HTTPS 证书。[PRE59]

这部分的完整操作篇幅不短，如果这篇反响不错，我下期专门写一篇“域名+HTTPS 证书配置教程”，记得在评论区告诉我。

## 五、最后几个小提醒

- 云主机暴露在公网上，容易被人扫描和试探，尽早配上 HTTPS 会更安全。
- 所有命令建议直接复制，不要手动敲，差一个空格都可能导致报错。
- 每一步都按顺序执行，不要跳步，很多问题都是跳步造成的。
- 命令行里执行成功通常没有输出，这本身就是“成功”的信号。

到这里，N8N 云端搭建和域名绑定就完成了。打开浏览器，输入你的域名或 IP:5678，就能随时随地访问自己的自动化流程，不用再担心本地电脑关机导致任务中断。希望这份攻略能帮你顺利上岸，我们评论区见。
