# 第一章｜选题，是所有文章的第一道关卡

## 1.1 选题不是"写点什么"，而是"写给谁、为什么写"

很多刚开始做公众号的人，坐下来第一反应就是"今天写点什么好"，然后盯着屏幕耗掉一上午，最后来一句："没灵感。"

但真相是：不是写不出来，而是题没选对。

在公众号的语境里，选题远不止一个标题那么简单。它是一套完整的"预设系统"，动笔之前就要想清楚：这篇文章是给谁看的？为什么写？读者读完后能得到什么具体的收获？

落到实际操作上，一个成熟的选题需要回答三个问题：

**第一个问题：你的文章是写给哪个人群的？**

是35岁、一边上班一边带娃的职场妈妈？是刚毕业、还在摸索方向的大学生？还是工作几年、想找副业突破的上班族？人群越聚焦，内容越有穿透力。

**第二个问题：你希望读者读完产生什么反应？**

是发自内心的"这就是我"的共鸣？是收获一个此前不知道的知识点？是停下来认真思考某个问题？还是直接点转发、点在看？

**第三个问题：这个话题里，你能提供什么别人提供不了的东西？**

比如你独有的经历、你亲手跑过的案例、你对某个现象的独特观察，甚至是你对一个主流观点的反向推理。

说白了，一篇文章有没有人看，跟文笔好坏关系不大，真正起作用的是：这个选题能不能在读者心里点着一把火。

所以，好选题的出发点永远是"价值"，而不是"灵感"。

下面一节，我会详细拆解所谓的"三种价值维度"：情绪共鸣、信息增量、目标参考。

## 1.2 三种价值维度：让读者觉得"看这篇不亏"

你写得再用心，读者看不看，看的不是字数，是"值不值"。

做了一年公众号，我最深的感触是：内容必须让读者感觉到价值，他才愿意停下来。

每一篇文章动笔之前，至少用这三种价值过一遍脑子。

### ✅ 第一维：情绪共鸣

人为什么会转、会赞？不是因为你讲得全对，而是因为你戳中了他。

有时候一句话写对了，评论区立马有人喊："说的就是我！"

这就是情绪共鸣的力量。

我自己写过的两个选题，数据都挺好：

*   "你不是不够努力，你只是在和生活硬碰硬。"

*   "写了100篇没人看，我差一点就放弃了。"

读者看到的时候，心里想的不是"这作者文笔不错"，而是"这不就是我吗"。

### ✅ 第二维：信息增量

在当下这个时代，"信息差"本身就是稀缺品。

比如我写GPT辅助公众号、AI提示词、知识库实操、全托管项目这些内容，很多人是第一次听说、第一次接触。一个新概念加上能落地的操作步骤，信息增量就有了。

所以写之前问自己：

"这篇文章里，有没有读者以前不知道的东西？"

### ✅ 第三维：目标参考

也叫"解决问题的价值"。

这类型选题通常方向极其明确，适合垂直账号或靠内容变现的作者。

举个例子：

*   "公众号标题总是起不好？这套公式直接拿去用。"

*   "AI零基础，如何30分钟做出一支爆款短视频？"

*   "用这3个写作框架，普通人也能写出能变现的文案。"

这一维的核心，是带着读者走完一段从"不会"到"会"、从"焦虑"到"清晰"、从"卡壳"到"解决"的完整路径。

👀 值得注意的是一些同时占满三种价值维度的爆款。

比如：

"35岁职场妈妈裸辞自学AI，3个月做出月入3万的副业。"

这个标题同时做到了：

*   情绪——中年裸辞的焦虑、人生翻盘的爽感

*   信息——AI这个新赛道

*   目标——副业怎么变现的具体路径

三种价值叠在一起，才能形成那种"不得不点开"的吸引力。

## 1.3 六套选题打法：好标题从来不是"灵光一现"

知道了"好选题长什么样"还不够，关键是怎么稳定地产出好选题。

下面是我反复验证过的六个方法，可以独立使用，也可以组合起来用。

### ✊ 打法一：真实故事 + 情绪张力

读者最爱看什么？是"别人的故事里，有自己的影子"。

选题不需要多宏大，真实就好，最好能让人一下子就代入进去。比如：

*   "她30岁离婚，带孩子搬到郊区，靠一台旧电脑把日子过了回来"

*   "那对从不吵架的夫妻，第七年离了：没有裂缝的关系，才是最大的问题"

真实感加上冲突感，情绪入口就自然打开了。

### ✊ 打法二：日常话题 + 反常识切入

所有人都说是A，你偏要拿出逻辑证明是B。反转本身，就是流量。

来看几个例子：

*   "你不是拖延，你只是太想做到完美"

*   "情商高的人，从来不去'搞定'别人"

*   "副业一直失败，不是缺资源，是太听话了"

反常识、反直觉、反经验，都是套在读者头上的认知钩子。

### ✊ 打法三：具体数字 + 强对比

数字能让"可信度"和"真实感"瞬间拉满。

尤其是配合对比使用，读者一眼就能看到差距：

*   "网上的爆款公式一大堆，我拆了一百篇，最后只留这4个通用的"

*   "同样做公众号，她一个月赚3万，我坚持了3个月，赚了86块"

*   "我花199报了一门AI课，用课程做出来的第一个成品，卖了6980"

数字不是为了炫耀，而是给读者一个理由，判断这篇文章值不值得往下读。

### ✊ 打法四：热点事件 + 个人视角

热点自带流量，关键是你怎么切进去。

比如：

*   "李佳琦翻车，砸掉的不是人设，是打工人最后的情绪防线"

*   "高考作文写的'多巴胺陷阱'，就是我们每个成年人的日常"

*   "董宇辉分红400万那天，我辞职的冲动涨到了顶点"

借热点的势，同时输出自己的观点，是冷启动阶段效率最高的方式。

### ✊ 打法五：人群点名 + 痛点直击

越敢点名，越容易让对应的人群"对号入座"。

*   "35岁，国企，存款10万，孩子3岁，我决定干副业"

*   "公众号写了100篇，读者只有自己一个人，怎么办？"

*   "对AI又好奇又害怕的，直接看这篇"

一句话精准命中一个群体的核心焦虑，比长篇大论更有效。

### ✊ 打法六：场景描写 + 解决路径

实用类内容最适合开门见山：场景摆出来，解法跟上去。

比如：

*   "不想打鸡血，也不想参加酒局，这3个副业适合内向的人"

*   "脑子里天天像一团乱麻？我用这个办法，每天清空10分钟"

*   "公众号快断更了？我靠一张表，把日更撑了下来"

写内容本质上就是"带读者走一段路"，标题先告诉他终点在哪里。

这六套打法用熟了，会变成一种写作本能：

看到热点，自然知道从哪个角度切；

翻日常琐事，随手就能挖出痛点；

讲一个故事，下意识就知道怎么包装结构。

## 1.4 选题工具箱：问题到底从哪里来？

做公众号最磨人的，不是写不出来，是压根不知道该往哪个方向写。

很多人熬夜写出一整篇，数据却差得离谱。不是写得不行，是从选题这一步就偏了。

记住一句话：选题永远排第一。

一个能稳定输出的作者，手里一定有一整套选题方法。这节内容，就是把我的方法全部摊开给你看。

### 🔍 工具一：三层找题法——从外面往里挖

这是我一直沿用的方法，操作简单，任何人都能上手。

#### ⭕ 第一层：热点层（借流量）

目标：搭上大话题的便车，获取初始关注。

*   怎么做：盯着微博热搜、小红书热榜、知乎热议话题、微信指数这些渠道。

*   关键词参考：翻车、离职、爆款、焦虑、00后、AI、教育、婚姻……

示范：

热点："李佳琦翻车事件"

切入角度："打工人为什么不再买账？又是谁偷走了他们的底气？"

#### ⭕ 第二层：生活层（找共鸣）

目标：从日常生活里提炼出大家共有的情绪。

*   怎么做：记录你在工作、家庭、社交里碰到的困惑、突然想通的瞬间、让人矛盾的处境。

*   关键词参考：累、烦、迷茫、不甘心、撑不住、想改变……

示范：

日常片段："昨晚加班到10点，还被老板说效率太低"

延伸出的选题："成年人有多能忍？被骂到狗血淋头，还是不敢辞职"

#### ⭕ 第三层：专业层（做输出）

目标：用你擅长的知识，解决别人不会的问题。

*   怎么做：把你在一个细分领域踩过的坑、攒下的经验，整理成方法、模板。

*   关键词参考：方法、模板、框架、清单、案例、拆解……

示范：

我的积累："用GPT写公众号写了一年"

输出成果："提示词不会写？这套公式我用了半年，效率是以前的3倍"

### 🛠 工具二：三道筛选题——值不值得写，写完之前先判一判

动笔之前，拿这三道题过一遍：

#### ❶ 有人想看吗？

这个题有受众基础吗？还是你自己在自嗨？

→ 去知乎、小红书、公众号里搜索一下，看看有没有人讨论。

#### ❷ 我写得出来差异化吗？

这题是不是早就被人写烂了？你有没有自己的独特角度和经历？

→ 如果只能复制别人的思路，那不如不写。

#### ❸ 写了对我有什么用？

能带来流量吗？能推动变现吗？能强化你的个人标签吗？

→ 写之前想清楚目的，不然等于浪费时间。

### 🧠 工具三：三角透视法——从三个角色角度磨一个选题

一个真正的好选题，要能同时照顾到以下三个角色：

如果只盯着一个角色想，很容易写偏；三个角色都照顾到了，内容才是真正有传播力的。

✅ 做个总结：

*   三层找题法，解决的是"去哪找"；

*   三道筛选题，解决的是"值不值得"；

*   三角透视法，解决的是"怎么写得有劲儿"。

下一节，我们进入更实操的部分：如何用这些方法，搭建一个结构清楚、让人愿意读完的"爆款骨架"。

# 第二章｜结构思维：让文章"读得下去"的底层逻辑

## 2.1 把写作结构当成一个"函数"来理解

很多人的公众号文章，问题出在三个地方：

👉 逻辑断裂——想到哪写到哪，前后接不上；

👉 内容堆积——观点不少，但串不成一条线；

👉 结构松散——写完自己读一遍，像在翻聊天记录，口语感很重。

这样的文章熬出来，就像一锅半生不熟的粥——东西不少，但全都糊在一起。

反观写作能力强的人，写文章跟搭积木一样：每一块都严丝合缝，每一段都往同一个方向推进。

给你一个很容易记的公式——函数式结构：

好文章 = 结构（骨架）× 情绪（血肉）× 节奏（节拍）

拆开来看：

### ✅ 01｜结构，相当于骨架

读者需要在最开始就知道：这一段在讲什么，下一条线是什么，通篇会把我带到哪里。

常见的有三种骨架：

*   并列式：几个观点一字摆开，"观点1+观点2+观点3"

*   递进式："是什么→为什么→怎么办"，一层一层往下钻

*   叙事式："起→承→转→合"，靠情节带着情绪往前走

骨架立住了，读者才不会中途走丢。

### ✅ 02｜情绪，相当于血肉

写公众号不是写报告，不能让读者"觉得有道理"就完事，得让他有感、有画面、有共鸣。

给文章注入情绪，常用这几招：

*   放一个真实案例（普通人+冲突+细节）

*   写一段自己的经历（失败、顿悟、情绪上的反转）

*   用一句有力的话开头或结尾

📌 示范：

"我在电梯里崩溃大哭，因为领导白天当着全组说了那句话。"

这句话为什么让人想点开？因为画面、情绪、潜台词全都有。

### ✅ 03｜节奏，相当于节拍

写文章和写歌一个道理，节奏对了才有人愿意听完。

写作时随时注意节奏感：

*   句子长短换着来，别一口气写十行全是逗号

*   段落之间留白，让读者喘口气

*   每一段都为主干服务，写跑题是大忌

像长跑一样，起跑发力，中途匀速，收官阶段再冲一把，张弛有度。

✅ 浓缩成一句话：

结构决定走的是哪条路，情绪是路两旁的风景，节奏是你迈出的步幅。

下面，我们拆解三种最高频的结构模板，配上实际范例，保证你能直接用起来。

## 2.2 三个通用结构模板：会搭一个，就能套用所有

大部分公众号文章，翻来覆去就那几种结构。

就像盖房子用的是标准尺寸的钢筋水泥，写作也有自己的"预制构件"。只要掌握它们，什么选题都能往里套，写起来的难度直接砍半。

我建议新手先吃透这三种：并列式、递进式、叙事式。

### ✳️ 模板一：并列式

#### ✅ 模型：

观点1 + 案例1 + 小结

观点2 + 案例2 + 小结

观点3 + 案例3 + 小结

可以简化成"123公式"：三个平行的观点，各配一个支撑案例。

#### ✅ 适合的写作类型：

*   干货教程（如"3个写作技巧""5个副业方向"）

*   心得总结（如"这半年，我学到的3件事"）

*   方法论拆解（如"普通人赚钱的4条路径"）

#### ✅ 标题示例：

*   "公众号写作，这三个坑我挨个踩了一遍"

*   "副业第一个月，我只认真做了三件事"

### ✳️ 模板二：递进式

#### ✅ 模型：

是什么 → 为什么 → 怎么办

简化后就是：

"概念 → 原理 → 操作"

这是干货类内容最常用的逻辑结构，尤其适合知识输出和教学。

#### ✅ 适合的写作类型：

*   概念拆解（把一个新东西讲透）

*   教程操作（把实用经验一步步交代清楚）

*   问题解决（带着读者解决具体难题）

*   观点表达（轻阅读、感受向的内容）

#### ✅ 标题示例：

*   "提示词写不好？先弄明白它到底是什么"

*   "AI文章总是跑不出量？你可能漏了这3步"

*   "公众号变现完整路径：从0到1的三个阶段"

*   "一个人真正变强的开始，是不再抱怨。"

📌 提醒：

递进式的核心在于"环环相扣"，逻辑衔接要自然。段落之间加一句承接很有必要（"那么第二个问题是……"、"知道原因之后，该怎么做？"）。

### ✳️ 模板三：叙事式

#### ✅ 模型：

起 → 承 → 转 → 合

用一个片断 / 一个冲突时刻 / 一段心路变化来驱动全文。

#### ✅ 适合的写作类型：

*   个人经历分享

*   情绪共鸣内容

*   打造个人IP

#### ✅ 标题示例：

*   "裸辞第30天，凌晨两点，我哭到停不下来"

*   "35岁宝爸靠AI翻身，真正改变的其实是心态"

*   "她辞职去做公众号，第一篇就有100块打赏，背后的故事却很心酸"

📌 操作建议：

*   开头用一个具体事件制造悬念

*   中间把过程、冲突、挣扎展开来写

*   结尾收住情绪，落一句感悟或建议

✅ 简单总结：

不懂结构的人靠灵感硬写，懂结构的人靠模板做事。

*   想要稳定高效地输出？选并列式

*   想把一个事讲明白？选递进式

*   想把情绪写进人心里？选叙事式

## 2.3 一个自创的结构公式：组装文章就像拼乐高

你有没有过这种体验？

开头写得热血沸腾，写到中间开始跑偏，结尾草草收工。整篇情绪很满，但结构稀碎。

原因很简单：没有结构模板，就等于没有一个"容器"。内容再好，装不住也会洒出来。

这一节，我把自己一直在用的一个原创公式送给你：

### 🧩 公式：钩子 + 主线 + 佐证 + 收口

展开来讲就是：

开头抓人 ➝ 主体推进 ➝ 证据跟上 ➝ 收尾有力

#### ✅ 第一步：钩子——读者看不看，就看前三句

开头的作用是让人"停下来"，而不是"介绍背景"。

常用钩子有三种：

*   情绪型：一个崩溃或挣扎的瞬间

*   "我在电梯间突然哭了，就为领导那句冷冰冰的话。"

*   悬念型：一个让人忍不住想知道答案的问题

*   "她辞职做副业，第一个月就月入过万，她做对了什么？"

*   反差型：一个强烈的对比制造冲击

*   "他写公众号月入3万，我写了三个月只进账86块。"

一个选题的打开率，由前三句话决定了一半。

#### ✅ 第二步：主线——按结构把内容展开

这部分直接调用前面学过的三个模板，根据内容性质自由选择：

*   并列式：三件事、三个原因、三个方案

*   递进式：是什么→为什么→怎么办

*   叙事式：经历→转折→反思→建议

写的时候要盯紧：每一段都必须咬住主干，不让它变成没有主题的闲聊。

#### ✅ 第三步：佐证——给观点配上"实锤"

一篇有说服力的文章，不能只有观点，还要有"证据"这个部分。

可以零散穿插在正文里，也可以在结尾集中放一组：

*   一个真实案例（自己去经历过的，或从外部看到的）

*   一组数据或一份研究（拉动专业质感）

*   一句金句（调节节奏、加深记忆）

📌 示范：

"知乎上有个高赞回答，说：'副业不是换一种方式赚钱，而是重新理解你是谁。'"

这类补充信息不是主菜，但少了它们，文章会显得很单薄。

📌 小贴士：佐证素材平时就要注意积累。比如我自己有一个专门的金句库，做AI知识库的时候也可以直接导入进去调用。

#### ✅ 第四步：收口——要么升华，要么让他行动

结尾别再写"所以……"了，你可以换用这些更有力的方式：

*   用金句升华

*   "成年人最踏实的安全感，不是一份稳定的工作，而是转身离开的能力。"

*   引导行动

*   "如果你也站在原地犹豫了很久，不如先从公众号开始迈一步。"

*   回应开头

*   "那天晚上我突然想通：选择本身就很难，但永远不选，更难。"

记住：结尾是你留给读者的最后一句话，必须让人"想记住你"。

✅ 这个公式归纳起来就是一句话：

# 第三章｜素材管理：写不下去不是缺灵感，是缺弹药

## 3.1 好素材的标准是什么？

很多人写着写着就卡住了，开头还行，越到后面越空，最后只能烂尾。

这种体验很常见——但问题通常不在表达能力，而在于素材没备够。

把一篇文章想象成造房子：

选题是地基，结构是框架，素材是砖瓦灰浆。

但素材多的时候又会有新的烦恼：怎么筛选？什么样的素材才值得用？

### ✅ 标准一：能撑住你的观点

你抛出的每一个观点，都需要有东西"兜底"。素材就是那张底牌。

*   一个案例、一串数字、一个故事，都可以。

*   没有支撑的观点，读起来就像干巴巴的说教。

比如你说"副业不能盲目开始，要先盘点自己的能力"，你就得补一个例子：什么样的人没盘点就直接干，最后把自己搭进去了。

### ✅ 标准二：能带动读者的情绪

素材不能只有冰冷的"信息量"，还要有"温度"。

*   最能打动人心的，永远是情绪饱满、细节扎实的故事
