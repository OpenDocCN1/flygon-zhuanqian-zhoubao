# 一、为什么要把方法论搬进 Prompt？

读书的好处不用多说，我想强调的是“把书变成 Prompt”这件事本身有多值。从我自己的实践看，光是知识内化就有两大收益：

1.  让理解更扎实
2.  让理论真正落地

## 1）理解更扎实

这本质上就是费曼学习法的变体：

1.  输入阶段：从书里吸收知识。
2.  输出阶段：不是对人讲，而是对模型对齐思想，写成 Prompt。写不明白就说明没懂。
3.  对齐反馈：看模型回的内容，和自己的理解做对比，立刻暴露盲区。
4.  迭代优化：根据反馈把 Prompt 改得更准、更简洁。

## 2）理论更快落地

这个过程也符合经验学习圈：

1.  具体经验：读书拿理论。
2.  观察反思：把理论转化成具体问题写进 Prompt，逼自己想清楚怎么用。
3.  抽象概念：借模型回答再深化理解，怎么把抽象概念讲清楚。
4.  主动实验：用模型生成的方案直接去真实场景试。

# 二、福格行为模型速览

## 一）模型的核心公式

斯坦福行为科学家 B.J. Fogg 提出：
Behavior = Motivation + Ability + Prompt
行为 = 动机 + 能力 + 提示
三者缺一不可，少一个行为就启动不了。

举个最常见的例子：系安全带

[PRE0]

1.  动机：为了安全，减少伤亡风险。
2.  能力：车里有安全带，都会系。
3.  提示：车启动的提示音、上车后自然的坐姿动作。

反过来缺了哪一块就不会系：
1.  缺动机：觉得短途不用系、不重要。
2.  缺能力：安全带坏了、不会用。
3.  缺提示：没提醒、也没养成习惯，忘了。

## 二）别再让动机背锅了

### 1、动机是最不可靠的变量

很多人问：我明明想变好，为什么做不到？是不是我不够努力？其实问题不在“想不想”，而在动机本身的特性。

#### 1）动机很乱，而且会打架
动机来源很多：
1.  你个人的欲望，比如想吃甜点
2.  行动带来的利弊，比如交税
3.  外部环境，比如朋友都在做
当两个动机对冲，就会像跷跷板一样左右摇摆。比如我想戒甜食，又真的很想吃蛋糕。

[PRE1]

#### 2）动机上头快，下头也快
很强的动机能让你做一次性的硬事，比如辞职、赶飞机、把垃圾食品全扔掉。

[PRE2]
但它很难长期在线，冲到顶点后迅速回落。坚持不住不是你的错，是动机的工作方式。

#### 3）动机波动不可控
可预测的：双11、618前网购欲望自然抬头。
不可预测的：疫情初爆发，口罩需求瞬间爆炸。

#### 4）动机追不上抽象目标
健康、自由、人际关系、生活平衡，这些都是抽象概念。光有愿望没方法，只会内耗。

### 2、正确设计行为的六步法

行为=动机+能力+提示，所以设计流程可以拆成：
1.  明确愿望
2.  找行为选项
3.  匹配黄金行为
4.  调整行为难度
5.  找到合适的提示
6.  执行后立刻庆祝

# 三、从零开始做一次行为设计

我以“改善腰部疼痛”作为愿望来演示。

## 一）先分清愿望和行为

| 类别 | 解释 | 例子 |
| 愿望 | 抽象的想要的状态 | 改善腰部疼痛 |
| 行为 | 当下能做的具体动作 | 去做理疗按摩 |

## 二）列出所有可能的选项

为改善腰痛，我能做的事：
1.  每天散步
2.  定期做腰部拉伸
3.  保持良好坐姿
4.  用支撑坐垫
5.  控制体重
6.  定期热敷
7.  久坐时定时起身
8.  专业按摩
9.  换枕头床垫
......

## 三）挑出黄金行为

黄金行为=影响愿望 + 自己能做到 + 自己愿意做。福格的第一原则：帮人做他们本就想做的事。

用焦点地图评估：横轴难度，纵轴对愿望的影响。

在我常出差住酒店的条件下：
1.  每天散步：低影响，中等难度
2.  定期腰部拉伸：高影响，中低难度
3.  时刻保持坐姿：高影响，高难度
4.  使用支撑坐垫：中影响，高难度
5.  控制饮食：中影响，高难度
6.  热敷：中影响，高难度
7.  久坐定时起身：中高影响，低难度
8.  专业按摩：高影响，高难度
9.  换枕头床垫：低影响，低难度

## 四）把难度调到能做

先看能力五要素：时间、资金、体力、脑力、日程。

腰部拉伸分析：
1.  时间：只需1分钟
2.  资金：0成本
3.  体力：低消耗
4.  脑力：不用思考
5.  日程：随时随地可做

让行为变容易的三招：
1.  提升技能：B站看个教学视频
2.  准备工具：这个动作不需要工具
3.  缩小行为
   *   入门步骤：双手扶腰
   *   缩小规模：先做1个拉伸

## 五）找到“对”的提示

三大提示类型：
| 类型 | 定义 | 例子 | 评价 |
| 人物提示 | 靠身体本能 | 饿了、困了 | 最不靠谱 |
| 情境提示 | 环境触发 | 便签、App通知 | 动机能力不足时无效 |
| 行动提示锚点 | 用已有行为触发新行为 | 站起来后深呼吸 | 设计需要功力，效果最好 |

锚点三要素：
1.  匹配物理位置
2.  匹配频率
3.  匹配主题/目的

我选择的锚点最后动作：想上厕所时起身离开椅子
1.  位置匹配：基本都在椅子上
2.  频率匹配：一天上厕所很多次，和饮水习惯也吻合
3.  主题匹配：上厕所是休息节点，和拉伸放松同频

## 六）做完立刻庆祝

福格第二原则：帮人感受到成功。大脑靠庆祝来编码新习惯。

庆祝规则：说点什么或做点什么，让自己感觉好。

常用方式：挥拳喊Yes、敲桌面、想象拥抱、点头、投篮、放烟花、笑、比赞、画笑脸、哼歌。

我选的是：拉伸完深吸一口气并微笑。

最终公式：
行为 = [锚点最后动作] + [新行为入门步骤] + [庆祝]
想上厕所起身离开椅子 → 双手扶腰做3-5个腰部拉伸 → 深吸一口气并微笑。
