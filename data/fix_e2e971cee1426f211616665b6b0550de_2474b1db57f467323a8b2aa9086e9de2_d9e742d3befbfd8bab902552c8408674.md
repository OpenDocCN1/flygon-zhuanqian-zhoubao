### 概念四：插件
- **核心插件**：官方自带，在设置里开关即可。
- **社区插件**：第三方开发，必须到插件市场安装。

第一天别碰社区插件。先把核心插件里常用的几个打开用起来，等用上两三周后，发现原生功能真的卡住了再去找补充方案。

## 第 5 章 高频功能速成

### 文件、检索、收藏夹
- **文件面板** 左侧：右键新建笔记/文件夹，拖拽移动，双击打开。别一开始就花两小时搭目录，先写内容。
- **检索** 放大镜图标：在全库搜关键词，是后期最常用的手段之一。
- **收藏** 星标：每天要回看的页面钉住，避免在树状列表里翻。

### 两个肌肉记忆
- **Ctrl/Cmd + P 命令面板**：万能入口。找不到功能就搜这里，创建、设置、导出、运行插件都能找到。
- **Ctrl/Cmd + O 快速打开**：输入标题秒定位，比鼠标点选快很多。

### 关系图谱
把所有笔记的双向链接画出来。笔记少时只有几个孤点，等几百篇后会很震撼。新手看一眼即可，别沉迷研究。

### 推荐调整的设置
- 编辑器 → 默认编辑模式 → 实时预览
- 文件与链接 → 新建文件存放位置 → 指定一个收纳文件夹，避免散落
- 文件与链接 → 附件默认路径 → 指定如“附件”，图片 PDF 统一归位
- 核心插件确认开启：日记、大纲、收藏、标签、模板

### 高频快捷键
更多在 设置 → 快捷键 里查看和自定义。

## 第 6 章 三套组织思路

核心原则：文件夹保持扁平，控制在 1-2 层以内，用链接和标签做主线。没写够量就去设计完美分类，基本会翻车。

### MOC 内容地图
建一篇目录型页面，主要列举同主题的其他页面结构，不写大段正文：
[PRE3]

适合做主题入口。还可以建一篇 Home 页面，把所有 MOC 汇总，形成“地图的地图”。这是 Obsidian 里最流行的组织方式。
[PRE4]

### PARA
按用途和状态分四类：
- **Projects 项目**：正在推进、有终点的事情，如“装修居所”。
- **Areas 领域**：长期负责、无终点的事项，如“健康”“财务”。
- **Resources 资源**：兴趣素材库，如“摄影”“Python”。
- **Archives 归档**：已结束、不活跃的资料。

迁移技巧：从旧工具搬过来时，先把历史资料全扔进 Archives，桌面瞬间清爽，历史仍在。

### Zettelkasten 卡片盒
核心三条：每篇只记一个想法、用自己的语言复述、主动建立关联。流程是“即时记录 → 定期整理 → 重写并连线”。适合重写作和研究的人。它不是分类法，是写作法。

### 怎么选
- 想一眼看见主题结构 → MOC
- 想按“正在做什么”归类 → PARA
- 想沉淀写作素材 → Zettelkasten

最好先无脑写半个月，等真实需求自己冒出来，再针对性采用对应方法。

## 第 7 章 10 个社区插件推荐

### 7.1 通用安装流程
设置 → 社区插件 → 关闭受限模式 → 浏览打开市场 → 搜索 → 安装 → 记得点启用，很多人忘了启用以为失效。

市场打不开可换网络或加速，或去 PKMer 等国内镜像站手动下载，放到 仓库路径/.obsidian/plugins/插件名/ 目录下重启即可。

下面 10 个按安装顺序排列。其中 Templater、Tasks、QuickAdd、Dataview 配置稍复杂，其余装上就能用。

### 7.2 第一批立刻装
**Calendar 日历** —— 右侧多一个可视化月历，一眼看出哪天写了日记。点日期可跳转或创建。必须配合核心插件日记使用，建议把面板固定在右侧，每天打开第一件事点今天写日记。

**Templater 高级模板 —— 重点**
比核心模板强大，能自动填入日期、标题、星期，甚至弹出选择框。
使用方式：
1. 设置 → Templater → Template folder location，填写模板文件夹名，如“模板”。
2. 在该文件夹新建一篇笔记当模板，如“日记模板”，内容：
[PRE5]

新建笔记后按 Ctrl/Cmd + P 搜索「Templater: Insert template」→ 选择模板，内容会自动填充，日期会变成当天。
建议为日记、读书笔记、会议纪要、项目笔记各建一个模板。

**Image Toolkit 图片工具箱** —— 点击正文图片可全屏预览，支持滚轮缩放、拖拽移动、左右切换、Esc 关闭。装完即用，经常插入截图的人必备。

**QuickAdd 快速添加 —— 重点**
把灵感捕捉的阻力降到最低。按快捷键 → 输入框弹出 → 回车 → 自动追加到指定页面，全程 3 秒内完成。

典型配置捕捉灵感：
1. 仓库里先建一篇「灵感收集箱」
2. 设置 → QuickAdd，顶部输入“捕捉灵感”，类型选 Capture，点 Add Choice
3. 点齿轮配置：File Name 填“灵感收集箱”；Capture format 填 `- {{VALUE}} ({{DATE:YYYY-MM-DD HH:mm}})`
4. 回到首页点闪电图标注册命令
5. 设置 → 快捷键，搜索「QuickAdd 捕捉灵感」绑定快捷键，如 Ctrl/Cmd + Shift + I

之后有想法按快捷键输入回车，灵感就自动落入收集箱。

**Periodic Notes 周期笔记** —— 核心日记之外补充周记、月记、季记、年记。设置里开启 Weekly Notes，格式设为 YYYY-[W]ww，指定模板和文件夹。配合 Calendar 可直接点周数创建周记。每周日花 15-20 分钟复盘，坚持一个月会发现工作量惊人。

### 7.5 安装节奏建议
- 第一周：Calendar + Templater + Image Toolkit
- 第二周：Tasks + QuickAdd + Periodic Notes
- 第三周起：Kanban + Dataview + Excalidraw + Various Complements

插件并非越多越好。很多人装二三十个，结果启动变慢、界面臃肿，大部分闲置。正确思路是先遇到问题再找插件解决，而不是先装再找用途。工具为你服务，别为工具打工，先把内容写起来。

## 第 9 章 导入外部资料

### Word
安装 Importer 插件 → 命令面板搜「Importer: Import data」→ 选 Microsoft Word → 选文件导入。少量文档可直接复制粘贴到 Obsidian，新建笔记粘贴后标题、加粗、列表会自动转为 Markdown。

### 飞书文档
打开文档 → 右上角「⋯」→ 导出 → 优先选 Markdown，没有就选 Word。Markdown 文件直接拖进仓库即可。批量导出时勾选多文件 → 导出为 Word → 解压后用 Importer 批量导入。

### PDF
设置 → 文件与链接 → 附件默认存放路径指定文件夹。然后直接把 PDF 拖进编辑区，自动入库并生成链接。文件列表双击可阅读。页面里嵌入写 `![[文件名.pdf]]`。

### 音频与视频
支持 mp3 / wav / m4a、mp4 / webm，其它格式先转码。放入仓库后笔记写 `![[录音.mp3]]` 或 `![[演示.mp4]]`，阅读模式会出现播放器。注意视频体积大，易导致仓库膨胀，大视频放网盘只记链接。

## 第 10 章 同步与备份

笔记越积累越值钱，务必备份。
- Obsidian Sync 官方付费：端到端加密、有版本历史、跨设备无缝，最省心。
- 坚果云 / iCloud：把仓库放在同步目录，简单但 iCloud 仅限苹果生态。
- Obsidian Git 插件 + 私有 GitHub：同步加完整版本历史，可回滚，适合愿意折腾的人。
- Syncthing：免费开源点对点，不依赖云厂商，配置稍复杂。

底线：至少保留一份独立本地备份，如每周 rsync 到移动硬盘。

别求快。Obsidian 的价值随时间累积。一周写十篇可能没感觉，坚持一月三月，你会真正拥有“第二大脑”。

22. 先写后整理。别先花两小时设计文件夹分类，写多了自然知道怎么归类。
23. 不要追求完美笔记。一行字也值得记。笔记是给自己用的，不是作品。
