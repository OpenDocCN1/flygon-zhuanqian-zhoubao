做短视频最让人头疼的事，就是不知道下一个爆款在哪儿。刷了一整天别人的内容，眼睛看花了，还是找不到方向。最近我挖到一套“YouTube Shorts 数据采集+分析”的完整工具，简直是选题焦虑的救星。它不光能批量抓取视频数据，还能从播放、点赞、评论、时长等多个角度做交叉分析，更可以追踪热门频道和标签走势，并且一键输出报告。如果你正打算系统研究Short赛道，这套系统值得认真看看。

先说下运行要求：Windows 7以上系统，用Chrome、Edge或Firefox这类主流浏览器，联网状态就能跑，首次使用需要卡密激活。当前版本是v2.0，发布没多久，功能上做了不少升级。

上手其实就三步：激活、采集、看结果。

激活时打开程序，输入卡密，点一下激活按钮，等服务器验证通过就能进主界面。卡密会自动存在电脑上，下次启动自动验证，不用重复输入。作者还放了个小福利：点赞过100就送100个激活码，想抢先体验的话可以留意一下。[PRE0]

采集数据呢，切到“数据收集”标签页，把你的YouTube API Key填进去，再输入关键词，比如Roblox、Minecraft，支持中文和英文。接着设置最多收集多少条视频，建议范围在50到10000之间。还可以选择只抓最近N天的内容，留空代表全部时间。一切就绪后，点“开始收集”，跑完数据就会自动存到shorts.json文件里。[PRE1]

数据拿到手，就看分析了。切到“Data Analysis”标签页，点一下“分析所有数据 (HTML)”按钮，仪表板会在浏览器里自动打开，然后直接展示各种图表和统计，整个过程不用手动导入文件，非常省事。[PRE2]

这个分析仪表板，说实话，功能很能打。顶部是六大统计卡片：视频总数、观看总数、点赞总数、评论总数、平均数据，一眼掌握整体情况。往下是8个交互式图表，包括互动分布柱状图、时长分析直方图、观看与点赞相关性散点图、发布时间趋势折线图、热门频道横向柱状图、热门标签词云图、参与度雷达图、观看数分布饼图，基本上把想看的数据维度都覆盖了。[PRE3]

对于追热点的人来说，时间轴交互功能绝对是亮点。鼠标悬停在折线图的某个月份点上，就能看到当月视频数量；点击这个点，会打开一个新页面，只分析那个月发布的视频，所有图表和统计都针对该月，页面标题也会显示具体月份。比如你想单独看2025年11月的数据，点一下“2025 11”，瞬间生成专属报告。这个设计对于做月度复盘和趋势观察特别实用。[PRE4]

热门频道那块也很有意思。图表里展示的是发布视频最多的Top10频道，鼠标悬停可以看数据，直接点击柱状图，就会在新标签页跳转到该频道的YouTube主页，方便你顺藤摸瓜去研究竞对。[PRE5]

还有几个贴心的新功能值得提：热门视频列表支持分页，每页可以选10/20/50/100条，翻页按钮很聪明，首页只显示下一页，末页只显示上一页，中间页两边都有，再多的数据也能轻松浏览；系统用localStorage技术，数据自动保存和加载，打开分析页就自动读数据，不用再手动找文件；想要报告的话，点导出按钮，就能得到JSON格式的完整分析，包含总览、前20个热门视频、前10个频道、前20个标签。

在高级玩法上，系统内置了时间范围筛选的三层机制：第一层，YouTube API服务端根据你填的天数只返回该时间之后的视频，减少传输量，节省配额；第二层，客户端过滤时长小于等于60秒的视频，确保抓到的都是真正的Shorts；第三层，判断收集数量是否达到你设置的上限，避免超额抓取。

关于API Key的获取，去Google Cloud Console创建项目，启用YouTube Data API v3，生成一个API密钥就行，系统会把Key自动存到api_key.txt文件里，用Base64编码保存。注意，这不是加密，只是编码，API Key还是别随便分享给别人。

常见问题也帮你梳理几个关键点：API每日配额默认是10,000单位，一次搜索消耗约100单位，抓取视频详情每50个耗1单位，所以别一次设太大；如果你发现收集的视频数比设置的少，可能是该关键词下Shorts本身不够、时长被过滤、时间范围限制或者API配额不足；数据文件默认跟exe同目录，开发模式下在脚本目录；备份直接复制shorts.json就行。
