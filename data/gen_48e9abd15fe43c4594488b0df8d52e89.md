# 用同一套 Prompt 就能让 AI 产出所有类型的 HTML，这就是目前最省事的玩法

## 28 个赞 · AI 做 HTML 的终极方案，一套提示词模板搞定所有应用

作者： 饼干哥哥🍪

日期：2025-03-23

最近 Claude 3.7 在审美把控、SVG 绘制以及在线搜图方面的能力又有明显提升，网上刷到的大量 HTML 作品也因此变得愈发精致有趣。PPT 式页面、在线简历、个人名片、高保真原型、知识点卡片、带动效的交互组件，几乎什么都能做出来。

但随之而来的痛点也很明显：每个案例的 Prompt 都写得又长又绕，需要反复打磨；不同用途的 HTML 又要记不同的指令，成本太高。

为了把这个问题解决掉，我花了半天时间把即刻、公众号等平台上流传比较广的 HTML 案例全部梳理一遍，烧掉不少 token 后提炼出了一套通用型提示词框架。以后你不需要再为不同场景定制指令，只要套用这一个模板，就能稳定生成精美 PPT、实用的简历页面、高保真原型图、知识卡片以及各种动态交互组件等多种形态。
