# 1、为什么必须要有自己的 AI 知识库

搭这套系统前，我试过飞书知识库、IMA 知识库、NotebookLM，还有各种 AI 笔记工具，体验都不理想。

飞书、IMA 这类库，问问题还行，让它做任务就拉胯。它无法基于我的方法论帮我写小红书笔记，不能帮我处理录音，也不能按我的风格执行。

NotebookLM 好一点，问答和任务都能做，但不够顺手。没法直接在电脑上操作文件，记不住我的写作习惯，也不能实时写入内容，每次都要重新说明。

## 后来在 X 上看到 Obsidian + Claude Code 的玩法，试了一下，几乎就是我想要的样子！！

简单说下。Obsidian 是本地笔记软件，文件全在自己电脑，markdown 格式。

Claude Code 能直接读写电脑上的文件。两者连起来，AI 就能看到我所有的笔记、方法论、素材，还能直接创建文件、归类文件夹、写内容。

最直观的对比。

同样是让 AI「帮我写一篇小红书搜索笔记」：

直接问，它给你一篇正确但空洞的通用文。

用我的知识库：AI 会先去搜关键词下的头部笔记，分析类型和结构，再去读我的搜索 SEO 方法论【9 章，从底层逻辑到关键词排布】，再去读产品卖点和关键词表。

然后按我设定的写作规范生成：标题怎么起、关键词密度、痛点开头、钩子结尾，都有明确规则。写完自动跑质量自检。

模型一样，输出天差地别。

# 2、知识库全貌

## 2.1 目录结构

整体结构大概是这样：

[PRE3]

我按自己的习惯分的——内容从哪里来、在哪里沉淀、在哪里出。最近还在把个人日程和手机记录同步进来，会更全一点。

几个关键设计：

### 1. 内容有清晰的流水线状态

- 选题库 → 待发布 → 已发布。文章位置=进度，无需记忆。
- AI 自检通过后自动从选题库移到待发布。
- 我改完发布后手动移到已发布【可全自动】。每篇文章库里只存一个位置，不会乱。

### 2. 方法论按主题归类，不按来源归类

很多人按「这是谁的课」「这是哪本书的」来分，找起来痛苦。

[PRE4]

我按主题分：搜索 SEO 方法论、内容创作方法论、营销销售方法论。AI 写搜索笔记时直接去 SEO 文件夹读，不用管出处。

### 3. 产品库和内容库分开

写产品引流笔记就去产品库读卖点和关键词，写个人 IP 内容就去内容库读定位和素材。互不干扰。

[PRE5]

## 2.2 CLAUDE.md：给 AI 的操作手册

整套系统里最核心的文件。

Claude Code 启动时会自动读取根目录的 CLAUDE.md，可理解为新员工入职手册：业务是什么、怎么配合、什么绝对不能碰。

我的文件约 400 行，核心是：

- 1. 你在和谁协作。

不只是介绍我是谁，而是 AI 需要的所有背景：业务是什么、核心产品、目标人群分层及优先级、转化路径。读完它就知道为谁干活。

[PRE6]

#### 2. 协作原则

> 「直接给方案，别反问我想要什么风格」
> 「中文优先，注释和文件名都用中文」「中文内容必须用中文标点」

都是用着用着加上的。AI 默认爱用英文标点，后来直接写进规则。

#### 3. 行为约束

四条铁律：

- 不能移动、改名、删除任何已有文件，除非我明确确认；
- 内容文件只归档不删除；
- 必须我喊「提交」才执行；
- 不能改动其他 Skill 的配置。

为啥这么严？AI 有时会“好心办坏事”，把正在写的草稿移走。

[PRE7]

#### 4. 项目索引

每个文件夹用途、文件命名、发布流程。AI 能知道新文件放哪、叫什么。没写前，AI 经常乱放。

[PRE8]

#### 5. 任务快速参考

写公众号用哪个 Skill、写搜索笔记用哪个 Skill、处理录音用哪个 Skill、做产品分析用哪个 Skill。AI 直接匹配。

CLAUDE.md 不是一次性写完的。第一版 30 行，后面遇到 AI 用英文标点、擅自删文件、放错位置等问题，就一条条补上去。两个月长到 400 行。

它本质是人和 AI 的协作协议。踩过的坑，都变成规则。用得越久越省心。

## 2.3 叁厅说明书：把自己数字化

CLAUDE.md 管怎么干活，叁厅说明书管我是谁。

### 1. 人物档案

完整履历：换过 20 份工作、最差月入 369 元、如何接触小红书、如何开始自由职业。AI 需要植入个人经历时来这里取。

### 2. 新 IP 定位

一句话定位、人设关键词、目标人群画像【四类人群特征及内容策略】、内容配比、写作调性。400 多行，反复打磨。AI 写 IP 内容前必读。

### 3. 活素材库

正在用的故事、案例、金句、新认知。分「当季素材」和「经典素材」。AI 写文章优先选当季素材，避免重复。

使用过程中，聊天灵感、学员咨询发现、踩坑经验都会被补进素材库。

这些文件合在一起，AI 比大多数人更懂我。定位、风格、产品、经历、近期想法，全在里面。

## 2.4 Skills

这是执行层。

普通人每次都要在对话框里写长提示词。Skill 把提示词、方法论、规范提前固化成一个文件，一句话触发。

我现在有 13 个 Skill。

拆一个「搜索笔记生成」：

- 1. 触发条件：我说「写 xx 关键词的搜索笔记」就触发。
- 2. 执行链路：
AI 先通过 MCP 接口去小红书搜该关键词，看头部笔记的类型、结构、切入点，做竞品调研。
判断用户搜索意图【了解概念/找方法/看案例】，再读搜索 SEO 方法论【9 章，四层漏斗原理】。
结合排名规律，读关键词库判断优先级，去活素材库找相关真实案例。
按内嵌写作规范输出：标题必须踩核心词、关键词密度、出现位置、开头结构、结尾引导，全有标准。

### 3. 质量自检：

写完自动检查：关键词密度、标题是否踩词、开头三行有无钩子、有无违规表述。过检才保存到待发布，不合格就重写。

这就是 Skill 和普通提示词的区别。Skill 是带方法论、规范、自检的工作流，输出稳定，不会因提示词偷懒而掉质。

而且它会成长。随着知识库丰富而越来越完善。

我有几条曝光只有几十到几百的搜索笔记，至今还在持续成交。搜索笔记要的不是爆，是被搜到时排前面。

AI 严格遵守排名规则，比我凭感觉写靠谱。

# 3、真实工作流

## 3.1 写公众号

公众号是我主阵地，以前一篇要大半天，最长做到周更、月更，现在能日更，AI 功劳很大。

流程：

上午去咖啡店，点完咖啡就说「从选题库随机选一个写公众号」。

AI 先扫选题库挑未写选题，再检查最近 10 篇的配比【实战/故事等】，若某类连续 3 篇缺席，会优先推荐。

[PRE10]

我之前连续写了好几篇观点文，自己没察觉，数据大跌。后来把配比追踪写进 Skill，AI 帮我盯着。

选好后，AI 读 IP 定位文件知调性，再读活素材库匹配真实经历和案例。AI 写内容爱瞎编，这一步能避免。

写完先自检：

1. 去 AI 化检测：比喻句、名人引用、排比、「在这个时代」式开头等，检测到就改。
2. 内容力审视：富贵老师的三个维度——是否有降维打击段落、作者情绪是否有变化、菜市场测试【大爷大妈能不能听懂】。
3. IP 辨识度测试：换个署名还成立吗？不成立才算有个人特色。
4. 平台合规检查：无具体收入数字、无轻松赚钱话术。我曾因“网赚”表述被删文，所以设为硬规则。

跑完一轮，咖啡也好了。修改细节、加个人判断，一篇从选题到发布约一小时。以前要大半天。
