# 【我是谁】

大家好，我是白龙笔记。在生财圈里学习了一阵，这次很荣幸来分享。

2022年经朋友介绍，我加入了生财。早先就听说过它，内容越积越多，我也想来长长见识。进来后信息量确实大，但我很快找到方法：锁定自己感兴趣的方向，去站内搜文章、找人，专题式学习。生财的站内检索系统很好用，分类清楚，查东西方便。[PRE0]

我研究的重点是个人品牌、小红书、知乎。这些积累带来了一点成果：知乎创业话题3万+赞、1万粉；小红书幼师教育类项目带过336位学员；个人品牌也在慢慢成型。离不开生财，但更离不开把学到的东西用出来。边做边学、专题深耕，这八个字送给圈友们。

再介绍下自己：白龙，名字取自一部日本动画，寓意帮别人实现愿望。老家湖北，大学读建筑，2015年毕业后去了深圳，转行做了线上运营。[PRE1]

深圳五年后，2020年6月离职，开始独自创业。现在主要打理公号“白龙笔记”，1.7万粉丝，还有两个线上资源业务。[PRE2]

这三年试过不少事：豆瓣渠道导流、跨境电商、星座号、应用拉新、直播导流、音乐类中视频号……做得好的还是幼师教育类和小学学科类内容。加起来，三年也有七位数进账。和一年赚七位数的大佬比，这成绩不算多，但对我来说，是从0拼出来的。[PRE3]

第一年最苦，是摸索期，收入少，生活开销却不少。能撑下来，靠的是对未来的相信和早期客户的支持。第二年开始顺了，第三年才有了像样的回报。回头看，这条路走得值。

我这种没家底、缺人脉、初始资金也不多的人，能在网络世界做出点成绩，靠的是长期思维、向行家请教、持续学习。我明白很多年轻人想有自己的小事业，但现实中，95%的人选择安分上班。我很理解，所以这不是鼓动你离职的文章。有人问我意见，我基本劝他先上班，业余时间把第二收入做起来，有成绩再谈以后。

要是你已经具备了条件和心态，那下面的经验，也许能帮你更快完成过渡。

# 【我为什么离开职场】

老家有油田，油田单位是当地体面的工作。高中时我还想过考油田专业，毕业拿五千就满足。

后来想法变了。2010年上大学，我选建筑学，想做建筑师。可大一读完，我知道自己没那个天分。

大二有了电脑，对专业没兴趣，就开始研究网络赚钱。那阵子看过很多国内外教程，也读了财商类书籍，观念被刷新。当时我就想成为一个有自己事业的人，个体户也好，老板也好，唯独没考虑过打工或进体制内求安稳。当然选择没有对错，只是个人喜好。

我也混过网创论坛，边看边练。前两年一直没突破，直到大三下学期突然开窍，靠卖建筑类电子资料，月入做到4000+，给了我很大信心。[PRE4]

毕业后，我依然迷茫，但唯一确定的是要进线上这一行。[PRE5]为了转行，还报了新媒体培训班。

刚做运营时，我很有热情。后来慢慢发现，即使手里握着几十万粉的公号，也不过是在帮老板实现他的梦，自己只是一个小零件。哪怕做到月入一两万，也看不到留在深圳的可能。[PRE6]

上班时浑身难受，只有研究自己的项目时才有劲。于是，我在完成日常工作之余，业余时间都在测试项目。2020年6月，时机成熟，我辞去工作，搬到了生活成本低很多的城市。当时有一本讲财富路线的书点醒了我：打工是绕远路，自己干才是高速公路。

# 【离开前，三件事要想透】

离职这件事，没有说起来那么轻松。我犹豫了一年多。那时候工作清闲，工资稳定，走掉等于丢掉安逸圈。但我明白，继续泡在温水里，五年后也不会有什么变化。所以那一年，我系统测了很多方向，只为确保辞职后还能活下去。

所以别头脑发热就辞职。在职场上好好干，一样能过上好生活；喜欢安稳的人，更不必学别人闯荡。你要先认清自己：求稳还是求变，各有代价。

倘若确要拥有自己的事业，离开前做三个准备：

一是留足12个月的生活费。零收入也能安稳过一年。已有第二收入的话，让它连续6个月覆盖生活开销再走。最稳妥的做法，是上班时就把第二收入养大，再谈离职。

二是别回老家。老家住着省钱，但家里的牵挂、熟人议论，很容易让心态崩掉。加上杂事多，朋友聚会，看到别人过得安稳，你会怀疑自己选择的意义。不如去一个没人认识你的地方。前期可以告诉家人还在上班，有成绩了再摊牌。这不是冷血，做事业需要专注。

三是控制开支，学会记账。创业没有固定工资，收入时高时低。赚得多时别飘，赚得少时才不慌。我用记账软件坚持几年了，每周翻翻账单，能砍掉很多无用支出。这叫有备无患。

# 【适合普通人的3个小成本方向】

聊点实在的：做什么项目合适？每个人情况不同，我只分享自己看好的三个方向。

第一个方向，个人品牌。做成了能做一辈子，信任度高，还能带来人脉和更多商机。劣势是要养很久，无法复制，每个都是孤品。我的“白龙笔记”就是这个路线。各行各业都可以，比如最近看到一位汽车博主，定期拍客户提车视频，粉丝信任后买车直接找他；他不压货，和本地4S店合作，客户拿优惠，他拿分成，去年赚了不下50万。[PRE7]类似打法的还有很多，不用做超级大V，深耕一个细分领域就很赚钱。

第二个方向，虚拟产品。卖资料、卖软件，不要进货，一份内容能反复卖给很多人。各种资格考试备考内容都是稳定需求。注意版权，优先选无版权内容。

第三个方向，知识型服务。靠专业和时间变现，不用备货，成本很低，单次定价可以做得比较高。我之前做塔罗占卜，一次大牌阵收费300+。劣势是用时间换钱，有上限，想做大就得请人帮忙。方向包括占星、塔罗、心理、情感、法律、身心疗愈、转职咨询、推广策划等。有些领域最好考到证书，服务要用心，客户不满意就退款，客户信赖才是长久生意的基础。

这三个方向都适合个人。我看方向只有两标准：一是能不能长期做、有没有复利；二是投入少、收入天花板高。如果只靠卖体力赚小钱，不如去跑外卖。我从不碰快钱项目，因为门槛低别人也能做，护城河很快消失，利润也被打没了。

# 【居家办公的基础配置】

单干后我一直在家办公，配置分享如下。

1、住房。前期不用租办公室。做事业不是撑门面，越快上手越好。线上这行，有床、电脑、网线就能开工，没必要在大城市租高价房。很多小城市租金很低，鹤岗每月两三百的也有。[PRE8]也不用跑那么远，在本省找欠发达城市，用租房软件看看价格，会发现新天地。B站有位旅居博主，分享过月租不到500的海景房，看完挺心动。[PRE9]当然，住便宜点只是过渡，等收入涨了再搬去理想城市。想分开工作和生活，也可以租共享办公的卡位，一月几百块。

2、电脑和手机。电脑在预算内买好点的，不卡很重要。台式组装机性价比高，同价位配置更好，散热和屏幕都更大。别去淘宝销量榜上的店踩坑，多在知乎、B站看长期经营的口碑店。我此前用笔记本，屏幕小累眼睛，后来加24寸显示器舒服多了。测试项目需要多部手机，也可以在二手平台淘个人自用的。买二手不丢人，钱花在刀刃上才是成熟。

3、网络。带宽至少300M，网速慢很影响效率。我用移动，便宜也够用。预算足，电信更稳。

4、桌椅。桌子能用就行，一百多块搞定。椅子一定要舍得，我坐了几年人体工学椅，没选电竞椅，五六百块的国产款就很舒服。[PRE10]

5、吃饭。以前忙起来总点外卖，脾胃都吃差了。现在有空就自己做。看了一些烹饪视频，用过铁锅、热锅冷油，后来嫌费油换了不粘锅，注意别干烧，涂层脱了要勤换。[PRE11]我吃饭的标准是：能熟、不难吃、营养够。日常搭配就按碳水+蛋白质+蔬菜，米饭加点糙米更健康。[PRE12]买菜用生鲜配送App可以送到家，或者去社区菜店，晚上常打折。熟练之后，做一餐不到20分钟。而且做饭也是休息，人生许多事不由你，但一盘菜听你的，这种掌控感会慢慢延伸到生活里。

6、社保。很多人离职后忘了社保。以前公司代缴，现在要自己办。别再找电商平台代缴了，政策不允许。直接在支付App里搜索社保服务，进入个人参保登记入口办理。交完记得查记录。[PRE13]月初就交，断一个月不能补，还会影响以后买房。

7、资金周转。遇到现金流紧张，可以用正规平台的短期借款工具，但这些都有利息，手里有现金就别动。更不要透支消费。一本理财书里的原则是尽量用现金，真要用信贷，选周期长的，能减缓每月压力。

# 【日常怎么安排】

作息方面，自由职业不用太早起，但最好9点开工，晚上11点前睡。我以前常熬到半夜，后来强制自己11点就去洗漱，睡前泡泡脚。身体能扛，事业才长久。

工作内容，我的日常分三块：引流、成交、服务。不同阶段各有侧重。单干时全流程都自己来，确实耗人，所以我会找帮手或外包。帮手是在社群里认识的，帮了不少忙。重复性高、价值低的事务可以交出去，比如在招聘平台发帖找兼职；没有公司资质，也可以找代发服务来发帖。

效率方面，我每天早上在纸上列任务，按优先级排队，先啃最难最重的事。普通人习惯先做简单的，重要的事永远没时间，人也越来越不值钱。还有一个口诀：2分钟能完成的，马上去做；需要一段时间的，先做5分钟，启动后惯性会推着你走。

# 【单干的好处和风险】

好处是收入天花板高。打工在北上广深，月入一两万基本到顶了。自己干，收入等于卖出的单数乘以每单收益。假设每单赚300，每月33单就是月入过万。而且做得越久，单数和价格都会涨。

这是做起来的状态。万一没做起来，收入归零也正常，这就是风险。
