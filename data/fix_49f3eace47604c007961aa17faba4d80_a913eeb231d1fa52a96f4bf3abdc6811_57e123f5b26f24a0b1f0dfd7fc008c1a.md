# ChatGPT 会员充不上？没有外币卡也能自己走通 Apple 充值这条路

先确认这篇适不适合你：你手里至少要有一台 iPhone、iPad 或 Mac。三样都没有，那就不适合走 Apple 充值卡这条路。

只有 Mac 也行，但有限制：Mac 可以注册 Apple ID、兑换充值卡、管理已有的 Apple 套餐。只是新账号第一次通过 Apple 内购开启 ChatGPT Plus，仍然需要 iPhone 或 iPad 配合。

另外提醒一句：OpenAI 现在要求免费账号第一次升级 Pro 必须在网页端完成，所以 Pro 首次开通不能照搬这套 Apple 内购流程。这篇写的是 Plus。

这篇教程是逐屏实拍整理出来的，你按着界面一步步走就行。

## 为什么会写这篇

我最近在 AI Agent 架构师航海项目里担任教练，发现一个高频卡点：很多人明明已经在用 ChatGPT 和 Codex，却卡在会员升级和支付上。没有 Visa，试过几种海外支付方式都不顺利，最后只能反复找代充，或者干脆转去购买 OpenAI 的 API。

其实不少人买 API 不是因为它更合适，而是 Plus 一直开不出来。按量计费听起来灵活，日常高频使用下来，往往比固定月费贵不少。把 ChatGPT 套餐正常办下来，就不用一直为同样的使用场景承担 API 的单次费用。

这件事麻烦在哪儿呢？账号、设备、付款界面互相牵连，口头说几句很容易漏，自己动手的时候还是卡住。所以我想把从注册美国区 Apple ID 开始，到买卡、兑换、开通、续费的整条链路，写成一份可以照着操作的教程。

尤其想帮到这几类朋友：没有外币卡、暂时无法直接海外支付，以及不想每个月把账号和验证码交给代充的人。

## 这套流程我自己反复跑过

写这篇之前，我手里已经有三个以上的美国区 Apple ID，每一个都是从零开始，完整走过注册、购卡、兑换和开通的流程。

最初折腾这些账号，是为了给不同的 Claude 账号付费。后来那批 Claude 账号陆续被封，前后一共八个，多出来的 Apple ID 也就闲置了。账号虽然闲着，踩过的坑还在，整理出来正好给圈友参考。

为了把过程写准确，我又在写稿那天下午翻出以前和 Gemini、GPT 讨论的记录，和 Codex 一起梳理。写到关键部分时，我还从新建 Apple ID 开始，把 iPhone 路线完整重跑了一遍。原以为几个小时能结束，结果一直忙到晚上十点多。

这次重跑还遇到一个之前没见过的情况：用一个注册过很多美区账户的手机号收完验证码，页面提示“此时无法创建你的账户”。我换成了自己长期使用、能正常接收验证码的另一个手机号，才顺利通过。这种只有重新操作一遍才会发现的细节，我也写进了教程。

## 教程里都覆盖了什么

我按新手真实操作的顺序，把整个流程拆成七个环节：

- 在 App Store 切到目标账户，核对 ChatGPT 套餐和实际应付总额；
- 把 Apple 充值卡兑换成账户可用额度；
- 通过 Apple 内购开启 ChatGPT Plus；
- 核对套餐状态，并知道以后怎么续订、怎么取消。

每一步都写清楚点什么、看到什么、什么状态算成功。

常见的异常情况也整理出来了：

- 出现 Review，或者找不到 None；
- 提示 Payment Method Required；
- 一个手机号注册了太多美区账户；
- 充值卡已经兑换，但额度暂时不能付款；
- Apple 已经扣款，ChatGPT 里却还没显示 Plus。

遇到问题可以直接跳到对应的排查段落，处理完再回到原步骤，不需要从头翻到尾。自己完整走通一次以后，后面通常只需要确认金额、购卡、兑换和续订，会顺畅很多，也不用每个月再把账号和验证码交给别人。

## 关于 Mac 用户

目前逐屏截图以 iPhone 路线为主。Mac 可以注册 Apple ID、兑换充值卡，也能查看和管理已经通过 Apple 创建的 ChatGPT 套餐，这一点我在 Mac App Store 里重新核对过。但新账号第一次通过 Apple 开启 Plus，还是要按 iPhone 或 iPad 的流程走。如果大家需要 Mac 版逐屏教程，我后面再单独补一篇。

# 国内用户从注册到开通的详细操作

先说明一下名称变化：Apple ID 现在叫 Apple Account。看到这两个名字，把它们当成同一种账号就好。

整个流程共七个环节：注册 → 登录美区 App Store 并完成首次配置 → 核对充值总额 → 支付宝购卡 → 兑换额度 → 开启 Plus → 核对结果。

开始前要有心理准备：如果界面强制要求你提供搞不到的手机号、付款方式或美国账单信息，就停在那一步。不要买卡，也不要为了继续而购买来路不明的资料。

本文不涉及科学上网，也不解决 ChatGPT 服务地区或网络异常的问题。文中写“不用切换网络”的地方，仅表示 Apple 或支付宝那一步可以在国内网络下完成。

## 先选你的情况

- 如果你有 iPhone 或 iPad，想从零开始：走方案 A。
- 如果你只有 Mac：可以注册 Apple ID、管理已有的 Apple 套餐；第一次开通 Plus 仍需 iPhone 或 iPad。
- 如果你已经操作过，现在遇到扣款、账号或续费问题：直接看常见问题。
- 如果三台苹果设备都没有：这条 Apple 充值卡路线不适用，不要提前买卡。
- 如果 ChatGPT 已经显示 Plus 或 Pro：不要重复购买；只是扣款或续费有问题，选上一条。

## 方案 A：iPhone / iPad 从零开通

### 开始前先备齐

- 一个没有注册过 Apple ID 的邮箱；
- 一个自己长期使用、能正常收验证码的手机号，不需要特意买美国号码；
- 一个准备升级到 Plus 的 ChatGPT 账号；
- 一台 iPhone 或 iPad；
- 支付宝。

手机号直接用自己的 +86 号码就可以，它只用来接收 Apple 验证码。同一个手机号可以给多个 Apple ID 使用，但不要用它反复注册太多美区账户。我实测发现，一个号码用得太频繁时，页面可能提示“此时无法创建你的账户”。遇到这种情况，先换一个自己长期使用、能正常收码的手机号再试。

Apple ID 和 ChatGPT 分属两套系统，注册邮箱可以相同，也可以不同。Apple ID 负责 App Store 和付款，Plus 会挂到付款时登录的那个 ChatGPT 账号上。如果还没有 ChatGPT 账号，先去 chatgpt.com 完成注册，并记好自己用的是邮箱、Google 还是 Apple 方式登录。

### 环节一：注册美国区 Apple ID

1. 用浏览器进入 account.apple.com。
2. 点“创建 Apple Account”。
3. 姓名和出生日期按页面提示填写，填完记下来，以后找回账号可能用得上。
4. 国家或地区选 United States。实测这一步不需要切换美国网络节点，页面能正常选择就可以继续。
5. 填好准备好的邮箱，设置密码。
6. 区号里能选 China mainland +86 时，就填你准备好的中国大陆手机号。如果网页入口不接受，可以换 App Store 官方入口再试：进入 App Store → 右上角的人像图标 → Create New Apple Account / 创建新 Apple Account。还是不行就先停下，不要借用或购买陌生号码。
7. 完成邮箱验证码和手机验证码。

按这条路径注册，填写的是姓名、地区、邮箱、密码、手机号和验证码，不会在这里出现账单地址或收货地址。看到账号首页，或者新邮箱已经能登入 Apple ID，就说明注册成功。

如果注册成功后网页继续要求绑定银行卡或 PayPal，先不要随便绑。关掉网页，下一步到 App Store 里登入新账号。

### 环节二：登录美区 App Store 并完成首次配置

这里只切换 App Store 的购买账号，不退出整台设备的 iCloud，照片、通讯录、备忘录和“查找”都不会受影响。

1. 进入系统设置，点最上方的人名或 Apple 账户栏。
2. 点“媒体与购买项目”。
3. 点“退出登录”，再次确认。这里只退出购买账号，不会退出 iCloud。
4. 再点“媒体与购买项目”，选择“不是［你的姓名］？”或“使用其他 Apple Account”。
5. 登入刚注册的美国区 Apple ID。需要双重认证时，输入发到受信任手机号的验证码。

#### 遇到 Review 或 None 怎么处理

Review 是新账号第一次使用 App Store 时可能出现的检查页面。None / 无表示不添加付款方式。

1. 出现 Review 就点继续。
2. 如果出现付款方式页面，并且能选 None，就选 None。
3. 没有 None，但页面允许不绑定银行卡或 PayPal、直接继续，就直接继续。
4. 页面接受后，会回到 App Store 的账户页或下载页，到这一步才说明首次配置完成。
5. 如果付款方式被标红，或明确要求绑定你无法提供的银行卡 / PayPal，就先停下来，去查看处理办法。

没出现 Review 时，可以先试着下载 ChatGPT 这类免费 App。能正常下载，就进入下一环节；下载时才弹 Review，就回到上面把配置做完。

账单资料不一定在这一步出现。没出现时不用主动去找，也不必提前补填。后面第一次拉起 Apple 购买流程时如果出现了，再按第六环节的相关说明处理。

最后核对账户地区：进入系统设置 → 你的姓名 → 媒体与购买项目 → 查看账户 → 国家或地区。显示 United States，并且 App Store 能正常下载免费 App，就说明这一环节完成。

### 环节三：确认要充值的总金额

这一步只看金额，不付款。本文下面按免税州填写账单地区；最终需要准备多少钱，以你自己页面上显示的总额为准。

1. 如果还没下载 ChatGPT，先去美区 App Store 搜索并安装；已经下载就直接启动。
2. 确认开发者名称是 OpenAI。
3. 打开 ChatGPT，登入准备升级 Plus 的账号。
4. 点对话页顶部的 Get Plus，或者进入设置后点 Upgrade。
5. 等待 Apple 的订阅确认页弹出，上面会显示套餐、价格和付款确认方式。
6. 记下套餐和总额。如果你的页面金额不同，以自己看到的为准。
7. 点关闭或取消，不要进行 Face ID、Touch ID、侧键或设备密码确认。

如果没有直接看到价格，而是先出现付款方式或账单资料，不要乱填。按第六环节里“第一次购买时出现付款或账单资料”的处理方法操作完，再回来看金额。

如果 Upgrade 按钮是灰色的，直接查看“Upgrade 按钮是灰色的”对应排查。

先确认金额再去购卡，可以避免只按固定美元价格买卡，最后发现额度不够。

### 环节四：通过支付宝购买美国区 Apple 充值卡

Apple Gift Card 在国内常叫苹果礼品卡。购买后会得到一串兑换代码，把这些代码充进 Apple ID，就会变成账户可用额度。

用支付宝作为主线，是因为入口集中、可以直接用人民币付款，也方便按截图核对。商品实际由页面显示的第三方服务商提供，不等于 Apple 官方直营。下单前要确认清楚适用地区、到账方式、退款规则和风险提示。

在你平时使用的手机支付宝里操作就行，不需要在美区 App Store 重新下载支付宝，也不需要切换美国网络节点。我实测在国内常规网络环境中可以正常进入并购买。

1. 进到支付宝首页，点一下左上角显示的地区或城市。
2. 把地区切换到旧金山 / San Francisco。其他能显示美国本地服务且带“礼品卡”入口的美国城市也可以，页面名称可能随版本变化。
3. 点“礼品卡”，进入支付宝里的第三方礼品卡服务页。
4. 点 Apple 卡入口；如果首页没有，就在搜索框输入 Apple。页面必须明确写明是用于美国区 Apple ID 或美国 App Store。
5. 进入付款页，在“税后消费总额”里输入需要购买的美元金额。金额不能低于上一环节看到的实际总额，第一次不要为了省事一次买太多。

付款前再核对四件事：卡的地区是美国区；美元金额充足；销售方和到账方式写清楚；退款或不可退款规则自己可以接受。

这一步在国内日常网络下就能完成，不需要科学上网。如果页面直接拦截付款，不要反复提交。

如果提示“该品牌正在补仓中，暂时无法支付”，说明当前没有库存，不是支付宝或 Apple ID 出了问题。先不要反复付款，过一段时间或者第二天再试。

额度提醒：正常购买并成功兑换的额度，不会因为长期未使用而自动过期。但兑换后会固定在这个美国区 Apple ID 上，不能转给其他账户，也不能换回现金，法律要求的例外除外。美国区卡只能关联美国区账户，也只能用于美国区购买。以后要更改 Apple ID 的国家或地区，必须先把额度花完；如果剩余额度低于任何单项价格，需要联系 Apple 支持处理。所以第一次下单只买实际需要的金额。具体规则见 Apple 美国区礼品卡条款和“更改国家或地区”说明。

确认信息无误后，在支付宝内完成付款。不要私下转账，也不要给卖家提供 Apple 密码、ChatGPT 密码、短信验证码或远程控制权限。

购卡成功以后，进入订单详情，在“门店及官网结账信息”或兑换代码区域找到代码，点“复制”。兑换代码通常是一串分组的字母和数字；截图里的代码已经用过，不能再兑换。复制完继续下一环节，不要把还没使用的代码发到群里。

其他渠道也能买到美国区 Apple 充值卡，比如闲鱼，有时价格更低，但这不代表卡源、售后和退款一定可靠。自行尝试时要看商家历史信用和真实评价，确认是美国区卡、交付兑换代码，并拒绝让对方登录自己的 Apple 或 ChatGPT 账号。本文不为这些渠道背书；第一次操作仍建议走支付宝路径。

### 环节五：把兑换代码变成 Apple 额度

兑换前再确认一次 App Store 当前登入的账号，确保就是刚注册的美国区 Apple ID。

1. 进入 App Store。
2. 点右上角的人像图标。
3. 点 Redeem Gift Card or Code / 兑换礼品卡或代码。
4. 选择手动输入。
5. 点代码输入框，粘贴刚复制的完整兑换代码。
6. 点右上角的“兑换”，完成兑换。

如果兑换时提示卡无效、已经兑换、未激活或地区不符，直接去查看兑换代码排查。
