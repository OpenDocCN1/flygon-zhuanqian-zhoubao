# 一、注册账号

注册没什么难度：用代理商链接填手机号注册，几秒搞定。注册完先做实名认证，再充值100元（随时可退）。这个钱不是白交，是因为账户余额低于100元没法下单买服务器。充值完成后联系代理商帮你调折扣，等折扣调好再继续下一步。

# 二、购买弹性IP

1. 先到顶部导航栏，点开【控制中心】。 [PRE1]
2. 从菜单里找到【弹性公网IP】，点进去。 [PRE2]
3. 选一个你需要的地区，每个地区最多购买10条IP。这里有个关键点：购买链接的URL里必须包含【console2】，否则后续没法搭SK5。确认链接没问题后，点【购买弹性IP】进入下单页。 [PRE3]
4. 计费方式选【按需计费】，公网带宽选【按流量计费】，带宽大小填【300】，购买数量填10条。 [PRE4]
5. 点【立即申请】，到确认页核对信息，没问题后点【提交】。 [PRE5]
6. 页面会自动跳回列表，等1分钟左右点【刷新】。 [PRE6]
7. 刷新后能看到刚买的IP，说明购买成功。如果显示的IP不足10条，那就是当前地区IP库存不够，换个时间再买即可。 [PRE7]

# 三、购买弹性云主机

买云主机时，地区一定要和刚才的弹性IP保持一致。比如我买的是深圳IP，云主机就选深圳。同样要确认URL里包含【console2】，这点直接决定你能不能继续往下搭。

1. 顶部导航栏打开【控制中心】。 [PRE8]
[PRE9]
2. 进入后找到【弹性云主机】，点【创建弹性云主机】。 [PRE10]
3. 购买页面有两种计费模式可选；实例类型和镜像按界面红框提示选择，其他保持默认，然后点【下一步：配置网络】。 [PRE11]

计费模式怎么选，给你一个参考：
- 包年/包月：准备长期用的话，选包月比按需更划算。但不建议直接按年，否则后面想换IP或退款时会比较麻烦。
- 按需计费：如果做的业务容易碰到封号，建议选这个，删机重开都很灵活。价格虽然比包月稍贵，但后期也可以随时转成包月，看你的实际需求。

4. 网络配置这页不用改动任何设置，直接点【下一步：高级配置】。 [PRE12]
5. 高级配置里，把云主机名称改成你喜欢的名字；root密码一定要设成自己能记住的，后面登录服务器要用。其他不用动，点【下一步：确认配置】。 [PRE13]
6. 核对一下配置信息，自动续费可勾可不勾，然后点【立即购买】。 [PRE14]
7. 跳到支付界面后，还没实名的话先实名，然后点【立即支付】。 [PRE15]
8. 支付完成，点【控制台】进入弹性云主机管理界面。 [PRE16]

# 四、配置云主机

1. 在控制台里点【云主机】，进入设置界面。 [PRE17]
2. 切到【安全组】选项卡，点【配置规则】。 [PRE18]
3. 再切到【入方向规则】，点【添加规则】。 [PRE19]
4. 按上图参数填写。这里有个小技巧：IP地址下拉菜单先随便选一项，再选回原来的，系统会自动填入0.0.0.0/0；当然也可以手动输入。填好后点【确认】完成添加。 [PRE20]
5. 接下来配置弹性IP，先点【控制中心】返回。 [PRE21]
6. 找到【弹性公网IP】点进去。 [PRE22]
7. 在【虚拟私有云】分类下，点【子网】。 [PRE23]
8. 点击对应的【子网ID】，进入子网详情。 [PRE24]
9. 切到【IP地址管理】，点【申请虚拟IP地址】。 [PRE25]
10. 创建方式选择【手动分配】，填入“11”，点【确认】。 [PRE26]
11. 创建成功后列表会多出一条虚拟IP，继续重复申请，一直申请到“19”。 [PRE27]
12. 确保从11到19全部申请满。 [PRE28]
13. 然后开始绑定：点【绑定弹性IP】，任选一条IP，点【确认】。 [PRE29]
14. 接着点【绑定主机】，选好对应的服务器，点【确认】。 [PRE30]
15. 剩下的11-19虚拟IP，都按上面的方式，依次把弹性IP和主机绑定好。 [PRE31]
16. 绑定完成后还剩一条IP没绑，先回到【弹性IP】列表。 [PRE32]
17. 找到那条未绑定的弹性IP，点【绑定】。 [PRE33]
18. 选好主机后点【确认】，再把这条IP地址记录下来——它就是之后登录服务器用的IP。 [PRE34]

# 五、配置服务器环境

1. 连接服务器，我用的是Finalshell。 [PRE35]
2. 打开后先点【文件夹】，再点【SSH连接】。 [PRE36]
3. 填写连接信息：IP填刚才记下来的那条未绑定IP，账号默认root，密码是买云主机时设置的root密码。 [PRE37]
4. 添加好后，双击该服务器就能连上。 [PRE38]
5. 首次连接会弹提示，选择【接受并保存】。 [PRE39]
6. 接着把下面这段命令复制到命令窗口，右键粘贴执行，作用是给网卡配上11-19这些辅助IP：

ifconfig eth0:1 192.168.0.11 up
ifconfig eth0:2 192.168.0.12 up
ifconfig eth0:3 192.168.0.13 up
ifconfig eth0:4 192.168.0.14 up
ifconfig eth0:5 192.168.0.15 up
ifconfig eth0:6 192.168.0.16 up
ifconfig eth0:7 192.168.0.17 up
ifconfig eth0:8 192.168.0.18 up
ifconfig eth0:9 192.168.0.19 up

[PRE40]
7. 接下来安装SK5脚本。安装文件是.sh格式，需要的朋友可以找我拿，生财的圈友直接免费。运行后看到安装成功界面就OK了。 [PRE41]
8. 装好以后，建议顺手把默认密码改掉。改法很简单：双击打开serve.toml文件。 [PRE42]
9. 把里面的 pass = "123456" 批量替换成自己的新密码，然后点【文件】→【保存】，再关闭文件。 [PRE43]
10. 回到命令行，执行 systemctl restart xray 重启服务，密码修改才算真正生效。 [PRE44]
11. 最后一步可选：检测一下SK5是否都能正常使用，一般情况都没问题。 [PRE45]
