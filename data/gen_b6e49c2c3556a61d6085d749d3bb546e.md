# 一、教育行业效果广告营销全链路

## 1.1 投放链路全景

[PRE7]

教育行业从触达到复购的完整链路是：获客→沟通转化→成交→交付→复购

获客：
表单链路：小红书表单H5 或 自由外链
直购链路：笔记 + 链接【外链/商品/私信】
私信链路：笔记 + 私信
种草链路：笔记【推荐码/公众号/小程序】

沟通转化：
表单链路：电销 / 加微 / 入群 / 试听
直购链路：加微 / 入群 / 试听
私信链路：客服 / 加微 / 入群 / 试听
种草链路：外溢 / 推荐码 / 试听

成交：线上正价课、线下体验面销、线下正价课付费，具体按公司策略定

交付：线上直播课、线上录播课、线上实操课、线下实体课

复购：跨科复购、同科续购、转介绍激励、回访运营

## 1.2 前端媒体与后端运营的双向优化

1.2.1 媒体端优化方向：

精准收割：
搜索：CPC 精确匹配 手动出价 / 自动出价
信息流：CPC 手动出价 / 自动出价

规模化获客：
搜索：① CPC 短语匹配 手动出价 / 自动出价
② OCPC 系统调控
③ 全站智投
信息流：① CPC 手动出价 / 自动出价
② OCPC 系统调控
③ Nobid 智能托管
④ 全站智投

*OCPC 指转化出价 + 指定/不限预算；Nobid 指系统自动出价 + 指定预算

1.2.2 运营端优化重点：

① 笔记内容：标题或结尾用资料、噱头做钩子，引导用户行动
② 笔记引导：利用聚光创意端口完成转化引导
③ 客服干预：小红书私信通 + 私信服务组件，配合人工话术及时承接

# 二、教育行业搜索广告投放要点

优化抓手：账户架构、选词与素材/笔记、出价策略
↓ ↓ ↓ ↓
优化目标：账户架构清晰利于精细化运营，阶梯式分词出价，各计划协同产生 1+1>2 的效果

账户架构：词库要全，覆盖潜在、意向、精准人群，最大化流量
选词素材/笔记：笔记围绕品牌、内容优质，降低前端成本并强化品牌力
出价策略：合理搭配不同出价方式，实现高效控本与放量

## 2.1 搜索账户搭建方法

需覆盖不同类型关键词，覆盖用户决策全阶段

搜索策略分攻守两端：

攻：种草教育
① 大流量核心词：抢占行业入口，高价抢高位
② 高价值卡位词：竞争相对平稳，业务高度相关且转化强，保证首位 SOV≈70%
③ 小流量长尾词：低成本引流，蓝海环境，多角度沟通

守：防守拦截
① 7×24小时首位防守
② 拦截竞品，最大化转化核心用户

搜索行为覆盖：
通用大词：潜在用户会搜，例如英语培训、早教
竞品词：对比型用户会搜，例如 XX.XX..
行业通用词：查询型用户会搜，例如英语培训机构、早教机构...
小流量长尾词：例如考研英语要报班么、早教几岁开始
品牌词：核心用户会搜，例如 XX、XX.....

## 2.2 计划搭建与一词多买逻辑

品牌词、通用词、人群词如何用聚光不同模式搭建

CPC 精确匹配：按系统建议值起步，根据竞争、期望排名、成本动态调整
CPC 短语匹配：出价可取精确匹配的 50% 左右
OCPC：按历史 CPA 表现设定目标成本

*通用词建议按特征拆分计划投放
*计划命名需体现词性与出价方式，便于追踪，如“搜索-通用词-早教-CPC精确”
*同账号不同创意单元间不会互相抢量，但同设置单元间会产生抢量

## 2.3 搜索计划搭建逻辑与目标

[PRE9]

按词性搭建账户，确保关键词匹配的出价和素材都有竞争力
切勿把不同词性关键词混投一计划，会造成无效高消耗，且笔记与搜索词不匹配

2.4 关键词采购建议

可参考小红书月度搜索报告及后台关键词规划工具

教育行业选词三大坑：
① 词量不足：跑量的计划单单元词量通常在 100-200 个，转化差的单元往往在 50 个以下
② 关联度低：投单一项目却高价买其他项目精准词，导致质量分下降、成本上涨
③ 只买竞品不买自身：高价投竞品品牌词，却对自有品牌词出价过低，造成流量流失

2.5 出价模式选择

整体上 OCPC 效果优于 CPC
OCPC：系统实时动态出价，在控制转化成本前提下提升转化量
OCPC 更适合规模化精准扩张，但 CPC 仍有价值，用于保底精准调价、稳定投放

若对聚光不熟或刚上手，建议直接用智能搭建：
[智能搭建]：基于推广业务/推广目标/目标成本/所选笔记，系统自动圈词与自动化投放，降低门槛与操作成本，提升效率

搜索广告优化总结：
账户结构：按词类词性拆分计划单元，而非按笔记拆分。同一单元内可多篇笔记上传，由系统赛马优选
选词：
1. 按品牌/通用/场景等维度拓展
2. 参考关键词规划工具选有量词，避免生造词
3. 保持关键词质量分≥6分，关注词与素材相关性，用高质量素材
匹配/出价：
1. 不要单模式投放，建议精确匹配 + 短语匹配 + OCPC 分计划并行
2. 投放 OCPC 后，避免随意调整核心消费的创意/关键词/落地页/计划开关/时段，以免破坏模型学习

# 三、教育行业信息流账户搭建

## 3.1 结构打法

信息流主要分两类：
① 全站智投：系统智能投放
② CPC 出价人工投放：个人习惯是一笔记一机会

搭建思路：① 按素材维度搭建，确保同一笔记在相同定向与相同出价下只有一个计划
② 同步多篇素材上传，由系统赛马挑出最佳笔记

优化思路：计划维度对比不同笔记的 ctr/cpc/转化数据；单元维度纵向对比同一笔记在不同定向下的表现，放大优质定向，关停低效单元

## 3.2 种草目标与转化目标的计划设置建议

投放目标：
产品种草——搭建建议：
同一笔记可同时建 1 个点击量目标计划【提升 UV、放量、降点击成本】 + 1 个互动量目标计划【提升点赞、降互动成本】

投放目标：
客资收集——搭建建议：
1. 行业兴趣与关键词兴趣双投：1 个行业定向计划 + 1 个关键词定向计划
2. 行业兴趣勾选相关标签如母婴、教育、金融、科技数码；关键词兴趣按项目定

信息流常规定向能力：
通投——小红书活跃人群
智能定向——系统基于行业/产品属性和投放目标挖掘人群
行业兴趣——基于行业阅读兴趣、购买兴趣挖掘人群
关键词兴趣——定向近 3 天内搜索过相关关键词的用户
人群包——支持 DMP 平台配置的精准人群包定向
平台推荐——高潜词包、特色人群、节促人群三大类
