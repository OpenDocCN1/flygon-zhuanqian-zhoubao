### 选对部署工具，别让工具拖慢你的网站

第一次把网站推上线，平台怎么选最让人纠结。Cloudflare 和 Vercel 其实都能用，区别在于上手体验。Vercel 的流程更顺滑，对新手更友好。Cloudflare 也可以部署，但如果已经用 Vercel 托管，就别再把域名的小云朵代理打开。

很多人看到域名后在 Cloudflare 上一直是橙色的小云朵，这就代表开了代理。Vercel 自带 CDN，再套一层 Cloudflare 代理只会增加延迟，不会加速。用 Vercel 的话，建议把这个代理关掉，恢复成灰色的小云朵。

Cloudflare 的付费档位，前期完全够用 Free 版。网站部署后样式全丢了，基本是资源加载或路径问题，直接把代码丢给 AI 帮你排查定位会快很多。

Vercel 免费版自动部署是有配额限制的。手动新建部署时要选对仓库和分支。Vercel 的分析功能是收费的，但你完全可以用免费的 Google Analytics，只要把 GA 代码合并进页面即可。代码更新后不需要手动去 Cloudflare 重新上传，GitHub 同步后它会自动覆盖，只是要自行确认页面是否真的刷新成功。

部署失败常见原因：用的是 Cloudflare Workers 不是 Pages，操作步骤遗漏了；分支已经推送但页面还是旧的，是还没完成部署；自定义域名删不掉 Pages 项目，是因为 DNS 解析还没先解绑。删项目前，先把指向 Cloudflare Pages 的 DNS 记录删掉，再一起清理。

纯前端站点没有数据库需求，直接上 Vercel 就行，不需要自己搭服务器再加 Cloudflare。Next.js 的话，官方推荐部署在 Vercel，兼容性最好，路由类型报错时也最省心。流量起来后 Cloudflare 在成本上更有优势，Next.js 项目想省心就用 Vercel，新手不必死磕概念，哪个好用先用哪个。

国内访问方面，Cloudflare Pages 托管的站点国内可直连，Vercel 则需要魔法。

### 服务器与多语言

练手阶段完全不需要买服务器，Vercel 或 Cloudflare 就能跑起来。关键词类项目不想用服务器，可以直接调用 Replicate、HuggingFace 这类平台的 API。

多语言实现两种思路都行，看项目需要。多数情况做在一个站点里。用不同的站点分开语言也可以。别用 span 标签硬存多语言，维护起来很乱。最简洁的做法是给每个语言建独立页面，URL 不同。更规范的做法是抽一个 JSON 文件做词库，页面通过变量取值，比如 t.apple，中文 JSON 里对应 苹果，英文 JSON 里对应 apple，切换语言只需切换词库。

### 网站美化与移动端

想让网站好看，先用 Gamma 按需求生成一个视觉模板，大致描述风格即可，生成后截图给 Cursor 照着写就行。整体或局部美化时，可以直接把目标样式截图给 AI，或者用关键词描述：高大上、科技感更强。21st.dev 是产品 Hunt 上常被提到的模板库，很多免费模板可直接喂给 Claude 参考。

移动端适配不能拖。桌面端好看不代表手机好用。F12 调整视口大小可以快速预览，精确调试建议用开发者工具。Next.js + Tailwind 本身自带响应式能力，提示词里直接要求适配移动端即可。导航站初期移动端体验也重要，部分权重搜索引擎会参考移动端体验。游戏站要看核心用户群体和使用场景，PC 为主还是移动为主决定优先级。

### 开发实战常见坑

本地 Windows 用 Cursor 写商城测不开，通常是技术栈和环境配置问题，不是换 Mac 就能解决，要理解数据库和应用服务器原理。Next.js 是全栈框架，可以处理前后后端。WordPress 想用在 GitHub 上是不行的，必须用服务器部署。

需要数据存储，推荐 Supabase，不需要自建服务器。文件下载类资源越来越多时，不要堆在 GitHub public 文件夹，用 Cloudflare R2 更合适。功能未完就不要追求完美，先上线再迭代宣传。样式丢失时先看 F12 控制台报错，大多是资源加载问题。多页面跳转嫌麻烦，抽公共组件做菜单和页脚引用即可。登录方式选最简单方便的，Google 一键登录是常见选择。

博客类网站 WordPress 能全能覆盖，但技术栈复杂。Vercel 官网有大量模板可参考。

### 变现与收款

刚上线不必急着跑通海外支付。初期可以用香港卡收款，产品先做起来。工商、招商等国内银行卡收外币要办香港银行卡。YouTube 广告分成国内卡也能用，不是订阅类收款。MasterCard 账单地址直接填国内地址即可。没有信用卡可在二手平台找代充，域名购买可用支付宝，Cursor 可代充。Spaceship 支付宝支付地址无效一般是拼音问题。域名续费贵与否前期可以忽略，能变现再考虑成本。Google Ads 国内用户也能投放，只是单价偏低。过早接入联盟营销链接不会影响谷歌排名。

### 游戏站 iframe 嵌入

Game Distribution 用 iframe 嵌入必须先提交域名申请许可。Kongregate 的游戏不能直接用网站链接，要找游戏专用的 embed 链接，格式类似 https://www.crazygames.com/embed/farm-merge-valley。

部署后出现防盗链提示，通常是源站做了限制，换站即可。被拒绝请求一般是作者禁止嵌入。CrazyGames 的游戏可以嵌入，本地可能有问题，部署到 Vercel 后通常正常。

找 iframe 的常用方法：在游戏页面打开开发者工具 F12，切到元素面板，搜索 iframe，复制代码串并验证能否单独打开。也可以直接在 GitHub 搜游戏项目。社区里也有现成的提取工具，批量提取链接信息更省事。
