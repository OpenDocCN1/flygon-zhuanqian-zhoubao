# 赚钱这件事，倒过来想会更清晰

> 来源：[https://pznme756ly.feishu.cn/docx/Xnr9dGr31o7iwwxa4nIcZQiJnFe](https://pznme756ly.feishu.cn/docx/Xnr9dGr31o7iwwxa4nIcZQiJnFe)

大家好，我是明白。

后台常有读者留言，问法都差不多——

我这把年纪都三四十了，一直在公司打工，从没刻意打磨过自己，手里也没什么硬本领。现在想找条路赚钱，完全没头绪，能给点方向吗？

我能理解，因为我自己就走过这段路。之前从码农圈出来，想在网上找点事做赚钱。2017 年进了生财有术，里面项目琳琅满目。我折腾了一年多，换了好几个赛道，结果都卡住。后来才恍然大悟，症结不在项目选择，而在本人底盘太薄。

* 学习力
* 思考力
* 输出、交流、成交
* 品类、推广

样样欠缺，却总想找一个零门槛的偏门，不用动脑、不耗时间、不用投入学习，就能快速回本。想想现在都觉得荒唐。

后来我做了什么调整呢？

# 1 《大江大河》里那个村书记

说到转折，我先讲近期重看《大江大河》时的一个镜头。

小雷家村很穷，村里一堆三十多岁的光棍，姑娘都不愿意嫁过来。后来上来一个退伍的村书记，人很开明，带村民琢磨致富路。他们干了三件小事——

* 建砖窑卖砖
* 组织施工队承接工程
* 搞预制厂做预制板

因为是县里第一批起步，抢了先机，赚了第一桶金，县里还把他们当样板，给政策给贷款。

但后来和县里闹僵，扶持没了。他们给县电线厂干活，对方欠了六十多万工程款，厂子效益差，钱拖着不付。村里一下子被套牢。

与此同时，其他村看到赚钱，也纷纷上马砖窑、施工队、预制厂。这三样活门槛极低，只要土和水泥钢筋就能开张。没新招的话，小雷家很快会被拉回原点。

县里后来提了个置换方案：用一套生产电线的设备抵债。全村反对，觉得要设备干啥，农村不会用，没人会操作。书记却坚持，先请专家验机，确认设备能正常产线，才点头。

设备拉回村里，书记说要建个电线厂。村民炸锅：没技术、没人手、没原料、没证照，看着就是赔本买卖。

书记在会上讲：县里已经不照顾我们了，邻村都在抄砖窑那套，等他们起来我们就没优势了。电线这条路不一样，整个县就我们有这套设备，能做出电线就是独家，别人想追也追不上。中间困难肯定一大堆，但办法总比困难多。这事很难，非常难，但做成之后，收益可能顶得上其他几家工厂加起来。更关键的是，现在不是选不选的问题，是不干，村子铁定回到过去的穷日子。

他顶着压力往外跑人情，高价聘技工，找上游材料，还和外县厂子搞联营，最后硬是把电线厂运转起来。首批产品一出就被抢光，他扛回一袋子现金，村民都说书记眼光远。

我当时特别受触动。他立项电线厂的逻辑，从来不是算眼前能赚多少，而是倒推未来要去哪。[PRE1]

# 2 把自己当作一个长期工程来规划

回到开头那个困惑。如果过去没积累，能力簿，现在就从当下开始补课。以前欠下的学习债，越早还越好，还清了人生会顺溜很多；还不清，就会一直循环：

* 到处找项目
* 追热点找风口
* 每天焦虑、恐惧、迷茫

我当时想明白后，就开始盘点自己该补什么——

* 学、思、练
* 写作为势能，产品为载体，营销为转化
* 商业洞察、沟通、成交

每项能力我都按 学习、演练、实战、成习惯 的节奏走了一遍。耗时耗心，但真正走完后，以前觉得高不可攀的项目，现在上手就顺。我才真信了那句话：项目本身都能赚钱，决定因素是人能不能扛住。

赚钱只是结果，背后是把一件事做成。能把事做成的根基，是知识和能力。两者齐备，做事成功率就高，钱也就来了；两者短板，做事必卡，钱自然无缘。

所以先搞清楚：你想做的变现路径，底层需要哪些能力。然后从今天起，把时间、体力、脑力持续投入进去，把它学会、内化、熟练。这个过程本身就是在为未来赚钱，只是收益会延迟体现。

这事确实吃力，但就像小雷家建电线厂一样，现在吃苦，未来复利。现在的学习，本质上是在为自己画路线图，让未来按你设定的方向发生。[PRE2]

# 3 赚钱这条路，怎么算毕业

如果把赚钱类比成上学，赚到钱就是毕业。

上学怎么毕业？看培养方案：修够学分、过够课程、拿够证书，条件满足就发证。

赚钱不一样，没人会给你一份标准答案：学了A就能赚到钱。所以只能自己去复盘：生财里那些真正持续变现的人，身上有哪些共同的素质和能力。那些素质，就是你的学分和证书清单。

然后在日常里老老实实去上课、做题、复盘错题、总结方法。重复次数够了，给自己时间，大概率能拿下好成绩，顺利毕业。

愿大家都能从现在起，为自己的未来做主动设计。
