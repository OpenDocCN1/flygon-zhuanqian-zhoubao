## 三条底层认知：先读懂模型的偏好

### 一、口语它能听懂，程序式逻辑它更吃香

日常交流天然带有歧义。同一词汇放在不同语境意义会漂移，例如“冷”可以指温度低，也可以指态度疏离，还能指思路清晰。“打开窗户”有人理解为通风，有人理解为翻窗进入。加上文化差异、个人经验、口语与书面语的差别，带来大量不确定性，模型解析自然语言时成本就高。

### 二、白话它能接受，专业词汇能让它更靠谱

专业术语负责准度，通俗表达负责流畅，二者配合效果最好。以股市为例，用“股票市场的价格会上涨和下跌”来提问，得到的回复往往空泛。若改成“股价存在波动”，模型立刻抓住核心，给出更专业的分析。反之，若堆砌大量修饰性描述，回复就会臃肿冗长，可读性下降。

这背后考验两件事：一是提问能力，能否把需求表述清楚、把问题边界划定清楚。二是知识储备，领域理解越深，越能判断答案质量，越能提出更有针对性的追问。两者兼备，才能把模型真正用好。

### 三、中文可以跑，英文才是主场

ChatGPT 的训练底座偏向英文，对英文指令的理解更自然。遇到复杂需求时，先用英文描述，经过模型生成后再让其转译为中文，往往比直接用中文提问更省力。

三条底层认知虽然偏理论，却是提升操控精度的重要基础，值得反复体会。

## 六条可直接上手的实操方法

### 方法一：使用精准指令模板

当对文本质量要求更高时，可以采用以下骨架：

[背景/上下文] + [角色设定] + [动作指令] + [成果形式] + [参考来源] + [表达风格] + [目标受众]

常用选项如下：

- 背景/上下文：当下事件 / 历史脉络 / 技术演进 / 文化语境 / 社会议题 / 经济态势
- 角色设定：撰稿人 / 行业顾问 / 讲师 / 研究生 / 营销人员 / 用户 / 设计师 / 创业者 / 管理者 / 开发工程师 / 心理咨询师 / 史学研究者 / 叙述者
- 动作指令：描述 / 解析 / 解释 / 预测 / 对比 / 设计 / 发想 / 推荐 / 探讨 / 评估 / 演示 / 批判
- 成果形式：短文 / 长文 / 报告 / 信件 / 清单 / 评论 / 演讲稿 / 方案 / 幻灯片大纲 / 脚本
- 参考来源：统计数据 / 研究报告 / 专家观点 / 档案资料 / 案例分析 / 新闻稿件 / 评论解读
- 表达风格：正式 / 轻松 / 幽默 / 严肃 / 感性 / 客观 / 主观 / 故事化 / 学术化 / 商务化
- 目标受众：儿童 / 青少年 / 成年人 / 老年群体 / 学子 / 行业从业者 / 消费者 / 投资人 / 研究人员 / 创业者 / 大众

七个维度不必每次都用全，按需求自由组合即可。

### 方法三：顺着模型的特性持续反馈

一次对话很难拿到理想答案。有效做法是在交互中持续给反馈。结果偏离预期时，立刻叫停并说明期望的调整方向；结果符合预期时，给出积极肯定，比如“不错”“我很满意这段”等。每一次反馈都在帮助模型校准下一步输出。不想打字也可以用表情符号点赞。

第一步，明确你想要的输出形态并写下来；第二步，提炼其中的关键词和核心概念；第三步，用这些概念构建明确问题；第四步，对问题做精简，去除冗余信息，必要时补充关键背景；第五步，若问题复杂，可拆分为若干子问题逐步引导。
