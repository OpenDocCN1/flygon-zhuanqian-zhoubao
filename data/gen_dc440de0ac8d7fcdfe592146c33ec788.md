# 陪诊赛道到底怎么赚钱？一份来自一线实操者的拆解

> 来源：[https://oen722req0.feishu.cn/docx/ScDWdhjkHolKzAxyHpjclEDsnMg](https://oen722req0.feishu.cn/docx/ScDWdhjkHolKzAxyHpjclEDsnMg)

陪诊这个赛道近一年迎来爆发，很多人问我到底能怎么变现。今天我就把自己在广州跑医院一年多的实战经验，全部摊开了说。

这次分享的初衷有三点：
1、给刚想入局的伙伴一些参考和思路；
2、广州是华南的医疗高地，我把过去一年在医院里摸索出的就医路径整理出来了，希望能帮到来广州看病的朋友。(见附件)
3、挂号难怎么破？我之前写过一篇入行指南，里面有应对技巧，想了解的可以去看彩蛋部分。

[PRE0]

# 一、自己亲自接单跑腿

核心服务就是陪同看病、代为问诊、代取药品、跑出入院手续、代拿检查报告等。我个人最高峰一天接了5单，日常平均大概1单/天。一线城市半天服务费普遍在300元左右。

[PRE1]

# 二、深耕试管陪诊这个高壁垒业务

做一轮试管婴儿，往返医院大概要15次左右。我已经全程跟过11个周期。试管陪诊属于这个行业的护城河，流程复杂、周期长，有人全程带路能帮客户省下大量时间成本，还能减少交通和住宿开销。

[PRE2]

# 三、做派单中介拿分成

先把流量做起来，再把订单分发给同行自己赚差价。我一般抽3成，执行方拿7成。美团上能挂靠陪诊服务，但真正的大流量场还是抖音，而且这个赛道目前基本靠自然曝光，不适合烧投放。

[PRE3]

# 四、带货医院院内制剂

我之前做过一支中医院自制制剂“开胃醒脾饮”的内容，单条视频收益过2万，到现在还有持续复购。院内制剂是医院自行研发的独家配方，市场上买不到同款，用药历史久、口碑稳定，只在院内销售。

[PRE4]
[PRE5]

# 五、做陪诊教学卖课

市场上陪诊课程价格跨度很大，从几十块到3000元都有。我线下亲自带过几个学员，后来发现纯线下带教太费时间，所以停掉了。现在想做教学的，一定要先把课程录好。抖音直播挂链接带转化是最常见的售卖方式。

[PRE6]
[PRE7]

# 六、组建团队招加盟

收加盟费+营业额分成是常见模式。市面上一个加盟名额报价在5万到10万不等，比如优德医是5万元起，陪诊无忧是10万元起，后续还会按分公司业绩分成。这是来自圈内朋友的真实交流。

[PRE8]
[PRE9]

# 七、提供就医绿色通道

说白了就是用钱换时间。大三甲医院排一个手术床位通常要等1-2个月，走绿色通道一般7天内就能安排，快的2-3天搞定。费用区间在5000到20000元不等。我有一个客户在中山大学附属第一医院等了两个多月还没排上。

[PRE10]

# 八、代预约疫苗和代购医美/减重产品

比如全国范围代约九价HPV疫苗，代购司美格鲁肽注射液等。需求稳定且刚性。

[PRE11]
[PRE12]

# 九、帮厂商把药品器械推进医院

如果手上有人脉资源，可以对接医药代表或器械商，把产品介绍进科室拿介绍费和分润。

[PRE13]

# 十、导流到高端私立医院做检查治疗

公立医院号源紧张，私立医院体验更好且当天可约。例如PET-CT检查，公立要排一周以上，私立当天就能做，费用约7000元，和公立相当，佣金能拿到2000+。类似子宫肌瘤、腺肌瘤的无创磁波刀、伽玛刀治疗也是高佣金方向。备注：前海人寿广州总医院是前海人寿首家自建三级综合医院，总投资约60亿元。

[PRE14]

# 十一、牵头海外就医服务

数据摆在眼前，中外癌症5年生存率差异明显：中国40.5%，英国54.3%，日本65.8%，美国67.1%。对接海外就医机构，按实收金额提成8%-20%。

[PRE16]

# 十二、推广基因检测项目

很多重症都需要先做基因检测来明确方案，而医院内部通常不开展，需要对接外部机构。推广一单佣金在1000-3000元区间。

[PRE18]

# 十三、帮人抢号挂号

入行后每天都会有人问能不能帮忙挂号。对于熟客我会用资源帮忙，没有资源时热门专家号很难抢到。一单佣金大概50-100元。
