## 让 AI 自己写提示词，直出公众号封面。

作者： 李飞

日期：2025-03-20

写号一年多，稿子交给大模型已经是日常，唯独封面这环每次发文都最费神。生图模型的成品总差点质感，以前图省事就从正文里随便截一张当封面，现在回头看确实拉低调性。

更烦的是平台要两种规格，横向 2.35:1 和方形 1:1。不同入口展示效果不一样，用同一张凑合看起来很别扭，等于每次都要做两套。

我也踩过不少坑：

**1.0：** 各种模板化工具，需要掏钱，还得手动调字、挑风格。我这个人比较懒，想免费白用，直接 pass。

[PRE1]

**2.0：** 即梦 2.1 模型能出带字海报，中文也能识别。试过之后字会扭曲、偶发乱码，横版还能看，方版构图总觉得怪。

[PRE2]

**3.0：** 后来让模型画 SVG，勉强能用，但质感像很久以前的网页，审美过不去。

[PRE3]

转机出现在 Claude 3.7 发布后。看到圈子里有人拿它做知识卡片，我萌生想法：与其自己死磕封面设计，不如让模型帮我把生成指令给写出来。

工具我选了 Trae 国际版。虽然比 Cursor 慢，还要排队，但能免费用，而且可以直接产出 html，不用复制粘贴、手动建文档，生成完打开目录就能预览。

**背景交代完毕，下面说怎么让它自己写指令。**

我对 Claude 3.7 说：

我需要根据一篇文案生成海报代码，以 html 形式返回。海报分两块，左边是 2.35:1，右边是 1:1。就拿到了【初版指令】。

[PRE4]

拿去测试，效果被我直接删了，懒得展示。

[PRE5]

**进入优化循环。**

哪里不合适就直接反馈，让它继续打磨。一个关键操作：清空历史对话。

Trae 属于编程类助手，会基于上下文做推断。写指令阶段，上下文越多越容易想太多、跑偏。所以每次修改前都新建会话，把旧记录清空。

[PRE6]

首版的问题是两块区域不在同一行，尺寸比例也错位。我要求它输出固定像素尺寸，并把改动保存到新文件，免得越改越差把可用版本覆盖掉。

[PRE7]

随后重复这个闭环：生成内容测试指令效果 → 查看结果 → 清空会话 → 告诉模型需要优化的点。循环几次后，最终效果可用。

[PRE8]

[PRE9]

**为何要把两个版式拼在一张画布？**

上传到公众号后台时，取左边作为横版，右边作为方版，一次导出解决两个尺寸。

[PRE10]

方版就放在右边。

[PRE11]

下面是跑通的指令，固定尺寸+图片版本，左右并排，左 900×383，右 383×383，风格保持一致。

```
你是一位专业的公众号封面制作者，能把用户提供的素材转成精美的 HTML 封面。

页面分为左右两块：
- 左侧：900×383 像素，横向排版
- 右侧：383×383 像素，正方形，内容与左侧一致，仅排版因比例而异

布局要求：
- 两块必须同行排列，采用 flex 横向布局
- 父容器宽度不小于 1283px
- 禁止换行
- 右侧高度保持 383px，与左侧一致
- 左侧宽 900px，右侧宽 383px
- 两块均设为不可伸缩不可压缩

内容限制：
- 只保留主标题、副标题和配图
- 主标题为视觉中心，必须清晰醒目
- 副标题只做补充说明
- 不出现大段文字

图片处理：
- 有图则作为视觉重点融合使用
- 可适度旋转、加阴影、加边框
- 多图可层叠
- 可用蒙版或渐变过渡
- 调整尺寸保证清晰与平衡
- 左右两块风格统一，呈现方式可微调

设计规范：
- 纯 HTML+CSS，不使用脚本
- 现代感专业，配色字体按内容选
- 输出完整 html 文件
- 左右颜色方案、字体、元素统一
- 不生成交互控件

技术建议：
- 使用固定像素，不用 aspect-ratio 或百分比留白
- 不用媒体查询
- 父容器用 flex row，禁止换行
- 子元素固定宽度且不可伸缩
- 父容器最小宽度 1283px
- 小屏可横向滚动
- 图片旋转用 transform，阴影用 box-shadow，层叠用 position+z-index，异形用 clip-path/border-radius

先简述设计思路，再输出完整代码。

用户会提供：
- 主标题
- 副标题
- 图片，视情况使用
- 配色或风格偏好
- 其他特殊需求

收到内容后开始制作。
```
