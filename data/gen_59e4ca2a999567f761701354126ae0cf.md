## 一个全职宝妈的 cursor 编程之路（迟来的航海好事）

作者： 初心

日期：2025-01-06

**用想法点火、用耐心浇水、用热情续航**

大家好，我是初心，是一位全职带娃的宝妈。今年 8 月 29 日我再次登上生财这艘船，这是我的第二次航海。

Cursor 的航行我坚持到了 12 月 16 日成功靠岸。航海手册里共 6 个开发任务我全部做完：AI 恋爱预测网站、YouTube 本地下载工具、小红书爆款笔记抓取与分析工具、网页二维码插件、网页金句卡片插件，以及 YouTube Shorts 视频批量剪辑工具。

对于有编程背景的人来说，这些可能只是小练习；可对我这样在接触 Cursor 前看到代码就发怵的纯外行而言，几乎等同于登天。

那我这个连代码是什么都搞不清的全职宝妈，到底是怎么从 0 到 1 再到 6，把这六个案例全部交付的呢？

# 一、从想法开始播种

每个人心里都藏着一个想做的东西：一辆车、一套房、一个理想伴侣，或者一款实用的小工具。现实里我们往往卡在第一步。

正因为有这份强烈的想做的心，才迈出了最难的那一步。这次航海的契机，就是看到花生做的「小猫补光灯」。它一下子点燃了我心里很久未动的那个念头。

过去要做一个 App 得配齐各种技术栈，现在借助 Cursor，一个对代码零认知的人也能独立把想法变成可上线运行的产品，这感觉太让人振奋了。

脑子里一下子冒出太多念头，完全不知道从何下手。好在有航海手册做引路，第一站是俄罗斯方块和图片压缩网站。

照着手册的步骤操作，几乎没怎么卡壳就能把两个小项目跑起来，连 Bug 都很少。功能相对简单，让我第一次真切感受到自己也能成事，这种信心非常关键。

小试牛刀后，我开始跃跃欲试，想着赶快把手册里的案例都过一遍，早点出师，再去实现自己心心念念的那些小工具。

# 二、用耐心一点点耕耘

越往后难度越高，牵涉到的代码量也越来越多。群里的大佬们看代码都直呼头疼，更别说我这种代码小白了。

但亲身用下来我发现，Cursor 的核心优势是能无限次改错，缺的只是时间。所以只要肯花时间反复试、反复调，也能慢慢把事情做成。

### 1、AI 恋爱预测网站

我第一个啃的案例就是 AI 恋爱预测网站，也是我花时间最长的项目。因为一开始不会驾驭 AI，我就傻乎乎地一路跟着 Cursor 的指令往下走，没做任何验证，也不知道代码能不能跑起来，感觉像没有终点。

我意识到这样下去热情会被磨光，必须先拿到一个哪怕很简陋但能跑起来的版本来打气。

[PRE0]

于是我停下来调整策略，明确告诉 Cursor：我现在要一个功能极简但能正常访问的网站。生财人常说的最小可行产品 MVP 就是这个意思。Cursor 很配合地开始基于已有代码做精简和收敛。

整体还算顺利，但问题也不少。我习惯直接把报错信息复制粘贴给 Cursor，让它去修，循环往复，核心就是给足时间保持专注。

一个细节很关键：Cursor 有时会重复犯同样的错。这时候一定要回头看对话上下文，确认它改的是不是正确的那个文件。我就撞过好几次枪口，它总去改同名但在错误位置的文件，最后还是我自己排查出来的。

大概 5 到 6 个小时后，AI 恋爱预测网站终于成型。界面丑是丑了点，但它是 Cursor 时代我的第一个完整网站，我给自己狠狠鼓了掌。

上线后还有个小插曲：我把代码推到 github 再部署到 vercel，结果打不开。我不甘心自己做的东西不能分享，于是用 ChatGPT 找办法，最后把自己的域名先解析到 CF，生成二级域名再绑定到 vercel 项目上，二战就顺畅了。

后面几个项目我都用这个二级域名的方式，省心很多。

第一个网站完成，自信明显提升了。我对 Cursor 的使用也更顺手，开始慢慢理解目录结构、git 这些概念，基本功都是在航海手册里打下的。

后面 5 个案例，我在完成手册要求的底线上，开始主动给自己加难度。

### 2、“YouTube 本地下载站点”

手册要求做网站，我却想着做成 Windows 下直接用的小工具，不是更方便吗？于是我问 Cursor 能不能做成桌面软件。

起初我觉得不太可能，结果方案一出来发现并不难，按照它的提示一直点 “accept all” 就行了。

没想到花了大概 1.5 小时，我就做出了人生第一款 Windows 软件。输入 YouTube 链接点下载，视频就落到本地电脑里了，现在同学也在用，反馈挺顺滑。

[PRE1]

官网我也做了个简单的，但因为 github 和 Vercel 的托管限制，无法做数据交互，基本就是个摆设，下载链接也没加，时间有限就先放下了。

[PRE2]

这个项目其实和我另一个航海 “YouTube Shorts” 能形成互补。

### 3、“小红书爆款笔记抓取”

同样是手册要求做抓取代码，我脑子里全是 Windows 软件的想法，既然之前成功过，这次就非做成桌面版不可。

代码验证没问题后，我顺势让 Cursor 也把它做成 Windows 版。成功了，但调试花了近 5 个小时，过程很磨人。

我又开始给自己加戏：市面上的软件一般都有官网，哪怕只是介绍和下载页，我也想配套做一个。于是又让我的“黑奴” Cursor 开工，我只要说清需求，再盯紧代码里的路径就行，因为 Cursor 经常会指错文件，大概率是我的提示不够严谨。

官网做起来更快，就是一个介绍页，放软件说明、功能点和下载地址。样式简陋，先用着。

[PRE3]

### 4、“网页二维码”和“网页金句卡片”的浏览器插件

按我的思路，每个工具最好都有 Windows 版加官网。这两个浏览器插件相对之前要轻量一些。

于是我保持了一天一个的节奏，插件本体一天搞定，官网也同步完成，大部分时间花在让 Cursor 反复修改代码上。

我没有中间停顿，而是连续打通整个流程，这样学得更快。

### 5、“批量剪 YouTube shorts 视频”

这是最后一个案例，也是使用价值很高的一款工具，和 “YouTube Shorts 航海” 遥相呼应。手册要求用代码直接生成视频，我照例给自己加难度：做成 Windows 工具并配官网。

这次问题更多，尤其是视频合成环节，预览总出现条纹，最后不得不让 Cursor 回到手册里的参考代码才解决。

前后折腾了将近 8 个小时，我自己都惊讶。过程中有倔强也有着急，但最终还是在当天晚上接近 24 点前完成了打卡提交。我一边看时间一边修 bug，发誓当天必须收尾，结果也做到了。

# 三、让热情持续燃烧

手册里的六个案例全部完成后，我关心的已不是能不能做软件，而是能做出怎样的软件。

在后续的打卡里，我给自己列了几个方向：

1、英语实时对话工具，帮助孩子练口语。
2、视频分析工具，解析视频内容而非转文字。
3、某平台关键词分析工具，分析关键词在平台上的表现。

我先挑了第二个，花了约 3 小时把核心功能跑通，接腾讯云 API 时也调试成功。但在做网页端时因为对 Cursor 的掌控不足，核心功能失效了。累计 10 小时左右仍未解决，主要卡在不懂代码以及 Cursor 没能准确读取腾讯云官方文档上。

后来被夸克网盘分享链接大面积失效困扰，我又花了 3 小时做了一款“夸克网盘分享链接批量有效性检测工具”，终于把烦心事解决了。

[PRE8]

我能明显感觉自己正处在 Cursor 的热潮里，意愿很强。AI 把门槛拉得很低，我们一定要抓住这个窗口。

# 写在最后

这次实战让我能快速做出小工具，主要归功于：

1、强烈的意愿
2、充足的时间
3、足够的耐心
4、不满足于现状
5、真诚的热爱

如果你没能全部完成也不用灰心，可能只是时间不够。有时间的话，你或许会做得比我更快更好。

每个人情况不同，路径也各不相同，只要发挥自己的优势就行。

最后，感谢本次航海的志愿者、教练和领队对我们船员的帮助！
