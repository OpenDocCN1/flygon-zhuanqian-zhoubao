## 3. 抢占公众号名

五号开始，朋友圈里到处都是 ChatGPT 对话的截图，我意识到热度已经起来，立刻去查了百度关键词规划师、腾讯广告关键词工具以及微信指数。

[PRE4]  

关键词规划师上已经挂了热搜标签，微信指数也在飙升，规模还没到七位数。看完数据后我马上在微信里搜“ChatGPT”，公众号的注册数为零，小程序注册数为二，名称分别是 ChatGPT、ChatGPT 中文。

完全一致的命名已被小程序占走，于是我第一时间提交了公众号申请，名叫 ChatGPT 中文版。因为带了“中文版”三个字，初审被拒，直到傍晚才收到驳回通知，改名后才通过。截至发文时，大多数用户搜索核心词，我的号基本排在最前，因搜索个性化不同，位置会略有差异。

## 4. 把 OpenAI 对话模型搬进公众号

OpenAI 对外开放了大量封装好的能力，包括文本补全、改写、图像生成等，其中基于 GPT 的补全模型 text-davinci-003，能实现接近 ChatGPT 的聊天效果。

灵机一动，我花了十来分钟写了几十行代码，就成了全网首个把 ChatGPT 能力接入公众号的人。

[PRE5]  

这个号我并未公开，仅小范围给朋友体验。产品成熟度不够，我不好大规模推送，也很感谢几位朋友私下给的建议。当时要考虑的点比较多：

1. 接口按量收费，按输入加输出的 token 数量计费。token 到字符的换算基于压缩算法，大约一千 token 对应七百五十个英文单词，中文字符没有明确对应。新号只有十八美元额度，若不想付费就需要多号轮换，代码里要加账号切换逻辑，成本不小。
2. 最早上线且名字靠前，必然吃到公众号搜索入口的流量。熟悉微信生态的人都清楚，要保证稳定必须处理好微信服务器的大量回调，这块也要投入精力。
3. OpenAI 机器人的回复没有针对国内互联网环境做合规处理，若要公开接入公众号，就必须额外接入内容审核接口，又是一项工作量。
4. 该 GPT3.0 接口在上下文连贯性上终究不如 ChatGPT，单次调用上限四千零九十六 token，而 ChatGPT 的能力超出很多，这个问题无法根治。

值得一提的是好友 @码叔 走的相反路线。我在群里分享了接入方案后，他也迅速做了个版本。

[PRE6]  

虽然问题不少，但他第一时间就把链接发到三个微信号的朋友圈做宣传，并直接开始售卖该功能变现。后来我还帮他解决了报错问题，他的变现收益后续非常可观。

## 5. 发现镜像站点

十二月七号中午，Caoz 的群里有人分享了 gpt.chartapi.art 这个站点，这是 ChatGPT 的一个镜像站点，立刻吸引了我的注意。

该镜像不仅复刻了整站，还内置了账号认证凭证。用户访问时站点会作为代理访问真正的 ChatGPT，并带上站方准备好的凭证，让受限地区用户也能免注册直接使用目前最强的对话 AI。

## 6. 再做一层镜像

看到镜像站的第一反应是查其部署位置，ping 后发现是在 Cloudflare 上运行，常见做法是利用 Cloudflare Workers 做反向代理，本质上属于边缘计算和函数计算的范式。

第二个想法是 H5 在微信内体验不如小程序顺手，比如转发和使用感受。虽然当时已有少量小程序，但多是空壳占位。我决定做第一个真正可用版本。

为追求最快上线，只需在小程序里嵌一个 webview，唯一难点是需要一个已备案的业务域名作为入口。由于我手上没有阿里云备案域名，这里域名和 SSL 证书都是小张同志提供的，就是现在大家熟知的 xingchengka.com 作者。于是我又花了十几分钟，做了 ChatGPT 镜像的再镜像，部署在阿里云函数计算上，封进小程序壳上线，似乎又成了全网首个真正集成 ChatGPT 能力的小程序。

需要承认，我镜像的是别人的镜像，意味着所有流量都要经过他的服务，理论上可以优化但我没折腾。这就导致他的 CF 额度被我消耗不少，一个免费账号每月十万次免费请求，超出后五美元可扩到一千万次，成本也不高，希望未来能发个红包致谢，目前消耗接近五十万次请求，好在热度随后消退。

## 8. 一点反思

做这些东西，真正动手的时长并不长，但持续关注和参与讨论却打乱了我原本的项目节奏，影响不小。而且我几乎完全是出于兴趣在做，并未考虑变现。

热点年年有月月有天天下有，我认为有一定敏锐度的技术人应该怎么做，假设是以技术驱动且能做决策。最关键的是先把自己的技术底座搭好，这样风口来临时才能最快响应，而不是被风口牵着走，而是平静看风口往复。

所以每次风口过去，复盘下技术基础设施是否得到完善，这点很有价值。

再从运营角度看，风口流量如何高效利用？我觉得有两点：第一，别错过任何流量的裂变机会；第二，及时找到合适的后端产品做转化，例如卖号，这块技术人自己别亲力亲为，做成自动化交给机器更合适。

最后，从风口里提炼出可长期做的方向。比如前文提到的会话保存插件，这完全可以做成付费产品，核心功能并不复杂，借助风口流量完成第一轮 PMF，就很值。这个会话保存插件，我手上有本葵花宝典，你要做的话我可以倾囊相售，哈哈。
