# 二、这座工厂是怎么磨出来的

先说来路，知道来路，后面每个设计才有意义。

最早我做的是流量号。娱乐八卦、情感、婆媳、老年人赛道，追风口。跑起来时单篇能到十万阅读，评论区热闹。但平均爆文在1-2万，也有一堆号毫无起色。

打法很激进，在红线边缘试探。违规、违禁、律师函都经历过，号死一批残一批。

十万阅读里有些擦边、有些被投诉、有些踩线。一旦被判违禁，收益清零，号也救不回来。现在我拿老号尝试清洗，后续有结果再汇报。

这之后我学会一个流量主保命经验，多人不知：做风口类短平快流量文，爆了收益到手就主动删文。

这类内容平台只做一次性分发，留着无用且风险常驻。主动删除，收益落袋；等被投诉再删，收益没了。所以我的爆文大部分是我自己删的。

这也是本文看不到10万+截图的原因——目前能翻到的最高七万多。赚到钱才是自己的，闷声发财最安全。

那段经历教会我两点。

第一，流量号是概率游戏，爆不爆看平台，死不死看你手贱。第二，平台红线是真的，能把几个月心血一夜清零。

流量起伏多年，只有朋友圈IP日更一直在持续。

日更是个体力活。我很早就想让AI帮忙。第一次尝试，让AI写得口语、真实、无AI味。结果出来排比满篇，每段金句收尾，整齐得像广播体操。

当时只求先发出去，别人只知道我在更，内容本身毫无价值。

等于公开宣告：这是机器写的，朝暮本人下班了。

后来想明白，号要真做起来，这一关绕不开。

于是开始磨提示词。

初期版本2.0，一页纸：5个标题公式、3个内容池、正文三步走。

迭代到5月3.2.3版，17章1.6万字。标题公式扩到8个，情绪节奏成独立系统，4种骨架配10种风味，发布检查清单20条，还有脱敏对照表。

再到7.2，朝暮日更全量上下文系统。

但问题来了：提示词越长越难维护。1万多字改一处牵动全局，换个模型指令不全认，上下文过长前面规则被吃掉。

提示词的极限在于它活在一次对话里，对话结束就遗忘。

于是我转向Skill。

Skill本质是提示词，区别在存储和执行方式。

提示词：每次新对话要手动粘贴，太长贴不完，也不一定全记住。

Skill：存在.md文件里，AI Agent每次自行读取，按流程执行。你不用记顺序，启动即跑。

关键区别：提示词存在于对话，Skill存在于文件系统。

提示词每次要重贴。Skill保存在本地，修改后下次运行自动读取最新版。配置、案例、禁用词表、人格内核、任务产物都可存在指定目录，由总控按阶段读取，无需整包投喂。

类比：提示词像菜谱，每次做菜要翻书买菜切菜。Skill像一条装好的产线，原料投入自动产出成品。

从提示词到Skill，是从手工作坊升级为工厂。

初期我教的是提示词，因为很多人连Skill是什么都不懂。但提示词天花板很快触到，Skill才是长期解法。

今天工厂主体由一条主产线、5个专业工位构成。总控负责启动自检调度，七罪标题系统负责标题，5个引擎各管一段工作：

| 角色 | 负责内容 | 主要产出 |
|---|---|---|
| 总控 | 检查配置环境任务状态，分阶段调度Skill，记录路径确认点风险 | 启动自检、任务状态 |
| 淘金引擎 | 归档原始材料，拆出事实、判断、金句、案例、证据位置 | 原始材料、素材包 |
| 布局引擎 | 拆篇、查重、追问缺口，安排栏目顺序与对标任务 | 拆篇计划、对标拆解 |
| 铸文引擎 | 读取计划原料人格内核对标，生成初稿，不自检 | 初稿 |
| 七罪标题系统 | 生成标题候选，校验正文能否兑现，用户确认终版 | 标题候选、标题确认 |
| 鉴文引擎 | 由未参与写稿的独立上下文做8层鉴文，给出证据和修改建议 | 鉴文报告、修正稿 |
| 淬文引擎 | 完成32项发布终审，核对事实、隐私、平台边界、格式与风险 | 淬文报告、发布稿 |

中文阅读包里是5个中文引擎，方便理解；机器安装包里有7个可调用Skill，因总控和进化系统需单独识别。只是同一套逻辑的两种包装，不要求放在Obsidian。

为何要拆？因为同一个AI不能既是运动员又是裁判。

测试后发现：让写稿的上下文立刻自检，容易漏问题，还会为自己的表达找理由。必须由未参与铸文的独立上下文做鉴文，生产与质检才真正分离。

这就是工厂逻辑：各工位各司其职，质检与生产必须分开。

前后迭代400多次。搭完仍觉得文章不像我写。几十条“不要这样不要那样”的指令也无济于事。

真正开窍的一刻是：问题不在指令，在AI根本不够认识我。

从那天起，重心从“怎么命令AI”转向“怎么让AI深度认识我”。

之后的人格档案、鉴文引擎、七罪引擎，都是从这个逻辑长出，分别解决工厂里的一个问题。

今年5月线下验证，14人一节课跑通流程，当场有人产出首篇初稿。流程可行。

这就是整篇帖子的来历。

# 三、你的AI文为什么一眼假

几个扎心事实。

大部分人让AI写就一句话：“帮我写篇副业干货，不要AI味”。结果开头“在这个快节奏时代”，中间排比三连，结尾“愿你我成为更好的自己”。

发出去没人看，平台还判定低原创限流。

市面会给你三条路：提示词包、买贵模型、一键降AI率工具。

我全试过，都是止痛药。提示词包还是那个味，贵模型废话更流畅，降AI率工具检测过了人读不下去。

核心不在提示词。

AI让写内容变便宜，几分钟一篇。但写得越多，能用的越少。生产成本接近零，判断什么值得写、什么像你，成本却越来越高。

问题是四重错配。

第一，方向错配。让AI写爆款，却没说写给谁、解决什么问题。无靶心生产，子弹越多越乱。

第二，原料错配。只给选题和提示词。真正决定质量的是你的真实经历、踩过的坑、对标爆文。一篇文章质量，对标素材占60%，任务描述30%，提示词技巧仅10%。你把精力全砸在10%上。

第三，角色错配。把判断立场故事全交给AI，自己只负责复制粘贴。正确分工：你出判断经历立场，AI出结构连接执行力。

第四，回路错配。流程是选题→丢AI→复制发布→结束。发布后的数据、评论、用户问题从未回流到下一轮创作。每次从零开始，AI永远不懂你。

一篇文章发完就死，它是消耗品。经历、判断、用户反馈喂进下一篇，它才成资产。

大部分人用AI写作，生产了内容，没攒下资产。

四重错配背后是同一个问题：

## AI不认识你

它不知道你是谁，踩过什么坑，说话什么腔调。让一个认识你三秒的陌生人替你说话，只能得到全人类平均值。

全人类平均值就是AI味。

简单检验：把作者名盖住，同行能否直接拿去发？能，就不是IP内容，是公共内容。

AI不认识你，一半是你没喂，另一半是你自己也未必讲清自己。你让AI写真实一点，你的真实长什么样你说得出来吗？口头禅是什么？判断与他人差异在哪？说不出来，AI只能放大你的模糊。

模型是公共的，Claude、豆包人人可用，差距拉不开。真正私有的是你喂进去的东西：经历与判断，抄不走。

正确顺序是倒过来的：先让AI认识你，再让它认识市场，最后才写。

这就是内容工厂的底层逻辑。接下来按顺序教你搭建。

但动手前，先定一个事。

# 四、搭工厂第零步：先选入口，你喂它什么

工厂是通用的，唯一不同是入口。

两个入口，对应两条路：

入口A：你的素材→IP打法

日常遇到事、冒出想法、聊到有趣观点，对着手机说一遍转成文字，就是素材。

系统按你的人格档案、节奏、语气、判断生成像你说出来的文章。

IP逻辑：垂直到最小人群，先服务小圈层再外扩。

选IP路线，前于写什么更关键：你的交付产品是什么？

很多人写不好不是文笔，是没想清交付什么。是做信任还是带货？不定下来，内容东一篇西一篇，读者看不出你是做什么的。

产品是根，内容从根长出。没有产品，先做你这个人，这个阶段你就是产品。

我以自己为样本。朋友圈写了三年，前期没效果、没变化。阅读低迷，没人找我，看似无用功。

但慢慢长出信任。现在合作、资源、项目介绍，只要认识我加微信，翻到日更记录，基础信任就建立—这人靠谱不会跑路。

“朝暮日更”标签已绑定我，一提到坚持靠谱就想到我。朋友圈阵地管信任，人从别处来，信任从日更来。

反直觉点：起步时内容不必多好，只需让所有人知道三件事—这人坚持、靠谱、一直在做这件事。

信任不是靠一篇惊艳文章，是靠一千多天“朝暮今天又发了”堆出来。

垂直号逻辑相同：一厘米宽，一万米深。一直写下去，用户在微信搜你领域问题，弹出的全是你，该赛道位置就是你的。

IP变现公式：信任+需求=购买。

入口B：爆款对标→流量号

流量号入口不是你的素材，是别人已验证的爆款。

找准对标，把人家爆文的状态、情绪、反差搬进你的文章，流量文皆有公式。

做泛流量吃流量主收益，不要过度垂直，垂直池子变小。

核心链路是点击、完读、点广告，用户点开广告收益是没点开的10倍以上。

追热点拼速度，要多账号测试。要吃流量就纯吃流量，别想着顺便做积累。又想流量又想IP又想粉丝，最后三头抓不住。

多账号还有一个我用真金白银换来的意义：保命。号只有一个，出事就归零。

做流量主，要做渣男，脚踏多条船，号挂一个其他还能用，不影响心态。
