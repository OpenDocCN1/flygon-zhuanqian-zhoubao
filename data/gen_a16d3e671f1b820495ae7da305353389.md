很多人问我，一个刚毕业的大学生，凭什么能在小红书上半个月做到15万？今天我不卖关子，直接把整套流程从0到1拆给你看。你能耐心看完，并且照做，我不敢保证你能赚多少钱，但至少比你现在盲目摸索强一百倍。

先交代一下背景吧。我是00年的，去年刚大学毕业，但大学期间基本没闲着。大二就开始折腾，从票务平台干起，当时靠卖电影票、景区门票，在泰安本地做得算头部。一张电影票美团卖35，我这边30两张，进价才10块，你算算利润空间有多大。后来因为口罩封校，又开始做应用注册量，京东、滴滴、中国银行的校园拉新我都接过，京东一个学生认证我拿货价18，滴滴下载9块，中行29。带着十几个学院的负责人，外加兄弟院校的代理，整个大一新生基本都被我撸了一遍。

再后来大三休学去北京，做线上志愿者活动。因为封校，学生线下做不了志愿者，加不了综测分，我们就联合各种中字头协会搞线上活动。其中一个大熊猫保护活动，报名人数直接干到120万，这还只是其中一个项目。变现方式也很简单，证书电子版免费，纸质版收费，外加纪念奖牌。

说到这儿，懂行的可能已经猜到了，我的核心打法是：把抖音直播内容录制下来，搬到小红书做无人直播带货。如果你做过视频号无人直播，这篇可以直接划走了，因为接下来我要从最基础的注册账号开始讲，是给纯小白看的。

先给你们看个数据，我现在同时起10个号，能跑通8个。这是某一天其中一个号的数据，去掉退货，净利润大概在40%左右。说实话，比上班香太多了。


## 第一步：先搞懂账号怎么养

别急着赚钱，越是着急越容易翻车。按照步骤来，不可能一口吃个胖子。

**最重要的一条：一机一卡一号。** 就是一个手机，只下载一个小红书，只登录一个账号，一个手机号。不要来回切换账号，我8月份的时候五个号同时被封，就是因为来回切换。别跟我说你有黑科技可以多开，我也会，但请按我说的来，这是吃过亏换来的教训。

账号数量多了以后，可以去转转、闲鱼、找靓机这些平台买二手手机。不用买太好的，700块左右的苹果X就行，苹果系统至少流畅，安卓机暂时不推荐。或者500块的苹果8P也行。我现在手里十个手机，全是苹果的。去线下通讯城买也行，跟老板说是工作室用的工作机，他会给你推荐便宜的。**切记：没有摄像头、没有人脸识别的不要买**，因为后面要扫脸实名。

注册的时候，年龄选30岁，性别选女性。ID名称想好后，先在小红书搜一下，看看有没有重名的。这个很重要，重名的话申请店铺过不了审。为了一次通过，选一个独一无二的名字，用户搜你也好找。

注册完先别急着实名。先刷小红书，找你对标的账号，刷到喜欢的就点赞、收藏、评论、转发。很多人只告诉你要这么做，但没告诉你为什么。因为小红书有等级体系，在编辑资料最下面能看到。刚开始是“尿布薯”，升等级需要满足四个要求，就是上面说的那四个动作。

想快速启动账号，有个狠招：发一篇图文笔记，内容就写“30岁了，快劝我不要生二胎”，用醒图做张白底图，把字打上去，选好看的字体和排版，控制好行间距。发布的时候带上话题，比如“该不该要二胎”“生孩子”这类的。发完之后，至少有一千个女性用户给你评论，点赞、涨粉、浏览量全都有了，账号就激活了。女性粉丝群体的购买力非常强，试过的人才知道这招有多猛。

笔记发出后，浏览量（也就是小眼睛）突破1000，正常爆文在5000左右，就可以实名了。一个人只能实名一个账号，想多开的话，找朋友、同学、爸妈帮忙实名就行。


## 第二步：开店到底选哪种

实名完了就能开店。小红书店铺分四种：**个人店、个体店、专业号、企业号**。

- **个人店**：一张身份证就能注册
- **个体店**：需要个体工商户营业执照
- **专业号**：有个体户执照前提下，交600块，可以开通三个子账号，子账号能卖主账号的商品
- **企业号**：需要交2万保证金

新手小白，建议先从个人号开始。开店之前，先按照平台提示做一次申诉，结果正常之后再开。


## 第三步：个人店申请流程

打开小红书 → 点“我” → 右上角三条杠 → 创作中心 → 更多服务 → 开通店铺 → 立即开店 → 选择个人店 → 选电商商品，类目根据你想做的品类选（注意：百货类里的家用清洁品，驱蚊、除螨抑菌这类需要资质，先剔除）→ 填完身份证信息提交就行。

一个实名只能开一家个人店。

## 第六步：个体户店铺绑定分销号

个体户店铺先升级成蓝V号（也就是企业号），然后去专业号中心 → 更多功能 → 账号关联 → 主理人账号关联 → 邀请 → 输入已经开通个人专业号账号的小红书号，邀请并同意就可以了。


## 第七步：店铺通过了，怎么选品

个人店审核基本当天就能过，最迟第二天。

开通后先找商品。我一般做服装类目，目前小红书无人直播最好做的也是服装，最容易拿到结果。

找品的话，去1688、抖音、拼多多找商家聊。话术上，把自己的单量说得大一点，比如每天能稳定出一百到三百单，加上微信聊价格、聊售后。**售后一定要让他们负责**，通过店管家这类工具代发，提前把售后规则说清楚。问他们有没有店管家或者聚水潭，要发货地址和退货地址。


## 第八步：地址和物流设置

新建地址的时候要特别注意，系统有默认地址。发货地址目前对无货源管得松，可以写自己的，但为了安全起见，建议写商家地址。退货地址选择“多地址退货”按钮，把商品放上去，再把自己的地址放上去就行。

## 第十步：上架工具之妙手

多介绍几个插件是因为目前插件不稳定，这个不行就换另一个，总有一个能用。

小红书店铺端必须开通店铺后才能登录。在店铺主页下面有个“服务”，点进去到服务市场，找到“妙手商品上架”。点获取 → 商品上货 → 设置商品。上架设置里，商品类目选手动设置，品牌设置为空，如果必须选就选默认第一个，货号留空。价格设置，我一般设置乘以200%，也就是挣一半利润。市场价格必须设置，因为市场价要高于售卖价才能上架。运费模板选非偏远地区包邮。**是否预售这个要注意，不能选预售**，选非预售，然后选48小时发货。保存后就能上架了。


## 第十一步：怎么找同款商品链接

在小红书找低分爆款 → 截图 → 打开拼多多 → 右上角识图 → 选刚截的图 → 挑一个价格合适的，复制链接粘贴到商品软件。

1688的话，右上角有转发按钮，直接复制链接即可。要注意找源头厂家，别找二道贩子。认准牛头标志，有牛头的基本是源头厂家。

拼多多操作演示：打开拼多多 → 左上角拍照图标 → 点你截图的商品 → 就能找到同款 → 选销量好、评价多的 → 复制链接。

1688操作演示：打开1688 → 右上角放大镜片 → 一键识图 → 找对应商品。淘宝和抖音操作逻辑类似，不细说了。


## 第十二步：上架审核不通过怎么办

按步骤排查，处理完再提交。

打开小红书千帆 → 点击商品 → 找到问题商品 → 点编辑 → 看系统提示。最常见的问题是类目不正确，有些类目你没有权限，需要在店铺设置里找到“类目申请”，提前多申请一些，因为审核周期要2-3个工作日。我就吃过亏，找到一个品才申请一个类目，非常浪费时间。其次，图文里不能出现淘宝、抖音、1688、拼多多的字样。还有，图片不能有白边。按提示处理完，提交商品，等审核通过就行。
