# 双十一临时起意做场生日促销，7天卖到10万+，超预期近50%，我把复盘拆成几件事跟你说

> 原文：[`www.yuque.com/for_lazy/thfiu8/fieenruk2masaxmz`](https://www.yuque.com/for_lazy/thfiu8/fieenruk2masaxmz)

## 知识付费 IP 双十一7天营收破10w，超预期49.6%，关于做促销我有5个关键认知

作者： 叶叶 _ 优势教练
日期：2023-11-24

大家好，我是盖洛普优势教练叶叶在觉。做 IP 到现在第四年了，我一直不擅长搞转化，日常基本不做活动。没想到今年赶上农历生日撞双十一，临时起意搞了一场生日充值活动，结果营收直接超预期49.6%。

更重要的是，这次把 IP 的客单价拉升了，也给老用户多了一个持续链接我的理由。

如果你也在为提升客单价、打破营收天花板、让用户心智里牢牢记住你而发愁，这份复盘或许能给你一些参考。

* * *

# 一、这次活动是怎么来的

说实话原本没计划碰双十一。10号那天我才发现生日和双十一同一天，脑子里灵光一闪就决定做一场生日特辑，然后把策划丢给了团队里的同事 zz。

她临危受命，给了我一个方案：充值3000送500。

乍听起来很常见，甚至有种割韭菜的味道。我第一反应是拒绝。因为认可我的老用户基本都买过全家桶了，让他们再充钱买什么？我现金流也不缺，IP 势能摆在那，十来万的体量也收不了太多，顶多几万块，对我生活没质变，意义在哪？

她用一句话把我点醒了：**这可以用来筛选铁粉。** 她还顺势建议我把线下闭门会提上日程，正好是我明年想做的方向。

我们简单对齐后，我直接发了朋友圈，说这是场意义非凡的会议。事实证明没说错。方案是10号晚上才敲定，零预热，第二天就开始一对一私信老客户和意向客户。

# 二、这场活动带给我的体会

## 1、你跟谁一起干活，直接决定你和团队的进化速度

跟厉害的人搭档真的爽，1+1 真的能大于2。

之前用的人大多是听我给思路再去执行。这位销售同事不一样，她敢跳出我的框架去想。可能跟她盖洛普优势里“战略”排第一有关系。她之前剪过直播切片、找过对标账号，我觉得都还好，但做活动方案时想法就很开。

**如果不是她抛出这个充值方案，我的 IP 可能还卡在优势教练的定位里，铁粉圈也不会这么快成型，也不会这么早满足用户除了学优势之外的其他连接需求。**

有了铁粉圈后，产品体系才算完整了，千元、五千、一万、三万四个价位都有了。

以前我觉得打造铁粉圈遥远，也觉得市面上的私董会太多。但这次让我想通两件事：

**第一，再多的私董会也不妨碍我做自己的铁粉圈，因为我的特质和别人不一样。**

**第二，铁粉的深度链接不是靠送礼物、嘘寒问暖，而是你能不能持续带他们成长、升级思维。**

## 2、我原来是有合作能力的，只是没意识到

我一直觉得自己团队协作意识弱，成长路上基本都是单打独斗，很少有跟别人配合完成一件事情并沉浸其中的体验。

我大学就喜欢混圈子，但总觉得自己不属于任何一个核心圈子。

**做完这次双十一，我才确认，我其实会合作，而且我最享受的友谊是跟优秀的人一起冲锋拿结果。配合得好，感情会特别深。**

**我喜欢的是互相成就的关系，而非吃喝玩乐式的关系。**

## 3、IP 必须不断造势，提前放出未来产品做预售

很多事你不试，根本不知道有多少人在默默看好你。

我严重低估了自己的影响力，也低估了铁粉想深度链接、一起变好的渴望。

**所以做 IP 不能只守着现有产品，还要基于未来的预期去试水用户的付费意愿，不断抬高身价和客单。**

如果你做的是非刚需赚钱赛道，用户生命周期就会很短。用户从你这里解决了某个问题，工作人际步入正轨后，注意力就会流失。所以必须不断推出新产品，满足更立体的需求，才能维持长期关系。

## 4、当别人冲着链接你来付费，交付就退居其次，IP 才算真正成型

这次的铁粉产品，更偏重连接而非交付。

优势圈、天赋营、教练课，都是我教别人东西，收钱合理。

但这次17个人愿意在没有明确交付清单的情况下支持我，而且从第11个开始，每多一个人门槛就涨500。

有个铁粉没及时看到消息，先转了3000，等他回复时已经涨到4500，我本来担心他会犹豫，结果他立刻补了1500。

大家的果断说明我的 IP 比自己想象的更值钱。

**当你有商业能力和人格魅力，吸引来的都是优质高付费用户，这本身就是一道壁垒，因为你能整合圈子资源做互换。**

**客户付费的就不只是你个人的技术，而是你背后的圈子资源，这就大大降低了你一人交付的成本。**

**圈子里的信息差和资源互换，本身就是一种交付。**

生财的航海家俱乐部就是典型，亦仁不承诺交付，很多人依然留下，就是为了靠近亦仁本人和俱乐部动态。

## 5、IP 的外在势能和内在势能是互相喂养的

很多做 IP 的人都内耗，觉得自己没别人有影响力。我之前也羡慕别人一呼百应。这次活动前我也没底，不知道没产品介绍的情况下能有多少人信任我，所以只定了5个铁粉的小目标。

定向私信发出去后，不少人直接打款，还有人说“不用考虑，我知道值”。没上车的人也给了很多肯定，有人夸我“你是我心中的一道彩虹🌈”，瞬间把我的内在势能点燃了，对自己产品带给人的价值更有底气了。

**以前我总觉得优势教练课要拼价格，现在我更清楚，我带给学员的不仅是变现的知识，更是我自己的生命状态和能量。**

相信自己能做到，就会去追更远的目标，做更大的里程碑，修炼中自带磁场，就能吸引更多贵人和铁粉。

**人气聚齐了，财气自然会跟上，外在势能就会越来越强。**

## 6、钱少事多的客户不一定要一刀切

IP 做上去后容易被惯坏，习惯了客户上来就付款，就对预算少、问题多的客户没耐心。

**但其实钱少事多的客户，很有可能是你最忠实的铁粉。**

最后一个上车的铁粉，刚开始说分期再考虑，看了链接也没拍。第二天他又问我明年规划和产品矩阵，想知道充值后能在哪消费。他那时已经有16个人充值了，远超我的目标，我第一反应是没必要再说服他了，铁粉应该是不用劝、付款无压力的人。

但我还是认真回复了明年规划。隔天他一次性充了5000全款。后续他看复盘也非常认真，还给了反馈：

这件事告诉我，**对那些预算有限但真心想付费、渴望变好的用户，一定要耐心回答问题。**

谁没穷过呢？我当年也是从一穷二白的农村大学生起步，攒下第一桶金，赚钱能力才慢慢变强。**要给那些暂时手头紧的潜力股一个机会。**

当然，如果客户只关心跑路保障、权益补偿，那还是劝退更合适。

# 三、这次做得不好，下次会怎么改

活动能照出团队的真实状态，我总结了几个坑：

**1、优先级没排好。** 活动期间我应该先把所有意向铁粉私信触达完，再去写公众号日更。很多意向铁粉的私信是到最后一天晚上十点多才发，转化率本可以更高。这也说明要常备一份铁粉和潜在铁粉名单，做活动时心里才有底。以前搞过但不完整，这次提醒我必须精细化运营。

**2、时间太晚且没预热，导致很多人没预算。** 下次我打算618就先做一场。

**3、涨价门槛设置保守。** 15个人每人涨500元，可能太少了。如果设为200元一人涨价，或许能让更多人上车。这跟第一个问题相关，心里没个数就不敢设高。

**4、下单后对接流程没标准化。** 因为临时起意，方案确定后就开干，下单后的文案、触达名单、物料、倒计时话术、人员分工都没准备好。

**5、数据统计要专人实时跟进。**

**6、别为了冲业绩拉低信任度的人，不轻易承诺终身制，后续交付会很耗神。**
