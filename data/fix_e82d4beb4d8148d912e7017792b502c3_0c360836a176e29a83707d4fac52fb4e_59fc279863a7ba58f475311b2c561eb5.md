.env 配置文件禁止被浏览器直接读取，访问 https://域名/.env 必须得到 403。

11.4 宝塔计划任务的设定思路
上线后在宝塔计划任务里建立三项：
Laravel 调度器，每分钟触发一次，命令写法向 Codex 询问“Laravel schedule:run 的 crontab 表达方式”。
数据库备份，每天凌晨 3 点运行，沿用第六步已配置好的宝塔自带策略。
清理日志，每周运行一次，命令向 Codex 询问“删除 30 天以前日志的具体写法”。

11.5 文件权限的常见坑
如果 AI 提示权限异常，需要明确告知 Codex 当前环境是宝塔，PHP 以 www 账号运行，storage 与 bootstrap/cache 设为 775，其余目录 755、文件 644，严禁使用 777。

第十四步 AI 出错时的处理方法
AI 可能会说已完成但实际未完成，原则是不要相信口头汇报，必须自行验证。

14.1 AI 声称完成但未成功
“环境配好了”要验证健康检查是否通，浏览器打开 /api/health 能否返回 200。
“数据库建好了”要让 AI 运行 migrate:status 并截图。
“部署完成了”要线上访问 https://域名/api/health。
“SSL 配好了”要在地址栏看到绿色锁标。
“备份配好了”要在宝塔计划任务里能看到对应任务。
“权限对了”要确认是 775 而非 777，可问 AI 当前权限值。

14.2 502 Bad Gateway 排查顺序
PHP 未正常工作，按顺序核查：
问 Codex “PHP-FPM 是否运行，如何检查”。
宝塔 → 软件商店 → PHP 8.2 显示运行中。
宝塔 → 网站 → 设置 → PHP 版本是否选为 8.2。
问 Codex “storage 与 bootstrap/cache 权限是否正确”。
问 Codex “查看 Laravel 最新日志，报错最后几行是什么”。

14.3 数据库连接失败
核对 .env 中数据库配置是否正确。
宝塔 → 数据库确认 miniapp_todo 库是否存在。
宝塔 → 数据库确认 miniapp_user 用户权限是否足够。
让 Codex 运行 config:clear 清缓存。
确认 .env 中 DB_HOST 为 127.0.0.1 而非 localhost。

14.4 小程序登录返回 400
检查微信公众平台 → 开发设置 → AppID 是否一致。
核对 .env 中 WECHAT_APP_ID 与 WECHAT_APP_SECRET。
问 Codex 是否需要刷新 config:cache。
在小程序模拟器 Console 查看 wx.login 是否拿到 code。

14.5 COS 上传失败
腾讯云 COS 控制台确认 Bucket 存在。
腾讯云 CAM 确认子账号具备 COS 权限。
核对 .env 中 COS 配置与 Region 是否正确。
执行 config:clear 清除缓存。

14.6 小程序真机预览白屏
开发者工具 Console 查看红色报错。
开发者工具 Network 查看接口状态。
微信公众平台 → 开发设置 → 服务器域名是否填写正式域名。
开发者工具 → 详情 → 本地设置中“不校验合法域名”不要关闭。

14.7 小程序审核被拒
查看审核驳回邮件原因。
常见原因是隐私保护指引与实际功能不符。
微信公众平台 → 开发管理 → 隐私保护指引勾选实际使用权限。
使用 wx.login 需勾选“获取你的 openid”。
使用 wx.chooseMedia 或 chooseAvatar 需勾选“选择图片或视频”。
使用 input type="nickname" 需勾选“获取你的昵称”。

附录 B 轻量应用服务器与 CVM 对比
价格上轻量便宜 30%+，CVM 较贵。
带宽轻量为固定带宽加流量包，CVM 按带宽或流量计费。
宝塔方面轻量提供官方镜像一键安装，CVM 需手动安装。
安全组轻量自带简易防火墙，CVM 支持完整安全组。
弹性方面轻量不支持升降配，CVM 支持灵活升降配。
快照轻量手动快照，CVM 支持自动快照策略。
适合新手与个人项目，团队生产环境选 CVM。
本教程选择轻量，流量上来后再迁移。
