# 从 0 到 1：我用 Claude Code 搭了一套公众号自动化流程（附完整提示词）

大家好，我是周行。

刚结束生财的垂直小号内测航海，过程中发现了一个特别磨人的痛点：用 AI 写公众号，真的很难两全。

用 ChatGPT、Gemini、豆包这类对话式大模型，一次只能吐一篇，量一大内容就开始“撞脸”；换成飞书+DeepSeek 或者 coze 之类的组合，确实能批量产出不少稿子，但质量就飘忽不定了，经常需要大改。

所以我花了几天时间，用 Claude Code 搭了一个工作流，把公众号从选题、写作到排版的整套流程都给自动化了。整个流程可以根据你做的领域和具体需求灵活调整，不是什么死板模板。

这篇文章篇幅不短，主要适合下面这几类朋友：

1. 手上有好几个公众号在运营，想靠 AI 自动化产出，拿到内容稍微过一眼就能直接发；
2. 时间精力有限，想坚持写公众号，但又真心不想发一堆一眼假的“水文”；
3. 想了解 Claude Code 在内容创作上的基本玩法和思路。
