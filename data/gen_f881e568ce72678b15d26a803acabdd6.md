# 开始建扣子工作流

先说清楚，这个工作流要解决什么？

把原本的：

*   看到目标视频 -
*   复制链接 -
*   打开小程序 -
*   粘贴链接 -
*   等待识别 -
*   复制文案 -
*   打开网页 -
*   打开飞书 -
*   新建文档 -
*   粘贴内容

10 步操作，压缩成 1 步：

看到视频，直接转发给飞书机器人。

这就是工作流的本质：

用 5 分钟的搭建，换来之后每次 30 秒的效率。

## 配置参数

确认一下全流程的输入输出：

*   上一个节点的输出 = 下一个节点的输入
*   下一个节点的输入也可以引用更前面的节点输出

开始节点保持默认即可。

### 配置视频文案提取节点

【视频文案提取节点】：提取视频文案并输出

[PRE17]

需要填两个输入：

*   ali_bailian_api_key
*   douyin_url

意思很直观：

ali_bailian_api_key 是阿里百炼的 API 密钥，去阿里百炼平台免费注册登录即可。

[PRE18]

有 100 万 Token 免费额度，获取方式篇幅有限，可用元宝、豆包、千问、秘塔搜索：

[PRE19]

第二个参数 douyin_url，

不是每次把链接手动填进去，我们点输入框后的⚙️，选择开始节点的 input 即可。

# 逻辑比工具更重要

第一个工作流跑通后，你就掌握了 AI 自动化的核心：

从开始到结束，由不同功能节点串联组合。

搞懂这个，再复杂的工作流也不怕。

别嫌它简单，我后来的「Claude 文案导入飞书自动写入公众号」工作流，就是从这 4 个节点长出来的，现在部分自动化：

[PRE34]

这几天它已经帮我自动写入了 20 多篇文章，其中一篇 1w+，收入快 100 了。

[PRE35]

现在还不是全自动，Claude 生成后需要我手动导入飞书，自动化我还在研究。

不管多复杂，本质上就是：多加几个节点，多连几条线。
