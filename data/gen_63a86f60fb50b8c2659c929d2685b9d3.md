# 嫌翻帖太累？他做了个“风向标”推送机器人，每天自动把干货送到你微信

上个月，生财航海里冒出一位叫小五的新人，他参加的是“ChatGPT + 海外工具站”这条航线。一趟下来，他感慨自己最大的收获不是做完某个项目，而是被教练和同行们的高质量分享彻底打开了视野——原来海外市场还有这么多玩法。21天的旅程虽然结束了，但他对海外站的探索，才刚刚起了个头。

航海期间，他花了大约两天时间，捣鼓出一个能实时推送消息的群机器人。这个机器人干的事很简单：把知识星球里每天更新的“风向标”帖子，自动转发到自己的企业微信里。

问起为什么做这个，小五的回答很实在：白天上班根本没空刷，晚上回家翻历史记录，总有种“错过一个亿”的焦虑。说白了就是懒，但懒人多了，工具才有进步的动力嘛。

聊到实现思路，他也没藏着掖着，大致分了五点：

1. 知识星球的 API 比想象中好搞，只要带上 cookie，就能轻松拉到自己加入星球的动态数据。
2. 一开始想走微信公众号推送，结果发现只有订阅号支持，还得过企业认证，门槛劝退。转头一看，企业微信机器人现成又好用，就它了。
3. 第一版先解决定时推送，后面打算加上分类筛选、关键词订阅，再往后可能引入 GPT 做内容总结。
4. 选型上用了 Go 语言，因为编译产物能同时跑在 Windows 和 Linux 上，跨平台没烦恼。
5. 写代码过程中，ChatGPT 帮他搞定了几个又烦又无聊的格式转换需求，这波 AI 辅助开发，真香。

这个工具适合谁？小五列了几个场景：

- 每天生怕漏掉风向标更新的圈友，拿去用；
- 本来就用企业微信上班的朋友，这简直就是摸鱼神器；
- 要是你还有别的玩法，也欢迎自己挖掘。

当然，工具也有短板：部署起来不是零门槛，至少得懂一点 shell 命令，才能让它跑起来。
