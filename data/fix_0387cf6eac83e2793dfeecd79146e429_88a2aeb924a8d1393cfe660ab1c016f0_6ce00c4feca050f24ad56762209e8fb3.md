# 二、钱从哪里来

用户在你的 Agent 里保存了你放的网盘链接，你就能拿到佣金。不需要盯盘，纯被动收入。

现在的结算标准：
- 移动端拉新：8元/人
- PC端拉新：3元/人
- 移动端转存一次：0.45元
- 新会员充值分成：20%
- 老会员充值分成：10%

注意：PC端保存、微信小程序里保存的链接，都没有转存收益。[PRE13]

# 三、搜索流量从哪里进

入口一共三个：Agent 名称、Agent 简介、你上传表格里的关键词。[PRE14] [PRE15] [PRE16] [PRE17]

整理表格时，只用第二个模板，示例和黄色注释先全部删掉。之后 Agent 会根据用户搜索词自动发对应的链接。如果遇到敏感词，表格里写真实文件昵称，网盘里的文件昵称则改成缩写、代号之类的。[PRE18]

# 五、发什么能赚钱

最省事的思路：去闲鱼、拼多多、淘宝、小红书，找卖虚拟资料的商家，进主页照单全收。对方卖什么，你就能发什么。大类基本就是：资料、影视、游戏、课程、工具、素材、音乐、热点。懒得想词，也可以直接问 AI。[PRE19]

我平时扫货会看这些方向：
- 学习考试：各类软件、技能、职业考试课程和复习包；
- 办公文档：各种能直接用的标准表格、合同、方案模板；

想挖更细的长尾词，可以从这些方向展开：学习/考试、办公/文档、设计/创意、AI/编程、营销/运营、财经/理财、个人成长、生活兴趣、娱乐内容、蓝海创新。系统化的词库，可以去5118拉：[5118项目入口](http://www.5118.com/xm/startup)[PRE21] [PRE22]

# 六、搭建全流程

## 1. 注册账号

打开[百度智能体平台](http://agents.baidu.com/)注册登录。[PRE23] [PRE24] [PRE25] 有弹窗直接跳过。[PRE26]

## 2. 基础参数设置

**名称**：把赛道关键词放进去，但别写“资源”两个字，防风险。

**简介**：建议抄同行，关键词尽量多堆。

**设定（角色逻辑）**：
方法一：用现成模板，打开复制：[PRE27]
方法二：抄同行。[PRE28] [PRE29] 把同行的角色逻辑复制下来，[PRE30] 丢给豆包或其他AI工具，让它按这段逻辑改写成“分享XX资源”的角色设定，[PRE31] 再把结果贴回来，点“AI优化”，[PRE32] [PRE33] 然后点“使用”。[PRE34] 注意：等之前的黄色提示消失，功能才正常。[PRE35] [PRE36]

另外，设定里要强制加一句：所有回答都从知识库调取。如果一直不成功、界面报错[PRE37]，就重新新建一个 Agent；或者先不加知识库，发布过审后再补。

**开场白**：模仿同行写。开场白问题写3个，直接填本地资源库表格里的关键词，内容不要带“网盘”两个字。比如你做旅游攻略，本地关键词是“云南旅游攻略、丽江旅游攻略、大理旅游攻略”，就把这三个填成开场白问题，引导用户按这种模式提问。[PRE38]

**自动追问**：开不开都行。[PRE39]
**快捷指令**：忽略。
**联网搜索**：关掉。[PRE40]

## 3. 知识库（网盘链接调用）

[PRE41]
上传你做好的表格。第一列表头命名为“xx资源名称”，第二列命名为“XX资源链接”。第一列写用户会搜的关键词，第二列直接放合集链接即可，不用一个资源单独分享。当然，不怕麻烦也可以拆开。参考旅游攻略的例子：[PRE42]

最新提醒：表格标题里别出现“网盘”两个字。[PRE43]
不想自己整理资源，就上闲鱼、淘宝、拼多多买一份，让卖家发百度网盘，转存后再上传。

插件、工作流、数据库：全部忽略。长期记忆：开或关都行。[PRE44]
声音、背景、线索转化、商品挂载、链接挂载：也全部忽略。[PRE45]

## 4. 测试

所有配置完成后，点右侧测试窗口，随便问一个问题，看 Agent 会不会回复知识库里的网盘链接。能回复就说明配置没问题。也可以发布后再测，偶尔会有 bug。[PRE46]

## 5. 发布

测试没问题，点右上角“发布”。访问权限选公开访问，部署平台不用管，设置完点发布，等审核上线就行。[PRE47] [PRE48] [PRE49]

## 6. 发布后的排名影响因素

1. 使用次数和对话次数。[PRE50]
2. 选细分小众赛道，搜索流量基本全归你。
3. Agent 名字、简介、表格里的关键词能否被搜到。
4. 网盘里别放微信引流信息：轻则被屏蔽，重则整个链接被和谐。
5. 每天上去优化，按系统给的推荐方案走；顺便翻翻用户对话，把高频关键词补进知识库表格。
6. 后台做任务拿流量包和曝光，有机会上24小时热门，爆一次权重就起来了。
7. 后台站内信提示资源违规，直接删掉对应链接即可。
