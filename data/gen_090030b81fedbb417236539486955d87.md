做公众号一年多，文章可以让 AI 代笔，封面却一直让我头疼。每次发文前，看着 AI 生图工具产出的“杰作”，总觉得不够精致。以前偷懒的时候，直接截一张文章里的图应付当封面，说实话，显得特别不专业。

更要命的是，公众号封面有横版方版两种规格：2.35:1 和 1:1。不同展示位置要用不同比例，硬拿一张图通用，怎么看都不舒服，相当于每次得准备两张封面。

我也折腾过不少工具。一开始用市面上的模板软件，结果要么付费，要么还得手动调文字、选风格。又懒又想白嫖的我，直接 pass。

转机出现在 Claude 3.7 发布后。看大佬们拿它生成知识卡片，我瞬间又对封面燃起了希望。既然 AI 这么能写代码，不如让 AI 自己把提示词写出来？

我用的工具是 Trae 国际版。坦白讲，它比 Cursor 笨，还得排队，但架不住免费。最香的是它能直接生成 HTML 文件，省去复制代码然后新建文件的麻烦，生成完直接打开文件夹就能用。

我先跟 Claude 3.7 说：根据我提供的文章内容，生成一份 HTML 海报，左边是 2.35:1 横版，右边是 1:1 方版。它很快吐出了初版提示词。

[PRE4]

拿着这版提示词去测，效果惨不忍睹，当场删了，就不放出来丢人了。

[PRE5]

接下来就是反复优化。我的套路是：哪里效果差就跟它直说，让它继续改。但有个细节特别重要——先把历史对话清空。因为 Trae 是好学生思维，会拼命召回上下文来“理解”你，可咱们这是在生成提示词，上下文太多反而会让它想太多、会错意。

所以每次优化前，我都新建一个对话，把之前的聊天记录删干净。

[PRE6]

第一版生成出来的问题：两个区域不在一行，大小比例也不对。我让它改成固定尺寸，并且把优化后的提示词另存为新文件，免得它改坏了，连初版都给我覆盖掉。

下面把我调好的提示词分享出来，这个版本是“固定尺寸 + 图片版”，左右两个区域同排展示，左侧 900×383，右侧 383×383，适配公众号封面。

```
你是一名公众号封面设计师，负责把用户内容变成精致的 HTML 封面。

页面分为两个区域：
- 左区：900×383 像素，横向排版
- 右区：383×383 像素，正方形，内容与左区一致，设计风格统一，仅版式随比例调整

布局必须：
- 两个区域用 flex 横排（display:flex; flex-direction:row）
- 父容器宽度至少 1283px
- flex-wrap:nowrap，禁止换行
- 右区高度与左区一致，同为 383px
- 左区宽 900px，右区宽 383px
- 两区域均设置 flex:0 0 auto，防止缩放

内容只保留：
- 主标题（视觉焦点，必须醒目）
- 副标题（简短补充）
- 图片元素（可选）
- 不放长段落，适合公众号封面

图片处理：
- 如果有图，把它当成视觉焦点之一
- 可以加 5~15 度旋转、阴影、边框
- 多图可层叠摆放
- 可用蒙版或渐变色融合
- 图片缩放要保证清晰与整体平衡
- 两区域中图片的展示方式可以有差别，但风格必须一致

设计规范：
- 只用 HTML 和 CSS，不写 JavaScript
- 样式要现代、专业，符合当下审美
- 字体、配色根据用户内容选择
- 输出完整的 .html 文件代码
- 左右两区域的颜色、字体、视觉元素完全统一，只是布局比例不同
- 不生成按钮、悬停效果等交互

技术实现：
- 请用固定像素值，不要用 aspect-ratio 或百分比 padding
- 不要使用媒体查询
- 父容器必须使用 display:flex 和 flex-direction:row
- 父容器必须设置 flex-wrap:nowrap
- 子元素必须用 flex:0 0 auto 和明确的 width 值
- 父容器 min-width 设为 1283px
- 如需小屏查看，允许 overflow-x:auto 水平滚动
- 图片旋转用 transform，阴影用 box-shadow，层叠用 z-index 和 position，特殊形状用 clip-path 或 border-radius

开始之前，先简要描述设计理念，再输出完整 HTML 代码。

用户会提供以下内容：
- 主标题（必需）
- 副标题（必需）
- 图片（可选，如果提供，请说明使用方式）
- 颜色或风格偏好（可选）
- 其他特殊需求（可选）

等用户把内容发给你，再开始设计。
```

如果你也想让封面支持一键保存，只需要在提示词末尾追加下面这段要求：

```
在封面下方加一个显眼的「保存图片」按钮，风格要跟整体协调。
点击按钮后，把左右两个区域合并成一张 PNG 图片下载。
用 html2canvas 库实现，记得在 HTML 里引入。
保存的图片要包含完整封面，不要包含按钮本身。
脚本放在 HTML 底部。
文件名中要带“Trae AI封面”字样。
合并时，把装有两个区域的父容器作为 html2canvas 的捕获目标；确保内容渲染完成再截图；可以用 Canvas API 拼接两块内容，画布尺寸要装得下全部。
```

有了这个，生成 HTML 后直接点按钮就能存图，连截图虚线都省了。

最后想说，这套玩法里，提示词本身不是关键，核心是“让 AI 自己写提示词”的思路。你只需要会描述问题、会提优化意见，AI 就能帮你把工具打磨得越来越顺手。如果有哪里没讲清楚，欢迎评论区留言，我尽力解答。
