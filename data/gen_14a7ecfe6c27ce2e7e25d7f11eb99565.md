# 二、Cursor 到底是什么

## 1、认识 Cursor

Cursor 是一个基于大模型的代码编辑器，本身就是一个集成开发环境。它的设计思路是让开发者在敲代码的同时，和 AI 实时对话，获得补全建议、错误检查和自动修复。

和市面上的常规工具不同，Cursor 把 AI 能力做进了编辑器的每一个环节。AI 不再是可有可无的插件，而是工作流的核心，这让编程更像是在和搭档沟通。

## 2、和 Copilot 相比的差异化

相较于 GitHub Copilot 这类助手，Cursor 的体验更立体：

### 1.模型可切换、可定制
支持多款大模型，用户还能根据自己的习惯微调 AI 的编程风格。最近接入 Claude Sonnet 3.5 之后，代码质量和一次成功率明显提升。

### 2.全仓库级别的智能联想
不止看当前文件，Cursor 会扫描整个项目库来给出建议，上下文更完整。

### 3.实时分析与自动修复
写着写着就能揪出错误并给出修复方案，准确率和开发节奏都大幅提升。

### 4.自然语言对话
可以直接用中文提问、改需求、重构代码，理解和优化体验很顺滑。

### 5.Tab 预测和多行协作
能预判你下一步想改哪，能一次对多行代码做批量修改注释、重排，改大块样式时很省事。

### 6.隐私与合规
提供隐私模式，已通过 SOC2 认证，可以选择不上传代码到服务器。

# 九、我的使用体会

把需求整理清楚丢给 Cursor，预览生成结果，不满意就针对局部继续追问改细节，完全可以通过中文指令把一个网站搭起来。不写一行代码也能完成前端开发。

我本身是程序员，后台有现成系统可以直接复用，所以这次只用 Cursor 处理前端。当然 Cursor 也能生成后台代码，只是环境配置会更重。拿来做官网、谷歌插件、微信小程序、简单 App 很合适。程序员用它能大幅提效，产品、设计、测试也能直接编程。
