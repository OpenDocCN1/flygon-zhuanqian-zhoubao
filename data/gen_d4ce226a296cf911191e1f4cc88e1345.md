# 部署 n8n 前要准备什么？

- 一台能上网的电脑

npm 默认的源是海外服务器，因为大家都懂的原因，速度特别慢，甚至直接失败。这种情况有两种解决办法。

**方法一：给命令行设置代理**

如果你是那种追求精致生活的人，可以试这个办法，但操作起来不太容易。

首先，你得找到你用魔法工具时用的代理端口。

啥？你不知道？那还是用方法二吧。

知道端口之后，在命令行输入这两条命令：

npm config set proxy http://127.0.0.1:7890

npm config set https-proxy http://127.0.0.1:7890

注意：这里的 7890 要换成你自己魔法工具的端口
注意：这里的 7890 要换成你自己魔法工具的端口
注意：这里的 7890 要换成你自己魔法工具的端口

如果你装好 n8n 之后想取消代理，可以用下面两条命令（这不是必须的，不影响安装）：

npm config delete proxy

npm config delete https-proxy

**方法二：用淘宝镜像**

直接无情地输入：

npm config set registry https://registry.npmmirror.com

这是用国内的镜像站，缺点是更新可能不及时、兼容性稍差，但好处是就算没魔法，下载也飞快。

想恢复官方源的话（安装完成后可做可不做）：

npm config set registry https://registry.npmjs.org/

注意：上面这些命令执行后，通常没有反应是正常的，直接继续就行。这里只是把下载源换掉了，你还需要再次输入：npm i -g n8n

# 工作流思路

开始搭工作流之前，想跟大家聊一个理念：不管是写代码还是搭工作流，本质上都是把我们的想法翻译成机器能理解的东西。所以在动手之前，脑子里必须先有一个大概的思路。

今天这个字幕优化项目，我的思路是这样的：

1. 从剪映里导出字幕文件，一般是 .srt 格式
2. 把字幕文件上传到工作流
3. 把字幕文件解析成纯文本
4. 通过 API 把文本字幕发给 AI，同时附上处理提示词，也可以接入专门的敏感词库或错别字 API
5. 把 AI 返回的文本重新转成 .srt 文件
6. 下载处理好的 .srt 字幕文件

这里只是分享思路，详细的步骤在下面。有了思路，我们就可以把它翻译成工作流了。

## 二、把字幕文件变成字幕文本

第一步工作流拿到了文件，接下来就要开始处理它了。

webhook 默认接收文件的方式是二进制，所以这一步我们要做的，就是把二进制文件转换成文本文件，这样后面才能发给 AI 大模型去读取和优化。

点击 webhook 旁边的加号，在右边搜索【code】，选择第一个 code。

[PRE21]

进来之后会看到三个板块，分别是【预处理文件 INPUT】、【处理文件代码 Code】、【处理后的文件 OUTPUT】。

[PRE22]

前面说过，我在第一步上传的文件，是第一个模块的终点数据，也是第二步的起点数据。所以你会看到 INPUT 里有一个数据文件，这就是我们上传的二进制文件。

我们要写的代码，就是来处理这个二进制文件的。后面的 OUTPUT 不用管，只要代码没报错，它就会把执行结果显示出来。

所以重点放在中间的 code 板块上。

code 板块要改两个东西：一个是 mode，我们保持默认第一个就行。它的意思是代码的执行方式。

第一个选项 Run Once for All ltems：代码只执行一次。
第二个选项 Run Once for Each ltem：根据 INPUT 输入项的数量，每项都执行一次。

因为我们的工作流 INPUT 只有一个文件，所以选第一项 Run Once for All ltems。

[PRE23]

代码如下：

```
return (async function () {

const itemIndex = 0;

const item = $input.all()[itemIndex]; // ✅ 用 .all() 获取第一个 item

const binaryPropertyName = Object.keys(item.binary)[0];

const binaryData = item.binary[binaryPropertyName];

const buffer = await this.helpers.getBinaryDataBuffer(itemIndex, binaryPropertyName);

return [

{

json: {

fileName: binaryData.fileName,

mimeType: binaryData.mimeType,

content: buffer.toString('utf8'),

}

}

];

})();
```

把原来的代码全部删掉，复制上面这一段。

然后执行：点击【Execute step】按钮，运行这段代码。

[PRE24]

不出意外的话，你的 OUTPUT 板块会出现下面的信息，这代表文本解析成功，右下角同时会出现成功的提示。

[PRE25]

至此，恭喜你完成了第二个工作流模块——二进制文件转文本文件。

## 三、把文本字幕通过 API 发给 AI，并写好提示词

我们点击左上角返回，会看到前两个工作流模块都变绿了。现在来处理发送字幕文本给 AI 的部分。

[PRE26]

AI 这里可选的方案就很多了。如果你的电脑是 RTX 3060 以上显卡，完全可以部署本地模型作为 AI 处理接口。但这期不是重点，我就不展开讲了，需要的话评论区留言，后面会考虑写一篇。

第二种方式就是用在线 API。想要效果好，就接 ChatGPT 或者 Claude 的大模型。我这边考虑到性价比，用的是阿里的【通义千问】模型。

获取 API key 地址：大模型服务平台百炼控制台

拿到密钥之后就开始正式配置。因为要给大模型发请求，所以第三个工作流模块选择 HTTP Request 模块。

[PRE27]

进去之后有四个地方需要改：

1. 请求方式：还是用 POST，因为我们要传的数据量很大，不能坐飞机，得坐轮船。
2. 请求地址：这就是 AI 大模型的地址，你想让 AI 帮你处理数据，总得知道它家在哪儿吧。
3. 头部信息：这是校验信息，用来证明你是哪家的数据。AI 看到你有额度，才会帮你处理，不然根本不理你。
4. 参数：这部分是具体的字幕内容和提示词。

[PRE30]

JSON 里的代码：

```json
{
  "model": "qwen-turbo",
  "messages": [
    {
      "role": "system",
      "content": "你是一名字幕清洗专家，请你对下面的 .srt 字幕内容进行处理：【清洗要求】： 1. 修改所有错别字，使语句通顺； 2. 删除或替换所有低俗语言、脏话； 3. 替换所有涉及违法、敏感、违禁的词句（包括政治敏感、涉黄涉暴等），改为中性表达或删除； 4. 保留时间轴格式（即每条字幕的时间线不变）； 5. 不添加解释或注释，只返回清洗后的字幕内容； 6. 如果某句无需修改，原样保留； 7. 输出必须是标准的 .srt 字幕格式（包括空行、时间、换行等等）。 下面是字幕原文"
    },
    {
      "role": "user",
      "content": {{ JSON.stringify($json["content"]) }}
    }
  ]
}
```

这个提示词可以根据自己的需求去微调。如果你觉得 AI 直接替换不够好，也可以让 AI 把违禁词换成 *，后面再用剪映的查找功能快速定位需要手动替换的地方。

```json
{
  "model": "qwen-turbo",
  "messages": [
    {
      "role": "system",
      "content": "你是一名字幕清洗专家，请你对下面的 .srt 字幕内容进行处理：【清洗要求】：将所有错别字的具体字替换为 *（不改正为正确字）；将所有低俗语言、脏话替换为 *；将所有涉及违法、敏感、违禁的词句（包括政治敏感、涉黄涉暴等）的相关部分替换为 *；保留时间轴格式（即每条字幕的时间线不变）；不添加解释或注释，只返回清洗后的字幕内容；如果某句无需修改，原样保留；输出必须是标准的 .srt 字幕格式（包括空行、时间、换行等）。下面是字幕原文"
    },
    {
      "role": "user",
      "content": {{ JSON.stringify($json["content"]) }}
    }
  ]
}
```

特别提醒：修改 content 的时候注意，提示词千万不要换行，否则代码会报错！

完成上面的设置之后，就可以点击【Execute step】按钮了。它会向 AI 发出请求，等几秒就会返回优化好的数据。
