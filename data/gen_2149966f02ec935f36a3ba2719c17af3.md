# 用 IFTTT 把 Twitter 大 V 的动态实时推送到邮箱、企业微信或钉钉

> 来源：[https://yq9pu32e9v.feishu.cn/docx/P2XLdJF2yoivV8xUDszcz853nZg](https://yq9pu32e9v.feishu.cn/docx/P2XLdJF2yoivV8xUDszcz853nZg)

前段时间我对象提了个需求：能不能让某个推特账号发新动态后，几秒钟内就能出现在微信里？这样就能第一时间捕捉 Web3 圈内头部玩家的动向，跟着他们一起布局项目。

需求明确了就去找方案。推特是海外平台，国内很多工具都用不了。折腾一番后，我锁定了 IFTTT 这个自动化平台。它的逻辑很简单，不用写代码，只需要填好条件和动作就能跑通自动化流程。

平台目前支持两种常见推送路径：

1、推特指定账号发推后，自动以邮件形式把原文推送到你指定的邮箱地址
2、推特指定账号发推后，通过企业微信群机器人或钉钉群机器人把信息推送到群内

我两个方案都实操验证过，都能正常触发。下面把完整设置思路拆开讲。

进入后会看到一个经典的 IFTTT 逻辑：第一行是 If This，第二行是 Then That。合起来就是“如果发生 A，就执行 B”。掌握了这个思路，就能玩出很多玩法，比如有人就用它把微博内容自动同步到推特，在 YouTube 上也有不少现成教程可以直接复用。

## 一、先设置监控源：指定推特账号

点 if this 后面的 Add，弹出服务选择页。

[PRE3]

在搜索框输入 twitter，选择 Twitter 平台。

[PRE4]

随后会出现一堆触发器。电脑端可以用浏览器翻译，我需要的是“当指定用户发布推文时触发”，就选图上箭头标注的这个。其他需求可自行翻译挑选。

[PRE5]

进入账号配置页，需要填两个账号。

[PRE6]

第一行是你的 Twitter 登录账号，第二行是你要盯梢的目标账号。

点 Add new account 后会弹出授权窗口。

[PRE7]

输入自己的推特账号密码完成授权，然后在 Username to watch 填入目标账号的用户名。

确认后点 Create trigger 完成触发器创建。

[PRE8]

这时会回到主界面，下面就是 then that 的动作配置，不同的推送方式区别就在这里。

## 二、动作一：推送到邮箱

点 then that 后面的 Add，搜索 email。

[PRE9]

进入后只有一种可用操作，直接选择它。

[PRE10]

进入编辑页，默认模板已经生成。

[PRE11]

如果想在邮件里加更多信息，可以点 Add ingredient 来补充参数。设置完成点 Create action 提交。

注意，收信地址默认就是你注册 IFTTT 时用的邮箱。保存后机器人正式生效，目标账号一旦发推，邮件就会立刻送达。

## 三、动作二：推送到企业微信群，钉钉同理

### 企业微信侧：先建好 Webhook 机器人

官方说明可参考： 如何使用群机器人

#### 建群

先把需要接收消息的人拉进一个群。提醒一点，如果群里包含外部联系人，是无法创建机器人的。想做一人群时，没有像钉钉那样简单的建群方式，需要先把人拉进来再踢掉，就能得到一个单人私密群。

#### 添加机器人

进入群聊设置，找到添加机器人入口。

[PRE12]

[PRE13]

#### 获取 Webhook 地址

创建成功后会得到一个 Webhook 地址，后面统一记为 {WebhookUrl}。简单来说，只要向这个地址发请求并带上正确格式的内容，就能把消息投递到群里。

在 IFTTT 里搜索 Webhooks 触发器，选择 Make a web request 动作。

[PRE14]

[PRE15]

参数配置如下：
url 填入刚才的 WebhookUrl，其他选项按图示选择，Additional Headers 保持空即可。

[PRE16]

body 内容填写，复制下面这段 JSON：

{
"msgtype": "markdown",
"markdown": {
"content": "> 账号:{{UserName}} \n> 内容:{{Text}}\n> 链接:{{LinkToTweet}}"
}
}

配置完毕后提交，机器人就创建成功了。

[PRE17]

钉钉的逻辑完全一样，只要能拿到 Webhook 地址，都可以用同样的 Make a web request 方式实现推送。
