## 90 赞《不是程序员也能用 ChatGPT API + 自动化提高生产力-变现》

作者：Fredrich
发布：2023-03-20

ChatGPT 持续爆火，但真正吃到红利的人依然是少数。想切入这个赛道，有两条路：要么用它把自己的工作效率拉满，要么直接做成生意来变现。思路其实就这么简单。

今天我就用一个可落地的商业自动化实操案例来讲，如何在没有编程基础的情况下，借助 ChatGPT API 和自动化工具，把业务效率提升数十倍。

为什么不讲 RPA，也不讲代码？因为对大多数人来说，RPA 本身就有门槛，更别提写程序了。而 ChatGPT 的商业价值很大一部分就在于自动化，如果放弃了这一环，等于把它的威力砍掉了一半。

希望这篇文章能起到抛砖引玉的作用，帮到看到的朋友实现业务上的跃迁。

**一、这篇文章适合谁**
1. 想用 ChatGPT 做自动化变现的从业者；
2. 想用 ChatGPT 做自动化提效的个人或团队；
3. 没有无代码/代码能力，但渴望让办公和业务流程自动化的朋友。

**二、核心逻辑一句话概括**
自动抓取需求 → 丢给 ChatGPT API 让它处理 → 得到结果后通过自动化工具自动回复、存档、发布，甚至触发手机硬件、调用 Webhook、联动 IFTTT 控制智能设备。简单说，就是一套半定制的自动化流程。
