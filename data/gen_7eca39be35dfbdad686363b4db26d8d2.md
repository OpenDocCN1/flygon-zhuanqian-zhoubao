# 零基础用 Cursor 给儿子做了一个 AI 学说话助手

> 原文：[`www.yuque.com/for_lazy/zhoubao/qnfz109t5rcvlobg`](https://www.yuque.com/for_lazy/zhoubao/qnfz109t5rcvlobg)

加入生财很久了，航海也报了好几次。过去基本都是白跑一趟，没做出能拿出手的东西，也就没什么好分享的。

直到这次 Cursor 航海，感觉像是被打开了一扇门。虽然最后没赚到钱，但那种被点燃的感觉很强烈。

我完全不懂编程，就是花点业余时间摸索一下，居然真能把一个有用的小工具做出来。这种可能性对我这种小白来说太有吸引力了。

所以这次我格外较真。航海前我就开始练手，用 Cursor 捣鼓了几个玩具，比如给自己用的 Midjourney 官网插件、小红书去水印小工具之类的，也注册了域名上线，找回了久违的成就感。

这些项目都比较浅，真正一碰带后台的复杂逻辑就容易翻车。试了几次都卡在 bug 里，自己也搞不清问题在哪，信心受了一点打击，就先把难的放下了。

转机出现在看到大家都在聊 DeepSeek。脑子里突然冒出一个念头：能不能用它做点好玩又实用的东西？反正 Cursor 当时还能白嫖，DeepSeek 的 API 也便宜，试试又不亏。

一开始只是想做个能聊天的 AI 套壳玩玩。带娃的时候灵感来了，我为什么不给儿子做一个陪他练说话的 AI 小助手呢？没想到这次竟然真的成型了。

功能现在还很朴素，但对我来说已经足够惊喜了。把这段折腾的过程整理一下，也许能给同样零基础的朋友一点参考。

* * *

**第一步，动工前先和 AI 把需求聊透**

过去我做复杂点的东西总是失败，这次我决定先稳住。开工前我花了不少时间就和 AI 闲聊需求。

我把脑子里模糊的想法倒给 AI，让它帮我评估完整度、判断能不能实现。它会主动挑漏洞、追问细节。

我还提前说明要接 DeepSeek API，最后要部署到 Vercel。明确了这些边界后，AI 很快就把需求梳理清楚，还给了个初步的技术思路。

这一步很关键。我没有开发经验，如果上来就开干，需求没想清，最后大概率会做出一个自己都不想要的东西。

**第二步，让 AI 产出详细需求文档，并且一直保持更新**

需求聊顺了，我就让 AI 写一份正式的需求文档。我觉得一份好文档至少要包含三件事：要做哪些功能、用什么技术、怎么分阶段推进。

更重要的一点是，文档要活着。项目做到一半，需求和方案一定会变。及时记录进展和变更，否则 AI 还会按旧版本写代码，最后项目就炸了。

另外 AI 的上下文记忆有限，做一段时间就得让它刷新一下进度。这样新开会话时，AI 能更快进入状态，不会乱改。

过程中我会给关键修改做时间线命名，方便回滚。万一走不通了，能迅速退回上一个稳定版本。

**第三步，把阶段拆得足够细，一次只做一件事**

不懂代码的人用 AI 开发，最怕的就是一步跨太大。我以前想一口气做带后台的网站，结果卡在解不开的 bug 里，郁闷到放弃。

这次我换了策略：把一个阶段只限定一个小目标，成功率立刻变高。

对我这个项目来说，第一阶段的目标就是能接通 DeepSeek API，并且能正常对话。就这么简单。哪怕做到这里停下，对我也是 0 到 1 的突破。

事实证明，接通 API 并对话成功后，我的信心就上来了，后面就顺着这个节奏一点点推进，最终真的做出来了。

最终实现的功能大致有这几块：

**1、成功接入 Deepseek API 并实现正常对话**
**2、能记录我儿子已学会的词语，自动归类，并推荐相关度高的新词**
**3、用图谱可视化展示已学会的词语**
**4、具备数据库，能保存词语和对话记录**
**5、提供基础的词语管理能力**
