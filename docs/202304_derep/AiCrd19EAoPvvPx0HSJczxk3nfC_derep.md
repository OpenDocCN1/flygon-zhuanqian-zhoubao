# ('《赚30万的项目和赚300万的项目有什么区别？》@龙哥', (2, 29))

今天有朋友问我：年入30万和年入300万的项目，差别到底在哪？

我的回答是：本质上，它们其实是同一个项目。

你以为年入30万，是因为自己足够特别？其实在你看不到的地方，可能还有十个、甚至上百个和你能力差不多的人，同样也在赚这30万。

如果你有足够强的复制能力，把这些人变成你的“分身”，做成矩阵，那这个项目就变成了年入300万的盘子。

一个视频号能赚1万，那一百个视频号呢？就是100万。这就是矩阵思维。

别瞧不起小钱。星球里偶尔有宝妈圈友分享：一个月靠某个项目赚了几千块。很多人一听就觉得没意思，嫌少。但我真觉得，这些人没想明白——一个普通宝妈都能靠它月入几千，说明什么？说明这个项目门槛低、复制性极强。越是这样的项目，越藏着几十倍、上百倍甚至上千倍的增长空间。

这才是真正的好机会。
