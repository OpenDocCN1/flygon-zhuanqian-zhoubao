# ('《视频号直播违规避坑》', (2, 13))

你有没有发现，视频号直播越来越多人进场，但真正能避开暗坑的却不多？最近在生财圈子里看到一篇很实在的分享，讲的就是这个。

分享者是一位深耕微信生态超过十年的电商人，人称“宏”。他算是最早一批踏进视频号直播的人，亲手操盘过几个垂直类目的品牌头部账号，直播间场观做到过百万以上，GMV也冲过两百万关口。更硬核的是，他在付费投放上烧过两三百万的流量券，对微信豆的投放玩法算是摸得门儿清。眼下，他还在帮不少直播间做代投流和代播，属于实战经验拉满的那种人。

就在刚结束的3月航海实战中，他受视频号带货项目负责人邀请，把自己踩过的坑、攒下的经验一次性讲了出来。目的很纯粹：希望后来的人能少走弯路，在视频号带货这条路上跑得稳一点。

分享全文已经放出来了，内容覆盖了不少实操细节，适合正在做或打算做视频号直播的人参考。评论区也有不少人跟他互动，想进一步交流的可以直接私信联系。

总之，这年头信息差就是钱，能提前看到别人趟过的雷，等于省下的都是真金白银。感兴趣的话，不妨点开链接慢慢看。
