# ('《怎样一边搞学习，一边搞钱？》', (2, 17))

经常有人问我：到底怎么才能一边提升自己，一边把钱赚了？好像学习和赚钱总是两件互相抢时间的事。

其实，把这两件事拆开看，底层逻辑惊人地相似。

**1. 学习和赚钱，都得先抓住“最小单元”**

学习任何一门知识，无非是先把基本概念、核心原理、应用场景搞清楚。先知道，再熟练，最后形成条件反射。很多人学了一堆，但让他独立讲出来、用出来，就卡壳了，这就是基本功不扎实。

赚钱也一样。你选什么赛道、做什么产品、定什么价位、在哪个渠道成交、怎么说服客户下单——这些关键环节，心里必须有一张清晰的作战地图，缺了哪一环，赚钱的速度都会打折。

**2. 学习和赚钱，都靠“死磕式练习”堆出来**

把大目标拆成小要素之后，剩下的就是反复练。想考过试，就一遍遍刷教材、背知识点、做真题、分析出题人意图，每一轮都复盘，时间会给你答案。想赚到钱，就多观察身边的人怎么赚钱，多研究用户心理，多从市场角度想问题，然后大胆试错，把有效动作固化下来。本质上，赚钱也是练出来的手艺。

**3. 学习和赚钱，都需要“定力”来托底**

在一个领域泡久了，就会生出直觉，遇到问题知道往哪儿使劲，不会慌。学习上的定力，是遇到难题知道怎么拆解、怎么找突破口；赚钱上的定力，是知道什么阶段用什么打法——新兴市场怎么进、红海市场怎么打、衰退市场怎么退，心里有数，敢于下注。

当然，你可能会问：万一是错误的方向呢？什么时候止损？说实话，这是门艺术。你是在成功前夜放弃，还是在大滑坡开始前离场，只有事后才能看清。没有标准答案，但你必须有扛住挫折的定力。

**4. 学习和赚钱，随时都能开始，也随时都能精进**

学习就像吃饭，不能吃一顿管一个月。赚钱也是，别等“准备好了”再出发。

如果你在上班，那就研究透公司的业务和盈利逻辑——学业务是学习，提升议价能力是赚钱。如果你没上班，研究ChatGPT也好、跨境出海也好、私域IP也好，学玩法是学习，动手操作是赚钱，赚到钱复盘是学习，亏了钱总结经验也是学习。

所以，别再给自己找借口，边干边学，边学边赚。

**5. 想变厉害，就去和厉害的人扎堆**

小时候家长让我们上好学校，就是因为那里会搞学习的人多。而会搞学习的人，以后大概率也更容易会赚钱。注意，这里说的“会学习”不是只会拿高分，高分只是其中一种体现。

现在网上社群很多，有的聚集学习型人才，有的聚集搞钱型人才，但真正两者都强的人不多。我也观察到一种现象：只会学习的人容易清高，觉得“万般皆下品”；只会赚钱的人可能看不起拿死工资的，觉得对方不开窍。这两种心态都是因为没打通两个领域，成了井底之蛙。

真正厉害的人，往往是既会学又会赚。时代一直在变，持续发展就得一边学、一边赚。

所以，想好好学习，就靠近学习强的人；想好好赚钱，就靠近赚钱强的人；想两者兼得，就去找那些既能学又能赚的人。但前提是，你自己也得拿出这种势头来——哪怕现在还不够，也要让人看到你在成长，不然别人凭什么在你身上花时间？

**6. 最好的状态，是学习和赚钱同频发力**

我始终觉得，个人成长最理想的样子，就是一边学习，一边赚钱。君子爱财，取之有道——“道”靠学，“财”靠干。

具体怎么做？就是让学习和赚钱同步推进、同时发力、同向发力。我做了十年学习社群，一直在把赚钱的认知引入学习圈；同时，我也在龙哥盟这样的搞钱社群，分享学习的方法论，帮大家用学习突破赚钱的天花板。

古人讲修身齐家治国平天下，学习和赚钱，就是修身这件大事里最核心的部分。

愿你我都能在成长路上，既能静心学习，又能痛快搞钱。
