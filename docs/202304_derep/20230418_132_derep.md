# ('《2023 年如何入局视频号直播》', (2, 19))

2023年，视频号直播依然是个热门话题，但很多人还在门口徘徊：到底怎么入局？有没有捷径？最近刷到一位实战派教练的分享，觉得特别适合想上车又没头绪的朋友，这里把他的干货和精华问答整理给你。

这位教练叫Erik，在山东济南，团队专门做直播带货和直播培训。他的战绩挺亮眼：去年拿下4颗龙珠，还连续三期担任抖音半无人航海教练，带过1000多位圈友入局直播。而在刚结束的龙哥盟二月航行里，他同样以视频号直播航海教练的身份，给大家带来了一场主题分享——《2023年如何入局视频号直播》。内容既有今年视频号直播的最新趋势判断，也有专门给直播小白准备的快速上手技巧，可以说都是实战中趟出来的经验。

他本人的期待也很实在：希望这些内容能帮到更多想在视频号直播里拿到成绩的圈友。想读全文的话，可以点击这个链接：[https://i.shengcaiyoushu.com/docx/EBUxdyjCOocMQjxqx8FcZpAxnqb](https://i.shengcaiyoushu.com/docx/EBUxdyjCOocMQjxqx8FcZpAxnqb)

更精彩的是评论区里的连环追问，信息量很大：

- 有同城朋友直接来认亲；
- 有人问健身类目怎么变现，Erik答得干脆：带货好做，健身类目更容易做出出彩的场景；
- 还有圈友现身说法，说用了Erik的“找熊猫”方式拉场观，因为用的人太多触发了违规提示，好在没扣分，但后续直播场观确实起来了——开头一小时才100人场观、平均在线1分多钟，一小时后不断进人，冲到2600场观、在线300人时被提示违规下掉，且之后进来的多是男性。第二天再播一小时能有200场观，比以前好，就是男性流量偏多；
- 关于新号不推流要不要投加热，Erik建议投两条：一条选“进入直播间”，时长设两小时；另一条选“互动”或“成交”，时长4小时以上；
- 有人播6小时才1500场观求提升方法，还问到拉时长到1万场观是不是就能破号拿权重，这个问题的答案也值得在原文评论区里找找。
