# 从零搭建年入千万级职业教育在线平台，我踩过的六个关键环节

> 来源：[https://yqqb1l50gj.feishu.cn/docx/A4UGdiBqBoH4T0xnkW5c0Nxtnkh](https://yqqb1l50gj.feishu.cn/docx/A4UGdiBqBoH4T0xnkW5c0Nxtnkh)

很多人问我，职业教育线上项目到底怎么做才能做大。我从2014年入局，亲手操盘过一个医考类品牌从无到有，到爆发期一年做到1500万流水。起因很简单，彼时国家对持证医疗人才的政策导向明确，我们就锁定了执业医师、执业药师、健康管理师这条赛道。

今天把从0到1的完整路径拆开讲一遍，包括注册、生产、产品、技术、招生到招商，每一步该怎么走、坑在哪。

这篇适合从未做过教育品牌的创始人参考，少走弯路。

### 一、先把公司主体搭好

传统线下教育需要教委颁发的非学历培训资质，还要配固定场地。线上就不一样了，我们当时走的是教育科技公司路线，主营在线教育科技服务，获批难度低，北京地区营业执照半个月左右就能下。经营范围可参照常规科技教育类模板。

一个小细节：公司起名一定要多备几个备选名，重名率极高，提前准备好替换名能节省大量时间。

### 二、课程怎么产出

核心是找对老师。起步期不用追求顶流，找业内有口碑、价格相对亲民的名师即可。医院、高校的研究生团队也是不错的挖掘池。课时费市场价大概在1000到5000元区间。

场地就用外部录课室，按天计费，音画质量好的室费会贵一些。录完后做剪辑、加字幕，一般PR就能完成。

需要配一个小型教务团队：负责优化PPT、剪辑成片、整理讲义、做答疑服务。

资料包也必须做。把历年真题汇总、归纳、重组，就是一本高转化的陪读资料。资料单价低、传播力强，是很好的引流利器，也是宣传物料里不可缺少的一环。

### 三、产品怎么分层

产品逻辑其实很清晰，分三层走。

引流层：知识点精华、习题集、模考卷、考前冲刺卷。

利润层：
基础班 = 基础讲解 + 冲刺提升
全套班 = 基础 + 冲刺 + 模考 + 应试技巧 + 急救包
VIP班 = 全套服务周期拉长至两年，或支持学历保障类退费机制

课时多少决定班型设置，录播负责基础输入，直播负责提升与答疑，这是常见组合。

### 四、技术基建怎么搭

一套完整的线上平台至少包含官网、APP、小程序、H5四个触点。

官网在阿里云买域名搭建，接入听课入口、模考系统、题库系统。题库单独拿出来做低价引流，配合活动一天可带来上百线索。

课程资源放在阿里云服务器托管并加密存储。

APP和小程序现在模板化程度高，开发成本已大幅下降。

H5主要用于移动端裂变传播和活动落地页。

### 五、招生与渠道裂变三步走

第一步：借力权威机构。项目启动期我们对接全国的品牌连锁药店、医院、护士院校，通过总部发文形式做联合推荐。当时5个销售，半年就回本100万。本地项目也可以找当地权威机构背书，比如教育局体系，搞定一个就能撬动一片。

第二步：学员转代理。首批忠实学员通过后，开放课程代理资格，按推荐分成50%。好处是学员有收益动力，同时能吸引各地小培训校关注。我们当时不收加盟费，只收可抵扣课程的预付款，结算成本压到2.5折，远低于行业普遍7折，第一年招商就做到500万。

第三步：贴牌输出爆发。2018年网校兴起无logo白标模式，我们已有1000多家合作伙伴，立刻调整策略，在保留品牌加盟的同时推出贴牌定制课程。很多地方机构最怕被总部抢学员，希望自建品牌沉淀客资。贴牌模式恰好满足这个需求，一年营业额冲到1200万。

从公司注册到贴牌放量，这就是一个职业教育在线品牌完整的迭代路径。思路清晰，执行扎实，千万级流水并非遥不可及。有想法欢迎交流，一起探讨赚钱之道。
