# 《活动复盘：7 天线上活动，为儿童摄影门店拓客引流 5000 》

标题：7天带来5000余条新客线索，一家亲子影楼是如何做到的？

线下深耕了9年，我一直在帮实体店做增长运营。今年2月，我参加了一场集中实战，复盘对象是一家亲子影楼。7天时间，它拿到了5000多个新客，这个结果让很多人意外。

有人问：这么多客户，门店排得开吗？答案是能。这家店日常拍摄量约每天10组，方案里特意把整个活动消化周期放到两年。亲子摄影的到店节奏也很有特点：前90天是顾客集中到店的时期，之后预约拍摄会慢慢回到常规状态，档期并不会被占死，还能继续接待其他渠道来的客源。

更关键的是，近30%的客户在正式拍摄前就选定了2000元以上的全价套系。也就是说，活动还没真正落地，客单价已经有保障。具体的组织方式和落地细节，我写进了文档，想看的可以私信我“摄影案例”，或直接打开原文链接：https://www.yuque.com/for_lazy/thfiu8/eh1hmvxa3veptkoo
