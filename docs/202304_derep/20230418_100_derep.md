# 《刚入赚钱的新人程序员对项目的筛选过程以及最终的执行路径》

新手程序员如何半个月锁定第一个项目？我的筛选逻辑与执行路线分享

我是刘卡卡，一个今年3月18号刚刚加入赚钱的程序员。说起来有点难以置信，才半个月时间，我的认知就被彻底刷新了——原来搞钱的路子能这么野，更难得的是，还有人愿意把自己的赚钱方法一步步写出来分享。可下一期航海要等到5月才启动，我实在不想干等，就决定亲自下场，先跑通一个小项目。

那么问题来了：怎么从一堆项目里选出最适合自己的？我给自己设计了一套“漏斗式筛选法”，整个过程也整理成了笔记，如果你也在起步阶段，不妨参考一下。当然，如果有幸被路过的大佬看到，欢迎多交流。

整个筛选分四步走：

第一步，拆解自己。把自己的技术底子、空余时间、现有资源以及个人偏好全部摊开，搞清楚自己手里有什么牌。

第二步，盘点项目。我把2月航海涉及的项目类型逐一过了一遍，从个人角度去分析每个项目的玩法逻辑、门槛高低以及收益空间。

第三步，果断做减法。凡是自己搞不定的，或者内心抵触的，直接划掉，绝不留恋。

第四步，二选一。最后留下的两个候选是小绿书店铺和视频号。我纠结了一会儿，最终决定先做小红书店铺。为什么？很简单——先跑通一个最小商业闭环，验证一下自己的执行力，然后再考虑更大的盘子。等店铺稳定出单后，我会把重心转移到英文工具站上。
