# 主营品类

## 代理销售

### 一、代理的品类方向

在快团团做代理，我聚焦三条线：

1、应季生鲜水果：草莓、橙子、枇杷、芒果等

2、生活方式用品：鲜花、香薰蜡烛等

3、便捷预制菜：凉皮、鸭掌煲、螺蛳粉等

为何锁定这三类？我的理解是快团团的本质是人货场协同，货要与人的真实需求匹配。先读懂人群，再选对应商品，才能实现爆发，后面会展开说明。

### 二、重点爆款：草莓

重点拆解一个爆品——草莓。单品月佣金超3万元，平均一单提成11元，共成交2800余单，复购占比超过40%。

选择草莓的核心原因：

1、当季稀缺，草莓成熟期只有约3个月，供不应求

2、酸甜口感受小朋友喜爱，家长会反复回购

3、客单价和毛利空间都不错，线下水果店价格偏高，线上具备价格优势

![](img/8cb6f76515474ca48d805a09e0456deb.png)

### 三、高转化高复购的打法

1、饥饿感营造：每日10点固定秒杀，限量200份，售罄即止。不少用户提前设闹钟抢购。

2、从众推动：群内保持持续好评输出，制造热卖氛围。需注意，群里会安排少量托维持节奏，否则容易沉寂。

3、性价比对比：在群内定期发布超市、线下水果店同款的价格与实拍，突出品质与价格差，让成员产生占便宜的感知。

# 人货场在社区团购中的运用

### 一、先定人，再定货

很多人困惑快团团到底卖什么，答案是先回答卖给谁。我微信群里的人群画像较为集中：

1、中产家庭的居家主妇：时间相对充裕，群内活跃度高，个人经济来源依赖家庭，消费决策围绕家庭展开。她们对自己出手保守，但以孩子和家庭名义消费时意愿很强，同时也追求社交认同带来的满足感。高收入家庭在日常饮食、刚需消费、子女教育等高频品类上，更偏好高品质、高势能、能体现生活品味的产品。

2、一线城市的上班女性：工作节奏快，情感诉求多通过消费释放，个人价值感强，消费能力也强。她们更在意自我表达，在晒单与社交展示时希望强化自身的高级感，人设核心是“懂生活、会生活”。但时间有限，需要快而有效的形象加分品。

### 二、从需求反推选品

先厘清“生活方式”概念。很多人以为就是装点门面，其实不止如此。源自英文 lifestyle，指的是生活格调与风格。叠加社交媒体经济后，生活方式消费的意义被放大——能让消费者感受到格调提升的商品，人会愿意为之支付溢价。社交媒体上，个人生活方式能迅速转化为社交资本。

因此，选品若能在生活方式维度成立，就能自发激发分享欲，而非靠低价抽奖驱动。

当然，消费者为格调付出的预算是有限的。选品与定价需兼顾格调感与性价感，让买家既觉得有品味又感觉划算，才容易爆单。比如头部主播先塑造“懂生活、懂美学、懂格调”的形象，用户认同后再看到优惠价，转化率才会上去。若信任感不足，同样的货也难以卖动。

不同人群对生活方式的定义不同。人货场中人永远排第一，要倾听需求再做供给。

我周边的几个小区属于中高端社区，小红书引流的粉丝质量也高。长期群内互动后，我对两类核心人群的消费力与社交诉求有清晰判断，进而做了精准的品类与价格策略。

结合人群画像，水果成为首选：女性对水果有天然好感；水果颜值高，具备社交传播属性；属于高频刚需；线下定价高，存在价格破局空间。

水果的短板也存在：易损耗，品相问题易引发售后；非标品，稳定性受限，天花板会受压制。

但先看机会点。基于对人的洞察，我作为“场”，叠加自己的“吃货属性”，确定了“货”的方向：高性价比的生鲜水果，具体聚焦颜值高、品质稳、欲望强的高端品如葡萄、草莓、蓝莓、高端柑橘等。快团团仅是我的分发工具。

人群与商品定位完成后，关键是获客，有流量才有交易。

# 成功关键点

套路并不复杂，品类也不罕见，我能跑通的核心差异在于以下几点：

### 一、个人IP沉淀：建立信任与代入感

本人有市场广告背景，十年间跨领域创业，个人微信原有7000+好友，日常分享生活方式图文并组织各类线下活动，在周边社区具备一定影响力。朋友圈与微信群的带货因此具备天然信任背书。

IP塑造要点：

1、朋友圈内容保持美感与正能量，让粉丝产生向往与代入：“买Luca的东西，就能过上Luca这样的人生”。赚钱的航海朋友圈运营手册很有参考价值。

2、积极参与并组织线上分享、读书会及线下赚钱聚会，打造思想饱满、情绪丰富的独立女性形象，这正是主妇与年轻白领群体希望投射的形象。

3、只卖自己熟悉并喜爱的品类。5年餐饮经验让我对饮品、水果、糕点等有真实了解，也常去产地探访。但对美妆、母婴等不熟悉的品类坚决不碰。

### 二、裂变拉新

1、私域裂变：老客户邀请好友加入Luca买买群，可获得2元抵扣券。兼顾留存与获客，平均1个老客可带来2个新客。

2、小红书引流：发布系列笔记导流至个人微信，再沉淀至购买群。目前已运营13个买买群。

如何让小红书用户从首页点击进入并私信加微信？笔记文案是核心，其逻辑与朋友圈、微信群文案相通，后续统一说明。

### 三、文案与呈现能力

单纯发图+链接，转化会很差。生鲜水果团笔记与朋友圈的吸睛要素总结如下：

1、强调原产地直发、现采现发，制造无中间商的感知

2、价格对比强烈，例如52元在超市仅能买1斤草莓，跟我买能买3斤

3、图片冲击力要强，摆盘丰富、色彩饱和

4、提前写明售后政策，降低购买顾虑：包邮、口感不佳可退、破损包赔

5、晒真实用户好评截图，制造社会证明

6、保持氛围组，维持群内活跃

7、限时秒杀，例如限200份或限1天，制造紧迫感
