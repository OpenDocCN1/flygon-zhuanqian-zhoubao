# ('《新人进入 Web3 的正确姿势》', (2, 19))

Web3新手如何迈出第一步？“All in Web3的Start”来给你指路！作为《从零开始读懂Web3》的统筹作者，以及龙哥盟两期Web3小航海的教练，Start在带新人这件事上很有发言权。他目前还创办了Web3Going新手实战营，持续为入行者保驾护航。

这不，应@小霸王老师的邀请，Start重新公开了今年2月担任龙哥盟Web3小航海教练时的完整分享，聚焦“新人进入Web3的正确姿势”，干货满满。他本人也表示，从两期小航海的学员反馈来看，大家确实都很有收获，这套方法很适合零基础入门者。

在龙哥盟这个圈子里，Start尤其感谢龙哥老师、静伟老师、小霸王老师的认可与支持。他希望能继续留在这条赛道上，陪更多想冲进Web3的新人少走弯路。
