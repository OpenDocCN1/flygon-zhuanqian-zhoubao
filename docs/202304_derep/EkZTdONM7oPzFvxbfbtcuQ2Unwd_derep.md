# 在闲鱼随手卖了10W+自己的旧衣，有几点经验总结

### 我把旧衣服挂闲鱼，卖了10万+：几个普通人能复制的经验

你敢信吗？换季收拾衣橱，随手拍了几件不怎么穿的衣服挂到闲鱼，居然陆陆续续卖出了10万+。我是阿黛，一个刚进赚钱圈的萌新。和那些动辄几百万几千万的大佬比，这点成绩实在不够看。但我知道，还有很多比我还小白的伙伴，没经验、没方向、一直在观望，所以我想把自己的真实经历拿出来，给同样迷茫的你一点启发。

以前我做过实体生意，赶上过黄金时代，后来行业没落了，转型转得很痛苦。卖家乡腊肉算是找到了一条小路，还得了精华分享，也收到很多朋友的鼓励。那段时间我最大的收获是：人要培养顺手赚小钱的能力。别小看几块钱的利润，说不定哪天，小机会里就长出了大生意。

我也当过职业经理人，管过几亿销售额，但那些光环其实和我没太大关系。后来，我花了很长时间适应落差——从前年薪百万，后来卖一斤腊肉只赚几块钱。适应之后，我反而养成了一个习惯：小钱也愿意去赚。相信攒着攒着，总会遇见大机会。

千里之行，始于足下。光想没用，想做什么就赶紧去试。这也是我很期待赚钱航海实战的原因。

在闲鱼卖旧衣完全是偶然：换季收拾衣橱，发现好多衣服根本穿不上。尤其郑州春秋短得几乎感觉不到，好些衣服一年到头也穿不上一回。拍下照片挂上去，没想到陆陆续续卖了10万+。后来还发现，有些姑娘专门做这种生意，收益也很不错。

我觉得自己的经验不算普遍，但有一点可以肯定：个人风格鲜明的人，卖旧衣会更容易。你也可以从现在开始留意，慎重买进，几年后让钱重新流动起来。

**1. 稳定的风格，就是在提前积累客户**

物以类聚，人以群分。这二十年我穿的衣服品牌特别固定：例外、楼上的拉姆、部分Uma Wang，还有极少数小众设计师款。它们的共同点是：不在流行里打转，所以不会过时。当年马可还在例外的时候，偏爱重磅棉麻，设计宽松，太瘦的人反而不容易穿出味道，特别吸引文艺女青年。很多款到现在还是经典，更别提那些限量款了。年轻的时候，我每季都买不少，还专门飞去直营店扫限定款，买得多到品牌方订机票酒店请我去看秀，还给我起了个绰号“X例外”。至于现在的设计嘛，就不多说了。

楼上的拉姆是个特立独行的牌子，创始人是把古董绣片带进服装的开创者之一。2004年成立到现在，一直坚持“创作惟一”，尊重每一块绣品的不同，十九年所有作品没有一件重复，全是孤品，自然吸引了一群同样特别的人。

![](img/78ceeb5a32ac2ea5e5836eae6eeee8ce.png)

这大概也算是另一种长期主义。我穿这些衣服穿得够久，手上攒了不少别人喜欢却没买到的款。很多人在博客、微博时代就因为我穿这些而关注我，后来在闲鱼看到我挂出来，基本都是秒抢。

**2. 小众设计师作品，可能是潜力股**

有些设计师名气不大，但作品是真的好。十六年前，我在淘宝买过几条获奖的裤子，价格不贵。现在店已经不在了，设计师也不知去向，但裤子依然是条好裤子，还是有人喜欢。卖多少钱我都开心——毕竟质地好、也没穿过几次，当废品扔了太可惜。

![](img/2e6ec70c44fd894bd55e29eaca9573d6.png)

![](img/6d73f68dec01f62442332a0870e869f9.png)

另外，古董绣片本身就是不可再生资源，在固定的圈子里会保值，甚至升值。我有几件老绣衣服，卖出去的价格比当初买时还高，而且还真有人买。可能是有设计师买回去二次创作吧。还有一些小姐姐加了我微信，直接对着我的照片问身上那件卖不卖，我也转手了不少，除非特别喜欢或穿旧了，才不卖。

![](img/1064321a05add7751ffb451873508628.png)

反而是大牌不好出，价格也压得低。2018年有人送我一个Gucci托特包，国内专柜一万八，全新没拆。我问二手店，人家只肯出两千。算了，自己背。

**3. 认准一个平台，别到处撒网**

没必要同时挂好几个平台，精力不够，客户也没法沉淀。二手平台也需要运营，但我属于佛系卖家：不理砍价、不拍视频，偶尔想起来了才去擦亮一下。要是勤快点、配合度高些，肯定能卖更多。

**4. 我们真的需要那么多衣服和包包吗？**

囤东西真的是一种病。我虽然卖了不少，但家里堆的更多，常穿来穿去就那么几件。包包也一样，我现在出门多半拎环保袋，装电脑、放健身衣服都很方便。

年纪越大，物欲越低，很少对什么东西势在必得。内心丰盛了，就不需要靠外物来证明自己。

但在明白这个道理之前，我是真能买。不止衣服，半夜睡不着，还会远程指挥在巴黎的闺蜜帮我在拍卖行买古董酒具和皮箱。买得太多，家里放不下，特意在乡下的员工宿舍旁租了个仓库。后来项目结束，我撤场搬走，一个女孩儿帮我把东西带回她婚房的客房照看。等她孩子都一岁多了，我才去拉回来。现在想想，我这个老板也是挺离谱的。

![](img/e45677dbe9a875f3347ac724dd220177.png)

后来，我终于下定决心开始卖东西，就开了一家店。当时郑州好些自媒体来采访。可惜的是，2021年7月20日那场特大暴雨，把我的地下二层仓库淹了。17天后我才终于进去，很多东西已经没法救，它们用这种决绝的方式永远离开了我。

现在我要是看中什么，都会先放进购物车或截图存相册，过阵子再翻出来，问自己是不是还想要。大部分最后都被删掉了。这个办法能有效抑制冲动消费，希望对你有用。

**5. 处处都是生意**

现在大家都在搞钱，斜杠青年中年到处都是。只要用心，处处皆学问，真没想象中那么难。

我们可能只是出个闲置，但有心的姑娘们已经把这件事做成了生意。她们懂行情，知道哪些经典款常被人稀里糊涂低价挂出来，于是用工具2000块秒拍，再换个号6000块挂出去，转手就赚几千，比普通小白领一个月工资还高。当时我听完都惊了：原来还能这么玩。真的长见识。尽管我大概率不会这么干，但多观察多琢磨，总不是坏事。

之前例外做特卖时很低调，不怎么公开宣传，只有一些老客户知道，分布在各地，一折两折就能淘到以前的款。就有个在淘宝开店的姑娘，拖着行李箱跟到各个城市去淘。
