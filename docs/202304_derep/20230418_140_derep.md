# ('《两个正确姿势，度过难熬的新手起号期》', (2, 21))

把抖音推文的起号期熬过去，就靠这两个姿势（新手必看）

先自我介绍下，我是某人周。我是去年加入生财的，之后一头扎进了抖音推文项目，到现在都还挺喜欢。为什么选它？因为对新人太友好了：投入小，试错不心疼；不需要绞尽脑汁搞原创；整个操作的流程都是现成的，照着一步步走就能上手。像我这种短视频经验几乎为零的人，也能跑起来。

这次受生财团队木木的邀请，我来聊聊自己在推文新手期的体会。整个分享主要围绕两件事：一是怎么做视频，二是怎么养账号。很多刚起步的朋友应该都有感触，最难受的就是推流忽高忽低，甚至发出去根本没人看。所以我打算先讲清楚平台推流的底层逻辑，再讲怎么通过优化操作把播放量瓶颈一层层顶开，最后说说推文基本功该怎么练。如果你对抖音推文、短视频项目还不熟悉，这篇应该能给你一点思路。

另外，评论区里有几个高频问题，我在这里统一回应一下：

第一个是账号流量低的问题。有朋友说，自己用的是新手机卡注册的号，刷到的几乎全是推文视频，账号检测也没查出违规，视频还支持投豆荚，可发了两条视频播放量都只有50上下，有人点赞，但和文中提到的200-300初始流量差太多了，这号还能继续用吗？

我的建议是：先打开抖音创作者中心的“账号检测”，看账号和之前发的作品有没有问题。只要没有异常，就放心接着用。不用为那几十播放量焦虑，更直接的办法是再发一条作品，看真实流量怎么走，让数据来验证账号健不健康。

第二个问题是：推文小说从哪里找？怎么联系授权？这个可以去翻翻三月小航海的《抖音推文航海手册》，里面的素材来源和联系方式都写得很明白。

第三个问题是：抖音推文到底怎么变现？说白了，观众从你的推文视频去对应小说平台开了会员，你就能拿到平台给的分成。想了解更多细节，同样是看那份航海手册。

最后说一句：新手起号期确实难熬，但只要把做视频和养账号这两个姿势练扎实，流量会一步步好起来。希望这次分享能帮你少踩点坑。评论区见。
