# ('《普通人如何打造自己的创业类付费社群，2 个月引流 200+ 付费用户，变现 9900+》', (2, 47))

从19.9到199，2个月200+人付费，这个草根创业圈子做对了什么？

先自我介绍一下：我叫新侠。白天在一家深度参与苹果产品制造的上市公司做中层，带着20多人的技术队伍和50多人的一线班组，日常工作偏数据洞察和组织协同。业余时间，我基本都泡在线上，折腾各种小副业。

今年初，我正式开始了副业探索。前期的路子谈不上原创，更多是拆解别人的打法，再结合自身情况不断调整，最后慢慢磨出了一个以线上创业为主题的付费圈子。

圈子刚开时，门票只要19.9元。随着内容和交付不断加码，价格一路提到了199元。前后不到两个月，就有超过200人加入圈子，总进账超过9900元。

更能说明这套打法普适性的，是我小舅子的经历。4月2日，我把整套项目逻辑拆成一步步可执行的动作，交给了从没碰过线上运营的他。结果4月6日他就完成了第一单，从学习到成交，仅仅用了4天。

回头看，这几个月走得很曲折，弯路没少绕，坑也没少踩。好在最后趟出了一条平常人也使得动的线上路子。最让我安心的是，这套玩法不仅在我身上奏效，在一个彻底零基础的新手那里同样奏效。

因此，我把整个过程中碰到的麻烦、想出的对策和个人的思考，整理成了一份完整复盘，放在飞书文档中。想细看的朋友可以点这个链接：https://pbw5yhoa0k.feishu.cn/docx/K3oEdbAo1o5fq4xlSf3cOhkMnrg

留言区里有人问现在还收不收人。其实我写这篇分享的初衷并不是拉人头，而是想把经历过的东西沉淀下来，给同样在副业路上摸索的人一点参考。
