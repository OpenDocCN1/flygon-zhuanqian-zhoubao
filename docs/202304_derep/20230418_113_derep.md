# ('《靠近本身就是一种成长》', (2, 14))

有人告诉你：还没正式加入一个圈子，只是在圈子边缘转了转，就先赚到了7000块——你信吗？

不管你信不信，这事真真切切发生在一个90后宝妈身上。

她叫谦羽，是个生命成长教练，去年8月还在待产，就完成了从实体管理到身心灵赛道的转型。她身上挂着一串标签：国家二级心理咨询师、正念冥想教练、身心灵疗愈师，江湖上还有人喊她“优势挖掘机”。

用她自己的话说，剥掉这些头衔，她和你一样，就是个普通人。

但这半年来，她开了生命成长特训营，做一对一咨询，还有私塾陪跑，前前后后帮了260多位学员找回“真我”。学员们最大的变化是：天大的事落到头上，也就是“天空飘来五个字，那都不是事”。

她的愿望很朴素：让一亿万人看清人生和生死的真相，提升心智，回归内在的丰盛，享受健康、和谐、幸福的关系。

为什么会发这么大的愿？

因为她自己就是从泥潭里爬出来的。

早些年她活得又偏又执，把全部精力扑在事业上，在家里无限度付出，最后把自己耗得伤痕累累：垂体微腺瘤、严重胃下垂、颈椎四处变性突出、早起流鼻血、甚至晕厥。身体在报警，心在嘶喊：这不是我想要的生活。她离了婚，对男人充满偏见，从此踏上学习之路——参加读书会，学教练技术，上身心灵课程，研读阳明心学，线上线下读了大量书，终于找到答案：

向内求。我是一切的根源，爱是一切的答案——可以无条件地爱，但不能没有底线地爱。

当她真正看见“自己就是财富和幸福本身”的那一刻，身边一切都变了：现在这位老公宠她入骨，公婆待她如亲闺女，还迎来了一位天使宝宝。更神奇的是，家里并没有上演“有了孩子就一地鸡毛”的桥段，反而夫妻、婆媳、大家族之间的关系越来越顺滑，越来越有爱。

正因为自己痛过，她看见身边还有太多人困在恐惧、迷茫的小世界里，靠情绪做事，对夫妻、亲子、婆媳、人际关系的规律一无所知。

然后，她和“生财有术”的故事开始了。

她说，自己和生财的缘分，其实出现过很多次。

第一次，是在加入Chat GPT社群时，就动过进生财的念头，但因为认知局限，怂了。

第二次，她一连听了七小的好几场分享，关于七小本人在生财的成长轨迹和赚钱思路。七小还让助理酥酥在群里分享了几篇生财的帖子，她逐字逐句看得认真，后来还感慨：这就是她变现的助缘。但当她翻到亦仁益语第59页，看到一大段关于编程的内容，瞬间劝退了——让她答疑解惑、传道受业没问题，可是编程？那简直是代码认识她、她不认识代码。

——这就是认知局限给她设的限。

转折发生在2023年4月3日晚上。她本来都要睡了，阴差阳错点进刀姐黄小刀的直播间，听到刀姐转述亦仁的一句话：

“如果一件事情反复出现在你面前，那就说明你们是有缘的。”

这句话像一把钥匙，把她全身的细胞全打开了。她脑海里像放电影一样，闪过一次次想进生财却没进的场景。这一次，内心的声音异常清晰：不能再错过。

她立马去刀姐朋友圈付款，于是就有了那个一边奶娃一边写文章的夜晚。

更有意思的是——她还没真正踏进生财大门，就先尝到了“靠近”的甜头。

加入之前的那个月，她反复听刀姐、七小、炮爷的会议回放，研究七小的赚钱知识分享，学习大佬们的思维方式，轻轻松松就变现了7000块。其中还包括酥酥朋友圈里一条9.9的信息，直接带来1000块左右的收入。

她再三强调：钱是其次。真正值钱的，是认知被撑开的感觉。

更让她有共鸣的是七小讲过一个卡点：对自己的要求特别高，写出来的文章满满正能量，结果只有少数人能接收，其实是在自嗨。而大多数人更喜欢的场景是——你把他的伤口撕开给他看，然后告诉他：我这儿有修复方案，你要不要？

她说：太真实了。

加入生财后，她收到了亦仁第一时间发来的一对一私信，像大哥哥一样叮嘱她别迷路，时间是当晚22:18。

进来之后，七小又给她重新发了“生财不走弯路”的神帖，她直呼太好用了，强烈建议收藏。还有新圈友指南，以及七小那篇著名的“40W评论数据分析”长文，专治小白痛点。

正当她琢磨怎么把自己的主干道——生命成长智慧践行——延伸出去时，翻到亦仁的一段话，让她又一次被击中。她说那个帖子让她强烈感受到亦仁极致利他的思维，还有那份真诚、格局和对人才的爱护。

她还因此在新人登记表“你希望获得哪些资源”那一栏里，认真写下了自己的期待。

来到这个圈子，她也开始体会到什么叫“乱花渐欲迷人眼”——精华帖太多了，感觉满地都是钱，不是在读帖子，而是在地上捡钱。里面最让她迷恋的氛围，是利他、共赢、爱和鼓励。

她在群里看到很多人因为靠近而变现，心想：这里藏龙卧虎，这么多大佬，靠近他们，岂不是能更快提升和拓宽自己的认知？

赚钱，反而成了顺带的事。

如果你也是刚进生财、还有点迷茫的新人，她想对你说几句掏心窝的话：

想一千遍，不如做一遍。管他呢，豁出去，万一成功了呢？

自信是一点一点做到的，从一块钱开始也行。跟紧大佬，生财有术，期待你的绽放。

她还立了一个Flag：借助生财各位大佬的影响力和监督，做到成长可视化——把成长过程、参加航海的心得，一五一十记录下来。

她感恩亦仁搭建了这个平台，也感恩遇见了刀姐、七小、静伟。她自己说得很通透：靠近本身就是一种成长，就看我们能不能看见、并接住老天爷送来的礼物。

有人问她：为啥我没收到亦仁的信？她答：可能是你一不小心划走了。

也有人在这个帖子下留言说：好的文字不需要技巧，真情流露就够动人。还有人在生财待了三年多，深有体会地共鸣。

最后，她借用亦仁的一篇短文作为收尾，也当作送给自己和所有人的祝福：

一切成交，都是为了爱。
