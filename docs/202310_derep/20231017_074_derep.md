# 从亏空200万到闲鱼月赚20万：一个00后店群玩家的逆袭实录

我是瑜大，00后，互联网这条路已经走了6年。

今年2月，我经历了人生至暗时刻。广州那家我合伙的直播公司直接破产，前几年在互联网里积累的200多万现金流一夜清空，连谈了很久的感情也在那个月宣告结束。清算完所有债务，兜里只剩3000块。

很多人以为我会停下来，其实那次跌倒让我更清楚：创业的起伏，本就是成长的代价。我的信念一直很简单——凡事杀我不死，必将使我更加强大。

低谷期我没选择硬扛，而是把失败的原因一条条拆解出来。3月，我带着这套认知all in闲鱼，开始搭建咸鱼店群模式。

从3月起盘，到5月稳定下来，团队平均月利润稳定在20万以上，月销售额破100万，而且是实打实的个人纯利。

这套打法并不是什么玄学，主要核心在于模式选择和利润管控。我走的是对接厂家直发，不做无货源赚差价的套利游戏。这样出货效率高，质量可控，利润才有保障。

很多人在评论区问手机能不能赚1000、能不能供货、是不是很累。说实话，早期确实拼，经常熬夜。但现在赛道已经跑顺了，精力消耗远没有起步时那么大。
