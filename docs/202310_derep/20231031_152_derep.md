# ('web3 生存指南', (2, 11))

各位生财有术的朋友，晚上好。我是Koda，一名web3创业者和加密资产投资人。创建了RichDAO社群，管理着一支加密基金，过去一年收益率大概40%，也曾在单笔交易里拿到过百万级利润。另外，我还深度参与过一个估值5000万美金的web3头部社交项目。常驻杭州。

不知不觉，web3航海已经做到第四期了。从去年12月第一期开始，我有幸参与搭建生财的web3入门体系，到现在，差不多2000多位圈友都从这里起步了。这期间，我对web3的认知也在不断变化。

今晚是这一期的首次分享，我想尽可能全面聊透一个事：普通人到底能在web3赚什么钱，怎么赚，以及现在为了赚钱能做什么。

首先统一认知：我们现在说的web3，是区块链圈子的说法，不是亚马逊、谷歌这些互联网大厂定义的。区块链技术目前真正创造价值的核心场景是金融。所以我一直觉得，与其叫web3，不如直接叫区块链金融，甚至可以理解成金融行业的一个子行业。海外很多课程也是这么叫的。至于区块链金融是什么、比特币又是什么，航海资料里有详细解释，这里就不展开了。

把概念理清后，我们再来看赚钱路径，我习惯分两个维度讲。

第一个维度：赚非金融行业的钱。适合没有金融背景、不做投资交易的朋友。说白了，把web3当成一个互联网金融行业就行。你可以创业，也可以打工。创业方向覆盖整个生态：挖矿算力、基础网络、数据处理、应用开发、上下游服务商，甚至KOL流量变现、知识付费社群，新行业里这些东西都有钱赚。打工的话，结合你已有的技能找位置，比如技术、设计、市场、社群运营。目前待遇最好的，一类是对标传统金融机构的数字货币交易所，另一类是拿到大量融资的创业公司，薪资不输互联网大厂。如果你已经厌倦原来行业，想换个新赛道，web3完全可以是备选——你的能力能复用。我认识一个朋友，从互联网技术岗直接转去区块链技术岗，上一轮牛市半年时间就上市变现了。

第二个维度：赚金融行业的钱，这是今天我想重点展开的。

先看历史。有金融能力又入场早的，2010年前后进场，到今天基本都有十位数资产。还有那些踩中早期红利的创业者，大多金融和互联网能力兼具，比如福布斯前20的赵长鹏，90后白手起家财富榜首的孙宇晨。

然后看几轮牛市。2013年，比特币从1美金以下猛拉到260美金，大批目光被吸引。2017年，资产发行方式创新，比特币站上2万美金，造富效应惊人，这轮进场还活到现在的人，资产普遍9位数以上。2020到2021年，去中心化金融爆发，比特币一度逼近7万美金，VC和散户疯狂涌入，这一轮在牛市初期进入且活到现在的人，多数也有千万级沉淀。

但我要泼一盆冷水：web3跑得太快，全球监管基本还是一片空白。没有监管的金融市场，镰刀多到数不清。所以普通人真正要紧的，是在这片暗黑森林里找到属于自己的确定性；找不到，就别碰。

金融，说到底就是个服务业，也是钱的管道。所有信息都与钱有关，只要能帮资金流动，就在创造价值，也就能分到利润。银行、券商、保险，本质上干的都是这个。

在这个行业，交易和套利是两条完全不同的路。交易，是你花钱买一个金融产品，未来卖出，赚或亏，比的是你对未来走向的判断。套利，则更像“发现机会”：同一个产品在不同市场卖不同价，你快速低买高卖赚差价，需要敏锐的商业嗅觉。

传统金融里，一级市场是发行市场，二级市场是交易市场，比如股票交易所、债券市场。但在web3，这个边界是模糊的。我们暂且把交易所发行后的交易算作二级，其余算作一级。传统金融里，普通人很难进优质项目的一级市场，但区块链金融给了大家这个机会，这是相对优势。

散户在这套体系里的角色，有点像传统互联网的淘客：项目方越优质、拿的钱越多，你能分到的空间就越大。有些玩法现在听着可能陌生，先记下来，后面的高手分享会具体讲。

两种经典玩法，一个是撸毛，一个是打新。

撸毛，本质上就是帮项目方做冷启动。比如web3应用上线后需要用户，项目方还没发代币，就用未来代币奖励早期用户，等代币正式发行再卖出去。打个比方：传统互联网给你5块钱下载一个APP，聪明团队可以让100万人下载，赚500万。撸毛就是这门生意。UNISWAP、OP、APTOS、ARB、BLUR、SUI都是著名案例。因为项目方手里握着大量VC的钱，每年都有充足预算推广，只要web3热度不熄火，这就是个百亿级市场。

打新，逻辑又有不同。项目方为了让更多人买自己的代币，会在交易所或发行平台低价发币；优质项目，大资金和做市商往往愿意在二级市场以更高溢价接盘。散户去帮项目方在一二级市场之间提供流动性，就能赚到价差收益。账面倍数，熊市10倍以上，牛市甚至百倍。不过大部分项目方有锁定期，早期筹码只能分1-2年卖出，所以实际收益率没账面那么吓人，但优质项目的确定性和利润空间仍然很大。最经典的案例有flow、Casper，以及今年上半年的SUI——生财圈友里就有人靠SUI打新，单笔赚到百万美金。

打新也分两类。一类是众人皆知的好项目，拼的是批量复制最小盈利模型的能力，适合专业工作室和能从1做到100的团队；另一类拼的是认知，项目往往是生态里的创新资产，懂的人不多，但参与就有极高赔率，比如今年上半年的铭文生态，生财小伙伴里也有人快速跑出百万利润。

看到这里，你可以把整个行业理解成以比特币为本位的周期游戏。就算什么都不做，早期拿住比特币，长期持有，也已经赚得够多了。但现在这个时点，真正高确定性的只有比特币和以太坊，其他都极其危险。以现在的价格，它们不可能再有万倍空间，但依然胜过大半个金融圈，长期年化20%+的确定性还是有的。眼下市场正处在熊市，大周期钱看起来好赚，可大部分人因为认知不够，根本拿不住。

也有人喜欢赌“下一个万倍标的”，那是风投思维。新型赛道的龙头，下轮牛市确实可能百倍千倍万倍，但很可能你挑了50个，49个归零，只有一个跑出来。所以要量力而行，这也是多数VC会选的高确定性策略。代表案例：链游AXS、公链SOL、MEME里的狗狗币和SHIB。

再回来说套利。套利和交易的区别在于：你先注意到同一个产品在不同市场有价差，然后快速操作赚钱。不成熟的金融市场里，这种机会从来不缺。比如之前航海嘉宾，在BRC20新生态里发现微信和Discord上同一个产品有5-10倍价差，迅速拿下第一桶金。经典例子还有合约与现货的价差套利、LUNA暴雷时的搬砖套利、中心化交易所和去中心化交易所之间的转移套利。想接住这种机会，你需要长期泡在市场里，有耐心，有行动力。

当你把上述任意一种方式跑通单个盈利模型，就可以撬动更多资金，去赚“管理费”的钱。到这儿，web3主要的赚钱路子，基本都覆盖到了。

最后聊聊怎么真正行动起来。很多人赚钱动不起来，根本不是执行力不行，而是没看到别人在轻松赚钱的真实画面。看到了，你自然会动。所以，丰富信息源极其重要。要经常问自己：我的信息源完整吗？它们之间是互斥的吗？我现在常用的是小圈子、付费社群、免费群、公域信息。完善信息源不容易，但它值得成为你在这个行业的长期课题。

投资最核心的一句话，其实就是“寻找属于自己的确定性”。但是简单，不等于容易。你要能控制住自己，只在出手前就算清楚“多长时间后能赚多少钱”时才动手，这相当难。只能靠不断实战，加上持续读经典投资书。我的航海资料里列了书单。

早期阶段，本金多少没那么重要，比的是你有没有真正下过场。投点钱、花点时间、不纸上谈兵，找到机会就动起来，这比什么都强。等你找到自己的0-1模型，下一个重点就是积累1-100的资源。这个行业已经不是蛮荒时代了，各领域都有高手。多和行业内的人链接，低成本资金、技术资源、投研资源，都是能在熊市里悄悄积攒的。

最后，祝大家都能在web3发财，也祝这次航海你收获满满。往期分享链接里能看到我的成长轨迹：2022年12月《我们在web3.0的赚钱机会》、2023年3月《如何在web3寻找我们的机会》。欢迎随时和我连接，我很乐意交朋友。
