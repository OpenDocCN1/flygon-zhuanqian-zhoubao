# 被骗几万💰的经验贴

上周末在龙哥盟刷到一个帖子，作者讲述了自己被同一个“靠谱朋友”骗走几万元的经过，看得我心里一阵发凉。这位所谓的老哥常年在社群里活跃，加了一大批好友，社交能力相当强。他给外人的感觉非常专业，说话也是一套套的，甚至在线下聚会和不少人都见过面。正因如此，大家对他的信任度极高，谁能想到最后钱一转过去，项目就石沉大海，人也开始玩消失。

目前，这个人已经被赚钱官方拉黑处理，但他的账号并没有彻底消失，最新微信名叫“考爸考妈陪跑”。如果你正好有他的联系方式，请务必对他向你推荐的任何项目打起十二分精神，别再重复同样的悲剧。

更让人担忧的是，作者在评论区表示，这个人在赚钱里添加了大量的好友，因此实际的受害者很可能远远不止已经站出来发声的那几位。底下也有网友追问：“当时要是签了合同，是不是就能追回来？”可现实却是，很多钱都是通过私域聊天的窗口直接转过去的，连个白纸黑字的凭证都没有。再加上“线下见过面”这一层滤镜，大家更容易卸下防御，而这种“见过面”的错觉，恰恰成了被收割的最大隐患。

评论区里还有一句挺扎心的话：“我从不轻易相信任何人，只相信自己。不管什么项目，都得一步步从0到1，再从1到10，最后做到100。”虽然这话听起来有点偏激，但在这样一个真假难辨的环境里，多一分谨慎永远没有错。

还有人额外提醒，一位叫“十字勋章”、打着“匿名信”旗号的玩家也坑害过赚钱圈的不少成员，款收了、承诺的交付迟迟不来，最后干脆拉黑了事。看起来套路如出一辙，大家一定要擦亮眼睛。

总而言之，无论对方包装得再光鲜、话说得再动听，只要涉及转账付款，先把最坏的情况想明白。赚钱本来就不容易，别让那些张口“带你赚钱”的人，反过来拿你的钱交了学费。
