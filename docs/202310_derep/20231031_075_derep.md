# 小红书流量的底层逻辑

最近有朋友在圈里问我，小红书的推荐流量到底按什么规则来的？发出去的笔记会被推给多少人，又由哪些条件决定？我是艾小飞。说实话，这个问题一问出来，我就猜到还有不少伙伴虽然天天发笔记，却一直没搞清楚平台到底怎么看待你的内容。

所以这篇想结合我自己的实操经验，认真聊聊笔记获取曝光这件事。

小红书给笔记的流量，从来不是单一维度决定的，而是由好几个模块共同支撑。大体上可以从五个角度去拆解：第一，平台的流量基础结构；第二，推荐流量是怎么产生的；第三，搜索流量在其中扮演什么角色；第四，付费流量何时介入；第五，一篇笔记从发布到被推荐，完整经历了一套怎样的流程。

把这几个方向弄明白，你就会发现，平台分发其实有迹可循，并不全靠运气。
