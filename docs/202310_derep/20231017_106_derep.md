# 用竖屏导图深度航海：108 份导图回顾 8 月航海之旅

今天想和你分享一个用竖屏导图“记录一场航海”的故事。

故事的主人公是圈友罗卜。今年4月他才加入龙哥盟，最初几个月的状态和很多新人一样，每天默默翻着精华帖、刷风向标，一边学习一边观望。慢慢地他发现：社群里的干货内容太密了，很多伙伴看着看着就卡住，不是内容不好，而是阅读负担太重。于是罗卜想到，自己不是擅长竖屏导图吗？能不能把航海手册、高手分享和精华帖都变成导图，让大家一看就懂？

这个想法在8月变成了现实。共读活动期间，他一个人完成了21份《龙哥益语》导图；8月底航海启动时，他更是把“一个人的创意”做成了“一群人的项目”——组建研学社导图小组，先做内部培训，再拆解任务分工。最终，团队一起完成了11本航海手册的86份导图，加上22份高手分享导图，总共108份。整场航海的内容精华，就这样被一张张竖屏导图收纳得井井有条。

这86份航海手册导图覆盖面很广：选品特训有23份，图书共读《学会写作 1.0》有12份，IP朋友圈运营9份，个人优势挖掘8份，社群发起人8份，公众号爆文写作6份，时间管理5份，商业访谈5份，ChatGPT+海外工具4份，资料整理3份，抖音图文电商3份。数量背后是团队的配合：有人负责拆解内容，有人专注视觉呈现，每一份导图都经过反复打磨。

导图的用途也不只停留在“整理资料”。航海前，他们用导图做自我介绍，帮助大家快速认识彼此；分享环节中，导图让嘉宾的干货更容易被消化，也让参与制作的组员更多地被看见。罗卜还分享了一个独门技巧：如何快速听完一场直播，直接产出可用的竖屏导图。这个方法对很多“听完就忘”的小伙伴来说，真的非常实用。

除了方法论，他还谈到了竖屏导图的商业变现路径、航海导图制作的核心要点，以及这次经历带给自己的成长。与其说是108份导图的产出，不如说是一个人在实践中完成了从“单干”到“带团队”的跨越。
