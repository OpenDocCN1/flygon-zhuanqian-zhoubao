# 三年全职做📕，我是怎么从焦虑到松弛的

前两天在阳台晒太阳养花，家人笑着说我这日子过得跟提前退休似的。不怎么见朋友，不用挤地铁通勤，早上睡到自然醒，醒来澆澆花、翻翻书、泡杯茶，也就这么一天过去了。

其实还真有点像。

三年前我裸辞转做全职博主，当时嘴上还挂着“不行就回去上班”。没想到一晃三年过去了，再也没冒出过回去打工的念头。就算生活再紧巴，我也觉得不会比上班时更糟了。

主要还是习惯了这种自由。被规矩框住的日子我实在待不下去了。再加上这几年一路摸爬滚打，做这行做出了些底气。就算偶尔遇到瓶颈卡住，也能很快调整心态，补技能、跟趋势走。

心态的变化也很明显。刚开始那阵子整个人都是慌的，现在却能从容应对。身边做自由职业的人不少，有比我早入行的，依旧走得稳当；也有刚起步的小伙伴，经常来我这取经聊天。

对“自由职业不稳定”这件事，我的看法也变了。过去我总觉得不稳定就是作息不稳定、收入不稳定。现在想明白了，真正的稳定是内心的稳定，是工作节奏的稳定。

比如我现在虽然时间自由，但作息很规律，基本还是沿用朝九晚五、双休的框架，只是真正投入创作的时间只有以前上班时的三分之一。至于收入，波动确实大，有时半个月过去一分钱没进账，有时月初就把上个月的总额赚回来了。算下来，平均水平远高于我以前的月薪。

总有人会说自由职业难搞，但说这话的大概率还在最煎熬的成长期，既没办法自洽，也没法立刻看到改变。

说到底，不管选哪条路，坑都不会少。朝九晚五看着安稳，却要拿通勤时间去换，还得接受那种大体不变的死工资。自由职业省去了路上折腾，但你要自己主动去试新东西，去扛收入波动。

就目前而言，做全职博主这三年，我过得挺舒坦，也很想把这份轻松自在的日子一直延续下去。
