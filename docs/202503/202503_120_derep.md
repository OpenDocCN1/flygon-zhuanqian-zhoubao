# 半年副业复盘：我在赚钱的成长笔记



## 复盘过去半年，我在副业工作的收获与心得

作者： 七天@龙哥盟

日期：2025-03-12

加入赚钱才半年，体感像经历了整整三年的沉淀。超群老师甚至打趣，要我来讲讲“半年抵三年”的速成逻辑。

趁着最近梳理思路，我把这半年零碎的感悟整理成了阶段性复盘。

**1. 从盯目标到建系统，副产品才更稳**

过去我总把精力押在某个具体结果上，比如要出一篇爆款、要把发帖数拉上去。心态紧绷，还容易被短期消耗拖垮。

后来才明白，目标只是终点的一个点，系统才是铺开的网。当我开始琢磨流程怎么跑得更顺、机制怎么搭得更活，不再死磕数字时，好的结果自然长出来了。

这其中的转变主要体现在三处：
a. 效率靠系统兜底，而不是靠拼命。把重复性动作流程化后，我腾出了更多时间去做创造性工作。
b. 目标会失效，系统会延续。做传术师激励时，我没再追一刀切的短期KPI，而是搭起一套能持续滚动的内容生产和成长框架，反而效果更长久。
c. 视角从关注点挪向杠杆点。长期复利的事才值得反复投入，比如协作方式、用户路径，而不是一时的高光数据。

以传术师运营为例，我不再一味催发帖量，而是搭建可复用的生产与成长体系。结果是数量上去的同时，优质内容也能稳定流动。

**2. 相信常识，也敢为判断买单**

准备乔迁仪式时，龙哥问我能不能给个主题方向。我抛出了一个好奇：为什么他在逆势时选择了一条不一样的路。他立刻拍板，就用这个。

活动当天龙哥的分享点醒了我：悲观是情绪，乐观是行动。三年前花1000万租下整层楼做新办公室，看似重手，实则下限可控、上限开放。他要的不仅是空间，更是把人聚拢、把项目做深的可能性。

我从中get到：敢给自己的判断下注，下注的筹码大小，本身就决定了执行力度。

**3. 成长感和真实度，比起步就正确更打动人**

龙哥曾给我一个任务：2025年帮助100个人做IP定位。起初我很犹豫，怕自己的建议不够专业。

他一句话点醒我：IP的本质不是正确，是真实。

真正能打动人的不是一个完美答案，而是一个有血有肉、在路上的人设。允许试错、坦诚表达，反而更容易产生共鸣。

他还给我的IP做了定位：不要当“专家”，要当“养成系”。专家强调权威正确，养成系强调成长过程。这个标签让我轻松很多，因为真实的成长比起初的正确更有温度。

**4. 表达本身就是生意**

赚钱的路径大致两条：一是把手上的业务做精，让业务自己带业务；二是持续对外表达，让更多人看见你的能力。

龙哥常说：越分享越幸运。传术师们愿意敞开经验，正因为内容一旦流出去才有势能。表达让经验流动，分享让价值放大。

**5. 能随时听懂底层逻辑，是最大的福利**

群里讨论《不要攒局》时，我顺便请教了龙哥的看法。

我的理解是，文章里被广泛转发的金句核心是：在激烈竞争中需要高密度投入才能做深，而攒局很难产生这种密度，所以不如自己搭局。

龙哥的补充是：资源并非创业成败的主导因素，这点大家基本认同。但“攒局”只是个动作，有成有败。所有观点都成立，前提是有约束条件。

他说的一句话我印象很深：智慧在于看清观点的边界，并能同时容纳两种看似相反的结论。

**6. 战略清晰，细节再乱也能自我修复**

看一家公司时，容易被表面的混乱带偏，甚至觉得要不行了。但一家公司能不能活，取决于核心发力点是否清晰。即便末端再像草台班子，只要核心策略在线，纠偏只是时间问题，甚至末端细节也能自运转。

有个类比很有意思：人没了四肢躯干还能活，没了躯干只剩四肢就不行了。回到公司，也是一样，要盯住核心战略。

做事亦然：把最重要的事不断抬高优先级，把紧急不重要的事尽快甩出去。做社区也同理：优质内容、社区氛围、让人被看见，这三件事不能丢。

有人创业爱做数学题，像培训这样清晰可算；有人爱做语文题，说不清具体SKU，但擅长经营品牌心智。路不同，只要走对自己的路就行。

这几个月看着赚钱小组、mini航海一点点成形，才意识到老板的蓝图其实很早就在那儿了。老板是先相信再看见，我是先看见再慢慢相信。

**7. 用10倍思维换游戏**

最近的一个新认知是：赚10万和赚100万的难度，可能是同一个量级。关键不在堆努力，而在换到更高杠杆的游戏。

航海家见面会上，95后怡然靠外卖CPS一年引流1000万私域用户。她抓住了消费降级与刚需的交点，用科学效率做爆款。

这让我想起《10倍比2倍容易》的核心：10倍的目标会逼你放弃无效忙碌，聚焦在自己最擅长的杠杆上。10倍增长要的是清晰和专注，而不是疲惫的奔跑。

**8. 选创业公司的三个关键词**

如果有人问我怎么挑一家好的创业公司，我现在的粗略标准是：
1️⃣ 有机态组织：内部持续流动，有自我疏通的能力。
2️⃣ 有反思力：尤其是中层以上，靠复盘推演未来，而不是拍脑袋。
3️⃣ 会赚钱：现金流是抗风险的硬底牌。

**9. 赚钱生态里最大的收获：两件事在并行**

在赚钱的生态里，我最大的体悟不是学会了某个方法论，而是看清了价值创造者的共同行为：
1️⃣ 在确定性里建系统，比如传术师体系；
2️⃣ 在不确定性里种可能性，比如和圈友一起做的联合办公空间。
