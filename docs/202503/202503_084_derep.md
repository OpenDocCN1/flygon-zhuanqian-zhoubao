# 熟人一起创业，钱怎么投、怎么分，才不会伤感情

很多想和朋友一起开店的人，第一个卡住的地方都一样：起步要掏多少钱、赚了钱怎么分、后期扩张又怎么算。这个问题问得不算完整，但我还是把自己踩过的坑捋一下给你。

**一、0到1阶段的启动资金和分成怎么定**

别凭感觉拍脑袋。先把开店可能花到的钱全列出来：注册、开办、加盟、装修、设备、各种证照、三个月房租、人工、原材料、日常运营。能想到的全写下，然后总和直接乘以1.3，基本就接近真实成本了。

钱怎么投，取决于谁扛事。能力与责任要匹配投入，多投多得和多劳多得之间找个平衡点。核心创始人必须牢牢守住51%以上的控制权，这是保证决策不扯皮的底线。创业不是做慈善，股份占比也是对创业本身、对金钱、对人性的一种敬畏。想随便入股分红的初级合伙人，基本没准备好。

**二、职责划分要不要分得特别细**

理想状态是越细越好，现实是根本分不完。0到1阶段，大家都得救火，前厅后厨财务采购营销售后，谁空谁上。一个人身兼数职是常态。

但要记住一点：责任越模糊，内耗越大。贡献值这个东西，不管最后是做大了还是做倒了，都说不清。所以分工要尽量明确，哪怕执行时要互相补位。

**三、0到1跑通后要做1到N扩张，钱和收益怎么算**

开店这事比较特殊。如果前期合作很顺，可以沿用原来的投入分配机制，保持稳定。

另一种常见做法是引入新资源。比如最终变成七个股东七个店长，每人对自己负责的店投入大头、拿大头收益，其他人小比例跟投来分摊风险和兜底。核心逻辑你get到就行。

**四、跨城市扩张，兼顾职能和区域负责人行不行**

一个人既管一个职能板块，又管一个城市的店，招商运营一把抓，听起来很高效，实际上很难玩转。除非你已经具备连锁化能力，可以干脆转型成招商加盟公司。

补充一个经验：单城多店到10家以上，规模效应就很明显了，平均成本能降20%，利润能提升20%。在能力范围内，先把一个城市做深，比盲目多城市铺开更稳。

**五、合同是必须的吗**

必须，而且要极致细。股东协议、股权结构、分红机制、权责边界、退出机制、股权转让与回购、知识产权归属包括品牌配方系统、线上线下资产包括自媒体账号私域流量、竞业禁止等等，全都要写清楚。

先小人后君子的心态对。合同执行起来可能有各种博弈，但没有合同，一吵架就是撕破脸。

**六、公司主体怎么选**

前期可以个体户起步，后续必然要成立公司来承载品牌、技术等核心产权。这是自然演进的过程。

等业务做大涉及资本运作时，可能需要控股架构，会更复杂。但那时你基本已经懂了，不懂也有专业的人带。只是股权架构混乱，很多好项目资本看一眼就走了，这个教训一定要提前留好余量。

最后说几句大实话。

想得越周全越好，但别指望能想得周全。想太多就等于没想，方向太多就等于没方向。度自己把握。

嗐，本来没事干嘛非要创业呢。
