# 奔五零基础主播，7个月把实体女装店搬进直播间做到月销13万

这是一个几乎没有任何直播基因的人，做直播电商的真实记录。

主角是个奔五岁的实体女装店老板，电脑基本不会操作，直播脚本全靠手写，过去自己从未在直播间下单过。一切从零开始，没有投放预算，也没有所谓的套路技巧。

就是靠硬扛，7个月时间，把一个冷启动的直播间做到月销13万GMV。

我是龙哥，在赚钱圈子里待了5年。过去这几年跟着圈友的分享和航海的思路试过不少项目，有小成也有试错。这次想分享的是去年到现在一直在孵化的一个实体女装直播项目。

没有爆款神话，没有惊艳数据，也不需要你会什么高阶玩法。就是两个普通人一边踩坑一边解决问题的笨办法，想做一个能稳定养活一两个人、长期做下去的生意。

全文不投流、不靠黑科技，完全是硬起号的過程。我把整个来龙去脉梳理清楚了：项目是怎么起来的、怎么准备的、直播间里遇到什么问题、又怎么一点点解决的、踩了哪些坑、最后沉淀了哪些能用的经验。

如果你也在考虑把线下生意搬到线上，或者想看一个零基础转型的完整复盘，这篇万字实录可以看看。
