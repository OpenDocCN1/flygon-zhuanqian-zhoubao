# 如何让一家公司成为全球比特币持有量最多的？听听 MicroStrategy 创始人 Michael Saylor 的底层逻辑
作者：龙哥

如果要复刻 MicroStrategy 的比特币之路，先别把它当成一场普通的投资博弈。

在吴说的专访里，Saylor 给出了一句点破关键的话：你必须用物理学家、科学家、数学家的视角去拆解世界。唯有真正搞懂系统运行的底层规律，你才会看清比特币的本质——它不是虚拟币，而是一个数字能源网络。

人类有史以来第一次，出现了这样一个真正意义上的全球化数字能源网络。它开放、通透，随时可以接入。只要你接入进去，就等于站在了通往繁荣的入口。

这正是 Saylor 一直在做的事。不是押注价格，而是押注网络本身。作为商业公司，他把比特币看作一种可编程、可叠加的数字能源，然后用企业的体量持续接入、持续积累。

所以问题从“要不要买比特币”变成了“如何以最坚定的方式，成为这个网络上持仓量最大的玩家”。

答案很简单：用科学的认知建立信仰，用公司的现金流持续买入，用时间换取规模。

这套打法，最终造就了今天世界上比特币持有量最多的公司。
