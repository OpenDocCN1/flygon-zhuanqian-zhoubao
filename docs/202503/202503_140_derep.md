如果你有关注 Cursor 和 Windsurf，最近它们都内置了对 MCP 服务的支持。这个 MCP 到底在玩什么花样？

MCP 全称 Model Context Protocol，即模型上下文协议。它是一个开放的行业标准，用来让大语言模型和外部数据源、各类工具无缝对接。

打个更直观的比方，就把它当成 AI 世界里的 USB 接口。只要工具按这个接口规范开发，就能像插U盘一样即插即用。

换句话说，你可以按需给自己的编程助手扩充各种外设能力，把它从单纯的写代码工具升级成一个全能的智能体。

下面这篇就是手把手演示，如何借助 MCP 把 RooCode、Copilot 这类 AI 编程工具，变身成一个能自主检索、分析、编程、交付页面的超级智能体。
