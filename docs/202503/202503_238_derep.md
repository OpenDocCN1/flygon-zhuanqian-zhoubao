## (20 赞)#线下聚会# 凌子期和 Vicky 老师《把日拱一卒的业务拍出获客视频》

作者：小 L 姐

日期：2025-03-08

2025年3月1日，宝藏主理人凌子期和 Vicky 老师的分享会上聊到一个核心：无论做什么内容，观众要的都是一个鲜活的人和一个有血有肉的故事，这本身就是一种生命力。

Vicky 老师现场给了几条很实用的操作建议：

1. 把身体的微小变化记下来。比如某刻身体突然僵住、眼眶发热想哭，这些躯体信号往往藏着内心最真实的叙事。也可以反向追踪自己刷内容的偏好，哪些题材会让你上头、被触动，反复问自己“为什么会被它打动”。
2. 去找异常点。就是你跟别人不一样的地方，这个需要借助外部视角来校准。
3. 有意记录观众的反馈。公司年会、公开演讲、日常发言时，都可以观察现场反应。一方面复盘自己的表达是否到位，另一方面能判断哪类听众买你的叙述方式，通过观众分层找到真正会被你吸引的那群人。
4. 好素材要反复用。同一个故事可以在不同场合拆解使用，提炼出最能支撑观点的人和情节，其他枝节适当弱化即可。
5. 刻意训练3分钟镜头叙事。生活里随时可能递给你一支麦克风，能不能在三分钟内讲清一个故事是基本功。
6. 多制造冲突感。人在情绪激昂、尤其是愤怒时，表达欲最强，内容也最有张力。

凌子期老师的分享则更偏执行路径：

1. 普通人怎么起步？先动起来，实操中自然会暴露坑点，也会清楚哪些环节可以外包。
2. 抄爆款是入门的快车道，但想长久必须靠“IP 有故事”来沉淀。
3. 账号内容可以分三类放：能引流的爆款故事、能立牌坊的品牌故事、能背书的专业案例。
4. 多打辩论能有效提升思辨力，对内容结构帮助很大。
5. 别拿自己去跟天赋型的短视频IP比，先拆解优秀片段，大量堆量练习。

会上还推荐了几位值得学习的账号：赤焰男孩、老蒋巨靠谱、薛辉短视频课。
