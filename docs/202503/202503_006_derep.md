# 为什么李嘉诚卖港口一出街，全网都在盯着看？
作者：龙哥

说到底，因为这条消息正好踩中了新闻最容易让人上头的那几块点。

伯内斯在《舆论的结晶》里引用过埃尔文的判断，新闻能不能火，大致看四个维度在不在：我们偏爱自己爱看的内容；我们对事件里的人和背景越熟，关注度越高；新闻对我们生活的影响越大，我们越在意；新闻里的人物和事本身分量越重，越能抓住眼球。

李嘉诚这次的港口交易，几乎把后三条全占了。

先说人。李嘉诚是谁？华人商业圈的标志性符号，公众对其的认知度已经远超普通企业家。熟人效应直接拉满，大家看到名字就会点进来。

再说影响感。现在是一个很敏感的节点，港口、美国财团、中国利益，这些关键词一组合，很容易让人产生“这事跟我有关”的联想。哪怕普通人并不直接参与港口运营，也会下意识担心国家安全、外资走向这类大叙事。越觉得会影响自己，越停不下来。

最后说分量。主角是首富级别的李嘉诚，交易对接的是中美两大市场，香港特首、媒体舆论场也都被牵进来。人物重要、版图重要、议题重要，三重重要性叠加，哪怕当事人想安静处理，外界也不可能让他低调。

所以这并不是简单的商业新闻，而是一则自带放大镜的故事。熟悉的人、关乎影响的议题、重量级的参与方，凑在一起，不火才奇怪。
