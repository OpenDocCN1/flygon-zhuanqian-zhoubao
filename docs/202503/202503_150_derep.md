# 苹果手机图文采集配置

整体逻辑：借助快捷指令调用 Coze API 来驱动工作流，核心凭证为 Coze 的 token 与 workflowid。

第一步 Coze 工作流首先把笔记的短链展开成长链，若本就是长链则直接保留，随后请求📕接口抓取详情。
第二步 抓取结果经 JavaScript 脚本整理成 JSON 保存成变量，再发起飞书表格 API 写入。
第三步 飞书表格接口需完成授权，并提供表格的 base 路径与 sheet id。
第四步 我提供的模版会自动把图片链接转为附件，并在飞书表格中展示封面图。
第五步 基于该模版，标题和正文会触发 DeepSeek 自动创作。

最终使用感：打开📕笔记链接，点一下就能同步到飞书多维表。教程刚上线，后续还能扩展更多玩法，比如一键拆解爆款视频、爆款图文做二次创作，基于对比生成词云等，持续完善中。

## DeepSeek 数据分析教程

1. 用电脑浏览器打开 DeepSeek 官网 [`www.deepseek.com/`](https://www.deepseek.com)
2. 点击“开始对话”，未登录会跳转注册。注意先注册才能使用。

![](img/b7665ca4f9d10167d09c2cafd9cf04c7.png "None")

3. 登录后进入对话窗口

![](img/cb09386cf84253ee0471dec17675a935.png "None")

4. 打开飞书多维表，点击右上角“...”，选择“导出”- Excel/CSV 文件

![](img/f2c25cd180340d8ffa792b0759c551b8.png "None")

5. 默认 CSV，点击“下载”

![](img/ab7678385548fd284fe5738fd5035717.png "None")

6. 下载后把文件名改为 one.csv，方便上传

![](img/6c144eb7228a52729ff06ecf23731298.png "None")

7. 在 DeepSeek 对话框点“大头针”图标上传 one.csv

![](img/ea25de22efe8f7426cef94ba2ccac3a2.png "None")

![](img/4451875c3a4aa7e7ffaa6c8dbefa2590.png "None")

8. 把下方提示词复制到对话框发送，DeepSeek 会自动分析笔记

**提示词模板：↓↓↓**

根据 one.csv 文件是📕笔记内容，请分析出笔记的内容结构、标题公式、情感分析、关键词，标签分布、智能打标签、笔记内容结构。

1.标题公式：根据笔记标题划分笔记类型，分析标题特点和结构，最好能总结出公式、常用的关键词

2.情感分析：哪些关键词或内容能调动用户情绪、吸引用户

3.关键词体系：关键词类型、关键词出现次数、关键词在标题、笔记内容中出现频率

4.笔记标签：标签类型、统计重要标签

5.笔记内容结构：分析内容的结构内容并统计归类，优缺点等

6.根据数据详细说说：用户核心需求、内容优化建议等

7.分析完内容后，统计你分析的数据和结论，写十个标题、写十遍笔记内容、写十个标签。
