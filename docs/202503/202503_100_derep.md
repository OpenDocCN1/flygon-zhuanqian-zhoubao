# 到底要all in一条船，还是两条船一起试？

最近很多朋友在航海项目报名截止前来问我同一个问题：

是把全部精力押在一件事上，死磕到见顶，再滚雪球放大？
还是见好就收、边走边换，用多个项目轮换来找到真正能长期干下去的赛道？

这个问题问得很本质，其实就是在问：我该长期深耕，还是不断试错换赛道？

我的看法很简单：

当一个决策是可逆的、试错成本又低到可以忽略时，别在原地反复权衡。立刻拍板、先上车再说，走了几步之后答案自然就出来了。

你最坏的结果是什么？报两条船多花一个名额，保证金拿不回来也就199块。相当于请我吃一顿饭的成本，这点学费换一次实战经验，太值了。

纠结不会帮你避开风险，反而会让你错过最后的报名时间。先动起来，错了再调，远比完美计划却一事无成要强。

评论区里大家也说得很直接：
Victor : 别犹豫
Hugo : 直接冲
浅笑 : 可逆，成本低
追梦 : 试错成本低，就干就完事

所以今晚就别再纠结了，选一个、或者选两个，报名完开始干，前方自有答案。
