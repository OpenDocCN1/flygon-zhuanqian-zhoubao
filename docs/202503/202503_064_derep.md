# 从路边摊到百万账号：一个摆摊自媒体的实战拆解
作者：龙哥

在赚钱圈里认识一位做摆摊自媒体的操盘手，网名叫成成。他的玩法很直接：白天真摆摊卖小吃，顺手把制作过程拍成短视频，晚上用这些内容卖小吃配方教程。

目前他团队已经在多个小吃赛道把培训类账号做到了品类第一梯队。

最典型的数据来自去年的提拉米苏项目。只用了26支视频，就拿到了1.5亿的自然播放量，单项目变现突破55万元。
