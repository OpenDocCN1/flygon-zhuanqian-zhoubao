# 从滨海一线走出来的招商笔记：5年实战，从0到1怎么谈项目
作者：龙哥



大家好，我是龙哥，笔名半扇咸鱼。在潍坊滨海开发区干了五年一线招商，2019年到2023年基本都在跑市场、谈企业、陪落地。做了三年财友，一直想把一线踩过的坑和看准的机会整理出来。越分享越通透，这次就把这五年的体感沉淀成一套可用的0-1实操笔记，干货多、案例多，看完能直接理解地方招商到底是怎么玩的。目录我放好了，想看哪块直接跳。

* * *

**问答实录，聊聊当下最现实的问题**

**问：全国统一大市场和公平竞争审查收紧后，返税政策基本不能明说了，招商部门还能用什么抓手把外地企业招进来？**

答：核心还是回到地方有什么、能给企业什么。最近坊间都在说招商已经变成投资招商，像合肥那种重仓模式。确实，靠财政撬动投资需要两个硬条件：第一口袋里有钱，第二有一支能看懂产业、算清账的投研队伍。很多欠发达地区这两样都缺。

我们滨海能打的牌是地缘禀赋。手里有国家批复的几万亩光伏用地，可以拿出来做合作开发；两碱、新材料、医药化工这些赛道已经成群成链，成熟的化工园区和用地指标都在，而且性价比明显。江浙那边化工地块动辄五十多万一亩，我们这边不到一半，园区配套也齐全。对实体制造业来说，算账最实在的是能不能在可预见的时间里稳妥投产、把钱赚回来。

另外，地方资源是动态发现的。之前我一直觉得滨海不适合搞养殖，直到实地走了一圈，才发现水质条件其实很好，又叠加上海洋牧场的规划方向，这就又多出一个可操作的切口。

至于税收返还，现在基本是“对赌”逻辑。头部企业可以谈条款，中小企业根本不把它当决定因素，亩均税收达标难度大，返不返意义不大。

**问：要是真做到了亩均税收对赌线，返还还有操作空间吗？**

答：过去有，现在基本没人明面上提了。政策环境变了，再谈返税很容易被理解为地方自选动作，被查到就是合规风险。当然市场上总有各种变相的玩法，我就不展开了。

**问：你们是给政府做招商服务的机构？**

答：不是中介。我们本身就是开发区管委会下面的国企，招商引资是主业。
