# 为什么德鲁克写管理，却让人读得像在读散文
作者：龙哥

最近把德鲁克的《管理的实践》啃到一半，越读越上头。

说他是现代管理学的开山鼻祖，这话没错。但真正让人不放下的是，他本人就是个实战派出身，书里藏着浓浓的生活气息，完全不像一本理论著作。

《管理的实践》这本书，正是他成名的那本。别指望会看到满屏的术语和艰深的论证，他的表达很松很轻，还带点幽默，甚至有种读诗的感觉。

昨晚翻到人力资源那一段，我就被钉住了，摘一段给你体会一下那种味道：

企业招人，招的从来不是一双手，而是一个完整的人。IBM 的案例就很说明问题，买人手是不行的，得把人本身一起请进来。恐怕没有哪种关系，比人与工作更需要全身心投入。

《创世纪》里说，人类本性里并不包含工作，但工作很快成了生活的一部分。“你必汗流满面才得糊口”。这既是惩罚，也是恩赐。正是工作，让人生变得可承受，也变得有意义。

唯一可以排在工作之前的，只有与造物主和与家庭的关系。因为这是人生的根基。生命、成就、社会、艺术、历史，所有这些，都离不开家庭、信仰与工作的共同支撑。

如果我们把人当成普通资源去盘算，觉得人力跟铜矿、水电没什么区别，那我们就会去寻找所谓的最优配置方式。

从技术角度看，企业确实得先盘点清楚人最大的长处和短板，再围绕这些来设计组织。人力资源有个独一无二的特质：它会思考、会整合、会判断、会想象。这是它唯一打不过机器也会赢的地方。至于体力、熟练度、感知精度，机器早就全面超越了。

可与此同时，我们又不能只把人当成生产要素来看。工作里的人，首先得是人。得承认人的道德性与社会性，让工作的安排去契合人的本性。作为资源，人力可以被企业使用；作为人，只有他自己才能真正把自己用好、把潜能发挥出来。

这才是人力和其他资源最本质的分界。人的独特性在于，他对是否工作、有没有心工作，拥有绝对的自主权。很多强势的管理者都忘了这一点。你可以消灭反抗，但消灭不了工作的动机。想要事成，必须先改变动机。
