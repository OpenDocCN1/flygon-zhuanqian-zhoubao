# 0 编码基础小白 4.5 小时成功建好一个游戏站
作者：龙哥

作为一个完完全全没有编程背景的小白，我花了仅仅一个下午——从中午12点到16:30，就把一个游戏网站成功搭建起来了。前后算下来，刚好4.5小时。

先简单介绍下自己：我是龙哥，加入赚钱已经13个月，这是我的第一篇分享帖。去年3月，我去了杭州的千人见面会，现场那种人人都在琢磨怎么赚钱的氛围，真的让人备受感染。

目前我手头有两个团队：一个专注系统定制开发，以前主要做政府项目，但因为一些大家都懂的原因，我们决定收手，转向服务B端客户；另一个团队做视频号直播带货。看了龙哥的《超级标》系列之后，我下定决心all in AI+出海，想闯出一条新路。

这次能这么快把站建起来，必须特别感谢赚钱Web网站开发航海的教练团。他们编写的手册详细到堪称“喂饭级”，每一步都写得清清楚楚。还要感谢@良辰美教练，还有其他教练和群里的热心的船友，我那些“超级小白”级别的问题，他们都没嫌烦。尤其是良辰美教练，我截个图问一句，他都能一五一十地解释到位，真的是像一勺一勺喂饭一样细致，心里特别感激。

借这篇帖子，我也想跟大伙儿说：别因为觉得难就不去碰。很多时候，不是你做不成某件事，而是你打心底里不想做，才让事情显得格外难。龙哥常讲，要做难而正确的事。希望每个人都能顺顺利利。

我是南宁人，最后借用刚刚结束的赚钱南宁见面会的口号：让我们一起龙哥盟，邕抱财富！
