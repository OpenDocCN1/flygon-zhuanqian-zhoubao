# 2万块，4个月，一个人把大半个中国加两个国家跑了个遍

去年裸辞后，我就揣着背包出发了，没做攻略、没定路线，就这么在路上晃了整整四个月。吃住加交通总花费2万出头，乍一看是穷游，实打实体验却一个没少，吃也没抠过。

一路走一路踩坑，也慢慢摸出了适合“有空且想省钱”的人能直接用的玩法，写下来希望能帮到正在犹豫或已经准备出发的你。

这趟旅程最大的意外收获不是景点，而是人。因为是一人行，反而更容易和同路人搭上话。每天几乎都有旅伴同行，年龄、职业、背景都完全不一样。真正让我懂了，旅行的价值从来不是把网红打卡点集满，而是沉浸在当地的生活气息里，被那些细碎的人文瞬间打动，对生活多一份热爱。
