# 人有三种焦虑，无人可以避免
作者：龙哥

这一生，有一样东西谁都躲不掉——焦虑。

但你可能没想过，焦虑的底色，翻来覆去就三种。

**第一种，是“死亡焦虑”。**
因为生命有倒计时，你总嫌自己太慢。
内心那个声音不停在催：“快一点，再快一点！得赶紧成功，不然就来不及了！”

**第二种，是“无意义焦虑”。**
你怕自己人间走过一遭，却像从没来过。
于是，成功成了你证明自己存在的方式——好像只有做出点什么，才能确认自己不是人群中可有可无的一个。

**第三种，是“自责焦虑”。**
深夜复盘时，你一遍遍在心里骂自己：
“那件事怎么就做错了？那句话怎么就说出口了？我怎么总是这么笨？”

三种焦虑，你可能只中一种，也可能全部中招。
就像有人在评论区感慨：“完了，我三种全占了。”

但我想说的是：
焦虑不可耻，它恰恰说明你在乎。
看清它的来路，你就能少一点被它摆布。
