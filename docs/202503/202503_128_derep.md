# 武彬老板提到的几个关于 AI 业务和做 IP 思考
作者：龙哥

关于AI业务和打造个人IP，武彬老板最近分享了不少实在话。他目前已经牢牢站住了“AI+电商”这个标签，最近频频出现在各类访谈节目里，相信大家对他多少有些脸熟。我把他对AI业务和做IP的几个思考整理了一下，分享给你。

第一，做AI+垂直行业，反而是创业公司更有机会的赛道。大厂对垂类场景的理解，通常不如深耕这个行业的公司，而且他们大概率不会专门为了某个细分领域去做产品。这个空档，正是中小团队可以发力的地方。

第二，聊到“培训”这件事，行业内不少技术型公司是看不上培训的，觉得只有赚不到钱才去搞培训。但武老板的看法不一样——他做的to B工具本身就包含培训环节，现在只是把它单独拿出来收费，因为这个环节本身就有很大价值。

第三，IP能顶替掉公司一百个销售。他做起来之后发现，IP会天然吸引B端客户主动找上门，根本不用销售在外面跑。接下来再用培训去筛出真正有合作意向的客户，最后把合作落地。

第四，他为什么做AI MCN？最初的目标很简单，就是想给AI工具做MVP和PMF验证，验证跑通了再卖给B端客户。做这个的过程中，业务自己跑通了，还实现了盈利，于是发现可以把它放大——业务就是这样“长”出来的。

第五，做老板IP，他有自己的一套方法论：不招人，自己跟对象两个人折腾。内容主打专业化。前期靠做客访谈IP来起势、破圈，之后再通过输出专业内容和直播，持续留住目标用户。

第六，他把直播看作一个好杠杆，花一次时间就能让一大批老板深度认识自己。就拿去遥望聊生意来说，客户连他高考各科考了多少分都清清楚楚。

第七，他做公司的方法是事必躬亲，什么都自己上，好奇心也特别强。

下周三18:30，他会有一场直播，专门深度聊聊AI+垂直行业的创业新机会。有问题的话，评论区可以先发出来。
