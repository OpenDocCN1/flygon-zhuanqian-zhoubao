# 个人项目大赛要来了，想组队备战的圈友这边集合
作者：龙哥

最近“📕”正在推一个面向个人创作者的官方竞赛，圈子里的朋友看到消息后，不少人已经摩拳擦掌。也有人有点犹豫：自己没系统学过编程，能参赛吗？

其实不用太担心。AI 辅助工具已经能很好地完成代码编写和调试，技术背景不再是报名参赛的硬性条件，更关键的是你想做出一个什么样的产品。

要是你决定试试，又不想一个人埋头准备，欢迎在这条内容下方留言区回复一个“1”。我会把大家聚合到一个临时协作群里，后续可以在群里同步进展、交流思路、互相催进度。

再补一个很配的彩蛋：三月航海计划中专门设置了两个实战方向，一个围绕 Web 端站点制作，另一个围绕 iOS 端应用开发。两者和这次大赛的目标高度同频，正在备赛的话，结合起来做会顺手很多。
