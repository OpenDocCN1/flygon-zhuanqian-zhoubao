# 被扣200块清洁费后，我硬是要回了一半

你退租时，有没有被房东用“不干净”这种理由扣过钱？我最近就遇到了，而且差点自认倒霉。

年后我从义乌搬到杭州上班，租约正好在2月底到期。为了不在退房时留话柄，我特意在23号折返回义乌，把房间从里到外仔细打扫了一遍，临走前还拍了不少照片留底。当时房东说自己不在家，要晚点再来看房。结果这一等就是好几天，最后他的理由是“地面没弄干净”，要收200元保洁费。

说实话，听到这个说法我是不服的。房间是我特地返程打扫的，照片也拍得清清楚楚。200元说多不多，但这种钱真不该交得不明不白。于是我把照片和情况整理好，冷静但坚定地跟房东沟通，明确表示不接受这个扣款。折腾了一番之后，房东终于退回了100元。

这件事给我几个很深的感触：

1. 租房全程都得留证据。入住时的状况、退租前的清扫情况，最好都用照片或视频固定下来。真要发生不愉快，手里的记录就是底气。

2. 别因为钱少就懒得争。很多时候，房东或二房东就是看你好不好说话。哪怕你把屋子收拾得再利索，对方想找茬也总能找到说法。

3. 维权其实没那么复杂。不需要多专业的法律知识，只要事实清楚、证据齐全、态度明确，很多不合理扣款是有机会追回来的。就像有位圈友说的，年前在广州试过一次之后，对退清洁费这件事就有了信心。

如果你也正在租房或准备退租，希望我的经历能给你提个醒：遇到不合理的扣款，先别急着认，多争取一下，说不定就省下一笔钱。这大概也算是一种“省钱有术”吧。
