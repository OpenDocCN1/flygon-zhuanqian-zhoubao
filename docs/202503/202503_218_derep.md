# ('YouTube 通过 YPP 的小伙伴，大家都可以来开直播啦', (2, 32))

好消息！只要你成功加入了YouTube的YPP，现在基本都能解锁直播功能了。我自己实测了一下，横版长视频的千次播放收益大约在0.7美元左右。最爽的是，这种直播可以全天24小时循环播放，既不用专人守着，也无需电脑全程开机，成本低到几乎可以忽略不计。搭配一份保姆级搭建教程，普通人也能轻松跑起来。

具体的操作步骤，作者都整理在飞书文档里了，想要动手尝试的朋友，可以直接点开链接照着搭一遍，讲解非常细致，基本是手把手带你的节奏。

评论区也热闹得很，有小伙伴分享了自己的实战体验：说最省事的方式就是直接用OBS，不过竖版直播效果一般，收益也确实不算多，自己最长播过18个小时，但奇怪的是竖版似乎更容易获得平台推流。对此作者的回应也很实在：能播就一直开着播呗。另外，还有人好奇：YPP开通后究竟适合跑哪几个赛道？竖版直播难道就没有收入吗？这些问题目前作者还没给出明确答复，感兴趣的话不妨自己先去实测一轮。
