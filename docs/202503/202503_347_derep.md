# 面对 3 月航海的双选题：📕电商 vs App 开发，怎么选才不踩坑
作者：龙哥

原文参考：[`www.yuque.com/for_lazy/zhoubao/cywyxaoetop6gm2t`](https://www.yuque.com/for_lazy/zhoubao/cywyxaoetop6gm2t)

近期航海圈里讨论度很高的一条提问：
“我了解到 3 月的航海项目同时开了📕电商和 App 开发两条线。本身我就是做互联网开发的，之前也曾在📕电商航海里取得过不错的成绩，但后来没坚持下去。现在想再入局，又怕精力分散。毕竟我还有正职，真正能用的时间主要集中在周末，请教一下是先两条线都试试水，还是开局就锁定一个方向深耕？”

给出的核心建议很明确：

如果你本身已有 App 开发的底子，那就别犹豫，直接往 Web 站和 iOS 应用玩法上靠。起步门槛确实不低，学习曲线会比较陡，但一旦跑通，上限和变现空间远不是电商玩法能比的。
