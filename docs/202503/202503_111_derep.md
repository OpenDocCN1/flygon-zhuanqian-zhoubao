# 雷军说所有的公司竞争策略都是性价比？
作者：龙哥

前几天，有位读者在社群里抛出一个很有意思的问题：雷军曾说，除了奢侈品不太懂之外，几乎所有公司的竞争打法本质上都是性价比。还提到我也讲过类似观点，比如可口可乐那个例子。他想听听我怎么看这句话，以及奢侈品和服装行业该怎么理解。

说实话，我之前没留意过雷总的这段采访，还专门去搜了视频来看。确实，我也表达过类似的看法——所有商品拼来拼去，最后拼的还是性价比。

但这里有个关键点：为什么很多争论看似针锋相对，其实并不是谁对谁错，而是大家对同一个词的定义根本不在一个频道上。定义不同，说出来的话自然就拧巴了。

所以咱们得先把“性价比”这个词掰扯清楚。

雷总说的性价比，其实是他自己的一套定义。我理解他的意思是：性价比 = 性能 ÷ 价格。想做出高性价比，要么把性能和价值做得足够高，要么把价格压得足够低，两头占一头都行。

按这个公式算，苹果手机性价比也相当能打。虽然它卖得贵，但性能确实顶，两者一比，比值并不低。可为什么大家过去从不觉得苹果算高性价比？

因为大众平时聊性价比时，虽然嘴上也说“性能价格比”，但心里其实藏着两个默认前提。

第一个前提：高性价比的东西，往往得是便宜货。按这个标准，苹果的价格直接出局。

第二个前提：所谓“性能”，通常只指基础功能。什么好看的设计、流畅的体验、精致的质感，都不算数，顶多叫附加值。

但我说苹果有性价比，是因为我把它的体验、设计、外观全都纳入了“性能”范畴。

咱普通人的确习惯把性能理解成“能用就行”。酒店能睡觉就行，手表能看时间就行，自行车能骑就行——至于有没有碳纤维车架，有没有减震系统，爬坡顺不顺手，骑行舒不舒服，那都是浮云。

所以你会觉得一百多块的永久自行车很有性价比，而一辆十万块的专业越野自行车简直离谱。

为什么？因为大部分人根本不需要那么好的减震、那么轻的车身、那么顶级的骑行感受。能安安稳稳骑着上下班，就是他们眼里的全部性能。

可换个角度看，花十万块买那辆车的人，会觉得每一分钱都值。既然他觉得值，那对他来说就是有性价比的。

再假设有个品牌，能把原本十万块水平的自行车做到五万块卖，那它的性价比就更上一层楼了。

至于为什么还有人愿意掏十万块买原来的那款？因为它在圈内是公认的天花板，品牌声誉本身就是价值的一部分。往宽了说，品牌声誉也能算作一种性能。

但即便五万块的车做得差不多好，在很多人眼里，它依旧不便宜，也依旧谈不上有性价比。

所以说，雷总的结论在既定定义和边界内，是完全成立的。可任何结论，都只在有限范围内正确。真正的分歧，从来不在结论本身，而在定义上。

就像广东人喊“靓仔”，其实就是给男青年打个招呼；天津人叫“大姐”，十八岁以上的女性都能这么叫。但外地人听着就总觉得哪里不对——说到底，还是定义不一样。

希望这个解释，能帮你少一点困惑。
