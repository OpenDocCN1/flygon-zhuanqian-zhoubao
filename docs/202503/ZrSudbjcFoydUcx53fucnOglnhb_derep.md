# 一、项目背景

这套玩法不算新鲜，但最近跑下来效率很高。核心逻辑就是借助AI生成的美女视频做冷启动，因为这类内容自带高关注度，起号速度极快。等账号有了基础量级后，后续可以围绕粉丝做各种延伸变现，最保守也能直接挂牌出售账号回本。

第三个钩子
承诺60天实操打卡，若无收益可退学费，降低客户决策门槛，定位副业增收。

# 三、养号节奏

覆盖📕、抖音、快手三个平台

原则是一机一卡一号

前3天每天投入20分钟进行模拟真实用户行为，主要是刷同类美女内容并点赞关注收藏
后4天每天20分钟，每天发3条随拍原相机视频，比如日常风景
