# 从部队到同城实体发售：一个退伍兵的8千元试水笔记

作者：森林

很多朋友以为我和赚钱这件事很熟，其实恰恰相反。

我在部队一待就是八年，去年9月才退伍。部队里的生活是今天有饭明天也有饭，完全不用为收入发愁。退伍后我先去了杭州做房地产销售，本以为就这么安稳下来了。

变数来自退伍前就埋下的一个念头。

在营里时手机管控很严，周末才能多用两天，工作日一天也就一小时。我就是靠着这点碎片时间刷内容。那段时间我跟战友聊过退伍后想回家创业，他直接把我推到赚钱的门里，说里面教怎么赚钱的人很多，创业的思路也多。我天生就有付费学习的习惯，就进去了。

当时我还惦记着一个心愿：想参加航海。部队不允许，退伍后时间终于自由了。刚好航海要开班，地点就在杭州，而且项目里有线下同城实体发售这个方向。我越看越觉得合适，跟公司直接请了一个月假，报名就去学了。

坦白说，作为一个只熟悉军事训练的老兵，面对商业变现几乎是一张白纸。两个月的航海经历对我来说是真正开眼的。孙策老师的商业打法让我惊叹，也让我第一次把“钱是怎么赚来的”这件事拆解清楚。在担任商务老师的过程中，我反而更清楚自己的长处在哪里。

这次我把自己这两个月同城实体发售的实践，粗略整理成了三块想和大家聊聊：

一、我是怎么走完这两个月同城实操的

二、商务谈单里我悟到的三条小技巧

三、参与过程中对赚钱本身产生的三点感悟
