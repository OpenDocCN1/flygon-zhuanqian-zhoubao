# 读书能不能让你成功？
作者：龙哥

经常有人问我：多读书，真的能让人成功吗？

我的答案不是简单的“能”或“不能”，而是——看人，也看你怎么读。

孔子当年被弟子问“闻斯行诸”，对子路说“有父兄在，不能贸然行动”，对冉有却说“听到就去做”。为什么同一件事，给出完全相反的建议？因为子路勇猛好胜，容易莽撞，需要踩刹车；冉有胆小犹豫，容易退缩，需要加油门。教育是这样，读书的成功之道也是这样——没有放之四海而皆准的公式。

身边确实有人因为博览群书而功成名就，我也不否认名校毕业生更容易拿到好牌。但请注意，我们讨论的往往不是同一个话题。对大多数普通年轻人来说，那种“靠读书就能复制成功”的想法，忽略了每个人的条件不同、处境不同。

我们讲唯物主义，就是要具体问题具体分析。你是在真实的事情上碰壁、尝试、调整，才能拿到结果；而不是脑子里塞满了概念和名词，觉得自己已经懂了，就应该成功——那不是唯物，那是自嗨。

真正有效的学习，往往发生在做事的过程中。遇到困惑，回头翻书，在书里找答案，这时的阅读才值钱。

我不鼓励的，是那种把读书当终点的人：学了一堆理论，说起话来头头是道，做起事来寸步难行。读得越多，越容易陷入夸夸其谈的幻觉，这其实是很多人的坑。

我始终相信：所有理论都有它的适用边界，我的回答也一样。

打个比方，我们帮“1949豆腐脑”把产品从早餐扩到午餐晚餐，单店营业额翻了一倍多。但面对另一个客户，我们完全没有建议他照搬这个打法。为什么？因为选址、产品结构、门店模型全都不一样。一个成功经验，不能随便套用到另一个场景。

阅读也是如此。最重要的是，你读的东西能不能帮你解决问题、把事做成。生活和工作里谁都会遇到事，有人绕着走，混过去；有人却拼命想办法，把问题啃下来。

你要做后一种人。一直这样做，你会变得非常值钱。
