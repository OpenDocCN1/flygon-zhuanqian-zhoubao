# 从自动驾驶高管到跨境卖家：一个程序员用 2 个月跑通 Shein 全托管
作者：龙哥

作者：李酸🍋  
日期：2025-03-06

如果几个月前有人告诉我，我会从自动驾驶行业转身去做跨境电商，我大概不会相信。

我曾经是一名程序员，从实习生一路做到公司高管，带过一支 150 多人的团队。去年，由于公司战略发生变化，我选择离开熟悉的职场。

离职后，我一直在思考一个问题：

有没有一件事，能真正属于自己，并且让自己每天愿意主动投入，而不是一想到工作就感到疲惫？

但对一个从未创业、没有任何实战经验的人来说，找到这样的方向并不容易。

那段时间，我在网上持续了解各种项目，也加入了不少社群，希望从别人的经历里找到答案。后来一次偶然的机会，我在赚钱星球看到了小善分享的内容，随后加上了他的🛰️。

经过几天交流，小善邀请我去海南数字游民社区见面。也正是这次接触，让我开始认真了解跨境电商，并决定亲自下场尝试。

1 月 5 日，我正式拥有了自己的店铺。

从完全没有经验，到逐步熟悉选品、上架、运营以及平台规则，我用了大约两个月，终于从 0 跑通了 Shein 全托管的完整流程。目前店铺已经产生了成交，虽然这只是开始，但至少证明了这条路是可以真正走通的。

对于一个从程序员转型、没有创业背景的人来说，这段经历让我最大的感受是：很多事情并不是等准备好了才开始，而是在行动中不断学习、修正，最后才慢慢形成自己的方法。

后续我也会继续记录自己做 Shein 全托管的过程，希望能给同样想转型、想尝试跨境电商，但还没有迈出第一步的人一些参考。
