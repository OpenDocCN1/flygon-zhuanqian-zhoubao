# 纯小白第一次做在线站，与顶级程序员 cursor 同事的沟通复盘

昨天随手发了条关于自己做网站的朋友圈，没想到不少朋友留言说“有用”，让我这个纯小白受宠若惊。想了想，干脆把这段从零开始、跟 Cursor 这位“顶配程序员”共事的经历好好捋一遍，也许能帮到同样一头雾水的你。

事情的起因很简单：之前参加 YOUTUBE 航海，我一直有提取视频帧的需求，找现成工具又麻烦，索性决定自己动手做一个网站。

当时 AI 建站的航海手册只放出部分试看内容，但就是这么一点点内容，瞬间点醒了我。因为之前用 AI 做视频已经积累了不少对话经验，所以跟 Cursor 沟通时我完全没有心理负担，也没按什么标准模板，直接走了野路子——把之前常用的那个视频帧提取网站丢给它，说“帮我做一个类似的”。

你想啊，前路两眼一抹黑，纠结那么多干嘛？先跑起来再说。就像小孩问大人问题，别怕丢人，想问就问。后来才慢慢明白，教练当初强调的那些格式化表达，背后是有道理的：当时我根本看不懂那些术语，问也是白问，但等你做过几个网站之后再回头看，就会发现，开局就把关键信息问清楚，效率能翻好几倍。
