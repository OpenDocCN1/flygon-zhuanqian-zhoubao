# ('新店开业应该开在哪里？', (2, 13))

如果你正准备开一家餐厅，第一站会选在哪里？别急着回答，这个问题可能直接决定你未来能走多远。

大多数人第一反应是：首店必须火，最好一开门就排长队。于是他们倾向于选最旺的地段，配上铺天盖地的宣传，让新店一露面就成为爆款。这种思路本身没问题，不少网红餐厅就是靠这个套路起家的。

但等一下，你有没有问过自己：我到底想做一个什么样的品牌？

如果目标就是当一家网红店，那开业即巅峰确实很重要。可如果你心里想的是未来开出几百家、上千家店，做的是正常的餐饮生意，那就得换个思路。

真正的关键在于：你选的第一家店，应该能代表你未来最普通的门店状态。比如你最终想入驻的是普通商场的普通位置，那第一家店就该开在这种地方。只有这样，你才能清清楚楚地判断，这家店到底是靠产品本身活下来，还是仅仅靠黄金地段撑起来的。

反过来，如果一开始就选在雍和宫大街那种游客扎堆、客流量爆表的特殊位置，表面看生意红火，可那都是“一次性”流量。这种选址根本测不出你门店的真实战斗力，因为热闹是地段的，不是你的。

所以说，别迷恋那种一开业就火爆的特殊铺位。那种成功，说明不了任何问题。真正有野心的品牌，反而敢于把自己丢进最普通的环境里，去验证这个模型能不能成立。只有在那里跑通了，你的生意才算是真的站住了脚。
