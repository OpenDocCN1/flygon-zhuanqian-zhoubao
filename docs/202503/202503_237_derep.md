# 从“帮助别人”到“成就自己”，再回到“帮助别人”：我是如何邀请高冷大咖担任分享嘉宾的
作者：龙哥

大家好，我是龙哥。

去年，我曾经特别热衷于组织线下活动。

毕竟，在线上认识再多人、聊过再多次，也不如线下真正见上一面。那时的我干劲十足、充满期待，还和圈内朋友约定：一年要组织几十场活动。

不过，理想很丰满，实际执行却没有那么顺利。整个去年，我最终组织的线下局还不到 15 场，距离最初设定的目标相差甚远。

到了今年，在赚钱团队子安（木木）的鼓励下，我决定重新认真思考“组局”这件事，也希望借着邀请河林老师担任线下活动嘉宾的经历，和大家聊聊这次过程中的真实感受、心理变化，以及我总结出的组局方法。

对于很多想办活动的人来说，组局过程中常见的顾虑大概有这些：

1. 担心报名人数不够，最后被迫取消；
2. 场地筛选、预订和协调十分麻烦；
3. 害怕现场没人说话，气氛尴尬；
4. 担心无法邀请到合适的嘉宾；
5. 不清楚组织活动究竟有什么价值。
