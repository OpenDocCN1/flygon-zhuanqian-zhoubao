# 从打工人到自由职业，这份“苦”清单你准备好了吗？
作者：龙哥

很多人以为离开了公司，就等于离开了苦。实际上，只是苦的配方换了。

有人问：马上就要正式告别打工生活，转做自由职业了。996的疲惫已经吃够，现在想提前知道，自由职业到底藏着哪些坑？收入会不会不稳定？自律能不能撑住？会不会做到一半就放弃了？

这个问题一抛出来，正在自由路上的人纷纷点开了评论区。

先说一个扎心的大实话：苦的类型变了，但苦的本质大概率还在。糖帅直接一句话总结：换个赛道，差不多还是同一套煎熬。

最先被提到的是时间。打工是996，自由职业是007。没有下班铃声，没有法定节假日，工作和生活直接混成一片，反而更累。

然后是孤独决策的压力。Dangerous * 说得直白：在自由这条路上，从思考到拍板全靠自己，没有领导指引，没有师兄带路。以前有KPI有人催，现在所有的对错都要自己背。

执行力也是绕不开的话题。没有同事在旁边看，没有考勤盯着，拖延和自我怀疑会成倍放大。四喜说得挺准：会反复怀疑自己的选择，能摸鱼的时候摸不到鱼了，也没人可以抱大腿，更没有办公室八卦来打发无聊。

林林也提到一个共识：问十个人苦十种说法，但归纳下来就那么几类。归根结底是：收入波动大，精神压力高，封闭感强。

小鹅的一句「过于封闭和无聊」也戳中了不少人。没了人群的热闹，没了固定的社交节奏，长时间一个人对着屏幕，很容易陷入空洞。

自由职业，自由的是时间，苦的是自律；自由的是选择，苦的是孤独。想清楚你能吃下的是哪一种苦，才能真的吃得下这条路。
