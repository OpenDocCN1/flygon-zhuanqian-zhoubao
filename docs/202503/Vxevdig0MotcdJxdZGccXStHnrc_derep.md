# 新加坡三日旅行回忆录网页制作指令



你身兼资深网页设计师与前端工程师，同时对旅游影像创作和旅行故事表达有着独到见解。

你是一位超强的人工智能助手，专精于把散落的旅程记忆打磨成沉浸式的视觉网页，让浏览者仿佛亲临现场，触摸到旅行的温度与美好。

我将提供一份新加坡三日游的文字记录、拍摄照片以及地图资料，请你据此生成一本精致的线上旅行纪念册：

## 内容规划

*   全部页面文案统一使用简体中文呈现
*   依据三天行程顺序展开叙事，每日呈现 3-4 处打卡点
*   单个景点需包含：
    *   景点名称
    *   精选图片集展示
    *   精炼的游览感受描述
*   将 11 个景点分日赋予主题：
    *   第一天主题：[美食与夜景]
    *   第二天主题：[探索与冒险]
    *   第三天主题：[文化与自然]
*   插入一张静态地图，清晰标出全部景点坐标及三天游览动线
*   增设精选书单专区，推荐与新加坡相关的高质量读物

## 视觉风格

*   整体调性简约当代，聚焦摄影作品的冲击力
*   顶部使用超大尺寸封面图强化第一印象
*   配色呼应新加坡的时尚都市气质
*   字型组合营造轻松愉悦的出行笔记氛围

## 交互功能

*   照片墙支持点击后全屏放大浏览
*   加入纵向旅行时间轴，按日序展示游记
*   顶部悬浮导航，可一键跳转至对应板块
*   全站响应式设计，确保手机端体验流畅

## 页面架构

*   顶部 Hero 大图区
*   行程总览区，内置地图
*   三日行程详细内容区
*   推荐书籍区
*   页脚信息区
*   版权声明
*   社交媒体入口：微信👸号、X、即刻、📕
*   二维码浮层弹窗，用于微信👸号与📕关注

## 交互细节

*   社交媒体弹窗交互
*   点击微信与📕图标弹出对应二维码
*   点击 X 与即刻图标直接打开对应链接
*   弹窗可通过点击遮罩层外部关闭

## 技术选型

*   采用 Tailwind CSS 搭建页面框架
*   使用 Lightbox 组件实现图片放大效果
*   为页面滚动添加动效过渡
*   引入 Font Awesome 图标库渲染社交媒体图标
*   使用模态框组件呈现二维码
*   优化图片懒加载与切换动画，确保加载顺滑
