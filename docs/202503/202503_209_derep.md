# Tempo Labs：像使用设计工具一样编辑你的前端代码
作者：龙哥

把前端代码当画布来改，这体验有点惊艳

最近逛论坛的时候，我意外发现了一款很有意思的 AI 编程工具——Tempo Labs。它和我之前用过的编程助手都不太一样：别人还在靠对话生成代码，它却让你像操作 Figma 一样，直接在项目界面上拖拽、点选、调样式，前端代码会跟着同步变化。这种“可视化改代码”的交互方式，确实让人眼前一亮。

以前我们启动一个新前端项目，可能会先借助 Bolt 这类工具把架子搭起来；而现在，Tempo Labs 给出了另一个选择：把编辑过程变成设计工具的操作体验，让开发者和设计师都能更直观地掌控页面。尤其是设计背景的朋友，如果想亲手触碰代码，又不想被一堆命令行劝退，这款产品非常值得一试。


总的来说，Tempo Labs 走了一条很新的路。至于它能不能改变前端开发的习惯，我不好说，但至少值得大家亲自体验一下。
