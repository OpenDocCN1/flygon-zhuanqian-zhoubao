# 草台班子想放大业务又怕踩坑？先别急着把公司做成正规军
作者：龙哥

很多做项目的朋友，0-1 跑通后就开始焦虑放大这件事。招人吧怕背上劳动关系、社保税务的雷，不招吧又做不大。

于是出现了各种“轻量化”的玩法：挂合作、搞阿米巴、兼职干活、口头约定。表面上看是灵活省钱，实则全是裸奔。一旦有人去仲裁，账上没几百万立马就被拖垮。现在网上还有专门教年轻人靠仲裁薅公司羊毛的产业链，真的防不胜防。

面对这种情况，大部分小团队的第一反应是：是不是得一上来就全套正规？劳动合同、五险一金、个税代缴，全部拉满才安全？

答案未必。

当公司体量还很小时，你的全部注意力应该放在一个核心问题上：能不能活下来，并且把钱赚到手。

税务层面，没赚到几百万之前，真的没人会盯着你看。规模在那里，风险自然低。劳动关系层面，只要工资正常发放，纠纷概率本就可控。被仲裁几次算什么，企业发展中很常见的事情。赚钱运营至今马上第九年，也一样没遇到过劳动纠纷。

现实是，市场上绝大部分小企业在社保和用工合规上都做不到 100%完美。真出了问题，补上就是了，不是什么天塌下来的大事。

所以别在没长成之前，就把自己绑死在流程和合规的枷锁里。先把业务放大起来，先把钱赚到兜里。等你有稳定现金流、有抗风险能力了，再逐步把团队管理、人力制度、税务社保做精做细。

草台班子最怕的就是还没起飞就先把自己拖死了。先挣钱，再完善。活下来，才有资格谈正规化。
