# 为什么普通人很难有钱？
作者：龙哥

普通人很难有钱，根子不在起点，而是大部分人一辈子都卡在同一层。

一万个人里，九千九百九十九个走的是同一条路。所以，普通人的起跑线并没有落后，机会一直都有，真正的分水岭在起跑之后怎么走。

生意从低到高分五个段位。看懂这五层，才有可能谈跨越阶层。不少人琢磨做生意、搞创业，却都栽在同一件事上：永远在最底层打转。

最底层是什么？卖产品。

这个段位的人，只能卖自己能看见的东西。开餐厅的，买来食材加工一下再端上桌，多少还有点手艺，可本质上赚的仍然是进出差价。摆摊的、卖杂货的，连手艺都不需要，就是左手进右手出。

三十年前，信息不透明，这么干还能活。现在是什么时代？手机拍个照，各平台的比价信息全出来了，信息差归零。新手做倒卖，只会让原本不富裕的生活雪上加霜。

再往上走，第二个段位：做品牌。

有人以为注册个商标就是品牌，甚至还叫什么“宇宙第几”，那只是商标，品牌从来是市场给的。

什么叫品牌？就说我们公司楼下那家杨哥螺蛳粉。档口小得可怜，附近五百米内有十五六家同行。别家早上九点就开门，有的甚至全天不打烊；他们家傍晚才支摊，只干到半夜十二点，就做六个钟头。但只要招牌一亮，附近同行店里立马没人，他家门口排起长队，能排五十米，一直排到隔壁螺蛳粉店门口。

靠什么？就三样：汤够浓、料够足、味够正。这就是他的品牌。

拿我们团队来说，我们被市场叫做“中老年养生赛道带货专家”，这称呼不是我们自封的，是供应商和市场给的定位。我个人在口播带货领域，也是千万级自然流达人，有数据支撑。所以品牌是别人给的，不是自己起个名就完了。

大多数人做生意的认知天花板，其实就卡在这一层。没人点破的话，可能一辈子想不明白：品牌不是注册出来的，是市场评出来的。

第三个段位：做模式。

能走到这一层的人，万里挑一，大多是大厂精英，或者跟对了人被带出来的幸运儿。

品牌做得再好，一个人的能力始终有限，最后赚的还是辛苦钱。想赚更多，就得规模化。但很多人对“规模化”有误解，以为雇几百个人、发发工资就是规模化。二十年前的老板确实爱这么想，但那仍然在前两个段位打转。

真正的模式，是把品牌标准化，然后带动一群人跟你合伙、合作，把盘子做大。

我现在做短视频带货，带人也不只是带他卖产品、做品牌，还会教他做规模，让他不用发工资也能开起自己的公司，当上老板。

规模是这么搞的吗？我身边有个朋友，2023年一心想“上规模”，上来就砸了两百多万。他在广东一个很深的巷子里，开了一家特别有格调的烤串店，注册商标，装修风格清新脱俗，还做了PPT到处融资，打算开更多店。我专门去尝了一回，串儿实在难吃。牌子都没立起来，规模从何谈起？

第四个段位：做供应链。

一条铁律：连锁店里，店长挣的是终端差价，真正的大老板挣的是供应链利润。而那些顶级连锁品牌，比如肯德基、麦当劳、真功夫、汉堡王，其实已经站在第五个段位，也就是整个商业金字塔的顶端。

我现在就处在第四个段位，做供应链的生意。跟过我带货的人都清楚，我不只是自己做达人，我手里还有一套完整的“带货赚钱”交付体系。你想学带货，我有交付；你想低成本开带货工作室、开公司，我也有完整交付方案。这套交付，就是护城河，别人干不了。

很多人以为我是靠培训赚钱，结果去年我直接把线下学徒的培训费全免了，一整年，所有人都目瞪口呆。其实真相是：只要是合法的培训，恰恰是最不赚钱的生意。

为什么？原因就四个词：没法标准化、没有复购、客单太低、成本太高。培训的客户千人千面，没法标准化；几乎一锤子买卖，只能不断拉新；只要你还有良心，认真做交付，随便收多少费都是低客单、高成本。培训费最多收回成本，甚至可能赔钱。当然，骗子除外。

我敢免费一年，不是因为傻，而是因为我的业务模式，是把短视频带货这个技能做成完整的交付供应链，然后把带货达人团队规模化。哪怕一个小白，也能在极短时间内变成带货达人，然后跟我建立长期的线上协作关系。

第五个段位：做资本。

那些商业巨头和互联网大厂，没有一家不设立自己的资本公司，专门为供应链上下游提供资金支持。前四层所有的折腾，本质上都是在搭生态、打地基，最终都在给顶层资本当垫脚石。

有人问：你说自己处在第四级，怎么知道第五级的事？因为我是从互联网大厂走出来的，认知被打开过。你会发现，从大厂出来的总监级人物，一旦创业，会迅速把产品、品牌、模式这三个阶段走完。这对我们来说是基础工作，因为创业的时候，业务模型就是完整的。剩下百分之九十九的时间，都在向塔顶攀爬。

回看滴滴、抖音，产品设计之初就先画好业务模型，后来的所有工作都围绕资本化运作。当年的淘宝，某种意义上也是为了成就今天的蚂蚁金服。

所以别小看读书。学历能帮你进大厂，而大厂才能打开你的眼界、抬高你的认知。不然的话，就只能盼着贵人拉一把。可天底下哪有那么多贵人？
