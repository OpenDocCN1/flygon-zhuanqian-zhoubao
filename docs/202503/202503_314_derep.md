# 从零到高级 YPP：我用两个月在 YouTube 上试错六次赛道的全过程复盘
作者：龙哥

大家好，我是龙哥，一个最近刚入坑赚钱的新手玩家。

去年 11 月我加入赚钱社群，运气不错正好赶上 12 月的 YouTube 航海营，之后就一直把精力砸在 YouTube 上。到现在大概两个多月的时间，感觉自己的实操能力跟项目认知都被拉升了不少。

因为是 All in 投入，期间我换了不少方向在测试：达人秀、AI 猫猫故事、动物预警类、古风美女走秀、Reddit 故事号、解说号...几乎每个赛道都上手试过一轮。现在我把重心收敛到了两个方向：故事号和解说号。

在 @方波妮 教练和 @Gary 曹教练的指导下，目前已有两个账号成功达到高级 YPP 的门槛。对我来说，这算是 YouTube 项目的第一道关卡终于过了，后面还有更长的路要走。

实操这段时间，我踩过的坑、卡过的点、焦虑的时刻也不少。抱着“分享越多越幸运”的想法，我把自己的实战心路和一些经验教训整理了一下，希望能给正在做 YouTube 的朋友们一点参考。
