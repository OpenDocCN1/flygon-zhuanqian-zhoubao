# 第 4 章 项目筛先 —— 从"盲选"到"匹配"

## 学习目标

- 理解新手选项目的核心逻辑是"筛选而非挑选"
- 掌握项目筛选模型（覆盖近 20 项参数）的结构与用法
- 理解"流量-产品-变现"最简商业模型，建立宏观项目认知框架
- 掌握四层递进筛选漏斗：原则 → 能力 → 收益 → 市场
- 理解"积累优先于收益"的第一性原则，用它指导项目选择

## 4.1 生活类比

选项目就像**相亲**与**筛简历**的区别。挑项目时，新手常像"挑对象"只盯着对方条件（这个项目热门、那个赛道赚钱）；但正确的做法是像"筛简历"一样，先看**自己匹配度**——这个项目需要什么能力、什么资源、多少时间，我有没有。项目筛先的核心，就是把"我要选最好的"换成"我要筛出我能做的"。

## 4.2 概念地图

```
项目筛先
├── 两种心态（挑选 vs 筛选）
├── 项目筛选模型（近 20 项参数）
│   ├── 风险（风险概率 / 风险程度）
│   ├── 收益（反馈周期 / 最高收益）
│   ├── 附加价值（货源 / 人脉粉丝 / 专业能力 / 杠杆复利复购）
│   ├── 市场（持续周期 / 渗透率 / 供需 / 优化空间）
│   ├── 能力（技能 / 行业知识 / 资源）
│   ├── 时间 / 成本 / 个人评估
├── 最简商业模型（流量-产品-变现）
├── 四层递进筛选漏斗
└── 积累优先于收益
```

## 4.3 新手的两种选择心态：挑选与筛选

**为什么需要这个概念？** 很多新手面对海量项目时，第一反应是"哪个热门选哪个""哪个赚钱选哪个"，这就是在"挑选"。但新手既没有商业网感，也没有资源实力，这种"挑优质标的"的心态会带来**选择瘫痪**——觉得这个竞争大、那个是红海、另一个天花板低，最终一个都选不出来。

> "新手选项目是『筛选』而非『挑选』，关注自己能力和资源是否匹配。"
> ——《项目筛选模型》

**核心定义**：挑选是像大佬一样，在几乎所有可见的项目里挑回报最优的；而筛选是像筛简历一样，只关注**自己能力和资源是否匹配**，从中筛出 1 个自己能做的项目。

**关键性质**：

- **匹配优先**：大佬选项目看项目本身的风险与盈利；新手应更关注自己的能力和资源与项目是否匹配。
- **降低标准障碍**：一个人能做的项目未必是最优的，但一定是最适合当下的。能筛出一个能做，就已经谢天谢地。
- **动态调整**：随着能力、资源、资金变化，可筛出的项目范围会扩大，筛选是持续迭代的。

**典型例子**：一个红利期项目要求会编程、初始投入 10 万、团队 30 人，大佬直接做，但普通人拿不出钱和团队，就不该为了"热门"硬上。反之，外卖删差评这种小项目，普通打工人就能做。

**边界条件**：筛选逻辑不否定项目本身的好的判断，而是强调"好项目的判断标准"需结合"自身匹配度"；若完全没有任何项目能筛出，通常要先调整自己的 filter（见 4.6 节）。

## 4.4 什么是对项目筛选模型

**为什么需要这个概念？** 单纯说"要筛选"太抽象，新手需要一套可操作、可勾选的评估框架，把"判断项目行不行"变成一张可以填写的表格。

> "构建项目筛选模型，覆盖近 20 项参数：风险、收益、附加价值、市场、能力、时间、成本、个人评估。"
> ——《项目筛选模型》

**核心定义**：项目筛选模型是一套覆盖近 20 项参数的系统化评估表格，从风险、收益、附加价值、市场、能力、时间、成本、个人评估等维度，辅助新手筛选与自身匹配的项目。

**关键参数一览**：

| 维度 | 参数 | 关注点 |
|------|------|--------|
| 风险 | 风险概率、风险程度 | 是否违法违规、损失程度（仅盈利/成本/名誉） |
| 收益 | 反馈周期、最高收益 | 多久见到第一块钱、天花板多高 |
| 附加价值 | 货源/人脉/专业能力的积累 | 是否具备杠杆、复利、复购效应 |
| 市场 | 持续周期、渗透率、供需、优化空间 | 项目能存续多久、是否红海 |
| 能力 | 技能、行业知识、资源 | 是否需要重学技能、是否有粉丝/货源 |
| 时间/成本 | 每日耗时、是否需紧盯、投入 | 与主业/资金是否冲突 |
| 个人评估 | 符合优势、符合兴趣 | 是否擅长、是否愿意长期做 |

**关键性质**：

- **结构化**：把模糊的项目判断转化成可勾选、可比较的参数项。
- **动态性**：模型里的参数标准应定期更新、填入新的判断。
- **个性化**：参数的权重因人而异，需根据自己的情况调整。

**边界条件**：参数覆盖是新手评估项目的"脚手架"，不等于每个项目都要填满 20 项；初期可重点抓风险、能力、收益三项。

## 4.5 项目的"最简骨架"：流量—产品—变现

**为什么需要这个概念？** 在微观参数之前，还需要一个宏观框架让你一眼看懂任何项目。几乎所有项目都能归结为一个最简的三模块模型。

> "几乎所有项目都符合最简商业模型『流量-产品-变现』。"
> ——《项目筛选模型》

**核心定义**：最简商业模型将任何项目拆解为流量、产品、变现三大模块——**如何引流、如何搭建产品、如何设置变现**，这三件事就是做项目的基本武器。

**关键性质**：

- **普适性**：无论是小红书资料引流、外卖 CPS 还是电商，都可套用此模型拆解。
- **模块化重构**：拆解两个项目得到 6 个模块（流量/产品/变现各两个），拼合起来就是一个新模式的雏形。
- **学习导向**：读精华帖的一大目的，就是拆解并学习他人如何引流、搭产品、变现。

**典型例子**：拆解"小红书资料引流"项目——流量：小红书铺关键词获搜索流量；产品：以微信号为载体的虚拟课件；变现：通过微信售卖。拆解"外卖 CPS"项目——流量：投放公众号/外卖小哥广告；产品：以公众号为载体搭建的领券小程序；变现：用户领券下单。

**边界条件**：最简模型是"骨架"，落地时每个模块还可细分；但它能帮新手快速看懂一个项目的全貌，是入门的确定性抓手。

## 4.6 四层递进筛选：过滤漏斗

**为什么需要这个概念？** 有了筛选模型这张表，下一步是如何高效地用起来。四层递进筛选就是一条可执行的操作路径。

> "先筛选原则（违法违纪决不干）→ 再筛选能力 → 再筛选收益 → 最后筛选市场。"
> ——《项目筛选模型》

**核心定义**：四层递进筛选是按照"原则 → 能力 → 收益 → 市场"的顺序，像漏斗一样逐层过滤项目的方法。每层通过才进入下一层。

**关键性质**：

- **原则优先**：第一层先排除违法违规、损人利己、钻规则漏洞的项目，守住底线。
- **能力次之**：第二层过滤自己是否具备能力、资源、时间，这是新手最现实的约束。
- **收益第三**：先收益后市场，是因为"项目能否赚钱更取决于自己的能力，而非市场多大"。
- **市场最后**：最后再看市场是否有空间、是否红海。

**边界条件**：若漏斗过滤后一个项目都没有，说明你的 filter 太苛刻、看的项目太少，或对项目不了解——此时应放宽标准（如把"持续周期 10 年"放宽到"1 年"），或去看更多项目、深入了解后再填参数。

## 4.7 积累优先于收益 —— 新手的第一性原理

**为什么需要这个概念？** 排除了"最优幻想"之后，新手在筛选时还需要一个价值排序的底层原则：到底看重长期积累，还是短期现金收益？

> "积累比收益更重要，积累让我步入下一阶层。"
> ——《项目筛选模型》

**核心定义**：在项目筛选与本质过程中，能力与资源的积累比短期现金收益更重要，是进入下一阶段的通行证。

**关键性质**：

- **复利传导**：积累技能、人脉、货源，能让下一个项目更有优势，形成向上的复利。
- **阶层跃迁**：收益只说明"我现在有钱"，积累才决定"我未来更值钱"。
- **类比**：做技术员可以积累可迁移的技能，而打螺丝只能赚钱、什么也积累不了——后者换个项目只是"换个厂打螺丝"。

**典型例子**：做外卖删差评能积累私域流量粉丝（人脉资产），做无货源电商能积累优质货源，做英文工具站能积累编程能力——这些积累比单纯赚几百上千块更有长期价值。

**边界条件**：积累优先不等于不赚钱——在能力、时间、资源有限时，首先要考虑"这个项目我能不能做（能力匹配）"，其次看"能否积累资源为下个项目铺路"，其他都是次要的。

## 4.8 动手练习

- **心态检测**：写下你近期想在几个项目间犹豫时脑海里的念头，判断它们是"挑选"（看热门）还是"筛选"（看匹配）。
- **筛选模型填表**：从你感兴趣的领域挑 3 个项目，用筛选模型的参数表逐一填写，找出风险、能力、收益三方面的评估。
- **最简模型拆解**：用"流量-产品-变现"拆解 2 个你熟悉的项目，各得到 3 个模块，尝试拼出一个新模式的雏形。
- **漏斗过滤**：设定自己的原则、能力、收益、市场四层 filter，对 5 个项目做一次过滤，看最终剩下几个。

## 4.9 本章小结

这一章我们建立了"方法论引擎"的第一步——**项目筛先**。我们明确了新手选项目的核心逻辑是"筛选而非挑选"；掌握了一套覆盖近 20 项参数的项目筛选模型；用"流量-产品-变现"最简模型建立了看项目的宏观框架；学会了"原则→能力→收益→市场"四层漏斗过滤方法；并以"积累优先于收益"作为新手选择的第一性原理。

| 概念 | 解释 |
|------|------|
| 挑选 vs 筛选 | 新手应看能力资源匹配，而非挑最优 |
| 项目筛选模型 | 近 20 项参数的系统化评估表格 |
| 最简商业模型 | 流量-产品-变现的三模块骨架 |
| 四层递进筛选 | 原则→能力→收益→市场漏斗 |
| 积累优先于收益 | 能力资源积累比短期现金更重要 |
