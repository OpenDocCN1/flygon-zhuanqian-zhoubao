# 五年视频号直播实战，我悟到的五个关键节点与底层逻辑

做了这么多年视频号直播，回头复盘才发现，真正决定能不能走下去的，从来不是起跑有多漂亮，而是中间那些被迫转弯的瞬间。

前两天有朋友邀请我在6月7号的大会上做主题分享，翻数据才惊觉，我们断断续续在视频号上跑直播，已经整整五届年头了。这里先抛一个简版的思考，详版咱们会场再深聊。

**一、开门红是纸面成绩，真正算赢的只有落袋为安**

下面这张图是2020年12月2日微信公开课官宣的案例，当时官方用我们的直播来宣传视频号直播功能。现在看像个时间胶囊。

彼时我们手握大量私域，直播本就在自家小程序上跑成熟了，迁移到视频号技术门槛并不高。但说实话，那个阶段平台用户量有限，功能也还在打磨，团队判断是先观望，等生态更稳了再all in。结果这一观望，就直接观望成了两年。

**二、变化才是常态，应变才是基本功**

2020年疫情毫无预兆地到来。初期还能维持运营，后面办公室关了、仓库停发了，精心规划的海外选品和溯源行程全部取消，去一趟基本等于回不来。

祸不单行，我们投入大几百万的教育项目刚起势，就撞上了双减。

2021年到解封前，整支队伍都很迷茫。电商这条腿被疫情掐断，教育这条腿被政策砍掉，唯有现金流还算健康。那个时候唯一的信念很朴素：留得青山在，不怕没柴烧，先扛住。

复盘下来，计划顶多是现实的千万种可能性中的一种。被打乱的时候不必自责也不必愤怒，无常反而带来新机会。应变能力，才是穿越周期的底层肌肉。

**三、有常识不难，难的是在对的时间用对的常识**

解封后可以重新动了，但23年用户流失严重，孩子们也到了不需要母婴产品的年纪，赛道天花板肉眼可见。必须找新方向。

疫情之后大众最焦虑的是什么？健康。尤其是吃的安全。于是我们立刻启动全国寻源计划，给妈妈们找特色生鲜，用美味和健康做抓手。

思路很顺，执行也坚决，项目也赚钱，但最后我还是砍掉了。因为利润率太薄、售后成本太高，做小而美可以，做300人的体量完全不现实。

这段经历让我重新校准了判断标准：痛点、痒点、利润率，三者必须同时看齐。疫情前我们看规模、看想象空间，疫情后我们只看利润、看能不能活下去。思维惯性会变成枷锁，能不能及时切换认知，比常识本身更难。

**四、释放善意就像放飞信鸽，总会飞回来**

那天我在海南太阳底下考察贵妃芒基地，许久没联系的老友忽然打来电话：“政策有松动了，我在豆神大语文做顾问，要不要再试一把？”

说实话，教育这个词对我来说已经有两年多的心理阴影，脑子里立刻浮现的是血亏的画面。

但我们还是聊了，聊了很久。对方预期我们能卖500万，我自己觉得能做50万已经不错了，对当时还在卖5块钱一斤橘子的我们来说，压力极大。

顶着这份压力开了播，当天直接破了800万。

复盘有两点特别清晰：第一，主动释放善意，善意像信鸽会归巢。你发出去的多，周遭回来的也多。第二，我们对自身价值的判断极易被过往成败带偏。当拿不定主意时，先把门打开再说。成了就开心几天踏实干，失败了也不丢人，接着找下一个机会就好。

**五、直播变现的两个实操心法**

跑了几年直播，有两个感受最深。

第一，好的直播是换脑，不是洗脑。

你要先把用户脑子里错误的认知拆掉，再帮他重建一套新的。换脑成功，用户自然产生强烈的认同感，转化也就来了。

举个例子：很多人觉得定期查视力、少玩iPad、少看电视就能护眼，这是个常识性误区。其实近距离看书和近距离打游戏对视力伤害是同级的，高强度近距离用眼才是近视主因。琴棋书画、乐高这类精细活动对眼轴冲击更大，而传统视力表检测准确度极低，国家真正认可的金标准是眼轴长度。

用几分钟测试就能预测孩子的远视储备还剩多久、什么时候开始近视，再结合同仁医院的专利方案，教家长在家里创造10米望远的学习环境，从根源上阻断近视。这就是典型的换脑。

第二，直播必须有明确的限制性条件。

早期我们玩限时限量，后来做视频号转向真诚去套路。数据一对比就很明显，没有限制的场，数据明显下滑，而且用户体验并不会更好。用户其实享受的是在限制里完成决策的快感。

常见的限制设计是：数量只剩100单、整点抽半价只持续5分钟、首发价仅限前XX个、赠品送完即止、名师名额先到先得……

保健品赛道有一些新的玩法，以及怎么和团队小伙伴共建战斗力，这些我们就约到6月7号大会和夜话再聊。广州见。
