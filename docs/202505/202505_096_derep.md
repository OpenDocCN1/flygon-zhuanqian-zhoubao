# 为什么很多创业者半路熄火？YC 合伙人的一句话点醒人
作者：龙哥

一篇被转了65次的笔记，拆解了YC合伙人对创业失败的真实观察。

原文出处：[`www.yuque.com/for_lazy/zhoubao/zcz5e5yu529el06a`](https://www.yuque.com/for_lazy/zhoubao/zcz5e5yu529el06a)

核心信息来自一段分享：

“别总对自己产生怀疑，几乎所有创业者都会碰到瓶颈。外界看到的成功企业，往往呈现出一片顺遂的假象，实则背后都经历过反复的挣扎。困难是常态，不是例外。不要因为一时的挫折就选择退缩，咬牙继续走下去，解决方案终会在坚持中出现。” [`mp.weixin.qq.com/s/tyc_SVQyU-0YmVLOrZbAAw`](https://mp.weixin.qq.com/s/tyc_SVQyU-0YmVLOrZbAAw)

作者：龙哥的收藏夹
发布：2025-05-16

很多人创业失败，并不是因为想法不够好，而是因为在问题面前失去了信心。把别人的光鲜当成自己的标准，就会误以为自己走偏了。

真相是，创业从来没有一帆风顺的剧本。坚持，才是把问题扛过去的唯一方法。
