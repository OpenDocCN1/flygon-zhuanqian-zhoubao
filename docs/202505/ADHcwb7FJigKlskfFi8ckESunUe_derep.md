# 10个月，我把一场创业做成了教科书级的失败
作者：龙哥

一口啤酒下肚，脑子里就蹦出这10个月的经历。写出来，也算是给那些蠢蠢欲动想辞职创业、或者想做海外出海App的朋友提个醒。

2024年7月23号，我接到了朋友的一条消息。那天刚把行李箱塞进新租的房子里，武汉的七月像个蒸笼，手指还没来得及洗干净，手机就响了：“出来一起干吧，赚钱吧。”

在老公司待了六年，人都麻了。这条消息像石头砸进死水里，荡起了一圈涟漪。

说实话，条件看起来挺诱人的。五星级写字楼办公，口头说有百万资金进来，海外有官方背书，当地社群大佬声称会支持，还有现成的用户池和多年的主营业务。所有信号都在喊：现在上车，正好。

**第一幕：从饭局开始的草台班子**

团队成立的时候，钱还没到账。第一次正式碰面是在一顿商务午餐上。创始人轮流上台给投资人做个人秀，履历、战绩、专长，包装得像个商业神话，仿佛我们已经稳赚不赔。

可问题是，签约前我们彼此之间连个群都没有，也没有任何工作上的交集。我当时就觉得不对劲，创始人明显在刻意切断大家的横向联系。这个隐患，后来应验成了散兵游勇和一人独裁的常态。

**第二幕：没有产品经理的狂想**

第一次需求会，尴尬到像黑色幽默。我们做的是一个以用户为核心的社交App，结果最关键的产品经理职位是空缺的。

会上创始人激情四射：这个功能抄A，那个金币系统搬B，我们的“创新”是把语音房的礼物特效换成狮子、换成汽车。没有原型图，没有需求文档，没有用户路径闭环。他的逻辑只有一句：用户来了就会花钱。就靠这句话定了全部开发方向。

**第三幕：用鸡血换工时**

所有人都被画饼打满了鸡血。每天至少13小时在肝，唯一的喘息就是午饭和晚饭。创始人负责精神按摩：“三个月上线，六个月数据漂亮，之后就是分红、盈利、去泰国、包游轮。”他说会给付出多的伙伴更多分红。

我们信了。

**第四幕：4.3a地狱和停薪令**

三个月突击开发，迎来App Store审判。大家等着过审通知就像等暴雨一样，结果三天后苹果回了个4.3a。脸都绿了。

我们像侦探一样排查：是不是语音房的问题？先藏起来再说 —— 4.3a。改个分类换成娱乐，开屏换游戏画，把首页做成会动的卡牌 —— 4.3a。改方法名、混淆代码、大改UI —— 依旧4.3a。

距离创始人承诺的三个月上线，已经逾期两个月。创始人说项目资金快见底了，为了证明团队决心，全员停薪，等包过了再双倍补发。

**第五幕：被逼着“借壳上市”**

停薪不久，创始人说同赛道的一家公司愿意把已经上架的App包借给我们，用来做业务逻辑移植。

第一次投票，我们拒绝了。接下来的一个月里我们又折腾了一遍所有可能，没用，最后僵住了。这一拖，又晚了三十多天，还额外赔了股份和分红。事后复盘，根本原因就是代码重复，只是表面修修补补，自欺欺人。

第二次投票，全票通过合作。重新谈判后，为了换到这个壳，我们又割出了一大块分红和股份。

**第六幕：至暗的分崩离析**

签约后，创始人带着开发组飞去外地，日夜做功能移植。本该准备上线冷启动的合伙人，却在公司里光明正大地摸鱼、健身。

没有产品经理的锅在这个阶段炸开了。合作方的App功能很全，创始人陷入了“全都要”的取舍困难，向投资人承诺的版本又被拖了40天。

好不容易上线，留存数据难看得离谱。投资人本该打款的节点，直接撕毁默契，停止后续资金。

**最后一根稻草**

骆驼倒下不是因为一根稻草，是长期超载。用户链路不通、内容空洞、新用户接不住、需求堆砌毫无逻辑、产品决策一人说了算……警告灯一直亮着。

我熬夜画过完整的用户体验地图和原型，强调要以体验为核心，最后全成了废纸。最终每个模块都硬拗成付费入口，赤裸裸逼着用户充值。

我曾争辩过，我曾努力过……

最后还是醒了。黄粱一梦，大梦初醒。10个月，从武汉的热浪开始，到搬离武汉时宣告结束。
