你有没有遇到过这种情况？辛辛苦苦写完👸号文章，还要花时间排版成📕风格的长图，费时费力。

最近刷到一位叫“陈序员大康”的创作者分享，他把👸号文章的发布流程接到了扣子空间的 MCP 上做了个智能体。本来只是自己图个省事，顺手分享出去，没想到评论区一堆人喊着“我也需要”。

变化出在 coze 的图像模型接入了即梦 3.0，这个模型对文字生成的支持非常强。像那些治愈系文案、金句摘抄，用它来做图效果应该会很出彩。

但也有个坎儿：一旦遇到信息量大的内容，比如知识干货类分享，文字一多，即梦 3.0 就有点扛不住了。正因如此，他才没继续往下做。
