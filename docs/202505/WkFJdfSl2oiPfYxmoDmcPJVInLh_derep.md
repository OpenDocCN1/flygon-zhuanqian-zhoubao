# 方向怎么定的

2023年跟着生财航海，用ChatGPT批量做视频内容，认知被打开了——下一波机会一定和AI相关。但当时我也懵，AI能怎么变现说实话没头绪，只有一个原则：项目选择必须围绕AI转。

2024年7月，我把“AI”当关键词，把生财站内相关帖子和中标帖全刷了一遍，出现了一个异常现象：AI写作这个赛道，有好几位头部玩家已经跑出结果，而且他们的学员也在持续跟进，不是玩玩就撤。

于是我锁定了四位在AI写作上做得比较深的大佬，逐一加了朋友圈盯了一阵，发现迭代速度很快，且长期重仓。花了一个月做调研后，我的结论是：

- 赛道向：和AI沾边，和预期一致
- 做起来难不难：有新鲜的成功案例，学员经过培训也能放大，说明可复制
- 投入产出：主要拼人力，0到1的精力成本高，但回报比可观

判断清晰后，我就把这个赛道定为公司主线，全力押注。

### 选址那些事

建工作室初期先定场地，我把广州的众创空间全筛了一遍。第一次租场地怕踩坑，我还把每个场地的母公司老板都查了，实缴资金、名下公司全记录。现在回头看纯属瞎忙。

租场地真正重要的就几条：

1. 通勤时长：老板时间要优先，早期经常凌晨才回
2. 费用：押二付一还是押三付一、物业、停车、能耗、均摊都要谈清楚
3. 地段交通：招聘半径和地段强相关，交通方便覆盖面就大

小提示：合同看不懂就找律师。我大学做项目时就在闲鱼绑了一个线上律师，遇到问题付费咨询，拿到的建议很实在。

# 实证分析

## 4.1 实证分析是什么

实证分析 Empirical Analysis 指通过收集真实数据，用科学方法去研究，从而得出结论或验证理论假设。它强调数据驱动，借助统计、计量经济学、社会学等方法对现实现象进行分析和解释。

常规流程：

1. 研究问题提出：定好研究对象和问题，明确假设或目标。
2. 数据收集：问卷、实验、公开数据等途径获取数据。
3. 理论框架与假设：基于已有理论提出假设和框架。
4. 数据分析：用统计或计量方法分析，比如回归、方差分析等。
5. 结论与解释：根据结果验证假设并解释发现。

实证分析常用在经济、社会学、医学、心理学等领域，跟纯理论分析不同，它更依赖真实世界的数据来检验理论。

在AI写作里，单独做实证分析这个赛道在闲鱼也能变现，一单客单价在1K到2K左右。

### 4.3.1 描述性统计分析

概念：描述性统计用来总结数据特征，快速了解数据全貌。主要包括：

1. 集中趋势：均值、中位数、众数
2. 离散程度：标准差、方差、极差
3. 数据分布：偏度、峰度
4. 图形展示：直方图、箱线图等

为后续分析打基础，广泛用于市场研究、社会科学等。

![](img/fbaa3c1b5190c181d905837265b5ce02.png)

找到频数，把人群标签拖进去，系数用默认的，导师有要求再改

![](img/540291f7e76189d9aa74590e651758ff.png)

结果直接复制即可

### 4.3.2 信度分析

概念：信度分析评估测量工具的可靠性和一致性。主要类型：

1. 内部一致性 Cronbach's α
2. 重测信度
3. 分半信度
4. 评分者信度

信度越高，测量越可靠。

![](img/2ed84d09ded773db2c50d593b26211ba.png)

找到信度，把对应变量放进去

![](img/43b63582117f32961d3ccd987300fe5b.png)

结果复制

### 4.3.3 效度分析

概念：效度分析评估工具是否准确测量目标概念。主要类型：

1. 内容效度
2. 标准效度
3. 构念效度

效度高说明测量准确。

![](img/5793aada8d3e433b34d5a7328409ada7.png)

找到效度，把对应变量放进去

![](img/c375398f76d3e9af5804d20552f2f95a.png)

复制结果

### 4.3.4 差异性分析

用于比较不同组数据的差异，判断是否显著。常用方法：

1. t检验：两组均值比较
2. 方差分析 ANOVA：三组及以上均值比较

通俗说就是看性别、身份、类别等不同分组下变量的变化。

![](img/060115d6e404dabe057cb3dc9a7ac7e6.png)

![](img/63d6d3e9d45c383e16f0b8f5e08e8166.png)

![](img/4f115d5fd40c54baff27f35203100042.png)

选择方差分析，按需求操作

### 4.3.5 相关性分析

评估两个或多个变量间关系强弱和方向。常用方法：

1. 皮尔逊相关系数 Pearson
2. 斯皮尔曼等级相关 Spearman
3. Kendall相关系数

相关不等于因果。

![](img/9e0d9580a1456f9844582b96d02765af.png)

找到相关，把变量丢进去

### 4.3.6 中介分析

检验中介变量在自变量和因变量间的作用。路径包括：

1. 路径a：自变量对中介的影响
2. 路径b：中介对因变量的影响
3. 路径ab：中介效应
4. 路径c'：自变量直接效应

常用 Baron-Kenny 和 Bootstrap。

![](img/82e6b1a3251cf79bd24612ee964137a0.png)

把对应变量放到对应位置

### 4.3.7 回归分析

解释自变量与因变量关系。关键指标：

1. 回归系数 β
2. p值
3. R²
4. 调整后 R²
5. F值和F检验
6. 标准误

帮助理解变量关系和模型有效性。

![](img/a34a2c795f025d3441988589f3ebe480.png)

按论文核心因变量选择放入变量

### 4.5.2 AI不足 当下

AI坏处

AI当然不是完美的。

它有时会在原有内容上擅自发挥，补充一些并不存在的信息，甚至把错误内容写得像模像样。更麻烦的是，这些“编造”往往足够自然，如果没有进一步核实，普通人很可能根本察觉不到。

除此之外，AI偶尔也会出现各种不稳定的BUG。

但在我看来，这些问题更多属于发展过程中的阶段性现象，随着技术迭代和使用方法不断完善，未来都有机会被解决。

AI真正令人兴奋的地方，也不只是帮我们节省成本、提高效率。更重要的是，它让普通人第一次拥有了调用数据库、检索信息和验证观点的能力。

过去，很多信息差掌握在少数人手里；而现在，我们可以借助AI寻找资料、交叉验证结论、挖掘那些原本难以接触的信息。对普通人而言，这或许才是AI带来的最大红利。
