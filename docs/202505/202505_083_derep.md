# (精华帖)(122 赞)YouTube 魔法女孩虚拟 IP 打造，赚到第一千美元

两个月，2062美元——这是困困在YouTube上用“魔法女孩”虚拟IP赚到的实际收益。作为YouTube赚钱深海圈的实习教练，她的起步并不算早：去年才加入赚钱平台寻找副业机会，去年12月参加YouTube Shorts航海，今年3月中旬进入深海圈，随后把主账号方向定为魔法/魔术主题的少女虚拟形象，也就是虚拟人物IP赛道。3月23日账号开通首个YPP（YouTube合作伙伴计划），到5月14日，后台收益已经突破两千美金。


帖子发出后，评论区很快有了热烈讨论。有人称赞她“开辟了新赛道”，也有圈友从自己运营👸号IP的经历出发，提出了“虚拟形象+不同职业身份+热门场景”的组合玩法：比如让同一个虚拟角色拥有律师、医生、设计师等不同身份，再围绕对应职业去设计有热度的剧情。困困本人也在互动中鼓励大家：先报名航海行动起来，在实战中慢慢找感觉。

从一个模糊的副业念头，到第一个YPP开通，再到两千美元入账，困困的经历算不上惊天动地，却给所有关注YouTube虚拟IP的人提供了一个清晰的参考样本。
