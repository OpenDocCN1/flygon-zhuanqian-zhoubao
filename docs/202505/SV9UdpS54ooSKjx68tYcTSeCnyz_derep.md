# 小白看完就能学会！10分钟搭建📕批量图文爆款仿写助手（保姆级教程）

10分钟速通：从零搭一个📕图文仿写助手（新手友好版）

前两天在线下活动上跟云枢老师学了套智能体玩法，趁热打铁整理成教程分享出来。我原本也是零基础，这几天闲下来就翻了不少智能体教程，看多了反而觉得没那么神秘，说白了就是熟能生巧，多摸几次自然上手。这篇不掺水分，纯实操，大家跟着走完就能有自己的仿写小助手。

## 一、先建飞书表格

![](img/91c84ed4094fa4f41fc2b6accd9f7b46.png)
![](img/b21d60ca145fa65201fc4069a1d2b67d.png)
![](img/c08972bf8a0c8a5b9d1e981fae254bfd.png)

入口很简单：按下「创建多维表格」，建好之后把系统自带的那些无关设置藏起来。进到新页面，只留最左边一列，右侧三列顺手删掉。

![](img/690a9f9e50d5a3d76c8921bcc4ac4f62.png)

鼠标移到第一列表头，双击把默认的文本类型改为标题（右键也能改）。接着再按顺序把下列字段一一补上：【作者】【文案】【图片链接】【封面】【文章链接】【文案改写】【标题改写】。

其中有几列要用不同的方式处理：

1. 【封面】：类型选「附件」，然后在字段捷径里搜「链接转附件」，图片地址就能自动转成附件。

![](img/618f17f5efa3a90e5011f2fd4eb02ff7.png)
![](img/ad0350ce879d2356de03dcaee7eaad91.png)

2. 【文案改写】：类型选deepseek-R1，联网版千万别碰，烧token太狠。不懂token的朋友，可以把它理解成话费里的流量包，飞书起初会赠送若干免费额度，后面再充，成本不高。

![](img/88b3092aeae812aa0061246250b889e4.png)
![](img/7dbbff35511eea5f947062da3ab4f531.png)
![](img/ee2023de63ad009189fa416826fd76be.png)

打开配置面板，把「输入指令」的引用字段设为「文案」。提示词懒得写的话，用下面这段现成的就行：

根据 内容，按照以下几点进行分析“原文主题、关键信息、原文风格、目标受众、使用场景、需要强化的点、需要弱化的点、关键词”，并且根据分析的结果，生成一篇高质量的二创📕文案，我只需要你最后输出一篇高质量的二创📕文案

保存后，把「获取更多信息」和「自动更新」都开启。前者只勾「输出结果」就够，想看推理过程也可以，不过我个人喜欢表格清爽，就不放一堆多余的列了。

3. 【标题改写】：类型依旧deepseek-R1，其余操作跟上面差不多，看图即可。

![](img/9c43f4defb8e95bdb2b18b51b4b19e60.png)
![](img/d286bf246457a10bc0f1bd9c6732095d.png)

唯一要注意的：引用字段认准「文案改写，输出结果」。

提示词如下：

根据 内容，按照以下几点进行分析"核心钩子、情感燃料、风格锚点、平台特性"，并且根据分析结果生成十个高质量爆款标题，字数限制20字以内，我只需要你最后把分析出来的标题输出出来，不需要把你分析过程给我

至此，飞书这块准备完毕，进入下一环节。

## 二、编排工作流

工作流属于智能体下面的功能模块之一，此外还有提示词、插件、代码等构件，先不管，直接跟着操作。

![](img/6bd17fb462adb7d00b5aaa20a5b1a7bc.png)

打开扣子平台（https://www.coze.cn/），登录后前往个人空间。

![](img/52f3d34514d392654fec881dffa2a1b5.png)
![](img/e89b2eb0d90b2de94142484e30201d55.png)

选择「项目开发」，新建智能体。名字、简介都能自己定，图标就点我截图里标红的那块，交给AI自动生成即可。简介填不填都行，主要方便自己一眼看懂用途，别人看也明白。

![](img/aec8e4ef4a1d19d148382a89010ec2c4.png)
![](img/881e58a423b173b4af8af10de5cbd1ff.png)
![](img/4d9c29a1eeac45e0a1ad492e9fd59c28.png)

建完进入这样的主界面。

![](img/ce716cdaf2da0c7cae134c57a7c8e962.png)
![](img/967a66d12a14819c8fd45e909e30f0d2.png)

然后选择「创作工作流」。这里有个规矩：工作流起名只能用拼音，平台规定，原因未知。描述可以写中文，写明白就行。

![](img/b791521123c595aeff69c729ce4eaad3.png)
![](img/8ae02e372209494a6c92af691ea16a41.png)

进来后就是编辑器页面，先放一张最终效果图给各位参考。

![](img/d62f96f7efb683b7ab1f67fd18411952.png)

准备好了吧？接下来照着抄，不会有偏差。

![](img/a851c258d4b861bb255c0e9101972406.png)
![](img/bfbcc41aca9ddd3ab8e3a5f1e74524bf.png)

点「开始」右侧的+号，选择「插件」。检索「📕文章」，点插件右侧的箭头完成添加。

![](img/311c5a39cb749258b908893c39be3f37.png)
![](img/f4785146653b4f1af863f51a23b4881b.png)
![](img/e4bb85b2ac5d9610f0cef761b610a3f7.png)

这里最要紧的是搞懂节点之间的串联关系：上一个节点吐出的数据，会成为下一个环节的输入，两边字段名必须完全一致，不然流程必炸。

考试重点，连说三遍！

想通这一点，后面都顺了。还没理解的话，看这个例子：

![](img/916daa2e33023bb1d12d0666d4e67e4b.png)

万一手滑把工作流页面关掉了，也别慌，去资源库能找到刚才的内容。

![](img/cfd00d61a088e43f8f91f3ca60cd88bd.png)

具体步骤如下：

1. 在「开始」的配置区，把默认参数名改为url，别忘了勾选必填。
![](img/146d5f1fedfa2f0b95cff8b3b9b7b72f.png)

2. 点📕插件的齿轮图标，在「开始」里选url作为入参。
![](img/1b68954d1ff3c8e1975b10196aacd887.png)
![](img/cb535fd10d3dce0683cfe52b8cf9b8b8.png)

3. 新建代码块。
![](img/68754a86165478ca2dfc1931fb1a079c.png)
![](img/859efedbb01d25231c50acc44499a234.png)

代码块要处理的事多一些，但别害怕。先在输入区域点5下+，再把左图中的名字挨个填入。

![](img/85485aef4d5cfe255105b76d62d3ca21.png)
![](img/7189dfc5eb326150e76ffc60ffbe891e.png)

五个输入框，依次接到对应的模块上。

![](img/290ff1481c147158d03b01511448da98.png)
![](img/5a42a904c0ebad2eba9e8c5f8501d2ad.png)
![](img/15a81bfecc14319bd02b2bd5bdced590.png)
![](img/13dc3bcd0f3cdf90f641ebbda5c27b2c.png)
![](img/08d5c0903ab14e432cba821a9b7f2b2b.png)

接下来进入写代码的环节：

![](img/86d4eb160df883a235ae92f30e87e921.png)

把下面这段原样粘进去：

```typescript
async function main({ params }: Args): Promise<output>{
const fields = {
标题: params.title,
作者: params.nickname,
文案: params.content,
图片链接: params.imageUrls[0].urlDefault,
文章链接: params.url
}
return {
info: [{fields:JSON.stringify(fields)}]
};
}
```

贴完点右上角的X关掉弹窗，回到工作流主页。

![](img/c5608fa0c5ab030250ff364fbdc1d593.png)
![](img/ef84155cb8e1a927eb7ba5d0c64f3e2a.png)

接着修一下输出列，把key0、key1、key2这些默认项全清掉。

![](img/5e34f184cf1950a775321e27e7d15663.png)
![](img/9c0bdd60ac955674931f3418dab31b98.png)

清到底之后，变量名更改为info，类型切换为array-object。代码块到此完工，大家可以休息片刻，缓一缓再继续。

4. 再建一个插件。跟在代码块后面，检索「飞书多维表格」，选截图那个并添加。

![](img/d693522f7cf2bd9270b6100c7974094d.png)
![](img/c7a9065a4838a8884ee32723d15326eb.png)

apptoken一栏，把刚建好的表格链接粘进去就成。

![](img/9d0af8dbe043917174aae7fde9e3d601.png)
![](img/0d18ffac9e2b7b7947aeb36f1d63881a.png)

records取代码块输出的info即可，其余保持空白。

![](img/998e85d15c1f0785a4eeabfcb2f05379.png)

收尾时在结束模块里选add_records，再选msg。一切就绪，可以点「试运行」验证了！

![](img/0b8d8af40c84ea1e3bd14b33fa7e46f9.png)

任意输一条📕笔记链接，跑通后数据立刻落入表格。若失败，找到亮黄点的地方，点一下完成飞书授权，再跑一次即可。

![](img/9bf9bde9c9d74a250225284aca408ac2.png)

到这儿，主流程算是通了。不过有人可能会嫌每次进工作流有点费事，开头新建的智能体还记得吗？该它出手了。

## 三、给流程加上智能体外壳

先确认前面的步骤已经跑通，再往下走。

![](img/b578a96e86d8be3aaf125455a696aa29.png)

放上完成图，这就是最终形态。提示词抄我的即可：

无论用户输入什么，始终调用工作流

需要选择上工作流的时候，按住shift+{ 注意这个括号得是英文的状态

当客户输入无关内容时，提醒客户“请戳下方【点我开始】”开启工作流

括号务必要用英文输入法打出来。如果用户跑偏聊别的，就照提示词提醒他触发流程。

然后把要模仿的笔记链接丢给它，再到飞书表格确认产出。

当然，这只是个入门级工具，抓不了视频里的内容，服务图文类创作者刚刚好。要是玩过之后你对智能体来了兴趣，后面可以继续深入。
