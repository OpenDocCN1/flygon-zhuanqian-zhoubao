# ('(62 赞)04 年学生入局小红书电商，我是如何快速选到多个爆品的？', (2, 36))

一个04年出生的大三学生，没背景、没资源，靠小红书电商赚到人生第一桶金，总成交额25万+，利润超10万——这个故事听起来像运气，但她说，核心就一句话：选品定生死。

我是小加里奥。一年前，我还是那个上课刷手机、觉得大学条条框框太多、不愿参与学校体系的普通学生。闲不下来，总想折腾点自己的事。去年5月，从朋友嘴里第一次听说小红书电商，说实话半信半疑。我对内容电商几乎零认知，但凭着那股冲劲就扎了进去。前路踩了不少坑，好在没放弃——一个月后，单子突然爆了。一个多月时间，打出了1.7万单的成绩。那是我的第一桶金，也是我决定深耕这个项目的起点。

后来我加入了生财，把实操经验反复打磨，慢慢形成了自己的一套方法论。心态也从一开始的患得患失，变成现在的笃定。这篇文章，想认真聊聊我在小红书电商里最看重的几个环节，以及我最核心的选品思路。

内容不绕弯子，也包含一些心理层面的复盘，毕竟我也是从新人一步步走过来的。如果你刚接触小红书电商，放心读。

文章主要分四块：
1. 小红书电商拿结果，最重要的环节到底是什么
2. 选品定生死——我凭什么能连续选中多个爆品
3. 做小红书电商真正核心的东西
4. 结语
