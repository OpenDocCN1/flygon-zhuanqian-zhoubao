# (138 赞)在赚钱，就要靠不断的行动，躬身入局弄脏双手
作者：龙哥

你有没有发现，刚踏进赚钱圈子的头一个月，几乎人人都像打了鸡血——满屏的精华帖、实战复盘看得眼花缭乱，恨不得把每一条都收藏起来。

可问题恰恰出在后面：如果只是“看”，没有“做”，那股新鲜劲儿一过，剩下的就是铺天盖地的焦虑。信息越来越多，越囤越慌，最后干脆不知道该从哪下手。

这事儿，其实和赚钱很像。当你手里的钱多到一定程度，如果不去把它变成更有价值的东西——比如创造事业、帮助别人、投资未来——那赚钱本身也会变得空荡荡的，甚至让人迷失。

那破局点在哪儿？

说白了就一句话：亲自下场，把手弄脏。别光在岸上看别人游泳，要跳进水里扑腾。把你刷到的每一条干货、每一个思路，拿去试、拿去练，哪怕做得难看也没关系。做着做着，那些别人的经验才会长成你自己的认知、本事和底气，最后变成实实在在的收益。

这就是“干中学，学中干，边干边想，边想边改”。当你把信息真正消化成自己的东西，下一步行动就会更有方向，拿到的结果又会反过来给你更多信心——于是，一个正向的飞轮就这么转起来了。

在赚钱，从来不缺好内容，缺的是一个肯低头做事、把双手弄脏的你。行动，才是唯一的解药。
