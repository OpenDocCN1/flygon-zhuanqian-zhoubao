# 别将就，好的结果都来自不将就
作者：龙哥

想要到最好的结果，就别在中途妥协。

别委屈自己去接受身边平庸的人，别在自己不喜欢的工作里硬撑。很多人会告诉自己将就一下就好，以为这已经是能拿到的上限了，然后一忍再忍。忍得下去不代表合适。

真正打开局面的人，会明白这个世界远比你想象的更宽。机会不是等来的，是试出来的。你需要不断去尝试、去筛选、去升级人际和工作的配置，直到你真的遇见最匹配的人，走到最值得投入的事业上。
