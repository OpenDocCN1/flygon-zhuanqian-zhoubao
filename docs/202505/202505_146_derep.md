# 一个人、一台电脑，1年4个月，我是怎么拿到人生第一个100万的



大家好，我叫风小海。

现在在武汉落地生活，算起来在赚钱圈里混了三年了。背景是服装行业，路上既有亏钱的教训，也有赚到钱的经历。如今手里时间相对自由了，距离真正意义上的财富自由，还差那么一点点。

过去一年，我靠风向标的活动中标拿到了一张赚钱的年票。我自认不是那种一眼就能看明白局势的天才玩家，只是踩过的坑可能比你稍微多一点，走过的弯路也更弯一些。正因为这些经历，我想把这些年亲手验证过的变现打法，一点点整理出来。从现在开始做一个小尝试：连续输出100个真正跑通过的项目笔记，写给那些想踏实生活、踏实赚钱的人看。

这篇内容说的就是我从零开始，到拿到第一个100万的全过程。耗时大概一年零四个月。中间只用了一台电脑一个人干。

文章里会具体讲到我碰到了哪些卡点、哪些阻力，以及当时我是龙哥。没有灌鸡汤，也不是那种一帆风顺的爽文。更像是一个人在废墟上，自己一锤一钉把地基重新垒起来的记录。如果你现在也在低谷期，或许这点真实的经验能给你一点点光。
