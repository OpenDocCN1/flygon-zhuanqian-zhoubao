# (53 赞)从小米“智驾”更名，聊聊名字在传播中的意义

你有没有发现，小米SU7标准版上的那套Xiaomi Pilot Pro，悄悄改了名字：从“小米智驾Pro”变成了“小米辅助驾驶Pro”。为什么改？前阵子它被连续推上新闻风口浪尖，随后监管部门发话——谁也不许再叫“智驾”了。

别小看这一个词的变化，它背后藏着对“传播”的深刻理解。

名字不只是标签，它本身就是定义、指导和解释。车企明明会在手册里写清楚辅助驾驶的边界，可顾客哪有耐心看？大家就是靠名字来感受功能的。你叫“智驾”，人一听就觉得“它能自己开，我可以睡大觉了”；你叫“辅助驾驶”，人自然就懂“这车还是得我盯着”。一字之差，认知天差地别。

在中国做传播，命名更是头等大事。儒家讲“名不正则言不顺”，还专门有个词叫“名教”。我们对名字的重视，是几千年文化里长出来的。看看文艺作品就知道了：老外书名、片名常常朴素得像论文标题，吕克·贝松的电影原名叫“Leon”，翻译到中国就成了《这个杀手不太冷》；Spiderman是蜘蛛人，到了咱们这儿叫“蜘蛛侠”；Ironman是钢铁人，叫“钢铁侠”；Wolverine本来是狼獾，叫“金刚狼”——是不是立马比原来高大上？再看称呼，英语里一个brother、sister大小全包，姨妈舅妈姑妈也是同一个词；汉语呢？表兄表弟、表姐表妹、叔伯兄弟、两姨姐妹、姑舅亲，关系光谱被名字切得清清楚楚。国外的老品牌，过去也大多拿创始人姓氏来当名字，直到后来姓实在不够用了，才有了各种新造词。所以在中国做营销，商品名、品牌名，绝不能随随便便取。

名字甚至可以左右一个产品的生死。“预制菜”就是最典型的案例。按行业定义，预制菜分四种：即食食品，拆袋就能吃；即热食品，加工好冷藏冷冻，加热一下就能上桌；即烹食品，帮你处理到一定程度，还得自己下锅；即配食品，就是配好的菜，买回来还得自己洗、切、炒。按这个标准，汤圆、速冻水饺、馄饨全是即热食品，可大家从来不反对；菜市场、街边的卤味，也是即食食品，照样受欢迎；过去餐馆里的馄饨汤圆很多都是提前包好冻好的，谁也没觉得有问题；即便是“现炒”，那些调料和配菜，哪个不是提前“预制”完成的？面包店更是预制的主力，所谓现烤热出，面团是工厂预制的，冰箱里的冷出就更不用说了。但“预制菜”这三个字一出来，与“现炒菜”形成了强烈的对比，于是整个品类被一棒子打死。许多骂预制菜的人，家里的冰箱却塞满了速冻水饺——名字的杀伤力，就是这么不讲道理。

人理解新词，靠的是拆解旧词。“非典型性肺炎”大家从来没听过，但“非”“典型”“肺炎”都是认识的，组合起来就明白了。“非典”这个缩略词倒是相对中性，但有些词就没那么老实了。“预制菜”听着就不太想碰；“牛油果”听起来高级、健康，但它的旧名“鳄梨”是不是瞬间让人想起鳄鱼？再举个例子：“民族社会主义德意志工人党”，99%的中国读者第一回见到，拆开看全是正面的词，民族、社会主义、德意志、工人、党，甚至会以为是个进步组织。可一旦知道它是“纳粹”的全称，印象立刻反转。这就是命名带来的联想。

一个真正的好名字，能节省大量解释成本，还能自动输送好感。“发财树”就是活例子：学名叫瓜栗，也叫马拉巴栗，平平无奇；可一旦叫“发财树”，哪个老板的办公室不得摆上一盆？

说到底，人类的所有沟通，都要靠命名。没有名字，任何事物、概念、难题都没法讨论。命名甚至是事物“存在”的前提，海德格尔说：词语破碎处，无物可存在。

而且，命名的力量比话语更直接。我们服务逮虾记时，打造了新品类“虾排”，又因为虾肉含量达到95%，直接将它命名为“95纯虾排”。如果只写口号“逮虾记虾排，虾肉含量高达95%”，大家还会犹豫、求证；可一旦“95纯虾排”成为名字，它就是铁一般的事实，没人会去质疑。反过来想想，“预制菜”这个命名，让所有人都认定它跟现炒无关；如果当年有聪明人把它叫成“速冻菜”，舆论也许完全不同。

所以，下次再看到产品改名，别觉得只是换个说法。名字，从一开始就决定了它会被怎么理解和接受。
