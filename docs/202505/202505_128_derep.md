# 当亲人深陷赌瘾，你能做的不是拯救，而是放手

日期：2025-04-22

提问：

龙哥老师您好，我想向您求助一个让我非常困扰的问题。

我身边有位至亲，从2020年开始沉迷购买体育彩票，信用卡被刷爆到征信黑名单，还在各种网贷平台上借了个遍。家人发现情况后凑钱帮他把债务还清，并且进行过很严厉的管教。结果戒断仅三个月，他又偷偷重操旧业。现在又一次负债累累，欠款已经数万元。每次投注从几百到上千不等，平均下来每天要花掉一千元左右。他的工资全都进了赌局，甚至还编造理由向朋友同事借钱，已经让不少人血本无归。

我本身是个重感情的人，长期的奔波和纠结耗尽了我大量的心力，直接影响到了我的创业节奏。真的很两难：放任不管于心不安，强行介入又无计可施。对这类状况我完全是新手，毫无头绪。想请教，有没有真正从赌博里彻底走出来的真实例子？或者有没有同样身为赌徒家属的朋友，可以分享一下你们当时是如何处理的？恳请大家给点实操建议，万分感谢！

回答

放下拯救的执念，尊重他的人生轨迹。
