# 拆解一个老牌虚拟项目：流量包充值，单号年入 1-2 万的被动玩法

最近加入赚钱，刷到不少关于虚拟资料变现的干货，受益不少。今天也把自己几年前实操过的一个虚拟项目拿出来复盘一下，项目品类就是“流量包充值”。

这个项目是我很早之前就开始做的，属于典型的低门槛虚拟类目。跑下来之后比较稳定，放到现在依然能吃到长尾效应。一个账号养起来后，后续基本就是被动的状态，每年能稳定带来 1万 到 2万 左右的收益。

最火的时候，项目刚起步那一年，单号的年订单量就接近 1万 单。虽然现在流量环境变了，但模式本身的逻辑还在。
