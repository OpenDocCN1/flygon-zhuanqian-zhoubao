# (精华帖)(266 赞)通过合理投资与创业实现财富增长，同时要保持正确心态。
作者：龙哥

今天分享一篇很实在的访谈，五个问题，聊透了投资、创业和心态。内容不短，但是值得看完。

第一个问题，过去五年最大一笔钱怎么赚的？

我其实没有精确统计过五年到底赚了多少。以五年为周期看，来自证券投资和生意经营的回报大致相当。差别在于，投资端的收益常常在某一两年集中兑现；而生意端的收入则相对平稳，年年都有。我更愿意双管齐下，把生意赚来的钱再次投入证券市场。

实际上，除了一些房产和其他小投入，我几乎把所有现金和持续现金流都放进了股市。底层逻辑是，我做的生意启动成本往往非常小，可支配现金流因此越积越多；这些钱再放到更稳定、比我自己的生意更优秀的企业上，长期复利的效果会非常惊人。

举个例子，两年前我在老本行职业教育之外，孵化了餐饮品牌马厂老火锅，如今已开出100家直营店。假设门店数量不再增加，而投资端能复利15%，那10年、20年、30年后的回报分别约为4倍、16倍、66倍——相当于凭空多出3个、15个、65个马厂在给我赚钱。

同样，我把创业20年的收入全部投入证券市场，按15%年化算，未来30年里就像有3个、15个、65个“我”同时在为我打工，仿佛平行世界里的分身，把收入都汇给了同一个自己。

所以，多赚一点当年业绩，远不如把长期平均年化稳定在15%。单年赚很多或赚很少，都不如稳定一直在路上。我花更多时间想的是：怎么保证不亏钱，怎么在最低风险乃至几乎无风险的前提下，拿到安全范围内的最高回报。

经营公司时，我不太关心今年多赚几个点，而是想怎么延长企业的寿命，把本来只有十年盈利空间的生意，做成二十年甚至更久。这大概是我和多数人思考方式最大的区别。

很多人自称价值投资，拿了两三年亏了，就断言中国没有价值投资；还有人觉得价值投资等于死扛。听着都很有道理，其实恰恰说明，大多数人对投资还停留在门外。

我的持仓里，有腾讯这种拿了很多年的“长期持仓”，也有新东方这种只拿了一个月的“短线”。下面讲一下新东方。

这只股票在不到一个月里带来了约4000万利润。买入时正是董宇辉刚开始走红，股价约9.1元。我本来就在互联网行业，在抖音也有直播经验，知道能从蝉妈妈这类平台看销售数据。所以董宇辉走红后，我一直在盯他们的销售额和粉丝数变化。

当董宇辉真正破圈时，很多股民和机构还没反应过来，东方甄选的销售额已经是每半天增长几十个百分点。我按净利润5%、10%、15%快速估算，公司至少值250亿到350亿，对应股价约30元，显然值得买。

这种机会很特殊。政策打压时，新东方市值只剩几十亿，像辆破自行车；后来东方甄选出现，底层逻辑彻底变了，破车直接变摩托。朋友说5块钱时就想过买，我告诉他，5块买入并不比9块买入高明，因为没有确定性支撑。你不能在新东方还是一辆单车时，仅凭“俞敏洪应该能东山再起”就买入，那是情绪，不是逻辑。

而且“想买”和“真的买”中间隔着千山万水，“买一点”和“买到位”又完全是两回事。这两道坎加起来，足以让白日梦永远只是白日梦。另一方面，我对直播这种增长的持续性和可复制性缺乏足够把握，所以没有下重注。但面对一道送分题，我选择了买入“买少了不后悔、涨飞了也不眼红”的仓位。买过十倍大牛股却只拿了一点仓位的人，可能会懂这种心情。面对机会，要根据风险等级决定仓位大小。

后来它一度冲到六七十，但我对它的估值判断只在30以内。我不希望等它停止增长时还拿着它，那会让我睡不着。于是我们这段不到一个月的“热恋”就结束了——也怪它，一个月就涨了三倍。

这个例子说明，持有时间长短不是判断价值投资的标准；真正与时间紧密相关的是复利。

真正让我安心的是护城河深、业绩持续向上的公司。短期股价可以上蹿下跳，但最终还是会回到业绩曲线上。2019年买腾讯时，它净利润约1200亿，到2025年预计有2400-2500亿。这种公司，股价再怎么震荡，最终都会沿着利润增长线走。赚这种钱，我睡得踏实，平时不用看账户，不用操作，钱就像呼吸一样自然，躺着也能进账。

过去五年腾讯股价像过山车，我从300多买入，最高到过760，后来跌破200，如今又回到500多，账面利润也随之起伏。但我的原则很简单：涨也开心，跌也开心。腾讯低估的那几年，我一路加仓，现在持仓是最初的近4倍。等企业增长兑现时，我赚的是原来的好几倍，还有什么比这更开心的？

市场给我机会，对不懂的人是噩梦。一组数据：中美股市里，即使公司能做到年化20%的复利，平均每三年也会有超过30%的回撤。只想要结果、受不了波动，注定赚不到大钱。所以，真正赚大钱的人，通常都不觉得累。

第二个问题，未来一年最看好哪些赚钱机会？

这个问题问得我有点为难。我很少用一年周期看机会。给大家一个建议：频繁换项目、换股票，都不是聪明的做法。既然非要聊一年内的机会，我分为两类。

第一类，一切从低成本启动的项目。我自己就是轻资产创业的受益者。最大的投入是马厂老火锅，投了一百多万，后面一边开店一边靠利润滚动，才变成100家店。对餐饮业来说，100多万可能连两家店都开不起，更别提两年做成100家。我另一家公司米课，做教育快15年了，成本只有3万注册费，那还是为了合规才存的。更早的海外创业，要么零成本，要么几万块起步。

什么叫创业？其实就是无中生有。如果一上来就要砸几百万上千万，那么要么是奔着几十亿的大生意，要么本质上就是投资，不是创业。因此，只要启动成本接近零，就值得去试。哪怕判断全错，你也没有损失，反而能得到十次、几十次试错机会。

第二类，顺势做当下热门项目。热点自带流量和需求，问题是人人都能看见，竞争会迅速白热化，利润越来越薄，最后变成连狗都懒得做的生意。当然，我知道很多人只想尽快赚到钱，这不是嘲讽，而是说要分阶段。如果你刚刚起步、迫切需要第一桶金，热点项目确实可以作为一个入口。

第三个问题，如果只有10万，一年内要变成100万，会怎么做？

10万到100万，一年时间，说起来不难，其实根本不用10万。股票市场里，投资不可能给你这种回报；投机有可能，但更大概率是连本金一起输掉。所以剩下的路径只有创业，这正好符合我前面说的“无中生有”。为什么不用10万？因为只有靠买卖实物赚差价才需要钱进货；而做虚拟服务，几乎不需要本金。

我自己做知识付费很久了，以我的经验，只要你足够想赚钱、足够勤奋，愿意没日没夜地干，那赚到100万根本不是问题。方法很简单：把自己熟悉的知识打磨成产品；自己不会，就去找一个会的人。目标很小，用BOSS直聘就能解决。举个例子，做财务培训，最好卖的一定是税务课，因为老板都怕税务问题。你可以在BOSS直聘上一百个财务人，找一个脑子活、口才好的，你负责运营包装，他负责讲课直播。你的时间要100%压上：能直播就直播，短视频不断拍，👸号不断写，电话销售、线下活动全部安排上。初期免费也行，等跑通了，线上+线下一起收费。

我敢打赌，只要你做到一年休息不超过5天的勤奋，最终赚到的绝不止100万。这让我想起健身教练：我体脂率已经很低，手臂和大腿青筋都看得见，却一直没有腹肌，于是总问教练。教练说，水煮菜吃三个月就有了。但到现在我还是没有——因为我连一天都没坚持。所以你看，随便一个项目都能做到百万级，真正执行的人却只有1%甚至更少。希望这篇分享能给大家一点启发。

第四个问题，有没有觉得“太累了”“不想干”的时刻？

我确实有喊累的时候，但通常是在事情干得特别漂亮的阶段。我很少心累；身体累说明我清楚自己要什么，一天恨不得掰成两天用，这种累，其实是一种冲劲。最紧绷的一次是2017年做米课App。当时公司必须从网页端转型到移动端，可我根本没有App开发团队，只有一个PHP程序员和一个前端。那年我真是不分昼夜地赶工。从零团队到做出一个集社交、直播、线上课程、裂变、私信于一体的App，还要同时支持iOS和安卓双端，我们只花了3个月。这中间还包含了我这个外行面试几十个程序员的经历。后来大厂朋友看了产品，都说三个月能做成这样很不容易，我自己也有点得意。

技术从来不是门槛。那时候得到App把课程放在首页，市场都认为这是标准设计，团队也建议我照着做，我直接否了。因为我信人性：没有人（或极少数人）真的爱学习。再像得到那样充满知识，用户第一眼或许喜欢，但人性深处最关心的还是八卦。外贸圈又是一个小圈子，正好适合做社区。所以首页我坚持用个人动态信息流，而看课的入口被藏得很深，放在底部菜单的“我的”里面。因为客户花了钱，就算入口埋到四级页面，他们也一定能找得到。事实证明这个设计很成功，后来我五年没怎么管公司，App活跃度仍然不错。

说到“不想干”，主要出现在疫情那段时间。在家办公久了，购物欲也不强，钱渐渐变成数字，20岁时的激情也就淡了。也正是那段无聊的日子，让我跑到B站做了《一亿实盘》，还搞了12小时吃火锅直播聊天。回头看，很多事像是注定。2019年我决定躺平，2022年却鬼使神差去做餐饮连锁，没有刻意追求，也没有一丝焦虑。躺平就好好躺。2002到2019年，我几乎没真正休息过，不是身体累就是心焦虑，所以那段时间我躺得心安理得。

如果非要说建议，我觉得与其要求自己每天进步一点点（这太难坚持），不如改成每周进步一点点。机会总会来，而你已经积累好抓住它的能力。缘分和机遇非常奇妙，往往在你完全没想到的时候出现。所以焦虑等于做无用功，过好每一天，反而更有可能收获惊喜。

第五个问题，穿越回去，会对刚起步的自己说什么？

这问题让我意识到自己已经是大龄创业者。真要说，可能得对20年前的自己说几句。我想说的是：早点健身，找一项你真正喜欢的运动。它们会带来无形的快乐，而且必须靠时间积累，才能回报远超普通人。但我也可以什么都不说。过去20年，我对自己的状态总体满意。世间很多事都动态平衡，也许正因为我把大量时间献给了事业，才得到了相应的收获。如果我从那时就迷上运动，现在可能正为钱发愁。每件事都标好了价格，只不过不到最后，很多人看不透。

总而言之，过去无法改写，纠结和怀念都没有意义。不管之前的岁月是光鲜还是灰暗，只要你想改变，从今天起就能改变未来的方向。认真过好每一个“今天”，它们串起来，就是我们的未来。
