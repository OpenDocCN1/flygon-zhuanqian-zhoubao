# 高客单副业：酒店代订，这条冷门赛道我研究了很久

作者：风小海

很多人问我，除了服装，还靠什么在赚钱。我在武汉，混赚钱老圈三年了，亏过、赚过，现在时间自由，离财富自由就差那么一点点。

过去一年，我靠发风向标换来了一年赚钱门票。我不是什么天才，只是踩过的坑比你多一点点。所以我想把自己亲手验证过的项目，一件一件掏出来写清楚。这次挑战是分享100个能真正落地的副业，全是给认真生活、想认真赚钱的人看的。

今天要讲的，是酒店代订。

说实话，可能全网第一次有人把这个项目这么系统、这么坦白地摊开来讲，会得罪不少同行，但也应该能帮到更多人。

现在太多普通人只想找一个稳当点的副业，连创业都不敢想，能多赚一千块就已经能喘口气了。酒店代订这个生意，恰好符合这个需求。

它不用囤货、不用打包发货、也不需要你上镜直播。只用一部手机，话术在线一点，就能开跑。

而且哪怕你最后没打算做，也能学会自己订酒店省钱。出差、旅游，都能省下一笔不小的开销。

最关键的是，这门生意没大家想的那么门槛高，也没那么卷。
