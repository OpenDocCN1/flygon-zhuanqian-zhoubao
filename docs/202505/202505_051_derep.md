# 从 0 到月入过万：我用两个月在闲鱼做虚拟产品的一个复盘

最近整理了一下自己在闲鱼卖虚拟资料的经历，感觉到了分享的节点。

我是龙哥。2024 年 4 月，经叁斤老师的推荐加入了赚钱，一路潜水学习了整整一年多，这还是我第一次正式发帖把经验沉淀出来。

这次复盘的核心很简单：通过闲鱼切入虚拟产品，两个月内从零起步，月收入突破一万。


短评区也有几个问题挺有代表性，顺手回应一下：

有朋友担心买家拿到资料后降价倒卖，会不会形成恶性竞争。确实会存在这种情况，我的应对方式是把交付放在飞书上，通过权限控制来管理传播范围。

也有朋友好奇我得物运营做得还不错的操作方法，这个我先整理一下，准备下期再详细聊。

最后想说一句，也是目前做下来最深的体会：方法看得再多，不如一步步照着做。执行力才是把 0 到 1 拉起来的关键。
