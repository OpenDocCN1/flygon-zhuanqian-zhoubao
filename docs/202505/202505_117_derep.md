# 生财有术第9年：邀你成为“种草官”，一起让好物被看见

各位好，我是黄小鱼，生财有术团队里排号第四的员工。今年对我来说有点不一样——既是我陪伴这个社群走过第九年，也是我正式加入团队的元年。

前些天，一位圈友跑来告诉我，她偶然看到我的司龄信息，觉得特别意外。她没想到生财已经坚持了这么久，而团队直到2019年才逐渐搭起架子。如今会员总数将近七万，核心工作人员却始终不到五十人。

对团队来说，每年418都是一场硬仗，但也是我们和圈友们贴得最近的时候。我从几年前开始接手这个项目，每一轮活动都忙得脚不沾地。昨天，一个新加入的圈友对我说：“直播的时候，其他人都笑得挺开心，只有你没笑。你是紧张，还是累着了？”看到这句话，我心里一下子暖了起来。

我们最自豪的时刻，就是看着新人不断冒头、持续活跃、拿到成果，最后变成下一个闪闪发光的名字。这种成就感，比什么都珍贵。

这些年，有太多人是因为先“种草”而被大家熟知的。他们真诚分享、认真做事，逐渐积累起自己的影响力，获得更多合作与支持，也打开了成长空间。

生财有术的第九年已经扬帆，我想对所有圈友说：来做我们的“种草官”吧，把那些适合的朋友，带上这艘船。
