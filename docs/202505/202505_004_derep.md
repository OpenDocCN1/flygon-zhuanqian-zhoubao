# 一篇👸号长文，直接拆成一套📕爆款图？Gemini 2.5 Pro 直接把我整破防了
作者：龙哥



作者：Super 黄
日期：2025-05-12

说真的，做内容的人都有这个痛点：👸号的长文写完了，兴致勃勃想搬到📕做二次分发，结果卡在了「做图」这一步。

我自己手里就有个📕小号，粉丝将近一万，结果长期吃灰，就因为每次都要重新裁 3:4、排版、做封面，一想到要出几张配图就直接放弃了。

之前还特意去问身边做运营的朋友，有没有那种一键把文章转成📕图的方法。结果问了一圈，压根没有现成工具可以用。

既然没有，那就自己造。

直到我把这件事丢给了 Gemini 2.5 Pro Preview 05-06 去试，效果直接让我叹服。真的能把一篇完整的长文，拆解成多张符合📕审美的竖版图文，效率感人。具体生成效果的截图我放上来了，大家感受一下。
