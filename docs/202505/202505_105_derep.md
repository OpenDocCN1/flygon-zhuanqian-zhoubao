# 从六位数到七位数，04年大学生用一年做的六件事
作者：龙哥

作者：小鹅

2025-04-25

我现在正坐在回杭州的飞机上，滑行带还没断开，起飞前最后五分钟，趁这点空档把这一年的复盘先发出来。

这是我在赚钱的第二个418，也是我连续第二年做年中复盘。去年的那篇复盘发出来后意外拿到千赞，让我受宠若惊。于是我决定把每年在赚钱见到的关键人物、关键事件、以及对我冲击最大的认知节点整理成一个系列，希望能一直写到龙哥老大退休。

去年对我而言，是20岁到21岁的一年。

这一年我从一个纯观众变成了线上的嘉宾，从一个人单打独斗的个体户，慢慢搭起了一个线上小团队。打法也从早期的免费矩阵，转向了更注重付费流量的模型。营收从六位数跨到了七位数。这一路上的变化太多了，我想把经历拆开说说，希望对刚入场的新人有点用。

我今年04年，211大学大三在读。方向一直是流量、私域和AI写作。

下一篇见，我们第三年418再见。
