# 从月入过万到带队30人、运营400多个闲鱼账号，我是怎么跨过“不敢扩张”的心理关？



**闲鱼从月入 1 万到打造 30 人，400+账户的工作室，我如何迈过“怕扩大”的坎**

作者：杨小六
日期：2025-05-12

做闲鱼做到月入一万，几乎每个人都会卡在同一个问题上：

要不要开始招人？要不要把单人作战变成工作室？

这个节点上想法很矛盾。既不想再一个人熬夜打包、回私信把自己累秃，也害怕一扩张就失控，收入不增反减。更怕的核心是：老账号被玩坏了、同事学走手艺自己单干、好不容易攒起来的心血被搞砸。

我完全懂这种犹豫，我就是从这个坎里爬过来的。

从一个人扛下所有流程，到迎来第一位客服，再到划分小组、最终做到30人规模、400多个账号在跑，这条路我走了整整6年。中间试过错、摔过跤，也总结出了自己一套能持续变现的操作打法。

今天就用过来人的视角，帮你梳理这条升级路径，尤其是最关键的【1人到10人】过渡期，哪些环节可以放心交出去，哪些环节必须牢牢抓在自己手里。
