# 想在 Chrome 里顺畅阅读中标风向标？这个插件已上架，分析区自动展开

如果经常在 scys.com 上查看“中标风向标”，你可能会注意到：详情页正文下方的那块分析内容，总要手动点一下才能展开。现在这个问题有解了——一位开发者专门做了一款 Chrome 插件，而且已经正式上架 Chrome 网上应用商店，任何人现在都可以直接安装使用。

装上之后，效果很直接：打开任意一条中标风向标的详情页，正文下方会自动出现一块“分析”区域，并且是展开状态，省去手动操作，看起来更清爽。

作者也坦诚，第一次进入页面时可能会觉得加载稍慢，这部分他还在继续优化，所以遇到卡顿别着急。

想安装的话，具体安装步骤和详细说明都在下面了，直接点击即可：
