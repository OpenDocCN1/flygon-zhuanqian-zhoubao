# (精华帖)(60 赞)如何做一个接入 AI 功能的站？如何做一个 UI 精美的站？

想搭一个带 AI 能力的网站，还想让界面看起来足够精致？这篇实战记录值得你花几分钟看完。圈里之前有人抛出过一套方案，但我实际看下来发现，那套做法要付的网站费用并不低，对普通玩家来说门槛偏高，不太友好。于是我自己重新摸了一条路：API 免费接入，页面照样能做得漂亮。

我做出的成品是 picassoai.top，感兴趣可以去看看效果。同类型的参考站点还有 raphael.app、ghiblio.art、youphoto.ai，拿来对照学习挺合适。

这篇文章主要讲两件事：一是 AI 图片站从零到上线的完整流程，二是怎么把前端做得顺眼又好用。为了搞定前端 UI，我干脆自己做了个站点，把常用的 UI 组件和配色方案集中起来方便随时查阅，还补了一些 UI 基础知识点，地址是 iu-topaz.vercel.app。话不多说，全是实打实的干货。
