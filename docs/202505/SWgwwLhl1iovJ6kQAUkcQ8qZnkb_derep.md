人生的走向，有时候比剧本还离谱。去年我在旅途中随手敲下的那篇文章，意外收获了几千人的认可。那时候我还在康复期，心里攒了很多话，写出的东西反而有温度。今天又是赶路途中——刚从考场出来就奔向机场，想在起飞前把这篇写完。既然有了第一篇，不如每年写一点，把这个习惯慢慢养成一个小系列。

# 一、我最重要的“资产”，是那串通讯录名单

如果要我说手里最值钱的东西是什么，我会毫不犹豫地回答：是我的社交通讯录。只要打开它，几乎每个卡点都能找到对应的人帮忙解开。有人关键时刻点拨我，有人辅助我做判断。做产品卡住时有产品老手，内容方向迷茫时有内容搭子，账号矩阵理不清时有人帮忙梳理，连社交动态的文案写不出来，都能找到人来救急。

![](img/d5313827e335399817ca7eae0b3174b4.png)

![](img/15ec048ada0ccb63f68939616fdae329.png)

![](img/9bb2c07bdb3a3fdeaaac45fb518a25eb.png)

![](img/31e0f74238bea7b31953836b3f167c07.png)

再细小的事也一样：想买个效率工具模板、车刮了不知道找谁修、搬家要请收纳师、想卖掉闲置的饰品……我都能在圈子里找到靠谱的人搞定。

之前和朋友吃饭，聊起这件事，他给了我一个更高的视角。他说他认识的一个人，平常话不多，习惯听别人说；但他会带着观点去请教别人，问对方怎么看。我朋友曾好奇地问过那个人为什么这么做，得到的回答是：每次想启动一件事，他会同时找五个已经拿到过大结果的人，每人问一遍他的视角，或者换作对方会怎么操作，再回来对照修正自己。而且这五个人最好来自不同赛道——产品、内容、流量、个人品牌，各来一个，免得被同一种思维裹挟着带偏方向。

我又问：要是几个人给出的方向互相矛盾，或者和自己的想法完全相反呢？他说：那就思考每个人建议背后的出发点，快速选定一条路径去试，拿到反馈再调整，别让精力死在犹豫和内耗里。

这话像一根针，扎醒了我。第二天，我就把拖了半年的事启动了起来。

那问题来了，怎么才能让通讯录里满满当当都是高手？

第一步，去社群的网站搜索感兴趣的关键词，按点赞排序，筛选参加过官方航海的成员，找平台主理人要到对方的联系方式。第二步，认认真真准备一段自我介绍，三个要点：做什么业务、业绩亮点、谦和有礼。第三步，抛出一个有份量的问题。

什么算有份量？比方说，你已经做出了一条完整的业务链路，从获客到交付全部跑通，还附上了几张数据截图——那就该问“接下来是深耕现有方向还是横向扩品类”。要是问“我没有基础，能不能入行”，对方基本就沉默了。

还有一条更省力的路径：报名参加大型线下活动，在现场找机会直接和合适的人交谈。聊完加个好友，把自我介绍发过去。通常熟人带熟人，答案很快就有了。

有几点边界要注意：别窥探隐私，别有占便宜的心态，也要想着自己能为对方提供什么。

如果在这个圈子里一个熟人都还没有，那就先完成一个小目标：认识五个圈内人。

# 二、定期和比自己“高一截”的人坐在一起

同样是在那顿饭里，那位朋友说了一句话让我印象很深：“想一直保持向上，最有效的办法是让自己成为社交圈里实力最弱的那个人。”

找项目的参照物也一样。现在月入一万，就去看月入十万的人在做什么；月入十万，就去看月入百万的动态。别老盯着数字差异，要看对方具体有哪些动作是你没有的。你一天收到一百个潜在客户，对方一天一千个——他是不是多做了几个平台？你只做了两个渠道，他又开了哪些新渠道？你一天发三条内容，他一天铺几十条；你的成交比例是两成，他是四成，那就去反复琢磨他的说辞、节奏和跟进方式。

这些信息，光靠在线上发消息根本问不出来。真正有价值的东西，几乎都藏在线下的饭局和闲聊里。我翻看自己这两年的历程，每一次明显的成长和顿悟，都出现在社群活动前后——但不是会场内，而是在去会场的路上、结束后的聚餐、几个人窝在一起聊天的时候。

今年三四月，有几段对话深深影响了我。在北京，一位前辈看着我说：你们年轻人做事看起来乱糟糟的，但那股蓬勃的劲儿很动人。

![](img/002d8a00f62ce9f35b1726d24becfe38.png)

另一位朋友说：这个社群里很多跑通了闭环的业务，利润做到百万以上并不稀奇，卡住普通人的从来不是项目，而是组织能力和执行力。还有人说：一切都要靠数据说话。还有一位做内容的人告诉我：做用户画像不能贴标签，要想清楚目标用户具体是什么样的人，年龄、家庭背景、经济状况、情感经历、消费习惯、受教育程度，甚至她男朋友对她好不好——你想赚谁的钱，脑子里就要浮现出那个人的样子。

还有一个比喻戳中了我：在传统领域学到的东西像冷兵器，而在好的圈子里学到的是一套现代装备，带着后者回去，等于降维。他末了还朝我打趣一句：你该不会又在群里秀了一把就下线了吧。

![](img/6d36a33ee6f5a0c46dbb319f75a3e0e9.png)

行，扯远了。总之，定期和认知水平远高于自己的人线下碰面，带上高密度的问题去，是成长最快的路之一。

# 三、做那个“一提某个领域，大家第一个就想到你”的人

我的业务增长，很大程度依赖老客户的复购和转介绍。经常什么都没做，就有人来加好友，开口就是：“我之前听谁谁提到过你，想请你帮我做……”

每个人的视野半径都有限：剪头发不会跑到一公里外找Tony，请家教不会跨越大半个城市，订酒店也基本翻不开平台的前几十页。所以一旦你的名字和专业成了很多人视野内的“最优选项”，需求就会自己涌过来，收益反而是副产品。

这背后有两件事要刻意去做。

一件事，是让自己高频地“被看见”。我本身爱看电影，加过好几个影迷群，聊得深入了，大家都知道我在做什么，于是不断有人把朋友推荐过来。后来进入线下社群，每场活动我几乎都会留下来帮主办方收尾，或者承担拍照、记录、整理之类的杂活。次数多了，只要参加过同一场活动的人，大概率都认识我。这不是做样子，而是在主动付出中自然走进了别人的世界。

另一件事，是敢于、并且善于把自己的价值说出来。我观察到很多人自我介绍时会陷入两个极端：要么信息太杂让人抓不住重点，要么支支吾吾不敢讲清自己在做什么。别人不是不想给机会，而是压根没听懂你能交付什么、能不能被信任。

有一次我对象在活动上介绍自己，只说了两句话：“我在做一个面向人工智能的工具，也在尝试这个方向的内容机会。”我回去直接把他骂了一顿——这种介绍等于什么也没说，没有任何可记忆的信息点。

后来他开始认真梳理自己的介绍。在一场大型活动上，他因此认识了好几个大客户；再一次直播时，他见缝插针介绍了自己的网站，现场就有千万级身家的人说“今晚最大的收获就是认识你”。

![](img/e1d166c0c6cb798d8f41ccc65035ae92.png)

想要机会，先让自己被看见。一个人哪怕站在生态位上游，资源与信息也会自动向他聚拢。

# 四、真正值钱的东西，都藏在细节的夹缝里

前几天和朋友聊起知识付费。我们俩都交过不少学费，有的物超所值，有的纯属被割。最后得出一个共同感受：真正好的课程，哪怕贵到几万块，最珍贵的内容可能就几句话，但正是这几句话，可能就帮你捅破了卡了很久的那层窗户纸。

为什么讲师能说出这种“生死攸关”的话？因为他对知识的理解里，有大量细节的缝隙。

拿股票打个比方：教科书上的曲线是一条平滑的弧线，而真实走势是一条颤抖的、锯齿状的线，充满起伏。投资人在每一个起伏里经历过的害怕、兴奋、后悔和贪婪，最后都会沉淀为具体的操作习惯。项目也一样，底层的逻辑其实不复杂，学两天谁都能讲两句；真正拉开差距的，是实操里积累出来的、对细节缝隙的敏感度。

比如做私域，所有动作指向一个目的：让来访的人愿意买单。但“愿意”这个结果，是被无数小细节推起来的——主页上的一句介绍、对方加你之后收到的第一句话、置顶内容里的引导，以及客户最初从哪条路径找到你。

![](img/874edf169dd84e7160ed2f1f044b52fe.png)

换句话说，怎么把“陌生来访”到“愿意买单”这个比例拉高？

答案可能藏在很多不起眼的地方：签名里的一句话、打招呼的措辞、置顶内容的指引，或是跳转过来的路径设计。

![](img/e002d68eb00d8a3043e46386da7e0c7e.png)

再比如，有人用免费资料在种草平台上引流，拼的也是细节：那条自动回复的消息怎么发？拆成三行：第一行说自己是谁，第二行单独留下联系方式，第三行写清楚要领取什么。这样对方复制起来方便，系统也不容易把它丢进垃圾箱。这些细节，没亲手做过的人可能想破脑袋也想不到。

# 五、把自己从琐碎中解绑，才能腾出手干正事

经常有人问我：“你不去学校上课吗？”当然要去。偏偏社群里的大型活动总爱挤在周五和周一，正好撞上考试周。过去那些日子，我的状态基本是：上午在教室，下午在机场，拖着箱子赶去上课，晚上在酒店里争分夺秒地背材料。

第一，花钱买时间，把投产比不高的事全部外包。大一的时候我为了卖货，加满了各个宿舍楼的群，货虽然没卖成，却攒下一大批校内人脉，后来找代课特别方便。我一天的产值大约几千块，代课的日薪不到一百，用一百块换几千块的时间，这笔账算得过来。琐碎的事全部交给别人跑，我坐等结果就行。

# 六、命中的礼物，早已标好了价格

“盈亏同源”这四个字，我第一次听说是在一场线下分享里。那位前辈谈到，他因为懒得操作，把币拿在手里很久，结果赚到了一笔；也因为同样的懒，少做了几个关键动作，本该更早到手的收益又从指缝溜走。当时只觉得这话有点意思，并没有多想。

后来在一期播客里再听到，像是有什么东西重重砸在胸前——“所有命运赠送的礼物，早已在暗中标好了价格。”

![](img/31f53a69dbf6a528ceb2d74cdbd11a66.png)

说白了，赚钱和亏钱是同一个策略的一体两面，只不过在不同环境下呈现出不同脸色。你因为重仓一只股票吃到过大肉，未来也可能因为同样的重仓体验大回撤；你因为分散持仓躲过暴跌，也只会在某个时刻发现，分散恰恰让你错过了本该暴击的机会。高回报、低风险、高确定性，这几样东西本就不可能同时出现。

想从市场里拿走大部分利润，就得接受波动期里随之而来的恐惧、自责和后悔。没有完美策略，就像没有免费午餐。命运的礼物已经摆在那里了，你付得起价，才拿得走货。

《风吹半夏》里赵丽颖演的那个女人，就是一个例子。她做码头、做废钢、建钢厂，一路赚过大钱，也几乎没有一天能睡踏实。无数个节点，她都有机会停下来，但她没有，而是不断做着更大的事，去和世界的不确定性正面交手，在一轮轮的颠簸里把结果抓回来。

为什么？

![](img/c91c9fbd3ea3089ce3f7625a68869a48.png)

因为她心里清楚那个“礼物”是什么。清楚，所以承受得住。波动、恐惧、痛苦，都不是额外的代价，而是走向礼物的必经之路。

那期播客听完，我整晚没有睡着，反复想自己过去的恐惧和犹豫。原本的计划是寒假去深圳，回来继续按部就班上课，暑假再出去闯。可坐在教室里的一刹那，我忽然觉得等不下去了。我怕的从来不是成本——同学的目光、老师的问询、来回机票的开销，这些在那一刻全部变得没那么重要。

从冒出一个念头到搬进杭州的新房子，我只给了自己三天。每月往返机票要两千块，代课费八百块，外加新城市的房租，这是一笔持续的开销。但在我看来，这不是被逼的付出，而是选择了一种让我更能安放自己的活法：永远在路上，永远在学新的东西，永远与不确定为伴，然后在起伏中一次次确认自己的信念。

我愿意为这份礼物付钱。

今天刚好是我进入这个圈子两周年。系列文会继续写下去，三周年见。
