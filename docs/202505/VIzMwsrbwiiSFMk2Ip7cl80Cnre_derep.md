# AI文生图网站怎么做？这份实操笔记把每个步骤都讲透了

最近刷到一个很实在的分享：一位叫念明的同学，把一个AI文生图网站从0到1完整做了出来，并且把全过程记录了下来。网站已经上线，地址是picassoai.top。这篇文章相当于那份记录的转述版——更精炼，也更有条理。

![](img/87ac3de0efc94172f344a22ddf24aa53.png)

他给出的完整链路一共五步：定技术方案 → 设计落地页 → 对接API → 打磨界面 → 部署上线。听起来很顺，但每一步都有不少值得展开的细节。

第一步，先别急着写代码，要和AI把方案聊透。他对cursor说得很直接：我要做一个AI图片站，文字生成图片，先出MVP版本；不保存任何用户数据，用户关掉页面图片就清除。然后让AI输出一份可执行的readme.md文档。这还没完，多轮对话很关键——哪里觉得复杂就让AI换简单方案，直到自己能真正理解、能落地为止。这个阶段花的时间，后面都会加倍省回来。

等方案心里有数了，才开始做落地页。前提是开发环境、API密钥、项目初始化都准备就绪。他的做法是：把设计提示词喂给cursor，快速生成第一版index.html，在浏览器里直接预览。如果你是做AI图片站，记得在页面里增加一个“AI图片生成器”的功能区域。第一版不顺眼也别着急，核心功能跑通后再精修不迟。

然后是整条链路的重头戏：接入API。他的需求很明确——免费、文生图。直接问AI要推荐方案，最终选了阿里云百炼平台上的FLUX.1-schnell模型。

操作路径大概是这样的：进入阿里云官网点开“大模型”![](img/4c2f821a8708e57f32fc837c765c8382.png)，找到“免费体验”按提示完成勾选，就能进入体验页面![](img/f1603e143198bae28c79edf2bf004185.png)；在左侧导航栏找到“视觉模型”下的“图片生成”![](img/e1b09e2c02fceca7819c15c1f99c9b61.png)；先随便体验几个模型，心里有数后，再点顶部“API参考”![](img/db7be930a212554fc4c8abcfbbc8beb8.png)。准备工作一栏要认真读，尤其是“配置API KEY到环境变量”，选Windows系统跟着做就行，不需要安装SDK![](img/67951e9f122d33ae7eb3427637d59e84.png)。最后找到想用的模型，进入配置环节![](img/9e9b1b1ba9bebaf32eabb34b539fc48b.png)。

配置这件事，他分享了三种省心办法：一是把当前页面截图发给cursor，让它一步步指导操作，做完一步截一屏，它就会下一步；二是直接把网址发给cursor，让它自动配置（可能要用MCP，不行就换第三种）；三是全选复制模型页面的全部内容给cursor，让它自己搞定，出错了就让它自己解决。至于第四种技术流操作，大多数人用不上，也就不展开了。

![](img/746269ee67c0ca60acd10679deb73ace.png)

这里有个特别重要的提醒：按照他的技术栈，前端服务器和API服务器必须同时运行，否则页面能打开、图却生不出来。

功能跑通之后，才轮到UI精修。他的方法论非常简单：模仿+创新。

模仿的素材从哪来？三个参考站：Raphael.app（小排老师的网站）、ghiblio.art、youphoto.ai。先把这些网站的截图发给AI，让它分析优点、哪些可以借鉴，再结合自己网站的特点做整合。比如他觉得小排老师网站的header和hero区域做得很好，就直接截图给AI，要求参考功能布局，但样式上要有自己的独特风格、不能照抄。

![](img/348219191af5623e995dddb674060061.png)

![](img/0b08148dbc7b261aa582e14010b789cd.png)

Logo这类细节也有巧办法：可以用免费的Logo制作网站，也可以“AI+AI”解决——从小排老师的网站里挑一张满意的图，让cursor写个脚本裁成30×30和60×60两张圆形图片，分别放在header和hero区域。

![](img/d18aa5c62682cc21e6754fd0acedd70b.png)

至于创新，这是长期做站锻炼出来的能力。也可以让AI在模仿的基础上多做一步变化，慢慢培养自己的设计手感。

部署上线相对简单，按自己的技术栈文档操作即可。他选的是Cloudflare Pages。

最后聊聊容易被忽视的事：前端制作技巧。作者提到两条路——一是Figma，但他自己还没深入研究，所以重点说第二条：系统化补足UI设计认知。他花了3小时用cursor做了一个“UI指导书”网站，部署在Vercel上，地址是iu-topaz.vercel.app/index.html。

这个网站把UI设计知识梳理得很清晰：从HTML、CSS与UI的关系等基础理论，到基础、表单、数据展示、导航、反馈五大组件体系；从按桌面端、移动端、小程序、跨平台分类的主流组件库，到尺寸、间距、状态、主题等通用属性；再到主题色、功能色、中性色、渐变色等完整色彩分类。

它的特点是结构化呈现、可视化学习、代码示例丰富、支持响应式访问，而且持续更新迭代。对UI/UX设计师、前端开发者和产品经理来说，都是不错的参考资源。

整套流程看下来，最大的感受就是：先想清楚再动手，善用AI但不盲从，设计能力靠系统学习和持续实践。希望这份记录对你有所启发。
