# (118 赞)赚钱的\u202c本质是创造并释放价值，坚持利他，成己达人，帮助别人成\u202c就自己。

你有没有发现，越是想赚钱的人，反而越容易赚不到钱？其实财富的底层逻辑并没有那么玄：你能为别人创造多大价值，并且愿意把这些价值真正释放出去，钱自然会来找你。本质上，赚钱就是一次价值流动，而你最该做的事情，就是把“利他”两个字刻在行动里——先帮别人解决问题，在成全别人的同时，自己的路也会越走越宽。

那为什么有些人走着走着，渐渐赚不到钱了？说到底，是心里的自私盖过了利他。该分给伙伴的利益，悄悄攥进了自己口袋；该拉人一把的时候，选择了冷眼旁观；该给出帮助的时候，却开始斤斤计较。一次两次，大家可能看不出什么；时间久了，身边愿意跟你合作的人就会越来越少，资源、信任、机会，通通都会慢慢远离你。

这个世界的运行法则是圆的：你释放出去的每一个念头、每一份善意或算计，最终都会绕个圈回到自己身上。心里只装着自己的人，注定会被世界孤立；而愿意先照亮别人的人，前路一定不会黑暗。

所以，赚钱的真相很简单：想赚钱，先让自己值钱；想成功，先帮别人成功。这才是最高级的“利己”。
