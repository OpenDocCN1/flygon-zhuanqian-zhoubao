# 读书这件事，最后拼的是“信得过、愿得下、做得成”
作者：龙哥

读一本书，能不能真正用上，差别往往不在书厚不厚、作者名不名，而是你拿它是什么态度。

我前段时间收到一条私信，读者看完我的《营销笔记》后说：这书太通俗了，圈内人估计瞧不上，看的人多半是刚入行的新人。这个评价我不好反驳，但它让我想起一个更根本的问题：营销这行的底层方法论大家都差不多，该看的书也都看过，为什么做出来的东西还是良莠不齐？

答案其实藏在读书的方式里。

李叫兽是一个很特别的存在，他很多能力就是纯靠读书读出来的。我不一样，我更多是先在实战里撞出感觉，再回头读书来印证、梳理。所以“读了就能会”这件事，稀缺极了。

上次和李叫兽直播聊天，他总结读书要守住三条线：信、愿、行。

信，就是先让自己信。信不信，决定你读这本书的姿势。你如果一边翻一边挑刺、只图个热闹，那这本书对你而言就只是消遣。读之前就得想清楚，我为什么要信它、我要从它这里得到什么。

我服务过的一个早期客户老板刘丹尼，他对这点就很极致。他说自己读过的书，会对书里的每个方法都去做一次小实验，跑通了才敢用上。这就是一种主动的信任，不是盲从，是愿意先让理论通过实践来验证。

愿，是相信之后愿意去做。很多人相信长期主义、相信利他、相信认知升级，朋友圈里宣言满满，可真到需要付出的那一刻，就犹豫了。愿不愿意，隔着一层现实的疼。

行，才是真正的分水岭。混沌大学创业营里有个同学分享过一个细节：创业圈里人人喊人才第一、以人为本，于是他现场问台下上百个老板，你们公司工资哪天发。有近一半的人回答是次月15号之后。说一套做一套，最真实的裂缝就露在钱和时间上。

我这些年写文章、出书，传播的数据看着不错，但真正“信了、做了”的人，屈指可数。读了我，被骂惨过、豆瓣评分也一般的《那些让文案绝望的文案》，也确实有人照着用，最后在文案这条路上打出了成绩。他们后来回来感谢我，我知道，他们并不是因为我厉害，而是因为他们真的信了、愿意试、最后做下去了。

有多少人读了《营销笔记》然后真的在自己的店里落地了？非常少，不到百分之一。公司里有个同事叫怪兽，就收到了一个读者的反馈，说他不是把收获停留在笔记里，而是直接在门店里执行了。这才叫真正读进去。

最近和马文亚聊播客时他提到巴菲特，厉害的不是认知有多高，而是他能一辈子死磕自己的那套底层逻辑。很多人嘴上天天喊长期主义，一见能快钱的机会就冲上去了。那就别叫长期主义了，叫机会主义更诚实。这才是知行合一。

读书这件事，终究是信得过、愿得下、做得成三步走。缺一步，书再好也只是书架上的摆设。
