# (58 赞)AI 写作法，它是如何帮助我从一个三流作者到成功登上到虎嗅👸号头条

好久不见，各位老铁！过去这大半年我整个人基本泡在项目里，连静下心来好好写篇文章的工夫都挤不出来。但恰恰是这段高强度的实战期，让我把不少细分赛道从0到1跑通了闭环，现在正挨个放大复制。

今天掏心窝子跟你们聊一个我反复验证了一整年的心得——判断一个项目是不是真的值得做，有个特别朴素的标尺：如果连你身边那个“看着不太灵光”的人，都能在这条路上轻松搞到钱，那这项目基本稳了。

说白了，就是门槛低到尘埃里。而我今天要拆解的AI写作方向，就是这种典型代表。

这活儿压根不要求你文笔多好，也不逼你搞懂那些绕来绕去的增长套路，只要照着流程一步步走，就能接到单子、把钱落袋。夸张点讲，属于“闭着眼睛都能跑”的生意。当然，有个小波动得提一嘴：降重和降AIGC的需求有季节性，基本每年3到6月是最旺的时候，想入场的可以踩这个节奏。

虽然这项目利润不错，但在龙哥盟这儿，我还是决定——直接全盘托出，链接放下面了，自取。
