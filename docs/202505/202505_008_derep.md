# 十一天到手一万+，我靠AI+公众号+像素级抄号做到了

原文链接：[`www.yuque.com/for_lazy/zhoubao/ka0d5grxgmmeweq8`](https://www.yuque.com/for_lazy/zhoubao/ka0d5grxgmmeweq8)

作者：舒未读
发布日期：2025-05-20

很高兴能成为赚钱的一员，我是舒未读，目前在深圳一家私企里做底层程序员。

最近是不是常刷到那种公众号，一条内容赛道能一直爆，单篇10万+不是梦，而且这种热度能稳稳续上几个月甚至更久？

这类号，其实是可以被系统化复制的。手上备足账号跑测试，基本一个多月就能摸到能稳定变现的模型。

关键就在于提示词可以逆向推导。操作并不复杂，挑一个对标号里表现最好的3到5篇内容喂给AI，让它反推出生成逻辑，再做一点微调优化，就能复刻出相似的爆款节奏。

更关键的是，输出的文本还能做到绕开检测。我用【朱雀大模型检测】测过，AI痕迹基本被抹掉。图里那两个号，就是靠这套打法11天就冲破1万收益。
