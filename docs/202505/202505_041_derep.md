# (71 赞)裸辞老师首航📕电商：第二周就成交，两个月收回成本的实战复盘



## 裸辞教师转战赚钱：📕电商航海初体验，两月回本的踩坑与心得

作者：薇薇老师

日期：2025-05-22

嗨，我是薇薇。刚从教师岗位上裸辞出来，2025年2月底正式入圈赚钱。

十年前我进入民办中学，先后做了十年教育行业，其中八年担任中层管理。期间我操盘过全国性教育协会的年会全案，还总导演过万人规模的音乐晚会，累计策划执行的线下大型活动超过一百场。

离开稳定的体制后，我想彻底换一种玩法。想借赚钱这个平台打破原有的社交边界，认识不同赛道的人，把自己从教育圈搬到互联网赛道。多年高压、超负荷的工作节奏，让我养成了还算扎实的执行力。

没想到进度比预期更快。加入航海项目后，第二周就迎来了第一单。一个月后流量开始集中爆发，最高峰时单日成交突破两百单，当时太兴奋没来得及存证。现在累计GMV已经到五万左右，两个月的时间已经把参与航海的门票费用赚了回来。

作为刚入场的新人能这么快拿到正向反馈，真的很提气。它再次坚定我的认知：只要方法对、执行到位，赚钱的路径是可复制的，别人能成我也能成。

这次的复盘分享是应赚钱澄歌的邀请完成的。虽然目前在📕电商里我依旧算个入门玩家，爆单里运气的成分也不小，但过程中积累的心态调整、操作细节以及踩过的坑，都很值得跟后来者聊一聊。
