# (精华帖)(21 赞)没上过一天班，在 AI 热潮中把 AI 代写做到 top

零工龄、八年创业、把AI代写做到行业头部，他的经验全在这了

大家好，我是龙哥。一个1996年出生、从未上过一天班的连续创业者。到今年，我已经在创业路上走了整整八年。2023年开始接触AI代写，两年下来，从完全陌生到摸透这个领域的0到1，再到有底气去挑战“从1到10”的放大问题，过程里踩过的坑和验证过的路，都还算清晰。

上周受龙哥盟邀请，去海口做了一场线下分享。今天把分享的核心内容重新梳理一遍，希望能给同路人一点参考。

先说转型的契机。2023年1月，我第一次接触到AI代写。在这之前，我做过ChatGPT账号售卖，但那个模式没走通。后来仔细琢磨，发现AI的文字生成能力，和代写服务本身，完全可以拼成一个商业闭环——客户付钱，买到的是由AI生产、再经过人工把关的文档。想明白这一点后，我就果断转了方向。

再说这个项目怎么跑。运营模式其实不复杂：核心就是“AI产出内容+代写服务交付”。对新手来说，有两条路可选。一条是当纯写手，只在后台接单、用AI帮客户完成文档，全程不用直接面对客户，一单收入大概在10到20元之间，门槛低、赚得也直接。另一条是当商家，自己开店、自己对接客户，收益空间更大，但精力消耗也是成倍地往上走。

流量这块，各人有各人的打法。免费流量可以从闲鱼、📕这些平台去抠，好处是不花钱，坏处是结果没法保证，今天有单、明天可能颗粒无收。付费流量则要舍得投钱，但真正的难点在成交价怎么定、ROI怎么才能平衡。不同的电商平台，机制和投放逻辑也各有优劣，需要自己去试错、去琢磨。

除了代写本身，我还做了知识付费。这个方向不是单纯教人怎么写，而是帮学员把能力提上来，把整个商业闭环打通——包括流量怎么搞、报价怎么定、单子怎么接，这些都是实打实的问题。目前学员的平均复购率在20%左右，说明这个后端模式是能跑起来的。

自营业务和知识付费，并不是两件独立的事，而是互相成就的。自营盘稳定，付费产品的后端才稳定；反过来，付费学员有了单子，我们也能统筹手里的订单分发给他们去做，两边都是活水。

最后聊聊孵化超级个人这件事。最大的难点并不在从0到1，而是在从1到10的放大过程。流量怎么放大、付费流量的数据怎么统计、后端团队怎么搭建，每一项都能卡住人，必须有一套完整的系统去支撑。
