# 10天拉新1700+、个人号新增700+，我把这套发售SOP拆给你

很多做内容的朋友都在问：怎么才能让用户愿意主动帮忙传播？这一年，我反复用“产品发售”来做增长，个人号从1000人涨到13000多人，累计变现几十万。最近一场活动10天进群1700+，个人号新增700多。每天都有朋友来问方法，所以我把自己的打法整理成一套标准模板，方便大家直接套用。

整套活动分为三段：前期梳理、中期蓄势、后期转化。下面用最常见的“7天手机摄影体验营”来拆解，其他产品换汤不换药，底层逻辑完全一样。

### 2. 推广大使群怎么布置
拉新不能只靠主理人一个人，关键是让愿意帮忙的人清楚“做什么”和“拿什么”。大使群的置顶消息里，要把这两件事写明白。

你要做的事情：活动期间每天在个人号状态发布活动海报、训练营群二维码和个人专属邀请码，并配合群里的统一节奏；如果用户对产品感兴趣，可以直接推荐给主理人，成交后溯源分佣。

你能拿到的回报：动态奖励、邀新奖励、成交奖励三部分。
- 动态奖励：只要发了状态并截图到群里，每条发1.88元红包，每天发3轮；
- 邀新奖励：邀请5-10人送新手课，邀请50人、100人、200人分别对应不同金额红包、课程和社群席位；
- 成交奖励：推荐3单99元红包，5单199元，10单399元加课程名额，20单699元加更多名额和一次万人名片推荐。

注意：阶梯奖励不叠加，冲到更高档位会补差价。产品资料、海报、分销流程、状态文案都放进在线文档，有疑问直接在群里@运营团队。

### 3. 体验营群规则
体验营的核心是收新粉、沉淀到个人微信号，所以一切规则都要围绕“加微信领福利”来设计。

进群先加主理人微信，才能领取邀请礼包；开课前全员禁言，但可以邀请朋友一起学习；7天课表每天一个主题：
- 第1天：5个拍摄技巧，轻松拍出氛围感
- 第2天：百万播放照片的拍摄秘诀
- 第3天：手残党也能上手的人像精修
- 第4天：5步让风景照变得通透
- 第5天：拍照如何帮你打开社交圈
- 第6天：用DeepSeek生成本月度最实用的高情商话术
- 第7天：手机拍摄的5个出圈技巧

群内保持得体互动，不互加、不刷屏，违者清退。

## 三、后期转化：把氛围顶上去

### 1. 社群氛围三件套
- 进群引导：先放资料福利，引导大家添加主理人微信，把流量沉淀下来。

![](img/00459e026a6a1a42fe2cfae2d71d7249.png)

- 课程预告：提前公布嘉宾、主题和时间，制造期待，拉高到场率。

![](img/4b3aab77d17b9ed9ca73eeae91267270.png)

- 产品讲解：嘉宾分享结束后，自然切入产品介绍，完成转化动作。

### 2. 社群促成交
晒单：把已购学员的截图发到群里，让观望的人看到真实购买行为，刺激从众心理。

## 四、几点提醒

1. 信任永远排第一位。别用轰炸式营销，真实故事和过硬专业能力最能打动人。
2. 紧迫感要设计到位：倒计时、名额限制、专属权益，样样都不能少。
3. 要有全链路意识。从引流、运营到成交，让后一环自然衔接前一环。
4. 付费找大使分发是增量打法。如果自己的流量池还不够大，不建议直接找专业团队做发售。发售本质是激活存量，不能凭空创造增量；想要增量，就要借助小大使的力量，付费或资源置换都可以。
5. 每次做完活动都要沉淀复盘。既能优化自己的流程，也能把经验变成内容，帮助更多人。
6. 用社群做发售涨粉很快、变现效率高、信任价值高，建议一年做3-5次，流量池增长会非常明显。
