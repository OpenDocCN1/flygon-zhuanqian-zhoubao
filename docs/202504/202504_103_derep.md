# (27 赞)深度体验 GPT-4o：发现两个普通人的赚钱指南（附实操模板）
作者：龙哥

最近AI绘画圈又炸了锅——OpenAI在3月26日给GPT-4o来了次大更新，付费用户现在直接能在ChatGPT里生成和编辑图片，彻底把DALL-E晾在了一边。结果你猜怎么着？才一天工夫，网络热图和梗图就被各路玩家用4o重新画了个遍。

我也忍不住上手试了试，三分钟就搞定一套吉卜力风格的插画头像，看着屏幕上的成品，后背一凉：这技术迭代的速度，简直让人跟不上。更吓人的是，普通人已经靠它捞到真金白银了。

有人把AI做好的吉卜力头像挂上闲鱼，一天进账几百块；有人趁热在📕发了几篇笔记，两天就涨了三千多粉丝；还有人把吉卜力画风带进PPT，做成模板出售，一个就卖了两千多。

说白了，这就是两个普通人的野路子：

第一招，闲鱼卖“宫崎骏风格头像”，用GPT-4o批量产出，成本几乎为零，赚的就是信息差和手速。

第二招，📕发吉卜力风PPT模板，先靠热门画风吸粉，再靠模板变现或接定制单。
