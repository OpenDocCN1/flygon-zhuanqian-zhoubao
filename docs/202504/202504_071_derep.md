# (84 赞)对接下来的路有点迷茫

前两天在龙哥盟看到一个提问，很有共鸣。提问的人说自己做了五六年数据分析，去年下半年从上一家离开，年底回老家歇了一个多月。过完年再出来找机会，面试了不少，可聊完基本都没了下文。好在跟着龙哥盟做了个油管项目，做出了一点小成绩，凭着这个竟然顺利进了一家做内容出海的公司。

但入职没几天，他就发现公司这个油管业务根本没有一条能稳定赚钱的路子，团队每个月光人力开销就盖过了收入，内部已经传出要动刀裁人的风声。目前他所待的项目组还算稳当，至少两三个月内不会有事。于是纠结来了：这段期间，下班后的精力到底该重点放在运营自己的油管号上，还是继续打磨数据分析这块，以防被裁之后能立刻开启新工作？

龙哥的回答很利落：肯定是做油管。

理由也很清楚：正好这两三个月工作上没多少事，是难得的窗口期。而且AI时代下，单纯的数据分析技能已经越来越不吃香了，更核心的是对商业、用户和业务的洞察力。做油管，就要奔着做出能赚钱的视频去。为了这个目标，你得琢磨选题怎么抓人、用户到底想看什么、平台规则怎么玩、视频怎么剪、内容怎么表达，还要能从数据里找到问题并及时复盘调整。这些东西练出来，不光能让你自己的账号起量，回来也会反哺你的本职工作，让你在职场上更有底气。

一边是正在贬值的旧技能，一边是越做越值钱的商业实战，答案其实已经写在你心里了。
