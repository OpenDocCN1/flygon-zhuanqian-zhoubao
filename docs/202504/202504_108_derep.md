# 视频转手绘，豆包就能上手的小众玩法拆解

最近在风向标里注意到一个正在起量的赛道：视频转手绘。抱着验证的心态我去扒了几家对标号的作品流，实操下来发现门槛并不高，用豆包就能跑通完整流程。为了让更多小白少走弯路，我把整个过程整理成了一套上手视频，讲得比较细、比较笨，但基本跟着做就能复现。

评论区反馈是这个教程最有温度的部分。

旭宏在评论里说这期内容属于直接上手的喂饭教学。更让人意外的是，教程里收尾提到的去重思路，其实最早是他写在亦仁分享的风向标项目评论区的那7条方法，当时被亦仁置顶过。现在这套思路被放进实操视频里讲解，他说有种被看见的共鸣感。

他也提到，视频里对那几条去重对策做了逐条拆解，节奏稳、细节足，新手看完基本能直接开干，友好度很高。

关于评论区讨论比较多的两个点，旭宏做了进一步补充：

**一、评论率和正能量怎么兼顾**

视频号的创作者分成，本质上不是冲播放量，而是冲评论量。只有用户真正进评论区互动，才有广告分成机会，光有点赞、收藏、转发是拿不到收益的。

从数据角度看，越是容易引发情绪对立的内容，评论越容易炸。比如翻红司马南的正面形象、去年发酵宗庆后的负面料、现在聊李嘉诚的正面评价或者汪小菲的负面话题，都能带来高互动。但账号要想活得久，还是建议顺着平台调性来，别硬刚。流量起来后被盯上，封号风险会直接跟上。

**二、去重的另类打法**

旭宏提出了一个还没大规模验证的小思路：同主题多素材合并。不是单条转绘，而是把同一情感母题的几个短视频剪成一条，比如都讲“孩子心疼妈妈”，把产房里男孩心疼妈妈的片段和其它小孩心疼妈妈的片段拼接，再逐段做转绘处理。这样重复度会被稀释，去重几率会提升。

作者才也认可这个方向，认为感人向内容拿2-3条同类素材拼一起，每条都做转绘处理，去重力度会更强。

旭宏最后补充，他之前看到过一个“父母过度指责孩子”的爆款，也是把七八条同题材素材合并在一起实现的，只是当时没有做转绘。现在结合手绘转制，效果可能更好，值得有兴趣的朋友去试试。
