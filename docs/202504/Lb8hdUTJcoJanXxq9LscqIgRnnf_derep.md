## 一、寻找单页小游戏并上线

以下编号对应航海手册中的步骤，方便大家对照查看。

### 3.3.2

![](img/c1954472ecdcd185d9af4ecd4c5e7339.png)

这一部分刚开始看可能有点不太明白，下面按照我的实际操作方式解释一下。

#### 1. 域名填写什么？

这里填写的是你在后续步骤中购买的域名。

比如我的域名是：

`zoo-3dcube.online`

#### 2. 游戏名称怎么写？

这里可以理解成网站或小游戏的名称，主要用于说明你的网站是做什么的。

我当时直接参考网址来填写，写成了：

`zoo-3dcube`

大家也可以根据自己的游戏内容起一个简单、容易理解的名字。

#### 3. 游戏链接从哪里获取？

这里需要找到一个支持 iframe 嵌入的开源小游戏。打开游戏后，把它的网页地址复制下来，再填入对应位置。

具体步骤如下：

注册并登录 GitHub 后，进入页面顶部的搜索框进行搜索即可。不同账号看到的页面可能略有区别，但操作方式基本一样。

![](img/a294070e3353c75221869e16d237a1a2.png)

![](img/6f68955866e07315555258c39913c841.png)

我当时使用的关键词是：

`iframe game`

![](img/369bc8d19e640127875fa14e8937093f.png)

在搜索结果中，可以找到一些能够正常打开的小游戏项目。我当时随便选择了一个，进入游戏页面后复制浏览器地址栏中的网址，再粘贴到上面说明中的“3”所在位置即可。

![](img/d1a4da8e0c09a522069470a652cb0c0e.png)

### 3.3.3.1 注册域名

![](img/acbafd24b064be4d32e4bee6a406d3a9.png)

这里搜索的是域名前面的主体部分，也就是未来用户搜索网站时会看到的主要名称，不包括最后的后缀。

例如我的域名主体是：

`zoo-3dcube`

![](img/2d80a4f4f6a9a8c2ca57af150e7c02c5.png)

有时候登录后会自动进入其他页面，这种情况不用担心，直接点击页面中的 `Domains` 即可。

![](img/c8f614aa5bd94a995a3fd454893f90c4.png)

![](img/679347b6dae9852ea01e4b68e954592b.png)

进入 Domains 页面后，在搜索框中输入你想要的域名主体，然后挑选一个喜欢的后缀并完成购买。

![](img/3d4f1916c7e187012ecbf4fa9f38c6c1.png)

操作时需要先点击右侧的 `Add to cart`，将域名加入购物车，之后才能继续结算。

![](img/c2b43edde6c2d864a5b9d59245dff5c9.png)

付款时我选择了支付宝。平台可能会要求填写地址等信息，按照要求填写即可，地址信息可以填写常用地址。

![](img/397b1469ffddb827b19022b823a3e051.png)

![](img/4f26e07290fa41374fcc62967a3e2481.png)

我当时付款遇到过几次失败，原因包括实名认证未通过、支付没有成功等。遇到这种情况不用太紧张，可以重新尝试几次，通常就能完成。

### 3.3.3.2

![](img/73762f057722bd47b6ec269c7270f2a5.png)

这里填写的名称，直接使用域名后缀前面的主体部分就可以。

比如我填写的是：

`zoo-3dcube`

下方还会让你选择仓库类型：

- `Public`：公开仓库，其他人可以看到仓库内容；
- `Private`：私有仓库，不希望别人查看代码时可以选择。

不过需要注意，私有仓库可能存在数量或使用方面的限制，大家根据自己的需求选择即可。

### 3.3.3.3 在 Cloudflare 中绑定域名

![](img/64331505a0aca4a43eb25822c9a646ff.png)

这一步很多人第一次操作时容易困惑。图中显示的两个域名，后面需要复制到 Spaceship 中使用。

当你在 Cloudflare 操作到这一步时，页面上会出现属于你自己的两个名称服务器地址。先将它们复制下来，再打开 Spaceship。

在 Spaceship 中找到你刚刚购买的域名。如果域名数量不多，可以直接在列表中找到，不需要再次搜索。然后点击右侧的 `Columns`。

![](img/89540e963a52a77623db6d60db9548bf.png)

接着点击右侧的 `Nameservers`。

![](img/d871c9b4b9fe6360e610c49c296accfa.png)

进入之后，点击 `Change`。

![](img/6ac17757c7ff112a465b8f8dde92c54c.png)

把刚才从 Cloudflare 复制的两个名称服务器地址粘贴到对应位置。

![](img/a3e02e3686e100e99cb77581c7e685f7.png)

完成后，继续按照航海手册后面的步骤操作即可。

## 二、查看网站数据并进行调整

### 3.5.3.3

![](img/99420985784f53ffda025d7db48ab813.png)

这一步生成代码时可能不会立刻显示，需要耐心等待一会儿。

我第一次操作时，点击右上角的“下一步”后，页面很长时间没有出现结果，还以为操作失败了。后来发现其实只是加载需要时间，大概等待接近一分钟就会显示。

如果等待时间过长仍然没有反应，可以刷新页面，再重新按照步骤操作一次。

接下来，把生成的代码交给 Claude，让它帮你整合到原来的网页代码中。

如果之前已经和 Claude 有过对话，可以直接打开原来的历史记录，在同一个对话框里继续输入，这样它能更好地理解此前的代码和需求。

历史记录示例：

![](img/e42de75d53be97bfa76823e9b0285055.png)

我当时大概是这样向 Claude 说明的：

![](img/1e9d9cec81ae309b73f951e518cfdc70.png)

Claude 生成完整代码之后，将全部代码复制下来，然后进入你保存项目代码的平台。我使用的是 GitHub。

登录 GitHub 后，在左侧找到对应的项目。

![](img/ad447fb1fb9d67080edf2736076e5224.png)

进入项目后，找到并打开 `index` 文件。

![](img/3eb7505aeb2ac39118b0eda9296be65c.png)

点击右侧的编辑按钮，将原来的代码全部删除，再粘贴 Claude 返回的完整新代码。

![](img/6d1c988d60bdbb5a20763ff029b17d02.png)

完成替换后保存修改，并点击右侧的 `Commit changes` 提交。

![](img/4b37915b038f9ef82a7ea5aaa22634a9.png)

提交成功后，就可以回到 GSA 进行测试了。

![](img/779069137b2fd118d70f81f8354de2fa.png)
