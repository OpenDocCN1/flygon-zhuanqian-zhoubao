# 从职场宝妈到年入25W+：自由职业不是逃离，而是把自己练成一支队伍
作者：龙哥

大家好，我是龙哥。

3月22日，我受邀参加了海南赚钱线下见面会，并作为分享嘉宾站上了舞台。

就在一年前，同样是3月，我还带着期待和忐忑，第一次参加杭州的赚钱全国线下见面会。那次经历让我获得了很多力量，也第一次认真想象：如果有一天，我也能站上台分享自己的故事，会是什么样？

当时我是和慢慢一起去的。她对我说：

“等到明年的今天，我们也要站到台上。”

我听完只是笑了笑，心里其实充满怀疑：

我真的可以吗？  
我真的能做到吗？

没想到，一年之后，我真的站到了这里，开始讲述自己成为自由职业者这一年多的经历。

那一刻，我非常开心。因为曾经随口向宇宙许下的愿望，竟然真的在一点点变成现实。

回头看，成为自由职业者并不是突然发生的决定。早在五年前，我就已经在心里埋下了这颗种子，只是那时候的我并不知道，自己有一天真的会走到今天。

这次分享，我主要想聊四个部分：

**一、起点：我是什么时候开始向往自由职业的？**  
**二、试错：第一次裸辞后，我为什么两个月就重新回到了职场？**  
**三、转型：第二次出发时，我做对了哪些关键动作？**  
**四、复盘：自由职业第一年，真实体验究竟是什么？**

很多人以为，自由职业意味着时间自由、收入自由，不再被工作束缚。

但真正走上这条路后，你会发现，它更像是一次重新组装自己的过程：你既要寻找客户、交付工作，也要管理时间、维护收入、承担风险，还要在迷茫时继续做决定。

所谓“一个人活成一支队伍”，并不是说这条路轻松，而是你必须逐渐拥有独立解决问题的能力。

如果你也身处职场，曾经想过离开稳定的工作，尝试一种新的生活方式，希望我的经历能给你一些参考和力量。
