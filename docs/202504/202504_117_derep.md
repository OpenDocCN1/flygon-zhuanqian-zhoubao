# (13 赞)分享一个 gpt 推荐的标签管理工具 raindrop.io

最近挖到一个宝藏工具，是 GPT 顺手推荐给我的——**Raindrop.io**。折腾下来发现真的好用，赶紧来分享一波。

事情是这样的：昨天翻完 AI+web 站航海手册，里面记录了一堆我从来没见过的网站，看得我眼花缭乱。但问题来了——我的浏览器书签乱成一锅粥，根本没法好好归类收纳，越存越乱，想想就头疼。

于是我去问了 GPT，有没有什么好用的插件或工具能拯救一下。它给我推荐了这个叫 Raindrop.io 的标签管理工具。今天用下来，确实香。

它的核心能力是：无论在电脑、手机还是平板上，都能随时打开并查看你收藏的网页；而且支持跨设备同步，比如在公司电脑存的书签，回到家打开手机就能直接看到，电脑和手机之间切换毫无压力。对喜欢到处收集资源、又经常在不同设备间切换的朋友来说，简直不要太方便。

我已经用它把自己的网页收藏夹重新整理了一遍，还顺手写了篇 800 字的小指南，希望能帮到同样有整理困扰的你～
