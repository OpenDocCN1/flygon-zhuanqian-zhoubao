# 先做自己真正在用的东西——关于 AI 编程的几句心里话，以及我的卡片生成器上线了

我是龙哥。

四月 DeepSeek 航海的航海教练，过去十年一直做集团企业的后台产品和系统集成。

本想只发一条卡片生成器上线的通知，结果写着写着就写成了这篇复盘。把这个小工具从零到 MVP 的完整经历梳理了一遍，希望对之前参加过 Cursor 航海、以及这次 iOS APP 航海的小伙伴有点参考价值。

最近用 AI 编程的同学特别多，Cursor 也好，Windsurf 也好，bolt.new、Trae 什么的也好，几乎人手一个自己造出来的玩意儿：恋爱预测网站、二维码生成器、爆款笔记抓取工具、视频下载器……花样很多。

但说实话，很多作品做出来就躺在角落里了，几乎没人用，也说不清到底解决什么问题。学会了打代码的快感有了，生活却没变，口袋也没鼓。
