# (8 赞)关于听了易仁永澄老师心力课程的一些思考以及对 3 月📕航海的复盘
作者：龙哥

一篇只有8个赞的复盘帖，却意外值得细读。圈友“呼呼”在4月16日发了这条内容，把自己参加线下活动的心得和线上航海项目的失败经验，揉成了一篇长文分享。

她先是回顾了4月12日在山东举办的那场线下见面会。能到场听易仁永澄老师讲心力课程，本身就很幸运，现场还有不少📕赛道的大咖做分享，一圈听下来，行业知识和商业认知都提升了不少，也借机结识了一批做📕的朋友。对她来说，这是信息量和人脉双丰收的一天。

然而，线上的项目就没这么顺了。三月份她报名了📕的“高客单价”航海项目，这也是她头一回以线上形式参与这类项目。可结果并不美好，她直接“栽”在了这一程，0到1的闭环始终没打通。好在项目结束后，她没有把这次失败随手扔掉，而是借助永澄老师的心力方法论和各种工具，重新把整个过程捋了一遍，做了一次相当认真的复盘。


评论区还有个小插曲：起初有人反映链接打不开，她重新发了一遍，说这次应该没问题了；但有圈友依然表示没法访问。如果大家遇到类似情况，可以稍后多刷新几次，或者看她后续有没有补新的链接。

整篇帖子最打动人的地方，是不回避失败，还愿意把失败后的复盘思路完整展开。对于同样在探索线上项目、还没跑通0-1的人来说，这种来自一线的真实记录，比任何漂亮的成功学都有参考价值。
