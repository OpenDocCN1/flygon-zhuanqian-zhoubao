# 笔记站图文批量抓取：电子表格也能连图带文一起收

> 原文：飞书文档

作者哆元经常被问到：怎么把笔记站里的图文成批扒下来？市面上的解法并不少，有自动化流、有扩展、也有整套工具，但要么上手难，要么价格劝退。

上一轮大模型实战营结束后，不少朋友开始研究在线表格的扩展能力。我之前推荐过一款抓取扩展，唯独配图这块拿不到。这篇文章只解决一件事：把笔记的完整照片也一并拿下。

先建一张空白工作表，模板稍后放出来。

![](img/0dfac0112e1bc2a99a6945f74d7f55d5.png)

第二列去快捷字段库里挑“笔记助手”。

![](img/ebd16aa8ac0906ffb1906cbecb1ce679.png)

确认后，配置面板随即出现。先解决接口问题：这个助手是付费的，但很便宜，10元可调用1000次；免费方案我放到后面讲。

![](img/812b3426f850623d12c89cf0e84c8815.png)

配置方式：先点绑定账户，其他接口同理。旁边的小图标进入后，可填写站点地址和执行步骤。

![](img/c07c97f9953e2593be009b61ffb75740.png)

页面会要求输入邮箱地址，下方就是购买入口。付款后，接口令牌就能复制了。

![](img/d4a54fea9ab24c360a12ba47eca1f8a5.png)

把令牌填进对应输入框并确认，下方会出现你的账户。注意：以后每开一张新表，若还要用这个接口，都得手动重新绑定一次。

![](img/0a2d000eeabbfa526397d0d17e4e6ecb.png)

保存配置后，回到工作表，指定放笔记网址的那一列即可。

![](img/cb463178fc58ec41f7bebfb014e140f6.png)

身份凭据字段我留空了，想填也可以，照截图操作就成。

![](img/3e9f130bc501b5767145c249718dbcf9.png)

身份凭据到底负责什么？我拿豆包打了个比方：它像是网站发给你的一把临时钥匙。

![](img/a63a228a597a90076ec913cf7d71daec.png)

再来看抓取参数。核心只有两个字段——“全部配图”和“封面配图”：前者收录笔记内所有照片，后者只取封面一张。

![](img/b2fceadb302f29c22079af0d1a63e54b.png)

注意上限：一次最多返回5条照片地址；多于5张，系统会报错。但封面不受影响，依然能取到。破解办法下面说。

![](img/28685321422eae7077143dfe03ce6941.png)

打开自动同步开关，之后每多贴一条笔记网址，系统都会自动触发抓取。

![](img/e41c3f03bb74572947173a9e7cae8b7b.png)

拿一篇不超过5张图的笔记做测试，比如这篇。

![](img/6adc4c4f4a883f6ad5da0935d87b34c6.png)

按下转发按钮复制网址，不用清理中文，贴进表格，抓取马上开始。

![](img/f50d53ba5b072b0adc4803110eab4fee.png)

几秒钟就有结果。

![](img/a5e96db8b3ba0d2ae5157e8dbfb029af.png)

表里显示的仍是地址，而不是缩略图。其实这就是照片存取的URL，前端源代码里也能找到同一条。

![](img/6c8f594a90a9758d168ca686891a4c61.png)

双击地址，复制后在浏览器新标签页打开，原图便显示出来。

![](img/04fa9a23aaf341d88a718789cd0e7d28.png)

每次都这么操作太麻烦。在“全部配图”右边加一列，专门用来把地址转成可预览的文件。

![](img/845b66f9317145e0af18aa6cdb4e3dea.png)

这一步用“网址转文件”插件。

![](img/9ed34957fe8c7df51d3d47475583fee1.png)

数据来源选“全部配图”；如果只想要封面，选择“封面配图”。

![](img/c9c24b3762811a49b2d85ec0114fed02.png)

开启自动同步，确认后，文本地址会自动变成附件，不到5秒所有照片都出现在工作表内。超过5条的笔记依然取不到完整照片，只能拿到封面。

![](img/9751195dda4a55cc0c21a47238d9e916.png)

那如果笔记有12张图呢？

![](img/411e3ee2d7560ff5939629b8d7d6a8d5.png)

先把笔记网址复制好，回到表格工具继续操作。

系统果然又报错：这个插件只支持处理5条以内的地址。

![](img/2012d42fb15f41b864206881231fef83.png)

点开“全部配图”字段，能看到它其实是由每张照片的地址排列组成的。12张图就是12条地址。

![](img/c1ad5b3cc1def9601196a9cf15b6bfcd.png)

解决办法很简单：把12条地址拆成5+5+2。这时轮到“抽取字段”插件登场。

在“全部配图”右侧加一列，命名为“组1”，使用“抽取字段”，来源选“全部配图”，抽取规则填：只取前5条地址。

![](img/76d5baafe07bc38034337841a02f40b9.png)

开启自动同步，确认后“组1”提取成功。再把“网址转文件”那一列的数据来源改到“组1”。

![](img/bb83639bf6a71a782e9bc0cf51f1dc44.png)

说白了，抽取结果落在哪一列，转文件时就引用哪一列。

![](img/407269311e149f07a477833deee2cef9.png)

至此，不管原始笔记有多少张照片，前5张都能稳定入库。后续每5张一组，做法完全复制：再建一组“组2”。

![](img/e2853e8289470dde1534aef2c1d72e93.png)

抽取规则写：从第6条地址开始，最多取5条；若第6条不存在，则本组留空；若不足5条，有几条取几条。

效果正是想要的。

![](img/6dfee951cc9e6485cbd29b813866cf89.png)

接着在“组1附件列”右边加一列，应用到“组2”。

![](img/a74ba86b4d33dfdfe262745a3c0f902f.png)

确认后，第二批照片也顺利显示。

![](img/a7f42a914f692a18bf287606a3800f33.png)

超过10张时同理：再建“组3”，抽取规则写：从第11条地址开始，最多取5条；若第11条不存在则留空；若不足5条，有几条取几条。

![](img/5c43c208230d9984cce8deb2a7d1445c.png)

完成。照片较少的笔记会看到提示“总共只有5条地址，后续为空”，这是正常现象。

![](img/25fd55b8e5aaf6c43c52feb8a081c7ca.png)

再在“组2附件列”右侧增加“组3附件列”。

![](img/6b6211c107953180702286ab2dce1437.png)

12张照片就全部整理完了。

![](img/93387600ce99f108773ea81ab7b696bd.png)

模板限制只是起点，灵活变通就能覆盖更长的情况。

以后遇到超过12张的笔记，抽取规则按规律续写即可：
- 组1：第1～5条
- 组2：第6～10条
- 组3：第11～15条
- 组4：第16～20条
每组都追加一句“起点不存在则留空，数量不足按实际提取”。

拿18张图的笔记做测试。

![](img/4d68c5554b30eca3094dcee165e394ab.png)

18张等于5+5+5+3，需要组4次。我的模板已经备好，把网址贴进去，整个流程由模板自动完成。

![](img/5957fe648e268e372add463e9d9dce61.png)

单篇抓取到此告一段落。若想整批操作，比如把某个作者的全部笔记一次性搬走，借助扩展就能办到。

我用的是名为媒体助手的扩展。玩过扩展的朋友都知道，Chrome或Edge里都有扩展管理入口。

![](img/359d60bd8f60a62fd7387443b2c12ab3.png)

进入管理页。

![](img/090c6482dba9a6468074f5cbdb82065d.png)

把页面上的开发模式开关打开，再到扩展商店搜索媒体助手并安装。Chrome用户可能需要额外网络条件。

![](img/be73efb51a89941c6e47c6ce2a6dedf0.png)

安装完成后，在小某书和某音的网页端都能看到它的悬浮按钮。比如打开小某书的单篇内容，按钮可离线保存内容、拷贝文案，也能拉取评论区。

![](img/040d516210cfaa35aaf4f488e425a0c1.png)

评论区数据在这里尤其值得一提。我此前写过一个抓评论的Tampermonkey脚本，但它没法导出干净版本的原始照片；该扩展正好补上短板。因此，需要原图走扩展，只要文字用我的脚本即可。

进入创作者主页，还能把整个账户的笔记成批导下来。

![](img/b9c53ca89f8ef5de4258a65e45a4d585.png)

某音也支持，务必用网页端。随便选一个创作者试试，比如一个读书号，点一下导出按钮。

![](img/8ca52566150ae5ec2b660460be234569.png)

可自选条数，演示用10条。

![](img/f1b46baf45eba88304a3b4765a90bdf2.png)

页面右下区域会出现进度提示。

![](img/75830f613f80e11ce6aeb506ebd73708.png)

拿到的这份数据和付费接口相比几乎没有差别，连照片地址都包含在内。所以也能改用该扩展抓取，再放进表格工具执行网址转文件，那10块钱就不用花了。

![](img/6e5a2c580707a8a00f83861c1372b636.png)

短板也很明确：没法按自己的想法随意筛选，而且每次导入新表都要重新设置一遍。若只是想整体抓取某个创作者的全部笔记，也不想花钱，这个方案最合适。

拿到数据后，把原笔记网址那一列复制出来。

![](img/42fb4b103be9f53e2c7c7f969b0372cd.png)

贴进配置好的工作表，几秒内抓取完成。

注意：粘贴时用单击选中单元格，不要连续点两下进入编辑状态；否则所有内容会挤进同一个格子里。

![](img/e33752dba0d8ad50afc39dec138a6181.png)

正确状态长这样。

![](img/17f927ab30e732ab8aef25c4f78b9970.png)

![](img/0e358b4d6c6c0254900d685a72190051.png)

接着照片也全部到位。

![](img/6719f15b1ace5a5dae2769a06ceb2b56.png)

整号抓取之外，还能配合前面说的Tampermonkey脚本做精选式抓取。

找对标有两条路：先全部抓回来再筛，或者边刷边存。我更建议后者——边刷边存本身就在锻炼分析眼光。

用脚本看到中意的笔记就存下。脚本安装地址在素材区。

例如我想研究去新疆玩的素人文案，就专抓这类内容。

![](img/bfd06cdc9c5df521767af96f809bfec7.png)

我抓5篇来看看。

![](img/4d43d4f049c7d1d06577e346aba9517f.png)

之后把这几篇笔记的网址复制进工作表，内容会自动补齐。

![](img/e42f43ba014514bb459216c1626c941d.png)

总之，这个需求不管哪条路都能走通。想要高度自定义，就按上面思路自己配；拿到模板后先另存副本，再按需调整。

不想用付费笔记助手，可以用媒体助手扩展抓取；代价是每张新表都要重新配置。反过来，用付费接口就不用反复设置。

![](img/0f64cb25f75e784cc45ec6d86cecceaa.png)

好了，抓取部分就聊到这。在线表格里还有不少好玩的功能，各位可以慢慢逛。数据到手后，后续分析交给AI处理就行，改写、原创都随意，我此前也聊过挺多相关心得。
