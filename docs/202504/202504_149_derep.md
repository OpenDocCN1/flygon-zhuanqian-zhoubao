# 《漫展活动运营手册》来了，一套能直接落地的全流程操作指南

作者：鲈鱼 Shawn   
发布：2025-03-25

先简单自我介绍一下，我是鲈鱼 👋

还记得 2023 年那篇在星球里发布的关于漫展的精华帖吗？虽然漫展听起来有点偏门，但那篇文章出来后私信和反馈非常踊跃，好多人说第一次搞清楚了漫展活动到底是怎么运作起来的，整个行业的逻辑也清晰了不少。

两年过去了，我虽然已经离开一线不再深度操盘漫展，但对这个赛道一直有关注。这两年平台规则在变，内容传播的方式在变，活动玩法也在不断进化。我也顺手做了一个聚焦漫展举办知识的垂直号，期间累计解答了大量同行和新手的提问，并沉淀出了一份超过 25 万字的内部梳理。这份沉淀，现在正式整理成了《漫展活动运营手册》。

这本手册的体量在 25-30W+，几乎覆盖了从零到落地的完整链路。不是泛泛而谈，而是可以直接拿来当 SOP 和执行 playbook 用。

手册整体框架如下：

**01. 漫展基础认知**
漫展到底是什么？它的商业变现方式有哪些？什么样的人适合入局？市场怎么判断有没有机会？怎么建立一套自己的活动思维模型？

**02. 启动前的准备**
活动怎么立项？时间窗口如何挑选？场地选择的关键点在哪？品牌调性如何确立？冷启动怎么做？审批和报备流程怎么跑？

**03. 活动内容设计**
漫展内容矩阵如何搭建？舞台环节怎么策划才有记忆点？互动游戏机制如何设计？官方 IP 如何引入？摊位招商怎么才能招到对的人？

**04. 组织与执行**
团队怎么搭？各岗位分工怎么定？NPC 人物扮演者的招募与管理怎么做？如何与动漫社团、高校社团联动？

**05. 票务上线**
B 站票务怎么上架？抖音团购怎么对接？微店、小程序票务通道怎么打通？

**06. 线上宣传**
📕、抖音等站内内容怎么投放？新媒体账号如何做运营、涨粉和转化？

**07. 线下渠道联动**
门店合作体系如何搭建？票代的结算和分销机制怎么设计才能跑通？

**08. 风险与预案**
遇到同类活动竞争怎么办？人流高峰如何疏导？舆情危机如何预演？现场突发状况有哪些应对方案？

**09. 工具表格合集**
从票代合同、门店合作协议、摊位招商合同，到展会业务合同、人员劳务合同、公司对接合同、活动报备文件，一套表格直接可用。

这本手册的核心价值，不只是告诉你漫展是怎么做的，而是帮你建立一套系统化的行业观。无论你是做传媒、策展还是想跨界尝试，都能借此快速上手，找到可行的实践路径。

我做这件事的初衷很简单，就是热爱。这个行业虽然小众，但足够有生命力，能抵挡时间的消磨。
