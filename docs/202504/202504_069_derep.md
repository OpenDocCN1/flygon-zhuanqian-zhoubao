# (80 赞)后续发展建议
作者：龙哥

日期：2025-04-15

提问：

老大，最近被几件事卡住，想跟您请教一下，我尽量说得清楚点：

1、【民宿债】疫情前一年签了三年民宿合同准备做民宿，结果刚起步就遇上疫情，只开业了半年多就欠下银行贷款。这几年靠主业工资、副业收入和东拼西凑周转，今年春节前才彻底还清，去年副业的盈余正好把窟窿补上。

2、【短剧项目翻车】2022年疫情高峰期投了一部横屏短剧，为了让朋友执导，我自己拉来30多万投资，还单独签了保本承诺。主控方口头没保底，是我个人担保的。结果项目一直拖到现在还没上线，年底为了平息每周被投资人催的压力，我承诺先把本金退回。本来打算拿还清民宿后的钱来填这个窟窿，结果银行债优先清了。现在 deadline 到点，钱实在凑不出来，投资人今天下了最后通牒。

3、【当下状况】现在主要现金流靠📕内容+电商，过去一年有几十万的规模，去年全被民宿债务吸走了。今年本想冲到百万级别，被这事完全打乱。现在既借不到正规贷款，也不敢碰年息100%的高利贷，对方要我20万换40万。

想问三个问题：
1、这种年息100%的高利贷，预估明年能还上，但怕惹上黑产，该不该碰？
2、能在一两天内搞到30万吗？副业月入几万但都有账期。
3、之后怎么发展？目前已经全职做副业，正在憋夏季新品。

PS：知道您很忙，这事闹得我最近半夜都睡不着。想对投资人负责，又怕一步走错彻底翻车，求您给指个路！

回答

1/ 高利贷绝对不能碰，那是彻头彻尾的陷阱。认输也是一种成熟，接受现实，降低预期，把周期拉长，从头再来。

2/ 一两天内凑齐30万的路子我不知道，那种操作背后是长期积累的资源和人脉在短时间内集中爆发。要是你真找到，我愿意花1000万买下来。

我既有过一天亏3000万的经历，也有过一天亏500万的教训，你要听吗？

3/ 发展建议还是深耕你擅长的赛道，把📕电商这条路做透。
