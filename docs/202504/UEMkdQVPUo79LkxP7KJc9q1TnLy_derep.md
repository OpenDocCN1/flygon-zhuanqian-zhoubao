# 不想再手动复制？RPA帮你自动整理船员信息+打卡记录，20多天“零操作”真香

作为航海志愿者，通常每个人要负责大约35名船员。为了方便查看，大家几乎都是手动把这些船员的信息一个个复制到Excel里。人数看着不多，可重复劳动做久了，不仅枯燥，还特别容易出错。

但这还不算完——信息填完之后，每天还要挨个去志愿者后台核对船员的打卡状态。而且这种事情不是一天两天，而是要连续忙活21天。

说实话，每天这些琐碎工作也就占用几分钟。但你想过没有，把这几分钟省下来，去看看漂亮小姐姐的短视频，难道不香吗？

所以，今天就是来帮大家“偷懒”的。我直接用RPA写了个自动化流程，可以让志愿者后台的船员“🛰️昵称、群昵称、是否围观”这些信息自动填进Excel；第二天还能把上一个航海日船员的打卡情况一起更新进去。

## 这套RPA到底能做什么？

整个流程分成两段。

第一段，负责从志愿者后台抓取船员的【🛰️昵称】【群昵称】【是否围观】等信息，并写入Excel。

程序跑之前，表格大概长这样：![](img/087dd9e66b049f2be1a89ca4e978fba1.png)

跑完之后，数据就自动填好了：![](img/f7c7a966f7a8ee4f65a415ee17b14672.png)

这里要注意下各列的含义：
- 【🛰️昵称】就是后台显示的🛰️昵称；
- 【群昵称】是后台显示的群昵称；
- 只要后台里标记了【围观船员】，C列就会自动出现“围观”；没标记就留空。如果你想，也可以手动改成“提醒”之类的内容，方便和船员沟通后做标记。

关于运行参数，有一点要特别说明：![](img/ee6c4a8350f13c508348d9b16c808b2d.png)

你只有在这个界面运行应用，系统才会弹出【运行参数设置】；如果直接进入代码编辑页面再运行，是不会弹出来的。![](img/7d94b880b2a82ee37eed1f32b31cef24.png)

完整代码也贴出来了，供想研究的朋友参考：![](img/da1bf669154f84bd5c7c3881f7babc69.png)![](img/5ce4d1693a2ab27fcba15c5f964cecce.png)

第二段，负责把志愿者后台“作业”选项卡中的打卡情况，同步到Excel。

不过这里有个关键逻辑：程序只会更新“航海第X天”的“前一天”数据，也就是航海第X-1天的打卡记录；当天的最新打卡不会立刻进表。所以，航海第21天的数据需要在第21天结束后手动补录一下。

另外，这个程序需要每天运行一次。

运行后的效果是这样的：![](img/b897bca7600339971fd5f394b277016f.png)

如果某个船员当天打过卡，系统就会在他对应的日期列写上“1”；没打卡的话就空着。最后一行“合计”直接用SUM函数就能算出当天总打卡人数；等21天结束后，最右边一列也可以用SUM函数自动统计每个船员的累计打卡次数。![](img/b5ce4729602e6988557d773846c0698a.png)

在这个界面运行应用，才会弹出【运行参数设置】。

第1个参数可以不填，默认会读取志愿者后台当天的航海天数。如果你当天忘了跑程序，没关系，等你想起来时，只要手动把航海第X天填进去，它就会去更新第X-1天的打卡数据。

第2、3个参数和上一个程序一样，需要你指定船员Excel文件的路径——两个程序最好用同一个文件路径。

## 一个小坑，懂技术的朋友可以看看

最后再分享一个关于第二个程序的小卡点，纯小白可以直接跳过这段。

程序在查看“航海第X天日志”的时候，需要先用鼠标滑动滚动条，定位到具体日期后，再点击那个选项。

但这个下拉框不是标准的select下拉框，所以没办法用【设置下拉框(web)】指令去直接定位到某个航海日，也基本没法用【if网页包含】或【if元素可见(web)】去判断被遮挡的日期，比如航海第7天（03月26）这类选项。![](img/ab5fed0c1c9222d067d6094492ec73c9.png)![](img/9d0a05e46006ac10192cd230b9bee5f0.png)

后来我通过F12，找到控制下拉框高度的css样式，发现只要取消勾选 `max-height:290px`，滚动条就会消失，原本被遮挡的日期会全部显示出来，这样就可以正常点击了。![](img/8afb9c5e707f3417aa5399bc1cbe43a4.png)

如果是影刀RPA，可以用【设置元素属性(web)】重新设置一下max-height的值，从而去掉滚动条。

但八爪鱼RPA里没有对应的指令——说实话，八爪鱼RPA的指令确实还不够完善。所以这里只能在网页上执行JavaScript函数指令，绕过去实现这个效果。如果你不懂HTML/CSS，确实会有点吃力。至于JavaScript怎么写，其实也没那么可怕，关键是要懂得向AI提问，问对了，答案自然就来了。![](img/d0aef1321f5fabd4842f46f695d60974.png)

要说这篇文章的重点，其实并不是教你怎么写RPA，而是让你直接拿去用。

我已经把这两个程序的编辑权限全部放开了，有兴趣的人完全可以在此基础上改一改、写一写。当然，如果改坏了，别找我就行。
