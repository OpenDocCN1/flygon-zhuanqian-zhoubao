# 抖音作品一收藏就被“整理”进飞书表格？去水印＋自动归档，iPhone 就能搞定



# 先来看效果

![](img/c69b7c63f7756191da0ba94e6537ef9f.png)

![](img/bedfc5d0f5cf68dca3b8ff6d2eada3a8.png)

平时刷抖音，遇到好素材你会怎么处理？点赞、收藏，让它静静躺在收藏夹里？如果你习惯用飞书整理素材，其实还可以再多走一步：点一下收藏，视频就会自动去除水印，并把标题、链接等关键信息写进飞书表格。之前逛社群时，见过不少把网页、👸号内容转发至飞书的案例，但针对抖音收藏这个场景一直没人分享，所以我把这套链路整理了出来。

# 整体思路

![](img/0955b5614c80a04cede87d6d315dd649.png)

整个方案拆成三段：飞书侧先准备好接收表格，Coze 侧搭一条自动化处理流水线，iPhone 侧放一个触发脚本。

## 一、飞书侧：建表 + 记录两串编号

先去飞书官网完成注册，这一步比较简单，不多赘述。

![](img/0e4ab07a6b7b21317742da5d281c7726.png)

注册好之后，来到我提供的模板文档页面，点一下另存副本，系统会把副本存到飞书空间。

![](img/e7a1af2c73f291d761d18508b11158d5.png)

接下来，在浏览器地址栏里找到两串关键编号：base/ 后面的那串字符是这张表的 token；table= 后面的数字则是 tableid。记下它们，Coze 配置时会用到。

![](img/406f25cb275ff814532f1d6cfb3fba4e.png)

![](img/01aaebdfb755fed7bea05386fe7eabf2.png)

## 二、Coze 侧：搭一条自动化流水线

在浏览器打开 Coze 平台（域名：www.coze.cn），注册登录后，创建一个 Bot。名字随意取一个即可。

![](img/1826da86e6c488982bfcc9152c446928.png)

![](img/69be54618ada1307c7533fa9853c18c0.png)

![](img/b05d631fb71e5cf1bcd75f02143f0013.png)

![](img/687435e016284b5618a104057c3f72a3.png)

![](img/3e58f82758ab4a4ae962767d091c899b.png)

进入 Bot 编排界面后，重点放在“工作流”上。

![](img/fedef43a6cefddc775b8f6146417e4e3.png)

流程逻辑是这样的：先把分享链接转成标准格式，再读取作品信息，接着抓取无水印视频或图集，最后交到表格里。

按这个顺序，在流程中依次加入三个模块：

- 「抖音短视频链接转换」：负责把分享链接解析成可用的标准链接
- 「douyin_link_reader」：负责取出视频的基本信息
- 「抖音视频图集无水印下载」：负责抓取无水印视频或图集

接着插入一个脚本节点：

![](img/07a55957f00dc446166102b18fc933fc.png)

![](img/478b9a30494fa648cb75a0ae1aee5876.png)

点开节点后，在输入参数区域建立 data、yw_url、content、content_type 四个参数；输出变量里新增 record，类型设为 string。

代码直接用现成的，打开需要的脚本链接，把全文复制过来。注意把默认脚本语言选成 Python，再整体粘贴，覆盖原来的内容。弄完后关掉编辑窗口，系统会自动保存。

![](img/05f5bf7ed0cc382164d1be49ab44306e.png)

![](img/3833489b1b575695a60717fead8abf9f.png)

随后把「飞书多维表格」组件接入流程，负责最后的数据写入。

![](img/c068d43a0cc6fc01e0d36406d2822046.png)

首次测试时，页面会给出一段授权提示，需要点开里面的蓝色链接完成授权。

![](img/23e6511f23a601c67879279424564cc4.png)

第一次运行后，把返回结果里的参数和链接记下来，点击蓝链完成授权即可。

授权完成后，页面会生成访问令牌（token），妥善保存。顺便把流程 ID 也记录下来。

![](img/eff0e8eb41e7e33c44b0b217e5ea7336.png)

## 三、iPhone 侧：放一个触发脚本

最后来到手机端。我做好了一条自动化捷径，点开下面的链接保存到手机：

https://www.icloud.com/shortcuts/4ad51015dd4045d59de775f9e8c3e5c7

存好后打开编辑页，滑到最底部，找到填写 token 的位置，把刚才那个访问令牌粘贴进去。

```
Bearer pat_XXX
```

![](img/95b30d176f5d78b26f6283f8d8dd5e6b.png)

别忘了，令牌前方还有一串 Bearer 前缀，后面跟着一个空格。这是请求格式固有的部分，不要删掉。

唤起方式可以自己选：在 iPhone 的辅助功能里，把“轻点背面”的双击或三击绑定到这条捷径上；也可以设置成辅助触控按钮。以后刷到想收藏的作品，顺手触发一下，整套自动归档流程就完成了。

![](img/53b2194fc0a3a732b929bc4674a2c790.png)

![](img/02e756d844146fd1168ad121b5695912.png)

到这里，三端链路已经全部跑通。下次刷抖音时点个收藏，再去飞书表格里看看，内容应该已经自动躺在里面了。
