# 我花了半年把工业品无货源电商从零做到能稳定赚钱，踩过的坑都在这里

大家好，我是龙哥。

最近被不少人问到工业品无货源这条路到底能不能走，我想把自己过去半年的实操经历坦白地聊一聊。

说实话，一开始也是半信半疑的。直到龙哥老师一直强调工业品电商的空间很大，才让我鼓起勇气去试。每次遇到想放弃的念头，就会想起这句话，结果真的被指引对了方向。

时间线捋一下：从去年下半年正式入局到现在，差不多六个月的周期。最开始只是摸索着跑模型，去年就已经小规模验证成功，当时我自己都觉得是不是只是恰好撞上了好品类。没想到过完年后，新上的品类接连起来了，流量开始可控，订单不再是偶发，收入也逐渐变得 predictable，团队和上游供应链也慢慢搭起来了，算是真正从试错期进入稳定期。

这段路走下来，最大的感受就是工业品这块市场远比想象中更有想象力。
