# (23 赞)跨境卖家在墨西哥走街串巷，发现巨大的信息差
作者：龙哥

这段时间，美国关税政策连番波动，把不少跨境卖家的节奏全打乱了。就在大家焦虑观望的时候，TikTok悄悄向墨西哥放开了大门——消息一出，我立刻订了机票，亲自飞过去待了四天，跑了不少地方，也见到了不少当地人。

说实话，出发之前我是龙哥。但真正踏上墨西哥的土地之后，我才发现，原来纸面上的了解和一个真实的墨西哥之间，隔着整整一整个信息差。

出发前，几乎所有人都跟我说：墨西哥太危险了，别一个人去。说什么的都有，抢劫、绑架、街头枪战，仿佛我这一去就是九死一生。这种话听多了，心里说不发怵是假的。可等我真到了那，才发现现实和传言完全不是一回事。城市比想象中要规整，大部分地区治安状况并没有传说中那么夸张，更重要的是，这里充满了机会与活力。

这是我第一次来墨西哥，但绝对不是最后一次。

这四天里，我几乎没有停下来过，一场接着一场的走访和考察，手里攒下了大量一手资料，很多细节跟外界的刻板印象完全不一样。怎么说呢，用一句话来概括：我们以为很了解这个市场，但实际上，大多数人甚至连边都没摸到。


另外说一句题外话，这几天已经有不少同行注意到，墨西哥本地的店铺资源价格正在悄然上涨，市场嗅觉灵敏的人早就开始动手了。

信息差永远存在，但你能不能赶上这趟车，是另一回事。
