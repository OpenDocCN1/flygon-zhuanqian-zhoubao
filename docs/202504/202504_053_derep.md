# 从零到上线四站：一个文科老人的 AI Web 航海踩坑实录
作者：龙哥

作者：liliya | 2025-04-14

大家好，我是 龙哥，混迹赚钱圈四年了。这次报名了 AI Web 航海训练营，最后实打实把 4 个站点推上去了，3 个是游戏类站，1 个是 AI 绘画工具导航。说实话，现在流量几乎为零，收入也是零，但过程带来的成长感真的太强了。

尤其是对我这种文科背景、年纪也不小的玩家来说，完整走通一次上站流程，本身就是一次不小的突破。

开局第一个站点还算顺畅，后面就开始各种卡壳。最致命的一次是卡在图片站的部署环节，直接卡到航海结束都没解开。回头复盘下来，我这套弯路、走神、焦虑的节奏，大概率就是很多新手小白的真实写照。

所以我把这次用 Cloudflare 部署全过程里踩的所有坑，重新整理成了图文笔记，算是对官方航海手册的一个补充细化版本。主要是想帮到那些** *还没成功把站点上线，或者在 Cloudflare 这一步卡住的圈友***。
