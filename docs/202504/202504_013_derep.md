# (11 赞)MAC 端 定时强制休息 appTime Out，实现 app 图标和锁定弹窗 icon 修改

最近为了治我的“一坐到底”毛病，特意在 Mac 上装了个强制休息小工具——Time Out。每隔一阵就锁屏提醒我起来走走，效果确实不错。不过这默认的图标实在有点“原生态”，看着没啥动力，索性自己动手把应用图标和锁定弹窗的展示图标一并换掉了，瞬间顺眼多了。

整个替换思路不算复杂，关键是要找到对应的资源文件，再借助 mac 自带的图标替换机制，把想用的图标拖进去就完事。弹窗上的那个小 icon 也能一起改，让整套界面风格统一起来。具体怎么操作，涉及到的路径和步骤比较细，我整理在了飞书文档里，照着走就能搞定。

有同样需求的朋友，不用再对着丑图标叹气了，直接去我的飞书看完整替换流程。
