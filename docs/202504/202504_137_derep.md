# 从零起步，我如何用三个月在 TikTok 把月销量做到上万单

作者：王润博 Rocky
发布日期：2025-03-29

去年十月，我正式在国际版抖音 TikTok 上开店。上来之前就觉得出海这条路值得试，于是把重心全压在了 TikTok 电商上。

结果出得很快。开店第一个月，订单就到了几百单。第二个月直接拉到几千单。第三个月，一个月就破了万单。

这套打法本质上是从 1688 找货，算是一种无货源玩法。目前能做到直接跨境发货的，只有东南亚的 TikTok 店铺。美区就不一样了，美区基本要走本土仓储和履约，对小白来说门槛和难度都高很多。
