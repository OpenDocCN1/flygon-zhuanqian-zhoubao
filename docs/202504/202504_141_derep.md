# (1 赞)YPP 视频收益正盛，写一些和主流声音相悖的内容

最近不少做视频的朋友都在聊同一个话题：YPP 的分成收益还在风口上，红利肉眼可见。可就在满屏都是“如何赶上这波流量”的时候，偏偏有人不打算顺着大流说话。

刘同学这次就特地整理了一篇“逆耳”的内容——不是说教，也不是泼冷水，而是站在和主流观点不太一样的角度，把这阵子的YPP收益热重新拆解了一遍。是机会当然没错，但有些值得留意的地方，可能大多数人在热闹中都忽略了。

他把这些想法系统地放进了自己的飞书文档，想看完整版本的可以直接点进文档慢慢读，链接我放在下面了，感兴趣的朋友自取。
