# 海南海口线下聚会分享复盘
作者：龙哥

作者：条形马
日期：2025-03-28

晚上好，各位。

简单跟大家同步一下上周六 3 月 22 日的行程。那天受赚钱之邀，去了海南海口参加圈友见面会分享。周末虽短，但体验很丰富。

现场氛围很舒服，分享也进行得比较顺畅。在那个场景里，我忍不住想多聊几句，也更愿意敞开一点和大家交流。哪怕只是客套话，也要先感谢一下主办方的工作人员，以及百忙之中赶来现场的各位赚钱圈友。

这次受邀的几位老师，黄小鱼、掩体、小伞，给了我很多启发，笔记也记了不少。
