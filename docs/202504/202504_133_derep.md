# 一个月卖出90万！📕纯笔记带货的实操复盘，建议认真看两遍

这波成绩，先得归功于坤哥和seven老师。坤哥的指点，让我把方向定在了📕笔记带货；seven老师那篇选品长文，又帮我锁定了“原创实拍”这条路线。

不夸张地说，seven老师的选品方法真的值“百万”这个评价。我照着文章思路做了款微原创产品，累计卖了200万，眼下每天依然有大几千销售额入账。

我给自己定的原则是：产品要合法，玩法要合规，做的事情要有积累、能沉淀。📕的流量长尾效应特别夸张，你认真布下的内容，可能过很久还在持续被搜到、被下单，真·长坡厚雪。

目前店铺的基础盘是这样的：

- 单店月销90多万，清一色原创实拍，纯笔记带货，没开过1场直播
- 每天仅花600-800元做乘风微付费投放，相当于给笔记买点冷启动
- 账号结构：1个蓝V主号 + 3个关联子账号
- 内容节奏：每天30多篇挂车笔记，图文占比60%，视频占比40%
