# 两周涨粉 2万 的📕养生账号怎么做？

我扒了一个半个月涨了两万粉的红书账号，发现养生号的国风视频全是AI做的

红书上的健康内容，这几年一直是流量重地。早先有账号靠大字海报就吸了几十万粉，“百岁老人计划”是典型；后来又冒出个“拉屎女王”，单聊排便话题就把带货橱窗做到近百万成交。

![](img/1ebc9f814d2a9b905dce8ef8d494abf9.png)

这类内容为什么总有人看？因为主题常青，形式又会翻新。最近更新的玩法，是把养生内容包装成中国水墨动画。“无忧四季养生”这个号只用了半个月就积攒了两万粉丝，而且整套做法用AI就能复刻。
![](img/e2def69349f101a579cadce0a1c62dcd.png)
下面按三步拆：定主题、写文案、做视频。
![](img/7836d298f1aaae424f1d2bef735c2f1b.png)

先看它的16篇笔记，内容其实很统一：菜怎么处理，身体各部位分别该吃什么，孩子春季怎么吃，哪些食物能提升免疫力，哪些坏习惯比吸烟还伤身，垃圾食品要怎么“解毒”，还有长寿和零成本调理。所有食材都是日常货架上的普通东西，但标题都带着很强的效果感。一句话，就是用最便宜的材料讲最厉害的好处，走的是省事养生路线。
![](img/c0072ab390d9ba15c81abf63287b97ed.png)
照这个思路延伸主题：比如一日三餐搭配，消水肿食物，身体受损预警，春季长高菜，养胃黄金食材，排毒茶饮。我最后挑的是养胃黄金食材。
![](img/1022f33642135c8606a313fa5c8b85b5.png)

看点赞最高的几篇，每篇都是短句、押韵、节奏工整，有点像“三字经”的古风版。比如写器官和食材，都是“某器官喜欢某食物”的句式；写焯水，把每种蔬菜的问题和解决办法编成顺口溜；写补脑，就按不同脑部状态给食物。这种文体用AI写很容易。先给模型一段身份设定，再报上食材名，它就能生成同款韵文。
![](img/1b9848fa0b7154eb82c52ad533626fbb.png)
我当时用的指令类似这样：
```
帮我就——《5种黄金食材，让你的胃越来越强壮》这个主题，写一段文案，需要是古文体。你可以参考下面的例子：

——————
《身体各器官最爱的食物》
心脏喜欢红薯，肺部喜欢梨，血管喜欢西兰花
大肠喜欢苹果，大脑喜欢核桃，脾胃喜欢山药
肝脏喜欢枸杞，肾喜欢黑豆，皮肤喜欢西红柿
眼睛喜欢胡萝卜，牙齿喜欢猕猴桃。

《这些常见的蔬菜需要焯水》
豆角不焯水，肚子疼成鬼。
菠菜草酸高，热水易冲销。
蘑菇杂菌多，沸水一焯净污浊。
西兰花藏虫深，滚滚热水来驱奔。
香椿亚硝多，烫过才敢说。
木耳沙难去，焯水更顺利。
黄豆芽藏菌，热水洗礼更放心。

《疯狂长脑的8种食物》
注意力难集中，多吃全麦面包
爱忘事，多吃银杏果
学习效率低，多吃南瓜子
脑子笨笨的，多吃深海鱼
记忆力衰退，多吃花生
大脑紧绷，多喝绿茶
逻辑混乱，多吃芦笋
脑子卡壳，多吃鸡蛋

《越吃越健康，看这些食物》
常吃菠菜抗衰老，常吃番茄皮肤好
常吃枸杞眼睛亮，常吃红枣气血足
常吃核桃记性好，常吃山药肠道顺
常吃苦瓜火气消，常吃豆类补蛋白
```

文案定了之后，把每一句拆成一张图。描述画面也可以让AI来写，例如第一句可以写成“古代文人在书房喝南瓜粥，旁边有竹简和画卷”，第二句是“雪天庭院里，书生举着生姜，袖袍随风飘”，后面的句子照这个格式补完。
![](img/d1cb2af8bbdce3acd543bb97270428a9.png)
接着要复刻博主的画风。截取他作品里的几幅图，上传给AI让它反推风格描述，得到的关键词大约是：国风水墨、古典雅致、淡彩柔和，有东方禅意，笔触接近齐白石，墨韵接近李可染，构图又有张大千的影子。
![](img/b0b59d031ecdafa2f1c443cd08423b94.png)
把这些描述粘到即梦的文字转图页面，第一张成品就出来了。

然后让图动起来。文生视频工具可选的不少：海螺AI、可灵、即梦、Runway、Sora、Vidu、Luma、PixVerse。我选海螺AI。
![](img/1487f6fc08f5afaecabf48a2effa7266.png)
把七张图依次上传，输入动作描述，比如“镜头缓缓推进”“衣角微微飘动”，生成七个小视频，存到本地。
![](img/768d23ef699163fce71e0b772b7a4468.png)
打开剪辑软件剪映，把七段素材按顺序拖入轨道，拼成完整片子。
![](img/8d198dba5cc33cd753f78e7001a76da0.png)
![](img/6bcb29a4f83cdfeab3638f3358935d59.png)

声音部分，用Fish Audio克隆原博主的声音，生成旁白。
![](img/07bbce6bfde88b50907b3d223f4bbf85.png)
生成的音频可以先试听，满意后再放进剪映备用。
![](img/eeb228e4f1dca5fa54312b3fa01a2732.png)
字幕字体需要对齐。把原视频字幕截图丢到字体识别网站，返回的是“华康俪金黑”，我们就用这款字体。
![](img/eb188e2b17c9c0b2afcaa6ec8c47fbb0.png)
![](img/2050b9e018592435b6d5e9bca88bba13.png)
![](img/1de15c8a8b884d91fcc760aefd71c75c.png)
然后在剪映里调下字号和描边，字幕就清楚了。
![](img/fe6586cd1c66eee13fd9aea64d7ff829.png)
BGM方面，原片用的是《神话》的一首古风改编，我搜到剪映自带葫芦丝版本，直接拖进音乐轨。
![](img/95f3bd14a8101e6c793290607f47ac4c.png)
![](img/8673f61aa88e71a6160f0213baa12673.png)
最后根据旁白节奏把每段画面修剪到合适长度，声音画面完全对齐。
![](img/62df318b80f956f773cff082a183819a.png)

全部搞定后，如果旁白音量不够，就用剪映把音量推高。再做一个封面图，这个账号就能照常发布。
