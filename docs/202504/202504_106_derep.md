# **总结**

1. 用英文写提示词效果更稳。图片里要出现文字的话，中文目前还不理想，英文表现很好。

2. 细节上还是有小瑕疵，但整体效果已经绝了。

3. 美工大概率不会被彻底干掉，但会用 AI 的美工效率会翻倍，而不会用的美工很快会没饭吃。

4. 对于做铺货的电商老板来说简直是福音。用这个工具可以给产品换背景、换模特，每张图都是独一无二的原创。

5. 不止电商，做社媒、做 SEO，只要工作里有图，原来的流程里都能塞进这个 AI 来大幅提速，还能提升原创度。
