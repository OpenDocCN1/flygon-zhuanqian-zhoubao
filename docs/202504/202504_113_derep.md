## Cursor 指导搭建云服务器全攻略

作者：TED  
发布日期：2025-03-26

最近在做 iOS 航海训练营，第一次深度用上 Cursor，体验相当惊艳。

之前我用 Cursor 搭 Web 项目，跟着 Claude 的提示装好 Node 和 PM2，整个网站运行环境算是勉强跑起来了。这次为了 iOS 开发，想按教程装宝塔面板，结果 Nginx 直接冲突，环境乱成一锅粥。

我本来的诉求很简单：同一台云主机，既要能跑 Web 服务，又要能支持 iOS 应用的后端开发。既然现有环境已经不可救药，不如直接重装系统，完全交给 Cursor 来操刀部署。星球里关于云服务器从零配置的干货并不多，我就把这次实操过程整理出来，方便大家少走弯路。

这篇内容适合三类人：
* 想给 Web 或 App 搭服务器，但完全不知道从哪开始；
* 服务器之前配过，现在想推倒重来，配一个更干净的；
* 服务器已经到手，想部署 API、挂 Web 页面却卡在环境上。

篇幅有点长，但希望能帮你省下不少踩坑的时间。
