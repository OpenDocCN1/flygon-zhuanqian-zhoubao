# 为什么发财的人总是少数？
作者：龙哥

很多人穷的不是钱，是定位。

真正限制一个人财富上限的，往往不是能力不够，而是方向乱了。

有一种典型的思维陷阱，就是一旦尝到一点点甜头，就开始觉得自己什么都能做。于是顺着这种“无所不能”的错觉，什么热闹追什么，什么赚钱去碰什么，最后的结果是：到处沾边，到处平庸。擅长的没有深耕，不擅长的硬要上阵，时间、精力、资源全被摊薄了，财就自然发不起来。

发财从来不是靠广度取胜，而是靠精准打击。

一个人如果能把自己最擅长的东西，跟市场正在强烈需要的东西撞在一起，就相当于站在了风口的中心。这才是财富积累的最小阻力路径。

评论区里一句话说到了点上：

做战略的本质，其实就是把“你能做好的事”和“时代正在要的事”拼起来，让两者互相放大、互相配合。当个人优势与时代需求形成共振时，才是最完美的战略，也才是最容易变现的战略。

少做点自己不擅长的事，多把自己擅长的那件事做到极致，再把它放在对的时间、放进对的需求里。道理很简单，能坚持下来的却很少。
