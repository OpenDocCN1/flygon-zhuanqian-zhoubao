# 收入 30 万+的 AI 线上兼职项目复盘

从零到30万，我靠AI接单挣到的小里程碑

先自报家门：之前那篇AI副业经验贴是我写的，当时没敢写透，因为事情还在进行中，很多结论还没稳定下来。现在团队从5月启动至今，累计赚了30多万，算是到了一个值得记录的时间点，所以静下心做了次复盘。

这次的复盘讲了五个方面：
一是这个接单方向的机会到底在哪；
二是当初我选择这条路的理由；
三是它的赚钱逻辑怎么层层运转；
四是从和客户沟通到交付的完整流程；
五是面对形形色色的需求，怎样产出对应的内容。

完整版内容比较细，我放在了飞书链接里，链接放在文末，感兴趣的可以自取。

留言区里，有朋友说内容很干，收获很大；也有人说这个方向还很有潜力，值得试试；还有人追问，不同稿件的Prompt怎么写？有没有现成的模板？怎么继续深入学习？怎么联系我？
