# 新手怎么做韩国跨境电商？以出名的 coupang 运营为例
作者：龙哥

最近不少圈友在问小白怎么做韩国跨境电商，今天就结合我自己折腾两年多的踩坑经验，跟大伙儿掏心窝子聊聊这个事儿。

先讲个有意思的发现：我刚开始摸索韩国市场时，成功逻辑其实特别朴素——韩国人天天吃泡菜，那我就卖不锈钢菜板，主打一个防菌好打理；韩国女生冬天再冷也要穿裙子，那打底袜绝对是刚需，到了夏天就换连衣裙上架。

这套打法说白了就是“抄作业”：把韩国人生活习惯里藏着的需求挖出来，照着本土热卖款去跟，基本都能跑通。我自己就是从这一步开始，慢慢才走上精细化运营的正轨，后来再优化产品、打磨详情页、拉升订单量。想入局东南亚、韩国这些市场的朋友，初期真建议往“本土化”这个方向靠，先把基本功打扎实，再跟着市场节奏逐步放大。

先简单交代下背景，我是今年刚进赚钱的新人，圈里年入百万、千万的大佬太多，我真不敢班门弄斧，就把自己实操的一点心得拿出来分享下，说得不到位的地方还请前辈们多指点。

在韩国做电商，绕不开Coupang这个平台。有人在这儿赚到了第一桶金，也有人亏得血本无归。那这平台到底值不值得做？我为什么要从它入手？下面从几个维度拆解一下。

# 一、为什么我会选择入场韩国市场？

**（1）先看底子：市场蛋糕够不够大**

韩国虽然只有5000多万人口，但电商活跃用户已经超过3300万，也就是说每10个韩国人里就有6个在网上买东西，这渗透率相当惊人。

再看钱包厚度：2022年韩国人均GDP达到3.23万美元，对比国内的1.28万美元，购买力差距直接拉满。换句话说，韩国电商市场的整体含金量约等于国内的北京+上海两大城市。

另一个关键指标：韩国目前是全球第五大电商市场，2022年交易规模冲到1429.2亿美元，排在他前面的只有中美日英四国。而且韩国线上零售占总零售额的比例已经到32%，仅次于中国的46%和英国的36%，这反映出韩国人网购的习惯相当深厚。

![](img/8b1d35bf053b74ab8489e8c6b97484ac.png)

**（2）再看增量：趋势和风向都对**

年轻人正把海淘玩成日常。韩国统计局2023年6月发布的在线购物报告显示，二季度跨境网购总额达1635亿韩元，同比涨了25.6%；其中中国直购商品金额更是暴涨120.7%，达到777.8亿韩元——咱们的货在那边确实吃香。

![](img/7c8aad469cb6b0237cbd30dbb3093f4e.png)

移动端交易同样增速迅猛，2022年三季度同比涨了21.2%。从平台格局看，Coupang月活用户接近1700万，稳坐韩国头把交椅，后面跟着11街（993万）、Gmarket（817万）、We Make Price（760万）、Auction（561.3万）。这也是我第一站就选Coupang的核心原因——流量集中，大哥位置稳。

（多说一句，韩国市场天花板确实不如欧美亚马逊那么夸张，但好处是大卖看不上、小卖家竞争也不激烈，对咱这种白手起家的新手反而友好。）

# 二、我在Coupang经历的四个阶段

我属于纯小白，没干过国内电商，平台后台、物流、选品、广告、韩语一概不懂，规则更是两眼一抹黑。

（给新手一个建议：起步阶段一定要混圈子，找群找战友交流，跟有结果的人学，比一个人瞎摸索快得多。）

我从2021年9月入驻，当时拉了几个网友组了个小群，互相答疑打气。如今群里100多卖家全都成了并肩作战的伙伴——除了不互问具体卖什么品，其余经验知无不言。大家现在人均年销售额过亿韩元，月入万八千块人民币轻轻松松。

**（1）第一阶段：跟卖试水**

刚上手时选了个最省事的玩法——跟卖。找韩国本土热销、国内又能供货的产品直接挂链接。

第一个爆款是不锈钢菜板。我赌的就是韩国人的泡菜文化，切泡菜容易滋生细菌，这款防菌菜板应该能戳中痛点。果然，上架当天就出了6单，那成就感至今难忘。不过当时对物流和定价完全是外行，最后算下来销量好看但利润没达标。但每一次试错都是垫脚石，这个模式跑了2个月，到手差不多1万块。

![](img/7c936f954388154f9f52a03f89639946.png)

11月天气转冷，我开始往保暖方向想。韩国女生冬天穿裙子是刚需，打底裤肯定有市场。于是照搬菜板思路，在拼多多找到同款货源，第一天直接十几单，之后每天稳定10单左右，单件利润27块。这一个品过冬卖了大概1000条，赚了2万多。那一刻才真真切切感受到：这个市场太肥了。

我的选品方法论也是在那时定型的——**跟着韩国人的生活节奏走，契合季节需求，找用户非买不可的东西**。

不过12月份平台开始严打跟卖，而且这玩法侵权风险确实大，韩国对版权极其较真。我就顺势转向铺货。后来才知道，有人早就在用批量跟卖软件，一键扒走本土卖家整个店铺的链接，根本不管什么选品，纯盲铺，一天几百单。哎，信息差就是钱，人永远赚不到认知以外的钱。

**（2）第二阶段：铺货跑量**

用ERP批量传链接，不投广告不烧钱，纯薅平台自然流量。当时Coupang刚对中国卖家开放，正需要中国商家来填充商品库，那真的是躺着都能捡钱的蓝海期。链接越多曝光越大，新品还有流量扶持，出单难度也不高。大批卖家涌入后，商品池迅速饱和，我又开始琢磨转型。

**（3）第三阶段：半精品优化**

有了铺货期积累的数据，我大概清楚哪些品能打了，开始集中优化出单款的标题、详情页、评论区、客服咨询和广告投放，真正进入了电商运营的节奏，一边试错一边摸规则。

平台机制也逐渐摸透：

1、新品流量期。新链接入池后（标题能被前台搜到），有3天扶持期。这期间一旦产生订单，系统会认定产品受欢迎，权重开始拉升，之后销量逐日递增，排名也会跟着往上爬。这其实就是刷单的逻辑，像耳机这类大众品类，连续递增刷1-2周，基本能杀进前三页。

2、广告系统。Coupang有新品广告、品牌广告、关键词竞价等形式，但价格是真的贵。我因为走低客单价路线，平时很少开（后面讲我选品策略里的秘密）。

3、用户咨询。链接底部的问答区域也是隐形加权项，有人问就有流量和转化提升。

4、核心还是选品。我常用的三个维度：搜索热点、关键词、销量榜。

**① 按搜索热点选品**

Coupang没有独立的关键词搜索工具，官方也没开放数据接口。我一般看NAVER——韩国最大的搜索引擎，全球排第五（仅次于谷歌、雅虎、百度和必应）[`datalab.naver.com/`](https://datalab.naver.com)。

在这里能看到每个品类每天的热搜关键词排名，跟着热点上品，就能踩准当季需求：春天上防风衣，夏天推连衣裙和雨伞，秋季准备衬衫和夹克，冬天做起滑雪服和棉服。

**（4）第四阶段：精品护城河**

这个选品路子让我舒服了一阵子，每天出单稳定，收入也满意。但没过多久，有同行发现了我这款产品，直接照搬上架，虽然他不知道我的关键词，但价格比我狠，订单量肉眼可见下滑。

这时候开始琢磨怎么建立壁垒——答案就是商标+OEM。去韩国注册商标，找国内工厂代工贴自己的牌，渠道和货源都攥在自己手里，别人想抄连货都拿不到。

想在这行长久舒服地赚钱，必须有自己的供应链和品牌，不然利润迟早被卷没。

# 三、不同店铺类型的玩法与区别

**（1）中国跨境店**

有两种官方仓发货模式：

**CGFLite模式：**
从1688拿货发到官方仓，再由官方仓转运到韩国消费者手里。
优势：一件代发，不压货，资金压力小；
劣势：时效慢，没有紫色火箭标识，流量表现差一些。

**CGF模式：**
提前备货到官方仓，出单后官方仓直发。
优势：带紫色火箭标识，流量更好，有官方扶持，还能参加促销活动；
劣势：需要压货在威海仓，占用资金。

**（2）香港跨境店**

**自发货模式：**
出单后通过第三方物流直接寄到韩国。
优势：物流成本低；上架不用经过官方审核，可以大量铺货；无需压货，支持一件代发；
劣势：整体成本比国内跨境店略高，流量也差于本土店。

**（3）本土店**

**韩国自发货：**
用一般贸易方式把货先囤到韩国海外仓，出单后从当地发货。
优势：本土发货2天就能送达，体验好；
劣势：要承担海外仓租金、压货成本和韩国税费。

**中国自发货：**
玩法跟香港自发货一致。

**橙火箭：**
货压到Coupang韩国官方仓，出单后官方直发。
优势：橙色火箭标识加持，发货快，流量大；
劣势：压货占资金，官方扣点加韩国缴税，利润空间相对薄。

**（4）一个联合运营的“骚操作”**

跨境店不能跟卖，但本土店可以。于是有卖家动起了脑筋：
第一，用本土店跟卖跨境店的链接，配合韩国本地物流单号做单，能有效规避平台查刷单的封店风险；
第二，本土店跟卖跨境店链接还能给跨境店引流提权，毕竟跨境店没有税，利润优势更明显。

**（5）货源渠道**

最常用的还是1688、拼多多和淘宝，如果你有更好的货源渠道，欢迎在评论区交流共享。

# 四、做起来Coupang的五大核心要素

**（1）吃透规则**

想在Coupang站住脚，先要把它的排名逻辑摸清楚。我整理了一套爆单SOP，把影响链接权重的所有因素列出来，再逐一对产品做优化配置。

看不懂没关系，总结成五字诀：**“抄”“仿”“烧”“打”“刷”**——抄就是选品，仿是照着优秀同行设计主图描述，烧是投广告，打是打价格战，刷嘛，自然就是刷单。

**（2）抄——选品**

**需求选品法：**
从本地人的生活习惯出发。不清楚韩国人爱什么？就去看平台上什么卖得好、评价多，这两块就是藏宝图。销量能告诉你哪些产品受欢迎，找到那些有一定单量的爆款，优化链接、设好广告、调整价格，把流量截过来。评价则是消费者心声的窗口，能帮你快速搞懂他们为什么买、对产品的真实反馈。平时也可以多关注韩国人的生活方式，比如那边的男生女生就挺喜欢手工艺、十字绣、编织包、手绘画。

**关键词选品法：**
专找蓝海长尾词，用关键词工具挖掘细分赛道，靠关键词布局实现出单。

**（3）仿——主图与详情页**

比如你知道宠物自动喂食器在韩国卖爆了，自己照样上架却不出单，问题多半出在主图和详情页。我的做法是：去平台找该品类销量Top10的链接，逐个拆解他们的视觉设计逻辑，学习并内化成自己的方案。实践下来发现，详情页里放动图或者宠物实际使用视频的，转化率要明显高出一截。

**（4）刷——刷单的艺术**

只要是电商就绕不开刷单这关。多数Coupang卖家找服务商，一单25-30块，捧一个品要30-100单，相当于至少花两千多试错成本。很多人没有这个魄力和资金，所以刷着刷着就放弃了。

我当时的操作是：花了2000块买了十几个刷手号自己操作，成本一下子打下来。在产品质量和详情页过关的前提下，一个品刷50单大概只要100块钱，如果没明显起色立刻换下一个品继续测试（注意：现在国内跨境店已经刷不了单了，想刷就得搞个香港店铺）。

**（5）跟上趋势**

做好Coupang其实没想象中那么难，选对品+刷好单，普通类目保守估计单链接日销10单，一天赚两三百并不难。想单日几百单就别想了，韩国人口天花板搁在那儿呢。

最后聊聊平台风向。这两年Coupang的变化太快，每个动作都要反应敏锐，跟着政策走才有肉吃，不然永远在啃别人剩下的骨头。比如最开始能跟卖，等有些人听到消息进场时，平台已经开始打击跟卖；平台早期不管刷单的时候，有人成百上千地刷，结果等平台动真格严查时，反而有些人偷偷摸摸地试水，最终被封了店。

为什么前两年Coupang好做？说白了是因为平台规则不完善，到处都是漏洞和红利。有人说它三天两头变规则，但换个角度看，每次洗牌都是新机会。要敏感，要快速，要果断——想搞钱就得冲！

# 五、门槛、机会和风险

**（1）入门门槛**

**国内跨境店：**
需要中国营业执照、法人身份证、手机话费流水等材料。入驻成本不高，大概200-500元。真正难的是运营资金——平台结算周期长达2个月，你得备足3-5万周转金。

**香港跨境店：**
需要香港营业执照和法人资料。办执照4千块，入驻费1千块，买现成店铺则要1万左右，同样需要3-5万启动资金。

**韩国本土店：**
需要韩国公司的营业执照和法人资料，一般要委托服务商代办，费用3-5万。入驻后每月还有1000多的固定开销（话费、房租、记账），启动资金建议至少20万。

**（2）机会点**

韩国电商市场规模有限，大卖家稀缺，小卖家竞争也不算激烈。对新入局的玩家来说，这恰恰是难得的成长窗口期。

在韩国站做跨境，退货体系并不完善，这直接影响了选品思路。绝大多数商家只能扎堆做低客单、走走量来填补利润缺口。而一旦改走韩国本土店，并且能对接上靠谱的海外服务商来承接退货闭环，高客单、高毛利的品类就完全打开了，空间相当可观。

**要注意的风险**

其一，teum 正在推卖家托管+低价打法的组合拳，流量和订单的内卷被进一步放大，后续想守住盘面就得提前想转型路径，比如往非标品、差异化品类上挪。

其二，平台对刷单的打击越来越精准，现在做刷单基本都要真发货，一单下来光是物流就要吃掉约15元成本，整体刷量成本只会越来越高。

# 六、总结

**给新手的落地方案**

如果你是刚起步、预算不算充裕的新手，我更倾向于先用香港店练手作为跳板。原因很实际：

1. 操作弹性更大。香港店在铺货和刷单的自由度上，都比国内的跨境店更宽松，留给新手试错的空间也更多。
2. 资金压力更小。香港店的整体开店和运营成本明显偏低，相较于韩国本土店，能帮你把起步门槛压到最低。

当然，如果你本身资金储备充足、已有一定实操经验，也愿意承担前期投入，那可以直接上韩国本土店。

前期投入确实会高不少，但换来的是更稳的长期盘子和更高的利润天花板。加上能用上海外仓，履约时效和服务体验会是明显的升级。
