# 一个采耳师，月入一万五

前阵子出差，和客户吃完饭，顺路去做了个采耳。给我服务的是位四川大姐，店里的头牌，正好有空，就多聊了几句。

她年轻时候在工厂打工，一个月也就几千块钱。后来到贵阳郑远元店里做修脚，年纪渐长，体力跟不上，收入也不理想，索性辞了。

再后来听说采耳这行轻松些，就动了心思。可没技术，去店里应聘，人家要先收五千块学费。她和同伴舍不得，私下找到店里一位师傅，花了五百块，学了个半吊子，其实没太学明白。

后来听老乡说上海采耳赚钱多，立马就跑过来了。

刚上手时技术一般，但她有个特点：爱琢磨。谁手法好，她就凑上去请教；自己平时也没少下功夫研究。靠着这股劲，慢慢攒下一批老客。这些客人无论她到哪儿，都会跟着找她采。

我好奇问她收入，她说老板包住，自己管饭，一个月到手一万五，能存下一万。丈夫在成都打工，陪着儿子读大学。

聊下来我发现，做采耳无非两种客人。

一种是图舒服的。那你一上手就得摸清人家的受力轻重，喜欢采哪个区域。她说自己上手几下，心里就有数了。

另一种是有耳朵小毛病的。这种就得懂点医学知识，能上手处理。她平时一直在自学，遇到自己拿不准的，就建议客人去医院找大夫。

她还自己买工具和药膏药水，根据客人情况用一点，或者直接送。

所以那些常采耳的客人，每次采完一只耳朵，就会问她工号——能感觉到她专业，下次还点名找她。她现在是店里赚钱最多的员工。

这行她入行也才三年，往后老客越攒越多，收入还会往上走。

这是前几天偶遇的一位普通大姐的故事。她让我相信：做事用心，人人都有机会。
