# 别等完美答案，你的天赋会告诉你如何变现
作者：龙哥

各位朋友，以及所有关注天赋成长的人，你们好。我是龙哥，一名坐标北京的天赋教练，也是一个小型教育品牌的主理人。从北京大学完成学业后，我先后在不同体制的企业做过十余年人事工作。2018年，我离开了职场；两年后，我正式创立了自己的品牌。这三年多，我一边在家工作，一边经营事业，累计创收了400多万元。我们没有雇佣几位全职员工，也没有租用办公室，年收入却始终稳定在七位数。

这些年，我拆解过上千份评估报告，也和几百位学员单独交流，长期陪跑他们。最触动我的，不是谁不够努力，而是太多人因为不认识自己，白白绕了好远的路。所以我想把“认清天赋”这件事，讲给更多想改变境遇的人听。

聊到赚钱，很多人想的是方法、风口、运气。我却觉得，第一步是定位。你最后能获得多少回报，本质上取决于你为别人做出了什么贡献。而你能做出什么贡献，又取决于你在哪些方向上有真正的天赋。换言之，天赋为你画好了坐标：你适合站在哪种角色上，能交付什么成果，能换回多少钱。

发现天赋，别人替代不了，只能靠自己。这像一条孤独又刺激的闯关路，需要拿出全部的勇气面对自己。我见过不少朋友，抱定一个想法：必须找到一个“绝对正确”的方向，才开始行动。结果是，他们都在找方向，从来没有迈出过一步。实际上，方向不是等来的，而是在一次又一次尝试中撞出来的。

我曾经分享过一张位置参考图，大多数人能从中找到两三种与自己有关的可能性。你可以用直觉选一选，再结合对自己的了解，判断自己属于哪一类。

拿我自己举例。创业的头几年，我的标签大致是1和4；如今变成了1、4、6、7。2、3、5从来都不是我的主场，我通过与擅长它们的人合作，补齐了缺口。

无论你做的是图文号、视频号、直播还是卖课，这些只是表面的赛道。真正让你被记住的，是你在具体项目里做出的独特贡献。不妨拿一张表格，把自己的技能和价值逐项列出来，看看哪些别人替代不了。赛道可以换，但你在做事过程中练成的本事，会跟着你走，成为你最大的底气。

那怎么把天赋挖掘出来？任何一门能持续带来收入的生意，背后都有一条完整的链条：内容、推广、获客、转化和交付。你该问自己：链条的哪一环我最能发光？我贡献的是什么？它最终如何变成钱？我能凭什么比别人做得好？看清这些后，就把火力集中在那一环。不会的知识，花钱请教已经拿到结果的人，找他们带路。

我有一位学员，曾经是基金操盘手。

![](img/8d0a0d8f6e8e4263e204109fd99803ca.png)

他很聪明，但过去总是拿自己的短处，去跟一群学历傲人、脑力过硬的同事硬碰，结果天天精神内耗。转做保险顾问之后，他开始善用自己的关系天赋：特别会洞察每个人的特点，又肯承担责任，经常复盘自己。他把老客户维护得非常用心，针对不同客户搭配不同的专业建议和情感照料，慢慢成为大家愿意信赖的朋友，也在若干群体中有了名气。他从不做公域引流，但因为善于打交道，遇到的客户都很精准，合作推进很顺畅，客户还会主动转介新客。转型后的头一年，他就赚到50万，强度不高，自己还觉得特别自在。

再说说我自己。我的天赋偏“战略+执行”：做内容、搭体系、学新东西、看本质，都很拿手；但让我去跑市场、不停和人聊天，就很受罪。所以我的定位是导师型角色。可事业要往前走，传播、获客、交易一样躲不开。我靠两招化解：其一是寻找和我互补的伙伴，其二是把必需的本领快速学会，再教给团队，或者花钱外包。

我的好友兼合伙人，是个天生的活跃分子，特别擅长当众讲话和带动气氛。她帮我管理群聊，在各种场合为我站台、推单。我还有一位负责助教团队的伙伴，也是“感召+谋略”兼备的人。负责后勤的管家，则是一位极擅安抚人心的温暖型人才。她们补足了我身上缺乏的感性和号召力。

这里要分清“普通技能”和“核心本领”。像做海报、剪视频、维护群聊这类普通技能，不顺手就外包；没钱的时候先自己做，等日后有预算再交给别人。但像咨询、流量、转化、内容创作这些核心本领，就算不感兴趣，也要逼自己学会，至少做到及格。学会之后，我还能把方法教给团队——教别人这件事，恰好是我的强项。如今我们团队中最善于成交的伙伴，有一两位比我还厉害，因为他们天生就吃这碗饭。

用天赋赚钱，考验的其实是抉择和舍弃的智慧。不要四处撒网，把大部分精力压在你最强的那个点上，打出几个漂亮的案例。当你找准自己的位置，输出了不可或缺的价值，换来了应有的结果，成了团队中少不了的人，再往后就只是“简单的事重复做”而已。

我自己就是这样。我打算把目前的主打产品持续服务很多人，不断打磨迭代，陪伴团队成长，而非一年到头忙着开发新东西。看清自己，比什么技能都重要。这便是我所说的赚钱功课的起点。

另外，很多人有“自己造产品”的情节，特别是做课程或顾问服务的朋友。可这个时代并不缺优质产品，缺的是能把好东西卖出去的人。学会卖出价值，才是普通人翻身的最好入口，也是走到哪里都吃香的本事。

不论你是写文章、录制短片、做图文、提供顾问服务、做直播、带群、讲课还是发动态，这些环节里总有一些你讨厌的部分。但如果你做的一切无法促成交易，那就很难变成收入。

不同天赋类型的人，在促成交易时的状态和弱点完全不同。

思考型天赋靠前的人，通常不爱主动推销，因为他们光是想问题、学知识，就已经很满足了。不过，当他们真正认可某样东西，又有足够的专业功底，就能给出非常漂亮的解决方案和解释，让客户心服口服。我见过一位备孕顾问的自我描述，她不仅讲服务内容，还把工作升华成“迎接新生命，让家庭更圆满”。能有这样独特的视角，正是思考型人才最打动客户的力量。所以他们挑选项目时，要挑那些有深度的复杂方案，而不是一般的生活用品或中介角色。

有带动力天赋的人，天生适合影响人，也容易成为传统意义上的销售明星。他们适合做信息中心、流量节点，一个人面对一群人是他们最舒服的舞台，比如演讲、直播、带群。但一旦发挥过头，就会显得咄咄逼人，让人反感，一句话都可能把人得罪光，更别说建立信任了。他们还有一个难题：目标很远大，耐心却很短促；想一下子成功，受挫后又容易陷入自我怀疑。哪怕是天生会说，也要先花时间积累实在的能力，不然很难让人心甘情愿买单。这一类型里，柔和的人要防讨好，强硬的人要防压人。

擅长关系的人，成交常常是无声无息的。他们不像“自来熟”那样容易破冰，却足够细致，能照顾到客户情绪，甚至经营出长期友谊。说到底，人都有感情，做决定时尤其如此。这类人若能提供情绪支持，老客复购和转介新客会特别猛。但他们的毛病是自贬：本来有八分能力，偏说自己只有五分；特别在乎别人怎么看，想说的话憋在心里；也不好意思展示自己的价值，结果白白错过很多机会。

执行天赋强的人，靠“靠谱”赢得订单。一句“交给你我放心”，价值千钧。别觉得认真负责太平凡，实际上“凡事都给出回音”的人，走到哪里都受欢迎。比如目标意识强的人会持续跟进；爱解决难题的人会设身处地帮客户排忧；讲究秩序的人能把使用步骤整理成清单。唯一要注意的是，这类人容易像一头任劳任怨的耕牛一样默默无闻，最好主动把自己的做事过程记录下来，晒出来，这也是建立口碑的好办法。

以上只是粗略的分法。具体到每个人，还要看你的天赋组合、所处阶段、行业阅历和资源情况，没有统一答案，只能靠不断体悟、摸索和积累。

世界上没有两片一样的叶子，各人有各人的花期，不必相同。但只要你愿意下功夫，终会迎来你的精彩。那套测评工具，就像一份给你专属的生命操作手册，帮你找到走向全新天地的那扇门。

从创造收入的角度看，你要懂得用天赋找位置，拼命输出价值，形成别人拿不走的竞争力。而在实操层面，最值得修炼的就是“促成交易”这项能力。希望你找到适合自己的方式，去连接他人、传递观点、卖出产品，体面地赚钱，也保持内心安宁。

祝各位天赋绽放，财路越走越宽。
