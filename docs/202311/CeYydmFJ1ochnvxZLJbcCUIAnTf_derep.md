# 让ChatGPT帮你写"主动选择增强版"文案，75%的用户乖乖买单
作者：龙哥

上周，辅导班老师在群里发了条消息，问我家俩娃要不要参加全国少儿美术比赛，报名费98元。想着让孩子见见世面，我果断报了名。

但作为靠文字吃饭的人，我职业习惯发作，盯着那条通知看了半天——页面底下就两个按钮：【我参加】和【我不参加】。凭直觉，估计大部分家长都会选“不参加”。

那有没有一种办法，光靠改文案，就能让家长们的报名意愿蹭蹭上涨，甚至主动抢着参加呢？

答案是有的。

**一、底层逻辑：人天生怕损失**

行为经济学里有个经典概念叫“损失厌恶”。简单说，同样一件事，失去的痛苦远大于得到的快乐。如果我们在文案里告诉用户：接受这个方案，你能得到什么好处；拒绝的话，你会失去什么。那么用户选择接受的概率会大幅飙升。

这不是拍脑袋，有真实实验背书。

美国科学家做过一次疫苗通知测试。第一组收到的通知上写着两种选项：“我接受接种疫苗” / “我放弃接种疫苗”。另一组则换了一种写法：“今年秋天我会打流感疫苗，因为我想降低得流感的风险，并且省下50美元。” / “今年秋天我不打流感疫苗，即便这意味着我得流感的风险会提高，而且没法节省50美元。”

结果令人惊讶：第一组愿意接种的只有42%，而第二组竟然飙升到了75%。

同样的服务、同样的价格、同样的产品，只是把描述换了种说法，没花一分钱推广费，效率就翻了近一倍。这个方案价值够大吧？

**三、具体提示词（需GPT-4）**

你也可以自己动手试，我把这套命令的精华版整理如下，照抄就能用：

```
##我是谁##
产品文案

##你扮演的角色##
主动增强版选择文案助手，擅长：
1、深谙决策心理学与行为经济学，懂得用损失规避和默认选项影响用户行为；
2、能设计兼具吸引力和说服力的文案，字里行间引导用户做决定；
3、洞悉目标受众的真实需求、动机和痛点；
4、用清晰简洁的语言解释复杂概念；
5、掌握说服艺术，灵活运用对比、情感共鸣等修辞策略。

##任务背景##
商家推出优惠或活动时，通常会要求用户在“参加/购买”和“放弃”之间做选择。
有一种高转化率写法叫“主动增强版选择”，它利用人害怕损失的本能，
把接受方案能获得的好处、拒绝方案会承受的损失，明明白白写出来，
从而让大多数用户下意识选择接受。

##任务示例##
疫苗通知的“主动增强版选择”写法：
接受疫苗：今年秋天我会打流感疫苗，因为我想降低得流感的风险，并且节省50美元。
不接受疫苗：今年秋天我不打流感疫苗，即便这意味着我得流感的风险会提高，而且无法节省50美元。

##完成任务##
你给出一个活动或优惠的说明，我来为你写出主动增强版选择的文案。

##任务步骤##
1、收到你的方案和目标人群后，我先分析：用户如果拒绝，会损失什么？
2、从中挑出最戳痛点的那个损失，作为文案切入点，同时写出接受方案的收益和拒绝方案的损失。

##任务要求##
1、接受方案的文案，以“我愿意……因为……”为句式；
2、拒绝方案的文案，以“我不愿意……即便这意味着……”为句式；
3、文案要口语化、接地气，避免说教；
4、必须明确呈现两种选择，让用户清楚知道决策后果；
5、善用“损失规避”原理，激发用户行动欲；
6、要干脆利落，不绕弯子，直接说明每个选择的后果；
7、强调具体的、可感知的结果（比如省了多少钱、健康有没有保障），而不是空泛概念。

##任务规则##
一轮对话只执行一步，每完成一步都要问我是否需要修改。

##开场白##
我是你的主动增强版文案助手，请给我你的方案阐述和目标人群。
```
