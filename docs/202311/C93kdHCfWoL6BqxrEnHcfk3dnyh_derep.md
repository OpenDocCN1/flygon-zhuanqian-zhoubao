# 别再花9.9去支付宝买营业执照了，注销要你2200+

很多人都知道支付宝上能花9.9搞定一家营业执照，还包邮，感觉白捡便宜，省事又省钱。

但便宜的背后藏着两笔大账：注销光是一笔就得2200+，每年找人代办税务又要900+。不交钱，自己搞又容易被代理盯上，一个举报下去麻烦全是你的。

所以与其踩坑，不如自己动手白嫖。现在浙江这条路我已经全跑通了，完全0成本，流程顺的话半小时就能搞定，分享出来给还在观望的兄弟们。

先说地址问题。办执照必须填经营场所，可又没必要真去租实体店。一个网店地址就能用，淘宝、拼多多、微店的店铺地址都行，方便又合规。地址这块的操作思路，可以去参考@广深莞注册公司@山歌在圈内的详细拆解：https://articles.zsxq.com/id_85oj2zwgwlpe.html

重点来了：浙江的执照申请，PC网页端已经玩不转了，因为没有电商选项，系统强制要求填实体租赁门面。只有浙里办APP能走通。

下载【浙里办】，这是杭州官方的政务服务APP，日常办事基本都在这一个App里搞定。注册登录后就能开始申请。

APP界面长这样
![](img/9803a18fe8bbe6390d8f0252750a8d29.png)

具体每一步怎么点，我录了视频跟着做就行，不用死记硬背。

App偶尔会卡顿闪退也正常，别纠结，直接退回上一页重来即可。
![](img/0a1eea69fb3fb41e55e100f7331621c2.png)

提交完材料后，大概等半天左右会收到短信通知是否通过。没过的话就按提示改一下内容，实在改不动的地方就直接重新提交，新流程往往更快。至于客服电话，基本是打不通的，我试过了。
通过后就进入电子签名环节，同样在APP内完成。搜索栏搜【个体户】，选对区域后进入页面。
![](img/4fd31a02bead5a6991e0bf23ca494f11.png)

点进去完成电子签章即可。

签完章继续等待系统审核，差不多也是大半天左右，会自动进入【企业开办一件事】的流程。

这里有个容易卡住的小坑：显示已通过了，但营业执照就是查不到。
![](img/40bd0e4ce5c7973a6f5525de9bd2325b.png)

这时候别在浙里办里死等，去🛰️小程序搜索【电子营业执照】就能立刻拿到。
![](img/7267f5a1d04e43c8b45c07a946fba782.png)

点进去下载电子执照文件。
![](img/861ab3f1f1d725cc61ebad5509f4e2c6.png)

最后一步就是打印出来，完整的PDF执照就到手了。需要查询验证的话可以用这个官网：
https://zzapp.gsxt.gov.cn/
![](img/e446f0ed61ec6c2794b7a44eab58cf45.png)

按着上面的顺序一路走下来，执照就属于你了，恭喜。
