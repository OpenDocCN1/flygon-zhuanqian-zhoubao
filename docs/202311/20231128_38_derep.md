# 第一篇笔记万赞，首月赚5000+：我的小红书职场IP冷启动复盘

大家好，我是小猪哥。

211院校本硕连读，大一那年就开始折腾创业和套利；后来上过《电子竞技》杂志封面，26岁全款提了奔驰。手里握过6个不同行业运营岗的offer——央企、垄断国企、五百强民企、互联网大厂都集齐了。在小红书上做职场IP，付费咨询次数已经突破200。

第一次做自媒体IP，我没有想太多，直接选了最熟悉的职场赛道。为什么？因为现在就业环境大家也都懂，总会有人拼了命想走到你现在的位置。所以职场内容天然不缺受众，流量来得快，变现也顺。

第一篇用来做资料引流的笔记意外爆了，点赞上万；随后第一个月就赚到5000多。在龙哥盟的圈子里，这个成绩并不耀眼，但对我来说已经很有意义——毕竟我是工科出身，这是第一次正经做内容转型。

能做到这个程度，真的要多谢花爷和谢无敌老师。我在他们的指导下连续做出几篇万赞爆款，甚至一度冲动到想辞职去花爷公司上班。

这篇内容，其实就是一个自媒体小白做职场IP从0到1的冷启动复盘。我把它完整写出来了，希望给大家一点信心：新人能跑通的路，往往比大佬的宏大方法论更容易模仿。
