# 创业46条之32：我的十万美元社交实验

昨天聊到的那段创业经历，还有一层前情没来得及展开。

2011年，我在广告行业已经泡了八年，做到蓝标策划总监。表面看还行，可这行肉眼可见地在走下坡路：加班加到怀疑人生，挣的却是一般般的数。我实在忍不了，决定离开。那阵子，我35岁，太太正怀着孩子，父亲车祸后失忆，母亲身体也不好。整个人活成一个“苦”字。说想改变是真的，可要说有什么清晰规划，那是骗人的。

后来刷微博，看到一条招聘启事。一个创业团队在找市场合伙人，创始人叫马源。我跟他聊了聊，居然就决定去试试。那几年互联网创业热浪滔天，我这个做传统广告的，隔着岸看那边热热闹闹，总觉得自己像局外人。正好有这么个机会，不如跳进去看看。马源当时在上海，我在北京，他说半年后公司搬到北京，我就先飞了过去。

有意思的是，前脚刚跟马源谈完，后脚暴风影音的冯鑫也面试了我。冯鑫很看好我，恨不得当场敲定，还说会给我股份。相对而言，暴风显然更靠谱。可我已经答应了马源，只好守着一个“已答应”的承诺南下。

我们做的产品，抄袭的是美国社交问答网站Formspring。这家美国公司一年做到2800万用户，够吓人的。马源是哥大研究生，被扎克伯格的故事激得热血上头，直接休学回国复制这个模式。技术合伙人叫李鸿，之前待过微软。马源和李鸿都是上交毕业，我是西交，整个团队算是“交大系”。办公室就落在上交对面，我不太会来事儿，马源却是个社交达人，认识不少上交的创业者。其中一个大学生项目，专在学校附近送外卖，老板还跟马源打过德州扑克。那项目，后来成了“饿了么”。

有一次我们去上交新闻学院找魏武挥老师请教。他是博客大巴的联合创始人，公司卖掉后进学校当了老师。魏老师给我们泼了盆冷水：做社交，至少得融到一亿人民币，你们那十万美元，根本不够玩。我们没听进去。倒不是觉得他说错，而是我们压根没有商业经验、公司经验，全凭一腔孤勇和梦想。后来撞了南墙才明白，魏老师是对的。如今我也常这样劝年轻创业者，他们照样不听，跟我当年一模一样。

2012年的冬天，公司从上海搬到北京。我在北京也是租房，中央音乐学院南边的槐柏树街，一个老破小区。回去那天，我妈煮了大闸蟹，特意让马源和他女朋友带上几只。送他们走时，路灯下霾锁北京，像灾难片现场。

我们最早租的办公室在惠新西街附近。李鸿两口子、马源一对、另一个程序员夫妻俩，全从上海搬了过来。唯独仇鲁没来，因为女朋友不愿意。仇鲁后来进了公关圈，自己也开了一家公关公司。

那年3月，我孩子出生。可公司还卡在开发阶段，帮不上太多忙——说实话，当时我也不太懂互联网。

后来，我们终于承认这个模式走不通，干脆关掉网站。从立项到关闭，差不多两年。这时候，徐老师投的钱已经烧完。好在我们又融到了一笔，投资方说好600万，第一笔300万到账，可网站已经撑不下去了。

几个合伙人凑一块儿，花了一两个月琢磨接下来怎么办。这次理性了不少。当时我恰好读过《精益创业》，知道了什么叫MVP。我们列了一堆现实痛点，比如公司员工吃饭难，也动过做外卖的念头，但马上意识到自己没那个实力。

后来，从美国一家叫Skillshare的公司身上找到思路：找有知识、有经验的人来平台上开课，学员付费，平台抽佣。于是，我们做了“第九课堂”。资金紧巴巴，logo是我厚着脸皮请前奥美的同事帮着设计，给了个友情价。这算是我第一次从立项阶段就参与的创业项目。第九课堂后来确实做出了一些动静……
