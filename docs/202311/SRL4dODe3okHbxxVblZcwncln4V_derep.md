# 视频号实名和换绑的详细解读以及橱窗号突破5个限制的方法
作者：龙哥

做视频号带货的朋友，基本都会碰上实名认证这件事。很多新手一进后台就懵了：怎么填个名字和身份证，前前后后要折腾三四回？还有的人用的🛰️号是亲戚、朋友的实名，那视频号这边到底该写谁？后面赚了钱能不能顺利提出来？更有人听说视频号能买卖，是不是得连🛰️号一起收过来才安全？🛰️支付实名又怎么处理？

还有一个常见困惑：一张身份证最多能实名5个🛰️，那是不是意味着，哪怕做再多视频号，能带货的橱窗号也就5个封顶了？

我最早接触这些问题时，也找不到一篇系统讲清楚的教程。后来自己摸爬滚打，把遇到的情况整理了出来。下面这些内容基本覆盖了大多数人的疑问，个别冷门情况也欢迎补充，我后续会继续更新。

## 实名、提现，先分清两件事

想靠视频号赚钱，得先搞清楚“橱窗”和“视频带货”是两个概念。视频带货（就是视频里挂车）有另外的门槛，这里先不展开。刚开始一般先开橱窗，再引导用户去主页的“商品橱窗”下单。

### 第一步：商家资质认证

进入视频号带货中心后，要先交橱窗保证金。交钱之前必须完成商家资质认证：

![](img/aea5355aacfc36f69980d0af0405141e.png)
![](img/4244a92549cdc8b3c6ab19f1944e493e.png)
![](img/96e62b8ef85ebc85389a117b4df8f9d6.png)
![](img/3c5b03d7cfc455ceec55edd2dbbfb56a.png)

这里填的实名信息没有硬性限制，只要是你能掌控的信息就行。认证完，充值100元保证金。

注意一个关键点：认证时填的主体，将来退保证金时，钱只能退到这个个人或个体户法人名下。所以这就是第一次要填身份证的地方。

### 第二步：验证🛰️支付实名

保证金搞定后，就可以去选品中心了。第一次选好商品点“加橱窗”时，系统会提示要验证🛰️支付实名。这个信息必须和🛰️号本身的实名完全一致：🛰️号是A的实名，这里就填A，不能换人。这是第二次需要填身份证的地方。

### 第三步：开通联盟账户

在带货中心点“佣金”，第一次会引导开通联盟账户。

#### 情况一：🛰️号和视频号都是自己用

直接选“个人”，填和🛰️实名一致的信息，然后等审核。

审核通过后，再点“佣金”就会提示签署协议，签完就成功了。这是第三次填身份证的地方。

如果只想做一个号，到这一步就已经全通了。

#### 情况二：🛰️实名是别人，但想提现到自己卡里

比如🛰️号是家人或朋友实名的，但赚的钱想提到自己账户；或者公司签了达人，想先用他的🛰️号开视频号，再提现到自己卡上，回头另外给达人结算——这些都能实现。

关键在于第一步商家资质认证：如果一开始就打算提现到B的账户，那认证时就填B的实名信息，这样保证金将来也好退。

概括一下：🛰️号实名是A，但提现目标是B。这时开通联盟账户，要选“个体工商户”，并且你必须是这个个体户的法人B。

## 视频号换绑，其实比想象中简单

有人问：视频号交易是不是要把对方🛰️号一起买过来？那🛰️实名怎么办？提现又怎么办？

还有人问：视频号想注销，但等太久，我还想用同一个🛰️号重新注册视频号，有没有别的路？

要理解换绑，先记住一个点：视频号和🛰️是相对独立的。视频号可以迁到另一个🛰️号上，前提是接收方还没有注册过视频号。

举个例子：你想继续用🛰️A做视频号，但A上原来的视频号a被限流了，注销又太慢。那就先把视频号a换绑到🛰️B，然后🛰️A就能重新注册新视频号了。

操作前要注意：先把视频号a的带货佣金结清。换绑过程中需要输入🛰️A的密码；如果忘了密码，找回后还要等14天才能继续。

接收方🛰️B必须没有视频号。先用B关注视频号a，然后再发起换绑。

换绑时，B那边会收到通知，需要点击接受邀请。

![](img/cb3c39605b1843c548a2714d1be50798.png)
![](img/37aa643e7b94c56a0a150ce655941f75.png)

整个过程很快就能完成。换绑成功后，B上就能看到视频号a了。

这个思路可以举一反三：不只限流注销，只要你想调整视频号和🛰️的对应关系，都能用。买卖视频号自然也没问题。

换绑之后，商家资质认证不会变。100元橱窗保证金也还在，提现时仍打回之前认证的主体账户。联盟账户信息也不变，还是原来那一套。

## 如何突破5个橱窗号限制？

正常情况下，视频号换绑到的🛰️号，往往都是实名的。这样一来，一张身份证最多只能支撑5个视频号的实名认证。那能不能再多？

假如一张身份证已经实名满了5个🛰️，现在想腾出名额给新的🛰️号，常规操作是：在🛰️里点“钱包—支付设置—注销🛰️支付”，然后再到新🛰️上重新实名。这样算下来，有名额的🛰️还是5个，没变多。

如果🛰️A注销了实名，会变成下面这种状态：

![](img/4fbd509eda51508823b38ffdd4a48638.png)

这种未实名状态下，换绑视频号过去，是无法正常上架橱窗的——在“验证🛰️支付实名”那一步就会卡住。

![](img/4edf0ea6f3ed6e7a0752b6739c9eedfd.png)

那怎么破？先了解一个概念：🛰️顶实名，也叫冻结🛰️支付状态。

![](img/9299faeee24acd7241697cd8a3886b29.png)

看上面这个图，钱包里还有钱，但转账时会提示“需要实名认证”。实际上这个🛰️的实名已经被顶掉了，属于半实名状态。

有意思的是，这种半实名状态不但能正常橱窗带货，还能正常提现到联盟账户。

![](img/f60a9bf648f7be1b25b62812f596689e.png)
![](img/5a9829b1fcd7a9873cca032b596ef97d.png)
![](img/7f65212a8f2eef621c2d5d3a624655dd.png)

那这种“顶实名/冻结🛰️支付”状态怎么实现？

先在已经完成实名的🛰️号（比如常用的大号）上操作：

钱包 → 帮助中心 → 实名问题 → 查询名下账户 → 前往查询 → 验证账户信息 → 看到名下绑卡账户 → 清除即可。

![](img/cd09a8c836507e67fc6a856673a404e9.png)
![](img/c451225d92aaec8b6fa539ed3f2fb6bb.png)
![](img/04b441bdd6ea1a3eadd84a4d2afe158b.png)
![](img/7259124a9693b4e9d211e11dbf434cde.png)
![](img/3fe4887f8f0a51560b4d3d0be742b736.png)

被清除的那个🛰️A，就会变成顶实名状态。注意：在冻结🛰️支付之前，最好先在A钱包里留几块钱，防止系统直接把🛰️支付注销掉。

如果🛰️A上已经有视频号，试试橱窗上架和提现，会发现一切正常，没受任何影响。如果A还没有视频号，那把别的视频号换绑过来，也能正常带货、正常提现。

理论上，🛰️B、C、D、E的实名信息也可以照这个办法清除，腾出来的实名名额又能绑定到新的🛰️号F、G、H、I上，这样就不再受5个橱窗号的限制了。

不过也有朋友反馈：操作太频繁可能触发风控，后续实名认证视频号时会被限制。所以建议先等实名认证满5个视频号后，再开始操作，而且动作要适可而止，别太猛。
