# 从抖音亏钱到视频号实现五十万营收：一位赚钱新人的复盘笔记



各位赚钱的伙伴们好，我是今年才正式加入社群的后来者。去年十月起就把全部精力放在视频号上，截至现在累计回款已过五十万，其中短视频内容变现约二十五万，小店运营约二十五万。比起站内的头部玩家不值一提，但对我个人而言是一次彻底的路线重塑。今天把从抖音踩坑到视频号起势的心路拿出来梳理，也算给自己做个阶段性总结，这是第一次发帖，欢迎大家指正。

先交代一下个人履历。我原本做技术出身，程序员做了两年后开始自立门户创业，项目起起伏伏，最后还背了点负债。转折点在二零二零年，有朋友拉我一起做比特币交易平台，我主要负责团队管理和项目推进，那一年不仅把债务清零，还换了车，账户里也积攒了一些启动资金。妻子当时怀孕在家休养小半年。那段靠快钱积累的经历，后来成了我进入抖音时翻车的重要诱因。习惯了坐收分成，又长期处于管理岗不亲手操盘，执行力和把一个项目跑通的能力退化了，动不动就想花钱请人解决。

必须先讲讲我在抖音的狼狈历程。做视频号之前，我一直死磕抖音带货直播。二零二一年下半年开始试水，本来也看过矩阵短视频赚钱的案例，但我执迷于来钱快的直播，还是零粉丝开播的形式。事后看来，当时能稳定赚钱的几乎都是先做短视频做起号的，上来就直播的多半在亏。起初我以为招几个人、配几个主播、备点货投点钱就能跑，前前后后换了好几拨合作方，折腾数月毫无起色。后来又花一万块去武汉东西湖一家直播培训机构学了一个月，纯属浪费。那里的教学现在看很多都是错的，指导方向就不对。那期同学里有做淘宝的、有汉正街卖衣服的、还有自建厂的，最后没一个做起来的。这件事让我对付费课程极度谨慎，方向带偏的代价比花钱更大。从那以后我不再报课，全部靠自己试错。

折腾到二十一年的十一月，账号仍无起色，我让妻子上场播，我负责后台。选品完全不懂，自己跑金华跑了半个月厂家，最后定在一个当时很热的车载品类——电动洗车机。首播当天就成交了十几单，单笔毛利一百多，觉得开张了。大概播了一个月，日净利能维持在两千到三千，正要起势时，提前囤的一千套配件厂家没发货，正好金华区因疫情封控，一个月无法出货。本来可以换品过渡或协调供应链，但我当时被快钱思维惯坏，觉得随便换个东西也能卖，厂家不靠谱就不做了，年底直接停播回老家过年。附上当时的一张直播抓图。

二十二年上半年我彻底放弃自囤货，直接切抖音精选联盟，后端不管，只玩清仓、无人带货和废号操作。钱是快，但账号实名被拉黑到现在都无法在抖音开店。号死一个开一个，单场观 rarely 破两百三，几百万播放的场面一次没碰到。算下来基本没赚到钱，还极不稳定，一个号运气好能赚几千上万，不行就换。附几张当时的图留个纪念。别被数据迷惑，能持续稳定造血的模式才有意义。

那个时期割韭菜的人非常多。号刚有点流量，就有人挂着收徒头像冲进直播间抢榜一引流，我把他踢了，他反过来举报我无人直播。那个阶段到处是无人陪跑三万、包上号几千的广告，真正靠无人稳定盈利的其实是卖课。我的号都是自己养的，没拿到大结果，也不想做割韭菜的人。想明白后我就撤了，开始休整，迷茫了一段时间。

真正点醒我的是二十二年七月。同城一个做玩具的兄弟，那个月成交额干到二百多万。他和我是同期入局直播的，也是夫妻档，我起步时的数据还比他好看，但他一直坚持到爆发，而我三天打鱼两天晒网。深夜一起喝酒看着他意气风发，我回去后开始自我检讨。让妻子先回老家带孩子，我花了差不多三个月自我剖析。才意识到自己更像投机者，对抖音规则虽熟却没沉淀，总追平台脚本，永远慢半拍。一整年的失败让我慢慢摸到一点经商的感觉。

国庆回老家后我跟自己和解了一次，觉得抖音基本没戏，手上既没有沉淀账号也没有团队。为了解外面的情况，我甚至假装求职跑了一天抖音运营公司面试。那天感觉大家都在挣扎。意外收获是下午面了一个体量很大的公司老板，他很认可我的能力，想让我负责他们公司的视频号，他说了一句让我印象深刻的话：在抖音上挣扎的公司，今年在视频号都拿到了不错的结果。当时觉得有大佬背书，这个赛道值得试一试。

回来后我就开始研究视频号。以前做过小程序和👸号，对腾讯系生态有一定认知，我认定这是一个可以重新开始的机会，抖音已无积累，不如在视频号从零起盘。

确定方向后，我和妻子各挑一个单品各开一个号试水，很幸运都爆了。那时搬运审查还不严，正是红利窗口，蓝海素材很多。我们选品感觉还行。我选的是家电类，一单毛利一百多，毛利率约六成。号在一个星期内纯自然分发就连出几个几百万播放的视频，一条涨粉几万。视频号私信过千会变成三个红点，附当时截图。

![](img/175b56ea05283c8dc87d992756a5d3d2.png)

我的商品不在官方的选品中心，就在主页留了电话和🛰️。几天内电话被打爆，白天黑夜不断，几通电话同时进来占线根本接不完。接通后加🛰️转账发货，🛰️的优势很明显，视频号用户习惯🛰️支付，防备心没那么强，很多直接转账确认收货。怀疑的会打视频电话，我妻子接，耐心讲解，成交率很高。附上几张当时的截图。

当时不少用户还没习惯在视频号下单，要求货到付款的很多。我们就先和京东签了货到付款账户，先登记再从厂家调货发货，最后拒签率其实很低。那段时间电话打到卡被运营商误判为诈骗被停机两次去营业厅解封，两个🛰️也多次被提示异常限收款。我们基本都是让客户主动加我们，加了三千多人。那一个星期就赚了五万多，后续断断续续小爆发，到年底这个品累计变现二十万左右。妻子的车品号也爆了，大概变现五万左右。那段时间我变得务实很多，供应链对接、客户消息耐心回复、私域承接都认真起来，不再浮躁，更像一个电商从业者。

中间也有遗憾。爆了后本想开直播，但对视频号直播规则不熟，怕违规封号不敢试。选品中心没有我们这个品，对入池和小商店也不熟，就做了一个微店小程序挂主页承接，等做起来时流量已在衰退。截图如下。

溢出的流量我后来放到了拼多多同款店铺去承接，但客户挑剔，且拼多多仅退款机制很坑，用了几个月基本都在赔。后来干脆注销了。矩阵号没及时做，后面再开就频繁违规，也确实精力不足，从接单到发货到售后全是两个人扛。疫情放开后我们俩都阳了，还在透支体力做客服，状态很差。其实当时完全可以做得更好。

今年三月初我搬到武汉，去年几个老号流量已大不如前。来了后玩了半个月，思考接下来要做什么。此时我已经知道龙哥盟社群，是去年年底在直播间听到别人提及的。那时买了盗版精华帖翻看，专门看视频号相关的。真正让我决定付费的是三月时鱼丸发来一张体验卡，可以浏览全部帖子。

![](img/d9f38ff5e8946601fcc19867709c15ff.png)

我翻到二十二年底，有个ID叫summer的大佬分享的视频号小店玩法，给了我很大启发。这是当时能找到的唯一系统讲视频号小店的干货。研究后我觉得非常适合我，有选品能力和供应链对接经验，上手不难。原文现在找不到了，在这里特别感谢summer大佬无意间的帮助。也是因为这篇，我决定付费加入赚钱，在四月十八号预定了会员，当时价格很划算，第一次加入。

预定后要等到四月十八才能进群，三月中下旬我就已经开始动手做视频号小店了。当时判断summer的帖子发在去年，小店当时正处蛮荒期，现在矩阵店群模式可能不适用。我也不适合上来就铺矩阵，结合自己视频号前端的经验，核心结论是视频号小店能做，成败看执行。因为精力有限，一开始只做一个店铺测试。我在抖音做过一段时间的选品，知道什么品什么价什么佣金达人才愿意带，所以决定手动精细化上品，把每个品当爆品做，先跑通模式。上品全凭感觉，不参考同行，抖音快手视频号拼多多淘宝加各种工具疯狂找品，定价佣金随心定，相信有同样带货思路的达人才会认同。

三月下旬开通优选后先做百货店，每天上三十到五十个，到两三百个时开始陆续出单，但很零散，收入不稳。其实那时也不知道结果，只觉得方向对。

那段时间压力很大，妻子也不太理解，为什么去年短视频前端能赚钱还要转做后端。我自己的判断是先把后端稳定了再做前端，整个模式更稳，但意味着要暂时放弃前端带货，时间精力只能二选一，失误就等于上半年白费。雷军造车那句话“押上人生全部声誉”当时对我触动很大，体现了决心和自信。所以我用三个月时间押注视频号小店，给自己定死三个月目标，不行就撤回前端。每天晚上跑步，黑暗中只有路灯照着，像现在的处境一样未知，但我一直在给自己打气。

上到五百个商品时偶尔有品开始小爆，四月底五月初两个店铺同时起量，当时随手录了个视频。

店铺比预期爆发更快，本来想多开几个店，但发货售后占用时间太多，五月上新不给力，六七月销量有小幅下滑。目前我们三家店，总成交额一百二十万左右，利润二十五万加，其中能稳定出单的只有两家。第三家店是我招的人在做，精细选品方法一样，但一直没起来，应该是选品感知力没达标。

目前我们没有对接任何达人，全靠选品撑着。一定程度上，抖音时期的选品能力在小店派上用场了。达人流动性大，对接成本高，爆单达人偶尔联系一下，留不住。我们计划下半年把重点放回短视频和直播，先把前端能力沉淀下来，并组建团队。视频号直播测试过一场，利润好时也能有一两千。现在前端后端都跑通了，对电商的认知打开了很多，不用再把自己框在一个模型里。未来主战场还在视频号，也许有一天重回抖音，但前提是我已经在视频号拿到了结果和认知，抖音的失败始终是我心里的一个结。

说实话，和赚钱圈里那些真正的大佬一比，我还差得很远。每次刷到他们的分享，看到那些让人拍案叫绝的操作手法和商业模式，心里只有佩服，也忍不住觉得自己怎么这么笨，需要补的课还有太多太多。

回想过去做抖音那阵子，整个人其实是飘着的，心浮气躁，很多事儿都没想清楚就闷头冲进去，最后栽跟头也是意料之中。要是当时能踏实一点，把基本功打牢，抖音这条路未必拿不到大结果，但世上没有后悔药，最好的那波风口确实已经过去了。后来决定做视频号，心态完全换了一种——更像是在跟自己较劲，逼着自己一点点沉下去，找回思考力和执行力，每个细节都亲手抠到位，哪怕整个状态看起来有点闷，也在所不惜。

这篇帖子，与其说是分享，不如说是对自己一个阶段的总结和回望。也算是借着这个机会，试着把自己推出去，让更多人认识我，多结识一些同样在做视频号的朋友，链接到更多同频的人。我现在定居武汉，特别希望认识本地的圈友。我目前主要擅长抖音短视频和直播，视频号这边的短视频、直播和小店也一直在做。欢迎大家来找我交流，我的🛰️号是：hbutacm，加我的时候记得备注“赚钱”。

最后真心感谢龙哥盟这个平台，我真的很喜欢这里的氛围。也特别谢谢鱼丸，耐心教我发帖和飞书这些操作，我完全是第一次弄，全靠她指点。能让这么多创业者和前辈看到我的分享，真的非常荣幸，以后还请多多指教。
