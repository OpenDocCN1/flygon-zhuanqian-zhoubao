# 当终端终于追上 IDE 的智能，Warp 就是答案

大家好，我是龙哥，在一家世界 500 强外企写代码。曾立下flag要每两天更一篇，现在退而求其次，改成每周两更，生怕哪天又滑落成每月两更。还好自带逗比人设，不然老改承诺脸都丢没了😭。希望这篇干货能给你一点点效率提升，也带来一点点乐子。

先说在前头，这篇文章是写给写代码的人看的。如果你对开发有一点点好奇，往下看也能涨点认知，开发效率直接拉满。如果你纯粹为放松来的，直接去刷抖音刷头条更快乐，没必要强求。

前段时间刷到一位大佬的直播现场，对方在终端里操作行云流水，指哪打哪，那种流畅感正是我长期在追的终端体验。定睛一看工具栏上写着 warp。好奇心被点燃，当场去搜了一下，打开了一个新世界。原来在 zsh + ohmyzsh 之外，还有一款全面集成 AI 的下一代终端：Warp。

夸它一句 21 世纪最硬核的终端工具可能又要被说标题党了。之前有读者提醒过我少用最、第一、史上这种词，我也收敛了不少。但这一次我愿意再破例一次，因为我真心不觉得这是标题党。

接下来聊聊我眼中的这款工具：**Warp**

官网直达：[`app.warp.dev/`](https://app.warp.dev)

![](img/0223f8c9924162109f1e8ad9866c4e12.png)

官网自己就定位为 21 世纪的终端。

做开发的同学一定对 IDE  Repositories 不陌生，简单说就是写代码的软件和跑代码的软件。现在 IDE 早就百花齐放，JetBrains 全家桶、VS Code 这些随手一说，智能补全到几乎不用手写，口气描述一下就能蹦出一个功能。

可尴尬的是，终端这边近四十年几乎原地踏步，vim 时代的影子还在，zsh + ohmyzsh 也只是颜值和插件的堆叠，智能化程度和 IDE 完全不在一个维度。这点被一位谷歌的前工程师看在眼里，他直接离职创业，决心打造一款真正属于这个时代的终端工具。做出来就是 Warp。如果你用过，你会承认他是做到了，值得鼓掌👏🏻
