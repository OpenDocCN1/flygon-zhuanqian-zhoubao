# ('说一说我当年战略上的无知', (2, 14))

聊聊我当年在战略上的无知

这是“创办一家小公司并活下来”系列的第四篇。今天想说的，是我年轻时对战略有多迟钝。

第九课堂最早推出的课程，是纪元老师的《如何做到早起早睡》。纪元本人做时间管理，这门课后来也成了平台存续最久的一堂课。第一次开课就在建外SOHO的办公室里，到场大概十个人，报名费我记得应该是99元，现在有点模糊了。

为了把课堂弄得有趣，我们设计了一个相当特别的玩法：早上七点开课，如果你能在七点前赶到，就能领到一份免费早餐。建外SOHO楼下就有一家711，我和公司同事常常一早去把豆浆、包子买好，然后陪着学员一起上课。一堂课下来，我们抽的佣金也就一两百块，明摆着是亏钱。但这门课口碑极好，大家都觉得新鲜、有意思，于是它成了第九课堂早期的招牌课。

紧接着，我们又开了不少课，有Excel技巧、时间管理、HR、魔术、社交传播、创意、MBTI、职业规划、产品经理等等。

老师又是怎么来的？那会儿马源一个人已经扛不住这么多课程的需求，我们便多招了几个同事，专职负责开发老师。渠道不外乎豆瓣、微博上的红人，以及身边朋友和他们的转介绍。我开发老师的方法很简单：先把对方在社交媒体上发过的东西翻一遍，觉得有内容，就私信过去问人家愿不愿意来讲课。

那时候在第九课堂讲过课的人，今天已经有不少名字闪亮：水滴筹创始人沈鹏、搜狗输入法之父马占凯、万能的大熊、讲学习方法的成甲、做时间管理的永锡、做投资的马文亚、讲MBTI的彭莹、首位骑车环游世界的华人李峰、有门广告创始人王小塞……都在这张名单上。

工作需要逼着我去接触老师，这也把一个原本有点社恐的我，硬生生练出来了。每见一位老师，都要提前准备、深入交流，不知不觉，各行各业的知识就被我吸收了不少。说那段日子是我个人见识和认知提升最快的阶段之一，也毫不夸张。

我自己也在第九课堂开过一门分享课，内容是广告文案写作。收费199，一次能招十几个学员，我能赚到几千块。别看不多，放在当时，我每个月从公司领的工资也不过6000块，相比起来已经很能打了。

慢慢地，老师供给问题解决了，甚至还有主动跑来开课的人。可一个更大的坎在前头：我们的模式本身就有硬伤。大多数老师会讲课，却找不到一个合适的分享场地，因为我们是线上招募、线下授课，老师想开课并不容易，业务也难以大规模复制。我们被困在北京，想去上海就得先开家分公司。

其实第九课堂那会儿的课很新颖，不少网友都邀请我们去他们城市开课，那是2012年。为了找场地，我们绞尽脑汁：找那些在公司有会议室的分享者，跟咖啡店谈合作——我们负责拉人过去，对方免费提供场地。可这些始终不是治本之策。

其实，当时在线授课已经有了雏形。做在线教育的同行，自己搭个直播间，建在线教室，就能把课讲向全国。可我们模仿的是一家美国公司，人家走的并不是这条路。要换模式，网站就得重新开发，加上我们总觉得线上听课的氛围和互动体验欠佳，所以迟迟下不了决心。如今回头看，那明明是再清楚不过的方向，当年就是不敢迈出那一步。

哪怕做得不够好，第九课堂在在线教育圈里依然有几分声量。2012年，我们被搜狐教育频道评为年度在线教育公司前三名，还收到过哈佛大学在线教育大会的参会邀请。沪江网校、好未来等机构也对投资我们表现出兴趣。只是我们太实在，和好未来的几位董事见面时，直接说自己还没把模型想清楚，于是这件事便不了了之。

今天再回头看，如果那时候果断转型做在线教室，我们很可能有机会成长为一家大公司。但李笑来的那段话也点醒了我：你不必为自己错过那些机会后悔，因为当年你没买房、没买股票、没买比特币，只是因为你根本不知道那些事能赚钱。

我现在想通了，自己当时确实没有战略判断力。就算碰巧做了在线授课，也不过是运气好，恰好踩到了对的点上。雷军说“不要用战术上的勤奋掩盖战略上的懒惰”，这话放在我身上并不准确。我们不是懒得思考战略，而是没有那个判断能力。

从战术上说，我们当时做得算不错，第九课堂也拥有不少拥趸。可战略方向错了，再拼命也换不来想要的结果。更可悲的是，我们连自己做错了都不知道。所以你看，想要认清自己的无知，往往得先具备极高的认知。

至于我们在战术上究竟有多勤奋，故事还没完，下次接着讲。
