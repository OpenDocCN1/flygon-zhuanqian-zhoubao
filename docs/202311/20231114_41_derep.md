# 追风口，等风来，这波 Web3 的铭文机会你抓住了么？

在浪潮来临之前，你选择追逐还是守候？

我是 Start，Web3Going 的发起人。过去一年多，我在赚钱平台带过多轮加密训练营，亲眼看着报名数字起起落落：第一轮有 1350 人报名，第二轮只剩 280 人，第三轮 300 人，第四轮 350 人。我为此做了一张柱状图，见下方。

![](img/2afbecd94522d7105b34b4269718ce31.png)

自去年 12 月训练营启动以来，我见过太多人带着好奇进场，又悄悄离场；也见过不少财富故事：Blur 与 Arbitrum 的空投，以及 Space ID 的空投；SUI 和 SEI 的打新；大饼生态与 ETH 生态的轮番爆发；还有 Layer2 之间你死我活的竞争。与此同时，也有人抓住了机会，比如路遥——她四月来我的群里，十月初已经自立门户，做起了一个专注铭文的社区。

但说到底，这个领域对很多外面的人来说仍是一道高墙。不少人只听过 BTC 和 ETH，一个小细节就能卡住他们；还有人直接把它归为骗局。也许正因为有距离，训练营才显得有价值。

结合报名数据，我得出几点感触：

1. 报名人数的折线，基本就是市场热度和造富预期的折线。高点之后会回落，然后进入漫长的横盘，ORDI 上市后的行情轨迹也是如此。只要牛市情绪还在，新一期的报名数很可能被 FOMO 推过前高。补充一句：这篇文章写完后不久，ORDI 在一周内翻了 5 倍。

2. 能坚持在圈子里的人，多数是聪明的追浪者，他们更愿意做自己喜欢且拿手的方向。

3. Web3 的准入门槛比我原先想的要高一些。门槛越高，反而越说明普通人的机会藏在后面。

4. 那些敢用很小成本去尝试、经历多次起伏也不离场的人，才是真正的“候风者”。他们像将军一样，提前排兵布阵，只等风起，顺势而动。

所以问题来了：该追着风跑，还是提前候着风起？

我让 AI 助手给了我一套判断标准，大致如下：要看需求端有没有大幅放量，新进入的用户是不是足够多；要看技术层面有没有出现新的变量，旧玩法是否被重新定义；要看资金侧和媒体侧的热度是不是在持续升温；要看用户增长的速度和留存情况；要看赚钱逻辑是否成立、天花板够不够高；还要看监管环境是否友好、大众情绪是否接纳，以及竞争格局里还能不能找到自己的独特位置。最后它补了一句：没有哪个所谓的机会能永远保持热度，判断标准会跟着时间调整。

我看完只能说，这份答案简直是在为 Web3 量身的——当然，也可能是我的立场自带滤镜。

之前的分享里，我聊过不少 Web3 内容。比如有一篇讲定投，那会儿 ORDI 只有 3 到 4U，跟着文章思路布局的人，后来大多拿到了大约五倍收益。这还不算市场狂热期冒出来的土狗币，比如 RATS 和 LION，以及后来的 PIIN。

拿 AI 的标准去对照 Web3：除了政策环境不够友好，其他几条几乎全都命中。技术上持续迭代，关注度虽然小众但很稳定；BlackRock 这些传统机构已经入场；行业方向越来越清晰；用户基数增长很快；天然的和别人不同不必多说；社会舆论各执一词，干脆让时间给答案。这个金钱游戏里永远有人赚有人亏，守住“看不懂就不碰”的底线，至少能活得久。

市场偶尔会被某种情绪点燃，那种行情下收益会很夸张。最近这波铭文热就是一个例子，它几乎凭一己之力拉动了整个大饼生态。十月中旬我就在社群内部提醒过大饼生态的机会，所以定投组合里这个板块的仓位占到了四成。十月底，我在北京办了一场线下聚会，王峰也被我邀到现场——他刚成立了一支 1500 万美金的 BTC 基金。他分享的内容让我更加坚定对 ORDI 的判断。进入十一月，土狗行情先动了起来，各种项目满天飞，我真正抓到的大机会只有两个，好在都抓到了。

事后复盘，说我是眼光独到纯属自夸。之所以能踩中，无非是长期泡在这个领域里，把链上数据、线下人脉和各种零散信息拼在一起，慢慢形成了判断。任何行业都不会把运气白白送给新人——大风起来时，一个准备不足的人是上不了车的。要做的是提前把基础打好，把流程走通，把资金备好。等风真正起来，哪怕你开的是辆破车，也可能被推着变成布加迪。

这两天社群里很有意思：有人靠 ORDI 赚到钱，开心地给大家发福利；有人踏空，拍大腿；有人后知后觉，开始研究怎么注册钱包；也有人只顾追高，结果被套在里面。风一起，什么声音都会有，关键是你要想清楚，自己到底是那个提前埋伏的人，还是那个追着风跑的人。

前两天有朋友问我下一轮 Web3 的机会在哪里。我的答案仍然围绕四个关键词：游戏、Inscriptions（铭文），以及 NFT 和 Lightning Network。它们要么已经走强，要么正在积蓄能量，要么刚有苗头。我们真正该做的，是把基础设施和策略提前准备好，然后安静守候。

最后说回我最初的期待：希望再往后新一轮训练营的报名人数能再创新高，也期待这个领域能越来越规范。我更希望每一位参与者都能走到收获的那天，别让行业里的急功近利和浮躁情绪干扰自己的日常生活。祝读到这里的你，早日过上想要的日子，也早日拿到属于自己的大结果。我是 Start，来自 Web3Going，我们下次见。
