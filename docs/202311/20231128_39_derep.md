# 小红书账号如何做出不一样的记忆点



## 小红书 IP 打造：差异化才是流量起点

大家晚上好，我是叨叨。

从公众号、抖音转战到小红书，至今一直在做 IP 孵化。

我最拿手的环节就是想破脑袋做差异化内容去抢注意力。因为我一直相信，先把定位玩明白，流量自然会来。后期精致的拍摄、剪辑和排版，只是锦上添花。

所谓差异化，说白了就是人设定位不一样，内容表达也不一样。

拿我操盘过的案例「子笺子凛」来说，这是一对双胞胎兄弟。账号起步算早，起量也快，但一年冲到千万粉，依然很惊艳。

复盘下来有三个关键节点。

第一个节点是开播两个多月破百万，随后立刻撞上增长天花板。当时他们主要做的是热点翻拍，比如跟风热门舞蹈。

我们做了二次定位，把两兄弟的人设拆开：霸总哥哥 VS 小奶狗弟弟。同时上线了一个妹妹角色，人设更立体之后，兄弟斗嘴、宠妹等剧情线也出来了，一波爆款就来了。

用三个月时间涨到 300 万，冲破千万用了接近一年，期间也试过联动博主、进一步丰富人设等打法。

所以被邀分享时，我第一反应就是来聊差异化。

先聊人设的差异化：把缺点摊开，就是拉近感。

做过大量 IP 孵化，尤其女生，普遍对形象有强迫症，外貌、妆容、体态、穿搭都要完美。

在意形象没错，但过头就反了。

有个想做穿搭的女生，体型偏胖但长相很甜。我建议她直接做大码、学生党及职场新人的超大码穿搭试穿。一个月后她告诉我，她开始减肥了，想等身材变好再发。

这就偏了。大码试穿的天然差异点就是她的身材+可爱的长相。一旦开始减肥向大众审美靠拢，反而失去了记忆点。

还有位博主第一次出镜，硬把脸上的一颗痣给遮了。她觉得无暇才好看。我跟她说，这颗痣就是你的辨识度，留着更让人记住。

再举个例子：我天生眼睛小，常规做法是化大眼。我选择反其道而行：眼睛小小，语气拽拽。反而成了用户记住我的标签。

邵雨轩的宽额头、梅尼耶的小眼睛，都是典型的例子。

美从来不是复制粘贴。我们身体上的任何特征都能成为记忆锚点。有人染绿发，有人始终戴圆框眼镜，有人永远穿汉服，这些都是刻意制造的辨识度。

知识类博主经常在后期反复磨内容，因为觉得自己不够漂亮。这其实本末倒置了。知识赛道最核心的是有用，而不是美不美。

我一直主张先完成再打磨。在时间有限的情况下，与其反复精修，不如先发出来。拖到内容没上线，就是最大的浪费。

在当下的自媒体生态里，用户更吃真实。那些看起来是短板的特质，往往才是让人上头的点。

过去流行完美人设，把自己立得很高。现如今优秀的人已经泛滥，真实且真诚的自我展示更受欢迎。有瑕疵的人设才有灵魂，端着的完美和偶像包袱反而会把人推远。

专家型人设能做吗？能做，但门槛高。

适合的人群：律师、医生、房产、硬核知识类。

普通人更稳妥的路线是成长型人设、经验分享型。

用「赛道+X」的公式去套，你就能快速找到自己的细分角落。

卖水果这个品类，能怎么做？

人设 1：山里土味人设，自己种自己摘，主打朴实无华的溯源感。溯源为什么能火？因为真实，吃得放心。

人设 2：打扮精致的女生，继承家族农场，从事三农却穿梭在果园里。精致与质朴的反差，记忆点立刻出来。

人设 3：一条狗狗摘橙子，参考抖音【我是拉不拉金】。动物出镜，差异化直接拉满。

最后都要落到变现。想卖一个产品，多角度拆解呈现方式。

同样是干货分享，你可以素颜穿睡衣在床上说，也可以走在马路上边走边拍，还可以 360 度环绕拍。别被固定场景绑住，像朋友闲聊一样自然，才更亲切。

小结一句话：设计真实感。
