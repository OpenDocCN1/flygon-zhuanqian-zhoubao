# 创办一家小公司，并且活下来（3）



## 创办一家小公司，并且活下来（3）

作者： 小马宋

日期：2023-11-02

创办一家小公司，并且活下来（3）：创业 46 条之 33

昨天讲到项目被砍了，却意外收到了 600 万人民币的融资，很多人觉得这很矛盾。

其实时间点很重要。十年前正是 VC 最疯狂的窗口期，拿到钱比现在容易太多，尤其是做互联网。加上我们创始人马源，人脉和商务谈判特别在线，我之前提过他很会搞关系。再加上当时我们对标的美国问答社区也正处于高速增长期，投资人就顺势把钱投了下来。这笔资金名义上投的是乐问网，但说白了天使轮大多是撒网式的，有投赛道的，有投人的，具体做什么项目反而不那么关键。

讽刺的是，钱谈妥的当口，我们内部已经决定关掉乐问了。

上一篇聊过，我们转身要做一个技能分享平台，叫第九课堂。逻辑很简单：你有能拿出来讲的东西，就可以在平台上开课定价招生，我们只抽 9% 佣金。用现在的词说就是早期的知识付费，不过当时是线上集客，线下授课。

我们当时判断有三点支撑：第一，学习的需求是真实的；第二，四个创始人本身就有干货，可以先自娱自乐起来；第三，马源擅长把人拉进来，前期师资不成问题；第四，北京的人才密度，找老师相对容易。于是第九课堂立项，网站开始重写。

推广怎么做？到手的是第二轮的启动资金 300 万，看着不少，其实要养设计、扩前端后端团队，乐问的老界面实在没法看，预算立刻就紧起来了。

这期间我招进了一个后来成了核心的年轻人。王洋，山东人，从大连来北京，之前在游戏公司做原画。后来他跟着我去了暴风影音，再后来一起创了小马宋，现在是我们的创意合伙人。

没钱就只能玩免费的。

网站还在做，只有一个欢迎页。我的打法是先从自己圈子破圈，把 4A 时代的同事、以前的老板都请来当种子讲师，马源则在外面疯狂搜罗储备讲师。同时我负责布关键词、参与原型，并注册了官方微博“第九课堂”。每确认一位讲师，就在微博上推“第九课堂认证讲师”，不少老师本来就有粉丝，顺手一转就等于给我们做背书。

那会儿中关村的创业咖啡馆很热闹，车库和 3W 是据点。36 氪是当时关注度最高的互联网媒体。我研究了他们的采稿流程，也知道主编王壮每周二会去车库咖啡和创业者聊。我就卡着时间过去见了一面。

我介绍完模式，他说还没开课没东西写。于是我换了个说法：我们已经锁定了 200 位来自大公司的总监级认证讲师，话题覆盖面极广。他听完觉得有意思，就写了篇报道。

文章一发，我们的服务器直接扛不住，宕机了。这才切身体会到一篇报道的流量杀伤力。更尴尬的是网站当时只有欢迎页，空荡荡。我让技术临时把第九课堂的微博链接挂在首页上，至少把涌进来的访客都转化成粉丝。

从那以后，我基本靠内容在媒体上白嫖曝光。自己写稿拆解在线培训的商业模式，顺带把第九课堂塞进去，用笔名投虎嗅、钛媒体这类创业号，稿子被用了不少，品牌慢慢有了声量。

后来我又买了本当时很火的《第一餐经周刊》，把编辑邮箱全抄下来挨个发商业模式的介绍。很快就接到电话，对方有个固定栏目叫《好想法》专门讲新点子，就约了我采访。

就这样泡媒体、写稿、聊记者，几乎零成本地把第九课堂推起来了。用户和微博粉丝在持续累积，也逐渐有了自传播的基础。

第九课堂的第一堂正式课，是时间管理专家纪元老师的《如何做到早起早睡》。这门课后来一直都在开。
