# 双十一发售复盘：得物终身陪伴群 7 天招 58 人，收款 1.3 万

原文：[`www.yuque.com/for_lazy/thfiu8/yxse93wlwpz0kz1y`](https://www.yuque.com/for_lazy/thfiu8/yxse93wlwpz0kz1y)

大家好，我是奉小又，一个一边带娃一边做自媒体的全职宝妈，定位是“左手育儿，右手事业”。

在今年双十一档期，我们把得物终身陪伴群推了出来。发售周期只有一周，最终揽下 58 位学员，团队到手约 1.3 万元。今天把这次实操的经过拆开讲讲，给同样在做小体量产品发售的朋友一些参考。

说实话，我们对这次发行并不抱太高期待。毕竟账号体量属于中小型，影响力有限，预热准备也比较赶，整体售卖窗口又很短。本来的及格线是 50 人，能招满就算达标。

结果 7 天下来，最终报名人数定格在 58 人，轻微超出预期。虽然这个成绩算是个小小的超额完成，但复盘下来，问题和优化空间也相当明显。
