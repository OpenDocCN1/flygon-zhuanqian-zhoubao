# 3 个月 0 成本带 260 名学员，在得物搞钱的经验
作者：龙哥

这年头想搞点副业，最怕的就是还没开始赚钱，先倒贴一堆学费和工具成本。但我最近刷到一个挺有意思的案例：有人从8月起在得物做“好物种草”，愣是没投一分钱，3个月带出了近260名学员，自己接到的商家免费产品价值已经超过4000块，而且都是生活里真能用上的东西，不堆灰、不闲置。佣金这块另算，等于产品白拿，钱也照赚。

这位叫小又的创作者，跑通模式之后，跟搭档搞了个“得物变现内测打卡营”，把自己趟出来的经验整理成了新手课，第一期内测营就有超过七成学员成功上岸。后来受陈舟Amber老师邀请，她又去对方星球里开了同样的变现打卡营，结营时上岸率依旧稳在六成八。目前学员接单的品牌包括花花公子、黄金饰品——当然送拍的大多是合金材质——还有玉饰、大牌香水、美瞳以及各类美妆产品，覆盖面确实够广。

很多人一听到“种草”就条件反射觉得必须真人出镜，评论区也有人问过这个难题，但作者的回复很直接：不想露脸也完全可以，照样能接到合作。

也有人对比过其他平台的收益，说视频号那边的流量分成更可观，但缺点是一旦连续三次被识别搬运，流量推荐就会断掉。相比之下，得物的种草收益确实不算暴利，优势在于稳定——毕竟得物本质是个交易属性很强的购物平台，用户点开内容就是为了看东西、研究东西，转化路径短，平台不容易因为“变着法子薅流量”就把你限流。

具体怎么起号、怎么对接商家、怎么写内容拿到合作，作者把整个流程都整理成了一份飞书文档。想要了解细节的可以点进去看，不用被“带学员”三个字吓到，实操部分其实门槛不高。
