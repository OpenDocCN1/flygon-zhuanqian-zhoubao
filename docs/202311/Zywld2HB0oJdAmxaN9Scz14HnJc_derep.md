# 2个月，我👸号写了10个领域，摸索出来推荐算法，每天躺着赚500+，做梦都笑醒！
作者：龙哥

说到👸号的流量变迁，很多人可能还有印象：2016到2019那阵子，文章想被看到，基本全靠粉丝主动点开订阅推送。结果就是大号越滚越大，随便发一篇都能刷屏；小号呢，发出去像石沉大海，根本拉不到新读者。不少创作者一看这架势，干脆跑去抖音、快手找机会——说白了，这就是一场典型的“强者通吃”游戏，弱者连口汤都难喝上。

![](img/bfd667ff0f8816427802923dc3a631ec.png)

我自己前前后后折腾过十多个不同领域的👸号，跟推荐算法打过不少交道，也算摸出点门道。平台的推荐机制算是整个生态的心脏，可算法细节从来都是“黑盒”，外人根本猜不透。唯一的办法就是拿多个账号反复试、不断调，一点点探出规律。下面这些收益截图，就是我近两个月实操跑出来的成绩。

![](img/a35f674eb4a814b5be3b0e1965ddad95.png)

![](img/4ea654da8383d50506914c3f04901d62.png)

🛰️显然也意识到了问题。为了把优质创作者留住、吸引更多人回来，大概从2020年起，平台做了一次大改动：从单纯的订阅推送，转向了智能推荐分发。这一改，等于给文章打开了一条更宽的路，不再只靠粉丝那点“家底”。

![](img/bc4d02bb1c9c0f8525d0e5a8283e1e4c.png)

现在刷👸号的，早就不只是中老年用户了，年轻人也成了主力读者。具体来说，文章能拿到流量的新入口，基本分两块：主推渠道和额外渠道。

主推渠道包括这几个：
一是订阅号消息里的“看一看”入口。我有次无意点进去刷，居然看到自己的文章躺在里面，紧接着阅读量就呼呼往上冲，那速度是真猛。

![](img/f434c95ef922f463e1b58f19482ca71d.png)

二是“看一看”信息流。这个更像是个热点聚合场，优质内容更容易被翻牌子。一旦你的文章冲到10w+，这个位置还会继续给你加推。

![](img/6895bf601761b49e79927a562e0e7f0c.png)

三是“朋友在看”。有朋友读过你的文章，系统就会以“朋友看过”的形式做一波弱推荐，相当于熟人背书。

![](img/ba3e09fa95787f86e9152161e71e0366.png)

四是话题推荐。文章会自动打上话题标签，在相关话题下，也能蹭到不少曝光。

额外渠道也有三个：
一个是搜索。用户在🛰️里搜关键词，碰到质量不错的文章就能看到你。
另一个是相关推荐。别人文章的底部，会根据内容相似度挂上你的文章。
还有一个是账号推荐。如果你的👸号本身已经有了一定影响力，系统会在各种地方给你推荐。

现在🛰️文章的主要推荐来源，其实还是“看一看”这个信息流，它有点像🧣式的聚合内容广场。至于搜一搜、话题这些，多半是从“看一看”分流出去的。所以，能不能搞定“看一看”的推荐，基本就决定了你能吃多少流量。

![](img/6e756cbdee106035dca371b37bb85114.png)

另外，每篇文章底下的“相关推荐”模块，也会按内容相似度来推别的文章；👸号主页下面还有个“订阅号推荐”专区。这就说明，推荐系统不只看你单篇文章，还会整体评估账号的“家底”。

同一个号里，有些文章篇篇都爆，有些只是偶尔冒个泡，这背后其实藏着两种不同的推荐逻辑：
如果一个👸号连续一段时间发啥都没人看，那基本就是没进平台推荐池；
如果只有某篇文章突然火了，其他文章照样冷冷清清，那说明这篇文章被单独提溜出来了，可账号整体分量还不够，没被列入账号级推荐。

抖音这种平台，一条视频爆了，能顺势把整个账号带火；但👸号更看综合实力，光靠一篇文章的噱头，很难改变一个号的整体走势。

那到底怎么让👸号更容易被推荐？核心就一句话：提升账号的推荐权重。权重高了，进推荐池的概率自然大。

平台这个推荐池，业内也叫“进池”。系统会根据内容质量和账号影响力来筛选。另外，账号的标签也很关键，它决定了系统把你往哪个方向推、推多频繁。

也有人说，光靠一篇文章就想迅速走红，概率太低，容易“以偏概全”。真正该琢磨的，是怎么稳定地拿到高流量。

这里有个很扎心的真相：我们看到的，都是被系统筛过一遍的结果，却很少意识到背后那道筛选机制的存在。被筛下去的那些，才是大多数人忽略的关键。

打个比方，你去超市买水果，货架上摆的都是挑好的、漂亮的，可仓库里堆成山的那些呢？你根本没机会看见。你以为货架上的水果就是全部，其实那只是被人挑剩下的一小部分。

👸号平台也一样。算法把内容过滤一遍再推给你，你能看到的永远是“精选版”，而原始信息池子有多大、里面有多少好东西，你根本不知道。

所以，看平台上的推荐内容时，心里得有个数：背后一定有筛选过程，被筛掉的不代表不好。别急着下结论，更别以偏概全。

那怎么提高权重、顺利进池？核心还是持续输出高质量原创。具体可以这么干：

第一，原创是地基。平台偏爱原创，原创内容更容易获得认可，权重也会慢慢涨。当然，别碰黄赌毒那类红线，得按规矩来。

第二，内容得对着用户的口味写。要有趣、好读，更重要的是——别今天写美食明天写科技，老老实实守住一个领域，把目标人群钉死。

第三，把老读者养起来。定期来回访的人多了，粘性上来了，权重也跟着爬。平时多回回评论，让账号显得“活”一点。

第四，多用A/B测试之类的办法，琢磨标题怎么写、文案怎么调，传播效果才能拉满。热点出来就赶紧追，别犹豫。

第五，别光跟着别人屁股后面跑，得有自己的调性。

说到底，想在👸号上稳定吃高流量、然后舒舒服服地赚钱，没有捷径。持续输出高质量原创，再用数据一点点调优，把用户的兴趣彻底勾起来，平台自然会认可你，权重上去、推荐频次上来，钱也就跟着来了。这事儿急不得，得耐心，也得对自己有点信心，剩下的就是死磕到底。
