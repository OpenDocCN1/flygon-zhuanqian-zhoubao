# 如何通过GPT3.5 做一个📕引流程序，而且非常丝滑，超级防封
作者：龙哥

做私域的人都知道，📕和抖音的引流，是绕不过去的两大难题。特别是📕，群聊和私信里直接甩网站链接，像 www.baidu.com 这种，用户根本点不开，点击没有任何反应。

但有个有意思的点：📕的官方域名 www.xiaohongshu.com，在私信或群聊里是可以正常打开的。也就是说，只要链接长成📕的“自己人”，平台就不拦着。

于是就有了一个超级顺滑、几乎不怕封号的玩法：在📕的群聊或私信里，先发一个📕官方域名形式的链接，点开后其实是跳转到🛰️小程序，小程序里放着自己的二维码或引导图。

📕不认根域名，只认“包含”www.xiaohongshu.com 的二级域名。也就是说，用一个带备案的自己的域名，解析出一个包含📕域名的二级地址，这个链接就能被📕放行，点开还能跳到自己的页面。

整个玩法的前置准备工作很简单：一个备案域名 + 一台服务器（阿里云或腾讯云都有卖）。

假设你的域名是 baidu.com，解析出一个二级域名 www.xiaohongshu.com.baidu.com，再申请一个 SSL 证书，得到 https 开头的地址，域名部分就搞定了。

接下来，关键在于跳转🛰️、打开小程序的部分。这里用 GPT3.5 就足够写代码了，不用非得 4.0，写这种小功能，3.5 完全能胜任。

首先，从🛰️小程序开发手册里，找到 APP 跳转🛰️小程序的标准代码。![](img/ecd18a91f4b84917cb1cba570a88db45.png) ```
location.href="weixin://dl/business/?t=xxx
```

然后让 GPT 帮我们写一个 html 页面。![](img/e2769ce5c65cfcd52034fd1ba0149b20.png)

有了这个 html 还不够，得把跳转🛰️小程序的 js 代码也一起塞进去，才能实现完整跳转。![](img/9c2e111d15c589e216cb96b3dc209e6c.png)

这样，保存成一个 html 文件，放到自己的服务器上。如果服务器装了宝塔面板，操作会更方便。![](img/061a4c32708da28f25ece50ec9b0ab96.png)

接下来，是拿到“跳转自己二维码”的链接：

先做一张图，可以是自己的🛰️二维码，或者其他任何能吸粉的图。然后去草料二维码官网注册账号，上传这张图片，生成一个活码。![](img/f41f455e8fbf6f889637bcc530b60e87.png)

在草料里能拿到对应的二维码。![](img/b3bbd874d1748fc10af54e7c92a6868e.png) 点击“预览”，![](img/0ae34a9d5afa610a62f1b8334c93f052.png) 在预览窗口里，右键右边的二维码，选“复制图片地址”。![](img/af06f131825b5ff9b2bcab1e09cc8d61.png)

接着打开 https://vhuoma.cn/URLScheme.html，用里面的“方法二”，![](img/fd7a2ccb025f38143aa8608a1078018f.png) 把刚才复制到的图片地址粘进去，点“获取 URL Scheme”。![](img/bcbe2250b1bbda1863931b9c87437b2f.png)

这个得到的链接，就是“打开🛰️小程序，并在里面展示自己二维码”的入口链接。把它放到之前那个 html 的源码里，保存。![](img/5c8d14bc33b85a84db91a6f15a51f27e.png)

到这里就可以测试了。在📕里发一个类似 https://www.xiaohongshu.com.xxx.xxx/123333.html 的链接（xxx.xxx 替换成你自己的域名），用户点开后，就能跳转到🛰️，看到你的二维码。

不过这里有个坑：🛰️最新政策规定，一个 URL Scheme 只能被一个人打开，第二个人点就会提示“无法访问”。这显然不是我们想要的效果。![](img/8d7b495d1cdd473a5a5740c840f38438.png)

解决办法是：每次有新人点击时，系统自动获取一个新的 URL Scheme，替换到 html 里，再跳转。这就要再次用 GPT3.5 帮我们改代码。![](img/0e1300a2e2eff697d54db70c5bc093b9.png) ![](img/f0cc596bca9b336c685c467335ea2472.png)

把需求和当前代码发给 GPT，让它补充完整。![](img/ad4b9ba2440396ec12e16c9223e0f265.png) ![](img/216fd9e114452e58531ce1b8e987f8ce.png) ![](img/e23e13b13fda98dfc7d262578e5337da.png)

然后把 GPT 生成好的代码存成文本文件，改名为 url.php，上传到宝塔面板。![](img/b22c914c0fcaa5069aaad4997a234a42.png)

最后，在📕 APP 里发链接：https://www.xiaohongshu.com.xxx.xxx/url.php，用户直接点击，就能实现无限次跳转🛰️并展示二维码，畅通无阻。
