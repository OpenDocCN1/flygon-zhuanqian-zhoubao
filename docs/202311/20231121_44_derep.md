# 闲鱼卖二手书的实操路数和踩坑避坑盘点



## 闲鱼二手书的日常运营细节分享与常见问题答疑

作者： 磨人的小妖精

日期：2023-11-14

各位赚钱的伙伴大家好，我是龙哥，目前是一名应届生，正在备考考研。很感谢赚钱的邀请，今天跟大家聊聊我做闲鱼二手书的一些实操经验。

现在我手上就两家店。六月份坐高铁时在星球看到老瞿发的二手书项目帖子，当天就把证办了。7月1号上架第一本书，到现在两个半月，两店累计GMV 20202，其中大部分集中在最近一个月，单日破千也出现过好几次。

![](img/bd74b02085fd44831842818fb3bb093c.png)

今天主要分享的是我平时的日常打法和大家常问的问题，中间也会穿插一些我对这个赛道的理解，希望对你有用。

我做二手书的核心时间段基本都在午休那一个多小时，主要做选品、改价、下架这些事。

先聊选品。我的思路分成两类，一类是跟着市场走，一类是跟着目标人群走。

以市场为导向又可以拆成两种做法，一种是顺势，二种是让市场自己筛选。

顺势说白了就是追热点，哪个题材当下热就囤什么。具体操作就是去扒各大电商的热销榜，关注当下火的剧和电影对应的原著有没有。很多热剧都是改编自小说，剧火了书也会被带火，甚至连作者的其他书也会被带动。比如之前的《长相思》、最近的《奥本海默》。

让市场自己筛选的逻辑是先把货铺满，再用数据说话。上架两周以上曝光还是过百的就直接删掉换新品。这个曝光过百不是死规矩，要结合自己整体的数据水平来定。

用数据硬指标来筛，能把主观臆断挡在外面。上架下架的时候别带感情，觉得“这本书我看过”“这本书是专业经典肯定有人买”都是干扰项，违背了让市场选的初衷。

能开单的书，哪怕你很看好，也先删掉，过两天重新开个链接再上，效果反而更好。

以人群为导向的选品就是做垂直深耕。

圈里做垂直的已经分享过不少了，我补充一点：做一个垂直类目，不只是把相关书堆上去，得对这个方向有真实认知。

比如做考研，哪个院校哪个专业考哪些参考书是最基础的，政治要上架就得知道肖秀荣是谁，有什么系列，能跟买家聊上两句，专业感出来了，买家愿意为这种信任感付溢价。

人群导向的好处是书本身就有需求，只是没被看到。后期运营里曝光不行就删了重发，基本都能起来。

这两种思路不是对立的，可以一起用。我日常上架就是大面积铺开，一个类目全选直接上，看起来很粗暴。但我不会放过任何一个能多成交的机会。

自然流出单时常会出现用户问有没有配套习题的情况。我会先帮他找到对应习题，然后给原链接加一个习题的SKU，再单独上一个习题链接。

这样原链接价格可以压下来引流，又能多卖一本。同样，遇到直接甩书单过来的用户，我也会尽量帮忙找，哪怕他这次没下单，这个书单本身就是很值钱的选品清单。

除了习题和书单，也会抽空去看淘宝和同行的上架方式。有些同行会把一本书和别的书打包成套卖，我也会照搬过来做成套装。

总结下来就是先铺、再看反馈、有反馈就扩散，顾客提过任何需求都不要放过。

我每天中午一个多小时里，选品只占很小一部分，最费时间的是优化。工具帮我们降本增效，但不是让你偷懒的理由。

优化主要做两件事：降价和换图。定价我会先找交易成功率90%以上的稳健店铺做参考，在此基础上加价30%左右，然后卡一个价格带。

卡价格带就是做整数的心理价。比如下好价后是10.5，直接改成9.9，19.4改成18.9。明明只便宜了五毛，买家感受是便宜了一块，下单意愿会更高。

换图我参照航海手册的选图标准，熟练后一个品的降价+换图半分钟能搞定。除了降价换图，我还会给最近有出单的品加SKU，能做成套装就上套装，能上习题就上习题，没条件就加个电子版。电子版的找法星球里有相关帖子可以参考。

一般下午四点左右我会把白天的订单拍完。四点后下的单，我会跟买家说第二天发货，睡前统一拍就行。

晚上学习到十一点左右，拍完单去夜跑半小时，回来就做鱼塘任务。顺便说一句，凌晨做鱼塘任务能比中午多两个。

然后复盘一下当天哪些书出单多，第二天一早用超级擦亮和鱼币去推。

个人体感鱼币推广比超级擦亮更划算，鱼币经常有超额曝光，超级擦亮基本没有额外收益。从平台逻辑看，平台更希望在它上面成交，所以你推广期成交多，流量就会持续给你。

![](img/588070253996a212b57bb242c26104a8.png)

以上就是我的日常打法，其实动作并不多。下面解答几个高频问题：

“上了XX本书，曝光只有XXX正常吗？”、“曝光有XXX就是不开单”，这类问题几乎大家都遇到过。老瞿在航海直播里讲过，我理解是这样的。

交易本质上是商家和买家之间的事，买家觉得东西对胃口、价格能接受才会买。

商家能卖多少，取决于基数和转化率。基数就是有多少人能看到你，转化率就是看到的人里有多少会下单。基数受店铺权重、名气等因素影响。是否成交取决于受众大小、产品质量和服务。

平台能做的就是把你的商品推给更多人，扩大基数，但它改变不了买家的购买意愿。线下该有的服务、产品结构、口碑，搬到线上一个都不能少。平台为了留存，自然更倾向于推能成交的店铺。

所以一开始的任务就是把顾客搞定。曝光量取决于你成交了多少顾客，而不是你上了多少书。曝光高不开单，就要反思产品是否满足需求。不知道需求是什么，就回到最原始的一句话：不要放过顾客提过的任何一个需求。

我遇到的最多问题是盗版，主要集中在计算机编程类图书。作为中间商，售后要面对商家和买家两边。

对商家，买书时尽量规避不确定性，优先选数据好的，交易成功率90%以上的尽量选。遇到的好商家要记下来，老熟人的光环在售后沟通和补发上非常管用。我最近两单售后，老熟人直接全额退款，连书都不让寄回。

对买家，要站在他角度，书等了这么久收到盗版，换谁都难受，先把情绪接住。让他拍几张照片，告诉他我们会让专业同事辨认，确认问题在我们这边就全额退款或重新发货。

争取这段时间一是让买家冷静，二是争取跟孔网商家沟通的时间。也遇到急性子，直接说“确定是盗版，重发就重发，退款就退款，都没问题”。对方选了重发，我马上补发一本，对方收到后不仅好评，还返单买了五本。至于盗版本，老熟人直接退全款，血赚。

刚入行的人遇到买家要一套书，会担心在一个店买太多快递多被怀疑代发，其实完全不用顾虑，核心是质量。质量OK买家不会多想。之前有买家说“只要包邮，给我分一百个快递都行”。我最多一次给一个买家发了11个快递，一本一本寄。

理论上补单是最直接的拉流方法，能让平台误判商品有市场需求而给更多推荐。我个人补单很少，两个半月只让对象和我姐补了三四单。更多时候是用户问我有没有别的书，我会让他先拍下我想要他拍的链接，跟他说拍下后改价付款即可。问到了就说店里有还没上架，或者已经上架但闲鱼搜索不好找不到。
