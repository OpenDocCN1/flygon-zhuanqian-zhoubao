# 印度的眼科手术与签名售书
作者：龙哥

你有没有想过，一台高难度的眼科手术，费用能低到原来的十分之一？在印度，他们真的做到了。

全球范围内，眼科手术都算得上最烧钱的项目之一。能做这类手术的医生，培养成本极高，而且顶着高强度和高风险，堪称外科医生里的“顶尖高手”。但在印度，大量贫苦的白内障患者面临一个残酷现实：不做手术就会失明。真正的难题不是手术本身，而是怎么把价格打下来——毕竟，顶级眼科医生的时间和培养成本都摆在那里，一天能完成四台手术已经是极限。

印度医疗界却想出了一个出人意料的破局思路，叫作“眼科手术流水线”。他们发现，再厉害的大夫，真正不可替代的也只有最关键的那一下“下刀”动作。既然如此，何必让大神从头忙到尾？于是，他们把手术流程拆开，把患者像生产线一样排好：消毒、切开前的准备、术后的缝合等辅助环节，交给不同层级的医生来处理，而那位最顶尖的医生，只负责在每个病人身上精准地完成最核心的那一划。

结果，手术成本断崖式下降，费用直接缩水到了原来的十分之一。完成这一创举的，是印度的亚拉文眼科医院。

有趣的是，这个思路同样可以用在签名售书上。我曾亲身体验过：签一本书，核心动作不过是一个签名，但如果你自己负责翻页、摆放、递书，速度就慢得让人着急。后来我让助手把书提前翻到签名页，我签完一本，马上有人收走并整理好。就这么一个小小的调整，签名效率提高了不止三倍。

这背后其实是丰田精益生产法里常说的“动作整顿”。它的核心目标很清晰：一是减少不必要的动作；二是缩短时间和移动距离；三是让操作更轻松。

把最值钱的动作留给最厉害的人，把辅助动作分出去，往往就能撬动惊人的效率。也许我们做任何事，都可以先想一想：哪一步才是真正不可替代的“那一刀”？![](img/1c37d505930596d12a88ab23e11aa07a.png)
