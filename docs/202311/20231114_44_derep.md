# ('做闲鱼二手书如何选品', (2, 12))

标题：闲鱼卖二手书，选品到底怎么搞？3个月卖到3.8万，我的实战方法全公开

大家好，我是星禾。毕业刚两年多，现在跟两个合伙人一起在福州做K12培训。说是电商小白一点不夸张，真正开始卖货是从这次航海才起步的。目前两个闲鱼号已经稳定出单，另外四个新号还在养号阶段。从6月15号跑到9月11号，卖书一共卖了38032.79元，7月5号那天单日爆了40单，最高GMV冲到1737.4元，单品曝光最高4.3w+。这些成绩靠的就是选品和细节优化。今天重点聊选品，之前也分享过一轮，这次做了不少迭代。

![](img/689eb28416ee1f48960f05f0aa3a1382.png)
![](img/f18659014c4c8cc8964c4ffb5359ef9c.png)

先搭个框架。我选品基本走两条路：一条是流量视角，去孔夫子旧书网看销量榜、到闲鱼上盯同行的出单动态，这套逻辑几乎拿到哪个类目都能用；另一条是用户视角，先搞清楚我的客户是谁、有什么痛点，再有针对性地列书单、配话术。两条腿走路，成单率才上得来。

先说怎么挖教材需求。每个大学官网几乎都会公示各专业选用的教材，附件地址通常就挂在公告页面下面，格式一般是Excel或PDF。直接百度“学校名+教材选用公示”就能找到链接。还能顺便翻到一些学校挂出的《全国大中专教学用书汇编》表格，不管2022秋还是2023秋版，里面都把大一新生要用到的书统计得明明白白。我当时找到表格后，按专业和热销逻辑去搜索、上架，效率比瞎猜高很多。这个表文末会放出来，需要的话自己拿。

书选好了，还要看顾客是谁。我习惯把买家分成几类来打。

第一类是大一新生。他们多半拿着学校发的清单来问，价格敏感得要命，160多的书上来就问能不能100或130。碰到新生团购，先确认“是不是真确定要”再去找书，只要对方给了准话，后面砍价你也握得住主动权，不会白忙活。

第三类是有职业需求的人。比如做医药销售的需要补专业知识，或者要考职称、拿从业资格证的，都会来找对应的考试用书。这类人大多已经在社会上有收入，价格敏感度低，经常直接下单、不砍价，也不在意书是不是九成新。像医院工作的买家，点进主页看一眼职业信息就能判断，转化非常自动。这块是我后面打算深耕的方向。

第四类是纯兴趣买家。不是本专业、也不考证，就是自己想了解某个领域。这类人通常只给一个大方向，让你帮他挑相关书籍，报不出具体书名和作者。因为他们买得多、很少逐本比价，报价空间可以拉高一点。同样是直接下单、不议价，对品相要求也不高。

再说说我的两个店铺怎么定下垂直方向的。第一个号最开始就是觉得某本地理书不错，试了试水，慢慢有学生来问这个专业的其他书，我就顺藤摸瓜把地理科学类的相关书目都补上了。

第二个号更典型。当时发现医学类的几本书一直有需求，于是去孔夫子旧书网把医学类销量前3页的书挑了一遍，6月20号到7月1号之间上架了大约80本。那段时间根本没做任何账号优化，照样出单。后来只要有人来咨询医学类书籍，我就统一往这个店导，慢慢就把它养成了垂直医学书店。下面这张是6月11日到9月11日的订单明细，有兴趣的朋友可以细看。

同行动态也是一座金矿。怎么挖？你先在闲鱼搜大类目词“正版二手”或“二手正版”，整个类目下的商品都会列出来。然后挨个点进商家主页，看他们的“卖家动态”有没有开，重点关注最近有没有出单记录。如果同一个产品反复出现在不同店铺的订单里，说明这个品类的选图、定价已经被市场验证过了；如果一家店多个品同时在出，说明这家店整体运营水平不错，值得抄作业。

![](img/d31180df5e8dc156725af27cb0079d1b.png)
![](img/ba080866a3cca689b8e4a3b8fa53420f.png)

更细一点的操作是：随便找一本你自己上架过的书，去闲鱼搜同款，会弹出一堆卖同一本书的店。点开那些店铺，只要他们成交记录可见，就把卖出去那本的ISBN复制下来，存到手机备忘录里。然后用批量搜索工具，把这些ISBN一次性跑一遍，效率极高。建议优先选自己熟悉或已经在卖的类目去筛，如果搜出来一大堆同行，说明不是竞争太卷就是需求不足。筛选的时候可以把价格下限设成6元，再加其他过滤条件，这样留下来的大多是职业卖家，个人卖家基本被过滤掉。

![](img/60c3cebddf1044125bac2a06e85b7ead.png)
![](img/a1547567add3393c254a77a3088a9a32.png)

选品时优先盯那些“别家已经在持续出单”的书，这类书你上架后曝光一般不会差，也能加“我想要”。数据反馈好，自然更好卖。如果你要卖教材，就沿着教材类目去找同行；卖小说或童书，就按对应类目去找店。有人觉得这种跟品方法比自己大批量铺书慢，但铺书没曝光的话，上架下架反而更耗时间。与其广撒网，不如直接向有结果的人学习。

这里我把从同行动态里收集到的、最近有出单记录的22家书店的ISBN整理了一份，免费送给大家。可以说财富密码就在这张清单里，能不能接住看你自己的执行力了。

还有一个提前布局的小技巧：小红书每个月都会出各行业/领域的月报，里面有一块“细分类目分析”，会列出当月的热搜关键词。根据这些词就能判断接下来流量会往哪类书倾斜，然后提前去孔夫子找货上架。比如我现在看到的趋势是音标、英语语言类、考研这几个大类就是最近的热点，跟着布局就对了。

![](img/409544b73d05d2d6abb0d63021e91f90.png)
![](img/79013a5b0459248962b809d564bf8c72.png)

工具方面，我在用八爪鱼采集器。这是个网页数据采集工具，可视化操作，不用写代码，内置模板很多，官方说连续五年在数据采集领域排名领先。用它对ISBN做批量查询、抓取数据，能省不少手工活。

![](img/1c37d505930596d12a88ab23e11aa07a.png)

总之，闲鱼二手书的核心不在“卖”，而在“选”。把流量视角和用户视角结合好，再借用同行验证过的数据和小红书趋势，你的出单概率会翻着倍往上涨。祝大家都能在二手书里挖到属于自己的第一桶金。
