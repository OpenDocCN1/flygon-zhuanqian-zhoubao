# 成为自由职业者的 20 个必备特质

最近“副业”这个词实在太火了，打开各种平台，好像不折腾点副业，就显得不够努力、不够上进。但冷静想想，副业真的是人人标配吗？

我从2012年进入职场，这些年兜兜转转，选择的方向几乎都和自由职业沾边。眼瞅着“副业”从一个小众概念变成大热话题，自己也攒下了一些真实体会。

不少人其实误解了副业：总觉得有副业就一定好，人生非得配一个副业才算完整。可实际上，副业只是一种“需求”，而不是一种“潮流”。有些人这辈子压根不需要副业——把主业老老实实做好，安安稳稳干到退休，赚的钱也足够覆盖生活所需，那又何必给自己硬塞一份额外的压力呢？

要不要开始做副业，真正该想清楚的是：我有没有这样的需求？是不是只有再多一份收入，才能实现我每个月想达到的目标？如果是，那副业值得认真考虑；如果不是，把主业做精做深，本身就是一条很踏实的路。


别让所谓的“副业焦虑”推着你往前走。先问自己有没有收入缺口，再决定要不要去折腾。适合别人的，不一定适合你；适合你的，才是最好的。
