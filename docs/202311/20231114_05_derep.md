# 影刀 RPA，一键下载小红书博主所有笔记标题和文案

在小红书运营里，拆解对标账号是个效率活。现在用影刀 RPA 就能批量抓取某位博主发布过的全部笔记标题和正文内容，一键搞定，省去手动翻阅复制的麻烦。

这个方案最适合两类人：一类是做小红书电商的商家，另一类是靠小红书引流的运营者。拿到这些素材后，可以用来拆解爆款逻辑，也能将热门标题和内容进行组合再创作，为账号持续产出提供灵感。

具体操作流程和配置步骤，作者已经整理成了飞书文档，需要的话可以直接查看：https://riodtlbegu.feishu.cn/docx/YsotdRZPdoMxqtxWr9Jc6ohUnSc
