# 视频号万粉，两个月变现5万，起底营销号起号变现的全流程

60天变现5万，视频号做娱乐号的全套玩法拆解



各位朋友好，我叫辰风。这篇分享的主角是我带过的一位学员，吖吖。她现在全网加起来大约15万粉，实际用时约60天，光是视频号这一个平台，就到账5万块。接下来的内容，大部分来自她的实战复盘。

先说说为什么选它。视频号现在入场的人不多，流量池却很大，赚钱的链路也短。最关键的是变现路子多：除了官方给的分成，还能接商单，也可以把粉丝往私域引。说白了，做这种生意的核心就是选题和热点反应速度。我现在每天涨粉600到700，偶尔做出一个爆款，单日涨上千也是有的。

![](img/92cdd676e1615d472f47aad7a399c707.png)

下面按三个部分展开：视频号的机会；娱乐号的起号方法；营销号怎么变现。

# 视频号的机会在哪里

👸号、🧣、抖音、快手，这些平台发展了这么多年，头部玩家早就站稳了，普通人想再挤进去，难度极高。视频号不一样，它还算新，正在爬坡，平台也在扶持新人，对刚入行的人很友好。

视频号能起来，背后有个最大的推手：🛰️。🛰️的日活量级是十亿级别，这一点抖音、快手比不了。短视频这块大蛋糕被抖音、快手分走太多，🛰️不可能没动作。你去看，视频号的入口就放在🛰️动态的底部，这就是明晃晃的扶持态度。

另外一个优势：你在🛰️里积累的社交资产，直接能当启动流量。好友、群聊、私聊，视频做出来发一圈，播放量自然来了。这在其他平台是做不到的。

商业价值更不用说。流量在哪儿，钱就在哪儿。视频挂链接卖货这件事，抖音、快手已经替大家验证过。视频号还可以在内容下方挂图文链接，把用户导到图文端去转化。目前视频内容、图文内容、🛰️动态已经打通了，未来如果小程序也接进来，想象空间会更大。

![](img/faa74a890b444e4d20f4360edbe0e314.png)

总结一下，视频号值得做的几个点：一是熟人点赞能带动裂变，二是官方愿意给新人流量，三是分享出去很方便，动态、群聊都能发。

# 娱乐号怎么起步

做娱乐搬运类账号，内容本身不缺流量，难的是涨粉。所以从第一天起，就要想明白两件事：参考谁，以及用什么人设示人。这种账号也是能做个人设的，我就见过一个很有意思的号，定位是“教别人做号的号”。

先看两个参考号。第一个“毒舌扒姨太”，声音很特别，自称姨姨，更新节奏快，用户刷到就有印象。第二个“小冷看看”，用土味自拍和剪辑片段破冰，之后主做搞笑内容，热点做辅助，慢慢就红了。

视频号上还可以观察这些账号：肥肠综艺君、明星娱乐最前线、大碗娱乐v、杰尼龟娱乐、飞天小娱警、娱乐可爱吖、星娱酱1、明星行为图鉴、娱乐哈拉少、娱乐圈小妖1、毒舌扒姨太

![](img/70c38dc2b4b8208e66b2888db8683aa6.png)

抖音上则可以参考：芒果大明星、娱乐圈、娱乐资讯君、娱乐大事件、追星少女孙小寒、明星大头条、会火、娱乐八卦奈小妹、圈内教父、热心观众高兔子、圈内鱼报、娱乐速报、明星行为大赏

![](img/9f4e1915b0486d1277beb067ff8772a6.png)

账号方向定了之后，内容要垂直。以我自己在做的号为例，主要围绕明星动态、文娱热点、话题争鸣来产内容。

发布时间也有讲究。中午11点到1点，适合发综艺切片、明星八卦、话题度高的内容，流量不错。晚上7点左右，学生放学、打工人下班，人累了，容易共情，适合发走心文字类视频，配几部剧的画面和BGM，很容易引起共鸣。

做视频之前，先把底图做出来。底图的核心作用：一是引流，告诉用户去哪找你；二是留记忆，强化账号印象；三是方便后期加字幕、标题。底图的中间画面最好和底色形成强烈反差，这样剪片时更好看。

底图可以自己做，方法很简单：

第一步，去堆糖这类App上搜对应风格的壁纸，比如复古风就搜“复古风壁纸”，把满意的下载下来。

第二步，打开醒图这类修图软件，新建一块不同颜色的画布，把壁纸铺进去，调整好位置。

第三步，添加贴纸，搜索“框”这个关键词，挑一个跟底图风格搭的框，把账号名称、头像放进去。

第四步，整体调色，导出图片就行。

第二种做法，直接用现成的。在Canva（可画）里搜索“视频边框”，模板很多，选一张改成自己的字就行。首次注册能白嫖14天会员，够用了。

![](img/efb75b8424086f2063ba75c7daba1269.png)

需要提醒的是，用模板的话，先把视频剪好、字幕加上，再到Canva里套底图，调整好，最后导出。

接下来拆剪片流程。以漫剪为例，分两步：先剪原片，再叠底图。

剪原片。配音导入剪映，多余的剪掉。时间线拉大，剪得更准。音频里留白的地方，多半是断句、停顿，这是天然的剪辑点。

![](img/e2635ea8f3f758c2f95148a4d0be718b.png)

加画面。打开本地素材文件夹，按配音的情感找对应镜头，一句一句地切。切的片段时间要和文稿句子数配套。画面不要总在一部作品里打转，多混几个，看起来更丰富。比例要统一，四周别留黑边，水印、字幕一定要清干净。原声关掉，小喇叭点灭。视频不长，转场无所谓。

![](img/a9a8d136325c917640e449c4189cbcdf.png)

字幕用自动识别，识别完再手动检查一遍。字体重新挑一挑，优先选“可商用”的。白色字幕加个描边，清晰度更高。刚开始可以多试几款字体，找到最顺眼的，记下来，以后一直用，不用反复换。

![](img/8eb924b412b66bbd984cd2896b5fa605.png)

原片剪完以后，到Canva网页版把视频传上去，套到底图模板里，把要突出的文字填进留好的空位里，居中调整，按最高画质导出。

![](img/8ce6cc0d3c06a499388623a6eb6b6fdc.png)

发的时候，配文先写利索。可以从文案里挑一句话当收尾，也可以写几句个人感受，别太长。结尾补几个标签和关键词，比如#情感#情侣#人生#文案#漫剪#情感共鸣，具体看内容来。去同类视频的留言区捞几条热评放过来，也能带动互动。发完头一小时少刷后台，别制造焦虑，一小时后再看数据。

再做一张SOP表。把剪辑、发布、检查的步骤列清楚，执行稳定，效率也高。以后交给助理，照着SOP做就行。

# 爆款内容怎么找

0粉起号，最快的测试方式是：去抖音、快手找娱乐号最近两天出的爆款，用自己的底图、模板重做一遍看数据。这不算抄，是测试市场的反馈。跑通了，再放大。后续内容以爆点为选题，用新闻素材、影视片段来做，也能放表情包。尽量不碰已经被判定为原创首发的作品。后期可以找热门议题来二创，自己写稿子，或者替换几个关键画面，原创度就上去了。素材靠平时积累，追剧的时候多存一些。

素材来源：

一是🧣，刷热榜，拿题材、图片、视频混剪，稿子自己写。拿到题材后，再去抖音、视频号搜同话题——如果有账号已经做了，直接下载，或者换画面留原声，省时间。

二是抖音热榜。上面通常有成品素材，画面、声音都能拿。

三是参考账号的作品。非热点的趣味内容也可以借，留言区一般有人艾特原出处。

文案有讲究。第一个原则：不站队。事情没有实锤之前，不能把话说死。第二个原则：允许有讨论空间，说一半留一半，评论区自然热闹。第三个原则：没有争议的话题，就用搞笑来写。参考毒舌扒姨太，她那种吐槽风格很多人学。

工具再列一遍。抖音的视频可以用去水印工具，比如轻抖小程序，复制链接就能拿到不带水印的原片。作图用醒图，或者顺手都行。剪辑用剪映，简洁够用。

# 怎么追热点

号做不大的常见原因，是对热点不敏感。追热点的办法有三个：

第一，盯榜单。刷🧣，看热榜和头条，排在前面的关键词，有感觉的顺手存素材。

第二，推演。很多热点有后续，比如某国排核废水，先有“要排”的消息，接着可以想，排了以后会引发什么反应？有什么连锁后果？想到第二步，选题就快人一步。

第三，跟同行。没有公司团队帮忙，就自己盯着同赛道账号，他们发什么你很快跟上。最好控制两小时以内，这样能承接不少流量。

# 涨粉

视频号的推荐和抖音不是一套逻辑。抖音是爆款驱动：一条视频爆了，流量立刻灌进来。视频号更像熟人推荐加算法：发出去先给朋友看，朋友点了赞，再往下一层滚。等播放量过1000，系统才可能放开推荐。我做过一个关于生育的话题，在抖音发，话题已经凉了，点赞寥寥。在视频号发，我转给几个朋友，又往群里发了一圈，播放过了1000，系统自己开始推。效果比抖音好很多。

# 促活

涨粉之外，还要促活。促活的价值在于：互动更深、关系更牢、粘性更强；后面无论做什么变现，都有基础。促活的办法也很朴素：

视频最后埋个问题。“这件事你怎么想？留言区见。”一句话，评论区就动起来了。

留言区搞抽奖。抽粉丝送小礼物，送的是关注。

做情绪树洞。在标题或留言区写“来聊聊你的故事吧”，让粉丝把话留在这里，文案号特别吃这一套。

评论及时回，人感到被尊重，下次还会来。

每条评论都用心回。大号留言区经常没人理，你这儿每条都有回应，用户会把你当特别的号。

![](img/6c06bd88f9983c95ea06fdb045b3777a.png)

之前我做新号的时候，专门在留言区回评论，有好几个粉丝私信说：“你跟其他号不一样。”看到还挺暖的。

![](img/d3de2502511f35d1c3028f97440ecf96.png)

忙不过来的时候，送朵花也行，比不吭声好。有空，就回应再加送花。

再引导大家互相留言，讨论氛围起来了，账号活跃度也好。

# 钱怎么变现

视频号变现，常见的是五种路子：广告、👸号导流、私域转化、带货、账号本号卖钱。

先看广告。官方渠道有三：

创作分成计划：100粉后官方邀请加入，开通后原创视频的留言区会出现广告位。注意，一定要原创。

小任务：后台有商家发布的任务，100粉就能接。按需创作，从后台点发布，也是要原创。

互选平台：粉丝1万以上才有资格。实名认证，内容合规，开通后等着接品牌单。

![](img/d6137f28581bc37da4cd208fd6dd5c4d.png)

其他广告：

CPS分佣。广告主给一条链接加渠道码，你这边成交多少，按比例分成。

图文链接位。视频号内容可以挂图文链接，视频有流量，链接也有曝光，可以当广告位卖。

音乐推广。音乐平台会下任务，按赞数结算，价格看粉丝量和数据。聊天记录号、文案号适合这种。行情举例：聊天记录类账号，6到8万粉，稳定更新，300到500一条；1到5万粉，150到300一条。

表情包也能变现。加入神图君或银河创作者这类组织，把表情包嵌进聊天截图，流量起来后在留言区置顶引流，用九宫格排版吸引人，再补一句“关注领表情包”。

👸号导流。把粉丝引到👸号那边，通过流量主和接广变现。这个方式涨粉快，粉丝质量一般，但量大。绑定👸号之后，后台能展示👸号身份，很适合做快速导流。

私域。引导粉丝加个人号、企业号，存进通讯录，再用日常内容逐步转化。后面能开社群、卖课、做招商，也能带去线下消费。账号做稳之后，把整套起号流程做成课程，主页挂联系方式，收徒。这跟抖音的玩法一样。

带货。本质是卖货分佣金。先开通橱窗，交100元保证金，0粉也能开。开好后到选品中心挑与账号内容匹配的商品。可以直播带货，也可以视频下方挂商品链接，留言区引导下单。开通视频下方挂商品链接，满足一个条件即可：有效关注满1000人，实名认证，持续发原创；或者有营业执照（个体户也行），申请企业号绑定，缴纳保证金。

账号变现。付费订阅：视频号支持原创作者开付费区，做精品内容收费用。账号出售：粉丝单价大概两到三毛，按粉丝量和权重来评估。

做号过程中踩过的坑，以及限流怎么处理，篇幅有限，下一篇再写。

做视频号营销账号，最怕的就是凭空被限流。先说说最常见的一种：跟着抖音爆款走，结果素材内容大量雷同。在视频号平台，原创审核本来就严，这种“搬运式”内容很容易被官方识别，然后直接限流处理。

![](img/79e9ab29be766256b79cb8485aef12d1.png)

还有一种是自己踩了虚假宣传的坑，喜欢把效果夸得天花乱坠。我自己就遇到过，发了一条“打九价会影响怀孕率”的内容，一下子话题就火了，但同时也招来不少男性举报，结果被限流了。

![](img/a7bfc2efe0f466d93f8061547f456bc1.png)

再有就是涉及黄赌毒或明星负面事件的流量陷阱。比如之前Lisa的疯马秀，热度确实高，但这类内容很容易引发粉丝群体举报，流量再大也接不住。

![](img/05b85875f1fbd9bbb99a64aa13724f0a.png)

所以建议大家没事就去翻翻视频号的违规条例，搞清楚哪些雷区不能碰。

那限流了到底怎么解决？首先，坚持发正能量的内容，但得注意保持自己账号的一贯人设。比如你做的是风景号，就别突然跑去发情感鸡汤，那样风格混乱，反而更伤权重。其次，发满十条视频后，可以走申诉渠道要求解除限流。平台本身有信用分机制，你能做的就是尽量维护自己的信用。最后想说，官方处理申诉通常很慢，与其等那点回复，不如从一开始就别碰那些雷点。

以上就是我做视频号营销定位的全部心得，感谢你耐心看到这里。
