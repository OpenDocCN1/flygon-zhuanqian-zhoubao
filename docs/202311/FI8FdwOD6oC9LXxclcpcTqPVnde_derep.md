# 如何做好一场5-10万营收的GPT线下课

这两年AI火得让人心痒，但真正敢下场把它做成生意的人，其实没那么多。我是个纯文科背景的普通人，不写代码，不懂算法，却硬闯进了GPT培训这条赛道。原因很简单：我认定ChatGPT是一个持续存在的风口，而我的长处在于把碎片信息消化重组，变成一套有体系的内容，于是顺理成章地成了讲师。

更直白地说：先用培训养活自己，不下牌桌，才有后续翻盘的可能。

前阵子分享过怎么成为一天课酬过万的企业GPT讲师，今天聊聊另一个话题：怎么从零开始，策划并落地一场营收5万到10万的GPT线下课。

我过去两个月正好办了两期，第一期9月初，定价999元，来了45人，收入近5万；第二期11月初，定价1699元，48人报名，收入约8万。

![](img/eb389e2b254d029f4dc947b70a726f70.png)

说实话，最初我觉得线下课是个偏传统、难爆发的生意——直到真正扎进去，才发现这其实是个大咖看不上、普通人做不了、还处在蓝海阶段的稳定赛道。

我这两期的打法，总结下来其实就三步：产品设计、营销推广、交付体验。

# 01 产品：先想清楚用户为什么买单

动手设计课程之前，第一步不是想讲什么，而是搞清楚谁来买、为什么买。

我锁定的目标人群是：职场中高层、中小企业主和个体创业者。至于大企业老板，他们一般会去EMBA商学院或者企业内训，充其量我来给他们讲讲趋势认知。

那这群人凭什么掏钱？我把知识付费的底层逻辑拆成了四类，基本就是人性驱动的四种需求。

第一种，为认知付费。他以前没看清AI是个机会，你一句话点醒他，这就是认知升级，能帮他做判断做决策——他当然愿意花钱。因为比起付钱，他更怕错过，更怕被看不见的对手降维打击。

第二种，为技能付费。比如过去做一份PPT要三小时，现在AI十分钟就搞定，质量还不输。天天写方案、出报告的人，对这种效率革命没有抵抗力。再比如用GPT语音功能随手记录灵感，几分钟就能转化成带有不同博主风格的文章——对日更的自媒体人来说，这能救命。

第三种，为认证付费。如果学完能拿到正经证书，比如工信部认证、人社局认证，或者行业认可的资质，对升职加薪、简历背书有实在的帮助，用户的预算就会大幅上调。

第四种，为变现付费。这是最直接的诱惑，也是很多培训机构主打的招牌。看到别人靠AI月入十万，谁都会代入一下自己，然后痛快付几千上万学费。但残酷的是，真正能跑出来的人永远是少数。

如果纯看赚钱效率，第四种最赚。我身边也的确有学员靠AI赚到了钱，但客观说，我目前没法承诺大多数人都能复制这个结果。所以我的选择是：克制。不拿“变现”当噱头，因为我想要的是长久生意，不想被反噬。

第一期课程，我把价值聚焦在前三层，核心是技能价值，另外叠加了一个加分项：微软与领英联合颁发的全球通用人工智能证书，也算是个行业敲门砖。

# 02 营销：本质是重复，但别让人烦

营销这行有句老话：营销的本质在于重复。可口可乐名气够大了，为什么还要年复一年投广告、换创意、冠名赞助？就是为了在你脑子里反复刷存在感，让你买饮料时下意识选它。脑白金就更典型了，逢年过节买保健品，脑子里自动蹦出那句洗脑广告。这就是心智占领。

但个人IP的营销，不能照搬电梯广告那套，因为朋友圈是能屏蔽的。你不能用同一句话刷屏，得学会从不同维度去讲述同一件事。

比如你想表达“ChatGPT实战营报名很火爆”，可以这样拆解：

- 晒报名截图：一位北京校友专门打飞的来杭州上课。
- 晒组团学习：某学校的老师组织了5人团集体报名。
- 晒口碑推荐：上期学员疯狂推荐同学来学。
- 晒提前预订：下期刚开放名额，就有人抢先锁位。
- 晒大咖背书：某业内大佬也来报名了。
- 晒实时名额：还剩下三席，手慢无。

这些维度都在说“火爆”这同一个事实，但用户不会觉得被打扰，只会觉得这课是真的抢手。如果你只会反复喊同一句话，那才是骚扰。朋友圈内容必须真实，不能造假，这是底线。

关于发朋友圈这事，我原来挺排斥的，但做线下课后彻底改变了。理由有两个。

一个是用户心理层面。首先，你一直在发广告，反而说明招生顺利项目正常；如果长期不吭声，用户反而会起疑：是不是出事了？是不是捞一笔就跑？其次，用户没法走进课程现场，只能透过朋友圈来感受你。你今天展示自信，明天展示好评，他对你的认可就会持续叠加。再者，用户天然“买涨不买跌”，他要看你连续办了两期三期，才开始真心信任你。就像买房，没人会买跌。

另一个是算账逻辑。第一期我在三天内集中发了大约15条朋友圈，最终成交36000元，平均每条的转化价值是2400元。现在我的朋友圈平均每条能带来2到3个咨询，成交1单，大概就是1000多块。你说这朋友圈该不该发？

除了朋友圈营销，开课前还有三件事必须沉淀。

第一，客户资源。我的第一期付费用户，80%来自得到高研院的同学。凭什么？因为我在那建了ChatGPT精进社，持续分享AI内容，组织了两场线下分享，还深度服务了几个关键意见消费者。开始宣传时，他们愿意帮我打call。

第二，系统知识。自己会用和能教别人是两码事。你不能只会侃侃而谈，得把知识结构化，及时跟进行业头部的人，把信息差变成一套有体系、有层次的课程。

第三，授课经验。内容再好，站上台讲不出来也白搭。我的经验是去大企业线下磨出来的，最初从99元的线下工作坊开始，小规模试水，获得反馈后再迭代优化，逐步打磨出最适合自己的讲法。

如果你不想等三个月，也有快速启动的路径：在当地有企业资源（比如AI协会、HR协会之类的），可以直接谈合作办大课，由对方负责招生；如果没什么资源，就先依托某个组织成立AI社团，用几场低价的线下分享积累品牌认知；再或者，你能谈下头部AI企业，搞企业游学，也能吸引高净值学员。

还有个容易被忽视的板块：团报。我收到了一个5人团、好几个2-3人团，主要是企业和学校。企业需要送员工来学AI技能，职业院校也需要有人带他们接触前沿技术，这是真实存在的需求。关键是解决两个痛点：一是开发票，必须有企业主体，方便对方走报销流程；二是提供带模棱两可官方色彩的文件，方便他们快速通过内部审批。个人团报则简单多了，给优惠就好，我的策略是第二位起8折，相当于把推广费用返还给他们。

最后说渠道。现实很骨感：前一两期大概率靠自己死磕，除非你自带靠山。但只要跑通了第一期，拿到了真实成果，你就有筹码去跟大渠道聊合作了——他们往往也缺线下落地的课程，双方可以互补，谈好分成，一起长期推进。

# 03 交付：超出预期，才有口碑

交付只有一条原则：超预期交付。这是我在“龙哥盟”待了三年多，学到的最重要一课。

记得筹备线下课时，我的私教老师问我：“你这课在市场上值多少钱？”我毫不犹豫说至少2980元——因为市面上同价位甚至更贵的课，落地性和实用度都不如我。但他建议：前几期定价要比2980低，让用户感受到超值，口碑才能立起来。

我照做了。第一期定价999，给到用户的是远超这个价位的体验和收获，先让第一批种子用户觉得“赚到了”，口碑就慢慢有了。

关于场地，也给大家几个省钱方案：

- 人工智能主题的创业园：空置率高，他们需要有人来助力招商，可以试着谈免费或低成本借用。
- 政府主导的公共空间：比如杭州有些讲堂，网上申请就好，费用很低。
- 共享办公空间：适合前期人数不多的时候，容纳二三十人没问题。
- 大企业的会议室：周末一般闲置，有关系的话能借用，回馈几个学员名额就很好谈。
- 酒店：是最后的选择，贵且主题契合度一般，除非外地学员占比高才值得。

再说一个重要价值：升单。线下课让用户面对面看到你的专业度和现场能力，建立信任的速度远超线上。除了两天正课，你可以多展示一些企业落地提效的案例。对创业者或企业一把手来说，他们不需要事必躬亲，但一定愿意为“ROI大于1”的提效方案买单。

我自己正在跑一个路子：AI+具体场景的解决方案。比如“创始人IP套餐”——用AI跟踪对标账号、捕捉爆款视频，配合ChatGPT生成文案，再批量制作视频或配合数字人代运营，让创始人每周只花两小时就能做到日更。这个模式还在打磨阶段。

# 04 总结：机遇与局限并存

线下课的优势和劣势都很明显。

一年想赚1000万，基本别指望靠它；但一年赚50万，完全有机会。

优势在哪？第一，认知鸿沟依然存在，现在多数人还是“听过但不会用”的状态。第二，需求确定性高，只要你在一个细分场景里帮他提效，他就愿意付费。第三，线下市场相对空白——大佬看不上，普通人做不了，你可以在自己的城市里建立壁垒。第四，培训可以无限细分。职场人可以学“10分钟生成高质量PPT”，现场讲透、操练、PK；青少年可以搞“AI绘画体验工坊”，孩子画完还能把作品装裱带回家；甚至可以做“教家长用GPT辅导作业”，在K12被严管的背景下帮家长降本增效。

劣势同样要认清：必须在一二线城市做，否则认知度不够、付费人群太少；招生是命门，前期做出案例后最好能抱到大腿，否则第三期开始就会出现乏力；培训是个苦力活，细节多、口碑要用心抠，又不像K12或技能补贴类课程那么刚需，招不到生的时候是真的焦虑。

至于衍生方向，我看好两条线。

一个是AI认证课。长期来看不可能一直卖自己，等模式跑通后，就要学会抱大腿。因为有了线下课的成绩，我才有机会和环球网校合作开发线上认证课程，目前也在和智谱AI谈企业培训体系的共建。当所有人还在迷茫时，你专注在一个方向做出成绩，自然会吸引合作资源。“先活成一道激光”，这句话是我真实踩坑后的体会。以前我也觉得培训是苦力活，有点嫌弃，后来才明白：只有把一个技能做透，才能换来持续的机会。前期一个人就是一个团队，拼命卖自己；等有了案例和口碑，再培养团队、卖合伙人、卖模式。

另一个是AI培训的规模化操盘。To B的AI培训、咨询陪跑，To C的线下课、认证课，如果都小打小闹，很难成气候。真正的想象力在于：一端牵头整合AI人才，做认证培训，形成各细分领域的课程体系，同时把市面上的大模型和工具研究透，搭建解决方案资源库；另一端深入企业，了解大中小型企业的真实需求，按需提供AI培训、咨询、认证、工具软件甚至稀缺人才。两端一对接，就是一个巨大的盘子。
