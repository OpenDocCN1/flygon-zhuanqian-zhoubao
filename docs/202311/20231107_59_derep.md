# 从汽修车间到互联网自由职业，他用五年攒下180万首付：一个普通人的真正逆袭
作者：龙哥

如果你正站在互联网的门口徘徊，想寻找一份真正属于自己的事业，那不妨停下脚步，花几分钟听听我的故事。

我没做出过多耀眼的成绩，更谈不上年入千万百万的传奇。说到底，我只是个平凡得不能再平凡的人，没有天赋异禀，也没有过硬的资源。可正是因为我普通，我的经验才更有借鉴的意义——我能走通的路，大多普通人也能复制。

五年前，我的日常是和扳手、机油、底盘打交道，一个不起眼的汽修小工。而今天，我已经靠互联网自由职业站稳了脚跟，并在合肥买下了自己的房子。那180万的首付，是我五年间一笔一笔挣出来、攒下来的，没有运气、没有捷径。
