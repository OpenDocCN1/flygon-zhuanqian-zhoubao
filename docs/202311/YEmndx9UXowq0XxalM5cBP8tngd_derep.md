# 7天跑通日利润100的小项目：闲鱼二手书
作者：龙哥

你有没有发现，网上从来不缺赚钱路子：有人靠小项目月入三千，也有人做大生意年入千万。但问题是，这些机会未必适合你。

我特别认同一个判断标准：这个项目有前景，而我刚好懂一点，那就值得干。就像俞敏洪做东方甄选，不是因为他预测到了什么风口，而是助农话题当时正热，他自己又常年泡在抖音直播，熟悉这个赛道，所以才一头扎进去。假如他当年只懂教培、从没碰过直播，恐怕也不会押注这个方向——毕竟在公司业务版图里，那根本不是他有话语权的领域。

我决定做闲鱼二手书，也是这个逻辑。

之前我做过几个月的营业执照代办业务，对国内资质和执照这块的门道很熟，所以搞出版物许可证对我来说没什么难度。加上我运营过淘宝和拼多多店铺，做的都是虚拟和服务类目，对电商平台的玩法心里有数。于是就想：那就试试二手书吧。

当然，我也纠结过要不要选📕。后来放弃是因为📕多一道选品环节，你得琢磨做文具还是服装，测完还得找供应链，后端太费时间。而闲鱼的后端几乎不用操心：卖什么？书。供应链在哪？孔夫子旧书网。整条链路直接闭环，省下大量研究成本。

还有一个私心：闲鱼周期短、上手易，一旦跑通，我打算去抖音直播卖课，专门教别人做闲鱼。这其实才是利润的大头——我之前创业第一个项目就是抖音知识主播，当时日入三千多。对这个板块有兴趣的可以在评论区说一声，后面我单独拆开讲。

所以，我选闲鱼，完全是基于自身资源、经验和长远计划做出的综合判断。

项目定了，立刻行动。我动用以往的人脉找了个代办，花了1150元，7天下证。下证当天就注册好三个闲鱼号，对应好支付宝和手机号，两台手机登录三个号。接着配置华少的闲管家，测试自动上品，第一次就成功了。

第二天上架30个品，一算账：要填满500本得花17天，太慢了。于是第三天改成每天50个，还是嫌慢，后来直接每天100个，就这么持续干。操作上，我会把前一天曝光最低的链接全部下架，只留下有潜力的。

坚持到第7天，终于有人来问了。但咨询的基本都是软件自动上架后标价特别低的，有很多错误，几乎是亏本单。我照样接，前5单全是贴钱出的。为什么？因为这说明项目跑通了，有人愿意买，方向对了。

从第一单开始，接下来一周每天都有5到10单。

要说这项目有什么门槛，真的不高，核心就是执行力。

讲几个关键心得。

第一：粗暴上架，以量取胜。二手书这个项目本质就是靠批量铺货去测试平台流量，找出高曝光商品，再优化出单。所以我一开始根本没花心思去精修图片和文案——因为就算你修了，链接未必能出单。不如先用数量对冲不确定性，筛出值得细调的那部分再重点优化。

第二：出版物资质别太当真。不管谁跟你保证“能用几年”“有年审”“出问题帮你处理”，基本都靠不住。你找代办无非是群友介绍或者淘宝找来的，这些人源头其实是当地有一定渠道的人，人家批量出证，几百几千个地做，根本顾不上服务你一个人。你接触到的多数是中间商，承诺都只是为了成交，后面的事没人敢打包票。所以出版物许可证就当消耗品，哪天出问题都得有心理准备。

第三：闲鱼账号之间基本不抢流量，可以放量操作。我才做了一周，平均每天利润80到100多。如果再开三个号，好好运营，月入过万并不难。而且前面已经有大佬用团队化运作验证过这条路走得通，这也是我下一步的方向。如果卖书能赚钱，我就继续开店；如果利润见顶，我就转型去抖音直播教别人做闲鱼。

总的来说，闲鱼二手书对普通人来说，真的是比较容易上手的项目，只要你觉得适合，随时可以试试。

我是朔愽，现在在云南昆明。如果你也感兴趣，欢迎来找我交流——一个人跑得快，但一群人才能走得远。
