# 大学生从颓废摆烂到初试创业变现六位数，我的成长经历及思考

前几天刷到一位00后大四学长的故事，心里挺有触动的。他从大学里的“躺平选手”，到如今创业半年、账上流水六位数，这中间的经历和思考，我觉得很值得拿出来聊聊。

他说自己以前也是个彻头彻尾的小白，试过不少项目，眼睁睁看着别人起飞，自己却始终没折腾出水花，迷茫得不行。如果你现在也处于这种状态，不妨看看他的路径，也许能少走几步弯路。

和大多数人一样，他一开始也不懂什么门道。后来因为遇到几位贵人，才真正被拉进了互联网的圈层。他特别感谢带他入行的康哥，以及一位长期用朋友圈“启蒙”他的行一哥，因为这些人，他接触到龙哥盟，认识了更多同路人，资源和人脉也都慢慢攒起来了。

为什么会把自己的经历写出来？他总结了三个原因：一是感谢帮过他的贵人；二是想帮刚进互联网的新人少踩坑，早日赚到第一桶金；三是记录自己的成长，提醒自己别停下，继续往前冲。

他把这段旅程拆成了几个阶段：互联网创业前的状态、初次试水踩过的坑、二次出发后的柳暗花明、目前的收获、对未来的规划，还有给赚钱新朋友的几条建议。

回顾过去，他说心里既感慨又平静。每件事的发生，都在某个层面让他往上走了一截。最关键的心得是：跟对人、做对事，真的能省下大把试错时间。


如果你也正在迷茫，或者刚迈上创业这条路，希望他的经历能给你一点亮光。每一条路都不白走，每一次踩坑都是累积。共勉。
