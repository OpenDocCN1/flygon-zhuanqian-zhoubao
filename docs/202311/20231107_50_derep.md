# 如何在 Web3 里面 work to earn
作者：龙哥

大家好，我是龙哥。2018年就进了区块链圈子，算是个老“矿工”了。先后在头部交易所做运营、Web3创业团队管市场，也在一家Crypto基金负责PR和投后项目。近几年还在各种DAO和社区里活跃着，偶尔“用爱发电”。今天想换个视角，聊聊普通人怎么通过在Web3工作来赚钱——也就是大家常说的Work to Earn。

都说Web3入场姿势很多，翻阅航海手册、听嘉宾分享，罗列出来的方式不少。但对比一圈你会发现，在里面找份工作可能是成本最小、风险也最低的选择。那在这行上班到底啥感觉？我总结了几点好处。

首先，远程办公很普遍。好多岗位不用坐班，你甚至能参与海外项目，实现“地理套利”：拿着欧美或一线城市的薪资，住在老家或某个风景秀丽的小城。国内数字游民聚集的地方，Web3从业者占了很大比例。而且时间灵活，省下的精力还能干点别的。

除了全职加入某项目，Web3自带去中心化和社区优先的基因，所以兼职机会特别多。像一些知名DAO或项目，会招MOD（社区管理员）、“大使”之类的志愿者。我身边就有很多“斜杠青年”，同时给好几个项目做贡献，资源互通，收益最大化。

在这样的行业里待久了，你的信息圈和人脉圈都跟以前不一样。相比圈外用户，你处于更上游，更容易抓到早期机会。除了固定薪水，不少早期项目还会给员工、兼职成员发代币，相当于拿到了项目期权。万一项目爆发，回报可能相当可观——毕竟Web3的赚钱周期比传统公司上市短太多，牛市里的空投神话大家都听过。

Web3号称下一代互联网，目前金融属性很强，又天生全球化，所以有互联网、金融、出海背景的人转型相对容易。当然我也见过从传统金融、跨境电商、自媒体、在线教育、4A、电视台等五花八门行业跳过来的朋友。说白了这个行业还在早期，门槛没那么高，你只要有硬技能，或者学习能力够强，抓住窗口期入行并不难。

下面凭我个人经验，把目前Web3里的工作机会粗略分个类，可能不全。我自己就在第二类（非开发类），这几年除了写代码，其他岗位基本都试过。

看岗位名称就知道，跟传统行业的要求差不太多。如果你原本就具备相关岗位的能力，再对Web3有一定了解、补足一些专项技能，完全可以上手。目前市场需求最大的是开发者和运营/市场，尤其开发者稀缺。我接触过不少开发者社区和公链团队，都说合适的人太少，现在又是熊市，缺口更明显。

拿开发来说，传统互联网的前端、后端、测试等岗位在Web3同样存在，还多了智能合约开发这类新角色，需要学新语言、新框架。好在公链和基础设施项目提供了大量免费学习资料，还有Grant、黑客松等活动吸引新人。有些“黑客松猎人”光靠做demo就能拿几万到几十万美元奖金。

运营和市场类则除了基本功，还得对行业热点、用户群体有深层感知，制定策略时才能接地气。这些都得靠时间泡出来。另外，英语能力比较重要——Web3是全球市场，对外沟通的岗位尤其需要英语，开发岗要求稍低。如果你还会点别的外语，那就是加分项。

给想入行的朋友几条建议吧。整个求职大环境在剧烈变化，Web3的核心是“无需许可”，未来求职也会这样。以前那种被动投简历的路子走不通了，在Web3里，你得主动建立自己的能力体系，维护好个人履历，然后大胆出击。

不过也要提醒一句：Web3有很强的周期性，很多创业团队说没就没了，就算大交易所、公链在熊市也会大幅裁员。如果你在大厂拿高薪，很多Web3项目可能给不到同等待遇，心理预期得先调好。

所以我的建议是，初期别急着All in，别脑子一热裸辞进来。你可以先去DAO组织里混个脸熟，或者通过内容创作和自媒体积累认知、补齐能力；然后在你认可的项目中活跃起来，从边缘位置、兼职或志愿者做起。当然也别真的一直“为爱发电”，要挑那种背景靠谱、对贡献者大方的项目参与。等时机成熟了，再考虑要不要全情投入。

最后是找工作的渠道。

![](img/a5d5d5ef24d0ab91e1f0fc454509b14d.png)

中文社区方面，可以看看ABetterWeb3、Dejob、smartdeer（全球化平台，Web3职位比例很高）以及👸号/社群BlockJob。开发者还可以多关注各类Web3开发者社区，招聘信息常在那里发布。

国外平台也不少，更新比较及时的有：
- AngelList：偏初创公司职位；
- Remote Web3 Jobs：专注远程岗位；
- Web3.career：聚合平台，有学习导航，按技术和非技术分类，还能看高薪排行；
- 再加上一个加密世界最大的综合职位聚合平台，基本就是门户级别的。

好了，今天就分享到这儿。希望对想进入Web3的你有点帮助。
