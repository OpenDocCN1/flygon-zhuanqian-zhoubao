# 单月流水三百万的传奇直播cps变现业务，项目实操经验以及团队化运营方案（含：抖音直播鱼塘起号详细流程，适用所有抖音直播）

关于传奇直播CPS这条赛道，圈内一直流传着不少造富神话。今天要分享的这位W先生，是一位90后流量玩家，在互联网一线摸爬滚打了7年，做过网易运营增长专家，负责过百万级用户增长全案，现在是一家流量公司的合伙人，主攻方向就是直播获客。

他从2023年5月开始切入传奇类游戏直播，目前单月流水稳定在300万左右，佣金比例拿70%。最猛的时候，单日注册用户冲到过2000+。团队配置并不复杂，核心打法却非常系统：抖音直播鱼塘起号+微付费平播，几乎适配所有直播赛道。

先说说两个平台的取舍。

抖音的优势很直接：8亿日活，市场空间大，流量精准度也更高，懂算法的人能撬动更多自然流。但劣势同样明显：需要资源才能拿到直播间白名单资质，单个授权差不多8万；每天还有硬性投流指标，单账号日均投流不低于1万，否则直播间会被封；平台规则严格，容易违规；同行也卷得厉害。

相比之下，快手投流没限制，规则宽松，没那么容易抬直播间。但日活和流量精准度都略逊一筹，投流流量注水严重。

所以如果要做，优先考虑抖音，前提是有资源能扛住门槛。个人或小工作室如果流量玩得转，可以先搞“野播”——也就是没有授权，不露游戏画面和敏感词，靠话术把用户导到私域再发链接。前期的账号筛选阶段，W先生就是用野播方式起号，流量不错的号再加白名单。

再聊项目本身。

传奇直播CPS的逻辑很简单：拿到游戏授权，申请抖音白名单直播间，用户充值后拿佣金，比例通常在70%左右。目标用户画像也非常清晰：30-40岁，三四线及以下男性，有房有车有存款，付费习惯早就被市场教育过了。只要产品不太烂，首充付费率能做到30%以上。

这行的门槛主要卡在授权上。市面上好产品都要抢，普通人想找游戏合作，有三个路径：一是看直播间的“小手柄”，查游戏发行/运营公司，用企查查找联系方式；二是直接私信直播间博主谈合作；三是混相关行业社群，接商单。

团队岗位怎么搭？

W先生的公司架构很精简，按最小单元体复制放大。主要分三块：

流量前端：主播、直播助理、剪辑；私域后端：GS、聊手；职能部门：人事、财务、行政。

前端直接负责人是他自己，重点盯运营和投流。主播每天播4场，每场1小时，下播要复盘。直播助理要维护评论区、控评、管理抖音群、做私域导流，还要管鱼塘号，配合主播带节奏、补数据。剪辑每天出至少3个直播切片，更新账号，还要做直播间贴片。

这里有个核心思路值得学习：重运营，轻主播。

主播的招聘门槛很低，只要听话照做、吐字清晰、能背稿就行。所有流程全部标准化，主播只是“柜台销售”，业务核心抓在运营和团队手里。新人来了先试用3天，第一天熟悉游戏和直播稿，第二天试播，第三天再试播，能达标就留下，不合适直接换。所有话术、答案、互动协作流程都做成SOP文档。

![](img/64b57843a86b1ee30912500468138d38.png)

主播里面再挑有网感、有自主学习能力的人做进阶培养，但绝不依赖主播的个人能力。因为团队的核心竞争力是运营和流量控制，主播走了也不怕，换一个照样跑。

接下来是重头戏：鱼塘直播起号，这套流程适用范围很广，个人、工作室、公司都能直接抄作业。

鱼塘号就是给直播间做数据、带节奏的工具号。先说怎么养号：

养号的核心是“螺旋打标”。开播前，所有鱼塘号先刷相关领域的视频和直播，找到同一个头部直播间（比如传奇游戏头部主播），伪装成真实用户进去停留、互动、关注、加灯牌。然后在这个直播间里，通过点用户头像，逐步关注自己的“鱼塘主号”，这样鱼塘号就和主号建立了间接联系。开播时，鱼塘主号先刷到自家直播间，其他鱼塘号就会因为关注了主号，被系统推荐到直播间，轻松刷进来。

![](img/bd4519d47d1c453de86fcc9603204ec8.png)

养号的评判标准是：小鱼刷10条内容，至少5条是相关领域；大鱼（鱼塘主号）10条里至少6条是。

几个细节要注意：所有鱼塘号互动必须用领域相关关键词，帮直播间打标；鱼塘号之间不要互相关注，也不要提前关注主播号；鱼塘主号最好在抖音有付费行为，等级10级以上；鱼塘号不要都放公司里，员工分批带回家晚上刷5-10分钟；主播开播时要关闭搜索，防止同行搜到；刷到直播间不能上来就关注，至少停留互动5-10分钟，再点赞、关注、加灯牌，防止养出死鱼。

正式起号是螺旋打法，目标就是前三场打爆feed流推荐，然后挑流量好的号过白、挂小手柄。

核心五要素：

第一，真实成交。首播无论播多久，必须至少有10个真实下载注册再下播，用话术诱饵或者鱼塘带节奏都行。首播打好了，后两场事半功倍。

第二，数据递增。第二场数据要翻倍，重点盯关注、灯牌、成交三个指标。

第三，分钟流速热度叠加。分钟级评论起来，feed推荐就会增加。控场节奏要做到让真实用户产生粘性，比如说“点赞过10万发20万红包”，可以适当“骗”一下，把人留住。

第四，鱼塘操作。鱼塘号开播20分钟后再进，不要一开播就全涌上来。先进20条鱼，5-10分钟后看数据，拉不动成交就再换一批。最多一场用了近100条鱼。

第五，流量占比。feed推荐占比要尽量保持在90%以上，用白号+鱼配合控制。

这里有一个反直觉的认知：流量不能过度精准。一旦兴趣标签太垂直，流量层级反而会萎缩。W先生会控制游戏领域标签占比在10%左右，甚至不让游戏兴趣进用户标签前三。用这个办法最近起了七八个号，百分之百成功。

数据模型才是决定流量池的关键。用户在直播间的任何动作都算互动，互动率越高，系统给的feed推荐就越高。但直播间的“标签”不是固定的，而是动态的。判断标签是否精准，要看结果转化，而不是表面兴趣标签。如果今天账号刷美女，兴趣标签就是lsp；如果下单美妆，行为标签就变成美妆。所以一切以结果为导向倒推标签。

数据权重排序：成交转化 > 灯牌 > 关注 > 互动 > 停留。新用户的数据权重远高于老用户，所以要用话术引导新用户做动作。

关于鱼塘号，还要提醒一点：鱼只是“公交车”，作用是带节奏和做人气，不能指望鱼塘号精准打标，因为权重不够。好的账号是筛选出来的，做账号有玄学，流量大小不一样，要用账号测流量，流量好的再重用，浪费时间的账号直接弃用。

他们的实际直播数据：单场场观普遍在100在线左右，高的时候150，流量曲线非常平稳。这不是能力不行，而是有意为之。主播的承接能力有限，平稳流量下性价比最高，急速流反而容易接不住。通过匀速投流补量+鱼塘做数据，把流量控制在一个稳定的流速上。

每天单账号播6-9场，单场50分钟。近期流量虽然有所下滑，但平均转粉率3%，加粉团1.5%，注册率1.9%，场观和注册比约60:1。这个转化效率相当能打。

# 八、后端运营：私域精细化与后端团队搭建，锁定留存与充值

项目的长线价值，不只靠前端流量，更靠后端的精细运营。我们把后端团队拆成两个关键角色：GS（行会会长）和聊手，分别负责“玩得爽”和“充得值”。

## GS（行会会长）：让用户留下来、玩进去

GS的核心任务，就是待在游戏里，陪用户玩出感情、玩出黏性。

1. 管好区服，建好行会，让每个行会的人数和战力都相对均衡；
2. 带着用户下地图、刷怪、打对抗，让玩家时刻有事情做；
3. 把用户拉进YY、拉进行会🛰️群，持续跟进互动；
4. 引导用户添加聊手的企业🛰️，完成从游戏内到🛰️生态的衔接。

## 聊手：盯着充值，做好服务式转化

聊手要做的不是硬推销，而是“陪着用户花对钱”。

1. 每天根据后台各区服的充值动态，做好记录和跟进；
2. 针对不同用户推荐合适的充值套餐，教他们怎么花更少、玩更爽，比如装备升级、战力提升这些实用技巧；
3. 用户有问题，第一时间响应解决，把服务做到位。

## 团队管理：渠道分流，把风险和内耗降到最低

很多人好奇，为什么我们连直播间、投流账号甚至后台都要全部拆开？核心逻辑就这几点：

1. **单账号多播**。每个账号每天投流至少1万，通过一天播6到9场（现在已加到12场），配合鱼塘+微付费的打法，把投流时间拉长，让流量更精准，转化自然更高；

2. **做小不做大**。把主播培养成流水线式销售，能复制、够稳定、随时可替代，不被某个大主播绑架。与其赌一个头部，不如养十个腰部；

3. **多直播矩阵**。账号可能限流、违规或封禁，所以直接换号，绝不陷入没流量、没直播间的被动局面，也防止主播之间内耗，灵活性拉满；

4. **减少内耗**。让主播之间保持有效隔离，避免负面情绪聚在一起被放大。每个主播就是一个小组，配运营助理、投流、直播助理，独立后台、独立链接；

5. **风险规避**。后台与链接全部隔开，不放在同一公司主体下，防止流水和注册量太高被同行盯上搞恶意竞争，顺带也能考虑部分税收减免政策。

# 十、我对项目的思考总结

1. 赛道和对手的选择，比什么都重要。普通人真正的机会，往往藏在别人看不到、看不上的角落。大佬们不稀罕的赛道，反而是普通人的主场，甚至能做出降维打击的效果。

2. 做小不做大，要猛，更要持久。有时候保住下限比冲击上限更重要，活着，永远比什么都强。

3. 想都是问题，做才有答案。先完成，再完美，直接干就完了。等什么都准备好再动手，黄花菜都凉了。决定做事前，把最坏的预期想清楚，只要亏损在承受范围内，就果断去试，失败了大不了及时止损。

4. 小老板一定要懂业务，必须亲力亲为待在一线。因为大概率招不到特别强的员工，就算招到了也不一定留得住。要尽量减少员工的思考负担，老板自己多想多做，别对员工抱有过高期待。

5. 现金为王，落袋为安。别只追求规模和数据的漂亮，钱真正进到你口袋里，才算是你的。

6. 生意的本质是利润，流量追求的是获客。曝光和数据背后的虚假繁荣，远远没有结果重要。账号只是工具，不是资产，号没了再起，流量不行就换，别整天纠结账号废了怎么办。
