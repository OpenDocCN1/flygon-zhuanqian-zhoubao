# 从自卑到自信，一名志愿者是如何“改写运势”的？

大家好，我是龙哥。过去两个月里，我接连参与了龙哥盟的八月航海和十月续航，身份是视频号带货Rico团队志愿者。两个21天走下来，最大的感触不是赚了多少钱，而是整个人生状态被彻底点亮了。所以特别想对所有圈友说一句：来龙哥盟，一定要申请一次志愿者，你会看到一个远超预期的自己。

很多人觉得航海的价值是项目变现，可我在这场航行中捞到的“金子”，其实是内在突破。曾经那个躲在角落里、总觉得自己不行的我，现在有了底气，敢肯定自己了；曾经害怕社交、不敢主动的我，居然报名了@Lemon 的线下培训，还争取到了宝贵的直播学习机会。这些变化让我从心态到仪态都焕然一新。当一个人状态对了、眼神亮了，好事自然会被吸引过来——所谓运势，或许就是这么被改写的。

为什么志愿者经历有这么大的能量？答案很简单：志愿者这个身份，本身就是一种强有力的信用背书。它给了我主动加船友、主动找领队聊天的胆量，让我迈出了最艰难的第一步。而一旦跨出去，一连串正向反馈就滚滚而来，好运也跟着降临。

这次航行中，有太多人值得感谢：领队@Rico 的信任和鼓励，让我迅速成长；@凌心 引领我走进了赚钱这个温暖的大家庭；@梁靠谱 始终在陪伴群里为我加油；@理白 的知识输出让我受益良多；@星月 大佬的肯定给了我莫大的动力；还有每一位船员的认可，以及赚钱团队幕后的辛勤付出，我都记在心里。

如果你也对当下的自己不太满意，想看看这些大佬到底给了我多大帮助、我又对他们说了哪些掏心窝的话，那就来围观我的志愿者之旅吧。下一次航海，希望我们结伴同行，一起成为更好的自己。
