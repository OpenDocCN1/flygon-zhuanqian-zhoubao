# ('阅读精华帖的两种思路，你应该用哪种？', (2, 20))

精华帖光读过不算会？两种阅读思路，帮你从“看完就忘”到“学完能用”

不知道你有没有这种感受：每次看到星球有新帖，总会条件反射点进去，边读边觉得“好有道理”，可过一阵子再回想，脑子里只剩一片模糊。越读越焦虑，总觉得自己在做无用功。

其实，问题不在你是不是够认真，而是读法没用对。

我把读精华帖的方法分成了两种：一种横向铺开，专注把一个领域彻底吃透；一种纵向深挖，只取当下最需要的答案。一个像是建房子，先搭好筋骨，再往里面填东西；一个像是翻字典，遇到难题就查一下，解决完就走。

这两种方式并没有谁更高级。如果你正打算系统研究某个方向，或者想在专业领域里继续精进，那横向建体系会更受用；如果你手上已经有项目在跑，或者天生就喜欢“先干起来、不会再说”，那纵向解决问题会更舒服。关键不是二选一，而是看自己在哪个阶段，灵活切换就好。

先说横向铺开。

想真正摸清一个主题，不能东看一篇西看一篇，而是要围绕这个主题，把能找到的信息都扫一遍，弄清楚它底下有哪些知识点、彼此是什么关系。这个动作，叫做主题阅读。

就拿“如何阅读精华帖”来举例。我当时先在生财的搜索框里敲下“精华帖+阅读”，结果一口气出来好多页相关内容，我就一页页翻过去，把看起来和主题有关的帖子都点开扫了一遍。 ![](img/d282b25f63b1e510bcfb9d7737865dec.png)

翻完之后，再把其中真正有价值的那几篇挑出来，存好、反复看。以下就是我当时精挑后的“存货”，你们有空也可以翻翻看。 ![](img/9a162f3ebc4134b247022e4014a76e6d.png)

但如果某个主题在星球里没有现成的系统整理，该怎么办？那就得自己动手来一场“拼图游戏”：先把碎片化的信息大量搜出来，再一块块拼起来，最后形成一套自己能看懂、能复用的内容。

比如我后来做“信息差”专题，就是靠这种方式，把和“信息差”沾边的帖子全翻了一遍，才拼出下面这张完整图谱。 ![](img/6d0cc850067a87e2b8b1ce7e8766e748.png)

这个拼图过程，背后依赖的是结构化思维。篇幅有限，我不展开讲；想深入的话，推荐去微信读书找两本书读：《金字塔原理》和《结构思考力》，都是很好的入门钥匙。 ![](img/dbcde1eb1990ace792845e70847bae56.png)

具体操作也不难。先搜一次“信息差”关键词，把相关帖子全部打开。这里要强烈安利一个浏览器插件——OneTab，它能把你打开的百八十个页面全部收进一个面板，免得电脑卡到怀疑人生。 ![](img/2a0f3e4dc026bb8e9b2cba2f9ec071e8.png)

接下来就分批处理，我习惯一次开20篇。快速浏览，无关的直接关掉，有关的先留着。我记得当时100篇筛完，剩下大约60篇。再进一步，把每篇里面真正说到“信息差”的三五百字挑出来，复制到飞书文档里集中存放。 ![](img/0d0f847e1bcf27fce90ded87f78f7432.png)

内容收完以后，再按照主题把素材归类：讲案例的放一起，讲概念的放一起，讲方法的放一起。 ![](img/e5da4cb5b4758880869dc6f17c706b0f.png)

分好组，接下来就是最见功夫的一步：自己想一个框架，把所有小组串起来。这一步没什么捷径，全靠平时积累的思维模型。我当时正好觉得“道法术器”很贴合，于是就用它当了整套信息差内容的骨架。 ![](img/ceea5488b95cca09c3fd3322df1f9f05.png)

![](img/438795a699ecb2ac310e170c54a68414.png)

这套方法听起来步骤简单，但真正的难点在大量练习。我现在能看几眼就搭出框架，背后是近三年反复处理信息的积累。刚开始做不到不用慌，可以先用三四篇文章配XMind思维导图练手，慢慢来。而且一旦练成，你会发现它不只在读帖时有用，做项目卡壳时，也能帮你更快定位问题。

再来说第二种，纵向解决眼前问题。

这种方法更适合已经在实操中的人。核心就是两个词：查字典、看说明书。

遇到实操性很强的帖子，别把它当“文章”读，而要当“待办清单”用。 ![](img/a2d53e398c3530da9ab2815bc6735c08.png)

比如有人分享一个方法，我不会只看一遍就算了，而是把里面讲到的关键动作拆成一条条 to-do，直接对照着做，一步步走完。 ![](img/287562664e6cab78dbd6725df53636a8.png)

如果你只是在项目里遇到一个小卡点，更不需要通读全文。正确的做法是：先搜出相关帖子，打开后用Ctrl+F定位自己的问题关键词，直接读命中的那一段。 ![](img/54f80678fb6534233f9715ac4e7d9cbf.png)

简而言之：横向阅读练的是思维和体系，纵向阅读解决的是当下的实际问题。我自己做项目时，两种方法常常交叉使用。希望这篇分享，也能给你带来一点新的启发。 ![](img/1c37d505930596d12a88ab23e11aa07a.png)
