# 公众号爆文自动化流程极致提效全解秘

先自我介绍下，我是JsonChao。今年4月初，我才正式加入赚钱这个圈子。在此之前，我已有几年写技术公众号和成长类文章的经历，也因此对公众号爆文项目格外有好感。在把赚钱里的多个项目横向对比之后，我锁定了公众号爆文，决定在这里长期深耕。

真正迈出第一步是在6月14日，我发布了第一篇情感类内容。到10月30日为止，刚好四个多月。整个过程被我拆成了四个阶段，每个阶段的玩法和收获都不太一样。

6月14日到8月5日，我只守住一个情感大号，每天雷打不动更新一篇，一个多月下来收益做到了3000多。

8月6日到9月10日，我开始把盘子铺大，同时打理11个情感号，每天都要写不少稿子。坦白讲，那阵子相当折腾，可最后只有3个号进入流量池，收益依旧维持在3000以上。

9月2日到10月3日，我又切换成多领域、多矩阵的打法。巅峰时期，我同时运转着8个领域里的26个账号，最终有16个号成功入池，这个阶段累计收益达到2.5万+。

10月4日到10月29日，我做了新一轮收缩和聚焦：从8个领域里挑出收益最好的2个核心领域，保留6个成熟老号，再新增24个新号，账号总数拉到30个。那些收益越走越低的领域，我直接停更，不再消耗精力。这波操作下来，总收益冲到8万以上。

这几个月积累下来的自动化流程，我都整理成了完整文档，还配了各类提效脚本，放在飞书里，排版体验会更好，有需要的朋友可以直接点开看：https://iv8irdz7945.feishu.cn/docx/C8Dmd7AYwoeGv1x2RkkcF06Rnuc?from=from_copylink
