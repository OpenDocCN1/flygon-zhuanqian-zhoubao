# 95 后女生在二线小镇做包租婆，2 个月拿房 20 套实现睡后收入
作者：龙哥

有一位95后女生，在二线小城当起了“收租婆”，短短两个月就签下20套房，靠租金实现了“睡后收入”！  

没错，这就是她的副业故事。她把整套经验整理成了一份飞书文档，名字叫《二房东入坑手册》，专门分享给想试试这条路的人，希望能帮大家打开一点思路。  

她特别感谢了《搞钱女孩》主理人陈雪，说是听了那档播客节目才加入了赚钱圈子，也感谢赚钱这个平台给了她机会。  

如果你也想了解怎么从小白做起，一步步拿下房源、运营出租，这份手册确实值得一看。
