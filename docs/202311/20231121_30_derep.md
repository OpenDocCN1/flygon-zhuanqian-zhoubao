# 视频号直播，怎么利用手机做摄像头进行直播？

你是不是也受够了电脑自带摄像头的渣画质？每次准备开播，一看到模糊的画面瞬间就没了心情。其实，你手里那台手机完全可以派上大用场，成为你的高清摄像头！今天这篇保姆级教程，就带你一步步搞定视频号直播画质升级，包教包会。

首先，你只需要准备一台 Windows 电脑和一部手机，硬件门槛非常低。

第一步，在手机上下载“无他相机”。注意，一定要认准官方图标，别下载成别的奇怪版本。![](img/42553ee5daba390fe270bb1aec182ef7.png)装好后打开 App，点击“立即使用”。![](img/ac60b393a5efa05116eb93de2e3bc571.png)

第二步，到电脑上操作。打开浏览器访问无他伴侣官网（www.wuta-cam.com）下载安装。![](img/309407ab6dad7e27197d93063cb0894d.png)装好以后打开软件，再用数据线把手机和电脑连起来。正常情况下，连接成功时界面会立刻有响应，就像下图这样，整个过程非常轻松。![](img/52e65f42df72d07ed0e513f08d6e0a77.png)

不过确实有很多人在这一步卡住了，手机插上电脑却毫无反应。别慌，原因一般逃不出这几种：

· 苹果手机用户少了 iTunes 驱动。插上手机后电脑如果弹出提示，跟着步骤装一个就行。
· 安卓手机用户没有打开开发者模式的“USB 调试”。去系统设置里找到开发者选项，把 USB 调试开关打开即可。
· 数据线接触不良。这种情况也很常见，换一根能传数据的数据线就能解决。

如果还是连不上，可以去无他官方帮助站点查看详细视频教程：articles.wuta-cam.com/activity/community-activity/index.html#/helper

当电脑和手机顺利连接后，点击软件里的“同步”按钮，你的手机就正式变身摄像头啦。你会发现，只要轻轻转动手机，电脑端预览画面就会同步跟随，几乎零延迟，效果特别棒。![](img/862143b5d7524d4d6b61424966072d00.png)![](img/098623351d5f3f0c71493c538a4d255b.png)

看到这里，恭喜你，摄像头改造计划已经完成！![](img/0c2c38e4d1e37b5add5782f2d49d7f57.png)

接下来就是最关键的一步：如何把它接入视频号直播？操作依然很简单：

打开🛰️，进入视频号直播界面，在摄像头来源列表中选择“无他伴侣（竖屏）”。![](img/2895562d194b1c0c2d6bc3a2587a9c28.png)![](img/e4433478f55bdc6379045e7be12f4a3e.png)选好后，直播画面直接就变成手机镜头的高清视角了，是不是格外简单？![](img/7f3d8201c771dc3210424806012977ba.png)

最后补充一个小彩蛋：有朋友在评论区问能不能用绿幕，答案是当然可以，不过需要搭配 OBS 使用，并且要开通无他相机的会员才能启用绿幕功能。也有人提到“直播加加”这个工具也能实现手机直播，感兴趣的话不妨多试试。![](img/1c37d505930596d12a88ab23e11aa07a.png)

这就是今天的全部教程，希望每位主播都能拥有漂亮清爽的直播画面！
