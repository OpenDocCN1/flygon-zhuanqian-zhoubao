# 闲鱼小赛道四个月变现利润 70 万技巧分享

在绝大多数人挤破头冲向抖音、快手、视频号和📕的时候，有个 00 后却悄悄掉头，钻进了一个“小赛道”，四个月净赚 70 万——他叫瑜大，在成都运营一家电商公司，互联网创业已经有 6 年。

说出来你可能不信，今年 3 月之前，他对电商几乎一窍不通，只模模糊糊听人讲过，早几年闲鱼红利期有人赚到了第一桶金。可当时身边所有人都在喊“抖快视红”才是主流，他也跟着冲了进去。结果呢？大风口反复折腾了两年，直播一直做不出成绩，直接被筛了下来。

但瑜大不信命。他说：普通人也能翻身。既然大风口跑不通，那就换个跑道试试。于是他离开拥挤的直播赛道，转战闲鱼的小众垂直领域，没想到这一转，还真让他跑通了——四个月，利润突破 70 万。

他把自己的玩法沉淀成一套可复制的打法，核心就两个字：选品。不追求爆款满天飞，而是聚焦细分需求，深耕单点，然后批量复制。

有朋友问他：为什么不回去做微商？他的回答很干脆：微商时代已经过去了，人要顺着趋势走。
