# 《四个月闲鱼小赛道撬动70万利润，我的复盘笔记》
作者：龙哥



# 先说我是谁

嗨，我是龙哥。00后，互联网里摸爬滚打快6年了。17岁那年我带着微商品牌起盘，带过万人团队，也自己操盘过品牌出货。2020年疫情期间我放弃了985的学籍，出来搞直播公司。21-22年在广州开了家5000平的直播基地，因为战略认知跟不上，项目收尾了，庆幸的是没有背负债务，手里只剩3k生活费。到今年我重新起盘靠闲鱼站稳了脚跟，这次把从谷底爬起来的做法和心路历程摊开来讲。

上次发的干货信息量太大没细讲，这次我尽量把经历、操作和心态拆开说，希望能给正在路上的朋友一点参考。

# 7个月的数据复盘

![](img/e97991e6ada98327a0eaef5106335b50.png)

![](img/5681b4f4d5d50067ecca7c1fd1a793c1.png)

2月份直播公司刚关，我零基础一个人去试探电商。白天在阿道夫公司做运营养活自己，晚上下班就钻闲鱼去摸规律。算到现在，账户上清算下来的净利润接近70万，11月初准备搬进新的办公场地，再小规模扩张继续放量。

低谷也来过。红薯无货源、航海号、视频号短视频、抖店商品卡，我都试过，最后都没跑通。样品费把仅剩的生活费烧掉了一半。总结一句话：赛道太拥挤。三月上旬我彻底陷入自我怀疑。18年到23年我经历过不少风光时刻，这次却像被按住后背，没人扶一把，跟过街老鼠一样人人躲。

说不难受是假的。车都卖了，能贬的资产基本都处理了。可越是拧巴，越磨出定力。我变得更稳、更波澜不惊。回头看像坐过山车，我不知道下一秒是什么，但我有一颗不死的心，时刻准备着迎击。

# 阶段一：从零到月利润1万+是怎么打出来的

### 1. 别空想，先上手

我觉得闲鱼的入门门槛比别的平台低，通过朋友口口相传我决定自己试水。刚开始完全不懂规则，在2-3月翻平台的时候，注意到C端二手相机在热搜榜上很活跃。结合之前几年的沉淀，我的直觉告诉我这条线能做。

![](img/3b16c1585b58d50253a779b8dece5dc3.png)

![](img/9bee552fc51733a055eee1961227918c.png)

起初在1688上找货量很小，售价和我的拿货价只差20-50块。拼多多上也看了几十家，怕被套路不敢给联系方式，也没人愿意一件代发。聊了20多家后，终于找到一家能代发的供货方。

### 2. 站在别人的肩膀上跑更快

我对闲鱼一无所知，就去筛同行里成绩不错、好评高的账号做对标。头像、昵称、背景图、个性签名，全部1:1借鉴。相信她能成，我一个外行也能复制60%的成功，这对我的电商认知是质的提升。

![](img/5dc7c0c128febd18ba9cac28c1ab8263.png)

### 3. 舒适区是增量的敌人

按同行模板起步后，咨询和下单开始进来。但相机单品利润也就一两百，闲鱼虽然流量大，可毕竟是二手定位。每天大把时间耗在聊天上，成交也就十几单。平台没法像抖音快手那样投流放量，野心达不到。

按这个节奏，全职月入1万左右是可行的，也算小白毕业。但我不想停。于是开始找高利润的盘子，想办法批量扩号、提升投入产出比。在新的舒适区里我选择继续奔跑。

# 阶段二：从月入1万到月入3.5万的增量逻辑

我只抓住两点：

1. 找到利润更高的品类，让同样的时间产生更大产出。
2. 批量开号复制。经历过那么多风口，我清楚风口不会常在，早执行一天就多赚一天。大钱不是月月赚，是波波赚的。这也为后面公司化复制埋下伏笔。

![](img/56af83132ac837f5097e839f5c67ffc5.png)

![](img/d822c1691b412649577e651c39c5a640.png)

这是我作为闲鱼小白的第一个起盘周期。之后用同样方法筛了新品类，先是投影仪，后面转到笔记本电脑，逐步放量到现在。

# 1. 选品别按常规打法走

1688和拼多多的价格优势并不明显。转投影仪阶段后，我换了思路。

细节做法：先在1688和拼多多上批量私聊供应商，但线上报价难以达到我想要的利润空间。

第一步，筛选综合评分靠谱的厂家。很多厂家要么爱答不理，要么不让利，最终挑出态度积极、实力过关的。

第二步，合作前看发货地。大数据一查就知道，比如苹果手机的核心产地是深圳、广州。如果一家号称源头的厂家发货地在苏州，就要警惕是否二道贩子。环节越少，利润水分越少。

第三步，让对方看到诚意和结果。底线是有一定出单量，能朋友身份约厂家见面吃饭。线下一次比线上聊一万次都管用。跟厂家熟了，认识了更多数码厂家的圈子，后面笔记本电脑和超性价比的苹果手机盘子就是这样沉淀下来的。

# 2. 货盘+老板社交的关键变量

我用真诚、大方、善良、大格局、懂感恩的态度去经营关系，被厂家和比我更厉害的大佬赏识。过节送礼，4月去澳门、3月去惠州，每到一处都买当地特产寄给供应商和给我指点过的朋友。特产我自己基本没吃，钱都用来买子弹扩盘。虽然第一笔利润不多，但我愿意拿三分之一来做链接和学习。

起初他们没把我放在眼里，后来主动帮我牵线更优质的货盘。

总结：想往上走，就要有魄力、肯低头、会感恩、沉得住气，时刻清楚自己要什么。

# 3. 从1个号到七八个号的注意事项

1. 账号问题：闲鱼提现走支付宝，必须保证能收钱的支付宝。扩号期间我曾用别人的号收款，自己垫资，结果被卷走6000块货款。所以账号一定要用亲戚或绝对可靠的人。个人操作5-8个号是可控范围。
2. 设备问题：建议用iPhone操作，流畅且好批量管理。不必买太贵的，iPhone 7plus目前成本价约530元即可。一机一卡。

![](img/b38264ec7a818e07dda3478771ea9de0.png)

3. 数据管理：运营账号不能凭感觉。每日我都会做表记录波动，肉眼能看到的退步和进步，问题已经比较严重了。现在团队里线上100人、线下20多人，都在坚持每日记录，坚持下来效果非常明显。

![](img/7ab226fd30a86ae02bfc99567eb5afb9.png)

# 阶段三：从个人到团队，月收益冲到10万左右的核心

之前广州5000平直播基地失败后，我花了很长时间复盘，也去大公司上班、学习案例。明白一个道理：胆大很重要，但投入产出比跟不上时，还得一步一个脚印。

我先用5个号测试，一个月做到3.5万。随后复制矩阵，前期招了3个人，4月时个人收益仍占大头，因为新人上手慢。员工去工资后净赚1.3万，我自己3万多，当月总利润4.3万。没气馁，我知道这是上升趋势。第2个月员工产出提升，再招3个新人老带新，一直滚到现在。

一个人走得快，一群人走得远。请人的前提是自己的方法稳定了再扩，前期带人很累，培养出三角结构后就省心了。团队管理我融合了微商团队和直播基地的管理模式，这里就不展开，后续会单独写一篇。

# 阶段四：真正的大收益来自哪里

### 归根结底是货盘利润，其次是玩法细节，再是复制和群店管理

## 选品和好货盘是翻盘根本

### 大部分人会踩的坑：

1. 无货源模式。对接各种货盘以为越多越好。我也跑过，无货源即便好做也是昙花一现。运气好赚几千几万，运气不好一天累死赚几百，持续几个月半死不活，信心会被摧毁。

我不喜欢短暂的昙花，更爱细水长流的深耕。
1. 不被大平台认可的小赛道；
2. 利润无法深挖，投入产出比上不去；
3. 不稳定，带团队航海风险太大。

2. 多类目乱铺。大家都急着赚钱，我也测试过。一个号上架很多类目，和一个号垂直一个板块测试一个月，结果完全不同。

多类目账号流量再大也很难做到几十万级爆量，而垂直账号每周都能出一两条破几十万曝光、咨询上千的帖子。现在我的每个号都是精准垂直，平台也会更精准地推对应流量。我测试了十几个号，只要垂直精细做，一个月至少能有一条几十万曝光的波段。

想做高利润，就要垂直做、精细做。

3. 不算投入产出比，只会埋头干。前期我也选过几十块利润的货，以为大众喜欢就会好卖。

测试过蓝牙耳机、相机、冰箱、风扇、文具、虚拟商品、高仿表、高仿服饰鞋包等，不是利润太低就是咨询量少。

东西能卖，但一个号最多十几单，一个月大部分时间平淡，50单*50元=2500元。即便批量复制，利润也很薄，不如一个人单干。团队和时间耗不起。电商无根基，别想赚一辈子，要在有限时间内创造最大收益。

我静下心筛盘子，锁定笔记本电脑和iPhone 14/15，这两个利润相对可观，都是厂家介绍的。

### 笔记本电脑：大学生入学、毕业、实习的刚需，年年都是稳定饭碗。单台保底利润500-1000元，客单价2000元，投入产出比马上起来。目前已是该类目Top榜单，回款周期3-4天，资金快速回笼。

### 全新苹果手机

第三阶段的一单利润约1200-2000元，一个号一天可出10台，单号日利润稳定1w。厂家给到绝对价格优势，爆量很猛，公司账号都不敢放量操作。资金回款闭环也在完善中。

前提是要准备7-15天出货量的资金，覆盖客户收货周期和大爆风险。我测了4个号，咨询量和流量都很可观，价格优势让客户下单很爽快。

苹果品牌多年控价严格，是数码界的硬通货，降价不会崩盘，目前风险在我可承受范围内。

# 给还没跑通的朋友五句话

1. 一步一个脚印坚持深耕
万事靠坚持。上次分享后很多朋友来找我交流。很多人失败案例里都一样：信息时代钩子太多，捡了芝麻丢了西瓜。选定一条路，就埋头干，别左顾右盼。

2. 抛弃易碎的心态
做了一周没结果就抱怨放弃，不复盘原因，只怪项目不怪自己，这样的心态很难有好结果。

我的座右铭用了六年：‘凡事杀不死我的，必将使我更强大。’面对挫折不要逃避，正面迎战，把它塑造成更强大的自己。

3. 选对路比瞎干一万倍有效
大家都努力，但要努力有方向。判断项目能否做的标准：
从利益看：值不值得做
从风险看：要不要赌
从能力看：能不能干
从结果看：划不划算

4. 永远摆正发心
无论困难还是规模上涨，心态会摇摆，但发心要稳。我对客户、厂家、员工、合作伙伴，一直想的是我能为他带来什么。

一个人能走多远，靠的不是眼睛，认知有限。最大的自私是无私，立利他之心，行利他之事，好的事物自然会向你靠拢。

最后，真的很感恩能在这里认识大家。平台让我认知升级，也遇到很多贵人。欢迎做电商的朋友一起交流，我们互相进步，我知无不言。
