# 一、得物好物种草的变现逻辑有三条

## 1.挂赏金链接做种草

只要商品挂上赏金链接，有人通过点击下单你就能分佣。0粉就能挂，这是得物最友好的地方，其他平台往往要粉丝门槛。来看下种草赏金的规则。

![](img/2ec24ca5ce6394f14d7ad769c8665bb0.png)

我现在发的多是低价品，佣金不算高，主要还是靠商单。但赏金也是实打实的收入，单条动态同时赚佣金和商单费，奶茶早餐钱就出来了。看看我们上一期学员的赏金。

![](img/91aefea25022230d58944592bd05652c.png)

这份是她在做得物十天内的赏金，带的是一个轻奢小包。图一出来还没开始接商单，浏览量就过万了。数据好之后，很容易被商家主动邀请定向合作，佣金自然更高。

## 2.百粉入驻引力平台接商单

达到标准就能申请入驻，拿到产品+广告费。粉丝上去后，平台会主动推单，商家也会来定向邀约，单价更高。

看下部分合作记录。

![](img/997250e1d434c417c5e466d122fefe10.png)

百粉阶段的稿费确实不高，但百粉很容易达成，而且商品基本都是置换。能用就自用，等于白嫖日常用品；用不上闲鱼一转手也是钱。搭档意儿兼职一周就破百，我带娃带课挤时间大概十天破百，每天花在得物上不超过半小时。营里最快的三四天就达标了，只要照着新手课做，开通品牌合作权限基本没问题。

过500粉后合作层级就变了，单价和选择更多。过1000粉更上一层，能接到不少商家主动邀约的定向单，几百到几千都有。

## 3.视频号分成

一个月内发4条20秒以上的视频，总播放破1000就能开通创作分成。模式和别的平台类似，在得物也很常见。

![](img/291ac75ad165656e8514d047eebec74f.png)

我们的核心课主要讲好物种草变现。以上三种是常见路径，还有进阶玩法可以慢慢解锁。

我并不承诺你进来就月入过万，那不现实。合理预期是，快速涨到一百多粉，在得物赚点零花钱，实现日用品自由，还是很容易的。持续深耕，月入几千也不是没可能。

# 二、百粉怎么快点达成

纯靠种草自然涨粉比较慢。我遇到过做女性成长图文、文案号的学员，粉涨到一百多却申请不过引力平台，或者入驻了也接不到单。

得物是购物平台，商家找达人投放，会先看主页有没有种草内容。主页如果全是无关内容，商家大概率不会考虑。

所以新手需要点启动技巧。

## 1.精准互粉

去搜“得物赚钱”话题，看评论区大家怎么做就跟着做。

![](img/cc0b542c76a34f9f86b958c80a1770fd.png)

注意节奏，不要一次性点太多，也不要秒关。建议先进主页浏览、点赞，再关注，模拟真实用户行为，不然容易触发风控。不要自己发互粉动态，新手操作不当很容易违规。

## 2.内容混发

纯种草起号难，可以先发点女性成长、自律、文案类的图文，这类内容涨粉快。起号期混着发，等过百粉再以好物为主。这样申请入驻和接单都更顺利。

提醒一点，得物对内容质量要求很严，严禁搬运，跨平台搬运也容易被判定低质。违规多次会影响账号健康，轻则封单，重则封号。

# 三、官方也在扶持新人

目前没有哪个平台像得物这样对新人友好。官方会办萌新训练营，手把手教运营，还会给流量扶持和大额无门槛券，直接0元购。营里的学员不少都拿到过。

![](img/57b6bff8f592814200ec966d9e39dec0.png)

![](img/caad880295fd45a86b9b72e02df42207.png)

88元、100元无门槛券是真给的，还有流量券助推。我搭档意儿多次0元购，我自己佛系操作也有两次。

怎么进训练营？一种是正常发优质原创，账号健康，官方会主动拉你进群。另一种是去官方账号的招募帖下报名，官方会筛选潜力作者。并非人人都能进，需要无违规、内容优质等条件。

先看下百粉后能申请的合作页。

![](img/b73ce4ac7f89218697cb001da05265db.png)

觉得能完成的都可以点报名申请，品牌方审核通过后会有置换或稿费+置换。如果你手里已有产品，还能接复投单，拍一套图再发一次，再赚一次。

前期申请可能不顺，有些同学投了二十几个才过。原因多是内容和商家要求不匹配，比如展示不够丰富、文案不够真实。这时可以先接置换单练手，熟悉商家诉求，再去冲有稿费的单，成功率会高很多。
