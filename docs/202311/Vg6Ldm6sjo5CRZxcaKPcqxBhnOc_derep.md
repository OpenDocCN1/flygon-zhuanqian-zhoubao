# 别把年会当成行政任务：一次操盘，把人心盘活，明年自然爆发



距离年末还有大概两个月，市面上一片年会筹备声。不少创始人把这件事直接甩给行政，自己只打算年关露面颁个奖就走，实则把全年最好的情绪收口机会拱手让人。年会一年一回，是老板真正能站C位、把团队情绪拧成一股绳的时刻。必须亲自挂帅，把时间精力押上去。

大家好，我是昊布斯，坐落在西安，做企业展厅及展示工程。今天就以我公司2019年的那场年会为例，拆解老板如何用一场年会把氛围点燃、把信任买下，让团队来年直接开足马力。

# 一、先让工作变有劲，精神盘子托起来

为什么年终奖刚发完人就离职？为什么你花大钱包下豪华酒店、海鲜大餐、抽奖环节，老板自己嗨到朋友圈刷屏，员工动态却一片空白？

你在大群里说“兄弟们今天开心，我请大家喝酒”，员工回你“好的”，心里想的是“操，又得陪老板吃饭，今天回不去了”。把本想打的“妈的”删掉改成“好的”那一刻，裂缝就出来了。

薪酬不等于只有工资。薪是钱，酬是感受。缺钱加缺感受，双缺都走。谈恋爱时女孩常说要么给钱要么给爱要么滚，带人也一样。入职期缺钱，后期缺感觉。

马云那句老话：员工离开无非两点，钱没给够，心里不爽。上期讲了年终奖的发法，那是薪的部分；这次讲年会，这个年度复盘节点，如何把精神部分撑起来。

总有人抱怨“员工没精神”，先照照自己。老板一天阴沉，员工早上满血来上班，一看到老板那张脸也蔫了。因为老板心情差，自己开心反而像挑衅，于是集体低气压。整个公司像活死人墓。

反过来，老板每天状态满格。外界传公司下月要完，员工私下议论“我看老板不像啊，真要完了老板早慌了，老板这么稳肯定有事”。状态就是定心丸，可以稳住军心。

![](img/d382f2f86667c7fe333bf515a86391b7.png)

看一张照片，女扮男装。阿里八周年，马云扮白雪公主，七位高管扮小矮人上台献艺。员工一看，老板都疯了，我们还不跟上？马化腾低调的形象大家都知道，年会上却能直接上台跳舞。有人说腾讯年会让我去一次不要工资，免费干一年都愿意。快乐的公司味就这样。

微软最辉煌时，年会召集全球三万销售到夏威夷。台上三人戴面具，一个高一个瘦一个胖，跳踢踏舞跳得稀烂，下面员工吐槽“公司是不是经费紧张，找这三个二把刀演”。面具一揭，是比尔盖茨、鲍尔默和CFO。全场炸裂。

钱是玩出来的，生意也是玩出来的。来星球是来学还是来玩？来学就得悬梁刺股，来玩状态自然就上来了。打游戏快通关时必出BOSS，越难打说明越接近胜利。用玩的心态面对挑战，人生才乐观。公司保持玩的氛围，人自然绽放，结果自然跟上。

# 二、会前一个月先做人

年会前一个月，别只忙着给客户送礼。我连续开车跑了几百公里上门拜访员工家里，远的打视频拜年加微信。

![](img/3b4955c89d327d8af8afe457bed5a10e.png)

![](img/4afa4dc0aba3175d20d858905b3af621.png)

企业做大不是老板一人扛。客户是员工在服务，老板时间精力有限。老板亲自服务，要么服务不完，要么做不大。最后结果只有一个，企业消失。

![](img/70fcd4857d2b4ccb877ef613ffc32ae8.png)

![](img/1213d53d4bbe39d06d72c61b8e37e6bd.png)

员工父母多是普通农民，从没见过老板上门。早早在路口等着迎进来，沏茶倒水。聊孩子往事，问在公司表现，还让老板多严格点。他们明白，能上门的孩子是被器重的，笑得合不拢嘴。

![](img/9cb6caae66e5c63ced91a7358c10e5f0.png)

![](img/ba91abab5a29c478d858287c30425ab0.png)

父母皱纹里藏着生活的难。有的在西安工地做活，有的在县城工厂上班，辛苦钱。家里突发疾病，买房的钱都花了。钱这么难挣，家里最缺的是钱，但父母从未提多挣钱，只希望孩子多学点、平平安安、日子好过。

父母是孩子的镜子。父母开朗孩子爱笑，父母内敛孩子话少。无论怎样，都是最爱最无私的。

以前不懂新闻联播里领导为什么要下基层，家访后懂了。朱门酒肉臭，路有冻死骨。了解基层疾苦才能担大任，了解员工生活才能扛起公司使命。我的肩膀更重了，承着几十个员工背后几十个家庭的期待，甚至几百个家庭的未来。

没有业绩翻倍，哪来的身心自由。公司做到一百萬，就有一百万的事；一千万就有一千万的事。做大了不觉得累，做不好一人公司也心力交瘁。修身齐家治国平天下，事业靠团队，所以先照顾好人。

家访时我做了一件秘密事，为每位员工父母录一段视频，让他们对孩子说心里话、祝福、来年期望。外地的让自己录发给我。他们没录过这种视频，真诚中带着羞涩，结尾几乎都说“孩子跟着这样的老板有福气，好好干”。父母一句话，顶老板千句。

全程保密，请父母不要告诉孩子。剪辑成一个长片，前半段造氛围，后半段全是祝福，泪点拉满。想感受的可以去找找感觉。

再说个误区。很多老板觉得年会就是给几天排练时间，员工表演节目，领导鼓掌。员工心里想凭什么付表演费？你想聚人心，就得走进群众。

前面那些大佬，节目必须老板先上，身先士卒。所以我这次定调Cosplay，在某宝买了埃及法老装，每人一套。行政对接节目单，我参与的节目一起设计排练。

小米《参与感》鼓励每个员工用户成为产品代言人。内容运营要遵循有用、情感、互动，避免信息过载。年会同理。行政提前为每人录一段话，年会开场播放。

素材积累极重要！每年都有新人，不了解老板和公司。把这一年里大家手机里有趣有意义的瞬间剪出来，新人更立体，老员工更归属。

## 3、老板讲话
![](img/094534c758c40c9812da33fdcc2fa33d.png)
致辞定全场基调，别套模板，要讲内心独白。我的稿子供参考：

尊敬的各位领导、各位来宾、家人们、新老朋友，大家晚上好！

百忙之中来参加轻屋年终盛宴，再次以热烈掌声欢迎，谢谢你们！

转眼走过2018，即将迎来2019。看着同事从稚嫩到成熟，从陌生到一家人。争执、分歧、感动、互助，每一段成长我都记得。虽然平时交流不多，我却一直感恩。因为有你们添砖加瓦轻屋才走到今天。感谢长期支持、理解与辛苦付出。

昨天听马云在达沃斯的讲话，发现我们和阿里有共同点。我们团队初期也不多、地方不大、凝聚力极强。我们和马云爸爸英文都好、个子不高、爱学习，具备成为伟大企业的起点了，大家说对吗？

工作中我有不足，但和各位一样，有迎难而上的拼搏精神。昨晚两点我还在想，坚持这家公司的目的是什么？当年是一个人的梦想，对生命的不甘平凡。创业路上也在不断成长。借着年会，分享2019轻屋两大发展方向。

第一，成就员工。玩才能开心，开心才能提效，效率上去钱自然来。2019年让大家玩得更开心，把工作变成游戏，增加团建，提升幸福感！过去因能力不足不断邀请优秀者加入，也在照镜子揪头发反思。去苏州重庆八次花40万学管理打造学习型团队，还不够。真正的成就，是你中有我我中有你，敢于要求你成长，助你晋升合伙人、股东、成为一辈子抱团前行的一家人！

2019年我和总经理张改滔目标是培养晋升3-5位业绩达标者，拿到买车买房基金，一起抱团发展。大家加油！

对未达标伙伴，公司已导入季度递增式激励薪酬机制。在公司框架下业绩上升，股东分利润给你共享，目标全员收入稳定增30-50%。公司成就大家，大家成就公司，对不对？

第二，对外成就客户。

公司使命：用科技让地产营销更轻松

愿景：成为世界第一名的地产科技产品开发公司

价值观：客户第一、诚实守信、团队合作、结果为王、迎接变化、积极向上

因战略失误2018走了弯路，向大家道歉，鞠躬。及时纠偏，二年后重新定义使命愿景价值观，这是大家智慧。给这么优秀的自己鼓掌。

2018年4位销售创造1600万营业额，2019年销售要达20人以上，目标保底4000万冲刺6000万。创业坎坷，只有用心服务让客户持续满意并尖叫，客户才持续掏钱。做好服务先感动自己，感动自己才能感动别人。持续经营客户的内疚感，让客户一直欠你，就能在下行周期再创佳绩。

老板思维是企业天花板，我正意识到，已持续学习，也会带优秀中层去学习，看外面的世界、激烈竞争，边玩边学边赚钱，一起成长，把前沿理念产品带回，让业绩不断突破，给团队不断创造价值。我们一起打造属于大家的时代，你们愿意吗？

# 四、收尾
年会操盘只是管理系统工程的一环。就像五行对应五脏，金木水火土对应心肝脾肺肾，治一个器官要调全局。肝出问题可能是胆的问题，就是肝胆相照。经营公司亦同，别头痛医头。

说到薪酬，很多老板第一反应就是涨一点、调一点，但真相往往没那么简单。

企业里一旦出现薪酬相关的矛盾，背后牵扯的未必是钱本身，更多时候是股权分配不清晰、人和用不好、架构搭得乱、晋升路走不通这些系统性问题。单点去修，治标不治本，只有把整体盘清楚，才能对症下药。

关于这些更深层的拆解打法，我在知识星球『不懂股权 别当老板』里做了系统分享，后续也会择优在赚钱这边同步出来。

如果你正被股权薪酬设计、企业管理上的难题卡住，欢迎来找我聊聊。

祝各位圈友不只会赚钱，更要会做有格局的生意。
