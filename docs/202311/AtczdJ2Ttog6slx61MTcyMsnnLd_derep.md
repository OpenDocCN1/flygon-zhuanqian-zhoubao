# 📕电商系列细节篇
作者：龙哥

趁着这周事情少一点，赶紧把卖货系列接着写。之前聊过两回，今天换些新角度，把几个容易被忽略但直接影响结果的要点，一次说透。

先简单报下成绩。短视频那边做直播带货，个人加合作账号，累计成交额已经超过三千万。今年五月进入小红薯卖货，现在有三款货的矩阵各自破了百万，十万级小手笔也攒了好些。今天的内容分五块：售价怎么定、帖子怎么发、号群怎么配合、彩蛋玩法怎么用、指标怎么读。

先说售价。很多人觉得卖多少钱无非是看别人卖多少，抄就行。真不是这样。上个月我们打爆的一款货，累计走了一万两千多件。十月一号从平台自带的选品工具里发现它，立刻用三个号铺开测试，很快出了一些单，也确认需求存在，就迅速加预算。 ![](img/63c71fc608512abb917ade05b236b785.png) 但随后的几天数据一直温，很多同行就放弃了。我看货还能继续走、流量不差，需求又扎实，加上别的平台已经热起来，全网眼看要断货，值得再赌一把。于是十月六号做了个决定：所有打这款的人，统一把标价压到九块九起跑。 ![](img/b3e28580078629a3ce393837162eccc2.png) 改完以后数据马上起飞，十月十六号单日干到三千件。 ![](img/e02277bafe9ca310eebc176d3467abf7.png)

最后能赢，一是封面强，二是发现流量没换成订单后，立刻做出价格调整。同期也有账号流量不错，硬是撑着原价不肯动，结果全废了。

所以定价不是一味便宜，而是随情况快速调。毛利再高卖不掉也没用；只要出量，供应商后面自然会降，号稳住了，后面利润反而更宽。

关于定价有两个典型误区。

第一，看到这个平台的用户舍得花钱，就把价标得老高。我们打品的时候，看到过很多初始流量比我们好得多的帖，就是不出单，点进一看标价，简直把用户当冤大头。用户消费实力强，是说你的货和文案够好时，他愿意出更好的价，不代表随意一件烂货也能卖得贵。

第二，直接搬其它平台的定价，不做灵活调整。抄爆款价位本身不会错太多，但还得看目前爆到什么程度、同行怎么在打、自己转化如何。

具体怎么定，建议这样来。

先让价格合乎常理。能卖九块九的就别卖十块九，多一块钱可能劝退一堆人。再守住毛利，尽量维持在25%以上，平台会在累计成交额破万后收取5%的手续费。除非货特别能走量，否则太薄没必要做。然后参考平台上的竞争状态。如果这个平台还搜不到那款货，可以参考其它平台卖价，甚至略微上浮，但要小心别被人用低价把客源截走。如果平台上已经有人打爆，你新进去，价格最好比对方低一点，前面不必太在乎几块利润，先把单量和评价堆起来。如果平台上价格很乱，九块九和二十九块九都有，先看两边的打法是不是一样，粉丝基数差多少，品牌自营店除外。有人靠名人出镜把货卖到高价位，你只会素材剪辑，就学不了。如果两边打法近似，建议从九块九切入，等量起来后再慢慢提价。

折扣券是个好东西。它能在价格上画一道线，让人产生捡到便宜的感觉。我们实测过，用来提高成交很有效。用法有两个细节。一是上架价标得高些。比如进价五块，预期卖九块九，上架标十五块九，再设一张六元券。以后想涨价，不用动页面标价，只要调券的面额。想卖十二块九，就把券改成三元。所以从上架前就要想清目标价和最低能接受多少。二是用单款专用的券，之后款多也不会搞乱。 ![](img/350fcb83bc3761111557c4f7b2f3070b.png)

规格组合也必须重视，单价低的产品尤其受益。比如某款货进价五块，两件装大概能谈到六块五。如果是讲颜值的货，像抓夹，一件九块九，两件十五块九。很多人愿意买两件，但两件一模一样又劝退。那就把两件装做成同风格不同花色，我们实际测试中，超过一半的人会选两件装。如果是功能型产品，用户冲的是用途，那就只能把多件装优惠力度拉大，并在主推规格上标“火”“划算”，诱导点击。这样连单毛利都不差，但一定要让主推组合显得最划算。

再讲发帖上的细节。

挂购买链接时，如果货有好几个规格，选最便宜那档展示。帖子页面亮出的是你选的价格，低价更容易让人点进来。 ![](img/7a24fcf26ff5203df3641cbdf089caa5.png) 另外，货品后台的留言引导开关要打开，并填上一句合适的话。一来能放营销文案，二来开启后系统会自动带“同款购买”四个字。留言量也会因此增大，又进一步拉高内容热度。具体写什么，最好参考同行的表达和自己的卖点。像“留言领彩蛋券”这种话，就会有人跟着留评。

发布入口也有区别。常见的是首页加号，另外还有两个入口能拿到一些额外曝光，虽然不多，但对新号很值。一个在创作者后台的灵感话题，随便选个话题发；一个在商家后台的热搜词广场，挑自己相关的主题发。 ![](img/023aa8e7767d2de63eccb6cdc049d096.png) 平台官方活动也要跟，双十一期间挂话题后官方给的流量非常可观。双十二就在眼前，要提前备好内容。 ![](img/a9ec7607a3ecfd18beb8aac342970d1a.png) 只要帖子本身够好，还会额外获推。 ![](img/c7e73632ad6755b722e87da9108eb302.png)

接下来说号群怎么配合。先说清楚两点：这个平台真不太需要刷量，我们做号群配合，更多是让帖子显得有人气，让陌生访客更愿意下单，而不是直接去抬权重。第二，方法不对会被平台提示风险，注意细节就能避开。

具体步骤也不复杂。先把小号养一养，让它们多刷同领域内容，打上对应标签。帖子发完、浏览量过两百后，再派小号进。注意不要搜账号名，要用搜索词按最近排序找，或者在转发链接里打开。进去之后模拟普通用户完整看一遍：认真读完，点个赞，把货放进购物袋，找客服问一句，最后留条言。平时网购怎么逛，就怎么操作。

另外，小号最好真实拍下。这个平台有晒图功能，真实成交比空口推荐更能服人。小号拍的时候数量填十，发货时只发一件，免得用户看到销量只有一两单，马上没了兴趣。留言区也提前备好一些常用话术，比如“打开一不留神就花了九块九”“已拍，坐等反馈”“蹲一个质量反馈”“质量不行我肯定回来骂”。对应类目还可以多存一些热评。收到货后，再回来晒图配一句好评。我们评论区里不少热门回复都是自己安排的；遇到陌生人给好评，也会第一时间私信，送点小福利请对方帮忙晒单。 ![](img/334a0abf798a69a47fab340c539b13f9.png)

下面讲彩蛋起号。之前提过爆款有三类：好看、实用、能捡漏。今天细说能捡漏那一类。 ![](img/4ebfee4da8ba93cd031eb595841e2042.png) 这类玩法的共同点很明显：价格不高，大多在二十元内；留言区清一色刷彩蛋；标题直接写超值；买单的多数是在校生。如果你的货本身便宜、容易走量，就可以试试。

基础玩法不复杂：标题主打超值，留言区写“留评随机掉X元券”。标题模板可以去看同行的爆文积累，比如“九块九毛绒三件套”“七块九化妆包”这类，但注意标价别低于真实卖价。留言区最好自己先发一张中奖截图，可信度更高。

彩蛋真的会掉吗？这个奖励本来就是官方给用户的活动，钱也是平台补的。我们只是利用认知差，让用户认为留言就有机会中，从而把互动带起来。 ![](img/0b878c5f95ece9ab66ffed04e86922a6.png)

高阶玩法更野，会拿“零点一元买”当噱头。但别直接抄，容易触线。想用的话有几个技巧：一是翻自己成交记录里的最低价，比如有过二块九的成交，就把零点一换成二块九。二是凌晨挂一张大额券，数量只放一张，自己小号领走成交，这样就有了真实低价记录。三是把肯定句改成提问的口吻，比如“你们怎么买到这么便宜的？”比直接写出来安全许多。当然风险也要清楚：这类流量大多价格敏感，容易把账号人群带偏；用不好会被系统提示描述不一致；成交比例也比普通帖子低。所以这个方法只适合低价走量款，做高价货就没必要碰。想拿平台的补贴，要挑对品、挑对人。

最后讲指标怎么读。想一直有收益，这东西一定要懂。内容发完后，怎么判断封面、标题、正文、售价行不行？靠数据。用一个简单链条来理解：第一层是内容打开率，对应封面和标题；第二层是货品点入率，对应正文、展示价位和留言氛围；第三层是付款率，对应售价和说明页。 ![](img/9e1011ab771d77df5d77d8df8d1e1c1b.png) 如果光看浏览量少，你很难往下调；但看到打开率低，就知道换封面标题；看到付款率低，就知道价格或说明页要改。不同环节出问题，表现完全不一样。

读指标有三个原则。第一，没有统一标准。卖美妆和卖零食，数据差很大。平台是同类对比机制，你能赢过同期同赛道就行。第二，样本太少不用读。总共一百来个浏览，硬分析没意义。第三，对比才能定好坏。付款率只有百分之一算不算差？如果你之前一直是百分之十，那就是异常。一百三十斤的人算不算胖，要看跟谁比；一杯九块九的水贵不贵，参照物不同，答案也不同。

具体分析就记三条线。

第一条线：同一款货，不同封面和标题的内容打开率对比。打开占比高的那套，就继续用。 ![](img/9301e9c82e9e496312ee5985ad719303.png) 这也是为什么必须持续测内容，不光是测货本身，也测哪种包装更能卖。

第二条线：同一款货，比较货品点入率。甲帖有四成点入率，乙帖只有一成，多半是甲帖的正文和留言氛围更打动人。 ![](img/027bf97d8eba3133ab503de5d5426c93.png) 用不同文案反复试，再回来读指标，就能找到更容易让人点车的方式。

第三条线：不同货之间对比付款率。付款率的算法是付款单数除以点进商品的人数。 ![](img/e6d71b5e6bab438a612cc2df8cf76050.png) 比如两款货卖价一样，甲货一百个人点进，二十人付款；乙货一百个人点进，只有四人付款。这时候多半是乙货有问题，说明页不够抓人，或者用户心里价和标价差太多。这种货以后也很难拿到流量。平台骨子里就是一套算法，谁能帮它从用户兜里收到更多钱，它就会把资源给谁。把指标读透，就能顺着这套算法一直找到新的机会。

这篇内容满满当当，建议先收藏再照着试。如果觉得有用，下期继续更新。

做📕店铺，光勤快发笔记可不够，还得懂怎么看数据。但先别急着分析，有个大前提得先记住：数据量太小，参考价值就大打折扣。比如你想比较同一款商品在不同笔记里的点击率，这思路没错，可要是访客寥寥几个，那数据基本没啥意义。

那数据从哪看？其实手机和电脑都能看，但平时用手机就足够了。打开📕商家版，找到“数据中心”，里面能看到总揽、流量、商品、笔记、营销、服务这几个板块。对咱普通卖家来说，最值得盯紧的是“商品”和“笔记”这两个。

先看商品板块。核心是关注支付转化率。点进“商品排行”，每个商品的访客数和转化率都列得清清楚楚。这时候别光盯着转化率高兴，得看看访客数做参照。举个例子：一个商品只来了3个访客，其中1个人下单了，转化率看起来有30%多，挺唬人吧？可这并不能说明商品有多能打，没准儿就是碰巧遇上了“对的人”。

再看笔记板块。这里重点看笔记的“交易引导”数据，也就是这篇笔记到底带来了多少成交。具体的功能按钮，你等自己店铺有数据了，在后台挨个点一点，自然就门儿清了。

![](img/74814c482e64004fdb40819f2f45b18e.png)

电脑端的话，登录网页版“商家管理后台”，点击“数据”，进去后就是“数据总揽”，整个店铺的概况一目了然。

![](img/b13e44868d5a556d78f5b33e1c93b5da.png)
