# 我在雅加达的14天：TikTok Shop被叫停之后，亲历者都看到了什么？
作者：龙哥

10月初，印尼一纸禁令让TikTok Shop骤然熄火，互联网上立刻炸开了锅：有人说印尼电商要集体凉凉，有人说整个东南亚都会跟着关门，还有人脑补出更大的剧情。带着一脑子问号，我两周前登上了飞往雅加达的航班，去处理公司在当地的落地业务。朋友调侃我，“别人躲都躲不及，你还往火里冲”。

这趟行程里，我几乎每天都在见做电商、做TikTok的同行。下面这些零碎观察，可能对龙哥盟的朋友有点用。

## 一、做电商和TikTok的人，活得怎么样？

这轮冲击里，最难受的其实不是普通卖家，而是围绕TikTok长起来的服务商。

我接触到的MCN、TSP团队，撤的撤、散的散，尤其今年以来刚成立的那批，基本关得差不多了。原因也好理解，这些公司本身是轻资产运营，最大成本就是人。项目没了，把办公室退掉、人员裁掉，也就结束了。我甚至还亲眼撞见了一场现场裁员：一个二十多人的办公室，负责人很平静地跟当地员工说，项目不做了，想转主播的可以把简历交给人事，我们帮你们推荐。所有人都很沉默，没有争吵也没有闹，大概这二十天里，大家早就有了心理准备。

卖家这边，则普遍在忙着往其他平台搬。有人每天还坚持播上一两小时的TikTok，有人彻底停播，转而全天候播Shopee。但比较扎心的是，同样一番折腾，Shopee卖出去的量差不多只有原来TikTok的20%到40%。裁员当然也在发生，只是数量多少的区别。整体上，卖家的心态反而比服务商稳：大家是可惜，是心疼，但没有多少怨气。毕竟能在印尼扎根的创业者，抗压能力早就被锻炼出来了。

## 二、仓库和物流，才是被闷声打的那批人

电商前线乱成一团，背后的仓储物流同样没躲过这记重拳。一些专门给TikTok发货的仓库，前一天还能日出几千单，第二天直接挂零。问题是，仓库大多是按年租的，想走走不了，只能硬扛着成本摊薄。

还有一件让很多人不安的事：查仓变严了。印尼政府这次的动作，其实不光是针对电商平台。我了解下来，警方还在突击检查那些靠灰色清关进来的、缺少资质的产品仓。那阵子，我见过的十几个小卖家、小仓库，几乎都把货物从仓库转移到了员工宿舍里，生怕哪天警察突然上门。去唐格朗那边拜访朋友，几个仓库大门全闭着，非要打电话确认了，才敢拉开一条缝让我闪进去。

常跑东南亚的人都知道，查仓这种事向来是日常，只是这阵子风声确实紧到扑面而来。物流那边我没太多熟人，没专门去打听，只听说因为海关态度强硬，价格一路飙了上去。

## 三、那到底还有没有机会？

有，而且有人已经开始接红利了。

我在当地拜访过一家工厂，老板自己就说，10月4号之后，来找他谈合作的新客户一下子多了三倍，都是想在印尼本土把供应链建起来。这背后正好指向印尼政府真正在意的事：保住本地市场，推动印尼制造。

这和很多人脑子里的印尼不大一样——它本来就有一定的工业底子，而且野心很大，想在全球制造版图上再往前挤一步。以前中国卖家通用的那套打法——灰关进场、海外仓囤货、低价冲爆款，确实让印尼本地产业吃了不少亏，也让政府恨得牙痒。这次TikTok Shop被封，最深的根子就在这里。其他什么政商博弈、枪打出头鸟，只能算是导火索。我们老话说的必然和偶然，在这个故事里就是：那套旧玩法注定走不下去，而TikTok Shop恰好撞在了枪口上。

眼下，几乎所有在印尼的卖家心里都有数了：想继续搞，就必须走合规之路，包括清关、产品资质等等。可合规这事太重了，不是嘴上说说就能落地的。明摆着的困难有三个：本地供应链成本比国内生产加海运还贵；各种认证要花钱更要花时间；长期躲在暗处、习惯用“解决问题”来平事的从业者，突然要走到阳光下和政府打交道，一点都不适应。

所以我不打算武断地说印尼市场能不能赚钱。和过去相比，这扇大门明显抬高了门槛。想进去，你得带着更多资本、更多人手，还有更长的耐心。

以上，是我这几周的所见所思。祝龙哥盟的各位，都能挖到自己的金铲子。
