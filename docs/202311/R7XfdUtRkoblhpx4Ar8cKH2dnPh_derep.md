# 一、专业能力拷问

## 一）面对大模型 token 限制，如何在有限上下文里榨出提示词的最大效用？

面试官想看什么：

1. 你对大模型与提示词工程的技术本质是否真正吃透。
2. 你有没有可落地、可创新的解法来绕开技术天花板。
3. 你能否综合运用 token 管控、文本压缩、上下文建模等手段。
4. 你的方案能否在真实产品里提升性能。

回答思路：先给结论，再显性化框架，然后展开三点，最后升华。

参考表达：

结论先行：
关于 [××××] 大模型 token 限制的应对，我在过往项目里主要落地了以下几组提升效能的策略：

显性化框架：
* 第一步做文本精炼，确保每个 token 都在干活。通过去冗余、换紧凑表达来压减 token 消耗。
* 第二步做上下文取舍，保证关键信息不丢。将最有价值的上下文保留，必要时适当拉长但严格剔除无关噪声。
* 第三步做提示词筛选，只留高信息量部分。通过抽取关键词、短语或实体，让提示词与上下文高度咬合。

总结升华：
[××××] 面对 token 上限，核心是精炼文本、聚焦上下文、挑选高价值提示词。这套组合拳能明显拉升提示词工程的表现，为新媒体与 AI 提效类产品创造更多价值。

2. 你能否有效处理模型不稳的根因并落地行动。

回答思路：用 STAR 模型。

参考表达：

曾负责一个 AI 提示词模型的研发，目标场景是 [补充业务背景]。核心挑战在于 [特殊场景/波动输入] 下仍要保持高质量稳定输出。

任务：
需要把稳定输出率稳定到 80% 左右，保持用户体验一致，面对输入波动、边界情况等压力。

行动：
* 先做模型根因排查，分析训练数据分布、架构设计与超参配置，找到不稳定的来源。
* 制定稳态方案，采用 [××××] 处理长文本输入，优化模型的 [××××]，并引入 [××××] 机制来降低输出方差。
* 搭建自动化监控看板，实现实时性能追踪，异常可快速告警与回滚。
* 全程与研发、产品协同，把发现与方案同步给团队形成共识。

结果：
最终稳定输出达标，80% 左右的稳定率得到验证，用户投诉下降，历史痛点得到解决。该项目也让我对稳定性优化有了更深的体感，可复用到你们团队。

## 三）用户表达方式各异导致 GPT 回答不准，怎么办？

考察点：你能否提升模型在多样语境下的准确率。

回答思路：结论先行+三点展开+升华。

参考表达：
结论先行：
面对表达多样、语境差异大的情况，提升 GPT 响应准确率是必须的。我过去常用这几套做法：

* 先盘点训练数据来源，覆盖不同表达风格与语域，让模型对口语化、专业化、模糊化请求都有认知。
* 再做场景化微调或专项训练，针对特定业务场景做指令适配与范式对齐，提升任务契合度。
* 最后建立持续反馈闭环，把用户真实问法与纠错结果回流，迭代提示词与训练样本。

总结：
通过数据覆盖、场景微调、反馈迭代三步，模型在各种表达面前的准确率能明显提升，用户体验也更顺滑。

## 六）上下文 token 太长导致模型遗忘，以及提示词过长导致胡言乱语，如何解决？

考察点：技术解决、灵活性、协作诊断。

回答思路：拆成两个问题用 STAR 处理。

参考表达：
这是两个相关但不同的问题。

问题一：上下文过长导致遗忘
目前常规做法是从表达结构入手压缩语义熵，用更高效的表述承载相同信息。核心原则是用户端自律：表达要精炼，不说废话，减少无效 token。

问题二：提示词过长导致胡言乱语
情境：在大模型使用中，提示词过长会占用过多 token，导致模型输出跑偏。
任务：要在控制长度的前提下保持回复质量。
行动：精简提示词保留核心指令；对超长部分做截断或摘要化处理；尝试不同模型规格与 token 上限，找到性价比最优配置。
结果：输出质量回稳，胡言乱语现象明显下降。

## 七）写完提示词后如何测试？测什么、测几轮、怎么量化差距、如何迭代？

回答思路：STAR。

* 构造多样输入：常见问法、复杂问法、边界问法。
* 按项目需求确定轮次，通常覆盖足够样本以验证稳定性。
* 用准确率、连贯度、可理解性等指标量化结果。
* 差距分析后做根因定位，针对性优化提示词并再测。

结果：通过闭环测试迭代，提示词达到预期质量标准，也锻炼了我的持续改进习惯。

## 九）把只能在 GPT-4 上跑的提示词迁移到 GPT-3.5 以降本，你怎么做？

结果：成功迁移，成本下降同时性能保持在可接受区间，达成业务目标。

面试最难的不是专业题，而是那些“怎么看都像在挖坑”的题。比如“为什么从上家离职？”“遇到不服从的下属怎么办？”“你部分能力不符，凭什么胜任？”尤其是AI提示词工程师这种新兴岗位，答错了容易给人“不稳定”“没方法”的印象。别担心，下面这份攻略，把高频问题拆成可用的应对框架。

### 团队管理：先给方向，再给动力

面试官问你团队管理，不是要你背名词，而是要看你有没有带人的逻辑。

- **怎么带成熟的团队？** 先给团队一个清晰的方向和目标，让每个人知道“我们要去哪、我在其中扮演什么角色”；接着再设激励机制，用奖励和认可让优秀表现被看见，士气自然起来。最后升华一句：成熟的团队管理，是领导和协作的平衡；互信与尊重是土壤，方向和激励是水和阳光。

- **遇到不服管的下属？** 别硬碰硬。先私下聊聊，听他把想法说完，找到问题的根；然后把团队目标和职责边界摊开，让他明白“我们是一根绳上的蚂蚱”；再建立阶段性的检查和反馈机制，如果问题还持续，就用培训、辅导或调整岗位来解决。核心是：用积极沟通管理冲突，而不是用情绪压制。

- **有没有成熟的管理方法论？** 有，三个词：透明、赋权、进化。透明靠沟通渠道和同步节奏；赋权让下属在专业领域内有决策权，激发责任感和创造力；进化强调学习和复盘，让团队能力不断往上走。这套组合拳能带出既高效又长期有战斗力的团队。

### 求职动机：把“离开”讲成“向上走”

面试官从动机里看三样：你稳不稳定、有没有目标、和公司对不对味。

- **职业规划：** 分三步讲。长期想在AI提示词领域成为专家，甚至主导项目；中期持续学习，跟上AI的快速迭代；短期用高质量工作帮公司拿到成果。这样既有高度又落地。

- **为什么离职？** 分三种情况破题。  
  1. 如果同一岗位干了3年以上：面试官会担心你适应不了新节奏。所以要强调你一直没停止学习，再说明公司近期的方向与你的规划不太一致，你想换个更有挑战的环境自我突破。  
  2. 如果老东家很有名：别正面回答是不是被淘汰。只说现岗位与职业发展不契合，你已经攒够了经验和能力，准备去更有前景的地方。  
  3. 通用说法：关键词是“职业规划”。希望去更优秀、更有挑战性的平台历练，拓宽通道、不断突破。

- **为什么会有半年空窗期？** 面试官会担心你懒散了、能力弱了、找不到工作、身体不好、不会协作。回答时要把空窗期包装成“成长期”：这段时间上了系统的课程，做了几个和个人能力相关的项目，也重新复盘了职业目标。总之，你不是被动休息，而是主动充电。

- **为什么选我们公司？** 可以坦率说：AI提示词领域对很多企业还是新东西，但正因为如此，机会很大。我的经验能帮公司在降本、创新和客户体验上带来实际改变，我也希望和这里的团队一起推动AI落地，成为公司AI时代的一份子。

### 通用问题：稳住节奏就能赢

- **自我介绍：** 用MTVB框架——我是谁（背景+特质）、做过什么（工作经历）、做成过什么（成果和项目）、能带来什么（价值主张）。讲的时候带点故事性，比如“我进公司时是执行岗，半年后开始独立带项目”，比背简历有力得多。

- **部分能力不符：** 先下结论“我能胜任”，然后给三点：我有可迁移技能，之前做过A，方法论能平移到B；我学习快，遇到新知识习惯用2W1H模型快速搭框架；我主动性强，愿意找问题、解难事。这样说，缺口反而变成你学习力的证明。

- **你对公司有什么期望？** 从三个角度答：希望有专业挑战和成长机会；希望和优秀的团队协作，在碰撞中解决复杂问题；希望公司的使命和价值观与自己同频，最好再加上“一个有积极社会影响和可持续愿景的公司，我愿意为之全力以赴”。这个答案很加分，因为它既不卑微，也不傲慢。

- **遇到不会的专业题？** 承认不会，但别冷场。诚实说“这块我不太熟”，紧接着反问“您是想考察我某方面的能力吗？我可以用一个类似案例来回答”。把话题主动引到你擅长的领域。

- **薪资怎么谈？** 先别报价，反问薪酬结构，问清楚工资、绩效、奖金、五险一金。等对方说出区间后，按自己的经验和匹配度报一个偏高的数。如果对方追问上一家工资，就回答“综合平均月薪”。如果对方给的钱符合预期，也别秒答，略作考虑并说“给我一点时间，明天答复你”。

- **“你还有什么想问我的？”** 千万别答“没有了”。你可以分三类问：第一类关于文化和价值观，比如公司最看重什么、团队氛围如何、岗位是新增还是替补、试用期多久、面试结果什么时候出；第二类关于岗位目标，比如部门有多少人、有没有成熟流程、你希望我短期解决什么问题、长期打什么仗、最大的挑战是什么、晋升通道怎么走、试用期考核最看重哪一点；第三类关于领导风格，比如您平时喜欢怎么配合下属、汇报频率多高、你最欣赏什么样的工作态度、你能成为团队负责人一路走来的最大挑战是什么。如果你聊完发现自己的核心优势还没机会说，可以再争取两分钟：“关于这个岗位，我有一些想法想分享。” 然后把你过去的经历和方法论与岗位需求连接起来，最后说“不知道我的理解准不准确”，并表达很想加入的意愿。

### 不同职级面试流程，要做到心中有数

- 初级岗位：HR面（动机+通用）→部门经理面（团队+通用）
- 中级岗位：HR面→团队领导面→技术/项目经理评估
- 高级岗位：HR面→团队领导面→技术面→案例或领导力面
- 高管级岗位：HR初筛→战略面→领导力面→公司高管面，重点看战略思维和愿景共鸣
