# 新手做小红书定制旅游，两个月卖到10w+，我如何迈出从0到1那一步

今年4月，我才刚刚加入赚钱这个圈子。作为新人，那阵子我像是打开了一个巨大的宝库，满屏的实战项目让我既震撼又兴奋，甚至有点眼花缭乱。可没想到，接下来的大半年时间里，我陆续尝试了不少方向，结果却并不理想——始终没能拿出像样的成绩。

回头反思，问题其实出在我自己身上：涉足的项目太杂，又缺乏足够的专注和坚持，总想着广撒网，反而都没能深耕下去。

转机出现在7月底。我有幸遇到了阿渡老师与易老师，跟随他们认真做起了旅游项目。这一次，我下定决心专注在小红书做定制旅游，踏踏实实地执行每一步。结果让人惊喜：仅用了两个月，销售业绩就达到了10w+，顺利完成了我个人从0到1的关键阶段。
