# 百万创业债压顶，怎么稳住阵脚继续往前走

原文链接：[`www.yuque.com/for_lazy/thfiu8/xxo61wkcw671ilc4`](https://www.yuque.com/for_lazy/thfiu8/xxo61wkcw671ilc4)

作者：果果 | 债务清
日期：2023-11-07

做债务优化这段时间，接触的客户里近一半都是创业欠的钱。有人是三年疫情把现金流打穿了，有人是个人判断失误一头扎进去。今天就把我对创业负债的一些观察和实操建议，梳理出来跟大家聊聊。

疫情后大家的负债率整体是上去了，不过跟海外发达国家比，国内整体水平还算克制。但创业者这个群体明显更重，启动和运转基本都离不开借钱。

## 一、负债率高不是你的独角戏，先把心态摆正

创业者的借贷额度，受资金需求、融资条件和回款能力共同决定。关于欠债，我建议从两个维度来看。

其一，债本身不是原罪。适度借钱能盘活资金、撬动发展，还能形成一种向上的压力。但一旦借得过头，财务风险就会失控。眼下大环境下，如果成功概率不高的项目，还是要谨慎入场。我写这篇帖子，恰恰是因为身边创业负债的案例太多。

其二，看债用在哪、回报是什么。拿去买资产、做生意、创造现金流，是有价值的投入。拿去满足即时消费和短期欲望，换不来长期收益，就要三思。

所以负债高不高，没有绝对标准，得结合自身状况和抗风险能力。借钱前要算清金额、利率和能不能还上，确保钱是为业务添火而不是添堵。家庭层面也得保持理性消费和储蓄习惯，才能让财务保持韧性。

## 二、债务增速和收入增速的博弈，决定生死线

对个人和企业来说，债和收入谁跑得快，直接决定财务健康。

借钱在生意里常态化，能放大规模、投新品、提产能。但前提是得管住，绝不能让欠款增速超过赚钱增速。

一旦债务跑赢收入，就很危险。还不上、资产被迫变卖、信用受损，都是连锁反应。所以必须时刻盯着两条曲线：欠款在涨，收入有没有同步涨。

当你发现当月收入已经覆盖不了本金利息，甚至连利息都吃紧，就要拉响警报。如果未来收入没有明确的提升路径，这个局面会越陷越深。![](img/2aac7c56f78f7bd40117e6756b3fe242.png)

我经手过一位老板，征信一直很好，信用卡和贷款额度都很高，结果成了越借越顺的陷阱。现在在我的建议下他及时刹车止损了，不然在零收入情况下只会越滚越大。

另外，收入增速还要看生产力是否跟得上。收入涨得比效率涨得还快，看似风光，实则成本会飙、利润会薄，最后竞争力被拖垮。

管理负债和收入，核心是找到平衡点：欠款增速不高于收入增速，同时收入增速要和生产力提升相匹配。

## 三、已经创业负债了，企业层面怎么自救

1. 重新审视商业模式和打法。把项目扒开看，问题出在哪，产品定位是否跑偏，市场需求有没有变化，需要怎么调整。
2. 寻求外部资源对接。与投资人、合作伙伴、行业同行建立联系，看有没有合作或融资的可能。外部经验和资金，有时就是关键的缓冲垫。
3. 精简成本、提升效率。把各项开支过一遍，能砍的砍，能整合的整合，供应链、人力、运营都要做效率优化。
4. 放大获客和品牌声量。加大推广投入，提升曝光和转化。线上广告、线下活动、社群运营，都可以组合使用。
5. 不断学习进阶。市场在变，能力必须跟上。保持学习、保持韧性，相信调整后的方向能重新起盘。

创业负债是考验，也是机会。模式复盘、外部求援、降本增效、强化营销、持续成长，这五步做好，有机会重新站稳。

## 四、家庭生活怎么安排，负债别自己扛

1. 压缩开支。把日常花销列清楚，保障衣食住行等刚需，砍掉一切非必要消费。
2. 做预算表。收入、支出、还款、应急金都要列明白，确保月度支出不超收入。
3. 拓展增收渠道。兼职、副业、闲置变现，都能缓解现金流压力。
4. 主动管理债务。跟债权方沟通，争取延期、降息、分期。制定清晰还款节奏，避免逾期罚息。
5. 寻求专业支持。财务规划师、债务顾问能帮你把方案做得更稳。

心态上要保持积极，负债可怕，可怕的是被负债打垮。最好能跟家人坦诚情况。有能力的一起扛，没能力也能减少催收上门时的恐慌。

我见过太多人选方案时最怕的不是钱，而是怕家人知道。可是纸终究包不住火，早点摊开，家人才能配合，也才能不被突如其来的催收搞乱阵脚。

## 五、公司关门了，是再战还是先找工作

没有标准答案，得看个人条件。

1. 资金与抗压能力。负债压力大，先找份稳定工作还债，再图后续，比空转更安全。有足够缓冲资金和风险承受力，再考虑重启。
2. 兴趣与热情。是否还热爱创业，是否相信自己能做得更好。热情还在，可以再赌一次；倦了不确定，就先休整。
3. 能力与经验。技能是否匹配新方向，过去的经验能否复用到新项目上。缺短板就先去职场补位。

无论选哪条路，都要认真评估、冷静决策，保持行动力，相信困境总会过去。

## 六、面对创业负债，果果的六条实操建议

1. 直面现实。把所有负债列清单，做还款计划，确保按时履约。盘活手头的资产，筹集还债资金。
2. 请专业人士协助。负债咨询师能帮你厘清法律和财务边界，谈判还款方案，避免踩坑。
3. 增收节流同步进行。找兼职、提升技能做溢价、精简开销，把省下的钱用在刀刃上。
4. 建立应急金。哪怕先存一小笔，应对突发状况，避免因小事再借新债。
5. 培养财商。学会做预算、规划支出、控制借贷，建立健康的财务习惯。
6. 配置基础保障。健康出问题会让债务雪上加霜。经济紧张时先买百万医疗等性价比高的险，有条件再逐步补充。

负债不可怕，可怕的是自暴自弃。人生有起伏，低谷期只要持续行动，总会迎来转机。
