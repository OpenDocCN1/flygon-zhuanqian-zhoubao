# 用GPT从0到1开发一个软件功能模块，我总结了五个关键环节

大家好，我是峰兄，一名在世界五百强外企搬砖的程序员。之前给自己立了个目标：每两天写一篇干货。结果没多久，“二更”就变成一周两更了。好在我是逗B人设，改flag也不怕打脸。

上周没更新，真不是偷懒。最近小报童特别火，我也跟几个朋友合伙搞了个AI编程变现的小报童，前前后后忙了一通，今天总算能腾出手来，来赚钱星球补一篇。

这篇聊聊怎么靠GPT从零开发一个软件的功能模块，做开发的朋友可以看看。我的思路是把过程拆成五步：先做需求梳理，再整数据库设计，接着写接口文档，然后实现后端代码，最后补上单元测试。这五步随便拿出一步，都够单独写一篇文章，所以这篇只给整体框架，细节大家按需去挖。
