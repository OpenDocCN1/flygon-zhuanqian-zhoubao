# Gpts 制作教程，太炸裂了！聊聊天就做一个 app
作者：龙哥

周末我亲测了一把OpenAI的GPTs，结果彻底被震撼到了：从有想法到正式发布，仅仅花了一个小时，就搞定了两个小程序！这过程简直就像在跟AI聊天，说着说着产品就出来了。

这篇文章会把从制作、测试、到发布、修改的全流程都记录下来，配上截图，希望能帮到想试的人。

**先说一下前提条件**
1. 网络方面要能正常访问ChatGPT（你懂的）
2. 账号必须开通ChatGPT Plus会员

**具体怎么操作？一步步来**
1. 进入ChatGPT官网后，找到左上角的【Explore】按钮，点开后再点【+】号。  
![](img/6d59e35452e7fa39a06db7d168f141b6.png)
2. 这时候ChatGPT会问你想创建一个什么样的GPT。直接用普通话把你的需求描述出来就行。  
![](img/9c43a120794fccdc3403e2cb8317d9e5.png)
3. 根据描述，它会给这个新GPT起个名字。我懒得改，就沿用了它起的名字。
4. 接着，ChatGPT开始设计产品图标。我觉得原来的不太满意，就让它再生成两个方案看看。  
![](img/b6aea330577baa9866d39fe26ee83ff8.png)
结果它立刻生成了两版新图标，还分别讲了设计思路。我挑中了第一个。  
![](img/28988808d06bb4d1ab82c9b4d8ce052a.png)
5. 然后ChatGPT继续引导我确认一些细节问题。  
![](img/2048bc11bc5b6951dcf424e5bb9f0af3.png)
看到满屏英文，我有点懵，直接让它翻译成中文再继续。  
![](img/9a227592521c616a33c7ceb049af24cf.png)
6. 聊到这里，基本就没什么要补充了。  
![](img/a2a77c8b68bfefd7bb71ba555056987b.png)
这里要特别注意：前面所有这些对话都发生在【Create】选项卡下。切换到【Configure】选项卡后，会发现ChatGPT已经把我们的聊天内容自动变成了指令和【Conversation starters】——也就是最开始的对话快捷提示。先不用动它。  
![](img/28988808d06bb4d1ab82c9b4d8ce052a.png)
7. 接下来做个小测试：我上传了一张PNG图片，要求它转成JPG，结果它告诉我“转换不了”。  
![](img/28988808d06bb4d1ab82c9b4d8ce052a.png)
咦，为什么？仔细一看，原来是我没有勾选【Code Interpreter】。因为我让它做的事都需要靠代码来实现。把这项勾上，再重新转换，居然就能正常下载了。  
![](img/28988808d06bb4d1ab82c9b4d8ce052a.png)
![](img/5c2c2cb86ecba51f9abf616f143ce4ca.png)
8. 简单验证没问题后，就准备发布。点击右上角的【Public】，然后点【Confirm】。  
![](img/c6ddd89b81f05b6d016c0cb17ec12088.png)
发布后的页面长这样。  
![](img/0698f412726ff3070eeb60bae843b4ec.png)
我们来正式体验一下：点开列表里最后一个选项“How do I convert a PNG to JPG?”。  
![](img/7b17394080d1f4fb180cb1173cd25014.png)
结果却不是我想要的——它只是告诉你怎么转换，并没有直接帮你转。这样一来，我也总算搞明白了【Conversation starters】到底是什么意思：其实就是我们预先设定好的对话需求。
接下来我打算修改一下已经发布的这个GPT，按图示进入【Edit】即可。  
![](img/ebe4f6cb64ec04c60569d9353f8eb36b.png)
按照我的真实需求，我把【Conversation starters】重新改了一遍。  
![](img/2b114b0d5f6c5664293754f3545cb513.png)
改完之后，点右上角的【Update】就能重新发布，系统还会生成一个新版本的查看链接。  
![](img/7b874b2b609c58f5f3c7023dfa1d5691.png)
发布后的效果如下。  
![](img/49713bcaa9618e2858d9bcc8b7ba9c6f.png)
之后，就可以根据自己的需求随意处理图片了。

上面这些截图，基本覆盖了制作、测试、发布、上线后再修改的完整链路。写得可能有点乱，有不懂的地方随时找我。

另外一个GPT是PDF Tools，当时制作时忘了截图，先放一张使用界面给大家感受一下。  
![](img/f45cce18061ccc05c9a0c6988c336388.png)
![](img/0acf072f6e4a30742f0d2c8225cdd100.png)
这个工具支持PDF的常见编辑操作——压缩、分割、合并、提取文字和图片；也支持格式转换，比如PDF转Word、Excel、PPT、图片，或者反过来转。而且每次转换如果失败，它会自动重试，最多试5次。我给它的测试任务是把PDF转成PNG，再把前10页拼成一张长图。
