# 闲鱼二手书项目新政策与应对策

我是龙哥，熟悉我的朋友都知道，我在赚钱主要围着二手书打转。2013年从211毕业后，在职场待了8年，最好年份年终奖也能拿个百万上下，算是房地产圈里比较年轻的中层。2021年给董事长做了个《房地产的前世今生》PPT，越做越觉得这行业没啥干头，干脆走人。创业路上没少踩坑，最后连自己都没想到，靠二手书活了下来，还活得挺不错。现在小区里开了个工作室，手上有30多个闲鱼号，每月纯靠闲鱼二手书的利润稳定在10万+，开学季能冲到20万+。

二手书这个项目在赚钱算是我一手带起来的。它赚不赚钱，数据最直观。5月航海有位船员来报喜，如果你看过之前的二手书直播，应该还记得那个和我连麦的学员。现在6个号，开学季日销破万，按这个趋势，9月利润冲上10万+不是问题。

所以龙哥那句话我还是信的：赚钱航海挑出来的项目，每一个都具备年入百万的潜力。![](img/2a356c6555b51961dfa774d99ec23e5e.png)

最近好几个圈友来问：之前直播连麦时盗坤说闲鱼是垃圾项目，老瞿你怎么看？我的回答很简单：谁赚得多，谁说得对。盗坤都年入千万了，比我多，他说垃圾就垃圾吧（笑）。不过玩笑归玩笑，咱们还是得理性拆一拆。

先不避讳地说，闲鱼的上限确实不高。我30多个号，单号月利润平均也就5000多，开学季能到1万左右。上次航海有个学员一个人管6个号，日销售额2000+，月利润2万+，订单多到处理不过来，直播时还来问我工作室怎么搭。所以一个人做闲鱼的利润天花板大约在每月2-3万。对年入千万的大佬来说，这确实投入多、回报低，说是垃圾项目不算冤枉。但如果你是刚进互联网的小白，我建议把项目分成三个级别：

初级项目，闲鱼二手书就属于这一类。好处是超过一半的人能拿到结果，坏处是上限明确，流程有点繁琐。中级项目像抖音短视频带货，上限高，一条视频爆了可能赚好几万，走精选联盟还不用自己发货；但要求也高，选品、网感都得有，成功率可能只有10%。高级项目比如个人IP，一个人加个小助理，直播间卖课一年能卖几千万，赚钱里的李一舟、粥左罗就是例子；不过对个人能力要求更高，成功率或许1%都不到。成年人的世界讲究“选择即接受”。选闲鱼，可能1-7天就出单，但别指望无限放大；选个人IP，可能半年没收入，一旦跑通收益巨大。做项目和谈恋爱一样，你得把优点缺点一起接受，才能把它经营好。等你在一个项目上跑通了，再把它变成工作室也好、当基本盘养活自己也好，之后去冲中高级项目都不迟。一上来就要做个人IP的，大概率坚持不了多久。普通人更现实的路，是不断拿正反馈，跟着赚钱一点点走，把认知和执行能力慢慢抬上来。

我做闲鱼二手书两年多，平台一直在变，闲鱼APP和闲管家网页改了又改，底层逻辑没变，但有几个新变化要留心。

先说出版物许可证。现在查得越来越严，海南的证被一锅端，江西部分区也开始出现异常，店铺被关。很多人慌了，问是不是不能做了。那句话怎么说来着？浪越高，鱼越贵。做项目和打工不一样：打工遇到问题可以推给岗位职责，做项目必须自己想办法解决。眼下主要有两个应对思路：一是分开办证，像我手里3个证，分布在三个地方，就算其中一个翻了，还有两个能用。二是去周边偏远县城办，这些地方政策通常更宽松。证出问题大多出在经营地址上，能找中介租个地址，基本就稳了。海南江西之所以翻车，正是因为代办在同一个区域办太多，被盯上了。只要你分散开，或者自己亲自办，证照问题大概率能化解。

再聊聊软件。我以前全靠人工上书，后来用了华少开发的“闲助手”。它是专门为闲鱼二手书设计的，上书效率、同步孔夫子订单、集成客服聊天，都能省不少事。有圈友问我：用闲助手会影响流量吗？为什么感觉手动上架曝光更好？说实话，影响流量的从来不是这类软件——它们对接的是闲管家官方API。真正影响流量的是人变懒了：用了软件以后，选品应付、图片随便、价格直接套系统默认，流量怎么可能好？工具确实能提效，但别忘了它只是工具，别因为有了它就不思考，上完书就等风来。

再说闲管家。它是闲鱼官方的卖家数字化工作台，也是闲鱼APP官方合作出品，可以用电脑上架商品、管理商品、处理订单，一个闲管家能绑定多个闲鱼号（现在叫闲鱼店铺）。闲管家有不同的版本，具体对比看下面：

如果只绑了一个闲鱼店铺，可以先不升级；如果绑了多个，想提升效率就最好升级。高级版收费是：28元/月/号，68元/季/号，108元/半年/号，138元/年/号。

![](img/158fffeb762561bd8edffb054f67dc09.png)

如果多账号想再进一步提效，可以试试圈友华少开发的收费软件“闲助手”，它需要配合闲管家来用。这套系统能做批量上书、订单🛰️提醒、多账号客服集成等。可以先找华少开账号体验，觉得好再付费。要提醒一句：用了闲助手，就得开通闲管家开放平台；不用闲助手，就不用开。闲管家准备对使用开放平台服务（包括对接第三方ERP或自研ERP）的用户收软件服务费，不用的用户不受影响。如果要用闲助手，必须接通开放平台，订购时找华少要邀请码还能享受折扣。

![](img/86d7b8c0ceba0e7fcbd812934488a463.png)

服务保障这块也要留意。闲鱼专业卖家开通后能在一定程度上增加商品流量。现在二手书项目大多数账号都被要求开通“7天无理由退货”，要交500元保证金，可退，不交就无法发布商品。注意，服务保障不是通用的，每个闲鱼号都要单独开通。其他服务可以根据精力自行决定要不要开。想关闭的话，在APP端点服务保障，全选，关闭即可。另外，开通后每月成交，平台会按每笔订单抽取1%的软件服务费，比如成交一笔订单，就按订单金额的1%扣。

经历了这么多项目，我越来越认同一个公式：项目成功=熟悉流程10%+理解底层逻辑10%+执行迭代80%。大多数人做不成，问题就出在执行力太弱，弱到连流程和逻辑都没真正摸清。5月沉淀下来的航海手册已经相当完整，跟着手册一步步走就行。如果你以前完全没碰过电商，一定要反复看。小时候学写字，最笨的办法是抄一百遍；长大了反而看不上这种笨办法，可它偏偏最管用。涛哥直播时也说过，练直播网感最简单的方法就是播够200场。我最近在练直播，算了一下，一周3次、一个月12次，得播一年多才能凑够。但这就是个被短视频和直播推着走的时代，想超车，就得先去拥抱它。

我也一直提醒自己：别低估任何项目的门槛。如果真有那种小白上手、每天2小时、月入过万的项目，为什么还有人在肯德基端盘子？时薪20，一天8小时才160，全职一个月不到5000。闲鱼已经是最初级的项目了，但也没有例外。航海设置21天打卡12天，是为了让更多人愿意下场试错，找到适合自己的方向。可一个项目要做出成绩，通常得给自己2-3个月。我见过的圈友，很多光靠执行力就甩开了90%的人。所以21天结束不等于项目结束，你要继续做下去，才有可能慢慢做大。同时也要有意识培养能力、给自己成长的时间。上次航海里做得好的，不少本来就在玩闲鱼。我拉过20个人试抖音真人出镜带货，成绩最好的那位，之前做中视频有过千万播放，后来又做国外育儿短视频，再到真人出镜才跑出来。每次参加项目，不妨给自己定个提升的小目标。上次航海没人愿意做直播，我就顺手把老瞿的直播技能点亮了。

最后，祝大家在闲鱼二手书航海里都能拿到好结果，等你们月入10万来报喜。
