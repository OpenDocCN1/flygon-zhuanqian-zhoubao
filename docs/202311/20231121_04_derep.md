# 用影刀自动盯“对标账号”，数据图表化，谁爆了一目了然

做抖音整整一年，前前后后关注的同类账号，少说也有几十个。每天最头疼的，就是没法第一时间搞清楚对方的新动作——作品几点发、什么时候开始爆、今天众多参考账号里哪个视频突然起量了，我能不能马上跟上。

于是我就琢磨，能不能有个工具，定时帮我去采集这些账号的点赞数据，比如每隔一小时自动记录一次，最后把数据变成像Excel那样的可视化图表。

后来我用影刀RPA把这件事实现了。我把脚本重新梳理完毕，只要配置好，它就能按设定频率自动抓取，并把历史数据整理成图表，比自己手动记录省心得多。因为排版原因，具体的效果表我放到了飞书文档里，可以点进去看：[飞书链接](https://w0kp7t5wqc.feishu.cn/docx/PaRldAqNloMqW4xNcLAcWAMhn5c)![](img/0b648cb1d16acbf7019e2e8da3d099af.png)

评论区里大家聊得很热闹：有人说这太实用了，有人说目前有自动监控类脚本，但缺了频繁监测+图表展示这个环节；还有人等着我分享影刀的具体步骤，我说回头把脚本拆出来发给大家。另外有朋友提醒，社区版对超过30行的代码有限制，这个以前倒是没有遇到过。

这套方法不限于抖音，其他平台的同类账号监控需求一样能套用。希望也能帮到同样在盯数据的朋友。![](img/1c37d505930596d12a88ab23e11aa07a.png)
