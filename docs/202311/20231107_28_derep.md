# ('公众号爆文进阶教程', (2, 11))

最近，公众号圈子里冒出个自称“神秘人”的老哥，叫张波。别看他嘴上说神秘，实际上可一点也不低调——一个人打理着20多个公众号，每天收入相当可观。他参加了近期的公众号航海与续航活动，还一直活跃在《公众号爆文写作-10月续航1群》里。平时他除了闷头实践、每天沉淀新感悟，还把群里高手们的分享全部过了一遍，最终整合出了一份《公众号爆文进阶教程》。

这份教程适合谁？张波给出的话很直白：如果你已经摸索了一段时间，却始终没能写出10w+，同时又不太认可他的写作思路，还觉得运气差了点，那确实不如趁早换赛道，及时止损。但如果你已经拿下过10w+，这份整理也能作为参考，或许可以锦上添花。

他希望这份内容能帮到处于不同阶段的朋友：新手朋友可以借此了解大致流程，抓住文章里的关键模块，甚至还能拿到现成的全自动指令直接上手；老手们也能看看别人的操作思路，说不定能带来一些不一样的启发。

当然，这份教程也有没覆盖到的地方。张波把它定义为1.0版本，之后可能还有2.0、3.0甚至更多。这次他完全没有提RPA，理由是GPT-4.0次数受限，Claude偶尔不稳定，ChatGPT3.5的文案质量也一般。此外，公司注册、多开账号这些操作细节没有展开。他也承认，还可能有其他不足，欢迎大家多指教。
