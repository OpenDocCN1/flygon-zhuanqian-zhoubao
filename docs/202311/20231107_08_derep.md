# 为什么说内容输出力是个超能力，如何培育持续的内容输出力？
作者：龙哥

我们总在讨论公开表达的红利，也总在强调内容输出的价值。但在我看来，持续输出内容的能力，简直是一种超能力。

可为什么它这么厉害？很多人只是嘴上说要重视，却迟迟不动，根子在于没想通它到底重要在哪。只有从底层把这个问题想明白，行动才会坚定，才可能日复一日做下去。

**为什么说它是超能力？**

先问自己：你会因为什么尊敬一个人、敬佩一个人、信任一个素未谋面的人？再想想：有什么东西能跨越时间和空间，钻进无数人的大脑，让人印象深刻，甚至改变他的思维、行为和生活态度？

答案是：表达出来的语言。

因为一个人用语言带给了你启发，触动了你的情绪，引发了你的思考，甚至改变了你的做法，你才愿意信他。

《遥远的救世主》里，丁元英对芮小丹说，文化产业、文学、影视都是“拉人灵魂的艺术”，功效就是启迪人的觉悟、震撼人的灵魂。众生需要这个，所以它就是功德、市场、名利。这话放在内容输出上，同样成立。

想象一下：苏轼、曾国藩、孔子，这些影响了无数代的先贤，如果当年没有写作习惯，没有把思想用文字留下来，没有留下只言片语，今天还会有这么多人记得他们、反复研读他们吗？恐怕不会。

而今天，信息传播的速度和广度远超从前，更不用说了。只要你有内容输出力，无论写文章、做直播还是拍视频，只要你的作品能让别人看完有所启发，你就能很快赢得尊重和信任。他看过你的文字、听过你的话、看过你的视频，只要深度认同，基础信任就建立了。看得越多，信任程度越深，他就想认识你、链接你。如果你还能解决他的问题、提供他想要的价值，他就会为你买单。

每一个持续对外输出的人组建的社群，其实都像一个小型宗教，凝聚力极强。所以人们常说，有1000个铁杆粉丝就够了。我倒觉得，不需要1000个，100个就能养活自己。

而那些比你厉害的人，如果看过你的内容，觉得你很靠谱，愿意把你推荐给更多人，你就等于拿到了一个“超级节点”，有机会实现指数级增长。以后无论是合作还是求助，你都省去了费力自我介绍的环节。向上链接、向下链接，就算你性格内向、不善言辞，文字也会替你说话。

只要你能持续输出真正有价值、能启迪人心的干货，天底下同频的优秀之人都会涌向你，成为你的朋友、伙伴，甚至贵人。

还有什么能力，能让你如此高效地链接更优秀的人？如此高效地跨越时空，把自己的经历、思考和观点传递出去？一旦练成这个能力，等于给人生加了一根杠杆，事业、人际、整个人生都会越来越好。

**怎么把这门能力练出来？**

第一条：打通“阅读—思考—输出”这个系统，先从一个极小的循环开始。不用贪多，每天读10分钟书，读的时候带着脑子，主动找让你有触动的点，读完至少写100字。记住：输入是消费，输出是创造。先逼自己从消费者变成创造者。我自己就是从当初憋不出500字，写到今天日均5000字。

第二条：写着写着不知道写什么？那就去输入。输入有三个方向：

一是你的个人经历。当你开始写，你就已经在写自己过去和现在的经历。这是你最顺手的素材，也最能打动人。真正好的内容，能打开读者内心的保险箱；而最好的钥匙，是创作者的真诚与真实。这个时代什么都能被模仿，唯独你的经历抄不走。没什么可写时，就去回忆过去：成功的事、有趣的体验、踩过的坑、犯过的错。同时，当下要主动多创造经历，去做那些你不敢做、害怕做的事，既创造了经历，也创造了素材，还能打破自己。

二是多读书，多读你喜欢博主的文章，甚至可以加入他的圈子，多链接人，有条件多见人。书和人，是日常获取信息的两大渠道。书那么多，人那么多，只要勤奋，可写的东西永远不缺。我经常是读到一句话、看到一篇文章有了启发，顺着这个灵感就开始输出。刚开始可能读了也没什么感觉，很正常，因为大脑里的知识连接还太少。慢慢来，读多了、写久了，输出力自然变强。大脑放着不用会生锈，越用越灵光。

三是多提问，多收集好问题，用“问题+回答”的方式来输出。知乎、🛰️问一问、别人请教你的问题、你自己遇到的困惑，这些都是线头。拿着线头去梳理答案，写成文字，就是非常优质的内容。

内容输出力这件事，越早开始越好。凡是依靠积累的能力，早一天就是绝对优势，因为占到了时间的便宜。不用焦虑，把它当成长期的事，当成终身的日课来打磨，路上一定惊喜不断。
