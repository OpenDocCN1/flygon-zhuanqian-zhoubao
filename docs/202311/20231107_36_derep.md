# 朋友圈，成了我从“三无大学生”逆袭的最大底气
作者：龙哥

你敢相信吗？一个兜里没钱、手上没人脉、身后没背景的普通大学生，单靠经营一个小小的朋友圈，硬是把人生过成了别人眼里的“高光剧本”。

我是龙哥，一个03年出生的女生。创业到现在才一年多，已经靠朋友圈实现了经济上的独立——不再向家里拿生活费，还能自己稳稳地撑起生活。

但说真的，这趟旅程带给我的远不只是“钱”本身。更大的收获是：我的圈子变了，身边链接到的人越来越优秀；我的资源盘活了，很多机会主动找上门；我的形象也焕然一新，从埋在人群里看不见的小透明，变成了一个自信、有影响力的人。

这一路走来，有方法论，也有无数个真实的故事，我一直想找个机会认认真真地讲给你听。虽然这是我在社群的第一次发帖，可能还不够完美，但我希望这些攒了很久的心里话，能给同样在路上的圈友一点力量和方向。
