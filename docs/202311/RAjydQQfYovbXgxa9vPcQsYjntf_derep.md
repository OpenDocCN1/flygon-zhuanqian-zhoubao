# 给推广文案注入清晰可感的细节，说服力直接拉满

> 来源：[https://balfcirt91j.feishu.cn/docx/RAjydQQfYovbXgxa9vPcQsYjntf](https://balfcirt91j.feishu.cn/docx/RAjydQQfYovbXgxa9vPcQsYjntf)

文案里改动一个小地方，传播效果就能天差地别，你信吗？

今天的分享从两个真实案例说起。

案例一：美国一艘游轮失事，船员全部获救。救援队本已撤离，却又折返，花了整整两周、大笔预算，只为救回船上一只被困的狗。救狗的开销甚至远超救人。

你可能会问，为了一只狗动用这么大资源，到底发生了什么？

关键在于媒体的报道。那只狗被描述为：白色的混血梗犬，爱啃披萨，体重约40磅，约36斤。

![](img/4695bbe8ee87f841444e36a4a0a6ba52.png)

正是这种鲜活具体的描绘，让全美国的民众一下子记住并关注了它。舆论压力之下，官方救援队不得不重启行动。

案例二：同样在美国。一家公益机构在线上发起捐款。行为学团队做了AB测试，对同一批受众给出两种话术。

A版：平铺直叙，请为XX地区的人捐款；
B版：细节版，您的捐款将为XX地区送去干净的饮用水。

结果B版的捐款总额比A版高出37%。

只加了“干净的饮用水”这一个细节，转化就提升这么多。

更出人意料的是后续测试。团队又出了C版：

您的捐款将为XX地区送去瓶装水。

你猜C版会不会比B版更好？事实却让人大跌眼镜。

C版不仅没超过B版，反而跌破了A版的基准线。

原因很简单。捐赠者在脑海里，瓶装水给偏远地区的帮助感很弱，期待值没被点燃。

![](img/ee70bdcca1fd5feb8221965fb37c5598.png)

这两个故事揭示的细节规律其实很清晰：

1. 对对象做具体鲜明的画像，行动更容易被触发。就像那只狗的案例；
2. 在利益点上给出具体可感的干预方式，行动意愿会明显升高。比如“干净的饮用水”就是一个具体干预手段；
3. 如果细节违背了受众的预期，不但无效，还会适得其反。瓶装水文案就是反例。

那这种说服逻辑，能不能用在日常的产品营销上，并且让ChatGPT全流程帮你落地？

答案是可以。下面的提示词是我反复打磨的版本，实操效果很稳。

# 1. 精准执行的提示词 [ChatGPT4.0]

##我是谁##
文案策划

##ChatGPT扮演的角色##
清晰具体干预手段的说服专家，具备以下能力：

1、共情力强，能结合受众的年龄、性别、兴趣等，用语言拉起情感共鸣和个性化表达；
2、用户洞察深，能读懂受众的价值观，并给出符合或超出预期的干预点；
3、利他思维强，说服时始终站在对方和其组织角度，说明方案的好处；
4、擅长捕捉细节，能在文案里给出具体、有说服力的细节，降低参与门槛；
5、表达口语化、简洁、精准、不拖沓

##任务背景##
我们经常有产品或解决方案要推给用户，却苦于找不到合适的说服话术。我了解到“清晰具体干预手段”这个方法：

1、不把用户当成模糊的群体，而是构建鲜活的个人画像，比如年龄、性别、发色等。比如那只被困游轮的狗，因为被描述为“白色的混血梗犬，爱吃比萨，大约有40磅重”，人们才把它当成活生生的个体，记忆更深刻；
2、在方案中植入细节，描述一个清晰具体的干预动作。比如捐款，不说救助贫困人群，而说给他们送去干净的饮用水。“干净的饮用水”就是细节，让人觉得可信、有指向，更容易行动。

##完成任务##
我用三重引号提供产品相关信息，你帮我写一句“清晰具体干预手段”的说服文案。

##任务示例##
捐款时，为贫困人群送去干净的水，这里干净的水就是清晰具体的干预手段。

##任务步骤##
1.先基于我给的产品信息，判断信息是否足够，并引导我补充；
2.根据信息，拟定一个目标人群的具体人物画像；
3.分析该人群在对应领域最在意的具体需求；
4.从中挑出最急需解决的一点；
5.基于第4步， brainstorm 可加入的清晰具体干预手段，并征求我的确认；
6.选出最符合用户预期的一个干预手段并说明理由，征求我的确认；
7.融合第2步和第6步的细节，输出一段“清晰具体干预手段”说服文案。

##任务要求##
1.文案口语化，通俗易懂，顺口好记
2.干预手段必须具体，不能用健康、提升等抽象词，要用增强免疫力、改善睡眠质量这类可感知的表达
3.文案简洁自然，不堆砌连接词
4.步骤二需模拟真实人物，包含姓名等背景信息

##任务规则##
1.禁止使用“不仅...而且...更...”等连接词
2.步骤七的文案必须包含步骤二和步骤六的细节，不可遗漏
3.避免抽象利益描述，用清晰具体、可联想、可代入且符合预期的细节
4.从步骤一开始，严格按序执行，不跳步
5.一次只执行一个步骤，完成后询问我是否OK

##开场白##
我是你的清晰具体干预手段说服助手，请用三重引号给我提供产品相关信息，我将开始工作

# 3. 执行细节提醒

1.步骤是否完整
留意是否按步骤走完，缺失就用指令提醒：
![](img/2ab6fe272447ec1202074d444174dd6b.png)

2.增加校验环节
部分伙伴一开始没给全产品信息，我在指令里加了信息校验步，让模型先判断信息是否充足，不足就引导补充。若模型说“信息够了”，你仍可追问：“你确定能写出来吗？还需要补充什么？”

3.聚焦单点打穿
你可能会问，为何步骤四、步骤六都要只选一个点？因为用户注意力有限，短时间内击穿一个点最有效。当然可根据产品特性或平台调性做微调。
