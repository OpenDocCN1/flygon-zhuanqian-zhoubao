# 看了这么多文章之后,我对搞钱的理解

刷了那么多篇赚钱相关的文章后，我对“搞钱”这件事终于有了点自己的体会。

先感谢几篇让我茅塞顿开的干货，算是给我的认知做了一次大升级：

- 七小写的《思考了 4 个月，用万字长文，盘点阻碍我赚钱的 18 个认知误区！》
- 明白写的《如何通过分析成功案例，帮自己建立赚钱清单》和《看懂这张图，你未来赚钱会越来越轻松！》
- 敏渝写的《三无新人举手》
- 根源写的《9 年传统行业 1 年时间，从一无所有，到年入 200 万》

列表就这么短，不是因为我飘了，别急着开喷，接着往下看。

前前后后读了几十篇文章，发现大部分内容里的核心认知，其实都能被七小那篇长文覆盖或总结掉。所以我就挑这篇最有代表性的放出来，再次给七小大佬点个赞。

接下来，我从自己的角度，聊聊对赚钱这件事的理解。按认知阶段分三部分：突然想搞钱 → 网上乱逛没头绪 → 看着大佬心发慌。

先上目录：

**一、突然想搞钱**
1. 上班别急着裸辞，先搞副业，跑通了再全职搞。
2. “搞钱”到底是什么？
3. 我能靠什么搞钱？
4. 我这么普通、这么菜，还有戏吗？

**二、网上乱逛没头绪**
1. 知识永远学不完。
2. 这东西看起来太简单了，真能赚到钱？
3. 决定了搞钱，啥时候能见到第一笔收入？
4. 想进的市场已经卷成红海，巨头遍地，是不是没机会了？

**三、看着大佬心发慌**
1. 别人那么牛，我却这么菜，是不是天生不适合搞钱？
2. 同样的项目，别人跑得飞快，我是不是得换个赛道？
3. 大佬都是组团作战，我是不是也得招人建团队？
4. 看了好多项目，却不知道从哪下手。
5. 吭哧吭哧干了不少，效果却不怎么样。
6. 各大平台都在贩卖焦虑，这种营销也太 low 了吧。
