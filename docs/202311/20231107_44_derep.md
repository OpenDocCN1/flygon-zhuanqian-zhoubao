# 千粉📕账号，一年做到 200 万+ GMV？她的复盘值得认真看
作者：龙哥

最近刷到一份很有启发的📕实战复盘，作者自己做过三个账号，战绩相当能打：

第一个是服装穿搭类图文号，不到 7 个月做到 3.1 万粉，后来因为认证问题注销了。
第二个是轻奢珠宝类图文号，做到了 1.1 万粉，团队散伙后停更。
第三个是中古店账号，粉丝 1.3 万，却从📕引流了 1 万多个🛰️好友；2022 年全年 GMV 突破 200 万。最让人意外的是，2022 年这个账号其实才刚过千粉。

而且这 200 万不是单靠一个渠道撑起来的：既包含了从📕引流到线下门店的消费，也包括加上🛰️之后持续裂变产生的复购。

作者在复盘里反复提到一个观点：📕这个平台值得认真做，但不是“顺便发发”就行，而是要用更高效的方式运营，并且用矩阵思维去放大优势。

她自己当时属于“顺带运营”，同时还要忙门店营销和其他事务，没花太多精力，也没做矩阵布局。回看经历，她坦言自己这版打法其实不够高效，建议大家别学她，一定要把📕当成一个值得重仓的渠道，系统化、矩阵化去做。

完整的账号拆解和运营细节，她已经整理在飞书文档里了，想深入了解的可以去看看。
