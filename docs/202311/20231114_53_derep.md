# 十一月八日：给所有新闻同行一个可落地的增收思路
作者：龙哥

如果你在这天还在赶稿、剪片、盯直播，请先停一下。

11月8日，立冬。这个日子在很多人眼里只是节气，但对我们这行来说，它是一个纪念日。今年是我入行的第16年。我没有能力送大家什么大礼，只能把手上正在跑的一套赚钱方法，毫无保留地拿出来。它不能让你一夜暴富，但每月多九千到三万块，是能落地的实际收益。

这套东西我已经跑了三年，现在依然在跑。收入很稳，我觉得起码还能再撑三年。以前这是付费内容，通常我抽5%到10%的分成；今天特殊，不收一分钱，全部讲给圈内的朋友听。

先说说我的背景：2007年入行，做过暗访报道，当过主编，也带过内容团队，目前仍在新闻机构任职，负责单位的传播矩阵搭建。2018年起，我又开始做产品规划，带团队开发APP。这些身份让我有机会接触到不少内部打法。

# 收入怎么算？

拿头条平台上的账户来举例，B档水平大致是：

![](img/3676b8cab47acc34ad178ce0ced25d82.png)

每1000次浏览，系统给1元左右；1万次浏览10元；10万次100元；100万次1000元。所以三档的核心差异，其实只有两个变量：千次浏览的分成价格，以及单日浏览量。

为什么B档最多？因为分成价格一直是1元、单日浏览量也总是百万上下，这类号占了大头。

实测口径：单个号一天要放出100到150条短视频，一日的浏览量累计在百万上下，单号日入就是1000块。

# 入场有哪些硬条件？

这套玩法能跑通，很大程度上是因为入场壁垒高。我现在在操作的是三个渠道：逛逛、小世界、头条。不同渠道的结算逻辑各不相同，仍以头条为例。

账户需要同时达到两条标准：

1. 账户主体必须是新闻媒体；
2. 这个头条账户的注册时长，已经超过1000天。

![](img/590e7cbb2e4442d1d79fcd3bad2e9253.png)

![](img/494ce048d73710ec39a5feff7e6e37c9.png)

这两条，缺一不可。假如你恰好有满足条件的账户，看到这里，就可以直接来找我拿后续操作手册了。

要是你完全没头绪去哪找，我给个大概方向：拥有新闻采编资质的广电集团、报业集团、期刊社，以及各区县的新闻中心。2018年前后，这些机构大多批量注册过头条账户，发过几篇东西就再没管过。现在，这些“沉睡账户”恰好是选题的主力。它们里相当大比例的账户，靠运营都能进入B档。要是还有长期更新的账户，更好——里面可能藏着A档苗子。

我们机构里达到要求的头条账户一共19个，已经拿了12个在跑。

# 为什么值得做？

第一，能产生现金流。单号日入1000，月入3万。第二，能带来关注者。单号一天新增200到300关注，一个月就是五六千。

头条账户的关注者本身价值不大，但它和抖音账户绑定后，关注者数据是同步显示的。头条这边涨多少，抖音那边就同步显示涨多少。许多机构的抖音账户正在流失关注者，可考核指标又卡着每月涨粉5000。这套打法恰好把缺口填上。赚钱的同时完成涨粉KPI，里子面子都有了。

# 钱怎么分，活谁来干？

这是最关键的两个问题。

先说分配：账户产生的收入，个人拿30%。单个B档账户，每月到手9000；两个就是18000；三个就是27000。跑得多，拿得多。

再说工作量：每个号一日要做出并投放100到150条自制的短视频。想自己动手，我把整个流程拆给你；不想亲自动手，我告诉你外包团队怎么找。我这边则是把素材收集、剪辑、投放交给专业的外协团队，我只负责把关选题。

# 这个做法的变与不变

放在2020年前后，这套打法并不神秘，干的人很多。但那时候，赚到的钱全部进了机构账户，做事的人没有任何分成，动力自然就没了，做着做着就停了。当时千次浏览的分成最高能到6到10元，现在回想，确实可惜。

这两年，系统分成越压越低，头条还能维持在1元左右，其余渠道远不如它。不过，2020年的老方法放到现在并不奏效，照搬旧路效果反而更差。虽然单价降了，但干实事的人能分到钱，这比什么都重要。

这套玩法的重心，在于单日要产出上百条自制短片，逐条都得是原创。那么多自带版权的内容从哪来？这一步是整个操作的关键，现在只在这个社群内部展开讲，不会写进公开展示的内容里。心里有数的人，直接开工；没想明白的，随时私信问我。我再强调一次：这套东西只在这个社群里免费教，每一步都会讲透。

# 我最近在忙的两件事

第一件，是搭一张传播矩阵。具体动作分两步：先让参与进来的伙伴和所属机构看见回报，同时帮每家机构搭自己的传播矩阵——让每家机构在全平台至少拥有50个保持日更状态的活跃号；再把大家整合成一张协作网，统一发声，做跨城市的合作，放大收入。

第二件，是围绕大健康做整合。计划分三阶段推进：先搭一个电商板块，同时在全国10个城市布局疗养基地，基地主题会根据城市资源来定，目前已落地3城；再做医疗体育联动服务——身体有毛病的人，安排绿色通道挂号；身体没毛病的人，可以领到健身卡，并得到一套适合日常坚持的运动计划；状态不太好但没到生病程度的人，会根据体质得到饮食建议，并供应部分原料食材（绿色通道服务单独在跑，顶配会员年费30万，交付反馈不错）；最终会把四个板块合成一个完整平台：运营机制、团队培训、销售体系、客户服务。这块业务在我接管之前，已经投进去4000万，烧完后被迫叫停。后来我重新联络到投资人，对方恰好也有类似布局，双方一拍即合。手头有健康领域资源的朋友，欢迎一起碰碰想法。

# 最后

回到这份心意本身。这套操作的门槛不低，但所有新闻同行，刚好站在壁垒之内。凛冬之下，很多老牌新闻机构都在找出路，我给不了太多，只有这一点实打实的暖意。

你要是做新闻的伙伴，不必拘束，直接找我。有问题可以在留言区说。

帖子下面有人留言，问我是不是代运营公司。我再说一遍：我是广电机构的，不是代运营公司。只是手头还有其他事，找了家剪辑机构配合。想自己上手的朋友，完全可以自己动手做，具体方法我会教。
