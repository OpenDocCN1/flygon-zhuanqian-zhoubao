# 一家小公司怎么做传播

**小公司没钱怎么做传播？小马宋这些“土办法”太实用了**

很多人问，小公司没钱怎么做传播？小马宋的回答既朴素又直接：别总想着靠钱砸，而是要把自己变成到处找出口的人，不断发现那些能帮你发声的资源。每一分预算都要花出回报，成本越低越好。早先他做网站时，就靠着给创业媒体投稿，拿到了不少免费曝光。后来第九课堂真正开张，依然没什么钱，但他照样把传播做得有声有色。

先说他干过的一件“不可能”的事。当时他的办公室在建外SOHO，那里算得上北京最早的一个办公楼集群，整整30栋楼。他盯着这片区域，心想：楼里的人不就是目标客户吗？要是能让每栋楼下都贴上自己的海报，那该多好。乍一听像白日梦，但他愣是给做成了。

有一天，他看到街道办事处在建外SOHO办理财讲座，便专门跑去现场。活动结束后，他找工作人员闲聊，发现对方愁的是搞活动请老师不容易。他随即说：我可以帮你们找老师，但你们能不能帮我把海报贴到建外SOHO所有楼下？后来他见到了街道办书记，对方很痛快：海报给我，我让人帮你贴。资源一置换，这个看似不可能完成的任务，就这样轻轻松松下马。

线下有了曝光，线上也没有闲着。他们有一门文案写作大课，客单价定在一两千元。为了给这门课拉人，小马宋在微博、豆瓣等平台到处下功夫。有一次，他花钱请一位广告圈的微博博主首发长文，内容实在太有趣，发出后直接被罗永浩、李开复这些大V转发，瞬间爆掉。他发现这招管用，就继续写下去，一两个月一篇，一连写了8篇《一个文案的自白》，篇篇都能在圈内刷屏。

也正是这些被疯传的内容，催生了他的公众号。当时他发现，看的人多，报名的人数却有限，流量白白流失太可惜。于是他注册了个号，起初叫“中国文联”（中国文案联合会的简称），后来改成“小马宋”。每次做推广就顺手带上二维码，第一批粉丝就这样攒了下来。

说起来，他做号还是受了沈鹏的启发。那会儿沈鹏在美团没太多事，随手注册了个营销类公号，结果忘了密码，几个月后登进去才发现，一篇文章没发，已经有6000多粉丝——那正是公众号的红利期。沈鹏当时还来第九课堂讲过公号经营，小马宋便跟着注册了一个。后来沈鹏筹备美团外卖时，两人还聊过业务模型，再往后沈鹏创办了水滴。

大学生这块，他们也没有放过。当时想给广告、营销专业的学生讲文案，团队里的王兴华就去对接各校学生会。那段时间，小马宋和同事们拼了命地跑校园，短短两个月，从北京、石家庄、廊坊、保定，到烟台、威海、济南、郑州、西安，一路讲了60场。住的是经济型酒店，两人挤一个标间。一场下来少说也有200人听讲，从民办高校到中传、北大，什么学校他都去过。这60场让他原本不擅长的演讲能力飞速提升，也成了他微博号首批粉丝的主要来源。他后来形容：以前社恐，因为到处找老师，硬是把社交能力练出来了；不擅长演讲，是因为一次次讲同样的内容，讲到快吐，反而再也不怕了。再后来，他签约客户的市场部同事，正是当年在北大听他讲课的广告系学生——这大概就是“今天的成功来自昨天的努力”最好的注脚。

那段时间，团队里也有几位关键人物。负责推广的郭文龙，曾就职于美团。他算不上多有灵气，但擅长把目标拆成一块块，做事踏实到可以一直往前拱。后来他回到山东潍坊，在淘宝上替人装系统，一年也能做到百万级收入。另一位是王兴华，之前在一家面向大学生的培训公司，后来去了深圳，如今是深圳顺道出行的CEO，当年校园巡讲能跑起来，很大程度靠他跟各校学生会的对接。那时的合伙人还有黄有璨——也就是后来《运营之光》的作者。另有一位运营负责人，网名叫飞鱼船长，之后也自己创业。王兴华后来还爱开玩笑，说跟小马宋“睡”过好多回。

线上投放方面，他们选的也都是又便宜又精准的位置。豆瓣有大量文案、广告类小组，小马宋就去找组长，花200块把广告帖置顶一周，一口气铺了许多小组。还在顶尖文案、数英网这类专业平台投过广告，价格不贵，全靠内容撑住效果。小马宋说，传播这事没什么玄学，就是找到目标顾客出没的地方，把信息送到他们眼前。虽然偶尔会冒出爆帖，但更多生意，是靠一场场讲课、一次次博主投放、一个个小活动累积起来的。那阵子公司算不上富，但一年也有几百万进账，起码不是靠烧钱续命的。

这些看起来土掉渣的打法，其实藏着最朴素的传播逻辑。他还留了个悬念：明天接着讲第九课堂后来的经营困惑，以及他最后为什么退出这家公司。别错过。
