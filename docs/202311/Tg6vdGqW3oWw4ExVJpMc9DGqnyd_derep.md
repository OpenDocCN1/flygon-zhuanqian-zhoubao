# 从0到30万+：我如何用AI切入线上文字兼职赛道

大家好，我是龙哥，00后，创业三年。去年12月，我在龙哥盟第一次听说GPT，当时公司主业是知乎和📕的内容营销与文案代写。AI一出来，说不慌是假的，但慌完就逼自己上手学。当时各种项目和提示词都得去GitHub翻，我英语很差，只能硬着头皮啃。好在一段时间后，我摸出了一条路：把GPT和公司积累的内容生产方法论结合起来，去写客户要的东西。

在把GPT用熟之后，我进了一个线上兼职投稿群。群里客户发单，写手接单，需求天天都有。10月份群里消息的截图如下：

![](img/3ca125d55469934ca179bf154a7e3d94.png)

看到这种生态，我脑子里冒出一串问题：中国的文字劳务市场到底有多大？能不能把GPT当成提效工具，做成一个项目？在个人写手和专业内容公司之间，有没有可能夹着一个“AI生产内容+人工把关”的文字劳务公司？带着疑问去调研，我发现这事儿真能落地。BOSS直聘上有大量需要文字服务的公司，我叫它们劳务公司。这些公司大多数知道GPT，但基本没用起来，或者干脆觉得不好用。甚至有些客户打心眼里看不上AI写的东西。可我们实际做下来，AI出初稿，人工改润色，很多客户根本分辨不出来。

接了足够多订单后，我发现了客户订单的结构：
- A级：品类固定、数量稳定，占43%
- B级：品类不固定、数量稳定，占17%
- C级：品类固定、数量不稳定，占18%
- D级：品类不固定、数量也不稳定，占22%

针对这个结构，我做了两件事。

第一，用“AI文字工厂”的逻辑长期吃A级和C级订单。这类需求品类固定，打磨出一套提示词就能反复用，好上规模、好标准化、好流程化。然后招更多人，开更多客户，建更多文案生产线，去抢占更大的市场。

第二，从B级和D级需求里制造新机会。这两类品类不固定，我一开始也先接单，合作一两个月后坦白：前面的内容其实是用GPT加人工润色写的。然后顺势引导客户买提示词，一套可以卖到5000到50000。只要交付质量稳定，客户真不太在乎你用什么手段，他们只看结果。而且坦白之后客户并不会跑，你能保质保量，他反而更省心。

为什么我选这个项目？因为需求大量不在大城市，而在下沉市场。比如一家五线城市的幼儿园，园长想拍短视频，但团队从没干过，只能花钱去外面找脚本，预算也就200元左右。这类需求在BOSS直聘上一抓一大把。

我自己总结了一条AI项目公式：

**自身专业能力 + 可复制的AI提效方法 + 下沉市场洞察 = AI项目**

这条公式不只适合文字。图片设计、图片制作、图片加工，我们也在慢慢复制同样的玩法。

另外，文字的价值很容易因为客户预期而溢价。举个例子：一篇3万字的短篇小说，如果只是发在知乎上当连载，收入少得可怜；可要是卖给抖音短剧剧组，价值可能翻几十倍。现在有不少专门收“本”的公司，我们先帮他们干活，混熟之后再把提示词卖给他，两全其美。

这个项目还能做长线。线上兼职对劳务公司是好事：业务高峰比如618、双11需要人手时，兼职随时顶上；不用交社保，工资也不高，工时还能按需排。成本可控，这模式他们当然愿意长期用。

接下来拆收益。订单类型不同，价格天差地别：

- 各类文章：👸号、微头条、历史、传记、人物故事、情感等，30到500元/单，情感类最值钱。
- 📕文案：多数来自代运营公司，少数来自品牌公司，5到200元/单。
- 直播脚本：常见的是农产品话术，客户多为小地方直播或抖音代运营公司，300到800元/单，看时长。
- 纪录片文案：100到5000元/单，也是时长决定价格。
- 情景剧、舞台剧、剧本杀剧本：100到10000元/单，我们最高纪录是剧本杀8000元/单。
- 情景剧、舞台剧、剧本杀台词：50到3000元/单，单量偏少，因为有的客户要求写剧本的人连台词一起写完。
- 短视频脚本：舞台剧、年会、短视频公司，多为小城市小公司，30到200元/单。
- 短篇小说：收稿的是小说公司、知乎推文团队、短剧剧组，常见字数1.5万到3万字，价格2000到10000元/单。
- 长篇小说：收的公司少，多半是专业作者，谈成一个客户能忙活很久，7万字起步，5000元/单起。

再说实操。平台直接认准BOSS直聘，其他平台别浪费时间。我们踩过58同城、猪八戒、甜薪工厂和各种兼职APP的坑，花了不少冤枉钱和时间。那些不诚信的平台做不长久。一句话总结：挖BOSS直聘这座金矿，用AI收割平台上的劳务预算。

简历嘛，说重要也重要，说没那么重要，它就像商品售前页。找个简历网站充个会员，选文案模板，把公司名、工作日期、姓名、照片、年龄一换，包装出几年文案经验，再顺手改改智能诊断的提示，基本能到80分。照片别用真人，用证件照去妙鸭相机生成一张好看的头像。

试稿一定要上心。简历不出错就行，试稿过了，后面审核宽松的单子才会不断涌来，每一次试稿都是一次现金流机会。

试稿守两个诚信：时间上准时交付，内容上要过自己这关。至少要跟对方给的范文水平相当。小妙招：研究范文每句话的字数，再看看每个自然段有几句话，把这两个点对齐，风格基本就贴近了。

试稿挂了大不了再来，转化率本来就不可能是100%。心态要稳，拜拜就拜拜，下一个更乖。如果不甘心，可以再问对方能不能给一次机会，虚心要修改意见。一般来说，第二次试稿通过的几率很高。

日常接单有两个提醒：

一是被甲方提需求或给反馈时，别上头。要感恩，因为这些都是一线实战经验，花钱都买不到。GPT用得多深，取决于你的知识体系。AI下半场一定是服务B端，过程中积累的经验和迭代的提示词，才是最值钱的资产。

二是做好甲方不给钱的准备。我们也被逃过单，所以交稿前一定要打码加水印。遇到不诚信的人直接拉黑，不用纠结。这个社会还是讲诚信的人多，专注做单就好。
