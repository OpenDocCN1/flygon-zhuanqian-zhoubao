# 自媒体一环：内容方向生产 AI指令交付文档
作者：龙哥

把ChatGPT训练成📕爆款选题机：这套提示词流程请收好

做📕内容的人都知道，光靠灵感写选题，迟早会枯竭。我最近一直在用一套提示词工作法，让ChatGPT先吃透平台生态，再基于产品输出爆款方向，亲测效率很高。今天把这套流程完整拆给你，分“循环调教”和“一次性打包”两种玩法，第三种是后续调节技巧。

一、循环调教：六个指令把AI喂成📕专家

强调一下，最好用ChatGPT网页版4.0，全程锁死在同一个对话窗口里按顺序发送指令，中途别开新窗口，否则前面积累的理解直接作废。

指令1：先让AI建立基础认知
直接告诉它：“你了解📕吗？请为我做一份📕用户画像分析。”

指令3：把平台玩法喂给它
这一步信息量最大，核心是让AI吃透三块内容——

发文形式有六种：
第一种，单品安利。只围绕一款产品展开，突出真实使用痕迹。开头可以讲自己遇到了什么困扰、怎么无意间发现这个产品，最后落到亲身体验上。文字里少堆砌功效词，图片要显得自然，像随手拍的而不是精修广告图。
第二种，横向评测。把同类产品放一起做对比，用打分或排序的方式讲清楚各自的优缺点、成分、价位、适合人群。
第三种，主题打包。比如待产包清单、新年礼盒合集、短途出行必备、双十一犒劳自己的礼物，围绕一个生活场景把多款产品串起来。
第四种，干货科普。销售感要压到最低，核心是分享有用信息。你得先摸清用户真正关心什么问题，再把这些问题转化成内容，用个人经验去化解他们的疑虑。找到真需求、放大痛点、选准切入角度，这三件事和封面图、文案质量一样重要。
第五种，场景叙事。从某个生活画面切入，比如浴室一角，顺着洗漱护肤的动线自然带出沐浴露、洗发水、身体乳等产品。可以用大牌给自家品牌引流，类似“李嘉诚、马化腾、马云、王健林和我，这五个人的身价足以撼动整个亚洲”这种借势思路。
第六种，教程攻略。把产品放进具体操作步骤里，比如用身体乳或磨砂膏教刷酸、美白，既有实用干货又完成了推广。

这六种形式不互斥，像“干货+教程”“合集+场景叙事”都可以混搭，关键看怎么铺最有效。

卖点提炼则从三个角度切入：
功效层面——产品解决了什么问题，用户使用时的真实感受。
场景层面——如果产品力不够突出，就从生活场景找价值感，用好看的布置烘托产品，但场景和道具必须贴合产品气质，太假会翻车。
体验感层面——强调五感细节：握在手里的质地、看在眼里的颜值、闻到的气息。把真实的感官体验写出来，比干巴巴的产品说明书动人得多。

还有两条补充原则：
找参考爆文时，别困在自己的品类里。比如晚上饿了，在外头宵夜和零食不算你的对手，但宅在家里就算。竞争对手是随场景变化的，所以想清楚产品可能出现在哪些生活或消费场景，去这些场景对应的类目里找爆文模版，网会大很多。
同行内容可以参考，但绝不能抄，拿来用的部分要改到认不出原样，避免搬运风险。

指令4：给AI立好人设
把身份牌递给它：“假设我开了一家📕内容创作公司，你是员工。你的第一项任务是吃透我给的内部资料，之后我会陆续给你产品信息。你需要结合产品实际、内部资料，以及你对📕用户弱点和欲望的理解，产出能引爆的软文方向。收到请先复述你的设定。”

这里要特别告诉AI，好内容的标准是：精准触达目标人群，戳中他们的爽点，但表面看不出广告痕迹，产品信息是在潜移默化中传递出去的。

![](img/4540cae60b351987d0e032350b4823be.png)

指令5：让它总结爆款标题的底层规律
跟它说，我最近刷到一批数据特别好的内容，点赞评论收藏都爆了，请你找出它们受欢迎的共同逻辑，学习这种风格语感，不用逐条分析，提炼共性和通法就行。

然后把类似这样的标题发给它作为样例：“宝子们闭眼选面包不踩雷”“驿站取件被路人追问链接”“每天早起的动力就是这一口”“早八人多睡半小时的秘密”“做了1000个吐司总结的10个避坑点”等等，也可以换成你自己行业里真正跑出数据的标题。

之后还要给AI一套标题质检标准：
1. 关键词必须突出卖点，比如“小众”“性价比”“质感”或人群标签“百元”“无糖”“无痕”“三分钟”。
2. 从用户视角说人话，戳中具体痛点，比如“梨型身材”“圆脸”“微胖”“小个子”“看一眼就心动”。
3. 蹭当下热点词，灵活融进标题和关键词。
4. 标题加emoji提升眼球吸引力，头图用花字标签补充卖点信息。
5. 内容要有力度、能引发共鸣。想明白自己刷📕时为什么愿意点赞和收藏，才能真正理解用户互动的动机。

指令6：正式进入产出阶段
跟AI说，前面几轮内容吸收得很好，现在要你在不照搬的前提下做创新。接着给它产品资料，要求生成十个爆款内容方向，互相不能重复或高度相似，既要满足用户需求，又要让产品信息自然融入，并严格按这套模板输出：内容方向／爆火标题／利用了哪些需求点、人性弱点、爽点、欲望点、恐惧点／主要从哪个层面提炼卖点／属于六种发文形式中的哪一种。再加一句强度拉满的限定：人性弱点和欲望点的利用必须有极强针对性，做到让人不点开就觉得亏大了、会后悔。

二、一次性打包：把六个步骤合成一个大提示词

如果嫌一步步太麻烦，可以把上面所有要求揉进一段完整提示词里，让AI自己按步骤边理思路边执行。大致框架是：

身份设定（你是📕内容创作公司员工）→ 第一步分析用户画像 → 第二步拆解人性弱点与深层需求 → 第三步学习发文六形式和卖点提炼三层面（功效、场景、体验感），以及找参考爆文不局限品类、借鉴但不抄袭的原则——同时记住好内容要触达精准用户、戳中爽点但看不出广告痕迹。然后把高互动标题样例喂给它，让它总结共性通法，再根据标题五条标准去做判断。最后让它针对你提交的产品信息，产出十个不重复的爆款内容方向并按模板输出。

三、拓展指令：不满意就继续调

AI产出的内容不达标时，直接提意见就好，不必重开聊天。比如“语言太书面，广告味太重”“选题吸引力不够”。输出形式也可以改，像“改成故事化标题，但标题中完全别提产品，结尾再带出”。如果某批方向特别满意，就让它“再多来二十条”。内容太多想要筛选，就让它“把刚才的方向提炼成标题，按互动潜力排序，容易被点赞收藏评论的排最前面”。

这套流程看似步骤多，核心逻辑其实很清楚：先把📕的内容生态和用户心理原原本本喂给AI，让它在理解的基础上生成方向，而不是瞎编。多磨合几轮，你就能拥有一台稳定的爆款选题生产机。
