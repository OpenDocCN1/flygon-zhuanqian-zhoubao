# 船小惊涛骇浪，组好班底才算真起航

早期创业就像开一条小船出海，风浪说来就来。光靠船长的眼光与决心远远不够，必须有人掌舵、有人掌帆、有人看风。

创始人往往在某个维度极致出色，但天无全才，短板必然存在。而这些短板，恰恰是联创要去补位的关键。数据也印证了这一点，近十年成功创业的团队里，平均联创人数已经攀升到 3.7 人。换句话说，一位船长要在航路上稳定前行，通常需要 3.7 个不同方向的核心伙伴共同组队。

在起步阶段，团队本身就是最硬的壁垒。选对的人、配齐的人，比任何商业模式的包装都更重要。而真正优秀的联合创始人，是稀缺品。稀缺不只是因为门槛高，更因为要价值观契合、节奏一致、能真正心有灵犀地并肩作战。
