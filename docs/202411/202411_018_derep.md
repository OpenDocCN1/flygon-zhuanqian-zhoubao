# 从“交门票”到“赚回门票”，一个普通小白的第一个副业闭环
作者：龙哥

今年三月底，我咬咬牙给龙哥盟续了费。说实话，当时心里也没底，就是觉得不能一直当观众，总得下场试试水。到了九月，航海计划一开，我挑了个项目就跟着上了船。没想到，这一趟居然真的跑通了——从零到一，拿到了人生第一笔副业收入。到今天算下来，刚好把当初那张门票钱给挣回来了。

这点钱在各位大佬眼里可能连零头都算不上，但对我来说，意义完全不一样。它像是一个里程碑，让我这个纯小白第一次感觉到“我也能行”。那种对生活的掌控感，还有对自己的信心，一下子就不一样了。真的，特别感谢赚钱这个圈子，太爱了！

对了，忽然想到，要是每个小白都把“先赚回一张门票钱”当成第一个小目标，好像还挺带感的，哈哈。
