# 第二期龙珠悬赏：AI 生成视频在 YouTube 的盈利潜力
作者：龙哥

第二期龙珠悬赏，正式开擂！

上一期龙珠悬赏的结果才刚出炉，咱们不歇气，第二期马上接力。前几天我聊过一个方向：用AI批量生成视频，发到YouTube和Shorts上，靠广告分成或电商带货变现。当时我就说，这个空间相当大。结果没几天，圈里就有人跑通闭环、晒出收益，还跟着抛出了一大堆硬核内容——

比如，有人把做YouTube的方法论整理得明明白白；有人加入了YouTube合作伙伴计划（YPP），直接分享实战数据和经验；有人搞来了一套方法，收集了一万多个YouTube Shorts AI视频当作对标库；有人基于600个不露脸频道的实操，教你通过油管官方API去采集对标账号；还有人把千次播放、万次播放的收益彻底拆解，并讲透了Shorts的收益分配机制，以及大多数解说赛道的玩法。

这些内容，感兴趣的圈友都可以去翻一翻，作为热身。

那么，第二期悬赏的主题是什么呢？很简单：请你找一个你判断“正在赚钱”的YouTube或Shorts账号，把它拆解并复刻。上面提到的那一万多个对标账号都可以参考，优先选择不需要露脸的频道，AI生成类或非AI生成类都OK。

具体展开，可以从这几个角度入手：

- 先说清楚你为什么会选中这个账号，并尽可能深入估算它的收入水平；
- 然后研究它的内容选题：账号到底在发什么内容？哪类内容容易爆？如果换成你来运营同类账号，第一批选题你会怎么选？
- 接着举一反三，再找十个类似的频道，看看它们的收入情况如何；
- 最后给出一份可落地的行动方案：假设你要正式启动这个项目，三个月的目标是什么、行动计划怎么排、有哪些难题必须先解决；
- 当然，其他任何有价值的补充都欢迎，格式不限于以上。

奖励方面，本次悬赏截止到11月8日，排名前50%的参与者可以共享一颗龙珠。需要注意，这次不按点赞数排名，而是由专业评审组根据分享内容的价值来评选；只要参与，都会有参与奖励。

最后再提醒一句：请务必认真审题。上一期就有几位圈友因为没看清题目，发的内容和悬赏主题根本不搭边，真的很可惜。

好了，话不多说，舞台已经搭好，各位“传术师”，轮到你们上场了！
