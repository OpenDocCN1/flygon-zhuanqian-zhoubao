# 如何写出令读者喜欢的 IP 产品文案
作者：龙哥

**IP文案怎么练，才能让读者一眼就爱上？**

我是龙哥，一个总把“翻盘”当习惯的IP博主。很多人问我，为什么我写的东西总能被读者夸“有感觉”？其实没什么玄学，我只做对了一件事：把产品文案当成跟读者面对面的聊天。你想想看，产品内容本质上就是你对读者说的话，既然要说话，总得先弄清楚——你在跟谁聊？你想让他记下什么？你用哪种口吻他才愿意听？

这三点，就是我搭文案框架的全部家底。跟谁聊，决定你站在什么位置开口；记什么，决定话语里的含金量；什么口吻，决定他能不能笑着看到最后。

我不太爱讲空道理，直接给你看我的实践。学IP才两个月的时候，我按这个思路写了一篇近万字的深度长文，后来有位朋友评价说：“哪怕你的文章混进五位数的付费专栏里，也不会掉价。” 这句话让我挺意外的，但也让我彻底相信：能打动读者的文案，背后一定有一条清晰的逻辑线。

今天我就把“和谁聊、聊什么、怎么聊”这三个问题摊开讲透，再附赠几个我私藏的写作小技巧。完整内容放在飞书里，随手打了#项目拆解#的标签，好奇的朋友直接点链接去看。
