# 设计人和老板都得看：字体与配图踩雷全记录，侵权真的会一字值钱、一图赔光
作者：龙哥



最近在帮老板做品牌宣传和个人IP打造时，反复被问到同一个问题：用在海报、短视频封面、👸号推文里的字体和图片，到底能不能随便用？

其实这类需求是共性的，一家老板的困惑就是一群老板的痛点。所以这篇梳理，是想帮做自媒体、做广告投放、做品牌建设的同行们，提前把坑避开。

不管你是接单的自由设计师，还是管理团队的公司负责人，亦或是正在经营个人IP的创作者，字体和图片的版权雷区，都绕不开。以下是我整理的实操避坑框架。

**一、字体侵权，真的能做到一字千金**

1.1 字体到底有没有版权？
字体文件本身受著作权法保护，字形设计属于美术作品范畴，未经授权商用就是侵权。

1.2 法律依据是什么？
著作权法明确规定，未经著作权人许可复制、发行、通过信息网络传播他人作品的，属于侵权行为。字体商用属于前述行为。

1.3 真实案例：为一字赔上万元
司法实践中已有“文字侵权一字万金”的判例。法院会综合作品使用量、传播范围、获利情况来计算赔偿，动辄数万起步，企业承担不起。

**二、自媒体配图侵权，代价远比你想象的重**

2.1 图片侵权的法律依据
与字体同理，摄影作品、插画、设计图等均受著作权保护。未经授权商用发布，构成侵权。

2.2 怎么判断一张图能不能用？
看来源是否明确授权、是否标注了不可商用、是否属于原创发布。网络上流传的“免费图”绝大多数默认不可商用，尤其在🧣、📕、抖音等带有商业属性的账号发布时，更容易被认定为商用。

2.3 图片侵权会坐牢吗？
以营利为目的、侵权数额巨大或情节严重，依据《刑法》第217条可构成侵犯著作权罪，最高可处三年有期徒刑，并处罚金。评论区已有创作者分享：三年前🧣发的一张网络配图，上个月被诉，最终赔了1500元。

**三、字体怎么用才安全**

3.1 先查版权，再选字体
优先查阅官方版权公示网站或权威字体库的授权说明，确认是否支持商用。

3.2 尽量避开的高风险字体
市面上常见的部分付费商用字体，如未获授权就用于对外宣传物料，后续维权概率极高。尤其是知名品牌定制字体、设计师独立发布字体，谨慎使用。

**四、真正能免费商用的资源去哪找**

4.1 免费商用字体渠道
可通过国内主流字体开源平台、政府公开字体库、以及明确标注 SIL Open Font License 的字体库筛选。

4.2 免费商用图片渠道
推荐使用 Unsplash、Pexels、Pixabay 等境外平台，以及国内明确标注可商用的图库。注意即使是免费图，也要保留授权链接和截图备查。

**五、花瓣上找素材的实战技巧**

很多设计师习惯在花瓣网找灵感，但花瓣本身是聚合平台，并非授权源。正确做法是：在花瓣上找到喜欢的图后，追溯原始出处，确认版权方是否允许商用。优先收藏标注“可商用”“CC0”的合集，并建立自己的素材白名单库。
