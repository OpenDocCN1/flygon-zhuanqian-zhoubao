# 我折腾过的AI项目，和一路踩出的商机
作者：龙哥

这个赛道还没凉，机会一直都在。

我这些年在AI圈子里折腾，做过不少项目，有赚有亏。今天把一些经验摊开来说，给大家做个参考——这行里头的机会，真的还有不少。

**海外账号：门槛就是护城河**

ChatGPT、Claude这类账号，注册和支付都有一定的门槛。可正是因为有门槛，早期才有人靠“代开/代充”赚到钱。新事物刚冒头，谁能先跨过门槛，谁就能吃下竞争优势。

**小程序+套壳站：红利来得快，退得也快**

小程序刚火那阵，我入局做过，确实有过不错的收益。后来监管收紧，好日子就到头了。套壳网站也一样，早先推广轻松，现在环境变了，玩法必须跟着调。

**技术：把comfyUI吃透**

在绘图这块，我一直死磕comfyUI，调参数、做优化，常跟同行交流，出图的质量一点一点堆上去。这些看似笨功夫，恰恰是护城河。

**工具：给API插上“傻瓜”模式**

很多朋友不会调用ChatGPT等模型的API，我就开发了降低调用门槛的小工具，让非技术用户也能轻松上手。解决别人的麻烦，就是自己的生意。

**MVP：用Cursor狂跑试错**

我习惯用Cursor快速搭出MVP，直接丢到市场里验证。数据行就行，不行就掉头。这种快节奏打法，让我始终不掉队。
