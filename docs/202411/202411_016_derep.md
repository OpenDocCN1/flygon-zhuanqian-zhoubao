# 从新手到全职：碧梨的航海成长与成绩汇报

第一次航海，成交额没过千；第二次，6700；第三次，20多万。

大家好，我是碧梨。今年四月底加入龙哥盟，跟着航程一路走到了现在：五月在视频号打百货，七月在视频号做图书带货，九月转向抖音做精致达人。虽然不敢自称资深玩家，但也算是经历过三轮风浪的老船员了。

这一轮，我是全职投入。每天睁眼就开始干活，和上班一样，一直忙到夜里十一点半才不得不收手。不是不想停，是活真的干不完。

回头看，前两次视频号航海给我的最大收获，其实不是成交数字，而是镜头感。刚起步时我连出镜都不敢，特别怕熟人刷到我发视频卖货；如今哪怕旁边站着人，我也能坦坦然然对着镜头讲，表情和语气都能放得开。这变化，是花了三个多月一点一点磨出来的。

赚钱这件事，真没什么不好意思。围观的人根本不重要，重要的是那些看了你的视频、愿意下单的人。

再说句大实话：这篇更多是我个人的航海体感记录，真正的方法论，盗坤团队的《精致达人孵化手册》已经写得很透，教练也一路细致陪跑，深夜还在为你指引方向。我能做的，大概就是把自己交给时间，把该做的事一件一件扎扎实实落地。

从月销三位数到六位数，从怕出镜到全职投入，这段航程还在继续。也谢谢一路互相鼓劲的好搭子——做项目，真的需要有人一起往前走。
