# 一个90后宝妈的自媒体破局笔记：从瞎拍到月入破万

大家好，我是龙哥。

90后宝妈一枚，家里有个让我上头的小棉袄，有一个力挺我做自媒体的老公，还有一对每天给我作品刷赞的父母。

现在手上在跑：2个抖音号，粉丝1.3w和1k；3个视频号，粉丝8k、7k、2k。最近30天，视频号成交1.93w，抖音1k。今天把自己这几年在赚钱航海里挖到第一桶金的经历摊开聊聊。

**01 探索期：闷头练手，网感是撞出来的**

2019到2024年8月，我就爱拿手机拍娃。抖音上开了个萌娃号，发女儿日常，蹭上几次热门，播放破百万、点赞几万，粉丝冲到2k就卡住了。自己东摸西试，也没找对门路。

2024年8月，我第一次跟上赚钱的视频号带货航海，选了真人口播带书做情感内容。硬着头皮连拍近100条。结果口播状态忽高忽低，3个号只有2个破千粉，卖出几单书就没了。

真人出镜对我来说是巨大的心理坎。我把自己拆了重建，明知道第一版视频不堪入目也发了出来，就靠老公和父母的点赞撑着。那段时间的努力很笨，真的不建议复制。

**02 转机：两次连麦相面，找到了舒服的赛道**

第一次连麦是鹏老师的相面。老师和群里朋友的点评让我看清了自己的特点，也提醒我要用自己舒服的方式表达。后来我找身边人聊，发现大家眼里的我就是温柔、絮絮叨叨讲故事的类型。于是确定了情感表达的调性。

第二次连麦，老师问我不为带货会挑什么书。想到自己常去图书馆，个人成长、人文历史、自媒体技巧都会看，但总会留一两个名额给育儿书。我当时就指了育儿类。那次被老师和群友鼓励后，我决定把沉睡的抖音2k粉老号捡起来，又新开了一个育儿视频号。

情感书单号后续没啥起色就先放下了。意外的是，航海期间育儿号几条视频炸了，抖音冲到1.3w粉，育儿视频号也涨到7k。

**03 取舍：忠于热爱，放弃精致达人**

最近一次航海是抖音精致达人。几天里学到一套很系统的带货方法论。但我反复琢磨：我不是精致女性达人的人设，也学不来那种高感染力的精致带货表演。纠结一周后，我选择忠于自己。长期想深耕的还是育儿，我热爱它也擅长它。达人号和育儿号没法兼顾，最后只能放弃精致达人航海，难受得哭了一场。

也在这里喊一句，做育儿号的宝爸宝妈们请猛戳评论，让赚钱看到我们这艘船的需求，哪怕是迷你航海也行！

**我在赚钱这一年的能力变化**

加入赚钱后，每次航海都在给我加buff。

文案：以前只按自己的想法写，很真诚但自嗨。现在是先学再改，挑爆款视频拆解，写能解决用户痛点的文案。
拍摄：从拿起手机就拍孩子，变成会布局场景、打光、构图。
剪辑：从手机剪映升级到电脑剪映，还会混剪了，效率明显提升。
出镜：演技味太重，现在找到了舒服的表达方式，找了对标账号，口播更自然。
接单：以前自己掏钱买样，几乎不聊商务。现在主动加商务，视频爆了后有稳定合作，成熟商家会提供寄样、文案、投流，我只需把拍摄做好，对兼职党很友好。
类目：从玩具、母婴日用品，转向主推童书、教辅、文具、益智玩具，少量食品。
风格：从萌娃日常、情感图书的低变现，到现在的童书、学前小学教辅为主，亲子出镜+口播+桌拍结合，最近还敢试中学教辅口播。
成交：以前几百块可忽略不计，现在近30天视频号1.93w，抖音1k。

**最后说点心里话**

育儿号很累，但成长感和长期复利很明显。你是刚观望、浅尝辄止，还是已经深耕？

在赚钱的第一年，我的副业发生了质变。宝妈的自由时间很稀缺，我基本把能空出来的时间全砸在了事务上：对接商务、发视频、跟投流。

不过樊登读书的一本书点醒了我，我不能一直卡在执行层。最近我硬挤出10%的时间来复盘、学习、吸收，试图从执行者转向领导者视角。

短视频带货工序很多，后续我会考虑签约MCN，把精力集中在内容质量上。每天也固定半小时泡在赚钱里，同时去其他平台拓宽视野。

我开始在想几个问题：
我能从常参与航海的船员，变成赚钱的航海家吗？
我能从自己带货，变成教别人带货的人吗？如何找到更高能量的圈子，搭起一个小团队，在教人的过程中系统提升自己？

最后的期待：赚钱的项目密度很高，不知道有没有像我一样做育儿号的宝爸宝妈。我们是不是都在等一个育儿相关的航海，不管是常规、长途还是迷你。
