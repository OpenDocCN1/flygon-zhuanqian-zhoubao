# 探索 AI 视频制作流程：从图片提示词到最终视频的简易步骤
作者：龙哥

很多人一听到“做AI视频”就以为要懂编程、会剪辑，其实真没那么玄乎。整个流程只要你会点开软件、点几个按钮，就能搞定。

具体怎么做？我给你捋一遍：先写一段图片提示词，交给工具生成一张图；接着用“图生图”功能，把这张静态图变成三五秒的动态片段；如果你想更有氛围，可以配一段音乐（这步看你自己，不是必须的）；最后把视频片段和背景音乐合到一起，导出就完事了。

没错，就这么简单。不需要任何技术基础，唯一的要求就是愿意动手操作。顺便说一句，如果你身边有人提到“魔法”，那只是跨网络的小工具，跟视频制作本身没太大关系。

想上手的朋友，按这个思路去试就行，剩下的交给工具本身。
