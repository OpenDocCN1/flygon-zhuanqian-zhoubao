# AI 博主分享“小猫补光灯”App 开发与小红书推广经历

最近，小红书上一款叫“小猫补光灯”的App突然火出圈。很多人可能已经刷到过它的种草笔记，但未必知道，这个爆款小工具的开发者，竟然是一位不会写代码的AI博主。

先看一组让人惊讶的数字：其中一条小红书笔记的阅读量达到118万，点赞数7.3万；App上线没几天，下载量已经超过3万；在App Store的分类排行榜上，它最高冲到第20名，前面是YouTube、Instagram等超级巨头。

这款产品的故事，要从前几天说起。那位分享过YouTube运营经验的博主“花生”，在赚钱社群里看到有圈友提到自己刚上架的App在小红书火了，并建议他写篇复盘。据他介绍，自己上周一正式上架了“小猫补光灯”，整个过程堪称极速：他不会编程，也不是工程师出身，纯粹靠AI编程工具Cursor，只花了一小时就写完代码，第二天就通过了苹果审核。

“小猫补光灯”的功能相当直白：把手机屏幕变成一块可以自由变换颜色的补光板，女生在拍照时用来打光。正是这个极其贴合需求的小设计，让它天然具有在小红书被传播的基因。而花生之后做的推广动作也很简单——在小红书发笔记分享使用效果，没想到内容在平台自发刷屏，评论区满是“太实用”的真实反馈。

在花生看来，这几乎是AI时代小成本创业的典型样本：一个人、一个好点子、一个趁手工具，就能把想法快速变成产品。当然，从零到一的过程并非表面看上去那么轻松，他特意把完整复盘写成了一篇长文，其中既有对需求的观察，也有上架前后的细节，还有内容引爆的心得。
