# 那种一看就想买的课程目录，用 AI 怎么自动生成？

你遇见过那种只要看到目录，就忍不住想立刻下单的课程吗？条理清楚、亮点醒目，感觉不买都亏。可等自己动手做课时，光是整理大纲这一关，就能卡掉不少人：坐在电脑前憋半天，写出来的东西连自己都打动不了，怎么指望打动别人？

其实，这种“一眼勾人”的课程目录，完全可以交给AI生成。关键在于，你是否掌握了正确姿势。

做课这件事，两面性非常明显。会用AI的人，每个环节都能被提效，以前可能要苦熬几个月的巨大工程，现在可以迅速收工；而不会用AI、或者只会“乱用”的人，则容易陷入最尴尬的结局——要么耗上大几个月，课也没影；要么好不容易做出来，却卖不出去，所有努力都打了水漂。

在“AI+课程制作”这块，特别是“课程大纲自动生成”环节，老玩家半目已经有一套相当成熟的方法论。之前他在一个3000多人的社群里做过一次专题分享，讲的就是如何借助AI快速产出高吸引力的课程目录，现场反馈很热烈。现在他把那晚的实战心得完整整理成了文字版，每一步都有详细拆解。如果你正打算用AI做课，或正被课程大纲折腾得头疼，这份内容建议反复阅读，能省下很多摸索时间。
