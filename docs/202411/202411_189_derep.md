# AI 动物故事视频的复刻与批量生产
作者：龙哥

最近“AI橘猫动画短片”这类内容在短视频平台特别火，很多人想复刻却找不到门路。其实，这类视频完全可以通过代码实现批量生产，而且操作思路并不复杂。

有位叫“土豆君”的程序员，平时就爱研究用代码提升效率。他在7月到9月这段时间，亲自尝试复刻了一波AI橘猫类的小视频，还真的写代码搞出了一套批量产出的流程。最近他终于在大家的催促下，把这些经验整理了出来，赶在截止日前分享给了大家。

他说，这次主要是想讲讲自己当初是怎么拆解这类视频、又是如何通过代码实现自动化生产的。更贴心的是，他还在文章末尾附上了可直接使用的代码文件和详细的食用教程，保证拿到手就能跑起来。想深入了解的，可以移步他的飞书文档阅读。

另外，评论区里很多人都在纠结AI生成图片的角色一致性问题。土豆君也特意支了招：用GPT自带的Dalle-3出图，再配合一段专门的提示词，就能让同一角色在不同表情、动作、服装和场景下保持样貌统一。有网友试过之后反馈说，这个方法对猫猫兔兔这类形象特别有效。

如果你也想吃这波AI视频的红利，不妨去翻翻他的完整分享，说不定下一个批量出爆款的就是你。
