# 小绿书如何写出多篇 10w+、不到一个月赚到 1 万多？

从第二天开单到月入破万，我的小绿书带货复盘

今年9月中旬，我正式入局小绿书带货。说来很神奇，第二天就迎来了第一笔订单，那种“笔记发出去，订单跟着来”的体验，给了我很大的信心。

然而到了10月上旬，流量突然遭遇滑铁卢，笔记发出去几乎没人看。我没有急着放弃，而是停下来复盘、测试、调整打法。一个多月后，也就是11月，我有多篇笔记阅读量突破了40万。回头算一笔账：从真正起步到赚到第一个10000+，用时不到一个月。

关于账号怎么选，我自己用的是服务号，目前手里一共有十几个👸号。有些朋友担心服务号受限、流量差，但我的实际体验是服务号跑起来完全没问题。还有伙伴说自己发了好几篇都只有个位数流量，这太正常了，我也经历过。流量低谷恰恰是调整和成长的机会，只要找到问题所在，并持续发布，总会被推荐机制看见。

希望我的经历能给大家一点参考：小绿书带货不需要太多技巧，先做起来、保持更新、及时复盘，机会就在下一次发布里。
