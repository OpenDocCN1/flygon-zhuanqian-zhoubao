# 别再乱做Shorts了！选对赛道前，先搞懂这波收益门槛

总有人问我，YouTube Shorts到底怎么挑方向？怎么判断能不能赚钱？今天不绕弯子，直接把选赛道的底层逻辑和收益规则掰开揉碎了讲给你听。看完这篇，你至少能少走三个月弯路。

## 一、别被假标准骗了，真正的门槛是这一条

先看官方给出的两个所谓“达标线”：

1. 90天内达成300万播放 + 500订阅
2. 90天内达成1000万播放 + 1000订阅

很多新人以为第一条就够了，天真了。第一条只是给你开个门缝，让你摸到部分功能的开关；第二条才是真正能让你拿到广告分成的硬指标。换句话说，你累死累活冲到300万播放，以为能躺赚了？打开后台一看，收益为零，别问我怎么知道的。

再看收益构成，开通后你能获得这些收入来源：

- **会员资格**：粉丝每月付费订阅，你拿70%净收入，还能给他们搞专属徽章、表情包、直播特权。
- **超级留言/贴纸**：粉丝在直播或点播里花钱让你注意他，平台抽成后归你。
- **购物橱窗**：在视频和直播里挂商品卖货。
- **观看页广告**：长视频播放页周边挂广告，你有分成。
- **Premium分成**：YouTube会员看你的视频，你不用看到广告也能分钱。
- **Shorts Feed广告**：Shorts滑动流里插的广告（10月15日后时长放宽到3分钟以内）。

所以看清了吧？真正想变现，硬指标就是1000万播放 + 1000订阅 + 90天。看到1000万别腿软，油管给量是真大方。内容正当、赛道不差的情况下，基础播放量一万打底，爆款上个百万千万不稀奇。甚至第一条视频就炸号的情况我也见过不少，运气这东西，谁说得准呢？

## 二、选赛道，本质是选时间成本

为什么说赛道是决定生死的第一步？因为你的时间只有一份，投错了方向，前面全白干。

挑赛道时要问自己几个问题：

- 这个方向跟我合不合拍？
- 做的人多不多？挤不挤？
- 还有没有增量空间？
- 开通收益的难度大不大？

说白了就是找利基市场。别辛辛苦苦做到达标了，倒在了人工审核那道坎上，你说冤不冤？

好在我们可以用工具和技巧，在动手之前就把赛道摸个底朝天：开通率高不高、有没有雷区、收益区间大概多少。心里有数了，再决定做不做，信心自然就不一样了。1000万播放确实吓人，但听完后面的拆解，你会发现——这钱怎么看起来也没那么难赚？

## 三、实战拆解：怎么找对标、怎么做判断

很多圈友盯着AI赛道，觉得成本低、效率高、最省事。行，那就拿AI赛道开刀，看看我是怎么一步步筛选的。

### 1. 找对标账号

目标很明确：找一个**已经被市场验证、但还没被挤爆、仍有创新空间、能快速模仿复制**的方向。

我会先找5-10个对标账号，要求风格类似、选题类似、文案调性类似、画面呈现也类似。

### 2. 常规采集方法

- 用标签或关键词搜索初始对标，关注、点赞，然后疯狂刷首页和Shorts，刷到新的继续循环。新号更容易刷出来，手机端比浏览器概率大；有历史记录的账号需要点耐心。
- 参考钱塘江鲤大佬整理的AI标签文档，或者直接用他分享的代码自己采集。
- 顺着页面周围的同类推荐走（单独的Shorts页面没有这个入口）。

### 3. 热门音乐怎么用

从这些频道里找热门音乐，再通过音乐反向挖出高度垂直的账号。这是拓展细分赛道的好办法。

Runway show则是新赛道，靠AI生成视频的技术迭代，给AI方向注入了新血液。

### 4. 分析拆解

两组垂直赛道各整理5个账号，筛选标准：

- 总播放量大于1000万
- 近3个月内有高爆内容（看垂直视频的时间线，不是看频道注册时间）
- 排除印度频道

说实话，Runway show这个赛道太新了，符合标准的账号真难找。也正因如此，钱塘江鲤大佬的思路才显得珍贵。

AI视频转绘赛道内容多、变体多，但加了人头的总觉得心里不踏实。到底行不行？我们直接上货币化查询工具（ytlarge.com/youtube/monetization-checker/）过一遍。

结果有点意思：

- Runway show 的频道，**全部显示无法货币化**。
- AI视频转绘的频道，**全部已货币化、全部原创、全量广告**。

等等，Runway show真的不行吗？我分析了一下：这个赛道太新，很多账号一个月前才注册，数据虽然达标但api可能没更新，说不定人家正在开通的路上。如果你说纯AI图、AI猫故事、AI名人恶搞过不了货币化，我信，因为我自己就在做，同质化太严重了。但换成图转视频、图生视频之后，我直接就过了。所以Runway show的货币化前景，我反而觉得不是大问题。

至于AI视频转绘全部三绿，说实话我也没想到。可能加人头真的对原创判定有加成？我没做过这类，不敢乱评。

### 5. 二次筛选的判断逻辑

看一个频道值不值得抄，看几个状态：

- **货币化是否开启**：账号当前有没有收益权。
- **原创度**：系统认为这个频道是不是原创。
- **广告状态**：视频广告是否在投放（更多指长视频）。

可能出现三种情况：

- **全绿**：稳了。大概率人工+机器审核都不会卡你。
- **货币化开启/关闭，但非原创，有广告/无广告**：这赛道内容多半有问题。账号可能是买的收益号，后来转型到这个赛道；或者之前过了YPP，但因为侵权、违规被处罚了，出现隐藏限流（Shadow Ban）、关停收益等情况。
- **已货币化、原创、部分广告**：通常只是音乐版权分走了一部分收入。

需要说明的是，以上判断都是预估，不是百分百准确。YouTube目前没有任何渠道能保证百分百查准。给自己一个锚点去深挖，就够了。

### 6. Shadow Ban是什么？

内容违反社区准则——仇恨言论、暴力、误导性虚假信息、不当儿童内容、滥用“家庭”标签、暴力极端主义等——就可能触发限流。

还有一种情况：新号内容一切正常，但连续三天播放为0，这也属于影子禁令。这种号直接放弃，别恋战。虽然继续发能救回来，但没必要跟一个先天残疾的号死磕，换个体质健康的吧。

### 7. 看天花板：爆款上限决定你的钱袋子

确定赛道三绿之后，还得看看它的天花板。Shorts这玩意儿，本来就是靠爆款吃饭的，别指望着每天一两万播放细水长流——后期收益号都是养老状态，真金白银全在爆款里。

所以我会观察最热门视频的排序和播放量差距。

Runway show的热门视频看起来没那么夸张？最爆炸的视频和第二炸裂的差距很大？没错，如果是老赛道，我直接放弃。但它是新赛道，是AI技术迭代的产物，发挥空间巨大，我会留下。

真正不能选的对标长什么样？

同样是千万级播放的频道，最热内容之间落差巨大——这种号，选题、画面、文案，一个都不值得抄。但如果这种频道只是赛道里的极个别现象，那问题在号不在赛道。你可以接受自己起号阶段如此，但不能拿它当模仿对象。毕竟，跟着千万赚百万，跟着一万赚一千。

## 四、选题和收益估算，其实就一句话

选题时，关注垂直度 + 起量速度。

最简单粗暴的玩法：**采集同赛道达标频道的视频，按播放量从高到低、时间从近到远排下来，挨个抄。** AI类就反推提示词，重新画、重新生成，1比1复刻，猛干就行。

别心疼单个账号的得失，多开几个号，让时间给你答案。

**最后再提醒一遍**：任何赛道分析都没有百分百的答案，工具给的是概率，决策靠的是你。想清楚，再动手。

聊点掏心窝子的干货，今天这篇建议直接收藏。

先说说“一鸭多吃”这个玩法。

逻辑很简单：去找同赛道里那些被验证过的好内容，然后给自己定死一个方向——只要什么内容、想表达什么、给观众什么情绪价值，全部提前想明白。

举两个例子你就懂了。如果你想做AI恶搞号，就让巨石强森和施瓦辛格组CP，一个捧一个逗，画面感直接拉满；或者你也可以拿神偷奶爸和他女儿做主角，同样的桥段换个皮，频道照样立得住。

说白了，一段搞笑对话，我可以让巨石和施瓦辛格演，也能换成格鲁和小黄人他闺女来一遍。一套东西，拆出好几个垂直频道，完全没问题。

这背后的想象力其实很大，同一套内容在不同赛道里换着花样跑，自动化的操作空间也很大。这个坑先挖到这，回头专门抽时间细聊。

接着聊YouTube Shorts频道怎么估值。

我的判断是，做Shorts要盯紧账号的生命周期——一个新号能冲到多高、开通变现后的巅峰期有多长、到了养老期还剩多少余量。Shorts有个毛病，就是生命周期偏短，爆发力强但续航不行，做到后面容易乏力。我始终觉得长视频才是终局，希望这次3分钟改动真能帮它续一口命。

那如果一个频道既发了长视频又发了Shorts，收益怎么拆？很简单：先点进Shorts，看最热门栏目前几排播放量，减掉1000万，乘以1（想多算点就乘3）。

长视频那边，把刚才Shorts最热门前几排的播放量减掉，再看这个号做的什么赛道、什么选题，乘对应的领域单价，就得出一块收入。两边相加，大差不差。觉得多了就乘0.8，觉得少了就乘1.2，怎么舒服怎么来。反正真实数字只有作者自己知道。
