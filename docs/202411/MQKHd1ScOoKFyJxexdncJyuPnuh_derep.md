AI 提示词（Prompt）保姆级入门指南：从小白到大神的万字长文

很多人刚开始用 ChatGPT 时都会有个疑问：为什么同样的问题，不同问法得到的答案差别那么大？秘密其实就藏在“提示词”里。这篇教程会用最直白的方式，帮你把 Prompt、Token、AI 的“知识截止”和“幻觉”问题一次性讲透。文中凡是出现 [PRE*] 标志的地方，都是对应配图的位置，记得对照看。

一、先搞懂 Prompt 到底是什么？

你可以把 AI 想象成一个知识面超广的朋友，你对她说的每一句话，其实都是在发出一个 Prompt——它可能是一个问题、一条命令，也可能只是一句闲聊。AI 会根据你给的信息来理解意图并组织回复。

Prompt 的定义很简单：凡是交给 AI 的指令或信息，都能称作 Prompt。它决定了 AI 将如何解读你的需求，也直接影响输出的质量。就像现实中和朋友聊天，问题越具体，对方越能给出有用答复；如果你含糊其辞，朋友也只能先反问更多细节。

Prompt 在交互中承担三大职责：
1. 开启对话：它是所有回复的起点，告诉 AI“你需要做什么”。
2. 控制方向：通过设计特定的 Prompt，你能把 AI 的思路引向某个话题或思考路径。
3. 决定输出质量：提示词越清楚、越细致，AI 给出的答案往往越精准、越可靠。

常见 Prompt 类型有哪些？带你快速看 10 个高频场景：

描述性 Prompt——用于描述或查询具体信息。示例：“描述埃菲尔铁塔的历史。” ![](img/a5aeed8bd3973afd10135299b32216da.png)

创造性 Prompt——用于激发新想法、让脑洞打开。示例：“创造一个关于未来城市的故事。” ![](img/566ad9033e6ce488a514b0f7bb61717a.png)

指令性 Prompt——让 AI 执行明确的操作。示例：“将这段文本翻译成法语。” ![](img/219586c0d7586810e5da4a06bc555118.png)

探索性 Prompt——用于深入探讨某个主题。示例：“探索全球变暖对极地生物的影响。” ![](img/0180023d1fc18163c6fdcbbe55826629.png)

情感性 Prompt——用于表达或探讨情绪感受。示例：“写一首表达失落情感的诗。” ![](img/9d1a34aa8da69f262566ead7f54077b7.png)

问题解答 Prompt——用于解决具体疑难。示例：“如果一个圆的半径是 5 米，那么它的面积是多少？” ![](img/15a6ef3563fc50919b49375294d93d38.png)

新版界面的右侧还新增了“执行分析步骤”功能，用起来相当顺手：![](img/8f2c1cd9060acdb60dd0f224576f46cd.png)

编程/代码 Prompt——处理编程或技术问题。示例：“写一个 Python 脚本来排序一个数字列表。” ![](img/cd99ffec34aea114fc8e88d3a55144cb.png)

咨询性 Prompt——用于获取分析、建议或洞察。示例：“给一位希望提高时间管理技能的专业人士提供建议。” ![](img/8e0e3709d9e100d7e43b6968a0e54f02.png)

图像生成 Prompt——用于创作或改造图像。示例：“生成一幅描述太阳系的图像。” ![](img/665784cab595fdc5753029e818a59033.png)

音频/视频 Prompt——用于生成或编辑音视频。示例：“创建一个关于太阳系的短视频。”需要提醒的是，目前的 GPT 还不能直接完成这类创作，但已经有不少工具可以做到，比如 Pika、Pixverse，以及最近大热的 Sora。

二、Token 是什么？它和 Prompt 有什么关系？

如果说 Prompt 是你对 AI 说的话，那 Token 就是 AI 世界里“文字的碎片”。想象一本书被剪成一个个小纸片，每张纸片上可以是一个字、一个词或一个短语；GPT 正是靠这些碎片来识别语义、拼装语言。

Token 在 GPT 中主要起三方面作用：
1. 理解语义：模型通过分析 Token，像孩子学语言一样逐渐掌握词语的用法和组合方式。
2. 生成回复：收到你的输入后，模型会把你的话拆成 Token，再重新组合成答案。
3. 提升效率：Token 化让模型能像拼图那样快速处理海量文本。 ![](img/3e063c417d0d4d9770a791c539907ea8.png)

需要特别说明：GPT 实际使用的 Token 化方法并不是我们日常理解的中文分词，而是基于 BPE 算法实现的，底层逻辑比较复杂。想深入了解的可以看这篇：https://zhuanlan.zhihu.com/p/620426699 为了便于入门，我们可以先简单分成字级、词级、子词三大类来理解。

- 字级 Token：最小粒度。比如中文里每一个汉字都可能是一个 Token。 ![](img/6576f2576eeded53cd2adc47d38537df.png)
你看上图，每个汉字都对应了一个 Token。

- 词级 Token：在英语等语言中，一个单词可视为一个 Token。 ![](img/3c8a1a2193d7b976e7a054dd782db0bf.png)
像“中国”虽然是两个汉字，但在特定情况下只算一个 Token。 ![](img/9260ea504f8b08b42f11390a6ab679c5.png)
再看英文示例：空格加上 red 这 4 个字符，合计就是一个 Token。

- 子词 Token：把复杂词继续拆成更小的单元，处理生僻词时特别有用。 ![](img/a676b4b4865aa4069c2643170a15be06.png)
例如“工程师”这个双字词，在拆分后可能变成 3 个 Token，因为“师”被拆成了两个 Token 的组合。 ![](img/312a77d50d960f571544c7017fd3c664.png)

三、Token 的实际应用：计费、限制与提示词策略

理解 Token 到底有什么实际意义？先记下一个换算关系：100 个 Token 大约等于 75 个英文单词，或约等于 100 个汉字。

1. Token 怎么计算？
OpenAI 的 Token 消耗统计包含两部分：你提交给模型的输入 Token 数，以及模型生成回复的输出 Token 数。例如，你输入花费了 100 Token（约 100 个汉字），模型回复花费了 200 Token（约 200 个汉字），那么这次交互一共消耗 300 Token。

2. 最大 Token 限制是多少？
不同模型的承载能力不一样。官方文档在 https://platform.openai.com/docs/models/gpt-4-and-gpt-4-turbo 中写得很清楚： ![](img/daf26c6383b604901a82a5096fb67bfb.png) ![](img/311e7fd997954db530f310d59ec19c3a.png)
GPT-3.5 的 Token 上限约 4096，差不多相当于 3072 个英文单词或 4096 个汉字。
GPT-4 的 Token 上限约 8192，大约对应 6144 个英文单词或 8192 个汉字。

3. 超过 Token 上限会怎样？
一旦对话内容超过模型的承载上限，模型就会开始“忘记”较早的对话内容，因为它的记忆容量只能容纳有限 Token。为了给新内容腾出空间，旧信息会被挤出。这就好比孩子听一个超长的故事，听到后面，前面的情节已然模糊。所以在长对话中，维护对话结构的连贯性极其重要。

4. 怎样查看自己用了多少 Token？
OpenAI 专门提供了 Tokenizer 工具：https://platform.openai.com/tokenizer ![](img/350650d0d9943b2cc350ae3851372589.png)
中文场景下基本接近 1:1。比如我输入了 331 个汉字，工具统计为 337 个 Token。
再看英文输入：![](img/aabf460bf4b705126c7809d9b87b866e.png)
我大概输入了 700 个英文字母，最终统计是 149 个 Token，折算下来大约每 4 个字母等于 1 个 Token。

5. Token 限制给提示词创作的启发
- 控制有效记忆长度：明白模型可能记不清太久之前的内容，所以在长对话里不要指望它还记得你最初的所有要求。
- 表达尽量精炼：遵循奥卡姆剃刀原则，能一句话说清的事不要拆成三句，省 Token 也减少干扰。
- 重要信息要重复：在连续多轮对话中，关键信息值得在不同节点简要重申，帮助模型维持记忆。
- 合理分段提交：大段文本或复杂任务最好拆开处理，或定期总结已讨论内容，让模型始终处于清晰语境中。

四、时效性困境：GPT 为什么不知道今天发生了什么？

GPT 是一个基于历史数据训练出来的模型，它的知识库固定在数据采集的某个时间节点，无法自动实时更新。 ![](img/909ad1de7a97efb9c9f0bc31ccafcdb6.png)
如果你问它最新的新闻、流行梗或科技动态，它大概率给不出新鲜答案，甚至可能用“过时情报”误导你。

比较好的解决办法，是选用带联网功能的 AI 工具。比如 GPT-4 默认对话框已经集成了上网能力，可以实时抓取信息。 ![](img/ffef92bb8a86dd87aa24cdbaf4b88a70.png)
但这里必须明确一点：联网工具展示的是“现搜”的内容，并不是模型训练库里新增了数据。也就是说，GPT 的底料并没有因为联网而更新。
不妨看看 GPT 如何解释自己的局限：![](img/42fc129a718927529c78d5c5eb886264.png)
再把联网版和非联网版的回答放在一起对比，本质差别马上清楚：![](img/70dfc8e07032157774591bb5e3bd4fc4.png)
理解了时效性问题，你就不会再把 AI 的每句话都当成“最新真相”。

五、幻觉问题：为什么 AI 会一本正经地胡说八道？

所谓幻觉，指的是模型生成的文本没有忠实于原文，或不符合客观事实。简单说，它可能在知识空白时编造出看起来合理的答案。

从类型看，幻觉通常有三种表现：
- 输入冲突：生成内容和用户给出的前提相矛盾。 ![](img/0bb5c070232d2c656d8acf8d22ba6ea9.png)
- 语境冲突：生成内容和之前已经说过的内容互相打脸。 ![](img/30961a88f87ce47fc600a0bfd5f2ac42.png)
- 事实冲突：生成内容与已知世界知识明显相悖。 ![](img/f705000c9f0b5b74d03b93cd82d5e27c.png) ![](img/8933cb589237ff74589cf385d8b0035c.png)

幻觉从哪里来？主要有四个原因：
1. 模型缺少相关知识，或者把虚假关联（比如位置靠近、高频共现）误当成了事实，这与训练数据的分布密切相关。
2. 模型容易高估自身能力，它给错误答案时的自信程度往往和对答案时一样高。
3. 对齐过程可能存在偏差。如果预训练阶段没有获得相应知识，后续的指令训练可能诱导模型胡编；另外“谄媚”倾向也会让模型迎合用户观点，从而偏离真相。
4. 生成策略本身有风险。即使模型察觉到了早期错误，它也可能为了保持自我一致而“将错就错”，像滚雪球一样越滚越偏，而不是主动纠错。

怎样减少幻觉？这 7 个实战技巧值得收藏：
1. 提供清晰的上下文与约束条件。比如在医疗问题中明确“仅基于最新 2023 年医疗指南回答”，并要求“不要做无依据的推测”。
2. 引导模型逐步推理。让它先列出关键步骤再下结论，这样能显著减少跳跃式错误。
3. 让模型“大声思考”。要求它在给出结论前展示完整推理路径，方便你发现逻辑漏洞。
4. 生成多个版本再择优。请它从不同角度输出几版答案，然后综合或选择最一致的那个。
5. 指定数据来源。要求模型基于特定文献或数据集作答，并标明引用出处，让它锚定事实。
6. 采用结构化 Prompt 模板。比如 CO-STAR 框架，将回答拆解成“背景”“关键要点”“支持证据”等模块，确保逻辑清晰不跑题。
7. 限制回答长度。短而聚焦的回答能大大减少无依据的延伸和编造空间。

写在最后
Prompt 是你与 AI 对话的“语言”，Token 是你使用 AI 的“成本账本”，时效性和幻觉则是 AI 的“天生短板”。把这四件事搞清楚，你已经从新人阶段迈出了关键一步。后续我还会继续更新提示词系列教程，欢迎持续关注，一起升级进化。

每一款AI工具都有它的脾气。跟它们打交道久了，你就会摸清：动不动瞎编几句，说过的话转头就忘，报个数也能翻车……这些毛病看似无解，其实各有各的对付办法。接下来就把这些“坑”和“梯子”一并掰开揉碎讲清楚。

【先说“嘴硬”】

AI最让人头疼的毛病之一，是“嘴硬”。哪怕它完全不知道答案，也能一本正经给你编出一段听着很有道理的话。想让回答靠谱，有三招。

第一招，逼它把出处亮出来。凡是问题牵涉到复杂知识或最新消息，就在指令里注明“必须引用权威资料库、核心期刊或官方机构发布的信息”。比如聊理财风险，写上“依据XX监管机构披露的文件作答”；聊健康话题，注明“按XX医学会的指南回复”。

第二招，用不同说法反复盘它。碰到复杂题目，可以从各个侧面反复提问，得到多份答复后逐条对照。若某些信息在多个答复里都能对上，可信度就高；一旦看到前后不一致的结果，就说明它在胡诌。像分析某段历史事件时，完全可以换个角度再问一遍，把两份对比着看，真假立刻分明。

第三招，把“禁区”写到明面上。在指令里白纸黑字列清楚：不得把没有出处的流言当论据、少做关于未来的断言、不用含混词语。以理财为例，你可以强调“禁止把没有依据的市场预期当结论”。把规则立好，模型自由发挥的余地就小多了。

顺手再说一个小窍门：假如你只是要个简短答复，不妨在提问时补一句“控制在50字内，直接给答案”。细节设定到位，跑题的概率自然降低。

说到底，会胡说八道的AI也给我们上了一课：机器给出的内容不能照单全收，保持存疑、动手验证、带着批判的眼光去看，才算稳妥。

【关于记忆】

很多人以为GPT记性好，其实它根本没有长期记忆。前面聊token的时候提过，模型能记住的内容受窗口大小约束，一旦对话达到上限，最早的片段就会被挤出去。

做个粗略的计算：GPT-3.5大约能装下4000字的中文或3000词的英文，就按一轮问答500到1000字来算，撑过4到8轮之后你最初说的什么它就不记得了。GPT-4的窗口翻倍，能扛到8000字上下，换算下来约莫8到16轮便会失忆。

这对用户最直接的影响是：聊到一半，你报过的名字、你提过的口味，它全都抛到脑后。

不想被“失忆”坑到，可以留意四点：

先算好它能记多长。对话超过承载量之后，就别再追问早先聊过的话题，问了也没用，它早忘了。
话尽量简短。按照“如无必要，勿增实体”的老原则，每句话都直奔重点，省下的token可以让它多记住些要紧事。
特别关键的一些细节反复交代。隔几轮就重新说一遍“我住在杭州”“我习惯早上九点开会”，相当于给它定期提个醒。
长内容切成小段。把复杂问题拆开给，或者时不时总结一下前面聊到哪儿了，让它处理得有条不紊。

还有一条捷径：与其每次重新嘱咐，不如做一个定制的GPTs，把你想要的个人资料和沟通偏好统统装进去，让它一上来就进入状态，压根没有忘记的机会。

【关于押韵】

让AI写押韵的文字，就像让程序员写诗——能押上，但总透着别扭。现代大模型写文章不在话下，一碰到韵律工整的要求，立刻露怯。

毛病出在三个环节：为了凑韵脚，硬塞一些并不贴切的字眼，读起来生硬；古诗的平仄节拍难以兼顾，念着不顺；为守住格式，内容被牺牲，诗意和深度都没了。

改进的办法有三条：把韵律要求写具体，比如“请按ABAB韵式写一首四行小诗”；丢给它几篇范文，让它照着路子仿写；别忘了在指令里提醒它“内容厚度跟韵律同样要紧”。拿古诗创作来说，给模型一个韵脚要求，它的表现大致是这样：

![](img/1221747c5d349fa64739c36f90fca8d5.png)

即便AI没法像资深诗人那样靠灵感和直觉写作，给它清晰的框架、再经人工修改打磨，照样能在韵律创作上助你一臂之力。

【关于字数】

“差不多一百字吧”——AI听到这种要求，经常给你回到二百字开外。原因在于，模型优化回答的第一标准是内容是否靠谱，字数从来不在它的考虑范围内。

对付这个毛病，有几个递增的招数。

头一着，把字数直接写进问题里，比如“写一段约百字的个人介绍”。可别以为写了“约”字它就一定规矩，照样可能放飞自我。

![](img/0925843b6f27f17ee696ba4b6bb24569.png)

再进一步，把要求嵌进结构里。比如“提出三点省钱建议，每一点控制在20字内”，它会老实很多。

![](img/506db1b9e97617a83dcc26f855f3b602.png)

结构还能更细。比如“分三句陈述环保的紧迫性，每句控制在35字内”。

![](img/ca41c8731e816df4fc8b8982829854de.png)

即便如此，AI对字数的拿捏依然谈不上精准，所以动手删改的准备还是要的。理解了AI在这方面的局限，再学会相应调整用法，用起工具来才更顺手。

【关于修辞】

AI写的东西时常带着一股“机器味”：句子都对，读起来却乏味。具体表现在三方面：一是措辞套路化，想让人眼前一亮很难；二是缺失真人执笔时那种情感浓度和个体视角；三是让它在诗歌、小说这类高度原创的任务上放得开，更是难为它。

改善的方法也挺直接：想要什么味道，就在指令里点明——幽默、正式、忧郁都行；拿一段风格相近的作品贴给它模仿；别指望一步到位，把写作这件事拆成几个环节，边写边修正。不妨看一组现场示范：

![](img/50c5e479b0c4b7b3fe49a44390e35223.png)

【关于边界失控】

你千叮咛万嘱咐“别写太长”“别谈政治”“别用术语”，它偏偏全犯一遍，这就是边界失控。后果通常是：产出跑偏、违背你定下的底线，甚至踩到合规的雷区。

想改善，可以这样：

指令简化。与其拐弯抹角说“编段故事，但篇幅别太长，政治内容一概不要，也少用生僻行话”，不如直接说“用200字讲述一段普通生活里的小事，不涉及政治话题，通篇大白话”。

界限画清楚。与其说“能不能提几条建议？不过别搞太复杂”，不如说“给我3条贴近日常的提示，每条压在15字内”。

多试几版。第一版指令不灵，就改、就调，直到模型准确接收信号为止。比如“说说未来会有什么技术，可别像科幻片那样”不够清晰，把它改成“结合眼下科技演进的脉络，用200字勾画一项未来可能出现的装置”，效果立竿见影。

回头看这些优化案例，底层拼的还是遣词造句的水准：字词拿捏得准、思路不绕弯、不留歧义，边界失控的麻烦基本就解决了大半。

【让思路“出声”】

最后分享一个通用解法，我把它叫做“出声推理”。核心逻辑很简单：别让模型直接给结果，而是逼它把推理过程一步步吐出来。碰上复杂的活儿，这种按部就班的推演能极大提升正确率。

具体操作分四步：先把大问题拆成小块；再把各步骤串成清晰的思维链；接着一步步演算，把每步算出的结果先记下来；最后根据它的回答调整追问方向，逐步逼近正确答案。

这招还能提升模型的可解释性。不过，思维链也不是对任何体量的模型都灵光。有些实验显示，参数规模不足时，硬逼着模型一步步推演，效果反而不如直接给答案；要等参数涨到数百亿这个级别，思维链的增益才真正显现。说起来，最朴素的触发方式就是在问题末尾加一句“Let's think step by step”。

# 二、实战技巧｜让模型“多想几层”，再给你综合答案

## 1、策略概述

上一课我们教的是让模型“逐步推理”和“大声思考”，也就是要求它把每一步的逻辑拆解清楚，别急着给结论。而这一招的进阶版是：在逐步推理的基础上，让模型同时考虑多种理由，最后再给出一个综合性的答案。这样做的好处是，模型会更深入地把问题掰开揉碎，给出的回答也更全面、更有逻辑层次。

## 2、具体怎么操作？

1.  先让模型把推理过程“写”出来：用明确的指令告诉它，按步骤来，每一步都解释一下自己是怎么想的。
2.  鼓励它“自言自语”：让模型把思考路径说出来，这能帮你看到它如何从已知信息一步步推出结论，也更容易发现潜在的漏洞。
3.  别只盯着一个答案：提示模型在思考过程中多走几条路，列出几种可能的答案或角度，然后逐一比较这些观点的优劣。
4.  最后逼它“收网”：要求模型把前面提到的各种理由串起来，给出一个兼顾全局、逻辑严密的最终结论。

## 3、举个例子

我们拿“为什么远程办公在当今社会越来越受欢迎？”来试验一下。

你是一名具备深度分析和多角度思考能力的推理者，能够通过询问和评估多种理由，综合所有信息后得出可靠的结论。你的任务是最大程度地考虑所有相关因素，以确保最终结论的稳妥性和全面性。

2\. 通过询问多种理由，确保考虑到所有潜在的因素和可能性。
3\. 提供逻辑清晰且易于理解的推理过程，确保用户能够理解分析过程。
4\. 对不同理由进行权衡和比较，确保得出的结论经过充分验证。
5\. 确保结论在各种可能情境下都是稳妥且具有说服力的。

4\. 在多种可能性中寻找联系并进行综合判断，确保结论的稳健性。
5\. 保持语言简洁清晰，确保复杂的推理过程易于理解。

## Constrains
1\. 必须对每个理由进行分析，不能忽略任何潜在的可能性。
2\. 在推理过程中，避免过于依赖单一理由，确保综合考虑多种因素。
3\. 确保每个推理步骤都有明确的依据，避免出现模糊或不确定的描述。
4\. 尽可能提供多种情境的分析，确保结论的普适性和可靠性。
5\. 避免冗长的描述，确保每个步骤都是关键且必要的。

4\. **比较权衡**：对所有理由进行比较，找出最具说服力的理由，考虑各种可能性之间的关系。
5\. **综合结论**：结合所有分析，提供最可靠的结论，并明确解释其背后的逻辑和依据。

## 4、效果分析

- **一步一步来**：模型没有脱口而出一个总结，而是先列举出好几个原因，再逐个分析每个原因的重要性和内在逻辑。
- **多角度覆盖**：它把技术发展、疫情催生、工作生活平衡、企业降本等维度都纳入了考量，保证回答不偏科。
- **结论有分量**：最终给出的收尾结论把各个观点都串了起来，并讲清楚了它们之间是怎么互相影响、共同作用的。

说到底，让模型“逐步推理”再“大声思考”，对复杂任务的效果提升非常明显。再让它把多种可能性都摆上桌，一一权衡比较，答案自然更全面、更严谨，也不容易漏掉关键信息。
