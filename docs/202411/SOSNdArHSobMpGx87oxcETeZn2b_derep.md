不写一行代码，我用 Cursor 在两天内做出了第一个上线产品

先说说成果：我这种编程菜鸟，过去只懂某一小块内容，根本撑不起独立开发一个完整产品。但今年，我靠着 Cursor，从零到一做出了自己的第一款网页工具，并成功部署上线。整个过程没有亲自敲代码，所有代码都是和 AI 对话生成的。

这还要从亦仁大佬的第三个“超级标”说起。看到那个帖子时，我觉得这事儿可以干。过去一年多我一直在接触 AI 相关的东西，早就知道 Cursor 很强，却始终没有深入使用。直到那一刻，我决定好好学一把。那段时间我正好在 B 站刷到一位刚拿到精华贴的大佬，他开发的产品直接在小红书爆了，还冲上 App Store 前 20 名。这让我一下子有了信心：原来有想法，真的可以变成现实，而不是只停留在脑子里。

![](img/cd26e14a67ff92ac64145d8b15067c90.png)
![](img/1e1bfd277cd4e261679f3994854b9bf1.png)

看完基础教程，我马上去官网下载了 Cursor（https://www.cursor.com/）。这里提醒一句：登录时可能需要“科学上网”，没有梯子的话，可以去 B 站找找方法，或者直接去淘宝解决。如果你真想学，这第一关肯定能过；毕竟做海外相关的项目，梯子本来就是最基础的工具。

![](img/cfef71792e3dc6f9b0f77d2322b686ec.png)

一、先用浏览器插件试水

亦仁的超级标里把 AI 应用分成了 AI 网站、AI App、AI 插件几类。我本能地觉得插件门槛最低，于是决定先拿它练手。当时我正好有一个痛点：电脑没登录微信或 QQ 时，遇到禁止复制的网页，想截图转文字都很麻烦。于是我想，干脆做个截图 OCR 插件。

我对 Cursor 完全是个新手，提问也很“傻”：先让它生成一个最简单版本，再一步步完善。

![](img/2398e5a3cbe7cd795249692f576a7eb1.png)

过程中遇到报错，我就直接复制错误抛给 Cursor，让它修复。

![](img/8bc6426403984b02bb0922514a1f1bde.png)
![](img/af97007af5312f78c6ba702e4ebbd216.png)

很快第一版插件就出来了：截图功能没问题，但 OCR 一直不能用。

![](img/2fc2c2839155c4f5c63c3770197a29ae.png)

我继续问 Cursor 怎么办。它先给了一套复杂的方案，我觉得太麻烦，又问有没有更简单的办法。

![](img/33d5d9e568d81264da3510bd264ceaed.png)

这次它建议我去注册百度 AI，因为百度有现成的 OCR API，只要把接口接进来就行。我照着教程一步步操作，顺利拿到了 API Key 和 Secret Key。

![](img/a37251a1785cb342a12f5f670344e903.png)
![](img/56a0115b56a118a45ff683360b781905.png)
![](img/73fef7801284a319d436447c8893404b.png)

把两个 key 填进插件保存。

![](img/95a4a49d818795836d9f6444e7a5ea52.png)

再用插件截图+OCR，浏览器界面里的文字就都能识别了，成功解决了我的刚需。

![](img/e85c130810acc84b3956bde735f7700b.png)

做完以后，我还想过把它上架到谷歌应用商店，结果发现要 5 美元入场费，想想这个需求还没大到值得付费，就放弃了。但这次尝试让我很兴奋：一个从没做过浏览器插件的小白，从 idea 到能用，只花了一个多小时，这在以前根本不敢想。

![](img/947613b24748ced96cc290152c3211d7.png)

有了这次经验，我开始琢磨：有什么是更多人需要的真正痛点？很快我想起一年多前花 298 元买过的一款工具，主要功能是图片编辑、图片压缩这类小文件处理。既然 Cursor 这么能打，我为什么不试着把它“复刻”出来？

![](img/a153ed13118bad08f35542cef8aa17cd.png)
![](img/dcd39b5bc152379db289ad70f79fc140.png)

说干就干。我先把那款工具作为参照，仔细分析它的界面排版，然后把分析结果总结成提示词，发给 Cursor。

![](img/c994c6f7945b3c01def0a0c777aadac3.png)
![](img/5ea4e06071357736c3c40cef5231b9ac.png)

很快它就生成了一个基础版网站。说实话，我这种小白还是有点畏难情绪，但畏难不是停下，于是我从最简单的三个功能开始，逐个加功能。

![](img/69b0525c0c9c58b66e9e97e39d6aa7d0.png)

有 bug 就让 Cursor 修，不符合预期就继续提需求，网站的功能就这么一点点丰富起来。

![](img/e9540f21f7b397f3a28b33d42163d4f2.png)
![](img/87f5eaa4c664b5f56c3129683ccb6e1a.png)

测试 JSON 功能时，我还跑去问 GPT 要了几份样例数据，现在各种 AI 工具配合起来，简直不要太方便。

![](img/dede4b012efc6759df63d8e1030f72c9.png)

过程中也踩了两次坑，主要是一些功能并不能靠纯前端实现，得通过 API、前后端结合，或者本地 Python 处理。后来我学聪明了：每开发一个新功能前，先到 GPT 那边确认实现思路，再回到 Cursor 描述需求、让它开发。

![](img/9c4c749c24ca336d349024ff03f22d0d.png)
![](img/4d6b2fe41df162adaf3184f52464d239.png)

比如想要左侧栏点击后显示不同类别，直接下指令让 Cursor 改就行。它远比我想象的更强，有时候还会主动给我提出网站优化建议。

![](img/4df0cafeb45622d1b99c2df2d52e8c0b.png)
![](img/412c0647828394d0b18c2a87c33c33b8.png)

就这样，我复刻了大部分功能，历时将近两天，做出了 30 多个功能。但由于我基本没接触过后端，有些功能只能等以后再说。现阶段先把纯前端能完成的部分都做出来。

接下来就是如何让用户用上的问题。这里我用了熟悉的组合：GitHub + Vercel。这个思路我在 23 年初就玩过，当时 GPT 镜像站很火，GitHub 上扒代码，Vercel 一部署就能直接用，所以后面操作也不算陌生。

首先访问 GitHub（https://github.com/）注册并登录（同样需要梯子，虽然也有不挂梯的偏方，但建议还是配一个）。没有账号的话，点击注册，填好账号密码，去邮箱完成验证就行。

![](img/617c0fa94d55a12b25af5ba2e6ae2ae6.png)
![](img/3daf6742461e128a988ecc494ec5a347.png)

登录后点击创建项目，再点击上传文件，把 Cursor 生成的那一堆文件全部传上去。

![](img/105b50d186d0e37494fee23b51d554ec.png)
![](img/71409e23bce2a017a19019c3caa68570.png)

GitHub 搞定了，接着去 Vercel（https://vercel.com/login）。打开官网，直接用 GitHub 账号登录，不需要额外注册。

![](img/a720a43b401a584272d4fde675802f49.png)

登录后点击添加项目，找到刚才在 GitHub 上创建的项目，Import 进来，再点 Deploy，部署就开始了。

不过默认域名太奇怪，用户记不住。要正式运营，还是得买一个自己的域名。我推荐腾讯云（https://cloud.tencent.com/），微信扫码登录即可；第一次用要先实名认证。

![](img/015d24134a4b80fb0aa1eef3ef1422ed.png)
![](img/8b2e9f998caf9b1713e65a4a049c6056.png)

认证完，在腾讯云搜索“域名”，就可以注册了。

我选的域名是 shuchong888，后缀选了便宜的 top，暂时够用，以后有需求再换。

![](img/900511125c546f0d132969dee1358588.png)

![](img/8bbbf7bc99500fe23e176b798e9f7509.png)

最终上线地址是 www.shuchong888.top。虽然只是个低阶版本，不少功能还不完善，但对我来说，从网站开发到上线的整个流程已经完整跑通了。

![](img/fff4c858572632e8abb6fc7b0c1da675.png)

开发期间我开了 Cursor 会员，两天用了 290 条快速请求配额，就完成了这个网站。所有代码都由 Cursor 生成，我全程一个字符都没手打。它的可行性，远超我的预期。

![](img/d3bf016ed81efd8cc036e52c11648929.png)

接下来，我打算在这个域名上继续完善功能，尤其是那些纯前端搞不定的部分，后续得去补后端知识或接 API。如果一切顺利，我还会写一篇从 0 到 1 完整制作产品的教程。大家如果有什么想要的小工具，也可以在评论区留言，我会记录下来，一个个去“捣鼓”。

目前产品完全免费，除非未来复刻程度超过那款 298 元工具的 95%，并且有能力加上用户登录和支付通道，我才会考虑收费。

最后说说用 Cursor 怎么盈利。亦仁的第三个“超级标”写了十三句话，其中最触动我的是最后一句：

“AI + 出海 + 短视频流量 + 个体全能 + 长期深耕，几波趋势和红利叠加，可能是少有的一个好机会，值得你重视，开始研究。”

我过去一年多一直在和 AI 有关的东西打交道，也加了不少 AI 群。群里有时会看到“拿这些账号到底能干嘛”的疑问，经过调研和朋友聊天，我找到了一个关键模式——镜像站。

比如 AI 音乐生成工具 Suno，官网是 suno.com；而 sunoai-music.com 其实是一个镜像站。它的玩法是：从官网注册并充值会员，然后逆向拿到 API，接入自己的镜像网站。功能一模一样，但价格更便宜，用户想省钱就会来这里，整体做得还非常不错。

![](img/9711ff06180c11ddfd0cc9756717d6e1.png)
![](img/bcde29159a71a2d5f3e1dde1bf737cfc.png)

而且这个站点的 SEO 做得很好，就排在正版官网下面，自然能截获大量流量。这不仅是 Suno 一个例子。AI 绘画、AI 视频，以及最常规的 AI 对话（GPT、Claude），都可以套用类似的思路。工具是现成的，关键在于你有没有能力把产品做出来，并想清楚怎么把流量变成钱。

Cursor 真正让我震撼的地方是：它把一个普通人的“想法”和“产品”之间的距离，压缩到了以天为单位。如果你也有一个一直想做的产品，也许现在就是开始的最好时机。

说实话，做AI网站的想象空间远不止我现在想的这一个方向，但我要从自己最顺手的地方先落地。

我手头正好有低价拿货的资源，这块我已经持续跟踪观察了两年多，对市场和玩法算比较熟了。与其去一个完全陌生的赛道硬啃，不如先在熟悉的舒适区里往上提一层，把优势用起来。

网站搭起来、上线了，真的只是刚开始。真正考验人的，是上线之后怎么让它被搜到、被看到。谷歌SEO的排名怎么做、流量怎么沉淀下来，以及最后的变现问题怎么解，是要走广告分润还是做付费订阅，这才是核心难题。

接下来我会把重心沉到谷歌SEO的学习和实操上，慢慢啃透。等有阶段性成果了，再回来跟大家同步进展，分享踩坑和经验。
