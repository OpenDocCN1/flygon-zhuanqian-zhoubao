# 【赚钱技能】我知道副业很重要，但是却找不到坚持的动力？

你有没有过这样的经历：

副业已经跑通了，甚至开始赚钱了，可一到该干活的时候，就是不想动。明明知道坚持下去就有结果，但身体和情绪都在抗拒。放弃吧，不甘心；继续吧，又提不起劲。

最近被问到最多的副业问题，几乎都是“我怎么才能找到持续做副业的动力”。我带着学员实操时，也发现一个很有意思的现象：

**能不能把副业做好，关键从来不在项目本身，而在你内心深处那股劲儿够不够。**

很多人卡在副业上，不是方法错了，也不是能力不够，而是——他其实根本不需要做副业，或者压根没想清楚自己为什么要做。

一个模糊的动机，撑不起一段长久的坚持。今天就想和你聊聊，怎么找到那个能让你稳定、持续做副业的源动力。

### 一、先别急着找动力，问自己一个问题

我过去带团队、做培训，接触过大量想赚钱的人。2022年转做线上知识付费后，我开始重点教沟通、时间管理、销售这些基本功，反而不太直接谈赚钱。

为什么？

因为我发现，那些能在副业里赚到钱的人，跟着谁都能赚到；而打心底里没有动力的人，换再多老师、换再多项目，照样赚不到。问题不在外部，在于意愿度和驱动力。

所以，在做副业之前，你最该问自己的是：

**我的人生，真的需要一个副业来让生活变得更好吗？**

如果你的主业完全能支撑你的生活开支，还能存下钱、陪伴家人、做自己喜欢的事，那真的不必硬给自己找罪受。安心把主业做好，也是一种很棒的生活。

就像我父亲，一份工作做了二十年，从基层业务员做到主管，照样把家养得很好。

很多人做副业没有动力，不是懒，不是拖延，而是他根本不需要。既然不需要，何必折腾？

### 二、动力从哪里来？我把它分成两类

如果你确认自己确实需要副业，那动力到底从哪来？我总结了六种来源，分成外在和内在两类。

#### 外在动力：环境、危机和变故

**第一种，环境的激励。**

比如你参加一个航海实战，身边每个人都在认真打卡、执行，你自然会被带动起来。别人能做到，你也想做到。这种“大家都在跑”的氛围，会推着你往前走。

**第二种，危机驱动，最常见的是“负债”。**

房贷、车贷、孩子学费、赡养父母……这些都是每个月必须支出的钱。当你知道这个月必须赚到多少钱，你自然就清楚每天该干什么。

负债有良性和恶性之分。良性负债，比如房贷车贷，能让你更有效率地工作、创造更高收入；恶性负债，比如投资亏空、盲目消费欠下的钱，则会压垮人。

但不管哪种，只要一个人愿意面对，负债就能成为一种很强劲的外在推力。我一直觉得，合理的负债不是坏事，它等于给梦想找了个实实在在的落地锚点——总不至于让人躺平。

**第三种，人生重大变故。**

家人突然破产、投资全赔、生了一场大病……这些被迫的觉醒，确实会让一个人拼命赚钱。你看明白老师，因为身体原因，必须保持稳定作息、持续工作，所以他比大多数人都自觉。

但这三种外在动力里，第三种最好不要发生。人没必要非得吃够苦才清醒。

#### 内在动力：梦想、责任和使命

**第一种，梦想驱动。**

环游世界、买带花园的房子、每年带家人出国旅行、送孩子去留学……这些画面只要在你脑海里足够清晰，就会变成一种主动提醒你“该干活了”的声音。

但说实话，能靠梦想驱动的人极少。我见过真正能做到的，基本都在35岁以上。年轻人鲜少能靠梦想让自己每天都冲劲十足，我就是个会偷懒的普通人。

**第二种，社会责任。**

我有位咨询者，公司将近三万人，那年出了严重状况。我问他怎么不把公司关掉？他说：我关了，这些人马上就没工作了。一直以来，我是让他们家庭稳定的那个人，我得负责任。

这类人做事，已经不单为自己，而是觉得“我的能力应该为这个社会多做点什么”。

**第三种，使命驱动。**

这更稀有，我至今只遇到过两三个。使命驱动的人做事，不是为了赚钱，而是真心想带着别人成长，想让更多人觉醒。他们的动力来自“我不是在做一个项目，而是在成就一群人”。

### 三、怎么判断自己能不能做好？对照这六条

现在，每当我动力不足，就会把这六种动力重新翻出来，一条条对照：

- 我有没有身处一个积极的环境？
- 我有没有需要承担的良性负债？
- 我有没有经历过非醒不可的变故？
- 我心里有没有一个清晰的梦想？
- 我有没有放不下的人和社会责任？
- 我有没有想要达成的使命？

**动力越多，行动力越强；动力越多，稳定度越高。**

所以，如果有朋友来问我“这个副业能不能做”，我很少直接评判项目，而是先拿这个框架去对照他——他满足其中至少两项吗？

如果满足，我给的建议才有用；如果不满足，我给他再完美的方案，他一个月后还是会回来问同样的问题。

这不是方法的问题，不是能力的问题，而是他压根没有做副业的需求。

### 写在最后

我做副业相关咨询越多，越深地体会到一句话：

**没有“为什么开始”的答案，就没有“坚持下去”的力气。**

先向内确认自己是否真的需要，再向外寻找推自己一把的力量。当你把内在和外在的动力都盘清楚，副业这件事，就不再是“痛苦的坚持”，而是“我本来就是这么活的人”。

我是根源，第四期赚钱圈友，2w+实战案例的心理咨询师，12年线下销售与团队管理经验，目前深耕线上知识付费。希望今天的分享，能帮你找到那股稳定向前走的劲。
