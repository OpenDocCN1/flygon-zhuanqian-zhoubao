# 想升级思考，先找到一个小切口

文 / 优嘉

这个系列，我准备把一些确信有效的思考习惯，以及常见的思维陷阱，都摊开来聊一聊。希望读到的你，能从中找到一点属于自己的新视角。

国庆假期，有两位长辈来家里做客。他们两家的小孩都即将从学校毕业，踏入职场。长辈们希望我跟孩子们聊一聊，给些建议。我清楚，那些大而空的话，孩子们早就听腻了，重复一遍反而成了负担。于是我没有讲任何道理，只挑了自己真实经历过的几件事，讲给他们听。讲述时，我也像在对自己做一次回望。讲着讲着，我才发现，原来自己不知不觉间已经跨越了那么长的一段路。

如果你想改变思考方式，不妨先找一个小切口，认真把它聊透。

留言区有人问起一本名人传记，也有人推荐那本像“打开天窗”的书。作者回应说传记确有其实，而那本书也值得读，能让人用更高的视野看世界。
