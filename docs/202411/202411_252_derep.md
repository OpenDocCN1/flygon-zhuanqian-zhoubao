# 做了三年的小红书博主涨粉 7.4 万，摸索了一些领域规则可以借鉴

### 深耕小红书读书赛道三年，从7.4万关注到近40万收益：这份避坑指南请收好

从零开始做小红书读书号，到今天已经三年了。账号攒下了7.4万粉丝，也换来了将近40万的收入。但这背后真的是一路碰壁：粉丝都快破2万了，我才知道原来博主能自己向品牌方报合作价；也是做了很久才搞明白，读书博主的收入来源远不止“书籍置换”这一种。

如果你也打算做读书博主，并且希望它能真正赚到钱，请把下面这10条经验反复看几遍：

第一，赛道选择别盲目追热点，要挑自己真正喜欢且擅长的方向。方向一选对，后面就是事半功倍。

第二，初期搞不定拍照和书桌场景怎么办？那就把镜头聚焦在书本上，主页背景尽量做减法。干净简单的画面，往往最不容易出错。

第三，真要靠账号变现，就要让书籍以实拍方式单独出镜，尽量不要用设计排版图替代。否则你的变现之路会越走越窄。

第四，审美在线的人，请一定把书桌布置起来，或者加入更多生活场景。这样除了书籍，学习用品、数码产品等领域的合作也会找上你。只要画面保持美感，暴露的商业位越多，接单的机会就越大。

第五，想打造一个能赚钱的账号，本质是把它包装得具备商业价值。图文也好，视频也罢，内容决定粉丝愿不愿意留下来，封面却决定别人愿不愿意点进来。所以封面风格要固定：如果你的审美偏大众，就选择最稳妥的通用风格；如果你的审美足够惊艳，再尝试有辨识度的小众方向。

第六，学会主动推荐自己。比如出版社编辑来找你时，在聊完之后顺带说一句：“以后如果有合适的新书，也欢迎再来找我呀～”出版社每个月都有新书推广需求，这种关系天然容易维持长久合作，你给人留个好印象，下一次机会自然也会优先落在你头上。

第七，不要担心报价吓跑品牌方。在价格合理的前提下，勇敢报出自己的合作价，这是建立商业模式的第一步。相比免费或低质置换，收费合作反而会推动整个流程更专业、结果更可控。何况大多数品牌都有市场预算，真不需要你替他们省钱。

第八，尽量别碰“直发合作”——就是对方把做好的图文或视频内容直接给你，让你照原样发布。这类合作通常价格不高，还会拉低账号流量、影响主页的垂直度和美观度，性价比很差。

第九，把心态放稳，带着“职业博主”的意识去打持久战。把上班时的认真和自律放到账号运营上，结果多半不会差。

第十，拖延就等于取消。既然决定做读书博主，现在就拿起书来读、打开文档去写，别让“准备中”变成永远的开始。

这些道理，都是我一步步踩坑、试错换来的。如果你刚好也想做一个既热爱又能赚钱的读书账号，不妨从今天这10条开始实践，哪怕只做到其中几条，也一定比盲目努力走得更快。
