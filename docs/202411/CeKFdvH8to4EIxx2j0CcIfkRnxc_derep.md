# 写到让人拍案叫绝的产品文案，到底靠什么？
作者：龙哥



练手 IP 两三个月，把一篇万字长文打磨出来，有人评价说放在万元付费区里也算顶尖水准。我是怎么做到的？

不绕弯子了，直接把方法拆开来讲。

我们做的内容，本质上就是对读者说话。想让文案打动人，就得先把这三件事想清楚：

1. 说给谁听？
2. 说什么内容？
3. 用什么方式说？

我会按这三点展开，最后再补上四个实操级的修改习惯。

# 一、对谁说，先把人找准

对谁说，核心就是锁定真正的目标受众。

举个例子，准备往某个平台投稿，你以为读者是目标？其实是编辑。投稿前先研究编辑在想要什么、偏好什么。

写论文，面向的也不是大众，而是刊物审稿的编辑。

做新媒体，面向的也不是泛泛的“所有人”，而是你的垂直赛道里的那批人。

平台不同、目的不同，真正要打动的人就不同。

当目标对象明确，比如要投稿、或者赛道已经确定，创作前就必须先去揣摩这群人的需求和偏好，再去写。

举个真实案例。之前人民网的编辑通过我们学院老师向学生征稿。我投之前先厘清了谁在要稿：征稿编辑。

她找大学生写，指向性很强，说明在推大学生评论。第一点需求就明确了：作者必须是大学生。

第二点，人民网是国家级平台，评论的议题必然是国家大事。当时正值冬奥会，选题就有了。

第三点，冬奥会这种大题材，人民网自有专业评论员，为何还要学生来写？大概率是想拿到非专业青年的视角，和专业评论不一样的年轻语气。

第四点，大学生写冬奥会，落脚点还是宣传国家取得的成绩，文章基调就定了。

一篇文章至少要同时满足这几层需求，还要有新鲜角度和亮点，才能从众多投稿里脱颖而出。反过来，只要逐项对齐，被选中的概率就会明显提升。实践也证明了这一点。刚开始写时建议多和编辑交流，多做向上社交，这些关键信息编辑往往会直接告诉你，不必自己猜。

但很多人在起步做 IP 时根本没用户画像，不知道对谁写。这时可以反推。

产品存在的意义是解决问题，问问自己：自己是在什么年纪、什么阶段、遇到什么问题时最需要这个答案。当年的自己，就是最原始的目标画像。以此为锚点去做内容定位，就不会空转。

# 二、说什么，先看读者能吃到什么

搞定“对谁说”后，下一步是“说什么”。

作者的段位，往往由读者决定。

知道了受众大概是谁，就要去判断他们的知识储备和接受门槛。门槛越低，传播越顺畅。

比如受众是上山下乡那一代、现在已是年长的群体，你就不能用课本里的例子，也不能说语数外物化生，而要用他们熟悉的生活符号，比如沙家浜那样的戏曲。

如果受众是受过义务教育、在校或刚毕业的年轻人，例子就可以从课本、童年记忆、他们所处的时代里找。

受众决定了选题范围，也决定了可用素材的边界。

我做向上社交的内容，用《送东阳马生序》开场，就自动筛掉了没读过中学语文的人。

选择一个知识起点去写，就等于放弃了另一群人。所以受众基数不能做得太小，不然后续运营会很吃力。

# 三、怎么说，逻辑和理解机制要兼顾

怎么说主要分两层：逻辑要顺，表达要顺着人脑的理解路径走。

逻辑通顺常见两种推演方式：归纳和演绎。

归纳是把具体事实归成一个总规律。在文章里就是总分结构：一个总论点，配上几个互不重叠的子论点，合起来支撑总论点。

演绎是把一般原理推到具体结论。文章里常表现为追问-解答的链条。

以今天的主题为例：如何写出令人拍案叫绝的文案？

这是 How 问题，就要用 How 来答。

要逻辑通顺；
要内容适配，即素材匹配目标群体的理解水平；
要表达贴合，即表达方式符合人的理解机制。

这就是归纳法，三个子论点互不重复，又共同支撑总论点。

再看演绎法：

问：男大学生怎样才能顺利谈恋爱？
答：先进入女生多的环境。
问：进去了要干嘛？
答：多聊天，了解女生对恋爱对象的平均期待。
问：了解后呢？
答：在不违心的前提下向平均线靠拢和调整。
问：具体怎么调？
答：穿搭、健身、谈吐……

思考的过程是层层追问，最后才得出结论。但呈现时不能照搬思考顺序。

这就涉及到表达要顺应理解机制。

第一，结论先行。我们思考是先问后答，最后才到结论；表达时必须把结论提前，先给答案再给推导。否则读者没耐心跟你一步步走。结论前置既省力，也能激发好奇：这个结论是怎么来的？

比如开头抛：男大学生怎么谈高质量恋爱？结论直接给：要具备识别同性恋的能力。读者自然会好奇两者有什么关系，带着疑问继续读下去。

第二，先易后难。讲新观点前，先用读者已知的旧观点搭桥，降低理解成本，也拉近距离。

教小朋友什么是平行线，先说“就像桌上两根筷子，无限延长也碰不到”，再给定义。小朋友立刻能懂。

这点和“说什么”紧密相关。对受众知识面判断错了，旧观点就搭不起来。

第三，创新。创新就是打破常规。

比如我的产品用向上社交的角度解读《送东阳马生序》，而不是常见的自强奋进、勤奋读书。这种新的切口会带来新鲜感。就像你一直以为家里的门只能左右开，突然发现它能从上方折叠到天花板，那种冲击感就是创新的价值。

# 四、四个修文小习惯

①先列框架
写长文必须先搭骨架，天才除外。没框架写到后面容易失控，只能推倒重来。框架阶段只保证逻辑没问题。逻辑错了，后面怎么改都救不回来。

比如写高质量恋爱，要先确定它是什么、为什么需要、怎么做。细节都是从这三点长出来的。没有框架，很容易在举例子时跑题，最后变成“那些年我们追过的舔狗回忆录”。

②通读全文
读到哪儿卡住，哪儿就是问题。通读能揪出逻辑、遣词、流畅度上的毛病。这个方法被老师点过很多次，实用又不费时间，建议养成习惯。

③给目标读者或更高水平的人看
给目标读者看，看懂不懂、要不要。给专业人士看，看专业度够不够。需求端和理解端都要兼顾。

④放几天再改
刚写完总觉得自己是文坛八斗之才。热乎时改不出真问题，放两三天再回来看，问题会自己浮现，改动效率更高。

⑤放宽心，慢慢打磨
一个两万字左右的产品，无论多好，都需要长期迭代。一千字改三遍是常态。我的向上社交产品在私教老师指导下改了14稿，才有了现在这种内涵足、文字顺、深入浅出的效果。所以想做好，没有捷径，只有反复打磨。

⑥记得随时保存
