# ('跨境电商-出海企业老板如何避免法律风险：远洋捕捞警示与自救指南', (2, 33))

近几年，“远洋捕捞”这个词在出海圈子里被反复提起，甚至被官方媒体点名定性。对跨境创业者来说，这不再是新闻里的抽象概念，而是可能真实降临的危机。

很多做外贸、做跨境电商的老板，人在国内，业务却遍布全球。正因为触角伸得远，某些地方执法力量也把目光盯了过来。所谓“远洋捕捞”，简单来说，就是外地公安或相关部门跨区域抓人、办案，把企业家带走调查。听起来遥远，但已经有大量案例浮出水面。

这篇文章之所以重要，是为了提醒所有出海老板：别觉得法律风险离自己很远。与其等着法规慢慢完善，不如先自我排查、主动自救。等制度来救，太慢了；能救自己的，只有自己。

为什么“远洋捕捞”会频频发生？说到底，无非是利益驱动。一些地方财政吃紧，就把目光投向经营良好的企业，尤其是跨区办案、取证困难的外向型企业。抓一个老板，冻结账户，谈条件，成了一门“生意”。这就是为什么许多民企老板一听到这三个字就双腿发软。

丁邱洁律师团队处理过不少这类案件，有两起极具代表性：

一起是骗取出口退税案。深圳一位工厂主，被带到内地某四线城市，最终判了五年多。相隔千里，人生轨迹就此改写。

另一起更典型：深圳一位跨境电商卖家，先被合作方通过民事诉讼缠上，紧接着又在省内某城市被控告两个不同罪名。多重夹击，步步紧逼。

面对这样的风险，怎么防？丁律师反复强调一个理念：事前风控，远比事后救火有效。具体来说，可以从七个维度自查：

第一，供应链要彻底盘点。你的上游供应商有没有涉罪风险？合作方是否干净？自己不违法还不够，整条链路都可能是雷区。

第二，税务问题上必须做到物理隔离。与税相关的一切操作，该切割的切割，不能有任何模糊地带。

第三，出口合规是底线。没有许可证，千万不要碰。合规凭证、报关文件，一项都不能少。

第四，选品要谨慎。有些供应商卖给你的可能本身就属非法产品，你只是最后一环，却可能成为最先落网的人。

第五，别把“精准辩护”做成“精准踩坑”。有些老板找律师只看价格，不看专业，结果把自己送进了更深的坑。

第六，员工关系必须管理好。被内部人举报，是很多企业翻车的起点。矛盾积累到一定程度，可能就是一份举报信。

第七，别忘了家庭成员。配偶的工作、行为，也可能成为被利用的突破口，别让最亲近的人成为隐患。

如果风险已经发生，又该怎么办？记住一条铁律：接到传唤，第一时间不是到场，而是联系律师。早介入、快应对，才能争取最好的结果。同时也要擦亮眼睛，警惕跨国集团的电信诈骗陷阱，别被人卖了还替人数钱。

还有一点务必清楚：远洋捕捞和普通刑事案件不同，它往往带着强烈的地域利益博弈色彩，所以特别让人恐惧。企业主瑟瑟发抖，是因为知道自己可能成了“提款机”。但越是害怕，越要提前布局法律防线。

最后，把这段话送给所有出海的老板：保护民营企业，不该只是一句口号。严厉打击远洋捕捞，刻不容缓。但在此之前，请先学会保护自己——法律意识，就是你最好的铠甲。
