# 资深品牌设计师分享自媒体 IP 美学干货及小报童发售经验

大家好，我是曦子，一名资深品牌设计师，平时也在业余时间折腾自媒体。我的定位很简单：设计是我的主业，自媒体是我的副业，两手都在抓。

今年下半年，我花了整整两个月，陆陆续续写了100多篇关于自媒体IP美学的干货文章，主题覆盖了朋友圈视觉、个人品牌形象搭建、📕美学方向、社群审美氛围等方方面面。

8月中旬，我开始发售自己的设计类小报童。那一次没有做太多推广，纯粹靠着自然推荐，四天时间就突破了1000人订阅。到了9月中旬，我又搞了一场小报童的发售活动，订阅人数一路涨到3800+，直接拿下了设计类目小报童专栏的第一名。

我把这次发售的具体时间节点、每一步做了什么，以及配套的文案素材全都整理了出来，分享给想做小报童发售的朋友们，希望能给你们一些启发。完整的飞书文档就放在下面的链接里，有需要可以自取。
