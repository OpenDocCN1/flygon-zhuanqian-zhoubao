# 对于滴漏、返工及错误的敏感性与处理策略
作者：龙哥

你有没有遇到过这样的情况：一个小环节出了岔子，你随手改了、补了，以为事情就过去了。可没多久，同样的问题又冒出来，甚至换了个更隐蔽的形态，让你付出几倍的代价去收拾。其实，这就是“滴漏”在作祟。

所谓滴漏，就是那些不起眼的小失误、小疏漏，它们像是水管上细小的裂缝，眼下看只是渗出一两滴水，可时间一长，整面墙都会被泡烂。

所以，聪明的工作者会对滴漏、返工和错误保持异乎寻常的警觉。不是说让自己变得神经兮兮、草木皆兵，而是培养一种敏锐的嗅觉：一旦察觉到哪里不对劲，立刻停下手中的事，把这个问题单独拎出来、归好类，搞清楚它属于什么性质、出现在哪个环节、根子在哪里。因为这类问题有个铁律——它永远不会只出现一次。

换句话说，第一处滴漏就是信号，是系统发出的预警。如果你只是在表象上把它修好了，而没有去追溯它为什么会发生，那么它一定会在你忙碌的某个节点再次现身，也许还披着新的外衣，让你更难辨认。

这种思维，让我想起《华与华方法》里那句掷地有声的话：最高的效率，就是不返工；最快的进步，就是不退步。打仗的最高境界，也不是打赢哪一仗，而是让自己始终处于不败之地。放在日常工作里，这个道理同样适用——总在补窟窿的人，看起来忙得脚不沾地，实际是在原地打转；而真正的高手，宁可慢一点、细一点，也要确保一次做对。

那怎么在一次次的实践中做到不退步？答案就在参与和沉淀里。比如航海——为什么那么多人热衷于加入航海活动？就是因为它是所有人一起动手、把一件件具体的小事扎实做成的过程。每个问题被摆到台面上，被认真对待、逐步解决，航道自然就越来越宽。日子久了，你回头看时会发现：扎实走好的每一步，都成了你不再返工的底气。

所以，别再忽略那些不起眼的差错了。每一次滴漏被逮住的瞬间，都是你变强的机会——抓住它，别松手。
