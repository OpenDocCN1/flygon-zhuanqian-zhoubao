# 私有知识库 + 🛰️群机器人搭建复盘分享



## 基于私有知识库的🛰️机器人开发复盘

作者： 大铭🍀
日期：2024-11-07

最近在落地的几个项目里，遇到一个共同的需求：月嫂学员想随时随地向老师请教问题，但又不能让培训老师被消息淹没。另一方面，面向月嫂大姐们的产品，操作必须足够简单粗暴。

于是我做了这样一个方案：把培训资料沉淀为私有知识库，再把机器人接入🛰️群里，让学员在群里直接提问。机器人从知识库里检索答案自动回复，同时在每次回答的末尾顺带推送一个课程链接，起到二次引流的作用。

目前这个机器人还在内部试跑阶段。下面这篇复盘主要拆解的是从需求到落地的思考脉络和构建思路，详细过程可以看这里： [`rxas35pmvn.feishu.cn/docx/M7jWdHvehoC8zuxt0Gic3WyynWf?from=from_copylink`](https://rxas35pmvn.feishu.cn/docx/M7jWdHvehoC8zuxt0Gic3WyynWf?from=from_copylink)
