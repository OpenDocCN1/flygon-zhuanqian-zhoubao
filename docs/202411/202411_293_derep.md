# 创业不是逃难，而是应约出征
作者：龙哥

经常听到这样一种说法：“我实在受不了现在的工作了，干脆辞职创业去。”听起来很有魄力，但其实把因果关系搞反了。

创业从来不该是一场“逃离”——逃离令你心烦的老板、逃离无休止的加班、逃离一眼望到头的生活。如果仅仅是因为“不想待在”某个地方而创业，那这个动机本身就埋下了隐患。因为“逃离”是被动反应，它只告诉你不想要什么，却从不告诉你到底想要什么。

真正值得出发的创业，是心中有光亮在牵引。也许是某个问题让你夜不能寐，也许是某个灵感反复叩打你的心门，你觉得这件事一定得有人去做，而且非你来做不可。这种冲动一旦出现，你会发现自己不再纠结于眼下的得失，而是一心想着如何靠近那个目标。

拿“厌倦了大厂”来当创业理由，尤其危险。大厂让你不舒服，这很正常，但那种“不舒服”只能证明你想离开，不能证明你该去哪里。如果心里没有一份明确的召唤，仅仅为了逃避而创业，很可能是从一种疲惫跌入另一种焦虑，换了个赛道继续内耗。

所以，不妨在冲动按下“辞职”键之前，先问自己：我到底是被什么吸引，而不是被什么追赶？我是想去创造一件“非我不可”的事，还是只是想逃开眼前的人与事？

答案是后者，你需要的或许只是一次休假。答案是前者，那恭喜你，你听见了创业真正的号角。创业，不是跟旧生活的赌气式告别，而是向新使命的郑重奔赴。
