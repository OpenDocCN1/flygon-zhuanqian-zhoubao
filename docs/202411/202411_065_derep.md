# 【星主的收藏夹】5 篇
作者：龙哥



收藏夹这东西，就像私人书架，摆的都是自己验证过、舍不得删的东西。星主这一次的收藏夹，不搞虚的，五篇内容全是经过筛选的实用干货，适合不想浪费一分钟在无用信息上的你。你不需要自己大海捞针，因为已经有人替你逛完了整片信息海洋，把贝壳捡回来摆好了。


回到这次的收藏夹本身，五篇内容各自独立，但有一个共同点：都是能让你少走弯路的实用派。你不用关心星主是从哪个犄角旮旯把它们挖出来的，你只需要知道，它们现在被整整齐齐地放在这里，点开就能用。这不就是收藏夹最大的意义吗？让好东西不再吃灰，让自己不再重复踩坑。

当然，收藏只是第一步，真正拉开人与人差距的，是你收藏之后有没有去用。星主的建议是：这五篇内容，别一次性瞟完就算完事，挑一篇你当下最需要的，静下心读透，然后去实践。其余的，留着以后遇到相关场景时再翻出来，效果会更好。


最后说句实在话：在这个信息过载的时代，愿意帮你做信息筛选、把好东西整理好送到你面前的人，真的不多。星主的收藏夹更新得很勤，但每一次都不是凑数。这一期的五篇，你值得花点时间好好看看。
