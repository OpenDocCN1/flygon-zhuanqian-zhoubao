# 二年级就敢开工作室，我用失败换来的这几课
作者：龙哥

大家好，我是龙哥，02年的大四在读生，一个到现在还在路上摸索的创业者。说实话没做出什么惊天动地的成绩，但大二那年笨拙地上线一个工作室并最终凉掉的经历，足够让我写一篇文章来提醒后来人别踩同样的坑。

那时候年轻气盛，觉得只要开始就等于进步。结果一头扎进了典型的“先烧钱再想事”模式：拉合伙人、分工合作、租场地、录课程……全是投入大、回款慢的事。等到真正需要把产品推出去、写文案引流、做一对一转化变现的时候，我却一个动作都没落到实处。没有先做最小可行产品去验证市场，一上来就是重资产的铺排，时间花了、钱烧了，经验倒是攒了不少。

回头看，这场失败最大的收获不是遗憾，而是清醒。

我现在把那段经历梳理成了笔记，也放在飞书上方便大家对照阅读。简单来说，创业不是找个办公室就开始的，而是先让钱进来，再谈扩张。

评论区里有朋友说我闲鱼上的虚拟资源玩法做得不错，这一点我也认同。后来我才明白，人选比执行力更关键。当时咸鱼从一家店做到三家店后，学会把自己从日常操作里解放出来找人分担，业务才有了真正的增量空间。闲鱼做知识付费其实方向是对的，问题出在顺序上：该先搞流量赚钱的活没做，先把花钱花时间的重活给干满了。

失败不可怕，可怕的是把同样的错误当经验复用。希望我的这次翻车，能帮你们少走几步弯路。
