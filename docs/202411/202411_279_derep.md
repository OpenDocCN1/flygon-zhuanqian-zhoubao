# 1 年半全国暴增 15000 家，无人自助台球厅的崛起

你可能还没留意到，一个看似小众的实体生意正在悄悄爆发：不到18个月，全国冒出了大约15000家无人自助台球厅。这个数字背后，是一个年轻创业者亲身踩出来的路。

大家好，我是tiger老虎。算下来，我在创业这条路上已经走了7年，学的是商科，毕业于985高校，之前做过企业管理咨询，现在是反射角台球的创始人。和赚钱圈里很多做线上流量的朋友不同，我算是很早就一头扎进了实体行业。家里从小开过超市、烧烤店、幼儿园、玻璃厂，而我大学时就折腾过家教、驾校、校园活动承接。毕业第二年，我开了属于自己的第一家酒店，到现在它依然在为我提供被动收入。

后来因为老家恰好是全国台球厅设备的生产基地——德州，我很早就接触到了无人自助台球厅这个模式。如今我自己已经开了5家店，并且把全部精力都押在了这个赛道上。

还有一个月，我就进入赚钱整整一年了。在这里确实开了不少眼界，也想把这段开店经历分享出来。
