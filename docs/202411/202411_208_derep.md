# 从 50 元到 199 元，我这个细分知识星球是如何一步步做起来的？

大家好，我是 Peron。赚钱六期、七期圈友，也是七期 TOP50 推荐官。

去年 4 月，我刚从大厂离开，34 岁，站在职业的岔路口。现在回头看，真的很感谢自己当时做了一个决定：往垂直赛道的知识 IP 方向走。一年过去，我有了自己的公司、团队，也拿到了一些结果。之前陆续在赚钱分享过三篇文章，分别聊了做垂直小众赛道知识付费的第一个月、个人 IP 如何破圈、以及从个体到开公司的战略思考。今天这篇，聊聊我做知识星球这套打法背后的完整复盘。

## 为什么是知识星球？

2024 年 3 月，我正式启动“用户研究成长圈 | Peron”这个星球。原因有两方面：一是我原本做 B 端调研业务，想再开一条 C 端知识付费的路；二是有不少学员来咨询，我发现用户研究领域的新人学东西太碎片化，这里看一点、那里学一点，效率低，也难形成体系。

当时的想法很简单：既然大家缺一个系统化交流和学习的场子，那不如我自己搭一个。对比了一圈，知识星球门槛低、付费方便，是最适合起步的产品形态。

## 1.0：先做起来，再慢慢升级

刚开始时，我的👸号粉丝还不到 3000，主要靠👸号和朋友圈导流，慢慢攒下第一批种子用户。

内容怎么来？第一步就是“搬运”——把👸号发过的内容重新编辑，拆成一个个模块，搭起最基础的知识框架。我分了八个方向：行业认知、职业成长、工作开展、研究方法、研究工具、统计分析、解决方案与案例、学习资源。

因为内容不算丰富，很多模块还是空的，我把价格定得很低：50 元一年，这是知识星球的最低门票。当时我也跟用户说了，后面会持续升级、持续涨价，早入就是赚。

这就是 1.0 阶段。

## 2.0：加服务、涨价，也踩了坑

种子用户到 100 人后，我开始认真运营，新增了三样东西：星球成员问答、每月两篇长文干货、直播访谈回放视频。价格也随之涨到 99 元/年。

说实话，内容交付很重。回答一个问题动辄两三千字；写一篇长文，基本 3000 字打底，很多时候写到 5000 字以上，需要查大量资料，一篇就得花一两天。一个月两篇，光这块就占掉四天时间，成本非常高。但即便这样，我还是觉得内容更新频率远远不够，星球价值不高。

这个阶段，星球从 100 人涨到 200 人，花了差不多 6 个月。没怎么宣传，基本都是自然增长。

彼时我的重心其实放在高客单价产品上，比如 3980 元的《大厂用户研究实操课》、15000 元一年的《和君商学·战略用户研究班》、2980 元一年的《新出海调研 VIP 会员俱乐部》。现实很打脸：除了课程，后面两个都卖得不好。

这也让我彻底想明白一件事：用户研究这个赛道本身盘子里可能就几千人，不到 1 万人；我自己的自然流量不大，又没做付费投放，还要去做超细分人群的高客单价产品，这不是自不量力吗？

我见过很多同行从几百元的课转型做一万多的服务，看起来挺成功，但他们前提是受众广、流量基本盘是我几十倍。所以还是那句话：实践出真知。我立刻调整思路——先做大付费用户的基本盘，再考虑高客单价。

于是，我的视线重新回到了知识星球。

## 头部星球研究：这三件事缺一不可

为了把星球做好，我买了知识星球官方出的《星球大战》来读，又把 APP 里各个赛道的头部星球挨个研究了一遍。尤其关注产品、运营、设计这些和用户研究类似的职场教育类星球，很多都已经做到上万人。

研究完我发现，头部星球有这些共同点：

1. 更新频率高，基本日更；
2. 核心资产是专业领域内的资料文件，相当于一个资料库；
3. 部分星球还会额外提供教程/案例拆解、需求发布和承接服务；
4. 价格有规律：只提供信息资料，普遍在 99 元到 199 元；如果还有培训、需求交易这类信息服务，基本都要超过 365 元；
5. 背后一定有一个大 IP 或新媒体账号在持续引流。

还有一个特别重要的发现：从内容生产模式来看，头部星球最终几乎都会落到多人共建模式，而不是群主一个人输出。因为一个人做内容，可持续性太差了。

所以，你想在一个垂直领域做出大体量的知识星球，得先问问自己三个条件是否满足：有没有充足流量来源？有没有专业领域内的资源沉淀（包括信息、需求、服务）？有没有专职团队持续运营？

很多人做不大，是因为只把星球当副业，没有长期主义。你做这件事的重视程度和投入程度，直接决定它能做多大、能走多远。

## 3.0：从个人输出，变成团队+群友共创

今年 10 月下旬，我正式启动星球的 3.0 升级。

具体做了八件事：

- 新增大量用户研究项目案例实操资料，这是核心价值；
- 新增与用户/消费者研究相关的行业报告；
- 新增向 500 强公司学 PPT 模板；
- 新增用户研究知识卡片，让大家可以可视化学习；
- 引入团队运营，更新频率大幅提升，每周至少三更；
- 从群主一人分享变成多人共建，邀请更多合伙人加入共创，也鼓励星友分享干货和资料，被加精华就能用积分兑换门票等奖励；
- 有效期从固定期限改成固定时长，从你加入那一刻算起，一年有效；
- 目标群体从用户研究从业者，扩展到所有工作中涉及到用户研究的泛人群，比如产品、运营、设计。

价格也从 99 元涨到 199 元，11 月 1 日正式生效。

3.0 阶段的核心目标，就是完成从个人输出到团队输出、群友共创的转型，把用户研究资料库真正搭起来。

为什么敢定价 199？因为在这个垂直领域，资料是很稀缺的。

同样卖资料库，有些星球只卖 99 元，因为他们的资料获取难度低，很多是网上爬的公开内容，或者低价批量买来再发出去。但用户研究这个赛道很特殊，高质量的调研报告在网上几乎没有公开爬取渠道，因为那些报告往往是大客户花几十万上百万做出来的，涉及大量用户数据和隐私，也没有开放购买渠道。

所以，你能在星球里直接看到各大市场研究公司、一线大厂的用户研究报告长什么样，各种类型项目的报告都有覆盖，这个价值就很不一样。说实话，现在卖 199 元都算便宜，定上千元也不过分。

那这些资源从哪来？说白了就是做资源的生意。

第一，我过去十几年在 5-6 家头部甲方乙方公司待过，手上攒了大量报告；第二，我会邀请资深同行合伙人加入，开放他们的资料库；第三，我会设计积分和交易制度，鼓励成员把调研报告共享出来——上传 3 份被加精华的 PDF 调研报告，就能兑换下一年门票；同时也可以直接在星球内交易，比如带水印的 PDF 文档可以售卖，PPT 原文档也可以买卖。

所有上传资料，我们团队都会人工脱敏。如果真有侵权，也会第一时间下架删除。

3.0 阶段，我计划做到 1000 个付费会员，然后开启 4.0。

## 4.0：从信息社群，升级为“信息+服务”社群

4.0 阶段的愿景，是从纯信息分享社群，升级成一个信息+服务的社群。具体包含四件事：

- 增加用户研究基础培训课程，定位初阶，覆盖基础知识、技能培训；我原来的《大厂用户研究实操课》则重新定位为中阶，更多是项目案例拆解教学；
- 增加行业主题训练营，会借鉴龙哥盟的打法，邀请快消、游戏、智能硬件等不同行业的资深用研专家带队，带大家打卡实战；
- 增加资源交换板块，大家可以在星球发布调研需求、承接调研需求，或者发布职位信息、看工作机会；
- 开展线下同城学习交流活动。

到了 4.0，星球价格会调整到 365 元/年。而且这个时间不会太长，肯定不超过一年，所以越早加入越划算。想想最初 50 元加入的那批用户，你就明白了。

## 想从星球里赚回门票？送你三条建议

作为星球主理人，我也想聊聊用户视角。

第一，你要愿意投入时间。我自己也付费加过不少星球，有些门票上千元，内容确实好，但我不怎么看，续费时就会犹豫。所以，加入一个星球前，先问问自己能不能每周留点时间学习。哪怕是睡前、通勤路上这些碎片时间都行。为了帮大家消化内容，我们团队会另建会员微信群，每周汇总更新内容，不定期做主题合集发到群里。

第二，找到自己的应用场景。光学习、光获取信息，你不会觉得物有所值。比如我加入龙哥盟时，门票 1500 多，但我跟着实操了👸号爆文副业项目，赚了一万多，所以它对我来说就超值。加入用户研究成长圈也一样，你要想清楚自己的场景是什么：是准备入行求职需要系统学习，还是工作中需要更多报告参考，还是想靠发布报告、承接调研需求赚钱。

第三，从一个学习者，变成一个输出者。龙哥盟里有很多这样的例子：新人一开始跟着教程和航海老师学项目，后来做出成绩，就变成最佳实践分享者，甚至成了航海教练。当你哪天能在星球里做内容输出、分享自己学以致用的成果，那才是真的学会了。

做细分赛道，慢就是快。我的星球从小做到大，走的每一步都不算快，但一直在向上走。希望我的这些经历，能给同样在垂直领域摸索的你一些参考。
