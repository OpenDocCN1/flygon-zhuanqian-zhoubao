# 终于实现了，同时支持👸号文章、小绿书的一键生成+自动配图+自动排版+自动发布（附：最新 RPA 脚本）
作者：龙哥

最近后台总有人问我：👸号自动发布、小绿书一键生成、📕转小绿书……这些工具能不能合到一起用？

说实话，我自己也早就受够了。一会儿开这个脚本，一会儿切那个工作流，光切换就够烦的。更别说很多朋友没有Coze基础，照着我的工作流去搬，搬到一半就卡壳。还有些做矩阵的朋友有IP隔离需求，之前的方案根本接不住。再加上好几个人提出：文章能不能顺便把排版也自动搞定？

行，那就干脆来一次大整合。

我咬咬牙，花了一周时间，把之前散落的各种工具全部收拢成一套完整流程。改进之后，你只需要做一件事：在飞书选题表里把想写的主题放进去，剩下的交给自动化。

这套流程现在能做什么？

——根据主题自动生成整篇文章；
——支持自定义提示词，想写什么风格、什么角度，你说了算；
——根据主题自动产出小绿书金句型内容；
——自动提取关键词，顺手把配图也生成好；
——文章自动排版，省掉手动调格式的麻烦；
——自动发布，图文类型和小绿书类型都能发；
——之前那套爬取📕内容转成小绿书的脚本，也兼容进来了，不浪费。

整个链路是这样的：

第一步，你在飞书表里提前设定好要发布的主题；
第二步，RPA脚本触发Coze工作流，Coze自动拉取选题，批量生成文章和配图；
第三步，RPA再触发👸号发布，从飞书里取回已经生成好的内容，自动排版、自动发布。

也就是说，从定主题到内容产出，再到排版发布，基本无需人工干预。

如果你也想做👸号和小绿书批量发布，这套流程应该是目前最省事的一版了。
