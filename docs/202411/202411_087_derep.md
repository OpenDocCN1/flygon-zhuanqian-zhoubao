# 借助 Cursor 与 AI 实现 YouTube Shorts 高效自动化运营流程

大家好，我是龙哥。

前阵子受了龙哥“超级标”的启发，开始琢磨 YouTube Shorts 的 AI 视频运营。一开始真没觉得这活儿有什么技术门槛，自己也刚起步，没跑出什么像样的成绩，所以压根没想写出来。直到前两天跟龙哥聊起这事儿，被他推了一把，才决定把目前的玩法整理一下，给同样在探索的朋友做个参考。

这套流程，现在基本跑通的地方包括：内容采集、对标视频的复刻、创意点子生成、图片和视频素材产出、后期剪辑，以及多账号矩阵运营。讲实话，除了“人工筛选图片”和“人工筛选视频”这两个环节，其余几乎全自动了。早先我也试过完全无人值守，结果成品质量一言难尽，所以后来主动加了两个人工节点，专门用来把关素材。整体思路就是：先把数量铺满，再靠人工做减法，挑出能用的内容。

我算过一笔账：按目前用的图片模型不同，单条视频的成本大概在几分钱到几毛钱之间。想再压成本当然可以，但质量就没保障了。所以“保证基本质感”的前提下，这个成本是完全能接受的。

工具方面，主要用了下面几个：
- 提示词反推：Midjourney describe + GPT-4o-mini
- 图片生成：Flux + ComfyUI / Midjourney
- 视频生成：即梦 / 可灵 / 海螺


发出来之后，评论区也挺有意思：有人说“啃不动”，也有人说“自动化的神”，还有朋友调侃“赶紧卖铲子，价值百万美金”。不管怎样，能给大家带来一点点启发就值了。
