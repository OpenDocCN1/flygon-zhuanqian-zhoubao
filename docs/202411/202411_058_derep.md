# ('财税公司定制化税务合规产品项目分享', (2, 19))

今天想跟圈友们聊一个特别有启发的实战案例：一家头部财税公司，靠小红书做垂直行业的税务合规产品，一个月拿下200多条精准客资。

这可不是纸上谈兵，而是生财圈友@超群 亲自辅导过的真实项目。超群在财税行业深耕了8年，今年是他加入生财星球的第二年。他特别感谢驴哥带他进圈，也感谢@彩虹 老师的帮助，这次是第一次发帖，就把这么干的干货分享出来了。

先说说这个项目的背景：不是泛泛的财税服务，而是锁定“垂直行业”的税务合规。在小红书上通过内容规划，精准吸引有合规需求的老板和个体，单月客资量直接冲到200+。这个成绩，对正在做企业服务、获客难的朋友来说，太有参考价值了。

如果你正经营一家财税公司，想从传统业务转向垂类合规赛道；或者你在做ToB服务，天天愁怎么高效抓客户；再或者你本身就是超级个体、小公司老板、电商从业者，想提前了解自己有哪些潜在财税风险——这篇分享都能给你不少启发。
