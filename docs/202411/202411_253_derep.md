# 1 个人做📕 3 个赛道，聊聊自媒体心得
作者：龙哥

最近，我的📕账号加起来粉丝终于突破10W了。说实话，这个数字不算炸裂，但对一个单枪匹马干了两年多的人来说，还是有点小成就感的。这两年里，我先后尝试过读书、家居、电商三个赛道，手里同时管着好几个号，中间还不断有新人来问我：怎么起号？怎么定位？怎么把内容做好？怎么变现？想换赛道又该怎么转？说起来，大家来自不同领域，问来问去却都是这几个问题。说到底，所有问题都绕不开两个字：运营。![](img/8955d1119e64ce6e08fc997fa8c37b39.png "None")

我的经验是：每个赛道都有自己的门道，但运营的底层逻辑是通的。只要你能把下面这三件事想明白，账号基本就走不偏。

第一，先定赛道。

赛道相当于账号的“地基”，地基选在哪，内容就得围绕哪里长。拿读书号来说，只要跟书相关的内容都可以发：阅读日常、书桌搭配、阅读方法、运营心得、知识干货……范围可以放宽。但千万别跑偏，一会聊育儿，一会发个人vlog，一会儿又跑去推荐母婴产品，这些内容出现在读书号里，粉丝会直接懵掉。垂直才是吸粉的关键，你的为人，决定了你能吸引到谁。

第二，再找选题。

赛道定好以后，真正决定爆不爆的是选题。一篇笔记如果选题准了，基本就赢了一半，剩下的一半才是内容本身。说白了，选题决定用户是否点进来，内容决定用户是否看完，主页决定用户是否点关注。所以选题是把人引进门的那个抓手，太重要了。怎么练？没捷径，一个字：勤。去首页搜同类目的热门笔记，拆解它们的核心亮点，能吸收的转化成自己的语言重写一遍。坚持写一段时间，对什么话题会火，你会慢慢产生直觉。

第三，稳住心态。

说句大实话，做自媒体的人，谁没被数据虐过？焦虑几乎是标配。但最后能走多远，拼的就是心态。我见过发了一篇就开始质疑“为什么不火”的，也见过做了一年还毫无起色的。前者太着急，后者太淡定了点。数据有波动太正常了，人也不可能一直情绪高涨，不过别让心情跟着数据大起大落。如果发了三篇数据还是不行，先别急着否定自己，而是该想想是不是方向有问题，换个选题试试；但如果总共才发了三篇，就喊着“自媒体做不下去”，那可能只是过程太短，耐心还没跟上。任何事都需要时间，你只管接受它，然后继续做。

最后想说，做自媒体，内容要深耕，心态要沉稳。剩下的，交给时间就好。
