# 八期新手参与线下同城夜校航海复盘
作者：龙哥

**八期新人的夜校航海回顾：从抢到名额到吃下双十一红利**

圈友们好，我是龙哥，赚钱第八期新加入的成员。说实话，我自己都没想到，报名首期夜校航海活动时会这么顺利——不仅拿下了名额，还通过了赚钱的筛选，最后完整参与了一场为期一个月的线下同城夜校实战。更让人兴奋的是，这次活动正好撞上双十一，我和同船的伙伴们一起抓住了一大波流量红利。

这趟“航海”的时间跨度是十月中旬到十一月中旬。我们主要在📕、视频号、抖音上运营素人账号，逻辑很清晰：先靠内容吸引流量，再把用户引导到私域完成报名付费，后续的课程交付与售后全部交给合作商家负责。整个项目落地性很强，门槛不算高，如果你也有兴趣，欢迎随时来聊。
