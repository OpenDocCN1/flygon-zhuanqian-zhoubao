# 一个“常年翻盘者”的15年自白：底层起步，我是怎么一次次逆袭的
作者：龙哥

很多人都问我，运气好能翻一次盘，怎么能把翻盘变成习惯？

我叫修进，做个人IP也写内容多年，今天就把这15年里反复验证过的方法论摊开讲讲。说到底，我从头到尾都是个起步很慢的人，但偏偏每次都能在关键节点逆风超车。

我的履历看着像反转剧本：

中学时期长期排在班级末尾，高考前最后90天硬是提了30多分，最终拿到985名额；大学绩点一度掉到年级后30%，后来却成了学院近几年唯一在读期间发到C扩期刊的本科生；曾经是公认的写作困难户，如今在国家级和省级媒体累计发文已超百篇；求职笔试名次倒数第一，面试阶段却连超30名对手拿到央企offer，还被副总当场点名要人。

这些经历的背后，其实只有两件事在起作用：持续的自强，以及主动的向上社交。

当翻盘从偶然变成一种状态，方法就不再是秘诀，而是可复制的路径。我的完整复盘和操作细节，整理在了下面这份笔记里⬇️
