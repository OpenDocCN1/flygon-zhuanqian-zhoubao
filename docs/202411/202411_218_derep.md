# 王阳明：事忙不慌，闲而不散
作者：龙哥

忙碌的时候，心能守住清明，这需要的是智慧；清闲的时候，心能不落空虚，这需要的是豁达。

很多人把焦虑归咎于事情太多，却忘了真正乱的是心。真正的忙，是脚步不停，内心却有主轴。能分清轻重缓急，能在风浪里定住航向，才算得上忙而不乱。

而闲，才是更难的修行。没有 deadlines 追着跑，反而容易被空洞感吞没。刷手机、瞎消耗、胡思乱想，都是因为心无所依。心不空的人，闲下来会读书、会思考、会生活，用乐观的心态把日子填满。

忙有了智慧，闲有了热爱，人生才不会在两端失衡。

礼新：心念一转，天地就换了 [呲牙]
一卒：太懂了，我之前就是忙得只盯细节，最后算错账，错失了翻倍的机会
