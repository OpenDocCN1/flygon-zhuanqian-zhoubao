# 女性如何冲破偏见？这位赚钱女孩的一年，看得我热血沸腾

最近刷到一篇让我反复品读的帖子，来自赚钱圈友“有尔”。距离她第一次在这里发帖，已经过去一年多。她说自己最近见了两位新圈友，从她们身上看到了太多女孩的影子，于是忍不住写下这篇文章，想带着所有赚钱女孩一起撕掉偏见，完成蜕变。

先看她这一年的轨迹，简直像开了加速器：

1. 去年底，拿到了龙哥的微天使支持。
2. 被北京的宋大主动抛出合作橄榄枝。
3. 尝试做伴手礼创业，结果栽了跟头。
4. 过敏缠身好几个月，整个人身心俱疲。
5. 但在赚钱风向标上，她却连续多次中标。
6. 后来遇到张昭，得到了对方的赏识。
7. 紧接着，新业务正式起盘。
8. 身边的朋友也是一个接一个地给她送机会。

是不是有点像坐过山车？有高光，有低谷，最终被看见、被认可。

她把文章分成了三个板块：“想和赚钱的女孩聊一聊”“也许对你们有用”“人人需要的高情商”。如果你是女生，建议直奔第一个话题；如果你想要点实用干货，后两个板块才是重点。

里面有一段话特别戳我：

> 社会底层对女性的偏见和恶意，实在太大了。都这个年代了，难道读书对我们来说还是一种奢侈吗？如果你忍受不了这种侮辱，那就自信起来，努力往上走，去更高的阶层看看。

她说，能进入赚钱，某种程度上，人生已经向上迈了一个台阶。

关于向上链接，她的思路非常清醒：先想想自己有什么能跟对方交换，或者能给对方提供什么；哪怕你先付出也没关系。关键是让对方看到你的价值、你的可能性——说得直白一点，你得有“被利用”的地方。如果这些都没有，那……

还有个小故事：她刚打完球，在地铁上发现一位类目Top1的大V就坐在对面。对方正在打电话，不好打扰。她灵机一动，拿出前几天活动现场拍的对方照片，示意自己是粉丝。她大概知道对方会在哪站下车，眼看快到站了，对方还在通话，于是……

故事到这戛然而止，留足了想象空间。

再看评论区，简直是一面镜子。

有圈友说“沙发一下，先赞后看”；有人说“看到标题已经学到了”；还有人评价“北京局王有尔在杭州这一年过得太精彩了”，她回了句“那真是‘丰富多彩’”。而“热爱抵过专业”这一句，被很多人单独拎出来点赞。船长更是直言“收获巨大，值得每天看两遍”。

其中一位叫“看山”的圈友写了段很走心的小结：

- 面对外界的评价，试着去分析评价者的出发点。比如出租车司机说她学历高没用——但对方可能自己没读过书，见识也有限，所以这条评价没有任何意义。不是所有评价都值得你内耗，去找那些能推动你进步、让你愿意行动的评价。
- 职业选择，要结合自身优劣势和市场行情，别盲目跟风。创业时会遇到来自亲戚的压力，他们大多希望你和他们一样，这样他们才觉得安心。但请注意，他们只负责提建议，不承担任何风险，这样的建议要警惕。
- 向上社交，要在大佬面前留下印象，得做点差异化的事，别出心裁又与众不同。同时要有服务意识，让别人在和你相处时感到舒服、有交流欲望，别太急功近利。
- 保持好心态，适当放松，低谷期也要坚持学习。记住：Fast is slow。

还有一条评论让我很触动。一位圈友说，看完全文非常惊艳，有尔真诚又有思想，特别善于总结，能力很强。作为一个小镇女生，她仿佛一下子看见了光，以后会反复阅读，在行动中慢慢内化，推动自己成长。她说得很对：这样的女性，就是真正的榜样。

所以，别让偏见困住你。像有尔一样，摔过、累过、也惊艳过，然后一点点把自己活成光。
