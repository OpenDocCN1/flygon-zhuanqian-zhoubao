# 迈出第一步：当“审美差”不再是我的借口

> 说实话，视频剪辑这件事，我躲了很久。不是不想学，而是心里总有个声音在说：你审美不行，剪出来肯定很烂。于是，那些摆在面前的学习机会，我都悄悄绕过去了。

简而言之，我一直在“想”和“不敢”之间打转，直到龙哥老大发起超级标。那一瞬间我突然觉得——也许，我也可以试试呢？

活动里，各路高手的精彩操作铺天盖地。看着他们的成品，我先是佩服，接着是更深的犹豫——就我这种水平，真的要把处女作晒出来吗？

反复纠结之后，我想通了：发吧！反正也没人认识我，怕什么呢？不如敞开了接受大家的指正。

所以，我的第一个视频就这样诞生了，诚惶诚恐，也带着一点破罐子破摔的坦然。欢迎朋友们尽情批评，轻喷也是爱：
