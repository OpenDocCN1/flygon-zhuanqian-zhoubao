# 📕虚拟资料项目进展及干货笔记制作心得
作者：龙哥

📕虚拟资料项目又来交作业啦！这次同步一下最新数据：截至上周五下午 3:30，累计粉丝 755，赞藏总数 2.2W，一共发了 31 篇笔记。

这周账号流量肉眼可见地往下掉，听说大家都说是因为双十一分流，那我就不客气地拿这个当挡箭牌了哈哈。上周聊了怎么迈出第一步，这周重点说说：我是怎么用十几二十分钟做出一条干货笔记的（按我账号的经验，这个方法挺容易出几十赞或上百赞）。

为什么只聊干货笔记？因为我现在攒下的粉丝和赞藏基本都是靠干货笔记来的，产品笔记我还得再琢磨琢磨。

核心要点：做笔记的“动手”环节可以偷懒，但找选题、拆解对标这些关键动作一点都不能省！

方法一：资料打印出来直接拍
把资料复制到 Word 文档里，打印出来。手边有笔就圈一下标题、重点，或者顺手写两句总结，懒得写也没关系，拍张照直接发。但有个前提：第一页一定要有大标题，让人一眼就知道这篇笔记讲什么。实拍图自带真实感，我用这个办法出过千赞笔记。

方法二：备忘录截图永远的神
我最常用的招数：把内容复制进备忘录，排版好，用醒图调成 3:4 比例，贴纸搜“横线”，选波浪线把重点划出来。没时间精细做笔记的时候，我就靠这招救急。

方法三：封面越简单越好
用美图做一个极简封面：纯色背景加粗体标题就行。颜色和字体记得选年轻女生喜欢的风格，要是没概念，就去刷同行的号，看到大量类似封面自然就有感觉了，直接对标模仿，他们怎么做你就怎么做。

以上三种是我用得最多的做法。毕竟是第一次跑项目，笔记发得越多，数据样本越丰富，对比分析才更有感觉。我记得钟哥说过一句话（原话记不清了），大意是：等笔记发满 100 条，再谈数据分析的事儿。

下次整理我最看重的两个维度：怎么找对标账号、怎么挑选题内容，到时候再分享！
