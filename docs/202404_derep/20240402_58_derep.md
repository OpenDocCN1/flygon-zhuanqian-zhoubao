# ('作为普通素人，如何快速成长并拉起一个项目团队', (2, 24))

普通人想从零开始快速成长，还要搭起一支能打的项目团队，这事到底有没有捷径？今天想和你聊聊这个不少人都关心的话题。

先认识一下我：大朱，一个 95 后斜杠青年。白天在建筑行业搬砖，晚上切换成自媒体新人和健身爱好者。混迹赚钱圈子，拿过新手训练营学霸称号，也在项目拆解营里拿过优秀学员。这几年没少折腾搞钱路子——做过推文短剧、红包封面、视频号分成计划，还办过线上减肥打卡营，带着 20 个人一起科学健康地瘦了下来。

最近我又押注了一个新平台，做短剧 CPS 项目，并且拉起了一个 90 人的项目社群。从一个素人走到今天，我觉得“快速成长 + 拉团队”这件事，靠的不是运气，而是一套可复用的打法和思路。
