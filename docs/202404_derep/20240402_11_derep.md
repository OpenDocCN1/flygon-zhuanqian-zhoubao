# ('中视频双去重，一键多平台，可达日入 2000+', (2, 25))

如果你正在找一个“操作不难、上限可观”的副业方向，那今天这个分享或许能给你一些启发。

故事的主角是一位37岁转型中的大叔——大铭。他常泡在生财圈里看大家的精华内容，虽然自谦写不出大佬级别的高深文章，但他想把自己实操过的一个小项目分享出来，帮到更多人。

这个项目核心就两件事：**双去重处理视频 + 一键分发多个平台**。有圈友实测做到过日入2000+的成绩。因为门槛确实低，跟着步骤走基本都能上手，所以现在做的人不少，竞争也有点激烈。但话说回来，任何项目想做出结果都离不开坚持，这个也不例外。
