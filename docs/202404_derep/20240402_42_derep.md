# ('AI 创业在产品、团队和流量上如何破局？', (2, 22))

AI创业的风口很大，但能真正飞起来的团队很少。产品怎么打磨？团队怎么搭？流量从哪里来？这三个问题卡住了不少人。最近，乔帮主在赚钱航海家线下见面会上，就专门组局聊了这个话题，而且一口气聊了两晚。

说起来挺有意思，他原本只打算开一场15人的夜话局，结果系统出了bug，同一个主题被同时创建成了两场，还瞬间报满。为了不让大家白跑，他把后一场挪到了周五晚上。担心酒店房间装不下，他还特意提醒大家别带人，可到了现场，人数还是超了——周五、周六两晚，每场都挤进了20人。

其实早在去年11月，乔帮主就发起过同主题的线下交流。这一次，他结合两轮夜话的讨论，又把自己近一年在AI方向的创业实践和思考做了系统梳理，整理成了一篇干货文章，专门聊AI创业在产品、团队、流量上的破局思路。

正文没有放星球，而是发在了公众号上。想看的圈友可以直接点下面的链接阅读，相信会有启发。

另外，他还把过去整理的运营工具、技术赚钱实践指南、私域引流方法等精选内容，连同往期干货合集一起放在原文里，需要的话可以顺手收藏。
