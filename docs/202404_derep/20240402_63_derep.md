# ('要站在“社会变革”的立场上理解 AI', (2, 20))

聊到AI，很多人第一反应是技术又突破了、哪个赛道要起飞了。但如果我们只把目光停在技术迭代和商业机会上，恐怕会错过更重要的东西。

真正值得我们去思考的，是AI正在催生一场深刻的社会变革。它不只改变工具，更在重塑人与人之间的关系、生活方式，甚至整个社会的运行逻辑。

有句话挺有启发：AI带来的路径，很有可能是先全面走向虚拟化，再在局部回归现实，形成一个个小而紧密的圈层。也就是说，未来不是简单的线上或线下，而是两个世界不断交错、重新融合。

所以，与其纠结于某项功能是否好用，不如跳出日常视角，站在社会变迁的高度去审视AI。这，才是我们理解这个时代的关键姿势。
