一次买房经历，让我从月入两千的迷茫打工人，变成月入两万的自由室内设计师。

大学毕业后我漂在外面两年，换了七份工作。薪水始终原地踏步，最后只能想着回老家。那次返乡反而成了转机，让我看到了真正的机会和客户痛点：

购房者在选户型时，看不出隐藏的缺陷，等到装修开工才炸出一堆问题，而这些问题其实在买房阶段完全可以规避。

于是我把这个痛点打包成服务，通过抖音、小红书做个人IP引流，第1个、第10个、第100个客户就这样来了。沉淀一年后，第二年仅户型改造一项业务就突破20万+。

下面把我从打工人到独立设计师，月入2000到年入20万的完整路径拆开讲，希望对你有启发。

# **一、职场新人如何从月入 2000 到年入 20 万+**

**大家好，我是李勇，独立室内设计师，全网粉丝8万+。今天复盘一下，我是如何从月入2000的职场新人，做到年入20万+的独立设计师。**

和行业大佬比，20万可能只是开始，但对我个人而言，这是一次质的跃迁。

![](img/c7ac6ed704056b05567343d3e59af231.png)

6年前，我还在装修公司朝九晚五打卡，是个典型的设计小白。那段日子是我职业生涯最低谷，底薪不到2000，日子过得浑浑噩噩。

刚入行经验几乎为零，客户不买账，领导也不看好，每月只能靠微薄底薪撑着。

我一度以为是平台问题，于是两年里换了7家公司。结果无论换到哪，薪水都在2000元上下徘徊。才明白问题出在我自己身上，于是开始想办法突围。

![](img/b13a1064409dfc7f177bcbed67218d58.png)

在外漂泊两年赚不到钱，生活压力越来越大，我决定回老家。没想到这次回家，彻底打开了新的职业思路。

回到老家后我继续在一家装修公司上班，父母为我结婚打算要买房。正是这套房子的选购过程，让我发现了室内设计的新赛道，也走出了困境。

![](img/6c44deca101314a0b9bb4fd0e0a12286.png)

买房第一步就是选户型。身为设计师，我在量房时经常看到客户买到的户型暗藏各种问题。

其实这些问题在购房前就能避免，只要选对户型，装修时的麻烦就能大幅减少。

![](img/62cbb7eb98b47b2d2a81634fa97aece3.png)

于是我在心里构思：先把看中的几个户型做出方案，再去决定买哪套。这样就能提前知道哪套更合适，也能避开后续装修的坑。

我把几个心仪户型的方案都画了出来，对比后更清晰哪个更适合自己。就在这个过程中，我捕捉到了商机……

非专业买房人选户型时很难发现隐藏问题，总要等到装修才暴露。所以这就是一个亟待解决的痛点。

能不能在选户型阶段就把问题解决，而不是等房子买了装修才后悔？

我判断可以把这个痛点产品化，在买房前就为客户做户型规划，帮他挑到合适的户型，并提出理念：“**买房之前，让设计先行**”。

![](img/0bbd81b8f6fc6192c01df823bf57fc60.png)

有了想法我就立刻动手，用自己买房的经历和画好的方案去推广。

![](img/89041f8ee124be39b797dd7f4073f10b.png)

起初我用的是县城本地的微帮号发布朋友圈推广，效果很一般。县城的需求意识和市场体量有限，很快就遇到瓶颈，于是我寻找新的流量入口。

![](img/b6afea5127e0c78e898d58ea445ddb0d.png)

我是知乎的长期用户，于是决定把买房选户型的经历写成文章发在知乎，分众更广。这次尝试终于带来了第一个客户，但结果出乎意料……

![](img/644b06400afdf14dc1d4fcedb4b20489.png)

找我咨询的并不是购房前的客户，而是已经买房、户型已定，准备装修才发现问题要我帮忙改造优化的。

我观察一段时间后发现，主动找来的一水都是要做户型改造的，并没有人要买房前选户型服务。

![](img/8205fa06a34b6ea3845934d7f3c8bdf7.png)

业务方向与最初设想出现了偏差，市场用脚投票告诉了我真实需求。既然如此，我就顺势调整，专注做户型改造这条路。

![](img/ffc3f4b884fb5c32376373a4dbc8ea6a.png)

拿到第一个线上客户后，我坚信这条路能走通。有了第一个，就会有第十个、第一百个。于是我辞掉了老家公司的工作，把全部时间投入到这个项目上。

经过第一年的积累，第二年户型改造业务收入直接突破20万+。

![](img/3c2c84da6ddede5111c4ce3d48d0880c.png)

回头复盘，我在装修公司赚不到钱的核心原因是能力不够。整体设计师要懂平面方案、施工图、效果图、工艺、材料……面太宽，短期内无法精通，自然拿不到结果。

![](img/11c8782687de70c77737f66b1550de55.png)

后来我只做户型改造优化，反而更快看到成果。把精力聚焦在一个点上，很快就能做到专业。总结下来，职场新人想快速出成绩，要找到细分赛道切入，做专才而非想做全才。

光会专业还不够，还得学会把专业卖出去，自媒体运营和微信私域运营是必备技能。

# 二、**如何玩转自媒体两大平台抖音、小红书**

接下来讲我如何把设计生意搬到线上。

最早从知乎起步，然后到抖音，再到小红书。知乎现在红利已过，下面重点讲抖音和小红书。

![](img/0c74523ee3d796a79b36d6459e534a86.png)

**（1）抖音运营的技巧及心得：**

我2018年入局抖音，正好赶上风口。那会做设计的很少，内容很容易获得曝光。也正是这一波流量，让我尝到甜头，客户不断找上门。

**（2）关于做抖音的认知：**

![](img/62fbedc9d492b4bd7060a3b0bd616b7c.png)

做定位时要选垂直细分专业内容，别盲目追求泛流量和粉丝量。要追求的是精准流量和转化能力。

有些账号粉丝几十万却很难变现，有些几千粉却稳定成交。所以账号价值要用变现能力衡量，不是粉丝数字好看就行。

![](img/71820d298c19d7ab9aeb1d3895678d70.png)

**（3）关于做抖音的技巧：**

分享一个让视频播放破30万的做法。

![](img/7097a3ffc297fa15ecdb50b551dc3ccf.png)

**① 把专业知识和大众社会话题结合。**

比如我做过一个标题《为什么才四十几岁就开始分房睡了？》，这就是一个容易引发讨论的社会话题，能吸引已婚人群参与讨论，覆盖面广，自然播放量高。

做视频时思考一下，能否把专业点和一个低门槛的社会话题挂钩，掌握这个就能抓住流量密码。按这个方法做的几条视频播放都在二三十万。

**（4）小红书得运营心得及技巧：**

![](img/e77c6ba20d9f96e2d816930eed90cea0.png)

小红书现在仍有很大潜力。用户量虽不及抖音，但竞争相对没那么激烈。抖音已从一线到八线全覆盖，小红书主要集中在一二线，仍有下沉空间，这就是机会。

**下面分享我如何用3个月把小红书从0做到1万粉。**

背景：
1. 2022年，花一年时间涨了500粉
2. 内容：平面户型改造方案

![](img/28cabb06a0cbdab24d5ce28adcc24181.png)

2. 2023年3-5月，3个月涨到10000粉
3. 内容：每天一个设计小知识

![](img/b205cf0bf94ca00dea888d044664a750.png)

**下面把从0到1万粉的心得拆解出来。**

![](img/403537e5d41cf028bdc2ddc625eaa727.png)

2022年我一直发改造案例，效果平平，一年只涨500粉。后来我反思，平面方案对普通业主理解门槛高，除非方案惊艳，不然很难爆。

于是我换思路，让内容更直观、更容易懂。

![](img/1eeb1e18f27fb1c6e38891f978778971.png)

我每天都会在设计网站学习案例提升自己。想着能不能把学到的知识点记录下来分享？这样自己复习总结，别人也能受益，一举两得。

![](img/e58b65fab59ec00ea3485b8de246cf3c.png)

于是开始在小红书连载《每天一个设计小知识》。第一天反馈就很好，我就坚持下去，三个月做到了万粉。

**①小红书内容要越细越直观越好。**别把内容讲得过于高深，观众看不懂或不感兴趣就没曝光。

**②内容必须对用户有价值。**用户不在乎你多厉害，在乎有没有用。有价值才有关注理由。

**③最好结合个人成长。**我的知识点就是学习笔记的自然输出，你也可以把日常学习的东西整理成分享。

做好自媒体只是第一步，真正的成交在微信私域。抖音、小红书的目的是把潜在客户引到微信，最后在朋友圈完成转化，所以朋友圈运营至关重要。

# **三、如何通过运营打造微信朋友圈赚钱**

下面讲朋友圈如何运营，让用户主动给你打钱。

![](img/3742e51d097579443e922dd3e0b67f46.png)

我总结朋友圈主要分5类内容：

**①要发专业成果。**

![](img/a6551f9b007f425f75ab7b3f2b9e34da.png)

让客户感知到你的专业。设计师就要常发自己的设计方案和案例。

**②要发客户转账截图。**

![](img/170b6e624ed049e32f29cf40f33524a5.png)

转账截图是社会证明，让还没成交的人知道你不是第一个服务的人，降低决策门槛，增加信任和从众心理。

**③要发客户好评截图。**

![](img/b02e328897b1b42566e688ffd745a362.png)

客户的评价比自己说一百句都管用，是权威背书，能大幅提升信任。

**④要发认知感悟和思考。**

![](img/8bb6c5bd4c27c3b27db2e022af5958a2.png)

塑造正能量、爱思考、爱学习的人设，让客户更有好感。

**⑤要发生活类照片。**

![](img/f7b9a947db18c4a777e1c4ea3c6a3ed6.png)

别把朋友圈经营成只有工作汇报的公告栏，适当穿插一些生活瞬间，能让你的形象更立体、有温度。偶尔晒晒日常的点滴，既能让 feed 不至于单调乏味，也能让潜在客户感受到你是一个有生活、有趣的人，而不是一个只会谈工作的机器。

正是借着这一套思路，我回顾了自己从职场萌新到独立设计师的完整成长路径，想和大家梳理清楚。

**最后做一个简要收敛：**

① 入行初期很难做到面面俱到，但可以快速锁定一个行业细分赛道深耕，把自己打造成该赛道的行家里手。唯有如此，才能在短时间内沉淀出可被市场认可的核心竞争力，站稳脚跟。

② 职场新人一定要学会借助新媒体的传播力，把自己的专业能力输出出去。互联网不只是展示的窗口，更是获客的渠道，能把你的服务送到更广的人群面前。

③ 只要你做的是线上生意，微信朋友圈就是最重要的主战场。懂得如何有策略地运营朋友圈，把产品价值和内容价值呈现出来，才能让潜在客户主动找上门并完成转化。

就分享到这里了，希望这段实操经验能对你有所启发。
