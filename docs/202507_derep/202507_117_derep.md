# 赚钱技术团队集体转身 AI 全栈时代已然开启

作者：龙哥
日期：2025-07-07

今天跟赚钱的技术团队开了个会，聊完后我直接拍板：给全员开上 Claude Code Max，每人每月 200 美金额度，由我来承担费用。先挑一位工程师先行试点，等他把使用方法吃透、跑顺后，再把这套工具平铺到整个团队。

会上还达成了另一个关键共识：从此不再纠结前后端划分，研发形态直接走向全栈化。更进一步的是，产品经理、测试同学、UI 设计师也都将逐步具备编码能力，真正的目标是实现人人都能写代码的人均全栈。

一旦这个状态跑通，10 个人的研发小队，就能扛起过去需要几十人团队才能完成的业务量级。
