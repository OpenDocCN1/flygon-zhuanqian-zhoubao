# (185 赞)副业有术应该怎么做销售？

最近认认真真把龙哥盟的销售逻辑翻出来重想了一遍，越理越觉得过去很多做法是需要推翻的。今天把思考整理出来，也算给自己一个交代，也欢迎大家监督。

先说结论：我们过去被市面上很多看似有效的销售套路带偏了。那些常见的“流量打法”“成交话术”，大多是短期主义的东西，不加辨别地照搬，只会把自己往坑里带。而且，这个坑我们待了不短的时间。

真正适合龙哥盟的销售，应该是下面这些样子。

销售的第一性原理，是筛选，不是说服。我们要做的不是把一个不想来的人劝进来，而是把本来就适合这里的人识别出来。所以，哪怕对方已经加了微信，哪怕对方看起来是个潜在客户，只要不符合我们的方向，也要敢于放弃。我们不讨好所有人，只服务那些真正匹配的人。

那到底哪些人是我们要的？这必须想得非常清楚。与其强调“我们适合谁”，不如坦诚地讲清楚“我们不适合谁”。把不适合的门槛讲明白，比把适合的亮点吹上天更有价值。因为本质上，不是用户在挑选我们，而是我们在挑选用户。遇到不符合标准的，果断放下，不要犹豫。

另外，销售过程本身就是交付的一部分。一次好的销售，相当于完成了龙哥盟一半的交付。所谓销售的全部工作，不过是帮对方想明白自己到底要什么，然后把我们的核心理念、核心价值和使用方法讲明白。至于转化率，它不该成为我们骄傲的指标。我们真正在意的，是有没有帮到对的人，有没有被准确地理解。哪怕对方最后没有付费，只要他是那个“对的人”，我们依然为自己传递出去的价值感到开心。

在具体的销售动作上，有几个原则必须守住。

不做低转高。龙哥盟的目标用户普遍看重时间，低价产品只会浪费他们的时间。我们要做的，是“0转高”，直接让对的人看见真正有价值的东西。

不轻易做降价促销。除了418这样的固定节点，其他时间不做非必要的促销动作。

不制造焦虑，也不制造稀缺感。像“只剩最后几单”这种话，我们不会说。我们不靠吓唬人或者制造紧迫感来成交。

不迎合用户的错误认知。有人觉得龙哥盟是赚快钱的捷径，我们不会顺着这种想法说。即便因为说了真话而失去订单，也认了。

我们只帮那些已经意识到要改变的人，而不是去叫醒一个根本不想改变的人。一个人是否真的想改变，看他在销售互动中的每个细节就知道。同时，我们不以穷富来评判人，只看意愿。愿意改变、愿意行动的人，哪怕眼下没有钱，将来也一定会富起来。

还有一条很重要的原则：销售不是销售部的事，而是全员的事。人人都是龙哥盟的代言人，人人都在做销售。销售的本质，就是把自己认为正确和重要的事情告诉用户，并和用户达成共识。

这份共识，要从一开始就建立。第一次接触用户时，我们就要把销售原则和价值观讲清楚。如果用户不认可这些原则和价值观，那他注定不是我们的用户，那就果断放弃。

最后，作为销售，我们应该为自己的专业、真诚和克制感到自豪。销售动作和话术必须与我们交付的产品保持一致——交付是怎么做的，销售就怎么说。不夸大，不包装，不装。只有当我们把自己真正信的东西，用最诚实的方式传递出去，销售这件事才有意义。

方向对了，路就不怕远。龙哥盟的销售体系要彻底调整，也需要时间，但这条路我确信是正确的。
