# 普通人做小红书电商：从零起步到月销20万，我是这样跑通的

大家好，我是大雄，一名网络工程师，也是一个正在摸索副业的普通上班族。

2025 年 418 活动期间，我加入了龙哥盟。其实在此之前，从去年 8 月开始，我就已经尝试做小红书电商，并且逐步完成了从 0 到 1 的验证。
