# 把 Agent 和 RPA 串成流水线，一次做出一千张金句卡片

来源：赚钱有术周报精选
分享人：龙哥
日期：2025年7月7日

你有没有发现，AI 正在把人分成两种：会用它的，和不会用它的。而会用的人里，还有一道分水岭——有人能用它造出产品，有人只是拿它处理些零散小事。

我是龙哥，平时专注研究 RPA、AI Agent、AI 编程这类能直接落地的提效工具。今天这篇，想分享一条让我效率翻了不止一百倍的操作路径。

先回答一个经常被问到的问题：Agent 和 RPA 到底有什么不同？很多人以为它们是一回事。我的理解是：Agent 擅长把任务拆解成清晰的步骤，RPA 擅长把这些步骤一遍遍稳定执行。所以，最有效的组合不是二选一，而是先用 Agent 把整件事规划好，再交给 RPA 去“流水线式”重复跑。这样一来，原本要手动跟进的事情，就可以自动批量完成。
