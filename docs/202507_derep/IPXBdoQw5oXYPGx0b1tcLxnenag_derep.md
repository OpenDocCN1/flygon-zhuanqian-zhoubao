# ('从0开发内容提效工具箱，赚到10000元', (2, 22))

零基础懂内容、不懂代码，我从0做了个内容提效工具箱，赚了1万多

大家好，我是赚钱圈友郭耀天，在这边待了七年。中间有两年没发长文了，不是没做项目，而是每天泡在虚拟资料这个赛道里，玩法来回就那些，感觉没有新东西值得拿出来说。这次冒泡，是因为看到很多同类伙伴踩了同一个坑：做起内容来，工具不够用。

做虚拟资料，绕不开word转图片、pdf转图片、word生成视频这些需求。听上去都是小事，真找到能批量处理的工具却很难。每开一个项目，就要装一堆软件；有些功能只为一个点，还得单独付费，操作麻烦不说，还不能批量。更头疼的是，某些需求市面上干脆没有解法，硬着头皮做，效率极低。

![](img/ac700bf43a7a827d147e5f25d0474b42.png)

其实我很多年前就想自己做一个合集工具，把虚拟资料制作里的常见卡点都收进去。但当时找人开发，不是价格高得离谱，就是对方没能力持续投入，还有的说功能根本实现不了。淘宝问过一家，光一个“word批量转图片”就报价两万多。现在回头看，这些功能靠AI写代码很快就能落地。

后来有个伙伴做虚拟资料推广，天天被换背景、文档转换折磨，自己搞了个初级版工具。我们聊到我想做一套更完整的工具箱，他也有兴趣，两个人一拍即合，“玩赚工具箱”就这样从0开始了。我们定位很清晰：专注虚拟资料制作板块，只做内容提效和批量制作。不追大而全，只围绕虚拟资料的小需求，定制开发真正能用的功能。

刚开始的时候，有人看不顺眼：别人都去研究AI出海，你还在搞这种“小东西”？我觉得能解决问题就有价值。半年过去，这个工具箱已经帮不少伙伴实现了内容批量制作，光工具箱的直接收费就有一万多，加上微信收款，合计两万多的进账。虽然还没覆盖全部开发投入，但由它带起的整体收益已经超过20万。我自己的判断是，继续走下去，这个数字有机会到百万。

![](img/f8688641c74a82f23a384b51c33570a9.png)

先介绍我们最早做的word转图片。公文项目我们做了五年，天天要把word变成图片，还经常要把标题加粗。市面上单张转换的工具很多，能批量处理却不掉链子的很少。我们的方案是：导入多份word，一键生成单页图片或长图，直接拿去推广。

![](img/b4198c527ca74bac17bc8bef8327f5f7.png)

后来用户问得多了，pdf转图片、PPT转图片也都陆续安排上了。

![](img/6dbd412078d057aa4bbaf52bc22d3d86.png)

图片搞定，视频也不能落下。像公文号在B站上的滚动视频，用剪映做一条要花五到十分钟。我们直接做了一个批量生成功能：导入word，一分钟出一条视频。以前手动一天做几十条，现在电脑配置够用的话，一天几百上千条也能跑完。

![](img/0b91ecc8e000dd66e9b0cb716ea082e9.png)

再说一个很受小红书用户欢迎的功能——背景替换。做小红书的都知道，看到好背景就想把内容贴进去，比如教室、电脑屏幕。正面图相对好办，斜面图就麻烦了，常规工具基本搞不定。

![](img/cac8deea0f7fae43fdf923710a001bef.png)

我们于是开发了一个灵活的背景替换工具：导入自己的内容图，再导入背景，拖动四角调整到完全重合，点一下就能批量替换。现在小红书上大量斜面图，都是靠我们这套工具批量做出来的。

![](img/172921becc3b3e51c8b8bb1d1542ceb7.png)

一键融合，快速完成背景替换，内容生产效率一下就上来了。

![](img/84e0e15260a2adf86c95bdaf9cf4bc51.png)

图片背景可以融合，斜面视频也能做到。前期我们也没把握，磨了很久终于落地。用法跟图片类似：直接把视频拖到背景画面上调整位置，让视频和斜面背景自然融合，批量换背景的同时，也保留了推广所需的场景感。

![](img/90f424c13f3902d0e059853e47d5fe20.png)

做教师资料的朋友，对PPT制作应该很有共鸣。用美图秀秀、搞定设计这一类工具，单独做一张不是不行，但很难批量产出。

![](img/aef69af3fc936aa39da241b804c17425.png)

有需求就去解决。我们做了“百变拼图”，小红书上九成图片拼图效果都能还原。提前设好模板预设，后面只要导入图片，就能自动生成页面内容，批量制作变得很轻松。

![](img/e59ac9fbd02852ca37da2405666ee52f.png)

内容页面解决了，新的问题又冒出来：封面内容和内页不一样，能不能也批量做？顺手把这个问题也抛给了技术。

![](img/b9a7cf7e40fb1f53363914e4bf477d9a.png)

其实对技术来说，很多功能都能实现，只看费不费力。我们不断提想法、做优化，最后真把“百变快拼”做出来了：一键搞定封面、内页的批量导出。

![](img/a1ce7604dc155ffa4c209cdd511dc0c3.png)

它不仅支持一个内页，还能一次批量生成多种版式的内页。最近还看到有人用word替换背景发公文推广，效果不错，有伙伴跑来问这个能不能做。

![](img/70da773749dd7d0fe8c5435355987035.png)

我不懂代码，一行也不会写，但AI让很多想法有了落地的可能。像美图秀秀能做批量抠图，可是按生成次数算钱，成本太高。我们继续提需求，后来也实现了：导入word文档，批量替换背景，直接解决制作问题。

![](img/1c905dda4910c13241ac2bdf2bf2225e.png)

尤其适合做交叉融合的场景：一组内容图，可以分别和不同的背景图去组合。你准备100张背景，就能得到100种不同背景的内容。整批生成会按文件夹整理好，用于推广或二次剪辑都很方便。

![](img/d1ab711312ad41250809f055e38b35bb.png)

这些只是其中一部分，其实我们已经把虚拟文档制作中的一大串功能都纳入了工具箱。

![](img/e570c6daa0823608765b1b79c7e4a1d4.png)

举个例子，PPT转预览视频。WPS和Office都能转，但没法批量，转出来还得再加工。我们选择在转换的同时对视频做处理，可以添加音频、调整变速，让成片直接达到预览视频的效果。对于拿PPT推广虚拟资料的人来说，省事不是一点半点。

![](img/957c46fd6a6851c9a0d58fd8a0d52ded.png)

拼图模式也做了很多种，市面上常见的拼图样式基本都覆盖了。简单说，用户需要什么，我们就开发什么。

![](img/8412ff5f220da814e14e6c67a2ebfc81.png)

写了这么多，最想说的是：只要有想法，找到能落地的人，普通人也可以开发出解决问题的工具。这个项目最初的出发点只是自用，没想到会有那么多人愿意付费，还因此收获了一批铁杆用户。AI越来越强，完全可以根据自己的需求写一个小工具，再卖给同样有需求的用户，赚钱这件事就顺理成章。

技术和AI都不是核心，核心是找到真实需求。我们后续也会把更多AI能力融入工具箱，但现在先把基础功能做扎实。对工具有兴趣的伙伴，可以找鱼丸要我的联系方式，我会给你开通试用。如果有好的建议，或者想实现的功能，也欢迎留言，我们会按大家的需求继续开发。

虚拟资料这个赛道，我依然看好。做的人越多，共性需求就越集中；谁愿意去解决这些需求，谁就能分到属于自己那份回报。
