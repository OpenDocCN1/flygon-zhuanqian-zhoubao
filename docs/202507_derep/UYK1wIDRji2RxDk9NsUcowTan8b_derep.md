# AI图像变现案例拆解：Thiings

上周我刷Reddit时，无意间挖到个AI图像赚钱的宝藏网站Thiings，做起来门槛低到离谱，普通人完全能照着抄作业！这周我又花时间把它怎么赚钱、怎么从小白做到爆火的路径全捋了一遍。顺便说一句，我一个纯开发小白，居然也手痒试水搞了个低配版demo。如果你也想做AI产品出海，这篇拆解应该能给你点启发和底气！

先看Thiings到底是个啥——它就是个持续更新的免费3D图标库，所有图标都是AI生成，每个还配了语音描述，目前已有5000+图标入库。用户可以按主题逛，生成专属图标，或者一键下载全套官方版本，这些图标不管是个人用还是拿去商用都行，完全免费。它的受众正是一群需要独特高品质3D素材的设计师、开发者和内容创作者。

![](img/43c168878108cddb948b3da45d7e59c2.png)

它的生成流程也不复杂：调用OpenAI的“gpt-image-1”图片生成接口，配上参考图和详细的风格规范，每半小时自动跑一张新图标，后台有人工过一眼审核。除了官方库存，开发者还给每位注册用户送了1个免费积分，让你能亲手定制专属图标。我试了一下，让它搞一颗闪着黄光的小星星，成品还真好看！你还可以发起图标申请，要是被官方采纳进库，又能白嫖积分！这招既让用户心甘情愿贡献内容，又大大省了新增素材的成本，太聪明了。

![](img/24aa178d93637214d041d722509b10fa.png)

![](img/828d879db97234893a461f64629ff8f9.png)

开发者今年4月25日注册域名，建站加做图标各花一周左右，5月16日在X正式亮相，接着6月7日直接登顶Product Hunt日榜第一名，接下来我就扒一扒他的冷启动奇招。这哥们儿可不得了，15年设计和开发老炮，今年靠AI一口气做出好几个AI图像产品，光Thiings就有3款闯进Product Hunt日榜前五，牛人作品大家可以去翻翻。

![](img/43d0e794494a5372440af63da410e689.png)

![](img/e7bc838792aafc48ecfb186fa3822d64.png)

![](img/2be35d7d8ab5773b95f602741075b7a9.png)

AITDK的数据显示，这网站月访问量已经破了20万，飙升速度简直让人眼红，关键是其中超过60%都是直接流量，说明Thiings的品牌效应已经起来了！用户大头来自美国、中国和印度。

![](img/9c363b1521bcef5fa7a99a1c6bf97f6d.png)

![](img/45ae40901001310ebf4997814913d98e.png)

![](img/2b0d43dd709733b9da91cec0fd81340a.png)

再来看它的盈利路子，目前就三条：终身买断、积分充值、品牌赞助，全是最常见的变现打法。

![](img/f02263e44e21a9c3657acd60bff58215.png)

![](img/88d87d709777287311725d472b877c37.png)

![](img/6eb109b67e19ad3a03c02ecf6e302fb6.png)

开发者亲口说，这些变现模式都已经跑通了。虽然调用的OpenAI模型烧钱，前期为了生成1200个图标差不多花了400美元（平均每个图标折合0.33美元），但很快就回本了，上线才一周销售额就破了千刀，赞助商也跟着来了。

![](img/ec6cd0969225c46b46e6a3cce00fa9d5.png)

![](img/a5835d5f7cf3879c2db641e062a74f6c.png)

![](img/fe81a02472898d16c1afeff423d15342.png)

接着我把开发者的各个社交平台翻了个底朝天，整理出了Thiings的冷启动时间线：

*   X：他在辞职做自由职业后，就开始在X上活跃，慢慢攒了几千粉。正式发布前，他不断po创作过程和图标样例，既测试用户反应又拉着大家一起玩。5月16日官宣Thiings的那条帖直接爆款，又圈了千粉。

*   Reddit：5月21日新注册reddit账号，在r/SideProject、r/InternetIsBeautiful、r/indiehackers这几个版块发帖狂推，主打“免费”、“可商用”、“3D图标库”，在r/SideProject那边反响最好。

*   Hacker News：5月24日也去HN发了帖，可惜平平无奇。

*   GitHub：6月2日开源了交互式网格组件，意外收获200多个star。

*   Product Hunt：5月底第一次提交上了但效果一般，开发者并不气馁，向PH团队申请二次打榜，还根据用户吐槽改了网站内容，最终6月7日重新提交，一举拿下日榜冠军。

拿下Product Hunt日榜第一后，口碑直接引爆，网站流量翻了倍（这不就是小排老师说的第一效应嘛！），中外媒体也纷纷自发安利，持续给产品输血。到6月25日，单日独立访客已经冲到近1W，而且主力流量来自谷歌搜索，估计是被某个大媒点名了，引发了大批用户自发搜索和分享，最后变成了品牌搜索拉动增长的飞轮。

其实对于懂行的开发者，复刻这个产品真不难。已知API调用的是OpenAI的“gpt-image-1”模型，而且开发者大方开源了那个独特UI组件——“thiings-grid”，意味着我们完全可以在这个基础上做自己的创意延伸！为了证明复刻到底有多轻松，我这个开发幼儿园学生也亲自试水了一把：

第一步，由于不知道Thiings生成图的具体prompt，我直接找ChatGPT帮我逆向推导，然后用4o去生图。
