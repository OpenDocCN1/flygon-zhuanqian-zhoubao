# ('(精华帖)(316 赞)零基础，在狗都不做的国内市场，如何三个月做出稳定变现的 ai 产品', (2, 47))

很多人都在问：一个完全不懂代码的人，在普遍不被看好的国内市场，真的能做出赚钱的AI产品吗？

今天要分享的故事，给出了一个让人意外的答案。

故事的主人公叫六六，曾经在阿里、美团做产品经理，现在是一名AI产品创业者。她把自己在SCAI实验室从0到1做产品的全过程，写成了一篇深度复盘。这篇帖子在赚钱有术拿到了316个赞，也被标记为精华帖。

她不是技术大牛，甚至可以说是个编程零基础的普通人。但在学完小排老师的课程后，她只用了三个月，就做出了一款稳定变现的产品。这件事放在“狗都不做”的国内市场里，显得格外特别。

很多人好奇：SCAI实验室到底教什么？小排老师有什么不外传的秘密？六六在复盘中都坦白了。

更让人动容的，是她低谷期的自我重建。一个在迷茫中的人，如何一步步找回热情和初心，这个故事本身就足够打动人。

产品叫《我在》，是一款小程序。有读者为了找到它，在微信、小红书、公众号里换了各种关键词，搜了整整15分钟。试用之后，意外地被感动到流泪。这位读者还友情提醒：产品虽好，但搜索路径确实该优化一下。

评论区里，小排老师的评价特别真诚。他说，六六是他见过最勤奋的人。刚到SCAI时，她每天凌晨三四点发日报复盘；刚报课时，她是第一个跑完全流程的人，好像从不睡觉；当助教时走得最晚；不管任务多难，她都会拼命学会。在杭州，她成了实验室新的“关灯人”；到北京交流时，其他人晚上8点就走，她总是一个人待到凌晨两三点，在空荡荡的房间里专注做自己的事。

小排老师说：可惜六六不是一支股票，不然一定建议大家买点。有她这股劲头，做什么都能成。

还有人评论：她是SCAI实验室名副其实的卷王，对产品精益求精。每一次看她的复盘，都会被字里行间的真情实感打动。用心做出的产品就像艺术品，期待她迎来大爆单。

真诚自有万钧之力。这篇文章里的故事，不仅是关于做产品，更是关于一个人如何靠努力和信念，把“不可能”变成“可能”。

如果你也对SCAI实验室好奇，或者正处于低谷想找回力量，这篇复盘值得一读。
