# ('(精华帖)(76 赞)国庆 5 天利用 AI 编程手搓 Youtube 提效工具', (2, 42))

国庆期间，我用 5 天时间，靠 AI 编程给自己做了一个 YouTube 提效工具，没想到效果出奇得好。这条记录，是我个人从零开始的一次 AI 协作实战复盘。

先说说背景。

9 月我报名参加了 YouTube Shorts 的航海项目，初衷是熟悉 AI 视频生产链路——文生图、图生视频这些常用平台和提示词技巧。但当时主业忙得不可开交，实际只产出了 5 条片子，其中 3 条播放量都卡在了 3 万附近。想继续往下深耕，效率却成了最大拦路虎，慢慢就有点磨没了耐心。

正好赶上国庆小长假，我索性用 Cursor + Claude 这套组合，花几天时间捣鼓出了一个自用型工具包。它能做的事包括：对标账号追踪、视频资源抓取、图片生成、视频合成、以及图片去水印等模块。工具做出来之后，居然已经有两个朋友预定了使用名额，现在 Windows 版和 Mac 版也都已经打包好了。
