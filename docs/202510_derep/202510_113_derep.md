# 故事才刚启幕：我在北京 SCAI 实验室的 100 天

大家好，我是兔老大 Roxy，熟悉的人都喊我兔老师。本职是大学老师，同时也是刘小排老师的学生之一。前几天六六写了篇复盘文，顺带问我要不要也把在 SCAI 的经历梳理一下。我第一反应是拒绝的——**我对她说：“故事才刚开始呢，我打算等真正离开那天再动笔。可那一天什么时候来，我自己也说不准。”**

说实话，我心里还藏着另一个念头：**“不想在半路上就开香槟庆祝，眼下的这点成绩，根本够不上复盘的资格。”** 但六六一句话点醒了我：“你不写下来，迟早会忘的。”

是啊，记忆这东西，不记就会跑。我被说服了，决定把这段历程记下来。如果这些文字能给别人一点点启发，那就更值了。

今年五月，我正式加入了北京 SCAI 实验室。只要没课，我都会泡在那里干活。可以说，SCAI 替我推开了一扇全新世界的大门。得提一句，“赚钱有术”这个账号是我老公注册的。起初看到这名字，我差点以为他误入了什么传销窝点或被割了韭菜。带着满腹疑虑，我点开了赚钱社区，翻了几篇精华帖后，之前的那些“偏见”瞬间碎了一地。随之而来的，是深深的自我怀疑。**我这一路走来，从读书到教书，始终没出过校园。在我原本的认知框架里，人生似乎就该按部就班——读书、考公务员、进大厂、挤国企、出国、拿绿卡，仿佛这才是标准答案。**

可看到那么多圈友在不同的赛道上各显神通，看到一个个超级个体和一人公司拔地而起，我由衷敬佩。同时也猛然警醒：我在原有的舒适圈里待得太久了，眼界越来越窄。每当一届届毕业生为了“北京户口”“事业编制”“大厂 Offer”挤破头，在就业寒冬里挣扎时，**我突然懂了，为什么我帮不了他们。因为我的世界只有一座独木桥，我自己都没见过人生的旷野，又怎么可能带他们看见那片广阔天地？每每想起这点，我就忍不住羞愧。**
