# 别再拿“专注”绑架自己了，先学学拆解和模仿

“明明什么都试过了，也赚到过钱，但就是没法坚持一个项目，怎么办？”这样一个问题，在一段时间里让一个研一学生特别困扰。

他尝试过公众号爆文、AI代写、闲鱼虚拟资料、小红书资料号这些路子，几乎每个都跑通过。可每次一到执行的中后期，要么是太想快点赚到钱，但能力还跟不上，要么是在和特别难缠的客户来回拉扯时，心态先崩了，然后他就突然放弃，顺手拿“项目不适合我”当台阶下。

现在他手上还留着一个虚拟资料项目在持续产生被动收入，脑子告诉他要抓住这个有正反馈的方向，好好专注下去。可奇怪的是，他对这个项目就是提不起动手的欲望。想做点原创内容，硬是憋不出来，又怕自己操作不规范，收到维权律师函。想去看看别的项目，又觉得这样是不是就不专注了。于是整个人卡在一个别扭的位置，有很长一段时间，他甚至不想打开赚钱有术，也不想碰任何项目。

不过好在他没有全盘躺平。毕竟研一还有大把空余时间，也想提升赚钱能力。他重新翻出了《赚钱宝典》，翻旧帖子，看具体项目，逐个试着实操，虽然暂时还没发现答案，但至少他决定先按这个节奏继续走。

龙哥的回复很短，却很戳心：那些做出原创的人，是靠哪1、2、3个步骤把原创搞定的？你仔细去拆解，然后认真模仿就行。

换句话说，与其在“我到底该不该专注”里打转，不如把注意力放在那些已经做出原创的人身上，看看他们从0到1到底用了哪几步。是选题方式、素材收集习惯，还是写作框架、发布节奏？一条条拆出来，然后照着做。模仿不等于抄袭，而是把成功者的路走一遍，再慢慢走出自己的道。有了这样的抓手，行动力才不会空转，原创也不会像石头一样挤不出来。

所以，如果你也困在这种“专注牢笼”里，先别急着逼自己“必须坚持一个项目”。试着找到一位你佩服的原创作者，拆出他的1、2、3步，然后认认真真模仿一遍。说不定，答案就藏在动作里。
