# 当对老板产生不满时，我们真正卡在的地方

在职场里，遇到卡点很常见。更常发生的，是我们下意识地把卡点归到“管理者没搞定”上。

这种归因一开始很解压。把责任外放，转头抱怨几句，瞬间就能获得情绪上的喘息。好像问题被推走了，压力被分摊了。

但现实很快就会打脸。抱怨的声音消散后，任务没变，deadline没变，自己该扛的压力、该承受的不适，全都原封不动地留在原地。

换句话说，责怪上司或许能买到片刻的心理轻松，却换不来工作的实质轻松。难题依然是难题，劳苦依然是劳苦。

于是关键的问题就浮现了：当指责别人已经无法让我们免于辛苦的时候，我们该如何自处？
