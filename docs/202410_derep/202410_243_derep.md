# 圈友作业里藏着的书单，原来大家都在读这些！

最近被一份有趣的统计吸引住了：赚钱有术圈友@怪才 把“0919作业”里所有被提及的书单数据抓取下来，做了一次完整梳理。乍一听不复杂，但实际操作却挺考验耐心。

他透露，最初想让 kimi 直接给出结构化数据，但效果不太理想。于是干脆自己写代码进行清洗，再用 WPS 做汇总，最后还人工把同一本书的不同称呼合并到一处。毕竟有些书在作业里会出现“别名”，不归拢一下数据就不够准确。当然，极少数冷门书籍因为出现频率太低被剔除了，整体影响可以忽略不计。

最终统计结果如下：775 份作业里，累积提到了 2728 本书，去重之后，共有 894 本不同的书。![](img/ce7b28d6a721658ea641d13db380b168.png "None")

这个书单在评论区也引发了不少讨论。圈友小吴姐直接安利了《富爸爸》《纳瓦尔宝典》《影响力》《10倍增》，说自己反复读过好几遍，非常推荐，还提议：赚钱能不能挑几本组织共读？没想到龙哥很快回应“可以有”，甚至表示可以给小吴姐安排一个共读小组，让她来负责带读。小吴姐乐呵呵地接下了任务，龙哥则说细节10月份再沟通。另外，圈友周彦充也留言感叹这组数据很棒，准备今天就去选几本快点读起来。

从一份作业书单，到一场可能诞生的共读活动，这种“分享—响应—行动”的节奏还挺动人的。10月的共读小组如果落地，应该能给不少人打开新的阅读方向。
