# 一家女性饰品店，从亏掉100万到年入50万：我踩过的坑和翻盘的核心思路

最近总有人问我：“现在实体店还能做吗？感觉做啥都亏钱。”

但我自己的经历是：2020年疫情最凶的时候，我反而逆势开店，中间巨亏近百万，差点撑不下去，而如今单店年利润稳定在50万左右，还在继续拓店。

今天不讲虚的，只把这几年的真实经历、亏损教训和翻盘关键掰开揉碎讲清楚，希望能给想尝试实体或者正在硬撑的你一点参考。

## 一、所有人都不看好的时候，恰恰是入场的窗口期

我是金融行业出身，2018年离职后一直想找一份自己热爱的生意。考察过养发馆、医美、美甲、珍珠蚌，全都没谈拢。2019年底，口罩问题突然爆发，北京实体遭到重创，商场空铺一大片。招商部到处拉人，商铺从过去的“想进进不去”变成了“求着租”。

当时很多人嘴上都是同一句话：“实体完蛋了，别碰。”但我的判断恰恰相反——当一个行业被大多数人判定为“没戏”的时候，机会往往就在里面。

有一次逛街进了一家欧式复古风的饰品店，人挤人，每件商品都特别有调性，当时逛了半小时就走，回家后心痒得不行，第二天又专门跑去一逛是仨小时。后来接触到老板娘小A，她有自己的供应链，首批按标价的2.5折供货，零售最低能卖7折，甚至支持月结和退换货，还免加盟费。聊完后我心里那杆秤一下子有了答案：这就是我的项目。

## 二、判断一个店到底赚不赚钱，像侦探一样去摸底

开店前我花了两件事去验证这个模式：

第一件事，蹲守。我连续十几天在店铺门口假装路人，偷偷记数——每天进店多少人、提袋出来多少人，再根据购物袋大小估算客单价。结果让我很惊讶：每4个人进店，就有1个人掏钱。这个转化率在实体店里算相当惊人了。

第二件事，进店工作。我以学运营的名义进店打工，做销售、收银、理货、补货，甚至趁没人时偷偷翻老板娘账本。真实数据如下：

- 日均营业额2万，月60万
- 人员工资：店长1人+导购3人，合计5万/月
- 房租+物业：18万/月（北京一等商圈）
- 电费管理费：约2千
- 产品毛利率：70%
- 月利润粗算：60×0.7－5－18－0.5＝18.8万

这数据直接打动了我，于是决定入局。

## 三、砸了100万才明白选址和装修的坑

开店第一步就给我上了一课：找铺子位置。

我用了整整两个月扫遍北京热门商圈——青年多、女客多、有活力的场子，比如朝阳的几个大型商场，我都是亲自去蹲人流、看客群。然而光看没用，还得有资源。当时招商部给的报价高得离谱，那真是吃拿卡要，收了钱不办事的也有。最后靠朋友牵线，找到商场招商总监，给了两个候选铺位：

- 一是30平小铺，在美食街入口，客流大但门口有根大柱子挡视线。
- 二是100平大铺，在地铁口附近，中岛容易分流，户型有点斜角。

当时的我鬼迷心窍，觉得“大就是好”，选了100平那间。这个决定后来让我吃了大亏——租金太高，成为闭店亏损的根源之一。而且谈租金时我以为已经够低了，后来才反应过来，还能再压一截。合同签的时候我根本没注意，写着每年租金阶梯式上涨。直到第二年看到账单才傻眼。

装修那就更是一场硬仗：围挡要审批、图纸要改到吐、商场指定空调消防公司报价比市场高一大截。预算外又砸了差不多30万。30万报价压到24万，算是只学到了一点压价技巧。当时元还天真地少看了现场，墙面刷错了一部分，发现时也只能将就着。这里给每个准备“进场”的朋友泼一盆冷水：工程位置不对，你找人没用，要早做心理预算和功课，准备给自己的认知买单。

开业前的总花销大致是：押金25万+首月房租8万+装修30万+首批货款20万，合计一下直接烧掉80多万。

## 四、开业第一天才卖一千块，我连夜改陈列

开业前一晚我紧张到睡不着，朋友们都来帮忙摆货、打扫。结果开业当天进店人数一只手数得过来，傍晚营业额才破千。

我急得抓起电话打给小A，她连夜跑来，指出问题：店铺太“规矩”了，门口空荡荡，没有任何吸引人的东西。女生逛街是被“视觉勾住的”，不摆出来让人远远就想走近，根本不会有人进店。

第二天我赶紧把最大的展台推到了门口，铺上最吸睛的新品。结果一下子堵满了人，人越聚越多，营业额几天后就起飞了。

**开门迎客的前几天其实自带流量红利，有问题必须连夜改，不能拖。**

而这几天之外，更重要的秘诀是持续上新。我们老客几乎每周都会来，店面必须让他们每次来都有新东西看。我犯过的错误是前期不懂控量，导致滞销堆积、畅销缺货、压在仓库的钱压得现金流发紧。

后来的做法是：每周小批量上新，卖完再补；滞销款两个月内必须退换掉；换季清仓要提前做，“舍不得打折等于亏钱”。另外，陈列真的是技术活——哪个区域放高价品、哪个角度能勾起购买欲，要反复试。

开业一年左右，月均营业额35万，利润算下来：35×0.7－4－0.1－8.5≈11.9万，勉强回本。

一切都看似很顺时，只有问题在暗处抬头——每月营业额其实已经开始下滑，而我还沉在“小赚”的喜悦里。

## 五、经济风向变了，嗅觉迟钝的人先亏钱

转捩点出现在2021年下半年。口罩反复，商场人流肉眼可见地往下掉。大三之前热闹的圣诞档，前一两年备货根本不够卖，那年却几乎清不动货。年轻人消费意愿骤减，收入预期变差。

那时候月营业额跌到25万，房租反而涨到9.5万。算下来净利润只有3.9万，几乎白干。更惨的是2021年5月，因商场出现病例，强制闭店超过三个礼拜。闭店期间房租照付——因为租约背后是港资企业，减免申请交了也石沉大海。最艰难的10个月，账面蒸发了差不多80万，只剩靠银行经营贷续命。

我必须坦白——那阶段最大的失误：完全没把“合同”当护身符。租金上涨、免租条款、不可抗力期间的租金豁免……这些明明是可以白纸黑字定的，而我在签的时候没有任何概念。后来自媒体上大家总结的教训，我都是用百万现金换来的。

店铺闭着，等于是无底洞。我只能偷偷溜进店里，架一部手机，开始在视频号和熟客直播，用半价清货。意外的是因为大家也憋在家里，直播效果异常火爆，推着我把库存清了一波，还顺便搭起了私域的底子。

## 六、局面越难，越要向供应链和人群打法调头

2022年初解封。原本期待“触底反弹”，结果等来的是“消费降级”。人回来了，购买却没了。周末店里人来人往，收银台却一直没人结账。

眼看小A还活在旧世界的模式里不改，我跟她正式分道扬镳。

我拿着两年的经验，直接跑遍了广州十三行、义乌小商品城、深圳南油、连云港水晶城、嘉兴濮院，找核心供应链。看生产端的能力之后终于明白，1688上80%还不是源头，想要足够低的成本必须下沉到源头市场。当然中小卖家不必一口气就跑到工厂拿货，二批也能活，至少比盲目干要强。

更重要的是品牌定位的转折：从轻奢转向高性价比，保住质感，降低客单价，走“精致小众+通勤百搭”的路线。让女孩们既能穿去上班，也能周末派对换风格，不贵但时尚，不再被“中产焦虑”绑架。

同时另一大关键，是私域的精细化运营。

- 加微信的话术一律拿“售后”当理由：“任何问题都可以微信找到我们第一时间处理。”这个理由几乎没人会拒绝。
- 对高购买力的客户做VIP备注，重点服务和维护。
- 重要节日跟着用户情绪走——女生即使是3.8也要给自己买东西，得让她们总有找到一个“买买买”的合理出口。

凭这套组合拳，进店顾客的微信转化率能做到50%左右，回头客复购率明显提高，利润也重新垒了起来。

## 最后说点大实话

回顾这100万学费买来的经验，几条最重要的认知送给你：

1. 别人恐惧的时候，反而是机会最扎堆的时刻；
2. 没经验时，选一个靠谱的体系加盟能少走很多弯路；
3. 租金、合同条款一定是谈判重点，能压价绝不心软；
4. 店铺的生命力来自“流量+上新+陈列”的组合拳；
5. 现金流永远比营业额重要，算不清账迟早白忙；
6. 消费风向变了，你必须比客户变得更快。

生意走到最后都是精细活。当大部分人说“不行”时，恰恰是需要你站出来用自己的方法，把它做出“行”的样子。

希望我的这些经历，能帮你少踩几个坑。

这两年实体店到底还能不能做？很多人都在犹豫。今天不绕弯子，直接把我自己摸爬滚打出来的真实经验分享出来，希望能给你一点参考。

先说私域运营这件事。我们做活动主要放在社群和朋友圈，基本不主动私聊客人——说实话，现在的顾客特别反感被销售频繁打扰，所以不如把精力放在群消息上。客户需求不一样，就分门别类拉群，比如秒杀群、上新群，既能精准区分人群，又方便针对性地推送活动。只要顾客主动询问、点赞，或者有任何互动信号，我们一定第一时间跟上服务，不管最后有没有成交，都把情绪价值给足，再顺势引导到线下，提升进店的可能。

关于发朋友圈的时间，我们试过很多次，发现午后、傍晚和晚饭后这几个时段，大家刷手机的空闲时间比较多，关注度也更高。但有个坑必须提醒：朋友圈千万别被折叠！一旦折叠，曝光直接归零。所以每天的发圈文案都要用心打磨，我会去小红书找灵感，发完之后再用另一部手机检查，确保内容完整展示，而不是被系统吞掉。

再聊聊饥饿营销。换季的滞销品，就靠秒杀价、福利价来清货。库存只放几个，制造手慢无的紧张感，甚至可以让熟人带带节奏，烘托一下热卖的氛围。秒杀规则一定要严格执行，过了时间决不延期，饥饿感出来了，大家的参与热情自然高涨，成交率也跟着上去。这一招还能顺便测试新品潜力——用预售模式，既能压力库存风险，又能提前锁定爆款。

新品预定也很关键。先收定金再下单，一方面能探清顾客的真实偏好，减少压货，另一方面也能把客群画像越描越细。更难得的是，这种模式增加了和客人的沟通频率，粘性和忠诚度慢慢就养出来了。

说下我的实际成绩：调整两个月后，4月营业额回到20万，5月稳定在25万。虽然比不上最风光的时候，但已经心满意足。到2022年底，全年利润50万。经历过消费观念的大转变，营业额很难重回巅峰，所以现在的策略就是稳字当头，先在内卷的市场里活下来。

进入2023年，我做了几个关键升级。首先是上数据化系统。以前收银只按价格区分，条形码扫出来就是“饰品90”“上衣399”这种，完全看不出什么品类卖得好。后来在库存上新系统里强行加入了细颗粒度标签——风格分为甜酷、辣妹、千金风，品类型分百褶裙、高腰裤、喇叭裤，材质分羊毛、马海毛、桑蚕丝等等。这样一来，数据可以从多维度交叉分析，选品不再靠感觉，滞销概率明显下降。

然后是供应链深度绑定。我们和供应商合作更紧密了，做小批量独家定制款，比如饰品两打起就能微调，把A产品的零件换成B产品的，就成了独一无二的款式。衣服虽然难搞小批定制，但可以筛出质价比高的版本，再用服务和营销卖出去，形成变现闭环。

团队也进行了升级。5月扩了人，服务流程写成简单SOP，从进门接待、推荐产品、夸顾客，到成交和不成交的话术，全给员工方法，后面不断完善。换季前分批做培训，拆解下季流行点、时事热点，顺便练员工默契，线上线下合发力。2023年利润也稳稳落在50万。

复盘这几年，能活下来，我大概做对了这么几件事：一是时机，口罩初期房租便宜押金少；二是别怕别人不看好，机会一开始总是冷门的；三是产品差异化和上新速度要跟上，性价比和质量都不能差；四是店铺选址和客群匹配，做精致女生生意，店面也要有质感；五是跑义乌、诸暨、嘉兴、连云港、广州、深圳的源头工厂，压缩成本，支持小批量改款；六是自己别做甩手掌柜，天天盯在一线，摸清顾客需求；七是每月算账，严格控制进出，订货量提前计划好；八是换季清仓要狠得下心；九是要坚持自己擅长的事，别到处追风口，等风来。

给新人提个醒：第一，不要轻易跨界，最好是先去同行业打工学习，攒够经验再开店；第二，招商资源很重要，房租和关系硬不硬直接相关，街道、消防那边也要吃透；第三，没资源就要舍得花钱；第四，一定要找房租足够低的地方。加盟更要当心，尤其是那些一天打八遍电话催你的，绝对有坑。

评论区好多人问我有没有做短视频账号，也有人问行情不好是不是该及时关店止损。其实每个人情况不同，但我觉得，无论最后选择什么，这些踩过的坑和攒下来的经验，至少能让你少走弯路。
