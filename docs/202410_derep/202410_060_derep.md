# ('淘蛙如何在餐饮行业利润逆势增长中提升效率降低成本', (2, 26))

餐饮行业普遍在喊“钱难赚”，但有个品牌却悄悄把利润做上去了——淘蛙。昨晚在直播间听了小马宋和淘蛙创始人刘总的交流，收获不少。淘蛙目前在广东开了300家店，主打厚汁干锅蛙，他们最厉害的地方，不是营业额暴涨，而是把各项成本压到极致，利润因此逆势增长。这里帮大家划几个重点。

**一、把门店做“小”，餐位却不能少**

大多数同类餐厅，门店面积都往两三百平奔，淘蛙却只开150平左右的店。但人家不是单纯图面积小省租金，而是在小空间里塞进了和大店差不多的餐位数。怎么做到的？首先，在符合消防规范的前提下，把过道压缩到最窄；其次，桌椅该多宽敞还是多宽敞，顾客坐着不憋屈。核心诀窍在厨房——把杀蛙、处理牛蛙的环节全部移出门店，交给中央厨房，门店不需要大块储存区和操作台，厨房缩小，用餐区自然就大了。另外，店里的冰箱数量严格控制，能少摆一台是一台，餐厨空间就这么省出来了。

**二、中央厨房集中处理，电费、人工双双大降**

淘蛙的门店密集扎堆广东，这给中央厨房的集中配送创造了绝佳条件。现在能做到一天两次配送，中央厨房凌晨开工，现杀牛蛙、油炸之后再送往各家门店。凌晨是用电低谷，电费算下来只有两毛钱，要是在门店厨房自己炸，电费得一块钱。这一下，单店月电费就能从一万元摊薄到四千元以内。人工方面更是惊人：一个中央厨房配10个杀蛙工，就能覆盖100家门店；要按老模式，100家店得养100个杀蛙工。省下的人工成本，还能拿出来给中央厨房的工人提工资，总体成本却大幅下降。

**三、门店用人，学萨莉亚的灵活打法**

淘蛙的门店人工成本只占营收的12%，这在餐饮圈相当能打。他们研究过萨莉亚的用工结构，如今大量采用钟点工——忙的时候把人叫来，闲的时候就不排班，而且钟点工不需要提供宿舍，房租成本也一并省掉。用人模式一变，固定开支自然被摊平。

**四、所有环节都是“连环套”**

你会发现，淘蛙的降本逻辑不是孤立的：中央厨房集中杀蛙，才让门店厨房能缩小；厨房缩小，餐位数才能追平大店；门店面积变小，租金才能降；密集开店，又让中央厨房的高效配送成为可能。每一步都咬合得很紧。

说白了，淘蛙的营业额没有翻天覆地的变化，但租金、电费、人工、厨房成本全被压了下来，利润自然就往上走。在行业利润整体下行的时候，这种“抠”出来的增长，确实值得回味。
