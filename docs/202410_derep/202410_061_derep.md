# ('我是如何做自己的时间管理体系、让工作效率能维持在挺不错的状态', (2, 32))

效率，大概是每个既搞项目又搞副业的人，绕不过去的一道坎。总感觉时间不够用，事情永远做不完。

但有人偏偏不靠延长工时来硬扛。他每天给自己安排的工作时长只有5~6个小时，一年下来却还能保持将近七位数的收入。这个结果，很难归因于运气或天赋——他自己总结了一套时间管理的方法论，而且整套方法不是拍脑袋的想法，而是每天都在实践、反复验证过的执行方式。

更关键的是，他不是只讲大道理，而是把执行细节都整理成了可参考的内容。这套分享在圈子里反响也不错，连龙哥都直接评价他是“时间管理教练”。可见这方法论不是空谈，而是能真正落地、支撑起高效产出的实操体系。

如果你也是身上同时扛着项目、副业，或者正在创业的人，那我强烈建议你去看一看他的飞书好读版。里面记录的，就是他如何用有限的工作时间，撬动持续稳定的高产出。

也许你看完后会发现：效率的核心，真不是把自己逼到极限，而是建一套能长期运转的系统，让自己在关键的事情上持续发力。
