# ('全网最全搜索技巧汇总', (2, 12))

上个月参加了一期AI写作实战营，过程中有个很深的体会：想让AI生成高质量内容，最直接有效的办法，就是先找到足够优质的文章“喂”给它。但我自己搜索时经常翻半天都找不到合适的内容，要么结果不相关，要么满屏广告，效率特别低。

后来灵光一闪，想起以前看过不少搜索相关的技巧，要是能用上，说不定能精准定位到想要的资料。于是我一口气把网上能见到的搜索方法都翻了出来，统一整理成了一份合集。

整理完我就在想，圈子里的朋友可能也有同样的困扰，干脆拿出来共享给大家，希望能帮到有需要的人。

其实不只是AI写作，几乎任何项目都离不开搜索。学会用正确的检索方式，做事往往能事半功倍。
