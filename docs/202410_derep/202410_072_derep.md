# ('实习志愿者经历：从小红书教育资料航海中收获的成长与经验', (2, 29))

哈喽，我是西里。今天想分享一段让我又哭又笑的经历——作为龙哥盟的实习志愿者，参加小红书教育资料引流航海的全过程。先说个小插曲：我在这个社群的第一次发声是发了一条风向标，后来把那个品放到小红书百货里卖，竟然卖出了400多。这次呢，我又以志愿者身份开启了一个全新的副本。

时间回到2024年：5月我加入了龙哥盟；6月参加了百货航海，顺利跑通MVP，GMV做到500+；到了9月，我第一次挑战教育资料引流的志愿者工作。说真的，刚开始心里完全没底，但等整趟航海结束，我只有一个感受：这个志愿者，当得太值了！

为什么想当志愿者？说白了，就是不想只当个围观群众，想真正下场做点事情。那志愿者平时到底忙啥？主要是维护群秩序、帮船员答疑解惑、同步最新消息这些事。一路实操下来，我掌握了不少社群运营的小技巧——比如怎么用群接龙高效收集信息、怎么群发消息不惹人烦、怎么给船员做备注分类快速记住每个人。这些小动作看着不起眼，用好了效率翻倍。

还要特别感谢电饭煲老师，他分享的笔记制作提效方法让我眼前一亮，原来做笔记也能既省力又高效。另外，“慢即是快”这句话也让我特别有感触，尤其是在统计船员信息的时候，越急着求快越容易出错，反而耐下性子一步步来，才是最快的路。

当然，这一路我也没少踩坑，每一次教训都挺痛的。但正是这些坑，让我对运营、对细节、对责任有了更深的理解。
