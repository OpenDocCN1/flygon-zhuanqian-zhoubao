# 短视频从业者常用的 5 款工具和网站

做短视频的老手，手头总有几个舍不得分享的秘密武器。今天我就把日常用得最多的五样东西掏出来，给同行们做个参考，全都是亲测好用的那种。

先说说去水印这件事。以前找素材最烦的就是满屏的抖音、快手Logo，后来发现了一款叫“悠米视频助手”的工具，简直像开了外挂。它不光能批量解析抖音、西瓜、头条、快手、小红书、B站，连TikTok和YouTube都能搞定。更厉害的是，你可以直接拿它扒主页视频、作者喜欢的内容、整个合集，甚至按关键词搜素材。无论是找选题、搞二创，还是单纯囤素材，都非常顶。收费也很友好，月卡才25块，而且邀请一个人能送三天VIP，配合临时邮箱操作，基本能一直白嫖。这个我给五星推荐。

接下来是免费的大模型聚合平台。以前想用GPT-4、Claude3.5、Gemini这些，要么付费要么折腾，现在有个网站把主流模型全整合在一起了，还能同时调用两个模型做对抗式回答，相当于一个问题拿到两份答案。最妙的是，从Coze平台复制一些现成的提示词过来，配合使用效果直接起飞。这个同样五星，强烈安利。

第三个是配音克隆网站。你只要上传一段音频，它就能把那个人的声音给你“复制”出来，还原度真的绝了。我平时做混剪用得特别多：视频画面不用动，直接把文案重新配音改一遍，前后衔接还特别自然，丝滑到没朋友。想搞点整活儿二创的，这绝对是神器。五星推荐。

第四个呢，是提示词助手。很多人用AI提效卡住，不是AI不行，而是自己根本不知道想要啥，也写不出好用的提示词。这时候别硬想，直接去借用别人已经调好的成熟提示词，按需查找就行。省时省力，效果还好。四星推荐，因为有一定学习门槛。

最后一个是临时邮箱。注册账号不想暴露自己的真实邮箱，或者需要批量操作、做邀请任务、接验证码，用它最省心。这类工具很多，我一般备着几个轮换用。三星推荐，因为场景相对单一。

这五样东西目前是我常用的，如果大家觉得有用，回头我再把其他压箱底的家伙事整理出来，比如破解版剪映、ComfyUI工作流、免费数字人什么的，到时候再聊。
