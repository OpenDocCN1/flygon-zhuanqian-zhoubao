# ('AI 绘画工具 ComfyUI 的进化与应用', (2, 24))

最近刷到龙哥的龙珠悬赏，正巧我平时折腾AI绘画工具不少，干脆借这个机会写点东西。我是行者，在深圳，23年其实已经在赚钱发过两篇AI绘画精华帖了。

很多人跑来问我，说看到有人拿Flux弄真人写真，再配着可灵、海螺这类视频工具，直接就把小红书上的矩阵美女号做起来了，效果炸裂。可一听说要用ComfyUI工作流，立马就打了退堂鼓。

其实真不用怕。ComfyUI这两年进化速度远比大家想象得快。现在早就不只是本地部署那一条路了——你可以直接用哩布、吐司这样的网站在线出图，也能租仙宫云、揽睿这类云端服务器跑，甚至官方也给出了在线出图的方案。玩法越来越多，门槛已经低很多了。

这篇文章我写了五千多字，配图也不少，完整版在飞书里，大概要花15分钟慢慢看。想深入研究的，建议直接点链接过去。
