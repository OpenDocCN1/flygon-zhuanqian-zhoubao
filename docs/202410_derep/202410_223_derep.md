# 抖音越来越难做，如何找到破局点--视频号是新的蓝海吗？

刷抖音做知识付费的朋友，最近是不是普遍有种“使不上劲”的感觉？流量越来越贵，转化越来越难，团队再拼也难换来增长。如果你也陷入了这种疲态，不妨把目光转向视频号——至少在我看来，这可能是当下值得押注的新战场。

我自己做知识博主五年多，全网攒下30多万粉丝，带过两万多位学员，算是个“老兵”了。今年下半年，我们明显感到抖音的瓶颈期来了，于是下定决心转战视频号，没想到还真跑出了一些效果：单场直播卖知识付费课程能做到5万以上。

1. 把视频号平台的底层逻辑和玩法讲透；
2. 怎么设计钩子，让用户最短路径找到你；
3. 在视频号里埋留资点位，让微信号越滚越大；
4. 提升互动率的小方法，让用户愿意跟你互动，就像呼吸一样自然；
5. 视频号付费加热的实操技巧。
