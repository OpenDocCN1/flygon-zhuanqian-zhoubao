# ('抖音航海记：15 天账号收益破万的个人探索与团队支持', (2, 28))

说实话，我从来没想过自己能在这么多牛人汇聚的地方，晒出这么一点小成果。能在生财这个圈子里摸爬滚打，我真的收获太多了，今天总算轮到我来给大伙做点贡献。

我这次参加的是抖音精致达人航海项目。本来只是抱着试试的心态进去，结果没想到，短短15天，账号收益就破了万。这个速度连我自己都有点懵。所以想把这段经历写下来，万一能给正在观望或者刚上船的朋友一点启发，那就值了。写得不够细的地方，大家评论区尽管问，我尽量答。

这里要特别感谢一直陪着我梳理思路、打磨这篇分享的@澄歌 老师。更详细的实操记录，我放在飞书文档里了，感兴趣的朋友可以直接点进去看：项目实操 [链接]

回看这段旅程，评论区里大家的反馈也让我挺触动。有人说，在没人带的情况下能自己起步，已经很厉害了；也有人说，最难得的是我坚持做抖音这么久，终于在这次航海里等来了爆发。其实我心里清楚，哪有什么突然的运气，不过是把一件小事反复做、认真做，再加上这次航海给了我一个推力和方向。另外，时间管理对我来说真的很重要，每天把节奏理顺，才不会手忙脚乱。

还有个信念一直撑着我走了两年——“自媒体是普通人低成本赚大钱的唯一机会”。这句话我信得特别深。正因为相信，才会看见结果。所以如果你也在犹豫，不妨先信一次，然后往前走。说不定下一个破万的，就是你。
