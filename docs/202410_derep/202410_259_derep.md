# ('寻求突破的一个关键是寻找关于未来的一个非共识的机会', (2, 27))

你有没有发现，真正能改变局面的突破，往往不是因为追随主流，而是因为提前看见了那个“大家都还没认同”的未来。

很多后来被证明伟大的构想，在最开始的时候，听起来都像天方夜谭，甚至会被当成笑话。那些最初看不懂的人，会觉得这想法荒唐透顶、毫无逻辑。

如果你做的事，周围所有人都觉得你疯了，那结果通常只有两种：一种是你真的疯了，另一种是——你正在做一件了不起的大事。而真正了不起的事业，从来都不是靠走大家都走的那条路走出来的。

所以，想寻求改变和成长，关键不是挤在共识里找安全感，而是去发现那个关于未来的、少有人看见的机会。
