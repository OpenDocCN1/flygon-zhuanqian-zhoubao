# 9.20 交作业后整理 0919 会员日书单推荐

### 0919会员日书单整理完毕，我挖到了不少宝藏好书

9月20日提交完作业后，我就马不停蹄地开始整理0919会员日的书单推荐。越往后更新，越觉得这趟梳理太值了，不但翻出很多此前没留意到的好书，还有不少书被圈友们反复提及。

关于书目的收录方式，我的做法是这样：凡是能在微信读书里直接搜到的，就同步收进书单；那些搜不到的，则在飞书文档里把电子版补上。

先简单介绍一下飞书文档里的内容，包含两块：
1、微信书单。由于微信读书单个书单最多只能放500本书，所以这次的书单分了不止一份；
2、圈友推荐的全部书籍，做了一份完整的汇总统计。

完整的资料可以直接点开飞书链接查看：
https://ivqd5pmg5of.feishu.cn/docx/JiP3d1ajnoSx7gxq2bsc9xx0n5b?from=from_copylink&reRdXZ=1

不想逐份点开文档的话，直接看这两个微信书单就够用了：

书单二：https://weread.qq.com/misc/booklist/23210632_7UwdqonNi
