# ('躬身入局，中老年知识付费项目复盘：半年投入近 8 万，只转化了 7 个用户', (2, 39))

半年过去，龙哥盟圈友也么哥再一次发帖复盘。上一次，她聊的是小红书女装；这一次，主题换成了“中老年知识付费”，交出来的却是一份很不一样的成绩单。

半年下来，她在这个项目上砸进了大概8万元，换成付费用户却只有7个。她在10月18日的复盘里坦言：项目只是把流程跑通了，离盈利还很远，现在连助理的工资都难以负担。这8万里，有半年的助理薪酬，有产品合作费用，也有场地租金。

按她自己的说法，这次经历没法简单定义成成功或失败，更接近一个新手在全新领域里的真实跋涉。从产品打磨到流量获取，从销售推进到成交转化，每一步几乎都是边学边做，边做边错，期间有不少心酸、决策失误和反复挣扎。她也特别提醒，自己踩中了一个很多圈友都容易掉进去的大坑，希望能给后来者提个醒。

她把完整复盘写进了飞书文档，想看细节的话可以直接打开：https://z1zu4xvq1ns.feishu.cn/docx/MdCedv6XZoNFpLxG2dgckIq5n4b?from=from_copylink

帖子在社群里引发了不少共鸣。龙哥评价说，这是一份很有参考价值的“失败复盘”，成功从来不是一蹴而就，他几乎走过同样的路，也认为赚钱人该为每一次跌倒鼓掌。评论区里，有人感谢她排雷，有人佩服她的勇气，还有人说自己也在关注同一个赛道，想和她交流。更多同样处在迷茫期的圈友则感叹，谁不是一边摸索一边往前走呢。

半年时间、8万投入、7个用户，这个数字确实不算光鲜。但敢于把失败摊开讲，本身就是一种难得的复盘态度。也许下一份答卷，就能真的漂亮起来。
