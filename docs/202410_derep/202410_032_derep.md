# 做了近10年图文自媒体，我总结的公众号爆文心法全在这了

大家好，我是财火。本职是程序员，业余时间搞自媒体。说实话我这个人挺懒的，要不是@澄歌 一直在背后推我，估计这篇文章还得再拖一阵子。

时间过得真快，9月航海结束已经一个月了。这个公众号爆文项目我到现在还在跑，成绩算是稳住了。当时航海途中被志愿者拉去做了一次分享，今天把核心内容整理出来，希望能给正在做或者准备做的圈友一点参考。

我大概从2015年就开始碰图文自媒体了，说句不谦虚的话，算是国内最早吃这碗饭的那批人。头条、百家、大鱼、企鹅、趣头条、搜狗号、网易……这些平台我基本上都玩过。现在回过头看公众号爆文这件事，其实骨子里和当年的头条号逻辑没什么区别。

下面我从三个方面聊聊我的理解和判断。

## 一、回看这些年，图文自媒体到底是怎么走过来的

我完整经历了图文自媒体从萌芽、野蛮生长到洗牌降温的全过程。

2015年，头条号刚推出那会儿，入场的人屈指可数，平台给钱也爽快——1万阅读就能拿100块。你再看看现在，头条号1万阅读的原创首发收益大概也就10到20块，非原创那就更惨了。那时候平台规则也松，内容越猎奇越容易爆。我记得有账号天天发外星人、UFO之类的奇闻，几乎发一篇爆一篇，收益直接起飞。

到了2016年，风向就变了。大鱼号、企鹅号、百家号这些大平台开始疯狂抢作者，单价一家比一家高。后面连惠头条、搜狗号、趣头条这些体量小一些的平台也冒出来抢人，最离谱的是优信二手车也搞了个创作者平台。

平台多了，竞争自然就卷起来了。为了留住好作者，各家纷纷上线首发、独家这些功能——只要你愿意把内容独家发给我，收益直接翻倍。企鹅号甚至搞签独家作者协议。另外，各家的创作者榜单也是变着花样发钱。对了，百度百科当时还弄了个“百科他说”，主动邀请垂直领域的头部作者入驻，直接给3000块一个月的保底。

那阵子对图文作者来说，说是天上掉钱也不夸张。你就写一篇文章，往所有平台各发一遍，一份内容吃遍天，一个号在所有平台的收入加起来，一个月跑过10万真不是梦。要是你百家号上了榜，最少又是5000到手（上限能到2万）；大鱼、企鹅那边上了榜单也一样有月奖。

当然，野蛮生长总有乱象。当时抄袭、洗稿满天飞，各家平台才开始陆续上线原创保护和维权功能。我印象中那时候一个叫“维权骑士”的工具特别火，专门帮作者打击搬运。后来龙哥老大跟我说，那个维权平台其实就是他们做的——这倒是没想到，哈哈。

这段路走下来，其实能看清一个规律：平台砸钱、作者进场、收益高位、内容稀释、监管收紧、红利消退——几乎是每个平台的必经剧本。

## 二、做公众号爆文，真正该有的心态和打法

回头再看现在的公众号爆文项目，本质上就是当年那套逻辑换了个场地重演。但很多新人最容易犯的错，就是拿“打工思维”来做内容，希望今天发、明天就见效，一旦没水花就焦虑放弃。

我做这个项目最大的一个感受是：收益波动特别大，心态不好的人根本撑不住。

我自己的账号就是这样，好的时候一天能有4169块进账，差的时候第二天就只有11块。你要是盯着这几千和这11块的落差去看，心态早就崩了。但如果你站在一个月、甚至三个月的周期去看，整体趋势是在往上走的，那就够了。

至于变现路径，目前公众号爆文项目主要就是三条：带货赚佣金、小说分销、流量主广告分成。最近还看到有圈友在搞短剧分销，说是正处在红利期，也是一个值得留意的方向。

所以我的建议是：**别把单日收益当回事，要把持久输出当回事。** 数据有起伏很正常，关键是你要不要长期做下去。这个项目就是一道持续题，不是一次性爆发题。

## 三、接下来公众号这个赛道会怎么走

站在我这个“老图文人”的角度，聊聊对公众号爆文未来的一点判断。

很多平台当年趟过的路，公众号大概率也会再走一遍。现在买量成本越来越高，平台的流量分配逻辑越来越精细化，纯粹靠搬运、洗稿的垃圾内容被发现和限流的概率只会越来越大。平台真正缺的，永远是能把人留下来的好内容，而不是来薅一把就走的人。

所以未来能在公众号这个盘子里继续吃肉的，一定是那些**把内容质量当底线、把精细化运营当习惯**的人。如果你只想着去撞大运，动不动就断更，只想短期捞一波——那你大概率不会是这个项目的赢家。

反过来看，正因为还是有不少人忍受不了这种收益波动、做不到日更不辍，留下来的人反而更有机会。这个项目做了这么久，我最大的心得体会其实就是一句话：**比别人多扛一天，你就多赢一点。**

希望每个圈友都能在公众号爆文这条路上，拿到自己想要的结果。
