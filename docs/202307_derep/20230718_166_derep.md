# ('普通人如何通过拆解大量同行找到适合自己的项目', (2, 24))

我是梨云。这期想和大家聊一个很实在的话题：普通人怎么找到适合自己的赚钱项目？我的答案很粗暴：别瞎琢磨，去拆同行。

小红书这几年跟一座金矿没什么区别，无数人抄着铲子就进场了。但金子不会全摆在地上，很多都要下功夫去挖，否则你也不会看到那么多博主，悄无声息地就把钱赚了。龙哥的风向标栏目我挺喜欢，它用共创的形式，让每个人把自己淘到的小金矿都拿出来晒一晒。受到这种氛围的刺激，我忍不住想：要是能有一套方法，把更多金子批量探测出来再挖走，普通人挑项目是不是就轻松多了？

后来拆了几百条中标笔记，我发现一个共性：真正能爆的内容，都会精准勾起用户的欲望，再由博主用评论互动完成营销闭环。换句话说，需求强的笔记，评论区往往会出现特定话术。所以，想挖到更多项目，本质上就是去拆大量同行的营销内容，分析他们背后的动作。更细的挖掘思路，亦仁大佬那篇文章已经写得很明白，这里就不展开了。

按这套思路，我积攒了不少有意思的产品和服务库。但最要紧的不是词库本身，而是怎么通过大量拆解，找到适合自己的项目。最好的老师往往不在书上，而在同行里：拆得多了，眼界自然打开；跟着模仿，弯路也就少走很多。分析过程中，不断衡量流程和成本，才能判断一个项目到底适不适合自己。

我随手拿“笔芯”举个例子。![](img/8416e5637ae1c1eb808d16de376ddf9f.png)

打开小红书搜这个词，点“商品”，再按“销量”排序，先确认需求。几千上万，说明这个品不缺买家。看完需求，还要看收益。我们是无货源玩法，所以下一步去拼多多或1688查进货价。小红书卖56，拼多多拿货34，1万销量粗略一算就是22万利润。要是开个会员，或者直接跟店家谈合作，利润还能再往上抬。所以，这个品从收益角度看，完全值得入局。![](img/f08d6237d2dbb3702bd5a458731d059e.png)![](img/7628528817eb6fccc8b25c1a2b0eb01e.png)![](img/ac53529cc325bda50a1cb42bd2395354.png)

接着去看店铺是怎么发笔记的，判断要花多少时间和精力，难度到底大不大。点进去发现，名字旁边有个蓝标，说明是企业号，背后对应几百块认证费和资质要求。企业号的隐藏好处是，抽奖可以名正言顺地搞，平台还鼓励；换成素人号搞抽奖，笔记很容易被限流下架，因为平台一眼就能看穿你在引流。

再看笔记制作，门槛真不高：拍几张照就行。但细节藏在摆拍里，角度要舒服，背景要干净。要是觉得拍摄太费劲，那就果断走上“搬运”路线。![](img/9cf4e29c221efb039e6fe1f45bc7c902.png)![](img/329e6d474a45a48e775b26bd3a13fe6f.png)![](img/3a20e587c941b749bbdd3ff01ee8d8f7.png)

如果对标这个企业号，成本确实有点高，那也没关系。同一个品类，换个款式卖，再去找素人号店铺。顺藤摸瓜，还能从别人店里挖出更多爆品。![](img/e68381fa60a828c87120796892b2cdda.png)![](img/005f19ad9235959c5c1fe007c1218a91.png)![](img/d918ba3f16ed5d23c50cc4e7734c777c.png)![](img/d6521b0a9db8cfa6a4745f5f368357e0.png)

比如这个素人号，店铺成本就低太多了。再看看笔记成本：1300多条笔记，时间跨度长达一年半。本来想用灰豚数据偷个懒，结果数据不全，哪有一开始就5000粉丝的？![](img/685750b4cd94b75ba3ac5ec4226dd734.png)
没办法，梨云只能手动把1300条从头翻到尾，翻完只感叹一句：这工程量，真服了！![](img/a4be369f7e4118777118da7c3a51d433.png)![](img/47ef0222f137f6e10153e0ab276a184d.png)![](img/a28a633a31232c28f2b7603eabd5ed3b.png)![](img/97d68ea96d9d215dc44c156998a3ba45.png)![](img/a8b82c1f4faaa88509897970c1ff3994.png)

然后看视频怎么做的。画面很简单：旁边放一堆笔，博主拿笔写字，写的内容就是笔的卖点。制作方式有两种：要么伪原创，照同款的布置自己来，自己拿笔写，门槛是字要拿得出手，再加上基础拍摄剪辑；要么直接搬运，找同行的视频混剪、去重。

顺着这个思路，我又跑去抖音搜这个品类，发现一件有意思的事：销量照样爆炸，随手找个账号，人家一直发，近期也没停，而且内容形式和小红书那篇几乎一模一样。可能因为市场大、竞争也激烈，这个博主只带出了300多只。但这也反复验证了一个老观点：抖音跑通的项目，完全可以在小红书上再做一遍。

既然如此，我们是不是也可以按这个套路，先攒一个抖音1000个产品词库，再丢到小红书里挨个检索，专门去挖那些不为人知、却真实在赚钱的项目？这个玩法，大家完全可以亲自试试。![](img/c235a197c398eb36c6d0f9ed0dec536d.png)![](img/a224e33ab9d55dfbedcad325693545d7.png)

以上就是我的一点简单分享，希望能给你带来启发。![](img/894d30a529e7c37bcd3392323c99941c.png)
