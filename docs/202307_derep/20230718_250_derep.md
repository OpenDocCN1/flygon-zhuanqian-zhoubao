# ('新人入局小红书店铺 GMV9W+ 的经验分享', (2, 24))

新手做小红书店铺，50多天卖了9万多，利润5万多，我的真实经历分享

如果你最近也在关注小红书电商，想找个靠谱的副业路子，那今天这篇分享值得认真看看。

我是大树，今年4月初开始入场，起因是看到圈子里不少朋友都在做小红书店铺，而且成绩都不错。我当时就想着不能再观望了，直接翻出赚钱有术2月份的小红书店铺航海手册，照着里面说的方法下场干了。

从4月11号发布第一条商品笔记开始，第二天就出了第一单，19块9。虽然金额不大，但那种“原来真的能卖出去”的确认感，给了我很大的信心。到6月6号，50多天时间，累计GMV冲到9.4万多，纯利润大概5万多。![](img/942c91c5c802da88c741a5898d142dbe.png)

更让我兴奋的是第7天——一篇笔记直接把当日GMV干到了13679.7元。![](img/987c89c5fc63ce678a146b950afc07d8.png)

到了5月份，我继续深耕同一个单品，基本每天都能稳定出单，日均GMV保持在1000以上。![](img/883d323485a8f3795c35b1b5fa5341ac.png)

很多人可能会觉得，能出爆款是不是运气好？其实不是。我想先说一个心态上的问题：不是每篇笔记发出去都能爆，但只要你一直发，持续发，哪怕只有一篇突然被系统推上热门，它就能为你带来很长一段时间的稳定出单。所以，坚持这个事，比什么技巧都重要。

我自己也是从小白走过来的，太清楚新手最焦虑什么了——无非就是选品不知道从哪下手、笔记发了没人看、单量提不上来。

那我具体是怎么做的？分几块和大家说。

先说选品。

开通店铺之后，第一步不是急着上架，而是先确定你要做的商品类目和方向。怎么判断什么品类值得做？有个很笨但很有效的方法：去看主流电商平台的销量榜，如果某个商品在多个分类榜单里反复出现、排名靠前，那它基本就是当下的爆款，直接可以作为小红书的选品参考。这个方法在淘宝、1688、抖店同样适用。

类目定下来之后，再去小红书搜索你这个领域的关键词，找到那些销量比较高的商品，然后顺着商品找到对应的账号，把它们作为你学习和模仿的对标对象。

接着说笔记流量。

经常有新手问我：是不是要先发一些普通笔记养号，再发商品笔记？我的建议是：每篇都发商品笔记。因为做小红书电商的最终目的就是卖货变现，能快速跑通才是关键。![](img/70ffde38acf485801df680a21109f0ba.png)

平台的态度其实也很明确——从官方通知就能看出来，小红书非常鼓励大家持续发布优质的商品笔记。你发商品笔记、参加官方活动、添加热门活动标签，平台都会给额外流量奖励。![](img/87e405dc4d745b63b89c088d7726431c.png)

开通店铺之后，新手任务别忘了做。根据官方指引完成任务，能拿到薯条券，用薯条券去投放薯条，能获得更高的曝光。入口在小红书【商家版后台】-【消息】-【成长】。![](img/2f544092e68a1432fa91df4b44ee6606.png) ![](img/1161c86ae591346f03543b50eb4092e3.png) ![](img/2697bef828f37bb267c9c1aba804ddff.png) ![](img/d9c5065a7bfc6e530239680f2c99105a.png)

还有，小红书官方在不同时期都会推出促销活动。![](img/3cd81b717743eccad1ed6d78007720f2.png) ![](img/b04724693793825e603f0e9bb491c096.png) ![](img/2c93e07317601e3578d2d5db225f498e.png) 跟着官方活动发相关商品笔记，能有效增加曝光，最终带动销售额。类似的还有数码大玩家、手作翻车现场这些，官方会定期私信推送活动通知，平时记得多留意消息。![](img/134c22d4c75366ca2a6647a974d4ef80.png) ![](img/c0b530d61593e6b3db3981093c162fa0.png)

另外一个很容易被忽略的流量入口是“笔记灵感”。路径：【我】-【三】-【创作中心】-【笔记灵感】。![](img/aa2cff053c859168897721664a346603.png) 选择和自己账号内容相关的标签去发布笔记，同样能获得额外流量奖励。持续使用笔记灵感发笔记，还有机会瓜分流量券，上榜创作者榜单的话更有额外奖励。所以还是那句话，持续发优质内容，争取平台流量扶持，能让你的账号事半功倍。![](img/edb5663555585900944f704d9a80f40a.png)

当曝光上来了，配合适当的评论区引导，订单自然涨得快。不过有个细节：引导性评论建议用小号操作，别用主号。![](img/4935a67184a580aaeee52909e9c71d34.png) ![](img/ccc2ba18b67e537e553bf2a58e714969.png) ![](img/2246bff96ffef2d38bc12d20e634be51.png)

热搜词也是一个重要的工具。

小红书会根据搜索热度和内容缺口，不定期公布热搜词。![](img/8129886632f86461dea0c77cf2f2b1d6.png) 发笔记之前先看一下这些热搜词，挑和你的笔记内容有关联的，植入到封面、视频、标题、正文和话题里。

之前航海手册里也讲过怎么更系统地用热搜词，核心两条：第一，之前发过的商品笔记里，如果有数据表现好的，选几个合适的热搜词重新植入；第二，30天内的普通笔记，如果匹配到热搜词，可以编辑后重新挂上商品。![](img/0f5f15699344f6ced9c82112c86b3951.png) ![](img/0b88ee8adfff22ccec86a2f544f948dc.png) ![](img/7e7bd0a8dc3312a20a3aa1a167c73fec.png)

最后说说到店流量如何分析优化。

通过笔记的基础数据、观看趋势和笔记诊断，能看出问题所在。![](img/6a12b7a8ee71284afd6dd746f0261f60.png) ![](img/b92f513e3c6e41f6881ad99c673db94b.png)

互动量不高？就用本号或小号发引导性评论，带动用户参与讨论。![](img/0eba893e8e1c155aed3e69abe3ee2b77.png)

点击率不高？封面不够抓人，换一个更有吸引力的试试。

观众流失严重？看观众从第几秒退出，针对性优化内容结构。![](img/cb29db36f5bc205e2c1ca19b5c29aeea.png) ![](img/2f4ebcccbaa47d60a0db2308225f940c.png)

观众画像也很重要。比如我有一篇笔记，粉丝画像显示女性占比94%，25-34岁是主力，兴趣集中在娱乐、影视、美食、时尚。那你在选品测品的时候就应该往这个人群靠拢——宝妈用的母婴用品、儿童玩具，就是很明显的方向。

最后用三句话总结一下：想要在小红书稳定出单，就是1、选对品，2、发好笔记，3、坚持大量发笔记。

感谢赚钱伙伴们的观看。希望在船上的各位，都能借小红书电商这波趋势拿到自己想要的收益，一起把这个红利期项目打深打透！
