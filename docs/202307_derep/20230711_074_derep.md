一、基础概念速览
以太坊 ETH：以太币的代号，以太坊网络的原生资产，可在交易所交易，也用于支付 Gas 及算力费用。
Gas Fee：燃料费，转账、铸造 NFT 等链上行为需付给验证者的手续费。
以太坊二层 L2：Layer2。主网吞吐约 15 TPS，拥堵时费用飙升，单笔动辄数百至上千美金。L2 用于扩容，降低成本、加速确认。主流有 Optimism、Arbitrum、zkSync、StarkWare 等，目前 OP、ARB 已发币，后两者未发币，所以交互时我更看好后两者的预期。
加密钱包：Web3 的身份凭证，资产托管其中。常用 MetaMask 小狐狸、OKX 钱包、Starknet 生态的 Braavos 头盔钱包、Argent X 人字拖钱包。
TX / TXS：项目交易笔数。
撸空投：又称薅羊毛。项目方为推广生态会预留激励预算。类比 Web2 的广告投放，Web3 的空投就是把广告费直接给用户。逻辑链条：优质项目→积累用户→活跃度和交互量提升→更易融资→融资后向早期活跃用户空投→用户进一步增长→正向飞轮。最终项目数据好看、投资人拿一级筹码、用户拿空投。

先把名词捋顺，避免知识诅咒。后续遇到陌生术语可回头查，或直接在群内提问。

二、为何从 L2 数据切入
当下无论老手新手都在做撸毛，zkSync 与 Starknet 是本轮牛市前以低成本获取一级筹码的主线之一，也是我目前的重仓方向。

配合网络清单：https://chainlist.org/

可直观对比 L2 与以太坊主网的交易量、月活、官网、社媒、技术路线等。

可清晰看到各链活跃用户与交易量，从而判断热度。可把已发币二层与未发币二层做对比。比如 SUI 曾号称 130 亿 FDV，5 月 28 日日活仅 333，未带“K”。也能侧面反映当前公链的接受度。
![](img/dbc8a3db44459c136af74b3b29d4d8fe.png)IP 质量检测：https://whoer.net/zh#
IP 是否需要配置业内无共识。OP、ARB 已发币，未强制查 IP。稳妥派主张配置，务实派觉得不必。若只做两个已发币二层，号数 3-5 个，可用 Chrome 多开：右上角菜单→其他个人资料→添加。不同地区 IP 可直接多开，无需指纹浏览器。篇幅有限不展开。
取消授权：https://revoke.cash/zh
