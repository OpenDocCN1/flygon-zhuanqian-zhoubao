# 把个人 IP 当客户池来运营，普通人也能起号变现



## 用经营客户的思路做素人 IP，你也能做到

作者： 小女巫忻忻 
日期：2023-07-14 

《入行半年营收翻六倍，从0到1跑通个人IP变现》

刚踏进销售这行的人，脑子里几乎都会冒出这三句话：
没有人脉能带来单子吗？
不会谈、没经验，还能有业绩吗？
为什么别人的客户主动来问产品，我介绍完客户就冷了？

其实把销售换成做素人 IP，困境几乎一模一样。起号初期最缺的就是三样东西：来的人、会成交的方法、让人信服的份量感。没有流量等同于没有客户，没有话术等同于没有成交思路，没有信任等同于没有势能。

我自己就是干了16年金融的老兵，既在一线做过销售，也做了十多年销售教练。靠个人IP从零起步，第一次就拿到六位数的收入后，我越来越确信一件事：不做销售也得会销售的打法。

起步时我试过好几个低价产品，最便宜的几十块钱一个，也没赚到什么钱，却把自己忙得筋疲力尽。后来把多年的销售经验沉淀成一套可复用的五步打法去复盘优化个人IP的运营路径，仅仅半年，收入直接翻了6倍，6个月净利润就到10万。

这套打法拆开就是：
先聚人，再立信，后懂货，再谈钱，最后敢收。也就是积累客户、赢得信任、研究产品、探讨预算、勇敢成交。
