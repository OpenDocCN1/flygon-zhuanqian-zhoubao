# ('有限合伙不分钱就不用交税？', (2, 15))

最近有不少朋友刷到短视频后跑来问我：用有限合伙当股东，钱不分配到个人账户，是不是就不用交税了？今天专门写一篇，把这个问题讲透。

先直接说结论：这种想法大错特错。

很多人理解的“先分后税”，以为意思是“钱到手才算我的，到手才交税”。但实际根本不是这样。依据财税〔2008〕159号文件第三条，合伙企业生产经营所得和其他所得，按“先分后税”原则处理。关键就在这里——这里说的“所得”，不仅包括已经分给合伙人的钱，还包括企业当年留在账上的利润。

换句话说，只要有限合伙企业账上有了留存利润，哪怕一分钱没往合伙人个人卡里转，合伙人也要按约定比例先“分”出属于自己的部分，再按自己的税率去申报纳税。“先分”不等于“先拿钱”，税义务不会因为你不分红就消失。

举个例子你就明白了：

自然人小帅持有有限合伙企业A 40%的份额。A投资了有限公司B，今年B给A分红100万，这笔钱全部躺在A的公账上，没有打入小帅的私人银行卡。要不要交税？

答案是：要。

怎么算？

第一步，先分：小帅占40%，对应40万属于他。

第二步，后税：小帅是自然人，按20%税率，40万×20%=8万，必须申报缴纳。

所以，哪怕钱一直留在合伙企业的银行账户里，只要利润已经形成，该交的税就跑不掉。别再被“不分红就不交税”的说法带偏了。
