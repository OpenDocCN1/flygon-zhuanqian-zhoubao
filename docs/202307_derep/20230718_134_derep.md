# 通过几个赚钱思维，在闲鱼电商找到人生新航向，月入 3W

曾被抑郁和暴力的关系拖进谷底，我用几个赚钱思维在闲鱼电商翻身，月入3万

各位赚钱圈的朋友，我是小雨，一个仍在这条路上学习的新人。你大概想不到，我曾在抑郁的泥潭里苦苦挣扎，也遇见过一个可怕的人。而今天，我靠着闲鱼电商，一点点把自己捞了上来，不但走出了黑暗，每月还能稳定入账3万块。这篇东西，就是想把我的经历和可复制的路径都告诉你，给迷茫中的你一点参考。

三年疫情落下帷幕，电商行业重新火热起来。从4年前开始，我在闲鱼上尝试卖货，期间踩过坑、走错过方向，靠着不断复盘才慢慢上路。回头看，真正让我翻身的不是某个操作神技，而是几条重要的“赚钱思维”——它们教我如何看待需求、如何选择赛道，也让我在人生最低处，找到了一条值得扎下根走的路。

关于新手从0到1做闲鱼的完整落地步骤，我一口气都整理了出来，每个环节都能跟着做。因为篇幅不短，就放在了飞书文档，想实操的朋友直接点链接阅读：
