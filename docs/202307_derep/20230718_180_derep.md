# 心态放平，电商小白也能在航海收官周做到3000+

> 原文：[`www.yuque.com/for_lazy/thfiu8/vinwggg9x1x9bg0t`](https://www.yuque.com/for_lazy/thfiu8/vinwggg9x1x9bg0t)

各位伙伴大家好，我是前行。2023年3月18日才入圈的赚钱新人，此前副业完全空白。是赚钱打开了我的认知，让我看到原来除了工资之外，赚钱的路径和玩法远比想象中多，而且很多赛道的上限对我这个阶段来说非常值得深耕。

要特别感谢朋友当时分享的赚钱66个赚钱项目合集，正是这份清单让我真正踏入赚钱，也陆续拿到了人生的第一笔副业收入、第一百块、第一千块……一步步走来。

今天主要复盘一下从5月份开始试水的第一个副业——小红书店铺项目。对我而言意义很不一样，是真正意义上的从零起步。

截至2023年7月10日，我前后试运营过5家店铺。前三家切的是饰品、防晒和玩具类目，基本没什么起色。转折点从第四家开始，我把方向锁定在食品赛道，终于有了可验证的小成绩。但问题依然不少，目前基本只验证了从0到1的通路，从1到1.5的规模化方法还在探索。

比较有代表性的是后面两家店，都在上线的第一周就实现了3000+的成交，随后便遇到了限流。这次复盘的初衷，一方面是想给还在0到1阶段卡着的圈友一点信心，另一方面也是给自己做一次冷静回顾。
