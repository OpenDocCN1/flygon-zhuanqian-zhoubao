# 刷风向标挖到金矿，5天赚了2000块

龙哥说过，风向标赚到钱了记得来报个喜。今天就来交作业，聊聊我从风向标里扒出来的一个项目——抖音今日话题玩法。

先简单自我介绍：我是宝哥，现居安徽，一个执行力拉满的退伍小伙。在龙哥盟潜水整整三年，上周一口气写了两篇帖子，没想到全被评成了精华帖，兴奋了好几天。

前几天晚上闲着没事刷风向标，正好看到有圈友分享【抖音今日话题玩法】的帖子，点进去一研究，立马就感觉是个机会。没项目的人，真的可以从风向标里挖到宝贝；已经有项目的人，也能在这里撞见新的灵感和突破口。
