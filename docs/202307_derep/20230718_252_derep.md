# 我眼中的 Web3：别急着梭哈，先找到那点确定性

船员们好，我是 Start | 9527。

2021 年，我在生财有术私董会从温虾米那里第一次听到 Web3，后来又靠着焦波大哥引路，进了稳赢加密湾，才算是真正迈进了这个圈子。现在回头看，正因为入场的起点选得对，我才能在这个暗流涌动的赛道里一直活到今天，没有被洗出局。

这些年慢慢有了些积累，我也开始想做点带新人的事，比如出书、开新手训练营。同时我也很清楚，自己还没有完整走过一轮牛熊，需要继续沉淀的东西还有很多。

早年我没少被 FOMO 折磨，怕错过、怕掉队。后来总算找到了自己的位置：进入 Web3 职场。以职业身份参与进去，比单纯拿钱去投资，更能摸到这条赛道的脉。之后我做过 Flow 中国大使，也担任过某动漫 NFT 项目的大使，每天周旋在项目方、投资人和普通散户之间，那种利益纠缠的关系，只有身在其中才品得出味道。

这个行业给我的最深感受是：任何一个新领域，都会有一个位置和你的能力精准咬合。我擅长运营，也有点演讲和文字整理的底子，加上以前做书店和读书会时攒下的出版社资源，于是我顺理成章去帮行业里的大佬出书。这件事我已经做成，以后还会接着做。目前，我在生财有术担任了三期 Web3 教练，也会不定期输出相关内容，同时还建了自己的 Web3Going 新手实战营，收了 120 位学员。未来嘛，想找个舒服的港湾继续发光发热。

在我的认知里，Web3 大概是最能演绎“0 成本博万倍”的舞台，遍地都是造富故事的引子。但先别急着上头，真正该问的是：机会摆在面前，你抓住了吗？就算抓住了，你赚钱了吗？

我一直不是个爱抠概念的人。直到今天，我都没把比特币白皮书完整读完，但这并不妨碍我被这个赛道的财富效应和两年来的真实结果说服。比起那些花里胡哨的理论外壳，我更愿意相信实打实的利益。

不过有一个知识点还是值得弄清楚：Web3.0 延续的是 Web1.0、Web2.0 的脉络；而 Web3 延续的是比特币和区块链的脉络。把它叫成 Btc3 反而更好理解——它要解决的是，在区块链的范畴里真正实现“可读、可写、可拥有”。

Web3 最先解决的是金融权益。从当年 2 万枚比特币只换了一个披萨开始，数字货币就有了真实的资产价值；后来 DeFi 带着去中心化金融向传统金融发起一轮又一轮挑战，虽然一直四面受敌，但里面依然藏着不少优质项目和大量资产。

就拿刚完成发售的徐工 NFT 来说，市场整体表现不算亮眼，但它居然给持有者提供了买挖掘机打 6 折的权益。这种玩法恰恰说明，NFT 可以把数字资产具象化，这是很值得关注的探索。类似的探索还延伸到身份认同、游戏内角色的唯一性，甚至李宁、绿地这些品牌，以及知名投资人朱啸虎，都入手了无聊猿 NFT，顺便也成了一波品牌营销事件。

DAO 同样如此。疫情里的分布式办公，已经让人对去中心化协作有了初步体感；而 DAO 独特的那套 Web3 激励机制，可以把参与者的协作热情拉满。艺术品资产化这类方向，也正在被反复尝试。

说到底，这一连串探索，都没有脱离中本聪当年对比特币的设定：去中心化、唯一性、可确权。只是 Web3 现在还太年轻，许多理念都只能算雏形，所以才显得难以捉摸。但单看财富效应，它已经足够吸睛。

当然，Web3 此刻的本质依然是趋利的，这也是绝大多数人进来的理由。一旦涉及金融属性，就免不了博弈；有博弈，就必然有输赢和亏赚。可惜现实是，大多数人抱着赚钱的预期入场，最后却成了亏钱的那个。

因为这个游戏自始至终都是多数人大概率亏损的局。所以真正重要的，不是拿自己的血汗钱去赌，而是学会在不确定性里寻找有确定性的收益点。

我的建议是：下场方式很多，但先把成本控制住，用低风险的方式起步。尤其是新人，别一上来就梭哈。那该怎么培养自己的判断力？离不开对 Web3 生态的“盘感”——这是你真正经历过、有了自己的投资原则之后，才会长在身上的东西。学着想投资人一样看行业，收益感可能会更好。

可盘感这东西，恰恰最难速成。无论你拿着 20 年前的互联网做对照，还是从比特币诞生至今的牛熊周期找规律，甚至把人类几千年的文明史翻个遍，都未必能精准预判下一个机会在哪。更务实的做法，是亲自下水去折腾：混 Discord 社区，看 Twitter 发文，听 Space，读白皮书，拆经济模型，搞懂钱包助记词，参与项目交互，把所有操作流程跑一遍。

整个过程里，小成本试错是完全可行的。你只有真的进来感受过，才有资格说它到底是庞氏骗局还是财富机会。如果连门都没进，张口就骂这个赛道是骗局、那个项目是垃圾，这样的判断是不负责任的。

当你在这个行业拿到了第一个反馈，不管赚了还是亏了，这才算真正踏进了大门。紧接着，你就会被铺天盖地的信息淹没，真正的焦虑也才就此开场。
