# RVC 开源变音神器上手全记录，自由度拉满的玩法我整理好了



## 刚入坑 RVC 这款开源变声工具，我就被它的可玩性深深吸引了

大家好，我是 Lan。

前阵子在 B 站上刷到一条变声演示，效果直接把我惊到了。顺着找去看了原 UP 的相关视频，自己折腾了好几天，越玩越上头。操控空间真的很大，于是把心得整理成这篇分享，希望对想入坑的朋友有帮助。

目前能想到的应用场景就不少了，比如直播带货配音、视频解说换声、有声书制作等等，肯定还有更多玩法，欢迎大家一起补充。

这篇内容主要涵盖了三块：

一、RVC 实时变音的实操方法，整合包里直接自带了三个可用的声线模型
二、基于整合包的模型训练流程，步骤很简便，对电脑硬件也没太高要求
三、如何用整合包给已有音频做批量转换

文中使用到的整合包我已经打包好放在百度网盘里了，直接拿去用就行。
