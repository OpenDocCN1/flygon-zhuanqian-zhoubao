# ('餐饮圈新生 100 万韭菜', (2, 15))

今年一季度，餐饮赛道涌入的新面孔，数据面上看突破了百万量级。剔除老手扩张的部分，剩下的大多数，是压根没摸过锅铲的小白。

为什么扎堆往这儿冲？无非是觉得“民以食为天”，开馆子总不至于亏。但真相是，这行当既磨人又薄利，而且暗处蹲着不少磨刀霍霍的“收割者”。你以为是来掘金，其实是来送人头的。

有个西南城市特别典型，网红扎堆，镰刀也扎堆。怎么割？套路其实老掉牙，不外乎制造信息差，让圈外人看得眼花缭乱。

第一招，堆砌网红元素。摆盘弄得精致些，加几个打卡位，拍照发小红书，立马就“爆款”了。那些爱探店拍照的姑娘们，不知不觉就成了免费的“气氛组”。

第二招，拉明星站台。挂个“明星合伙人”的名头，给点干股，瞬间显得根正苗红，信任感拉满。

第三招，发起价格攻势。五折是起步，三折也不心疼。总店能连着两三年都摆出排队的盛况——一半是来拍照的，一半是揣着折扣券薅羊毛的。至于回头客？那是什么东西，能当饭吃吗？

自媒体也不明就里，谁家排队就冲谁家拍，跟着镰刀一起蹭流量，好不热闹。

新来的加盟商呢？站在总部门口看三天，天天人山人海，脑子一热，合同一签，百万加盟费就交出去了。当年那些红透半边天的品牌，如今一家接一家关门歇业，尸骨还热乎着呢，新一波韭菜又前赴后继地补上来了。这记性，是真的不长。

平时买个三百五百的东西，都得上网比半天价；偏偏到了签上百万加盟合同的时候，连尽调都懒得做，眼睛一闭就转账。真是讽刺。

评论区有位老兄说得好：加盟的底层密码，就是总店的排场。有些开在顶级商圈的总店，压根没打算靠单店赚钱，人家打的是品牌样板，钓的是后来的大鳄。

还有做外卖的吐槽，卖一杯奶茶还得倒贴给外卖平台两块配送费。更别说满大街的新店，抖音上人人发套餐券引流，顾客倒是乌泱乌泱的，但全是冲着便宜来的，吃完这顿就转场下一家薅羊毛。开店的看似热闹，月底一算账，全给平台和房东打工了。

这种“看上去很美”的生意，跟Web3圈子里那些拿着本金冲进去想赚快钱的新人，简直一个模子刻出来的。

说到底，餐饮不是不能做，但没摸爬滚打过五年的，别轻易碰加盟或单干。镰刀锃亮，韭菜正绿，半生积蓄，一夜清零。这不是危言耸听，是无数人用真金白银买来的教训。
