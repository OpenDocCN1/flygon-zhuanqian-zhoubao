# ('8 种在 Youtube 赚钱的方法', (2, 20))

最近，生财有术圈友郭小帅抛出了一份实在干货：一口气整理了8条YouTube搞钱路子。这可不是什么高深莫测的“大佬秘籍”，他自己先说了，顶多算个入门级选手，早前碰过一阵联盟营销，没整出啥大动静，频道也一直晾在那里。所以这份内容对刚接触YouTube变现的新人特别友好。当然，他也不是万能选手，有讲得不对的地方，欢迎大家在评论区帮忙纠错。

他是刚加入生财不久的新人，用他自己的话来说，进圈后感觉像推开了新世界的大门，各种神仙玩法看得人眼花缭乱，自己也一直在拼命吸收。为什么突然写YouTube？起因是有圈友在风向标群里感慨，说星球里关于油管的资料太少。郭小帅一听，立马觉得“这不就是机会吗”，于是把自己的经验梳理成了这篇基础教程。

至于具体是哪8条路子，他都写进了飞书文档。链接如下：
