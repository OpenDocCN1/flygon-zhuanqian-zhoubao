# 知识付费类型的产品,合作如何分钱？

知识付费类的合作，钱到底怎么分才合理？这是很多刚起步的流量方都会纠结的问题。

最近就有位大学生朋友遇到类似情况：他负责从小红书引流，合伙人提供类似 DISC 天赋测试这样的产品，先做初步转化，再把用户导给合伙人做高价咨询。当他问对方怎么分钱时，对方让他自己提，他却心里没底。

其实这类合作在行业里有一条可以参考的经验线：负责引流和成交的一方，通常能拿到销售款的 30% 到 50%。但具体落在哪个点，要看产品本身的品牌议价能力——品牌越强，顾客可能是冲着名字来的，流量方的作用相对变小，分成比例就要往下走；品牌越弱，越依赖你带来的客源，那你的话语权自然更大，比例可以往上谈。

如果你是刚起步的新手，不用一上来就冲到最高，建议在 30% 到 40% 之间报一个自己觉得舒服的区间。而且结算方式尽量按实际成交来分，卖一单算一单，清晰又公平。

所以别慌，先锚定这个区间，再去和合伙人聊，心里就有底了。
