# 四.破局

## 1.逆着人性开了局，却每步都顺着人性落子

群这东西，兜售的无非是三样：信息、认知、人脉。到我这个大学生手里，前两样的权重最大，圈子属性很淡。

但信息、认知恰恰是典型的非标品，走“先给货后收钱”的模式，难度直接拉满。人天性爱白拿，对信息值多少钱心里没数，供需两端也天然错位。我这一搞，等于把定价权和打分笔全部塞到对方手里。最后还要从人家荷包里往外掏钱——可人家东西都到手了，凭啥再给你掏？掏多少算够？掏1块是情分，掏100是本分，扭头不掏又能怎样？那阵子，我压力大得不行。

第二层，弱关系的“弱”反而成全了它的“快”。弱连接里没有熟络关系那种密集的日常琐碎和情绪牵绊，信息在弱关系链上的流动很少受阻，跨圈层传播的阻力比熟人网络小得多。换句话说，它能帮你更快、更省力地接到新鲜信息和资源。

第三层，弱关系跟职业跃迁的关系相当密切。研究者温加特的调查显示，相当多的新增职位和机会，是通过弱关系送达当事人手上的。这意味着，你职业道路上的下一个转角，很可能不是天天见面的密友带来的，而是一位久未联系的老朋友偶然递出的线头。

# 五.这次社群策划，我最想留下的四句内功心法

## 1.要有成果物思维

“成果物”三个字，是我在徐宿那里学到的。他讲这个概念的框架里，先是借用了乔布斯晚年在一次公开演讲中的那段话。

英文原文我就不全文默写了，翻译成中文意思是：你没有办法在向前走的时候把一颗颗点串起来，只有回头看的时候，那些点才连得成线。所以你只能选择相信——相信自己当下经历的一切终会在未来接上。你要去信那样东西，你的直觉、你的命、你走过的路，随便什么都好。这种做法从来没有辜负过我，也让我这一生彻底不一样。

一句句拆开落到我自己身上：“你没法在向前时看清点与点的连接。”我策划并落地这个社群的时候，压根没想好怎么变现，喊得响的只有一句“先交付后收费”，而且心里其实空空荡荡。

我为此热血上头过，也为此彻夜失眠过。可是所有的辛苦都没有白费。时至今日，我愈发相信，这段日子会成为我往后人生里的一台发动机，推着我一直往前跑。

复盘了一下最近这段经历，我发现几个重要的认知。

这段时间的社群实践，让我遇到了一群有意思的人。有人变成了我的运营搭档，有人成了我的人生导师，也有人将是我未来的合作伙伴。

直到今天回头再看，我才真正读懂乔布斯那句话：只有未来回顾时，你才会明白这些点点滴滴是如何连在一起的。所以，你得相信，现在所经历的一切，将来多少会连接起来。信直觉也好，信命运也好，信生命也好，信业力也好。这份信任从没让我失望，也让我的人生彻底不同。

那“成果物”到底是什么？我的理解是：成果物＝作品＝产品。社群交付期时，我向群友分享过这个想法：![](img/565a6155a2caae2fddc1fb43a6be1cfa.png)前面说的是概念，后面说的是用法。如果再往下拆，作品又离不开“内容”这个载体。内容无非三种：文字、视频、音频。我主攻文字，就拿朋友圈的“日更”笔记来说：![](img/67ed37fade06f99a5503f0c4a9213242.png)把自己的学习、经历、感想、见识，用文字、视频、音频等方式呈现出来，这就是成果物化。当足够多的成果物汇集成“作品”，就能拿去做投放，享受时间的复利。

再说“打磨好销售和交付，然后不断做内容、做投放，重复进行”。这句话源于花爷的《开眼2》。花爷拆解了张琦矩阵号玩法：博商给每个老师录两天课，剪辑成批量视频，看哪个能爆。对张琦来说，爆是随机；对博商来说，总有一个讲师会爆。花爷还留下三句话：IP要做大，光有质量不够，高频产出才是关键；稳定质量的高频输出能覆盖更多流量，与粉丝高频触达；打磨好销售和交付，再不断产出内容、投放，循环往复。当时我理解不深，觉得只要内容够好，就能反复卖。后来发现，有些内容有“时间红利期”，过期就贬值。所以得持续做好内容、新内容，前端解决信任，后端解决交付体验，复购就会自然发生。

工作的复利来自有效资产的积累。![](img/e283e2662ce3f120167bef8cc16bd49b.png)之前我理解不深，直到我看到刘慈欣的故事：他从1999年开始写《超新星纪元》，此后每年都有新作，一直到《三体》，再到2019年火遍全国。二十年时间，从普通人变成顶级IP。这就是“结构性优势积累”——每天进步一点点，量变引发质变，然后突然爆发。它和“有效资产的积累”本质上是一回事。

做内容创业，先要有信息资本，然后才有知识资产。信息资本就是优质信息：成长的优质信息藏在大V公众号、知乎、B站以及经典书籍里；赚钱的优质信息在行业报告、论文、知识星球、国外案例和高端饭局里。信息有门槛，有人会用搜索引擎，有人会请教大V，有人直接付费加圈、买课，把信息差拉到最低。长期浸泡在优质信息中，就攒下了信息资本。知识资产呢？我认为成果物是，怎么做出成果物的方法更是。成果物像做菜，原料是信息，手艺是方法。原料足、手艺好，菜就好吃，口碑积累，顾客越来越多，利润越来越多。

所以，这四句话在我这里成了一个完整系统：一要有成果物思维；二要打磨销售和交付，不断做内容、做投放；三要积累有效资产，享受复利；四要先建立信息资本，再形成知识资产。

接着说说那十句话里我践行的五点。

第一，自己说好不算好，别人说好才是真好。为此我专门发过朋友圈：![](img/64146bbcc385ca2691dc6001f020ce82.png)部分截图如下：![](img/1b849908ebf2f7b2ab371058f14b9637.png)![](img/977ac48b9d951b26606d8c5dd380fd80.png)那是开营第二天，我明白了：别人的认可才是真正的认可。

第二，成功的案例要自信地传播出去。我这10天收获颇丰，收益超过四位数。有人给我打钱，也有人没打，但都在意料中。按单价算，这个回报率已经很高了。更重要的是，我积累了自己的“成果物”：10天交付了23个内容，其中70%以上能算作品。这个过程让我完成了从“信息资产”到“知识资产”的转变。我还拿到了大量AI应用场景：有群友用AI一分钟生成英语卷子，![](img/16840f97886c832c7e4909d3bf64a4a3.png)用AI写旅游文案每天薅羊毛，![](img/38526e668f14269fd156fd10db2a4780.png)![](img/82f57812dd8e3399e74110d4165687da.png)用AI写论文还挺像样，![](img/7a61ada075c6478979ff7e315d6c467a.png)![](img/a36d88681850d847004e54a8f0ec7aba.png)我也用AI写了一篇论文赚了40元。![](img/7bfafbf9daeebc78ddc11bd4a5b4c8c1.png)![](img/549d2287fda702948357e20a85cde5d7.png)那是某985高校的理科作业。除了变现，我还用AI写小红书种草文案，![](img/35aba08cbb0efdad2648be7c09b093de.png)![](img/6095d607d33388f15c5631f5def6e9e6.png)你能猜到哪篇是我写的吗？还用AI写散文，在另一个星球收到20多个赞，题目是《古道边的记忆：杭州的顺德菜、毋米粥锅的故事》。![](img/dc2b66a06e9a759b99e10b44e8bf3ac9.png)那段“石磨汤锅”和“家”的文字，我觉得完全能投美文公众号。后来我还用AI写诗，有位年入千万的大佬点了赞。![](img/d7cf5b39ad85e01f6db53722aee4142d.png)虽然整体不怎么样，但有几个排比和结尾还不错。当然那首诗是我拼凑的，但确实没有一个字是我原创的。用AI写小说也可以，我给它设定了一个短篇科幻大师的角色，让它以“流浪地球”为背景创作，![](img/6d54d4569086a33b0987a4c1175edf41.png)开篇和结尾都有模有样，放在网文圈能秒杀很多写手。我还用AI洗稿百度语料，![](img/0101ded91f9badc7bb93224afef83a78.png)生成的文章金句频出，![](img/85cc57d6ce54f787114b1a0c08d9721a.png)比我们学校领导讲得都好。这些案例都是我的成功案例，今天分享给同行的人，就是自信地传播。

第三，钱只是中间态，用收入换影响力很划算。我敢做“先交付后收费”，说明我不那么在乎钱，但很在乎付费态度和性价比。能花小钱办好事就花小钱，办不了就大方付费。非亲非故的，哪有什么无缘无故的帮？尊重彼此的时间成本。最后我只收了很多人的9.9元，甚至有人消息不回、9.9也不付，没关系，永远让人白嫖一次。蔡哥一句话点醒我：之前是希望别人为事付费，之后是希望别人为人付费。为人付费，就是IP的价值。论事，我产出了23个内容，几万字原创，包括6个免费使用AI的方法、本地部署GPT教程、小红书调教案例、Prompt生成方法论，这些放外面都值几百上千；论人，10天只请假一天，90%的人为我付费。同时，我也是淘金碎片＆AI之心的获得者，还成了2.7w人AI星球的大航海教练。![](img/49a43bd2749509a03247c6ab5719d71d.png)![](img/c5380237c7208148607ba6e5c22dc6c8.png)![](img/d8fd46b7a47bb6d5663dfa1277e64404.png)![](img/9e3b4e23d3400a9b1fe16c95cee430f0.png)![](img/5adc924c53939a6d629ad0d40d35fa3e.png)在教练里我资历最浅、年龄最小、收入最低，但没关系，钱只是中间态，用收入换影响力很划算。

第四，利他是最大的利己。我的愿景是成为超级个体。我之前试过知乎、视频、闲鱼，都不是最擅长的。直到接触AI，前面积累的写作和变现经验终于爆发。曾经我不愿意分享赚钱方法，怕别人抢饭碗。后来明白，信息差只对一点就通的人有用，也只有这样的人会来感谢你。我的第一篇代表作《利用GPT帮助小红书蹭流量的全流程》帮很多人跑通商业闭环，他们在作品里艾特我，等于给我增加曝光。我帮你突破卡点，你帮我留名，这是双赢。![](img/ea6a0e4d813de6627b9c7b83f02401e7.png)小番深夜感谢我，他们的产品“光点红”后来也确实加了SEO优化、首图和爆款复刻功能。![](img/ce7877bd8dc5cfd82e2f90c69c407c2c.png)![](img/e9839c25ba1dc1e4c134855db71b7d05.png)两篇文章帮人家日赚1000多，第二篇是我的。![](img/775b9f1f1d714b6c8543ab9585a3bacd.png)这套方法再次被验证。我赢你也赢，才是真的赢。

第五，小局变大局，从一个小点开始突破。一个好的互联网人，要先入局，再会做局，最后破局。我3月份开始做公众号，这是入局。不断学习、写作、加社群、链接，用钱换影响力，把优质信息转化为知识资产，产出作品，给自己上杠杆。这篇近万字的复盘也是上杠杆。之后我做局，设计了先交付后收费的玩法。虽然开局逆人性，但运营每一步都顺着人性。虽然没能让所有人付费，但瑕不掩瑜，没人能让所有人都喜欢。

说实话，一开始我真没想那么多。
十天后的局面，谁能预判？谁会愿意付费，我猜不到；十天后居然赚到四位数，我更没敢想。
这些“结果”不是等来的，也不是算来的，而是一件事一件事干出来的。

四个月前，我的公众号只有一百多人，文章常常只有几十个阅读。
现在，公众号有两千多人，阅读量稳定过百，私域突破千人，在万人规模的星球里也拿到了成绩，AI付费成员超过四十位。
时间只过了四个月。
我真正做对了两件事：一是把公众号的方向摆正，二是用利他思维启动了社群运营。
起点只是一盘小棋，但从小切口撕开，小局慢慢变成了大局。

### 01 影响力，不需要等自己成为“最厉害”

这一点我特别有体会。
学历、社会地位、专业技能，我都不敢说自己比别人强。
可我必须等到拿了100分才敢交朋友？必须等到财富自由才敢追喜欢的人？
当然不是。
该做就做，该往前就往前，别管别人怎么看你，别怕失败，别怕丢脸。
只要你走在正确的方向上，全世界都会来帮你。
获得影响力，从来不是先成为顶尖高手，而是先迈出那一步。

### 02 一个人能值多少钱，看他为别人带去了什么

我把这句话翻来覆去读了三遍。
我的理解是：当你本身价值很小的时候，更要学会资源整合。
要么做流量，要么做产品。我选择了后者。

走流量路线，得会吸引人，也得会经营朋友圈。
我朋友圈里就有这么一位，她尤其擅长构建信任感，每次线上聊天都像老朋友叙旧。
靠着朋友圈CPS分销，她做到了月入过万。

走产品路线，得能一秒看懂一句话，也得能从目录倒推别人的内容设计。
前者靠演绎，后者靠归纳，都是最底层的逻辑功夫。
我现在就特别喜欢拿着书的大纲或课程框架去倒推，看看对方是怎么构思的；如果手头有这本书，我还会拿自己的理解去和作者对比。

扯了这么多，别忘了主题：
一个人能值多少钱，不看他手里拥有什么，而看他为别人创造了多少价值。

如果你擅长流量，你就在产品和用户之间架了桥。产品端负责承接需求，获客端负责帮用户省掉信任和时间成本，所以你能赚到钱。
如果你擅长产品，你等于沉淀了一套可复制的方法论，能帮别人少走弯路，省下时间和试错成本。而且产品可以复制，你本人还在不断升级。
真正聪明的生意人，不会去白嫖合作伙伴，更不会去占一个超级个体的便宜。这次你占到了，下次呢？你敢赌对方手里没有新东西？

为了验证这样的理解，我还专门请教了ChatGPT。它给出的答案也很实在：
![](img/d890659dbf3a9e25e4e0a67d5378a5c6.png)
一门生意，离不开流量、转化、产品这三个支点；而我的理解更偏实践，不是空谈概念，而是通过搞流量或搞产品，去为他人创造实实在在的价值。

看到这段，我当场悟了。

### 03 聪明人都在建自己的“成果档案”

说白了，这是在给自己积累信用。
大多数人只看结果，不关心你背后吃了多少苦。事情做成了，你不说，就没人知道，影响力自然也没了。
所以朋友圈总有人晒成交，本质是在降低别人信任你的时间成本。

我在一次社群自我介绍里见过六个字：
淘客，佣金过亿。
简短，却极有分量。

古代名医董奉也深谙此道。他看病不收钱，只请痊愈者在门前种一棵杏树。年复一年，杏树成林。
这就是“杏林春暖”的由来。
最有说服力的案例，不是自己吹出来的，而是“客户”帮你种出来的。让别人替你说好话，比自夸一万遍都管用。

那普通人该怎样建自己的档案？
把成交截图发到朋友圈是一种；像我这样，把值得骄傲的操盘经历写成文章，让更多人看见，也让自己以后回看时能找到线索，是另一种。
重要的是有心，不分大小。

### 04 但行好事，莫问前程

这句话的意思是：把眼前的事做好，别总盯着未来。
ChatGPT给过一段解读：所有宏大的目标，都藏在每一件小事的完成度里；别为了幻想的未来，忽略当下该做的事，只有脚踏实地，才算真正在走向目标。

我另外找了两句意思相近的话帮助理解：
涓涓细流汇聚成海，点点星光点亮苍穹。
大道至简，行者至远。
说到底，都指向同一个内核：知行合一。

如果你现在每天连信息收集、内容积累和输出都做不到，那不妨先试着日更朋友圈。
如果连这个也坚持不了，干脆躺下吧——这么懒的人，做什么都会累。

### 05 超过别人的预期，是一笔稳赚不赔的投资

我现在再看“尽可能多超出预期”这话，感受又深了一层。它至少有三层意思。

第一层：信任、口碑和复购。
超预期，意味着交付的价值大于对方的期待。产品和服务足够好，别人的问题真正被解决，口碑就会自然形成。用户感到惊喜，就会复购，就会帮你传播。
信任有了，忠诚度有了，资源和机会自然也被吸引过来。

第二层：学习、质量和创新。
能持续超出别人预期的人，一定也在不断超越自己。没有高标准，就没有高预期；没有持续学习，就没有真正的创新。
这十天高强度的交付，让我产出的内容被更多人看见，也让我进入AI破局俱乐部航海教练组，同时成为淘金之路7月“AI × 小红书”实战项目嘉宾。
高密度输入倒逼质量提升，再和最前沿的AI赛道结合，便成了我独一份的创新点。

第三层：竞争力和差异化。
在拥挤的赛道上，超预期就是最好的辨识度。你比别人多做一点，用户就多记住你一点。品牌形象立住了，竞争优势也有了，长期增长自然更有底。
肖厂长在“超级个体”中讲过一个概念叫“IP标签”，打造标签有四种工具：专业锚、视觉锤、文字钉、行动枪。
这次社群运营策划，就是我的“行动枪”，是我的代表作，也是我的差异化。
