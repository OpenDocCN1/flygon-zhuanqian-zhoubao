# ('3 个月亏掉 20W，抖音店播我都踩了哪些坑？', (2, 25))

三个月，20万，血本无归。这不是段子，是我刚刚亲历的抖音店播“踩坑实录”。

先交代一下背景：我此前在上海打拼六年，做过PR、商业记者、品牌营销，访谈过无数消费品牌的CEO，也接触过各平台电商直播的顶级玩家。说得不客气一点，理论水平拉满，动手能力归零。今年2月我回到义乌，接手家里的内衣厂，专做中老年大码内衣；3月底上线抖音直播，到6月20日关停项目、解散团队，整好三个月。除了主播没换，运营换了三个，场地换了一次，产品换过，客群也换过，结果照样没起色。

不想看长篇的朋友，先划个重点，我这三个月主要死在这几件事上：

- 把账号能起来的希望，全押在了别人身上；
- 只会纸上谈兵，实操一塌糊涂，白白被运营割了好几轮；
- 付费投流亏本冲低价，越卖越亏；
- 跟气场完全不对路的人硬凑合作，内耗到崩溃；
- 只抄别人的玩法，却没理解背后真正的用户痛点。

这三个月，按三位运营的来去，我把它分成三个段子：

第一段，上海职业派VS义乌江湖派。一个讲方法论，一个靠野路子，彼此都看不顺眼。用吧，又不敢完全信任；不用吧，又没人可用。

第二段，我成了自卑老板，遇上了PUA大师。对方一句“我在跟你讲底层逻辑，你不虚心还质疑我”，就能把我噎死。

第三段，来了个只有60分的职业派运营，平稳是平稳了，但根本解决不了问题。就像温水煮青蛙，最后项目连挣扎的力气都没有，直接凉透。

更详细的复盘我整理在飞书文档里了：想看重点，直接看开头省流版；想听段子，跳过到“99爹”那一段；想看我账号做得有多烂，就去数据复盘——一个马赛克都没打，真诚得像个显眼包。

评论区里也有人跟我一样的感叹：“很真实，就是交学费了。”也有人问：“现在运营都这么牛气哄哄吗？”还有人教我：招人再怎么样也得要个身份证复印件吧？我只能苦笑——在义乌，不签合同都能上班，我说要签，人家说身份证没带。我还能说啥，下次一定。

这20万的学费，不算白交，至少让我记住了：别迷信别人，别硬融圈子，别只看表面，先搞懂用户再说。
