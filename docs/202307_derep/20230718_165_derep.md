# 说到底，长期主义难的不是坚持，而是懂得放弃

很多人把长期主义，想成是一场意志力的马拉松——只要咬牙撑下去，熬过当下，未来自然会回报。

王川给出的答案却很反直觉：长期主义最难的，恰恰不是怎么去做，而是敢不敢不去做。

我们的时间和精力永远是有限的库存。问题不在于你有多少热爱，而在于你每天在为多少低价值的事情买单。那些看似无害的琐碎、无效的社交、拖泥带水的内耗，正一点点稀释你的长期势能。

真正能走通长期主义的人，都拥有一种近乎残酷的自律：对低价值事物的持续、严格、毫不犹豫地舍弃。这种舍弃不是逃避，而是一种主动的筛选。它把你从琐碎的噪音里解放出来，让真正重要的事有足够的空间生根发芽。

所以，长期主义的解放之路，始于一遍遍清晰的取舍。先学会说不，才有资格谈坚持。

“对低价值事物的持续严格舍弃的自律，正是通往高价值成长的长期主义的解放之路。” #龙哥的收藏夹#
