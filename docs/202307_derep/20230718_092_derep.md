# ('勇敢下场找到正反馈，就会发现赚钱这个事也没那么难', (2, 26))

别再脑补困难，先下场赚一把正反馈试试

前几天跟朋友吃饭，我随口感慨：“这事儿太难了，我真搞不定。”朋友不紧不慢地回我：“真没你想的那么难，你只是从来没在这件事上尝到过甜头，光凭想象就把自己吓住了。想迈出第一步，不如先主动给自己攒点正反馈；尝到点甜头，你会发现自己完全可以做到。”

这句话一下点醒了我。回头想想，这不正是咱们航海圈一直在讲的理念吗？别光在岸上观望，先下水、先上手，在行动中积攒属于自己的正反馈。当你真的体验到“原来我也能行”，赚钱的路子自然会显现，挣钱这件事也会变得简单起来。

很多人不是能力不够，是被自己的想象困住了。想，全是问题；做，才有答案。先下场，找到正反馈，然后你会发现：赚钱，真没那么玄乎。
