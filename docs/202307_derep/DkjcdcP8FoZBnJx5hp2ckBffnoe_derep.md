# 00后靠盲盒交友项目，1个月怒赚23w（复盘总结）

如果有人告诉你，一个刚毕业的零零后，不靠背景不靠资源，靠一个叫“盲盒交友”的项目，一个月赚了23万，你可能觉得他又在吹牛。但今天这篇复盘，不讲虚的。

先交代下我是谁：野鸡专科毕业，学的是数字媒体，一毕业就进了腾讯。我算不上什么天才，就是什么都会一点，而且执行力爆表。接下来把从0到1、从1到放大的完整过程拆给你看。

![](img/a82348a912403191648647036d8cf019.png)

**先弄懂：这个项目到底是个啥？**

简单来说，就是把线下那种“街头月老办事处”搬到线上：一张桌子、两个箱子，男生女生各放一张写着自己联系方式的纸条，想脱单的人花1块钱，就能投一条自己的纸条，同时抽一张别人的纸条。线上就是把这个场景做成小程序，用户抽一次纸条花1到2块钱，还有五连抽、十连抽的套餐。抽到的纸条上，就是异性的交友要求或者微信号。

为什么要做这件事？因为单身的人实在太多了。我国单身成年人已经高达2.4亿，这么大的需求摆在那儿，随便切一个细分领域都够赚。只不过有人做了相亲，有人做了情感咨询，而盲盒交友，把年轻人的猎奇和社交需求一起打包了。

**钱是怎么赚的？**

这项目不靠卖货，靠的是平台分佣。用户每花1块钱，红娘最多拿0.9，平台留0.1。用户还可以付费进“脱单交友群”，也能成为代理去分销，层层都有人赚。

我用他漏出来的“红娘”“盲盒”“线上交友”当关键词去抖音搜，很快找到一个对标账号，立刻开始模仿起号。第三天，数据就有了：

**进圈子之后，怎么从日入100做到日入1000？**

那个群里一共8个人，平均每天能赚100到200。一开始我也是这个水平。但跑通一个账号后，我就开始复制：1个抖音、2个抖音……一直到7个抖音同时发。原来群里的那些人，慢慢被我甩在了后面，收入也从每天100多涨到1000多。

做到7个号时，我发现单枪匹马上限快到了，因为要剪辑、发布、通过好友、私域转化，全是耗时间的工序。

![](img/3d13dbac8a822fa152c268ba564e14c8.png)

这时我停下来复盘：除了放大，还要精细化。我盯着两个盲盒平台方的私域运营看了几天，发现他们引过来的用户，客单价只有1-2块钱。问题出在两点：一是加过来第一句话就是广告；二是朋友圈全是硬广，毫无吸引力。

这个项目的用户画像很清晰：男性为主，18到25岁，来找对象的，就喜欢漂亮女生。所以我做了三个小调整：

- 朋友圈广告改成“海报+漂亮女生照片”；
- 私信不发广告，全靠朋友圈养熟成交；
- 多用“yyds”“绝绝子”“天花板”这种网络用语，让账号看起来像个人，而不是官方号。

就是这么几个动作，客单价从1-2块钱直接拉到5-8块钱。后来平台方和同行都来抄我的打法。

![](img/43ba46eb842862c8d9c4260aa790a212.png)

**怎么放大引爆？**

转化率搞上去了，接下来要解决“量”的问题。我的口头禅是：中国不缺货源，先搞定流量。所以我围绕流量做了四件事：招代理、做教学陪跑、找代发、布局私域。

先说招代理。第一期我搞的是免费教学，想着平台有分销机制，代理赚到的钱，我也能拿到20%的提成。但招来的人大多是以前朋友圈里的朋友，没做过网创项目，执行力低，交付成本高，收益也不理想。跑完一周，我直接把这个模式砍了，就当测试流程。之后我明确了：我需要的是创业粉，不是路人粉。

接着做了两件事：

**1. 朋友圈广告投放。** 我去找各项目方，在他们朋友圈投广告，一条300-600块。我的教学陪跑客单价是288块，一次广告只要成交2个人就回本。按这个逻辑，只要不亏就无限投。实际数据是：一次投放能加到25-50个好友，平均转化6个客户。算清楚账之后，我真的是无限投。

**2. 网创平台投稿。** 做好海报，录制课程，但只讲大框架，细节留到陪跑里讲。这么做有两个好处：一是有人按照课程去实操，成了我的代理，我能拿20%提成；二是想要深度陪跑的人，会自然来付费。

![](img/f2954886011e3d682901d297187a4e6f.png)

两种方式一起跑，10天左右引流了1000多个创业粉，一个月下来大约5000个。

有了粉，新的问题来了：一天几十个学员，根本没法完美交付。为了保证利润和口碑，我用上了私域转化的核心打法：**逼单+提高客单价**。

这个项目是短平快，如果我在网上无限收徒，风口很快会消失。所以我直接用“每天涨价100”的方式制造紧迫感，让观望的人赶紧上车。效果出奇的好，犹豫的人纷纷报名。

转化过程中还有一个细节：我基本都用语音沟通，这比打字更容易建立信任，能极大降低客户的戒备心。

**二次点燃：把同一个产品换个包装再卖**

我之前读过的产品类书里有个观点：产品核心不变，可以换无数种包装卖给用户。可口可乐和百事可乐，卖的都是可乐，只是换了一批卖的人而已。

于是我给自己加了人设：

- “前腾讯媒介部核心导师一对一陪跑”；
- “5年网创经验，带你龙哥盟”；
- “报名进专属网创圈子”。

![](img/84f276f3a5fbc69d4102954fc7b8a659.png)

但包装完之后我发现，报名人数并没有暴涨。可能大家已经对这种套路免疫了。于是我迭代了海报和玩法，本质上还是换汤不换药。

同一个渠道、同一种方式推第二次，效果大约是第一次的50%。但这时候产品已经被验证过，没有额外成本，继续推就是纯赚。

**基本盘怎么再放大？代发！**

教学盘的放大做得差不多了，接下来轮到自己那7个账号。我想到的突破点是“代发”，也就是用别人的号帮自己发作品，流量全部导到我的微信。

流程三步：批量剪视频、找兼职粉、测试跑通。我先找了3个兼职粉，一条视频给他们3-5块钱，用他们的账号发，微信留我的。跑通之后直接放大。

但我已经没时间亲手干了，这里有个心得：千万别把自己活成工具人，重复劳动一定要外包。我招了个远程助理，底薪1000，加成交额40%提成。一个月下来成交额13988。那阵子刚好赶上口罩政策放开，大家轮流阳，有半个多月没法正常引流。要是整月不断，这个数应该能到3万左右。

**项目最后怎么样了？**

阳完之后马上过年，加上入场的人越来越多，平台开始管制，利润直线下滑。这时候该退就要退，不恋战。

来总结一下数据：账号端收益，有几个后台已经关了没法截图，估算加起来大概8万；教学陪跑端大概15万。一个人，一个月，合计23万。

**抛开项目本身，核心玩法是什么？**

第一是流量。雷军那句话永远不过时：站在风口上，猪都会飞。年轻的社交小程序配年轻的平台，属性天然吻合，流量不爆才怪。而且客单价低，拼的是数量，不需要每个用户都精耕。

第二是私域。引流是前提，私域是钱袋。用户带着社交需求进来，想让他掏钱，朋友圈必须精准打痛点。成交主战场就在朋友圈，不是硬推广告。

第三是盲盒的终局。人对“好奇+抽奖”天然上瘾，限量版、隐藏款更能刺激购买。但线上盲盒野蛮生长，没有规则管制，平台质量越来越差，真正能脱单的没几个，违规广告倒是越来越多。用户一旦体验变差，消费就只能停留在最初几次的新鲜感上，不可持续。不过没关系，前几波用户规模，已经够平台们吃饱了。

![](img/35f957a6a089961452f786a32861d5c9.png)

有人问我：你都做到这个体量了，为什么不开个平台自己干？

因为事情要算投产比。开平台要管搭建、域名、售后、代理提现，工作量比引流大多了。平台本来就愿意把九成收益让利给引流的人，我只专注拿好自己那份就够了。如果当时真去开平台，收益大概率腰斩。蛇吞象的事，不建议干。

![](img/de6f0e9870fbe11bdc3dc942710f32d9.png)
