# 出书这件事，为什么我会把它当成长期战略

## 为什么一定要出书，以及从中得到的一个赚钱思考

作者： 粥左罗 

日期：2023-07-24 

【粥左罗：为什么一定要出书，以及从中得到的一个赚钱思考】

大家聊出书的好处已经聊烂了，今天不重复那些共识，我想拆解一个我最近越想越通透的逻辑。

对一个做知识IP的人来说，出书的底层逻辑非常特别。你打造的是一个高质量的内容载体，但它能不能卖得动、卖到什么程度，并不取决于你多努力去推。更关键的是，这个产品会自然长出一批比你更着急它卖的人。

换句话说，你负责把内容做到位，剩下的推广生意会自动有人接盘。出版社的工作室、产品经理、营销编辑、线下渠道、分销商，还有那些靠书单号、短视频荐书卖书的创作者，他们会主动为这本书找流量、造话题、做转化。你根本不用盯着。

反观知识IP的其他形态，课程、训练营、社群、一对一咨询，本质上都是强人设陪跑型产品。内容是你产的，销售也是你扛的，交付更是你负责的。产品、销售、服务三条线全压在一个人身上，时间和精力消耗极大。

书就不一样。因为它自带一个利益共同体，你只要持续输出能打的内容，别人就会帮你把价值榨干净。你赚到的是余波收益，而他们赚到的是第一波执行收益。这才是真正的分工。

所以我的习惯很简单，每年稳定产出，每年我只做一件事，就是把稿子写到能过审、能打动人的程度，然后交给出版方。剩下的宣传动作，我几乎不碰。朋友圈、公众号很少主动卖书，因为我清楚这件事不需要我亲自上场。

我的定位应该是去写一本有机会长卖的书，而不是去当一个卖书的销售。长期看，这反而是更高效的投入。

这也是我把出书当成躺赚的原因。

《学会写作》第一版累计已经突破10万册，第二版上线后热度也不减，一本书连续卖了四五年还在走量。《学会成长》虽然起势没那么猛，但也稳稳站在了3万册以上的畅销线。《成事的时间管理》是春节后新上的，短短不到一年就被抖音上的内容号带火了，目前每天稳定在抖音卖出300本左右，这个状态已经保持了一个月还在延续。

今年我正在推进的是一本关于打造个人IP的书。目前的节奏已经固定下来了：每年一到两本，把持续出书当成战略资产。数量堆上去，总会有几本冲到几十万、百万册的量级，甚至出现能反复加印、卖十年二十年的经典。

【而且在出书这件事上，其实我一直没有专门花时间，我平时写文章写课程，我都会用一个标准来要求自己，就是每一篇每一节的质量得是能够出书的标准，因此我每年出的书都是现成的一些内容，不需要专门写书。】

还有一个很少人注意的点，书是知识类产品里最容易被“免费帮你宣传”的媒介。你的课程、训练营、社群，大家发朋友圈会觉得像在帮你招生，很刻意。但晒一本实体书，发一条读书笔记拍一个短视频讲感受，写一篇读后感，这些行为对大众来说非常自然，完全没有广告感，却是最有效的口碑裂变。

做流量和转化，是让人直接为你付费。做品牌，是让人在心里越来越认可你。书能同时帮你完成这两件事。

最后，我从出书这个模型里提炼出一个做生意的方法论。如果你做一个项目，最后的利润几乎都留在自己手里，那这个项目很难长出一个生态。反过来，如果你能主动把一部分收益让出去，让更多人因为你的产品而赚钱，那么他们就会自发地成为你的分销网络、你的推广部队、你的口碑放大器。

分钱的能力，本质上是赚钱的能力。过去我们更多把这个逻辑用在团队建设和股权分配上，现在我发现，产品机制本身就可以设计成“让利型”。当有一帮人靠你赚钱时，你就不会缺钱。![](img/12392670e5e324a3edad8715a9cf2f47.png)
