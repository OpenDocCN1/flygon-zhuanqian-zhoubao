# 干了三年小红书好物种草，我把实战经验摊开了说



## 做小红书好物分享三年，矩阵起号和变现实录

作者：叁斤  
发布：2023-07-11

《一个跑了三年的副业：小红书好物分享博主》

大家好，我是叁斤。2020年入局小红书，第一条路就是走好物分享。期间陆续试过衣物配饰穿搭、桌面好物盘点、零食测评这类内容，也正是在做这些账号的过程中，我开始摸索做账号矩阵。

单纯靠素人好物号接广告，单子其实不算少。当前行情大概是1000粉一个报价在100元左右。我的一个千粉号，从首条笔记发出到达标，熟练后大概7天左右能完成。新手从零起步的话，预留一个月时间比较稳妥。

今天把这三年摸出来的小项目整理出来跟大家聊聊。想靠它实现暴富不太现实，但把它当成一个挂在身边的副业来做，月入几千到一万块是完全可以实现的。
