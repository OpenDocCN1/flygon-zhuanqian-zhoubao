# 六、公众号承接流量

1. 注册一个公众号用来承接流量，注册步骤就不展开说了，直接搜“微信公众平台”到官网自己注册。
2. 设置关注自动回复，在底部菜单栏留微信号，把用户引到私域。前期可以从简，比如下图的样子就够了；后期可以做精细化运营，加欢迎语、资料引导、定期推文等。

![](img/de1e60664a7edd7bfbe0d2f44ccfbd0e.png)

最后再把用户引到私域或者直接成交。

这套变现路径非常简单，流量大利润也不低，收益还能越滚越大。趁现在时机合适，早点入场。
