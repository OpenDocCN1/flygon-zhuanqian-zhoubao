# 别急着躲开痛苦，它可能是你最强的“训练场”

你有没有发现，那些真正让人脱胎换骨的时刻，往往都伴随着难受和煎熬？最近翻到一本很有意思的书，叫《Can’t Hurt Me》，书名本身就是个态度：你根本伤不到我。

这本书没有给你灌什么温吞的鸡汤，而是用近乎残酷的视角，重新定义了我们和痛苦之间的关系。它想传达的核心很简单——痛苦不是来惩罚你的，而是来成就你的。我们总想着如何避开不适，却忘了正是那些咬牙硬撑的瞬间，才把普通人磨成了狠人。

书里反复强调一个逻辑：越是让你想逃的，越是你该迎上去的。当你不再把疼痛当成威胁，而是把它看作成长的燃料，你的承受边界就会一次次被拓宽。读完最大的感受是：我们不是被痛苦打败的，而是被自己对痛苦的想象击垮的。

如果你正处在低谷，或者觉得日子太难，不妨换个角度——把每一次崩溃都当作一次升级。要知道，疼痛不会永远停留，但你在疼痛里长出的韧性，会陪你走很远。

最后想用一句话收尾：那些杀不死你的，终将成为你的一部分。![](img/894d30a529e7c37bcd3392323c99941c.png)
