# 从零到1100+单：一个在职宝妈的小红书店铺“航海”实战手记

原文链接：[`www.yuque.com/for_lazy/thfiu8/gaih1sunogn5qlz6`](https://www.yuque.com/for_lazy/thfiu8/gaih1sunogn5qlz6)

大家好，我是丹丹🍀。之前我在少儿教育机构上班，小红书店铺就是在那段在职时间里，跟着航海项目一点点摸索做起来的。

航海结束后，其实身边就有不少朋友催我写一篇复盘。彼时我总觉得经验还不够成熟，迟迟没动笔。后来又陆续被好几个朋友提起，这份“踢皮球”才算踢到头，终于把这段经历整理出来了。

这篇分享，我主要想给三类人看：

1）正处起步阶段、信心不足的新手。你看我这样一个普普通通的入门者都能跑通，你也可以的！👍 希望我走过的弯路，能给你一点点底气和力量❤️

2）负责课程研发和教学的老师。我会尽量真实还原一个零基础的小白，初次接触小红书运营时到底卡在哪、心态怎么波动，方便大家设计出更贴合新手的课程内容👍

3）单纯想放松一下的朋友。全文不算硬核干货，你就当看个创业小故事打发时间也挺好的~🤭
