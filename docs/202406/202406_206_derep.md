# 如何通过陪诊赚到 124.72 元-拆解

陪人看一次病，到手124.72元，你敢信？

最近拆解了一个很有意思的副业项目：陪诊服务。有人在江苏淮安试水，2021年11月，一单客户付费496元，扣除陪诊员报酬、打车费、保险和提现手续费，净赚124.72元。钱不多，但流程清晰，可复制。

什么是陪诊？就是陪着患者跑医院，帮忙挂号、排队、取药、拿报告、和医生沟通等等。主要服务独居打拼的年轻人、老年人、孕妇、残障人士，以及那些不想欠人情的人。现在老龄化加剧，陪伴需求上升，陪诊正在从新鲜事物变成规范行业，养老机构、家政公司、保险公司也都在入场。

为什么选这个项目？灵感来自《天道》里的一段对话：精神层面的需求，比物质麻醉更暴利，而且没有法律和心理负担。这个“暴利”不在于某个具体项目，而在于人的文化属性——精神需求一旦被看见，掏钱是挡不住的。

具体怎么操作？

第一步，模仿爆款。去抖音、📕、视频号搜“陪诊”，挑出近一年点赞最高的视频。![](img/613f3db4dc2ede5e06c00ba1203be9f3.png)用微信小程序“轻抖”去水印下载，再用它提取文案。![](img/209eee2af26dcfab7ef21ce29f17a514.png)把视频和文案整理成表格，逐个拆解。![](img/1a111c79601c663460c32318cbd75dd9.png)研究不同拍摄形式。![](img/161075e1ae1199224d3b2a5b2a444e70.png) ![](img/79f5a4126e05b60e83894712761aba0a.png)然后戴上口罩，一天跑三家医院，拍100多个素材——社恐也能干。![](img/9d154339b5c477ccac490b18fe23b631.png)打开电脑版剪映，照着爆款视频的结构，用自己拍的素材拼出相似视频。![](img/594a0c04bebc70f186bcace6fe3e3a55.png)多导几个版本。![](img/772227ddd09d8985a1395d92d1559b17.png)还可以故意带点本地口音，更容易吸引同城用户。![](img/d3859bc1f7e43d3917d9b2386ec41739.png)发到抖音、视频号、📕，同时用一个微信号同步朋友圈，方便新好友建立信任，并记录发布情况。![](img/6a58c639915f5eac7507537f4c0cf86f.png)发视频时加上同城医院定位，有机会上同城热门。![](img/fc29dc8af16449604418c5f9c75b885f.png)不同视频类型有不同的引流效果。![](img/c4efb186d63898d3a01fffb7fcec70ce.png)当时的效果：一个视频抖音播放量20万+，📕5万+，点赞1150，收藏880，评论200。![](img/d4618ca97f2f76a17501213fb0f3b927.png) ![](img/d1b19e4c71939696814dbb8f36db983b.png)

第二步，搭建陪诊员网络。加微信有技巧：抖音私信发带微信号的图片；📕用小号发带微信的图文，大号分享小号笔记；视频号简介直接留微信。![](img/95a98eee29d4a4bfe95bc5d4bf99aeec.png)给陪诊员登记信息：姓名、手机号、年龄、性别、职业、优势、可陪诊时间、补充说明，最后发常驻地址定位，用“P+地区+姓名+职业”备注。![](img/5edecdd119417652d9bfdb3f4f6aa71a.png)所有陪诊员登记了定位，就能做出一张陪诊员地图。![](img/9d96409485057c5c2405659a72fb787c.png) ![](img/564a1bde3c22ed4d0c4dbf9f1b2d4e2c.png)客户下单时，按地图找最近的陪诊员打电话确认。

第四步，询单对接。客户来咨询，先了解需求、位置、时间，要身份证买保险。![](img/0bb6ede5d33fce17a61745c970d2059a.png) ![](img/0c75650b870fbb28d9c4a258648febed.png) ![](img/568f6e467e5db67eee441be83e99022e.png)陪诊员那边，先看地图找附近的人，电话确认时间，让其发身份证，提前一天买保险。陪诊过程中收集图片视频素材，方便后续做新视频。![](img/b0e3aef8e539811eff6ecfc921b0d20d.png) ![](img/9a22508950f56d0c759d38f771ebf64a.png) ![](img/ff60ff4553351715d47170190a022e48.png)建群同步进度，发图片、视频、语音，家属直接付医疗费。![](img/c0ed55732b75d7b003b2ca653aaebdff.png) ![](img/4d5c9f7c29c6c2b555035a9f938d38f2.png) ![](img/3a975a78f0fdcd87d9a648db0b6fe5f7.png)

保险怎么买？用平安1天意外险，链接见官方页面。![](img/b17ef06924d5822959270a167d12557f.png)每次陪诊留存图片、视频、录音、保险单，建好档案。![](img/5605b9529841d7ee35f26d8f6470a0f7.png)

再说说给陪诊员的结算话术：半天90元，全天150元。一般看病半天搞定，所以单日预期收入：90元（一个半天）、150元（一个全天）、180元（两个半天）。确认预约后先付15%定金，完成后付尾款85%。接送有3种方式：第一种，陪诊员去接人，一起到医院，再送回家，陪诊员自己返程，客户付4次打车费加服务费50-100元；第二种，陪诊员接人，一起到医院，然后打车送患者回家，客户付3次打车费加服务费30-50元；第三种，陪诊员帮忙叫车，司机负责接送，客户付2次打车费。比如一个案例：就诊人75岁，血压高，半天陪诊费90+接送50=140元，定金21元，完成后付119元，打车和医疗费群里家属直接付。![](img/62897201a12b48d15efdf403343a06d2.png)

利润就出来了：客户付了396元预付款+100元小费=496元。支出一共371.28元：陪诊员215元（半天90+接送50+超时40+返程路费35）、打车费146元（48+45+46+7）、两天保险7.9元、小商店提现2.38元。496-371.28=124.72元。

最后是延伸思考。关于复购，可以学一家公司的做法：把第一个客户的绝大部分利润分给业务员，后续老客户重复消费时，继续给业务员一定比例的奖金。这样业务员越积累越舍不得走，老客户也不流失。同时用规则约束：一旦发现贪污、少报、接私单，立刻开除，累计客户归举报者。团队的销售和客户都可以看成业务员，按首单利润和复购利润分成。

关于拓展渠道，有团队用了这个玩法：分成三个小组，每组7人，要求他们尝试非传统销售渠道，给3个月考核期。结果胜出小组的渠道出人意料，连老板都没想过。于是停掉所有其他渠道，全力深挖这个意外渠道，利润每月暴涨。核心就是：小步快跑，让每一个成员都发挥主动性，用竞争和奖赏驱动创新。

这背后也是MVP法则：做最小可行产品，快速拿到市场反馈，再迭代。先用最低成本验证需求，再优化放大。陪诊项目正是这个思路——先跑通一单，赚到124.72元，再复制规模。

你有没有发现，有些生意根本不需要你自己具备交付能力？你要做的，只是把“有需求的人”和“能交付的人”拉进同一个群。

甚至可以连钱都不经你手。只要跟交付方谈好：第一次成交，你拿纯利分成；后续复购，你拿一个更小的纯利比例。然后，用同样的逻辑去对接那些可能会复购的需求方。这样一来，整个模式是不是就能自己跑通了？

也就是说，你的核心资产不是产品、不是服务，而是“信任”和“连接”。用利益绑定两端，让交付方有动力做好，让需求方有理由持续复购。你不碰交付、不压现金，只赚取属于“连接者”的那份收益。
