# 月嫂行业，使用美团、大众点评评论，生成📕（抖音）笔记话

月嫂老板必看：如何用大众点评差评，批量产出📕/抖音选题？

最近在带一群做月嫂生意的小伙伴搞获客，发现一个很扎心的真相：选题找不对，内容全白费。参考同行爆款是条捷径，但真正可持续的选题素材，往往藏在客户的负面声音里。大众点评和美团评论区，尤其是那些中差评，就是一座没被充分挖过的金矿。细看差评，你既能读懂客户的真实需求，又能顺手把它们变成📕和抖音的笔记选题。

这套打法的SOP并不复杂，核心分五步。

第一步，采集点评。我当时选了北京地区点评量排名前31的月嫂公司，从淘宝买了个采集服务，一共拉出来18000多条真实评价，统一存成Excel。

第二步，筛出中差评并打标。把评分在3.5及以下的评价单独挑出来，逐条丢给AI处理，让AI自动归纳成一个个标签。这一步看着简单，其实是为了后续“先聚拢、再拆解”做铺垫，因为做话题之前，得先把零散素材归堆。期间我还试过把某一条差评单独扔给AI，让它当场生成一个话题，也能给出一些灵感。

第三步，合并一级分类。AI第一次输出的标签特别细碎，上百个类目让人无从下手。没关系，继续让AI来合并，最后压缩成十个大分类。

第四步，拆内容包。把每个大分类对应到具体评论，生成一张“分类—评论”关系表，再根据表把差评分别抽出来，整理成独立内容包。这中间会出现一条差评同时属于多个大类的情况，比如“服务态度与沟通”这个包里的某个评论ID可能重复出现好几次，因为不同的子分类都提到了它，不用觉得奇怪。

第五步，生成话题。有了十个内容包之后，AI就能更有针对性地产出选题了。你也可以套用一些常见热度话题去提问。这里的关键是：内容包里保留评论ID，等真正写笔记时，随时能调出原始评价来佐证，真实感立刻拉满。

拿我的实操举例。在“月嫂服务质量”这个大类下，我让AI根据对应内容包生成“月嫂服务质量中最大的十个坑”，并且额外要求每个坑至少匹配三条真实评论做证明。这样产出的笔记，每一句话都有用户原声兜底，比凭空编内容强太多。

更妙的是，这些中间数据还能复用。同一个内容包能裂变出一堆话题，比如“月嫂服务质量”除了“最大的十个坑”，还可以写“别让这样的十个服务骗了你”。算一下，这一个分类下就有大概436条评论、7900多字，想不多角度输出都难。另外，统计各个细分类的出现频次，还能判断出客户最关心什么、行业目前最差的环节是什么，反过来推动服务升级。

后面还有两件值得做的事：拿着话题和大分类去📕上找同款爆款，用“抄”的办法优化自己的笔记质量，这套技巧在龙哥盟里聊过很多；再就是用同样思路把好评也啃一遍，找出客户真正喜欢的服务细节，给团队指个改进方向![](img/bacc6aa469d0a939d7acbdd58734e5d2.png)
