# 当“反常”的结论，反而成为更合理的判断
作者：龙哥

有一则出自《十日谈》的旧故事，我过去只当笑话看，直到在吴军老师的阅读写作课上被重新提起，才意识到它藏着一套相当锋利的思考方式，现在把它拆开说说。

故事的主角是一个名叫亚伯拉罕的犹太人，他的好友杨诺是天主教徒。杨诺常年游说亚伯拉罕改信，并不断强调天主教的优越之处。

亚伯拉罕并非全然排斥，但他提出想先去罗马实地看看，再做决定。杨诺立刻警觉，怕他亲眼目睹教廷的糜烂后彻底却步，于是极力劝阻他别去。

亚伯拉罕不听，照样去了罗马。归来后，他果然看到了教会内部不堪的一面。令人意外的是，他最终选择皈依了天主教。杨诺百思不得其解，追问缘由。

亚伯拉罕的回答很奇特：支撑天主教的本该是主教们，可他们却在拼命地败坏它，千方百计想让它崩塌。但即便如此，天主教不仅没有倒下，反而越发兴盛。正是这种“被糟蹋到极致却依旧屹立”的事实，让他确信教会有其超越人力的力量，一定是正统而神圣的。

杨诺始料未及，亚伯拉罕竟是从腐败中反推出信仰的坚固。

吴军老师借此点出，这种“以反常为证据”的逆向推理，在投资和工作中极具用处。我们往往只盯着表面的好坏，却忽略了现象背后被强行压制仍存活的韧性。

这种视角让我联想到餐饮里的两个牛肉面品牌。

康师傅牛肉面经营了二十年左右，门店规模始终徘徊在六十多家，却始终没有关门。李先生牛肉面更低调，鲜少出现在市中心商业区，绝大多数扎根于高铁站、交通枢纽等流动性场景，几乎没有营销声量，却已在中国深耕近四十年，门店逼近千家。

按照常规逻辑，这些看似“奇怪”的存续方式本该早已消失。但它们活下来了，甚至活得很好。就像亚伯拉罕的判断一样，正是这种违背直觉的长存，暗示着我们尚未察觉的某种特长或特殊机制在起作用。

这个故事带来的收获很简单：阅读不仅是积累知识，更是在获得一套全新的观察滤镜。就连一本闲书里，也能偷到改变思考习惯的工具。
