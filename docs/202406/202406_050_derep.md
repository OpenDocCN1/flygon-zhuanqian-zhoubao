# 一年多时间，我用知乎把稿费从 60 元拉到 3000 元，还白嫖回家一堆小家电



## 新手知乎实操笔记：一篇稿费涨 50 倍，我是怎么做到不投一分钱的？

短视频当道的时候，很多人会怀疑，写字还有人看吗？做图文平台还有意义吗？需求真的存在吗？

我相信，你心里早有判断。无论是拍视频还是写文章，内核都是内容。知乎至今仍是图文赛道里最值得长期深耕的阵地之一。

我叫陈知意，一年前的兼职写作让我鼓起勇气裸辞全职做内容。在来赚钱社区这段时间里，我见证了很多伙伴的破局，也收获了不少干货分享，今天把这些感恩化为回馈。

在 @陈舟 amber 老师的力推下，我把自己在知乎从 0 到变现的底层打法、进阶套路以及可复制的躺赚逻辑，全部摊开讲清楚。

全文约 6000 字，10 分钟左右读完。
