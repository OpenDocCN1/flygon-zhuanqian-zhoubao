# 大龄职场人-互联网小白，如何做一门 ChatGPT 在细分领域的应用课程，卖了 10w+
作者：龙哥

一个80后学术期刊编辑，原本只是互联网世界里的普通观望者，却靠一门AI细分课程，在四个多月里卖出100多份，总营收突破10万。她是怎么做到的？

她是迪娜，一名深耕SCI期刊行业多年的职场人。2020年加入赚钱后，她尝试过Tiktok航海、📕个人IP等项目，虽然也涨过粉、出过爆款，但因为一直没有想清楚怎么变现，最后都不了了之。她甚至自嘲：那段时间很少打开社群，因为“只要不行动，失败就找不到我”。

转折出现在ChatGPT横空出世之后。她没有追逐泛泛的AI风口，而是把目光拉回到自己最熟悉的领域——学术论文写作。

结合本职工作，她很快做出了一套《ChatGPT辅助SCI论文写作润色》课程，定价999元，4个多月卖出了100多份。后来在老学员的建议下，她又开发了一门面向中文毕业论文的AI辅助课程，几乎没怎么推广，999元也卖出20多份，其中大部分是老带新的复购。

那么，一个非技术出身、不擅长搞流量的互联网小白，到底是怎么把课做出来的？她在拆解中给出了四个关键环节：项目从何而来、适合任何行业的GPT做课方法论、从引流到转化的一整套卖课思路，以及给普通人的避坑清单。

这套打法的核心在于：不是“AI+行业”，而是“行业+AI”。先深扎一个你懂行、有痛点的领域，再让ChatGPT为你所用。恰恰是那些在本行业摸爬滚打好几年的人，最有可能靠这个思路跑通闭环。

如果你也在自己的行业积累了三五年，或者正对AI课程跃跃欲试，她的经验或许能给你不少启发。更多细节，可从她的飞书分享中获取。
