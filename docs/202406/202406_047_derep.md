# 97 年小白裸辞做宠物定制工艺品从零到 200 万的感悟
作者：龙哥

这年头，最让人破防的故事，往往是那些“明明可以躺赢，却非要折腾”的人。

今天要聊的这位主人公叫洛更，97年生人，24岁就已经在头部互联网大厂做到商业产品经理，年薪60万起步，还亲手带出过一个流水高达数十亿的广告产品。这履历放在任何圈子里，都足够闪亮。

可他却在2022年做了一个让所有人意外的决定：裸辞，然后一头扎进了宠物定制工艺品这个赛道。

你没听错，就是那种根据宠物照片或特征，做成雕塑、摆件、挂饰之类的个性化产品。他选择的是自研产品、兴趣电商的打法，从零开始，一个人把单品做到了年销售额接近200万。

很多人会好奇：一个搞广告产品的大厂经理，怎么会想到去做宠物周边？又凭什么能快速跑通？


这份复盘发出来后，评论区也相当热闹。有人觉得惋惜，认为他在产品做大后过于追求完美，其实完全可以做三档产品线：低档走量外包、中档半标准化、高档继续走精品路线，把客户分层管理。也有人表示正好想入局宠物定制，想加🛰️聊聊。还有做布艺品工厂的朋友出来赋能，说自己有一件起订的ERP系统后端，可以48小时发货，欢迎定制类和文创方向的圈友合作。

从这些反馈能看出，这个赛道确实有热度，也有空间。但洛更的分享最打动人的地方，是他没有只讲成功，而是把收缩、放手的过程也摊开来讲。

这种勇气，比那200万更难得。

如果说他的经历能给我们什么启发，大概是：平台的光环从来不是护身符，真正决定你能走多远的，是你敢不敢跳进未知里，去试错、去复盘、再去迭代。

哪怕最后没有一路高歌猛进，光是那份“把过去彻底想明白”的劲儿，就已经值回票价了。![](img/21de372a77ea1f441c613f7316831ae1.png "None")
