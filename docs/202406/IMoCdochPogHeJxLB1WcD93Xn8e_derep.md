# 一周18,000+营业额，拆解手艺人如何利用节日成交

一到节日就发愁，怕发了朋友圈没人看，怕做活动显得自己很功利？这篇文章或许能给你一点勇气和方法。

我是广州的独立摄影师，没有自己的工作室，和合作方共用场地，用一次才算一次成本。现在引流、成交、交付基本都靠我自己，修图、化妆、助理、社群运营这些重复性工作外包出去。今年我给自己定了个方向：主攻前端流量，后续成交和交付都找专业的人合作，这样才能把盘子做大。

先看两张这次活动时的截图：![](img/df6a8843408bd823c89ece70500aebf2.png)![](img/d9e2feab0eafcf9ed9417f88c7bf837b.png)

为什么我会盯上“520”这个节点？因为节日是最天然的收单理由。活动目标有三个：一是批量成交，短时间内把一两个月的订单量收进来，后续少焦虑；二是现金流更稳，用预收款来支撑后续发展；三是定期把种子用户收进来，用户需求可以被激发，收单其实就是开启正向循环。

这次的数据：13位客户，总营收18187元。接下来拆解一下我做了哪些事。

一、活动开始前的准备，比活动本身更重要

1. 选品：只卖最好卖的那个

我有很多摄影产品，但每次活动只选一个主力款。标准就两条：第一，客户点单最多的爆款，我这次选了A套餐，因为80%的客户首选它![](img/5c9eedbaeafb2f379e1eb393209fb5f6.png)；第二，价格要在中间档，最好卖，我没选最低价引流款，因为去年中秋卖过，这次换成标准利润款。记住：高利润款难卖，别在活动里硬推。

2. 海报：必须回答这三个问题

海报做不好，成交直接打折。我的海报要回答：第一，为什么现在买最值；第二，为什么选我不选别人；第三，为什么必须马上行动。

怎么体现“值”？比如套餐原价1599，活动价1399，若只写便宜200，没吸引力。我把福利二、福利三改成30秒视频花絮+6张底片，这些平时都没有，并标注市场价值，客户瞬间感觉自己赚到了![](img/d2c73e149aabf4274223e6be2965b820.png)。怎么体现“为什么选我”？写清楚现在买和以后买的差距：现在1399，以后2697![](img/31de5734f62caaf3353fac6ea8eb0e2c.png)。怎么体现“马上行动”？明确截止日期：某天前是这个价，之后就恢复原价![](img/73f834a2e342567f7e1a28e51f8ec9ca.png)。

3. 冷启动：先让场子热起来

人都爱凑热闹，新店开业都要找人来排队。所以我活动开售时会用小号或朋友先做几个虚拟咨询和订单截图，把场面搞得热热闹闹的，让真实客户觉得“这么多人买，应该不错”![](img/010fa75566f8567123680389a1e7ffdf.png)。

4. 素材：把“证据”备齐

卖摄影产品，本质是卖效果、卖信任。我提前准备了这批素材：

- 拍照前后对比图：反差越大，越能激发“我也想拍”的欲望![](img/8626321b4307dc28f2683445eb97c2d7.png)；
- 真实客户反馈：用户只信用户的嘴，商家自夸不如客户一句话![](img/8cf58bea3a1a75c11e3d3e51d01e172d.png)；
- 订单截图：证明有人买，顺便制造从众感![](img/22474c7fc33f540930ba0b07a06d68a7.png)![](img/63e063da2766dcad35f701343d8e0a61.png)；
- 常见Q&A：把高频疑问做成统一回复，一次发圈解决所有人的顾虑![](img/0450172c70158f80e5e4ee5fb1803308.png)![](img/17902d8fbb069a41e2e42603a44f191d.png)；
- 人设故事：从成长经历到职业波折再到产品，让熟悉你的人更懂你，让陌生的人开始信你![](img/593208519edcc0cf266f65d001acce09.png)；
- 爆款作品合集：爆款意味着大众审美，反复发、换着花样发，不会错![](img/b7e59c730677bfda66ca4dce64392e2d.png)![](img/48381d1dd1b0908d19e1101d5a7879e6.png)；
- 发圈SOP：把所有素材排成表，定好闹钟，到点就发，不靠灵感![](img/0f28538935474e851556f2ceffa502a2.png)。

5. 朋友圈四件套，全是成交入口

- 昵称改成“活动进行中”![](img/6637feef587dfa8da836d947e37e9550.png)；
- 背景图改成活动名称和价格![](img/bd45515f3d510719058526dae1900f05.png)；
- 拍一拍改成活动截止日期![](img/ee6b85ff07d8bc484ec59fa37cccdb46.png)；
- 简介也改成活动卖点![](img/7d59382521d6abfc8fc27f19a44591ef.png)。

这些细节看起来不起眼，但能降低大量沟通成本。

二、活动中：被看见，才有可能被成交

发圈时我习惯让用户点赞，然后发小红包，这招在活动时特别好用。我会在那些点赞过的朋友圈下留言，植入活动卖点和力度，等于把广告精准投给一群对你内容感兴趣的人![](img/a47a689960c88b0b41d786ade4862447.png)![](img/26390664221761651b72bff4362926b8.png)。

群发要有技巧。那种一上来就“打折了快来买”的话术，只会被拉黑。我采用的方法是“抬高对方身价”：比如“你是我的一类好友，有好资源我会第一时间通知你”……先让人舒服，再给福利，反感率会低很多。素材里还总结了三种群发法：好奇吸引法、占便宜心理、抬高身价法，我用的是第三种![](img/808357dbdfa1ab649b45b9532d677a5c.png)![](img/164f0b3145e0bc36834c11e6854ab9fc.png)。

客户来咨询，我会记住一个目标：不要被客户带着跑。先问清楚需求：你为什么想拍照？想拍出哪种感觉？过去拍照有没有不愉快？这次最想要的是什么？![](img/dde3f2d252bd3e8d4bb59535140c2be9.png)![](img/2a3137d9f4c1c2db20608354782bbc73.png)然后针对他的顾虑给解决方案，最后给一个非买不可的理由，比如“这是520特别套餐，活动结束就恢复原价”![](img/0ee71b08baa4e9b6e55ec2dd0ca05f91.png)。

晒单也要会“讲故事”。客户拍生日照、纪念日照，我就结合这些使用场景来写文案，让潜在客户看着看着就想起自己也该拍了![](img/b3948b22f93c957f64ece675749d6376.png)。

三、活动后：最后两天，才是成交高峰

前五天每天晒单两次，最后两天我每天至少晒四次，因为之前的所有铺垫都是为了最后冲刺。但我不会硬广，而是在晒单里夹带一些干货或客户故事，哪怕被屏蔽也能接受![](img/20e28cc646e527b89bf4b5cf94883a8e.png)。

同时，在每条软广、硬广下面留言，写上活动力度和截止时间，尤其点赞多的朋友圈，都要去“占楼”![](img/62fe3139e51f1ddf1b4123157935a389.png)![](img/617c1694210d3accc9da86512cc0c9f2.png)。

群发两次，用不同的内容，在不同时间段发。因为朋友圈的触达率有限，只有“朋友圈+群发+社群”同时组合，才能让更多人看到![](img/d213c9baffbba58b52f1d1a7f89ef312.png)![](img/82d8c5423b8c40ca80bed890ce643673.png)。

跟单时，只看高意向客户：需求明确、顾虑已解决、最近主动咨询过。拍照是感性消费，过了那个热乎劲，再发优惠也很难打动人。

四、你可能关心的几个问题

- 精力不够做社群？裂变和成交最好分开做，一次集中做一件事。
- 群发怕被讨厌？按上面说的“抬高身价+给好处”的模板来，就不会让人反感。
- 活动做几天？5到8天最合适，太短没效果，太长消耗耐心。
- 不会做海报？平时多收藏好海报，拆解它为什么吸引你，然后把核心卖点写出来，找设计师执行。
- 怕被朋友屏蔽？活动前先预告，让不想看的朋友留言，拉到单独分组。不过我个人不太介意，所以没做这步。

五、下次一定要补上的坑

这次有个摄影同行给了我新思路：同城异业联动。他联合咖啡、宠物、美业等主理人一起抽奖，每家贡献福利，互相导流到自己的群和🛰️，一次活动让同城潜在客户都看到你![](img/491c45343b5a2bc71e29bd0dde308ac8.png)。这个玩法我下次一定要试。

另外，这次以纯成交为主，没有设计太多裂变环节，等精力够了，我会专门做一次裂变活动。做活动也要及时收单，就像稻谷熟了就要收割，客户的需求总需要一个出口，不在你这边解决，就会被竞争对手解决。不如摆正心态，让收单来得更主动。如果想做社群，可以搞一个免费咨询/拍照风格诊断的快闪群，限制名额，在群里做分享，哪怕不成交，也在客户心里种下一颗种子。

六、最后，说点扎心但有用的

做活动真的不难，难的是心里那关。我这次活动其实拖了一个月，总觉得难、不好意思、怕丢脸。后来想明白：我需要钱，也需要通过做事来获得成长。迎难而上，把问题拆开一个个解决，比原地退缩强一百倍。搞钱这件事，需要野心，也需要行动力。

希望我的复盘能给你一点启发。

大大方方收割自己的劳动成果，本来就没什么可羞耻的。这是我最近想通的一件事。以前我一提到“营销活动”就有点放不开，总觉得像在自卖自夸。可后来我发现，它和种田是一回事：一年四季，你得先播种，再花时间去杂、施肥，最后才等来收获。赚钱也一样，平时每一次累积、试错和调整，都是在为最后的结果打底；活动一来，其实就是那个等待已久的丰收期。把眼光放长远点，心态立刻不一样了。

如果你也在拖延边缘反复挣扎，可以试试这个办法：不要只盯着眼前的困难，先闭上眼，想象一下“这件事已经做成了”的画面。画面里有什么细节？你会看到谁？心里是什么感受？把答案想得越具体，你反而越容易站起来行动。我就是靠着一个清晰的画面，直接迈出了第一步。

另外，我一直很相信“越分享，路越宽”。每次活动收官，哪怕事情暂时告一段落，我也会强迫自己坐下来，把过程拆开、复盘，然后写成文字发出去。有人问我怕不怕被偷师，我说真不怕。因为写复盘的时候，表面看是在帮别人避坑，实际上是在帮自己把脑子里的乱麻一根根理顺，那些容易被忽略的关节，都会在这个过程中现出原形。这些攒下来的经验，就是未来遇到问题时，帮我最快找到出口的底气。

以上，就是这次活动的复盘分享。如果你也在筹备活动，欢迎来聊；有拿不准的地方也可以问我，只要我能回答，都会尽量答。最后，谢谢你有耐心看到这里，希望这篇内容真的能帮你少走一点点弯路。
