# 为什么大多数人很难把钱赚到手？
作者：龙哥

翻了很多人的真实经历后，我发现卡壳的地方 surprisingly 差不多，都是这几类思维陷阱在作怪。

一、总觉得自己专业不够，必须等一个完美的体系才肯动。等会系统化、等会再精进，结果窗口期早就过去了。

二、太在意面子，觉得某些方式很 low、配不上自己的身份。姿态放不下来，机会就被别人先拿走了。

三、扎进的都是人人都在喊“可以做”的赛道。看似正道，实则早已内卷到红海，普通人根本分不到汤。

四、没有生存压力就绝不入场。口头上很有兴趣，真到要动手赚钱时，却总觉得时机还没到。

五、习惯性观望，先研究先观望。好像研究本身就能产生价值，拖到项目凉了才后悔没早点试。

六、还没赚到一分钱，就开始算天大的风险。先想最坏情况、先做风险评估，把启动的勇气提前耗尽。

七、看问题只盯难度，不看机会和回报。越难越不敢碰，越有价值的赛道越被自己过滤掉。

八、视野被自己的舒适区框死了。只在自己擅长的那一小块里找项目，看不到更广阔的可能性。

说到底，赚钱难很多时候不是能力不够，而是这些心理关卡挡住了行动。
