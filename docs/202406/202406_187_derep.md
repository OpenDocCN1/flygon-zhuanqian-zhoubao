# 不想真人出镜？我用“数字分身”做带货，居然还能这样玩
作者：龙哥



## (42 赞)白嫖党如何克隆自己做数字人带货视频

作者：Rio

日期：2024-05-27

大家好，我是 龙哥。一个爱折腾、爱说大实话的 AI 玩家。

这期想聊聊数字人+视频号带货，也是我第三次航海复盘的记录。

一开始报名，我是想练真人出镜的种草功夫。教练很给力，上游选品、下游佣金结算全给配好了，学员只要乖乖对着镜头录内容就行。

可我到了第 7 天，还是选择“跳船”。

为什么？因为这跟我的铁律——“能用机器绝不上真人”——直接冲突。航海课要求真人实拍，再加上群里一堆人在搞“空调清洗剂”“调味酱”，我看着就觉得：这么多人挤同一个赛道，忙活半个月估计只能拿个“最佳演员”证书，根本没肉吃。

这7天我没闲着，一直在琢磨一件事：能不能造一个“我”的克隆体，让它替我去拍？我想让它怎么说，它就怎么说。平台真要搞活体检测，我就扫自己的脸，它也拿我没辙。

这么玩的好处，我盘了一下：

1. 口播稿想改就改，不用烧脑硬背
2. 语音语调随意调，嗓子不用受苦
3. 做矩阵很方便，同一个形象搭配不同音频视频，能裂变出一堆原创内容
4. 成本极其友好，不买服装、不买器材、不买绿幕，一台带 N 卡的电脑就全搞定

最近风向标里有个特别火的例子，彻底验证了我的思路——黄宏生院长。

![](img/b11c0076837fb6b86d78c1a8897ad3d7.png)

他们团队用 AI 数字人技术，给黄院长做了大量分身，场景各不相同，一口气铺了近 20 个账号，总流量直接过亿。变现路数也很清晰：评论区往橱窗一引，卖课走起。这种玩法特别适合做 IP 矩阵，一套人设复制 N 份，能顶好几个团队。

![](img/6b6726c8f8870ce4cb32d1d23ede6d0d.png)

市面上做数字人的付费软件不少，不过最近剪映也放出了新功能，单个形象 49 元/月，算是比较良心的价格了。

![](img/00a43b1ded2bc801f4f842df2cba460d.png)

但咱是谁？咱是“能不掏钱就坚决不付费”的白嫖党。所以我还在继续探索，看看能不能折腾出一个“完美”的数字人，一分钱不花。
