# 一个道观住持被逼出来的“淘宝双图”国学引流术

我是丙恒，一个住庙道士。说出来你可能不信，我最近被流量折腾得够呛，最后居然靠“野路子”破了局。

去年年底，我终于从师爷门下出师，被派到一座道观当主持。这两年，我的互联网国学做得还算不错，以前主要玩抖音、📕，可现在越来越力不从心。毕竟咱不是专职干流量的，眼看着线上获客越来越难，我只好自己捣鼓各种偏门方法。

其中一套偏门方法，就是淘宝的“双图”玩法。简单说，就是利用淘宝商品展示机制里的一些小窍门，避开常规限制，把真正对国学有兴趣的人，精准引到私域来。起初纯粹是死马当活马医，没想到还真跑通了。

既然跑通了，就干脆拿出来分享。反正我们这个行业，能分享的东西真不多。

不瞒各位，还有个小故事。有个道观主持，因为完全不懂前端获客，被市场狠狠教训，实在没辙了，才让懂技术的朋友帮忙琢磨出这么个办法。没错，那个主持就是我。

再聊聊评论区里说过的一些事。有同行看到我有宗教教职人员证书，说：“你这是持证上岗啊，太厉害了，手头有大把流量可以合作。”也有人打趣：“你本人就是个流量入口。”

但现实是，这行想合作起来非常难。市场太乱了，劣币驱逐良币。你认认真真做一场法事，人家挂50块一场，这还怎么打？更离谱的是，现在摆张桌子、供个神像，就敢说自己有后端实力；或者跑庙里拍几张照、找个道长加个微信，出来也自称“大师”。线下香客客源其实一直很稳定，但线上想找个靠谱伙伴，真的不容易。

也有人在评论区问：能不能你管后端，我们管前端？这事儿以后再说吧。
