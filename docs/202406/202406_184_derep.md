# 一个人闷头干了100天，从欠20万到月入4万+，她做对了什么？

大家好，我是轻舟。现在我主要靠AI写作和线上游戏陪玩这两个方向吃饭。

很多人可能想不到，疫情那年我辞掉了上市公司的亚马逊运营岗，回到长沙。从游戏陪玩做到语音厅厅主，收入像过山车——有时一个月就几百块，有时能冲到8万，但到最后，反而欠了20万。

去年龙哥盟会员日，我背着债加入。这一年里各种项目都试过、踩过坑，也算慢慢摸出了门道。过完年后，我从零开始啃一个新项目，还是一个人干，到现在不到100天：还掉了6万债，剩14万没还，最高那个月收入是4万多。

这一路有经验，也有教训。今天把这段经历写下来，分享给圈友。真的很感谢赚钱这个平台，让我接触了大量项目，也终于找到了现阶段最适合自己的方向。写得不好的地方，大家多包涵。
