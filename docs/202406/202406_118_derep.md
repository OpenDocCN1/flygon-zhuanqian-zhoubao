# 放下月薪两万的工作裸辞三个月后，我单月做到7万+，却只想说一句早该走了
作者：龙哥

大家好，我是龙哥。之前干了三年程序员，在大厂里做一个安静的螺丝钉。

今年3月5号，我递交了离职申请正式开始创业。算到今天6月5号，整整三个月。最直接的结果是，上个月的收入突破了7万元。但说实话，我现在的情绪不是兴奋，而是懊悔——懊悔自己为什么没有更早一点迈出这一步。


希望我的经历能给正在犹豫要不要出发的你一点参考。
