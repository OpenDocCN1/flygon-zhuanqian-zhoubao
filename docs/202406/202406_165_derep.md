# 工具在手究竟是使用还是驾驭？我从码农到创业者的破局笔记
作者：龙哥



## 用技术，还是让技术为我所用？在互联网路上我的成长与突围

署名：乔帮主

刊发：2024-06-05

各位好，这里是乔帮主。88年出生，算是在互联网圈子里沉浸十余年的从业者。说实话，“老兵”这个称呼我不太认同。上回参加线下聚会，主持人在台上就给我贴上了这个标签。

放到当下，95后、00后创业者占据主流，我的背景在他们眼里自然显出资深。标签甩不掉，但这份阅历恰恰成了差异化的价值点。

我习惯拿自己开涮，戏称是IT界的屌丝。过去带技术团队时，还自嘲是领着一帮屌丝的老大。外界对屌丝多是贬义，我的判断是任何事物都具备两面性。

从早期纯技术岗到现在的创业实践，我总结出一条自我要求：敢于自我调侃，正视短板，放大长处。只有先搞清楚自己是谁、处在何位，才可能把个人价值兑现。

近期深度试用AI落地的过程，让我对技术与人的关系有了新的体悟。关键分歧在于：我们到底是被动地调用工具，还是主动地操盘工具？一字之差，结果天差地别。结合自己从写代码到做生意的轨迹，我想把这些感悟梳理出来和大家聊聊。
