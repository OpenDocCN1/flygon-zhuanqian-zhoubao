# 优势是牢笼

很多人以为，把小公司压垮的，是那些做得不够好的地方；但真正让大企业走下坡路的，恰恰是它最引以为傲的强项。

小公司天天盯着自己的短板，小心翼翼补漏洞，反而躲过了不少坑。可一旦做大了，手里有了王牌，就容易放松警惕——毕竟优势嘛，谁会觉得它有问题？但恰恰是这份笃定，让人一步步走进自己设下的圈套。

说到底，不管优势还是劣势，本质上都是我们给自己画的框。所谓强弱，只是框的两面。真正的出路，从来不是守住某个标签，而是敢于打破这个框，哪怕它看起来再光鲜。

记住：牢笼不分好坏，关住你的，就是牢笼。打开它，才能活。
