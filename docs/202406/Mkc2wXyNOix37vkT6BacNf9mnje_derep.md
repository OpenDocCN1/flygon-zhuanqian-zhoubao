# 《0基础新手小白实体创业开自助鞋店，一年半变现七位数》

从微商转型实体，00后姑娘一年半开出3家自助鞋店，还想把经验分享给你

大家好，我是大眼，一个00后创业者。做实体店一年半，我已经在三个城市开了自助鞋店，同城累积了一万多客户，带出了300多家学员门店。很多人一听到“实体”两个字就摇头，觉得大环境太难，但我偏要用自己的经历告诉你：实体项目，照样能做出漂亮的成绩。

2022年冬天，疫情最严重的时候，我反而决定开店。当时我快大学毕业，内心就一句话：不想给别人打工。我每天刷各种创业项目，最后目光停在“自助鞋店”上。这个项目最吸引我的是：投入不高，几万块就能开，操作起来也不复杂。去年我还把自助女装加进店里，做成了自助鞋服集合店。那阵子发抖音，几乎每条都是万级播放，平台全给我推同城流量，效果特别猛。

其实我的创业史不算短。16岁开始折腾，运气好踩中过小风口，16到20年那阵，我在🐧上卖减肥产品，赚到了人生第一个六位数。21年以后🛰️封号变严，我就转战🛰️，卖美白、祛痘这类产品，做到了品牌里最高的代理级别。后来眼看这条老路在走下坡，加上马上毕业，我便下定决心转型，去看看实体生意。

我当时把早餐店、餐饮店、奶茶店、甜品店全研究了一遍，得出的结论是：对新手小白来说，都不太友好。早餐店要凌晨起来，我自认吃不了这个苦，面食技术我也不懂，加盟的话供应链基本都是半成品，投资还高；餐饮嘛，我一个女孩子既不了解也不感兴趣，有点名气的火锅店动辄几十万起步，疫情当下拿这么多钱去冒险，想想就慌；奶茶店很难绕开品牌加盟，杂牌基本做不起来，好位置早就被人占了，设备、人工、水电算下来，回本遥遥无期，亏钱的一大把；甜品店更现实，光靠着“爱吃”根本撑不起一家店，审美、耐心、细心我都不太自信。

所以我就想：有没有一种店，投资低、不累、回本快、不用请人、新手又能快速上手的？想着想着，自助鞋店这个概念就冒出来了。

为什么我更看好实体店？因为实体能给人实实在在的信任感，看得见、摸得着。比如卖鞋，舒不舒服到店里一穿就知道，当场就能成交。互联网项目我也做过，刚起步时确实甜，但到后面引流越来越费劲，基本都在吃老顾客的老本，再耗下去老顾客的热情都会被我耗光。实体店的包容性也更强，素人草根都能做起盘；互联网项目反而需要网感、认知和思维，门槛真的不低。

而且我不觉得实体店会没落。就像餐饮做得好吃，不宣传也有人帮你介绍；理发店、美甲店价格合适、技术到位，也有大把人买单；服装鞋店性价比高、老板娘会搭配，照样能做出成绩。好的环境里有亏钱的人，坏的环境里也有赚钱的人，实体店一定会经历一轮优胜劣汰。你看现在流行的勃肯鞋、洞洞鞋、北面冲锋衣、破洞裤，十几二十年前早就火过一遍了。流行是个轮回，实体也一样，一定会等来自己的春天。

当然，不管是实体还是互联网，前提是你得真正热爱。足够热爱，才愿意全力以赴。

再说说自助鞋店为什么能跑通。对比传统鞋店，我的优势非常清晰：第一，无人售货，省掉人工费。传统鞋店老板要么自己守店，要么请人看店，成本高还累。我这边顾客自己选、自己试、自己扫码买单，我在家看看监控就行。第二，没有囤货压力。传统鞋店一个款式要备好几个尺码，100个款可能就压了500双鞋，资金全被库存绑住。我这边卖多少补多少，货架上的货就是仓库里的货，第一批我只拿了200多双，一天就卖空了，补货继续卖，良性循环。第三，款式更新快。传统店一个季度才上一次新，我这边根据顾客反馈和售卖情况灵活上新，顾客每次来都有新鲜感。第四，价格是真的狠。传统鞋店一双动辄上百，冬靴卖到200多；我全场明码标价99两双，一年四季不变，还承诺断底断面包换新，便宜也把服务做到位。

更关键的是，现在的顾客很不喜欢被导购跟着，很多人进了店浑身不自在，恨不得马上走。我的自助鞋店简直是为社恐人群量身打造：没有推销，没有跟随，想试多久试多久，不买也没关系。所以年轻人喜欢，中年人也喜欢。

那很多人会问：网上卖鞋的那么多，为什么要来你店里？第一，我不跟电商玩价格战，再便宜也有更便宜，我玩的是新模式，顾客花两位数买到的鞋一定远超过这个价值，而且很多是品牌鞋和独家货源。第二，不是实体不行，是只做线下的实体不行。我的店能直接试穿，质量摸得着，几十块钱的价格比网购还划算，还不用等好几天快递。第三，淘宝能帮线下店引流吗？你能说服那些不爱网购的三四十岁、甚至年纪更大的顾客线上下单吗？实体店的价值就是扩大客群，把线上线下一起做起来，当然更吃香。

废话不多说，直接拆解我的开店投资SOP。

门头招牌这块，灯箱加发光字一共花了1600。灯箱上直接写“无人售货 自助鞋店”，路过的顾客一眼就懂，拍照发抖音也很有话题。有人问“你怎么卖这么便宜”，我都会说：公司统一配货、统一管理，就是这个模式。遇到还价的就回：公司是要查账的，统一价格，少卖几块钱我们会扣保证金。![](img/6adbd87db06c6cd7b64606d4cd4c7c06.png)![](img/e2d09e5d1d120613e117e0774df5bd55.png)

鞋架要准备6个，35到40码，一个码一个架子，按码数分区摆放，顾客自己就能找到尺码。号码牌随便找当地广告公司做就行。架子我从淘宝买的半成品，自己组装，一个200多，6个总计不到2000块。![](img/f35f0e27ea7aca03b880546b24fc06bf.png)![](img/441f0bc57cdb3dbacbe64eb3921952ff.png)![](img/978d116894288e45f93553ceabdf1635.png)

店内还要定制横幅、号码牌和广告牌。全场99两双任选，再加上“鞋盒请自取”“购物袋请自取”“店内已装监控”这些提示，顾客一进门就懂规则。号码牌贴在对应的鞋架上，方便顾客自助挑选。![](img/85275bb054f51dd4f1911aa537796264.png)![](img/f236d3d00a666806cdbaaa8824cc7228.png)

价格表是必须的，印好“无人售货”和价格，每个鞋架都要贴上，不断强化自助购物的认知。![](img/23e42c63236a04729a3273dab680ac39.png)

首批货品也很关键。我第一次进货拿了8箱，总共不到6000块，平均一双才20多。卖99两双，毛利有一半。来看看刚铺好货的样子，和一天被抢空的样子对比。![](img/3c1bc7ac5c09e0999c79c10e9b1763b2.png)![](img/0df404ec5a65d3b03850d01636d0fc79.png)![](img/e8ca2b48d48b5b66335031a9d0646afc.png)![](img/7607bbb6e41f063930b8b39a6137b9b2.png) 我自己都没想到会火成这样，开业第一天线下就卖掉200多双，那一刻彻底感受到实体店的爆发力。

算一笔账：我的总落地成本3万出头，三个月不到就全部回本。具体明细是：房租1600、押金1000、转让费18000（收银台、沙发、监控、镜子、空调都包含在内）、招牌灯箱1600、鞋架1950、货品6000、定制购物袋245、定制广告牌180，合计30575。回本周期大概三个月，当时正好是11月，赶上冬天旺季。房租每月1600，电费每月300，每天固定成本大概64块。我平均一天能卖20双鞋，拿货价多数20多、少数30多，按99两双、综合利润50%算，一双能赚24块左右，一天利润450到500。换句话说，每天只要卖出3双鞋，当天成本就回来了。因为无人售货，人工费为零，一个月扣除损耗和房租水电，纯利润稳定在1万到1.1万。一般店铺的回本周期是3到6个月，具体还是要看投入和经营情况。

我没有停留在1.0版本。22年99两双确实打爆了市场，但23年我主动调整：改成69一双、129两双，品质、款式、质量全面升级。为什么？因为99两双要保持50%利润，拿货价就只能压在20多，很多好看的款式拿不到，也容易出现售后问题，长期下来很伤信誉。实体店拼的是口碑，我要把这份事业一直做下去。调价以后，看似单价涨了，但顾客的选择变多了，品质也更好，我还谈下了更多品牌鞋和档口鞋资源，拿货价控制在20多到40多之间。最后结果很明显：营业额上升、利润上升、口碑越来越好。

后来原来的小店已经装不下我的野心，我直接租了一个100平的铺子，做成了全网首家自助鞋服集合店。这里有一个很重要的理念：你的东西可以卖得便宜，但你的店一定不能显得廉价。地摊货为什么只能卖地摊价？因为没有灯光、没有陈列，哪怕老板真没赚多少，顾客潜意识里还是觉得“它就该便宜”。我恰恰相反，花不多的钱弄出很有质感的效果，69块的鞋、几十块的衣服摆在高级环境里，顾客看到的第一反应是“这店装修这么好，居然卖这么便宜”，反差感一下就有了。我还加了自助衣服和包包，明码标价，顾客买鞋的同时随手带走衣服，客单价和成交率都提高了，包包也是69元任选。![](img/a30b1d77002bb3480688f431d6ad1868.png)![](img/5e60aca7d5995de0eee290e04dc0f681.png)![](img/28503fc932c20532aa050a7ed3ee9a39.png)![](img/dd52220f4a273c6457c3a49397f08387.png)![](img/5da4595ca15855c656ee91afc91a30d5.png)![](img/ca9aca5e12fee46152479c6ae92f2142.png)![](img/a10548036818bdb2d10280acc85f2714.png)![](img/a283d381fd01b84e698446ec4d437a59.png)![](img/5a41115c92a4660394fca7668fd29cbe.png)

最后分享一个很实用的抖音同城引流技巧。封面一定要把“首家自助鞋店”“99元两双自助鞋店”这些字打得大大的，让用户刷到的时候不用点开就能明白你是干什么的，好奇心一上来，播放量自然就上去了。就像这张封面一样。![](img/7aae32ab9545a241110510c33b2ee23e.png)

至于话题和文案内容，也要多花心思，要贴合同城用户的需求和关注点，让平台一眼就能把你的内容推给周边的人。

这就是我的实体创业故事。我不是什么天才，也踩过坑、走过弯路，但自助鞋店让我看到了线下生意的可能性。如果你也在犹豫要不要做实体，希望我的经历能给你一点信心和方向。我是大眼，咱们下次接着聊。

开实体店，选对方向很重要。自助鞋店这种模式，光是“自助”两个字，就已经自带话题。发抖音的时候，记得把“自助鞋店”和“当地地名”一起放进话题里。为什么？因为这个组合足够新鲜，很多人根本没见过，平台一看也明白要帮你推给同城的人，两个关键词一叠加，播放量自然就上去了。

视频一开口就要说清主题：xx首家自助鞋店，无人售货，自助选购，社恐人士放心冲。别觉得这几个字太简单，越简单越直白，越直白越有用。

接下来，背景音乐也得用心。别光顾着挑自己喜欢的歌，要站在用户的角度选。节奏感强的DJ舞曲，或者正在抖音热歌榜往上冲的歌，都很合适。很多人在刷视频时听到好听的歌，会愿意多停几秒，这几秒一留，完播率就有保障，系统推热度的时候也会更给力。说到底，音乐不是选你爱听的，而是选用户爱听的。

视频内容也不能总是一个套路，多换几样形式，爆款的机会更大。

一种是vlog/创业日记。这种适合拍一分钟以上的长视频，只要内容做得够好，观众愿意看，平台自然会给流量。平时店里忙了些什么、自己想了些什么，都随手拍下来。素材不用一天拍满，攒上几天，再挑需要的拼在一起，最后看着素材写文案，就像写日记一样。

另一种是采访新闻/娱乐类。这种玩法最近很常见，其实是变着花样给大家安利你的店，容易上热门，也能把同城客户带出来。直接用剪映，搜“新闻采访”“娱乐采访”，会有很多模板跳出来，都不用自己从零做。

这些娱乐模板完全可以拿来直接用，把自己的素材和文案放进去，就是一套新鲜风格的宣传。

还有一种就是探店。用第三方的视角带大家逛你的店，同城的人会被锁定，店铺位置也介绍得明明白白，线上的粉丝看完就可以直接到店消费。

再说说📕同城。

发笔记一定要带本地定位，这样系统会把内容推给附近的人。话题里再把城市名加上，别人搜索相关词的时候，也能找到你的笔记。

![](img/010925880b2849c06d3203cafa0380ac.png)

封面更是关键的曝光入口。一定要把“自助鞋店”“99元自助鞋店”“69元自助鞋店”这几个字大大方方打在封面上，让人一眼就知道你在卖什么。📕是信息流页面，封面不够突出，别人连点进去的欲望都没有。

![](img/aea62f6f8572d54011f8c66c3ded3f85.png)
![](img/0a69320bf4985bb8c5b54281035861df.png)

我在封面加字的时候，一般会用黄油相机，字体好看又精致，视觉效果会加分不少。

标题文案也要会抓人。📕只显示标题的第一句话，所以这句话一定要勾起好奇心。文案要跟封面配对，封面也提前想好。我有一条百万浏览的笔记，至少引流了3000多人。其实那句话看着很简单，但我在里面藏了三个点：先说“小县城”，比起大城市、市区，这个词更接地气，直接抓住了下沉市场的人；再说“自助鞋店”，很多人听说过自助餐、自助售卖机，偏偏没听过自助鞋店，这4个字一下子就抓住了兴趣；最后补一句“太无语了 只剩下2双鞋”，意思就是这家开在小县城的自助鞋店竟然火爆到只剩两双鞋。你想想，这样的标题，你会不想点进去看看吗？

所以说，标题要突出你想表达的核心，把“自助鞋店”讲清楚，让人知道你正在做一件新鲜事，并且对这件事产生好奇，他们就会点进来。

线下也一样有引流方法。在店里做一块🛰️二维码广告牌，尺寸做大一点，旁边写上“加店主🛰️有优惠”或“有礼物送”，顾客看到有好处，就会愿意加好友。这些加到🛰️里的人，就成了你的私域客户。

再说一个很实用的做法：多做几个账号，多平台一起发。🛰️视频号、抖音、📕都安排上，形成矩阵。这么做是因为我们不知道哪条视频会突然火，多一个平台、多一个账号，就等于多一个机会。同一个作品放到不同平台上，并不会被限流；就算没成大爆款，只要有质量，每个平台都能分到一些流量，带来稳定的转化。

当然，不同平台的玩法不一样，内容也要调整。除了同步视频之外，📕我会额外发图文；抖音我运营两个号，一个专门记录创业日记做线上引流，一个专门拍店铺日常做同城引流。线上、线下互相配合，利益就能最大化。既然把实体店当成了全职，那就要舍得花时间多拍、多剪。刷到同行拍得好的作品，也要多琢磨，把别人的亮点借鉴过来，再变成自己的创意。想比别人做出更好的成绩，就得比别人付出更多行动。

接下来聊聊新手创业的心里话。

第一，资金不够，别轻易开实体店。我指的不是暂时紧张，而是口袋里连几万块都拿不出来的人。贷款或者借钱创业，我本人非常不建议。每天都有想开店的人来找我，但被我劝退的也不少，因为开店这件事，真不是人人都适合。

一个人的状态，真的会影响风水。你每天精神饱满、信心满满，做事情就会顺利很多；你天天唉声叹气，就会觉得什么都不顺。没有足够资金的人，大概率也沉不住气，容易变得急功近利，最后小钱看不上，大钱赚不到。当然，也有人白手起家、从零翻身，但不管创业的盘子是大是小，你都要问自己：有没有资金、有没有生意头脑、有没有能力、有没有执行力、能不能扛住压力？现在，你占了几条？

创业总要有过程。新手如果手里没什么钱，又对自助鞋店这个项目有兴趣，完全可以借我一臂之力，少走弯路、控制风险，起步会稳很多。我能帮你理思路、给方法，让你快速落地、尽早站稳市场。当然，适合自己的才是最好的。

反过来，如果你手里有周转资金，又有开店理想，那自助鞋店真是个不错的选择。有资本撑腰，做事也会更有底气。

实体店还必须懂线上获客。美团、📕、抖音，总得占一个。很多人一听短视频就觉得难，但只有把线上获客做起来，你才真正有竞争力。

现在的行情下，开实体店却不会做流量，约等于已经倒闭了一半。文案怎么写、画面怎么拍、脑子怎么想，全都有门道。流量为王的时代，找对核心方法，选对项目，赚钱真的没那么难。当然，最根本的，还是要看你自己的悟性、思维和执行力。

关于心态和执行力，我最想说三个字：不要等。

有句话说得好：人生不像做菜，不能等所有材料都备齐了才下锅。等你什么都准备好了，机会往往也结束了。我们总习惯说“下次吧”“有空再说”“以后一定”，可如果非等到最完美的那一刻才开始，很可能永远都开不了头。

所以，先完成，再完美。别老是纠结怎么做才万无一失，先干起来。想太多全是问题，做起来全是答案。不等待、不拖延，真的能少错过很多机会。你不需要先变得完美，才觉得自己有价值。
