# 做一个社区圈主，普通人也能副业过万？

你有没有想过，一个看似普通的“社区圈主”，也能让普通人把副业做到月入过万？这年头，圈子文化和社群玩法越来越火，一个有人气、有信任感的圈子，不仅能带来稳定收入，还能让你摆脱“打工”的束缚，实现时间自由。像大学里的校园墙、各种同城社群，都在干这件事。

今天聊的正是这个方向，而且它可能很适合一大批普通朋友，帮大家打开收入的新思路。操作门槛并不高，核心就两条：愿意执行 + 热心肠。甚至性格内向的人反而更容易做出色。
