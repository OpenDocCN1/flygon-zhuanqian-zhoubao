# 名片、工牌、传单想让人真的看？先搞懂它们到底是干嘛的
作者：龙哥

很多时候我们做一些看似很小的物料，根本没去想清楚它的核心作用，就直接开干了。实际上，每一样东西只要你摸准了它的本质，用途就自然清晰了。

先说名片。名片说到底就是用来让人知道你是谁、怎么联系你的。以前它还肩负着保存信息的任务，现在基本没人会真的留着了，见完面客套一下，出门就扔了。

认清这一点，设计思路就有了。

第一点，信息要足够醒目。有些设计师为了追求高级感，把姓名、公司、电话都做得细细小小，其实拿到手的人根本看不清。关键信息一定要放大，越直白越好。名片还可以兼顾宣传功能，把你们的核心业务、能解决什么问题，直接印上去，让它本身就是一则小广告。

那怎么让别人不随手扔掉呢？给它一个留下的理由。比如在背面印一张价值五万的优惠券，客户为了这张券就会保留下来，以后有需求时自然会想起你。

再说工牌。工牌同样是信息载体，最核心的功能就是让人一眼认出你是谁。所以部门和姓名必须最大化呈现，照片反而是次要的点缀，别本末倒置。

最后是传单。传单也是在传递信息，但传递的是广告信息。它最大的痛点是留存率极低。所以设计前要先代入受众的场景：人家可能在逛街，可能在赶地铁上班，根本没心情细看。

因此传单的设计逻辑只有一个：第一眼就要抓住注意力，迅速产生兴趣，让人愿意多看一眼、甚至愿意带走而不是直接丢进垃圾桶。

以上这些思路，我都在《卖货真相》里详细展开过，有兴趣可以去翻阅。
