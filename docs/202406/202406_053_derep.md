# ('怎样的人才能被称为老大', (2, 13))

很多人以为，老大是头衔最大、位置最高的人。其实，能被大家从心底叫一声“老大”的人，靠的是实打实的胆识和担当。拢共分三条：

第一条，在所有人都拿不定主意的时候，他敢一锤定音。哪怕前路没人走过，他也敢把决策权握在自己手里。

第二条，责任像烫手山芋时，人人躲还来不及，他敢伸手接。真出事了，不推诿、不甩锅，先把担子扛稳再说。

第三条，旁人觉得没戏的资源、人脉、路子，他总能弯道超车，想法子盘活，把不可能跑成可能。

所以，老大从来不是自封的，是一件事一件事做出来的。能做到上面这三条，自然会有人心服口服地认你当“老大”。
