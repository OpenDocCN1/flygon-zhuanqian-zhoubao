# 四个月创收上亿美元，4399 靠小游戏迈入出海 2.0 阶段
作者：龙哥

4个月，海外收入破亿美金。4399这波操作，给“小游戏出海”打了个样。

这件事最让人意外的点在于：在大家扎堆做重金大制作的时候，4399反而靠着中轻度游戏，在海外市场杀出了一条路。仅一个季度多一点的周期，它就实现了超过1亿美元的收入。

它的逻辑其实不玄乎：把国内已经被玩家验证过的爆款产品，搬到一个新市场里重新运营。那些轻量、易上手、又容易上头的玩法，天然适配海外玩家的碎片化场景。加上它对不同市场的精细化发行，这些游戏很快就有了自己的用户盘。

尤其值得注意的是4399的底气来源——它在日韩市场积累了多年，比很多后来者更懂当地玩家的偏好。这套长期沉淀下来的发行能力，一旦叠加到产品出海节奏里，竞争优势自然就被放大了。

某种程度上，4399已经不再是“卖一款算一款”的出海姿态，而是进入了有系统打法、有稳定输出的“出海2.0”。四个月破亿美金，也许只是它这套玩法的前奏。
