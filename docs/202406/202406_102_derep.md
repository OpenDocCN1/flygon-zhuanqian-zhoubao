# 一个人带娃还想有被动收入？这位全职宝妈在闲鱼卖虚拟资料，每月稳定爆单
作者：龙哥

你敢信？一个全职宝妈，每天一边带娃一边用手机闲鱼卖虚拟资料，居然把“睡后收入”做成了常态，还总结出了一套新手也能复制的打法。

这位宝妈叫飞儿，是龙哥盟连续四年续费的老会员。用她自己的话说，21年刚进来的时候纯纯小白一个，连娃都还没有，如今孩子都会打酱油了，自己也从“小小白”熬成了“大白”。

为什么突然想分享这个？她说得很实在：在社群里待久了你会发现，真正的新手其实非常多，很多项目看着热闹，真上手了反馈慢、见效难，做着做着人就散了。可闲鱼不一样，它对新手特别友好，门槛低、操作简单、出单快，很容易给人正反馈。

她特别建议那些刚起步的小白，想找练手项目，完全可以拿闲鱼试试。先尝到甜头，有了信心，才更有底气在副业这条路上走下去。

至于她是怎么一个人带娃还靠闲鱼虚拟项目实现“睡后收入”爆单的，具体操作细节都整理好了，戳链接就能看到完整版经验。
