# 群发售实战复盘：操盘50+场、拿下400万+业绩，这份全流程拆解请收好

各位赚钱的圈友，大家好！我是彩卉。很幸运能在赚钱这个优秀的平台分享自己的实战心得。一路上，特别感谢理白老师与靠谱老师帮我精准定位、持续托举，还手把手打磨稿件、指导发售，他们是我自媒体路上的恩师；也感恩芷蓝姐的答疑解惑，以及小鹿对分享稿的宝贵建议。

做知识付费或实物产品的朋友都清楚：不管产品是什么，渠道永远是命脉。👸号、朋友圈、直播、社群，各有各的价值。而群发售的厉害之处在于，它能把这些触点全部串联起来，在极短时间内建立用户认知、占领用户心智。操作起来也很顺手：先用社群公开课做钩子，快速讲清产品价值；再用直播、社群分享持续互动，拉近距离，转化率自然就上去了。

群发售几乎是每个IP的必修课。无论你卖的是实体产品还是虚拟产品，每年认真做上1-2场，就能把沉睡的私域用户重新激活，为业绩带来可观的增量。

今天，我把自己跑过50多场群发售、累计创造400W+业绩的底层逻辑和完整操盘流程，一次性分享给各位，希望能帮大家在转化路上少走弯路。

整个分享将围绕三个板块展开：

- 什么是群发售？为什么值得做？
- 群发售全流程一览
- 分阶段拆解：预售筹备、预热发售、追售复盘

具体来说，第一阶段是预售+筹备。核心动作有五步：先明确发售的产品梯度（建议2-3个）；接着搭建公开课的标题与大纲；然后启动预售；同步准备多种福利；最后多做社交、广结人脉，请更多伙伴一起托举你。

第二阶段是预热+发售。首先做好人员分工；然后建群预热，把氛围炒热；接着正式发售；最后通过一对一私信谈单，推动成交。

第三阶段是追售+复盘。在正式发售后继续挖掘意向用户的价值，同时对整场活动进行数据复盘，为下一场做足铺垫。
