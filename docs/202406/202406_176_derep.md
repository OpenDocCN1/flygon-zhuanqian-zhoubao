# 如果你需要工作和社交，那不建议你取一个奇怪的🛰️名
作者：龙哥

只要你还得上班、还要跟人打交道，🛰️名这事，真别太随意。

我平时常帮人拉群，可总有些朋友的头像和昵称是一堆特殊符号，连名字都显示得模模糊糊。想拉他进群，我根本找不到他的标签，只能盯着聊天记录找入口。那位朋友自己可能觉得挺酷，但对我来说，确实要多花不少工夫。

更现实的问题是：🛰️好友动辄上千，大家找人全靠搜索。如果你的昵称是一串图标或者生僻字符，别人输入不出你的名字，翻遍通讯录也找不到你。这不等于是给自己设了一道隐形的墙吗？

如果从品牌传播的角度看，这种昵称其实很吃亏。营销的本质，说到底是帮顾客省事、让顾客觉得值。想做到这一点，至少要压低三种成本。

第一种是钱包上的开销。最直观的就是价格，再看后续的使用花费。比如电动车比燃油车跑起来省钱，所以跑滴滴的都愿意开电车。

第二种是心理上的负担。比如一个在意形象的白领，可能不愿意用平价护肤品，怕在同事面前显得没档次。选品牌，也是在选一种自我认同。

第三种是行动上的力气。顾客要下单，得先记住你的名字；如果你的名字难记难认，他可能转头就忘。再比如订外卖，你三公里内没有门店，再想吃也只能放弃——不是东西不好，是拿到的成本太高。

说回🛰️名。我始终觉得，最稳妥的就是用真名，或者朋友日常相处时叫惯了的称呼。这样别人一搜就能找到你，不用猜、不用问。

要是你想保留一点个性，那至少选个能写出来、能叫得响的词，中文英文都没问题。但如果你常住国内、工作环境也是中文，小众语种或花式符号，还是尽量绕开吧。

毕竟，名字是拿来喊的，不是拿来破译的。
