## 复盘好评率 90%，教你如何从 0-1 打造一门简单的训练营

作者：曦子
日期：2024-06-03

嗨，我是曦子，一名做了 4 年的设计师兼插画师。

转折点是在被鱼丸邀请做了一期表情包教学视频后，内容被更多人看见。借助这个契机，我用设计能力为不少个人 IP 操刀了海报、表情包等衍生物料。

下方是生财上那期表情包视频教程的链接：

累计完成 40 多个设计实战后，水龙哥给了我一个建议：不如做一期训练营，把经验系统化，帮更多自媒体 IP 解决美学上的困扰。

我后来复盘发现，这个痛点非常真实。很多自媒体 IP 手里有社群、也有知识付费产品，视觉物料要么自己硬着头皮做，要么想找设计师外包。外包的成本对中小体量的 IP 来说压力不小，自己做又总卡在没有专业的方法论上。

正是看清了这个缺口，我决定立刻动手去筹备一门设计训练营。事实证明，这一趟走得相当顺畅。

下面是我整场营的复盘笔记，希望能给想做第一门营的人一些参考。
