# 📕店铺矩阵起号注意事项

开了近200家📕店铺，我才摸清矩阵起号的门道

我是曜文，又来和大家聊📕开店了。今年五月份，我又一口气新开了近60家📕店铺，到现在手里差不多200家了。一路走过来，踩的坑真不少，所以今天把几个最重要的事项整理出来，打算做矩阵开店的朋友可以少走点弯路。

一、注册阶段：设备、电话卡和注册环境

设备不用太贵，流畅不卡就行。我自己用的是无面容的iPhone X，64G，大概600块。安卓机要特别当心，最好别碰矩阵工作室淘汰下来的机器——那种设备发笔记浏览量容易卡在1，真遇到这种情况，多半是设备有问题，赶紧换设备、换IP。

电话卡优先选营业厅的厅卡，广电、移动、电信、联通都可以，一个人最多能办20张，直接找营业厅业务员上门办。有些地方一个运营商三个月内只能办3张，那就拿家人名义办。另外，部分注册卡也能注册账号，但大多数没流量，行不行要自己实测。

注册环境非常关键。同一个地点，一天最多注册3个号，再多就会跳验证，触发风控，发笔记也没流量。想稳妥一点，就换地方、换IP注册：比如在A地点半小时注册3个，换到B地点再注册3个，基本不会触发风控。注册完先把资料完善，再发2条互动笔记做测试，两条记得隔2小时，别连着发。数据过了200，就可以开店或实名；数据不好，第二天再测；如果隔天小眼睛还是不到20，去检查设备和注册环境。查不出问题的话，坚持发爆款互动内容，或者把📕App降一降版本。

记住，注册时不能同地点、同IP批量来，必须换地点换IP。如果不赶时间，同一地点一天注册3个号，每天都这么操作，风控也不会找上门。

企业店或者个体店，开通需要交600元认证费，但收益也很明确：能绑定主理人。一个主理人可绑定3个实名号，所以1个企业店加3个主理人，就相当于4个号。主理人号出的单都会汇总到企业店，客服也统一在企业店接，管理起来省心。账号之间流量互不干涉，就算企业店主体被限流，主理人号也照样正常出单。

企业店认证有几个细节：同一个法人，同一天内别认证超过3个店铺，超过会触发风险提示，要等两个月后才能再认证。一个月内慢慢注册一般不会触发风控，但有些地区仍会提示，最好多准备几张不同法人的营业执照。店铺昵称前面可以加字母，避免店名重复，否则审核时间会被拉长。一张营业执照能注册2个店铺，第一个店审核通过后，第二个店通过得快很多。

个人店就更简单了：一张身份证能开多家，不过一般控制在25家以内，再多容易跳支付风控。每个店都需要一个实名，注册流程和企业店一致。

二、起号阶段：账号怎么分配、怎么测品

先说说账号分配：企业店一组3个号，一个运营能管2组；个人店也是一组3个号，一个运营能管6个号。这个配比是按运营每天8小时工作量、从内容产出到分发来算的，如果是成熟运营，可以再加号加设备。人手充足的话，把剪辑、素材、分发拆成独立小组，做成流水线。比如，剪辑每天剪10组素材，同时收集20个爆款标题做对标；分发负责手动发布、观察主页数据，再把数据反馈给运营，运营做优化。

新店的发展节奏，一般要经历权重期、提升期、爆发期，整体7到20天。有些号出生就高权重，一发笔记就是几千上万的小眼睛；有些号只有几百。高权重号出爆款快，但这种号能遇到的概率很低，大部分号需要先把权重提起来再带货。

第1到第7天是起号关键期。权重低的号别发太多，笔记控制在3条以内，先看数据能不能过200，过了再慢慢加量。这七天本质是在测垂直类目，哪个品数据好，就顺势多发几条，爆款概率会明显提高。但一定只测垂直领域的产品，如果今天发这个明天发那个，账号标签就乱了，根本起不来。

第七天之后，基本能判断账号适合什么类目，再冲着该类目的爆品去测。同时盯紧对标账号和垂直类目的异常值，一旦发现爆款苗头就赶紧跟上，爆款率自然能拉高。

三、运营阶段：限流、发布时间和设备环境

账号限流常见四种情况：
1. 同IP下多账号被限流——换IP，再把📕版本降下来试试。
2. 发布太多骗点击的内容——等14天处罚期过去，会恢复正常。
3. 发擦边球或违反平台规则的内容——基本无解，直接换号。
4. 突然之间被限流——找客服申诉，多次申诉，至少3次以上并上报工单，通常能恢复。

发布时间也要讲究。建议让账号错峰发，别都挤在同一个时间点，也别用定时发送。每个账号的爆款时间窗口不一样，需要自己慢慢测。

设备环境方面，尽量一机一卡，厅卡直接开流量。没有流量的话，就办一张可以全国跳IP的流量卡。手机超过50台时，不要把设备都堆在一起，否则有概率影响账号流量。

说到底，做矩阵账号只是个消耗品，只要这笔账算得过来，能盈利就行。
