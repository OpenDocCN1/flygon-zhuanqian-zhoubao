# 企业🛰️单向好友清理神器：RPA 批量自动删除方案

这批无效联系人不仅拉低私域触达效率，让运营数据失真，更要命的是，企业🛰️现在按外部联系人规模计费。养着一堆删你的人，等于白交钱。

为了解决这个问题，我们梳理了一套针对企业🛰️的 RPA 自动化方案，专门用来批量识别并自动剔除单向好友。

这套方案的核心是一套基于机器人流程自动化 RPA 技术定制的轻量工具。它模拟人工操作逻辑，自动巡检你的企业🛰️通讯录，判断哪些好友已成为单向关系，并一键批量删除，帮助企业把通讯录瘦身、把成本降下来、把运营效率拉回来。
