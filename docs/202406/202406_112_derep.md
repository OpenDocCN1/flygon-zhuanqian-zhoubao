# 冯仑：大哥的逻辑

江湖上常听人讲，真正的“大哥”不是靠嗓门大，也不是靠出场时前呼后拥。冯仑先生总结过一套极简的“大哥逻辑”，一共就三件事：给大家指明方向，出事了顶在最前面，最后还得掏钱善后。

说白了，指道，是在迷雾里给众人画出一条路；扛事，是风雨来临时自己先站出去；买单，是收尾时不躲不闪，把责任和代价一并接住。这三样缺一样，所谓的大哥人设就会塌方。

评论区里还有一条高赞补充——牺牲。这大概是在三项之上再加一层：真到了关键时刻，连自己的得失也能押上去。这样一来，大哥不再是个头衔，而是一种担当的集合体。

转发给那些你心里真正佩服的人吧。能做到这三条，哪怕一条，也已经很了不起。别忘了那句补充：指道、扛事、买单，再加牺牲，才是完整的答案。学习+1。
