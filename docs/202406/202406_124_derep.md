# 夫妻搭档做事业，怎么把“家”变成真正的合伙
作者：龙哥



为什么要专门聊夫妻档？

说两个现实。

第一，我服务过的少儿培训机构老板里，差不多一半都是夫妻在扛。偶尔他们会找我吐槽，互相埋怨对方不给力，还让我当裁判。看多了才发现，问题都出在“不职业”上。赚钱圈里讲个人创业、超级个体、团队创业的很多，讲夫妻搭档怎么玩的很少，我就补这一块。

第二，我自己就是从2003年起一直夫妻档走到现在。好在哪里，卡在哪里，怎么相处，我都亲自踩过。我们带过大团队、带过小团队，也经历过就两个人365天24小时黏在一起的日子。我的客户也多是小老板，超过一半是夫妻档，他们的困局我看得太多了。

先说结论：夫妻档做一个事业，配好了是降维打击。

第一，夫妻同心，其利断金，而且利益分配天然简单。亲兄弟都可能反目，合伙人也容易反水，朋友闺蜜也吵得稀里哗啦。夫妻不一样，钱基本进同一个口袋，很少为分钱撕破脸。这一点是其他组合比不了的。

第二，两个人互补直接补上小团队最缺的“左右手”。我见过太多教培夫妻，一个管教学教务，一个管招生税务对外，一个唱红脸一个唱白脸，效率直接拉满。自己单干的人都要里外全扛，想甩锅都找不到人。夫妻档好处就是，可以把最信任的人当专业分工对象。像有些机构老婆管内部，老公扛外部，配上两三个优秀老师，一年稳定做到50-70万含薪资，在当下已经很扎实。

好处说完了，毛病更致命。夫妻配合不好，还不如一个人单干省心。很多夫妻档不是被市场干掉，是被“不职业”拖垮，最后连公司带家一起散。

所以夫妻档是一把双刃剑，想玩转，以下5点必须守住。

**1. 在公司里先卸掉“老公老婆”的身份，分工到岗不甩锅**

生意场上没有家庭辈分，只有岗位。能干就干，不能干就滚蛋。很多夫妻公司就是坏在身份混淆。

我见过太多老婆心情好时是前台教务，对方说啥都行；心情不好就拍桌子变老板娘，老公这个老板瞬间作废。老板娘永远比老板大，尤其耍无赖时。员工看在眼里笑在心里，夫妻看在眼里吵在心里。

家里的习惯不能搬进工作。家里吵公司的事，公司不要拿家里的气来发。真过不去就出门吵，吵够了再回来。清晰的边界才是职业。

**2. 钱必须分清楚，发工资、发提成，比什么都重要**

这是我见过最多、最伤人的问题。机构收款码、公户都放老婆那里，老公一分钱没有，连工资提成都没有，天天忙得像狗，最后连应届生都不如。

人需要体面。你让一个老板连买瓶可乐、给父母转2000块都要伸手要，他怎么有尊严？怎么有动力？

我2022年在昆明处理过一个案例。女校长抱怨老公半年没斗志，摆烂黑脸，连家长上门都不接待。机构从四五百个学生跌到快倒闭。根源就是老公手机里从来不超200块，钱全在老婆手里。

后来我建议：夫妻档一定要把工资和利润分开算。机构赚的纯利润可以存着买房，但基本工资和提成必须双方都发。结果女校长给老公发了2000底薪加提成，自己也领一份。没多久老公开始主动地推谈单，两年又做到500人左右。

日常开销用工资，大的目标用利润存。两个人都体面了，事业才有劲。

**3. 必须同步进步，否则认知差会杀死感情**

刚开始同心同气，做着做着一个往上走，一个想躺平。一个人拼命学习，一个说“那么累干嘛”，最后沟通变成“你傻逼听不懂，我牛逼你别管”，机构废了，家也散了。

夫妻档不是员工，不顺眼不能开除。价值观撕裂最可怕。我观察下来，十个散伙的夫妻档里有九个是老婆上进老公想躺平。老婆要做500强，老公觉得一年20-30万就够了。

唯一的解法是同修。一起上课，一起学习，一起抬头看更大的天空。我的线下课一直主推夫妻同行，对方半价，就是这个道理。

**4. 情绪要管住，阵线必须统一**

公司里别用个人喜好指挥团队。有些老板娘一言不合当场发飙，老师直接跑路。更糟的是在前台、招生现场为旧账翻家里的账，甩电话甩教材，现场所有人都尴尬。

公众场合一定要一条心。夫妻不同心，员工不敢留，孩子也学不到稳定感。情绪不稳定，干脆别合伙。

**5. 决策权要提前定好，关键时刻听谁的**

小公司没有董事会，最后拍板的还是两个人。意见不一致时不能靠脾气大，而是提前约定好：听谁的。听更理性、更负责任、用数据说话的那个。

我们公司大的决策都是我拍板，比如2022年5月解散还在赚钱的招生团队做转型。用赚钱衡量不如以前，但幸福感和内心富足提升很多，从未后悔。

总结一下，夫妻档一起干是最省心的组合之一。利益同向，分工互补，信任成本极低。我们现在日对夜对，一年365天都在同一件事上，有商有量，孩子也一起看着长大，挺踏实。

找到能一起做事的另一半很难，找到了真的很幸运。
