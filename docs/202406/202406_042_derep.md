# 赚钱思维课图谱：37 张竖屏思维导图，解锁赚钱新思维
作者：龙哥

这段时间，赚钱圈里又出现了一份让人眼前一亮的共创成果——《赚钱思维课图谱》，总共37张竖屏思维导图，由圈友罗卜带领11位小伙伴合力打磨而成。

说起罗卜，常逛赚钱的人应该不陌生。去年418，他正式入圈，从此一头扎进竖屏思维导图的世界。这些年他在社群里陆续分享了四百多张导图，圈子里不少人都觉得，论把竖屏思维导图玩得明白，罗卜算得上数一数二。也正是凭着这门手艺，他不仅得到了许多大佬的认可，还成功破圈，连续两期担任思维导图特训教练，最后成为赚钱航海家中的一员。

这一回，他没有独自完成，而是带着一支11人的小团队，把赚钱思维课的核心内容梳理成37张竖屏导图。用他的话说，就是希望尽一点微薄之力，让看到的圈友多少能有些收获。

所有成果都已整理好，放在飞书文档中，感兴趣的朋友可以直接前往查阅。

最后，感谢每一位参与共创的小伙伴。一个人的导图是风景，一群人的导图才是图谱。
