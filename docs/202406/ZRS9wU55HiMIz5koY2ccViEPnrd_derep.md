# 从三无大学生到大学三年赚了30W，我是如何利用朋友圈实现逆袭蜕变的？
作者：龙哥

我叫静文，一个00后，大学三年，赚了30W。

看到这里你可能以为我要讲什么逆袭爽文。但我想说的，其实是一个关于“朋友圈”的故事。

三年前，我是大家口中的“三无大学生”：没资源、没背景、没学历。普通二本，工薪家庭，从小城市走出来。这样的人设，放在哪个赛道都算不上漂亮。

但我今天可以很坦诚地告诉你：我翻盘的杠杆，就是朋友圈。

大一寒假，我花了一笔钱加入一个社群，开始学打造个人IP。那时候我才意识到：原来自己是可以通过朋友圈被看见的。于是我坚持每天更新，也就是从那时起，机会开始找上门了。

那年6月，我被一家上海初创公司的老板选中，获得了一个线上实习的机会——给大学生做成长咨询，进而推荐课程产品。说实话，我能接住这个机会，不是因为我多厉害，而是那段时间我一直在付费学习、每周和同频的伙伴打电话交流、帮他们解决问题。这些积累，在机会来的时候刚好能用上。

实习期间，我一个月的咨询电话能打60多个。单价360的产品，一个月卖了30多份。你可能会好奇，我既没学过销售，也不会写👸号，不会做直播，凭什么能成交？

答案很简单——在每次电话前，我都会让对方先去看我的朋友圈。

一个人的朋友圈，就是了解他的最快通道。如果对方提前通过我的文字和日常建立起了信任，那电话沟通的效率会高很多。如果没有朋友圈，哪怕你花15分钟讲自己的故事，对方也不一定买单。

那一年，我也做过很多蠢事。比如实习期间，我的朋友圈就是清一色的晒单转账培训广告，硬广打得飞起。结果可想而知——好多人把我屏蔽、拉黑。甚至有付费用户离开我。那个时候我懂了：因为产品来的人，也会因为产品离开你。

后来我决定彻底转变思路。

有天夜里我反复问自己：你开朋友圈，到底是为了赚钱，还是为了给靠近的人带来点什么？

最后我给自己写下三个词：美好、能量、价值。

从那天起，我不再晒单，很少发硬广。我开始记录创业日常、写我的思考、分享我的生活。把自己全方位地摊开给用户看。我不再把朋友圈当成卖货的工具，而是当成送给世界的礼物。

转变之后，神奇的事发生了：收入没有减少，反而越来越多。

印象很深的是一次分销写作社群，单价599元，我5天时间靠朋友圈卖了40多份。很多人没怎么聊过天，直接转账来付费。

还有我自己推出的私教项目，原计划第一期收10个人，结果来了20个。朋友圈训练营招募时，我定的目标是30人，最终也真的招募到30人整，而且只用了两天。

后来陆续有人和我说：“静文，我每次心情不好就翻你朋友圈，看完觉得生活还是有盼头的。”还有很多人会发来长长的告白小作文，说被我的文字影响、被我的状态感染。

说实话，每次看到这些话，我都觉得这一年多的坚持值了。

很多人问我：到底发什么才能让别人喜欢？我的答案很简单——“把你的成长和生活可视化。”

我连屁大点事都会发到朋友圈。今天吃了什么、见了什么人、做成了一件什么小事、学到一句什么话，都值得被记录。不是要活给别人看，而是你的每一天，都值得被认真对待。

如果你也想开始做这件事，送你三个心法：

第一，别急着赚钱。先把该做的做好，沉下心去扎根、学习、实践、分享。赚钱只是结果，不是目标。

第二，相信相信的力量。你只有先相信自己能成，你才可能成。我办私教第一期本来只打算收10个，结果来了20个。做训练营我想着能收30人，最后真收了30人。你给自己设定的上线，往往就是你能走到的终点。

第三，发心向善。当你不是只冲着钱去，而是想着怎么利他、怎么给更多人带去价值、怎么把自己修好活好，钱自然不会缺。

这是我在这条路上走出来的最大领悟。

现在回头看，经营朋友圈这一年多，带给我最大的改变不只是经济独立。而是整个人被重塑了。

以前的我，又矮又胖，衣服只图便宜，合影永远站在最边上。为了改变这种状态，我一个学期每天跳2000个绳，雷打不动。学着去收拾自己，不追求白幼瘦，只求在自己原来的基础上变得更好看一点。形象变了，发在朋友圈里，别人看你的感觉也确实不一样了。

这就是我的第一个蜕变——形象上的蜕变。

第二个蜕变，是经济上的。靠朋友圈，我实现了大学期间的经济独立。我拿着挣来的钱去破圈、付费学习，不断拓宽认知边界。很多有价值的资源和信息，都是必须要付费才能接触到的。免费的，反而最贵。

第三个蜕变，是人脉和资源。因为会写朋友圈，我被企业老板邀请去做内部分享，在上千人中脱颖而出成为粥左罗老师的写作社群合伙人。线下见到老师、一起吃饭，也有了越来越多深度信任我的学员伙伴。

有人问我，这一路是不是特别顺利？说实话，没那么光鲜。

我也曾在深夜崩溃大哭、没钱的时候抱着被子在被窝里发抖；也曾在电脑前一边啃馒头一边单手打字赶课件；也曾在凌晨写完了当天该发的那条朋友圈才敢睡。

大一开学时，妈妈塞给我一千块钱，低声说了句“家里现在没钱，你先拿着用吧。”这句话我记到今天。也就是从那一刻起，我在心里对自己说：一定要在大学里做出点什么。

所以，你现在看到的那个在朋友圈里闪着光的静文，不是天生如此，而是一步一步走出来的。

创业这一年多，我发了上千条朋友圈。从一个发硬广被拉黑的人，变成很多人每天都不忍心错过的能量源泉。从变成“成交好难”，到实现“不销而销”，我用了接近两年的时间。

如果今天你正处在迷茫期，不知道该做什么，我只有一个建议：从好好发朋友圈开始。去爱你的用户，发自内心地帮助他们，不保留地分享你的成长，真诚地表达你的观点。

你吸引的从来不是所有人，而是和你同频的那一小部分人。他们喜欢的是你的真实、你的能量、你人生的另一种可能性。

我不是什么传奇，普通人也有普通人的活法。每个人，都能写出属于自己的故事。

如果今天这篇文章，能让你开始重视朋友圈这件事，那就够了。
