# 我做的 Agent 智能体上了 Coze 扣子官方推荐之后的心得
作者：龙哥

最近用 Coze（扣子）做的 Agent 智能体，居然连续两次被官方推荐上了热门榜单，还顺手拿下了“通往 AGI之路”活动的最酷 Agent 奖。

说实话，最大的感触就是：Agent 简直是大模型的“增强版插件”。如果说大模型还在 1.0 时代，那 Agent 已经一脚迈进了 1.5 时代。

靠插件和工作流的组合，Agent 把大模型原本的边界又往外推了一大截。大模型能做的事，Agent 做得了；大模型搞不定的活儿，Agent 也能接得住。比如，搭一个基于私有知识库的问答机器人，或者一键把抖音文案扒下来改写成📕内容，还能自动配图。
