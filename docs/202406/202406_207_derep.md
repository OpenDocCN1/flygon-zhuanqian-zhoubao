# 义乌工厂批发怎么靠小红书SOP导流？一天吸引300+批发大户的复盘

大家好，我是做获客引流的阿甜，义乌创业者，当年创业亏过钱，还意外上过微博热搜第一名。今天这篇，算是我做义乌工厂批发项目的完整复盘。

如果你是那种想当倒爷、做中间商，或者在B端批发这条路上折腾的人，这篇内容值得读完。尤其是你手头有货，想做电商，或想在小红书素人铺量打粉，同样可以拿来参考。
