这次邀请到的是@阿甜，她靠“小红书铺量+导客资”的打法，当天就给微信加了300多个批发大户。想链接她，可以直接加微：wx+ 77296403。

她的玩法并不复杂：拉了24个账号，批量铺内容，发出去就能来精准客资。如果你手里刚好有货源，想做电商，或者想走小红书素人铺量打粉，这篇很值得看完。

# 一、项目概况

这个项目本质上是帮义乌工厂获客，主打产品是亚克力串珠。阿甜负责在小红书持续产出内容，把想拿货的人吸引过来，再导到工厂老板的微信。老板看到好友申请直接惊了，连说“人太多了”。

![](img/63d8d63761e0317ae79b3b630373a613.png)
![](img/31b5655bf8ca98cd9506cec9086b4281.png)

当时是2月份，“打粉”这个词还没流行起来，大家更习惯叫“引流获客”或者“倒客资”。其实阿甜最初并不看好这个方向，因为她手头还在做数字人项目。她也想过把账号直接交给珠子老板，但老板实在没空运营，也没时间学。最后账号还是由她代管，只是她把置顶的珠子内容撤掉了，因为咨询量太大，接单接到手酸。

哪怕她后来有点“消极怠工”，来找她的人还是不少，甚至有5位客户专门跑到义乌线下看货。一直到5月，都还有订单陆续进来。

# 二、项目是怎么来的

这个项目能成，纯属偶然。阿甜楼下正好有一家珠子工厂，她平时常去看货，和老板关系处得不错，本来她也有心做义乌倒爷。

义乌最不缺的就是工厂和产品，可很多外地创业者缺的正是货源渠道。她想做的事情很直接：把上游工厂和下游找货的人接起来，自己在中间赚点信息差。

有一次她随手把仓库场景发到小红书，笔记直接跑到了百赞，后台私信全是来问“怎么拿货”的。这让她意识到，只要把人导给工厂，自己拿中间介绍费也很香。

那时候是2月，打粉概念还没普及，但她已经嗅到机会了。

# 三、快速验证：24个账号铺量

为了验证这个“不出镜、成本几乎为零”的打法，阿甜找了24个伙伴一起测试。她先写好了一套SOP，又拍了一大堆珠子图，让大家照着发。

结果很直接：发了就肯定有客资。要知道，如果去1688烧钱引流，一个月轻轻松松烧掉几万块。把这笔账算给义乌老板，他们心里比谁都清楚。

![](img/ecb264e990b0284e3bf1baca0c76f1f7.png)

具体SOP她放进了飞书文档。因为中间涉及直播和线下实操，案例部分没有完全公开，但90%的框架都在里面。文档里还有几百张珠子图片，拿到就能直接用。

# 四、遇到的坑

咨询量一旦上来，新问题也跟着出现：客户会反复追问材质、颜色、价格、重量。几百种珠子摆在面前，总不能让他们自己挑到眼花。

所以一定要做标准化，把选择范围压小，减少反复沟通的成本。

# 五、产品调整

义乌工厂不缺产品，但大部分工厂当时只有两种卖法。这里有个信息差：很多工厂只做批发，零售基本都被“二道贩子”拿走了。如果你直接做C端用户，工厂反而很欢迎，而且你根本不用压货，不压货就不用先掏钱。

![](img/9f8bbb87e3f713d8cd9934b592632635.png)
![](img/7dbfc625f6dc220d0de4e6d6bf8dd77d.png)
![](img/c31c7630f1ee19acc70e181430db42a7.png)

阿甜手上当时有两块业务：

一个是批发：单色、单珠、单品，一包200颗。工厂几百种珠子摆出来，看得人直眼晕。
另一个是直播：一包300ml，单包29.9元，主要靠直播出货，除了1688以外没开其他店铺。

但两条路跑着都不太舒服。批发单量太大，价格不好把控，重量、运费都得反复问老板；零售单价又太低，分品麻烦，而且直播之外就没什么流量，拼多多还得烧钱，工厂压根懒得折腾。

所以最合适的还是批发，但要做面向小红书轻创业人群的小批量批发。

后来阿甜发现，很多宝妈和副业人群也想加入，单色单珠的批发模式对她们来说门槛太高。于是她重新设计了一个199元套餐：3000ml混珠小批量批发，价格大概是抖音同规格的一半。

她还带着测试的24个伙伴在小红书开店，主推这个199套餐。

# 六、把链路再拉长

如果只卖产品，赚的只是产品差价。199元的套餐，阿甜单笔也只能赚几十块，再分给24个伙伴，利润就更薄了。

所以她决定往上再走一层，最好还是零成本，比如知识付费。

她给素人创业者做了一套SOP，设计了8种人设打法：串珠创业、电商创业、朋友圈售卖、摆摊达人等等。很多人都不会发小红书，她就把服务链路拉长，额外教大家怎么做小红书。

素材也要跟着换。之前拍的都是大货批发图，面向宝妈和轻创业群体显然不太对味。于是她又去迪士尼拍了一批单串珠子的素材，这样大家不用批发，单独卖一串也能做成生意。

# 七、第三阶段：线下沙龙链接资源

珠子产品跑通之后，阿甜看到了更大的义乌市场。

小红书在义乌还是新事物，义乌最不缺的就是创业者。接下来她打算做四件事：

1、对接更强大的供应链，因为他们需要更多客户；
2、帮助正在找品的创业者，撮合双方合作；
3、给两头都做小红书培训，一个做批发，一个做零售，彼此也不冲突；
4、给义乌老板和创业者做IP孵化咨询，把声量做大。

# 八、复盘与选择

阿甜说，这个项目她只当测试来跑，主要是想验证这条路能不能通。现在她并没有把全部精力放在这边。

她的角色更像一个精选联盟：把手头看中的产品握在手里，再去找创业者对接。上游可以拿供应链货盘的钱，下游也能收创业者的费用。链路听起来挺顺，但对她来说问题很大，这也是她没继续加码的原因。

既然都能把前端获客跑通，为什么不直接做高客单的生意？

在义乌做产品的这趟经历，让她看清了一件事：她并没有那么喜欢“做货”，也不想每天跟货打交道。她更想接触的是B端商家、企业和高客单人群，那样才能让她快速进步和破圈。

她创业才第一年，创业本身就有难度，也是长期的事。她不后悔放弃这个项目，因为不需要每天泡在义乌的货盘里谈价格、做对接。她更想把自己的账号做好，让更多厉害的人主动来链接她。

把能力释放出来，盘子不必做得很大，只要在某个小范围里能形成稳定现金流，就已经是一个很好的开始了。
