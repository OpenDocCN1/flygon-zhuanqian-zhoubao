# 这本书，我为什么非要手动重译一遍？

你可能不知道，在中文互联网圈里，有一本英文原版书被许多知名人物反复推荐——硅谷王川、龙哥盟创始人龙哥，都对它赞不绝口。这本书叫《10x is easier than 2x》，2023年5月才出版。

我是去年8月偶然发现它的。当时一口气读完了英文原版，那种震撼到现在还记得。今年三月初，龙哥盟旗下的航海家俱乐部还为它组织了一次专题共读，而且只对航海家开放——龙哥有多看重这本书，由此可见一斑。

读得越多，我越确信：这是一本“手册式”的好书。它尤其适合有组织创新意识的创业者和超级个体——既给你讲心法，也给你提供新的思考框架，还教你具体怎么落地。但它绝不是一个能“读完就完”的书，你得反复咀嚼、拿出来分享、找人和你辩论，才能真正内化成自己的东西。

你可能会问：现在GPT、Kimi这些工具翻译一本书只要几秒钟，干嘛非要花时间去手动校译？原因很简单——市面上流传的中文版，至少九成八都是机器翻译的产物。机翻最大的问题在于“不说人话”，严格来说，是不说符合中文母语者习惯的人话。一句话翻得七零八落，读起来太费劲。

所以我这个版本是纯人工，一个字一个字校出来的。目前已经完成到引言部分，后面还会继续推进。如果你以前被机翻版本劝退过，不妨再给我这个版本一次机会，你会明显感觉到阅读顺畅了不少，对内容的理解也会跟着加深。

其实之前在风3群，我就已经自发组织过一次“十倍增长”主题的共读。等这次校译稿全部做完，我希望有更多朋友愿意一起组队来读，把身边与“10倍速增长”有关的真实案例都带过来一起碰撞。我们一起借这本书，完成一次能力和认知上的双重升级。

这篇文字首发在龙哥盟，写的时候真是有点激动，想到哪儿就写到哪儿，有疏漏我再补。也欢迎你随时来评论区加入讨论。真心感谢龙哥，也感谢所有鼓励我、支持我的圈友。

令我没有想到的是，评论区很快就热闹起来：“比机翻舒服太多了”“几乎是最好的中文版本了”“常读常新，这个翻译更好懂了”“好看，爱看，速更！”……看到这些反馈，我觉得后面再辛苦都值得。
