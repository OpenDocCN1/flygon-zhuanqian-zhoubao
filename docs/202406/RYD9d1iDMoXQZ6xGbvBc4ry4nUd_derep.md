# 全职宝妈一人带娃做闲鱼虚拟项目“睡后收入”爆单经验分享（适合小白看）
作者：龙哥

赚钱圈里泡了四年多，从当初啥也不懂的小白，到现在也算摸出点门道了。回头看看，时间真快，那会儿还没结婚，如今娃都会跑了。这些年最大的感受就是：圈子里小白其实很多，但很多项目对新手不太友好，反馈慢，做着做着就放弃了。闲鱼不一样，门槛低、上手快、正反馈来得也快。真心建议小白拿闲鱼练手，有了正向反馈，才有动力走得更远。

之前我也分享过闲鱼相关的实操，第一次是电影票项目，纯小白两天出了19单；第二次是爆品截流，新店半个多月日订单冲到45单，日利润最高破千。链接我就不重复贴了，感兴趣的可以翻我以前的帖子。

看订单数和成交金额会发现，虚拟资料客单价很低，平均一两块钱，但配合全自动发货系统，整个操作非常顺滑。

重点说下卖什么：PPT模板、短视频素材、合同模板这类虚拟资料。定价基本两块左右，买家拍下自动发网盘链接。货源呢？去淘宝找同款，很多只要一分一毛。淘宝上买一份就能反复给多个买家发货。只要某个链接出过单，我就在自动发货系统里配好发货内容，后面每单自动完成，没人工什么事，算真正的一本万利。

选品方法还是沿用之前说的爆款截流，所以起量很快。

这个店完全是我人工找品、选品、上品慢慢养起来的。第一个月基本没收入，全在打基础。到了第二个月下半段，流量慢慢起来了，后面爆单就止不住。因为我用老号重开，起量慢；后来试了个新号，第二天就开单，第二周就起量了。新店明显更容易起来。

说实话，刚开始完全没想到单价一两块的东西，单店一天纯利能上300。目前这店连续五天日收入稳定在200+，全是利润，我自己都有点意外。

我全职带娃，每天要管孩子吃喝拉撒，还要做饭做家务。做闲鱼的时间全是孩子睡觉时挤出来的，一天也就两三小时，换来每天200多的收入，已经挺知足了。

这种项目真大佬看不上，但小白拿来练手，一天两三百的进账挺香。而且我每天投入时间都集中在娃睡觉时，加起来2到4小时。哪怕按每天4小时算，一个月五六千收入，对小白来说投产比非常划算。

从结婚、备孕、生娃到带娃，副业一直没停过，都是见缝插针地测项目、学实操。兜兜转转一圈，发现还是闲鱼最好做。之前中途停掉实物类闲鱼，是因为爆单后得去拼多多拍单、填快递单号，忙得不可开交，还随时有售后问题，一个人带娃真撑不住。

虚拟资料完美解决了这两个痛点：发货全自动，不用手动输单号；客单价低，基本没什么售后纠纷。节省了大量精力，既能好好带娃，又能让店铺每天产生收入。

现在我又利用碎片时间开了个闲鱼新店，安卓手机双开闲鱼很方便。继续探索一下自己的潜力，要是再做成一个爆单店，边带娃边月入过万真不是梦了。

项目本身不复杂，我就不做目录了，用大白话流水账的方式讲出来。懂的自然秒懂，不懂的也欢迎来交流，一起龙哥盟，冲！
