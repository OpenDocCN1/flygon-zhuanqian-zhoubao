# 八年创业往事：从年入百万到负债归零，再到千万营收，我走了个来回



## 31赞｜八年起落，我的创业账本

作者：镕升师兄  
发布：2024-06-18

第二部分 从开着奥迪去上课，到口袋空空。顺境逆境都聊聊，我是龙哥。

顺风时，人总把成绩归功于自己多能干；倒霉时，又习惯怪环境不给机会。按现在的理解，这个逻辑刚好倒过来了。只是回头看那段没毕业就冒头，又很快掉下来的岁月，终究是年轻气盛。

要是今天有同行问我，到底凭什么做成现在的样子，我只会说：运气。说实话，从创业的第一天到现在，这份运气一直都在托着我。愿这份运气也能分一点给你。
