# ('为什么你的小红书一直做不起来？其核心原因是以下 三点...', (2, 31))

刷了上千个小红书账号之后，我发现一个扎心的事实：很多人做不起来，原因惊人地相似，翻来覆去就是这三个坑。

第一坑：老板心态太重。总觉得自己是发号施令的人，动手的事都该别人干，自己端着架子不肯亲自下场，账号自然越来越凉。

第二坑：等靠要思想太严重。动不动就想把事情甩给员工或者外包代运营，自己当甩手掌柜，指望别人替你做出成绩。可账号是你的，你不投入，别人凭什么帮你把它做起来？

第三坑：轻信所谓的“某某方”。那些号称有捷径、有内部方法的人，大概率是在收割你的信任。真正的路，还得自己一步一步走。

具体怎么避开这些坑，我整理了一份详细说明，放在飞书文档里了，需要的朋友可以自己去看。
