# 垂直赛道做个人 IP，到底该怎么跳出舒适圈？



去年4月，我刚从大厂离职，34岁，加入了赚钱。那时我心里没底，如今一年过去，我已经在垂直的做用户研究与市场研究的这条赛道上逐渐站稳了脚跟：自己拉扯了一个咨询公司，组建了小团队，也做出了一些成绩。今天把这段摸索的经历梳理一下。

一年前我写过一篇《做用户研究知识付费首月做到15万+，我是怎么做到的》，有兴趣的朋友可以翻看。2023年下半年我正式创业，做了一家偏研究类的公司。跟同行比起来，我没有现成的客户资源，只能靠做内容来获客。

做下来最头疼的点，就是太窄了。专业度够了，可传播天花板很低。写一篇关于用户研究或市场调研的深度文章，能有1000阅读就算不错的了。最近有粉丝加我🛰️，给了我三篇文章的建议。我打开一看，两个作者我早就关注过：刘润，代表战略咨询；小马宋，代表营销咨询。都是踩在这个赛道上做起来的咨询服务业，我想看看他们的破圈路径能给我什么启发。

**01 刘润是怎么把战略咨询做大的**

刘润曾在微软工作16年，2014年出来创业，创立了润米，聚焦战略咨询。

他的破圈，我总结为两件事：顺势卡位知识付费风口，以及用👸号做起了个人信任资产。2016年左右，他在得到上线《五分钟商学院》，每年办年度演讲，同时持续用👸号输出内容。

他👸号的核心打法是：做个人IP，而不是机构号。机构号讲的是公司，个人IP讲的是价值观、人生观，能更直接地建立信任，降低从认知到成交的成本。

为了强化IP感，他的文章大量带个人印记，开头几乎都是“刘润”。比如《刘润独家探访圣农：再不好好学，我连养鸡都不会了》《刘润：我是个社恐》等，真实的生活工作切片。

内容大致分三种：商业观察，像《京东，开卷》《宗庆后留下的，不止娃哈哈》；职场方法论，像《你不是没重点，你是没结构》《如何让年终汇报PPT配得上你一年的努力》；个人成长与情绪价值，像《自律就是对抗廉价快乐》《做难而正确的事》。

这三类都很会蹭热点。比如宗庆后去世，他迅速推出相关解读；招聘季来临，他写《招不到人，背后是什么问题》；过年档期，他写《春节前20条锦囊》。第一类瞄准商业人群，是核心高价值客群；第二类覆盖职场人群，盘子更大；第三类面向泛大众，覆盖最广。形成了一个金字塔。

三类内容在日更的情况下，都能稳定吸量，头条动辄10万+，次头条也能几万阅读。团队化运作，相当一部分内容有AI辅助。可见他并不是围绕“战略咨询怎么写案例”“战略咨询怎么规划职业”来做内容，而是先用商业认知做内容，讲清商业现象，再向外延展到职场干货，最后到情绪共鸣。

他为什么还要重做C端知识付费？《五分钟商学院》卖出50万份，累计营收5800万+；年度演讲“进化的力量”连续三年带来上亿级流量，票务和广告也过千万；社群“进化岛”365元/年，1.8万人加入，营收600万+；还出了多本书。C端确实赚钱。

更重要的是闭环。C端触达到大量的商业爱好者和小白，这些人里未来会长出B端客户；B端咨询的实战经验又持续反哺内容素材。闭环很漂亮，直到去年年会演讲翻车，被质疑数据夸大、纸上谈兵。

我之前专门写过《一个用户研究人怎么看刘润翻车事件》。这不代表C端思路错了，而是课程、演讲、社群这类产品服务深度有限，难以让所有人都满意，积累的负面迟早反噬。

**02 小马宋是怎么起来的**

小马宋早期在广告公司，后来创业折腾了几次，到2016年40岁左右重新出发，做“几件事”，也就是现在的营销咨询公司。

他的破圈路径是：低客单价起盘+内容势能加速。👸号起家时，他用低价做品牌营销咨询，口碑一传十，客户排满。随后把现金流投入内容和品牌，出版《朋友圈的尖子生》《营销笔记》等，势能拉满。价格水涨船高，现在咨询费160万起，且坚持不比稿，只筛选适配的客户。

团队一直维持特种兵模式，年利润千万级。核心是两件事：会做内容传播，以及专业能力+经典案例带来的口碑。

看他的👸号，和刘润一样也是个人IP定位。大量内容是个人历程和思考。比如《创办一家小公司，并且活下来》《我创业三次，这次活了八年》《最近对市场的一些感受|小马宋》。这些内容建立人设信任。

其次是商业热点解读，比如《长文回顾：宗庆后的天命》《热辣滚烫破30亿，我对减肥的12点认知》，用来破圈触达泛人群。

然后是案例复盘，比如《小马宋2023年度营销咨询案例合集》《破局护肤品红海，绽妍x小马宋复盘》，直接为B端导流。

最后是方法论输出，比如《怎么提高营销能力》《营销的终极难题：回到用户视角》，为C端课程和出版导流。

和刘润相比，小马宋的内容更聚焦商业营销，平均阅读2-3万，流量规模小，但人群更精准、价值更高。这也符合业务逻辑：他以B端咨询为主，所以内容重心是服务B端获客和品牌背书；刘润以C端知识付费为主，所以内容更偏向C端转化。

**03 我从中提炼的四点做法**

**1. B端和C端都要做，但要分清主次。**
2024年我会重点发展C端知识付费，它能帮助B端破圈。一个学员背后可能就是一个潜在的B端客户。但我会坚持重服务、轻课程，做交付而不是堆产品。

**2. B端和C端没法兼顾所有，必须取舍。**
刘润和小马宋都不是两头抓，而是各有侧重。我也在摸索期，C端上线后会对比数据，与B端业务做对照，用一年左右确定最终聚焦方向。

**3. 不会传播，就只能做低端市场。**
现在想从价格战里跳出来，像小马宋那样从低价抢单到反向筛选客户，就必须有品牌和IP。内容是最快的加速器。创业者要有专业能力，也要有传播能力，否则只能做外包代工，赚辛苦钱。

**4. 用“1+3”做内容。**
“1”是做一个有血有肉的个人IP，而非工具人号。我👸号起初发了一堆方法论干货，阅读寥寥。去年重启后，我先发了《快35岁大厂裸辞，换一种活法》，随后把名字从“用研那些事儿”改成“Peron 用户研究”。IP内容未必讨好所有人，但能筛选到同频的人。

凯文·凯利的“1000个铁杆粉丝”理论我很认同。对创作者而言，只要有1000个愿意为你持续付费的铁杆，就能活下去。铁杆的定义是：你做什么他们都买，愿意开车200公里来看你，即使已有你的内容也愿意再买高配版。我的目标就是先聚起这一千人。

“3”是内容框架：垂直专业干货+破圈内容+个人IP故事。

专业干货必须写，先在赛道建立心智，让同行和新入者搜得到你，让市场知道你能解决什么问题，再谈破圈。现在图文上，👸号、📕、知乎、人人都是产品经理这些平台搜市场调研、用户研究，基本能看到我的名字。中视频短视频我还没精力。

借鉴小马宋，我今年会加大案例输出，提升专业背书。

破圈内容我也在尝试。用市场与用户的视角解读商业热点，比如我写《靠测评起家拿到400万迈凯伦的王自如，为何去格力》，阅读直接破10万+。标题和选材确实重要，但流量退潮后粉丝增长和精准客户转化并不明显。所以不要迷信流量，它能带来影响力和资源连接机会，但不是目的。

个人IP部分，目前主要分享职业发展和创业的经历思考，后续会拓展到生活方式和体验，增加故事性和可读性，这也是趋势。
