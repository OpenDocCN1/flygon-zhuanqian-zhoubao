# ('躬身入局，把手弄脏 福州见面会分享', (2, 19))

前几天在福州见面会上，我做了一次线下分享，这也是我第一次站在两百人面前讲东西。主题就八个字：躬身入局，把手弄脏。

为什么想讲这个？因为我觉得这是创业路上特别重要、却特别容易被忽略、还特别容易做错的一个心法。说来也巧，去年我正好设计过一件印着“把手弄脏”的T恤，算是提前打了个招呼。

现场来的圈友背景差异挺大，有做不同行业的，有处在不同阶段的，人生状态也各不相同。所以我没有直接讲道理，而是挑了三个故事来讲我的想法——一个是百年前大航海时代的真实故事，一个是生财团队内部发生的事，还有一个来自生财的一位航海家。每个人听完，应该都能从中找到属于自己的那一点触动。

第一次做这种规模的分享，PPT 前前后后准备了一百页，最后砍到五十来页。砍掉的部分，等以后有机会再慢慢聊吧。
