# 本地跑 DeepSeek R1：用 LM Studio 断网部署的完整思路

春节档 DeepSeek 直接爆火，趁着假期我也上手实操了一波。起初是刷到 B 站 UP 主 NathMath 的演示，讲的是怎么用 LM Studio 把 DeepSeek 本地化并且物理断网。视频讲得挺细，但回看操作总归不方便，我就结合自己的复现过程整理成了这份图文思路，给同样想自己玩本地模型的同学做参考。

先说为什么要折腾本地部署，三个点说清楚就够了：

第一，云端偶尔抽风、排队长的时候，本地模型随时能用，不受服务器影响。
第二，敏感资料不用上传，数据全在自己电脑里，隐私可控，模型不会收集你的对话。
第三，本地环境自由度高，思考时长、系统提示词、角色设定都能按自己的需求调，不受官方限制。

整体流程其实不复杂，分成五大块操作：

1. 先去官网把 LM Studio 客户端装好
2. 挑一个适合自己显卡的 DeepSeek R1 版本，下载后放到 LM Studio 指定的模型目录下
3. 打开 LM Studio 导入模型，完成加载
4. 根据自己电脑的显存、CPU、内存等硬件情况，调整启动时的参数，避免爆显存或跑不动
5. 用 Windows 防火墙给软件断网：新建 6 条出入站规则，把 lm studio.exe、elevate.exe 和 lms.exe 三个程序的网络全部拦截。这样即使误触也不会外发数据
