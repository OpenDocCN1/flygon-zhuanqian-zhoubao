# ('搞流量的人都要有一个根', (2, 13))

做流量的人，不管在哪个时代，都得给自己留一条“根”。

这话怎么讲？过去二十年，从PC到移动互联网再到短视频，每个阶段都有人踩中风口，拿到惊人的成绩。但你很难找到一个团队，能跨越好几个周期，始终保持着正向增长。谁也不敢说，某个小时代结束之后，自己还能继续风光。

楚川在打流量的路上，经历过两次刻骨铭心的教训。

2019年，他做解酒糖，第一年就干出了8000万的业绩。当时他信心满满，觉得2020年还能再上一个台阶。结果“口罩”来了，一夜之间，整个类目直接清零。五年过去，他在电商和大健康领域，好像从没来过一样。这就是纯靠流量、只做白牌的悲哀。

2021年，他又带队做抖音本地生活小程序服务商，220人的团队，只干这一件事，业务铺到了60多个城市。到了11月，抖音突然宣布直营，把第三方服务商一刀切。楚川没有犹豫，直接遣散团队。一直到2022年上半年，才缓过劲来，找到新方向，做出新成绩。可在他背后，是上万家同行原地破产。

回头看这两次变故，第一次，是时代落下的一粒沙，可当时电商渠道占了营收的80%以上，这点沙子就压垮了一切；第二次，是对平台生态的变化不够敏感，靠红利驱动的业务，没有纵向布局后手，牵一发而动全身。归根结底，都是太依赖流量，手里没有底牌。

很多公司活过了十年，靠的并不是流量；而流量也从来不能平地起高楼，没法让一个人在一个平台里再造出一个行业巨头。流量的作用，始终是做加法，是放大规模。

最近两年，楚川的恐惧，来自团队的“寻根”。他怕流量触底，怕迟迟找不到基本盘。所以2023年，他们投资自运营了众鑫夏令营；2024年，又自运营了麦金设计。这两块业务的净利润贡献，从0涨到了30%。有了这个底，团队才敢从抖音，往美团系、小红书、视频号横向拓展。

有人会说，你既然流量玩得溜，那下场做产业，速度应该很快吧？楚川却觉得，资源匹配、选项目、找合作方、搭团队、投资打样、逐步放大，这一套流程走下来，保守估计也得一年起步。真正能选出来跑出来的难度，比自己在平台上摸索一套流量打法要难得多。

但只有把这些事做扎实，才能一步步开辟多平台战场，才能持续创业，持续吃到流量的红利。这，也是每一个做流量的人，最终都要去拥抱的方向。
