# 我的 2024 年终总结（电商人版）

2024年对我来说，真的是坐过山车的体验。团队业绩起起伏伏，心态也跟着反复煎熬。这一年大家普遍都不容易，但我们最终的成绩反而超出了自己的预期，也算是个意外之喜。

年初那阵子，主战场还是天猫。没想到后来平台为了推1688一件代发，开始连环判定无货源违规，我们被轮番打击，业绩几乎跌到谷底。那阵子每天还能稳住两三万的利润，可惜好景不长。好在年前我们顺手测试过抖音小店，看到天猫这边大势已去，五月份立刻把重兵和资金都调过去，不到两个月，日销售额居然冲到了十几万，这在龙哥盟里也分享过。

六到九月才是最磨人的四个月。做过抖店的朋友都懂，它的玩法和规则比天猫严多了，一上来我们就交了罚款。六月、七月、八月，我几乎把所有市面上的付费课程都扫了一遍，当然都是用的小号报的，免得被同行看到尴尬。到七月份，单月做了几百万的销售额，做的是女装，账面上的利润率高达八九成，可退货率也高到八成，算下来其实只赚了一点辛苦钱。当时我总觉得一天十几万的销售额已经是个人能力的天花板，越发觉得这生意难做，于是在八月下旬到九月中旬，干脆把这个项目整个停掉了。八月份在赚钱做过一期航海，不少人抱怨退货率高、售后麻烦，但电商的三角模型——高利润、高转化、低退货——本来就不可兼得。实际上那期航海里，还真有人靠女装和配饰把月销量做到了几百万，说明这条路是通的。

九月份以后，我们把学过的各种课揉在一起，开始做精细化抖音铺货，说白了就是每天上品、死磕细节。到十月份有些起色了，但起店周期普遍要一个月起步，还是嫌慢。当时收了几个徒弟一起干，结果一半人没撑住，因为见效太慢，而且电商的钱并不是弯腰就能捡的，没有超强的执行力和全身心的投入，很难熬过来。

到了十一月，精细化那套因为精力有限就没怎么管了，转而研究批量铺货。先开了30家店试试水，一天能出一千多利润，觉得可行，立刻在十一月加码到120家店。十二月下旬，团队每天的单量直接破万，那几天我几乎没合过眼，办公室又成了卧室，十个人干了个通宵，待发货量也没见减少，反而越来越多。可以说双十一之后，抖店项目正式从测试期进入了扩张期，短短半个月，店铺数量就翻了好几倍，连帮我们代开店的人都被这个速度惊到了。

十二月初，因为错过了一个能赚大钱的项目，整个人特别fomo，天天躺着不想动。躺平了几天，还是回到了正轨上。我们开始大规模引入RPA和AI，把很多需要人工重复操作的活儿都交给了机器，大概半个月时间，全公司的效率翻了一倍。我当时还想着，要是每天冲着几万单去，真得请一个全职的技术来好好打磨效率，让兼职写脚本，沟通成本太高了。

十二月中旬以后，我开始主动收缩规模，把单量压到三千单以内，但利润总额反而没掉。怎么做到的呢？就是让客单价涨了三倍，利润率保持在原来的水平，人力和时间成本却大幅下降了。所以明年的重点还是放在利润和客单价上。

进入一月，我去试了港股打新，上了两个顶锤号，结果都只中了一手，加起来赚了两万多不到三万。这充分说明必须靠量取胜，所以我又跑去香港，把父母的账号也开了，接下来再拉上亲戚，全部上阵，要把做店群的执行力用在打新上。

回头看看这一年，年中那几个月是真的很不顺，但整体结果还挺好，尤其十二月，业绩做到了历史新高。我们也头一次深度用上AI和RPA，大部分工作已经半自动化，明年还会继续往上提。

守了七年的天猫店群，终究没扛住时代的变革，几乎全军覆没。但好在我们切换新业务时还算顺滑，没有伤筋动骨。最大的感触就是：想法和执行之间的距离，真的比想象中要大得多。别想太多，先动起来，这本身就是给自己一个不能放弃的理由。

新的一年，我依然会all in抖音小店，这里的空间真的太大了。明年的目标很明确：做到500家店，争取日利润十万。说实话，今年自己表现不算好，有躺平也有颓废，还有装修来添乱。但这一年的丰富程度，已经远超预期，值了。

电商这行，有人天天骂“狗都不做”，但真要进来了，就得做好死磕到底的准备。
