# ('大学生零基础在 AI 绘画赚到第一桶金', (2, 21))

**理工男零基础，靠AI绘画赚翻了？这个案例让人坐不住了**

最近看到赚钱有术圈友可乐（圈名BCC）分享自己的搞钱经历，挺有感触。他刚大学毕业，在天津读的机器人工程，这专业听听就觉得和美术、设计不搭边。他自己也承认，美术功底是真谈不上，顶多是理工科教育多少培养了一点对“美”的感知。

偏偏就是这样一个“纯理工男”，因为对新鲜事物充满好奇，一脚踩进了AI绘画的赛道，还真赚到了第一桶金。

其实可乐也是“折腾”出来的。他试过不少副业，包括薅羊毛这种活，绕来绕去最后被AI绘画吸引住了。问他当初怎么想的？他就一句话：好奇，想试试。

但比好奇心更打动人的，是他从想法到行动之间的距离。有圈友感慨说，BCC这种“先想清楚、再马上动手”的路径，很有代表性；现在的00后，是真的有想法就敢去干，看着就让人来劲。评论区还有人直接说他被感染到了，甚至想找他约图，也有圈友当场想加好友谈合作。

聊到成本，有人以为AI绘画工具很贵。BCC用的是Midjourney，两个月开支大约75美金，买的是4到6人的共享账号，平时自己出图完全够用。问的人一开始还以为是75人民币，知道是美金后才反应过来：这价格其实挺划算。

回头看，BCC能赚到钱，靠的不是什么美术天赋或专业背景，而是对新兴领域的热情，以及说做就做的执行。AI绘画的门槛已经低到普通人也能试试，所谓“零基础”根本不是理由。

所以，别急着说自己不行。与其盯着别人的成果羡慕，不如学他那样先迈出第一步。说不定，你的第一桶金就藏在一件你没试过的新鲜事里。
