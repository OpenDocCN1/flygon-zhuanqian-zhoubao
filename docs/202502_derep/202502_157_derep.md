# 纳瓦尔：读书的唯一原因

最近刷到纳瓦尔的一段分享，心里默默点了好几个头。他说，一个人翻开书，最根本的驱动力就是发自内心的喜欢，除此之外，根本无需任何“必须读”的附加条件。阅读不是一项需要被塞进待办清单的任务，它更像是一种自然发生的享受——就像有人喜欢看电影、有人喜欢散步一样，只是因为做这件事本身让人感到愉悦。

很多人会把读书看得过于沉重，总觉得要带着目的去读，要读出点成果，要完成年阅读量指标。可一旦抱着这种心态，书就变成了负担，阅读的乐趣反而被稀释了。纳瓦尔想提醒的正是这一点：如果你真的想读，那就单纯地因为“想读”而读。不必解释，不必证明，更不必拿读书来标榜自己。

回想一下，那些真正让你废寝忘食的书，往往不是你“该读”的书，而是你“想读”的书。那份纯粹的喜欢，才是带你走进更广阔世界的最佳向导。

所以说，别再把读书当成一项苦差事了。喜欢，就是唯一的理由，也是让你一直翻页的最强动力。愿我们都能在书页之间，找回那种最简单的快乐。
