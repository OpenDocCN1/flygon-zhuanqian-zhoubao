# ('（航海好事）Shein 航海实战，做起一个每天几百单的新店', (2, 31))

有个工科男，在成都做跨境电商，两个月不到就做到了日销几百单。

先说一下他的背景。他叫张炯，西北人，在成都生活，是个典型的工科男。过去这些年，他一直在国内电商圈子里打转：

17年到19年，他运营天猫女装，从零起步，把年销售额做到了3000万左右。
19年到22年，他跟合伙人一起做抖音IP，积累了80万粉丝，月销售额冲到400万。可惜赚了钱之后，合伙走到头，散伙了。
22年到现在，他在小红书自营女鞋。

以前总有人问他：你这么多国内电商经验，怎么不做跨境？他的回答永远是——太陌生了，玩法不一样，经验没法复用。

结果这次Shein航海计划，他上了船，也开了眼。

他自己负责的店铺是12月25日开始跑，到现在差不多两个月。近30天销售额已经超过3万，而且还在每天往上走。对一个新店来说，这个增速他自己都说“没想到”。

从一个说“绝对不做跨境”的人，到近30天跑出3W+销售额，他这趟航线，算是真的开出感觉了。
