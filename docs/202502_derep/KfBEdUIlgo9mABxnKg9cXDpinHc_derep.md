### 撰写演讲稿

#### 新手常见误区

*   误区1：写出的稿件像说明书朗读

👉 告诉deepseek（错误指令）：

```
写一篇关于环保的演讲稿
```

错误原因：指令中缺乏关键信息

👉 告诉deepseek（改进指令）：

```
写一篇初中生环保主题的3分钟演讲，开头用塑料袋漂流的故事，结尾让同学举手承诺
```

*   误区2：内容空泛缺乏重点

👉 告诉deepseek（错误指令）：

```
帮我写竞聘班长的演讲稿
```

错误原因：指令中缺乏关键信息

👉 告诉deepseek（改进指令）：

```
写竞聘班长的3点计划：① 设立'烦恼信箱' ② 每月组织趣味运动会 ③ 班费透明化，要带表情符号和同学互动台词
```

从以上两组对比可以看出：

*   两组提问均未说明交付要求；
*   两组提问均未给出背景说明；

因此在起草前请先对照下面的《自检清单》。

#### 自检清单

✅ 开头是否设置了能抓住注意力的故事或提问
✅ 每段落能否用一句话概括核心
✅ 结尾是否给予听众明确的行动指引，如鼓掌、举手、反思等

#### 三步打造优质稿件

根据DeepSeek的反馈，一篇符合标准的《演讲稿》至少需要三步走。

##### 第一步：录入稿件细节

👉 告诉deepseek（输入问题细节）：

```
我要在['场合']给['谁']讲['主题']，
重点是['XX']，
不要提到['XX']，
希望听起来['有趣/专业/感人']...
```

提示：‘绿色字体’部分可自行补充。

👉 举例说明，告诉deepseek你的具体问题：

```
我要在'同学婚礼'上作为'闺蜜''发言'，
重点是'回忆校园趣事'，
不要提'前任'，
希望'搞笑又温馨'，
时间不超过'3分钟'
```

##### 第二步：增强表现力

为了让《演讲稿》更具号召力，需要对成稿进行润色，具体做法如下：

👉 告诉deepseek（润色演讲稿）：

```
为了让我的演讲稿更吸引人，你可以添加以下要素：
加个比喻：把道理比成日常东西（如"坚持就像外卖配送，总会迟到但不会不到"）  
插入对话：假装和听众聊天（如"有同学问：这和我们有什么关系？我想说..."）  
来点反差：先严肃后搞笑（如"专家说每天要睡8小时——但看看在座各位的黑眼圈！"）
```

提示：在润色时需考量使用场景。庄重场合不适合过于俏皮，轻松场合不适合过于刻板。可在上一轮输出后继续在对话中微调。

👉 告诉deepseek（确认风格）：

```
 这篇《演讲稿》的'使用场合'，请你确认最终风格。
```

##### 第三步：适配听众表达

在明确演讲场合与听众画像后，需要进行语言风格的适配。

👉 告诉deepseek（润色语言）：

```
方案一：把'因此我们可以得出结论'改成口头语
方案二：每段开头加个'记得那一年或你们有没有'
方案三：删掉听不懂的词语，换成'初中生能明白的话'
```

以上方法仅作参考，若不适用可直接向DeepSeek提问。

👉 告诉deepseek（征求意见）：

```
你觉得我这篇《演讲稿》的初稿在'语言风格'上是否满足我的要求？有哪些建议？
```

#### 常见问题解答

##### 篇幅过长如何处理？

👉 告诉deepseek（优化文章长度）：

```
方案一：文章过长，请删掉重复的内容，每段留最关键的'*句话'。请简化内容，简明扼要，通俗易懂。
方案二：这篇稿子念慢点要'*'分钟，帮我删到'***'字左右
```

##### 回复缺乏情感怎么办？

👉 告诉deepseek（情感回复）：

```
方案一：在原来的基础上，添加一些“语气用词、语气用语”，让文章更有感情。

方案二：在原文的基础上，让文章更加有“情绪感”，你可以参考以下语言风格：
'在讲失败经历时加点自嘲：当时觉得自己像不会游泳的救生员'。
```

##### 台上担心遗忘台词怎么办？

👉 告诉deepseek（手卡制作）：

```
把这篇稿子改成手卡小纸条格式，每张纸条写'1个关键词+表情符号提醒',大致的'演讲时间'。
```

##### 突发需要改动怎么办？

👉 告诉deepseek（修改内容）：

```
原稿第'*'段讲'某某内容'，现在要改成'新的某某内容'，其他部分不变，请重新生成这一段。
```

##### 如何让AI模仿个人说话风格？

👉 告诉deepseek（模仿语气）：

```
  方案一：请用这个语气改写演讲稿：'...（粘贴你的演讲稿示例）...'
  方案二：这是我平时的文章和聊天记录，请学习风格。输入内容：'文本内容'
```

### 撰写新闻稿

#### 新手常见误区

*   误区1：像写作文一样冗长

👉 告诉deepseek（错误指令）：

```
在这个阳光明媚的春天，我们公司怀着无比激动的心情宣布..
```

错误原因：指令中缺乏关键信息

👉 告诉deepseek（改进指令）：

```
使用倒金字塔结构，把最重要信息放开头：【XX公司今日发布首款AI翻译耳机，准确率达98%】
```

*   误区2：自夸过度引发反感

👉 告诉deepseek（错误指令）：

```
我们的产品是市场上最好的，远超竞争对手...
```

错误原因：指令中缺乏关键信息

👉 告诉deepseek（改进指令）：

```
换成第三方证言『实测比同价位产品翻译速度快2倍』——科技媒体评测
```

#### 自检清单

✅ 5W1H 是否齐全？

*   Who：主体是谁？
*   What：发生了什么？
*   When：何时发生？
*   Where：地点在哪？
*   Why：原因是什么？
*   How：过程如何？

✅ 是否包含直接引语“...”负责人表示
✅ 文末是否附上联系电话/官网

#### 三步产出合格新闻稿

据DeepSeek反馈，一篇达标的《新闻稿》至少需要三步。

##### 第一步：填写新闻信息表

👉 告诉deepseek（输入问题细节）：

```
[Who]：'市环保局 + 阳光小学师生'  
[What]：'开展"变废为宝"手作大赛，收集300kg废旧物品'  
[When]：'6月5日世界环境日 9:00-11:30'  
[Where]：'市青少年活动中心展厅'  
[Why]：'响应环保号召 + 培养儿童环保意识'  
[How]：'展出150件创意作品，获奖作品将在全市巡展'  
请结合上述内容，分别生成3种风格“严肃版 / 故事版 / 数据版”
```

提示：‘绿色字体’可自行填充。

若DeepSeek生成内容偏表面，可视为挖掘不到深层原因，此时应：

👉 告诉deepseek（探索新闻事件背后的深层次原因）：

```
为什么这个事情会发生？为什么这个时间/地点特别重要？
```

优质新闻稿的深层原因往往一针见血，决定成稿优劣。

### 起草合同协议

#### 新手常见误区

*   误区1：遗漏“失信不履约”条款

👉 告诉deepseek（错误指令）：

```
签了装修合同没写逾期每天赔100元，结果工人拖延
```

错误原因：遗漏相关条款

👉 告诉deepseek（改进指令）：

```
乙方逾期完工，每延迟一日支付合同总额0.5%作为违约金
```

*   误区2：遗漏“赖账不认账”条款

👉 告诉deepseek（错误指令）：

```
合作开发APP没写"成果归属"，最后抢版权  
```

错误原因：指令中缺乏关键信息

👉 告诉deepseek（改进指令）：

```
本协议项下所有知识产权归甲方所有，乙方享有署名权
```

#### 自检清单

✅ 双方身份信息完整（姓名/身份证号/住址）
✅ 金额同时大小写并行（如¥1000元整+壹仟元整）
✅ 违约情形描述具体（不可仅写“违约方承担责任”）

#### 三步制定安全合同

合同/协议条款至关重要，务必重视。

##### 第一步：填空式基础信息模板

👉 告诉deepseek（输入双方信息）：

```
你是一位资深的律师，请结合以下信息，帮我生成一份合同/协议初稿：
合同名称：'____'协议  
甲方（需方）：姓名'____'身份证号'________'  
乙方（供方）：姓名'____' 身份证号'________'  
合作内容：'____'  
履行时间：'____'年'__月__日至____年__月__日'  
支付方式：'____'（定金/分期/验收后付）  
交付标准：'____'（附验收清单）  
违约责任：逾期每日罚'___% / 质量问题赔___倍'  
争议解决：协商不成向'___法院起诉'  
签字页：'双方手写签名+按手印+签日期'  
```

提示：‘绿色字体’可自行填充。

等待DeepSeek回复后，请核查条款完整性与可靠性。

👉 告诉deepseek（检查合同/协议中条款）：

```
请仔细检查刚才生成的合同/协议中条款设置的合理性。
```

将合同/协议文本拍照上传DeepSeek附件，解析完成后：

# 别再把DeepSeek当成聊天机器人了！三个真实工作场景，手把手教你榨干它的价值

天天用DeepSeek，可一到写正式文档就抓瞎？生成的内容要么太泛，要么不是那么回事。别着急，这篇文章我会带着你逐一拆解三个最高频的办公场景——修协议、写总结、出会议备忘，每一步都给出可以直接照搬的提示词。看完你会明白，不是AI不够聪明，而是你还没把需求说透。

## 一、合作协议修改：把AI变成你的审稿搭档

替客户打理新媒体账号这行，最怕甲方突然来一句“再给我们加个需求”。整套方案推翻重做？倒也不至于，不过相关条款确实要跟着调整。这种琐碎活儿，交给AI处理也就是一两句话的事。

先用下面这套通用框架，把合作背景交代清楚：
```
服务内容：'乙方为甲方运营抖音账号（@美食探店）'  
考核标准：  
• '月更12条视频，点赞<500的需重制  
• 3个月内粉丝达5万，未达标退还50%服务费 ' 
付款方式：  
• '签约付30%定金（¥6000）  
• 每月15日付¥5000'  
保密条款：乙方不得透露甲方店铺地址及供应链信息  
```

接下来，按需选择对应的问法就行。

**场景1：甲方临时要求塞新内容**

别一个人闷头改，直接把诉求丢给AI：
```
在原合同第'*'条后新增：'乙方需额外提供每周运营数据报表，格式见附件3'
```

**场景2：某句话怎么理解都说得通**

当条款出现模糊地带，让它帮你把表述不清的地方揪出来：
```
'1'条条款存在歧义，请仔细检查，并按照我的'看法'进行调整
```

**场景3：觉得协议还缺了点什么**

想让约定更周全、覆盖更多意外情况，可以这样问：
```
我需要在'*'条款处，补充'**细节'
例如：
"详见附件1：设备清单"
"按附件2验收标准执行"
```

## 二、年终汇报：从平淡无奇到高光时刻

每年写总结，怕的不是没活干，而是干了一堆却说不出亮点。下面这套方法，能让你的汇报脱胎换骨。

### 先避雷：两大常见翻车现场

**翻车①：通篇平铺直叙，像在写工作日志**

反面提问：
```
1月完成A项目，2月参与B培训，3月协助C活动...
```

毛病出在哪？没有写清楚具体做了什么、带来了哪些变化。

那该怎么问？看这里：
```
按"能力成长维度"重组内容（如沟通能力/专业技能/管理能力）
```

**翻车②：只报喜不报忧，全程回避问题**

反面提问：
```
虽然有些不足，但总体进展顺利
```

这样写的漏洞在于：没写明每件事的来龙去脉和最终结果，说服力大打折扣。

改进后的问法：
```
Q3客户投诉率上升15%，经分析发现服务SOP未及时更新，已牵头完成3版流程优化
```

### 落笔前，对照这六条过一遍

- 每个成果都要配上数字
- 问题剖析的部分控制在整篇的两成以内
- 多用“主导”“推动”“重构”这类动作词
- 排查并删除至少6个空洞修饰词，诸如“重大”“显著”
- 至少举两个跨团队协作的真实案例
- 后续计划要对准公司大盘方向

### 六步打造一份让领导点头的汇报

#### 第1步：搞清楚“谁在看”

一般会有直属上级、人力资源、更高层管理者三类人。所以你的材料要能体现综合能力和横向协作意识。

一份完整汇报的权重建议如下：

- 业绩表现（30%）→ 用目标完成比例说话
- 能力进阶（25%）→ 新拿下的证书或本领
- 问题攻关（20%）→ 啃下来的硬骨头
- 协作贡献（15%）→ 支援兄弟团队的案例
- 创新改善（10%）→ 流程上的小改进

从中也能看出，AI更偏爱“年度硬数据”，而流程优化这类软性亮点的权重相对较低。

**排序：业绩表现 > 能力进阶 > 问题攻关 > 协作贡献 > 创新改善**

#### 第2步：先搭一个框架，再往里填肉

把你的岗位、职级、工作范围发过去：
```
请根据我提供的职业信息，请帮我生成一份述职报告初稿：
核心价值定位: 
"作为____角色，本年度聚焦____三大重点"  
关键成果举证  
"实现____目标，较去年提升____%，超出预期____%"  
能力进化路线  
"从____到____的能力转型，具体表现为____"  
战略级反思  
"如果重新开始，我会在____阶段采取____策略"  
未来价值蓝图  
"下一阶段将把____经验复制到____领域，预计带来____改变"
```

AI会自动生成一份初稿。注意：初稿里标成绿字的地方，直接换成你自己的真实信息，无需修饰，原样填进去就行。

#### 第3步：把真实数据“喂”进去

没有数据的汇报就像没加盐的汤——寡淡无味。把你整理好的数据按下表分类，再整体发给AI。

| 统计口径 | 适合用在什么时候 | 示例 |
| --- | --- | --- |
| 纵向增长（和自己过去比） | 展示成长性 | 老客户的续签比例比去年同期涨了32% |
| 横向排位（和身边同事比） | 展示竞争力 | 小组排名由中游升到前三 |
| 成本收益（投入产出比） | 展示决策力 | 调整协作流程后，省下46人天的投入 |
| 长期收益（对组织后劲的影响） | 展示战略眼光 | 我带过的三位同事，现在已经能独当一面了 |

提醒：所有数字都必须真实可靠，提前做好筛选和清洗。

接下来，把你整理好的数据整体发送：
```
请结合以下数据，帮我形成方便领导理解，又能凸显我的工作能力的《述职报告》详细稿件。
数据：'上文中绿色字体内容'
```

AI会返回一篇信息扎实的完整版本。但这还不算完，继续往下走。

#### 第4步：把大白话改成“公文腔”

汇报文本需要正式、克制。别换窗口，直接在当前对话中继续输入这条：
```
请按照以下要求帮我润色优化语言：
'语言需要正式'
'专业名词需要表达正确'
'不要出现明显的语病'
'不要出现错别字'
'要有吸引力'
'字数在2000字左右'
请输出完整的《述职报告》
```

让它顺着上文的语境来调整措辞。

#### 第5步：给全文做个深度SPA

想要更精致的表达？试试这个：
```
请将报告中提到的数据进行数据可视化分析，例如：
对比设计："市场份额增长（12%→18%）" 改为 "市场份额增幅超行业平均3倍"
价值换算："节约成本25万" 改为 "相当于创造2.5个新人全年编制价值"
请你按照要求帮我修改报告。
```

如果输出里还有“大概”“左右”这类模糊字眼，或者过于主观的人称表述，你可以自己动手改，也可以继续追问AI。例如：

- “大概”“左右” → 落到具体数字，比如92.6%
- “我”字开头的句子 → 换成“和团队一起完成”
- “没辙了” → 换成“换了一种思路”

或者更省事，把你的修改要求直接告诉它：
```
请帮我检查稿子中是否存在以下情况，或者类似的情况，如果存在请参照示例修改。
❌ "差不多/大概" → ✅ "精确到92.6%"  
❌ "我自己" → ✅ "在团队支持下"  
❌ "没办法" → ✅ "探索出替代方案"'
```

#### 第6步：给汇报埋几个“锚点”

领导记不住你写的每句话，但会记住那些亮眼的句子。

方案一：
```
第一步：请你根据刚才分析的内容，为我输出金句、符号化标签。
第二步：再结合刚才生成的金句、符号化标签，继续添加进述职报告中，并润色述职报告。
```

方案二：
```
你需要结合我提供的段落：'段落文章'
生成金句+符号化标签，并将这些内容体现在报告中。
让报告具备有逻辑、有号召力、有吸引力的表达。
```

### 汇报中三个难言之隐

**怎么婉转地说“人手不够、预算有限”？**

不用直接抱怨，让AI帮你包装：
```
请在文中委婉表达资源不足，
你可以参考下列格式表达： 
在现有资源下实现____突破，若获得____支持，预计可提升____%
```

**团队成绩和个人的作用怎么分开写？**

```

你可以参考下列格式表达：

```

与其找借口，不如让它给你一套稳妥的说法：

```
你可以参考下列格式表达：

展示补救措施："建立预警机制避免同类问题"  
关联后续价值："沉淀的经验已应用于____项目"
```

## 三、会议备忘：从混乱现场到清晰文档

每次开完会，最痛苦的就是整理备忘录？篇幅太长像逐字录音，太短又怕漏掉关键。这里有一套完整的思路，帮你从源头解决这个问题。

### 两个高频误操作

**误区①：把全程发言原样誊抄下来**

错误示范：
```
逐字记录"张总说...李经理回应...
```

问题核心：会议备忘不是逐字稿，没必要逐句照背。

正确打开方式：
```
提炼核心观点，按"议题-结论-责任人"结构化呈现
```

**误区②：抓不住重点，丢三落四**

错误示范：
```
只记结论不记背景，导致执行时理解偏差。
```

问题核心：结论和来龙去脉对不上，容易引起误解。

正确示范：
```
使用以下结构复述：
✅背景：'因Q2客户投诉率上升15% ' 
✅决策：'优化服务流程3项'  
✅依据：'客服部调研报告数据'
```

### 先判断：这是哪类会？

不同性质的会，备忘录的详细程度完全不同。规格越高的会，要写得越细，侧重点也不一样。

- 定方向型的会 → 侧重：敲定的事项 + 谁来做
- 议方案型的会 → 侧重：各方观点 + 待办清单
- 听通报型的会 → 侧重：关键数字 + 改善方向

所以让AI动笔前，先把“这是个什么会”告诉它。

### 四步流程走一遍

另外，涉及保密的会议，千万别把原始材料传到云端；日常例会则可以留好速记，方便后面整理。

#### 第1步：会前先“热个身”

拿到议程和材料后，圈出重点。可以用AI帮你列一份会前清单：
```
你是一位资深的行政秘书，你需要参加一场会议，你获得了会议的资料：
'会议议程'
'会议议题' 
请你帮助我生成可供制作《会议纪要》使用的模板框架和需要重点关注的点。
```

它列出来后，你就知道该把注意力放哪儿了。

#### 第2步：会中记什么？怎么记？

在做现场笔记之前，可以先让AI给你一些提示：
```
我在会议现场记录，我需要注意哪些细节？怎么提高记录效率和准确性？
```

它给的建议里，有两个方法特别好用。

第一招：关键词捕捉
- 原话举例：“这次活动预算，先按区域拆开，再分梯度设置。”
- 速记：预算 → 区域 + 梯度
- 补充：华东区 / 华北区 / 华南区

第二招：符号标记
- “!” → 事项已敲定
- “?” → 尚需核实
- “→” → 工作分派
- “@” → 后续追踪

这两招能应付大多数会议。如果你想系统性地学习更多技巧，可以让AI继续教你：
```
请详细说出'关键词速记法、符号速记法'的具体操作细节。
```

#### 第3步：把速记变成结构化文档

回到原来的对话框，把会议的基本信息填进去：
```
会议基本信息  
时间：'____'  
地点：'____'  
参会人：'____'  

议题与结论  
   '| 议题 | 讨论要点 | 决策内容 | 责任人 | 完成时间 |  
   |------|----------|----------|--------|----------|  
   |      |          |          |        |          |'  

待办事项  
'@张经理：6月15日前提交市场分析报告  
!全体：下周试行新考勤制度'  
```

记得按现场情况把内容补全。之后请AI帮你把文字理顺：
```
这是我的现场会议记录，请将下列内容进行优化，让《会议纪要》更加专业，突出重点。
现场会议记录：
'填写会议的基本信息模板：'
同时需要帮我按照"轻重缓急"的要求罗列重点。
```

如果会后还需要人员跟进，也可以让它顺手生成一条日程提醒：
```
请按照日历，帮我生成'事件提醒'，能够导入至我的'win'系统备忘录中。
```

#### 第4步：发出去之前，人工核查一遍

不管AI生成得多流畅，最终责任都在你。请按公司现行规范完成存档与分发：

- 关键结论标红
- 写得模糊的地方加一句注释
- 尽量当天就把最终版本群发给参会者

### 效率工具叠加使用

除了速记，这些工具也能帮你省力：

- 腾讯出品的会议软件里，有一键生成摘要的功能
- 讯飞出品的录音转写服务，现场话音落字就出
- 用Xmind把要点画成图，思路一眼看清

把DeepSeek和它们组合起来用，效果会更惊喜。

### 快速核对清单

- 会上讨论的每一个事项，最终都对应一个明确说法
- 布置下去的每件事，都有人接、有时间点
- 专业名词首次出现时加个注解
- 保密内容提前做匿名化处理

### 三个高频疑问

**会上有人说了一大堆但毫无逻辑，怎么办？**

- 顺着讨论主题拆成几段来记
- 把存疑的地方单独列一栏
- 会后找本人核实

**关键事项怎么记才不容易出错？**

- 定的是什么事
- 凭什么这么定
- 谁不赞成、理由是什么
- 满足什么前提才能动手做

**一份备忘到底写多细？**

- 定方向型的会 → 依据和定论都要写足
- 议方案型的会 → 重点写不同意见
- 听通报型的会 → 把最要紧的几组数字和上级强调的要求摘出来
