# ('通透是一种什么感觉？ 既是局中人，又是局外人', (2, 24))

你有没有想过，一个人真正“活明白”了，到底是什么体验？

我的理解是：身在棋局中，心在棋盘外。

一方面，你完全看得懂眼前的游戏规则，知道怎么玩才能赢；另一方面，你又不被这套规则绑架——因为你心里清楚，规则从来都是既得利益者写好的。想通了这一点，那些所谓的PUA、洗脑，也就很难再套住你了。

同时，你的情绪可以尽情流淌，该哭就哭，该笑就笑。但你心里还住着另一个自己，像站在屋顶上，低头看着这个肉身在人间经历爱恨情仇、为琐事纠结、为某人难过，然后轻轻说一句：我知道。你不是在演戏，你是那个既演着戏、又清醒看戏的人。

说白了，通透就是——既认真入局，又能随时抽身；既全力以赴地活着，又始终知道自己是谁。
