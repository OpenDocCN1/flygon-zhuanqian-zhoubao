## 二、背后的实现原理

### 1）工作流怎么搭建？

打开 Coze 官网 [`www.coze.cn/`](https://www.coze.cn/)，首页最显眼的位置就写着已经接入了 DeepSeek-R1 模型。

![](img/1a6a276eac7d136519482e0ad18dcf76.png "None")

然后按这个路径进入：工作空间 → 资源 → 工作流。

![](img/f4b947c87cf2645f1ab3b7b83576b945.png "None")

点进去就能新建工作流。飞哥已经提前搭好了，直接看完整链路。

![](img/e38b4008e543a5a4ea3a2c758d0ef28e.png "None")

下面拆解一下每个节点到底在干什么。

#### ① 开始节点

![](img/ee346a9c6df9d25aa2865cdebc27190f.png "None")

这个节点默认就有，飞哥在里面配了三个参数：

1. `org_url`：想仿写的公众号原文链接，非必填。如果填，就要用 `mp.weixin.qq.com/s/xxxxx` 这种格式。
2. `Prompt`：写给他的提示词，不需要多复杂，比如“请用大白话生成一篇 DeepSeek 的科普文”就行。
3. `feifshu_folder_token`：飞书文件夹的 token。

#### ② 选择器节点

这个节点专门判断 `org_url` 填没填：有链接就走仿写分支，没链接就走自由创作分支。

添加方式：底部“添加节点” → 选择器。

![](img/8147dd1473eeded7c03bf573bc3b7353.png "None")

判断逻辑很简单：先看 `org_url` 是否为空，再看它是不是一个合法的公众号文章链接。

![](img/c132e90af864b152a375ca7bb707d9be.png "None")

#### ③ 提取公众号文章内容

只要传了原文链接，就先调“链接读取”插件把内容抓下来。

添加路径：添加节点 → 插件 → 链接读取 → 添加。

![](img/40074fa6ecb111e8cd82fd5ff618146a.png "None")
![](img/8137a024bbdf61959bb8e95762219ad8.png "None")

这里只需要把开始节点的 `org_url` 引进来就行，飞哥把这步重命名成了“解析公众号链接内容”。

![](img/7aac2724728fc7fd0327a48273394310.png "None")

#### ④ 调用 DeepSeek 大模型节点

接下来就是重头戏——让大模型写内容。

同样点“添加节点” → 选择大模型。

![](img/641de7438c801ef10506dc95cfe0c2af.png "None")

模型选 DeepSeek-R1，系统提示词里指定它是公众号创作专家，并且要求用 Markdown 格式输出。

![](img/c6d34c1c9317cdf75794a41ec84d7538.png "None")

没传原文时的创作节点，逻辑基本一样，就不重复说了。

#### ⑤ 变量聚合节点

这个节点用来把不同分支的输出汇总起来，正好匹配这个场景：把“无原文写作输出”和“有原文写作输出”都选上。

![](img/9af54ea3f1cda47dd1b21002367d69db.png "None")

#### ⑥ 生成标题节点

DeepSeek-R1 在生成正文后，其实也自动带了一个标题。我们要做的只是把标题单独提取出来。

用豆包大模型就能轻松搞定。

![](img/1d3aad57f990cdc67ef391dc4be5b585.png "None")

#### ⑦ 创建飞书文档插件

这个插件负责把内容写进飞书文档。添加方式跟第③步一样，在插件里搜“飞书文档”，然后选“飞书云文档 → create_document → 添加”。

![](img/c6e8ad706cddd753a029eaf62492468b.png "None")

只需要把大模型生成的内容和文件夹 token 传进去。

![](img/4843f5837b9bc398a9b261fd6ed31cbf.png "None")

#### ⑧ 输出节点

![](img/cc3b55013d2069b7eb8f0fbfde5720d0.png "None")

输出节点负责把最终生成的飞书文档链接打印出来。

#### ⑨ 测试工作流

点“试运行”，把必填参数填上，点运行。

![](img/76aaf8aa71da03920688994e45fd83d7.png "None")

差不多 2 分钟，一篇文章就出来了。

![](img/fd025640fd7ab1548b96f23bce37c49d.png "None")

打开链接看成品。

![](img/88c8728bb35522d58f6e7a8676896076.png "None")

再拿腾讯原创检测跑一遍——原创比例 90%，同样很顶。

![](img/b057908d20900fb2d0be15d26f9b2afe.png "None")

配张图就能直接发。工作流调好之后，点“发布”就可以给别人用了。
