# ('DeepSeek 崩溃用不了，我用 Cursor 开发了一个 DeepSeek 自动回复插件', (2, 48))

最近 DeepSeek 是不是又把大家急得够呛？一会儿提示“服务繁忙”，一会儿又跳出“无法联网搜索”，聊着聊着就断线，体验实在一言难尽。

这背后的原因大家都懂：国外攻击一波接一波，再加上用户蜂拥而至，服务器根本扛不住。虽说市面上能找到不少接入了 DeepSeek API 的第三方站点，可真正用起来你就会发现，论效果和稳定性，和官方版本还是差着一截。

与其干等着，不如自己动手。于是作者伟豪干脆打开了 Cursor，让 DeepSeek 自己帮自己“治病”——开发了一款自动回复插件。这个插件干的事很简单：只要对话框里出现“服务器繁忙，请稍后再试”之类的提示，它就会自动重新提交刚才的提问，完全不用你守在电脑前狂点鼠标。

这样一套操作下来，就算官方通道依旧拥堵，也能靠自动化硬生生把使用体验拉回来一点。评论区里有人问实际操作如何、回复率高不高，作者也回复了：主要是人太多，所以靠工具自动点击，省去人工盯屏的麻烦。

思路倒是挺巧，工具不够，AI 来凑。如果你也被 DeepSeek 的崩溃搞到没脾气，不妨学学这位老哥，让 AI 帮你“自救”一把。
