# 赚钱一年，我从边缘到出圈，竖屏思维导图这条路是怎么走来的
作者：龙哥



距离我正式加入赚钱社群满一周年，只剩下不到一个月。

初入时的我几乎没存在感，往事也没什么可炫耀的。

当时给自己立下了一个硬指标：在社群里完成一次竖屏思维导图的公开分享。目标刚定，心里先是一阵发虚。自己到底能不能扛住？脑子里冒出的第一个念头是害怕，但同时也有一个很小的声音在说，试试看没准行。

具体路径我当时完全摸不着头脑，也没有现成的攻略可以抄。最后只能选择把这件事先搁置，靠时间去发酵。

开局前三个月基本处于懵圈状态。真正的转折点来自于后来跟队共读《龙哥益语》，那段共读帮我理清了竖屏思维导图的玩法和大致方向。

从迷茫到跑通，势头就起来了。到现在为止，我在赚钱内部一共牵头组织了四场导图共创，累计参与志愿服务四次，两次受邀担任思维导图特训营的主教练。与战友们共同沉淀的导图作品总数已突破四百张。

下面这部分，我想把这一年走过的坑和关键节点大致梳理一下。

也要特别说明，感谢赚钱的信任与邀约。十二月以及三月的两次小航海行动，我都有幸担任思维导图特训赛道的带队教练。
