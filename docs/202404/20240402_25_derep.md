# 从0到三个月入账7W+，这个应届生靠小红书笔记做了什么？

头一回发帖，愿你点开后能有些收获。

嗨，我是章易，一个01年出生的年轻人，刚离开校园不久，正走在自由职业的路上，心里装的是财富自由。去年我进入赚钱圈子，一年过去，自身的变化让我都感到意外，不论是从零开始时的懵懂，还是现在看问题、做执行的能力，都比以前强了不少。在小红书上，我手底下废掉过数不清的号，可正是这些失败，帮我打磨出一套自己的建号策略和写出爆款笔记的方法。今天，我把这一年摸爬滚打的经验全部讲出来，给大家做个参考。

适合读这篇的朋友：

1. 想尝试小红书的虚拟类目，但还没找到入口；
2. 笔记发了一堆，流量却始终起不来，搞不清爆款到底怎么打造，也看不到收益；
3. 有些迷茫，想发展副业，但不知道怎么迈出第一步，赚到第一桶金。

更多的细节和方法，我已经整理成一份文档放在飞书，想了解的直接点： [https://ogv8250mbw.feishu.cn/docx/Q6ASdyh2voRYSRxAK55cHe0bnJd](https://ogv8250mbw.feishu.cn/docx/Q6ASdyh2voRYSRxAK55cHe0bnJd)

另外，评论区有朋友询问是否卖课，我统一回应：课程和案例资料都有提供。

愿我们都能少走弯路，早日找到自己的赚钱节奏。
