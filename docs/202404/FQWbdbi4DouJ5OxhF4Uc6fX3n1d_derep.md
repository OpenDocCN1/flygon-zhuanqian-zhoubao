# ('参加完上次的思维导图航海，有了自动生成的想法', (2, 24))

我画一张竖屏导图要90分钟，后来干脆做了个自动生成工具

如果你也被竖屏思维导图的排版折磨过，这篇值得看看。

去年4月18日，我成为生财有术的一员，之后一直在里面学习。本职是程序员，业余喜欢做一些小工具网站。这次续费的时候，刚好把“Markdown 转竖屏思维导图”工具做了出来。它算是去年“公众号转思维导图”那版工具的升级版，这次优化得更精细。在这里，也感谢生财有术提供的环境。

为什么想不开做这么个项目？起因是“生财思维导图航海”。当时教练们耐心答疑，也让我第一次发现，思维导图可以做得这么惊艳。我跟着试做了一张，光是竖屏排版里的对齐、配色就折腾了一个半小时。新手阶段，这些操作尤其耗费精力；就算有现成模板，填内容也得反复调。我去找市面上的工具，能支持Markdown转普通导图的不少，但没有支持竖屏导图的。既然如此，不如自己做，目标是降低制作门槛。![](img/469bbba4553954dbd82ecfb6bd6a528c.png)

这个想法能落地，多亏了生财的公众号教练@张波。他会反复问“这工具是给谁用、价值在哪”，我则专注于技术实现。两人讨论了很多轮，经过一次次迭代，才有了现在的版本。

先给你看常规做法有多麻烦：把文本丢给GPT，让它转成Markdown，再复制到Xmind，然后找模板、逐行粘贴、手动对齐。举个实例吧，就拿航海手册的导图来说：![](img/40d8e0f98f67d7c551e8fad777c41729.png)![](img/1f5626a61b5b7b0399bf8ee4149afa7a.png)；把这些Markdown装进Xmind模板后，![](img/8a22f9b3d1f1347420600822d391f841.png)，你会发现每个节点都得手动整理，熟练操作也省不了多少时间。

用我这个工具呢？把GPT输出复制到网页，如果排版乱就手动加几个换行，![](img/1d66d2182fbc842f7e74911a075dc504.png)![](img/8e63adea1d81167912de53e29d1be088.png)![](img/4d311dc7f58c8d47e93396275cc05fa2.png)，然后下载导图文件，用Xmind打开。之后想改颜色，直接在Xmind里二次调整即可。![](img/0892d8a42a510af149c94841bc83070a.png)

工具内置了三种常见模板。第一套“生财模板”，适合新手快速完成简单导图；但子标题不能太多，否则布局会乱。![](img/7ef19e630f774be400a37cb2576cf8e1.png) 第二套“复盘/读书笔记模板”，适合内容量大的场景，子节点最多能到七个，把书目录拆分后还能继续加章节总结。![](img/dacd4047f603c193ee61e61e3daf4935.png) 第三套“自我介绍模板”，固定格式，直接套用即可；劣势是不够灵活，无法扩展。![](img/dedcdb1948c91f635cfab3af0dce17c3.png)

关于模板转换：普通思维导图想转成竖屏样式，现有工具基本做不到，官方也没有提供这种转换能力。![](img/2c117f26efe1e5c5047d79a2c8f0fca1.png)![](img/0594f2e78598ab8f2b8320c6ece6d539.png) 我的工具能实现模板切换，前提是导图都用Markdown在系统内生成，要换模板时直接把Markdown粘贴到对应主题下就行。

变现方面，我看到了三种可能。第一是闲鱼：竖屏导图单价高，竞争者少，但手工做太耗时，审美差异又大，很多人宁愿不接单。![](img/11ee9c1bdc61f75864fc1d635d571987.png)![](img/269547d0022e06216053f1002ebb9c12.png)![](img/577f2be8464690a2ccc1d7b13af452ac.png) 第二是淘宝：搜“竖屏思维导图”有同行在做，还有人误以为这是PPT而不接；如果真要接，一单100元也正常。![](img/07e7d9ee06cf0993a86c5ebff2128afd.png)![](img/ef77e46bb2371a2fd228b15e255c70cb.png)![](img/f26ff5c4fa0d9177f1ad8570791c336c.png)![](img/173cbb944c40882a4f960ef580bf623e.png)

第三是小红书涨粉。航海手册建议重点做小红书，它可能更适合图文内容。![](img/4c78834bdc2fa791c327259b4915dc0c.png) 我试着做了一阵，数据一般，![](img/43335903ede01881cdfd1f033b7b369a.png)![](img/73e264b7073ea985189b62d9b73f34ab.png)![](img/7d86dea2e02b148d72cb7d44ca1d5cfa.png)，但有一篇算小爆，甚至有用户私信要模板——说明需求是真实的。我也清楚自己不太擅长内容，这次纯粹为了测试变现模型，所以号没能起来。生财案例库里关于小红书运营的资料很多，普通人要做好确实有难度。抖音图文、公众号图文，我暂时没深入测试。

当然，任何航海项目理论都能变现，但落到自己手里，还是要亲手试一次才知道结果。上面的体验就是一种验证。

未来想把工具继续升级。第一个方向是“直接输入文本”。现在用户还是要先让GPT产出Markdown，不同模板对子标题数量要求不同，常常需要反复调整；如果省掉这个环节，用户只需输入内容，系统就会自动匹配最合适的模板。第二个方向是支持更多文件格式。视频、音频、PPT、Word等媒介，现在还要先转成纯文本再转成Markdown，流程可以继续压缩。第三个方向是丰富模板库。现在只做了几个基础模板，后续会增加更多样式，比如![](img/74fee84f73d8eb669dba256ac70517d0.png)，也可以做些接近成品的商单初稿，用户稍微改改就能交付。
