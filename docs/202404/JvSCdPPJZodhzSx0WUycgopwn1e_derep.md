# 从失业幼师到绘本爆款：AI数字人让她两天斩获100万+小眼睛

2024年1月，我还在小红书的店铺赛道上摸索。那时认识了小美，一个宁夏姑娘，个子不高、模样清秀，说话会脸红。她白天在幼儿园带小朋友，晚上经营绘本小店。幼师收入不高，她希望靠副业多挣一点。因为我们都是新手，又都有点“社恐”，所以很快熟悉起来。

后来我的店卡住瓶颈，担心继续下去只会亏更多，就果断撤了。小美却不肯走。她说，做绘本店就像种树，每天浇水、施肥、看它长大，舍不得放弃。我看着她朋友圈里的复盘笔记，一边佩服，一边又隐隐心疼。

在现实面前，光有热情远远不够。小美最大的坎，是不敢出镜。她可以在拍摄绘本细节时极有耐心，把每一张图都修得像艺术品，可她始终不愿露脸。我也曾建议她真人出镜，让绘本和她的气质一起被看见。她鼓起勇气拍了两条，却因为太紧张，动作表情都很僵硬，播放量也不理想。我那时候甚至有点自责，觉得自己不该乱出主意，害她怀疑自己。从那以后，我很多话都不敢再说了，专心捣鼓起数字人。

数字人这条赛道给了我很大变化。我不只认识了很多同路人，收入也有了前所未有的增长。某天我看到小美在朋友圈给我的内容点了个赞。我记得她以前说过，她很少给别人的内容点赞，能被触动才会按下去。我当下冒出一个念头：也许可以用数字人技术，替她解决出镜难题，顺便救活绘本店。

我犹豫了一下，还是发了消息：“小美，谢谢你点赞。我最近在做数字人，说不定能帮你提高绘本销量，你愿意试试吗？”

消息发出去，半小时没有回音。我有点坐立不安。快一小时时，小美终于说话了。她告诉我，最近运气太差：幼儿园因为经营不下去要关门，她下个月就要失业；绘本订单冷清，心情跌到谷底。她说看到我的消息特别温暖；以前一起做小红书店时，我们还是同样的新人，现在我却在数字人领域做出成绩了，她既替我高兴，又怕我们差距越来越大。她最后吞吞吐吐地说：“我知道你的收费不低，但我现在最多只能拿出一万块，不知道够不够……”

看着这些文字，我能想象她有多难开口。我几乎是立刻下决心：无论如何，要帮她一把。我回复她：“钱的事先放一边，出了结果再说。你只需要拿手机录一段2-3分钟的视频，把镜头当成幼儿园里的小朋友，像平时上课一样，语气平和地讲内容。录完发给我，剩下的交给我。”

她坚持要先付钱，我也不再推辞，想着如果效果不行，一定全数退还。就这样，我们正式开始了这次少儿绘本项目的合作。

技术时常被认为是冷冰冰的，但当它用到对的人身上，就会变成一束光。它不只是技术升级，更是一种表达权的解放。现实中，我们总以“有没有镜头感”来判断一个人能不能做内容，却忽略了很多美好是藏在镜头之外的。小美在孩子面前会自然发光，可一旦面对陌生人，她就像缩进壳里，满身才华无处释放。这并不代表她没有魅力，只说明她没有找到一个适合她的表达方式。

数字人的价值，恰恰在于打破了这种限制。它不需要小美硬装外向，也不需要她克服基因里带的恐惧；数字人可以模拟稳定的情绪，还能不知疲倦地持续输出，把她在课堂上的亲和力完整呈现出来。网络上的武汉幼师“花开富贵”，凭一首“挖呀挖”让全网记住了她，靠的是轻松愉快的课堂氛围。小美的外形和亲和力都不输，她缺的只是一个能绕开镜头恐惧的载体。当她拥有一个AI替身，她就不必再把精力耗在“如何显得自然”上，而是把自己最温暖、最有爱的一面完完整整交给观众。

我花了整整一小时为她打磨两条视频，从节奏到表情，每一帧都反复调整。当小美看到成品时，几乎不敢相信：“这真的是我吗？原来我也可以在镜头里这么自然、这么真实。”她有些不好意思，但声音里带着此前少有的信心。我提醒她，发出去的时候，最好隔一小时再发下一条。

3月22日，我把视频交到她手上。第二天，我又给她补做两条，她一直没回消息，我也忙得没顾上多想，只是心里偶尔闪过一阵空落落。直到某个深夜，我正要关电脑，微信提示音忽然响起来。小美发来的是一张截图——视频“小眼睛”已经冲到了100多万。

紧接着她的语音到了，又急又兴奋：“你最开始给我的两条视频，隔天小眼睛就破万了，后台订单一下子涌进来。我赶紧把你后来发的那两条也发出去了。睡了一觉醒来，小眼睛从十万涨到二十万、三十万，一直往上飙……订单多到处理不过来，还好有朋友来帮忙。我现在还在打包发货，真的谢谢你！”

我悬着的心终于放下。这个世界上，不是每个努力的人都能等到同等的回报；但小美那种韧性，配上一次对的机遇，她稳稳站进了那少数人中间。

要说她从此变得外向，那不可能。性格刻在骨子里，哪能一夜翻转。但这恰恰说明数字人的意义所在：它不改变人，而是放大人的优点。小美的专科学历并不耀眼，家世也普通，放在互联网的洪流中，她原本是最不起眼的那一个。可是她把幼师的亲和力、对孩子的喜爱、对绘本的用心，全部嵌进数字人呈现的内容里；那份纯真笑容成了客户看到的第一印象，细节和形象叠加在一起，成交就顺其自然地发生了。

太多人像小美一样，带着改变命运的期待走进互联网，却被流量、算法、镜头一次一次打击，最后陷入自我怀疑。放弃还是坚持？也许我们不该只追问这两个选项，而是该换一条路。客户真正想看见的，不是一个完美产品，而是产品背后那个活生生的人——她的故事、她的热情、她的真诚。只有你的表达足够“像人”，信任才会发生，爆单才有机会。
