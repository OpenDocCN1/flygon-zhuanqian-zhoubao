# 21个SKU撬动单店日销2万+，米村拌饭的供应链打法拆解
作者：龙哥

米村拌饭用极简菜单做出了高坪效的成绩，单店日营业额能突破两万元，背后并非偶然的爆款运气，而是一套围绕供应链搭建的精细化体系。

创始人周强在过往访谈里，曾把这家拌饭品牌的崛起逻辑归纳为四个核心抓手：中央厨房统一生产、标准化的物流配送、SKU的极致精简，以及对门店管理人才的严格甄选。

四个维度环环相扣。中央厨房负责把控口味和品质的一致性，让全国门店吃到同一种标准；标准化物流配送则保证食材新鲜度和上架时效，把损耗和波动降到最低；SKU只保留21个，降低备货复杂度、提升周转效率；门店管理人才的选拔确保前端执行不跑偏，让供应链的优势真正落地到客单价和翻台率上。

正是靠供应链做底座，米村拌饭才实现了少而精的产品策略和高稳定性的营收表现。
