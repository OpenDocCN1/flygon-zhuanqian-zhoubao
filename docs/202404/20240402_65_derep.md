# 别被钱绑架：巴菲特股东信里藏着的一句人生箴言
作者：龙哥

很多人读巴菲特的股东信，只盯着投资技巧和市场判断，却忽略了他随手点出的一句人生拷问。

在 2021 年的那封信里，巴菲特抛开繁复的财务分析，用极简的一句话叩开了职业选择的本质：

选行业、选岗位、甚至选一起共事的伙伴，都不要先问“能赚多少钱”，而要假装自己根本不缺钱来做决定。

这句话乍听反常识，细想却直指人心。

如果你剥离金钱的诱惑，还会不会选择现在的这份工作？这个领域会不会依然让你着迷？这些同事会不会依然值得你并肩？如果答案是肯定的，那你才真的走在了对的路上。

金钱是结果，不是前提。用“不需要钱”的视角筛选职业，才能避开被高薪牵着走的陷阱，找到真正匹配热爱与人品的工作。
