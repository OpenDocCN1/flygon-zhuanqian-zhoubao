# 活着的证据，是你曾主动做过一次选择

我们总喜欢问“你最近怎么样”，却很少去问“最近一次，你为自己做过什么决定”。

李笑来说过一句很锋利的话，判断一个人是不是真的在活着，核心就看两点：他愿不愿意选择，他有没有能力去选择。

顺着潮流走、任由境遇推着走、把所有委屈都说成是命中注定，这样的存在方式，和活着的区别并不大，甚至可以说是一种更安静的消耗。真正的生命感，从来不是心跳和呼吸，而是在某个岔路口，你能抬头、能判断、能承担后果地做一次自己的决定。

人生并非只有大风大浪时才需要选择。每天都在发生的无数个小选择，累积起来就是你的人生走向。但真正考验人的是那些关键时刻。当所有外部条件都指向“别动”，你依然愿意为自己的价值、信念、底线去做一个主动的决定。那一刻，你才算从被动承受的状态里走出来。

主动选择很难，也很贵。正如评论区有人说的，这份能力在当下的文化语境里尤其稀缺。它意味着你要先看清自己，再扛住外界的评价。

活着的意义，从来不是被世界安排得有多体面，而是你在什么时候挺身而出，为自己选了一条路。
