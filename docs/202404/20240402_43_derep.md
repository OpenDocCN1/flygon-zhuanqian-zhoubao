# ('单兵作战自媒体月入 2w 的小副业：AI 修复老照片', (2, 28))

单枪匹马做自媒体，靠AI修复老照片月入2万？

翻开家里的老相册，那些斑驳模糊的脸庞，在别人眼里是回不去的时光，在会 AI 修复的人手里，却可能是一份不错的副业收入。

我是深圳阿岳，一个在设计行业熬了四年半的老兵。从小美工起步，一路做到管理 40 人团队的设计总监。这几年最有成就感的事，就是借助 AI 工具，在没有影响产出、也没有拖慢效率的情况下，把团队人力砍掉了三成。2023 年开始，我又迷上了“视觉设计 + AIGC”的各种尝试。今天想聊的，就是其中一个我亲自跑通的小项目——AI 老照片修复。这个副业不需要团队，一个人通过自媒体接单就能做，做得好一个月能到两万块。

这个项目我连续做了三个月，从发现机会、亲身试水、拿到市场正反馈，再到复制放大，完整跑了一遍。整套复盘写下来有五千多字，认真读完大概需要十分钟。

如果你的体量已经达到千万级，这篇内容就不用看了；但如果你正想轻资产启动，或者只有一两个人一起干，又或者副业收入还没迈过万，那这篇文章大概率能给你一些参考。
