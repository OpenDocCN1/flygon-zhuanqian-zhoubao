# 自媒体新手入门，请先看清这 3 个真相

![](img/753d1a2ec816433f9b2844f1a214dd49.png)

你好，我是龙哥，干了10年品牌营销的广告人，同时也是5年自媒体运营。从🧣时代一路做到现在，我运营过不少十几万粉丝却不怎么变现的号，也做过几百粉丝却赚到上万的号，眼下正在冲击六位数收入。

前阵子有学员问我：新手做自媒体，到底该从哪里学起？作为过来人，有些话不吐不快，干脆写成文章，让更多有需要的人看到。

关于自媒体，我想先说三个真相：

第一个真相：靠自媒体赚个几百、几千块，真没你想的那么难。只要你运气不错做出过一两个爆款，或者服务的群体足够垂直，就能接到一些几百块的广告单。但如果你想靠自媒体做自由职业，拥有稳定收入，彻底摆脱枯燥的工作——成功率连1%都不到。你看到那些声称靠自媒体实现财富自由的人，要么真的是万里挑一，要么只是实现了“文字自由”。
