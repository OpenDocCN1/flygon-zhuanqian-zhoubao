# 我在大厂上班期间副业开实体店，6个月亏掉25万：7个坑，3个教训

都说实体开店别轻易碰，看到这句话时我已经晚了。

我曾在赚钱群里反复看到龙哥的提醒：能不做实体、能不加盟就不做，回本慢、失败率极高。结果我偏偏逆着走，做了艾灸养生加盟店。半年时间，亲手亏掉了25万。

把这段血亏经历拆开讲出来，不是为了诉苦，是想让准备冲进实体的人，先看看坑有多深。

**目录**
1. 为什么我会一边在大厂上班一边去开店？
2. 25万到底亏在哪了？
3. 我踩过的7个大坑
4. 总结的3条血泪教训

**一、我为什么选择大厂期间开副业实体店**

毕业后我在大厂做产品经理，快满五年。互联网下行，焦虑感越来越重，22年我加入了赚钱，想找个副业对冲风险。

前两年跟着航海做过美团电商、短视频带货、抖音团购、出海工具站，项目换了不少，结果一直平平。复盘下来有两个根源：

一是看不上重复的基础活，比如刷素材剪视频，干着干着就抵触；
二是前期收益太薄，剪了八条视频只成交一单，佣金二三十块，自我怀疑感爆棚。

我当时给自己找的理由是：轻资产项目人太多、门槛太低，没壁垒。实体应该不一样。

再加上自己常年加班身体不舒服，想做点养生方向。被圈友介绍到一个艾灸养生加盟品牌，交了5万加盟费就上了路。

**二、半年亏25万，钱花在哪了**

开店前我算过账，启动20万就够了。半年下来总投入超过30万。

一次性启动成本约13万：
品牌加盟费5万；硬装3.3万；大件采购3.5万，包括两台空调1.3万、新风系统6400，电视洗衣机等。

月度固定开销约3.1万/月：
人员工资2万左右，店长9000，员工7000，提成另算；
房租水电7200，房租5600，物业300，水电1000，宽带200；
每月向总部进艾灸耗材4000，艾绒必须从总部进，价格明显高于市面。

还有些杂项：地推团队1万、美团商户通4000。

我当时认为月营收做到3万就能盈亏平衡。实际最高月营收1.8万，最低只有3000，每个月亏1-2万，从未打平。

这半年我无数次想关店又犹豫，总觉得能扳回来。直到看到龙哥转发的段永平那句话：知道错了就马上停，代价就不会更大。我才在第六个月关门。

**三、踩过的7个大坑**

**坑1：没做市场调研就开干**
开店前我一次艾灸都没体验过。以为养生就是按摩推拿，挺好理解。结果养生是个大盘，美容、艾灸、推拿、私密各不同，艾灸里还有仪器灸、手工灸、铺灸。

因为不了解，选址时没注意到艾灸店必须有卫生间。签完合同进装修才发现，选的门面没有卫生间，商圈一楼根本没排污管，根本做不了。

品牌调研也很致命。我去看了杭州一家200平的旗舰店，月流水10万，就以为自己做到3万很容易。后来才知道，该品牌杭州70%的门店都挣不到钱。别人全职都做不起来，我凭什么能？

**坑2：选址小白翻车**
没窗户的房间没考虑到排烟，新风系统要单独装。沿街商铺租金比里面贵2000，我没在意，互联网思维总觉得小钱不算钱。

更糟的是，商圈旁边某大厂，十家养生店扎堆竞争。区域代理商当时说竞争对手快不行了，我们能碾压。开业后才知道，本地服务体验都不差，根本没有碾压优势。

**坑3：装修全靠自己摸索**
品牌只给视觉概念图，具体装修自己扛。最大的坑是新风系统。

师傅按经验装了300匹风力，说能排烟。开业两个月店长反馈没用，排查一个月才发现风力不够，设备白买。

对品类不熟，对接待流程不熟，很多基本问题都是开业后才一个个撞出来。

**坑4：招人难，实体第一难**
总部不包人，我自己在BOSS直聘上找店长，每天私聊50人，花了不少钱，基本没结果。杭州店长行情1.1-1.3万，我小店养不起。

最后靠区域代理推荐招到一个店长，手艺不错，但不懂中医辨证。艾灸重在辨证调理，光会按摩根本不行，效果出不来。

**坑5：人管起来心力耗尽**
店长又推荐了个40多岁的朋友来做店员。两人像姐妹，上级下级关系模糊，经常吵架，店长心力交瘁。

更离谱的是店员私自做微商，把到店客户往自己微信里导。三个月黄金期被拖垮，我当时太温柔不敢开除，错过了最佳调整期。

**坑6：获客手段踩雷**
总部负责抖音美团，我们负责接客。8月开业旺季一天6-8单，10月转凉后一周就3-4单。

总部建议刷好评没用，我找地推。地推套餐68元3次艾灸3次泡脚3次膏药，到店成本我还倒贴40元/人，实际成本100+。

更坑的是，地推外面喊的是68元做9次艾灸。顾客冲着9次来，到店发现是拼盘套餐，直接觉得被骗，口碑崩了。

**坑7：加盟体系不靠谱**
总部定价权在手，美团抖音团单39元一次，远低于市场价。平台抽5元，总部抽10元，耗材成本20元，每成交一单基本就是亏一单。要盈利只能靠转化会员，可我们的专业度和销售能力都不够。

想增加推拿SPA项目，总部直接拒绝。说他们靠我们不断进艾灸耗材赚钱，你做了推拿我们就少赚钱了。

加盟商活不下去，总部照样收钱。

**四、3条血泪教训**

**1. 没有甩手掌柜，开店老板必须在场**
开店前被画饼说招好人就能每月稳定1-2万躺赚。现实是，做得好的店老板都在店里。

老板就是门店的定海神针，你不在，员工就会松。六个月我平均每周去店里不到一小时，店长多次说没底。我自己也知道不对，就是做不到。

古茗创始人访谈里说过，他们宁愿拒绝纯财务投资、不在店里的加盟商。门店是人的生意，不是资产的生意。

**2. 一切成本都要付两次，别高估自己的执行力**
买本书，第一次付钱，第二次付时间读书才有用。开店也一样。

我算了13万启动费和每月3万成本，却没算持续投入精力的成本。我以为能每天抽1-2小时，周末全天坐镇。结果一周一小时都挤不出来，累、逃避、心累。

决策前高估了投入意愿，低估了隐性时间成本，这是最大的失误。

**3. 实体杠杆极低，务必发挥自身优势**
刘飞说过，做了9年互联网再做实体，才知道互联网杠杆多高。没有库存、没有供应链、没有快递。

实体是我花10小时累到腰疼接4个顾客，营收300。互联网敲几下键盘就能影响几万人。

创业一定要选擅长的。我有5年产品运营经验，做互联网才匹配。硬去做陌生的实体，折腾半年买25万学费。

写到这里，道理我开店前都懂，却还是撞了南墙。折腾过的教训，比听来的话更扎实。希望这篇文章能帮你避开这些坑。
