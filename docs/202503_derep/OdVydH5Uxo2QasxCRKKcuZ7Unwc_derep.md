# 一次租房押金维权，我把200元的“清洁费”追回了一半

> 来源：[https://r9r259cvxs.feishu.cn/docx/OdVydH5Uxo2QasxCRKKcuZ7Unwc](https://r9r259cvxs.feishu.cn/docx/OdVydH5Uxo2QasxCRKKcuZ7Unwc)

年后工作地点从义乌挪到杭州，房租正好卡在2月底到期。退房那天我把房间打扫得干干净净，房东却说不在家晚点看。拖了好多天后，他忽然以地面没擦干净为由，直接扣了我200元卫生费。

我是2月23号特地从杭州跑回义乌再清理一遍才走的，全程有照片留底。最后在维权后，拿回了100元。

说实话，押金被扣的瞬间我气得不行。租的时候房东客客气气，退租时就变脸恶意克扣。我性格一直偏向ISFP，过去职场生活里吃亏了大多是多一事不如少一事，自己咽下去。这次我告诉自己，要从维护合法权益开始改掉这个毛病。把这次经历整理出来，也算给遇到同样情况的朋友一点参考，顺便算是省钱有术了。

# 二、维权前我做了哪些准备

维权最怕空口无凭，证据一定要先备齐。

1、租赁合同的完整文本
2、租金转账的截图记录
3、房屋状况的影像资料。我手上只有退租前的照片，入住时没拍。提醒大家，入住和退租前后都要拍照留存，避免事后扯皮。
4、与房东的所有沟通记录。现在基本都用微信沟通，尽量用文字，不要语音电话，方便日后举证。

另外一个小建议：入住前后拍照，沟通尽量文字化，涉及钱款的结算尽量当面搞定，别给对方事后找理由扣钱的机会。

# 三、我是怎么一步步维权的

## 1、先尝试协商

我参考了网上一些案例的说法，比如提醒对方消防合规、发票未开具等问题。结果房东直接摆烂，说房子不租了，跟我硬杠，中间空置的损失还要我赔，用这种方式来吓退我。协商无果，只能走别的路。

## 2、找渠道投诉

第一步，我打了当地110。警察回复只能现场调解，属于个人纠纷，给不了实质性帮助。我在杭州，对方在义乌，来回成本太高，而且对方已经开始耍赖，我也担心当面安全问题，最后放弃了这条路。

第二步，转向线上投诉。
我查到几个点：未开票涉及偷税，可以向税务部门举报；浙江本地有浙里办线上信访；实在不行还能线上法院立案。

我先用了浙里办线上举报。周末提交，周二两个工作日，街道的工作人员就去找房东谈了，最后协调退回100元。因为我入住时的原始状态照片没有保留，所以没有继续死磕，接受了这个方案。

这次的经验是：能有文字留痕的线上渠道就用线上。大部分线上举报都会有工作人员跟进并给出处理结果，流程相对闭环。电话举报基本很难推进。

# 四、租房渠道和注意事项的血泪总结

## 1、怎么找房源

连锁品牌如自如这类，线上就能筛选通勤和预算，确定范围后再实地看。缺点是服务费会比房东直租贵，优点是APP全流程线上结算，适合社恐的I人。

小红书、抖音的租房笔记和租房群，也能刷到部分转租和房东直租的信息。

问朋友。去北京时朋友推荐豆瓣租房小组和暖房小程序；后厂村那套性价比很高的房东直租也是豆瓣小组找到的。暖房上也有不少个人房源。

线下看告示栏。南京、义乌的一些小区楼下公示栏，房东直租信息还不少。

58同城的个人直租。二三线城市有时候会有惊喜，我之前也是在上面找到的合适房源，作为补充渠道很不错。

## 2、看房签约要注意什么

货比三家。像逛超市一样多看几套，你才能清楚自己要什么朝向、什么格局，也不会被房东看出你很急而压价。

看房时间尽量白天。采光、潮湿情况晚上根本看不出来，白天看更靠谱。

合同别糊涂签。重点看能否转租、中途违约怎么算。最好自己带一份模板去，双方权益写清楚。很多房东准备的合同只写了租客的义务，不写自己的。正常来说，房东要负责水电维修，租客有妥善使用义务，双方违约责任要对等。

核实身份。签约付款前，确认对方是不是房东本人，看房产证或相关证明。如果是中介或二房东，也要看原房东的产权证明和授权文件。

# 五、最后的感想

维权的过程我全程都很不舒服。小时候好像没人教过我们要去争取权益，吃了亏就自己扛。但其实很多亏是可以避免的。希望和我一样性格的人，别再怕麻烦。事情发生了，就敢于用合理的方式去争取自己的合法权益。在赚钱有术的路上，遇到恶意的时候，多一点勇气。今天先给自己鼓个掌。
