# ('老板避雷手册 5：如何招聘、筛选小红书运营人员', (2, 25))

老板避雷手册第5篇来了：小红书运营到底怎么招、怎么筛？

很多人觉得公司做不大，是管理不到位、培养不够狠。但真正的问题，往往在源头上就已经埋下了——招进来的那个人，一开始就是错的。

今天想聊这个话题，是因为看到了“只做小红书高客单珍妮”分享的避雷心得。她本人从1500元起家，在留学、房产这两个赛道里，既做过自营，也做过代运营，都跑出过成绩。也是因为亲身经历过小公司从0到1的全过程，她对招聘、筛选、定薪、管理这一整套流程，算是摸得透透的。

她之前就写过“老板避雷手册”系列，还被龙哥盟邀请做过直播分享。这一年间，她面试和带过的运营越来越多，也踩到更多“筛人雷区”。她发现一个很扎心的事实：一个不合适的人，你花再多心思去管、去教，最后基本都是白费。

那么，到底该怎么避开这些坑？她总结了三个关键问题：

第一，怎么用更低的成本招到人？
第二，怎么判断一个候选人适不适合做小红书运营？
第三，怎么控制运营的人力成本？

这三点，是每个想在小红书上做出成绩的老板，都必须想清楚的。

有意思的是，评论区里也有很多人分享了自己的实操经验。有人说，以前招人时简历收一大堆，挨个聊下来特别浪费时间，有时候微信聊完转头就忘了。后来学乖了：先让对方发邮件，并且把要求写清楚，再设置一些小门槛，把明显不合适的人先筛掉。这样既省时间，又能快速锁定真正靠谱的候选人。

说白了，招聘不是碰运气，而是设计流程。源头把关严一点，后面管理才能轻松一点。
