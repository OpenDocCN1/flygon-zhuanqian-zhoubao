# ('#龙珠悬赏 04 不管是做产品，还是做服务，最重要的是先抓住真需求，而不是搞流量', (2, 42))

你有没有过这种感受：一个问题让你难受了很久，却一直找不到好用的解决办法？这时候，只要有人做出一个靠谱的产品，价格也合适，你会毫不犹豫立刻买单。

这种感受背后，就是真需求。

做产品也好，做服务也罢，最重要的从来不是先折腾流量，而是先抓住真需求。需求一旦摸准，产品自然做对，流量也会跟着水到渠成。

真正的需求，通常就藏在你最难受、最想解决的那个点上。所以这一期，我们想发起一个征集：有没有某个具体的场景，让你痛得足够深？深到只要出现合适的产品、价格也说得过去，你会立刻付款，连犹豫都省略？

这个场景不限领域：赚钱、工作、生活、副业、衣食住行、吃喝玩乐、个人爱好……统统可以。由你自己亲身体验到的需求，就是最货真价实的真需求。如果你觉得这个需求恰好能用AI相关产品来满足，那就更棒了。同时，也很欢迎你分享自己挖掘、判断需求的方法和心得，内容优质会被加精。

参与方式：在赚钱社区发帖，打上“赚钱朋友圈”和“龙珠悬赏”两个标签。描述越细越好——你当时在什么场景里？正在做什么？卡在了哪一步？心情怎么样？有没有试过找解决方案？最好能配上照片或截图，让大家更直观地感受到你的困扰。

别担心自己是“小白”没话可说。恰恰相反，越是普通用户，你的真实体验越能代表大多数人的共同处境，价值也越高。

看看评论区里，已经有不少人晒出了切肤之痛：有人觉得当季水果很难买到好吃又安心的；有人吐槽AI写作正文还行，但标题永远一股“AI味”，改提示词也救不回来；有人特别想要一个能统筹工作、生活、健康的个人AI助理；还有人发愁广告投放时不知道怎么辨别渠道资源是否靠谱……这些看似小而散的痛点，背后都是真机会。

来吧，大胆说出你的真需求。本次征集截止到3月31日。
