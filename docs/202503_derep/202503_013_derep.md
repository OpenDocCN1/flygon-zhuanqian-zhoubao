# 照着龙哥的提示试了七天，到手四位数



## 获赞 241 的实操复盘：一条提示，七天跑出四位数

撰文：代一
日期：2025-03-19

二月底，妻子偶然看到一种手绘感很强的短视频，觉得观感讨喜，也看好后续空间，便想利用业余时间试一试。

我当时其实没太放在心上。她独自折腾了几天，前前后后做出十几条内容，还真被她撞上一条小爆款，粉丝过百后顺利解锁了平台分成。但实际收益相当有限，顶峰时一天也只是个位数；偏偏素材去重不够彻底，原创标识和广告权益偶尔会被平台收回。

后来，龙哥在站内放出一条机会提示，我才意识到这条路值得认真走一遍。于是踏踏实实做了七天，把整条链路彻底走通，最终到手四位数。这七天的操作过程，我整理成文，把一些外面付费课也很难听到的打法和细节一并放了出来。
