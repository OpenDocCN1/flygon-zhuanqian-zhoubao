# 明明创业和自由职业这么累，你到底图什么？

总有人在朋友圈里吐槽自由职业、创业的苦：没人管、没社保、收入不稳定、天天焦虑。

既然这么苦，为什么赚钱有术里还是挤满了人？为什么你，包括我，依然选择一条看似更难的路走下去？

其实支撑我们留下来的人各不相同，但仔细听，都是同一个逻辑：不想把生活的主动权交给别人。

有人说得很直白，上班根本发不了财。用时间换钱的上限，早就被制度框死了。

有人已经尝到甜头了。一旦你自己能定价、能选择客户、能把收入和能力挂钩，就回不去那种干得多拿少的感觉了。

也有人更现实一点，为了给家人更好的生活。不是为了风光，是想给孩子更多选择，给父母更少担心。

有人就是找不到满意的工作。钱多事少离家近，这样的公司不是没有，是对我来说不存在。还不如自己当自己的老板。

还有人形容上班像温水煮青蛙，是钝刀子割肉。每天都在耗，看不到边际。

不想早起挤地铁、打卡、开无意义的会，自由职业至少能自己决定一天从什么时候开始。

当然也有人承认，苦是真的苦，但好玩。打工一眼看到头的日子太无聊了，自己创业哪怕折腾，至少每一步都是自己的故事。

最核心的那句话是：上班是卖时间，创业是买可能性。万一成了，这辈子就不一样了。

所以不是我们不怕苦，是我们怕的是另一种苦——一眼望得到尽头的平庸。
