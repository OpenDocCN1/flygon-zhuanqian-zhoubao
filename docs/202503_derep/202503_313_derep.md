# 三个月长视频开通高级 YPP 复盘-工作流分享

都说AI时代做内容，人人都是导演。可为什么有人三个月就能拿下YouTube高级YPP，有人折腾大半年却还在原地打转？或许差距不在创意，而在有没有一套完整的工作流。

富百的经历就是一个很好的样本。他原本是数据分析师，如今一个人全职做内容已经一年半。小红书直播切片，他做过，半年利润40万；抖音实拍带货，他也试过，单月最高GMV突破10万。现在，他把全部精力压在了YouTube长视频上。

最近，他把自己三个月开通高级YPP的完整过程做了一次复盘，重点分享了两块：

- 长视频有哪些被验证过的主流内容类型
- 他这三个月亲手搭建起来的长视频工作流

用他的观点来说，AI时代写代码、做文案都变得更容易复制，大家硬技能的差距在缩小，真正拉开人与人之间距离的，反而是工作流。这次公开分享，也是想帮大家提效，少在重复造轮子上浪费时间。
