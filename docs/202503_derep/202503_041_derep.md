# 建筑师到小红书带货人：我是怎么在护肤赛道拿到 20% 以上的利润率



## 建筑背景转身做小红书电商，护肤品类做到 20%+ 利润率的实操复盘

作者：齐亚子
日期：2025-03-17

大家好，我是齐亚子。从2020年4月入赚钱到现在，续费坚持了整整五年。这五年里我一直在闷头学习、试错赛道，却很少在社区里分享。今天鼓起勇气，把过去几个月在小红书电商上的实战经历梳理出来，和大家交流。

我真正开始接触小红书电商，是2024年4月的事。之前对电商完全零基础，小红书对我来说也就是个搜索工具，笔记从来没发过，账号粉丝屈指可数。能取得现在的成绩，跟做电商多年的老手比起来当然不算突出，但对于像我这样从零起步、还要带两岁多女儿、只能做兼职的人来说，我已经很知足了。

更关键的是，我没有任何电商经验，也不是护肤专业的科班出身，更没有走先做IP再变现的老路。我的做法很直接：第一篇笔记就是带货笔记。玩法简单粗暴、上手极快、复用性强，对个人创作者或小团队来说非常友好。
