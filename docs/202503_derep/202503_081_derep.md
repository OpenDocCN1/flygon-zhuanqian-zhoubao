# 怎么看待“快手”这个平台

最近有位朋友跟我聊起快手，他挺困惑的。

他说自己过去一年在快手踏踏实实做，赚了几十万，还带了一帮人一起干，团队里也有好几个突破了十万收入。但有个问题一直让他心里犯嘀咕：身边几乎没人聊快手，大家要么埋头做抖音，要么扎堆小红书、视频号。他忍不住怀疑：我们是不是找对了路，还是找错了坑？尤其最近快手规则变动不少，他开始纠结，要不要换个平台重新开始？

这个问题其实挺有代表性的，我给他讲了讲我的看法。

一个地方挤满了人，你再挤进去，大概率分不到多少东西。现在快手没多少人讨论，你恰恰应该偷着乐——你去做抖音、视频号、小红书的人那里打听打听，他们整天焦虑成什么样了。

不可否认，快手的盘子确实不像那几个平台那么大，上限可能低一些。但对你来说，这根本不叫问题。你想在快手赚到让自己满意的钱，这个空间不但存在，而且比你想象中宽裕得多，足够你放开手脚折腾很久。

所以现在真正该想的，不是“我要不要换个平台”，而是“我怎样把快手这条路上的收入再翻几倍”。你已经用结果证明了自己选对了地方，与其去陌生战场重新开局，不如在熟悉的地盘上把优势彻底打透。

哦对了，评论区有人说了一句挺有意思的话：在快手做到十倍，比在抖音做到两倍更容易——当然，这话只对当前的你成立。
