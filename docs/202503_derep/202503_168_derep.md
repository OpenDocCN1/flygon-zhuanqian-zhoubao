# 给还在纠结要不要航海的伙伴，这份周四直播逐字稿别错过

原文出自：[`www.yuque.com/for_lazy/zhoubao/alwesrrgg5i7f924`](https://www.yuque.com/for_lazy/zhoubao/alwesrrgg5i7f924)

最近被龙哥上周四的那场直播彻底打动了。

事情是这样的，明天是我裸辞一周年的直播，还请了雪姨来把关。她在聊到流程时提到，周四龙哥的那场分享在节奏把控和思路展开上特别顺畅，就问我有没有意愿帮忙把那场整理成逐字稿。我答应下来后，周末就把回放完整听了一遍，把 Get 笔记导出的初稿再逐句校对、排版调整。

说实话，听完后收获很大。龙哥在直播里讲的初心很真，关于行业趋势的判断也特别清晰透彻，整个逻辑都很通透。

如果你现在也在为航海这条路犹豫不决，或者对方向、时机拿不定主意，这份整理好的直播记录很值得你静下心来看一看。

有圈友在评论区问这份稿子整理起来费不费劲。

确实花了大概两天时间。先用 Get 笔记把直播原稿导出来，再一句一句对照回放梳理、修正错字和语序，最后调整成方便阅读的格式，才成现在这个样子。希望能帮到同样在路上的人。
