# 用标签批量扒 Shorts 爆款和对标号，RPA 工具实操分享



## 根据标签批量采集爆款 Shorts 及账号的 RPA 方案

作者：Jiahao
日期：2025-03-05

嗨，我是 Jiahao。Youtube 自带的标签搜索页体验很让人头疼，想看发布时间、看视频详情都得一个个点进去，重复又耗时间，全是低效的体力活。受不了这种手工操作，我就做了个自动化小工具来解决这个问题。

这套工具的思路很简单，就是用 RPA 机器人来跑。你只要在 Excel 里把想抓取的标签批量填好，脚本就会自动去拉取指定数量的视频信息，省去逐条点开的麻烦，后面找对标账号和做选题参考会快很多。
