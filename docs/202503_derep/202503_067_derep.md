# ('创业者可能忽视的团队——支持性团队的管理逻辑和价值思考', (2, 29))

很多创业者习惯把目光聚焦在销售、产品、研发这些“前台”岗位上，却常常忽略另一类同样重要的角色——支持性团队，也叫职能团队。它们看似不直接创造收入，却深刻影响着组织的运转效率和文化根基。

分享嘉宾是一位资深HR从业者，从传统行业到互联网，再到游戏行业，长期从事人才发展、组织发展和招聘工作，也曾和朋友一起做过电商创业，虽然没赚到钱，但积累了宝贵的实战视角。去年他再次离开职场，与老同事对接投资资源，共同创业做游戏公司的配套业务。他本人擅长人才发展、培训体系设计、课程开发，也愿意为社群伙伴免费提供咨询。

这次的内容，是他结合在一家知名公司三年多的亲身体验，以及和多位创始人长期交流后沉淀下来的思考。他提到，这些道理与圈内很多大咖的观点不谋而合，这也是他加入赚钱后倍感幸运的原因之一。

重点来了：关于支持性团队的价值逻辑梳理，请直接看原文中的“2.1.3”章节。这部分能帮你理清职能团队到底在创造什么价值，以及如何衡量它们的工作成果。

这个逻辑有两类典型应用场景：
第一，当团队规模扩大时，用这套思路统一大家对工作理念和文化的认知；
第二，以此框架去反推每一个岗位、每一类角色的核心价值到底是什么，以及怎样判断和评估。

对于创业者来说，最大的价值在于：用这个逻辑重新审视你公司里的各个岗位，想清楚如何评价他们的产出，如何判断他们真正的工作贡献。
