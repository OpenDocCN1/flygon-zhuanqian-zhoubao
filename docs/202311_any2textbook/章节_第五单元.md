## 第 7 章 用"咨询思维"跑通你的成长飞轮

### 7.1 一套可以打包带走的通用解法（概念）

咨询行业在长期实践中沉淀出一套普适性的问题解决框架，素材把它总结为**四步法**：

1. **界定问题**：明确真正要解决的是什么；
2. **拆解问题**：把大问题拆成可处理的小问题；
3. **执行解决**：针对每个小问题制定并执行方案；
4. **总结复盘**：回顾全过程，沉淀经验教训。【src=20231114_08】

这四个阶段构成一个从"发现问题"到"沉淀经验"的完整闭环——这正是一个人成长飞轮的骨架。

### 7.2 方法论非线性：跳着用的路线图（原则）

很多人在学习新方法论后会"死板套用"，以为必须严格按顺序走完每一步。但四步法的核心特征恰恰在于——**所有步骤都是可以跳的**。

- 对**熟悉**的领域，可以直接跳过界定问题甚至拆解问题（"这个问题我太熟了"）；
- 遇到**意外**情况，可以随时回到前面的步骤重新调整；
- 不存在任何"在真空中丝滑运行"的工具，反反复复、甚至上线就踩雷都很常见。【src=20231114_08】

> 生活类比：四步法就像用 GPS 导航。熟悉路段你可以直接跳过"规划路线"靠直觉走；堵车时可以随时重新规划。从来没有哪张地图要求你每一步都严格照做。

### 7.3 议题树：把大问题切成小问题（方法）

最能体现结构化思维的，是**议题树（Issue Tree）**——将一个大问题逐层拆解为若干个小议题的结构化分析工具，其核心原则是 **MECE**：

- **Mutually Exclusive（互不重叠）**：同一层级的小议题之间不重叠，避免重复分析；
- **Collectively Exhaustive（穷尽所有可能）**：所有小议题合起来能完整覆盖大问题，没有遗漏。

> 示例：分析"为什么产品销量下滑"——第一层拆为"外部因素 / 内部因素"；"外部因素"再拆为"市场竞争 / 政策变化 / 经济环境"，"内部因素"拆为"产品力 / 渠道力 / 营销力"，逐层展开成一棵完整的树。【src=20231114_08，方法提炼】

同时，素材补充了几个对新手非常友好的判断：
- **Bottom Up（自下而上）拆解**比主流 Top Down（自上而下）对新手更友好——先看具体事实再归纳成议题，而非一上来就搭大框架；
- 议题树拆出的**小 Todo 可以直接执行**，不必等到整个树拆分完；
- 假说驱动（Hypo-Driven）在**熟悉**某件事时更顺，不要对陌生问题强行套用。【src=20231114_08】

### 7.4 整合前四单元：搭建你的个人成长飞轮（综合应用）

现在把前四个单元整合进四步法的闭环，就得到一个可循环的个人成长飞轮：

| 四步法阶段 | 调用前面哪一单元 | 行动 |
|---|---|---|
| **界定问题** | 第一单元（认知纠偏）| 弄清真正困扰你的问题，不被情绪/心理卡点带偏 |
| **拆解问题** | 第五单元议题树 + 第三单元（优势定位）| 从优势视角把大目标拆成可做的小事 |
| **执行解决** | 第二单元（时间管理）| 用日计划三步法与五星功夫安排并执行 |
| **总结复盘** | 第四单元（输出倒逼输入）| 用读书笔记六法/内容输出沉淀经验，被看见、可积累 |

【src=综合多素材，原创整合】

这就形成了一个真正的"飞轮"：**界定 → 拆解 → 执行 → 复盘 → 新的界定……** 每一圈都比上一圈转得更顺，因为经验在不断沉淀。
