# 第三单元 优势定位：找到你的独特杠杆

> 本单元回答一个根本问题——"我到底该在哪里发力"。核心素材：找准个人优势（20231107_66）、内容输出力（20231107_08）。

## 学习目标

## 第 5 章 赚钱=提供价值：先定位，再发力

### 5.1 一个被忽略的等式（定理）

很多人努力却赚不到钱，根源在于把"赚钱"理解为"从别人那里拿走钱"。但更本质的等式是：

> **赚钱 = 提供价值。** 你只能靠做擅长的事情去提供价值，你的优势决定了你在事业、社会、团队中的位置，位置进而决定你能赚多少钱——这就是"定位"。【src=20231107_66】

一句话概括这条传导链路：**优势 → 位置 → 价值 → 赚钱。**

### 5.2 发掘优势是你的责任（概念）

作者强调一个关键前提：**发掘自我优势，只能是你自己的责任，需要 100% 的自我负责。** 这是一条"英雄之路"，没有人能替代你去认识自己。【src=20231107_66】

### 5.3 定位是"试错"出来的，不是"找"出来的（认知）

很多人有一个执念：必须找到"正确的定位"再开始行动。结果是终生停留在"想"和"找"的阶段。

作者基于上千次一对一咨询的经验断言：**定位不是找到的，是实践（试错）出来的。** 先在不完美的情况下快速行动，在实践中迭代优化，才能逐步逼近那个真正适合你的生态位。【src=20231107_66】

> 生活类比：定位就像选择登山路线——你应根据自己的体能优势（耐力强还是善于攀岩）选择匹配的路线，而不是盲目去跟风挑战技术攀岩路线。合适的路线能让同样体力的你登得更高。

### 5.4 用盖洛普四分类认识自己的优势（方法）

要"找准优势"，先要有一个识别优势的框架。盖洛普将人的优势才干分为四大类：

| 类别 | 特点 | 典型角色/场景 |
|---|---|---|
| **战略思维** | 善于分析、统筹、学习内化、本质洞察 | 产品设计、架构、导师/顾问 |
| **影响力** | 善于表达、感染、推动他人、一对多 | 演讲、直播、社群运营、销售 |
| **关系建立** | 细腻、善于信任维系、老客户转介绍 | 深度客户服务、朋友式成交 |
| **执行力** | 靠谱、使命必达、步骤详细 | 交付、推进、落地 |

作者特别提醒：**没有哪一类更好，只有是否适合。** 绝大多数人是多个类别的组合。【src=20231107_66，概念提炼】

关键洞察是：不同类型的人，达成"销售成交"的方式完全不同——
- **战略思维**靠出卖认知与洞察（如专业解决方案）打动客户；
- **影响力**适合一对多的价值中心、流量分发；
- **关系建立**适合润物细无声地提供情绪价值，老客户复购转介绍无往不利；
- **执行力**靠"事事有响应、件件有着落"赢得信任。【src=20231107_66，方法提炼】

### 5.5 普通技能外包，核心技能自掌握（方法）

定位清晰之后，作者给出一条非常实用的资源配置原则：

- **普通技能**（如社群运营、海报制作、视频剪辑）——如果自己不擅长，就**外包**；实在没钱外包也自己做，等有钱再外包。
- **核心稀缺技能**（如咨询、流量、成交、内容）——必须**自己掌握**，哪怕不喜欢不擅长，至少也要能做。

因为核心技能是放在哪里都值钱的"硬通货"。【src=20231107_66】

### 5.6 市场上"缺卖者不缺产品"（定理）

一个反直觉但很重要的判断：**市场上不缺好产品，缺的是能把产品卖好的人。** 因此，有一项能力是每个想赚钱的人都必备的——**销售成交能力**。

无论你写文案、拍视频、做咨询还是做社群，如果这些动作无法导向成交，你的优势就无法与变现结果挂钩。对很多有"自己做好产品"执念的创作者来说，认清"卖东西"本身就是核心竞争力，是普通人逆袭的正确打开方式。【src=20231107_66】

> 一句话收束：清晰带来成功。认清自己是谁，是"生财"的第一步，之后才是谈赚钱的技能。【src=20231107_66】

## 练习题

1. **用四分类评估你的优势组合**：凭直觉给四类才干打分（0-10），为得分最高的两类各写 2 个真实成功事例，再判断你当前的角色是否发挥了最强才干。
2. **完成价值对接**：你的优势能为他人的什么问题提供价值？这如何对应"赚钱=提供价值"？
3. **盘一份外包清单**：列出你目前做着自己不擅长、又可以被外包或强化的"普通技能"事项，以及你绝不能失去的 3 项"核心技能"。
