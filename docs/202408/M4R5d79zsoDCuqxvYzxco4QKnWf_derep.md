# ('拆解小红书AI英语短文赛道，高单价19.9-39.9变现，实操玩法一条龙分享给你', (2, 42))

我是黄岛主，今天不聊虚的，直接拆一个我们正在跑的小红书AI项目——“每日英文短文”。

这个赛道主打的是用AI批量产出英文小故事，再配上AI插画和配音，做成笔记发到小红书上。内容几乎是全自动生成，单价却不低，卖19.9到39.9都很正常。关键是现在做的人极少，除了北京有一个团队在跑，剩下的基本就是我们了。可以说，这是一个含金量很高的蓝海方向。

![](img/2d91cb3f64625954b248ea4298653f16.png)
先看一个具体案例：一条视频围绕milk、white、clouds、morning、calcium、teeth、bones、honey这些单词展开，每个单词都揉进了句子里。家长买回去给孩子每天跟读十分钟，一个月下来词汇量自然就上去了，还能顺便打造外语环境。听起来有点夸张，但实际效果并不虚。之前生财里有圈友发过风向标，对标的同行卖电子书和音频，销量都很猛，我们自己也承认还没人家做得好。

![](img/c3716fd75b4b02379a5b969bda00c429.png)
这个项目的人群画像很清晰——懂英语的宝妈、老师群体。小红书上这类用户非常多，需求也大，虚拟产品几乎没有成本，天然适合小红书变现。

下面上干货，一步步讲清楚。

一、注册账号

小红书注册很简单：下载APP、手机号登录、获取验证码、点登录就完了。但几个细节要注意：
- 一机一号一IP，用流量注册，保证新号。
- 生日选在最近一个月内，因为生日当天平台会送一张半个月有效的流量券，发笔记时能派上用场。
- 年龄填30出头，性别选女，爱好随便选。
- 名字和简介先别动，等发了3篇笔记之后再改。
- 强烈建议开新号，或者把老号注销重新注册。老号标签已经定死，换赛道很难起来；长期不发的号权重也流失严重，发出去没量。新号从0到1反而更顺。

二、养号

养号期间什么作品都别发，就老老实实把自己当普通用户去刷。第1天刷2小时，多点赞、多收藏，但不评论。手动搜“每日英语短文”“每日英语短文听读”等关键词：

![](img/141aef9876f94fc6c8c6c66fd1a15292.png)
看到相关内容后，正常点赞、收藏、关注、评论，模拟真人操作。这是我们做参考的对标账号：

![](img/7b0e23116a419ef546513704f65ec56e.png)
第2天继续，刷2小时，分不同时段，正常点赞收藏关注，同时开始适当评论。评论比例控制在5个点赞里评论1个就行，不知道怎么评就直接复制别人评论。第3天照旧。第4天看首页，如果推荐的已经基本都是同行内容，说明号养得差不多了。之后改资料、发作品，每天发3-4条，分时段发：早7点、午11点、下午4点、晚8点。之后每天花30-60分钟继续养号，别断。新号浏览量200左右很正常，养7-15天会慢慢起来。

1. AI短文生成

先确定主题，比如季节、节日、动物、食物、活动等，目录完整版在这：

AI指令模板也给你整理好了。核心逻辑是：让AI写一篇8-10句的连贯英文小短文，要有标题，翻译也要；再提取10个关键词，按“单词+音标+词性+中文”的顺序输出，关键词开头不要带数字；最后再给两个提问和对应中文。针对不同人群，把人群描述替换成“英语零基础小学生”“少儿启蒙”或“零基础成年人”就行。

实操演示：打开讯飞星火，找到写作助手，把指令粘贴进去，主题写“端午节”或“春游”，点击发送，标题、正文、关键词、问题一下就全出来了。然后把内容复制到语雀或飞书存档。再输入“请生成这篇短文的主题图片详细描述词，汉语”：

整套玩法跑下来，核心就是轻资产、高客单、蓝海内容。先用免费工具把流程跑通，养好号、持续发，等账号权重上来，引流私域、开店、千粉卖号，变现的路自然就有了。想上车的朋友，按这个步骤一步步做就行。

今天分享一个我自己跑通过的项目全流程：少儿英语短视频怎么做，以及后续怎么变现。从AI生图、修图排版、剪映剪辑，到发布运营和三种变现路径，我会一步步拆明白。

先看第一步，AI生成主角图。你可以用这样一段提示词：公园里有个超萌的小女孩，扎着头发、戴着帽子，穿着粉色珍珠质感的连衣裙，大眼睛亮晶晶，五官很精致，正微笑着吃西瓜。背景干净漂亮，光线明亮，整体走迪士尼动画风，又带一点现代立体感，画质超清。图片生成后，鼠标右键保存到电脑就行。

![](img/b0e041c384a3093d82e07b9e99f5eb5b.png)

![](img/3977a89a44363e2976db3f77f2de9729.png)

拿到图片后，用美图秀秀打开，把尺寸改成16:9并导出。然后放进wink，点“画质修复”，选“超清”开始处理，画质会明显提升。

第三步做圆角图。打开在线工具 https://www.dute.org/image-round ，选择刚处理好的超清图片，圆角数值设置在20以内，导出圆角图片备用。

第四步，制作带文字的背景图。这里要用到搞定设计。点击“创建设计”，输入宽1080、高1440，也就是小红书竖版的3:4比例（其他平台尺寸可以参考下面这张图）。创建后把右侧不透明度拉到最低。

先把AI图片拖进画布，摆好位置，利用中间线对齐，可以放在最顶部。接着添加文字，主标题输入“spring outing”，调整大小、字体和颜色；再添加副标题“《春游记》”，选一个喜欢的特效样式。记住，所有元素都要沿着中间线才是居中。

然后加入正文区域，底部要留出空间给字幕。字体可以自由选择，我个人推荐“仓耳与墨W02”和“汇文明朝体”，字迹工整又好看。

接下来标记重点单词：选中单词，把文字颜色换成红色、黄色或绿色，再加粗突出。上面那张AI图只是用来定位的，现在可以删掉了。完成之后，点击右上角下载，命名为“春游第一张”，顺手保存模板，下次就能直接复用。

接着做第二张文字图：改掉文字内容，把文本移到左侧，设置左对齐，根据字数多少调整大小，做好后导出为“春游2”。再做第三张，加入问题和译文。先复制一层文本，放到下面，英文位置写上“translation”；再复制一层，把中文翻译放上去，确保上下对齐。导出为“春游3”。

![](img/3e145520b9419492a3700378b21b5811.png)

![](img/3fe9a3d432660b1156cf8c426c4f5aef.png)

第五步进入剪映剪辑。先把配音放进去，再把三张文字图片和圆角图拖到主轨道，视频比例设为3:4。选中配音，把语音分离出来。

![](img/a178da5e2515fde74459880b0be25e73.png)

![](img/92e5a776c15563bda19769ad290d0dcd.png)

打开背景填充，选择模糊效果，第二个或第三个都可以，看个人喜好。把主轨道图片长度拉到与语音对齐，然后缩小并移到合适位置。

![](img/dad9f0e18883bac7962827702faef692.png)

接着打字幕：点击文本，新建项目，把中文翻译逐条添加进去，字体样式随意选。后面的英文单词部分不需要再配字幕。

![](img/3f15d5b3740fbfe69796c1e490b575c8.png)

接下来做光标跟随字幕移动的效果。先准备一张纯色背景图，比如黄色，导入剪映后，把颜色图层放在文字图层下方、主题图片上方。

![](img/ed6ca39bbbb1dc659367030bc6034607.png)

选中文字，从第一句开始，根据音频进行分割，然后点击右侧蒙版，选择矩形蒙版，调整大小盖住需要的文字。

![](img/48ab342027cd03a1db5228ae23165ce2.png)

如果一屏有两行文字，就要做两排光标，同样对齐音频，重复矩形蒙版的调整步骤。重点单词也要单独调。这一步最花时间，全部调好后视频就基本成型了。

![](img/28ac2d1a3b3a8d6b6d49cc116c8645d4.png)

最后把图片和音频对齐。第三张图片上的翻译和问题不需要朗读，所以在视频结尾空出5秒左右。全部对齐后导出，就可以发布了。

![](img/84c474d81bc95e8eb2cb070e5b1d80fa.png)

到这里，一条完整的视频已经做好。下面是发布运营。

发布数量上，每天发3-4个作品，建议分时段：早上7点、中午11点、下午4点、晚上8点各发一个。时间充裕就多发，实在没时间也要保证2-3个。

标题可以直接参考同行的格式，基本都是统一的。比如“少儿小学英语，每日短文听读|我的身体”“每日少儿英语短文听读|我的身体”“Day6每日英语听读，坚持打卡100天｜冰激凌”（Day后的数字可以换成1-7）。主要就是换短文名字，也可以自己想类似的格式。

封面务必用自己视频里的画面截图，不要搬运，一旦违规账号可能就废了。店铺笔记图片一定要原创。
