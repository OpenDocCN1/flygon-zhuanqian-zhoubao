# 创始人 CEO 怎么写一份硬邦邦的商业计划书？

很多创始人觉得，把商业计划书写出来，是为了“展示”自己已经想得很明白。但真相可能恰恰相反——不是因为你脑子里有清晰答案，才动笔顺利；而是当你真正去写的时候，那些隐藏在“模糊的自信”背后的空白，才会被逐一曝光。

“以为想清楚”和“真的想清楚”之间，隔着一份写出来的商业计划书。别急着说服自己“我已经想好了”，坐下来，一字一句拆解你的商业模式，把所有假设都落在纸面上。你会发现，落笔的过程本身，就是一次最硬核的思考训练。那些写不出来的地方，不是文笔问题，而是思考漏洞。

请记住：不是想明白才能写明白，而是写明白了，才算真正想明白。商业计划书不是写给投资人的情书，它是创始人 CEO 逼着自己面对现实的一面镜子。

所以，如果你还没开始动笔，别想太多，先写出来再说。灵感是改出来的，战略也是。
