# 企业家真正的分水岭，在于能否兼顾利润与创造

生意人看的是账本，创作者盯的是灵感。

一个人如果只把目光死死钉在收益上，算尽成本、追逐回报，那他本质上就是一个精明的生意人；另一个人如果只沉浸在自己的表达里，追求纯粹、拒绝妥协，那他更像是一个执着的创作者。

这两者并没有谁高谁低，但放在企业经营的语境下，极端化都走不远。

完全放任市场逻辑的逐利，会让品牌失去温度和长远生命力；完全任由个人审美的创造，会让好点子变成无法落地的消耗品。

优秀的企业家，懂得在冰冷的算计与热烈的创造之间来回游走。既能用商业的理性守住边界，也能用创造的激情打开可能，于取舍之间，找到可持续的平衡点。

这才是生意做得长久、作品也活得精彩的关键。
