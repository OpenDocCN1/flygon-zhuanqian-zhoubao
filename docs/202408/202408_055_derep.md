# 40 岁以下的人，很难真正实践稳健的长期投资

听过一句话，扎心却有道理：四十岁之前，很难真正静下心做稳健的长期投资。

不是智商不够，也不是不懂方法，而是经历还没把人磨到那个份上。

大多数人的路径其实很像：把所有能走捷径的赚钱办法都试上几遍，被一次次亏损撞得鼻青脸肿，直到输得心服口服，才肯老老实实回到那条“看起来慢、其实并不慢”的路上。

这段修行，起码要十五年甚至二十年。在那之前，心里总有个声音在说：万一我可以更快一点呢？

所以，四十岁以下的人，即使道理全都明白，实际操作时仍会被短线交易那种“立刻有反馈”的刺激牵着走。嘴上认同长期主义，手上却按捺不住频繁操作。

这话出自硅谷王川，真的值得细品。
