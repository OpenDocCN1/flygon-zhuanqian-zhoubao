# 怎样从网红晋级到真正的 IP？
作者：龙哥

真正的IP，都是熬出来的

总有人问我：怎么才能快速做出一个IP？说实话，这条路并没有捷径。那些看似一夜爆红的人，背后往往藏着无数个无人问津的日夜。被流量裹挟、被舆论拷打、被现实反复摩擦……不经历这一遭，很难沉淀出真正的分量。

IP的底色是什么？是你的内容经得起时间的审视，是你的名声在风浪中没有坍塌。只有这些扎扎实实地立住了，你所谓的“基本盘”才算数。否则，再热闹的围观，也只是一时的烟花。
