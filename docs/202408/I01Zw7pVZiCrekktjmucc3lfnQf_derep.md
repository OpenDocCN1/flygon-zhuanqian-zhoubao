# 一些生活中很实用的ai工具

哈喽，我是小鹅，04年的大二在读生，平时主要研究AI写作。之前总有人来问我：“能不能整理一份AI工具清单啊？”我当时真觉得没啥可说的，不就是那几步操作嘛。后来才发现，好多朋友，尤其是不少老板，对AI工具的认知基本一片空白，明明有兴趣，却抽不出时间摸索。再不更新我就要大三了，既然被点名了，那就老实交作业吧。

![](img/567c32838192db18454787456c354c33.png)

### 一、快速“读完”一集播客

不知道有没有人和我一样，耳朵没耐心，但眼睛很老实：播客一听就犯困，换成文字却看得津津有味。想快速知道播客讲了啥？很简单。

第一步，把播客链接复制好。
![](img/ec698e3793d4fce6399cc6335e984c0d.png)

第二步，微信搜索“通义听悟”小程序，点“音视频链接”；
![](img/007a4bfbe3a964e9527fbab3fa459465.png)

第三步，把链接粘进去。不过要有心理准备：部分内容有版权限制，比如龙哥、小马宋那几期就转不了，换一集能转的就行。
![](img/2b326af4020d479d04d74be9ca9cfffa.png)

第四步，开始解析后，就等它干活吧。
![](img/7b38df5ae06e8624e058bc42c5fb8490.png)

你可以选“区分发言人”，有1人、2人、多人选项，它还能自动把不同声音拆开，标成发言人1、2、3，顺手生成智能摘要和章节脉络。
![](img/d138eef26a39fe5ffaa8e84011a2f5eb.png)

第五步，导出文件。如果想再清洗、提炼，直接把文件丢给Kimi，让它帮你做总结和整理。
![](img/3f2829f2cfd536ccc6400d97a74b15f6.png)

### 二、遇到陌生话题？用这招快速补课

聚会时大家聊一个词，你完全插不上话？约会时对方聊电影聊书，你心里一片空白？掏出“秘塔AI搜索”小程序，把话题输进去，基本答案马上就有。
![](img/f16a0913ce2f10ef219bc5a38335afb3.png)

不过这里有个AI通病：容易产生幻觉，把相近概念混在一起。比如你搜“铭文”，它可能给你讲青铜器铭文；如果你加上“web3中的铭文是什么意思”，它才会去搜细分领域的内容。
![](img/5e01e1a8f78fc672464d453c4d46a04b.png)

觉得答案太简单、信息量不够？先登录，选“研究模式”。
![](img/50e24c85356dfd2ebe32bc2cfbe7d095.png)

耐心等一会儿，它给你输出一篇万字长文。
![](img/9ec67897fe15513b6f87bc4bae0025ff.png)

还能一键生成脑图。
![](img/ff3056d141d55bec99faa2c50aa8f2c6.png)

文字能导出成Word或PDF。
![](img/21d2828803219b06fa5fa07a83d5965c.png)

再体验一下瞬间变出PPT的快乐吧。
![](img/a59496ecc70489e48ade94dbc0563d5b.png)

### 三、打造一个专属“书搭子”

我个人很爱用智谱清言，目前国产AI里它的数据质量算是第一梯队。先拿官方示范智能体“互联网黑话P9专家”玩了一下。
![](img/da3c25c51b88b506005290275532f208.png)

发现AI只要聊到关键内容，你直接圈住它的话，就能点“引用”。
![](img/cc9602e8c77c40eb5be70246c1a77525.png)

点一下，让它继续解释这句话。
![](img/ea4caee095fe24734aa04f74f2426c2e.png)

那怎么建自己的书搭子呢？点“生成智能体”，简单描述一句，它会自动生成完整设定；再把书的内容文件传进“知识库”。设置项其实不少，但大致是这几块：

1. 配置信息：描述角色能力，比如“你是一个xxx助手，你的角色是帮助用户处理xxx，能力有1、2、3……”。
![](img/9579fada52a899a150076e0184820565.png)

2. 对话配置：设定交互流程。比如用户先输入“开始”，agent回问一个问题，用户作答，agent再修正整理。开场白、预置问题、下一步问题都可以设好，AI会按你的节奏走。
![](img/ee4ec1ed7e005c79cc8e6533890311fa.png)

3. 能力配置：自建插件算高阶玩法，普通玩家直接从插件市场拿现成的就行。
![](img/68a0b6e876c5ad34feff5beb9cd7ad62.png)

像流程图助手、思维导图助手、动图生成助手、快递网点查询助手……多安几个，你的智能体战斗力直线上升。
![](img/2bbc36f7a552f8cdea6d382c3974dd1d.png)

4. 知识库配置：可以传自己的资料，也能放网页地址，还能授权读取👸号文章和🧣，让它们成为智能体的“大脑”。
![](img/de94d9353893401102bc6a05a724ae96.png)

这一步很重要，因为AI原来只靠训练数据，实时信息或针对性内容完全不行，必须靠你上传资料“喂”给它。
![](img/2e22932594eecf27b142e35a61983868.png)

5. 生成多样性：AI也有性格，有的跳脱，有的严谨客观。你可以调“温度”，选稳定、中立或随机。
![](img/3b81fb642adeb20992198c7df81ebbf9.png)

设置完，点发布。
![](img/9363b0d06a728b04841ddbd64d2c10a8.png)

然后就能和书搭子聊天了。
![](img/9e8e541e434b684ba1de1d26e8cf9d43.png)

说真的，我一开始也不知道除了提问闲聊，还能怎么进一步消化一本书。脑子卡壳怎么办？直接问AI呗。
![](img/577dd1936c99c4444aa5a97014e3219d.png)
![](img/bdf32bcedc8683f39427e029da98f0f7.png)

顺便说个我很喜欢的概念——“数字资产”。比如龙哥的《龙哥益语》、涛哥的《平民创业手册》，他们把自己的思想沉淀成数字载体，在AI时代就能吃到复利。如果你积累够多，完全可以把所有写过的东西都喂给智能体，养一个“高仿自己”当智囊，遇到问题找它商量。是不是很酷？

### 四、救命的英语口语搭子

我这种文静又容易紧张的人，一遇到英语口语考试就头大。线下找外教？面对严肃的菲律宾老师，我连一半话都说不出来。以前我会写好稿子，用朗读工具机械念出来，又呆板又没对话感。后来用ChatGPT，也只是把写稿这步变顺了，交互还是很弱。

直到豆包出现，局面才真正改变。豆包是字节家的产品，最核心的玩法是：真的可以打电话，它会很有耐心地陪你练。
![](img/0aaf4e0297c6467f0ca61e9e0a266368.png)
![](img/6ca212f17ee2e59e1efec1455ea96103.png)

豆包也能自定义智能体，创建逻辑跟前文差不多。但它有个杀手锏——剪映里所有AI配音音色，都能在豆包里用，你可以为搭子选择最喜欢的声音。
![](img/8c025c0f148ef47a8064afe8334bb926.png)

聊着聊着，真会觉得屏幕背后有个小伙伴。
![](img/afefc580848d49f4cd48de34d4e9b932.png)

我期末复习基本全靠豆包陪我，效率很高，特别适合我。各位老板如果不用学英语，也可以造一个“创业搭子”，遇到低谷和负面反馈时，让它安慰你、陪你继续跑。具体可以看易仁永澄老师的《使用「赚钱鼓励师」，帮自己在赚钱的路上跑起来》：https://t.zsxq.com/Azgf7

### 五、直播两小时，切片全自动

前阵子我做了几场直播，每场差不多两小时。播完真的累瘫，睡醒完全想不起来说了什么。可这些内容都是好素材、好数字资产，互联网人哪能随便扔？

第一步，电脑端打开视频号，下载直播回放。这里有个巨重要的细节：直播结束后的数据页下方，有一个很小的选项，问你是否生成回放。
![](img/7faee1a01c21de24f8ac53a74113b0ee.png)

一定要选！一定要选！一定要选！不然以后想找都找不到。
![](img/a39bd6d341bb798caa046f8292b177e4.png)

第二步，打开老朋友“通义听悟”，上传视频，等它干活，老板们可以趁“AI员工”加班时摸摸鱼。
![](img/45d4e5783d87ae4bb3f6d79e0c654390.png)

它会自动生成区分发言人的文稿。第三步是整合处理：你的发言可以标记、打点、设置待办，还能分享给团队。
![](img/4862de812e9cf40ba6fa81dedd1c8c9b.png)

右边有笔记功能，可以对照着稿件记录每部分内容。
![](img/0e478f292208ea3a9c026456be3a172a.png)

之前我犯过傻，时间点全手动记；其实左边就有打时间点的功能，一键标记，以后能从笔记直接跳转。
![](img/a9cf6f7c788140631abdf3efed8cedda.png)

第四步，把链接发给团队小伙伴，确认他们能看到，然后在旁边批注哪部分交给谁剪。这效率，比让一个人从头到尾看两小时视频高太多了。
![](img/496637f523f70ffa7e277e453d84a8ca.png)

### 六、微信里的大文件，不用硬啃

群友发来一个又大又干的文件，你知道是好东西，就是没时间逐字看。把Kimi小程序设成浮窗。
![](img/7ee3bd31f947e80de0dee5a5473abb5a.png)

需要时左滑一下就进来，点右下角选择微信聊天记录，挑出那个文件。
![](img/324b8ada8b438c55a067017017730559.png)

然后就直接问。比如那份《私域风控自检手册》，那么长，我只想知道“怎么防封”，Kimi直接给出1、2、3、4、5、6条。
![](img/cb2faed66e36d4676dd28208660bda02.png)

光看完可不够，学以致用嘛。
![](img/0d18159badb69309ada4dbcc72ae9cf9.png)

我会让“K秘书”先梳理框架。
![](img/1d45b2b32e85661819d84ddbe0cd675a.png)

再帮我做个小课出来，这不就手到擒来了。
![](img/d171dad08fce34a5d96ec431e327ecf5.png)

### 七、会议结束，发言稿已经整理好

讲到这儿我已经有点口干舌燥了，但要是还没学够，那就把压箱底的办法拿出来。参加一个会，嘉宾刚从台上下来，我已经把ta的发言整理成完整稿件。怎么做到的？

硬件准备：电脑、电脑充电器和充电宝（以防万一）；手机全程不能碰，如果需要接电话或拍照，最好带一个备用机。

流程是这样的：手机屏幕常亮，把休眠时间调到最长。
![](img/e0831ec7d3d3f80f261b5552d25a6360.png)

打开微信，进入“文件传输助手”或小号对话框；用搜狗输入法（或任何带语音功能的输入法）开始录音。
![](img/f08b9a1ab2a93b441a1d20b7a56529ce.png)

每隔五分钟，你会得到一段没清洗的粗糙文案，先发给合作伙伴，手机继续录。
![](img/e9265f594174fe73a9e591566464dd76.png)

电脑上把这堆文字粘贴到Kimi（还是微信小程序搜“Kimi”），发给它这样一条指令：“下面是一段关于xx（主题）的文案，请进行清洗，使用第一人称进行输出。”
![](img/bc8610a782a70c791c1ccfb6018f5258.png)

拿到清洗后的口播稿，简单改改错字和名词（比如“赚钱”常被识别成“身材”）。
![](img/ab78b1077f4beb20a1201272913dee31.png)

把和AI交互的部分去掉，再复制到公用链接里的对应位置。
![](img/5241f5e0aca26f093bc53efd3545486c.png)

### 八、意犹未尽再说几个

还有很多我常用的东西：GPTS怎么玩、怎么让AI洗📕的文案、一键搬运TikTok视频（https://ssstik.io/en-1#google_vignette）、AI做Excel（app.formulabot.com）、输入TikTok链接自动生成商品视频（https://www.jogg.ai/?fpr=xm7e5）、AI生成证件照（https://pfpmaker.com/）。

那一刻的感受，就像原始人看到火车从面前轰隆隆开过。突然觉得，广阔天地，大有可为。AI一定会越来越落地，渗透进生活的方方面面，也带来大量新机会。也许不是每个人都能靠它赚到钱，但它或许能帮你从一堆琐碎重复的工作里抽出身来，多陪陪家人，看看大海。
