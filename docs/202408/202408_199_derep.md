# 1500单不是梦：TikTok 美区小店从0到1实战复盘
作者：龙哥

大家好，我是龙哥。

现在白天在深圳做 TikTok 运营的工作，私下还兼着健康管理这条副业。家乡在广西，2021年还没毕业就在琢磨副业的事，这几年一直闷头学别人怎么做。

去年鱼丸在群里让我聊聊 TikTok 的打法，今天终于把美区这块给我跑通了。三个月里店里累计出单破1500，也算是真正从零起步验证了一遍。

下面这篇是我对整个过程的复盘整理，把踩过的坑和能用的方法都摊开讲。如果你也在做 TikTok 美区小店，希望能给你一点参考。
