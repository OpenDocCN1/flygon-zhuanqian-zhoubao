# 大学毕业生如何实现百万存款？完整复盘 0-1 的财富进阶

刚毕业就攒下人生第一个100万，是种什么体验？今天想聊的这位00后，不是什么天才少年，就是个普通大学生。但他硬是靠着一路踩中风口、踏实做事，在毕业前完成了很多人工作十年都没达成的存款目标。

他的轨迹挺清晰：2020年，微信👸号还在红利期，他闷头扎进去，野蛮生长；2021年，又赶上头条号的风口，顺势捞了一波；到2022年，手里有了点余钱，开始静下来思考未来的方向；2023年AI浪潮涌来，他敏锐地嗅到机会，果断下场，还因此加入了各种知识星球社群，在赚钱里潜水刷帖、提升认知、找项目；到了2024年，大学毕业，他想的已经不是短期赚快钱，而是怎么长期主义地走下去。

他说自己一直觉得自己没什么可写的，直到在个人👸号随手发了篇关于毕业百万存款的文章，没想到很多人留言想看完整经历，这才动了复盘分享的念头。用他自己的话说，就是希望给那些同样有赚钱想法的00后一点灵感。

评论区里，大家对他的评价很一致：勤奋、踏实、靠谱。有人特别提到，当年好几波大面积封号的时候，很多后端都跑路了，唯独他把账号售后做得妥妥帖帖。一图胜千言，评论区直接刷屏“虫哥牛”。

从一个普通大学生，到百万存款，这条路没有太多玄学，无非是抓风口、肯钻研、做人做事靠得住。完整复盘他放在了飞书文档里，有兴趣的可以自己去看。
