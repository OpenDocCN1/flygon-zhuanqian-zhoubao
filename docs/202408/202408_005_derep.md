# 选对人，赢面放大十倍：我筛选项目合作伙伴的心法
作者：龙哥

你有没有想过，一个项目能不能成，在组队那一刻就决定了？钱少了可以融，方向偏了可以调，但人要是没选对，一切都白搭。反过来，一旦人选准了，后续的执行、推进、落地都会顺畅得多，成功的概率也能成倍往上走，说是十倍也不夸张。

我是龙哥，在知识付费和私域运营领域深耕了两年半，之前还有过12年带团队的经验。这些年我最深的一个体会就是：识人、选人，是比做任何事都重要的一环。所以我有个习惯——任何项目启动前，我都要先花大量时间筛选合作者。这件事不解决，我宁愿不动手。

有人可能会问，这么看重选人，效果怎么样？这两年多，我和明白老师、陈雪美女一起做俱乐部，会员净增长和复购率的数据都很稳定，这里面的关键，就是一开始就把合适的人选到了合适的位置上。

那具体怎么判断一个人靠不靠谱呢？我的答案很朴素：多观察、多沟通、多在具体事情上验证。别急着给结论，也别只看表面。这也是我自己一直在项目开始前反复做的事。

这篇文章，算是我把平时筛选合作伙伴的方法做了一次梳理，也融合了一些过往的经验和思考。如果你也正在为找不到靠谱的人发愁，希望它能给你一点帮助。欢迎看完后留言，我们一起聊聊识人这件事。
