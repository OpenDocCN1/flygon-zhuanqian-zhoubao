# 把副业做到超过主业收入，你必须得知道的 20 件事！
作者：龙哥

为什么有人能靠副业跑赢主业？根源说，答案可能不在能力，而在别的地方。

他做自由职业超过12年，又在知识付费和私域运营赛道深耕两年半，和明白老师、陈雪一起运营日新月异俱乐部，年利润稳定在七位数，会员净增长和复购数据也相当亮眼。一路走过来，他最大的感受是：副业能否做好，拼的往往不是专业能力，而是你做事的习惯、身上的特质，以及对副业这件事本身有没有想清楚。
