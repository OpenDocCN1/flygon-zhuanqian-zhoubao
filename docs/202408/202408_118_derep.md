# 剪映批量做分镜带货视频：如何用一条原片“裂变”出海量高原创度相似视频？

最近发现一个很省事的玩法：用剪映配合一款RPA辅助工具，就能让带货视频的生产效率大幅提升。简单来说，你只要有一条原始视频，剩下的分镜、变体、风格化处理，都可以交给自动化流程批量完成。
