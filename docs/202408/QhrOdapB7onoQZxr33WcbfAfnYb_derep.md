# 天翼云SK5的搭建SOP（保姆级）
作者：龙哥

别再花20-40元/月买了！天翼云四五折搭建SK5，保姆级SOP来了

大家好，我是龙哥，平时就爱折腾黑科技。SK5这名字，可能不少朋友听着陌生，用的人也不算多，毕竟它要靠一台服务器自己搭。之前赚钱有圈友分享过思路，网上相关教程也有，但能一步步截图讲清楚的很少。我这次亲自完整跑了一遍，把每个环节都记了下来，整理成一套照着做就行的SOP。

先说说SK5能拿来做什么：

- 给自媒体矩阵的每个账号配上独立IP，让账号之间不容易产生IP关联。
- 电脑能用，安卓手机也能用。
- 市面上卖SK5的人很少，基本也找不到地方买；一条SK5的行情价大概在每月20-40元。
- 👸号矩阵、抖音矩阵、📕矩阵这几个玩法，使用频率最高。

看到这里，你对SK5应该有个基本印象了。接下来聊重点：怎么用低成本把它搭出来？答案就是天翼云服务器。正常去天翼云官网注册，是拿不到折扣的；但通过代理商注册，折扣通常能压到0.45-0.55。需要代理商链接的话，可以找我。下面是完整SOP，照着一步步操作就行。

# 一、注册账号

注册没什么难度：用代理商链接填手机号注册，几秒搞定。注册完先做实名认证，再充值100元（随时可退）。这个钱不是白交，是因为账户余额低于100元没法下单买服务器。充值完成后联系代理商帮你调折扣，等折扣调好再继续下一步。

# 二、购买弹性IP

1. 先到顶部导航栏，点开【控制中心】。 ![](img/09d533b26a7569d0659cedaeb89e8021.png)
2. 从菜单里找到【弹性公网IP】，点进去。 ![](img/31cff5b76303be99c62594e7e0e8fbd6.png)
3. 选一个你需要的地区，每个地区最多购买10条IP。这里有个关键点：购买链接的URL里必须包含【console2】，否则后续没法搭SK5。确认链接没问题后，点【购买弹性IP】进入下单页。 ![](img/b656c05e38f09dcb5055748116e85f60.png)
4. 计费方式选【按需计费】，公网带宽选【按流量计费】，带宽大小填【300】，购买数量填10条。 ![](img/1841c12b51a5e960517fc520ae9fcd94.png)
5. 点【立即申请】，到确认页核对信息，没问题后点【提交】。 ![](img/40a0a224ed7f640f6fc012977c971be3.png)
6. 页面会自动跳回列表，等1分钟左右点【刷新】。 ![](img/d71dad3f83e12fcc10f0b004abe65a6e.png)
7. 刷新后能看到刚买的IP，说明购买成功。如果显示的IP不足10条，那就是当前地区IP库存不够，换个时间再买即可。 ![](img/86ec61f174d4e113593cd8748d011670.png)

# 三、购买弹性云主机

买云主机时，地区一定要和刚才的弹性IP保持一致。比如我买的是深圳IP，云主机就选深圳。同样要确认URL里包含【console2】，这点直接决定你能不能继续往下搭。

1. 顶部导航栏打开【控制中心】。 ![](img/097384d05df549155ab1d44f2218ea44.png)
![](img/f4fd3caf57dfc4ee80ac4ebc753dc1a7.png)
2. 进入后找到【弹性云主机】，点【创建弹性云主机】。 ![](img/575e212cf1fd1eb06bfefa6468687196.png)
3. 购买页面有两种计费模式可选；实例类型和镜像按界面红框提示选择，其他保持默认，然后点【下一步：配置网络】。 ![](img/f3f5f18e7595416230349b59aa4a2f58.png)

计费模式怎么选，给你一个参考：
- 包年/包月：准备长期用的话，选包月比按需更划算。但不建议直接按年，否则后面想换IP或退款时会比较麻烦。
- 按需计费：如果做的业务容易碰到封号，建议选这个，删机重开都很灵活。价格虽然比包月稍贵，但后期也可以随时转成包月，看你的实际需求。

4. 网络配置这页不用改动任何设置，直接点【下一步：高级配置】。 ![](img/83d22f8b9fe1bf3e52b1f57658d48523.png)
5. 高级配置里，把云主机名称改成你喜欢的名字；root密码一定要设成自己能记住的，后面登录服务器要用。其他不用动，点【下一步：确认配置】。 ![](img/d1a8ac4994e92a25ba2094767bb179ba.png)
6. 核对一下配置信息，自动续费可勾可不勾，然后点【立即购买】。 ![](img/e1c760d8cfc76fce822b8a0f304827ef.png)
7. 跳到支付界面后，还没实名的话先实名，然后点【立即支付】。 ![](img/7495f033df9935bdf1785829ad1b8482.png)
8. 支付完成，点【控制台】进入弹性云主机管理界面。 ![](img/676180889aa14048a98a04f1b99a2194.png)

# 四、配置云主机

1. 在控制台里点【云主机】，进入设置界面。 ![](img/43bba76b391cf928ccd157d55c3a0d79.png)
2. 切到【安全组】选项卡，点【配置规则】。 ![](img/8610682ae3bbf5388daf699464d257bd.png)
3. 再切到【入方向规则】，点【添加规则】。 ![](img/294cd30167f35d92b8bc0dff39bada19.png)
4. 按上图参数填写。这里有个小技巧：IP地址下拉菜单先随便选一项，再选回原来的，系统会自动填入0.0.0.0/0；当然也可以手动输入。填好后点【确认】完成添加。 ![](img/da14098b366cae6349abecc52d67c504.png)
5. 接下来配置弹性IP，先点【控制中心】返回。 ![](img/e02bf17e684e746757653f0edd6f3dc2.png)
6. 找到【弹性公网IP】点进去。 ![](img/4c0bf0864458665982f235dfa3123073.png)
7. 在【虚拟私有云】分类下，点【子网】。 ![](img/7936fe89c2b353b9c2ea13c5696c8d2b.png)
8. 点击对应的【子网ID】，进入子网详情。 ![](img/9e1384273d6e330912ddc0865dfef8a2.png)
9. 切到【IP地址管理】，点【申请虚拟IP地址】。 ![](img/cf979a38b7710aa4363c9a570cc51cba.png)
10. 创建方式选择【手动分配】，填入“11”，点【确认】。 ![](img/a818774b54c7acd5d6177287efcd5f8b.png)
11. 创建成功后列表会多出一条虚拟IP，继续重复申请，一直申请到“19”。 ![](img/f113ab52dd4afb991f99eaeafe36d04c.png)
12. 确保从11到19全部申请满。 ![](img/57157b033bacd3d4d466ff6520bb5e29.png)
13. 然后开始绑定：点【绑定弹性IP】，任选一条IP，点【确认】。 ![](img/2781fc837c6b3e08cef7d66d37b0dbb5.png)
14. 接着点【绑定主机】，选好对应的服务器，点【确认】。 ![](img/45fab6e6a883d9c60f5c1d4df77825a9.png)
15. 剩下的11-19虚拟IP，都按上面的方式，依次把弹性IP和主机绑定好。 ![](img/d660a1636f21d58bce1386230f3fdd99.png)
16. 绑定完成后还剩一条IP没绑，先回到【弹性IP】列表。 ![](img/20a3a480a0983ad73c7eb881aba819ad.png)
17. 找到那条未绑定的弹性IP，点【绑定】。 ![](img/2c9c0d9540012045d30a8fadba073ba9.png)
18. 选好主机后点【确认】，再把这条IP地址记录下来——它就是之后登录服务器用的IP。 ![](img/8a530892dd52bbd2a8bb15d711d202c6.png)

# 五、配置服务器环境

1. 连接服务器，我用的是Finalshell。 ![](img/d841edc8ceaabd6115423d8c434fbf24.png)
2. 打开后先点【文件夹】，再点【SSH连接】。 ![](img/3073708c96d811cefe877af0ee1d38ca.png)
3. 填写连接信息：IP填刚才记下来的那条未绑定IP，账号默认root，密码是买云主机时设置的root密码。 ![](img/6b8fe582a1748406f1d800386069cd6d.png)
4. 添加好后，双击该服务器就能连上。 ![](img/2f2f7ab05f07c4a2e8cd133c26ab4062.png)
5. 首次连接会弹提示，选择【接受并保存】。 ![](img/19d1abf1ce00aef98545a9f29fed1e51.png)
6. 接着把下面这段命令复制到命令窗口，右键粘贴执行，作用是给网卡配上11-19这些辅助IP：

ifconfig eth0:1 192.168.0.11 up
ifconfig eth0:2 192.168.0.12 up
ifconfig eth0:3 192.168.0.13 up
ifconfig eth0:4 192.168.0.14 up
ifconfig eth0:5 192.168.0.15 up
ifconfig eth0:6 192.168.0.16 up
ifconfig eth0:7 192.168.0.17 up
ifconfig eth0:8 192.168.0.18 up
ifconfig eth0:9 192.168.0.19 up

![](img/4b5bc2608cc9985e2b7a874df57309e0.png)
7. 接下来安装SK5脚本。安装文件是.sh格式，需要的朋友可以找我拿，赚钱的圈友直接免费。运行后看到安装成功界面就OK了。 ![](img/ec0557a015c3645fc636957db1815fb6.png)
8. 装好以后，建议顺手把默认密码改掉。改法很简单：双击打开serve.toml文件。 ![](img/125941f2587db622764df75afbbcf289.png)
9. 把里面的 pass = "123456" 批量替换成自己的新密码，然后点【文件】→【保存】，再关闭文件。 ![](img/c9531c4c74a9ae65c05196f46c8321be.png)
10. 回到命令行，执行 systemctl restart xray 重启服务，密码修改才算真正生效。 ![](img/d4edf2beaca962d92a2499f5e62b3ede.png)
11. 最后一步可选：检测一下SK5是否都能正常使用，一般情况都没问题。 ![](img/81570a79aee71ba272339c4392d6b3d7.png)

整个SK5搭建流程到这里就全部结束了。哪一步卡住了，欢迎到赚钱对应帖子里提问，我看到都会回复。
