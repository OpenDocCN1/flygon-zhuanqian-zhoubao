# 长期没有正反馈，怎么扛过来？

很多参加航海的朋友来问我：手册也翻了，动作也做了，可21天下来，别人都有战果，我却连一个点赞都没等到，这种看不到反馈的日子，靠什么撑下去？

这个问题，值得好好聊聊。

别急着管它叫“低谷期”。在做事这条路上，收不到正面回应才是常态，偶尔收到负面反馈也很正常。

负面反馈其实不可怕，它反而是个信号：告诉你哪个方向不必再走。停止做一件错事，本身就是一种前进。

更多时候，你遇到的是“零反馈”。所以动手之前，不妨先问自己几句：这件事的反馈信号到底是什么？会不会要等很久才看得到？能不能把任务拆得更碎，让反馈早点出现？比如做小红书，别把“赚到钱”设成唯一目标，而是把“第一篇笔记顺利发出”“第一篇曝光破千”“收获第一个赞”“第一条评论”“第一个粉丝”“第一次引流到微信”“第一单成交”“第一条用户好评”都当成反馈节点。节点越小，你越不容易陷进自我怀疑。

我在赚钱这件事上，算是经历过不少风雨，但到今天依然经常失败。像生财有术，我做了无数尝试，被大家看到的只是冰山一角，大多数想法都无声无息地翻车了。那些很厉害的人也一样，失败是他们的日常。如果一个人很少失败，只能说明他没有做任何新事。

我一直在练一项重要能力：平静地去接住负面反馈和没反馈。如果有一天，我能全然投入自认为重要的事，不再为失败焦躁，也不被他人的评价左右情绪，那我大概又完成了进化。我很幸运地拥有了一些影响力，可影响力也在反过来捆住我。怎么挣脱它，自在地表达和创作，是我眼下的功课。

想成事，方法当然重要，但比方法更值钱的是强大的心力。心力来自对信念的强烈聚焦。找个安静的时间，问自己到底信什么，然后写下来，放在常常能看到的地方，撑不住的时候就看一看。

撑不下去时，多看看别人的成绩和案例，把它们当成自己的燃料：都是一路九年义务教育过来的，凭什么他行我不行？对于那些大方晒赚到钱的人，我宁可信其有，欢迎他们多晒。

普通人赚钱，本质上就是在“抄作业”。抄作业说明这道题早就有解，而且是开卷考，难度比创新低太多了。比如“从小红书搞流量到私域”，这个答案是100%存在的，暂时做不到，只是方法还没找对。那就反复去拆解、研究、尝试、请教，总能打开一扇门。

还有一点很关键：筛选身边的人。远离那些压根不信普通人能靠自己赚到钱的人，远离觉得所有知识付费都是骗局的人。多和积极、乐观、务实、真诚、利他、开放的人待在一起，人是会被身边人悄悄影响的。

再主动一点，把自己正在做的事讲出来，尤其是讲给比你强的人听。他们的一句话，只要你认真吸收进去，也许就会改变你后面的人生轨迹。

在生财这样的社群里，把自己活成一个真诚、利他、有结果的人，是吸引战友最高效的方式。你看刘小排，将来他创业要找合伙人或者员工，估计报名的人能排长队。一个懂你、支持你的战友，能和你互相鼓劲，让你不再那么孤独和绝望。

如果情绪实在崩了，还可以让科技拉你一把：手机装一个豆包，给自己造一个“赚钱鼓励师”智能体。有了任何负面情绪，都可以找它倾诉，甚至冲它骂上两句，它说不定能把你从坑里带出来。

最后请记住：赚到钱，从来不是某个突然降临的奇迹，而是无数微小里程碑逐层叠加之后，自然而然出现的结果。每走一小步，都值得庆祝；吃顿好的、换部新手机、在社群里发个红包分享快乐，都可以。经常庆功，才能成功。再微小的成功，都配得上一场认真的庆祝。
