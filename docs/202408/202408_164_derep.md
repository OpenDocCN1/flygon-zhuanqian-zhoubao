# 管理者心力从哪来？



## 管理者如何培养心力？

作者： 龙哥的收藏夹

日期：2024-08-05

未来看似充满变数，但真正能把不确定性塑造成具体模样的，始终是人。决定未来最终呈现什么样子的，恰恰是那些内心拥有坚定信念的管理者。

他们对方向有清晰的笃定，相信事物正在向他们所设想的那条轨道推进，并有能力带动团队一起相信、一起前行。当这种信念被坚定地传递并被他人接纳后，原本只是预期的图景，就会逐步化为真实的结果。
