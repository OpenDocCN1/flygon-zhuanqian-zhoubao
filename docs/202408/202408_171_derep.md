# 从一家生意兴隆的采耳店，谈一谈企业的经营和战略定位问题

我常去的那家采耳店，这几年一直预约不上。直到放开后，线下生意普遍清淡，才终于有机会常去。观察下来，它的红火不是没道理。

先说常见采耳店怎么经营。任何产品或服务，都有三种价值：实用价值、体验价值和象征价值。对采耳而言，实用价值是治耳病、处理耳部问题；体验价值来自采耳时的感受和店面环境；象征价值几乎为零，没人会因为“我在某品牌采耳”而觉得有面子。

于是市面上的采耳店，大多在实用和体验上做文章。为了多赚钱，惯用招数无非这么几类：死磕充值办卡；或者“宰客”，比如夸大耳病、推荐高价洗耳，其实只是抹点药膏；再不就是增加项目，头疗、SPA、拔罐、艾灸全都上。这些做法大家都会，最后就变成行业标配，毫无差异。还有些打擦边球的，正经商家碰都别碰。

当大家做的事一样，就只能在同一个维度拼命比谁做得更好、成本更低、效率更高。就像草原上的羚羊，最大的威胁不是狮子，而是其他羚羊——大家抢同样的水和草，你只要比同类跑得快就行。这就是极度内卷。

波特在《战略是什么》里指出，摆脱内卷要靠战略定位，用一组独特的经营活动建立壁垒。也就是毛主席说的：“你打你的，我打我的。”国民党想拼装备，我们就跟他打游击，用灵活和运动战取胜。南城香是个好例子：它的战略定位是“北京城区的全时段社区餐饮店”。它从不对顾客说这句话，但所有动作都围绕它展开：只进社区不进商场，只在北京城区（最近才去上海），为了拿到好铺给中介双倍佣金，因为一日四餐要求员工多技能，所以用计件工资。这一套独特打法，别人想抄都抄不来，因为历史包袱太重。

那家采耳店，并不一定懂这些理论，但我给它总结了一个定位：“追求极致采耳体验的门店”。它从不做功能性服务，不治耳病，甚至不把耳屎掏干净，只让你舒服。它不赚治病的钱，也不赚充值后不来的钱，赚的是你反复光顾的钱。别的采耳店，哪怕嘴上说追求体验，实际行动也做不到。

它的一组独特经营活动是这样的：

第一，只做采耳，不做按摩。按摩手劲重，再去做采耳，手感容易飘，客人体验就不好。这里只练一样，手感稳定，也容易标准化。

第二，禁止技师推销充值。采耳时客人常常想睡一觉，推销纯属打扰。但这家店会员反而不少，因为会员有专属采耳工具和折扣，海报上写着，没人来烦你。

第三，采耳时间最短50分钟，正常60分钟。而市面上大多20到30分钟，很多连40分钟都不到。

第四，不装豪华门面，只图干净整洁。它开在商住楼里，不做底商，租金和装修都省了，全靠口碑和复购，而不是靠门脸招客。

第五，排班玩法独特。如果客人单点某位技师，这个技师要抵消一次正常的排班轮次，并不能因被单点而多赚机会。这样避免技师为了被选而跟客人套近乎，忽略服务本身。

第六，成本压到极低。门店只有一个前台，还要兼顾🛰️私域；但私域从不做推销，只做预约。几年下来前台没换过，技师离职率也低，服务标准自然稳。

细节也用心：店里只提供两种小食，但都是知名品牌；卫生间备了头绳、吹风机、香氛；技师服装素雅，口罩从不摘。很多店看似项目丰富，实则四处粗糙。而这里，舒服、干净、克制，形成了一套经营闭环。

这家店在北京东直门银座，叫“享耳空间”。生意好到约不上，我也不是给它打广告，老板我也不认识。

说到底，做一家店也好，做一千家连锁也罢，都要回答两个问题：这么多店，客户凭什么选我？和同行比，我的核心竞争力到底是什么？以前有时代红利，不会游泳也能随大流漂一阵。红利一退，拼的就是真功夫。没有让顾客非来不可的理由，没有同行学不来的优势，那只能问自己一句：凭什么是我？
