# 从超休闲转型混变，年营收突破 6 亿美元！Voodoo 副总畅谈游戏公司经营心得

在手游圈，有一家公司最近的操作让不少人直呼“壕气冲天”——直接买下了一个月活超过4000万的社交平台。而这家公司，正是当年靠超休闲小游戏起家的Voodoo。

你可能好奇，一家做轻量级小游戏的公司，怎么突然就变得这么“不差钱”了？答案就藏在它的转型路径里：从超休闲游戏大胆转向混合变现模式，结果年营收直接冲破了6亿美元大关。

最近，Voodoo的副总裁在接受访谈时，分享了不少关于游戏公司经营的实战心得。这些经验不是空谈，而是他们真金白银趟出来的路。比如，如何把握转型时机，如何让产品在保持轻量特色的同时实现更健康的商业回报，又如何在收购和扩张中保持自身优势。

从默默无闻的小游戏厂商，到能够大手笔收购社交平台的行业巨头，Voodoo的这波操作，确实给整个游戏行业上了一课。
