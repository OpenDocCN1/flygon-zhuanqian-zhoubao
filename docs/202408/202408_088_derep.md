# 从留学行业转身，2个月卖掉近1个亿的“蓝海产品”（第一集）

2024年，很多行业已经在肉眼可见地降温，还有一些正站在降温的起点上。

留学、金融、法律、语言培训、健身、宠物（尤其是猫）、设计、奢侈品、传媒、音乐、艺术、戏剧、咖啡、主打烫染造型的美发店（护发和白转黑除外）、需要动刀的手术类医美（轻医美除外）、酒吧、KTV、电影院、高尔夫、轻食、以及标价高得吓人的面包店……

这些方向，未来十年大概率还会继续往下走。

如果你刚好身处其中，请认真读完这句话：趁早转行，别和趋势对着干。

这篇文章会跟你聊清楚两件事：
一、这些赛道为什么会下滑？
二、我们该往哪个新赛道走？

先介绍一下我自己：我是龙哥，2022-2023年，我和合伙人Ivy（陈铭）在📕上做留学赛道，做到过2700万营收。察觉到风向不对后，我们并没有死守，而是果断切进了一个超高客单价的新赛道。

转行后，只用了2个月，公司就签下11套房产，其中7套已经成交，总金额接近1个亿：

- 一套2000多万；
- 一套800多万；
- 一套700多万；
- 一套4000多万；
- 一套200多万；
- 一套1400多万；
- 一套400多万。

还有4套，正在帮房东寻找精准买家。

在转型之前，我写过《老板避雷手册》和《📕留学赛道趋势分析》，都意外爆了。爆文之后，很多留学同行找到我，说自己的业绩正在下滑，公司越来越难做。

他们问我：怎么救？要不要继续跟流量成本硬拼？

我的回答是：我们已经转行了。留学业务，现在只是保底。
