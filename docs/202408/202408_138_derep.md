# 从验证到放大：闲鱼旧书新手的月销8万复盘
作者：龙哥

分享人去年9月加入一个商业类社群，11月确定把闲鱼上的旧书交易当作主攻方向，此后几乎所有精力都放在这条线上。项目从零到一跑通，只花了一周左右；但从一到十的放量，却让他前后折腾了整整半年。最近他总算空出时间，把这段经历写下来，说是整理思路，其实也适合处于相同阶段的同行借鉴。

先看7月的结果：他名下共有3个商家管理账户，活跃的闲鱼店铺有15个，当月总成交额约8万元，毛利率约26%；把人力成本和售后赔付都扣除后，净利率约19%。当前团队共5人，除了他之外，有一名负责日常协调的全职伙伴、两名打包发货人员、一名运营人员。盘子还在继续做大，按他的估算，等新学年开学，销量还会有明显上涨。

放大过程中，他感慨最深的一点在心态层面，而不是操作本身。最初他以为，单个店铺的模式验证成功后，就等于有了一套可以无限复制的模板；真正上手才发现，单人模式和小组模式完全是两回事。选什么品、备多少货、怎么发货、售后怎么处理，每一项都需要重新建立规则。半年里他没少遇到问题，但正是这些难题，逼着他把基础动作一点点磨到合格。

他在文章里感谢了社群团队在项目筛选与资料整理上的支持，也感谢了一位前辈在业务细节上的指点。完整的放量过程被他汇总到一份飞书文档中，按阶段写清了各个难点和应对方式，有需要的人可以从原帖看到入口。

留言里的观点同样耐人寻味。有人说读完后最大的收获在心态层面，提醒自己不要浮躁，把眼前的事做扎实。也有人觉得，这种项目卡住的通常不是手艺，而是认知中的“道”；把这个想清楚了，换方向也只是换了一种术。还有一位前辈总结，外界总爱晒那种短时间赚到十万的战报，但真实的成长节奏是先跑通个人链路，再带几个人放大，等这一整套流程走完，后面再做其他方向会省力得多。
