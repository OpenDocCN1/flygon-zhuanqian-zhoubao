# 100万的引流底座，其实就是这5个习惯
作者：龙哥



说到底，流量哪有什么黑科技。

把东西讲透了，所谓的秘密也就拆穿了。你看有些人绞尽脑汁研究半天，效果还不如别人随手发一条。别把自己耗空了，想玩就敞开了玩。

但先问自己一句，你的目标用户是谁？你到底要服务哪群人？没有这条主线，前面全是空谈。

做分享不是为了自我感动，也不是为了自嗨。你要想清，来看你的人能带走什么。是情绪价值，是干货方法是认知升级，是共鸣是启发，甚至是一次小小的顿悟。先想清楚你能给什么，再决定怎么说。

跟观众比，用心多那么一点点就够了；跟普通人比，强那么一点点就行了。这点差距，足以让你脱颖而出。这件事得自己琢磨透，連自己都搞不清的人，很难走得远。

信息时代，谁分享都有目的。泛滥的内容里，看到即是价值，你感兴趣自然会留下。你什么都看却什么都不在意，就是浪费时间；真正的人，会琢磨、会反思、会问自己能不能做到像他一样。

你的手有点懒吧？多点一次搜索会死吗？一搜下去，可能只是好奇心，结果却越挖越深。信息差就是这样被拉平的。检索不足、总结不会，你就只能当观众。

讲到抗压能力，很多人是典型的想得到就要马上得到。现实是，没人有义务白给你东西。买来的东西都有它的价值，只是你分辨不清。

信息从来不属于谁，他能说的你也能说，你能说的他也能说。关键是谁说得更像自己的话。粉丝的注意力有限，复刻不是贬义，多做就是内化。

要面子有什么用？觉得钱难赚屎难吃，是穷人思维。盯着钱去追钱，反而越难赚。真正有格局的人，眼里全是机会，因为他们在做布道。

布道是什么？就是锁定一类人群，先把这条路上的“道”吃透，再把钱赚到。想从别人口袋拿钱，先让别人信你。信任有了，转化自然发生。所以你要持续输出同一类人群需要的东西。

**赚到100万的执行底座，五件事必须做起来**

**1. 先占领5个流量入口**
抖音、视频号、快手、📕、🧣，全上。哪个平台先爆你也不知道，哪个给你面子你就好好伺候哪个。

**2. 单平台一次性开5个号**
测试就别抠抠搜搜。1个号玩到怀疑人生，不如5个号一起跑数据。号太少拖垮的是你的耐心。

**3. 单号每天稳定发5条**
先把输出能力养起来。数据好坏先放一边，量起来了手感才对。多发到后面，你才不会为没内容发而发愁。

**4. 坚持做5个星期**
1个号发5条，5个号就是25条。复制到5个平台，每天就是125条。5周下来，你累计产出4375条内容。流量规律在这量级下，自然就看明白了。

100万说白了不就是流量问题吗，有那么难吗？先把这套打法跑通，不管项目好坏，你都得先跑一遍。哪怕是一个破洞的丝袜，也能找到买家。

学习是学不会赚钱的，只有上手做一遍会了。所有高手在成名前，都分不清什么是对的，他们靠垃圾项目练手，练成了能力。真正的核心是引流和成交能力，项目只是载体，什么都能卖才叫本事。

做到没有？做不到就别多想，闭嘴开干。你只看到我现在分享的光鲜，没看到我之前闷头猛干的模样。这篇文章我也花了一个小时写成，半小时拆解同行，才有了灵感。
