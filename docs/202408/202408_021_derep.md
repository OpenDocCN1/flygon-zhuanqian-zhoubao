# 一天 50 条口播伪原创：AI Agent 流水线实操拆解



## 用 AI+Agent 搞定 50 条口播视频的日产出

作者：张一凡
發布：2024-08-21

先说清楚：我只是对 Agent 工作流感兴趣，临时灵感突发就把这套流程跑通了，目前没有实际搬到自媒体平台去实测，仅供大家作为思路参考。

这套生产线的核心逻辑，就是把别人的爆款拆解、换皮、复刻成自己的版本，整条链路基本可以全自动跑：

1. 用插件把目标抖音号的视频全量抓取下来
2. 筛选出点赞量靠前的爆款，用 Coze 把视频文案抠出来
3. 把自己的素材库或风格文档喂给模型，让 AI 模仿你的说话风格重写爆款文案，风格也可以换成别的头部主播或名人，比如雷军式表达
4. 调用自己的数字人分身，把改写好的文案导入生成口播视频
5. 最后做一轮二次剪辑，加上字幕和画面素材即可发布
