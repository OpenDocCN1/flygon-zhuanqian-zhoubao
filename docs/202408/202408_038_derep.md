# 乙方生存实录：那些让我哭笑不得的客户

2003年，我一只脚踏进广告圈，这行一待就是七八年。江湖上关于乙方的段子我听过不少，但亲身经历过的才叫“魔幻现实”。今天挑几个讲给你听。

第一个故事，发生在服务一个传统老板的时候。这位老板做事很稳，没什么怪癖，唯独对字体格外执着——喜欢隶书。我们设计组为了过稿，把各种字体试了个遍，全被退了。最后灰溜溜地换上隶书，竟然直接通过。从此，我们像是摸到了老板的密码，对外物料、海报、广告牌，全都清一色隶书。乍一看挺憋屈，可时间久了，这套字体反倒成了他品牌里肉眼可辨的识别符号。

第二个故事，是我在一家本土广告公司时的事。我们服务一个韩国电器品牌，他们中国的广告部长是位韩国欧巴。我为新品写了几条广告语，拿去提案，他看完皱起眉头，抛出一句让我记到现在的话：“这些文案，我一个韩国人都看不懂，中国人能看懂？”这句话的逻辑，我到现在也没捋顺。

第三个故事，来自一个前同事。他在服务某大客户，客户的市场老总要上行业大会发言，自己脑袋空空，就让广告公司代笔写稿。麻烦的是，这位老总自己也不懂好坏，一遍遍挑刺，稿子改了无数版还是过不了。同事被折磨得没办法，给我打电话：“要不你来一趟吧，公司出评审费，你就以行业专家身份夸两句，说这篇稿子有深度，客户肯定信。”我当时又好气又好笑：“你们这都‘跪舔’成什么样了？客户的发言稿也得你们写？”他不屑地一笑：“这算什么，他当年MBA的毕业论文都是我们代劳的。”后来我把这事讲给另一个开广告公司的朋友听，他一脸淡定地接话：“那都不叫事，我们客户家的马桶堵了，还是我们上门通开的。”

听完这些，你大概能理解为什么很多人说乙方没尊严。其实也未必。等我后来自己开了家咨询公司，就再没被这些破事儿纠缠过。过去在大公司做下属，业务和收入不是自己能做主的，碰上离谱要求也只能硬着头皮上。自己当老板就不一样了，不该赚的钱，一分都不想碰。比如前期接触时，如果有客户暗示回扣，我会直接婉拒，这单宁可不接。服务过程中要是遇到故意刁难或是理念不合的客户，也绝不委屈求全，体面地跟对方说再见就好。

赚该赚的钱，赚配得上的钱，做一个不卑不亢的乙方——这世上没有理所当然的“跪”，只有互相尊重才走得长久。
