# 生财要讲究术，更要讲究道

一直想把这句话说清楚：既要会赚钱，也要赚得有底线。

最近看到圈子里有人拿同路人下手割韭菜，看到亦仁持续发声，内心那种酸涩和怀疑感，我感同身受。副业这口锅被做脏了，真正想做事的人反而不好意思开口。

我自己手上也有培训业务，过去很多次想在副业发声却忍住了，怕别人误会我是在做自我营销。对这份业务怎么来的，我不想多解释，解释一句都嫌多余。我只说一个立场：我的课程统一七天无理由退款，如果是副业圈的伙伴，三十天无理由退款，绝不纠结。

但我想说的远不止是退款政策。核心是副业的底线在哪儿。

君子爱财，取之有道，这不是口号。

你说自己没启动资金、没资源、没人脉，第一桶金来得难，喊你去组建团队做产品，确实有点站着说话不腰疼。做搬运、做混剪，充其量是职业操守有问题。

可当你开始在视频号卖所谓包治百病的神药，那已经触碰了诈骗的红线。在小红书兜售高奢高仿，那就是明晃晃的售假。更别说刻意包装人设，在朋友圈晒P出来的虚假数据，借此收割别人的培训费，这早就不是什么割韭菜的道德争议，而是涉嫌电信诈骗。说白了，这是违法，不是缺德。

问题是，有些人靠这些擦边、违法的路子赚到一点小钱，还沾沾自喜，把经验包装成方法论跑到副业社区里分享。这已经不是赚不赚的问题了，这是带偏人、毁前程。兄弟，这已经是误人子弟，谋财害命的层次了。

这篇不是点名，也不是针对谁。我只是为副业这个群体的纯粹发声，为亦仁那份想把事情做干净的执念发声，更是为我们每一个人以后的路发声。

人身自由远比财务自由重要。钱亏了可以再挣，底线丢了反而能挣更多，这话听着像段子，信以为真就是歧路。

物以类聚，人以群分。副业的风向，靠亦仁的初心，也靠你我每个人的自觉。别让放大器放大的是信任流失。
