# 赚钱这件事上，我们该如何以终为始设计自己的未来？
作者：龙哥

经常有人带着困惑来找我：明明已经三十多岁，过去这些年一直按部就班地工作，也没有刻意提升自己，到现在没什么拿得出手的技能。现在想赚钱，却不知道从哪里下手。不知道你是否也有同感？

老实说，这个坎我也踏过。当年从程序员岗位离开，想在互联网上找点机会，整个人都是懵的。2017年我加入了龙哥盟，各种项目琳琅满目，看多了反而更迷茫。后来才渐渐明白：项目永远追不完，赚钱的钥匙从来不在项目清单里，而在你自己身上。

因此，在寻找项目之前，先把自己研究透。不是先问“做什么能赚钱”，而是先问“我想成为什么样的人”，从那个终局倒推回来，设计今天该走的路——这就是所谓的“以终为始”。

想通这一点之后，你会发现赚钱的底层逻辑其实很简单：先搞懂自己，再打磨出一种别人难以替代的价值，认认真真帮一批人解决问题。你越用心，回报就越厚。项目本身并没有绝对的好与坏，能不能成，关键在做事的人。

如果你正处在同样的迷茫里，不妨先停下来，回到自己身上找答案。
