# 单枪匹马扛住 158 个读书群，我是这么做的



## 一个人就能管 158 个群？我的运营逻辑

作者：小马宋
日期：2024-07-29

最近总有人问我，你到底是怎么一个人把 158 个读书群撑起来的。群已经做了两年多，数量还在涨，维护的人就我一个。

其实很简单，我运营社群的目的很明确，就是为了保持持续的对外发声。文章、视频号、🧣都行，读书群只是我实现内容分发的一个渠道。

所以我的定位就是低功耗运营，我不去追求群里有多热闹。

我每天的工作量就两件事：周一到周四，每天发一段自己的读书感悟；周五发一段关于学习方法的总结。借助企业🛰️的群发功能，一次撰写就能推送给全部群，工作量可控。

这背后是一套取舍思维。战略的本质就是放弃。想要群精准，就要牺牲规模；想要群活跃，就要投入大量时间成本；想要规模做大，就必须接受成员质量参差不齐。

诸如答疑互动、引导讨论这些增进活跃度的事，我基本不做，也做不过来。

群里有人@我提问，我没回是常态，回了才是意外。真有需要处理的紧急情况，比如拉人进群、踢人违规，记得直接@我。其他常规问题，我不一定能及时处理。

规模上来后，麻烦也来了。只要新群一开，就会有推销者盯上。常见套路是进来批量加人，然后开始卖课、发广告，甚至有筹款平台的人进来发求助链接。

群里光明正大地发广告的，一律直接踢出，无论是公益还是商业，都一样处理。

至于私下加人的，我真的无能为力。读书群是自动入群机制，根本审核不过来。你想拦住那些进来只为了发广告、拉人头的，也拦不住。而且这类人通常加完一轮就自动退群，自己就走了。

正因为是低功耗模式，所以也请大家理解，我不会因为有人私下加人就去处理。

提问欢迎，但我不承诺必回。想实时交流，可以每周四晚上来我直播间连麦。想深度沟通，我们提供 3 万元/次的见面轻咨询，可私信详谈。

朋友想进来一起读，完全欢迎拉人。

我开这个群的核心诉求，是扩大个人观点的触达范围。说得功利一点，就是维持影响力。对进群的朋友，我能保证的只有一点：我会持续输出个人见解。至于其他服务性期待，我无力也不打算兑现。
