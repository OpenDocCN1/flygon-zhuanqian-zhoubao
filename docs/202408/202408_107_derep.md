# 主业和副业，别总想着“平衡”

作者：亦仁 ｜ 日期：2024-08-11

每年都有不少圈友在星球里问同一个问题：主业和副业，到底该怎么平衡？

这个问题我答过很多回，每隔一段时间，答案就会变一次。不同阶段的人，也会给出不一样的答案。原因很简单——人对事情的看法，会随着自己的处境和阶段不断更新。如果现在再让我回答，我的思路是这样的。

**一、先理清关系，再谈安排**

很多人一上来就琢磨怎么把两份工作的时间劈开，我觉得这思路得调整一下。主业，其实是在为副业铺路；副业，则是在为未来的事业铺路。与其纠结怎么“平衡”，不如想想怎么“衔接”——把主业和副业看成一条线上的不同环节，而不是互相抢时间的对手。

**二、每个人都该有一份自己的事业**

我一直相信，或早或晚，每个人都得有自己的事业。能找到一件事，让你百分之百投入、心无旁骛，哪怕最后没做成，那段经历本身也是一种独特的人生体验。人活一世，说到底就是为了尽可能多地体验不同的东西。

**三、在主业里，用创业的姿态去干**

我说主业在为副业铺路，绝不是让你在主业里摸鱼。恰恰相反，你要拿出创业的劲头去投入、去尝试。这笔账怎么算都不亏：

- 做成了，只要老板不算太差，回报和机会都不会少；
- 做砸了，经验和本事长在自己身上，风险有老板兜底，不用赔钱、不用负债，更不会破产。

**四、盯住主业里最值钱的几样本事**

在主业里，要有意识地练副业最需要的能力：怎么从0到1，尤其是怎么用最低成本去试错。我始终觉得，低成本试错的能力，就是赚钱最重要的能力。

如果运气够好，能近距离观察老板或操盘手，看他们怎么把一件新事从0做起来，那你一定要认真学，哪怕经常挨骂也值。

**五、赚钱的本质，是别让自己出局**

能赚到钱，核心就一条：把风险和成本控制住，让自己不被淘汰出局。只要还在牌桌上，就可以不断尝试，直到撞上成功。

**六、副业有起色了，又舍不得辞职？**

如果副业已经有了起色，却因为收入问题暂时放不下主业，那就拿副业赚的钱去招个线上助理，别舍不得。哪怕只是把时间省下来休息充电、养精蓄锐，或者多陪陪家人，都值。

助理最好从同学、家人、朋友里找，因为他们更信你。这时候你连招聘平台都还玩不转，陌生人大概率只会把你当骗子。

但你要提前做好两个心理准备：第一，助理很难干到让你满意，你会觉得这钱花得不值；第二，副业一旦太赚钱，助理没准最后就成了你的竞争对手。

没关系，大家都是这么过来的。先解决眼前的问题，未来的问题等来了再说。用钱买时间，再用时间换空间。

**七、这世上没有“全都要”这回事**

说到底就是取舍。你不可能副业风生水起、主业步步高升，同时休息和娱乐一样不少。反正我没见过谁能做到。赚到大钱的人，背后基本都有巨大的付出，只是有些付出的维度，你想象不到。

所以，当你问“怎么平衡”的时候，不妨再问自己一句：我是不是在期待——休息、娱乐、主业、副业，全都只增不减？

这好事，凭什么落到你头上？

**八、一个效率翻倍的笨办法**

和老婆打好招呼，周末专门留出一天，去付费自习室拼命干一整天。这一天的产出，基本相当于你每天下班干一小时、连干半个月。

另外记住：及时把你的进度同步给老婆。让她看到你在认真做事，以后你就有机会换来整整两个副业日。

**九、身体要紧**

别长期熬夜，先把身体保重好。

**十、让副业光荣转正**

给自己定个目标：三年，用副业赚到100万，然后体面转正。

能来到生财有术，你已经赢在了起跑线上。一起加油！
