# 用“奔袭战”的打法做同城实体发售航海营：30天撬动60万+，我们是怎么做到的

> 原文：[`www.yuque.com/for_lazy/zhoubao/ln3kygxbl3bdbr3x`](https://www.yuque.com/for_lazy/zhoubao/ln3kygxbl3bdbr3x)

先把结果摊开看。

同城实体发售孵化营上半年已经跑了两期，下半年在济南升级为“同城实体发售航海营”。三期的战报大致如下：

第一期、第二期落地山东临沂和济宁，学员个人到手月入过万的占比超过七成，其中两到三成的人单月到手收入奔着数万走。

第三期在济南升级后，30名船员结营。结营后16人被团队承接孵化，2人主动申请二次复训，留存率超七成。开单率做到100%，模式复用性被验证。全员助教加船员合计拿下60万+佣金，人均变现破万。

今天把能复用的底层打法拆成6个关键点，奔袭战的精髓就在于快、准、集中火力。

1、目标必须绝对统一。船员上船前就对战果有共同预期，方向不散，执行才不飘。

2、用牛刀杀鸡。配置和打法完全对标大项目来做，标准拉满，细节不将就。

3、始终以人为本去运营。先稳住人，再谈业绩，归属感有了，转化自然顺。
