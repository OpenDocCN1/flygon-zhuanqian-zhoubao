# 【实操分享】扣子自动生成公众号爆文，并发布到公众号

最近在龙哥盟的航海里挖到一个超好用的玩法：用扣子搭一条自动化流水线，从标题到成稿再到公众号后台，全程不用自己动手敲字。今天把完整步骤拆给你，跟着走就能让文章自己“跑”进你的公众号草稿箱。

先说下整体思路：我们会在扣子里创建一个工作流，让它根据你给的标题自动产出文章、配上封面图，然后通过公众号官方接口把内容传到后台。你只需要最后过目一眼，点个发布就行。

**第一步：新建工作流**

打开扣子，创建一个空白工作流。

![](img/4a31d7c07ea095b2066faa0e32c1a2e3.png)

**第二步：设置入口参数**

这里要预留几个输入项：公众号的AppID、AppSecret，还有你想要的标题。AppID和密钥后面会讲去哪拿。

![](img/1b73e338ed1133800afd7a3f4618d4d1.png)

**第三步：接入大模型写正文**

在工作流里加一个大模型节点，提示词就写“根据标题生成一篇公众号文章”，输入参数关联到刚才的标题变量。当然，你想让模型按什么风格写、写多长，都可以自己在提示词里调整。

![](img/4a1d2d7228aedcc6e5cced64607e0d18.png)

**第四步：用图像流做封面**

封面图不需要自己设计，直接让图像流用标题当提示词生成一张图就行。如果你想让封面更贴合文章内容，也可以手动改成正文里的关键词。

图像流需要提前建好，操作路径如下：

![](img/e07dc2f1d5076fe0546477e1870bc24c.png)

![](img/30cb735b1be2054e374d3442a3973c72.png)

![](img/2c7bd833a543b1fe356093b29efc8e21.png)

![](img/ea60180fd8c38811f2ac65861b496253.png)

**第五步：安装公众号发布插件**

在工作流里找到插件市场，搜索“微信公众号助手”，把它添加进来。我这里选的是“发布到草稿”，因为我不喜欢直接发出去，人工检查一遍才安心。

![](img/544670b39fca0d5e40cb1a84148c0ce3.png)

![](img/f13c00b360f6ad9ed7a4a8f5eb711e36.png)

![](img/cec26e8df094141941b9a94226172029.png)

**第六步：拿到公众号配置**

先扫码登录公众号后台，进入“设置与开发-基本配置”页面。这里能看到AppID，然后点“生成”获取AppSecret。注意：密钥只显示一次，生成后立刻存好；万一丢了也没事，重新生成一个就行。

把这两个值复制出来，待会儿要用。

![](img/3a9ff5bf64b783fda6c2fdc43f1cac92.png)

![](img/6a03111cbc331292c4f4b607a081fb82.png)

接下来还需要拿到公众号组件的IP。回到扣子插件页面，查看插件明细，展开后复制那个IP地址。

![](img/72e354df15130f7441a42d2d32685bb0.png)

![](img/b9924a8ef10ebdb22a50f11e781d3a8c.png)

![](img/33492a242544f8ff012f2bd5343887fe.png)

然后去公众号后台配置IP白名单——因为调用接口获取token时，只允许白名单里的IP访问。操作是：设置与开发-基本配置-IP白名单-修改，填入刚才复制的IP，确认后扫码即可。注意刚改完不会马上生效，可能要等几分钟。

![](img/7168a8a12242b3852388dd90a196540d.png)

![](img/90aadfc19c9405b9317f22faad5d4225.png)

![](img/220853899596f9bd07547ceea19c263a.png)

**第七步：配置token获取节点**

回到工作流，添加一个wx_access_token节点。access_token相当于你操作公众号的“身份证”，必须先去换取。参数就填前面在开始节点里输入的AppID和Secret。

![](img/3fe4322693f2845c18a0fb4a90d59ae2.png)

**第八步：上传封面素材**

用wx_material_upload节点把生成的封面图传到公众号素材库，返回一个media_id。这个ID就是封面的身份标识，后面发布文章时要用到。image_url取图像流的输出，access_token取上一步的返回值。

![](img/77406b15b0a46cfb3e71317ed8d650db.png)

![](img/ddf431b6cccc31f0b4b187d86d7027f0.png)

![](img/7d1469be89b1ea9e55e69ec18eb24cb6.png)

**第九步：发布到草稿箱**

最后用wx_upload_article节点，把文章标题、正文、封面media_id组装好，提交到公众号草稿箱。这里需要把刚才的access_token也传进去，参数照着图里配置就行。

![](img/ddaffeffd0595a228587cc47f4015670.png)

**跑一遍看效果**

填好公众号信息，输入一个标题，点试运行。整个流程会自动跑下来：

![](img/db38a4142a6a128ec9db63b53350ccf9.png)

![](img/070e54c9603390e00f3ec8cf80fa178c.png)

![](img/0fcb9f5a84cf3e3bf65cf239070b9b9d.png)

等状态变成成功，打开公众号后台的草稿箱，你就会看到这篇文章已经安静躺在里面了。接下来是排版微调还是直接发布，都随你。

这套流程最爽的地方在于：你只需要想一个标题，剩下的交给扣子。多试几次，找到适合你账号的内容方向，然后就能批量生产了。赶紧去搭一条属于你的自动发文流水线吧。
