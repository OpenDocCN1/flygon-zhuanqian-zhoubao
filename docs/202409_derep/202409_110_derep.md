# ('从 0 到 1，使用 RPA+Claude，我做了一个小红书爆款商品采集和分析工具', (2, 43))

最近我用 RPA 和 Claude 从零搭了一套小红书爆款商品采集与分析的小工具。

很多人不知道，小红书移动端 APP 里，用关键词搜出来的笔记和商品其实藏着不少机会。我的思路是：先把这些商品批量抓下来，再按预估销售额从高到低排个序，换个角度去观察用户需求和市场风向，效果还挺惊喜的。

整个自动化流程和前端展示页面，我都整理出来了，完整过程在这里：[`ia0969wpr2.feishu.cn/docx/Q5JbdWDvRohrbax45HscbUBHnVd?reRdXZ=1`](https://ia0969wpr2.feishu.cn/docx/Q5JbdWDvRohrbax45HscbUBHnVd?reRdXZ=1)

评论区也有朋友聊到，之前见过类似的东西，问我能不能把标签做成词云、顺便显示点赞数。我解释说，我这边主打的是商品信息采集，同时也会把笔记详情拉得更全，比如精确的点赞数、标题、文案都能拿到，不过确实还没加词云功能。对方也认同，说我的数据要详细得多。

还有人在问：能不能抓到最近 24 小时的销量，这样就能直接锁定小红书的实时爆款，对选品跟品会更方便。
