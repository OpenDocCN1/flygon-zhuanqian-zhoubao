# ('成大事，一定要练就自己持志如心痛的感觉', (2, 21))

想成大事，先把志向练成一种“心痛”的感觉。

你有没有见过那种人？不声不响，却进步惊人。好像什么都不在乎，又好像什么都放不下。差别不在天赋，而在心劲儿。

真正值得奔赴的志向，不是挂在嘴边的口号，而是藏在心底、一碰就疼的执念。就像心痛一样，深刻到你想忘也忘不掉。别人在为琐碎的情绪唉声叹气、为无谓的感情反复纠缠时，你却被自己的志向牢牢拽着，疼到不敢松懈，也痛到无法放弃。一个在情绪里打转，一个在志向上燃烧，差距就是这样被拉开的。

别小看那份“痛”的力量。因为痛，你才会天天惦记；因为痛，你才舍不得停下；因为痛，你才算真正把它当成了命里的事。别人还在原地感伤，你已经被那一点越烧越旺的念头，推着往前走了很远。

与其继续消耗自己去迎合那些无关紧要的情绪，不如试着让志向往心里扎深一点，深到像心痛一样，甩不掉，也忘不掉。到那时，超过身边人只是结果，成大事才是必然。
