# 卖学习资料，5个月赚了20万？我的小红书实操复盘

刷到不少圈友在问小红书卖资料还能不能做，今天干脆把这5个月的实操经历摊开讲一讲。我是申铭，第一次在赚钱有术发帖，如果哪里讲得不够到位，欢迎评论区拍砖。

先聊聊我和赚钱的缘分。我今年4月才正式入圈，但早在2021、2022年，我就没少蹭赚钱的内容看，算是一个资深“外圈粉”。今年托郑韩韩哥的福，被他拉进了圈子，这份情谊我一直记在心里。

再说项目本身。这个项目是2023年9月开始筹备的，10月上线了第一个商品链接。从上线到2024年元宵节前后，掐指一算也就5个月，账户里多了大约20万。最猛的一个月，30天做到了4.9万。我做的是教育学习资料类目，最大的成本支出就是平台扣点——最初抽5%，不过单月交易额在一万元以内不收佣金；最近我看了眼后台，这个类目的扣点已经降到了2%，相当于成本又薄了一层。

有朋友在评论区问我，打印是线下还是网上找的？我是统一在网上搞定。每次直接印100到200份，淘宝搜“同城打印”就行，但千万别图省事，一定要提前打样看看效果。另外特别提醒：自己原创的资料随便印，可影印或翻印别人已经出版的内容就不行了，今年三四月份出的政策，千万别踩线。
