# ('「老板识人大法」：如何避免被人割韭菜？筛选运营、销售、与交付人员？', (2, 35))

创业路上，最怕的不是项目黄了，而是看错了人。钱没了可以再赚，心被伤了、路走偏了，才是真麻烦。今天这篇，咱们就聊聊怎么练出一双“避坑眼”，把那些不靠谱的运营、销售和交付人员，提前从你的名单里筛掉。

我是珍妮，和合伙人陈铭 Ivy 一起，两年时间做出了两千七百万的营收，后来杀进房产赛道，两个月干了1个亿的成交。听起来挺顺吧？但说实话，创业这三年，我们也交过不少学费，被人坑过，冤枉钱花了不少。好在论起识人这门功夫，我俩在老板圈子里，还算拿得出手。

举个例子：去年12月，我就提前闻出了一个人不对劲。当时有个朋友来问我某样东西值不值得买，我自己其实根本没买过，但是凭着这人平时在公众号、朋友圈、社群里的说话方式、表达习惯，我直接就判断：这人手上的东西，靠不住。于是我赶紧拦着朋友，别急着掏钱。结果呢？没过多久，那个人果然爆雷了。

所以今天，我决定把这套识人方法分享出来。但请先记住一句很重要的话：这招只能用来防身，不能拿去主动攻击谁，尤其是刚入门的新手，功夫不到家就乱用，容易伤到自己，也容易误伤别人。

再给各位老板们垫句话：我没有任何树敌的意思，这篇也不是冲着谁来的。文章里没有夸任何人的话，凡是可能像夸赞的词，我都用“xx”替掉了，该感谢的人，我把谢意放在最后。

至于更详细的案例、拆解和对应的链接，我都附在文末了，感兴趣的朋友可以直接点进去看。如果遇到打不开的情况，记得在评论区跟我说一声，我马上把权限重新开一下。
