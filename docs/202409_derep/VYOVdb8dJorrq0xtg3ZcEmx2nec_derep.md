# 体制内人如何靠一个公众号副业做到月入过万的真实拆解

> 来源：[https://s943jw76tw.feishu.cn/docx/VYOVdb8dJorrq0xtg3ZcEmx2nec](https://s943jw76tw.feishu.cn/docx/VYOVdb8dJorrq0xtg3ZcEmx2nec)

我现在主业是国企金融体系的一名从业者。副业是从2022年开始做的。当时未婚单身，正好撞上被催婚的高峰期，身边结了婚的没结婚的，都爱来找我聊聊情感上的困扰，吐槽的抱怨的都有。

我就顺手在公众号里写写类似相亲日记的东西。后来自学了排版和写作技巧，粉丝慢慢攒到了几千。内容是有了，但变现完全没头绪，不知道路在哪。

# 转折点来自赚钱有术

2023年8月，我偶然看到一篇赚钱有术关于“投资亏钱”的合集整理，于是加了鱼丸微信，加入星球。随后参加了当月的航海计划，跟随公众号爆文航海实战学习了一大圈方法。

实战结束后，我的流量主收入从之前每个月两三百，提升到600，再到两千多，现在稳定在每月一千多左右。

我并不是走专业爆文路线，也没开多号。我觉得对上班族来说，公众号副业更适合稳扎稳打。追热点做爆文，流量主这块太单一，而且流量波动大，需要多号矩阵和批量工具，普通人很难复制。我的判断是，一个上班族，用一个账号踏踏实实做，月入五千以上是完全可以实现的，两年内达到这个水平不难，难的是很多人撑不到回本期就放弃了。

# 我的变现版图拆开看

**1. 流量主**
算是基础盘。现在累计变现已超过2万元。

**2. 付费文章**
我的粉丝非常垂直，都是靠内容涨粉，没做过引流，粘性很高。基本都是25-35岁的情感粉，女性居多。

我会定期推出付费文章和付费合集，频率是每周一篇。定价根据篇幅和干货密度分档，9.9、19.9、29.9都有。文章字数多、干货足，反响不错。平均下来每月能带来一千元左右的收入。

**3. 打赏**
这块很小，每月几十到一百多，聊胜于无。

**4. 私域转化**
情感号天然适合做私域。我的文章即使没推荐，平均阅读也能稳定在1500-2000，所以我做了情感咨询，按小时收费199元，还推出了半年和年度咨询套餐，价格都在千元以上。这块累计收入大概一万多，支付宝微信都有。

补充一句，情感咨询非常耗心力，大多是负能量且复杂的案子，心理承受力不够的人不建议做。

除咨询外，我自己写了一本脱单手册，从今年6月开始在私域售卖，这块收入已经突破3万元。

**5. 星球社群**
一开始我做过一个女性成长免费群，有一百多人。结果活跃度极差，基本只有我在发资源和电子书。免费的东西大家不珍惜，而且主业忙，精力跟不上就解散了。

最近刚上线付费星球，定价59元，上线不到一周收益就过了500元。后面应该会越来越好。

**6. 接广告**
目前一条广告报价1200元，接了不少单。最初想着每周接一单，但发现很多广告主不走互选，尽管承诺安全，实际出事率很高。所以接广一定要谨慎，违规了平台只罚创作者，广告主毫无损失。

**接广告实操注意：**
1. 互选接广风险很高。如果账号已有稳定收入，不值得为几百块冒险。接广还会影响自然流量，频繁接容易被限推。我接过的一半广告最后都被判定违规，即使删除了也会被追溯，常见原因就是过度营销骚扰用户。
2. 坚决不接的品类：算命封建迷信、医疗、减肥丰胸类黑五类、代发文章尤其是足球博彩相关、金融投资类下载软件、兼职副业类诈骗高发。
3. 报价没有标准。我一般按粉丝量10%报价，或按平均阅读量0.5-1元/阅读来算。可以主动给广告主一个区间，比如粉丝1千，报1000-1500，让对方砍价，记得往高报。

# 我的收入护城河思路

**保底收入：** 主业是国企，收入稳定，能覆盖生活和贷款，零压力。

**发展收入：** 公众号就是发展收入，会有小幅波动但整体稳定。这部分我基本不花，都留作保障基金和自我投资。如果没有新项目，就把已盈利的项目做大做精做优。龙哥说过，跑通最小闭环的项目就能放大，赚1块钱的模式也能做到100万，我很认同。

**开发新收入：** 当主业稳定、副业跑通后，有余力再去探索新赛道，比如小红书带店或视频号，都是可以叠加的。

# 给上班族做副业的建议

如果想做副业，最好选个人就能操盘、结合工作和兴趣的项目。既不耽误主业，也不折腾生活。

我也试过写热点追流量，但我对社会民生和八卦没兴趣，写得很吃力。写情感文章才是我擅长的，得心应手又赚钱。同样的耗时，我宁愿写两篇自己擅长的情感文，也不想硬啃一篇热点。

我的号是日更，全是手写。我的方法适合有耐心能坚持的人，不适合想快速套现的。

上班族做公众号完全可行，利用别人摸鱼的时间搜集素材写稿，很适合。

**变现的通用打法：**
职场号可以引流私域做职业咨询、面试辅导、简历修改，卖PPT模板、沟通话术等资料。
穿搭号可以做形象改造、穿搭指导，甚至卖饰品。
国学玄学占星号可以做八字解读、水晶手串售卖。

所有赛道都能找到私域变现点。

另外，提醒一下：上班族做副业别做免费引流。泛粉和白嫖粉太多，耗时耗精力转化率极低，还伤心态。精力有限，就服务认可你的付费意愿强的精准人群。可以从9.9的低价产品开始，至少筛选出有付费意识的人。

我常被误会是团队运营，有人加微信上来就命令我像客服一样回复。有些人加了不备注也不说话，直接删掉就好。私域要做精准，不要浪费时间在泛粉上。
