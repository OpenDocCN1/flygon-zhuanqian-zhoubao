# ('普通圈友的项目踩坑与反思', (2, 14))

普通圈友的真心话：没逆袭、没战绩，只有一堆踩坑反思

先说个前提：这篇文章不讲成功，只谈失败。没有逆袭的热血，也没有亮眼的收入截图，我就是个普通得不能再普通的圈友——小秦哥。进生财有术满打满算才一年，还是新人一个。今年4月，多亏涛哥推荐我才有机会进来。平时我基本不冒泡，主要是潜水看帖，老实说收获不小，但同时也被各位优秀圈友刺激到了，愈发意识到自己还有很长的路要走。

这算是我第一次在生财发帖，有点惭愧，但也是我真心的复盘。

我把这些年做项目掉的坑，以及后来怎么想的，尽量用大白话写了出来。文章分四个部分：
1. 我为什么要写这篇
2. 大学期间做项目，踩过的那些坑
3. 毕业后做项目，又踩了哪些雷
4. 关于创业，我有3个想法
