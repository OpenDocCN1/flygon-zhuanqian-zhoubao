# ('赚钱急于求成的心态，该如何破除？', (2, 18))

越急着赚钱，越赚不到？聊聊怎么跳出这个坑

原文来自龙哥盟 · 明白（每晚九点半入睡）

2024年9月6日

我已经在这个社群泡到第八期了，算是老人。

前阵子有位社群的伙伴跟我诉苦：他做梦都想赚到钱，东试一下西试一下，却总是铩羽而归。他并非不懂该先沉住气学习、把能力养厚，可每次还是会被“怎么还没结果”的焦躁拽走。他问：这种心态到底怎么治？

我听完特别有共鸣。这种状态从来不是个例，我的私信里经常有人问类似的问题。坦白讲，早年间，我本人也是如此。满脑子都是快一点、再快一点。后来经历得多了，慢慢想通了一些事，也看清了背后的底层逻辑，才终于从“必须马上变现”的执念里走出来。

所以今天，我想把关于“赚钱时总想抄近路”的思考重新梳理一遍。这份梳理不仅是写给提问的伙伴，也是写给曾经那个焦躁的我。

如果你正卡在同样的情绪里，不妨往下看。飞书上有排版更舒适的版本，入口在原帖里。

从留言区也能看到不少人有类似感受：

有人说，自己心里其实模模糊糊，隐约觉得有些地方还欠火候；可真要具体说哪里不足，又讲不清楚；直到对照文中的走势图，才惊觉自己正站在最左边那条曲线上。还有人说，道理是认的，但一直得不到正面反馈，难免开始动摇；身边没有可请教的明白人，也容易撑不住。我也在留言区回了一句：正面反馈这个话题确实值得专门聊聊，另一篇文章里有更细的展开。也有人只留下一句感叹：能力这东西，攒着攒着才变厚。更有人说，如果能更早读到它，大概能避开不少弯路。还有人直呼讲得真好，连声道谢。
