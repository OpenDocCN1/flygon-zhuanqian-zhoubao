# ('两性咨询赛道，我是如何做到日入 6000 元的？', (2, 26))

两性咨询日入6000元？这个副业让我越做越有底气

我是今年年初才混进“龙哥盟”圈子的，到现在也算是个新人。其实这个项目我早就想拿出来讲了，只是总觉得自己的成绩还不够亮眼，怕被笑话，所以一直拖着。今天算是下了决心，打算把我在两性咨询这一行的经验，认认真真复盘一遍，分享给感兴趣的圈友。

讲到这个项目的起点，其实挺偶然的。我最初并没有赚钱的念头，纯粹是想分享一些自己懂的东西，顺便多交几个朋友，跟大家碰撞一下想法。结果写着写着，来找我咨询的人突然多了起来，私信一天比一天密，到后来我一个人根本回不过来。既然需求摆在那，我就顺势开了付费指导，也是从那时候起，收入开始直线上升，最高的时候一天能进账6000块钱。

这个成绩谈不上多厉害，但至少证明这条路是走得通的。今天把这段经历摆出来，一是希望能给同样想做这块的朋友一点灵感，二是也想听听大家的想法，看我还有哪些地方可以改进。

当然，两性咨询的内容比较敏感，平时我在表达上都会特别小心。也请星主大人看在我认真分享的份上网开一面，别跟我计较。

评论区的朋友很给力，已经有人提议我做抖音直播引流，还有人说可以去推特上拓展流量。直播这事我其实有点慌，因为尺度真的不好拿捏，太露骨了容易违规，所以还在琢磨。推特这个平台我倒真没玩过，回头得去研究研究。另外还有位兄弟在评论区问“壮阳药哪个好”，结果被其他人一句“无中生友”调侃了，评论区氛围一下就欢乐起来了。
