# 扣子自动生成公众号爆文，并发布到公众号

公众号创作者最头疼的环节是什么？无非是写稿、配图、排版、发布这一连串的琐碎流程。现在，一套基于扣子的自动化工作流，把这些事一次性打包搞定——不光能自动产出公众号爆款文章和封面图，还能直接帮你把内容发布到公众号后台。

这一整套流程，等于把“选题构思—文章生成—封面设计—最终推送”全部打通。你只需要给扣子一个方向，剩下的写作与配图工作交给它，连最后的上传发布环节都替你省掉了。

换句话说，你不再需要反复切换编辑器、下载图片、手动粘贴排版。文章写好了，封面做好了，点一下，内容就已经出现在公众号里，可以预览、可以发布。

想要了解完整搭建方法和具体操作细节，可以直接看作者梳理的飞书文档：https://s1osl1nvrd.feishu.cn/docx/GfOhdEPY0odAzTxYUP4cPHJynkf?from=from_copylink

作者守正分享的这个方案，被不少圈友评价“太强了”“受益匪浅”。如果你也想让公众号创作从手动模式切换到自动模式，这份工作流值得一试。
