# 纯干货！普通人如何把小红书粉丝做到 10W+

小红书零基础，普通人做到十万粉，到底藏着什么门道？今天就来聊聊我的亲身经历。

大家好呀，我是柠檬。头一回在赚钱冒泡，先简单交个底：

我现在是全职做小红书的内容创作者。摸爬滚打了好几年，总算攒下了一点小成绩——全平台粉丝累计超过十万，把“读书博主”和“家居博主”这两个IP都做了起来，并且靠着小红书变现了五十万上下。

最有感触的是，如今我每天只需要投入四个小时，剩下的时间可以自由安排。用三成精力去搞钱，七成精力去生活，那个曾经不被看好的副业，现在稳稳地成了我的主业。

回头看，真的是自媒体改变了我。

下面说说我的做法。详细的执行细节，我通通整理进了一份文档，链接放在文章末尾，需要的小伙伴自取就好。

有朋友之前反映说打不开，我已经更新过了，现在能点进去，放心看。

很多人和我说“低成本先动手，再慢慢优化”，这话我特别赞同。也有人感慨“启发很大”，其实我想说——先把事情做起来，比什么都重要。

还有小伙伴问我：读书博主的变现渠道到底有哪些？这一块我在文档里写得很明白，看完你就会有答案。

还是那句话：别想太多，干就完了。
