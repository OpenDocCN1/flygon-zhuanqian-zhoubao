# 不会编程的我 2 小时用 GPT 写了一个 PDF 压缩工具

代码零基础，花两小时，让GPT帮我写了个PDF压缩工具

大家好，我是保山。

前阵子要投标，文件被卡在“30M以内”这条硬性要求上。我在技术论坛里翻了大概半小时，终于找到两个备选方案：一个是在线处理的网页工具，另一个是某捷6.8版的PDF处理套件。本来这事到这儿就该结束了，可第二天我冒出一个想法——要不让GPT帮我写一个？

没想到，这个念头真的成了。

回头复盘，这个工具是2024年5月做的。那时候Cursor还没火起来，我的整个操作流程特别“原始”：从需求出发，让GPT帮我写代码，我再把代码复制进运行环境里跑，遇到报错就把错误信息原样丢回给GPT，让它一步一步改。前前后后折腾了大概两个小时，最后拿到了一个能用的程序。要是换到现在用Cursor，估计连复制粘贴的步骤都能省掉，体验会更爽。

整个过程其实不复杂，却挺有代表性：一个完全不懂编程的人，只靠和GPT反复沟通，就能把脑子里的简单需求变成一个实际可用的工具。

详细步骤和完整对话我放在了飞书文档里，想动手试试的圈友可以接着往下看。如果这篇分享能给你带来一点启发，那我就没白写。
