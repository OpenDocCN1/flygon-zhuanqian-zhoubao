# 别等亏空变亏心，及时止损才是真正的止损



最近看到一个合伙创业的困境，听完真的让人后背发凉。

楼主是加入龙哥盟两年多的创业新手，和从小一起长大的发小在做抖音方向的项目。分工很明确：朋友负责拉业务，占比七成左右；他自己管公司运营和客户维护。公司一直有利润，关系也一直挺好。

转折从2023年开始。合伙人以财务混乱、管理不到位为由，强行收走了所有财务权限，自己一个人管进出，还定下规矩：合伙人每月只发3500块工资，年底再分红。楼主当时觉得是为了公司好，就点头了。

结果钱进了他手里，账没理清，制度也没建立。公司账户始终空荡荡的，反倒是他个人花销很大，对外人很阔绰，经常动用公司资金周转。而其他合伙人拿着那点死工资，根本不够生活，入不敷出。

楼主多次提过优化财务、放开权限，对方每次都否认挪用，拒绝任何改善建议。钱还在挣，钱却看不见，信任已经在一点点被掏空。

遇到这样的问题怎么办？

我的建议很直接：再找他认真谈一次，把底线和诉求说透。如果态度依旧没有改变，那就果断结束合作。

这不是一句容易做到的漂亮话，我知道身在局中会很难割舍，毕竟是发小，创业两年，感情和投入都是真的。但段永平说过一句很扎心的话：人其实大多都清楚什么事是错的，关键在于你有没有立刻停止去做。只要把错的事停下来，你就已经向做对的事迈进了一大步。而所谓做对的事，本质上就是——一旦发现自己在做错事，立刻停手，哪怕付出再大代价，那也都是最小的损失。

发现是错的事情的时候要马上停止，不管多大的代价都是最小的代价。

拖得越久，亏的就不只是钱，还有信任、时间和心力。当一个人已经开始用“管理混乱”为由独揽资源，又拒绝监督和制度化时，问题已经不只是财务问题，而是价值观和底线问题。继续耗下去，只会把小止损变成大沉没。

别用幻想去谈改变，也别用感情去绑架判断。合伙人一旦动手开始独吞权柄，那回头的路通常就已经关闭了。与其等到彻底崩盘，不如现在就认清，干净地退出，才是最体面的自救。
