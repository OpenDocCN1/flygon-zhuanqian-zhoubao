# 没有提前准备，我却因为这场临时跨年直播多赚了1.2万

嗨，我是龙哥，专注自媒体IP孵化和新个体创业，全网累计20万粉丝。熟悉我的人都知道，往年跨年我更习惯用一篇👸号文章来给这一年收尾。但2024年12月31日，我临时起意，给自己加了一场完全不在计划内的年度直播。

这场直播的初衷很单纯：向已经付费支持我的会员，以及一直观望还没上车的潜在伙伴，好好汇报一下这一年我到底做了些什么。没有精心准备，也没有刻意设计套路，结果直播一结束，竟然意外多成交了2个会员，直接变现一万二。

这个成绩算不上什么大数字，但放在“临时策划”这个前提下，的确是个不小的惊喜。所以我把整场活动的流程、关键动作和心得体会，都完整整理出来了。如果你也打算在2025年做一场年终演讲，或者通过直播来盘点成绩、撬动转化，这份复盘应该能给你一些思路。
