# 适当远离大佬！路在脚下，不在远方
作者：龙哥

这些年，我踩过不少坑，回头看却觉得每一步都算数。创业也好，做人也好，说到底就像一场规则随时会变的游戏。而我在跌撞中只学会了一件事：把本质想透，把过程看清，最后跟自己握手言和。

**一、别盲目追随大佬，跑出自己的步调**

以前的我，总盼着那些“功成名就”的人能直接给我答案。现在想来，那真是最傻的念头。站在高处的人，讲起道理来当然头头是道——坚持、长期主义、努力、踏实……这些金句听上去滴水不漏，让我忍不住仰望。可后来我明白了，大道理可以听，但落到具体行动上，如果你们不在同一个行业，他们的建议千万别当真。很多人栽跟头，恰恰就栽在这里。

更扎心的真相是：不少成功人士，自己都搞不清是怎么成功的。他们只是特别擅长把故事讲得又美又对。也许他分享了十个关键节点，真正靠谱的只有第一个，剩下的不过是赶上了风口。

我不是否定他们的能力，而是成功本来就是天时地利人和的叠加——风口、能力、资源、运气，缺一不可。大佬能讲清其中一两个要素，但他们的成功绝不是这几个要素的简单相加。更何况，对他们有效的做法，放到你身上未必灵。

我有一次跟一位跨行业的朋友聊天，他做得很红火，我忍不住问：“我现在做XX项目，你觉得怎么样？”他给了一堆建议，每一条听起来都很有道理。可等我回去一试，发现根本行不通——他的经历跟我的赛道八竿子打不着，那些建议反而成了干扰。

所以我得出一条心得：跨行业，别轻易采纳大佬的具体建议。他走通的路，可能跟你毫无交集。创业者最该有的能力，就是独立思考。

**二、判断一件事值不值得做？问问自己有没有尝过甜头**

为什么有些大佬翻来覆去就讲那几个观点？原因很简单——他们在那些点上尝到过甜头。坚持很重要，是因为他靠坚持成功了；创新是核心，是因为他靠创新赚了钱。这些观念被亲身经历反复强化，他们当然深信不疑。但对你来说，不一定适用。

可为什么听道理的人千千万万，真正做成的却寥寥无几？因为道理大家都懂，做到的人太少，而且这些道理未必适配每个人。

后来我自己琢磨出一套判断标准：**把整个流程拆开，看看自己在哪些环节真正尝到过甜头。**

比如过去做项目，哪些环节格外顺手、特别有成就感？那些能持续给我正反馈的地方，就是适合我的路。而那些怎么做都费劲、始终看不到效果的环节，大概率不是我的长项，要么找别人配合，要么直接放弃——前提是我能判断这件事本身是对的。

举个例子，我试过好几种获取流量的方式，只有其中一两种让我觉得游刃有余，也实实在在拿到了数据反馈。那我就该在这个方向上深挖，而不是盲目跟风新玩法。其实很多时候我们已经试过了，只是没留意哪些反馈是好的。

所以，如果某件事让我始终尝不到甜头，那它大概率不是我擅长的，我也不该把精力耗在上面——要么找搭档补位，要么果断Pass。

**三、心力不是等来的，要主动给自己充电**

做事最怕的不是方法不对，而是提不起劲。明明知道该干什么，却浑身无力，这种“心累”说明内在驱动力不足。

我也摸索出一些给自己“充电”的小办法，当然仅供参考：

**戴上耳机，听喜欢的歌。** 累到不行的时候，放一首最爱的曲子，让旋律把情绪唤醒。那种瞬间被治愈的感觉，能让心力慢慢回流。我个人偏爱钢琴曲。

**开车，打开阀门。** 一个人开车对我来说是一种重启方式。打开窗，踩两脚油门，很多好点子都是在那会儿冒出来的。

**穿上最喜欢的衣服。** 买一套自己觉得特别“有范儿”的行头，打扮利索，站在镜子前，心里自然会冒出一句“我可太行了”。这种底气会不知不觉带到工作里。

每个人恢复心力的方式都不同，但这些方法让我学会了一件事：**多跟自己的灵魂聊聊天。**

**四、幸福和成就感的真相：向内求**

很多人觉得，幸福来自外界的认可——收入涨了、职位升了、别人夸了。但我越来越发现，真正的满足感源于内心的平静。换句话说，**幸福是向内求的，不是向外求的。**

**帮助别人，比得到什么更爽。** 我真正开心的时刻，不是我赚了多少钱，而是我能帮到别人。当用自己的能力解决了他人的难题，或者带给别人一点启发，我会觉得自己活得很有意义。这种发心，比任何数字都让人踏实。

**多帮人，会收获看不见的能量。** 那些帮助未必会直接回报你，但它就像一种无形的推力，会在你低谷时出现。我失落的时候，曾经帮过的人一句简单的鼓励，就能让我重新打起精神。

**情绪低落时，别做任何决定。** 我有过几次在沮丧状态下拍板的经历，结果都损失惨重。后来才懂，人在负反馈里是看不清全局的。先把自己从情绪里捞出来，再面对问题。

**最后：找到你的心力开关，也找到让你开心的事**

这种“向内求”的感觉，该怎么形容呢？就像昨天偶尔跟一位23年初第一期培训班的学员通了电话。从业绩看，他们现在已经做到月利润三五十万。他说，当时只记住了我一句话：稳一点，走得远才是关键，要细水长流。但我觉得核心其实就一点，用段永平的话说叫“不做错事”。这阵子他一直围绕本质做事，不被短期诱惑带着跑。他告诉我，各个平台的店铺都开了，供应链和仓库也搭得差不多了，这才算真正要走到从1到10的阶段。我听完特别欣慰——这不是炫耀，是真心话；也不是营销，因为美团的培训早就不做了。希望他越来越好，行稳致远，我是由衷地高兴。

朋友们，每个人都有自己的路。别人的路只能当参考，不能照搬。**找到本质，找到自己的心力，找到真正让你幸福的东西——这才是最重要的，听自己的心。人生的路不在别人的嘴里，就在你自己脚下。**
