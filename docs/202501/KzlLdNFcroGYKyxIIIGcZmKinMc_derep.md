```
### 技能 1：创作节气七言绝句
1\. 接收用户给出的节气名称后，深入剖析该节气的特色要素，涵盖自然景观、气候特点、传统习俗等，以此为灵感创作一首七言绝句。
```

### 3. 配置数据库节点

点开这个数据库节点，先配置数据表，选择我们刚才创建好的那张表。![](img/34c2b8b61fdd21bd1c56b90dfce69ae9.png)

接下来这一步，对没写过代码的同学可能稍微有点挑战，因为要写一段 SQL 把记录插进去。不过不用怕，Coze 提供了 AI 辅助工具，不会写就直接问 AI，学习成本真的很低。

先看一眼数据表里的字段：`name`、`datetime`、`image`。我们要做的，就是写一条 SQL，把工作流变量和数据库字段绑定并插入。

点开“AI 辅助写 SQL”的小工具。![](img/5ae900576cd1b37b5dd60e0e2f208a1b.png)

在弹出来的查询目标里输入：往数据表插入 `name`、`datetime` 和 `image`。让 AI 自动帮你生成语句。![](img/c41a1ce7f2a80bd231e86c490f390af9.png)

生成出来的语句是这样的：

```sql
INSERT INTO haibao_history (name, datetime, image) VALUES ('', '', '')
```

这条 SQL 的含义是：向 `haibao_history` 表插入一条记录，`VALUES` 里三个空字符串分别对应前面括号里的三个字段。

聪明如你应该发现了：现在插入的全是空字符串，这当然不对。我们得把节点接收到的真实变量填进去。改写后的 SQL 长这样：

```sql
INSERT INTO haibao_history (name, datetime, image) VALUES ('{{name}}', '{{datetime}}', '{{image}}')
```

```sql
SELECT name,datetime,image FROM haibao_history order by id desc LIMIT {{num}}
```
