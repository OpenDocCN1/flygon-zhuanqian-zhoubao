# 每个月都能稳定跑大几百万的流量，有什么变现效率比较高的业务吗

手里握着每个月稳定的大几百万流量，想找一条变现效率更高的路子，该怎么选？

这是我去年九月在杭州，向圈里做本地生活很有一套的聪哥请教的问题。当时我的团队已经跑通了比较成熟的获客体系，也试过不少行业的玩法——家政阿姨、亲子培训、禅修营招生，都折腾过。一路做下来，团队流程和作战经验都磨得比较扎实了，就想着找个利润更厚的赛道再冲一冲。

聪哥听我讲完，反问我一句：为什么不回到你原来最熟的餐饮？

我一开始是有点抗拒的。餐饮我自己开过一百多家店，这行利润薄得可怜，不管代运营还是自己干，营销成本都很难覆盖。但聪哥接着问：餐饮里就没有接近100%利润的生意？

这句话点醒了我。做了这么多年餐饮，我确实有点看轻这个行业，总觉得外面还有更香的项目。但仔细一想，餐饮里还真有一种模式能做到接近100%的利润——文旅餐饮。

它属于比较特殊的餐饮业态。去年十月我在这块做了些尝试，目前看机会挺大，值得琢磨琢磨。大家不妨看看自己所在的城市，能不能把类似的模式复制落地。
