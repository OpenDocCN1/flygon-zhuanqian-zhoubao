# 面试不是审判，是把你卖出应有价位的交易：我的从发抖到被抢offer的转变
作者：龙哥



## 从社恐发抖到猎头主动递offer，我踩过的面试坑

作者： Yorking

日期：2024-12-30

圈子里搞赚钱、赚快钱的大神不少，但对一群还在打拼的年轻人、在职的大厂人、以及想斜杠转行的朋友来说，能不能靠面试拿到一份真正匹配的好工作，才是更现实也更关键的能力。

对于绝大多数没有背景资源可走的人而言，二十岁到三十岁这十年里，靠面试闯出一份理想工作的经历，几乎能决定你职业起点的高度。说得直接点，面试这件事玩得溜的人，就能把自己的价值卖得更高，甚至能把人生轨迹拐个大弯。

最近就有位做室内设计的朋友私聊我求助面试问题，我俩语音聊了二三十分钟。我从简历怎么打磨、面试前要做哪些功课，到现场细节和注意事项，都给他梳理了一遍。

说实话，我自己就是典型的 I 人。小的时侯见到陌生人就慌，让我上台说两句，我腿软到整个人都在抖。曾经的我谈面试色变，一紧张连完整的句子都组织不好。后来却慢慢逆袭到被猎头轮番追着给offer，成为面试常胜的状态。这一路的体感和拆解，可能对你也有些用。
