# 新人要怎么迈过商业市场上那道 0-1 的门槛

**新手怎么跨过商业市场那道从0到1的坎？**

如果你正卡在“从0到1”的位置，不妨听听我的故事。我是龙哥，老家在安徽淮南，现在合肥生活。八月份我加入赚钱；九月尝试👸号爆文，没能跑通；十二月调转方向，到📕做虚拟资料。没想到转折来得很快：12月11日发出第一篇笔记，12月14日拿下第一单——10元；到12月21日考研开考之前，累计成交53单，入账450多元。对我来说，这是真正意义上的“从0到1”破局。

之所以把这段经历写出来，是因为圈子里还有不少新人卡在这一步。说真的，450多元并不算多，也并非遥不可及，只要肯把项目研究透、执行到位，并在过程中不断优化，大多数人都能到达同样的地方。希望我的分享能给你一点启发。
