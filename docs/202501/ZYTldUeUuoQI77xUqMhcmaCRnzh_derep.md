# 我把情侣聊天记录做成了一份“恋爱论文”，20小时搞定出海版MVP



大家好，我是Cheer（林悦己）。这期想跟你分享一个我用AI做编程变现的真实项目——**「情侣聊天记录可视化报告」**。

事情的起因是：去年6月，有个网站上线了一个叫“微信聊天记录可视化报告”的东西。我研究了一下他们的产品后，决定自己动手做一个新版本：

**海外版情侣聊天记录可视化（非中文）**

现在MVP已经做出来了，不过还没部署上线。整趟下来，我靠的全是GitHub上的开源项目加上Cursor这个AI编程助手。从零到做出下面那张成品图，一共花了20个小时。

整个链路是：

**导出数据 → 数据清洗 → 数据可视化 → 数据分析 → 排版出报告**

每一步都交给代码搞定。

# 二、我自己的产品思路

我一开始的想法是：“可以换一批目标用户，但保留‘聊天记录可视化’这个核心卖点。” 甚至考虑过做“群聊天记录可视化”，还想去调研一下运营社群的朋友有什么需求。

但真正开始动手的时候，一个念头冒了出来——**我为什么不做英文版？直接出海啊！**

这个产品的存在本身，已经证明了有很多情侣或者用户需要这种服务。既然中国人有这种需求，老外肯定也有啊！

既然人家已经帮我验证了需求，那我干嘛还要再换个方向瞎折腾？

所以我又绕回来，还是做情侣聊天记录可视化。

他们做微信、QQ，那我就做海外版的“微信”和“QQ”——比如WhatsApp、iMessage、Instagram、Messenger，甚至一些恋爱交友App，像Tinder之类的。

方向就这么定下来了。至于聊天记录可视化本身，对做技术的我来说倒不是难事；最麻烦的是怎么把各个平台的聊天记录导出来。本着快速跑通的原则，我决定“近水楼台先得月”——先拿自己现成的聊天记录下手，渠道优先选iMessage。

顺便说一句，我自己就是iMessage和dating对象聊天的，已经积累了两个月左右的聊天体量。

## 2. 一步一步生成数据和图表

按照原本的计划，我应该去下载微信聊天记录，让对方帮我生成一个模板，然后像素级拆解。但我又抠门又懒，就直接看了她的报告目录，搞明白她的思路后，立刻开干。原始报告有4个板块，我的MVP只挑了第一个板块来复刻。

## 3. 数据和图搞定了，怎么整合？

其实我一开始根本不知道该怎么“排版”。用Python拆数据、画图，是我熟悉的领域；但最后要生成一个PDF，到底怎么做？我不懂。所以我就让Cursor告诉我“实现路径”，先了解思路和可用工具，再让它一步步实现。

![](img/b9926fac48bf4935ea662d955f954274.png)

![](img/a48c1856da2b2685a61143ba4705504b.png)
