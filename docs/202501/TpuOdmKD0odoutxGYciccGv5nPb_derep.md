# 杭州传术师闭门会笔记：学事、做事、连结人的完整复盘
作者：龙哥



我是龙哥，成都。刚从杭州的传术师线下见面会回来，这次特意做了归纳，从个人成长、商业打法到人脉经营，提炼出几条可以直接落地的收获。没能到场的朋友，可以看看有没有能用上的部分。

先感谢赚钱团队的组织，也谢谢组长大智的夜话局，感谢七天给的建议，七天的内容功底真的强。

## 一、个人成长视角

### 1.1 学习要一直在线，纸质书是基本盘
有朋友问闭门会博主输出力从哪来。他的回答很简单：每天雷打不动看纸质书。
大量阅读能让认知不断更新。会上听到领导说今年已读十几本，我自己却一本没碰。想起刚工作三年时，我也靠工具书起步，《文案训练》《我在一线做用户增长》《传神文案》这些书帮我建立了框架，还写过读书笔记被转发。那段时间停止了输入就开始吃老本，惰性上来后输出质量也下降了。这次又被提醒：高手之所以持续领先，是因为从未停下学习。

### 1.2 用AI做商业推演，别只让它当搜资料的
提升决策力的关键词是：用AI，喂名人类语料，用大佬视角来推演。
火火老师分享自己思考时会直接对AI说“如果你是段永平，会怎么想”，并先把段永平的语录喂给模型，让它先内化再输出。核心思路是小样本模仿。
实操建议是先让AI把图片或长文本描述清楚，再进入提问。能玩出几种角色：
1. 商业智囊团，让段永平、巴菲特、马云、乔布斯、雷军、周鸿祎一起开会
2. 反方辩友，预判攻击点和应对方式
3. 内容模仿，套用喜欢的脱口秀演员风格写稿
4. 沟通沙盘，模拟“你是老板/你是下属”，优化话术

### 1.3 反馈要主动索取，尤其要找负面反馈和更高位的人
龙哥给出的思路是：主动要负反馈，听比你结果好的人。
负反馈像一面镜子，照出盲区。动作很具体：问信任的人“我哪里需要改进”“有没有更优的打法”。价值在于快速修正。
找高手建议，三步走：带着明确问题去，不要空谈；全程倾听不辩解；建议落地后及时复盘并反馈进展。必要时创造合作机会，实现双赢。
一句话：主动求批判，让成长加速；向大佬请教，让路径变宽。

### 1.4 底层自信的来源是赚钱的自由度
关键词：多赚钱。
会上有人问如何平衡家庭与副业。嘉宾举例说儿子会骄傲地说“爸爸有钱”，这种配得感就是自信的底座。
我曾看过《人世间》的说法：孝有两种，养口体是照顾衣食住行，养心智是让父母为你骄傲。二者皆重要。养娃亦然，经济能力带来的安全感，是另一种形式的陪伴。

## 二、项目实操视角

### 2.1 精准找项目，离源头更近
关键词：贴近发布者和信息源头。
我自己的判断逻辑是：先认识更多人，扩大信息差，再看自己能不能做。
流程：
1. 目标先定：要现金流、要长期收益，还是要资源人脉
2. 资源盘点：现有账号设备能不能0成本启动？团队是否具备对应能力？我之前想做图文还是短视频直播，因为账号现成、团队写文强剪辑弱，最后选了图文，避免重投入亏本
3. 小步快跑验证：看准就立刻测，至少测4-5次。没资源时，金成的建议是每天睡前30分钟刷赚钱，盯风向标筛项目

### 2.2 遇到危机靠心力扛住
关键词：自我调节。
无论是舆论压力、项目瓶颈还是人生低谷，核心都是心力够不够。靠自己强大的支撑力熬过去，相信认可的方向终会开花结果。

## 三、如何和优秀的人建立深度连接

关键词：分享、真诚、持续输出价值

**分享是开门的钥匙。** 会上所有精华帖作者都毫无保留地讲过路径，尤其是几位资深前辈，把选品、执行、避坑全盘托出。分享本身就是关系的起点，龙哥说的“越分享越幸运”在现场得到验证。

**别被第一印象骗了。** 有人看起来高冷难近，聊开后却非常真诚乐于分享。被拒绝是常态，说明你在向上爬。真诚交流后才会露出深度关系。

**建联四步法：**
第一步：会前做功课。了解对方经历、擅长和代表成果。
第二步：问对问题。避开泛泛而谈，聚焦可复制的关键点：
- 你是怎么发现这个机会的？
- 第一次做到百万，最关键的三件事是什么？
- 瓶颈期你是怎么过的？
- 提升某项能力，你建议从哪些资源开始？
- 你获取高价值信息的渠道是什么？
- 你如何判断一个风口是真的？
资源类问题：
- 谁或什么资源对你职业最重要？
- 我想做这件事，你建议从哪些渠道或人脉切入？
第三步：主动给价值。输出见解、实战经验、行业观察，让对方感受到诚意。
第四步：长期维护。会后联系同频的人，做桥梁介绍资源。建联也看缘分，不要执着于名单，开放心态往往有意外收获。

## 四、给00后年轻人的建议

关键词：前五年跟对人学事。
一位嘉宾35岁才开始赚钱，他说前五年积累能力比赚快钱重要。回头看，30岁前拼命透支的人很多进入瓶颈。年轻人最该做的是跟对的人学事，提升能力与格局。
我刚毕业时在知乎也看到过类似观点，后来选择深耕而非速成。事实证明，前五年沉淀的人，35岁后往往出现质变。别用速成换眼前利益。

## 收尾
线下活动的价值不在于认识了多少人，而在于能否建立高质量的连接。高效连接靠精准判断加真诚交流，用主动提供价值来维系，才能打开持续合作的大门。
