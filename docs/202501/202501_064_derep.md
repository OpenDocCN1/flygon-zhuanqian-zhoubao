# 火爆的私域直播，普通人该如何切入这个赛道？
作者：龙哥

下午跟私域直播赛道里的标杆企业亿绘驿站聊了整整半天，信息量很大，值得好好复盘一下。

先说说我对这个模式的理解：私域直播本质上就是“社区团购 + 中老年直播”，可以说是专门给中老年群体定制的社区团购升级版。目前这个赛道还处在抢地盘阶段，年利润破亿的玩家非常多，而且大量加盟店也都在实实在在赚钱，并不是只有头部公司在吃肉。

我们团队一直在做同城实体赋能相关的事，所以看到这个模式的第一反应就是：这不就是帮社区小店增收吗？基于这个判断，我们做了一轮比较扎实的调研，也打算正式往这个方向试水。
