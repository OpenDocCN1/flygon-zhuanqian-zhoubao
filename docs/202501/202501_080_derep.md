龙哥盟这次想把一部分办公资源开放出来，让和我们一样的人可以聚在一起干活。

如果你正好符合下面这几种状态，可以重点看一下：

1. 你现在是自由职业者、个体创业者，或者想抽空 gap 一段时间，或者正在找工作，或者工作本身就能线上完成、地点不重要
2. 你想亲身体验下赚钱总部里的创业节奏和搞钱气场
3. 你渴望加入一个能交流、能抱团、既有独立空间又有部落感的同频人群
4. 你希望有机会能在办公室里碰到我，跟我聊聊你的项目、聊聊方向

1. 入驻只是共享办公，不等于进入龙哥盟的孵化体系
2. 名额只面向龙哥盟圈内的朋友，不对圈外开放
3. 入驻后需要缴纳工位费用，标准是 1 颗龙珠碎片/月，折合 1265 元/月
4. 为了保证办公氛围，每个申请者都需要通过一次面试
5. 龙哥盟保留对相关规则的最终解释权
