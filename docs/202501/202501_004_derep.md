# 团队扩张必备：统一工作理念的 20 条通用准则
作者：龙哥

**团队一扩大就乱？我整理了20条工作原则，帮全队对齐认知**

很多团队在从“小分队”走向“正规军”的过程中，最容易出问题的不是业务方向，而是大家思考问题、做事情的标准不统一。一个人一个想法，协作起来全靠沟通靠磨合，效率自然上不去。

我是龙哥，87年生人，算是个标准的中年大叔。这些年一直在打工，从传统行业到互联网，再到游戏行业，大部分时间都在做HR相关的工作：人才发展、组织发展、招聘这些。岗位和收入在HR圈子里也算比较靠前，传说中“HR年薪百万”算是真实存在。中间有两年和朋友一起做电商创业，可惜没赚到钱，又回职场了。今年再一次离开职场，和以前的同事对接了投资资源，正在做游戏公司的配套业务，还在起步期。

2024年5月被朋友推荐加入赚钱。说实话，以前对社群这类东西挺排斥的，总觉得是割韭菜的。但朋友打包票说一定会有收获，就进来了。进来的大半年基本都在潜水看帖，确实看到了很多有价值的案例和故事，自己也记了不少笔记。我没有成功的创业经历，但有两句话特别触动我：**“发声=发生”、“一切链接要先考虑能为别人带来什么价值”**。所以我想从自己擅长的领域写点什么，希望给处在某个阶段的创业者和老板们一点参考。

今天想分享的是我在团队规模扩大之后，总结出来的一套团队工作原则，也可以理解成20条通用准则。它更多是我个人经验的沉淀，不是绝对正确的标准，但背后的道理，对团队人数不断增加的伙伴应该会有点启发。

这套原则主要适用于两个场景：

**第一种**，当你的公司或组织已经出现两个以上团队时，就必然涉及个人分工和团队间的协作。这时候，每个人都需要对自己手头的工作、自己的产出，有一个底线性的要求。

**第二种**，当团队人数超过3个人，就不再是单纯靠个人产出拿结果了。大家需要提前对齐认知，建立一套共同的标准，让所有人对“工作”和“产出”的理解保持一致，这样分工配合才会顺畅。
