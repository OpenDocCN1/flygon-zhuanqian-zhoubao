# 副业小白加入副业半年多，跑通多个项目并且成为航海教练，我做对了什么？

你可能不会想到，就在半年前，我还是个在副业上颗粒无收的“老白”——整整三年，没靠副业赚过一分钱。但加入龙哥盟之后，我的副业轨迹彻底改变了。

半年多的时间，我不仅跑通了几个项目，还意外成了航海教练，甚至参与了航海手册的编写。回头看，其实并没有惊天动地的秘诀，只做对了几件事。

第一个路径是闲鱼二手书。别人把它当赚零花，我却找到了“躺赢”的玩法，不必时时盯盘，订单自己会来。

第二个是👸号爆文。第一篇还在摸索，第二篇就撞上了10万+，更惊喜的是，之后连续发了50篇，其中11篇都是10万+。这个结果，说实话，我自己都有点意外。

第三个是视频号带货。高峰时段一天佣金接近一万，靠着从赚钱链接到的伙伴，我组建起一支150人的线上打品团队。这些伙伴，几乎都来自赚钱这个圈子。

很多人问我，从0到教练，到底做对了什么？我想说，最大的改变不是技巧，而是认知和圈层。在那之前，我像没头苍蝇一样乱撞；加入后，才真正理解了项目选择、执行节奏和团队协作的重要性。

现在我把完整复盘整理成文档，放在飞书链接里，感兴趣的朋友可以直接去看。写出来，一是想请各位老师多指点，二来也是希望给那些正迷茫的伙伴一点信心——你看，一个三年没开张的副业小白，都能在半年内跑通多个项目，你也可以。


期待在评论区和你交流，一起加油。
