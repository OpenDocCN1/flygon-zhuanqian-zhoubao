# 两个月从短视频老师到 AIGC 设计师，我的经验复盘
作者：龙哥

两个月前，我还是一个教短视频的老师；两个月后，我成了AIGC设计师。很多人觉得不可思议，但我想说：转型没有想象中那么难，关键是别让自己一直站在“老师”的位置上旁观。

你真正要做的，是下场动手。开一个自媒体账号，持续发布你的作品，这其实就是为自己刷新一封“数字简历”。没有经验的新人，最需要的就是自己给自己创造机会。流量、粉丝、商单，从来不是目标本身，而是在你专注证明自己的过程中，意外掉落的礼物。

回顾这两个月，我走过了三个很关键的阶段：

第一个阶段，是第三周。那时我连AI工具都还没完全吃透，却意外签下了人生第一单AIGC商单。这个经历让我明白：机会往往在你行动之后，才会主动敲门。

第二个阶段，是第一个月。我开始静下心来研究AI绘画、AI视频的创作技巧，并且把心得同步到网上。就是这份分享，让我的账号从0涨到了1000+粉丝。

第三个阶段，是第二个月。一家AI头部公司给我发来了AIGC设计师的offer。那一刻我突然意识到，前面所有的积累，已经在悄悄为我铺路。

当然，这一路我也踩过不少坑。我把自己踩过的坑、总结出的方法、完整的复盘思考，都整理进了一份飞书文档，链接放在下方。无论你是和我一样想转型的创作者，还是刚接触AIGC的新手，这份经验都值得你打开看看。


希望我的经历能给你一点勇气和方向。
