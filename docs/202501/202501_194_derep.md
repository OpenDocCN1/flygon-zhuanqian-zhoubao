# 加入赚钱四年后首次担任航海教练的体验与感悟

四年赚钱老船员，第一次当上航海教练，我彻底被震撼了！

大家好，我是龙哥，编号9817。掐指一算，今年已经是我在龙哥盟的第四年，即将迈入第五个年头。就在这次，我终于圆了多年前的一个梦想——担任时间管理航海的教练。

第一次以教练身份参与，从启航前的筹备到正式开船，整个过程让我再一次深刻感受到赚钱体系的强大。那种细致程度真的令人叹服：航海手册一改再改，连海报上的介绍文案，都要用精准的数字反复推敲。这里必须隆重感谢我心中的新女神——小鱼。她逻辑清晰、心思细腻，前期全靠她的引导，否则这么多琐碎又复杂的事情全堆给我一个人，真不知道要熬多少个日夜。

当然，还有领队和志愿者团队的鼎力支持：雪雪、藍、逍遙、ing，以及众多默默付出的志愿者。这些繁杂又精细的工作，如果没有他们分担，我恐怕早就被压垮了。

因为是第一次当教练，时间管理航海有不少规则需要讨论。让我特别感动的是，小鱼在沟通过程中给了我很大的自主权。比如航海直播原本固定安排在晚上八点到九点，但和我自己的课程时间冲突，我就试着问能不能提前一小时。小鱼很快回复：帮你争取争取！结果三分钟后就告诉我没问题。这种效率和对教练的尊重，简直让人心潮澎湃。

更特别的是，这次航海手册的呈现方式非常有意思：一开始完全是空白的，每场直播后逐渐填入内容，直到七次直播结束，才形成一份完整的手册。这个方式也是我提议的，小鱼没有二话，立刻答应。作为教练，能被这样信任和尊重，真的是一种满满的幸福感。

这篇文章除了表达感谢和开心，还想给所有圈友分享一份我觉得特别棒的档案。航海过程中，我一直习惯用举手提问的方式互动：船员按固定格式举手，我用语音回答，然后由我的学生和志愿者帮忙，把每一条语音都转成精修过的文字。最终沉淀出了一份完整的《时间管理问与答手册》。

航海期间，船员累计举手提问213个，问答总字数达到了22.4万字！所有这些内容都整理在飞书文档里，带完整的标题和大纲，全是时间管理相关的干货。希望能对大家有帮助。

最后，真的特别开心能担任这次航海教练。感谢小鱼、雪雪、逍遥领队、蓝领队、ing领队，还有所有志愿者、每一位船员，以及帮忙整理档案的学生们。这也是一次非常奇妙的共创之旅！
