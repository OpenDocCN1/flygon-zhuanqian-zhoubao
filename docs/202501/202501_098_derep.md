# 生病也能少花钱？我把这些报销的“冷知识”整理出来了
作者：龙哥

大家好，我是龙哥。

白天我在做医疗运营的工作，经常为三甲医院的医生撰写科普内容，平时基本泡在门诊里；业余时间我是一名保险经纪人，对医保规则特别感兴趣，家里也有正在与癌症抗争的亲人。长期的关注让我养成了习惯：总想着怎么让看病花的钱更值。

去年在赚钱社区刷到几篇讲省钱思路的文章时，我忽然想到，能不能把自己这几年在医院和保险领域摸索出来的经验，整理成一套关于“如何让报销更划算”的实操分享。于是有了这篇笔记。

我把内容拆成了三大块来写：

第一块，医保目录内有哪些容易被忽略、但能帮你省钱的信息差；
第二块，一旦遇到大病冲击，能用哪些方法把报销比例拉满；
第三块，在没生病之前，如何提前做准备降低未来的医疗支出。
