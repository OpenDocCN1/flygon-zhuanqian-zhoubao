# 副业信息差怎么找？我用 8 年副业研究经验，拆给你看，还附了 2 个春节就能上手的机会
作者：龙哥

嗨，我是 龙哥。

折腾副业这条路我走了快 8 年，最大的体感就是：赚钱的本质就是信息差。


**一、我研究信息差的基本思路**

信息差不是瞎猜，是有套路可循的。

1. 先找“时间差”。比如节假日、开学季、年底年初，需求爆发但供给还没反应过来。过年就是典型的窗口期。
2. 再找“人群差”。不同年龄段、不同职业、不同圈层对同一件事的需求侧重点完全不一样。
3. 最后找“平台差”。同一个产品，换个平台卖，价格、玩法、用户都变了。

核心就一句：别追热点，先卡位差。

**二、两个过年就能做的实操信息差**

我这次重点整理了两个春节期间验证过、可快速落地的方向，思路和细节都在上面的飞书文档里，有兴趣直接拿去复刻就行。过年回老家也能搞，不耽误走亲访友，还能顺便赚点零花。
