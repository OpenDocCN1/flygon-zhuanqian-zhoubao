# 别让“好学生”思维毁掉你的创业幸福感

最近和于冬琪聊创业，聊到一个特别反常识的点：在📕做消费品牌，学习成绩好，可能反而是 handicap。

我们写《种草》的时候就一直在琢磨一个问题：为什么那么多大厂出身、名校毕业的硬核创业者，做不出让人尖叫的爆款消费品？

答案可能很残酷：用户要的是生活，而他们自己根本没在过。

于冬琪举了个例子，有家公司下了班就断电关灯，6点之后整个园区黑下来。更绝的是，老板会强制要求团队休假，还规定今年必须去新加坡玩一趟。理由很简单：我们的用户都在新加坡打卡，你没去过，你凭什么理解她？

能做出好产品的根本逻辑，从来不是脑子更聪明，而是比用户更会生活。你得先有生活，才配谈懂生活。

而这里就牵扯到学霸和学渣的本质区别了。

这不是褒贬，是两种面对错误的方式。

学霸为什么成绩好？因为他把大量时间砸在了学习上。孩子们在放学冲出校门的时候，他还在题海里自罚。因为一道错题，会让他产生强烈的焦虑和自我惩罚。

而成绩不好的那批人，慢慢练就了一项关键能力：犯错了，不自责。错就错了，这道题不重要，下一个。

于冬琪说他自己就是典型。曾经的学霸，后来在北大“堕落”成学渣。他庆幸没有一直被分数牵着走，因为他更早地摆脱了那种对完美的控制欲。

你去看那些状态真的松弛的创业者，问他一句“你当年是不是成绩不咋地”，十有八九他会笑。她能包容自己的失误，也能包容团队的失误。这种松弛感，就是生活的起点。

创业做产品，本来就是一个无限犯错的行业。bug、差评、策略失误，每天都在刷新。但学霸模式的人一旦看到问题，就会立刻被焦虑激活。焦虑怎么解？只有两条路：减少生活，投入更多时间去死磕。

结果是，你离用户越来越远。

反过来，一个从小在错题本上混迹的人，他的底层心智是：不是所有错都致命。什么该死磕，什么可以放手，他门儿清。于是他能把时间空出来去生活，先过上用户向往的那种生活。产品自然有了灵魂。

这让我想通一件事：我们一直把效率当成美德，其实极致的效率可能是最大的不幸福来源。你追求零失误，最后只能用批评和惩罚来维稳，这是最省力的管理方式，却也是最让人精疲力竭的方式。

但现实里，真的存在另一条路。很多优秀的消费品牌，它们既有利润，也有温度。团队能准点下班，老板敢强制休假，产品却做得比别人更懂人心。

成功的方式有很多种，为什么非要选那种又苦又累的呢？

干脆选一种更幸福的成功方式，不好吗？
