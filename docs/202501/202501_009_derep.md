# 关于市场的两种玩法：钓鱼与拳击
作者：龙哥



上周五聊到何加盐老师提出的积累型游戏和排序型游戏，今天我想换个角度，分享我自己归纳出来的两种市场原型：钓鱼型市场，和拳击型市场。

在商业世界里，市场形态大致可以分成两个极端，而绝大多数行业都落在这两端之间。

先说钓鱼型市场。特点很直观：你的业绩几乎和对手无关，彼此井水不犯河水。你只需要把自己的钩子下好，鱼会上钩与否取决于你的技术，而不是别人。说白了，你能否做成事，全看自己手艺深不深。

散户参与的股市就是一个很典型的例子。你能不能赚到钱，和隔壁那位股民的表现基本没有关联。咨询行业在我身上也得到印证。

中国有几千万家企业，真正有需求的潜在客户基数非常庞大，缺的不是需求，而是能靠谱交付的服务商太稀缺。几年前我给一位做香水的朋友引荐了一家选址咨询团队，今年他特意来感谢我，说这家是他们成立以来合作过最靠谱的咨询方。

其实他过去也找过不少团队，效果平平。那不是竞争的问题，是整体供给质量的问题。只要你把服务做到足够扎实，并把口碑传出去，客户自然会找上门。这就像在太平洋上钓鱼，真正下钩的人只有一百多号，关键看谁的技术更熟练，而不是谁抢了谁的位子。

这类市场最大的特质是：机会是常驻型的，不存在一闪而过的窗口。想什么时候入局都可以，核心永远是把自己练好，再让人看见你。

再看另一个极端，拳击型市场。在这种场子里，不把对手打趴，你就拿不到名次。即时通讯就是教科书案例，🛰️之所以成为终局，就是因为把其他的社交应用都清理掉了。平台类赛道基本都属于这一类。

在这里，节奏比功底更致命。必须在窗口期集中投入、速战速决，抢到第一把交椅，后来者再优秀也很难翻盘。

现实中纯粹的极端不多，更多企业处在两者之间。我个人更偏爱钓鱼型的赛道，规则简单，不用天天算计对手的招数，做好一件事就够了。
