# 📕能赚钱的，恰恰是因为人家先过上了好生活

作者小马宋在2025年1月3日的这篇笔记里，聊了三件看似不相关，却指向同一个答案的事：📕上真正赚钱的商家、自己的家庭日常，以及电影《破地狱》。

**一、先有生活，才有生意**

前一天和于冬琪老师的直播主题是「📕怎么赚钱」。去蹭干货的朋友可能要失望了，两小时我们没丢出一个速成套路。

我们聊的是一个更底层的观察：能在📕上做起来的商家，到底是什么样的人和公司。

很直白的结论：他们是会过日子的人。团队里员工的幸福感普遍在线，不是那种把命都押在事业上、苦大仇深的传统老板。传统老板往往只有工作，没有生活，自然也不懂顾客口中「想要更好的生活」到底是什么感觉。

而📕上的赢家，他们自己就过得相对松弛，会玩、有生活、有情绪。所以才能和同样想把生活过得更精致的用户产生共鸣。会生活，不但不阻碍赚钱，反而是赚钱的前提。

**二、陪伴本身就是沟通的练习**

这周一，我被太太强制放假一天。上午陪她去改裤脚，我就坐在裁缝店旁的咖啡馆里喝咖啡。

中午去西单吃了碗螺蛳粉，是她广西老家的味儿。吃完去了青年宫影院看《破地狱》，口碑不错的港片。

看完陪她去做头发，我顺带做个头皮护理。元旦那天则陪儿子写了一整天作业。青春期孩子火气大，冲突在所难免。

但火气大不等于没法谈。我花时间听他说感受、说想法，也把我的看法讲清楚。最后事情还是顺利完成了。

我自己的体会是，家庭里很多失控的争吵，本质都是沟通失灵。听不懂对方在说什么，也进不了对方的视角，矛盾只会越滚越大。

可惜的是，像我这样奔五的老男人里，大多数人跟妻子孩子几乎没有真正意义上的交流，活在自己的世界里，既不陪伴也不对话，家里自然各种糟心。

**三、环境会让沉默代代相传**

我小时候在山东农村长大，家里人之间交流极少。夫妻、父母子女都是有事说事，没事就沉默。情感表达几乎是缺席的。

哪怕心里有话想说，当地方言里也没那么多温柔的表达方式。说“我喜欢你”“我爱你”用普通话还算自然，用山东话就很别扭。所以我觉得推广普通话是有意义的，它能让家庭的情感流动更顺畅一些。

**四、《破地狱》讲的也是这个**

《破地狱》看上去是道教题材，其实内核是生活和沟通。

郭文很爱女儿，却张口闭口都是“女人污秽”。他逼儿子学法事做破地狱，其实是担心儿子读书没出路，想给他一条能养活自己的路。儿子却只觉得父亲剥夺了自己读书的权利，很羡慕能自由选职业的妹妹。

女儿想继承父亲的职业，可这门手艺又传男不传女。

三个人心里都有话，都很爱彼此，但没人说出来，只会用争吵代替表达。

电影没什么大剧情，就是一地鸡毛的日常，看着就让人心酸。最后的安排让所有人都放下了执念，各自解脱了。

郭文临终前让女儿给他破地狱，在传统里是近乎叛经离道的举动，却也成了最体面的和解。
