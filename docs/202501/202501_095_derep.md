# ('业绩好的员工，未必可做高管：《南洲翁遗训》有感', (2, 25))

为什么很多“销冠”一升任管理岗就废了？一个业绩顶尖的销售，单兵作战能力无可挑剔，可一旦被推到总监位置，反而团队带不动，自己也焦头烂额。难道业绩好不代表能力强吗？这个问题，其实早在一百多年前的日本，就被西乡隆盛说得明明白白。

西乡隆盛，号南洲，是明治维新的核心人物，也是稻盛和夫的鹿儿岛同乡。稻盛和夫一生推崇的“敬天爱人”，正是源自这位前辈的思想。甚至稻盛和夫的许多名言，溯源上去都来自西乡隆盛。而西乡留下的《南洲翁遗训》，乍一看就像中国古代圣贤的著作，字里行间全是浓厚的汉文气息。

书中有这样一句话：“于国有勋然不堪任者而赏其官职，乃不善之最也。适者授官，功者赏禄，方惜才也。”意思是：一个人对国家有莫大功劳，但他没有能力胜任官职，这时候非要封他官做，反而是最大的祸患。真正珍惜人才的做法是——能胜任的人给他官职，有功勋的人给他厚禄。

道理很简单：功劳和能力是两回事。立了功，可以给钱、给荣誉，但未必适合升职。就像销售冠军，你给他加薪、给提成，怎么都合理；但硬把他按在管理位上，很可能害了团队，也害了他。

创业者尤其要明白这个道理。那些跟着你打天下的兄弟，有人才华出众，当然要一路提拔，让他管更多的事；但也有人忠诚有余、能力不足，这时候与其硬塞进管理层，不如给他丰厚的薪水待遇。对公司是好事，对个人也是成全。

《鹿鼎记》里也藏着同样的智慧。韦小宝替康熙立下无数大功，康熙却始终没把真正的实权交给他。因为康熙太清楚，韦小宝是个福将、弄臣，打仗可以，治国理政是真不行。所以该赏的金银、该封的爵位一样不少，但实权岗位始终与他保持距离。

有趣的是，《南洲翁遗训》通篇引用的典故，从尧舜到四书五经，几乎全是中国的古典文化。这并不让人意外。日本长期受汉文化浸染，在明治时代前后，官方正式记录仍以汉字书写，后来才逐渐弱化。今天日本常用的汉字也还有一千九百多个。去奈良看古寺庙，那些匾额碑刻上的繁体汉字，常让人恍惚以为身在长安。而浙江湖州长兴县的大唐贡茶院，明明是复原的唐代建筑，许多游客却觉得像极了日本风格。文化流传与错位，就是这么有趣。

说到底，业绩好的人，未必就该做高管。奖赏他的功劳，别高估他的管理能力，这才是真正清醒的用人之道。
