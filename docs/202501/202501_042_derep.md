# 付不起 Cursor 的账单？用 Roo-Cline + DeepSeek 一样丝滑



最近全网都在刷 Cursor 的使用心得，讨论热度确实高。功能层面它确实在线，我自己也用过一段时间。但免费额度耗尽之后就基本停用了。主要原因很现实：第一，作为海外服务，国内访问体验时好时坏；第二，重度使用下来，费用肉眼可见地往上飙。

就在这时候，看到一个开源替代方案在社区里冒出来：[Roo-Cline](https://github.com/RooVetGit/Roo-Cline)。上手研究后发现，这玩意儿的功能覆盖相当全，代码补全、文件操作这些 Cursor 的核心能力它都有，甚至还额外支持命令行对话、驱动浏览器做 AI 自动化测试。

最关键的一点，是它的模型接入方式非常开放。Roo-Cline 本身不绑定任何一家大模型，而是通过 API 形式接入。你可以接 OpenRouter、Anthropic、OpenAI、Google Gemini、AWS Bedrock、Azure 以及 GCP Vertex 这些主流服务商。更灵活的是，它还能接入任何兼容 OpenAI 格式的 API，也可以本地部署模型，像 LM Studio、Ollama 这样的本地方案都能直接用。

这就意味着成本可控了。想省钱就换性价比更高的模型，想完全自控就自己部署一个开源模型跑本地，Roo-Cline 都能适配。
