# 用 AI 把爱变成一份可视化报告，我在试水“情侣聊天数据变现”

大家好，我是 Cheer，林悦己。今天聊一个我正在做的 AI 编程变现项目：情侣聊天可视化报告。

起因要追溯到 2023 年 6 月，有个国内网站上线了微信聊天记录可视化报告，据说上线半年流水就突破了 10 万。这条信息点醒了我。

我换了个赛道去做对标：做一个面向海外的、非中文的情侣聊天记录可视化版本。目标用户就是那些想用数据回顾感情的情侣。

目前原型已经跑通了，正式上线还在排期，Demo 效果可以看 P1 的截图。整个 MVP 我是纯靠 Github 上的开源方案加 Cursor 一把梭搞定，从原始聊天记录导出、清洗整理、图表生成、情感分析到最终的报告排版印刷，全部由代码流完成。一个人闷头做下来，差不多花了 20 个小时就把第一个可用版本跑出来了。

这篇复盘我会把思路拆开来讲：

1. 我是怎么拆解对标产品的
2. 我对海外版产品的定位和功能设想
3. 从零到可用的完整实操路径
4. 冷启动阶段的 0 到 1 推广打法
5. 下一步的迭代规划
6. 做这个过程中 Cursor 的一些实战用法，尤其是画流程图那块的细节
