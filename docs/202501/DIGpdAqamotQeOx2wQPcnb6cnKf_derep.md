# 扣子实战拆解：如何用一键生成新年春联海报

> 来源：[https://mb8jo3jay5.feishu.cn/docx/DIGpdAqamotQeOx2wQPcnb6cnKf](https://mb8jo3jay5.feishu.cn/docx/DIGpdAqamotQeOx2wQPcnb6cnKf)

最近在给一个做大学生及社会工作者英语学习 APP 的客户搭建智能体，他们参加鸿蒙应用大赛已经进决赛了，想在产品里再加点有创意的 AI 功能，大家有没有好点子可以交流一下？目前已经上线的是一套剧本杀智能体。

为了回馈大家的讨论，我和搭档整理了一份新年春联生成器的制作拆解，文里的方法可以改一改复用到很多场景。

# 一、成品效果

整体思路是实现一键出图式的对联生成：

1、由用户自行输入内容
2、把输入当作横批或作为创作主题去延展
3、直接调用画板功能渲染成成品图

# 二、上手流程

## 1、进入扣子平台

国内地址：https://www.coze.cn/
海外地址：https://www.coze.com/

国内版可接入国内大模型，海外版可接入海外大模型，日常使用国内版即可。

这是进入后的主界面

![](img/d894b75ab5b23325fa2371d657b45798.png)

首页有官方教学引导，往下是工作空间。新手默认只有个人空间，可以新建团队空间，团队内可多人协作开发智能体，资源也能共享

![](img/6e74182466cb8e3f0638de56d35efdbb.png)

点一下创建新团队即可

![](img/4109e7ce6029f041b176c2316e5680c8.png)

商店里收录了别人的作品和官方出品

![](img/352937feac81eb11d46f03ffe2a9107c.png)

模板是可以直接复制复用的智能体，工作流也能一并搬走。官方模板免费，其他人发布的模板可设免费或付费

![](img/d7d0a99d843221285af90ca1828354b0.png)

其他功能上手很快，直接点进去就能明白。我们直接切入正题

点右上角的 + ，会出现两个入口：创建智能体 和 创建应用。简单说应用是界面更精致、可自由排版的版本。如果刚开始不熟，建议先从创建智能体入手

![](img/83dcf7174b3e1adef7009ad17bc41a9a.png)

![](img/1783586ae084211a6a424dd898a4dd3e.png)

创建完成后会进入这个编辑页

![](img/d4293249454b9f6696acad849d64bdea.png)

先忽略其他功能，先点这里新增工作流

![](img/38bf5e5d77815b5739d512d9a7a00017.png)

点击新建工作流，下方还会列出你发布过的资源库工作流。若在团队空间，能直接引用团队成员已做的工作流，再往下还有官方示例，拿来即用。

![](img/159846675e90f5245709007744f89e18.png)

进入创建页面后有两种模式，这里选择工作流

![](img/923bf97da9b3dcb72a707ae3fb608247.png)

为工作流命名，建议用英文，输入错误会有提示。描述里写清楚用途，一方面方便大模型理解，另一方面后期作品多了也能快速定位

![](img/02c8c85ffffe30f230fa67a5fb1e0431.png)

进入工作流画布，默认自带两个固定节点：开始节点接收用户输入，结束节点输出结果。底部是扣子新推出的工作流模板，可直接套用。节点间需用连线连接，点击蓝色小点即可连通。

![](img/0c98c3fa8303e187cee62a094a1c86ec.png)

下面开始搭第一个节点

## 01、开始节点

![](img/cf3f53553a7348c750635110e00461ef.png)

点击开始节点后右侧会弹出配置项

变量名：input，可自定义但必须英文，代表用户输入
变量类型：string

对变量类型不太清楚可以参考这个视频：https://www.bilibili.com/video/BV1cS421d7Lo?spm_id_from=333.788.videopod.episodes&vd_source=2fbc07ca9d77406a24df42e65c625454&p=21

## 02、大模型节点

点“添加节点”选择大模型，并与开始节点连线

![](img/6dc4a34d3608389f65e68bccc6e20ff0.png)

进入大模型配置页

![](img/ea997099482abed74b8689b8555dc367.png)

最上方是单次处理和批量处理。单次处理一次只进一条信息，批量处理可一次多条一起处理。这里我们用单次。

模型选择区可挑选想要的大模型，每个模型都有说明。

![](img/34aa9f9c6e5f2c7e9ca08525312a9899.png)

技能区可挂载插件扩展能力。注意插件也可以在智能体主页添加，实测放在大模型节点里更稳定。

![](img/1d7e13d9f7334aecbcdf74ce63dafd60.png)

![](img/33cc9b7102bd08f7680663356c060613.png)

在输入设置里点设置按钮，选择开始节点里的 input，表示大模型接收的数据来源是开始节点的输入

![](img/8a22b1d65a373db1a7c1d3e076b71ad8.png)

随后配置系统提示词。用户提示词是给角色的具体指令，系统提示词是设定角色身份，例如医生。本案例只需要系统提示词即可。

![](img/b03f5021829986fd39c29e9ed5338d1d.png)

```
系统提示词：
# 角色
你是一个擅长对联创作的人工智能助手。能够根据各种主题撰写平仄合理、对仗工整、文字优美且内容喜庆祥和的对联。

# 任务
请你根据用户输入的创作主题{{input}}创作一副对联。要求：

创作要求：
你是一个能根据特定主题创作对联的人工智能助手。所撰写的对联内容紧扣主题，平仄合理且对仗工整，上联以仄音收尾，下联以平音收尾，整体风格喜庆祥和，字数相等，结构对称，既可典雅也可通俗，富有深意，简洁有力。
1，上下联是7个字，横批是四个字。
2，在duilain字段输出对联内容，格式为：
上联：
下联：
横批：

然后请你在up输出上联文字内容，不要包含其他信息。
然后请你在down输出上联文字内容，不要包含其他信息。
然后请你在hp输出上联文字内容，不要包含其他信息。

```

输出字段定义为：

up： 上联
down：下联
hp：横批
duilian：完整对联

![](img/5e295768003ea634afe21243e02ef711.png)

## 03、输出节点

![](img/c67f2bdd1ef965b29ebaca79872e172e.png)

在输出节点点设置，选择大模型节点的 duilian 作为引用

![](img/bc61b50f5daa745c443c3b5a2ae9db43.png)

在输出内容里填入提示词

![](img/9f4b2729a54e295f1afaf819f81c7dfc.png)

提示词示例：

好的～💡

根据您的要求，我写了一副对子：

{{output}}

接下来给您配一张图，请稍等片刻

{{output}}，按住 shift 键 + 大括号，颜色变蓝才算正确引用

## 04、画板节点

继续添加画板节点，与前一个节点连通

![](img/bbc16d0556402769ed305c7882001216.png)

点击画板节点，点击 + 号新增元素

![](img/cbdc237140f55b1caecf3515f640fae8.png)

这里的变量名要与前面保持一致，元素值需一一对应大模型输出的内容

![](img/bb358c857370bb5ae6a6a0e1cb88e688.png)

双击右侧画板编辑区的空白处或点击放大，即可进入编辑。素材已提前准备好

![](img/10a0a0762851c245e7332342987cea68.png)

![](img/15e7c3f22502bf7d8770a509562e5224.png)

## 05、结束节点

最后接结束节点，选择返回文本，参数名设为 image，参数值引用画板节点的 data

![](img/c4a81cea7ac785893d3abe1dafe50d0e.png)

![](img/6d88ecf08b3054aa60908bf7f4f62d60.png)

提示词写法：根据你的需求，为你生成的对联图片如下：![]{{image}}，使用这个 Markdown 语法可在智能体内直接展示图片，不写的话只会显示链接，需要手动点击。

## 06、发布前检查

发布前务必先试运行，排查错误

![](img/45828790e03d37be07d714736bb917e5.png)

![](img/9a0d8995033e92dd63c7ac32b9331aeb.png)

确认无误后点击右上角发布

![](img/f748f6977ab7bbecd7ec033b0075bf98.png)

填写版本号和版本说明

## 07、收尾优化

下方有角色设定与回复逻辑编排区，还提供提示词库，可保存自己的提示词和官方模板。写好提示词还能一键优化，也可再次修改智能体名称

根据用户输入，调用工作流 {}

![](img/e4d839ae3fe34c4ac7a13373e4223b92.png)

可添加开场白、预设问题、背景图、语音等

![](img/7905f20377b95245c2b06c50241f8b1d.png)

![](img/732159894a8ce67d1bd0c5540ed7a228.png)

设置一个首页背景图，可以用生成的春联图

发布前再做一次测试，确保流程通畅

![](img/efa74fcb9e7b4bffde2da1664fd98513.png)

最后点击发布，发布记录可一键生成，发布平台按需选择
