# 选择难而对的那条路
作者：龙哥

办公室墙上我特意挂了一句话：做难而正确的事。

它写给我的，也写给团队，更是想给每一次走进赚钱办公室的朋友一点触动。

每当我们真正在做一件难而正确的决定时，迎面而来的通常不是掌声。会有来自最亲近的人的怀疑，会有眼前很诱人的捷径在晃动，会有一波又一波的负面反馈扑过来。有时候连自己都会动摇，会问自己值不值得，会想退一步，会想干脆算了。

可正是这些时刻需要一个明确的锚点。假如我们习惯性地总去摘最低的果实，总去选当时看上去省事、见效快的选项，日子会越过越紧，麻烦会越积越多。反过来，如果我们能够在一次次岔路口，都逼自己往难而对的方向走，那么整体的难度曲线就会被拉平，路反而会越走越顺。

做难而正确的事，从来不是逞强，而是给未来的自己减负。
