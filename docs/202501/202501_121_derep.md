# 用 cursor 开发了个手机桌面文案壁纸生成器

标题：我用 Cursor 做了个壁纸小工具，也从一篇文章里读懂了赚钱这件事

大家好，我是龙哥。

最近我折腾了一款小应用，专门在手机上生成带文案的桌面壁纸，全程靠 Cursor 写代码搞定。做这个工具，大多数时候是靠着零碎的闲暇时间一点点磨出来的。也正因如此，读到明白老师的《如何在赚钱这件事上，做到知行合一？》时，我特别有感触。

文章里说，很多人在赚钱路上其实并不缺方法，也不是不知道该怎么努力，但偏偏就是做不到。为什么会这样？真正的“拦路虎”是惯性。行为上有惯性，情绪上有惯性，思维上也有惯性，这些习惯性的反应会在不知不觉中把我们钉在原地，让每一次的自我改变都变得异常困难。

那要怎么破局呢？文章给出的方法很落地：把激励自己的话放在抬眼就能看到的地方，让它们反复提醒自己；同时借助高频重复练习，把好的行为一点点内化成新的惯性。另外，环境也非常重要，无论是所处的圈子，还是长辈的言传身教，都在潜移默化地影响我们，以及下一代。想要改变，就得从日常小事做起，日积月累地坚持，才能真正见效。


最后，评论区有位朋友留言说，能一边利用零碎时间学习，一边还把软件做出来，挺厉害。哈哈，谢谢这位朋友的鼓励。其实我更想说，工具只是放大器，真正推动人往前的，是那份愿意打破惯性、持续努力的决心。希望我们都能带着这份决心，在自己的节奏里走得更远。
