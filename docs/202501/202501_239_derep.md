# ('2024 年感悟最深的 78 条朋友圈分享', (2, 23))

回望2024年，我在朋友圈零零散散写了很多心里话，快到年底时翻出来一看，竟然有几百条。我把它们反复删减、沉淀，最后留下了这78条。这不是什么成功秘笈，只是亲身踩坑后的一点清醒。

**关于成长与自我**

一个人能影响多少人，取决于你的辐射力；但你能真正成就多少人，才决定你的价值深度。想活出哪种人生，最直接的办法，就是找到已经活成那样的人，照着他们的人生轨迹走。别怕挫折，那不过是带刺的礼物；也别抗拒失败，那是在教你如何换个姿势重新站起来。

没有人是靠讲道理彻底醒来的，99%的醒悟都来自现实无情的敲打。每上一个台阶，都会觉得疼，但疼一次就长大一次，收入也会随之悄悄翻倍。最无助的时候，谁都帮不了你，只能自己咬牙撑过去。无人问津的时候，别急，那正是磨刀的最好时光。

真正的衰老，不是皱纹，而是不再尝试新东西。2025年我的关键词是“打开”——接纳一切未知，主动迎接变化。永远别说“我不行”，也不要给自己贴不设限的标签。害怕的时候就去面对，每次跨出一步，都会遇见一个更勇敢的自己。被占便宜、被误解、受委屈，这些都不是坏事，而是通往强者的必经之路。世界从来都是弱肉强食，想要拥有话语权，就让自己成为规则的制定者。

**关于做事与事业**

别再到处找风口了，能把一件事做到极致，就是你的风口。做事业不需要摊子铺得多大，宽度只有一厘米，但深度要挖到一万米。产品不要做一堆，把那个引流的爆款打磨到极致，比什么都强。标签太多，别人记不住你；只有留下最锋利的一个，才能被真正识别。

想法永远不值钱，干出来的才算数。边学边做，成败都是反馈，这正是创业最迷人的地方。成功的方法从来不神秘：找到一件行得通的事，然后反复去做，直到它失效为止。所谓半途而废，不是毅力不够，而是重复太少了，还没把本事内化成自己的一部分。

每一次看似轻松的小胜利，背后都是漫长的积累和持续的输出。越庆祝成功，就越容易赢来更大的成功，因为好的感觉会拉着你往更好的方向跑。没有名气的时候，别到处晃，专心修炼基本功；一旦风口来了，赚钱的机会不要手软，该狠狠抓就狠狠抓。在没有好项目的时候，先守住现有的基本盘，同时不断试新玩法、总结新经验。

**关于赚钱与私域**

在公域做流量，要顺着人性来；在私域做成交，要靠真心换。赚钱从来不会来自偶尔做一件事，而是来自你日复一日不动摇的坚持。靠运气赚来的钱，时间长了，最终都会凭实力亏出去。做自媒体，要学会把同一份时间卖给很多人，让自己“小钱不断”。

一次赚到钱，很可能是运气；能持续赚到钱，才是真本事，持续永远比爆发重要。积小胜才能成大胜，攒小钱才能变大钱，一直成功才是成功之母。很多你以为和钱无关的烦恼，说白了就是缺钱。赚钱能解决99%的问题，这句话越品越有味道。

别用自己的时间去换钱，要用思想和认知去赚钱。别人不愿意靠近你，钱就更不会靠近你；别人愿意信任你，钱会主动来找你。你不敢卖，别人自然不敢买，很多人赚不到钱，卡住的是自己心里的那道坎。赚钱的意义，就是让你有资格投资自己，果断买下曾经舍不得的东西，去做一直想做却不敢做的事。你的认知决定赚钱的上限，你的习惯决定你能赚多久。人脉不是努力来的，而是吸引来的，你的圈子，就是你的财富水位线。

普通人最快的捷径，其实是找到一个已经拿到结果的人，拼命学他、模仿他，然后超越他。但比赚钱更重要的，是让自己越来越值钱，多做那些能产生复利的事情。真正想赚钱的人永远是少数，大多数只是嘴上说说而已；那些真正赚到钱的人，早就放下了所谓的面子，怀着空杯心态，认认真真卖货。

想要对抗这个世界的不确定性，最好的方式就是多做有复利的事。每天保持进步，状态就会越来越好。做副业，不要一上来就指望快速暴富，先从拓展自己的朋友、学识、眼界和商业思维开始。真正有效的正反馈，从来不来自外界，而是来自今天比昨天强一点的自己。赚钱也好，做 IP 也罢，说到底就是四个字：准时出摊。别因为顾客少就三天打鱼两天晒网，剩者为王，你能一直留在牌桌上，就已经赢过了绝大多数中途离场的人。

**关于学习与连接**

如果你实在不知道从哪里开始，那就模仿。找一个年入百万的大佬，抱住他的大腿，学习他的思维，复刻他的动作，甚至和他变成同类。跟有结果的人在一起，你才会做有结果的事。选老师也是这个道理，要么别选，选了就死心塌地跟到底。一个人能成事，通常有两种可能：一种是身后有高人谆谆教导，另一种是自己跌到过谷底，然后在废墟里重新长出了一颗不死心。

被圈子捧得越高，越容易飘；只有读书，才能让你重新看见自己的渺小。新手想入局自媒体，最聪明的做法就是找一位好老师，然后把自己的执行力拉满，再找到一群志同道合的同行者。与其听一群号称“年入千万”的人在酒桌上吹牛，不如和一群踏实的“草台班子”一起低下头猛干。在你还默默无闻的时候，要拼命输入，像星辰大海一样去积累；同时也要拼命输出，像一剑封喉一样去表达。很多人看不见机会，是因为站得太远；只要你肯凑近一点点，就会看到那些看似平滑的地方全是空白和裂缝，而那里恰恰藏着别人没解决的问题。越具体，就理解得越深；越精通，就越能切入更细分的领域。

**关于品牌与关系**

大众永远会同情弱者，但他们只会为强者买单。珍惜那些话少、做事多的人，远离只会说漂亮话的“表演艺术家”。经营品牌，本质上就是在经营关系。一个懂得感恩的人，身边一定会聚集越来越多的贵人。一个人越来越好，并不是因为他什么都好，而是因为他不断让身边的人也变好。

当你创造的价值足够大，你就一定会被别人需要，也才能进入更大的社会交换系统，得到同等的回馈。最好的产品其实是你自己，最好的生意就是把自己卖出去。一味推销只会让人反感，但专业又热情的建议，却能让顾客真正喜欢上你。高客单价不等于销售，它是成就客户，是持续施加影响，而不是一锤子买卖。顶级销售从不抱怨，遇到问题就积极解决，专门帮客户处理最关键、最具体的痛点。

换一个圈子，就像换一条命。和高手同行，再小的素鸡也会慢慢变成凤凰。没有关系的时候，不要硬攀，先用心帮人，心甘情愿地付出，惊喜往往会在不经意间来到。每天主动花一分钟，真诚地链接一个朋友，久而久之，你拥抱的将是整个世界。那些牛人能够不断升级，常常是因为懂得“抱大腿”；但请牢牢记住，贡献永远等于收获，先给出你的价值，才会收到更大的回馈。

这一年，我遇到过二十几分钟的掌声，也熬过无人问津的长夜。回头看，最幸运的不是赚了多少钱，而是找到了自己愿意做一辈子的事业——自媒体，以及一群可以同行的兄弟：学富家族。如果此刻你也在某个沉默的角落里独自生长，请记得：别封闭，别设限，别停下。新的一年，愿我们都能把“打开”变成一种习惯，让所有好的连接，都向着我们涌来。
