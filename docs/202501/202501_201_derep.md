# 副业越做越焦虑？不妨先把“心态”理顺

上周末，我有幸以“组局官”的身份，参加了传术师大会在赚钱新办公室举办的线下见面会。我们荷包蛋小组围绕“副业焦虑”这个主题，展开了一场深夜围炉式的夜话。组里的伙伴们各自深耕的领域完全不同：有人做自媒体，有人搞电商，也有人跑通了自己的小咨询生意。大家都有拿得出手的成绩，按理说应该更有底气，可真聊起来才发现——每个人心里都藏着一团焦虑的火。

听了一晚上的案例和故事，我最大的感触是：情绪和心态，已经成了很多人事业进阶、个人成长的第一道卡点。它比方法、资源、流量更早地堵住去路。你会发现，很多时候，不是我们不知道怎么做，而是脑袋里的自我怀疑、比较和恐慌，让人迈不出下一步。

这次复盘，我把大家提到的共性问题做了归纳，也结合自己的体会，整理出几个针对性的解法。其中特别让我有共鸣的，是“好学生思维”——习惯了找标准答案，害怕出错、害怕被评价，这种思维放到没有既定路径的副业里，更容易引发内耗。但其实副业不是考试，没有满分，更不需要一步到位。允许自己先做成一团，再慢慢修改，就能卸掉不少压力。

说到底，副业带给我们的不该只有焦虑，还有探索的乐趣。把心态放平，路反而会越走越宽。这次夜话的完整复盘我已经整理成飞书文档，感兴趣的伙伴可以去看。希望这篇分享，能帮你找到那份久违的松弛感。

正如我们常说的：布道传术，成人达己。
