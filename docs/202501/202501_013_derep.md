# 如何在项目海洋里，快速锁定真正适合自己的那一个

大家好，我是龙哥。

过去八年，我一直深耕在教培的商业模型和销售转化体系里。2024年7月后，我加入赚钱，负责投资孵化和高阶航海的合作。日常工作说白了，就是每天大量看项目、聊项目。

最近周二晚上，我给赚钱的志愿者们做了一场内部闭门直播，主题就是《3步教你选出适合做的项目》。这套方法对正在找赛道、挑项目的搞钱新手特别友好，今天把核心思路整理出来给大家。

整个筛选框架我分成了三层递进：

第一层，是定性判断做粗筛。当赚钱的精华帖、风向标、航海项目铺天盖地而来时，怎么用一套清晰的维度快速把不合适的剔出去，先锁定有潜力的池子。

第二层，是定量验证算细账。光看感觉不够，要去做真实的市场调研，把数据拿在手里。算清楚营收模型、算清人效成本，检验整个商业逻辑是否真的跑得通。

第三层，是阶段匹配看适配。就算项目本身再好，也要问一句：这个项目适不适合我现在的资源和阶段？我能不能玩得转。
