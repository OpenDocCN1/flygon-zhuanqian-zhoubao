# ('00 后大厂产品 AI 创业复盘(下)', (2, 21))

一位00后前大厂产品经理兼业余程序员Mose，在2023年下半年又搞了不少新动作。这次他的创业复盘直指四个方向：toC、toB、卖课、出海。回顾上半年，他分享的创业经历意外获得亦仁大佬的认可，还被不少朋友点赞转发。这回来聊下半年，算是给全年画个句号，也希望给更多人一点启发。

他最亮眼的战绩，是参加了生财有术的第一期AI工具航海。在教练的指点下，两个月就打通了商业闭环，既拿到了利润，也沉淀下稳定的客户群。到了第二期航海启动前，他已经被选为辅助教练。这速度，确实让不少同龄人羡慕。

当然，评论区也很热闹。有人反映链接无权限，作者很快调整了开放。还有朋友好奇他出海是不是仍和之前的小团队同行，Mose直言已经换了好几拨人。大家感叹“后生可畏”，也调侃“世界是个巨大的草台班子”，但能在变数中不断折腾，本身就是一种本事。
