# 线下教培机构招生，如何用群裂变撬动区域流量？

做教培的朋友都知道，招生最难的不是课程，而是流量。

线下机构普遍存在两个痛点：一是流量把控太弱，二是首次转化率偏低。但好在只要把学生转化进来，后续续费基本挺稳。所以“流量+首次转化”就是第三方机构的价值所在。授人以鱼不如授人以渔，教培人不仅要招到生，更要学会自己找生源。今天分享的这套群裂变区域爆破打法，来自一场双十二活动的真实复盘，特别适合教培机构和实体店参考。

![](img/2a279ef162634e3c94e06d1ed088a94a.png)

先看结果：引流环节几乎没赚钱，利润全靠后续转化。除去激励成本和链接内礼品，校区最后赚了2.3W+。![](img/8aafcf593198854dd338f6ea72065e47.png)近一年的总营收如下：![](img/a1e737b104904c1a7f27d81825f1f0f5.png)

这套打法分三个阶段：引流前准备、第一拨裂变、第二拨裂变。

先说校区背景。这家机构成立6年多，两个校区近260个学员。周边2公里内，同科目机构7家，其他教培对手18家。疫情后家长消费普遍收紧，再加上周边各种买课送礼活动早就把家长炼成了“老油条”，对礼品套路已经有点免疫了。

所以引流前必须做好三件事：第一，家长消费低迷，就要靠气氛点燃冲动，用从众心理刺激下单；第二，旧裂变方案没人买账，就直接换新玩法，先让一小部分A类家长掏钱，再用红包和裂变方案拿下B类、C类客户；第三，锁准3-8岁年龄段，用价格便宜的绘本和名著做诱饵。最终策略定为：群裂变+免单。

校方同步要做两个准备：一是打印老生名单，二是打印潜在资源名单，包括所有地推、到访、陌电、没报过正课的新生和活动生。这些资源提前分给参与活动的老师，可以按师生粘性分，也可以平均分。

第一波执行，核心就是混进群、多进群。管理者一定要明白：制度立起来，信任才有基础；监督跟到位，放权才不会失控。员工不会因为你期待就主动做到，你盯到哪他们才做到哪。所以每天必须上报进群数据，包含日期、姓名、今日新增群数、今日未进群数、累计进群总数。

混群的方向要按需求划分。孩子需求类：母婴店、服装店、儿童摄影、瑜伽馆、培训班；宝妈需求类：微商群、宝妈群、美容美发、车友群、健身群；生活需求类：水果店、超市、卖菜、团购、优惠、租房、家委会、业主、二手置换。有些群进不去，可以请家长帮忙发消息拉一把。

要群的渠道也有一些技巧。让家长拉你进周边商家群、买菜群；在朋友圈透露需求，比如想做个美甲、换个发型，请家长推荐商家；或者去店里买东西时，问商家能不能微信下单、拉进群；再直接一点，朋友圈发“有没有本地群可以互拉”。别怕被拒绝，先开口才有故事。

老生要群话术可以这样说：“xx妈妈，总部有任务要检查我们手机里的群数量，你手上有宝妈群、水果群或者团购群吗？拉我一下，放心，我不会乱发广告，就偶尔发个红包，告诉她们想学xx可以找我。”

线下要群，碰到新开的超市就问有没有福利群能发每日特价；碰到隔壁店就说“我是隔壁xx机构的老师，你手机里有没有本地群？咱们互相分享资源共享一下”，这样对方戒备心会低很多。

进群流程要注意：把手机上所有本地好友群发一遍，别只发200人；进群后修改备注，比如“3.25.1买菜群”，方便识别；优先进优质群；当天最多进30个群，超过就第二天再进；每次间隔3分钟，避免封号；互助拉群，多多益善。

接下来就是发圈、建群。宣传语要短平快：无需消费，进群就有；本地宝妈，登记领取；暖春回馈，感恩有你；精选绘本任选2本。让家长先发朋友圈，然后拉进群，告诉她“领绘本的人太多，群里会公布领取时间，怕遗漏你”。

竞猜期间依旧要继续催进群：群发、私聊、朋友圈全部铺开。先问“宝妈，你领绘本了吗”，再补“700款绘本，想领回复1”。家长回复后，立刻发海报、文案和群二维码。同时提醒大家集赞后把朋友圈截图发到群里，登记老师要及时跟进。

小技巧：每段文字末尾配个可爱表情，传递温度；同样内容的朋友圈，隔40分钟删掉旧的再发一次。家长加好友登记时，回复“收到啦宝妈，您填写一下信息，为您备注登记”，然后收集宝宝姓名、出生年月、妈妈电话。回复“6”的家长，到校再送一份小礼物，顺便完成客户筛选。晚上9点再发朋友圈：“感谢宝妈信任，绘本持续赠送ing，想领回复1。”

整个流程要形成闭环：混群->进群->红包->登记->集赞->裂变，一直循环。提醒的时候可以调侃着来，比如“一定要邀请宝妈啊，多多宣传！中国人不骗中国人。”

作为管理者，还要盯紧过程。如果今天群人数没突破400，说明有环节没落实。检查朋友圈有没有按时更新、私聊有没有全跑完、群公告和红包雨有没有跟上、集赞截屏的私包奖励有没有发到位。同时，把手上的群资源继续放大，把“全城免费送绘本，最多领20本，想一起薅老板羊毛的进群”这句话和群二维码甩到你混的所有群里。

最后是售卖课包。群内总人数至少500人，再公开课程礼包。原玩法客单价在200到300元之间，如果想降低操作难度，可以先卖19.9。先丢预告：“课程加油包来啦，19.9元猜次数，猜对有奖。”正确答案是3次或6课时。下午3点公布竞猜，然后私聊老会员和意向家长，让他们抢先买，当团长。晚上8点公布答案后，用校区号发已报名家长的链接和参团步骤，制造热度。

### 拼团的具体玩法

在群里把拼团秘诀讲明白：

第一步，转发到小区群、机构家长群这些本地群，里面全是有同龄孩子的人，最容易成团；
第二步，发朋友圈，这事看家长的人脉圈，效果因人而异；
第三步，直接私信或者电话联系身边有同龄孩子的家长，速度最快；
第四步，用群发助手一次发200人，曝光量很大，成团轻松。

这四步照着做，没有凑不成的团！

家长每完成一个动作，一定要盯着他们把截图发回群里。这么做有两个好处：一是让其他家长看到后跟着做，二是方便你及时发奖励。奖励也不用大，2.88、3.66、5.12的专属红包就很能调动情绪。

### 最后单量冲刺

到了活动收尾阶段，要做两件事：

1. 在群里告诉大家，现在能领的是什么礼品，想拿到下一档礼品，还需要完成什么动作。
2. 安排老师们轮番给后台留下的意向家长打电话，做最后一轮攻坚。

电话里围绕四个方向：一是价格政策有优惠；二是课程本身价值高；三是名额稀缺、错过就没了；四是告诉老师有任务量，请家长帮个忙，顺手发圈、发群或私信给好友。

### 总结与几点大实话

就我观察，2023年不少教培机构都过得很难，疫情刚结束，好不容易把之前欠家长的课补完，流感又来了。但不管多难，24年一定要死磕招生。随着人口红利慢慢消退，教育只会越来越不好做。守住自己那一亩三分地，把机构做精做细，才有出路。关于流量，我有几点想法分享：

1. 社群、地推这些和家长沟通的方式要坚持做。我这些年见过太多机构，因为沟通不到位，续费率低得可怜。光想着成交，不重视平时的维护，这是大忌。成交很重要，但维护是地基。

2. 如果有全职老师，可以考虑把她们打造成区域明星老师。明星老师对聚拢周边流量非常有效。但培养之前一定签好协议，要么给股权，要么做成合伙人，否则很容易出问题。

3. 学习不能停。抖音本地直播、视频号直播，凡是跟区域相关的，都要敢去试。不用做第一个吃螃蟹的人，但一定要做敢迈第一步的勇士。

4. 如果按上面这套流程实操，对教培机构来说完全够用。除了细节，还要建立一套有效的奖惩PK机制，监督到位，有奖有罚。

5. 员工执行的时候，最好是“复制粘贴式”操作，别让他们问为什么，直接照着做，越简单越好。有些人能力没多少，拒绝操作的花样倒是一套一套的。正是这些拒绝，把机构一步步拖垮。

6. 一旦做活动，全校区就要像打仗一样全力以赴。拖后腿的当场点名罚，干得好的加倍奖励。不为别的，就为把事情做成。
