# 视频号“乡村夜色”治愈系短视频：从0到1制作与变现全流程拆解

> 一个人静下来的时候，刷到那种农村夜晚的视频，明明画面里只有月光、老屋、树影，但配上那几首熟悉的旋律，瞬间就把人拽回了二三十年前。

你好呀，我是黄岛主。

今天想把这套“农村夜晚治愈系怀旧短视频”的完整玩法和你聊透。这类内容说白了没什么花哨镜头，也没有跌宕剧情，可偏偏就是能让 70 后、80 后、90 后翻出手机里的旧时光——嘴上不承认，心里却已经开始怀念了。画面本身素得不行，但BGM一响，那种说不出道不明的情绪就上来了，氛围感直接拉满。不瞒你说，我自己刷完是这样，估计你也是。

当然，想做白天版本的也完全没问题，关键是剪辑时自定义素材方向就行。
