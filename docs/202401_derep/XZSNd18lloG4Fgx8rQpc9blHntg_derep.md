# 12月RPA航海结束前，我用UiBot做出了一个美食地图探测机

12月RPA航海临近尾声时，我用UiBot捣鼓出了一台“城市美食探测机”。这玩意儿到底能干啥？简单说，你告诉它一个城市，它就能帮你挖出当地最火的餐厅榜单，还能结合真实顾客的评价，帮你自动生成小红书或大众点评风格的推荐文案。无论是自己出门前做美食攻略，还是做内容创作，它都能省下大把时间。

先交代下背景。我叫tide，12月刚加入赚钱，也是在这才第一次听说RPA。平时工作里总有大量重复性、需要手动批量操作的任务，了解RPA后我发现它恰好能搞定这类标准、可描述、重复的流程，于是果断报名了RPA航海。跟着航海的课程一步步实操，我算是真正入了RPA的门，越用越觉得这工具高效又稳定，真是相见恨晚。

这篇文章我会把美食机器人的实现过程掰开揉碎地讲，手把手教你怎么用UiBot把它做出来，文末还会附上源码供你直接拿走用。咱们一起开启RPA提效之旅吧。

# 一、需求和功能说明

## 1.1 背景需求

- 从我的本职工作看，我是做餐饮营销策划运营的，常常要盯各个城市热门餐厅的核心数据，还要分析顾客评价内容。这活儿标准、重复、逻辑也不算复杂，基本都在RPA航海教过的范围内，所以我就想让它自动化，让机器人不知疲倦地替我干活。
- 从普通用户角度看，比如你打算去一座新城市，免不了要纠结去哪里打卡。要是有个机器人，你只需给个关键词，它立刻帮你列出一堆热门美食，还带品类、人均、推荐菜、评分等信息，选起来就快多了。
- 从项目角度看，小红书上做旅游内容，美食推荐是少不了的环节。推荐哪些店、从什么维度推荐、文案怎么写，其实都可以靠机器人一次性抓出结果，作为创作的原始素材。

## 1.2 这机器人能帮我做什么

按身份来说：
- 美食爱好者：快速筛出各地人气餐厅，帮你决定去哪家拔草。
- 大众点评玩家：评价内容和笔记灵感都有了，创作效率直接拉满。
- 餐饮营销策划：观察同行、分析市场行情，再也不用手动扒数据。
- 小红书博主（美食/旅游方向）：创作方向有了，直接素材库也有了。

按项目来说：
- 小红书旅游：一键罗列城市热门餐厅信息，还能生成推荐文案。
- 公众号爆文：想写《全国各地美食人气指南》系列？素材源源不断。
- 点评达人矩阵：快速批量产出笔记内容，更快成长、更快变现。

### 2.4.4 抓取各商家的好评内容

模块逐行说明如下：

![](img/d376eb27f77275a228f85daee5ebca61.png)

①筛选好评，进入商家的好评列表。

![](img/2550a10daf73d56a32e8f13674cf8055.png)

②循环点击“展开评价”元素。

![](img/a2c37a96f815a14233dc0ab84949bf3d.png)

![](img/906ab08d82ee62dbf4438fd1f52658f2.png)

这里为什么要点击“展开评价”？为什么要循环？为什么还要用“尝试执行”模块？为什么要跳出循环？

- 不展开的话，抓到的评价只有前半截，不是完整内容，所以必须展开。
- 每页默认展示15条评价，所以最多可能出现15个“展开评价”按钮。从0到14正好15个，写元素特征值时用了变量i，从0开始，所以需要循环。
- 你可能会想，每页都展示15条，那是不是一定会有15个“展开评价”按钮？其实不是。有些评价本身很短，根本没有“展开”按钮。所以这里要加一个尝试执行模块：本来循环最多执行15次，但实际可能只有14个、13个按钮（反正最多15个）。那就尝试执行15次，一旦点不到这个元素，说明该点的都点完了。如果继续往下循环，机器人会报错说找不到元素。那就直接捕获错误——既然都点完了，后面不用再执行了，跳出循环就好。

这块有点绕，但这是我设计时踩过的最大的坑，花了好久才排查出来，所以啰嗦几句。

# 三、后期优化方向

## 3.1 让AI生成的内容更完善

我之前完全没接触过ChatGPT，所以选择了讯飞星火。提示词也没做精细化设计，导致AI生成的总结效果不够理想。后面可以慢慢优化提示词，让AI产出更贴合需求的内容。想学ChatGPT的话，可以看12月ChatGPT航海手册。

## 3.2 让机器人更自动化

在设计的时候，比如要取排名前多少的商家、每家取多少条评价、对多少家做AI分析，这些数值都是通过循环次数写死的。其实完全可以把它们放进参数表里，提前在Excel里配好相关参数，机器人就能更灵活地按需运行了。

你有没有设想过：只要设定好规则，机器人就能帮你抓取全城排名靠前的商家，统计每家店的评价内容数量，甚至对整体口碑做一轮AI分析？更妙的是，同一个地方、同一类菜系，它还能根据每个人的不同偏好，排出不一样的推荐顺序。至于评价数量不够用怎么办？这种小麻烦，自然也是设计流程时需要提前想清楚的细节。

这种能力放到小红书旅游赛道上，堪称“内容创作加速器”。你可以用它生成“城市美食地图”“特种兵一日游吃喝指南”，或者按用户场景来推荐：适合表白的餐厅、适合带外地朋友体验的本地菜馆、本地人私藏的某某菜系榜单……机器人的玩法没有天花板，所有功能都能随需求不断更新升级。说到底，凡是有逻辑、重复性的流程，都可以丢给它——不用休息，不闹情绪，安安静静帮你把活干了，真香。

接下来想聊聊RPA新手的那些“心态关”。

很多新人一打开航海手册就头大，内容太多，静不下心，还忍不住跟别人比较进度。其实作为零基础，最好的姿态就是像我当初那样，从头开始，边读边实操。别跳着看，知识是环环相扣的。手册里藏着99%的答案。你只需要关注眼前这一步，不要还没学会输出调试信息，就担心抓取机器人会不会翻车，焦虑解决不了问题，动手才能。

还有人复刻机器人，结果总是“差一点”。如果急着追进度，可以先把教练配好的机器人导入，但你要有心理准备：元素找不到、表格参数填错、删除数据方式不对……都是常见的坑。更建议的做法是：100%复刻手册里的每个机器人——对着手册，一个模块一个模块自己配，严格按步骤来。比如功能模块的“选择、摆放、设置”，目标元素标记的“221”法则。另外，最好把每个机器人的手动操作过程和流程图都亲手写一遍、画一遍，这样理解才能深入。

至于“同一坑里反复摔”，别急着当“十万个为什么”。RPA偏技术，你的操作环境、提问时的截图不完整，都可能让教练来回问细节，效率反而低。记住：先查手册，再搜群聊关键词，大概率能自己搞定。实在不行，重新过一遍自己的操作，再精准提问，这样教练也容易帮你定位问题。

说到举一反三，核心是建立流程思维。看教练画好的流程图和自己画一遍，效果完全不同。遇到复杂的模块（比如try、数组遍历），可以单独开一个测试流程来验证它的运行逻辑。只有弄懂每个模块的“脾气”，你才算真正掌握了它。这时候再去做大型机器人，就会恍然大悟：看起来眼花缭乱的模块，不过是老朋友换了排列组合。

大型机器人难度暴涨，怎么破？先接受一个观点：流程逻辑永远比具体实现技术重要。别被一堆模块吓住，其实它们都是纸老虎。你只要把流程捋顺，然后照着逻辑去摆放模块，难度就降了一大半。遇到新模块，记笔记，专门测试，搞清楚它的使用场景和运行逻辑。不要只追求“机器人能跑通”，那是“道”；要追求“每一个模块我都懂”，这才是“术”。积累多了，任何新需求都只是重新理一遍流程，模块组装已经难不倒你。
