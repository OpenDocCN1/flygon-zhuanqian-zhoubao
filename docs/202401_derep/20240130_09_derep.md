# 赶在12月RPA航海收官前，我用UiBot造了一台“美食地图探测机”

我是tide，一个12月才加入赚钱的新圈友。RPA这个词，就是我在赚钱第一次听到的。看到有RPA航海活动后，我抱着试试看的心态报了名，没想到在结束之前，我真用UiBot做出了一个挺有意思的小机器人——我管它叫“美食地图探测机”。

它的能力很直白：你输入一座城市，它就能为你生成一份当地热门餐厅的排行榜。去外地想吃点好的？先让它扫一轮，哪几家值得打卡、哪些是本地人心头好，心里马上有数。更让我喜欢的是，它还能抓取真实的消费者点评，然后通过AI帮你提炼成一版可以直接参考的文案角度，无论是发小红书还是写大众点评，都省力不少。

为什么我会碰RPA？说来也简单：日常工作中，我常被大量重复性的手动操作拖住。后来了解RPA，才发现它恰好是这类“流程明确、说得清楚、反复执行”的任务的天生克星。于是跟着航海内容一步步实操，越练越顺手，高效又稳定，真是相见恨晚。

接下来的篇幅，我会把这个机器人的功能实现彻底拆解，手把手带大家用UiBot从零做出一台同款，源码也会一并附上，拿来就能用。咱们这就开启RPA提效之旅。

当然，这个机器人能落地，多亏了几位贵人。最想感谢的是航海教练，没有她精准的思路指引、毫无保留的帮助，以及每次日志里的暖心鼓励，我可能早就打退堂鼓了，更别提让机器人落地、把文章写出来。也要谢谢航海领队，他鼓励我大胆分享，还帮我牵线搭桥，这才有了这次输出。最后是手册制作团队和直播教练，虽然没直接接触，但教程细致入微，让我这个零基础的新手也能轻松入门。
