# 把自己变得没那么重要，其实不是真的不重要

晚上刚踏进家门，就被家属劈头问了一句：你今天写的那段话，是不是没过脑子？你让员工们看见，会怎么想？

我愣了一下，随即笑着解释：你可能误会了。我不是让大家把自己看轻，而是希望大家看到赚钱里更大的机会和空间。每个人都该主动去培养一个能接替自己的副手，把自己从日常琐碎中一点点释放出来。只有手头的事有人接，你才有空去接更大的事，创造更大的价值，也才能赚到更丰厚的回报。

那“让自己变得没那么重要”这句话，到底该怎么理解？

它并不是让你真的变得无关紧要，而是让你从一个具体的业务环节里退出来。原来的子系统可能不再依赖你，但在更高层级的系统中，你会被需要得更厉害。因为能培养出副手的人，能把自己从流程中抽身出来的人，背后一定站着管理能力、产品能力、流程化能力、系统设计能力，以及一个人的格局和视野。这些能力比具体做事的能力稀缺得多，也值钱得多。聪明的老板，一定愿意为这样的能力花更多的钱。

所以，别把“不那么重要”看成自我贬低。那不过是让位给更合适的人，好让自己腾出手去够更高的目标。这不是退让，是升级；不是可有可无，是换了一个不可替代的位置。
