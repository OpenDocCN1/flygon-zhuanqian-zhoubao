# 聪明，从来就不是一种固定的模子，而是你要亲手去挖出来的

我们总在谈聪明，却很少有人停下来问一句：我的聪明，究竟长什么样？

有人擅长算账，有人擅长讲故事，有人能在混乱里快速抓住关键点，有人能在细节里反复打磨到极致。这些看似迥异的能力，本质上都是个体独有的解题方式。真正的高效，不在于去复制别人的聪明，而在于把自己与生俱来的优势，系统化、武器化。
