# 再读俞敏洪的书，又有了新的体会



## 继续翻阅老俞的笔记有感

作者： 龙哥

日期：2023-12-30

又拿起老俞的书细读了一遍。

1. 创业刚起步阶段，老俞选择亲手备课几乎全覆盖，核心目的就是防止被某个老师卡住脖子。当时公司赚的钱非常有限，一旦出现一个不可替代的人，就很容易被要求提高分成比例，那样就会抽走本该用于再投入的资金。

这一点我非常认同，在公司最早期，能上手哪块就上手哪块，尤其是流量和产品这两个核心环节，要亲眼看清运转逻辑。只有自己真正吃透业务，才能识别出真正能干的人，也才能避免被任何一位员工掣肘，保持主导权在自己手里。

2. 老俞提到，足够聪明的老板，应该主动为优秀员工设计更好的激励。

我猜老俞在这件事上没少吃亏，我自己也踩过不少坑。这句话对我这样以及对很多创业者来说，都是一个提醒。

在没有出现明显危机前，大多数老板都不会去动激励这块，觉得眼前更急的事一大堆，先应付过去再说。像这次董宇辉事件的发酵，其实就是过去的机制没跟上。

但经历下来我越来越清楚，对老板而言，一个合理有效的激励体系，重要到不能再重要。如果在这上面多花心思，业务和团队能得到巨大的正面推动。

晴天修屋顶这句话一直在提醒我自己和同行，这件事考验的是格局和眼光。

而激励方案的搭建，对于绝大多数老板都是全新领域，学问极多。设计得好，大家皆大欢喜；设计不好，甚至能把整个业务拖垮。

我现在的想法是，与其自己摸索，倒不如请专业的同事长期盯这件事，再搭配外部顾问解决关键难题，效率会高很多。

3. 老俞说过：“碰到一件你自己搞不定的事，就要同时找几个人一起做。除非你真的相信，已经给对方的利益足够大，能让他一辈子都跟你走。当然这种事不太现实，因为业务做大后，各岗位之间的利益平衡就会变得复杂。”

换句话说，做成一件事的前提是人才布局到位，而且要让人才帮你把事业做大，而不是反过来把事业架空，要让大家共赢。这是我在创业初期最深的体悟。

同时站在员工的角度想，如果你恰好成了老板某个模块的定海神针，老板离不开你，千万别频繁在老板面前强调你的不可替代。那老板心里基本已经在找人拆分你的独特性了。

做了很多年管理者，我最看重什么样的人？

他清楚自己的价值，也清楚老板清楚这个价值，他能感知到老板的顾虑，于是主动跟老板沟通，如何把他手里的核心能力做备份，如何培养更多人来承接。

这种表面上看像削弱自己位置的做法，其实是站在老板的高度在思考。放长远看，你要么很快成为合伙人，要么自己就是老板。

放弃短期的小利益，才能换来长期的大回报；舍弃局部系统的好处，才能赢得整体系统的成功。

4. 新东方刚开始时，俞敏洪定下了一条铁律：没有名师就不开班。

名师的成长需要时间，这就导致班级数量受限，后来一开课往往瞬间爆满。

就是这个无意的选择，让他领悟到品牌传播的一个关键逻辑：饥饿营销加顶级产品。

品牌成长不是大面积铺开，而是先在一个点上集中突破，比全面开花更容易。通过控制供给，把一个点做到极致，占领用户心智，再从这个高点往外延伸，这或许就是品牌成功的路径。

道理谁都懂，做起来很难。眼前的钱，收不收？想把所有能收的钱都立刻收完，很可能就成不了真正的品牌。

还有一个值得反复问自己的问题：你的生意里，你到底在控制哪一块核心供给？想明白了这个，商业壁垒也就想明白了。
