# 一、这套工具能干什么

整体定位是一个一站式视频工作台，功能会不断扩充。目前已规划的核心方向主要有三块：

**1、智能分割方向**
不再靠手动一点点抠时间轴。工具提供三种分割思路：
A. 模拟在剪映端手工切片的导出流程，自动把预览轴上的片段一个个导出出来；
B. 直接读取剪映里已经做好的智能分割结果，一键把原始视频按同样的节点切分；
C. 完全脱离剪映，根据你自定义的规则，让AI自行对视频进行智能拆分。

**2、混剪组装方向**
A. 拿已有的切片素材做随机混剪，再自由搭配封面、片头、片尾等固定模板片段，让每条视频都有新鲜感；
B. 未来还会接入更多元的混剪逻辑，满足不同渠道的投放需求。

**3、批量处理方向**
覆盖从抽帧到特效的全流程：自动抽帧抓图、批量加水印或贴纸、自动嵌入动态小视频、统一特效风格、智能转场等等。简单说就是能把原来需要人工逐条操作的细节，全自动化跑完。

# 二、怎么上手用

**1、剪映端切片模拟人工导出**
上手前注意这几个细节：
1. 先打开预览轴
2. 如果时间轴上有字幕，记得先冻结字幕，避免导出错位
3. 确认导出快捷键仍是 Ctrl + E
4. 把导出窗口元素捕捉调成自动模式，提前设定好文件名前缀和后缀格式
5. 时间线适当放大，避免切片排太密点不到
6. 点下开始任务后，保持剪映窗口处于激活状态，让程序能正常捕捉

**2、按剪映智能分割结果一键切割源视频**
操作要点如下：
1. 指定根目录，这个目录要和剪映里已切割好的视频文件夹一一对应，自动匹配才会生效
2. 选择时长精准度，等级1最快但精度稍低，等级3最准但耗时更长，按需求取舍
3. 可以指定最终保存路径，不填的话默认会放在根目录同级的文件夹下
4. 时间线放大一点，有助于提升最终切片的准确度
5. 点击开始任务后耐心等待，完成后即可获得按剪映节点切分的原始片段
