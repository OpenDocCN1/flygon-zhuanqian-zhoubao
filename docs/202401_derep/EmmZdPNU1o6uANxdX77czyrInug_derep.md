# 小白从0到1跑通小红书电商渠道，4个月卖了1000斤福州特产，变现5W的复盘

这年头，普通人想搞点副业，最怕的不是不努力，而是方向不对，努力白费。今天想跟你分享一个真实跑通的案例：一个福州姑娘，没有网红脸，不懂爆款套路，就靠卖家乡特产——福州鱼丸，4个多月卖了1000多斤，变现5万多。整个过程没什么惊天动地的爆文，全靠笨办法和细节打磨，希望能给想尝试自媒体带货的你一点启发。

先说说这位姑娘的背景吧，她本职是个深耕零售和生鲜行业的产品经理，平时跟ERP、供应链打交道，副业则一头扎进了AI+小红书的赛道。她是从去年9月开始干的，到2月底累计卖出了3000多斤特产。她反复强调，这个项目对新手特别友好，因为大多数新人卡在“定位”上，总觉得自己没什么拿得出手的。但家乡特产不一样——每个人家里都有点好东西吧？人设天然可信，产品也自带故事和流量。哪怕你完全没网感，只要肯把过程跑一遍，收获绝对比看一百篇方法论强。

先来点实际的成绩单。9月初她发第一篇笔记，5天引流到第一个用户，第8天成交第一单。没有爆款加持，单月营业额破万用了不到2个月，第四个月直接冲到2万多。从9月到11月，一个号引流一个号开店，总共引流240人，成交110人，加上店铺和私下转账，总销售额2.6万。她发了150个笔记，基本没有爆款，就是把产品反复展示，硬生生跑通了0到1。到了12月，引流号被限流了，但店铺号还在收钱，加起来近10万，私域复购也稳稳的。

那为啥选了福州鱼丸呢？灵感来自一个卖蟹老板的案例。顺着思路，她想到福州最出名的特产就是鱼丸，而且正好有个靠谱货源——同事的哥哥每年送礼买鱼丸都要花3万块。市场调研也很关键：淘宝上月销1000+的单品很多，说明需求没问题；抖音销量更大，但基本靠直播；小红书量最小，说明大家还没进场，竞争少。她判断这玩意儿能在网上卖，但在抖音得直播，小红书反而是机会。再加上本地人身份，人设天然成立，产品本身有流量，还不用跟工业化产品拼价格，于是决定开干。

真正开始做，第一步是账号装修。昵称、头像、简介、背景图、产品名片笔记，全都围绕“可信的福州本地人”来打造。不需要你多专业，甚至可以说“帮村里不会上网的叔叔阿姨卖点好东西”，真诚就是必杀技。笔记选题呢？她没那些花里胡哨的所谓“爆款方法”，核心就是吃SEO搜索流量。小红书上卖鱼丸的人少，那就把淘宝货架逻辑搬过来：用户搜什么，你就做什么内容。选词别贪大，“福州鱼丸”太泛了，要找具体成交词，比如“福州鱼丸邮寄”。埋词要做到标题、图片、正文都出现，但别堆砌，要站在用户角度告诉你怎么选。

具体怎么做笔记？她特别朴素：从顾客下单逻辑倒推。展示支持邮寄、顺丰发货快、原产地直发、客户评价好、手工制作健康——一张图一个卖点。这篇笔记直接躺赚，搜索流量源源不断。除了自己实拍，她还用“下厨房+”小程序找灵感，等做起来后顾客返图就够用了。淘宝的评价和提问区也是宝库，顾客关心的问题都具有普遍性，拿来做选题天然吸引人。还有微信聊天好评截图，转化率高得离谱，因为买家秀永远比卖家秀可信。另外，卖鱼丸的可以看看卖牛肉丸、腊肠甚至苹果的对标，模仿人家的标题和句式，别抄内容就行。

变现上她走了两条路。先做引流私域，推荐建小红书群，笔记关联群聊，用小号在群里发微信号，这样能持续触达。小号引流也行，简介@小号，评论区也@小号。引流没有100%安全，要多看别人怎么玩，把自己当成猎物去找钩子。用户加到微信后，门面功夫要做足：头像和小红书一致，昵称尽量一致，背景图放产品图加简介，朋友圈置顶产品介绍和好评。加好友后主动打招呼，先别急着报价，问问对方是不是想尝尝。产品价格要设计三类：成交款、主打款、利润款。比如新手全家桶145元，让第一次吃的别买太多；5包鱼丸组合199元，给回头客；鱼饺35、鱼面25，顺手加购，为复购打开空间。节日促销也要试，加过来很久没下单的要多用朋友圈激活。

做完引流又开店，是因为私域聊天费时，还容易被限流。店铺冷启动有技巧：让私域用户去店铺下单，收货后引导好评。甚至可以小号下单或朋友帮忙，收货信息用微信顾客的真实信息，这样更真实。换位思考，你会买一个0成交0评价、客单价一百多的食物吗？店铺起来后还有流量补贴，商品卡也能成交，复利更大。小红书群也要好好做，笔记除了挂链接，再挂群入口，有流量赠送。私信组件和客服欢迎词也别浪费，能直接促进转化。

避坑方面，她踩过不少坑。账号限流是最头疼的，两个号都被限过，从警告、3天、7天到14天，一定要多做几个号，心态上做好准备。开店后客服考核很重要，小红书会看3分钟回复率，不达标就限流，所以常见问题要设置自动回复。发错货或包装破损偶有发生，售后要超预期，把危机变信任，赔付是一次性的，生意是长久的。最后就是爆款焦虑，她也天天纠结拍啥发啥，每天逼自己更新，看别人好的就学，小眼睛不过百也坚持，日积月累接住了不少搜索流量。虽然爆款还没来，但做出了受信任的笔记，说不定哪天就爆了呢。

对了，本地流量这一块她还没写完，但整个思路已经够清晰了。从选品到流量到转化，每一步都是普通小白能跟下来的。看完这个故事，别光收藏，动起来，下一个跑通的可能就是你。

刚开始做那会儿，我盯着后台流量看，发现大头全在本地。心里第一反应是：本地人哪会网购鱼丸？何况福州鱼丸这名字就写着“福州”，流量自然绕着本地转。当时我还跑去跟薯队长争了半天。结果后来慢慢发现，本地用户不但会下单，而且不少人一买就是好几包，专门用来送人。

本地人最精，大品牌流水线鱼丸，他们反而不怎么信；他们认的是能从头道工序做到成品、真正源头上的手工鱼丸。

所以好多事儿，想再多都不如真下场干一轮；只有亲手做过了，才算真正懂。光靠想象，真的会跑偏。

# 五、写在最后

从9月4号把鱼丸定下来，到12月31号，整整卖出了1000斤，覆盖27个省。写这段不是为了炫，就是想给那些总觉得没资源、没方向的朋友打打气，顺便分享一条可以复制的思路。（1月又发了一单到新疆，现在已经是28个省/直辖市/自治区了。）
