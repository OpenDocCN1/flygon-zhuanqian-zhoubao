# ('小红书上教人赚钱的博主都在玩些什么？', (2, 20))

最近在龙哥盟看到一篇挺有意思的帖子，作者叫代一，分享的是小红书上那些教人搞钱的博主，背后到底在玩什么套路。

这位代一可不是随便聊聊。他自己在知识付费和成人教育这行摸爬滚打了好多年，之前还在前公司专门负责小红书渠道的运营，管流量、管转化，最猛的时候做到过一天往私域引流500多人，单月引流破万，变现超过30万。所以他对这个平台的玩法，算得上是门儿清。

这篇文章不是只盯着某一个或几个账号拆，而是把小红书上“赚钱/副业/创业粉”这个赛道拎出来，结合他自己的实操经验，做了一次整体性的梳理和分析。目的是让圈里的朋友，也包括他自己，能对这个赛道有个更全面的认知。

因为内容量不小，为了阅读体验，全文他放到了飞书文档里，想看完整版的直接点链接就行。
