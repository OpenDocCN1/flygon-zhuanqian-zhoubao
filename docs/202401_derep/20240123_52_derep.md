# ('假发行业科普 B2B', (2, 12))

大家好，眼瞅着马上要过年了。关于假发这个老本行，我琢磨了一年，今天终于想写点实在的。

在跨境圈里，假发常被称为“黑色黄金”，甚至被看作“跨境电商的神仙品类”。不过这个赛道格外排外，供应链门槛又高，市面上真能讲透的文章少得可怜。它的核心从来不是流量，而是供应链——谁能把这条链上的环节摸清，谁就掌握了这个行业的大部分密码。

说说我自己的经历吧。以前做假发出海时，我从零起步建了新站，第一个月就收到3000多个询盘，广告投入算下来还不到9000美元。其中有一位客户，一年累计的订单金额接近1亿人民币。这个数字，可能就是对供应链价值最好的佐证。

具体的细节没法在这里全部展开，我已经把完整版整理到飞书文档里了，有兴趣的圈友可以直接点链接查看。

顺便回答一下大家常问的问题：为什么我后来没有再接着做？其实早先是给公司打工，等到真要考虑自己创业时，我意识到这行对现金流要求太高——供应链采购全部现金交易，没有账期，而且库存占用的资金比例极大。对新人来说，很容易被资金链拖垮，所以我选择了绕道。另外，关于退货率，B2B确实很低，但B2C会偏高一些，基本上和服装行业差不多。

如果你也对假发行业感兴趣，欢迎随时找我聊聊。
