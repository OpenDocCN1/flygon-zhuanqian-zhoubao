# CSDN资源批量发布自动化机器人：完整方案与代码图解
作者：龙哥

> 原文：码农飞哥 | RPA定制

大家好，我是龙哥，在上市公司做资深软件开发，也是CSDN博客专家。平常主要研究各类RPA机器人的开发，顺带接一些毕业设计定制的活儿。

如果你经常在CSDN上逛，应该知道它有个挺特别的付费资源功能——开发者可以把源代码、文档传上去标价出售，别人付费下载。这个机制和其他博客平台不太一样，算是CSDN的一大特色。

但这里有个痛点：每传一份资源，就得手动把资源名称、介绍、标签、价格一项项填进去。

![CSDN 图片](img/a0a22323b29c7dbebca8aeaff12e8a1a.png "CSDN 图片")

手头资源少还好说，要是攒了几十个甚至上百个文件，光靠人工一个个传、一个个改，既磨时间又折腾人，效率低到没法看。这种时候，让机器人来接管这些重复劳动才是正经解法。

## 二、上手使用教程

1.  先把要传的资源文件整理好
2.  用Chrome打开CSDN的批量上传入口：  
    [`mp.csdn.net/mp_download/creation/batchUploadV2`](https://mp.csdn.net/mp_download/creation/batchUploadV2?spm=1011.2124.3001.6137)
3.  同样在Chrome里登录讯飞星火大模型：  
    [`xinghuo.xfyun.cn/`](https://xinghuo.xfyun.cn/)
4.  启动影刀RPA应用，自动批量调整价格、标签这些信息

## 三、程序运行全程拆解

![img](img/00a78e3bf41cece60e7ff6a462617cab.png "img")

整个流程大概是这个顺序：

1.  把待上传资源统一放到一个文件夹里，方便后续批量操作
2.  Chrome登录CSDN，打开批量上传页面
3.  Chrome里再登录讯飞星火大模型
4.  先批量上传资源，等文件全部传完
5.  运行影刀RPA机器人
6.  机器人会按顺序逐个完善资源描述，改完一个发布一个

## 四、机器人代码解读

### 1、完整代码展示

![image-20240520092937009](img/cd045392459c3b8479faa723e829741b.png "image-20240520092937009")

### 2、获取已打开的网页对象

第一步，用【获取已打开的网页对象】这个指令，直接抓取刚才打开的批量上传页面。

![image-20240520093306066](img/be52141297bd6facae0325a92bd1857b.png "image-20240520093306066")

### 3、遍历所有资源

![image-20240520093824539](img/351f2c32f37ac205830e835a4c4216fd.png "image-20240520093824539")

这里用【循环相似元素】指令，把页面上所有“编辑”按钮都循环一遍，每个按钮对应一个资源。

### 4、循环内部的任务

循环体里面就干三件事：抓到每个动态元素、拿到资源名称、根据名称配合提示词去星火生成对应的资源描述。

#### 4.1、提取元素信息

通过【获取元素信息】指令，把资源名称元素的文本内容取出来，也就是类似“springboot二次元商品购物商城.zip”这样的文件名，存到`web_element_attribute`变量里。

![image-20240520124706047](img/591cf746d3af035b2e6a2a36146a3a2a.png "image-20240520124706047")

![image-20240520124751300](img/5288ca2c112d93b2f2cf88a023d68bac.png "image-20240520124751300")

#### 4.2、调用星火生成资源简介

这部分借助讯飞星火大模型写资源介绍，步骤是：新建会话→输入提示词→发送→复制生成结果。

1.  **新建会话**  
    用【点击元素】指令点开星火的新建会话按钮。

![image-20240520125310364](img/f3fd1d0bd47ebd04fee3d4d2a36ca7be.png "image-20240520125310364")

2.  **填入提示词并发送**  
    在提示词输入框上使用【填写输入框】指令，把前面获取到的`web_element_attribute`变量填进去，作为提示词内容发送。

![image-20240520125918167](img/6eafad3039eb454677668441b77ed6d2.png "image-20240520125918167")
