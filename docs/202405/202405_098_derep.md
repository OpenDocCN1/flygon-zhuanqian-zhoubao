# 个人认为最适合新手小白上手的项目一定是 AI 写作
作者：龙哥

聊到新手入门该选什么方向，我见过太多人纠结半天，最后绕了一圈又一圈。但如果你问我心里最笃定的答案，那一定是：AI 写作，而且我想不出第二个能跟它并列的选择。

我是龙哥，进赚钱圈子已经一年多了。这期间我试过的项目不算少，可真正让我觉得能让一个纯新手稳稳迈出第一步、跑通从 0 到 1 全流程的，AI 写作绝对是排第一位的那个。

今年三月份，我发了一个关于 AI 写作的风向标，没想到居然中标了。那一下就让我下定决心，不再东张西望，就在这条路上往深里扎。到现在，我做 AI 写作正好满三个月，也跟大家同步一下进展：之前背着的二十万负债，这两个月已经还掉了五万，目前还剩十五万在慢慢清。真的挺感慨，要不是在赚钱里找到适合自己的方向，我可能还在原地打转。
