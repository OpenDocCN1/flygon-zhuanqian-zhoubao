# 五十岁也能靠AI代写月入五千？我妈的真实逆袭记



## 五十岁宝妈零基础入局AI代写，两个月就拿到5000+收入，怎么做到的？

我是观星，目前在B站和YouTube做内容，日常标签大家可能比较熟悉：

*   🎖️ 前特种兵
*   ⌨️ 提示词实战与定制
*   🎥 AI副业实操教学
*   💰 投入AI赛道四个月完成8万+变现

2022年底，我在互联网大厂被裁，算是被现实按在地上。那段时间我遇到了两位关键导师，林杰老师和慢慢老师。在他们带路下开始做AIP自媒体，惊人的是两个月内就做到单月2.6万的收入。

尝到甜头后我想把这股AI的推背感带给身边的人，于是我把妈妈和几个朋友引荐给了慢慢老师的AI代写训练营。说实话，妈妈之前完全是工具小白，电脑操作都磕磕绊绊。但凭借一股不服输的倔强，她硬是在两个月内做到了月入五千以上。这一结果彻底刷新了我对AI代写变现天花板的认知。

看完这篇，你大概能带走这三件事：

*   普通人在AI时代弯道超车的底气
*   从零基础到上手AI代写的实操路径
*   用副业收入实现生活上的小自由，比如天天关东煮不用心疼

其实机会永远站在准备好的人那边，真正让事情发生的是你先迈出那一步！
