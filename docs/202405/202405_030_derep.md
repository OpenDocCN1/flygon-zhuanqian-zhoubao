# 如何采集📕 APP 关键词下的全量笔记？

做📕内容，最让人头秃的环节是什么？很多人都会说：找爆款灵感。刷到那些流量高的笔记，总想拆解一下别人是怎么写的、怎么排版的。但实际操作起来，却有个挺尴尬的问题——在电脑网页端搜一个关键词，系统翻来覆去只给你显示200条笔记。这点量，想深挖某个赛道，基本不够塞牙缝。

那怎样才能把关键词下的笔记全捞出来呢？有人已经找到了一条野路子：借助开源工具，直接从📕APP端抓取数据。这个操作可以完美绕开网页端的条数上限，把特定关键词下的笔记一股脑全扒下来，不管是做对标分析还是挖掘爆款灵感，都会从容很多。

具体的操作方法，作者整理成了一份飞书文档，里面有详细的步骤和工具配置，想上手的朋友可以直接点开看看：https://ia0969wpr2.feishu.cn/docx/C4jvd3zUsotAQPxoQXRcg6apnLe

顺便说一下，评论区里也有不少讨论。有人觉得：“用网页端不是更方便吗？”作者回应说，方便是方便，但网页端一个关键词只能采集200条，而正常关键词下的笔记数，基本都超过这个量，所以还是不够用。还有人提到网页端容易出现滑块验证码，作者也分享了自己的经验：只要IP没问题，最多就是被限频，滑块倒是从没遇到过一次。

总之，想要拿到全量笔记，APP端采集确实是条值得尝试的路子。
