# 这 36 本书，建议创业的人找时间读一读 黑马精选书单
作者：龙哥

创业路上，时间从来不是用来挥霍的，读书也一样。真正聪明的创始人，不会把“读了多少本”当作炫耀资本，而是更看重“这些书能不能帮我解决眼下的问题”。最近看到一份“黑马精选书单”，里面挑了36本值得创业者抽出时间慢慢啃的作品，不多，但每一本都有它的分量。

黑马导师、创业黑马集团董事长牛文文说过一段很实在的话：创始人的学习，最终要落到企业经营落地这个终点上，一切学习都该为实战服务，为增长服务。这句话其实点破了很多人读书的误区——读得热闹不算本事，读完后能用得上、能推动业务往前走，才算没白读。

这份书单也带着同样的标准而来。它不是泛泛的畅销书堆砌，而是围绕创业者在真实经营中会遇到的难题，挑出那些能带来方法、启发和力量的经典。无论你刚起步，还是正处在瓶颈期，都能从中找到自己需要的答案。

与其漫无目的地刷书，不如跟着这份书单，一本一本慢慢读。让每一页翻过的时间，都变成公司向前一步的台阶。
