# 当负债十五亿的韩后创始人选择不跑路，他用三百多套房产买回信任

原文链接：[`www.yuque.com/for_lazy/zhoubao/xza9q7fnsumc35fa`](https://www.yuque.com/for_lazy/zhoubao/xza9q7fnsumc35fa)

判断一位创业者是否真的摆烂、最简单的标准并不是账面上的数字，而是人还在不在场。

只要他没有离场、没有把烂摊子丢给团队和债权人，而是站出来扛、继续顶着压力去清偿，就意味着这场危局仍有翻盘的可能。

韩后创始人最近的一次深度访谈，核心就在于此。为了填补高达十五亿元的债务缺口，他变卖了手上超过三百套房产，用个人资产为企业续命。

这份选择，比任何豪言壮语都更具分量。
