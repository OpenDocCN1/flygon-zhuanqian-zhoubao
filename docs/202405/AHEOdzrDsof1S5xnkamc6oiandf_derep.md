# 项目核心：热点资讯类PPT

## 只要地球还在，热点就不会断

这个方向的灵感来自我原本在做拼多多虚拟资料的选品。无意间看到📕上时事热点PPT卖得非常好，靠一个热点就能快速变现。目标人群主要是大学生，每月都有新鲜话题出现。我一开始直接搬到拼多多试水，单店一天净赚一百多。后来同日就有三四个原创作者找上门来理论，从此不敢再搬运。于是改成在闲鱼上买一份现成PPT，再找人二次创作去重，做成自己的版本。

![](img/f9221ee171a6f130a1144c821b30335d.png)

## 实际收益

目前主要在淘宝、拼多多、📕上架，抖音、快手负责引流。引流方式很粗暴，评论区有人问就回“去淘宝/📕搜XX PPT店下单就行”，完全不怕限流。半年下来共产出29份PPT，每月稳定收入六七千。若想冲到月入过万，就把🧣、知乎、贴吧也覆盖上。

## 花费与操作要点

我只能说这项目几乎零投入

1.每周至少更新一份PPT，到现在累计29份，多平台同步分发，月收入稳定在五六千左右，寒暑假会稍淡。

2.找闲鱼代做，17-20页30-40元，20-30页40-70元。售价方面，17-20页客单5-10元，20-30页客单10-20元。先买一份别人的成品，再花40-100元让闲鱼的PPT工作室二创去重，换模板改版式即成自己的。

3.笔记发布很简单，直接把PPT素材放上去即可。关键点别只发图文，要做成一键成片的视频笔记，能加配乐。例如《蜜雪冰城营销分析PPT》，我会把页面拼成成片，配上蜜雪冰城的经典BGM，视听体验立刻拉满。这个细节很重要。

![](img/f5c3580ade28e867ea971f6f2ea6353e.png)

操作细节的演示视频在下方

4.流量来源

做了半年后验证，笔记本身有没有播放量并不关键，真正下单的都是关键词搜索来的买家。因此PPT的数量是核心，数量越多收益越稳。这是一个可长期做的蓝海，只要世界还在运转，就能一直做。

5.利弊分析

优点：·操作简单，赛道持续蓝海
·无需主动引流，自动发货
·侵权风险低

缺点：虚拟资料易复制，要时刻留意自己的PPT是否被倒卖，一旦发现就直接投诉，动员粉丝一起施压，粉丝的威力很可怕
