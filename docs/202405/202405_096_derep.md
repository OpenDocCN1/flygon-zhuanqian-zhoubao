# 哪个最好用？国内 4 大顶尖 AI 工具实测对比

最近国产AI大模型又支棱起来了？我把4款头部大模型拉出来实测了一轮，专门用👸号爆文做仿写，结果还真有点意外。

先抛结论：如果只是写文案、做内容，国产大模型已经足够能打，甚至有些场景比GPT-4.0还顺手。我平时主力其实是GPT-4.0，但最近👸号上那篇《AI时代，不上班，也能养活自己的100个自由职业！》以及聊GPT-4o的《OpenAI又在改写历史，1分钟了解GPT-4o是个啥》，全部是国产模型生成的，几乎没改一个字，排版完就直接发了。

这轮测试的起因，是看到龙哥在航海家分享了几篇爆文，内容标题都很有感觉，加上ChatGPT-4o刚发布的热度，就想用AI仿写一波，顺便看看国货到底行不行。
