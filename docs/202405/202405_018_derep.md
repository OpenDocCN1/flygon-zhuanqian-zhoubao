# 两年视频号电商实战复盘：普通人如何找到突围方向？

两年前，我在龙哥盟里看到很多人在说视频号是一波大机会，于是没有犹豫，直接进场。

2022年初，我还是个连基本操作都不懂的纯新人，靠着搬运混剪入了门。之后试过无人直播、🛰️豆投流、自然流带货、短视频导流直播间，几乎把主流玩法摸了个遍。如今我带着一个小团队，直播间每天的场观稳定在20万以上。


评论区有位朋友问了一个很现实的问题：一年前不懂，用同一个Wi-Fi批量注册了五六个🛰️号，现在虽然严格按照一机一卡使用流量，但用这些🛰️去注册视频号，会不会带来流量惩罚？或者说，要不要直接重新注册新🛰️再开通视频号？另外，我听说🛰️老账号开通视频号会享受更好的流量，这是真的吗？

这个问题值得展开讲讲，我后续会专门出篇内容。
