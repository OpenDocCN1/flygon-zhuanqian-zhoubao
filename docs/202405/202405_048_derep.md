## Agent 是否可以创造出有商用价值的应用？

作者： 拔刀刘

日期：2024-05-24

我是龙哥。上次我分享了《不懂技术，我是如何用 Coze 手搓一个 Agent 来提升学习效率的》，反响超出预期，很多朋友私信交流。原文链接在这：

最近我又陆续搭了好几个 Agent，其中一个用个人照片一键生成学生证风格证件照的功能，已经被 20 多个人实际用过。

说实话，纯娱乐的玩法只是冰山一角。真正值得琢磨的是一些看似老旧却仍在收钱的业务：专属头像定制、标准证件照、电子写真、电商主图美化等等。过去这些都需要付费服务，现在借助 Agent 基本可以做到零成本自助完成。

下面几张图可以直观感受一下效果。

但要判断能不能做成生意，得先看清楚本质。对于高度标准化的产品型 Agent，盈利天花板其实很低。定价最终由市场供需说了算，你很难做出一个只有自己能造、别人复制不了的 Agent。一旦某个赛道开始赚钱，立刻会有大批玩家涌入，供给激增，价格就会被打下来，最后就是集体无利可图。

我更认同的看法是，Agent 当下最实在的价值在于赋能业务端做 0 代码的私域工具化。业务人员可以根据自己的实际痛点，直接把工具搭出来提效，完全不用去排技术部的期。以前这类需求都是技术最头疼的：体量小、难量化、写不进绩效，基本没人愿意接，只能靠自己硬扛工作量。AI 加持下，这类流程化的重复工作，Agent 完全可以接手。

在此之前，我解决同类问题主要靠 RPA。但坦白讲，上手门槛和可操作性，Agent 比 RPA 友好太多，效率也更高。

所以总结来说，短中期来看 Agent 的真正机会点，大概率会集中在流程化、强定制、业务化的内部场景里。这类需求里，才可能长出可持续的商业模式。

观点仅代表个人，欢迎一起讨论。
