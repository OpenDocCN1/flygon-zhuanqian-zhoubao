# 这个周末和一个厉害的朋友聊了几句，越想越有感，记下来

原文：[`www.yuque.com/for_lazy/zhoubao/uzz52u4pttawc7hn`](https://www.yuque.com/for_lazy/zhoubao/uzz52u4pttawc7hn)

最近周末碰到一位朋友，聊完之后我一直在回味，干脆把要点整理出来。

1. 真正能换钱的信息，都藏在极小众的圈子里在转。

它几乎就是现金流，能直接让你多赚或少花，而且圈子层级越高，这类信息越值钱。

但这种圈子不好进。不是你认识的人多就能混进去，通常需要长期相处、共同经历过事，还得有人带一把。就算好不容易进去了，也别以为稳了。不持续输出你独有的价值，很快就会被边缘化，别人下次聚会就不再叫你了。

我观察到一个挺实用的打法，就是主动把自己做成信息枢纽。大部分人接收信息就只到“听见”那一层，听到什么就信什么，懒得去交叉验证、做逻辑梳理、去求证。哪怕是一些很厉害的人也一样。

举个例子。几位大佬随口聊到各国签证政策的门槛和变化，说话的人可能只是随口一提。你如果能趁机把这件事吃透，研究清楚、甚至花钱系统学习一下，变成这个细分领域里的小懂行，下次再聊到相关话题时，你就能贡献出别人没有的细节，这很容易让人刮目相看。

同理，你也可以反过来把自己领域的干货，提炼到和他们收入体量对齐的高度再输出。比如你做跨境，很少有人愿意花时间把“能稳定做到千万级”的机会点，浓缩成十分钟就能听懂的逻辑图。你把它整理清楚了，拿出来分享，后续的局自然会有你的一席之地。

这里有个细节要注意，分享时要自然。拿到一点信息就急着掌控谈话节奏，想表现自己，结果反而适得其反。什么都不说，和太刻意表现，效果基本一样差。
