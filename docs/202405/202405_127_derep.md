# 能不能把标准，定在底线之上？
作者：龙哥

你有没有问过自己：一个公司、一个老板，做到合法合规，够了吗？就够了？还是说，在底线之上，我们还可以再往上走一步？

今天聊小马宋。

2010年，小马宋还在广告公关业。那一年，太太要做手术，他却因为一个比稿提案，没能去医院陪护。手术不大，太太自己也能搞定，但这根刺，让他下定决心离开这个行业。他说自己工作很拼命，比九成以上的同事都投入，但他从来不认为，工作应该把人逼成一个不顾家庭、没有喜怒哀乐的铁人。

那一年，他受够了无休止的加班，也受够了客户的傲慢和指使。他觉得，自己当初入行，不是要来受这些的。

2011年，他转身创业。到2016年，小马宋公司成立了。他给公司定过一个小目标：做一家自己都不讨厌的公司。

怎么算不讨厌？有一次，朋友晚上七点来找他做直播，推门进来很惊讶——怎么整层楼都没人了？小马宋说，我们同事不是不加班，但多数时候，都能按点下班。在他看来，八小时如果真正用足，效率就非常可观。

后来刚解封那会儿，感染人数暴增，网上到处都在夸“带病直播”，好像发烧咳嗽还在镜头前硬撑，才是敬业。小马宋看不下去，写了篇文章，标题就叫《我不提倡带病工作》。他说这种作风，本质上就是作秀，甚至自残。他的校友樊登也发过视频，说自己逞能带病直播，差点出事。小马宋自己当时也中了招，在家老老实实躺了一周。

再讲几件小事。

公司曾有位设计师，新晋妈妈，家里要照顾孩子，问她能不能早到早走，每天提前一小时下班。小马宋很爽快就答应了。后来有没有影响工作？并没有。最近还有个同事，孩子放学没人接，中途要出去接娃，把孩子带回公司再继续干活。小马宋觉得这也很正常，工作没落下，公司也不会因为员工离开一小时处理家事，就关门大吉。

他们的制度里还写过一条：产假比国家规定多一个月，带薪休。

你可能会说，小马宋你当然不忙。他说，论忙碌程度，他可能超过99%的人，但他照样能顾家。只要人在北京，孩子的早餐都是他做。每周他都会亲自下厨，给全家人做一餐饭。下班就直接回家，不参加任何饭局，不赴任何社交。在北京，他几乎把所有应酬都推掉了。

他说，家是社会最小的单元。没有家，社会就散了。公司请员工，法律上确实没必要管人家家庭里的事，可一个人后院都着火了，又怎么能踏踏实实上班？那些只是为了生计硬撑着加班、一边干活一边骂公司和老板的人，这样的公司文化，真的是大家想要的吗？

小马宋也承认，多数做得好的企业，老板都是工作狂，不然公司很难做起来。但老板拼，不等于公司就得冷血。

小公司为了生存，可能顾不上太多人情，这可以理解。可是已经做大的公司，如果还一心只想着资本回报，恨不得把员工榨到一滴不剩，那这样的公司，究竟给社会传递了什么价值观？我们真的需要那么多以剥削为乐的企业吗？伟大的公司，不该只贡献利润和技术，也该为社会的公德和普通人的幸福出一份力。员工也是人民，员工的幸福，就是在为人民的幸福添砖加瓦。

当然，他也不是要惯着摸鱼的人。员工该尽责，天经地义。但公司和高管在讲竞争文化的同时，能不能也讲一点温度？合同和制度当然可以谈，但那些只是底线。底线之上，我们能不能把标准再抬高一点点？

人间理应美好，不该是现在这般凉薄。
