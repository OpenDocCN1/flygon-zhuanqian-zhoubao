# 行动力不足？你可能只是没把一件事“拆”到足够细
作者：龙哥

马斯克说过一句很扎心的话：一个人迟迟不动，根源不是懒，而是对目标的认知太模糊。

放在赚钱这件事上也完全成立。尤其是我们这些想搞钱的普通人，绝大多数人的收入，并不是靠原创闯出来的，而是靠把别人验证过的路子走通。而“走通”的前提，是你能看到人家每一步的细节。

拆得越细，看得就越清。

一个案例，你把它一层层剥开，才会发现：原来这个项目真正赚钱的动作在这里，原来这个环节的门道是那样。这些隐藏细节一旦浮出水面，内心的底气就会迅速膨胀，行动力自然跟着提上来。

反过来，那些迟迟赚不到钱的人，往往缺少这个动作。他们不拆解，只凭感觉硬上，闷头干一阵子没见到正反馈，便泄了气，轻易放弃。一来二去，就陷进了同一个循环。

所以，如果你还在起步阶段，还没赚到第一桶金，别急着埋头苦干。先多看——看精华帖、看风向标，把好的案例存进脑子里；再带着好奇去拆——看到任何可能的机会，就往深处挖一挖它的关键节点；最后就是多试——跑一段时间如果还是没反馈，停下来问自己：是不是有个关键点没拆到位？

这样循环一段日子，你对项目的判断力会肉眼可见地变强，赚钱的路也就越来越清晰。

行动不是等出来的，都是一点一点拆出来的。
