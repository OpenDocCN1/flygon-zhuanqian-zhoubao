# ('因为盖洛普，我 1 个月完成了 2350 万的业绩', (2, 27))

你有没有过这样的时刻：明明很努力，却总觉得被卡在原地，甚至开始怀疑自己到底行不行？

去年我就深陷在这种状态里。主业是金融机构的国企员工，身上背着理财产品销售指标，可业绩总是不尽人意。每天下班后，我忍不住反复问自己：如果离开平台，我还能做什么？又能做成什么？那种无力感，几乎要把我吞没。

但就在加入生财、跟随个人优势航海学习之后，我的处境发生了彻底逆转。不是因为天上掉馅饼，而是因为一次关键的思维升级——盖洛普帮我真正看清了自己，找到了最适合我的工作节奏，也打通了困扰已久的销售卡点。紧接着的一个月，我完成了2350万的业绩。

回头看，我最大的感悟是：与其等着好运降临，不如主动改变认知。这段经历，我想用四个部分和你好好聊聊：

一、我的成长之路
二、盖洛普如何破解我的销售困局
三、2350万业绩背后的成交复盘
四、一些掏心窝的经验

特别感谢生财、个人优势航海和盖洛普，是它们帮我打开了一扇全新的窗，让我重新看见世界、看见自己、也看见未来。同样感谢靠谱、醒醒、苏姐（排名不分先后），让我意识到自己身上还有那么多未曾被发掘的可能性。

详细的成长经历和干货复盘，我都整理在这份文档里了：
