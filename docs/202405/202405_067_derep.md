# 重生之 80 后大叔职场外寻求第 2 春的故事
作者：龙哥

一位80后体制内大叔，在职场之外折腾出“第二春”的真实经历。

主人公学医出身，在体制内待了20年。曾经靠个人网站冲到过千万流量，也赚到了人生第一桶金。可惜后来凭实力把靠运气赚的钱全赔光，事业一度停滞，职场也不顺，那几年几乎没做出什么成果。和不少体制人一样，他开始觉得日子就这样了——上班、下班、等退休。那种看不到希望的窒息感，正是他后来所说“重生”二字的由来。

沉寂了很久，这位职场老鸟决定再扑腾一次，试着搞副业。

但问题来了：现在的90后、00后都在冒头，80后大叔做副业还有戏吗？拖家带口、工作绑身，还能放开手脚吗？脑子里的框框还能打破吗？眼光还能重新打开吗？

他后来想明白了：想成长，年龄根本不是拦路虎。关键是看你有没有重新上路的勇气和决心。

幸好，他遇到了赚钱，遇到了一路靠谱的伙伴，也接触到了很多愿意分享的大佬。从这时候起，他的人生就像被按下了加速键。

他开始转攻自媒体，照着前辈们分享的方法一步步跑：👸号爆文跑出过百万阅读，10万+/100万+的爆款素材也被他挖了出来。后来在贵人帮助下，重新定位，结合自身情况，定目标、做价值、抓素材、用工具、搞陪伴，一步步搭起了自己的小模型。

现在他有了1000人的小报童矩阵群、270多人的付费素材群、180多人的付费陪伴群、70多人的付费陪跑群。从零产品到定位清晰，只用了半年，副业GMV就突破了10万+。一个80后职场大叔，硬是在主业之外蹚出了一条新路。

今天他把自己的经历分享出来，也是想告诉每一个想做副业、或者在职场里挣扎的人：你走过的坑，他也走过；你正在熬的夜，他也熬过。希望他的故事能给你一点共鸣，也给你一点启发。

全文一万字，五大部分，大约15分钟读完。从草莽摸索的千万流量，到爆文素材的反复死磕，再到私域社群的真诚利他，接着用工具高效放大，最后落到“干就完了”。每个环节都是踩坑换来的实战总结。
