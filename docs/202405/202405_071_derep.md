# 为什么都是做副业，我能第一年就达到七位数？
作者：龙哥

从0起步做副业，第一年赚到七位数，我做对了什么？

很多人加入龙哥盟，心里想的都是同一件事：靠副业多赚一笔。可真做起来，副业并不是一条轻松的路。

最近我把自己过去两年的经历重新复盘了一遍。当初的我几乎是一张白纸，副业从零起步，结果头一年就斩获了七位数的收入。我忍不住问自己：到底是什么因素在起作用？是什么让成功发生的概率被大大抬高？

复盘过程中，一个很有意思的发现浮出水面——副业做得好不好，和你的“能力水平”并没有想象中那么大的关系。真正起决定性作用的，是两件事：你的“行为习惯”，以及你的“认知方式”。

这也是我想写这篇文章的原因。我想把背后这些底层逻辑讲清楚，看看能不能提炼成一套行之有效的方法或框架。如果可行，那这件事就具备了被复制的可能。文章里的经验和方法，希望能给正在读的你一些启发；看完之后，也欢迎你和我一起讨论。
