# 从零到十八万：一名前产品经理的公众号爆文自白

大家好，我是 ph。

四月份刚入圈赚钱不久，今天想把我自己这段单飞做公众号爆文的经历梳理出来。最近看到不少伙伴在分享做号的实操笔记，感触很深，所以也把自己过去几个月摸爬滚打的心得复盘一下，希望对同样在找方向的朋友有点用。

在去年之前，我的工作身份是产品经理。项目砍掉后我就裸辞在家，整天无所事事，对接下来要干嘛完全没头绪。

转机是朋友偶然聊到公众号爆文这个赛道。反正闲着也是闲着，不如拿来试水。于是我一个人开始了这场孤军奋战，没团队没资源，就靠自己照着市场上跑通的逻辑一点点试。

说实话一开始也是懵的，但越做越清楚。整个过程我都写成了复盘笔记，篇幅有点长，这里就不展开了，感兴趣的可以直接看飞书文档：‌[`zndm7xwy6x.feishu.cn/docx/V0rMdOTPiosHvRxzDfjcAau1n0c`](https://zndm7xwy6x.feishu.cn/docx/V0rMdOTPiosHvRxzDfjcAau1n0c)

简单说一下核心结论：哪怕是小白，单枪匹马也能靠一篇文章的裂变效应吃到可观的回报。我个人的第一笔成就是 18 万。

这条路不是玄学，更多是选题判断、标题打磨和分发节奏的重复迭代。希望我的踩坑记录能帮你少走点弯路。
