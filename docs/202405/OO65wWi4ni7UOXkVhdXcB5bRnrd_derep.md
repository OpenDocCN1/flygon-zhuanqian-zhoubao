# 利用 AI 将一个链接转换成1篇排好版且有表情包的📕文案
作者：龙哥

做📕最让人头疼的是什么？不是没流量，也不是被限流，而是——发着发着就断更了。一开始注册账号时信心满满，结果没几天就不知道该写什么内容了。但在AI时代，这个困境有了新解法。有人说AI写笔记还不简单，可生成的内容根本没法看。没错，纯靠AI凭空原创，目前确实难达预期。但今天这个方法，不靠AI硬写，却比原创还像原创。最近我又挖到一个好点子，赶紧把SOP更新一下。

先看效果：只要把一篇文章的链接发给AI，它就能自动产出完整的📕文案，还排好了版。AI会按照“痛点引入+情景描述+人设+方法介绍”的框架来重新组织内容，还会用分隔符排版、加数字表情包，非常省心。![](img/b20278da9e7ab3a8e15d1ad9e0f96ff1.png)

那这个链接从哪来？主要有三个方向。

第一个方向：📕下拉词搜索。在做搜索流量时，有个技巧是“关键词+a-z”的下拉词布局。比如我想写📕运营相关的内容，就试着搜一下“📕b”。![](img/7fdd2ff8b39cf92da33185c65abf2c4c.png)结果发现这个需求搜索量挺大。那我该怎么做？老套路是点进别人的笔记洗稿再发布——之前发过一篇“洗稿方法论+提示词”的文章，没看过的圈友可以去找找。但今天不讲洗稿，咱们直接去站外平台挖优质内容。

第二个方向：站外平台找内容。🛰️👸号的文章质量一直不错，很多大神会发深度内容，所以先去“🛰️搜一搜”。

在🛰️搜一搜里直接搜“📕变现方式”。![](img/0ac2dd606e94cdb1a287c1bd38088a6a.png)比如看到这一篇![](img/c4b8428007b9b024522a9f599951047b.png)后，接下来就该AI登场了。我尝试用ChatGPT4.0处理，但4.0直接输链接会出现这种情况：![](img/17245e743d166dae6ef9cf2fc4b299b0.png)。以前有联网访问链接的插件，现在却找不到入口。难道就没辙了吗？其实可以通过创建GPTs来接入这个功能。

进入创建GPTs的界面，拖到最下方，找到Action。![](img/7fc5c873db5ba63bd3579e3964254bb1.png)![](img/d9007f277a070adc912dee1a2b20ed61.png)把下面两个链接放到对应位置，然后点击import：![](img/b8d09b9b8f257b413a51c3b6a0ab2675.png) https://gpts.webpilot.ai/gpts-openapi.yaml 和 https://gpts.webpilot.ai/privacy_policy.html。接着回到外层配置界面，保存好。之后使用的时候，系统就会提示允许联网了。再把提示词配置好，就大功告成。

配置好后再试一次![](img/aef46906d9b6a553c326f66c3285cb08.png)，可以看到AI已经把链接里的文章整合成了一段文案，还带上了我设定的人设和结尾。当然，你可以在提示词里自定义自己的身份和补充信息。

同理，知乎搜一搜也是这个玩法。搜索“📕变现方式”![](img/aeddb7c7cd7de9317adb6b93ffa02e24.png)，找一篇合心意的文章，丢给刚才配置好的GPTs助手就行。这里不重复演示了，直接分享下一个更赞的技巧。

第三个方向：用Kimi和秘塔AI找文章出处。这个我强烈推荐。利用AI整合文章的能力，这两个国内免费工具搜索内容时，会标注文章的来源地址，特别好用。

先看Kimi：网站是https://kimi.moonshot.cn ![](img/b773feff093335ddd38f7cd688e2522b.png)。由于文章来自不同网站，我们选第一篇来试![](img/e086054571faab6552d0f0523571ed98.png)，然后复制这个页面的网址发给GPTs![](img/31d78c530be369a0381546af886e248b.png)。

再看秘塔AI：网站是https://metaso.cn/。它有多个等级，选最高级别的，内容更丰富![](img/db4aed9ce6bab7d0e5a04d5e9160bd21.png)。最后能得到一堆来源文章链接![](img/09aacdc2aa976da867a72e49c8c10f8d.png)，随便挑一个点进去![](img/74069fb59a3e0f684255ccf8334866ec.png)，然后丢给GPTs![](img/eb2a55a68420def11ae4a8afa01f8706.png)。

这样一来，内容还缺吗？只要参考文章足够多，随便整理一下就是一篇能发的📕文案。就算不用AI，靠这个技巧也能找到大量参考素材——去搜你所在领域的关键词下拉词就行。

我是哆元，专注AI📕。
