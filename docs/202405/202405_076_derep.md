# 新圈友如何快速融入赚钱，找到方向。

新手进圈一个月，我是怎么从迷茫到找到方向的？

大家好，我是龙哥，坐标河北保定，主业教轮滑和滑雪。作为赚钱第八期的新成员，我加入这个圈子刚刚满一个月。这短短一个月里，我先后摸清了剪辑（IP直播切片）和RPA两个小项目的门道，中间还尝试过不少其他方向。回头看看，这段经历挺值得记录，所以想写下来，给那些和我一样刚入圈、还在原地打转的朋友一点参考。

如果你也是刚加入不久的新人，或者正对剪辑、RPA感兴趣，那这篇文章可能会对你有用。我会分享自己从零开始摸索的成长过程，也会给出一些快速上手的思路——包括剪辑怎么练、直播切片怎么拆、RPA怎么入门。具体的方法和教程我已经整理好，放在文末的飞书文档里，有需要的朋友可以点开看。

说实话，刚进来那阵子我也挺焦虑的，方向不明、项目一堆，不知道从哪下手。后来慢慢意识到，与其纠结，不如挑两个小项目先跑起来。正是在一次次尝试中，我才渐渐找到了适合自己的节奏。

最后，我想认真感谢几位拉过我一把的人：谢谢鱼丸，把我带进新人营，还鼓励我说“什么时候开始学都不晚”；谢谢七小、张柯、梁靠谱、陈雪几位前辈，在我成长过程中给了我很多机会和帮助；也谢谢牛顿、大铭、沐之，分别在剪辑和RPA上给了我特别具体的指导。还要特别感谢靠谱姐和雪姨，帮我把这篇帖子改得更加完整。

作为新人发出的第一篇帖子，真心感谢每一位读到这里的朋友。
