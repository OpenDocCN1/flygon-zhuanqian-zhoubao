# 普通人想成功，其实是个概率游戏
作者：龙哥

普通人逆袭，说到底就是一场概率升级游戏。

老话说得好：一命二运三风水，四积德五读书，六名七相八敬神，九交贵人十养生。这些环节，其实都能拆解成一套系统，一步步优化。

第一关，是起点，也就是原生家庭。出身越普通，资源越少，成功概率就越低。你最初的圈子和人脉，基本都来自父母兄弟。如果父亲有钱有势，或者有见识，都能给你托底。但现实是，大多数普通家庭的孩子，父母既没经济实力，眼界也有限，父子之间的认知鸿沟很难跨越。更扎心的是，有的父母还会在无意中把孩子往下拽。

第二关，是学校。这是普通人第二次改命的机会。在学校里，如果遇到好老师，或者在年纪小时结交到潜力股朋友，都能大大缩短奋斗时间。如果父亲提前帮你规划，找到名师，这就是一种捷径，也是学区房贵的逻辑。但光靠自己埋头苦干不一定管用，有的寒门子弟进了名校，也不懂得借力，最后照样默默无闻。何况很多教育内容根本不实用，甚至有害——免费的往往最贵，里面塞满了广告。

第三关，是社会周期。这些年中国中产规模扩大，很大程度上是吃到了几十年经济上行的红利。只有在大上升期，才会批量诞生富豪和中产。要是活在明末乱世，能保住命就不错了。所谓的“普惠”，只有在上升社会才可能实现，否则大家一起卷到死。举个直观例子：上升周期里，1000个人有100个晋升名额；下行周期可能只剩10个。所以有人说“在电梯里做俯卧撑”，就是这个道理。过去十多年的IT热潮，早进去的人都混到了饭碗；楼市也一样，买得越早、买得越多，吃到的时代红利越大。

第四关，叫红利。你会发现有些人出身一般、学历一般、认知也一般，却照样混出头了。这种一手烂牌打好的情况，本质是在小概率中赌对了一个赛道或机遇。想要在小概率里赢，就得找到少数正确的方向，这就是红利。上行期红利多，下行期红利少。怎么抓住红利？有人靠赌——破釜沉舟，把身家押上去，成则功成名就，败则销声匿迹。也有人眼光精准，但只要概率不是100%，就有赌的成分。所以识别的关键在于眼光，更在于勇气。身边有人靠btc暴富，那是找到了巨大alpha并且重仓；也有人靠互联网赚到了钱。

第五关，是运气。那些成功的人，九成以上都离不开运气。而所谓努力、靠谱、忠诚这些美德，本质上都在增加好运的概率——它们做的都是降低风险、提升胜率的事。

第六关，是认知。这东西跟你一辈子，受环境、经历、看世界的方式限制。很多人靠对投资的认知翻了身。

第七关，是能力。能力必须由认知来指引，只有市场需要的能力才是有效能力。普通人最值钱的就是时间，时间要用来换能力。能力分短期和长期：短期能力用来谋生变现，长期能力不会随时间贬值。所以普通人至少要练两种能力：一个管眼前吃饭，一个管终身成长。

第八关，是心态，也叫性格。心态改变一切。很多人之所以普通，根本不敢想象自己能变强。不管是自卑、懦弱、原生家庭影响，还是习得性无助，本质都是不敢想。他们靠短视频、游戏、爽文麻痹自己，一边恨自己没用，一边放不下即时快乐，最后陷入平庸。想变强，先得有强者心态，想都不敢想，自然做不到。

第九关，是执行力。说干就干，别等一年做准备。莽撞的行动好过不行动，没计划的执行好过算计半天却偷懒。很多人输不是因为社会没机会，而是被懒惰和完美主义拖垮了。

把这些环节系统性地认识清楚，再一步步升级，你的成功概率自然会大大提升。
