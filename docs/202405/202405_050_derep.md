# 把消费品出海第一步，拆成一道选择题
作者：龙哥



## 6000 字说清消费品出海第一步

作者： 竹叶三十

日期：2024-05-20

“不出海，就出局”。这句话从2023年喊到现在，几乎成了共识。出海的风越刮越大，但想法有了，落地怎么干，却把很多老板卡住了。一类老板跑遍考察团，听了一圈分享还是不敢下手；另一类老板一上来就招人砸钱，最后发现挑错了盘子，不得不撤退。

我从2009年起就在电商平台上做海外生意，亲眼看着出海从无人问津到被研究透彻。回头看，启动出海并非玄学，是有可复制的思路。接下来这套方法论，就是想把原本模糊的问答题，变成清晰的选择题，让出海多一点确定性。我本人只做过2C消费品，内容也只限于这个赛道。

先说清楚，到底什么是出海方式

出海方式说白了，就是我们把手上的产品或服务，送到海外消费者手里的路径。它大致分三层：产品出海、品牌出海、本地化出海。

过去几十年，最常见的就是产品出海。广东做服装、深圳做数据线、义乌做工艺品，皆大欢喜地装进集装箱，卖给美国沃尔玛。企业只要管好品质，其他的营销、售后、渠道都交给别人。门槛低，也最省心。

后来一批企业不想只当代工厂，开始注册品牌、用线上线下讲故事。Anker、JJHOUSE、Creality、Insta360、Ecoflow，国内很多人不熟，海外却是各自品类的头牌，充电、婚纱、3D打印、全景、移动储能都有中国品牌站上C位。这个阶段，品牌力、营销力和渠道搭建能力，才是核心。

再往前一步，就是本地化出海。意识到隔着代理商看海外是二手信息，开始派团队过去，直接和当地人交易、服务。传音就是典型，国内几乎没人知道，但在非洲是第一大手机品牌，年销售额600多亿人民币。他们把黑人自拍曝光不足的问题当成工程来做，收集10万张照片，200人攻坚，把硬件、软件、算法一起调优，解决了真痛点。

OPPO也走得很远。2013年才在印尼设公司，2015年就成当地第二。后来OPPO印尼的总经理又创立了J&T，现在回国叫极兔。传闻OPPO体系在东南亚有几十万员工，业务从科技、物流、电商延伸到母婴、美妆，已成区域巨头。

可以只做产品，把销售交给代理或跨境电商；可以做品牌，用YouTube、Facebook、TikTok去触达；也可以在当地建公司做深度本地化。但方式必须和目标、能力匹配，否则就是硬套。

我见过不少制造型企业，看下游出货火爆就自己组建市场部想做品牌，结果还是围着自家工厂的产品打转，最后亏钱收场。这就是典型的错配。

匹配的例子也有。深圳坂田有家公司在亚马逊做品牌年销十几亿，老板从没出过国，但说起YouTube、Ins、TikTok上哪个达人带货猛，能一口气报出来。也有老板做到全球供应链第一，却坚持不做品牌，只是把物美价廉的货送到消费者手上。出海方式没有高低之分，只有合不合适。

第二个常见坑，就是国家没选准

经常有人问我，老王我要做东南亚、欧美。我一定会回问：具体哪个国家？

世界上没有一个叫“外国”的国家，也没有一个叫“欧美”“东南亚”的统一市场。马来西亚是马来语穆斯林为主，印尼是印尼语穆斯林人口最多，越南是越南语无神论，泰国是泰语佛教。语言、宗教、人种都不一样，需求自然不同。

很多企业都栽在这上面。2022年一家国内美妆新秀高调进军东南亚五国，一年下来同样的打法在四国失效，只在越南站住脚，最后成了越南头部品牌。成功的是“越南”，不是“东南亚”。

我自己也踩过雷。公司做过一款颜色很夸张的蝴蝶结，在美国尤其是迈阿密卖得很好。觉得英美都是英语，就推给英国。结果英国一单没出。代理后来跟我说，我们更想要你们以前那种暗色简约的风格。我只能点头。

每个国家都是独立的个体。出海要忘掉大区概念，锁定到具体国家。消费品出海必须基于产品特性，选定一个国家起步。

我做过十几个国家，给大家一个粗分：美国是全球最大消费品市场，也是品牌高地，愿意为高科技和新奇特买单，创意DIY类产品在这里有天然流量，但竞争也最激烈。英国和德国GDP分列全球第四第五，购买力强，高客单价产品首发很合适。东南亚则适合低客单价、相对落后于中国主流的产品，可以挑一到两个国家切入。以上是经验之谈，具体会根据调研不断调整。日本、澳洲、墨西哥、巴西，现在也都被中国企业盯上了。

怎么选国家？做一道期望值乘法题。

先从产品匹配度筛出几几个候选国，然后算两件事：成功的可能性，以及成功后的体量。

可能性要看竞争烈度、自身实力、当地资源。有没有蓝海、有没有增长、有没有靠谱的合作伙伴，都是加分项。结果大小要看市场规模。

国内习惯了动辄十几万件销量，一场直播几百万GMV。到了海外，市场就没那么多了。我曾为英国业务不温不火而困惑，觉得7000万人口能有多大。L教授反问我，知道比英国人口多的国家有多少吗？我查了，英国人口全球第21位，比它多的只有20个国家。7000万相当于中国湖南省的人口，做透一个英国，就相当于在国内拿下一个中等省份的省代。瑞典、希腊这种1000万人级别，大约等于成都市的市场，相当于一个市代。

体量决定天花板，竞争决定能否拿到。把可能性和结果大小相乘，排个序，靠前的就是优先目标。

电商出海也能做选择题

纯电商的出海方式，本质是选模式和平台：做精品还是铺货，是国内直发还是本地仓。

平台选择也是期望值问题。高科技产品主打美国亚马逊；低单价产品去Shopee选一个国家深耕；觉得美国亚马逊太卷，可以试日本亚马逊、德国亚马逊、英国亚马逊；想走铺货路线，eBay是不错的备选。

确定了产品模式后，同样用可能性乘以结果大小来排序选平台。

选好方式、定好国家，出海第一步就算过半。剩下的就是把闭卷考变成开卷考，多借鉴。

首先借鉴自己过去的经验。出海不是一走了之，而是把过去的积累嫁到新家庭。企业自身的能力路径，永远是最好用的参照系。

其次借鉴国内成熟打法。国内竞争激烈，迭代快，任何赛道都有大量实战案例可以搬运。比如国内口腔品牌“参半”在抖音做得很好，出海印尼的团队发现当地同样有机会，就做了一个叫Me too的漱口水品牌，把抖音白牌美妆的打法搬到印尼TikTok，年销过亿，从线上走到线下。线下海底捞在印尼的排队盛况，也正是把国内卷出的服务标准原样落地。

再者借鉴不同历史阶段的印记。有些目标国家的发展节奏落后于中国，可以用“时光机逻辑”。印尼的供应商现在很强势，起订量高、议价难，这和中国90年代到本世纪初很像。当年中国赚钱的生意是开厂开店，现在印尼可能正处在同样的窗口期。发达国家发生过的事，会在发展中国家重演一次。把过去的经验搬过去，就像坐上时光机。

现在出海，本该像在星图指引下航行，而不是靠渔民的传说慢慢试错。方法论不是唯一答案，但用对了，能帮消费品企业更稳地跨出第一步。
