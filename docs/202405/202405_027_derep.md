# 花几万做📕女装，最后只成交一单，我的踩坑全记录
作者：龙哥



在赚钱潜水了快一年，令狐冲兄弟一直催我把经历整理出来发出来，我总觉得自己的项目太拉胯，数据难看得不堪入目，拿不出手，也没脸跟大家那些月入数万的干货案例放一起。

后来想想，成功案例大家看多了，反而是那些走过的弯路、栽过的跟头，才更能给正在选项目的萌新们提个醒。于是把这段📕女装试水的失败经历摊开了讲，图个警示作用。爱笑就笑吧，我认。
