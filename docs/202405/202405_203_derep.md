# 10天进驻20所高校，这个校园餐到寝项目如何做到日利润过万？

大家好，我是龙哥，赚钱第八期圈友，也算互联网赛道里的新面孔。2023年2月至12月，我加入了一个校园综合服务团队，专注做高校早餐到寝业务。团队覆盖了北京、上海、广州、天津、河南、山东、西安、合肥、武汉、福建、厦门等地的本科院校，十几个人用一年时间，硬是把日均单量做到了1万单，日利润也稳定在万元上下。

整个模式的运作路径很清晰：先搞定小程序（租或买均可），接着搭建校园内的运营团队，再去和商家谈合作，每天早上由商家把餐送到学生手上，学生取餐后即形成完整闭环。听着不难，但真正拼的是落地速度。

我负责北京区域时，只用了10天就开通了20所高校的早餐到寝服务。当时就一个想法：把方法复制到每个校区，快速跑通。更让我受触动的是在武汉遇到的一个学生团队，他们在一所双非院校从零做起午晚餐平台，很快就达到日均千单，直接垄断了校内外卖市场，美团、饿了么都进不来。他们凭什么做到？这篇文章会直接把答案拆开讲。
