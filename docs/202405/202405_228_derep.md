# 赚钱不靠做完1到9，靠的是2和6——那两件真正重要的事

> 龙哥 | 龙哥盟

每天都要想一遍：眼下真正要紧的事，有哪些？
每隔一小时，再在心里过一遍：现在做的这件事，非做不可吗？能不能先放一放？

忙得脚不沾地，并不代表方向正确。

如果你还没找到重点，那么把“找重点”本身当成头等大事，就是现在最该迈出的第一步。

不需要把九件事全部做完才叫努力。真正决定结果的，往往只有其中两三项。比如第2件和第6件，这两项能撑起八成的产值；而第1、3、4、5、7、8、9件合起来，最多只占两成。

想要有钱又有闲，就得主动砍掉那八成。说穿了，每个人心底都清楚关键点在哪，只是迟迟不敢下手——不是不知道，而是缺一点往前冲的劲头。

我女儿常念的歌谣里有一句：什么叫勇敢？那就是迈开步子往前冲。
