# 从龙哥一篇帖子开始，谈谈我理解的行动力

从龙哥那条帖子聊起，我想通了一件事：行动力不是靠想出来的。

我是 west，坐标杭州三墩镇。曾经靠应试刷题闯出来，后来在大厂摸爬滚打到 35 岁，越干越觉得不甘心。三年前一冲动裸辞，转身跳进创业的深水区。折腾了不少方向，但说实话一直还在“试探期”——去年搞过微信👸号流量主，今年正在啃📕本地生活这块硬骨头。

熟悉我的朋友都知道，我这个人从来不算行动派，甚至可以说非常拖延。如何让自己“说干就干”，这个问题已经缠了我很多年。所以五一前看到龙哥发的那篇关于行动力的帖子，心里像被电了一下，决定借着这个契机，好好把脑子里那团乱麻捋一捋。不求立竿见影，但至少搞清楚自己卡在哪，后面才能真的跑起来。

本着“不吐不快、欢迎拍砖”的心态，我把思考整理成了一篇长文，里面也放了不少对自身经历的复盘。如果其中有那么一两句能给你带来一点启发，我就很满足了。完整内容放在飞书文档里，想深挖的朋友可以直接看：
