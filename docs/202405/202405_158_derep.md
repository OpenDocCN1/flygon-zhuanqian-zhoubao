# ('新手做小红书，涨粉 8000+，变现 4 位数，1 个月内找到工作的秘诀（6000 字干货）', (2, 48))

从零开始做小红书：6个月涨粉8000+，变现四位数，还把账号变成了求职敲门砖。

大家好，我是小怪兽，一个30岁跑到深圳重启人生的终身学习者。这篇内容有点长，但全程干货，建议先收藏。

先交代一下背景：我原本连小红书都没安装过。后来为了找兼职，刷了不少生财有术知识星球的精华帖，其中有十几篇关于小红书的文章，让我对这个平台有了基本认知。看完的最大感受是：小红书运营起来不复杂，普通人也容易上手，完全可以当成副业来做。

于是2022年7月4日我开始注册账号，用比较佛系的节奏更新了6个月，涨了8000多个粉丝，也赚到了四位数的零花钱。一共发了53篇笔记，其中一篇爆款播放量63万+。

为什么我最终选择了小红书？原因有六点：

第一，小红书是内容、社交、电商融合的消费决策平台。用户上来不是随手刷，而是想解决问题，要么了解买什么，要么想提升自己。

第二，女性用户占比高，超过80%生活在一二线城市，消费能力突出。

第三，自媒体本身就属于轻资产创业，变现场景多，普通人也完全能入场，只要内容有价值，人人都有机会被看见。

第四，反正每天都要花时间刷手机，与其一直做消费者，不如转成创作者，把用户的注意力握在自己手里。

第五，做小红书特别适合兼职，时间和地点都很自由，而且容易产生正反馈。

第六，做号对求职转行也有直接帮助。号起来了，将来甚至可以全职运营，等于多一条职业路径。

接下来聊运营。新手最容易犯的错就是“自嗨式更新”，想发什么就发什么。我总结了自己跑通的核心思维，一共三点：

1. 模仿思维。同行就是最好的老师。前期不要凭空创造，要盯着近期爆款笔记，借它的选题、封面、标题、正文和整体排版，先做出80%相似的内容。

![](img/120389c4de8e1ea89e2d068aead14d30.png)
这些模仿笔记并不是简单复制，而是在爆款的基础上多塞进一些实用信息，让人感觉内容更充实。

2. 模板思维。一旦某种形式的笔记火了，就沿用这个封面排版、内页展示、起标题的方法，连续复制，直到这个风格不灵为止。

我自己的封面就迭代了三个版本。最早的1.0版本，封面大小不一，选题平平，标题也抓不住人。

3. 迭代思维。先完成再完美，先模仿再超越。新手不一定要一步到位，从同行身上抄作业，边做边复盘，慢慢加入自己的标签，最后形成独特风格。

从零起步做出一个能稳定出爆款的账号，我的实操步骤如下：

第一步，找定位。起号阶段最忌讳急着发笔记。《2小时玩转小红书》的作者吕白给过一个思路：认真思考三个问题——我到底是谁？我能为用户带去什么价值？我跟其他人的差异点在哪里？

我当时写下的答案是：一位终身学习者；分享个人成长经验；30岁来深圳重启人生，知识付费4年累计10万+。连起来就是：一个知识付费走过弯路的终身学习者，持续提供个人成长干货。

如果发现自己什么都能做，定位定不下来，可以“先发散再聚焦”。多发几种类型的内容去测试，让数据帮你做选择，然后集中火力做最好那一类。

这里再分享一个逆熵增老师的定位模型，叫“金喜善”。金代表用户有需求，喜代表你真心喜欢，善代表你擅长做。三者相交的地方，就是最适合你的定位。

第二步，学对标。定位清楚后，找同领域的好账号去模仿。怎么找？

一看内容定位是否一致。去小红书搜你想做的关键词，看看排在前面的账号叫什么、做什么内容。
二看形式是否容易模仿。图文笔记肯定比视频更容易起步，成本低、好坚持，也容易得到反馈。
三看粉丝量级是否匹配。几万、几十万粉的大V离新手太远，最好去找近3个月刚爆起来、粉丝在1000到5000之间的账号，研究他们最近做了什么、为什么能涨粉。

找到对标账号，重点学四样：头像、昵称、简介、主页。头像尽量使用真人照片，传递信任感；昵称要挂钩你输出内容，可以用“名字+领域/身份/技能”这样组合；简介要一句话说清楚价值和优势，不会就参考同行改。还有一个提醒：粉丝没到5000之前，不要在简介里留微信号等联系方式，容易被判定违规、被折叠。

![](img/f7927018c761558859e85167e47c7c32.png)

第三步，定选题。在小红书广场搜“个人成长”这样的关键词，观察排名前20的爆款笔记，总结哪些选题反复出现、制作是否简单、自己能不能模仿。只想看图文，就在筛选栏勾选“图文”。

![](img/ffe8c774803d98ea3f344ed6a76158e9.png)

把那些让你不自觉点进去的标题整理进爆款选题库和标题库。

![](img/c0245c5035340147d9f1aa3d9527bc81.png)

第四步，作笔记。我主要用稿定设计。封面模板定下来，内页模板也固定，效率一下子就上去了。

![](img/29b699a199c8346056c23725793c5831.png)

第五步，发笔记。参考爆款的封面排版、行文结构、标题设置、结尾标签和发布时间。发布后盯数据，重点看小眼睛和浏览量。如果浏览量连500都没到，说明选题、封面或标题至少一个出了问题。

![](img/d1a12f76c0227b34bcc8ca4ea8fecce7.png)

第六步，改笔记。数据不佳不要反复改，最多优化1-2次，改多了会影响账号权重。

![](img/35d62c15a86a415ab337874a56d9b90d.png)

第七步，做SOP。爆款出来后，要把经验沉淀成固定流程：固定封面风格、固定文案风格、固定爆款因素。以后想放大操作或教别人，都有章可循。

关于广告报价，一开始我是按粉丝数的10%报，但品牌方也会看你最近的数据来砍价。想接广告赚钱，就要多发能涨粉的内容，粉丝越高，报价底气越足。

《2小时玩转小红书》里也给了很多变现思路，我帮你把关键点整理出来。

最适合靠小红书变现的4类人是：有技能的人（比如画画、化妆、健身）；在某个领域有心得的人（比如考研考公、职场沟通、运营、设计）；有特殊经历和人生感悟的人；有实体店或线下项目、想要线上获客的人。

不可错过的五大赛道是：好物推荐、技能分享、心灵疗愈/心理咨询、线下线上双赢、女性成长。

适合普通人的四类博主：读书博主，变现方式包括广告、直播带书、知识付费、读书社群；干货分享博主，利他就是利己，可以接广告、做知识付费、做咨询；育儿博主，宝妈可以重点考虑，因为抓住一个妈妈就等于抓住一个家庭的消费决策；家居博主，分享好物，靠广告、带货、开网店赚钱。

工欲善其事，必先利其器。分享几个我常用的小工具：

最后是心得总结。《2小时玩转小红书》里列过一份避坑清单，我把关键几条拎出来：

1. 选题不够吸引人。爆款内容的底层逻辑是“和我有关、对我有用”。如果某个选题能找到3个点赞过万的同类笔记，基本可以放心写。

2. 爆款相似度不够。建议找同领域50条爆款内容，从选题、封面、标题、内容、行文结构、开头、金句、结尾、评论区逐项拆解。

3. 内容杂乱，垂直度不够。和定位不相关的内容坚决不发，垂直度越高，账号权重越高。

4. 封面难看且不统一。封面要高清，背景要简洁，字要大、要少，风格尽量固定。

5. 标题平淡无趣。把那些吸引你点击的标题全部积累下来，做成标题库。

6. 内容质量不过关。少说废话，要么给足信息量，要么给足情绪价值。多去刷同类型笔记的评论区，了解用户真实关心什么。

7. 整体视觉效果差。封面排版、文案排版都要花心思，多看优质笔记提升审美。

以上这些都是我一路踩出来的经验。如果你也想做小红书，别怕起步晚，找对方法，坚持执行，普通人也能拿到属于自己的结果。

最近很多朋友问：素人怎么把小红书做起来？我自己踩了不少坑，也攒下了一些经验，今天干脆一次聊透。

先说三个最容易翻车的细节。

第一，人设一定要让人一眼就记住。头像最好用真人照片，昵称要跟内容方向挂钩，主页风格和简介也不能敷衍。简介用一句话讲清楚：你是谁、能给用户带来什么，别让人看完主页还猜不出你在做什么。

第二，别把评论区当摆设。那些能火的笔记，评论区往往观点交锋、讨论氛围很热，这正是助推流量的好机会。你可以主动置顶几条评论，抛出话题或立场，引导大家往你想看到的方向聊。评论区越活跃，系统越愿意给你分发。

第三，别随意删笔记。发出去之后哪怕数据不好，也尽量选择隐藏，而不是删除。删笔记会拉低账号权重，后面想再起来就难了。

如果作为素人想跑出成绩，下面这六项能力绕不开。

一是综合能力。文案、拍摄、剪辑、修图、调研、复盘，这些不一定样样精通，但至少一样要能拿得出手。二是学习能力。做内容最怕原地踏步，持续学、持续想才是关键。看到好的表达和结构，就拆开来模仿借鉴，慢慢变成自己的东西。三是数据分析能力。别只盯着点赞量，更要关注互动率。简单记两个数：互动率=（点赞+收藏+评论×3）尽量超过8%，封面和标题的点击率尽量超过5%。四是选题能力。说实话，笔记能不能爆，80%的功劳都在选题。所以一定要建自己的选题库，平时多囤素材。具体怎么找？可以先分析定位相似、数据不错的账号，新手期重点对标近三个月涨粉快的同类号；再复盘自己数据好的笔记，顺着同方向持续产出，也可以去小红书的话题和实时热点里找灵感；还能站在用户痛点那边，用你的经验帮他们出主意，或者一起吐槽，让大家觉得“你真的懂我”。五是变现能力。想持续赚钱，就要围绕人设持续输送有价值的内容，信任建立起来，收益只是顺带的结果。六是时间管理能力。别等到万事俱备才动手，先做出一个粗糙的版本，再去打磨。顺手把标题库、金句库、选题库都建起来，效率会高很多。

回顾我这一路，真正起作用的是这些想法。

同是博主，同行其实就是最好的老师。多看他们的长处，补自己的短板，先把好东西“抄”过来，再“超”过去，最后才是“钞”能力。一句话：先模仿，再创新，赚钱就是自然的结果。

还要想明白一件事：粉丝多不代表能赚钱。账号越垂直、人群越精准、越能真正解决别人的问题，商业价值才会显现。选赛道也要有智慧，别在没鱼的水塘里干等，要去鱼多的地方钓鱼。流水不争先，争的是滔滔不绝，持续输出比一时爆发更重要。

最后说点真心话。我从没想过，自己会因为小红书获得工作机会。所以特别感谢“生财有术”这个平台，感谢亦仁大大，也感谢星球里所有无私分享的朋友。成长就是在具体的事上练、事上学，实践得多了，自然就进步了。扎克伯格有句话让我印象深刻：Done is better than perfect——完成比完美更重要。勇气其实是最宝贵的才华，别给自己设太多限制。你不需要很厉害了才能开始，但你需要开始了，才会慢慢变得厉害。
