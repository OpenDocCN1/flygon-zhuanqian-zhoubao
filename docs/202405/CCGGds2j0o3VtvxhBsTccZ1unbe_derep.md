# 先搞清楚自己是谁，再去啃下第一单
作者：龙哥

大家好，我是龙哥， 赚钱编号48034，目前还是个二年级的学生。看到龙哥盟的人数已经冲破七万，我由衷为这个社区高兴。抛开社群氛围不谈，光是信息密度和服务响应，在我体验过的付费圈子里，确实能排到前列。是不是像在吹捧我自己？我承认有点，但以上都是肺腑之言。

今天这篇，是写给那些还在赚钱里逛项目、却迟迟没赚到第一块钱，或者对下一步完全没概念的同学。希望能给你一点清晰的思路。

# 一、先把自己看明白

1.  刚进来的人，经常被各种战报刷屏：我在XX天赚了多少、我做了什么。看完以后容易既佩服又焦虑。

我们得先承认现实：
*   我们是新人小白。看到别人的数字，可以相信但别全信，保持一份怀疑，用空杯心态去读，而不是被数字带跑情绪。
*   我们大多没资源、没启动资金。别人做的百万项目，与当下的你并无直接关系，先别对号入座。
*   焦虑完就想着怎么办，却停在想的阶段，这本身就是一种拖延。
*   大多数人习惯避重就轻，天然想找一条轻松就能拿结果的路。

其实赚钱的前期引导已经做得很足了，手册、分区、指引，新人上手不难。
每两个月一次的航海，很多同学都在纠结选哪条船。龙哥在信里提过 Think different。当一条船人满为患时，反过来想想：它真的最适合我吗？冷门的船是不是反而藏着被错过的机会？

朋友圈里总有人一天到晚晒收益，看到后心里发慌的，直接屏蔽就好。现在最需要的是把心静下来，别被别人的节奏干扰。

赚钱这件事，需要用更长的周期、更大的格局去看。不要急，慢下来反而更快。能人很多，能抓到机会的永远是少数。赚钱本质就是概率游戏，二八定律不变。我们唯一能做的，就是想办法把自己的中奖概率抬上去。

# 二、学会做信息过滤

*   赚钱里有真大佬，也有看起来很像的大佬。遇到值得的人，去溯源他的公开足迹、过往文章、思考方式。如果你认可，并且他的付费内容正好匹配你当前阶段，花钱建立深度连接是值得的。
*   很多帖子写得漂亮，像钓鱼。看下来感觉什么都讲了，其实什么都没讲。甄别和过滤是必须的能力。真正利他的人，会把能复制的点讲透。有些模式背后靠的是资源、资金和信息差，光看文字学不来。
*   一个项目出来，总有人晒收益，看到心痒很正常。先别冲动，先调研、再分析。实在想做，可以付费系统学习，关键是先让自己通过这个项目赚到第一块钱，拿到正反馈。选对方向再全力以赴，比到处乱试强太多。

# 三、执行和坚持，才是门槛

*   选定项目、报了航海，就要做到位。我见过太多人，前几天热情满满，日志水了两下就不写了，最后为退保证金而打卡。这既是浪费社群给的机会，也是浪费自己时间，很不划算。
*   如果你也曾这样麻痹自己，先别自我否定。赚钱本身就是反人性的。成功这条路从不拥挤。给自己断后路，逼自己向前走。
*   看到别人成果时，逼问自己：为什么他行我不行？是封面、时长、更新频率、选材？把差距拆解出来。
*   船上的人就是资源。主动交流、信息互通，哪怕这条船没结果，认识的人会在未来某个项目里成为你的合作伙伴，帮你赚到第一单。
*   做计划、追结果、复盘过程。航海的21天，每天复盘，积累起来就是质变。
*   项目比拼从第一天就比执行力和耐力。大家都撑不住了，你还能坚持，回报往往会超出预期。就像郭晓文老师说的，看见和参与是两回事，参与和抓住又是两回事。抓住一次，可能小富即安；抓住对的，可能直接翻盘。
*   结果不可控，但努力不会白费。一步一个脚印，走在路上，总会在某个节点迎来转机。要相信自己，相信持续的力量。

# 四、别下牌桌，时间会给你机会

坤哥说过：时间是最强的壁垒，人在牌桌上，就永远有机会；你这一生最好的作品是你自己。

不必焦虑我来晚了。我也后悔没更早进赚钱，但也庆幸现在进来不算太晚。种树最好的时间是十年前，其次就是今天。

给自己时间沉淀、学习。心态不骄不躁，别去追自己当前能力配不上的结果。在赚钱里打开视野，拿出真正的执行力，拿到结果的概率会很大。

祝好。
