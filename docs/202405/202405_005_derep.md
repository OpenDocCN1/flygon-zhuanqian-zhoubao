# 入赚钱半年，我把自己拆了重装了一遍
作者：龙哥

作者：薄荷 Heidi

大家好，我是龙哥，一个90后普通人。今天鼓起勇气把自己的这半年经历写出来。

本来一直在赚钱里潜水看热闹，迟迟没敢发声。促使我开口的理由有几个：

一是罗卜老师的点拨和激励，给了我底气；

二是回想起一年前还在抑郁里挣扎的日子，如今状态已经慢慢回暖；

三是半年前因为搞钱女孩的引荐正式加入赚钱。进来后亲眼看到圈子里各种赚钱案例、航海实战复盘、好事榜和精华榜上的喜报层出不穷。

我猜刚进来的人，可能和我当初一样，既兴奋又迷茫、又焦虑。所以我用思维导图把自己的进阶轨迹梳理了一下，希望能给同样处在迷路期的新人一点参考。

整篇复盘主要围绕五个阶段展开：

1. 我还没加入赚钱之前的样子
2. 辞职后度过的那半年
3. 入群的第 2 个月发生了什么
4. 入群的第 4 个月有什么变化
5. 入群的第 6 个月认知如何重塑
