# 第一次赚钱拉新复盘 私域如何引流发圈销售

我的首次私域拉新实战复盘：从0到1，如何引流、发圈与卖出知识付费

先介绍一下自己，我是龙哥，一档名为《搞钱搞流量》的播客的主理人。去年经醒谱白引荐，我成为了赚钱的一员；今年则以队员身份跟着醒谱白战队，亲身参与了完整的赚钱拉新过程。从当初懵懂的旁观者，到如今全程深度参与，我所在战队最后拿到了第五名的成绩。

这也是我第一次把私域拉新当作一个正经项目来落地。整个过程中，我拉了700多人进群围观，积累了90多条朋友圈内容，私聊沟通了300多位用户。最终成功转化9人加入赚钱，团队也冲进了前五。这个数字和很多高手相比并不惊人，但对我而言，从零起步所踩过的坑、试出的方法，相信能给同样打算在私域发售知识付费的朋友带来一些启示。

如果你正考虑通过私域拉新来推荐知识付费产品，或者想在经营自己热爱的同时获得商业回报，那这篇复盘值得一看。完整版大约5000字，我把它拆成了三块：

第一，我为什么参与赚钱拉新？以及知识付费怎样才算投入产出为正。
第二，第一次做知识付费拉新时，引流、发朋友圈和私聊销售分别怎么操作。
第三，从这次发售中提炼的复盘心得，以及哪些经验可以迁移到其他场景。
