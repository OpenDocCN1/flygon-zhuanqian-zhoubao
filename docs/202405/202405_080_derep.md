# ('公众号爆文全自动化代码分享', (2, 15))

我是毛韩，第五期圈友，编号 21985。之前分享过一篇公众号爆文复盘（原帖戳：https://t.zsxq.com/2f5s1），当时收到了不少圈友的点赞和鼓励，真的很感谢大家的认可。

之后陆续有圈友问，能不能把那套自动化工具也拿出来。于是我花了两天时间，把代码彻底解耦，又整理出一份使用文档。今天直接分享给大家，希望能给还在做公众号爆文的同学搭把手。

不过得先说清楚：这套代码量不小，而且结构嘛，你们懂的，多少带点“祖传屎山”的味道。所以配置过程不会太轻松。有编程经验的圈友，预计两个小时能搞定；零基础的话，建议留出五个小时以上。最关键的是：跟着文档一步步走，每个字都要看仔细，别跳步。

整套配置分三大块：

- Python 端：负责扒取对标账号的文章，然后调用 GPT API 批量生成新内容，保存到本地文件夹。
- 飞书端：相当于全流程的“中控台”，参数调整、收益统计都在这里完成。
- 影刀端：驱动悦互联浏览器，把本地文章自动发布到公众号后台。

具体细节我都写进飞书文档了，链接在这里：https://tjhy5ng53f.feishu.cn/docx/EaSSd0KJsoHDysxItnFc3xsgnAh?from=from_copylink
