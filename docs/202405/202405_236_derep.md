# 大佬的人生循环论
作者：龙哥

一个人从凡人到大佬，其实走的是一条看似散漫却高度重复的闭环。

第一幕，是把命搭进去搏。白天黑夜地干项目、扛压力、拼到心力交瘁，创业这条路几乎把人掏空。

等到第一波成果落袋，第二幕就来了。名利到手后，人开始用声色犬马的方式报复性释放，纸醉金迷的放纵是应得的狂欢。

狂欢总有倦怠期，第三幕转向身体的自省。卸下西装换上登山鞋，翻山越岭、一路徒步，用自然的艰苦把浮躁磨平。

走不动的时候，第四幕是向内塌陷。寻一座古刹，听钟声敲过心头，彻底放空、什么都不想，借静默找回自我。

可静不代表结束，第五幕是回光返照式的再出发。像是耗尽电量前的最后一亮，旧火重燃，再次杀回牌桌。

然后呢？循环又开始了。
