# 3 个月在📕 K12 赛道，引流营收过百万的方法论

今天是 520，朋友圈里全是甜蜜暴击，但我觉得对单身又爱搞钱的人来说，最浪漫的事莫过于收到一份“赚钱方法论”。没错，我是龙哥，这篇就是送给还在奋斗路上的圈友们的礼物。

去年我亲手操盘了一个项目，趁着这段时间业务上的压力反而逼着自己沉下来做了次完整复盘，整理了一份超过 12000 字的深度拆解。别被这个体量吓到，静下心阅读差不多 5 分钟就能看完。整个项目聚焦在📕的 K12 赛道，我们只用了 3 个月，就把引流和变现跑通了，最终营收突破了百万大关。从账号定位、内容打法，到引流路径、成交转化，能复用的细节全在里面了。

其实很多时候，公司真遇到困境，反而人才能清醒下来好好思考，也有动力走出来多交流。这段时间我争取高频输出，不再当放鸽子的那个人。完整文档链接放在下面，直接自取。

对了，评论区不少圈友在问怎么加入、如何获取 SOP，我已经把之前的部分 SOP 文档权限重新打开，觉得内容有收获的朋友记得一键三连支持一下。最后温馨提示：分享里有些技巧可能已经过了红利期，但没关系，因为我所在的公司现在每天都在跟平台规则死磕，最新鲜的玩法和规则变化都装在我脑子里，有问题直接在评论区问我，看到都会回。![](img/21de372a77ea1f441c613f7316831ae1.png)
