# 听劝！互联网想赚到钱，坚持这两步！

有人总问：普通人怎么在互联网上赚到第一块钱？听起来高深莫测，满屏都是风口和捷径。但在互联网行业沉浮多年的鲍称称看来，这事远没那么多玄机，坚持做好两步就够。

他是89年生人的“互联网老兵”，也是二胎全职奶爸、河狸创赛教练。从销售到淘宝，再玩抖音直播，如今主攻📕。他的第一个一百万是在淘宝赚到的；眼下靠📕的大学生创赛项目引流到私域成交，一个人、一个账号，月入三万多。

鲍称称说，想通过网络赚到第一块钱，第一步就是别在岸上想太久，马上下场干，先做出一版最简洁的可行产品；第二步，用正反馈推着自己跑起来，只要尝到甜头，就会越干越有劲。他甚至把总结浓缩成一句话：空谈误国，实干兴邦。

评论区的哈总也分享过一个类似的做法：看见很多人卡在“赚第一块钱”这道坎上，他干脆把自己操作支付宝红包码的整个流程打包成营销内容，教别人先赚到第一块钱。这正是一个先跑通小闭环、再把经验变现的活例子。

别把网络赚钱想得太玄，先干起来，再让结果喂养你。攒到第一个小胜利，后面的路就顺了。
