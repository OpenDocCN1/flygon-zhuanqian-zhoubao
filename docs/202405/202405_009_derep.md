# 正心诚意，才是真正的思无邪
作者：龙哥

前几天我分享了关于得到平台的一段往事，没想到成甲老师在私信里回应了一句意味深长的话。

他说当年是我把他推荐给了得到，这成了他职业生涯的关键转折，后面很多重要的机会都与那次推荐有关联。可这么多年下来，他始终觉得自己没能回报什么，心里一直过意不去。

我当时回复得很干脆：那次推荐，从来没想过要回报，也没想过要交换什么利益。我只是觉得他的风格和能力，恰好就是得到当时需要的讲师，对平台是有价值的。所以推荐了。假如用处不大，哪怕是至亲好友，我也不会开口。

这就是正心诚意。

你做一件事，是因为事情本身就该做，而不是先算了一通得失和回报。

反过来想，如果一个咨询公司和某家媒体签了返佣协议，客户让其推荐媒体时，他自然会优先推那家能给他带来提成的媒体。这种推荐，里面掺着的就是利益计算。

前天也有个做 IP 商务的同行给我递来合作资源，我直接转给了一个很合适的客户，并且说“给你拉个群，你们自己聊”。客户当时有点惊讶，私下跟我说，你完全可以走我们公司的渠道收点佣金。我明白他的意思，但我推荐的出发点很简单：这个资源确实适合他，能帮上忙。佣金从不是考量。

正心诚意的逻辑就是这样：客户付了咨询费，你就应该全心为客户的利益着想。你做的每一步，都必须是真正能帮助到他的，而不是服务于你自己的小算盘。

这让我想起孔子对《诗经》的总评：诗三百篇，一句话可以概括，就是思无邪。

意思是诗经里写的东西都是发自内心的真话，没有做作、没有虚伪。

开一家公司也是同理。你是真心想让团队过得更好，和你只是想让员工替你多赚钱而对他们好，这是两种完全不同的状态。你是真心和朋友交往，和你只是因为朋友能带来资源价值而维持关系，也是两回事。

很多人嘴上挂着正心诚意，脑子里却转着利益交换的盘算，这就已经偏了。与其如此，不如直接承认我们就是商业互惠，这比口不对心要坦诚得多。

用真心去对待客户、员工、合作伙伴和朋友。

这才叫思无邪，这才叫正心诚意。
