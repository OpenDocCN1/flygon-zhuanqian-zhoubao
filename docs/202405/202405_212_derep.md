# 左手职场右手副业，挖掘 1000 万素材赚到 10 万+GMV 几倍赚钱门票的复盘
作者：龙哥

从0到3000+私域，他靠挖掘千万级素材，把赚钱门票赚回了数倍

大家好，我是龙哥，一个80后，白天在公司里默默干活，晚上在副业里折腾出一点名堂。加入赚钱刚好满一年，这一年我的私域从近乎零基础涨到了3000多人，从没产品可卖到定位“素材+陪伴”，做出了10万+的GMV，赚到了6位数的回报。趁这个机会，把这期间的经历整理出来，希望给同样在职场和副业之间挣扎的朋友一点参考。

说起来，很早以前我做过程序员，玩过火车头采集器，配合个人网站收录，把网站的流量做到了千万级别，靠这个赚到了人生第一桶金。那时候其实也听说过赚钱，但总觉得一个星球能有多大价值，就没当回事。结果后来风口过去，凭运气赚来的钱，又靠“实力”亏光了。加上职场那几年不太顺，整个人消沉了挺长一段时间，中间断断续续试过一些小项目，都没做出什么水花。

转变发生在2023年。经涛哥引荐，我正式进了赚钱。跟着航海跑了👸号爆文项目，跑通之后又顺着爆款内容往上游挖，最后锁定“素材”这个方向深耕。结果，投进去的入场费，几倍赚了回来。所以到期续费那天，我眼睛都没眨一下，直接续上。说实话，是赚钱教会了我怎么在副业里找到自己的生态位——有航海项目领路，有同频的圈友彼此加持，再加上涛哥给过的那些点拨，让我这种40多岁的“老职场人”，硬是在副业这条路上又重新支棱了起来。

我的爆文打法和大多数人可能不太一样。航海结束后，我没有急着做号，而是直接尝试卖素材，把付费用户拉进群里。最初的想法很简单——找一批同路人，一起继续挖掘素材的玩法，让航海结束后大家还能互相鼓励、接着往前走。

结果做得过程中发现，需求比我想象中大得多。大家不只想要素材本身，还想要“怎么用素材”的拆解方法，以及更好用的挖掘工具。我先后在赚钱里翻过📕、RPA、数据库等玩法，最后决定扎根素材领域。后来参考了圈内几位前辈的打法，我推出了一本👸号相关的“100万小报童案例”小册子，订阅很快就突破了2000人。再后来，又经高人指点，我把“小报童福利群+素材福利包”设为社群的门槛，持续在群里做真诚分享，靠价值吸引人留人，慢慢跑出了“素材+工具+方法+课程”的陪伴陪跑模式。

到现在为止，我建了5个近千人的小报童交流群，1个近300人的年度素材群，1个150人的年度付费陪伴群，还有1个80人左右的年度陪跑群。借着这些群，我相当于给自己搭了一所“自我学校”。在这里，我不仅认识了很多志同道合的朋友，也完成了一点和自己、和他人互相成就的小事。

我挺信一个词，叫“最小后悔法则”。说白了就是——等你老了往回看，那些当时能做、想做、该做的事，如果没去试，会不会后悔？如果现在让我重新选一次，2023年要不要加入赚钱、要不要做这个副业？我的答案依然是：要。

人间清醒，搞钱要紧。宁可做过再后悔，也不要因为错过而遗憾。别等到白发苍苍，才来感叹年轻时的犹豫。

有人带路的时候，别着急，也别害怕。拆解对标，持续积累，不断精进，路才会越走越宽。凡是过往，皆为序章；人到中年，不是借口；身在职场，也不是理由；不懂技术，更不能成为退缩的挡箭牌。何以解忧？唯有行动。

这趟心路历程，大致可以拆成五个阶段，分享给同样迷茫过的你：

一、草莽期：普通人就用手边有的资源，定位别反复纠结
二、破局期：从自己擅长的地方切入爆文赛道，认准了就别停
三、社群期：群里既有分享也有陪伴，价格从免费到中高价都有人需要
四、工具期：人天生有惰性，用对工具，效率翻倍
五、践行期：道理说再多都是空，做过了才不后悔
