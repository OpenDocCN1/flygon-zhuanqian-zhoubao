# 别再吼“还剩最后3单”了，董宇辉式文案，用ChatGPT两步就能写出来

刷到董宇辉的直播间，很多人会先愣一下：这真的是在卖货吗？

没有声嘶力竭的逼单，没有故意制造的倒计时，他只是在淡淡地聊生活、说说远方，聊聊藏在产品背后的人与情怀。那种带有诗意和温度的表达，让你仿佛不是在逛直播间，而是在听一篇优雅的散文。你忽然意识到：原来“卖东西”也可以这么从容、这么打动人。

如果你也向往这种“散文式带货”，不必硬憋灵感。用 ChatGPT，两步就能生成：

**第一步：分析。** 把董宇辉的直播文案交给 ChatGPT，让它从语气、风格、语法结构三个维度逐层拆解，提炼出这类表达的核心“套路”。

**第二步：执行。** 在分析结果基础上，给 ChatGPT 布置一个清晰的写作任务，让它按照董宇辉式的语言习惯，围绕你的产品生成全新文案。

当然了，上手前最好先通读董宇辉的原版文案，以免跑偏。完整流程可拆成三件事：先解析他的文案，再让 AI 复刻风格，最后设定任务让它落地。


如果你也想去试试这种“有温度”的直播文案，强烈建议看看这份文档。

希望你的直播间里，也能少一点“3、2、1上链接”的喧嚣，多一点像董宇辉一样的从容表达。
