## 项目赚钱逻辑

网盘平台为了抢用户，会花钱找推广机构做拉新活动；机构把任务放在渠道平台上，我们去接单。每带来一个之前没用过该网盘的新用户注册，就能按CPA结算佣金。

CPA即Cost Per Action，属于按真实行为付费的模式——用户完成注册、下载、购买等动作后，广告主才付钱。

在网盘拉新里，用户注册一次，推广者就有一笔收入。

![](img/323c0938ccbbc2a847c6a01f8dd9167e.png)

## 收入来源有哪些

对接平台后，很多平台有二级分销机制，所以收入分为个人收益和团队收益。

### 个人收益

1. 拉新奖励：用户转存你的资源时，必须先注册网盘。如果他从没注册过，你就能拿到4-9元，主流产品大约5元/人。不同网盘价格不同。

![](img/7dc594ad62222119481295d6acd6bd41.png)

2. 转存佣金：只要用户转存了你分享的文件，你就有收益。不同网盘单价不同，新老用户的价格也不一样。

![](img/0e96b433e6d9494dbf28603e627d39fe.png)

3. 会员提成：用户为转存资源开通会员，你能拿会费10%-40%的提成。各平台比例不等。

![](img/757c9edff6d7ea7d52234ea0e210cf74.png)

4. 活动补贴：平台有活动时，转存或拉新达标会有额外奖励，属于不定期福利。

### 团队收益

平台的分销功能允许你组建自己的推广团队，拉来的下级产生的佣金，你能按比例抽成。

![](img/4009d147e42a008dafe236a7ca2781d9.png)

不过现在分销抽成比例很低，想靠团队收入很难，踏踏实实做个人推广才是正路。

![](img/f84c8aae2fcf1ff27f8e4864fc115894.png)

### 3. 写👸号文章

一篇文章由标题、开头、内容、结尾组成，完全不用原创。

第一种写法：
标题：搜剧名后看下拉推荐词，组合成一个爆款标题。例如《我在80后当后妈全集免费，完整版观看，速进！》。

内容：这部分只为了撑结构。在👸号里搜剧名，复制一段剧情介绍，配几张剧照即可。

![](img/06f5277ae61f46712c4cc84f1b5d89a2.png)

结尾：跟开头呼应，放资源搜索站链接。由于吸引的是精准搜索用户，一定要提前把对应短剧资源放进搜索站。

这种类型的稿子最省力，标题词库是现成的。现在能用的关键词就这些：短剧资源每天更新、短剧资源更新、短剧资源分享、短剧分享、短剧更新、短剧更新合集……

##### 4. 👸号操作注意事项

（1）文章别勾选原创，系统有时会判定为滥用原创

（2）文章里不要放网盘直链，这样能有效规避侵权投诉。

举例：我刚开始尝试时，直接把短剧标题+网盘链接发在文章里，效果还行，但投诉风险很高

![](img/7086941a94854e395f1bdb01a5272775.png)

唯一的缺点就是容易被投诉，不过不用太担心。

遇到问题，就换思路、做优化！

文章会被自动下架，但账号是不会受影响的，别等腾讯人工判定，我手上几个👸号被投诉几十篇，全认了，全自动删除，现在账号还是正常运营。

# 项目复盘

网盘拉新是一个可以长期做、且偏被动的项目，怎么理解？

拉新收益是一次性的，但转存收益对新老用户都一样。你手上如果有1000个老用户，只要持续不断给他们更新资源，1000次转存就是200元收益。所以核心就是不断更新资源库就行。
