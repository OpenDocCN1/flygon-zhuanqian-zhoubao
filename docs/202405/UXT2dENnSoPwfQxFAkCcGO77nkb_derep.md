# 一、硬件篇：器材该怎么拿

## 安卓阵营

优先小米或红米，具体门槛是小米8往上、红米note9往上。理由很直白：小米系刷机成本最低，而且支持把整套系统备份出来。

先解释“备份”这个概念：所谓备份，是把手机里的全部数据抽离到电脑上，让号在电脑环境里慢慢养，等哪天要用再还原到手机。比如你刚注册完一个新号，直接发创业类内容必被盯上，怎么办？先备份出来，放它一个多月再还原，此时这个号拿到手里已经算“陈年旧号”了。好处是不占手机内存，不然几十个号全塞进一台机子里养，人工效率太低了。

不过要提醒一句，备份这套玩法的红利已经稀释得差不多了，大家别抱太高期待。求稳的话，时间越长越好：小米8建议至少一个月再启用，小米11也说说15天打底。设备配置越高，备份期的需求就越短。此外，凡是备份恢复出来的号，正式开工前最好用真机或电脑比特再养上半天。

这套路子比较适合小型团队做截流；自然流团队也能用。

## 苹果阵营

用苹果的话，起步建议7p。渠道不限，但买前一定追问一句：“能不能刷机还原？”因为号一旦反复被封，就必须刷机清理，否则会牵连设备本身被标记。那种不能刷机还原的机器虽然便宜，可一旦设备被封，插上去几个号挂几个号，这台手机基本报废。

苹果机更适合自然流团队。

*备注：自然流=自己铺内容吃免费流量来导人；截流=钻到别人内容底下捡流量。*

# 二、账号篇：五类号逐个拆

## 1. 接码平台的“毛号”

这类号几乎只存在于理论中——除非你彻底玩明白了规则，否则别碰。清一色虚拟号段，公认为最劣质的一档。唯一的优点是便宜到忽略不计，也有人会拿去截流，但体验非常折磨：评论发不出去、关注没动静，说白了，你做的所有动作都被平台静默屏蔽了。所以结论很简单：不管截流还是自然流，都别选它。

## 2. 四方号

四方号的本质，是经由四方接码平台搞到的厅卡号。接码有效期约为3天，窗口期内可以反复接码上号。借助🧣或🐧做第三方绑定，能实现无限次废号重新激活，一般来说一个号扛住3-4次问题不大。价格在2-4元浮动。使用建议：截流可以，自然流别拿来赌——就算偶尔过了推广，也纯属运气，不具备复制性。

结论：截流专用。

## 3. 拦截号（纯科普，禁止使用，涉及违法）

这种号的来源是：有人不经意间把短信权限抛给了某个恶意App，或者是扫了路边不明二维码导致短信被劫持，而后通过拦截平台实现接码。它只能接收一次验证码，一旦退出登录，这个号就再也找不回来。市价约为5-7元。

拦截号和厅卡号、地推号运作逻辑接近，差别在于：地推号是当面拿到对方手机操作，拦截号是完全不见面的远程劫持。拦截平台支持筛号，但筛选本身要收费，大约每次4-5分。如今市面上的老拦截号已经极其稀缺，有些平台筛号一次就收好几块，折算下来一个老号逼近10元。我们工作室筛出的老号，主要投放在高危赛道的自然流上。

做贷款、复刻、国学、创业这四类的人，几乎人手拦截号。新拦截号随时能拿货，但真正把📕打粉当长期事业来做的人，基本都是自己搭建备份养号体系。当然，直接收购老号效果更佳，代价是预算要往上抬。

结论：高危自然流可用，但法律红线需自掂量。

## 4. 地推号

所有类型里价码最高的。要警惕的是，市面上总有人拿低端号来顶替。识别方式其实有规律：地推号只会在正常作息范围内出现。如果有个卖家凌晨两点多给你接码上号，那百分之百是拿别的号来糊弄人。

验货也很简单——拨一通电话过去，看有没有真人接听。

地推号没有公开交易平台，一般靠地推团队或者圈内群对接。新地推号可以去试探低危赛道；如果瞄准创业这类高危赛道，还是老号或用备份养出来的号更稳妥。

## 5. 外国号与香港号

美国老号是目前流通量最大的，售价极低，基本只需3-5元。现在市面上还出现了一些“29粉丝”特供美号，以及做过点赞评论数据的美号，价格略高，确实好一点，但也好得有限。

安卓机就别碰美国老号了——实操美老清一色都是苹果。安卓跑起来复杂到怀疑人生，听劝。

美号玩法是：电脑开着VPN，挑一个外国节点，接到比特指纹浏览器上，用电脑端发作品。这篇内容的重心是打粉前的准备工作，具体操作细节后面再更新，大家可以先关注一下。对小白而言，用外国号做自然流有点门槛，但并非学不会，我手上有一份教程，需要可以找我要。外国号和港号的真正用户群，就是拿高危类目当主业的专业团队。

结论：外国/香港老号，专攻自然流。

# 三、网络篇：卡与IP分头讲

严格来说，手机卡（注册卡除外）一插上，用它的流量就等于自带了一个IP。但为了不混淆，我还是把卡和IP拆开讲。

## A. 卡

**厅卡**
线下营业厅办理的普通卡，IP底子干净，适合老老实实做内容、长期运营涨粉。个人名义最多办15张，等于15个账号位。虽然🧣、🐧等第三方能帮忙“顶号”开启新号，但能注册的账号总量始终有限。

团队做的话，可以拿营业执照申请运营商上门办理，一口气就能办满额度；个人跑营业厅则只能一张张办。

**流量卡**
网上常见的19元/29元/一二百G那种大流量卡，和厅卡差异不大，同样适用于正规长期运营。区别在于，线上渠道最多办10张，用完后就得转战线下厅卡。

还有一点：不建议办广电卡。广电号注册出来的账号权重先天低于移动、联通、电信三网。

**注册卡（绑定）**
用途极其单一：收验证码、养账号。也就是俗称的虚拟卡。电话短信流量全无，一般由工作室买来注册App或绑定手机号。注意：很多注册卡不支持注册🛰️，动手前务必跟渠道确认。

**物联卡**
前几年流行过的纯流量卡，只能上网，电话短信功能全面砍掉，现在也有很多人直接叫它流量卡。行情一般是19.9元/60G、29.9元/100G。如果贱卖到离谱，大概率是虚标，实际流量根本到不了标注数值。个人能办10张，后面基本不会触发人脸验证。嫌麻烦也可以直接买已经实名好的，价格会抬升。物联卡分普通款和可跳IP款，主要用于低危类目的自然流和截流。

## B. IP

**厅卡流量**
坊间传言厅卡是静态IP，但我们团队亲测后发现，飞行模式一开一关，厅卡的IP也会变动，只是只动后段地址（形如xx.xx.aa.aa里的aa那一截）。所以“只有全国跳才能跳IP”这种话术，大可不必当真。厅卡完全够用，别被卖全国跳的忽悠了。

**WiFi**
WiFi环境下IP恒定不动，所有人共享同一出口。适合踏实做内容，不会有废号风险。

**物联卡流量**
这里特别容易踩坑。物联卡分能跳IP和不能跳IP两种。不能跳的买回来发现IP雷打不动，还不如直接拿流量卡。能跳的又分为全国跳和省内跳，当然全国跳更优。买之前多问一句不亏。

**跳IP具体操作**
插卡、激活、充值、确认流量可正常使用，之后就一个动作——飞行模式开一次关一次，IP随即更换。质量差些的卡偶尔跳不动，多来几个回合就能解决。跳完之后可以用ipinfo.io自查一下IP是否发生变化。

不过必须承认，物联卡用的人与日俱增，IP的“纯净度”也在肉眼可见地缩水。低危赛道拿全国跳应对绰绰有余；但创业、国学这类高危赛道，还是别省钱了，上纯净IP吧。

**购买IP节点**
如果上述方案都无法满足需求，那就直接购置IP节点。截流团队买共享节点就行，成本友好；自然流团队建议下血本买独享纯净节点，网络这一环算是锁死了。到时候要是还卡在推广上，那问题就只可能出在账号、设备、模板这三个环节里，排查范围一下子收窄很多。

国内号配国内节点，外国号配外国节点，别混用。

**软路由**
原理不多解释，百度一搜就有。只需知道它适合大体量团队：一个场地能开出几十个WiFi，也就意味着几十个独立IP。

# 四、两个关键认知

## 1. 没有绝对公式

上面的所有定论，都是为节省新手的时间而刻意“武断”的。如果不给出明确边界，很多人会在选型上反复纠结，日子就这么白白耗掉了。

我拿苹果举例，我说了7p起步，可5s真的不行吗？也不是不行。但拿5s去发内容，📕又不傻，你觉得它能给你推流吗？这个问题的本质是：设备越强越好、账号越老越好、IP越纯粹越好，并没有一个“及格线”。也有不少人拿私人老号连WiFi，照样跑出流量。但作为一个把自己定位为“真诚利他”的博主，我还是想劝一句：准备工作做到七八分就开干，想都是问题，做才有答案。

## 2. 出问题先按流程筛查

内容不过推广时，十有八九离不开这四个变量：设备、网络、账号、模板。可以按下面的清单挨个排查：

- 上号前有没有双清刷机？
- 有没有可能同一个IP下挂了几十台设备，被平台反作弊盯上？
- 购入的IP确定性如何？
- 账号本身是否有历史违规记录？
- 养号是不是没养到位？
- 内容模板是不是该换代了？
- 批量克隆软件是否调校妥当？

为什么我一直强调设备拉满、账号资产、干净IP？因为这样可以快速做排除法。比如你手里是苹果15、独享纯净节点、拦截老号，随手拍都能过推广，那么大流量还进不来，剩下的结论只有一个：模板拖后腿。换模板，仅此而已。
