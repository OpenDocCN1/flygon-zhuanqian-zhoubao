# 当平台忘了为谁服务，野心就会反噬自己

最近一条关于阿里巴巴高层的访谈，在行业里炸开了锅。蔡崇信直言不讳地承认了一个迟到的反思：我们曾经把注意力放错了地方。

他说，真正应该放在第一位的，从来不是商家、不是广告主，而是真正打开 App 买东西的普通用户。而过去很长一段时间，平台的动作和决策，并没有把用户体验做到极致。

“我们疏忽了真正的使用者是谁。”这句话听起来平淡，却直指核心。是的，增长模型跑偏了，内部的 KPI 和生态逻辑，慢慢盖过了用户最朴素的需求 —— 快、顺、值、好用。

结果就是，用户感受到了疏离，活跃度在波动，信任在消耗。现在回头看，这份迟到的觉醒，有点像自作自受。

蔡崇信把这种后果总结得很克制，也很残酷：我们有点自食其果。

从一家以用户为中心起家的电商帝国，到被迫承认“忘了客户是谁”，这个转折本身就是最有力的警示。平台再大，商业模式再复杂，最终都得回到一个原点：产品好不好用，体验值不值得留。
