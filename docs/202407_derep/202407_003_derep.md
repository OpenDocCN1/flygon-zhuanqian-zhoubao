# 5万本金，怎么一步步做到年赚百万？

分享人：千易  
发布时间：2024年7月23日

这篇来自龙哥盟的深度内容，拿到了266个赞。核心讲的是：很多人不是不努力，而是卡在“不知道该做什么项目”和“不知道怎么判断项目靠不靠谱”这两件事上。作者用亲身实战总结了一套筛选和评估项目的逻辑，专门帮大家解决这两个难题。

```
今天给大家分享的是选项目的底层方法论，也是我过去这么多年创业的经验总结，这套方法论帮我 3 次用 5W 资金做到年利润 100W，我觉得能够帮助很多人拿到结果。再过去的两年中，我也测试了多个项目，用这套方法没有亏过钱，基本都能跑通从 0 到 1。
```
