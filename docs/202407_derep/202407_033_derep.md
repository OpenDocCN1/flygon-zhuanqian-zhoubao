# ('最近在 AI 培训上看到的商业机会！', (2, 20))

我是乔帮主，先和各位打个招呼。今天想分享的是，过去三个月我在AI培训圈里看到的一些实打实的机会。如果你正准备做AI培训或AI知识付费，这篇值得你花几分钟读完。

从五月份起，这三个月我基本没闲着：
线下连着开了两期《AI实战训练营》；
飞了一趟成都，在《独立老师IP研习社》现场做了分享；
在龙哥盟的《培训赛道10倍赋能闭门会》上，也聊了我的一线观察；
还在老板圈的《AI双域流量系统变现》课上做了分享；
前前后后，线上线下加起来参加了十几次AI交流活动；
自己这边，也推出了两门新课，一门是《AI编程（爬虫）》，另一门是《AI亲子训练营：让AI成为孩子的良师益友》；
接下来，线上版的《AI实战训练营》和一门全新AI课也在路上。

说实话，虽然我一直在AI第一线，但AI的更新速度快到令人咋舌，连我的学习速度都有点追不上了。不过回头看这三个月的表现，我对自己的这份成绩单还算满意。

上周亲子营刚上线，就有圈友问我：“乔帮主，你怎么做起小孩教育了？”其实我没转行。我一直认为，所有行业用AI的核心都是同一件事——提示词编程。亲子训练营只是把这个核心用在了家庭教育、孩子学习和成长上，换了个场景而已。

那我为什么非要扎进垂直领域？原因很简单：大而全的通用AI培训，红利期正在肉眼可见地退潮。与其继续做泛泛而谈的通识课，不如在细分场景里把课做深、做透。

关于接下来的机会，我梳理出四个判断：
一是，通用型AI课程的黄金期已过，未来属于垂直场景的深度内容；
二是，线上培训必然会成为大家的必争之地，先卡位的人更占便宜；
三是，AI培训的方向会越来越多，AI+育儿、AI+编程、AI+办公等等，每个细分赛道都值得重做一遍；
四是，做这个事一定要流量先行，课程可以边卖边迭代，千万别等课程完美了再上线。
