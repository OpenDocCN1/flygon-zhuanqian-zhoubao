## 用 ChatGPT 搭出价值百万的选品分析工具，程序小白也能做到

作者： 易焘

日期：2024-07-03

完全不懂写代码的人，有没有可能不用自己动手敲一行代码、也不用自己排查 Bug，就借助 ChatGPT 批量做出实用的 Python 工具？

正值 Code Interpreter 问世一周年，我忽然想起这个在赚钱圈里讨论得并不热闹，却极具分量的能力。Code Interpreter 能自主生成代码、在沙盒里执行并自行修正，最终完成指定任务。思路很简单：先让 ChatGPT 借助 Code Interpreter 去跑通一个它理论上能处理的典型任务。跑通的那一刻，就意味着它已经在临时环境里写出了可用的 Python 流程。接下来，把这个已验证的执行思路抽出来，再让它按照同样的逻辑，为你定制一套能在本地电脑上跑、能处理更大数据量、能应对更复杂场景的代码。
