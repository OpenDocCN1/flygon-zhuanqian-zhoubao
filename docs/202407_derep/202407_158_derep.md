# ('怎么才叫懂业务？', (2, 10))

究竟达到什么程度，才算真正摸透一个业务？这个问题，恐怕许多职场人都在心底反复琢磨过。

最近在“龙哥的收藏夹”里读到一篇相关分享（2024-07-10），读罢颇有感触。文章没有急着抛出标准答案，而是留下了一个很值得玩味的思考入口。如果你也想一探究竟，可以点开原文看看：[https://mp.weixin.qq.com/s/eOJ9qBzBhHEKvLmtplTpFQ](https://mp.weixin.qq.com/s/eOJ9qBzBhHEKvLmtplTpFQ)

在我看来，懂业务绝不等于熟练操作流程、随口抛出术语，而是能看清业务背后的底层逻辑与真正目标。至于具体该怎么衡量，或许每个人都有自己的答案。
