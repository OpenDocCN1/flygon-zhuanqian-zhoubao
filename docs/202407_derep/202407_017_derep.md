# ('如何通过增加触达次数提升私域知识付费的复购率', (2, 24))

你有没有发现，做知识付费的人，最头疼的往往不是“怎么让人第一次掏钱”，而是“怎么让人掏完钱之后还愿意继续掏”？

第一次成交可能是运气，是文案，是冲动。但复购，才是私域真正的试金石。

最近我看到一位在这个领域深耕了两年半的实战派——根源老师，分享了一套他的真实打法。他目前和明白老师、陈雪老师一起运营“日新月异俱乐部”，年度利润稳定在七位数，会员的净增长和复购数据都很亮眼。

他这次讲的核心，就一句话：**私域的二次转化，关键在于提升触达次数。**

听起来简单，但很多人根本做不到。因为大部分人卖完一次就“消失”了，等到下一次想推新品才冒出来，用户早就把你忘了。

根源老师是拿一个真实学员的提问案例来拆解的。他没有讲玄乎的理论，全是自己踩过坑之后的实操经验。怎么做触达、什么频率、用什么内容、怎么让用户不反感，这些都是他反复验证过的。

如果你也在做知识付费，或者正在经营私域，建议认真看完这篇分享。哪怕只学到一两个点，可能就能让你的复购率上一个台阶。
