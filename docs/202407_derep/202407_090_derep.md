# 帮人从莆田系医院讨回损失，居然是一条高收益副业？

> 你可能想不到，维权这件事，不仅能帮人挽回损失，还能让自己赚到可观的收入。

最近看到一位叫“周末”的老圈友分享，他靠这个项目，直接从打工人转型成了创业者。先说说他的背景：本科念的是兽医专业，后来自学转行互联网，毕业进了腾讯，做了五年产品经理。副业这条路，他是通过赚钱有术打开的认知，从此发现赚钱的门道远比想象中多。

这几年他尝试过的项目几乎个个赚钱：
- 撸货：抢茅台、手机、纪念币；
- 知乎好物：一篇带货文章做到千万级GMV；
- 抖店无货源：单店月利润破十万；
- 游戏推广：零基础两个月，单条视频播放量超200万。

不过他说，比赚钱更值钱的，是认识了一帮志同道合的朋友，还找到了合伙人。

去年，他靠着维权项目（之前发过精华帖）真正完成了身份转变。很多圈友在他的协助下，成功从莆田系私人医院拿回了被骗的钱。

那这个项目到底怎么发现、怎么操作？他把完整拆解都放在了这篇文档里，想深入了解的朋友可以直接去看：[`t.zsxq.com/zE6ed`](https://t.zsxq.com/zE6ed) 以及 [`g9hkgjr2ny.feishu.cn/docx/QC2adiuKAoO6qfxHbMMcpKzynJd?from=from_copylink`](https://g9hkgjr2ny.feishu.cn/docx/QC2adiuKAoO6qfxHbMMcpKzynJd?from=from_copylink)

评论区里也有不少人在讨论：
有人说“周老板很靠谱”，还有人担心“客户会不会跑单”——作者回应说这种情况极少，他们会和客户建立很强的信任，还会用钩子一步步引导，毕竟双方是利益共同体。也有个别杠精质疑“把维权当生意，三观有问题”，但作者一句话怼了回去：客户被骗钱了，我帮他们拿回来，助人为乐还能赚钱，哪里有问题？
