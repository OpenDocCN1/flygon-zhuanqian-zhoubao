# 我的 2024 上半年复盘

先自我介绍下，我是轻舟。

回头看这半年，年初定下的两件大事，都在按预期往前跑。

一件是清债。原本计划今年把20万的负债全部还掉，现在差不多已经还了一半，剩余部分按目前节奏，年底前有希望能都结清。

另一件是减重。减肥这件事，我真是把能试的方法都试过了，始终没看到明显效果。早就有心去那种封闭式训练营，但当时经济条件不允许，就一直搁置着。今年6月总算如愿入营，进去27天，体重降了17斤。

为什么这半年忽然变得这么顺？我觉得核心转折是二月底开始做AI写作变现。在赚钱平台上，我找到了真正适合自己的一条路，既能保证每个月有收入拿去还债，还能在赚钱之外，有余力去训练营专心减肥。就这样，还钱和瘦身两件事，居然同时向前推进了。

当然，过程中也有不少困惑和卡顿。详细的一些经历和问题，我都写在飞书文档里了，想看完整版的朋友可以点这里：https://riupvml5qjl.feishu.cn/docx/C5mQdfl88oLiOTxjGQXcfk1an6f?from=from_copylink

如果大家有类似经历或者建议，也欢迎一起交流。当时评论区还有朋友说我这算一举多得，也有人认为不一定非得去减脂营，方法用对的话在家一样能瘦。想想也是挺有道理，关键还是找到适合自己的节奏。
