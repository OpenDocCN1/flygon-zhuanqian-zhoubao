# ('全面复盘我的一次失败', (2, 12))

我把自己最惨的一次失败，从头到尾扒开写给你看

说实话，这是我头一回在社区发这么长的帖子，真心盼着各位圈友能赏光读一读。我自认是赚钱圈里混得最差的一类人——没有稳定收入，天天在找项目、换方向，满脑子都是不确定。要是你也正卡在挑项目的岔路口，也正满心迷茫，那我敢说，这篇复盘多少能给你一点真实有用的参考。

文章写得很白，没有任何美化，全是我一个字一个字敲出来的真实经历。正文大约两千五百字，还配了好多过程截图和记录，希望你能耐着性子看到最后。每个句子都经过反复打磨，不掺一点水分。

完整版我已经转存到飞书了，想看的直接点链接：[`maes23mxkpz.feishu.cn/docx/XwSndGpDsoXBeXxjTB9c3HPynve`](https://maes23mxkpz.feishu.cn/docx/XwSndGpDsoXBeXxjTB9c3HPynve)

帖子发出来后，评论区也热闹得很。有朋友冒出来说“我才是那个最底层最失败的”，我回了句“您有六百多人关注呢，太低调了”，结果对方说“根本没用，都是风向标涨的粉，一分钱没赚”。还有人夸我敢想敢做，有人鼓劲说“搞个项目，瞬间起飞”，也有圈友安慰道“只要还没下牌桌，一切就都有机会”，最后还有位小伙伴简单说了句“加油”。

这一条条留言，让我觉得暴露失败也没那么难堪。毕竟，最差也不过如此，接下来每一步都是向上走。
