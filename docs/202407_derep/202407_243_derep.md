# ('怎样通过 ChatGPT 编写 Python 爬虫工具，赚钱 AI 编程航海带给我们的潜在机会？', (2, 50))

最近，我报名参加了龙哥盟组织的“AI编程（爬虫）”出海活动。其实在参加之前，我就已经在用ChatGPT做编程尝试了，可以说它帮我实现了不少过去想做但一直没落地的小产品。这次参加航海，主要是想跟着教练的思路和手册，系统补一补AI编程方面的盲区，争取用ChatGPT做出更多实用的东西。于是就有了下面这一连串的动手记录。

完整的实践内容都在这里了，包含：

- 用ChatGPT写爬虫，抓取公众号文章；
- 用ChatGPT写爬虫，批量下载百度图片；
- 搞定验证码校验，爬取亚马逊商品；
- 绕过反自动化检测，抓取小红书笔记；
- 改写爬虫逻辑，抓取知乎热榜；
- 打造一个专门生成爬虫程序的GPTs；
- 把爬虫程序封装成产品，以及背后可能存在的商业机会。
