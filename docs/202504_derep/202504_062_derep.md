# 纳瓦尔摊牌了：这就是他对幸福的终极答案

上周，一篇关于纳瓦尔人生哲学的整理在圈子里疯传，点赞数已经破五十四。作者是龙哥的收藏夹，发布于2025年4月15日。原文链接：[`www.yuque.com/for_lazy/zhoubao/so5hdxqrd4ze6rz7`](https://www.yuque.com/for_lazy/zhoubao/so5hdxqrd4ze6rz7)

纳瓦尔把话说得异常透彻，幸福其实只有两个方向可以选。

第一种，是真的去拿。你想要的房子、车子、自由职业、被动收入，全都到手，物质层面的匮乏被彻底填满，满足感自然就来了。

第二种，则是反过来做减法。你干脆从根上就不去要那些东西，欲望本身被拿掉，外物自然就不再能左右你的心情。高兴与否，不再取决于拥有多少。

这就是纳瓦尔的经典判断：要么拥有你想要的一切，要么直接不再想要。

评论区里最高赞的留言一针见血：
彩笺 : 要么你根本不想要那些东西，赞。
