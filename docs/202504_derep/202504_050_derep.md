# ('(11 赞)看榜单（6）Top AI by Revenue503', (2, 34))

最近读刘小排老师对AI产品的分析，挺受触动的。我给自己定了个新习惯：每天挑一个榜单上的AI产品，认真拆一遍。碰巧看到“良辰美”已经在这条路上跑起来了，用的正是刘老师那套“翻石头”提问框架——越看越觉得，这才是把产品看透的好办法。于是我也打算开始“每日一品”，并且把过程公开晒出来。真心希望圈友们帮忙盯一盯，多给我点真实反馈，我好随时调整方向，跟大家一块往前走。

今天拆的是YourTeacher AI。它瞄准的是一群中级语言学习者：明明能读能写，一到开口就卡壳。而它给出的方案简单直接——用AI陪练，便宜、方便，还能顺着你的水平走。它能跑出来，关键就两个动作：一是跟社交媒体上的网红合作，把流量引过来；二是特别听用户的话，反馈一来就改进。这两招撑起了它的增长。

当然，它也不是没有毛病。技术上的稳定性还差点意思，定价策略也有点挑人，而且对完全零基础的初学者来说，门槛并不算低。这些地方都有继续打磨的空间。

要是有人想照着它的路子做一款竞品，得先想清楚：技术能不能跟上，合作伙伴能不能搞定，品牌认知怎么重建。这些都不是轻松事。但机会也藏在它的短处里——把它的长处留下来，再补上它没做好的部分，比如把课程体系做更完整，定价更灵活一点，或者把新技术嫁接到体验里去。

说到底，要不要做类似的产品、能不能做成，关键是两件事：一是你对自己要投入的资源心里有数，二是你愿不愿意长期坚持，并且真的热爱这件事。缺了后者，再好的模型也转不起来。
