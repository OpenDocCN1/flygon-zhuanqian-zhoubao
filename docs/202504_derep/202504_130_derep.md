# 从程序媛到小红书电商主业：两年副业试错，我终于把副业扶正了

大家好，我是汐汐，也有人叫我汐然。以前大家都叫我“啷里个浪”，这个昵称让不少朋友都尴尬了好久，索性改过来了～

主业线我原本是做研发的程序员，后来内部竞聘转岗，开始帮研发总监管团队。副业这条线，我一直扎在小红书电商上。最近正式递交了离职，把小红书做成了主业，现在在生财的联合办公空间开启轻创业的新阶段。

回头看，正好是我加入生财满两周年。去年三月我去参加了线下航海家见面会，当时给自己立下的小目标，今天算是兑现了。于是来交一份复盘作业。

这篇笔记主要是聊聊我这两年在生财里的成长轨迹，以及从小白到小红书爆单的实操经验和踩过的坑，希望对正在做副业的朋友能有点参考价值。
