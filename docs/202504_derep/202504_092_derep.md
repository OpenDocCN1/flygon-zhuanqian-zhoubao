# ('(精华帖)(45 赞)游戏网站如何获取更多游戏？', (2, 26))

最近关注游戏站的朋友越来越多了，尤其是在 AI 应用与 Web 网站航海活动里，大家对这个方向热情很高。我研究游戏站也有一段时间了，今天想结合这次航海，聊聊自己的一点心得。

这篇文章主要想帮大家解决一个核心问题：游戏从哪来？也就是游戏供给。把这块理清楚，你就能打开 iframe 游戏的新思路。当然，供给只是第一步，真正让网站跑起来，后面怎么获取流量才是关键。
