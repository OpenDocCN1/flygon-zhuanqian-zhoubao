# 副业翻倍赚钱了，为什么更焦虑？关于收入波动、身份迷茫和未来不确定性的答案

日期：2025-04-17

原始提问来自一位互联网行业的前从业者：

“我之前在互联网公司，年收入曾做到40-50万，后来行业下滑到30多万，去年11月失业。现在和朋友一起把量化交易跑通了，主要做黄金交易，当下月入约6万，年收入预计60-70万。合伙人负责日常，我手上有了空闲时间。

现在纠结三条路：1、回去找份年薪30万左右的稳定工作；2、在生财找个新赛道深耕，做成第二个主业；3、继续放大量化交易盘子。

家庭月开销2-3万。最大的困扰是：收入会不会说没就没，职业身份找不到归属感，未来完全看不准。”

针对这三个痛点，给出以下拆解：

**一、先把“职业身份缺失”这个问题解开**

这种空落感，本质是工业化时代的教育惯性。应试和流水线体系教会我们：人必须先有一个标签，程序员、运营、产品、设计师，然后再去匹配对应的岗位和薪资。

现在要跳出这个叙事。现实里并没有固定的职业，只有持续创造价值的人。

别再问：我是程序员我该干嘛？我该做什么工作？

要换成老板思维：我是价值的创造者，我的目标是什么，我需要坚守什么信念，要实现它我得补哪些技能，要整合哪些资源，要混进哪个圈子？

身份不是公司给的头衔，是你自己创造价值的方式。

**二、收入不稳和未来不确定，其实是同一件事**

先承认一个事实：这个世界的不确定性无处不在。从底层到顶端，几乎都在波动。唯一稳定的，是选择躺平的人，那种稳定本质是贫穷的稳定，是他们已经接受了收入几乎不增长的现实。

所有想向上走的人，都必须和不确定性共处。我自己也不例外。怎么相处，可以参考这几点：

1/ 短期波动不可避免，而且无法精确预测。短期的时间长度因人而异，对有人是几周，对有人是一年，对有人是几年。但拉长时间线看，3-5年、5-10年的大趋势，确定性是非常强的。技术驱动、贸易驱动、市场经济、用户价值、连接效率、审美升级、多快好省，这些底层逻辑长期有效。

2/ 选方向的核心是顺应长期规律。把精力用在和长期趋势共振的事情上，短期的噪音自然可以忽略。前辈说过一句很有穿透力的话：短期靠策略，中期靠战略，长期靠做个好人。做个好人，在这里的含义就是长期主义：利他、真诚、感恩，符合人性和市场底层规律的行为。

3/ 主动拥抱不确定，把它变成杠杆。回到你的选择题：回公司拿30万年薪，还是自己开辟新赛道，还是把量化盘子做大。如果是我，我会选择不确定性更大的一条路。因为不确定意味着向上突破的空间，更有机会冲到年入百万以上。而它的下限，是你现在能接受的。

4/ 最后的决定权在你。现实的经济压力摆在面前，需要你自己权衡。选定之后，就别再纠结对错。把对错的评判换成行动，用行动让当下的选择变得正确。

焦虑的根源不是钱不够，而是你还在用旧的身份系统去解释新的人生阶段。

放下职业标签，做价值创造者；接受短期波动，锚定长期规律；拥抱不确定性，而不是逃避它。祝顺利。
