# 毕业一年零资源零人脉，我是怎么靠赚钱有术走出来的

作者：张微笑 | 2025-04-17

去年这个时候我还在为毕业后的路发愁，如今已经在赚钱社区待满一年，现在是一名自由职业者，主攻小红书虚拟资料的变现。

同龄人还在迷茫要不要考研、要不要回去考编的时候，赚钱给我的是踏实的前路感。我很清楚自己想往哪走，也知道下一步该怎么走。赚钱的价值就在于把普通人起步的门槛压到几乎为零。我自己以前就是餐厅里端盘子的服务员，也是在富士康流水线上当过一颗螺丝钉。那个圈子里根本看不到什么“搞钱思路”，是赚钱让我第一次真正看见了外面世界的机会。

这篇笔记我专门写给刚入圈的新手看，里面大概讲了5个点：

1. 怎么去挖掘那些能直接变现的信息差
2. 做项目过程中新手最容易掉进去的坑
3. 没有背景怎么依然能得到圈内前辈大佬的带一下
4. 如何通过复盘和输出，让自己变得越来越值钱
5. 加入赚钱之后你可能会遇到的“副作用”
