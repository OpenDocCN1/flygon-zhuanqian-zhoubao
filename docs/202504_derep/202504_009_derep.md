# ('(34 赞)从离职待业到自由职业者，我的赚钱使用指南', (2, 28))

标题：从被裁待业到自由职业，她这份“赚钱使用指南”值得人手一份

如果你现在正处在“没工作、没方向、没副业”的迷茫期，不妨看看长沙圈友竹子的故事。

竹子目前的身份是：AI自媒体博主，同时也在做YouTube AI内容出海。但她刚接触龙哥盟时，却是另一副模样——因为公司业务调整被“优化”，没有副业经验，典型的互联网搞钱小白。

2023年4月18日，她选择了加入龙哥盟。这个决定，让她的人生方向盘开始转动。从最初被迫待业在家，到现在一年能赚到六位数，竹子说虽然和圈里的大佬没法比，但能不再依靠打工养活自己，她已经非常开心了。

更令她欣慰的是，自己的商业思维被彻底打开，整个人都有了底气，甚至放话：就算以后不打卡上班，也照样饿不着。她常开玩笑把这里叫作“搞钱大学”。

加入两年多，竹子深度参与了很多项目：她当过5轮志愿者，做过1次领队和1次航海教练，航海项目更是跟满了16期。这一路走来，她的心态发生了很大变化，于是专门整理了一份“赚钱使用指南”，想送给刚进圈的新朋友。
