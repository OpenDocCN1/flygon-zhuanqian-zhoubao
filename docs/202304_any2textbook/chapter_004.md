
# 第 4 章 创业层级 —— 从卖货到建生态的阶梯

## 学习目标

- 理解创业七层级
- 掌握创业层级决定利润天花板定理
- 掌握创业层级评估法

## 4.1 创业的七层阶梯

想象你正在爬一栋七层的楼。每一层看到的风景不同，能做的生意也不同——这不是一个平面的赛跑，而是一段垂直的攀登。创业不是在同一水平线上比谁跑得快，而是在七级台阶上比谁爬得高。你可以暂时在某一层停留、修整、甚至小步后退，但真正意义上的"进步"，只有一个标准：你是否站到了更高的层级上。

这个类比的关键在于：**层级决定视野，视野决定选择，选择决定利润**。一楼做的是流量生意，三楼做的是产品生意，五楼做的是生态生意，七楼做的则是"见天地、见众生、见自己"的格局生意。每一层都有其独特的商业模式、竞争壁垒和利润结构，而你的企业能长多大、能赚多少，根本上由你所在的那个层级决定。

## 4.3 创业七层级：定义与边界

> [P001, p.5] "流量型业务、产品型业务、头部类目圈、行业、建生态、推动领域、见天地见众生见自己。"

这段话来自对创业商业模式的深度观察，它勾勒出一条从低到高的演进路径。我们先把它拆开，看看每一级台阶对应什么样的业务形态。

**创业七层级定义**（来源：《创业层级评估法》）

| 层级 | 名称 | 业务形态描述 |
|------|------|--------------|
| 第一级 | 流量型业务 | 靠流量变现，货架思维，卖货赚钱 |
| 第二级 | 产品型业务 | 打造有竞争力的产品，以产品力驱动增长 |
| 第三级 | 头部类目圈 | 在某个细分品类做到头部，形成品牌效应 |
| 第四级 | 行业 | 从单品扩展到行业解决方案，覆盖更多客户 |
| 第五级 | 建生态 | 搭建平台或生态，让外部参与者共同创造价值 |
| 第六级 | 推动领域 | 影响整个领域的规则、标准或基础设施 |
| 第七级 | 见天地见众生见自己 | 超越具体业务，承担社会使命，与时代共振 |

这张表展示了七个层级从"卖货"到"建生态"再到"见天地"的完整阶梯。每一级的跃迁不是简单的规模扩张，而是**商业模式的质变**——你在第一级赚的是差价，在第五级赚的是平台服务费，在第七级赚的是影响力与信任。

那么这个框架要解决什么问题？让我们回到创业者的核心困惑：**为什么有些人辛辛苦苦做了十年生意，利润还是不如别人一个新点子？**答案就藏在层级里。你如果在第一级，做得再勤奋，天花板就摆在那里；你如果在第五级，哪怕收入暂时波动，利润空间也远大于第一级。

## 4.4 利润天花板定理

> [P001, p.5] "你创业的层级决定利润的天花板。"

这句话朴素但极其重要。它告诉我们一个残酷的事实：**利润不是你努力程度的函数，而是你所在层级的函数**。

**利润天花板定理**（来源：《创业层级评估法》）

$$
\text{Profit}_{\max} = f(\text{Layer})
$$

$$
\text{Layer}_1 < \text{Layer}_3 < \text{Layer}_5 \implies \text{Profit}_{\max,1} < \text{Profit}_{\max,3} < \text{Profit}_{\max,5}
$$

第一个公式展示了利润上限与创业层级之间的函数关系：你的最大可能利润不是一个固定数字，而是由你所在层级决定的一个上限。第二行则把这个关系具体化——层级越高，利润天花板越高，且这个排序是严格的。

这个定理的实践含义是什么？它意味着很多创业者"累死累活不赚钱"不是能力问题，而是**层级问题**。你在第一级做流量生意，利润天花板可能就是百万级；你做到第三级做头部品类，天花板上升到千万级；你做到第五级建生态，天花板可以到百亿级。同一个团队、同样的努力程度，换一个更高的层级，利润空间完全不同。

这也解释了一个常见的现象：为什么有些公司收入很大却不赚钱？因为它们虽然收入规模大，但所在层级的利润结构太薄——比如纯流量分销，毛利被上游挤压、下游分走，自己只拿一个搬运费。收入的"量"不等于利润的"质"，层级才是决定利润质量的核心变量。

## 4.5 收入可波动但层级必须增加定理

> [P001, p.5] "收入可以波动但创业层级一定要增加。没有进步就是退步。"

这条定理是前一条的推论，但更加强调**动态视角**。利润天花板决定你"能赚多少"，而这条定理决定你"该往哪走"。

**收入可波动但层级必须增加定理**（来源：《创业层级评估法》）

$$
\forall t: \text{Layer}(t+1) \geq \text{Layer}(t)
$$

$$
\text{if } \text{Layer}(t+1) = \text{Layer}(t), \text{ then } \text{RelativeProgress}(t+1) = 0
$$

第一个公式展示了层级随时间演化的单调性要求：不论收入如何起落，创业层级在任何相邻时间点之间只能不变或上升，不能下降。第二个公式则揭示了一个更微妙的判断——如果你停留在同一层级，那么相对进步就是零，"没有进步就是退步"。

这个定理给创业者的启示是两方面的：

- **收入波动是允许的**。市场有周期性，产品有生命周期，收入短期下滑不可怕，只要你的层级在上升，长期利润空间就在扩大。
- **层级停滞是危险的**。如果你连续多年在同一层级打转，即使收入稳定，也意味着你在相对退步——因为竞争对手在往上走，行业整体在往上走，你原地踏步就等于被超越。

所以这条定理本质上是给创业者一个**战略罗盘**：每当面临重大决策时，问自己一个问题——这个选择是让我往更高层级走，还是让我在原来的层级里打转？前者是投资，后者是消耗。

## 4.6 创业层级评估法

> [P001, p.5] "以是否提升创业层级、避免低水平重复作为评价标准。"

有了前两条定理，我们就需要一个**可操作的工具**来落地执行。创业层级评估法就是这样一个决策工具。

**创业层级评估法**（来源：《创业层级评估法》）

```
Algorithm 1: 创业层级六步评估法
1. 识别当前业务所处层级（对照七层级定义）
2. 列出当前所有战略项目和资源投入
3. 对每个项目判断：它是否有助于提升到更高层级？
4. 标记所有"低水平重复"项目（留在同一层级的项目）
5. 重新分配资源：减少低水平重复，增加层级跃迁投入
6. 定期（季度/年度）重新评估层级变化
```

这段伪代码展示了一个系统化的决策流程。它把"是否提升层级"作为唯一评价标准，帮助创业者从日常的忙碌中抽离出来，看清哪些工作是在"爬楼梯"、哪些只是"原地跑步"。

评估法的核心价值在于**打破虚假的勤奋**。很多创业者每天很忙，但忙的都是第一级的活：谈客户、发货、对账、催款。这些事当然要做，但如果你把所有时间都花在这里，你就永远留在第一级。评估法逼迫你回答：**你今天的忙碌，是在为下一级台阶铺路，还是在原地重复昨天的动作？**

实际操作中，你可以对每一个项目问四个问题：

1. 这个项目做到最好，能把我带到哪个层级？
2. 如果放弃这个项目，我的层级会下降吗？
3. 在当前资源下，是否存在能更快提升层级的路径？
4. 我是否有意无意地在用"忙碌"掩盖"层级的停滞"？

## 4.7 多源对照

创业层级框架在目前的素材中主要由单一来源支撑（P001），但它的方法论内核与其他经典创业理论存在可对照之处。

### 共识

- 创业存在不同的"质"的层次，而非单一的量的竞争；
- 利润上限由结构性因素（层级/模式/生态位）决定，而非单纯的努力；
- 战略评估的核心标准是结构性进步，而非短期收入变化。

### 分歧

- [需要补充文献] 经典创业理论（如《精益创业》）更强调"快速试错"和"迭代"，而层级框架更强调"方向性跃迁"。前者关注"如何更快地跑"，后者关注"是否在正确的阶梯上跑"。二者可以互补，但优先级不同：层级框架认为"方向对了再谈速度"。
- [需要补充文献] 也有一些观点认为"层级"不是线性的，而是网络状的——企业可以通过组合多个中层级业务来创造超越单一层级的天花板。这一视角在素材中未涉及，可作为后续补充方向。

## 4.8 设计中的取舍

**为什么不用"收入规模"或"利润额"作为创业层级的划分标准？**

因为收入规模是结果，不是结构。一家年营收 1 亿的流量分销商，和一家年营收 5000 万的生态平台，前者收入更高但层级更低。如果我们用收入做标准，会得出"这家公司很成功"的错误结论。而用层级做标准，我们能看清：流量分销商的天花板就在那儿，平台的天花板远在其上。所以层级是"图纸"，收入是"施工进度"——图纸决定了楼能盖多高，进度只是当下进展。

**这种设计的 trade-off 是什么？**

层级框架的最大优点是指引性强：它给"什么算进步"提供了一个清晰的判断标准。但代价是它**牺牲了细分维度**——同一层级内部也有巨大差异（同样是产品型业务，有的做日用品，有的做医疗器械），层级框架无法捕捉这些差异。另一个代价是它天然偏向"做大"的叙事，可能让一些"小而美"的创业者感到压力；但反过来，也可以解释为：小而美也可以做到较高的层级（比如在一个细分领域做到"见天地"），层级不等于规模。
