# 闲鱼卖二手书：我是怎么做到高客单 + 数据化选品的



## 闲鱼二手书项目复盘：高客单玩法与数据选品思路

作者：莫凡
发布时间：2023-11-28

在赚钱潜水已经超过三年，每天抽空看精华帖，多次参与航海项目，其中不乏 TK 和闲鱼二手书。

最初加入赚钱只是为了开拓视野，没想到顺手做下来也赚了将近十万，非常感恩这个圈子。

TK 航海阶段的收获：创作者基金累计约 4.8 万，孵化出 84.6 万粉丝和 45.3 万粉丝两个大号，外加一堆小号。后来因父亲需要治疗，精力跟不上转型带货，就把项目暂时放下了。

转战闲鱼二手书航海后，已经是第三次上船，深耕了五个月左右。截止目前累计成交超 3000 单，总销售额 169112 元，净利润大约 44814.06 元。放在副业范畴里，这条路还能再走好几年。

特别感谢一路带路的前辈，老瞿、小嵩、华少等老师，没有他们指路很难这么快上手。

今天想把自己在「二手书高客单选品」和「数据化快速选品」上的一些实操心得整理出来分享给大家。

由于内容细节比较多，我把完整的方法论整理在了飞书文档里：[`nrsagciwti.feishu.cn/docx/KIIxdokwYoE4uax1Tk4ceTBxnlf?from=from_copylink`](https://nrsagciwti.feishu.cn/docx/KIIxdokwYoE4uax1Tk4ceTBxnlf?from=from_copylink)
