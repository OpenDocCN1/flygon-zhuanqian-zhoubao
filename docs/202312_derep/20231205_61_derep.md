# 個人養老金為什麼能退稅？這篇把邏輯講明白了

時間點很重要：如果你想在今年享受稅收優惠，記住繳費截止日是2023年12月31日，實際的退稅是次年才會發生。

先說結論，個人養老金能退稅，本質上是國家用稅收優惠來推動第三支柱養老，為現行的養老保障體系補位。

這個政策為何會出現？背後有幾層現實壓力。

第一層是人口結構的變化。生育率持續走低，人均壽命不斷延長，老年人口占比快速攀升。第七次人口普查數據顯示，2020年時60歲及以上人口已佔18.7%，65歲及以上佔13.5%，中國正邁向深度老齡化。十年間老年人口增加了8640萬，預計到2030年還將再增加2.23億。同時少子化趨勢明顯，2021年出生人口跌至1062萬的歷史新低，相較2016年下滑43.6%。勞動力縮減與養老需求擴大同時發生，現有體系承壓加大。

第二層是現有保障體系的缺口。長期以來，我國主要依靠基本養老保險加企業年金再加個人儲蓄的三層結構來支撐養老。但在老齡化加深的背景下，這樣的模式難以完全覆蓋未來支付缺口。十四五規劃明確提出要發展多層次多支柱的養老保險體系，提升企業年金覆蓋率，規範發展養老第三支柱，讓整體體系更均衡更完善。

第三層是支付可持續性的考量。當養老金領取人持續增多、繳費人相對減少時，財政和企業的負擔會越發沉重。鼓勵個人提前為自己的退休生活儲備資金，有助於分散國家與企業的支出壓力，形成個人自助與國家助助相結合的模式。

第四層是制度學習借鑒。早在我國推動之前，美國的401k計劃、澳大利亞的超級年金等成熟的個人賬戶制，已經證明了通過稅優引導個人自願儲蓄的可行性。這些國外的實踐為國內設計個人養老金制度提供了參考框架。

2022年11月25日，人社部、財政部、國家稅務總局聯合發布先行城市名單後，個人養老金正式成為在基本養老保險之外，額外增加的一條補充性養老渠道。參與者既能為晚年築起資金緩衝，也能享受國家給出的稅收優惠政策，實現自律儲蓄與福利回饋的雙重效果。
