# 草根零背景创业，90%的人都倒下了，我是怎么扛过来的

工作整十年，创业也满六年了。好久没在生财说话，最近趁着这个节点，停下来花了一个月梳理经历，又用一周时间把笔记写成了长文。

从零起步，没有人脉没有资源，家里甚至一度捉襟见肘。在创业这条几乎九成都要被淘汰的路上，我到底靠什么活了下来？这次想把一路踩过的雷摊开说清楚。

里面聊的不是鸡汤，是真正掉过坑里的实操复盘：
变现是怎么被折腾出来的坑，股权谈判里差点翻车的教训，战略方向选错一次代价有多大，以及财富积累这条路上走了多少弯路。

我是阿may。过去在社区里写过11篇精华帖，也曾靠9颗龙珠换来10万块的启动。目前把完整的心得整理到了飞书文档，里面有更细的拆解和避坑清单。

想走草根创业这条路的，可以去看看。希望能帮你少绕一点弯。
