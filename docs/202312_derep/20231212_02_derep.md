# ('做直播带货团队，股权结构到底应该怎么搭？', (2, 22))

做直播带货的团队怎么设计股权架构？这个问题其实问的是：你的钱到底该用什么样的主体去收？

我是昊布斯，在西安做天使投资，早年花过一百万上各种老板课，管企业将近二十年，旅游、软件、设计施工、新媒体都干过，亲手做过两家两千万营收的高新技术企业，辅导过三十多家创业公司，也投过五家互联网公司。

现在我基本把主营公司交给别人打理，算轻度财务自由，主要做企业咨询，帮中小企业诊断合伙、股权、薪酬这些事。

说实话，现在很多做直播和跨境电商的朋友，风险意识还停留在很原始的阶段。金税四期上线后，直播带货的钱还往个人卡里进，一年流水几百万几千万，看着吓人。我身边不少人跑过来跟我说：老师，我钱太多了，每天乌泱乌泱往个人卡里进，心里发慌，晚上睡不着。

民营企业倒闭的原因五花八门，但归根到底就两条：要么死在钱上，要么死在税上。死在钱上是自己折腾死的，死在税上是被人揪住尾巴整死的。

这几年主播被查的案例还少吗？你用什么东西收钱，决定了你该注册什么主体，这一点千万马虎不得。

先说个人卡收款，这是最危险的玩法。做跨境电商的，很多人的钱先到香港，再通过第三方结算机构转回内地个人卡。你想找专业的人做税务筹划，很难找，因为大多数做跨境电商的人，连资金怎么进、怎么回都讲不清楚，你怎么指望他帮你设计？

你的货卖给老外，老外付美元或其它外币，这些钱通常进香港公司。但香港的钱回不了内地，怎么办？找第三方机构，第三方再把钱打到你的个人账户。你可能会觉得，第三方能处理这事，肯定正规合法吧？我告诉你，这些第三方很多是干洗钱的，还有做对敲的。这种环节本身就埋着雷，风险系数爆表。一旦被查，拔出萝卜带出泥，你几十年的积累全搭进去，等于给共同富裕捐了个大礼包。所以个人卡收款，这是第一个大坑。

那用公司收款呢？税负又太重。25%的企业所得税，再叠加20%的个人所得税，利润基本就没了，等于白干。那怎么办？

我的建议是：去注册个体工商户，用个体户来收款。有人会说，个体户不是只能收百来万吗？我一年几千万流水，不照样累进税率？

这就错了。个体户和个体户不一样。在一些特定的税务洼地注册个体户，别说几百万，几千万都能进，而且税负很低。普通的个体户按累计收入计税，但还有核定征收这条路。你说核定征收不是取消了吗？我只能说，有人的地方就有江湖。

具体是哪个洼地？我不好在这里公开说。一旦我说出来，大家全涌过去，洼地就被填平了，不再是洼地。而且不同类型要选不同洼地——劳务类、工程类、咨询类、贸易类、电商类，各自适配的地方不一样。有需要的朋友可以找我，我会先问你做什么类型、流水多少、每年进多少钱，再帮你推荐合适的洼地。
