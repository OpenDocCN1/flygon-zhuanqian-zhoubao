# 上手小红书做旅游变现，两周时间就已经赚到三千多

这篇实操复盘来自田新一。

在副业深耕三年后，他今年正式把自己定位为流量商做全职创业，目前手上在跑的赛道涵盖教育、奢侈品以及沪牌。最近他跟随赚钱的旅游航海项目入局小红书旅游赛道，数据跑出来了：最近一周引流超60人，成交9单，累计服务客户10余人次，客单利润在200-300元区间，两周累计利润已突破3000元。

在旅游航海还在进行中，他计划接下来系统拆解一次完整的操盘路径，从目的地挑选、内容库搭建、内容制作、引流方法到成交转化五个环节展开分享。特别是目的地怎么选、内容该怎么做会是重点篇幅，欢迎同行一起交流打磨。
