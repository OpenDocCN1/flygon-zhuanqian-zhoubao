# 第一部分 先想动机，比技巧更重要

先聊驱动力，我觉得它比任何方法都关键。我们可以模仿别人的结果，却很难复制别人的初心。

我的建议是，在没搞懂这一点之前别轻易上手。

核心要问自己：你做这个账号的终极目的到底是什么？

如果第一反应就是“为了赚钱”，基本就没想明白。

只是看到别人赚钱，自己也想试试。

现实情况是：超过九成做不下去的人，都缺少“以终为始”的思考。

看不清终局，过程中就会反复迷茫，最后放弃。

我把做号的动机大致分为五层：

![](img/e1a411a840d6389887a6136de7740129.png)

五层没有高低之分，只是心态、目标和打法完全不一样。

## 第一层 为求职和升迁服务

没错，绝大多数人主业仍是打工人，自媒体只是副业。

如果你本身在市场运营相关岗位，或者想转行到这个赛道，小红书是最快的敲门砖。

怎么操作？很直白，做合集型号。

比如书单合集、影视合集、工具合集之类，只要掌握内容生产方法，数据通常都很漂亮。

我见过一个案例，她把高赞图文合集直接放进简历：

累计XX万阅读量，XXXXX个赞藏，熟悉选题、文案、排版、运营等创作链路，网感强

![](img/ac19c537b01532adcc4f19fad9b578ec.png)

这种作品集放在求职材料里非常吸睛。

我带市场负责人时，也更倾向招聘有个人号经验的人，沟通顺畅思维也更灵活。

投入产出比很高，无需打造人设，也不用拍图拍视频。文案能借助AI生成，流程化操作，就能得到一个数据好看的号。

## 第二层 副业接单变现

这是大多数人入局的理由。

平台对新手确实友好，接单也相对简单。

但要先搞清楚，接广告需要哪些前提？想接哪类广告？每月期望收入多少？

先说门槛，大致三点：

有人设、有可售卖的广告位、数据稳定且过关。

能看出，第一层的账号基本达不到这个门槛。

因此想走广告路线，就别再纠结“为什么数据不错却接不到单”。

再说广告类型，比如做读书知识类，能接的基本就图书和课程两类。

预算普遍不高，尤其是图书，多为置换，几万粉的预算可能只有几百块。

想接更高预算的广告，做法不是在原赛道死磕，而是换赛道。

否则发一百篇，也只是在感动自己。

目标不同，反推的行为完全不同。

## 第三层 电商带货

如果你有货源，或有电商经验，这是最匹配的方向。

开店选品卖货的具体打法可另行参考。

选品直接决定内容打法。

比如卖纸巾这种大众刚需，图文堆量即可，点赞收藏多少不影响成交。

![](img/9f8144a5bd4984b0b78e2d8c862cb5f9.png)

如果是卖高颜值的小物件，打法就不同了，封面必须足够吸睛。

![](img/edacdb3298e8460b52f03ec41800909e.png)

如果是卖知识付费或资料类，内容一定要干货十足、利他性强。

不同品类侧重点不同，整体上带货笔记更看重评论而非赞藏，且更新频率要很高。因为不需要粉丝关注，只要刷到就产生购买冲动即可。

## 第四层 私域导流

核心不是在站内接广或卖货，而是把流量导到私域再完成变现。

比如卖虚拟资料、付费社群、知识星球、高客单产品、公众号涨粉等。

若主阵地在公众号，就持续发布征稿、投稿、写作赚钱的笔记。

思路打开后，重心甚至不在内容，而在投放。

批量寻找性价比高的素人博主投放，就能快速实现引流。几百粉的素人就能带来爆文，费用低投产比高。

![](img/9fbe4029e75b5d9f39981670fc0e543b.png)

你只需把精力放在运营好承接平台。

再说高客单产品。

小众高客单受众窄，很难出爆款。策略就是做精准粉丝覆盖，用50-100篇笔记把行业关键词全部占领。

平台最大流量来自搜索，用户搜索关键词能搜到你的内容，就会持续带来精准咨询。

## 第五层 改变人生

这层和第二层听起来像，其实心态和目标完全不同。

你已经不满足副业小钱，而是要把它做成个人事业：打造IP、打通公私域、构建多条变现线。

把它当成生意，就要有启动资金、商业模式、现金流测算。

投入程度、长线规划、内容调性都会不一样。

这条路有门槛，需要一定积累。

也许五成的人能从平台赚到钱，但只有一成能真正改变人生。

可以从副业变现过渡到事业型，不用急。

我从2016年注册，2019年才认真玩，当时靠摄影兴趣发内容，靠一篇爆款涨到1w+，但动机不够强，后期就荒废了。

![](img/aa96b22a6e90f62185f0b8bfe2b1570e.png)

去年我很清楚，这次不是玩玩，而是要做成个人事业。所以投入、规划、内容选择都和以前不同。

我见过很多朋友做不下去，本质不是方法问题，而是没问过自己：真的全力以赴了吗？

我非常看重以终为始，先想清楚why，why想透了，动机才会足够强。

新手常犯三个错：

错误1：把平台当朋友圈发

平台已不是INS美图时代，已进化成生活指南。核心是利他！利他！利他！

你的内容能给人什么价值？实用、情绪、谈资？不要自嗨流水账。你不是明星，没人想看【你的】生活，大家想看【生活经验】。

错误2：靠灵感瞎发

笔记生产是科学流程，有套路。只靠灵感做专业内容，很容易早期被打击，难以持续。

新号有沙盒机制，持续更新才能提升权重，平台才持续推流。

错误3：没人设，只涨赞不涨粉

判断标准：笔记换个人发会不会很违和？如果谁发都一样，可替代性太高，为什么要关注你？

## 3、文案是灵魂

字数限制1000字内，实际约700字可用。别写流水账，实用、逻辑、情绪、有趣、真实，五项占两项即可。

# 第四部分 起号最头疼的定位问题怎么解？

早期困扰大家的不是怎么写笔记，而是定位。

精简成一句话：基于我XXX的优势，我是一个能帮助XXX解决XXX问题的XXX人

比如，基于我8年营销和小红书10W+涨粉经验，我是一个能帮助自媒体创业者解决小红书获客变现问题的导师。

写出自己的定位即可。

若实在不知道自己擅长什么，深挖三个问题：

1、别人夸过你的点有哪些？请别人说出你的三个具体优点
2、别人愿不愿意为这些优点付费？
3、目前你在哪些事上花时间/花钱最多？

优势不自知，但别人的评价和你的投入是骗不了人的。

## 定位案例

有同学问：想做学习博主，但学历成绩普通怎么办？

这困扰不止学习博主独有。

我的思路很简单：关键不在于【你会什么】，而在于【你能持续学什么】、【用户想看什么】。

看这个账号：

![](img/d163240f1740e9c1dc38a069aa32ef5c.png)

她在更新油管大神的高效自我管理系列，把方法总结翻译过来。

![](img/8a37f91ea8440a0dc9d068ec2525a97e.png)

不需要原创，有大神背书，且可无限找优质博主持续更新。她笔记不多，点赞5.5万，粉丝3K+。

怎么变现？目前可接广，后续结合方法发PLOG，慢慢过渡到实践日常，走干货PLOG路线，相关内容占比从10%到50%，账号就立住了。

总结就是信息差+持续学习+用户需求。别担心自己现在不够厉害，花一周钻研就能超过80%的人，足够分享了。

我在生财里看过太多“现学现卖”的例子，印象最深的两个就是，一个人把路人P掉的技巧用在小红书上，一周就把第一个千元到手；还有个零基础的小白照着AI小和尚说话的教程学，一口气拿下自媒体的首个四位数。

从这两个案例里，我提炼出新手真正能落地的五条底层逻辑：

1、别等准备好了再出发。很多时候“没经验”“还不够强”只是在给自己找借口。上面那两位都是先定目标再倒推要学什么，先干起来，边做边补课。技能不需要精通，能用就行。绝大多数工具类技能，从0到能用只花1-2天就够了，这个水平已经甩开大部分观望的人了。

2、技能再小，只要有人需要就能变现。你做自媒体一直没钱，问自己一个问题：能帮谁解决什么痛点？需求找对了，变现自然会跟上。

3、站在别人的肩膀上抄作业，红海反而更安全。很多人怕“别人都做了我还做什么”，但信息差从来不缺。新手去红海，相当于有人把路都踩平了。你可以直接去星球检索想学的方向，搬别人成体系的教程来学，遇到卡点再搜，跑通一次流程后，你得到的经验和信心远比赚的那几百上千块值钱。且别小看这点小钱，它是你第一次独立闭环的证明，比打工赚同样数额意义大得多。

4、把第一次赚钱的过程讲出来，就是下一次涨势的起点。一个小成绩能写成经验贴，能发到星球拿精华，能聊收徒、也能卖工具。把这一单成功用内容放大，自媒体的赚钱雪球就开始滚了。后来会有更多和你一样的新手来找你付费，你越分享越专业，从小白成长为头部，如此正循环。

5、想都是问题，做才有答案。不少新手太爱护自己的账号，怕这怕那，一个月只发一两条，根本起不来。新手号试错成本几乎为零，不行就重开。把账号当成一群猪来养，越多越好，目标是让它产奶，而不是花大把时间给猪梳毛。

2、关于内容模型
账号长什么样，其实是有套路的。我常用的721模型：20%干货合集 + 70%专业经验 + 10%人设故事

1、前期起号：20%干货合集。
就是在你领域里做信息整合的盘点。 
比如女性成长：优质女生都在听的8个播客合集
摄影：小白也能用的九种万能构图
两性情感：性知识不该从片子里学，3本入门好书分享
这类清单体笔记，容易出圈，适合冷启动。

![](img/3ea3da2fb789bdf468a85aa93f2a1a19.png)

2、中期涨粉：70%专业经验。
干货合集来赞快来粉慢，中期要把亲身经历、踩过的坑结合专业点输出，这类内容才能带来稳定涨粉。

![](img/0359249911ac616af73886225617b2f9.png)

3、后期巩固：10%人设故事。
新手期千万别一上来就讲个人生活，大多数人还不认识你。等有几万粉、有铁粉后，再适度释放人设故事，效果才好。

# 五、想拍口播/vlog，如何低成本做桌面博主？

这是圈友问得最多的问题之一：
小翼，我想拍vlog，但家太丑拿不出手怎么办？
其实很简单，只要一个书桌改造到位，下班后就能做副业，不再担心失业。

## 1、想做博主？从桌面改造开始！
很多上班族想转博主，又怕知识不够、环境不好。没必要整屋翻新，一个周末把书桌改造好就够了。
分享读书笔记、学习日常、职场心得、生活感悟都行。

![](img/61f9a0e13194034f2a31f3da3bb3db1f.png)
就算你不是大咖，治愈舒服的画面也会让人看下去。而且桌面博主的变现比纯口播更容易，桌面上的每个物件都是天然的广告位。
新手在小红书接广告的渠道，我已经整理好：

![](img/75d6f9951ccd61955f1fad39edbefc96.png)
坚持更新，商家会主动来找你，一条视频几千块很正常。

## 2、我的桌面改造过程及好物清单
改造顺序建议：墙纸 → 墙面装饰 → 桌面布局 → 氛围感好物 四步走
下面是我精挑细选的8个基础好物，直接抄作业：

1、墙纸：
建议选加厚0.6cm的，手残也不会起皱，颜色白色或暖色系最百搭。

![](img/3a4094354a20c75a33b9e770bcd5ff1f.png)

2、墙面装饰：
毛毡洞洞板 + 复古海报 + 风景画的组合，方便粘贴，氛围感瞬间拉满。

![](img/53ad2ec45bf6d613c5dccf194d968776.png)

3、桌面增高架：
人手一个必备，提升层次感，打造三层空间。

![](img/9df453f8b07095006de26cc07fc6239f.png)

4、台灯：
我用的是明基护眼灯，颜值在线还护眼。

![](img/0b8bb0eab92a1ac8ba2c6176220f1b6b.png)

6、豆瓣日历：
每天翻一页有仪式感，还能解锁电影，和台灯底座完美适配。

![](img/fbba4079275e7a422447e3034c5c4d85.png)

7、充电线收纳器：
挂在桌下，凌乱的数据线全消失。

![](img/cde7c49a326aeaeecee530edde9610e3.png)

8、计时器：
既能看时间又能正反计时，几块钱解决。

![](img/f631762d53c3ff64cf4441b53efecb9c.png)

## 3、小白快速上手桌面vlog的四步法
主题 + 脚本 + 拍摄 + 剪辑，逐项拆解：

1、主题：
新手容易拍成流水账，读者无收获自然没记忆。这里我直接给你全网验证过的爆款选题，挑一个适合自己的做出第一条爆款就行：

![](img/f7e2235b8d4d2c8cd2580ae089c51ddb.png)

2、脚本：
这是核心，不能省。先写稿，再为每句话匹配场景。机位的核心有三个维度：高度、方向、距离。高度分平视俯视仰视，方向分左右中，距离分特写近景中景远景。

![](img/87b41fbef5d0e04fe906cda3e9d9e97b.png)
新手先掌握平视+近景就够了。脚本模板我也直接放出来：

![](img/108be91530bf46051be10b3b9ead718a.png)

3、拍摄：
一部手机 + 落地三脚架 + 桌面支架即可，拍完用统一滤镜调色。有条件再上相机，手机可当提词器用。

![](img/31e0828b65f519398be955cb081b2e1f.png)

4、剪辑：
用剪映完成，封面用黄油相机做。记住两点：
每个场景控制在3-5秒，勤换镜头保持新鲜感；
拍摄没有捷径，拆解优秀作品后多练习。
