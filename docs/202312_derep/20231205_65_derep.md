# 合作伙伴之间怎么用制度分配利益

合伙创业，最怕的不是项目难做，而是分利时各说各话。

商业世界里，真正的常态并不是台前的体面和风光，更多时候，是一次次选择之后不得不面对的灰头土脸与心里没底。这时候，比能力更重要的，是你选了什么样的搭档，以及你们之间用什么样的规则协作。

规则立得住，利益才分得清。与其等到矛盾爆发再靠人情硬撑，不如从一开始就把“怎么分”写进制度里，让双方都有明确的预期。这不是斤斤计较，而是对合作关系的长远负责。
