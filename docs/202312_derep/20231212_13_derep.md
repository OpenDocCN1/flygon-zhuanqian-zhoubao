# 清迈旅居指南

去清迈旅居，第一次该从哪里入手？别急，我把自己两个月的亲身经历整理成了一份新手指南，从行前准备、找住宿（特别是数字游民共居空间）、热门景点，到怎么在当地建立社交圈，一次讲清楚。

先自我介绍一下，我叫小燕。之前那场数字游民大航海结束后没几个月，我就飞去了泰国，前后旅居了两个月，其中有一段时间就住在清迈。清迈可以说是很多自由职业者向往的地方，我这个数字游民自然也跟着去体验了一番。身边有朋友看完指南后感慨，这简直是一份超详细的出国旅行攻略。
