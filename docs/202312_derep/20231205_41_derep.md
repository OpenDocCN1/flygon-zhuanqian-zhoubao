# 美业IP月变现20W+，普通人也能复制的细分赛道玩法

都说行业卷，但卷有卷的活法。当大多数人挤在医美和生美的红海里贴身肉搏时，有人换了个姿势，在“问题性肌肤”这个细分赛道里悄悄做到了月入20W+。这期内容来自圈友夕子的实战复盘，希望给你一点新思路。

很多人看到“美业”就摇头，觉得普通人没机会。夕子却认为，只要把用户需求往下钻，依然有蓝海。她自己做的赛道叫“问题性肌肤管理”——不做那种洗洗脸、补补水的轻服务，而是针对性地解决痘痘、斑点、敏感、细纹等具体困扰。这正是她和传统医美门店最大的差异：别人给你做基础护理，我直接给你解决问题。

先说说她的背景。江西农村出身，踩着分数线考进211医学院。大学期间做过家教、服务员、摆摊，甚至去过东莞工厂当流水线工人。被盒子和机械动作折磨到怀疑人生，但心里有底：反正我将来要当医生。后来在三甲医院实习，偏偏对皮肤科情有独钟，即便轮转其他科室，也要抽空回去跟主任学。实习期间把学到的东西写成帖子发到网上，真的有人来找她咨询皮肤问题——但当时只给建议，不开药不卖货，纯粹为爱发电。

待了几年后，她发现公立医院开药太受限，不是激素就是抗生素，很多损容性皮肤病没有更好的手段。于是跳到广州一家大型私立机构，去了才发现自己成了“医美流水工”，咨询师开什么就做什么。后来因为一次院内团购意外赚了400多块，她索性离开了医院。2019年12月底，为了续社保和方便拿货，注册了公司。从一个人干到现在4人小团队，整整用了4年，没大起大落，但稳扎稳打。

项目模式用一句话说：线上远程帮求美者改善油、痘、敏、斑、衰老等皮肤问题，客单价1500+。线上咨询是基本盘，另外还延伸出线下医美项目合作和品牌广告。为什么能延伸？因为四年积累了上千个真实案例，这些案例就是做内容、做运营的弹药。她还能把这些经验赋能给同行——教她们做小红书、做私域、搭产品。

问题性肌肤和传统美容院不是一回事。医院排队两小时、看诊两分钟，能开的项目和药有限；不专业的医生长期开激素药膏，把皮肤搞成激素脸的比比皆是。而年轻消费者越来越懂成分、看效果，传统的洗脸敷面膜已经很难打动他们。所以这个赛道赚的是良心钱，也是成就钱。

启动成本高不高？分两种情况。线上启动、不开实体店，大概5万，包含学习拓客、朋友圈运营、专业知识、产品，重点先切痘痘肌和敏感肌。如果开实体皮肤管理店，10-30万左右，看城市。她朋友投了10万开祛痘店，现在月业绩10万+，利润率50%以上。关键是要先跑通小闭环，再复制放大。

用户从哪来？疫情没法线下拓客，她就做自媒体。最早在知乎写文章，用低价产品引流，一天5-8个新咨询。后来知乎渠道断了，2021年3月转战小红书，发现变现效率高得多，客单价也上去了，高峰时一天30个咨询。后来平台限制引流，流量降了，但老顾客转介绍多，转介绍成交率50%以上。现在她还顺着平台调性做直播带货，卖自家产品。内容拓客成本低、信任感强，还不容易卷价格，值得中小美业老板坚持做。

内容怎么做？有套路。

首先是定位。套一个公式：“为xx人群提供xx元的xx服务”。比如spa店，为25岁以上女性提供598元的放松身心灵spa；皮肤管理店，主推祛痘项目，用户10岁以上，客单价1000+。一句话说清自己是谁，别贪多。

然后是账号装修和养号。前7天，前三天只刷不发，点赞评论关注，像真人一样；第4-7天发点生活日常，不用发专业内容。7天后正式运营，重点做三件事：昵称带行业关键词（方便被搜索），个性签名写经历、背书和定位，但别写价格——写价格容易劝退用户，平台也会觉得你在营销。头像用真人大头照。

接着是对标。有人一想到对标就头大，但这是最省力的捷径。找3万粉以内的同行账号10个，把它们的昵称、签名、头像、选题都拆下来放到表格里。每天往表格里丢几个，固定运营动作。最开始她也是自嗨，后来通过对标找到了用户思维。直接搜账号、搜领域关键词、看首页推送，把可借鉴的都记下来，再结合自己的想法，回到自己业务上。

![](img/10558a2e6e0af017abcc921702bd87ee.png) 比如纹眉，搜索纹眉，按用户来，挑10个3万粉以内的账号关注。然后看每个账号的作品，点赞过百的都可以作为对标对象。

![](img/b9d3463bdb490dddd166d1b23389df50.png) 再点开主页看个性签名，有可借鉴的也填进表格。这里有个半永久纹绣师的签名值得参考：“专注半永久，从业六年，美术院校毕业生，每天只约2位顾客，非流水线操作。”最后用价格表达很直观，但长期发展不建议写，可以放在助理号上发布。

![](img/a0e6782350f87cb5ff6a24719f15aed0.png) 哪怕现在用不上，以后做矩阵账号也用得着。置顶的两条内容也可以学：一条是“不用礼貌问价，xx元”，发用户对比照，最好有肖像权授权，愿意在小红书展示说明，还可以挂链接做预付款或面诊金，实现平台、用户、你三赢。另一条是前后对比图，美业最吃香的就是before和after。太血腥恐怖的图审核容易卡，别发。

![](img/89321d592d289e561c7766ed22b45627.png) 按这个流程选10个账号，每个账号选2个选题，就有20个选题，够发一个月。能完成这一步，就已经超过90%的同行。

有了对标表，制作内容就简单了。按选题、内容、标题、封面、发布内容、话题六个维度拆解。结尾记得埋钩子：“我的一个客户按我给的方案，从这样变成这样”，如果用户想要方案，可以留言区找我。内容要跟自己相关、跟用户相关，别人才想来链接你。

比如对标“方圆脸纹眉像整容一样”，你可以起标题：“瞬间改善方圆脸的整容纹眉秘诀”，可以用AI辅助生成标题。

![](img/ee285b2ba65b070c51af3d8debf38ab9.png) AI给了几个选项，挑一个中意的。封面用前后对比图，正文写你的设计理念，比如“以前小仙女迷恋一字眉，其实眉形要按脸型设计。亚洲骨相更适合弯月眉，一上脸顿时大气端庄，立体又显脸小。”注意先查敏感词，再配话题。

发布也有小技巧。进入创作中心，点“笔记灵感”再发布。

![](img/03d661490f24b841996a3a69a72e8bd8.png) 从笔记灵感里选一个相关话题，再进入创作中心。

![](img/09b04575d3cc173e8e035258cdbb3d28.png) 这样能蹭到官方流量，增加曝光。

引流也有技巧。别一上来就私信发微信号，那是平台重点打击的。可以挂店铺链接，个人号也能开通商品；建群，然后小助理号@用户发微信号，同时告诉用户加你有什么好处，比如送《美业人做自媒体IP运营指南》《不同眉形报价单》之类；小助理号发布联系方式并置顶；小红书号改成微信号。小助理号能帮你分担风险。坚持2个月，肯定有客户来找。如果来了客人没变现，回头看看聊天内容和朋友圈。

目前她矩阵5个号，3个新号，还没被封过，核心思路就是跟平台共赢。

转化和复购怎么做？模拟一下成交路径：用户从小红书找到你，加了微信；用户翻朋友圈，看你的人设、案例、价格；然后私聊咨询；你给出方案，用户选择买还是不买。不买就在朋友圈继续激活。朋友圈要发生活、工作、用户证言、服务过程，提前准备几条，有灵感就存起来。

咨询时也有成交流程：1发自我介绍；2问需求；3填咨询资料——不填的说明不心疼自己皮肤，不勉强，这也是筛选；4分析皮肤和产品，给用户价值，比如正确洗脸方式、哪些产品适合她；5给案例、列方案；6成交。

![](img/788e92eb34e96d63f156d4abb4aa5b21.png) 流程没建立前，她聊天东一句西一句。阶段一变纯客服，阶段二发问卷但周期太长，阶段三做成聊天SOP后，新诊一般当天就成交，快的半小时内。线下实体店因为用户已经到店，成交率更高，前提是项目确实有效果，服务流程也SOP化。

最后是赚钱系统的打造。第一步是解决产品和客源。她创业资金不到2万，从市面上挑了个线上线下都有点名气的品牌，靠它解决了很多用户问题。后来品牌政策变了，她改用大品牌带小品牌，把利润率拉高。新手找产品可以关注院线品牌的官方微信，找合作联系方式，别怕——你是甲方。

第二步是单人全链路。早上写文章引流，下午晚上接诊，还要自己打包发货。等跑通全链路，再慢慢组建团队、扩大规模。

以上，就是她从三甲医院离职到美业IP月变现20W+的完整路径。核心不在于追风口，而在于把细分人群的问题真真正正解决，然后通过内容放大。希望对在美业门口观望的你，有一点启发。

一路走来，真的挺累的，但总算是扛住了。想先谢谢自己没放弃，也谢谢每一位用户给的信任，还有身边亲友一直以来的支持。

**小团队作战**

去年夏天，一位特别靠谱的伙伴加入了我们。她一来，接诊这块的压力基本都被她分担掉了。现在她在皮肤问题上的专业度真的没话说，皮肤咨询管理师团队交给她带，我特别安心。

我现在主要focus在定方向、抓公司整体运营这些事上。

团队规模不大，真正干活的加起来5个人。其中有3位新同事是9月才来的，还在磨合期。这对我来说也是个考验：从单打独斗到带团队，各方面都得更规范化，还得给不同岗位把SOP建起来。

**嫁接实体**

做久了就发现，用户的需求其实很深。有些朋友的问题性皮肤，光靠涂涂抹抹根本解决不了，比如痘坑，得靠医美手段。所以我和一家很熟的机构合作，我负责提供流量，他们把交付接住。

最开始我也会自己接诊做治疗，后来实在忙不过来，就专心做流量，把专业交付交给更合适的人。

当然，我选合作方是有标准的——技术得跟我差不多，甚至比我还好。毕竟要对得起信任我的用户。

实体板块是另一笔营收，医美客单价高。有些在国外的用户，因为信任我，专门飞回来找我，单次消费能到10w+。线下业务也还是围绕皮肤来做。

不过话说回来，线下做得再好，我的基本盘也绝不能丢。

**普通人做IP的门槛**

很多新手卡在几个点上：不知道方向、不知道定位、不知道从哪下手；也容易忽略自己手上已有的资源，比如美业的朋友，明明手里有客户案例却不会用；还有就是输出内容坚持不下来。

怎么破？

第一，套个公式：为XX人群提供XXX元的XXX服务，先把定位定下来。

第二，把以前的客户资源整理一遍。如果没有客户案例，你自己就是最好的素材，记录自己的变化就行。

第三，一次把一个月的选题、脚本都定好，比如15条，统一拍。不想自己剪辑，就去闲鱼找人兼职，把对标账号丢过去就行。从最简单的口播开始。

还是那句老话——做好对标记录。只要对标做得够细，你会发现根本不缺内容，也不缺能变现的好内容。静下心来，朋友们，你真的可以！

**未来规划**

化妆品大盘是5000亿，再加上服务类美业，空间更大。我们这几百万几千万的营收，扔进去连毛毛雨都算不上。

关于自创品牌：做到现在，积累了不少用户，大家对于产品的要求也越来越高——品质、安全、有效、稳定，这些是最基本的。现在卖的是别人的牌子，今年特别强烈的想法就是做自己的品牌。好在身在广州，美妆资源得天独厚。去年就开始筹备了，注册商标、对接工厂，一步步来，目前已经到打样测试阶段。

关于结合线下实体店：我写过一篇文章叫《实体店的春天，快来啦》。美业里很多服务确实离不开实体店。等品牌出来之后，我会先去对接实体门店，给它们赋能。

这样一来，我相当于成了一个平台型选手。思路一打开，来者都是客呀！
