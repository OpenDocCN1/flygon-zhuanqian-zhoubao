# 短视频给了 O2O 新的机会：在美团总部分享的体会

2023年10月底，我到了美团总部，做了四个小时的线下分享。其实最早一次是2022年11月，当时隔着屏幕聊了两个小时，已经让美团的核心高管反复讨论了好几轮。一年后再见，我把过去几年的积累重新梳理了一遍，自己也明显觉得整个认知框架都跨了一个台阶。如果你想看本地生活领域的真实打法，这篇内容值得你读三遍以上。

先说说背景。2023年渐近尾声，头条系的生活服务业务正在冲击4000亿的年度目标，指向已经非常直白：就是要和美团正面抢商家、抢用户。接下来一年，双方大概率会硬碰硬。我作为两边都在接触的服务商，已经能感受到暗涌的竞争，那种拉扯感让团队最近也有些疲惫。

接下来，就是我当天分享的完整内容。

我从2020年7月开始做短视频本地生活，到现在三年多。很多服务商起起落落，但我应该算是这个赛道里坚持最久的人之一。我始终有一个判断：视频平台的流量爆发力极强，可它更适合做拉新，而不是做留存；流量用完很难再次复用，更别指望有多少自然的长尾。所以今年我们一直在追问一个问题：一个品牌或项目，凭什么在短视频本地生活里活得更久？所谓“活得久”，不是靠某一次爆红，而是要有一整条稳定持续的增长曲线。

先讲我给自己立下的两个标签。

第一个标签，我是这个领域里最肯写复盘的人。这些年我产出的运营笔记和方法论内容，不管数量还是传播范围，都算行业里的第一梯队。

第二个标签，我带的团队非常擅长短视频矩阵，而且执行力很猛。举一个例子，2023年4月到8月我们做军训夏令营，让孩子在7到21天里接受军事化训练，磨炼品性。4月份我们发了一万条短片，结果成交没出来，远远低于预期，于是马上换内容结构、换拍摄模板。5月发出三万条，线索量瞬间就上来了，订单量也一路上扬，热度一直持续到8月。整个过程里，我们始终信一件事：短视频和直播一定能带来生意。数据不好，肯定是哪个环节出了问题，那就去找出来改掉，再按新方法打一遍。

过去几年的成绩，可以用两个数字简单概括。第一，我们实打实服务过5000多家实体商户。第二，从2020年起，我们每年发出的视频从没少于100万条，2021年更是突破1000万条。大量重复的简单动作，让我们沉淀出了一套自己的判断标准：如果发了1000条视频还是没有任何产出，基本可以断定这个赛道不适合在短视频平台获客；发到1万条，能看清项目的转化漏斗到底通不通；发到10万条，品牌会开始在用户心里留下痕迹，品牌的规模效应会慢慢显现。

下面，是我这几年的七个重要认知转折。

第一个转折，是关于“榜单”的颠覆。2022年下半年，我连续四个月跟踪了两家平台上的吃喝玩乐热榜，结果发现两个体系里的上榜商户，重叠度居然从来没有高过5%。这个数字让我很震感。于是我开始思考另一个问题：一个从来没进过任何榜单的商户，凭什么靠十万条视频杀出来？事实是，无数叫不出名字的产品，正在通过短视频变成爆款。我自己的餐饮品牌就是例子，我们只靠两个人在做内容——一个拍素材和剪辑，一个做分发，结果在平台成交上超越了长沙一家非常有名的龙虾品牌。两个人打一个地方头部，这放在过去根本不敢想。

而且，越是不起眼的细分领域，越容易在短视频生态里闷声发财。我们服务过一个云连锁家政品牌，只有一百多个POI，但一个月能做到30多万的营收。我们做的事情非常简单：剪好视频，发给所有加盟商，发动他们一起发。这就是短视频给小型团队的机会——大品牌不一定能压住你，只要你有流量爆破的能力，完全可能弯道超车。

那段时间我刚从电商转过来，一度觉得短视频的力量太恐怖了，仿佛无所不能。我甚至放话，要把美团做过的事全部重新做一遍，甚至未来挑战它。但后来认真研究之后，发现短视频平台的流量逻辑和美团的流量逻辑并不一样，双方最多只是部分重叠。那些踩过的坑，说到底都是在为当时的认知不足买单。

第二个转折，是我们亏掉了一千五百万换来的教训。在美团生态中，一个人管理上千家商户也不稀奇，所以你可能觉得“同时交付500家”也没多难。但2021年，我们在短视频平台一共交付了4600家客户，峰值时同时处理500家，最后的结果却是巨亏。为什么？因为每个品类的表达方式完全不同。烤肉和小龙虾，看似都是餐食品类，但内容传播的核心情绪、画面节奏、受众关注点天差地别。500个客户，意味着要设计500套不同的内容方向，这种复杂程度不是线性增加，而是指数级上升。很多服务商压根没意识到这一点，哪怕是所谓的抖音老炮，陷进去也会赔个精光。短视频流量既能帮商户突破瓶颈，也能让商户快速倒下——根源就在于服务交付跟不上、产品能力撑不住。

第三个转折，是我重新理解了服务商的价值。2021年11月，平台下发新规，一夜之间切断了所有第三方团购小程序的服务通道，很多服务商当场没了生意。我们也开始被迫思考：如果不依赖平台闭环，实体生意还能不能重新做一遍？早前我们做蹦床项目，两个月就能打爆，但很快所有同行都开始1:1模仿。等整个行业被大家做熟之后，平台直接切掉第三方，只允许官方团购上线。那一刻我明白过来：如果只满足于在平台上把流量做到顶点，你的价值很快会被平台自己收走。服务商不该只做“短期波峰”，因为顶点到零可能只有一夜，甚至跌成负数。

第四个转折，是我确信只有爆品才拿得到流量。复盘完2021年的4600个客户后，我们有一个重要发现：成功爆火的项目里，90%和品牌没太多关系。它们能火，主要是产品本身在短视频生态里就带着内容属性。换句话说，能把商家引爆的不是品牌，而是产品。但这些已经爆过的商家，也几乎都没能做到第二次、第三次、第四次爆发，原因还是一样——90%的商家没有办法持续迭代出新的爆品。

所以现在我和品牌合作时，第一个判断条件就是：这个产品在短视频生态里，是不是自带流量？很多行业以前从不做短视频推广，还在用传统竞价或表单式的方式买线索，结果获客成本甚至比美团还高，用户反而不精准，还经常收到差评。比如装修行业，过去在美团上最常用的引流品是1块钱或9.9块的工程测量、设计图纸，如果把这个思路直接平移到短视频平台，差评率会高好几倍。两个平台的底层逻辑完全不同，引流品的打法也应该是两套逻辑。在装修这件事上，我们做产品组合：装修前提供工地摄像头，装修后提供霍尼韦尔的除甲醛产品——那种遇到甲醛会变色的膏体。把两个产品组合成引流品，效果出乎意料地好。

在美团，用户是带着明确需求来搜索的，本来就想找装修公司，也预期会拿折扣，所以低价引流的那个东西具体是什么并不重要。但短视频平台是内容找用户，你必须从某个具体的需求点切入，让用户先被内容吸引，再被产品说服。一旦理解这个区别，流量就变得好拿了，但紧接着又会撞上第五个墙。

第五个转折：没有供应链，你只是在帮别人做嫁衣。去年我们和生鲜供应链合作，商家采购我们的大闸蟹、小龙虾、蓝龙虾，我们免费帮他们做短视频引流。我们把流量端和供给端绑在一起，用爆品思路搭了一个新模式，去年这盘生意17个人做了1.6亿，净利1000万。但这个生意很快就越来越难。原因是我们没有切进供应链的深水区，没有掌握“坐庄能力”——一旦出现实力更强的人，他能用很小的成本把整盘生意端走。

蓝龙虾项目就是一个例子。我们这类互联网公司想做源头，于是去跟虾农签约，把虾空运到长沙，再分包给不同的品牌方。流程听上去很简单，真正做起来才发现，短视频的爆发力带来了极大的资金占用，供应商又分散，品质很难稳定。长沙做虾的品牌有非常苛刻的标准，比如单只重量上下浮动不能超过10克，超标的全部退回。我们一个人要对接十个养殖户，无论品质还是货盘的稳定度都容易出问题；更要命的是，养殖基地不在我们手上，源头不可控。流量爆发越猛，我们的掌控力越弱。虽然能赚钱，但资金链随时会断，别人也能轻易抄走模式。

家政领域也是同一个道理。去年11月到今年3月，我们把家政行业做成了爆款案例，是第一个把这个行业打爆的团队。合作的家政品牌在美团时代有一定知名度，但本质是一个靠加盟费赚钱的中介公司，服务没有统一标准，也没有可控的交付团队。流量一起来，客服和履约全乱了，最后只能被迫和别人合并。今年的某家政爆火品牌，其实正是吞并了这类中介公司、补上了交付能力，才真正跑了出来。这个故事再次验证了：没有供应链底牌，你做得越快，越可能给更大的玩家铺路。

第六个转折，是我意识到新的O2O时代正在到来。这个概念来自一位朋友的点拨，让我彻底重新审视了O2O在短视频时代的可能性。我们17个人就能在生鲜供应链上做出1.6个亿，5.5个人就能把家政行业打到第一，今年10月“51喝水”送水到家业务也做到了不亏钱完成冷启动。要知道，2015年的O2O想触达用户，无非是铺线下广告、发传单、做地推、买竞价排名。而现在，替你发传单、做地推的是素人和KOC。你只需要把内容准备好，分发给他们，自己抓好供应链，就能把项目从0干到1。这是上一代O2O创业者根本不敢想的事。

第七个转折，是关于时间维度的选择。我们不断起新盘，做成一个再换一个，表面上很热闹，可团队的精力一直在被零碎地消耗，盘子也没法持续做大。所以我们开始思考：什么样的行业值得扎下去干十年？我们的筛选标准很直接：能稳定经营3年以上，成交周期短于15天，单笔分成金额超过1000块钱。标准背后无非两条：第一，能快速得到结果；第二，别人不容易把你踢走。最后我们选定了到家赛道。今年9月，我正式加入天鹅到家。这家公司从PC时代到移动互联网再到短视频时代，一直保持敏锐，并且和我们团队的思考方式很合拍。

再展开讲讲短视频给各个行业带来的新变化。

生鲜水果是一个很典型的赛道。比如浩昌海鲜，当时短视频平台还不允许上架活物，我们就换了个办法，把大闸蟹标成9块9一只。视频发出去后，一夜卖掉了八千多份。定价策略也很重要：单只蟹负责引流，但用户大概率会买十只，剩下九只的成交不经过平台，门店毛利更高。按当时的进货价，六月黄成本4.9元，再算上10%的损耗，就算全部在平台成交，毛利仍接近10%。就算用户真的只买一只，也不亏，还能换来一个进店客户。绑蟹要成本，包装要成本，烹饪也要成本；我们把这些过程做成短视频内容，还原吃蟹的真实场景，用矩阵去放大。过去大家靠团购券找新客，我们是直接让产品自己说话。

家电和电动车也在变。海尔和台铃电动车，过去在美团生态里很难做推广，现在直接发冰箱抵用券、空调抵用券，再用短视频和直播去引流，例如满500减200的优惠。两个品牌都拿到了新的增量，不再靠信息流砸曝光。

男装里，七匹狼是第一个做爆的。它没有用什么高深打法，就是参考家电零售的逻辑，发袜子兑换券、衬衫券、外套券，用户买完到全国几百个门店核销。零售场景在短视频平台里就是个选品展示中心，利用流量把人引到店，再促进到店消费和升单。湖南品牌“新佳宜”也很典型：周年庆卖66抵99的券，一天就能卖出几十万单；平时卖4.9元的冰美式，把价格打到行业最低；还会上架19.9元一箱农夫山泉这种一看就有锚点的产品。只要不亏钱、能获客，自然有人走进来。

植发医美也值得一讲。传统模式下，雍和植发在美团拿一个客资大概要花5000块，对应的套餐价是13800；但在短视频平台上，获客成本只有五六百块，靠的是短视频内容加直播。氧颜蔻的做法更大胆：一天到两天内铺三千多条SEO短视频，然后开直播，把直播间的人员和气氛都拉满，形成闭环，第一个月就能日均播30万，冲刺时甚至到50万以上。可见，视频和直播让过去只能靠信息流硬抓用户的模式彻底变了，核心是场景还原。

保洁整理收纳同样是被短视频改变的行业。天鹅到家6月开始发力，10月份做到2000万；整得清从7月到现在做到近一个亿。后者的内容模板特别简单，只有五到十个模板轮换：一个阿姨对着镜头自拍，说我叫谁，现在在哪儿，做整理收纳多少年了，今天加入了整得清，已经做完几单。就这么一套内容，所有阿姨反复发，竟做成了3000万到4000万曝光，支付GMV接近一个亿。用短视频还原线下服务场景，确实可以给无数行业打开新世界。

另外，有两个数字都叫85%，放在一起看很有意思。一个数字是：订购家政服务的用户中，85%是24岁到40岁的女性。这个人群有高消费力、高复购率，也愿意接受新服务。另一个数字是：天鹅到家积累了六年的老用户，近三个月新增的数量居然比前六年加起来还多；目前每个月下单的人里，85%是从没在任何平台请过保洁的新用户。在过去的O2O周期里，这样的增长几乎无法想象。

最后再讲一讲长期阵地。短视频流量的确很凶，能集中爆破，但我观察下来，品牌和商铺想长期扎根，阵地还是美团和私域。比如线下餐饮，我们打了一轮短视频流量后，美团点评的评分会自然升到4.2、4.3，我们并没有额外投入一分钱。再比如“十三烧”，点评账号停了六个月，今年国庆我们做客流分析，发现抖音带来的客人只占30%，美团和点评占30%，另外40%是自然到店。这说明两个平台不是替代关系。美团和微信很像，用户会主动搜索、频繁打开、容易触达复购人群，所以它也许会成为未来商家经营私域的重要阵地之一。

短视频给出了一条最顺滑的从0到1爆破路径——它由三件事组成：基于地理位置的推荐流量、基于兴趣的精准推荐，以及站内搜索优化。用一套组合拳好好打，才能在这轮新O2O大潮里吃到真正的红利。

抖音的本地生活打法，核心就一个词：先把人找准，再把需求点透。

它厉害的地方在于地理围栏的玩法。系统会优先把内容推给 3-5 公里内的用户，而门店的落位本质上就是 POI。也就是说流量是锚定在单个 POI 上去发的，先把这一个圈子的人筛出来。等 POI 密度起来，网格变大后，兴趣算法就能在更大的范围内把目标人群全网罗到。

现在抖音的搜索体量早就超过百度了，这已经是行业共识。就拿我在做的干洗项目来说，订单来源非常清晰：抖音 SEO 贡献了一半，直播带单占 5% 左右，剩下的 45% 几乎全靠短视频的自然推荐在承接。

2020 年那会儿我很激进，想着用短视频把美团这样的巨头掀翻。后来看到全盘逻辑，才意识到短视频并不会彻底取代图文，二者更像是一种分工明确的共生关系，各自找到合适的活法。

### 超级平台时代已经过去，留存逻辑在重写

2022 年我对抖音在本地生活的进攻还是存疑的，觉得垂类平台终究会分一杯羹。现在我的判断变了，超级平台很难再诞生了。O2O 本质上像一条高速公路，基础设施和路基早被头部平台铺好了。剩下的事，是品牌方如何顺应内容形态的改变，去重塑自己的存在方式，本质上就是用户留存方式的迭代。

## 短视频本地生活的终局长什么样

2015、2016 年的 O2O，获客靠地推、靠小广告铺量。广告铺满一个城市就能打样，再复制到下一个城市、下一个大区。

抖音做的，本质上是把这套线下打法的逻辑搬进了短视频：高频触达、品类封杀，全部指向成交。

成交导向让内容表达也变了。过去追求唯美高级感，现在追求转化效率。用短视频矩阵把一个品类打穿，把流量效率做到极致。

我们的实操思路是先沉淀大量可复用的内容模板，批量剪辑分发，形成矩阵作战。然后不断迭代视频结构，沉淀成项目级的模板库。把拍摄场景拆解成标准化素材包，批量生产，最后搭起一套低成本的直播矩阵。

就目前来看，抖音本地生活正处于野蛮生长期，接下来就是把这套打法复制到更多行业，用短视频撬动不同赛道的增量。

至于终局，我认为缺不了两样东西：会做流量的能力，和能自己掌控的爆品供应链。

流量这块，说白了就是矩阵搭建+抖音 SEO 的长期布局，关键词、搜索占位都要做在前面。

供应链这块，核心是可复制的爆品。靠一个大 IP 养品牌太难了，过去那么多案例都证明 IP 难以复制。更现实的打法是用数量换确定性：一条不行就上 1 万条，10 万条总有一条能爆。用铺天盖地的小号矩阵，替代过去那种单点 IP 扛大盘的模式。李佳琦是用一个大 IP 带一堆品牌，未来更多是 N 个小号去养一个品牌。

供应链的掌控力也很重要。比如天鹅到家在每个城市的阿姨都是直营招聘、直营培训，我们不是中介，而是对服务标准和交付质量负责。

产品的微创新也是爆品的关键。举个例子，装修引流可以用除甲醛工具+装修摄像头，让用户随时在线监督工地进度，这就是服务上的微创新。

## 品牌在抖音本地生活的增长路径

### 稳定增长=短视频矩阵+低成本直播

我们现在的结论是，抖音的稳定增长来自短视频矩阵配合低成本直播。因为直播对主播和 IP 依赖度高，所以我们更倾向“重短视频，轻直播”的组合，降低对人的依赖。

### 品牌增长=弱 IP 运营+长期 SEO+私域闭环

增长要靠弱 IP 运营来降成本，用长期的 SEO 去吃长尾价值，最后用私域闭环把用户沉淀到微信、美团、点评等渠道。

具体路径分三步：

第一步是传播，用抖音 KOC 做种草，把话题和曝光率打出来。没有传播基础，后面成交就无从谈起。

第二步是占位，通过抖音 SEO 的系统布局+1+n 内容模板的放大，让同一信息从多个账号触达到用户。占位期大概 3-4 个月，累计 10 万条以上内容，这个品类在用户心智里就立住了，成为真正的抖品牌。

第三步是转化，把抖音来的用户沉淀为品牌的长期用户。

这就是我们这三年多在本地生活领域总结出的增长三步曲。
