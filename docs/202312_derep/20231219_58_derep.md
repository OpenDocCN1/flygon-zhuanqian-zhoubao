# 聪明赚钱的本质，是这9种思维在起作用

> 原文：[`www.yuque.com/for_lazy/thfiu8/snzddg5zbp0wqa27`](https://www.yuque.com/for_lazy/thfiu8/snzddg5zbp0wqa27)

大家好，我是刘宁培，也可以叫我宁老师，龙凤胎奶爸，常年在深圳，全国到处飞。

主营业务是企业咨询，核心做股权设计、经营管理和商业模式。

副业也折腾一点小投资，名牌加盟店开着，年底还去线下摆摊卖红包春联。

我是生财第二期就一直续费到现在的老成员，编号1748。

最近跟很多人聊下来发现一个规律：聪明的人赚钱看起来不费劲，越是拼命耗着干的人，往往越难积攒财富。

我见过不少基层同事，习惯用“没功劳也有苦劳”来安慰自己，但这种只靠苦力的模式，很难通往富裕。

与其硬扛，不如换个更聪明的打法，去做更有价值的事。

我长期观察一批做得不错的老板，发现他们在行动底层，基本都共享了这9种思维模式。

**1、利他思维**

一个人能走多远，取决于有多少人真心希望他成功。因为这种成功是让人获益的成功。

刘润在《底层逻辑》里用鸡、雀、鹰来比喻三种格局，特别有画面感。

鸡的格局：目光短浅，怕输怕被抢，总觉得别人的赢就是自己的输。合作时充满防备，宁愿自己扛也不愿共赢。

雀的格局：比鸡积极，但太急太浅。想单打独斗速战速决，结果把机会浪费在走弯路和内耗上。

鹰的格局：视野开阔，讲求共赢。愿意携手他人一起成长，看得见远方，明白合作才是长期制胜的关键。

书里反复强调，真正的胜利不是抢来的，是搭出来的。稻盛和夫的“一壶水”哲学也是同理，倒给别人，自己的水反而更满。

**2、分钱思维**

财散则人聚，财聚则人散。会不会分钱，是老板能不能留住人才的核心能力。

胖东来创始人杜创于1995年，在许昌把胖东来做起来，核心就是让利于民、服务于民。

他的做法很野：95%的利润用来分给员工，让员工真正成为股东，和公司一起赚、一起长。配套的培训和成长通道也做得很足。

反过来，一些新项目老板拿掉成本后，愿意跟操盘手五五、三七分，项目反而能活下来。而那种90分给自己、10分给对方的做法，通常没多久就散了。

分钱不是亏钱，是把利益绑定，让好人留下来，形成正循环。

**3、相互成就**

合作的本质是长期关系的建立，彼此成就是最好的养料。一旦偏离了这个逻辑，关系很难持久。

2005年苹果放弃IBM和摩托罗拉的方案，转向英特尔芯片。

对苹果来说，拿到了更强更省电的处理器；对英特尔来说，绑定了苹果这个顶级品牌，声誉和市场都跟着上去。典型双赢。

**4、重复思维**

高手和新手的最大差别：高手把一招练一千遍，新手一天想换一千招。

看大佬的打法往往很简单，靠的就是一招管用就反复做，反复迭代就变强。

《天龙八部》里的乔峰和慕容复就是例子。乔峰专研降龙十八掌，一招打透，战力无解。慕容复武学广博，却样样半吊子，模仿再像也成不了顶尖。

一招做到极致，远胜于一万招平庸。

**5、复利思维**

复利就是滚雪球，利上加利，常被称作世界第八大奇迹。

自媒体时代最典型的就是内容复利。很多创始人IP在各平台持续输出文字、视频、音频，时间越久，资产越厚。

**6、先予后取**

赚钱的核心逻辑是先给价值，再收回报。

企业不只是卖货，是在做价值交换。先解决客户的问题，满足需求，信任自然来，忠诚度就跟着来。

个人的路径也一样，先帮助、支持、贡献，良性循环才会启动。商业、人际、合作甚至公益，都通用这套规则。真正赚钱的是关系，不是单笔交易。

**7、战略思维**

选择大于努力，战略本质上就是选择的能力。

有钱人一直有钱，往往是因为会做长期取舍。战略不是看眼前哪个单更划算，而是把时间线拉长到三年五年去看。

单子多一万少一万不重要，今年多签一个少签一个也不重要。重要的是这三五年的积累，最后能不能得到你真正想要的。站得远，才知道当下该不该走。

**8、解决问题**

我身边有钱的人，几乎都有一手很强的破局能力。

别人卡住的问题，他们三言两语能点到要害，给出解法。这就是赚钱能力的内核——解决问题的能力。

市面上有人花10万块买亦仁一个小时，买的就是这个能力。

**9、善于去卖**

这个时代，卖得好的不一定是产品最好的，但一定是会卖的。

再好的产品不被看见，也就是个废品。高手都在卖，无论是卖产品、卖自己、卖方案、卖价值、卖梦想。

回头看你朋友圈里最成功的老板，会发现他们都很会讲、很会让客户买单。他们懂需求、会定位、会链接。
