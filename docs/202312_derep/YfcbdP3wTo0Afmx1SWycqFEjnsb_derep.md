# 单人操作年入30W，百度竞价冷门产品详细实操教程

大家好，我是绍辉。今天分享一个我亲手跑了两年的Baidu搜索广告玩法，收益稳定，每月入账两到三万，而且一个人就能全程操作。一年下来三十万，是可以实现的。

先介绍下自己。我老家在山西，19岁就下井挖煤，在矿上干了四年。2015年偶然看到QQ群里的网赚信息，从国企辞职，全职转行。2016年靠CPA挣到第一桶金，整整一百万。后来做过CPS、保健品、网店群等，现在专注Baidu的SEM投放和短视频带货。SEM这个方向，我做了两年，收益一直没垮。

为什么选这条路？以前做自然流量，最怕平台改规则、封号。后来想明白，不如直接买流量。Baidu的模式很简单：商家投广告，客户带着需求来搜，看到广告点进落地页，下单购买。Baidu按广告费办事，不会因为平台规则变动让你一夜归零。只要Baidu还在，这件事就能一直做。

我选的是小众品类，也就是竞争少的蓝海商品。目前这套玩法主要有三种类型。

第一类，电子资料。除实体商品外，像小吃配方、学科教程等都算。交付方式通常是图文或视频。我现在跑的一款奥数网课，今年7月光这一个品就赚了一万多。

![](img/3ab143a98b76e5771e354e98b5e5d324.png)

![](img/8ec06d43891c3250ec73a2f3522dc3d7.png)

客户从广告页进来后，落地页上会有详细说明，以及电话、微信、即时沟通入口。我还接了在线支付工具，客户能直接付款。现在的成交中，约两成靠付款工具自助下单，八成是加了微信后转化的。

收到订单，我就去电商平台找同款课程，买下来存进存储盘，然后快递给客户。目前同时跑的电子教程有80款。

第二类，本地服务，比如开锁这种日常需求。

![](img/a1b5366c2e665cd198f56b0915668d1b.png)

第三类，实体商品，常见的有虫草、野山参、花胶，利润高、复购强，适合沉淀私域，不过竞争也大，做到月入几十万的并不少。

## 怎么找品？

我主要跑电子教程，找品就用三个办法。

一是到电商平台搜“教程”“课程”“视频”等字眼，把结果收好。

![](img/1d8fb802f9eb12f78bc7c24c38cb65b3.png)

然后去Baidu查这些词，看有没有竞对在投广告。比如PLC教程，现在就有竞对在打，这种就可以记下来。继续翻，能找出很多类似的。

![](img/6491bed1c547211a521df668d7b1e2a8.png)

二是看店铺里的相关品。刚才说到的PLC教程，可以点进卖家主页，看看他还有其他什么货。

![](img/5a041ddf01f6aa6ad7145af9b1c44805.png)

这家店一共53个商品，逐个去Baidu查，只要有竞对投了，就记录。

![](img/0c11c7820cfe1a80dea4c79c54fccc05.png)

三是用5118挖词。这个站要会员，搜“教程”等词，导出词表。

![](img/5651b70d5def4b133407baec2c4241f9.png)

![](img/8240a4492fa80579798640d7e4b84703.png)

我手上这份是之前导出的。把每个词复制到Baidu里搜一遍，有竞对就记下。像“魔法剪头发接吻”这种词，直接忽略。工作量确实大，但值得做的品基本都在里面。

这三种方式，放在实体商品和本地服务上也通用。

找出品后，按以下标准筛选：

1. 必须有竞对在投。广告有成本，一直投说明有回报，没人愿意长期亏钱。
2. 单件毛利300以上。比如奥数课卖398，扣掉包装2元、存储盘20、书20、快递18，毛利338，达标。Baidu广告一单可能要两百，毛利太低会亏。
3. 电商平台销量过30。看销量排行，是为了验证需求。销量高意味着要的人多，太低的不要碰。

![](img/e1e5ce1e07ef65b3d8f927cf28407009.png)

4. Baidu内部选词工具显示，周均搜索量过30。先在Baidu营销平台装好软件，用开户账号登录。

![](img/3cc0d6e280b55596f2d273ae1dde7dcb.png)

进入这个软件后，找到“关键字”和“规划师”入口。

![](img/f26302f4dee6eddb76b56565c8a16b13.png)

填入“奥数”查一下，按从高到低把结果排好。

![](img/7829aca8cea9667f6a7106a20bd5721d.png)

显示“奥数”的周均搜索量是30，达标。搜索量越高，需求就越大。

![](img/cc3a042ce1ccf21cd99f57b771ff9997.png)

5. 竞对数量少于4。在Baidu搜“奥数课”，我看到3家在投，达标。竞对越少越好做。

前两条是硬指标，后面三条可以参考。当然全中更稳。

2\. 新建计划的时候，名称栏随手写个顺眼的就行。预算这块，我习惯把每个单品限到50，说白了就两层考量：一是提防同行故意刷量，二是防止某个不着调的词一夜之间把预算烧穿。底价填多少不太重要，真正说了算的是后面关键词那一层。扣费方式勾按点击计费。业务类别挑和自己的商品沾边的类目即可。单元名我统一标成“教程”，你可以把它看成计划下面挂的一个分栏。单元底价一样不用纠结，后期操作都是围绕关键词来定的。自动文案优化必须关掉——这功能一旦开着，系统就会擅自改创意，我曾经就被它把标题改成“免费”两个字，结果涌进来一大批只想白嫖的流量。

## 4.写创意

创意即展示给访客看的广告文案，目标是勾起点击欲，通常就是标题配上描述。

![](img/b97a33d52bb681c5b8eb56164d3421ac.png)

1.一个省力的路子是直接扒同行的创意，把他们文案里亮眼的词组和话术收集起来，慢慢养一个自己的素材库。下面这些是我过往整理出来的记录。

![](img/650b3e39a85362d1c0cff1965a57e517.png)

2.先进到“创意”标签页，接着点“添加”。

![](img/785a5ec7a2cd3de345229b2366fd6e0d.png)

3.落笔写创意标题时，既可以参考同行、临摹同行的写法，也能用前面储备的素材库自行拼装。标题讲究的是简单直观、朗朗上口，同时把产品的卖点摆到明面上。

这里有个关键动作——插通配符。这个符号能自动套用推广组里的所有词条，有助于拉高跟用户搜索词的相关程度，点击率自然也会好看。具体用法就是写“{XXX}”，它会自动切换成组里的任意关键词。不管标题还是描述，都建议放一个通配符。用户搜的词和通配符里的词吻合度高了，创意就会飘红。

标题里顺手标个价格也是好习惯，那些只想要免费的访客就直接绕道了，不会来消耗预算。字符数硬上限是50。

![](img/5279788b365d5ce951060782ea8d9f26.png)

4.创意描述也可以借鉴同行，或用词库自行组合。描述1和描述2在前台展示时是拼在一起的，每段最多80个字，所以必须言简意赅、逻辑顺畅，顺便把产品的专业底子亮出来。

创意件数是多多益善。我给每个单品都准备了10条上下——因为没人能预知哪条的点击表现好，广撒网跑几天，再把数据漂亮的留下，表现差的清掉就行。

![](img/7b6a844ee537e5a49885fcab05cfc558.png)

5.然后在“移动计算机访问网址”填上开户商给的地址。

![](img/89be1c1b232c72ab755cf2def9d57565.png)

## 5.找关键词

关键词实际上就是我们买的那批词。打个比方，你投的是“奥数教程”，当有人想买这类东西而输入“奥数教程”来查找，系统就把你的广告匹配给他。

在找词以前，先代入买家的思维去推演。比如你锁定了“奥数教程”这个方向，那么打算买这类资料的顾客，多半会搜“奥数教程”和“奥数课程”。如果他们更偏好视频版本呢，搜索词可能是“奥数视频教程”或“奥数视频课程”。打算掏钱购买的，也许会搜“奥数教程多少钱”“奥数课程多少钱”，或者“奥数教程怎么买”“奥数课程哪里买”。而抱着学习目的来的，又会输入“奥数教程怎么学”“奥数课程怎么学”。

顺着这种需求推理，一轮词表就出来了。下面放的是我早先整理的样例，可以作个参照。

![](img/95c558aeb452acb24d8e49bba152cfaf.png)

我个人主要依靠“关键词规划师”工具来发掘词汇。

1.打开百度营销客户端，进到“关键词”页面，按一下“添加”。

![](img/7d2e96a5071efc5274c0b6c1c379c7f9.png)

2.跳转到关键词规划师后，把刚才整理好的那批种子词输入进去，让系统帮忙延展出更多相关词汇。

![](img/b99c30aa455d0460ebdd9e3748ede8cf.png)

3.点击“添加全部”把结果都收纳进来。

![](img/63a5c23d0f88157ebad8c0503175624a.png)

4.收完这批后，再换不同的种子词继续挖，循环操作累积词量。

![](img/c818d6fb88766e5e3a6503f4b9389984.png)

5\. 最后把筛选出的词条批量复制出来。

![](img/4b499e6ceae2e4c7005eb7d0978bed09.png)

## 6\. 筛选关键词

1.把复制出来的词条摊到表格里，逐一审视，思考每个词背后藏着什么意图。凡是带着明确购买信号的词就留下，比如“奥数教程怎么买”“奥数教程怎么卖”这类，明显是准备掏钱的精准人群，值得投放。

![](img/155fdc7e1c33dc9d6e71d9c7bdb6d778.png)

2.至于购买意向模糊的词，直接划掉。比如“有必要学吗”“有帮助吗”这类问句，提问者多半还在观望期，成交概率不高。广告是要花钱的，这种词留着纯属浪费预算。另外，像“免费”这种打眼一看就是找白嫖资源的词，也一并清掉。

![](img/e27213111cb0f96621547769a1246d2e.png)

3.搭好否词列表。

否词分成两块：块级否定和精确否定。块级否定的意思是，你把某个词否定后，所有带着这个词的搜索词都无法触发你的广告。拿“免费”来举例，它被加进块级否定后，任何带“免费”字样的奥数搜索词都不会把你弹出来。精确否定则是针对某一个完整词条下手，比如“奥数怎么做”被精否了，这个词以后再也无法触发你的广告。

账户起步阶段主要做块级否定。精确否定的词，通常是跑了一段日子后，把那些明显不转化的词逐个清理掉。

![](img/d14ae3a9d293d39ea2f592d2f7521e7d.png)

## 7.把关键词导入账户

1.在关键词规划师里把筛完的词粘贴进去，指定好计划和单元，点保存。

![](img/0bb8cab816ca321fc72e33b26a3dd88f.png)

2.给词设定价格，我通常先给到1块，后续跟着数据反馈再微调。匹配方式选“短语匹配”，再点确定。

![](img/1b3f217388787db60b72a06a39405f8d.png)

3.用ctrl+a全选所有词，然后在下方“移动计算机访问网址”处填好做好的落地页链接。

![](img/f33c3083e551f1739dc171e8046f29f4.png)

## 8.添加否词

进入推广计划，打开“否定关键词”选项卡，把表格里整理出的两类否词全部填进去，最后点确定。

![](img/f78ab6340b469dcde67601b3e3f80330.png)

## 9.上传计划

点一下“上传更新”再确认，上传成功那一刻，广告就开始在线跑起来了。

![](img/b8bafda0c7148fb187ec1d73a0edafb1.png)

# 五.账户优化

## 1.检查搜索词报告并进行否词

1.每天起来第一件事，就是复盘前一天的搜索词报告，顺手做一轮否词动作，否则垃圾点击会不断蚕食预算。在后台进入搜索词报告，把昨日的数据导出来。

![](img/98c9adbf551f0cb04908a0b5f21d288d.png)

2.打开导出的明细，逐条分析背后的人群动机。比如“咪咕视频小学奥数”——咪咕视频本身有大批免费内容，这位访客大概率是去那里找现成资源的，并无付费意向，算不上精准流量，下单可能性微乎其微。那就可以给“咪咕”设置块级否定，之后再有人搜这个词也不会碰到咱们的广告，预算也就保住了。

再比如“瀚博初一奥数”，“瀚博”明显是一个培训机构的招牌，碰见这类不确定的词，去百度查一查就明白了。搜这个词的人是在锁定线下补习班，同样没有购买在线课程的需求，那么“瀚博”也值得做块级否定。

还有“通项归纳法小学奥数视频”，这个搜索词说明用户只想找某个具体知识点的讲解视频，让他掏钱买整个课程体系的概率极低，所以“归纳”这类词也能进否词表。至于“小学一年级奥数辅导”，“辅导”往往让人联想到线下家教或一对一答疑，购买意愿弱，一样列入块级否定。

![](img/8137eb239e77c641678cfb121665ec5b.png)

3.把整理好的否词填入账户后台，重新上传更新即可。

![](img/5b261f478917b8d575e93453b1f04014.png)

## 2.关键词调价

每周抽个时间检查上周各品的消耗情况。要是某个产品花钱特别慢，我通常会在基础价1块的水平上加个一两毛，接下来几天留意流量和消费有没有抬头。数据起色了就继续跟进观察转化。如果调了几次价格还是纹丝不动，说明这个品类的搜索体量就这么大，加价也撬不动更多流量，那就把价格恢复到原样。

每一笔成交都要记录在案，特别是触发成交的搜索词和关键词，用表格随手记下来就行。一旦发现某些词特别能出单，就给它们单独加价、加大投放力度。

我用200块广告费作为单品的试错成本，烧完200块还不见订单的产品就果断关停。同时每天不停地上新品去测，等你铺到100个产品的时候，靠盈利出单的至少会有三四十个。我自己前后测了大约200个这类品，最终跑下来了80个。教程类的东西本来就不可能天天有单，核心打法就是拼数量——铺几十个乃至几百个品，才能撑起每天稳定的出单量。

# 六.客服转化

目前我的成交里，大概两成来自订单系统直接支付，其余八成都要靠加微信后慢慢聊出来。客服话术没必要自己憋，拿小号去加一些做得好的同行，把他们的对谈话术搬过来就能用。朋友圈内容同样可以参考同行，同行本来就是最省事的老师。

客服号尽量养一个老号来用，新申请的号频繁加人很容易触发风险提示。收款也一样，微信经常弹风险提示，弹一下客户可能就跑了。我建议优先用支付宝。不过也有相当一部分客户没有支付宝，我后来接了有赞的小程序收款，一年费用五千上下，收款顺畅且不会冒风险提示。另一种玩法是让客户先付30%定金，剩下的部分走货到付款，只要客户愿意预付，到货签收率能做到99%。

# 七.新人建议

跟抖音那种卷出天际的平台相比，百度竞价在冷门品上的门槛友好很多。既不用天天担心被封号，也不用怕平台一个政策下来玩法全废，竞争烈度小，稳定性强，适合没有经验的新人进来摸索，也能长时间做下去。

门槛不高，可执行力和心态的要求一点不低。指望一夜暴富、干三天歇两天的人，这行恐怕不适合你。

真正建议的做法是，前期把选品面铺开一点，然后再动手测试。选品基数大了，拿到正反馈的周期会缩短、概率会提升。太多人都是因为一两周内没看到结果就选择了退出。

这套思路不止能套在虚拟教程上。刚上手的人可以先从冷门品切入攒经验，跑通之后可以挑战高复购、高利润的私域产品。
