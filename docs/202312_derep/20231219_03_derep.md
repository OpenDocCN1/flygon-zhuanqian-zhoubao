# ('不妨挣快钱，不妨短期主义', (2, 14))

跟好几个朋友吃饭，聊到现在做项目，绕不开一个词：长期主义。好像不把眼光放个十年八年，都不好意思说自己有格局。但我最近听了一期播客，嘉宾一句话点到心坎里：很多事儿，本质上就是短期的，赶紧挣完，就是最理性的打算。

这话细想是对的。我自己在互联网里混了挺多年，论坛、博客、豆瓣、微博、公众号、短视频，一路换着平台玩过来，最大的体会是：每个平台给的红利窗口，其实就那么两三年。靠某一个平台火起来的人，能顺利搬到下一个平台继续红的，少之又少。所以当你预感到自己可能就红这几年，最不傻的做法是什么？当然是在风口还吹着自己的时候，拼命把钱挣完。

这道理放哪儿都成立。你看职业篮球运动员，身体巅峰就那么几年，35岁往后基本打不动了，那他们的最优解就是把能签的大合同先签了、把钱先攥在手里。青春饭，不丢人，因为有些机会的窗口压根就是按“几年”计的。

而且，一个人愿不愿意“等”，很大程度上取决于他对未来的预期。虽然这种预期本身不一定准确，但它的确左右着当下选择。前些年大家都乐观，觉得多忍一阵子，后面能换回更大的回报，所以人人愿意延迟满足，开口闭口都是长期主义。你看互联网大厂那些年估值一路涨，很多人捏着期权不着急卖，觉得往后还能再翻倍，自然乐得谈“长期”。可这几年股价一路缩水，风向立刻变了，能套现赶紧套现，谁还有心思讲信仰？悲观情绪一到，把钱先攥在手里才是本能。

说白了，大多数人信奉长期主义，并不是因为他多爱那件事，而是算准了“撑得久，拿得稳，赚得更多”。既然大家真正在乎的是回报数字，快钱和慢钱就没有高下之分。只要短期真能挣得更多，短期主义就完全站得住脚。

我自己现在算半个长期主义者。原因不是这个词多高级，而是我兜里已经攒下了些底子，不用再为生存焦虑；同时我对“赚得更多”也没那么大执念，够花就好，反而更想把公司做得久一点。可每个人的处境不一样，当你的核心目标还是攒第一桶金，真没必要被“长期主义”绑架。把账算清楚，什么来钱快、来钱多就去做，这才是最清醒的活法。
