# ('印钞 650 万亿，日本物价为什么不涨？', (2, 22))

按理说，开动印钞机疯狂放水，资产和物价总得跟着飞涨才对。但日本央行这些年砸下了650万亿日元，国内的股价、房价，乃至超市里的商品价格，却依然稳如老狗。钱到底去哪儿了？

答案有点出人意料：这些钞票压根就没流进老百姓的口袋。

日本央行印出来的巨额资金，基本只在政府、央行与大型金融机构之间来回倒腾，相当于钱在金融系统内部“空转”。真正参与生产消费的企业和普通家庭，手里并没多出多少能花的钱。没有新增购买力，自然不会有人去哄抬股价、抢购房产，连柴米油盐的价格也毫无起色。

说到底，印钞规模大不代表通胀就来。关键在于钱最终能否抵达实体经济和普通人的钱包。如果资金只在金字塔尖打转，民间感受不到“放水”的暖意，物价自然就按兵不动了。
