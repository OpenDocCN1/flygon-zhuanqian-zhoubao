# 当朋友圈会赚钱：一个95后女生如何把月薪7k的加班生活，变成月入7w的自由节奏

在互联网大厂里刷 KPI 的那段日子，我大概是最清醒的“社畜”。

毕业后进了很多人眼里体面的公司，月薪卡在 7k，作息却被拉满。每天都是加班、内耗、身心俱竭。更扎心的是，我根本不喜欢这份工作，所以升职加薪对我毫无驱动力。

于是我做了一个决定：白天还穿着工牌打卡，晚上和周末把自己当成创业项目来做。我开始持续给自己“充值”——学技能、拆案例、练变现，把朋友圈当成作品集和信任场来经营。慢慢地，我摸清楚了朋友圈美学的底层逻辑：不是发好看的图，而是用一手专业技能+一手内容呈现，让信任自己长出来，让订单自己找上来。

这一套打法跑通以后，收入的曲线开始陡峭：从月入 7k 到月入 7w，背后是技能在手里，变现握在手上。

我是白羊，一个95后的线上自由创业者。这条路并不玄学，只是把“会”和“被看见”同时做到位。
