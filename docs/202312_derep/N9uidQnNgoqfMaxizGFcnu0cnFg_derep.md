# 好了，现在进入正题：10分钟搞定一条破百粉作品🚀

今天这套小白涨粉打法，我把它拆成了七个步骤。

1.  第一招 找元素
2.  第二招 解元素
3.  第三招 靠AI
4.  第四招 下剪映
5.  第五招 抠细节
6.  第六招 升内容
7.  第七招 挑时段

* * *

# 第一招：找素材

去微信视频号上扒一扒现在在火的、数据漂亮的作品。

![](img/ccce3ed661080b349ea51bd21f96cb2a.png)

看这几条爆款，播放都不错，而且画面都很简，复刻成本低。

我们要找的就是这种只靠一张图就能打爆的粗暴型视频。

### 为什么偏偏选这种单图高数据的作品？

说实话我也没深究原因。我只有一个想法：

爆款既然能爆，肯定有它的道理。别先去问为什么，直接拆解学模仿。先抄再说，抄着抄着你就摸到门路了。

* * *

# 第二招 解元素

把视频拆开，把文字、贴纸、主视觉等关键组成拎出来。

![](img/2942bc06523541898eec4698e98bdaf7.png)

像这种壁纸类爆款，构成其实就四五样东西：

1.  背景
2.  文字
3.  贴纸
4.  特效
5.  配乐

![](img/dac3d8753b8e2ff4aca4c4adf73a796a.png)

再看另外两条，也是这个套路。这类视频基本都是这五大件拼出来的。

我们做的时候也一样，把这五个零件拼装起来就好。

* * *

# 第三招 靠AI

用AI工具快速生成或优化画面。

为什么要上AI？怎么上？

两句话搞定：

*   为什么：AI能大幅提高出图效率，快速产出高质量视觉，而且能直接走原创。
*   怎么用：最省事的方案就是剪映。

![](img/d1ecdb8956eb62cd56142e5a518bcdbe.png)

比如我做财神图素材，一次出四张，直接入库。

现在剪映这功能还是免费的，工具不止它一个，我只是图它上手快。

* * *

# 第四招 下剪映

用剪映这类剪辑软件完成成片。

剪映功能全又好用，是目前上手最快的视频工具之一。

### 最关键的是，我们需要的那些元素，剪映全能搞定。

* * *

# 第五招 抠细节

把视觉和听觉要素再精细化，比如比例、时长、音乐等等。

![](img/449f4811b988dbf31100cbb85abf9990.png)

先把AI生成的图导入，画面比例调成9:16，接着给素材抠图去背景，换个纯色底，再把其他元素叠上去拼接。

这里有几个小要点：

1.  每个元素的展示时长控制在8秒到15秒之间；
2.  贴纸记得加一点动效，画面会更活；
3.  图层顺序要注意，主素材一定要放在最上层。

* * *

# 第六招 升内容

把封面和文案做优化。

这一步也是爆款的关键，好的封面和文案是点击的第一眼。

*   封面直接截视频里最吸睛的那一帧。
*   文案用情绪化的祝福语，比如“迎接财神”“祝你财源滚滚”，再加上“#主题”标签。
*   参考对标作品设置时长，配上同款音乐或截取对标音频，文本里放上“迎接财神”“财源滚滚”“身体健康”等关键词。

* * *

# 第七招 挑时段

结合数据挑一个最合适的发布时间。

多试几个时段，看哪个时段流量最好，然后固定下来。

我实测下来，这类祝福视频在四个点最容易被推：

8:00、13:00、18:00、20:00
