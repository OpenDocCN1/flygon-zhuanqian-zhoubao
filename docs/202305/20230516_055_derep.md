# 《承认自己的无能和无知》
作者：龙哥

很多创业者坐到那个位置以后，慢慢地就会有一种错觉——觉得自己英明神武，事事都能搞定。这不是谁的错，而是位置带来的“副作用”。有研究说，人一旦掌权久了，大脑里负责共情的部分也会悄悄退化，说白了，就是容易听不进别人的话。

但你有没有想过，今天能做成点事，也许只是踩对了时代的节奏，运气比别人好了一点。我们总爱把它归结为自己的决策英明、努力过人、头脑清醒，可真相往往没那么玄乎。

真正厉害的人，反而敢承认自己不行、不懂。因为只有你承认了这些，你才愿意听别人说两句，才明白哪些事你干不了，也才舍得放弃那些根本不擅长的事情。这是一道坎，但最难的是——要认清自己的无知，本身就得有一定的认知水平。

不过话也不能说死。老板要是一味低头，又容易被那些“专业术语”糊弄住。所以判断一个人，别只听他讲得花哨，要看他真正做了什么，又做得怎么样。

评论区里也有人说得好：每个人都有盲区，区别在于你能不能发现它。越成功的人越难看到自己的盲区，这是规律。但普通人也别灰心，只要你知道自己“不知道”，就已经比很多人强了一大截。保持空杯心态，别把自己太当回事，也别太不当回事。一边谦虚，一边清醒，该听的时候听，该看的时候看，路才能走得稳。[PRE*]毕竟，认识自己，永远是一辈子的功课。
