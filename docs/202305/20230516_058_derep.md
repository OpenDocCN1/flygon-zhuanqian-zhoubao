# 《从负债十九万的金融打工仔，到年净赚近百万的投资人》



大家好，我是龙哥。90后一枚，2019年那会儿我还在为19万的负债焦头烂额，干的也是体面的金融民工，到了2020年才算真正翻身。

这一路能走过来，得感谢太多贵人。

是教会我记账的那位朋友，让我学会了做流水账，摸清自己的钱往哪流，也学会了怎么用数据去分析利润、指导投资方向。

叶总，外号夜场王子，是把我拉进证券行业的人，他打开了我投资的大门。

股丰登，是我开始正式玩股票的引路人。

厦门斗猫网络的李总，让我第一次触碰到淘宝客这条赛道。

老胡，则打开了四大行无风险套利这条路。

当然也得感谢自己。多年下来练就的靠谱和真诚，让我在一次次机缘巧合里抓住机会，也有了迎接挑战的底气。

先跟大家盘点一下近几年的战绩：

2019年，我还在背负19万负债。2020年，实现净收益22万。2021年花24万买了个车位，当年净收益96万。2022年又花38万购入一个车位，净收益93万。2023年到目前为止，净收益已经32万。

目前我的收益结构大致是这样：

1. 股票经纪人佣金，年入12万到20万；
2. 个人股票投资，年入约20万；
3. 淘宝客项目，年入约50万；
4. 可转债打新，年入6万到10万。

从2021年疫情开始算起，连续几年年净收益都逼近百万。股市里躺着的未分红收益也上百万了。

其中股票相关的投研我不建议盲目跟做，其余几项都有可落地实操的做法。
