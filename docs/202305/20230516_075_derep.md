# 《用 ChatGPT 超级写手批量制作抖音带货文案》

最近在钻研抖音卖货的视频内容，发现一套挺有意思的玩法：把别人验证过能卖货的短片，拆出口播稿，让ChatGPT以它为参照重新整理，再融入视频和关键词，实现一种近乎“量产”的效率。这套流程不需要高深技术，手动跑顺之后还可以让机器接着干。

![](img/17cdbefb573755f29d39086803708c98.png)

先看工具清单。手机里装一个抖音官方的热点追踪工具，用来挖推荐向内容；如果想用电脑去操控手机，安卓系就上total control，苹果系则建议虫洞；网页端的轻抖方便取口播文字，新注册的账号得半小时免费时长；一个名为ChatGPT助手的小工具，是在uibot平台上搭出来的；ChatGPT本身的注册跟着常规教程走就行，我写过另一篇讲解题思路的文章，可以配着看；和ChatGPT对话时附加一个叫temperature的数值参数，输出的语气和风格会明显改变；安装webchatgpt扩展后，ChatGPT就能连上网络，资讯不再停留在2021年9月之前；最后是那个能凭文案直接出片的视频生成工具，它能拿写好的稿子生成片段并配上声音，之后可以再把本地素材换进去。

核心思路只有一句话：直接向卖得好的人取经。操作上大致是，从热点追踪工具的内容流里，或者在抖音大屏上筛出半年时间内的挂车短片，把口播稿扒出来，丢给ChatGPT做一次仿写式重写。还能反着来：先看看抖音小店里哪些东西在爆，总结卖点，再结合目标人群和热点追踪工具里的参考，让ChatGPT参考这些卖点和人群来写新稿子。稿子出来后，用出片工具产出一段粗剪视频；不想每月为了云希音色付88元，就去微软的Azure注册一个免费账号，因为云希本来就是微软官方给的免费音色，有些平台只是代为转售。手动环节跑明白后，后续的稿子写作、短片合成、账号发布，都能交给RPA一项项做掉。再把搜索框联想出来的关键词、关联搜索词、站内热搜词，都放到视频的稿子、简介和标签栏里，让用户在抖音里搜什么都撞见你。

具体分步看。首先要找一条值得参考的模板视频。选内容只有一个硬标准：明确在卖货，最好还是软件语音合成的那种。

这个热点追踪应用里有两条路可以找。其一是推荐向内容：时尚板块的总榜，时间切到最近7天，凡是内容上挂了商品小标签的，就是要找的。![](img/f7d3b9b781b07a9d738736af48299c28.png) 另一个入口是热榜，点进去把时间设为最近7天，切到上升最快的那个子榜。热榜里的内容量更大，不过卖货内容要自己逐条去看，数量不如推荐向板块集中。好在刚够1万赞的小爆款也能登顶，不至于卷到夸张。用大范围类目词来检索，比如女装这类；牛仔下装也行；甚至更宽的鞋、裤。![](img/a25ec446417aeabfca3bfd39e7e0bcaf.png)![](img/a94d6cd12db6a3c11a79c7d099581dd1.png)![](img/839ad32a6922370de42c6b29055c7f40.png)

或者换个方式，直接在抖音站内筛：点赞数从高到低排，时间限定在最近半年。![](img/94286e7081956be05dea47ecb65b6616.png) 这一步让RPA来采集，把热点话题、视频的链接、商品页的跳转地址都抓出来放进Excel，方便后边接着用。

第二步，把视频里的口播稿拿下来。最省事的是轻抖这类外部小工具，新注册的账号有半小时免费时长。![](img/5b554d555c5f55713826ddade4b0e2f2.png) 一个账号不够就找亲戚与好友再凑几个号码，测试阶段这些额度完全够用。卖货短片普遍不长，付费方案是60块50小时，算上时间成本，直接付费反而最划算。RPA加飞书里的妙记，能免费处理大量口播稿，适合已经完整跑通项目、哪怕两百个小时也不够用的重度玩家；如果只做到一半，就别研究这个了。提取口播稿不是关键环节。程序批量跑，解决的是从1份到100份的复制，但解决不了从0到1的起步。

第三步，让ChatGPT来干改稿的活。简单说就是通过一个基于uibot的ChatGPT小助手，把拿到的口播稿成批地重写一遍。这里有个值得玩的参数：把temperature调成不同数值，回答差异非常大。![](img/9058f8e6266221d278502ff69234af65.png) 至于怎么选数值，直接让ChatGPT自己解释。![](img/783650c22b2aa43683f300f3905adf3c.png) 对结果不太认可，或者觉得内容离预期很远，就调整temperature校准。![](img/6475fa9348f9e113ee6f891c91aba339.png) 具体操作可以看作者录的示范视频。

第四步，把别的商品套进已验证的模板里。素材里有个示例，大概意思是一位体重148斤的女生，试穿几条不把腿露在外面的裙装。第一条是背带款，套上就省了搭配心思，粗腿也藏得住。版型偏宽松，中间抽绳一拉就有腰线，看不出孕肚。第二条是绿底花色的裙子，偏日常，胸下收腰能把腿衬长，手臂的肉感也被遮掉大半。转过身去、侧过头来看也没有死角。粉底花色的那条适合出游玩，肚子收得干净，背后不显厚重。整套上身显得贵气，胸前和背后的压褶细节服帖，不紧绷也不箍肉，日常通勤照穿。要学习的是它怎么描述卖点与人群，再套到新商品上。比如一款阔腿版型的西裤，卖点这么写：穿着显瘦，个子显高，腿显得很长，腰线收紧后肉感被遮住，小个子穿了不显矮，腿型好看，面料是哑光的西服布，手感很软，同时透气性也好，不会闷汗。人群定位是职场女性、时尚派、商务场合。![](img/79ecafe3d3072d179723a81475149d9b.png)

第五步，拿那个视频生成工具把稿子变成视频。图片哪里来？电商平台的买家评价区，或者抖音挂车页的买家秀，都行。万彩可以把图片串成画面；或者让出片工具直接根据稿子生成一版，再把素材换成自己的。初版效果欠佳没关系，进剪映逐段替换就好。一般用图片生成PPT式视频就够了，电脑上的万彩自带现成的做法；测试阶段直接把图放手机里，用剪映的图片成片功能也能出。![](img/e0ecc8b8bdd9ec849d5dc61348a4c76c.png)![](img/1d3e3130bb5a167e9ba7c34ee2530b75.png)![](img/b328df372954c6b9a10dfe27515b1363.png) 最后再交给RPA发布，把成品分发到各个站。凡是这类流程固定、重复度高，手动能做的操作，都可以让RPA接手，前提是先把手动步骤走通。![](img/1226004d8c9b265d556366307a89194a.png)

第六步，搜索位占道。抖音搜索排序值不值得研究？就像一门功夫秘籍：别人学了你不学，肯定吃亏。越往深处想越明白，手里有几条爆款也不等于能出单；用了ChatGPT和RPA，也未必拼得过对手。因此这个动作必须补上。![](img/b9648d67e91a9727972b5d3f4acec14c.png) 具体办法并不复杂：把搜索框的联想词、关联搜索词、平台热搜词都置入视频的稿子、简介和标签栏。如果平台认定你在堆词，或者有作弊嫌疑，那就让一条片子少放几个词。反正程序已经把稿子、视频、发布全流水线化了，一条片子里多几个词少几个词影响不大。![](img/94e3bd1d4b842f1e5fffb6cb77788627.png) 结果是：用户搜什么都能撞见你发的内容。同行未必有这个意识，也未必有这套玩法；就算有，靠人手逐条去做也跟不上。实在卷不动就换一个冷门类目。
