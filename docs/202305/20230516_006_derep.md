# 别指望把所有问题都修好，先把要命的问题修好
作者：龙哥



创业 46 条之 16 · 解决真正的问题，而不是试图解决所有问题

刚创业那会儿，我特别想做一家无懈可击的公司。后来才明白，这个念头本身就不现实。

公司终究是人堆出来的，而人不可能完美。欲望、偏见、懒惰、自负，每个人身上都有，管理层也一样，我自己更是问题成堆。在这个前提下，追求面面俱到、样样拔尖的公司，无异于缘木求鱼。

经营的本质，是在某个阶段抓住最致命的矛盾去处理。

公司的毛病永远排着队，但它们的威胁等级完全不一样。

第一类是会要命的问题，不解决公司马上就垮。疫情时线下门店的现金流断裂、业务全面萎缩就是典型。这种时候别谈什么长远规划，能续命就行，贷款、砍线、找新现金流，什么有效用什么。

第二类是寄生性的问题，等主矛盾破了它自然就没了。比如团队总抱怨收入不高、奖金少。根子不是分配方式，只是公司没活儿、业绩上不去。业务量上来、订单多了，收入这个抱怨会自动消音。没必要为它单独开一场改革会。

第三类是结构性无解的问题，你耗尽力气也搞不定，搞不定就别硬耗。最典型的是分配公平的抱怨。你永远无法让所有人觉得自己拿够了，因为人天生会高估自己的贡献和价值。一个团队让每个人自评贡献度，加起来能到 150%。这种心理惯性是人性，不是制度能根除的。公司能做到评价相对客观、规则相对透明，就已经是及格线了，剩下的抱怨，只能听，不必全消。

做事要像老兵赶路，不抓小兽。先把决定生死的矛盾抓住解决，其他的随形势再说。 #小马宋每日思考
