# 《今年 65 岁的我，在这次大航海我报了四个项目》
作者：龙哥

### 65岁，她一口气报了四个项目，评论区沸腾了

谁说65岁就只能在家含饴弄孙？来自北京的Lily姐偏不。这次大航海，她一个人就报了四个项目，让许多年轻人都自愧不如。

Lily姐退休后可没闲着。她组建了业余的艺术团“北京金百合外语艺术团”，还因为活力四射被媒体起了个响亮的称号——“中国忘龄女DJ”。不仅如此，她还在八达岭脚下亲手打造了一个童话般的“北京童话世界小院”，这些故事上网一查就能看到。

除了这些，Lily姐还在闲鱼上开了一间名叫“Lily北京驿站”的小店，卖的是圣物类宝贝。她在eBay上也有足足十年的购物经验，虽然一直是买家而非卖家，但她心里早种下了做跨境电商的念头。这次大航海，她就是冲着学新东西来的，一口气报了四个项目，实在让人佩服。

评论区里，大家都被她的状态点燃了：“年龄对她来说只是数字”“这人生太精彩了”“活到老学到老，向Lily姐看齐！”65岁还能这么拼，果然是“忘龄”啊。
