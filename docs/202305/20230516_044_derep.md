# 从 BRC20 到 VMPX：一个 Web3 老兵的实战复盘与思考

如果你也在关注 Web3 的新赛道，最近 BRC20 生态里的 VMPX 项目热度不低。有位在加密圈浸泡了两轮牛熊的老玩家，分享了一篇深度复盘，读完后我觉得里面的视角和框架很值得复用，特意整理出来给你。

这位老哥叫瓜藤，用他自己的话说，是个“在 Web3 里浮沉了两轮周期的人”。上一回让他如此兴奋，还是 2020 年踩中一波大机会的时候。而这一次，他是在 5 月 8 日凌晨三点，冲进 VMPX 项目完成了一次实战。他自己坦言，这是“摒弃偏见后的第一次出手”，并且觉得这段经历对自己挺有价值，也希望对你有所启发。

整篇文章篇幅很长，他特意说，这是写给那些愿意花时间改变自己命运的人。如果你也有耐心，不妨认真读一读。
