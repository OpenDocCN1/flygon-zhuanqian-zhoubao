# 出名这件事，有人算得过账

最近聊到一个不太常见却挺扎实的看法：出名，本质上是一种成本。

前段时间和蔡钰老师聊天，我随口建议他把《蔡钰商业参考》里的干货做成短视频切片分发出去。他认同这个思路，但直接拒绝了。他的原话很直接，出名就是变现的附加费用。现在的体量已经够用，他不想再把知名度放大，放大之后带来的各种麻烦他不想再扛。

剽悍一只猫的猫叔也是差不多的心态。他的折中方案是做内容，却始终不露脸，生活里也几乎不接受合影。有次我们在东京排队吃网红店，我随手发了张照片里带了他背影的图，他马上打电话来让我撤掉朋友圈。

还有我孩子艺术指导的那位老师，思维很深也很有格局。我曾想邀请他上播客聊聊，他很客气地谢绝了。他说现在的活已经少到刚刚好，钱够花，学生也接不过来，所以从没做过任何宣传。过几年打算去西双版纳安静读书，后半生就不想再参与这些公开活动了，很抱歉。

类似的例子还有不少。这段时间里，我有几个朋友都委婉拒绝了我的直播和录播邀请。其中一位名气挺大的朋友，一年前就彻底停了工作，选择隐退。

他们的选择并不主流。绝大多数人还是渴望被看见，名气越大越好，我自己也一样，为了咨询公司的业务，不得不去做传播。绝大部分人都希望财名兼收，这是很正常的人性，真正觉得钱够了、就该收心的，终究是少数。我们常说名利双收，几乎没人把名气当成一种负担。
