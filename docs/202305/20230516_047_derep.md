# 《90 万粉丝🧣博主分享涨粉干货》

大家好，我是龙哥。我主要混🧣，现在账号上挂着90万粉丝，但说实话这数字要打对折——平台后期给我灌了不少假粉，真粉假粉掺着来。![](img/9838fb37f848fe8dd61a33ab07815a49.png)

我是2019年6月才正式在🧣开号，到当年10月就有了10万真实关注，随后开始变现。目前电商这块儿流水稳定在每月200到350万，淡旺季会有点浮动。下边这个截图是其中一个店铺上个月的数据：![](img/d894a114c28a79fe626eb67c06dc99bb.png)

今天不聊电商，专门把🧣涨粉那点事掏出来说说，都是自己一步步试出来的经验。🧣跟其他平台最大的区别是：新号早期特别吃大V转发。好处是只要找对人、人家愿意搭把手，你很快就能跳过冷启动的煎熬；坏处是平台自身的自然流量比别家低，想靠算法偶然爆一下，概率不大。

总有人说🧣凉了，没必要做。我观察下来，它还真有搞头。一面是其他平台流量卷到头了，一面是🧣自己也在折腾新规则，我还亲眼看见有2022年才起号的新人，现在已经啃到10万粉。

涨粉的路子，归结起来就六个方向：大V转发、付费推广、同盟互转、追热点、找🧣运营，以及抽奖带量。

先讲大V转发。我自己起步就靠这个，但最早也踩过坑。当时我现实里认识几个大V，以为说一声就能帮转，结果人家转了跟没转一样。原因很简单：我写的是干货文字，人家粉丝爱看漫画、爱看段子，根本不买我的账。后来真正带动我涨粉的，反而是原先不认识的人，有些到现在都没碰过面。

所以找大V帮忙之前，先做功课。观察他发什么、粉丝是什么人，判断这些人会不会对你的内容感兴趣。我印象最深的是，开号前我就是水库的读者，认同他们那套观点，后来写了几篇同价值观的文章，像《买包，我看你像个包》和《我曾经有过一任男友非常爱玩》，被卢湾伯爵一转，第一批粉丝就这么来了。等到粉丝量往十万走的时候，欧成效老师也关注了我，还多次转发，效果相当好。另外一篇《女性创业远离烘巧咖》，被风中的厂长转了一下，一条就带来上千粉丝。这就是内容跟转发博主匹配的结果，当然，前提是你得写得好，还得有人看得上。

还有一点：别逮着同一个大V反复求转发。人家要顾自己主页，不可能天天带人；再说同一人转多了，数据会越来越差，因为他的粉丝圈里对你感兴趣的就那么些人。要不断物色新目标，找那种写作风格、价值观、粉丝画像跟你对路的，前期多互动，多刷脸，别装清高。

可问题是，你还是小透明时，怎么让人家注意到你？核心逻辑是：你得让大V发现你有价值，而且这价值现在或以后可能帮他赚到东西。具体我有几个招。

第一招，留言和私信。注意，留言不是为了蹭粉，是为了跟大V混熟。混熟了，机会才会来。私信怎么发？先自报家门，说清自己擅长什么，表达想互动，问对方愿不愿。要是粉丝量拿不出手，就用现实身份撑场。我早期给人发私信就说自己在华谊影视，自媒体只是爱好，不少内容从业者对影视圈很好奇，甚至想把手里的文字卖给片方，一听这个就会回我。写书哥也这么干过，他主业是出版，又是清华毕业，就用出版人兼学霸的人设去结交文字博主，特别好使。留言怎么写？一半要有含金量，一半要表达欣赏，在正经和活泼之间来回切，后者让人记住你，前者让人愿意转你的留言。🧣是信息流，内容容易被错过，博主经常需要从评论里挑精华再转一次，那不就是你的曝光机会嘛。

第二招，名字加头像。这俩是评论区里仅有的记忆点，尤其头像是图形，名字是文字，都得够醒目。我最服的一个ID叫“南山侠女”，头像是舒淇演《聂隐娘》的剧照，名字有侠气，电影很小众又很有质感，我一下就被吸住了，点进去发现她写得好，于是几万粉的时候我就互关了她，现在是特别好的朋友。反过来，评论区老出现又互动频繁，可名字一长串、头像天天换的，基本就是无效操作。名字最好好记、不长、没生僻字，定下来就别老改。

第三招，付费转发。这条路看个人情况，有的博主收钱，有的不稀罕，破冰到什么程度才适合提，要自己判断，也可以广撒网试。开口要礼貌，先关注，再介绍，表达认同，最后问愿不愿意有偿转发。钱有时有用，有时没用，大V一般不缺钱，能打动他们的更多是你身上的其他价值，人家看着顺眼才肯收你的钱。我刚开始做号那会儿，每晚躺床上逼自己发二三十条私信才睡，第二天零回复是常态。反过来，如果对方主动关注你，说明你内容真的好。那就盯着每天的新增关注，发现粉丝多的立刻回关，先搭上线。

第四招，多跟小V打成一片。我粉丝只有几万的时候，高攀不上几十万的大V，就先找同量级甚至更少的博主互动。千万别觉得自己粉丝少跟别人互动就吃亏，人家大V不往下看，你还往上够？再说你根本料不到哪个小V背后有大V朋友。我当初跟水原十口互关，他🧣粉丝不算多，可我在水库那边读过他不少文章，后来他转了我的内容，没想到就引起欧成效注意了，欧老师回关我以后，又带了一串大V朋友来关注我。这种事不止一次。所以别小看内容好但粉丝少的博主，他们要么认识大V，要么现实里有资源。就算最后没捞到什么，跟好内容互动本身就是种收获。

第五招，用现实中的关系网牵线。我跟姓氏乔是通过共同朋友认识的，当时一听朋友认识她，我马上来劲，求着引荐，去成都还带了礼物请吃饭。我也是通过朋友引荐才认识的千万粉博主英国没品笑话。就算后续互动不多，多认识些大V也值。

第六招，用合作把网上关系推进到现实。网上的关系太虚，得靠具体的事情落地。2019年我虽然跟“一只蹦蹦跳跳的尤物”互关了，但一直没互动，人家百万粉，我十几万，高攀不上。后来疫情期间他在为武汉筹货，我也有心做点事，可我的供应链没他强，于是就想直接把钱给他，让他去操办。一来互关这么久我信他人品，二来买过他卖的东西，信他能力，三来本来也是为武汉做点事。所以我连问都没问就把钱转过去了。这件事成了关系分水岭，从那以后成了🛰️好友，偶尔聊天，他上北京我们还约饭。尤物后来帮了我太多，他对自媒体和电商的理解，对我来说非常宝贵。

还有一个偏门招，就是靠漂亮照片当头像，给异性大V发私信表达仰慕。我自己没用过，但听说效果不错。谨慎用，因为万一以后火了，聊天记录可能被人挖出来添油加醋当黑料；何况你们也可能翻脸，对方看你不顺眼，再配上一堆截图编个故事，你哭都来不及。

另外还有一招：帮大V整理内容。有的小博主用心把大V的文章做成合集，按数据排好，求对方转发。一般人都不会拒绝——毕竟是认同，也是帮对方展示。但现在🧣限制多，一篇文塞太多链接会被压流量。总之要琢磨大V需要什么：是收钱？是出书？还是把小说影视化？投桃报李、资源置换，就算有些大V人特别好纯粹帮你，也不能一直指望。人际关系的本质就是交换，不是绝对平等，但总得是交换。你想跟人家互转，连自我介绍都没有，粉丝还是人家的十分之一，这跟拿十块钱买真耐克有啥区别？钱不够，就得拿别的资源补。那些现在粉丝少但能力强的小V，往往跟你相识于微时，后来可能一发不可收拾，千万别看不上。

然后说说付费推广。去关注“粉丝头条”官方🧣，“我要推广”里可以买涨粉，普通粉丝大概一块钱一个，要是限定年龄、地域、性别，价钱更高。我自己花过钱，买得不多，不到一万，粉是涨了，但真假不好说。问过几位大V朋友，都说这类粉丝的成色存疑。

同盟互转也很重要。做起来以后，要渐渐养一个同量级的互动圈子，互相转、互相带。单个博主带来的粉不算多，但能攒，而且没准里面就藏着未来的大V。写书哥当初就是跟我一起混的，几万粉时我们经常互动，他后来涨得快，社交又强，我认识厂长、自我姐、罗罗姐都是他牵的线。要是我当年只盯着更高量级的人，绝对不会有后面这么多机会。找圈子也是主动发私信，别怕拒绝。给大V发三十条也许只有一人理你，给同量级博主发，人家基本都会回，因为新号更需要归属感。比你粉丝少一点的，也比比你粉丝多一点的更愿意回复，人都想占便宜，你愿意先吃点“亏”，事情就好办了。其实这不叫吃亏——20万粉博主给你转粉未必比30万少，跟时机、内容、调性都有关系。别那么小气，转了人家一条就催着人家还。

追热点绝对是我个人最常用的方法之一。热点分两种：顺着已有的话题写，或者干脆自己造一个话题。风中的厂长首批粉丝就是因为“淘宝均价168以下的女性不要交往”上了热搜，那是他聊电商多年对低价客户的直觉，属于自己造热点。造热点需要内容强、能引起强烈认同，再加点运气，也可能上负面热搜——2019年上海有个张雨晗，马桶堵了抱怨几句就被全网追着骂。而追随热点，我们大部分人都能做。少年伯爵写过一篇《永生，蝙蝠，冠状病毒》，赶上疫情期间的蝙蝠话题，直接上了热搜，转发达6.1万、评论七千、点赞八万，吸粉五到十万，而且那种热搜劲儿很长，后面几个月的流量都很猛。我自己因为绿地陈军事件写了《捞女的哲学》，也算小型爆了：转发1550，点赞1.6万，涨粉3000。我靠热点涨粉，多的时候五六万，少的时候一两千，这是我做得最快的方式，但未必人人都适合。

热点文怎么写？社会热点要写出情绪、写出共鸣，观点还得独树一帜。你人云亦云，谁会关注你？新人尤其别怕意见不同，就是要写点有新角度的话。有几种错误不能犯：一是为了追而追，没写几句话就硬加个话题标签，就算上了首页也没人理；二是没有独立思考，写作能力又比不过大V，甚至直接抄别人的，粉丝都会跑大V那里去；三是过于极端，站队骂人，骂出互动也带不来关注；四是娱乐话题只聊八卦。我也写过不少追综艺的文章，比如《伊能静：爱与控制的边界》《张雨绮：她不是你以为的憨憨》《王漫妮不是什么受害者，贪心也不是完美婚姻的充要条件》，互动和涨粉都不差。有人说追热点没意义，娱乐综艺没有深度，我真不同意：能不能写深，是能力问题，不是话题问题，写不出深度别怪热点。也有人说热点文章有保鲜期，过了就废了。我又不认同，全民热点像浪姐、三十而已，长期霸屏，不追才亏。你写篇文章能吸粉、能引起共鸣、能带来数据，已经是很大的收获了，还想要不朽名篇吗？即使不追热点，普通人写的东西也一样会过时。而且你在写热点里的思考不会过时，下次碰到类似事情还能举一反三，金句还能重复用，何乐而不为。

等粉丝到了几万，可以找🧣后天的运营。平台有分管不同内容赛道的运营者，比如读书、教育、科普、美妆，他们手里有热搜名额，你文章足够好，他们免费帮你投热门。我现在🧣在读书领域，时尚金V是当初申请失误。不过得说一句，🧣内部挺凌乱，一年多我换了几个对接人，有的傲慢，有的高冷，有个很好但很快离职了。等做到一定程度，会有专门的大V客服中心伺候你，在线喊人工客服就能解决问题。他们也会讲一些规则：文字类🧣最好超过一百字，太少没扶持；图文类别只写一行，至少配两三行字；加的热门话题别超过三个，正文@的用户别超过三个，否则就限流。

最后是抽奖。花钱抽奖涨粉很直接。三年前有人砸十万二十万抽奖，效果爆炸，现在没那么神了。常见的操作是找愿意带你的大V做联合抽奖——你出奖品，对方买热门，在他的主页抽，粉丝就哗啦啦涌过来。关键看对方粉丝给不给力。我做过一次划算的：iPhone12出来时，朋友熊猫大李带我，我出手机钱，他买热门，我涨了三万粉丝，手机也就一万多，而且他那边的粉丝是很会花钱的。也翻过车——我付费找过一个专门做抽奖的博主，粉涨了一大堆，可几乎全是垃圾粉，年龄低、没购买力、观点偏激，整天只想着中奖占便宜。这种粉要是将来带货搞知识付费，基本没用；要是只想接广告糊弄一下，可以试，可🧣广告费也不高。

这一套组合拳打下来，涨粉路数基本也就齐了。希望给正在🧣摸索的老哥老姐们一点启发。

乔一毫不吝啬地夸了一句“太优秀了”，张潇雨看到后乐不可支，热情招呼起来。迎十里也惊喜地冒泡：“哈哈，真的好久没见了！”林海盐更是激动，直呼“自己喜欢的博主居然来啦”。温州土老板则谦虚地说，十里可是相当有实力的前辈。迎十里一边连称“你太客气了”，一边回了一颗比心的小爱心。丛林大鹅也在评论区乐开了花，表示又在这里逮到十里了，还夸这次分享全是实打实的干货，真了不起👍🏻
