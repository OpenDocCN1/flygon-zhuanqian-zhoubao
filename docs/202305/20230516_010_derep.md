# 《20 岁月入 6 位数的七年创业之旅》

《13岁拿1块钱起步，20岁月入6位数：一个县城少年的7年搞钱路》

他叫梦宸，2004年出生，如今是一名大一学生。在河北廊坊的小县城里长大，家境普通，却从小就有股不甘平庸的劲儿。

2016年，他13岁，兜里只有1块钱，就敢开始做网赚。没人教，没人带，他从互联网的边角料里一点点摸索。七年过去，他已经成为月入六位数的大学生。

这七年，他没有太多同龄人的假期——别人追剧打游戏、朋友聚会闲聊，他常常整夜不睡，对着项目反复琢磨方案。赔过钱，也被家里人反对过，用他自己的话说，那股倔劲儿是长在身体里的，遇事绝不轻易回头。

为什么这么拼？他的答案很实在：钱能给人底气，也能洗掉骨子里的自卑感。他知道自己起点不高，所以更想把生活掌握在自己手里。

2023年，他总算圆了一个小梦想：一个人跑去杭州。吹了吹西湖边的晚风，也在灵隐寺晒了晒太阳，亲身感受了那座“电商与自媒体之都”的创业气息。回程的时候，他特地买了西湖龙井和其他当地特产，不为别的，就盼着父母在亲戚朋友面前能把头抬得更高一点，甚至被夸一句“你们家孩子真懂事”。爸妈嘴上说“别乱花钱”，可眼里藏不住的笑意，就是最大的回报。

他常说，努力的意义并不宏大：想出发的时候可以随时买票，想爱的人能够好好去爱，想做的事不必犹豫太久，还能让父母提到你时，语气里带着光。

如果此刻你也正纠结眼前的日子到底值不值得，不妨看看他走过的路：

- 13岁，用1块钱敲开网赚大门；
- 经历过低谷，却从没停下脚步；
- 14岁的暑假，用两个月撬动了不少财富；
- 为了网赚一度离开家，父母不理解，他仍然坚持；
- 后来不断开拓视野，冲进一个又一个新领域；
- 疫情来临，他逆势爆发，一周做出1亿流量；
- 放弃高考，头也不回地走上创业路；
- 一个人拖着行李，在大学旁开启租房创业的生活。

完整细节，都收进了这篇长文——想听他慢慢讲完这七年，可以点开飞书文档：

评论区里，有人说：“我13岁还在玩泥巴呢。”也有人感叹：“我23岁了，还只会老老实实上班。”可梦宸想说的是：起点低从来不是借口，真正拉开差距的，是你敢不敢早一点开始。
