# ('知识博主小红书半年涨粉20万IP打造实操复盘（生财版）', (2, 29))

我从来没敢想过，像我这样的普通人，竟然也能在小红书闯出点名堂。做学习类账号半年，粉丝从0涨到20万；如今总粉丝量32万，广告收入一年40万。今年开始尝试知识付费，两个月就收了10万。

![](img/e9f5d672ca582429905a11598d6ba6dc.png)

在这之前，我始终觉得自己没什么特别的。直到某天突然意识到“流量是很值钱的东西”——看到别人靠接广告赚钱，看到带我实习的leader全网百万粉，可他在生活里看起来就一普通同事。原来，做博主不是天赋异禀者的专利，普通人照样能成。

更让我吃惊的是信息差的力量。过去我刷到过无数文章、金句、方法，以为大家都看过，直到看见有人把同样东西搬到小红书上，竟然火了，评论区一片“相见恨晚”。我才明白：你觉得稀松平常的事，对很多人来说是新鲜宝藏。所以只要懂得筛选和转述，我也能做出爆款。

当初选小红书，是因为觉得微博知乎早已人满为患，这里或许还有机会。后来我弄懂了它的流量分发逻辑，才恍然大悟：小红书从来没有所谓的“入场太晚”，它随时欢迎新玩家。

真正开干以后，第一篇笔记就成了爆款。标题是《雅思居然考了8分，但是依然出不了国》。你看，这就是“成就+落差”的组合，天生自带冲突感。我知道这种标题一定能火，因为很早以前做公众号时，我就练过这种网感——夸张、反差、挑战常识。说实话，我当时并不懂平台的推荐机制，只是凭直觉觉得，热度会让系统推更多内容给喜欢我的人，他们点进主页，看到别的干货，自然会关注。后来证明，直觉很准。所谓网感，其实就是大量刻意练习后，思考快到连自己都没察觉。

然而爆款之后，我却陷入了低谷。因为第一篇的热度没法复制，我开始乱发日常，染个头发也发，结果数据惨淡。那时我还不懂“垂直”这个词，只觉得怎么发什么都不火了。

直到我想起最初说的“信息差”。既然第一篇是雅思，那我就去把那些雅思博主的资料、网站、学习方法都搬过来。这一招效果立竿见影，因为这类干货本来就是公开资源，不算抄袭。但我也明白，搬运永远不是长久之计。

于是我开始自己做内容，从雅思扩展到英语学习：复习计划、资料测评、网站清单，反响很不错。中间还走过弯路：用“关注后私信领资料”来涨粉，当时觉得聪明，后来才知道平台严令禁止，而且那些资料明明可以直接卖钱，白白浪费了变现机会。

很快我又卡壳了，因为我的思维一直锁死在“雅思”两个字上。怎么办？我决定不再瞎刷，而是有目的地“对标”。

我搜“雅思”“英语”的关键词，点进一个又一个博主的首页，发现除了垂直号，还有好多分享自己学雅思经历的普通人。我突然醒悟：我跟他们太像了——都是大学生，都为了出国、考研拼命努力。既然大家经历相似，我为什么不做一个“个人IP”，而是继续当冷冰冰的营销号呢？

我找到了三个和我高度相似、又起号很快的账号：二本逆袭985的软柠柠、一边读书一边打工的农村女孩niki1998、爱分享学习感悟的未央erin。有了对标，我的思路彻底打开了。

那段我做对的事，概括起来就是：大量接收信息——找到和自己相关的触点——消化成自己的东西——再融合创新。

真正让我步入正轨的，是对“选题”的重新理解。选题比内容重要得多——这是我这趟旅程最重要的结论之一。她们发什么火了，我就跟着发：二本考研辛苦、校园里独来独往、二本人生不是二流人生……很多标题我扫一眼就知道怎么写，因为那本来就是我的经历。不一定全相同，只要有相似的痛点和情绪，就能借用。

封面也有套路：讲努力，就铺开笔记、奖状；考了研，就晒录取通知书；出身农村，就放老家的稻田和城市的写字楼拼图。核心是给用户三种价值：情绪价值（佩服）、认知价值（有料）、时间价值（拿来就能用）。

在那之后，我开始一点点学着做个人IP——当时并不知道这个词。我从雅思过渡到英语学习，偶尔穿插生活碎片。粉丝的回应让我意识到，一个完整、真实、有烟火气的人，远比完美的学霸更让人喜欢。再后来，内容自然长到了考研、大学生活、人际关系。每次发这样的内容，评论区都有人追问：大学到底怎么学英语？室友总在阴阳怪气怎么办？

这些提问，成了我最好的选题来源。

我开始把私信和评论当成内容工厂。缺灵感的时候，就站在用户视角问自己：一个大学生会需要什么？学不进去、成绩不好、要不要参加社团、和老师同学关系差、生活费不够……再往深里想，生活费不够可能牵扯原生家庭、心理问题、自我价值感。这些话题，永远有市场。而且只要你足够真诚，今天做也完全来得及。

最重要的是，要垂直于“人”，而不是垂直于“内容”。解决用户的需求，而不是解决自己的表达欲。

从5万到20万粉的半年，我才真正体会了什么叫“根本停不下来”。评论私信里的问题取之不尽，写一篇爆一篇，私信又滚雪球一样涌来，形成了一个良性循环。

更大的突破，是我开始敢把缺点摊开给人看。

我按对标账号的爆款复盘自己的人生，做了张思维导图，把所有经历都盘了一遍。

![](img/4aaa60f84cdb69a95b3d379df2e94da7.png)

那段时间我每天能写一两篇，几乎篇篇都是爆款。特别是一次看到软柠柠的《不合群的女生》爆了，我意识到：大家都爱有个性的普通人。我跟着写自己不被喜欢、被人说功利、目的性强，这些“缺点”竟然比单纯的学习逆袭涨粉更快。印象最深的是，一篇只有1万赞的笔记，直接带来了2万粉丝！

所以，别急着掩盖自己的不完美。功利、算计、孤僻、敏感、笨拙……这些你拼命藏起来的东西，恰恰是最能引发共鸣的。我后来专门写焦虑症、原生家庭、自卑，越暴露自己，涨粉越快。

想让人共情，首先要让人在你身上看到自己。真实的普通人，才有资格谈经验；有棱角的个性，才让人记住；而一个完整、不完美、仍在成长的人，才让人愿意Follow。

我还建立了自己的爆款选题库：对标博主（不只小红书，不只看今年）、新晋黑马、热点、评论区，以及随时随地刷到的书摘、短句，通通存进去。

![](img/33f20e874ac62af6eb578ab040978907.png)

怎么把灵感变成可复制的流水线？关于我的写作SOP，涉及一些隐私就不展开说了。

![](img/523a736022c1d811a7f3a0c5810e540f.png)

靠着这套机制，我持续产出爆款，粉丝数量一路狂飙。涨粉的秘密很简单：爆款，也只有爆款。

粉丝多了以后，我开始琢磨怎么接广告。我通常去问同量级博主怎么报价，参考品牌方的反馈和数据平台的估价，再揣摩他们喜欢什么样的调性。于是我把封面统一成同色系，让主页看起来更干净；把广告位设计得更醒目；想接平板广告，就先发自己用平板学习的攻略；想接笔记软件的合作，就先晒自己的手账方法。慢慢地，我还会在笔记上半部分真人出镜，下半部分留广告位置——既拉近了和粉丝的距离，又让品牌更愿意下单。

从20万到30万粉，涨得没那么猛了，但这段日子让我真正喜欢上自己做的事，也重新找回了做内容的初心。

我也曾为数据焦虑到睡不着。后来想通了：如果只为了赚钱，就得容忍自己写不喜欢的内容；如果要做自己认可的内容，就得接受一部分用户和收入会流失。既然已经有了底子，继续写那些肤浅的爆款，不仅会拖累自己，也会辜负一直跟着我的粉丝。

于是我把内容重心从“过去的经历”转向“现在的变化”：记录当下的学习、工作、思考，让所有人看见我依然在野蛮生长。这半年，光是微信读书我就看了一百多个小时，家里还攒了近百本纸质书。每周复盘，保持一周三到五更。涨粉慢了，但每一篇都是我真心认可的东西。

我越来越坚定：要做能长期留下价值的内容，而不是看爽就完的速食。如果你不知道怎么输出，就回到评论区，或者想想当年的自己需要什么，然后对着过去的自己说话。你自己必须真实地进步，成长本身比任何说教都有说服力——粉丝才会觉得，跟着你，没错。

真实和技巧并不冲突。我仍然会用反差标题、非常规视角、略微夸张的情绪，但内容的目的不再是数据，而是筛选出同频的人。

很幸运，我真的等到了他们。有几千个粉丝主动链接我，毫不犹豫为我的课程付费，照着我的方法去学习。有人因此考上了理想的研究生，有人去了想去的城市，有人开始坚持学英语，还有人干脆也做起了博主。看到这些反馈，比多赚几千块钱爽多了。现在他们中的一部分人甚至成了我的团队成员，未来很可能是我事业上的合伙人。

用真实的成长互相激发，吸引认可你的人，再把价值一起放大——这件事简直太棒了。

回头看，小红书现在才算真正站上了风口。早期只是微商、美妆玩家误打误撞，现在各路运营大佬、品牌商家都在涌入；百度还专门给小红书开放了“笔记”窗口，把搜索流量直接导了进来。

而我能做成，其实只有两点：一、先把自己从50分提升到70分，让自己有说服力，再想尽办法为50分、60分的人提供价值；二、认识自己，也看懂人性，发人们真正需要、愿意看的内容。

经常有人问：“没有好成绩，也能做个人IP吗？”我的答案是：人人都能做，而且都该做。哪怕你只有60分，也可以帮50分的人；只要你愿意在某个细分领域钻研到70分，就永远不愁没用户。我自己后来也逼着去学编程、学写作，再把方法传授出去。

加入生财后，我的视野又开阔了不少，知道了更多变现手段。以前我只靠广告和知识付费，现在结合平台规则，还摸索出了利用推流期涨粉、卖号、引流、矩阵这些玩法。希望接下来能在这里结识更多大佬，深入解锁每一种新玩法。
