# 从月薪三千到带 257 人团队：我在赚钱圈子里完成的蜕变

> 这篇文章不是教程，只是一个普通人走过的一段路。

各位朋友好，我叫思蒙。

几年前，我每个月只拿三千块工资，在工位上搬砖。今天，我带着两百多号人一起做短剧赛道。听起来挺魔幻，但确实是我一步步走过来的。如果你刚进这个圈子，面对满屏内容毫无头绪，也许我的经历能让你安心一点。

新一期赚钱社群马上就要开始了，圈子里已经有不少牛人发过新人建议。我本来觉得自己没资格说什么，但转念一想：我从完全零基础，到现在能带着一个 257 人的团队往前跑，这段变化本身，可能比任何方法都更能给新人信心。

我知道，“老圈友”和“新朋友”里都藏龙卧虎，各有各的本事。但像我当初那样，一进来就是张白纸，看到好内容兴奋得不行，关上页面又什么都不记得的人，肯定也不少。所以，我趁着这一期开营，把自己这几年的脚印重新踩了一遍，分享出来，供你参考。

文章大概分六块：

1. 我的起点和现状
2. 刚进来时的傻眼
3. 下场试水却受挫
4. 死磕到第一个爆款
5. 混圈子带来的意外收获
6. 短剧项目与带队经历

有空的可以从头看，没空的挑你感兴趣的段落。

先说说我的情况吧：

2020年10月，我进了这个圈子。

2021年，总共赚了两千多元。

2022年，不到二十万。

2023年二月和三月的收入，就已经超过了我以前上班时最高的一年的年薪。

这些年在圈子里写了六篇长文（作业不算），其中两篇被加了精华，另外四篇被收录进每周精选。跟真正的大神比，这根本不够看。

但一个四万多人的圈子，不可能个个都是大神。像我这样从零开始，慢吞吞积累，最终能赚到钱的，才是大多数人的故事。普通人的样本，可能对你更有参考价值。

我生于1993年，家在西北一个普通地级市，全市不到六十万人，放在南方也就一个县城的规模。

大学四年，我沉迷摄影、设计和骑行，曾和朋友从西安一路骑车到青海湖，往返超过一万公里，街拍照片攒了过万张。

毕业后，我先后进过两家公司，都做到了区域主管，可最高月薪只有八千块。

2019年，我回到老家和同学合伙开水果店，两年里连开三家，结果撞上疫情，又遭了一场火灾，合伙经验也不够，最后我主动退出，至少保住了朋友间的情分。

![](img/036cd4467c7b281db41ed1c4c20e36c9.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

刚进圈那天，我彻底傻眼：页面上全是标注了“精华”的文章，和一堆牛人的战绩。越看越心虚。更要命的是，我完全没想清楚走哪条路。每条赛道都有人晒收益，可我适合什么？能做什么？脑中一片空白。

加上当时还有工作，我就这么一天天拖着，今天看这篇，明天看那篇，到最后连打开圈子的兴致都没了。偶尔刷到别人晒收益，只会觉得那些人和我不在一个世界，甚至怀疑自己是不是白花了这笔钱。

后来总算鼓起勇气跟着一场实操试了试，确实落袋了几百块，但耗进去的时间太多，性价比太差。再看看别人，似乎随手就能月赚五位数，而我累死累活一天只进账几十，心里一凉，干脆又停了。

![](img/24e69a9b50076202f8aa6803621629ff.png)
![](img/55386bd514002bb6839f5d97a7cee94e.png)

这一停，又是六十多天。

一边为钱焦虑，一边又懒得上进。后来我实在受够了，告诉自己：我现在穷得只剩时间，哪怕失败了，也不过是浪费一点时间而已。想通这一点，我又翻出了那些收藏的帖子，找到一个有点把握的方向，反反复复研究了三遍，联系了分享的老师。结果对方表示要交学费，数目还不小。

我犹豫了几分钟，又劝自己：进圈子的钱都出了，现在看到可能的机会，反而舍不得了？于是心一横，付了学费，跟着老师认真做。

后面的事，顺了很多，我也把这段经历整理成了自己的第一篇精华文章。

![](img/f0d732a64e742debd24cad358429ec0d.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

不过，刚开始我确实想得太美。

我总以为一两个月就能见效，结果三个月过去，账上多了两千元。那些“月赚上万”的故事，怎么在我身上就不灵了？

嘴上可以抱怨，但行动不能停。我继续研究平台规则，看别人如何赚到钱，对照自己的差距，一点点改。后来平台突然调整，同行都在转型，我也是最早反应过来的那批人之一。调整的过程很痛苦，但结果告诉我，这条路是对的。

又过了一个月，我有一条视频播放量破了百万。可惜当时游戏还没上链接，一分钱收益都没有。

再过一个月，又来了一条小爆款，这次赚了一千多元。那是我第一次在一天里收入过千，兴奋得当场在群里发红包。从那时开始，我的月收入从六千涨到一万二、一万六，再冲到两万一……

这段反复被打磨的过程，也让我真正弄懂了视频内容的根本规律，于是有了后面的第一篇精华，以及那几篇写养号、账号标签、限流问题和内容逻辑的文章。

![](img/872c5b232e048e35693582cfc39c6e13.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

拿到第一个“精华”时，我有些不敢相信：一个没赚到多少钱、分享内容也没什么深度的人，居然也能被选中？

直到现在我还觉得，是龙哥特意照顾了我。也许他心里清楚，第一篇精华对新人来说意味着多大的鼓励——它会让人相信，自己也能一步步变好。

反正从那时起，我就打定主意，以后要一直留在这个圈子里。

方向稳定下来后，我开始关注别的机会，才发现专注做项目的这段时间，已经错过了好几个看起来更诱人的风口。但我并不后悔：就算我当初选了那些方向，以我当时的积累，未必做得起来。

所以，别为错过的东西纠结，守住眼前的路，才是正事。

不过，原来的方向并没有一直顺下去。大概在过年前后，它开始出现波动，我也加快了寻找新方向的节奏。

正好那时，成哥让我去测试一个玩法。我第一天准备好账号，第二天动手测，第三天看到数据不错，就开始批量放大。那是个短周期的“薅羊毛”机会，好的时候一天能进账几千甚至上万，前后持续十来天，算下来赚了好几万。

做到第五天时，我已经赚了近两万，为了感谢成哥，我给他发了个8888元的大红包。神奇的是，接下来两天收益反而下滑了。机会结束后，我还跟他开玩笑：“幸好红包发得早，不然我可能就没这么大方了。”

![](img/913a4afba08d4a526a925a74d7f65939.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

这一段和时间线没关系，算是另一条成长线。

在我埋头做事情的那段时间里，我其实很少打开圈子，连一次义工服务都没碰过。直到方向相对稳定，我才重新露头，开始参加各种实操，并主动报名做义工。

做义工听起来是付出，但我得到的远超想象。我认识了不少值得深交的朋友，也近距离见识了社群运营和活动落地的很多细节。那些细节单独拿出来很不起眼，串在一起却特别高效，既让组织者省力，也让参与者感到舒服。

所以，我真心建议有时间的圈友——哪怕你现在没有项目，也至少下场参加一次实操，或者担任一次义工。只有亲自下水，才知道什么叫标准流程，什么叫团队协作。

后来，我还有幸被子安和静伟老师邀请，担任抖音游戏实操营的教练，跟大家一块儿编写手册。那一次让我看到，真正专业的实战手册应该长什么样。这也为我后来带团队和拿到第二个精华打下了基础。

说实话，做那些事的时候，我根本没想过有什么用。当时经常忙到晚上十一点才开始动笔，写完已经凌晨一两点。最夸张的一次，我在外面办事，子安临时喊我做分享，我只好在车里开着热点硬撑着完成。

也正是这些经历，让我后来带队时，少了慌张，多了从容。

![](img/802b1bee5146f0cac9e6251408d29ad4.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

回到主线。原先那条路线开始波动，过完年我一直在物色新的方向。

有次在社群里翻到一篇讲短剧的文章，突然想起之前朋友也随口提过这事。再后来，我又在👸号看到有人分析同一个赛道。龙哥说过，当一个词反复出现的时候，你就得留意了——背后可能藏着一个大机会。

于是，我马上联系渠道，付费学了一遍，花了两三天把整个玩法跑通。接着，我用在圈子里学到的写教程方法，把短剧推广的玩法梳理成一份手册，发到了社群里。

其实我一开始没想过要带队，但这个玩法和以前的逻辑很像，操作还更简单。想了想，我就拉起了陪跑群，把首批用户接了进来。

做交付的时候，我把当义工时攒下的那些经验全部用上了：提前备好沟通话术、整理常见问题清单、定期开直播、请表现突出的同学做分享，还做了一张信息量很大的思维导图。这些东西都是从各种实操和课程里一点点学来的。

很幸运，在帮大家赚钱的同时，我也赚到了很多感谢、红包和认可。甚至有一位渠道负责人看了我的内容后说，他们本来不允许收费，但我分享的东西确实有价值，完全可以靠这个变现。

![](img/df3a02386bcad4f67bf39882aa87ea1e.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

这些能力，不是做完短剧才有的，而是之前做过的事、走过的路，一点一点堆起来的。

我第一次组织陪跑，就得到了两百多位朋友的信任。还有很多人告诉我，成了我的“小迷妹”，以后愿意继续跟着我做事。这种被信任的感觉，比赚钱本身更让人踏实。

而这些，是当初那个一进来就发懵的我想不到的。

![](img/c31fc46d7436caeff3b6b4e3bb3d69e5.png)
![](img/6b57f376b519f6f3800ddf8e85cf5b37.png)

最近，除了运营陪跑群，我还在学直播和 AI 画图。圈子里要是有这两块的玩家，或者正准备入局的朋友，欢迎来链接。

今年，我给自己定的目标是五十万，明年争取翻倍到一百万。我不是那些已经打通任督二脉的牛人，他们可能一年随便做做就挣一百万。但对我来说，这个目标还差得远。不过有一点我越来越确信：只要认真选一个方向，做到每个月五位数收入，已经没有太大悬念。

这种底气来自哪里？来自这几年每一次成功或失败的经历。它们一点一点积累起来，让我敢想以前不敢想的事。

我是思蒙，欢迎你一起，在这个叫赚钱的圈子里，找到属于自己的路。
