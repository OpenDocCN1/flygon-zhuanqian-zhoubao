# 13岁起步，20岁月入六位数：我用七年时间从1块钱撬开创业世界



大家好，我是梦宸，现在是04年的大一新生，老家在河北廊坊一个普通的县城，出生平平，可骨子里一直不甘平庸。

2016年我13岁，兜里只有1块钱起步做网赚。算到今天20岁，已经是大一在读，月收入上六位数。

这七年里，同学都在暑假打游戏追剧，我却在琢磨怎么把钱赚到。通宵研究新玩法，项目砸过，父母反对过，可我就是那股不服输劲儿在支撑。

写这篇文章，就是想告诉所有人：努力赚钱，因为钱是治愈自卑最直接的底气。

2023年的我还是大一学生，心里一直有个念头，想一个人去杭州看看，吹吹西湖夜风，晒晒灵隐寺的阳光。后来我真的去了，也亲身感受到了电商和自媒体之都那种扑面而来的创业氛围。

我想让爸妈提起我时嘴角上扬，成为别人家口中那个“别人家的孩子”。所以我给他们带了西湖龙井和杭州特产，一口一个“儿子非要给我买”，那一刻大概就是父母最骄傲的瞬间。

努力的意义，大概就是能说走就走，也能让家人因为你而发自内心地笑。爱自己喜欢的人，做自己想做的事。

如果你偶尔会怀疑当下做的事有没有价值，不妨看看我这七年的轨迹。点滴拼凑成了今天的我。听完我这段创业经历，或许能给你一点启发。

# 一.13岁起步的网赚传奇揭秘

2016年那年夏天，我刚小学毕业。无意间被拉进一个QQ群，群里大家都在刷QQ业务——会员、黄钻、绿钻、名片赞、空间访客这些。

当时年纪小爱虚荣，也想拥有这些，却没钱。口袋就一丢丢现金，刷不起给自己刷。那就先帮别人刷，赚了钱再给自己刷。

去哪刷？找渠道。百度搜到一个叫辉煌卡盟的网站，一万名片赞只要四毛钱。巧的是班级群里有人发红包，我抢到了一块钱。就这一块钱，成了我网赚的启动资金。

流动资金只有一块钱，只能做最便宜的名片赞。第一步，要让人信任你，得先有赞自己刷。我先花四毛给自己刷了一万赞。

接着我以一块钱的超低价接单卖给别人。可我没资源怎么办？先从同学朋友下手，便宜到一块钱，五六个同学就找我刷了。

![](img/d2d59cec0a586df2a21665bb84e43fd2.png)

光靠熟人不行，得放大。我脑子里冒出一个念头：自己建一个像当初被拉进的那种QQ群。执行力上来就干，直接把QQ好友全拉进来，再让同学朋友帮忙拉人。很快群里有七十多人，生意明显变好，每天十几单，客户还会带朋友进来。

很快撞到瓶颈。于是我加入了一些QQ兼职群去打广告，继续用一块钱的低价引流，既攒了资金也积累了人脉。但我骨子里想站到食物链顶端。

我找到辉煌卡盟的站长问怎么搭网站。了解到可以建分站，普通版150，专业版250。那会儿我手里攒了大概300块，直接上专业版。

![](img/f22810ffca344c7962d226a6c74c8d86.png)

目标很明确：让更多人知道我的站，从中赚差价。我在自己的QQ群里宣传，告诉大家现在可以直接自己刷，还能帮别人刷赚差价。

就这样，六年级暑假那两个月，我赚到第一桶金。虽然只有一千多块，但全是自己挣的，开心到不行。

梦宸小课堂：

1. 年纪小但敢想敢做，执行力拉满，赚钱其实不难。
2. 没钱没人脉很正常。没钱就从零成本入手；没人脉就先从身边朋友起步，用价格战引流，亏本也要把量做起来。
3. 拿到结果别躺平，要想办法升级。

# 二.虽然经历低谷，但从未停下脚步

父母希望我接受更好的教育，放弃了老家免费读公立初中的机会，把我送到衡水读私立初中。

说到衡水，大家第一反应就是地狱式教育，没错，就是那个。暑假网赚的经历让我爱上了研究项目带来的感觉。

衡水的模式是全封闭，一个月只放一次假，放两天，回程就占一半。我家离学校200公里，手机都带不进。等于是每个月只有一天能管管卡盟网站。

一天能干嘛？网站销量直线下滑。七年创业，有六年都是一个月只上一天来经营。

可我不怕。哪怕只有一天，也要把这一天用满，把这一个月欠下的事补回来。直到初一暑假，我迎来了小高峰。

梦宸小课堂：

一个月只有一天假期也能把事做成，关键是把碎片时间用好。

吃饭时看一篇干货文章；公交地铁上刷风向标保持敏感；累了读点纸质书放松大脑；睡不着听点商业电音频。

# 三.疯狂暑假赚金，14岁少年两个月撬动财富

终于等来暑假，我想大干一场。看到一个人在QQ群里卖快手直播号，行情很火。我了解清楚后付费跟他学了888。

那是2017年，快手直播还在内测，大部分账号没权限，只能靠作品上热门自动开通。我们做的就是注册新号开通权限后卖给号商。注册零成本，快手当时管控松，没设备、IP限制。

我拿着旧苹果5，一台机同时注册5个号，一天就能把普通号变成有直播权限的号，转手40-50块卖掉，纯赚。

号商需求大根本不愁卖。靠这一个暑假，我赚到人生第一个五位数。

![](img/aa0257497665061cd7976030f38ebdec.png)

梦宸小课堂：

1. 做项目前先判断前景和自己适不适合，知己知彼。
2. 该花钱买时间就花。选对人付费能省大量试错成本，别被割韭菜。
3. 项目跑通就要放大，我当时年纪小，没能力放大，很后悔。

# 四.离家追求网赚，父母不解我心

那时我妈在做刷单，一单几块钱。我把我的玩法告诉她，换来的是指责和骂，说我这年纪不该赚钱，好好学习就行。回想现在，话也对，14岁确实过早。

第二天我爸知道了，非要问钱从哪来。我说网上的，他们不信，直接摔了我手机。

我气不过离家出走，在县城里晃到凌晨三点，最后还是妥协回家。和父母谈了很久，表面上我认了错，但心里不甘。

说实话，那段时间的网赚确实拖累了学习，最后只能上专科。

梦宸小课堂：

初中高中阶段，重心必须是学习。考上好大学更重要。

别丢了西瓜捡芝麻。过来人说句实话：上学没上好，钱也没赚到，最惨。赚钱的机会未来还有很多。记住一句话：是金子总会发光。

# 五.开拓新视野，拓展新领域

父母的话没让我停手。每月一天假期和寒暑假，我仍在搞钱。直到快手把直播权限普及到所有实名账号，我的生意自然死了。同行转做粉丝号，我也撤了。

机缘巧合进入了撸界圈子。第一个加的QQ群群主叫二郎，群里发👸号撸羊毛活动。

我看中的不是几块钱羊毛，而是能建群。通过转发活动建立信任，后续再收徒带付费项目。

引流是难题，我把QQ好友全拉了一遍才100多人。于是我想了个办法：建个QQ小号，名字改成“空间看莉哥视频”，空间放群二维码，配上文案，拉到各种2000人禁言群。别人看到邀请记录，好奇点进空间，就被引过来。三天引到第一个2000人QQ群。

![](img/71d0a22daf5b8605b35e590e4ec3c1f3.png)

引流快但敏感，对同行也不友好。我立刻停手，转而融入撸界大佬圈。

当时很流行组团队，茗门团队招人，要求有一个2000人QQ群。我刚好符合，进去后看到完全不一样的世界。大佬们都在互换资源，我用一个2000人群去换资源，很快有了第二个、第三个、第四个。

一个月从新手变大佬。瓶颈来了，我又找新方法。刷快手时看到有大佬发QQ技巧视频引流。我用小号混进去，发现三小时就能引满2000人群，而且全是精准学生粉。

我是行动派，立刻开号模仿。前几天没流量，突然一条几万播放的视频爆了，群里多了1200人。引流爽，但不会变现，就抄同行。他用赚钱APP拉新变现，我也跟上。一个月引了20个2000人群。

![](img/1e4ead93c3ae894a34fbcbf0a41c2bde.png)

可初三开学要中考，学习压力越来越大。20个群没人管，毕业后再看基本不活跃了。不过那一个月变现了3万左右，还是很开心。毕竟上学无法改变。

梦宸小课堂：

1. 引流本质是用人性。好色、想白嫖这些心理都是切口。
2. 学会向上社交，链接大佬。
3. 先抄后超，守破离。最好的老师就是同行。

# 六.疫情中崛起，一周内斩获1亿的流量

2020年高一寒假，疫情爆发，也是我初中高中六年里连续赚钱最久的一段。

刷抖音刷到影视剪辑直播间，视频动不动几万几十万赞。我也试了几条，播放只有500。果断花899付费学习。

学完后第三条视频就爆了100万播放，自信心暴涨。

但抖音第一次大范围打击影视剪辑，80%账号收到限流通知，整个圈子懵。只能申诉，我没通过。

没放弃，注销一万粉号重新起。五次被限流后，第五个号才申诉成功。

每天看电影电视剧、剪辑、研究开头钩子、过度和悬念。封城在家，日夜都在剪辑。

两个月后，一条视频5600万播放，120万点赞。热度最高时开直播，瞬间1.4万人，场观59万，收音浪2000块。直播只做一件事：收知识付费学员，一场400多位。

![](img/50436fe301648f430beb6f2125aa2b53.png)

抖音吃到甜头后，我去试快手。没直接搬运，先研究同行。发现快手对混剪要求严格，抖音那套不行。

研究明白后开干，发一条爆一条，几十万上百万播放。开通创作者激励，每天稳定几百收入。

![](img/8d7cd4762645e5a8ce978cfc51cc11cc.png)

后来开学了，高中三年学业更忙，快手抖音长时间断更，号也废了。这段算是我连续赚钱最长的一段时间。

梦宸小课堂：

1. 遇到困难别放弃，调整心态克服。
2. 去新平台前先搞懂底层逻辑，别瞎做。

# 七.放弃高考，勇闯创业天涯

高三寒假，我做了一个决定：放弃高考。并不是不上大学，而是走河北的单招考试。

单招只能上专科，我成绩一般，高考未必能上本科。父母嘴上尊重我，实际心里不希望我走这条路。走单招，高三下就能不用去学校，有大把时间搞钱。

当时想继续做影视剪辑，但两年过去，领域早已内卷，靠剪辑上热门难了，更看重原创。

我转向影视解说，难度更大，要写文案，还要学PR剪辑。之前都是手机剪映。

每天看片记时间轴，写文案改几十遍，配音剪辑。不算看片，一个1分半的视频最快3小时。我一天更三条。

![](img/85f2afb2a2dbd85d2dd5ccb03e149150.png)

![](img/aa5fe48b682e4c328beb20d1bb40cfbe.png)

坚持了三个月，涨了1万粉，只有一条400万播放。意识到抖音影视风口已过。

![](img/4c8934fd883b51bf843d379788c6669a.png)

我养成了个习惯：有个独立微信号，加所有抖音快手小红书引流的号，专门看朋友圈看他们在做什么项目。

朋友圈看到有人做抖音好物、闲鱼无货源，还有团队在做拼多多短视频带货。团队很团结，天天晒收益，有几千也有几十块，很真实。备注显示是通过直播间加的，我立刻去蹲直播。

直播的晒单和话术都把我吸引住，直接花499加入学习。进团队后看到的和朋友圈一样，全是晒收益，闻到了钱的味道。

其实没那么多玄机，方法和技术到位了，剩下的就是干。我没搞矩阵，就靠一个账号，三个月赚了4.6个w。那时候我脑子里只有一个念头：学她，开抖音直播，带学员。

不过我不是那种冲动型选手。开播之前，我先把直播间的推流逻辑研究明白了，又把怎么拉数据、稳流量的套路练熟，文案也反复打磨过，这才敢点下开播键。

![](img/bc6753edc9a1b228e9f90f3b97c529de.png)

第一个月，稳定在线人数50多，单场最高1000人，每天私域能进15个左右，平均一天成交1到2单。到了第二个月，直播间同时在线峰值冲到3900——一分钱推流没买，全是自然流量。四个月下来，499的客单价，收了400多学员。

![](img/fb3952110078cc4545007b53b2f3e21f.png)

但紧接着就撞上大问题：大一开学了咋办？宿舍又吵又乱，在那种地方直播，效果拉胯，心态也容易崩。梦宸小课堂：如果你在一个项目上死磕很久都拿不到结果，就别死磕了，这是在提醒你该换赛道了。

八、孤独启航，租房创业

办法总比麻烦多。宿舍不能播，就到学校外面租个房子走读。租房、签合同、打扫卫生、组装桌子、买设备……所有事都是我一件件自己搞定的。

![](img/063b323c4fce3ae06ee91f9c986f3a1c.png)

![](img/1351ab49837bde083a2cb5088467e19e.png)

那时候才真正体会到，一个人出来创业有多难，身边的同学朋友根本理解不了。他们问我：宿舍一年才800，外面一个月一千多，图啥？我笑了笑，没说话。是啊，要不是想闯一把，谁不愿意住宿舍？可我已经走上这条路，没人逼我回头。

那段时间，上午上课，下午窝在出租屋里干活，一直干到晚上12点。无用的饭局和社交，我全推了，留一两个真心朋友就够了。其他人，不过是大学里的过客。他们想过什么日子，跟我无关；我要去的地方，和他们不一样。

我的危机感一直很重。专科只有三年，两年在校，一年实习。也就是说，我必须在这两年做出点成绩来。当初爸妈反对，我没听；苦熬了这么久，更不可能半途而废。

读大学这几年，我的目标特别清晰：第一，攒下创业本钱；第二，低成本试错。校园里试错不吃力，失败了也不至于伤筋动骨。多试几次，总能找到适合自己的路，总好过一毕业就迷茫。

我这人天生爱折腾，受不了那种一眼望到头的稳定工作。对男人来说，房子、车子、彩礼、娶媳妇，哪一样不是沉甸甸的担子？就算本科毕业在大城市拿一万多一个月，想攒套房也得攒到猴年马月。

所以从去年开始，我同时做拼多多短视频带货和抖音直播引流创业粉，一对一教学员。市面上的项目再多，永远有人赚也有人亏。拼多多短视频带货对新人很友好，因为知道的人还不多，正处在野蛮生长的红利期。

我的态度就一句话：该赚钱的年纪，别跟我提佛系。

创业这条路，注定是孤独的。一间屋子，一台电脑，一个人。剪片子、开直播、带学员，全都是我一个人的活儿。没有团队，没人分担，遇到坎儿哭也没用，只能咬牙挺过去。挺过去了，才能见到彩虹。

创业是一场看不见硝烟的战争。把目光放远，今天的孤独都会变成日后的筹码。我一旦认准的事，就直接All in，猛干。别想太多，执行力拉满，把退路堵死，逼自己一把，这就是我的玩法。

七年创业经历，到这里远没结束。我才20岁，未来还等着我去折腾。
