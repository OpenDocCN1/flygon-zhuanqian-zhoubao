# 小白入局二奢一年，月净利稳定30万+的实战复盘

很多朋友一听到奢侈品二奢就觉得门槛高、不好玩。我自己是从零开始切入的，真实感受是没那么玄乎。这个赛道唯一的硬门槛其实是启动资金，只要钱到位，货源链打通了，就能分到一杯羹。

入场方式并不唯一。资金充裕可以开门店、搭直播工作室囤货直卖终端客户；资金有限也可以先做个轻量工作室，收来货直接转卖给同行赚差价。

下面我用过去一年从新手到月稳利润30万+的心路历程，把二奢的经营逻辑拆开来说，希望能给大家一点参考。

# 一、自我介绍

我是凡响，目前在杭州做抖音二奢直播。以下内容主要聊二奢行业的底层生意逻辑。

# 二、身份背景

2021年我加入龙哥盟，算是老圈友。2022年初搬到杭州，和朋友合伙进军二奢。

这一年里我轮过同行贸易销售、私域负责人、中台负责人、公司总运营、直播后端负责人、客服、供应链负责人、财务等多个岗位。

2021年1月1日门店开张，到现在满一年。我们把杭州最大的二奢同行贸易供应链做出来，抖音二奢类目黑马榜一度第一，单月GMV峰值1500万。

# 三、第一次接触二奢

团队的起势有点意外。

2021年在北京做SaaS，年底融资受阻，几个人想找新赛道。先用短视频代运营试水，第一个客户是合伙人师兄介绍的，杭州那边要做二手奢侈品，正好对口。

线上开会确认了服务边界和收费方式后正式接单。运营团队2020年6月就开始组建，一边调研行业一边找变现点。

和几位同行聊后发现，现在做二奢的基本都是有点积蓄的小老板。行业头部一年也就20亿左右，基本都是快速起来的项目。

于是我们去报了鉴定师、养护师的班，同时在身边挖有经验的老师。认识了个开了十年门店的老朋友，沟通后他投了50万入局。

2021年12月公司正式成立，模式是门店+工作室起步。

# 四、创业推进线

### 1. 小步试错
行业里主流打法有两种：同行贸易和直播带货。我们选了两者兼顾。

直播由合伙人带原北京同事负责，虽然没经验，但通过快速复盘启动。早期试过复制同行账号、做“二奢老板娘”矩阵，效果一般。

同行贸易先跑通：先找货再卖货，单量上不来。后来把找货和卖货拆分，人效立刻提升。

模式验证后就扩销售团队，身边靠谱的人先做销售，做熟后转回收。同时从外面挖了几个回收手，回收量直接拉升。

### 2. 野蛮扩张
2022年3月完成60单，4月150单，5月300单。

人到30人，6月搬到800平办公室，直播间扩招。主播薪资从7000提到15K，人到60人。为了解决回收缺口，又租了400平作为供应链部门。

同行贸易月销300万，直播GMV突破200万。

### 3. 战略失衡
7月管理层犯错，把资源全砸向直播，供应链没货可卖。

当时设想下月直播GMV到400万压过同行贸易。公司分两块：供应链每月收500万，直播每月卖500万。直播毛利12%，约60万利润。

8月人增到90多，供应链30人，直播40人，仓储6人，销售6人，短视频运营4人，行政财务4人，售后4人，养护3人。

9月四个直播团队已盈亏平衡，但资金吃紧，招财务并开始裁员。供应链负责人和核心骨干离职。

### 4. 快速崩盘
10月裁员慢，人剩70。引入新直播负责人，公司供货扶持。

11月10日公司解散全体员工，两位副总离职做中古供应链。回收部几人承包办公室定向找货。投资方派人盯账，仓库货物被抵押带走。一层办公室转租给四支前员工团队。

我开始对接资方，处理直播外的事务。

### 5. 破釜沉舟
只保留最看好的主播，用最低配团队：客服、运营、中控全是新手。无底薪，只分利润。

和行业头部供应链谈赋能直播+深度绑定。短视频运营批量剪直播切片，团队每天必须播一场，没包就去包展、门店走播。

流浪一周后落地供应链小房间开始开播。

### 6. 起死回生
11月14日一条视频爆了，直播间流量被救回来。我们一度准备放弃直播回头做同行贸易。

当时没办公室，只能在门店凑合处理抖店和提现。11月GMV做到700万，百万播放的视频一条接一条。

12月GMV1000万。主播客服不够，从供应链借调主播和中控，每天两场12小时播。

1月初我收尾公司事务后下场当早场客服。1月GMV1500万。

### 7. 谋求独立
供应链开始限流。他们两间直播间因我们带动业绩翻倍，反过来想约束我们。

我们决定自建寄卖商家、店铺运营和完整体系。招主播和中控，人员质量不达标，最后只稳定一个客服。团队扩张很困难。

### 8. 稳定期
2月业绩回落，筹备独立办公室。月底净利润仍有30万。

2月底搬入独立办公室，新增标品负责人和中控。

### 9. 团队强化
3月GMV600万，80%来自自接的二奢寄卖和标品，只有小部分是供应链货。

业绩继续下滑但不亏损，利润约20万多。抓住红利期回笼资金，偿清了对资方的债务。

新增店铺运营负责人管后端。

### 10. 重新定位
3月底复盘，连续三月下滑，通宵开会重新定方向。

直播流量很稳，最大瓶颈是货源。转型期还没适应。

明确两位主播分化：一路走不可复制的达人路线，主做流量，接精选联盟全品类，月利润约15万；另一路做可复制的精品二奢包包直播间，月利润约10万，配置仅主播+中控两人工。未来复制团队扩抖音流量入口。

## 11. 核心关键路径
行业本质是套利。

第一步是货源。没资金很难玩，至少要有启动金，甚至信用卡额度也行。

最稳的出货口是直播，可以接同行寄卖。

直播货盘分三类：全新爆款、中古深库存、二奢利润品。

全新爆款入局：找海外买手，欧洲专柜折扣拿货。周期约15天到手，国内3天内清掉，单件利润1000+。

出货还可以走闲鱼。桐庐有同行闲鱼月GMV200万，利润率10%，月净利20万，资金需求约100万。

给直播供货对供应链要求极高，要持续迭代。

# 五、四个前员工组建的团队现状

拆出来的四家公司各走各路。

中古深库存团给我们供货，一个月资金周转300万，转两圈，一个销售就能出完，单件利润10%，月利润60万。

第二支做定向找货，对接上游大收渠道，几个人跑闲鱼、微信群找品类供货商，月入十几万。

第三支延续我们老模式，找销路自己收货，快进快出，50万资金滚，养活一支团队。

第四支对接门店，收门店客户货转C端销售，一人操作月入十几万。

目前看，我们十几人的直播间利润反而是四支里最低的。

# 六、做好关键路径的关键之关键

怎么找优质渠道？

1. 入行先找好导师。大家都忙，愿意带的人少。市面上80%货差价不大，优质商家都有代卖，不好出量。
2. 找到上游后持续学习。有个代理跟着我学，每天看微商相册，上千次浏览，半月出货。后来自己找了源头全新品压资金做。
3. 社交能力决定上限。他的社交比我强，现在囤货几百万，也成了我的全新爆品供货商，二奢直播公司都从他拿货。
4. 换群拉群创造价值。入行时我不认识品牌，就疯狂经营微信，建了60多个同行群，在圈子里建立影响力。新人通过我找合作，现在他们也成了我了解行情的眼睛。

解决供应链端流量是赚钱核心，同行资源最好拿。

# 七、二奢供应链业务的逻辑

包包流动是：供应链-中间商-消费者。直播兴起后，很多公司轻资产做直播抢C端流量，给重资产供应链带来机会。

重资产供应链核心看动销率，受前端直播需求和后端源头供应影响。源头对快速回款需求极强，资金压在运输途中，只有快出才能进入下一轮。

举例，150万资金，从国外专柜到国内要15天，每天压10万约10件。一个月可完成300万流水，利润10%即30万。资金1500万可做到月利润300万。

作为源头与直播之间的供货商，资金比例约3:1。

假设有150万，100万常压在货上保证随时有货，50万机动采购。每天出3件，一个月转一圈利润5万；每天出9件利润15万。环节简单，只需打通源头与直播关系。

行业内每个环节都在竞争。

# 八、整个行业的逻辑

妃鱼链接全国门店供货，用强直播能力收货。小花在私域早布局、很强。北京胖虎直播运营很强。杭州桔夕家靠胡兵成为头部。

我们现在只有两位主播，但今年有信心进第一梯队。

# 九、一些具体操作与建议

### 1. 行业基本盘
国内二手奢侈品分现代款和中古款。现代款是近几年在售款，价格透明。中古款已停售，年份早，价格不透明。

盈利逻辑是低买高卖。

流通链路：工厂→专柜→首位买家→回收商家→出货商家→终端买家。我们要卡在中间吃差价。

各环节作用：
专柜：地域折扣差异，全新货源地。
首位买家：专柜个人买家，闲鱼上很多，但需甄别同行。
回收渠道：闲鱼定价不准可捡漏；微信群看商家上新；奢当家SaaS可线上展会；包展北京上海杭州苏州成都深圳每月有，LGE最大；大型回收商对外放代理；大型洗护商如天津包拯积累百万用户，寄卖价低；日本七大中古交易所可拍货。
出货渠道：有需求的二奢商家；囤货急出；社交平台低价；包展清库存。
终端买家：通过线上平台、社交、个人关系联系，以高价成交。

### 2. 收货渠道
闲鱼搜LV Gucci 香奈儿，私聊要微信。
小红书搜二奢包包奢，关注私信拿联系方式。
微信群加好友自我介绍要微商相册。
包展关注LGE公众号报名。
奢当家APP注册并开通线上展会。

### 3. 售卖渠道
闲鱼是最大二手池，直接挂卖。赚钱很多玩法就不展开了。随意挂也能被商家找上门。

80%来找的是回收公司，砍价低于同行就放私域换群。

同行群要合规养号：账号养一个月，24小时加好友不超过12，每三小时换群，每次不超过10群，广告不超过3图，4小时发一次，每次可发200群。

朋友圈日更100条，描述详细，同行第一步是搜朋友圈。找到你后问价，收钱确认需求可溢价。

和固定直播间长期合作供货。了解直播间可卖品类，持续找货备货。

直播间最看重数据其次利润，可低价供让他们赚钱扩复制。

得物可卖，规则看全新程度，保养过的全新也有机会，流程快可多次转卖。

包展可一日清货，但成本高市场饱和，有品类优势再考虑。

### 4. 风控
正品有流通价值，小绿牌是正品基准。鉴定师培训约2万，6天培训+1天考试。

在二手奢侈品这个圈子里，最怕的就是收到假货。想避开这道坑，其实有几个现成的办法：闲鱼买东西可以走验货宝，花78元让平台先做鉴定，万一这样还能收到假货，平台负责赔你；也可以找本地的鉴定师付费验货，30元只出结果不包赔，90元则承诺包赔；另外还有一堆收费鉴定软件也能救急。平时多跟鉴定师走动走动，关系熟了，让人家顺手帮你免费验个货也不是难事。

新人想入局，先看清这个二级市场的玩家结构。第一类是直播公司，比如桔夕、胖虎、妃鱼，他们直播间、回收团队、线下门店都配齐了，业务路径清晰，体量也大。如果你资金够、团队也有底气，想在这行分一杯羹，现在入场时机不错——正面去抢一个生态位，等赛道继续做大，红利自然跑不掉。第二类是线下门店。没有实体店，业务量基本很难起来，因为门店自带信任感。开一家店约需200到300万资金，备货100件上下，选址要挑消费力旺盛的商业中心，装修得有档次，人员配备也很轻，一个店长加一个店员就能转起来。第三类是个人工作室，通常就自己在家干。这种模式的核心是流通，不压货，收进来就赶着卖出去。

给新人的建议很直接：去考个鉴定师证书。脱产学只要7天，还有终身服务带你入行，先从回收身边人的包练起。这个证我觉得任何行业的人都值得拿——技能越老越值钱，而证书的门槛随着行业成熟只会越来越高，早考早省心。

最后说说我自己的故事。

这篇文章聊的，是我们一群完全没碰过二奢的普通人，过去一年从探索到野蛮生长，再到迅速崩盘，最后逢凶化吉、扭亏为盈的全过程，也夹杂了一些我视角下的行业观察。文末还写了不少实操细节：货源怎么找、出货渠道怎么搭、怎么才能在这行赚到钱。

我为什么偏偏选了二奢？最初的判断是：经济不好的时候，奢侈品的需求反而会旺。这个灵感来自游戏《文明六》。疫情三年，互联网公司一路下行，中国经济大概率会经历五到十年的调整期。第二个理由是，全球40%的奢侈品都流进了中国，二手奢侈品在中国市场的机会肉眼可见。第三个理由出自我自己的折腾——做过社交电商、社区团购、私域运营工具，全都没起来，后来想明白：私域只适合做高客单价的东西，而二奢恰好满足这个条件。第四个理由更简单：现在二奢赛道里的头部公司大多是家族企业，人才和管理经验跟我们差不多，那凭什么我们不能挤进一个不错的生态位？

我本来就是个普通人，2021年第一次接触赚钱，当时还是小透明，天天刷精华帖、参加线下社交，一点点打开眼界，才有了后面这些想法。也是那年7月，我冲动地跟着大佬去创业。那次失败了，没拿到什么结果，但和合伙人之间结下了一种“革命友谊”。最初他多次跟我沟通，安排我来杭州参与项目，自己回北京做科研。我当时想得很简单，就是搭上这艘快船，赚点红利。没想到崩盘来得太快：项目陷进低谷，公司垮了，债务也压上来，那种痛苦我相信每个老板都不想来第二次。

去年4月到杭州时，团队还有30人。前两个月我在一线做销售，业绩垫底，刚有点起色，公司又把资源倾斜到直播端，调我去负责私域系统和中台管理。接手没几个月，公司就崩了：副总走了，供应链负责人也走了，内部乱成一团。后来我们索性砍掉多数人，只留下两个主播和直播必需的配套人员。回想11月，我和老板连续见了好几个投资人，我还给赚钱里的大佬发过私信，差点连房租都交不上。现在说得轻松，其实要不是一条视频突然爆了，我们可能连直播都放弃，两个人找点别的事赚生活费算了。

说到经验，我反复想过，真的有什么能分享的吗？看了那么多经验，真正做事的时候根本来不及用。最有用的还是打开视野，因为每个人的理解能力不同，经验能起的作用也因人而异。我是运气好，赚钱让我开了眼界。比如我建议合伙人用飞书，在他的推动下团队很快就用起来了，而我只是那个提出建议的人。真正厉害的是他——系统性思考、高效组织飞阅会，这些我一直都在学习，也努力复制他做过的每一件事。直播能再次起飞，主要是他的能力，我只负责帮他应付投资人债务这类麻烦事，替他省出时间。我知道自己不适合做团队管理，他才是那个管理者。我也试过独自创业，结果发现自己根本不适合单干，连每天准时出摊都做不到。

我特别喜欢一句话：功成不必在我。做企业从来不是一个人的事。创业失败一次不可怕，看似可怕，其实换来了真正的革命友谊。正因为有了第一段革命友谊，我才拿到进入二奢的机会；而后来公司的崩盘，又让我收获了第二段革命友谊。
