# 新手小白如何借助赚钱小航海把月收入做到2万：我的真实复盘与项目筛选模型拆解



各位朋友好，我是来自郑州的毛韩。2020年进入赚钱，2021年9月才真正动手，到现在已经把一个项目跑通，月净赚稳定在2万元左右，并且保持着每月近20%的增幅。

从零到一的这段经历对我意义很大，我觉得对大多数刚入门的新手也很有参考价值。借着小航海的机会，我把这段路径梳理了一遍，如果能帮到同样在起步阶段的你就太好了。也要感谢河南赚钱群里的大哥们，特别是@凡灵逸尘 的点拨，以及刘小排、明白等老师的启发。

### 一、先说我到底想解答什么

这篇复盘主要围绕四个核心问题展开：

*   小航海怎么才能赚到第一笔钱？
*   精华帖到底该怎么读，才有价值？
*   到底该报名哪个航海项目？
*   一个项目跑通后，如何把它做大？

### 二、我的心路历程

我一直对赚钱很感兴趣，高中就玩应用试玩、彩票套利，大学做过头条号、淘宝客。但能力有限，只能在钻漏洞的灰色项目里捞点小钱，正规的玩法基本没赚到。工作几年一直996，把全部精力放在公司业务上，副业想都不敢想。

公司后来不行了，工资也撑不起生活，2020年我加入了赚钱。刚进来和很多人一样，418以最低价冲进去后开启精华帖狂读。各种玩法层出不穷，看得人眼花缭乱，却感觉离自己很远，像是在看一部科幻片。

年入百万、年入千万的案例满天飞，自己却插不进话。那种“这场盛宴是不是专门给我制造焦虑”的感觉持续了两个月。后来索性就不打开App了，直到看到鱼丸的朋友圈说小航海开启。

我被小排老师的蓝海挖掘打动，感觉就是为我准备的。于是报名。开航那两天拜读了小排老师的航海文档，受益匪浅。

*   原来赚钱可以拆成这么清晰的步骤
*   原来赚钱能力是各种模块的组合

从那以后我开始在碎片时间重读精华帖，拆流量、拆产品、拆变现。可惜当时只有方法论，没有具体项目，感觉像打造了一把好兵器却没战场。于是按小排老师的方法，在📕里去找蓝海。

## 二、方法论拆解

我把整个过程分为四个阶段：

1.  初入赚钱：猛刷精华帖，发现大佬很多、项目很多，发誓今年要赚到第一桶金。但那时我只是“看”，看不出精华帖对我有什么用
2.  筛项目：想立刻实战，于是挑来挑去。有人太多竞争、有人已红海、有人天花板低……全是我的筛选理由
3.  动手难：确定项目后不敢下手，怕赚不到钱、怕风口过去、怕自己不行
4.  放大难：跑通后不知道怎么放大，是招人还是投广告？选择困难

这四个阶段几乎是每个新手的必经之路。跨过去的关键在于每个阶段的心法。

### 1. 初入赚钱 = 锻造武器

所有项目都遵循“流量-产品-变现”模型，这是龙哥、涛哥、小排、明白老师反复强调的。

读精华帖的目的，不是为了打鸡血，而是拆武器。把别人的引流方式、产品搭建、变现路径拆解出来。

举例：
📕资料引流项目拆出来是：
流量：📕关键词搜索
产品：🛰️承载的虚拟课件
变现：🛰️直接售卖

外卖CPS项目拆出来是：
流量：👸号广告+外卖小哥广告
产品：👸号+领券小程序
变现：用户下单返佣

拼两篇帖子就能得到6个模块，换到新项目就能组合。例如📕引流+👸号承接+自动发货小程序，就能降本增效。

赚钱有近4000篇精华帖，每个都是模块库。先花一个月拆完，相当于把武器库建起来。战场上就算用不来，也知道有这件兵器能用。

我总结的流量形态有三种：
关键词：如SEO，我的规划就是走这条
关系链：如🛰️裂变、商家群发
算法推荐：如短视频

掌握一种流量形态的找法和铺法，就等于掌握了它的密码。

### 2. 筛选项目 = 明确战场

有了武器，还要有战场。赚钱项目库太多，该打哪一个？

老师推荐的选项目标准很多：
小排老师的帖子、战劲老师的帖子……

但老师是“挑选”，新手是“筛选”。老师看一眼就知道项目全貌，资源能力都够。新手没有网感，资源有限，所以只要能筛到一个自己能做的就行。

比如需要会编程、投入10万、团队30人的项目，大佬直接上，普通人根本玩不起。美团电商要5000保证金，学生党做不了，打工人可以。闲鱼需要时刻盯客服，上班族不合适，自由职业可以。

所以新手选项目，先看匹配度：能力、资源、时间、成本。

基于老师的判断维度，我做了自己的项目筛选模型，现在还在用，参数会定期更新。总共近20个参数：

项目筛选模型参数概览：

项目名

杠杆复利复购：杠杆效应、复利效应、复购效应
市场评估：持续周期、市场渗透率、供需状态、优化空间
能力评估：所需技能、是否需学习行业知识、是否需新技能
所需资源：是否需私域粉丝、货源、变现产品
所需时间：每天耗时、是否需随时盯
所需成本：首次投入
个人评估：是否符合优势、是否符合兴趣

### 如何用这个模型选项目

我的流程是：
先筛原则：违法违纪坚决不碰
再筛能力：对照能力评估一项项核对
再筛收益：对新手来说，能否快速正反馈比市场大小更重要
最后筛市场

筛完可能得到一个或多个项目。如果一个都没筛出来，就要反思三件事：

打开知识星球，总能看到有人问：为什么我天天看项目，却始终没找到适合自己做的？问题往往不在运气，而在于推进顺序。与其零散地刷帖子，不如按一套流程走：先磨刀，再找战场，然后下场，最后做大。

**第一阶段：先攒一座“弹药库”**

这里的“弹药”，指的是把别人的成功案例拆成可复用的方法。建议你把精华帖大量刷一轮，看到好案例就拆解，把里面的关键动作、适用条件、踩坑点都记录下来，整理成一张清单。这张清单，就是你以后判断项目的底气。

哪怕你当下什么都不会，也得先知道武器长什么样。否则你看到一个项目时，连从哪个角度评估都不清楚，更谈不上选择。

**第二阶段：别急着抱怨项目少，先检查自己的筛选条件**

很多人筛不出项目，原因无非三类：一是条件设得太多、太死；二是看得太少；三是对项目本身不了解。这三个问题不解决，过滤模型做得再复杂也是空转。这一点，小排老师在文章里也专门讲过（链接在文末）。

拿我自己来说，一开始我设了五个硬性指标：得能做十年以上，启动资金不超过一万，每天投入小于两小时，不能依赖粉丝、货源这些资源，还要在一个月内有回款。你猜最后匹配出多少项目？零。可当我把年限改成不小于一年时，能做的项目一下就冒出来了，像是用📕做资料引流，或是到闲鱼上做无货源店铺，都可以上手。

所以新手不必执着于找一个“能干一辈子”的项目。这世上不存在永远不变的项目。当我们没钱、没资源、没粉丝、没时间的时候，判断一个项目能不能做，首先看能力跟不跟得上，其次看它能不能帮你攒下一些东西——资源、经验、用户都算，用来给下一个项目垫底。至于项目能火多久，根本不是重点。

顺便说一句，我觉得“积累”比“收益”更值钱。收益只能证明你此刻兜里有钱，而积累能让你的未来更值钱。它像一门手艺：做技术人员，学到的东西能带到任何地方；做流水线工人，赚到的只是计件工资，换个厂还是要从拧螺丝开始。所以，做项目尽量挑有积累效应的事。

那么，怎么判断项目能不能做？你可以自己搭一个项目过滤模型，也可以反过来先看项目，再针对项目去补齐对应能力。这两个顺序并不冲突。

如果你不想自己建模，可以用我分享的“5月小航海项目筛选模型”，链接在文末。用电脑打开后，点右上角“创建副本”，复制到自己的飞书文档，再按你的实际情况调整参数就行。要注意，模型里的参数不是标准答案，你可以随时根据自己的认知去修改、增减。

**第三阶段：别再空想了，直接下场实战**

很多人走到这一步又开始纠结：万一我判断错了怎么办？万一现实和预想不一样怎么办？万一我就是拿不下呢？其实破解方法只有一句：马上行动，遇到问题再解决问题。

想做淘宝蓝海，别想太多，先注册一个店铺，挂个产品上去；想做📕，先注册账号，发一篇笔记；想做抖音，先开号，发条视频。做完之后你会自然发现问题：怎么没流量？那就去学引流；有浏览没成交？那就去优化页面和话术。问题会一个个冒出来，你解决一个，就往前走一步。

如果实在迈不开腿，可以借用《福格行为模型》里的公式：行为=动机×能力×触发物。举个例子，我原计划今天在闲鱼上传5个品，结果没完成。这时候我会问自己：动机上，是不是我根本不想做，还是动力不足？能力上，是不是上传流程太繁琐、太耗时？触发物上，是不是我压根没设提醒？找出原因后逐个击破：找动力、简化流程、定闹钟。这套方法不只适合项目，学习、工作、健身都一样能用。

**第四阶段：跑通之后，怎么放大收入**

第一个项目跑顺了，就要考虑规模化。在圈内搜“放大”，出现频率最高的答案是“矩阵”和“投放”。但理论和落地之间还有距离。根据我自己的经验，放大主要有两条路：一是做大现有业务本身，二是顺势扩展关联业务。

先说做大业务本身。最好的抓手是增长模型——把你的收益写成一条可以一步步拆解、优化的公式。比如📕资料引流这个项目，最终指标是收益，可以拆成：

收益 = 客单价 × 支付人数  
继续往下拆：  
收益 = 客单价 × 支付率 × 咨询率 × 添加率 × 私信率 × 阅读量

实际执行时，就是把每个环节的转化率拉高：支付率低，就定期给咨询过的客户发提醒；咨询率低，就主动去私聊；添加率低，就用自动回复工具第一时间响应；私信率低，就在评论区引导互动。如果想更精细，还可以把新客户和老客户分开算，因为两者转化率差别通常不小。

流量也可以拆。阅读量 = 推荐阅读量 + 搜索阅读量 + 同城阅读量；继续拆，就成了关键词数量、点击率、单篇帖子覆盖词数、发帖数量、账号数量、客服人数。关键词本身的搜索量我们控制不了，但能优化标题和封面去提升点击率，多发帖子去覆盖更多词，多开账号去做矩阵，甚至扩大客服团队。客服团队也能继续拆成招聘渠道、面试率、入职率。

放大现有业务的本质，就是把每一步转化率都做到极致，同时把最源头的流量做大。某个渠道流量饱和了，就去挖新渠道；至于怎么挖，回到你第一阶段的弹药库去找答案。

再说扩展业务。小米有了硬件用户后，会继续给你推荐智能家居、会员服务，核心思路就是挖掘同一个用户更多的价值。对一个项目来说，常见路径有五类：业务迁移、变卖流量、卖影响力、做培训。

业务迁移又分两种：一种是朝同一用户群体的上下游延伸，比如你做📕幼师资料，可以顺手做幼师考证课；另一种是拿同一套打法去服务不同人群，比如本地相亲之外再开拓中老年相亲。如果你没精力研发新产品，可以把流量变卖给有产品的人，比如在自己小程序里给其他商家打广告。等你做出了一定影响力，还能做品牌授权、招代理、收合伙人。如果连品牌都不想维护，就直接把这套模式打包卖给别人，做培训教他们操作。

这一阶段的底层逻辑是：既然你已经跑通了项目，手里至少握着一样东西——要么是粉丝，要么是货源。粉丝就是流量，货源就是产品。有了流量，就围绕这批人开展更多业务；有了产品，就去找更多同类流量。如果当前项目不适合扩展，也可以根据这套思路去类比，找到属于自己的放大方案。

最后总结一下，新手想赚到第一笔钱，核心就四步：第一，多刷案例，打造自己的弹药库；第二，用筛选模型找到能力匹配、有积累价值的项目；第三，先干起来，把问题逐个解决；第四，用增长模型做大体量，再通过业务扩展寻找新增长点。

这条路不是唯一，但能让你少走很多弯路。
