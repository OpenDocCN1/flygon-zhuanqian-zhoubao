# 《通过 ChatGPT+RPA 13 次拖拽实现文案全流程自动化》

你有没有遇到过这样的场景：每天要把无数个文案标题复制进ChatGPT，等它生成完，再手动把内容粘贴出来？不仅繁琐，还特别占用时间。

最近，一位圈友就带着这个痛点找到了我。这还得从4月12日我在赚钱朋友圈发的那条RPA资源对接说起。当时我做这件事，主要抱着两个目的：一是想探探市场对RPA的需求到底有多大；二是想借着大家提出的真实问题，逼自己去用RPA解决实际场景。

结果还真有圈友因为这条动态加了我，告诉我他平时工作很忙，反复在“标题粘贴进对话框—等输出—复制出来”这个流程里打转，效率很低。于是我就用RPA帮他把这个环节变成了全自动。

很多朋友一听到RPA，本能地觉得门槛高、学不会。但我想说，真不用担心，这东西完全能自学起来。B站上有大量免费教学资源，我个人比较推荐影刀RPA的官方课程，讲得系统又全面，跟着学就行。


如果你也在研究RPA，或者对ChatGPT+RPA这套组合有想法，欢迎来评论区一起聊聊。有人问ChatGPT网页版用哪个版本，其实不管什么版本，底层原理是相通的，学会一通百通。

对了，评论区也有朋友提到另一个思路：如果以后真做出一个批量处理标题、批量导出内容的工具，用户用自己的API Key，不靠网站收费，说不定也很有市场。你怎么看？
