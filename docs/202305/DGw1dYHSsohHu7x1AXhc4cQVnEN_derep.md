# 《利用赚钱的思维，用8块钱成本，一个月小赚2w多，我跑通了一个没见过的有趣的小项目》

朋友早上一条“你多久没更朋友圈了”的消息，把我拉回年后那段折腾的日子。当时我顺手测了个小项目，成本不过8块钱，二十来天收了2万多，🛰️里多了几百个好友，单价挂30元，有人一口气回购了20次。说实话，🛰️收款的感觉比走平台爽多了，但我现在已经停了——那阵子全是拿积了分的废号在跑，平台动不动就扣分，实在熬不住。本来不想拿出来说，可回头看，里面有几个歪打正着的优化步骤，还挺值得聊聊。

![](img/2d20da11c2b02f1525d01769d118cd6b.png)

这项目说白了就是“视频定制”：客人发文案，我改一段视频里的字，1~2分钟就能交付一个成品。听起来简单，但发现它纯属偶然。年后某天晚上刷视频，撞见一个直播间，背景是广州塔在循环播放，塔身上滚着“XX我爱你”“XX生日快乐”之类的字，主播现场改文字，围观人数蹭蹭涨，一晃就一两万场观，屏幕上一堆人刷“龙哥我爱你”“杨涛我爱你”。那阵子我还没进入工作状态，本来是想找品带货的，结果被这个形态震了一下——直播带货做久了都知道，硬拉个一千两千人场观都能偷笑，人家这流量跟白捡似的。

我当时就冒出个念头：这玩意儿我是不是也能搞？于是按着赚钱的思路，先像素级拆解。加客服、扫码、走🛰️，每一步文案和引导我都截图记下来，最后知道一个成品收费30元。好家伙，卖货时十几块利润都算不错了，这单价完全可以干。技术乍一看也不难：OBS放素材而已。

一开始我想得太美，以为用剪映拉关键帧就能做。随便找了段广州塔视频，折腾十分钟，效果生硬，卡顿不丝滑。我找客服要原始素材，人家一口回绝。也行，我自己找。

![](img/9426edecf4bfcdf23ec1caac57b405ef.png)

抖音、快手、📕搜了一圈，原视频全带着字，愣是没找到干净的。后来想起万能淘宝，一搜还真有——原来这玩意根本不是普通视频，是AE模板，只要改模板里的文字就能出效果。更惊喜的是，这个项目19年在抖音火过一轮，顿时更有底气了。8块钱买下100个模板，里面居然连那兄弟朋友圈发过的款都有。当天晚上我就装插件、配环境，把他直播间的效果1比1复刻出来，丝滑得很。

![](img/7bcc74e38e949f63e238876bdea910d1.png)

软件操作不复杂，打开模板，找到能改字的地方换掉，导出是大体积avi，OBS能直接用，但发客户得用格式工厂压成mp4。这行当有个正经名字：AE动态跟踪，还能做马赛克跟随之类特效。最耗时间的是找配套插件和字体，我搜素材的功夫还行，愣是啃下来了。模板、插件和字体我都打包扔百度网盘了：链接：https://pan.baidu.com/s/1VRYD8y2tEVzULSWWPd6iTQ?pwd=inbn 提取码：inbn （注意字体是我用过的，不代表所有模板通用哈。）

接下来就是像素级模仿。头像、简介、企业🛰️承接、自动回复、二维码推送、添加好友，连标点符号都没放过。自动回复里我在加好友失败时加了句“回复1”，是防🛰️风控换二维码的备用入口，免得客户走丢。企业🛰️需要认证，我之前带货时花300一年办过；懒得认证的话，直接把🛰️号挂简介里也行。

![](img/b6b2e385f7c789282f7faaf768033e8b.png)

直播间用OBS搭，他露脸，我嫌麻烦只露了手，基本还原到位。第一场播出去，场观破万很快，互动也猛，但转化惨到不忍直视。我像个傻子一样现场一条条做，满足他们不信真能改的虚荣心，最后靠“坑蒙拐骗”才出了2单，嗓子都喊废了。连着三天都是这鬼样子，最多3单。不过想着带货号也没起色，就当蚊子腿肉继续苟着。

好在模仿时我也照他那样发了几条成品视频到朋友圈。有客户看到其他模板，又回来下单——这一下让我意识到，复购率是真实的。得，再挣扎一次。

![](img/9d9f95c22e59a113711549a391cf17b0.png)

这里用上了一个赚钱思维：不能盲干，得盯着问题优化。当时我还没搞清用户到底要什么，满脑子以为是表白祝福。后来想起来，抖音火是因为年轻人多，视频号全是中老年，照搬必然水土不服。于是我换了套素材——画风直接变成美女试驾什么的，土得掉渣，我都不好意思看，可观众爱，平台也爱，一分钟场观几千，最快一场一分钟破万。公屏齐刷刷“欢迎XX前来试驾”，热闹得不行。一个人做来不及，我就开了打赏，送一个棒棒糖的优先安排。结果还是忙乱，有人送了好几个礼物见我还没做，干脆加🛰️来催。

场观到3万的时候，我实在顶不住，下播先交付。就那一场，🛰️收款过千。

![](img/6855322b22563aa6521644d50f52fde6.png)

![](img/acc35af732cba891203e33cfd7376881.png)

下播后我调整了策略：加了🛰️先别急着收钱——不收他就没理由催你；一旦收了钱又半天没交付，人家肯定着急。所以改成先直播做几条，招呼大家🛰️发红包，做出来现场交付。这样两边都照顾到，第二场顺多了。

尝到甜头就想复制。可我没法同时盯几个账号，手头一台PC一台Mac，Mac还播不了。于是京东花800多块整了台便宜PC，让小助理同步播一场。这算半个复制吧，好在第一场就回本，后面全是净赚。

![](img/da097e921206f9b381458dd2e1b5beee.png)

![](img/b0b91579792131228dbb8bb0fa461cef.png)

用的号都是直播带货扣过分废掉的。反正废号多，一个一个轮着播，每次拉到一定场观就下，下一场再拱高点。意外收获是：以前带货播一两个小时几十个场观，这回稳稳几万场观，看来不是号的问题，是内容的问题。

越做需求越清晰——年轻人祝福根本不是主流。看成交客户，全是老板、销售、做生意的：减肥的、二手车的、房子的、烟草的、茶叶的，还有卖猪饲料的，以及专门奉承领导的。于是我把视频引导词往这些人群靠。

![](img/ed3fa154556e5c12597d3860e9e0719a.png)

美女素材是真香。模板里美女图少，朋友圈发完就断货。我使了个骚操作：去淘宝搜素材截图，不买，直接发朋友圈，等有人下单我再花几毛钱买回来。基本发出去的都有人要——美女本身就是流量。这也是以前学过的：用朋友圈验证需求真假。

![](img/880e566c79e20e8cee6f52751be1f655.png)

![](img/a03b20e09593612ec94879a7a2cc15f9.png)

![](img/6ec46459eb2c67fcf2c65b0618b610be.png)

怕什么来什么。某场上人特别猛，平台直接判我“引流”，直播被掐断。那之后我全程提心吊胆，有时一句话不说也照样中招，最多播一小时或场观到三四万就自己下。想认证蓝V保平安，没用，听说系统bug级别。开小店把视频挂商品页要交几千保证金，还可能资质审查，我怂了——这项目本来就不像能长久的，没敢下重注。

![](img/33a14853352b108c446eefa85ef8b120.png)

![](img/920ae7eb25b2146666a06f70d2178f83.png)

再往后，废号扣分扣得差不多就换，号不够用了，做的人也多起来，最好的一条素材又被判侵权，我干脆收手。所以你现在问我这项目还能做不？我劝你冷静。天天跟平台博弈，挫败感太强，我不想再对着干。但若只图体验一把被流量冲的感觉，可以试试。需求是真的强，客单价也不高，非标品复购又猛——只要找到更稳的获客渠道，这条路其实还有戏。你要是🛰️里好友多，搞不好效果比我还好。等攒下一波废号，我也想再试一次，榨干最后一点价值。

![](img/3ebe9eebb80886f56132ebaeea6d550c.png)

我还试过主动加人：按成交客户的行业去视频号、抖音找同行🛰️来加。效果不理想，被动流量和主动流量的差距肉眼可见，又费时间，后来停了。但思路留着：精准客户其实会留🛰️，主动抓未必不行，适合高客单价产品，慢慢养。

![](img/055aec6df19280366461731cbc793921.png)

为什么还分享这个？因为项目本身不好复制，但底层的招数能复制。比如像素级拆解和模仿，这是我第一次完整逆向走一个项目，给我的信心比赚到的钱值钱。流量密码也通用——美女、漂亮AI主播，就是能拉场观。直播形式更能复制：这种互动型直播几乎不用说话，打打字就行，下次我想上AI绘画、AI聊天，让别人在公屏报题、我来生成，据说有卖课的一场能出100多单。等我号到位就试，执行力强的可以先替我探路。

![](img/a99cffc30c339631a5e0c8c9b82f0157.png)

![](img/5d2c0df174d9882c90b9d2fb3f19e720.png)

到头来看，这个案例真正想说的是：怎么用赚钱思维找项目，再用像素级模仿快速验证。我虽然没坚持做下去，但它带来一连串有价值的启发。说远一点，赚钱思维已经改变了我看机会的方式——发现异常值，把别人的玩法当启发，敢试敢抄，认怂之后还要冷静复盘。这条路还长，我还会继续拿这套思维去碰更多新东西。（最后的升华是AI帮我写的哈～）
