# 如何“利用”赚钱，做到连续 3 年，副业年收入 10 万+

做了三年副业，我最大的心得是：普通人想靠业余时间多赚点钱，真的不用自己瞎摸索。过去三年，我靠着一套固定的“借用”思路，每年副业收入都能稳定在10万以上。没有暴富，但足够踏实。

今天把这段经历整理出来，不是想说自己多厉害——在圈里大佬面前这点成绩根本不值一提。但如果你也是个起步不久的新手，也许我的路径能给你一点参考。哪怕不能直接复制，至少能让你少走几步弯路。

我的方法，其实就四个步骤。

第一步，先明确自己内心真正想做的那件事。比如我，早就认准了读书写作这个方向——它曾经把我从低谷里拉出来，我也想用它带更多人走出来。但我努力了很久，却发现项目始终做不大。后来我在赚钱里搜索“读书写作”相关的精华内容，结果让我有点意外——相关的好帖子很少，甚至几乎空白。我一下清醒了：读书写作可能并没有我想象中那么强的市场需求，它甚至是一个“伪需求”。这让我意识到，自己想要的，和用户真正需要的，往往是两回事。

这就引出第二步：不要凭感觉判断一个项目值不值得做，要借助现成的“筛选结果”。赚钱里的精华帖，都是平台和团队层层挑出来的。就算我们个人认知有限，跟着这些内容看别人在做什么、怎么赚钱，也比自己闭门造车高效得多。有一阵子我很想做“教你做读书会”的训练营，毕竟我自己做了三年读书会。可我去搜了一圈，发现“读书会”几乎没有精华帖。那一刻我懂了：与其教别人做读书会，不如教他们做📕——因为大量普通人和商家都在📕找客源，需求是实实在在的，而想学做读书会的人，少得可怜。

第三步，踩在已有的知识碎片上做执行。既然决定做📕，我就在航海手册里挑了一种笔记写法套用，又在精华帖里学引流技巧：设置钩子、小号评论区引导、图片和群聊留🛰️。这几招组合起来，我用一整年做到了涨粉近3万、引流近1万，顺利变现超过10万。

第四步，学会“倒着学”——去赚钱做一次志愿者。我当了三次志愿者，最大的收获不是荣誉，而是能近距离看他们怎么做用户运营。你会发现用户有哪些问题、有什么需求，再对照自己能不能解决。如果能，这就是赚钱的机会。

说完了大方向，再说说怎么赚点小钱。姜胡说的《价值心法》里有句话很戳我：“别把赚钱的事想得那么高深，你能找到问题，知道怎么找解决方案，能把这事情搞定做完整，就能获得收入。”懒惰是人的刚需，那些等着别人把饭喂到嘴边的人，恰恰是最好的客户，因为他们数量巨大。而普通人的进阶路径就是：拆解、学习、模仿、尝试、总结、重新理解。等级慢慢提升了，能接的事自然越来越多。

很多新手想做内容，却卡在“不知道从哪开始”。那很简单，拆解别人怎么做的就行了。我自己就因为这个逻辑，做了两个案例库：一个叫《100个拆解IP案例库》，另一个叫《100个拆解📕赚钱案例库》。IP那个定价149元，📕那个前期特惠只要69元。我帮用户解决了信息筛选的难题，他们花一顿饭的钱就拿到了干货。

很多人问，那100个案例是从哪找的？我常用的渠道有三个：一是赚钱里的风向标，看到好项目我会先自己下场试试，跑通了就整理进案例库；二是我平时刷📕时顺手积累；三是刻意搜索——赚钱里面很多大佬分享过各种工具，比如蝉妈妈，还有航海手册自带工具箱，都能拿来用。

找到用户也不难，就是做好内容、主动引流。我用的是最“老土”的方法：📕引流，加上持续输出对别人有用的内容，一个一个积累粉丝和朋友。我们总听一夜爆粉的故事，但要记得自己是普通人。普通人的路，就是从一件小事做起。那句话怎么说来着——人们总是高估自己一年能做的事，却低估自己十年能做的事。

我私域里的1.5万好友，就是我从2018年慢慢积累起来的。有人因为读书会认识我，有人看了我的文章或笔记主动加我，还有人是在分享场合里受益后找过来的。整个过程就六个字：利他，利他，再利他。你给对方真正需要的东西，对方自然会回馈你名和利。
