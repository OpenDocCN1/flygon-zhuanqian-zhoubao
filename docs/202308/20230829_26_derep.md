# 如何用滴答清单做高效的时间管理？
作者：龙哥

你是不是也常被脑子里那些“提醒”缠得没法专心？

正准备沉下心干活，脑海里却突然跳出各种声音：等一下要和技术对需求，记得检查文件带没带齐；明天要给领导汇报进度，得抽空整理数据；周末朋友过生日，礼物还没挑……

一天折腾下来，忙得像陀螺，却又感觉什么都没干成，时间总是不够用。

可真相是：不是时间太少，而是你把大脑用错了。

有调研显示，蓝领工人一天劳作十多个小时，月薪不过三四千；而不少富豪每天只工作两三个小时，月入却能达到几十万。

所以，时间管理的本质，不是逼自己每分每秒都在忙，而是明确什么重要、什么优先。

我这三年一直在用的方法，叫“外包大脑”。它源自时间管理达人艾伦提出的 GTD（Getting Things Done），简单说就是把所有要做的事统统记到纸上或软件里，再按体系去安排。相当于给自己请了一个私人助理，既能赶走脑子里的捣蛋鬼，又能把日程打理得井井有条。

这套“外包大脑”的核心，其实只有三步：收集 → 分类 → 处理。
