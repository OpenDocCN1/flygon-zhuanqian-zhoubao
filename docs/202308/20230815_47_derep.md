# 别说玩物丧志，我在台球房里找到了赚钱的门道
作者：龙哥

“你最近怎么总泡在台球房？”朋友忍不住问我。

我笑了笑：“打球是假，找机会是真。”最近我确实迷上了台球，几乎一有空就往球房钻。只不过和以前单纯的娱乐不一样，这次我是带着“赚钱思维”去玩的——球房的人气、客人的习惯、场地的空档，我都下意识地多看了几眼。结果真让我发现了一个赚钱的机会。

更赞的是，我已经把这段时间的心得全部整理好了：从怎么找商机、怎么对接资源，到最终怎么落地把钱赚到手，还有过程中容易踩的坑，都完整写进了一份飞书文档。有兴趣的朋友可以直接打开看看：


评论区也聊得热闹。有人感慨，只要肯用心观察，赚钱机会到处都是；有人说自己一局台球能打半小时；还有广州的球友问我具体在哪个位置、想来约球——哈哈，我人在花都，欢迎有空一起玩。
