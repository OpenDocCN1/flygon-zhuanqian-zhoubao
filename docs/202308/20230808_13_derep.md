# 三种甜蜜的毒药：太早出名、太快致富、太顺开业
作者：龙哥

李叫兽私下跟我聊过两件让他至今心有余悸的事：太早被看见，和太快变有钱。讽刺的是，这两样诅咒都让他亲身经历过。能走出来，是因为他当时及时踩了刹车，反复审视自己。

人人都想沾上这两种光环，看起来像是天上掉馅饼。现实却很残酷。有研究跟踪过美国彩票的巨奖得主：原本经济拮据的赢家，数年后多半又滑回原点，更糟的是有人因沉迷恶习而过得更差。

设想一下，今天清晨醒来，账户里平白多了1个亿。绝大多数人根本没有驾驭这一笔数字的经验和肌肉记忆。一旦钱到手，想分一杯羹的人会瞬间聚拢，你也很难分清面前的是真机会还是精致的陷阱。

我认识的一个人原本就不缺钱，后来身价突然翻了百倍。结果他被这百倍的体量反噬了，根本来不及学会如何持有、如何使用，最后收场很狼狈。

这条规律在餐饮圈同样成立。那些开业即爆满、排队上新闻的品牌，十之八九会在之后几年里栽跟头。真正能活下来的，往往是像古茗那样在摩擦和挫折里慢慢长硬的。

原因很简单：爆火会让人产生致命的错觉，以为每开一家都能复制奇迹。实际上他们只会经营一家“天天爆满的店”，排队本身会掩盖掉管理混乱、用人失当、成本失控等所有问题。可一旦门店规模上去，总会遇到客流平淡的日子，而那时所有短板都会暴露无遗。

我知道这话说出来没几个人信。一夜暴富的幻想太有杀伤力了，我自己也心动。所以祝大家都能暴富，但请先想清楚暴富之后你要怎么活。

评论区里有人点出了要害：骤然得名得利，最怕的就是骄狂导致决策失误，以及招来嫉妒和觊觎。 

炫耀式的张扬是为了喂饱虚荣；沉静的积累才是守住成果。细水长流的致富，反而更靠谱。
