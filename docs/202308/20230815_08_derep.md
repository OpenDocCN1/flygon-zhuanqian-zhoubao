# 直男约会与广告传播的问题
作者：龙哥

约会里女孩说“天有点冷”，男生回一句“多喝热水”——这个段子背后，藏着广告传播的死穴。

先说场景。女孩说冷，真实意图可能是“想要一个拥抱”。这句话本身就是她抛出的符号，必须结合氛围、语境才能准确破译。可惜不少男生太讲字面意思，只接收到了“冷”这个信息，双方完全不在一个频道，沟通直接失败。

广告的本质也是同一件事：品牌方心里有想说的话，先设计成一句文案、一支片子，再投给大众。整个过程真正完成，要等受众看见并且理解。广告圈常讲“到达率”，其实很多广告根本没被看见，只是一堆潜在符号；而看见了却没读懂，同样等于石沉大海。

为什么传播老出偏差？因为编码本身就可能失误，也可能受众解读各异。比如你想宣传床垫高端，取名“冠军床垫”。有人会理解成“冠军牌的产品”，也有人会以为是“冠军睡觉用的”。更糟的是，台湾有一种廉价啤酒就叫“冠军牌”，这个符号在那里直接跌到谷底。

同样一句话，不同人群解读千差万别。一句大气磅礴的白酒文案，70后看了觉得有档次，00后看了可能默默吐槽。于是传播学给出一条铁律：面向大众，要挑人类共识最大的符号来用，这就是“超级符号”。否则你真正想表达的意思、广告呈现的意思、用户理解的意思，经历两次变形，早就面目全非。

但如果你只针对某个小众圈层，那就完全可以用“黑话”。“双厨狂喜”“递弱代偿”这类词，圈内人一看就懂，甚至产生“是自己人”的共鸣与认同；代价是圈外人一头雾水，大众传播直接失效。

想起一句精辟的评论：想说什么不重要，重要的是对方听到了什么。广告从来不是自说自话，而是让接收者稳稳接住那颗信号。下次写文案前，不妨先问问自己：用户听到的，真是我想说的吗？
