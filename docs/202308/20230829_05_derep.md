# 男女关系营销学
作者：龙哥

如果把谈恋爱看成一场营销，很多让人上头的操作，其实都有传播学的影子。

先说“直男式误解”这件事。

广告说到底，就是在发信息。信息要流动，就得靠符号。一次完整的信息传递，要有发出的人、信息本身、接收的人。

约会时女生说“我有点冷”，她真正的意思是“来抱抱我”。但“冷”只是她发出的符号，必须结合当时的环境和关系，才能被正确解码。直男却只按字面理解，以为她在陈述天气，于是信息传到了，却解错了码，沟通直接失败。

广告也一样。品牌方心里有意图，把意图包装成一条广告，但我们看到广告后，如果没按品牌方期望的方向理解，这条广告就白做了。所以，别用那种只有一小撮人才懂的“黑话”符号，要用最大多数人一眼就能看懂的通用语言，效果才最稳。

再说“为什么结婚非得送钻戒”。

建立信任，是广告里最难的事。所以你会看到各种“信任符”：明星代言、权威背书、销量数据。自媒体想让人相信，也得先老老实实免费写很久，粉丝觉得你靠谱了，再带货才卖得动。这段时间的免费输出，就是博信任的“工作量证明”。

结婚送钻戒，逻辑也一样。男方想证明“我爱你”，可这没法验证，怎么办？那就买一个又贵又没实际用途的钻石送给她。钻石正因为没用、正因为贵，才能证明他愿意为你付出代价——这就是结婚版的工作量证明。

接着，理工直男哄不好生气的女友，和公司公关安抚不了愤怒的群众，是同一个道理。

约好看电影，你迟到了。原因是二环出了车祸，你堵在路上，不能变道、不能下车、不能掉头，只能慢慢磨。女友很生气，你觉得冤枉：不是我不重视，是路况太差。你试图跟她讲清楚时间、路线、突发状况。可她说：“我不听，你就是不重视我。”

你越讲道理，她越火大。因为她要的不是逻辑推理，而是你的态度。你放弃辩解，先道歉认错，这事才能过去。

企业出负面也是同样的剧本。大众和公司之间有信息差，公众没空也懒得去搞懂真相，他们只想知道：你认不认错、你有没有态度。这时候急着摆数据、列证据、证明自己没错，只会火上浇油。不如先真诚认错，别急着解释。

最后，讲一个酒吧搭讪的故事。

你在酒吧看上一个姑娘。

你走过去，直接告诉她你是高富帅——这叫推销。

你花钱让 DJ 当着全酒吧喊你是高富帅——这叫广告。

你请酒吧老板私下跟她说你人很好，很靠谱——这叫公关。

你点了店里最贵的红酒，让十个人排着队给你送过来——这叫次级品牌杠杆，整套动作本质是活动策划。

姑娘听完之后自己走过来跟你搭讪——这叫品牌吸引力。

道理说完了，祝各位七夕快乐，愿你的爱意编码成功，信任到位，少讲道理多抱人。
