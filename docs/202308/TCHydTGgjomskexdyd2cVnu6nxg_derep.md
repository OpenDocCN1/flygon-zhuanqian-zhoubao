# 卖了九年大闸蟹，我悟出的几件生意小事

一转眼，我在这行已经摸爬滚打了九年。中间不是没动摇过，甚至好几次想甩手不干，但终究还是留了下来。走到今天，我反而越来越笃定：这件事，我会一直做下去。

最近出门参加活动的次数比往年多，见了不少新朋友，也重逢了一些老朋友。大家对我的印象很一致：一提大闸蟹，就会想到我。这份信任，我发自内心珍惜。更让我意外的是，有位前辈级的大哥，在一次饭局后认真地和我聊了一轮，不久后居然真的决定进军大闸蟹赛道。照他的架势看，绝对不只是玩玩，而是打算认真做大。

他为什么听完就下了这个决心？今天这篇文章，我就把当时聊的东西，以及这几年攒下的思考，一并做个梳理。

## 选方向：先问自己两个问题

老话说，“女怕嫁错郎，男怕入错行”。创业选方向，基本就是定生死。方向一旦跑偏，越努力，反而离目标越远。

在我心里，判断一个行业能不能干，只需要两个标准：第一，这事能不能做十年以上？第二，我手里有没有成熟的供应链？

先聊供应链。当年我回老家卖螃蟹，想法特别朴素：靠水吃水。老家有大闸蟹特产，市场又有需求，那就干呗。后来被那位大哥一点拨，我才反应过来——所谓的“靠水吃水”，本质上就是供应链能力。他做汽配改装件也一样，不是冲动，而是因为他老家在常州，汽配产业发达，身边同学朋友就有工厂，货源稳定、拿货方便。这不就是我们常说的“产业带思维”吗？他能选中我合作，大约也是看中了我背后这条沉淀多年的大闸蟹供应链。

再说“做十年以上”。我经常看顾小北的文章，他是我非常佩服的创业者，多次强调选项目的第一标准就是能不能做十年，如果不能，再赚钱也不碰。这话我记在心里。有客户问我，螃蟹打算做到什么时候？我说，再做三十年，正好退休，然后把生意传给下一代，继续服务大家。你看，卖个螃蟹，硬是被我说出了传家宝的感觉。

“能不能做十年”背后，其实就是长期主义。我为什么能在这个行业里熬出头、赚到钱？说白了，就是不下牌桌。大多数人一两年没见效就换方向了，而我愿意在一个事情上日复一日地死磕。时间会帮助你淘汰掉九成的人，三年入行，十年称王。我还远称不上王，但确实摸到了一些门道。选择一个能长期做的行业，就是选择和时间为友，让时间变成自己的护城河。

难走的路，从来都不拥挤。越往后走，反而越从容。好的风景总在景区深处，这不也是一种另类的蓝海吗？

消费者也更愿意信任一个长期专注做事的人。你一直在做，至少说明你东西不太差，不然早就做不下去了。一个刚入行的小白，和一个深耕十年的老师傅摆在一起，大家天然会更信赖后者。这就是时间的信誉，也是百年老店的底层逻辑。

## 做IP：让客户主动来找你

懂懂曾说过一句话，我非常认同：互联网是近二十年最大的杠杆。结合我自己的经历，我想再补一句：自媒体，是普通人最容易抓住的杠杆。

我常常跟人说，我是从自媒体起家的。2017年夏天，我偶然发现了知乎这个流量洼地。当时想法很简单：要是能写出一个万赞回答，不就等于有了一万个支持者吗？于是我开始认真写螃蟹知识，写来写去，硬是把自己写成了一个“螃蟹专家”。那会儿根本没有“个人IP”的概念，就是傻傻地写，结果攒了几万赞，文章还上过专业餐饮杂志《四川烹饪》，也陆陆续续引流了几千个精准客户。那应该算是我在自媒体上挖到的第一桶金。

后来知乎总部还邀请我去分享打造螃蟹IP的案例，我私下里把这理解为“高光后的谢幕”。我一直很感激知乎，是它把我领进了自媒体这扇门。

之后，我把混知乎的这段经历写成复盘，运气不错，被《鸟哥笔记》等业内大号转载。记得刚看到转载私信时，我翻来覆去看了好几遍，心里偷偷高兴了半天。再后来，我混进知识付费圈子，在龙哥盟等社区继续输出卖蟹干货，慢慢发现自己的IP不再是单一维度了。以前是“螃蟹专家”，现在又多了一个“卖螃蟹的人”的标签。两条腿走路，确实比以前稳当。

去年刘润老师做“开封菜”直播，需要大闸蟹相关素材，兜兜转转找到了我，后来我居然成了他笔下的大闸蟹高手。那一瞬间真有点如梦似幻，我何德何能？

说了这么多，打造个人IP到底图什么？

做过生意的人都懂，主动找上门的客户有多金贵。有一句很形象的话：男追女，隔座山；女追男，隔层纱。你追着客户推销，是“男追女”；客户主动来加你，是“女追男”。哪种更容易成交？答案不言而喻。

我写👸号、做自媒体、经营个人IP，本质上就是在积攒影响力，让更多人知道“我是谁”。但比这更关键的是，这个过程能解决客户最关心的信任问题。

一切交易的前提，都是信任。你持续输出价值，就是在替客户事先打消顾虑。比起从前盲目地满世界找客源，这样的获客方式明显效率更高、用户更精准，而且成本几乎为零。

你可以试想一下：你为什么会愿意加一个美女的🛰️？因为她提供了美的价值，让你不自觉地被吸引。想通了这一点，引流也就通透了。

把自己当成一朵花，认真打理好自己，让别人看到你的价值，他们自然会主动靠近。到了这一步，再谈成交，不过是水到渠成——因为信任，早就在价值输出的过程中建立好了。

卖货过剩的时代，竞争只会越来越激烈。个人IP是一种很妙的破局方式，低成本、高杠杆，解决信任问题，收益远远大于付出。所以我建议，做生意的人，都应该建立自己的个人IP。卖货之前，先学会把自己卖出去。

把影响力这颗种子种下去，就是给商业人格修炼内功。日子久了，你会亲眼感受到它的威力。

## 信任：文章赢第一次，产品赢每一次

做生意，说来说去，其实就是解决用户的“第一次”和“每一次”。第一次是指用户愿意在你这里初次尝试；每一次是指他愿意回头复购，甚至帮你转介绍、做分销。有了这种循环，生意想不赚钱都难。

这个说法，我早年是在天涯论坛看到一个牛人分享的。后来自己做创业，一直记在心里。拿餐饮举例：好吃的，下次再来；不好吃的，说破天也没有下次。相信大家都有同感。

做自媒体卖螃蟹之后，我也慢慢总结了一套自己的说法——文章是第一次信任，产品是第二次信任。

怎么理解？用户先在公域平台刷到你的文章，现在也可能是短视频，看了之后觉得：这人挺专业，买回来试试？这就是“文章带来的第一次信任”。等到他收到货，尝过之后发现：哎哟，还真不错，对得起文章里说的，不是个奸商。于是第二次、第三次继续买，甚至还安利给亲戚朋友。这就是“产品带来的第二次信任”。

这些年我越来越体会到一句话：诚实，其实是提高工作效率的最好方式。千万别以为我在讲道德高调。富兰克林早说过：诚信不但是美德，更是最好的生意策略。在商言商，传统美德本质上是一种进化出来的决策策略——选择长期来看让自己受益最大的路，而不是光顾眼前那点蝇头小利。就像开车，你不可能永远只盯着车头前方那半米路，得抬头看远一点。

我讲一个自己刚入行时的经历。那时候我什么都不懂，有天到一个朋友介绍的蟹农那里拿螃蟹。他特别热情，拍着胸脯说肯定不会坑我，我也信了，傻乎乎地付了钱。回家一称，发现问题了：明明说好四两的螃蟹，怎么变成了三两五？后来我才知道，螃蟹有软硬规格之分。刚从水里捞上来的螃蟹，必须沥水半小时以上再称重，才算硬规格。那个蟹农，正好用这几分钟“水分”，给我上了一课。

这么些年过去了，我偶尔还会想起他。他好不容易拉到一个新客户，为什么非要一锤子把人推走？他为什么这么傻？反观这几年一直跟我合作的蟹农，每一次都给我符合要求的螃蟹。他们从我身上获得的，是一次又一次的复购。而被我惦记着的那个蟹农，他损失的不止是我这个客户，还有未来漫长的生意链。最可悲的是，他可能至今都不知道，他占的那点小便宜，早就标好了更高的价码。

这就是“诚实是最高效率”的真相。不诚实的人，做的永远是一次性买卖，效率极低；诚实的人，生意可以一直延续，协作越做越顺。方法论只能帮你跑得快，价值观才能决定你跑得远。

我到现在还记得刚玩知乎时，那上面杠精真的很多。我从2017年用“螃蟹人设”入场，到今天还活得好好的，老客户也一直跟着。原因无他：我始终把客户的利益放在第一位。发货时老老实实，因为咱做的是长期生意，不是在火车站干一锤子买卖。我要是把客户当傻子，那我自己才是那个最大的傻子——因为我在亲手把好不容易引来的流量往外推。

小蚁在龙哥盟发过一篇关于“利他”的精华帖子，写得非常好。他在国外留学期间做生意，说西方的商业课一开始不讲干货，反而大讲商业道德。他发现我的那套“土办法”居然与世界顶级的商业理念不谋而合，这对我来说是莫大的鼓励。刘润老师也多次说，如果只能留下一篇文章，那一定是商业道德，而商业道德的第一条，就是正直诚信。

武侠小说里，魔道功夫上手快，正道内功起初不起眼，但时间越久，后劲越大。价值观就是内功，平时感觉不到，关键时刻全看它发力。这也是做难且正确的事，是长期主义的真正实践。

查理·芒格在《穷查理宝典》里反复强调正直诚信的重要。他有一句说得特别好：声誉和正直是你最有价值的财产，而且随时可能在瞬间化为乌有。

## 写在最后

本来想着写个两千字就好，结果一不留神又写超了。还有很多想法没来得及展开，只能留给下次了。

不过这些年做事的内核，基本都在上边了。总结起来不外乎三句话：找一个能做十年以上的项目，用自媒体杠杆把它放大，然后真真切切地做好产品、不坑顾客。有心人读到这里，哪怕只能少走一点弯路，这篇文字也算值了。

文末感谢一下吴世春老师，写创业方向那部分时，我借鉴了他的一些观点，因为真说到我心坎里了。万人丛中一握手，使我衣袖三年香。谢谢各位看到这里。
