# MJ、SD 以及 lora 的换脸教程整合版

最近看到有人把 MJ、SD 和 Lora 这几种换脸玩法串成了一套完整攻略，实测下来确实香——尤其最后用 Lora “炼丹”出的效果，简直可以当手动版秒鸭相机了。

我自己把三种方式都试了一遍：SD 的局部重绘在相似度上明显更胜一筹，但如果你想拿来给普通人做张正经证件照，还是差了点意思。于是干脆自己训了个 Lora 来换脸，出来的效果还挺像，算是在写真自由路上迈了一大步。

这篇就把 MJ、SD、Lora 三种换脸路线全部揉在一起讲清楚。想直接看“炼丹”环节的，滑到第四部分就行。

先说明一下：我是 Mac 用户，SD 和炼丹都在云端跑完的，所以对 Mac 党特别友好，不用本地折腾环境。

### 一、素材怎么准备

先准备一张表情自然的正面照，可以参考下吴彦祖、安妮的示例图。

如果你是想换自己的脸，按这几个标准去拍就好：

1. 正脸，光线充足
2. 五官轮廓清晰
3. 微笑，且表情尽量贴近你要换的那张照片
4. 可以用美图秀秀做个轻微修饰，把眉毛、眼睛、皮肤简单优化一下（MJ 里不会改肤色，这点注意）

### 二、MJ 换脸

这部分内容较长，完整步骤放在飞书文档里了，直接点链接看就行。

### 三、SD 换脸：Roop 插件

我这边用的是 SD 的 Roop 插件。因为 Mac 本地跑不了，就选了云端部署。查了下 Roop 在云端的配置也挺折腾，干脆直接在镜像中心挑了个带 Roop 的现成镜像。

平台用的是 AutoDL，流程大概是：

注册 → 租新实例 → 选内蒙 A 区 + A40（之前试过低配，Roop 根本带不动）→ 选带 Roop 的镜像 → 创建成功 → 跑 Python 文件 → 跑通后打开 SD 就能用了。

### 四、Lora 的安装与使用

为了省去配置的麻烦，我直接上了青椒云，然后选了朱尼酱大佬打包好的现成镜像，几秒钟就能开工。

这里必须划个重点：**训练集真的非常非常关键**。它决定了模型能学到什么，也直接决定了你 Lora 能不能成、泛化能力强不强。

**1）照片准备**

- 数量：20～30 张
- 清晰度：越高越好
- 角度：尽量多样化，别太重复。中景、近景、远景、上下左右都来一点，数据越丰富，效果越稳
- 背景、妆容、服装：能简单就别复杂。我第一次直接用了出去玩的写真，结果练了 4 个多小时还没出图
- 瑕疵处理：像肤色暗沉、痘痘这类你不想让模型学到的明显瑕疵，可以稍微 P 一下。但千万别美颜过度，否则反而会拉垮模型效果

**2）Tag 打标**

这一步同样重要。把人物特征转成文字、变成数据给模型学习，靠的就是它。

可以直接套这个模板去打标：

- 主题：人物（1boy/1girl、触发词）
- 主要人物特征：比如发色
- 动作、视角、光影效果、其他

有个细节：**你希望保留的特征，千万别写进 tag 里**。比如你想让发色永远不变，这属于你自带的核心特征，那就不用标注。

最后检验 tag 打得好不好：拿原来的 tag 去生成图片，生成的越像，说明 tag 打得越好。
