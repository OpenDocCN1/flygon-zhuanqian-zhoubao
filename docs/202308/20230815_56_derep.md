# 管理者一定不能困于具体的业务

管理者千万别把自己困在业务细节里

我常对团队里的管理者讲一句话：不要一头扎进具体的业务事务中。如果你发现自己做事做得心力交瘁、痛苦不堪，多半不是事情本身有多难，而是你身边的人没选对。

关于“选对人”，吉姆·柯林斯提出过一个经典框架——“第五级经理人”。他把经理人的成长路径分成五个层级：

第一层，能把分内之事做得漂亮；第二层，不光自己干得出色，还能与周围同事默契配合，带动整个团队一起出成绩；第三层，单兵作战、团队协作都不在话下，更能领着队伍打赢硬仗；第四层，在前面的基础上多了一份真正的使命感，愿意为事业全力以赴；第五层，则比第四层多了两种极其可贵的品质——谦逊与坚韧。

什么叫谦逊？就是永远把自己当成一个新手，随时归零，保持初学者的心态。这其实非常难做到。我们大多数人在一个行业里待久了，不知不觉就会生出几分自满，慢慢变得固步自封。

什么叫真正的坚韧？就是无论你落入什么样的困境，都能一次次突破自己，咬着牙往前闯，最终抵达理想的彼岸。

对一个组织来说，真正要思考的核心命题永远是：如何把对的人请上车。如果你足够幸运，团队里已经有一位第五级经理人，那么你要做的不是指手画脚，而是充分授权、给予信任、全力激发他。

请记住一句话：优秀的人才不是教出来的，是筛出来的。选人的重要性，是培训的100倍。

而在筛选人才的时候，先想清楚你要的“人才画像”是什么，这件事的重要性，又是筛选本身的100倍。

有朋友看完这段内容后感慨：先把自己培养成第五级经理人，再去想别的。
