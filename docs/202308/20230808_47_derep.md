# 没做过餐饮也能玩转：用抖音做招商，我是如何做到月入十万的
作者：龙哥

大家好，我是龙哥，97年出生在南方的普通人，龙哥盟三期的一个幕后“潜水员”。上个月被鱼丸老师点名，和大家分享一下我正在操盘的一个副业项目：借助抖音给餐饮品牌做招商，帮他们收加盟商和培训学员。

很多人会觉得餐饮招商是专业人士的游戏。其实我之前对餐饮一窍不通，纯粹是零基础从零试错。2022年9月底我和第一家门店签下合作，10月份开始跑单，11月份直接爆发，当月成交35单，流水破100万。需要说明的是，这100万是项目总成交额，不是个人到手利润，最终要和品牌方分成。

这套打法是我跑了好几个餐饮项目后总结出来的实战SOP，不是理论，而是可以直接抄作业的落地动作。文章里我把我们团队用到的全部【工具表单】都附上了。

整体思路我拆成四块来讲：

一、如何拿到一个能爆的餐饮品类
选品决定下限。怎么判断一个餐饮项目值不值得做，怎么找对品牌、怎么和品牌方谈合作，这一步是基础。

二、抖音流量怎么跑起来
包括账号怎么起号、内容怎么写、投放怎么打、视频怎么拍剪、直播怎么引流。没有大体量吃播经验也能平稳起量。

三、从流量到成交的转化闭环
私信怎么跟进、如何建立信任、话术怎么设计、如何促成签约，这才是把播放量变成真金白银的关键。

四、一个人的项目怎么稳定操盘
从时间管理到团队分工，心态和复盘的方法论。
