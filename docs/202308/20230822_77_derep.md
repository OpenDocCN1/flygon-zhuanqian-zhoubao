# 3-4人小团队做亚马逊精铺，如何把利润做到翻倍？



## 3-4人小团队做亚马逊精铺，实现利润翻倍增长？

作者： 黄达龙 
日期：2023-08-18 

冰箱里放鸡蛋的收纳盒能做成一个亚马逊品，那冰箱里放蔬菜水果的置物架能不能做？再往前推，厨房里一整套收纳品类，是不是都有一条路子？

我现在用的就是这套思路，月销稳定在60万美金左右。今天就把我这几年走的精铺路，从选品到团队搭建，完整拆开讲给你听。

# 一、简单说下我的路径

18年靠国内一件代发起步，投几千块试水；19年国内做到800多万；20年国内遇冷转头研究亚马逊，21年亚马逊做到60万美金，22年冲到380万美金，23年回到相对稳定的月销60万美金左右。

亚马逊玩法大概分三类：精品、精铺、铺货。精品是红海爆款打法，铺货是海量概率博弈，精铺则是我一直在做的：小爆款、低需求细分市场的深耕。

起初我也不知道有这三种说法，就是按自己能上手的方式先干。等店铺数据跑通后，再补团队、再补供应链，随着品类、经验、工厂资源的叠加，规模自然上来了。

# 二、精铺的核心打法

**机会在哪**

对比国内电商，亚马逊整体竞争没那么激烈，汇率又带来额外加成，回报率更高。我入行时美金兑人民币在6.4到7.3之间浮动，目前整体ROI能做到3左右。

精铺的逻辑不是去赌大爆款，而是找能稳定出单的小品。我的切入标准很简单：日出几单起步，客单价在20美元上下，积累起来后部分单品月销能到800单。

**选品方法**

我主要靠三点找品：以前熟悉的品类、可触达的供应链、以及生活里的灵感。比如厨房鸡蛋收纳盒，就是日常能摸得到的东西。放到亚马逊上反查数据，如果竞争不算激烈、又能找到优化点，同时1688工厂能配合，就值得试一试。

举个例子：

调研egg holder时，有一款月销能到9000件。亚马逊仓储费5.69美元，15%佣金约1.5美元，回款是9.99-5.69-1.5=2.8美元。投入端，1688拿货成本9.26元约合不到1.5美元，海运头程约1美元，回款2.8-1.5-1=0.3美元，这还没算退货和广告。毛利只有3%左右。

做多了选品，会慢慢练出来对品类、工厂沟通、产品拆解的敏感度。

持续筛品的过程中会发现一个规律：客单价抬高一点，尾程和佣金占比掉到40%以下，切入会更舒服。

比如另一款，月销能到1万件。仓储费6.39美元，佣金2.7美元，回款17.99-6.39-2.7=8.9美元。1688成本9.48元约合不到1.5美元，头程约1美元，回款8.9-1.5-1=6.4美元，未算退货广告。

这款毛利率能到35%。ROI=6.4/2.5=2.5。把毛利和ROI算到自己能接受的区间，再去对接工厂谈采购发货。

这个过程中会不断沉淀供应链，了解工艺、物料成本，为以后做私模打基础。

等塑料置物盒的数据稳定了，就反向找工厂做开发延展。复制逻辑可以从材质和场景入手，比如塑料材质的浴室用品、户外用品、超市用品等。

供应链方面，店铺有销量后我发现做塑料的工厂多集中在浙江。先去拜访几家合作过的，看看产线、聊聊工艺。了解透了以后再匹配需求：比如工厂没1688店铺、能自建模具、生产排期灵活、资金压力不大。初期可以现金支持模具费和货款，换取小批量快出样。

# 三、3-4人团队怎么搭

① 合伙人

现货测试跑通数据后，再找价值观契合、彼此信任的朋友一起做。跨界小白可以，无电商经验可以，无需立刻掏钱。核心是信任、尊重和闭环执行。价值观不合、工作不闭环的，宁可不合作。

也可以直接招人，这样掌控感会更强。

② 运营机制

1. 新人进来先带一个有业绩的老店加一个新店，业绩提成按3%-10%阶梯拿。运营基础扎实后，再多配一个新店，为下一个新人做准备。
2. 引入新人的时候，老员工要把一个老店贡献出来，我们叫传承。老店交出后，老员工只要负责指导和协助销售，该店的提成减半。
3. 一位员工带下一位，下下位员工的业绩只跟第二位挂钩，被动收入最多到两层。
4. 带人的员工底薪会增加1000，但贡献出去的店提成降50%。比如原本每月能拿6%，共享后只剩3%。
5. 所有员工的提成比例和层级规则保持一致，想多带人就多带，不想带就把自己的店做好。

③ 协议

提前把合作协议、退出机制、持股比例写清楚。

④ 选品

优先上架测试过的品，并向同类、同供应商方向横向延展。

⑤ 文案和Listing

做listing要素材图，找供应商要原图，淘宝修图。文案要保证可读性，同时埋入关键词。卖家精灵的listing生成器前期可以参考学习。

![](img/51c4371c9eb86e10eea1e7ff8a6a978e.png) 

⑥ 广告

上架就开自动广告，验证系统推荐词和竞品是否吻合，判断listing是否跑偏。自动广告同时配合竞品定向投放。

亚马逊官方学习中心：

[https://advertising.amazon.com/zh-cn/resources/learning-console?ref_=a20m_us_hnav_lc_t1](https://advertising.amazon.com/zh-cn/resources/learning-console?ref_=a20m_us_hnav_lc_t1)

⑦ 分红

合伙人模式下，前期公司投入。当总回款大于总投入加预留资金时，超出部分按约定比例次月分红。

比如累计投入20万，回款到50万，预留20万用于周转，剩下10万拿出来分红。预留资金会随库存和周转需求动态调整。

无论是合伙人还是招人，前期有验证过的品和跑通的流程，能省掉大量试错时间，也大幅提升成功率。团队磨合期，尽量让问题早出现早暴露，建立信任更快。

# 四、做亚马逊的几个底层认知

模式：铺货、精铺、精品三种。

测算公式：售价 - 佣金 - 尾程 - 产品成本 - 头程。佣金按类目收取，参考：

[https://sellercentral.amazon.com/help/hub/reference/GTG4BAWSY39Z98Z3](https://sellercentral.amazon.com/help/hub/reference/GTG4BAWSY39Z98Z3)

尾程按体积重量长宽高判断，参考：

[https://sellercentral.amazon.com/help/hub/reference/GABBX6GZPA8MSZGW](https://sellercentral.amazon.com/help/hub/reference/GABBX6GZPA8MSZGW)

头程海运按体积重量计费，20公斤起，美西慢船约40天；空运按体积重量，一件即可发，5-7天。尾程头程都有体积重量维度，所以轻小品天然占优。

选品工具可以借助卖家精灵，市场筛选功能很实用：

[https://www.sellersprite.com/.](https://www.sellersprite.com)

举例筛选逻辑：月销量<800、售价>16美元、毛利率>50%、新品占比>20%。筛出Executive Desk Toys，类目前台结果532个。

![](img/8d05f0cbcb3bfa9885995107495a1661.png) 

往下看10-20美元区间销量占比最高，抽一个品举例：

![](img/b14166a2a8807ca657c59b5876476774.png) 

13.99美元售价，尾程4.08美元，佣金15%，回款还有7.8美元。国内成本8.2元，头程空运约12元海运约2元。即使走空运仍有4.8美元回款，毛利率34%。

![](img/d02221ecff174b795964022e46a7d684.png) 

所以刚起步建议优先做轻小品。利用卖家精灵的教学视频做调研，5分深度就已经领先大部分人了。先找到细分子类目，对标产品后排除专利，再思考优化点。

前期切入可用赠品或组合装，后期再考虑模具和差异化设计。

拿货发货和广告学习，可关注👸号“亚马逊广告”，里面按阶段整理了大量资料。

先从点切入跑通，再慢慢延展到面，数据验证后复制放大。
