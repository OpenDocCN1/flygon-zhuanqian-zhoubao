# 用小红书做国学粉引流，我的100+稳定获客实战全流程



## 小红书国学日更引流100+ 实操SOP

作者：行一（不吃饭）
发布日期：2023-08-21

大家好，我是行一，00后大学生。大学前三年就拿下人生第一个百万，现在手里有两块业务：一家做小红书电商的工作室，一家主打私域引流的流量公司。流量公司核心就是做私域直营，目标人群是国学粉和商业粉，自称流量操盘手。

熟悉我的人都知道我从东北飞到长沙，赚钱见面会现场长沙的伙伴还开玩笑说，有人为了赚钱专门从东北飞过来，那个人就是我。特别感谢赚钱的朋友们，让我有机会在长沙见面会上站台分享，把我的小红书玩法完整摊开讲。

为什么来长沙？很简单，东北的互联网生态暂时受限，需要一个新盘面去放大。年初跟朋友的约定要兑现，一诺千金，年纪轻轻有点冲劲，既然决定all in创业，就得有狼性，熬夜通宵也得干。

今天把我这段时间一直在路上跑的国学小红书流量打法一次性整理出来。之前一直在执行没时间复盘，这份国学引流SOP希望能帮到想在小红书做获客的同行，全干货无保留。
