# 小红书内部会看这两个指标，是社区稳定增长的关键因素

小红书增长的秘密，藏在这两个指标里

一个社区想要长期增长，最关键的地方在于两端：内容生产和内容消费。小红书内部盯着的两个核心指标，恰好就落在这两端上——一个叫「亲书作者」，对应内容生产端；一个叫「社区用户」，对应内容消费端。

这组指标跟其他平台常用的衡量标准很不一样，乍一听甚至有点反常规，但仔细琢磨会觉得很有意思。

内容生产端能持续输出优质内容，内容消费端能持续贡献阅读、互动和传播，社区的稳定增长就有了最扎实的底盘。
