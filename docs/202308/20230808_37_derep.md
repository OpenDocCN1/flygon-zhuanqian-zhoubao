# 过朋友圈卖手机-二手机，赚到了第 1 块钱
作者：龙哥

你信吗？有人只靠🛰️朋友圈倒腾二手手机，就赚到了人生中的第一块钱。这个人就是赚钱圈友“罗卜”——一个今年4月才入圈的小透明，平时擅长做竖屏思维导图。

别看他资历浅，华强北那套手机生意的门道，他可是真刀真枪趟出来的。他在分享里讲得特别细：怎么把卖手机做成副业；华强北一天天的真实状态；交易路上容易踩到哪些坑；客户都是从哪冒出来的；这门生意到底有什么优势；用户真正的痛点是什么；以及他接下来打算怎么做。无论是新机还是二手机的进货渠道，他都一条条拆开讲，连具体位置也没藏着掖着。他还专门教大家怎么给二手手机做品质检测，另外抛出了一个很有想法的路子——利用百亿补贴来赚差价。

完整的实战记录他整理在了飞书文档里，想深入研究的可以去慢慢翻。他还特意感谢了靠谱大佬的耐心修改和【赚钱研学社】小伙伴们的支持，看得出这篇分享也是集体智慧的结晶。

这条分享发出后，收获了58个赞，评论区也相当热闹。有圈友直接感慨：没有三年行业经验，根本写不出这种深度。一位同行留言说，她老板在飞扬四楼专做苹果机生意，货多价实，有需要可以直接找她。其他人也纷纷点赞，直呼“厉害”“真不错”“长见识了”，还有人感叹“原来这里面门道这么多”。

接地气的生意经，从来不缺观众。
