# 私域涨价后，客户一句“能不能按原价？”怎么答才不尴尬、不丢单？

“刚涨价不久，老价格还能不能给我？”做私域久了，你一定遇到过这种场景：你刚宣布定价上调，之前还在观望的客户反而冒出来了，最常用的理由就是拿“涨价时间不长”当筹码，希望还按原来价格成交。

说实在的，这个问题并不简单。答得不好，客户直接转身离开；答得太硬，就算成交，人家心里也未必舒服。根源老师专门针对这个场景做了一期专题，讲的正是他自己在实际接待中会采用的处理方式，目标很清晰：一边尽量争取留住这个客户，一边就算对方最后没有下单，也不至于对你产生太大情绪。

我读完最大的感受是——他提供的思路不是强硬拒绝，也不是轻易妥协，而是在涨价和人情之间找一个平衡点。整个过程有理有据，适合所有在私域里做知识付费、卖课、做服务的伙伴参考。
