# 个人 IP 分享共读，超级努力才能看起来毫不费力
作者：龙哥

标题：表面云淡风轻，背后都是拼尽全力

你好呀，我是龙哥，一个专门带写作新人上路的教练。

前阵子在辰风的社群加餐里，听了一场关于“个人IP”的分享。刚接触时感觉挺简单，好像是一套拿来就能用的方法；但真正往深处琢磨后才发现，这套东西里有“心法”也有“打法”，两者配合好了才有效。

可惜的是，很多人在这一步就停住了。有人甚至盯着那些成功IP的每个动作，一帧一帧地照着做。可最后换来的反馈和结果，总是比预期差很多，同样的事，人家做了就是另一番景象，自己做了却平平无奇。

也正因如此，不少人用力折腾了很久，始终没能形成自己的个人IP标签。说到底，他们只是知其然不知其所以然，表面看着挺像那么回事，里面其实空荡荡的。

而那些真正有影响力的IP，之所以做什么都显得云淡风轻、轻轻松松，是因为背后都极其用力。拼尽全力，才有资格说“我只是运气好”。
