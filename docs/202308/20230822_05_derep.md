# 做生意、谈钱的事，别让身份标签蒙了眼
作者：龙哥

最近老有朋友私聊我，说圈子里出现了借贷扯皮、合作闹翻的情况。

再次说清楚：

在任何商业往来或资金往来上，都请保持清醒和审慎。不要因为对方是赚钱员工、赚钱的圈友、龙珠的成员、航海家，甚至是站上过赚钱舞台的嘉宾，就自动降低你的风控标准、放宽审查流程。钱和资源的安全，最后都要你自己来兜底。

我的底线很简单：拿钱去做生意的借贷需求，我一概不参与。离有赌徒属性的人远一点，远离风险。
