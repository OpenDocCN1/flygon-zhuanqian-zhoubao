# 如果要学乔布斯做产品，先搞懂这一个核心

很多人把乔布斯神化了，觉得他的产品之所以让人上头，全靠天才审美、完美细节、还有那个标志性的发布会语调。

其实剥开这些光环，回到做产品的本质上，乔布斯始终在死磕同一个问题：用户到底需要什么惊喜。

我们时常陷入功能罗列、参数内卷、同质化竞争的怪圈，产品做得越来越重，用户却越来越无感。乔布斯的做法恰恰相反，他从来不是去满足用户已经说出来的需求，而是去创造用户还没意识到，却会立刻上头的需求。

那是一种超出预期的价值感。

不是你想要什么我就给你什么，而是你还没想到，但得到之后会觉得“原来我一直缺这个”。iPod 的一键播放、iPhone 的多点触控、Mac 的极简交互，每次都是这种出乎意料的惊喜把市场重新定义了一次。

所以学乔布斯，不必先学他的完美主义和控制欲，先学他的产品思维起点。

给到客户的价值，如果不是意料之外，那大概率就是可替代的。而一旦价值超出了预期，后续的口碑、复购、传播都顺理成章水到渠成。
