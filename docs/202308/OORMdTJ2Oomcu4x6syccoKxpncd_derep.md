#### Q1：TK中视频基金这个项目该怎么理解？

通俗一点说，这就是TikTok官方推出的创作者奖励机制。只要你往平台上传视频，平台就会依据播放表现给你发奖励。

它的官方英文名叫“TikTok Creativity Program Beta”，直译过来是创意者激励项目。之所以大家都叫它“TK中视频基金”，是因为它的分成逻辑和抖音中视频计划非常类似——按播放量付费，所以约定俗成就这么叫了。

![](img/757e1da88fbc77e8ff0c6dffc86ba314.png)

#### Q2：基金收益怎么算的？

前面提过，这个项目靠播放量来激励创作者产出优质内容，具体换算标准是怎样的呢？

根据目前我们跑下来的实测数据，每1000次播放，平均能拿到0.5至2美金不等的分成。

换句话讲，如果一条作品冲到了10万播放（英文写作100K），大致能带来50到2000美金的区间的入账。而TikTok的流量池又深不见底，爆发力极强。

#### Q3：中视频激励和创作者基金是不是一回事？

不少伙伴早前听过“创作者基金”这个概念，会好奇它和中视频有什么关系。

严格来说，TikTok早在2020年7月就推出过第一代激励方案，就是“Creator Fund”（创作者基金）。后来到了2022年年中，法国等地区率先上线了新的激励玩法，也就是我们说的TK中视频计划。

![](img/d2d606a1822a926c7a2b02da955ff60f.png)

因此圈内人也习惯把前者称为老基金，后者称为新基金。

两者虽然都是播放分成逻辑，但具体差异有好几处：

##### 差异一：到手的收入不是一个量级

虽然结算都看播放量，但新基金给到的单价要比老基金高出10倍都不止。同样做到10万播放，新基金最高能拿到两千美金以上的奖励。

![](img/ed355d553a9ce513dcfd19b4bcf2e89e.png)

##### 差异二：对素材的审核门槛更严

新基金对发布内容的原创属性有硬性要求，如果不符合平台规则，权限可能随时被收回。

![](img/a0f9c58a19a2a546ae370996dede12f2.png)

##### 差异三：开放的区域范围有限

就目前官方公布的信息来看，新基金仅在法国、美国和巴西这三个国家落地。

![](img/bcbfd9cee172c007d59045b47736dd35.png)

#### Q4：怎么开通中视频基金？手把手指引

当粉丝数积累到一定体量后，就可以着手申请开通权限了。

上面有提到，新基金和早期创作者基金在开通门槛上基本保持一致。

![](img/f15df1bad7c0a2b0ca34f806b64d3177.png)

如果已符合基本标准，接下来只需要备好两样东西，就能进入申请环节了。

![](img/264bcedbe194eb2fcbbe3954e5a2e95f.png)

我把详细的流程整理了一遍，总共十八步，并做了中英文界面截图对比，即便你手机系统是英文模式也能轻松跟上节奏。

第一步：打开个人主页，点击右上角三条横线的图标，在菜单中选中Creator Tools并进入。

![](img/98096a0a1178869a8f7ab41f0c3051cb.png)

第二步：在工具列表中找到Creativity Program Beta的入口并点击。（这里再补充一个小知识点：中视频基金只是我们平时叫的昵称，本质上就是新基金，由早年的创作者基金升级演变而来。）

![](img/a136eb7f51b5c7e1a1caea847d2f0c59.png)

第三步：页面跳转后，只要三个前提条件都已达成，直接点击红色按钮继续。

![](img/b6396e5ba6e5b8267948fa6debb059d9.png)

第四步：接下来需要选定你的证件归属区域，照实选择自己所在的国家就可以了。

![](img/c02c5f0d0f94d019106ba0f7e1a3143b.png)

第五步：然后选择证件类别，护照和身份证二选一即可。

![](img/2653e6443da3fbf819ac0eb924149190.png)

第六步：点击下一步，进入身份校验环节。

![](img/e05c33437ed728489c74ab760198245b.png)

第七步：将证件拍照上传，注意照片要拍清楚，尤其是年龄信息那一栏。

![](img/4c52fe13430cd8042d2466509adbd64d.png)

第八步：传完证件后，点击Continue按钮，接着补充更详细的个人资料。

![](img/acb84bc53e32c63b5fa556a8724a3822.png)

第九步：根据页面提示把信息逐项填好。特别注意第二栏的姓名拼音序，先名后姓，例如“李保国”要写成BAOGUO LI。

![](img/fd233c122477d60ef63a03c7952b347a.png)

第十步：再次核对所有信息无误后，点击SUBMIT提交。

![](img/e2ec8d4f2494d74b5c59573dc0405d7d.png)

第十一步：提交后页面会显示under review，意思是审核中。返回主界面等待大约3分钟，再重新从个人主页进入Creativity Program Beta查看状态。

![](img/3373e24407070aa6513cb0ef027244cb.png)

第十二步：一切顺利的话，你会看到界面显示已经开通。如果没通过则会提示失败。在这个页面等待3天，之后就能看到收益明细了，以后日常查收也从这个入口进。

![](img/7cc41fe11e2d272c27adc214d7a03fa1.png)

第十三步：如果你是美区或巴西区的用户，后面还有一个额外环节：完成年龄验证后，还需要填写税表并关联PayPal。点进去后，第一行是绑定收款账户（也就是PayPal），第二行是补充税务信息。如果收款入口点不动，就先去填税务资料，回头再绑定收款渠道。

![](img/4664468a1c3a13733c54ca1b0a9cdbb5.png)

第十四步：提交税务信息时，账户类型这里选择个人Individual。

![](img/264857d6c20d6c273553c42c77b9ee39.png)

第十五步：随后要补充身份信息和税务号码。这部分内容涉及隐私，不方便在公开场合细说，容易撞红线。假如你卡在这一环，可以单独找我，我把操作指引发给你。

![](img/a9f25d28ba74ea1af65b9d6ffdfbb485.png)

第十六步：资料填妥后，系统会让你复核并提交完整的税表。（这个大家不用太紧张，对咱们没什么实质影响，就是个标准流程。）

![](img/6660992681b3f29ed48074aa26d8b760.png)

第十七步：提交完成后跳回TikTok，点击DONE收尾。

![](img/e36d9e9806ac26245abab529c3f4739a.png)

第十八步：返回原页面后，点一下收款信息设置，录入PayPal账号和密码确认绑定即可。

#### Q5：开通后钱怎么提出来？

说完开通，再聊下大家最关心的部分——已经产生的收益如何顺利落袋为安。

![](img/f1ae9e982f416f8a086438c891257a8e.png)

首先你要清楚，所有收益都会汇入之前绑定的PayPal账户。美区和巴西区是次月15日自动打款到账；法国区目前仍是月底手动申请提现，走的是老基金的那套流程。

核心挑战在于，PayPal里的美金怎么结汇成人民币转到国内银行卡。目前我们反复测试后，总结出了三条可行路径。

路径一：通过万里汇转结

流程是PayPal先提款至万里汇，再由万里汇结汇到国内储蓄卡。去年以前我们团队一直走这种方式，确实省事。但今年万里汇对非电商性质的款项审查力度明显加大，限额卡得比较严。如果你手头本来就有电商方向的流水，这条路可以说是最优选。当然真碰到额度不够的情况，也有办法可以解。

这个方案最大的弱点就是流程繁琐，需要递交大量材料去证明资金来源，非电商款项又卡得格外严谨。

万一你实际操作时也卡在额度环节提不出钱，到时候可以来问我。

![](img/5fd8661c936a495339287f9b22ef8d05.png)

路径二：通过报白账户周转

这个方案用起来最省力。因为我们的账目流水一直很大，之前专门对接过一个报白账户来配合处理。你只需从PayPal转账到报白账户，后面就能直接提现了。不过这里涉及资金安全的风险管控，对于不熟悉的客户我无法确认资金来源，所以这条路暂不对外开放，只帮社群内部的伙伴应急。如果方法一行不通，你可以私信我帮你看看。

路径三：通过万里汇的虚拟信用卡

针对提现额度不足5000元人民币的情况比较适用。具体怎么操作，直接咨询万里汇的在线客服更高效。（这条路我本人还没动手实测，所以就不展开讲了。）

#### Q7：什么样的作品适合拿来跑中视频？

被问到最多的问题就是：中视频到底适合做什么类型的作品？

从前面我们也聊到了，新基金对素材质量是有隐性门槛的，如果作品形式不符合规则，可能直接被收回操作权限，或者因为被判“非原创”而颗粒无收。

下面我推荐四类经过验证的创作方向：

1. 数字人讲述类
内容形态：以人物口播方式讲故事，或者输出人生道理。
落地思路：结合当下成熟的AI生产链路，先用Midjourney等绘图工具生成贴合主题的人物形象，再借助AI平台把静态图转化为可以开口讲话的动态视频。

![](img/d8870ff5a735fd5089150afbdf27be9b.png)

2. 解压向作品
内容形态：瓶子滚落挑战。
实现逻辑：在瓶子里装上液体或彩珠，从楼梯一级级滚落下来，视觉效果极其解压。用户的猎奇心理会驱使他们看到最后，完播率就这样在无形中被拉满。

![](img/7794aff2ee318547864805724d99391c.png)

3. 3D视觉作品
内容形态：跟随音乐节拍律动的3D小球。
制作思路：用C4D等三维软件打造高逼真度的动画，比如小球有节奏地掉落，同时配合敲击感十足的音效。这和上面提到的推瓶子逻辑相通，靠视觉奇观吸引眼球，甚至很多人会误以为是实拍。

![](img/38cc2ad339eb3932047d86e38cb96ffd.png)

4. 搞笑混剪切片
内容形态：多素材混剪类作品。
制作思路：大家平时刷到过不少这类内容吧，其实它们一样能顺利过审。把不同来源的有趣素材进行拼接融合，只要原片质量过关，审核问题不大。

![](img/a75cf033abec7373e1b5b6f427473b03.png)

#### Q10：新手最容易踩到哪些坑？怎么破？

刚开始操作时，以下问题出现的频率最高：注册频繁、无法点赞、关注受限、改资料被挡、0播放、低播放。

先说注册频繁一类的问题，根源大概率出在设备或网络上。
对策：可以尝试切换注册渠道，比如接码注册、谷歌邮箱第三方登录；也可以还原手机设备再试；要是还不行，直接换个节点就解决。

至于注册成功之后遇到点赞、关注、修改资料被限制，或者发出去的作品完全没有播放，这类情况是TikTok近期对新号采取的风控策略。通常等个3天就能自行恢复。注册完成后，建议多刷一刷视频，保持账号活跃度。

#### Q11：起号阶段需不需要养号？

要不要养号，一直是圈子里争论不休的话题。我一直以来的态度都是：最好养。

我们不妨倒推一下：如果TikTok的后台机制会给行为轨迹异常的账号打上营销号标记，进而压低流量分配；那当你通过养号能大概率规避这个风险时，为什么不顺手做一下呢？老话说得好，宁可信其有，不可信其无。

之前TikTok也验证过这点——新账号注册后的头3天，大概率拿不到播放。这本质上就是平台对新号的考核期，通过识别网络环境和设备指纹等因素来判定你是否可能是营销号。

那具体怎么养？注册完之后不要急着改资料、换头像，先正常刷刷视频就好，刷个半小时足矣。这段时间也别浪费，顺便翻翻同行的账号，观察他们的内容风格，等于给自己补充弹药。刷完之后隔几个小时，或者第二天，再去完善资料以及发布作品。

我们每天都会批量注册一批账号，就像补充弹药一样，按照这个节奏循环运转。

#### Q13：一台手机能不能同时跑几个账号？

不少伙伴因为手机资源有限，都会动“一机多号”的念头。

新手请务必不要这么做。我的标准建议永远是：一台手机只能跑一个账号。最核心的原因在于，如果出了状况——比如视频没播放——你根本没办法判断是不是因为自己多号操作才被限流的。

所以我的看法是，最好从3台手机起步，一台设备对应一个账号。这样还可以做对照试验，出了问题能立刻定位到具体环节。另外，用不同的手机跑不同的内容赛道，也更容易在起号阶段快速验证方向。
