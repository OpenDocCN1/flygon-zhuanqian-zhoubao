# 回来啦：走南闯北三个月后，我卸掉了“卷王光环”



## 松弛心态：那个曾被封为精华帖卷王的我，跑了三个月后不再硬拗奋斗了

作者：七小
日期：2023-08-18

《松弛心态：被叫做精华帖卷王的帅小伙，外出历练三个月后也不玩命了》

大家好，消失了许久的我回来了。刚刚结束了一趟为期三个月的出行，从郑州到杭州再到上海。这段路上走走停停，让我对职业、项目和创业的认知有了很实在的跃迁。这些心得我会抽空整理成万字长文再来分享。

今天想先聊聊更私人的变化，我关于奋斗和赚钱焦虑的看法。过去圈子里常把我归为卷王，如今我已经不想再当那个“奋斗逼”了。是怎么一步步松下来的？我的思路拆解如下。

正文在飞书里：

目录大致是这几块的旧想法被我推翻了：

旧想法一：猛赚钱就等于很厉害
1. 把隐形成本全算上，还香吗
2. 钱到手了，过程舒不舒服
3. 钱到手了，能不能守住
4. 小结

旧想法二：奋斗就该像呼吸一样日常，工作八小时理所当然
1. 男人世界的打法
2. 女人世界的打法
3. 看清了天赋起点和努力天花板后，我不再鼓动所有人更拼
4. 想帮别人加油，先得承认人与人之间的差异

旧想法三：所有人都要奋斗，早点成独当一面的年入百万大佬
1. 承认物种不同，超级个体模式并不普适
2. 别人的胃口不是你的胃口，别硬喂人吃撑
3. 关键不是上进不上进，而是对当下的满意度和对未来的渴望度不一样

旧想法四：每天都得拼，等钱够了就有自由和幸福
1. 钱够了之后呢
2. 明明已经进步飞快，为什么心里还是发慌

旧想法五：他们那么强，我也能稍微好一点
1. 如果“厉害”会让人焦虑，那换个词叫“幸运”会怎样
2. 旁人再快，你的上限终究是你的上限

尾声碎碎念
