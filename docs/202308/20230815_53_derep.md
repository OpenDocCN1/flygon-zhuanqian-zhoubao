# 《纳瓦尔宝典》作者 Naval Ravikant 播客接受访谈分享
作者：龙哥

最近，《纳瓦尔宝典》的作者 Naval Ravikant 做客了 Tim Ferriss 的播客，聊了不少硬核思考，我帮你把精华捋出来了。

先说读书这件事。Naval 认为，真正重要的不是读哪本书，而是你有没有养成长期阅读的习惯。他自己主要是在 Kindle 上买书，然后用 iPad 来读，最近正重新翻看物理、历史和哲学类的经典。

关于习惯，他提到每天早上的 30 分钟健身，是他雷打不动的头号习惯。除此之外，冥想、阅读、少碰酒精和咖啡，也是他日常坚持的方向。

说到幸福，Naval 觉得每个人定义不同，但在他看来，幸福其实是一种既没有痛苦、也没有欲望的状态。很多人误以为外在环境和物质能带来幸福，这恰恰是最大的误区。

对自由的理解，他也有变化。过去他认为自由就是想干嘛就干嘛，现在他更认同“免于反应的自由”，比如不被愤怒牵着走，不被悲伤困住，这才是真正的自由。

经济学方面，Naval 直言自己已经不太信宏观经济学了，因为很多东西没法证伪，数据又多，大家其实只是在挑选自己喜欢的叙事。他认为微观经济学和博弈论才是经济社会的地基。商业上能不能成，很大程度上取决于你对供需、劳动力与资本、博弈论这些底层逻辑的理解。

那什么是好的创始人？他说了三点：一是愿意做长线思考，二是在过程中能真正享受，而不是死盯着短期结果，三是有执行力，能把手上的事扎实推下去。

至于生命的意义，Naval 认为这没有标准答案，每个人都要自己去寻找。某种程度上，生命本无意义，意义要靠自己创造。他甚至还给了一个物理学视角的猜想：从热力学第二定律来看，熵只会不断增加，而生命作为一种复杂系统，在加速宇宙热寂的过程中，或许就构成了一种意义——虽然这个答案并不怎么令人愉快。
