# 当权力走到尽头，李斯才想回上蔡打兔子
作者：龙哥

听《熊逸讲透资治通鉴》时，正好撞上秦二世胡亥和赵高联手送李斯上路的那一段。

那位曾执掌秦国朝政的丞相，最后的结局可以用惨烈来形容：五刑并施，腰斩于咸阳街市，全族株连。五刑即墨、劓、刖、宫、大辟，依次是刺面、割鼻、断足、去势、处死。夷三族，则是父系、母系、妻族一并清除。

行刑那天，李斯和他的二儿子一起被押赴刑场。他的长子李由，早在雍丘之战中被刘邦、项羽所杀。走上刑场前，李斯留下了一句广为流传的遗言：“吾欲与若复牵黄犬俱出上蔡东门逐狡兔，岂可得乎？”

翻译过来就是：我想再拉着你一起回老家上蔡，从东门牵条黄狗去猎兔子，这样的日子再也回不去了。从此，李斯一门从此断绝。

临终这句追悔，很容易让人觉得是幡然醒悟。我的理解恰恰相反，更多是无路可退后的感慨。李斯从小吏一步步爬到丞相之位，期间有无数个可以抽身的节点，他没有选。他始终在赌局势会逆转，舍不得手里已经到手的荣华。

《史记》记载李斯是楚国上蔡人。年轻时曾做过小官，有次上茅房，看见粪坑里的老鼠狼吞虎咽却惶惶不可终日，一点风吹草动就仓皇逃窜。后来他又去看过粮仓里的老鼠，吃喝不愁，安稳自在。这一对比给他的人生启示是：人生境遇的好坏，就像老鼠的命运，关键看你待在哪个位置。

受此启发，李斯投奔荀子求学，后入秦。一篇《谏逐客书》让他被重用，随后一路攀升。儿子李由做了三川守，家中男丁续娶秦公主，女眷下嫁秦公子。秦二世大兴党锢，李斯的子女首当其冲受累。李由休沐归家时，李斯大排宴席迎接，前来祝贺的百官车马竟排到上千辆。那时李斯也曾私下感慨会不会盛极而衰，可感慨归感慨，他从未想过放手或急流勇退。

赵高的陷害一步步收紧，昏庸的秦二世又跟着起哄，最终酿成灭族之祸。

李斯的后悔只在最后一刻显现。若真让他重来，我猜他仍会选择向上攀爬。毕竟没到绝路，谁会轻言放弃？若当初他就留在上蔡庸碌度日，或许他一辈子都会觉得自己像那厕所里的老鼠，战战兢兢、提心吊胆。

再看当时的时代环境，即便李斯留在楚国，多半也难逃被征调为兵，与秦军厮杀的命运。即便侥幸活着，终究会被编入秦国的户籍体系，或死在长城、五岭，又或死在骊山。

荣华富贵与平平淡淡，从来不是简单的对错题，而是位置、选择与时代共同决定的宿命。
