# 00 后大厂产品 AI 创业半年，最后靠卖课变现几十万

说实话，这半年我在AI赛道里扑腾得挺累，但故事还挺有意思。

一个00后，从大厂产品岗出来，兼职折腾AI创业，没搞出什么惊天动地的大项目，最后倒是靠卖课赚了几十万。听起来有点魔幻？但这恰恰是我最真实的经历。

最近终于有空坐下来，把这半年的坑、弯路和思考好好盘一盘。文章可能有点碎，毕竟很久没认真写东西了，大家将就看。

这半年我到底做了什么？踩过哪些坑？对AI这个赛道又有哪些新的认知？都在下面这份复盘里了，感兴趣的朋友可以点开细读。

对了，评论区也挺热闹。有人想加微信谈合作，有人催我赶紧写抖音引流卖课的实操干货，还有前辈直接抛来橄榄枝——上次他邀请的年轻人，现在已经做到领域头部，年利润接近八位数了。真是人比人，气死人啊。

不管怎样，这半年没白折腾。哪怕没拿到什么大结果，至少知道了哪些路走不通，哪些路值得继续走。你呢？如果也在AI赛道摸索，欢迎来聊聊。
