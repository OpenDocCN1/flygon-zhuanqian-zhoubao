# 如何用“通义听悟”帮助我们更好的提炼音视频内容？

看视频、听播客的时候，你是不是总感觉“信息过载”？好不容易听完了，转头就忘。我最近一直在用阿里大模型能力孵化的“通义听悟”，在提取音视频要点这件事上特别能打，帮我省下了大量重复视听的时间。

不过比起单纯分享这个工具怎么用，我更想把它的产品原理也拆给你看。为什么要搞懂原理？因为只有理解了AI背后的逻辑，你才知道它是在哪些环节帮你省时间，也才能真正把AI用到位。

我现在写文章、做内容，很大程度上都靠“通义听悟+Claude2”这对搭档：一个负责从音视频里抓关键素材，一个负责把内容整理深化，配合起来相当顺手。

这篇关于通义听悟的使用解析，和上一篇讲Claude2辅助深度写作的文章，我都放在飞书文档里了，两个链接可以一起打开看看：
