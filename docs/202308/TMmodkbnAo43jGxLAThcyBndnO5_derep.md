# 一、📕商单怎么做？

📕这个平台大家也知道，用户种草意愿强，品牌方烧钱做推广很舍得。以前他们只盯着中腰部和大博主，现在反倒愿意把预算分给普通人。更关键的是，官方接单平台“蒲公英”的开通门槛已经从5000粉降到了1000粉，这就是给咱们普通人敞开大门嘛。千粉之后，一篇广告报价在150～500元之间，而且基本都是图文单，品牌方把图片和文字发过来，你直接复制粘贴保存再发出去就行，一点技术含量都没有。

![](img/b5e4017dcd7a4e8fde58fda8eb7adaed.png)

那问题来了——怎么快速突破千粉呢？很多人不知道，最快的方法其实是“搬运”。但搬运不能乱搬，📕有自己的查重机制，你随便搬别人的作品，可能原作者早就在📕发过了，这样很容易违规。正确姿势是：专门找那些没在📕发过作品的博主，从抖音/快手搬他们的视频过来，再用剪映做一遍简单去重，相似度低于60%就不会被判违规。

我自己拿两个号做过测试，发笔记两三天就破了千粉，其中一个号7天直接冲到6000多粉，破万就是时间问题。

![](img/7c493633522c040e46c2ae536468e526.png)

怎么判断别人有没有发过📕？最简单的办法：在📕搜你想搬运的博主账号名，看名字、头像、作品是不是对得上；或者直接搜视频标题的关键词，也能查出来。另外建议别碰100万粉以上的大V，容易被举报。目前这个玩法知道的人还不多，很多小众领域都还是蓝海，机会一大把。

搬什么内容？不限制领域。你可以从自己感兴趣的赛道下手：爱玩游戏就搬游戏，喜欢动漫就搬动漫，综艺八卦也没问题。但重点最好放在女性受众更多的内容上。还有，新手起号一定要垂直。想做哪类视频，就先刷哪类内容，每天花一小时模拟正常用户刷视频，点赞收藏加转发。这样养号三天，账号至少会变成“奶瓶薯”，基本就算养号成功，可以开始发作品了。

比如这个号做的玩泥巴、影视解压类视频，播放量涨粉速度都很猛。

![](img/c3ea29132ca5d579b49ec8e2c1b9fc74.png)

还要提醒一句，有些影视搬运号连水印都不去掉，原创作者一搜一个准，很容易被举报。所以尽量找无水印素材，或者用工具把水印去掉再发。

![](img/ebe7ec18b9ee2ef803fd31fb915f4b49.png)

一般影视剧素材从抖音搬，泥巴解压类素材去快手找，搜“史莱姆”“玩泥巴解压”这些词就行。找到后用剪映一拼就能发。

![](img/1792677be0d48364f683af23f56e0ea1.png)

最近魏大勋热度很高，抖音上有不少影视和综艺爆款片段，可以直接搜来用。哪怕你是个纯小白，一条视频5分钟也能搞定。每天抽一小时，同时打理两三个账号完全没问题。注意一定要一机一卡一号，千万别双开。手机端可以用去水印小程序，电脑端用批量搬运软件，我更推荐电脑操作，省时省力。

千粉之后，去实名认证、申请开通蒲公英，就能接广告了。数据好的话会有品牌方来邀约，也可以自己接单；但自己接广告资源少，而且违规风险高。我现在绑定了MCN机构，靠谱机构手上的广告资源特别多，几乎天天都有单，毕竟是给平台交过“保护费”的，不容易被判违规。机构还有专人教你怎么玩，跟着市场情况随时更新打法——因为搬运的人一旦多起来，固定类型的视频被判非原创的概率就大了，必须不断换新思路。
