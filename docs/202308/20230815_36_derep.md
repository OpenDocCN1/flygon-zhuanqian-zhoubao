# 在直播间卖一张流量卡，我是怎么做到年入百万的

先做个自我介绍，我是阿阳，95后，来自哈尔滨。目前全身心都在通信这个赛道上，专门做手机卡的副业已经做了两年多。说实话我入行算比较晚的，但也正因为来得晚，我才更知道怎么抓住当下的红利。

核心就一个点：线上办的流量卡，比运营商线下柜台的套餐便宜太多。

现在谁还用一台手机只装一张卡？几乎人人都双卡双待。用一张卡保留常用号码当主号，另一张卡专门冲流量当副号用。需求一出来，市场自然就大了。大家对价格敏感，对便利性又要求高，这就是流量卡在直播间能卖爆的底层逻辑。

我把这个模式搬到直播间做，客群精准、成交快、复购逻辑也清晰。两年时间下来，这个赛道带给我的回报已经稳定在了百万级别。

想了解具体的选品、话术、引流和供应链搭建，我整理在了飞书文档里：https://rad7nmnpd6.feishu.cn/docx/ZRUIdkOYyodJkfxdreJcrVQYnx7?from=from_copylink
