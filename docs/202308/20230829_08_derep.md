# 创业路上，时间与钱，到底哪个更值钱
作者：龙哥



## 时间与金钱谁贵

作者： 小马宋

日期：2023-08-23

时间与金钱谁贵：创业 46 条之 22

在经济学家看来，世间万物最终都能折算成价格，连时间与生命也不例外。

有一位经济学教授的观点更狠，他认为世上没有绝对的刚需，空气、水、甚至生命都一样，一旦价格高到某个临界点，人们就会选择放弃，转而寻找替代品，任其自然就是最终的出路。

创业的逻辑也类似。公司处在不同阶段，对时间与资金的权衡天差地别。

刚起步时，大部分创业者手里没钱，公司的一点点创新和增长，基本都是用创始人的时间与体力硬换来的。熬通宵、泡在一线、亲力亲为，就是那段时间的生存方式。

这个阶段，钱是稀缺品，人是充裕品。只能靠堆时间、拼精力，用饱和式的个人投入去碾压对手，赢得先机。

等公司做大了，创始人本人的时间就成了最贵的资源。此时人值钱、钱不值钱。能花钱搞定的事，就别再占用创始人的精力去亲自操刀。做事的思路就变成用钱去买效率，哪怕人效看起来不高，也要把成本当成护城河来用。

三顿半、永璞咖啡一开始走的就是创始人深度下场、靠极致投入换增长的老路，钱袋子没那么鼓，只能靠人。瑞幸从第一天起就反着来，用资本去解决问题：请世界咖啡大赛冠军当咖啡师，请张震、汤唯当代言人，广告铺满全网，开店速度不计成本。两种打法没有绝对的高下，全看你手里有什么资源。

腾讯出本书能请吴晓波来操刀，我出书就只能自己熬夜码字，因为人家的稿酬至少是我的一万倍。马总要是自己写书，付出的时间成本根本扛不住。
