# 真正清醒的人，把坏消息也当成情报

如果有人告诉你，坏消息和好消息在决策面前同等重要，你信吗？对于真正尊重事实、敢于直面现实的人而言，这并非鸡汤，而是一种清醒：消息不管好坏，都是判断世界的材料。

2007年2月23日，周五。星巴克创始人霍华德·舒尔茨正坐在犹他大道办公楼九层的办公室里。门猛地被推开，一个同事冲了进来，用难以置信的眼神看着他：“发给高层的备忘录，泄露出去了。”

“什么？”舒尔茨以为自己听错了。

“备忘录已经在网上传开了。”

那份备忘录写在情人节当天，内容不是官腔，而是一个创始人对公司现状的真诚自省——星巴克在高速发展过程中，已经积累了不少问题。这种内部反思本不该外传，却被人公开到了互联网上。外界很快就炸了：有人不明真相就开始批评星巴克和舒尔茨，网友的评论阴阳怪气，重量级媒体也争相报道。

在舒尔茨眼里，这几乎等同于“背叛”，星巴克被一下子卷到了舆论的中心。可风暴过后，他也比任何时候都更清楚地看见了两件事：

一方面，世界上没有真正的秘密，这是互联网时代的新现实。无论你是公司还是创始人，说话再真诚，也要注意场合、保持谨慎。

另一方面，移动互联网的浪潮已经扑到门口，而星巴克在网络上却几乎没有任何话语权。就在备忘录泄露前一周，苹果发布了iPhone；更早一些的2006年12月，谷歌收购了YouTube；到了2007年10月，Facebook横空出世，迅速收获几百万用户。相比之下，星巴克对数字世界的感知，确实慢了半拍。

正是这两个事实，帮他更清醒地理解了这个真实世界，也为他2008年回归星巴克、重新出任CEO并推动公司变革，打下了认知基础。

传播学告诉我们，坏消息向来比好消息更有传播力。报纸时代如此，互联网时代同样如此。“坏比好更有威力”这个规律，从未被推翻。但在个人成长和真实世界的维度上，坏消息与好消息其实是等价的——它们都是能帮你提升决策能力和认知水平的高价值信息。

所以，别急着把坏消息关在门外。一个实事求是的人，会把它当成难得的信号，而不是可怕的噪音。
