# ('私交与公事，情感与理智，管公司要公私分明', (2, 22))

最近读叶明桂的新书，最后部分让我最有感触——他讲自己是怎么狠下心辞退老员工的。

叶明桂算不上老板，公司不是他的，他是台湾奥美的总经理，职业经理人身份。奥美创意部有位元老级人物叫hoho，入行时机还是手工绘图的老年代。等整个行业转向电脑制图，他不肯学新技能。奥美没办法，只能专门配一个年轻设计助理，让hoho动嘴，助理动手。

到了最后，叶明桂还是咬牙做了决定，请他离开。送走共事多年的老伙伴，心里当然不好受，但站在公司业务的角度，这步棋非走不可。

这种两难我也体会过——从私人感情上说，我真开不了口；但从公司立场上讲，这个人必须离场。

更离谱的是，我碰到过公私完全拎不清的老板。他们公司的天猫旗舰店，居然被一个经销商攥在手里。我劝他把旗舰店收回来，结果他找经销商一聊，对方哭天抹泪，说这家店是自己的命根子。老板心一软，收回的事就搁下了。后来旗舰店用淘宝贷款逾期，公司信用被坑得够呛，这才总算把店收了回来。

生意场上，有一些老板拿义气当通行证，最后恰恰栽在义气上。签合同前嘴一撇：“哥信任你这个人，合同不用看！”听着豪气干云，其实是极度的糊涂。万一碰上个背着人算计的角色，公司被搞到关门都不算稀奇。这些年，我是亲眼见过太多这样的案例。

公司的事归公司，私交归私交。只要涉及公司业务，就一定要公事公办，不能让感情替理智拿主意。
