# 我们开年会为什么不坐一架飞机？

《瓦格纳坠机背后，藏着一个中国人都该懂的道理》

普里戈任的私人飞机坠毁，机上瓦格纳高层几乎团灭。真相扑朔迷离，但有几个教训，值得好好嚼一嚼。

先说历史这面镜子。翻开中国帝王史，掌权者最怕什么？怕手下有兵，更怕有兵的人动了反心。赵匡胤一杯酒解了将领兵权，刘邦朱元璋杀功臣杀得毫不手软，本质上都是同一个逻辑：你能威胁到我的座位，你就活不长。

普里戈任虽是商人，但手里握着武装力量，还真的带兵闹过事。放在中国古代，这种“实锤造反”的剧情，任何皇帝都不会留他活口。当年王翦出征伐楚，仗还没打，先跑去跟秦王讨赏赐。你以为他贪财？不，他是在装俗气，告诉老板：我只图钱，不图别的。因为手握重兵的人，最怕被老板怀疑有野心。贪钱没事，想上位才要命。

再说风险意识。去年我们去三亚开年会，公司特意安排大家分乘两架飞机，就是怕万一出状况，别被人一锅端了。珍宝岛那么紧张的时期，中央八位副国级领导分头去了八个城市，同样是避免集体陷入危险。而瓦格纳这帮高管，战时还挤在同一架飞机上，只能说太自信了。

有些规矩，不是怕死，是懂博弈，懂历史，懂人性。老祖宗用五千年撑下来的智慧，别不当回事。
