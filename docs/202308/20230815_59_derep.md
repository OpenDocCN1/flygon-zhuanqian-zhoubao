# ('创业过 3 次他在创业初期是如何思考产品的', (2, 23))

你发现没有？理想汽车在舆论场上总是被各种质疑，可一看销量，却常常让同行眼红。而这一切的背后，绕不开一个人——李想。作为连续创业三次的老手，他早期对产品的那套思考，才是真正值得挖的宝藏。

很多自媒体聊理想，翻来覆去都是口水战。但说句实话，我之所以对这家公司有好感，是因为很久之前看过李想讲产品的一段演讲。那内容含金量有多高呢？到现在我想起来，依旧觉得触动很大。

一个CEO最厉害的地方，往往不是多勤奋，也不是多会管理，而是在最关键的分岔路口，押对了方向。而这种“押对”，靠的可不是玄学，而是日复一日的深度思考。所以，与其围观那些争论，不如直接回到源头——看看李想当年是怎么琢磨产品的。

他做产品的逻辑很清晰：先想清楚用户真正需要什么，再一层层拆解。他提过一个特别实在的标准：好产品要有三种感受——安全感、优越感和价值。你看，安全感是基础，用户得觉得这东西靠谱；优越感是加分项，让用户觉得有面子、与众不同；价值最直接，就是这东西得有用、能解决问题。这三样，其实放到很多行业都成立。我们拿生财有术来说，安全感就是沉淀多年的内容、持续更新的精华、还有一群同路人；优越感可能是圈子里的高手和大资源；价值嘛，更简单，就俩字：搞钱。你看，是不是完全对得上？

那汽车之家当年是怎么做起来的？也是靠这套思路。李想不是拍脑袋做产品，而是从用户的实际需求出发，把信息做得更透明、更丰富、更好用。所有决策背后，都有日常积累的观察和思考在支撑。

对我们普通人来说，能学到什么？我觉得最大的一点是：别急着上来就炫技，先花时间把产品背后的逻辑理顺。你的用户要什么？什么能让他们安心？什么能让他们自豪？什么能实实在在帮到他们？把这几个问题想透了，方向就不会偏。

说到底，正确的选择从来不是灵光一现，而是长期思考酿出来的果实。李想的故事，其实就是这句话最好的注脚。
