# 如何写出一篇对读者“有用”的文章？

**写出的文章没人看？先别怪文笔，你可能掉进了“自嗨”的坑**

做自媒体，最憋屈的事莫过于：冥思苦想半天，一个字写不出来；好不容易写完，发出去却像石沉大海。很多人这时候会怀疑自己文笔不好，其实，真相往往是——你写的东西对读者来说“没用”。

尤其是刚起步、还没什么粉丝的时候，千万不要只顾着写自己的心情、感悟和日记。说句直白的话：没人真的在乎你脑子里转了什么，大家只关心“我花这几分钟读你写的字，到底能带走什么”。如果你想靠写作变现，那更要牢牢记住这一点，必须输出对别人有价值的内容。当然，如果写作只是你的个人爱好，为了记录、为了练表达，那随性写就好。写作目的不一样，打法自然不一样。这就是自媒体写作的第一课：思维转换。

想通了“为读者而写”，但还是不知道从哪下手？其实最简单的方法，就是去写你看过的书。拿出一本书，诚实地回答四个问题：它讲了什么？你最喜欢书里的哪个部分？它对你产生了哪些影响？它有哪些优点值得分享？把这四个答案写出来，一篇对读者有用的“荐书稿”就成型了。因为你的推荐会让人少踩坑、多收获，这就是价值。

![](img/c9a8b9af138dcf8db7602a9de4491e50.png)![](img/b2e97f699a886c10fea2835e8b2bcee4.png)

当然，也有人会说：我看完一本书，毫无想法，怎么办？别急，这多半是没读懂。那就借助外部力量——去知乎、豆瓣、今日头条搜一搜别人的读后感，把不同的观点记下来，整理出十条二十条，再回头翻书。有了这些参照，理解自然加深，想表达的东西也会跟着冒出来。毕竟，只有自己真正懂了，才能讲给别人听。自己都糊里糊涂，写出来的文字也只能是一团浆糊。

![](img/1e101adba3de97ca6c701fc3c57b77c9.png)![](img/961ad6cf16cf3c9b5a30fd5dfb1ed7c0.png)

而且，一个人读什么样的书，直接影响他的思想和表达水平。所以选书特别重要。市面上烂书太多，一旦挑错，吸收的观点就容易跑偏。很多鸡汤类文章之所以能成爆款，就是因为门槛低、情绪浓，读着好像很有道理，实际却给不了任何实质帮助。这类书，还是躲远一点。我平时比较喜欢用樊登读书，![](img/5e207c539291ccf2dd7b19d9f5bf5c72.png)新用户以前可以免费听7天，现在还有没有这个活动我不确定，需要的话可以扫码看看。🛰️读书也值得逛逛，免费电子书不少。樊登本人是博士，讲书时条理清晰、逻辑分明，听久了，他拆解一本书的思路会悄悄被你吸收。至于得到和喜马拉雅，感觉更像大杂烩，好的坏的全混在一起，筛选成本太高。

解决了“没得写”，再解决“案例难找”。很多写作者总觉得例子不够用，其实，案例不是“找”出来的，而是靠理解“造”出来的。你举什么例子，直接决定读者能不能秒懂你说的概念。举不出来通常有两种情况：一是概念本身没吃透；二是懂了却表达不到位，写出来像流水账。那该怎么练？不如从共鸣感最强的日常场景下手。

比如要讲“睡眠能力”这个概念，你可以先看看这样一个现成的开头：![](img/a22c0679f1aac3d527e879292c94c04b.png)![](img/9db2cd0d1a94beb01998ecfe603e8e4d.png)看到没有？关键词就是“当妈的睡不了整觉”“宝宝要抱着睡、哄着睡、奶着睡”。这些是众多家庭的真实日常，不是谁家的独家原创。所以，你完全可以顺着这些关键词编自己的故事：![](img/6b020bf07cc1eea368a55b54ae092668.png)可以写你自己当年的经历，可以写你去探望坐月子的姐妹，也可以写某个同事在电话里叹着气跟你诉苦。写法千变万变，只要把关键词扣住，最后落到“这就是宝宝的睡眠能力问题”上，就不会跑偏，更不会被扣上抄袭或洗稿的帽子。

说到跑偏，很多人的文章就是死在例子偏题上。我见过一个学员，本来想解释“什么是感官能力”，![](img/13cbf5bcab1e8dbde3907676c3938597.png)![](img/05726539bf82da7473a51f81ed20e27f.png)结果举的例子却是在讲“不同宝宝的感官能力不同”。![](img/bfc0472edff689f405a727f55f4327bf.png)一个是解释概念，一个是讲个体差异，完全不是一回事。关键词一换，整篇文章的方向就歪了。所以，别嫌列框架麻烦，有了框架，你才知道故事该在哪儿转弯，该用怎样的篇幅去收尾。

如果你未来想写付费专栏，也是一样的道理。卖知识之前，先站在买家角度问自己：我到底为什么愿意为这钱买单？无非两点：作者有没有真本事？我学了能不能照做，并且做出同样成绩？想清楚这两点，你的自我介绍就不会干巴巴的。比如你的履历本身很亮眼，![](img/3df80086db572cd11f0427c97efb7b5b.png)但也别光把数字堆上去，完全可以换个讲法：![](img/c8e7082af9cddf6d5b44dabfdb9610ec.png)告诉读者“我用一个小号验证过这套方法，拿到了这样的结果，而且这套路径可以复制”。这样既亮出实力，又给了别人“我也能做到”的希望，吸引力自然翻倍。

最后，想说一句：上面这些方法，听起来都不难，难的是真去练。很多人看完文章，心里默默说了声“有道理”，然后就没有然后了。一边抱怨没有进步，一边急着想要变现，却又静不下心来写一篇、改一篇、再写一篇。其实，只要照着做，收获是100%会有的。怕就怕“知道”和“做到”之间，永远隔着一条懒洋洋的河。愿我们都能把脚迈出去，真正写起来。
