# 从百万学费到AIGC：一个技术创业者的三年方向探索记

最近一两个月，我几乎没怎么更新文章。不是懒，而是创业又碰到了新的瓶颈，项目方向需要重新梳理。这三年，我经历过孤独、负债、合伙人争执、被骗，也经历了项目失败。可以说，没被这些磋磨过，都不好意思说自己是创业者。而正是这些磨难，逼着我反复思考一个核心问题：什么方向才是对的？方向一旦错了，再多的努力都可能白费。

2020年辞职出来，我带着一个技术人固有的执念：做一款APP，幻想产品跑起来就能躺赚。结果大家都能猜到——失败了。复盘后才明白，当时外因是只看到了别人的界面，没看到背后的运营体系；内因是没认清自己的优势，只觉得自己“技术行”。这个方向选错，加能力不匹配，一百多万学费换来的是产品、研发、运营、商业等全方位的成长。现在想想，这钱虽然贵，但好在没白交。

摔了跟头，我开始学着务实。我自身技术底子不错，又会写书、能讲课，写作和表达也算得上优势，于是判断自己适合做IP、走知识付费。可具体要做什么内容？卖课还是做社群？一头雾水。我知道，迷茫的根源往往是输入不够、看得太少。

为了补输入，我加了不少付费圈子，从赚钱到花爷、曹大、帅张、群响，前前后后把200多个同行的内容翻了个遍，甚至把龙哥、暴走二狗、群响刘老板等几十位大佬的公众号文章下载到本地，一篇一篇扫。也是在这个过程中，我越发觉得赚钱是真正开放、价值观正的社群，所以后来很多深度内容我都愿意首发在那里，其他社群连同步都懒得弄。

可看了那么多，反而更困惑了。感觉技术能做，自媒体能做，IP能做，社群能做，卖课也能做——什么都能干，就是不知道该选哪个。后来我去请教龙哥，他建议我在“技术+赚钱”的交叉点做差异化的定位，做一个程序员版龙哥盟。这让我眼前一亮，立刻决定干技术赚钱社群。

说实话，每个创业者心里都藏着一个社群梦：一群人高质量链接、互相支持、共享价值，甚至能找到用户和商业机会。我也一样。今年3月开始持续输出，5月28日生日当天开放付费社群，没怎么做推广，就靠信任来了200人付费。对流量大佬来说可能不值一提，但对我这个刚起步的人，算是正反馈。

然而想和做是两码事。真正下场后，两个问题让我很痛苦：第一，做社群太重运营了，要持续输出、邀嘉宾、做活动、做用户运营，除了写文章是我擅长的，其他都是短板，合伙人也解决不了；第二，“技术+赚钱”这个定位很难融合。偏赚钱，创业者只关心流量和营销，技术根本没地位；偏技术，市场又小众，我也提不起兴趣。中间形态怎么找？找不到。有一段时间我还痴迷于小红书协议引流和矩阵技术，后来跟痴海深聊才醒悟：靠技术自动生成内容搞流量，本质是在对抗平台规则，平台一更新就全废了。这简直是一条不归路。社群梦虽然美好，但和当年的APP一样，我没能理解它背后的流程和是否适合自己。

就在我埋头纠结的时候，一个投资人朋友在我朋友圈留言：“说实话和你上一个项目一样不看好。”我当场就怼了回去。但他下一句让我记到现在：“劝你还回归技术本身，要清楚自己的优势。”那时候我其实懂这个道理，只是缺一个能把优势放大的具体方向。

转机出现在AIGC爆发的时候。我早就开始研究ChatGPT，也一直关注它赚钱的可能性。后来参加了一场线下AIGC培训，把技术、应用和商业逻辑全串了起来。我突然意识到：AI就像当年的云计算。以前企业从自建IDC搬到AWS、阿里云，是一场基础设施革命；现在AI会重做各个行业的内容和业务流程。ChatGPT发布后，连老太太都知道这是未来，认知教育这个成本已经被别人付完了。所以创业者真正该关心的，不是AI有没有机会，而是怎么把它用在自己最擅长的领域、最擅长的业务上。

我最擅长什么？15年讲师经验，做过黑客讲师、Java讲师、Python讲师、运维讲师、阿里云金牌讲师；还有15年技术背景，从研发到架构师、技术总监，服务过上千万家企业，迁移数据超100PB。这就是我的竞争壁垒。于是我用ChatGPT，分别给C端和B端设计了两套课程：一套是《ChatGPT教你学编程：普通人的编程入门课》，让普通人也能跟上AI时代；另一套是《ChatGPT企业级应用与实践——提高企业10倍生产力》，帮企业用AI提效。这两个方向，一个落在我讲课的优势上，一个落在我技术咨询的优势上。

创业三年，我走了不少弯路。但换个角度，这些都是修行：专注做自己不擅长的事，才会更深刻地理解什么才是真正适合自己的。一旦方向找对，以前所有经历都可能变成复利。今年我准备重新参加云栖大会——从第一届阿里云开发者大会开始，我曾经连续七年到场，还拿过三届全球最有价值专家（MVP）。现在，我要宣告回归，重新站到技术的前沿。

最后，想对每一位创业者说：不要盲目追风口，回到起点，做能力范围内的事，用自己真正的优势去竞争，才有可能在这场孤独的修行里走得更远。
