# 搜索优化领域的订阅号做到三万关注，有何秘诀？为何现在流量称王？

这几天，我的订阅号后台显示关注人数到了三万出头。这个数字放在全网看，不算夸张。可如果告诉你，这个号是2018年1月注册、4月开写，此后一周更新一篇，五年下来从未停笔呢？![](img/5731906c4b2ee385e1e2bb45519bdadf.png)更让你意外的是，“搜索优化”这个关键词的热度近十年持续下滑，如今搜索量只剩下十年前的25%，而我的关注列表却一直在变长。![](img/3d29ca1cbf84d97b815e7035c3d1ebf8.png)

上星期，一个社群的发起人约我去做现场交流，原定聊搜索优化前景，后来题目换成了“各个网络平台的搜索优化规则”。![](img/0e5f84e3724edebcbcc322a4243511b0.png)接到题目，我心里确实没底。不同平台的搜索机制，别说一个人，就算十个人一起实战也未必覆盖得全。所以我深知自己的边界，开场先讲了两句掏心窝的话：其一，多谢发起人抬爱，嘉宾身份唯一的特权，就是能多给自己两分钟介绍时间。我这个号从零起步做到如今三万关注，自身🛰️好友也加了三万多人，引流方面多少有些心得。其二，平台数不清，我真不敢以行家自居，只想同各位聊聊。今天有搜索优化的引流分享，稍后还有高价产品的盈利分享，就缺一位做产品的嘉宾。假若能凑齐产品、流量、盈利模式，正好形成闭环。这几句话说完，现场掌声响了起来。其实台下做介绍时，我与所有人一样发怵；可一站上台，反而踏实了。我问在座的人，有多少了解搜索优化，近三十位中不到五位举手。

这次互动给我最大的感悟，是搜索优化必须讲得更接地气，要把它和引流、赚钱、具体行业绑在一起。这名字最初是为了普及搜索优化技术，偏向PC网站的排名优化。可后来用手机上网的人远超电脑用户，我就把优化范围从PC站点扩大到了各类内容社区。

那么，这账号为何能持续收获关注？我提炼了三点。

其一，取名好比播下引流的种子。总有人误会“白杨”是我的本名，其实这只是一个网名。我姓杨，“白杨”这称呼用了多年。一提白杨，大多数人会想到路边的树、课本里的散文、还有一首老歌。重要的是，我在名字后加了搜索优化的英文标识，内行扫一眼就明白我的方向，外行反而想知道，于是搜索一下。这么一来，名字自己就能招来访问量。![](img/3dfae6033138e6bbfe0a579850b41328.png)

其二，在生态中占据一个独特位置。这个说法是我从前一位学员口中听到的，那位学员专注知乎上的退休保障话题。说白了，不管你身处哪种平台，还是某个小群，只要你身上的标识足够明显，别人遇到相关需求时马上记起你，你就算占住了位。我这个订阅号在2018年注册，更早注册的号也存在，但能在搜索优化这块持续写作五年、留下四百多篇独立写作的文章，少之又少。于是，在这个小范围里，我成了一枚绕不开的坐标。![](img/cfa3456050d02e0bd27c7da82cb5d026.png)

其三，坚持背后的信念。坚持本身不难，难的是内心始终相信能成。这观点来自一次线下交流。那位朋友说，社群里布置过不少实战任务，可能拿出结果的人总是寥寥。问题不在学不会，也不在手速慢，而在信念不牢。所谓信念，就是认定自己终会做成，是将就收尾与追求极致的差别。我在关注者只有两百多的时候，就从不质疑这件事能成，硬是撑到了现在。![](img/379eaada9cfac502073743fd9590c990.png)

还有一条压箱底的经验：脸皮得厚。哪怕内容浅显，只要对一部分人有帮助，我就敢写敢发，不在乎评论区说什么。

讲到“流量即王道”这句口号，多年以前就有人提过，今天依然适用。![](img/ba3e247278c0615983ff631cf261b5d8.png)各位有没有在某视频软件上买过东西？有没有发现，那里的带货价格有时比京东还高？![](img/5105c8714c73eb5b87c7028d7584da91.png)![](img/f3bc96a45466722f5258121cb8de1e9d.png)原因不复杂：那个平台每天的活跃用户数量，高出京东一大截，更别说另一家低价电商了。手握大量用户，自然手握议价筹码。

说到底，今天不缺商品，真正欠缺的是让人信任的高品质商品；好帖子也不缺，少见的是能让人读下去的硬核内容。做生意离不开流量，做转化离不开信任，而商品、服务和干货，都是获取信任的手段。唯有摸清这套商业规律，才可能长久赚钱。
