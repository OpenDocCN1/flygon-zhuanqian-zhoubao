# 把看不见的自己搬上台面，结局才有得选
作者：龙哥

你有没有发现，自己明明想往前走，却总在同一个坑里打转？同一个类型的感情反复遇到，同一类工作卡点不断出现，同样的焦虑在每一次关键时刻准时报到。

这不是运气差，是模式在自动运行。

当那些藏在底下的信念、欲望、恐惧从未被看见，它们就悄悄当家做主。每天的你以为在自由选择，其实只是在无意识地复读旧剧本。重复，就是命运最安稳的表达方式。

荣格说得直白：当潜意识被呈现出来，命运也就被改写了。

呈现不是分析半天，而是把它从暗处拽到明处——命名它、看见它、承认它真实存在。那个一直让你拖延的完美主义，推你否定自己的童年内疚感，总让你先发制人攻击别人的不安……一旦被具象化，模式就失去了隐身衣。你才第一次拥有不跟随它的选项。

评论区里有人戳破了真相：

谦墨 : 低水平的重复，无意识的轮回。在学习区比在舒适区要好玩有趣的多!
