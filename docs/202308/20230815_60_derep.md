# 我计划重新审视自己的生活和余生

在中国，一个人站在什么样的社会坐标上，从来都不是小事。它不是个人偏好，而是整个群体潜意识里的标尺——周围所有人都会用这个坐标来给你贴标签，并据此决定对你的态度。

回过头看，过去大多数人在做出“重新打量生活、规划余生”这个决定时，往往是在竞争中已经败下阵来的时刻，带着一身的疲惫、不甘与深深的失落。

只有极少数人是个例外。他们要么是早已闯过重重难关、心中坦然“轻舟已过万重山”的人，要么是真正看透了一切、拥有由内而外的豁达与通透。
