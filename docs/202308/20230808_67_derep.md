# 淘客，今年怎么了？还有机会吗？

好久没更新了，这半年我的重心调了调，差不多每个月有十来天在外面游学或出差，加上公司一堆杂事，就一直没动笔。

前两天出差跟老朋友碰面，几乎每个人都会问：淘客这门生意还行不行？怎么圈子里一点声音都没有？是不是要凉了？

老实说，今年的淘客市场，确实比去年冷清不少。

我自己做淘客四年多，目前每月佣金大概200万。当初就是从淘客起家的，现在公司主要业务也还是淘客，算是行业一线队伍吧。

![](img/e92c19087f46d160021bb67be762d556.png)

今天就不说废话，直接聊聊我看到的几个原因。

在聊之前，先给不懂的朋友补个背景。我知道关注这里的，除了淘客圈的人，也有不少做其他互联网项目的朋友。

淘客说白了，就是替淘宝商家推广商品，成交一单拿一笔佣金。这种按结果付费的方式，就叫CPS。

那商家为什么需要淘客？因为淘宝商品想排到前面，靠的是销量和评价。刷单风险大，而淘客帮忙出的每一单都是走官方渠道，既安全又能把权重提上去。商家付出佣金，淘客赚到钱，阿里妈妈再从佣金里抽10%作为技术服务费。三方都有得赚，这个生态就成立了。

所以淘客这个模式，底层逻辑一直没毛病，问题出在外部环境变了。

我总结下来，今年市场变冷主要三个原因。

第一个，流量成本涨得太凶。

去年最火的玩法就是社群淘客：把用户拉进🛰️群，在群里发商品链接，出单就有佣金。这种群你一定见过，就像下面这张图那样：

![](img/c56fdb54c7385ab7fb1a47dc7976028f.png)

这些用户不是白来的，都是花钱投放买过来的。一个人进私域多少钱，加上建群运营的成本，再除以每天群里产出的佣金，就能算出多久回本。

拿美妆赛道来说，去年拉一个群的流量成本大概6000块左右，运营正常的话，6个月内能回本。我们公司去年投了500万做美妆，现在本已经回来了。今年呢？一个群的流量成本快奔着1.3万去了，几乎翻了一倍。做这行的都精于算账，回本周期一拉长，不确定性就多，风险大了，谁还敢大手笔投？我问过好几个去年投了几百万的同行，今年不玩的原因都很一致：流量太贵。

那为什么流量会变得这么贵？表面上是投放平台管控变严，素材难过审，钱烧不出去，成本自然走高。但这只是表层。

我跟不少在抖音做投放的头部团队聊过，真正的核心原因，其实是曝光转化率下降了。

什么叫曝光转化率？你花钱买曝光，平台给你多少人看到，其中多少人愿意进你的私域，就是这个数。去年花钱，10块钱可能有50个人看到，里面40个会加你；今年同样10块钱、同样50个人看，可大家早被这类广告磨没了耐心，可能只会有20个人愿意加。钱花得一样，带来的人却少了一半，综合成本当然高。

另外还有一个推手，我放到第二点讲。

第二个原因，资本进来了。

去年淘客太风光，盯上这块蛋糕的人自然多了。从资本的角度看，一个项目6到10个月能回本，还能快速复制放大，这在互联网圈里太难得了。所以他们开始大把撒钱进场。

资本玩法和普通玩家不一样，他们不追求慢慢赚，而是想着怎么在最短时间内把规模堆起来，用体量去撬动后期收益。为了抢流量，他们愿意给流量主开更高的价，直接把市场价格抬高了。这既推高了流量成本，也让原来安稳的行业秩序变得混乱。

第三个原因，能做的品类变少了。

去年行业能快速起量，很大程度上靠官方力推美妆，当时品类又多又好，优质单子不断。但今年美妆类目翻来覆去就那几样，淘客没得选，用户也没得挑，产出持续下滑，市场自然就没了之前的热闹劲。

![](img/93204b74b3fc56040773ce9be22370c2.png)

看到这里，你可能会想：那淘客到底还能不能做？

我的判断是，能做，但旧思路走不通了。结合我自己的团队和行业里做得好的同行，现在还有三条路是走得通的。

第一，精细化运营社群。

逻辑很简单：既然流量成本大家都一样，那就把用户的价值挖得更深。从开群、日常运营、气氛带动到群里的活动，每个环节都往细里做。我听说现在圈里做捡漏群的头部玩家，能做到半个月回流量成本，一个月回全部成本，后续用户粘性和产出还特别高。要是大家想学，我可以请他们来分享下具体怎么操盘。

第二，切入细分领域。

普通捡漏群和美妆群成本高，用户产值又不见涨，于是有人转向了母婴、猫车、狗车、撸酒这类垂直赛道。这些用户人群更精准，产值也更高。

这背后还是那个曝光转化率逻辑：用户看到新鲜内容，容易产生兴趣，同样的曝光，转化率就高，成本就降下来；反之，老是重复一种营销内容，看得多了就烦了，转化率自然掉。去年年初美妆群刚出来时，群成本比捡漏群还低1000多块，但后续的产值却是捡漏群的1.3倍左右。流量成本更低、回本更快，这才是核心优势。

可能有人会问：那现在母婴群一个要13000多，比普通捡漏群还贵，怎么回事？其实道理一样，母婴赛道从去年年底到今年被大量投放，用户早就疲劳了；而且这类群切得非常细，引流钩子基本都是纸尿裤等垂直内容，用户成本自然就高了。不过选择细分赛道的玩家，相当于避开主流红海，在自己擅长的领域深耕，我觉得这是符合大趋势的。

第三，快团团等私域赛道。

今年快团团特别火，我看其实是很多老淘客对原有市场失去信心的表现。

在快团团的玩法里，供货团长、帮卖团长，对应的就是淘客圈的招商淘客和社群淘客，本质上都是私域生意，很多基础设施和用户资源可以直接搬过去用。

我问过几个转型到快团团的淘客朋友，大家选择转型主要是为了两件事。

一是把流量握在自己手里。做淘客，流量最终都要导到淘宝去成交，自己只是个中间角色；而快团团是个免费工具，从商品发布、营销推广到成交转化全链路都能自己完成。用户从引流到下单、再到复购，全程都在自己的池子里，可以长期绑定。

二是建立自己的IP和团队品牌。就像我们因为相信李佳琦，会在他的直播间下单；因为信任小杨哥，会买他推荐的东西。这背后驱动你的不是产品，而是人。所有做CPS的人，终极梦想都是让用户因为你而买单，并且持续复购。说白了，就是最大程度开发流量价值，实现稳定长期的收入。

不过我的看法是，快团团和淘客虽然底层有共通之处，但操作手法差别挺大。淘客那套收割打法，直接搬到快团团上肯定不行，真要切入，最好找这个领域里做得比较资深的人聊一聊。
