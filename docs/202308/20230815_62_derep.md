# 做内容的人什么时候该有危机感？

做内容这件事，最怕的不是数据波动，也不是灵感枯竭，而是你突然发现自己对用户“失去感觉”了。

什么时候该拉响警报？不是流量掉的时候，而是你开始摸不透读者在想什么的时候；是你发出去一篇东西，心里完全没底、猜不到人家会怎么反应的时候；是你甚至搞不清楚这条内容到底会吸引谁点进来，连标题有没有吸引力都拿不准的时候。

说白了，危机感来自“失控”——你对受众的认知失控了，你对内容的预判失控了。这个时候，别急着追热点、堆技巧，先停下来重新搞清楚：你的用户到底要什么，他们的兴奋点在哪，痛点又在哪。

就像评论区那位朋友说的：你必须先把用户的思考路径走一遍，才有可能真正踩中他们的爽点和痛点。否则，内容做得再热闹，也只是一场自说自话。

所以，当你开始“不懂”用户的那一刻，就是最该警惕的时刻。
