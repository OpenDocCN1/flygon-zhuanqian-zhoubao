# 当人民币一直在贬值，普通中产该怎么自救？
作者：龙哥

最近一个问题被反复讨论：如果人民币的贬值趋势一直持续下去，国内的中产家庭还能做点什么来守住自己的购买力？

答案其实很清晰，大的思路只有一个：**把手里的现金流，从更快贬值的货币，换成保值甚至能增值的东西。至少是贬值速度更慢的资产，理想状态当然是能触达到全球市场的资产。**

说白了，就是不要把所有鸡蛋都放在一个篮子里。人民币的购买力在走下坡路时，资产配置的第一要务不再是追求高收益，而是先做好“抗贬值”。

具体到操作层面，就是增加对境外资产的配置配比。无论是海外指数、美元资产、黄金，还是其他具备全球定价权的资产，都是在用另一种方式对冲汇率风险。核心逻辑不是赌涨，而是降低单一货币的敞口，让财富的锚点从国内转向国际。
