# ('初创企业设立形式及股权架构全分享 ————架构没搭对，利润全交税', (2, 34))

创业第一课：搭错架构，赚得越多，交税越多！

很多人以为创业最难的是找方向、搞产品、做流量，等到真注册公司才发现，光“选哪种组织形式”这一关就能把人绕晕：个体户、合伙企业、有限责任公司、股份公司……名字听着都熟，但到底有什么不一样？税务和风险差在哪？

说实话，这个问题我几乎天天被问到。先自我介绍下，我是刘文怡，清华与常春藤MBA双硕士，全国税务领军人才，做过税务系统公务员，也在世界500强当过税务总监，这么多年帮企业节税上百亿，现在是5A级税务师事务所合伙人。关于初创企业股权架构，我在清华、北大都讲过，今天这篇内容也来自我出的书《一本书读懂税务筹划合规与风险管控（金税四期适用版）》。

接下来，我会用“开烘焙店”的故事，把单主体和多主体的选择一次讲透。不想入坑的，建议认真看完。

单干，选什么？

先看个体户。老张开了一家烘焙店，一个人当老板，面粉自己买，还请了个烘焙师小莉。结果有顾客吃坏肚子索赔，不管赔多少，得老张自己扛。在某些地方（比如深圳）可能有个人破产制度，他不需要倾家荡产，但绝大多数情况下，个体户的债务等于老板个人的债务。

税务上，小莉的工资要按“工资薪金所得”交个税，3%-45%累进；老张赚的钱要按“经营所得”交个税，5%-35%累进。个体户和个人独资企业在这块的规则基本差不多。

一句话：个体户就像结了婚的小两口，看似各花各的钱，其实就是一本账，出了事谁也躲不掉，大事来了就是整个家的事。

两个人合伙，怎么选？

如果小莉不想只拿工资，想和老张一起干，两人各出40元，这时可以考虑合伙企业和有限公司。

普通合伙企业，俩人都要承担无限连带责任。顾客索赔2000元，店里只有80元，剩下1920元，老张和小莉得一起凑。这就是“连坐”。

有限合伙企业呢？规则要求至少有一个普通合伙人（GP）承担无限责任，有限合伙人（LP）只承担有限责任。比如老张只管供面粉、不参与经营，小莉负责管店，那让小莉当GP、老张当LP。赔偿2000元时，先用合伙企业的80元，剩下1920元全由小莉出，老张不用再贴钱。

合伙企业在税务上有个特别的地方：它是“透明体”，自己不交企业所得税，利润直接分到合伙人头上——合伙人是个人的交个税，是企业的交企业所得税。这里一定要注意：就算当年赚的钱没有实际分到手里，只要企业赚了，合伙人就要按该分的份额交税，分配不分都一样。

所以合伙企业像亲兄弟，自己管自己的税，但出了事要一起扛；要是兄弟里有个能扛事的，那责任就多压在他身上。

想做有限责任，选有限公司

老张和小莉都不愿意承担无限责任，那就成立有限责任公司。公司是独立法人，股东只在自己的出资范围内负责。再遇到顾客索赔2000元，公司只有80元，法院判公司破产，股东不用拿个人财产去补，顾客只能自己认栽。

可是在税务上，公司就要被“单独算一笔账”了。盈利80元，先交25%的企业所得税，剩下60元。这笔钱留在公司里，股东不用交税；一旦分给股东，还要再交20%的个税。算下来，从80元利润到最后股东到手48元，一共交32元税，综合税负40%。看起来确实不低。

那为什么市场上还是有限公司占大多数？两个原因：第一，公司可以不分配利润，资金可以一直留在公司用于扩大再生产，股东就能合法地把个税“延后”；第二，小微企业所得税优惠很给力，年应纳税所得额300万以下的，实际税负只有5%。很多小企业根本到不了300万，所以实际负担没有想象中那么重。

有限公司就像一个养子，法律上独立自主，不替爹妈还债；但儿子赚的钱要自己花，想给爹妈花，爹妈还得再交一笔税。

发展到更大，就变股份公司

烘焙店越做越大，股东越来越多，超过50人以后，有限责任公司装不下了，只能改制为股份有限公司。股份公司股东上限是200人，股东之间大多不熟，靠资本把大家聚在一起，股份转让也更方便。所有能上市的公司，基本都是股份公司。税务处理和有限公司基本一样。

一句话：股份公司更像陌生人凑钱养鸡，谁都可以中途卖掉股份离场，谁也不替谁担责。

初创企业到底该选哪种？

没有绝对答案，但可以按场景对号入座：

如果你是单干，做的是餐饮、住宿、零售、娱乐这类生活服务行业，个体户或一人有限公司都不错，管理简单，也能享受税收优惠。

如果你有几个股东，做的是传统实体经济，比如制造、批发零售、服务，优先考虑有限公司或股份公司。既能隔离风险，又能把利润留在公司里滚动发展，还能用到小微优惠。

如果你主要是做投资，收入来源是股息红利、利息，那合伙企业更合适。个人合伙人拿到这类所得，按20%固定税率交税，省掉了中间那层企业所得税。但要注意：合伙企业里的合伙人如果本身是公司，那公司收到分红还是要交税（小微企业5%，其他25%）。

更高级的玩法：用合伙企业当持股平台

很多人的认知还停在“只设一个主体”，其实成熟的股权架构往往是多层的。比如上层放一个合伙企业，由它去持有实体公司的股权。为什么很多上市公司都这么玩？因为好处不止一个：

1. 融资更省事。国企等机构想进来，受让合伙企业份额比直接受让股权手续简单得多。
2. 可以做税收策划。把合伙企业注册在税收洼地，享受低税率或财政返还，比如海南最高能到15%。
3. 适合做高管股权激励。很多上市公司都是用合伙企业持股平台来装激励股份。
4. 能突破股东人数限制。一家有限公司可以有50个合伙企业股东，每个合伙企业再装10个合伙人，就能实现500人间接持股；而且上层合伙人怎么变，都不影响实体公司的股权结构。
5. 可以同股不同权。无论投票权还是分红权，都可以和出资比例不一致。创业公司融资时需要保持控制权，这个结构非常灵活。
6. 允许劳务出资。干活的人可以以劳务入伙，当GP掌握管理权；只出钱的人当LP，不参与经营，也享受有限责任。而有限公司和股份公司是没办法用劳务出资的。
7. IPO阶段信息披露要求更宽松。合伙企业作为股东，披露义务通常比股份公司要低。
8. 盈亏可以互抵。同一个合伙企业，当年卖掉A公司股权亏100万、卖掉B公司股权赚100万，两者相抵后可能不用交税；如果个人直接持股，就不能互抵，还得按赚的100万交税。

写在最后：创业是一场长跑，很多人只顾着往前冲，却忘了出发前把地基打牢。公司形式没选对、股权架构没搭好，后面赚得越多，可能交税越多，风险也越不可控。希望今天这篇能帮你迈对第一步。
