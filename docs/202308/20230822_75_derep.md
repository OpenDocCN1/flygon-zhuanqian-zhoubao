# 十分钟挣到100万（12万美元）？我的海外赚钱连载，写到第七回了
作者：龙哥

我是龙哥，英文工具站教练组的一员。之前在杭州线下会上，我跟龙哥表过态：以后会多分享点靠谱的出海内容，让龙哥盟这股劲儿越烧越旺。

更早的时候，我写过一篇海外赚钱案例盘点，专门讲了三个单人就能启动的项目；后来又拿出一个同样适合一个人单干、只要跑通就有机会做到月入万刀的新项目，链接放在这里：


不过还是有人不太信。那今天我就拿一个自己正在跑的项目，来给大家拆一拆。其实这个玩法一年前就曾在知识星球“丝绸之路”里反复提醒过会员，只是当时没人像我一样把它做到这个体量。

ChatGPT最火的那段时间，我在龙哥盟发过一篇独家文章，可惜内容过于敏感，最后被星球官方删掉了：


上个月那篇关于Wise推荐项目、每天躺赚一万英镑+的分享，倒是收到了不少好评。借这个机会，再次谢谢大家的点赞和认可。

这两天正好赶上高考，龙哥抛了一个问题：考上985和年入100万，到底哪个更难？我也因此写了一篇文章，算是把之前航海活动里挖下的坑填一填。

其实这个连载的起点，是我在航海时答应过各位船友要持续输出。趁着这次契机，我干脆把系列名改成了“那一年，我十分钟赚到了100万（12万美元）”，以后就用这个标题一路更下去。当然，我也会时不时点题，把二十多年来互联网圈、尤其是海外互联网圈里见过的事和抓住过的机会，慢慢讲给大家听，希望多少能带来一点启发。
