# 一个人操盘三个号，我的📕店铺30天做到56万销售额，净赚25万的实录



## 6月航海📕店铺变现，我拿下个人榜第二

赚钱的伙伴们好，我是小灰灰。入圈到现在已经四年了，过去一直都是个安静的潜水用户，分享的东西不多，所以很少有人注意到我。这次六月的续航活动中，我报名参与了📕店铺赛道，结果很幸运地登上了个人变现排行榜，拿到了第二名。

这次的成绩是我独立完成的，用的就是3个账号，周期是一个月，最终GMV累计到56万，扣掉成本后净利大概在25万左右。

赚钱里高手云集，大家的战绩都非常亮眼，我这点成绩放大家堆里确实不算突出，但对我来说是第一次真正跑通闭环拿到正向反馈。相信跟我一样，之前一直没找到感觉、没有稳定收益的朋友也会有点共鸣。希望这段复盘能给你一些参考，感谢你看到这里。
