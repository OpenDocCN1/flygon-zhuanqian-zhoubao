# 从 0 到 1 的社群，是怎么长出来的？

很多人看着龙哥盟今天的规模，总觉得这是一场精心设计、一步步推演出来的大棋局。但真实的过程，并不是这样。

2023 年 8 月的一次回答里，创始人龙哥把当年的起盘经历摊开讲了，这几条逻辑，到现在依然很扎心。

**一、就是随手开干，别给自己立高预期**

龙哥盟不是一开始就被规划成现在的模样，它是长出来的。

17 年那会儿，龙哥完全没想过它会长成今天这个体量。当时根本没什么预期，反正只是个随手的副业，和其他事一起在做。搞砸了就搞砸，被骂了就被骂，反正没人认识你。

他说，如果当时就知道后面会这么复杂，打死他也不敢开始。

你在做的副业如果听起来有点low，自己都有点不好意思，甚至觉得配不上自己，这反而是正常的起步信号。越尴尬，说明起步越早。先把自己推出去，在不自在的状态下才开始有机会。

**二、对价值的笃定，是扛住低谷的底气**

龙哥盟从一开始就是收费的，而且不便宜。但龙哥内心非常确信自己在做的是有价值的事。

他引用成甲的说法：短期靠策略，中期靠战略，长期靠做个好人。

只要你认定自己的事对别人真的有用，并且发自内心想利他，那大方向就没错。中间再多问题，扛得住。

这几年赚钱也遇到过不少困难，甚至有过想放弃的念头。能一直走下去的核心原因，是他觉得“上哪去找一个真心想带着大家赚更多钱的地方”。这份初心和好心，是压垮困难的底牌。

**三、对赚钱这件事，认知要干净**

从来没觉得收钱会有什么心理负担。

赚钱就是提供价值，提供价值就是赚钱。这件事上没有拧巴。对他来说，你付钱我交付，天经地义；你得到更多，我收更多，天经地义。

如果提供的价值不去变现，反而无法持续提供更好的价值。变现不清，是对用户最大的不负责。

所以赚钱一开始就很清晰：付费社群，价格不低。你认真做事，我多给钱，双方本分，谁也不欠谁。

**四、定位要扎在时代的缝隙里**

17 年的社会共识很分裂：想赚钱的普通人，要么去高大上的创投圈聊独角兽，要么掉进低到尘埃的网赚圈去薅羊毛、搞灰产。

龙哥盟就是卡在这个缝隙里：普通人凭方法赚 100 万、1000 万，赚钱可以有术。

定位之所以能立住，还因为个人背书足够硬。前十年他从 0 到 1 亲自做过无数项目，赚到第一个 10 万、100 万、1000 万。内容是社群的生命线，而他能做到没人分享自己上，完全能兜住。

时代的隐形共识 + 个人独特的经验资产，定位自然就成了。

**五、先在外面露脸，再谈被看见**

龙哥盟的第一个贵人是曹大。

在做社群之前，龙哥先是在写👸号，写完就发到曹大的星球去，几次下来才有了文章被转载的机会，才有了后面的故事。

这就是表达者红利。对外输出，对外分享，持续做，就会带来无数意外的好运。不主动展示，再小的机会也跟你无关。

从随手开始，到坚信价值，再到清爽赚钱、精准定位、持续曝光，这就是一个从 0 到 1 的普通人路径。没有高大上的起点，只有带着点尴尬先干起来。
