# 11 年后，👸号的公域流量闸门被悄悄挪开了
作者：龙哥

👸号迎来 11 周年纪念日之际，一条很关键的动作被低调放出：公域流量的入口正式向创作者开放了。

这个变化对写作者群体来说，意义不小。尤其是那些粉丝基数不大、订阅量一直上不去的账号，此前基本只能靠私域存量吃老本，现在终于多了一条能把内容推送到更广人群面前的通道。

说白了，就是平台开始松口，让内容有机会跳出账号围墙，去公域里被看见、被分发。这对长期在增量困境里挣扎的中小号创作者而言，无疑是一针久违的希望。
