# 把乱糟糟的数据换一个坐标系，产品和流量会自己找上门
作者：龙哥



龙哥 | 2023-08-23

市面上一向有一堆零零碎碎的资料。如果有人能把它们选出独特的观察角度，换种方法来归类、展示——做出的东西多半更容易存活，也更容易被注意。

当然，坐标定在哪里，靠的是个人眼光和分析方式。

规模大一些的项目，可以先看看下面两个参考：

- [参考一](https://mp.weixin.qq.com/s/8uvZaKhliDiLNsO3rnhHvg)
- [参考二](https://mp.weixin.qq.com/s/2B31kP8kTQCtvVpNPhhUhA)

小一点的例子，像“龙哥盟”那样，把散落各处的变现手法收进同一个池子。

再更小一号的样本：国外的 X（原 Twitter）和不少博客里，许多人都爱晒自己的营收和 MRR。要是有人把这些数字都抓下来，做成一个可随时翻阅的清单，一年收你 100 美元，就能看到超过 1000 家愿意公开真实经营数据的产品——你会掏这个钱吗？至少我会掏。
