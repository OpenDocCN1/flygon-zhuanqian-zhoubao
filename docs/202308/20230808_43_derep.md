# 40个企微群、9000+私域用户：我是怎么把社群变成自动成交系统的？

分享人：辰风  
日期：2023-07-31

各位朋友，我是辰风。目前手上有两个订阅号，粉丝量分别是6万和2.6万，私域沉淀了约40个群，总人数超过9000。副业这块每个月被动收入大概6000元，不算多，但基本不占用精力。团队做推广、群维护和项目变现，合作方负责流量承接，投入产出比约1:4。

![](img/6c816cca2f988fca0c2f0d9748f88d9d.png)

今天想聊的是企业微信群批量搭建的方法。我按三个部分展开：变现方式、群类型设计、复制与管理。

## 一、社群赚钱的几种方式

做社群一定要有明确目的，我最直接的诉求就是通过它获得收入。

最初建群只是为了给账号涨阅读量，十来个群。后来接了第一个广告，帮猫老师推广直播间，佣金60块。虽然钱少，但转发一下就能成交，让我意识到这条路径可行。

### 1. 专门做广告的副业群

我比较排斥在读者群里发广告，担心读者觉得我只想赚钱、不关心他们。于是单独建了兼职副业群，把👸号广告都投到那里。这些群的人本来就是为了找兼职，所以广告内容并不违和。

后来群数量到几十个，持续拉人、持续投放，每月靠广告费能稳定带来几千元。

![](img/36c0137823704c7f2e5f782072f4bdd4.png)

### 2. 承接CPA广告

👸号常见的收入来源之一是CPA。用户关注后回复指定关键词，或点击链接报名，就能产生收益。我账号上挂了多个项目，包括主播招募、趣职业宝、PS/原画课程等。

![](img/54b4a209c7f8021ca2caa62eebd2f42a.png)

### 3. 测试网赚项目

最近试过美团圈圈的拉新活动，这是美团针对线下门店推出的小程序，邀请新用户注册有10元奖励，做到达人级别最高可以赚1000。我通过微信群推广拉新，大概提现了500元。

![](img/2c4046d033d75485238699fc446e590b.png)

### 4. 课程类产品

我做了一个年度社群，定价不高，每月按主题分享，交付比较轻，相当于用课程广告的方式持续获得收入。

## 二、建群前先想清楚方向

群里要装什么人、为什么聚在一起，这是必须先回答的问题。如果目标是提升阅读量，就做读者群；如果精力有限，先盘活一个群，跑通后再复制。

社群和👸号一样有生命周期，拉新、维护、促活、留存是常态。群冷清就补新人，再不行就想办法唤醒老成员。通过话题互动、小活动，让群氛围更像一个互助社区，而不是文章推送工具。

我不喜欢发文章就@所有人。一般会提醒助理，没大事不要打扰。大家注意力很宝贵，不会为了看你的推文才进群。要从用户角度想：他们为什么愿意留在这里？有人想赚钱，有人想参与建设。用投稿、话题征集等小钩子，让成员参与进来，产生归属感，群才会越来越牢。

### 1. 读者群

两个订阅号各配了2个读者群，总共4个群，交给4个助理维护。主要用途有三块：节日或周年活动、引导点赞在看、拉近与读者距离，把群成员转化为真正的粉丝。

### 2. 副业群

这类群主要用来做广告曝光。比如投放博主广告需要点赞支持，就把任务丢进去，靠人群基数快速冲数据。

### 3. 助理群

助理群专门做多平台投放引流，圈子里叫“上车”。通常做法是雇几个固定助理按指标找车，而我采用的是批量模式。巅峰时期有6个助理群，每群200多人，全是负责找车的伙伴。

群公告会写清楚整套找车和投流流程，并有专人对接，对接人也能拿提成。群里持续晒单，带动大家行动，所以找车效率一直有保障。找车这件事本身很琐碎，只有把流程标准化、批量化，才能把自己解放出来。

### 人从哪里来？

这些群的人基本来自订阅号后台。我设置了关键词自动回复和菜单栏入口，用户回复某个词就能获得群二维码；还可以附带一篇推文，推文里再引导加入其他群。

菜单栏的文案一开始想走文艺路线，后来发现还是直白词汇有效。像“副业变现”“兼职赚钱”“小白赚钱”这类词，点击率和转化率都更好。

![](img/54b4a209c7f8021ca2caa62eebd2f42a.png)

## 三、如何批量复制和管理社群？

### 1. 创建群：善用活码

普通群二维码7天过期、满200人就不能扫。活码则能自动切换，永久有效，满员后自动开新群。市面上活码工具多收费，但企业微信自带的客户群活码免费，只要账号或群不违规，理论上能一直用。

![](img/f284201bd93d13df3cea0f8da6e1228b.png)

具体操作：在企业微信后台选“创建客户群”，系统会生成一个外部用户可扫码进入的群，普通企业微信群只能拉内部员工。一次可以关联5个群，每个群上限200人，也就是最多能承接1000人。今年一二月新增了一两万粉丝，我就是靠这个机制全部承接住，再慢慢转移到后端变现。

### 2. 群模板

群模板相当于一键初始化。创建群时提前设置好群名称、防骚扰规则、管理员列表，以后每次新建群都自动套用。

![](img/7b52d54ca4d7b67c32aa17ea8a25b914.png)

还可以配置入群欢迎语，有人进群后几秒或几分钟内自动回复，引导新成员查看群公告。这样哪怕没有管理员在线，也能完成接待和引导。

### 3. 成员查重

作为群主或管理员，可以检查成员是否同时出现在多个同类群中，如果不需要，一键移出群聊，操作非常方便。

![](img/dfa3c5db4f3cb3af4ca9d035b17344b9.png)

### 4. 防骚扰机制

![](img/5553998987843d375d3ae2c33954c12d.png)

企业微信的防骚扰有两个层面：一是只允许本企业员工进群，外部人员无法加入；二是对特定行为和关键词进行拦截。比如发广告、发图片、发链接、昵称带敏感词、消息超过设定字数或换行数、短时间内连续发多条消息，达到条件都会被自动踢出群。

![](img/793f558431bc8593ef6abc73c6f890f7.png)

黑名单功能更彻底：如果某个用户被拉黑，系统会把他从所有群里移除，并且以后任何场景都无法再加入你创建的群。

这里有几个容易踩的坑：

第一，账号如果有违规记录，进入开了防骚扰规则的企业微信群，很容易被永久封号，我之前一个号就因此没保住。

第二，企业微信一旦违规，所有群二维码都会失效。怎么判断违规？群里发消息出现红色感叹号，或者你发消息时出现红色感叹号，都是信号。企业微信不会主动通知，封禁时长也没有固定标准，可能1天、3天或一周，属于阶梯式处罚，可以申诉。

第三，管理员只能从企业微信成员里选，个人微信用户不能设为管理员。另外，用个人微信转成企业微信群的话，属于外部群，上面说的钩子、防骚扰等功能都不适用。

### 5. 统一管理和职责分工

群命名一定要规范，最好统一前缀，一看就知道是哪个项目、谁负责、目标是什么。常用群置顶，预先配置快捷回复和群模板。

![](img/87bfb02c63708817926b642e69135826.png)![](img/7a85b95147a35a282fa20fc16f7a5acb.png)

我习惯给群统一命名，整齐清晰，找人找群都很方便。一个人管几十个群不现实，所以要配助理。我的团队主要做三件事：一是读者群日常促活，带动聊天和活动；二是清退广告党，及时警告违规行为；三是做外部对接，比如找车投流。

企业微信还支持权限继承。如果员工离职或岗位变动，管理员可以把他的群和客户列表一键转给其他人，账号资产不会丢。

对我来说，社群已经变成一个半自动成交系统。用户从👸号后台进来，扫码进群，机器人自动接待，助理负责维护，再通过活动和项目完成转化。整套流程跑下来，不需要每天盯屏，收入也在稳定发生。
