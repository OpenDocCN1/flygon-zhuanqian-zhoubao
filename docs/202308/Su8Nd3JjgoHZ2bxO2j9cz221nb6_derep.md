# 八年地摊卖花实战复盘，七夕最后冲刺窗口别错过



# 先交个底

叫我小天，天哥都可以。91年冬月生，今年三十二。干用户运营、私域七八年，现在在做除醛的一线市场，未来打算和朋友一起单干。地摊是2020年疫情期间被推上风口起玩的，断断续续到现在也有八年左右。

我是北京长大的四川广安人。2015年毕业回成都，第一站是青旅义工，零收入。七夕那年和高中同学凑了三个人去卖玫瑰，是我在成都的第一份现金收入，数额不大，坑踩了不少。

第一次靠摆摊攒到房租，后来才稳定下来找工作。大概就这样在情人节七夕之类节点出来摆摆，断续八年。手感好就上阵，今天把这些东西摊开讲，没有绝对标准，参考就好。

2016年2月14，第二次和我姐搭伙，纯利干到了2800+，营业额记不清。那次是我姐交不起房租拉我，我嘴笨她销售一流。刚卖完回公司上班，第二天公司就解散了，运营总监不好意思提前说，15号到岗才知道大家都领赔偿散伙。现在那些同事还是朋友。

唯一一次亏本是21年情人节，后续再补一篇失败复盘。失败是成功他爹，能避就避。

# 卖玫瑰之前，先掂量自己

## 起步要满足的三件事

1、脸皮够厚，能吆喝，执行力够，说干就干。
2、地段要对，客群消费力匹配。优先选超大商圈，比如长沙坡子街、成都春熙路、重庆解放碑这类。
3、能扛住苦，熬夜、脏累都不怕。

脸皮薄真的不适合摆摊。我常碰到同行，花没卖两朵就走了。你不认识路人，大胆喊就对了。

以成都举例，白天我扎春熙路、太古里核心商圈，夜里换到酒吧酒店周边，和TT一起卖。
吃苦这块必须说。我基本是1-2人作战，去年合伙三人，两女的。提前打了招呼会很累，她们没真get到。最后晚上九点就要求回家，还要分钱，最后一个删好友一个不联络。合伙要提前把分工、分成说死，找能扛事、会推销的搭子。

做买卖别找亲戚或太熟的朋友，容易伤感情。规则先谈清。

说回物料，卖花缺啥：

## 必备物料清单

1、手推车，越宽越大越好，露营车更合适，装得多赚得多。
2、水桶，用来养花保鲜，损耗控制全靠它。
3、固定水桶的锁紧绳。
4、剪刀、小胶带、闪光小灯，夜里灯一闪单价就起来了，还有补光的摆摊灯。
5、去刺工具、单支包装袋、花束包装纸、绑带、包装盒。
6、折叠小凳，七夕是马拉松，不能一直站着。

# 七夕实战核心

玫瑰的销售窗口很宽，214、女神节、三八、520、七夕、教师节、光棍节、圣诞、毕业季都能卖。但真正能拉高价的只有214、520、七夕、毕业季。打好了一天净利润两三千没问题。

2023年214我在春熙路带了两个新人，人均落到500+。那年大环境差，消费降级。以前一天不到一千算失败，今年更难。现场很多情侣不买花了，说不如吃喝实在。同行也多了不少。现阶段要靠差异化提客单。

## 怎么挑花

货源是命门。节前两周就要去踩点，实在来不及立刻去问价，先做预算。

新手不要贪。我吃过亏，一次拿800朵，拆刺包装就耗掉一下午，错过了黄金销售时段。

选花思路：
1、去当地花卉批发市场多打听，问摆摊老手和花店。成都首选三圣乡。找到性价比的渠道，利润才有空间。
2、别只认便宜。七夕在夏天，花容易蔫。买回来放桶里看着饱满，当天一开就软，卖相全毁。
3、挑花苞大的品种，云南卡罗拉很稳。可分家拿货，600朵分三家各200朵，互相兜底。
4、品类以红玫瑰为主，占比80-90%，配一点蓝妖姬、粉白做差异。永生花新手别碰，我曾亏过几千。永生花不适合街头，携带麻烦，建议朋友圈预售。

永生花进价低，大牌卖贵，自己也能玩，但街边不建议。

玫瑰可配满天星、情人草做花束，客单价直接拉升。单支卖赚不到钱，花束礼盒才是赚钱点。

进价参考成都：一般1.5-2元，旺季能到1元左右。选卡罗拉或AB级大苞，后期能卖10元一支。价格受季节和紧俏度影响，我最高买到过3-4元一支。

蓝妖姬进价约4元，可卖20-30元，话术送给身边最特别的那个人。
永生花现货几十到百元，可卖298-900。

💥新手建议：先拿50-100朵练手，双人可试200-300朵。

## 前期筹备

货源锁定后，提前三天问清取货价并确认。一般这种价必须提前三天问才准。

拿到手后放家里水养，7天内都能保持。最好放卫生间这种潮湿环境。
回来基本带刺，我自己剃，3个人六七百朵约两小时，会有点小伤。只做去刺，然后单支用包装纸包好插水里养。千万别提前打开花苞，打开就易蔫。卖时再开，自然绽放。

这些前置工作别带到现场做，会浪费赚钱时间。

## 实战操作

### 卖花时段

七夕举例：前一天晚上8-9点先去商圈酒吧放一波。
第二天早上6-7点到商圈抢位。
晚上转酒吧街，喝醉的人好说，嘴甜点随手掏。
最晚到后半夜4点清货，酒吧还有人。

可搭配小熊和TT一起卖。

新手体力有限，可按自己情况压缩时段。别贪，我以前拿太多累成狗利润没涨。

### 现场执行

600-700朵至少需要2-3辆手推车。最好有面包车，公交地铁打车都未必装下。花少自己想办法。

小技巧：找门店寄存一部分，卖完再去拿。酒店前台说软话，滑板店我也放过，送几枝花就成。

![](img/06ad9d4f77b42bcede3abedaf0b3dd22.png)

滑板店我放过十几年，送店员店长几枝就行。

![](img/bf1ce494ef937a2edaf885cd2e118e3e.png)

会包花束很吃香。我包的29朵报299都有人收，简易手法5-10分钟一束。成本50，净赚249。

包装纸用黑红，简约高级。扎带备足。

![](img/f9474bcb28279fed241ca1cdfacaf8b1.png)

盒装花束比散装更简单，像拼盘一样，一盒200起卖，按朵数定价。

![](img/f63395ee8f3e18380364d578d958e03d.png)

花语很关键。我自己做的“花与她”花语，介绍时有代入感。主推29朵长长久久、33朵三生三世。现包20-30分钟，留电话取货，一人包一人卖。

单支10元，买几支可适当让价，目的早卖完。蓝妖姬20-30元，成本4元，对手降价你也能灵活。

### 销售技巧

1、选人流大的点站住，开喊：爱她就送朵玫瑰，来支玫瑰祝情人节快乐。
2、有条件做个牌子写明价格，淘宝70左右的发光灯牌白天晚上都好用，显得有档次。
![](img/b44b160a897ff2412d3a5b0e58ae6901.png)
3、顾客买单支就推11朵一生一世、29朵长长久久、33朵三生三世。觉得多就说3朵我爱你、7朵一周每天爱你，都是话术，适当优惠也行。
4、男生买就说29朵女生一定懂心意。女生在旁边就夸她漂亮，女生常说不要买，你就说买了她会开心。
5、夜里开露营灯和闪光灯围住花，摊位最显眼。
6、空闲时提前备好7朵、11朵、29朵现货，提升成交效率。
7、备少量蓝妖姬10支，夜灯下好看，讲个故事卖。
8、酒吧街别久站，认识保安酒保合作塞进去卖，外面也好卖。夸恩爱天长地久。
9、没人流或生意差，立刻换位或加强吆喝，主动改变。

### 躲城管

穿蓝的就是城管，S形游走。
真被逮别硬刚，递烟或请喝水赶紧撤。商圈城管多，忍不了就别干。酒吧保安也严，认识酒保能合作。

### 业绩测算

理想：500朵玫瑰+100朵蓝妖姬
成本：500x2.5+100x4=1650，杂项350，总成本约2000
销售额：500x10=5000，100x20=2000，共7000
考虑让价损耗按6000算，净利4000，两人分很舒服。

💥这是理想值，按自身能力来。

# 王炸Tips

1、推车怎么来：大型超市租、闲鱼买、借。露营车闲鱼找大尺寸。
2、低成本回血：卖完后用低价收同行卖不掉的花。他们没推车没凳子累了，帮你去刺包装好的就能便宜拿。损招但有效。
3、尾货处理：没卖完找小区群、闲置群成本价清，回血为主。

# 总结

大前提：
1、脸皮厚会吆喝，执行力强。
2、选超级大商圈，地段匹配。
3、能吃苦能坚持。

物料：
手推车/露营车、水桶、锁紧绳、剪刀胶带闪光小灯摆摊灯、去刺工具包装袋包装纸绑带包装盒、折叠小凳。

实战：
选花→前期准备去刺包装→实操：时段选择、现场执行、销售技巧、躲城管、业绩测算→低价收花→尾货处理。
