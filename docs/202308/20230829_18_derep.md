# AI 绘画社群从设计到发售，7 天累计营收 7 万+的复盘

昨天看到一份相当硬核的AI绘画社群复盘：从零设计到正式开售，前后只有7天时间，营收却做到了7万多。整个过程算不上顺风顺水，但很多操作思路特别值得参考。

主角叫“沧海大表哥”。曾经在一家电商公司做设计经理，如今辞职一年，转型为设计师提供个人IP和副业/创业方向的陪跑，运营着一个叫「自由人」的社群。

他当初为什么离开公司？说起来也是踩中了风口。2021年，他靠做抖音特效道具，短短3个月赚了上百万元。这次经历让他意识到，与其待在原有轨道里，不如主动探索更大的可能性。

创业初期，他同样不轻松：没有资源，没有圈子，方向也不明确。但他有个很实用的人生算法——“先把包扔过墙，再学怎么🪜”：起步时不用太精致，办法总会在行动中长出来。


评论区里有两个问题还挺有代表性的。有人问：用Midjourney是不是也得“魔法”？用户会不会因此付费犹豫？他的回答很坦白：确实需要魔法，但目前没有人因为这原因停止付费。还有人问：定价这么高，不怕卖不动吗？他的策略是“先找到对的人，选择客户永远比服务客户更重要”。

这份复盘最打动我的地方，倒不一定是7天7万这个数字，而是那种“先行动再调整”的执行力。如果你也正想在AI绘画或知识付费赛道尝试，可以好好读一读。
