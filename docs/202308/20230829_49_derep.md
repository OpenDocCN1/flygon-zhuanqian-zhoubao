# 出版江湖正在被彻底重写

最近和一位摸爬滚打多年的出版老炮儿聊了一顿饭，他手里拿着最新的数据，聊起图书市场这几年发生的动向，听着像玄幻小说。

第一，真正吃肉的已经不是新书了。截止到今年7月，靠新书贡献的营收只剩5%左右，剩下95%全靠老书续命。过去新书还能占总销量两成，现在基本发出来就凉。一本没被市场挑中的新书，死亡速度快得惊人。

第二，中间地带的书正在被挤死。尤其是月销5000到2万册这个区间，过去是出版社的主力产区。现在自媒体时代的规则是极端化，要么爆，要么归零。做不上爆款的书，就没活路。没有爆款傍身的出版社，以后日子会越来越难，这就是另一种赢者通吃。

第三，书的生命周期被压缩到极限。以前一本书能舒舒服服卖两年三年，第一年卖一万册，第二年还能卖八千，慢慢衰减。现在是悬崖式下跌，第一年一万，第二年可能直接跌到三千，第三年不到一千。没有持续的声量推着，火得再快也会掉下去。

第四，销售的主战场已经换人了。抖音、📕、视频号这些自媒体渠道，整体盘子已经全面超过当当、京东、淘宝。十年前当当是新华书店的噩梦，现在自媒体成了当当的噩梦。渠道的王冠换了好几茬。

第五，达人开始明码标价自己的影响力。书卖得动，他才愿意播；要出版社让他从零带货，人家开口就是高额广告费，根本不按销量分成。流量为王的时代，达人比出版社更懂自己的价值。

第六，推书成了马拉松式的热点追逐。想让销量持续，必须不断把书和新的热点话题绑在一起，持续制造曝光。曝光和销量现在是焊死的，没有前者后者不来。出版的体力活比以前重太多。

第七，验证过的话题可以反复收割。同一主题，只要能火，就要拆给不同达人去做。以前火的，以后依然会火。有意思的是，一本抖音上靠一个话题卖出300多本的书，换个人操作又能卖600多本。原创性已经不重要了，重要的是谁抢到曝光。

第八，选题的门槛被拉满。现在想赌一把，必须三件套齐全：内容过硬+作者自带流量+话题够热。单靠内容好已经不够了。酒香不怕巷子深的时代结束了，没点流量加持，普通人更难出头。

第九，传统强势品类也在掉队。管理类、职场类图书整体下滑明显。像《人力资源》系列这种过去的渠道常青树，今年销量也跌了三成。大环境变了，读者觉得买书也涨不了薪，还不如躺平。

第十，国外的经典畅销书在国内自媒体环境里失声了。德鲁克、韦尔奇这类名字，没有人持续推，读者根本看不到。老炮儿说个画面感很强的比喻：整个抖音生态，最多只能养活一万本月销过千的书，其他的都被挤到台下。注意力经济下，集中度极高。

第十一，自媒体渠道的红利期在收窄。去年自媒体带书的销售额暴涨200%，今年前7个月只涨了40%，增速明显放缓。未来会进入一个新均衡期。目前头部三大阵地是抖音、视频号、📕。

第十二，儿童书和绘本市场在跟着人口走。生育率下降的后遗症来了，幼儿园都招不满孩子，绘本自然卖不动。没有绝对的爆款能力，这个赛道普通玩家别轻易进去。

第十三，自媒体带货的利润很薄。一件包邮+高额佣金，出版社很容易做成赔本赚吆喝。所以人民邮电、机械工业、中信这些大社都在自建直播团队自己带货，绕开中间环节，把成本压下来。

整个图书市场正在从内容驱动转向流量驱动，从长尾时代回到爆款时代。适应不了新规则的，都会被快速淘汰。
