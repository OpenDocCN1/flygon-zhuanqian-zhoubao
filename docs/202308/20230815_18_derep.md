# 创业开公司，先把“壳”搭对：设立形式与股权架构的避坑指南



## 创业第一关：公司怎么设，钱才不会白交

在上一篇《从 18 线贫困县学生逆袭成为年薪百万的清华卷王 ———— 人人都能学的卷王“大法“》发出后，得到了赚钱小伙伴们不少认可。在和闫君的沟通里，我们决定把更实用的专业干货带给大家，于是有了今天这篇关于初创企业搭建的分享。

大家好，我是龙哥。拥有清华大学与美国常春藤联盟院校的工商管理双硕士学位，是全国税务高端人才。长期受邀为中税协、东奥教育、四川、西藏、宁波、安徽等地税务局，以及四川师范大学、西南交通大学、西南财经大学等高校授课，亦面向众多世界 500 强企业内训。履历上既有税务机关征管稽查的经历，也有在大型跨国集团担任税务总监、累计实现节税超百亿元的企业实战经验。如今任职于全国前四的 5A 级税务师事务所合伙人。

赚钱的各位创始人，启动或扩张时几乎都会碰到“建公司”这个决定。有限公司、合伙企业、个体工商户、股份有限公司，这几种常见形态在税负、责任、融资和退出上的差异很大，稍有疏忽就会出现架构搭建错位、利润被税吃掉的情况。

这篇内容脱胎于我在清华、北大课堂上讲解的初创企业股权架构体系，也参考了人民邮电出版社出版的《一本书读懂税务 税务筹划合规与风险管控（金税四期适用版）》的相关章节。目的就是帮大家跨过创业起步最容易踩坑的第一步。

全文思路分为两个维度：
其一，创业初期只设立一个经营主体的情况下，如何在不同组织形式间做出最优取舍；
其二，业务发展到需要多主体协同运作时，如何设计合理的持股与资金流转。

为了让抽象的税务规则变得好懂，我用了一个贯穿始终的蛋糕店经营案例，并为每种情形配了几首形象的打油诗做总结。力求把专业讲明白、讲清楚，让财务专业人士也能深挖，也让创业新手不至于迷路。
