# 牛杂，牛肉与牛蛙，做餐饮的话你怎么选？
作者：龙哥

想进餐饮行业，牛杂、牛肉、牛蛙三条赛道，你更看好哪一条？

这个问题没有标准答案，但可以拆开算一笔账。

先说牛杂。乍一看，做牛杂的人确实不多，竞争压力小，可为什么这个品类始终没跑出头部大牌？核心障碍有两个。第一，大众并没有把牛杂当日常菜的消费习惯，牛杂煲的传统主要存在于广东，尤其是广州，离开这座城市，愿意买单的顾客就大幅缩水。第二，牛杂在顾客心里属于“便宜货”，可它的实际进货价高得离谱，甚至超过牛肉，成本不占优势，自然鲜有人开大店去做。

把目光转向牛肉和鸡肉，这两样是最成熟的肉类品类，供应链稳定，麦当劳、肯德基的菜单基本就是靠牛肉和鸡肉撑起来的。假如做牛肉，最好选用进口牛肉，别碰国内的草原牛或贵州黄牛，因为进口货源的价格比国产低不少。

不过我更倾向于鸡肉。顾客会本能地觉得鸡肉比牛肉便宜，心理价位大概只有牛肉的一半，可牛肉的采购成本实际是鸡肉的三倍以上。这样一来，做鸡肉的毛利空间就要大得多。看看国内那些大型连锁餐饮，几乎都是做鸡起家的：华莱士、正新鸡排，还有门店数已经超过9500家的肯德基，都在靠鸡打天下。

牛蛙则是另一类产品。顾客认为牛蛙价值不低，愿意给出较高的价格预期，但它的真实成本并不高，因此毛利很可观。问题在于，牛蛙的供应链远不及鸡肉牛肉成熟，目前依然比较混乱，标准化程度不够，所以大型连锁品牌通常不敢轻易碰牛蛙。

说到底，餐饮选择的本质不是看食材本身贵不贵，而是找那种“顾客觉得值钱，但实际成本不高”的品类。

评论区里也有同行补充：鸡肉和鱼的供应链最稳定，毛利率都不错，只是鱼的毛利额偏低；不少人担心牛蛙有寄生虫，养殖牛蛙的隐患其实更多是药物残留；还有人注意到蛙店如今开遍大街小巷，但很多养蛙人自己反而不吃。
