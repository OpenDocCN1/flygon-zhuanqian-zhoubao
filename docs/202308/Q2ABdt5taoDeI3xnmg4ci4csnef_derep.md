# 经历过上次的续航，开发了一个自动加微信的RPA

上次活动结束后，我顺手把“自动加微信”的RPA流程完整跑通了。平时参与航海活动，作为老志愿者，好友列表里总是塞满新圈友，一个个手动点添加，既低效又容易分不清谁已经申请过。那时候我就想，要是能把这种重复操作甩给机器，我就能把心思放在更重要的事情上，也能让同船的伙伴获得更好的体验。

先把结论放在前面：RPA自动加好友的时候，只要让操作节奏贴近真人，基本不会触发封号。保险起见，一轮不超过5到10个好友，加完以后至少隔半小时再做下一轮。为了防手误和忘记停止，我还在流程里加了自动保护，加满第10人就会自己停下来。

下面进入正题。

**一、开始前需要准备的**
1. 安装影刀客户端：https://www.winrobot360.com/share/activity?inviteUserUuid=118838783572787201
2. 下载好要用的“自动+V”表格。
3. 获取自动加微信的机器人应用：https://api.winrobot360.com/redirect/robot/share?inviteKey=6a5435f00951c66a （访问密码：scys）
4. 打开“自动+V.xlsx”，在Sheet1里维护好需要添加的好友信息。

**二、怎么跑起来**
1. 把微信和“自动+V.xlsx”表格都打开。
2. 在影刀「已获取应用」里面找到「自动+v」机器人，按下「运行应用」。
![](img/a1e20b74a0a11cb080de5ae04bdbf62d.png)
3. 弹窗出现后，选中你下载好的“自动+V”表格。
![](img/10b1239339ce665694606c662c0c7439.png)
4. 之后耐心等它执行，期间键鼠都不要碰。

我设了第10人自动停止，所以哪怕你临时走开，也不用担心机器失控。过半小时再重新启动一轮就行。

**三、再配一个“志愿者数据抓取”，体验直接拉满**
1. 获取配套应用：https://api.winrobot360.com/redirect/robot/share?inviteKey=bbf52b823e344c69 （访问密码：scys123）
2. 给浏览器安装自动化插件：可以从头像进入，顺着「工具」找到「自动化插件」；也可以新建/打开应用后，点右上角三个点，再选择「自动化插件」安装。
![](img/b018fb3c0b93f7ee9859f079334969fb.png)
3. 在影刀「已获取应用」列表找到「志愿者数据抓取」机器人，点击运行。
![](img/8111fdca633c07f6136fe1af1c1b64ab.png)
4. 用谷歌浏览器打开志愿者后台网址。
![](img/2ec9db881dfed5fd0b03ffde69196d2b.png)
![](img/ea2e32fd6f57b161aedbbe4b3b67bfdc.png)
5. 等脚本跑完，表格就会自动出现在你指定的文件夹里。

其实RPA的潜能远不止“自动加好友”。凡是重复、有逻辑的操作，统统可以交给它。比如微商统一给客户发营销消息，快手/视频号定时发视频，📕店铺批量定时发布笔记，自媒体人批量群发文章；甚至还能抓取对标账号数据、下载网站上的图片和视频。把力气省下来，去做更值钱的事，这才是我专注RPA的原因。
