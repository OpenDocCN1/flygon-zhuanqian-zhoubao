# ('一旦你寻找胡萝卜问题，你会发现它们无处不在', (2, 23))

满世界都是“胡萝卜问题”，只要你愿意看

最近看到一个特别有意思的概念：胡萝卜问题。

什么意思？你去观察那些成功人士的经验分享，会发现一个规律：凡是成功路径没法坦白说的人，几乎都会把自己的本事抬出来当挡箭牌。真实原因可能是运气、资源、关系，甚至是一些不可说的操作，但他们讲给你的，永远是那套“我很努力、我很聪明、我选对了”。

这个故事，就是一根胡萝卜。

它看起来很有营养，实际上却吃不到。它挂在你前面，让你拼命往前跑，以为跑到头就能复制同样的成功。可惜，你越追越发现，你和它之间永远隔着一段距离；你搭进去的是时间、金钱和心气，运气好点白忙一场，运气差些直接被带进沟里。

更绝的是，一旦你开始用“胡萝卜问题”的视角去看周围，你会发现自己被无数根胡萝卜包围着：教你赚钱的、晒收益的、大讲认知的、分享逆袭经历的……你根本分不清哪句是真话，哪句是借口。

![](img/c03b00318bd58ce3348a9bf6d7eadfbe.png)

有读者在那条内容下留言：扎心，想起某大厂的操作。也有人直说：太喜欢这个说法了。我想，喜欢它的人，大概是受够了那些体面的说辞。下一次再听到谁的成功故事，不妨先问一句：这真的是他成功的原因吗？还是又一根胡萝卜？

多留个心眼，总没坏处。
