# 聊聊刀郎的新歌《罗刹海市》这个事件
作者：龙哥

最近刀郎的《罗刹海市》刷屏，我和老范专门录了期播客聊了聊这件事。下面是我们的一些观察，整理出来分享给你。

先说年龄圈层。这事儿在70、80后中间讨论得热火朝天，但90后、00后基本无感。说到底，刀郎的黄金年代属于我们这代人，年轻人不认识他，自然也不关心。我们俩都是70后，选这个题本身就带着这代人的视角。

有人问我这歌到底好不好听。说实话，我不是资深乐迷，而且人的音乐口味通常在25岁前就定型了。我从小在山东农村听太爷爷唱民间小调长大，审美底子就那样，但我觉得刀郎这歌确实不错。

《罗刹海市》的故事原型出自《聊斋志异》，和《西游记》《官场现形记》这类古代通俗作品一脉相承。讽刺、反抗这类主题，古今通吃，放到今天照样击中人心。

这首歌能爆，完全可以用《引爆点》里的三法则解释：个别人物法则——刀郎、那英、汪峰都是自带流量的话题中心；附着力法则——复仇戏码、围观心态、拆字游戏，每样都让人想转发；环境威力法则——舆论风向加平台算法，直接把热度推上了天。

有家自媒体总结过11种爆款内容结构，刀郎这次是典型的W型：崛起、被打压、复出、名动江湖。这跟英雄电影的经典套路一模一样，也契合《千面英雄》里说的“启程-启蒙-考验-归来”的成长叙事。

中国人最吃的英雄人设，无非两种：扫地僧和孙悟空。前者是佛家式的，平时深藏不露，关键时刻一鸣惊人；后者是道家式的，自由自在，不把权威放眼里。当然儒家英雄如乔峰也受人敬佩，但不够娱乐化。而刀郎在大众眼里，恰好是扫地僧加孙悟空的合体。

那几个当年批评他的音乐人，为什么现在被群嘲？一是确实说过些不妥的话，但更关键的是，这些年他们没拿出过硬的作品。就像诺基亚要是还像当年那样碾压苹果，今天没人嘲讽它。巴菲特看不上马斯克，没人骂巴菲特；可要是换成许家印这么说，早就被喷成筛子了。

还有一个背景：当年的乐坛偏精英化，现在被抖音这些平台彻底大众化了。过去遍地精英，你俗气就会被笑；如今遍地通俗，你反而显得有点精英范儿——参照物变了而已。

视频和播客的兴起，看起来是技术推动，本质上却是一种文化返祖。因为人类历史上识字、爱读书的人从来不多，文字出现的时间也短，早期内容全是靠嘴传的。

有人夸《罗刹海市》词曲俱佳，但“好”的标准是分阶层的。这首歌妙就妙在“有文化”得恰到好处——既不像早年那么直白，又没深到普通人看不懂，正好击中最大人群的审美公约数。拆字是很多人都爱玩的游戏，但“马户”这种拆法属于入门级。你看《西游记》里孙悟空拜师的地方，“灵台方寸山，斜月三星洞”才是更深一层的拆字——“灵台”就是古人说的心，只有方寸大；“心”字本身就像一弯斜月配三颗星。作者想说的是，神仙就在自己心里，不必外求。但这种内涵今人大多看不懂，自然流传不起来。

平面设计里放几个英文就显洋气，这首歌用了些古文元素就显得有文化——这是形式带来的效果。形式很多时候直接决定内容，《理解媒介》里那句“媒介即信息”，说的也是这个道理。

民歌曲调、聊斋故事、古文文风、复仇叙事，这几样组合起来就是创新。创意的本质，本来就是旧元素的新组合。

其实我没从这首歌里读出多少“复仇”的意思，内容基本忠实于《罗刹海市》原著。但文艺作品被过度解读是常态——大家顺着自己的理解去发挥，早就偏离了作者本意。

可人民群众就爱看这种戏码，而且人天生同情弱者，懒得去细究当事人谁对谁错。比如李子柒和资本方闹掰，96%的网友想都不想就站李子柒，资本在大家心中永远是反派。刀郎这事儿，逻辑一模一样。

话说回来，传统音乐人对词曲有自己的标准，这很正常。作为大赛评委，坚持自己的判断也没错——如果流行就能评上金曲，那评委直接撤了，按销量发奖不就行了？

哪个行业没有鄙视链？当年主流乐坛看不上刀郎，就跟我在国际广告公司时看不上本土同行作品一样。那时候是真那么想，只是如今我不再这么看了。
