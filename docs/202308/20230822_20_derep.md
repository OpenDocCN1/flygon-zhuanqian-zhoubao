# 创业三年，从 App 到社群再到 AIGC，我到底想明白了什么？

作者：乔帮主  
发布时间：2023-08-16

最近一个月左右，我几乎没怎么写新文章。社群里最多转发一下旧内容，👸号也像按了暂停键。

状态低迷的原因有两个：一是业务推进到这个阶段，老模式有些卡壳，我需要重新判断手上项目是不是还值得继续；二是在酝酿一次新方向的转型，新东西没成型之前，我不想分心写稿。

但分享始终是建立连接最好的方式。今天这篇大概五千字，把这三年做过的项目、踩过的坑、以及对“项目方向”的思考都串起来聊一聊，希望给还在摸索期的朋友一点参考。

创业是什么？我的体会是，它就是一场漫长的自我修炼。如果你没有体验过一个人扛所有事的孤独，没尝过负债的滋味，没被合伙人伤过，没被所谓的朋友骗过，也没亲自把一个项目送到终点，那大概还算不上真正的创业者。

这条路上，问题永远层出不穷，它们一遍遍压向你的心理防线和意志底线。你唯一能做的，就是像拆线头一样，把每个难题都一点一点解开。只有持续解决掉这些麻烦，你才可能在创业圈里站稳；否则一次重击，就可能让你彻底出局。

解决问题的能力，当然是创业者最基础的素质。但比它更关键的，是项目方向本身。方向一旦错了，后面所有努力都像往错的地图上填色，画得越用力，离目标越远。这是我这三年最深的感触。

我们经历的挫折和失败，说到底不是用来折磨人的，而是用来提醒人的：现在这条路到底对不对？要不要换一条？这种反复审视，有时比能力提升更有价值。
