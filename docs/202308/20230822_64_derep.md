# 一人企业方法论

一本很有意思的实验性小书，作者是龙哥的收藏夹，于 2023-08-15 发布，目前收获 14 个赞。

这本书的诞生方式本身就很「一人企业」：人类负责搭建骨架，AI 来填补血肉。

具体来说，书中的思维导图和整体目录都是由作者亲手完成，而每一章的具体内容则交给了 AI 来撰写。先有人类的思路框架，再让 AI 高效填充，形成了一套人机协作的创作闭环。
