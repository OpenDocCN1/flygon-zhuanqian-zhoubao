# 分享微头条 AI 写作小副业项目，用指令写出 10W+爆款微头条

AI指令就能写微头条？起号2天出10W+爆款，这个副业玩法太省心

最近AI风头正劲，我们团队也在用。目前主攻百家号和今日头条，只要认真操作，这两个平台出10W+爆文很常见。相比之下，我个人更推荐微头条：起号快、单价不差，当个副业完全够看。今天就把今日头条旗下微头条的AI写作玩法，一次性讲清楚。

先说说微头条是什么。它是今日头条里的一个动态功能，形态和🧣、🐧空间差不多，也和百家号动态类似，能发2000字以内的短文，说白了就是平台自带的轻内容发布入口。头条创作者粉丝数满100，就能开启微头条收益。

再说写作这块。以前微头条都是人工写，问题很明显：枯燥、重复，很容易写着写着就没了热情。除非已经赚到钱，否则很多人倒在了起号期的执行力上，项目也就黄了。

现在的玩法则完全不同。把写作交给AI，基本属于“傻瓜式”操作：只要给AI设定好指令，它就能源源不断产出符合大众口味的短文。整个流程就是和AI工具深度绑定，操作门槛大幅下降。而且这套逻辑不只适用于微头条，放到其他自媒体平台一样能跑，感兴趣可以自己测一测。
