# ChatGPT 基础+场景应用
作者：龙哥

最近看到一份很实在的干货，来自姬小光老师，主题是ChatGPT的入门与场景运用，整篇内容有八千多字。圈子里讲垂直领域实操的人很多，但专门为业务人员写覆盖这么全的科普还真不多。他在公司内部已经讲过五次，还顺手落地了两个真实业务场景的工具。

说到AIGC落地，他并没有一味吹捧。他的实际感受是，一旦进入具体的工作流程，GPT能覆盖的部分其实很少，不少环节靠工具根本接不住。再谈提效，由于学习成本、流程调整这些因素，真实的效率提升不一定明显。不过，倒是能帮大家多挤出一点摸鱼时间，也算个意外收获。AIGC看起来什么都能干一点，但真要用起来，细节上的坑也不少。这些都是他个人在实际项目里的体会，不是泛泛而谈。
