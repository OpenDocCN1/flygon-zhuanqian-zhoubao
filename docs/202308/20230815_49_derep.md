# 用极简粗暴的方式在 B 站收割创业粉
作者：龙哥

最近在实操一个非常直接的 B 站引流打法，专门用来吸高质量创业人群。

为什么叫“暴力引流”？因为整套玩法就是反精细化。

视频内容做得极粗暴，基本就是一分钟左右的口播；引流动作也极粗暴，不玩花活。适合想快速铺量的人上号。

我是龙哥，7 月份开始测试这套方法，效果很稳定。具体的脚本框架、选题库和投放细节我整理在飞书文档里了，想直接照抄复现的可以自己去看。


评论区里大家最关心的还是后端的转化问题。

有朋友问：把创业粉引进来之后能做什么变现？

回答很直接，能做的盘子很大。课程销售、1V1陪跑、训练营报名、私域社群收费都可以接。只要粉的质量对，转化路径是现成的。

也有人好奇制作成本。

这是照着提前写好的文档稿子直接念出来剪辑成视频，平均一条作品控制在一分钟内就能发。话术不用自己想，跟着稿子念即可，所以上手极快。

有人吐槽这是用手绘号在做，也有人觉得操作太简陋。但正因为简单、快、可批量，才是暴力引流的本质。![](img/894d30a529e7c37bcd3392323c99941c.png)
