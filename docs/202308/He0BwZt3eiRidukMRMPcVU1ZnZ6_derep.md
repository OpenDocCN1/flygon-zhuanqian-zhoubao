# 拆解60：理想汽车CEO李想！创业过3次他在创业初期是如何思考产品的

很多人可能想不通：理想汽车在网上的争议从来没断过，但销量却一路走高。秘密在哪？答案就藏在它的创始人李想身上。

李想这个人，我关注了很久。早年间偶然刷到他一场关于产品的演讲，当时就被震住了——一个能把产品价值讲到那个份儿上的人，后来做出来的车能卖爆，我一点都不意外。一个CEO最厉害的地方，不是多勤奋、多聪明，而是在关键时刻做对了选择。而选择的能力，就来自他平时怎么思考问题。

所以今天，我们就来拆一拆李想在创业早期，是怎么思考产品的。

先说下李想这个人。1981年生于石家庄，父母都是中央戏剧学院毕业的，这在那代家长里挺少见。高三时，他做个人网站加给IT媒体写稿，一个月就能赚一两万，最高逼近三万，是他父母工资加起来的十倍。于是他就面临一个选择：考个普通大学，还是继续干手里的事？他选了后者。用他自己的话说——我做选择只看自己，不看别人。乔布斯和盖茨是大学辍学，他更狠，高中就辍了。

后来就是大家熟悉的剧本：2000年做泡泡网，成为中文IT垂直网站里的头部；2004年筹备汽车之家，没花一分钱推广费，靠中立客观的内容和实拍图等创新，一年杀进前五，2008年做到行业第一，2013年登陆纽交所。再之后，2015年创办理想汽车，从理想ONE到L9、L8、L7，一路把家庭SUV做成爆款，2022年单月交付突破两万辆。

但李想最值钱的，不是这些成绩，而是他对产品的底层思考。接下来就进入正题。

李想现在是“🧣之王”，218万粉丝，几乎天天高强度上网冲浪，说的全是自家产品，小到一个零件，大到品牌形象。但时间退回2017年，他在混沌大学讲过一段关于怎么做产品的思考，那才是真正的好东西。

当时他说，过去两年创业热潮里出现了一个很糟的现象：一堆完全不懂产品的人，天天把“体验”挂嘴上，占满各种媒体版面教人创业、做产品。结果呢？那两年的创业失败率是历史上最高的。钱投进去一大堆，真正跑出来的企业寥寥无几。

那到底什么是产品？李想的定义很宽——开一家公司、做一个服务、一个APP、一个网站、一个功能，甚至写一篇文章，都是产品。而产品力，在他看来首先不是技术能力，而是一项管理能力。因为产品里最重要的不是专业技能，而是管理。如果只把产品当专业技能玩，就容易为了刷存在感，把一步能做完的事拆成六七步，低效就是这么来的。

所以做产品，第一步不是画原型，而是先定目标。

他发现大多数人做产品，恰恰是缺了这一步，导致后面全白干。什么叫定目标？就是针对你要解决的问题，定一个清晰、可衡量的目标。为什么要这样？因为如果没有目标，几十个人的团队，每个人脑子里想的都是不同的世界。大家各吵各的，谁都觉得自己的体验好、功能好，但产品到底要达成什么，从来没聊过。

他拿当年的经历举了个例子。2008年，汽车之家合并了另一家汽车网站“车168”。合并前，汽车之家的访问量是对方的十倍。合并后聊目标，车168的人说，我们的目标是做“最有影响力的汽车网站”。李想问：什么叫最有影响力？回答就五花八门了——有人说要最专业，有人说要在厂商那里有号召力，有人说要让用户评价好。你看，连目标都理解不一致，执行的时候怎么选？保用户还是保客户？完全没标准。

而汽车之家的目标特别简单：做访问量最大的汽车网站，衡量标准就是PV。随便问哪个员工，答案一模一样，所有人都在为同一个目标干活。

定目标这事，最大的坑是贪心。总想用一个产品同时解决四五个问题，照顾所有人，最后什么都做不好。产品也一样，你问他要解决什么问题，他说既要A又要B还要C，那就是胡扯。除非他是神。

有了统一目标，第二步是给产品定标准。李想的标准只有三个词：优越感、安全感、价值。

安全感决定用户是不是不用你、不买你；优越感会变成口碑和品牌向外传播；而最核心的是价值。价值就是——你帮客户解决了什么问题。比如顺丰，价值就是最快把货送到你手上，简单直接。汽车之家的价值，就是帮用户买车、用车，就这么简单。

第三步，也是最难的——标准怎么衡量？

李想说，用户价值只有两个衡量维度：一，用户愿不愿意为你花时间；二，用户愿不愿意为你花钱。有些演示视频看着炫酷，界面做得漂亮，底下评论一片“太棒了”，但你根本不会去用，更不会掏钱——这是产品最糟糕的结果。

他2008年招了一个刚毕业的产品经理，后来成了产品总监。那人提了一个“反人类”的理论：只谈价值，不谈体验。李想他们还真就这么干了。为什么？因为每个人对体验的要求完全不一样。iPhone一个home键，安卓三个按键，哪个体验好？没有任何道理，而且十分钟就适应了。与其耗在体验上，不如死磕价值。

价值怎么衡量？事后很简单，看访问量、看收入、看利润。但事前怎么衡量？总不能等做完了再后悔。李想给的方法也很实用：找五到十个不同部门的人坐在一起，把用户需求里提到的可选项全部列出来，然后让他们自己排个序——你愿意花时间用的，排个名；你愿意花钱买的，排个名。最后取前一到三个，做成产品功能，剩下的全砍掉。你自己都不用、不买的东西，凭什么卖给消费者？

他还有一个特别经典的练习，专门用来训练新加入汽车行业的员工。他会问：如果这辆车增加一万块钱的物料成本，你会把这钱加在哪？一屋子人讨论下来，黑板能写满——有人说加空气悬架，有人说要可变色天窗，有人说加按摩座椅，有人说上22寸轮毂。这就是大多数人做产品的方式：到处问需求，然后什么都要。结果呢？市面上的车，卖得最好的还是黑白银灰；做二三十款配置，真正有人买的就两三款。为了多出来的配置，座椅要同时找四家供应商，测试要花三年；如果只做一款座椅、一家供应商，一年就够了，供应链和质量控制还更好。

然后李想会问第二个问题：如果你们自己是消费者，多花一万块，你会买哪个配置？答案瞬间集中——90%以上的人都选了“把这一万块全花在内饰上”。接着再问：那你看市面上同价位同级别的车，是不是内饰最好的那个，销量就是第一？几乎是。每个级别，都是内饰最好的车卖得最好。

这就是李想的产品方法论：先定一个清晰可衡量的目标，再用优越感、安全感、价值这三个标准去定义产品，最后用“时间”和“钱”来验证——事前靠团队内部的选择排序来砍需求，事后靠用户的行为来检验。

回头看，李想连续三次创业，从泡泡网到汽车之家再到理想汽车，每一步都不是靠运气。他的厉害之处，就是能在关键节点上，用一套极其清晰的逻辑去思考产品。而我们普通人能学到的，或许就是那句最简单的：做产品之前，先想清楚到底要解决什么问题，然后用最简单的方式去衡量它。

别天天嘴上挂着体验，先问问自己：用户愿意为它花时间吗？愿意为它掏钱吗？如果不愿意，那什么都别说，回去改产品。

外形这条赛道已经卷到红海了，想要靠线条、比例再做出本质区隔越来越难，反倒是内饰，这个被很多人轻视的空间，才是真正的决战场。

最典型的参照是中级车里的那场博弈。上代车型里，宝马5系一骑绝尘，奥迪A6、奔驰E加起来都追不上。原因很简单：5系把7系的内舱几乎原封不动搬下来了，而当时的奔驰E反其道而行，把C级的内饰往上提了一级。结果就是，5系月销巅峰能摸到1.5万辆，奔驰E最好的时候也就在两三千辆，还得靠10万块的优惠才能走。

换代后剧本反转了。这代奔驰E把S级的内饰完整下放，立马就开始加价，月销轻松破万。放眼全市场，从紧凑SUV到B级轿车，榜首永远是那个把内饰做到同级最令人信服的。

可讽刺的是，国内厂商几乎都明白这个逻辑，却反着来做。他们心里清楚用户会在意内饰，可在造车时给内饰的预算永远是最低的。10万块的车，内饰成本有时候还不到2000块。为了省这几千块的成本，宁可后期在市场上降两万去促销，也不愿在前期把氛围、触感、质感拉起来。这是产品逻辑的错位：需求很明确，落地却背道而驰。

更清晰的信号是，绝大多数国产车企的员工，几乎不买自己造的车。大家对自家产品的评判标准，和用户的感知完全不在一个频道上。

所以做产品，事前事后都需要同一把尺子。当一个团队共享同一个世界观、同一种评判标准时，底层人员的效率和价值会被无限放大。

就拿汽车之家来说，它占据了汽车垂类网站六成以上的流量，却从不用堆人堆头衔。产品经理的队伍很小，基本是新人培养上来。关键不是技能堆砌，而是产品力，是那种能把运营、技术、产品组织起来往一个目标冲的能力。因为大家看问题的视角一致，每个人都能把自己专业的长处发挥到极致，而且都觉得自己在参与、在贡献价值。

衡量用户价值，时间、钱是两个最直观的标尺。后来又多了一个维度：情感。情感怎么量化？用口碑来衡量。当用户真心喜欢一个产品，他会自发传播，这份自发的传播在社交媒体和搜索引擎上的沉淀，就是情感价值，也是品牌价值。

聊产品标准，其实就三件事：价值、安全感、优越感。绝大多数我们日常首选的产品，都同时满足这三点。

以苹果为例。价值是设计和易用，拿起来就懂。安全感是省心，不会弹一堆无用弹窗，不用担心系统被各种乱七八糟的东西打扰。优越感是社交场景，朋友聚会时苹果手机是摆在桌上的，不是塞在口袋里的。

顺丰也一样。价值是速度，隔日达是预期。安全感是丢件率行业最低。优越感是用户在淘宝下单时，商家提示的是“顺丰包邮”，而不是四通一达。企业间寄重要文件用顺丰，对方感受到的是尊重。

🛰️的价值是沟通效率极致化。安全感是相对干净，没广告轰炸。优越感是朋友圈的展示欲，旅行、育儿、生活片段的分享，构成了社交优越感的流通。

做品牌时，安全感是基础，但打动人的是价值和优越感。茅台的优越感是国家领导人也在喝，价值是多层工艺的叙事。爱马仕的优越感是好莱坞顶流、向往场景里出现包包，价值是鳄鱼皮与法国手工缝制。安德玛让顶级运动员穿戴，产生“穿上我就接近他们”的优越感，同时用透气面料解决运动中的黏腻问题传递价值。

苹果早期的Think Different广告酷是酷，但用户找不到自己的影子。后来改名为Apple后，广告永远讲让人向往的场景，即使产品老人也能用，广告主角永远是年轻人和小孩。因为人人都希望自己更年轻，而广告里讲的设计、拍照、音乐，才是用户能买单的真实价值。

我当年创业做汽车之家，过程没有外界想的那么玄。2004年我要找一个能从零做到第一的赛道，候选有旅游、房地产、汽车。

旅游的头部是携程，核心壁垒是几千人的呼叫中心。我们当时全公司一百来人，去管几千人呼叫，不是强项，也没兴趣。

房地产的头部是搜房，核心壁垒是在几十个城市扎堆开分站、落地深耕。我们做的是轻互联网，分站管理不是我们的打法。

汽车反而是完美标的。2004年是典型的卖方市场，雅阁全程加价，最少3万、最高5万。4S店一年回本是常态，市场还没爆发，正是卡位的好时机。汽车也是标准化产品，北京的宝马3系和山东的宝马3系一模一样，和当年做IT网站要覆盖19类不相关产品相比，复杂度只相当于手机那么简单。当时市面上的汽车网站基本靠发通稿、照搬厂商图，没有真正的产品价值。

2005年六一，我们上线了汽车之家。第一个产品是产品库。那时候大家买第一辆车，周末才有空，北京一本田的店才两家，现在二十多家。跑店没样车是常事，我们想让用户在家里看车比去店里更方便。

我们去4S店挨个拍照建档，甚至把钥匙、杯架、空间细节都拍清楚，原厂图那种PS感带来的不信任感就没了。配置信息也全部结构化录入，并且能跨品牌跨车型一键对比。那个年代买车的决策周期要一年，现在一个月能定下来，信息不透明带来的焦虑就极大。像沙漠里渴了三天来一杯水一样，这个产品库很快让网站流量从百家网站里冲进前五。真实带来安全感，省下的跑腿带来价值，拥有信息优势带来的分享欲就是优越感。

第二个阶段是内容。我们认为文章也是产品，必须同时有安全感、价值、优越感。之前的行业文章要么复读通稿，要么用毫米、千瓦这种专业参数吓人。用户不是来看智商检验的。

我们改成“人话”。空间不说数据，说175cm的人坐进去，腿部空间一拳几指，头部几指。杯架不说直径，说能放可乐还是脉动。看完文章就知道这车值不值得买，哪个配置最值得买，而不是模棱两可。用户看完就能成为朋友圈的汽车达人，被人请教、被认可，这份优越感就形成了口碑的传播。

做产品，本质上是做标准，内饰比外观更诚实，价值比噱头更长久，优越感比参数更难复制。

很多人问，汽车之家是怎么一步步做起来的？其实我们早期只做对了一件事：让用户读文章时感到安心、有收获、有认同感。这个习惯，我们一直保持到今天。

当时同行在干什么？他们拼命在文章里秀专业、秀实力，结果用户看完只觉得自己是“傻子”，或者觉得编辑是“傻子”。所以我们反着来，从用户的角度写内容。大概只用了半年，到年中时，我们的访问量就冲进了前三，而且几乎没花一分钱推广费。到了2006年底，我们已经是所有汽车网站里的第一名，依旧几乎是零成本。

到了第三个阶段，我们想的是：怎么才能稳住第一，并且拿到更多用户？于是又发现了一个机会——那时候几乎所有汽车网站，周末都不更新。但用户周末恰恰是最需要看车的，因为买车对普通人来说是大事，他们恨不得抱着电脑把论坛每一条帖子都翻遍。可网站不更新，用户啥也看不到。

我们就想：如果我们周末有更新，就像沙漠里的一杯水，没人会挑剔是可乐还是茶，有水就喝，有多少喝多少，根本没有竞争。所以我们定了个规矩：每周六上班更新一部分，周日再用定时发布推一部分。不需要多惊艳，只要你有，别人没有，就够了。

慢慢大家形成习惯了：周末想看车，就去汽车之家，因为只有这里有新内容。后来我们把这个策略做到极致——每天早晨用户几点看更新、晚上几点看更新，我们一定赶在那个时间点之前，把文章、论坛推荐、产品库全部更新到位。

为什么用户觉得汽车之家有安全感？你去别的网站看看：周末不更新、节假日不更新、更新时间全看编辑心情。而汽车之家一年365天，天天有更新，而且时间固定，用户上来根本不用想，肯定有新东西。这件事我们坚持了十年，从没变过。

后来很多同行来问：“你们流量怎么涨这么快？是不是投了大量搜索广告？做了很多SEO？”我说我们连SEO的人都还没招。他们说：“不可能。”我说：“你们天天不更新、周末不更新、时间随机，等于在给我们白送流量。”他们恍然大悟，回去也搞更新、定时发布，结果坚持不到一个月就放弃了。

而我们一坐就是十年。这带来了什么？每天用户准时知道你有内容，这是安全感；看到的内容对自己有用，这是价值感；感受到你的团队用心在做，这是优越感。用户不是傻子，你用心了，他们感受得到。他们觉得用汽车之家比用别的网站更踏实，因为这里的编辑是积极的、努力的。

就这样，年底我们的流量成了第一名。最初我们目标定的是2008年底做到第一，当时没人当回事，结果只用了一年多就实现了，而且一直保持到今天。

这没什么高深的秘诀，不是什么玄妙的“用户体验方法论”。我们就是坚持最朴素的东西，然后用这套方法论培养了一帮年轻人，让他们自己去做产品、做内容。

有意思的是，虽然流量遥遥领先，但我们是所有汽车网站里产品经理最少的，发布的产品也是最少的——因为基本每个产品出来都是成功的。反观很多网站，一堆产品堆在界面上，乱七八糟，没几个好用。

很多网站特别爱“改版”，APP也天天改版。我就想问：你手机里用得最好的软件，哪个天天改版？天天改版就是刷存在感，每一次改版都会让用户的安全感大幅下降，因为界面又变陌生了。真正好的应用从不频繁改版——百度贴吧历史上只改过一次，还改回去了；🛰️今天的界面和几年前比，几乎没变化。

这就是我理解的有效做产品的方法。我觉得过去两年大家被各种舆论带偏了，今天想把这条简单直接的路分享出来：怎么正确地做产品，怎么培养做产品的人。
