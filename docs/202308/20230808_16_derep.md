# 从零到第一个10万：一个国企上班族的自媒体副业实战笔记



## 一个每天只投入两小时的新手，如何在半年内用自媒体副业拿到首个十万

大家好，我是龙哥。4月18号才入圈的小白一枚，白天在国企做本职工作，今年机缘巧合把自媒体作为副业开始尝试。

入行到现在正好一年，几乎全程靠每天下班后的两小时左右余量去经营。上半年就跑通了第一个十万元。

这篇是我对上半年经历的复盘，篇幅接近一万字，差不多把我踩过的坑、做过的选择和真实的收入变化都摊开了说。里面还附上了我每日记账的流水，数据摆在那儿，更直观。

十万块对于赚钱群里的高手可能只是个小目标，对我而言却是一次非常扎实的正向反馈。它证明自媒体这条副业路子是能变现的，我也亲手完成了一次从内容到收入的小闭环。

过去我对副业的认知基本停留在开店、跑滴滴、跑美团这种体力型模式。接触赚钱之后视野被打开了太多，赚钱的玩法远比想象中多元，我也第一次有了靠持续输出就能积攒第一桶金的笃定。

赚钱像是一把钥匙，给我推开了工作之外那个很广、很刺激的商业世界。我相信再坚持下去，副业收入追上甚至超过主业并非遥远的设想，未来的自媒体创业也有了现实的基础。

感谢一路引路的人，感谢带我入行的老师，感谢带我认识龙哥盟的炮爷，感谢赚钱社区给我补足商业认知、让我有了实操敢出手的底气。也谢谢一直陪我讨论、点赞的朋友们。
