# 真正的软件，靠的是能一直被拉伸的生命力

很多东西能用，但只有一部分能活得更久。

软件的价值从来不在于上线那一刻有多完美，而在于它能不能随着需求的变化不断被改造、被重用、被赋予新的意义。能够保持延展性，在不同场景里自由变形、持续适配的，才配得上软件这个名字。![](img/c82517cf434fbdb3a6ae9332b4e0a1ce.png)

一个僵化的系统，哪怕功能再全，也只是当下的工具；一个具备延展性的系统，即便起步简单，也能随着时间生长出新的可能。这正是区分一次性产品与真正软件的分水岭。![](img/894d30a529e7c37bcd3392323c99941c.png)
