📕商单这事，真的不难，可以说是零门槛。你只要做到每天稳定更新，严格按照流程来，基本7到10天就能积累到一千粉丝，甚至有的学员两三天就达标了。下面把细节掰开揉碎讲清楚。

# 一、账号养号

1. 注册新号：用手机号就能注册，一个人最多能办15张电话卡。

2. 做实名认证：想接广告必须要实名，自己的名额用完了，还能借家里人的。

3. 刷垂直内容：比如你想做影视混剪，那就去搜同类账号，花一小时刷相关视频，连续养三天，点赞、评论、收藏都做一遍。本质上就是模拟普通用户的行为，等📕把你标记成“北鼻薯”，基本就算养号成功了。

4. 尽量用4G/5G流量，少连Wi-Fi。尤其是手上账号多的朋友，否则一旦某个号因搬运被判违规，很容易连累其他号一起遭殃。

# 二、素材搬运与剪辑

用剪映就够了，手机上就能剪。要是担心不会去重，这里有免费的剪映课程：
链接：https://pan.baidu.com/s/12fUg7BHA2aQnayCENt_L1g?pwd=1lyt

选什么素材很关键。之前有人傻傻地问：别人发过的素材我还能用吗？当然不能！别人用过了，你再用就是同平台搬运，很容易被判定违规。

正确的做法是：去其他平台找博主发布过、但没同步到📕的作品。这样你在📕发布时，它就算你的原创。除了抖音、快手，还有🐧小世界这类相对小众的平台，都可以去挖，这就是所谓的信息差。

至于影视混剪的具体剪辑方法，可以翻我上一篇帖子，这里就不重复讲了。

# 四、图文广告怎么发

品牌方会通过🛰️来找你，谈好之后，他们会把现成的图文笔记发过来。你只需要复制内容，直接粘贴到📕发布。官方审核通过后就能正常展示。如果没通过，别慌，找品牌方的编辑去改，改完再发就行。

这里提醒两点：不要断更；广告还没审核通过、还没正式发布前，你仍然可以发自己的内容。但广告正式发布之后，要再等三个小时，才能发自己的作品。

# 五、多多V计划

八月份开始，官方的规则变了：📕账号要有5万粉丝，才能把作品分到多多去赚流量收益。但现在有个新玩法，直接先在多多视频起号，再把作品分发到📕，这样📕这边的商单佣金照样拿。

多多V计划非常值得搞，📕商单只是小试牛刀，V计划才是真正的大头。
