# 写作者的长效能源：自己造选题、造素材、造下笔法



## 写不动的根因，往往是没学会造料

作者：微微
发布日期：2023-08-11

嗨，我是微微，目前在做新手写作的陪跑。

前天群里有位朋友私信我：最近怎么没更新，是还在假期松弛感里放不下，还是选题枯竭、灵感断档了？

我回他：只是周末歇一下啦。不过这条问候倒让我意识到，这正是绝大多数写作小白卡死的共性困境。

想写，却找不准方向；方向有了，却搜不到可写的干货；干货凑齐了，却对着空白文档发呆。这看似是入门级的三连问，恰恰是最难啃的硬骨头。

一切创作都像盖楼，底座打不牢，上层再华丽也会散架。起点不稳，过程就东拼西凑，成文也容易四不像。

所以这篇分享，我把之前沉淀下来的方法拆开来讲：怎么自己生产选题、怎么自己生产素材、怎么用一套可复制的下笔公式把内容落地。都是很实在的养分。
