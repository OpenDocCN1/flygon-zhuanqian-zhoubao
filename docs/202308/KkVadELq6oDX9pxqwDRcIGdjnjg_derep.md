#### 2.1 先泼冷水

完全没必要自己注册，前几次操作新手至少要花1小时：

（1）注册环节需反复测试接码平台的手机号，可能耗费1-2小时耐心

## （八）【科普8/11】双因素身份认证（已下架）

双因素身份认证的逻辑是：登录时除了密码，还要输入一条临时验证码，以此把账号安全拉到最高。

在账号风控比较严的时候，开启它会让账号更稳、更安全。

但在2023年7月8日更新的版本里，这个功能已经被取消了，后续会不会再上线目前不确定

过去，使用GPT4从Plusgins store安装某些插件时，系统会强制要求你先开启双因素验证，否则安装不了。

下面演示一下开启和关闭双因素身份认证的操作流程。

### 1 开启双因素身份认证

#### step1.打开开关
GPT聊天界面 -> 点左下角… -> 点 Settings -> 点 Data controls -> 点最下方 authentication 一行的 enabled 按钮开启  (我现在已经开启了，所以按钮显示的是disable)

![](img/b6905b19e0d185c664a5173f46a1fd40.png)

#### step2.立刻重新登录
开启后会要求马上重新登录，输入用户名和密码后会弹出二次认证页面

![](img/3a864e7a727478ea289379cd6755a471.png)

#### step3.装一个Authenticator app
需要一个Authenticator应用，iOS直接搜这个名字，安卓找个类似的就行。这种应用专门用来生成双因素验证码，有的收费，iOS这个是免费的

![](img/746319ac56158af66aa3c9b70662f0b0.png)

#### step4.生成验证码
用app扫GPT页面的二维码，app里会显示一个倒计时的验证码，填进GPT页面点Continue即可

![](img/2870aa424cf10a3a7b8bbfd25f496639.png)

#### step5.后续登录
注意：此后每次登录都得做二次验证，不过不用每次都扫码，app里会一直有验证码，直接填入就行

### 2 关闭双因素身份认证

#### step1.关闭开关
觉得二次验证麻烦的话可以手动关掉，之后恢复成账号密码登录就行

点这里：

![](img/caeb5d3ee866076b073bb8816f9ca8eb.png)

## （十一）【科普11/11】如何为ChatGPT API充值

### 1 API价格体系
充值前先了解价格

5美元免费额度用完后可以自行充值，默认每个月最多用120美元，超出需要额外申请。申请表链接：https://share.hsforms.com/1AQvscELNT724FkL2Hp5Lvg4sk3，一会儿会教你，获批难度比较高

API一次对话到底花多少钱

调用GPT-3.5-turbo模型，官方定价是输入1000token 0.0015美元，输出1000token 0.002美元

1000token大概等于750个英文单词

也就是说，下一个750词的指令花0.0015美元，GPT回复750词花0.002美元，一次对话约0.0035美元，约合人民币2.5分

调用不同模型价格不同，最贵的是GPT-4-32k模型，输入0.06美元/1k token

了解这些就够了，普通玩家准备一个120美金的账号就很够用

具体模型与价格见官网：https://openai.com/pricing
