# 你做不出一个不属于你的东西，品牌到最后都是你的影子

很多人做品牌时总想先设计一个“人设”，再去包装故事、找定位、做投放。好像只要模板套对了，就能把一个冷冰冰的符号硬生生做成热销品。

真相恰恰相反。

你根本造不出一个与你本人格格不入的东西。所有的坚持、取舍、脾气、妥协和偏执，最终都会从产品里漏出来。消费者买的不是你PPT上的slogan，而是你长期做出来的一致性的行为模式。

所以，品牌这件事走不通捷径。借来的调性会很快失效，模仿出来的风格会很快疲惫。能活下来的，永远是你自己真实的样子被持续放大、被市场看见、被信任沉淀下来的那个结果。

与其去问“我的品牌应该是什么样”，不如先问“我是怎样的人，我愿意为之负责的东西是什么”。当你把答案说清楚了，品牌也就自然长出来了。
