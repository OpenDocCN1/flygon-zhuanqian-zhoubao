# 写不出东西怎么办？我的私藏素材制造法，看完就能用
作者：龙哥

经常有小伙伴问我：“为什么我读了很多书、看了很多文章，真到动笔的时候还是脑袋空空？”

其实这个问题，我以前也遇到过。回想自己刚开始接触写作那会儿，每天逼着自己看书、记笔记、思考人生，可真坐下来写的时候，常常写两三行就卡住了，后面怎么憋都憋不出来。

后来我才慢慢想明白一件事：写作这回事，光靠“输入”是不够的。你脑子里存了一堆知识，但如果缺少**把知识转化成素材**的能力，那这些存货就跟堆在仓库里的货物一样，落灰也变不成钱。

那怎么办？答案是：学会“自制”素材。

别觉得玄乎，今天我把自己亲测有效的一套方法完整分享给你。我把它分成了四个阶段，由易到难，你可以根据自己的情况选着用。

## 一、从TED演讲里“挖”素材

很多人觉得TED演讲就是听个热闹，听完感叹一句“讲得真好”就翻篇了。但在我眼里，每一场TED演讲都是一篇现成的高质量文章——它本身就有清晰的观点、结构和论据。

你要做的，不是“听”，而是“挖”。

怎么挖？分两步。

**第一步：表面延伸。**

说白了就是对着演讲里的关键观点，反复“问自己问题”。

比如说那篇很有名的《20岁，光阴不再来》，里面有个观点是“建立学习目标”。

你可以问自己：

- 我为什么要建立学习目标？
  - 因为没目标的生活容易让人迷茫、颓废。
  - 因为目标能帮我安排每天的学习计划，不至于瞎忙。
  - 因为我想把有限的精力花在真正重要的事情上。

问完这些问题，你已经有了初步的写作素材。

别急着停，进入第二步质疑模式：

- 那如果要建立学习目标，从哪些方面入手呢？
- 如果没有目标，我的生活真的会变得很差吗？
- 走一步算一步的人生，真的没有意义吗？

这么一轮下来，你会发现可写的东西变多了。

**第二步：深入延伸。**

这一步有个简单的公式：**WTH**。

- **W（What）**：我要成为什么样的人？我想过什么样的生活？什么样的目标才适合我？
- **T（Time）**：完成这个目标要分几个阶段？每个阶段要多久？怎么安排时间？
- **H（How）**：具体该怎么做？用什么方法？不适合自己的方法怎么调整？

你看，就一个“学习目标”，被你从“是什么、为什么、怎么办”三个维度挖了一遍，素材一下子冒出几十条。

最后你用思维导图把这些散落的点串起来，就能轻松整理出好几篇不同角度的文章选题。

**一篇15分钟的演讲，足够你写出4-5篇文章。** 这就是“挖”的价值。

## 二、看书、追剧时，“代入”比“摘抄”好用多了

很多人看书看电影找素材，习惯性做摘抄、写读后感。这方法没错，但挺费神的——因为你要一边理性分析内容，一边输出感性体验，两个脑区同时运转，很容易累。

我用的方法是：**代入角色**。

你可以把自己想象成书里或者电影里的某个人物，用他的眼睛去看、用他的心去感受。

比如读《富爸爸穷爸爸》的时候，我就把自己代入主人公清崎。

第一次接触“资产负债表”这个概念时，我满脑子都是问号：

- 为什么自住的房子是负债不是资产？
  - 因为它不产生收益，还会折旧。
  - 因为它需要装修、维护，持续花钱。
  - 因为你要还房贷，每个月都在支出。

站在主角的角度，向“富爸爸”提问：

- “可我总觉得买房子更踏实，还能转手卖出去啊。”
- 富爸爸回答：“亏本的收入就是负债。”
- “那怎么能赚到钱呢？”
- “你可以去研究那些能带来现金流的资产。”

你看，一场对话下来，素材自然就出来了。而且因为是“亲身经历”的视角，写出来的东西会更有代入感。

看电影也一样。看《流浪地球》的时候，如果我是刘启，看到大家都掉头回来帮忙的那一刻，什么感受？感动、激动、热血、想哭、感受到了人性的力量……这些关键词一冒出来，选题就跟着来了：

- 危急时刻，为什么普通人也能成为英雄？
- 人性本善，还是本恶？

然后你再换个角色想一想，比如从反派的视角、从配角的角度，又是完全不同的素材体验。

**一本书、一部电影，用这个方法能榨出上百条写作素材。**

## 三、观察自己，是最稳定的素材来源

如果说前两个方法是从外部找素材，那这个方法就是从内部挖。

想要打造个人IP、输出真正有影响力的内容，你得学会“盯住自己”：

- 你的缺点是什么？怎么在改善？
- 你的优点是什么？怎么分享出来让别人也能受益？
- 你最近做成了一件事，过程是怎样的？
- 你跟别人相处时，哪种模式最舒服？
- 你处理事情的方式，有什么可以优化的地方？
- 你最近有没有什么小确幸？

别小看这些日常记录，**只要你一直在成长，这类素材就是取之不尽的。**

比如我前两天出门，差点被树上掉下来的芒果砸到。当时就在想：写作这件事不也一样吗？有时候你越着急赶路，越容易摔跟头。慢一点、稳一点，反而能走得更远。

这种素材是带着你个人温度的，别人拿不走，也复制不了。

## 四、生活里处处是素材，就看你会不会“想”

等你思维能力练得差不多了，就进入最高阶的一层：从日常生活的细节中捕捉灵感。

这个方法的核心只有一个字：**思**。

跟你讲个特别简单的例子：

你带孩子去公园散步，看到一对年轻情侣有说有笑，旁边一对老夫妇安静地坐在长椅上。

你第一时间想到什么？

**第一层：人生的阶段。**

- 年轻人有青春、爱情、活力，还有对未来的无限憧憬。
- 带娃的你，有生活、温馨、责任，也有对孩子的期待。
- 老人家有安逸、回忆、坦然，和人生后半程的从容。

这些关键词拎出来，就是一大把选题：

- 恋爱中要注意什么？
- 什么样的婚姻才值得？
- 有了孩子之后，生活到底有什么变化？
- 白头偕老的婚姻，都有什么共同点？

**第二层：再往深处看看。**

如果你还能多想一步，把“活力”“时间”“财富”这些因素组合起来，又能得到一个新的洞察：

- 年轻的时候，有活力、有时间，但没钱；
- 中年的时候，有活力、有钱，但没时间；
- 老年的时候，有时间、有钱，却没活力了。

从这个角度出发，又是一批全新的选题。

日常交流也是同理。比如有朋友聊到“一只小狗被惊吓到撞上玻璃门”，你马上联想到：人在慌乱时是不是也容易“撞南墙”？就像我前阵子看到群里大佬们的分享，焦虑得不行，后来才意识到，焦虑本身就是一块玻璃门。

核心内容一拎出来：**焦虑**。

后面的选题就顺理成章了：

- 成功路上的几种情绪陷阱，你中了几个？
- 急于求成的人，后来都怎么样了？
- 稳扎稳打，是我的制胜法则。

一个方法百样用，关键在于你有没有养成“万事皆可联想”的习惯。

## 最后说点心里话

以上四个方法，从基础的“表面延伸”到进阶的“生活联想”，我自己整整走了一年才慢慢融会贯通。

说实话，这些方法本身不复杂，难的是“耐住性子”去练。

写作这条路，没有谁能一步登天。但只要你掌握了“自制素材”的能力，就不用再担心灵感枯竭——因为你已经拥有一台永不停歇的**素材永动机**。

期待我们都能在写作这条路上，越走越远，越写越从容。
