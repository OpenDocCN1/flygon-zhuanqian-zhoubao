# 最近半年经历：📕带货榜 22 名、一天 2 万单近距离体会河北电商疯狂

## 半年复盘：📕带货榜第22、朋友日销2万单，我终于读懂了河北电商的凶猛

大家好，我是小李哥。

眨眼半年过去，想把自己的见闻整理出来，跟大伙聊聊。

这半年，我这边在📕带货榜上冲到了第 22 名。但要说真正让我开眼的，还是去朋友那取经的经历。他状态最好的时候，一天能出将近 2 万单；现在虽然热度稍有回落，但那个体量，依然让人震撼。

也正是这一段近距离的观察，让我实打实见识到了河北电商的疯狂——那种打法、那种节奏，不亲身经历真的很难想象。
