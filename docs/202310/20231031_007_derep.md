# 每个创业者应具备的思维——选品思维

创业前，请先修炼“选品思维”

在电商圈，选品的重要性怎么强调都不为过。有个说法很流行：一件商品能不能卖爆，七成靠选品，三成靠运营。但很多人没意识到，这套逻辑同样适用于创业项目的筛选。

如果你进入的是一个处于上升期、仍然有红利的赛道，哪怕你和别人的运营能力差不多，也有机会被大势推着走；反之，如果选了一个正在衰退的行业，即便投入再多心血，可能也难有起色。所以那句话永远不过时：选对方向，比盲目努力更重要。

那么，如何判断一个方向值不值得做？我并不是电商从业者，但我从古辛、盗坤、丹牛等前辈的选品方法论中，学到了很多。他们分享的选品框架，完全可以迁移过来，用来筛选创业项目。在这里也特别感谢这些大佬的无私分享，让我这个“外行”也能跨行业受益。


希望这套“选品思维”能成为你创业路上的一盏探路灯，帮你避开那些没前景的坑，找到真正有红利的赛道。
