# TikTok 美国小店日均 GMV 达 600 万+美元，对我们来说有哪些机会？

美区的TK电商眼下正处在上升通道里，小商店的日成交总额站上600万美刀后还在上探。但依然有许多人觉得难切入，甚至弄不清打法。其实，资金体量、团队配置、店铺层级不同，切入姿势可以有差异，但底层逻辑跟其他电商渠道相通：是冲爆款还是守长销款？供应链扛不扛得住？产品怎么出现在目标人群面前？而真正能决定你能不能持续拿结果的，是商品筛选。

先说第一道坎：店铺能否活下来。
被封号的原因大致有三类：一是很多人够不着官方入驻条件，市面上买资料/买店铺的服务又良莠不齐；二是没有在美库存，却用假海外仓发货，也就是从国内直发，让物流商隐藏轨迹，伪装成美区本地发货，平台正在严打；三是商品质量和履约能力不达标，同样会被清退。

目前TK在美区主推三种店铺形态：本地店、跨境店、托管店。
本地店由美区本地主体或自然人申请。企业要求：公司注册在美，中国血统股东持股不低于25%也可以；货放在美境，支持境外仓履约尾程或平台上门揽收；对应类目在Amazon美区站的总流水超过200万美刀，流水越高顺序越靠前，过1000万美刀的优先处理。需要申请材料的，在评论区告诉我，我会发给你。
跨境店则分几种。有美区货源的跨境卖家，需要货从美区境内存放并发出，可以用境外仓或FBA多渠道配送，但国外直发和伪境外仓都不被允许；还要有跨境电商操盘经验，单店年流水在200万美刀以上；还要能建联内容创作者，具备内容创作能力。准入门类涵盖美妆护理、3C数码、时尚配饰、家居生活、收藏品、食品饮料等大类；其中数码含汽摩配件、电脑办公、手机电子，时尚含母婴、珠宝、箱包、男女装、鞋靴、运动户外，家居含家具、家电、厨具、宠物用品、五金工具、玩具等。
已经有海外布局的品牌，只需满足以下一类条件：社交账号粉丝总数达到10万以上；品牌官网月访问量20万以上；自然搜索量每月1万以上；或在当地已有品牌直营店/经销渠道。
还没有海外布局的品牌，则要求年营收过千万美刀，或累计融资、固定资产超150万美刀；或属于已上市的集团跨海业务；或进入BrandZ、Kantar、胡润百强等榜单。
托管店方面，目前主要在沙特、英国、美区上线，供货方只负责供货，流量、销售、收款、物流、售后都由平台统一处理。

再聊经营层面的思路。
第一，用低价SKU冲排名。商品正常上架后，另选一条链接挂最低价SKU，控制库存，做到不亏或微亏；同时拍一条带购物链接的视频，24小时后到广告后台用“视频观看次数”为投放目标去加热，连续推3天，观察一天内的播放和出单，判断这个品能不能打。低价SKU只是钩子，利润要靠主力SKU，新手慎用。折扣券码促销同理。
第二，创作者铺量。免费送样给创作者，换回高质量的投放内容。关键是提前谈好：付费投流带来的流量不分成，创作者只拿播放数和涨粉；多数人接受，少数不接受就给1%-3%。拿到对方的专属推广码后，用新链接绑定广告，投流出的单就不用再分钱。有免费流量的视频，建议等免费流量快结束的时候再投放，往往能再起一波；观察一天内的数据。内容选择上，已经出单的视频都可以测，免费流量超过100万次播放的要谨慎追投，10万以上且转化不错的可以加大预算。
如果不送样，也可以直接给创作者素材，让对方出镜讲解，这样能快速验证市场，缩短试错链路。厂家内容+创作者口播，就是一条完整的带货视频。
第三，付费驱动店铺增长。店铺稳定出单后，可以把商品均价整体抬高，再用投放放大。最大的坑是成本和回报算不清：美区测过不少品，一般CPA在10-20美刀；内容和热度都好，可以直接投视频观看次数，CPM在1-2美刀；内容一般就控制出价，别盲目加预算。预算500美刀以下按50叠加，超过1000按500叠加；复制3条放量计划，观察1天，不行就重建；5000美刀一组的计划匀速消耗，ROI不行直接关。
人群圈定范围如果过窄，计划很难起量；过宽，用户又不精准。跑量不错的计划要缩窄人群，建议复制新建，不要在原计划上直接改。新广告计划不出量，排除出价和人群后，最快解法是换内容。每天保持不同类型视频创作，分析旧内容的数据，找出优质内容的共性。评估内容质量，主要看前3秒留存率、点击占比、购买转化比例。旧内容一直不出量就停掉，先看黄金开头画面能不能留人，优化后再生产新内容；新内容起量快但不转化，就拉出来分析卖点表达和结尾引导，保留优点改掉缺点。
第四，商城的搜索入口。很多商家还没有认真优化产品页面的权重，商城内不花钱的曝光入口是一个明显的洼地，值得提早布局。
第五，内容变现。有账号运营经验和打爆视频经验的团队，可以不碰发货，直接与商家合作，靠内容产出赚取分成，后面还会衍生出更多机会。

总括一下：
免费流量做账号，起号慢、需要铺量、要持续积累；大量找创作者带货是目前拿到大结果的主要路径，还能拿到大量用户生成内容，解决内容供给问题。![](img/58c581896ea73321a23c4910ac78a709.png)
付费投放仍处于早期，整体投放效果不算理想，纯靠付费的玩家很少，但这条赛道之后一定会跑出大赢家。![](img/e2f24cec5696ebe836e3d24429630855.png)（Pipi Ads可查看美区小店的投放数据）

货源这块，是很多人的瓶颈，但有几条路可走。
第一，多渠道分流库存风险。如果本来就有多个跨境渠道，比如品牌官网、Amazon，那就可以共同分担库存，库存压力会小很多。![](img/e7cce0329b30d9f4598db85ab88f9df9.png)
第二，接本地货主的盘。身边有Amazon卖家或渠道资源，可以商量合作，从对方那里调货；尤其是Amazon大卖家的货，往往在美区小店也很能打。此外，外国卖家的货源结构也值得研究，很多本地供应链还没被挖透。
第三，自主囤货。这非常考验开款能力，建议先选成本低、重量轻、有新鲜感的商品，小批量测试，跑通后再放量。
再强调一次：商品筛选才是根本，没有开款实力就很难走远。

商品筛选可以从三类信息差入手。
一是国内爆款平移。很多国内已经验证过的品类，可以直接搬到海外，比如曾经在国内火过的健腹轮。![](img/fc6d59270b92d2a13c60e586eb0e4cc2.png)
二是平台间的信息差。Amazon、品牌官网、Etsy等平台上已经跑出来的商品，可以拿到美区小店再试一轮。尤其Etsy，调性和TK用户很契合，找款参考可看 etsyshop.ai。![](img/141eb3cb047d31726587dc72ac904969.png)
三是国家间的信息差。TK覆盖多个国家市场，很多商品是全球通吃的。东南亚先爆的商品，调研一下美区也许还有机会。用Pipi Ads做数据锚点，可以实时追踪美区小店的投放和销量情况。![](img/8965a3fa42de407fbee547d5ffc7df0c.png)

接下来拆一个规模过亿的品类：家用监控设备。
Pipi Ads监测到，海外监控设备市场增长很快，不少广告主在TK投放单品，已经有人打出不错成绩。![](img/85708234c2340895beed4bc1ae15168f.png)（多广告主投放数据截图）
海外成熟市场对监控设备的需求是全方位的，商业、家庭、市政多个场景都在增长，而出海热潮最集中于家庭安防场景。![](img/b018d17f05f65ad093d0f0b1bc37badd.png)
需求可以归纳为两点：一是安全防范意识提升。欧美很多家庭住独立式住宅，室内、庭院、车库、花园都是需要布点的位置，通常不止一个设备；家里有老人、儿童或宠物，外出时需要通过远程画面安心工作。
二是技术环境在成熟。从硬件安装、信号传输到软件存储、维护，门槛大幅降低。以前在海外装一套智能系统，请人装一次要花掉二三百美刀的人工费；现在用户可以自己装，步骤简化，门槛被压得很低。![](img/73eb101cb51033b909c4d0330ead3bcd.png)
供应链端成本下降、市场竞争良性，也让更多实惠的安防产品流向消费者。
以螺口灯式监控器为例，这个单品已经红了几年，至今仍有人在做。![](img/c834f840c446b71d3e66deaaf51bfca8.png)
最早是多个DTC官网广告主在TK上换着地区反复打，核心手法就是按地区定制内容。![](img/599f6ddf4284654909a2c4aa52036e9a.png)
看Amazon，不少卖家都在跟进销售同款，销量从几百件到上万件；![](img/c9cee8f92068654ddfa1825bb7cd50db.png)
看Walmart和Google，同样是多家在卖、搜索热度持续浮现；![](img/151a37b61d7784abf8cf6301257dd1a1.png)
再看美区小店近期销售，多家店铺在售，累计也有数千件。![](img/6c1d180950c2ce724c3a2f41b0ee21dd.png)
爆款的共性是：在多个平台上都能出货。根据这个共性可以反向推演：社交平台上出单的商品，再去电商渠道验证；一个平台火了的商品，换到另一个平台试；美区跑出来的品，拿到欧洲或其他国家试；免费流量起量的品，拿去付费投放试。内容维度也一样：品牌官网上的爆款搬到小店，一条视频创意火了就迭代新版本。
产品维度上，某个单品火了，可以找同质化差异品复制；某个品类火了，可以延伸周边。
这些判断的底层，来自对市场、消费者诉求和信息的持续掌握。

Pipi Ads的使用，有几个实操点：
如果想查特定广告主，可以输入品类关键词或域名，看竞争对手的销售情况；但因为投放的特殊性，很多广告主没把标题文本和关键词绑进去，会漏掉一部分数据。![](img/b6085aee611cb7f96da9bb92d508ec3a.png)
想追爆款动态，把时间框在近3到7天，按广告曝光量或广告创意数排序，每天刷一遍。![](img/d483d40dd0282d74e8ab26e9fad9ee84.png)

长期品牌案例，看Wyze。
![](img/65d16fcfcfa0dfc3a312ca8b4d1c9ada.png)（Wyze在Amazon的部分销售数据）
Wyze 的公司总部放在西雅图，主营智能硬件和无线监控设备，2017年由前Amazon员工创办，创始团队四人，其中两人为华裔。![](img/2deab6d4383b203454d5128ef1095e48.png)（Wyze官网）
它最核心的杀手锏是极致价格力：把带Wi-Fi和App的无线监控设备压到20美刀以内，而当时同类竞品普遍在100美刀甚至150美刀以上。低价+硬质量，加上围绕消费者需求、绑定优质代工厂、自主研发，形成了口碑自传播。
Pipi Ads观测到，Wyze美区小店有26个SKU，较短时间内累计出单约15万件。![](img/4be44147acdf34174fc2bc817e1fa877.png)
出单最猛的是Wyze Cam v3，累计卖出八万件，单价33.99美刀，销售额折合约272万（美元），Pipi Ads收录广告创意25条，曝光累计6200万次。![](img/ac07fc5727d4b3500dffe0b4b7bc5df0.png)
产品支持多种安装方式，有超清画质录像、低光夜拍、远程对讲、云端储存、移动侦测和声音感应，还能联动烟感器和一氧化碳感应器发出提醒。
这套打法，确实能让极致价格力深植人心。![](img/c4522a5ab27db3f9aad376311548dffd.png)

最后说两句长期判断。
TK的流量盘子会继续吸引品牌涌入，许多细分赛道也会冒出新的品牌玩家。
第一，讲品牌故事要和市场打法形成合力。监控这种体量巨大的市场，很多人想进来分蛋糕，可以参考Wyze，先用极致价格力快速圈地，再用口碑做大规模自发传播。
第二，从用户中来到用户中去。选择赛道、挑选商品，本质上就是挖掘需求、解决痛点、满足其诉求。品牌要做长期，必须始终把用户放在中心位置，这件事很难，但绕不开。不同规模的玩家，满足不同层次的需求，各有各的生存空间。

做细分市场的小切口，起步往往更轻松。

**第三条路：技术创新＋成本控制**

所有产品最终都要靠供货体系来支撑。货源品质稳不稳定，交付靠不靠谱，必须逐步磨合和挖掘。尤其消费电子行业，在保证性能的同时压低价格，既是难点，也是机会。

无论是做爆款、做垂直品类、做小众品牌，还是做大品牌，每个组织都有自己的使命要去完成，也有自己的意义要去寻找。

先别急，让节奏慢一点。
