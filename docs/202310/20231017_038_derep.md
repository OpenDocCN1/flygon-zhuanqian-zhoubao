# 说服用户行动的营销策略，拿来训练 ChatGPT 效果出奇的好
作者：龙哥

你有没有遇到过这种情况：明知道某件事是对的，却总是说服不了别人乖乖配合？其实，营销圈里早就藏着一套“身份绑定”逻辑——只要把你想让对方做的动作，和他理想中的自我形象挂上钩，或者反过来，把你不希望他做的事，和他厌恶的那类人划等号，对方就很容易被说动。

听起来有点玄？咱们用个生活场景来拆解。假设你有个朋友，打喷嚏从来不遮挡，你觉得挺不讲究，怎么劝才有效？直接说“你这样太脏了”，估计他左耳进右耳出。但如果你换个说法：“大多数有素质的人，打喷嚏时都会主动捂住口鼻，他们往往很顾全大局、很有同理心。”你猜怎么着？对方可能下次就记住了——因为没人愿意承认自己是那个没责任心、不顾别人感受的家伙。

道理确实简单，可一到真实的策划案、广告语里，想绕明白还蛮费劲的。好在我们有 ChatGPT。你完全可以把这个“身份关联”的底层逻辑教给它，然后让它帮你写出各种场景下的转化文案，省心又高效。我自己就是这么干的，具体怎么喂指令、怎么调教，我把全过程整理在飞书文档里了：
