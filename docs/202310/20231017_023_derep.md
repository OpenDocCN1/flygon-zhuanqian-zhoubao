# 写之前，先把脑子里的“滤镜”拆掉



## 动笔前，先给自己做一次认知重启

大家好，我是龙哥。12 年笔龄，改过 560 多篇稿，累计输出 70 万字以上，原创 300+ 篇，一直在做一件事：把写作的方法拆开讲，给刚入门的新手找方向。今天想和你聊聊自媒体写作路上最容易卡住的那一关，并不是技术。

最近私信里反复出现几类相似的吐槽，我摘出来你感受一下：

① 文笔我觉得还过得去，为啥就是投稿一直被拒？
② 我写的干货明明很有用，为什么没人看，还被同行挑刺？
③ 写了差不多三个月，稿费加起来连五百都不到，还要被反复要求修改，写这个到底能赚到钱吗？

...

看着这些话，我一下子想起了自己当年被割韭菜的经历。被坑是真的疼，但也正因为那次撞墙，我才明白一个很现实的道理：**一篇内容值不值钱、好不好使，最终的裁决权不在你手上。**

我猜，现在ยังมี不少朋友卡在同样的心理里。文字功底其实不差，却总在投稿环节翻车，还莫名其妙要被质疑打击。

碰到这种状况，先别急着给自己判死刑。不要立刻认定是自己不行，然后疯狂内耗去补课。市面上书看不完、课报不完，越补越焦虑。

也别急着把所有负面评价都推给“审稿人太挑剔”。要知道，1 个人说你不行，可能只是口味不合；但如果 100 个人都给出同样的反馈，那也该认真照镜子了。这两者并不矛盾。

换个角度想想，会不会问题根本不在写作能力上，而是你对“写给谁看、在哪个平台发、平台要什么样”的认知跑偏了呢？

具体怎么判断和调整，细节我整理在飞书文档里了，阅读体验会更好：
