# 独自踏上巴厘岛那趟行程后，我终于学会了原谅那个曾经被所有人嫌弃的自己
作者：龙哥

说实话，在出发前的那段时间里，我的生活并没有什么特别的亮点。

工作上总是慢半拍，朋友聚会里容易沉默，爱情里也总是差一点点就被说“不够好”。长久下来，我对自己的评价越来越苛刻，好像前半生就是一连串的被挑剔、被否定、被放到一边。

我曾经以为，只要换个更安静、更美的地方，就能暂时逃离这种自我嫌弃。而巴厘岛，就是那个我随手定的答案。

一个人落地乌布的黄昏，天还没完全黑，空气里已经混着稻香和远处海浪的咸味。我没有行程表，没有攻略，也没有要发朋友圈的冲动。只是租了一辆小绵羊，慢慢晃进稻田，晃到海边，晃到一个小小的咖啡馆坐一下午。

没有人催我表现，也没有人对我指指点点。那种被世界放过的安稳感，是我很久没体验过的。

在海边发呆的时候，我忽然意识到，我这半辈子的“被嫌弃”，很大一部分其实是我自己先把自己嫌弃完了，才等来别人的嫌弃。巴厘岛没有给我什么巨大的顿悟，它只是把我从人群的噪音里抽离出来，让我第一次听见了自己的心跳。

回程的飞机上，我不再急着去证明什么了。我开始有点喜欢那个慢热、不张扬、容易在意别人眼光的自己。毕竟，那个从未被善待过的我，也曾那么努力地活到了今天。

和解不等于忘掉那些难堪，它只是不再用它们来惩罚现在的自己。
