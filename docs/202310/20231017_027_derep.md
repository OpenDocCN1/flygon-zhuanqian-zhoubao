# 从零搭起你的第一个 Prompt：以拆解一则👸号爆款文 Prompt 为例



## 新手如何从零开始调制一个 prompt，以拆解👸号爆文 prompt 为例

作者： 枫晓陌

日期：2023-09-28

嗨，我是龙哥，一名通过微软认证的 AI 工程师。接下来的一年里，我计划把 AI 嵌入到上百种真实工作场景中，让大家真切体会到 AI 可以带来的效率提升。

你想让 AI 帮你做什么，我都很乐意聊。AI 写作、AI 阅读、AI 📕运营、AI 私教健身、朋友圈营销、简历优化、热点解读……都可以来交流。

最近注意到一个很有意思的现象：不少朋友看到别人分享的一个好用的 Prompt，就想照着学、照着改，但卡在了一个关键点上，不是不知道框架怎么写，而是不知道框架里该填什么内容。

其实要破这个局，方法很简单。停下来问自己一个问题：此刻你最迫切想解决的是什么？需求就是从问题里长出来的，有了清晰的需求，Prompt 自然就有了落笔点。

我本人更偏好结构化 Prompt 的思路，所以下面这份拆解也会围绕结构化 Prompt 来展开。先给大家看一个参考范例：[`t.zsxq.com/12cSTRIYG`](https://t.zsxq.com/12cSTRIYG)

**为什么要聊结构化 Prompt**

可能很多人第一次听说这个词，甚至对 Prompt 和 GPT 到底是什么关系都不太清楚。打个比方，GPT 就像一辆性能不错的车，Prompt 就是你的驾驶技术。车再好，技术跟不上也跑不快。
