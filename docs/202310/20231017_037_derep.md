# 10W+自媒体爆款文章，用 ChatGPT 写“开幕雷击”标题
作者：龙哥

做自媒体的小伙伴，应该都领教过什么叫“开幕雷击”。这个词最早出自游戏《舰队Collection》，意思是当你点开一篇文章或视频，开头几秒就出现极其炸裂的言论或画面，直接让人瞳孔地震，像被闪电劈中一样。  

而这种标题之所以能轻松拿下10W+阅读，背后往往藏着七个秘密武器——金钱、数字、性暗示、走捷径、死亡或暴力、反常现象、民族情绪。  

以前想凑齐这七个要素，得对着屏幕挠半天头，死磕很久才有灵感。但现在有了ChatGPT，一切都变得so easy，你只需要下达正确的指令，它就能帮你批量炮制“开幕雷击”级标题，省下的时间够你多写好几篇稿。
