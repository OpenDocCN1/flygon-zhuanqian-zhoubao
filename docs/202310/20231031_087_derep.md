# ('12 天，1300 块，你也能把美国公司开起来', (2, 25))

标题：12天，1300块，我把美国公司注册了（亲测避坑）

没多少预算，也想把美国公司开起来？我用自己的真实经历告诉你：完全有可能。不瞒你说，整个注册过程真正动手加起来只用了12天，花费1300块，还是半DIY搞定的。

为什么非要注册一家美国公司？说白了就是为了收款。海外业务收款麻烦，有个美国公司身份会方便不少。但我兜里确实拮据，舍不得全交给代办，只能能省则省，自己动手摸索。

注册这个动作本身真不费劲，累的是前面一堆选择题：公司注册在哪个州、代理机构挑哪家、邮箱服务用哪个、手机卡怎么办、银行账户选哪家……每一个环节都要找资料、做对比，门道特别多，坑也不少。最典型的坑就是注册地址：你以为随便挑个地方就行？它直接关系到你后续能不能申请到某些银行卡。个别州，部分卡种死活办不下来。这个教训我后来专门记下来了。

别看真正干活只有12天，整个过程走走停停，前后拖了快一个月，大部分时间都耗在犹豫和踩坑上了。为了帮大家省下这些摸索时间，我把主流程整理好放在飞书文档里了，链接在此，有需要的自取：https://cijczs95il.feishu.cn/docx/XVbidP1jQoa9LtxINW7cG9rfnkh?from=from_copylink

再提醒一句：注册费只是第一步，后期维护才是持续投入。评论区有朋友提到，像Firstbase的地址加报税代理，一年下来差不多要600。所以做预算时一定要把这笔账算进去。
