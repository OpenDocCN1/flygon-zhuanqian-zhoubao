# 月饼短视频带货，两个月利润 50w，我是怎么做到的？

两个月，50万利润，7个人的小团队，就靠短视频卖月饼——这几个数字凑在一起，你可能觉得不可思议，但这确实是我亲手跑出来的结果。

大家好，我是矢渝。加入龙哥盟的第二年，我以操盘手身份带团队做了这个项目，收官时累计成交额冲到了200多万。回想项目初期，编导、拍摄、剪辑、出镜、投流……几乎每个岗位都由我一个人兼着。从零开始，一点一点把各个环节打磨顺畅，才换来这个来之不易的成绩。

成绩背后有很多门道，用一两句话很难讲透。所以我把从选品、素材制作，到投放节奏、团队分工的完整打法和思考，都整理成了一篇飞书文档，方便圈友直接查阅，少走弯路。

文档的获取方式我放在评论区了。有圈友在留言区问“能不能链接一下”，这里统一回复：入口在下面，大家自取就好。
