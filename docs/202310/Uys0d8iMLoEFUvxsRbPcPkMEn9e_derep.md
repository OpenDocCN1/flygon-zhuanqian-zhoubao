# 1. 做情感赛道的原因和初衷

### 1.1 为什么选择情感赛道

现在做情感定位的人非常多，📕、抖音一搜全是同行，赛道看似拥挤。但我依然决定all in，原因有两点。

1. 市场需求真实且刚性

人人都想要感情上的幸福，只是多数人不知道怎么拿到。最典型的是对异性缺乏了解。

《男人来自火星，女人来自金星》说得清楚：男女在沟通、思考、感知、示爱、需求上全都不一样。

我们从小几乎没人教过谈恋爱怎么谈、怎么懂异性。学校只管学习，早恋被禁止。长大后没经验、不敢接触，想渴望又羞于开口。到了适婚年龄被推着相亲结婚，随后就是离婚循环。

很多人困惑：反正结了也离，大家都不认真，你骂渣女她骂渣男。

我此前在群里调研过，高频痛点有：

* 怎么把感情里的配得感升级成你值得
* 如何复盘过往恋爱经验变成自己的方法论
* 母胎单身零经验怎么找到合适的人
* 筛选大于培养，如何提高选中好人的概率
* 钢铁直女/直男如何不知不觉变成聊天黑洞
* 相亲线上线下破冰增好感怎么做

大量人渴望幸福却因缺经验、看不清真相而稀里糊涂。

2. 这是我真心热爱的方向

情感是我敏感且实战经验最足的领域。小时候起就经历告白、约会、恋爱、分手循环，对男生的了解可能比很多男生还深。手上的异性样本多到数不清，身边朋友的情感困惑第一个找我，连负面情绪我也能稳住。

之前边谈边复盘，却从没想过做情感IP。今年中旬才正式决定做个人品牌。我的性格就喜欢做自己热爱的事，不怕没掌声。初心很简单：每个人都值得一段好的感情。

以前朋友问我聊这么多男生不浪费时间吗？我很认真在筛未来伴侣，想在年轻时找到最不后悔的人，所以找对象我很认真也很策略。既然我能做到，渴望幸福的人也能被带动起来。

# 3. 课程围观群的裂变、转化与成交方法

我曾犹豫见证群要不要收费，靠谱姐说一般不收，约一个月内推课。接下来从7个环节拆解这次围观群的全貌。

### 4.1 社群冷启动：发布宣告文

条形马老师比喻很形象：朋友圈是广播站，社群是小集市。冷启动的核心是从哪来人？主页通知、兴趣小组、朋友圈、👸号、好友群发都行。我主打朋友圈。

先发招募/宣告文：我要做【实战篇：恋爱聊天脱单课】，扫码进群围观做课，群内可免费提问。这样正式且精准，进来的人都带需求。

### 4.2 分享真实案例激发讨论

我在社群运营圈子里读到过一段话，至今印象很深：判断一个人有没有领导力，并不只取决于他本身有多强，也不只取决于他能不能掌控最终决策权。还有一个很关键的因素，就是：当他发出指令时，有没有人接住他。只要有一个人第一时间跳出来回应，一个最小化的领导力闭环就已经成立了——这个回应者，本身就是号召的“正反馈”。

这段话一下子点醒了我。那时我正准备做情感社群，但粉丝基础几乎为零，更没有人愿意陪我演双簧。我该怎么让群友愿意搭理我？我想来想去，觉得最接地气的办法就是：抛真实案例。

恰好那时有个朋友来找我聊感情问题，她的性格是典型的“钢铁直女”，聊天记录自带槽点。我征得她同意后把内容脱敏发到群里，让大家一起讨论。结果讨论度出奇地高，很多人说“这话题有意思”。群的热度一下就被点燃了，大家的目光全聚过来。我没有立刻输出，而是先让他们聊个痛快，最后由我收尾，分享我的分析、我遇到的类似情况，以及我当时的做法和拿到的结果，用活生生的个人案例做补充。

关于裂变，我总结过三种有效路径。

第一种，真诚利他，放下成交心。什么样的人适合做社群？我记得有人总结过：真诚的人、喜欢分享和交流的人、扛得住冷清和挫折的人、愿意走近人并理解人心的人，才是先决条件。我做情感IP的出发点，是希望帮更多人经营好幸福的关系。我相信每个人都具备经营感情的能力，只是缺方法而已。所以我的裂变思路很简单：认真回答每一个问题，不施压，也不要求谁必须拉人，只会在赠送资料时提一句：“这是送你的见面礼，有问题可以在群里免费问，身边有脱单需要的人也可以邀请进来。”效果反而很好——很多我根本不认识的人，看完我的分享后主动拉了朋友进群。核心就是把利他心态放在前面，把成交心放到最低，真诚自然会换来信任。

![](img/b6cb535e7764dfecee7ffb117befa053.png)

第二种，持续干货输出，打造好口碑。刚拉群时，我先做自我介绍，说明为什么要建一个“免费围观群”来见证我做课的完整过程。然后每天固定分享干货，内容包括：身边真实案例、个人实战经历、两性聊天技巧等。如果有新人进群，我会把往期精华打包再发一遍，然后继续当天的分享。虽然没有刻意推销，但干货分享的第二天就有小伙伴主动打钱买课。我提前预告了课程价格，却没有急着收割——因为还有人在围观，当下的任务依然是消除顾虑。后来群友觉得真的有收获，开始自发拉身边的亲朋好友进群，正向循环就这样滚了起来。正是因为分享的内容足够颠覆认知，群众才愿意推动群众。

第三种，分佣。裂变通常有两种驱动力，一种是口碑驱动，另一种是纯分佣驱动。我分配给推广者的佣金是50%。但我敢分佣的前提，是口碑已经立住了。如果自己的口碑不硬，分佣就等于消耗帮忙宣传者的信誉。先把自己的口碑做好，才能维护好宣传我的人。

正式预售阶段，我选择了七夕前三天，也就是8月20日至22日。节奏规划得非常紧凑，中午和晚上都会做干货分享，同时用接龙的方式锁定报名。

先重新自我介绍一遍。群里很多人是中途进来的，可能没看过我的自我介绍，为了让大家知道“我是谁”，这一步不能省。

在最后两天预售期，为了让更多用户被触达，我用了“四连击”的方法：早上抛出一个情感疑问，让群友自由思考、畅所欲言，然后发一次报名接龙；到了中午，我把早上的疑问拆开讲透，再发一次接龙；下午重复这套动作。一天下来能有四次接龙触达，而且每次发都有人报名。这个方式能潜移默化地种下认知种子：先让大家自己思考，然后我给出颠覆常识的答案，他们就发现“原来聊天还能这样聊”，于是主动接龙。千万不要直接给答案，否则群友会误以为“我也这么想”，反而低估了你的干货价值。

我记得有一次凌晨，群里有人聊起了不符合正常恋爱价值观的内容，而且越来越过分。如果不是靠谱姐、馆长、理白及时、理性地干预，肯定会伤及群友信任、破坏群氛围，甚至导致大量流失。第二天白天，我作为群主又重申了正确的恋爱价值观，希望大家共同维护聊天边界。

任何社群都有生命周期。这个免费围观群的定位从一开始就很精准：需要脱单、不擅长相亲聊天、想提升恋爱能力的人。我做课期间免费分享干货，也提前预告了“课程会在第六节课完成后开始预售”，所以这本质上是一次“内测”，在测试痛点的同时丰富课程内容。当群的价值已经实现，就要及时解散，避免变成广告垃圾场。解散前，一定要留下个人🛰️名片。靠谱姐又及时帮我发了名片，哪怕之后有人爬楼看到，也能多一次用户触达。

做这个项目的过程中，朋友圈的同步造势也必不可少。产品圈会透露做课计划和“可以来围观、免费提问”的诱饵，吸引更多人进群。

时间规划上：8月10日到14日，朋友圈宣告拉群、明确裂变主线；8月10日到23日，群内自我介绍、每天干货分享、免费答疑；8月20日到23日，趁七夕节点做三天预售；8月23日，解散免费围观群。海报就是把课程目标加上“免费围观群”几个字，但说实话我对那张海报并不满意。

朋友圈文案的触发节点包括：宣告开始做课、人数一晚拉满时、群内领取资料时、答疑被好评时、干货分享时、别人拉亲友进群时、有人主动询问课程时、准备预售时，以及解散群道谢时。

复盘下来，这次也有明显不足：一是新人欢迎语没有提前准备，临时拼凑；二是海报做得不够好，没有达到我理想中的质感。

不过，也正是这些不完美，让我更清楚下一次该怎么迭代。

最近复盘自己做社群和发售课程的经历，发现有几个地方特别值得记下来，也分享给你。

先说海报这件事。当时我做的海报上只有课程大纲目录，其他什么都没有——没有个人介绍，没有课程简介，没有课程特色，没写适合谁，也没说学完能得到什么。现在回头看，这海报确实太单薄了。下次再做，一定要把这些信息补全，让看到的人能快速判断这门课值不值得跟。

再说群公告。建群第一天，我其实没明确说“禁止发广告”。当时觉得，在别人群里不打广告应该是共识吧？结果没过多久，就有群友在群里发自己的票务广告。最直观的影响是，那会儿很明显有两个人直接退群了。所以啊，有些规矩不能靠默认，该说的一定要第一时间说清楚。不然群就会失去意义和价值，人也留不住。

然后是整体节奏。运营那个见证群的时候，我基本是凭感觉在做，边做边发现问题边补救。虽然“先完成再完美”这句话没错，但确实希望下一次能更有计划、更从容一些，而不是一直缝缝补补。

最后想说点心里话。这是我第一次做社群，第一次发售课程，也是第一次搞免费围观群。单靠我一个人，根本不可能完成。很幸运在赚钱航海里一路成长，还能把这些经验用在自己的社群里，赚到了意料之外的收入。特别感谢靠谱姐，在我需要的时候总能给出合适的建议和动作；感谢芷蓝姐，不厌其烦地点评指导我的朋友圈；感谢理白在写作上给我的帮助。这三位真的是我人生中的贵人。
