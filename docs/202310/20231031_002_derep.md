# 与别人合伙开公司要注意哪些事情？
作者：龙哥

创业路上，很多人栽过的跟头，就是找几个熟人合伙开公司，业务跑得动，经营却一塌糊涂。到头来，兄弟情义变成了撕破脸的仇怨。上周六我在西安做了一场线下闭门分享，现场聊的就是关于合伙与公司治理的干货，不少朋友没到场，觉得遗憾，所以我把核心内容整理成文字，再发一次。

先简单自我介绍：我是龙哥，坐标西安，做天使投资，也做过近二十年企业，行业涉及旅游、软件、设计施工、新媒体等，先后创办过两家两千万营收的高新技术企业，辅导了三十多家创业公司，投过五家互联网公司。过去花了不少学费，系统学过各类老板课程，现在主业是企业咨询，专门帮中小企业诊断合伙、股权、薪酬、管理这类老毛病。

我发现很多创业者的通病是：懂业务，不懂商业逻辑，更不懂公司运作。几个人凭一腔热血凑在一起开公司，结果往往是“兄弟式合伙，仇人式散伙”。为了避免这种结局，分享三个最容易踩坑的板块：

1、公司怎么注册才算正规？
2、合伙人中途想退出，怎么处理才不伤和气？
3、发工资的十二种错误方式，你踩了几个？
