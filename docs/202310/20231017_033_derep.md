# Stable Diffusion 生成数字人视频实操教程，解锁流量密码

用Stable Diffusion做数字人视频？这份避坑实操指南请收好

大家好，我是小辉AI教练。最近我一直在折腾怎么用SD生成数字人视频，试过不少路子，也踩了无数坑，总算是把门道摸清了。这期就来聊聊我的实操心得。

网上的教程几乎清一色默认Windows环境，原因嘛，离不开Ebsynth这个依赖——它目前没法在Linux上跑。为了这，我还特意租了青椒云的服务器，花了小几十块，结果依然没能生成。后来我悟出一个关键：其实根本不用死磕Windows，Ebsynth任务完全可以离线处理。

后来我又尝试了Temporal-kit流程，同样是一路踩坑，好不容易到收尾一步，直接报错，整个方案只能作罢。

关于具体怎么做，视频演示和配套资料我都整理好了，放在文末的飞书文档里（视频在这里发不了）。有需要的圈友可以自取，觉得有帮助的话，别忘了给我点个鼓励。
