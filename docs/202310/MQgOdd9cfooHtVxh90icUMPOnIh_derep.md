# 《从直播亏掉200万到闲鱼月净利20万：我的起盘实战与避坑笔记》
作者：龙哥

大家好，我是龙哥。00后，目前在做互联网已经超过六年。

17岁那年我开始接触微商，18岁就带起了万人级的团队，自己也操盘了品牌做出了量。2020年疫情期间，我放弃了985的学籍，出来创立了自己的直播公司。2021到2022年，我在广州跑了一个5000平的直播基地。这一波大起大落后，今年我把盘子收了重来，转做闲鱼，目前团队月度净利润稳定在20万左右。以上全部是亲身经历，没有夸张。

# 为什么我一直能扛下来

第一，我是从底层出来的。家境不算好，一个女生想向上，靠不了家里，只能靠自己去改变结果。

第二，小时候家里条件紧，物资匮乏让我很早就明白，靠打工改变命运和家族现状是不现实的，必须找到放大杠杆的方式。

第三，关于伴侣。我一直相信能量守恒，自己的价值匹配不到位，再好的另一半也留不住。靠嫁人翻盘是最高风险的赌博。创业除了赚钱，更是精神上的成长和阅历的积累。自我价值实现了，物质和精神都能自给自足。爱情是甜点，不是主食。

以上只是我个人的认知，尊重每个人不同的奋斗信念。

# 六年互联网，我到底拿到了什么

1. 微商起步期
从18岁开始，我一边读高中一边全国各地飞去带团队、做培训、讲交付。那段日子被很多人唾弃，但正是这段经历给了我：敏锐的商业嗅觉、灵活的团队管理与公司运营能力，以及第一笔原始资金沉淀，约300万。

![](img/d8d593c228e48d71905a397c6c41db99.png)

互联网给我最实在的回报：20岁在广东付首付买下第一套房，总价160万左右，还给老家父母买了一间店面约30万。从16岁开始我没向家里要过一分钱，每个月都会反哺父母，具体记不清了，反正想起来就打。

2. 直播带货期
2021-2022年运营5000平直播基地，最后是亏损收场。这段经历最大的收获不是销售额，而是一个认知：永远不要去赚认知之外的钱，认知没跟上就不要撬动资本杠杆。

我们很早就在做视频号的护肤IP账号，从19.9、29.9、39.9的低客单起量。最大的失误是认知没跟上，应该趁第一波流量红利把客单价拉高，同时把私域后端接上。当时没做到，结果钱就在嘴边没吃到嘴里。

3. 直播也让我完成了18岁的某个小梦想，虽然目标不大，对我这个年纪来说已经很满足了。

![](img/f5aba2b6fd80a12c24f6d335671a4674.png)

特别提醒：看到这里很多人会以为直播很赚钱，我先别急。我的观点是，有本事就做自己能赚到钱的，别盲目跟风大众赛道。

两年直播沉淀下来，我用钱买到的教训是：

我20出头的时候，身体垮了。每个月几乎都在医院跑，心脏、免疫力、胃都有问题。直播到凌晨两点，五点又要起床继续，长期撕心裂肺的高强度输出。我以为年轻可以拼，直到体检报告一张张出来，一次次扎针，异乡一个人扛工作、写脚本、运营账号，白天去医院，傍晚回公司，凌晨还在管团队。身体调养了一年都没好。23年2月我算清楚了投入产出比，跟我能创造的有效价值不匹配，加上赛道选择失误，我选择关盘养身体。直播总体下来亏了200多万。

# 为什么最终落脚在闲鱼

我选闲鱼，是因为门槛低、回款快、上手简单、资金压力小，竞争远不如抖音、快手、视频号。

三月份切入投影仪，当月收益4万。四月份开始扩号到2-3个，手里纯利做到10万。五月份投影仪盘子加上团队复制，总收益17万。六月份我开了第一家公司换货盘，九月份又换了三次场地，规模持续扩大。

# 闲鱼起盘，选品决定生死

我从没投过一分钱推广，全靠选品。选品对我来说就是定江山。

我的选品原则

第一，不做无货源。无货源不稳定、做不深、利润撑不起野心，而且风口已经过去。从抖音小店搬运到📕打击无货源，都在证明这条路走不通。要顺势而为。

第二，选小众、看起来贵、市场价格不透明的品。这类品竞争小、利润空间大、好维护。

我不会碰的品：小家电几块到几十块利润的，或者风扇、空调这类200-300元的红海。利润太薄，竞争太激烈，闲鱼流量是固定的，分到你手里的少，成交率还不一定高，白忙活。

第三，选大众刚需且普遍觉得贵的品。这是我的核心逻辑。

第一个爆品：投影仪。近两年生活品质提高，投影仪逐步替代电视。配合剧集、短视频的宣传，认知在普及，属于新品类，竞争还不大。我们对标吉米、当贝、坚果这些高端品牌，用平替思路切入。相当于当年华强北平替苹果的打法。没有牌子，其他配置接近，价格便宜4000元，质量好，用户反馈不错。精准卡住“想要高品质又不想花大价钱”的需求。三个月让工作室翻盘。

结果：三月4万，四月扩号后纯利10万，五月17万。

第二个稳定盘：笔记本电脑。大学生开学、毕业、实习是刚需，每年循环。客单约2000元，单台利润保底500-1000元。投入产出比高，所以我能快速扩公司、招人、站稳。

第三个阶段品：全新苹果手机。这周刚启动，单台利润1500-2000元，一个号一天10台左右，一个号日利润稳定1万。马上要复制第二个分公司。

选品就是翻盘的机会。现在的电商已经不是拼技巧的时代，是拼货盘和选品的时代。

# 心态才是稳步起量的核心

有能力的人，去做自己擅长赚钱的，别去追大众赛道。我当年直播基地亏200万，就是项目太多：多多、闲鱼、淘宝、视频号、抖音、快手无人直播，什么都想做，最后一个都做不精。不要捡了芝麻丢了西瓜。人的精力是有限的。

找到适合自己的赛道。我视频号直播随便一个号月入几百万上千万，但需要付出百分百的精力。而现在的电商，我每天直播8小时后额外做，精力只花40%左右，收益却更稳。这是这些年我感受到最踏实的那种钱。微商和直播赚来的钱，后面慢慢都流失了，人生大起大落验证了这一点。

我只想分享我的实操经验，帮助还在迷茫的同行少走弯路。很感谢赚钱这个圈子，让我能把干货拿出来。也欢迎一起做电商的小伙伴交流，知无不言。
