# 从零基础到抖音IP变现过万：我的细分赛道实操复盘

## 纯小白如何切入抖音IP细分赛道，实现月入过万

大家好，我是龙哥。

大概一年前，我加入了赚钱社群的抖音 IP 大航海 2.0 训练营，当时的主攻方向就是做自己的课程并完成变现。距离那次经历过去一年了，今天想把过程中的踩坑和转折梳理出来，给同样想从零起步的朋友一些参考。

**第一步：撞墙期，摸着石头找方向**

刚进航海组的时候，大家其实都很迷茫，不知道选哪门课来做，也没有卖课的实操经验。那21天基本就是跟着项目组节奏走，最后的数据并不理想。

我当时锁定的是 Excel 赛道，思路是先用 Excel 教学短视频做内容引流，再挂靠别人的课程做代销分佣。结果整个周期下来，几乎颗粒无收。

作品的播放都很拉胯，连直播间都冷清到尴尬的地步。我至今还记得有场直播，房间里就站着两个人，自己一个人硬撑着讲完的感觉。
