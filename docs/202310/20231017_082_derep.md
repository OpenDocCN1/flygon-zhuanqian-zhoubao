# 在📕商业赛道里，我孵化出2个盈利项目，月流水已经破百万



## 📕做商业，两个项目在跑，月营收合计已超100万

作者：昊总
日期：2023-10-09

大家好，我是昊子。投资、战略都做过，全网的商业粉丝加起来10万+，现在的主阵地是📕。目前创办了青澜咨询，核心业务就是📕商业流量的变现。公司手上正好有2个已经盈利的项目，两个加起来的月营收超过100万，主要聚焦在知识付费的商业化变现上。

很久没出来更新了。之前在龙哥盟分享过我做社群的实操心得，还被龙哥老师选为精华帖。具体内容可以看这份资料《📕从0到1，起盘我0元做起一个社群，单月变现8w+的经验》[https://wxqp5aw3pm.feishu.cn/docx/K4zfd2djsoEAdWxTaXrceSf9nLf](https://wxqp5aw3pm.feishu.cn/docx/K4zfd2djsoEAdWxTaXrceSf9nLf)。时隔近半年，我的模式已经从个人单干，完成了向公司化、团队化运营的升级。

想重点说一句我的感触：当你把0到1跑通之后，一定要马上做体系化、团队化。先把流程和组织搭起来，这样才能抗风险，也才能把收益做大。我觉得纯个体户、数字游民的方式，只能当成一个过渡阶段，真正想长期做下去，团队是必须的。

下面简单概括一下我们现在操盘项目时依赖的两个核心打法：自动化矩阵运营 + 精准流量投放。因为篇幅关系，详细方法论我放在了飞书文档里：[`s0udwk13bl8.feishu.cn/docx/OzgUdha38okA8xxPkWIcLkgmnic`](https://s0udwk13bl8.feishu.cn/docx/OzgUdha38okA8xxPkWIcLkgmnic)，感兴趣的小伙伴可以自行查看。
