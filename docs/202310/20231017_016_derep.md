# 决定对不对，别只看结果

我们总习惯用“成王败寇”的逻辑去评价一个决策——结果好，就是高明；结果差，就是失策。可这种判断方式，真的理性吗？

曾经有研究者问一群年迈的高管：“这辈子做过最正确的决定是什么？”他们的回答出奇一致：全是那些最终收获了好结果的决定。

这听起来顺理成章，但背后却藏着一个思维陷阱：我们太容易用结果反推决策质量。可事实上，结果里往往混着运气，而决策的好坏，应该看它背后的道理。

举个极端的例子：两个人买完菜回家，一个图省事直接横穿马路，另一个老老实实走过街天桥。结果，走天桥的人偏偏被雷劈了，横穿马路的人反倒毫发无伤。那么，谁的决策更好？

当然还是走天桥的那个人。因为从概率上讲，天桥更安全，出事的可能性更低；被雷劈纯属小概率意外，不能因此否定他做了明智的选择。

再想想生活中那些劝烟民的话——“你太爷爷又抽烟又喝酒，还爱赌钱，不也活到九十多？”这就是拿个别案例去否定统计规律，用运气代替理性。

决策真正的依据，是概率，是权衡收益与损失之后的选择，而不是“一定会有怎样”的承诺。所以，评价一个决策时，别只盯着结果，还要分清哪些是运气，哪些是过程。

至于如何精确计算概率，那需要更多的数据与判断依据，是更复杂的话题，今天就不展开了。
