# 凯文凯利 & 杜晨 采访中文翻译稿
作者：龙哥

凯文·凯利来了！这位《连线》杂志的创始编辑、无数人眼中的“科技预言家”，最近又带着新书和大家见面了。很多人都喜欢叫他“未来学家”，但他本人却对这个称号有点“不以为然”。他说，真正的难点不是预测未来，而是看清当下——这句话，值得细品。

这次他来中国，第一站就是上海。距离上一次踏足这片土地已经过去了四年，他坦言对这座城市的最新发展其实并不算特别了解，但这恰恰是他来的原因：想亲眼看看，这个国家正在经历什么。他尤其关注中国在人工智能和制造业上的结合。他有一个大胆的想象——在不久的将来，会出现一款由中国制造、像iPhone一样风靡全球的电动汽车。至于具体会不会诞生在上海，他没有轻易下结论，因为他深知，隔着太平洋去观察一个国家的真实面貌，太难了。

关于“预测”这件事，KK有一套自己的哲学。他说，几乎所有的预测都可能出错，但一个错误但积极的未来愿景，仍然有价值。他不是在预测未来，而是在帮助人们为未来做准备。而“预测现在”为什么难？因为世界有几十亿人，每个故事都千差万别，媒体报道和抽象概念常常会遮蔽我们的眼睛。他花大量时间研究AI，正是为了剥离这些噪音，去看技术被真实使用的样子。

谈到AI，KK的观点很有意思。他说，目前AI的进展被高估了，但长期影响又被低估了。眼下最热门的大语言模型，本质上是“模仿”——它能模仿天才的逻辑、一本书的精华，但它并不拥有真正的智慧。他打了个比方：在语言和文字里能学到的智慧，AI都能模仿得很好，但人类的智慧还有大量无法被语言捕捉的部分，比如行为方式。所以现阶段的大语言模型就是个“书呆子”，聪明，但局限。

那怎么消除对AI的恐惧？KK的回答特别简单直接：每天用它。用得越多，你越会发现AI和人的思维方式差距还很大。真正害怕AI的，恰恰是那些不碰AI的人。

他每天都在用AI，但不是一键生成那种——他说和AI共创美术作品，其实和摄影差不多，要反复找角度、调光线，一张好画可能要花上一个小时去打磨。他还会让AI做信息摘要、结构化整理，甚至生成创意。不过他强调：AI只是实习生，它的产出需要你校对、润色、重写。AI最擅长的，是把那些原本不会同时出现的元素、风格和理论，融合在一起。

这次的新书叫《宝贵的人生建议：我希望早点知道的智慧》，500多页短句，像一本没有故事、只有建议的“圣经”。他原本不觉得自己爱给建议，但写着写着就停不下来。他定下了三个标准：第一，自己实践过；第二，简洁好记；第三，积极正向，不带讽刺。他说自己还在继续写，享受着把复杂思考浓缩成金句的过程。

有人问他：你会不会担心自己的作品不够好？他提到了“冒名顶替综合症”——很多人觉得自己不配被认可，但KK的态度是：你只要真诚地表达自己的观点就够了，不需要头衔，也不需要百万粉丝。如果你真正独立思考，而不是模仿别人，那你就是创造者，何来“冒充”一说？

至于怎么给别人提建议？他的方法很简单：讲自己真实的故事。别人觉得有用就采纳，觉得没用就忽略。建议的价值不在于说服，而在于提醒。

他特别相信热情的力量。招聘时，他宁可要一个热情的人，也不要一个绝顶聪明的人。聪明人往往高估聪明的价值，但伟大的成就还需要勇气、毅力和想象力。而乐观，是一种极其宝贵的品质。悲观者很难获得高水平的成功——你不会为一个自己都不相信会发生的事情投入一周80小时。那些修铁路的人、相信疫苗的人、梦想登月的人，共同塑造了今天的世界。

有人问：现在AI爆发、经济下行，环境这么糟糕，乐观还有用吗？KK说，当然。他自己不是“保持乐观”，而是每天比前一天更乐观。乐观不是情绪，是一种选择。两个方法：一是读历史，读得越多，越清楚今天的进步有多可贵；二是用复利视角看世界——每年进步1%，三十年后的变化会是巨大的。眼光放长，自然乐观。

最后，关于网络上的无意义争论，KK的建议是：不要卷入。大多数争论的本质不是理性，而是情感。想改变别人，需要的不是逻辑而是共情——理解他为什么相信，才有可能影响他。与其批评和破坏，不如创造更好的东西。他说，愤怒很廉价，他更愿意关注那些在建设、在创造的人。

至于那句让人印象深刻的话——“那些真的相信自己在对抗邪恶的人，也许他们才是邪恶本身”——他用这句话提醒我们：真正的善意，往往始于反思。

凯文·凯利：最危险的邪恶，是“虔诚地做坏事”

凯文·凯利说，最危险的邪恶，常常不是坏人的故意，而是好人的虔诚。纳粹、美国奴隶制的捍卫者、发动911的极端分子，都真心相信自己是在替天行道：他们认定自己正与邪恶作战，于是义无反顾地制造了更大的恶。所以他给出的提醒是：若你想消灭世上的邪恶，先要小心自己的信仰是否正在把你引向深渊。

类似的陷阱，他也曾在科技创始人身上一再看到。他认识很多人，也相信他们说自己“想改变世界”并非虚言。但绝对权力是一道考验，甚至比逆境更难通过。一个创始人在不知不觉中就会滑向腐化：他会越来越相信自己是正确的，会说服自己那些灰色手段都是必要成本，结果是好的就够了。问题是，许多决策在当下看来顶多算“妥协”，放到十年后回望，却可能是灾难。凯文·凯利也愿意承认，至少这些创业者在创造新鲜的东西。

凯文·凯利特别提醒，我们对过去常常过于苛刻。每个时代有每个时代的尺度。今天被认为是野蛮的事，在几十年前也许是天经地义。他举了个例子：杀猪吃肉。一千年后的人看我们，大概很难理解为什么非要把猪杀死才能得到猪肉，他们会觉得这个时代残忍。但反过来说，我们今天定义的正确，到了未来也可能显得愚昧。所以，不要轻易用此刻的道德标准去审判前人。

可这不是说科技创始人可以被豁免。凯文·凯利欣赏他们想要科技向善的心愿，却坚持认为他们必须接受媒体和社会的制衡。受到监督肯定会令人不快，但这是让他们不变成“恶龙”的机制之一。他也不会对创始人过于苛刻，因为那个位置本就不容易应付。有些批评只是噪音，忽略无妨。他同样觉得，过度政治正确并非好事。而真正想让那些创始人记住的批评，最有分量的方式，是你自己也做出一个独角兽公司。

关于提问，凯文·凯利的态度非常直白：在他那里，“愚蠢的问题”并不存在。我们觉得自己问了蠢问题，多半是因为想象别人都懂。可不懂就是不懂，承认困惑才能往前走。他讲到自己参加AI讨论时，听到别人说“TPS”，他会当场问那是什么意思。这个问题在行家看来也许很基础，但对他而言是真实的困惑，所以他选择问出来。“知道就知道，不知道就不知道”，没什么好羞耻。

这种坦诚，也体现在他的写作观上。新书《宝贵的人生建议：我希望早点知道的智慧》只有500多段，每段都像电报一样包藏着复杂的判断。因为他不讲故事，只讲结论，所以文字被压缩到接近诗意的密度。他做过《连线》杂志编辑，明白一段文字同时要短、要清楚、还要打动人，非常不容易。有时候必须有篇幅、有修饰才能让人记住。所以他说，“简单删掉冗余”和“种子写法”的区别没有想象中那么大。种子式段落更接近诗：诗不替读者把话说尽，而是在字里行间留出空间，让读者自己去思考。因此这本书需要慢读，有人看了两页就停下来，因为光是阅读还不够，剩余的部分要在脑子里完成。他原本的设想就是让人每天读一条，像在Twitter上每天刷一条那样，也讨论过要不要做成一个每天弹一条建议的App。

在凯文·凯利那里，建议是从哪里来的？他说自己很幸运，遇到一些值得尊敬的导师和同事。他重视的是智慧而非智商，会去关注一个人真正的生活排序：如何取舍、如何决定优先级、如何为人处事，而不是听对方说了什么漂亮话。他提到，恒今基金会中的许多人都有更宏阔的时间视野，和他们相处，他自己的智慧也在增长。

当谈到最担心谁时，杜晨把她的一票投给了埃隆·马斯克。她承认马斯克在改变世界，但也做了很多糟糕的选择；他傲慢、缺乏同理心，却拥有大量崇拜者。凯文·凯利如果只能给一位巨头提建议，他会对马斯克说：离开Twitter。“如果他再也不碰这个平台，一半问题就自动解决了。”这句话带刺，但未必不是真。

凯文·凯利还分享过自己与有钱人的相处经验。他曾在一群亿万富翁面前宣布自己才是全场最富的人，因为他完全拥有自己的时间。他劝年轻人尽量不要成为亿万富翁，因为那是份无法辞职的苦差：钱多到花不完，于是每一分钟都被责任缠住。金钱只是工具，不是目的。成功不该用财富衡量，也不该用别人的定义。能活成自己的样子，比富有重要得多。

他同样反对“成为下一个马斯克”式的野心。KOL这个赛道已经挤满了人，做别人做过的事没有任何优势。更好的办法，是去做那种尚未被命名、却属于你的事情。就好像十五年前，你说自己在做“播客”，对方大概会觉得莫名其妙。凯文·凯利说，你要拿回自己人生的剧本，而不是在别人的电影里跑龙套。这世上已经有了一个马斯克，他是唯一的；你也应是唯一的，哪怕不是最好的，也没关系。

那凯文·凯利自己呢？他依然在写关于技术和社会的书。眼下这个项目叫“理想百年”，不是预测，而是推演100年后的世界可能长什么样。他想象公元2125年，人工智能和基因工程都已成为日常，生活不是乌托邦，而是一种“进托邦”，并计划覆盖体育、时尚、食品等上百个细分的领域。

与此同时，他选择了“激进的乐观主义”。高中时他在艺术和科学之间犹豫过，最后选了科学，但他偶尔会想：如果去学艺术，也许会更快乐。他也觉得人们太过看重智商——把爱因斯坦和老虎关进同一个笼子，最后活下来的肯定不是那个聪明绝顶的人。当AI的智商越来越高，人类真正要寻找的，是智商之外的品质。这也是他常年思考的问题。

那天访谈结束时，杜晨说，这是一场很棒的对话，即使她可能问了些蠢问题。凯文·凯利纠正她：没有任何问题是愚蠢的，而且这次采访中确实有几个他从没遇到过的问题，这让他很开心。
