# Friend.tech 经济模型拆解：博弈、期望与一张被误读的需求曲线
作者：龙哥



作者：龙哥的收藏夹
发布时间：2023-10-12

表面上看，Friend.tech 的玩法设计极其简洁，几乎可以用三句话概括。

第一，持有者的 Key 并非固定价，随着发出数量的增加，价格会一路向上抬升。
第二，每次买卖都会被抽取 10% 的费用，这笔钱一半归协议方，一半归到 Key 的发行人也就是 KOL 本人。
第三，平台承诺在接下来的半年周期内，通过积分的形式回馈给参与用户。

就这么一个模型，却被迅速放大成一场关于社交代币的博弈实验。

如果把设计权交到你手上，你会如何权衡增长曲线、抽成比例和激励发放这三者之间的张力？
