# 4个月，30万流水，我把家教中介做成了副业现金流

各位老铁，鸣风，马姓。今天不聊主业，聊一个我从五月份就开始跑的副业项目：家教中介。

先交代背景一下，我白天主要在带一家做设计和软件开发的信息科技公司，这只是我的兼职线之一。很多人对家教中介都不陌生，但真正把它当成一个可复制的生意来做的人不多。我从5月启动，到现在累计变现已经超过30万。下面把实操思路拆给你看，详细记录我也整理在这里了：[`uqp3l475ckb.feishu.cn/docx/KU0Edh7pToq6NkxvmrOc550Pnib`](https://uqp3l475ckb.feishu.cn/docx/KU0Edh7pToq6NkxvmrOc550Pnib)

为什么这个赛道稳？因为它抓的是家长的刚需。孩子成绩、升学焦虑永远在那儿，市场需求不会断。

执行上核心就三件事：老师资源池、精准获客、标准化收费。

我没有自己去上课，我做的是撮合。老师是我长期沉淀的资源，家长端则通过社群、口碑和信息差快速触达。成交后，我的收费逻辑很清晰，跟评论区朋友聊得一样，通常是按学生前两周的课时费来收中介服务费，具体比例一般在80%左右。也就是家长能立刻感受到性价比，我也能快速回款。

有人问我主要做哪个学段。实操下来，各阶段都有需求，但重心是家长付费意愿最强、决策最快的段位。模式跑通后，复利效应就来了，一个学生转介绍一个家长，一个家长带来一整个班级的需求。

说到底，这就是一个低成本启动、高现金流的轻服务生意。不需要囤货、不需要重资产，只要你愿意把供需的链路搭起来。
