# 你选择向谁看齐，就决定了你能走到哪
作者：龙哥

这个结论，我是周末带孩子去见一位艺术老师时听来的。

聊到今年诺奖文学奖的热门名字残雪，他说残雪的文字气质很明显来自卡夫卡，她几乎是把卡夫卡当成自己的引路人。而在文学史上，几乎没有一个巨匠是凭空出现的。张爱玲的灵韵里藏着《红楼梦》的影子，海明威的《老人与海》那种宿命的悲壮，则被很多人解读为受了莎士比亚《李尔王》的影响。

大师都有师承，差别只在于师承的高度。你跟谁学，基本就把天花板锁死了。

他举了个画画的例子。如果你一开始就去照着陈丹青练笔，那你往上追溯，陈丹青自己也是有老师的，刘晓东背后也有源头，层层递进。再往上走，如果你直接对标毕加索，那已经是在顶层打转了。可毕加索自己又向谁致敬？他吸纳的是宗教、文化、哲学这些更根本的力量。

再看近代中国画家常玉。他的画为什么干净、安静又透着贵气？因为他内在的老师是佛学，而外部条件又给了他极好的自由度。加上他身边常年围绕着徐悲鸿、林风眠、毕加索这样的巨擘，视野自然被拉开了。所以他的作品在西方市场被高度认可，如今一幅就能破亿。

广告这行也一样。刚入行时，我们模仿奥格威、伯恩巴克，国内同行追捧许舜英。即使你把这些人的招式练到极致，也很难超越许舜英本人。说明许舜英之上，一定还有更大的参照系。

这些年我开始换赛道学习：战略、管理、哲学、符号学、传播学。学的对象不再是广告圈内的前辈，而是各领域真正奠基的人。一旦学习层级抬高了，看到的格局也就不一样了。

所以成长本质上就是不断升级你的模仿清单。把学习对象往上移一层、再上一层，你的上限自然会被重新抬高。
