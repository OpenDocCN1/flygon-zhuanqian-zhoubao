# 让人脸无限贴近真人的AI调教指南，玩转人像变现
作者：龙哥

大家好，我是龙哥，一名入行三年的AI图像工程师。平时最大的爱好就是拍照和钻研人像写真，再加上日常工作本就天天跟图像打交道，所以在选择AI深耕方向时，我几乎没犹豫，直接锁定了更可控的stable diffusion + 人像这条赛道。

在人物写真这块，我主攻的课题只有一个：如何让生成的脸，最大程度还原原图人物。今天这篇文章，就是我近三个月围绕人脸还原，通过多个专题实践总结出的一套出图思路、技巧与心得。我会从最底层的出图逻辑讲起，再到具体的优化路径，一步步拆解，希望能给同样对人像AI感兴趣的朋友一些启发。

- 怎样根据一张图像精准还原人脸？
