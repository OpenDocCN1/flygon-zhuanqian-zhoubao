# 两个老板的大学故事，让我重新理解了什么叫"真本事"
作者：龙哥

跑市场、见客户的路上，听两位创始人聊起他们的大学生涯，有两段经历让我印象极深。

先说说醉得意的彭总。他是室内设计科班出身，毕业那阵子还站过讲台，之后转型做策划公司，给华莱士当过乙方——"半天妖"这个名字，就是出自他的手笔。后来他把华莱士的部分门店接手过来，自己踏进了餐饮圈。如今醉得意单店营收还在稳步攀升，怎么看都带着一股逆势上扬的劲儿。

彭总入学早，当年学 3Dmax，学校里连一台电脑的影子都见不着。于是出现了特别戏剧性的一幕：全班同学整整修了三年的 3Dmax，除了彭总，没有第二个人碰过机器——连任课老师都不会，全程照着课本念。

那彭总怎么会？他大一就跑出去兼职，在一家设计工作室打下手，天天真刀真枪地练。结果后来，反倒是老师反过来跟他请教 3Dmax 的操作。

另一位是香氛品牌尹谜的沈总。他跟合伙人是大学同学，读的是某专科学校的电商专业。当时教电商的老师，自己压根没做过一单生意，上课也讲不出个所以然。

不过，那所学校的做法很让人佩服：从大一开始就想方设法替学生联系实习单位，把人往真做电商的公司送。沈总一进校门，就跑到义乌开干了。他们全班都一样——课可以不上，班必须去上。老师不会教不打紧，学校知道怎么让学生学到真东西。

就这么一所专科学校，电商专业后来却走出一大批金冠店铺的老板，全是沈总的师兄弟。

听完这两个故事，我挺有感触。

说白了，绝大多数本事是实践喂出来的。你在课堂上背一百条理论，不如丢到真事里摔打几天。那个专科学校为什么能人才辈出？答案就俩字：练得多。

中国高校的专业设置里，医学院的教学向来被公认为最有效，原因也不复杂——每所医学院都自带附属医院，学生还没毕业，就已经在真实的病房里摸爬滚打了。

所以我也很希望，每一所大学的每一个专业，都能给孩子留一点实战的窗口。哪怕只是提醒他们一句：别只会坐教室里念理论，走出去找个地儿实习、实践，收获都会大得多。

别到头来，学了一肚子概念，却连一件实事都干不利索。
