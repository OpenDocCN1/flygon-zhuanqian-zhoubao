# 学会谈钱，谈钱不丢人

以前我是个带点文艺气的人，总觉得自己跟“经商”二字绝缘。后来被生活推着开了公司，心里却一直别扭，觉得把钱挂在嘴边太俗气，不好意思大张旗鼓地讲。

但这些年我的看法彻底变了。我现在觉得，商业大概是人类社会发明出来的最奇妙的东西之一——正是那一套交换与协作的逻辑，才点亮了人类璀璨的文明。这不是往自己脸上贴金，是我打心眼里这么信。所以现在，我特别骄傲自己是个商人，也特别愿意大大方方地谈钱。

你看农耕时代的逻辑，讲究的是血缘和人情，适合熟人圈子。我小时候在农村，谁家要盖房子，哪有什么施工队可找？就是全村劳力一起上，你家出人，我家出力，完了主人家管几顿饭就算回礼。要是哪家平时总躲着不出力，等轮到自己盖房，院子里冷冷清清也是常事。

可如今呢？连村里都慢慢商业化了，修房、装修、办酒席，一切都能外包，掏钱就行，效率翻了好几倍。

商业社会本质上是个陌生人社会，不靠感情，靠利益交换和契约精神。我🛰️里有两万好友，99%都算不上真认识，不过就是加了联系方式而已。所以在这种环境里，谈事就得按商业规矩来，不能像对老熟人那样含糊。

有人约我吃饭，我说不好意思，真没空吃饭，有正事咱们电话聊，没事就不必破费了。有人想咨询品牌营销的事，我直接说可以，但要付费——我没有义务做免费顾问。当然，如果对方手里有我需要的资源或知识，那也是交换，是等价互换，不是交情。交情是熟人之间的游戏，头一回见面就别假装称兄道弟。

当我不再不好意思谈钱，日子反而过得清爽了，效率也高了不少。

当然，今天国内很多城市做生意还带着熟人社会的影子，越是小地方越讲究关系。好在我待在一线城市创业，不用靠酒局、送礼、人情世故也能把事办成。

谈钱没什么不好，真的。欢迎来到商业的世界。

评论区里也有位朋友分享了自己的故事：以前做纯公益读书群，大家不珍惜，后来转了付费营，学员反而认真听课写作业，于是果断解散了所有免费群。她说，敢于收费，是对彼此的时间负责。

深以为然。
