# 白手起家，创业者如何找到自己的战略势能？
作者：龙哥

创业路上的很多小咨询公司，都卡在同一个问题上：手里有本事，客户却不买账。

原因往往不是专业能力，而是缺少一套让客户“敢信任你”的底层设计。换句话说，在你开始卖服务之前，得先把适合自己的商业模式和战略路径搭好。这一步没走通，后面谈再多技巧，都是白费。

刘润曾经以润米公司创业期为例，复盘过自己如何从零到一，把商业模式一点点理清楚。他的经验很直白：白手起家的人，最该先找到自己的战略势能，而不是急着扑向市场。
