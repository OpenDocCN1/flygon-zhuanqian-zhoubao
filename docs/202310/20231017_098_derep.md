# 二本考研上岸双一流硕，转型考研辅导项目变现 50 万的经历复盘
作者：龙哥

你们可以叫我“这是轻舟”。

熟悉我的人，总喜欢给我贴一串标签：二本院校出身，后来考进一所双一流大学读硕士；从生化环材跨到跨境电商，现在是一名自由职业者；研究生毕业那年，账户里攒下了近30万。

最近三年多，最让我有成就感的一件事，就是把“卖考研专业课资料”这个副业，一点点做成了考研辅导项目，累计变现50万。

回想起来，故事挺有戏剧性。2020年考研时，我的第一志愿填的是江南大学食品学院的专硕，后来被调剂到湘潭大学化工学院。研究生还没入学，我就开始卖专业课资料了。从真题、笔记到辅导班课程，产品线慢慢搭了起来；B站、📕、🧣、知乎、社群，各种引流渠道几乎试了个遍，还摸索过不少野路子玩法。

怎么卖？我总结了一套自己的打法：梯度涨价、扩大流量、筛选用户而不是教育用户、用优惠预售锁定订单。

整段经历里，我更看重这几个环节的复盘：和用户的初次相识、靠内容发布促成转化、下单成交，以及我后面准备接着做的计划。踩坑经验和最终复盘，连同一些碎碎念，都放在了完整版正文里。

非常感恩芷蓝姐一路提供帮助，也谢谢理白学长和靠谱姐帮我把帖子改得更完整。
