# A16Z 创始人：创业中唯一重要的因素
作者：龙哥

在创业这件事上，绝大多数人都在拼命抓住那些看起来稳妥、却只能按部就班增长的机会。可真正的关键，不是把眼前的小利攥得死死的，而是要懂得识别那些能带来指数级爆发的赛道。捡了芝麻丢了西瓜，是很多创始人最容易犯的错。

A16Z 的创始人点破了一个真相：创业路上，真正值得你押上全部精力的，只有一件事——追求指数型增长。线性增长看起来很安全，但天花板就摆在那里；指数型增长起初可能不起眼，一旦起飞，就是质的跨越。别让眼前的小收益麻醉了你，也别让“稳”字绑架了你的判断力。学会放手那些只让你多赚一点的机会，把目光投向那些能让你完全换一个量级的可能，这才是创业中最稀缺的清醒。
