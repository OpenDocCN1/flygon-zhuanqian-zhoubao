# 从“卖自己”到“卖案例”：专业服务公司成长的必然路线



## 刚起步靠个人成名，规模起来后靠案例说话

作者：小马宋

日期：2023-10-16

刚起步靠个人成名，规模起来后靠案例说话

这是朋友徐昇在解读《专业服务公司的管理》时的系列思考之一，转发过来与大家共勉。

徐昇曾为我们小马宋做过辅导培训，也欢迎关注他的👸号“徐昇”。

1、绝大多数乙方公司老板一路走来，都会从松散的工作室形态，演进成体系化的公司形态。

2、在工作室阶段，客户买的其实不是一个机构，而是一个人，或是一个核心合伙人团队。

国内策划圈的开局如此，王志纲、高峻、叶茂中这些名字，客户找的都是创始人本人。

在客户眼里，老板本身就是权威，而且是有辨识度和口碑的权威。

3、要建立这种个人权威，老板必须持续输出：写文章、出书、讲课、发声，把尖锐且有洞见的观点通过合适的渠道投放出去，沉淀专属认知。

衡量标准很简单：老板在本行业客户圈层的认知度有多高。

这条路走得最狠的是奥美创始人大卫·奥格威。

很多人看过《一个广告人的自白》是在入行甚至入行之前，所以很难体会他写书当时的冲击力。

这本书销量至少在150万册以上，到今天依然在为奥美带来客户和人才。奥格威自己总结过写书的三个用意：给公司拉新客户、测试公司上市时的市场反应、提升自己在商业圈的知名度，一箭三雕。

他是在1962年暑假写的书，那时他创业已14年，1948年才起步。

而后面的从业者根本不用等那么久，比如叶茂中，正式创业前就把大量阅读心得整理成《广告人手记》，1996年就出版了，而他的公司要到1997年才成立。

4、工作室的经营思路，从来不是追求规模和增速，而是追求两件事：

· 打磨出未来可以作为口碑载体的标杆案例
· 培养能长期分润的合伙人型人才

小马宋在2017年刚创业时也说过类似的话：

“我现在就是想做一家小的咨询公司，核心目标是不做大，今年明年四个人就够了。”

“很多人创业就想快速做大做强，我也曾心动，但这不符合咨询的规律。

咨询公司需要一个个实战案例来打磨认知、迭代方法、孵化人才。

盲目扩张没有规模红利，反而会拉低服务水准，对公司长期，和客户双方都没好处。”

这一阶段管理的关键，是点燃团队的主观能动性。

5、当公司慢慢长大进入组织化阶段，宣传的重心就会从个人代言，转向项目实绩。

到后来，一页广告可能就是密密麻麻的客户logo墙。

这不代表创始人退场了，他依然会出现在著述和传播中，只是角色从主角变成了公司的代言人。

6、这时候客户要找的，是在特定问题上反复验证过的方法论和经验丰富的团队。

公司对外需要传递两类核心信息：

第一，我手上有很多同类项目的实操经验；
第二，我能把这些经验系统化、可复制地用在你身上。

因此要把成功项目提炼成商业案例，不断对外释放。

7、工作室升级为公司，内部的知识传递也会从师傅带徒弟，变成标准化、结构化的培训体系，让经验能在组织内部流动和复用。

8、随着客户需求越来越复杂，对知识沉淀和复用的要求越来越高，部门职能和组织架构自然成型。

公司也会把顶尖人才集中起来，深耕细分行业，形成行业专业化的小组或事业部。

9、到这一步，工作室时期的管理方式已经不适用了，管理复杂度显著提升。
