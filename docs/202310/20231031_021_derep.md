# 打开广告的那一刻，人心里其实在问三件事

最近重读赵毅衡的《符号学：原理与推演》，被一个点点醒：体裁本身就是在传递信息。媒介即信息，体裁也是信息。我们读诗和读小说时的心态就不一样，看广告时，顾客的心理预设同样不一样。

广告说到底就是为了促成一笔购买。这背后，接收者会本能地带着三种期待来看你。

**第一层期待：你可信吗**

广告本质上是说服行为，所以第一道门槛是诚信。观众要感受到你不是在瞎说，是在“据实而言”。这里的“实”未必是冷冰冰的事实，而是事实性。也就是一种让人信得过的姿态。

所以广告才要堆修辞、堆背书。要权威机构盖章，要写假一赔十，要上实验室数据。要把文本裹上一层可信的外衣，让人觉得发出者负责任。没这层信任感，后面全不成立。

**第二层期待：你和别人有什么不一样**

劝人买就得给理由。这理由就是区分度。便宜、好用、颜值、服务、独家……哪怕一点点差异都要被放大。区分越大，说服力越强。

如果实在比不出区别，至少要靠重复曝光把品牌名刻进脑子里。没有差异的广告，连广告都算不上。

**第三层期待：这和我有关系吗**

广告不能悬浮，必须能接上观众的生活经验和欲望。同一款产品全球通用，广告却不能全球通用。文化不同，关心点就不同，生活语境不同，代言人也不同。

书里提到征兵广告的中美差异很典型。话语体系完全不一样。再比如能量饮料，美国人无所谓牛磺酸本身，中国消费者却非常在意激素和添加剂。我们之前做过一款能量饮料，主打的就是不含牛磺酸，就是在做相关性。

诚信、区分、相关性。三层期待环环相扣。广告做的不是信息堆砌，而是先让人信你，再让你觉得你特别，最后让你觉得你是为我而来的。

赵毅衡这本符号学在同类著作里算通俗好读的，感兴趣可以翻翻。
