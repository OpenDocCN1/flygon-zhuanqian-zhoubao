# 在 Web3 的牛熊轮回里，能活下来的都是会做这四件事的人



大家好，我是 Start9527。连续四届担任龙哥盟 Web3 航海的教练，也在带 Web3Going 新手实战营，目前主要做 Web3 领域的传播工作。近期我还和北大合作，正在推出《Web3 数字经济发展研修班》，由北大教授授课、发放北大结业证书。感谢龙哥老师、静伟、小霸王的邀请，把第四期的分享整理出来和大家一起复盘。

这次分享的主题是《穿越 Web3 牛熊，这几个基础操作你必须知道》，这期内容到现在看依然不过时。整篇我会围绕四个实操点展开：

1. 主动拥抱新叙事
2. 让资金保持流动产生收益
3. 用空投作为起步路径
4. 通过持续输出倒逼自己成长

这四点是我长期在赛道里验证下来，真正能帮助新人建立体感、降低试错成本的方法。

**操作一：别拿偏见挡住新叙事**

传统圈子对 Web3  vốn就存在误解，如果连我们自己人也对新玩法嗤之以鼻，就真的格局太小了。StepN、brc20、eths 这几个案例就是最好的例子。

StepN 是华人团队在 Solana 上做的链上跑步项目。起初白名单 mint 只需要 1 SOL，很快就涨到 5 SOL 左右。项目本身用 NFT 作为挖矿资产，创意并不算颠覆，但赶上了 NFT 退潮后链游缺爆款的空白期，加上币安等机构的背书，一路冲到高峰。1 SOL 的成本拿到巅峰，近万倍收益完全不是夸张，我当时因为觉得模型像三年前的旧鞋就错过了。

brc20 的代表 ORDI 是 2023 年 3 月在比特币生态上发行的铭文。刚好我之前操盘过 NFT，所以 Yuga 在 BTC 上发 Twelvefold 时，我接到的技术咨询我直接觉得不靠谱给拒了。随后投研群在三月就注意到这个项目，当时一枚铭文才 3 美元，最高冲到近 3 万美元。我既有先入为主的抵触，又一拖再拖，直接放跑了一次翻身的机会。

eths 则是在 2023 年 6 月左右模仿 brc20 公平发行的以太坊铭文项目，一个多月涨幅约 300 倍。

三次错过，原因都一样：偏见。后来我们内部就总结了一句话：拥抱新叙事，必须留一小部分仓位试错。投对了就是意外的惊喜。

**操作二：别让资金空转**

Web3 里稳定币生息是比传统金融更香的躺赚方式，关键是别让资金闲置。去年 6.2 的汇率到现在接近 7.4，单纯持有 USDT 就有接近 19% 的汇率收益。

更进一步，在像 OK、币安这种体量大、合规相对完善的中心化交易所，可以做稳定币的定期生息，年化大约在 10% 左右。重点要强调的是交易所要选头部，小平台监管和安全风险高，很容易出现跑路，注册一定要以大所为主。

举个例子，1 万 USDT 放一年，既能吃到汇率差的 19%，又能拿到 10% 的理财收益，双重加持。

至于代币本身，在熊市里大多数币都有明显生命周期和回撤，稳定币则不会。

**操作三：空投是新手最友好的入场券**

撸空投是我自己最核心的变现板块，Web3 里我其他方向的收入都不及它。很多人觉得门槛高，其实流程很清晰：选钱包、选链路、用上检索工具、挑项目做交互，熟练了就形成肌肉记忆。

入门一定要备齐工具：

一个是信息登记常用的邮箱；

一个是类似 QQ 号的社交账号，用来做项目方认证、工作证明，也是关注项目动态的重要渠道；

一个是类似微博的媒体宣发平台，现在改名后的 X 是项目信息最集中处；

电报风险较高，因为资产诈骗重灾区很多，新人如果自控力不足不建议频繁使用。Discord 也是主要的社区社交工具。

这些工具的使用逻辑和微信微博差不多，都是聊天、找线索、连项目方。

交易所是 Web3 的银行，中心化交易所如 OK、币安，去中心化交易所如 Uniswap、Curve。赚钱逻辑类似银行，但风险完全不同。记住一句话：只玩头部，只玩头部，只玩头部。重要的事说三遍。别因为别人推荐一个不知名小所就冲进去，最后你就是别人的燃料。

链的转账也别被绕晕。ETH 生态里 ETH 是手续费燃料；BSC 生态里 BNB 是燃料；Polygon 里 MATIC 是燃料；OP、ARB 这类以太坊二层链，虽然有自己的治理代币，但交互时仍然要用 ETH 付费。

还有 Atom、Flow、Solana 已发币，ZK、LayerZero、Starknet、Zeta 等未发币的链，这些未发币的链恰恰是空投玩家最爱的标的。

以 ZK 链交互为例，标准路径是：先用人民币通过 OTC 或交易所换成 USDT；再用 USDT 换成 ETH，因为 ZK 属于以太坊二层，燃料仍是 ETH；然后把 ETH 提现到自己的去中心化钱包，比如小狐狸或 OK Web3 钱包，并选择 ZK 链网络。若钱包暂不支持，可先提到 ERC20 网络，再通过跨链桥转到 ZK 链；最后用这笔 ETH 去做项目交互即可。

每一步都会卡人：资金安全、选桥、选交互平台都需要自己去踩坑解决。知识网上都有，但一个熟悉的圈子能让你少走很多弯路。撸空投本质是执行力、团队和资金的比拼，信息差越来越小，新人基本不会出现灾难性亏损，反而能在这个过程中熟悉产品、甚至给出改进建议，成为建设者。

**操作四：持续输出，倒逼学习**

输出是最好的影响力放大器，但前提是要有一次赚钱的实战作为背书。没有结果的输出很难持续，因为大家来都是为了赚钱。

推特的创作者收益在不断提升，很多大 V 已经靠内容实现副业收入。内容素材可以从龙哥盟的库里提炼，也可以用 rootdata、CoinMarketCap 等聚合站做项目解读，用图文或短视频形式都可行。做内容的过程就是逼自己把知识体系化，坚持下去一定有回报。
