# 学历平平、没资源、没人脉的宝妈，怎么在母婴赛道硬是做到了两年变现百万？

大家好，我是龙哥，一位95后的宝妈创业者。

没有任何启动资金，也没有行业背景，学历也只是普通水平。两年前的我，几乎被重度抑郁击垮，唯一支撑我走下去的，是想把女儿的先天性甲减治好。

就是这份不服输的劲儿，让我把全部精力扎进了母婴赛道。两年深耕下来，我从一个全职带娃的普通妈妈，变成了日进14万的母婴供应链主理人，累计变现超过100万。

这篇分享里，我会把从零到一的实操路径拆开讲。想看完整版的宝妈带货打法，可以移步飞书文档查看详细拆解：


无论你是学历普通、不甘平庸想做点副业增收，还是经济不独立、想摆脱在家看脸色生活的宝妈，都希望我的经历能给你一点启发，帮你找到一条适合自己的赚钱路径。

这条路能走通，离不开一路扶持我的贵人们。特别感谢@芷蓝 @姐夫 @靠谱 @理白 @浩哥 @小鹿 @比比 @小可爱 等多位老师的无私提携，也感谢@龙哥老师给我进入优质圈子的机会。
