# 1985 年《花花公子》采访乔布斯
作者：龙哥

1985年，乔布斯不过29岁，却已经顶着“计算机革命之父”的名号，个人财富更是飙到了5亿美元——按当时币值，也就是1984年的5亿。那一年，他破例接受了《花花公子》的深度访谈。这场对话堪称宝藏，几乎全程高能，把三十多年前苹果这家传奇公司起步阶段那些引人入胜的往事，原原本本地铺展在读者眼前。从一个青涩创业者的视角，到改变世界的野心，很多细节如今读来依然令人震撼。想穿越回那个年代，亲耳听听乔布斯怎么说？完整采访在这里：[阅读原文](https://zhuanlan.zhihu.com/p/107101944?utm_source=wechat_timeline&utm_medium=social&s_r=0) ![](img/1c37d505930596d12a88ab23e11aa07a.png)
