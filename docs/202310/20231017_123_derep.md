# 1 亿人的小红书：时机、摇摆和决心

五年时间，互联网江湖潮起潮落，却只有一个平台悄悄跨过了“日活一亿”这道门槛——小红书。很多人研究它做了什么，但真正懂行的人会说：看懂小红书，恰恰要看它没做什么。

我们和几十位与小红书有关的人聊了聊，包括在职和离职的中高管、一线员工、投资机构、品牌伙伴、创作者以及普通用户。拼凑出的故事，不是关于它如何激进进攻，而是关于它如何在人人都在追求爆发的行业里，选择不着急。

在“增长”几乎成为唯一信仰的中国互联网，小红书的耐心显得有点格格不入。但这种看似慢的节奏，却让它找到了属于自己的生态位，成为近五年里唯一达成日活破亿的平台。

也许，它最特别的地方，不在于跑得多快，而在于它愿意等多久。
