# 新手志愿者避坑指南：我连续三次上船后的实战复盘
作者：龙哥

大家好，我是龙哥。

从今年开始，我一口气完成了三次志愿者航海任务。说实话，第一次报名前我脑子里全是问号：赚钱的志愿者体系听起来很“神”，自己上去真的能hold住吗？会不会拖后腿？

结果真上了船，才发现这是一场被积极能量包围的探索之旅。借着八月航海收官的节点，我把自己这几趟的心得做了个迭代梳理，也好给自己下一次航海打底。干货就浓缩在下面三件事上，刚想入坑的朋友可以抄作业：

**一、用三张表把航海工作跑通**
别靠脑子记，靠表格管。我的实操组合是：
船员基础信息统计表、航海目标及需求调研表、航海志愿者任务检查清单。这三张表能把人、事、目标都串起来，上手快很多。

**二、提前预判高频问题**
航海里志愿者最容易卡住的点都差不多，提前知道会遇到什么、怎么回，就不会手忙脚乱。我把自己踩过的坑和反复被问到的情况都整理成了高频问题清单。

**三、一套能立刻用的小技巧**
从沟通节奏到分工细节，有些小操作能省很多沟通成本，这些都是在船上一步步试出来的经验。
