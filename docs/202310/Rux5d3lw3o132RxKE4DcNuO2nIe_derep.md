# 一、ChatGPT写文案不行吗？

“用ChatGPT写出来的东西太烂了！”

这句话我听过无数次。把对方的提示词拿来一看，问题基本都一样。

指令写得太粗糙了。

比如有人会说：“你是个有十年经验的作家，帮我写篇1200字左右的文章，主题是年轻人不必急着结婚，要有吸引力。”

![](img/efe9504031b15c926b8854f7fae4b93d.png)

这种问法能产出高质量稿件，真的只能靠运气。

ChatGPT本质上是一个共享的临时外包，和刚入职的新人一样懵。它知识面广、智商在线，分析起来一套一套，但缺乏实战经验，执行时容易跑偏。

更麻烦的是它的记忆很短，聊几轮就忘。

你给一个模糊的Prompt，得到的一定是模糊的答案。

模型会在背后掠过上万种生成可能，最后挑一个最符合机器逻辑、最中规中矩的版本给你。

和ChatGPT配合，核心是人机共创。你既是导师也是考官，必须把自己的业务经验、做号方法、成功案例讲清楚，任务要点1、2、3条列明白。

比如你知道它默认是强逻辑、偏生硬的表达，就可以在指令里加一句：“表达要口语化、接地气”。

它习惯用“首先、其次、最后”做递进，你就可以规定：“段落衔接要自然流畅”。

案例太空泛，就要求它“细节要饱满，细节要能让人共情”。

觉得太平淡，就让它“多写让人记住的金句”。

我以前做过一条《ChatGPT七夕劝退信》的入门指令，只加了三点：过渡自然、语气口语温柔亲切、多用金句。结果出来的文案效果非常好。

所以，ChatGPT能不能写出好文案，关键看提问的人会不会提要求。

爆款都有套路可循，前面说的那些初级设定只是内容框架的一环。

选平台、定选题、用哪种结构、什么语气、什么技巧，都会直接影响质量。

在AI写作里，我们要做的就是把“什么是好文章”用明确的标准讲给它听，让它照做。

# 二、好用的GPT写作指令做法

想让ChatGPT更懂你要什么、结果更可控，可以用基于“BRTR原则”的<gpt>。</gpt>

BRTR由 背景B、角色R、任务T、要求R 四部分组成，是一个清晰好上手的结构化提示模板。

我于2023年7月提出BRTR模型，被不少学习指令的朋友采用。

<gpt>，则是针对AI写作场景做优化的指令框架。</gpt>

把文章要求拆解后填进BRTR这个模块化框架，就能得到一条可复用的“GPT写作万能公式”。

写作指令=背景+角色+任务+要求

背景：说明账号在哪个平台、做什么主题、受众是谁、人设定位、变现策略等

角色：给AI一个对口的专家身份+具体的技能经验

任务：简要说明写作方向和预期效果

要求：语气风格、内容结构、写作手法、参考样例、执行流程

# 三、GPT写作指令法的任务框架

<gpt>可以拆成两个大模块：【任务设定】和【任务要求】。</gpt>

## （一）【任务设定】

背景、角色、任务属于基础设定。

先让模型搞清楚你要发在哪、让它扮演什么专家、要干什么，从而把回答范围收窄，答案更聚焦。

如果角色和任务本身已包含背景信息，也可以简化为RTR模式。

背景：我运营一个叫“年轻人交流空间”的👸号，现在很多年轻人被催婚困扰。

角色：你是一位资深文案专家，擅长说服类写作。

任务：请帮我写一篇主题为“年轻人不必着急结婚”的文章，要能引起共鸣。

## （二）【任务要求】

要求是写作指令的核心，用来搭建详细的内容规范。

我把AI写作拆解为语言风格、内容结构、写作技巧、观点态度、关键词五个维度。

其中语言风格、内容结构、写作技巧是搭建文案模板最关键的三要素，也是最常用的。

布置任务时还可以附上模仿样例，约定好创作流程。

要求越具体，模板的可控性和可预期性越强。

![](img/b513afba1611c7edb5a82d341825227b.png)

基于这个拆解，可以得到文案要求的万能公式。

写作要求=语言风格+内容结构+写作技巧+模仿示例+创作流程

语言风格
第一眼感受。长短句搭配、口语还是专业、是否用网感词，体验完全不同。

让它模仿刘润、王家卫、乔布斯的风格，写出来的辨识度会很强。

内容结构
决定了叙事和论述的走向，读起来顺不顺。

可以参考经典写作模型，如故事类用叙述模型。

写作技巧
用手法增加文采和吸引力。

比如用悬疑设问吊好奇、用细节案例引发共情、用金句让人记住。

模仿示例
帮助模型理解你要的效果，尤其在描述抽象时更重要。

示例可以独立放，也可以融进风格和技巧里，按需使用。

创作流程
任务复杂时可以分步，比如先定题、列大纲、再成文。流程不是必须，按需约定。

# 五、GPT写作指令的3种写法

## （一）初级指令

指令简单时直接写成一段。

背景：我在📕运营美妆号。角色：你是资深📕文案专家，擅长写用户爱看的爆款文案。任务：围绕“ysl经典口红”写一篇📕爆款文。要求：1、口语化表达；2、多用emoji；3、适当加入个人使用体验和评价

## （二）中级指令

要求多时分行书写，清晰度更高。

背景：我在📕运营美妆号，23岁东北妹子，写文喜欢带点口音。

角色：你是一名资深📕文案专家，擅长写爆款文案。

任务：围绕“ysl经典口红”写一篇📕爆款文。

要求：

1、口语化表达

2、标题要有吸引力

3、多用emoji

4、加入个人使用体验和评价

5、控制在500字内

6、文末生成相关标签
