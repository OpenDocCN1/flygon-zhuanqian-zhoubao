# 一种用 canva 来批量制作图文或者是视频的方法
作者：龙哥

别再一张张改了，Canva 这个联动玩法能一口气产出几十张图和 N 条视频

如果你也靠做内容矩阵吃饭，一定懂这种痛苦：图片要一张张排版，文字要一个个拖动，光重复劳动就能耗尽力气。今天聊的这个方案，是我目前在用的高效率操作，它的核心是利用 Canva 的表单关联功能，把大批量的图、文、视频一次性派发出去。当然丑话说在前头，这套打法只对版式固定的内容有效：背景布局基本不动，模板框架保持原样，每张作品之间仅仅更换文字语句或个别装饰符号。

只要是上述这类需求，都可以直接套用。比如这几类帖子（![](img/23e7e08d4a00d0029816eef729a95f5d.png)），又比如这种封面固定的栏目（![](img/e8e4a471c19e5ebcadc29ef8f53a3313.png)），以及这种只需要换标题和落款的日常更新（![](img/b445ec17b65d5b922a124e20d3fa058a.png)）。而且有意思的地方在于，静态图做好以后，借助 Canva 的能力，加上背景音乐与页面转场特效，还能继续把这些图片一键变身为动态视频，相当于一套素材，两种成品。

先说账号准备。Canva 没有账号是不行的，注册方面自己动手即可，嫌麻烦也能去电商平台直接买现成。我自己用的版本是教育授权，拥有一部分 Pro 权益。这里分享一个小窍门：搞到学校的 edu 专属邮箱，再去国际站点申请注册，就有机会免费批量拿到多个带高级功能的账户。据说淘宝上那些写着“永久 VIP”的账号，源头就是这种操作，做成生意也能有收入。我最后一次批量注册已经是很久以前的事了，现在的审核政策有没有变化，需要各位自行验证。

登录成功之后，先做出自己的母版。我给演示准备的范例只放了两张画布，大家完全可以根据所处领域做八张、十张，甚至更多（![](img/df182964b3e8df36c9dca8bffcfa45ca.png)）。

母版做完，就该做减法了，把哪些永远不需要动的元素挑出来。举个直观的例子，我周围用红线圈出的区域，就是整批内容里恒定不变的部分（![](img/44348777050d3207ec7f36c18c0bdfc5.png)）。除了这些底盘，剩余的就是需要每次更新的文字内容了。我数了一下，演示版里一共有四个要变的点位（![](img/1d11c8cadd7f75cff5fb424dc526a0ac.png)）。

那么整个思路一下就明朗了：先收集文案稿，再把四个点位分别换上对应的新内容，系统会自动生成整套新的成品。建议大家在 Excel 里按照下面这种格式维护一个文案库（![](img/5b99c44e57f243954ded83055619ffdd.png)）。如果打算一期出五张成品，就往这个表里填充五组数据。我为了演示效果，随便敲了一些无关字进去（![](img/89756e68363816685608c83a7bbbd509.png)）。

准备就绪后，就进入生产环节。先找到左侧边栏的“批量创建”（![](img/2853e86fe3d52f60f4ccf7e149c8fecb.png)）。想要把数据传送进来有两条路线：第一条叫“手动输入数据”，软件会当场在线开出一个数据表，直接粘贴填写；第二条呢，是把做好的 Excel 另存为 csv，再提交上去。本次以第一条路线为例（![](img/02fe7618c39ba2f281d90d3b9a6be29b.png)）。

进入线上表单之后，你会发现系统预置了两列，因此请按界面左上角找到的“添加文字”按钮，把剩余文字列补齐。这里留意一个小差别：假如你按的是“添加图片”，新增的列就会采用图片格式，适合用来做图标、照片的大规模轮换（![](img/b62263eb1876388b60cbe5ce472ece4f.png)）。所有内容粘贴完毕后，顺便把每一列的列名修改到位，然后按下右下角的“完成”（![](img/5f9e3cfadaa8a2147cf4c554aaa3fe52.png)）。

然后进入这篇教程最关键的操作——把列数据与画布上的文字做绑定。先用鼠标选中某个文本，右击唤出菜单，执行“关联数据”（![](img/892babd8179b4aa986ddee1c64aeb607.png)）。在弹层中指定你要使用的那一列，比如我选了第一列，这一列的列名叫作“标题”（![](img/cf2fafa8a5006a98e265aacc80479c3c.png)）。绑定生效后，画布上原有的文字会立即替换为该列的列名（![](img/a273e94ecd72d6dccfd275bbdfbe9daf.png)）。接着按同样的方法，针对第二页的三块文字也执行三次绑定。每绑定成功一条，左侧就会亮起一个对勾标识（![](img/9c4ebcc00085a68a0c6875141476137d.png)）。当全部完成后，每一列的信息分别落在画布的什么位置，整个对应关系非常清晰，我把它们标了出来（![](img/692365f7b31ccb713406bf7268c0e279.png)）。检查没问题后，按下“继续”（![](img/34dad63ed6016fda411ba023595c82d7.png)）。

由于表格里我仅放了五条记录，系统便据此产出五组作品（![](img/b3c9e878f235f5749ab06e14e45a32c8.png)）。每组包含两张，总共得到了十张图。你可以按下那个矩形缩略按钮，进入总览模式（![](img/2f9ebb23d37d93666e1357de62d9ff4a.png)）。这时五份完整成品尽收眼底（![](img/7c4735a24b17554e471bd3003b2699fa.png)）。最后在右上角打开“分享”，从弹窗左下角选择“下载”，所有图片就会整体存入电脑（![](img/3ad010889f4f886a6322f85cec63b64c.png)）。

那么图片是如何变成短视频的呢？先回到左侧栏进入“素材”库，把列表下拉到底部附近，能看到“音频”这一项，点开它下方的“查看全部”（![](img/adf8273c6f81b3e0465066bcb15f6574.png)）。挑一段中意的背景音乐，轻触播放，音乐便会自动落到右下角的音轨区。再左右拖动音乐条，让它的时长完整盖过所有图画（![](img/dd1c9ba19d477776c6730b018169fc86.png)）。接着选中第一个页面，在界面左上角进入“动效”设置（![](img/c97de1329531f854999d234f53f3874e.png)）。从容挑选一种合适的动画吧，记得点选“应用于所有页面”哦，否则每页效果不统一（![](img/a9f1386b4167cbfb33c1c9072ccce684.png)）。这时可以通过左侧的播放键，预先感受一下音效与画面结合的最终状态（![](img/9f39597731f2365324e2a3ef37cf2454.png)）。

到这里，图文内容已经全变成了视频素材。剩下的事情是按两页一组的方式分别导出成 MP4。操作上，每次都是在“分享”菜单里选“下载”，文件类型切换到“MP4 视频”（![](img/6906fdfa7b5338ebbbf7f6e9b453eedd.png)）。在“选择页面”区域里勾选第一页和第二页，最后确认并开始保存（![](img/e201f1aaf2b673e0c3a5168454851e4c.png)）。第一个短片就这样新鲜出炉。接下来的动作一模一样，对应选“第三页第四页”“第五页第六页”逐次保存，拿到五个视频没有任何难度。如果不想分批操作，也可以全选所有页面合出一条长视频，再丢进剪映分割成几段，同样能达到目的。

最后还有两个容易被忽视的小坑，值得单独说一说：
一是相邻文字之间的距离，建议留出两行的余量。因为有些文案字数偏多，到达换行阈值后会自动折行，空间留得太窄容易发生重叠（![](img/bbe07fe135135cc5ef7cfd7d929271e8.png)）。
二是如果想整体改变成品尺寸，不用重新排版，直接在左上角位置点选“调整尺寸”就能搞定（![](img/7b611cdd11dc204b9bcd2bd314bfc58b.png)）。
