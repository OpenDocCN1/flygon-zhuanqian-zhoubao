# 迟迟下不了笔？让 ChatGPT 用“击鼓传花”法快速写出一个段落，效果很惊艳

每次打开文档，盯着光标闪半天，却一个字都挤不出来？好不容易鼓捣出一段，读起来又总觉得有种“AI腔”——满屏的“首先”“其次”“不仅仅”“更”……这种刻板的连接词，正是机器写作最容易露馅的地方。

今天就分享一个亲测有效的思路：“击鼓传花”写作法。借助这个玩法，你能让 ChatGPT 帮你快速生成长文段落，而且写出来的文字自然不少，更像人话。

有意思的是，这套思路不但能破解“开不了头”的困境，还能顺手治掉机器味。因为“击鼓传花”式的推进方式，会让文字像流水一样一段接一段滚出来，而不是靠一堆僵硬转折词硬凑。
