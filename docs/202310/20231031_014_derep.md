# 这趟上海的三个小时，我把龙哥的商业底层逻辑拆开了



说起来我也是个半路出家的创业者。

本职医疗，做👸号经营信任，商业版图是医疗业务+自媒体+房产投资，算是有点小成绩。但跟赚钱系人马比起来，还是差太多内功。

上周从上海出发，专门约了龙哥做了一场三小时的闭门交流。出发前我把《亦无所知》从头到尾又刷了一遍，笔记本记了大半本。看一个人，不如看他没火之前写的东西，那才是骨架。

我2021年就进了赚钱，一万块的门票，入群人数早破万。当时我就好奇，到底是什么样的玩意儿能把流量玩成这样。后来慢慢研究，才发现赚钱的每个节点、每年的战绩、每个项目是怎么长出来的。

龙珠、大航海、日历，这些运营产品不是拍脑袋加的，是按节奏迭代进来的。

见面我第一个问题就是：你名气已经到顶了，知识星球也做到头了，为什么👸号反而停更了？

龙哥的回答很直白：要控供。

这让我想起罗振宇当年退出优酷、all in 得到。100个免费平台的散粉，不如一个付费App里的铁粉。供给收紧，反而让价值更贵。

第二个问题，我问他抖音这些大盘流量你为什么不去啃？

他说做过，很赚钱，反馈也极快，但他砍了。自己下场就被流量绑架，整个公司的人、产品、商业模型都要围着他一个人转，其他业务就死了。

他想要的是把自己摘出来，把流程、组织、架构做成机器。即便没有个人IP，机器照样印钞。那才是长线的钱。

第三个困惑：知识星球听起来很轻，你们内部运营怎么养了这么多人？

龙哥说，知道、做到、赚到，难度完全不是一个量级。只做资讯观点随便一个人就能发，但大多数人缺的是执行力。靠运营把执行力拉起来，于是才有龙珠的激励机制，才有能容纳两三万人的大航海。有人在活动中真做出来项目，这就是最硬的交付，也是续费的根基。

同事们就是做这个存在的。精简成本理论上能省上千万，但可能性就被砍掉了。

关于孵化投资，我问他有没有私董会、有没有内部投项目。他说私董会大概一千人，更窄的圈子。投过，也赚到钱。张潇雨最近也在跟他聊这条线。

我把自己在星球里做的微天使玩法跟他讲了：在付费社群里投年轻人，给钱给流量做筛选，让社群有了金融属性。我做了十几期，确实跑通了。

我又给他讲了一个外界几乎不知道的案例，一个市值千亿美金的500强公司，用40多年时间做了300多次并购，从地产基金起家变成全球并购之王，甚至超越苹果的市值表现。商学院的经典案例，但大众没听过。

对有流量、有运营、有资金的人来说，这才是顶级对标。龙哥听完很震撼。

事出反常必有妖，要有异常值思维，这正好呼应了他👸号里的核心观点。

有几条笔记我整理后反复咀嚼：

1、输出内容守住两条线：真诚，和有用。
2、别只堆观点，要沉淀成自己的方法论。
3、市场上鸡汤太多，真正能落地、跟着做就能变现的术太稀缺。龙哥盟就是因为刚需而火。
4、要造一个能自己转的赚钱机器，实现睡后收入。
5、过往他提过三条不做：低利润产品、线下发货产品、帮别人卖货。
6、赚钱的底层是欲望+敏锐度+执行力，和我之前的总结野心+聪明+行动，本质一样。
7、内容要工具化，等于流量模式×产品模式×盈利模式。
8、做巨头的边角料。
9、精益测试先赚钱跑通模型，再规模化自动化，规模化前做AB测试筛效率。
10、信息源：RSS、付费渠道、小圈子、日常观察。
11、价值分两类：信息价值+链接价值。利他做交付，让人有获得感。客户不为技术买单，为解决问题买单。
12、可重复的事就要标准化，有限制的地方就有痛点，就有生意。
13、人最大的需求排序：怎么赚钱、怎么快赚钱、怎么赚大钱。社群要做到谈钱不伤感情。
14、把用户当朋友，不是当流量。
15、先建立正反馈，先赚第一块钱。
16、自己的利益后置，别人的利益前置。
17、对项目零判断，不因成本高、低、传统而设限，都是偏见。
18、不知道做什么时，乱做也比不做强。
19、近曹者富，曹政是贵人。
20、别人赚钱的事，就是你的指南针。
21、如何建立对手抄不走的壁垒：规模效应+信任议价实现成本领先；低利润也是一种能力；财务算账能力；赚钱有四个维度：利润、结构、成本、品牌。

龙哥对赚钱的启示我也抄下来了：人力总成本领先，核心自留其余外包；精细化运营数据驱动做核心星友；持续输出价值；追求溢价而非议价；专注主航道别乱搞；规避风险不被团灭；规模化才有话语权；付费社区的核心竞争力永远是内容和服务。

这三小时，比我一年刷文章收获都大。祝龙哥盟越做越猛。
