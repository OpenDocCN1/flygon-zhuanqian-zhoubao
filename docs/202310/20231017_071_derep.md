# 闲鱼卖幕布国庆 7 天赚了 6158 元的分享

国庆假期，有人去看人山人海，有人在闲鱼上悄悄赚钱。一个20岁的宝妈，靠卖幕布，7天入账6158元。她把这个过程完整分享了出来，看完会发现，这不是靠运气，而是选品、运营和专业积累共同作用的结果。

故事的主角是小雨，今年20岁，已是一位宝妈。她从17岁就全职做起闲鱼，靠在这个平台上卖货，积累了数十万的收入。今年5月，她又开设了自己的1对1私教课，并通过自媒体运营，实现过单日收入破万。9月，她开了一个新号，专门深耕幕布这个垂直品类。上架、优化、测款，整整忙了一个月，终于在9月底跑出了爆款。紧接着的国庆假期，新号7天就带来了6158元收益。

为什么选幕布？小雨说，现在闲鱼上卖货的人越来越多，想在同样的平台里拿到结果，关键在于选品上的差异化。幕布刚好是一个容易被忽视、但利润很可观的品类，毛利率能做到20%到55%。只要货源靠谱，出单后的收益会比很多人想象中更可观。

当然，幕布不是随便上架就能卖爆的。小雨把自己掌握的专业内容整理成了一份完整笔记，里面包含几个核心板块：

- 幕布货源的利润拆解；
- 幕布货源需要掌握的基础知识；
- 回复顾客咨询时的专业话术；
- 新号如何快速起量；
- 幕布货源的优点与缺点；
- 参加赚钱📕店铺打卡后学到的方法；
- 最后的结语与阶段总结。

从选品逻辑到运营节奏，再到客服应答，基本都覆盖了。她也特别感谢了可爱老师、芷蓝姐、白哥，还有靠谱姐在整个过程中的指点和帮助。
