# 20平米炸鸡摊位，95后女生5个月做到月流水10万的实战复盘

现在实体生意不好做是共识，但总有人在夹缝里把小店做成现金流。

我是龙哥，95后。半年前我在副业小镇开了家20平的炸鸡小店，完全零经验起步。没想到5个月下来，月营业额就稳定到了10万左右，甚至有老客一年复购了60多次。好吃是根本，但好吃之外的一系列打法，才是让小店活下来的关键。

当时我也是从小白开始摸索的。实体店要生存，不能只靠等客上门，得把产品、运营、口碑一套套打通。

* * *

市场的反馈其实很直接，大家也在评论区问到一些很真实的问题。

关于同行恶意差评，我的经验是：这种事在小吃赛道几乎必然发生。平台官方一般不会主动介入，但自己是有操作的空间的，比如花40元/天做差评的删减处理。

另外运营方法上，我的确借鉴了家族经验。我叔叔的火锅店就是我来操盘的。好评的积累也是一件需要设计流程的事。比如顾客结账时，找一个女生去沟通，客户通常会比较放松。提前准备好评模板，直接用顾客的手机帮忙发出，配合一瓶2块钱的水或者一张免费停车券作为小赠品，转化率会很高。
