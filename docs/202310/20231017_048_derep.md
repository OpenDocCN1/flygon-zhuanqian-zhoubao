# 0 基础小白写👸号爆文，25 天写出 5 篇 10W+、副业收益 5000+的经历分享
作者：龙哥

零基础写👸号，能快速出爆款吗？有人用短短25天，给出了一个让人羡慕的答案：5篇10万+，副业多赚5000多块。这是安七和她学员交出的成绩单。

安七是谁？她自称是10W+爆文写作者，也是那种喜欢用文字打磨自己的姑娘。她的经历有点特别：大学期间已经自食其力，毕业后与百亿集团股东打交道，做过天使投资人；23岁那年，她创业开了一家代运营公司。虽然加入赚钱圈子已有两三年，她总觉得自己只是在围观，身边大佬太多，自己没什么值得讲的。

转折出现在她报名👸号和视频号航海之后。因为时间安排，她没能跟完全程，却在航海过程中遇到了人生中的第一位客户，也是她口中的贵人。她说，这次航海真的超值。

今年9月，她开始带学员实操爆文变现，交出的成绩包括：

- 零基础学员，25天里产出5篇10万+，一个月靠副业多赚5000多块；
- 有账号发布7篇文章，3篇阅读量破万，1篇飙到39万，2篇上千；
- 一篇文章39万阅读，带来1950+的变现；
- 也有单篇阅读量冲到46万以上。

安七说，是圈友的鸡汤又一次鼓舞了她。趁这个月刚开始一周，她也想给同样在围观的朋友们打打鸡血。这篇分享比较长，她把完整内容整理在飞书文档里，想看的朋友可以自取：
