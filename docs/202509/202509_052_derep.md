# 被骂，是最便宜的清醒课
作者：龙哥

早上刚回完几个问题，顺手就怼了不少人。别心疼，也别太脆弱，有时候事实就是扎人。想听我正式开骂，得先交钱进星球，外面随便逛逛的，我犯不着浪费口舌。

骂自己人当然也常有，我也不知道同事们听完心里什么滋味。但要是有个上司能定期给我上上强度，帮我把世界的样子看得更明白点，我一年给他打一百万都觉得值。
