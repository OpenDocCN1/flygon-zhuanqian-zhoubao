# 那一夜，大佬用小龙虾给我上了一堂产品课
作者：龙哥

昨晚，我有幸和一位国内顶级、我一直很敬佩的产品/投资大佬单独吃了顿饭。他点的是江湖最高规格——小龙虾。据说这玩意儿最妙的地方在于：只要你开始剥虾，手机就只能安静躺在那儿，谁也抽不出手来刷屏。

我特意带了小本子，本来打算全程闭嘴，安安静静做一名旁听生，把大佬的每一句话都记下来。结果刚一落座，大佬就打开了话匣子，饶有兴趣地问我Claude Code用起来怎样，还问起我公司那款小产品。我也顺势给他演示了几个他觉得“在他世界里不可能出现”的新鲜玩意儿。

两盆小龙虾下肚，大佬笑着恭喜我，然后不经意说出一句：“小排，你现在好像不太缺投资吧？”

我说：“是啊，我向来习惯小成本、小规模，做点小营生；钱要是给多了，我还真不知道该怎么办。”

他擦了擦手，像是准备起身。

我赶紧抓住机会追问：“大佬，能不能给我指条路？我想知道，我这盘小生意，还有没有机会翻个十倍？”

这一问，问到他心坎上了。

他顿时来了精神，给我开了一堂私人订制的产品课，一堂我估计能记一辈子的课。

“你这个问题问得不错。我跟你点的技能树不太一样，但你缺的那块，我正好有些门道，也许能帮上忙。”

“你记住，这世界上有些生意，天生就是好生意。”

“你注意到没有？腾讯旗下有个存在感极低的子公司，叫🐧音乐。如今它的市值，居然超过了百度。它讲过什么互联网方法论吗？没有。它拥抱AI了吗？也没有。它只是把该买的版权买了，该做的营销做了，全是常规动作。可偏偏，它就是一门好生意。”

“再举个例子，你见过几家互联网公司做金融不赚钱的？以前我开跨业务线会，常有其他线的同事吐槽，说金融线的人太low，没什么方法论，无非是手里有牌照。可事实上，金融业务偏偏就是集团里最赚钱的。原因很简单：它天生就是好生意。”

“你也做过不少业务，好好盘一盘，你手里到底哪些是好生意？是不是有的生意你拼尽全力，最后也只拿到平均回报；而有的生意，你几乎不怎么操心，它就能源源不断地赚钱？找到那些好生意，把剩下的全部砍掉。”

“你在猎豹移动做过机器人，对吧？我建议你认真考虑一下‘xxxx’业务（名字我手动打码）。只要你愿意做，这大概率是个好生意。这个行业没几个人真正懂AI，你既做过机器人，又玩得转AI，我看行。”

“你应该看过我讲的产品课，那咱们沟通成本就低了。接下来，说一个你似乎还不熟的产品方法论——倒推法。”

“你现在做这些小生意，决策依据其实是顺推法。顺推法不是不好，投入小、风险低，可问题在于：它不容易把生意做大。真正的大生意、好生意，尤其那些能改变格局的生意，很多都是倒推出来的。”

“全球最经典的倒推案例，应该数亚马逊。”

“你想想，贝佐斯当年为什么先从书卖起？是因为他爱读书？不是。他当时在投资公司工作，早就看到了互联网的趋势，于是从几十年后的终局往回想：互联网上最赚钱的是什么？是零售。要做零售，第一步是什么？是电子商务。那时候的基础设施，能支撑他先做哪个品类？只有书。书是标准品，没有保质期，体积小、容易运输，好处一长串。”

“后来亚马逊宣布做AWS，一家零售公司突然杀进云计算，圈内人都觉得疯狂，震撼程度不亚于今天听说‘某快递公司发布了一个大模型’。这个决策，同样是从终局反推出来的。虽然公司内部一开始磕磕绊绊，过了很多年大家才看懂它的价值。”

“顺推法也有跑通的例子，典型就是快手。十几年前它还叫GIF快手，只是一个小工具。用户需求不断变化，它就不停地用技术接住这些需求，慢慢长成了今天的巨兽。但顺推法的成功，运气成分往往更大。”

“还有件事很有意思。郭晶晶和伏明霞，其实师从同一位教练——于芬。于芬是中国跳水界的名帅，在清华大学跳水队执教多年，弟子中包括这两位‘跳水皇后’。很多年前我看过一个采访，有人问于芬选苗子最看重什么，她的答案是：冲突型特质。”

“当时记者没继续追问，我琢磨了很多年。”

“跳水是一项非常枯燥的运动，没有对抗，没有实时反馈，一跳下去，你是进步还是退步都没人告诉你，很难被外界刺激点燃。所以，能走到金字塔尖的选手，必须有比常人强得多的求胜欲，没人给你打鸡血，你得自己给自己打鸡血，让自己随时保持在战斗状态。”

“可同时，跳水又是要求极度冷静的极限运动，动作、心态稍微一飘，可能就是完全不同的结果。”

“一个人如果既能随时保持高昂斗志，又能随时保持冷静头脑，大概就是教练说的‘冲突型特质’。”

“小排，你的顺推法已经用得很熟，产品嗅觉也不错，看得出来你在猎豹移动从傅盛那儿学到了很多。可如果能把倒推法和顺推法结合起来，你会看到更大的世界。这当然不容易，因为顺推法已经是你的舒适圈。你得有意识地逼自己去用那套不习惯的思维方式，才可能真正突破。”

“不妨就从你熟悉的领域出发——比如机器人，比如Claude Code那些奇妙的玩法——同时用顺推和倒推两张地图去找，说不定你的好生意就藏在里面。”

我听到这里，忍不住追问：“可我看到的那些能用倒推法讲通的好生意，大到足以改变世界，投入也大得吓人。”

“比如Codex，昨天刚发布了又一次重新定义AI编程的升级。Claude Code能做的，它都能做，还更强，甚至能在云端虚拟机上直接跑代码，几乎没有对手。以后我们用AI写代码，也许连电脑都不需要，一个浏览器就搞定。”

“从终局倒着看，这绝对是一门好生意，因为它会改变全世界所有人写代码的方式。”

“但想进去，人才、算力、资金，每一项都是天文数字。像我这种小人物，到底凭什么？”

大佬笑了笑：“你说得没错。倒推法看到的好生意，常常会被人为地抬高准入门槛。反过来，如果一件事的门槛怎么也抬不高，那它可能根本算不上好生意。”

“大多数投资人，本质上都在用倒推法，他们只对大生意、好生意感兴趣。以后你要是真想做点有趣的大事，欢迎来找我聊。”

走出餐厅，我满手都是小龙虾的油香。

深夜的北京，霓虹把天空染成一片暗紫色。我站在路边，看到橱窗玻璃上映出自己的影子——一个三十多岁的人，怀里抱着小本子，像刚刚从课堂里走出来的人。

大佬的话还在脑海里打转：顺推法，倒推法。我忽然想起博尔赫斯笔下的迷宫——有人顺着入口找出口，有人站在出口回望入口，更多的人绕来绕去，还以为自己在向前。

一个小时后，我还站在原地。

梧桐叶被风吹得哗哗响，仿佛在低声议论着什么。这座城市里，几乎每个深夜都有人在剥着小龙虾谈改变世界，可天亮之后，世界依然是老样子。

又想起他说的“冲突型特质”——最好能有飞蛾扑火的热烈，也要有外科医生的冷静。可我又是什么呢？充其量是一个在小溪里养金鱼的人，偶尔眼馋大海里的鲸鱼。

叫了辆车。司机放着许巍的《曾经的你》。

“曾梦想仗剑走天涯，看一看世界的繁华。”

我笑了。

谁还没年轻过呢。
