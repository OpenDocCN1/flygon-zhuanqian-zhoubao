# 从想放弃到一单回本：我在B站好物30天里的关键抉择与心态蜕变

作者：王小小  
日期：2025-09-10

关注龙哥盟也有一些年头了，圈子里确实能看到五花八门的项目机会。B站好物这个赛道，我一开始也上手试了，说实话，刚开始那段时间真的煎熬，每天投入不少精力，却看不到明显的回报，脑子里时不时就冒出“算了吧，太耗时间”的念头。但转念一想，既然已经开始了，半途而废也不是我的风格，索性一咬牙，报了深海圈深入学习。
