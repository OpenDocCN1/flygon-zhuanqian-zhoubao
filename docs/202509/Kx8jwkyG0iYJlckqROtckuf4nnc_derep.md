今年夏天，我给自己挖了一个“坑”——报名去当龙哥盟自媒体推特项目的一名带队教练。头一回站上这个位置，说实话，手忙脚乱，还被平台警告过好几轮。但最后的答卷，连我自己都没想到：帮一批学员把账号做了起来，其中4个人在48小时内关注量破千，还有人当场就赚到了钱。

今天这篇复盘，我想聊两件事：我跳进内容创作这个坑的起因，以及“带一批人”这件事，到底回馈了我多少。

## 做内容这件事，起因其实很朴素

我此前做过一款产品：从需求挖掘到开发上线，全栈网站跑通了。但紧接着就碰到一座墙——我不会推广，没有流量。于是我开始认真补营销的功课，越补越觉得，营销最核心的东西可以浓缩成三条。

**第一条，营销的本质是贩卖感受。** 大家愿意掏钱的，无非是社会地位、财富、健康这三样。我拿自己的菜谱网站举例。第一版是典型的程序员思维——把功能一条条列出来。功能型产品吸引来的全是精打细算的用户，竞争对手多一个功能，你就可能被抛弃。后来我换了个思路，把菜谱做成生活场景：家庭主妇做几道拿得出手的菜，发个朋友圈很有面子，营养搭配还能让孩子长得更壮。这时候，我的竞争对手不再是美食网站，流量的入口一下子宽了很多。具体、生动的场景能带来信任，信任最终会转化成购买。

![](img/7593a7417efeccaf4e33ebd8ea21b318.png)
![](img/b85873fde78a5a4b2ac9f8bd08784d3a.png)

**第二条，做事要讲究共赢。** 柏拉图讲过一个洞穴寓言：一群人一出生就被锁在黑暗的洞穴里，面朝墙壁，不能转身。他们身后有一堆火，有人举着各种器物从火前经过，于是墙上投下影子——洞里的人从小到大都以为那些影子就是真实世界。直到有一天，有个人挣脱锁链爬了出去，看到阳光下的山川草木，才明白洞里的自己一直被幻象困住。他出于责任回到洞里，想告诉同伴真相，但那些被锁住的人不但不信，还嘲笑他疯了。

人活着逃不开人群。我们不过是从一个洞穴出来，再走进另一个洞穴；每个洞穴里的人，都有自己深信的一套东西。想跟赚钱的人打交道，就先聊赚钱；有人群的地方就有合作，合作想要长久，就必须让所有人都能赢。

举个例子：一家品牌的公关（PR）找到你，请你接一单商业推广，你赚到了钱。然后呢？你可以多问一句——你们还需不需要别的博主？你把单子分给同行，对方赚到了佣金；PR因为帮忙找到了人，任务完成还有提成；你则收获了PR的好感，下次有单子会第一时间想到你。你看，一步操作，三方受益。

再留一道思考题：假如你现在是个Nobody，花心思写了一份高质量的个人介绍文档，想请大V帮你转发——你该怎么让这件事变成共赢？

**第三条，沟通要分场合。** 面对一群人，你可以尽情展示；面对一个人，请掏心窝子。说白了，一对多的时候允许“装逼”，一对一的时候必须真诚。

![](img/59609128177c0a655bd695ecc81dc41a.png)

想明白这三条之后，再看看推广渠道，其实就三类。

- **一类是SEO。** 它本质上是零和博弈——所有人都在抢Google排名的少数位置，有的词红一阵就凉了，有的词可能让你一夜翻身。但SEO没法在不同关键词之间直接复制，换一个新词又得从头做一遍。整个方法论可以沉淀，但前一波积累的用户很难跟着你迁移到下一波。
- **一类是自媒体。** 自媒体是共和博弈，大家共享粉丝、共享商单，而且这种资产对任何产品、网站、服务都有叠加效果。
- **一类是付费广告。** 它是门手艺活，本质上是跟平台双赢，也是把杠杆放到最大的方法之一。

### 内容平台怎么选？

先给内容分个类：普通图文、干货图文、视频。抓主要矛盾，我看好的是推特、🛰️👸号、📕。

一位做公关的朋友说得挺直接：📕的需求量最大，但红的程度也最高；👸号和推特还有机会，特别是推特——经济下行的背景下，企业和个人都在往外走，推特还处于蓝色海洋阶段。

分发上有个实操技巧：把即刻、🧣当成试验田，抛出去试水，看哪个方向有反馈，再根据平台规则调整内容形态，最后分发到主阵地。

## 信息不对称，是内容人的朋友

如果把它拆开，其实由三个部分组成：位置的差异、认知的差异、行动的差异。

**位置的差异，指的是你处在信息链条的第几环。** 分享一张很有意思的图，叫“铁锤人”：https://x.com/lxfater/status/1950745399645638742

![](img/7718c21ae82e116d00505c64632703ba.png)

再推荐两个信源，来自张咋啦（前飞书产品营销负责人，字节AI业务出身，哈佛本科）。她的📕笔记里有一篇讲了怎么在YouTube上找到AI行业的一手信息：http://xhslink.com/m/1rgf8vq7tUx

另一篇笔记的链接也一并附上：http://xhslink.com/m/jytezFImI7

**认知的差异，体现在你能不能判断一个信息的含金量。** 拿nano banana来举例，市面上对它的认知可以切成六层：

1. 只是听说过，国内大多数人还停在这一层；
2. 理解了，知道它是做什么的、解决什么问题——各路媒体把概念普及完后，关注AI的人基本都能达到；
3. 感兴趣了，觉得被说得很心动，想亲自上手试试；
4. 动手尝试，找国内第三方平台或Google官方渠道，自己跑通一些想法或复现某些案例；
5. 把它工具化、流量化——做IP的自媒体人抓住机会收割流量，或者用vibe coding做点小工具、小应用来引流；
6. 产品化变现——比如出现了nanobanana.ai这个网站，和日活过10万的小程序，哪怕只是套壳赚差价，也能借着Google和自媒体自传播的势头分一杯羹。再往后，还会有人拿它的能力做真正颠覆行业的产品。

![](img/ca98ba175d058033b0a0501e88c87c3b.png)

**行动的差异，考验的是你把认知落地的速度。** 首先得闯过心态这一关。

推荐大家都去读一读《摆摊式创业》这本书。因为太多人有“曝光羞耻感”——总觉得自己普普通通，拿不出手；觉得自己没背景没作品，不可能在别人的主场胜出。

但事实其实是这样的：

1. 无论你在自己的领域能打多少分，总会有一批人需要你；
2. 你把信源质量和认知水平提上去，就已经能帮到那些信息落后于你的人；
3. 大语言模型时代有一个很有趣的现象——大家反而更喜欢口语化的表达，因为口语更有“人味”；
4. 形式永远盖不过内容，信息永远压不住观点——在信息爆炸的环境里，观点代表着你对信息的加工深度和专业水平；
5. 传播最远的内容，往往是那种“仰望15度角”的内容：你只比读者领先半步，他们踮起脚就够得着。

![](img/1da2b569bf9aeb8a6d83d4de042b82c7.png)

心态过关之后，还要直面一个更根本的问题：你到底想不想赚钱？很多人嘴上嚷嚷着搞钱，心里其实觉得钱“脏”，甚至不屑于谈钱。带着这种念头，钱怎么会往你这里跑。内心真正指向哪里，行动就会走向哪里。

把视角拉高一点：一人公司、SaaS出海、自媒体，这些听着高级的词汇，本质都是摆摊。摆摊的第一步，是把摊子支起来，而且要按时出摊——单靠“被动收入”的幻觉，顾客不会自己上门；按时出摊，是让那些来找你的人不会扑空。第二步，是学会吆喝，不然那么多人凭什么停下脚步选你？第三步，才是把好产品摆出来，卖给真正需要它的人，解决他们的真实痛点。

另外，摆摊不要嫌弃盘子小。先把摊子支起来，后面再找杠杆把财富放大——信息、认知、行动，三者叠起来就是财富。

## 推特起号的实操路径

最后，把推特起号的实操路径完整走一遍。

先交代几条前置认知。

**中推和英推怎么选？** 优先做中推。你没有在英语互联网世界浸淫过，不了解那边用户的习俗和“黑话”。目前从中文推成功切换到英文推的大号极少，尽管英文推的上限确实更高。

**蓝标开不开？** 不开的话，别人很可能不关注你、不回关你，发文有字数限制，还有传言说会被限流。怎么开才能省钱？把网页语言切换成其他区域，看看日区或者其他区的价格，开个premium档就足够了。

![](img/018900ea3d92739b9e36f016b9672e30.png)

**推特的三大主流需求**（键政和黄推除外）：情感和情绪价值、赚钱、学英语。这三个大需求还能延伸出不少细分赛道，有空就多去拆解那些小号的爆款内容，拆到一定程度会发现，你能模仿到的是它们的“神”，改掉的是它们的“形”。

接下来是账号培育。新号注册后，别急着操作，先让账号安静地待两三天，像普通用户一样每天登录、刷刷首页，看看大家在聊什么，给账号一个正常的“养熟期”。然后完善资料：换上真人头像，让账号看起来可信；把个人简介写清楚，说明你的兴趣和关注领域，增加辨识度。

做推特自媒体，先给你两个确定结论：只要持续更新，粉丝一定会涨；而搬运内容、分享工具，也能涨粉，而且速度不慢。

冷启动怎么做？要么就硬发——默默更新，哪怕每条只有几个曝光、几十个曝光；要么就写一篇个人故事贴，走“长文共情”或“战绩+共情+长线程”的路线，关键是让大V帮你转发，这是共赢。走这条路线，个人IP更强，起号更快，后期变现渠道也更多。举个实际案例，一条推文涨粉超过1000，具体见 https://x.com/GoSailGlobal/status/1949467524669776131 ，还有人专门拆解了它：Cell 细胞的拆解 https://x.com/cellinlab/status/1949662017155223798 ，营销启蒙老师铁锤人的拆解 https://x.com/lxfater/status/1950117226620625372 。![](img/9986947406500c6eda1e5f4d8c122e1d.png) 另一种“战绩+共情+长线程”的模板，案例同样有说服力：https://x.com/axichuhai/status/1955521806473069033 。![](img/536d6d2920063037e22066e782759b19.png)

到了进阶阶段，蹭热点就是基本功。比如歸藏老师用一个 nano banana 的话题，一周流量做到400万，参考：https://x.com/op7418/status/1962352258122944736 。![](img/cb361f3de8cc57826e505933bc701b99.png)

持续产出和放大，核心是理解“信息差”。信息差 = 位置差（你在第几手信息源）+ 认知差（你能不能识别价值）+ 行动差（拿到信息后行动多快）。

搬运看起来简单，但想做成大号，拼的是学习、检索和持续迭代的能力。这里有几个实用工具：飞书内容可以用官方剪藏插件 https://chromewebstore.google.com/detail/%E9%A3%9E%E4%B9%A6%E5%89%AA%E5%AD%98/mofcmpgnbnnlcdkfchnggdilcelpgegn ，也可以用 Cloud Document Converter https://chromewebstore.google.com/detail/cloud-document-converter/ehkomhhcinhikfddnmklbloahaakploh ；免费下载推特视频，用 https://twitterxz.com/zh 或 DataTool.vip；多平台素材下载器，用 https://github.com/putyy/res-downloader ；想看英文推主，用沉浸式翻译插件转成中文。

建立信息源也很重要：优先用RSS，官方RSS源，或者 RSSHub 提供的第三方聚合 https://docs.rsshub.app/ 。

总之，持续输出，表达你自己的观点。![](img/120fc61630b18e0c92e69f19103cc1b5.png)

接下来聊变现。我的自媒体收入已经接近五位数，主要来自这几个渠道。

第一种是咨询。咨询也是产品/服务：首先你得会“吆喝”，我的第一个咨询来自数字游民社群的群聊——我把出海内容分享到各个群，恰好遇到一个做情感化学习插件的客户，他有一些困惑想咨询。要敢定价，建议按以前上班时薪的2倍报价，之后再调。我第一次报价350元，因为是第一次，还打了折。客户一开始想做AI基础设施，在大厂情感交互的背景下，想从小切口做生态。但理想很丰满，现实很骨感：他没有考虑融资方案、收益方式、生态建设成本、人工成本、数据上链成本。我就一点点引导他：可以考虑从web3项目方融资，可以从B端转向C端，缩小应用场景，我还调研了一些产品给他。后续持续跟进，客户很满意，额外打赏了88.88元。![](img/241ed47b07ec442f3c1b4a68065cc669.png)

![](img/6facd86b2c2b45fb3ffd0070ae52a79b.png)

第二种是商单。要想接单，必须多曝光。我的第一个商单，是加入了向阳乔木老哥组建的博主群，迅速接龙、在飞书表格里填好信息，广告商就顺着表格联系了我。定价要敢，一般根据粉丝数和阅读量出价，大不了再降。前期别嫌商单价格低，粉丝少、阅读差就先开单，再迭代。更重要的是维护自己的信誉和商单数据，否则就是一次性买卖。![](img/becb9f2e081f9130aa10261e345844c2.png)

![](img/9a6c06388516c7cfcf95d70f48fabfe9.png)

![](img/f8c7f2a03ab0f0668c1a1f84cbee6ba8.png)

第三种是分销。首先，你必须是产品/服务的真实用户，否则影响口碑。其次要明白，分销对各方都有益：开发者获得更多订单，你获得佣金，用户通过你的链接得到优惠。一开始不要太在意佣金率。可分销的产品包括：别人的小报童/知识星球，SaaS订阅产品（可以用Affiliate或面包多生成分销链接，方便追踪订单来源）。

另外还有两种变现方式：一是“马斯克低保”——达到500M曝光，并且有500个蓝标认证关注；二是知识付费。![](img/c32ec609cab9d601d2d61bd547ba96f5.png)

复盘一下，我踩过的坑有：怕曝光，放不开自己；觉得自己是Nobody，没人看；想太多不行动——纸上得来终觉浅，绝知此事要躬行；总是盯着那些恶意评论；对没做过的事充满恐惧；过度内耗。

给新手的建议：现在适合做吗？当然，推特自媒体还是蓝海，赶紧下场。什么样的人适合做？如果你有自己的见解和知识储备，可以打造个人IP，为以后的产品和服务引流；如果你只想赚钱，那就搬运AI资讯快速涨粉，用商单、网盘变现、知识付费赚钱；或者分享工具和资料，做网盘变现，再引流到自己的网站做广告变现。
