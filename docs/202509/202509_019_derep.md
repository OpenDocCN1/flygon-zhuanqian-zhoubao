# (50 赞)创始人困境：改不了的人又无人可换，需搭建人才供应链
作者：龙哥

很多创始人卡在最难受的一个死结上：团队里有人怎么都带不动，想换掉却找不到替代者。于是只能忍着、耗着，最后整个公司都被拖住。

其实创始人的痛苦源头往往很简单——不是人不行，而是“改不了”和“没人换”同时发生了。改不了，说明你拿他没办法；没人换，说明你也没有备用选项。两件事叠在一起，就成了死局。

那真正的解法是什么？不是赌某个人突然开窍，也不是指望运气好招到完美员工。关键是把人才供应链建起来。只有持续有人才供给，你才有选择权，才不会被某个改不了又离不开的人裹挟着走。

所以，别把精力全花在改造那些改不动的人身上，更别让自己陷入“只能将就”的被动局面。建立稳定的造血机制，让人才源源不断补上来，这才是创始人走出困境的根本出路。

记住：改不了的人，就得换；而换人的底气，来自你手里始终有人可用。否则，痛苦只会一直循环。
