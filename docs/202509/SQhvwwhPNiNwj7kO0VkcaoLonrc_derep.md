# N8N 云端搭建避坑指南：从海外主机到域名解析，一篇讲透
作者：龙哥

很多人一听到“自己搭 N8N”就感觉门槛很高，其实拆开来看就是四件事：选台海外主机、装好运行环境、启动服务、再绑个域名。本文按这个顺序走，每个环节的坑和捷径都给你标出来。

## 一、主机怎么选？先避开最大的坑

买机器之前，先记住一句话：别碰境内机房。

不是开玩笑，国内服务器硬性要求 ICP 备案。备案流程起步就是一周多，这段期间网站无法正常访问；备完之后还可能接到回访电话。对想快速做项目的人来说，这套流程太消磨耐心。而且各种支付和登录能力也受限制，比如🛰️支付、支付宝、👸号扫码登录等，不是不能解决，但比较绕。

解决办法也有：登录可以走👸号验证码，收款可以用发卡平台或者个人支付服务。至于网速，只要选对位置，基本感知不到差异。最推荐的区域是香港、日本、新加坡，离得近、延迟低。

另外，选海外主机还送一个隐藏福利：很多国外工具和服务不用再折腾代理，直接就能访问。

下单时也要留个心眼。平台经常搞“低价秒杀”，看着很香，但不少套餐的地域只能选国内，而且可选范围就几个，买完反而被绑在备案流程里。别因为省几十块给自己埋雷。![](img/03196b93efd1010dd3d626616102cfa8.png)

具体到阿里云，打开轻量应用服务器购买页面就行。![](img/82adff857fd73748adc8413d15e54b8f.png)

配置方面，内存至少 2G，再小跑不动服务。新手入门的月付档位就够了，没必要一上来就上高配。![](img/023ab488d00fa80341b32bd979c11e97.png)

机房位置优先香港；如果你有其他用途，新加坡、日本也可以。购买时长建议先选 30 天，跑顺了再按月续费，别一买就是三年。

下单完成，机器会出现在管理控制台里。![](img/87c2a90e67e2f6f76bf647285df156e0.png)

一开始状态是“准备中”，等它变成“运行中”就能进一步操作了。![](img/d1853d9959d9953bbd927813329cd950.png)

第一次操作先设置 root 密码，设置完机器会自动重启，等重启结束就绪。![](img/aeb4a70b552a5005f215de0d8b185149.png)

## 二、装 N8N：不搞花哨，直接 npm

在云主机上跑 N8N，不需要宝塔面板，也用不上 Docker。你只是要跑自动化流程，不是建网站，环境越简单越好，和本地用 npm 安装的思路一致。

### 2.1 登录云主机

本地按 Win + R 打开“运行”，输入 CMD 回车。然后执行：

```
ssh root@你的公网IP
```

公网 IP 在云控制台的机器列表里能看到。![](img/ff07b794c108b32b3060c1369dec2ca3.png)

第一次连接时，系统会问你是否确认连接，输入 yes 回车。![](img/471b78e0d8237ce4b43b7f1067a1ce69.png)![](img/fbdafd94384387896b98b72697c85414.png)

接着会要密码。这里注意：输入密码时屏幕没有任何回显，别以为没输入，直接敲完回车就行。![](img/f61629b3a4e03227917fdef1771b0942.png)![](img/1b93305f3b3049ebc621bae25fe427a9.png)

登录成功后，命令行提示符会变成 root@主机名，看到这个就代表连上了。![](img/212bcc3fcb490ee46fb00040f4c25b16.png)

如果提示认证失败，多半是密码打错，重新输一次。实在不行，就去控制台重置密码再连。![](img/7ae7ea30d0e34de5cec7022fe247288b.png)

### 2.2 安装 Node 环境

先安装 NVM，复制下面这条命令到终端执行：

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
```

等命令跑完、光标重新出现，就代表装好了。![](img/7bdf9ffd4cc33e1b7028c1a47116df7a.png)

然后输入 exit 断开连接，再重新 ssh 登录主机。![](img/a8cd4771b398f19fbb0e2c2ab38fd907.png)

执行 nvm -v，能打印出版本号就说明 NVM 正常。![](img/40003b26552bf5e8bcecb76916e5d937.png)

接着安装 Node.js 最新 LTS 版：

```
nvm install --lts
```

看到安装成功的提示即可。![](img/5e22ce6514ee67baaf8de42ab5c7ce46.png)

再执行 nvm use --lts 切换到刚装的版本。![](img/8f3533cc42bd01d07f8d6f8275057254.png)

最后全局装好 N8N：

```
npm install n8n -g
```

这一步可能要等一段时间。终端里出现的 warning 可以直接无视，只有 error 才需要管。![](img/f46624a5c5fdba3c766637f0b2b57039.png)

如果卡住不动，最常见的处理办法就是把命令行窗口关掉，重新连上主机后再执行一次安装命令。![](img/7b0bf0d3bfd8b25d9ad348912742b68a.png)

看到安装成功的输出，N8N 就算装完了。![](img/54cf5d03e4adc3d97f09c1912e944787.png)

### 2.3 启动 N8N 并放行端口

执行 n8n 启动服务，启动完成后，浏览器访问地址就是 你的IP:5678。![](img/051574a0b26efb87981c17a4e9a1feed.png)

不过要先去云控制台的防火墙里把 5678 端口放行，否则外部无法访问。![](img/29783a13c84c726c8241f4d54bf41a06.png)![](img/f719567fef58007d8bb8234c05c69e79.png)![](img/77da4a4fff5dbe7642745f420df77428.png)

首次访问时，N8N 会因为没有配置域名和 HTTPS 证书而拒绝进入，这是它的安全机制，不是 bug。![](img/4d9a8a9e799bb12ce9929e426b5473ee.png)

想先绕过这个限制的话，可以这样操作：

先查看当前 n8n 的进程：

```
ps aux | grep n8n
```

找到进程号后，用 kill -9 结束它。![](img/383fb2917c86518dc4cd409acfffc49d.png)

然后用下面这个命令重新启动 N8N，跳过安全检查：

```
N8N_SECURE_COOKIE=false n8n
```

再次访问 IP:5678，就能进到 N8N 界面了。![](img/170c38bd306baef5279c00479423cf23.png)![](img/c9a2572016a9bd73dc2af4837c74757d.png)

页面右下角如果出现报错提示，不用管，不影响正常使用。另外提醒一下，云端和本地的数据是隔离的，就算用同一个账号登录，也需要在云端重新激活。![](img/8df7f7bf03cad26df5b80363534939fb.png)

### 2.4 用 PM2 防止服务“突然消失”

直接靠命令行跑 N8N，有个很现实的问题：终端一关，服务可能就断了，好不容易搭好的流程会跟着没。所以建议再加一层守护：

```
npm install -g pm2
```

安装完成后，先杀掉之前的 N8N 进程，然后用 PM2 来启动：

```
N8N_SECURE_COOKIE=false pm2 start n8n --name my-n8n
```

这里的 my-n8n 是任务名，可以改成任何你喜欢的名字，只要后续命令保持一致就行。

日常管理命令：

- 查看状态：pm2 list
- 停止：pm2 stop my-n8n
- 重新启动：pm2 start my-n8n
- 重启：pm2 restart my-n8n

如果发现服务访问不了，先看 pm2 list 的输出：没有任务存在，就重新执行启动命令；任务存在但状态不对，就 start；任务在线仍然异常，那就 restart。![](img/94b62a6adb390e88a800ffee87ca4e2e.png)

## 三、域名购买：NameSilo 很省心

云主机搭好后，再配一个合适的域名，后续做 HTTPS 会方便很多。域名商推荐 NameSilo，理由有三：海外注册商事情少；支持支付宝；域名价格不贵。

购买流程如下。

注册并登录后，在搜索框输入想要的域名关键词，回车。![](img/7d8fd2b8ec3da1cb17d8e5173c97352f.png)

选一个后缀合适的域名，放入购物车。跑自动化流程的话，没必要买贵的后缀，最便宜的就行。![](img/8f653d07ebb30549b08de1c9ef290dec.png)

点击购物车后，页面会出现绿色按钮，继续往下走。![](img/87de64ad6ff7fc2cecab59ca4e381a9b.png)

进入订单页时注意盯住付款金额，确保自己只买了域名本体，其他默认勾选的服务一律取消。![](img/ccb257bbe6bace6c10b565987fb6bb03.png)

支付方式先点 see more，再选择支付宝。![](img/b38f6ad0023d72c2843c22522644c006.png)![](img/eb2b7e0467ee5fe1acad4e49c7451071.png)![](img/5f8e310b882ac60d5367c3be9250d1f2.png)

地址栏可以不填真实信息，不确定写什么就搜一下“美国地址生成器”。![](img/7c0ff3d8418c9c6ebf363349c74efa3a.png)

勾选同意条款后确认支付。![](img/34d8cb48a8e9f6ab386a59373d061bbe.png)

弹出二维码后，用支付宝扫码完成付款。![](img/a4811311d11cfa06df0852e8229eda7f.png)

支付完成后回到网站首页，点击右上角头像，进入 My Account。![](img/d5f01f1f5896d1a5c684f0a83a3bd586.png)![](img/c707a3f31ff22e62f7425e353cd9efed.png)

在 My Account 中找到 Manage，点进去就能看到你买到的域名列表。![](img/d91af9ec93398574c188f5f5e2039bba.png)![](img/ba1a0a84ec01bbb2a9cccb62b1ffa9a9.png)

## 四、用 Cloudflare 把域名绑到云主机

域名解析推荐用 Cloudflare，免费方案就能满足需求。注册/登录后，如果看英文界面不习惯，可以切换成中文。![](img/3cafee369a62a97e148aa70ae2244a24.png)

在 CF 后台输入你的域名，选择快速扫描 DNS 记录，然后继续。![](img/3d69f45eca215bc5de25fc99a82b9939.png)

套餐选择免费计划即可。![](img/a7cfc5f22637557dfcee565b580a973f.png)

接着按提示填写 DNS 记录，把域名解析到你的云主机公网 IP。![](img/2dd2cc9c660c7a64f04bf6c3ee6ca10c.png)

填写完保存，再点击“继续前往激活”。![](img/b6230ac82b6f545fb51357a0189f894c.png)

接下来会进入等待激活的页面。![](img/710afd843a00cf4519dec0f5424bc816.png)

这时候需要回到 NameSilo 的域名管理后台，找到 Change Nameservers。![](img/6f7c648fbfa97cf828ac37a84f8a912a.png)

把原有的 NameServer 记录清空，改成 Cloudflare 提供的那两条。![](img/2827a84ef8406cb33c6e503988adcdfe.png)

确认无误后，点击提交。![](img/ed11844a6cdaa4770a781c449e93d3cf.png)![](img/f2937b31bea95ded4bd487be775d8320.png)

NameSilo 这边会显示“处理中”，再回到 Cloudflare 点击继续。![](img/a24cc32be581aa99e9cdc9bbf8b9bdee.png)![](img/843d453bcf901e39050ddd4209797ce3.png)

域名生效时间不太固定，快的话 10 分钟，一般半小时内都能好。![](img/410bf58151fac82e0e3c345c2fbd1731.png)![](img/1f6558be005b626e9049184a0e569d67.png)

生效后访问域名，如果发现打开的并不是 N8N 页面，先别慌。原因很简单：N8N 跑在 5678 端口，而网址默认走 80/443 端口。想象你要进一栋房子，正门锁着，你又想从窗户翻进去，当然进不去。解决思路是把 80/443 的流量转发到 5678，并补上 HTTPS 证书。![](img/c1a8810d6d5bd90b7bcee2b05d60c390.png)

这部分的完整操作篇幅不短，如果这篇反响不错，我下期专门写一篇“域名+HTTPS 证书配置教程”，记得在评论区告诉我。

## 五、最后几个小提醒

- 云主机暴露在公网上，容易被人扫描和试探，尽早配上 HTTPS 会更安全。
- 所有命令建议直接复制，不要手动敲，差一个空格都可能导致报错。
- 每一步都按顺序执行，不要跳步，很多问题都是跳步造成的。
- 命令行里执行成功通常没有输出，这本身就是“成功”的信号。

到这里，N8N 云端搭建和域名绑定就完成了。打开浏览器，输入你的域名或 IP:5678，就能随时随地访问自己的自动化流程，不用再担心本地电脑关机导致任务中断。希望这份攻略能帮你顺利上岸，我们评论区见。

想在自己的域名下顺畅访问 N8N？跟着下面几步走，小白也能轻松搞定。

**第一步：进控制台，连上服务器**

打开你的域名控制台，找到“远程连接”按钮，点进去。

![](img/b4e04dda9599cd7f4ba01dd14090583b.png)

**第二步：选密码登录**

在登录方式里，选择第二种，也就是用密码登录。

![](img/73050f2ba4b72447fa120dbe8c078fe9.png)

**第三步：登录成功后的界面**

连上之后，你会看到类似这样的命令行界面。

![](img/300780842dd445b08da7f4f7ea0848c2.png)

**第四步：先停掉旧的 PM2 服务**

如果你之前用 PM2 跑过 N8N，那得先把老服务停掉。

先输入这条命令，看看当前有哪些服务：

```bash
pm2 list
```

![](img/816930583b37ae3be2bb8aae59e999b8.png)

如果列表里有服务的状态是绿色的 `online`，那就执行下面这条命令来停止它：

```bash
pm2 stop my-n8n
```

注意：`my-n8n` 只是示例名称，你要换成你自己实际的服务名。执行后状态会变成红色的 `stopped`，这样就对了。

![](img/6126d5d9cb04baa5c70bae22d0a471eb.png)

**第五步：让 N8N 跑在 80 端口**

把下面这段命令复制到终端里，然后把 `WEBHOOK_URL` 后面的地址改成你自己的域名。

```bash
N8N_PORT=80 \
N8N_LISTEN_ADDRESS=0.0.0.0 \
WEBHOOK_URL=https://你的域名 \
N8N_SECURE_COOKIE=false \
pm2 start n8n --name my-n8n
```

注意看屏幕上有黄色背景的部分，那里是示例域名，务必替换成你自己的。粘贴完成后，直接按下回车！

![](img/8efb2d38b60efd02d14a6fa77cbbfbab.png)

**第六步：调整加密模式**

最后一步，进入设置，把加密模式改一下。

![](img/cb2410987cdf68dc34c2f8f099715b10.png)

选择【灵活】这个选项。

![](img/5ac459e55f40bdfec6a32ea5c3978e79.png)

然后，就搞定了！

现在直接在浏览器里输入你的域名，就能打开 N8N 开始使用了。

![](img/ce81f7363672d87cf2277e58d991bee2.png)
