# 别跟基因谈恋爱，你是在和它打仗
作者：龙哥

我们总以为长寿是人生的终点，却忘了基因根本不在乎你活多久。

基因的KPI只有一个：把自己复制下去，让拷贝尽可能多地散播到世界里。它要的不是个体活得久，而是活得够用。母螳螂吃掉交配过的雄性，只为给下一窝孩子攒点营养；蜉蝣成虫活一天就死，只要当天把卵撒下，任务就算完成。天地不仁，用万物当柴火烧，大概就是这个意思。

对基因来说，个体的舒适度、痛苦值，都是可忽略的噪音。分娩的撕裂与剧痛，在它眼里只是繁殖的代价。年老时的行动不便，也不会触发任何保护机制。

人类之所以显得特殊，是因为我们生来未完成。从出生到独立需要漫长的喂养与陪伴，上一代甚至要帮着带下一代。这种社会性抚育，让基因对我们的使用期限做了精打细算。在没有现代医疗的年代，熬到四十岁，基本就把传宗接代的活儿干完了。基因给我们配备的“质保期”，也就三十多岁到四十岁左右。往后每多活一个个体，就多一个竞争者去抢食物、抢水源、抢阳光。

一旦过了设计寿命，身体就会开始逐项罢工。

三十来岁开始，熬夜一晚第二天很难再满血复活。到了四十岁，眼角的老花悄然上门，骨头的钙在慢慢流失，肌肉如果不主动去撑，骨骼就会先垮。四十五岁以后，男性的前列腺会慢慢变大，排尿开始费劲；女性则面临更高概率的尿失禁。一个尿路长一个尿路短，各有各的麻烦。

与此同时，血压、血脂、血糖在悄悄爬升，血管弹性在下降，随之而来的是冠心病、心梗、脑梗、中风、心房颤动这一串心脑血管的连环套。肝胆肾也在掉链子，胆结石、肾结石的概率显著提高。

更底层的是端粒在一点点变短。压力越大，变短越快。端粒缩短后，DNA复制出错的概率飙升，出错累积到一定程度，细胞就开始失控。那就是癌症。癌症不是外来病毒入侵，而是人自己的细胞复制时弄错了代码。年纪越大，代码出错的机会就越多。

关节的半月板持续磨损且无法逆转，头发变白、掉落，牙齿松动老化，听力衰退，皮肤松弛下垂……这些都是不可逆的损耗清单，基因从未承诺会修复。

但这并不等于我们只能听天由命。基因给了我们一个使用手册上限，生活方式却能决定我们离那个上限有多近。健康的作息、合理的运动和饮食，依然能让身体状态保持得更好，把寿命往后推，并让晚年的生活质量不至于太难看。

我自己也曾被健康问题逼到墙角，过去两年里系统地学习了相关课程，做过不少自我实验，证伪了一些流行说法，也验证了一些真正管用的方法。为了把状态拉回来，我找了两位专业人士长期配合：一位是运动康复专业的训练教练，负责我的身体训练；一位是药学与功能医学背景的营养师，负责日常饮食的设计。走了这一圈，我对健康有了更落地的理解。

后面会慢慢把这些思考拆出来讲。
