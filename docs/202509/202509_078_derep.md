# (精华帖)(97 赞)n8n 自动复刻千种爆款带货视频，并发布到带货平台

**从“社恐程序员”到 n8n 航海教练，一套工作流让我批量复刻爆款带货视频**

大家好，我是龙哥。今年6月初正式加入「龙哥盟」，当时怎么也没想到，不到三个月，我就被官方邀请成为航海教练——收到消息那晚，激动得完全睡不着。

其实我以前是个典型的“技术宅”：00后，科班程序员出身，一毕业就扎进代码里，几乎零社交。加入赚钱后，我陆续参加了13场北京圈友的线下饭局，认识了一大帮同频的人。从最初坐在角落不敢开口，到现在能上台做分享嘉宾，身边的圈友们都见证了我的变化。每次线下交流，都比线上聊几百句来得更直接、更有冲击力——这也是我成长最快的秘诀。

当然，能走进这个圈子，要感谢当初拉我入伙的学长，光电话就聊了两个小时。回头来看，今年做的最值的一个决定，就是让自己泡在一个高能量的圈层里。被周围人带动着，才会真正往前走。

这次想分享的，是我用 n8n 搭出来的一个自动化工作流：**自动复刻上千种爆款带货视频，并且直接发布到带货平台**。整个流程从拆解爆款、生成素材到成片发布，基本全程自动运转。不少圈友关心成本，以5秒的视频为例：画面生成大概0.7~1元，如果选顶级模型做视频，大约2~4元。整体下来，性价比相当能打。


这是我入驻赚钱后写的第一篇长文，内容可能不算完美，但希望给同样在做带货、做内容的朋友一点启发。越分享，越幸运，之后也会继续输出更多实操干货，欢迎大家一起交流。
