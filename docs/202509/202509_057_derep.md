# 四五十岁就被脑梗心梗带走，为什么创业者要更警惕？
作者：龙哥

最近云海肴创始人赵晗 40 岁因心梗离世的消息，再次把一个残酷的现实推到台前。创业这条路，拼的是脑力与耐力，但身体的账，到四五十岁往往会集中清算。创业者本就长期处于高负荷状态，健康风险其实远高于普通人。

那么，为什么这个年龄段的脑梗、心梗会集中爆发？本质上是血管系统在多重打击下崩溃了。

先说血管本身的脆弱性。吸烟尤其是尼古丁，会直接损伤血管内皮；年龄增长也会让血管弹性下降。同型半胱氨酸水平过高时，它会像砂纸一样刮伤血管内壁。

当内壁受损后，关键变量是低密度胆固醇的状况。LDL 进入血液后，如果遇到氧化应激产物，它会变性。什么会产生氧化应激？高盐高油高热量的饮食、睡眠剥夺、长期高压、体重超标，都是典型的诱因。

变性后的坏胆固醇更容易嵌入被划伤的血管壁，久而久之血管壁增厚，随后发展为动脉粥样硬化，斑块里充满炎症因子。

一旦斑块破裂，内部的炎症物质瞬间释放，激活凝血机制形成血栓。血栓堵在脑部就是脑梗，堵在心脏就是心梗。

因此我一直强调，先把低密度胆固醇这个数值管住。它升高时，通常没有任何自感，等到发病就是大事件。好在 LDL 并非只能靠药，绝大多数人通过生活方式就能有效改善。如果调整效果不佳，规律使用他汀类药物也是成熟的医学手段。

风险是叠加的。如果你本身 LDL 偏高，再叠加动脉硬化、年龄偏大、慢性压力、睡眠不足、超重、血压偏高，每多一个风险点，发生心梗脑梗的概率就指数级上升。年纪大血管越不抗冲击，血压高会不断冲击斑块，肥胖、熬夜、焦虑都会加速胆固醇的氧化与沉积。

还有一类特殊人群要额外注意，即携带 APOE4 基因型的人。这种基因型天生对胆固醇的代谢能力较弱，心脑血管事件往往提前出现。据说这类人群用他汀更容易出现不良反应，所以更推荐以生活干预为首选，但前提是必须更早更严格执行。

胆固醇的危险之处就在于“静默”。高血压会头晕让人警觉，胆固醇高却毫无感觉。

想把风险降到最低，做这几件事就够了：

1、彻底戒烟限酒。
2、饮食上控糖控盐控油，主动减压，保证早睡早起。
3、运动要做组合，每周至少150分钟，做有氧搭配力量训练。
4、控制体重，回到合理的体脂区间。
5、荤素搭配合理，摄入优质蛋白和好脂肪。
6、补充欧米伽3，比如三文鱼、亚麻籽、核桃、松子。
7、减少高胆固醇食物摄入，鸡蛋除外。
8、每半年一次系统体检。

最后说明一下，以上内容属于普适性科普，个体差异很大。涉及用药和深度调理，请务必咨询营养师或功能医学医生，结合自身检查结果制定方案。
