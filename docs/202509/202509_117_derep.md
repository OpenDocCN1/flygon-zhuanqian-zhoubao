# 想真正变好，就给自己装一个“强制函数”
作者：龙哥

最近刷到一个很有意思的概念——forcing function，翻译过来就是强制函数。

它说的不是数学公式，而是一种行为管理的玩法：给自己立一条完全没有商量余地的死规矩，用这条硬杠杆逼自己去行动。

说实话我之前没听过这个名字，但回头一想，我自己很多年的日常，本质上都在用这个逻辑。

减肥的时候我给自己定的规则是：每天早晚各称一次体重，如果当天早上比前一天重，哪怕只多一点，今天的饭量直接砍半。没有商量，没有“明天再说”。这个不能讨价还价的底线，就是最典型的强制函数。

读书写作也一样。我长期在读书群里坚持每天发500字心得，不是靠热情，而是靠一道强制函数——今天不交作业，明天就断档。所以我必须每天读、每天想、每天写。正是这条硬规则，逼着我保持输入和输出的节奏。

工作里更是如此。以前在广告公司做创意时，我给自己立了规矩：每天至少看完5个外部新创意，不管当天忙不忙。创作不是靠等灵感，而是靠强制建立的信息触达量。

下班前花15分钟复盘当天做了什么、卡在哪、明天怎么改，也是一种强制函数。它把“总结”从一件可做可不做的软任务，变成了必须完成的硬流程。

生活中的小事也能用。衣柜塞满了怎么办？给自己设个数量锁：每买一件新衣服，就必须扔掉一件或送人。想断舍离，不靠意志力，靠规则强制。

强制函数的核心就在于把模糊的“我想进步”变成清晰的“做不到就必须付出代价”。当短期内没有奖励也没有惩罚时，人很容易启动所谓的随意函数，今天拖明天，明天拖后天。真正的差距，往往就在于是否愿意给自己立规矩。

当然，规则只是外壳，内驱力才是根。但在内驱力还没被点燃之前，一套靠谱的强制函数，恰恰是点燃它的引线。

想进步，不妨从今天开始，给自己装一个不能反悔的强制函数。
