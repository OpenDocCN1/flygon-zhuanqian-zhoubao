# 打开眼界之前，先想想你看见了谁

前几天读到一句话，越想越觉得有道理：

“见贤思齐”，这四个字里，真正决定命运的其实不是“思齐”，而是“见贤”。你能看见什么样的榜样，才会生出什么样的向往。很多人焦虑自己不够好，但真正的问题是——你身边有没有那样一个人，让你觉得“我也想成为他那样”？

这就像一个人想学画画，如果他从没见过大师的作品，他以为画得好就是把苹果涂得像苹果。可一旦他看见莫奈的睡莲，看见梵高的星空，他心里那根“原来还能这样画”的弦就被拨动了，从此他向往的方向就变了。

见贤的意义就在于此：它给你设定了向往的坐标。你见过谁，决定了你想成为谁。

这也是为什么那么多过来人会告诉你：圈子很重要。那个一万多一年的“航海家”社群，值钱的地方就在这里——它不仅是学东西，更是让你站在一群优秀的人中间，亲眼看见别人是怎么思考、怎么行动、怎么把日子过出花样的。有了这些“贤”在眼前，你的“思齐”才有了具体的方向，而不是空空的自我鞭策。

所以说，与其闷头努力，不如先抬头看看，你面前站着的，是谁。
