# (精华帖)(135 赞)从零开始 b 站好物深海圈，只发了两个视频，开始日入 1000，3 天速通深海圈，预计 10 天破万收益，我做对了什么？

最近刷到一个让我很受触动的案例：有人从零起步做B站好物，只发了两个视频，就实现了日入千元的利润，三天就把投入的成本全赚回来了，还预估十天内收益能破万。关键在于，他并不是什么大V，也没砸钱投流，就是从一个普通新手开始的。

这位作者叫鹿书野，主攻B站好物，加入了平台推出的“深海圈”计划。他自己都感慨，B站好物这波红利实在太猛了，正反馈来得快得惊人——第一个视频就有人下单，第二个视频直接引爆收益。从0开始，也能摸到这么高的天花板，这是他之前完全没想到的。

他把这段经历写成了一篇万字长文复盘，从自己花了多少时间，到做了哪些关键动作，再到遇到问题时怎么拆解思考、哪些环节必须死磕到及格线、又如何去达成这个及格线，以及视频内容可以怎么优化升级，全都写得清清楚楚。他说写这篇帖子光净时间就花了12个小时，前后跨了一周，读一遍大概需要20分钟。内容不只是鸡汤，还有大量可以照着做的实操方法。

评论区里也是一片好评。有人说他人在交流群里毫无保留地分享经验心得；有人夸他能做出这么深的思考，成事几乎是必然的；还有同期的报名者表示，看到他拿到结果，自己也终于有了执行力，准备全力开跑。

如果你也想了解B站好物是怎么从0到1跑通的，不妨去读读他的完整复盘，链接放在素材里了。红利就摆在眼前，行动快的人已经在数钱了。
