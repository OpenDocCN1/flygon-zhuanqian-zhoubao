# ('(193 赞)熬夜不是奋斗，是消耗：请学会可持续成长', (2, 28))

别再信奉“熬夜式努力”了，那只是在透支自己。

身边总有人说：不熬夜，怎么拼得过别人？可在我看来，熬夜从来不是奋斗的勋章，而是对身体储备的一种亏空。真正明智的做法，是让赚钱这件事具备可持续性，而不是靠损耗健康去换一时收益。我始终反对熬夜，也不认为把熬夜做项目包装成经验来分享是对的，特别是在生财这类社区里，拿这种案例当榜样，本身就是跑偏了。

为什么可以慢慢来？因为咱们这一辈人的寿命预期真的可能很长，活到150岁也不是小概率事件。把眼光放到这个尺度上，哪怕你已经40岁，也依然是个年轻人；更别说才20多岁的你，基本就是小屁孩一个。前不久有位50多岁的大哥，正兴致勃勃地学AI编程做Web3工具，他说50多岁正是奋斗的好时候。别觉得荒谬，我们这一代人，大概率都会活成这个样子。

所以，请别急着鸡血满满，也别在深夜自我感动。试着把作息往前调一调，争取在夜里11点前放下手机，睡够8小时。吃好三餐，规律运动，稳定心态，赚钱这件事，慢慢来反而更稳。

身边就有活生生的教训：有人一到晚上就心慌心悸，各种检查都查不出问题，最后发现是长期熬夜加上咖啡因摄入过量；也有人年纪轻轻，55岁、60岁就骤然离世，让人惋惜。挣钱明明是场马拉松，你却偏要当百米冲刺来跑，图什么呢？想省时间，就好好利用AI这类工具，而不是压榨睡眠。换个思路，早睡早起，用清晨的高效时段去创作，说不定比夜猫子模式更能形成差异化优势。

说到底，活得足够久，才是人生最大的复利。今晚，早点睡吧，明天的事，明天精神饱满地再做。
