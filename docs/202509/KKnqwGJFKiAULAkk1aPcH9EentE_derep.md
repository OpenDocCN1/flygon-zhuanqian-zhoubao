# 一、色彩：别再凭感觉乱配了

有没有觉得自己的页面越改越奇怪？十有八九是颜色在拖后腿。

完全不懂色彩理论，也想搭出顺眼的配色？其实很简单。

第一步：先定主题色。别贪心，一个主色就够了，其余颜色都围绕它来展开。

第二步：请工具帮忙。配色网站已经把所有色卡都给你搭好了，直接拿走去喂给AI，省时省力。下面这几个配色网站是我自己很爱用的。

## Khroma

它的特点是会用AI慢慢“学习”你的审美——你只需要点选50个最喜欢的颜色，它就能用轻量神经网络算出专属你的私人色板。不用注册，颜值也高。多玩几次，你会越来越清楚自己的色彩偏好，下次定主色也就不纠结了，连“配色肌肉记忆”都能练出来。

网址：https://www.khroma.co/

![](img/96bf870361ba559a273e6050b9cde90f.png)

![](img/42bd8bed50e481774ad5c6735f8c10b0.png)

## Coolors

按一下空格键就帮你随机生成一整套色板，还能从图片里提取颜色、检测对比度、实时预览效果，要落地干活选它准没错。支持收藏、分享、多种格式导出，手机App和Figma/Adobe插件都有，设计和前端在同一个平台上就能把颜色敲定。

网址：https://coolors.co/

![](img/4152899e119172e124a9930f3371cff1.png)

## Web Gradients

一个免费的渐变背景图库，收录了大约180组线性渐变。点一下就能复制兼容所有浏览器的CSS，也能直接下载PNG，还附赠Sketch/Photoshop的素材包。做网页背景、按钮、封面，拿来就能用。

网址：https://webgradients.com/

![](img/2beab30ff230015162dc9b20c527e791.png)

# 二、字体：它是品牌的“声音”

字体这玩意儿，相当于品牌在开口说话。说到免费字体工具，Google Fonts依然是首选。字体家族里两大门派要分清楚：

*   非衬线体：利落、干净、亲和力强，数字产品里最常见
*   衬线体：古典、端庄、气场足，金融、出版、奢侈品圈子最爱

## Google Fonts

找不到合适的字？直接去Google Fonts逛一圈，按项目需求筛选、预览、下载一步到位。

## 非衬线体 Sans serif

这派字体的特征是笔画的末尾不带任何装饰尾巴，造型干练、直给。科技、互联网、时尚、创业公司这类网站尤其喜欢用它，传递的气质就是现代、友好、不设防。

## 衬线体 Serif

衬线体的标志性特征是：字母笔画的头尾处带有一条小横线或装饰性细线。这其实是印刷时代的遗产，当初是为了让纸上阅读更省力。如今这类字自带一种正式、传统、权威且优雅的滤镜，书籍、报刊、杂志，以及金融和法律类网站都偏爱它。

Playfair Display

灵感源自18世纪的排版艺术，线条修长柔美，自带奢华与高端的标签，大标题和品牌展示的最佳拍档。

![](img/f5b05b381a726576fe12f1a13baafd7a.png)

Libre Baskerville

脱胎于经典Baskerville，针对屏幕阅读做了专门优化，正文和需要营造信任感的品牌场景都能胜任。

![](img/2044ca2ae5d3fff2d0454ff4c020bdcb.png)

Soria

受新艺术派和Didot风格熏陶，线条摩登有型，做logo、横幅这类需要抓人眼球的设计很出彩。

![](img/4b205a12803529dc541661ea60fc4149.png)

Neuton

荷兰血统，几何结构分明，省空间能力一流，标题正文通吃，又现代又精简。

![](img/ffbc60e6791d5efa0a7b681f9b15b806.png)

Lora

现代衬线体里的文艺担当，带一点手写笔意，线条舒展。大标题和正文都能驾驭，优雅和易读兼顾得恰到好处。

## 动效工具

### GSAP

GSAP官网网址：https://gsap.com/

如果想玩点艺术感更强的动效，GSAP绕不开。Awwwards上的不少神级网站背后都是它。

GSAP和任何框架都能配合，自由度极大——用简单的补间动画就能给任意对象的任意属性加动画。

想学具体功能，官网有现成教程视频。

![](img/ea0079245b42ff09aa42344150e480c8.png)

#### GSAP-Core

核心包可以通过插件扩展不少高级玩法：

*   Flip：让元素在不同状态间无缝切换
*   ScrollTrigger：让动画和滚动条联动，滚动特效分分钟安排
*   MotionPath：让元素沿着自定义轨迹运动
*   Draggable：页面元素拖一拖、转一转
*   Observer：监听五花八门的事件，收集动态数据

![](img/fa830f916ea8c7d3aad970d3e2bb18e6.png)

#### GSAP-Scroll

经常眼馋别人网站的滚动阻尼效果，自己却不知道怎么下手？GSAP在滚动这块确实强得离谱：

*   ScrollSmoother：滚动变得丝般顺滑，用户体验直线上升
*   ScrollTrigger：动画与滚动条绑定，滚到就自动触发
*   ScrollTo：页面平滑跳转到指定位置，导航常用
*   Observer：捕捉滚动、触摸等事件，自由定制交互

![](img/ba08bd32db575b108e999bd7962ce9c9.png)

#### GSAP-SVG

*   MorphSVG：让SVG路径自然变形，圆变爱心之类的，适合艺术和品牌动画
*   DrawSVG：让路径像被画笔“画”出来一样逐渐呈现，手绘风和进度条都是一把好手
*   MotionPath：对象沿自定义路径跑动，流程演示和数据可视化都能hold住
*   MotionPathHelper：直接在浏览器里编辑运动路径，效率翻倍
*   Draggable+Inertia：SVG元素可拖、可转、可甩，还带惯性，互动小游戏能干起来

![](img/908567899080f66af2ed5bfbf3f849ee.png)

#### GSAP-UI

*   Flip：元素在状态之间平滑过渡，卡片翻转、列表重排都是它的拿手好戏，做界面切换和动态布局很适合
*   SplitText：把文字拆成单字或单词，逐个逐段做动画，标题、广告、艺术展示都爱用
*   Observer：监听滚动、点击、滑动等事件，收集变化数据，做自定义交互和高级动画控制
*   Draggable+Inertia：页面元素拖拽、旋转、甩动，还带真实惯性，互动组件、小游戏、健康类交互工具都能做

![](img/575ae7ab9802094c1f5a6aa5cbf44981.png)

#### GSAP-Text

*   SplitText：
    *   把文字切碎成字符、单词或行
    *   每一部分都能单独做动画
    *   兼容嵌套标签和emoji
    *   分隔符可以自定义
    *   滚动、逐字逐词动画好帮手
*   ScrambleText：
    *   文字内容随机打乱
    *   可只打乱字母、数字或大小写
    *   悬停、加载等动态效果很带感
*   Text：
    *   逐个字符替换网页上的文字
    *   打字机、逐步显示文字动画常客

### 用积木式思路拼装落地页

前面拆解过的各类组件，本质上就是可复用的积木。你的任务只是像拼拼图一样，把模块和文案放到合适的位置。

一个标准的着陆页通常由这些板块构成：

*   导航栏
*   首屏标题区
*   产品核心功能介绍
*   CTA 行动召唤
*   用户评价
*   定价方案
*   常见问题
*   页脚导航

![](img/52781370fdebb1a824a248bab6a84779.png)

![](img/095be9ef48246e12f6eace43f8723a66.png)

你可以让 CC 或其他代码类工具先帮你生成一份 design.md，把字体、色值、响应式等设计规范写进去作为约束条件。

目前用 GPT、Gemini、Claude 等模型生成落地页示意图的效果已经很可用，整体框架基本能还原我之前在 Figma 里画的版式。识别出对应区域后，直接把合适的模块填进去即可。

随后就是配图和动效环节。依据页面功能挑选合适的图片和视频，加入点击交互动画。这一步可能需要用到剪辑工具，对某些精美素材做剪辑拼接。

最后把你希望统一的配色色值丢给 AI，让它帮你做整体色彩校准，基本就收尾了。

Launch UI 兼顾免费和付费。免费版对个人和初创小团队永久开放，包含 1 个网站模板、9 个区块和 4 个自定义动画。高阶功能需要一次性买断 $99。

![](img/3ab312e6638dda4b8169a2ec43e79841.png)

Github 上也有不少开源可用的模板：

网址：https://github.com/cruip/tailwind-landing-page-template

![](img/0ab04f66b3a53e2b76783a4b6d1a000c.png)

# 5. 设计师常用的资源站点

最后汇总一些我日常找素材、练审美的工具站，希望能帮你更快找到合适的免费资源，提升审美判断力。

## Pinterest：

亮点：需要🪜，但体验极佳，是全球最大的视觉收藏站；借助瀑布流和强推荐机制，几分钟就能搭起灵感板，覆盖平面、家居、包装等多个品类。找参考图、发散灵感都很顺手。

官网网址：https://www.pinterest.com/

比如搜索 Landing page，点进第一张图后系统会持续推荐同类图，再点开喜欢的图还能继续联想，循环往复。

![](img/9a90ff843226bdb58d0bb5d9c328aa17.png)

![](img/e54aa74f636dfea4e4130e85f90611be.png)

## 站酷：

亮点：中国最大规模的设计综合社区，作品发布、招聘、赛事、教程一站式。内容更新快、活跃度高，是获取行业资讯和灵感的主阵地。

官网网址：https://www.zcool.com.cn/

在站酷上也能找到合适的合作设计师。

![](img/6c32741ca297749150f44c16df165930.png)

![](img/84929cc2713f458fcfbd427c68de85cf.png)

## 花瓣网：

亮点：国内的素材与灵感收集平台，和 Pinterest 类似，支持私密画板和标签管理，便于做 mood board。最大优势是不用🪜，国内直连可用。

官网网址：http://huaban.com/

![](img/d0f4cc5aa07416d26a3d4b6bd06071d8.png)

## Noun Project：

亮点：汇聚 800 万+ 免费 SVG、PNG 图标和高质量照片的资源库，广泛服务于设计、演示、网站和 App 开发。全部资源可免费下载，支持个人和商业用途，版权说明清晰。平台通过 API、插件和付费授权盈利，并扶持原创作者。

官网网址：https://thenounproject.com/

![](img/85e81909bf0e247bf8a9b667726b0675.png)

## Lucide icon：

亮点：开源图标库，提供多风格分类的 SVG 图标，支持个性化定制和商用。

官网网址：https://lucide.dev/icons/

![](img/b43ffbb1b07cc17612e28f714ae878aa.png)

## Figma：

亮点：内置模板与插件社区；可下载 UI Kit、设计系统、白板模板，或安装提升效率的插件，全部云端协作。现在 Figma 已集成 AI，用自然语言描述需求就能自动生成界面草案。

官网网址：https://www.figma.com/

模板入口：https://www.figma.com/community 打开社区后搜索你想要的类型。

![](img/644e12f304aa4e6a9afbb2c8a90c97ea.png)

![](img/b0fa09b5d45a63ed1b617090a9f1001e.png)

## Awwwards：

亮点：聚焦网页和互动体验的评选与灵感库，每日 Site of the Day、年度趋势报告都是 Web 设计风向标。收录的站点都极具观赏性，很适合培养审美和了解海外前沿趋势。

官网网址：https://www.awwwards.com/

首页可查看 site of the day/month/year。

![](img/12604fd86b1ccf33b4e24ec72a8debf4.png)

按需求筛选想要的作品类型。

![](img/7f23312401e835c1f7116c0ad400920d.png)

### Dribbble：

亮点：一图流创意为主的灵感社区，流行趋势迭代快，适合练习 UI 小稿、寻找配色和动效灵感。也常被用作寻找合作设计师的渠道。

官网网址：https://dribbble.com/

没有灵感时刷刷 Dribbble，长期下来审美会明显提升。
