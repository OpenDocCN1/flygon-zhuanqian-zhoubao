# 一、赛道盘点

### 1. 市场有多大

- 用户基数：中国第三方键盘用户约7.83亿，数据来自36氪2023年统计。
- 商业体量：动态主题与桌面萌宠类产品年销售额在3亿-5亿元区间，Statista 2022年数据。
- 增长曲线：动态主题用户付费占比每年提升约12%，萌宠类主题占全部主题下载的15%。

### 2. 为什么现在入局合适

行业进入换挡期，2025年有几个变量在发酵：

1. 技术端
- 增强现实眼镜量产：Vision Pro与华为VR Glass合计出货预期超2000万台，3D桌面宠物需求被点燃；
- 数字资产确权：平台可能接入NFT机制，桌面宠物升级为用户个人资产，催生二手流通。

2. 竞争端
- 🛰️键盘、抖音输入工具等巨头入场，萌宠形态需适配短视频弹幕互动等新场景。

3. 用户端
- 社交货币属性上升，消费者愿为独家限量萌宠支付溢价。

# 二、变现路径一：入驻官方商店，靠搜索与长尾分成

#### 上架流程

1. 递交：完成作品后发送至官方邮箱，审核周期2-5个工作日。
2. 发布：审核通过后进入主题商城，用户可下载使用。
3. 迭代：根据用户反馈持续优化，比如增加互动动作。

#### 收益测算

- 分成比例：创作者可拿到用户付费额的30%-50%，随作品热度浮动。
- 参考案例：
- 头部IP联名款：单品收入可达10万元，个人创作者难以触达；
- 普通键盘主题：下载量1万次、单价2元，创作者到手约6000-10000元。

# 2. 制作步骤

## 2.1 掌握设计规范

### 主题制作规范

- 手机端主题由候选栏、拼音区、云候选区、键盘底图、九键键盘、二十六键键盘、气泡等元素组成。功能键前景文字可自定义贴图，但中英切换、分隔符、大小写切换仅能改字体与颜色；字母键文字不支持贴图，只能调整字体与颜色。
- PC端主题主要分四种模式的输入框与状态栏。两者都支持png格式；注意标注尺寸，可小幅调整；输入框底图建议纯色或保留可拉伸区；输入框与状态栏的主形象不宜过大，以免影响打字。

# 六、优劣势总结

长处：
- 底层逻辑与红包封面、表情包类似，但竞争强度远低于二者；
