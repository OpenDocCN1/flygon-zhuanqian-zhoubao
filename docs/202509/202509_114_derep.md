# 看到同行赚钱，心里发酸怎么办？
作者：龙哥

作者：家蒙
日期：2025-09-12

最近我们这批做 B 站带货的兄弟，整体状态都不错。群里经常有人晒开单截图，有人一天几百，有人一天上千，甚至有单笔两千的案例蹦出来。还有更多更夸张的私聊截图我没法放。

一开始大家零散地赚个几块几十，情绪都很平稳。后来数字上去了，替人高兴的成分就少了，更多的是在心里嘀咕：他怎么就能挣这么多？我怎么就还在原地？说好一起吐槽没单子，你怎么偷偷跑赢了。

![](img/c78c30789b4c9b536ccae0fafc35af9a.png "None")

**01**

羡慕、嫉妒是人性，我自己也走过那段路。看过《七宗罪》，芒格也提过，七宗罪里有六个都是让自己爽的，只有嫉妒是纯纯的自找不爽。明明不舒服，还放不下，这滋味确实难受。

我早期在知乎摸索时也这样。看到别人爆了，我就急着追，怕掉队，结果赶工出来东西又烂，转化也不行，节奏全乱，钱更没影。

知乎的玩法偏长尾，一篇文章能吃几个月甚至几年流量。所以那时候的逻辑是反着来的：先慢后快，先难后易。把一篇文章打磨到能长久被检索，比乱发一百篇管用。口头禅就是：慢慢来，比快还快。别只想着去羡慕别人有鱼，不如老老实实把自己的网结好。

看到别人成绩好，安慰自己一句“那我也加把劲”，然后关掉群聊回家做自己的内容，这就是当时的 1.0 自我调节法。

现在做 B 站带货，逻辑不一样了。短视频的生命周期短，一条视频只能吃一阵子。做一条视频成本不低，想靠卷把别人超过去，卷到最后只会把自己耗死。

所以 2.0 的说法变了：别盯着目标，要建体系。

**02**

很多人一听到别人赚钱，就立刻去抄品类。自己也做同款、同品、同玩法。听起来像“跟进”，难听点就是“跟风模仿”。

大公司也常犯这毛病，听说哪个赛道火了，就空降一个部门让员工冲一下。结果绝大多数都扑了。

为什么？时机可能变了，条件可能变了，你就算复刻得一模一样，也拿不到同样的结果。更重要的是，这根本不是你自己体系里能稳健产出的东西。

东一榔头西一棒子的信息，只会打乱你建立可重复流程的节奏。

要体系，不要目标。

别人赚钱只是告诉你这个池子有水，能挣钱就行了。剩下的工作是把自己的生产机器搭起来，然后不断跑、调、优化，而不是喊一句“我也要赚一百万”。

**03**

借用一句别人的话：目标是给失败者准备的。

你定了一个“减掉十斤”的目标，在没做到之前，你每天都在失败。目标导向的人，长期活在挫败感里，容易耗尽精力甚至放弃。

系统导向的人就不一样。每次按照系统行动，都算一次成功，因为他做的是自己能掌控的事。

目标导向的人在每个节点都在和不满较劲，系统导向的人每次执行完都有掌控感。能量的走向完全不同。

减肥，减掉20斤是目标，规律饮食是体系。跑步，四小时跑完马拉松是目标，每天坚持练是体系。赚钱，赚到一百万是目标，能稳定持续产出优质 B 站视频的能力，才是体系。

说起来简单，做起来扎心。我之前看同行接广告，心里就犯膈应：这人做的一般吧，怎么又吃上回扣了。自己这边单子做不过来，事情一堆，本来就烦，再被别人刺激一下，更乱。

有单子做不过来烦，没单子看别人赚钱更烦。这就是体系没立住，被外部噪音带跑了。

后来我索性屏蔽一段时间外界信息，先把自己的事捋顺。等内功稳了，看别人成绩的态度就变了。

从“这家伙又来分蛋糕，气人”变成“做得不错，值得学习，我继续按我的节奏推进”。

闲下来就爱盯着别人，忙起来才有自己的地图。向内聚焦，外界吵闹也动不了心。方向不变，计划不变，继续执行。

稳。

**04**

说到这，体系到底是什么？

对我而言，很简单：E = 核心算法 × 重复次数²。数量本身就是质量的一部分。

具体到现在，就是每月稳定产出 10 到 20 条视频。认真做也好，凑数做也好，先把数量守住。守不住这个数，就没资格去羡慕别人。

做视频的人都知道，一条像样的视频七八天起步。一个月 20 条听起来离谱。但做开了会有规模效应，流程会简化，可以复用素材、组建团队、降低边际成本。

丰田汽车每两分钟下线一辆车，就是把造车拆成无数个两分钟能完成的环节。更快地产出足够多的、质量够用的视频，这就是体系要解决的问题。

哪怕最后一个月只发了 8 条、10 条，也已经是巨大的进步，不必过度苛责。

**05**

目标像一个远方的点，可能达得到，也可能达不到。体系是你每天都要做的事，坚持下来会让人踏实且长久地获得满足感。

有了稳健的体系，看见别人赚钱就不会心酸。你会进入一种状态：低头做事，偶尔抬头看看行情，持续稳定交付，心不乱。

等好运真的来了，你就可以淡定地说一句：

也不是多拼，就是运气好一点。
