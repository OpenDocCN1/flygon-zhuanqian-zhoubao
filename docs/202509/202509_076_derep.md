# (30 赞)youtube 纯小白，兼职 YTB,30 天初级 YPP，10 天高级 YPP 的复盘思考

0基础、纯业余，我如何用30天拿下初级YPP，又用10天冲刺高级YPP？

大家好，我是龙哥。

这次9月的【Youtube AI 视频】活动，让我这个从没碰过YouTube的纯小白，利用业余时间兼职做频道，硬是走通了从0到1的路。30天，先拿初级YPP；再10天，又拿下高级YPP。回头看，整个过程就像一次“打怪升级”。

能这么顺利，离不开一群人的帮助。特别感谢大魔王、群里的各位“大臣”，以及九月等教练，在我卡壳的时候给了很多关键指引。我平时的工作常常围绕企业规划展开，所以习惯带着商业视角去观察YouTube，也因此有了些不太一样的思考。

这篇复盘，我准备按时间顺序来写：把整个实践拆成几个阶段，针对和我一样的零基础朋友，给出每阶段可复用的方法和参考案例；等YPP目标达成后，我又对YouTube整体的商业玩法做了一个初步推演。

当然，这些想法不一定正确，理论也未必能直接指导现实操作。但我始终相信：唯有共识才是进步的阶梯。如果这篇内容能换来大家的讨论和碰撞，那就是最大的价值。
