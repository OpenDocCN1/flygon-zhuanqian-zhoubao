# (精华帖)(115 赞)两个搞钱真相，带你重启 100%执行力和源源不断心力
作者：龙哥

你有没有发现，在搞钱社群里，被问得最多的一句话往往是：“你打算赚多少？”

很多人都是这样起步的：目标立了一回又一回，计划表写得滴水不漏，可真到动手那一刻，就好像被什么东西卡住了。不是你不够拼，也不是你管不住自己，而是有两层最底层的逻辑，你一直没看透。

**第一层：你从来都不缺行动力。**

每个人的身上都藏着100%的执行力，只是被潜意识底层的一些预设悄悄“锁”住了。你以为是自己懒，其实是你内在的假设在作祟。

**第二层：真正驱动你的，从来不是那个数字。**

如果你的目标没有绑定到一种具体的生活画面里，哪怕数字定得再高，也扛不住时间对你的消耗。

这篇文章，我会结合我自己和上百位圈友的真实经历，陪你把这两层逻辑彻底拆开。当你看清了它们，行动力会自然回满，心里的那股劲儿，也会源源不断地涌出来。
