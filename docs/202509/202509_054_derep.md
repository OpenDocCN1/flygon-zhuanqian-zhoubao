# 按摩师学英语、马东发私信：所谓成功学，不过是把小事做透
作者：龙哥

前两天在合肥和南京之间跑动，去做按摩，正拿着多邻国打卡，技师来一句：“这软件我也在用。”我好奇她学英语的原因，她说店里常有海外客人，想能沟通几句。我问她：“那你应该是店里收入不错的那位吧？”她笑着承认。

这让我想到很多事。有些人的成功，听着很玄，其实朴素得很——就是愿意学、愿意做、愿意在细节上较真。

就像马东老师。这几天我收到他的私信，一看就知道米未又有新节目了，这次是《喜人奇妙夜》第二季。多年前他找我聊过营销，加了🛰️，之后再没怎么聊过天，但每年他都会发一两回这种群发消息。多大的咖、多高的品牌势能，还是在一条一条私信地拉观众。哪有一夜爆红，都是这样笨拙地争取来的。

又想起古茗的一位高层，我问过他怎么让加盟商都听总部的。他回答得很实在：“没什么办法。思想不统一，就一次次劝，一次不行两次，两次不行三次，总能劝通。”听起来像废话，却是真功夫。

爱玛那边也是。市场团队一个城市接一个城市跑，帮经销商开抖音、教他们拍视频，几万经销商一周就能发出三万条短视频。CMO莫总跟我说，全是体力活。但去年爱玛利润拿了行业第一，靠的就是这些“体力活”。

我自己维护两百多个读书群，也常被问到方法。说穿了很简单：每天写一段几百字的思考发群里，让愿意留下的人觉得这地方还有点价值。不追求活跃，持续给一点东西就好。

有句话说得好，如果有人比你做得好一点，99%不是藏着什么秘诀，而是他把小事实实在在做透了。我常提起的上海那家SPA店也一样，一次性内裤让人想带走几条出差穿，按摩服让人想买回家，连待客的饼干都被夸。这背后没有什么宏大设计，只是每件小事都多用了点心。

不少朋友也补充了例子，比如小米手机有个隐藏小功能：拨号时对方接听，手机就会轻震一下。这个细节连很多用户都没留意，但厂商做了，体验一下子就上来了。

日本扫除道创始人健山秀三郎写过一本书，叫《凡事彻底》——把平凡的事做到彻底。所谓朴素的成功学，说到底就是这个道理。
