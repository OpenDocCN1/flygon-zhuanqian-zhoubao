# 从裸辞到跑通小红书电商闭环：两个月做到11.9万GMV，净利润4.5万+的复盘

Hello，我是CC。

加入赚钱之前，我的履历挺跳脱的：做过婚礼顾问、公关广告策划、电商直播带货，还当过主持人、旅游博主，模特也做过一阵子。今年6月我选择裸辞加入赚钱，到现在正好3个月。

7月8日开始正式上手小红书电商，折腾了两个多月，现在的数据是GMV破11.9万，整体利润率稳定在40%左右，纯利润4.5万+。这是我第一次参加航海，也算带着一个结果上岸了。

回头看，其实我也经历过很长一段迷茫和焦虑期。最焦虑的时候，我就会去翻那些已经跑出成绩的同学们的复盘，看他们怎么从0到1的。正是这些分享给了我继续试下去的底气。

真正让项目拐弯的，是我把客服这块彻底外包出去了。把最耗精力的琐事腾出来后，我才有精力去做打法上的思考。之后正好赶上天时地利人和的窗口期，0到1的完整闭环就跑通了。

这次航海中，晴子教练给的点评建议对我帮助很大，顺便说一句，她们的服务确实很靠谱，后续有客服外包需求的同学可以找她聊聊。

下一步我打算做矩阵化运营，也在物色兼职来分担一些执行工作。把这次的经验整理出来，就是想给还在起步阶段、拿不到结果、心里打鼓的伙伴们一些参考。路是自己走出来的，但好在我们可以少走弯路。
