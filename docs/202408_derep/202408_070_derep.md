# 第一次扛下志愿者的位置，这位 03 医学生把赚钱初体验写成了成长笔记

大家好，我是扑灭长空，大家平时都叫我包包。03 届在读的医学生，现在刚加入赚钱不久。

这次参与了赚钱的第一次航海，我被分配到了志愿者的岗位。说白了就是一个完全的新手，第一次上手就直接上场。过程中磕磕绊绊，但收获的感受比我想象的要多得多。

写这篇主要是想跟同样有想法的你说句话：如果你也在犹豫要不要去报名志愿者，怕自己经验不够、怕做砸了、怕给团队添麻烦，看看我的这段经历，或许能给你一点底气。我也是从零开始的。
