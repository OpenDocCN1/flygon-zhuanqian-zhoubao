# 从零到到手170万+：一个普通人如何靠流量切入医疗维权赛道，完成从0到闭环的变现



## 1年做到到手纯利170万+，普通人从流量端起步做医疗维权是怎么做到的

作者：洋先生

日期：2024-08-16

赚钱老朋友大家好，我是洋先生。算下来我在赚钱圈子里待了四年了。19岁时第一次了解到赚钱，2020年正式加入，2021年中间断了一年，2022年又回来，期间基本都是潜水学习，只偶尔发点风向标，输出很少。

过去这一年我一直在深耕维权类项目，并且已经把前端到后端跑通成了完整闭环，到现在口袋里的净利已经超过170万，而且项目目前仍在稳定地产生现金流。趁着手热，我想把这套从流量端切入的思路梳理出来，给想入局的朋友提供一条可复制的路径。下面这张是我截到8月14日的收益明细，上一年4个月的流水也有上百单就不一一列了，另外一张是给流量合作方结算的部分记录，整体结算出去的成本累计已超100万。

搞好流量端本身就能吃到很可观的利润，更何况任何生意先解决来客问题都是根基。所以对于新领域，先从流量做起是最稳妥的打法。若什么都不懂就去盲目买课，很容易变成别人盘子里的韭菜。

接下来我会从项目逻辑、流量获取、中端转化、后端服务四个层面展开拆解，整篇将近8500字，我是断断续续写了好几周，预计阅读时长约15分钟。
