# ('王阳明教会我，如何提高 10 倍赚钱效率？', (2, 23))

王阳明的一句话，让我赚钱效率直线上升

你有没有过这样的状态：很想通过每天多读几页书、多写几段文字、多做一点副业，让自己赚钱的本事再上一个台阶，但工作已经把精力消耗光了，根本找不到整块时间。于是越努力越焦虑，越焦虑越觉得自己在退步。

我过去也陷在这个循环里，直到真正理解王阳明的“事上练”，才意识到这里藏着一个认知盲区：我们习惯把学习和工作分成两件事，觉得赚钱能力一定要靠额外抽时间来“喂养”。但王阳明提醒我们，日常的工作和生活，本身就是最好的修炼道场。

从那以后，我不再纠结“今天有没有时间学习”，而是把眼前遇到的每件事都当作练功场。工作中卡住的问题、客户抛来的难题、那些让我头疼的琐碎事务，统统不是“耽误学习的障碍”，而是“我缺哪块能力”的信号。缺哪块就补哪块，学完立刻回到真实场景里使用。这种带着明确缺口去学的方式，比漫无目的的囤课和刷书高效得多。

想要知道自己到底缺什么，最简单也最扎实的办法，就是坚持复盘。日复盘、周复盘、月复盘、年复盘，每次停下来问问自己：哪些问题反复出现？哪类事情总分心走神？哪些技能一到关键时刻就用不出来？这些问题指出的地方，就是你最该练的基本功。

不要等暴风雨停了再出发，高手从来都是在风雨中起舞。赚钱效率翻十倍，不是靠把时间表塞得更满，而是靠把每一件正在发生的事，都变成提升自己的机会。想明白这一点，可能比多学一百个小时更管用。
