# ('闲鱼虚拟店铺单日利润 200+，自动发货实现睡后收入', (2, 28))

最近看到一个很让人心动的副业案例：在闲鱼上卖虚拟商品，一天赚到200多块，而且整个过程不需要人工发货，系统自动完成交付，妥妥的被动收入。

玩法并不复杂，核心是上架虚拟类商品。买家下单后，后台会自动发送对应的下载链接或卡密，不需要人工盯电脑，更不需要打包发快递。有同行分享过，自己也在做这个项目，虽然收益不及这位作者，但胜在轻松，最近几乎没怎么专门去打理。

很多人关心：新号能不能跳过养号环节，直接发布商品？有实测经验的人说，稳妥起见，先让账号活跃一两天再上架。但神奇的是，也有人中午注册完、下午就发布商品，当天就来了订单。可见这件事的试错成本很低，不像想象中那么复杂。

虚拟商品最大的魅力在于，一份内容可以被无限次售卖，边际成本几乎为零。只要选品方向对，访客和成交慢慢滚起来，一天200多并不是遥不可及的目标。等自动化的交易链路完全跑通，你几乎可以把精力抽身出来，躺着也有收益进账。

如果你也在寻找低成本、轻操作、可持续的副业方向，不妨在闲鱼上仔细研究一下虚拟产品这门生意。很多细节弄明白了，你会发现每天多赚200块，也许只是个开始。
