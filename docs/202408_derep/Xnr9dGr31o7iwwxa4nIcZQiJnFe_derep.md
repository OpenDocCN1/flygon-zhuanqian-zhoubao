# 赚钱这件事，从终点往起点倒着规划

我是明白。今天想聊一个关于赚钱的重要思路。

后台经常收到类似的提问：我已经三十好几，这些年一直按部就班上班，从没刻意培养过什么能力，手上也没有一技之长。现在突然想多赚点钱，却完全不知道该往哪使劲，能给我点建议吗？

这种处境我特别能共情。我当年从程序员圈子里跳出来，想在互联网上找点机会。2017年加入赚钱有术，看到的每个项目都让人心动。可整整折腾了一年，换了一堆赛道，没有一个做出名堂。后来我才彻底想通：问题从来不在项目，而在我的基本盘太弱。

不会学、不会想，写作、交流、成交这些基本功统统拿不出手，产品和市场更是没概念。偏偏那时候还天真地幻想：有没有一种生意，不需要学、不需要练、不需要投入时间，就能哗哗来钱？如今回头看，真是荒唐。

那后来我是怎么调整的？

# 01 从《大江大河》看到的决策智慧

先讲一个最近重温《大江大河》时被击中的情节。

剧里有个村子，穷得叮当响，一群三十多岁的光棍娶不上媳妇，姑娘们都不愿往那儿嫁。后来来了一位退伍军人出身的支书，脑子活，也敢干，带着村民找出路。他们前前后后折腾了三件事：

- 开砖瓦厂，烧砖赚钱；
- 拉一支工程队，帮人盖房；
- 办起预制件生意，专门生产屋顶常用的大梁板。

因为是全县第一家，抢先占了红利，很快攒下一笔家底，县里也把他们当典型，给政策、给贷款。

可后来他们和县里的关系闹僵了，支持全都没了。之前帮县电缆厂盖房子，对方欠了六十多万工程款，偏偏厂子效益不行，根本还不上。村里的资金一下子断掉，处境变得非常危险。

更要命的是，周边村子看他们赚了钱，也开始学着做砖瓦、搞施工、上预制件。这几样活儿几乎没什么门槛，只要有土、有水泥、有钢筋就能开张。如果拿不出新东西，他们好不容易攒下的那点优势，随时会被抹平。

县里这时候提出一个方案：用一套生产电缆的设备来抵债。村民全都摇头——要一堆不会用的铁疙瘩干什么？但支书坚持先把专家请来验机，确认设备完好、能正常运转之后，他才点头。

设备运回村，他当众宣布：咱村要办电缆厂。话音一落，全村炸锅。

没技术、没工人、没原料、没资质，这厂拿什么开？所有人都觉得他疯了。

支书开会解释：县里如今不帮我们了，周边村子都在复刻砖瓦那套，等他们站起来，我们那点优势就归零。电缆这条路不一样，全县只有我们手里有这套设备，只要转起来，产出就是独家，别人想跟都跟不进来。中途一定有无数难题，但遇一关闯一关。这件事确实难，不是一般的难，可一旦做成，回报可能超过现在所有营生加在一起。更何况，现在早不是要不要做的问题，而是不做，村子就只能退回从前的穷日子。

他顶着压力四处奔走，花高价请来懂行的师傅，满世界找原料，还和外地厂子谈联营合作，硬是把这个厂从纸面变成现实。头一批电缆刚下线就被抢购一空，他扛回一麻袋现金，全村人都竖起大拇指，说还是支书看得远。

我佩服他的地方在于：他做这个决定，从来没有盯着眼前的得失，而是站在未来往回看——现在该做什么，才能让未来变成想要的样子。

# 02 世界那么大，先把自己这块拼图补齐

回到开头的困惑。如果过去没有积累、能力又一般，该怎么办？答案只有一个：从今天开始补。欠下的功课总要还，越早还，人生越早进入顺风局。迟迟不还，就只能一直困在“试项目、追红利、天天焦虑迷茫”的循环里出不来。

我当初想通这件事后，第一件事就是给自己列能力清单：

- 学习力、思考力；
- 写作、表达、共情；
- 产品感、营销感；
- 商业认知、沟通、成交。

每个方向，我都老老实实把“了解—学习—练习—实战—固化”走完一轮。这个过程特别慢，也特别磨人。但当我真正把这套流程跑通之后，再看以前觉得高不可攀的项目，突然变得轻盈起来。那一刻我才真正接受那句话：项目本身都能赚钱，关键看站在项目后面的人是谁。

因为赚钱是结果，是你把一件事做成之后自然拿到的回报。把事做成，靠的是知识和能力。

知识和能力都在，事情大概率能成，钱自然跟着来；知识和能力缺位，事情大概率要坏，钱自然躲着你走。

所以正确的姿势是：看到一个赚钱的路子，先别急着扑上去，而是拆一拆它背后到底需要哪些能力。然后从今天开始，把时间、精力、脑力持续投进去，把它真正学会、练熟。光是“让自己变强”这件事本身，就已经是在赚钱——只不过这笔钱会延迟到账，在未来某个时刻一次性兑现。

这条路当然难。但就像那位支书建电缆厂一样，现在吃下的苦，都是给未来铺的路。你现在学到的每一个本事，争取到的每一次突破，都是在重新设计接下来的人生，让未来的画面一点一点朝你设定的方向显影。

# 03 想在赚钱这件事上“毕业”，先找对你的学分清单

如果把赚钱比作读大学，那么真正赚到钱，就等于拿到了毕业证。

上学怎么毕业？很简单——翻开学校发的培养方案，看看要修满哪些课、攒够多少学分、拿下哪些证书，照着执行就好。

赚钱和念大学唯一不同，是没有谁会递给你一本标准答案手册，告诉你“学会这几样，就保证你赚到钱”。你只能自己去研究：那些真正赚到钱的玩家，身上有哪些共通的能力与特质。这些共性，就是你的学分和证书，是你未来“毕业”的硬通货。

然后，拿出学生时代那股踏实劲儿：听课、练习、刷题、整理错题、定期复盘。重复的次数足够多，给自己足够的时间沉淀，拿到好成绩就是大概率事件。

愿我们都能从今天开始，主动设计接下来的人生，而不是把未来交给运气去随机播放。
