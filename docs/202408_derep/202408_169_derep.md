# 流量在手，欲望上头

最近的网络，骂声和论战此起彼伏，看上去格外热闹。

在这个时代，流量就等于钞票，流量就等于话语权。能拒绝诱惑的人，我也见过几个，但绝对是少数。

没有流量的人，一旦靠一句挑衅、一次对骂突然爆了，他会尝到一种前所未有的亢奋。那种瞬间被追捧的刺激感，很容易让人上瘾。一旦尝到流量暴涨的甜头，就很容易放飞自我往偏门上走。当然，也有保持清醒继续走正路的，不过并不多见。

已经有流量的人，玩的是另一种感觉。他可以轻易给别人盖棺定论，一句话就能让一群人跟风围攻。那种一呼百应的支配感，像极了旧时皇帝批阅奏章，予人生路还是定人死罪，全凭心情。

流量终究是双刃剑。它能带来收益，也能改变人。

当一个人流量到手后，常常会做出过去想都不敢想的事。古人有句话叫身怀利器，杀心自起，慎而重之。大致就是你手里握了把枪，难免会变得骄纵跋扈，总想拿枪口对着别人。它固然能保护你，但也极易扭曲你的心性。

我们看着台上那些人贪婪张扬、盛气凌人时，总会觉得不可思议。真要是换成我们坐到那个位置，大概率也一样会得意忘形、竭泽而渔。说到底这是人性本能，只有意志足够坚硬的人，才能扛住这种诱惑。

绝大多数人，都躲不过这场权力的诱惑游戏。

明白了这一点，网上那些匪夷所思的现象就好解释了。

手握流量的群体，内部还分派系。网络混战时，最常见的就是帮亲不帮理。于是战局愈演愈烈，一旦闹大，甚至会殃及池鱼，全军覆没。

所以还是要收着点。

君子爱财，取之有道。手握利器，更需谨慎。
