# 98 年小伙裸辞创业，参加视频号带货航海，2 个月累积变现 6W+

### 98年小伙裸辞闯视频号，两个月变现6万+，涨粉10万，他是怎么做到的？

一个1998年出生的小伙子，在很多人还在为“要不要裸辞”纠结时，已经跳进了视频号带货的战场。他叫耿一凡。今年六月，他报名参加了视频号带货航海活动，一个人管着6个账号，先后发了200多条作品。两个月下来，总成交额跑到了6万多，账号粉丝更是涨了整整10万。

成绩背后，是实打实的方法。耿一凡说，这次分享他不打算讲虚的，只讲两件事：第一，这个项目的完整操作流程和落地细节；第二，他自己在这个过程中的真实经历和踩坑感悟。完整的图文笔记他已经整理好放在飞书里，链接放在下面，想拿的可以直接带走。

意外的是，他的分享发出后，评论区成了“加油站”。有人说自己正卡在视频号瓶颈期，看完这篇文章又续了口气；还有人直接晒出战绩：只用了3个日夜，佣金直接干到4.6万。一群素不相识的人，因为同一个项目聚在一起，互相给劲，这正是航海最迷人的地方。

如果你也好奇视频号带货到底怎么做，或者正站在创业的十字路口，不妨点开这份飞书文档。里面不只是方法，还有一个人裸辞后杀出重围的真实轨迹。
