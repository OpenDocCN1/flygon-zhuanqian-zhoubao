# ('一篇风向标和精华帖，如何让 30+位圈友抓住青年夜校风口，从 0-1 累计变现超 500W', (2, 47))

一篇风向标加精华帖，怎么就带火了青年夜校？30多位圈友靠它从0到1变现超500万！

大家好，我是谢不言，99年出生的连续创业者。去年年底正式启动青年夜校项目，一路走来，我亲自带动的、加上间接影响的圈友一共有30多位，大家从零起步，累计赚到的钱已经超过了500万。

回头看，这个项目的起点就是赚钱的一篇风向标，真正爆发则靠那篇精华帖。可以这么说：没有龙哥盟这个平台，青年夜校不可能在全国各地开枝散叶，不少人也很难赚到自己的第一桶金。我自己同样收获巨大。如今半年多过去，也该向圈友们交一份作业了。

1、青年夜校这门生意，钱到底是怎么赚的？
2、短短半年，圈友们凭什么就能拿下500W？
3、除了物质回报，这个过程还带来了哪些额外价值？
4、复盘自己：当机会摆在面前，我做对了哪几步？
5、送给正在观望和已经入局的圈友——10条关于夜校的深度思考。
