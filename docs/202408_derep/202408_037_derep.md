# 花一分钱，正版新书包邮到家？这个操作绝了！

最近挖到一个神仙bug：只需0.01元，就能把正版纸质书买回家，还免运费。乍一听像天方夜谭，但真有人靠这招连撸了半个多月。

事情是这样的，有位叫少波的圈友，四月加入生财有术。他原本做实体生意，性格特别谨慎，生怕投资踩坑。后来看到闲鱼二手书项目，觉得有门槛的事才更值得做。可一打听，卖书得办出版物许可证、还要出版社授权，怕违规就放弃了。接着他在社群里搜“书籍”“出版物许可证”这些关键词，经内蒙古的@乔久伴引路，才摸到了这个薅羊毛的门道。

具体玩法其实不复杂：每天用一个账号，就能以0.01元的价格下单正版图书，而且包邮。但有几点得留个心眼：

第一，每个账号每天只能薅一本；
第二，极少数店铺会收运费，这种情况直接换一家店下单同一本书，运费就没了；
第三，同一个账号天天用也没问题，作者亲测连续操作十几天仍有效，活动何时截止目前还没准信儿。

作者也提到，这套玩法确实有门槛，但正因为有门槛，才不容易被玩坏。详细的实操地图和避坑指南，他整理在了飞书文档里，想上车的朋友可以直接点开看：[飞书链接](https://va802z4imkx.feishu.cn/wiki/Ct1jwIZCWii6ohkAgchcgJItnSd?from=from_copylink)

总之，这种羊毛最适合爱读书的人，每天一分钱，慢慢攒一座小书架不香吗？不过好事能持续多久谁也说不准，趁现在还能薅，赶紧动手多囤几本正版书才是正经事。
