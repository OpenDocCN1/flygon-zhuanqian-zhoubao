# 一、笔记该怎么呈现

定位已经定在“自媒体”后，最关键的是选对呈现形式。我把这套摸索总结成三步：先收集、再归类、后判断。

## 🔴收集

起步先拿3-5天，把同行笔记通吃一遍。乔布斯说创新是旧元素的重组，脑子里没素材就组合不了。

常用四种做法

#### 关键词搜

关键词是入口。搜到别人内容，也方便别人搜到你。

自媒体相关词：自媒体运营、小红书运营、发帖时间、Vlog选题、脚本、新人博主、人设、赛道、账号搭建、拍摄技巧、剪辑工具、定位、爆款标题、爆款关键词、怎么做内容、下班后做自媒体、自媒体人常用网站、黄金发布时间……

起初抓5-6个核心词就够了，靠小红书的下拉推荐和笔记标题里继续挖词，滚雪球一样越挖越多，像玩密室逃脱。

![](img/5305e35632cc1735c953677b06e3236e.png)

![](img/6e45b38470eb1963c5d4899e25175092.png)

#### 话题蹲

看同行笔记下挂了哪些话题，把相关标签一并收藏。像仓鼠囤粮一样攒着，每天刷一刷。

建议先把关键词和首页法跑通再用话题法，不然推荐会跑偏。

![](img/72ce809304acea3bb569ebe19f8f2472.png)

#### 首页刷

大数据比你更懂你。看完相关笔记后回到首页，出现的推荐号就是新线索。

刷的时候要明确：点图文不点视频、点自媒体不点娱乐、点想学的别点想看的。杨幂比基尼、蔡徐坤王俊凯、辣火锅、婆婆语录、单位八卦、线性代数、八段锦、凡人修仙传……这些能忍就别点。

运气也很重要。首页恰好推给你一个低粉高赞的对标号，等于平台在给你投赞成票。为此我常换三个手机同时刷，声源多方向来，更清晰。

![](img/10cec823586b23ed688e41bcfc1ee3b9.png)

#### 工具查

想快就用蝉妈妈、新红的“低粉高赞”功能，按赛道或关键词筛，数据还能导出。短期会员去闲鱼拼夕夕找优惠。

手动刷能练网感，工具党效率高，各凭喜好。

刷完一轮，你对爆款选题和呈现风格会形成直观画面。下一步是把画面量化。

## 🔴判断

选形式起号看两点：A.这个形式长期有流量；B.最近流量在涨。

平台会推内容，推了才有量。

我的观察：

1. 备忘录在自媒体领域一直稳定吃香，两三年都有长尾号，这条适合打持久战。
2. 3月“开局一张图”火爆，5-6月又转回图文为主。
![](img/07a45f099f579a422228ed4a9412d212.png)

![](img/af007e877a0609e2b5150034ad4e13ec.png)

3. 平台推法会变，起号前必须观察。
4. 流量会衰减，风格要跟。看似选题不变，实则形式要换，四个字：跟随潮流！

先整理出10种可做的笔记形式，再筛出当前平台在力推的2-3种，用几个号同时赛马。数据好的形式再集中投放。调研完才是开始，选对了形式，后续选题自然顺水推舟。

直觉是可以练出来的，刚开始靠理性分析，后面会变成网感，像考驾照一样练出来。

# 二、爆款选题怎么找

形式定了，就找选题。说个现象：自媒体圈都在聊“香积寺之战”，发这个基本有量。唐朝两军互砍，盛唐拐点，情绪上意难平。像张小凡碧瑶的爱情也一样，情绪点被戳中就传播。

核心是找到你领域里的30个“香积寺之战”。

找法：确定形式后账号推荐已经刷熟练了，用首页、关键词、话题法把同行数据抓出来分析。

把过程游戏化比较好，受反馈不确定，游戏化能降低焦虑。投入越多越想回报，当成游戏反而更轻松。

## 常见爆款类型

#### 问题类
技能类永恒的话题：怎么做、怎样做。自媒体怎么定位、怎么找对标、怎么变现；做饭怎么买菜怎么切菜。关键词“如何”“怎样”就是选题矿。

#### 工具类
人对工具有迷信。自媒体文案排版工具、做图工具、剪辑工具，搜一搜流量巨大。

#### 书单类
互联网之前，解决问题靠看书和问人。亲子育儿书单、女性成长书单、创业书单，在小红书一直有量。

#### 娱乐类
减肥账号用“秦昊减肥法”出圈；过年期间“热辣滚烫”把减肥和贾玲绑定；杨幂同款、王一博同款DUNK……情绪和热梗永远有用。

起号前几篇一定要放王炸。选题也带周期感。去年春节前发《2024上半年自媒体风口》，大爆却没持续跟进，白白错过。

私域账号也在商家节日节点冲：五一发的5.1活动笔记爆了，春节也一样。顺风时出海省力很多。

# 三、内容怎么讲

“七分选题三分内容”没错，但我曾以为内容不重要，错了。选题解决能不能被看见，内容解决看完后会不会加你。心脏和大脑重要，不代表手脚胃脾不重要。

内容类型举例：涨粉型、引导型、干货型、互动型……

#### 涨粉型内容
粉丝=权威光环。互联网嘴替就是一种：用电影《年会不能停》讲打工人的无奈，对宝妈说鸡汤，站在用户角度共情。

关键两点：关爱+重视。大部分人幼年缺失这两种情绪，博主如果能给到，用户会本能靠近。

还有故事连载型、挑战100天xxx、娱乐八卦型，都是天性喜欢的甜食。

#### 引导性内容
有目的的行动指令：引流、下单。像讲武侠故事：我有一招过目不忘法，能打败考研怪兽，成为武林高手，从此升职加薪。你就会喊着求求求，然后来个“V我50”式引导。

#### 干货型内容
表面简单，实则难。分享要真有用，就得持续学习实践。嫌累也可以搬运，小白阶段分辨不出真假，公域引流对0-1人群足够用。

选题和内容一起构成心智占领，缺一不可。

现在玩小红书，本质上就两条路可选：一是做搬运，二是做沉淀式输出。要是你的目标纯粹是接单变现或者带货，我个人觉得搬运这一条路完全够用，甚至更省事。

搬运的底层逻辑是信息差。内容的源头非常多，抖音、快手、B站、老红书、纸质书、海外平台等等，都可以当原料库。只要你能把别人的东西换个说法、换个场景搬进来，就是价值。

走个人IP的路子则不一样，随着你在某个垂直方向持续学习、持续实操，你脑子里自然会积累出自己的方法论、操作技巧和踩坑心得，这些才是能长期沉淀的东西。

#### 互动型内容

我觉得能把互动做起来，基本上就抓住了账号能否起来的核心因子之一。

互动内容是什么？小红书的用户结构偏女性化，而且女性每天的语言输出量远高于男性。更关键的是，无论男女，大家都有很强的表达和倾诉欲。所以把小红书当成一个情绪树洞去做，是很顺势的打法。

当你能在自己擅长的领域里，扒出几个容易引发争议、容易让人上头讨论的话题，账号的活跃度很容易就起来了。你发一条笔记出去，下面几千条评论在吵架、互怼、互补，等于你开了一个线上房间，大家都在房间里围着你的主题聊开了。当然，热度只是第一步，要把热度转化成涨粉、成交、引流，最后还是得靠文案和评论区的引导来收口。

内容的形式非常多，市面上常见的就有好几十种，这里就不一一铺开了。做账号不需要把所有形态都吃透，能精通一种就吃饱饭了，但绝对不能只做一种。

# 四、引流

引流环节里最常用的就是评论区操盘，主要分两条：群聊引流和私信引流。

群聊最大的优势是被动。设置好之后它自己工作，你睡觉也能收人。私信则更即时，导流效率更高。

评论区置顶有两种操作思路：

A.主号自家评论置顶，B.小号评论置顶

主号置顶的话，千万别自己瞎编。直接去同行笔记里找高赞评论，复制粘贴过来用。最好整理一波存在讯飞输入法的常用语里。我之前自己写评论老是被吞，几次之后就老实了，直接抄作业。

![](img/3abe1d7d472e03c104d257dea4dbd757.png)

![](img/4c58d6800e41d97e2f0633c7bad6ca10.png)

小号的操作就更稳一点。用小号在自己的笔记下面评论“666”“求分享”“求带我”，把这条评论置顶，然后再用主号在它下面回复，引导用户私信或者进群。也可以直接在小号评论里留下群链接。这样流程虽然多一步，但合规安全很多。

![](img/f95b3bf0d2c091253e60b550d1c523aa.png)

其他的细节要命：

1.用户评论要及时回。后面的人刷到，感受到有人在实时互动，才会有参与感和可得性。

![](img/5b57dc35c139d7b5aff931113d16af03.png)

2.很多人不公开评论，私聊会直接发到后台的陌生人信息里，这部分经常被忽略，一定别漏了。

![](img/962fd9db2530a35ab3d94a50f5a2ff47.png)

3.回复越快，加微信的比例越高，我这边的转化能到一半以上。

4.私信我现在基本是直球营销，不再装了，直接摊牌。

5.私信的时候先点开对方主页看一下笔记和历史发言，明显是来捣乱的就直接放过。

目前我走的就是废号流心态。反正起号内容都熟了，号用一段时间就注销换新，很多时候新号比旧号还滑。说实话到现在还没遇到过举报限流，很失望，之前小心翼翼的时候反而三天两头出事。反动派都是纸老虎，你强它就弱，干就完了。
