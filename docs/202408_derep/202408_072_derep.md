# 从键盘到街头：我用三周时间，把“社恐码农”变成了能开单的自由人



## 同城实体发售实战笔记：敢开口、肯行动，结果自然来

作者：生命终究难舍蓝蓝的白*
日期：2024-08-12

大家好，我是李冬朋。过去的我只是个写代码的普通程序员，如今已转型做自由职业。加入【同城实体发售】的这趟航行，我只用了三个星期，就实现了 8000 元以上的现金流。

**我卡在哪儿**

辞职后我一直在寻找两件事：一是可以持续做下去的赛道，二是可以真正锤炼口才和人际交往能力的方向。坦白说，因为长期写代码的习惯，我的表达和沟通始终是软肋，这也是我最想突破的点。

**转机出现了**

就在我犹豫的时候，航海计划官宣了。最吸引我的是它不只在线上，还有线下实战。我点开同城实体发售航海的宣传海报，上面写着要主动找商家、要上门陌生拜访。光是想想那种画面就让我心跳加速，又紧张又兴奋。没多想就报了名。
