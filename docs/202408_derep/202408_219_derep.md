# ('如何花小钱，办大事？', (2, 12))

你有没有发现，真正会做品牌的人，从来不用砸钱？

他们更擅长用“小成本”撬动“大曝光”。思路其实很简单：凡是能被大众看见的东西，不管多小，都可以成为品牌传播的触点。一件T恤、一个手提袋、一张贴纸、甚至是一句印在包装上的俏皮话——只要你敢想，它们就能替你说话，把品牌带进更多人的视线。

低成本传播的底层逻辑，就是带着想象力，去“占领”那些日常可见的载体。别总盯着昂贵的广告位，路边、桌上、人们的身上，到处都是免费的展示面。你唯一要做的，就是让品牌以一种有趣、有记忆点的方式，自然融入其中。

举个例子，假如你有个社群，与其花大价钱投广告，不如给每位成员送一件印着slogan的定制T恤。当大家穿着它出门、拍照、聚会时，品牌就跟着他们流动起来了，而且这种传播是真实、有温度的。

所以，别再说预算不够。只要肯动脑，花小钱，真能办成大事。
