# ('单人月营收 10w+，在线上流量如此卷的今天，同城实体发售会成为新的机会吗', (2, 39))

#航海好事#

线上流量越来越贵，越来越卷，这几乎是所有做增长的人的共同感受。但总有人能在“卷”中找到另一条路。最近，一位赚钱有术的老圈友晒出了一份成绩单：跟着团队做同城实体发售，一个人单月做到10w+营收。

这位圈友是大林，赚钱有术5期老圈友，以前经常在赚钱航海当志愿者，最近低调了不少——其实是跟着孙策老板去做同城实体发售业务了。他把这段经历写成了总结，用四个问题讲得很清楚：第一，月营收10w+真实吗？第二，商务怎么谈单成交？第三，怎么选择和评估团队？第四，这个业务还能做多久？

他给出的核心信息是这样的：

- 成绩真实，是跑出来的，不是PPT画出来的。
- 谈单讲究“陌拜”功夫，一天拜访30多个客户，很锻炼人。
- 但光靠跑量远远不够，更重要的是把活动做好，用成功案例去撬动高质量客户。
- 选团队要看团队素质，这决定你是“打命中率”还是“打概率”。
- 业务可持续性方面，深耕一个城市复利很强，但他建议周边2-4个城市一起做。

完整分析他放在了飞书文档，想深入了解的可以去读：https://s62r7yipm9.feishu.cn/docx/FM7XdNnd0owif3xpUlBcPJC6nQo

文章发布后，圈友评论区也挺热闹：

有人感叹一天陌拜30+客户是真的锻炼人；也有圈友认为，关键是要想清楚自己究竟更适合思考打命中率，还是多跑动打概率，这跟团队素质有关。作者回应说，多跑只是基础，把活动做出效果、用案例撬动更多高质量客户才是核心。还有人问“坚守一个城市是不是复利很强”，他答：是的，而且建议周边城市一起布局，2-4个城市同时做。更有人开玩笑说，这份总结比昨天直播间的分享更清楚，看得出做这件事的人是个实在人。
