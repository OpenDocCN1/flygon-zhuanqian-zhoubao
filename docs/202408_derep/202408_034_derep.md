# 从关掉七家店到年入千万，他靠卖二手手机做到了别人做不到的增长



大家好，我是凡灵逸尘，郑州的赚钱圈友。今天要聊的这位朋友，和我认识很多年了，算得上是老熟人。

上一次我写他，是两年多前的事。那时一篇随笔给他带来了几十万的订单，后来我一直拖着没写新的内容。这次之所以补上，主要是因为太忙拖欠太久，觉得实在说不过去。更重要的是，2024 年这个节点上，他所在的公司在我接触的所有创业者里，几乎是唯一一家还在持续放量且保持高速增长的。

这种反常的增长轨迹，让我很好奇。于是选了个郑州下大雨的晚上，硬是约了他聊了整整三小时，从大学时期到现在的关键转折点全部复盘了一遍。

他做的行业是二手手机及工作机供应，听起来门槛不高，但这两年行业整体都不好走。他自己也经历过最艰难的时期，曾连续关掉七家线下门店。熬过来之后，现在公司年营收已经做到千万级别。

为什么能逆势起来？核心就一个字：懂人。

周围做互联网创业的朋友，最怕的不是设备贵，而是时间被耽误。机器坏了、配置不对、发货慢，这些隐性成本比价格贵一千块更致命。他恰好抓住了这个痛点。

我和身边朋友会反复给他介绍客户，原因很简单：我们两家公司的设备都是他供的，出了问题他都会第一时间解决。口碑转介绍不是靠吹出来的，是靠一次次解决问题的靠谱堆出来的。产品不行，关系再好大家也不敢介绍。

这次交流我收获很大。即便见过不少做得大的老板，能在当下环境下依然保持多倍增长的并不多。他做对的一个关键选择，正是把 “创业者需要稳定可靠的工作机” 这件事做到了极致。
