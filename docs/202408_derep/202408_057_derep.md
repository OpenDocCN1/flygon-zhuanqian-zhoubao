# 当商业思维撞上艺术思维，为什么总会鸡同鸭讲

商业和艺术，看起来都是在做事，其实底层在运行的两套操作系统。

做商业的人，先把规则说清楚、把边界划明白，然后才开始谈怎么把交易跑得更快、更稳。整个逻辑是效率优先，但也要兼顾体验，终点是让参与者在可预期的框架里获得满足感——效率与幸福感的平衡。

做艺术的人，顺序是反过来的。第一步不是定规矩，而是先给表达以尊重，给创作者一个被听见的空间。随后才是用真诚的回应去对话。衡量标准也不同，不是看有多高效，而是看作品能否承载一个人内心的投射，触发共鸣与感受。

一套模型是先共识后提效，一套模型是先尊重后反馈。两者出发点、评价体系、交流方式完全不在一个频道上。

所以你会发现，习惯了商业打法的人和习惯了艺术表达的人坐在一起聊天，往往话说得很多，却感觉隔着一座山、一片海，始终对不上。
