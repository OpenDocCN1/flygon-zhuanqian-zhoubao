# 高瓴向前，红杉向后

在中国创投圈，高瓴与红杉是两座绕不开的高峰。同样身处国内股权投资的第一梯队，它们既有相似的底色，又走出了迥异的路径。有人说，这就像同一颗种子落在了不同的土壤里，最终长成了形态各异的树。

“高瓴向前，红杉向后”——一句话，道出了外界对这两家巨头风格差异的直观感受。向前，或许是拥抱变化、追逐浪尖；向后，或许是回望本源、守住节奏。两种方向没有绝对的对错，却折射出完全不同的投资哲学。

或许这正是投资的迷人之处：同样的时代，同样的起点，却可以因为选择的差异，描绘出截然不同的曲线。高瓴与红杉的故事，既是一部资本进化史，也是一面映照企业抉择的镜子。
