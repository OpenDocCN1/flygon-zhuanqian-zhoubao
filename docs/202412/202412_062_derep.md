# 中国人开美国银行户的所有途径揭秘

长期定居美国，自己公司也在美国运营，身边总有人问我：中国人到底怎么才能开个美国银行户？今天我就从“在美国的外国人”这个视角，把能走通的路子一次性讲透。

![中国人开美国银行-1.png](img/article-) images.zsxq.com/FmBkOG4HwSp6DvvXbz31oGDJNZbp)

先说说国内见证开户。人在国内也能办，比如汇丰香港的见证开户，具体攻略可以参考这个链接：![中国人开美国银行-8.png](img/article-) images.zsxq.com/FhZvZKXqaHO-2CSbExvsKRyDnIfl) `www.amz10years.com/how-open-hsbc-hk-bank-in-china/`

再有一条路，光凭身份证就能开。目前比较稳的是华美银行，但 Velo 官方开户的成本不低：要存 2.5 万美金，还得交 300 美金开户费。 ![中国人开美国银行-2.png](img/article-) images.zsxq.com/FgJXCSjKlnFwgHRuFdfAWGW357ut) 不过也有靠谱的华美官方代理渠道，比官方便宜不少，存款门槛也没这么高，称得上稳定又亲民。 ![](img/0287edb190ba937b855ff9620fd774da.png "None") 想要代理渠道的话，可以找我。

同样是身份证，还可以走第三方跨境收款平台。 ![中国人开美国银行-4.png](img/article-) images.zsxq.com/FltTjkjLZX16A9KmIMCNjBGDiKub)

如果手上有护照，数字银行也是个选择。Wise 大家都知道，账户不太稳定，开着玩玩就好；Revolut 对 IP 的要求比较严，能开下来就能正常用。 ![中国人开美国银行-6.png](img/article-) images.zsxq.com/Fky6WZeRWp2CVyeP_vkAkcpHqp-t) （Wise 注册教程：`www.amz10years.com/wise-registration-2/`；Revolut 官网：`www.revolut.com/`）

护照+ITIN 的网上申请路线也值得一试：可以申请 Capital One 支票账户（历史文章有详细指引）、VARO，还有 Venmo（教程见：`articles.zsxq.com/id_x73bbkhkkzau.html`）。ITIN 的申请方法看这篇：`articles.zsxq.com/id_w0r5cibax0qb.html`。 ![中国人开美国银行-5.png](img/article-) images.zsxq.com/FhPweFc_Apzo3s_JN1XEUS48GQZg)

这里简单说明一下支票账户和信用卡账户的区别：支票账户类似国内的活期储蓄卡，支持转账、收款、付款和借记卡扣款；信用卡账户则不同，入金必须通过美国支票账户，有些银行支持不同名入金，比如 Capital One 信用卡，可要是没有支票账户，用起来会非常麻烦。信用卡主要用来支付，不能直接充值。

如果你已经护照+SSN 且人在美国，那就没什么好纠结的，直接去银行开户最省事。 ![中国人开美国银行-7.png](img/article-) images.zsxq.com/FiAM2hxmB_68pY3oNws3QJEndjjQ)

最后聊一下美国公司银行户。目前合规能开出来的选择不多，成本一般在 1000 美金左右，我自己对接过合规开户的代理，有需要的可以找我。当然，如果公司有负责人并且有签证，直接飞美国开就行。

以上就是中国人开美国银行账户的主要途径，希望对你有帮助。有问题欢迎评论区聊。
