# 视频号“手绘情感语录”赛道拆解：用AI伪手绘快速吸粉，兼顾创作者计划收益
作者：龙哥

大家好，我是龙哥。

最近我一直在实操视频号里的一个冷门但非常吃香的垂类：手绘风情感语录。这条赛道涨粉速度超出预期，门槛也低到惊人，所以把目前的玩法整理出来分享给大家。相信不少人刷视频号时都见过这类内容，它和送祝福类视频同属一个逻辑，都是精准锁定中老年用户群体的情绪内容。

变现路径也很清晰。第一是直接申请视频号创作者计划吃广告分成，第二是靠快速积累的粉丝做后期带货、私域转化等。实话实说，这个赛道的涨粉效率是真的猛。

### 这条路怎么玩？

操作思路非常直接粗暴，核心就两步：AI出图 + 剪映剪辑。

这里的“手绘”并不是真的拿笔画。借助AI工具生成一副看起来像手绘水彩、卡通风的配图，外加一句走心又扎心的情感语录，视觉上就有了那种温情手作感。利用这个“看似手绘实则AI”的认知差，成本几乎为零，却能做出和传统手绘同款的质感。

视频脚本也是高度模板化：画面是慢慢浮现的AI手绘图，背景配一段舒缓的音乐，字幕一句一句打出那种关于亲情、爱情、人生感悟的短句。内容调性偏治愈、共鸣、祝福，极易引发中老年用户的点赞、收藏和转发。

上手门槛低，复用性强。换一张图、换一句文案就是一条新作品，日更很容易实现。只要选题够共情、节奏舒服，播放量和涨粉都很稳定。

关于收益问题，这里也补充一个常见疑问。

有朋友问：视频号创作者计划的收益是不是主要靠评论区用户点击广告？之前有账号流量很大但收益却很少，是不是因为没人点广告？

确实如此。创作者计划的广告收益和互动深度高度相关。评论区活跃度越高、用户停留和点击意图越强，广告展示和点击的概率就越大。所以在做情感语录时，可以适度在文案结尾埋下引导互动的点，让评论区自然发酵，评论量上去，收益也会跟着上去。
