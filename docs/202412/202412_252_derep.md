# 从编程新手到🛰️小程序开发者：我的副业探索之路

大家好！

我是今年9月才加入赚钱圈的新面孔，一直以来都以潜水的姿态默默学习。作为一个上班族，我一直怀揣着一个梦想——通过开发小项目实现副业转型，实现真正的财富自由。虽然编程路上的基础薄弱，但我从未放弃，不断地去尝试各种新工具和新方法。

前段时间刷到油管上@AI进化论-花生的大作视频，分享的是用Cursor工具打造AI聊天网站的实战经历。视频中那些一气呵成的开发速度，直接把我带入了震撼世界。看完后，我立刻跟着原版跑起来，在vercel上快速搭建出了一个属于自己的AI聊天小网站。

后来发现，老婆对星座运势相关的内容特别有兴趣，视频里她常常被那些具体解读吸引，于是我决定顺势而上。花了整整7天时间，我用🛰️小程序的形式上线了一个小众星座运势小程序。整个项目从零到一地完成，拿到最终截图后，打开小程序实时体验，那种自豪感真是满溢心头。

不只是成就感，今天我还想把最近参与Cursor航海计划的第一个课后心得，全都分享出来。从前期规划到后期上线优化，我把自己在开发与部署过程中的一些感悟总结成点，希望能给正在尝试Cursor或小程序开发的同伴们带来一点启发。希望通过分享，大家都能少走弯路，早日真正上手。

开发心得分享：

1. 早期布局要扎实扎实。项目刚启动时，花大力气规划功能框架，把核心规则和技术路线都写入.cursorrules文件里。后面随着迭代，及时同步更新README文档和关键代码注解。遇到Cursor偶尔会忘掉之前的背景时，最稳妥的做法就是让它先翻看README，重新把握项目全貌。

2. 利用GitHub把控节奏非常关键。每完成一个 milestone，都要立刻提交代码并推送到远程仓库。Cursor有时候在修复bug时改动太猛，容易回过头去撕掉之前的好部分。这时立刻切换回上一个版本，进行修复和验证，能最大程度减少无效消耗。

3. 不能把全部压力交给工具来扛。遇到报错时，别急着一股脑把所有信息往Cursor里扔，否则容易卡死循环。应该先自己分析清楚代码的整体结构、前后接口关系以及数据流走向，提炼出几个核心问题点后再交给它分析。能够给出足够清晰的引导方向，解决效率会提升几个数量级。

4. 遇到审核关卡时，可以适当求助ChatGPT。在🛰️小程序的发布审核环节，我碰到了“涉及信息资讯”“深度合成技术”“算命占卜”这类敏感分类，多次被卡着说不行。后来参照ChatGPT的调整建议，重新改写功能文案和内容描述，最后完美通过。

5. 通过自动化脚本大幅提升响应速度。为了让用户查询时不要卡在智谱AI实时生成，程序调用太慢。我让Cursor写了一个定时脚本，每天凌晨自动调用接口生成对应星座运势并存入数据库。之后用户每次打开小程序，直接从本地数据库拉取数据，体验速度立即提升。

开发中使用的技术组合如下：

前端部分：采用uni-app框架（Vue3为基础），搭配SCSS完成样式美化，借助Vuex做状态管理，uni.request处理网络请求，自定义组件化UI搭建后端部分：使用Python FastAPI框架，结合MySQL数据库存储数据，并接入智谱AI的ChatGLM模型。

希望以上内容能让更多人看到这套从编程小白到小程序开发者的实践路径。接下来我在Cursor航海计划里继续深挖，现在强烈期待有兴趣的朋友来分享你的开发心得、踩过的坑，或者想交流怎么把类似星座小程序做到极致。

最后附上小程序相关页面截图，欢迎大家扫码体验一下并提出宝贵改进建议。我也会持续迭代，感谢大家耐心阅读和交流，一起在这个圈子里成长进步！
