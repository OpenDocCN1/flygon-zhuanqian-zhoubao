# 社恐新人感谢赚钱平台及鱼丸的支持与帮助

你能想象吗？一个刚进社群不到一个月、平时连话都不太敢主动说的新人，居然会自发写下人生第一篇帖子——不为别的，就为了好好谢谢我的“丸丸”。

我是维拉，11 月刚加入赚钱。进来没多久就发现一个有趣的现象：不管是新手体验期还是正式加入后，和我对接的人全都叫“鱼丸”。统一头像、统一昵称，大概是平台为了规范和效率吧，把大家做成了“标准化”。但实际接触下来，你会发现每一个“鱼丸”背后都是一个活生生的、超温暖的人。比如我的那位，我就偷偷叫她“丸丸”。

她很主动。我刚进来的时候，她就来问我：为什么想要加入赚钱？过一阵子又会发消息：最近看赚钱里的内容了吗？都看了哪些板块？有没有什么感兴趣的或者想不通的？后来我跟她提了一嘴想报名📕虚拟资料项目，她不但没敷衍，还把她自己跑过的经验一股脑分享给我，建议特别真诚，特别落到地上。

现在我已经开跑第一个航海了。航海手册写得挺细，群里教练也一直在线答疑。但当我带着疑问去找丸丸时，她依然特别耐心地又给我讲了一遍，还毫无保留地给了不少实操干货。最让我没想到的是，她还会变成“夸夸团”，一边给我打气，一边帮我把信心和经验都充上电。

说实话，我这待遇感觉像白捡了一个专属私教。这赚钱入得也太值了！所以我就想着，得用一个有仪式感的方式来道谢。我的 BP 丸丸——我定个小目标：一定把这个项目跑通，还要赚到钱。我觉得这比说多少句谢谢都更实在。

丸丸，你等着。这笔账，我记在心里了。
