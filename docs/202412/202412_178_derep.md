# 房晟陶：创始人的五大迷思，堪比中年男人的三大错觉
作者：龙哥

**打工和创业不是两条路，而是同一枚硬币的两面**

很多创始人都有过类似的纠结：到底是先积累几年职场经验，还是干脆破釜沉舟直接开干？总觉得选了一条路，就永久失去了另一条路的机会。

但房晟陶在谈到创始人常见的那些迷思时，说了一句非常清醒的话：职业和创业，从来不是对立的存在。它们就像同一件事的两种形态，内核是相通的——都是在解决问题、创造价值、修炼能力。真正让它们看起来水火不容的，不是环境，不是时机，而是创始人自己的认知。

如果你心里先把它们设定成“非黑即白”，那么无论你处在哪个位置，都会觉得别扭。反过来，如果你能看见两者之间的连续性，打工可以为创业积累弹药，创业也能为打工沉淀本事，心态瞬间就不一样了。

所以别再把职场和创业当成不可调和的两端。先拆掉内心的那堵墙，再决定往哪走。
