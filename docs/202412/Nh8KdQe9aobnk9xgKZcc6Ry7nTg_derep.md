# 英语场景对话视频制作工具、教程、提示词

想不想自己做出那种“英语老师同款”的场景对话短视频？不用会剪辑，不用会配音，也不用会画画，只要用好下面这三款工具和两段提示词，你也能快速上手。今天就把完整玩法整理给你。

## 一、用到的三款工具

1.  Kimi（https://kimi.moonshot.cn/）：用来生成场景策划、脚本内容，就连给绘图工具的提示词，也能交给它写。
2.  即梦AI（https://jimeng.jianying.com/a）：负责把文字变成漫画感插图，画面素材就靠它。
3.  TTSMaker（https://ttsmaker.cn/）：专门生成英文配音，直接出英语语音，省去自己录音的麻烦。

## 二、第一段提示词：让AI当“情景对话老师”

这段提示词适合用来生成完整的英语对话内容，核心思路是：

**角色设定**：把AI设定成英语老师，学生是准备去英语国家旅游的高中生。到了国外，到处都会碰到需要用英语沟通的场景。

**任务要求**：给这位学生准备10个日常英语对话场景，并且把每个场景的对话内容写出来，方便学生做口语练习。

**具体细节**：
- 用词要符合英语母语人士的实际口语习惯，不要太书面化。
- 如果出现了超过英语四级难度的词汇，必须标注音标和中文释义。
- 每段对话控制在20句左右。
- 对话生成完后，还要附上对应的中文翻译。

**执行流程**：先给出10个场景，等待学生选择想练哪个；确认场景后，生成该场景的英文对话；最后再生成中文翻译。

如果AI表示已经理解了任务，会回复一句：“我是您的情景对话老师，您现在先练习英语对话吗？”看到这句话，就说明提示词已经成功激活了。

## 三、第二段提示词：让AI当“插画师”

有了对话内容，还需要配合画面。这时候就要让AI扮演插画师，专门为英语课本绘制日常对话插图，走漫画风格。

**任务内容**：根据指定场景，写出绘画细节说明，让实习画手拿到就能照着画出来。

**必写细节**：
- 场景里的背景环境。
- 场景中出现的核心人物。
- 人物的外貌特点和穿着打扮。
- 整体绘画风格。

字数不用多，控制在100字以内，简洁清楚最好。

**操作步骤**：先确认要绘制的是哪个对话场景、有哪些人物角色；接着再根据这些信息，生成完整的画面细节描述。

## 小结

把三款工具串起来就是：用Kimi生成内容和绘图提示词，用即梦AI画出漫画图，再用TTSMaker配上英文语音，最后简单拼合成视频，一套英语场景对话短视频就出来了。核心就是这两段提示词，建议直接收藏，用的时候改改细节就行。
