# 下山才是真修行：修仙故事里藏着的职场入局感

别把我当得太严肃，这只是个娱乐向的拆解。

高中时期的同桌丢给我一部修仙小说《神游》，作者徐公子胜治。书里很多梗至今还在脑子里转，其中有个情节印象尤其深。

一位在大山里苦修了二十年的大弟子，修为已经够在小门派里直接当掌门了。师父某天把他叫到跟前，只说了一句：下山吧，去红尘走走。他答应了，却没料到真正的劫数，从踏出山门那一步才算真正开始。

这段设定，放在我们身上就是一模一样的剧本。十二年应试教育的闭环，我们就是在山上打坐的那批人。考卷是法诀，排名是境界，高考那天就是师门放行的令牌。一旦走出象牙塔，入世的修行才正式拉开帷幕。社会上的每一次选择、每一次试错、每一次自我证明，本质上都是换了场地继续修。

道家的修行框架从古至今都非常完整，典籍和案例也汗牛充栋。它未必能直接用在赚钱和成长上，却能提供一套很有趣的参照系。把公司当红尘、把 KPI 当心魔、把迭代当炼丹，也能让枯燥的打工日常多一层文学调味。把它当作一种精神上的 YY 就好，茶余饭后笑笑，别上头。
