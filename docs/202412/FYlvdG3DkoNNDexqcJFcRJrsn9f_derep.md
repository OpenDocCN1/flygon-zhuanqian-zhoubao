# 班本PPT赛道到底是什么

1、什么是班本PPT

简单说，班本PPT是围绕一个班级的特色、主题活动、文化建设、教学汇报等需求制作的演示文稿，用来展示汇报、辅助教学。主要是幼儿园老师给孩子上课用的演示材料。

班本一般分小班、中班、大班，建议先从一个年龄段切入，再逐步扩散。

2、📕上班本PPT的笔记长什么样

![](img/c59dc006c03ea18b314661443be3cd97.png)

![](img/ae8d5e9c8a2c7a53b506b0b1b79929b2.png)

从图上能看出，上半部分是PPT，下半部分是思维导图，二者合成一体的呈现方式。页数普遍偏多，买家基本不会要低于30页的，所以原创成本确实不低，也难怪人少。

3、目标用户是谁

核心人群就是幼儿园老师。很多老师没精力或不会自己做班本，只能在第三方买现成的来用。

4、如何获取流量

主要靠📕的长尾搜索。幼师会用关键词去搜相关资料，找到笔记后加微信询单。前期需要大量铺笔记，后期靠被动搜索转化。

举个例子，像“衣探究竟”这种词一搜一大片，老师一看就懂，会直接来搜或定制。

下面进入实操部分，包含账号注册、操作路径、变现方式。看完基本就能自己跑起来了。

# 一、账号注册

注册本身很简单，有手机和设备就能做。

1、手机下载📕APP
2、手机号登录
3、输入手机号收验证码，勾选协议
4、点击登录

有几个细节要注意：

1、一机一号一IP：单独手机+单独卡，最好用流量注册。新号最重要。
2、生日选在最近一个月内，📕生日当天会送流量券，有效期半个月，发笔记时能用上。
3、注册时年龄选20出头，兴趣随便点。
4、昵称和简介先别改，也别急着写。建议养号发3篇后再改，刚注册就改容易被同行盯上拉黑。
5、最好用全新账号，或者把老账号注销重来。不要用发过其他内容的号来做。

原因有二：老号标签已经固化，换赛道难起号；老号很久没发，权重掉得厉害。新号从0到1更顺。

# 二、养号建议

养号并不复杂，我们的做法就是搜垂直关键词，比如幼儿园班本，看同行内容，提升活跃度。别纠结什么七天螺旋、养多久。按我说的做，第一批笔记小眼睛基本都能过百。

下拉框会出来长尾词，可以点下拉或手动搜，看同行笔记，直到推荐页开始出现相关内容。

![](img/df2525991a7b27d46c18427136fdf092.png)

我们的简易养号节奏：

第一天：流量注册，注册完别动
第二天：开始刷领域笔记，每天30分钟，分段刷
第三天到第五天：持续养号，适度点赞收藏评论
第五天：改包装，人设搭好，上午刷笔记，下午发第一篇测数据，继续互动

如果一篇干货能当天破100小眼睛，账号基本就正常了，后续可以正常更新。

我们偶尔也直接发，不养号，效果也差不多。但建议边养边发，账号有活跃，平台才判定权重高。只发不看，容易被判定活跃低。

资料设置参考同行：昵称、简介、头像。头像可用卡通、真人或风景，昵称随意，简介照搬对标号。

![](img/2ab9e1e0d189c35ca16fe19ecb499298.png)

小结：准备手机+📕账号+成年实名→养号提权→选赛道→起号→持续运营。

# 三、资料制作

## 1、定主题

常见主题有：水果蔬菜类、季节类春夏秋冬、节日类清明、劳动节、端午、教师节、母亲节等。

不会找主题就用关键词搜：微信搜一搜打“春班本”“夏班本”，二学期大班要幼小衔接就搜“幼小衔接班本”，能筛出春天、夏天、花、果、野菜、西瓜、水、时间、姓氏等。

只要主题对，哪怕PPT做得一般，有需求就能卖，需求决定成交。

![](img/313840a7c3da468a57b7e70a85f13a5c.png)

也可以在📕搜：幼儿园班本、幼儿园班本课程、幼儿园班本课程小班/中班/大班，课程故事会出来很多主题。搜索页顶部会出现高频词，像泥、吃饭、瓶子都是通用爆款主题。

这类主题做上手后不易爆发，但长期稳定，配合时令主题一起做。

![](img/db62b6ee5885e67c0b9a03ce914ab211.png)

看同行笔记发布时间，如果是1-2天内的，就说明这个题材近期在跑，可以跟进。

![](img/bb71c79136ce0429b1b45784f28942f7.png)

## 2、班本结构

一个完整的班本结构是：课程缘起+课程目录+课程脉络图+课程实施+课程反思

课程缘起
就是主题如何产生的。比如蜗牛主题，缘起可以写户外探索时孩子被蜗牛吸引，进而展开讨论。核心是描述主题的触发点。

![](img/a0c58403c078e77022163a4c898dd90e.png)

![](img/5e2175194155fe38917b15e037d1c9bd.png)

课程脉络图
就是思维导图。活动结束后形成的逻辑框架，有预设图和实际图两种，至少要有思维导图。

![](img/c6f377e9ea5d6c9963f8da115a005158.png)

课程实施
逻辑要顺。比如生菜主题，先认识再深入，不能一上来就煮着吃。内容可以从👸号文章里搬素材，理清顺序就行。

![](img/2e88aaf4bd46b17c20c596d3e5f2ab20.png)

![](img/8420f1952f69ea6600b5e4b7a9ae73c8.png)

课程反思
教师的复盘环节，写孩子收获了什么、老师学到了什么，和工作复盘类似。

![](img/1b075d42b4e51919746ec01fdbb5b403.png)

整体流程：定主题→定主题重心→搜素材→做思维导图→写文档→做成PPT。

## 5、脉络图制作

思维导图可以参考别人的，也可以自己做。框架要有逻辑，多看👸号文章模仿标题即可。

制作方法：

1、电脑新建PPT，插入一张图片，选择思维导图模板。很多需要会员，可去闲鱼淘宝买几天试用。挑颜色亮的，别选黑白。点击立即使用。

2、整改填充。先去微信搜一搜找对标班本。比如生菜主题，找半年内的，👸号里标题一般是“生菜总动员”“你好生菜”“遇见生菜”“嗨生菜”“我和生菜有个约会”“生菜有道”等。大班可选“生菜有道”，小班选易懂的。

从左至右填充思维导图。

课程缘起基本通用，生菜大调查、生菜初体验、种植过程可写认识种子、松土播种、采摘生菜、生菜沙拉、小小厨师等。

## 7、班本PPT制作

打开整理好的文档，新建PPT，插入背景图。WPS自带很多背景，扁平几何、卡通小清新都可用。

参考同行做法，多是白底+贴画。

![](img/90d77370614c7f1e82b96088dc0f7bd5.png)

![](img/3091a35814374f57fac5e107ab6158c4.png)

也可以先找背景图右键设为背景，删掉原图，输入标题如“遇见生菜”，调字体和行距。

![](img/37f12bd07940f2441cf15c987590c8b1.png)

![](img/7ed3b4c67ac8b753a98c32c0e2a93dba.png)

制作人信息可写上。不想用自带图可去千图网找免扣插画，搜索贴画下载JPG格式。

![](img/d52d1d997cc041017189fe70b2cd7f98.png)

或在PPT插入→图片→更多图片→图标里找生菜插画，免扣可直接用，微调大小位置，多放几个，顶部加“幼儿园班本课程故事”字样。

![](img/dbd56d54c65606f9284b603423d5778c.png)

目录页：把主图复制粘贴，插入形状做底，颜色要和主题搭，别花哨。输入目录文字。

![](img/529750bdc8714db2c2d54155823b1385.png)

继续添加文本框，输入“课程起源”，加粗字体，样式自定。

![](img/f651364116ca836069c33babfac114dc.png)

![](img/4f390da915630fe6066b460082fa54b2.png)

做幼儿园班本课程PPT、想让内容被更多人看到的朋友，这篇建议先收藏。从PPT制作、发布到引流私域，整套操作都给你捋清楚了。

先说PPT部分。打开页面后，把形状调到顺眼的状态；倒影、阴影、发光这些效果都可以按需开关，想用哪个就点哪个。颜色别调太浓，淡一点更舒服，大小和属性就按自己的节奏来。![](img/eb56ae4791fcc7e5cb9d89424d156e5f.png)

接着把当前页面多复制几份，每一页分别填入板块标题：生菜初见、种植过程、生菜美食、趣玩生菜、课程总结，差不多就是这些，逐个调好。![](img/d7185cd434d740d47a9d192c8f9daed8.png)

再复制一页出来，放上对话框，把文字调整一下。还可以插入小朋友图标：在搜索框输入“小朋友”，然后到插入菜单下找图片，接着在更多图片里选图标，搜一下“小朋友头像”，出来的素材很多，挑个喜欢的用，这就是课程起源页面。![](img/950489dec7353152e0d809753b47236a.png)
![](img/7c81dab24ae516fa6ef21ec35bd69b4b.png)

下一页是小朋友讨论的对话，用对话框呈现：在插入菜单里选SmartArt，找一个合适的版式放进去；不想用现成的，也可以自己插入图片，再手动选形状，轮廓和颜色自己定。![](img/92a3263f901e5d15816805cc81be6278.png)

接着把小朋友的对话依次输进去，文字用黑色，字号调大一些。想加图标就去图标库找，颜色、形状、线条都按喜好来，喜欢哪个用哪个。老师说话的部分，找一张看起来像老师的人物插画，把位置放好，文字尽量对齐，整体才不突兀。![](img/d842d6bb1df73e26ddd2fba8e1db5b88.png)

对话框完成后，就是“展开激烈讨论、孩子们投票”的环节。把对应的文字和图片粘贴进去，调整好大小。图片想更精致的话，可以在效果里选“柔化边缘”，轻轻点一下边缘就好看不少。这步可做可不做，字体也随意，挑喜欢的用。![](img/e53132d0aea391e86a6cecf2f2824bdf.png)

接下来做“生菜初见”：复制一页PPT，先把原来的内容清空，新建页面后插入文本框，写上“生菜种类”，把字调大、换个颜色。PPT里字体样式多，随便选；再开一个文本框补充说明，下面放生菜图片。![](img/5624d059c4df77492db0c8a20ec4343c.png)
![](img/0e9a6b4078abad62eec8a4631c7e778c.png)

然后是“生长条件”：继续复制一页PPT，把生长条件的文字和图片填进去，边框大小根据文字量来调整。![](img/e89b97fff8259523915c27fe6885b883.png)

再是“营养价值”：按顺序把文字和配图填好，甜滋滋的位置要留意。到了“种植过程”，不需要的边框直接删掉，把文字单独提出来，重新放一个图形文本框，输入小朋友的对话，再插入人物插画。颜色、线条、字体颜色，都按自己喜欢的调。![](img/1bc6716241b863ceb15f1c3273793cca.png)

接下来是“拔草松土”：这页很简单，图片加文字，再配点插画就行。这些图片后面要发给用户，用户会换上自己幼儿园小朋友的真实照片，所以图片本身不用太在意。![](img/c007a16cf6a504639b3211835add2193.png)
![](img/7e7796ba9c1e2a519591aae40f230c1d.png)
![](img/586e2d78d15588f39810656382826364.png)
![](img/0aea2b66c2227d8b0264698b9875585a.png)

PPT主体做完后，把思维导图也放进去，位置在第一张图后面、课程缘起前面。可以复制粘贴，调到合适的大小和位置，再把线条、效果、颜色统一调一调，整体检查没问题就可以保存了。![](img/1281b91121a391153f8d5b8dca8418b2.png)

制作环节其实不难，大家可以按上面的步骤上手试试。制作先讲到这里，下面说发布。

标签写法：直接参考同行的标签，复制过来改改就能用。![](img/6a919c2525e46b6e2a1f0469eb18ef90.png)

发布后要做的事：发完先看看笔记能不能投薯条；大概2小时后搜一下标题，能搜到就说明被收录了。我们主要就是做收录，方便以后吃被动搜索流量。浏览量几十到100+都正常，只要内容是原创的，正常发就行。发完之后，别自己去点赞、评论、收藏，让笔记自然发育就好。

引流方法：私信引流就好，很简单。笔记下面有人评论，就让对方私我们，然后把带微信号的图片发给对方，大家都懂，直接引到私域变现。我自己做了一张简单的加微信图，经常用。![](img/3cfd7885db429aac86f2df4ace4ba5f6.png)
注意：评论里千万别提“私信、私聊、加v、微信”这些词。如果别人回复了你的评论，可以回“厚台思，宝子思我”这种谐音字，意思就是后台私信。千万不要直接说加微信，也不要说v，发图片过去就行。

朋友圈打造：日常朋友圈发发生活内容，穿插发班本课程也可以，不发也没问题。做一份目录价格表，客户有需要就直接发图片给他，可以单独购买，也可以加会员打包购买。![](img/5e81a23b88c525f2293f4e5fb5a3ca82.png)
