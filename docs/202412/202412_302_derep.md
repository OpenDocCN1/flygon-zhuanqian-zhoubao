# 转转2.0实战：一个做12年二手数码的老炮的收入拆解

大家好，我是山人。成都做二手数码，目前主要摸的盘是同行批发、回收、实时竞拍，加上转转2.0。零售和直播这块也在同步推进中。

我跟数码打交道已经12年了。新机卖过，维修做过，赛格也摆过档口，二手机直播也跑过。起初一直没下定决心写这篇二手机的实操，今天是被彩虹推动的，女朋友负责资源对接，彩虹从大纲到内容整理、进度跟进全程搭把手，在这先谢过。赚钱团队确实很会挖机会，投进去不亏。

下面聊重点，转转这个平台我简称转转。目前的赚钱情况是这样：今年2月刚好是入局第三个月，毛利冲到了40万。正常月份的毛利区间在15万到30万之间。净利润大概能吃掉毛利的30%到40%。一年里最难熬的是四五月，基本就维持在保本线。
