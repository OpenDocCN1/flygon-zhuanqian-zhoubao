# 构建有效智能体的实践与思考
作者：龙哥

你有没有发现，想做个AI应用，有时候一个提示词根本搞不定？我最近就在折腾一个小产品——让AI帮忙识别商业机会。一开始以为挺简单，结果发现复杂度远超预期，只能老老实实把任务拆开，一步步来。

后来我碰巧读到Anthropic（就是Claude.ai背后那家公司）的博客《Building effective agents》，才恍然大悟：我那些看似“土办法”的操作，其实全是官方总结过的模式。

把任务拆成几个步骤、每个步骤单独跑提示词，这不就是链式提示词嘛；遇到需要联网查最新资料的情况，就得有人分配任务、有人去执行，典型协调者/工作者模式；最后的结果好不好，还得靠用户反馈来判断，这又成了评价者/优化者模式。

整个过程流程明确，所以还轮不到智能体自己乱决策。想想也挺有意思——我们平时可能一直在不知不觉地构建“流程型智能体”，只是没人帮我们归纳成体系。Anthropic把这些模式整理得明明白白，以后再用起来，心里就有底了。
