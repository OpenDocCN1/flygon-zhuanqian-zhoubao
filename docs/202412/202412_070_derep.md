# 从体制内妈妈到教辅变现2w+：我用两个月验证的一个副业路径

很多人在赚钱里潜水很久，我也是其中一个。

我是静静妈，上海一个90后体制内二胎妈妈。早在2021年我就关注了赚钱，当时觉得内容信息量太大，自己消化不了，也就一直观望。直到去年12月才真正加入进来，开始认真尝试。

之前的副业尝试过知乎好物推荐，也在📕做过真人口播接广告。2022年4月开始，我断断续续地做私域引流，但一直没找到真正能稳定落地的方向。

转折点在今年10月15日。我决定聚焦一个更清晰的赛道：小学教辅，主攻低年级家长群体。仅仅用两个月的时间，收入就突破了2万，其中一部分还在支付宝结算中。

这条路对我来说不是一蹴而就，而是从长期积累到最终聚焦的结果。我把从了解到入场，再到做起来的实战复盘整理在了飞书，方便大家参考： [`a35q2zqvrm.feishu.cn/docx/OTCBdtlHUoQWaKxjeoKcqyfKnfd?reRdXZ=1`](https://a35q2zqvrm.feishu.cn/docx/OTCBdtlHUoQWaKxjeoKcqyfKnfd?reRdXZ=1)
