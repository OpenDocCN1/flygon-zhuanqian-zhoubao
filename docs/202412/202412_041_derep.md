# 互联网小白在 YouTube 和抖音的实操经验分享
作者：龙哥

一个纯新手，没资源没背景，硬是在 YouTube 上闯出了一点水花。今天把这阵子的经历好好盘一盘，给同样在路上的圈友一点参考。

先说数据：截至今天，YouTube 一共发了 48 条视频，账号总浏览量冲到 30w+，订阅数 288。近两天开始顺手把内容同步到抖音，没想到两天就拿下 20w+ 浏览，涨粉 400 多。这个成绩不算亮眼，但对一个刚入门的互联网小白来说，确实是个挺大的鼓励。


评论区里有人提到批量剪辑那个方法很实用，3 秒一个片段，效率直接拉满。确实，懒人自有懒办法，能用工具解决的事，绝不多花一分钟手动磨。

新手做内容，最怕的就是信息差和闭门造车。把经验摊开来讲，能帮一个是一个。大家有问题也可以在评论区聊，看到都会回。
