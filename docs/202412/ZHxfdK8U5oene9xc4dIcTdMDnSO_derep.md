# 转型📕职场博主，粉丝突破10万，接广变现6位数心得复盘

从百家号日更一年赚500，到📕10万粉赚6位数：我的4年副业复盘

先看一个数据：年初3.8万粉，现在10万粉，一年涨粉6万多，累计变现6位数。这说的是我自己——王多维，一个📕职场博主，目前运营两个账号，加起来有12万+关注者，主要靠蒲公英平台的商单变现。算起来，这是我深耕📕的第三年，也是真正跑通的一年。

在找到正确方向之前，我其实折腾过很多地方：百家号、知乎、抖音、B站都留下过脚印，还试过带货笔记、书单视频、短剧出海、小说推文。正是这些弯路，让我总结出6条最值钱的认知，今天全部摊开讲。

一、平台红利 > 个人努力

同样一篇内容，放在不同平台，结果可能相差百倍。我最开始做百家号，脑门一热，连续100天雷打不动写800字，坚持了一整年，最后账户里只躺了500块，还是靠卖号拿到的。后来转战知乎，我积累了一万粉丝，一年有6000块进账。再后来我来了📕，头一年就挣了两万，今年更是直接冲到六位数。也就是说，我今年在副业上的收入，已经超过了过去三年全部收入的总和。

内容方向同理。我最初在📕做大学成长，很快收获了三万粉丝。但放到现在，我绝不会再选这个赛道——因为当时做这行的人少，内容也偏基础；如今竞争白热化，我一个211硕士，放到人堆里根本不显眼。

所以我的结论是：平台和领域在不同的生命周期，能撬动的杠杆大不相同。最好选一个发展趋势向上的地方，并挑一个相对蓝海的内容方向。具体判断标准，我用一个公式来表达：自己熟悉 + 前沿数据信息 + 成功案例 + 前辈指导。这四个要素凑齐两样，就可以开干了。

二、想说话的欲望，是坚持的燃料

有人说做副业靠自律，但我不太认同。我能坚持四年，靠的其实是“想说话”的欲望——我很迷恋自己的想法被大家看到、得到认可的感觉。比如有粉丝按我的方法去了好学校，有人因此保研、拿到offer，这些反馈都会让我兴奋很久，也是我不断创作的原动力。

我平时会有意识地训练这种能力：上下班路上听到喜欢的播客观点，就打开手机录音，把自己的想法说出来；坚持写笔记，画思维导图，把思路理清楚；定期整理收藏夹，把零碎的知识用自己的话重讲一遍。

三、留在场上，赢过时间

我三万粉的时候，看那些五万、六万粉丝的博主，觉得他们像大神。但我现在十万粉了，回头一看，他们中的好多人还在原地踏步。这中间的差别是什么？不是天赋，而是他们爆款时我在赶路，他们停更时我还在更新。只要你不退场，时间自然会帮你筛掉一大半的人。

为了不被筛掉，我做过两个方向的努力。一是持续迭代自己。这几年我留下了250篇笔记，换过十几种完全不同的风格，什么大字报图文、单图图文、plog、口播、干货vlog、日常vlog都试过。每隔三四个月，我就会对封面、标题、文案和视频形态做一轮优化。因为📕在变，用户也在变，创作者不变就只能落后。二是尽量呈现真实的我。分享活生生的生活，比到处摘抄别人的干货更可持续。那种创作者和读者之间真正热络的连接，才是做号的最舒服的状态。

四、别让情绪偷走你的节奏

我的账号经历过至少三次大低谷——发什么都没人看。刚开始我也会着急得睡不着，后来发现，情绪根本救不了数据。于是我不再盯着后台，干脆把自己当成一台无情的更新机器：每天打开📕找选题，写内容，发出去，然后再找选题。发现没人点开，就从封面标题下手；看到完播率不行，就把开头改掉。实在不行，就把那篇笔记隐藏掉，重新再发。当我把注意力从焦虑转移到具体问题上，反而轻松多了。

五、向顶级选手“抄作业”

我上学时就用过这个方法：跟着学霸的脚步走，最后从挂科逆袭到保研。做📕也一个道理。先找到这个赛道里做得最好的几个“学霸”，如果是视频，就慢放逐帧看，研究封面、标题、画面是怎么搭起来的，然后照着拍。注意，模仿不是抄袭，而是把别人的成功逻辑拆到最小颗粒，再结合自己的特点做衍生。我就是这样，从几个10万粉博主身上学会了拍视频和剪辑，慢慢形成了自己的风格。这个环节不拼天赋，拼的是你有没有用心。

六、让主业和副业互相成就

这也是我最后悔的一点：我的副业和主业两条线完全是分开的，导致谁也帮不上谁。副业积累的资源无法反哺工作，工作积攒的人脉也没法导入到内容里。如果你正在考虑发展副业，我强烈建议优先选那些能从主业延伸出来的方向。比如一个健身教练做自媒体，不仅可以通过接广告增加收入，还能顺势提高自己的私教课单价，同时健身房场地、客户人脉、专业知识都能成为内容的养料，副业和主业互为支撑，内耗自然就小了。

最后，再送你一份从零开始做博主的实用清单，都是我踩过坑换来的——

1. 选题顺序：先选市场需要的，再选自己擅长的，最后才是喜欢的。
2. 📕的审美门槛不低，平时多刷高质量内容，把眼光养刁一点。
3. 影响笔记的点很多，别想一步到位，先把你现在能做的那一步做好。
4. 看数据时这样诊断：点击低，改封面和标题；点赞低，说明内容没有共鸣；收藏低，说明干货密度不够；评论低，说明个人特色还不鲜明。
5. 普通人是可以靠接广赚钱的，这一点不需要怀疑，我已经验证过了。
6. 报班付费要谨慎，能免费自学就先自学；如果遇到具体卡点，可以找有经验的人咨询一次，等你靠这行有了稳定收入，再去系统地学习，了解其他博主的玩法和平台逻辑。
7. 你的经历就是最好的内容库。比如我是94年的，211本硕，在国企待了5年，身高188，最近迷上健身、徒步和调酒。这些标签随便挑两个，都能聊出不少内容。你也可以从自己的身份和生活出发，去找选题。
8. 刚开始如果不会拍视频，就先从图文做起。图文照样能起号，但千万不要用那种幼稚的廉价风格。相机拍出来确实比手机有质感，不过iPhone直接出图也够用，前期不必为了画质专门买相机。
9. 想升级装备，记住一个原则：这些钱得在未来1-2个月内靠📕赚回来。我买的单反、vlog相机和macbook，今年都已经用商单回本了。
10. 这次先说这么多，之后有机会我再来一次更系统的复盘。
