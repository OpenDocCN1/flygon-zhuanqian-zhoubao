# “顺藤摸瓜”找养老：我的行业信息挖掘指南

跟养老行业打了一年多交道，我最大的感受就是：这行信息差大得离谱。想认真研究吧，搜出来的内容十有八九是互相抄来抄去，真正有用的东西藏得很深。为了摸清门道，我前前后后关注了上千个养老相关账号，刷了五千多篇帖子，几乎把自己泡在了信息堆里，后来都快成“养老百科”了。

可光靠刷手机远远不够。真正有价值的信息源到底藏在哪？碎片化的资料怎么串联成体系？后来我找了做医疗、康养、银发电商、私域、流量运营的朋友们聊，大家虽然方向不同，但都在盯养老。聊得多了，慢慢发现了规律：线上九成内容都是搬运，真正的干货都在线下。也就是从那时候起，我越来越确定——想搞懂一个行业，先得搭起基础认知框架，然后多出去跑，跟一线的人面对面聊，才能听到不掺水的东西。

算下来，我参加了二十多场行业大会和展会，越跑越发现，养老行业的信息壁垒是真实存在的，而且大家看到、感受到的东西往往很割裂。我猜一定有不少朋友跟我一样，对这个领域感兴趣，又不知道该从哪下手。所以我把整理好的信息源和方法都放在这份文档里了，感兴趣的可以点开看看，希望能帮你少走点弯路，咱们一起探讨，一起往前摸索。


别光收藏，多看多聊多跑线下，真东西都在那儿等着你。
