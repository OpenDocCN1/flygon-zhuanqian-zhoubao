# 👸号日更365天：从爆文到个人IP，我这一年的弯路与拐点

作者：大何
2024-12-24

大家好，我是大何。现在是赚钱【👸号写作航海】的第二期，我正以教练的身份陪跑大家。眨眼间，这期的航行也差不多要靠岸了。

领队让我在收官阶段给大家做一次分享，我认认真真纠结了好几天，最后还是没想出一个足够“高大上”的主题。不是因为我不想认真，而是我实在给不出几条能拿得出手的互联网头衔。

第一次担任教练时，运营同事让我准备一段自我介绍，我拖到最后才回复她。不是性格清冷，也不是故意摆架子，纯粹是翻来覆去想不出要用什么光鲜的title去包装自己。说白了，我就是比你们早踏入这个圈子一点点，多咬牙坚持了几个月而已。

这次航海里的人非常杂，也正因如此更难讲。有人是完全零基础的新手小白，有人是写爆文多年的老炮，有人账号粉丝不少但流量已经断层，正在犹豫是继续死磕爆文还是转型做个人IP；还有人一心想做IP，却被“没流量”卡在原地。

听起来，像在同时给不同年级的学生上课，怎么讲都怕讲不到点子上。

不过回头梳理自己过去一年多的👸号经历，发现我几乎把这些状态都走了一遍。从一头扎进爆文套路，到流量起伏时的迷茫，再到慢慢转向做自己、做个人IP。既然这些困惑我都踩过坑，那不如把自己的真实心路历程掏出来，跟大家聊聊。

这篇文章篇幅不小，大概六千多字，可能会有点啰嗦，但希望你能耐着性子看完。
