# 用 comfyui 搭建具有商业价值的“宝宝未来职业照”工作流

最近看到一篇挺有意思的分享，讲的是怎么用 ComfyUI 搭一套“宝宝未来职业照”工作流。别看是给小朋友做概念照，背后其实藏着不少商业变现的空间。

作者是“花开栀夏你若何”，12月24号发的帖子。她把这套工作流的思路、搭建步骤和最终展示效果都讲得很清楚，核心目标很明确：既要高效稳定地出图，又要保证每一张都有创意和艺术感，不是简单套模板。

整套内容她整理在了飞书文档里，方便大家直接查看和对照学习，链接也贴在文末了。

评论区也挺热闹。有人说“细节满分”，有人感叹“好厉害”，还有航海期的朋友提问：是不是跟着手册就能直接跑通？作者本人也亲自回复了：可以跑通。
