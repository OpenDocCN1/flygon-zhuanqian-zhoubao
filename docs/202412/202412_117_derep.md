# 怎么开始做一家营销咨询公司？
作者：龙哥

很多人问我：想开一家营销咨询公司，第一步到底该怎么走？尤其是怎么才能接到第一单生意？

我的看法可能和不少人想的不太一样：做这一行，往往不是先注册公司、租办公室，而是你已经有了业务，公司才能顺势成立。顺序反了，后面会很难受。

具体来说，咨询公司常见有两种“出身”。

一种是从大公司里直接“长”出来的。比如你本来在知名咨询公司做合伙人或总监，手里已经有一批长期服务的客户。当你决定出来单干，这些老客户可能就直接跟着你走了，或者至少会愿意再找你合作。很多今天有名的咨询公司，其实就是这么来的——像海星被切下一块，伤口愈合后，它自己就是新的生命。

另一种，是从知名品牌方出来的营销高管。比如做过某大厂的CMO，或者长期负责品牌市场业务的核心人物。他们在行业里已经积累了名声和人脉，创业前就有人不停找他们做咨询。所以公司一开张，业务基本不用愁——过去的行业经验和品牌光环，就是最好的敲门砖。我身边就有不少从海底捞、西贝出来的高管，现在都做着自己的咨询生意。

可如果你是刚入行的小白，没背景、没人脉，我劝你先别急着开公司。不管在甲方还是乙方，先踏踏实实干几年，攒够从业经验再考虑创业。否则这个公司开得就太草率了，大概率撑不久。

另外，还有一个话题：刘润老师说过，做战略咨询要“医不叩门”——意思是医生不会主动上门看病，咨询师也不该主动推销。有朋友就问我，那是不是主动去开发客户、找客户推销，就显得很掉价？

我觉得这是把这句话理解偏了。关键问题是：你不是刘润。

刘润老师能说这句话，是因为他有微软高管的光环、极强的写作能力、超广的知识面、出色的归纳总结能力，甚至还有一点社恐。他有资本坐在那里，靠持续输出内容来吸引别人主动来找他。

但你如果只是一个普通的咨询创业者，没有他那样的基础条件，还端着一副“医不叩门”的姿态，结果可能就是——门都不为你打开。对普通人来说，主动拜访客户、展示能力、争取合作，不是掉价，而是职业。先让别人知道你能解决问题，你才有资格考虑要不要“上门”。

所以总结下来就两句话：先有业务再开张，别拿名人名言给自己找台阶。营销咨询这条路，起步靠的是实打实的积累，而不是一腔热血和仪式感。
