# 📕虚拟资料引流与本地商家对接的 SOP 实践

2024年自媒体副业这样一步步走过来，真的是一场心酸到后来的心酸之旅。 上半年满脑子都是想把自媒体玩出花，结果全是流量数据，就是没看到一分钱的影子。抖音那边发了37条口播视频，加上了46场直播，累积直播时长146小时，积累了1113个粉丝，每条平均播放量接近32万；视频号那边粉丝877人，平均播放量6万。表面看成绩不小，可真正变现的部分仿佛一条条被卡住。

下半年终于按对了节奏，专心攻打📕这条主场。先从0到1搭建了一个最小可行版本，也就是利用虚拟资料做引流。这次操作下来反馈非常扎实。专升本方向那里，47个人加了🛰️，其中最终成功转化的4人，转化率高达8.5%。另一边，考研方向更给力，29人入群，转化人数6人，转化率足足20%，直接变现了8000块钱。数据虽不算爆炸，但质量真扎实，让人一眼看出这个方向确实能行。

紧接着又把思路往前推了一步，尝试把这些流量结果和本地商家对接。现在已经完成从1到100的迭代，每个月都能拿到相对稳定的收入。  
总结这一年的经历，就是先踩坑、后探索、再变现，真正体会到“坚持一个正确的事”到底能带来多大改观。也顺势为2025年的打法做个预告。
