# 好老板的双重使命：冲业绩，更做传帮带

一个称职的经营者，肩上其实扛着两件事，而且都绕不开。

第一件事，是把公司往前带，让战略落地、目标达成。这是最显性的战场，也是外界对你成绩的评判标准。

第二件事，更安静也更关键，是把公司平稳地交给下一批人。不是甩手交权，而是用心培养年轻人，让他们真正有能力、有格局接得住手里的盘子。

很多企业为什么起不来、飘不远？根子往往不在当下的冲动，而在基础不牢。人才这块地基打得好不好，直接决定了企业能不能长久、能不能续航。战略可以跑赢一程，人才才能托起一个时代。

所以，与其说经营是做业绩，不如说经营是做传承。带好团队，育出接班人，才是企业家最硬核的责任。
