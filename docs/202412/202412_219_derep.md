# 小绿书业务复盘：内容、选品与带货策略
作者：龙哥

最近刷到一位赚钱圈友的复盘，挺有感触的，分享给你。

这位叫沐木的朋友，从9月才开始接触小绿书，利用业余时间同时运营了25个账号，到现在带货佣金累计做到了5.3万。这个成绩，对于兼职来说真的挺能打了。

他把自己做小绿书的经验整理成了一份很详细的复盘，重点讲了内容怎么做、选品怎么挑，以及一路上踩过的那些坑。如果你刚起步，或者正在摸索小绿书，这份总结应该能帮你少走不少弯路。

内容上，他大致梳理了这几个板块：先晒了下带货数据，然后做了阶段性复盘，接着是爆品分析、选品思路、素材框架、素材制作、批量化操作，最后还有一些带货的注意事项。基本上从思路到执行都覆盖到了。


评论区里也有不少人问细节，比如25个号是不是都是实名认证的，沐木也回答了——是的，不实名挂不了品。还有人好奇每天发多少条、素材怎么批量做，这些问题估计文档里也有涉及。

一句话总结：小绿书这事儿，有人已经跑通了，而且给出了很实在的方法论。剩下的，就看自己怎么落地了。
