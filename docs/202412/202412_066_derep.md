# 美国人的“电子钱包”申请攻略：免费实体卡、手机刷信用卡、开通零成本

在跨境圈摸爬滚打的朋友，对 Venmo 应该不陌生。老美日常消费、朋友间分摊开销，十有八九都用它，地位跟咱国内的微信支付差不多。更让人心动的是，这玩意儿开通不要年费、不设存款门槛，顺手还能送你一张美国实体借记卡，用 iPhone 碰一碰就能刷客户的信用卡。

## 为什么做跨境生意的人离不开它？

大家跨境收款时总有各种尴尬：做 FB 私聊成交，很多品类 Stripe 直接拒之门外，客户也没 PayPal 账号，钱就卡在那儿。另外像给美国当地人返现、刷单这类需求，Venmo 属于几乎人手一个的工具，找他们收款特别顺。

还有一个让卖家头疼的点——PayPal 的纠纷机制。一旦买家发起争议，不单要退款，还得赔上一笔处理费，账号权重也跟着遭殃。相比之下，Venmo 省心很多。

线下交易的话就更方便了：App 装好后，把手机变成刷卡终端，客户的卡轻轻一贴就能完成扣款。

## 往里面充钱怎么操作？

一种是让朋友直接转账给你，简单粗暴。另一种是自己充：点 Direct deposit 入口，通过生日、ITIN、地址这套验证。

![](img/df3df2fb7dce7e2f133669b6f0d10701.png "None")

完成后系统会给你一组 Account number 和 routing number，这就相当于你的虚拟储蓄账户。别人打钱给你，就能走空中云汇、万里汇、华美银行这些渠道转进来。Wise 也能用，不过它的风控动不动就冻结，不如华美这类实体银行稳。想开实体银行账户的，可以找我助理，帮你对接美国那边的代理。

## 商业版账号开通指南

前提条件：公司已经注册下来，并且拿到了 EIN 税号。详细流程可以看这篇：`https://articles.zsxq.com/id_exggkcb30j69.html`

操作入口藏在个人账号的通知按钮附近，看到 create 就点进去。

![](img/54a4614320b25e3ce626cc583d56c3d0.png "None")

类型那栏一般选第二项。

![](img/f7dd1a7ec9fbd071e5506d97f6dad2bd.png "None")

接着按实际业务情况填写店铺信息。

![](img/92df92e95ca8ab249c7cf49ca1380fd1.png "None")

![](img/2729ce77f7aa38c00b1d2fe4d1e3c4f1.png "None")

设置好对外展示的名称和资料。

![](img/b1bd4ec7c8eba962fc93f934dc6e4db9.png "None")

预览没问题，点 publish 发布。

![](img/5b59c5b7c983a2a51cdc7599a51d87a6.png "None")

这个审核速度也很快，基本秒开。默认都要求上传对应法人的 ITIN 信息。

![](img/5b59c5b7c983a2a51cdc7599a51d87a6.png "None")

![](img/9e4d24c19aeadbc6f3f0ab612cc63eb3.png "None")

审核通过后就能正式接单了。最香的是，商业版支持手机收款：把 iPhone 当 POS 机用，客户卡片靠近一下，付款就完成了。手续费是 2.29% 加每次 0.09 美元，跟同行比相当良心。

![](img/1983e7f2e23934ee26b316ec1fa53267.png "None")

干货和细节都在这里了，建议先收藏，下次需要操作直接翻出来照着走就行。国民弟弟出手，又帮你省下至少 1000 刀。
