# 入手 Cursor 的那几天，我因为系统版本和参数踩了个大坑

上周刚入了赚钱，后来报了个 Cursor 的航海训练营，满心想着赶紧上手开干。结果安装环节就直接卡住了，折腾到最后甚至一度冲动去下单新电脑，笑死。

其实问题说白了就两点：系统版本不匹配，以及安装参数填错。看似很小的细节，足以让你白忙活半天。作为一名刚上路的新手，我把自己踩过的坑完整梳理了一遍，整理成笔记发在飞书文档里，方便后来人避雷。

原文参考：[`www.yuque.com/for_lazy/zhoubao/dmsggszp3q9gb2h7`](https://www.yuque.com/for_lazy/zhoubao/dmsggszp3q9gb2h7)


踩坑归踩坑，搞明白之后安装效率提升不少。如果你也刚接触 Cursor，提前看看系统要求和参数配置，能省下不少冤枉钱和时间。
