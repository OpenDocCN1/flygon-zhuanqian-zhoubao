# 新手小白的第一块钱，今日头条历史类视频变现【复盘】

你或许刷到过这样的画面：整段影像都定格在某处，旁白一句接一句，没有转场和运镜，却能被成千上万次收听。更妙的是，这类看似“偷懒”的创作，正成为不少新人的首笔线上进账。

前阵子，我被一个“反常”现象吸引。先看一张当时的示意图片： ![](img/91d0e690ead1225e6233f7b1fa700d39.png) 有位运营者，粉丝量少得可怜，内容才更新不久，却冒出一条热度颇高的作品。这种“小号跑出黑马”意味着什么？说明这套玩法离新手很近，照做也有机会。 ![](img/619f0882ebacae0af3db40cf0965e104.png)

变现方面，我最初想走官方的创作者分成计划。但当时该计划刚升级，短视频板块要求账号拥有五万个关注才能参与。我转而查看资讯端，发现那里的门槛友好得多，可以直接开启。 ![](img/047ef2438fc6f2f537bef7493e126853.png) 这个机制就像自媒体平台的广告收益，按播放数据给创作者发补贴。按参考账号的方式把内容分发到资讯端，果然又发现一批同样高产的作品，有些热度更加夸张。 ![](img/fa401026ea6e6584203b9c076881ad56.png)

收入上，我同时打理两个号，某天两号合计拿到99块。 ![](img/b8d526690c02c2657284cae68bdf9ff9.png) 备用号曾一天入账71块，比主力号还争气。 ![](img/d41f71bb6f7ad4dddc9aab4db228f030.png) 我甚至怀疑是系统对Android设备更友好，而苹果设备被调整了权重。

先拆解一下这类内容。 ![](img/c75a95c7251b8bf4db8d256fc3664fd1.png) 制作成本极低。全长超过半小时的素材，画面自始至终几乎不变，变数是文字与旁白。寻找底图很简单，去网络社区翻一张有年代感的图，再找一张主讲者的肖像即可。音频则取自一档知名的历史讲座节目，再用剪辑工具把台词自动转成文字。虽然错字偶有出现，但完全没影响阅读体验。

整个操作流程也不繁琐。第一步是寻找参考对象，参考对象发什么，我就准备什么。爆款内容的规律可以复用，在规则允许的范围内，尽量做到高度复刻。 ![](img/06ac339aee98d04dd1f537bbffc3403b.png)

桌面端的具体做法： ![](img/ce27daf92fc0d116544ab2616c8a2186.png) 先用电脑内置的浏览工具打开搜索页面， ![](img/51b77c540b8980086bc99d15d661c5ca.png) 输入“讲坛”找到官方站点。 ![](img/ca78ff07b61d681927e9bf900361c49f.png) ![](img/8a5249820df104f55766848467ee7efd.png) 进入后搜索参考内容的名字， ![](img/7177b04f70927b0f77f58e16b51d04fa.png) 找一条超过半小时的记录。 ![](img/8d7008041ff0cd0380963781b8c551c1.png) 接着安装一个叫FetchV的下载插件，从播放页面抓取音轨。 ![](img/a83e4f0d01a3897ebb3389da7e1af136.png) ![](img/99474caef2bb83744843cfd9b050abdd.png) ![](img/de0314e27fb8aaf6ddff23ef6c499ab1.png) ![](img/e870ec69f38326d2a161117a4f7d17cd.png) ![](img/bed2b49bcdce8a4f04148cc7e2c78df1.png) 打开播放中的页面后，点开插件即可开始抓取。 ![](img/f29dc7d775e4f5f3d95064f61f9f5b89.png) ![](img/b1370d10feabae9666aff5e0798a7194.png) ![](img/0b956e12875bcc0b0094e255da718ca2.png) ![](img/3817950449c2640862819ca44c9d83c1.png) ![](img/c4fe59cea4f41d88b1397c3499d8d0e9.png) ![](img/58b1111ba897f827990b94d4925e3960.png) 只要保留声音即可，画面并不重要。底图可以去内容社区找， ![](img/6803687f037b408dcd7fa16f8060ac84.png) 保存时借助微信里的轻应用清理掉角标； ![](img/571adccdfe8f23fb6bb0cc8d43d59826.png) 另一张人物照网上到处都是。我剪出来的成品大概长这样： ![](img/c0f13ac072e39265f3bb1393df33f3e8.png) 后期使用剪映，在软件中放入影像和配图，再由它自动生成文字。完整字幕需要付费订阅，所以有人用了非正式版本。最后参考对象的封面样式，稍作调整就能上传。

移动端的流程与桌面端大同小异。Android用户可安装“狐猴”这款浏览工具，它支持插件。 ![](img/c58731b65c55ac214adb0929fc479f49.png) 打开后先搜索进入同一官方站点， ![](img/30f829de5068bb8548246d01af393661.png) 再找到目标内容。 ![](img/c0f18b914d3cf3aa88790490692beb00.png) 接着打开插件菜单， ![](img/4877643f4e0646d979be062fe56c08ed.png) ![](img/8d46157e495fcc5cc03d12839f95c1b5.png) ![](img/0c593e345277236692e40c9e4719ccd3.png) ![](img/1d4218df6b0c60b8d318b8962aae8071.png) 安装好FetchV后，回到页面点开内容， ![](img/2e853bb61c872a7f31810bfe1ce19d21.png) ![](img/db4919d0ba93dfc51f60559a17677289.png) 将数据存下来。 ![](img/f0a259f2006f44bbf4b139e3508193ff.png) 后续的配图和后期，与桌面端所用方式一致。至于苹果设备，我暂时还没有找到可安装同类插件的浏览工具，若有群友了解，欢迎指出来。

先看下当前的收益截图： ![](img/38ae309c4067682180761900adc6fe2d.png) 截至现在累计进账三千余元，平台扣除了一些税费。初次领取收益时我毫无经验，后来才弄清超过某个限额才须缴税，那时候没到限额就提了出来。

但让我停下的原因不是收益太少，而是这类工作本质是机械化的重复：不断剪辑、上传，缺少能让自身成长的养分。我也试过做微调，然而其底层逻辑与“搬运”差异不大，继续下去意义有限。我更想投入能产生长期价值的事情，比如写作。这份复盘，正是写作练习的一部分。

这段经历给我留下三点启发。

第一，留意反常之处。当一位只有零星关注的创作者突然做出超高热度的内容，那么“反常”背后常藏着淘金的切入点。

第二，善用参考。参考对象要挑离自己近的，比如刚起步不久就做出爆款的那个号。选定之后，便认真复刻其框架。

第三，先动手再完善。想得再周全，不落地也是零；只有真正上手，才能暴露出问题，再逐一解决。这好比一把刀——不亲自去切菜，很难判定其是否好用。钝了便磨一磨，磨完继续用。

动笔前我也曾犹豫：这点收入放在日课数万的人面前，实在不够看。但我依然写了，因为每次梳理都算一次自我提升。相比被嘲笑，我更在意自己有没有往前走。

入圈以后，我最大的变化是开始阅读和写作。过去痴迷短视频，现在更愿意泡在社群里看他人分享；以前静不下心读书，如今居然读完了好几本。这里的人都乐于交流各自的心得，也愿意耐心回答新人的问题。

如果你也想试试个人运气，不妨多留意那些“不正常”的细节。也许你的第一笔线上进账，就藏在某个被忽视的反常之中。
