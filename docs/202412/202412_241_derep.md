# 别去等春天，真正的巨头都是在寒冬里长出来的
作者：龙哥

我们总以为好公司诞生在顺风顺水的好时候，等政策红利来了、市场红了、资本热了再去入场。

但事实恰恰相反。

翻开真正经得起时间考验的公司史，你会发现一个惊人的共性：它们几乎都不是在风和日丽里起步的，而是在最混乱、最艰难、最让人想放弃的节点上诞生的。

经济下行、行业寒冬、资源稀缺、规则未明——正是这类时刻，才筛掉了投机者，留下了真正做事的人。挑战越大，竞争者的壁垒越高，熬过去的，才有机会定义下一个时代的游戏规则。

有人在评论区说得好：所有伟大的企业，都是冬天的孩子。

当别人都在等天气变暖时，他们已经在零下里扎根了。所以，别再祈祷好时机到来。历史反复告诉我们，逆境不是绊脚石，它往往是伟大公司的孵化器。
