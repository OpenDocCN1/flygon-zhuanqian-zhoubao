# 📕蓝海副业-英语演讲定制实操经验分享

刷到就是赚到！今天分享一下我最近在📕挖到的一个冷门副业——**英语演讲定制**，亲测是妥妥的蓝海赛道，性价比高到离谱。

这项目有多“蓝海”呢？赛道本身很小众，几乎没有多少人做，但对新手极度友好，基本零成本启动，只要肯花点心思，每个月多赚个四位数是很轻松的事。

我自己目前的操作方式非常简单：每周只抽出一两个小时，把提前做好的内容排期发出去（具体制作交给兼职搞定），然后靠📕店铺自动发货，就这样在完全不费精力的情况下，每个月都能稳定躺收四位数。

有意思的是，我还把这个项目推荐给了一位朋友。她之前完全没接触过这些，英语水平也只停留在高中程度，但最近两个月人家硬是靠这个赚了两万多块。当然啦，她在里面投入的时间比我多得多，所以说到底，这个项目丰俭由人——想多赚就多花时间，想轻松点就少做点，全看你自己。
