# 当增长放缓，创业者要练就的“三板斧”：守住、打出去、站得住

> 原文：[`www.yuque.com/for_lazy/zhoubao/uiy9k7mefumgbmxe`](https://www.yuque.com/for_lazy/zhoubao/uiy9k7mefumgbmxe)

## 创业黑马看到的图片，有感而发，做个拆解，大家一起共勉。

![](img/33b7962862f7bb7db291967334413ca9.png "None")

**  **

现在这个环境，每个创始人几乎都得自己扛起全能战士的角色。经济进入低速爬行阶段，能不能活下去，能不能活得好，拼的已经不是点子多不多，而是领导者本身够不够硬。

我把在这种周期里能扛住的领导力拆成三个关键词：守、攻、正。缺一个都可能翻车。

**第一，守：先把家守住，再谈翻盘。**

对早期公司来说，活下去是最高优先级。这意味着业务不能断、团队不能散。产品的靠谱程度、组织的运转效率，就是你的生存底线。

更关键的是钱。健康的现金流和能赚钱的能力，是公司立足的根基。没有这个，后面画再美的蓝图也站不住。创始人必须有过硬的财务嗅觉，让每一分钱都花在刀刃上，同时留出安全垫应对黑天鹅。

**第二，攻：别原地等死，要会开新口子。**

市场在变，优柔寡断就会被淘汰。领导者需要有产业敏感度，能及时抓住升级窗口。比如借助科技力量与优质资本资源联动，打开新的成长空间。

更需要的是破局思维。AI应用、出海扩张，都是现在很多人用来破局的抓手。国内存量见顶的互联网公司，跑到东南亚、非洲去找第二增长曲线，这就是典型的攻的策略。这样的动作需要长线视野，也需要敢下注的勇气。

**第三，正：合规是底线，沟通是放大器。**

当下做事，首先不能触线。合规红线是不可碰的，经营、融资、营销各环节都得在法里走。

除了守规，创始人个人“正”的能量也很重要。个人IP是否清晰，是否能跟团队、用户、市场有效共情，直接决定资源能不能聚拢。靠分享真实的创业心路、价值观，赢得信任，才能把品牌做成护城河。

总结下来，低增长周期里的领导力，是三件事的叠加：像守城将军一样稳住基本盘确保不死；像突围者一样敢于进攻寻找新赛道；像信得过的领路人一样合规经营、有效沟通。只有守得住、打得开、立得正，创业公司才能穿越周期，走得更远。
