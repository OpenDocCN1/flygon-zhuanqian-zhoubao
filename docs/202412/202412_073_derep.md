# ('清予分享视频号带货-AI 数字人航海经验与爆单策略', (2, 27))

最近刷到一位杭州小伙伴的实战分享，特别有启发，赶紧整理出来给大家参考。

这位朋友叫清予，11月10日才加入生财，12月就第一次参加了“视频号带货-AI数字人”航海。结果怎么样？5个视频号里4个都出了单，累计成交额破7000，到手收益3200多。更猛的是，其中一个号连着爆了两条20万+播放的视频，两天涨粉2700+。作为一个新手，这个成绩相当能打。

她这次分享的重点，一个是新人怎么提高爆单概率，另一个是大爆之后怎么复盘接住流量。

先说说怎么提高爆单机会。她强调账号初期搭建很重要，这是“天选号”的地基；其次要选对合适的数字人；然后要坚持发流量视频，让账号更“抗揍”；顺序上要先发流量视频再发带货视频；如果流量视频用了公共数字人，一定要做去重处理。

再说说带货视频爆了之后的心得。主号和副号都要重视，别厚此薄彼；剪辑视频之前先把商品挂上橱窗；第一次开播前必须做人脸识别认证，尤其是视频号实名信息不是自己的情况；人在外面也要随时盯流速；不用怕爆了之后粉丝数不够开播，只要符合条件可以考虑买粉；心态上要记住“爆款永远在下一条”；要抓住几个复制爆款的关键时间节点；另外提前加几个代播，给大爆留条后路。
