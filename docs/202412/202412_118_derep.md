# 真正好的设计，往往让你察觉不到它的存在

我最近读到小马宋写的一篇文章，聊的是他很多年前看过的《设计中的设计》。那本书的作者，正是无印良品的艺术总监、被誉为日本国宝级设计大师的原研哉。

小马宋说，原研哉这支设计流派，痴迷于一个“无”字。他们不认为设计是给事物堆砌装饰，反而觉得那是把物件内在的本质一点点揭示出来。所以在原研哉的作品里，你能看到一种近乎苛刻的简洁与干净，实用和美感被拿捏得恰到好处——就像什么都没做，又好像什么都做完了。

书里让他印象最深的，是一个伞桶的设计，出自另一位设计名家深泽直人之手。

一般人听到“伞桶”，脑子里第一反应大概都是那个立在门口的圆筒。但深泽直人的解法是：在玄关墙根大约十五厘米的地方，往水泥地面挖一条八毫米宽、五毫米深的小缝。放伞的人，手里握着伞，身体会下意识地用伞尖去试探地面，发现那条缝之后，伞自然就齐刷刷地靠到墙上了。沟槽起了放伞装置的作用，可使用者也许从头到尾都没意识到那是一个“伞桶”。一个藏在潜意识里的细节，就这样把收纳问题给解决了。

小马宋的感想是：原研哉所谓的好设计，不太爱玩花样，更偏向用最简单的方法对付真实需求。照这个标准，北京那个被大家叫做“大裤衩”的建筑，在原研哉眼里约等于一个“怪物”。复杂的结构让施工难度大成倍增加，材料消耗多到吓人，连周边的配楼也没逃过议论。这和“用简单办法解决实际问题”的思路，完全是两股道上跑的车。

文章里还提到，小马宋从前听过一位日本建筑师的讲座。那位建筑师谈住宅楼设计时，对建筑、植物和装饰的理解，几乎和原研哉是一个路子。他们共同追求的，是人、建筑、环境三者自然相处。当时庭院里有棵树，他们会去琢磨，十年后这棵树会长成什么样，未来的居民、小孩子会在树下怎么玩，树影一天天改变，又会给生活带来什么影响。

讲完别人家的设计，小马宋也不忘吐槽自己住的小区。小区里的法桐，明明树冠大、个子不高，却种得密密匝匝，时间久了必然拥挤不堪。园林设计的好坏，大概不在当下，而在多年后的居住体验。

评论区也挺有意思。有人留言“昨天看到小马宋老师了”，还有个读者提出了一个相当刁钻的角度：那个“桶”字，是不是从一开始就框定了想象的方向？要是命名成“伞沟”，恐怕很多人脑子里立刻就是一道沟槽了。语言设下的边界，有时候比我们以为的更隐蔽。

最好的设计，大概就是那样一道不起眼的沟槽：你没注意到它，但你的伞已经被它整齐安放。
