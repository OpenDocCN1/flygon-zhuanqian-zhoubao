# 项目底层逻辑

核心公式：爆款开头 + 洗稿文案 + 混剪素材

抖音本质是复制市场，没文笔也没关系，直接学就行。

1、开头用爆款开头 + 洗稿文案
爆款开头：别直接搬同行的水印视频，而是去片方提供的原素材里重新扒镜头再二剪。我们做的5-20分钟短剧，开头决定生死。没创作力就抄同行前5秒，相似度做到九成左右，那个爆点才不会丢。

洗稿文案：为了躲避检测，必须洗稿。原话照搬流量上来容易被判定同质化。

2、后面用混剪去重
开头稳住后，后面只要把故事剪顺，让人看懂剧情就行。榜单上常能看到两个视频前几秒一模一样，文案只改了点词，后面剪法却完全不同，这样就实现了去重。

↓爆款参考↓

前20秒画面基本一致，只滤镜、尺寸、镜像有区别
20秒到2分钟画面相似度会下降
2分钟后基本全是混剪，无解说，每个人剪辑走向不同

![](img/d4859d202b341630603c7d21bd86a648.png)

为了方便理解，我整理过一份脚本结构表，按这个做基本不会被判搬运。几百条作品发出来没问题，100个人抄一个爆款也不会一起被判，因为每个人的剪法、片段选择都不同。

有的只剪开头解说，有的全程解说，有的开头解说后面混剪。总之以开头解说+后续混剪为主。

#### 5.5、正式剪辑
1、配音与画面同步，配音说什么画面出现对应的场景
2、删废话、删气口间隔
3、故事线压缩更密集
4、多加转场

分三段处理
* 开头20秒：照爆款剪法走
* 前2分钟：解说为主，把爆点、人物关系、起因讲清，可参考对标但不能照抄
* 后半段：自由塑造剧情走向，主角好坏由你定，主线顺就行

一百个人剪出一百种结果，所以大胆剪不怕判搬运。注意剪碎，越碎同质化越低推流越好，但别把剧情剪乱。

半成品状态：主视频+配音+BGM+转场已调好
