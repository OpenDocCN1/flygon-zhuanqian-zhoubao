# 从0到高客单，我用📕虚拟资料跑通了变现闭环
作者：龙哥

大家好，我是龙哥，广州人。

去年4月我入了赚钱，后来一共参与了6次航海，其中📕航海是第二次。我从9月29日发了第一篇笔记开始摸索，到现在已经实操了5个账号、踩过2个赛道，累计变现已破8000，最近更是稳定体验到📕日入500的节奏。

这次航海能走通，离不开教练的带教、领队的陪伴，还有志愿者和赚钱团队的全程支持，以及一路同行的打卡搭子sukie、妮吖。非常感谢。
