# 从0到1：三个月冲上Temu家具类目第一，他做对了什么？

文/整理：生财圈友

> 来源：生财有术星球

今天想跟大家聊一个挺提气的真实案例——一位坐标厦门的圈友，**完全没碰过跨境电商，用了三个月时间，硬生生把一家店做到了Temu家具类目的畅销榜第一名。**

他叫糖饼，背景有点意思：之前在手机品牌做营销操盘，也干过电商平台的小二。2022年从大厂出来，跟朋友一起折腾创业，中间试过一两个项目，最后都因为不在能力圈内，无疾而终。今年4月底加入生财，期间帮朋友打理过国内PDD店铺（ROI太感人，基本属于摆烂状态）。**转折点发生在8月——他决定试水Temu全托管。**

结果呢？11月初，其中一家店直接登顶品类畅销榜Top1；另外两家店日订单量破千。**单店月利润率30%+，月入4万多，三个店加起来月入超过10万。**

说实话，作为一个跨境电商零基础、电商经验也几乎从零起步的新手，这过程中的难度可想而知。糖饼自己的原话是“只能硬着头皮去刷航海手册”——巧的是，生财正好有Temu的航海手册，这让他挺感慨。
