# ('新手入局 Temu 3 个月登顶家具畅销榜 Top1 经验分享', (2, 33))

零跨境经验，她居然用三个月把Temu店做到家具类目第一？

很多人一提跨境电商，就下意识觉得门槛高、坑多，没点经验不敢碰。但厦门卖家糖饼，偏偏走了一条不太一样的路。

她做过手机品牌的营销操盘手，也在电商平台当过小二。2022年离开大厂后，她和朋友折腾过一两个项目，但都离能力圈太远，最后没了下文。今年4月底，她加入生财有术；后来还接过朋友的国内PDD店铺，货盘是现成的，但ROI实在不够看，基本处于放养状态。

真正迎来转机的是8月。她决定去Temu全托管试试水。问题在于，她的跨境经验几乎一片空白，电商也算半路出家。怎么办？只能咬着牙把生财的Temu航海手册刷了一遍又一遍。

结果超出很多人预期：到11月初，其中一家店铺直接拿下家具类目畅销榜第一名；另外两家店的日订单量也纷纷冲破1000单。月度利润率做到了30%以上，单店每月能赚4万多，三个店加起来月收入突破10万。

她自己也说，过程并不轻松，加上一点运气才跑出来。但围观的人更关心方法。评论区有正在做Shein的小伙伴提到，全托管这类模式底层逻辑其实是相通的；自己之前老被核价太低困扰，看完她的分享又收获了不少新思路。还有人说，最扎心的心得是：前期要多上品，先把商品量铺起来，后面才有优化空间。糖饼的回应也很实在：每天睁开眼，就是继续上架新品。

从零到类目第一，没有太多玄学，就是先把量做足，再慢慢调优。
