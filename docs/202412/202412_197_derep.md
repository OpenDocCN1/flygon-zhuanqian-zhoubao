# 航海第二周船员“分化期”，如何高效辅助船员打卡

航海进入第二周，船员之间的差距开始拉大：有人越跑越顺，有人却慢慢掉了队。作为📕自媒体商单航线的志愿者，我带着28位船员走过了这趟三周航程，今天想聊聊第二周这个“分化期”，志愿者到底该怎么帮忙，才能让船员保持打卡节奏。

我们把整个航程分成了三个阶段。第一周是“了解期”，大家从陌生到上手，热情最高，但也开始有人陆续退出。打卡数量通常是先高后低，新鲜劲一过，真实状态就显露出来了。到了第二周，就是明显的“分化期”：一部分人摸清了门道，开始真正实操，慢慢有了正反馈；另一部分人则被各种问题卡住，逐渐萌生退意。第三周则进入“疲惫期”和“收获期”——正常打卡的船员已经差不多完成任务，不需要太费心；没完成的人还需要继续催促，但到了这个阶段，运营压力反而小，只要对危险船员多鼓励、多托底，帮他们走完最后一段就行。

我想强调一点：船员能完成打卡，功劳并不在志愿者身上。真正决定结果的是船员自己的努力和坚持，志愿者只是用一系列招数去推一把、扶一下，让好的结果更容易发生。打个比方，船员是游戏里的“主攻手”，志愿者是“辅助”——我们负责投递有用信息、盯着进度、及时补血、帮忙恢复状态。主攻重要，辅助也重要，少了谁都不行。
