# 三生相伴：让生命丰盈、生活有质、生意有成

真正的理想状态，并不是只在某一个领域做到极致，而是让人生的几个重要部分彼此成就。

王志纲老师曾提出“三生有幸”的理念：所谓“三生”，指的是生命、生活与生意。

生命，应当拥有足够的宽度与色彩，不被单一目标束缚；生活，不只是忙碌地度过每一天，更要讲究品质、体验与内心感受；而生意，则希望在前两者得到滋养的基础上，自然而然地获得成果。

当一个人既能感受生命的丰富，也能享受生活的质感，同时还能把事业经营得顺利，这便是生命、生活与生意之间的和谐统一。

生意不是人生的全部，成功也不该以牺牲生命和生活为代价。真正值得追求的，是三者互相支持、共同向好：活得精彩，过得舒服，事业也能顺势开花。

这或许才是“三生有幸”最动人的含义。
