# 新手📕 2 个月涨粉 2000+实战笔记
作者：龙哥

龙哥盟的各位朋友们，你们好！我是龙哥，跨境电商从业者，同时也是一名初级的盖洛普优势教练。今天想把自己最近两个月的📕成长经历写下来，如果你也正在起步阶段，或许能从中看到一些自己的影子。

第一次接触📕是在十月份，当时的想法很简单：为副业多一个展示窗口。坦白讲，新手期真的不太顺利，我甚至因为踩坑被禁言了整整一个月，那会还挺沮丧的。11月10号，我调整好状态，重新开始打理账号，不再追求数量，而是认认真真打磨每一篇内容。慢慢地，粉丝开始向我聚拢。截止到现在，账号已经有2000多位关注者，其中有1000多人是在加入赚钱后积累起来的。期间还接到了一单商业合作，最终的成交额是160元。数字虽然不算大，但对我来说，这已经算是一个小小的奇迹了，心里确实惊喜又满足。


作为一个从禁言中爬起来的新手，我特别能理解大家刚开始做📕时的迷茫。希望我的记录能给你一点信心。慢慢来，比较快，我们一起加油。
