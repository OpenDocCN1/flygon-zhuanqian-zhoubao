ComfyUI 实操：让模特自然融入任意场景，这套融合工作流太香了

各位好，我是嘟嘟，平时主要在 ComfyUI 这块深耕。之前聊过用 Redux 来做背景替换：保持人物不动，只换背景。但这套办法有几个短板——打光效果一般，而且背景是风格迁移出来的，没法精准固定。如果你已经有了一张特定的参考背景，那就用不上它了。

这次我换个思路：给一个场景，把整个人直接融进去，重新生成一张图。好处在于模特和场景之间的融合会特别自然，非常适合电商场景——比如你手头已经有一张白底模特图，想把它合成到一个符合需求的场景里。主干依然是 Fill+Redux，但关键是怎么拆解思路。

先看看实际效果：![ComfyUI_temp_znlhr_00004_.png](img/article-) ![ComfyUI_temp_rthio_00002_.png](img/article-)
左边是模特原图，中间是参考场景图（需要手动涂抹遮罩），右边是最终的迁移结果，人物被完整放进新场景。这样背景就完全可控，满足电商图的制作要求。

完整工作流见这里：![output(9).png](img/FmsK-tWa3DUrt1897wpnKiyRq-)
整个流程被分成 5 个模块，但真正核心的其实只有 2 个：

- 图片遮罩处理及拼接
- Fill+Redux 重绘迁移
- 脸部修复
- SD 放大
- 成品图拼接

使用流程大致是：
1. 导入模特的纯白底照片；
2. 导入指定的场景图，并手动涂出要替换的区域（这个区域相当于给模特留出来的融合位置）；
3. 默认关掉修脸和 SD 放大，先跑一轮，把效果没问题的图挑出来，再决定要不要开启。

下面按业务流程拆开聊。

**图片遮罩处理及拼接**（![output(10).png](img/article-)）
核心还是“拼图”思路：把原图和遮罩拼接成一张大图，再交给后面重绘。拼接后的图在重绘时一致性会明显提高。你只需要手工把参考图的遮罩涂好并传入，其余不用动。图片最长边我预设为 1440，也可以自行调整。

**Fill+Redux 重绘迁移**（![0152c712-8587-45ae-8d7a-52f1f65436c9.png](img/article-)）
这里调用 Fill+Redux 的“三重迁移”能力，生成后把右侧区域裁剪出来即可。节点参数固定好就行，不需要额外调。

**脸部修复**（![a38b49b3-1b00-4372-94da-372d26445469.png](img/article-)）
这个模块调用了 ReActor 的面部恢复功能，做轻度高清化，默认不开启。如果你想要换脸，也可以用 Pulid 替代。我的实测感受是：修复后脸部确实更清晰了，但和原图会有一点点差异。如果生成结果本身已经很清晰，这个模块完全可以不开，按需决定即可。

**高清 SD 放大**（![a7ae44d6-76ad-4639-b99e-9f7c2edd98a9.png](img/article-)）
放大方案选了 SD 放大。原图已经足够清晰的话就别开，需要放大时倍数自己调，默认是 1.5 倍。提示词可写可不写，写上可以让细节更精准。
