# 弱小和无知不是生存的障碍，傲慢才是。
作者：龙哥

标题：让你错过机会的，不是实力弱，也不是见识少，而是那份“看不上”

你有没有过这样的经历：一个机会明明摆在眼前，你甚至早就看到了它的苗头，却因为打心底里瞧不上，而任由它溜走。

有人说，在生存这场漫长的考试里，拿到烂牌不可怕，看不懂题目也不可怕，真正让你直接出局的，是那种“我不屑于做”的态度。实力弱，可以慢慢变强；懂得少，可以慢慢去学；可一旦傲慢起来，人就会本能地拒绝一切陌生的可能，把自己锁死在原有的认知里。

我见过一个很典型的案例。有位朋友很早就听说了比特币，但他当时心里认定：挖矿是旁门左道，炒币的人都是赌徒；一提炒股，就皱眉说那是不务正业；看别人做闲鱼，觉得不过是低买高卖的投机生意；遇上知识付费，更是断言这就是在收智商税。因为看不上，所以从没认真了解过；因为从不了解，所以一次次与风口擦肩而过。多年后他才恍然大悟，真正让他错过这些机会的，不是运气，而是自带的傲慢。

傲慢最迷惑人的地方，就在于它会穿成“清醒”的样子，让你以为自己的偏见是远见。它会说：“这东西不靠谱”“这些人就是想赚快钱”。可正是这种自以为是的判断，成为生长在我们脑中的天花板，挡住了所有可能通往新世界的路。

说到底，在生存这件事上，起点低不可怕，认知浅也不可怕，可怕的是心里那股“看不上”的傲慢。保持谦逊，承认自己的局限，愿意蹲下来多看一眼、多问一句，才是这个时代最基本的生存能力。

如果你也曾因为“看不上”而错过了什么，或许现在就是放下那点优越感的时候。
