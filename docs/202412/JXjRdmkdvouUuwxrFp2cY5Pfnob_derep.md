# 一、账号注册

注册流程很常规，简单过一下。

🛰️号：已有🛰️直接用。没有多余号的话可以去营业厅办一张实名卡注册，一个实名最多可注册15张卡，移动电信联通各5张也可以在网上营业厅办理，套餐选30-50G的流量卡即可，也可以直接用视频号流量卡。

注册环境：严格一机一卡一号

🛰️可以多开，但不建议，风险高。部分设备能多开也不封，具体看个人情况，关键是别机卡分离，无线网即可。

注册步骤：下载🛰️App -> 点击注册 -> 填手机号和昵称密码并同意协议 -> 注册完成 -> 完善头像昵称签名🛰️号，资料随意。

🛰️养号：注册后先和自己的小号聊几句。

每天互动一下，发个朋友圈关注腾讯新闻，偶尔刷一下，充几块钱腾讯基金和腾讯公益，钱包里留几块钱。

# 二、开创作者计划

想做分成就开通，不想做就纯涨粉。下面是开通流程，难度不大。

门槛要求：开通创作者分成计划需要满足，粉丝有效关注100人以上、内容符合规范、公开视频数量>=10条。满足后3-5天或当天就能收到开通提醒，按提示操作即可。

开通条件：官方要求10条原创、粉丝100+、内容规范。全部达标后3-5天内会收到开通收益的通知，进入创作者中心-创作者分成计划-申请加入。

![](img/b4ac266a01c730fe1debf041481b2c90.png)

具体操作：

第一步、先发10条真人出镜的情感语录视频，分2-3天发完，上午一条中午一条晚上一条。第一天不同时段发5条，第二天发5条也可以。

真人出镜用前置摄像头拍脸和上半身，文案放慢读出来。文案直接抄对标，用美颜相机提词器，免费试用7天，到期后关闭。当前最稳最快过的方案，符合内容规范标准。

![](img/91bbb86b7995b549b78f910bfb2b0916.png)

第二步、制作手绘视频发布涨粉，粉丝到100就达标。

第三步、10条真人发完后，用手绘视频把粉丝涨到100，满足规范后申请开通。

注意：计划通过后，真人视频可以继续保留，账号起来后再隐藏。后期如果提示视频不规范，可能还得补真人出镜，模式一样。

创作者计划按需求选择，是做收益还是做涨粉。

# 四、文案撰写

文案门槛很低，主要是抄对标和AI生成。

文案指标：多找对标作品，点赞1000+的优先，或搜索手绘、情感、人生感悟等关键词找爆款文案。也可以去其他平台找近期情感类爆款。手绘主题不止父母儿童，还有励志类，目前老人、父母类最容易爆。

# 五、视频制作方法

制作也不复杂，看完就能上手。

制作要点：
1、时长控制在7-10秒左右
2、音量开大，尽量拉满
3、视频中加上声明：视频无不良引导请理性观看和树立正确价值观，分两行写，不透明度10-15之间
4、字体在安全区内，不要超出画面
5、做好后可分发到视频号、抖音、快手、📕、今日头条

本次提供两种做法：

第一种、静态视频操作流程

背景素材：

去📕搜索关键词，比如素雅绿色背景，找到喜欢的图，点击右上角箭头复制链接，打开🛰️小程序皮皮去水印，粘贴链接去水印下载。

![](img/5cda0f2b478ff6bea49fe67b92b7deb3.png)

背景音乐：找对标同行作品，点击背景音乐参与，不想参与就把视频录下来，剪映里提取音频。

![](img/388da53aecb899ee76ac62c19692f23c.png)

AI生成图片：

可用智谱清言、豆包，应用商城下载即可。

智谱清言：打开后点画图，提示词前面加上主体，如亚洲人、中国人、中国老奶奶或中国现代女人，再加上动作如坐在凳子上怀里抱着孩子，脸上洋溢灿烂笑容，结尾加素描。想做黑白就写素描手绘黑白，想彩色就不加黑白。比例选1:1或4:3均可。

选1:1发送，咒语可加自然光、立体光、光线、远景、构图、超高清等，发出去看效果。不满意重生成，改素描手绘为彩色图片即可。选好后下载保存。

视频制作流程：

剪辑：打开剪映开始创作，导入背景图，点击高清添加，画中画新增一层，导入AI图片，高清添加，背景比例调成9:16，整体也调9:16。

抠图：把图片拖到背景上对齐，选中AI图滑动到抠像，自定义抠像，选中后勾选，抠完后往中间放。

输入文字：参考同行文案，文本新建文本，输入上方文字，拉到上方，编辑样式大小，选新青年样式调成黑色，不想要描边就关闭，居中放置。

![](img/cbab554f8b2142c574b74d1a06e30767.png)

![](img/1cefa2ffb6d0f4be16a7968bb0cac2f2.png)

添加音频：视频号录的音频，仅导入声音，裁剪多余部分，拉到开头，全部时长与音频对齐。再添加贴纸，如搜索树枝，选免费的，旋转后放到右上角，再复制一个放左边，镜像对齐。

第二种、动态视频操作流程

原理就是让图片动起来，用即梦AI即可，操作和豆包类似，也能直接生成AI图。点击左下角想象生成视频，点数每天送，够用。

输入框里点右边图片图标，上传要动的图片，点击勾选，左侧紫色箭头视频生成提示词位置，不必输入，直接点右边5积分消耗生成，完成后下载保存到本地。

# 六、视频发布

发布也很简单：

一天至少发4条，上午7-9点、中午11-13点、下午17-20点，间隔约2小时，不要太密集。

当天有视频大热门，等热度下降涨量放缓后再发下一条。

原创分类选情感，计划未开通前没有分类就直接发，开通后选择情感分类或直接发也可自动归类。

背景音乐选同行爆款，话题照抄同行，位置不填，点原创发布，不点原创无收益。

如果多条没爆就先放着，抄的是爆款，后续爆的概率更高。

差不多就这些了，按这个SOP操作就能跑通这个玩法，有兴趣直接实操，做出效果欢迎反馈交流。
