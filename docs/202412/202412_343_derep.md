核心玩法很简单：

用 copycoder 抓取目标网页的结构和样式，再交给 bolt 去理解、生成代码。你不需要会写代码，也不用研究复杂的提示词，只要把那个网站的 URL 丢过去，附上几句具体要求，比如“按这个风格做一个首页”“帮我生成一个定价页面”，AI 就能自动把事情办了。

评论区里也有不少人说这是新大陆。有人在准备 Cursor 航海项目，正愁不知道怎么仿写网站，结果发现直接把 URL 扔给 Cursor，让它边学边写就行。还有人问：首页生成之后，其他页面怎么联动？作者回复说，你只要告诉它“参考首页的 UI 和设计，帮我生成一个定价页”，AI 通常会自动关联；万一没关联上，再补一句“请让它们风格统一”就好。

整套流程下来，你会发现：复制一个网站，真的就只是动动嘴的事。
