# 不懂代码，也能用 Cursor 搞定 Excel 自动匹配工具

你是不是也遇到过这种场景：每天要填一堆表格，字段又多又细，翻来覆去填到怀疑人生，而且填了还不一定有结果？

我在无忧传媒做 MCN 商务，日常就是拿着项目去找合适的达人。按理说，推荐达人嘛，把名单发过去就行。可实际上，每次提报都要在 Excel 里手动整理一长串信息——达人昵称、主页链接、粉丝量级、星图八大人群、男女粉丝画像分布……一项都不能少，堪称“表格版查户口”。

问题在于，费了半天劲填完交上去，能不能选中完全看运气，人为干预不了。让媒介同事反复配合填这种高重复、低回报的表格，时间一长，大家难免懈怠。嘴上不说什么，但我也没法硬催别人第一时间响应。

于是我就琢磨：能不能做个自动匹配的工具，让 AI 来干这活儿？一来省时省力，二来再也不用欠人情、催进度。

说干就干，我完全零编程基础，直接用 Cursor 把工具搭了出来。整个过程不写复杂代码，全靠 AI 辅助，最终实现 Excel 自动化匹配，效率直接起飞。
