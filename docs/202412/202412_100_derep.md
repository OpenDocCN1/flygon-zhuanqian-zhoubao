# 用 Cursor 开启🛰️小程序开发之路：不会编程，也能做出第一个项目



## AI 工具 Cursor，让🛰️小程序开发变得更容易

作者：赤木  
日期：2024-12-26

最近看到龙哥大大发起的龙珠悬赏，刚好这段时间一直在体验 Cursor，于是决定把自己制作🛰️小程序的过程整理出来，分享给圈友们。

对于没有编程基础的人来说，Cursor 的门槛确实低了很多。你不一定要先掌握复杂的代码知识，只要能用日常语言把需求、遇到的问题以及想实现的效果讲清楚，AI 就可以协助你逐步完成一个属于自己的编程项目。

当然，AI 也不是每次都能一次性给出准确结果。有时它可能无法理解你的需求，或者生成的方案不符合预期。这种时候不用急着放弃，可以重新梳理思路，换一种方式描述，再继续追问。问题多问几次、角度换一换，往往就能逐渐得到满意的结果。

更重要的是，和 AI 沟通时不需要担心它不耐烦，反复修改和持续提问都可以保持稳定的反馈。
