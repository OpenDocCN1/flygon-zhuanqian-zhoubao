# 跟准联合创始人聊创业，先把这些问题摊开谈



## 22赞 · 创业寻找联合创始人时，可以一起探讨的问题清单

作者：龙哥的收藏夹
发布：2024-12-18

创业不是一个人的独角戏，合适的联合创始人能把想法变成现实，也可能因为认知不合变成最大的消耗。在决定绑在一起之前，最省事的做法不是聊愿景多宏大，而是把可能产生分歧的点提前摆到桌面上。

找联合创始人，本质是在找一个能长期共担风险、共建规则的合伙人。所以在投入时间精力之前，不妨围绕几个核心维度进行一次坦诚的对话。
