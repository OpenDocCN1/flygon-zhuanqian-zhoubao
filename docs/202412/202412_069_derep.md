# 从零开始的 AI 动物故事类视频 Youtube shorts 实践

你知道吗？一个刚入圈一个月的运营小白，居然靠AI动物故事视频在YouTube Shorts上拿到了自然流量。这不是运气，而是一套从零跑通的实战路径。

故事的主角是Kennan恺南，本职是程序员，11月刚加入龙哥盟，正好赶上12月航海。在信息轰炸后，他选择了和自己专业沾边的AI赛道，目标很简单：用AI生成视频，运营自己的YouTube频道，顺带学习视频推广和引流的真实玩法。

虽然没有任何运营基础，但他照着@竹子和@土豆君两位大佬的教程，一步步把AI生成视频的流程跑通，并成功上传到了YouTube Shorts。视频如今已经开始产生流量，他也在复盘中说：希望后期能通过量变带来质变，目前第一次尝试还有不少短板，欢迎各位多提意见。

他把自己完整的实践记录整理在了飞书文档里，想实操的朋友可以直接点开参考：https://vebcgzyylx.feishu.cn/docx/A7lSd5SxwoDX20xdqBccgk8LnMh?reRdXZ=1

评论区也相当热闹，有人感叹“牛蛙牛蛙”，有朋友称赞他“优秀的学习实践方法”，还有人问怎么联系。更有一位叫九里香的圈友贡献了工具秘诀：用浏览器扩展（比如“视频下载”“猫抓”）就能直接抓取当前网页的视频，用这些工具下的“即梦”视频没有水印，图片方面也有类似办法。

你看，零基础、非专业、AI新手，都不是问题。重要的是先做出第一条视频，再在数量中等待质变。这个案例，也许就是你的下一个起点。
