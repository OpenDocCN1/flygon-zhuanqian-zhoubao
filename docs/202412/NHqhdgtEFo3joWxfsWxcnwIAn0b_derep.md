# 一、开号

📕开号要求很低，有手机和网络即可：

1、下载📕App
2、手机号登录
3、填写验证码并同意条款
4、完成登录

几个关键细节：

1、一机一号一IP：建议用独立手机加流量卡注册，保证是新号。需要流量卡渠道的可以找我。
2、生日选最近一个月内，生日当天会发流量券，有效期半个月，发笔记时能用。
3、年龄选二十多岁，兴趣随意填。
4、昵称和简介先不动，等养号完成、发了3篇笔记后再改。刚注册就改容易被风控，也别上来就给同行点赞，容易被拉黑。
5、建议全新开号，或把旧号注销后重开。老号标签已固化、权重流失，换赛道很难起势。空白号从零做更顺。

# 二、养号建议

养号核心就是提升活跃。别纠结七天螺旋养多久，按下面节奏来，第一批笔记的播放通常能稳定在百以上。

思路：搜“离婚协议模板”这类词，看下拉长尾，然后去刷同类笔记。

![](img/38b53ca0760e3214684dd8091ab16737.png)

![](img/caf8d137764b8c79b540c139813b3025.png)

我们现用的养号节奏：

第一天：用流量注册，当天不操作
第二天：开始刷垂直内容，每天30分钟，分时段刷
第三天到第五天：保持养号，适度点赞收藏评论
第五天：改包装，人设打好，上午刷笔记，下午发首篇测流，继续互动

如果首篇干货当天破百播放，账号基本健康，可以常更。

有时候我们也不刻意养号，直接注册就发，效果也差不多。但建议边养边发，保持活跃，否则平台会判定低活跃。

资料设置参考对标，头像可用卡通、真人或风景，昵称随意，简介抄同行思路。养号完成后即可准备开店和做内容。

# 三、操作流程

流程很简单，小白照做即可：

第一步、格式转换
找到合适的合同模板，用WPS打开导出为PDF。左上角导出，单独建文件夹存放，后续给客户可同时发Word和PDF。

![](img/dfaa35ad7396296299eb8cf6049ecce8.png)

![](img/d1fd8b0d23451d22d0c6505701a30971.png)

第二步、PDF转图
用PDF转图片工具批量处理。可把所有doc放一个文件夹一次性导入，输出PNG或JPEG，清晰度调8左右即可。

![](img/609f099dee20fe12de01cbec40c969d0.png)

输出方式设多张图，指定页默认，修改输出路径建图片文件夹，点击开始转换。

![](img/0d96b29228a41132aedd8ce1b969cc2b.png)

第三步、图文笔记制作
用美图秀秀批处理。打开软件点批处理，添加文件夹，把转换好的图全部加载。

![](img/6839de987b1dd412747ee011fe5a4da1.png)

![](img/78ba4a5b4892fbfa29dd312152074c2f.png)

添加文字水印：输入“黄岛主合同模板”，字体调灰色，不透明度降到40以下，角度斜一点，再叠加一层同水印错开。

![](img/7169d3768782077d21d4aa702c215db6.png)

点击平铺，把字体缩小到14或12，让水印分布更稀疏，不需要描边。

![](img/bafc160d4c83f3e43b12dd323541cbf3.png)

![](img/662a380c3f08b90e41f3d266d63231ec.png)

![](img/81bcdbd1e1ebb74ef9ac6f05962a032d.png)

确定后，再加一个主标题文字，比如“抵押合同模板”，选好字体颜色放在画面中央，描边阴影可加可不加，按需选择，字体大小适中。

![](img/9678ab579a56ac655c0205f9a41f8664.png)

导出时修改保存路径。

![](img/0bdf256c8a1e7f5ddf2a1085480c1de6.png)

![](img/983606113115b00b4ae75fbe62cc2698.png)

如果不想后面页也带标题，可以把标题图单独保存，第一张不覆盖，后面覆盖掉。水印太明显就把不透明度降到20多。
