# Z 世代的新赛道：一单形象改造收费 200 元
作者：龙哥

龙哥在 2024 年底分享过一件挺鲜活的事：家中一位 00 后小辈，主动提出帮他做一次形象改造，报价 200 元。费用说高不高、说低不低，但看完成效果，确实有那种为节日量身定制的味道——整个人都透着一股圣诞主题的喜庆感。

![](img/cf3502a1083ebb9ee4d7eaafedecba18.png "None")

帖子发出来之后，反响相当热烈。有人夸这套新形象很有创意，也有人从中嗅到了商机，甚至已经有朋友开始盘算：要是我自己做，按 5 元一单的价接活，也能攒下不少零花钱。

这种思路，某种程度上也是年轻人对“服务价值”的新定义：只要审美在线，把“换装”做成收费项目，也能成为一门小生意。
