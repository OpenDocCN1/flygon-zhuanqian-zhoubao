# 一、为什么我会选择得物

先做个自我介绍。我是北樱，接触自媒体四年多，曾在不同平台尝试过图文、社群运营和知识付费。现在做得物账号，粉丝数量算不上多，但累计阅读已经超过17万，也接到过不少知名品牌的产品合作，还在得物的航海冲浪计划中做过答疑学姐。

对比过各种平台后，得物给我最大的感受是两点：

**第一，规则对新号非常宽松。** 完全不需要粉丝基础，新注册的号也能参与带货和视频奖励。再往下走一步，想要开通品牌合作，也不需要等到100粉，只要注册后14天内发布的笔记中有12篇阅读超过500次，权限自动就会打开。

**第二，内容要求不高。** 不需要你懂什么专业理论，也不用会写长篇评测，只要从真实买家的角度出发，讲述自己使用某款产品的体验就行了。这一点和很多平台满屏的专业测评完全不同。

# 二、在得物上，钱是从哪些渠道来的

理解得物赚钱方式之前，需要先明白它的内容展示机制。得物的每个商品页面都有一个“开箱精选”区域，达人发布的真实使用感受、开箱视频，只要挂上商品链接，就会展现在这里。用户看到的是消费者视角的反馈，而非官方宣传，因此更容易做出购买决策。

拿一支粉底液来举例，官方页面只有产品介绍，但开箱区里能看到不同肤质的上脸效果、持久度、暗沉情况这些关键信息。

![](img/3b11472a26f71ca6c4ac7c7e69a1f314.png)

这样一来，普通人的分享就有了商业价值。目前主要的变现路径有四条。

## 路径一：品牌推广任务

这是做得物的大部分人最核心的收入来源。普通投稿的单条价格在20到100元之间，品牌点名的邀约任务，起步价则在100元以上。利用碎片时间就能接单，账号到达LV2后，每月接单数量没有限制，勤快一点，收入自然水涨船高。需要留意的是，这个模式从零开始到稳定出单，大约需要37天左右的沉淀期。等账号权重上来了，报价和单量都会同步上涨，达到月入过万不是空谈。

内容方面，图文任务需要6到8张图和300字以内的文案，视频任务只要30到60秒即可。开通推广权限的硬性门槛就是前面提到的：14天内12篇笔记阅读量达到500。得物的引力合作功能，相当于其他平台常见的“蒲公英”模式，但得物这个门槛明显友好很多，不需要粉丝数做前提。

![](img/297cddbc167a967ce507dd47df4fbcef.png)

品牌推广任务又分为两种形式：

**自由报名模式**：创作者在任务广场自己选任务报名，商家审核通过后进入合作。账号升级到LV2后，每月不限接单次数，月度产出量保持在15到20单之间是有机会的。如果你拍图出片效果好、数据稳定，收到的产品可以自己留着，也可以挂二手平台出掉。等到LV3，还可以解锁达人专享的“百元任务”专区，每天19:00更新，需要通过蹲点报名。账号数据出色的达人拥有优先权，即使名额满了也能报上。

![](img/84dc00a7798278370a72b3c88ae518c8.png)

![](img/c6d4d47d6a619d063d5affd26cc8a171.png)

**品牌指名模式**：这是圈内公认性价比最高的方式。以前需要500粉才能开通，规则改版后，只要账号达到LV3就会自动开启。品牌方在商家端后台看到你的公开数据，主动发起合作邀约，相当于别人拿着合作来找你，不用你去抢。报价由达人自己填，就算只有100粉丝，最低也可以定到100元一篇。

![](img/0fd5db70a202ebeef2d48ce7568c06a6.png)

![](img/80e810aac54811c5bd740810aef92771.png)

按每个月接10次指名邀约来算，现金保底就有1000元，再算上产品实物收益，月收入3000以上是很轻松的结果。如果再往上走，等级更高、流量更好、照片更出片，这个数字会继续膨胀。

## 路径二：短视频播放奖励

平台会根据视频的播放量、完播率、互动率等综合数据，给予现金激励，大致在每千次播放10元上下。这条路径特别适合擅长视频剪辑、二创的人，漫剪、影视剧盘点、娱乐八卦、美食教程都能做。

它的优点在于结算很快，发布后第二天就能看到收益，而且支持直接提现，不需要等很久。运营也很省心，不用太复杂的技巧，只要按时更新就行。建议一天放3到5条，一个月靠纯播放量也能赚到三千多。

![](img/6eb815b0ffdd0acececce52d7e178639.png)

![](img/ab5e890e18a9795662f580269e382a3a.png)

## 路径三：商品带货分成

## 7月：摸索阶段，收入316元

我费了一些功夫才把粉丝做到100，顺利开通了品牌合作，当时账号等级是Lv.0，每天只有5次报名机会，但每次报名都没有回音。那段时间很挫败，后来才慢慢意识到，其实是自己的账号没有达到品牌方的筛选标准。

总结下来，新手瓶颈基本卡在三个地方。

**一个是账号的垂直度。** 不要求知识多深，但所有内容必须围绕同一个方向做。比如我把账号定位在护肤美妆，那发的内容就和美妆强相关，引来的粉丝也基本都是对这个方向感兴趣的人，品牌方会觉得账号画像更精准。旧版创作者中心还能直接看到垂直度数值，新版虽然不显示了，但品牌方仍然非常看重这一点。我特意问过合作过的美妆PR，得到的答复是：“垂直度是优先考虑项。”

![](img/bf52a3b3c5d2c9e0ea57b545d374ef75.png)

![](img/a5a89d3533867535d3b0e6cef6026204.png)

**另一个是照片画质。** 会拍照，是得物账号的基本功。前期可以准备一些小道具，例如背景纸、摆件、托盘、反光板，再配一个无影灯；没有也无妨，普通台灯同样能补光。构图不熟也不用焦虑，在得物搜同品类产品的高赞笔记，照着模仿，就能进步很快。因为照片能直观反映创作者的风格和水平，决定了品牌方对你的第一印象。

**再一个是账号流量。** 公域平台的底层逻辑就是流量为王。品牌方投放，本质上是买曝光，所以流量是硬指标。最直接的办法是看最近半个月的动态平均阅读：

- 平均不到100，基本接不到合作；
- 100到300，可以尝试竞争压力小的任务；
- 300以上，多数投稿都能审核通过；
- 到了500以上，会有不少品牌主动找上门；
- 如果稳定在1000以上，那不用再投稿，等着收合作就够了。

想让流量涨起来，可以多留意创作中心里的近期活动，拿到流量券和无门槛优惠券，就能助推内容。入口路径是“我-创作中心-创作灵感”。

![](img/3bdf5d86ba165c1967443860e78f67d6.png)

最近平台还推了一个针对新人的内测机制，帮没有接过首单的账号完成破冰。我一个小号也收到了内测资格。

![](img/e0c5f3033a23117f91bbf9c63cf3dd82.png)

越来越喜欢得物的另一个原因，是它的公开透明：达人数据和商家数据互相可见，合作记录有据可查，结算也由平台代管，只需要缴纳少量手续费（100元以下的收入不收手续费，100元以上部分抽取5%）。这钱花得值，至少创作者不需要操心催款和扯皮，把精力全部放在内容上就好。

# 四、得物目前最值得做的六大内容赛道

赛道选得好，起步就容易得多。这里重点讨论六个目前得物上热门的方向，大家可以针对自己的兴趣和特长做选择。

女生对美妆、护肤、首饰更熟悉，可以从这些品类切入；男生对数码、电子产品更有心得，适合做科技类内容；穿搭和家居是通用领域，谁都能做。

## 1. 美妆护肤

得物的用户群体以年轻人为主，对美妆护肤的热情居高不下，天然适合内容创作。尤其是唇形条件不错的女生，做美妆几乎是“降维打击”——只靠口红试色就能撑起整个账号，完全不用思考选题，随意拍就是内容。

![](img/412b2348b2efac9a5c00a68a19159fb3.png)

![](img/c7d6ec9baf6f0688e1b3f9207a51e7fb.png)
