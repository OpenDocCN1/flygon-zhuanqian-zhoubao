# 航海复盘：Cursor 使用技巧与项目卡点解析

2024年12月23日，一场围绕Cursor的航海之旅迎来了一份特别的复盘。作者Range原本只想把这篇文字留给自己，为这段学习体验写下句点。没想到的是，他此前陆续发布的阶段日志，得到了教练蘑菇和领队海伦的认可，也正因如此，他收到了复盘分享的邀约。
