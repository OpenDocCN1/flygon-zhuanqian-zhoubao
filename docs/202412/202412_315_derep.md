# 离开苹果的那一年，乔布斯才真正开始自由创作
作者：龙哥

很多人只记得乔布斯是苹果的缔造者，却很少有人认真回味他被自己一手打造的公司开除的那段经历。

在2005年斯坦福大学的毕业典礼上，乔布斯坦诚地回忆起这段往事。他说，当时自己完全没意识到，被苹果解雇竟然会成为他整个人生转折中最宝贵的一页。

“我还没反应过来，那次的离开其实是我能得到的最好礼物。”他当时说道，“此前那种被巨大成功压住的沉重感，突然被一种从零开始的不确定和轻盈所取代。”

正是这种被迫放空的状态，让他彻底打开了创造力的大门。

“那段时光，是我至今为止最有创造力的阶段。”

这句话的背后，不是鸡汤式的励志，而是现实的残酷带来的反转：失去控制权，让人重新获得创造的自由。
