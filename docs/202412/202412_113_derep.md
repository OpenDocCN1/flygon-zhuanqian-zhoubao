# 不要痴迷于战略推演的精彩，要能忍受执行时漫长的枯燥
作者：龙哥

听别人讲战略、讲案例，往往是全程高能，越听越上头。脑洞够大、逻辑闭环，仿佛一条通往爆发的捷径就铺在眼前。

可你有没有想过：为什么故事听了那么多，真正“复制成功”的人却寥寥无几？

问题不在“知道”，而在“做到”。

案例是被剪过的电影，只留下高光镜头。战略推演是那块漂亮的冰山，水面下的执行才是体积庞大的本体。一个狙击手扣下扳机那一下子确实帅，但在此之前，他在掩体里趴了两天两夜，蚊子叮、天气闷、腰酸腿麻，这份煎熬才是工作的绝大多数。

前几天我聊过爱玛电动车的事。他们一周能产出三万条短视频，曝光量上亿，靠的是上万个经销商一起动手。思路复杂吗？一点都不复杂：每人每周拍几条。但问题来了，中国有几千个经销商的品牌比比皆是，为什么偏偏没几个做出这种效果？

真正难的就是“让人动起来”。

我当时问爱玛的CMO莫总：你们到底怎么说服经销商拍视频的？他回答得很朴素——没什么高招，就是自己先做出模板，给出示范，然后一个城市一个城市跑，一个经销商一个经销商谈。这样磨下去，一年可能都跑不完。

你能想象那个画面吗？同一套话术，面对不同的人，反复讲、反复讲。这种枯燥程度，足以让大多数人在第二周就想放弃。

其实周鸿祎早年间踩过同样的坑。他创业早期给代理商培训，讲同样的话讲到吐，后来看宗庆后的自传，发现宗庆后当年跑遍全国哇哈哈经销商，也是一遍又一遍重复同一套说辞。那一刻他释然了：这样级别的企业家都能坚持做“同一件事的重复”，自己凭什么嫌烦？

说到底，大部分人的问题不是能力不够，而是“不甘心只做一件事”。总觉得反复打磨一个动作太无聊，于是换方向、换赛道、换打法——结果是，井挖了几十个，水一口没喝到。

想突破这种心理，不妨多出去“混”一下。见见真正成事的人，读读他们踩坑的过程。你会发现，所有被人记住的作品背后，都是漫长而单调的重复。别人能坚持，不是因为他比你强多少，而是他心里有底——知道“重复”本身就是通往结果的必经之路。

所以，别太迷恋在沙盘上推演千军万马的快感，学会享受在真实世界里把一个动作做到一万遍的钝感，这才是真功夫。
