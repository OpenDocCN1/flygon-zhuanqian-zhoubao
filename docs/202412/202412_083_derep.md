# Cursor，我的盐不见了
作者：龙哥

写代码和下厨房，说到底是一回事：一道菜没了盐，你尝一口就皱眉；一段程序冒了bug，你的心情就像热锅上的蚂蚁。最近我就“翻车”了——明明之前还好好的，突然之间“盐”不见了，整锅菜都炒不下去。

这篇想跟你们分享的，是我让Cursor帮忙“找盐”的折腾经历，外加盐实在找不到时，怎么让这顿饭不至于彻底报废。如果你也遇到过让AI修bug修到“鬼打墙”，或许我的经验能帮你少走两步。

先说“盐失踪案”。我把问题丢给Cursor，它像一位信心爆棚的大厨，指挥我加大料、小火慢炖，锅里咕嘟半天，味道还是不对。换“谷哥”这位老朋友来救场，拿着同样的线索翻遍全网，倒真让我摸到点门路。

后面又来了个“酱油失踪案”。调料总凑不齐，我整个人已经不是在写码，而是在抢救一锅黑暗料理。Cursor照旧努力，谷哥照旧耐心，就这么一轮一轮折腾。我突然意识到：我是不是太依赖某一种调料了？于是试着问自己——不用moviepy家的“盐”，这道菜真的做不成吗？换了个思路，反而柳暗花明。

最让我哭笑不得的，是折腾一整晚之后发现：盐其实一直就在老地方，只是我眼睛长在头顶，硬是没看见。不过这一趟也值了，起码学会了一件事：盐暂时找不到的时候，先想办法把饭做熟，别让一锅好菜全糟蹋了。

编程和做饭说到底都是个手艺活，顺序可以调，心态别崩。最后想感谢一路陪我从“没盐”到“有盐”的志愿者雍康，还有领队蓝弈，你们的鼓励就是我的“锅气”。祝大家都能在代码的案板前，少一点手忙脚乱，多一分从容翻锅。
