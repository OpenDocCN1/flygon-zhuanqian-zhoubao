# 停止向世界描述你的监狱

你是不是也习惯了把自己的处境讲成一间牢房？跟朋友讲，跟家人讲，跟每一个愿意听的人讲。讲得越生动，心里就越憋屈，好像那面墙真的越来越厚。

可是，你有没有想过，最该停下的人，其实是你自己。你每天在脑海里复习那些“没办法”“离不开”“熬不出头”的台词，等于亲手给幻觉刷漆。

真正要紧的，从来不是继续诉说，也不是寻找同情。而是立刻起身，迈出那一步——哪怕只是一小步。

你可能会犹豫：外面是哪里？万一走错呢？但请你低头看看：那间困住你的“牢房”，有锁吗？有门吗？

没有锁，也没有门。它甚至不是一间真实的房间，只是你在心里搭的布景。所有围栏，都是你对自己的假设；所有铁窗，都是你对未来的恐惧。

所以，别再当那个叙述者了。站起来，走出去。因为监狱根本没有，你早已在门外。
