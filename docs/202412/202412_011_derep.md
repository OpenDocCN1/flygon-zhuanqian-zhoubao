# 用这 65 个问题，做一个完美的 2024 年终复盘吧！
作者：龙哥

不知不觉，2024年已经走到尾声。站在这个时间节点上，年终复盘绝对是一件值得认真对待的事。毕竟我们都听过一句话：选对方向，往往比一味埋头努力更重要。对此我也深有体会——如果不去回看这一年，我们很难说清楚时间究竟花在了哪里，哪些决定做对了，哪些又踩了坑。

年终复盘的意义，不只是为了给过去打分，更是为了给来年校准方向。只有认真梳理过这一年的选择、行动与结果，我们才能在2025年做出更加清醒、理性的决策，而不是被焦虑推着走，凭感觉做选择。

那复盘该从哪里入手呢？赚钱8期老圈友、也是“晚9点半睡觉”的明白，分享了一套自己一直在用的逻辑：人生最重要的三件事，就是健康、事业、亲密关系。这三件事如果都经营好了，人生的整体状态大概率会越来越好。与此同时，赚钱也从来不是孤立的事，它既关乎产品、流量、转化、成交、笔记等具体动作，也与健康、关系、情绪、精力这些底层要素紧密相连。

关于复盘方法，他还引用了《高效能人士的7个习惯》里的观点：想要达成任何目标，都要经历两个阶段——先在脑海中创造，再在现实中创造。如果没有前者，我们的行动很容易陷入犹豫、拖延、信心不足，最终走向失败。换句话说，年终复盘本质上就是在完成“脑海中的创造”，把明年的方向先在脑海里想清楚、画出来。

基于这套逻辑，明白精心整理了65个问题。别小看这些问题，据说他每一部分都要花上一个多小时去思考和输出，全部写完超过了一万字。这件事确实有点挑战，但如果你愿意沉下心来，一个个问题深入回答，相信今年的复盘会让你收获完全不同以往的感受。


新的一年就要来了，愿我们都能带着更清晰的规划，更从容地出发。
