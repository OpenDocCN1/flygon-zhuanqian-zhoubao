# 长沙专升本集训机构线索获客实操案例分享
作者：龙哥

最近在赚钱看到一篇很有价值的案例分享：长沙一家专升本集训机构，找团队帮忙做获客。虽然机构入场的时间点已经晚得相当离谱，导致后端的成交转化数据不太理想，但有趣的是，最前端的“线索获取”却跑出了肉眼可见的成效。

分享这个案例的是苏打（Soda）。她本人之前在上一家公司担任商务负责人，男朋友则是运营负责人，两人一起把一款产品做到了年 GMV 13 亿。可惜那块业务的风口窗口期特别短，公司也没有提前转型，之后他们陆续试了不少新项目，最后都陆续砍掉，整个人被折腾得身心俱疲。今年 8 月，两人双双辞职，从零开始创办了自己的自媒体工作室，主攻📕培训、陪跑和代运营。短短四个月，已经积累了不少可以拿出来讲的经验。

苏打提到，她 10 月底才加入赚钱，之前一直是只看不写的状态，经验贴和风向标都没发过。这次下定决心把案例整理出来，很大程度上也是因为在社区里受到了启发。整个分享主要分两大块：一是实操前做的市场调研，二是实操满一个月之后做的全盘复盘。
