# 受邀大航海分享有感：短视频赚钱不限于视频号或抖音，赚钱的能力来自认知

平台会变，认知才是你穿越周期的底牌

前几天受瓜斯邀请，在大航海的AI短视频带货训练营里做了一次直播分享。原打算分两节课讲的内容，硬是压到了一节课，不少地方只能点到为止。今天干脆写篇短文，把没展开的部分补上，想到哪说到哪，大家多担待。

先说一句最想强调的话：短视频带货这件事，平台永远只是管道，真正的核心竞争力是你的认知。直播间里不少朋友把注意力全放在视频号上，提的问题也基本都围绕单一平台。我能理解，但真替大家着急——如果目标是靠副业赚钱，最关键的不是死磕某个平台，而是先把0到1的底子打好。

怎么打底子？首先，别跳步骤，别道听途说，更别把全部希望押在一棵树上。以短视频带货为例，通用逻辑始终是：账号越多，流量入口越多；矩阵越大，商业机会越大。所以入局的第一步，就是用普通人的方法，尽可能多地在不同平台注册账号。注意，是不同平台，不是单个平台反复注册。视频号能用的一套打法，换到抖音、快手、小红书、油管、TK，甚至小绿书，底层逻辑都是通的。

UGC时代的内容分发，本质是兴趣分发。平台要的是好内容，你掌握了流量密码，就能打穿一条街。但流量密码不是靠守着一个平台等出来的，而是靠穿越一个个周期练出来的。

我算是一个穿越过好几轮周期的人。从知乎带货、小红书带货，到视频号带货、抖音带货，再到现在以抖音为主，每一步都是被环境推着走，也是主动选择走。2024年7月底到8月初，视频号突然开始严查，大批账号被封。我果断停掉带货动作，专心养号两个星期。两周之后，很多社群已经放弃，我的团队反而还在爆单。那段时间我们同时重新启动抖音，一个人单周也能做出10万GMV。

现在视频号的自然流量大不如前，不少团队既舍不得走，又不愿意尝试新路径，只能硬着头皮去学投流，结果把赚来的钱凭本事亏回去。我的选择很简单：直接转战抖音，绕开平台的周期波动。为什么能这么果断？因为类似的起伏我经历过太多次，平台有周期，人有惯性，但惯性可以被认知打碎。

昨天直播时有圈友问抖音实名的事：上个月还能绑定21个，这个月只剩6个名额了。有人追问，怎么做到6个？其实这属于最基础的第一课内容，不是进阶课。方法不复杂：去认证蓝V，每个蓝V都设置成“运营”身份，最多可以设置5个，再加上自己的实名，正好6个。

这也是我一直强调的：想入局，就老老实实从零开始，别总想着当插班生。我分享的内容是一个完整体系——从准备电话卡、注册账号、开通橱窗，到研究平台规则、想办法注册更多账号；从剪辑基础、口播技巧、AI数字人应用，到认识行业真相、防止被PUA和割韭菜、学会分辨爆款；再到爆款文案的结构拆解、提升爆率、违规处理办法。少了任何一环，都不完整。

但说实话，这些技能本身跟赚钱没有决定性的关系。它们只是工具，真正决定收入的，是你选择做的项目，以及你对项目的理解深度。

这也是我愿意做免费分享的两个原因之一。另一个原因，是我认同龙哥盟的价值观。听过第一节认知课的朋友，应该会有共鸣：第一，利他就是互利；第二，判断一个人能不能教你赚钱，就看他自己是不是正在做他教的事。

我现在的身份有两个：一是短视频创业者，在做全平台变现项目；二是短视频领域的创业博主，确实在做知识付费。但我不主动卖课，我更喜欢说，我是用免费的东西去“感化”粉丝成为会员。所以我有两件事是完全免费的：免费分享干货，免费带学徒。别人线下带学徒，收费九千多甚至一万多，我免费；别人做个人IP孵化高额收费，我免费；别人两三天一夜的操盘手课收费五千多，我还是免费。

为什么敢这么做？因为我自己靠项目赚钱，项目本身能养得起我。那些自己不做项目的人，当然不敢免费，也理解不了这种玩法。而带人做项目，我有三个原则：必须是我自己在做的，必须是我长期做得还不错的，必须是可以复制给普通人的。凡是复制不了的事，比如投流，我根本不教。

写了这么多，其实就一句话：赚钱这件事，最怕定式思维。短视频带货，别把自己锁死在某个平台——视频号不好做就转抖音，抖音不好做就转快手。平台是流动的，认知才是你的护城河。

认知从哪里来？从一次次试错中来。比如昨天有朋友问，快手发了视频没有播放，正常吗？我的回答是：坚持更新，等平台给你流量。因为快手一直在打压营销号，部分新号会被故意冷落一段时间，平台要确认你是不是真正做内容的博主。这跟去年抖音拼命跳核验是一个逻辑——平台怕你是营销号，宁可先误伤再说。

说到跳核验，很多人一遇到就直接放弃，真的太可惜。你把核验流程老老实实走完，说不定就会发现自己多了一个非实名的抖音号。这明明是一件好事。我在这个领域能讲到点子上，不是因为我多聪明，只是我把每件小事都抠透了，就算是踩坑，也要搞清楚坑在哪里。

多试一步，多做一次尝试，说不定就是柳暗花明。共勉。
