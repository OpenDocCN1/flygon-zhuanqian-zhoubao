# AI经典影视原创剧玩法
作者：龙哥

最近AI圈又有一个让人直呼“脑洞大开”的玩法浮出水面——用AI还原经典影视剧，甚至跳出原著重新演绎故事。

想亲手做一个《红楼梦》贾宝玉与林黛玉的60秒AI短片？想让他们在你设定的平行时空中重新相遇？这套操作路径，比想象中简单。

一共分四步走：

第一步：注册端脑云，直接在线跑模型，无需本地显卡。
链接放在这里：https://cephalon.cloud/#/share/register-landing?id=LnTSY0

第二步：拿到lora模型与comfyui工作流，用现成的方案快速搭建出图/视频生成流程。
百度网盘自取：
链接: https://pan.baidu.com/s/11h4N2bQ65GGU4FopTIco_Q?pwd=8888 提取码: 8888

第三步：打开创意灵感AI（豆包），用来生成剧本创意、画面描述和分镜想法。
直达入口：https://www.doubao.com/thread/w0593ed87aacaa656

第四步：把下面的提示词按顺序扔给AI，让灵感一步步落地——

1. 创意提示词：
“我想做一个60s的AIGC小短片，主题是关于贾宝玉和林黛玉之间的爱恨故事，古代场景，跳出原著，请你帮我想一点情节和画面。”

2. 人物对话生成补充：
“请继续为每个镜头再补充一些人物对话”

3. 绘画提示词生成指令：
“继续根据每个镜头的情节部分，转换成一段SDXL提示词”

三句话，就能把“故事创意→台词脚本→绘画提示词”全链路打通，剩下的交给AI去折腾就好。
