# 小某书电商入局第一步：盯紧“挑什么”和“怎么试”
作者：龙哥

做小某书电商一年半，我陆续碰过日用百货、美妆护理、化妆工具、功能养生、运动装备等赛道。今天想对准备从0起步的新朋友说几句实在话。

很多人以为入局难在写笔记、投流量，其实真正卡人的是两个关口：商品挑选与效果验证。只要把这两点打通，后面的一切动作都会变得顺理成章。

我把这一年半走通的选品逻辑、测品流程和踩坑记录都整理成了一份飞书文档，需要的朋友可以通过私信获取，我看到都会回。
