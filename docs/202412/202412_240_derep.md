# 为什么有些人越做越强，有些人一直原地打转？答案藏在元认知里

很多人会把差距归结为资源、运气、人脉、学历，但越往上走会发现，这些外在条件都在变，真正决定上限的，是你对自己思考方式的掌控力。

李笑来曾点破这一点：一个人的强弱，几乎是元认知的外化表现。看待问题、拆解问题、复盘问题的方式不一样，行为的长期结果自然截然不同。他甚至提出一个更极端的判断——一个人最后能创造多少财富，本质上取决于它的元认知水平高低，技术、渠道、资金这些，都只是配合作用。

这句话被很多人反复引用，也被很多人验证。

评论区里也有不少共鸣的声音。有人提到张一鸣的说法：认知排在最前面，因为所有资源都可以被搭建起来。有人在看《财富自由之路》，书里同样把元认知当成核心线索。还有人被他另一句提醒打动：万事都是可以提前布局的，觉醒的时机越早，复利就越大。

也正应了那句老话：事上磨，心上悟。把经历当成磨刀石，把反思当成打磨过程的人，元认知才会越练越锋利。

所以与其焦虑今天缺什么，不如先升级你如何思考缺的东西。
