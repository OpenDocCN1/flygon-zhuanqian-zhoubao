# 为什么越来越多人选择“出海做站”？其实一套公式就能估出Adsense月收入

前两天翻到一位朋友AI工具站的Adsense后台数据，只看一眼就被惊到了：同样是广告曝光，来自不同国家的用户，价值竟然能差出好几倍。![](img/41d13c13a978e11a394913b628404c4b.png)

先把千次展示收入从高到低列出来看看：瑞士是妥妥的第一档，能到7.34美元；美国4.34美元也不低；法国、加拿大同样在4美元以上。再往下，英国、澳大利亚、德国基本在2到3美元之间。![](img/c14a10f79b2335386e5a3c0b25b537f1.png)

这说明什么？浏览量高不一定赚钱多，你的访客来自哪里，往往更决定收入上限。国内很多站点的ECPM甚至不足1美元，而欧美发达国家常见3-6美元。与其守着低单价市场硬熬，不如直接面向全世界做产品，去赚美元、欧元、瑞郎。这就是“出海”最直白的理由。

那如果看到一个网站，想快速估算它靠Adsense一个月能赚多少钱，有没有捷径？有。先搞懂四个词：UV（独立访客）、PV（页面浏览量）、广告曝光（广告展示次数）、ECPM（千次展示收入）。一般来说，一个访客进站会看不止一个页面，一个页面也能放多个广告位，谷歌官方建议最多放3个。

为了好算，先记住一个“基准量”：假定有1000个UV/天，每个UV只看1个PV，每个PV只出1次广告，ECPM刚好是1美元，那么一天赚1美元，一个月就是30美元。

接下来估值就简单了：
月收入≈30 ×（每日UV÷1000）× ECPM × 平均每UV的PV数 × 平均每PV的广告展示数。

举个例子：假如一个查询工具站每天有1万UV，用户大多在欧美，ECPM按4美元算；查询类工具用户往往忍不住查很多次，每个UV带来3个PV；每次查询刷新还能顺带触发新广告，每个PV平均出3次展示。那么月收入就是：

30×10×4×3×3=10800美元，差不多人民币7.8万。

理论说到这儿，找个真实网站来验证：calculator-online.net。先看similarweb的数据。![](img/03f9854c6a453215b81ff30c025ec408.png)![](img/2af9a6bd527cc845f152993be5ce2450.png)

这里要提醒一句：similarweb的“访问量”和UV不是一回事。同一个用户，两次访问如果相隔超过30分钟，就会被多算一次。比如一个人连续在8:00、8:25、8:50、9:30、9:40来了五次，只会被记为三次访问。假设平时平均每个人一天访问三次，那么实际UV要用访问量除以3，按(180/30)/3算，大约就是2万。![](img/8d0294cc9b311f3e8560ce8686df3243.png)

但calculator-online不太一样，它的流量基本来自搜索，用户搜进来用完就走，很少短时间反复访问，所以可以按一个人一天只来一次算：月访问量180万，除以30天，日均UV约6万，也就是60个“千”。

再看similarweb上的其他指标：平均每个UV带来2.36个PV。打开网站首页，首屏就有3个广告位；点进内页，虽然也有3个广告位，但有的不在首屏，不会全都露出。综合感受一下，一个PV大概能产生2次广告展示。![](img/4cd463c043f9c4d9e2223c057df1edde.png)

流量来源方面，这个站的访客主要来自美国、巴西、印尼，我按经验拉一个大数，平均ECPM大概在2.5美元左右。![](img/348f858ac418a2ba6ae94bb1914a01fe.png)

把数代进公式：30×60×2.5×2.36×2≈21240美元。当然，这是估值，不等于账面上的精确数字；实际有可能高一些，比如两三万美元也并非不可能。

有意思的是，这个域名2013年才注册，赛道里早就有不少前辈了，但它依然能做出成绩。所以别说什么“没机会了”——尤其AI出现之后，把已经被验证成功的在线工具加上AI能力，重新做一遍，就是摆在眼前的新窗口。

评论区有朋友总结得特别到位：同样的努力，赚外币确实比赚人民币香。![](img/1c37d505930596d12a88ab23e11aa07a.png)
