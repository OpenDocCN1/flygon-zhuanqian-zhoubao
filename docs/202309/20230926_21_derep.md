# Stable Diffusion 模型整理与 ControlNet 模型下载指南
作者：龙哥

模型越攒越多，管理就成了大问题。其实只要掌握几个小技巧，就能让 Stable Diffusion 的模型目录井井有条。

## 一、模型管理小技巧

**1. 文件夹用中文命名**  
在 models 模型文件夹里，你完全可以按自己的习惯建中文子文件夹。这样做的好处很直接：查看和调用都会方便很多。![](img/4fb0cd9b7dae1694736262ef07187a8b.png) 想看分类模型时，只需在界面里勾选“显示文件夹”，所有归类一目了然；![](img/81082614a7f5befff9bb368b353f3786.png) 切换大模型时，也可以凭这些中文文件夹的名字快速锁定目标。![](img/90a282512098e7be4b54d1934077d28a.png)

**2. 给模型配同名的预览图**  
如果你准备一张与模型文件同名的图片，放进对应目录，界面中就会自动调用这张图作为缩略图。视觉化管理模型，找起来更直观。![](img/7c89eca516c7273a6d66b4c591c69c53.png)

## 二、LoRA 模型：两处位置，一个路径

LoRA 模型通常有两个存放位置：  
- 原生 LoRA 放在：安装目录\models\Lora  
- 插件 LoRA 放在：安装目录\extensions\sd-webui-additional-networks\models\lora  

问题是同一个模型往往要复制两份，硬盘空间就会被白白占掉不少。![](img/4960c3942b6bc811a58c51acad3e2302.png)

解决办法也很简单：进入“设置”里的 Additional Networks，把路径改成原生 LoRA 路径。这样插件和原生就共用同一个模型库，磁盘空间立刻省下一大块。![](img/d1bd2bbc568a6a609b65edce6cad23db.png)

## 三、ControlNet 模型：下载与放置技巧

**技巧 1：不用放在深层目录**  
很多教程会让用户把 ControlNet 模型放到“安装目录\extensions\sd-webui-controlnet\models”下，这个路径很长，找起来很麻烦。其实只要放到“安装目录\models\ControlNet”目录中，ControlNet 就能自动识别。![](img/2d01926a545fa5b4cce0189b095dde30.png)

**技巧 2：SDXL 模型用起来**  
现在 ControlNet 对 SDXL 的支持已经相当成熟。你需要把 Stable Diffusion WebUI 升级到 1.6，ControlNet 升级到 1.1.410，然后下载专为 SDXL 设计的 ControlNet 模型，放入上面提到的目录即可。

下载地址：https://huggingface.co/lllyasviel/sd_control_collection/tree/main  
这些是 ControlNet 专用模型，其中 3 个用于 SD1.5，包含 IP-Adapter 和 Recolor 模型。![](img/cebdffc81649c2a7c6b28152d3a04789.png) 剩下的 41 个都支持 SDXL 大模型，截图里并没有全部展示出来。![](img/3b38de55f66e684d9ea8284b21cd5c91.png)

腾讯的 T2I-Adapter 模型也可以在这里获取：https://huggingface.co/TencentARC/T2I-Adapter/tree/main/  
同样分两类：支持 SD1.5 的有 18 个，支持 SDXL 的有 3 个。![](img/83d8e7005fa93a112a6d8887b0ef8a91.png)

## 小结

除了 ControlNet 原有的 14 个基础模型，现在又多了 44 个支持 SDXL、21 个支持 SD1.5 的模型可选。新模型已经大量到位，赶快去下载体验吧。![](img/1c37d505930596d12a88ab23e11aa07a.png)
