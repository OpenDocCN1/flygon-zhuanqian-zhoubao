# 中秋国庆海报文案没思路？我把 ChatGPT 调教成了节日文案神器
作者：龙哥

中秋、国庆两个大节点马上就要到了，各位品牌人是不是又开始对着空白的文档发呆？

每逢节日，总逃不过这几道灵魂拷问：
- 自己的品牌该怎么自然地蹭上节日热度？
- 一句海报文案，怎么写出节日氛围，又让人过目不忘？
- 怎么跟设计师讲清楚，画面才能跟文案的气质严丝合缝？

更要命的是，一年几十个节日，年复一年还要变着花样来，光靠灵感硬熬真的容易秃头。

我也被这事折磨过，所以干脆换了个玩法：用 ChatGPT 专门训练了一个“节日借势海报助手”。它不光能替我把应景文案写得漂亮，还会顺手给出画面构思和设计方向，直接减少了我跟设计师之间的沟通成本。

实测感受：效果我能打到 80 分，一个下午就把一整年的节日海报文案全部安排明白了，老板再也挑不出“没创意”的毛病。
