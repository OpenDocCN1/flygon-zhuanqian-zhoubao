# 那些年差点握到手的天价璞玉
作者：龙哥

在资本圈里，谈起“最让人拍大腿的错过”，米哈游几乎是绕不开的名字。

而这份遗憾清单上，有一个人叫陈悦天，现任火凤资本的创始人。

他是资深二次元老炮，眼光很早。这块后来发光发热的米哈游，在还没被打磨成大众熟知的IP王国时，他就已经看上了。那时候的米哈游更像一块未雕琢的原石，潜力是有的，但光芒还藏在里面。

问题在于，当时陈悦天正待在创新工场。机会摆在眼前，却因种种原因连续两次没能抓住。两次的擦肩，让这段往事成了他职业生涯里挥之不去的遗憾。

如果要给投资界的遗憾排个名次，陈悦天的这两次错过，绝对能稳稳跻身前列。
