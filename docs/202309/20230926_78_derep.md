# 李国飞：禅与投资，这次我有了全新的理解

作者：龙哥的收藏夹
发布日期：2023-09-20
原文链接：[`www.yuque.com/for_lazy/thfiu8/cd7xh4gltg4h8ytb`](https://www.yuque.com/for_lazy/thfiu8/cd7xh4gltg4h8ytb)

读完这篇分享，你大概就能理解为什么《乔布斯、禅与投资》会给人一种对传统禅学认知被重塑的感觉。

李国飞在文中从更深的角度切入，聊的不是玄之又玄的概念，而是禅在日常工作和生活里的落地路径。尤其是在投资这件事上，如何把禅的精髓借来用，用来校准心态、梳理思路。

他用一句话把禅的本质点透了：

禅，不单是修心的功夫，更是一种活法，也是一套看待问题的思维框架。
