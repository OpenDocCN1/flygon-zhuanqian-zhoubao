李拜日 : 这些参数一部分是 Claude 自带的，一部分是可以自己定制的。Claude 本身就支持自定义。简单说，你想表达什么概念，就直接用“/ + 一个词”来定义就行。

比如你想给故事安一个场景，直接写 “/location 天安门” 就行。

我猜很多技术同学日常写东西也是查着有道云笔记直接粘贴的。参数完全可以自己造。

李拜日 : 我第一步先问 Claude 它有多少参数，它列出来一大堆。然后我再问这些参数是怎么生成的，它说可以自定义。

我试了下自己瞎编的词也完全能用，比如为了指定创作依据，我自创了 “/based_on_part”，组合一下就能用，自由度很高。
