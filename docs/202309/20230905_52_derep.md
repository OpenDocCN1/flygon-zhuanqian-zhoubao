# 经过闲鱼二手书赚钱航海-续航-再续航利润 4w+
作者：龙哥

哈喽，我是龙哥，坐标济南。白天在区农业农村委员会办公室上班，业余时间折腾电商，目前经营着淘宝、闲鱼、拼多多几个平台，其中闲鱼二手书账号已经有6个，还在计划扩编。从赚钱的第一次闲鱼二手书航海开始，我一期没落，每次结束都做深度复盘。算下来，靠着这个项目已经赚了4万多，现在准备继续加码。

应大家要求，今天把我的实战心得完整整理出来，全程无保留，干货浓度很高，不管你是刚入坑还是已经做了很久，应该都能用得上。

## 一、运营上，这几个细节最提业绩

库存是命脉。一旦缺货导致商品下架，权重和流量都会掉。我每天都会去闲管家后台看一眼：登录后点“商品”→“所有商品”，然后按库存从低到高排序。只要是0库存或低库存，立刻补货。现在正好是开学季，书的走量明显变大，每天都要安排一次检查，库存少就及时补。

优化商品时别手滑。上架还没满一个月的，或者月内出过单的，尽量不要动；真正该下架的是那种上架一个多月仍零销量的“僵尸链接”。

注意偏远地区运费。新疆、西藏、内蒙古、青海这些地方，孔夫子网通常不包邮，所以咱们闲鱼上要额外加收运费。

每单利润务必守住25%这条线。比如卖10块，至少要有2.5元利润；卖15块，利润要上3.75元。如果达不到，马上用闲助手提价。

差评别慌，但一定要在评论区回复处理方案。不是给那个给差评的人看，而是给后来的潜在买家看，让他们知道你负责、有售后，反而能加分。

每天把闲鱼币花出去。有销量的商品就开闲鱼币推广，别攒着，这能提升账号活跃度。另外每天早上每个账号花2块钱买“超级擦亮”，在我的-超级擦亮里抢就行。拿3个店铺来说，大号2元能推30个产品，新店刚开始只能推3个，养一段时间能到10个，所以一天6块钱差不多能推36到50个产品；如果前一天数据漂亮，第二天还会额外送推广次数，能多买好几个2元。曝光和活跃双重提升。

主图选择有讲究：优先实拍无码；俯拍胜于斜拍；有手拿书图的选手拿；近景优于远景；亮图优于暗图。

所有商品别忘了开5%的闲鱼币抵扣，能白嫖一波额外流量。

另外，官方曾公布过闲鱼图书卖家的常见违规，大家引以为戒：一是内容违禁，比如涉及政治、领导人、乔治·奥威尔、废都、索罗斯、查理九世、赵薇等敏感对象的书，千万别发。二是低价盗版、影印版，以及2023、2024最新版教材教辅，尽量不要上架，风险很大。

## 二、售后处理，我把原则定成“少亏当赚”

遇到盗版书，二话不说让快递上门取件，我们包邮退，同时去孔夫子申请退款，通常还能拿8元盗版补贴。

如果顾客坚决要退，书又不是盗版，先试着谈赔付3-5元，多半能搞定。要是对方油盐不进还想投诉，看金额操作：售价6-10元的，直接退款认栽；超过10元的，安排快递员上门取件，成本也就5-7元。但一定提前说清楚：不要私自邮寄，私自寄回的运费一律不报。

总之一句话：顺着客户来。为了店铺长远发展，赔一点小钱换好评、避免差评，太值了。二手书是长期项目，售后做漂亮，复购和权重才会稳稳往上走。

## 三、想放大的话，可以像我这样组团队

我现在按项目组跑，2个员工倒班：白班8点到16点一人，晚班16点到23点一人。薪资是每人1600底薪+6个店铺总业绩3%的提成，提成能调动积极性，员工干活更有劲。

白班工作清单：
- 群里同步6个账号当天的优化书数量和售后待处理数
- 回复上班时段消息，处理售后
- 每个账号优化10本书，有空多优化，把一个月没销量的书淘汰掉
- 盯闲管家库存，缺了赶紧补
- 买待发货的书
- 早上做一键擦亮+2元超级擦亮

晚班工作清单：
- 回复闲鱼消息
- 监督并协助售后
- 晚上用闲鱼币推广商品，开5%抵扣
- 同样每个账号优化10本书

我要求员工每天在群里按固定格式汇报，比如“某图书馆今日优化X本，闲管家待处理售后X个”。这样谁在干活、干了多少，一目了然。

## 四、出版物经营许可证，其实不难办

很多人想加账号，但卡在办证。我分享下我0成本一周拿到2张证的经验。不同地方流程略有差异，但大部分地区都适用。

第一，找个能用的经营地址——可以向开公司的朋友借，或跟房产中介批量合作。
第二，办公地必须配齐消防栓、逃生应急灯、烟感器和禁止吸烟标志。
第三，直接打给当地区县行政审批服务局，找到办理出版物经营许可证的窗口，问清楚材料清单。
资料备齐后送到窗口，一般一周下证。

以上就是我这次的全部心得。闲鱼二手书绝对值得长期做，正在参加航海的朋友，一定要珍惜实战机会，遇到问题多问教练。祝大家天天爆单，数钱数到手抽筋！
