# 闲鱼卖货完整保姆级实操流程
作者：龙哥

闲鱼卖货保姆级实操：从0到团队导师，她把全流程讲透了

我是龙哥，一个20岁的宝妈。自从接触闲鱼无货源卖货，我的副业之路才算真正稳定下来。在这之前，我吃过亏、交过智商税，也稀里糊涂试过十几个项目。回头再看，能让我一直做下去的，果然还是闲鱼。

那时候我连标题是啥都不知道，第一单卖了个全身镜，赚了23块，高兴得不行，马上又上了好几款镜子。后来开始试着卖几百元的产品，低价和高价同时发，没想到两种都能出单。接着又上了一些利润更高的单品，居然持续开单，信心一下子就有了。我用5天时间填满了50个商品位，又用家人的账号注册店铺，一共开了3个闲鱼号。现在做起来轻松很多，说到底就是坚持和积累。给你们看看我的两个店铺：![](img/2a83b67d8b3dc7f8051bb528d7425249.png)

很多人问：闲鱼不是二手市场吗？全新品挂上去能卖吗？先看图——这些是我们团队伙伴的晒单：![](img/7d58c676b5109dc1f69c1209f0b78dfc.png)![](img/37d42c9727e1e3fdfd45a96b85d251de.png)

事实是，闲鱼完全可以做高利润产品。我们团队的高客单价产品，利润率基本在20%～30%，少数能突破50%。去年有位伙伴成交过一笔80万+的大单，利润率虽然只有10%，但直接证明了闲鱼能做高客单价。闲鱼卖货基本是两个极端：低价产品单量多但利润薄，是典型的跑量模式；高利润产品单量少但利润可观，一单能顶十几个甚至几十个低价单。我们也测过9.9元的挂钩、收纳箱、调料盒，销量确实不错，一天接近200单，每单才赚5块，从早忙到晚也就挣个千把块，太累人。几轮测试后，这种玩法直接被淘汰了。总结一句：别做低价产品，容易出单只是错觉，利润低不说，还累人。

后来我们潜心折腾高利润领域，反复测试后反馈很好，还专门建了高级群，团队定期选品，新人进群可以直接跟。一般3～7天出单，有少数学员靠团队选品，单店收益能到一万甚至三万。不废话了，下面把闲鱼赚钱的完整流程掰开揉碎讲清楚。

01 闲鱼凭啥能做？

①门槛低：一部手机就能操作，一件代发不囤货，不用发朋友圈，不用付费推广，靠自然搜索流量；②免保证金：不用像淘宝、拼多多那样交保证金，淘宝或支付宝账号直接登录就能开店；③流量公平：平台给的都是免费流量，不用花钱买；④流量巨大：闲鱼在二手市场是流量第一，放在全国电商平台也能排到第六，月活超过4800万，仅次天猫，注册用户已超3.5亿，数据还在涨。疫情影响下大家对二手需求持续增加，到2022年依然有流量红利，而且可能会延续很久。![](img/6f08079f83d0be9c13e1f8a2cb45b95a.png)

02 开店要准备什么？

一部智能手机；一个能正常用的淘宝号或支付宝号；一个能正常用的拼多多号；一个呆萌价APP（应用市场搜“呆萌价”，邀请码：21EL9V）。呆萌价是个返利工具，你买东西或卖东西，通过它在拼多多或淘宝下单，都会有佣金。具体怎么用，下载后里面有个“商学院”，有完整教程。

03 闲鱼怎么赚钱？

说白了就是卖产品赚差价。我们在拼多多或淘宝找货源，挂到闲鱼加价卖，出单后通过呆萌价下单，填客户的收货地址，赚差价和佣金。举个例子：乒乓球桌，多多拿货价437元，闲鱼卖760元，差价是323元；佣金还能拿32元，总利润就是355元。![](img/ae8f4bb7f6d06759fe651a0ef353758a.png)

那客户为什么不直接去拼多多买？就像习惯在京东购物的人，不一定去淘宝一样，每个平台都有自己固定的消费群体，我们的任务不是赚所有人的钱，服务好一部分人就够了。

04 新手最容易踩的坑

1. 违禁品千万别碰：虚拟课程、医疗类、食品类、成人用品、军工类、高仿大牌等等，统统别碰。有人看见别人卖虚拟产品没事，但记住：不是所有坏人都能被抓住，你非要学，可能下一个被抓的就是你。违禁类目参考图：![](img/6015f787b1754d00599499d9862c04a3.png)

2. 注意串号限流：一个闲鱼号对应一个手机、一个网络，尽量用自己的流量，别连陌生WiFi。不同闲鱼号不要在同一个WiFi下登录，也别在同一台手机上反复切换账号，不然曝光会低到怀疑人生。已经有串号问题的小伙伴可以找我聊，有解决办法。

3. 别开鱼小铺：很多团队都在吹鱼小铺，但我觉得它不适合新手。它的优势是能发500个商品、支持多库存、宝贝分组、专题设置、粉丝价和粉丝管理；可开通后流量会降低，而且只能做垂直类目，百货类目的曝光和浏览会明显下降，所以新手慎开。

4. 别重复铺货：新手卖出一单后容易上头，恨不得50个位置全上同一个产品。我之前遇到一个人，40个宝贝里有30多个都是电脑椅，结果店铺不出单还限流。![](img/210ff03d20eed57437688fe8022e6238.png) 这道理放在哪个平台都一样：就算你发一条视频爆了，也不可能连续发几十条同款。就算想多发爆款，也要做好差异化。

5. 别反复降价：上架几天没出单，就觉得自己卖贵了，然后一降再降，连降四五次，这个产品就废了。记住，上架后不要频繁改一口价；如果真是写错价格或者非改不可，最多改一次。![](img/d9893f035df0a24e2df5c0e533b5c052.png) 也别去编辑页面提高一口价，和降价一样伤曝光。![](img/fbb049e2f18064fa7e61f30b6928cedb.png)

6. 警惕常见骗局：任何让你扫码的都是骗子；任何说支付宝没钱让你加🛰️的大概率是骗子；任何发广告让你点赞或做其他操作的，都是骗子；任何说要采集你店铺去拼多多卖货的，也是骗子。还有人说付不了款，让你点链接，甚至让你交保证金，千万别信。闲鱼保证金只有500元，而且自愿交，一般不用交。遇到类似下面这种扫码图，千万管住手，否则可能封号甚至资金受损！![](img/35d92aedbf2c9cdc5c6769c9423d71de.png)

05 卖货7要素

①选品：不要做低价产品。免费找货源的方法，就是打开拼多多看分类：![](img/0eaad5bf0cef15712979772a90c814da.png)。怎么判断能不能做？第一条，大牌不做，利润太低；第二条，去闲鱼搜对应关键词，看同行销量，零销量的不做；第三条，销量特别好的可以做差异化，处于中档销量的可以直接入局；第四条，别被价格迷惑，你买东西会只看最便宜的吗？价格从来不是决定因素。另外，付费选品可以看生意参谋、飞瓜数据、电霸等工具，当然我这边也有选品服务，可以免费送你一份。

②标题：标题决定曝光。标准标题是60个字符、30个汉字，闲鱼没那么严格。写法上，抄同行标题就行，参考闲鱼、多多、淘宝同行的标题。原则是：不选销量最高、也不选销量低于100的；标题必须和产品属性匹配；一般不带大品牌，有时候带品牌虽然有好处，但也有风险。![](img/5236b845afdc76c21aebef59413a0327.png)

③发布地址：发布地址影响曝光。尽量发到一二线城市，不要发小城市；不要一直用同一个地址，发一两个产品就换个地方；具体地址可以参考百度指数等网站。

④图片标签：很多人不知道图片标签是什么，其实就是图上的文字，比如“钓鱼船加厚充气船”，它是对应产品的核心搜索词或长尾词，能补充标题信息，影响曝光。标签可以加入尺寸、款式、价格等描述。![](img/10ad592a7a075cad4cc5452dfe2eea17.png)

⑤文案：文案影响转化。要包含售出原因、产品卖点、规格尺寸、服务售后这些信息。分享一个当年跑出来的小爆款文案模板，靠它累计卖了几百个：![](img/42dbf944871238a925207ec603c315ac.png)

⑥图片：尽量从买家秀里找图，千万别用商家图！闲鱼是二手平台，用户想看真实实拍。要求是：实拍图清晰；有整体图也有细节图；尽量用正方形或3:4比例；9张图尽量传满。

⑦定价：低价款可以拿来引流，利润控制在10%左右就行；但低价引流别太夸张，比如你一共设4个价位，最低价是99，第二个价格就尽量不要超过200。其他产品直接在货源价上加30%。价格尽量以99、199、128这类数字结尾，这就是消费心理学。

06 到底要不要养号？

说实话，养号就是个伪命题，理论上闲鱼不用养。如果非要说养号，每天做一遍一键擦亮，首页左上角签到、捞鱼换金币，有空逛逛闲鱼就够了。想让账号权重高，真正关键的是提高转化率：来咨询的客户，尽量都让他下单。

07 闲鱼怎么上架？

打开闲鱼App，点中间的“卖闲置”——发闲置——选择提前保存好的图片——粘贴写好的文案——选发布地址——选择对应属性——填写价格——右上角发布。是不是很简单？![](img/53207b2e7c8ff3b25028406f21eec809.png)

08 客服怎么做？

先把自动回复设置好：闲鱼右下角“我的”——右上角设置——所有宝贝设置自动回复——编辑。![](img/e137fd9681a49a100fc0ca2dd2cc64cd.png)

客户咨询尽量及时回复，既然要做这件事，有消息就把它看成赚钱机会，随时看一眼闲鱼，转化率自然高。客户砍价的话，不要答应得太干脆，也不要一下降太多，可以适当让一点，顺便让他收藏宝贝、关注店铺，或者承诺给好评。

聊天时这些词千万不能发：🛰️（V、VX、WX）、加我、+我、q、链接、二维码、手机号、帖子、头像、互想要、互赞、互粉、jianzhi、赚钱。这些严重会封号，真的会封号！唯品会、拼多多、网易考拉、国美、京东、58同城、转转、苏宁易购这些外部平台词也别提，说脏话同样算违规。

如果闲鱼店做的是单一垂直类目，后期可以把客户导到自己的🛰️，用心经营朋友圈，做持续复购，这才是真正的长期收益。

还有一种“麻烦精”客户，最好直接放弃。如果一开始聊天就觉得对方在挑刺，那大概率售后也不会顺利。售前麻烦的人，售后更容易出问题，白白耗你精力，得不偿失。我们能做的，就是不和这种人产生任何交集。

售后也真的不用怕。一件代发的售后率其实很低，就算真有售后，也能赚到运费险的钱。![](img/1e7ac292e761ae4fb72f361105dfee8c.png) 遇到特别难缠的客户，概率比你买彩票中大奖还低。真遇上了，可以来找我帮你解决。

09 怎么快速破蛋？

第一，上架。新人前一周不用管曝光，也不用急着追问为什么不出单，先按正确方法快速把50个商品位填满。闲鱼店就像超市，你店里有货，客人进来才有得买；货架空着，谁会来？我们测试的上百个店铺里，绝大多数都是一周内出单，少数10天以上。

第二，优化。方法对路之后，拼的就是执行力。做得好的店铺基本都是每天早上新、勤优化图片和话术，把曝光低、流量差的商品删掉，换新品重新发，不停循环。光是这一套动作，就能淘汰掉大部分人。所谓“剩者为王”，就是坚持到别人都撤了。

第三，心态。我常跟徒弟们说：把自己能掌控的事做扎实，比如上架、学习；把掌控不了的——订单和曝光，交给命运吧。
