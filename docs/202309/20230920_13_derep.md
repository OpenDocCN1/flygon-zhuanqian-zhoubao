# 如何判断一笔业务合作值不值
作者：龙哥



## 业务合作的质量

作者： 小马宋

日期：2023-09-13

年底复盘时，我习惯把一年的客户都过一遍：谁续签了，谁走了，谁在合作中途喊停了。判断合作到底好不好，用两条线就够了，一条是人情分，一条是交付分。

两条线一交叉，就出来四种局面。

第一种是理想型，人情分高，交付分也高。客户关系顺畅，作品也经得起打。这种客户是最稳的，只要他还花钱、还有需求，就会一直跟你走。

第二种是能忍的，人情分低，交付分高。客户难搞、爱挑刺，但东西是真做得好。对咨询这行来说，硬实力永远是根本。关系可以慢慢修，产品质量不能丢。这是能接受的短板。

第三种是必须警惕的，人情分高，交付分低。客户对你客气，不计较，钱也付得痛快，所以合作就一直拖着。表面上是留住了客户，实际上留住的是懒惰。

最危险的就是这种。客户越好说话，你越容易心大，觉得反正好说话就不会跑，服务也就跟着松懈了。这就像渣男逻辑：对方越在乎你，你越摆烂。真正该把精力投给的，就是那些对你认可、愿意给面子的客户，而不是把刺全亮出来的人。

如果交付质量提不上去，宁可主动退款收手，也别把这种温水煮青蛙的合作拖下去。

第四种是关系差、交付也差的，这种基本没讨论的必要，不该出现。
