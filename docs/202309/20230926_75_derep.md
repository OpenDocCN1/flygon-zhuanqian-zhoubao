# 知乎广告知＋投放文章创作指南

做知乎知+投放，先想明白一件事：曝光量其实是用预算换来的，买不到量，多半是出价不够猛。竞价机制的本质，就是谁出价高谁拿量。所以别整天焦虑没流量，真正要思考的是——当用户点进来之后，你的内容能不能接得住。

很多人误以为知乎是个纯广告平台，其实不然。广告得寄生在回答和文章里，本质是内容营销。所以做号的第一步，不是急着写文，而是把账号的“门面”收拾利落：头像、昵称、简介、背景图，样样都是信任狀。这四样东西，就是你人设的基础设施。

先强调一个认知：人设在知乎举足轻重。你是什么身份，就说什么话。机构号千万别用第三方旁观者口吻写文章，创始人认证号写出来的东西也必须对得起创始人的认知水准。人设其实就是定位，你不必装，真实最重要——用户读文字时，能感觉到你是个活人，还是堆满套路的营销号。别人是种草，咱们是种树，因为知乎广告赚的是长效。看到这里，不妨停下来，把头像、昵称、简介、背景图都检查一遍，它们是你人格化表达的支撑点。

关于头像：真人照片优于品牌logo，品牌logo优于网图和虚拟头像。机构号用logo没问题，做人设号，尽量用真人头像。

关于昵称：个人昵称/个人品牌词强过单纯品牌名。机构号可以叫品牌名，人设号就用个人名号。

关于简介：简介是用户点进你主页时第一眼看到的“黄金广告位”，也是建立第一印象的地方。等级上去了，甚至可以直接留联系方式。简介要回答三个问题：你是谁，你做过什么有说服力的事（最好用数据亮出来），关注你/找你有什么好处。字数别贪多，把重点信息提炼出来就好。如果不知道怎么下笔，搜一下行业关键词，找出10个同行，挑一个你觉得写得最好的简介，拆解框架，改写成自己的版本。这一招，叫“关注同行、借鉴同行、超越同行”，特别适合刚入门的写手。

要找同行也很简单：在知乎搜索框输入产品词、业务词，凡是有卡片的文章，基本都是知+投出来的广告。顺便说一句，知+并不只有纯竞价，它是商业流量+内容双轮驱动。你的文章内容本身就是广告创意，写得好不好直接影响成本、量级和质量。所以，把文章写扎实，就是对钱包最大的尊重。

广告文章的使命，是承接付费流量。它是你和用户之间的一座桥，让用户通过文字信任你，进而点击卡片、加🛰️、下单。知乎的本质，终归是内容。我自己实测过，一篇两万字的长文，照样有大批用户看到底。愿意看完两万字的人，精准程度还用说吗？几乎是直接成交。而且优质内容有复利，一篇好文可以连续跑一年以上，这是其他平台很难做到的长期主义。

把这篇文章拆开看，无非四块：标题、正文、卡片、评论区。

先说标题，这玩意儿怎么重视都不为过。文章标题不能做标题党，因为它直接决定了流量纯度。既然流量都是花钱买的，那就要靠标题把不相关的人挡在门外，圈进来的用户越准越好。知乎是按点击收费的，用户一戳标题，钱就花出去了。所以标题宁可精准一点，也不要泛。回答的选题也同理：回答的流量盘子比文章更大，但文章流量的精准度高于回答。文章流量通常来自首页推荐和搜索；回答的流量则来自首页推荐、搜索（关键词命中）以及问题下方的第二条位置。不要选泛问题，哪怕你觉得潜在用户重叠也不行——这是花钱买回来的教训，泛问题烧钱极快，数据却惨不忍睹。怎样判断一个问题的热度？看两个指标：关注人数和浏览量。选什么样的问题？可以用吐司工具，在登录知乎广告后台的浏览器里打开即可自动登录；也可以直接在知乎搜索你的业务关键词和产品关键词，把搜出来的一串问题都浏览一遍，心里就有谱了。

再说正文。正文第一段会被知乎抓取成外层描述展示，所以第一段一定要直给，配合标题一起筛选流量，同时还得让人忍不住读第二段。第一段的目的是把用户推进第二段，第二段再推向第三段，层层递进，像滑梯一样丝滑。知乎用户有个特点：极其热爱硬核干货，你写得再长也愿意吞下肚。今年广告风向也是干货分享、顺带转化，A1规则就是证明。文章结尾，可以抖点机灵，引导一下点赞、收藏、评论，完全没问题。而整个创作最核心的秘诀就是六个字：真诚、真实、真情。互联网最难解决的是信任问题，人与人之间的信任，你与客户之间的信任。真诚是最好的解法。用心把广告写明白、写清楚，真正认可你的人自然会找到你。

说说导流卡片。写文章时，要在输出干货的过程里塑造场景、激发需求。当读者正处于“特别想找你帮忙”的念头时，卡片出现在那里，点击概率会大增。文章里可以放多张卡片，但是要适量。每张卡片上方都能加一段引导语，用来引导知友点击，提高卡片点击率。卡片上的描述呢，一定要跟文章内容强关联。人都懒，没好处就没动力。给你一个万能公式：行动指令+索取方式+利益驱动。举个例子，比如“立刻点击卡片，加我🛰️xxx，免费领取价值3800元的引流教程一份”，这就很丝滑。

最后说评论区，它常常被忽略，但分量很重。我们测试过，用户看完文章后，有购买意向的人一定会翻评论区，而且会为评论区的内容做出行动。早前我们甚至在评论区直接留过🛰️号，还真的有人加。现在不能明着留了，就换个说法，比如“可以点击文章里的卡片来找我”。还有人愿意花一小时写一条回评，那评论的含金量比文章本身还高，吸引来好多人，变相创造了不少价值。所以，每条评论都要重视起来，认真回复都是加分项。你回复的那个人可能不回头，可后来看到这条评论的人，都会默默给你加分。

一句话总结：我们是在投广告，流量是买来的，而文章就是我们的落地页。用文字说服客户，用真诚打动客户。只要解决了信任，你的广告效果一定不会差。

评论区永远有意外惊喜——有人看过正文后，还会翻完你每条回评，再决定要不要找你。
