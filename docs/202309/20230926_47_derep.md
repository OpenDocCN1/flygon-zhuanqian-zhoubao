# ('刚筛选了近 100 位小红书博主，大概有 60%通过广告下单', (2, 32))

最近我集中过了一遍近百位小红书博主，发现其中大约六成是靠广告合作下的单。今天就把我的筛选思路整理出来，想在小红书上多接商单的朋友可以参考一下。

我挑人的时候，会优先看这几个维度。

第一，接没接过报备商单很关键。接过的人，流程跑得溜、效率高，沟通起来也省事，合作组件、执行细节都熟门熟路。反过来，从没接过商单的新手，因为缺少实操经验，容易在细节上出岔子，最后影响种草效果。

第二，会刻意让博主的领域错开。每个品类都安排一些，用不同内容风格去试爆款潜力和种草能力。如果你的赛道本身同类型博主很少，反而是个机会，品牌方正好缺你这一块的内容。

第三，重点翻一下过去合作笔记的数据。有些博主合作稿的点赞数量低得离谱，个位数甚至为零，这种数据品牌方基本不会考虑再投放。

第四，粉丝数、近期粉丝涨幅和粉丝单价也要综合看。目的就是筛出性价比更合适的合作对象。

第五，看看对方最近接广的节奏。如果近期广告排得很密，而且都是知名品牌，那基本说明这位博主经得起市场检验，品牌替我们都试过水了，单独踩坑的风险也就小很多。

当然，上面这些条件都满足，也不一定稳过。说到底，核心还是你自己的内容创作能力得过硬，否则其他条件再好看，审核这关依旧很难迈过去。

希望大家都能把小红书好好做起来，双十一马上到，祝各位商单接到手软！
