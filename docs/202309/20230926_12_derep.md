# 为什么别人愿意伸手帮你？
作者：龙哥

我以前是个特别怕开口求人的人。去年准备出《营销笔记2》的时候，编辑跟我说，要不找几位知名作者写几句推荐语？我想来想去，还是不愿意去敲人家的门。后来干脆和编辑商量：这版咱们不做名人推荐了，反正读者未必在意。于是这本书大概成了商业出版圈里的一个“异类”，封面印着五个字：没有名人推荐。

换个角度想，除了亲戚老朋友，一个和你交情没那么深的人，凭什么要拉你一把？道理其实很简单——因为你值得帮，或者更准确地说，帮了你对他有价值。等到他将来遇到麻烦，他也会想到你，甚至觉得这事儿非你不可。人和人之间的互相成全，说到底是一场价值交换。

所以，当你开口求助的时候，最好先做好落空的准备。别人愿意帮你，是因为你身上有值得他伸手的理由；别人拒绝你，那也再正常不过。帮你是情分，不帮是本分。

我曾在读书群里聊到这个话题。常有人私信我请教问题，可我的时间实在太有限，很多时候只能忽略。但同样的问题，如果放到群里问，我基本都会回答。这是为什么？因为在群里说一段话，其实是讲给两百多人听的，而不是对着一个人讲。我在知识星球回复一个问题，相当于给一万个人做了次分享，我当然愿意投入。

因此，后来我找人帮忙时，总会自觉地补上一句：“要是你不方便，真的一点关系都没有。”请人帮忙，心里要存着感激；对方不答应，也要报以理解，坦然接受。

顺带说一句：我的音频课《营销实战22讲》昨天已经在得到上线了。它和《营销笔记》有超过三成的内容重叠，核心思想是一脉相承的。如果你担心重复，就不用购买了，感谢每位读者的心意。
