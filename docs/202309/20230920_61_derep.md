# 一、我是谁

我叫陈炎彬，95年的，专科在南京江宁读的，后来专升本读了西南大学市场营销。

今年5月才加入赚钱。之前花过不少钱买课，也被割过。现在发现赚钱内部和外面完全两码事，里面赚钱的知识点应有尽有，但都是碎片，得自己拼成完整拼图才能找到宝藏。

# 二、做哪块、卖什么

先普及个冷知识，长荡湖已经十年禁捕了，以后塘养蟹会越来越多，固城湖、阳澄湖也一样。现在市面上大牌蟹基本都是商标+蟹农塘蟹的组合。

我家就在常州金坛长荡湖边，有自家蟹塘，平时请了两个工人照看，我有空也会下去。亲戚也做大闸蟹全产业链，从养殖到包装发货一条龙。

很多人觉得阳澄湖大闸蟹名气大，其实市面上99.9%都是假的，说出来不夸张。

套路大概就这些：

1、本地蟹：阳澄湖土生正品，不到1%。本地人基本吃不到。
2、移民蟹：外地蟹苗到阳澄湖长1-3个月镀金，不到2%。
3、洗澡蟹：外地蟹苗提前几天放进湖里，卖时捞出来，等于洗个澡，不到3%。
4、听涛蟹：没位置洗澡了，就直接运到湖边卖，只听见涛声没下水，约10%。
5、授权蟹：湖面不够，开放品牌授权，拿证就能卖，约20%。
6、标签蟹：授权都嫌麻烦，直接贴标签卖，约64%。

说完套路，跟大家简单聊聊养殖流程。

**1.水草种植**  
水草是池塘生态的基础，也是蟹的天然饵料和蜕壳庇护所，还能吸收水体养分净化水质。

**2.螺蛳投放**  
螺蛳是河蟹生态养殖的重要一环，既是饲料来源也能清理水底残渣净化水体。

**3.选苗**  
现在基本都用人工蟹苗，多为外地苗，3月左右投放。

**4.饲料投喂**  
以动物性为主，植物性为辅。动物性以新鲜小杂鱼为主，配小麦、玉米、豆饼。鱼必须新鲜，腐败饲料不能入塘。

**5.水质管理**  
投苗前要培育水色，保持到水温20℃左右。肥水能防青苔。水质决定蟹质，好水出好蟹。

**6.病毒防治**  
冬季排干池水，清理淤泥，每亩用150-200公斤生石灰消毒，塘底自然过冬。不同时期有不同小病，得用对药，螃蟹比人还金贵，一不小心整塘死亡，一年心血白费。

养殖受不可抗因素影响大，高温缺氧就会大批量死亡，水草和投喂方式也会影响成活率。

所以很多人干海贩，不养只做流通，避开养殖风险。

作为海贩或从蟹塘拿货的门店，优势很明显：无养殖风险。项目周期每年10月到次年1月中下旬，黄金期约3个月。

去年加入赚钱后萌生了赚点外快想法，就在朋友圈试卖蟹，目前主推礼盒蟹和断脚蟹。朋友圈反馈还不错，一开始发自己吃蟹的图，就有人下单。

慢慢就积累了一批客户。送蟹自带寓意，大发横财。

螃蟹寓意富甲天下、八方招财。蟹总爱找清澈水草多的水域。

大闸蟹，八条腿就是发，两把钳就是抓，煮熟通红象征红运当头。味道鲜美营养健康，敢吃螃蟹即是创新勇士精神。

也有不少是自家吃，不在乎完整度，主打蟹黄蟹膏，那就是断脚蟹。按斤称，我为了好卖按个卖，分规格打包，200一份、300一份都有。

**怎么挑蟹简单说一下：**

1、外观，肚圆是母，肚尖是公。青壳要看活力，死蟹别吃。
2、捏腿，从下往上数第二条腿，俗称钢筋腿，捏着硬说明成熟度高，软脚别要。
3、看厚实度。

母蟹看肚脐轮胎纹缝宽黄多，扒开泛红鼓起来说明膏满肉肥。

公蟹看嘴，红嘴品质一般不错，看胸口平整度，凹陷的不选，黄膏多少跟投喂有关。

螃蟹核心就是黄膏，断脚的蟹价格不到完整蟹的十分之一，挺可惜，其实吃法一样。

之前有女客户问我有没有脚全断的断脚蟹，我回她，全断的比全脚的还难找。因为很多人爱吃黄膏又懒得剥腿。

# 四、蟹卡逻辑

先推蟹卡是因为送礼场景多。教师节、中秋螃蟹未成熟，大家先买卡，成熟后再兑换，方便。

中秋蟹像生米饭，不好吃。蟹卡等螃蟹熟了再提货。母蟹10月中旬最好吃，公蟹11月。母蟹吃黄公蟹吃膏，饱满就代表好。

蟹卡企业和政府采购量大，能快速回笼资金。我的长荡湖蟹卡承诺永久有效，十年后再来也能安排发货。

# 五、变现方式

好蟹价格贵，一般人送礼才买礼盒。

断脚蟹利润35%-45%，客单集中在200-300元区间。按斤称，但前期按个卖更好，公母搭配，一捆打包150、200、300元。

苏锡常、泰州、高淳市场已饱和。我表舅90年代在金坛开第一家卖蟹店，92年就是万元户。第一年赚20万，那时6万能买套房。95年门店变多客户被分流，98年黑社会势力入局，机关单位都去他们家拿蟹送礼，后来演化成蟹卡送礼。那家黑店几个月赚100万，还欠着长荡湖30万货款没结清。

现在长荡湖已十年禁捕，市面上都是授权养殖蟹。长荡湖三个字被一家公司注册了专利，靠名字就能吃一辈子。

以后基本都是塘养蟹，很多保护区禁止养殖捕捞，违规罚钱坐牢都有。

冷知识再次强调，阳澄湖大闸蟹99.9%是假的，过水蟹、听涛蟹、外来蟹，挂上名字价格翻番。

我表舅店旁边现在开了50多家卖蟹店，都做外地客户。10月到过年4个月，好的赚几百万，差的赚四五十万。

现在短视频对实体冲击大，门店玩法会变。我看好的是断脚蟹下沉市场，用口碑打。

闲鱼上卖断脚蟹的人不少，生意很好，卖家还不多，属于蓝海。

近几年还能招代理收代理费共赢，售前代理做，发货售后我来。每年都有复购，今年做得好明年更好，客户每年都要吃蟹。

我也招了几个代理，以低价供货给他们，在我的价格上加价卖。我的精品蟹价格低，因为直发，质量和价格都有保障。

先把项目跑通，3年入行，5年懂行，10年成王者。我会把行业知识和套路毫无保留分享。

# 六、项目核心

核心是货源和质量。

有靠谱蟹塘就能一件代发，像闲鱼无货源，不用囤货。有能力可注册执照做视频号直播带货，跟货主约好稳定供应，顺丰或京东保证时效。

质量需要经验，腿软、壳空、个头大但空心都是新手坑。养殖期营养没跟上，个头大华而不实。螃蟹蜕壳像孩子发育，发育期不补营养长不好。

不建议自养，步骤复杂稍有不慎整塘死。养多亩也是分散风险。

要点：

1、放苗前清淤泥，防夏季安全问题。
2、草和水质是关键。
3、螃蟹吃VC、复合维生素、蛋白粉，平时以鱼和东北玉米为主，荤素搭配。
4、夏秋高温合理用药，杀藻杀菌杀虫要对剂量时间，防止伤水草螺蛳软壳蟹，导致缺氧浮头。
5、螃蟹金贵，小心一点。

蟹塘代发方便，但塘口不为几件货费心，都是大批量按斤卖。自己拿一批货在水池养着，能洗掉泥腥味。

运输要绑扎防消耗，休眠状态下放冰袋保鲜。

保存方法：

1、买回来先冲水，让蟹补水。
2、放冰箱冷藏室，5℃左右，别放冷冻。
3、盖湿毛巾保湿，保持湿润可存一周左右。

断脚蟹保存同上。
