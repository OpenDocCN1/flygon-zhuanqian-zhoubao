# 2023 年的摆摊风口项目

最近刷到不少人在聊摆摊，我也忍不住分享下自己这段折腾出来的真实经历。

早前其实我就试过一次摆摊，卖的是那种网红小金鱼。鱼本身颜值很高，价格也挺亲民。但我犯了个大错——根本没提前摸清周边环境。我摊位附近全是大学城，小孩子少得可怜，连幼儿园和小学的接送潮也特别短，基本放学十几分钟人就散光了。我每天守在那十几分钟里，加上前后耗着的四五个小时，一天也就卖出五六十块钱，刨掉成本，真正落进口袋的只有四十来块。

后来我学聪明了，先认认真真去踩点。既然周围的大学生多，那就卖大学生愿意掏钱的东西。于是我转做发簪和小灯笼。真是没料到，这两个小玩意居然成了惊喜。成本不到五块钱，小灯笼卖十五，发簪卖二十。每天只摆两三个小时，扣除成本后，净利润基本能稳定在三百到五百元。

当然了，这种产品在一线城市和外地早就烂大街了。想靠它赚钱，必须玩出自己的花样来，话术也得够溜，不然拼不过别人。

我这边刚起步时还只有我一家在卖，后来陆续来了几个人找我拿货、跟着一起卖。但只要你能把差异化做出来，影响其实不大。

另外，选位置真的很关键。我看到不少网友抱怨说卖十块钱都没人买。这种时候要先掂量一下当地的消费水平，再说说话术有没有到位。多少还是得有点商业敏感度。
