# 别再把个体户注册完就扔一边了，税务申报这一步，很多人都漏了

身边不少做电商、开网店的朋友，注册个体户时挺上心，全程网上操作，走当地市场监督管理局的线上通道，几天就能拿到执照。但很多人以为“执照到手=万事大吉”，其实这才刚迈出第一步。

真正让个体户“安全落地”的，是后续的税务申报。遗憾的是，绝大多数人压根没做这一步。平时看着没啥影响，可一旦哪天想注销，麻烦就找上门了——稽查、补税、滞纳金，一样都不会少。

为什么过去大家习惯“不申报”也没事？因为市场监管和税务是两套系统，各管各的，信息没打通。个体户规模小，数据不关联，自然没人追着你要税。久而久之，大家就默认“不报也没关系”。

但现在不一样了。金税四期的核心，就是税务、工信、央行、市监等各部门数据全面打通，给每个个人和企业画数字画像，用大数据来管税。个体户不申报，风险已经实实在在摆在面前，不再是“以后再说”的小事。

其实，申报流程比注册还简单，全国通用，照着做就行：

1. 打开“自然人电子税务局”官网，登录个人账户；
2. 点击“我要办税”，选择“经营所得申报”；
3. 每季度申报选A表，每年度申报选B表；
4. 选好对应时间和个体户的纳税识别号，填写计税信息；
5. 系统会自动算出应纳税额，没收入就填0；
6. 提交完成。年度申报换B表，步骤一样。

税率方面，分两种情况：

一是查账征收，按“生产经营所得”五级累进税率缴纳，比例在5%到35%之间，但可以享受国家给个体户的个税优惠政策，具体参考税务总局相关公告。

二是定期定额或核定征收，简单说就是按营业额的一定比例来交。早些年像薇娅在上海崇明岛注册的个人独资企业，就是按10%应税的。但这几年核定政策陆续收紧，现在能核定征收的地方已经很少了。

最后给几点实在建议：

- 就算个体户一分钱没赚，也要按时申报，零申报也是申报；
- 流水大的，老老实实如实申报，经营账户和私人账户分开，资金别混着用；
- 金税四期不是吓唬人，2025年智慧税务全面落地，业务、资金、发票、合同要实现“四流一致”，监管只会更聪明、更严格。

别让“注册一时爽，注销两行泪”发生在自己身上。提前把税务申报做起来，经营才能稳稳当当。
