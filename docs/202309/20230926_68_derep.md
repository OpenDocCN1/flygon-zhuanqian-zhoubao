# ('一个不起眼的技能，助我净现金资产增了三百', (2, 22))

毫不起眼的小技能，让我的净现金资产多了 300 万

嗨，我是老吴——一个在金融和互联网两个赛道来回切换的实践派。先晒晒家底：淘宝客佣金累计拿到 1000 万，股票账户盈利 200 万，其他投资项目的胜率基本保持在 70% 以上。以前我特别喜欢聊“怎么赚钱”，这次打算换个角度：一边继续赚，一边把钱守住。

这个看似平淡无奇，却帮我撬动了 300 万净现金资产的技能，说到底就一句话：把“赚钱”和“守钱”放在同一张棋盘上去排兵布阵。

能有这份转变，很大程度上源于加了生财。说实话，这里就像在我人生里多开了一扇门——过去只盯着钱怎么进账，如今学会了利他，也懂得了分享，连看待问题的视野都宽了一大圈。

之前在星球里也发过两篇：《从年负债 19 万，到眼光敏锐投资年净收益近百万》《听取一个良好的忠告也许就是赚几百万》。承蒙亦仁大大加精，这份认可让我更有劲头把自觉有用的东西梳理成文。
