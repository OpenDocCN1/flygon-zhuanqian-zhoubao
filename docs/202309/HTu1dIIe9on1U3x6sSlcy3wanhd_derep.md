# 38岁中年妇女，面临降薪、裁员，我是如何依靠ChatGPT走上自救之路的
作者：龙哥

我叫菜菜，85后，两个孩子的妈，在一家互联网教育公司做内容运营。按世俗的剧本，我这种年纪、这种拖着家庭包袱的状态，早就该退到事业边缘，安心把日子过顺就谢天谢地了。可我偏偏是那种心里压着火的人。今年2月，ChatGPT在国内刮起大风，我半懂不懂地扎了进去，最后竟然把自己练了十几年的内容功夫，和这个新工具拧成了一股绳，成了ChatGPT内容创作教练，如今也是三节课平台的特邀讲师，前前后后带过了3000多名学员，帮他们大幅提升内容产出的速度和质量。

![](img/843cdc7ee64935d9f4e666e1a003a35e.png)

01 那个总穿旧衣服的女孩

很多人问我，哪来的这股劲？我得承认，是那种“不想落于人后”的焦虑烧出来的。这焦虑早刻进了骨头里。小时候我是爷爷奶奶家的长孙女，我爸是长子，而那个年代的长辈，骨子里盼的是男丁。据说我落地那刻，奶奶脸上的失望藏都藏不住。她后来说过很多次：“要是你是男孩该多好。”

那时我跟爷爷奶奶、还没结婚的叔叔，还有姑姑家的表妹住一块。表妹从小就讨喜，扎两个羊角辫，小皮鞋擦得锃亮，穿着花裙子满院子转，长辈们的目光和夸奖永远围着她打转。而我呢，常年套着大人改小的旧衣服，怯怯地缩在角落。我不止一次说不想穿那些旧衣裳，可在奶奶家的那几年，唯一的新衣服，是二年级加入少先队那天发的。

![](img/17699f392ee534e42774b0ee5db95510.png)

为了争得一点关注，我开始学着模仿男孩，不穿裙子、不留长发，动作也故意带点野。结果有一次弄巧成拙——我跟妹妹打闹，学电视里的大侠，用火钳敲了她脑袋，她当场大哭，头上起了包。奶奶知道后，冷着脸说：“你还是个孩子，怎么心就这么毒？”后来她反复拿这件事说我，大人也许只当闲谈，可我像被判了刑，羞耻感咬了我很多年。我怨恨自己：为什么我是个女孩？为什么她随便撒个娇就能被喜欢，我怎么做都是错？成年后我看了那部日本电影《被嫌弃的松子的一生》，一个人关在房里，哭了整整三个小时。

02 写作，把我从泥里拽了出来

三年级，我离开奶奶家，回到城里的父母身边。妈妈买了一大堆课外书，我着了魔一样读，脑袋里好像有什么东西在拱，逼着我写出自己的话。说来也怪，别的孩子愁作文，我十分钟就能交出一篇像样的文章。家里买瓶酱油、路边看到一朵花，都能写出一篇不错的作文。语文老师总当众念我的稿子，作业本上画满红圈圈，参加市里比赛随便拿一等奖。那种被人肯定的满足感，我第一次尝到。也是从那时起，看书和写作成了我唯一拿得出手的“武器”，像基因一样长在了身上。

03 一个赌约，把我从泥里拽了起来

可到了青春期，自信又塌了。胃口好，脸盘发圆，脸上冒痘，整个人还含胸驼背。班上有几个男生给我起了一串带侮辱性的外号，每次经过他们身边，就是一阵阴阳怪气的哄笑。高二那年，因为其中一个男生，我的人生被猛地岔开了一道口子——别误会，不是爱情故事。

那天我和男同桌正聊着，那个常笑我的男生又开始阴阳怪气。我气不过，第二天写了封信塞他抽屉，照搬他的语气，添上对他外貌的揶揄，狠狠回敬了一顿。他看了勃然大怒，揪住我衣领要动手，我也不怂，骂着跟他扭打起来。结果当然是我吃亏。脸丢尽的那一刻，小时候那股羞耻感又涌了上来——我受够了。我记得自己捂着脸，一字一顿地对他说：“你记住今天。我正式向你挑战，等高考成绩出来，看谁是彻底的失败者。”

从那天起，我像换了个人。不跟朋友玩了，最爱的漫画锁进柜子，没日没夜地啃书。白天一下课就冲进老师办公室，把老师烦到看见我就苦笑：“你怎么又来了？我水都没喝。”晚上刷题到凌晨三点，困了就用笔尖扎大腿。我逼我妈听我背课文，她撑不住，求我：“给你十块钱，你去买点好吃的，放过我好不好？”

就这样，我硬生生用一个高三，从班里三十名左右冲进了前十，最后考上了本科。老师们都说这是个奇迹，又惋惜：要是早点发力，二本远远不止，985、211都有得打。你猜到了，那个男生没考上，读的是专科还是三本，我已经记不清了。我也忘了最后有没有当众羞辱他。但当我兑现了自己的诺言，心里的恨突然就散了。回过头，我甚至有点感激他——不是他，我大概永远不知道自己能拼到什么程度。

04 那12年，我反复把自己打碎再拼起来

因为喜欢写，又渴望被看见，我大学读了广播电视新闻学。毕业后考进长沙电视台，一干四年。体制内的条条框框让我憋屈。正好传统媒体开始退潮，🧣起来了，我借着记者身份接触明星资源，在🧣上和用户互动，写些感悟。后来听说新浪要在湖南建站招人，我凭着多年积累的内容敏感度，顺利进去了——我的自媒体生涯，满打满算干了12年。那阵子不少人羡慕我：到处吃喝玩乐，近距离见明星，风光得很。

![](img/aea71539a79448733e5a87050aacd4d0.png)

![](img/4b8d22c57da2408ebbe99ebf563c82ef.png)

可慢慢地，我意识到一个事实：平台厉害不等于我厉害，换个地方，猪还是猪。那时刚休完产假回来，我怕自己就这么废掉，深思熟虑后辞了职。

从🧣出来后，我进了一家不到50人的电商公司，老板是圈里知名的RPA导师@阿愚呱呱。他讲自己怎么从深圳回来，把一个珠宝网站从0做到年营收几百万，我听完整个傻了——互联网还能这么玩？当时也没管工资多少，铁了心跟他学。正是在他鼓励下，我拉起了新媒体团队，开始做👸号。公司卖海外保健品，没法直接硬广，我们就绕了个弯，做营养健康科普。可市面上的内容就两个极端：要么是家族群里疯转的“这几种食物吃了致癌”，要么是医生写的每个字都认识、连起来看不懂的论文。难道就没有既专业又读得懂的科普？

直到我刷到“混子曰”——用漫画加段子讲生涩知识，我一拍大腿：就它了！我们马上组了班子：专业的医学编辑负责把知识弄严谨，我和另一位文案负责把术语翻译成人话，再塞进网络热梗，最后由设计师画成漫画。几个月下来攒了几千粉丝。我又把过去攒的媒体资源全用上，疯狂向大号投稿，渐渐被人民日报、科普中国、共产党员、人卫健康等转载，还被《百科知识》杂志收录，拿了人民卫生出版社全国科普大赛二等奖，2019年挤进新榜健康榜前20强。

![](img/d413f633ac89a2c0021ccc526d5cebce.png)

那一段高光，我总结过四点：找准了市场空白；学丁香医生搭了套标准创作流程；每个周五整个团队窝在会议室啃文案底层逻辑；以及不停向外推荐自己、向上破圈。可惜公司后来发不出工资，账号本身又还养不活自己，我只好离开，去了一家离我家25公里的大型医院——每天通勤近两小时，搭同事的车，来回车费大几十，还是单休。全是妥协，可我咬牙去了。在那里又干了一件从没想过的事：培训医生做个人IP。第一期结束就有3位医生拿下多次今日头条青云奖，医院还没开业，医生们先在网络上攒了一波人气。


![](img/7fa55c6172866559525bd1ead14feff3.png)

也是因为这两段“为人师”的经历，我重新找到了站在聚光灯下的兴奋感，也为后来做ChatGPT教学埋了伏笔。再后来我主动学短视频和直播，给公司做抖音号，开发教培干货课程，连续40天每晚直播2小时，既给了公司不少零成本线索，也治好了我在镜头前的恐惧。本以为能一直这么下去，2021年双减落地，公司和个人都受冲击，减员、降薪、行业哀嚎一片，我又过了35岁，焦虑到整夜睡不着。但我这人，一焦虑就爱学。白天上班，晚上啃书，品牌、产品、营销、心理、文案，什么都能看进去。当时不知道，这些全是在给未来的ChatGPT喂养喂料。

05 原来AI，早就在等一个“会问问题”的人

2023年2月，我在龙哥盟第一次见到ChatGPT。第一反应不是害怕，是亢奋——我过去常常想，能不能有一种工具，不用写代码、只靠对话，就能替人搭建程序、干各种活？没想到真有人把它做出来了。我立刻去淘宝找人代注册了账号。上手一聊，竟有种莫名的熟悉感。靠着多年的媒体采访和写作底子，我好像天生知道该怎么跟它说话，怎么下指令。我随手把训练案例发在朋友圈。

![](img/778f55a4c5442606b3aa5dfca964443d.png)

试了几天我发现了更大的问题：周围太多人想用，却被账号、技术门槛挡在外面。于是我一冲动批发了一批账号，在抖音边直播边卖。我和别的同行不一样，他们只表演和ChatGPT聊天，我是直接连麦，一个接一个解决观众的提问，展示怎么问、怎么调教、怎么拿到想要的东西。直播间越挤人越多，同行也跑来围观，还在评论区打广告，我哭笑不得。就这么着，光卖账号赚了几千块。

很快账号生意卷起来了，还带着封号风险。我想了想自己的优势在哪——不是解决技术问题，而是：怎么跟ChatGPT对话，怎么把写作方法论灌给它，让它产出惊艳的内容。我观察到一个扎心的现实：大多数人用不好它，是因为根本不懂它的原理，只会直筒子式地抛出一句话，AI只能瞎猜乱给。要做教学，我有三张牌：一是十几年采访练出的提问能力，能顺着回答及时调整追问，这恰好是调教AI的核心能力；二是我肚子里存了大量内容生产方法论，可以一套一套喂给ChatGPT当老师；三是我既会研发课程，又会讲课答疑、运营社群，基本一个人就是一支队伍。加上这些年认识不少社群群主，他们手里正好有学员需要这个。

我找到运营圆桌会的大国老师，提议在他的社群里试水，做一期ChatGPT内容训练营。那一期意外地成功。我公开了一套简洁好用的对话心法，学员大呼过瘾，当天晚上就有50多人直接转学费报名。课程结束后好评一波接一波，老学员又陆续介绍了50多个朋友来，有人一个人就给我转了十个学员。后来，还有学员靠着ChatGPT写稿，拿到了真金白银的变现。

![](img/a3cc25384665a6393d4e471a11384fd7.png)

回头看这几个月，我最想说的是：ChatGPT确实是个风口，但能接住它的人，靠的不是抢跑，而是过去十年里一篇文章一篇文章、一个项目一个项目攒下的判断力。技术是放大器，真正值钱的，是你脑子里沉淀的东西，是你会不会问问题、能不能把一个模糊的需求拆成AI听得懂的指令。对一个38岁、被降薪裁员阴影追着跑的中年女人来说，这大概是命运留给我最体面的一条自救路。

![](img/9b474cb3b6c73f77f81cd6907719ad25.png)

在和大国老师建立合作之后，我又迎来了和野生运营松月老师的链接，受邀到她的社群内授课，反响非常不错。
