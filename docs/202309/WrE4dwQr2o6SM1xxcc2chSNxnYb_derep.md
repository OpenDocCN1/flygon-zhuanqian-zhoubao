作者：龙哥



# 各位抖店老板们好，我是江河

做抖店的都知道，体验分起来慢、出分难，找渠道刷分动不动就是五块钱一单，今天把我这边一直在用的低成本拉分打法拆开讲一下。单笔花费大概1-2块，起量快，每天稳定出300-400单，新店200-300单左右就能把体验分顶到4.8，老店分低也能直接拉回来。

## 我是怎么操作的

1. 打开抖音商城，直接搜“2元包邮”。跳出来的基本都是行业里用来冲分的引流品，样式非常多。
![](img/0b19063662cb398101366cae3f843db2.png)

2. 从这堆品里挑和自己店铺类目贴近、并且销量靠前的款，把主图保存下来。随后拿去拼多多搜图进详情，重点看差评。翻到最后一页统计一下差评占比，优先选差评率0.5%以下的款，降低中差评风险。参考图示。
![](img/20c562b1151d555956681aebea7ddad9.png)

3. 拿到主图再去淘特或1688上搜图，核对到手价。搬到抖店后，在原价上加2元再上架。标题前面统一加上【2元包邮】做强吸引。商品上架时挂两个优惠券：一个1元新人券，一个1元单品券。这样到手价能控制在2.1元到4元之间，既能计入有效销量，又容易出单。想冲量更猛的，就多选成本稍高的品，亏得越多起量越快。我们实际操作下来，平均每单亏损在2元出头。

4. 一次性多备几十款上去，上架数量越多分摊越快、起量越稳。我们一般会上50-60个SKU。出了单就去淘特或1688下单发货，千万别去拼多多下，极易被判定无货源。单品量起来后可以和源头商家谈代发，用店铺管家推单，能省下大量拍单时间。基本上3-4天能跑出300-400单，体验分基本就能稳定在4.8左右。

5. 到达目标单量后，就开始慢慢撤券。先撤单品券，观察一下销量波动，稳定后再撤新人券。这时候价格已经接近成本，可以平本继续刷一点销量来稳住评分。后续不想继续跑低价的就直接下架，我们的做法是把亏得多的品下掉，留几款亏损小的继续零星出单，维持店铺热度。等这些单签收完成、出分后再正常上架利润款售卖。
