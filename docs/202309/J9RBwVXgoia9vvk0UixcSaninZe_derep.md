# 一、入门篇

## 1.1 Discord 是什么

### 1.1.1 产品定位

Discord 起源于游戏语音和即时通讯工具，最初服务于游戏协作，后延展到直播生态，再升级为集应用商店于一体的兴趣社区平台。如今它已是游戏玩家沟通协作的核心阵地，同时也被各类学习小组、读书会、线上聚会团队广泛采用。

在美国年轻人群体中，Discord 已跻身前五大社交媒体，前三为 Snapchat、TikTok、Instagram。其用户扩张经历了三个明显阶段：

1. 2019 年以前聚焦游戏场景：竞技类游戏兴盛、大体量游戏的周边内容爆发、轻度游戏对社交和直播的友好适配；
2. 2019-2021 疫情与 Web3 红利期：疫情推动 Discord 向泛兴趣人群破圈，在线办公与在线教育场景落地；Web3 时代到来，Discord 的产品架构与交互方式天然契合 DAO/NFT 组织，成为其首选阵地；
3. 2022 年后 AIGC 带来增量：当前 Discord 的新增用户中约 10% 为体验 AI 功能而来，月活使用 AI 应用的用户超 3000 万，平台内含 AIGC 功能的服务器已超 300 万个，现象级 AI 应用 MidJourney 正是诞生于 Discord。

### 1.2.2 核心功能

![](img/96a2e75199e8251bf5f7faa2a80a1a86.png)

Discord 服务器

服务器本质上是虚拟化的群组，相当于一个线上社区的大厅。用户可按自身需求与兴趣自建或加入不同服务器，例如为某个游戏开设专属空间，或加入已有游戏社区。管理员可配置权限、规则及管理选项，保证社区秩序与安全。通过服务器，玩家能与志同道合者交流、组队、讨论主题。

频道——兴趣分群

Discord 不仅服务游戏玩家，也聚拢了大批兴趣用户。借由服务器与频道的层级结构，用户能找到并加入自己喜爱的兴趣圈。无论是电影、音乐、艺术、科技或其他品类，都能在 Discord 上找到对应社群，与同好交流、分享、学习并建立真实连接。

聊天室

群组成员可通过文字、语音、视频三种方式互动。

## 2.1 新成员验证

为避免机器人或无效用户进入影响运营效率，可对新成员进行验证，通过身份组实现

方案思路：
1）新建一个特殊身份组
2）新用户加入后除“验证”频道外其他频道不可用，通过验证后自动加入该身份组并开放权限
3）对所有频道设置仅该身份组成员可查看与发送消息

操作步骤：
1、新建身份组“成员”

![](img/6bdfce209a8d38f74029dbb8c2899fbd.png)

2、新建频道“验证”

![](img/4c99d9c0484c0596862c46206c26658c.png)

3、将除“验证”频道外的所有频道权限设置为仅“成员”身份组可查看、可发送消息

![](img/9fa381fcee24ce6afe5e0fecacd731ee.png)

4、在 MEE6 中使用 Reaction Roles 功能完成 Verify 设置

![](img/b284eacbc445ea6d6c66f7e6df694f5d.png)

选择验证后分配的身份组

![](img/c50b46333cd46f06e711b30b960aea74.png)
