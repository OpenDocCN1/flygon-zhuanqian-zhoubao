# 投入100万，头一个月只进账2800，产后康复这门生意到底靠不靠谱？
作者：龙哥

> 我拿自己的真实经历，给你盘一盘这个项目背后的门道。

“就算是借钱，也得把产后康复做了，不然以后漏尿、腰疼全来了。”

2016年年中，我出差去北京，身边好多医生同事都在聊这件事。我自己生过孩子，一直有腰痛的老毛病，听多了就好奇，特地跑到围产中心看了看。那儿的人多得离谱，走廊墙上贴满了宣传海报，各种盆底肌、腹直肌、骨盆修复的标语，一眼望去简直让人心慌。

我忍不住问几个排队的妈妈：“这些东西靠锻炼也能改善吧，干嘛非要花钱受罪？”她们几乎异口同声：靠锻炼得坚持太久，人都有惰性，不如直接花钱买服务。

这话一下点醒了我。北京这么火，我们那种小城市是不是也能做？

当时我花了将近3.7万，在北京把产后修复的项目几乎试了个遍——肩颈理疗、乳腺护理、中药熏蒸、骨盆矫正、妊娠纹淡化、开奶催乳、艾灸泥灸……整整做了三个疗程。结果腰不疼了，妊娠纹淡了，小肚子收了，体型也好了。这让我彻底下了决心。

那年年底，我回到老家，找了三位朋友一起干。每人出25万，凑了100万。买设备、请人、租场地，团队也搭起来了：

- 三名体制内主管护师做产康总技师
- 一位主治医生合伙人做顾问
- 两位护士长管理理疗师
- 58同城招来普通理疗师
- 刚毕业的医学生当学徒
- 护士长负责催乳，主治医生负责中医指导

我呢？负责打通各种关系，算是操盘手。

场地用的是自家公司的店面，第一年免租，之后按内部价交租。我特意强调一定要选高层，不要临街，安静、隐私好，最好公交直达或停车方便。布置要么走专业路线像医院，要么做得温馨浪漫些。员工统一穿儿科护士服，干净又可爱。

刚开始完全不会宣传，就盯上了医院围产中心。我们几个用职位之便，想方设法找产妇电话，硬着头皮一个一个打。两个星期只来了6个人，真正愿意做治疗的只有2个。

第一个月结束，100万投进去，收回2800块。

合伙人全都泄了气，觉得小城市干不成。可我不甘心——我自己亲身体验过效果啊。干脆关门放三天假，带着他们飞了一趟上海。跑了公立和私立好几家医院，发现人家的产康生意火得很。我们也不客气，把宣传册、海报统统拍了照，原封不动抄回来。

回来后，我们把目标死死锁定在医院：妇科、产科、围产三大科。直接拿着海报去找领导谈合作。

第一次找自己医院的领导，被一句“不合规矩”怼了回来。我心里骂了他八百遍，但也只能忍。从办公室出来，正值中午，电梯挤不上去，我就走楼梯。到了一楼住院部大厅，发现那里空荡荡的，小孩滑板、老人下棋，简直像个游乐场。

突然想到——北京协和医院五楼有一排大展柜，卖营养品、护肤品、零食饮料。我为什么不在这个大厅搞一个？

合伙人说我“癞蛤蟆想吃天鹅肉”，可我觉得不试怎么知道。于是又去找领导，这次开门见山：我帮你把大厅空地利用起来，你把产后康复交给我做。领导当场拍板，条件是医院什么都不管，亏了算我的，赚了归医院。

就这样，我们解散了第一批团队，搭进去五千块工资和一顿三千三的自助餐。熬了45天，医院商务中心开业了。这是整个地区第一家，卖母婴用品、产后用品、零食饮料，开张就火爆。

又过了15天，产康室开业。这次什么都没做——没海报、没传单、没报价单，只有硬件。

顾客从哪来？医院医生直接开单。理疗师也是医院的护士，免费干活，三班倒轮流来。

就靠着这种“狠抄笔记”的模式，一年时间，我们四个人赚到了人生第一个100万。还拿下了医院商务中心的卖货权、管理权，供货商也愿意信任我们。之后另外三家医院主动找过来，我们又做了三家商务中心。

再往后，月子中心、育儿、早教、游泳、亲子游乐场、瑜伽、陪诊、家政、培训……一个接一个开起来了。

现在说点具体的模式：

**合作怎么分？**
医院科室（妇科、产科、乳腺科、围产科这些为主）跟我们46分，再拿货品10%提成。顾客花1000块做治疗，医院拿400，我拿600。顾客如果买了奶粉，供货方或医院商务中心返还10%，员工拿1件的3%。

钱全部从医院账上走，既解决了税务问题，也背靠了医院这个金字招牌。顾客在医院做完检查，医生开单，在医院商务中心缴费，拿着单子到产康室治疗。如果买了面膜、精油、营养品这些，收益的10%返给医院。

**员工怎么管？**
招人不看学历，但必须得有特长——亲和力好、会唱歌跳舞、懂化妆穿搭、会阅读、有减肥经验都行。我一直觉得“员工是天，顾客是地，我就是电话线”，让他们随时通上话。

比如妈妈来做治疗没人看孩子，员工帮忙带帮忙喂，这些都培训过。

又比如店里要买加湿器，先问员工有没有渠道。员工报价100，我给150让他买，多出50就是辛苦费。月子中心食材，员工能拿到8毛，我本来自己找是1块，那就让他赚那2毛。端午节卖月饼，店里卖698，员工报我300，我给368，那68就让他赚。

这么搞，员工以后不会抬价，反而还会主动去砍价。

再比如教瑜伽的员工，工作时拍视频发抖音快手，闲时直播。场地设备店里出，直播卖出去的课，店里抽20%；如果顾客练瑜伽时又买了护肤品营养品，店里返20%给员工。顾客老公喜欢台球，就引流到合作的台球厅，打8.8折，还免费陪打两小时。

这些人都成了店里的宣传大使，每天都有老顾客带新顾客。

**引流怎么做？**
探店达人来过，基本是员工朋友和顾客，一顿饭搞定。也在抖音快手找了六千到两万粉丝的博主，一天给50，只做了两期。后来改用这些办法：

1. 派人去医院围产、产科、妇科“自行陪诊”，主打共情，加🛰️聊天。
2. 利用护士长等医护人员，推荐一人消费就返10%。
3. 给科室大主任办学术会议，一场给1500到3000。
4. 夏天联合同行办茶话会、团建，实行CC制，本来168，顾客只要68。
5. 维护老顾客，介绍美容、减肥、育儿、早教，同行之间互相导流。
6. 中医按摩搭配着来：妈妈做产康，婆婆或育儿师等着，正好去做肩颈腰部护理。套餐设计好，做盆底肌送肩颈理疗，消费够6999送全套中医按摩，介绍人再返现或送项目。

**陪诊也是收入。**
员工利用职位接陪诊单。服务费不一，公司抽10%。加号298到398，取药88寄顺丰，咨询加取药168，再加开单198，要是跟医生电话咨询再取药开单268。挂号费另算，老专家280，大主任200，副主任180，教授团队168，挂号费自理十到五十。医院自制药特效药我们也有，比医院贵10到50一盒。前段时间紧缺的可崴，我们的人用医保卡拿到货，老顾客白送两盒，新顾客消费899也送两盒。

员工工资构成：底薪+提成+自身可利用价值+小恩小惠+特长变现+陪诊+过节补贴+一年一次旅游。两年以上的老员工还能进驻医院商务中心，缴五险。

最后再说几句心得：
- 选址选高层，不选临街。
- 布置要么专业要么温馨。
- 员工要会带娃，穿儿科护士服。
- 老板可以不赚钱，不能亏团队。
- 走心做服务，用心去赚钱。
- 引流不知道怎么搞，就抄邻居的。

一路走过来，赔过夫人折过兵，但总算挺住了。从一个产康室，到现在的月子中心、育儿、早教、游泳、游乐场、陪诊、家政、培训……这条路，我走通了。希望我的经历能给你点启发。
