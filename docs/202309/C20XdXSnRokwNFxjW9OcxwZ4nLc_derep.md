# 二、AI绘画的几次转向

起初我并没有想做宠物。航海前账号就有了，赛道换了好几轮。下面按时间线把关键转折说清楚，每个节点附带当时的判断和复盘。

## 1.1 起点其实是婚纱照

5月初在赚钱看到有人用AI做定制头像变现，AI加宝宝、AI加头像讨论很多。我先观察没立刻进去。

正好那段时间在拍婚纱照，选片时刷到一条AI加婚纱照的笔记，泡泡玛特风格，收藏数不错，评论区都在问怎么做。发帖人是素人，不是专业工作室。

我搜了一下AI婚纱方向，市场几乎空白。于是把图发给未婚妻问：如果把我们的婚纱照做成这个样子，你愿意付费吗？大概什么价位？

她回复让我意外：效果可以的话，一张一百到两百是能接受的。

于是我决定先试AI加婚纱照，除此之外还有4个推演：

1. 客单偏高且需求刚性。结婚是大事，女性付费意愿强。婚纱套系动辄数千上万，再加几百做AI衍生图放迎宾牌或视频里不算贵。年轻人吃这套，一旦形成风潮规模会迅速放大。
2. 市场盘子大。每年700万对新人*100元均价*20%渗透率，保守估算1.4亿体量。
3. 时间窗口。AI头像定制门槛低，本质是时间差红利。随着国内绘图工具普及，一年后可能人人自助生成，定制需求会萎缩。
4. 素材质量。Midjourney对底图敏感，婚纱成片质量高，理论上生成效果会更好。但后文会证实我判断失误。

确定方向后我开号了，定位婚纱照加女生头像。

## 1.2 信心受挫，卡在几个硬伤

📕号直接发帖，没做预热。5月14号首更，头像与婚纱发了一周左右，曝光基本在一百左右徘徊。

首篇内容质量尚可，却在半个月后才缓慢涨赞，说明内容本身有潜力，是账号权重问题。复盘发现起步踩了多个坑：

![](img/0aa2a5c6b0561522823feacd7ee04205.png)

1. 没养号。拿新号就发，推荐分很低。首篇前七天曝光不足200，后期持续上涨，典型权重不足。
2. 没借势也没抄题。520档期我没提前埋点。📕有复刻效应，别人跑通的选题二次发布大概率仍有流量，我当时想法太发散，起号很慢。
3. Midjourney多人精度不够，这是放弃婚纱最核心的点。双人绘画体验很差，女性可人男性崩坏，表情失真，越精细调越糟。用自己的片子试了多次都不满意，客户更难满意。SD也咨询过资深玩家，现有模型单人可控，多人困难。
PS：若男女皆为顶级颜值，成功率会高很多，一旦一方普通，成品易翻车。
4. 发布时间拖后。基本在22-24点发，作图慢，下班回家才写文案，错过用户活跃窗口。

这里也印证一个规律：没人验证的打法，多半存在未被看见的坑。几亿人里，凭啥漏掉就你发现？

## 1.3 转向AI绘画加猫咪

婚纱技术不成熟，头像赛道已拥挤。我刷到AI加猫咪的图片，数据尚可，且自己家养猫，未婚妻爱猫，后期想交由她主理，于是锁定AI加猫咪。

当时有几个判断支撑：

1. 中国宠物市场体量足够

![](img/2e45cb917e20be2b93032423709cdca5.png)

2. 主人对宠物的情感溢价。AI宝宝能做，AI猫咪同样有需求。未婚妻把猫当孩子养，进口猫粮毫不犹豫。现在单身群体把猫当精神寄托。
3. 粉丝价值高，变现路径多。市面上流传的消费力排序：女性>孩子>老人>宠物>男性。养猫的大多是中高收入女性，同时覆盖高消费人群与宠物人群，价值可观。

![](img/5b9a0b680379b918bf95174d5f98c60f.png)

实际画像男女比例约2:8，高净值女性为主，验证了预判。
4. 自养猫利于信任。家里本身有宠物，内容更真实，后续变现更顺滑。不养猫的同学不建议盲入。若未来出现稳定宠物换脸，虚拟宠物博主会很猛。
5. 宠物类内容易出效。AI之前已有大号，AI之后玩法被指数级放大。猫挤地铁、猫送外卖、猫搬砖等脑洞在AI前无法实现，灵感不愁。配合ChatGPT提词工作流，10分钟可完成一篇笔记。

## 1.7 变现路径拆解

目前累计下来大概有400多元的收入，主体都是定制单。

定制单大致分三类，前一类我建议大家谨慎接，后两类上手快，可以多接一些。

### （1）猫咪奇幻定制

就是把客户家猫的真实照片做成奇幻风格的画面。通常客户会拿我之前发过的成品当参考，或者把别人那看到的图发给我。如果要完全原创的创意，则需要额外加钱。

这一类我不建议随便接，门槛比较高。因为是真猫，客户对神似度的要求会很苛刻。我就遇到过一单，客户说不求像，结果做完后嫌不像，最后只能退钱，这种体验真的很糟。

如果要接，先让客户把猫的清晰照片发来。猫的特征越明显、斑纹越不复杂越好操作。

比较好处理的品种：狸花猫、蓝猫、白猫、黑猫。

这类单尽量配合PS来做，关键是要提前把客户预期管住！

![](img/cc3a04ea641958bbcd075d5839e244b2.png)

### （2）女生单人照

这种迪士尼风的人像图生成效率很高，直接垫图就能出图，变现也比较顺滑。

![](img/c0a49a4d3a983e301a5632520c7d4575.png)

而且很多客户生成后会直接拿去换头像或发朋友圈，这时候只要关系维护好，临走时顺带说一句让他们身边有需要的朋友来找你，可以给点小福利留存。

### （3）女生抱猫照

![](img/d2628a081d4aabd99cd40e2dcc1a5e62.png)

主要有两种玩法，一是让客户本人抱着自家猫，垫图生成；二是客户已有抱猫底图，用换脸插件把猫换掉。

具体操作手法的细节在航海手册里有整理，有需要可以再翻看。

### （4）待拓展的变现方向

粉丝基数还在积累，所以闭环还没完全打通，但理论上可行的还有三条：

（1）广告合作：女性用户画像很精准
（2）📕带货宠物周边
（3）课程售卖：最近已经有不少人来问我猫咪是怎么做的了，只是手上时间确实排不过来

## 3、用ChatGPT生成📕标题

你是一名📕爆款标题专家，掌握以下能力：

2、公式

负面刺激：你不XXX+绝对会后悔(巨大损失)+(紧迫感)
利用损失厌恶和负面偏误

二、高吸引力标题技巧
1、用感叹号、省略号制造紧迫和惊喜
2、用emoji提升活力
3、用挑战、悬念式表达引发好奇
4、结合正负刺激触发本能需求
