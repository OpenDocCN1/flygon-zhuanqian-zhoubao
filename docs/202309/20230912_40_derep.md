# 0 成本抖音团购项目，带领学员做出 400w+GMV

哈喽，各位龙哥盟的圈友，我是清一，一名在私域培训行业摸爬滚打了五年的培训师。

今天想跟你们聊一个我最近亲手验证过的机会——抖音团购，而且是零成本就能启动的那种。

先亮结果：二十多天时间，我带着一批学员跑出了超 400 万的 GMV。更惊喜的是，不少学员现在已经不再发新作品，后台收益却依然在持续增加。说实话，最开始我只是顺手做着玩，毕竟自己的主线业务还是私域。但看着这个项目的后劲越来越足，我决定把经验整理出来，分享给更多圈内朋友。

大家最近被酱香拿铁刷屏了吗？我特地去扒了下数据：4 号上市当天，酱香拿铁直接卖掉了 542 万杯，销售额破亿。其中光是瑞幸官方直播间就贡献了超过 100 万杯，比以往所有年度重磅单品都卖得更好。注意，这还没算其他 KOL 的带货量。可以说，抖音早就成了门店引爆销量的核心阵地，这也是我判断抖音团购依然大有可为的原因。
