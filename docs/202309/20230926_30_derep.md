# 同城信息流实操：三人小团队如何用一对一上门家教做到月赚近20万



## 90后创业者复盘：同城信息流切入家教，一月利润逼近20万的关键打法

大家好，我是天道。90后，连续创业，互联网圈子里摸爬滚打了八年，是个偏实战的类型。现在主攻两块方向，商业私域引流和同城信息流变现。在赚钱潜水一年多，一直在看大家的分享，很少冒泡，主要是之前做的项目不太方便公开聊。

今年4月，我把重心从网创赛道转向了同城信息流。第一个落地的项目就是本地一对一上门家教。算是试水，效果却出乎意料，6月份团队三个人合计利润就差点追上20万的整数关口。今天把这套玩法拆开来讲讲，我们到底做了哪些事。
