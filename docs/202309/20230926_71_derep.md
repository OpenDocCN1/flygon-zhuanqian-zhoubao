# 圈外收费大几千的货拉拉项目保姆级教程
作者：龙哥

最近挖到一个圈外收费大几千才肯教的货拉拉项目，我在赚钱里搜了一圈，居然没有对应的课程分享。

先说明一下：我自己没亲自下场跑过，但下面的学员有去实操，下面的内容就是根据他的反馈整理出来的。

![](img/c18bec894c005b3aba723d702273ef4c.png)

既然能叫项目，背后肯定有它的盈利逻辑，无非是赚多赚少的问题。今天把它公开出来，也是想让大家少交一点智商税。

这个玩法的核心很直白：先在某个平台上接价格较高的订单，再去另一个平台上以更低价把单转出去，赚取中间的差价。说白了，你就是个中间商。
