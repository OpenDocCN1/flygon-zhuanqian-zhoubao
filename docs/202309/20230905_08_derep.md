# 汉高祖那本封赏账单，藏了多少被遗忘的功臣？

汉高帝六年，腊月里一个叫“甲申”的日子，刘邦给开国功臣们排座次、定封赏。这件事，《史记》和《汉书》都留下了一份名单，后来读起来，挺值得玩味。

熊逸在讲《资治通鉴》时，专门把这份功劳簿翻出来聊过，其中有不少让人意外的细节。

先说大家最熟悉的“汉初三杰”。萧何排第一，赏了八千户食邑。张良更夸张，刘邦让他自己挑，说齐国境内随便选三万户都行。曹参呢，封了一万零六百户——注意，他的战功明明排在萧何后面，可食邑却比萧何还多两千多户。

奇怪吗？要知道，从战国后期到秦朝，立国封赏基本只看军功。可萧何、张良这俩人压根没带过兵，一个管内政后勤，一个出谋划策，居然也能高居封赏榜前列，这等于把“仗打得好才封侯”的老规矩给改写了。

更蹊跷的是几个没名没气的人。柳丘侯戎赐，八千户；阳都侯丁复，七千八百户，和萧何不相上下；鲁侯奚涓，四千八百户，但《汉书》说他“功比舞阳侯”——舞阳侯是谁？就是樊哙，五千户。戎赐、丁复、奚涓这几个名字，今天有几个人听过？他们的封赏却高得离谱。

这背后藏着什么？熊逸的推测很有意思：历史从来只是被记住的那部分，而不是全部。当年一定还有很多战功赫赫的人物，只是后人在写史时选择性下笔，于是大部分功臣就慢慢被抹掉了。《资治通鉴》也一样，司马光写它的主要目的，是给皇帝当教材，而不是给历史存档。

拿李广来说，名气大得不行，可论实际战绩和封赏，其实平平。无非是写史的人怜惜他，加上他命运太曲折，于是就在书里占了很大篇幅。

还有虞姬，史书中就那么一闪而过，后世却被传了上千年。反过来，项羽麾下龙且、钟离昧、项声这些能征善战的将领，如今几乎没人记得。看起来刘邦帐下名将多，说白了，因为他赢了；输掉的那一方，连被记录的资格都没了。

至于史书上写他母亲和龙交合才生下他这种桥段，明摆着是编出来的，为的是给大汉朝的合法性镀层金。

所以说，历史就是一套筛选机制，记谁、忘谁、怎么记，背后都有手在拨弄。我们读到的，从来不是完整的真相，而是被取舍过的版本。
