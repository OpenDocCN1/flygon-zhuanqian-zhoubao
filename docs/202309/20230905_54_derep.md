# 做出让龙哥愿意付费的产品：1000 个以上分享真实收入的产品和服务（MRR in Twitter)）

“1000个以上敢于晒出真实收入的产品和服务，我愿意每年花100美元来看。”

当龙哥在2023年8月23日发完这句话，别人可能只当是句玩笑，良辰美却从中嗅到了产品机会。这位老兄的日常是：做亚马逊蓝海产品，兼营公众号自动化批量操作，平时最大的爱好就是研究海外工具站。一有空，他就钻进赚钱的精华帖搜索工具，把相关关键词翻个遍。

其实龙哥对海外工具站的偏爱早有迹可循：7月28日，他放话说可以投资或收购这类产品；![](img/d5d8b47304c944dc3678eebaedec7c16.png)到了8月10日，他又开玩笑说“不做龙哥盟，我就去做海外工具躺着赚钱”；![](img/2750666bd26dae6142b3c9ba7468832e.png)直到8月23日，这条“100美元看1000+真实收入案例”的需求一出来，目的已经昭然若揭。![](img/a068e2d472f9e40fe45b6ef948b5236d.png)

良辰美第一时间冲到评论区响应，说自己“非常感兴趣”，而且不是说说而已——他真的开始动手整理，还顺手在评论区更新起了进度。![](img/5cd4a0b7ef6f8b42a4cb06ee8d96cef5.png)![](img/a4926a57f2d2d3fe41360c3b5d3aeb12.png)

如今，这份整理好的合集已经躺在了飞书文档里，名字就叫“海外工具站的收入案例合集整理：1000个以上分享真实收入的产品和服务”。内容量不小，他特意叮嘱：最好用电脑端打开，留出一整块时间慢慢看。文档指路：[`fqlleg2dnfa.feishu.cn/wiki/FfKYw5PYmil3SokojBpcxaSVnrb?from=from_copylink`](https://fqlleg2dnfa.feishu.cn/wiki/FfKYw5PYmil3SokojBpcxaSVnrb?from=from_copylink)

评论区很快就热闹起来。文轩说，隔着屏幕都能感觉到他做这件事时的兴奋劲儿。良辰美也不否认，说自己好久没这么投入了，通宵达旦都不知疲倦。静水流深更是直接表态：“100刀一年太便宜，我愿意花一万元年费，看1000个跟龙哥一样的案例。”良辰美一听，半开玩笑地接话：“要不先预付个1%？”然后他意识到，话说得再漂亮，不如真金白银验一验。他刚在Twitter上看到有人卖产品发布手册，先免费测意愿，再开收费，还搭着咨询赚了几百刀。于是他也打算“卖空气”，用真付费来验证需求。

没想到，静水流深真就打了200元过来，成了第一位付费客户。良辰美既激动又清醒，他通报了这件事，还立了条规矩：凡在本帖打赏200元的圈友，都能低价拿到这些1K MRR案例。知识星球会抽成20%，其中实际收入的十分之一，他会反馈给赚钱。具体细节都写在了飞书文档里。海外工具站的同好们，可以来围观了。第一步已经卖出去，下一步就看龙哥那一份什么时候拿下。![](img/1c37d505930596d12a88ab23e11aa07a.png)
