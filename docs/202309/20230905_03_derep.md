# 独立把点子落地，才是那种让人上头的快乐



## 一个人靠自己把新东西做出来，这份爽感无人能替代

日期：2023-08-29

昨晚的满足感，全来自 ChatGPT。

我对技术基本零基础，但靠它的手把手带教，我还是成功装上了 Python，并把某个网站的数据爬下来整理成表，最后导出完成。

对我而言，这不只是完成了一个小任务，更像是一个转折点。

有种重新获得行动力的畅快，像忽然长出了翅膀，也像之前断掉的手臂重新接上了。自从买了车后，很久没有过这种行动范围被拓宽的自由感了。

过去，要把一个想法跑通、验证，往往得找人配合、靠团队推进。可信息在转手之间会打折，机会窗口也等不了沟通成本。

从效率和产出来看，让团队去执行具体的活儿，自己只盯战略和方向，才是最优解。

但换个角度说，真正属于个人的满足，恰恰来自于：不求助、不依赖，自己亲手创造出一件从无到有的东西。那种快乐，是外包不来的。
