# 二、核心拆解

## 01. 人设要站得住

人设其实就是性格、节奏、定位、领域、战绩等综合后在别人心里的那个“你”。

概念大家都懂，懂了就容易踩坑。所以先把人设拆成两部分看清。

### ① 正确打法

一个可用的公式：真实+选择性隐藏+专业+战绩=人设。

#### 1. 真实 30%

用现实的性格、特质、爱好做底，不要过度美化。线上呈现要和线下一致，不造假、不编故事。

如果你上来就造假，比如说自己是10年演讲家、到处拿奖，那你就要永远记得每一个听众和你说过的每一句话，自媒体信息是互通的，假的迟早穿帮。

真实不等于全盘托出。吃喝拉撒的日常全倒出来，既做不了IP，还会把精准读者劝退。

所以要有意识地做第二步：选择性隐藏。

#### 2. 选择性隐藏 5%

不是欺骗，是策略性收敛。把对定位无益甚至减分的真实细节藏起来。

比如我的定位是写作，就没必要把我爱做饭、逛超市买菜的日常硬塞给读者。这些琐碎和定位无关，过度分享只会拉低专业感。除非你是做美食或生活类。

偶尔点到为止的私生活能拉近温度，但一定要克制，别变成生活流水账。

#### 3. 专业度 55%

个人IP本质就是某个领域的活百科，比书更快、更省时、能避坑。大家宁愿跟有结果的IP学，也不愿自己啃书自学。

但有结果不等于专业，你需要的是可感知的专业度。

##### 知识量

专业的第一眼门槛是知识储备至少70分。我的做法：

Ⅰ. 精读当下有效书籍，持续补仓。
自学是起点，导师是加速器。先自学打底再跟师，否则容易形成依赖、抗压弱、应变差、没有自我判断。我的入门书单：

《精进：如何成为一个很厉害的人》
《戒了吧！拖延症》
《逆转思维》
《有钱人和你想的不一样》
《世界顶级思维》
《如何成为一个会学习的人》

同时紧跟行业新闻、政策变化和圈内动态，把对自身发展的信号提炼出来结合使用。

Ⅱ. 主动求教，破圈进高质圈子。
认知是被不断打破再重建的。你在低维圈子里很难突破60分。能付费就付费进社群、训练营，接受批评，从高维思维里学方法，然后把经验转化成对低维人群的输出。

注意，遇到问题不要上来就问，先自己消化。依赖式提问和有效求教是两回事。

##### 敏感力

专业不只是知识，还有眼力见。因材施教就是专业交付。

心理咨询师能筛选出执行力强的客户，就是敏感力。能捕捉领域相关信号、懂得定制化表达，才叫真专业。

##### 思维逻辑力

能把新信息快速理解、过滤、整理成清晰表达的能力。

说半天理不清的人，专业度很难被信任。逻辑是思考后的二次加工，能自我修正、抓本质、做预判。

比如看到行人让车：A只停留在吐槽，B能上升到“退一步的思维”，C能延伸到规则与变量的博弈。C的层次更高。

#### 4. 战绩 10%

信任的直接背书：收款截图、咨询实录、价值长文、变现结果。

我在阿猫老师的觉醒者·IP创业营星球日更20篇价值长文，连续4周上周刊，月榜第2，单月15颗觉醒果实；个人品牌变现攻略获多篇精华，20+和平星碎片，周榜第1。

《新手小白写作避坑指南书》电子版变现1000+；12年经验浓缩成资料包和课程变现3000+；4个付费社群预售单日1000+。

看到这些战绩，别人自然会想：学写作找谁？找微微。

这就是及格线以上的IP感。

### ② 常见翻车

人设是地基，翻车就全盘崩。

1. 真实：只讲真事，不要加料。没特殊经历就把读书到现在最有记忆点的事做成记忆点。
2. 隐藏：藏住自卑、不擅长的暴露面，放大优势面。别自暴自弃说自己每天刷手机，反向包装成“深挖刷手机危害”的研究者也行。
3. 专业：别不懂装懂、搬运冒充、皮毛授课。别假大空。
4. 战绩：没做过的事别夸大、别造假。自媒体信息流转快，别因小失大。

## 02. 知识蓄力

蓄力是知识量的进阶，重点是“为什么要学”。

### ① 链接的机会

无论新手还是高手，都需要破圈。资源、人脉、信息有限时，你很难凭微弱成绩接触到前辈。核心原因是你没价值。

自媒体让大佬触手可及，但前提是你的知识能帮别人解决问题。知识储备不足，价值感就薄。

### ② 成为优秀的跳板

1. 情绪：学识能帮你稳定情绪，减少内耗。能自洽的人才能持续输出情绪价值，治愈自己也影响他人。
2. 情商：书中自有黄金屋。学识让你更懂得敬畏学习，更愿意换位思考。越学越谦卑，越谦卑越受欢迎，人脉随之扩大。

### ③ 赚钱的唯一装备

人永远赚不到认知以外的钱。没时间试错时，提升认知最快的方式就是摄入知识。

大量储蓄知识、信息差、工具、方法，当蓄力到临界点，只需一个时机就能爆发。

## 03. 受众群体

有人问：我也日更200天，为什么没效果？

因为日更要有指向。没针对特定人群输出价值，再多天数也是白费。

### ① 定位要细

你擅长什么、能交付什么、能给对方什么，这些决定你的受众长什么样，也决定你在哪个平台发声。

别用大学生视角去教小学生情感，也别用没谈过恋爱的人去讲婚姻。

我的受众是关注写作、认知、自媒体的人，所以内容只围绕这三点展开，平台选知识星球、📕、👸号、知乎这种重干货的地方。

### ② 先备见面礼

见面礼是第一转化点。无门槛的价值会让读者产生好感和期待。

蓄力时自然会沉淀出干货。我的礼包分写作、认知、自媒体经验、知识管理四类，新人进来就能即拿即用，后续转化顺滑。

更深一步，要做用户画像：爱好、日常、工作、价值观、大众印象、小众特质。把用户当项目研究，抓住表层需求和深层渴望，才能留住铁粉。

### ③ 定位公式

你的擅长 + 感兴趣的人群 + 你的性格 + 人群接受年龄 + 你的内容形式 + 人群活跃地

例如：
写作 + 小白投稿者 + 温和细腻 + 35岁以下成年人 + 写作干货 + 知识星球读者圈

答案立刻清晰。

做个人品牌的第一步，我先去读者圈的知识星球里把目标人群摸清楚。数据给我一个很清晰的信号：年轻人最活跃、点赞评论最多的时段，是早上7点到9点。

于是我把发文时间卡在这个窗口，而且内容调性也跟着时间走。清晨的人需要被抚慰，而不是被鞭策，所以我选择上治愈系的文字，让人一睁眼就能共情，进而对这个背后的人产生好感，想进一步了解。

### 真诚利他的本质，是把用户思维用透

说到底，真诚利他之所以能让人心里发烫，是因为它同时满足了三层逻辑，这三层逻辑就是用户思维的运作方式。

所谓用户思维，不是单向地去推销，而是把我自己的视角和读者的视角叠加起来，找到重合的那块区域，再从这里展开。

这块重合区，通俗点讲就是痛点、爽点、痒点。

很多人写内容写成了说教，读者天然会有防御心理。所以我会刻意避开“老师上课”的口吻，改用“医生诊断”的视角。不是去命令别人改好，而是先点出不改的代价。因为人本能地会先保护自己，当你先说清楚危害，他才会愿意听你给解法。

带着保护读者的心态去输出价值，这才是真诚利他的样子。

**① 痛点：放大害怕，再给安全感**

痛点说白了就是让人心里咯噔一下的那个字：怕。

先挖出读者此刻最焦虑、最不想面对的东西，把它讲透，让他意识到继续这样下去会怎样。讲完危害，再递上回到安全区的路径，人性自然会把这份帮助记下。

比如同一件事，我可以犀利也可以温柔：
快行动起来吧，再继续下去只会让自己更被嫌弃。
你未来还有那么多想拥有的幸福，如果身体垮了，谁来承载？
核心是先让他感受到风险，恐惧起来了，才会有行动的意愿。

**② 爽点：即时满足，立刻上头**

爽点就是需求产生、当下就被兑现的那种快感。读者脑子里刚冒出一个期待，你的内容立刻给他一份可用的反馈，欲望被迅速填满，大脑就会分泌多巴胺。

这和游戏的充值逻辑一样：卡关了给提示，过关了给奖励，正反馈循环起来就停不下来。

放在写作上，如果读者觉得自己写得很差，我就直接给一份立刻能用的工具：300字短文案的写法、三个可套用的公式。五分钟就能出成果的那种。快速见效会让人上瘾，一旦尝到甜头，他会主动留下来等你下一波更深的内容。

**③ 痒点：描绘未来，点燃想象**

痒点相当于画大饼的进阶版，是对未来的期待管理。

每个人心里都有一个理想的自己：更会说话、更有收入、生活更松弛。如果你能把这个未来的可能性清晰地摆在他面前，比如30天语言训练营，从 socially awkward 到口才在线，他的好奇心和行动欲就会被同时激活。

这里的关键是真诚+交付。你可以按他的关注方向去承诺改变，但一定要能兑现。重交付也好，轻交付也好，都要在自己能力范围内。只要有一个人因为你真的完成了蜕变，你的案例库就多了一枚勋章，外界对你的信任度也会跟着上升。

把时间锚点、情绪调性、用户思维的痛爽痒三点串起来，再用日更的频率持续输出，这就是我实践下来，能稳定链接到精准读者、把陌生人变成粉丝的操作闭环，实测有效。
