# 零基础也能玩转抖音知识付费？一个大二学子的低成本第一桶金实战复盘



## 从高考物理到中医引流，一个19岁学生的知识变现路径

核心问题拆解成两点：

1. 完全的新手，如何借助抖音做知识付费，用极低成本拿到第一桶金，并且沉淀出可持续的长尾收益？
2. 做教育类IP，该如何避免“割韭菜”的质疑，实现长期主义的增长？

大家好，我是龙哥，00后，03年生人。刚结束暑假升入大二。这段时间主要在操盘一个中医粉丝引流的项目，家里本身就有中医产品线和线下实体店。

很多人可能不知道，我大一下学期就已经完整跑通过一个高考物理的项目，并成功拿到了人生第一笔可观收入。现在这个项目沉淀下来了一批学生私域，仍然在持续产生长尾转化。今天就把当时的完整思路和经验，毫无保留地拿出来和大家聊聊。

因为当时操盘时我还在读大一，所以最初的项目笔记标题就直接叫做“大一学生”。

这算是我第一次写这么长的复盘，也是第一次亲手落地的变现项目。认知和表达上肯定还有不足，文中如果有逻辑不通顺的地方，还请各位前辈多担待、多指正，感谢收看。
