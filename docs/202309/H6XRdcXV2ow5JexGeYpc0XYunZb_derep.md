# 从零粉到万人同屏：两次登顶电商知识付费直播的实战复盘

我是智豪。2021年4月离开大厂创业，到现在已逾两年多。期间踩坑不少，也收获了可验证的成绩。

这两年我一直在做知识付费直播。第一个项目是抖音电商方向，累计成交超过500万，我个人直播间最高同时在线破1万，单场到账4万+。![](img/e238635ee063f105dbd415511ed7d2cc.png)

同样的打法，我又作为负责人复制出了多个千人级别间。目前小红书电商赛道里的头部账号，绝大多数来自我们的“红商学院”。今年在抖音关注小红书电商的话，很大概率会看到我或团队成员。![](img/ec2b4ac90a630305316d151a315c3f25.png)

严格来说，这两条线都属于电商知识付费的分支，但受众画像完全不同。抖音电商用户以男性为主，诉求是创业；小红书电商用户90%以上为女性，诉求是副业。思维偏向也不同，男性偏理性，女性偏感性，因而内容形态、呈现方式和课程转化逻辑差异很大。

能在这两条赛道都获得头部成绩，说明直播的底层逻辑、思维模型和执行能力经得起市场检验。我在项目中同时承担主播、操盘和发起三重身份，从立项到一线全程参与，因此对该模式有自己的理解。下面就从这三个视角，把知识付费直播的内在逻辑，以及我两次登顶的过程做一次还原。

# 985理工直男，如何同时服务男性和女性用户

### 1.1 万人同屏的直播内容是如何打磨出来的

回到2022年1月，那是我播出生涯的第一段低谷。此前我每日直播2小时，场均变现过万，后因短视频违规账号被封。重开时我选择了最激进的路径：零粉丝零作品直接开播。

对当时的我而言，这是全新尝试。于是用整整一个月的时间打磨内容与表达，从80人场观逐步迭代到10万+。

先展示当月数据，完全来自内部复盘，真实可查。期间没有短视频导流，也没有付费投流，电商类干货直播因营销属性本就难以投放。![](img/eb19895178a6b49ef60e0c9b99c7a211.png)

![](img/10a1f35d28541d25d75a29f273a3f8d2.png)

具体怎么做？我拆成场、货、人三层来讲。顺序是场货人，不是传统的人货场。因为新用户进入直播间，对你毫无认知，第一眼看到的是画面。场景合格才能留住精准人群，场景失分后面就难补。

**场：画面要具备差异化与反差**

人眼对视觉的信息处理速度高于听觉，所以画面布局要充分利用屏幕，把能锁住目标人群的信息点都呈现出来。既要点明主题，也要抛出能让用户快速代入的钩子。

我把画面迭代的过程留了下来。起号期几乎每天根据体感微调。

起初是用手机对着电脑屏，屏幕里只有纯内容框架。那时电商直播间大多如此，千篇一律，毫无辨识度。![](img/450e5fecdcb672ed14815c339fcf6f5d.png)

随后我做了个改动，后来看效果非常显著：画面上半区放店铺实时成交数据，且必须是真实且夸张的，下半区放脑图知识点。当天就见效，坚持这个结构播了半个月，流量层级一路突破，直达万人。![](img/eeff19ddcf854c3e2834367652e7a778.png)

最终版定为三层：顶部主题横幅，中间店铺实时数据，底部脑图或PPT。此后大量电商干货直播间都在模仿这个结构，如今在抖音仍能看到它的影子，最早的出处在我。![](img/c6d0776b9b83e294a1ac3351fae669f4.png)

![](img/2e0595fb8ea79435d03b9372115321dd.png)

**货：知识付费的货是每句话**

电商直播卖的是手里拿的产品，知识付费卖的是口中输出的内容，包括干货、观点以及语气节奏。

我把“货”分为三类：
干货：提供实用价值，占80%。要清楚客户痛点在哪，哪些疑点最能激发好奇，哪些环节实操易卡壳，围绕痛点不断打磨，形成标准内容框架。
观点：提供认同或打破认知。通过案例植入观点并不断强化，让听众认可你的判断，从而愿意跟随你的节奏。
情绪：提供情绪价值。内容是剧本，主播是演员。平铺直叙会让用户觉得枯燥，抖音用户的本质需求是消遣，缺乏情绪起伏的直播很难做大。

完整剧本加合适演员，就能做出稳定的知识付费直播间。主播只需在固定时间重复演绎同一剧本并保持呈现质量，结果便可复现。

**人：靠心态而非人设**

我不靠短视频包装人设，粉丝对我的认知不够立体。所以纯靠颜值闲聊很难留人，必须靠场景与内容，但“人”依然关键。

发挥空间主要在两点：一是对内容的理解与演绎。脚本是打磨好的，但主播若缺乏电商经验，就必须先吃透内容，讲起来才能清晰、条理、细节到位。二是播出时的情绪与状态。基础能力合格后，情绪状态直接影响转化。

情绪状态难以言传，但影响极大。其根源我认为是发心。若发心是卖课割韭菜，表现会显得市侩，带营销味，人格魅力不足，难以获得信任。若项目靠谱，内容有用，心态是分享，则能卸下包袱轻松上台，观众感受更舒适，转化自然发生。

标准化流程包含三个环节：播前准备、播中执行、播后复盘。

我们对主播行为有明确规范，详细列出了播前播中播后的具体事项。![](img/310d36276af48738621e68e2b8df27d2.png)

![](img/a9c0be948aabfa7fc589c2b6dd0698dc.png)

一套机制下来，直播就变成一台小话剧。主播是演员，话术是剧本，每次开播就是重演同一出戏。

### 1.3 心态是顶级主播的底座

抖音是放大镜，优点缺点都会被放大。直播间曝光越大，盯着你的人越多，举报风险也越高。真正的大主播都经历过断播。

断播对纯自然流直播间打击巨大。可能前一天8000人在线，被举报后第二天剩3000，第三天峰值1000。这时心态就是生死线。

心态一旦失衡，播出质量必然下滑，流量会进入负循环。抖音极具现实性，不会给予太多纠错机会。今天表现不佳，明天只会更差。

因此主播必须保持强韧心态。每当感觉播不动时，要提醒自己坚持，今日不佳则明日更难。抖音主播永远是为明天的数据而直播。

# 零经验新人，如何七天从零到三千人直播间

很多人认为人才只能筛选不能培养，我持不同看法。人与人之间的差距有限，若体系完善，训练出来的概率很高，因而平台和时机很关键。

即便是纯小白，经过正确学习训练，也能月入十万。我们有一名男主播，原本做直播间运营，从未开播。经过不到半个月集中训练，在项目红利期稳定做到千人在线，连续两个月月入十万+。

### 2.1 哪些人适合投入培养

零基础新人做知识付费直播，通常要经历三个阶段：
纯学习期约3-5天，反复观看成熟主播录屏，理解并拆解内容框架。
练习期约5天，试播，看能否完整串联内容并做到生动亲和。此环节靠操盘手经验判断。
成熟期，熟练标准内容后，按起号节奏推进，约半个月可从新号做到稳定自然推流。随后学会应对突发状况并逐步形成个人风格，才算成熟。

我们招聘流程即为10天学习期，每天补助150元。前三天熟悉逐字稿和框架，之后开始自主串播并录屏。我会根据录屏点对点优化问题。学习期后公司提供设备与账号正式上播，一周左右可判断是否可行。已测试数十人，最终保留约十人。

能保留下来的共同特征：
性格外向。内向寡言者即使内容流畅也缺乏吸引力。
心思细腻。对观众有同理心，能预判说出某句话后的反应，从而把握话术重点。
有过起号成功经验。已有成功案例者再次成功的概率略高，但非决定性因素。

### 2.2 像素级模仿的方法论

看一个标杆数据：纯新号7天提升到1000+在线。![](img/67f863732aae02b02f0890729ccded22.png)

标杆明确后，新人只需做一件事：拆解内容并做到1:1复刻。

很多人模仿不成功，根源是拆解不细。我们拆解四个维度：
画面呈现。最简单但最需细心。
话术。每个人表达习惯不同，场控会捕捉主播无意间说出的金句并固化为必讲内容。犯错时，若能自圆其说则不干预，若无法自洽则提供标准答案。
场控配合。90%以上观众不重合，场控需在固定节点抛出话题做捧哏，并及时处理负面信息，维护主播并扭转氛围。
数据。自然流核心看人均停留、涨粉率。复盘表中有体现。流量上不去时，通过数据对比可定位短板并针对性强化话术。

### 2.3 内容迭代是核心

知识付费直播的核心是话术，但优秀话术不是闭门造车憋出来的。内容迭代通常经历：
广泛收集同行选题。
结合行业与用户理解，提炼用户最关心的选题。
汇总后选出3-5个典型问题，构思话术结构。
试播，根据数据与评论反馈不断调整选题与表达方式。
稿件成熟后框架固定，只做微调、换案例、增互动趣味。

关键在第四步。这个过程可能持续很久，一个成熟稿子定型前可能经历数十次修改。

反馈依据主要有：
录屏。尤其前期要全量录屏，不定期下载弹幕分析，直播间问题即用户最直接诉求，也能反映人群属性。![](img/e46985595d0989cd01efeed6ddf1db21.png)
记录每个选题对应的在线人数变化。在线人数是最直接的观众反馈，话题不吸引人则观众直接离开，吸引人则在线人数持续攀升。

总之，要对内容做多维度切片研究。凡有结果，必有路径。

# 什么是知识付费的蓝海战略

这是许多老板和操盘手关心的话题。不同层级老板对蓝海的定义不同。我仅以个人经历做分享，欢迎探讨。

知识付费长期背负割韭菜标签。我认为不管交付质量如何，任何项目只能保证部分人成功。抛开成功率，是否属于割韭菜，主要取决于三个维度：产品营销方式、目标人群层级、实际交付效果。

三点想清楚，就能判断一个项目是蓝海还是韭菜地。

做培训最致命的坑，不是项目不行，而是把效果吹上天。一旦开始过度承诺，无论你的学员是零基础新手还是行业老手，本质上都是在割韭菜。反过来，只要不玩虚的，在这个价位上把应有的产品和服务给足了，甚至用自己的核心壁垒去提供别人拿不到的资源和服务，这就完全是另一回事。再有人质疑，也就随他们去。

当然，市场上确实存在靠知识付费做得非常大的公司。他们的项目本身成功率很低，靠包装和投放活着，只要广告还能投，就砸钱往里砸。这种模式好不好，我不评判，价值观不同，选择也不同。

我们在决定做一个项目前，会先从三个维度做冷启动判断。

第一，看成功率。项目必须有足够多的正反馈才能撑得住。公域直播带货，流量是双刃剑，只有学员真能做出结果，才有复购和升单的可能。

第二，看投入产出比。我带的抖音小店学员里，有人一年到手净赚400多万，月入过万的更是比比皆是。选项目的核心就是看天花板够不够高，案例是否能持续产出，这样前端才能安心做流量、做转化，也才有弹药去讲故事。

第三，看是否真适合普通人。字面意思，门槛越低、受众越广，后续获客成本和难度自然越可控。上手难、圈子小的内容，流量贵得离谱。

当这三点都成立，我们才会说，这个项目值得去挖掘。注意，只是值得挖掘，能不能真去测，最后要看的还是项目的话题潜力和热度走势。

雷总那句话说得好，要顺势而为。热度会不会继续上涨，本质上就是看有没有势。

比如2021年，抖音大力招商，平台急需商家，那时候去做商家培训，就是顺着风口走。再看现在，无论是抖音、小红书，还是早期的淘宝，平台都在严打无货源电商。这时候再去做相关的电商培训，不是说绝对没人做，而是已经逆势，难度越来越大，投入回报已经不划算。

3.2 知识付费行业接下来会走向哪里？

过去几年，伴随抖音、小红书的爆发，知识付费经历了野蛮生长的黄金期。信息差足够大，卖课就能一本万利，造富了很多人，也诞生了很多白手起家的故事。

但现在，这个行业已经进入大洗牌的关键节点。依然有很多人看不懂原因，但行内人都清楚。当前行业呈现出几个非常明显的特征：

行业乱象丛生，用户越来越精，决策门槛和决策周期都被拉长了；
负面案例太多，平台承受不了舆论压力，必须出手管控内容；
受政策导向影响，涉及 Zc 相关、弱势群体保护、减负育儿等内容，审核越来越严。

但换个角度看，这也正是劣币出局、良币上位的时候。在这个内容环境下，能活下来的，基本都是靠谱的。

做培训的IP想活下去，只能把重心放在质量上。课程内容要扎实，产品要过硬，服务要跟上。纯靠信息差、纯靠销售话术获利的时代已经过去了。那些只提供空气感服务的培训机构，最多就是换个名字再开张的游击队，成不了气候。

社群的演变也是一样。几年前私董会、付费社群遍地开花，现在能持续续费、稳定存活的，已经是头部天花板的水准。

对照社群的逻辑，知识付费的未来其实就两条路：

第一，真正提供可感知的产品价值；
第二，提供与价格匹配，甚至超出预期的服务。

其他的都是锦上添花。知识付费正在像传统行业一样，回归到产品和服务的本质。
