# 自媒体入门必修课，社交礼仪

做自媒体想走得远？先补上“社交礼仪”这门课。

今天想和你说个真实的小故事。有位做了多年写作指导的博主，之前一直免费帮人改稿、答疑，常常深夜还在回复消息，甚至熬夜到凌晨三四点，腰酸背痛也没停下。就这样持续了快八个月。可当她终于决定开启付费咨询、付费改稿的时候，评论区却炸了——有人骂她、有人讨厌她。原因很简单：你一直免费给糖，突然不给了，有些人就会翻脸。

这个故事让我感触很深。它揭示了一个扎心的真相：**我们真的没必要讨好所有人，因为并不是每个人都懂得感恩。**

当然，这不是说我们要去跟人抬杠或冷战。无论线上还是线下，人都离不开社交连接。只有被别人看见、了解、认可，影响力才能慢慢长出来。而这个连接的过程至关重要——它影响你的口碑、人设、能力能否被顺畅传播，也决定了你在圈子里的声誉，甚至长远地影响未来的发展机会。

所以，**双向的“社交礼仪”显得格外重要。**

它不是客套，不是讨好，而是让别人舒服、也让自己体面的边界感。能分寸恰当地表达尊重，能及时回应善意，也能从容拒绝消耗。

这篇内容其实挺长的，作者还专门整理了近万字的完整版，我把它放在文末的飞书链接里了，想深入学习的可以去看看。

评论区里有人说得特别真实：以前加了不少群，遇到过各种奇葩，上来就说要“链接”，像网线一样到处硬接，结果彼此时间、精力都被消耗得够呛。

是啊，真正体面的社交，从来不是绞尽脑汁去攀附，而是先把自己修好，再用对的方式与外界相遇。

对你有启发的话，不妨从今天开始，注意你的线上礼仪，也尊重别人的边界。
