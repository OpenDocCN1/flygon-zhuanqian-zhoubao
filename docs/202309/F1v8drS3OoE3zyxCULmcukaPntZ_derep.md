# 用 AiGC 撬动小某书爆款：从数据预测到对标实操（上）



越越在此开篇。一个整天鼓捣 AiGC 工具的老玩家，也是小某书全站 6w+ 粉丝的内容作者。

我生在小商品之都，习惯用 AiGC 技术去解决生活和工作里遇上的各种效率难题。这次很幸运，成为九月的“赚钱航海”计划中 GPT+内容分队的一名志愿者，准备跟着大部队一起下水，把手弄脏。

必须承认，AiGC 做内容平台运营，完全走得通、能落地，也能把效率抬上一个台阶。但它的定位始终是辅助工具，真正的主角还是人。只有反复调教、不断试错，才能在这片 AI 的深水区里越走越远。这篇内容只提供思路和方向，模型本身还不够成熟，需要持续迭代和优化。

# 传统小某书运营，到底痒在哪

1. 拿数据太费劲，成本不低，而且多数人拿到手也不知道该怎么读。
2. 凭经验去挑参考号，样本小，不严谨，也不够科学。
3. 平台上的内容越来越像，想做出辨识度难上加难。
4. 写文案、设计主页都是体力活，忙活半天还容易跟风翻车。

# AiGC 可以补哪些缺

1. 把数据摊开来看，随时调整打法。
2. 高效率锁定参考账号，需要换方向也能快速转身。
3. 盯住全站流量走向，在大风来之前先站好位置。
4. 主页设计也能省心不少，既省时间又省钱。

# 第一步：先搞明白自己要什么

根据自己的实际目标，决定要抓哪一类资料。

【核心词】：准备切入的赛道主词。
【扩展词】：由主词延伸出来的长尾热词，可以在搜索栏的下拉联想里找。
【带货向笔记】：与你的变现目标一致的笔记，想卖货就去找带货型博主当样板。
【商单笔记】：由平台和品牌合作发布的笔记，整体质量较高，也值得参考。
【低粉高热度笔记】：粉丝基数不大但数据很抢眼的笔记，通常内容打法有亮点，是快速找参考号的最佳入口。

注意：限制条件设得越细，能抓到的结果就越少，反而容易漏掉一些真正优质的博主。所以可以从【带货向笔记】和【商单笔记】这类口径里适当放宽。

# 第四步：给文档起好名、归好类

想让后面分析不乱套，先把这些文档统一编号和归档。

- 话题文件分别存为：话题2.csv、话题3.csv、话题4.csv、话题5.csv。
- 热词文件分别存为：热词2.csv、热词3.csv、热词4.csv、热词5.csv。
- 笔记和博主资料汇总成一个文件：原始资料A.csv。

尽量把所有文档放进一个独立文件夹，命名要短、要容易辨认。

![](img/dbcf42e59ddb0831cb37ef033354e07d.png)

# 第五步：清洗数据，别怕麻烦

整理和清洗资料，是整个预处理的重头戏。核心目标是把错值、缺失项、不一致的地方找出来并修好，让整体质量过关。

这一步可以交给 AI 代劳，也可以在 Excel 里手工完成。具体操作可以参考网上的清洗教程，过程中务必把最初保存的原始文档和清洗后的新文档都留好。

# 让 AI 接过分析棒

## 先搭环境

代码解释器（Code Interpreter）以 GPT-4 为内核，算数学、画热力图、跑分析都能做，出来的结果质量很高。

准备步骤很简单：开通 GPT Plus → 打开代码解释器 → 上传你的资料包。

点面板上的上传按钮，一次最多能传 10 份资料，大部分格式都能识别。切记不要一次性全扔进去，要按顺序分批来。

## 先让 AI 读资料

给 AI 发一条学习指令，让它先把已有资料读完，并给出理解反馈。之后每个小环节，都必须让它先表态，再往下走。

```
背景：📕平台上许多零基础的博主需要提升他们的运营质量。
角色：一位资深数据分析师，专长📕平台数据分析。
任务：
1\. 加载并命名为【数据集A】的文件。
2\. 学习并理解该数据集的内容和结构。
3\. 完成学习后，回复“OK”以确认。
要求：在整个过程中，请确保使用中文与用户进行交互。
```

```

2\. 学习每个文件的列名定义和用途。
3\. 当接收到关键词【话题】，选择并理解【话题2】、【话题3】、【话题4】和【话题5】这四个文件。

## 开始训练模型

现在进入评分和模型训练环节：

```
任务：制定“综合评分制”规则，从数据层面评估笔记、博主的质量与发展潜力。
步骤：
1\. 加载【数据集A】、【话题】、【热词】数据集。
2\. 使用"特征重要性"方法，选择特征和目标变量，并处理非数值数据，保留笔记标题、笔记类型、博主名称、达人等级、笔记内容、红薯号、达人属性、红薯等级等列原始数据。
3\. 使用随机森林模型进行训练。
4\. 根据特征重要性分析，输出每个特征的权重。
5\. 使用【爆文笔记详细信息】数据，计算笔记得分。
6\. 结合【博主详细信息】和质量指数、历史数据变化，计算每位博主的得分。考虑合并近7天、近30天、近90天的点赞、收藏、评论和分享数据为“近期互动数据”。
7\. 结合【话题】和【热词】数据，分析大盘趋势和外部流量影响。
8\. 结合笔记得分、博主得分和大盘趋势，计算综合评分。对于多次出现的博主，取平均得分。
9\. 对于相同综合评分的笔记或博主，使用近7天互动数据、质量指数、近30天和近90天互动数据进行排序。
10\. 使用统计方法和随机森林进一步分析数据，计算未来爆款的概率（如果笔记的【预估阅读量】高于90%分位数，，则认为它是“爆款”），预测未来可能成为爆款的笔记或博主。
11\. 将得分标准化为100分制，并使用合适的算法增大分值差异度。
输出：综合评分和爆款概率（百分比表示）。
```

2\. 筛选数据集，选择笔记类型为“【图文】”，粉丝数少于【1000】人。
3\. 根据综合评分，对筛选后的数据进行降序排序。
4\. 选择综合评分最高的前【5】个账户。
5\. 按照以下格式输出：
【博主名】：
【红薯号】：
【笔记类型】：
【粉丝总数】：
【质量指数】：
【水平段】：

```

## 把规则固定下来

最后再给它交个底，明确告诉它“把以上所有规则存进记忆”。往后只要你发一个指定词，它就能自动匹配出对应资料。

```
请你请记住以上所有内容，当接收到【博主名称】、【变化趋势】等信息时请输出对应数据分析。
```

## 趋势预测能做什么

基于这套已经跑通的模型，还能进一步预判某篇笔记或某个博主的未来走向。当然，前提是样本量要够大、资料质量要够好、字段特征要够典型。

目前这个模型能给出一个互动规模的大致预判；更细的预测方法就不在这篇文章里展开了，感兴趣的圈友可以私下来找我一起研究。

## 效果怎么检验

接下来，我会根据最终得分选出的备选账号做持续追踪，并把反馈结果陆续更新到这篇文档中。

很多人会问：AI 分析出来的东西，真的准吗？

说实话，最终精度受很多因素牵制。比如资料质量，特征怎么设计和筛选，选哪种模型、参数怎么配，样本够不够多，有没有偏好，训练方式是否合理，评估标准是否科学，时间或空间上的变化，外部变量，甚至信息泄漏，都可能影响结果。而其中最关键的三块是：资料本身的质量和代表性，特征设计得好不好，以及模型的复杂程度和参数设置。

所以，这个 AI 需要你不断“调教”，数据采集和处理流程也要持续优化。

从这次实践也能看出来，GPT 不只是会写文案、做办公辅助，它还能在深度数据挖掘里发挥大作用。
