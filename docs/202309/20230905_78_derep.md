# 堆砌功能是产品大忌

做产品最容易踩的坑，不是功能不够多，而是功能做得太满。

很多时候，你以为自己是在丰富产品，其实只是在用战术上的勤奋掩盖战略上的迷茫。功能越多，越像没想明白的人随手撒了一把种子，看着热闹，却不一定能长出一棵结出果实的树。

一款产品如果缺少对商业底层逻辑和真实用户场景的深挖，那么所有的“加功能”都可能变成自嗨式的努力。你不断填东西、补模块，最终换来的可能只是一堆没人点击的按钮，和被冷落的产品页面。你以为自己至少“在推进”，这种感觉很充实，但这种充实本质上是一种安全幻觉，用忙碌掩盖了真正该想清楚的问题。

真正应该问自己的是：这个功能为什么存在？它在什么情境下被谁需要？它能推动什么核心价值？如果这些问题答不上来，那么接下来的每一项功能新增，都只是在给产品增加重量，而不是价值。

好的产品设计不是做加法，而是懂取舍。想不清楚的时候，克制，先别加功能。
