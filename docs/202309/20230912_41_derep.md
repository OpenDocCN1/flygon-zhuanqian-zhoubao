# 抖音图文怎么快速跟款？这个小工具让你“自动盯同行”，异常款一抓一个准！
作者：龙哥

昨晚听坤哥聊选品跟品，他给了一个特别朴素的思路：先关注一批做得好的同行，然后每天固定几个时间段，去刷一遍关注列。听起来不难，但真要手动去刷，既费时间又容易漏。于是我就琢磨，能不能让程序替我做这件事？

我用影刀搭配模拟器写了套小工具，把“动手刷抖音”直接变成了“自动化监控”。你要做的就是先定好异常值的判断标准，比如连续刷个5到10分钟，重点盯着发布5小时内、点赞过100的图文；只要符合条件的，程序就会自动截图，然后存到C:\截图目录下（记得先手动建好这个文件夹）。整套方法我已经整理到飞书文档里了，链接放在下面，有需要直接取。

顺便把大家常问的几个问题也捎上：有人担心会不会封号，作者的回复是“不会”；有人反馈模拟器里打开抖音会闪退，这个可能需要检查下版本兼容；至于Mac用户，暂时还没有对应版本，因为影刀在Mac上很多功能还没跟上。
