# 中产，本质上是一场经济红利的修行
作者：龙哥

很多人把“中产”想成一种身份标签，住大房、开好车、周末出国。其实它更像一个时代的副产品。

当一个国家进入高速成长的窗口期，经济保持中高速运转，支柱产业快速抬头，互联网、房地产、金融等领域一口气打开大量高薪岗位与创业窗口。与此同时，房子、股票这些能够沉淀财富的工具也逐步成熟、完善。

在这套组合拳之下，总有一批人抓住了机会。在“赚多少钱”和“能攒下多少”这两条线，都明显跑在了社会平均水平前面，于是被归入了中产的阵营。

这份阶层的舒适感并不是凭空修炼出来的，而是被经济的体温托起来的。只要蛋糕还在做大，分到手里的那一块也在变厚，中产才有松口气、谈品质生活的底气。

反过来，如果经济增速明显放缓，新岗位变少、资产端承压，之前靠红利上来的差额就会被拉平。没有新蛋糕可分，中产就很难维持住它自我修炼出来的从容。

所以说，中产从来不是一成不变的标签，它更像是一面镜子，照出的是经济发展的阶段性红利。
