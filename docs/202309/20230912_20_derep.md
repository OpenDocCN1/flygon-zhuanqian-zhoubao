# 使用 ChatGPT 低成本、可视化、高效性分析小红书爆款数据

用 ChatGPT 拆解小红书爆款，省钱、直观还高效，这个思路真的能打！

大家好，我是越越，一个爱折腾 AIGC 的实践者，也是在小红书全平台攒下 6w+ 粉丝的成长型博主。目前我已经把 AIGC 生活化项目完整跑通，并且把它实际用到了自己的自媒体运营中。今天就毫无保留地和大家聊聊：如何用 ChatGPT，以极低的成本把小红书爆款数据拆明白，还能让结果变得一目了然。
