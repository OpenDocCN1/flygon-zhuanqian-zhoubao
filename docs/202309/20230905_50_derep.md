# 一篇干货帖，帮我四个月攒下1.5万创业粉，赚到25万

大家好，我是知凡，混迹互联网多年的“老韭菜”一枚。

今年五月，我在社区刷到乔合大佬分享的闲鱼引流玩法。当时仔仔细细读了好几遍，越看越觉得这事靠谱——既能解决私域没人流的问题，又能搭配培训课程把整个商业循环跑通。于是我没多犹豫，立刻开干。

到今天为止，这个项目已经给我带来了超过25万的收入。趁着有空，我把这几个月的实操经验和踩过的坑重新梳理了一遍，在原项目基础上做了些优化更新，也算是对乔总分享的一份回馈和致敬。

详细的完整版笔记我放在飞书里了，感兴趣的圈友可以自己去看。
