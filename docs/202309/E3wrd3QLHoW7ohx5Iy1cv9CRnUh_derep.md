# 1、第一步先把需求丢给GPT

我之前用过写手机器人，所以一开始就让 GPT 先给我一个最简的运行骨架出来。

![](img/f8682842ad15b50ea548ca674321423a.png)

# 2、把骨架丢进 Tampermonkey 试水

这么简陋的框架肯定跑不通，但可以先测个大概。

打开 Tampermonkey，新建脚本，把代码贴进去跑一下就行，记得先清空之前的代码。

![](img/f1126a417b780f75a57335e120030d12.png)

跑完你会发现，上传按钮压根没显示出来。更关键的是，对话框的输入框它定位不到，CSS 选择器找错了地方，根本不知道去哪输入。

# 3、一点点往上加功能

所以就得一步步补。先让它给我加一个手动上传按钮，这时候代码量还小，GPT 一次性能把整段逻辑说清楚，后面代码长了就可以让他只写上下文片段。

![](img/a25590d643e48adf08a5aae7ef8610a8.png)

把新代码贴回去后，页面上就真的出现按钮了。

![](img/f84b4b2b1322c239fb63b17c84f3e7e3.png)

点上传文件后马上报错了。

原因是少引用了 XLSX.js 这个库。打开浏览器 F12 看控制台，把报错信息完整复制给 GPT，它就能直接给你补上。

![](img/f14f3118336dd742abbc2cc91b8dc6e5.png)

![](img/4f7f4900e1e70d49eeaf86fa3ef78e0f.png)

# 6、我的一些实战感受

需求描述得越清楚，GPT 就越省事，后期需要修的地方也会越少。先让它出代码，再去 Tampermonkey 里跑，看看报错或缺什么功能，直接把控制台的报错和网页源码相关片段复制给它，它基本都能改。

代码短的时候直接整段丢给它看问题最快；代码变长了就别整段丢，容易让它自己把之前实现的功能又删掉。

网页按钮和输入框的定位真的很重要，ID 最好是唯一元素，不然脚本就找不到目标或者误操作。最后就是细节慢慢磨。

不懂技术真的不要怕，一有问题就去问 GPT。很多时候你给的需求是想解决一个现象，GPT 会按字面给你复杂方案。如果你直接告诉它你真正想达成的目标，它往往会给出更简洁直接的办法。
