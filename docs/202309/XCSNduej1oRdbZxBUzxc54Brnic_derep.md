# 手心向上的日子，我再也不想回去了

生完孩子后，我在家待了整整4年，过着“花钱要看人脸”的日子。

2021年，我重新回到职场，其实是在老公公司打下手，月薪5000。他对外人慷慨，唯独对我计较。在他眼里，我不赚钱、没本事，他总说“你看看我婶婶，在职场多厉害”。想拿点零花，都得看他的心情。

那几年，我心里一直有团火：我一定要自己赚钱。

后来试过很多副业，也没少交学费，几乎一个子儿没赚到。我一度怀疑自己笨，运气也差。可我咽不下这口气。

# 公号让我重新活过来

去年，我看到一个很普通的女孩靠公号月入几万，心又热了，直接花1299报了课。

可现实很打脸。一年下来，公号不仅没赚到钱，还倒贴。梦想第二次碎了。

但我不服：怎么别人就行，我却不行？

就是这股不服，逼着我每天坐在电脑前，一个字一个字地磨。幸好没转身离开，今年终于翻盘了。

# 真正的爆发，从今日头条开始

8月最让我惊喜的，是公号分成单日达到五位数。

这一切要从今日头条说起。

早年间我注册过今日头条。当时什么都不懂，听说每天写10篇，总有一篇能爆，我就傻傻地写了一个月，最后还是放下了。

后来，我报名了一门799的头条课。跟着学了一阵，终于有篇200万阅读的内容，收益却只有200多。接着又出一篇100万阅读，收益只剩50多。单价跌得太快，我有点心凉。

课程结束后，我也不好意思总问老师。再后来，遇到一位老师，全年课程只要199，我又重新来劲了。

他告诉我，平台对新号其实有扶持。我果断注销旧号，重新注册，发第一篇内容几乎一夜之间就有3万多阅读，粉丝很快到500，收益权限也顺利到手。

![](img/cf2419be46c8cd62d8acbe4da0572408.png)

之后，我换了领域，把内容同步发到公号与百家号，这边不亮那边亮。

不少人在抱怨今日头条单价越来越低，也有人转去做视频。可公号要是进不了推荐池，基本就没有收入。赚不到钱的日子，谁能一直写下去？

我去年公号亏钱还硬扛着，和我同批出发的人，很多悄悄退场，最后只剩几个人。

按照课程里的标题写法，再加上AI帮我完成初稿，效率一下子上来了。后来，我终于进入推荐池，一篇20万阅读的内容，带来1100多收益。这个成绩，我特别满足。

之后的节奏就简单了：找题材、让AI写、排版、发布。每天收入稳定在几百，偶尔破千，单月接近一万。

真正的惊喜，是在一个普通早上来的。我打开后台，阅读量200多万，收益6000多。次日更夸张，阅读量400多万，收益1.7万。

公号的长尾流量香，突然爆发的爆款更香。

之后我保持更新，每天基本都能过千。8月结束，当月总收入超过8万。

# 爆款是怎么找的？我把方法都写出来了

## 1、先理解什么是爆款

爆款不是大V的特权，而是谁写都有机会跑出来的内容。

它的特点很明显：会有很多人点赞、转发、评论。因为人的情绪一旦被调动，就会忍不住互动。愤怒、爽感、认同、共鸣，都是引爆点。

![](img/16e41cca8b1162dd797ee473a50d9d97.png)
![](img/2e7ede53e1d6ec2f7d07ca30e7f027d6.png)

## 2、一个选题值不值得写

### 第一，看出处。

把标题粘到搜索框里，看看除了大V，有没有大量新号也写过，并且也拿到过高阅读。

![](img/9d1fc6ef6c7f26dec722be0a03279d2f.png)

大V本来就有粉丝基础，素人也能写爆，才是真正的好题材。我每天刷很多内容，反复拆解，慢慢就有了网感。

### 第二，看留言区的情绪浓度。

以今日头条为例，公号未必开放留言。

![](img/bb7cc3d33357e5717fbed7d248e98e6c.png)

我会观察三点：

a、是否存在对立观点？
b、情绪是不是一边倒？比如“就该这样”“真的服了”“为国家骄傲”这样的声音。
c、有没有人分享自己的经历，比如“我也遇到过”“我家人也这样”。

满足两条以上，就值得写。

### 第三，看时间窗口。

社会类、娱乐类热点的活跃窗口一般只有6天，过了再写，基本没有流量。

所以热点来了要抢时间。不过也要看账号定位，我的号更偏向人物故事，硬追时事反而不太容易爆。

想要找长期热门，可以去字节跳动的官方热榜看一看。

页面上的三项数据分别代表：内容供给变化、传播量变化、搜索人数变化。我一般找“内容供给减少，但传播还在涨”的选题；如果供给跌得多、传播没怎么跌，也值得尝试。

# 参考谁，比怎么写更重要

以今日头条为例。在搜索框里直接输入类目词，比如“娱乐”“新闻”。很多号主会把类目写在昵称里，方便别人找到。

## 3、去爆款里捡灵感

![](img/c49b6dc4729133e040a8688fa8787eb2.png)

## 4、选值得模仿的账号

- 粉丝在3万以下，且没有认证标识。这种多半是新号，他们能做到的事，素人更容易复制。粉丝量很大的账号，随便发都有人看，参考价值不大。
- 更新是否勤快。每天都有新内容，相当于持续给我们输送素材。看他们发什么、怎么写，再结合自己的角度做改编。
- 爆款率超过20%。发10篇能有一两篇爆，说明选材能力在线。找到20个这样的号，你的选题库基本就建起来了。

# 写内容，最怕被数据绑架

很多姐妹问我：天天发没人看，什么时候才能进推荐池？

我进推荐池的时候，其实完全没想那么多。当时只是把今日头条的内容顺手同步到公号，连赛道都没定。后来试了社会、情感，最后还是娱乐跑通了。

发完内容，我就去忙别的事，最多早上起来看一眼后台。

你越在意数据，数据越让你焦虑；你放松下来，反而会有惊喜。

没阅读就没阅读，接着写就好。别人跑得出来，我也能。

# 最后，想和还在坚持的人说几句

今年对我来说，像突然开了一扇门，所有努力都有了回音。


回头看，我走了很多弯路，也想过无数次放弃。但最庆幸的是，那次没有真的转身离开。

前几天有人对我说：“你是那个‘二’。”我明白，指的是20%的那拨人。这一次，我终于挤进去了。

和我同批开始的人，退出的太多。我不是最快的那一个，但一路咬到最后，终于等来了正反馈。

公号分成这件事，没太多门槛。像我这种不太聪明的人都能单日破万，你们一定也可以。

如果哪一天真的写不下去了，就对自己说一声：再撑一下吧，成功已经在来的路上了。

人们真正记住你，不是因为你刚开始出现，而是过了很久，你依然没有离场。

到那时候，你还在，我也在。继续向前吧。
