# 你付的不是工时费，你买的是一个人一辈子的沉淀
作者：龙哥

印度广告人塔森曾说过一句话，说穿了就是这个理：客户掏的钱，买的从来不是他坐在剪辑间的那几个小时，而是他这辈子喝过的所有酒、喝过的每一杯咖啡、吃过的每一道菜、翻过的每一本书、坐过的每一张椅子、走过的每一段感情、踏足的每一个角落……所有这些碎片被熔炼、提纯，最后浓缩成一支30秒的广告。这样的东西，怎么可能便宜？

真正值钱的，永远不是时间本身，而是时间里积累的生活浓度。

我最近刚聊到一位就是这样的人。他在台湾奥美干了整整39年，现在是台湾奥美集团的首席策略官，业内人都叫他桂爷，叶明桂。提到他，整个广告圈都会竖起耳朵，因为他就是那盏指路的灯塔。![](img/8a9dd429e30ba2ff87d098bef9553392.png)

有人在评论区点破了本质：买的根本不是服务时长，而是别人的感受和经验值。![](img/1c37d505930596d12a88ab23e11aa07a.png)
