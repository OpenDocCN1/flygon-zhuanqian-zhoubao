# ('学会对手机“上瘾”，获得赚钱的商机', (2, 19))

别再想着戒手机了，换个思路，你完全可以让它替你赚钱。

前几天睡前刷手机又刷过了头，被家人念叨了一通。但正是这一通念叨，反倒让我翻出了十几年前电商起家时期的资料。越看越觉得，当年那波靠着电脑“上瘾”发财的人，和现在沉迷手机的人，本质上是同一件事——只是时代换了壳。

很多读者跟我倾诉过类似的烦恼：上学的时候沉迷电脑，管不住自己；如今工作了，该拼一把的年纪，又栽在了手机上。听着像是吐槽，其实背后藏着的意思是：我想努力，但诱惑太难扛。说到底，是自制力和执行力不够。但电脑和学业并不天然对立，手机和赚钱也不是敌人。强行“戒掉”手机，不是明智之举。你可能会得到一段清静日子，但也等于关掉了九成创造新生活的可能性。

有句话说得好：有舍才有得。我确实是主动“陷进”手机里的，但和很多人不同，我舍弃的是无意义的娱乐、闲聊和消遣，得到的是快速成长和真金白银的正反馈。

**01 先别急着戒，重新认识你的手机**

很多人想的是怎么戒掉手机，我却在研究怎么“上瘾”——因为强行撕掉一个成瘾的习惯，会遭到巨大的反噬。这里有个概念叫“代偿”：比如一个人减肥，天天吃水煮菜，某天聚餐忍不住点了一桌油腻美食，这就是压抑太久后的爆发。同理，你哭着喊着要戒手机，砸了手机去读书，脑子里的画面还是短视频的剪辑，书照样看不进去。

所以关键不是戒，而是把“瘾”转化成对你有正向作用的动力。这就需要你静下来，重新看看手里的手机。

**①手机到底能给你带来什么？这里分三个认知阶段。**

**阶段一：通话工具、娱乐玩具、搜索答案。**

坦白说，80%的人停留在这个阶段，对手机的理解停留在商家宣传和传统认知里。这是很危险的信号——你以为是年轻人，思维方式却已经是老年人了。娱乐、刷视频、打游戏，这些几乎不需要深度思考，最大的作用是刺激多巴胺，让你快乐一阵子，代价是钱、时间和精力。这种快乐是即时的，却会持续拉低你未来的生活质量，让你物质基础变差、年纪渐长、毫无动力。

**阶段二：掌握信息差的利器。**

能跳过游戏和段子的诱惑，进入这个阶段，你就已经超越80%的人了，踏进了19%的圈子。手机像一本百科全书，那些即时享受的内容，本质上是在过滤掉不适合它的人。它能帮你足不出户知天下事，比如：

- 今日头条——新闻热点的聚集地，能挖到政策风向和实时消息。
- 知乎——专业问答平台，能找到基本的知识诉求和实时答案。
- 短视频平台——除了娱乐，也有专业的搜索功能，可以挖到小众信息。

你可以用不同的App获取不同领域的知识，甚至找到相应的社群和圈子，拿到第一手资料。对提升思维、认知、格局都有大帮助。这时候，手机才是你最好的工具。

**阶段三：并肩作战的AI伙伴。**

能走到这一步的，是那1%的人。手机对他们来说，不只是工具，而是有共同目标的合作伙伴。养好它，它能带来人脉、资源、机会，和多种变现途径。比如：

- 整合各种社群信息碎片，拼成信息网，用它链接人脉、兑换资源、开新项目。
- 从平台细节里发现普通人看不见的商机——前阵子四六级考试，有人一天涨粉4000+，有人3小时变现500+，有人链接到其他领域的达人。
- 在同样的信息池里，让你有机会成为某一层面的“老师”，增强你的可信度，放大你的光环。

这就是“一机在手，事事都有”。但大多数人连第二个阶段的门槛都摸不着，所以下面重点讲怎么从阶段一走到阶段二。

**②先戒掉“阶段一”，再有意培养“阶段二”**

如果你从没有坚持过半年以上的自律行为，最简单的办法是“疏”而不是“堵”，就像大禹治水。这里有三个最直白的方式，做到不容易，但做不到，后面就免谈。

**第一，安排时间。** 先连续记录三天你每天玩手机的时间，算出平均值，比如5小时。下周开始，每天上限4小时，多出来的时间换成看书、交流、学习相关知识并做笔记。用21天养成初步习惯。

**第二，灵活变通。** 刚开始肯定会犯规。记住规矩：今天超了多少，就从明天的额度里扣。今天玩了6小时，明天就只玩2小时。本质是向未来的自己“借时间”，不能不还。

**第三，循序渐进。** 前期不要奖励自己，更不要找放松的借口。而且随着自律增强，还要主动压缩娱乐时间，扩增学习时间——21天后从4小时降到2小时，再21天降到半小时，直到基本对娱乐诱惑免疫。

**02 学会“玩”手机**

新手的建议是做好三个“21天”，稳固自律基础。等你已经对娱乐诱惑基本免疫，就可以重新拿起手机，开始第二次“上瘾”——进入阶段二。只是这次上瘾，不是沉迷，而是“自我增值”。

具体做法：把之前玩手机的时长，换成一种新的玩法——用手机去搜索、了解、学习要掌握的信息。为了避免知识错乱，最好分阶段、分方向。

比如规定每天“玩”手机6小时，主题是学习写作：

- 前2小时，去小红书搜“写作思维”“写作技巧”“写作模板”，把知识点归类到专门的App里。
- 中间2小时，去今日头条和公众号找爆款文章（10W+、100W+），拆解结构、分析手法、总结方法。
- 最后2小时，去知乎和抖音搜“写作笔记”“写作学习记录方法”，筛选出适合自己的学习模式并记录。

为什么要去不同平台？因为每个平台的侧重点不同，App就像文件夹，帮你做知识管理，减少无效思考和时间浪费。

举个例子：小红书是干货集聚地，像小百科；今日头条适合拆文、仿文、搜集素材；知乎是专业知识问答的好地方，能优化学习方法。每个平台都值得单独研究，找到适合自己的组合。

另外推荐两个辅助专注的工具：番茄TO DO、Anki记忆卡片。至于怎么用，你去“玩”手机的时候自己探索。

**03 掌握“用”手机的方法**

学会“玩”之后，“用”就是让它替你创造赚钱模式。别怀疑，现在手机赚钱的路子，其实就是当年电商兴起时电脑玩法的升级版。

**第一，以史为鉴。** 最快搞清一件事的方法，是看历史。翻翻电商的起源、演变、风口、模式和关键节点，把它们和电脑、互联网的发展对照，再把共通处映射到智能手机上，结合“玩”手机的方法，记录下可复用的经验。

**第二，链接交流。** 掌握了经验和资源，接下来就是用手机打造属于你的人脉圈，把能够互利共赢的同频人链接起来。这在以前电商刚起步时是难以想象的——那时候只能做本地生意，电脑把范围无限扩大，现在手机把这一切再浓缩到掌上。

把它当成能解决你99%问题的合作伙伴，不仅能搜索、能学习，更能帮你聚拢人脉、资源、商机，营造一个属于你的能量圈。

讲实话，我目前也在“玩”和“用”的阶段反复打磨，算不上精通，但一直在精进。回头想想，互联网刚兴起的年代，多少人靠“网瘾”赚到了第一桶、第二桶、甚至第五桶金。如今手机正当风口，希望我们都能对它“上瘾”，赚到属于自己的一桶又一桶金。

对了，分享一个彩蛋：前几天晚上我刷的不是娱乐内容，而是在刷精华帖。手机可以用来辅助记忆、辅助学习、辅助笔记，真正“上瘾”了，你会发现所有点都能连成线。

很高兴认识你。愿我们都能在新人的路上，收获全新的认知、知识和经验。给自己一个承诺，用一年时间告别小白。你一定可以，我也一样。
