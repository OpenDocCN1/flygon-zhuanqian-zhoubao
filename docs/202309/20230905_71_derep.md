# 别只停留在看和用的层面，去创造属于自己的价值
作者：龙哥

我们习惯了用眼睛去追、用人去跟随，刷信息、买产品、点赞收藏，生活的节奏就被“消费”这件事填满了。可你有没有想过，另一种身份其实一直都在你手边——创造者。

成为创造者，并不是意味着你必须写书出书、拍片成名。创造，可以是把你学到的东西整理成笔记分享出去，可以是把一次失败的经验拆解成别人的避坑指南，可以是用你的时间、你的专业、你的视角，为这个世界多添一块砖。

当你从消费者切换到创造者，你的注意力就会从“有什么好东西给我”变成“有什么价值我能给出去”。这个视角的转换，会让你的学习更深、你的成长更快，也会让你的生活拥有真正的重量感。

你可以成为一名创造者，而不是一名消费者。![](img/2ae58a9b79b30c0537e2774a161911eb.png)
