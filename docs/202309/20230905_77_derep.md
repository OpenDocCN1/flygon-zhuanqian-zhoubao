# ('如何从周三就开始过周末？', (2, 14))

你是不是也总在周五晚上才惊觉：“怎么又要过周末了？”其实，真正会生活的人，从周三就已经开始“进入状态”了。

所谓“周末延长术”，并不是要把两天拉成四天，而是调整一种节奏——周三提前为周末做一点铺垫，或者把周末计划前置到周中。这样做的好处是，你不会等到周六早上才茫然地刷手机，而是从周三起，心里就有了期待和方向。

但比技巧更重要的，是一种心态的转变：我们对“生活”的想象与享受，完全不必被限定在日历上的那两格。周三的傍晚，同样可以是一周里的小假期；周四的夜晚，也能拥有周末般的松弛感。

说到底，周末延长术不是在“偷时间”，而是在提醒我们——生活的愉悦感，随时可以开始，只要你愿意。
