# 从金融从业者到陆家嘴创业者，我用两年把自媒体从零做起来了

Hi，我是龙哥，闪亮猫传媒的创始人。

上周和龙哥大哥吃饭，他点评我一句：你这人很适合做0到1，拿个想法就能快速跑起来。

借着这次小航海的学习，我把播客也从零启动了，凌晨赶出了第一期作业，就在这里和大家聊聊这两年多的心路历程。

两年多前，我离开了金融行业，正式All in 自媒体创业。说起来，这两年的变化真的可以用翻天覆地来形容，踩过的坑不少，得到的也很多。

💎 知识付费，说到底是为圈子买单。这两年我自己在知识付费上的投入超过了20万，但我会逼自己让每一笔投入都尽快产生回报，最终都是赚回来的。

💎 自媒体是一条真正普惠的赛道。以前待在金融圈，即便学历背景还算可以，却处处感受到无力感，周围清北、常青藤比比皆是，压力非常大。可到了自媒体圈，我才发现自己的履历在行业里已经算中上。更关键的是，这条路上草根逆袭的案例太多了，能打动人、够接地气的创作者，信任感和变现力往往更强。

💎 自媒体的形态远比想象中丰富。光是📕的MCN体系，就能拆出无数条生意。我们闪亮猫主要聚焦在知识付费和自营品牌的运营，但也有团队深耕媒介变现和广告投放，媒介这块还能再往下细分出非常多的垂类，每个赛道都赚钱，也都辛苦。

这次的播客是我和闪亮猫的合伙人周周一起完成的，她负责主持，我来讲讲自己的从零到一经历，希望能给正在路上的人一些参考🎧
