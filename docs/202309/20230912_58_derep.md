## 一、站内优化：先把页面基本功练扎实

拿到一个关键词，先别急着写代码。你得想清楚，用户搜索这个词，到底是想看一篇内容，还是想找一个工具，又或者是想找服务、找商品？只有把用户的真实意图摸清了，你才知道这个关键词该用什么样的页面去接住那些搜索流量。

### 1.1 怎么写好 TDK？跟豆瓣偷个师

先聊 title，也就是网页标题。

搜索引擎判断一个页面讲什么内容，title 是最重要的参考依据之一。很多时候大家嘴上说做 SEO，其实核心就是在琢磨标题怎么写。

标题还会原封不动地出现在搜索结果里，所以把标题写好了，既能帮助搜索引擎理解页面，也能让用户更有动力点进来。

![](img/921b944d1b7a66df3fdfe9c820cd4727.png)

豆瓣的电影详情页标题就很简单，只写了“电影名字（豆瓣）”。因为它权重已经足够大，不需要堆关键词。但你要是新做一个电影介绍站，就得换个思路——分析用户对某部电影关心什么，比如“主演是谁”“演员表”“主角叫什么”“评分多少”“票房怎样”，把这些词合理地拼进标题里。

![](img/64a6107486d326dceb1f98660eadb22c.png)

只要用户可能关心、又有搜索流量的词，都可以放进去。

description 网页描述也不能忽略，它同样会显示在搜索结果里。至于 keywords 关键词列表，现在基本没什么用了。我个人的习惯是：优化不要做太满，title 和 description 认真写，keywords 干脆删掉。

![](img/8f7e45b062bc6b93445a42d64eaf477d.png)

你仔细看豆瓣就会发现，它把本该放在标题里的词，全都挪到描述里去了。

TDK 讲完，看看真实效果长什么样。

谷歌展示的效果：![](img/103afb9d94b1e62ce01c43c8018c2b07.png)

### 1.2 网页结构：标题层级要清晰

除了 title 和 description，一个网站页面还要有明确的 h1、h2、h3 结构性标题。

先讲 h1。一个页面只能有一个 h1。你可以这样理解：title 是说给搜索引擎听的，h1 是说给用户听的。但搜索引擎也会拿 h1 来评判页面内容，最终给你排到什么位置，很多时候就是 h1 和 title 一起决定的。

![](img/6d2118103989e21f495c26a42dbd8705.png)

接着是 h2 和 h3。它们是构成完整语义化 HTML 的必要部分，一个页面可以同时出现多个 h2 和 h3。

![](img/44bcf978d64a2b8951dec177cdf2ff55.png)

h1、h2、h3 分别代表一级、二级、三级标题。除了这些标题，剩下的正文内容都要写在 p 标签里，图片也可以放在 p 里。

![](img/75ad023d5905c78565ba0bea0ef693a8.png)

图片是网页不可缺少的元素，用 img 标签合理放图，不但帮助用户理解内容，还能从搜索引擎的图片搜索里获得流量。img 一定要写 alt 属性，这是专门给搜索引擎看的图片描述。另外尽量用大图，比如 300x300 以上的。

![](img/ffffa0aebb267b64e432a04db9dc6aed.png)

不管你做的是工具类页面还是内容型页面，TDK 加上 h1、h2、h3、p、img 都是标配。

一个标准页面结构大概是这样的：

h1 → h2 → p → h3 → p → h3 → p → h2 → p → h3……

### 1.3 内链建设：让页面互相关联

页面做好了，接下来该用链接把它们串起来。网站内部页面互相跳转的叫内链，外部网站跳到你网站的叫外链。

通常来说，我们找到的主关键词都能延伸出一堆二级关键词、三级关键词。在网站首页，一般会把主关键词和这些二三级关键词分别用 h1、h2、h3 列出来，目的大多是为了优化主页的主关键词。

拿 coloring pages 来举例。主关键词是 coloring pages。

二级关键词可以是：

dog coloring pages  
cat coloring pages  
girl coloring pages  
flower coloring pages  

而 dog coloring pages 的三级关键词，又能做成：

cute dog coloring pages  

关键词和 URL 的对应关系是：主关键词用域名首页，二级关键词用子目录，三级关键词用子目录下的子目录，最后到具体内页。

内链建设的要求是：首页要有通向每个二级、三级关键词页面的链接，同时每一个页面也都应该有指向上级页面的链接。

比如在 cute dog coloring pages 页面里，加上一个文本为“dog coloring pages”的链接指向 dog coloring pages 页面；在 dog coloring pages 页面里，又加上一个文本为“coloring pages”的链接指向首页。甚至所有页面都放一个“coloring pages”的链接回到首页。

简单说：某个二级关键词下的所有三级关键词页面，都要指向这个二级页面；所有二级页面，也都要能回到首页。

### 1.4 六字真言：分门别类罗列

哥飞给首页布局总结了一句六字真言——分门别类罗列。

还是拿 coloring pages 网站举例，首页结构是这样排列的：

h1 coloring pages  
h2 dog coloring pages  
h3 cute dog coloring pages  
img1 img2 img3……  
h3 little dog coloring pages  
img1 img2 img3……  
h2 cat coloring pages  
h3 cute cat coloring pages  
img1 img2 img3……  
h3 little cat coloring pages  
img1 img2 img3……  
h2 flower coloring pages  
h3 red flower coloring pages  
img1 img2 img3……  
h3 yellow flower coloring pages  
img1 img2 img3……

### 1.5 必须用后端渲染

有一点请务必记住：上面说的所有内容，都要原原本本地出现在 HTML 代码中，不能靠前端 JS 动态渲染。也就是说，浏览器里打开页面，右键查看源代码，应该直接能看到这些内容；搜索引擎的爬虫来抓取时，也能抓到同样的内容。

搜索引擎确实偶尔会解析 JS 并触发渲染，但那是要消耗额外算力的。一个刚上线的新网站，凭什么让搜索引擎给你额外的算力支持？所以老老实实用后端渲染，别想太多。

### 1.6 URL 的唯一性

还有个小细节很容易被忽略：确保每个页面的 URL 是唯一的。

一个网页可能会有多个 URL 都能打开，但你应该在网页的 head 里用 canonical 标签，告诉搜索引擎当前页面官方指定的唯一 URL 是什么。

以🛰️在苹果 App Store 的页面为例，苹果官方确认的唯一 URL 是：

https://apps.apple.com/cn/app/%E5%BE%AE%E4%BF%A1/id414478124

但你会发现，下面这几个 URL 其实也能打开同一页面：

https://apps.apple.com/cn/app/id414478124  
https://apps.apple.com/cn/app/weixin/id414478124  
https://apps.apple.com/cn/app/wechat/id414478124  

![](img/dfb03a82cca938701b9ed93197ced3e0.png)

![](img/25c0563b8609abca5effebb83bc46099.png)

![](img/4d8d0e214b7ea4a3750928d0cef3b78a.png)

不论通过哪个地址进来，苹果官方在页面里设置的 canonical 指向的都是同一个规范化 URL。

所以，如果你的网站同时支持 www 和不带 www，或者同时支持 http 和 https，也要用 canonical 告诉搜索引擎官方指定的规范化地址到底是哪一个。否则在搜索引擎眼里，就等于有多个网址展示着重复内容，很可能就不收录了。

前面说的前端渲染也一样，会产生重复内容的问题，同样影响收录。

到这里，站内优化的部分就收尾了。

## 三、部署实操：从域名解析到网站上线

部署之前，先补充一点技术常识。

当用户在浏览器里输入你的域名，首先会经过 DNS 解析，找到这个域名对应的服务器 IP。这个 IP 可能是你自己买的云服务器 IP，也可能是 Vercel、CloudFlare 等平台的 IP。请求随后被发送到服务器，服务器做一系列处理后，把 HTML 页面代码返回到浏览器，最终渲染出网页。

因此，买回来的域名需要一个 DNS 服务器。大多数注册商都会免费提供，你也可以使用第三方 DNS 服务。这里比较推荐的做法是，统一用 CloudFlare 来管理域名解析。

接下来，我们以 CloudFlare 和 Vercel 为例，演示一个前端工具站点怎么部署。

### 3.1 配置域名解析

打开 CloudFlare，点击左侧菜单里的 Websites，进入网站列表页，点击右上角的“Add a site”，输入你要解析的域名，点 Continue。

![](img/f328584540028d10ed460ba9b421bae2.png)

选择免费的套餐，继续点 Continue。

![](img/f41e91b5490da01d1f35e50ebf665f4c.png)

把 CloudFlare 给出的 ns1、ns2 复制下来，填到域名注册商后台的 DNS 设置界面。

![](img/20bde6cd15ebbe0880fffd21305cf2f4.png)

有些 DNS 服务商提供 5 个 NS，CloudFlare 只有 2 个，那填 2 个进去提交保存就行。

![](img/108691b97d94108845c69a404a7796b6.png)

接着继续下一步，三个选项都开启，最后点 Finish。生效要等一小段时间，回到网站列表，看到“Active”字样，就说明 DNS 已经修改成功。

![](img/4a5ee2611e3fbd303155252ce1f7bb86.png)

### 3.2 添加解析记录

最常见的解析记录类型有四种：A 记录、CNAME 记录、TXT 记录、MX 记录。网站访问一般用前两个；配置邮箱，才需要用 MX 记录；有时候做域名所有权验证，会用到 TXT 记录。别人让你加什么，你就加什么。

![](img/a224a4b879fc19a585c10c510b2ee4a7.png)

### 3.3 静态网站怎么部署

用 Vercel 配 CloudFlare 来部署一个静态网站，总共六步：

1. 创建 Github 仓库，把网站的前端代码提交进去；
2. 在 Vercel 新建项目，把刚才的仓库关联上；
3. 等待自动构建完成，点击 Vercel 免费给的子域名，发现网站能正常打开；
4. 到 Vercel 的域名设置中添加自定义域名，建议选择无 www 域名作为主域名，让 www 跳转到无 www，再开启 SSL 证书，设置从 http 跳转到 https；
5. 在 CloudFlare 添加解析记录，注意 SSL 要选 Full 模式；
6. 等解析记录生效，直接用 https://域名 打开网站，部署大功告成。

经过上面几步，一个网站就正式跑起来了。接下来你可以打开搜索引擎，好好欣赏三分钟。

## 四、上线之后，马上做这三件事

网站部署好，别急着庆祝，还有几件收尾的事要做：提交 Google Search Console、配好流量统计代码、主动吸引爬虫。

### 4.1 提交到 Google Search Console

第一步，先为网站制作一份 sitemap。格式要求可以直接百度、谷歌，或者问 GPT。

然后在谷歌里搜索 site:域名，页面会有“尝试使用 Google Search Console”的提示，点进去。

![](img/d2e0ac2867601048018ffdbd72f5a62f.png)

进入后台，左侧找到添加资源，选择“网域”形式，输入你的域名，点继续。因为域名在 CloudFlare 管理，所以能一键授权验证所有权；如果域名在别处管理，就按提示配置解析记录去验证。

![](img/101fccdcbd6b49fb23b4268c2a6ec0d8.png)

验证通过后，把准备好的 sitemap 文件提交上去。接下来，等谷歌爬虫主动上门就行。

### 4.2 流量统计代码别忘了

打开谷歌分析后台，点击左下角设置，在设置页面选择“添加媒体资源”，跟着提示一步步填，到第 3 步时选择“获取基准报告”。

![](img/697a57e3d2f10462bd825b5e0c092377.png)

第 4 步把类型选为“网站”，然后输入网站域名和网站名称，提交后就能得到统计代码。

把这串统计代码放到所有页面的 </body> 标签之前，像这样：

<div style="display:none"></div></body></html>

用不惯谷歌的话，也可以同时放百度统计代码，同样放在这个 display:none 的 div 里。

### 4.3 想办法吸引爬虫

新网站最好通过启动外链来引爬虫，让搜索引擎尽快收录。主要有两个办法。

第一，去谷歌爬虫经常光顾的网站发帖宣传。比如 V2EX 的“分享创造”节点，就是一个不错的发布渠道。需要注意的是，介绍一定要真诚，别弄一堆敷衍的话术。

第二，在老网站上加友链。如果你手头已经有被收录的网站，在老网站里放上新站的外链，也能吸引爬虫过来。所以当你手里的网站越来越多，再上新站时，被搜索引擎收录的速度就会越来越快。

## 五、宣传推广：把流量引进来

做好前面的准备，就可以开始推广了。

先从你最熟悉的渠道下手。凡是你能影响的渠道，都去发一遍，先把第一批用户攒起来。这批用户哪怕是国内用户也行——他们的价值在于帮你测出 Bug，让你把问题修掉，给后面正式推广打好底子。

接着，可以把产品提交到一些周刊，比如阮一峰的周五科技周刊，还有 ahhhhfs.com、小众软件这些平台。

再进一步，把产品提交到 ProductHunt，这能给你带来真正意义上的第一波海外用户。因为我们的产品是 AI 工具，PH 上的信息会被各种 AI 导航站的爬虫自动抓取、收录，所以还能从那些导航站再薅来一批用户。

最后，还可以手动提交到一些不会自动抓取、需要主动登记的 AI 导航站。有些站可能收费，量力而行，太贵的先不碰。

以上就是从站内优化、部署上线到推广运营的完整流程，一篇给你讲透了。希望这篇内容对你有实际帮助。

当网站迎来前几批访客后，先别急着欢呼。你需要花点时间观察他们：产品用起来顺不顺手？会不会主动分享？老用户有没有带来新面孔？

如果这些表现都不错，下一步就可以去找一些小型科技媒体和自媒体账号，主动推荐自己的产品。优先选择免费渠道。只要工具足够有趣、足够实用，就会有媒体愿意帮你宣传——毕竟他们也需要内容素材。

另外，你也可以去推特搜一搜，看有没有人正在找同类产品。在评论区自荐时，态度要诚恳，坦白这是自己做的，请对方试一试并给出建议。有人置之不理很正常，但只要有一个人回应，你就多了一个用户。

做完这些，网站就算拥有了第一波种子用户。产品本身过硬的话，口碑会替你不断传播。与此同时，外部链接越来越多，搜索引擎也会慢慢提升你的排名，自然流量就会开始出现了。一切正朝着美好的方向前进。

但，是不是从此就能高枕无忧，躺着赚钱了？别高兴得太早。别指望流量一夜爆发，很多网站上线的头几天，访问量可能少得可怜。这时候，调整预期就非常重要。

这让我想起学生时代背过的《劝学》。不积跬步，无以至千里；不积小流，无以成江海——每一步、每一滴都在为未来铺路。还有那句“锲而不舍，金石可镂”，只要认准方向坚持磨下去，再硬的石头也能刻出痕迹。再快的马，一跃也不超过十步；再慢的马，连续走上十天也能跑得很远。蚯蚓没有锋利的爪牙和强健的筋骨，却能穿梭在泥土中，靠的是专注；螃蟹看起来张牙舞爪，却连蛇鳝的洞穴都住不进去，问题在于浮躁。说到底，成事不靠天赋爆棚，靠的是持续积累、坚持和用心。

如果你之前有经验，目标可以定得高一些；如果完全是新手，最好的办法是把期望值放低。不要瞧不上小钱，看得上小钱，才赚得到大钱，积少成多，聚沙成塔。

先从能力范围内的事情做起，认认真真把第一个网站做出来。当你第一次靠搜索引擎带来免费流量，再通过 Adsense 赚到第一笔广告费，恭喜你，已经入门了。

具体怎么做？比如选关键词，可以先挑那些搜索量不大、竞争也不激烈的词，照着这个思路做出一个网站，等谷歌开始给你流量，你就有了正向反馈。有了这份动力，再去挑战更高难度的词也不迟。

从我的经验看，谷歌依然是搜索领域的霸主。它就像一片大海，只要定位准确，出海航行两周内就可能看到成果，运气好点，一周就能有访客。我认识一个朋友，完全是新手，从七月开始做站，到现在已经上线了三个网站，每天广告费合计超过500美元。这就是谷歌给坚持者的礼物。

愿大家都能有所收获。
