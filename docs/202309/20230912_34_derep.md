# 视频号做了8个月，单月51万播放、12万收益，我的变现经验全在这

大家好，我是龙哥。

在视频号这条路上，我专注耕耘了8个月，终于拿到了还算满意的结果：今年6月，单月播放量超过51万，收益达到12万。也很幸运，被选为视频号航海的教练之一。

其实一开始我也和大家一样，是个纯新手，没有成套的打法，也找不到人带，走了不少弯路。所以今天想用自己的真实操作经验，聊聊方法和走过的历程，希望能帮到正在做视频号的小伙伴。

正式聊干货之前，先真诚感谢龙哥盟官方的小霸王和肉松小姐姐的指导，也谢谢一路支持的圈友好友达达、小刀，还有靠谱姐、芷蓝姐、理白哥和比比。在赚钱这个社群里，我不光收获了很多朋友的支持，也完成了从0到1、再从1到10的成长，打心底感谢这里。

这次的内容，原本是视频号航海活动中高手分享的帖子。当时群里节奏比较快，大家读起来可能不够顺畅；而且有些圈友跟我说对视频号很感兴趣，但没能赶上航海，所以干脆再把完整版分享一次。
