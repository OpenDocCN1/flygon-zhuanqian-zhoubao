嗨，我是枫晓陌，微软认证的 AI 工程师。接下来的一年里，我打算借助 AI 渗透进上百种工作场景，让大家真切感受到人工智能带来的效率升级。

不管你想把 AI 用在哪个赛道，都可以来找我聊：AI 写作、阅读提效、📕内容、健身指导、朋友圈营销、简历优化、热点拆解……都可以。

你报需求，我给你一套可用的 prompt。下一个我打算拆的是📕。

前不久我混进了一个 AI+拆书稿的快闪共学群。老师透露，现在做拆书稿的生意还在，只是没了知识付费爆发期的火热。那个阶段一篇拆书稿动辄上万块，想了解的可以自己去扒一下。

看到群里不少人跃跃欲试，我就顺手整理了一套 prompt 分享给大家～

现在写读书笔记还能变现吗？

给几个可以落地的思路！相信你脑子转一转，就能再联想到更多玩法，大家都是明白人，就不多展开了。

![](img/9d799c2732c3be260ac9a763eb05904c.png)

但现实是很多人要么写得很平庸，要么写一篇笔记要耗费大半天。那咋办？

我把市面上常用的拆书框架，比如 5W1H、蒙太奇、笛卡尔分析、洋葱阅读法这些，全部封装进了 prompt 里。即使你是零基础小白，也能快速冲到及格线60分，发挥好了拿个80分也不难。

剩下的分差，就靠个人的打磨了。AI 再厉害也只是个工具。它模拟不出你独有的审美和共鸣，做不到百分百贴合你的品味。

设计思路是什么？说实话拆书方法论我也不是全懂。那就让 AI 去搜、让网络去补。先凑齐一套可用的方法，再从中挑。

![](img/2653450305a5ce583f64c90c615f459a.png)

![](img/db6f266efd19350ab73bb1a455bb00fe.png)

我同时问了几款 AI，得到的答案各有侧重，挑自己顺眼的那套就行。

如果你手里本来就有私藏方法论，或者找到更好的框架，直接把它提炼成 prompt 用就完事了。

下面是我总结出来的实操路径。

## Workflow

1. 用户先把书籍的关键信息丢上来。
2. 如果这本书在我的知识库里，就继续推进；不在库里就先中止。
3. 给用户推荐三套匹配度高的拆书方法，并说明为啥选它。
4. 用户定好方法后，我先给出一份拆书大纲。
5. 按照用户指定的章节或片段进行正文生成。
6. 等用户确认整体内容是否达标。
7. 收到反馈后，再做针对性调整。

废话不多说，正文有点长，准备好小板凳坐下看。

```
# Role: 书籍拆解大师

## Background
在这个信息爆炸的时代，迅速获取高质量的读书笔记至关重要。

## Attention
请专注于书籍拆解任务，提供高质量的拆书输出。

## Profile
- Author: 枫晓陌
- Version: 0.5
- Language: 中文
- Description: 我是一位资深书籍拆解大师，精通各种拆书技巧。我不仅能够深入书籍并准确抓取要点，还能根据用户需求创造性地表达拆书内容。

## Skills
- 掌握多种拆书模型，包括：
  - 洋葱阅读法：分为碎片化阅读、快速阅读、深度阅读、主题阅读和研究式阅读，适应不同书籍的拆解需求。
  - 笛卡尔分析法：深入分析书中问题和观点，逐步解构内容以深入理解。
  - 蒙太奇法：将书籍内容划分、排列或重组，提高信息组织和理解。
  - 5W1H法：全面分析书籍内容，回答“是什么”、“为什么”、“何时”、“何地”、“如何”和“谁”的问题。

## Goals
- 根据用户提供的书籍，使用合适的拆书方法输出高质量内容。

## Constraints
- 如果我的数据库中没有这本书，我将无法回答，绝不编造信息。
- 输出内容必须基于我的理解，绝不抄袭。
- 遵循原文内容和事实，避免引入歧义。
- 需要考虑目标受众为小学六年级的学生，避免使用过多专业词汇。

## Value
- 提供多个示例和适当引用原文，确保逻辑清晰，通俗易懂。

## Workflow
1\. 用户提供书籍信息。
2\. 如果我数据库中有该书，则继续对话；否则，结束对话。
3\. 推荐三种适合的拆书方法，并解释原因。
4\. 用户选择拆书方法后输出拆书稿大纲。
5\. 根据用户指定部分进行输出。
6\. 用户确认拆书内容。
7\. 用户反馈后，根据反馈调整内容。

## OutputFormat
- 提供多个示例和适当引用原文，确保逻辑清晰，通俗易懂。

## Suggestions
- 提供不同细节程度的文章样本供用户选择。
- 增加原文摘要、关键词等辅助内容。

## Initialization
您好，我是书籍拆解大师，可以根据您提供的书籍进行拆解和创作。请提供您希望我拆解的书籍信息。

```

## 贫穷真的是“不努力”吗？两位经济学教授用数据告诉你：不是

很多人在谈论贫穷时，总习惯把原因归结为懒惰、不上进或者脑子笨。但《贫穷的本质》这本书，给出了完全不同的答案。

这本书的作者是麻省理工学院的两位经济学教授阿比吉特·班纳吉和埃斯特·迪弗洛。他们没有坐在办公室里空谈理论，而是长期走进非洲、南亚等发展中国家的村庄和贫民窟，靠实地观察和海量数据，重新拼凑出贫穷的全貌。

**贫穷到底是什么？**

很多人以为穷就是“没钱”，但作者指出，穷是一个相对概念。在同一个国家或地区，收入长期低于平均水平，就可能被划入贫困人群。国际标准也不统一：世界银行认为，每天生活费不足1.9美元就是极端贫困；中国国家统计局曾把年收入低于2300元人民币定为贫困线；美国一个四口之家年收入低于2.5万美元，会被认为贫困；而在肯尼亚，年收入达到3900美元，就足以走出贫困线。同一笔钱，在不同国家含义完全不同。

贫穷也不只是收入问题。住不进像样的房子、孩子吃不饱饭上不起学、生病了看不起医生、喝不到干净的饮用水，这些都算贫困。书里的数据显示，撒哈拉以南非洲有大约3.5亿人处于营养不足状态。甚至，内心的感受也很重要。美国的低收入群体虽然在收入标准上不算“绝对贫困”，但他们的幸福感和生活满意度，明显低于中产阶级。所以贫穷是多维度的，有物质层面，也有心理层面。

全球如今还有约10亿人，挣扎在每天1.9美元的收入线下，主要分布在撒哈拉以南非洲和南亚，比如印度、孟加拉国。即便在发达国家，也有相当一部分人面临收入、机会和社会资源的相对短缺。

**穷，是怎么来的？**

首先，穷会“遗传”。这里的遗传不是基因，而是环境。低收入家庭拿不出钱给孩子买足够的营养品，也买不起优质教育资源。孩子长大后，大概率还是从事低技能、低收入的工作，然后又把自己的困境传给下一代。书中提到，在巴西的贫民区，将近一半的穷人，他们的父亲当年也是穷人。

其次，歧视和不平等也在制造贫穷。因为种族、性别、地域出身，有些人被系统性地挡在资源门外。撒哈拉以南非洲的一些族群，因殖民历史长期被边缘化；东欧的罗姆人经常在就业和教育上遭到歧视；印度种姓制度下的所谓“贱民”后裔、农村妇女，以及残障人士，都更容易落入贫困。

第三，战争、殖民、气候灾害等外部因素不可忽视。非洲在殖民时期被卷走大量资源；气候变化带来的干旱和洪灾，能瞬间摧毁农业社区的生计；拉美国家当年的恶性通货膨胀，让不少中产家庭一夜返贫。贫穷背后有结构性的、历史的、外部的原因，简单地归咎于个人，既不公平也不准确。

**穷的代价有多大？**

最直接的代价是生命。书中数据显示，低收入国家的婴儿死亡率是高收入国家的18倍。卫生条件差，传染病就容易横行，疟疾在穷地方更常见，艾滋病也更多出现在低收入群体中。穷和病，经常互相喂给对方。

另一个代价是尊严和希望。即便在富裕国家，低收入者也容易觉得未来没有光，感觉自己不被社会尊重。这种压抑感不仅让人痛苦，还会伤害身心健康。相比之下，收入中等的人虽然物质不算富足，却往往更容易感到满足。贫穷不只是经济统计上的缺口，更会侵蚀一个人的智力、情感与道德发展空间，是一种伦理上的伤害。

**怎么才能真正脱贫？**

作者强调，单纯发钱、发食物，解决不了根本问题。想要脱贫，必须进行更深层的制度手术。

第一，打破不平等。给弱势家庭的孩子更多教育投入，让不同出身的人拥有相近的学习机会；建立更包容的社会氛围，消除基于性别、种族的歧视；改革税收，用再分配政策缩小贫富差距。

第二，补齐基础设施和公共服务。干净的水、卫生的厕所、能看病的诊所、通到家门口的电网和公路，这些看起来基础，却能真正改变贫困地区的面貌。

第三，微型信贷很有用。给穷人提供小额贷款，让他们能启动一个小生意，慢慢拥有稳定收入。作者分析了大量数据，确认这种“草根金融”对扶贫有显著效果。

第四，国际援助要“入乡随俗”。发达国家应该出钱出技术，但不能把现成方案硬套到别国头上。援助方和被援助方必须坐下来真正合作，尊重当地文化背景和实际需求。

**这件事该由谁来做？**

发展中国家政府是第一责任人。孟加拉的格拉米银行就成功服务了农村贫困人口，但也有不少国家的扶贫款被官员截留。专家建议建立透明的监督机制，确保每一分钱真正花在教育、医疗等公共服务上。

发达国家也需要兑现自己的承诺。数据显示，大部分富裕国家的对外援助金额，不到国民收入的0.7%。外界一直呼吁建立相应机制，推动发达国家拿出更多低息或无息贷款，并为发展中国家提供经济技术支持。

公民社会同样不能缺席。政府可以简化民间组织的注册程序，让公益团体更容易参与政策讨论；法律也可以鼓励企业和个人向公益组织捐款。一个宽容开放的社会，才能让扶贫力量真正扎根。

**结语**

《贫穷的本质》最核心的提醒是：贫穷不是个人的道德瑕疵，也不是命运写好的剧本，而是社会结构制造出来的系统性不公。它让无数人一生下来就输在起跑线上，甚至付出生命和尊严的代价。

好消息是，既然贫穷是制度造成的，那它也能通过制度去改变。这本书用大量数据和案例证明，贫穷有迹可循，扶贫有路可走。真正需要改变的，是我们看待穷人的眼光，以及整个社会分配资源的方式。

消除极端贫困，不能只靠某一个人、某一个国家。发达国家、发展中国家、国际组织、民间机构，甚至每一个普通人，都可以在自己的位置上做出改变。为了一个没有贫穷的公平世界，我们不该只是旁观者。

贫穷并非单一原因造成的孤立现象，而是一组相互嵌套的结构性困境共同作用的结果。教育往往被视作最稳妥的杠杆之一：当受教育质量提升，个体获取优质岗位与更高收入的概率随之上升，生活质量随之改善，下一代起步的起点也会被抬高，贫困的代际传递于是出现断裂的可能。

芬兰的教育实践常被拿来作为参照。这个国家把公平与质量置于制度核心，并不追求精英化筛选，而是把资源尽可能平均投放。无论居住地是北部的偏远小镇还是首都圈的繁华社区，孩子都能进入条件相近的校舍、得到相近的师资。起跑线的平整让家庭背景的影响受到抑制，教育在此既是个人发展的通道，也是社会凝聚力的来源。由此可见，重视学业投入的意义不仅在于提升文凭，更在于缓解整体的贫富分化。

若仅盯着课堂，贫穷的成因就难以说清，必须把视野转向文化与社会结构。文化惯习与群体标签会悄无声息地划出可见与不可见的边界。比如对女性的传统定型、对特定族群的先入为主，这些观念会渗透进招聘、晋升、信贷与司法流程，形成难以察觉却坚硬的屏障。受困于此类屏障的人群，很难凭借能力本身获得公平竞争的机会，抗风险能力被持续削弱。

更值得注意的是“宿命化”心态。某些语境里，贫困被合理化为命中注定，所谓“安于现状”成为一种社会默许的劝退。心态的钝化比物质匮乏更具破坏性，它会熄灭向上行动的动机。与此同时，资源富集阶层的子嗣可轻易继承人脉与资本，而资源匮乏家庭的子嗣却只能在低起点上自力更生，阶层流动性随之收窄。

印度的性别秩序提供了一个清晰的注脚。尽管法律层面废除了种姓制度，民间对女性角色的固化想象仍然强势。家庭内部与公共话语中，女性常被期待承担照顾义务，接受高等教育、参与职场与公共事务的机会被系统性压缩。企业招工、晋升通道因此出现明显的性别缺口，长此以往，女性经济自主权受损，国家也付出了巨大的人力资本浪费。

政治与经济的运行逻辑同样深刻地塑造着贫穷的版图。政局动荡会带来社会不确定性，投资萎缩、岗位消失、财产安全受损，普通民众首当其冲。发展机会的分配不均同样关键：当高收入岗位与创业资源高度集中于特定群体，收入差距被拉大，贫困风险被结构性转嫁。

政府的干预取向具有决定性。健全的社会保障、公共医疗与教育补贴能够在冲击来临时提供缓冲；反之，政策缺位或分配不公会让弱势群体更容易滑向贫困。宏观经济周期也起着放大作用：扩张期就业宽松，萧条期裁员潮涌，贫困率随之波动。

委内瑞拉的近期经历颇具警示意义。持续的政治僵局叠加经济失序，导致高通胀、物资短缺与社会不安。原本处于中产位置的家庭迅速跌入赤贫，资产贬值只在数日内完成。这印证了个体努力虽重要，却难以抵御系统性崩塌。

综合来看，贫困的根源可归结为机会失衡、教育断层、文化与结构性偏见、以及制度性失灵四方面协同作用。应对思路必须多维并进：一方面扩大优质教育的可及性，减少因出生地与家庭条件带来的差异，提供奖助贷等支持；另一方面清理制度与话语中的歧视性惯例，使各类群体获得同等展示与发声的机会。财政层面应向医疗、住房与就业支持倾斜，织密安全网。经济层面需稳定营商环境，扶持中小企业与创新创业，让增长转化为就业与收入的改善。

贫穷是多病因交织的慢性社会问题，需要近期的救助与长期的结构修复并重。只有当每位成员都感受到自身努力能够带来改变时，社会机器才可能沿着更公平的方向持续运转。

随后要演示的是另一项“拆书”实践：如何用蒙太奇视角解析经典文本。

先回顾GPT 3.5的尝试。模型输出了一份关于《杀死一只知更鸟》的拆解提纲，先做作品与作者的简要介绍，再把文本切分为若干单元，概括情节、人物变化与关键语句，随后对斯科特、阿提克斯·芬奇与布·拉德利进行人格与动机梳理。主题层面聚焦种族偏见、无辜者受累、道德成长等母题，并提示佐证原文。象征层面把知更鸟与拉德利宅邸当作核心隐喻，探讨其意义承载。背景层面把故事置于20世纪30年代美国南方社会风貌中，说明时代氛围对叙事的影响，并分析第一人称视角带来的代入感。结尾讨论出版反响与文学史地位，最后提出开放性讨论问题。总的来说思路完整，但演示者指出模型在执行时偏离大纲、效率低下，因而未完整展开。

再看Claude 2.0呈现的答卷，颗粒度明显更细。

演示以人物蒙太奇切入。以律师阿提克斯·芬奇为例：盛夏的南方城镇，他踏下车身，衬衫被汗水浸湿。围观人群高声要求对黑人被告严惩。芬奇没有退缩，也未情绪化地抨击，他逐条拆解证据的薄弱之处。有人问他为何要为“那样的被告”站台，他回应道：如果正义被恐惧取代，我们还能坚守什么？他的勇气不在于逞强，而在于在偏见坚固的堤岸前仍选择站立；他的仁慈在于看见他人的无知后仍愿以理性化解。他在充斥偏见的社区里，扮演了不肯弯曲的脊梁。

第二束光落在小女孩斯科特的成长轨迹。她怀着假期期待来到小镇，凶案起初对她像一场新鲜事件。旁听审判时她曾附和成人世界的鄙夷，直到“必须钻进别人的皮肤里去感受”这句话击中她，她开始重塑观察方式。她悄然接近被告，第一次见到一张温和而不具威胁的面孔，第一次怀疑起所谓“真相”。这个暑假完成了她认知上的换血：从随大流的旁观者转变为愿意理解他者、敢于质疑成见的人。觉醒往往始于一次心口的收紧。

最后是被告汤姆。外界难以相信温顺的他会犯下暴行，但他沉默的外壳实为长期求生训练的结果。校园里被称作贬义词，走在路上被推搡进泥水，他学会把拳头藏起，因为直接对抗只会迎来更残酷的报复。他的顺从是环境逼出的生存技巧，他的退让是黑暗中的妥协。即便命运苛刻，他仍寄望于世间存在不以肤色论断的善意。这三个人物如同三枚不同焦距的镜头：芬奇指向公理的支点，斯科特指向疑问的起点，汤姆指向牺牲的绝壁。三道视线交汇的结论是：行正义之事，暗夜才可能透出微光。
