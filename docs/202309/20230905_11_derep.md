# 更好可以做，为什么我偏偏选了将就



## 能做得更完美，干嘛不去做？

作者：小马宋
日期：2023-08-29

完美方案我清楚，问题是我没有资源去耗。

最近读书群里有人来吐槽，说刚进来一个新人，一路私信加人，备注写着加微信送课程，典型的来钓鱼的。群友提议不如以后进群都严格把关。

我回他，这事办不了，成本我扛不起。

假如真想杜绝这种进群就广告的人，思路无非几种。

第一种，熟人闭环。只让老成员拉人，朋友带朋友，质量自然可控。可这和我办群的初衷撞车。我想做的是开放的、大量的读书交流场，不是私密小圈子。要是靠一对一拉人，我这上百个群根本管不过来，绝大多数想来的朋友也进不来。

第二种，进群先审核。听起来最靠谱，实际上最扯。一个人一天加一百，我就要点一百次同意，我一个人管群，没助手，没这个精力。再说审核能拦住谁？一个普通头像普通昵称的账号，你怎么提前判断他会不会发广告？这事没法预判。

理论上可以去查他历史行为，看他在别的群里有没有发过链接。可找腾讯调记录，操作难度和时间成本都爆表，属于想想就放弃的方案。

所以，最后能用的就只剩一招：先进来，先放行，出事就封。只要一发广告，直接拉黑，并且全群同步拉黑。

这做法谈不上优雅，也不是最理想的状态，但它是我当前人手、时间和精力条件下唯一能跑通的解法。

这件事和做咨询的逻辑一模一样。你脑子里可能有个很炸的创意，但落地要花五千万去拍片，可口可乐或许能玩得起，小企业一碰就死。只盯着效果不算成本的方案，本质上就是空谈。

真正难的，从来不是想出一个好主意，而是把好主意变成现实。所以我常说，真正懂生意的人，看的是能落地的方案。这件事对我们公司而言，是方向，却不代表一定能做到。
