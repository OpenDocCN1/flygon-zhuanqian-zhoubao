# Weights&Biases 创始人：最疯的还是投资人，几乎没人将 LLM 投入生产
作者：龙哥

大模型热火朝天，但真正敢说“已经跑通生产环境”的有几个？

最近看了 Weights & Biases 创始人的一段分享，印象最深的一句话是：最疯的其实是投资人，因为放眼望去，几乎没什么人把大模型真正落到生产里。

这背后还有个更扎心的起因。

当年 Lukas 之所以创办这家公司，就是因为他察觉到：机器学习和深度学习发展得实在太快了，可那些真正在一线做模型的人，却缺一套趁手的工具。

搞AI的人，总不能一直靠手抄笔记来管实验吧？他们需要的是能追踪模型表现、管住数据版本、还能把模型注册归档的完整链路。没有这些基础工具，再聪明的算法也跑不稳。

所以，与其说大家在疯狂追逐大模型，不如说真正该被盯紧的，是基础设施能不能跟上这轮狂飙。毕竟，投资人可以疯，但生产环境不能崩。
