# 【其他】10 篇

我平时分享的东西大多能放进某个“正经”分类里，但总有那么几篇，既不想硬塞进某个系列，又舍不得扔掉——于是就有了这个名为“其他”的小合集，里面不多不少，正好10篇。

这些内容谈不上统一主题，更像是一盒“盲选零食”：有的可能是随手记下的灵感，有的像是碎片化的思考，甚至有的读起来会让人怀疑“这也能算一篇文章？”但它们都有一个共同点，就是我觉得值得被你看见。

与其让它们零散躺在收藏夹吃灰，不如聚在一起，做一次集中展示。我把这10篇全部汇总到了同一个页面里，点开就能通读，省时又省心。

传送门在这里，感兴趣的话直接点：
