# ('以男性视角在小红书上写情感账号，数据反馈好，变现也不错', (2, 29))

今天刷到一份很实在的分享，来自小红书博主邢加七。他用自己的男性视角做情感账号，把数据、变现、选题思路都讲得很透，我觉得特别适合想在小红书找机会的人认真看看。

去年他开了一个小红书账号，初衷很简单，就是想把跟媳妇的日常点滴记录下来。没想到写到第四篇就出了爆款，点赞超过5000，涨粉2000多。做到现在差不多一年，粉丝4万多，不算特别多，但互动质量很高：百赞率99%，千赞率54%，万赞率5%。靠着这些数据，他图文报价已经到8000一条，每月保底接两条广告。其实邀约远不止这些，平均每个月能超过13条，只是他比较挑品牌，大部分都拒了。

他做了一组对比，特意看了粉丝量10万以下的男性情感婚姻博主，发现这类账号的报价通常是粉丝体量的10%左右，每月报备广告能接超过10条。再算上非报备广告，扣掉手续费和返点，哪怕粉丝量还没到两万，每个月靠广告到手就能稳定上万。

更关键的是，起号并没有想象中那么难。只要选题方向对，写作思路清晰，多出几篇千赞万赞爆款，快的一两个月，慢的半年，就能把号做起来。

那选题怎么来？他给了两条路。

第一条：如果你天生对内容敏感，也擅长表达，那就试着从生活细节里找那些自带争议点和传播潜力的两性话题。他自己有6年情感公众号的底子，对什么内容更容易爆有预判。不过当时开这个号，更多是为了记录，想更真实一点，所以故意不用技巧。结果嘛，涨粉慢了一些，也少赚了不少钱。

第二条：如果想快速起号，不用自己瞎琢磨。先去研究一批对标账号，把历史爆款选题扒出来，然后用自己的视角和亲身故事重新讲一遍。虽然中心思想和底层逻辑都相同，但只要故事不一样，平台就不会判抄袭或洗稿。他说每次自己写出爆款，后台就会出现一堆同款选题的内容，但人家换了个故事，你根本没办法投诉。

为什么这个方向能跑通？因为小红书的主流用户是女性，她们已经看了太多同类视角，反而对男性视角的新鲜感很强、包容度也高。很多女性用户会留下类似评价：女生写这些可能觉得一般，但男生写出来就让人感觉特别治愈、特别美好；还有人说，光是你愿意写这么长的文字，就已经值得满分。所以这类笔记的互动数据天然不会差。

当然，写作视角要有偏向性。比如从男性角度写婚姻里的自我反思，读者会顺手@自己的另一半来看，阅读量和评论权重一起涨，很容易助推成爆款。再比如写媳妇平时对自己有多好，读者会觉得学到了，点赞收藏，还会反过来夸作者能看到对方的好。

他强调，自己的内容只写自己的经历、经验、教训和反思，不会为了迎合流量就一刀切骂男性。但如果只是想快速起号接广告，走“夸女人、骂男人”的煽动路线，确实更容易出效果。怎么选择，看你自己想要什么。

最后他分享了自己写过的十大爆款选题，几乎每个方向都验证过：

1、吵架：为什么老婆从不服软、为什么每次都是我哄老婆、我是怎么哄的——这个方向出过3篇万赞。注意，这里的哄不是低头认错，而是用非暴力沟通帮老婆疏导情绪。

2、仪式感：女生真正想要的仪式感是什么，具体该怎么做——出过2篇万赞。

3、情绪劳动：说说什么是情绪劳动——出过2篇万赞。

4、疼老婆：为什么要疼老婆——也有万赞爆款。

5、夸老婆：从日常琐碎中发现老婆的优点。

6、有效沟通：亲密关系里的重要性以及具体方法。

7、说到做到：行动比承诺更重要，尤其在两性关系里。

8、控制情绪：自我对话、课题分离等方法。

9、婆媳相处：男性怎么当好中间的桥梁。

10、男生都该来写小红书：男生写小红书的各种好处，他写了两篇，都是千赞，关键是涨粉率特别高。

另外还有两个很实际的提醒：

第一，封面图很重要。想更早接广、报价更高，首选真人照片，统一修图和调色风格，用相机拍摄的质感会更加分；其次是干净好看的风景图；最后才是动漫表情包之类的。表情包不影响数据，但品牌方看到后很可能就绕道走了。

第二，既然打算靠广告赚钱，就要给广告留出位置，别把内容塞得太满。

这个分享也许不算什么石破天惊的秘籍，但胜在真实可操作。尤其对想在小红书做副业的男性朋友来说，是一个很不错的参考方向。有问题欢迎在评论区交流。
