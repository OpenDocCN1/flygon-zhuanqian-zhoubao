# 这半年我读到的最有分量的成长笔记



## 这半年，读过最好的一篇成长文章

作者： 龙哥的收藏夹

日期：2023-09-04

进入七月，《黑客与画家》的撰稿人 Paul Graham 放出了一篇长文，主题是关于如何成为卓越。

流传的说法是，这篇稿子他酝酿了整整半年，洋洋两万字，只为拆解一个核心疑问：横跨不同行业，那些真正做出非凡成就的人，背后是否存在共通之处？能不能从他们的工作方式、人生选择和世界观里，提炼出一些可借鉴的规律，来指导我们完成更出色的作品？
