# 用 AI 产品拆解，给你一套可落地的 MVP 规划思路



## 以 AI 方向为例，彻底讲清 MVP 到底该怎么规划

作者： Max

日期：2023-09-13

赚钱的朋友们，嗨，我是 龙哥。

先简单做个自我介绍：曾在腾讯担任产品经理，后来担任过多个上市集团的产品总监，主导过数款 DAU 上百万、月流水破亿的项目。经历过两次创业的失败，目前在一家新三板上市公司担任副总裁，负责产品研发与市场营销。欢迎对这个领域感兴趣的朋友加我交流。

今年 4 月入驻赚钱之后，阅读社区内容、与圈友沟通，让我收获颇多。

对我触动最大的是，无论是大佬还是新手，大家都很真诚地在分享自己的认知、知识、能力与技能。

我在赚钱汲取了不少，也一直在琢磨，如何把自己的经验反哺给社区。

受一些机缘推动，这篇文章就此成型。

为了让内容更易懂，我以现在很火的 AI 产品赛道作为切入点，想通过这篇文章帮助大家弄清楚 MVP 应该怎么规划、怎么思考。

为何要聊 MVP 这个主题？

加入赚钱后我发现，很多项目都是在做从 0 到 1 的验证，也有不少圈友在聊 MVP。

但在理解和实操层面，可能存在偏差或只看到了一部分。

因此结合自己多年做互联网产品 MVP 的经历，希望能提供一些新的视角。

帮助大家更正确地运用 MVP 方法，顺利跑通从 0 到 1，拿到想要的回报。

更多详细内容，可移步飞书文档查阅。
