# 一、结构化 prompts 是什么

## 1. 结构化意味着什么

按 GPT-4 的说法，结构化就是按照事先约定的格式和模式来组织信息，让信息更容易被理解、分析和处理。

![](img/cdd0d329298ae60261a0ba8983bcc6ec.png)

通俗讲，就是用 AI 更习惯的编程式语言，把我们想要的和不想要的要素都填进去，让模型快速抓住重点，给出更精准的输出。

## 2. 通用结构与说明

一份常见的结构化 prompts 通常包含：角色、目标、约束条件、技能、执行流程等模块。

具体维度及说明见下表：

```
# Role:
角色（定位角色，方便后续输出的内容更专业➕聚焦）

## Profile:
- author: 作者名称（保护创作者权益）
- version: 版本（设置 Prompt 版本号，记录迭代版本）
- language: 语言（设置语言信息，一般是中文/英文）
- description: 角色描述（一句话简要介绍角色设定，技能等）

## Goals:
- 目标（设置该指令想要实现的目标，建议一开始就确定好，确保后续的指令是围绕着目标进行，不会偏离原目标）

## Constrains:
-约束条件，建议分点描述（把不想要/禁止做的信息内容填写在该处，确保输出的质量符合预期）

## Rules:
-规则，建议分点描述（可理解为：我们想要AI做的事情,也是确保输出的质量符合预期）

## Skills:
-技能，建议分点描述（重要‼️描述技能项,强化对应领域的信息权重）

##Example:
-参考例子（这个建议设置，方便AI借鉴输出符合内容）

## Workflows:
工作流程
1.流程a
2.流程b
3.流程c

## Initialization: 
-冷启动时的对白（强调需注意重点的机会+告诉用户关于该指令的信息）
```

补充两点：

1. 参考例子 <example> 非常重要！！！</example>

想要模型产出符合预期的内容，就得给它看样板。就像给下属派任务时，附上一个示范案例，执行效率会高很多。人是这样，AI 也是这样。

Q：有些领域我不懂，怎么给专业例子？
A：不用担心，文章第三部分我会分享一个提效神器，先卖个关子。

2. 工作流程 <workflows> 的通用思路</workflows>

流程的设计是为了让 AI 按我们的步骤走，总结起来一般有三步：

（1）接收用户信息，进行分析和提炼
（2）调用 <skills>，结合 <example> 开始生成内容</example></skills>
（3）输出结果，并邀请用户反馈以便优化

注：实际使用时可根据场景调整

你会发现，经过这样拆解，写指令就像做填空题，把对应内容填到指定位置就行，对文字功底的要求一下子降下来了。

# 二、为什么建议用结构化 prompts

对 AI 和使用者双方都有明显增益。

✅ 对 AI 而言：结构化 prompts 能精准激活大模型的能力，通过固定格式引导模型给出想要的效果。

✅ 对使用者而言，好处有三点：

（1）表达更清晰，按规则和格式提问，意图更明确，写指令的门槛更低；
（2）效率更高，模型更快读懂需求，响应更快，省时间；
（3）迭代更方便，后续优化只需在对应位置改动即可。

注：迭代后记得更新版本号，看着自己的 prompt 越来越好用，那种成就感很强😄

# 四、结构化 prompts VS 文字型 prompts

工具的价值在于帮我们更快更好地完成工作，所以两种指令形式都建议掌握。

我个人在实操中更多是混合使用。
