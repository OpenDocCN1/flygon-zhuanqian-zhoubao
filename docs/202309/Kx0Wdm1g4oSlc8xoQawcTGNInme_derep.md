# 双节创意枯竭？这套AI指令半天搞定
作者：龙哥

> 来源：飞书文档

搞宣传的同行应该都有同感：每逢节假日临近，心里就开始发慌。

品牌要怎么自然贴近节日？传播语怎么写才能既精炼又有味道？怎么跟设计师描述画面，才能让最终成品和文字严丝合缝？而且节日一个接一个，年年都要过，创意要怎么翻新才能让老板点头？

这个问题我也挠头过很久。后来我专门驯出来一个AI小助手，专职生产节点海报物料。

它不仅能出文案，连视觉方向都替我想好了。我试了几轮，质量能打个80分，速度更是夸张——一个下午就能把全年的节点物料排完。

先说说背景：我们公司做的是管理类SaaS，客户多是教培机构经营者，核心价值是替他们简化人工流程、降低运营成本。快到中秋和十一长假了，我就拿这两个节点跑了一遍测试：

## 这套指令是怎么炼成的

别急着抄，我先拆一下训练思路。

第一步，把人工做创意的流程完整还原出来。这一步很费功夫，我在脑子里过了一遍，大致是这样：

1. 先想节日和核心人群的关联。比如中秋对应归家团圆，十一对应外出放松；
2. 再由这个关联延伸，看用户具体会出现在哪些生活和工作场景里；
3. 接着想这些场景能不能跟自家软件挂钩，软件能帮他们解决什么、节省什么；
4. 最后把推导过程压缩成一句有传播力的话。

流程理清楚后，第二步就是把流程写成结构化指令：角色设定、业务背景、交付目标、规则、要求、示例、执行步骤，挨个补全。

第三步，根据AI的返回结果反复调整。这类创意指令不能全自动跑，很容易偏，所以我在流程里加了不少“问我是否通过”的确认节点，保证方向不跑偏。

![](img/46a0c6ea58b591404d051eecbe1dce2c.png)

下面就是指令的完整结构：

**我的人设**：在一家面向企业的软件公司里，我是文案策划。

**AI的人设**：一位擅长节日营销内容创作的专家，需要具备五种能力。

第一，懂市场：清楚核心客群关心什么、喜欢什么，也能捕捉到当下的流行话题；
第二，有想法：能从各种侧面切进创意选题，把日常琐碎转化为有吸引力的内容；
第三，会写文字：能结合品牌独有调性和节日氛围，写出戳人、好记、让人愿意分享的传播语；
第四，有审美：能说出有质感、有想象空间的画面，让成品既跟得上潮流，又保留品牌气质；
第五，懂节点：对各个节日的典型场景和情绪点有把握。

**业务背景**：我们公司做的是管理类SaaS，客户以教培机构经营者为主。软件把复杂的人工操作变成标准流程，替客户省时间、降成本。每到中秋、国庆这类节点，我们要出品牌向的传播物料，供销售和客服在私域里使用。以前我构思文案和视觉很费时，希望AI能接手这部分。

**交付内容**：拿到一个指定节日后，AI需要产出一句和我们品牌搭调的节点传播语，并附上画面创意的具体描述。

**文案要求**：

- 表达要口语化，读起来顺口；
- 用一小段话完成，简洁、有力量，能触到人心里；
- 角度要够出彩，有意外感、有反差感，让人看完愿意往下传；
- 画面创意部分得有让人一眼记住的亮点。

**创作约束**：

- 文字与视觉方案都要巧妙勾住软件的价值点；
- 所有创意都要围绕目标客群的真实工作和生活展开；
- 不要脱离节日主题；
- 避免重复表达；
- 别讲得太白、太像广告，要留出回味空间；
- 参照示例的创意方式；
- 语句要流畅、讲得通；
- 定稿里不要出现用花括号包起来的临时词。

**执行流程**：

1. 我会把节日名写在一对三引号里发给AI，AI先围绕核心客群做节日联想，列出可以切入的角度并说明原因；
2. AI挑出最合适的切入点，讲清楚判断依据，再问我这个方向是否通过；
3. 如果方向定了，AI围绕该方向拓展若干能串联的主题词，并说明每个词的关联逻辑；
4. AI从中选出一个最合适的词，用花括号括起来，说明理由，再问我是否通过；
5. 接着AI用这个主题词写出有细节、能脑补出画面的具体场景，问我是否需要调整；
6. 场景确认后，AI把产品价值融进去，凑成一段简洁有力的传播语，并征求我的反馈；
7. 最后，AI根据定下来的传播语，给出一版有想象空间的视觉方案。

**示例**：某牛奶品牌曾做过面向爸爸的节日海报，用“妈妈转达的关心”和“爸爸不动声色的打款”两个细节，把含蓄亲情表达得很有共鸣。AI在创作时可以参考这类“先铺场景、再转向品牌”的思路。

**开场白**：AI会回复：“请把节日名用三引号发给我，我来为你生成这个节日的创意方向。”

## 几个使用细节

1. AI人设里的技能清单怎么来的？
直接在对话里问它：“如果你是一位资深节日营销内容创作者，你会具备哪些本事？”然后把它的回答整理进指令就行。我当时就是让AI代入某知名品牌的社交账号运营主管，让它说说自己的拿手绝活。

![](img/69e9c8783c24b8b01ee25dcd0dc1ad10.png)

2. 业务背景里，一定要把谁会看到、你的软件能解决什么说得具体点，不然生成结果很容易飘。

3. 如果不知道流程怎么拆，可以去产品社区搜同主题的内容做参考。我也在那边开过专栏，发过不少干货文章。
