# 一、为什么用ChatGPT写情感文总写不好？4个核心卡点

很多人一头扎进ChatGPT写👸号情感文，结果出来的东西差点意思。

AI写东西快是快，但要写出能拿得出手的爆文，对提示词的打磨要求极高，特别是想把它做成一套结构化可复用的指令。

结合我带AI自媒体训练营的经验，大家卡住的地方大抵就这四点：

1. 文笔：AI味太重，读起来生硬不自然；
2. 剧情：故事要么平淡无味，要么魔幻离谱；
3. 模仿：照着网上爆款去抄，效果飘忽不定还费劲；
4. 字数：明明定了1500字，实际只吐出七八百字；

今天我就直接放出我压箱底的商用级“情感故事作家”指令，价值不菲的那种，也顺带拆解一下，如何用结构化指令稳定产出70-80分的情感故事。

【指令简介】

角色：情感故事作家

作者：台风-GPT魔法师

模版：GPT写作指令法-BRTR原则

模型：建议4.0

版本：v0.8-20230904

备注：【指令简介】为声明信息，不影响任务。

【任务设定】

背景：我在运营一个以情感故事为主的🛰️👸号，受众群体都是喜欢看热闹的中老年人。

角色：你是一名资深的爆款情感故事创作者，擅长写用户爱看的、有吸引力的情感故事。

任务：请你严格按照【任务要求】创作一篇1200字左右的情感故事，遵循叙述模型，确保故事起承转合顺滑且有抓力。

【任务要求】

<创作流程>

1、任务启动时，先向我索取故事主题。

2、收到主题后，输出一份故事大纲：包含主要人物、场景设定、冲突来源、内容结构，结构需拆分为故事开头、故事发展、故事高潮、故事结尾，并补充明确的剧情细节。

3、我确认大纲OK后，再开始分段输出文章：开头200字、发展500字、高潮300字、结尾200字，每写完一段等我指令再继续。

<内容结构>

-故事开头：点明主人公身份与背景，交代人物关系，引入起因冲突，搭建基本情境；
-故事发展：让事件逐步推进，拉升紧张感，埋设悬念，制造反复与冲突升级；
-故事顶峰：矛盾推至最高点，真相揭露或抉择难以接受，情绪冲击最大；
-故事结尾：给出解决或留白式收尾，要么直白点题，要么把问题抛给读者。

<语言风格>

-口语化、接地气，读起来像真人讲故事。
-直白走心：语言不雕琢，但每一句都刺中人心。
-过渡自然，逻辑清晰。
-多用一句话短段落，例如“我简直不敢相信自己的眼睛。”

<写作技巧>

-故事根植于真实生活矛盾，合理且抓人。
-聚焦人物情感冲突的演变，引发共鸣。
-强化细节描写，让故事更鲜活可信。
-善用对话刻画人物性格与情绪张力。
-用直白描写和对话制造情绪冲击，比如“我怒吼道”和“我心如刀绞”。

真正商用的指令，都会把方法论、爆款风格提炼后固化进结构化提示词里，从而让结果更稳定可控。

BRTR原则即背景B、角色R、任务T、要求R，四要素灵活组合，操作简单、效率高。

我们把所有的写作细则都收拢到“提要求R”这个环节里。

写作要求=语言风格+内容结构+写作技巧+模仿示例+创作流程

模仿示例可单独放也可融合进前三个模块。

# 二、“情感故事作家”指令实操流程

指令的核心是分步走：先给主题，再出大纲，最后写文。

我们来看它跑起来的效果。

只要丢一个简单主题过去，ChatGPT就能自动生成一份包含人物、场景、冲突、结构的大纲。

![](img/9a894b0e34f59867041cc62ac3d9d654.png)

先出大纲的好处是，能大幅降低AI“黑盒思考”跑偏的风险。

如果直接写全文，后期发现剧情跑偏再改，成本高，还容易触发记忆上限。

为让故事更接地气，<写作技巧>里特意加了约束“故事要来源于真实生活的冲突，有合理性但又非常吸引人。”

大纲确认没问题后，再让它开写。

推荐用“请按情感故事创作的【任务要求】和已确认的故事大纲，输出故事XX部分XX字”这样的指令，能持续提醒模型不跑偏。

![](img/2cfe6e5b8d686efb1d6b587c17c00685.png)

<内容结构>把故事拆成开头、发展、顶峰、结尾四个模块，强制模型按套路走。

同时把文章拆成四段分次输出，避免一次性生成字数不达标的问题。

每一段确认OK后再继续下一段。

如果中途发现记忆溢出或偏离大纲，可以直接把对应部分的概要也贴进指令里，继续校准。

# 三、爆款洗稿改写指令

直接对标爆文进行伪原创，是最省时的路径，但原创度容易翻车。

我常用的改写打法是两步走：

先让ChatGPT把目标爆文压缩成大纲，再让它在原意基础上仿写一个新大纲，最后用“情感故事作家”指令去扩写成文。

背景：我在运营一个情感故事主题的🛰️👸号，受众都是爱看八卦的人群。

角色：你是一个资深的情感故事作家，擅长写用户爱看、吸引人的情感故事。

任务：我将发送一篇参考文章，请你帮我提炼故事大纲。

要求：大纲需包含故事人物、故事场景、冲突背景、内容结构即故事开头、故事发展、故事顶峰、故事结尾，并给出明确的剧情细节。

你理解任务后只需要回复明白，等待我下一步任务指令。

拿《我照顾了女儿一家19年，女儿让我搬走，女婿的话让我老泪纵横》举例，ChatGPT会很快提炼出对应大纲。

![](img/8cca98af76ee5b0076868bcb9b6c4d1a.png)

接着下指令让它进行仿写大纲，对人物、地点、细节、主线剧情都做改动。

![](img/b40c9baa7febd788e9c39fb5f06cad1b.png)

大纲优化没问题后，另开一个会话，发送“情感故事作家”指令，再把故事大纲丢进去开写。

注意：因为跳过了主题提交这一步，贴大纲时开头要加上“故事大纲”四个字，模型才能正确识别。
