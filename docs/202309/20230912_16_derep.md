# 艺术走得远，靠的往往是钞能力与“不上道”



## 学艺术能出头，归根结底就两种特权

作者：小马宋

日期：2023-09-04

昨天陪孩子去拜访他的艺术指导熊磊老师，聊着聊着就拐到了一个话题：为什么身边某些艺术家特别能通关？

熊老师说他认识两位朋友，成就都很高，但成因完全不一样。

一位，纯粹是被钱养大的。家里不缺钱，他画了整整二十年，从来没为生计焦虑过。正因为不用算账，他能一直保持一种近乎天真的纯粹。空闲时间全用来读书，一个月轻松啃二十来本，从艺术到哲学、从宗教到文化，把人类沉淀下来的智慧都当成创作的养料。

钱多还有一个好处，不用去迎合任何人。没有甲方的脸色要看，没有市场的风向要追，创作自然就干净。

另一位，则是“情商不行”的典型。

情商低的好处在于不怕丢脸。同样跟着一个老师学画，别人都已经察觉到老师不耐烦了就闭嘴了，而他会继续死缠烂打地追问同一个问题到底。结果反而把老师压榨空了，学到的东西也最多。

这种打破沙锅问到底的劲儿，本质上就是苏格拉底式的学习法，非常经典。

当然，前者之所以能一直保持好奇，也离不开家庭条件对这种小孩心态的长期庇护。

其实套用到任何领域都一样，做事时多几个“为什么”，成长就会快很多。真正能吃上饭的本事也没那么多，掌握个几样就能封神了。
