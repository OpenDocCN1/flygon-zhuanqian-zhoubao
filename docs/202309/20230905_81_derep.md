# 当人生一直由别人来代答
作者：龙哥

很多人这一辈子，都在等一个明确的答案来替自己做决定。真正残酷的不是没得选，而是明明题目在自己面前，却始终不敢把笔握在手里。

决策这件事，说白了就是人生的选择题。每个选项背后都藏着不同的路口，不同的得失。有人在考场上犹豫，也有人把整个人生都交给犹豫来托管。

我们常说是对环境不满，对结果失望，可回头看，很多时候只是从未认真对待过自己的选择权。把决定权外包给父母、给老板、给舆论、给“好像大家都这么选”，到最后收获的不是安全感，而是一种长期性的无力感。

能做主的生活，并不是每次都选对，而是敢于为自己的选择负责。哪怕选错了，也是自己的经验；只有这样，人生才真正开始由自己书写。
