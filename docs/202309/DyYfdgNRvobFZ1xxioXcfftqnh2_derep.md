# 一、小说推文到底指什么？

上次图文篇我讲的是📕的发帖思路。这次视频篇我聚焦抖音的短视频玩法。

你在抖音刷到过下面这种内容吗？

![](img/862bf0ce85a2a11ad31d7634aa28b489.png)

目前常见的变现路径大概分三类。

第一类是关键词引流。视频里不放链接，通过评论区诱导用户去知乎、小说APP等平台搜关键词阅读。

第二类是口令引流。在标题或评论区放一个专属口令，让用户在抖音内搜索口令跳转阅读。

第三类是小程序直链。直接把小说平台的小程序链接挂在视频左下角，一键直达。

# 二、推文前必须先拿授权

不授权就没收益保障，还会有版权风险。给你两个常用授权入口。

第一类走关键词引流的平台。

想做知乎、US故事会、黑岩、番茄这些，先扫码注册对应小程序完成授权。

![](img/66e159477c6d2d0cb444de5581697970.png)

第二类走口令或链接引流的平台。

比如蓝鲸故事会、朵米故事会、桃子故事会、17K小说、掌文故事会等，都需要先扫码注册小程序拿到推广权限。

![](img/376676a78b98d9e5b1909e8413dd9ea8.png)

没授权，收益锁不住不说，平台也会有拦截风险。

# 四、视频素材怎么来？三种主流制作方式

## 1、游戏实操类

获取游戏画面有三条路。

第一，自己装个游戏App上手玩并录屏。操作不熟的可以去下破解版。

破解资源合集：http://m.6ll.com/k/dtpkmod/

第二，去抖音搜游戏名进直播间，右滑清屏后录屏。

![](img/6d5b8d90cd8ecdbf7569ed08d3019064.png)

第三，在📕发需求帖，花钱请人代打代录，把素材买过来。

拿到画面后，用微配音生成配音和字幕，再把画面、音轨、字幕、背景音乐丢进剪映合成即可。

# 六、如何让视频脱颖而出？四个提升技巧

1、养号+神回复

每天早中晚正常使用账号刷内容，像真人一样互动。评论时模仿高赞评论写一条类似的高质量回复。

这样既能提升账号权重，也是快速感知平台热点的办法，能第一时间捕捉到爆火书名和新玩法。

2、做外语配音版本

先用百度翻译把文案翻成英文。

fanyi.baidu.com

![](img/e81f75438cbfedfccfff1dd6b81caa7f.png)

再用微配音生成外语配音。

![](img/43e2b6e10982b030cbd56f7ba820b0d4.png)

最后在剪映成片。

![](img/202eced574f39c279f34eca24381c4b1.png)

效果参考如下：除了英文，日语、马来语、菲律宾语，只要微配音支持，都可以做。

![](img/3373fa56ba39ba763c1a85246dc2f461.png)

3、文中植入祝福语

比如黄色标记的部分就是我临时插入的祝福语，原文本没有。

![](img/922173d8eb343d12359edf5b9b4d3a57.png)

4、改造文案

一是开头加钩子。可以在正文前加上“万万没想到”“谁也没想到”“谁都没想到”“注意看”“你敢相信吗”“你绝对无法想象！”等强吸引话术。
