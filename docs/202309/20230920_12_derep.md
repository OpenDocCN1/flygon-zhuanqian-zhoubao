# 从李佳琦翻车，聊聊IP和社群这件事

这两天李佳琦的人设风波越闹越大，几乎每个群都在聊。很多做社群、做IP的朋友也开始自我检讨：个人IP的风险到底躲不躲得过？IP和社群，到底哪条路更长久？

上周的“社群发起人”航海分享，正好撞上了这个话题。作为助教，我也憋不住来说说自己的学习笔记。先声明：下文用小马宋老师的个人IP和龙哥盟社群来做对比，纯粹是为了把差异拆得明白，不是要捧谁踩谁。

看一眼标题“为了部落”，就能明白里面的双关——人类最古老的社群形态就是部落；玩过魔兽世界的人也都知道，游戏里的部落是典型的社群。

不少群友写日志说：这和我脑补的“什么是社群”完全不是一回事！其实我拿到手册的时间也没比大家早多少，所以这篇不是高手指路，更像新手手记——顺手还用了一下社群运营里“降低预期”的技巧。如果观点有摩擦，欢迎直接来辩，观点越争越亮嘛。

## 一、朋友圈IP，到底算不算社群？

朋友圈IP，说白了只是个人品牌的一种运营方式。个人品牌的核心，是围绕个人建立起来的影响力，包括你的形象、作品、风格、观点等等。发朋友圈、拍短视频、录播客、登台演讲，都是经营个人IP的手段。这类IP可以是“一群人的狂欢”，但不是“一群人的共创”。

社群则完全不同。社群的价值核心在于“集体”和“互动”。一群人抱团还不够，得靠共同的兴趣、目标或身份纽带真正凝聚起来。

拿小马宋和龙哥盟做例子，区别就非常直观：

**目标和价值观**：小马宋是个人持续输出观点，粉丝认不认随你；龙哥盟的人都是冲着“赚钱”来的，信奉“谈钱不伤感情”。

**互动与参与**：小马宋的互动基本停在评论区留言，内容是他一个人的独角戏；龙哥盟是典型的UGC社区，大家本着“利他”精神互相分享、共同创造。就像这次航海，没有成员动起来，船根本开不了。你当领队、我当教练、他当船员，一路往南开。

**信任与归属感**：小马宋的粉丝归属感是“我们都喜欢小马宋”，而赚钱圈友之间是有信任感的，大家特别以自己的成员身份为荣。我平时不爱通过陌生人的🛰️好友申请，但只要对方备注“赚钱圈友”，我立刻秒过。以前有一次让我写自我介绍，我就写了：龙哥盟44268成员。
![](img/3b848e35dc4a87825e14346da9ccdc8f.png)

**知识与资源共享**：小马宋是知识的输出者，粉丝负责接收；龙哥盟是一片共创的土壤，大家在这里提问、分享、找合作。个人IP也能让成员分享吗？不行，那是主角的舞台，你得听主角唱戏。

**集体身份**：小马宋的粉丝有没有专属名字，我没研究过。龙哥盟的黑话倒是一抓一把：“航海”“风向标”“龙珠”“愿得龙哥心”……我上次在面馆吃饭，听到邻桌大哥嘴里蹦出“利他”“航海”，直接站起来问：你们也是赚钱的？那大哥先是愣了愣，接着喊出我的ID。这就是集体身份的味道。

**支持与鼓励**：小马宋用自己的干货给粉丝们加餐；龙哥盟则靠鱼丸体系、航海实战体系给成员兜底。条形马说的“汇入车流”，就是这个意思。加入航海就像开进高速公路车流，你会有手册当补给，有群友当帮扶，有志愿者帮你托底。一个人闷头看手册，和一群人共同学习，成功率根本不在一个量级。
![](img/011b8584fed612761101c2668e4d03d9.png)

**领导与组织**：小马宋一个人就是一支队伍，自带领导属性；社群虽然强调集体，但也需要有人定方向、协调活动、维护秩序。说白了，没有规矩不成方圆，有了边界，自由才成立。

拆完这几点，大家应该有点感觉了：自己干的事，到底算不算社群。

接下来再说说两者的天花板，方便你做选择。

**扩展性**：个人IP能长多大，基本被个人能力、时间、精力锁死。人不是永动机，一天只有24小时，感冒一次输出断档一次。粥佐罗就说过：“我停了，粥左罗就停了。”社群不一样，多个人多份力，成员越多，资源和影响反而越滚越大。龙哥哪怕出国休假一个月，龙哥盟照样波澜不惊。

**适应性与多样性**：个人IP的枝干都绕着个人专长长，某一项很强，但很难面面开花。社群成员来自五湖四海，知识、技能、资源什么都有，遇到波动也更扛得住。龙哥个人的本事再大，放在整个龙哥盟社群里，也只是沧海一粟。赚钱的内容池子，压根不靠他一个人撑。

**持久性**：个人IP是长在个人身上的，健康、寿命、名声，哪一环断了都会崩塌。明星一旦爆出黑料，整个品牌价值跟着陪葬。我以前就立过flag不做个人IP，怕的就是人设还没起来，人先塌了。社群就没那么脆弱，只要核心价值还在，哪怕几张老面孔离开，盘子依然转得动。龙哥盟陪着咱们七年了，等我们活到77岁，完全能搞一个“老年搞钱俱乐部”。

**影响的深度和广度**：个人IP在某个领域可以钻研得很深，但广度会被个人能力框住；社群把不同领域的脑袋放在一起，深度和广度都能做大。话说回来，龙哥盟在公域上的动作几乎为零，这一点我觉得可以公开批评一下龙哥。

**收入天花板**：个人IP赚钱主要靠演讲、咨询、出书、卖课，本质是把个人时间包装出售。一天就那么多小时，拉到顶又能赚得了多少？社群的路子宽得多：会员费、广告、赞助、线下活动、品牌合作，甚至还能做孵化、做投资。龙哥说不定会拿下这样一个成就：赚钱没有上市，却孵化了十家上市公司。大家加油，把上市这件事搞起来。

聊到这，应该没人再纠结“朋友圈和社群是什么关系”了吧？要是真想通了要去做个人IP，那就安心去朋友圈IP的航海折腾。最后再强调一遍：个人IP和社群，没有谁比谁高级，只有谁更适合你，以及你更愿意承担哪种不确定性。

## 二、社群有哪些必备的规则机制？

群友@良辰美 很细心地记录了我们“社群发起人”群里的规则从小到大演变的过程。为什么要费劲立规则？因为规则是社群秩序和目标的红绿灯。没有规则的环境，人容易慌，怕说错话、怕踩雷，没法放开手脚；有规则，大家就知道边界在哪，只要不越界，做什么都可以。没有规矩的社群，通常离凉凉不远了。

那规则在什么节点建？

**初期**：社群刚拉起来，就得立点基础规矩，避免后面场面失控。我建“AI探索家”的时候，就定了硬规矩：小白不许发言。这不是歧视，而是一个高阶玩家俱乐部，认知必须过了扫盲阶段。试想，一群人在聊怎么把视频号GMV从300万干到1000万，突然一个新人举手：“请问视频号怎么开通？”气氛是不是瞬间就完了？认知在同一条线上，聊天才自由。

**增长期**：人越来越多，门槛就该动态调整。如果发现大量新成员涌入导致鱼龙混杂、内容质量下滑，就要在关键节点投下筛选或劝退机制。

**出乱子时**：群里两个人吵起来了，运营者得先拍板：允许吵到什么程度？会不会人身攻击？吵完了怎么罚？王者荣耀那一套就挺值得学：排位挂机、辱骂队友，扣信誉分；低于90分，直接禁排位。我在AI探索家也搬了这个模式——发旧闻（超过24小时或别人发过的）就扣信誉分。这一来，谁都知道什么不能发，大家刷信息也安心，不用担心啃到烂瓜。

至于怎么建规则，可以走这几步：

1. 先想清楚社群为什么存在，再制定对应的鼓励/禁止清单。
2. 研究一下同类社群都在用什么规则，像龙哥盟，好的地方直接借鉴。
3. 让成员参与意见，他们才是规则的亲历者。
4. 不用第一次就把规则写完美，先搭骨架，再在运行中一点一点补。

## 三、别被“正反馈”喂成傻白甜：聊聊回报和真实价值

这一节是条形马的小课堂，版权归他所有。

爆粉、爆量、爆群，这些东西为什么害人？因为它们能给你快速的爽感。正是这种爽感，耽误了不少聪明人，让他们沉溺其中三五年浑然不觉。这是最可惜的状态。

举个例子：前两天我碰见一个好产品，本来想找人搭桥投资一点，一查发现是个人开发者做的。对方一口价，100万卖了。100万多吗？对他来说，是巨款。可我和几个朋友复盘都觉得：他只要能稍微把格局打开一点，想塞给他100万的人早就排队了。尤其那支买下产品的团队，上个月已经开始正经商业化，按这个速度，不到12个月这笔钱就能回来。太可惜了。

这类故事，这几年我见了很多。其实每个人都不缺信息、不缺智慧，为什么还是会把机会弄丢？很多人以为在付费时购买的是“信息差”，我不同意。大家的困境，主要不是信息差。更准确地说，大部分人不是被未知卡住，而是被“已经习以为常的小正反馈”卡住了。限制你的不是你不知道的那些，而是你误以为自己知道的东西。错误的已知不会让你亏钱，反而会给你一点甜头，让你舍不得从舒适区爬起来。小和大是相对的，什么沉默成本、路径依赖、愚昧之巅，这些名词把一条完整的思考链拆成了一块块知识碎片。但人不是按碎片思考的，人是顺着整条线索思考的。

再问一个例子：我为什么不在手册里写“朋友圈人设对宣发有什么加成”？因为人设这东西，天然可包装、可虚构、可膨胀、可加杠杆。你当然可以说，包装能提高转化率——没错，一定有用。但提高的转化，对你钱包是好事，对你这个人是毒药。为什么？因为一旦包装有效，谁还会下笨功夫增长真本事？这等于亲手给自己造了一个局。假如我已经拥有66种方法来让别人相信我很有实力，那我就真的会变成实力派吗？不会了，再也不会了。等到真正的风险降临，别人信你不信你有什么用？真正厉害、能扛事、能平事的人才有资格活下来。只有写详情页的人自己心里清楚，那个主角到底是不是自己。

“fake it until make it”这句话，有个隐藏前提叫“知耻而后勇”。如果这个前提变成了“别人真的蠢、真的随便忽悠、口袋里的钱活该给我”，那么接下来触发的就是“fake it until fake it better”。失去自我，就相当于失去战略。

最后有三个问题，请每个人自己回答：你正在做的事，是自主选择的吗？你真的胜任吗？你处在一段健康的联结里吗？如果三个答案统统是不，那说明你的自我危机已经亮灯了，只不过暂时还没爆出来。
