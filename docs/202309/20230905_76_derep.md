# ('你的行为导致特定的结果', (2, 13))

你每次做出的选择，都会导向一个对应的局面；而那个局面所带回的反馈，又会在不知不觉中助长你类似的选择。久而久之，这一连串彼此咬合的动作，便凝结成了一个人身上那些稳定且近乎自动的习性——说穿了，它就是一个系统。![](img/e556a87b6fb7882b348ea22fb1beaa0a.png)

系统从来不是什么玄乎的东西，它就藏在你每天重复的取舍里。想重塑它，不用盯着遥远的终点，只要从改变当下一个动作开始。一旦新的动作带来新的结果，这个结果再推你一把，新的系统就会自己长出来。
