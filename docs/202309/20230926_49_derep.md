# 从月光宝妈到月收3万+：一个重庆全职妈妈的民宿逆袭实录

大家好，我是糖糖家。

在重庆做小区民宿的二房东，我是带娃的宝妈，也是从零收入起步、靠着民宿走到月入3万多的人。用了两年半的时间，把“手心朝上”的生活翻了个面。

2022年4月我加入赚钱，最初的状态就像刘姥姥逛大观园，看什么都新鲜，赚钱原来还能这么玩，真的被惊到了。很长一段时间我都只在潜水区默默看。直到今年才开始主动链接圈内的优秀伙伴，思路才被打开，行动才开始加速。

这次能站出来写这篇经历，最大推力来自老瞿Qu的一句话：“分享让经历更有价值”。这句话把我从长期潜水的状态里拉出来了。非常感谢赚钱这个平台，也特别感谢一直给我帮助和鼓励的同路人，没有他们，可能我还会一直潜到地老天荒。

很多人问我是不是财籽。不是，我就是一个野生的二房东。做的也不是诗和远方那种网红民宿，而是离家近、方便带娃的小区民宿。最初的动机也很朴素，就是想在照顾孩子的前提下，让家里有稳定的现金流。

从0到月入3W+，这两年半走下来，最大的感触是项目要深耕，别急着换赛道。也是在这种坚持里，我才有了从容应对颈椎问题、长时间对着电脑手机带来的身体负担，并一步步走出来的底气。

关于具体的选址思路、房源运营、客源获取和复盘方法，我整理在了飞书文档里，方便大家系统阅读。
