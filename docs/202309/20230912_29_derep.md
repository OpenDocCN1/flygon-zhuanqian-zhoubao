# ('通俗化理解 ChatGPT 如何做到词语接龙？', (2, 25))

你有没有过这样的疑问：明明只是敲了一句话过去，ChatGPT 却能在几秒钟内生成一大段回应，它到底是怎么办到的？它凭什么能从庞大的字词库里选出这些内容，再拼成我们看到的答案？

其实，ChatGPT 本质上就是 AIGC，也就是我们常说的生成式人工智能。说实话，我第一次接触它时根本没细想原理，只感觉这家伙简直太神了。直到后来深入学习，才意识到弄懂它背后的逻辑有多重要。

想想最早那批研究提示词的人吧，那真是一段苦日子。网上资料少得可怜，哪像现在随便一搜全是教程。我曾经跟一位玩提示词的高手聊过，他说那时候大家都是硬啃原理，从最基础的概念开始，一句一句去问模型，一次一次去试，遇到问题就忍不住琢磨：“它这到底是怎么想出来的？”说实话，这条路虽然慢，但恰恰最扎实。懂了原理之后，再遇到各种奇奇怪怪的报错或输出，你就不容易慌；后面写结构清晰、逻辑严密的提示词，也顺手得多。

通过这段时间的摸索，我基本理清了两件事：一是 ChatGPT 怎么理解我们输入内容的真实意图？二是它回答问题时，那种像词语接龙一样逐字推出的“涌现”到底是怎么回事？
