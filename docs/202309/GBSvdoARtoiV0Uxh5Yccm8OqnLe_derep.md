# 12小时发起一个社群，创建一个千人社群，难吗？

12小时从0到1400人，这个新社群是怎么做到的？

前几天，我亲身参与了“社群发起人”航海实战。既然是实战，就不能只坐在岸上学理论，总得下海把袖子卷起来干一把。

![](img/04c1f66408749c147dc9de1c1d38b691.png)

昨天，条形马教练和刀姐小助理在航海群的直播中，现场发起了一个新社群，从启动到成型，只花了12个小时。很多人会问：12小时发起一个社群、建一个千人规模的组织，难不难？

下面，我以船员兼参与者的身份，对这次发起过程做个复盘。部分思路参考了《社群发起人—航海手册》。

![](img/3d69f01ff48a6a842e46fd57d1b6f04d.png)

先来说说这个新社群的基本盘。它的主题是分享有趣的“梗图”，载体是知识星球加微信群——星球负责沉淀内容，微信群负责裂变传播。知识星球到发文时已有1400多人，免费分享；微信群有170人。规则上，除了常规运营规则，还加了一条特别的：星球里只准发图片，不准发文字。社群成员最初是赚钱圈友，随后逐步向外围扩散。

时间线是这样推进的：9月12日晚上21:27，刀姐和条形马老师在微信群里发起倡议，同时开始接龙；21:43，微信群开始组建；22:02，刀姐在知识星球上创建了星球，并发出第一篇帖子。到了第二天上午9:41，星球人数突破888；10:03突破1000；13:30突破1400。直到发文，人数还在持续增长。

![](img/b03018894fcd0ec8d74b871ba8713a41.png)
（图源：星主黄小刀）

这个局为什么能快速起势？首先是定位够清楚。整个社群始终围绕“梗图”展开，并且可以延伸周边产品。发起人心里很清楚，社群定位必须明确、聚焦、实用：社群不是杂货铺，不能什么都往里装。焦点越清晰，才越不容易跑偏，也才能把核心力量凝聚起来。

![](img/de2314a29b13dd870ac58c952ca81bba.png)
![](img/3c1cbf5c028995629a270d8e71be6c9b.png)

再说主题。社群文化里最有辨识度的社交符号，就是“梗”和“表情包”。这个社群的主题恰好踩中了这个需求：你需要梗？这里有；你想发梗？这里欢迎；你想造梗？这里随意。看到一张图就能想到这个社群，这种记忆锚点是很厉害的。

![](img/bc50e78e44facd8d5ae7ec58fb05c470.png)
（图源：星球“梗”）

航海手册里有句话：做好社群最关键的因素是“信任”，信任是发起的基础。在这个案例里，信任体现在四方面：一是解决需求，发起这个社群的确解决了圈友的真实痛点；二是慢以凝核，最开始吸收成员很慢，到第二天早上才开始爆发；三是规则明确，星球只能发梗图，简单好记，人人都能遵守；四是信任背书，社群达人们自带光环，他们一出现，潜在成员自然就多了几分信任。

人员基础同样重要。发起人具备很强的社群领导力，平易近人、真诚利他、充满热情、能力超强，这是快速起盘的关键。另外，航海大群的成员本身就有一定社群影响力，属于群众基础；还有一批社交能力极强的铁杆粉丝，秉持真诚利他的原则，主动帮忙拉新。成员们的共同特点是：响应热情、爱参与共创、乐于分享互助、自觉遵守规则。

![](img/dbff6f2abb73627c72a9d574a24fcdec.png)

社群里的正反馈也非常充足。对普通成员来说，新人会被看见、被重视；每个人都能感受到热情；创作会被认可，甚至能对接资源；提出的想法会被关心、被采纳、被表扬；发起人也很亲切。对发起人来说，他们的工作和成果被大家看见和认可；相处模式被接受；发言会被整理成金句；而且其他成员也把自己当成社群的主人。这种双向正反馈，是社群持续运转的燃料。

推广路径分两步。第一步是价值吸引、内部引流：在航海大群里用接龙汇集第一批成员，再由铁杆粉丝拉群，组成基础班底。

![](img/0a5f8c471b43b3a299fc8cc6e9eaac7b.png)

第二步是自然推动、外部裂变：老成员主动向外扩散，把船员以外的圈友、甚至非赚钱圈友也带了进来。

![](img/127efa9cae2973b5483c89113f5d7d30.png)

发起时刻也很有讲究。时间是9月12日21:20，正好在“龙哥盟—社群发起人”的直播分享中。这个时间点大家通常是放松状态，愿意接受新事物；直播主题又和社群发起契合，参与者正好在场景里。在对的时间做对的事，社群自然容易启动。

![](img/aa2a6dd3b71506d52cf18ee9f478f194.png)

社群的价值可以从几个角度看。它很有趣，大家不断发梗图，释放天性；它解决了痛点——很多人平时不能在社交平台随心所欲发梗图，这里可以，同时还能积累梗图资源库，完善周边产品供应链；它用了一个微小的主题，市场上很少见，反而更容易被记住；氛围还特别轻松，没有明显的发起人和成员之分，人人都是主人。

最后看发起流程，七步走：

第一步，定位用户需求，人人可参与。直播现场用“梗图”起话题，简单有趣，入门门槛低，小白也能上手。

第二步，通过接龙摸清意愿。在航海大群先接龙，探测种子用户，再根据反馈调整策略。

![](img/64965c7754bbe44315e94ba9be038dde.png)

第三步，吸引铁杆粉丝参与。这次发起过程中，有铁杆粉丝主动承担了社群发起、管理、汇集成员等任务。

第四步，从内部人员开始内测。先让“社群发起人”的航海船员试运行，根据反馈调整，而不是一上来就铺开。

第五步，取一个有趣、简单、易懂的名字。从名字就能看出核心规则：只允许在星球发梗图、不允许发文字。这个设定自带差异化标签。

第六步，结合用户分享，建立变现渠道。通过星球上大家的梗图分享，衍生出周边产品变现逻辑，所有人一起参与。

![](img/55e8a5e01411441ba226f09b42378400.png)
（图源：黄小刀）

第七步，用户主动分享有趣的事。很多人愿意把新社群里好玩的内容讲给外人听，甚至顺手帮忙推广，这也是它快速壮大的原因之一。

参与完这次航海，我有一些自己的思考：

社群不是靠拉人、圈人，再强迫用户形成依赖；真正的粘性来自用户自发认同，他们愿意加入能解决痛点、能带来价值的社群。社群是共创体，人人都是主人，心往一处想，劲往一处使。人们更愿意参与高价值的社群。主题不妨小一点，让每个人都能参与，参与感才会强。发起人只负责开篇，真正让社群裂变的是用户自己。无论是成员还是发起人，得到一点正反馈都要广而告之，这是持续经营的动力。相应地，违规的负反馈也要公开处理，这能划清社群边界。

以上，就是这次12小时发起千人社群的全部复盘。看起来不难，但每一步都踩在了点子上。
