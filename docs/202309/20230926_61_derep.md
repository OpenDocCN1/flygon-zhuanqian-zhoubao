# 两个月做到2.6万付费用户，GMV破500万：我从网易裸辞后，把知识星球打法的完整复盘

大家好，我是AI探索者。前段时间在龙哥盟做过一次分享，承蒙龙哥老大厚爱，把我拉进了航海家群。进群之后我真的大开眼界，群里的人个个能力超强，还特别愿意分享，相互之间的链接密度高得惊人。所以今天我把那次分享的内容再扩充一下，写成这篇文章，希望能链接到更多同频的朋友。

先简单说说我的经历。我算不上典型的互联网人，做过技术、技术管理、产品管理、运营管理，也创过业，还在大厂当过业务总经理。读书时我是个不折不扣的学渣，大学四年打了两年多游戏，挂科挂了好几门。直到大三被学校口头警告，加上游戏账号也丢了，我才开始发奋。后来一路考过四六级、高级程序员，又考进华科计算机读研。

2008年毕业后我先去了腾讯，2010到2015年作为360早期核心员工，见证了公司从500人到上市的全过程，自己从高级工程师升到了产品技术总监。360上市后我套现超过千万，拿着这笔钱在北京买了几套房，也算有了第一桶金。

再后来我连着创了三次业：第一次做手游，融了500万，没做成；后两次都是在线教育，也没大成。2020年我加入网易，担任一个部门的总经理，同时开始搞写作，三年时间在全网积累了50万读者。在网易这三年，我负责的业务年收入10个亿，做到了整体盈利，团队拿了一堆奖项，还拿到了网易集团创新奖：

![](img/0ebb29a2927344e0e7d5fa7100047694.png)

![](img/a8ebff66420b5511380eacc63f58e1c0.png)

离开网易之前，我刚在那里完成晋升。很多人不理解，为什么放着几百万年薪的高管不当，非要折腾？但真正懂我的朋友都明白，这人天生闲不住。表面上看，大厂高管光鲜体面，可我却经常在深夜失眠。不是为钱，而是那种对自由和探索的向往，一直在拽着我往前走。

真正让我下定决心的是一个机会：半年前，我观察到了知识星球的一种新玩法——用投放来快速放大规模。我当时就觉得，这件事能做很大。于是，我辞掉了网易200万年薪的职位，All in进去。

我用两个多月的时间，做出了一个299元的知识星球，付费用户做到2.6万，总GMV超过500万，在同类社群里稳稳排第一，用户量比第2到第5名的总和还多：

![](img/4ba666d2a20ee6bf31613e32f23057eb.png)

复盘下来，能在起步阶段跑这么快，我认为主要靠这五点：

✅ 在职场积累的商业和运营能力背书
✅ 自媒体带来的初始流量
✅ 身边大佬和KOL的人脉支持
✅ KOC资源
✅ 敢想敢试的投放模式

这里面，投放模式是最关键的胜负手。下面我分几个方向详细拆解：

![](img/0b05ea54be730178219a15bbd17f50c8.png)

## 一、社群本质上是个产品，产品得先“爆”

知识星球表面上是PGC+UGC的社区，底层逻辑其实是产品。做过产品的人都知道，品质决定生死。

可社群冷启动面临一个难题：刚开始内容少，凭什么让人付费？我的做法是借力。初期我硬拉着身边一大圈大佬来站台，包括投资界的吴世春、许朝军，IT圈的刘江，自媒体运营圈的黄有璨等等：

![](img/22c4ff3462d25ec4801b012619212aeb.png)

有大佬的信任背书，星球的价值立刻立住了。

但总靠星主和嘉宾输出并不持久，必须尽快从PGC切换到UGC。冷启动期一过，我就搭了一套UGC激励体系，核心是找出社群里的KOC，用精神和物质奖励让他们持续产生优质内容。这块还得感谢龙哥老大开创的玩法，给了我不少启发。我们社群发展一个月后，这套体系就开始运转，内容质量明显提升。

另外，运营活动也不能少。比如快闪式短期活动、线上直播、线下见面会，还有正在策划的实践课程。很多星球要等到第二、第三年才开始做线下，我们第二个月就接连在北京、杭州、上海、深圳搞了线下见面会：

![](img/f7c8c98c7aeaf69739e6ae1970478b26.png)

社群要的是链接感。不管是线上的快闪，还是线下的面对面，都能让会员产生强烈黏性。我们还准备策划千人大会，进一步加深互动。

说到底，用户付费进来，如果从头到尾不参与任何活动，那他就没有获得感，以后也不会复购，更不会续费。

![](img/adbf8edd2c6d499d78731a38b7b859fd.png)

## 二、增长靠投放 + 口碑，两条腿走路

我自己这个👸号，算是冷启动期的增长引擎，给社群带了大约7000个会员。虽然号不大（不到20万读者），这个转化成绩已经很可观。

可要冲向2.6万人，光靠自有渠道远远不够，真正的加速器是投放和口碑。

先说投放。我主要做👸号和视频号的CPS、CPT，另外还在尝试校企合作和线下代理。在大多数人印象里，知识星球是大V们用来给👸号变现的轻产品，很少有人会去投广告。但星球恰恰是典型的社群产品——人越多，内容越多，反而越好推；反过来，早期内容少、人少，就特别难推。

所以这里有一个核心观点：刚需性话题的星球，完全可以尝试投放。

![](img/76b24bd599da4423eff956b836623ed7.png)

什么叫刚需性话题？比如副业搞钱、赚钱思路、个人IP和品牌赋能之类的，都比较适合投放。

初期怎么最小化成本拿下第一波投放？我的建议是：先自己跑通一个小闭环，验证ROI有没有效率，然后找KOL/KOC用CPS方式放量。

MVP的思维很关键，背后需要数据能力和分析能力。我是因为看了自己账号的数据才有底气启动投放的。之前我也有个职场星球，后来发现现在做的这个星球在账号里的转化率，是职场星球的三倍。核心差别就是强话题性。

我当时自己也算过一笔账：接广告的收入和自己推星球相比，差距至少有2倍。也就是说，一个299元的产品，光靠自己推，就能做到ROI大于2。等我自己推够2000个会员的时候，那天晚上我失眠了。我意识到投放的机会来了，一旦跑通，规模会很吓人。

CPS的核心，在于前期一定要有大号帮你背书，而且要和足够多信任你的号主有交情。这种资源靠平时积累。你还需要用社群的远景去打动对方。👸号大号其实不缺广告，一般不肯接CPS，他们怕损伤粉丝口碑。

我找第一个大号的时候还在网易，花了两小时说服他，让他不做同类产品，转而来推我的产品。这个大号一跑通，我立刻拿他的案例去撬动其他号主，最终有近200个号主一起帮我推。给合作方的打款记录是这样的：

![](img/0c160c8c1836a207732d2d5ea60b05e7.png)

号主一多，打款和记账就成了麻烦事。我们花时间搭了自动化通道，把记账算法固化在Excel里，财务填几个数字就能自动出结果。

跑顺之后，社群达到了日增1000人的夸张速度。这个速度我自己都没预料到。看着GMV和用户数飞涨，我立刻下定决心辞职All in。All in之后我发了一篇文章、开了一场直播，文章阅读冲到4万，直播场观破万，又一次性带来1000多用户。

CPT我们也在做，但风险更大。CPT投放分两种：一是团队自己找号，一般在新榜上筛；二是直接找媒介，给对方抽成。选号先得看方向是否和产品匹配，我们选的是互联网、科技、创业、职场、副业类，离产品近。

筛选的时候，要看号接广告的频率、评论数、点赞数，核心就是判断IP的强度。IP越强的号，带社群这种品越好带，这和普通实物投放完全不一样，绝不能只看阅读量。我们见过只有500阅读的号，能卖几十个产品；也见过5000阅读的号，只能卖10来个。

整体投放下来，我们的ROI超过1.5，所以我们才敢持续放量。我总结了一个“可投度”公式：可投度=（点赞×评论）/阅读数×报价。这个值越高，号的价值越大，基本和ROI挂钩。给大家看一个我们投过的号，哪怕是广告文，点赞和评论都很可观：

![](img/1e1760560a280147b1a1e46a83819916.png)

视频号短视频和直播投放我们也试过，这两种都统一用CPS，因为很难用CPT定价，而且有时候还要我和对方连麦一起推。

所以别再说知识星球不能投放了，只要渠道找对、品选对，完全可以放量。比如猫叔前阵子做个人认知星球，一下就撬动几十个视频号、抖音同时直播，大概率用的也是CPS打法。

我的建议是：起步阶段先做CPS，别一上来就CPT，风险太大。

看整体GMV构成的话，我自有渠道大约占25%，CPS投放占40%，CPT投放占15%，剩下20%来自口碑增长。

接下来重点说口碑。我们在增长过程中疯狂打磨产品和服务，用品质去引爆口碑。现在每天都有50多个用户是靠老会员推荐来的，这个成绩我挺满意。

短短两个月，我们把内容栏目和新手引导建得很完善，所有用户都导进了企业微信，还搭建了激励体系和KOC发掘机制。一个社群能不能长期活跃，核心不是星主，也不是早期的嘉宾大咖，而是KOC。KOC越多，社群生命力越强，内部口碑增长就越猛（再次致敬龙哥老大和赚钱）。

很多KOC既有内容能力又有流量，把他们和社群利益绑定，他们自然愿意带人来。反过来，口碑越好，CPS才能持续放量。因为CPS本身就是号主们不太愿意接受的合作模式，只有当你的星球好到让他们觉得“我推这个产品是在给粉丝发福利”时，CPS才能长期转下去。

复盘整个过程，我认为只要是强话题性的星球，或者星主本人有强话题性，再配上一批够分量的嘉宾合伙人，星球这个产品就完全具备可投放性。价格定在99-299元区间，用户看一眼就能直接下单，不用做复杂决策。配合合适的投放方式，ROI很容易超过1。更别说之后还能在付费用户基础上做私域，搭二阶、三阶品类，实现更大规模的盈利。

## 三、降低退费率，是社群生死线

我们星球刚起步时，退费率高达20%。这个问题不解决，做多大都会崩塌。我们快速梳理内容栏目、课程栏目，光迎新流程就改了10多个版本。最高峰日增1000多用户，“迎新”变成巨大的挑战。后来我们让客服只负责自动回复和问题拉群，招募一批志愿者专门服务新用户，退费率才明显下降。

我们还优化了新手课程，给新人提供直播录播课，帮他们快速入门。一连串调整后，退费率从20%压到10%。别小看这10%，我们每天营收好几万，等于每天多赚了好几千。

## 四、利他，才是最好的商业模式

从网易离职到两个月做出2.5万社群，我最大的感悟就是：做商业一定要利他，利他就是最好的商业模式。

在网易当高管时，我手下带着百人团队，但我还是会抽时间帮助刚进入社会做自媒体的年轻人。我会用自己能提供的价值去链接大佬。后来很多年轻人成了大V，那些大佬也和我保持很好的关系。这次能靠CPS启动增长，最核心的就是我有自媒体号主的资源，没有信任，CPS根本谈不成。

再比如我设置的分销比例，几乎是同类社群里最高的，这在短期引爆了我的产品。人本来就是利己的，但要想明白一件事：别人凭什么帮你？只有你克服人性去做利他的事，最后才能真正利己。道理大家都懂，但做起来真的很难。

## 五、社群未来怎么走？

我们社群已经进入2.0阶段。这段时间我跑了好几个城市做企业家内训，也组织了五场会员线下见面会。

深度链接是社群的生死之战。凡是没线下活动、没实战活动的社群，最后一定死掉。

同时我还在考虑搭建二阶、三阶产品。一个299元的社群，如果没有升阶产品，利润空间非常有限。我设想的产品体系是299元→1999元→9000元。如果299转1999的比例是9%，1999转9000也是9%，那就算前端投放ROI只有1.0，整体ROI也能做到2.0以上。当然，这场仗肯定比第一场难打得多。

以上是我最近的观察和思考，希望对大家有启发。最后我想强调两句关于投放的认知：

**商业只有投放起来，才算真正的商业；商业只有利他，才是持久的商业。**

评论区里也是各种牛人，就不一个个复制了。
