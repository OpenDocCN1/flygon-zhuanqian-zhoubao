# 亚马逊账号安全解读
作者：龙哥

对于做亚马逊的卖家来说，账号安全这件事，看起来基础，却常常决定生死。我做了七年跨境电商，见过太多新手在这上面栽跟头。今天这篇就想把这个话题好好掰开揉碎了聊一聊。

先说几个最常见的账号问题：新品刚上架就被下架；卖得正好的产品突然没了；因为差评太多被系统盯上；还有的就是自己不小心触碰了平台的规则红线。这些问题听上去不大，但处理不好，账号权限说没就没。

再往严重了说，还有一类更深层的账户危机：

- 多个账号被判定关联
- 商标或其他知识产权侵权
- 制假售假被抓
- 产品安全违规
- 操纵评论被坐实
- 不小心上架了平台限制销售的品类

这些问题一旦被系统抓取，账号的销售权限可能会被限制，表现不外乎这几种：收到警告信、产品被迫下架、账号被邮件通知关闭，甚至更有一些情况是毫无预兆地直接封号——你连申诉的机会都得自己去找。

可以把账户安全问题拆成四个维度来理解：产品合规、销售合规、账户信息合规，以及出问题之后的申诉处理。篇幅有限，这一篇先专门讲透“产品合规”这个最关键的板块。

产品合规里，有这么几类风险很高的品类：容易引发过敏的护肤品类、服装类；移动电源或者含电池的产品，易燃易爆风险高；带电的宠物用品；插座这类直接涉及用电安全的产品；还有个人移动设备。

这些品类的共同点是，一旦出问题，买家投诉率极高。而亚马逊又是一个极度偏向买家的平台，所以，如果你的产品属于以上任何一种，最好提前把手头能证明产品安全的资料备齐，别等出事了才四处找：

- 产品的安全认证证书
- 实验室检测报告
- 产品外包装和标签
- 详细的产品说明书
- 工厂的ISO认证文件
- 工厂生产线的实验室介绍文档
- 采购发票
- 品牌授权书

这些材料建议选品阶段就开始准备，而不是上架后再补。

电子产品尤其要注意目标市场所在国家的法规要求。欧洲有自己明确的法规标准，美国那边则要看FCC认证。选品前先搞清楚这些，能绕开很多坑。

而所有品类里，儿童产品可以说是亚马逊上监管最严的类目之一。下面按几个常见细分产品来做具体的风险解析。

**先说儿童服装**

安全风险主要集中在三个方面：第一是化学危害，衣服表面的涂料、配件里可能含铅，而铅会影响儿童神经系统发育；第二是物理性危害，比如小配件脱落导致孩子误吞窒息，或者系带过长勒颈；第三是易燃性危害，特别是儿童睡衣，法规要求必须阻燃或具备自熄功能，适用于9个月到14岁之间的儿童睡衣，必须通过对应的易燃性测试和尺寸规格标准。

对应的参考法规有ASTM F1818等，不是全部，而且经常更新。

**儿童玩具方面**

化学危害是重灾区。欧盟新玩具指令把有害元素限制从8种增加到19种，新增了铝、硼、钴、铜、锰、镍、锡、锶、锌这些。比如铬的限制还细分了三价铬和六价铬；锡除了无机锡，有机锡也有限制。同时，首次明确禁止玩具中使用66种过敏性香味剂，其中有55种完全禁用，11种如果含量超过0.01%必须明确标识。

物理性危害也不容忽视：新指令对3岁以下儿童玩具的小零件要求非常严格，甚至一些需要入嘴的乐器类玩具也禁止有小零件。玩具里如果附带食品，食品和玩具附件必须分开包装；包装本身也不能有小零件风险；与食品紧密连成一体的玩具是明确禁止的。另外，设计要求上还得考虑儿童难以预测的行为，比如三岁以下儿童用的纺织品玩具，洗完之后还必须继续符合安全要求。

警告标识方面，要求更细了：使用者年龄、能力、体重限制，是否需要成人监护，都必须标清楚；并且要标在外包装或其他显眼位置；食物中带玩具的，以及含芳香物质的化妆套装，也都增加了对应的警告要求。

对应的参考法规有欧盟玩具安全指令2009/48/EC、ASTM F963、GB6675等，清单也不止这些。

**婴幼儿提篮和摇篮**

这是一个安全风险点非常细的品类。静态状态下要能支撑住使用者的体重；要防止其他小朋友探头看的时候把摇篮弄翻；睡垫厚度和尺寸有讲究，避免垫子和硬表面之间留出空隙导致窒息；单面高度要防止宝宝摔出来；分段床垫连接处必须平整，避免孩子脸朝下趴下去卡住；摇摆或摇动款的角度要能防止身体被卡；还要有明确的警示标识提醒照顾者注意跌落和窒息风险；另外，易燃性也要达标。

对应的参考法规有ASTM F2194、EN 1466等。

**婴儿学步车**

核心风险有三条：楼梯摔落风险——产品设计必须保证无论朝前、朝后还是侧着，都不会摔下楼梯；防翻转能力——在平面上不能因为孩子往前、往后或者侧倾而翻倒；座位区域的动态和静态负载能力——得扛得住孩子静止和蹦跳时的重量。

对应的参考法规有ASTM F977、EN 1273等。

**儿童三轮车**

这类产品同样受到严格监管，不同市场的法规要求各有差异，选品时务必逐项对照。

**儿童安全座椅**

这个类目更复杂，涉及的设备类型多种多样：约束系统是设计用来承载不超过30公斤儿童的；手持式婴儿提篮带有座椅靠背；增高座椅属于无靠背约束系统的类型；无靠背儿童约束系统包括两部分——一个没法伸展的座椅平台加上一个用来限制儿童身体前倾的软垫结构；安全带固定座椅的作用是把儿童固定在座位上，让汽车安全带更适合孩子使用；前向约束系统让孩子面朝行驶方向；后向约束系统则相反。

对应的法规有FMVSS 213、ECE R44/04或R129等。
