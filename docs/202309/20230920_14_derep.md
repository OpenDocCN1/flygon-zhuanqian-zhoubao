# 别忽视那些抱怨声，它可能正藏着赚钱的门路
作者：龙哥

你有没有发现，生活中最让人头疼的那些吐槽，往往就是生意最好的起点？

前几天刷到一条 B 站视频，让我把一个道理想通了：抱怨的本质，其实是需求没被满足。正因为问题一直卡在那儿，用户才会忍不住发声。比如有的城市夏天暴雨说来就来，一群人被困在地铁站口，嘴里骂着“这雨也太不靠谱了”，而旁边卖伞的人却已经默默开张了。再比如不少高铁站建在荒郊野岭，游客想进市区得折腾半天，抱怨交通太不方便，这时候出租车司机早就守候在出站口了。

这些例子虽小，却直指一个真相：哪里有怨言，哪里就有没被填上的需求；谁能接住这个问题，谁就能赚到这笔钱。

所以做生意，说到底就是做一件事：找到用户的真实痛点，然后给出解决办法。痛点抓得准，赚钱是水到渠成的事。

视频里还有一段让我挺受触动，就是“分工合作赚大钱”。他讲了一家公司如何从最原始的小团队，慢慢长成一套复杂的管理体系，整个过程特别有意思。为什么需要这么多岗位？为什么不同岗位的工资和绩效差这么多？它们组合起来到底在完成什么？

最基础的公司结构，无非三块：业务、推广、支持。业务负责把产品做出来，推广负责把产品卖出去，支持部门则给前两者做后勤保障。随着规模越来越大，除了这三块，还会长出一个新的层级：管理。账目变复杂，于是有了会计和审计；天天要处理各种公关事务、维护形象、强化品牌，于是法务也跟着出现。

作者有句话很有味道：简单的问题需要简单的解法，复杂的问题就得用复杂的解法。公司是这样，人的成长也一样。

更让我有感触的是，他拆解了不同岗位背后的“价值创造公式”。他把岗位大体归为四类：专家、管理、流水线、销售，而这里面最“吃香”的，居然是管理。

流水线最基层，工资按件计算，做得越多拿得越多。原因是这类工作的产出相对固定，多给你加薪并不能带来额外收益，老板自然没有动力多花钱。销售比流水线强一点，但也强得有限。销售的收入基本看个人能力，有人月入十万，有人连续挂零，能力本身就有风险成本。

管理则不同。管理者盯的是项目方向、团队业绩和公司走向，他的价值直接由所辖部门的销售额决定。给管理者加工资，是能带来回报的——他拿得越多，就越有动力把团队带好、把项目做大，因为团队卖得越多，他赚得也越多。所以，提高管理层的回报，其实是笔划算的买卖。

最后作者给出一个公式：劳动赚的钱 = 所处行业 + 具体岗位 + 城市 + 企业 + 投入时间 + 解决问题的能力。说白了，选择比努力更重要。你去一线还是待在三线，你挤进新兴赛道还是守着夕阳行业，你最终能创造的价值天花板，早在选择那一刻就被定下了。再往细看，不同企业、不同岗位、不同年限、不同项目经历，也都直接影响你的收入水平。

我很认同这个判断，但也想在后头补一句：个人努力依旧有用，只是它更像一个放大器——先靠选择确定方向，再靠努力把结果放大。选错了赛道，越用力越可惜；选对了方向，努力才真正值钱。

评论区里有人说：“有需求就会有商机。” 说得很对，抱怨声里，藏着的从来都是机会。
