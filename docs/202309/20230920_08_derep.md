# ('“这么多年，工资涨没涨？有没有在认真工作？', (2, 23))

标题：写给一位“越忙越穷”的朋友：想搞钱，请先避开这7个坑

见信好。

你问我：工作多年，工资没涨，感觉努力白费，最近看直播买东西还被人怼，心里很不是滋味。我懂这种憋屈。今天先不评判那位主播的话，只想和你认真聊聊“努力”和“搞钱”之间，那些常被忽略的门道。

第一个坑，是把“做好下属”当成“能赚到钱”。

从小我们被教“只要学习好，一切都好”，进了社会就变成“只要干得好，自然有钱”。但赚钱是一场多要素协同的游戏，单纯埋头干活，只是其中一块拼图。更麻烦的是，习惯了被安排的人，往往特别在意领导的眼色——领导夸一句就开心，批评一句就失眠，日子久了，就学会了讨好、自我怀疑、不敢质疑权威。如果你把评价权完全交给别人，那你的“考分”就由别人说了算。这样的人，不是不好，而是太容易被拿捏，成了哪里需要就往哪里搬的“砖”。

第二个坑，是信奉“能吃苦就能变富”。

必须承认，吃苦和赚钱没有直接关系。如果你表现出“我能扛”，系统就会源源不断给你分配苦差。但苦本身没有意义，苦过之后能换来什么，才有意义。如果只是用“我已经很努力了”来安慰自己，却从不计算投入产出，也不抬头看看有没有更优路线，那只会掉进“越忙越穷”的循环。

第三个坑，是想赚钱，却没研究怎么“赚”。

很多人谈起兴趣头头是道，但兴趣始终卡死在自嗨阶段。问题不在兴趣，而在商业思维。商业的本质很简单：你帮别人解决了一个问题，别人就愿意为你付费。你的爱好、技能、知识，如果能切中别人的痛点，让人家省心、省力、开心，那你就有了赚钱的入口。还有一点：别只盯着“钱”这个结果，要去琢磨“搞”这个动作。钱不是想来的，是搞来的；没有行动上的钻研，就不会有结果上的丰收。

第四个坑，是不好意思谈钱。

我们这代人受的教育和影视剧，总在暗示“爱钱可耻、有钱即恶”。于是很多人连想改善生活都不敢承认，生怕显得庸俗。但现实是，你越假清高，钱越躲着你；那些敢于开价、敢于争取的人，反倒被社会默默奖赏。你一味谦让省下的钱，最后可能变成老板别墅里的一间茶室。那些宣扬“别谈钱”的声音，也许正是为了让多数人放弃竞争，好让少数人独占好处。

第五个坑，是把自己活成一头拉磨的驴。

真正会搞钱的人，不像苦行僧那样一刻不停，他们更像丛林里的狮子：大部分时间在观察、等待、蓄力，一旦看见猎物，就迅猛扑上，赚个盆满钵满；时机不好，就原地休整，不乱消耗。努力是战略资源，不能到处乱撒。用表面上的勤奋，来掩盖方向上的偷懒，是很多人一直穷的根本原因。你真正需要的，不是更用力，而是想清楚该在哪里用力。

第六个坑，是分不清“表扬”和“认可”。

单位里有一种领导，很会给你精神奖励：夸你聪明、说你潜力大、给你发各种奖状，但一到谈钱，就开始讲格局、讲情怀、讲未来。这种人并没有真正认可你的价值——真正的认可，是愿意为你开价。如果你身边全是只给甜头不给甜钱的人，你要赶紧去找那些愿意用真金白银给你的能力投票的人。

第七个坑，是忘了让所有付出循环起来。

我自己的经历很简单：十年前喜欢写作，就拼命写、刻意练，慢慢写出了名堂；十年后，有人花钱请我分享写作经验。写作这个兴趣，最后长出了影响力、社群和收入。这个链条的关键在于：兴趣到能力，靠努力；能力到变现，靠被需要。当越来越多的人需要你的能力，你不想赚钱都难。

朋友，写到这里，我想说：努力从来不是问题，问题是你为什么努力、为谁努力、努力完之后能剩下什么。别人用你的时候，最盼着你埋头苦干、不问回报、便宜又听话。但你要学会一边低头赶路，一边抬头看方向。

共勉。
