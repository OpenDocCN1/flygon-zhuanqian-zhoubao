# 只靠剪明星带货视频，第一个月进账8万

手上管着37个小杨哥切片号，我来跟大伙说句实在话：直播切片现在还有没有机会？有，而且空间还不小。

你琢磨一下，切片圈公认的天花板三只羊，到现在都还在持续放授权。这本身就说明了一个问题：剪辑手远远没到饱和的程度，市场还在不断要人。更别说嘉之派、童锦程、湖远行、乐嘉、大logo这些达人也一个接一个把授权放了出来，每多一个授权，就意味着多一个上车的入口。

要说哪种玩法最适合刚接触互联网的新手，我第一个想到的就是切片。不用你扛着设备到处拍，也不用你硬着头皮开直播，只要你肯花心思学剪辑，就能把货真价实地卖出去。
