# 黄峥口中的“本分”，其实是一套系统思维
作者：龙哥

很多人提到拼多多的价值观，会直接联想到黄峥常说的那个词：本分。

本分在他眼里，并不是简单的老实做人、踏实干活，而是一种格局更大的系统观。

他的原话核心就在于：本分是在更高维度的系统里，对局部子系统做出必要的让渡和补偿，最终换来的是整个系统收益的最大化。

简单来说，就是用局部的小牺牲，换整体的大回报。

这种补偿的思路，可以说是 OV 系团队的共同印记。最典型的例子就是渠道的价格策略。旺季、淡季的需求波动不同，他们会主动去做调价、补差，让渠道商在不同周期里都能保持体感稳定，而不是让单一环节被波动拖垮。
