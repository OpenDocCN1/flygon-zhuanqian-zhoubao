# 一、淘宝精细化运营到底是什么

## 1.1 概念界定

淘系精细化运营，简单说就是围绕新品和老品做一套更细的选品-拆解-优化-维护闭环，通过更精准的动作把产品稳定性与成交效果做上去。

### 流量结构拆解

目的：搞清楚竞品的自然流量从哪里来，方便我们顺势布局

* 生意参谋-竞争-竞品分析，添加目标竞品，时间取7天，往下找到入店来源，统计主要的进店渠道作为后续推广方向。

![](img/9c386dca472fa234c580c61bd4eede49.png)

![](img/549aeb0746d78479810e72e0ead9da21.png)

### 类目拆解

淘宝的自然搜索推流与类目强相关，类目选错会直接影响流量分配。

* 同样在竞品分析里取7天数据，找到流量最大的关键词。

![](img/3ab2649abdc90267eaf19da8f11c6994.png)

* 复制该关键词，进入生意参谋-市场-市场大盘-搜索分析，时间选7天，查看类目构成，明确关键词的核心承载类目。

![](img/13d6c846b12961945e054c31d7fd5bdc.png)

由此可见，该关键词的核心流量集中在童装/婴儿装/亲子装-内衣套装，上架时就要对准这个类目。有人觉得这一步多余，这里留个小问题：打底裤到底应该放在哪个类目下？

### 主图拆解

数据查询显示同类目平均点击率约为3.5%，因此主图制作和测试标准就应以3.5%作为基准去迭代。

![](img/7ac112104e87bc11aeb743ba057944c6.png)

### 属性拆解与SKU策略

通过竞品SKU组合可以发现，其用一件装压低前端展示价，并把该SKU放到最后不做主推。

通过生意参谋-品类-商品360-销售属性分析，可以看到主销颜色为白、粉、绿、蓝。

我们可以借鉴：设置一个低价钩子SKU，并在主推区置顶主销颜色。
