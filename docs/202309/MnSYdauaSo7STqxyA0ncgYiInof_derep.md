# 学历高≠写作强，这5点才是学会写作的关键
作者：龙哥

总有学员满脸委屈地问我：“我都读到硕士了，写出来的东西怎么还不如你这个本科生改得顺眼？我读的书不比你少吧？”

说实话，这话我听过太多次了，每次听完都想说句实话——哪怕你把图书馆搬回家，也不代表你能写出好东西。

学历高，只能说明你装了一脑子知识，但能不能消化成自己的东西、能不能在需要的时候拎出来用，这是两码事。理性逻辑好，撑不起写作这摊事。

写作不是你学过的知识点一个一个排排坐、直接搬到纸上就完事了。它是思维、逻辑、知识、时间、敏感力，这五样东西搅在一起产生的化学反应。你想单靠其中一样练到极致就下笔如有神？不存在的。它们是环环相扣的齿轮，要一起转，文章才转得起来。

那咱们就逐一来拆拆看。

# 一、思维能力：你要有一双“抓取”的眼睛

先说个扎心的事实：有些人天生就是脑筋转得快，见一叶而知秋，拿到一个线索就能顺着摸出一整个瓜。就像有人天生不易胖，有人天生跑得快，你不服不行。

但好消息是，思维这玩意儿后天也能练。就算你原生配置不高，照样可以通过训练让它转起来。

先弄清楚思维能力是啥。说穿了，就是你看到一件事、一句话、一个情绪之后，能在脑海里炸出多少发散性的延伸。不是“哦知道了”就完了，而是能顺着往深处、往远处多想好几步。

举个例。你看到蝴蝶在飞，脑子里会蹦出些什么？

有人会想起蝴蝶效应——一件小事可能诱发一连串连锁反应；
有人会想到破茧成蝶——熬过蛰伏期的人，终会迎来绽放的一天；
有人会想到绝望——因为在西方，蝴蝶常被视作死亡与灵魂的象征……
同样一只蝶，看你脑子里能飞出多少东西来。

再比如，🛰️出了个“问一问”新功能，你会怎么想？

有人看到的是新风口——赶紧布局视频号、涨粉、带货变现；
有人看到的是引流机会——把精准粉丝导到👸号或🛰️，再做知识付费；
有人想的是发付费文章截图吸引点击，沉淀种子用户；

这些层层叠叠的联想，就是思维能力的体现。

那怎么训练？分两条路走。

**一条路靠外界刺激。** 人是环境的产物。你从小在一个思维封闭的家庭长大，你的认知上限就被框死了，思维也跟着被锁住。想破局？先去泡在好的环境里。

如果经济条件有限，那就选低成本打法。别一上来就砸钱报课——思维底子还没搭好，你连课都听不懂，纯属当炮灰。不如先去图书馆、博物馆、展览厅、辩论现场这些地方待着。多听别人怎么拆解问题、怎么分析现象，借别人的脑子来激活自己的脑子。还有，别窝在家里练，意志力薄弱的人一坐下来就摸手机刷视频打游戏了，半天进入不了状态。

如果你够自律，也可以线上混圈子，去📕、知乎、知识星球找相关的学习社群，跟人互相“卷”，在良性竞争里把动力逼出来。

**另一条路靠内部挣扎。** 环境是外力，但你自己有没有那股“想改变”的劲儿才更关键。

这里有个误区得破一下：很多人以为多读几本书思维能力就上去了，哪那么简单。没有足够的沉淀，你想发散也发散不起来。你连西方蝴蝶的隐喻都没听过，看到蝴蝶只来得及说句“挺好看的”，怎么可能产生素材？

还有一个反向训练法，就是追剧、刷片、看悬疑故事——警匪片、推理剧、反转爽文都行，边看边在心里推演“凶手不可能是他”“那个人肯定有问题”。这些娱乐行为其实都在悄悄训练你的思维运转，让你习惯性地去抓取信息、推断走向。只要记住这种专注投入的感觉，再有意地移植到日常生活中，慢慢你就会发现自己下笔有料了。

还有一条：当你遇到某个具体卡点，没必要花大钱从零开始拜师学艺。找一个有结果的人做两小时付费咨询就够了。你要的是在这个阶段解开眼前的结，然后继续走自己的路——而不是被导师同化成一个模子里刻出来的复读机。

# 二、逻辑性：别当啰里八嗦的“口水怪”

很多人以为写作要写得高深才叫好，其实完全搞反了。

大多数时候，白话文就是最好的表达方式。你不需要像写论文一样堆术语、引文献，你有条有理地把一件事讲清楚，就够了。

比如下面这两种说法：

A：“我今天去买菜呢，你知道遇到什么了吗，那个大妈竟然多收了我5块钱，我就很纳闷，哎她不承认呢，走两步又气不过来，我就跟她吵起来了……”

B：“我今天买菜时，和菜市场的大妈吵起来了，因为她多收了我5块钱还不肯退。”

看出区别了吗？A是口水话，想到哪说到哪，听着累；B是白话文，先甩结果，再补原因，一听就懂。

好多人写文章被人说像流水账，根子就在这。你光顾着自己写得爽，没有条理、没有次序、没有对信息做筛选，写出来的东西当然没人买账。

我给你两个立竿见影的公式。

**第一个公式：以终为始。** 别从开头往结尾推，反过来，先把结果摆上桌，然后倒回去补原因。比如你那篇带娃的吐槽文，你写“今天和他吵了一顿，因为……”，而不是一路从早上几点起床开始絮叨到吵架的那一秒。先让读者知道“吵了”，他们才有兴趣去听“为什么吵”，而不是先被你的流水账劝退。

**第二个公式：整理归类。** 打个比方，你让我帮你带东西，你这么说：“买奶茶顺便买2瓶洗发水、3袋面包、5包纸巾，哦还有浴巾、3包麦片给我妹妹的，别忘了小白菜，啊还有3把刷子……”你说完我基本上已经放弃了。

但你要是这么说：“去超市买日用品：2瓶洗发水、3把刷子、5包纸巾；再买晚餐的小白菜和明天早餐的面包、麦片。”我哪怕不拿笔也记得住大半。

写作也是一样。把同一类的内容归到一起，按区域排序说出来，逻辑自然就通顺了。

比如你抓到一对情侣逛街的素材——奶茶、鲜花、情侣装，归为“热恋期标配”；玩具熊和满脸笑意，归为“刚发生了什么开心事”。这么一归类，你就能顺畅地写出“热恋期的情侣总能让人感受到青春的美好……”这种句子了。

坚持这套方法，一旦形成习惯，你的逻辑性会在短期内脱胎换骨。

# 三、知识：别做会走路的书架子

这一点刚好呼应开头。知识当然跟写作有关，但你要是只会死记硬背、照搬书上的话，知识就是一堆没激活的废料。

一个大学毕业生能把教科书倒背如流，但他写东西永远是照本宣科，没有自己的理解和体温；另一边，一个小学生出生社会，经历了一堆人生的酸甜苦辣，能把个人经验跟书里的典故结合起来，讲出让人点头如捣蒜的话。谁更可能出书？谁更会写作？

多的是人一肚子墨水却憋不出两句像样的话，就是因为他把知识当成了终点，没当起点。知识只有经过你的二次加工，融进你的理解、你的情感、你的经历，才能变成文章。

那已经满腹经纶、却迟迟下不了笔的怎么办？你需要的是把知识变成行动。

这里给你一个实用招数——A4纸学习法。把你想要输出的知识点罗列在纸的左边，分区归类；再在纸的右边，写下你用思维能力延伸出来的相关联想。当你把这些零零散散的“零件”都摊在眼前时，你的大脑会轻松很多，写出来的东西也更流畅，因为你不再需要一边回忆一边组织一边硬憋了。

---

说到底，写作拼的不是谁读的书多，而是谁能把那五个关键技能攒齐了用起来。思维让你有料可写，逻辑让你写得通顺，知识给你素材弹药，再加上时间去打磨，敏感力替你捕捉生活里一闪而过的光。这五样东西，缺一不可。

如果你觉得写作这件事一直卡着不动，别急着怪自己书读得不够。去看看是不是思维没激活、逻辑没理顺、知识没活用。找准那个被你忽略的环节，刻意去练它。

机会，从来都是留给做好了准备的人。

顺手写句实话：写作真没那么玄乎，它就是一个人的思考被认真安放的过程。今天你开始动了，明天那个写得好的人，就是你了。

[PRE*] 如果对你有启发，顺手点个赞和“在看”。我是微微，一个靠写作实现了时间自由的自媒体人，在👸号等你来聊。

你有没有想过，为什么1+2=3？按照最直观的理解，左边一个苹果，右边两个苹果，合到一起自然就是三个。当然，你也可以换个方向摆，左边放两个，右边放一个，依旧得到三。但如果把这道题放到一张A4纸上，事情就变得有趣了——纸的左边写着“1+2=3”，右边可以延伸出无数个“为什么”：皮亚诺公理怎么解释它？哥德巴赫猜想跟它有什么关系？如果有一天，全世界公认的数学规则被推翻，世界会变成什么样？数学又是从哪里起源的？这些延伸出来的问题，才是真正让你把知识刻进脑子的钥匙。

知识这东西，你以为记住了，其实未必。它藏在记忆深处，不写出来你永远不知道自己忘掉了多少。每一次把知识点罗列在纸上，都是一次重新学习和加深印象的过程。在整理的时候，别只做干巴巴的摘抄，试着把相关的信息也融进去，先分段梳理清楚每个区域的内容，再慢慢加入自己的观点和想法。这样写出来的东西，才不会像流水账，初稿就已经有了血肉。

说到这，你可能遇到过一种人：嘴上讲起知识点来头头是道，清晰明了，可一让他动笔写，那些高营养的内容就全不见了。是写作能力不行吗？其实不见得，更可能是“记不住”。学生时代班里总有这样的同学，平时看着普通，一到考试就超常发挥，考完又打回原形。除开作弊的，剩下的人多半是瞬时记忆力强——像游戏里的爆发药水，能在短时间内大量吸收知识，但药效一过，什么都没留下。对这种人来说，什么A4纸学习法、艾宾浩斯记忆曲线，统统没用。就算当时记住了也复习了，知识也只浮在表面，沉不下去。

没有存货，自然写不出东西。而这种人的突破口，不在“写”，在“说”。你有没有发现，跟人争论过的东西，哪怕过了十几天，细节还能记得？因为比起纯文字记忆，大脑对“图像记忆”更敏感。跟人辩论时，那些画面、场景、对方的反应，都会成为记忆锚点。所以，想让自己持续回忆起所学内容，与其用笔抄下来，不如顺着自己擅长的记忆方式去做：找不同的人，反复讲同一个知识点，一直讲到对方听懂为止。如果对方听不懂，你反而有了新收获——你得琢磨怎么调整思路，加点什么内容，才能让更多人明白。这么一来，每讲一次，知识点就嵌进一个不同的场景里，下次只要你回想起和谁聊过天，那篇有逻辑、有思维、有干货的文章雏形就出来了。最快的办法，是试着把一个知识点讲给七八岁的小孩听，孩子都能听懂了，这知识才算真正长在你脑子里，随取随用。

再说说时间。你肯定听过一万小时定律，什么领域的大师，都得靠一万小时练出来。但问题是，读十本书只要一天，读一本难啃的书可能要十天，前者就真的比后者更渊博吗？不一定。没有方法的坚持，就是瞎忙。就像做兼职，没有条件要求，做得再久也成不了专家。时间得花在刀刃上，每一分钟都得有价值。先搞清楚怎么安排时间，你才能专注训练，而不是白白浪费精力。

怎么安排？第一，列出你的时间清单。时间成本是全世界最大的成本。很多人忍受着几十年机械重复的日子，也不肯花一两年投资自己，想想真替他们着急。所以，你得先盘算自己一天有多少可自由支配的时间。比如我的情况是：朝九晚六上班，午休一小时，下班后时间自由，夜里十二点前睡觉。零碎的时间用来干简单的活，比如观察事物练思维、看人物对话练逻辑、刷社群资料学知识。真正的整块时间，刨掉运动、家务和工作，基本就是晚上七点半到十二点。这段时间我会用来读书、做复盘、写笔记、列计划、练写作、改稿子。如果上班有空档，那就见缝插针把写推文这些轻活干了。

第二，做好每周计划。列完时间清单，你就必须做周计划，它能把时间直观地摆在眼前，让你没法忽视。我习惯在周末安排下周的计划，因为周末容易让人松懈，周一又犯假期综合征。所以前期写作，我建议你保持“高度内卷”：不娱乐、不放松、不休息。娱乐是指旅游、打游戏、无效社交；放松是指追剧、闲聊、刷视频；休息是指睡懒觉、发呆。没有基础的时候，就要狠打基础；没有成绩的时候，就要拼命学习。把周末的娱乐换成阅读，放松换成技能练习，休息换成深度思考。你想看起来毫不费力，就得在别人休息时加倍努力。这样做半年，你也能做出成绩，有拿得出手的资源，有底气去连接别人、帮助别人。

第三，别让别人偷走你的时间。犹太人有句话：时间比金钱更宝贵。为什么？因为金钱能存，时间不能；金钱能借，时间不能；你知道自己有多少钱，却不知道还剩多少时间。一个自媒体前辈跟我说过，他一天能赚两千块，相当于每分钟四块钱，被人打扰五分钟，等于被偷了二十块。我的主业工作虽然轻松，但我从不和同事闲聊八卦，多一分钟，我就多写一段练习、多收集一条素材。就算要聊天，我也会找前辈取经，弥补自己的认知不足。

最后，还有一个写作的助推器——敏感力。什么是敏感力？你刷到几篇写家庭琐事的文章，觉得搞笑，点个赞就划走。但如果你有敏感力，你会想：为什么这么多点赞？然后去分析阅读量、互动数据、发文频率、平台推荐，判断这个选题还有没有热度，能不能换个角度写。分析完发现大家确实爱看这种内容，那这个选题就成了你的素材，写作也有了方向。敏感力和思维力不一样。思维力是抓住一件事后往各个方向发散，而敏感力是你能不能第一时间察觉异常，然后再去思考抓捕。它靠的不是逻辑，而是情感反应、共情能力、感知力——说白了，就是感性。

感性能力是天生的，有人泪点低，有人泪点高，没有好坏之分，短时间内也改不了。除非经历巨大变故，否则你不用急着去“获得”它，慢慢养，时间会帮你。训练敏感力倒是轻松很多，就是多用情绪和感知去体验，形成习惯以后，自然会触发连锁反应。比如你看到一个拾荒的老奶奶，心里咯噔一下，想她这么大年纪了怎么还在外面，家人不心疼吗？比如你刷到一个视频，早上才一万赞，晚上快二十万了，你琢磨它是戳中了哪类人的心理；比如你翻到一份老报纸，想起当年它火过，你查了查年份、内容，想着它会不会再火一次；比如你去一家店吃饭，觉得服务差还不好吃，却开了这么多年，思考它靠什么活下来；比如你看到一个小商品几天卖几千个，就去找它的来路、爆火的原因、是不是有促销……这些都是敏感力的练习。

老话说，读万卷书不如行万里路。知识是写作的必备条件，却不是唯一条件。天底下没有哪件事是靠单一技能就能成的，都是主要一项精深，其他多项辅助。

最后，借用海明威那句著名的比喻：任何作品的初稿都是一堆狗粪。成功不过是把简单的事情反复做，也许一年半载看不见变化，但日复一日坚持下来，两年后，惊喜一定会来找你。记住——相信自己，是成功的第一步。
