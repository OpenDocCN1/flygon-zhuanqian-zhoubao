# AI从业者必看—深度合成算法备案及官方模板分享（一）
作者：龙哥

做AI产品的人，如果不了解算法备案，后面可能会走不少弯路。最近灵创AI的创始人墨文分享了他们平台的备案经历，信息量很大，我整理出来给各位同行提个醒。

灵创AI目前已经通过了算法主体的审核，算法备案正在推进中。之所以突然启动这件事，是因为🛰️小程序在类目选择上强制要求涉及AI绘画功能必须提供相关资质。墨文坦言，早知道就提前准备了。

根据多方收集的信息，备案的时间节奏大致如下：

- 主体备案：大约7个工作日审核一次（墨文本人是第6个工作日通过的）
- 算法备案：大约30个工作日一批
- 应用备案：约1到2个月

完整走完整个流程，大概需要3到6个月。如果你正打算做AI相关产品，建议尽早启动，别拖到最后一刻。

不过也不用过度焦虑。墨文透露，🛰️小程序现阶段只要求上传提交审批中的系统截图，也就是能看到主体名称、算法名称那些信息就行。换句话说，只要主体备案过了，小程序审核基本不受影响。

- 关于算法备案的一篇实用指南：https://mp.weixin.qq.com/s/mnkwzOyo3uauPpBskQaK8Q
- 德恒上海分享的互联网信息服务算法备案详解：https://mp.weixin.qq.com/s/K9zsub66pFbhXMMH9bxXIw

再分享两个很关键的提醒：

1. 算法安全责任人需要提交工作证明，如果公司没有工作证，用企业🛰️、钉钉或飞书的认证页面也可以。
2. 算法负责人的手机千万保持畅通，真的非常重要。有人就是因为联系不上被驳回的。万一被拒，也可以主动打电话给备案官方说明情况，这样不用再等下一个7个工作日。

后续墨文还会继续更新备案过程中的新情况和踩坑经验。下面这份是官方提供的公司主体备案和算法备案材料模板，大家提前了解，有备无患。
