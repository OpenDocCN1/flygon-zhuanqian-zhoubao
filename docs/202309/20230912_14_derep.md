# 一百五十万的付费复盘笔记



## 用一百五十万学费走完的付费试炼

作者： 子白

日期：2023-09-07

《花 150 万，成为知识付费体验家》

各位朋友，我是子白。熟人以前多叫我乾哥。后来有人给我起卦，取名子白，说这名字能带旺，我就用了。于是圈内少了一个常被割的乾哥，多了一个喜欢拆解付费逻辑的子白。

龙哥盟、高研社、掘金之路、AI探索家、K大谈AI、参哥抖音课、程前朋友圈、粥佐罗、玩赚新媒、尤校长、炸天帮……市面上以社群、星球、小报童、朋友圈为载体的付费产品，我基本都体验过。我的出手速度之快，以至于 、 、 等几位头部人物都对我印象深刻。下文是我这段时间的消费记录，希望能给正在迷茫的同行一点参考。

一、银行人闯入新媒体的几年

我在国内一家银行做中层主管，骨子里就不安分。五年在岗，五年试错，五年被收割，基本都是主动往坑里跳，打完还帮人点数。今年一月为止，我在各路项目、课程、内推上累计亏损、支出、受骗约一百二十万。钱没有投向正确的人，价值也没兑现。假如这笔资金早交到对的人手里，人生轨迹会完全不同。每次都是满心信任被利用，记性却总不好。

不安的心仍在。二月时GPT突然爆红，我很想上手，却因无法上外网被拒之门外。恰巧在某个🛰️群里被一位老哥拉进一个Mai号群。

为何说是被拉？他告诉我群费八百八，我想都没想就转账了。进群后人就不见了。我问群主是否收费，群主说不要钱。那时我还没意识到圈子本身就是商品，只觉得交税太冤。可钱已出，退群更亏，只能潜水围观。群里整天讨论开号机、日产十万、Token、API，我一个都看不懂，只看懂一句：这活太好赚了。

我忍不住问：“这群到底干嘛的？”
“倒卖MaiGPT账号。”
“卖什么价？”
“九十八到二百九十八，随意定。”
“成本？”
“八毛。”
“我靠？”
“做网的事，别谈成本。”
“带我一个！”

从此我成了群主的下家。他给我账号密码，我收两块钱，教我去各大评论区引流。第一晚就有上百个意向，我不敢定高价，只收九块九。

麻烦来了。买家多是学生，九块九的东西恨不得全寝室共用，每天骚扰不断。受不了后听照群主话，直接抬到九十八一个，滤掉学生群体，来的人基本都是白领，付完款基本不找售后，利润反而更高。

一路加好友、发密、收款。到二月底我净赚八万，群主当月进账一百万。我们根本没真正用过GPT，却照样靠话题赚钱。冷静下来想，这笔收入和能力相关吗？无关，是信息差加上风口。此时我明白，钱不是挣来的，是风送来的。

二、三人组课的翻车现场

从二月开始，GPT相关的课程、星球、社群像雨后蘑菇。好奇心驱使我买了几份，到手才知道多是预售，海报写着早鸟价。即便如此，一张海报就能撬动百万。当时知识星球收入榜，头十里六个都是GPT。

我既震惊又不服。凭什么他们一张图就能变现？我不行？说做就做，拉了两个伙计一起做课。有趣的是我们背景分别是银行、汽车、培训、公务员，全是纯小白，更不懂AI。可我们就是这么叫自己“团伙”。我是出资又出力的人。为找对标，我把市面上所有GPT课程和社群都买了遍。说实话，九成以上是收割，少数做得好，比如刀姐，成了我的主要学习对象。

五天后课程上线，公司注册完毕，小鹅通已上架，海报请 大佬高价制作，就在我盘算五百万怎么分时，现实泼冷水：无人问津。后来才明白，能靠海报赚钱的，大多是已有IP和势能的人。一条朋友圈就能让人排队付款，这是势能变现，跟课程本身关系不大。

三、误打误撞看见新大陆

课卖不动让我加深了对势能的理解，也让我发现很多优秀的收割者都来自同一个地方：龙哥盟。龙哥，轻点。

赶上四月拉新，我直接加入了 战队，转头就给 拉了个新朋友，刘驴大哥别介意，不是没贡献，是靠谱笑得太迷人，天天在朋友圈冲我笑，谁扛得住？

进入赚钱五分钟，我就觉得这里是付费领域的头部。两千块能买到上万人七年沉淀的创业心得，还要什么自行车？

可是越看越焦虑。赚钱里出结果的人太多，千万级的帖子我看了六篇，百万级的看了八十二篇，十几二十万的不计其数。跟他们比，我像个废物，焦虑自然上来。

于是我继续买社群、跟项目、报航海。五月航海我同时上岸四条船，还把本期所有手册啃完。焦虑少了一些，看十遍不如实操一遍，底气足了。但形形色色的社群仍让我控制不住掏钱。

四、方向扭转的那个人

直到认识比高，我多年的韭菜习惯才被终结。

我是在 口听说的芷蓝。那天她在群里说“做社群就抄比高，一定要抄比高”。名字很怪，种子却种下。

两个月后我在某创业号看到比高的一百条经典语录：

1、有人赚确定性的钱，有人赚不确定，有人赚概率，有人懂得提升概率赚钱。比高是赚确定性钱的高手。

2、看十遍不如干一遍，干一遍再跟一群人复盘。年轻人别瞎聊，要做无情的搞钱机器。
认知+执行力+项目=赚钱

📕要做商业闭环，首先是深耕变现。变现两大块，一个是电商，一个是本地生活。我研究下来，📕的商业价值很高，核心在于它承担了消费决策的作用。

我高度认同，就拿着钱去找他。那时我还不知道他是拆PPT项目的鼻祖，也不认识他本人，只是听转述就想买单，说明他的认知和势能足够高，本能让我向高势能靠拢。

经圈友引荐，我加上了比高的助理：
“大佬好，久仰，最高客单多少？”
“现在开门徒，两万八。”
“行，转哪里？”
“转公司，明天比高会电话你。”

两句话成交，这就是势能。

那时我手里的社群已够多，也体会到创业类社群高度同质化，很难说谁更好，只能说创业粉多，蛋糕大，卖铲子的都有位置。我付过太多一万以内的客单，进不了核心圈的对我没意义。两万八远低于心理预期，我以为至少得五万起。

跟了比高几个月，他的超额交付让我很满意，小圈子的强连接让我很暖。比高还点我，说我不拍视频不直播太可惜，逼我天天拍，说我一定能火。他的高研社维护也很细。

曾经沧海难为水。现在我拆过的项目没有一百也有八十，加过的社群快一百个，脖子上像装了钢板，很难再被割。我依然保留付费习惯，但不再是焦虑驱动，也不是被钓鱼，大都是为了交朋友或补票，比如给刀姐。

我走出了付费陷阱，经历可能比大部分圈友丰富。提升认知的途径很多，我选了花钱买教训，性价比最低的那条。到现在累计花了150万，至少130万打水漂喂狗。要是五年前我就加入赚钱，估计早就出结果了，省下的100万给圈友发红包多好！

最后给年轻人的建议：

1、别焦虑，心力很贵，内耗只会更难受。别跟大佬比，赚钱上万人，大佬毕竟少数。

2、项目会过时，经历难复制，但赚钱的逻辑总有相似韵脚，多学大佬思想，提升认知。

3、付费本身没错，付给对的人能加速成长。

4、赚钱是优质的流量池，每位圈友都是筛选过的，有付费习惯和能力的用户，也就是优质的韭菜，无数镰刀对咱们垂涎。

5、哪怕在赚钱内部，有的帖子引流也很明显，可以理解，我发帖也会展示好的一面。比如100个号有10个出圈，就挑收益最高的图，实在不行就P。大家都往大了吹，你谦虚就不对了。

6、话说回来，知识付费算割吗？很主观。你交了钱，他给了东西，只是不是你想要的，算不算被割？付费因人而异，要自己甄别。

7、如果你决定不了要不要付费，问问我。因为你想付的那个人，我大概率已经替你付过了，不然怎么叫知识付费体验家呢？消费过才有评价权，你说对吧～![](img/f5f97fc1084e23e2b6b4c5a8a6afe4b4.png)
