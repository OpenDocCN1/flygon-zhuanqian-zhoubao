# 下一个五年，互联网要批量孵化出一种全新的生存形态
作者：龙哥

有人把它叫做“新个体”。

这批人最典型的模样，是“一 solo 一家公司，同时过着数字游牧的生活”。

说白了，就是把公司压缩成一个人。没有办公室、没有下属，靠一套可复制、可长期跑的线上模型吃饭。地点可以是咖啡馆、海边城市或任何有网的地方，随时切换。

当模式跑通后，收入天花板会非常可观。很大一部分人，单年的营收就能稳定落在几十万到三百万元区间。![](img/211785aaaf8c523470b187e65f2d1afd.png)
