# 一条群消息带我跑通“猫捉老鼠”：📕同城引流完整复盘

各位圈友好，我是龙哥，这几年主要研究📕获客。今天这篇，不聊虚的，把我最近完整跑过的一个项目从头到尾摊开讲。

很多朋友都有类似的苦恼：想在📕做引流，但不知道从哪里下手；想找老师带，学费好几千直接劝退；网上的免费资料，翻来覆去都是过时技巧。如果你也正被这些卡住，那接下来这些内容应该能帮到你。

![](img/ee3a74b2ac3c38588e832f970340273c.png)

我花了三天时间，把初稿从1.8万字删到1万字左右，把所有关于📕玩法的思路、教程、经验都浓缩在这篇里。强烈建议你找个无人打扰的时间，安静地读上30分钟。我会用第一人称，像讲故事一样复盘整个过程。

## 一、项目是怎么被我撞见的

大概两天前，我在一个圈友群里看到一条消息，说📕上这个活动最近特别火，有人已经开始按人头收费，39元一位。我第一反应是：这是什么游戏？热度能维持多久？能赚多少钱？要怎么操作？

![](img/473aab56d886f16b94881ada3a17e38b.png)

我马上打开📕搜了“猫捉老鼠”。这游戏说白了就是成年人开共享位置玩躲猫猫。20个人里面抽5个当猫，其余当老鼠。游戏开始后，老鼠有10分钟找地方藏。10分钟一过，猫就开始抓。规定时间内猫把老鼠全逮到，猫赢；没逮完，老鼠赢。

![](img/65f96681818ead368d764d4aed8ca77e.png)

我归纳了它受欢迎的原因：一是参加门槛低，能跑爱玩就行；二是不限年龄、职业、性别；三是户外运动，能暴汗、减压、减脂；四是费用低，奖励和物料却不少；五是社交属性强，能交朋友，情侣一起去还能增进感情。

![](img/cc11b8dbb57b73728823e8204b0fa29f.png)

搜完我发现，这活动热度确实高，而且像是最近半个月才起来的。直觉告诉我，它还会更火。于是我紧跟着搜了“柳州猫捉老鼠”，想看看本地有没有人做。结果出乎意料：竟然没人做！

![](img/beaa6f397c6e862311265dae1b17294c.png)

我激动地截了图发给圈友。

![](img/07322ddf12c5a51735b44bac30d4a1de.png)

没人做说明有市场需求，却没有供给，这摆明了是蓝海。靠这个短期项目，既能赚点零花钱，又能试试能不能趁着热度快速把账号做起来。如果成功了，还挺有意思。

## 二、起号前，我先做了这些准备

先声明一点：我没有头脑发热直接上手，而是先确认需求。当时一二线城市很多人想报名，但柳州本地没人做，确定是肉多狼少的局面后，我才决定进场。你也可以先看看自己的城市有没有人在做、做得如何。如果觉得自己进去能超越他，再继续往下看。

起号要准备一台手机和一张电话卡，注册一个新号。如果你已有账号但价值不大，可以用同一个手机号注销重注，马上就能用。

注册时有个细节大家容易忽略：千万别连家里或公司的WiFi。因为这类引流号没有100%安全的说法，封号是家常便饭。如果你的号连过某条WiFi，一旦被封，其他连过同一条WiFi的号也会被牵连——莫名其妙被限流、被提示违规、流量突然消失。现在没法解，只能防。所以新号一定别登WiFi。

注册完也别急着改资料，什么都不要动。直接用这个新号去收集素材、制作素材、发笔记。

可能有人会问，素材有什么好收集的？这么说吧，一篇笔记的引流效果，很大程度上取决于素材，尤其首图封面。一张好封面，点击率能提升90%。收集方法很简单：打开📕，搜“猫捉老鼠”。

![](img/a130b21e6a9e9434cbd4d1dd4bab836c.png)

页面出来一大堆。选图标准是什么？我认为只要封面能吸引我，让我看了就想去报名，就值得截图保存。

攒够20张这样的图，再从里面挑一张最想模仿的，进行1:1二次创作。

## 三、实操：从封面到发布

选好图，就开始照着做封面。

![](img/28650f6eb7d6bb28488dff9ab1d94bc7.png)

我的做法是：打开美图秀秀，进美化图片，点右上角制作壁纸，选白色底图，下一步。

![](img/173b06b3560eb830ead7fc1cddb549f0.png)

然后点编辑，把尺寸裁成3:4。为什么要3:4？因为📕图文页是3:4比例，不像抖音9:16。比例不对，整体观感会差，点击率和流量也会受影响。

![](img/acb35909381687826148fa9295d2e8f8.png)

底图做好，再看要模仿的参考图。他的结构是上图卡通、下图实拍。我手上没有实拍图，怎么办？于是又去📕搜“猫捉老鼠”，找类似的图借来用一下，狗头保命。

![](img/e169e69b3103a6cdb2c080a9811e6acd.png)

![](img/f9d263f866a744c0474ed49e293e5fab.png)

找到后，只留下最底下的实拍部分，用手机相册裁掉多余区域。

![](img/dd757e29172fae7dd2a53cd4bf46fe7f.png)

为了让平台不觉得我在搬运，我把图做了镜像翻转。

![](img/90b2d8f4d6acd2fbf49cd0460db103d5.png)

做出来和原图对比，差别很小。这就是模仿式二次创作。好处是起号快——因为别人的封面已经经过市场验证，而📕爆款的底层逻辑就是重复。模仿一个验证过的封面，我的笔记大概率也分得到流量，还能省去绞尽脑汁原创的时间。

封面之后是内页。内页指封面后面的图。找法还是搜“猫捉老鼠”，从前20篇笔记里截取我觉得有吸引力的图。因为这是第一篇笔记，能不能爆我心里没底，主要为了测试需求，所以选得比较随意，只挑了三张。

![](img/b90c25c7127327226ad4da5d556a5e3a.png)

![](img/addefecbd37812c6526883b63087d54d.png)

标题我有套自己的逻辑：从笔记主题里提炼核心关键词，然后套进爆款标题模板。比如“柳州”和“猫捉老鼠”就是核心关键词，我去📕搜“爆款标题”模板，把词填进去就行。

![](img/9114669c78877339e882ff5946309b15.png)

![](img/653831236ff40e83cb2f99cae9e4effd.png)

标题的作用，是让用户搜索某个词时，我的笔记能排得靠前，获得更多曝光。同时配合封面吸引点击，提高浏览量。

正文同样关键。我还是用老套路：搜“猫捉老鼠”，收集20篇左右笔记的正文，复制下来重新整合、修改，就成了我的正文。

![](img/fd3dd5f87c76283607892299502b5841.png)

正文前半段写活动有多火、都是什么人在玩、为什么喜欢，主要为了激发兴趣；后半段写规则、时间、地点、费用、报名方式。前后一铺垫，钩子就埋下来了，一篇吸引人的正文就出来了。

最后是话题。话题的作用是让平台快速识别笔记方向，把它推给曾经浏览过同类内容的人。好处是能锁定精准人群，突破新号冷启动。我当时看到原笔记用的话题比较泛，就在每个话题都加了“柳州”这个关键词。

![](img/57e1ed430077d885b5ed98f0f0874111.png)

![](img/c907b12587c5628e9f8538b721f21fb7.png)

这样做是为了优先吸引同城用户，而不是“猫捉老鼠”这种全国泛流量——那种流量虽然大，但不精准，不是我的客户。别人搜“柳州猫捉老鼠”，我的笔记就容易出现在前排，搜索权重也更高。

发布前，因为新号没有头像和名字，我换成了真人头像和自己的名字，让用户产生一点基本信任。发出去后，浏览量一开始不到100，我还怀疑封面是不是出了问题。过了大概30分钟，评论区陆续出现“怎么玩”“DD”“怎么报名”这类留言。那一刻我很开心，说明柳州同城确实有需求。又过了差不多一个小时，来咨询报名的人越来越多。

![](img/532b23edc4f2221d05df6280de750764.png)

既然有人咨询，我觉得是时候导流了。当时犹豫是先拉🛰️免费建群聊再转化，还是先在📕筛选一轮、能接受收费再加🛰️。我在这上面踩过坑。之前做过免费服务引流，比如免费诊断账号、免费咨询、免费进群、免费领资料，引流效率很高，但转化率极低。一提到收费，对方就举报；发个朋友圈宣传，也被恶意举报到封禁朋友圈。想想就后怕。所以这次我决定：先在📕筛选，等对方确认能接受9.9元报名费，再加🛰️。白嫖党真的伺候不起。

定了思路，我开始引流。我先建了个📕群聊，把群链接放到评论区，引导用户进群，再用小号把人导到🛰️。这方法速度很快，一下子拉了50多人进群。

![](img/be95c260d94a02f99bb2505691425984.png)

但让我没想到的是，群里一有人说要花9.9元加🛰️，大家都不吭声了。好吧，你们都想白嫖，那我不伺候了，直接把群解散。然后我换了第二种方式：私信筛选法。也就是在评论区埋个钩子，让有兴趣的人主动私信我。后续就看这个办法效果怎么样了。

【标题】9.9元“猫捉老鼠”项目，我24小时跑通后又亲手放弃：这3个教训太深刻了

做互联网项目，我始终认为“钩子”是第一步。如果没有个让用户心动的点，人家凭什么主动来找你？为了让他们意识到主动是一件好事，我把压箱底的招都搬了出来。

具体怎么做？我又去搜“猫捉老鼠”这个关键词，蹲在评论区找用户的真实痛点。刷了半天，发现抱怨最集中的就是：活动怎么玩、规则是什么，根本没人讲清楚。好，那我就做一份活动介绍，专门当成鱼饵抛出去，看看有没有人愿意上钩。后来只要有人留言，我就把准备好的文案发过去。![](img/2d839ec6e695cd79788b541126a0cfc2.png)

没想到5分钟不到，真有人上钩了。![](img/efd7c8d05ca467b04ffdcfeb8e0dc12f.png) 私信和评论越来越多，我当时激动得手都在抖。回复都来不及。可越是这种时候越要冷静，深吸一口气，我开始想怎么设计话术，把真正有付费意愿的人筛出来。临时凑了一套不算完美的话术，给大家看个案例。![](img/3d470cc0f7e11e78e1b6eee02cd74b7e.png)

有客户私信问怎么参加时，我没有急着引流到🛰️，而是先在📕私信里做第一道筛选。我一般这么回：“稍等，我发一份活动介绍给你。你先看看合不合适，再决定要不要报名。”介绍里特意把费用标得清清楚楚。如果对方看完能接受，他自然会再找我；如果介意9.9元，我也不多解释。不是我的用户，没必要浪费精力。

这就是价格筛选的妙处：既能让精准客户自己冒出来，又能让同行举报的难度变大。讲到这，我突然想起一个特别有意思的账号，放出来你们看看。![](img/3ed7d15686f45821c0164e9936ac0a1e.png)

给你5秒，如果你遇到这种人，会怎么处理？……时间到。我遇到的是没名字、没头像、没简介、没IP的账号，这种基本就是来捣乱的，搞不好还是同行。千万别掉进他话术里。我的做法是：不理、不拉黑、暂时屏蔽。为啥不拉黑？一旦拉黑可能让对方应激，接下来会招一堆水军号来轰炸你，直到把你号搞封。我以前被搞过，真的很烦。所以干脆让他自言自语去。

我知道他暗地里肯定举报了我，所以我回头检查笔记和评论里有没有违禁词、违规操作。确认安全后，我反手点了举报——谁让他先骂我“傻逼”呢。你们看这张图。![](img/34ad90e576e433240e0e02189aae04c4.png) 我刚举报完，系统就提示我私信话术有点问题。不过没关系，我没说什么过激话，只是温馨提示，不影响笔记曝光。以后遇到这种人，不用理会就行。你笔记有流量了，总有人眼红，心态放平就好。

到这里，距离我发现项目已经过去6个小时。第一位付费客户找到我后，二话不说就直接转了9.9元，干脆得很。聊天记录在下面。![](img/9d1dd39dfc0da8b746c7a752618e86e6.png) 这就是价格筛选带来的爽快。那一刻，流量端和转化端都通了，接下来就看交付端。确认好客户需求，我马上准备采购物料。因为活动介绍里承诺过会提供物料，必须买回来才能办活动。![](img/7b9ef36a3286a3b2892b3f1be582e220.png)

打开拼多多，搜关键词，比价，挑性价比最高的下单。全部买完一算，成本不到100块。每人收9.9元，只要来10个人，采购成本就回来了。当然，这没算人工和其他支出。店铺截图我放在这，供大家参考。![](img/8fd5efae872ad18a38547c4e3ff36964.png)

物料搞定，新问题来了：共享位置用什么软件？我完全没经验，就继续去搜“猫捉老鼠”，发现大家都在用高德地图。我下载试了一遍，难度不大，顺手把流程分享出来。登录高德后点“我的”，在个人主页那向左滑，找到“群聊”功能，点进去同意提示就行。![](img/329275493bcec3ad931e97c367f50329.png) 创建群聊后，系统会自动生成一个群，点右上角“设置”，改好群名。![](img/bbe2b538a67f7f51aef1551264a3d259.png) 再点“+”，把群链接分享给用户，他们就能进来共享位置开玩了。![](img/653a8f53c82c33ce42bba7ee742a8377.png) 是不是很简单？效果图也给你们看看。![](img/be033ea51bac5760f4f69654f985ec49.png)

搞定这些，我把重心放回流量上。人越多，成本越低，利润越高。我又找了一些线下猫鼠游戏的素材，按之前的套路一比一仿了篇新笔记。发出去后，马上有人来咨询，陆陆续续有十几个人付了费。![](img/923f7d9dfe2673d7d0dcb77c14fe89c2.png) 但就在这时候，我意识到交付端的大麻烦：我一个人既要引流、又要转化，还要过几天做线下策划、找场地，根本忙不过来。想到这，热情瞬间降了一半。我赶紧去群里求助，问有没有人愿意合伙。合作方式很简单：我负责引流转转化，对方负责线下交付，利润对半分。![](img/dba05247e1604d13283c8e339b889a11.png)

结果不出所料，没人愿意。他们还提了一个我没想到的冷知识：![](img/bffceaa77898c7850dfef6ee19508673.png)

“万一有人受伤了，你怎么处理？你是组织者，出了事可跑不掉。”

那一瞬间我背后冒冷汗。这件事我真的没想那么细。没人帮忙，一个人又要忙前忙后，还得管安全，太难了。![](img/a42d5cf7fc5d7d750932d099bfd977b9.png) 我一度想放弃，但又不甘心，于是发了段话，继续喊人。![](img/554952a60e62e1c1c8333ee06683bf18.png) 还是幻想有人能拉我一把，把这件事做完，真的不想中途停下来。可大家还是劝我：这种重交付项目，除非有二转、三转的产品来支撑，否则靠9.9元很难赚钱，人还累死。那一刻，我放弃的念头飙升到98%。

没人合作，一个人再强也撑不起这么多事。算了，远不如洒脱一点，握不住的沙就别强留，相信下一项目更合适。

决定放弃后，最棘手的是怎么跟客户解释。已经答应了人家，突然变卦，我自己都觉得很不负责任。没办法，又去群里求助。![](img/b6da5bfc66fde67d0cb29d42a8357d27.png) 大家给我出主意，我临时编了套解释话术，挨个发过去。最后劝退了三十多人。有人骂我，有人理解，还有人帮我出主意。不管怎样，项目被迫终止了。![](img/c1c24f052f50a32e4bcbeecc3fd78510.png)

现在回头总结，从发现项目到劝退客户，刚好24小时。我确实用最短时间跑通了一个小闭环，只是交付端没走完，有点遗憾。但这趟经历给我的启发很深。

第一，获取信息的渠道很重要。项目能被启动，很大程度是因为圈子里有人分享了这个信息，我才能发现需求、快速落地。如果这个信息晚一个月才看到，可能连第一波红利都赶不上。

第二，执行力才能跑通闭环。信息再好，也要落地去试。有想法就要动手做，边做边优化，用最短时间打通引流、转化、交付。跑通0到1后，再想着复制放大到10倍、20倍、50倍。

第三，交付重的项目千万别单干。这种线下活动，先收钱后交付，非常考验后端的组织能力。一两个人根本做不了，需要成熟团队分工：有人采购、有人策划、有人管安全、有人带队。分工越细，客户体验越好。一个人，连细活都做不完。

那这个项目是不是就完全没戏了呢？也不是。如果你有兴趣，可以换个思路：最好拉上两三个伙伴一起干，流量照做、转化照做、活动照办，但你的利润点不在9.9元门票，而在后面的多次高客单转化。

具体怎么做？以我的付费客户为例，喜欢玩这种游戏的，大多是年轻单身群体，目的是认识新朋友。但新鲜感过后，他们很难复购。所以可以在活动时和他们建立基础信任，然后循序渐进：

先建一个相亲交友群，群费99元/年，群里可以自由聊天、约线下聚会。有了信任，这不到100元的入群费大家是能接受的。群人数多了，再办一场线下30人的相亲活动，男生199元，女生99元。还可以做私人定制服务，收费999元，根据客户要求，帮他匹配十个不同对象，双方满意就约见线下。如果有人因为你牵线而订婚，信任度就更高了。这时可以去找同城婚纱店谈合作，推荐客户并拿返点，一般是10%-20%。也就是说一份5000元的婚纱照，你能拿500到1000元介绍费。就说是“同学开的店，来了有特别礼物”，顺理成章。

之后，他们办婚宴前，你又可以在朋友圈推荐合作酒店。提前谈好返点，说是“亲戚家开的，有优惠”，酒店通常会返5%-10%。按5万元一桌婚宴，你能拿2500到5000元。再往后，生孩子需要的月子中心，也能谈10%-20%的分成。月子中心不太好谈，得认识圈子里的人转介绍。如果均价3万元，你就能拿3000到6000元。

你看，同一批人，从9.9元开始，慢慢玩出这么多利润点。前期最难的是信任积累，需要时间，多聊天、多维护。有了信任，关系就超越了买卖，人家才愿意跟你走。毕竟这届年轻人，可没那么容易被收割了。这个饼画得有点大，大家慢慢消化。

虽然我这轮项目算是失败了，但收获的东西并不少。这些复盘和延伸思路，你们可以套进自己的商业模式里，看看有没有参考价值。如果觉得有一点点用，就点个赞吧。我是艾小飞，今天分享到这，谢谢大家。
