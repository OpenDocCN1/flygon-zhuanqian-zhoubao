# 零基础怎么做 Coze 赚钱？我七天收入两千多的实操分享

9 月的航海计划里新加了 workflow 赛道。我最近正好在做一个 Coze 小项目，七天内就拿到了第一笔真金白银。趁活动还没开始，把这段经历整理出来，给想报名又担心自己不会的朋友做个参照。

我的赚钱方法并不复杂：接 Coze 流程定制、代做 Agent、把做好的成品挂出去卖。项目开工到第七天，收入已经跨过 2000 元。

自己跑过一轮之后，我的感受是：这个方向对新手特别友好。所谓新手，其实就是能熟练操作电脑基本功能的人，不需要会写代码，也不用组团队，门槛低到“敢动手就行”。

更细的操作步骤，我整理了一份飞书文档，感兴趣的朋友可以直接翻看。

留言区里也有不少干货。有位朋友推荐了自己的剪映辅助工具，说可以直接拿来用；也有人建议，能交给代码处理的活儿就别丢给模型，模型又贵又容易飘，写代码请 Claude 代劳就行，只要在需求里写清楚输入、输出和运行环境。作者道谢后表示会去试试。还有人在折腾 Coze 和 n8n，欢迎交流；想拿完整文档，加鱼丸🛰️，把原帖截图加一段简短个人简介发过去就行。
