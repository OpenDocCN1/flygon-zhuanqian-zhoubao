# 100w到手后，最触动我的不是那串数字，而是一位听障朋友的留言

三个月前，我把用一年零四个月赚到人生第一个100万的完整经历写了出来，那些踩过的坑、摔过的跤、摸索出来的路子，全都摊开来讲了。本来没指望能有多少回应，没想到收获了一大波圈友的认可，还有人专门顺着文章加了我的微信。

这些新朋友来自各种人群：有还没走出校门的大学生，有手捧“铁饭碗”的体制内上班族，有围着锅台和孩子转的全职妈妈，有背着30万外债的创业者，也有一些就是单纯想认识我这个人。最让我心头一颤的是一位“听障人士”——他尽管听不见任何声音，却靠文字把我写的每一个字都认认真真看完了。那一刻我突然明白：每个人都扛着属于自己的重量，有人为身份发愁，有人被金钱压得喘不过气，有人纯粹被命运按在地上摩擦。

这段时间，大家问得最多的问题总是那几样：

- 究竟该不该裸辞去创业？
- 哪里才能找到真正赚钱又靠谱的项目？
- 日子看不到光的时候，拿什么撑下去？
- 怎么才能找到自己身上隐藏的优势？

这些问题我反反复复想了很久，今天决定统一给出一份回答。整篇回答大概有1.2万字，我放在飞书文档里了，想看的直接点这个链接：https://fi8jncah4ds.feishu.cn/docx/O5iudHe9RoLMQmxXSElcNmyTnLd

有位圈友在评论区说了一句话特别扎心：人缺的从来不是努力，而是路径感。没想到连龙哥都看到了，还发了公众号表示认同。我写这一万两千字，不一定能让你马上拿到结果，但希望在你扛着重担往前走的时候，能帮你照亮一小段路。
