# ('(精华帖)(117 赞)小白在小红书虚拟赛道从 0-1 至变现 6 位数的复盘', (2, 41))

还记得去年十二月就该发出这篇复盘，结果一拖就是大半年——因为忙着做实验、赶毕业论文，硬生生把它搁置到了现在。我是星荧，也是六月小红书虚拟电商航海的教练之一。

去年十月那会儿，我的日常几乎被两件事填满：一边在实验室和自习室之间来回跑，一边把所有碎片时间都投进了小红书的虚拟赛道。选品、拆解爆款、做图发文、引流成交，节奏拉满，连刷生财精华帖的时间都挤不出来，感觉自己快要和圈子脱节了。

说起来，我和生财的缘分始于一张票。研一还没正式入学时，郭耀天大佬赠了我一张门票，没想到成了撬动我人生轨迹的一个支点。如今硕士顺利毕业，我也终于可以把这份迟到的答卷补上——想聊聊自己如何在虚拟赛道做到20万变现，如果能给同样在这条路上摸索的圈友一点启发，那就值了。
