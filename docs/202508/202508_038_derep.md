## (55 赞)别再手搓 n8n 工作流了！一个 MCP 插件，让 AI 从零到部署全包

作者： 陈序员大康

日期：2025-08-21

最近在啃 n8n 的时候，我突然注意到一个点：n8n 里所有的工作流配置，本质上都是 JSON。那这就很香了，意味着它和 AI 是天生一对。只要把节点能力、数据流转规则喂给模型，完全可以让它直接生成可用的工作流代码。

问题在于，n8n 节点多达数百个，一个个去扒文档整理，成本太高。

就在我还在琢磨这个思路时，发现已经有人抢先把这条路跑通了。

## 这个方案叫 n8n-mcp

简单说，就是把 n8n 的官方使用文档，配合 500 多个节点的详细参数，全部封装成了一套 MCP 工具库，并且做了规则适配。

有了它之后，工作流的整个生命周期就被 AI 接管了：

接到需求后，AI 会先调用工具查阅文档和节点用法，再按代码的方式写出工作流的 JSON，最后直接通过 n8n API 把流程推送上线。整个过程你完全不用碰鼠标，甚至不用打开 n8n 后台。

说白了，就是把“搭流程”这件事，从手工操作变成了提需求。
