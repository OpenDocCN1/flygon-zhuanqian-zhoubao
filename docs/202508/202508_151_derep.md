# 【龙哥问答】1 篇

**龙哥问答精选：一个值得反复琢磨的思维片段**

今天整理资料时，翻到一篇来自龙哥的问答内容，感触很深，忍不住想拿出来和大家聊聊。

不知道你有没有过这样的时刻——明明看了很多方法论、收藏了不少干货，但真到自己做事时，总觉得缺了点什么？可能你缺的不是信息，而是对某个问题的视角转换。

龙哥在这次的回答里，其实分享了一个比较底层的思考方式。他没有直接告诉你要做什么、怎么做，而是把问题拆开，从更本质的层面去重新看待它。这种思路，我觉得比单纯给个步骤清单要有价值得多。

特别是在当下这个信息过载的环境里，真正稀缺的不是答案，而是提出好问题的能力，以及看待问题的角度。龙哥的这种问答式内容，恰恰是在帮我们训练这种能力。


有些内容，看一遍有一遍的收获。这篇问答，值得你花几分钟静下心来读一读。
