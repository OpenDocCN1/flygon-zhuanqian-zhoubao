# B站好物带货实操：新人半月破万，我是怎么做到的

大家好，我是星空海绵，目前刚加入赚钱。还没正式成为正式成员的时候，试用期的第三天就刷到了B站好物的这个项目，感觉跟我非常契合。巧的是我之前在B站就经营过一个账号，粉丝有一千多，基础条件算是具备了，于是我就直接上手研究。


# 一、从哪里下手

先放一张我自己B站好物后台的成交截图：

![](img/713d1c873e5c9c02d45d9444a75c13b2.png)

起步阶段，我也翻看了赚钱里不少前辈的经验贴，但我更想自己去验证一下。于是我去找了月销售额过百万的头部UP主，看他们到底在干什么：

![](img/22b45fa6008d35fbede56172b33ceb97.png)

榜单上的账号基本都是模式跑通的。我没有去追高粉大号，而是专门找了那种粉丝不高但成交很高的账号来研究，整理出了一批对标对象。

![](img/db2dcc7b55bb934fb8c1031d038b246b.png)

研究下来发现，这些账号的核心打法高度一致：每天更新数码类的特价好物，单条视频时长大多在30秒到1分半左右。制作门槛也很低，就是几张商品图+固定话术生成，照着做就行，我也是直接模仿着上手。


# 二、怎么选品

我总结他们的成交逻辑很简单：带的都是当下真·低价。后来我就锁定了几个能稳定拿到低价的来源：

* 好价值得买的电脑数码榜单
* 慢慢买的手机榜单数据
* 京东、淘宝的国补专场商品

每天的货源就从这几类地方挑。也可以直接看对标UP最近在推什么，跟他们推一样的，因为很多人用的数据源都差不多。

我的选品原则就两条：从上述榜单里挑，或者直接跟对标账号选同款。

# 四、发布流程

视频、封面、标题都齐了就去投稿。投稿时记得勾选商业推广-视频带货，并把刚才加进选品车的商品关联上。这样只要有人通过你的链接下单成交，就能拿到佣金。

![](img/1a9a97751ae8a966a68e4ee70e9876a0.png)

# 五、目前的难点

现在最大的困扰是订单被取消。最近成交看起来不少，但取消率偏高。我B站小店显示售出30多单，实际只确认了8单，其他都是下单后被取消。B站目前是把取消的也算进售出里。我还在排查原因，后续会继续测，搞清楚了再更新。


# 六、我的小结

B站好物带货是真的能赚钱。想要量，就得靠产量：这种视频做起来快，适合做矩阵，多账号同时跑。坚持更新一段时间，效果会慢慢出来。实在跑不动还可以转评测方向。总的来说，这个项目变现能力是确定的，想赚更多，就得多花点心思去优化和放大。
