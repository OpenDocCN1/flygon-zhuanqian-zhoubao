# 别再纠结选路了，先把手里的事干起来
作者：龙哥

最近收到一个私信，问得非常典型：

我现在在做 YouTube Shorts，同时又特别迷中医养生。刷到很多中医养生的博主，分享日常的运动、饮食、小习惯，最后顺带卖养生产品。自己也挺想走这条路，但担心现在卷成这样还能不能做起来？如果做了，是不是得先拍视频、带货，再慢慢自学中医、考证？

他还说自己手上已经有 YouTube 的项目了，一直在犹豫要不要all in中医这条线。想让我帮他分析一下，中医养生带货和做 YouTube 视频，哪个前景更好、竞争更激烈，该选哪个。

说实话，这类问题我听过太多了。

我的看法很简单：想做就做，你这年纪试错成本真的不高。犹豫来犹豫去，才是最浪费时间的事。

别老是追求一个百分之百确定的答案。中医养生也好，YouTube 短视频也好，在我看来都值得先试试水。就算一年下来没赚到钱，你也攒了经验、涨了能力，这笔账怎么算都不亏。

你说你特别喜欢中医，那更没理由不去做。喜欢的事，本身就是一种加成。就算变现慢一点、起步比别人晚一点，也值得。兴趣会让你更扛得住前期没反馈的日子。

至于竞争？每个赛道都卷。卷不卷不是你该先考虑的问题。市场再拥挤，也足够容纳一个目标明确、想靠这个每个月多赚几万块的人。真正把人挤走的，不是竞争对手多，而是你自己还没开始就先退缩了。

所以，先别把路想得那么远。选一个你更想聊、更愿意持续输出的方向，开始做内容、开始积累。做着做着，你会知道自己适不适合、能不能玩得转。实在不行，回来再做 YouTube 也来得及。

少一点瞻前顾后，多一点动手试错。先干了，再聊前景。
