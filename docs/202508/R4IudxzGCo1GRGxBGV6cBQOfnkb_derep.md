# 三、从零搭建攻略

整体采集逻辑是：

1、复制目标链接后触发快捷指令，指令会把链接及相关标注信息通过扣子 API 推送给工作流。
2、工作流抓取网页主干信息，结合 AI 大模型完成视频文案提取、内容总结等处理，并按飞书多维表格 API 格式推送数据。
AI 大模型调用成本较高，后续我找到了性价比更高的替代方案，完美解决支出问题。
3、飞书多维表格自动新增记录，快捷指令返回结果并一键跳转到飞书 APP 的对应表格。
