# 每个动作都在做实验，带着10倍心智去找那个能爆发的假设



日期：2025-08-11

我们做的每一件事，本质上都是在做一轮假设检验。始终保持10倍增长的野心，不断去捕捉可能带来10倍跃迁的推测与假设。工作的全部意义，就是去证实它或推翻它。证实了是突破，证伪了也是突破。最危险的状态，是脑子里没有假设，手里只有忙碌。

工作三年以上的朋友，应该把这套思维内化成工作标准。

当某个假设被验证通了，立刻把跑通的路径沉淀下来。能做成自动化产品就产品化，能做成标准流程就SOP化，然后交给基础执行同事去稳定运转和持续迭代。自己则腾出精力，去验证下一个可能带来10倍增长的假设。
