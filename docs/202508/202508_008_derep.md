# 别只想着怎么卖，先想办法让路人“刹车”

线下生意归根到底不是一门说服的学问，而是一门让人在门口停留的学问。

上周六早上陪母亲在医院输液，我出来买早饭，顺便观察了两家客流很猛的店铺。它们并没有什么惊天动地的促销，唯一共通的细节是：门口能坐下来。

第一家在护国寺附近的点心铺，自己把橱窗改造成了一排可以歇脚的公共座位。那一带游客密集，走累了的人本能地需要一个落脚点。坐下来喝口水、歇会儿腿，顺手买一块点心就是顺理成章的事。

第二家是西什库大街十字路口的紫光园外带店，对面就是北大第一医院，人来人往。它的座位严格说来是公共设施，店家算是巧妙利用了这份“便宜”。不过即便没有座位加持，紫光园的奶皮子酸奶早已成为近几年北京游客带回家的标配之一，名气本身就是一种让人放慢脚步的理由。

让顾客慢下来，才有成交的可能。几年前我们调研满满元气枣糕时就发现，最赚钱的那家店在合生汇，门外正好放着一匹木马。小朋友经过忍不住要上去玩一圈，等着的父母自然有时间看一眼货架，买上一盒尝鲜。

从那以后我们给不少做家庭客群的客户提过建议：在门口统一放个木马或摇摇车。孩子被吸引聚集，父母也就留了下来。

放慢脚步的手段其实很多，市面上常见的做法无非是喊麦、门迎、现场歌舞、发气球、玩偶巡游、小型表演……本质都一样：用一个明确的视觉或听觉锚点，打断路人的行走惯性。

门店的价值不在于你多会讲，而是路人愿不愿意在你面前多站三十秒。花点心思设计一个“让人愿意停留的理由”，交易往往会自己发生。
