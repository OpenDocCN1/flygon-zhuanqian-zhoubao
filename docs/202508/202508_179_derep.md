# B 站好物悬赏，我用半个月从零做到 GMV 破万的实操复盘

大家好，我是龙哥。七月份才刚加入赚钱，入圈前试用期的三天里，正好撞见了 B 站好物悬赏这个超级项目，当时就觉得和我很搭。之前我在 B 站就运营过账号，粉丝有一千多，基础条件在那，我就直接上手去啃这个赛道。

研究摸索了大概半个月，GMV 已经上万了。虽然到手佣金目前只有六十多块，但足以证明这件事是真的能跑通、能变现。等把里面的卡点再打磨清楚，我认为靠它回本赚钱的门票钱是完全可期的。

下面是我整理的一份完整实操笔记，涵盖选品思路、视频怎么拍、怎么上传投放等具体细节，希望能给正在观望的你一点参考。

也特意感谢赚钱的超级项目、提供线索的家蒙老师，还有在圈里分享经验的各位朋友。

**互动精华：**

**问：数码 3C 类的佣金普遍只有 0.6%-1% 左右，是不是行业就这么低？有没有更高佣的路子？这类硬广视频播放量能上千吗，会影响成交吗？**

答：手机电脑这类品类佣金确实偏低，正常在 1% 左右，低的甚至到 0.1%。但单价高，一单两三千起步，算下来一笔订单也能有二三十块。想找高佣可以去 B 站的选品库筛选，也可以在京粉 App 里找定向高佣产品。

播放量方面，这类内容基本都在几百播放，很少能破千，和头部对标号也差不多。它的逻辑不是靠播放爆，而是强调“现在最划算，晚了就没了”的紧迫感，所以转化率反而稳定。当然取消率也高，提升转化是我现在在重点优化的方向。

**问：看到有些 UP 主发 0.01% 这种极低佣金的产品，是不是另有高佣渠道？羊毛群发的链接能算佣金吗？**

答：一种可能是和商家有私下合作。另一种是利用京东京粉这类工具做转链，转链后的链接发到群里，只要用户通过你的链接成交，佣金依然能算到你头上。

**问：刚达 1000 粉开通权限，怎么找不到带货榜单？**

答：手机端进入创作中心-悬赏带货，往下拉就能看到百万 UP 榜。电脑端在创作中心-悬赏带货的右侧也有榜单入口。
