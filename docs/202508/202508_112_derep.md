# (307 赞)龙哥公开写👸号的原则
作者：龙哥

昨天刷到一则很有启发的分享，来自龙哥，说的是他给自己定下的一套👸号写作规矩。看完挺有感触，很多点看起来简单，却是对“表达”这件事的一种松绑和回归。

龙哥公开的这套原则，核心思路就是：把写作彻底还原成一种日常动作，而不是一个需要精心筹备的“大工程”。

我梳理了一下他给自己立的规矩，大概有这么几条：

1. **只用手机写，不做复杂排版**，怎么简单怎么来；
2. **时间严格限制**，能15分钟搞定最好，但硬上限是半小时；
3. **每篇内容只聚焦一个话题**；
4. **字数要克制**，尽量别超过1000字；
5. **不追热点、不研究标题**，重点是把自己想说的讲清楚，彻底以自我表达为中心；
6. **放弃配图和封面**，顶多用工具自带的AI生成一张，不再花心思做视觉包装；
7. **一旦动笔，就算写出来的是“垃圾”，也要硬着头皮发出去**，把完整度放在质量焦虑之前；
8. **发完就“断联”**——马上转身去做别的事，不回头重读，不反复刷新看数据波动；
9. **留言全部自动公开**，不做筛选和干预；
10. **不去评判自己写得怎么样**，好与不好都不做自我评价；
11. **把👸号当朋友圈来发**，尽可能每天都更新一篇。

在评论区里，他和读者也有几句挺真诚的对话。有人问内容上是否还会坚持某个垂直领域，他的回答是：大的话题还是会围绕“赚钱机会”这个核心，但他已经不怎么在意流量了。保持更新的真正目的，是为了保住自己身上那种持续表达的状态。这个说法真的还挺戳人的。

想想我们平时写点东西为什么那么容易拖延或者半途而废？多半是因为把“写出来”看成了“写得好”，于是无形中抬高了门槛。龙哥这套方法的巧妙之处在于——它把所有跟“创作质量”相关的干扰项全砍掉了，留下来的只有一个纯粹的动作：想写，就去写。

就像他在其他场合反复提到的一个观点：表达本身就是一种练习，而练习的意义在于保持手感，不在于每次都能打出什么满分作品。

真的想坚持输出的人，不妨试试把标准降得低一点——先保证“有发”的频率，再去谈“发得好”的质量。
