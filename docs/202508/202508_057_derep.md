# 网络喷子那么多，真正的高手都在“冷处理”——聊聊如何和负面评价共处

前几天看到个挺有意思的事儿：一个技术圈的大号写了一篇文章，内容本身其实算中立，但评论区简直是“灾难现场”，一边倒的骂声。文中的主人公小排，估计看到那些留言也免不了心里堵得慌。其实让人不舒服的倒不是具体某句骂得有多狠，而是那种“我明明是一片好心，你们怎么解读成如此不堪”的无力感，人家压根不在一个频道上，想辩驳都无从下手。

其实不光是小排，像龙哥自己，从做龙哥盟的第一天起，就被各种声音包围。他分享了网上一些关于他和赚钱的评论，我看了下，用词那是相当“精彩”——什么“割小白韭菜”、“传销组织”、“精致的骗局”、“精心包装的大佬”、“自导自演的流量生意”……诸如此类，简直能出一本“网络骂战语录汇编”。而这只是海量负面评价里的一小撮。

那面对这些铺天盖地的攻击，该怎么办？龙哥结合自己的经历，给了几个挺实在的思路：

**1. 认清世界的“折叠”属性。**  
很多事没有绝对的对错，每个人都在说自己以为的“真相”。你以为的“真相”和别人眼里的“真相”，可能差了不止一个次元。他们未必是存心跟你作对，只是在反映他们认知里的“切面”而已。既然是真相的一部分，你有必要跟“部分真相”置气吗？

**2. 从攻击里“挖宝”。**  
如果负面评价也是世界的一部分，那就别白挨骂。把这些评论当成一面对着另一个方向的镜子，看看自己创业、做IP的过程中，有没有被忽略的盲区，有没有别人看得到、自己没注意到的角度。做产品、做IP、做社群，本质上都是在跟一群人达成共识，而在“达成共识”这件事上，永远有提升空间。

**3. 绝大多数时候，只需“看见”，无需“动心”。**  
对那些风马牛不相及的噪音，看一眼，知道有这回事儿，然后该干嘛干嘛。别让它们带偏你的节奏。如果你的目标足够清晰，那些不相关的评论就不值得你产生任何“后续动作”。就像小排后来退出了榜单纷争，专心打磨产品——把杂音关在门外，才是对自己最大的保护。

**4. 千万别跟“不讲理的人”讲道理。**  
如果发现对话的对象压根没有逻辑可言，最聪明的做法就是立刻闭嘴。跟胡搅蛮缠的人争论，你注定是输家，因为人家比的是嗓门和数量，而不是道理和论据。他们人多势众，很容易就把你拖入一场毫无意义的口水战。

**5. 主动隔离负能量场。**  
如果一个👸号的评论区常年乌烟瘴气，赶紧取关——这通常说明博主对此是默许甚至纵容的。如果一个社群充满了对他人的指指点点，那就折叠或退群——说明群主的格局有待提升。要主动选择跟那些乐观、积极、彼此鼓励的人待在一起，让环境滋养你，而不是消耗你。

**6. 永远别忘了，开心最重要。**  
如果实在被气得不行，憋出内伤了，那也别管什么形象和商业逻辑了，该怼就怼，该骂就骂。自己的感受永远排在商业价值前面。如果赚钱要建立在不断委屈自己的基础上，那这钱不赚也罢。
