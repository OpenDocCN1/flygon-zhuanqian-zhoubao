# 创建扣子工作流

先说明，这个流程想解决什么？

把原本的：

*   看到目标视频 -
*   复制链接 -
*   打开小程序 -
*   粘贴链接 -
*   等待识别 -
*   复制文案 -
*   打开网页 -
*   打开飞书 -
*   新建文档 -
*   粘贴内容

十步操作，压缩成一步：

看到视频直接转发给飞书机器人。

这就是工作流的核心价值：

用五分钟搭建，换来之后每次三十秒的效率。

工具选用「扣子空间」，官网可直达，免费注册。

![](img/d1583263183a8a72c2813703f094bce5.png)

## 开始搭建

先看下要搭建的整体形态：

![](img/69a9a934050d33caab721ee49a119128.png)

整体可简化为四块：

1.  起始与结束，系统自带
1.  视频文案提取，需配置接口
1.  大模型，用于规范文案格式
1.  飞书云文档，实现自动写入

中间的「current_day」日期模块是我额外加的，可省略。

具体做法：

*   点「添加节点」进入插件市场
*   检索“视频文案提取”和“飞书云文档”
*   依次添加并连线

## 参数配置

先确认全流程的进出关系：

*   上一节点的输出 = 下一节点的输入
*   下一节点的输入也可引用更前的节点输出

起始节点保持默认。

### 配置视频文案提取节点

【视频文案提取节点】：提取视频文字并输出

![](img/8758e4db064bc304ca9a62fc7bef51a7.png)

需填两个输入：

*   ali_bailian_api_key
*   douyin_url

含义直观：

ali_bailian_api_key 为阿里百炼的 API 密钥，去阿里百炼平台免费注册登录即可。

![](img/eef1ec00ef55528d2426474f5700f785.png)

有百万 Token 免费额度，具体申请方式篇幅受限，可用元宝、豆包、千问、秘塔搜索。

![](img/e33c2eb808c23fbff82be74d19bfe6d7.png)

第二个参数 douyin_url，

不用每次手动填链接，点输入框右侧⚙️，选择起始节点的 input 即可。

![](img/edad9a6102ef5b0b730a61e8139c2a97.png)

### 配置文案整理大模型节点

【大模型节点】：优化提取后的文字

需 1 个输入 + 系统提示词

输入选「视频链接转文本」节点的输出 text。

![](img/db07d4805734d73fb2cf75df7217f6a3.png)

系统提示词按需求填写。比如：

![](img/2628a6af56ba5076eab0954397a1e841.png)

别看我写得专业，其实一句话就够：

“帮我整理文案。”

点右上角的神奇小按钮，系统会自动优化：

![](img/f5ee09e9c3a1fe9afb06069a3e76d6a7.png)

也可以先给指令再点一键优化。

若运行后文案未写入飞书，在大模型的【用户提示词】里补充一句：

```
{{input}}
```

即可解决。如图：

![](img/de48494d814db9e96a360977d2374398.png)

### 配置飞书写入节点

【飞书节点】：把整理好的文案写进飞书文档

共需三个参数：

*   content*
*   document_id*
*   position

带 * 为必填。

content* 填大模型节点的输出：

![](img/178e8d7f3ff6a182c2d83c6fe85d0a57.png)

document_id* 填目标飞书文档的 ID，建议新建空白文档，将链接粘贴进去即可。

![](img/845b14662dc2d24c6f1841c565219ac4.png)

![](img/7cd4b3d123f372dbf0af07186d0dde7e.png)

### 配置结束节点

结束节点不关键，只要流程能跑通即可。

我们真正想要的结果在「写入飞书文档」节点已完成。

若想在结束节点看到原文，选视频转文本的 text；

![](img/a664cd4cafad1821b8afbd0785971787.png)

想看整理后，选大模型的 output；

想看是否写入成功，选写入节点的 msg；

![](img/35a65b116a4b3ead139bf8f82192dd17.png)

### 测试运行

全部设置完点「试运行」。

第一次基本都会报错，或未报错但内容未写入，这都很正常。

![](img/0b41235e87bb0c48f85d9ae12f7691b1.png)

我的测试显示运行成功，但：

"output": "document_id invalid, document_id is not alpha"

文档地址无效，不是 alpha 格式。修正即可。

打开一看，原来示范时填了汉字：

![](img/4c8f60bd22ba8f982d99eb9f79a1bac5.png)

解决问题的过程即是成长。我改了数次才通。

改好后，看到飞书文档里自动出现了输入链接的文案内容时，

![](img/423bd462b0436fd87d1f3ef8bcfa0846.png)

那种成就感很足。

# 逻辑比工具更重要

首个工作流跑通后，你就理解了 AI 自动化的核心：

从起点到终点，由不同功能节点串联组合。

掌握这点，再复杂的流程也不怕。

别嫌它简陋，我后来的「Claude 文案导入飞书自动写入👸号」流程，就是从这四节点演化来的，目前部分自动化：

![](img/fefc7e4eff6ec3f32491112d746f928d.png)

最近几天，它已帮我自动写入二十多篇文章，其中一篇 1w+，收入接近百元。

![](img/172ff7ebed21cdb73316a56ea0e1cac1.png)

现在还非全自动，Claude 生成后需我手动导入飞书，全自动方案仍在研究。

无论多复杂，本质就是：多加几个节点，多连几条线。

## 将工作流接入智能体

跑通后点右上角发布，即可配置到智能体，以后直接发链接给智能体处理：

![](img/812c603b8b17a9ec7aab188df39a3f92.png)

创建智能体与创建工作流类似，在配置工作流里点 + 号，把刚才的工作流添加进去。

![](img/92be3bb27a3c2c8d652530e3e8d46e92.png)

智能体的提示词也是一句话，让 AI 自动优化即可。

## 发布到飞书

最后还能把智能体接入飞书：

![](img/56647e30dc132723c243c10c886fa172.png)

在飞书添加对应机器人，直接把视频链接转发过去，文案就自动落到文档里了。

![](img/a90637660ef4a49b3e113b888fceeb52.png)

我的长期观点：

工具本身不重要，关键在怎么用。

*   再强，用不好就是累赘；
*   再普通，用对了就是利器。

所以不必焦虑，目前 AI 仍是工具。

能用就用，不能用就放。

行动建议：

1.  先从今天这个简单流程起步
1.  熟悉逻辑后再尝试更复杂自动化
1.  工具会过时，思维不会

先试试，搭建好后看到好文案，发个链接就搞定。

再考虑更高阶玩法，比如：自动抓取网页内容，整理改写，配图发👸号？

我是思蒙，口号：小白也能懂，让 AI 落地。

看到这里，相信你已有动手勇气，那就：
