# 别再把运气全算在努力账上

很多人沉迷于一种“只要够努力就能赢”的叙事，这套逻辑听起来励志，实则很残酷。它把出生、时机、人脉、资源这些带不走也带不去的先天牌面，全都抹掉了。

当成功被简化成纯粹的个人德行时，赢家很容易把好运当成自己的勋章，开始自负甚至看不起别人；而没赢的人，则只能把差距归咎于自己不够拼，陷入无尽的内耗和自责。

真相是，世界从不是一张白纸。运气和结构性的优势，始终在场，且不可复制。

这并不是否定奋斗的价值，而是让奋斗更清醒。承认运气的作用，不是躺平的借口，而是更聪明的起点：既保持行动的自律和积累，也不盲目硬刚命运，而是学会观察风口、选择赛道、在合适的时间把筹码押出去。

认清运气的分量，才能既不骄傲，也不自毁。奋斗的意义，从来不是战胜运气，而是和运气好好合作。
