# 虚拟资料 4.0 版本复盘：从卖资料包到卖人设，我的一家店做到了月入 20 万+

作者：申铭呀

大家好，我是龙哥，在娱乐行业打磨了七年半。距离上一次做虚拟资料项目的复盘已经过去快四个月了，当时我以为那篇就是终章了，毕竟这只是我的副业，主业这边也一直在推进。没想到在做了系统性的升级后，项目又迎来了一波新的爆发，这次我决定把这段时间的调整和成果做一次完整的版本梳理。

这次的迭代我们从 3 月底就开始着手。小团队内部花了将近一周时间反复打磨方案，确定方向后才投入执行。过程并不顺畅，踩了不少坑，但最后的数据着实超出了预期。尤其是临近暑假的节点，我们用新打法做的账号表现非常亮眼，现在单店单月的稳定营收已经到了 20 万+ 的水平。

这篇内容是我之前三篇同系列帖子的延续。如果你还没看过前面的复盘，建议先补一下再来看这篇，会更连贯。
