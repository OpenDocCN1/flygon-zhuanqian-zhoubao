过去需要一张张制作的图片，现在只要整理好Excel文案、字体和背景图，剩下的工作就能交给自动化流程完成。

# 如何使用？

## 方案一：直接使用已经上线的RPA应用

目前平台已经提供现成工作流，限时可以免费体验。

⏬RPA应用下载链接：小红书-RPA AI 批量图文排版-[Lisa] | 八爪鱼RPA官网（限时免费使用）

在运行之前，需要准备以下内容：

### 1. Excel文案文件

例如：

`E:\卡片文本.xlsx`

Excel中可以提前整理好需要生成的卡片内容。

⚠️当前工作流适用于两行文字排版。如果需要处理多行文字，需要另外定制工作流。

![](img/77fddcbd0e629679aba389f03b6ad76c.png)

### 2. 字体文件

例如：

`E:\shoushuti.ttf`

字体可以根据账号风格自行更换。

![](img/15b529389e255d075d55ed4d1f5ba31c.png)

### 3. 背景图片

例如：

`E:\template.jpg`

图片内容与文件名称可以自行准备。

### 4. 输出目录

例如：

`E:\output`

保存图片的文件夹需要提前创建。

准备好以上文件和路径后，根据工作流弹窗提示依次填写即可。

## 第二步：配置Python运行环境

这套流程会使用到Pillow、PIL等图像处理模块。

在八爪鱼RPA中，可以通过：

**其他 → 执行Python代码**

来完成相关环境部署。

由于RPA在相对独立的运行环境中执行，第一次启动时可能会自动安装所需模块。如果电脑中已经安装过，系统通常会自动跳过。

```
import importlib
import subprocess
import sys

def install_if_missing(package, import_name=None):
    try:
        importlib.import_module(import_name or package)
        print(f"模块 {import_name or package} 已存在。")
    except ImportError:
        print(f"正在安装 {package}...")
        subprocess.check_call([
            sys.executable, '-m', 'pip', 'install', package,
            '-i', 'https://mirrors.aliyun.com/pypi/simple/'
        ])
        print(f"{package} 安装完成。")

# 自动安装 Pillow
install_if_missing('Pillow', 'PIL')

# 现在可以安全导入
from PIL import Image, ImageDraw, ImageFont

# 你的后续代码...
```

如果自动安装失败，可以将错误提示复制给GPT，让GPT根据报错内容提供安装方法。随后打开电脑命令窗口，按照对应指令手动执行即可。

## 第四步：读取Excel数据区域

Excel成功打开后，还需要指定需要读取的数据范围。

进入：

**Excel → 读取Excel内容**

此前启动Excel时保存的对象变量，需要在这里继续调用。

由于示例中的表格包含两列数据，因此读取方式选择“区域”。

- `1`：从第一行或第一列开始
- `-1`：读取到最后一行或最后一列

读取完成后，将遍历结果保存为变量，例如“excel区域”。

## 第五步：循环读取每一行内容

获得Excel数据后，需要逐行处理。

每循环一次，就读取当前行中的文案和作者信息，之后再将这些内容放入对应图片中。

## 第六步：执行图片排版

接下来，通过Python代码将读取到的文字放置在背景图指定位置。

在左侧指令栏中选择：

**其他 → 执行Python代码**

代码的主要作用，就是循环获取Excel中的内容，并按照预设坐标完成图片排版。

```
from PIL import Image, ImageDraw, ImageFont
import os

def draw_image(quote, author, img_path, font_path, output_folder):
    # 加载模板
    img = Image.open(img_path)
    img_width, img_height = img.size

    # 字体设置（字号调大）
    font_main = ImageFont.truetype(font_path, 80)   # 主文字大字号
    font_author = ImageFont.truetype(font_path, 60) # 作者字号

    draw = ImageDraw.Draw(img)

    # 自动换行：控制最大行宽，靠左留白 10%
    margin_x = int(img_width * 0.1)       # 左右各 10% 留白
    max_text_width = img_width - 2 * margin_x
    lines = []

    words = list(quote)
    line = ""
    for w in words:
        test_line = line + w
        if draw.textlength(test_line, font=font_main) <= max_text_width:
            line = test_line
        else:
            lines.append(line)
            line = w
    if line:
        lines.append(line)

    # 计算总文字高度，整体垂直居中（稍微上移）
    line_height = font_main.getbbox("A")[3] + 20
    total_text_height = line_height * len(lines)
    start_y = (img_height - total_text_height) // 2 - 50

    # 绘制多行主文字（根据之前逻辑自动计算位置）
    x_start = margin_x
    y_start = start_y
    for i, line in enumerate(lines):
        x = x_start
        y = y_start + i * line_height
        draw.text((x, y), line, fill="black", font=font_main)

    # 绘制作者名字，放在底部靠左
    author_text = f"——{author}"
    author_x = margin_x
    author_y = img_height - 200
    draw.text((author_x, author_y), author_text, fill="black", font=font_author)

    # 保存结果到指定的输出文件夹
    os.makedirs(output_folder, exist_ok=True)
    output_filename = f"{os.path.splitext(os.path.basename(img_path))[0]}_{quote[:8]}_{author}.jpg"
    output_path = os.path.join(output_folder, output_filename)
    img.save(output_path)
    print(f"Saved: {output_path}")
    return output_path
```

需要注意：

文案和作者字段，要分别从第一行的第一个单元格、第二个单元格开始读取。操作时，需要点击对应行的内容，确保正确选中变量。

# 八爪鱼RPA和Canva，应该怎么选？

两者更适合不同的使用需求。

如果你的工作需要结合Excel数据、爬虫内容或其他自动化流程，同时还要一次生成大量图片，那么八爪鱼RPA会更合适，特别适用于批量生产和自动化场景。

如果你更看重设计效果，希望快速套用精美模板，而且制作数量并不大，那么Canva操作会更轻松。

简单来说：

- 重视数据连接、自动化和批量生成：选择八爪鱼RPA
- 重视视觉设计、模板丰富和快速出图：选择Canva
