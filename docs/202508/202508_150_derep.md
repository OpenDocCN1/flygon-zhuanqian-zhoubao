# 阿里出手了，本地生活这盘棋终于等到翻案
作者：龙哥

外卖市场寡头坐定的时间已经太久。京东悍然杀入之前，美团与饿了么双剑合璧，几乎把九成以上的份额锁在自己口袋里。抖音、📕在到店、酒旅上折腾得热闹，外卖这块硬骨头却始终是各家心照不宣的禁区。

本地生活这块硬骨头，阿里啃了七年都没啃动。曾经的新零售被逐步出清，饿了么也只能低头把账面先做健康。躺平、收缩、止血，是过去几年外界看阿里在本地生活的全部印象。

人到中年，最怕的就是被时代落下。最近三个月，局势悄然改写。

淘宝闪购被推到明面上挑大梁，历史悠久的饿了么被挪到幕后协同，连飞猪也被一并划入电商体系，三个业务被重新打包整合。吴泳铭在内部信里只用了八个字来定调：集中目标，统一作战。轻描淡写的一句话，背后却是迟到七年的战略转向。

从分散作战到集中火力，阿里本地生活的章法终于换了。
