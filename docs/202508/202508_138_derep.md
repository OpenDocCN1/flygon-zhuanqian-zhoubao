# 不会代码也能做网站？他用“打字游戏”带你零基础入门 HTML
作者：龙哥



前几天，龙哥大佬放了个消息：再过一两个月，就要手把手教大家怎么给网站搞流量了，还提醒大家趁早把 AI 编程学起来。

作为一个写代码的老手，我自然想出一份力。虽然现在 AI 写代码已经非常顺手，但说实话，它最擅长的还是那些单点的小功能、小模块。一旦碰上复杂点的项目，光靠 AI 硬写，效率反而会大打折扣。

关键问题在于，如果你脑子里没有完整的框架思路，也不懂怎么把代码拆分成清晰的模块，那 AI 也帮不上什么大忙。所以，哪怕只是懂一点代码的基础逻辑，对你来说都是非常有价值的。

市面上的编程教程，说实话已经泛滥了，而且大多都是照本宣科，听着就想睡觉。所以我想换个玩法：每次用一个好玩的小游戏作为载体，带着大家边玩边学。

这样学习的好处是，你永远知道自己为什么学、学了能干什么，不会越学越迷茫。而且每学完一个例子，你完全可以亲手做出一个同款的小作品，直接检验自己的学习成果，那种成就感是纯看教程完全比不了的。
