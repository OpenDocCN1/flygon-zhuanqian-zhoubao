# 用 RPA+AI 打造📕治愈系图文的自动化生产线



最近沉迷一个玩法，把📕上那种走心的金句海报、励志语录图做成流水线作业。今天就把这个 RPA+AI 批量排版的工作流拆给大家参考。

**核心卖点很简单：一台“图文印钞机”上号。3 分钟内吐出 100 张成片，风格统一，直接可发。**

先说说为什么这个需求会存在。

刷📕时，你会发现一类账号特别能养粉：统一的治愈风排版，一张图配一句金句，更新极稳，评论区互动也高。看着轻松，背后最磨人的其实是重复做图。选文案、调版式、导出、重命名，一张一张来，人都快做图做麻了。

我这套 RPA+AI 工作流就是来干这个脏活累活的。

从灵感生成到最终成片，全部闭环自动化：AI 负责出治愈系文案，RPA 负责套版、排版、生成，最终批量导出 100 张图文卡片，全程一键搞定。演示视频里就是这个流程在跑。

这个方案很适合三类人：

* 想用图文快速起号、但没设计师带的新手创作者
* 需要高频产出品牌语录、治愈内容的运营同学
* 任何想把每天几小时的重复制图时间夺回来的人

从此告别手动抠图和反复调整留白。

教程我放到了飞书文档里，做了两个版本方便不同水平的人上手：

版本一是即插即用的参数版，填好关键词就能跑。
版本二是可深度定制的教程版，想自己调字体、配色、版式逻辑都可以改。

很多在线排版工具要么贵要么限制多，这套流程最大的好处是：全程免费不付费，用开源工具和 AI 能力就把事办了🙂‍↔️
