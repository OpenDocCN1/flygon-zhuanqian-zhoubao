# (59 赞)被金钱诅咒的家族

富过三代？前世界首富被钱坑惨了一辈子

有钱很容易，难的是做个有钱人。

这句话，像是为前世界首富保罗·盖蒂家族量身定做的注脚。2017年那部电影《金钱世界》，演的其实就是他们家的故事。

很多人觉得，有钱人的烦恼就是矫情。可看完盖蒂一家，你会明白：钱多到一定程度，是会反过来吞噬人的。

盖蒂的父亲是个商人。1914年，老父亲给了他一万美元起步，大约十年后，这笔钱成了300万美元。1966年，吉尼斯世界纪录认证他是全球最富的人，身家估约12亿美元——按通胀折算，相当于今天的100亿美金。

注意，那时的12亿美元，和今天科技大佬账面上的股票市值不是一回事。很多富豪的身家只是纸面估值，几乎不可能一次性套现，因为老板必须长期持股，才能稳住公司的控制权。而盖蒂的钱，是实打实的现金。

这些钱大多来自石油。1949年，他从沙特国王手中拿到了沙特和科威特中立区大片土地的石油开采权。那片不毛之地当时没人看得上，三年后却给他带来了10亿美元进账。

有钱之后，盖蒂迷上艺术品收藏。为了安置这些宝贝，他专门建了洛杉矶盖蒂艺术博物馆。买画时他一掷千金，生活里却吝啬得惊人。1973年，他最心爱的孙子在意大利被绑架，绑匪索要1700万美元。盖蒂一开始分文不想掏，后来才松口说最多给100万，理由竟是：赎金能抵税，100万刚好是抵税上限。双方拉扯了好几个月，直到孩子的一只耳朵被寄过来，他才不情不愿地付了几百万，把人赎回。

盖蒂自己是商业天才，但孩子们却一个比一个让人窒息。长子一想到将来要继承这么庞大的家业，压力大到自杀了；老二从来不受父亲待见；老三染上毒瘾；被绑回来的小孙子受惊吓后，又染上毒瘾和酒瘾，基本算废了；老四原本口碑不错，却爆出婚外情和私生子，按当时美国社会的价值观，这种丑闻几乎让他无地自容。

盖蒂不是没预料到这些。他知道后代没有守业的本事，于是用家族信托安排财富：后辈可以定期领生活费，但不能随意动用本金；遗产税只交一次，不用等儿子再传给孙子时再交一次。这种遗产设计，也是很多富人偏爱的方式。他还特意只给家里留下一小部分钱，最大一笔捐给了盖蒂艺术基金会，用来维护博物馆的日常运转。

然而，再严密的遗嘱，也防不住后人“太聪明”。盖蒂一死，后辈们很快联合律师，从遗嘱里找到漏洞，把钱取出来分了。

这个家族原本有机会成为美国顶级的豪门望族，结果后代没什么出色人才，有人死于毒品，有人死于枪械，丑闻层出不穷，家产不断缩水。2017年，好莱坞把这段往事搬上银幕。电影里那句关于“容易”和“难”的台词，后来被无数人引用。

最近宗家遗产争夺的事也闹得很大，但放在豪门恩怨史上，那点钱只能算小场面——比它大几十倍、上百倍的争夺，一抓一大把。比如台湾巨富王永庆，去世时留下500多亿新台币，先被拿走120亿遗产税，剩下400多亿，几位太太和9名子女打了13年官司，直到最近才尘埃落定。

这种话听着确实有金句相，只是真正能共情的人极少，毕竟我们离巨富的距离太远。财富就像魔戒，没有强大的能力和心性去驾驭，得到它，往往不是幸福，而是噩梦的开端。我有一位年少成名的朋友说过：人生两大陷阱，一个是年少成名，一个是一夜暴富。最讽刺的是，这两个陷阱，恰恰是所有人做梦都想要的东西。
