# ('万字分享心理小白裸辞 9 个月，变现 20W 的辛酸史', (2, 29))

“想做心理赛道，但不知道从哪开始”“考了证却不知道靠什么赚钱”“副业做了好久，始终卡在0到1”……如果你也有这些困惑，那今天这篇分享一定要看完。

我是小檀，一名心理咨询师，也是优势天赋教练里最懂自媒体实战变现的陪跑者，同时还是自媒体实战中最能给你心力支撑的心理导师。因为见过太多人被挡在心理赛道门外，不确定自己适不适合、不知道怎么入门、更不知道怎么长期赚到钱，所以我想把自己的真实路径和经历完整讲出来，给对心理赛道感兴趣的朋友一个参考。看完有想法，欢迎随时留言交流。

这一次的内容，我整理成四个板块，分别对应不同阶段最容易踩的坑：

第一，新手入行，先给心理咨询师考证这件事祛祛魅；
第二，有心理学基础但一直没法变现，问题往往出在定位不够深入人心；
第三，副业心理人总困在0到1，我是怎么扛过低谷、提升心力的；
第四，从1到10跑通之后，靠天赋做事，累计变现20W。
