# ('不知道设计如何生财？你一定需要这份《生财设计搞钱指南》', (2, 29))

学设计的人，十个里有九个想过同一个问题：靠这行怎么真正赚到钱？会画图、会建模、懂审美，可一到“变现”就容易卡住。最近翻到一份《生财设计搞钱指南》，正好把这件事聊透了。

写这份指南的Keya，02年出生的INTJ，本科读产品设计，平时特别喜欢用设计思维去拆解各种问题。今年3月中下旬，她通过“搞钱女孩”认识了生财并加入进来，也进了生财大学生的社群，因而结识了七小哥和七玄门。这里必须感谢“搞钱女孩”的雪姨——没有她牵线，可能就没有这篇帖子。在七小哥的建议和帮助下，Keya和木鱼、锦黎、涂涂、路言、柯柯几位学妹组队，一起做调研、整理思路，又得到千帆老师、米斗老师的指导，前后忙了一个多月，才沉淀出这份指南。

这份指南做了哪些事？简单说，就是把生财站内和“设计搞钱”相关的帖子爬取下来，逐一梳理、归纳，从前辈们的经验里提炼出可参考、可落地的路径。对设计专业学生、自由设计师，以及好奇设计怎么变现的人来说，都是很有价值的一份参考。

值得一提的是，这也是Keya在生财发的第一帖，更是她头一次用“设计搞钱”的视角重新看自己的专业。她说这种方式让她对职业方向有了新的理解。帖子最后她也坦诚：内容还有生涩的地方，有些地方没讲清楚，欢迎大家指正。
