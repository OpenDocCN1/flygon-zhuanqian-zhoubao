# ('快递 cps 让我一年赚了 100 多万', (2, 22))

你可能想不到，一个学土木的90后，靠着“快递CPS”这个项目，一年干到了年入百万。这中间到底经历了什么？今天我把他的完整经历和核心玩法捋了一遍，分享给大家。

这位朋友是2016年毕业的土木生，刚出校门就撞上建筑行业寒冬。迫于生计，他干过三年的“刷量”活儿，说白了就是大家常说的水军，那几年倒也攒下了几十万。但后来这个灰色行业越走越黑，眼看风险越来越大，他怕把自己搭进去，果断收手。随后跑去工地搬砖，浑浑噩噩混了两年多，感觉人生一眼望到头，整个人都挺丧的。

转机出现在朋友提到的一个叫“快递CPS”的东西。当时他只是随手了解了一下，直到进了一个付费社群，看到圈友发了一份超详细的实操教程，他才意识到这项目市场空间有多大——电商每年都在爆发式增长，全国快递发件量跟着成倍往上翻，流量就在那里，关键是看你怎么接。

他决定赌上全部精力进场。

刚开始跑自然流量那阵子是真的难，一天也就几单，利润勉强够买几瓶水。但他没放弃，不断找群友请教、反复调整策略，慢慢摸到了门道，每天能稳定搞到几百人的精准流量，出单量自然是水涨船高。差不多一年多时间，他累计沉淀了50多万用户，月收入稳稳突破10万＋。

他在帖子里说，自然流量的具体打法已经整理成了一份详细文档，放在飞书里，想抄作业的可以直接去看。另外他也提醒，如果要做付费投流，前提是把回本周期算清楚，只要账能算得过来，在自己扛得住的范围内，哪个平台都可以大胆冲。
