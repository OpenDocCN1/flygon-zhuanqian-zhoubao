# 60天从0到千人代播团队，月入突破20万，这套“卖铲子”玩法值得细品

大家好，我是武汉萍姐。

今年是我在赚钱有术的第四个年头。这地方给我的，远不止一份收入。先要谢谢龙哥老大搭了这么好的平台，也谢谢每一位愿意把经验讲出来的圈友。前三年，我靠着从圈子里挖到的信息和机会，实实在在赚到了50万+。今年，我又踩中了视频号这波风口，找到了一条很特别的路径。

当时很多人都在做视频号直播，但最头疼的就是“时长不够”。直播时长上不去，流量就起不来，主播们只能硬耗着。于是我换了个思路——与其自己去挤淘金的路，不如做淘金热背后的卖铲人，帮主播们补上直播时长这个短板。

没想到，这个决定带来了意想不到的回报。我花了大概60天时间，从零搭起了一支近千人的代播队伍。三月，这个项目的月收入已经做到了六位数；四月，数字更直接冲到20万以上。现在项目框架基本稳定，整体运行也顺了，我和团队接下来要做的就是把细节做到极致，不给自己设上限。

做这个项目最大的体会，是“成人达己”——成全别人，也就成就了自己。这篇帖子我把自己从启动到跑通的经历、踩过的坑、总结出的关键细节，都整理成了一份深度复盘。完整内容比较长，放在飞书文档里了，想详细了解的可以直接点下面链接继续看👇👇
