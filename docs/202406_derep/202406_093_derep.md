# 从本地生活头部到生意测评：一日千粉的实操拆解

前几天在赚钱风向标里意外看到自己的名字，真的有点意外，也很感谢那位把我推出来的圈友。

现在我主要在做生意测评方向，也就是教人做生意的实操类内容，这类账号的涨粉速度和流量爆发力非常惊人。最近一条摆摊拉拉乐的测评在抖音上已经破了100万播放。

发现大家对这类生意测评内容比较关注，今天就把我整个做号的思路摊开说。从选品买工具，到实地摆摊的经验，再到拍摄剪辑手法和账号怎么养，都一次性讲清楚。

先做个简单自我介绍，我是成成。算是抖音早期的一批本地生活创作者。

2022年本地生活赛道最热的时候，我的账号在同城赛道里的表现是顶尖级别的。那个阶段本地生活垂直号很少，我在本地同时拿下同城达人榜第一，还参与了当地头部本地服务商的运营。靠着对业务的深度理解，我当时一条视频稳定几十万到上百万播放。

现在很多做本地生活的号还在沿用我那一年的文案和结构。如果你在22年、23年前做过本地生活，应该刷到过我的老号，当时叫成成/同城流量，现在已经改名成成/生意测评了。

可惜的是，2024年本地生活的整体流量断崖式下跌，我的视频从百万播放直接跌到上万都困难。年初我辗转多个城市后回到老家，开始思考转型方向。

我一直觉得商业类账号的变现效率是最高的。所以今年我直接把本地生活的老号改造成了生意测评号，每发一条视频就实测一个项目。

转型初期我全部选了摆摊项目来测试，原因很简单：摆摊类内容太容易起量了。结果也证明了判断是对的，这几条视频直接把我沉寂一年的老号激活了。

第一条漆扇摆摊测评播放破50万，第二条拉拉乐摆摊测评播放破100万，而且光这两条就给我带来了500多人的私域沉淀。
