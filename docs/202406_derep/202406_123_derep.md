# ('做面包，怎么省¼的钱', (2, 12))

都说烘焙行业利润薄得像纸片，但你知道有人能把成本压掉四分之一吗？

小马宋的客户“爸爸糖”旗下有个兄弟公司叫“糖兜科技”，它日常负责给盒马供应烘焙产品。最近小马宋分享了这家公司的一波降本操作，看完只能感慨：会过日子，才是真本事。

第一个绝招，是把工厂直接“贴”在面粉厂旁边。糖兜跟益海嘉里、盒马联手，生产车间就建在益海嘉里的面粉厂隔壁。面粉压根不需要装袋、上路，直接用管道“吹”进烘焙区。这样一来，包装材料省了，人工搬运省了，连运输途中洒粉、受潮这类损耗也归零了。

第二个招数，是“蹭”别人的仓库。糖兜干脆用益海嘉里现成的仓储空间，还把烘焙辅料也放在一起集中采购。自己不用大兴土木建仓库，库存周转也更灵活，省下的可都是白花花的银子。

第三招更妙：把生产放在夜里。晚上开工，电费直接按下调档价格算；而且凌晨做好的面包，早上一开门就能摆上货架。新鲜度拉满不说，面包在仓库里“过夜”的时间缩短了，保质期自然更长，退货率也降了不少。

最后一招，是克制。糖兜只做鲜奶吐司、北海道面包、麻薯、羊角包这四样爆款。产品线短，生产线换型次数就少，设备调试和物料浪费也跟着降到最低，效率反而蹭蹭往上涨。

你看，省钱的灵感不一定来自什么惊天动地的大变革，把供应链上的每颗螺丝都拧紧，利润自然就挤出来了。
