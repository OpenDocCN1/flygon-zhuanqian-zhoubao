# ('生财思维课图谱：37张竖屏思维导图，解锁生财新思维', (2, 27))

各位圈友，罗卜在这里。

熟悉我的人都知道，我是个“图解控”，尤其爱做竖版脑图。这些年我累计画了400多张图，也因为这个爱好被大家认识，后来还成了脑图训练营的教练，并加入了航海队伍。

今天要带来的，是一份我和11位伙伴共同完成的《财富认知课》图解合集，一共37张，内容全部围绕内部这套课程展开。

起因很简单：这门课每节末尾都会推荐3篇优质文章。我当时就想，如果能把每篇文章的要点都做成图，应该会很实用。单独行动也能完成，速度或许还更快，但我觉得把机会分给更多同路人，一起搞事情，会更有意思。

于是，这次共创启动了。参与成员包括：金多数、小玉、钱男友、睿睿、符亮、大吉、阳光笑脸、小青年、嗡嗡嗡嗡、六和、薄荷，还有我。那段日子，社群里最活跃的画面就是大家轮番晒图，运用费曼技巧互相提意见，氛围非常好。

在此，也要感谢课程幕后的运营和编写团队，更要感谢那些大方分享经验的原作者。没有他们的文字，这些图就成了无源之水。

在这个社群里待得越久，我越相信三个词的分量：真诚、利他、分享。做图恰好把它们串了起来。你真心实意地输出，别人能察觉；你做的图能帮人省时间、做回顾；你把图发出去，让更多伙伴看到，这三个词就已经落地了。

更有趣的是，最后赚得最多的，还是自己。

每做一张竖版脑图，我至少会把原文读上三遍：头一回先抓要点，第二回精简文字排版面，第三回按大家的反馈抠细节。三轮下来，各项能力都有实打实的提升。

写作上，看了大量好文章后，自然摸透了热帖的骨架和必备要素；思考上，面对长篇大论，我会下意识提取关键字、归纳大意；逻辑上，图做得越多，越会琢磨结构如此安排的原因、案例如此选取的道理；排版上，每条分支只容纳一个核心信息，清楚何时该加粗、何处该着色、字号怎样从大到小排布；色彩上，常用社群统一色调，也建议各位尝试相邻色、撞色等更多组合，别被单一色系限制住。

还有一点尤其值得说：选材时，优先挑与眼下或下一步计划有关的领域。这样图做完后，这个领域的运行逻辑、关键细节和背景知识也就基本吃透了。想继续深入，就再找同领域的更多文章来图解，角度一多，玩法自然更丰富。

当然，收获远不止这些。做图久了，它会成为一项让人注目的本事，帮你链接到更多机会。

那么，这套合集怎么用？建议搭配原文一起看。先读原帖，如果还有没弄懂的地方，再打开图对照着梳理一遍，思路往往就通了。
