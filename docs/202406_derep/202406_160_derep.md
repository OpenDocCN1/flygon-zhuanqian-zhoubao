# 请你不要看宠物行业

宠物行业，请别小看

今天，我不聊猫舍老板那套生意经，而是作为一名猫咪家长，和赚钱圈的朋友们说几句实在话，尤其是那些一直盯着宠物行业的人。

我是阿岳。2021年做起了猫舍，到现在快四年了。这四年，我亲眼看着宠物行业一路起飞，自己也跟着分到了不少红利。最初，我手里只有一只猫；如今，猫舍里已经有近200只品种猫，走的是高端路线，目标直指全球顶级华人猫舍。今年，我们还成为了程前朋友圈的专访对象。能有今天这些成绩，还真离不开赚钱方法论给我的启发，这份感激一直放在心里。

所以，别急着给宠物行业下结论，更别急着下场。我把更详细的内容整理在下面的链接里了，看完你再做判断可能更有底：
