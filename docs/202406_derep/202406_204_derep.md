# 同城实体发售，一个城市就能做到上百万？毛利还超70%，这事靠谱吗？

听到“同城实体发售”，很多人第一反应是：线下生意不好做，实体店都在关张，这还能赚钱？

但事实恰恰相反。专门帮本地实体店做发售，一个城市就能做出几十万、上百万的盘子，毛利还能稳稳地保持在70%以上。

我是孙策，过去一直在拉新领域做事，带过好几百位圈友在这行里赚到钱，其中不少人的成绩是几十万、几百万。22年的时候，我开始集中精力研究同城赛道，越做越确定：这大概是普通人为数不多的、能拿到大结果的方向。我们做的事情很聚焦——帮同城实体商家策划发售活动，这套打法打磨了整整两年，今年决定全国化，并启动线下孵化。4月份和几个圈友正式开城，短短时间，两个城市合起来做了将近150万，毛利超过70%。
