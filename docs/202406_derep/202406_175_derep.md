# ('用好赚钱， 打造自己的赚钱系统', (2, 17))

赚钱有道，关键在于“用起来”——这是四年圈友陈雪最想对新伙伴说的话。作为今年“唤新”活动的第三名，她以学姐身份分享：加入龙哥盟，不是买个门票看热闹，而是把工具真正变成自己的赚钱系统，走在对的方向上，心里就不慌。
