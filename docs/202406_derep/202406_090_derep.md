# ('小红书年产 10w 条素材 带货 5000 万的算法经验分享', (2, 32))

10万条笔记砸出来的5000万带货心得：小红书笔记到底该不该挂车？看完不再纠结

有个93年的内容老炮，叫戴小胖，干过广告、跑过MCN、也做过电商，这行一待就是10年。如今他主攻小红书电商和IP孵化，电商盘子做到了5000万以上，好几家店铺月销能破百万，最猛的单店单月干到800万，单条笔记带货最高80万，退货率控制在8%，冬季产品稍微高一点，但也稳在20%以内，这水平在圈内确实能打。IP端他坐拥200万粉丝，变现累计超千万。

最近老被人追着问：小红书的带货笔记，什么时候挂车合适？什么时候坚决不挂？为什么别人的笔记一挂车流量狂飙，自己的却一动不动？他用团队一年测试10万条笔记素材的经验，以及100多条带货超20万的爆款笔记，给出了他的答案。

先搞清楚平台怎么推。官方早就说过，笔记挂车后，除了常规的CES流量池，还会额外考核加购和转化，但具体权重怎么算，没有明说。他分享了一条真实数据：一支8秒的纯产品展示视频，没有真人出镜，看着平平无奇，一个月却卖了50多万，跑出1600万播放。如果不挂车，可能连500个小眼睛都混不到。一旦挂车，它持续出单，持续给平台赚钱。平台不推这种笔记，推谁？

很多人以为“转化”就是成交，其实要细分。所有电商平台分配流量的核心都是转化，但分两种：转化率和转化金额。淘宝和抖音看的是转化金额，淘宝叫坑产，抖音叫GPM，本质都是UV价值，也就是GMV和流量的比例。拼多多看的是转化率，说白了就是单量。比如两条笔记，流量都是200，A笔记客单价200成交2单，B笔记客单价10成交10单。A的UV价值更高，在淘抖体系里流量更好；B的转化率更高，在拼多多体系里更占优。那小红书到底更偏爱哪种？这点很值得琢磨，他准备以后单独开一篇细讲。

到目前来看，小红书电商笔记的流量分配，主要看三大板块：交易、商品流量和互动。

交易是排第一位的，也就是官方说的转化。而转化里最关键的是交易金额，毕竟平台是按总交易额5%抽服务费的。排在第二的是转化率，如果你撑不起高交易金额，那就退一步，用低价福利品去拉转化率，同样能快速提升笔记权重和账号权重。至于成单量，只是自己做分析用的，算法分配时不看这个。

第二块是商品流量，重点盯点击率和加购。官方也亲口说过，加购对笔记推流影响很大。所以自己操作时，可以适当优化加购和点击数据，交易数据也可以做一点，但比例要控制好，别超过真实成交量的10%。

第三块是互动，也就是CES：点赞收藏各1分，转发评论4分，关注8分。这里面最值得下功夫的是评论，粗暴有效的方法就两个：惊喜盒子和评论区“蹲”。

把这套底层算法琢磨透以后，挂不挂车的答案就清楚了。两句话概括：

第一，看产品竞争力和转化。有些品自带流量，笔记稍微带一下就飞；有些品全靠笔记硬撑，如果转化本来就不行，挂车只会拖累笔记流量，不如不挂。

第二，看广告属性。硬广是直接拍产品，流量有一定随机性，好处是出单快、省时省力，缺点是基础流量不高。软广常见于穿搭合集这类形式，挂车之后转化容易拉胯，那还挂什么？老实说，不挂更好。
