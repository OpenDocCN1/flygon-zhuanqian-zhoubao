# ('医生自媒体人分享健康保养与就医指南', (2, 19))

你有没有想过，拼命赚钱的同时，身体却在悄悄透支？今天给大家介绍一位特别的医生——梁靠谱。她不只是坐在诊室里的医生，还是一名做了五年自媒体的创作者，曾经支援过疫情、参与过洪水急救和灾后重建。更难得的是，她一直坚持运营一个免费的健康知识星球，为上万名网友义务解答健康困惑，再忙也没停过。

最近，她把自己多年遇到的常见问题整理成了一份超详细的“基础保养与就医指南”，全文足足两万多字。她说，我们每个人都是社会和家庭的支柱，努力搞钱固然重要，但千万别把健康晾在一边。她还算了一笔账：每年多赚200万，如果因为身体好能多活十年，那就相当于多赚2000万。这笔账，谁都会算。

这份指南内容非常实用，从日常保养到怎么高效就医，全都覆盖了。她希望大家在“龙哥盟”的同时，也能“长命有术”。好东西当然要分享，指南链接放在下面了，需要的朋友直接点开就能看。别忘了收藏，也转给身边那个总熬夜拼命的人吧。
