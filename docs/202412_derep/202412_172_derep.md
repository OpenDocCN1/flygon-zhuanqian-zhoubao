# ('专科大学生迷茫职业规划，通过阅读与实践寻求自我提升', (2, 27))

“毕业那天，我就能看到自己退休前的样子”——这是来自一位专科生的迷茫自白，我想，可能也是很多人的心声。

他出身普通家庭，没有人替他规划人生，所有选择都是自己摸索着做。他隐约知道，那份“一眼望到头”的工作并不是自己想要的，可又说不清到底什么才适合自己。他没加入社团，不热衷学生会，但却保持着两个习惯：读书和做事。看《真需求》《5%的改变》《薛兆丰经济学》《拆掉思维里的墙》——虽然不确定这些书的“含金量”到底多高，但至少觉得有收获。他还报名了12月的航海，正在边学边实践。于是他问：人生的大方向该怎么定？除了每天阅读，还有什么办法能让自己持续成长？

这句话让我特别有共鸣：人是走了很远很远的路，才慢慢看清适合自己的方向。

回头看，从07年踏入大学，到17年，整整十年，我也和大家一样：做一个项目赚点钱，项目黄了，再找一个，间歇性陷入迷茫。直到17年，我开始试着做一个叫“龙哥盟”的社群，当时也没有笃定这就是我一生的事业。真正认准这件事，是在三年后的2020年——我才确认，带着一群普通人赚钱，好像是我想长期做下去的事。

我想告诉大家的是：迷茫不是例外，而是常态。每个人都会时不时不知道下一步往哪走，这太正常了。

如果你实在不知道该干什么，那就去做离钱最近的事。哪怕那件事不是你最热爱的，赚钱本身就是在和真实世界硬碰硬地打交道。在这个过程中，你会慢慢认识自己，甚至撞见自己真正的热爱。

只是很多人太急了。一场航海没有立竿见影的反馈，就开始否定自己；一年没赚到钱，就开始怀疑一切。但这个世界有个朴素的逻辑：我们总是高估环境短期给一个人的冲击，却低估它长期带来的重塑。别急，慢慢来。

连我自己，花了17年才走到今天。我自认天资平平，你们中很多人的起点比我还好。我起步时，没有钱，没有人脉，没有圈子，一路踩坑，才找到方向。而今天，点开这篇文章的你，至少处在比当年的我有利得多的环境里——比如，你已经在龙哥盟这个圈子里了。有这份条件，加上时间的复利，你一定会比我走得更远。

所以，慢下来吧。把心放稳，允许自己按自己的节奏前进。日拱一卒，不疾不徐，有一天你回头看，会惊喜地发现：自己早已远远越过了当初以为的终点线。

别慌，路是走出来的，不是等出来的。今天脚下一步一步蹚出来的光，会在未来连成一条属于你的路。
