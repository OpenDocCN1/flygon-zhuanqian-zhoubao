# ('只工作 4 小时员子姐分享自由职业心法与自我认知', (2, 26))

“每天只工作4小时”的员子姐，进入自由职业的第二个年头了。回看这两年，她把成长分成了两种节奏：第一年是向外冲，一门心思跑通商业闭环；第二年是向内收，专注修炼内核、稳定心力，好去接住自由职业随时可能冒出来的困扰和阻碍。

作为职业生涯规划师、盖洛普全球认证优势教练、MBTI高级解析师，员子姐这一次没有讲成绩，也没有堆技法。她更想分享的，是这两年里沉淀下来的心法，以及怎样结合自我认知的结果，找到真正适合自己的精准定位。
