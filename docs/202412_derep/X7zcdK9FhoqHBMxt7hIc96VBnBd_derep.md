# ('AI雪地写字视频玩法', (2, 12))

最近“AI雪地写字”这类视频真的刷到过不少，看起来特别有氛围感，其实做起来一点都不难。

这个玩法的核心，就是用AI生成一张“雪夜车窗刻字”的图片，然后再把它变成动态视频，仪式感和浪漫感直接拉满。

操作上主要用到即梦这个AI工具，地址放这里：https://jimeng.jianying.com/s/iUb6MaPU/

关键在提示词的写法，我直接给你一套可以复用的模板：

胶片摄影，夜晚街道，路灯，大雪，堆满积雪的SUV汽车，车玻璃积雪上刻着“高鹏圈ILOVEYOU”，文字周围刻着可爱的简笔图案，复古滤镜

有几个细节要注意一下：提示词开头一定要带上“胶片摄影”这四个字，这是出片质感的保障。接着描述场景环境（哪里、什么天气），然后落到主体（什么车、哪里刻字、刻了什么内容），最后加上装饰性元素和滤镜风格描述。
