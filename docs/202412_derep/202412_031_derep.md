# 二、功能规划

为了让零基础也能快速完成，我把这个海报生成器的功能控制得很轻，只保留两块：

1、首页，用于生成海报的核心交互页
2、我的，用于查看历史生成的记录

后续的业务逻辑会交给工作流来承载，本期重点只做界面搭建。

# 三、移动端 UI 的搭建思路

应用创建好后，接下来就是页面建造。

## 1、选择 UI 搭建类型

进入应用后，点顶部「用户界面」，选择「小程序和 H5」，再点「开始搭建」

![](img/c95fcb4a7cadc8de297e16025fa49f7b.png "None")

## 2、搭建「首页」，也就是海报生成页

### ①、添加表单作为触发入口

![](img/91936e185fe63d799ad6416e50c78599.png "None")

### ②、调整表单字段

整个页面的交互很简单：用户输入一个 24 节气的名称，再填写图像生成的需求，点击生成后即输出海报。所以表单最终呈现为：

![](img/0632e492422f5120d99a444fe22cb7ed.png "None")

修改方式很直观，点击页面上的元素，右侧属性面板就会弹出，基本都能迅速上手，这里就不展开细讲了。

### ③、添加图片预览区

生成之后需要展示结果，因此在表单下方放置一个图片组件作为预览位。

![](img/9727aa7ea857d74e55733de059bd4566.png "None")

因为目标是手机壁纸的使用场景，比例需要改成 9:16

![](img/fe0068b09c17a4ca753603fe330936c1.png "None")

至此，首页的雏形就出来了。需要注意的是，页面打开时图片会直接展示，视觉上不太自然，后续在逻辑层需要控制图片的显示隐藏，暂时先保留。

## 3、搭建「我的」页，展示历史记录

生成的内容希望能保存下来，方便用户回看，这就是「我的」页的核心价值。

### ①、新建页面

点击页面底部的新增按钮新建一页，命名为「我的」

![](img/643eb5f2c4de498bb651067b2b52e803.png "None")

![](img/e247264108bf14737c0692fa48cd5766.png "None")

### ②、把菜单和页面关联起来

点开底部菜单栏，将「我的」按钮的跳转目标绑定到刚新建的页面上

![](img/e48e923560aa9bfcd9ee4eab2553fe24.png "None")

别忘了**首页那边的菜单也要做同样的关联**，否则切换会出错。

设置完毕后点预览，检查菜单切换是否正常。

### ③、添加纵向列表展示历史

用于滚动展示历史海报

![](img/0be37a8c428391aee82af4b8247abd79.png "None")

### ④、补充标题与时间信息

期望的呈现是：上方是图片，下方是节气名称+生成时间，最终效果如下

![](img/e3a6bd2e0b3dd7f0c9e461df20444cae.png "None")

**怎么实现？**

改布局需要用到「容器」控件，它负责灵活排版。我在列表内容下方加一个容器，拖动一次后所有列表项都会同步。

![](img/a220dba4f99eafd43aa55f759a4e1320.png "None")

接着把标题控件拖进容器内

![](img/1f8b6ff48de5799edbed2efd3aedc2cf.png "None")

时间也需要展示，所以再拖入一个文本控件

![](img/77974f749534d6b7c4bde691baec0b5d.png "None")

此时排版略显生硬，需要微调。点击控件后在右侧调整属性

![](img/2b7387996bed4a0ccb182a9603a75c77.png "None")

把高度改为「适应内容」，排列方向选「横向」，内边距调为 0 ，可以自行尝试不同参数看效果。

![](img/9ce7e838ee369192c0a39e8abdb08bf4.png "None")

调整后页面效果如下

![](img/e312a17d98993da6bc7cd727cf1b381b.png "None")
