# 新手小白在今日头条历史类视频变现的复盘

新手做今日头条历史类视频，能赚到钱吗？一位刚入圈的小学老师，用亲身经历给出了答案：能，而且赚到的第一块钱，可能比金额本身更有意义。

这位名叫九里香的作者，目前在中越边境小城当老师，今年五月才加入赚钱。她复盘了自己在互联网上赚到的第一笔收入——通过今日头条历史类视频变现。整个过程不算惊天动地，但对一个纯新人来说，却是一次完整的“从0到1”闭环。

有意思的是，评论区里的人并没有只盯着收益数字，而是提炼出了更值钱的东西。有人感叹：钱多钱少根本不重要，重要的是她一个人独立完成了一次MVP。而且严格来说，她其实完成了两次MVP——第二次，是把做项目的全过程写成文字、分享出来。这种“输出带动输入”的方式，会让人对项目的理解更深刻，对操作细节的印象也更深。每总结一次，就像攒下一颗珍珠；攒得多了，总有一天会有一根线自动把这些珍珠串成一条独一无二的项链。

还有人分享了自己的类似经历：也在今日头条做过视频赚钱，最后放弃了。但那条路最初是为了批量涨粉卖号，后来靠卖头条号赚了几千块。其中粉丝最多的那个号因为实名问题没卖成，等发现时已经八万粉了，索性试着搬运快手爆款视频赚收益。没想到其中一条视频就赚了501块。当时他还专门研究过这个项目能不能放大到月入一万，结论是：太难了，于是放弃。

更有意思的是，有人指出这种玩法的“翻版”已经出现——抖音语音故事号。同样是一张图配一段长时间语音讲故事，变现方式也是涨粉卖号。已经有朋友在批量操作，同时搞十几个号，具体收益情况还不清楚。

说到底，新手做内容变现，第一块钱的意义不在于多少，而在于你终于跑通了一个流程。更重要的是，把这段经历复盘出来，本身就是一次增值。下一个项目，说不定就是那颗把珍珠串起来的线。
