# 从2小时到2分钟：我靠Cursor把音频剪辑这个“死结”解开了

我是大橙子，一个刚进赚钱圈几个月的新人。12月航海，我脑子一热报了两个赛道：YouTube Shorts和Cursor。说实话，两个都是零基础。点燃我的，是钱塘江鲤大佬的一篇帖子——如果能用Cursor自动做YouTube Shorts，那岂不是躺着挣钱？抱着这种朴素的愿望，我上了船。

![](img/454e6cf9a57a9e54399621496a044155.png)
![](img/410f5cb8ab9fc84e3310091ab44f36f9.png)

上船没几天，双赛道给了我一个“下马威”。这边刚学会导入素材，那边就要面对一串天书般的代码。我就像个要同时颠两个炒锅的新手厨师，顾了这头顾不上那头。白天上班，晚上恶补，时间根本不够用，学得也很吃力。不过，看到群里伙伴晒出的成绩单，领队和志愿者一直在打气，我反而想通了：这不是挑战，这是航海实战送我的成长礼。挑战越大，我突破的空间就越大。

在YouTube Shorts赛道，我幸运地遇到了老马教练。第一场高手领航就让我目瞪口呆——他不是只讲理论，而是从头到尾亲手演示：怎么选让人想点的选题，怎么剪出不拖沓的节奏。教练几乎把饭嚼碎了喂到嘴边，就差替我们咽下去。他的故事号拆解帖子和领航实操视频，建议大家好好看几遍。

![](img/a4722e5084fe25b6d0d9a81ed7a69bf5.png)

接着说说我的实操流程，每一步都是照着教练的方法走。

别看我写得轻松，实际上光是准备第一条视频的素材、音频和文案，我整整花了两天。

**第一步：囤素材。** 我先把教练给的对标素材库账号挨个关注了一遍，然后去ins刷视频，看到可能有用的就关注。有个重点：尽量找没有人脸、没有字幕的素材，这样后期剪辑很省事。但也要小心，有些视频中间会突然冒出小字幕，最好点进主页确认一下这个账号的其他内容能不能放心用。确认没问题，果断关注。一条1分钟的视频，大概囤5条左右素材就够了。

![](img/d255705d24a848db4c950ea5fab97569.png)

**第二步：找文案。** 教练给了几个Reddit上的“故事矿”：BestofRecdates、AITAH、AmItheAsshole、TrueOffMyChest、self、nosleep。我挨个翻，专挑能让人情绪上头的故事，或者搞笑的段子，总之能给观众提供情绪价值。评论区也要留意，有时候底下藏着一条比正文还精彩的回复。

![](img/3a3d4bfc94ff869d7cb2faf71629a22f.png)
![](img/9d2dc497ae174288dedf6a194eb19f50.png)
![](img/5dde333bfd2da28f5ce9c61095886df8.png)

**第三步：改写文案。** 我直接用Claude改，提示词就是教练反复调校过的那套：字数控制在原文的1.1倍以内；结构是“精华开篇+细节递进+转折+点题”；人称和核心事件必须保留；每段最多重复两个关键词，多换新鲜比喻，多用动作描写；句子要短，主干要清晰。改出来的文本基本不用大改，非常省心。

![](img/5d23cdaf8a12bdd0a014b9262d939563.png)

**第四步：配音。** 用ElevenLabs，新账号有1万字符额度，拿来练手完全够。男声我选Adam，女声用Natasha - Valley girl。额度用光了，直接上淘宝解决。

![](img/3547dd0dfe6323db9681f20a76a41f7b.png)
![](img/a892162a306b6b72f4eb172966ee513b.png)

**第五步：标题图。** 用Figma社区的现成模板，把内容改成自己的就好，不用从零画。

![](img/7752e5c4179203cd53e60731bd28c344.png)
![](img/2e04a26f6b6a5d1974dcb37c407aa335.png)

**第六步：找BGM。** 看对标YouTube账号用的是什么歌，直接拿来用。但注意，一条背景音乐最好不要超过1分钟，不然可能有侵权风险。

![](img/782508b7d0d58ad147fca2f5befa1ea1.png)
![](img/64f7ed1ab0ab46149e4a23f6bf9b81ca.png)

所有素材备齐后，就是剪辑成片。具体操作老马教练在领航课里讲得特别细，我这里就不重复了。我反反复复看回放，一步步跟着做，总算把第一条视频做出来了。

![](img/e190a1818c4e26954706b47d8f3bd5c3.png)

做出视频那一刻，我真切感受到“有人领路”有多幸福。如果让我自己摸，可能猴年马月还在踩坑。可乐领队总在群里说“听话照做，惊喜不断”，这话我信了，也确实应验了。

**但紧接着，一个“克星”出现了：剪音频气口。**

第一次用CapCut，我一看到那条蓝色音频线就头大。一条1分钟的朗读音频，差不多要切掉27个停顿处，之后还要对齐。一开始我每天都要在这上面耗1到2个小时。连续熬了四天，我几乎崩溃，心想这玩意儿比看老板脸色还难受。群里的氛围特别好，教练耐心答疑，船员们互相帮忙，我不想放弃。我试过软件自带的智能剪口播和识别字幕，但系统总是识别不到，急得我像热锅上的蚂蚁。

与此同时，我在学Cursor，按手册一路从俄罗斯方块小游戏做到能上线的网页。做到“恋爱网站”的时候，我随手翻到手册最后，看到蘑菇教练写的《Cursor自动剪辑视频》。脑子里“叮”了一声：既然视频可以自动剪，那音频里的静音气口，是不是也能用同样的思路自动解决？

![](img/1ea80160ba9088073b4474218faa9831.png)
![](img/7f3baed98483e841b5323d5b367579f6.png)
![](img/3c009d723fbc04f0187199012cb73b30.png)
![](img/6b4d8dfb2e7d155d5846efb86606110c.png)

想到就干。我打开Cursor，输入要求：用Python实现音频“剪气口”功能；读取/F:/Youtube（素材）/音频目录下的文件，按顺序一次处理一个，生成新的音频；能通过设定音量阈值（比如-40dB以下）检测并剪除静音；最后重新合成音频。Cursor很快就给了我一段代码。

![](img/01be8b9f6fc445045f38790f17f942e9.png)

当然新手就是新手，后面报错报得我怀疑人生。先是系统环境变量，按Cursor提示装了FFmpeg；再是Python版本太高，又按提示降级。每次报错，我直接把错误代码甩给Cursor，它立刻能指出问题，要么帮我改好代码，要么一步步告诉我怎么操作。前前后后磨了半小时，试了四五次错，第一个能自动剪气口的小工具真的跑起来了。

效果怎么样？以前剪一条音频要2小时，现在2分钟能出N条，效果和手动剪几乎一模一样，效率直接原地起飞。我一个连代码都看不懂的人，居然在Cursor的引导下做出了自己的提效工具，这放在以前想都不敢想。

后来我把这个工具拿给蘑菇教练看，他帮我把Python脚本打包成了exe文件。这下不用装环境、不用写代码，任何人都能直接双击使用。我制作视频的效率，彻底被解放了。

回顾这段航海，我从一开始的迷茫，到最后能自己动手做工具，除了运气，我想是因为我做对了几件事：

**第一，听话照做，先动起来。** 不行动，你根本不知道问题会卡在哪。完成比完美更重要，你先按手册做出一个60分的成品，然后才有机会迭代到80分、90分。最难的就是迈出第一步。

**第二，遇到问题先自己找答案。** 一有问题就张口问，教练直接给答案，你永远学不会举一反三。只有自己实在搞不定了再问，这时候得到的答案会记得特别牢，也因为卡过而理解得更深。

**第三，找一群同频的人。** 这次航海最珍贵的其实不是技能，而是一起扛过事的伙伴。有人鼓励、有人指路、有人一起趟坑，这种“共同成长”的经历，比任何成果都宝贵。

感谢老马教练、蘑菇教练、马可乐领队，还有所有教练、领队、志愿者和并肩作战的队友们。赚钱有术对我来说，不只是一个学习平台，更像一个大家庭。开营时坤汀说：“快速试错、保护热情、不怕丢脸、下场做把手弄脏。”这一次，我真真切切地践行了。

虽然我做的视频并不出彩，没跑出爆款；我也不会编程，报错信息都看不懂；我做的小工具也很简单，别人可能10分钟就能搞定。但像我这样一个连电脑都不太懂的人都能做出来，圈友们只会做得更好、飞得更高。所以，别怕未知，别怕挑战。
