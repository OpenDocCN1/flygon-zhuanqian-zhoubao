# AI儿童故事绘本带货玩法

想靠AI做儿童绘本带货？这条玩法路径已经跑通了！不需要自己写故事、也不会画画，全程用AI工具就能批量产出绘本内容。今天把整个流程和工具清单一次性整理给你，照着做就行。

先理一下思路：整个链条分四步——生成睡前故事文案 → 提炼分镜描述词 → 扩写AI绘画提示词 → 用绘画工具出图成册。

第一步，用“睡前故事AI文案生成智能体”直接产出故事文本，入口在这里：https://doubao.com/bot/55X9eB7v

第二步，把故事交给“分镜描述词AI”来拆解画面。这个AI就在豆包平台：https://www.doubao.com

这里有个可以直接复用的提示词模板，记得把“故事原文”替换成你自己的内容：
"我将提供一篇睡前故事文案，我需要从里面提炼分镜画面描述词，请以表格的形式整理好发给我。故事原文：***"

第三步，用“AI绘画描述词扩写智能体”把刚才的分镜描述词进一步细化，让画面指令更精准。智能体地址：https://doubao.com/bot/2qupfuBv

第四步，打开AI绘画工具，把扩写后的提示词丢进去批量生成插图。工具我用的是Recraft，邀请链接在这里：https://www.recraft.ai/invite/VxMNm5yrdZ

整套流程下来，故事、分镜、画面全都有了，组合起来就是一本完整的儿童绘本素材，接下来就可以挂链接带货了。
