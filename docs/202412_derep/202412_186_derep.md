# ('个人消费变化与渠道压榨：通缩背景下的经济困境', (2, 24))

通缩之下，我为什么开始这样花钱？

前阵子我转了一篇讨论内容电商的文章，结果被平台给删了。删除的理由我倒能接受——里面的确有些数据引用不太准确。可那篇文章真正想讲的，是当下流量分配者从卖家身上抽血抽得太狠，这点我特别认同。

今年的大环境，大家心里都有数。通缩本质上是个不断自我强化的下行螺旋——东西越积越多，价格越压越低，利润越摊越薄，员工到手的收入也跟着缩水，大家敢花的钱越来越少，需求不足又反过来加剧产能过剩。这么一圈一圈滚下去，短期内很难翻身。

而在这个局面里，谁能把货卖出去，谁就掌控了利润分配。渠道凭着自己“效率高”的优势，把大盘里最肥的那块肉几乎全夹走了。商家就算有销量，留在自己账上的那点钱，也薄得像纸片。

更要命的是，渠道运转需要的人手极少，效率越高，创造的就业反而越少。哪怕它赚得盆满钵满，能分到钱的也只是极少数人。反过来，真正雇着大量员工的生产商和服务商，拿到的利润却少得可怜。渠道越繁荣，大众腰包越瘪，消费自然撑不起来。

所以，我个人的消费策略也在悄悄改变：我会刻意把钱花给那些能覆盖更多人的环节。

比如，能堂食就不点外卖，尽量让餐厅多赚一点；不在大主播的直播间下单，直接去品牌商家的店铺买；消费尽量向服务倾斜，而不是囤一堆实物——服务业是最难被机器替代的行业，也是目前最大的就业蓄水池，把钱花在这里，相当于间接养活了好几个具体的人。我的车一年开不了几千公里，出门基本靠打车。

手机贴膜、理发、修面、足疗、美甲、纹身、家政清洁这些，我也都很愿意买单。

我当然清楚，一个人的购买力翻不起什么浪花。只是，有些事不是因为注定有用才去做，而是因为心里知道，这么做是对的。
