# ('应届毕业生创业困境：坚持还是转向稳定工作？', (2, 23))

有一位今年的应届毕业生，刚踏出校门就加入了龙哥盟，航海也跟了，创业也试了，可半年过去，拿得出手的成果寥寥无几。他纠结的是：要不要把创业这条路继续走到底，还是先找份稳定工作，攒点钱和经历？龙哥的回答没有半点含糊：先去上班，先把自己养活，先把资金池建起来——那个标准是，哪怕连续 24 个月完全没有收入，你也照样能吃好睡好，心里不慌。

上班之外的时间，别浪费。副业可以不断试错，精华帖值得反复琢磨，风向标记得天天刷，实战机会主动去抓，航海任务一步步跟完。所有这些，都是在帮你攒认知、攒体感、攒技能，为未来铺路。

创业也好，副业也罢，本质上都是长期战役，别让自己扛着炸药包上战场。故事里那些背水一战最后翻盘的人确实存在，但现实是，90% 背着炸弹硬闯的人，最后都被炸得粉身碎骨。你越急着变现，钱越躲着你走；你越沉得住气，想着认真替用户解决问题，愿意把时间拉长来看，反而更容易赚到钱。

所以，别急着跟过去告别。先找份工作稳住基本盘，再在业余时间悄悄生长。等哪天副业真的长成了坚实支柱，再考虑放手一搏也不迟。先活下来，才有资格谈星辰大海。
