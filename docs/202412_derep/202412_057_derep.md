# 00 后如何借助前辈“开天眼”

你有没有想过，一个00后，凭着一股冲劲，就敢跑去另一个城市拜访行业前辈？

最近，秋秋桂就干了这么一件事——12月23日专程跑到武汉，找到了张昭老师。这趟“追星”之旅，不是为了合影，而是为了给自己的人生装上“导航”。

看完她的分享，我最大的感触是：链接前辈，不是碰运气，而是一套可以设计的方法。

她复盘了整场拜访的要点：怎么才能见到张昭老师、见面前要做哪些功课、拜访中的细节如何拿捏、职业规划分哪三个阶段，以及“选择”这件事到底有多重要。

其中让我特别有共鸣的一点，是关于城市的取舍。很多人毕业后选城市，靠的是直觉或随大流。但她的经验是：先想清楚自己的职业方向，再倒推适合的城市。顺序一旦反了，选择就会变形。

这背后，真正拉开差距的其实是执行力。评论区里有人说她“执行力max”，一点不假。很多人也渴望被贵人点拨，却连第一步都不敢迈出去。而秋秋桂，已经在路上，并且把全过程复盘成了干货。

如果你也想提升认知、规划路径，却不知道怎么走近那些高能前辈，她的这篇经历值得一看。

方向不是等出来的，是问出来的、闯出来的。
