# 一、怎样拿到网盘拉新的官方授权？

想做网盘拉新，第一步必须是获得授权，否则一切白搭。

目前市面上主流的百度网盘、夸克网盘、迅雷云盘，授权方式其实很简单——扫码注册就行。

![](img/4071acaeef5f8ceb761b1121cd7841ba.png)

## （一）夸克网盘授权流程

注册小程序后，点击“申请推广”，把链接复制出来。

![](img/abd24a97a2b6fcaa5303e10a59ae96e2.png)

用浏览器打开链接，系统会自动跳转到夸克APP。接着复制你的ID，选择渠道5002，然后点击绑定。如果手机号已经绑过其他渠道，换个号码或者解绑重新操作就行。

绑定完成后就可以直接推广了，但千万别碰色情、暴力这类违规内容。

![](img/843d2c2b15f346cfbcb42ce8e809c29f.png)

看到上图这个界面，就说明绑定成功了。之后把夸克链接分享出去就行。

别忘了回小程序填写信息，等待审核（周末不审核）。审核通过后，1到2天内会送你15天会员和20T空间。记得在小程序里填“申请推广”哦。

![](img/2a83ca364e2613f7320fc761ba60450c.png)

结算方式是周结，t+2出数据，周六日不算。后面还有额外福利：更多会员时长、更多空间，甚至可以拿到一年会员！在“我的申请”里能看到审核状态，一般工作日1到3天就能通过。

![](img/d217688de844eaa1cd11108a142fce62.png)

![](img/92c51e17774a939c3c59ad048b198022.png)

# 三、怎么发布资源，吸引大家转存和下载？

## （一）自己琢磨的方法

只要是别人需要的东西，都能拿来当网盘拉新素材。

比如《黑神话悟空》爆火那阵，可以分享壁纸、攻略。再比如国庆节，大家需要旅游攻略，那就发全国旅游攻略。

市面上热门的APP，也都能用来做网盘拉新。你可以搜“夸克”“迅雷”“pan.xunlei.com”“pan.quark.cn”这些关键词，看看目标网站和APP上最近有没有人发相关内容。如果有近期发布的文章或视频，而且没被封号，那你就可以试着发。如果近期根本没人发，那就不用白费力气了。

![](img/103ca1e9f00bda2e67f6cd3f866d25ab.png)

举个例子，我看到XX楼里有帖子留着网盘链接，但都是半年前发的。我也跟着发了2篇带链接的文章，结果链接第一时间被删，但文章还在。还有XX值得买上的帖子，有的发出去大家看得见，有的发出去别人看不见，而且站方也不提醒你。

## （二）我推荐的“每天1分钟”发布法

### 1、发公众号

文章写完后，可以引导大家关注公众号、回复关键词来获取网盘链接；也可以直接在文里放网盘链接；或者把链接做成二维码再放进去。

![](img/f391adfffca3b48a527bd6905992383a.png)

#### 1）注册公众号

我用手机下载订阅号助手，微信登录后跟着提示走，不到十分钟就注册好了一个新公众号。一个微信能注册5个公众号，一个手机号就能注册一个未实名的公众号。

![](img/521cfa6e4b5a2b25e478cc75df64ae8e.png)

#### 2）用AI写长文

点击我做的豆包智能体（https://doubao.com/bot/cC3so23u），输入你想写的内容，比如“帮我写一篇植物大战僵尸的游戏介绍文章”。生成的文字稍微改改就能用，效果如下图。

![](img/4568504f901a7689e778b8641e71e3d0.png)

#### 3）把网盘链接变成二维码

打开微信，搜“二维码生成器”小程序，进去后输入网盘链接，注意别加任何文字，点击生成二维码，再保存到相册。然后自己先扫码测试一下，看能不能直接用微信扫一扫打开网盘内容。确认没问题再发出去。文章结构一般是“长文+二维码”或“二维码+长文”。

![](img/59ade7c98da3445ef938e7155e57942a.png)

### 2、发A站

下载A站后注册账号，点击“我的”→“发布”→“文章”。注意不是什么内容都能发，最好找没有版权争议的素材。也可以先看看同平台博主发了什么，做个基本判断后再跟着发，万一违规就及时删除。

![](img/0704030c20e56335d35b31243dad11f7.png)

### 3、发今日头条，引流到QQ群

在今日头条发微头条，把网盘链接放在文章里，网盘内再放QQ群二维码，然后每天在QQ群里更新资源。具体操作：下载今日头条、注册账号，点击“我的”→“创作中心”→“发布”→“微头条”，输入内容和网盘链接，配上图片，发布即可。

![](img/561529976970532c42af28774f89fd44.png)

QQ群主要用来发布网盘资源汇总表，以及热门资源的独立网盘链接。

![](img/94ad9ed4ad6e123799a54766d80cdf8b.png)

### 4、发微博

下载微博后，用发文功能先写长文，在末尾加上网盘链接；或者反过来，先放链接再写长文。长文的写法，参考前面公众号部分就行。

### （三）新人到底怎么上手？

#### 1、盯紧今日热榜

https://tophub.today/

哪个热点能整理成资源放进网盘，就发哪个。

#### 2、看别人在发什么

比如你想发公众号，直接打开搜一搜，输入pan.quark.cn或pan.xunlei.com，点“文章”，再点“最新”，看看最近有没有人发。

![](img/3ad93c89b80be88dc3b7b52a9b905813.png)

如果某个平台近期已经没人发网盘链接了，大概率是平台不允许了，所以才看不到。发资源时，一定要认准无版权或弱版权的素材。
