# ('100 阅读变现 20 万，拆解 10 个公众号类型，带你了解公众号变现多样性', (2, 41))

阅读不过百却能赚20万？拆了10类公众号，才看懂真正闷声发大财的账号

你可能很难相信，有些公众号，每篇推文只有几十个人看，三个月却能默默赚进20万。

老罗做公众号已经8年，从2017年一直折腾到现在。他最近的感受是：公众号接入系统推荐之后，玩法早就变了。但遗憾的是，大家聊来聊去还是“流量主”，好像除了靠阅读量吃平台广告费，公众号就没有别的赚钱方式了。

所以老罗专门花了两周多的时间，挑了10个很有代表性的“非流量主”变现账号来做拆解。从起号时间、平均阅读、平均转发、真实变现金额，到内容类型、标题风格、内容结构、运营难点、素材来源，一共9个维度全部拉出来分析了一遍。

拆完之后你会发现，阅读量绝对不是衡量公众号赚钱能力的唯一标准。有些账号内容看起来并没有多复杂，却一直走高价路线，靠一单顶十单的方式轻松变现；另一些账号阅读数字毫不起眼，但实际到手的收益远超你的想象。
