# ('学习ComfyUI，从完全不懂到顺利做出满意图片的学习心得 2024.11.24', (2, 42))

2024年11月底，我完成了人生中第一次“硬核”技术类学习——ComfyUI。从一个看参数像看天书的小白，到最终能做出让自己满意的图，中间确实有蛮多话想说。如果你也是刚接触AI绘画、还在犹豫要不要上手的普通人，希望这篇心得能给你一些参考。

先说说我的情况：我叫Tian，之前做品牌媒介，主要对接抖音和小红书的博主。现在裸辞，做ComfyUI相关的AI绘画项目，算是一个正在探索下一段路的自由人。加入赚钱将近一年，星球的很多内容其实没怎么看过，只参加过一次线下活动。但说实话，199块的课程能做到不割韭菜、干货密度高，确实难得——这也让我理解了为什么那么多会员愿意持续续费。

当初选ComfyUI，一方面觉得它踩在了时代节奏上（之前也感受过ChatGPT带来的情绪价值），另一方面AI在电商领域的应用太广了，像remove background这类AI修图工具，还有极睿科技这种靠AI做业务扩张的公司，都是明证。对当时的我来说，离职后游荡了几个月，最需要的其实是秩序感——跟着一个项目走，正好能给2024年最后一个月一个稳定的锚点。

至于目标，很朴素：想真正上手一个AI实操软件，掌握电商图片和视频的AI替换操作。现在的成绩单是：完整跟完了课程，过程中遇到过几次好事，但实话讲，还没真正落地应用，底层知识也不够扎实，正在回顾和复盘中。

下面我从四个维度展开聊聊。

**一、从满腔热血到被挫败感淹没，再到重新支棱起来**

刚开始那几天，我简直动力爆棚。面对全新事物，好奇心拉满，虽然啥都不懂，但就是有一种“我来试试”的莽劲。更重要的是，第一天写完日志就收到了点评，那种正向反馈太爽了，瞬间觉得这项目也没那么难，还挺有意思的。

不过好景不长，课程一进阶，满屏密密麻麻的英文参数直接把我打懵。这个节点是干嘛的？那个数值调成多少？我折腾来折腾去，出的图就是不对味。学习时间也从一开始的2小时暴涨到4-5小时，有时候耗了一晚上，图还是不能看，那种挫败感真的是会把人淹没的。

后来怎么走出来的？其实特别简单——学累了就休息，脑子不转了就出去浪一天，听了一节思维课的能量鸡血，回血到八成，再继续干。最后两节课我拆得特别细：先只用一个lora做，再用多个lora叠加，一步步来。果然，拆解之后难度降下来了，虽然时间没少花。最终一天生成的图，离“优质”就差那么一点点，我已经相当满意，又开心起来了——知足常乐嘛。

一个特别大的体会：**一定要跟着航海线走**。最早看到时间线时，我还觉得一个阶段配1-3天是不是太拖了？直到自己实操才发现——真的高估自己了，那个时间线科学得很。

**二、跟上偏技术型航海的四条心得**

1. **直播一定得听。** 我自己更喜欢第二天倍速回看，毕竟看剧开倍速习惯了。但教练实操教学比自己闷头钻研效率高太多，还能听到大量扩展内容。更重要的是，他们能在高处点醒你——比如那句话“liblib只是实操工具，不用每个参数都懂，先用起来”，直接把我从“必须逐个弄懂英文”的执念里解放出来。能量课也一样重要，面对新鲜事物时，坚持本身就是最难的部分。

2. **定期看排行榜，感受大佬的碾压。** 排名TOP的选手，要么长期主义和执行力都拉满，在学习中还能沉淀新idea；要么在工具之外的实操变现上一骑绝尘，甚至两者兼有。我特别想听学员林育佳（赚钱账号“船长”）的分享，感觉他是那种有极强目标感的人，为了结果去学，而且用得超赞。还有连续打卡19天的长跑型选手，那种持续的力量真的像水滴石穿。

3. **别瞎想别跑偏，先跟着做。** 我自己就有个大bug：不能持续打卡（全靠志愿者吉果小姐姐提醒），还老想“还没学会走就想跑”——中间有一阵子去看AI出图后的小生意，光看不做，导致课程进度落下、基础没打牢。后来想明白了，先把脑子里乱七八糟的清空，一件事一件事执行。

4. **最低要求动起来，不追求完美。** 一天完成一个课程就够了，达成50%或60%也算赢。不贪多，如果学了好几个小时还没搞懂，大概率是脑子已经不转了，第二天再说。反正有航海线兜底，偏不到哪儿去。群里很多人折腾本地版，我又懒又不擅长电脑，随缘吧——在线版能用就行，真要我去搞下载，估计还没开始血就没了。

5. **不上难度。** 对liblib这种工具，我只求优化调试，不求搭建工作流。复杂工作流还是交给大佬们吧（偏程序员方向的人更合适）。

**三、接下来怎么打算？**

初期想在liblib上做卡通版或艺术版图片（可以找现成工作流，甚至在线生图），做成冰箱贴装饰冰箱，或者贴纸贴衣柜。后期再尝试探索自己的图片生意方向。不过实话讲，图片一致性这块，感觉只有本地版才能解决，自己做IP可能够呛——如果有学员做过成功的，求分享，真心想听。

另外想说一句：赚钱的思维课什么时候再开？想听+NNN！

**四、AI出图后还能做什么？**（我从小红书看到的方向）

- 线上AI图片账号：结合平台调性出图，比如小红书上手工类流量挺好。还有AI设计生图IP类、商用素材售卖、把静态照片变live图、让博物馆文物跳舞、甚至让小朋友的画动起来。
- 线上绘本：强故事性和寓意，不一定都是单一人物；国外更高级的绘本也值得关注。
- 积极IP类：核心是IP人物的一致性。
- 个性化定制很火：人和宠物都行，像给猫狗画各种奇葩角度（非可爱类），或者根据宠物照片定制18K金项链（设计费500+，制作费另算）。这方向连赚钱内部员工或星球周边都可以做。
- 线上热点流量视频：从手绘过程变成AI生图，视频发布时间效率能提升一大截。
- 插画类、贴纸/亚克力冰箱贴/热缩片：手帐圈和冰箱贴需求都不小，常规方形款和特殊图案款都需要（后者要小模具）。
- 微信表情包：本质上是贴纸IP的动态版。
- 如果你自己本来就有“树生枝干”的账号，像“莞迪Lydia”那样，给自己的博客配图也是可持续的路子。

**最后，絮絮叨叨几句**

每个人的背景不同，学AI的方式也完全不一样。我有个粗浅感觉（可能不太对）：设计出身的人，图片风格和美学底子好；程序员出身的人，操作页面对他们像代码一样顺滑，后期还能做优质工作流，进阶空间更大；电商/平台流量背景的人，商业思维和变现能力往往更强。所以，你是把AI绘画当“树的装饰”（增加技能），还是当“树生枝的关节点”（变成副业变现），路径完全不同。

世界确实是个巨大的草台班子，但每个人草台的级别还是不一样。永远向牛人学习，respect。
