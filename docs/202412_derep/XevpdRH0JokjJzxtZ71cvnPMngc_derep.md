# 二、先把功能想清楚

为了让零基础的朋友也能快速跟上，我把这个海报生成器的功能控制得很简单，只保留两个核心页面：

1、首页：核心的海报生成操作区
2、我的：用来存放和回看历史生成记录

这两个页面的交互逻辑后续会用 Coze 的工作流来驱动，今天我们只聚焦在界面搭建上。

# 三、手机端 UI 如何从零搭建

应用创建完成后，就要开始设计界面了。

## 1、选择搭建入口

在应用工作台点击顶部“用户界面”，选择“小程序和 H5”模式，然后点击“开始搭建”

![](img/51e4321a1b0df0f00121aa0a89f0a5db.png)

## 2、搭建首页：海报生成页

### ①、先放一个表单组件，用于接收用户输入

![](img/248ce1bd6bb3c83c49eb1cacc016d9f7.png)

### ②、调整表单内容

我的设计思路很朴素：用户输入一个 24 节气的名字，再补充一些图像风格要求，点击生成按钮后就出海报。调整后的表单示意如下：

![](img/966871d3f585661e958385715565e94c.png)

修改方式很直观，点击页面元素右侧就会弹出属性面板，基本一看就能操作，这里就不展开赘述了。

### ③、预留图片展示区域

生成结果需要一个地方能预览，我直接在表单下方插入一个图片组件，暂时不做复杂的层级隐藏。

![](img/892cabb4b40c0cc3f555fb2f2a9390c2.png)

因为目标是手机壁纸，所以把图片比例调整为 9:16

![](img/10eb03da47185321606231f9357f8818.png)

到这里，首页的骨架就算搭好了。有人可能会注意到，页面初始状态图片是空的，看起来有点怪。没关系，后续做逻辑时我们会控制图片的显示时机，现在先保留。

## 3、搭建“我的”页面：历史记录展示

生成好的海报最好能存下来方便以后查看，所以我们需要一个历史记录页。

### ①、新建页面

点击底部新建页面的按钮，新建一个并命名为“我的”

![](img/6f81d7f367e80bf48dcc665efd244539.png)

![](img/b01e43fa484ef44ea917eefa25da6afa.png)

### ②、把底部菜单和页面关联起来

打开底部导航栏，将“我的”菜单项绑定到刚刚新建的页面

![](img/10a93826bdf571480c39d2e01e7fdb23.png)

注意，首页对应的菜单项也要同步设置好，否则切换会异常。设置完后点一下预览，检查菜单是否能正常跳转。

### ③、放置一个纵向列表组件

用来滚动展示历史海报

![](img/7eb4d214724a20ad79d5b111b7efe539.png)

### ④、完善列表项的标题和时间

我希望的呈现形式是：图片在上，下面一行展示节气名称和生成时间，最终效果参考如下：

![](img/9e4264e2fe5b730be65ce59e0e8e231a.png)

要实现这种布局，就得用到“容器”组件，它是灵活排版的关键。我在列表内容下方插入一个容器，并复制到每一项。

![](img/5477855dfdb619cc7511b1a4c6d1cb68.png)

然后把标题组件拖拽进容器里，位置马上就变了：

![](img/e7b2a5d0172d409c519cf80284f6a3d4.png)

时间也需要展示，再拖一个文本组件进来

![](img/d14051a14b2fadbc26912ad8159a5952.png)

这时候排版看起来有点拥挤，我点进控件位置设置，把高度改为“适应内容”，排列方向改成“横向”，内边距调为 0，效果立刻顺眼很多，可以自己多试试参数。

![](img/d25703f38f8b5f6a926ee19b70568048.png)

![](img/8e03237c2bedb99fe7533551848538e6.png)

调整完后页面就变成这样了：

![](img/7274c5f2156613846c3059bd2a1d6907.png)
