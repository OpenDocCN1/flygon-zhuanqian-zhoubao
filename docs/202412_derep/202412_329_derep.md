# ('新人的同城发售航海复盘', (2, 13))

**小白也能上手的同城发售：一个程序员的真实复盘**

大家好，我是车夫子。好久没跟大家见面啦！

上个月，我以纯小白的身份参加了一场同城发售。说起来有点不好意思——我这人从来没做过销售，性格也偏内向，只是偶尔冒点外向因子。作为程序员，平时面对代码比面对人容易多了，但这次还是硬着头皮上了。

如果你也是没经验、有点胆怯的小白，那这篇文章就是写给你看的。我不会堆华丽词藻，也没什么惊天动地的方法论，只想把自己这一路的真实感受讲出来。不求多有用，只希望能给同行路上的你一点鼓励和陪伴。

这篇复盘我写了差不多三千字，也是我头一回码这么长的文字。说实话，写的时候心里特别没底，反复担心内容是否对别人有价值、算不算“利他”。但后来想明白一件事：与其在原地纠结，不如先勇敢迈出这一步。写不好也没关系，总得允许自己成长。

如果你觉得我的分享还算真诚，就点个赞让我知道吧，这会是我继续输出的动力，提前谢过！
