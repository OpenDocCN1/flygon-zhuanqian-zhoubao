# 盲目乐观促成与大佬的深度对话与机会复盘

你有没有想过，一个被大佬直接拉黑的人，居然还能靠着一股“盲目的乐观”翻盘，甚至换来一次深度对谈和清晰的方向？

今天想分享的，就是这样一个真实故事。

事情要从去年12月说起。那时候我刚加入赚钱没多久，偶然读到安七的一篇文章，认识了创业制片人张昭老师。当时张哥正在寻找合适的合作伙伴，我觉得自己或许可以争取一下，便主动链接了他。

起初沟通还算顺利，张哥让我准备一份项目资料。我花了整整10天精心打磨，但全程没有跟对方同步过任何进度。现在回头看，这是第一个大坑——我亲手把机会晾在了一边。

等我再联系时，张哥很直接：我的行为不符合他的人才筛选标准，然后删除了我。

说实话，那一刻很懵，也很难受。但我没有选择沉默，而是打了一通致歉电话，第二天直接坐车赶到武汉，争取到了一个面对面聊天的机会。我们讨论了足足两个半小时，过程并不轻松，张哥一度觉得我根本不适合走创业这条路。但因为我一直没放弃，不断地追问和碰撞，他最后说了一句让我愣住了的话：

“你的盲目乐观，已经变成了肌肉反应，这确实是个奇葩特质。”

然后，一个商业构想慢慢成型了——在经济下行、人人焦虑的时候，大家太需要一个情绪支撑点和能量补给站，就像深夜食堂给人慰藉那样。前端做账号引流，后端为不同的人提供对应的服务。而我的任务，就是把账号搭起来，把品选好。

一下就想通了。我过去做的项目和解压相关，在家人朋友眼里又像个“小太阳”，大家总说我身上能看到希望。原来这一切，都能串成一条线。

但收获远不止方向本身。更多的，是几个扎心的认知颠覆。

**第一，你真的认识自己吗？**

我以前觉得自己温柔包容、积极向上，同时也胆小、愚钝。但这只是表面标签。张哥连问三个问题：你不可或缺的价值是什么？你能拿出来和别人竞争的是什么？你为什么没有成功？

我答：我有自媒体经验。他说：你没做成功，失败经验只会延续失败，复盘事件意义不大。

我以为声音好听、有亲和力是优势。他说：样本太少，属性不强，别人短时间内感受不到。

那一刻我才明白，我对自己的认知只是“我以为”，并没有真正深挖到本质。

要更客观地看见自己，可以从三个途径入手：多列问题认真回答，借助优势测评工具（盖洛普这种，大厂HR都在用），再就是找比你高维的人或刚认识的人做镜子——前者能看透本质，后者能放大直觉感受。

**第二，弱者心态怎么破？**

张哥问我感情计划，我说35岁结婚生子。他立刻点出：为什么要给自己设置这条红线？这只会缩小选择权。

我反思才发现，我准备资料时也有一种“反正他这么厉害，看完肯定能发现问题”的心理。这其实是对外界的过度依赖，也是变相给自己找退路。

在优势方向上，我们不是越筛越窄，而是拿到一个合适的商业环境里不断放大。限制越多，确定性越小。

**第三，如何少踩坑？**

张哥给我分享了两个小故事。一个是约会时间，他提醒我留足余量，我嘴上答应，却还是下意识选了最早的时间，结果火车晚点，差点出丑。另一个细节是写这篇复盘时，我第一版写成了一个“被拉黑又逆袭”的故事，感觉不对但说不出来。张哥看了只说两句话：“你不是写小说，你要输出对圈友有价值的东西。”

这两件事都指向同一个词：潜意识。你以为是自己做的决定，其实是固有程序在操控。

他还有一句特别醒脑的话：“我们永远都有得选，只是不同的选择对应不同的价格。”很多人喜欢说“我没有退路”，但扪心自问，你真的把所有方法试遍了吗？大多时候，只是自我感动罢了。

回头看我这一路，从被删除到见面，从被否定到获得指引，中间确实有很多动作变形的地方。但这也是一次真实的压力测试。面对压力，我学会给自己三步：先接纳情绪，再想办法补救，最后找回理智。

我还学会了一些实用的小技巧：想象勇敢向前后能获得的改变；提前做功课，了解对方也准备好自己能提供的价值；从线下小活动开始练习连接，慢慢克服恐惧。

这次经历让我最感慨的一点是：如果你连自己都不了解，别人怎么帮你？而当你真正开始向内探索，很多答案就会逐渐浮现。

感谢张哥，也感谢那个没有放弃的自己。道理我已经写下来了，但距离真正活出自己的模式，还有很长的路要走。

保持敬畏，持续追问，内观外修，然后把自己收获到的，再给出去。

共勉。
