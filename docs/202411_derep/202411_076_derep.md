# 把心里的那点火，变成照亮自己的火把

作者：张不高 

先自我介绍一下，我现在的目标是赚到100万，到时候就把名字改成张高高。2024年4月，我踏进了生财，先后试了两条路：小红书做欧洲旅行推广，以及公众号做爆文，操作不到20天，两个方向都先拿到了1000到2000元的现金回馈。

说实话，我以前的履历很普通，是体制内混了快18年的边缘人。做过私房、做过微电，也没蹚出什么水花。越努力越迷茫，越迷茫越自卑，卡在那种想改变却找不到抓手的状态里。

转机来自一次和杨涛的聊天。他随口一句“赚两万，对我来说跟呼吸一样简单”，这句话像点燃火柴一样，把我心里压抑很久的渴望点着了。我就入群开始试。

在生财里，我先选了小红书旅游，后来又上了公众号爆文。这两个项目我都按手册把能做到的部分做到八成左右。短短20天左右，确实到账了那一千来块钱。对别人来说可能不算什么，但对当时的我来说，看到钱进账的那一刻眼眶都热了。那不只是收入，是我第一次有实证告诉自己：我也能行。

我为什么更留恋公众号这条路？很现实的体感。那是我能接受的节奏：时间地点都由自己定，起步门槛不高，而且是纯粹的内容输出，不需要像做销售那样一直在线回客，特别适合我这种内向的人。我当时就想，先把这项能力练出来，它是我换取自由生活的钥匙。

理想很高，落地很糙。第一天我调设备、搭环境就花了12个小时，用写了将近20年文案的手码出第一篇，结果3个阅读。我第三天才拿到人生中第一笔公众号分红，1分钱。我兴冲冲发到朋友圈，被人笑了一句。那瞬间我明白了，不能让一句嘲讽把刚冒头的火星吹灭。

于是我开始给自己加柴。每天跟自己说“好呀，今天从零到0.01了”“今天是十倍了”。卡住的时候就去“借柴”，教练、领队和志愿者都给了我很具体的反馈。日更坚持下来，收益曲线从1分、1毛、1块，慢慢爬到日均一百、二百、三百。整整一个月，我把每天的收入和感悟都晒在朋友圈，一口气连更30天，最后结算下来是2037元。

做流量的过程中我也曾怀疑。后台骂我乱写、胡说，每天改爆款模板，赚钱之外我找不到意义。后来和一个中医世家的朋友聊，她很遗憾地说网上一个医学错误观点拿了上万点赞，她却想把真正有用的健康常识免费送给普通人。那一刻我顿悟了：我的流量能力可以当成一座桥，把正确的信息送出去，用好的内容把坏的内容挤走。

更深一层，我意识到经济整体下行时，很多人像我一样迷茫。我从零到一的笨拙记录，对我自己是信心，对别人可能是希望。那个小小的火苗，已经慢慢变成一支能照见路的小火把。

我也越来越清楚，赚钱的本质是利他。当我能为别人提供价值时，选择权才真正回到我手里，自由的生活方式才有可能。

最后想谢谢生财这个环境。谢谢教练的细致点评，领队每天花式催打卡，志愿者琥珀给我的1V1辅导，还有航海群里一起提问、一起打卡的小伙伴们。也谢谢澄歌给我这次分享的机会，以及杨涛、珍妮子、梅子等大佬一直以来的支持。

我相信在场的每个人心里都有一团火。把它点亮、护住、再放大，我们就能一起举着火把奔跑，做点真正有价值、能帮到人的事。
