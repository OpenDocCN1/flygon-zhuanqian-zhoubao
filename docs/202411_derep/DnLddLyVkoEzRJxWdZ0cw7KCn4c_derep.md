# 合肥两日学习转化复盘｜森林



# 开场白

各位同城做实体发售的伙伴们，大家好，我是来自宣城战队的森林。

11月9号，我跟着孔老师到了合肥青禾艺术，专门学习转化端的实操。

短短两天一夜，收获很大，也对我们现在在做的事有了更立体的认知。

复盘对我来说是沉淀的最好方式，今天花了两个小时整理出来，大概三千字左右。

下面我以一个新手的视角，从自己的体感出发，分成转化端、商务端、项目认知三块来聊聊，供大家参考，有不到位的地方欢迎指正。

文字总有局限，读的时候有疑问随时私聊我，我们一起交流进步。

# 一、转化端

第一天我全程观摩了孔老师给一家教培机构做的内训，整场大概四小时。

这场课不只是给老师和校长，参与学习的圈友也都在现场当学员。因为后期交付时，这些细节都要我们自己去落地执行。

**1）控场要强**

作为外部来的转化导师，面对一屋子陌生的老师，要在短时间内把所有人的注意力拽过来，跟着你的节奏走，这本身就是一门手艺。

孔老师在开场前就在活动群里先发了个小红包。一个动作三重用意：先示好拉近距离，再把注意力引到群里，最后让还没进群的老师为了领红包主动进来，后续发通知才能全部覆盖到。

培训中他会不断地去确认：老师们，听懂了吗？这样既能确保大家跟上，也能把走神的人及时叫回来。

**2）专业要硬**

转化端是给校方证明活动效果的核心环节。我们自己首先要把整个流程吃透。

孔老师讲得非常颗粒化，比如给学生家长倒水时要放茶叶，水温最好在80度以上。目的很简单，让家长多停留一会儿。

校方老师现场提问，我们能不能答得上；教学环节的表达清不清楚、对方能不能听懂，这都是专业的体现。

**3）细节必须盯死**

第二天我被分配到青禾艺术驻店实操。前一天晚上已经按孔老师的方式指导校区布置了场地，但现场还是出了问题。

第一，场地执行不到位。洽谈区我已经定好，校方嘴上答应配合，实际还是让孩子在洽谈区做DIY。结果我们只能拉到大厅谈。大厅人多嘈杂、孩子乱跑，谈话随时被打断，成交率自然跌下去。有些话题在大厅里也不方便聊，家长本身就不想谈。场地真的决定成败。

第二，测评表没用。早上我明确交代做测评要用我们的表，老师没放在心上。这个疏忽在后期的谈单里暴露出来。无体验转化，家长不会立刻买单，大多要等体验课后。体验课时，家长只看到孩子写了几个字，很难被打动。但我们的测评表很细，能呈现孩子的思维和想法。最后那两个家长也只是交了定金保活动价。

第三，校方销售能力薄弱。课销根本不懂销售，作为驻店导师必须扛起来把控全局。

上午来了一个不想报正价课的家长，课销一句就把人晾在一边。我上前继续聊孩子，发现家长其实很愿意让孩子学艺术，只是现在在试探到底喜欢画画还是口才。我顺势把活动优惠讲清楚，强调哪里都是这个价格，帮他们做了定金锁定，避免被别人抢单。

下午我帮课销同时带两个家长谈。家长拿计算器算单价，把课销算懵了，完全被家长牵着走。我及时介入，把话题拉回学校优势和名额即将满员的紧迫感，制造焦虑感。最后校长过来，也只是进入了讨价还价，最后也只收了定金。

所以驻店前一定要把所有细节和校方对齐，必须亲眼看到做到位才能安心。转化做完后我才明白，会商务不代表会交付，但会交付之后，商务基本能轻松拿下。因为交付需要控场、沟通、销售、协调、管理等多重能力，而商务只需要销售这一项。

这次学习让我更坚定要学商务，因为商务本身就是交付的重要一环，不会销售，转化端会非常吃力。

# 二、商务端

了解了转化逻辑后，反过来看商务会更清晰。

我和队友易芝在跑市场时，对教培机构的认知还很浅。这次实操后，我对他们的真实想法有了新的判断。

**1）转化率的认知差**

和校长聊天时他说，现在招生能做到15%转化率已经很厉害了。而我们的宣传能做到30%以上，对机构来说吸引力非常大。

转化率高低也和校方执行力强相关。有些校区说自己也做过类似活动，没效果，大多是照猫画虎，没理解动作背后的逻辑。我们既然清楚逻辑，执行起来就会更坚决。认真做和随便做，动作表面一样，结果天差地别。

**2）成交量的基数问题**

当天大的机构一共才70人买课包，其中一半是老生，老生很多最后不会续费，实际新生只剩30多个。从这个基数看，想成交15个人，除非全是精准客户，否则很难。

由此可以推断，提升转化必须先保证量。按保守5%的成交率估算，起码要跑100家才有机会成交5家。多跑是唯一的解法。

**3）销售能力是核心**

驻店让我深刻体会到，转化率背后是销售力。如何破冰、如何快速建立信任、如何挖出潜在需求、什么时候切入成交、如何提高成交率，都是关键。

很多家长对机构和教学质量不信任，会问：交了钱会不会跑路？教学质量如何？能不能达到预期？

课销的回答让家长很不满意。如果是我，我会换个角度说：我们公司现在在积极向上发展，近1000多名学生，近80位老师，体量摆在这里，我们会想着跑路吗？

面对质疑，直面回答效果差，反问和用事实反推更有效。打铁还需自身硬，销售能力需要长期学习、练习、实战和内化。

# 三、对项目的认知

对项目的理解越深，执行力越稳。这次两天下来，我对项目又有了三个更清晰的判断。

**第一，可行性非常强。** 市场需求量大。跟校区沟通时发现，他们就算不赚钱也要做这个活动，因为宣传是刚需。项目本质是三方共赢：家长拿到低价课，学校获得曝光，我们赚到钱。

**第二，口碑决定复购。** 每做一家机构，就是一次对外宣传。做得好是正面口碑，做不好也会留下负面印象。这次转化还有不足，和我个人熟练度有关。口碑会决定对方下一次是否还找你，所以一定要重视。

**第三，我们的优势很明显。** 报价上横向对比很少见，我跑了这么多家，只有这一家用这个价格做活动，其他都是先收钱。服务上我们做前端引流也做后端交付，市场上大多数团队只做前半段。流程上细节把握到位，洽谈区、停留区、礼品区各司其职。之前校方只会在大厅随便聊聊，从没想过这么细的布局。

复盘到这里结束。项目执行中问题总会不断出现，但问题本身也是机会，能把别人做不到的细节做好，就是我们的突破口。
