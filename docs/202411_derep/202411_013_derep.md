# 最晚开单，却冲上总榜第二：同城夜校线下航海，我们靠“笨功夫”翻盘

大家好，我是阿钦。现在正跟着天盈教练跑同城夜校项目，还有幸拉上了奶油、咪咪、小埋三位超靠谱的合伙人一起干。

说说我的背景吧。2023 年我加入赚钱，那时候做境外游项目，顺手把小红书的那套运营逻辑摸了个遍。后来又陆续参加了好几期线上航海，公众号爆文、闲鱼二手机、AI 代写这些基本都碰过。

今年 10 月，很幸运被选进同城夜校项目。说实话，等录取通知那阵子，我天天晚上睡不踏实，总担心哪句话说得不对，名额就这么飞了。

真到实操阶段，我们厦门四人组一开始其实是教练眼里的“重点担心对象”。但谁也没想到，最后总业绩居然做到了整个航海的第二名。我们真不是那种天赋型选手，靠的纯粹是别人休息我们补课、别人犹豫我们硬干的那股劲儿。
