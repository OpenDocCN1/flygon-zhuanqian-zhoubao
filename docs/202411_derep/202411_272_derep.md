# YouTube Shorts 悄悄起风：小团队的两周年心得与机遇

谁能想到，踏踏实实做了两年 YouTube Shorts 的小作坊，突然有种“被看见”的感觉？今天刷到龙哥大佬的超级标，本来忙得脚不沾地的我，瞬间坐直了。兴奋的是，这条路上终于不再只有自己；担心的是，怕太多人冲进来，把那点红利挤爆。

过去一年，Shorts 确实没什么存在感，大家聊的都是 TikTok 中视频。可今年风向明显变了——单价最有说服力，从早先的 0.08rpm 一路涨到 0.3rpm，这可不是小打小闹的涨幅。说起来也是运气，去年 TikTok 中视频没让我赚到钱，今年转身做 Shorts，反而接住了一波红利。

我们组目前的盘子是 600 个频道，真正跑出收益的只有 20 来个，主打匿名、不露脸。赛道也很聚焦：解说、AI、萌宠。做内容离不开对标研究，以前我都是手动去刷手机、整理对标，效率低到崩溃。今天早上看到江鲤大佬分享的 RPA 自动化采集，真的眼前一亮——原来还可以通过标签持续扩展、去重，这我之前完全没想到。要是早点看到，月初就不用花大把时间折腾代码了。

工具方面，江鲤大佬用的是影刀 RPA，我自己用的是 selenium。说实话，selenium 用起来有点痛苦，要对接指纹浏览器、找定位元素。不过因为我每天采集量不大，只盯筛选后的对标，后来换成了 YouTube 官方 API。优点是省心方便，缺点嘛，就是一天只有一万次配额。但对采集量不大、想快速上手的新手来说，已经足够友好。

具体操作也很简单：输入频道名称（比如 @hublotbaggins），API 会自动把该频道所有视频的标题、发布时间、播放量拉出来，再按数据筛一遍，就能提取近期百万播放的视频链接和相关参数。

selenium 和 API 的调用方式，我后面都会整理出来。代码详解和官方 API 的调用指南，我已经放在这个文档里：[`https://yemahuyou.feishu.cn/docx/NQEYdXPWyoohmrxtaV2c4zQTnxh?from=from_copylink&reRdXZ;=1`](https://yemahuyou.feishu.cn/docx/NQEYdXPWyoohmrxtaV2c4zQTnxh?from=from_copylink&reRdXZ;=1)

顺便分享一点账号维护心得：我们用的是指纹浏览器，每个窗口独立 IP、各绑一个谷歌账号，600 个频道里能稳定变现的只有 20 个。有些账号生来权重就不行，不管怎么发，流量都起不来；连续测三天，如果还是零播放，内容本身又没问题的话，就直接弃号，集中精力养有潜力的号。

最后，真心希望能认识更多在做 YouTube 的朋友，欢迎来找我交流。代码分享在路上，记得留意更新。
