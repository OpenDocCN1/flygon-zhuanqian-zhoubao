# 13万“学费”换来的教训：别轻信电商代管公司

我从2020年开始做童装电商，2021年7月想扩大规模，就盘下了一家天猫店。店还没捂热，一个营销电话就打了进来，对方开口就点出我手上有童装天猫店，说他们也是这个类目的，可以交流经营心得。随后话题转向“麦叮当旗舰店”，称这家店就在湖州，是他们操盘的案例，合作之前几乎不赚钱，投放占比特别高，合作之后业绩成倍增长。

加上微信后，对方发来公司资料：成立超过六年，员工两百多人，其中技术人员占八成，大老板曾在阿里待过，属于2005至2011年间那批P7老员工，公司又被形容为杭州唯一的“纯阿里系”运营公司。技术、资源都被说成核心优势。

我追问如何测款、如何起量，对方说他们有自己的宝妈群和粉丝群，平时选品投票、补单、买家秀都靠这些资源完成，都是精准用户，能省下不少测试花费，也能让新品更快起量。

聊完这些，对方顺势邀请我到杭州公司实地感受一下，还说可以当面和他们的运营聊聊手头店铺的情况，了解完整的操盘思路。又发了一些群聊天记录，展示团队如何负责。

到了现场，公司划分成客服、运营、美工、洽谈几个区域。接待我的销售直接把我带到运营区，找到负责麦叮当店铺的运营，当面打开后台展示流量结构和近几个月生意参谋的销售报表，还特意刷新网页并上下滚动，证明数据是实时的，不是P出来的。

对方又讲了一遍起店思路：统一视觉，用同一模特实拍，让店铺更美观；多款商品同时测试，筛出潜力款后做数据递增、补单和投放；换季前提前布局，测好一批货，等季节到了顺势爆发。还提到一款小女孩连衣裙，背后有小翅膀，是结合热搜和爆款元素重新组合出来的独家款，市面上没有同类，12月直接打进单品销量榜。

他们的工位布局是一个小组五个人，负责一家店，配置是一名运营、两名运营助理、一名美工、一名美工助理。我前后聊了四组人，看了四家店，整体印象确实专业，讲的方法和我自己做店的经验也能对上。

于是我说想谈合作，销售却表示他们并非所有店都接，需要先和管理层沟通，确认客户实力。我在会议室等了一会儿，进来一位穿西装的男士，自称公司副总兼合伙人，原本端着银行的铁饭碗，辞职时家人反对，但坚持认可老板的理念，投钱入了股。他和我闲聊了将近一个小时，最后说自己也是江西赣州人，和我是老乡，觉得我合适，可以合作。管理层还要再开个会，然后让销售发合同给我。

第二天合同PDF发来，朋友提醒我看清条款、谨慎签字，可我当时太急于推进，虽然看了合同，却没有找对方仔细确认关键表述。合同里有一条大概写道：合作开始推广十五天后，乙方制定首期考核指标，双方协商一致后执行；如果没完成销售目标，甲方可以单方面终止协议或继续合作，且不用付违约金；如果完成目标，甲方不能单方面解约，必须继续合作。

我当时的理解是“不满就能随时退出”，后来才明白，这句话存在巨大漏洞：没有写明“未达标”由谁认定、依据什么数据、是否需要书面确认。

合作费用是每月两万元托管费，另加当月实际成交额4%的提成。我心想五个人分，每人底薪四千还有提成，应该会认真做，价格也能接受。没过多久，那位副总又来催款，说管理层在开年中会，让我早点打款，他好把项目在会里提一下，提高重视度。我听了就赶紧把钱转了。

7月17日，第一笔款项14万元进到对方账户。到账后，那边说公司内部要走流程，安排团队。可十几天过去都没人主动对接，我催了销售，才有一位综合管理部的人加我，说专门负责团队和店铺之间的协调。

7月28日正式启动，沟通都放在QQ群里进行。他们先制定了运营计划，包括选品、上款、基础销量、评价、测试等。我自己粗略算过成本：童装毛利通常在30%到40%之间，但我是去档口拿货的组货商，不是源头工厂，压缩不了成本。有些低价同行毛利只有15%，拿货价加十元就卖，快递每单三块多，还有运费险，一件衣服只赚几块钱，完全把淘宝当拼多多做。所以我直接在群里指出了销售额计划不合理的地方。

对方重新做了一份计划表，我核算后觉得按照这个执行，前期亏损能填回来，便同意继续。结果一个月不到，我就想喊停。对方运营的水平甚至不如我自己：投放计划乱开，一天烧一千多元，测试链接点击够了，收藏加购数据很差，还是不关计划继续烧钱。这还是在搭配“买四件免两件”活动的前提下，数据依然不行。首月直接亏掉两万多，还不算托管费。

8月投放花了1.9万元，成交额不到1.3万元，而且还是在活动期。眼看到了九九大促，我在群里提出意见，对方说要调整节奏，结果9月成绩照样惨淡。至此我已经彻底失去信心，两个月店铺损失4万，加上托管费用，实际亏了8万，日成交额还是只有几百元。

国庆期间我直接去杭州公司，要求终止合作并退款。他们把我带进会议室，来了一位所谓童装事业部负责人，也是合伙人之一。他先道歉，说前一个运营能力不行，耽误了我，又请求再给一个月，换个厉害的人重新做，靠双十一把损失赚回来。我居然又一次相信了。

新运营把主推方向从卫衣改成毛衣，说毛衣适用人群更广、款式不花哨，成功率更高。按他的节奏又做一个月，结果依旧是个坑，多亏了三万多。

11月1日，我正式提出解除合同、要求退款，对方只回了一句“开会商量”，之后便再无消息。

我开始意识到他们不会主动退钱，先去当地派出所咨询。民警表示这是经济纠纷，警方无法介入，建议我找律师走诉讼。律师看完合同后认为，那个“停止合作”的条款写得太模糊，两边都能解释，打官司不一定能赢，而且律师费6000元无论输赢都要由我承担。

那段时间我整夜睡不着，精神状态很差。钱里有一大部分是父母给的，亏成那样根本不敢开口。三个月合作下来，托管费6万，店铺亏损7万多，合计超过13万元。我也想过跑去公司门口拉横幅，逼他们没法正常办公，但最终没有那个胆量。

店铺还要继续做，亏损已经无法挽回，三个月的费用也退不回来，我只能安慰自己把这笔钱当成以后的美工费，反正作图还能继续找他们。后来和10月安排过来的运营聊天，才知道公司的分配真相：每家店名义上有一个团队，但实际上每个团队同时要做五六家店，多的甚至七八家。所以上款速度慢、消息回复延迟，都说得通了。

这些代管公司大多是赚概率钱。手里握着几十上百家店铺，只要有一家做起来了，就成了对外宣传的明星案例；做不起来的，都是商家自己的问题——不配合、款式不独家、图片来自档口、视觉和价格没有优势。问题从来不在他们。

更离谱的是，我后来刷朋友圈，发现之前对接的综合管理部人员早就离职了。打听后才知道，那家公司已经倒闭，楼层搬空，人彻底消失。我剩下的6万元托管费，成了永远讨不回的坏账。

2022年4月，我抱着试一下的心态在黑猫投诉发了帖。平台还没处理，倒先接了个陌生电话，对方说专门处理这类网络纠纷，可以帮我追款，但要抽成35%。

中间有个小插曲：向市监部门投诉时，对方教我说这笔钱是“以教学培训名义收取”。接线员似乎见惯了这种事，直接说会按教学培训交费的名义上报，但能不能成不保证。来回拉扯两天，对方终于松口：退款金额定为6.1万，再多没有，老板甚至放话宁可坐牢也不给。但又说自己还想留点信誉重新创业，不想留案底，所以愿意退这笔钱。

那两天打电话投诉、和民警对峙，心力消耗很大，心惊胆战，但也算一段极其宝贵的经历。

复盘整件事，我最想提醒大家的是：合同里不能只写“没达标可以终止”，必须写清楚没达标时对方要承担什么后果、按什么标准认定、退款流程怎么走。没有这些，所谓“保护条款”就是废纸，对方从一开始就立于不败之地。另外，超过一万元的付费决定一定要慎之又慎，多问几个为什么，把对方承诺的一切先打五折再评估。

我是超然，一个被现实狠狠教育过的电商人。希望这个故事能帮大家在面对类似招商话术时多一分清醒，别再踏进同一个坑。
