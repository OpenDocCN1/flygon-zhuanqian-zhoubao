# 服务 100 位创始人后，我发现 5000 万营收是他们的第一层天花板

接触了上百位创始人之后，我心里渐渐浮起一个判断：五千万元年营收，是很多企业绕不开的第一道隐形门槛。

为什么偏偏是五千万？不是市场不够大，也不是产品没有竞争力，更多时候，卡点就出在创始人自己身上。

细看下来，绝大多数行业的竞争，本质上都是人才的竞争。而真正优秀的人才，愿意追随的不是给钱最多的老板，而是能带他们不断看见更大世界的领路人。创始人就是一个公司的地基结构，地基一旦动摇，上面的楼就再难盖得更高。

很多创始人在公司进入稳定期后，悄悄关上了自己的“天线”。对新鲜事物变得迟钝，对陌生领域缺少好奇，甚至开始依赖过去那套成功经验。结果就是，组织也跟着失去了向上的势能，年营收也就长期停在五千万附近打转。

想要破掉这一层天花板，没有捷径可走。唯一稳健的打法，是创始人重新把自己“拆开”：保持彻底打开的心态，愿意听刺耳的真话，甚至敢于推翻自己最得意的方案；同时持续保持极强的学习能力，不断把外部的新认知引入组织内部，让整个团队始终处于进化之中。

五千万，只是一个“第一层”的标记。它真正提醒每位创始人：最难跨越的，从来不是业务难题，而是自己设下的边界。公司能走多远，最终取决于创始人还能学多少、变多少。
