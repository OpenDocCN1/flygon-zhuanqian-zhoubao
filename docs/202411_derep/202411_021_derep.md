# ('我的 6 次 29 条船的航海故事，成功赚回 N 倍门票', (2, 30))

六次出海，29条船：我把赚钱的门票钱，赚回了N倍

如果航海也有朋友圈，那我的动态大概全是“船”。加入龙哥盟以来，我一共上过29条航海船，当过2次航海志愿者。这些航程记录，在赚钱后台都能翻到。每一条船都平安靠岸，可能部分船有点“划水”嫌疑，但打卡、参与，我是认真的。

我第一次登船是在2023年6月。当时我刚在4月18日成为赚钱会员，就挑了“资料整理”和“风向标共读”两条船，同时兼着志愿者。

第二次是2023年9月，一下子选了6条船：公众号爆文、视频号爆文、商业访谈、剪辑特训、选品特训、社群发起人。这次有个插曲：我被人踢出了微信群。具体原因记不清了，大概是我在群里太活跃、太高调了吧。

第三次是2023年11月，我又回到公众号爆文航线，顺便再做了一次志愿者。

第四次是2024年1月，这是我“大爆发”的一期，一口气报了14条船：小红书店铺、运营、境外游、直播、出海第一站、ChatGPT提效、AI绘画、思维导图、风向标、自由职业、跨境电商……可以说把感兴趣的赛道都试了一圈。

第五次是2024年4月，只选了小红书达人变现。

第六次是2024年7月，上了ChatGPT和AI编程爬虫两条船。

回头看收益，大多数船我都只是浅尝辄止。真正跑出来的是小红书和微信公众号，这两个方向我一直在做，也确实有了变现。另外，我在赚钱里发现过“卖知识星球邀请码”的小项目，赚了大概2000到4000元，算是把门票赚回来了。后来官方自己下场卖了，我本身也没多大兴趣，就彻底放下。

还有一个帆布袋定制项目，被加精后来了几千元成交，具体金额记不清了。我还邀请过6位朋友加入赚钱，返佣也有上千块。其他零零散散的隐形收益，金额不大，就不拿出来“晒”了。

说实话，我并没有靠这些赚到大钱。但这个社区很好玩，会让人产生归属感。毕竟，创业的人、努力赚钱的人，内心往往是挺孤单的。

想对赚钱说几句期待：

第一，希望它越来越好“玩”，社区氛围更热烈；
第二，希望更多人能通过赚钱赚到自己的第一个100万。有人可能用1到3年，有人用5到10年，也有人可能永远到不了，但至少在这里，这个概率会变大。

以前我觉得航海好像没什么具体项目，后来随着更新，赚钱其实已提出具体项目了，只是我自己不感兴趣。所以，我希望未来能多一些有趣、具体的项目，更多好玩的航海船。长途航海是个很有意思的探索方向，如果能持续一年、三个月、半年甚至更久，说不定会更带劲。

甚至，赚钱也可以开一条“找项目”的船，让大家在船上不断测试，最终找到自己真正感兴趣的那条路。

12月的flag，我已经想好了：去探索更广阔的世界，继续在赚钱里捡珍珠、拾贝壳，直到把它们串成自己的宝石项链。这次我不会再报很多船，1-2条就够了。
