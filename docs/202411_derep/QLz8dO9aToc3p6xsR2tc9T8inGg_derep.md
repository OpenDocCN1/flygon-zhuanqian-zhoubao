# 零基础、零代码，我用 Windsurf 花两小时做出了 YouTube 下载器

大家好，我是雪梨。一个在赚钱有术潜水多年、从第一年就泡着但一直没行动力的“老透明”。今天终于鼓起勇气浮出水面，分享一件让我自己都意外的事——我这个连代码都看不明白的小白，居然做成了一款 YouTube 视频下载工具。

事情得从头说起。最近龙哥老大发了个“超级标”，我对 YouTube 一下子来了兴致，还试着传了两条视频。兴致归兴致，真要研究对标视频时，下载这一环差点把我劝退。试过好几个网站：要么打不开，要么广告轰炸，要么一下载就报病毒，想存高清版？先交钱开会员。于是我心里冒出一个念头：算了，自己做个工具吧。

一开始我想到的是 Cursor。之前照着阿紫大佬的教程折腾过半天，结果只弄出一个贪吃蛇，后面那个“古诗划字”直接卡住，对着教程一步步来还是做不出来。当时真的挺沮丧，觉得自己大概没什么编程天赋。可又不甘心一直被卡在起点，心想圈里总有更简单入门的办法吧，再不行就等 12 月的航海找大佬们带。

接着我去翻了翻红哥和钱塘江鲤大佬分享的 Cursor 实战贴，看完只能感叹：太强了。真正让我眼前一亮的，是这两条风向标：![](img/932648f2eac7ea8568bebfa60fc5aa5f.png) 里面提到的八个字——自动运行、自动纠错！要知道，之前在 Cursor 里最折磨我的就是反复新建文件、复制粘贴、运行代码，这套流程又繁琐又容易出错。既然风向标都出来了，哪怕没教程，我也得下载试试。

Windsurf 的官网下载地址在 https://codeium.com/windsurf/download ![](img/ae3e34924d0e7b5927c9fb58f6c069c1.png)，我反正先安排了。装好一打开，就是熟悉的“全英文暴击”。英语加编程，双重看不懂，简直是给我这种小白双重劝退。不过安装和下载这种操作我还是没问题的，先装上再说，万一会冒出来一个中文补丁呢？

首次运行就是傻瓜式操作，页面哪里有高亮我就点哪里。当时我选了第二个 Start fresh ![](img/a8e1dcbdb09d23808253e46f84dbc6d6.png)，编辑器风格选了第一项 Default (VS Code)![](img/5663e3e2d9a2eeb98c18027c61d6987b.png)，主题我没多想，直接选了第一个 ![](img/6d56785b85c7701fe121db1157e695fe.png)。接下来是登录注册，我点了 Sign up ![](img/e5ac7fc7d28b33a84b6dbb835ed8d552.png)，随后用谷歌账号完成了登录 ![](img/1af5af3612f338ea71115a800361fb17.png)。就这样一路点到了主界面。![](img/9f4284bb4394129b3b761b53c90f6cd4.png)

进去之后我第一反应是找 language，想把界面改成中文。结果搜出来的全是编程语言的词条；在设置里翻了一圈也没有语言选项；又试着找像 Cursor 那样的中文补丁，同样一无所获。那一刻我差点崩溃，总不能每一步都截图翻译吧？就在我准备逃回 Cursor 的时候，脑子里突然闪过一个念头：Cursor 右上角有对话框，Windsurf 会不会也有类似的对话入口？

还真让我找到了！![](img/6d0964dd6b647354eda87b56a15a38cd.png)![](img/3531200c48b8ebd2ad03f4f21d6f6bbc.png) 这个对话窗口看起来特别亲切，于是我敲下了第一句中文：

“我想做一个在网页上运行的程序，它是古诗划字连词游戏。玩法是把一首诗的所有汉字打散，玩家需要按正确顺序把汉字连接起来。你认为适合用什么技术完成？请给出一个你最推荐的技术以及对应的脚手架。”![](img/09eb3c705cfd765c13c64c64c14e6aa6.png)

没错，这段需求其实就是我从阿紫教程里搬来的。没想到 Windsurf 回过来的内容，居然是我能看懂的计划！我正准备把阿紫教程的第二段话复制过去，结果它告诉我：项目已经建好了，依赖也装好了！![](img/a9cf6c6fdb3db5617251174def10b8d9.png) 紧接着，它噼里啪啦输出了一大堆，直接甩给我一个网址 http://localhost:5173 ![](img/68dc112fbd752bc733cd3cacdbcd396b.png)，还特别豪气地问我：“你觉得这个游戏怎么样？有什么想改进的地方吗？”

于是，我打出的第二句话，居然就是对游戏的修改意见！这体验也太神奇了——不需要复制粘贴代码，不需要自己新建文件，也不需要 Win+R 敲命令。我要做的，基本就是跟着高亮按钮走，再时不时按一下 Accept 而已。对小白来说，这就是救命稻草啊！

趁热打铁，我马上开始挑战 YouTube 下载工具。本来我的想法是做一个浏览器插件，可惜试了好多次都报错，最后没能成功，这段过程我就不详细展开了。

后来我参考红哥的帖子，找了一个能下载 YouTube 视频但必须开会员才能拿到高画质的网站，把它发给 Windsurf 作为参考。![](img/5ce48cc1d4d70769b05aa3274a5f0782.png) 它又是一长串输出，随后界面上出现了 Accept 高亮按钮，我点下去，弹出了一个窗口。![](img/1dbde880eff07330c6133c76a4cc8d08.png)![](img/25ad5807dccaa3d91c827109cba860b3.png) 我随便找了条视频来测试，果然报错。我也看不懂日志到底说了什么，干脆直接把错误信息原封不动发给它。就这样来来回回重复了五个回合，终于成了！

不过新的瓶颈又来了：下载下来的视频被锁死在 360P。我继续提需求，让它把清晰度放开。![](img/c4fb819fe0aef7efc416ddc944c4e49b.png) 结果没等多久，它就把功能做出来了，画质想选什么就选什么！![](img/b9749408ebb7408f29ce271a39f021da.png) 完美。

算一算，从安装 Windsurf 到做出这个下载器，加起来还不到两个小时。中间有差不多一半的时间花在我找中文补丁和那个失败的插件上。而整个“写代码”过程，我输入的汉字可能都不到 200 个。Windsurf 输出的那些代码和日志，我一句都看不懂，但它居然真的把工具做出来了，看着最终成品，成就感直接拉满。还好当时没有放弃。

对了，中文补丁后来真的找到了，谢谢 NEVER 的指点！![](img/529394567d357543cb3bfe489c67d0a2.png)![](img/f9a132deaafff9854e51203a542ff8cd.png) 也感谢各位大佬的无私分享。
