# 小红书做商单，钱到底什么时候才能到手？



## 小红书接广告变现，账期才是关键

作者：哈默

日期：2024-11-15

#哈默教小红书#004 小红书接商单广告，都是怎么赚钱的？

很多人以为接了小红书商单，当天就能拿到钱，实际上从合作到钱到账，中间要走一整套流程，而且是有明确账期的。

我们双十一期间，单号账号商单量常年维持在20单左右，现金流的节奏感直接决定了团队能不能稳住。所以今天就把博主接商单的收款周期和合作模式拆开讲清楚。

账期这件事，对做自媒体创业的人尤其致命。帐面利润再高，账期拉长没现金流，运营也会非常被动。小红书博主变现，绕不开的就是这个到账逻辑。

1️⃣ 一单商单从邀约到提现，全流程长这样

从品牌方伸出橄榄枝到钱进自己支付宝，一共要经历10个关键节点：
品牌方发出合作邀约 - 微信对接细节 - 在蒲公英平台下单 - 博主创作笔记 - 笔记交付给品牌方 - 小红书社区审核 - 品牌方审阅内容并确认 - 博主正式发布笔记 - 品牌方确认订单完成 - 小红书钱包提现

2️⃣ 品牌和博主之间，常见的3种合作玩法

目前商单市场主流就这三种。

1）定制合作
品牌方精准点名博主，提出内容需求和创意方向，按博主自己的报价一次性买断。图1就是典型的定制邀约，主动权在品牌方手里。

2）招募合作
这个模式是博主先报名品牌方的招募项目，品牌方再从报名池里挑人。报价同样是一口价。和定制的区别在于，博主变成主动投标方，品牌方有筛选权。中标后平台会提示【已通过】，如图4，然后进入私信沟通和下单环节。

3）共创合作
品牌方自己发起项目，博主报名参与，审核通过后品牌方会先寄样。博主收到样品后发布笔记，收益不按固定报价，而是按笔记带来的实际效果分成。常见结构是【保底费用+效果奖金】，如图5。

这三种模式我都实操过，其中大部分博主日常跑量最多的是定制合作。

3️⃣ 博主自己提现，钱到底多久到账

下面只说不挂机构、自己操作提现的情况。平台每笔收入会收取10%的综合服务费，如图6。

1）最快能多久
笔记发布后，如果品牌方立刻点击确认完成订单，那么订单完成后第7天入账钱包，也就是发布后第8天中午12点开始陆续到账小红书APP钱包。最理想情况下，发布完笔记第8天就能提现到支付宝。

2）最慢能多久
最慢取决于品牌方第9步是否主动确认。发布后品牌方有权在7天内确认订单，如果7天内没操作，系统会自动确认。所以最长的等待周期是发布后15天才能提现到支付宝。

🌿 做小红书商单，本质上是在练项目管理能力。从邀约沟通、内容执行到流程跟进，每个环节都要盯。博主和品牌方是双向奔赴的共赢关系，在不断磨合中一起成长。

祝所有小红书博主，单子源源不断！
也祝所有品牌方，投放效果爆棚！
