# ('YouTube 中长视频收益差异解析：千次播放收益与语言影响', (2, 32))

同样做YouTube，为什么你的千次播放收入那么低？看完这篇就懂了

最近不少朋友问，为什么同样是YouTube中长视频，有人千次播放能赚大几十块，有人却只有几块钱？这其中的差距，主要就藏在RPM和CPM这两个概念里。今天咱们一次性讲清楚。

先说明一下，这里讨论的是中长视频，不是Shorts。长视频可以设置片头广告和视频中间插播广告，而Shorts是很多条视频才轮到一条广告，逻辑完全不一样。

要搞懂收益，先记住两个基础事实：第一，YouTube有一个指标叫RPM，意思就是每一千次播放，创作者能拿到的分成收入；第二，平台会把广告收入的45%分给创作者。

把这两个事实放在一起，你就能推导出一个公式：RPM = CPM × 视频中单次播放可展示的广告数量 × 45%。这里的CPM，就是广告主愿意为你每千次广告展示付出的费用。

这么一看就清楚了：想让RPM往上走，能动的变量其实只有两个：要么让CPM变高，要么让一条视频里的广告展示次数变多。

先说广告展示次数，这个相对简单。YouTube规定，超过8分钟的视频可以插入多条广告，而且插广告的位置你能自己控制。换句话说，视频越有吸引力、观众看得越久，广告展示次数就越多，收益自然也就越高。YouTube这么做，其实就是在鼓励创作者做更优质的长内容。

接下来是重点：CPM。这也是为什么很多人喜欢做英语赛道的原因。英语赛道的好处不只是全球观众多、播放量容易做大，更关键的是CPM明显更高。而CPM的高低，主要由三个因素决定。

第一个因素，受众的消费水平。广告主当然想把钱花在更有购买力的人身上。如果你的观众主要来自美国、西欧、北欧，广告报价自然不低；但同样是英语内容，如果观众大部分是印度人，那广告价值就大打折扣了。

第二个因素，内容赛道的变现潜力。搞笑视频虽然流量不一定差，但广告单价很难比得过财经、房产、美妆这些领域，原因很简单——后者的观众更有消费意愿和消费实力，广告主抢得凶，CPM自然被推高了。

第三个因素，广告主之间竞争的激烈程度。即便是同一个账号、同一类内容，不同时间段的CPM也可能天差地别。比如黑五、圣诞这种大促节点，广告主疯狂砸预算，RPM就会跟着涨一波。

有个圈友问过我：视频说中文、加中英双语字幕，算不算英语赛道？能不能拿到高RPM？看完上面的逻辑你就有答案了——当然不算。因为你能吸引到的核心观众还是华人群体，除非你的内容本身就是拿来做中文教学、面向老外的。所以你可以理解为，语言从来不是关键，受众才是。就像李子柒，她的内容以中文为主，但观众遍布全球，RPM一定非常高。

那为什么我做中文内容，RPM就偏低呢？主要原因是YouTube在大陆没有广告，所以来自大陆IP的播放几乎不产生收益。另外，不少华人观众在台湾、马来西亚，这两个地方的CPM也不高。唯一比较欣慰的是，有一部分大陆观众用的是美国节点的IP，这部分播放反而能把CPM拉高一些。

所以结论很简单：与其纠结你说什么语言，不如想想你的内容到底在吸引谁。毕竟，决定你收入天花板的，不是语言，而是你用户的价值。
