# 38岁非技术的前电商运营人，靠 vibe coding，从月入3千到变现10W+只用了四个月

## 38岁转行AI编程，前电商运营用四个月把副业从3000做到10万+

260708 副业SC精华



我叫晓海，38岁，曾经是网络营销公司的销售冠军，也带过一家淘宝店铺冲到类目TOP200。

去年开始接触AI，今年才真正用 vibe coding 做出了第一个能赚钱的产品。从零到盈利，前后不到半年。

今年一月加入赚钱，半年时间里大量吸收精华贴。里面很多前辈的实战经验，都是经过市场检验的，执行力与思路都让我受益匪浅。

去年底我用 Trae 玩过几个小工具，总共也就赚了几百块。当时受限于个人认知和国产大模型的能力，我觉得AI编程做商业项目还不够成熟，就先停了，转去研究 Coze 和 Make 的自动化流程。

直到今年进入赚钱后，我才下定决心用AI编程来做自己的主业。

选择用AI做网站，并不是因为我经验或能力上来了，也不是模型突飞猛进了。恰恰相反，是我意识到再等下去条件永远不会完美，问题只能在实操中一边推进一边解决。

## 一、项目全貌

我做的网站核心功能是电商一键生成主图和详情图。

前期投入非常低：算力、AI会员、试错费用、基础服务器，加在一起不到一千元。开发也就用了7天做原型再用7天打磨，共计14天。上线四個半月累计变现破10万，上个月单月收款4.4万。

从2月底上线到6月底，收入曲线一直保持向上。

## 二、运营拆解

### 1、定位思路

做网站前我先问自己手里有什么牌。

我有的牌是：

- ①对大多数主流行业的电商出图流程比较熟，通用性强，但缺乏对某个垂直行业的深度定制能力。
- ②手上还有一批可以合作的博主和电商人脉，基本都是中小卖家，行业覆盖面广。

做垂直行业的电商生图站当然更精致，但我当时要的是快速变现。如果从零去做垂直赛道的账号，周期和不确定性都太大。结合现有的技术资源和渠道资源，做一个面向中小卖家的通用型电商生图工具，是最匹配的选择。

### 2、定价选择

定价我参考了三点：竞品、同行客户群、自身的资源状况。

竞品层面，电商生图赛道没有绝对的头部。美图设计室这类相对头部的平台单价不到1元。也有靠极致性价比走量的卖家，2-3毛一张。也有主打高端跨境的，单张5元以上。

客户群体层面，大卖要么追求深度定制化要么追求极致低价。中小卖家的需求更务实：图能商用、能有转化、操作简单，比请美工便宜就行。

自身条件层面，深度定制能卖高价，但投入精力很大，不适合我。极致低价则意味着获客量要翻20倍，服务器和人力成本也会大幅上升，分销给合作方的比例也会被压缩，积极性受影响。综合权衡后，我选择了略高于美图的1元左右区间。

充值套餐从49到499，几个月下来平均客单价稳定在100元以上。

### 3、从Demo到MVP的关键一跃

功能能用、用户能充值，还只是Demo。真正的MVP要跨过业务死线，也就是木桶的底板。底板漏水，桶再高也存不住水。

在我这个赛道，业务死线就是大模型不能随意二创产品的外观。哪怕画面再漂亮，产品被改了就完全不可用。

Nano Banana Pro 和 GPT 这类前沿模型很智能，提示词门槛低，效果惊艳，但容易对产品做二次创作。上线测试时第一批用户就反馈了这个问题。

改成 ComfyUI 提示词难度和画面自然度又会下降。我的做法是给每张图加入限制提示词，经过两三天测试，在保留画面灵活性的同时遏制了模型乱改原图的倾向。这个问题解决后，老客占比才稳定在每月接近30%。

### 4、推广借力

这是我的第一个AI coding项目，我没有自己冲在推广第一线。如果闭环全是自己不熟的环节，很难快速打通。我选择借力。

我联系了之前积累的电商人脉，包括电商博主、直播带货主持、电商公司老板、想兼职的素人。

最终贡献主要业绩的是电商博主。合作的两个博主有共同点：一是我半年内曾付费买过他们的课程服务300-500元；二是我以前为他们开发过电商小工具，并在工具上挂了他们的专属🛰️二维码，方便学员裂变。

电商博主的优势是人群精准、有粉丝基础、懂用户需求、会做内容。当时电商培训市场不景气，他们正好在找新的变现方式。

我把功能演示和案例素材交给他们，后续基本不用我操心，第一个月就带来8000多元业绩。

为了增强信任，我给有分销权限的合作方后台开放了实时业绩数据。

### 5、分销机制

流量为王，我把合作者当合伙人来对待，不是外包推广。分销提成高达42%，并且用户复购和裂变产生的收益也计入合作者业绩。只要前期推一波流量，后续1-2个月都能持续有收益。

我还设计了二级分销，不过素人没有人带很难坚持，这块是我后续要拓展的方向。

### 6、内容打法

我们主要的短视频内容有三类：

- 口播介绍产品+案例展示
- 不出镜效果演示
- 结合用户场景的干货分享

第一条发的就是口播介绍，成本低效果中等，适合博主直接说卖点并展示出图效果。

不出镜演示属于高投入产出比的内容，素人也能做，制作快且能引流私域，后续放大我会更侧重这一类。

干货分享类制作门槛最高，但效果最好。业绩最好的几十万粉博主基本靠这种形式，一个月做两条就能带来大量转化。

朋友圈的促转也是必做动作。

### 7、私域沉淀

网站里嵌入了🛰️二维码，用定期积分抽奖做钩子，约20%的用户会沉淀到私域。

群里每周或每次大更新，我会放出300张图的额度供群友抽奖，中奖者获得3张图额度，不足以做全套，从而刺激充值。

私域还有三个好处：便于了解真实需求、通过抽奖和更新公告提升信任度、指导用户更合理地生成图片。

### 8、客户运营与敏捷迭代

通过私域沟通发现，实际客户以中小卖家为主。原本以为服饰鞋包会占大头，实际日用品、工业品、小家电的卖家占比很高。

目前每月充值客户接近300个，多次复购订单占比约30%。前期也吸引了少量跨境卖家，为此我增加了十多种语言支持，但由于图片清晰度不到4K，大部分跨境用户流失了。

用户痛点很多，我无法全部满足，但主要问题我都做了功能优化。除了前面提到的业务死线，不少用户希望文案、画面、构图能个性化。

我上线了自由生图页面，用户可自行输入提示词DIY营销图，这个功能直接调用生图大模型API即可实现，不需要复杂工作流。

还有大量用户想模仿同行优秀图片，我则开发了图片克隆功能，只需上传自家产品图和竞品主图，即可一键克隆风格。

最开始两个月我平均每天更新三次版本，至今已上线十多个业务功能页面和十多个免费小工具。

## 三、1.0版本开发复盘

设计文档主要靠 Codex 辅助完成，代码落地用的是 VS Code + Kilo 插件 + GLM-5.0。

### 1、核心逻辑
最初唯一的核心功能：上传参考图，输入产品名和介绍，自动生成电商营销主图和详情图。

这个思路不是原创，来源于一个 n8n 工作流模板，我拆解了流程和提示词后复现。

### 2、系统配套
包含邮箱验证、充值、积分、用户裂变、分销统计等系统功能。

### 3、网站结构
我用“页面 > 模块 > 功能”三级结构来控制复杂度。大模型的注意力和推理能力有限，层次太深容易出难以修复的Bug。

### 4、开发流程
① 设计文档：先让模型根据核心功能和系统需求生成完整的前端、功能、技术栈、后端以及服务器配置预期，再人工审核修改。
② 代码搭建：严格按文档搭建脚手架，半天左右完成，不纠结是否跑通。
③ 完善功能：修复语法和逻辑问题，更新后让模型同步修改设计文档和README，每次更新前先让模型读一遍文档。
④ 前端重构：首版UI不满意后，我用百度秒哒9.9元会员生成新前端，再交给GLM整合到网站。
⑤ 部署上线：雏形完成后让模型输出部署文档，按步骤上服务器。后续项目我直接用ZCode在服务器上开发部署，效率提升数倍。
⑥ 更新迭代：前三个月更新最频繁，每天3个版本，80%时间在修Bug。大多数Bug通过错误现象和代码对比汇总给AI，1-3轮迭代可解决。

最棘手的一次Bug是A页面的下载功能正常，B页面点击下载直接失败。原因是图片鉴权问题导致浏览器无法打包图片，国产大模型推理有限迟迟未解。我临时用服务器后台打包，等待约两分钟，或让用户单张保存。直到GLM-5.2发布后在ZCode上花了一小时才解决。

核心教训：业务链条要尽量简单，安全与体验之间需要做妥协。

## 四、为什么选这个赛道

圈内人都说要追风口。风口有两个好处：市场快速扩张，容易增量；专业竞争对手少，发育空间大。

AI是当下最大的风口，但它跨行业，我不会盲目冲。做之前我先问自己有什么、要什么。

我曾是中移动客服、电商客服，也在工厂待过。2014年自学SEO进入网络营销行业，三个月内从零做到部门负责人，月带团队业绩50万，个人6万。

后来因一次与上司冲突被频繁调岗，最终焦虑辞职。之后在小公司辗转，收入一直没突破。

2023年我用积蓄开电商店，没多久家里亲人被骗投资，我拿出大部分积蓄帮家里还债，创业中断。

反思过去的经历，我总结出三点：

- 建立清晰边界，尊重他人选择，过度干预只会反噬自己。
- 想掌握议价权，要握住流量端或成交端。
- 业务能力要过关，且要让更多人知道你过关。

年初我做vibe coding创业前的情况：

不利：非程序员出身、无大项目经验、资金有限、无流量入口。
有利：懂电商商家需求、做过电商小工具有AI编程经验、学习能力强。

如果选一个不熟悉的细分赛道，试错成本和时间都会很高。电商AI生图的技术原理不复杂，提示词+API调用即可，GitHub和工作流模板能解决大部分逻辑。流量方面我先走社群和博主合作的短期路线，长期再考虑自媒体或建推广团队。

## 五、复盘要点

1、开发到上线只用了14天，2.0版本压缩到3天，vibe coding把产品试错成本压到极致。

2、分销赛马机制。我合作了10多个分销，两个电商博主贡献大头。素人虽然前期拉新少，但复购能带来持续收益。做产品要同时找到能操盘流量的合伙人。

3、只做系统集成商，不做源头技术研发者。前者试错成功率20-30%，后者不足1%。

4、先找到业务死线并修复，再谈体验优化，否则都是空中楼阁。

5、定人群和项目前，先盘点自己手里的牌。

6、vibe coding能力 + 获客能力 = 产品 + 流量，最短商业闭环。

7、不迷信技术，业务场景的适配优化才是核心竞争力。

AI时代，有想法就先动手，你以为的问题往往不是问题。行动中很多难题会自然被解决，甚至有同行来帮你。
