
- **术语不一致（核心概念重名定义冲突）**：
  - **“最小可行性行动”**：第50章定义为“注册→发布→获流→优转化”的执行启动闭环（来源：毛韩飞书长文 [PGn5]）；第51章虽未直接使用该术语，但“微小颗粒度产品切入”与“零产品起步”传达相近“小步快跑”含义，易混淆“执行动作最小化”与“产品颗粒度最小化”两个不同维度的概念。
  - **“暴力交付”**：第50章未出现该术语；第51章将其定义为“交付即筛选、给结果/资源/路径、拒绝无限答疑”（来源：[P003]）。若第50章后续迭代引入此词，需统一定义口径。
  - **“边界感/劝退营销”**：第50章仅在“盖洛普才干-边界感”提及“立边界（保护领地）”（来源：[P016]）；第51章系统定义为“主动设定不做的事/不收的用户、公开劝退作为营销手段”（来源：[P004]）。前者为个人心理边界，后者为商业筛选策略，术语同源但适用层级不同，需显性区分。
