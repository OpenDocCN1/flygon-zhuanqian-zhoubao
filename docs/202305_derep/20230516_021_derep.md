# Stable Diffusion 入门不完全指南：从本地安装到亲手出图

这篇分享被收入精华区，获得了 578 个赞，被不少新手称为“保姆级”教程。作者前后投入 80 个小时，把 Stable Diffusion 的使用流程整理成一篇将近万字的教程。

教程的主线安排得很清楚：
- 先解决安装和部署，让本地环境能顺利跑起来；
- 再逐项拆解界面操作，把常用按钮和参数讲明白；
- 然后用多个可跟练的示例，带着读者复刻出同款画面；
- 最后介绍去哪里找好用的底模、LoRA 与提示词资源。

更让人省心的是，作者把需要用到的程序安装组件、大模型、LoRA、提示词文件等素材都打包好了，不用再自己满网找。跟着这份教程走，基本可以做到“看完就会做”。
