# 视频号到底还能不能干？三个月我靠它净赚 20 万，路子换了

大家好，我是橘子海。

2021 年我进了赚钱有术，年底直接辞职。去年初开始在全网做茶类 IP 的短视频带货，粉丝加起来十五万多，规模看着还行，但转化一直拉胯，赚的并不理想。

真正的转折点在去年五月，我把手伸进了视频号。那段时间做得和大多数人一样：用工具批量选品，剪视频发出去，运气好就开播。一直捱到十二月，靠发量堆概率，偶尔能中几个爆点，运气爆棚的月份也能到几万块收入。核心痛点始终是两点：选什么能卖，素材怎么做才有人看。

今年一月我换了打法。

不再死磕爆款，也没再开视频号小店，更不搞直播了。说白了就是懒，也觉得直播对我这种个人玩家来说成本太高。但出乎意料的是，收入并没有掉，反而更稳了。

选品的底层逻辑我在星球里沉淀了不少资料，这篇就不展开细讲。我更想把这次转变后，实操上到底是怎么跑的方法拆开说说。

最后说点个人经历。没学历没背景没资源，初中毕业就进厂拧螺丝，自学设计才进了行的头部公司。21 岁全款买了人生第一套房，也曾背过几十万负债。起点可能比赚钱里很多人都低，但工作也好创业也罢，我一直是全力以赴。

普通人要的也不多，就想赚点实在钱，让自己和家人日子好过一点。

如果这条路能给你一点启发，那我的分享就值了。
