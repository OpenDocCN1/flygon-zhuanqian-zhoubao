## 《A股投资方法论（择时+选品）》

作者：基金小克勒
日期：2023-05-09

大家好，这是我在生财写的第一篇长文。我是基金小克勒，CFA持证人，2013年入场A股，至今十一年都是正收益。

今天把我这些年的A股打法摊开讲清楚。A股和别的资产没区别，一轮行情赚大钱靠两件事：选对标的，和在对的时间上车。选品决定上限，择时决定你能不能把复利做起来、回撤压下去。

# 1. 择时，其实是性价比轮动

很多人说择时不靠谱，书本上也倡导固定配置。但十年实操下来，择时是长期收益的放大器。

靠一套可重复的交易框架，我在2015年6月、2018年2月、2021年2-3月成功离场，也在2015年9月、2018年末重新入场，2021年3月完成赛道切换。到现在我的择时胜率是100%。

关键要先想明白，这不是赌运气，是看资产性价比做大类轮动。所以择时的节奏很慢，可能几年才等到一次真正适合调仓的窗口。

先把干扰项扔掉。

第一类是突发事件、地缘冲突、港美股波动。这类消息一出，市场已经反应大半，后面再追仓位性价比极低。

第二类是财政政策、MLF/LPR这类中期货币政策、M2社融等宏观数据。它们最多影响日内波动，长期影响早已price in到十年国债收益率里了。

第三类是情绪观察，比如身边讨论股的人多不多、雪球股吧评论风向。样本小、量化不了，别当依据。

真正起作用的因子只有一个：股债性价比。

股债性价比 = 指数PE的倒数 / 十年期国债收益率

我主要盯的是沪深300的版本：
沪深300股债性价比 = （1/沪深300PE）/十年国债收益率

这个指标长期在1.5到3.0之间震荡。

过去十几年，指标在3.0附近建仓、在1.5附近离场，基本都能成为赢家：
![](img/e83686d5a816fc312b64a8b82b5e1486.png)

背后有逻辑：股票比债券风险高，长期回报也更高。美国200年数据里，股票年化收益大约是长期债券的两倍。
![](img/55d10824c40ed73a2373b1ed9f5345b0.png)

所以沪深300股债性价比长期在1.5-3.0区间波动，是理所当然的事。

技术分析可以当辅助。A股是非有效市场，会涨过头也会跌过头。上行时均线有支撑，下行时均线有压制。技术面主要用在高位判断拐点。

股债性价比到1.5附近时，有时拐点在1.6、1.7，具体点位没法提前精确命中。但当性价比已经很低并且跌破趋势线时，信号就很强了。
![](img/30ed71dde847fde8df732a450f1b8b61.png)

顺带说个楼市的经验：房产投资人看成交量，股市里技术分析就是类似的存在，辅助作用。价格足够便宜+成交放大，才是行情起来的信号。

沪深300股债性价比>3.0就一定1-2年大赚吗？不一定。过去十年结构性行情很多，需要结合四象限估值来看：大盘成长、大盘价值、小盘成长、小盘价值。

2012年底是典型系统性底部，四象限估值全部是历史低位。那时候买什么类型基本都能赚。

![](img/366a9709104499b893a6fe42ebce7e32.png)
2015年6月是典型系统性顶部，所有风格都贵。指数跌破趋势时清仓最稳妥。

2016年3月属于结构性底部，大盘股极便宜，小盘股依然贵。所以2016-2017年是明显的大盘行情，小盘无缘。

2018年2月又是系统性顶部，所有股票都不便宜，市场利率还高，十年国债收益率破4%。

2019年初系统性底部回归，四象限估值都回历史低位。

2021年3月比较特殊，很多私募当年在这里择时失败。大盘成长极度高估，价值和小盘却很便宜，市场明显撕裂。

2022年4月和10月，沪深300股债性价比再次回到3以上。但和2016年不一样，这次高估的是大盘成长股。所以现在更像结构性底部。

我的建议是，如果自己水平有限、长期年化达不到25%，就等系统性底部再重仓，其余时间小仓位试探。结构性底部如果没买到热点，很可能跑输私募和雪球产品，甚至跑输保本理财。

# 2. 选品：从三好到小规模

我的选品路径变了三次：2013-2015年玩分级基金和可转债套利，2016-2020上半年做个股反转因子，2020年中后转为主动公募基金。

分级已成历史，可转债、因子投资都有明显的顺逆周期。注册制推行后标的越来越多，难度直线上升。对普通人来说，最省事的办法是买公募基金，花1.5%的管理费买投研。

买主动权益基金常见三个坑：一是买前业绩漂亮买后变平庸；二是多只基金叠加，走势几乎一样；三是经理换人。

我用“三好”来筛：好公司、好经理、好体系。

一、好公司
很多人觉得投人就行。但幸存者偏差很严重，长期优秀的经理大多集中在头部公司。公司资源、投研体系、稳定性都不同，踩坑概率差很多。

头部公司有更充裕的投研资源，规模起来后经理收入指数级增长，中小公司的优秀经理很容易被挖走。

我心里的顶级公司画像：剔除货币基金后管理规模大、高管本身是优秀基金经理出身、各梯队经理持续出现、口碑好负面少、价值观偏长期投资不鼓励博弈、经理收入高是行业跳槽终点站。

给我好感的公司有景顺长城、易方达、富国、中欧、交银施罗德、华安。

规模大但质量不高的：华夏、南方、博时、广发、汇添富、鹏华、天弘。

二、好经理
公司筛完后选人就简单了。最粗暴有效的是看长期业绩排名靠前的经理。

两个加分项：是否担任公司投决会成员。投决会对基金经理买入非自有池标的超3%要投票，超5%要主席批准，能参与投决会的都是公司核心投资大脑。还有金牛奖的数量。中国证券报主办的金牛奖是业内最权威奖项，评选看长期价值而非单一年收益，能得奖的经理基本靠谱，短期博弈型经理很难拿到。

三、好体系
前两步筛出观察名单后，最关键的一步是只买小规模基金。

基金规模越小，交易摩擦成本越低，还有打新和参与小市值交易的超额收益。很多逆天的业绩曲线，都是小规模时期做出来的。规模快速扩张后买进去，历史业绩基本复不现。

我的硬性标准：不买超过100亿规模的基金，原则上不超过50亿，最好20亿以内。

选基金这件事本质上很枯燥，没有太多创造性，我在这上面已经说烂了。
