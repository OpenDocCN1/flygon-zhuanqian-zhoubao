# ('《从 0 到 1 的副业历程：项目很多，但我 all in 小红书》', (2, 36))

如果你正站在副业起跑线上，看着满屏的项目推荐却不知道该迈哪条腿，那这篇文章或许能给你一点方向。

我是叁斤，生财有术第七期的新人，平时主要捣鼓小红书运营。之前发过一篇关于小红书引流逻辑和套路的拆解，意外收获了不少圈友的认可，也因此链接到了很多同路人。聊下来发现一个很有意思的现象：不少人还停留在“想干副业”的阶段，迟迟没动手。问原因，大多是说项目太多了，眼花缭乱，反而不知道怎么选；也有些人倒是执行力拉满，同时开了好几个摊子，最后每个都浅尝辄止，一场忙活下来啥也没成。

今天不聊方法论，就想跟你讲讲我自己的副业故事——我是怎么从一堆花花绿绿的项目里，最终锁定小红书，并且决定把全部精力押注在上面的。这篇分享主要分成三块：我以前折腾过的副业经历、我副业路上走过的三个阶段、以及我是怎样借助生财有术这个圈子一步步找到方向的。
