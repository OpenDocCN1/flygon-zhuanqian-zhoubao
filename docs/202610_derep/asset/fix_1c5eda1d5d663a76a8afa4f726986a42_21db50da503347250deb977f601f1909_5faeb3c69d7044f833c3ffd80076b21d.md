长文撰写与操作要点整理

长文排版与配图
原生的表格能力很弱，数据对比建议拆成带小标题的分项清单。若必须用表格，建议导出为图片再嵌入，发布前用手机预览确认字号是否清晰、是否被裁切。配图数量上限以编辑器提示为准。

封面图与首图是两个独立位置，长文顶部设有专门的封面上传位，不要沿用其它平台第一张图自动成为封面的习惯，尤其从外部文档粘贴富文本时要留意。发出前切到预览，确认封面已填、裁剪合理。

已上线长文的修改流程与普通动态不同，进入菜单选择编辑后，系统会先把文章撤回未发布状态，修改完毕再重新发布。即便是修正一个错别字，也会走这一流程。

点右上角发布键会弹出受众选择，开启了创作者粉丝订阅可以仅展示给付费订阅者，面向公开时请确认选择「每个人」。

长文适合展开复杂议题，例如行业复盘、专题梳理、完整经历。

回复权限检查
发帖框上方会显示当前的回复范围，点击展开后按需求调整，点应用后再次核对发帖框内的显示是否已更新。

这张图中的选项包括每个人、你关注的账号、你关注的账号及其关注的账号、只有你提及的账号、认证账号，以及地区入口。

注意是「你关注的账号」，不是「关注你的人」。限制回复不会同时阻止其他人查看、点赞、转帖或引用公开帖子。

话题标签使用建议单条不超过两个，这是平台建议而非硬性上限。参加活动或固定栏目时再加对应标签，无需给每个关键词都加 #。

位置标签按内容决定，线下活动探店时补充地点有助于理解，日常行业讨论不建议把挂定位当成固定分发手段。

编辑排期与草稿
开通相应会员后，已发布的动态可在首次发送后1小时内修改，最多五次，修改不会刷新倒计时。

手机端发布的帖子须回到同设备 X App 的编辑入口，网页端发布的回到 x.com 修改。

以下类型无法编辑：给别人的回复、带投票的动态、付费推广、串推、置顶帖、经由第三方工具或 X Pro 发出的内容，以及粉丝订阅专属帖。

编辑会留下痕迹，修改后的动态底部会出现铅笔图标与更新时间，点击可查看全部历史版本，转评赞数据保留。需要更正事实请直接写清更正内容，不要期望编辑能抹去记录。

定时发送只能在网页端操作，撰写完成后点底部工具栏日历图标，选择日期时间并核对时区，弹窗内点确认后回到发帖区点排期提交。随后点右上角未发送内容，切到已排期，核对文字配图与时间。保存草稿与进入排期队列是两回事，只有在排期列表里才算生效。

改期或撤回也在未发送内容里处理，分为草稿与已排期，点开目标即可调整。修改后返回列表复核，取消后确认已从队列移除。

手机 App 是否显示日历按钮取决于版本与灰度，若找不到可改用电脑网页，或用手机浏览器打开 x.com 并请求桌面版网站。

重要长文建议另行备份，先用测试文字确认手机与网页草稿是否同步。官方提醒退出账号或卸载应用可能导致本地草稿丢失，换机或重装前请先导出。

图片视频与投票
当前单条动态可混合最多四个媒体文件，包含图片 GIF 视频的组合。能否上传取决于单个文件大小格式时长，按界面提示为准。

传图时信息流网格裁切比例各不相同，可参考 1200×675、1080×1080、1080×1350 作为画布经验值，核心文字与主体放在中间，手机预览确认是否被切。需要裁切点缩略图进入编辑，支持 Grok 改图的账号可先预览结果再决定。

给图片添加替代文本，手机点图片角落 +ALT，网页在图片编辑中添加描述，每张上限1000字符。

[PRE1]
替代文本是为无障碍设计的，帮助视障用户或图片加载失败时理解内容，请写清主体、截图关键文字或图表结论，保存后缩略图会出现 ALT 标识。不要把无关热门关键词堆进替代文本。

长视频上限与端点及套餐相关，免费账号常见140秒，付费会员在不同帮助页显示不一致，帮助中心写最长4小时16GB，套餐对比页按档位与端点区分，超长视频常要求网页或 iOS 上传。传输数分钟以上内容请以当前套餐在网页端的提示为准，转码完成后建议完整播放一遍。

投票可设2至4个选项，每个选项最多25字符，有效期5分钟至7天。选项应保持同一维度，避免一个写原因一个写结果。

投票匿名且每人仅投一次，投后不可更改，发起人可见比例与总票数，看不到具体投向。想了解原因请另请读者留言。

带投票的动态不在可编辑范围内，发送前请核对选项完整性、措辞歧义、截止时间。官方说明投票不支持配图。

会员订阅与收费
平台会员、原创内容奖励、粉丝订阅是三项不同功能，先明确需求再核对条件。

2026年10月公布的统一订阅体系 The X Subscription 将会员权益、Grok、代码编辑器 Cursor 额度打包，分 Plus、Premium、Super、Ultra 四档，基准月费8、30、100、200美元，实际价格受地区税费渠道与付费周期影响。

价格因账号地区、商店区服、支付渠道而异，购买前核对当前套餐与渠道。第三方代开涉及密码交出与不明付款来源风险，且新订阅仅官网直销，不授权转卖，外购账号可能被处置。

旧套餐可继续保留，新订阅的合格第一方用量按周共享，覆盖 Grok 与 Cursor，Cursor 的第三方模型不在此池。Grok Bot 包含于 Premium、Super、Ultra，Plus 不含。切换前对照所需能力再处理旧套餐剩余时长。

修改头像、显示名或用户名会触发蓝标复审，蓝标暂时隐藏，复审期间三项资料不可再次修改，时长以系统提示为准。有活动需要蓝标时建议提前调整或留缓冲期。

取消续订请回到原购买渠道操作，网页购买去网页管理，苹果或安卓内购去对应商店。旧套餐常规取消一般不退费，建议提前24小时操作并核对到期日，卸载应用不会停止扣费。

切换到新订阅时符合条件的旧订阅按未使用时间比例退款，扣费与退款分开处理。苹果商店购买的 Cursor 需自行取消并向 Apple 申请退款，苹果购买的 Grok、Grok Bot 或 X Premium 切换时自动取消，未使用部分向 Apple 申请，Google Play 购买的切换后请检查是否仍设为续订。

金标通常代表企业机构，灰标代表政府或国际组织，蓝标为付费订阅加基础审核。判断可信度应看原始材料是否可交叉核实，而非看是否有蓝勾。

新订阅 Premium 及以上提供更高的回复优先级加成，但评论排序还会结合互动关系、内容相关性与折叠过滤，最高档也无法保证排第一。

身份证件核验与购买会员获得蓝标是两回事，符合条件的付费账号可申请 ID 验证，通常需证件照加人脸自拍。请仅通过官方设置入口进入，注意第三方核验商条款与数据用途，以及证件签发地支持情况。普通蓝标不代表完成证件核验。

原创内容奖励 OCR
OCR 有地区限制，当前支持名单包含香港、台湾，未列中国大陆，申请前请确认所在地与身份资格，持有某地银行卡不自动等同资格。

OCR 仅接受个人或商业账号申请，政治组织与政府组织不可申请。条件包括年满18岁、账号状态良好、无反复违规变现记录；至少500个认证粉丝，过去90天至少50万次来自认证用户的首页曝光，回复曝光不计；持有合格付费订阅并持续发布原创。

合资格订阅包括原 X Premium、Premium+、Premium Business，以及新订阅 Plus、Premium、Super、Ultra，旧 Basic 不在清单。入口在创作者工作室，达标后仍需审核，不保证通过。

50万曝光指过去90天来自认证用户首页信息流的曝光，回复不算。收益计算看合格曝光，平台将 Premium 用户定义为原 Basic、Premium、Premium+、Premium Business 用户，帖子须在首页至少显示一半，同一账号对同一帖只计一次，付费推广刷量等不计。旧 Basic 不能作为申请资格，但其用户阅读可计入创作者收益。

首次申请未通过可申诉一次，申诉被驳回后账号继续达标需等42天冷却期再申请。收益目前每两周结算，满30美元起付，审核时长不固定请留意系统通知。

非美国创作者需绑定 Stripe 收款并完成身份验证，证件姓名收款资料须真实一致，按收款服务要求填写，获得资格后仍需完成收款设置才能收款。

部分内容可发布但不计收益，排除搬运复制、轻改洗稿、误导内容、专门讲变现教学或追求收益的内容，自动化创建发布的内容，以及被评为有帮助的社区笔记内容也不符合。即使使用平台允许工具也需另核对收益细则。

反复要求点赞评论收藏关注转帖或人为操纵互动可能影响 OCR 资格，普通互动不属于操纵，违规可能被暂时或永久移出计划。

搬运视频加片头水印镜像或轻改不等于原创，需分别核对 OCR 是否认定原创及使用权，有授权也不等于轻改后可计收益。

粉丝订阅打赏推广
粉丝订阅是读者按月付费阅读专属内容，与会员、OCR 收入体系不同，开通后可发布订阅者专享内容，到账节奏以创作者后台为准。

Tips 打赏入口连接第三方支付，是否显示取决于账号与地区。

收到推广费、免费寄测或其他商业利益时，请按平台政策标注付费合作，让读者知晓商业关系。

Boost 加推购买的是广告曝光，非自然增长，投放前厘清目标是引流至主页关注还是落地页转化。

自动化限制与可见度
帮助页显示每日最多关注400个账号，关注数达5000后还受比例限制。

私信总技术上限保留每日500条，向未关注者发送消息请求另有按账号与订阅区分的限制，500条不等于可给500个陌生人发信，遇到速率限制按提示等待。

浏览量低、回复被折叠、账号受限是三类不同问题，需分别排查推荐排序、垃圾过滤、地区规则与申诉。

账号安全
点进钓鱼链接后切勿在可疑页面输入密码或验证码，关闭页面后自行打开 X 官方 App 或手动输入 x.com 进入设置修改密码。

改密后进入设置和隐私-安全性和账号访问权限-应用和会话-会话，查看所有登录设备，发现陌生型号或异地登录可退出或注销所有其他会话，确认只剩自己的设备。退出会话不解绑第三方应用，授权需在同一菜单的已连接应用中单独撤销。

定期检查已连接应用，了解权限是只读还是读写加发私信的高风险权限，不再使用的授权直接撤销。改密码与撤授权是两道独立防护。

可在安全设置中开启密码重设保护，重设密码需额外账号信息，增加核对。它不能替代两步验证，绑定邮箱的安全也需单独维护。按账号提供的入口设置，遇到旧登记更新提示请按要求处理。
