# 别再囤课了：把直播、选题、配图、审核串成一条能跑的AI内容流水线
作者：龙哥

收藏夹里躺着一堆直播回放，笔记记了半本，轮到自己发稿还是心里没底——这大概是很多内容创作者的真实写照。问题不在你不够努力，而在信息没有变成可执行的资产。下面这套复盘，讲的是怎么让模型分工、知识库、合规检查和发布动作真正咬合起来。

## 一、先把模型分工摆清楚

第一类，深度推理型模型，比如 Claude Sonnet、Claude Opus。它们擅长长链条逻辑推演，适合拆解爆款背后的底层情绪触点、推演受众心理、提炼知识增量。

第二类，视觉生成型模型 Codex ImageGen。它专注生成带有真实市井烟火气、自然光影和材质肌理的高清画面。

第三类，多模型工作台 Open Codex。当官方提示额度打满、服务停摆时，我们接入了开源的 Open Codex（本地监听统一接口），把 Claude、Gemini、GPT 等模型整合到同一个工作台里。它的价值是方便切换已获授权且可用的模型，但不会突破服务方限额；每次切换都要检查费用、上下文和输出差异，任务也可能需要重试。

## 二、发布前先过一道自动安检

内容最终输出、准备存入草稿箱前，我配了一个专职的“微信👸号平台运营合规审查 Agent”，用来提示可能遗漏的问题；人工终审仍然是最后一步。

- 诱导互动词过滤：提示检查“敢拔吗”“能捡吗”这类可能空泛的设问；要结合上下文判断，不能拿词表代替内容审核。
- 知识增量核验：提示人工确认正文中的年代、物理原理、工艺或民俗来源；严禁空洞抒情，也不玩留白猜谜。
- 真实属性核验：检查有没有把 AI 辅助生成的图片写成绝对真实的突发新闻，守住真实性底线。

## 三、知识资产工程化：从直播逐字稿到赛道专属 Agent 的 Harness 知识图谱

很多人囤了十几场直播、买了几十节课，真正上手还是发怵，甚至一发稿就踩坑。症结在于，直播和课程本质上是流式输入：两小时答疑转成文字，动辄两三万字，里面塞满“嗯、啊、对吧”这类语气词、闲聊客套、学员打断和碎片化单点案例。把几万字直接扔给通用大模型，要么因为上下文太长而严重遗忘，要么被水话带偏，最后总结出一堆看似有道理、实则没法实操的泛泛公文包。更关键的是，如果没有把自己的事实、案例和边界交代清楚，AI 更容易给出泛泛回答。知识库能补上下文，但也要检查资料来源与更新日期。

为了把教练的一线真传和大群实战经验变成自己的资产，我们借两个定制 Skill，跑通了一条知识飞轮：直播逐字稿 → 渐进脱水精读 → 方法论工程提纯 → Harness 知识库挂载 → 赛道 Agent 自进化。外部输入包括航海核心课程录音、教练两小时答疑逐字稿、交流群实操案例。

阶段一：调用「逐字稿精读笔记 Skill」（progressive-transcript）。Layer 1 用 500 字提炼全局脉络骨架，理清认知底座；Layer 2 完整保留推理链条与边界反例；Layer 3 精准锁定具体业务参数、阈值和实操金句。

阶段二：调用「方法论提炼与执行化 Skill」（methodology-distiller）。抽取“问题 → 动作 → 参数 → 结果 → 修正”闭环，整理成清晰的 IF-THEN-ELSE 决策分支，产出带明确红线禁忌与验收标准的《标准化方法卡》。

[PRE1]

第一步：调用「逐字稿精读笔记 Skill」（progressive-transcript-notes），对两三万字长文做三层脱水。Layer 1 用 500 字提核心论点与推导脉络，快速锁定底层逻辑；Layer 2 还原因果推理链和边界反例，这是最值钱的一步——常规摘要往往只剩一句“要做 A”，而它会严格保留讲者“为什么做 A”的完整论证、真实学员正反案例，以及适用边界与反例。比如生活奇闻赛道，不仅记录要打视觉反差，还会记下教练强调的反例：绝对不能做苦难压抑叙事与沉重说教，因为用户打开贴图号，图的是解压、猎奇和社交谈资，沉重叙事只会招致反感甚至举报。Layer 3 抓明确约束的业务参数，如正文建议字数、首图 3:4 比例、文案大字报字幅控制在 40%、日发布间隔 2 小时等，并单独归纳教练金句，最终输出忠于原文、没有废话、可直接检索的 Markdown 精读笔记。

第二步：调用「方法论提炼与执行化 Skill」，把经验转成 AI 能执行的 SOP。精读笔记再清楚，本质仍是供人阅读的教程；AI 写稿要的是能直接执行的指令级 SOP。做法是：先把经验切小，统一成五元结构——面临痛点 → 讲者判断 → 采取动作 → 核心参数 → 验收标准；再把教练口头答疑整理成判定条件。比如，选题落在民间奇闻：首图用脏旧废弃环境与高价值物品形成强反差，正文补入真实考古或民俗知识增量，结尾平实收束；若选题是女性清醒观点卡：首图选做旧纸纹，40% 金句居中排，正文按三段式层层升维。知识库按赛道分目录，如怀旧回忆赛道/02-知识库/、婚姻家庭赛道/02-知识库/、生活奇闻赛道/02-知识库/。

赛道 Agent 运行时怎么学、怎么调？发稿前，如果生活奇闻赛道 Agent 要动笔，Harness 会自动读取该赛道专属知识库中的《三类常用选题模板卡》《选图军规》与《合规门禁》，作为 System Prompt 注入模型上下文。这样产出的文案，开头就带着实战烟火气，但仍需人工检查事实和语气，知识库也可能过期或录错。发稿后还有回填与自进化飞轮：每天发布后，结合真实数据复盘（阅读量、流量主收益、微信后台健康度）以及有权使用并经人工核实的案例与规则线索；一旦发现新的平台风向或违规苗头，确认适用范围后，调用方法论提炼 Skill 更新知识库里的方法卡，并保留日期和依据。这样知识库就不再是在网盘里积灰的静态笔记，而是日日吸收实战反馈、持续迭代的动态数字大脑。

## 四、AI 图片合规与来源标注

这次把做法校正过来：剥离 C2PA、破坏暗水印、伪造 iPhone 拍摄信息，都不再推荐。AI 生成图要如实标注来源，真实照片也不能配上编造的现场故事。

图片处理与发布检查可以按这几条走：原件要留，原图、生成记录或拍摄来源都存好，方便回溯；授权先核实，图片、人物肖像、商标和引用范围都要确认；质量可调整，裁切、尺寸、清晰度是为了阅读体验，不能改变事实含义；来源如实标，按发布平台要求打上 AI 来源标识，别装成实拍；元信息要核对，设备、地点、时间不能编，来源标识不能躲；隐私要检查，截图里的 UID、token、联系方式和无关个人信息都遮掉；图文得对得上，示意漫画就标明示意，生成图不能拿来当现实事件的证据。

标注来源不等于做完真实性、版权和内容检查；这些要和发前自查一并过。

## 六、新手三问答疑（技术与工具向）

Q1：账号流量断崖时，官方检测链接具体怎么提取？
先到登录后的👸号后台，看账号检测与通知入口。第四章留了我用过的页面路径；地址里的 token 只属于当前登录上下文，不能公开。它不是固定公开 API，也识别不了所有问题；入口若变，以后台当前功能为准。

Q2：新手刚开始做，每天做一篇到底要花多久？
熟练之后，15 分钟人机协作流可以走完一轮——前提是素材和查证结果已备好。但新手别一上来就拼速度：找对标切口、感受选图的反常张力、把提示词调出人味儿，单篇 30~40 分钟很正常。先把手感和审美磨出来，速度会自然跟上；别用求快掩盖前期该补的认知功课。

Q3：普通人完全没有代码和技术能力，该怎么搞定素材和对标？
完全不用写代码。最轻的办法是建一个只有自己小号的“三人群”。刷📕、抖音、看一看时，遇到有张力的画面和高赞文案就随手丢进群；等车、通勤时集中翻看，拆解画面的反常四象限，提炼第一眼直陈标题。群里有几百条爆款沉淀后，你就有了能定期复盘、筛选的样本库。
