前些天刷短视频，看到有人在讲 GitHub 上的中文项目《高性价比人生指南》。它围绕如何延长健康寿命、如何减少不必要支出、如何避免把自己拖进风险。我顺着找到源仓库，读完觉得内容密度很高。

于是把它改成了一个可互动站点：howtolivebetter.net。

发布七天，累计独立访客超过八千。项目维护者把网址挂到了仓库首页，还有读者自发去论坛推荐。下面把过程和后台数字完整摊开，截图都是真实记录。

作者在项目说明里特意交代：这是备选清单，不是任务表；任选其中一两项即可，连他本人也未做完多数。我想解决的点很具体：别让链接躺在收藏夹，把它做成能勾选的工具。想做的事放进待办，完成后划掉，感兴趣的先存着，进度一眼可见。

只看一遍容易，难的是动手。我希望把“开始做”的门槛再压低一点。

### 把一本开源生活建议书做成检查清单

littlebena · 9月28日 · 2570次查看

[PRE3]
GitHub 上有个中文项目，三周新增两万 star。它不是代码库，而是一本电子书，名字叫《高性价比人生指南》。核心围绕三个主题：长寿、省钱、避坑。

网上流传的生活建议很多，比如常听到的喝水、早睡、控制消费，道理都对，却很难落到决策上。这本书的写法不一样。612则条目，每条都按同一模板展开：

成本：需要多少金钱、时间、说服成本
收益：一句话概括能换回什么
证据强度：A、B、C 三档
出处：仅采用论文与权威文件，并给出原文链接
A 档多由系统综述、大规模随机试验等高强度研究支撑。统计下来，A 档413则、B 档150则、C 档49则，存在分歧的内容会另行标记。

作者在说明页也写了：这是备选池，而非必须完成的任务表。任选一两项即可，连他本人也未做完多数。

我觉得光读一遍，很容易记不住，所以做了个可交互的打卡站 https://howtolivebetter.net/
- 浏览这本指南，把想做的条目加进待办列表
- 已完成的可以标记，查看总体进度条
- 感兴趣的先存着，之后集中处理

先做到这个程度，下一步仍会围绕健康、省钱和高回报习惯继续打磨。

评论区声音很杂。有人说“生活哪能提前规划”，也有人说“每个人处境不同，没有放之四海皆准的模板”。二楼质疑最尖锐，大意是：这不就是 GitHub 上一堆 Markdown 文档吗？碰到问题让 AI 给答案不就好了？

@orion 可能今天太上头了？
@linvscode 杀人诛心脸😂
@lnmput 感同身受 🐻

唉，看来还是工程师式解题思路
有没有可能，这种思路才是最不划算的。投入最大，回报最低

第二天我回了一句：
跟让 AI 现场给答案相比，差别在于：如果你压根没意识到这件事，就不会主动去问。

这也是我做站的核心想法。举个例子，取消全部自动扣费、每年处理一次个税汇算，你未必会在某天想起去问模型，但在清单里刷到就能顺手执行。

被喷很正常。V2EX 那条帖子首日278次到访，后面累计500多次。

有几个点值得细说。

- 维护者愿意挂链接，回报最直接
GitHub 这边贡献1244次到访，基本都来自项目说明页的一条外链。它不像论坛帖那样只火一天；头五天里，每天都能稳定引入一两百人。这个3.7万 star 的项目每天都在吸引新读者，那行链接等于一个长期曝光口。

- Bing 明显高于 Google
来自 Bing 的到访有1623次，Google 仅45次。约四分之三读者身处国内，Google 无法正常使用。百度渠道七天内只贡献6次来自搜索的进入。若主攻国内读者，Bing 的索引工作不能马虎。

- 在电子书文件里放回站地址，效果不错
我在 PDF、EPUB 中嵌入了回站入口，这一项贡献251次到访。在1320次文件取走中，有人读完后重新回到网站。在交付内容里留一个返回路径，几乎不花成本。

- ChatGPT 也能导流
ChatGPT 带来了58次到访。数字不高，但可能有人在向模型咨询同类需求时，被推荐到了这里。

- 论坛发帖的流量曲线很陡
V2EX 的曲线是：278→110→43→4，到统计末期仅剩个位数。论坛适合开局冲一波，无法支撑长线。
