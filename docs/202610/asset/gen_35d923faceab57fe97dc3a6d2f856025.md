# 3000多粉、创作分成没开，45天进账近5万：我靠“拉新+答疑”跑通了
作者：龙哥


[PRE0]

小懒式判断：这套案例更适合手上没流量、粉丝不多、在X上憋不出爆款的人；不太适合冲着创作收益分成和商单路线去的人。作者单月3.2万，主要来自App开卡拉新，X只是把人引过来的入口。最值得看的是组合拳：X发实操内容拉人，TG群按进度答疑，把有效转化做上去，3000粉就能跑。坑也要注意：奖励不全是现金，有股票，还要卖出提现；前期换方向、封号也白耗了几个月。

我是龙哥，X账号@donniy520，平时更常写海外银行卡、U卡、eSIM这类开户和使用教程。这两天看完超级榜19和小木那篇半年5万粉、变现6位数的X自媒体经验分享，挺有感触。小木、鱼总已经把内容、粉丝和平台收益做出成绩；我这一个半月，则是在X上做海外App拉新、开卡实操和TG社群指导，做出了接近5万元的收入。

先把账摆出来：8月下半月正式开始做拉新，这半个月收入接近1.7万元；9月又做了3万多。合起来一个半月近5万。账号粉丝刚过4000，创作分成入口还没开，也从没领过X的创作收益。其中9月24日进账375.5英镑与469美元，按汇率约合6900元，是9月单日峰值。

先看几笔奖励：200英镑、470英镑、433.22美元……金额大小不一，都是这段时间一点点跑出来的。有个汇款App的汇款抵扣奖励累计到1350澳元；另外两个App的推荐奖励分别是200英镑、470英镑；还有个项目的后台累计奖励为15100菲律宾比索。单独看一笔不算多，但自己跑通一次，再把经验分享出去，就可能继续带来推荐奖励。

时间线也交代一下。今年3月我进了生财，先跑YouTube视频航海，再碰AI SaaS视频站，后来才慢慢把重心挪到X。3月其实就试过做X号，小木的X skill也用过，流量就是起不来。当时对自己适合什么没概念，见方向就学、就试；内容发出去没人看，也找不到症结。6月进了圈友B哥的X答疑小群，补了不少运营经验。此前基本自己摸，B哥给过很多参考，这里得说声谢谢。后来有个号终于有起色，结果又被封。没流量时好歹还有奔头，刚有起色就断掉，真的差点放弃。缓了一阵，我转去日区，把国内视频搬过去，折腾一段时间仍没水花，最后还是回到中文区。现在回看，前面就是不停换地区、换内容，每换一次都得重新猜什么有人看。回中文区做海外App拉新后，我才终于找到能长期写下去的主题。8月下半月拉新收入接近1.7万，让我更愿意投入；9月继续做，又进账3万多。标题里的一个半月，指的就是这段拉新周期；前面3月试水、6月进群、换方向、重做号，时间也都没少花。只不过到8月下半月，之前攒的运营经验才真正和手上的项目咬合上。

为什么有人愿意开这么多App银行卡？我自己都有点集卡上头。翻我的内容能看出，拉新和开卡常常绑在一起。有些项目本身就是“开卡带拉新”：对方通过推荐去开户、开卡，完成活动要求，我能拿推荐奖励，对方也可能领到新用户福利。但这件事要持续，前提是有人真的想开卡。最刚需的场景是订阅AI服务：想用海外AI工具，到了付款那步才发现手里的支付方式不行；一张能被服务接受的卡，就能把问题解决。至于到底能不能用，仍要看卡种、地区和服务支持。开卡教程因此要回答：申请要准备什么、开好后怎么用、能不能付自己想订阅的服务。这些问题正好落在我平时研究的海外基建范围内。

不过卡开多了，还有个不太能用“实用”解释的理由：集卡像集邮，会上头。我自己就这样：明明已有能用的卡，看到另一张卡面好看、设计特别，还是想研究。钱包里一排不同卡面，翻着看也有意思，所以我在X上自封“集卡狂魔”。

开卡内容好玩就好玩在这：有人为支付，有人看卡面，有人迷靓号。别人一晒，自己也会想知道怎么申请。对我的账号来说，内容就很自然：晒一张喜欢的卡，说清实际用途，再把申请流程写明白；感兴趣的人去看教程，需要帮忙的进群聊。遇到有推荐活动的卡，符合条件的人完成开卡和使用，就可能带来拉新收入。当然，能订阅AI不等于非得开一堆卡；实用是一层，收藏乐趣是另一层。我两种都占，所以这个方向一直有东西可研究、可写。

继续往下做，手机号、地址、税号就绕不开。要开卡、办海外账户，往往先得搞定手机号、地址或其他材料；基础没铺好，后面就算遇到喜欢的卡或合适活动，也未必能马上上车。我做海外地址和信用卡那阵，筛了300多个地址，跑过视频公证，也碰到预审批被拒、补材料，最后才批下来。这些流程写进教程也许只有几步，真操作时每一步都要处理。把它们记下来，就能写成比奖励截图更完整的内容。后来一篇海外银行实操长文浏览到26万多，反馈让我更愿意继续写这类东西。

短推可以只报一次进展、晒一笔奖励；遇到需要完整解释的流程，再展开成长文。做过的事越多，能写的东西自然越多。9月30日账号3980粉，现在已过4000。

这和我最初做X的感觉完全不同。以前总在找下一条能带流量的素材；现在手上没做完的事、上篇教程没讲透的点，都能接着写、接着发。账号方向越来越清楚，权重标签也慢慢有了，平台知道该把内容推给谁，流量才逐渐起来。

TG社群这块，我觉得做X最后最好同步把TG群一并做好。目前“东逆海外基建交流群”有3900多人，另一个拉新薅羊毛群有1200多人，两个群可能有重合成员。

[PRE10]

这也是我愿意继续在TG里花时间指导的原因。X上把人吸引过来以后，后面的操作还有很多问题要解决。粉丝可能看懂了，但不知道自己缺的那份材料该怎么准备；也可能已经注册，却漏了一步任务；还有人看到奖励迟迟没出现，不知道是时间没到，还是哪一步没满足条件。这些事情会直接影响他能不能把邀请任务做完，也影响推荐奖励能不能发放。

群里的指导，我抓三件事。第一，把门槛摊开：地区限制、身份要求、需要哪种账户、要占多少资金、活动什么时候截止，先让成员自己比对；不合条件就早点换路，别浪费精力。第二，按阶段回答：没注册、审核中、任务已完成、等结算，问题完全不同，先问清卡点，再给对应步骤，比每次都从零讲一遍省事。第三，把高频问题沉淀成教程：一个人问是答疑，十个人问就该写进文档，否则永远在重复劳动。别等群满几千人才做，第一个成员卡住的地方，就是教程该补的缺口。我想通过TG放大的，正是这部分指导：让后面来的人，可以用上前面已经讲清楚的东西。有了实际奖励之后，下一步就是把已经讲清楚的内容整理好，让后面来的人更容易独立完成；否则每来一个人都从头教，自己很快就忙不过来。粉丝数当然会影响有多少人看到你，但从“看到”到“完成”，还有很长一段可以做。

再说奖励形态：不全是现金，有些发股票，之后还要卖出、提现。比如有个账户就留下一笔243英镑的提现记录。开头放过9月24日的局部账本，这里再把整月记录摊开；项目名已裁掉，只留日期和金额。按参考汇率把9月进账合并，约3.2万元，包含奖励、返现等。再加上8月下半月近1.7万元，一个半月合计约4.9万元，也就是标题里的5万。对一个只有三四千粉、创作收益还没开的账号来说，这个结果让我相信低粉拉新值得继续。

X创作收益还没开，但后面还有一笔可以争取。8月下半月到9月底这段成绩，是在创作分成入口没打开时完成的。这也是我认为这条路值得继续的原因：眼下先用内容找到有需求的人，把App拉新和社群指导做好；等条件满足、创作收益开通并拿到分成，就能在现有收入外再多一份平台创作收入。一篇实操文既能持续带来有效推荐，也可能顺带贡献创作收益。后面的收入还有上探空间；具体能多多少，等开通后看实际数据，现在不预设数字。所以长文我会继续写，账号也会继续做。至少目前，创作收益没开，并没有妨碍我先跑出结果。

回看这一年：3月进生财、跑航海，6月到B哥小群学习，8月下半月做App拉新，中间换过方向、也被封过号。最后找到的这件事，终于把“我愿意研究的内容”和“实际收入”接上了。我是东逆，X账号@donniy520，主要折腾海外基建，欢迎同方向的圈友来交流。
