稿子临门那一脚，我从来不让机器替我签字。模型说某句有毛病，我只当参考；它没响警报，也不代表稿子就能直接推出去。碰到养老保障、医保报销、疾病治疗、法律纠纷、投资理财这些题材，信源不够硬，我就挂一个“待查”标记，或者干脆整段拿掉。

### 第五项职能：复盘不是看热闹，是决定下一步怎么走

上线满一天、满一周，我会各做一次快照：平台给了多少曝光，多少人点开，点开的人读到哪，赞、在看、转走、评论、打赏的笔数和钱数分别是多少，再拿题材相近的稿子做横向对照。

我很少把“怎么没火”直接甩给 Codex，而是先让它分层找原因：曝光够、点开少，题目先背锅；点开不错、讨论冷，主体承接要查；曝光一般、打赏却集中，说明受众窄但黏性强，这个方向先别砍。

复盘完不能停在“知道了”，得落成下一轮的一个动作。比如主体保留、题目换掉；题材保留、开场重写；或者继续服务同一群读者，但把文中能照做的办法写细一点。每轮只动一个参数，最多再加一个，下一篇的后台表现才能告诉我到底调对没有。

### 拿《六十岁以后，孩子又来开口借钱》跑一遍全流程

1. 先找三到五篇同题材稿子，把题目、主体、留言和公开可见的反馈归档。
2. 这一段交给 Codex 只做拆解：读者是谁、矛盾在哪、为什么点开、读者反复担心什么；先按住，不写稿。
3. 在“担心伤和气”“担心以后治病钱不够”“拿不准手里该攥多少”三个顾虑里，我拍板只选一个当主线。
4. 再给主线配人物、日常片段、钱怎么放，以及必须查证的材料；材料撑不住就暂停。
5. 让 Codex 提交写作交代和三到五个备选题目，我来定受众、切口和结论。
6. 初稿出来，查三处：开头一百五十字有没有接住题目；每个结论背后有没有实料；收尾有没有读者能照做的步骤。
7. 上线后一天和一周回看，把表现好的题目词、留言原话、踩坑点和修正方式归档回样本池。

### 最常卡住我的几处，以及我的处理

- 题目大得能装天，却不知道服务谁：先写一句“对象是谁、他正卡在哪、这篇替他解决哪件事”。写不完整，就暂不开工。
- 机器擅自编情节：立刻叫停，只要它列缺料清单。人物、场景、证据少一样，就回去补，不许它顺着编。
- 题眼很凶，开头接不住：把题目和开头一百五十字拎出来单看；题目里承诺的人群、矛盾、好处，开头至少兑现一个。
- 通篇顺滑，却一股机器味：砍掉整齐排比、万能转折、段尾金句；加动作、迟疑、小算盘，以及不完美的真实口气。
- 读着像小年轻指导长辈过日子：把“退休”“养老”“晚年”这些词遮住，再看票子、身体、伴侣、儿女这些忧愁是否仍像五十多岁到六十多岁的人会挂心。
- 政策、诊疗、金额查不实：先挂“待查”，再找权威出处；找不到就删，别拿“差不多”“也许”去赌事实错误。
- 后台难看却不知道动哪：按曝光→点开→读完→互动→打赏一层层找，单轮只改少量参数；一篇失手不等于赛道错了。

这套东西真正的作用，不是让机器替我把稿子写完，而是在每个容易翻车的地方提前设一道卡口：

定选题 → 拆样本 → 补材料 → 对读者画像 → 写说明 → 人来拍板 → 出初稿 → 查事实和语气 → 上线 → 用反馈决定下一版。

Codex 给我的最大变化，是让我分清自动化与人工签字之间的边界：哪些步骤能做成标准动作，哪些判断只能由我拍板。它替我缩短面对空白页的拖延，也在成稿前提示材料窟窿，还能记住前几次试错攒下的教训。但读者信任、事实准确、最后按下发送，这三件事它背不了。

### 银发内容还能不能干？我的答案没变：能干

但如果还想靠甜言蜜语模板、伪造通知截图、批量生成稿长期混，我持悲观态度。供给变便宜之后，套话也泛滥；过去一篇结构齐整的稿子能显本事，如今只是入场资格。

能活得久的号，会把具体的人写活、把难题讲透、把个人判断塞进去。工具提速可以，长期关心替不了。

这些想法是在生财社区里慢慢磨出来的。二〇二四年，我先进了辰风老师搭的🛰️群，才第一次系统接触生财。那时我做号已有一阵，基本一个人摸索；流量一差，我分不清是方向、题目、题眼还是主体出了毛病。

三千多元门票，对当时还在读书的我，不是随便能刷的卡。我起初跟着群里学，也替辰风老师跑过拉新；后来用群里给的消息挣了一些钱，攒出预算后才付费进圈。

后来去航海项目、航海家聚会、线下碰面，我不再瞄到谁跑项目就马上跟。先问：这个项目服务的群体能不能长久存在。

我给自己划了几条红线：不靠伪造通知、诱导按钮骗点击；不拿病痛、衰老、亲情吓唬人；不为流量挑动对立；也不因为读者信我，就推自己都不认的东西。

每次点发送前，我会想：这篇若被我爸妈看到，他们觉得被尊重、被帮到，还是被吓住、被收割？若偏后者，撤。

一个年轻人不会因为会敲 AI 提示词，就自动理解长辈。先收起自己的想当然，去贴近那代人的日常，愿意听、愿意跑、愿意试、愿意改。等判断长进脑子，机器才帮得上忙。

这是我从写银发感情，到写银发生活体悟，再用 Codex 把流程跑顺之后，最实在的感受。它算不上万能答案，但每一句都来自我真写过、走偏过、调回来，也被后台表现与回帖里的真实反应反复校准的经历。

我是都一妮。在生财，见帖欢喜。
