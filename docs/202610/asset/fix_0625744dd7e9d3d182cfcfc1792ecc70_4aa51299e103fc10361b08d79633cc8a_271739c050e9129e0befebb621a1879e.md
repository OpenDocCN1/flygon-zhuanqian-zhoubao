# 七位数、八位数、九位数项目都碰过：心理赛道创业者的三次能力换挡

作者：大黑｜在内容课程行业做了八年，现居杭州，经营心理赛道的内容经纪业务

小懒点评｜这次回望把内容课程创业拆成几个阶段：七位数阶段吃的是行业上升期，要区分个人本事与外部馈赠；八位数阶段补的是整条业务经营；九位数项目则靠线下成交活动与团队架构。每位到场客户贡献从五千元涨到两万元，核心在机制而非买量。适合已经做个人品牌、想把前端获客延伸到后端服务的人；若想找线下成交会的操作清单，会落空。注意第五节其实是寻找杭州坐班增长合作者的招募信息；多套机制如何搭建，作者也说明要另写一篇，这里只给骨架。

2019年，我赶上内容课程行业的上升期，用经纪机构的方式签下十余名讲师，围绕九十九元录播课做打磨，再分发到音频与内容渠道，全年流水做到七位数，首笔创业收益就这样落袋。

后来我负责简曼这个心理品牌，以项目总负责人身份带起三十人左右的班底，项目年度流水站上八位数。再之后，我以联合经营者的身份参与施威项目，从零搭起上百人的后端用户运营与线下成交班底，那个阶段的年度流水一度摸到九位数。

盘子每一次变大，摆在我面前的难题也在换代。曾经管用的打法，未必能带你走进下一层。这篇文章想讲清几个问题：头笔钱是怎么来的，为什么必须改变做法，以及做大项目后我为何越来越看重人与班底。

## 一、七位数阶段：首笔创业收益到手后，先算清自己贡献了什么

创业之前，我在头部音频读书平台负责内容课程业务。2019年出来单干时，身边已有朋友把内容课程经纪跑通，业务数据我能直接看到。更关键的是，我本身就在行：懂选题策划、认识讲师、清楚平台缺什么品。判断对标可行、投入产出合理，我就动手了。

起步期最关键的是商务拓展。先找旧相识，再让讲师介绍讲师、前同事推荐讲师。我帮讲师定选题、磨讲稿、做形象包装和推广，再把课程对接给音频平台和内容渠道。自己加两名兼职，全年流水做到七位数。

翻2019年的创业笔记，第四周我写下：“年底单月流水冲七位数。”往后翻，全是细活：改逐字稿、磨发刊词和详情页、跟讲师对选题、催合同。机会看着简单，落地全是重复推进。

把几段经历并排看，首笔收益给我的第一条提醒：把个人本事和时代馈赠分开。那年行业在往上走，我又带着课程经验和合作资源，起步自然顺。钱到手后要拆账：哪些是自己做得好，哪些是平台和行业给的，哪些是人脉带来的。环境一变，结果还能不能重现？

承认外部馈赠，不妨碍我知道自己擅长选题策划、产品打磨、商务合作。但对团队管理、成交班底、服务履约，我当时几乎空白，下一程必须补。

第二条提醒：趁着窗口还开着，把生意从“撮合”变成“可积累”。做了一年多，我看出撮合模式的脆弱：用户留在平台，讲师和平台熟络后，下一门课可能直接合作。不持续签新讲师、不上新课，生意就难持续。

这次交易让我知道自己有价值，但价值若不能沉淀，下次还得重新找机会。于是我从合作讲师里选了心理方向，决定深耕一个个人品牌，自己扛前端获客、自有用户池、产品和服务履约。生意变重，也逼我学新本事。

第三条提醒：有钱之后，仍要亲自下场做业务。有了资金、经验和老板身份，容易觉得具体活不该自己干，想靠投钱、招人解决一切。但新业务早期，用户要什么、产品哪里卡、模型为什么跑不通，经营者必须亲手摸。人和资源能帮忙，前提是你知道问题在哪。

回看七位数阶段，我更在意：这次靠什么成、下一程缺什么，然后继续下场补能力。这才接得住后面的八位数业务。

## 二、八位数阶段：从卖一门课，到对一盘生意负责

2020到2023年，我负责简曼这个心理品牌，以项目总负责人身份经营，直接组建并带领三十人左右的班底。这次我没只收服务费，而是和讲师一起成立公司、共同经营。回报绑得更深，责任也更重，这个选择决定了我必须补哪些课。

过去，一门课策划好、推给渠道，核心工作就完成大半。现在，前端获客来了怎么接、成交怎么做、客户买完怎么服务，都得有人兜底。任何一段掉链子，整体都受影响。

不少事我此前没碰过。第一次面试别人，我比对方还紧张；第一次处理减员，迟迟开不了口。账上有成绩，面对管理仍是新手。从七位数到八位数，本质是补过去没碰过的经营问题。

我开始组自有用户池的成交班底，招成交团队负责人和经理，研究成交机制，也从零学教育类服务履约。当时在北京，常和教育同行聊买量、成交、服务。很快发现差异：K12多是家长掏钱、孩子上课；我们做成人和家庭教育，是家长掏钱、家长自己学。学习主体、需求点、服务形式都不同，不能照搬。

这一轮我补的是整条业务的视野。你可以精通某一环，但项目总负责人必须知道各环怎么衔接，并把短板补齐。现在我对项目经营的理解是：找对人、学不懂的事、让班底转起来。

最值得回看的是线下成交会、现场辅导员、成交团队多套机制的搭建与迭代。那个阶段，每位到场客户贡献从五千元提到两万元，接近四倍。数字背后是团队架构建设做对了。几套机制单独看各有分工，放进客户现场体验里要协同完成同一件事。经营者既要看单体质量，也要看衔接效率。

我把打磨后的状态叫作“能自我驱动的生态型团队”。能自转，是我在这个项目里最看重的成果。

再看责任变化：最初是我把讲师、课程、渠道串起来；后来是以项目总负责人身份把一盘生意建起来；再往后是要让上百人的后端班底共同运转。这也是我在九位数项目里觉得自己最有价值的能力：搭机制、建班底。

几套机制的具体改造、交接方式、贡献核算方法，需要另写一篇展开。这里先说认知：聊增长这件事时，我会同时看获客能力与团队接住客户、做好服务的能力。对擅长前端获客的朋友，这也是合作时必须审视的点：你带来的用户能否被理解、接住、服务好，会决定业务走向和你的信心。

## 四、经历项目起落后，我更想留下能持续做项目的班底

把经历连起来看像一条上升线，我的体感并不如此。最近一年我常说“把过去没踩过的坑都踩了一遍”。项目合作会结束，业务做完也要重新找方向。过去的成绩不保证下一段顺利，单次成功也不等于持续成功。几年前能出结果，不代表就具备持续出结果的能力。

这让我重新思考内容课程经纪这门生意：若每个项目结束都要重找人、重磨产品、重搭班底，哪怕前面流水很大，下一次照样累。

所以我越来越谈人才。项目会变，但对行业和用户的理解、一起做事的人、经过验证的方法，要尽量沉淀下来。

看项目不再只看经营结果，我更关注：是否有人成长为能独立负责一环的人？哪些方法被团队内化了？换个项目后什么能用、什么必须重验？

我现在希望团队的样子，既做当下业务，也通过业务把人才和能力沉淀下来，让下一轮不必从零开始。

## 五、我想找什么样的增长主理人一起干

从内容课程经纪、心理赛道整条业务经营，到自有用户池、线下成交会、团队架构搭建，这几段经历是我现在的基础。接下来我想在杭州物色一位擅长短内容、直播或买量，愿意坐班配合、逐步转为全职做增长的搭档。

不需要上来就全能，但希望你在某个获客方向有真实打法，并且愿意往产品、成交、服务履约上靠。

我看重一个人回看成绩的能力：能讲清自己做对了什么、借了哪些条件、哪些其实不会。我自己就是这么一段段补起来的，也想和愿意扎进业务、一起补短板的人合作。

想做的事很具体：围绕一个真实项目，把前端拿什么样的人、后端怎么接住、最终结果如何串起来，找到下一步可验证的打法。你带获客经验，我把产品、自有用户池、线下成交会和团队建设的经验拿出来，一起判断什么能用、什么要重做。

对已经能做获客、想进一步承担完整项目责任的朋友，这是一个可以交流的方向。合作需要明确资源、职责和目标，最好放在具体项目里谈清楚。

如果你做过相关项目，欢迎聊一个真实案例：你负责哪一段、做了哪个关键改动、结果如何、后来卡在哪。

我最想交流的是：当获客已经能带来客户，下一步如何靠产品和班底把生意推得更远。这也是我接下来想和增长搭档共同解决的问题。
