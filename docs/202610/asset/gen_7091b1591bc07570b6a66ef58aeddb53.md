# 律师嫌6万小案不接，我用AI陪跑8个月，最后拿到67,555元赔付

[PRE0]

先说这案子适合谁：如果你正被物业或保险公司压价，想找律师又被嫌标的太小，这篇值得看。它不适合把维权全丢给AI的人。8个月里真正干活的是作者自己：拍证据、录音、投诉、寄EMS。整套方法里最该学的是把一份报价拆成17项，逐条对账，把一句“赔太少”变成对方没法糊弄的具体问题。也要提醒：AI会把猜测说得像定论，作者后来换了Kimi，并且坚持原始材料和AI分析分开。

今年1月27日，我家遭遇了一次全屋粪水倒灌。

厕所成了反涌口，污水夹着排泄物、杂物和刺鼻气味一路漫到门外公共区域。房子是2000年前装修的，柚木地板和木质装修不少，被粪水泡过之后陆续发霉、胀裂、开裂、腐烂，最后连电路也出了问题，已经没法正常住人。

[PRE1]

最开始找人粗估，修复要五六万元。后来我把损失拆成17项，正式报损68,555.20元。几个月后，物业保险回复的定损金额只有17,846.20元。两笔钱一对比，少了50,709元，只剩大约26%。

[PRE2]

9月23日，67,555元最终到账。

期间我也找过律师。一位专业方向比较匹配的律师了解情况后说，如果事实和材料够充分，这案子本身不算特别复杂，可以考虑自己起诉；如果由他们完整代理，一审最低大概25,000元，二审还要12,500元起，找他并不划算。后来我又去百度地图找很小的律所，有些门面看着真像“小卖部”，本以为一万多能不能做，结果问下来，6～7万元的案子人家根本不接，嫌浪费时间。

那时我真切感到，普通人维权太难了：时间、法律知识、钱、胆量、心力和谈判能力，少一样都难。所以后面大量事情，都是我自己结合AI一步一步做的：从现场留证、整理损失，到准备沟通、投诉、起诉材料、检查协议，再一直跟到钱实际到账。

下面按真实过程，把这8个月重新拆一遍。

## 一、用AI配合留证，先把责任厘清

1月27日下午，物业通知我们家里“爆屎渠”了。我回到房子时，看到的已经不是普通漏水。粪水从屋内厕所往外反涌，混着粪便、垃圾和污物，一直蔓延到屋外公共区域。

当天家人先开始清理，我也把室内受损、屋外公共区域、物业处理过程拍了下来。第二天，也就是1月28日，厕所又翻涌了一次。除了屋里情况，我后面还继续拍楼下化粪池、检查井、开挖和处理过程，把当时能看到的设施状态尽量留住。

[PRE3]

[PRE4]

事故一发生，我就开始在豆包里问这件事。为什么不用其他AI、不用GPT？因为我认为豆包在处理国内常规事件时，会有更接地气的数据资料，而不是国外模型。

我最开始问得很直接：

> 我家里爆屎渠了，我家里全是柚木地板，现在地板全部都废了。我现在可以怎么争取我的合法权益，争取最大赔偿？

[PRE5]

现场每多出现一个问题，我就继续往下问：哪些地方一定要拍，物业人员来了以后要留什么，化粪池、检查井和公共排污设施之间是什么关系；柚木地板泡过粪水以后损失怎么记录，清理、消毒、防水、电路这些后面要不要算进损失。AI前期给我的作用，主要就是不停提醒我还缺什么。现场照片、视频、物业沟通、受损区域以及后续清理和施工过程，只要当时没留下，现场一清掉，后面就很难再补回来。

通过一轮取证和豆包给出的分析结论，可以确定我是100%无责任，而物业必须承认100%的事故责任。

关键原因有几点：

1. 公共化粪池和管网属于物业的法定维护范围，这是法律强制规定。物业服务人应当按照约定和物业的使用性质，妥善维修、养护、清洁、绿化和经营管理物业服务区域内的业主共有部分，维护基本秩序，并采取合理措施保护业主的人身、财产安全。这次事故源头是公共化粪池堵塞导致粪水倒灌，故障点完全发生在业主共有设施范围内，天然属于物业的法定维护责任范畴。
2. 物业存在明确、可举证的管理失职，过错是完全的。核心物证是化粪池主清掏口被违规封闭。清掏口是化粪池日常维护、疏通时的必备设施，被封闭后客观上无法开展正常清掏作业。这直接证明物业长期无法履行维护义务，管理失职是既成事实，不是“没做好”，是“根本没法做”。
3. 你方无任何致害行为：没有私自改造公共排污管道，也没有向管道排放建筑垃圾、异物等可能导致管网堵塞的行为；对方同样拿不出证据证明你存在过错。
4. 不存在不可抗力：本次事故是长期维护缺失逐步导致的，不是地震、特大暴雨等不能预见、不能避免的自然灾害。

现场处理完以后，下一步就是把损失真正算成钱。

## 二、把五六万元粗报价，拆成17项正式索赔清单

现场处理以后，接下来要解决修复问题。当时找熟人装修队粗略看过、打过价，房子要恢复下来，大概需要五六万元。

[PRE6]

根据我做过超过400场宴会项目的经验，不能真拿这张草稿纸去跟物业和保险谈，肯定不能只说一句：“修房子大概要6万。”对方只要问一句“这6万是怎么算出来的”，后面就很难继续。

如果一场宴会最后总价是5万元，肯定不会只写“宴会：50,000元”，正常都会继续往下拆：菜品多少钱、桌椅多少钱、灯光多少钱、布置多少钱、人工多少钱，最后这些项目加起来才是总价。

这次我也按同样方式处理。我把前面已经留下来的房屋损失、现场照片和需要恢复的区域交给AI，先把地板、木作、墙面、清理消毒、防水、电路等拆成可以逐项核对的损失项目，再根据房屋实际情况去核哪些确实存在、哪些应该合并，以及对应的修复价格。

[PRE7]

表格其实也不是我做的，我只是把疑问和需求告诉豆包，由豆包直接给出方案、报价，我再复制粘贴到Excel里。豆包按照我的意思给出了很细的报价，还指出了手写单的错漏，确实让我很惊讶。

这里还有一个实际问题：房子装修很多年了，很多木地板、木饰面不可能再找到当年的购买发票。所以我报损时处理的不是“几十年前这块木头买了多少钱”，而是现在已经坏掉以后，按照现在的市场价格，把损坏部分恢复到正常使用状态需要多少钱。

这个问题我也跟豆包和其他AI大模型讨论了很多回合，最后得出结论：

1. 我们的诉求是依法办理，不是狮子开大口去博取超额赔偿。
2. 豆包实际上比较掌握现在的材料费用、人工成本等情况，可能是跟土巴兔或其他装修、家装工程有一定数据交流。
3. 关于“修复价格”，按照《民法典》第1184条，财产损失按损失发生时市场价格计算，迟延赔偿产生利息，而不是按照30年前的建造价格赔偿。这也是我们后续“维权、谈判”的基础之一。

最后，原本只有“五六万元”这个大概数字的维修费用，被拆成了17项，合计68,555.20元。

4月7日，我把这份报损清单正式提交给物业。从这里开始，后面再谈赔偿，就可以直接拿着具体项目核：哪些算了，哪些被删了，价格又是怎么计算的。

## 三、68,555.20元报上去，第一轮只回来17,846.20元

报损表交上去以后，又等了几个月。到7月，我看到对方发回来的一份Excel。

总金额：17,846.20元。

而我提交的是：68,555.20元。

直接少了：50,709元。

也就是说，对方这张表最后只剩下我原始报价的大约26%。

我开始把这张Excel一项一项往下看。不是简单把所有项目统一打个折，而是不同地方分别往下减：表格里有30%折旧，部分防水项目被剔除，墙面、木饰面有些没有进入，清运费用被压低，还有一些我认为恢复房屋必须做的项目，也没有按照我的报价计算。

[PRE8]

但除了金额，我当时还一直追一个问题：为什么保险公司从来没有到现场真正看过？物业可能回传了图片给保险公司，但这种情况下保险公司一次都不亲自来现场？不单我家里的情况没看过，连化粪池现场也没有看过，因为化粪池早就被修复了。由此可以判断，保险跟物业肯定有“某些默契”，也从侧面反映他们对本事件的态度和责任情况的拿捏。掌握这些信息，也对我后面对物业、保险公司的谈判博弈有重大意义。

到了7月，我手上的现有沟通记录里，没有看到保险人员在事故发生以后到现场查勘的记录。前期很多信息也是通过物业转述给我的。可这时候事故现场早已经清理了，很多东西已经不可能重新还原。

所以我一直在追：如果没有真正看过事故现场，这个17,846.20元到底是怎么定出来的？

豆包给出的解释是：这是财产险理赔行业标准化的第一轮报价策略，不是针对你个人，也不是真的认为你的损失只值这么多。核心目的是用“低位锚定”压低你的心理预期，筛选掉“不懂、怕麻烦、耗不起”的维权者，最终实现降赔。26%左右的比例是行业常规的首轮报价区间，不是随便算出来的。

对方的报价逻辑拆解下来，刚好对应不到3成的比例：

1. 只算主材，删除所有施工与配套成本。我的报价包含拆除清运、地面找平、防潮处理、人工、辅材、墙脚修复、消杀等全部必要工序，对方全部直接删除，只保留“地板主材”这一项作为计算基数。按总报价里地板主材约3.5万元计算，对方只在这个基数上打折。
2. 强制套用保险内部折旧规则。财产险理赔通用的内部标准是“家装5年折旧期、每年折旧20%、残值率5%”，也就是装修用满4年就直接折到原值的20%～25%。我家装修如果投入使用了4年左右，3.5万元的主材折完刚好在1.7万～1.9万元区间，和17,846元完全吻合。
3. 默认删除所有间接损失。临时安置费、资金占用利息、诉讼费这些法定赔偿项目，在保险首轮报价里默认完全不算，连提都不会主动提。
4. 预留谈判缓冲空间。首轮报价会在对方内部底价基础上再打7～8折，留出后续“申请、上报、让步”的空间，方便后续演“已经尽力争取了”的戏码。

看懂这套算法，才知道后面不是简单讨价还价，而是要把每一项损失、每一道工序、每一个法律依据都摆到桌面上。最终，这场从1月打到9月的维权，以67,555元到账收尾。
