# 02 建立算账的能力
作者：龙哥

不少自由单从业者，月表收入看似可观，年底盘点却所剩无几。症结不在于赚得少，而在于从未搞明白钱流向了哪里。我过去也不记账，只看月末账单，业务开支与生活开销混在一起，漏洞根本看不见。钱进来是真的，结余却越来越薄。

以滑雪教练为例，表面是“上课一天结一天账”，背后实则绑着雪票、交通、住宿、装备损耗等硬性支出。若不先剔除这些，看到的只是流水，不是利润。如今每笔成交前，我先扣除刚性成本再看净赚。📕做高客单引流，我没有花钱买公域流量，我的投入是雪票、路费、住宿本身，这属于生产性投入，和日常吃喝是两回事。

## 核算单元：把一单当成一个月来算

我采用的口径很原始，核算单元就是“每一单”。一单一行，写明这单收入是多少、雪票花了多少、路费住宿花了多少，最后落到净利。月底汇总，单量、总收入、总成本、总利润一目了然。

为何要细到单？因为只有细到单，才能判断哪单真正赚钱、哪单只是耗时间。汇总是结果，单笔才是原因。

## 定金：一次解决两层风险

我习惯先收定金，它同时处理两个问题：

第一，定金是这单的启动资金。雪票、路费、住宿都要提前垫付，定金到账，生产性投入才有来源，无需动用自有资金。

第二，定金抬高了客户毁约的成本。付过款后临时改期就会犹豫。这不是心机，是自由职业给自己加的一层风险对冲——被预约的时间一旦售出就无法回收。

尾款我固定在开课前一天结清。这样不易出现尾款收不回的情况，双方预期也更稳。

如果你也在做按天计费的工作，不妨把定金写成规则。它守护的不仅是现金流，还有时间边界。

## 记账后的另一个陷阱：把精力花在不该省的地方

记账后资金路径清晰了，却有一段时间我走向了另一个极端——为省钱过度比价。反复找便宜住处、对比机票、连一件小物都要挑选半天。省下的可能是几十上百块，自己却被耗得精疲力尽。等到真正需要决断的大事出现，比如是否接大单、是否投钱学新技能时，反而没力气、判断失准。

# 03 保持对抗旺季幻觉的清醒

自由职业最常见的翻车点，我和大多数季节性从业者都踩过——旺季幻觉。

雪季连轴转，每天都有钱入账，容易产生飘飘然的感觉：现在赚钱太容易了，花一点无所谓。打工时期“太累了犒劳一下”的念头并未消失，只是换了说法：看到好看的新雪服就下单，明知旧的还能穿；为了颜值换双新雪鞋，结果磨脚穿不了又得重买，一笔支出变成两笔；每天一杯二十块的奶茶，再加上频繁社交，一下子就几百块没了。当时总能自洽：雪季这么累，对自己好点很正常。

真正的打击永远在淡季。雪季一结束订单归零，连续几个月收入断档。看着存款一点点减少，我甚至看不上一天三五百的小单——胃口被旺季养大了，面对淡季业务反而提不起劲、动作变形。算总账时才发现，明明赚得比以前多，留下来的却远低于预期。

反复的淡季让我钉死了一个认知：“对自己好一点”是对的，但要分清是真正的成长投入，还是消费欲望的陷阱。旺季赚的钱，其中很大一部分，其实是借给淡季那个零收入的自己。

## 一个真正改决策的例子

我特别爱买鞋，运动鞋、撞款的家里一堆。每次都觉得“这双不一样”，买回来穿几次就闲置了。这就是典型的重复性消费——爽的是购买动作本身，而不是穿鞋这件事。

用《花钱的艺术》对照后我改了规则：鞋子不再是想买就买，而是变成目标奖励——达成某个目标后才允许自己买。改动不大，却实打实降下来了重复支出，而且买的时候更开心，因为是兑现承诺，而不是冲动。

投资上也是同样的逻辑。我不以博弈为目的，配置以低风险基金理财为主，比如标普500做定投。比例并非一成不变，会随经济周期微调。有些阶段多投、有些阶段少投。意义不在于多赚多少钱，而在于让花钱和投资都脱离情绪。旺季能克制冲动，不是因为意志力强，而是因为有一套可用的判断工具。意志力会耗尽，工具不会。

# 04 建立穿越淡季的结构与内核力

自由职业最磨人的不是辛苦，是不可控。

客户原本约好的时间可能临时延后。曾有客户付了小额定金预约元旦三天，我因此推掉另一单，结果他临时改期，我的档期空了，另一单也接不上。甚至说好连上七天的课，中途会被拆成两次三次，时间变得碎片化。寒假课多得排满，学期中却几乎没课。这种起伏无法控制，却极耗心力——没单时怀疑自己，有单时又怕错过。接受不确定性，然后用结构兜住它，是第一课。

## 我用三个动作搭起结构

- ① 写死铁律：旺季赚钱，按淡季标准生活。即便月入数万，日常开销依旧按淡季最低标准规划。坚决克制冲动消费，不盲目换装备、不攀比，砍掉烟酒、奶茶和无效应酬。把装备全部归为生产资料，非损坏非刚需不更换。

- ② 每笔进账先切四块，比例在《小狗钱钱》基础上结合淡旺季调出来，绝不直接进个人账户：

  - 30% 绝对不动的安全垫，冻结起来保障未来6到12个月零收入也能从容；
  - 20% 未来固定开销预留，锁定房租、基础吃住等硬成本；
  - 25% 事业再投资与装备成本，覆盖雪票、路费、住宿、装备更新和学习费用；
  - 25% 稳健投资理财，进入低风险账户产生复利。

  切完之后才知道本月能用多少，剩下的才是生活费。记账必须与分配配套，我会单独记一本生活开销，不是自责，而是看清钱流向。不记账的后果我太清楚：总觉得“就花小钱”，累积下来其实不少。有了账本，下月消费才有依据。

- ③ 把固定成本变动化。起步期不背固定成本，不租昂贵场地、不设高额底薪，合作采用按场次、按项目结算。有需求才付费，没业务时零成本潜伏。打工是公司兜底固定成本，自由职业是自己承担盈亏，所以我不签长期固定合约、不承担闲置人力成本。让成本随需求流动，不被固定负债锁住现金流。

## 最容易被忽视的成本：五险一金

自由职业常默认放弃五险一金。刚开始没感觉，后来想到医疗和房贷就发虚。于是我逐项补上：先交医保作为基础兜底；再配百万医疗险防止大病清零积蓄；公积金也办下来了，原以为自由职业没戏，后来发现灵活就业人员也能缴存并用于贷款。各地政策不同，值得花半天查清楚，这是几十年的复利问题。自由职业不是不要保障，是自己给自己发保障。

## 以阿米巴经营角度分析个人时间收入、人工成本与总劳动时间

阿米巴经营的核心是把单元拆到最小，让每个单元像独立公司一样核算。关键指标是单位时间附加值。

书中公式：单位时间附加值 = （销售额 - 除劳务费外的所有经费） ÷ 总劳动时间

个人对应：

| 概念 | 阿米巴原意 | 个人对应 |
| --- | --- | --- |
| 销售额 / 收入 | 对外销售 + 内部交易 | 实际创造的收入 |
| 经费 | 材料、设备折旧、水电等 | 创造收入产生的可控费用，交通、工具、培训等 |
| 附加价值 | 销售额 - 经费 | 收入 - 可控费用 |
| 总劳动时间 | 工作 + 加班 + 准备 + 公共时间 | 投入的总工时 |
| 单位时间附加值 | 附加价值 ÷ 总劳动时间 | 每小时净价值 |

公式通俗说：我干一小时到底赚了多少钱。对自由职业很重要，因为容易只看单价，忽略耗时。同样2000块，花4小时和花40小时是两门生意。

现在我会算自己的时薪，它帮我做三个判断：这单值不值得接；钱该花在哪，比如花钱买别人的时间就是提升自己单位时间附加值；该往哪走，短期时薪低但能抬高未来时薪的事值得投入。

阿米巴里有句话：不懂会计就无法成为真正的经营者。经营像开飞机，会计数字是仪表盘，不看仪表盘不知道飞向何方。我不需要成为会计，但必须看懂自己的数字。

# 05 建立立即落地的执行力

纸上得来终觉浅，差距拉开的永远是做过的人。

道理谁都懂，卡住的人都在同一个地方：想报价却不敢开口，想发内容却一直没发第一条，想找项目却总说再准备准备。一准备就是一年。我也一样，刚开始总担心报价高没人接、内容没人看，结果自己把自己吓退了，旺季也被浪费。

后来我逼自己做两件事：把“想”拆成立刻能做的动作，想接客户就先联系一个，想涨价就先报一次新价格，想发内容就先写第一段；把探索变成日常，主动看 AI 怎么用，看别人怎么做生意，顺着痛点找需求。淡季拿来充电，旺季抓紧赚钱。日积月累的坚持，终将胜过三分热度的假装努力。

# 06 建立内化的潜意识：把自己当成有钱人的脑袋

方法再好，内心不信也不会落地。真正的改变从认知开始。

以前我对钱是焦虑被动的，现在给自己一个默认设置：我有一颗有钱人的脑袋。行为上高度自动化：拿到钱先算账，不算清不花；算好了给自己一个小奖励，正反馈告诉大脑这样做有好处，保留人性别把自己逼到崩溃。

这套东西改变的不是意志力，而是我和钱的关系。安全垫给我的是底气：能选择不做，能抓住可承担的机会，能更有安全感地体验事业，淡季也能用来学真正感兴趣的东西，而不是慌着找钱。

必须老实说：没有存款，我不会有今天的认知。生财的会费大约3000元，是我用存款交的。正因为有存款，我才得以加入，看到更多赚钱方式，也更早接触到 AI。换个版本，如果当时月薪2800、手里一分钱没有，那张门票要么挤不进、要么得刷花呗。那我大概率仍在用未来的钱买今天的机会，被利息拖住。所以存钱存的从来不只是钱，是选择的权利。它决定你是被生活推着走，还是有资格主动挑方向。
