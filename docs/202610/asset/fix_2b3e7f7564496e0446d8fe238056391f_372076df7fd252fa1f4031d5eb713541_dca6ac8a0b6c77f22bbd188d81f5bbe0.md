- 招数一：地板价当锚点
这是套路的核心，用的是行为经济学里的锚定心理。先丢一个极低的数字做参照，后续所有讨价还价都会不自觉围着这个参照点浮动。举例来说，内心原本觉得值六万，对方一开口就是一万八，很快底线就会从六万往下调到四万、三万五，等到对方“让步”到三万五时，会觉得翻了一倍多还能接受，可实际上这个数离依法应得的水平还差很远。绝大多数没走过理赔的业主，潜意识里会把对方的报价当成标尺，而不是把法律规定当成标尺。

- 招数二：用低价把耗不起的人筛掉
本质上是一种价格歧视。首轮极低报价的用意，是把维权者分成两拨：不懂法、时间成本高、怕麻烦的人会觉得打官司太折腾，好歹能拿一点，直接接受低价，对方用最小成本结案；懂规则、有精力、愿意走程序的人才会继续往下谈，对方再逐步加价。等于用低价先甩掉最容易搞定的人，只对少数硬骨头加价，整体理赔成本被压到最低。实务中，这类物业侵权理赔，大约六成到七成的业主会在首轮或二轮报价后妥协。

- 招数三：话术探底
第一轮报超低价，同时搭配“这是公估行业标准”“保险理赔就是这么算的”这类说辞，核心目的是探查对方对规则的了解程度。如果只是争执“太少了”，说不出具体法律依据，对方就知道外行，后续会继续压价、拖延；如果直接点出“保险内部折旧规则不能对抗第三方受害人”“污染性损坏不适用自然折旧”，对方立刻知道门清，后续报价涨幅会非常快。

- 招数四：降赔与收益挂钩
不管是保险公司理赔员还是第三方公估公司，核心绩效考核指标就是降赔率，赔得越少，个人奖金、公司服务费越高。所以首轮必须报最低价，这是标准化作业流程，不是针对个人。哪怕诉求完全合理、贴近市场，他们也必须先砍到最低，这是岗位要求。

豆包此前总结的首轮定损报价四点策略，本人后面几乎一一撞上：
低位锚定：先打掉你的心理预期
成本筛选：把“耗不起”的人直接筛出去
信息测试：摸清你对规则的了解程度
KPI 导向：降赔直接和收入挂钩

### 让低价好咽的五种配套做法
为了让低价看起来合理、促成妥协，对方一定会配套操作，笔者遇到的全部命中：

- 磨时间：不回复、慢回复、“走流程”“上报审批”，用时间消耗耐心，让人觉得为这点钱折腾不值；
- 踢皮球：物业推保险，保险推公估，公估推物业，永远找不到能拍板的人，抬高沟通成本；
- 术语包装：张口就是“理赔规则”“行业标准”“折旧规定”，用听不懂的专业词制造权威感，让人觉得本就该如此；
- 冷处理：群里装死、电话不接，摆出“就只能出这么多，你爱要不要”的姿态，逼人主动降价；
- 虚假共识：暗示“别的业主都是这个价赔的”“打官司也拿不到更多”，用虚假的共识让人怀疑自己的主张。
