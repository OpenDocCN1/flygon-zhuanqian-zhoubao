## 冷启动到万粉

正式动手是 3 月底左右，当时纠结是先做产品还是先做流量，想不出答案就先走知识付费路线。我报了小胖老师的深海圈，也混进了 X 上的几个付费群组。通过花钱连接已有成绩的人，我判断 SaaS 产品周期太长，不匹配我需要快速正反馈的性格，于是决定先做流量。

起号文的参考对象是圈友志辉的帖子，我手上也有可用的标签：大厂 T11、年薪百万、35 岁离职。加上找了一批大 V 帮忙转发，爆发几乎是水到渠成的事。那篇动态给我带来了 2000 多粉，冷启动算完成。

和多位头部玩家聊下来，大家共识是：万粉在 X 上已经够用，往上走 ROI 会递减。做到万粉只需要吃透我 5 月份发的那篇帖子。
简单说 X 破万的经验就是：持续发帖，发有价值的内容。

### 蹭热点
哪里有流量就往哪里靠，需要一点网感。比如孙哥做中转站我就写中转站，黄推爆发时我就做黄推拆解，本质上就是 SaaS 里的抢新词逻辑，流量自然来。
[PRE8]
这套组合拳被我用顺手后基本每天百万曝光，涨粉 1000+。从 1 万到 3 万只花了一个月，增速过快也带来攻击和反噬，说明流量过大并非完全是好事。

### 圈友可借鉴的
上面这套打法现在依然能用，但要注意节奏，别看到涨 100 粉就叠一次。更稳的参考是 @AdrianPunk115 的方式，开源+社交。她持续开源作图提示词并坚持长文输出，punkskill 在 GitHub 累计 1000 多 Star，在各大 X 群高频互动，最近社群 3 天涌入 300 人，效果很明显。

## 3万-5万粉

这一阶段我放弃了组合拳，回到了擅长的领域。我本职工作之一是需求沟通，很会把技术问题讲给非技术人听。于是我做 AI 小白教程，每天都有新模型和 Agent 上线，素材源源不断，再配合一点热点，比如孙哥景甜事件，我就用技术视角写如何用 ComfyUI 复现孙哥视频，那篇播放接近 200 万。
[PRE9]
连续多篇百万级爆款后，我就站上了 5 万。

### 圈友可借鉴的
到这个阶段必须混圈子，单打独斗很难上 5 万。可以参考 @isnail，他经历过多次封禁、限流和黑屋，依然坚持开源👸号玩法和社交细节，把在👸号得到的成果毫无保留分享，同时在多个博主微信群高频刷脸，涨粉是必然结果。他的近期复盘可供参考。

## 5万以后
再往上基本都是各路神仙，中推顶流宝玉也就 20 多万，天花板并不高。我的建议是转向多平台运营，一鱼多吃，我自己也在这么做。

#### 商单
懂 X 的都知道，商单价格按粉丝量和影响力从几百到上万不等，我目前的报价基本在 500 美金到 800 美金之间浮动，作为新人自媒体已经很满意了。
X 上 2000 粉左右就能接到商单，而且很多甲方在海外，不像📕要抽成，所以做一个万粉 X 号回报很高。

#### 社群
例如我在 Flowus 发布过一份付费的 X 增长文档，本质是生财 5 月份帖子的升级版，售价 199 元含答疑群，卖出上百份。

另外 afternoise 社群是我和 X 上的朋友一起做的 AIGC 内容群，3 天进来 300 人。

在 X 上做出成绩后咨询需求很多，按时间定价即可，我给自己定的是 1000 元/小时。

玩 X 的都懂太多案例了，build in public，一鱼多吃。有产品就推自己的产品，没产品就把自己当产品卖。推荐对标哥飞、yihui、卫斯理，我参考的是卫斯理，把自己产品化，bio 挂了网站：

### 讲几个 X 才能玩的流量案例
比如我帮朋友做的 Workbuddy 代理公司拉人，丢几个二维码一天能进 1000 人，我个人效率比他们一整个公司在朋友圈发帖还高。还帮圈友卖茶叶，客单价几千，单条推文也能出几单。大家都玩过朋友圈营销，X 就是一个超级大的朋友圈。
[PRE16]
### 资源链接
X 最值钱的地方是人脉链接。举两个例子：
我在 X 认识了潮汕商会的大佬，他给我对接了商会资源，我本身有 FDE 技能，很快触达优质 B 端客户，X 账号也起到背书作用，信任建立很快，大佬们给钱也很痛快，一个小交付就成交了。
[PRE17]
我还认识了币圈做过矿场的大佬，他在折腾 b300，告诉我本地算力会涨价，于是我在 8 月份 dgx spark 暴涨前入手了几台，当时价格 30 出头，现在 50k 了。
[PRE18]
类似案例还有 170hx，我们是最早在 X 上讲这个矿卡的人，当时囤了一批，现在翻倍，本质是小圈子的信息差变现，没有 X 这个平台很难链接到这些人。
[PRE19]
再说一个：国内太卷大家都想出海找增量，一大批牛人来到 X 都是 0 粉起步，以前付费都难接触到的人，现在一个转发就能轻松建联，这个杠杆非常大。

## 总结
半年下来，我经历了账号成长的全部阶段，也见过太多人来又走。如果用一句话概括：X 的核心价值在于资源和人的连接，线上认识、线下交换信息差，信息差加执行力就是收益。做一个万粉的 X 账号，是人生 ROI 很高的选择之一。
