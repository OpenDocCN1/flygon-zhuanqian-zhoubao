# 零编程背景也能用微信小程序做到六位数：一次真实复盘
作者：龙哥

大家好，我是圈里待了七年的蓝子鱼。自从第一次跟随生财做📕航海之后，我就一直在这个渠道持续深耕，也整理发布过📕和抖音的教育资料合集。每次圈子里冒出新风向，我都会先问自己能不能落地。今年AI做产品的讨论非常密集，我就去实践了一把：先用AI把想法做成小程序，再在📕完成销售。半年多下来，我累计上线了六款微信小程序，首个作品上线后三个月内，平台带来的收入突破十万元，其余几款也陆续开始带来现金流。

到现在我依然看不懂程序，数据库、云函数这些名词也讲不清。但我发现搭建小程序并不一定要懂这些。有Claude Code、Codex、Workbuddy在手，只要能输入文字、能提供视觉参考，就能把需求交给模型去实现。

此刻真正卡住人的多半是心态。把环境搭好之后，基本就入门了。会聊天、会输入，就能让AI去做事。包子老师说过，GPT的上限超过清北的博士生，把事情交给它就行。我就是这样起步的。航海家线下的两天闭关，让我连续高强度用AI，回程后我才真正把它当成生产力。

**一、为什么要做自己的小程序**

去年我在📕和抖音做教育资料，之前也写过项目复盘。从目前来看，资料类依然是新手起步的好赛道。但小程序出现后，我认为对需要即时反馈的内容来说，这是降维打击，用户体验明显提升，在📕上讲卖点也更容易打动人。

举个例子，面试题库。传统形态是一份文档发给用户，自己回去看。看了也不一定会，价格很难上去。做成小程序就可以在用户选错或卡住思路时逐步引导，做错的题目自动归入错题集，并提示该题考察的点是什么。

再说防盗版。教育资料最怕的就是倒卖。你定价50元，闲鱼上1元就能买到，维权成本很高。做成小程序提高了搬运门槛，而且内容可以随时更新。

**二、怎么做才更容易赚钱**

我做小程序的期间也跟很多同行交流过，感觉靠小程序赚钱，最难的不是制作，而是找到用户愿意持续为之付费的抓手。我的几款产品都走订阅收费，不靠流量主。一个订阅用户的价值，能抵上几万日活小程序的流量分成。

我给自己总结的一条经验：变现效果大概是需求占六成、运营占三成、制作占一成。制作是最不费力的环节，后面我会展示我是如何做的——主要是文字描述加截图，按照模型的步骤执行，别被制作吓住。

也有技术很强的朋友跟我说，UI做得很漂亮，适合接B端定制。但UI再好，不解决真问题也很难持续变现。只要能解决真实痛点，哪怕界面普通，用户也会买单。

好比两家餐厅：大商场里的装修精致、服务员漂亮，但口味一般；小巷子里一家装潢平平，菜品却好吃。让人回头的是后者。

因而做小程序，找需求特别关键。要区分口头说想要却不付费的需求，和不得不解决的刚需。判断依据很简单：是否真的愿意花钱解决。当然，如果你是走流量主的思路，逻辑会另说。

市场上常见的伪需求：嘴上说想要，实际不用、不付钱也不传播，更像一种愿望或情绪。真实的痛点是场景明确、足够痛，用户愿意花时间花钱去解决，是“必须做”，不是“好像不错”。

还有两个概念值得留意：痒点是理想化自我，想要变好；爽点是即时反馈，做完立刻舒服。真实需求往往是痛点足够强、可被满足、用户愿意付出成本。光有痒点很容易做成伪需求。

我挑选的都是不得不处理的点，比如考试、与赚钱相关的场景。找需求的方法我之前也写过，简单说：

1. 找到已经卖得不错的资料或工具，看看能否用小程序再做一遍。
2. 找那些必须学会、必须解决的难题，比如四六级、各种资格考试、实操技能。
3. 健康、变美相关，观察身边人曾为之付费的东西，是否能用小程序承载。

**三、起步的做法**

**1、准备工作**

这部分在小程序航海手册里有详细说明，结合我的实践列几项：

- 能接收验证码的邮箱，用于注册小程序的AppID
- 用于设管理员的身份证，一张身份证最多绑定五个管理员
- 如需接入AI能力，最好有个体或公司主体
- 能够辅助制作的工具，我用Codex，海内外可用Workbuddy
- 电脑版微信开发者工具

**2、用Codex制作小程序**

我用Codex做。先把产品想做什么、面向谁、解决什么问题、希望有哪些功能告诉模型，让它先出规划。方案不满意就继续调整。

**四、推广方式**

做流量主的小程序可以发朋友圈或航海群，积累500用户后可开通。但我做的是付费用户，不会让非目标人群知道具体产品。

我目前在做的职场向产品，解决工作中的问题。定价一年29、39、49，功能不同价格不同。

**1、👸号贴图**

贴图是微信目前比较鼓励的形式，小程序后台与贴图联动顺畅，也不会被判定站外引流。

**2、📕种草**

📕是冷启动的好平台，我刷到很多小程序都是在这里起来的。可以分享开发经历和产品用途，做一篇种草。

最后总结：不会写程序从来不是障碍，关键看敢不敢开始。找准用户不得不解决的需求，用AI把产品做出来，再用运营去卖——制作只占一成，需求和运营占九成。如果你想试，先把工具装好，打一行字给AI，你就已经上路了。
