前几天刷抖音时看到一条在讲 GitHub 上的《高性价比人生指南》，讲怎么活得更久、怎么少花冤枉钱、怎么别把自己搭进去。点进去看完源仓库，内容很扎实。

于是我把它搬成了一个可用网站：howtolivebetter.net。

上线一周，访问量已经超过 8000。原作者把站点挂到了仓库首页，还有网友主动去论坛安利。整个过程和数据我全摊开了。

作者反复强调这是一份备选清单，不是任务表，挑一两条就算赢，他自己也沒做到大部分。我想的就一个点：别只收藏链接，把它变成能打勾的清单。把想做的事放进待办，做到了就划掉，好奇的先收藏，一眼就能看出进度。

读一遍很容易，真正执行才难。我想做的只是把“开始做”这一步降到最低。

### 高性价比人生指南，我把它做成了检查清单

littlebena · 9 月 28 日 · 2570 次点击

[PRE3]
GitHub 上有个中文项目，三周涨了两万星。它不是代码，是本电子书，叫《高性价比人生指南》。核心讲三件事：怎么长寿、怎么省钱、怎么避坑。

市面上的人生建议太多，多喝水、早点睡、别乱花钱，听起来都对，却很难指导决策。这本书的做法不一样。612 条建议，每条格式统一：

成本：需要多少金钱、时间、说服成本
收益：一句话总结能换回什么
证据等级：A、B、C 三档
来源：只引论文和官方文件，并附链接
A 级通常有荟萃分析、大型试验等强证据。全文 A 级 413 条、B 级 150 条、C 级 49 条，有争议的条目会单独标注。

作者在 README 里也写了：这是备选单，不是必做清单。挑一两条就算数，他自己也没完成大部分。

我觉得单独看书很容易忘，所以做了个工具型网站 https://howtolivebetter.net/
- 把人生说明书浏览一遍，把想做的单独建个 to-do
- 已完成的可标记，看整体完成率
- 对感兴趣的内容先收藏，后续集中查看

先做到这样，后续会继续围绕健康和高性价比做迭代。

评论区声音很杂。有人说「人生无法计划」，也有人说「世界没有两片相同的雪花」。二楼骂得最狠，大致是：这不就是 GitHub 上一堆 Markdown 仓库的区别吗？遇到问题直接问 AI 不就行了？

有几个点值得细说。

- 被原作者收录，是最值的一步
GitHub 带来 1244 次访问，几乎全来自 README 那一行链接。而且不像 V2EX 只火一天，前五天每天都有两三百次，很稳定。一个 3.7 万星的仓库，每天都有新读者，这一行链接等于长期入口。

- 必应远超 Google
必应搜索带来 1623 次，Google 只有 45 次。用户 75% 在国内，Google 打不开。百度这一周只带来 6 次搜索访问。做国内站，必应收录必须重视。

- PDF 里留链接很有效
PDF 和 EPUB 里我放了网站链接，这项带来 251 次访问。1320 次下载里，有人看完 PDF 又回站了。产出物里埋个回链，成本几乎为零。

- ChatGPT 也能导流
ChatGPT 带来 58 次访问。量不大，但很可能是有人问 AI 相关问题时被推荐到这个站。

- 社区帖子快热快凉
V2EX 第一天 278 次，第二天 110 次，第三天 43 次，到 10 月 3 日只剩 4 次。社区适合冷启动，撑不起长期。
