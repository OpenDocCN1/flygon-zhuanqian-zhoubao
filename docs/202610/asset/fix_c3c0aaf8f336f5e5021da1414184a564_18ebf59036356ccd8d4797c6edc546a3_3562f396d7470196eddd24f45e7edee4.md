## 从起步到关注过万

动手时间是三月底，当时在做产品还是做流量之间拿不定主意，于是我先走知识付费路线。报了小胖老师的深海圈，也加入了 X 上的几个付费交流群。跟已经跑出结果的人付费链接后，我判断软件订阅类项目周期偏长，不符合我需要快速正反馈的习惯，于是决定先做内容引流。

起号文的对标是圈友志辉的笔记，我本人的可辨识标签也很清晰：大厂 T11、年薪百万、35 岁离职。再加上邀约一批头部用户帮忙扩散，传播几乎是顺理成章。那条动态带来两千多关注，起步阶段算完成。

### 蹭热点
哪里有流量就往哪里靠，需要一点网感。比如孙哥做中转站我就写中转站，黄推爆发时我就做黄推拆解，本质上就是抢新词逻辑，流量自然来。

[PRE8]
这套组合拳被我用熟后基本每天百万曝光，增粉一千以上。从一万到三万只花了一个月，增速过快也带来攻击和反噬，说明流量过大并非完全是好事。

### 可复制的点
上面这套打法现在依然能用，但要注意节奏，不要看到涨一百就叠一次。更稳的参考是 @AdrianPunk115 的玩法，开源加社交。她持续开源作图提示词并坚持长文输出，punkskill 在 GitHub 累计一千多个 Star，在各大 X 群高频互动，最近社群三天涌入三百人，效果很明显。

## 三万到五万关注

这一阶段我放弃了组合拳，回到了擅长的领域。我本职工作之一是需求沟通，很会把技术问题讲给非技术人听。于是我做 AI 小白教程，每天都有新模型和 Agent 上线，素材源源不断，再配合一点热点，比如孙哥景甜事件，我就从技术角度写如何用 ComfyUI 复现孙哥视频，这篇跑了近两百万。

连续多篇百万级爆款后，我就站上五万。

### 可复制的点
