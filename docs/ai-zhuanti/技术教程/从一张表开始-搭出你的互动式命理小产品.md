# 从一张表开始，搭出你的互动式命理小产品

过去，智能工具更多承担“回答问题、生成内容”的角色；如今，把大语言模型接入飞书多维表格后，普通人也能把一个想法快速包装成可使用、可传播的产品。

无论是直播电商、门店运营、自媒体创作，还是资料整理、研究分析、日常办公，这种“表格+模型”的组合都能派上用场。它尤其适合个人创业者：数据可以批量处理，流程能够标准化，输出也能自动衔接。原本需要几天完成的重复工作，可能压缩到几分钟。

这不只是效率工具，也是一种低成本试错方式。没有开发团队，也能先把创意做出来、跑起来，再根据用户反馈持续调整。

# 为什么“命理测试”容易获得传播？

年轻人接触玄学，很多时候并不是为了寻找绝对答案，而是想给高压生活增加一点轻松感。测试一下事业、感情或近期状态，既像一种自我观察，也容易成为聊天和分享的话题。

此前有人用类似方法制作“MBTI增强测试”，在短时间内批量产出大量定制化结果，并通过表格自动回传给参与者。相比传统问卷项目，制作成本更低，反馈速度也更快。

这类产品通常具备三种传播优势：

**一是内容可以规模化产出。**

提前设置“桃花指数”“水逆提醒”等主题后，模型能够根据不同输入组合出多种结果，减少重复劳动。

**二是输入与结果之间有联动。**

用户填写最近的困扰，系统可以将这些内容带入星座、塔罗或命理相关的解释框架，增强“被理解”的感觉。

**三是结果天然适合分享。**

当报告足够有趣、足够贴合个人，用户往往愿意发到朋友圈。再配合数据看板，还能观察哪些人群、标签或主题更容易被转发。

从产品角度看，它卖的并不是“神秘答案”，而是参与感、趣味性和社交表达。压力越大，大家越愿意用轻松的方式，为自己寻找一种新的解释。

# 实操部分：把创意变成可运行的产品

## 1. 先确定主题，再做资料搜集

不要一打开表格就开始添加字段。先判断产品更看重哪一点：趣味、传播，还是后续变现。

可以利用秘塔搜索查看小红书、知乎等平台上的热门表达，重点收集用户对“玄学测试”的吐槽、期待和高频需求。经过整理后，我记录下了这些方向：

挖宝玄学、祈福水晶、电子木鱼、好运壁纸、八字、姻缘、面相、摇签、紫微斗数、甲子易道、神算喵、乾坤爻。

随后从中挑出“挖宝、水晶、神算喵、乾坤爻”几个元素，继续往产品概念延伸。

水晶这个方向之所以适合，是因为此前已经出现过类似玩法：参与者填写出生日期和性别，系统输出运势说明，并根据结果推荐黑曜石、海蓝宝、黄水晶等象征性物件。这个话题本身就具备讨论度，也容易形成视觉化内容。

为了完善设定，我再借助元宝中的联网与深度思考能力，让模型协助整理产品方案。

![](img/zhuanqian_6f754716d0e9f37e1d5f4e8ed6777d47.png)

![](img/zhuanqian_3fdcd5be8b5cd88c8ca0a43f9f9276b0.png)

经过筛选和人工组合，最终形成《神算水晶喵》的产品构想：

用户填写姓名、性别与出生信息后，系统围绕八字五行进行分析，从财富、工作、情感三个方向生成2025年趋势说明，同时标注可能值得关注的月份，并推荐一种对应的水晶。

整体采用“毒舌神算喵”的角色口吻，把命理元素、轻松玩梗和互动体验结合起来，打造一个适合年轻人尝试和分享的小型产品。

## 2. 把创意拆成字段链路

有了产品设定后，下一步不是继续堆文字，而是把它拆成可执行的处理链。

可以把每个处理环节看作表格中的一个字段：

- 收集参与者信息；

- 拼接专属指令；

- 调用模型输出报告；

- 从报告中识别水晶名称；

- 根据水晶名称继续生成视觉或推荐内容。

水晶相关部分也可以采用更简单的方式：提前准备若干固定水晶图样，利用模型统一生成，再将图片放进对应字段，最后由结果区域调取。这样更容易控制输出质量。

本教程保留多个水晶处理节点，是为了展示字段快捷操作、信息抽取、指令生成和图像生成等不同用法。

# 3. 先把角色提示写清楚

在创建表格之前，建议先准备好角色设定和任务说明。初稿可以包含以下要求：

- 设定一个具有辨识度的角色；

- 说明需要读取哪些用户信息；

- 明确要分析的内容；

- 规定最终报告的结构；

- 统一输出语气；

- 预留后续引导文案。

为了让指令更稳定，可以使用火山方舟中的“Prompt优解”进行整理。入口通常在火山方舟左侧导航的Prompt生成模块，输入初稿后即可让工具重新组织任务结构。

![](img/zhuanqian_e197a6bd6ff0b53b7e300e7fdb5a3d59.png)

![](img/zhuanqian_cf4dc9353bb3528c8742b8a4ab749991.png)

优化后的提示词，建议包含以下要素：

1. 角色身份：神算喵，熟悉周易、八字、五行和水晶象征体系；

2. 用户变量：姓名、性别、出生日期；

3. 分析范围：五行概览、财富、事业、情感及重点月份；

4. 推荐任务：选择一种水晶，并解释它与分析结果的关系；

5. 表达方式：保持毒舌、轻松但不失条理；

6. 输出格式：将分析依据与最终报告分开；

7. 结尾动作：加入统一的咨询或资料领取提示。

如果需要使用变量，可以写成：

```text
姓名：{{NAME}}
性别：{{GENDER}}
出生信息：{{BIRTHDAY}}
```

为了便于后续处理，建议让模型将内容放入固定标签中，例如：

```text
<思考>
说明分析依据、判断路径和推荐原因
</思考>
<结果>
输出最终报告
</结果>
```

需要注意的是，命理内容更适合作为娱乐和自我探索，不宜包装成绝对结论，也不应替代医疗、法律或财务建议。


## 字段五：指令拼接

创建公式字段，名称设为“指令拼接”。它的作用，是把姓名、性别、出生信息以及角色设定组合成一段完整请求。

![](img/zhuanqian_749f6f423a6b43a6af59f9175daae22e.png)

如果不熟悉公式，也不用手动研究函数。直接告诉表格助手：

> 请把姓名、性别和出生日期拼接成一段完整指令，并在后面附加神算喵的角色设定、分析任务、输出格式和结尾话术。

系统会根据字段名称生成公式。

核心逻辑类似下面这样：

```text
CONCATENATE(
"请以神算喵的身份完成分析。",
"姓名：",[姓名],
"；性别：",[性别],
"；出生信息：",TEXT([出生信息],"YYYY/MM/DD"),
"。请按照既定结构输出报告。"
)
```

实际使用时，可以继续把完整任务说明、标签格式和引导文案一并放入公式。

![](img/zhuanqian_220e54d8f90dc495254090ee9eced701.png)

![](img/zhuanqian_a909b3cdeeec0614edf481ddafc8eb68.png)

## 字段六：请求文本

再建立一个文本字段，命名为“请求文本”。它主要用于承接上一列的拼接结果，也方便后续模型调用和自动化流程读取。

![](img/zhuanqian_61829ad4e84e0ae66085dfb44a5bb47d.png)

## 字段七：模型报告

新增字段后，在字段快捷入口中搜索DeepSeek，选择R1模型，将“请求文本”作为输入来源。

随后开启结果输出和自动刷新。保存后，系统会生成对应的模型结果字段。

![](img/zhuanqian_46d86157c5e4f122ffa1551da4c21c43.png)

## 字段八：识别水晶名称

继续增加一个信息抽取字段，命名为“识别水晶名称”。

输入来源选择模型报告，抽取要求可以写成：

```text
只返回报告中出现的水晶名称，不要附加解释。
```

这样，后续流程就能直接拿到干净的水晶名称。

![](img/zhuanqian_bec611db7fbb39118737e53b59b463c4.png)

## 字段九：水晶延展指令

最后，再建立一个模型字段，名称设为“水晶延展指令”。

将“识别水晶名称”作为输入内容，在自定义要求中补充你想要的任务，例如：

- 生成水晶介绍；

- 解释其象征含义；

- 输出适合报告页面的短文案；

- 根据固定视觉规范生成图片描述。

开启自动更新并保存即可。

# 最终形成的产品链路

当用户提交信息后，系统会依次完成：

填写资料

→ 拼出专属请求

→ 调用模型生成报告

→ 识别报告里的水晶名称

→ 继续生成水晶相关内容

→ 将结果呈现在用户页面

这就是一套从输入到输出的互动式产品流程。后续还可以加入结果分享、数据看板、资料领取、咨询入口等模块，让它从一次性测试升级为可传播、可迭代的小型项目。

>

> 画面风格：[写实 / 奇幻 / 赛博朋克 / 卡通]中任选一种。

>

> 配色方案：以[宝石主色，如翠绿、嫣红、湛蓝等]为基调，用[光芒色调，像是暖黄光、青白光等]来渲染光晕。

>

> 光影处理：光线自[顶部、侧面等方向]照向宝石，形成[柔和阴影或清晰硬朗的影像]，高光区域表现为[明亮闪耀或微微泛光]。

有了这套模板，每张水晶图的提示词都能保持结构统一、细节丰满。

触发条件：记录新增或修改 → 判断拼接提示词字段不为空。
