# 我现在能做到什么程度

目前主攻的是 AI 达人秀赛道的 Shorts。抛开爆款复刻，常规的制作链路是：构思分镜 -> 分镜出关键帧图 -> 关键帧图转视频 -> 视频拼接。

这条链路里绝大部分环节都能被自动化，只是目前我的技术还做不到全链路一键串通。现阶段的落地效果是：分镜图的 PS 修图和图生视频的审核这两种需要人眼判断的操作保留人工干预之外，其余环节都已实现无人化处理。

其实不止达人秀，凡是动作能标准化的赛道，都可以考虑上自动化，把人的精力留给更核心的创意和把关。希望这套思路能给你启发。

# 我用的工具组合

这套方案核心是 coze、影刀 RPA、豆包、Monica、Runway、飞书这几块拼起来的。

*   **coze**：负责达人秀场景的策划，并自动产出多组备选分镜图；

*   **影刀**：去自动操控那些只有网页界面的客户端，比如 Monica、Runway。不是不想调 API，主要是 API 成本太高；

*   **豆包**：字节系，和 coze 集成很顺。个别图不满意时可以单独召回补图。有人吐槽豆包出图不行，我的实测是提示词写到位了，效果完全可用；

*   **Monica**：一个大模型集合器，能随时切 GPT、Claude、Gemini。我主要让 Claude 帮我写首尾帧之间图生视频的过渡关键词；

*   **Runway**：图生视频环节，性价比高，除了大动作戏份，日常质量已经能用；

*   **飞书**：用来沉淀 coze 产出的场景和分镜图，方便统一管理。

## 达人秀场景设计 + 自动生成分镜

这是整个系统里最复杂的一环，需要一点技术基础和工作流搭建经验。做出来后想直接分享现成模板，但工具是用谁的额度算谁的，所以还是教大家自己搭。

大体思路是：我指定一个动物，coze 自动调用豆包生成几个分镜的文生图提示词，并把每个分镜的提示词拆开，每组生成 4 张备选图，最后写入飞书表格。

开始节点接收被拆分后的提示词数组，并为每个场景自动出 4 张图。配置要点如下，点击节点后右侧会出现配置面板：

![](img/zhuanqian_7b3455e747b85631434bec70fc436bf5.png)

BOT_USER_INPUT：自带的参数不用改，设为非必填；

prompt_array：分镜提示词数组，变量类型选 Array<string>，必填，无默认值；

concurrent_count：并发线程数，变量类型 Integer，必填，默认 4，这个并发量比较稳，太高容易报错；

batch_count：每个场景出图数量，变量类型 Integer，必填，默认 4，4 张基本够用了，极少才需要补。

#### 删除标题并复制节点

该节点属于代码节点，负责处理前面得到的数组，将标题内容与具体场景分开保存。

如需修改上图中的代码，仍然是在IDE内完成。进入编辑界面后，将编程语言切换为Python，再把下面的代码复制进去：

```
import json
async def main(args: Args) -> Output:
scene_array = args.params['scene_array']
titles = scene_array[0]
scene_array.pop(0)
final_array = []
for scene in scene_array:
for i in range(4):
final_array.append(scene)
ret: Output = {
"sub_array": final_array,
"titles": titles
}
return ret
```

## 生成首尾帧图生视频提示词

每套创意完成上述图片生成后，建议每个分镜至少保留一张图片。通常只需要对分镜2进行PS处理即可，推荐使用即梦智能画布中的抠图和消除笔功能，具体操作可以参考航海手册。

![](img/zhuanqian_7c59bd0418878c6af4595e9fb949ab24.png)

那么，Runway所需的首尾帧提示词如何生成？我的做法是使用RPA配合Claude完成，其中Claude通过Monica调用。由于并不是所有人都有Monica会员，大家可以按照自己的条件选择工具。我这里分享的是整体思路，同时拥有Monica会员的朋友也可以直接使用我的RPA程序。

原本计划每次上传两张图片，但为了测试Claude是否能同时处理多张图片，也为了节省调用额度，我一次上传了四张图，让它直接生成各个分镜之间的过渡提示词。

具体做法是在Monica中创建一个智能体，然后输入以下要求。之后每次上传4张图片，智能体就会自动输出Runway提示词。

再结合影刀，自动读取“002-待生成视频提示词”目录中的创意，批量上传图片、获取生成结果，并将内容保存到Excel文件。

```
你是一位精通Runway视频生成模型的专家，能够通过提问的方式帮助设计适合Runway生成的AI视频动作。请基于Runway的模型能力，仔细思考并输出中文的提示词。具体要求如下：
# 动作设计：
图片已生成，仅需设计动作，无需涉及场景、人物或服装描述。
# 简洁描述：
提示词中避免使用形容词或比喻，动作描述应简练且易于Runway模型理解。
# 默认设定：
若无额外信息，默认主体为单人。
# 动作丰富性：
设计动作应炫酷且多样化，可以适当添加一些吸引眼球的特效，避免观众审美疲劳。
# 图片数量说明：
如果我提供了1张图片，根据图片中的主体特点，设计一个表演，需要动感十足的效果，并给出提示词即可。
如果我提供了2张图片，则遵照提示词设计规范来生成提示词即可。
如果我提供了超过2张图片，则需要根据我提供的图片数量，相邻的两张之间都要按照提供2张图片的要求来输出。例如当我上传了4张图片，那么1-2、 2-3、 3-4分别按照上面的要求生成提示词，并且对于最后一张图片，根据图片中的主体特点，设计一个表演，需要动感十足的效果，并给出提示词。
# 提示词设计规范：
图1为首帧，图2为尾帧，动作设计需尽可能避免转圈。
如果是两张图的主体数量相同，其中一个主体变换（一般是人变成其他东西），我希望一定是生成超强变身+特效这样的提示词，例如图一是两个美女，图二是一个美女和一只老虎，这代表图一的其中一个美女变成了老虎，提示词可参考“美女变成一只老虎，超强变身，星光闪闪特效”这类，因为这样给观众更震撼的视觉感受，更容易让观众停留。
如果是第一张图是两个主体，第二张图是一个主体，这种情况下，我希望一定是类似合体+特效、融合+特效这样的提示词，比如第一张图是一个美女和一只老虎，第二张图是一个美女，那么说明图一的美女和老虎进行了融合，提示词可参考“美女和老虎合体，超强变身，金光闪闪特效”这类，因为这样给观众更震撼的视觉感受，更容易让观众停留。
其他情况下，请认真分析图片，结合人物、动物或其他主体在两张图的方位变化、姿势变化，设计更丝滑的过渡效果。例如图1美女在左侧、马在右侧，图2美女在右侧、马在左侧，应该生成包含“美女向右走，马向左走”之类的动作提示词，否则Runway可能生成很差的效果。
# 完整句子：
提示词需以完整句子形式呈现，避免单词+箭头的组合。
# 简洁关键：
Runway识别能力有限，提示词应简洁，仅描绘关键动作。
# 特别提醒：
不需要任何解释和分析，直接按下方输出格式输出即可，切记两张图片之间只需要一段提示词，不要分开来输出。
例如我一共提供4张图片，输出提示词的格式如下：
"## 01
提示词1，适用于图片1-2过渡
## 02
提示词2，适用于图片2-3过渡
## 03
提示词3，适用于图片3-4过渡
## 04
提示词4，适用于图片4的表演
......"
```

## Coze（扣子）问题

### 1. 向飞书电子表格插入记录时报 NOTEXIST 错误（@酷拉皮卡）

很多人说数据格式检查过没问题，但还是会出现类似下图这样的报错：![](img/zhuanqian_120318bd49487fe84a6e5140c82d6724.png)

根据官方文档，这个错误的意思是“未找到指定的云文档”。建议按下面这个思路排查：如果电子表格是在知识库里创建的，后续很容易遇到额外问题；最好在知识库外面新建一张电子表格，再重新获取 spreadsheet_token 和 sheet_id，问题通常会解决。官方错误码文档链接也放一下：https://open.feishu.cn/document/server-docs/api-call-guide/generic-error-code ![](img/zhuanqian_05d7971d850b320c47f8ba824b28d100.png)

### 2. 插入飞书电子表格时提示“range in request is wrong, columns of value:22>range”（@酷拉皮卡）

报错截图见下：![](img/zhuanqian_9079a8040d45104e90b8e3c5965c6e87.png)

这个一般不是数据问题，而是表格列数不够。比如报错里的 22，意味着你想写入 22 列数据，但当前表格的有效列数不到 22 列。解决办法很简单：在表格右侧多补几列，让列数足够，就不会再报这个错了。

### 3. 插入飞书表格的节点提示成功，表格里却看不到数据（@花生）

现象就像下图这样，明明显示插入成功：![](img/zhuanqian_2e57f12c15d1f4e2f4bc32d9770820d8.png)

这种时候别急着怀疑数据丢了，先看一下表格里是不是自己之前创建了很多空行。把页面滚动到最下方，插入的数据很可能就在底部。建议只保留第一行标题，其他空白行全部删掉，之后就不会出现“找不到数据”的错觉。

### 4. 调用智能体时输出莫名其妙的内容，或调试对话流时图片工作流报一串数字错误（@沈瑾瑜）

问题截图如下：![](img/zhuanqian_14441777ee2202e974ca15ba8ea74388.png)![](img/zhuanqian_15c6ac699a9c68e1aed88b4ea8c2efb3.png)

遇到类似情况，可以按当初创建的顺序一层层倒回去排查：智能体调用出错，就打开上一层的对话流直接试运行；如果对话流也有问题，再打开更上层的图片工作流试运行。这样逐步定位，很快就能找到真正的报错点。最后通常会发现是免费版的功能限制，充 10 块钱开个专业版就能继续用一阵子。
