# 我在赚钱的 90 天：从追着项目跑到修炼赚钱本事
## 260104 副业 SC 精华
![](img/zhuanqian_2d52861abfebdf937547d8307f7b16ee_0_0.png)
各位好，我是濯生。
今年九月我进了赚钱，一进来就被琳琅满目的赚钱玩法晃得眼花，信息扑面而来。恰逢航海招生，我看了超标的分享后，直接入了 YouTube AI 视频组。
最近鱼丸看到我之前发的那个工具帖，联系我约一篇稿，潇墨托我多谢。他给我这个机会，我就接了下来。
这篇文章不是来教项目的，赚钱里真正出结果的人太多，我还在学习阶段，没资格谈经验复盘。
我只是想把这三个月来的心态变化老实摊开。
可能不少人和我一样：刷过一堆项目，试过几个方向，有的还在硬撑，有的早已搁置。最难受的不是没赚到钱，而是回头一看，手里空空。后来我想通了：哪怕结果没打通，至少要留下能复用的SOP、工具和记录，下一次才能更快起跑。
在进入正文前，先把背景交代清楚。
## 一、过去三个月我在干什么
这段时间我主要聚焦在两件事上：
- 做了 YouTube AI Shorts，故事类赛道，有一条做到百万播放。
全程零代码起步，我靠 AI 工具、航海手册以及赚钱前辈的经验帖，结合自己的实际卡点，最后自己搭了一个 Python 小工具来解决流程痛点。
可惜的是，这个尝试最终没有走到变现。还没开始赚钱，频道就因为儿童内容相关的问题被下架了。
另外，这三个月并非无缝衔接，因为本职工作原因，中间断档了一个月左右，整体节奏是断断续续推进的。
这段经历谈不上成功，却很真实。它逼着我问自己：这次的失利，除了教训，还到底留下了什么？
## 二、转折点：频道被移除，让我重新审视初衷
当初决定加入赚钱，最直接的动机是赚钱，相信这也是大多数新人进群的初衷。
![](img/zhuanqian_2d52861abfebdf937547d8307f7b16ee_2_0.png)
但这很容易掉进一个怪圈。于是我开始自省：是能力不足？执行不行？认知不够？
直到 YouTube 频道被移除，我才被点醒：如果这个项目不行就换下一个，下一个不行再换下一个。这种玩法本质上是吃信息差，窗口期有多长？等红利被磨平，是不是又得继续换赛道？
这就是低水平的重复建设，项目在换，人很忙，能力却没有沉淀。
我发现真正的焦虑来源，不是没赚钱，而是花了大量时间去试错，最后却说不清留下了什么。
## 三、我对赚钱这件事的重新定义
这三个月里，我的认知慢慢变了：
对我而言，赚钱不是终点，它只是驱动力。真正该追求的是可复制的持续赚钱能力。
这种能力不是空话，它包含认知、工具与技能、数据沉淀、方法论四个层面：
- 能否快速拆解新机制，把流程理清楚；
- 能否用工具把体力活降下来，进而做到矩阵化操作；
- 能否持续积累自己的数据资产；
- 能否把一次尝试提炼成下一次能直接复用的东西。
于是我用多维表格把所有东西做了归类：
![](img/zhuanqian_2d52861abfebdf937547d8307f7b16ee_3_0.png)
| 维度 | 内容 |
| **P1 工具资产** | 把我做的工具、搭的工作流、提示词模板、流程脚本等都记录进去。 |
| **P2 数据资产** | 把爆款案例、脚本/分镜模板、素材清单、踩坑记录、以及我自己整理的资料库入口都记录进去。 |
| **P3 内容资产** | 把每个频道每次发布后的关键数据、以及反馈简单记录下来。 |
| **P4 方法论资产** | 把我反复验证有效的东西记录下来，总结归纳。 |
把思路捋顺后，焦虑感一下子就轻了。接下来我在赚钱的重点，就是先把赚钱能力建起来。
平台和项目，只是用来验证能力的试验场。
## 四、回顾：那个工具是怎么被逼出来的
我在赚钱曾分享过一个 YouTube 整合工具，这里补充一下它的来龙去脉。
![](img/zhuanqian_2d52861abfebdf937547d8307f7b16ee_4_0.png)
### 4.1 产生的背景
航海第一天，我是从零手搓 Shorts 开始的。
严格按手册走：下素材、让 GAS 生成分镜提示词、用前辈工具批量出图、去不同平台抽卡生成视频、再用剪辑软件拼接。
最开始一条 20 多镜头的 Short，要花 4 个小时。后来熟练后压缩到 1 小时，能出 30 个镜头左右。
但问题也越来越明显：那 1 小时里，真正耗神的不是创作，而是等待和切换工具。反复刷新进度、来回点页面、改提示词，注意力被割得七零八落。
更糟的是，视频变成自己亲手做出来的，开始过度盯数据。发完就刷新播放、完播，一旦数据不好，负反馈被无限放大，心态受影响很大。
这时我才明白，流程到一定阶段，靠低效重复劳动既伤情绪又拖节奏。
也是这段时间，我读到 Zero 前辈的精华帖。他已经把 Shorts 生产流程做成工作流，能长期稳定输出。
我去看了他的几个频道，才意识到差距不在会不会做视频，而在生产逻辑完全不同。他的产出不依赖单条视频的即时反馈，而是围绕脚本和脚本生命周期运转。
而我还在沉迷于手搓细节和短期数据。
这让我第一次清晰意识到，内容生产要追求效率与规模时，核心就不是做得多精致，而是把人的注意力从重复劳动中解放出来。
于是我开始想，怎么把高频标准化的环节收拢起来，别再浪费在切换和情绪波动上。让工具干流水线，我的大脑去思考。
### 4.2 如何用 AI 快速做出一个够用的工具
我给自己定了边界：不求大而全，只解决当下最确定、最耗注意力的那一段。
我没有写代码，而是先把整个 Shorts 流程走一遍，标记出哪些环节是高频重复、高度标准化、不需要创意判断的。
结论很明确：最费精力的是机械处理、工具切换和等待。
确认后，我去补了航海手册里相关的技能，通过 claude code + gemini/gpt 来实现。思路是：需求我来提，gemini 写指令给 Claude Code，再由 cc 生成代码，问题由 gemini 和 gpt 交叉验证。
只要能稳定跑通、减少切换、把注意力拉回脚本判断上，对我来说就够用了。
因此这个工具定位从一开始就是：验证流程用的，不是对外售卖的产品。
现在我用 claude code 航海手册的内容重构了架构，前后端可配置，接入 N8N 工作流更稳更快。有需要的可以自取。
该工具完全免费，工具是我个人用来验证流程的，暂不作为产品维护。
### 4.3 我的一些体会
现在做 YouTube 的朋友都知道，平台规则在收紧，同质内容被限流，频道要么停更、要么被移除、要么被迫转型。
在这种环境下，与其反复纠结赛道值不值得做、流量能不能起来，不如在持续产出的同时，把精力投到核心能力的构建上。
这些能力不能保证你每个周期都跑得最快，却能让你在环境变化时不必从零开始。写工具、搭工作流，本质上也是在打磨底层能力的另一种方式。
回头看，做出来这个工具并不是最大的收获。我不指望它能直接变现，也不在乎被复制或过时，因为这已不是重点。
真正的价值是，我意识到自己正在搭建一套可以迁移复用的赚钱能力。
## 五、我的履历，以及赚钱带给我的最大收获
我之前在实体行业创业，武汉做娱乐相关项目，干了 6 年左右，2019 到 2021 年连续拿过某平台全市榜单 TOP1，走过完整的商业周期。后来因为疫情反复，几波下来资产归零还背上负债。
几年时间把负债还清，人也老成了不少，现在能更理性、更从容地看待赚钱的价值。我不再急着证明自己，只想把能力一块块练扎实。
我觉得自己的执行力是过关的，缺的可能是资源、项目、方法、能力和认知。赚钱的社群氛围会倒逼你学习、提升专业技能，这对我来说就是最大的价值之一，我现在正处于快速吸收的阶段。
打个比方：赚钱能力像一个水桶，赚钱能帮你迅速把水桶里最低的那块板补上。桶补好了，打水的地方就多了。
人若无名，专心练剑。现在对我来说是练剑的阶段，不是出招的阶段。我想先把剑练稳、练强，再去验证威力。
