# 飞书多维表格 + AI，公众号文章点一下就能生成
作者：龙哥

前几天，我把一个自己搭的多维表格发给朋友看，他愣了好几秒，问我这怎么弄的。我也没觉得多厉害，但既然能让人这么意外，不如写下来，也许能帮到几个有同样需求的人。不过因为着急下班，这篇就不花心思搞版式了，直接上干货。

先交代一下背景。那会儿我正和朋友一起做K12项目招商，要持续输出公众号内容。说实话，我对写这种文章完全不在行，它本质是把各路资讯重新揉合，AI写出来比我强多了，所以一开始我直接让AI负责。试了几篇发现两个问题：一是生成完还得手动调格式，每次都不统一；二是每换一篇文章都得重新提问，问的问题还差不多，实在太浪费时间。

于是我想：能不能把整个流程挪进多维表格里，让它自己跑？我最近才开始接触多维表格，先花了两天学基础功能，又花了两天做了几个小测试。感觉没有想象中难，就动手把这套东西做了出来。

## 一、公众号文章，点一下就生成

先说说成品是什么感觉，基本分三步走：

1. 点一下【+】

2. 系统自动从12种内容类型中选一种（这12种类型是AI给我的建议）

3. 直接产出一篇排版和结构都固定的文章，标题和正文齐活。标题按爆款套路来，正文按我自己设定的模板走

也就是说，我只要点一个加号，等着就行，一篇文章就出来了。而且它必然会符合公众号的爆款逻辑，因为后台指令里就写了“必须这样写”。

![](img/zhuanqian_5be75335fbd87e2fc011c37cc533d510.png)

那具体怎么搭呢？我把里面设置的字段晒出来，大家看一眼应该就懂。其实我的指令也全是AI代写的，整套多维表格没有一行是我亲手写的——这么一说，忽然觉得自己有点废。

## 二、公众号文章，自动“洗稿”

搞定这些之后，我还顺手做了一个自动洗稿的工具，体验同样很神奇。

操作也很简单，就两步：

1. 把需要洗稿的文章链接丢进去

2. 它会立刻给出一套全新标题和正文；两者都按爆款逻辑来，因为指令里已经写死了

![](img/zhuanqian_a1319f62af41e81f87e46d7ea21722e3.png)

具体流程也很好懂：

先把链接喂进去，工具会自动抓取全文：

![](img/zhuanqian_1250b4590f67979dd510033c569885ca.png)

再基于抓到的原文，一键生成洗稿后的版本：

其实我还照着同样的思路做了一个短视频版本，核心结构和公众号版完全一样，公众号版做完之后，短视频版只花了一小时就搞定了。

做完以后忍不住想：换做从前，请一个实习生，一天能写3篇就够呛了，而且质量忽高忽低。现在呢？AI一天能写100篇，几乎篇篇都在线，100篇的API成本大概也就十块钱。实在太香了。

说到底，这个世界，不过是一个巨大的草台班子罢了。
