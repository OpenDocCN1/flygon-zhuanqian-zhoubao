# 把 2.7 万美金等价的 Token 燃料，换成可复用的资产
作者：龙哥

> 应龙哥邀请在龙哥盟的分享稿。原版发在博客《人生的塞尔达时期》，技术细节较多。飞书文档 Agent 难以直接阅读，感兴趣可把博客链接丢给 Agent 让它解读。本版为圈友精简版，去掉了实现层，只留思路。核心就一句：**当 Token 还在打折时，把它沉淀为代码、服务和工作流这类能持续产生利息的生产资料。**

## 额度告急的那晚

最近公众号更新很少，原因很直白：正陷在薅羊毛里。

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_0_0.png)![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_0_1.png)

Claude Code 的一周额度撞线，Fable 5 也用完，Codex 的周期额度同样见底，Kimi Code 跑到 94%。备用的 GLM 余量 63%，Grok 余量 32%，DeepSeek 和百炼还算宽松，但主力全停了。

正好趁恢复空窗，把想法整理出来。

## 一、进入人生塞尔达阶段

玩过旷野之息的人都懂那种上头感：脑子里只有地图上未点亮的区域，吃饭睡觉都往后排，抬头就三点。

玩家常说“想要一个没玩过塞尔达的大脑”。因为内容终有尽头，通关后那种新鲜感便回不来了。

最近我又找回了类似状态。

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_1_0.png)

可以说进入了个人的塞尔达时期。好奇心把一天塞满，去碰不同方向、解决真实问题，经常和 Agent 聊到凌晨一两点。我的底层假设很朴素：只要数据在网上、模型训练时见过，原则上都可以用 Agent 试。之前的软件篇硬件篇就是这么试出来的。

整个七月作息被两件事牵着走：Claude Code 里 Fable 5 的有效期，和 Codex 的重置时间。7 月 10 日新周期开始，为避免作废集中消耗，连续数天合计日均 40 亿以上。

注意，这 40 亿是 20x 套餐的上限被吃满，不是体力扛不住。

这是我自建的用量看板。近 30 天总处理量含缓存，按 API 价格折算约

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_2_0.png)

等价 27,000 多美金——这只是等价估算，不是真实花销，我实际支出就是两个 200 美元订阅。从 Agent 视角看 Claude Code 与 Codex 各占一半；从模型视角看 gpt-5.6-sol 占 33%，Sonnet 5 占 24%，Opus 4.8 占 18.6%，Fable 5 占 5.6%。

由奢入俭难。额度降下来后像被抽空，下意识先问“这事能不能让 Agent 办”，徒手操作的肌肉记忆都快丢了。

这种构建的快感比游戏更上头，更容易进入心流。与塞尔达不同的是，这片大陆每天都在扩张，永远有新角落可探。

## 二、判断红利：能薅就薅，但要沉淀

结论先说：**羊毛期要最大化薅，但薅来的东西要能变成以后反复使用的生产资料。**

我从 2025 年 3 月开始用 Coding Agent，从 Cursor 切到 Claude Code，再一路升档：Claude Code 与 Codex 的组合从 20+0、100+0、100+20、200+20、200+100 加到 200+200。前者是 Claude Code 档位，后者是 Codex。现在我还在考虑再开一个 Codex 账号。

为什么这么做？一个判断：模型平均单价在降，但高智力部分的真实成本在涨。

现在这些订阅像早鸟票、双 11 秒杀，价格不真实，是平台抢用户与训练数据，不为短期盈利。所以低价套餐撑不久。Anthropic 与 OpenAI 都未上市，当下要的是规模与行为数据。

200 美元每月，我轻松打出 1 万美元等价消耗；Codex 更夸张，200 美元能拉到两三万美元等价——要感谢 Tibo 哥，Codex 重置机制负责人，节奏把控好，订阅利用率极高。

这种倒挂不可能长久。关键在于，薅来的 Token 怎么花才不浪费。

## 三、把 Token 兑成代码：工具与软件的边界

前提：如果高智力 Token 只能按 API 原价买，很多玩法会失效。所以趁现在，把它转成能长期复用的形态：清洗过的数据、工具软件、以及 Skill。其中我思考最多的是划分线。

### Skill 的价值与限制

Skill 好坏取决于写法和模型能力，两者缺一不可，短板就会飘。

优点是门槛低，全是自然语言，适合变化频繁的工作流。本质是借 Agent 处理不确定性，这是它最值钱的地方。

限制也在此。Agent 的注意力是最稀缺资源，必须用在不确定性上。这个观点我在《Context is All You Need》展开过。

想象注意力像员工精力，让它花一小时处理验证码，就少一小时做正事。

比如一个浏览器爬虫 Skill，偶尔用没问题。用频后你会发现大量精力被琐事拖住：反复登录、验证码折腾。次数多了，浪费的注意力比省下的时间贵，投入产出就崩。结论是：使用越频繁的场景，越不该现场交给 Agent，而应固化成程序。

### 高频就工程化

当场景使用足够高频，就该程序化。像开车换挡，熟路段换自动挡，把注意力留给需要判断的路况。常做的一道菜，不如买台面包机，把确定步骤交给机器，自己只管调味。

把 Token 变成代码是杠杆最高的转换，前提是代码要在线运行、持续被调用。代码边际成本接近零，大部分时间不耗 Token，即便耗也比 Agent 方式低几个数量级。

同套信息处理流程，我写成程序化服务，虽然也调 LLM，但走单次调用而非 Agent，模型可换成 DeepSeek 这类便宜的。单个项目一天七八百万甚至上千万的消耗，算下来日成本不到十块。同样的活若用 Agent，可能烧一两亿 Token，订阅能撑，长期不行。

局域网里我已攒一批服务：

- 处理 IP 风控、多语言切换、直播不可下等问题的 YouTube 下载；

- 输入 URL 就能拿到公众号、小红书、Twitter 内容的爬虫网关，零 Token；

- 每天批量转录几十小时音视频的 ASR；

- 图片 OCR 与理解服务。

建成后可被下游反复组合，无论是汇总各平台音视频，还是盯直播推流，都是基于既有工程化的组合。这也是《用 AI 长出来的那些工具》里说的 Skill 快速验证、工程化求稳定。

### 我的 Skill 原则

现在装的 Skill 不多，常年高频只用一个：YC CEO Garry Tan 开源的 gstack 包里的多视角 review。其他多为项目级安装，不放全局。或拆解原理吸收进工程项目。

判断标准：是否会持续迭代。多数博主分享的 Skill 若不更新，多为传播向，未在生产环境跑过。好 Skill 必然持续迭代，否则大概率没经真实场景检验。

## 四、从看护到放手：自修复系统

前面讲物，这一章讲人。Agent 越强，人应站哪。

### 人机协作三阶段

参考《AI agent 到底怎么才算真正落地》：

第一阶段 Copilot，人主导 AI 辅助。每个判断都要人点头，写文案改改、写代码补补。

第二阶段看护 Agent，人监督 AI 执行。可把复杂任务丢出，但走不开。Agent 跑偏要拉、卡住要推，像带婴儿，决策时间被挤占。

第三阶段自主运行，AI 主导人拍板。团队后台自转，人只在关键决策点出现。

内容创作同理：从改文案，到丢调研初稿但要盯偏，再到自主监控热点、排版，人只点发布。电商也是写描述→管上新流程→自主调价，人只批关键。

我正从第二往第三走。越交互越多发现瓶颈在人。要先解决卡点，才能把精力放到更高价值的事上。这像带团队：前期亲力亲为，后期靠规范与分工，你从执行者退到经理再到 CEO。与 Agent 协作同理。

### 我的实践

自用加团队服务约三四十个。多了就被运维与修 bug 吃掉。于是思考：能否让系统出问题时派 Agent 自修，修完通知我，我在飞书点一下就上线。

已跑通，还在一次线上故障中完整走通。

流程图如下：

整个流程我只做两件事：出事后在飞书回“去查”，修完在批准卡点“合并”。诊断、修复、提交、自动化测试、另一 Agent 复审，全部 Agent 完成。

三条规矩：

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_9_0.png)

第一，自动化检查不通过不上线。测试通过、改动量受限、核心基础设施文件不可触碰，任一不满足直接打回。

第二，写代码与挑毛病的人不能是同一个。提交后自动触发测试与独立 Agent 复审，会有界面的项目会自动模拟用户操作并录屏。写审分离，避免自我感觉良好。

第三，被叫出时必须是万事俱备只差拍板。提交后飞书只出现无按钮的进度卡，全部通过后按钮才出现，中间不打扰。

体系运转后

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_10_0.png)

大部分决策只剩两类：定方向、做放行。执行不再需要插手。

我的开发模式变为：先跟 Agent 聊一两小时，把目标、架构、取舍聊透，然后丢长程任务。短三五小时，长数十小时。三条硬规：先写验收标准再改动、每次改动小而完整、写审分离。

靠此可同时推进约十个项目。消耗看起来吓人：高峰半小时刷两三亿；Codex 取消 5 小时限额后，一天跑完 20x 套餐一周额度是常态。

## 五、Token 观与模型军火库

### 三个判断

第一，Token 已成为好奇心的燃料，是现实游戏币。

第二，Token 比精力便宜，但 Agent 注意力稀缺。要敢用，同时把注意力用在刀刃。上我很计较效率，不开 fast 模式，用并发；也会装工具压缩单任务消耗 60-90%。同时又不吝啬，会让不同 Agent 做交叉评审。

第三，消耗量不是好指标。我们暂时找不到更好客观衡量 ROI 的东西，才用消耗说事。真正追求是同样任务用更少 Token，或同样 Token 撬更大价值。

### 分层调用

顶级模型做规划调度，便宜均衡模型做执行，工程师风格做多轮 review。

命名：Claude 家 Fable 5 最顶，往下 Opus 4.8、Sonnet 5；gpt-5.6-sol 是 Codex 主力。

Fable 5 是技术合伙人，只做顶级规划。用得省。它会从业务视角做判断，哪些该投、哪些不该碰、技术选型怎样，给出扎实建议。会拦你，也会带路。

Codex 是严谨工程师与性价比之王。因重置机制它是性价比最高档。用它要控复杂度，得明确目标，避免过度设计，修问题做减法。Codex 的 review 体验目前最好，量大管饱。

Grok 4.5 是执行层。能力准一线，速度极快。印度区曾 30 元人民币月，现优惠已改，但仍可季付。每周两三亿额度，适合 Claude Code 与 Codex 高负载时分流。

Kimi 699：审美能打，工具待成熟。K3 前端审美国产最强，整体不错，一周七八亿量。命令行工具在长任务上下文与指令支持上仍弱于成熟工具，会逐步提升。性价比不及 Codex，但值得支持。

国产平价模型仍在追赶：

| GLM 5.2 | 199 | code review | 可用，缺多模态 |

| MiniMax M3 | 199 | 文档整理、日常 | 编程较弱 |

| DeepSeek | API 按量 | 程序化服务便宜劳力 | 如第三章所说日成本不到十块 |

| 百炼 Coding Plan | 199 | 简单任务 | 支持多模态，凑合用 |

## 六、大航海时代：你的行业离 Agent 还有多远

![](img/zhuanqian_afb9d4149e8cfc044abb86c06ec15fe0_14_0.png)

前面聊的都是我自己的使用经验、取舍逻辑。把视角拉远到整个产业，其实同一套判断依然适用，这可以算做《跑在熊前面的日子》的延续。接下来有几个观察，特别想分享给正在琢磨“AI 在我所处的赛道到底能不能落地”的人。

### 方向没变，落地会很慢

先给出结论：大势不可逆，智能体进入社会生产体系是确定的。但节奏可能比想象中更漫长，卡点主要在两层。

其一，程序编写是一个偶然且稀缺的场景。

为何写代码的智能体推进最快？因代码可执行、可测试、可自检，形成闭环的验证回路。再叠加开源生态数十年积累的海量仓库和资料，几乎全可用于训练。顶级薪资的程序员群体加上开放的开源文化，这种组合在现实中很难复制。其他行业多不具备：核心 know-how 多锁在现场人员头脑里，未被结构化；大量业务决策带有概率性，比如投放一个营销方案，结果受诸多变量干扰，无法像代码那样给出清晰的对错信号。缺少这两项前提的领域，智能体规模化应用自然会慢很多。

### 技术是小门槛，分配才是硬门槛

第一道限制是数据与场景，第二道限制是人性。英剧《是，大臣》里一句台词很到位：任何部门成立的理由最终都会收敛成证明自身存在的必要性。新技术推动到企业内部，真正碰撞的就是这一点。

因此 AI 真正进入企业，往往需要一把手亲自牵头、拍板决策。正如龙哥在直播里反复提到的。

### 但你只用跑赢同行

换个说法来看，门槛高是普世的。智能体渗透到生产环节的大趋势无人能改，进程也会拉长。好在竞争的对手不是模型，而是同业对手。你不需要去和硅谷的研究团队比模型能力，只需在自己的赛道里，比邻居快上一点。

而且如果你能看到这里，大概率已经在认知上领先了。大多数同行可能连智能体这个概念都还没捋清。这份认知差本身就是壁垒。

### 行业know-how + 执行力 = 杠杆最大化

光会用模型不够。这个时代最值钱的结构是：深度的行业经验，结合智能体的执行能力。智能体最缺的不是算力，而是你脑中那些训练集里没有的东西——判断力、阅历、踩过的坑、成型的最佳实践。

举个直观的例子。同样让智能体生成客服话术，初入行者和做了五年的老手给的指令完全不同：新人可能只说“态度要好”；老手会写：“退货先核对是否在七日内、订单金额超过500需主管复核、客户情绪激动时先共情再推进流程”。后者是多年实战沉淀，喂进去后输出质量会显著提升一个等级。

十年经验的行业洞察，配上智能体的执行力，才能放大杠杆。经验越厚、坑踩得越多的人，调教出来的智能体越好用。现阶段的行业老手最该兴奋，因为过去只能单兵使用的经验，现在可以经由智能体成倍复用。

愿意把真实经验交付出来的人，才是在传递真正的价值。

### 给赚钱朋友的几条落地建议

把前面的判断收束成可执行的要点：

- 一、当前 Token 定价属于阶段性促销，不会长期维持。200美元级别的订阅能换来相当于上万美金的算力消耗，这种倒挂是平台获客期的特征。趁窗口期，把算力换成可复用的代码、服务、技能包和流程——等价格回升，这些资产仍在你手上。

- 二、重复性工作要算经济账。是让智能体即时响应，还是沉淀为程序？注意力的稀缺度高于 Token 消耗。若某项任务反复出现且成本不低，值得评估一次性工程化投入 vs 长期占用智能体注意力的回报。并非所有重复都适合工程化，频率足够高、流程足够稳定才划算；低频且每次有差异的，继续交给智能体更灵活。

- 三、不要迷信单一模型。顶级模型负责规划，经济型负责执行，严谨型负责复核。不同工种交给不同模型，就像公司里分工一样。

- 四、行业经验配合智能体执行，杠杆最大。智能体缺的是人脑里的行业常识，经验越丰富，产出越好用。过去只能自用，现在可通过智能体复制放大。

- 五、当下最稀缺的是“做什么的判断力”。想法、见地、踩坑记录、行业know-how，这些是模型训练数据覆盖不到的。恰恰是你在赛道里积累的真实经验，是智能体最需要也最匮乏的部分。

## 写在最后

塞尔达玩家希望拥有一个没玩过这款游戏的大脑，是因为游戏内容有限，探索完毕便无新意。但这次不一样——新大陆每天都在扩张，每天醒来都有未知角落等待探查。

红利终将退潮：配额会收紧，套餐会下调，高智力算力迟早回归真实价格。所以能在窗口期薅到就尽力薅，更关键的是把薅到的资源沉淀为代码、服务和工作流这类可长期复用的生产资料。等算力变贵的那天，你手中的沉淀才是真正的通关奖励。

祝探索愉快。
