# 0 代码基础也能开发 AI 工具站？我做了 3 个，来交作业了
如果你和我一样，完全不懂编程，看到“开发网站”四个字就觉得自己不行，那请花 5 分钟看完这篇复盘。
我是前行，一个 0 代码基础的普通人，从 23 年加入赚钱以来，几乎每期航海都报名，一路试错，总算赚到了工资以外的第一个 1 万。也正是在一次次实战中，我找到了值得 All in 的方向——AI Web。我隐约觉得，这个项目会是我工资之外第一个 10 万、甚至第一个 100 万的起点。
为什么我敢这么笃定？原因有两点：
第一，AI 把编程门槛彻底打掉了。过去想做个网站，得先学一堆技术；现在，只要你善用 AI 工具，照样能做出看起来挺专业的站点。真正的分水岭不再是技术，而是你能否找到用户真正的痛点，并快速用网站去满足。换句话说，“找到真需求”的能力，比满分会写代码更值钱。
第二，我对做网站有一种近乎上头的热情，短期看不到收入也愿意持续投入，而且不会觉得累。再加上我还报名了刘小排老师的课程，有大佬护航，信心自然更足。
先给大家看看我做的 3 个网站：
- AI 专业头像：https://www.professionalheadshot.online/
- 文本转信息图：http://texttoinfographic.online/
- 轻量化语言学习（偏旅游）：https://www.littlelanguage.top/
欢迎大家上去逛逛，多给我提建议。这几个站点目前还有不少细节需要打磨，但我并不打算把所有时间都砸在优化上。更稳的策略是：一边看流量数据，一边迭代优化，一边继续挖新需求。
下面，我把整个开发过程做一次完整的复盘。这篇复盘特别适合和我一样没有代码基础、还在观望的圈友，希望能把你心里的那点疑虑打掉。
## 1. 准备期：魔法、账号和 AI 编程工具
第一步自然是“魔法”。网络不通，后面全是空谈。我用的这个节点服务还挺便宜，15 块多能买到 130G 流量，目前用下来比较稳定，有需要可以自取：https://mojie.app/
第二步是账号三件套。Google 账号是通行证，绝大多数应用和网站都能用它一键登录。注册并不麻烦：下载 Chrome 浏览器，搜索“谷歌邮箱”，进入页面后点创建账号，跟着提示填写就好。大陆手机号可以收验证码，也可以绑定辅助邮箱，记得把“魔法”开着。![](img/article-)![](img/article-)
GitHub 账号用来存放代码文件，具体操作不用懂，直接问 AI，边做边学就行。AI 编程工具方面，新手我只推荐 Cursor，先把一个用熟，不要朝三暮四。闲鱼上经常有教育优惠的一年账号，一百多块就能拿下；实在找不到，可以找鱼丸，我帮你推荐。
## 2. 找需求：把“新词”和“常青词”分开看
这一步是重中之重。我把往期的航海手册和高手领航翻来覆去看了不下四遍，慢慢整理出了自己的框架：需求就两大类——热点需求，和长期需求。
热点需求，简单说就是“新词”。某个关键词刚刚爆发，如果你能在极短时间内做出一个对应网站，就算你是新站，也可能吃到一大波自然流量。怎么发现新词呢？多关注 AI 领域的一线博主，他们一有风吹草动就会第一时间发出来，比自己去摸索快得多。我常用的信息源也分享给你：小虎 AI（www.xiaohu.ai）、toolify.ai（www.toolify.ai/zh）、GitHub Trending（github.com/trending）、HuggingFace Spaces（huggingface.co/spaces），还有 Reddit（www.reddit.com）。Reddit 相当于海外的知乎，里面藏着很多真实需求，我自己也还在学习中。
长期需求则不一样，它每年都有稳定的搜索量，不太会大起大落。如果挖到一个搜索量大、又足够稳定的词，基本就是“躺赚”的项目。具体怎么挖，可以参考本次高手领航的分享：https://shengcaiyoushu01.feishu.cn/minutes/obcnadk7rh7gfper83f9d7i5?from=from_copylink

## 3. 验证需求：三把尺子缺一不可
看到一个关键词，千万不要头脑一热就去开发，否则很容易陷入“自嗨”，或者一头扎进根本干不过的赛道，最后连一点流量都没有。我总结的三步验证法，供你参考：
第一步，打开 [Google Trends](https://trends.google.com/trends/) 看趋势。比如 AI、GPT 这样的词，搜索量非常夸张，而且仍在持续上涨；相比之下，gpts 的搜索量几乎可以忽略。![](img/31af106eb4bda4a3b8b927c32ebdfd54.png "None") 在优化难度一样的情况下，当然优先选择前者。什么是新词？趋势图上突然出现一条陡峭的曲线，搜索量快速飙升，就是典型的新词。![](img/424ba644cc4f866161c9b889faccc6dc.png "None") 我一般找的是爆发时间在 1 个月到半年之间的词。
第二步是查优化难度。这里有个免费的利器：https://ahrefs.com/keyword-difficulty。输入目标词，它会直接给出难度分，分数越高越难。![](img/2caca6c46d04186d71f6d0eb12b156b0.png "None")![](img/86785b6b28f4e296840d6cdab2fa5b07.png "None") 拿 AI 这个词举例，得分是 98，后面写着 super hard，这意味着需要 3106 个外链才能挤进前十，对新手来说基本没戏。建议先从 20 分以下的词开始练手。
第三步是直接去 Google 搜这个词。看看目前都是什么网站在满足这个需求。如果搜了一大圈，发现还没有人专门为一个词做站，那你的机会就比较大。当然，要结合前两步综合判断，不能只看其中一条。不过对新手来说，前几个网站真不用太纠结，先做出来再说，放到真实市场里测试，自然会有答案。
## 4. 开发阶段：先学 git，再让 Cursor 听你的
正式敲代码之前，我强烈建议你先花点时间搞懂 git。这个工具太重要了——它相当于网站的“后悔药”。有时候让 AI 改代码，它会把不相关的部分也改乱了，整个网站变得面目全非，这时一个 git 回退就能解救你。我自己专门用了一整个晚上学 git，然后边开发边加深理解。想系统学，可以看上面那本《Cursor-零基础做软件应用》手册；遇到不懂的，直接问 AI 也是很好的路径。
接下来说说怎么让 Cursor 更听话。我的秘诀是先做一个“cursor rules”文档。在开发开始前，让 Cursor 仔细读一遍这份规则；为了怕它忘记，每次对话都可以 @ 它来强化记忆。cursor.directory 这个网站几乎汇集了所有你能想到的规则模板，你可以从中挑一份适合的，再按自己的习惯修改。
我用的规则大概长这样：技术栈是 Next.js + TypeScript + React + Shadcn UI + Tailwind；代码风格偏函数式，避免写 class；目录用短横线命名；尽可能用服务端组件，少用 “use client”；同时会把 SEO 优化、元数据管理、结构化数据等内容都写进规则里。这样生成出来的网站不只是好看，还更容易被搜索引擎收录。
## 写在最后
回头看，零代码基础真的不用怕。这个时代把技术门槛降得足够低，反而把“发现需求”的能力推到了台前。只要把上面这几步一步步走通，普通人同样能做出 3 个、甚至 30 个网站。
希望这篇复盘能帮还在观望的你放下心理包袱，大胆下场。如果你有冷启动或者挖掘需求的好方法，也欢迎在评论区指教，咱们互相学习，一起赚钱。
从零代码到三个 AI 工具站，我把完整过程复盘给你
先讲一句我最想说的话：在 AI 时代，做网站这件事，挡在你前面的不是代码，而是“还没开始”。我是一个到今天仍看不太懂代码的普通人，却靠 AI 陆续做出了 3 个工具站。这篇复盘，就把我能跑通的路完整讲一遍。
一、开工之前，先把技术底座搭好
一个 AI 工具站，远不止“把问题丢给大模型”那么简单。我在实践中总结，至少要处理这些事：
1. 数据层
- 给 AI 内容挑一个匹配的数据库，比如 Supabase、MongoDB，按实际需求定。
- 内容必须支持版本控制，改坏了能马上回滚。
- 表结构、索引这些，要围绕“检索效率”来设计。
2. 缓存策略
- 用 Next.js 时，给不同内容设置合适的 ISR 更新频率。
- 用边缘缓存照顾全球访客的速度体验。
- 动态内容用 stale-while-revalidate，保证用户拿旧缓存的同时，后台悄悄更新。
3. 刷新机制
- 先按内容类型判断“多久需要更新一次”。
- 再根据数据表现做自动刷新，而不是拍脑袋。
- 每次更新的效果要记录、留档，作为后续优化依据。
4. 安全方面
- API Key 只放进环境变量。
- 用户输入要先清洗，再发给 AI。
- 生成接口要限流。
- 用户能影响生成结果时，一定要有内容审核。
5. 监控与 SEO
- 接入 RUM，把 Core Web Vitals 的真实数据收起来。
- 搭建简单的统计，观察内容表现。
- 自动化巡检 meta 标签、链接等 SEO 基础项。
- 按内容类型记录用户的互动指标。
另外，凡是涉及数据获取、渲染、路由，我基本都照着 Next.js 官方文档的建议走，既稳又省心。
二、写代码之前，先和 Cursor 把文档聊出来
定好 Cursor 规则后，我会花时间和 AI 深入沟通，最终产出 product.md 和 design.md 两份文档。
product.md 相当于产品说明书：把网站的功能、想法、实现方式都写清楚，方便 Cursor 理解这个站到底要解决什么问题，再按这份说明去写代码。我一般会做两个版本：一个 MVP 版，先快速上线验证；另一个详细版，把未来可能的长远功能也都记下来。
design.md 更像开发蓝图：把项目结构、用到的技术、整体流程记录完整，让 Cursor 照着开发。同时我还会建 readme.md 来记录开发进度；如果走模块化开发，每个模块也单独建一个 readme，进度一目了然。
文档准备好之后，简单网站就可以直接让 Cursor 生成代码了。我和 Cursor 沟通没什么高深技巧，基本就是自然语言，AI 现在的理解能力已经足够强。不过有一点要特别留意：同一个词、同一句话，尤其是带歧义或专业术语时，AI 和你心里想的可能不一致。遇到这种“说不清”的时刻，最好展开解释，让 AI 复述一下它的理解。我自己碰上过不少一直修不好的 bug，最后发现根因就在这里。
如果你的网站比较复杂，更建议先和 Cursor 把结构讨论清楚，画好网站架构，再正式动手。

关于“和 Cursor 的沟通技巧”，我的真实体会是：没有技巧，多聊多练才是唯一的门道。我自己前期用了三个免费账号，又叠加了一个月付费会员，才慢慢摸到感觉。如果硬要提炼一点，那就是表达要精准、具体，另外多学点开发术语会让沟通顺畅很多。遇到不会的概念，当场问 AI、当场学就行。AI 时代，大概 99% 的知识 AI 都有能力教给你，就看你能不能保持耐心。
三、部署上线：域名、Vercel、Supabase
上线并不难。域名在阿里云、Cloudflare、Spaceship 这些平台上都能买，用核心关键词当域名就是个不错的策略。部署我推荐 Vercel，免费且省事；现在大多数 AI 工具站都用 Next.js，和 Vercel 刚好是最佳搭档，SEO 的表现也很理想。后端/数据库就用 Supabase，同样有免费额度，个人项目足够用。
整个开发复盘走下来，真不存在什么神秘技巧，只有耐心——耐心地和 AI 反复对话、反复测试，遇到不懂就问。AI 的出现，让普通人也能把心里的想法变成实际的产品，这一点我是真的体会到了。
四、冷启动与推广：还没完全跑通
老实说，推广这块我只摸到一点边。目前主要在做 SEO，同时研究 Reddit 的规则，也会养一些能发外链的账号，后面再慢慢把外链铺开。因为这些玩法还没有形成成熟打法，我就不乱分享了，等我研究透了再单独写一篇。
五、几点个人感受
1. AI 把“做产品”的权力，交到了每个普通人手里。只要你有想法，就有机会这么做出来，真没理由继续观望。还在犹豫的朋友，尽早下场体验一下吧。
2. 零代码基础完全不是障碍。我到现在依然识别不了几行代码，但身边同样不懂代码的圈友，已经通过 AI 做出网站并拿到不错的结果。
3. 在我看来，耐心和热情才是决定这件事能不能成的关键。有了这两点，遇到任何问题都能解决，因为你等于随时带了一个 24 小时在线、从不会不耐烦的 AI 导师。
4. AI 迭代速度太快，新模型层出不穷，但我们没必要一直追新。找到适合自己场景的工具，长期用下去，远比反复更换更划算。
以上，就是一个零代码背景的普通人，借助 AI 做出 3 个 AI 工具站的完整复盘。希望能给刚想入场的新手一些勇气，然后果断动手。最后也感谢龙哥盟，让我能在这么多项目里不断试错，最终找到 AI Web 这条赛道。
