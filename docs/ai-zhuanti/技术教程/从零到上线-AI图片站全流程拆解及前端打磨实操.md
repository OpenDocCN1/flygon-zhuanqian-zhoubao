# 一、AI图片站构建全流程

## 1. 整体路径

敲定技术选型与开发计划 → 搭落地页原型 → 接入生图 API → 精修界面 → 部署发布

## 2. 具体执行

### 1）确定技术栈与开发计划

#### 和 cursor 的沟通方式：

1）目标陈述：我要做一个 AI 图片站，核心功能是文字转图片，先做 MVP 即可

2）边界补充：不存储用户任何数据，图片生成后用户离开即清理

3）交付要求：请给出完整技术栈建议和可落地的步骤拆解，用 Markdown 格式输出一份 readme.md

#### 多轮打磨 readme

先让 cursor 生成初版，再按自己实际需求反复修正。觉得方案太重就要求简化，循环对话，直到得到一份自己能看懂、能直接动手的可执行文档。这个打磨环节很关键，前期多花点时间，后面会省很多工。

#### 我的 readme.md

先通读这份文档，后面很多细节都基于它展开。

### 2）落地页设计

在动工前，先按 readme 完成环境配置、API 密钥申请、项目初始化。

#### 落地页提示词思路

模板选择和调整的具体做法我另起文档列出。每个人可根据自身站点的功能微调，AI 图片站通常会在中部加入一个文本生成图片的交互区。

把整理好的 prompt 丢给 cursor，很快就能得到一个可用落地页 index.html，直接在文件管理器里打开预览即可。

觉得视觉还不够理想也不要纠结，先把核心功能跑通，再回来做界面精修。

### 3）接入 API

#### 和 cursor 的对话

“我想接入免费的文生图 API，有哪些可选方案？”

cursor 会列出一批方案，我综合成本、效果后选择了阿里云百炼的 FLUX.1-schnell 模型。

#### 我的接入步骤：

1）进入阿里云官网，点击「大模型」

![](img/zhuanqian_4c2f821a8708e57f32fc837c765c8382.png)

2）点击「免费体验」，完成相关勾选后进入体验页

![](img/zhuanqian_f1603e143198bae28c79edf2bf004185.png)

3）左侧导航进入「视觉模型」→「图片生成」

![](img/zhuanqian_e1b09e2c02fceca7819c15c1f99c9b61.png)

4）随意体验几个模型，确定心仪版本后，点页面顶部的「API 参考」

![](img/zhuanqian_db7be930a212554fc4c8abcfbbc8beb8.png)

5）获取 API KEY

点上图中的准备工作，按指引操作。配置环境变量这步一定要选 Windows 系统，按步骤走即可，无需安装 SDK。

![](img/zhuanqian_67951e9f122d33ae7eb3427637d59e84.png)

6）为对应模型做配置

![](img/zhuanqian_9e9b1b1ba9bebaf32eabb34b539fc48b.png)

左侧菜单下滑找到目标模型，进入无脑配置模式：

方案一：把当前页面截图发给 cursor，问“我想接入 API，请一步步指导我操作”，每完成一步再截图反馈，让它持续带路。

方案二：把当前网址发给 cursor，说明要配置哪个模型的 API，让它自动生成配置代码。需要 MCP 工具时若不可用则转方案三。

方案三：在方案二基础上 Ctrl+A 全选当前模型页面的全部内容，复制给 cursor，让它自行完成配置，出错再让它修复。

第四种技术流做法不适合大众。

完成以上操作后，本地理论上就能实现生图。

#### 重要提醒

在我的技术栈里，生图必须同时启动前端服务和 API 服务，否则页面可打开但无法生成。会出现如下报错：

![](img/zhuanqian_746269ee67c0ca60acd10679deb73ace.png)

具体排查原因我已单独整理在文档中。

### 4）UI 精修

我的思路是先模仿再创新。

#### 模仿阶段

1）找标杆网站取精华：

Raphael.app 小排老师的站点

ghiblio.art

youphoto.ai

2）整体拆解

让 cursor 分析这些站点的优点，并提炼能迁移到我站点的设计点，做一次大体优化。

3）细节补齐

1）截图迁移

![](img/zhuanqian_348219191af5623e995dddb674060061.png)

我觉得小排老师站点的 header 和 hero 区很出彩，于是截图发给 AI，提示如下：请参考这张图中的 header 和 hero 布局，结合我站点的定位做风格化演绎，不要直接复制，按钮和功能排布可借鉴，视觉上要有差异化。具体风格按自己喜好写进 prompt。

2）工具妙用

如下图所示的 logo：

![](img/zhuanqian_0b08148dbc7b261aa582e14010b789cd.png)

该 logo 是 AI 直接套用的，需要手动处理：

a、去 Google 找免费 logo 生成网站自行制作

b、用 AI+AI 的方式解决

打开 Raphael.app，按如下操作：

![](img/zhuanqian_d18aa5c62682cc21e6754fd0acedd70b.png)

下载满意的图片后，发给 cursor 让它写脚本把图片裁切成 30×30 和 60×60 的圆形，分别用于 header 和 hero 区的 logo，然后让 cursor 帮我嵌入到站点。

#### 创新阶段

创新就是基于对网站的理解进行自主设计，或让 cursor 在模仿的基础上做二次创作，属于长期积累的能力。

### 5）部署上线

按技术栈文档中的部署说明执行即可，我采用的是 Cloudflare Pages 部署。

# 二、前端制作技巧沉淀

前面提到，创新需要长期实践积累。那如何系统提升呢？我走了两条路。

第一条是 Figma，我目前还没深入就不展开。第二条是建立对 UI 设计的体系化认知。为此我用 cursor 花 3 小时做了一个专门学习 UI 的站点，已部署到 Vercel，内容涵盖 UI 基础讲解、组件分类、主流组件库、通用属性、配色体系与色板。

站点地址：https://iu-topaz.vercel.app/index.html

我自己也还没完全学完，下面放一些页面截图以及 cursor 的专业概括：

UI 指导书是一个一站式 UI 设计知识平台，把现代界面设计的核心要素系统化呈现。

核心模块

*   基础理论：阐述 HTML、CSS 与 UI 的关联，为新手打基础

*   组件体系：覆盖基础、表单、数据展示、导航、反馈五大类，并配可视化示例

*   组件库盘点：收录主流 UI 框架，按桌面端、移动端、小程序、跨平台四类划分，并附使用说明
