# 小红书素材搜集实战：把笔记变“可视化”，变现赛道任你挑
很多人做小红书，一开始就给自己限了赛道：写职场、写情感、写干货……选来选去都是“码字”的路。但你看那些真正赚钱的账号，职场、家居、宠物、旅游、减肥，几乎没有一个赛道是靠纯文字跑出来的。为什么？因为非纯文字的内容，更容易植入商品、展示价值，也更容易让品牌方看到广告位。梨云把自己的实操经验做了次系统拆解，核心就一句话：把笔记形式拆细，素材问题就不难；素材解决了，赛道选择就自由了。
先说形式。小红书笔记表面只有图文和视频，但这种分法太粗。![](img/zhuanqian_7fe25e68cba1444a8545a25aa683dff6.png) 梨云翻了 3 万条笔记后，把形式细化成了六种：![](img/zhuanqian_7c188fce5ad8569c5c658e5bd29ce1e9.png)
图文类：文章图文是“公众号平替”，用文字和排版说话；![](img/zhuanqian_d1a7a2ad939b227684837a49b5e55fa1.png) 实拍图文是产品照片搭配文字，广告位天然存在，很多文章图文加了商业植入就变成了实拍图文；![](img/zhuanqian_32459a5f3238c09b4fbc33190dc5dc36.png) 素材图文不需要拍摄，收集素材就能出片。![](img/zhuanqian_24066a9104ae849368e3c91c3239cc3d.png)
视频类：实拍视频是自己拿设备拍，![](img/zhuanqian_9a332fcc195b41e934294cb9e862995e.png) 动画视频是用工具自己做，![](img/zhuanqian_7a70533045dc0ac578b2b7963bff2752.png) 混剪视频是拿现成片段二创。![](img/zhuanqian_9bf55466731c4c67dc110d591898737b.png)
那么哪种形式最好？并没有标准答案，只有“合适”与“不合适”。写人生感悟和干货建议，文字就是最高效的载体；种草旅游景点、口红、装修风，就必须用图片和视频来展示。纯文字没法传递视觉信息，就是形式拖了内容后腿；改成可视化，内容和形式就统一了。![](img/zhuanqian_d30b93c180aa31cb61ebad03d5c88368.png) 梨云还做过一个实验：把教育号停更一年的纯文字笔记改成实拍视频，直接做出了千赞爆款。![](img/zhuanqian_cf2f48b161cea7f029a3e0c296707cef.png)![](img/zhuanqian_7eeb10ac585dfa411933e0f619c274ab.png)![](img/zhuanqian_19a077040d3a8ee4af8ffc0318cc1b8f.png)
在六种形式里，素材图文的性价比特别突出：它比纯文字更有商业价值，变现天花板更高；比视频更省力，制作成本更低。看看市场价：美食赛道 9.6 万粉丝的号，一条广告能报 1.2 万；![](img/zhuanqian_bf9071a1c5ce7092cf375a3ef5f3f644.png)![](img/zhuanqian_2b8b20312fb3ed9402ee872ab87ac43b.png) 母婴赛道 4.4 万粉，报价 5000；![](img/zhuanqian_0df40125cdcaa909b467b39fed48fc89.png)![](img/zhuanqian_0b41ed32f2a9ad0475693abb4a1e3a45.png) 护肤赛道 2.2 万粉，也有 2300 一条。![](img/zhuanqian_6fdfa1d2614ca988e9e258c9c64238a1.png)![](img/zhuanqian_2e2c6a2a313b85886f5977483379d468.png)
接下来，重点拆解素材图文怎么做，分实体和虚拟两套。这套玩法如果配合梨云绿模板，可塑性很强，能帮你打开更多变现视角。
## 实体素材笔记：真实感就是广告位
实体素材笔记里全是实物图，真实感强，等于整篇都有广告位。很多账号有粉丝但接不到广告，就是因为笔记里没有产品展示位。好在每个赛道都有这种笔记，学会方法就能入场任意赛道。制作流程不复杂，关键是把素材卡点干掉。![](img/zhuanqian_7e99b13294998d5bbe6d46dba4017cb0.png)
第一步，拆排版。要精细化模仿，先用“要素分析”看清图里有什么：名称、价格、主体、背景；再用“网格分析”确定位置和尺寸。熟练之后，眼睛就是比例尺。另外，注意排序逻辑，按颜色、价格做排列，视觉会更有秩序感。![](img/zhuanqian_5fefbbaca83bc7f34b6e6a4a5ade5c86.png)
第二步，搜集素材。拿家居沙发举例，装个“以图搜图”插件就行。打开 Edge 浏览器，在右上角菜单里进入扩展管理，![](img/zhuanqian_06d3b375ee7415b480fcbaf296cc513d.png)![](img/zhuanqian_74040de04c18741b2a889034d09c8f5c.png) 搜索并安装“搜图助手”。![](img/zhuanqian_e1fc61e6a1696af13883c98d29eabde6.png)![](img/zhuanqian_b2eae2255923e78b6d08e9bb9cab92a4.png) 然后截图搜索，能看到商品来自京东、淘宝等渠道，![](img/zhuanqian_cb5f824d0d5826d3e8d8de3317431112.png) 点进淘宝同款，用 Fatkun 插件下载正面高清大图，素材就搞定了。![](img/zhuanqian_5b140f1e6d1e24fa337a787e57baa867.png) 这一套下来，你就有了从写文到出图的能力，跨越赛道不再是空话。![](img/zhuanqian_15f86f4e008e5c40a80b61948a45ea3f.png)
第三步，制作图片。网络上的图片大多带背景，需要抠图。手机端用美图秀秀、醒图、黄油相机；电脑端用 PPT、PS，或者稿定设计、photokit 网页工具。![](img/zhuanqian_fb365b3ee2013eee921c0afdd676518e.png) 抠好后拖进 PPT 表格，补上名称和价格，一张笔记图就完成了。![](img/zhuanqian_215971384b8c732ac7718c0acd17ddd4.png) 想找新选题？打开盖得网，里面按行业分好类，每种商品都能这么玩。![](img/zhuanqian_865f7f88915d11098f371af3e7705c08.png) 掌握这些，你就可以打开作图工具去解锁更多赛道了。![](img/zhuanqian_825cdc5a86f2ead70c6c116bdb6bf46e.png)
## 虚拟素材笔记：把干货可视化
除了实物，还可以用虚拟素材。它既能替代实体素材，也能让干货知识变得更直观。小红书 IP 要显专业，就得给小白展示详细步骤。但步骤多了就是说明书，没人愿意看，所以必须图像化。![](img/zhuanqian_23a84f00703d23355ae7f58103ebf487.png)
第一步，拆排版。同样看要素、位置和属性。遇到认不出的字体，用 likefont 识别一下即可。![](img/zhuanqian_6fc747d7c395d6d63479a121890c0b16.png)
第二步，搜集素材。虚拟素材大多是卡通图，以图搜图不太灵。![](img/zhuanqian_f2bae42d7998ca4a3095571e657effb0.png) 可以走三条路：图标聚合网站，比如 Iconfont、Noun Project、Icon Ninja、icons8、字节 IconPark；作图软件自带素材库，比如 WPS、稿定设计；![](img/zhuanqian_6a58badbb50e5605ac360bc2cbaea93d.png) 或者干脆去拼多多买现成的。![](img/zhuanqian_bd00014d6c077cda9a6303777c17c2b5.png)
第三步，制作图片。以 Iconfont 搜“尺子”为例，先要对准目标图的色号，可以用千通彩色库工具取色。![](img/zhuanqian_60c16546cf6fc1a8897944cc4bf86f1c.png) 接着在原图上画一个圆形，绿色填充、黑色描边，完全覆盖后调整透明度，让尺子的轮廓透出来；再把下载的尺子素材贴上去，尽量让面积重合。![](img/zhuanqian_2a6815889cd09b741c3b116360cc27c4.png)![](img/zhuanqian_2b6a8ada5b38c2ad480651e1df0cd52c.png) 这样就能做到一比一复刻。![](img/zhuanqian_497565cfe6c4ad9b71d1d99d64fe6be3.png)
很多人不敢碰家电、护肤、汽车、穿搭这类高价值赛道，是卡在素材上，毕竟现实中没条件实拍。但用上面的工具，配合少量付费购买，素材问题基本解决。下面再补充一个高频的“拼图素材”搜集技巧。
## 拼图素材：百度也能搜出高级封面
想找好看的封面图，百度其实完全够用。![](img/zhuanqian_ed96d6a18cd904a6d1a58ccd7b877d7d.png) 比如搜“玫瑰”，结果往往是花花绿绿，质感全无。![](img/zhuanqian_75efd5856e8f34cf5a812b9f8fb2d7d7.png) 但把关键词换成“玫瑰 ins 风 唯美”，画风立刻不同。区别就在于：前者是模糊词，后者有精准形容词。这和 AI 绘图是同一个逻辑，关键词越细，结果越接近预期。![](img/zhuanqian_00849db836c1e65f77a608e88f2b97fa.png) 再进一步，选一张最满意的图，用百度搜图反向找到原文，![](img/zhuanqian_4c4d006ceb8bafdceb2a57d495b28dc9.png)![](img/zhuanqian_b149f1a992710a0ec738f8794cb62086.png) 如果小编的配图风格统一，就把整篇文章的图都下载下来，纳入自己的素材库。![](img/zhuanqian_b22952f7ff4e5fd81660f6b9168fbad9.png) 还有个技巧：使用筛选器，调大尺寸拿高清图，自定义宽高锁定 4:3 的小红书比例，再按颜色统一主题色，整体视觉效果会更舒服。![](img/zhuanqian_7a63d7b2fa6eaaed91806f9b5b5a6c05.png)![](img/zhuanqian_519113c3aa61d40556e5452447ba8861.png)
