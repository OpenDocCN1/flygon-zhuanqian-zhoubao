# 通过 AI 和脚本，我总结了龙珠榜前100名高手的关键词
作者：龙哥

借助AI和脚本，我把龙珠榜前100名高手的核心标签全都挖了出来。这篇文章就是一次完整复盘。一句话版本：用AI吃透龙珠榜高手的文章，找出他们最擅长的赛道；再结合他们的自我介绍，提炼出个人关键词。成果如下：![](img/zhuanqian_e7de6aa34698df7f0ab5a7df9771a911.png)

全文约2500字，读完大概需要5分钟。接下来分五部分展开：一、为什么想做；二、具体目标；三、操作流程；四、用自我介绍补全画像；五、收获与展望。

# 为什么想做？

灵感主要来自两件事。

第一件，是在赚钱看到“搭建兵器库”的思路。精华帖和风向标里的东西，如果不内化，看过就忘了。把它们变成自己的知识，需要时随时取用，这才是积累。人脉库也一样，遇到不错的人，先沉淀到库里，下次搜索一下就能快速加深了解。

第二件，是AI数字人和知识库最近很热。我很好奇：如果拿高手写过的文章去喂AI，让AI总结他们擅长什么，效果到底如何？顺带还能练一下油猴脚本，把流程自动化。

做这件事的价值有三点：

1. 打通完整SOP，中间遇到的每个卡点都是实战学习。把一个小灵感做成事，行动起来，就能输出价值。

2. 在研究龙珠高手的过程中，能更深入理解赚钱这个社群。人是最宝贵的资源，这也是为将来建立更深链接做铺垫。

3. 给今年才加入、或者不太了解龙珠高手的朋友，提供一种信息密度更高、更高效的了解途径。

# 要做什么？

简单说就是：用AI分析高手写过的文章，提炼擅长领域和关键词。后来发现手机端的赚钱索引站能直接看到高手的自我介绍，于是又把AI分析和自我介绍结合起来，最终生成五六个核心关键词。成果截图放在这里：![](img/zhuanqian_f1a430c4dd840b9a36225f19855595cc.png)

# 怎么做？

经过反复尝试和优化，我总结出一套可复用的流程：先把每位高手的文章保存成txt，再丢给AI总结结论。

## 第一步：把文章下载到本地txt

电脑端赚钱索引站中，进入某个龙珠高手的个人页（比如涛哥的），可以通过榜单或搜索找到。![](img/zhuanqian_66e1f276a3751e5be1559e8a8fa65963.png)能上榜的通常都写过精华帖，所以优先分析精华帖；精华帖比较少的，就选点赞最高的帖子。具体操作就是点击“精华主题”，然后点开每篇文章，把文字内容保存成txt。

手动做太耗时，所以用脚本自动化。现在有GPT了，即使编程经验不多，写个简单脚本也不难。

以Chrome为例，先装一个“篡改猴”（油猴）插件，启用后固定在工具栏。![](img/zhuanqian_2cbad96ebf5f23e6394cb5848854b53c.png)![](img/zhuanqian_02d53fdf5f95af4b8af0c9304c8f5db1.png)

脚本用最通用的JS模拟点击，自动点“精华主题”和每篇文章。由于不同页面结构不一样，我写了两个脚本：一个用于索引站个人详情页（search01.shengcaiyoushu.com/personal*），自动点击精华主题并逐个打开文章；另一个用于文章详情页（wx.zsxq.com/dweb2/index/topic_detail*），这里要判断文章中是否存在实际文章链接（比如articles.zsxq.com或飞书链接），如果有，就打开链接再下载；如果没有，就直接保存到本地。

脚本怎么写？没编程基础可以让GPT帮忙，描述要具体，分步提问，比如“你是一个资深前端开发专家，请帮我写一个油猴脚本，实现点击文章列表、打开详情页并把文章下载保存到本地”。过程中卡壳很正常，把报错或不懂的复制粘贴回去继续问，一步步搞懂，本身就是学习。我有点开发经验，所以GPT辅助开发很快。脚本不是本文重点，技术细节就不展开了。

效果如下：自动打开一篇篇精华文章并下载。![](img/zhuanqian_396c71dd3bf32ab9b08451121383ba2b.png)

下载了很多个txt后，最好合并成一个文件，方便上传，也方便AI输出后校对。用命令行很方便，以mac系统为例：把文章放在单独文件夹，右键点击“在终端中打开”，输入命令并回车：```
cat *.txt > merge.txt
```就会生成一个merge.txt。

## 第二步：把文件喂给AI，用提示词输出结果

我用过两款工具：一个是Chato，一个基于学习素材定制的AI机器人；另一个是Claude2，类似ChatGPT，对话框里可以上传最多5个文件，每个10MB。![](img/zhuanqian_050066dc3a316f1365f20be8f0a86a9d.png)

一开始用Chato，优点是支持大文件训练，单次可传20个文件，每个30MB，还能直接输入文本或抓取网页。缺点也很明显：训练慢，要在训练页和对话页之间来回切换，回答质量也不够满意。对比下来，后来主力用Claude。上传、提问、回答的流程顺畅，速度快，回答质量也更高。

上传文件后，我用的提示词是：

“上传的文本是xx老师写的文章，请根据文章总结概括他的学历背景、工作履历、擅长的领域，擅长在什么平台做什么事，比如：擅长在抖音、微信平台建立IP。不超过100字。只能基于给定文本内容回答，不能做额外假设，不要随意推断，请百分百根据文本内容真实作答。”

效果见图：![](img/zhuanqian_4a454d1427ba647aec1d901b72331de8.png)

有时候AI还是会胡编或答得不好，所以我会把答案里的关键词放到原文里搜一遍，验证是否属实。质量不高的话，就按自己的理解修正，或继续追问。

# 通过自我介绍进一步完善

一开始遇到AI不准的情况，我就想：有没有高手的自我介绍？喂给AI再答一遍，可能会准很多。后来发现，赚钱索引站手机端直接就能看自我介绍——就是加入赚钱时鱼丸让大家提交的那段。自我介绍页也能通过榜单或搜索到达。![](img/zhuanqian_83c4efb2ba617f398a05c29084b4a82f.png)

电脑端也可以打开手机端页面，在开发者工具里执行一段JS代码，直接把个人简介内容抓出来。结合AI分析结果和自我介绍，最后总结出五六个关键词。举例如下：![](img/zhuanqian_f8bfa06851a3ddb15e5568514402da9c.png)

# 收获与展望

这次最大的收获，是把脑子里几个碎片串成了一条线：AI训练、个人兵器库、油猴脚本、认识龙珠高手。

过程本身才是最有价值的。在“遇到问题→解决问题”的循环里，我确实被锻炼到了。遇到感兴趣的人和文章，会顺手关注收藏，还发现了一些有意思的现象：有些高手已经很久不活跃了，他们现在在关注什么？要怎么才能重新激活这部分资源？

虽然没有直接赚到钱，但把一件事做成，给自己带来了很多正反馈，也能向外传递价值。当正反馈积累得足够多，赚钱是水到渠成的事——它只是持续输出价值的副产品。
