# 给初中生的编程入门路线：用 AI 工具 1 个月从零到上线 Web 应用

最近有初中生来问：想入门编程，到底该从哪里开始？我如果是初中生来学，我会直接上 AI 原生开发的路径，而且我可以赞助你学习期间会用到的付费工具，比如 Cursor、v0、Claude 的订阅。

别只盯着国内的教程。去 X 外网搜 “AI 编程学习” 或跟着当下流行的 AI 编程航海计划走，相关资料非常多。网上已经有人整理好了系统学习框架，参考价值很高。

下面这套方法就是一个实战者的总结：他花了 48 天、累计 217 小时泡在 Cursor、v0 和 Claude 上。48 天前他对 Next.js 的路由规则完全不懂，现在却能 4 到 7 天内独立搭完一个带前端、后端、登录和官网的完整 Web 项目。精髓就是把 AI 当作大脑，把自己当作项目经理。

**实操拆解如下：**

1. 先写文档，别急着写代码

把 80% 的前期精力放在用 GPT-4o1 这样的模型产出高质量文档上。包括项目需求文档 PRD、每个页面的布局结构说明、整体业务流程说明、功能清单文档。全部整理成 .md 文件后上传到 Claude。

2. 让 Claude 做项目总指挥

Claude 是核心大脑。注意 Cursor 自带的 Claude 3.5 Sonnet 表现一般，建议直接用独立的 Claude 项目，把第一步的全部文档丢进去做上下文。

3. 用 v0 快速出前端界面

Vercel 的 v0 是前端设计的神器。在 v0 新建项目，把仪表盘页、流程文档、功能文档等内容粘贴进去。v0 就能理解技术栈和需求了。构建时一定要把页面拆成头部、数据统计、表单等多个小组件，这样修改不会牵一发而动全身。

4. 把 v0 生成的代码喂回 Claude

把每个页面的代码再拷贝回 Claude 项目里，让它同时理解代码实现和原始需求，后续在 Cursor 里操作会顺畅很多。

5. 用 Replit 当桥梁

Replit 能把 Cursor、Github 和本地运行环境连起来。在 Replit 上新建一个 Next.js Repl，我自己用的是 Supabase + Next.js 的 Starter Kit，效率很高。接上 Github 后，用 SSH 把 Cursor 连进来。

6. 在 Cursor 里搭骨架

按 Claude 给出的建议创建好所有文件夹和文件结构。代码在 Replit 上跑起来，把 v0 的代码放到对应位置，装好依赖。

7. 后端交给 Supabase

数据库、文件存储和用户认证都用 Supabase 搞定。建新项目拿到密钥后，填进 Cursor 的 .env.local。

8. 让 AI 生成后端逻辑

数据库表结构、存储桶、认证表都让 AI 来写，然后按 Claude 的指引执行。完成后前后端就打通了。

9. 调试优化

用 Claude + Cursor 联合排查问题，把所有页面的功能逐一测试并优化。

10. 快速做出官网

落地页的内容和排版用 o1 模型打磨，v0 生成代码，Cursor 整合，Replit 部署。现在你就拥有了一个完整的现代 Web 应用 + 官网。

看起来步骤多，其实门槛已经很低了。50 天前他还完全不懂 Next.js 路由、数据库设计、登录鉴权、shadcn Radix、SSH 链接这些概念，全靠 AI 学会。现在 30 天内他就做了 7 个项目。

他的思路很清晰：不用先想商业计划，用 AI 先做出产品，再把项目卖给客户或放到 Acquire.com 上，循环迭代。构建本身最有意思。

评论区也有同行验证了这个路径的可行性，有人用 Cursor+v0 上线了小程序，也有人认为这是目前看到的最完整的 Cursor 和 v0 入门整合方案。

如果你是初中生，现在正是用 AI 学编程最好的时机。先从文档、Claude、v0、Cursor、Replit、Supabase 这套组合开始上手，比传统啃书快太多。
