# 在家带娃也能赚钱？我靠 Cursor 做了件漂亮事，还顺带接了 2000 商单
大家好，我是 Susumr，一个会 UI 的产品经理。自由职业第10个月，日常就是边带娃边琢磨怎么搞钱。
之前我分享过一个用低成本网站赚被动收入的项目，现在仍稳定运行。今天聊聊我在 AI 编程上的一次实践——用 Cursor 做了两个事：一套 Telegram 频道矩阵自动发布系统，以及一笔 2000 元的商单。
## 一、从手动搬运到全自动：我的 TG 频道进化之路
最早我做内容聚合，用的是 RSS + IFTTT：从国内一些公开平台抓取优质内容，再自动同步到 Telegram。这套机制简单高效，帮我攒了数万订阅者，覆盖科技、生活等好几个方向。后来我尝试在频道里接广告，没想到很快成了几单，赚到了第一笔 TG 收入。
![](img/1f6864303b7f11b3c92c665122908e23.png "None")
但时间一长，问题也暴露了：RSS 源内容参差不齐，重复、低质、甚至无关的帖子时常出现；IFTTT 也开始收费，限制多得让人难受；每天还要手动筛一遍再发布，效率特别低。我决定换个思路，干脆花钱订阅 Cursor，照着航海手册里的 AI 编程方法论，从需求拆解到功能设计，再到写代码，一步步搞出了一套自动化发布系统。
现在我的工作流变成：集中一天处理内容，用 RPA 工具或者手动收集，一次性备好一个多月的内容。接下来一个月基本不用管，偶尔瞥一眼就行。频道运营效率涨了不少，内容质量也回到可控范围，即使有广告，订阅数照样在涨。
这套系统暂时自用，下一步我打算尝试商业化。

简单介绍一下这套系统：它叫 Telegram 矩阵频道消息发布管理系统，支持多机器人、多频道，定时发布、自动任务、模板管理都有。架构上是前后端分离，后端 FastAPI，数据库 SQLite，算得上一个完整的发布工具。核心功能包括：
- 机器人管理：多机器人接入、状态监控、权限控制
- 频道管理：多频道关联、状态监控
- 消息编辑与发布：Markdown 格式、图片多传、GIF 动图、定时发布、状态追踪、历史记录
- 自动任务：CSV/Excel 导入、自定义发布时间和频率、内容模板与字段映射
- 模板管理：模板创建、变量替换、格式化设置
## 二、i 人日更朋友圈，竟然换来一个千元订单
我原本是那种很少发朋友圈的典型 i 人，总觉得把事做好就行。最近我试着改变，每天发一条，记录孩子成长、学习新技能的感悟、以及一些小小成就。没想到朋友们很买账，点赞留言多了，还有人主动来闲聊天。

说起来，开发倒很顺，毕竟我知道怎么和 AI 配合；真正让我崩溃的是部署环节。环境、依赖、配置一堆问题接踵而至，而我没系统学过编程，只能照着文档一点一点试。后来我索性放平心态——哪怕一个小问题，也从头再来。多撞几次墙之后，居然也能流畅部署了。
这段经历给我的最大触动是：主动展示自己，真的能带来意想不到的机会。日更朋友圈虽然一开始不习惯，但慢慢给了我自信，现在几乎每天都有朋友来咨询或问候。
## 写在最后
自由职业这 10 个月，家里添了新成员，我既能陪娃，也能探索新可能。虽然时间经常打架，但回头看，还是自由职业更香。昨晚跟一个老朋友感叹：自由职业者一定要保持开放心态，时刻准备着链接新事物、新机会。
自由职业远非终点，而是另一个起点。这条路，我还在继续走。
