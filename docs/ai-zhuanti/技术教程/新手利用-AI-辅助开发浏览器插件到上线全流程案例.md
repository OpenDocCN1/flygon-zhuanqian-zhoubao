# 新手利用 AI 辅助开发浏览器插件到上线全流程案例
作者：龙哥

大家好，我是龙哥，一个93年出生的跨境电商创业者。高中起就自学编程，大学毕业后在深圳一家跨境大卖做海外组，后来自己出来做软件SaaS。目前我们的产品服务了不少国内外卖家，覆盖全球17个国家，累计触达近3亿海外客户。技术谈不上多牛，只是刚好踩中了一点小风口。

之前主要服务国内客户，2023年才正式做面向海外用户的业务。从一个个小工具站开始，折腾了半年多，拿到几万美金的海外收入——在各位大佬面前不值一提，但至少证明这条路能走通。

为什么今天要分享这个？因为我发现很多新手和跨行朋友，看专题知识时都能懂，但没法连成一个完整的实操链路。所以我想拿一个真实需求做例子，带大家用AI在一天内把浏览器插件从需求到上架全流程跑一遍。顺便提醒一下，航海手册里还有一份插件开发专项指南，链接放在这里：https://search01.shengcaiyoushu.com/docx/doxcnNpOUMTUF7Dtxz3Ebkupwod ，搭配着看更省力。

事情起因是一个做亚马逊的卖家客户。他们发现最近购买的礼品卡（类似国内的京东E卡、天猫猫卡），邮件里不再显示兑换码，只有一个“充值到账户”的按钮。以前可不是这样的，大家看对比图：

![](img/zhuanqian_f6d5b63c99d0817872be4dd1d5235a6c.png)

![](img/zhuanqian_eddc52de2267c663e38caca9c81780e9.png)

可以看到新版邮件确实不再展示Claim Code。我点了一下那个充值按钮，登录买家账号后，出现的页面长这样：

![](img/zhuanqian_239bdd02bd1e228827d05adb33a9082a.png)

接着用F12看一眼页面代码，马上能发现这是个表单，兑换码其实就在里面，只是对应input的type是hidden，所以不显示。相关截图如下：

![](img/zhuanqian_4db937f505c865be1ebe54e97ebab522.png)

帮客户拿一次兑换码容易，但他以后还买啊，总不能次次都找我。所以我想，干脆做个插件，让页面一加载就自动把这个隐藏的input改成text，兑换码直接显示出来。只需要一点点HTML基础就行。

需求明确了，写代码这种事就交给AI。我把想法描述了一下，AI几秒钟就生成了完整插件代码。它默认给出的是Manifest V2版本，本地用没问题，后面再让它升级成V3就可以了。

![](img/zhuanqian_21ca226b4f3f08ff267b73237f008840.png)

我按照AI的指导，新建了一个“amzgiftcard”文件夹，把需要的几个文件都创建好，代码也复制进去。然后发现代码里需要images目录和三个尺寸的图标，于是去iconfront.cn找了个合适的图标，分别下载16×16、48×48、128×128三种尺寸，重命名为icon16.png、icon48.png、icon128.png，全部按路径放好。最后的目录结构是这样的：

![](img/zhuanqian_1be444dae1d95a7b01191d12e8199b19.png)

![](img/zhuanqian_83742865197180b7da08023bd159a3eb.png)

在Chrome里加载这个本地插件，重新打开礼品卡页面，兑换码马上就出现在文本框里，复制就能用，一次通过。如果遇到报错，多半是文件不全、命名不对或图片尺寸不符，检查一下就好。

![](img/zhuanqian_843a652a85d87b6676068c829f246012.png)

本地能用，但上架谷歌商店还差一步——把代码升级到Manifest V3。我让AI继续改了一版，顺便还发散了下思路，比如把所有hidden和password类型的input都搞成可见，做一个“星号密码查看器”之类的工具，功能会更有通用性。

接下来是发布流程。首先进入Google开发者控制台，用谷歌账号登录。如果是第一次注册，需要同意协议，并支付5美元的一次性开发费——真的很便宜了，看看Shopify开发者要99美金，这个简直等于免费。

![](img/zhuanqian_1da7659023a68ec8d2b6524fe13a85ac.png)

谷歌官方发布教程也写得很详细，链接我放这里：https://developer.chrome.com/docs/webstore/publish/ ，需要的朋友直接看。发布操作其实就是把整个插件文件夹打zip包上传，没什么复杂的。

![](img/zhuanqian_7cb610de2680f3aaca2c7e3a165dadab.png)

整个过程中，我最想说的是隐私栏的填写。一开始我自己瞎写，结果被打回两次，特别挫败。后来干脆把这个栏目的问题和要求全部丢给AI，让它帮忙写，一次就通过了。所以啊，遇到这种偏文案的事情，别自己硬扛，直接问AI就好。

![](img/zhuanqian_96481279ae0b4d04da406c22040679fc.png)

关于插件变现，前辈们已经总结过很多玩法了。就拿这个小插件来说，用户群非常精准——都是亚马逊卖家。那么完全可以在显示兑换码的位置下方，加一行带链接的文字，接广告或者推广服务商的分佣链接，都是不错的变现方式。更多可能性，值得大家一起发散思维。

好，全流程就讲完了。你会发现，在AI辅助下，新人一天之内做出一个能上线的浏览器插件，真的不是天方夜谭。别总想着做到完美再动手，先完成，再优化，再谈变现。做工具站的朋友也一样，像小排老师说的，一个函数就能撑起一个产品。希望大家都能行动起来，共勉。
