# 公众号 AI 写作，原创情感文写作 prompt 开源

最近在捣鼓公众号情感文的时候，发现了一个挺不错的效率神器，必须分享给各位。

很多做情感号的朋友应该都有同感：选题、搭大纲、写正文，每一步都挺耗神的。虽然我也早就用上了 ChatGPT 来帮忙，但一篇文章从初稿到润色完成，怎么也得折腾三四十分钟，有时候甚至要一个小时。关键是情感号还讲究“量”，得铺大量文章去试，看看哪篇能幸运地冲进公众号的流量池。这样算下来，每天光在写作上就得砸进去一两个小时，真挺心疼的。

后来我参考了不少结构化 Prompt 的玩法，自己花时间琢磨出了两条提示词，一条是《根据主题编出一个情感故事的大纲》，另一条是《根据故事大纲编写出一篇富有情感的短篇小说》。这两条搭配起来用，效果着实惊艳——一篇情感故事，五分钟就能搞定初稿，效率直接起飞。

现在我把这两条 Prompt 开源出来，已经整理好放在语雀文档里了，链接在文末。希望能给圈里的朋友们多一些写作灵感，大家一起进步。

当然，我自己也清楚，这套 Prompt 还远谈不上完美，还有蛮多可以打磨的空间，比如它暂时写不出那种让大众欲罢不能的狗血剧情（毕竟那也是个技术活哈哈）。所以也特别欢迎各位提提建议，一起把它优化得更顺手。

目前我这边用的是 GPT-4.0 测试的，评论区有朋友问 3.5 行不行，我晚点也调一下，尽量让 3.5 也能直接跑起来。
