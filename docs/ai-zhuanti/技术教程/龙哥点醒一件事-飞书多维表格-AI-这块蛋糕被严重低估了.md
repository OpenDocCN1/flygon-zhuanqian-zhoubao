# 二、先做市场摸底

先去小红书和闲鱼上搜了搜“多维表格”，发现已经有一批在做的玩家了，品类大致能归为四类：

一是多维表格与AI结合的小工具，比如自动记账、文献速读、电子橱窗、小红书笔记采集等；

二是基于多维表格搭建的团队和企业管理自动化/工作流模板，从胖东来、海底捞这种大体量，到跨境电商海外仓管理、电商团队协同、KOL合作管理等细分领域都有；

三是教学和培训类内容，既有飞书官方的，也有个人在做的课程；

四是定制化搭建服务，涵盖AI工作流融合与企业管理提效，飞书官方给企业的搭建报价是4999。

# 三、入门后的震撼

把从0到1的课程过一遍后，再去看那些海量的官方模板和复杂的工作流，感受很直接：这玩意儿已经不是传统意义上的表格了。它可以被做成ERP、SCM、CRM、SRM、OMS、WMS这类企业系统，也可以和AI联动形成自动化工作流，更能变成各种提效小工具。

当然，我的认知还很浅，对比专业的商业系统，它在某些专业功能上可能还不够完善。但搭建门槛极低、成本极低这一点就很致命，对中小企业和互联网团队非常友好。纯AI工作流可能比不上Coze、RPA那么极致，但上手快，复杂需求也能和Coze、RPA联动，基本能满足大部分开发诉求。

![](img/zhuanqian_74c61b8eff8d57e4cd9ca7d47f0ae8e8.png)

# 五、我的判断

同类型的小工具搭建起来非常快，本质上就是一个迷你App，可组合的场景太多了。

比如旅游类：输入目的地、出行时间、人 Jakub、预算、偏好，自动生成行程方案，旅行结束后上传体验感悟自动沉淀为个人旅行档案；

比如阅读类：输入需求自动推书单、解读书籍、记录阅读进度和笔记，并沉淀为个人知识库；

比如招聘类：批量导入简历自动更新、拆解结构化信息、生成评估结果并按岗位优先级排序；

诸如此类，每个细分痛点都能做成一个独立小产品。流程就是搭建 -> 测试 -> 推广 -> 迭代 -> 收费，形成完整闭环。虚拟资料赛道完全可以嫁接进来。如果验证效果不错，还能继续升级成小程序或App，和AI编程结合，甚至可以作为AI编程产品的原型验证环节。

![](img/zhuanqian_5d80bb00b4ea496e71947e9154d8db7f.png)

AI编程有灵感却苦于App开发周期长、成本高、用户不确定，多维表格正好可以作为低成本的MVP验证工具。目前多维表格里的Maker生态就是这么在玩的。

另外还能和知识库结合做社群运营，典型案例就是通往AGI之路。

![](img/zhuanqian_4131d771c0dbbe1fcb1b5657c6b4215a.png)

AI赛道已经跑通了，有没有别的赛道可以用同样的打法再复制一遍？

知识付费也是个方向。Excel、PPT教程都能养活一大批团队，多维表格功能更强、应用更广、难度也更高，教学赛道大概率会起来。而且不仅有个人的需求，企业端的需求也值得期待。

# 六、变现路径拆解

## 1）与自媒体账号结合

你是极简生活博主，可以做一个断舍离的个人物品管理系统，粉丝打卡刚需，增量空间不小。（见图1）

你是自律博主，可以做一个人生操作系统，类似的Notion模板在小红书很火，多维表格版本还有机会。（见图2）

你是自媒体运营博主，可以做一套小红书爆款笔记采集、数据分析、选题追踪、内容仿写的一体化提效工具，加AI后更有竞争力。（见图3）

甚至咖啡博主都能做咖啡豆管理系统（见图4）。如果暂时没有定位，直接做飞书多维表格垂类博主也有一条路（见图5、图6）

同理，穿搭博主可以做衣橱管理系统，职场博主可以做效率管理体系，宠物博主可以做宠物医疗档案系统……几乎没有哪个垂类不能挂靠上来，这等于给每个自媒体多了一条变现支路。

## 2）卖模板

官方模板不少，但精致度、覆盖面、细化程度都有限。做细分领域的精品模板，或把官方模板整理打包售卖，都是可行的。官方目前态度偏鼓励。注意别直接搬运别人的模板，稍作改造即可。上架很简单，截图+排版精美化发笔记就行，小红书+闲鱼双线操作，正反馈相当快。与自媒体结合卖模板也属于此列。

## 3）卖教程/课程

和Excel的玩法高度相似。找对标拆解流程后复刻即可。市场目前还很宽松，还能承接官方直播课程的分销，KOC合作佣金也很可观。最关键的是，市面上几乎没有一套真正从零开始、系统完整、足够细的入门教程。有刚需吗？我个人觉得非常刚需。如果有一套这样的体系课，我很愿意付费。官方课程目前偏科普，知识点比较散。

![](img/zhuanqian_5b0ecc288c65d2e0c02dfe8791923223.png)

## 4）卖服务

面向企业做提效和管理体系搭建，比如“一表管全公司”的多模态管理系统、KOL达人管理系统等。这条路需要对多维表格有较深理解，部分场景还涉及代码。也可以面向个人做模板的私人定制，并与Coze、RPA结合打造更复杂的AI工作流。玩法很多，已经有小红书账号开始投流接企业定制单了。

## 5）做产品开发

4月26日我在西湖参加了飞书多维表格的线下活动，现场三个Maker分享了他们的产品：全量抖音短视频数据抓取、新媒体全链路信息采集、AI简历秒筛神器。都是前文提到的工具型产品的进阶版，大多结合了RPA抓取+多维表格管理分析。关键是官方会主动推广，我加入了他们的产品群，基础用户池先有了，再根据用户反馈迭代优化，从免费过渡到付费，整个链路很顺畅。

## 6）进阶玩法

结合知识库做社群，比如通往AGI之路那种模式，用海量资料搭建知识框架来运营社群。飞书文档付费阅读和知识问答都在内测，时机不错。
