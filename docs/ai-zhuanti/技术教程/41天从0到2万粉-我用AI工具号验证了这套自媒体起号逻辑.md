# 41天从0到2万粉，我用AI工具号验证了这套自媒体起号逻辑
大家好，我是龙哥，现居杭州。
从1月1日启动账号，到今天正好41天，全网粉丝破2万。过年期间DeepSeek虽然火，但并没有给我带来爆款。
# 一、现在的数据盘点
从今年1月1日起，我同步在小红书、视频号、抖音三平台发AI相关短视频。
41天累计：小红书8,900粉，视频号8,600粉，抖音2,000粉。
变现情况：目前完全靠商单，已经接了6单，总计4,000元左右。其中两单千元以上，其它几单几百元不等。
即便没有出过真正的大爆款，粉丝依然保持每天100~200的稳定增长。
# 二、怎么选到AI工具这个赛道
这是我第一次做自媒体，最大的顾虑是坚持不下来、看不到变现、操作门槛高。
所以我给自己定了4条筛选标准：做起来有正反馈、能快点看到钱、制作门槛低、竞品不算卷。
带着这4条标准，我在公众号、小红书、抖音上用“AI”做关键词开挖。
先在公众号搜AI相关的文章，然后顺着收藏、点赞、关注的路径去看创作者的关键词，再看公众号的推荐流。就这样反向扒出了一个关键词池：AI、AI前沿资讯、AI提示词、AI工具、AI变现、AI神器、AI软件、AI搞钱、AI副业、小白学AI、普通人学AI、AI智能体、AI绘画等等。
再把这些词分别丢到小红书和抖音去搜，边看边点赞收藏关注。来回跑几轮后，内容形态和头部账号的画像就清晰了。
最后我锁定了AI工具这个细分方向。它正好对得上我前面说的4个标准：对着电脑演示工具即可，剪辑不复杂，变现路径就是接商单。
| 细分赛道 | 小红书对标账号 | 为何放弃 |
| AI前沿资讯 | 朋克周、赛文乔伊、马克张 | 受众面偏窄、剪辑工作量大、需要持续追踪海外动态，前期很难快速变现，更适合后期再试水 |
| AI副业 | 柿子的AI赚钱笔记、AIGC自修室 | 剪辑难度高，正反馈慢，变现靠卖课和直播带课，自己没有经验 |
做完这轮调研我才发现，这套方法跟我在工作中做产品调研、竞品分析的思路一模一样，用一个关键词就能以点带面把全盘摸清楚。方法通了，自信也就起来了。

## 3.3 文案怎么写
文案是转化核心，跟年终汇报一个道理：把一年的工作浓缩成半小时，要精华、要重点。
工具介绍我固定4步：
1、先报名字
2、一句话说明用途和核心优势。写之前我会去官网看首页介绍，那是最核心的卖点。免费开源的要重点强调，大厂出品要强调背书，付费的我基本不提付费二字。
3、说清楚适合谁、在什么场景用
4、最后加钩子：关注领xxx。这个技巧是我做了一个月后才开始用的。
视频时长我一般对标同行，现在稳定控制在20S左右。之前试过30-40S的，转播放效果明显下降，所以现在跟广告主沟通时也建议20S内。
写文案的打法：把几个爆款文案丢给Claude，让它分析火的原因，然后把我总结的核心功能、适用人群、场景丢进去，让它改写成意思一致、字数相近的新版本。
## 3.4 配音怎么选
最开始我用自己的声音，发现情绪不够饱满。后来换成AI配音。
在第3-6条视频时，我特意测试了不同音色，控制时长和选题大类一致，比如都是面向学生或打工人。测试下来发现音色对转化影响不大。
常用的免费配音工具：
https://anyvoice.net/zh/ai-voice-cloning
https://ttsmaker.com/
https://fish.audio/zh-CN/
https://speechma.com/
https://ttsopenai.com/
GitHub上开源的很多，有时间也能自己搭一套收会员费。
## 3.5 剪辑要点
配音和素材有了，就导入剪映。剪辑我也是从B站跟着学起的。
对工具号来说，最耗时的就是音频和画面时长对不上，需要调变速。其他就是加转场、做封面、叠字幕、调字幕颜色等基础操作。
跨设备传文件我用localsend，Win/Mac/Android/iOS通用，免费不压缩。
## 3.6 商单怎么接
第一个商单来的时候我完全懵，不知道“返点”是什么意思。我以为是用户买了给我分佣，后来去小红书和B站查资料才明白。
一步步走下来完成了第一单，感谢第一个广告主没嫌弃我，现在准备二度合作。
今年AI应用爆发，商单需求在增多。我接的两单千元级别来自视频号和抖音，是平台主动找我合作。粉丝里约20%是海外华人，他们主打海外市场，合作并非为了涨粉，而是为了让投资人看到有人在主动传播他们的工具，给投资人讲故事。
说实话，我更不喜欢被动接单这种不可控的变现方式。目前我正在探索工具号的其他变现路径，正在测试中。
