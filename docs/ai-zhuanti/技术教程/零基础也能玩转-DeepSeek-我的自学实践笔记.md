这是我询问 deep seek 他给我的处理方案

你可以通过以下步骤将 Ollama 的模型存储路径迁移到其他盘符，从而避免占用 C 盘空间：

* * *

### 方法一：通过环境变量修改存储路径

1.  创建目标文件夹在目标盘（如 D 盘）新建文件夹，例如：D:\ollama\models

1.  设置环境变量

*   Windows 10/11

1.  右键点击“此电脑” → 选择“属性” → 进入“高级系统设置”。

1.  点击“环境变量” → 在“用户变量”或“系统变量”中新建：

*   变量名：OLLAMA_MODELS

*   变量值：D:\ollama\models

1.  重启电脑使环境变量生效。

*   命令行临时设置（每次启动需重新设置）在命令提示符或 PowerShell 中运行：

```
setx OLLAMA_MODELS "D:\ollama\models"
```

1.  安装并运行 Ollama 现在运行 ollama run deepseek-r1:7b 时，模型会自动下载到新路径。

* * *

### 方法二：使用符号链接迁移默认文件夹

如果环境变量无效，可用符号链接重定向默认路径：

1.  移动原有文件夹默认路径为 C:\Users\<用户名>\.ollama，将其剪切到目标位置，如：D:\ollama

1.  创建符号链接以管理员身份打开命令提示符，执行：

```
mklink /J "C:\Users\<用户名>\.ollama" "D:\ollama"
```

替换 <用户名> 为你的实际用户名。

1.  验证路径运行 ollama run deepseek-r1:7b，模型将存储到新位置。

* * *

### 注意事项

1.  权限问题确保新文件夹（如 D:\ollama）有写入权限（右键文件夹 → 属性 → 安全 → 编辑权限）。

1.  磁盘空间确认目标盘有足够空间（7B 模型约需 15GB 左右）。

1.  备份数据操作前建议备份原 C:\Users\<用户名>\.ollama 文件夹。

* * *

通过以上任一方法，即可将模型下载到其他盘符，避免 C 盘空间不足的问题。

## 用DeepSeek测算八字的几种玩法

接下来进入重磅环节，给大家分享几个测八字的提示词，顺便说说它们的优缺点。

### 第1招：普通版，直接提问

你可以在对话框里输入这样的信息：“庚辰戊子辛亥庚寅，女命，大运是2004-2013丁亥，2014-2023丙戌，2024-2033乙酉，2034-2043甲申，请帮我测算一下，重点看事业和财运，并用表格列出2025-2030这5年的事业财运走向以及注意事项。”

这里有个建议：最好先用八字排盘工具（比如问真八字、测测）把盘排好，再把排好的大运像我这样直接列出来发给DeepSeek。简化一下公式就是：八字信息+性别出生时间+已排好的大运区间（建议3-5个，含过去未来）+想测的重点。这么提问会更有针对性，出来的答案也更贴近你的需求。然后你可以根据回复里感兴趣的内容继续深挖。

### 第2招：中西合璧，交叉验证

这个玩法需要给DeepSeek一个“人设”提示词，让它扮演专业算命先生，要求它具备以下硬实力：

- 中国传统命理学：精通八字、紫微斗数、六壬神课等，能熟练运用干支、纳音、神煞、流年流月等概念。

- 会分析八字五行、十神、十二宫位，并把这些和事业、婚姻、健康联系起来。

- 占卜技能：六爻、奇门遁甲、太乙神数不在话下。

- 风水学：能从居住环境角度提供调整建议。

- 西方占星术与血型学：熟悉十二星座、行星宫位，能解星盘，还会结合血型分析性格和行为模式，并把血型特征与八字、星象等命理结合。

- 职业素养：具备心理学知识，善于沟通倾听，客观公正，不误导人，保持谦逊和正能量，同时坚持因人而异，对具体情况保持开放态度。

这个提示词不限于八字，你可以拿来测紫微斗数、星盘、占星等等。重点是每个主题开一个新对话，这样不会互相干扰。多测几个方向，再对照结果，看哪个更贴合实际，然后顺着那个方向继续追问。

### 第3招：引经据典+特殊规则

这一招要求DeepSeek化身为资深命理学家，熟读《三命通会》《渊海子平》《滴天髓征义》《穷通宝鉴》《子平真诠评注》这些经典。你给它提供出生时间（精确到分钟）、性别、出生地，然后请它完成：

1. 整体分析格局，结合身强身弱、十神关系、体用平衡，必须逻辑合理，交叉验证后给最终结论。

2. 画一张ASCII字符版的五行能量分布图。

3. 排出大运和流年，并列出命主的历史事件，尽量丰富细致，用来校验准确性。

4. 根据未来五年的大运流年推测运势，给出指导意见。

同时要告诉它大运起法：三天折合一岁。阳年男命、阴年女命顺行；阴年男命、阳年女命逆行。按出生日与上一个或下一个节气的相距天数推算。

输出格式要求用白话文分段论述，既要专业术语，也要让人听得懂。

这招的亮点在于ASCII图，能把五行强弱的对比直观展示出来。举个例子，给过一个命盘“癸未壬戌己卯辛未”，DeepSeek会先分析日主己土生在戌月，地支三土，土势极旺，财星食神虚浮，七杀受制等，然后画出五行能量分布图：

```
░ ▒ ███████ ░ ░░
弱 中 极强 弱 弱
```

接下来排大运、验证历史事件，再预测未来五年。原文特别长，我就不全放出来了。![](img/zhuanqian_2569fc7d883548715349a3ac0f5af017.png) 不过要小心，它参考的经典大多是书房派，无论哪一派都有各自的局限。我个人感觉这个输出有些问题，比如五行能量的强弱分析并不完全准确（本人有半年集中学命理的经验），外行可能看不出来。建议你多批判它，多反问几次，让它自己纠错。

### 第4招：盲派铁口直断，前事测验

这个提示词的核心是让DeepSeek用盲派技法来分析。比如你可以说：“我是男性，八字是癸X壬X己X辛X。请用盲派技巧逐步分析八字，分析我的一生运势、体貌特征、时间节点和事件，越详细越好。着重分析大运能赚多少钱，包括学业和婚姻，建立准确的关系模型后输出结果。请诚实评价，不用温和的措辞。”

盲派和传统书房派不同，它不太讲究用神、格局那套东西，追求“铁口直断”，直接把你过去、现在、未来的事情像念判决书一样说出来。但正因为这样，盲派也经常出错。所以你可以主动提供前事来定盘，比如：“我在xx年发生了xx事，请结合这件事修正我的命盘。”

大家反馈的效果是怎样呢？它会分析你的外貌（比如土旺骨架粗、七杀眉眼锐利、食神嗓子好），性格（土多固执、财透无根、七杀压力大），命局的矛盾点，大运流年的关键节点（包括哪年赚大钱、哪年婚姻有变），最后还有财运量化和婚姻预警。内容非常直白，准不准就见仁见智了。原案例太长，这里先略过。

## 最后：说说用DeepSeek算八字必须警惕的一个认知差

从我个人的观察来看，会去找DeepSeek算八字的人，大多是对八字感兴趣但还没入门的萌新。这就会引出几个明显的认知差：最核心的一点是，你没法判断DeepSeek算出来的东西到底对不对。因为你不懂命理，只能对着它生成的内容傻傻地点头认可，完全不怀疑。所以我的建议是：把它当成一个拓展思路的参考工具，而不是权威真理。真有大事要定夺，要么找信得过的师傅，要么自己下点功夫学学基础，再回头审视它的输出。

最近 DeepSeek 很火，很多人拿它试八字、奇门、梅花。我也玩了一堆，先说结论：能玩，但别把它的输出当标准答案，尤其是命理，差之毫厘，谬以千里。

八字里看五行强弱，从来不是数数那么简单。金木水火土各有几个，代表不了真正的能量格局。你要看这个字有没有当令得令，落在旺相休囚死哪一档，再叠十二长生的位置。推理方向一旦偏了，后面的断语基本就废了。

另一个问题是心理承受能力。DS 一旦推出一段不太好看的命，尤其是推理有明显偏差的时候，心态差一点的人，当场就吓出一身冷汗。可这多半是你自己吓自己，也说明拿这工具算命，本身就不太靠谱。

有个朋友问我：DS 说我是“身弱”，是不是身体不好、容易生病？完全不是。命理里的身弱，指的是五行流通中自身能量偏弱，需要别的五行来生扶，从而判断喜用神。它跟现实里体质强不强，八竿子打不着。

再说正规流程。多数人算命，也就是听几句性格、体型，被告知身强身弱，再收到几条不知从哪来的建议，就结束了。

但正经看八字，是要写命书的。靠谱的师傅会先跟你核对前事，比如你几个兄弟姐妹、是不是独生子女，以此来验证命盘没错、出生日期时辰没排错。确认之后，再推一生福祸，涵盖妻财子禄、穷通寿夭。放到现在说，就是何时能发财、仕途如何、婚姻顺不顺、考公考研考编行不行、孩子怎么样、几时低谷几时翻身。最后还要给可操作的建议：该亲近什么、避开什么、家里风水要不要调、祖坟周边要不要清理草木。

所以用 DS 看八字，理想前提是你自己懂点易理，能第一时间发现它跑偏，再一直换角度追问。

实操上，可以先让 DS 推前两步大运，你用真实记忆去校准；校准完了，再让它推后面几步大运。

### 小说推文自动化：从文字到分镜到绘图prompt

以前我在做小说视频项目时，流程很固定：先用AI把小说内容“洗一遍”，提炼成一个个分镜；再把这些分镜转成出图模型能读懂的prompt。

![](img/zhuanqian_bf3e81d15ba44a96ead97d467bcd1bb0.png)

因为是批量执行，所以指令必须高度凝练，一次把需求说透。担心输出不稳定的朋友，可以把以前在GPT上沉淀的模板拿过来用，也可以去 https://www.aishort.top/ 找灵感。李继刚老师分享过的prompt写法同样值得学习，模仿几轮就能上手。

调优的笨办法是：先写一版初稿，分别交给Kimi / 豆包 / ChatGPT等几个模型跑一遍，观察结果；再继续追问，让它们各自给出一版你认为更接近目标的方案；最后把不同AI的答案放在一起，取长补短，合成终稿。这招可以叫“模型互相校验，左右互搏”。

### 如何把提示词打磨得更可用

这个思路来自我帮朋友改稿的经验。他的需求是让AI润色几千字的长文，但试了多个模型，输出都被压缩成几百字。解法是分段改：先手动改一段作为示范，再把“要求+示范”一起写进提示词，让AI改写500字，看看偏差出在哪里。然后给提示词增加几个##attention，比如：

##attention1: 不要压缩字数，原文与修改后字数差距不得超过±5%

##attention2: 不要省略细节，不能为了精简而歪曲事实

再测500字，效果稳定后就能定稿。

类似的，我也给一位老板做过短视频脚本指令。核心是：模仿对标视频文案，按拍摄节奏拆解，比如每5秒给一段文案、画面和口播语气；并额外用##attention锁死输出格式，不许它写成直播脚本或建议清单。只要产品文案给到位，指令就会自动生成带时间轴的完整分镜脚本。

如果自己写指令心里没底，可以把初稿放进提示词优化工具里过一遍。除了网上常见的Prompt Judger，火山引擎也提供同类工具，现阶段免费试用，之后可能收费。

提示词自改工具链接： https://console.volcengine.com/

（素材里附带的Prompt Judger，是一段能给prompt打分的分析器代码，主要功能是：按1到10分给用户提交的prompt打分，指出改进点并输出优化后的完整版，同时不改动用户原始意图。把它嵌进工作流，能帮你快速判断指令质量。）

等指令打磨完毕，再把它和飞书多维数据表结合，就能批量产出内容了。
