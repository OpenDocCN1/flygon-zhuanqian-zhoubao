# 被播放量逼到动手写代码，零基础做 YouTube Shorts，我搞了 4 个脚本翻身

来聊一聊最近折腾 Shorts 的真实状态。不敢说有什么经验，毕竟我离 YPP 的门槛还隔着十万八千里。

先说底子：这之前从来没碰过 YouTube，也没接触过 Cursor，完全从零起步。

第一个号目前投了 11 支短片，总播放量差不多 20 万，攒下 177 个粉丝，其中一条表现最好的片子单条已经破了 11 万。

第二个号发了 6 支片子，总播放大概 3.5 万，粉丝数只有 20，其中还有一条直接是个鸭蛋。两个号差得不是一星半点，到底是号没养好、选题出了问题，还是纯粹运气没站这边，我也说不太清楚。

# 选题为什么押在科普赛道上

最初想冲这个领域，是因为龙哥经常在社群里点名这个方向，说它是能放长线钓大鱼的活。再加上 AI 这股浪潮肉眼可见地凶猛，我一开始的打算是做 AI 向的 Shorts。

但后来在航海营里听了教练拆解，又刷完了圈友发的所有实战记录，最终拿定主意走科普解说，理由其实很朴素：

1. 我自己几斤几两很清楚。AI 方向的片子确实容易爆，可大家一窝蜂往里冲，同质化速度同样快得吓人，没有真本事很难杀出重围。而且做这类内容要花大量时间去抽卡调参，对一个刚上路的新人来说，前期投入的时间成本会让本来就看不到短期回报的心态更快崩盘。既然是长线项目，又迟迟等不来收益，选条更省力的路才不至于中途缴械。

2. 科普解说正好是我看得下去、也乐意做的，这样才有劲头把战线拉长。看了老马教练的讲解后，觉得整个流程很通透，顺着走就行，于是就这么拍板了。

# 号是怎么安排的

一个新注册的号，一个早年间自用的老号。

新号养了两三天，后来因为一直没动手又撂在那儿吃了十几天灰。

为了避免精力被摊得太薄、最后被懒劲儿打败，两个号统一跑科普解说这一个方向。

# 怎么找到第一波对标账号

刚开始真的连门往哪儿开都不知道。

好在教练给的资料里直接列了几家可以模仿的账号，我就照着名字去站里搜，点进去刷、点赞、顺手关注。逐渐地，首页开始推类似的解说内容，我凡看到没关注过的就点一下，时间一长，信息流已经听话得差不多了。

# 手工阶段的做法

做片子的方式基本是复刻老马那套：扒下热门片子，二次剪接。

流程拆开来看大概是这幅模样：

先去搜那些数据不错的科普解说源视频，下载依靠赚钱圈子里分享的第三方站点完成；随后用飞书妙记转出逐字稿；因为没开 ChatGPT 付费版，只好用它的免费入口抽取核心词——这一步让 Claude 来做也做不了；拿这些词去搜罗画面素材，确认库存充足后再决定这条片子是否开工。紧接着改稿子、上 ElevenLabs 配音；音效素材是在闲鱼淘的，从一堆里挑了几条凑合能用；最后用 CapCut 合成——这软件同样源于闲鱼的非正版渠道，头一回用没毛病，后面就开始隔三差五弹会员、锁功能，重装了好几次也没消停。

# 心态是怎么一点一点磨没的

手工剪了大约十天，两台机器总共出了 15 条。那种最初的热忱肉眼可见地凉了下去——每条片子都在吞噬大片整块的时间，打开后台瞄到冷清的播放数字心里就发堵，再看到 YPP 的进度条，简直雪上加霜。

更要命的是，这些工序里有太多机械性的重复步骤，工具也拖后腿，到了那个节点就开始本能地抗拒去碰。那时候心里只有一个念头：得找个法子让这件事能继续扛下去。

# 摸进 Cursor 的大门

当晚就按照航海手册把 Cursor 装好了，二话不说开始敲代码，一口气战到第二天天亮。

中间的细节已经模糊了。弄出来的东西都很初级、很将就，也夹着不少小毛病，但当时能用就行，后续再慢慢打磨。最直观的体会是：想把所有功能都塞进同一个界面，对 Cursor 来说有点超纲了——它很容易在新功能的编写过程中，把已经跑通的旧功能改出毛病；遇到报错时也容易困在一个小角落兜圈子。

当然了，根子还是我的水平、技巧和投入时间都不到位。所以最后拆成 4 个独立的小工具，并且按使用顺序编了号，做片子时流程清晰了不少。比如那个 2.5 号文件夹永远是空的——因为中间那步还得靠我这个“人肉模块”去手工交付。

![](img/zhuanqian_8183d702012f4da41a7055528be4ae8d.png)

![](img/zhuanqian_6e29426bc2dfaaa935c0c5b4b3abc220.png)

每一个子文件夹里无非是代码文件加上一个启动入口。头一个程序是用 Python 搭配类似 PyQt 的桌面框架写的，跑起来明显卡顿，写起来也费劲，果断弃用。后面的工具全部切到了网页版，基于一个 S 打头的 Python 库，直接跟 Cursor 说是哪个库它就清楚。切换之后速度有了质的提升，开发效率也直线上升。

## 一号工具：频道解析与批量拉片

![](img/zhuanqian_e5b192186bc3edcc3b589e88a43643cd.png)

* 可以连续抓取多个频道的资料

* 列出某个频道全部 Shorts 的数据

* 按条件筛掉不符合预期的片子

* 选定之后能一口气打包下载

* 频道和视频的明细都能导出

反复写这个工具、边测边调的过程中，顺手攒下了不少别人跑出过成绩的爆款片目，省去了原来天天蹲首页翻视频、大海捞针的功夫。

今后只需在碎片时间里刷一刷 YouTube、把看得上的对标账号收进清单就行。后续还打算利用这个工具的频道数据采集能力，继续攒更多的账号样本，慢慢往数据分析的方向走，甚至试试能不能估算频道的收入，好让心里多点底气。

## 二号工具：文案转写加词条提炼

![](img/zhuanqian_a9bb7c8249cd3fb80eeff0a2d872627f.png)

* 负责把视频语音转成完整体文字

* 顺手把稿子里的关键信息抽出来

过去全靠飞书妙记来解决转写。这一套流程很麻烦：得先启动应用、再传视频（上传还得等），完了还得看转写进度。偶尔忘了提前传，等素材都找好了才想起来传，只能在那儿眼巴巴地盯着进度条走，烦躁得很。

现在有了这个工具，就能把一号工具批量拉回来的片子一次性丢进去，转出文字后统一汇进一张 Excel 表里，之后做片子直接从这张表里挑稿子就行，省心太多。

## 三号工具：视频素材整批下载

之前一直在用网上免费的下载网页，每下一个视频就得手动贴一次链接，偶尔还要多跳几个页面才搞定；至于能批量下载的服务，基本都藏着付费墙，钱包扛不住。

于是又动了手，写了个批量下载脚本。用法很直觉：找素材的过程中顺手把网页链接贴进去，攒够一批再按一下，就齐活了。缺陷是下载速度不算快，几个片子的时间足够去做别的——比如先去切分音频句子。

说到这，其实切分句子这件事我也问过 Cursor，它确实给出过一版可用结果，只是产出的形态是一堆打散的音频小样，我不太满意就没继续用。不过后来想想，其实也可以接受。

另外在里头额外加了一个小功能：对成片做轻度锐化、提亮高光等参数微调，省得再回 CapCut 里一个个拉调节杆。虽然教练说 YouTube 对美化的要求远没有国内平台那么夸张，但我养成了习惯，每条都想微调一下。现在这套动作已经直接被封装到下载流程里了，拿到的片子就是调好的。我当时专门去问 Cursor 这些处理算不算改动视频指纹，它回我非常肯定的答案。真实性未知，先信着。

## 最后一棒：CapCut

最终拼装依旧在 CapCut 里收尾。我也曾动过写插件的念头，还向 Cursor 求证过可行性。得到的答复是：得走企业开发者认证的路子，还得啃 API 文档，显然不是一时半会儿能啃下来的，目前也谈不上迫切，就先搁置了。

现有的节奏是：一号、二号、四号工具可以连成一条自动流水线，抽个整块时间把一批爆款集中消化，把文稿、词条、配音全都备齐。到了日常制作的时候，就只剩找素材加剪进 CapCut 这一步了。整体算下来省掉不少时间，虽然离我的预期还有差距，但至少后续做数据汇总、信息归纳方面有了抓手。

# 一些边走边攒的想法

1、YouTube 并不吝啬给量，观众也愿意互动和留言。但二号号的数据实在让人心里打鼓，尤其是那条 0 播放就像一根刺，也害怕好不容易养起来的号哪天突然遭遇 0 播或封禁，坚持不到曙光出现的那天。

2、一条片子的前几秒有着决定性权重。

3、内容得选那些阳光、积极向善的。

4、Cursor 处理那些目标单一、边界清晰的功能，效果更稳。

5、用网页形态写界面比桌面方案利索太多。

6、这个项目注定是场持久战，中途碰到各种障碍和迷茫都是常态。这时候如果有一帮同行的人，大家你一言我一语地讨论、鼓劲、见证彼此的步履不停，坚持下来的概率会大很多。

要是这篇记录能给你一丝启发或者参考，那就值了。也盼着在这条路上，你我互相成为彼此的光——毕竟，我也希望被看见。
