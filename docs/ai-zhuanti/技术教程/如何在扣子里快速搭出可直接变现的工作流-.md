# 如何在扣子里快速搭出可直接变现的工作流？
作者：龙哥

最近圈子里分享的扣子工作流教程不少，但绝大多数都卡在火柴人这条路上。火柴人心理学类内容大家基本都用即梦来出图，实话说即梦的成片率很不稳定，想抽到一张满意的图得反复尝试，对强迫症患者很不友好。

更关键的是，很多教程只做到“能跑通”，并没有讲清楚后续怎么复用。图片一旦生成出来就是资产，复用机制一旦打通，后续的成本就只剩下AI生成文字的开销。

我这边就是在研究这个方向，只是我更偏向高度自定义的方案。比如我用的是 GPT4o 来生图，它的控图精度非常高，实测完全能达到直接商用的水准。而且当你的素材库积累到一定量时，把旧图检索出来复用是完全可行的，复用的思路我也会在下面展开。

![](img/zhuanqian_703c05344dd20b64ecf46191538eb465.png)

![](img/zhuanqian_52f767fb6e4161fbdb6d8b60859d482d.png)

看完这篇实操，你能独立搭建一套完整的扣子工作流，整套流程里出现的图片全部由AI生成，单张图片成本大约在0.05到0.3元之间，一个成片视频的成本控制在1到3元。

当产量达到1000条左右时，就可以写一段检索代码来复用已有素材，成本会无限趋近于零。

本教程有一定的搭建难度，属于中等水平。跟着步骤走基本不会出错，会对接腾讯云对象存储和多个GPT平台的接口。

## 中转 API 网站推荐

目前我常用的中转出图站点有两个，自行对比价格选用即可，算下来麻雀 API 要更便宜，个人优先建议用麻雀。

麻雀 API：https://ismaque.org/ （现价约 2 分钱 / 张）

中转站充值汇率 0.6

GPT 逆向模型：sora_image 0.084 / 张，约合 5 分钱 / 张，出图速度稳定且很快。

GPT 官方模型：gpt-image-1 0.2 / 张，约合 1 毛 2 / 张。

![](img/zhuanqian_97effed1ec31dac4e7ceb5677fa718c0.png)
