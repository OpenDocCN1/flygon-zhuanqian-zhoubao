# 利用AI+RPA，快速打造内容自动化工具
如果你每天都被重复的“复制—粘贴—保存”折磨到怀疑人生，那今天这篇内容，就是来解救你的。
这里有一套“AI+RPA”组合玩法，可以帮你把内容生产的流水线彻底自动化：让机器人替你读取标题、喂给ChatGPT，再把生成的结果自动写进Word文档保存好。全程你只需要坐在旁边喝杯茶。
先说说准备工作，其实很简单：
- 软件方面：装好影刀RPA（直接去官网下载），再准备Chrome浏览器（记住版本要≥115），以及Office或WPS（文档默认保存格式设为.docx）。
- 账号和文件：注册好ChatGPT，并登录网页版（chat.openai.com）；另外准备一个Excel文件（比如data.xlsx），记得表格里不要有合并单元格。
一切就绪后，就开始搭建自动化流程吧。
**第一步：先把你的标题们放进Excel。**
把准备好的标题复制到Excel里并保存，记好文件位置。我自己习惯提前把标题都列好——其实生成标题和生成内容，逻辑完全一样。
**第二步：在影刀里新建流程，读取Excel文件。**
找到刚才保存的Excel路径，把它填进影刀的文件路径设置里。
![](img/zhuanqian_07116b993c2d26ce96dc918d6b35aa84.png)
**第三步：循环读取每一条数据。**
我的表格是一整列排下来的，所以循环参数里，起始行号设为1，结束行号用-1表示最后一行（这样就能自动遍历Excel里所有内容了）。
![](img/zhuanqian_c4b4cab9237782c632ee6058859e5c06.png)
**第四步：匹配ChatGPT的网址。**
这里就是让RPA自动打开GPT页面。
![](img/zhuanqian_3f6956406d1d64e736427c7ec4a930e7.png)
**第五步：把Excel里的数据填写到GPT输入框。**
注意一个小细节：操作前需要先切换一下“四叶花”（影刀里的特定元素标识），不然可能会定位不到输入框。
![](img/zhuanqian_74d73e02dab11bfb466aaa2f6dfaa26a.png)
**第六步：获取GPT的“复制”按钮。**
让机器人点击复制生成结果。
![](img/zhuanqian_e13f2e3ae6410db982e883bc52641640.png)
**第七步：操作Word文档。**
创建新文档、粘贴内容、保存收工——全自动完成。
![](img/zhuanqian_504538a49d549a01d9fd4243ab697e88.png)
最后放上实例代码，方便你直接参考。
![](img/zhuanqian_e332830d7717faaefbb7ba10f9d7c875.png)
整套流程跑通之后，你会发现：内容创作里最枯燥的那部分，真的可以完全交给机器去干。
