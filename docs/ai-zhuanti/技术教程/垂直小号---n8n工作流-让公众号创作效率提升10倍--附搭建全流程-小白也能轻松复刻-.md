# 垂直小号 + n8n工作流，让公众号创作效率提升10倍 (附搭建全流程，小白也能轻松复刻)

最近赚钱圈子里接连炸出两个大招：7月底的【垂直小号】和8月的【N8N】超级标，一个比一个火热。到了9月大航海开启，这俩项目的报名人数直接霸榜前二——分别有4165人和3778人加入。

这信号已经很明显了：会搞钱的人，都在往这两个方向发力。

在920赚钱AI大会上，我亲眼见识了一套用N8N跑起来的公众号自动化流程，当场就被震住了。当时我就在琢磨：要是把“垂直小号”和“N8N”这两个王炸组合在一起，会发生什么化学反应？

于是花了整整两天时间，我成功搭建了一套能把“垂直小号”自动跑起来的N8N工作流。今天就把这套系统完整地拆给你看，从0到1，照着重做就行，不需要任何代码基础。

先说几个前置说明：

第一，这套系统功能很全，但为了让你更容易上手，我在能简化的地方都做了简化。每个功能只给一种实现方案，但整个链路是完整跑通的。

第二，因为反复测试、数据量大，我用的API以国产为主。学习阶段完全够用，但如果你要正经商用，还是建议换成国外的大模型，效果会更出彩。文末我会附上替换教程。

第三，整个流程太复杂，我拆成了6个小工作流。一方面是因为AI是辅助工具，关键决策还是需要人来把关；另一方面，如果你想一键出稿，只需要用 Execute Workflow 节点把它们串起来就行，就像拼乐高一样灵活。

![](img/zhuanqian_b2fbb38a0184c7efe0924f82d0971ad7.png)

整套流程的运作逻辑是这样的：

输入关键词 → 自动爬取近期同领域公众号文章，按阅读量排序 → AI评估每篇的爆款潜力并打分说明理由 → 选出你看中的文章当底稿 → AI分析目标用户画像和文章方向 → 结合底稿和画像提取更精准的关键词，二次深挖素材 → 基于这些素材和框架，AI生成全新文章 → 根据内容自动配图 → AI排版并把图片插入合适位置 → 直接保存到公众号草稿箱。

注意：N8N自动发布只支持服务号，订阅号没这权限。

### 一、选题灵感：输入关键词，爬同行爆文

**1. 新建工作流，添加 SET 节点**

![](img/zhuanqian_9b904b963f6c25623d54355cae492c3e.png)

这个节点的作用是存后面要用到的各种信息，比如API key、表格token、表格ID等。

进去点 Add Field，填以下信息：

【关键词】：你想做的领域主题，这决定了最终文章的方向，做什么主题就填什么词。

【抓取条数】：想抓多少篇文章，最少20，且必须是20的倍数，比如20、40、60、80、100等。第一次别写太多，每次抓取都有费用。

![](img/zhuanqian_fa13d1ce5d83871be5080296e7ea95d9.png)

填完点右上角【Execute step】运行，有输出就关掉页面继续。

**2. 添加 code 节点，控制循环次数**

![](img/zhuanqian_ebdf505198b468d8f77761afe9ebccbf.png)

输入代码：

```
const pageSize = 20;
const total = Number(items[0].json['抓取条数'] || 20);
const pages = Math.ceil(total / pageSize);
const keyword = items[0].json['关键词'];
const apiKey  = items[0].json['极致了API密钥'];
return Array.from({ length: pages }, (_, i) => ({
json: { page: i + 1, keyword, apiKey }
}));
```

![](img/zhuanqian_180752d5f27b9f64196939e7ea4eebff.png)

这段代码的逻辑是构建多个元素组成的数组，因为循环必须要多个元素才能触发。

http节点一次只抓20条数据，想抓100条就得抓5次，也就是5页，循环5轮。我们这次设置的抓20条，所以循环一次就够了。

## 二、选题确认与内容定位（让 AI 对抓取到的文章做爆款可能评估、受众特征拆解，并自动提炼关键词）

![](img/zhuanqian_53b0f1174e5f700b685052fe9b66d1c4.png)

### 第1步：摆放 Set 节点

把后续流程中要反复使用的公共配置统一存到这里。

![](img/zhuanqian_0a27f617771556a2c4d26cb5d5c9f0c7.png)

### 第2步：接入飞书，读取表格数据

通过飞书节点把数据表里的记录加载进工作流。

![](img/zhuanqian_8d4ed889b385de3475ce837f0de74a5f.png)

![](img/zhuanqian_7db4ce40b1326fd285933b343ae49499.png)

社群成员 @诸葛莉Lily 提到，这一步有时会报错。解决办法是：请求体 JSON 中最外面的一对花括号不能删，必须原样保留；如果模板里自带了一些默认内容，把它们清空，只留最外层的花括号即可。

![](img/zhuanqian_c3d4eb25cb16fb0f5a6f34c62ae28408.png)

### 第3步：用 Code 节点筛选有用字段

从取到的数据里，把后续真正会用到的东西挑选出来。

![](img/zhuanqian_93310cb905117106ebae5ef1bfc57e9f.png)

代码：

```
const rows = $json?.data?.items ?? [];
function pickText(v) {
// 常见格式：[{text:"xxx"}] -> "xxx"；多值就用逗号拼
if (Array.isArray(v)) {
if (v.length && typeof v[0] === 'object' && v[0] && 'text' in v[0]) {
return v.map(x => x.text).join(',');
}
return v; // 不是对象数组就原样返回
}
if (v && typeof v === 'object' && 'text' in v) return v.text;
return v;
}
const out = rows.map(r => {
const f = r.fields || {};
const obj = {};
for (const [key, val] of Object.entries(f)) {
if (key === 'ID') {
// 特殊：ID 只要 value[0].text
obj[key] = val?.value?.[0]?.text ?? null;
} else {
obj[key] = pickText(val);
}
}
return obj;
});
// ✅ 让 n8n 输出成一条条 item（最方便后续节点用）
return out.map(o => ({ json: o }));
```

### 第4步：增加循环节点

AI 每次只能读取一行列表数据，所以要靠循环逐行发送请求，把每一行都处理完。

![](img/zhuanqian_9d3c39defd728e23e85114f44d59b0af.png)

### 第5步：再放一个 Code 节点

这一步负责把 JSON 对象转换为文本形态的 JSON，方便下一步直接交给 AI。

![](img/zhuanqian_bd70c9ae734fad2fa62e7af2d9a41a4c.png)

代码：

```
const items = $input.all();
// 假设目标数组在 items[0].json.data.items 或者 items[0].json.fieldsArray
const arr = items[0].json?.data?.items ?? items[0].json?.fields ?? items.map(i => i.json);
// 将其序列化为字符串（漂亮格式，便于调试）
const str = JSON.stringify(arr, null, 2);
// 返回一个字段 stringified 供下游引用
return [{ json: { stringifiedArray: str } }];
```
