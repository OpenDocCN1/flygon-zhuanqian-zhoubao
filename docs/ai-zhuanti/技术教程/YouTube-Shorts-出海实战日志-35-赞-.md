## YouTube Shorts 出海实战日志

作者：龙哥 甲

日期：2025-09-17

先做个自我介绍

我入赚钱还不到一周，现职是一家体能训练工作室的教练兼合伙人，顺带还有个一级建造师证，过去是标准的土木男。

开个帖子把这段刚加入赚钱的兴奋劲儿记下来。

9 月的航海没赶上，就用这篇日志来记录每天的学习和落地。

9 月 12 日正式进来，契机是前几天在公众号刷到刘小排的名字，他一个人把 Claude 用到秃头。好奇之下用 DeepSeek 搜了相关资料，看了几篇文章才知道赚钱这个地方。起初先逛了赚钱的公众号，内容都很硬核，全是变现思路。然后开始查怎么加入，一开始走的是盗版路线，啃了不少精华帖，看得我热血沸腾，觉得照着做也够用了。后来发现两大问题：第一，精华帖普遍滞后一两个月，信息时效直接决定钱赚不赚，紧迫感一下就上来了；第二，这地方的核心是人，不是帖子，不交流就很难进步。了解了价格后 3000 多块有点犹豫，领了三天体验卡后，看到圈子里全天候的自驱氛围，当场就付费了。相信自己一定能十倍百倍地赚回来，把钱投在自己身上是最值的。

加入后每天照着手册实操，一步一步走。

先盘了下能落地的方向，因为本身就常玩 YouTube 和 GPT，决定主攻出海赛道，感觉自己有信息差优势。再加上现在 AI 的能力已经能让普通人把想法变成产品，关键是持续提问、持续迭代，和时间赛跑。错过了本期航海没老师带，正好看到龙哥发了「垂直号」超级标签，立刻报名。先用 AI 辅助写了几篇公众号，主题偏离商业，所以又补了一篇申请文，主体是我自己写的，文笔一般，框架和细节是我搭的，其余润色交给 AI，不知道能不能过，先等等。


第一个半分钟的片子，前后做了 24 小时才上线。做完也熟悉了豆包、即梦、GAS，学会了怎么抄爆款。听拾文的经验，不要乱创新，改动别太大，我就老老实实纯抄。频道在这里<[`www.youtube.com/@Magicat-`](https://www.youtube.com/@Magicat-) dd>

虽然是抄，但前两条都上了几万播放，正反馈极强。

抄了一段时间后就想着把机械重复的部分交给 AI。翻到 zero 大佬的一篇帖子[`scys.com/articleDetail/xq_topic/1524252811128482`](https://scys.com/articleDetail/xq_topic/1524252811128482)，大呼过瘾，然后照着用 Claude 写代码流程。我完全零基础，跑起来经常打不开，只能截图丢给 Claude 问怎么修，一步步部署。第一次看到自己的帧提取功能跑通，就像打游戏通关一样爽。PS：我从前游戏沉迷，入赚钱后游戏机一次没开机过哈哈![](img/article-) images.zsxq.com/FhYuFp7E15mUpPKmfGm6GjHtRV19)

这几日都在折腾自动化脚本，为了保持每天一条 Shorts 的节奏，还是会手工做一些，主要依仗豆包和即梦做图生视频，只是手工太费时间，自动化是必走之路。

今天看到逸尘大大的[`scys.com/articleDetail/xq_topic/5124215225485544`](https://scys.com/articleDetail/xq_topic/5124215225485544)，里面提到思明大佬做的一个工具。第一次通过鱼丸加圈内好友，没想到加思明时发现是老乡，太巧了。今天先到这，期待明天有新进展。因为很想有人带路，下午看到深海圈申请入口，以为只有大佬能进，立刻填表交钱。付完才发现报名到 7 月，吓了一跳。赶紧问鱼丸，说审核通过就能进，开心死了，等明天结果。

发帖三点原因：1 记录自己的成长轨迹；2 站出来被看见，增加被大佬点名的概率，争取贵人指点；3 入会后每天都像上头一样想把事情做完，这种充实感找回了方向，每天兴奋得睡不着，就想把想法落地。文笔不好请见谅，会持续更新。感谢赚钱，一起搞钱！

**9 月 18 日更新**

为了省资源，统一更新在这里，标签也不太会标。

确定要做 YouTube 了，接下来的所有动作都围绕它。16 号凌晨发完帖后早上醒来短暂迷茫，凌晨两点睡六点多起，身体很累脑子转不动。为了搞懂自动化工作流，看了一堆关于 n8n 和 Claude 用法的零散精华，名词一堆，完全陌生，只能在豆包和 DeepSeek 上狂问。16 号有点懈怠，就强制自己睡了一觉，下午继续刷帖，信息量爆炸，脑子里才有了零散的概念。17 号照着 0 到 1 搭 n8n，卡在中间。晚上怕频道断更，硬凑了一条卡皮巴拉的模仿视频，5 秒也折腾了半天，知识太碎，提示词分散在各处。

今天忽然开窍，可以用思维导图整理思路，把流程和对应的文章链接挂上去，回顾起来就清晰了。又想起航海实战里其实有系统化知识，当时怎么没想到。赶紧打开航海手册，从早看到晚，把 Claude code 部分啃了七七八八，像发现宝藏。边看边做，把简单的作业完成了，还学到 conductor 这个并行神器，![](img/article-) images.zsxq.com/FuV_ngvPQMBcWzpN-oaNluOP6-uV)以及 slash、sub agent 等工具。之前卡了好几天的 YouTube 视频下载，今天终于通了。现在在调对标视频的图生描述词和视频生成、描述词生图，![](img/article-) images.zsxq.com/FhYpm19MKknZb0ctldTnGYDqMA5u)再次感谢 zero 大佬的分享，省了太多弯路。过程中一直在问豆包意思、原因、解决办法，要是豆包是真人估计早崩溃了。反正 AI 不会烦，今天又进步一点点。待会继续搞，明天准备看 n8n 的航海手册，感觉调试会更顺。Claude code 有 5 小时限制，手册里有替代方案，先看看别的。

**9 月 22 日更新**

熬到 19 号，深海圈终于审核通过，立刻狂补内容，看了一整天也看不完。晚上继续啃 n8n，搭架子看着简单，实操坑非常多，折腾到今天还没整好，不过生图部分按李香君老师的文章跑通了，可成本 2 元一张，太贵。换模型后报错连连，最后在越越大佬的帮助下改了请求体成功，感谢！

这只是冰山一角，更多功能不知道怎么实现。于是看了航海高手领航的视频和 n8n 中文站，对 n8n 的定位和功能大概有了概念。继续实操，看到可以用 Claude code 写工作流，试了下，框架不错，到补全时又懵了，报错一堆，先放一边。

整天都在搞工作流，YouTube Shorts 只是粗糙发几条，数据很差，果然不用心不行。

到今天还是没跑通，脑子很乱，想先写下来梳理一下。信息爆炸，先把工作流闭环再说。

**9 月 29 日更新**

最近一周没更新，是在埋头做片子和整理笔记。上次更新时想做 n8n 提效，跟深海圈的教练李香君 1V1 咨询，他建议先手搓跑通流程，摸清卡点做出爆款再自动化，不然就是一堆赛博垃圾，醍醐灌顶。也建议多开几个号同步发，便于验证。

于是开始手搓，请教了不少前辈。豆包即梦生图效率低，去找提效工具，强烈推荐一卒大佬的精华帖，自行研究。也跟着 zero 大佬入门了批量生图和生视频，觉得要起飞了，结果扑街了。生成的图和预期差太多，还是得反复改。一问才知道，对标视频选错了，我当时选的是真人动作类，AI 现在几乎做不了，难度极高。换成 AI 类对标，提示词一丢，效果直接好用，批量跑图生视频。视频出来后个别不满意再微调，注意角色描述多余会导致画面乱入。剪映剪完发布，数据仍在万播徘徊，还在研究。

换皮发到其他账号，数据也很烂，分析原因是同质化严重，大部分只有几千播。再找对标，用 GAS 跑提示词问题仍多，怀疑提示词需要迭代。问 SZ 后，他让我看一卒的直播回放，一看豁然开朗。原来曹淦老大早把回放放在深海圈实战手册首位，我加入一周才发现。心态急了就只想埋头猛干，磨刀不误砍柴工，这一步直接拖慢效率。随后看 SZ 大佬的帖子，里面的剪映小助手把剪辑卡点打通了。现在全流程提效基本串起来，接下来逐个击破。

先从提示词入手。一卒大佬建议去 Gemini 搓定制提示词，我就和 Gemini 对线出稿，丢进 GAS 测试，反复迭代。偶尔某一版很满意，加细节后又变💩，只能打回重做。最终有一稿能稳定产出，直接可用的图占比很高，稍作调整就废，赶紧存档。出差期间抽空继续调。加入深海圈太值了，群里大佬天天晒播放量和收益，信心倍增，也更有紧迫感，怕错过红利期。每天脑子高速运转，晚上睡不着，早上醒得早，第一件事就是验证昨晚的想法。这段时间进步速度超过前十年。补个觉继续调提示词。吐槽一下改帖入口太难找，必须电脑端进创作中心才能编辑，可能是鼓励发新帖。
