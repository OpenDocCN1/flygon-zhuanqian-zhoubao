# 模型就是 Agent，Agent 本质上就是个工具


日期：2025-05-23

“把模型当成 Agent 来用，把 Agent 当成工具来用。ChatGPT 更像 AI 时代的操作系统。接下来的 AI 较量，不再是单一维度的比拼，而是围绕操作系统层面的全方位博弈。”

“当一个 AI 工具强到一定程度，它会把周边的细分软件一并吃掉。写作软件、笔记软件、修图软件、代码辅助工具，都可能被一并收纳。iPhone 当年就是这么干的，一机取代了 MP3、数码相机、录音笔和功能机。ChatGPT 现在走的也是这条路。”

**读者视角**

橘子脑袋：这只是个时间问题。

Frank.Z：C 端的 Agent 最终会聚拢到为数不多的头部玩家，B 端的垂直场景里，小团队仍有生存空间。

阿紫：模型、Agent、工具这三者不能混为一谈。Agent 的构成是模型加上提示词，再加上工具调用以及上下文记忆。ChatGPT 本质上是一个产品，它做不了操作系统。你没法在 ChatGPT 之上真正去做应用拓展，你能基于的只有 GPT 背后的模型本身。
