嗨，我是龙哥。今天聊一个我闲暇时随手做的副业测试：原本只是给自己用的锁屏清单工具，萌生收费念头到收到第一笔付款，间隔不到一天。没走教科书式的产品流程，思路有点乱，但验证链路很清晰，分享出来供参考。
## 一、闭环如何运转
逻辑很简单：把打包好的安卓安装包放到夸克网盘，再把网盘链接挂到小红书个人售卖，并绑定对应笔记。一单成交可拿双份收益：小红书售卖收入 + 夸克拉新分成。
为何选个人售卖而不是个人店铺？
个人售卖对软件类只收 0.5% 服务费，个人店铺要收 2% 手续费。个人售卖自带自动发货，能实现真正的睡后；不展示销量与评价，也少了很多售后麻烦。
### 这条路线的优势
对比常见的 AI 编程变现路径：iOS 上架要交 99 美元年费；做 Web 要买域名等 AdSense，周期长；做 Web 工具要接入登录订阅，Cream、Stripe 等技术门槛高；做社群又需要大 IP 带来流量。
小红书个人售卖发安装包，只需一个功能完整的应用即可。AI 功能可以后期再加，也能让用户自行导入密钥实现买断或订阅制。笔记发出后一小时内就可能产生转化，验证速度极快。
当时只是自用，并未拓展别的变现渠道，后面的延伸思路我会后面再补充。

## 三、从零到 V3 的推进节奏
### 1. 选开发环境
换电脑后之前的 Codex 对话找不到了，只能靠回忆。彼时 GPT 已付费，Codex 可免费用，Antigravity 还没出来，Claude Code 太贵，综合来看 VSCode + Codex 性价比最高。
### 2. 明确技术栈和需求
我把想要的功能口述给 AI，让它判断能否落地。先做安卓，后续考虑桌面端。
我问能否实现，AI 推荐 Flutter 跨端。确认华为、小米、红米都能兼容后，我让它基于背景写一份接近 PRD 级别的需求文档，并用 ASCII 画原型保存为 Markdown。
AI 一次性成稿后，我让它按文档开工。命名时我给出方向，AI 给出几个方案，最终确定“逐梦”。
Codex 做这种体量的小项目基本一次成型，文档越清晰成品越准。后期把默认占位图换成自制 Logo，没 Antigravity 的可以用图站找一张 1:1 的放进去。

AI 帮我定位 APK，别人下载后即可安装。上架个人售卖时务必开启自动发货，转化会更好。合规问题不懂就直接问小红书客服。

### 6. 顺带网盘拉新
这部分收入大约占销售额的 3% 左右，虽少但白赚。
### 7. 手册与用户群反馈
网盘里一定要放使用手册，建议用 Word。飞书文档要多跳一次，用户体验差。手册做到保姆级，一步不跳，售后会大幅减少，我到现在基本只遇到一次售后。

### 8. V3.0 迭代提价
根据用户反馈和自己的产品判断，我做了 V3.0。表面看功能变少，其实是把功能下沉到二级菜单，一级更简洁。上手更快，更干净漂亮。
这个版本主要靠 Antigravity 的 Gemini 3 Pro 做前端重构，我只给需求：合并繁琐功能，优化界面。改完再让 GPT 5.2 修 Bug。
完成后单价从 8 元提到 9.99 元，出单率基本没受影响。因为这个细分赛道安卓竞品几乎没有，iOS 用户也流不进来。
## 四、想放大收入的路径
### 1. 流量为王
发笔记、投流、截流、合作四种方式。发笔记最划算，找对标高赞笔记做微创新，标题保留核心关键词做 SEO。投流不建议，赚头不多。截流就是去竞品评论区找“求安卓”的用户私信，每天有次数限制。合作最舒服，我就和那个 iOS 标杆博主互相导流。
### 2. 升级用户画像
可以把锁屏工具做成大的时间管理 App，但竞争会变大，周期更长，适合想拿融资的路线。
### 3. 对接后端
后续可以接订阅、AI 秘钥等商业化，但我暂时没精力。
以上就是从灵感验证到迭代的完整闭环。核心就一句话：用小红书个人售卖 + 夸克网盘做最轻的 MVP 验证，快速试错，快速变现。
