# 用一张图就能让嘴巴“活”起来？思维语录变现玩法全拆解
一张老者照片、一句金句音频，配上会动的嘴巴，短视频平台最近靠这个形式疯狂吸粉。月增十万不算夸张，变现也清晰。
大家好，我是龙哥，做知识分享和网赚自媒体的。最近我在做的知识社群里一直在研究网络上的冷门黑科技。今天就把这个在全网爆火一个月的“图片嘴巴会说话”项目掏心掏肺讲清楚。
玩法核心很简单：找一张人像图，给它配上思维语录、禅语、创业鸡汤等口播，最后让图片的嘴巴跟着音频动。成品看起来像原创，不会被判定搬运，熟练后十几分钟就能出一条。
变现方式也很直接：账号起来后可以带徒弟、卖心灵类图书、挂小程序。门槛低、涨粉快、上手快。下面是我实操的完整思路。

# 一、工具准备
市面上能做口型同步的工具不少，我测了几款，最后锁定的是 CT8-CrazyTalk。这款是中文界面，操作直观，小白也能马上上手。
安装按提示一步步走就行，傻瓜式安装。全程点下一步即可，特别注意不要改默认安装路径，不然有概率变成英文版。软件包我放文末了。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_24f1b2d56176fb569083c1431a2523f6.png>
# 二、素材准备与制作
## 1、音频怎么来
在抖音、快手搜“老人思维语录、创业语录、禅语心得”之类的关键词，找到合适的视频后点右下角分享，复制链接，用“轻抖小程序”去掉水印下载下来。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_b7eae1f679f46291b62341f1ccf832f6.png>
下载完用“格式工厂”把视频转成mp3，就得到干净的音频素材了。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_a1bb05fede3343c8733c01f42fe853f4.png>
如果你想要更原创的声音，也可以去网上找配音工具自己配一句，声音是自己的，原创度更高。
## 2、人像图怎么拿到
直接百度搜图也可以，但我建议用 AI 生成原创头像，避免版权和撞图问题。
### AI 原创头像生成步骤：
1、先去某宝买一个 Midjourney 共享号，自己注册充值太贵，一个月几百块。某宝上 16-32 元/月的共享号就够用了，划算又无压力。
2、用浏览器打开 https://discord.com/，用买来的账号登录进社区。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_eb1342541bd7fd6c116fbaffb199b53c.png>
3、登录后点左下角加号，新建一个属于自己的服务器。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_272a26af2a83ee9149e8f9efe684a108.png>
4、进入服务器后点左下角的导航图标，选择 Midjourney 官方社区。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_18c823805f4406a25533973719e35f5e.png>
5、第一次进去右侧列表是空白的，先点右上角头像图标，唤出列表，然后找到 Midjourney 机器人，添加到自己的服务器里。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_0ce2e5dde70385a64ca26626d484d473.png>
6、进入服务器后，描述词要写英文。可以用百度翻译，把中文描述转成英文，例如《一个戴灰色帽子、长白胡子的中国老人，站在书架前微笑看向镜头，全身照》。建议背景用纯色，别写书架，后期合成更稳。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_9c1c6c700bd469c13d54cd04c816bd50.png>
7、点服务器最底部的输入框，选择 /imagine 命令。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_94fee16996beb42586643b8ac170bbae.png>
8、在输入框里粘贴英文描述，回车发送。记得在末尾加上 --ar 9:16，这样生成的就是竖屏短视频比例。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_3205789af128b115d837e22635f14956.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_4e57505698677fbe492c97649a5e3a9a.png>
9、等机器人跑完进度条到 100%。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_4f1d042d5f6219068f5f8de9c82e7dfb.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_94e6361fd3020c8bbe0904b7f7793671.png>
10、生成完会出四张写实原创图。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_149acdef2070588a140bd69a62bdaad1.png>
这里简单解释一下常用按钮：
U1-U4：点 U2 就是放大第一排第二张图，单独出大图。
V1-V4：点 V2 就是基于这张图的风格再生成四张相似图。
右侧刷新：对四张都不满意就刷新重来。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_e8d5dfe14cbd90d9034ea46485604052.png>
选定满意的一张右键保存到本地即可。
## 3、让图片嘴巴会动
1、打开已安装的 CrazyTalk v8.13 Pipeline Trial，按图示进入主界面。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_fa8e772033a684c80d70ae511601d6bb.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_adc5c36de0350caba7742a9cb642fd1c.png>

2、把刚才的头像图拖进软件，选择 2D 模式。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_055a3e047da49905c88f68c4c675c0d8.png>
3、点切割工具，框住人头部，再点应用，然后下一步。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_4a4eb154487edf0454fda51360dc92e9.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_ffcc8bcd9b29ad9a8b8537cec5d86752.png>
4、把眼角、嘴角的锚点调到合适位置，下一步。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_8c93b4f74b37938707ce54fd945ce89a.png>
5、拖动鼠标把脸部轮廓框准，下一步。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_5b5545a974abcb3857d10b15db6b3f79.png>
6、把鼻子轮廓也定位好。

7、进入配音模块，选择之前准备好的 mp3 音频，选择口型同步模式。三种模式可试试，一般第三种效果最自然。等待缓冲完成。
