## 写提示词前，先把这3个底层问题搞清楚

1. 提示词的本质：你思考问题的颗粒度

用一个最常见的需求举例：

* “帮我做张海报” → 太笼统，AI无从下手。

* “我要一张国庆主题的海报” → 有点方向了。

* “我想做一张发朋友圈的国庆海报，走红色调，走情绪煽动路线，需要放品牌Logo和Slogan” → 这种信息量，AI才能真干活。

提示词水平，本质上就是你拆解问题和描述细节的能力。

2. 我的提示词常用三段式

我常用的框架就三块：

* 角色与目标：让AI扮演什么身份，干什么事。

* 执行方法：这个角色要用啥技巧、啥流程、啥标准来完成。

* 边界与限制：不能怎么干，风格、价值观、格式有什么红线。

👉 举个例子：

“你现在是资深品牌视觉设计师，擅长把节日氛围感和品牌调性融合，帮我出1张国庆推广海报。要求红金配色，Logo完整无损，情绪关键词是‘鼓舞、热闹’，输出16:9横版。不要模糊图，不要花哨到看不清的字体。”

3. 别想着一次到位，提示词是越用越熟的

一个好用的提示词，从来不是闭门造车一次写成的，是在反复使用中磨出来的。

不同场景、不同任务、不同对话上下文，写法都不一样。

所以每一次和AI的对话，都是一次磨合记录。建议你建个提示词笔记库，把高频任务和对应的写法沉淀下来，久而久之你就有自己的AI词库了。

## 怎么让提示词写出来“好看又好用”？

很多人问我们手册里的提示词为啥结构这么清爽，我告诉你个小技巧：

1. 先写“怎么写提示词的提示词”

你可以先让AI教你怎么写提示词，它就会按你想要的结构给你生成：

```
请你作为一名提示词写作专家，帮我生成一个高质量提示词。
提示词格式如下：
- 角色设定：AI需要扮演什么角色？
- 任务目标：我要它帮我完成什么任务？
- 执行策略：你推荐它怎么做这个任务？
- 输出要求：你希望它输出成什么样子？格式？结构？语言风格？
- 注意事项：哪些内容不能出现？有什么风格限制？
```

有了这个“元提示词”做前置，AI才知道你要输出什么样结构的提示词。

2. 用结构化表达来训练思维

比如我们不会只说“给我拆解直播话术”，而是这样引导：

```
请你作为某某行业的资深主播话术分析师，帮我拆解某某老师最近的直播间内容。输出结构为：
1\. 主播的身份定位+话术风格
2\. 开场话术分析（吸睛+利益点）
3\. 成交话术分析（信任+紧迫感）
4\. 留资转化策略
5\. 话术优化建议
```

这么一引导，AI给你的结果既有条理，版式也顺眼。

## 从乱聊到高效协作，就差这几个小动作

### ✅ 1. 把“我是谁、你是谁、要做什么”说清楚

AI又不是你肚子里的蛔虫，不说明白它就一直在猜：

```
我：我想做一份直播复盘报告
AI：好的，请告诉我你想分析哪一部分？
我：你是某某行业的直播复盘顾问，帮我拆解直播间...
```

按“主体→任务→方法→限制”这个顺序走一遍，AI基本都能get到点。

### ✅ 2. 适当丢素材，效果更准

直接把文件、截图、视频链接丢进去，说“根据这份材料……”就好。

像元宝、豆包、通义千问这些国产大模型，都支持文档解析，新手用起来很友好。

### ✅ 3. 写不出来就让AI代写

不会写提示词？那就让AI帮你写提示词。

把背景、目标、痛点告诉它，它能直接给你生成一段可用的初稿。
