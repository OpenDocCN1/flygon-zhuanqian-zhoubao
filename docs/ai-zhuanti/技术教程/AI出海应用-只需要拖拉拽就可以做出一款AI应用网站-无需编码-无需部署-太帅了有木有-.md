# AI出海应用，只需要拖拉拽就可以做出一款AI应用网站？无需编码，无需部署。太帅了有木有？
不写代码、不用部署：拖拖拽拽，我也做出了一款AI出海应用
进赚钱差不多一个月，终于写下第一篇帖子，文字可能不太精致，先请大家多包涵。
直接说背景。昨天龙哥老师又放出了第三个“超级风向标”，方向很明确：做AI应用，AI网站、AI App、AI插件都算。仔细想想，前几个风向标也都和AI有关，AI的大趋势以及未来的市场空间，确实不需要再多解释。记得第二个风向标出来的时候，大家围绕“AI短视频变现”分享了不少经验和教程，我的收获特别多。不过慢慢也发现，内容开始有点同质化：核心逻辑基本一致，只是各自的切入角度略有不同。我一直都在吸收大家的精华，如果自己不拿出点东西来，总觉得有点不好意思。所以，昨天顺着第三个风向标的方向，我找到了一个专门做AI出海应用的在线平台。最惊喜的是，它完全不需要编程，整个界面靠拖拉拽就能搭出来，还把语言模型和图像大模型直接内置好了，拿来就能用。废话不多说，直接看。
网址：https://mindone.app/?ref=producthunt
我先说说自己做的第一款AI出海应用，名字叫“旅游大师”，大概花了一个小时完成。需要提前说明，访问可能需要“魔法”，所以我把样式和效果也直接贴出来给大家看。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_7d7a35ac96945746da765aef5415ea20.png>
从成品能看出来，整体风格挺简约，而且外观的可塑性很强；如果审美在线的话，完全能做出更加有质感的设计。我的灵感其实很简单：很多人出行前都要找旅游攻略，甚至有人愿意花钱买别人整理好的攻略。可这些攻略换个角度想，不就是用ChatGPT写好一套提示词生成出来的吗？但难的是，每个人的出行人数、出行天数、预算都不一样，通用攻略很难真正贴合需求。能不能做一个私人定制类的应用：输入想去哪个城市、计划玩几天、大概多少预算，然后自动生成一份靠谱的旅游建议？这就是“旅游大师”的出发点。
在想的这个过程里，我突然觉得自己“开窍”了：是不是所有帮人解决问题的工具，都可以用AI重新做一遍？出行可以，那其他场景呢？比如上传一张自拍照，AI帮你判断今天适合化什么妆，再给出具体的化妆步骤；再比如上传一张还没装修的房子照片，AI直接生成一套装修方案。这个思路一旦打开，就会发现：只要AI底层基建越来越完善，上层的AI应用很可能会迎来百花齐放。

应用里有三个输入框：城市、出游天数、预算。填好之后点击按钮，就会给出具体建议。我这版只让它输出了推荐的饭店、景点和住宿，使用的是免费版ChatGPT mini。当然，这只是一个“先跑通再优化”的版本，大家完全可以按照自己的需求去配置和调整提示词。
接下来简单聊聊这个网站。昨天我随手翻了一些关注的AI公众号，正好看到Product Hunt本周榜单。榜单里的产品一个个都让人眼前一亮，但大多数总觉得离自己有点远，找不到特别贴合的使用场景。直到看到这个工具，又刚好是刚看完超级风向标、正在思考AI应用怎么做的时候，就这么巧遇上了。
之前也看不少人用Cursor写代码、搭网站，可对没接触过程序的人来说，门槛实在不低。我自己虽然写过一阵子Python，但要现场写需求、看代码、再搞定部署，光想想就头大。而这个网站基本就是“无脑拖拽”，唯一的要求是心里要有自己的设计思路。想想也对，如果连想法都没有，那确实不适合做自己的产品了，哈哈。

最后说说优劣势。
优势很直观：真的不需要工程基础，也不需要代码基础，甚至不用学Cursor，不用碰代码，就能把一个App设计出来。想想还挺不可思议的。每个人都能够把自己的想法做进应用里，这可比简单套壳帅多了，好比百花齐放，大家只管去发挥想象力。
劣势也不能忽略：你设计出来的应用，所有权还是属于这个平台；平台一旦有点风吹草动，你的应用也会受影响。本质上它依然是一种托管模式，不提供代码，也不提供服务器。
