# 二、具体怎么干

开始上干货：

## 第一步：先去小红书补课，把流程摸透，核心就一句话，**整点疯狂点按钮**

[大麦网抢票技巧](https://www.xiaohongshu.com/explore/65294cba000000002101f6ac?m_source=pinpai)

## 第二步：自己手动跑一遍流程，实名认证、提前选座这些前置我就不赘述了，重点是下单环节，页面长这样：

![](img/zhuanqian_1dc875f50a27d017cc0123319657e816.png)

## 第三步：打开影刀，新建一个 python 模块，先把手机连上

![](img/zhuanqian_85a6fbb58fe7ed66cdb33549d20ba195.png)

手机连接这块就不展开了，连接成功后拿到手机的 session，这里默认你只连了一部设备

![](img/zhuanqian_596da87fbc9bf51bcc5fd37295163956.png)

## 第四步：在抢票页面放一个“眼睛”，每秒刷新一次判断是否开抢

#### 没到开抢时间按钮显示的是“已预约”，时间一到就会变成可以点的“立即预订”。

#### 另外脚本启动时页面必须停在抢票页，否则会报错

![](img/zhuanqian_60abfa9d7ab314bcd1b2d3f457671909.png)

不会写代码？直接用魔法

![](img/zhuanqian_0f4c0e283ba4451df5d6850ebb35b99d.png)

直接复制粘贴改一下就行了，搬运代码时给新手几个提醒，尤其是刚碰 Python 的人

第一，文件顶部记得把依赖库导入齐全

第二，缩进一定要对，少一个空格就会报错

![](img/zhuanqian_303aa9a363a88fd01b347294716d9e85.png)

看到这一步，恭喜你，已经解锁了影刀的一个付费功能：**魔法代码**

GPT 默认给你的是整点闹钟逻辑，实际我们需要的是设定一个具体的截止抢票时间，脚本会一直轮询比对当前时间和截止时间，一旦达到或超过，就去点“立即预订”；没到就刷新继续等

![](img/zhuanqian_ef11aadd5b8664a7513d63748f64dcf7.png)

## 第五步：依次点‘立即预订’→‘确定’→‘提交订单’，影刀官方文档里有点击的写法

![](img/zhuanqian_7838c52df94f9f62a3ad82bed141da1a.png)

这里我用的是元素定位，选 XPATH 方案，效率高也稳定

![](img/zhuanqian_3a21d5f7d444142997c21157eaddad1c.png)

大功告成，以上就是完整代码了，只需要把开抢时间填进去然后运行就行。抢到后有 10 分钟的付款窗口，超时就失效

![](img/zhuanqian_84ec708a77fec77d6dcfb8f984cf44b9.png)
