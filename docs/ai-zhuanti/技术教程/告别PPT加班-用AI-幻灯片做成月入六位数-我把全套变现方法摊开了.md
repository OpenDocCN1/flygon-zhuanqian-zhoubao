# 三、好的PPT结构怎么搭
在动手前，先搞清楚优秀PPT的结构。结构扎实，逻辑才顺畅，信息才高效。
好结构就像一栋设计精良的建筑，外观好看更要能承载核心信息。底子没打牢，再强的工具也无力回天。
## 1、视觉骨架
一套完整PPT一般包含：
a） 封面页：主题与基本信息
b） 目录页：整体框架概览
c） 章节页：新章节标识
d） 内容页：具体信息呈现
e） 总结页：要点回顾
f） 结束页：联系方式或致谢
## 2、搭建技巧
a） 逻辑连贯：页与页之间保持逻辑递进，像讲故事一样流畅
b） 信息分层：用标题、副标题、正文区分层次，一眼看懂
c） 视觉节奏：文字、图表、图片页交替，避免疲劳
## 3、各页要点
a） 封面页：
*   突出的主标题
*   简洁副标题
*   演讲者姓名与日期
*   公司Logo

## 2、提示词技巧
全网公认最强的ChatGPT4.0，相当于全领域哈佛博士。但不是人人都能聊明白。有人觉得输出智障，没实用价值；有人不知道该怎么问。根源是：不会提问。
就像点菜，跟顶级厨师说“给我做个菜”，结果很一般。但你说：
*   来一份低脂减卡、清淡爽口的鸡胸肉沙拉
*   鸡胸肉切丁不要切片
*   蔬菜要彩椒和番茄
*   淋柠檬汁不要蛋黄酱
厨师就能精准还原你的口味。
## 3、Prompt结构化框架
基础的Prompt需包含以下模块：
```
# 角色设定
## 任务背景
## 任务目标
## 输出格式
```
类比做菜，需要思考：
*   主厨是谁？有什么特点？
*   要什么效果？开胃还是主菜？
*   怎么呈现？炒还是汤？
对应Prompt即：
*   角色设定：扮演什么角色，背景特点
*   任务目标：完成什么任务、达成什么目的
*   任务背景：受众是谁、核心主题
*   输出格式：对话、文章或列表等
示例：
```
# 角色设定
你是一名PPT大纲设计专家，具有丰富的PPT设计经验，擅长为各种类型的演示文稿制定高效的结构和内容大纲。你能快速理解客户需求，并提供专业建议，确保PPT内容逻辑清晰，条理分明，能够有效传达信息。
## 任务背景
你收到了一个客户的请求，他们需要制作一份关于[主题]的PPT演示文稿。这份演示文稿将用于[具体场景，如学术报告、商业会议、产品发布会等]，需要涵盖[具体内容，如市场分析、产品介绍、研究成果等]。
## 任务目标
你的目标是根据客户提供的信息，设计一份详细的PPT大纲。这份大纲应包括各个章节和子章节的标题，以及每个章节应包含的关键点和主要内容。大纲应逻辑清晰、结构合理，能够帮助客户顺利完成PPT制作并有效传达核心信息。
## 输出格式
第一章 章节页标题
1.正文页标题
a.此处为正文小标题
- 此处为正文内容，为了效果更优，建议内容尽量精简
1.正文页标题
a.此处为正文小标题
- 此处为正文内容，为了效果更优，建议内容尽量精简
……
```
记住：AI是助手不是替代者，输出仍需人工判断与调整。
