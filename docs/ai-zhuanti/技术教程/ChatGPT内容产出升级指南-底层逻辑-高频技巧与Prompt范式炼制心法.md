## 3 向ChatGPT提问的策略

### 3.1 语义清晰，少让模型猜

模型不是人类，很多行话和潜台词它听不懂。把需求说清楚，它需要猜测的次数就越少，命中率就越高。

**反例**：

**正例**：

![](img/zhuanqian_0353ca1d8ecbb83be5e4e15fc6701284.png)

### 3.2 去掉废话，直击核心

多余语句会干扰模型抓重点。它像小朋友，你铺垫太多，它的注意力反而跑偏。而且超长输入和输出都会拖慢速度、拉低质量。所以提问要短，意图要准。

**错误示范**：想了解牛顿，就从“历史上的著名物理学家”开始铺垫，一口气要求介绍生平、教育、成就、哲学观点、对现代物理的影响等，还要“尽可能详细”。又长又绕，效果反而差。

**正确示范**：直接说“请提供艾萨克·牛顿的简要生平、科学成就以及对现代物理学的影响”，既清爽又直接。

### 3.3 简洁之外，让要求更具体

模型知识库太大，问题越泛，答案就越泛；问题越具体，越容易定位到你想要的那一个点。

**调整前**：

### 3.4 复杂任务要拆解

原理是链式思考（Chain of Thought）：一步一步想、一步一步算，比一次性硬刚更可靠。

拆法有两种：

- 不太复杂的任务：把多步要求写进同一条Prompt，让模型按顺序执行，只需对话一次。

- 很复杂的任务：把大目标分成多个子任务，每个子任务单独发一条Prompt；子任务还复杂就继续拆。

最典型的是字数限制：模型单次只能输出约1000字，想让它一口气写5000字不现实，必须拆成几次。

**示例一：同一条Prompt里做多步操作**

我设计过一条指令，让模型先阅读一段新闻，再用一句话概括并加前缀“总结:”，接着把这句话翻译成英文，加上前缀“翻译:”。新闻内容是关于百度网盘基于文心大模型升级并推出AI助理“云一朵”的消息。

![](img/zhuanqian_f80da8988ae44d6336f73539b16748af.png)

**示例二：把一道让GPT-3.5翻车的题拆开算**

以前我们喜欢用一道“牛奶加水”的数学题来区分GPT-3.5和GPT-4。GPT-4可以直接算对，GPT-3.5却容易错。原因是完整计算链对GPT-3.5来说太长，一步到位容易乱。

原版指令让模型在脑子里完成多轮“喝一半、加水”之后，一次性回答总共喝了多少杯水、多少杯奶。拆解后的指令则把整个过程切成几个小问题，每次只算当前阶段的奶和水数量，模型就能逐步算对。

![](img/zhuanqian_3df8d0bb2241b220bf6d744041c63209.png)

![](img/zhuanqian_3a39078410da202c40c5586eb718a105.png)

拆解思路大致是：

```
【任务】按顺序作答。
【步骤】
1. 小明喝掉一半牛奶后补满水，这时水是多少杯？奶是多少杯？
2. 再喝掉一半混合液后补满水，这时水是多少杯？奶是多少杯？
3. 最后全部喝光，水一共多少杯？奶一共多少杯？
```

![](img/zhuanqian_dec5baed1fb0bd1572ac9d724af80f6d.png)

如果需求更复杂，比如写一篇深度长文发公众号或知乎，你还可以把大任务拆成：爆款标题、素材收集、框架搭建、爆点设计、开头留人、结尾引流等子任务，逐个交给模型完成。

深度原创文章的核心，是你心里有想表达的观点，AI负责搜集素材、润色文案、补灵感、做部分创作。每一步如何精细设计需要单独教程讲解，这里先记住“大任务变小任务”的思维。

### 3.5 让中间步骤对用户不可见

大任务拆成多步后，模型通常会每一步都输出过程。如果你只想看最终结果，不想看内部推理，可以在指令中要求“对我保密”。

**不隐藏的版本**：给模型设计一条四段指令——先自己解题，再和学生的解法做对比，判断对错；如果错了，想一个不直接透露答案的提示；最后输出提示。题目是一道不放回抽球的概率题，学生给出了一个错误解法。

![](img/zhuanqian_df2183223f9da40d598ab92ec4771803.png)

**隐藏的版本**：同样四段指令，但注明前几步的思考、对比、设计提示过程都不许写出来，只能在最后输出提示。

![](img/zhuanqian_3b6a414bd5cd8aa14b3ce95b1346195e.png)

这样模型就会直接给出引导方向，而不是把答案和盘托出。

### 3.6 给一个正向示例，让它照着学

当你不知道怎么用语言描述要求时，直接给模型一个高质量示例，它就能模仿出相似的风格与结构。示例贵精不贵多，最好再配合一个反向示例，告诉它“不要这样写”。

比如先给它一句关于“耐心”的优美排比句，再请它用同样的句式写“海洋”，模型就能领悟你要的语感。

![](img/zhuanqian_1ff1c7302c8b8fbf852cb82270e216b2.png)

反向示例不是不能用，但效果通常不如正向示例精准。

### 3.7 投喂素材：让输出贴近你的语料

想让模型基于指定资料作答或写作，就把素材直接发给它。素材越精准，输出越靠谱。

素材的构成比例会影响输出方向：如果素材有80%在讲A维度、20%在讲B维度，模型生成的内容大概率也是A维度为主。若想输出变成五五开，就要先调整素材里的占比。

举例：你想让它回答“如何用AI制作视频”，可以先给一段关于Runway开放Gen-1/Gen-2、以及一位博主用Midjourney生成图片再转成视频的素材，再提问。模型就能从素材中提取答案，而不是凭空编。

![](img/zhuanqian_e49694dcf528532c8d4912318f3c9b76.png)

为什么不建议喂太长的原文？因为模型记忆有限，输入超过约4000个汉字就容易答非所问。普通需求下，可以把长文拆成几段，逐段压缩后再组合。

读后感的教程里，海盐只让大家投喂小说简介，就是这个原理。模型的生成机制是“下一个字更可能出现”。喂了1万字原著，它总结出的1000字推荐文可能全是原文细节，反而没有文采。高质量推荐文靠的是个性化观点和写作手法，而不是复述剧情。只给它故事简介，再教它写作技巧，反而更容易产出优质内容。

想用AI帮你干活，但总觉得差了点意思？问题可能不在AI，而在你给的指令。今天咱们聊聊提示词里那些能让你效率翻倍的实用“套路”。

先讲核心心态：别指望一步登天。就像增肌一样，需要持续给身体刺激，耐心积累，定期记录围度变化并调整训练计划。学提示词也一样，要长期实践，边用边复盘，每月给自己设个小目标，看看哪里还能优化。

好，进入正题。第一个大杀器：润色。你说话很随意？没关系，让GPT帮你把大白话变成专业文案。它能根据你的要求替换角色、更换语气。比如“专业性？气氛组？猛男音？应有尽有”——通过角色转换，让同段文字瞬间拥有不同风格。这其实就是角色扮演法的具体应用，以后会单独细说，现在你只需记住“润色”这个常用功能。![](img/zhuanqian_6f4186e599b47724cc29a0568c12a803.png)

第四个功能：个性化提取。你以为AI只能聊天？错了。把淘宝评论丢给它，它就能提取30个关键词并生成词云，还能用你指定的字体渲染。![](img/zhuanqian_a7e8937d728168196aac603be4954c3e.png) 这操作有多神奇？![](img/zhuanqian_da9475ad508ae0e1caa8d4cce18ffd03.png) 友情提示，要是普通GPT3.5用户，直接让它列关键词就好，只是没那么炫酷而已。![](img/zhuanqian_689b2982b113977fec09b704271eda90.png)

接下来，你还可以让AI针对同一批评论，专门提取技术部门关心的摘要——比如键盘的灯光方案、屏幕可玩性、驱动更新等，每条不超过20个字，再配合上传的中文字体文件生成词云。![](img/zhuanqian_77cc052fdb0e494102e4a517889ce24b.png) 同理，也能生成一版客服部门关心的摘要，比如售后响应速度、客服态度、物流包装等，格式要求完全一致。一套流程下来，各部门各取所需。![](img/zhuanqian_16b64adf5b9bb75b5fd96351716f4597.png) 最后，还能从产品详情里精准抓出“连接模式”“轴体参数”并输出成JSON，连代码都不用写。![](img/zhuanqian_fde49bb75b09e5328bae75f96c7d4590.png) 比如键盘支持2.4GHz无线、蓝牙5.1、有线三种连接；轴体采用COOLKILLER冰刃轴，触觉力度60±10gf等。![](img/zhuanqian_0d4a2b4a934aa67d55b4dda0625e6d6a.png)

大写的完美！![](img/zhuanqian_f2c82682f023b1bf3515e09213715dc2.png) 程序员再也不用写复杂正则去匹配数据了。普通人学会这招，瞬间拥有数据分析师的能力。从一篇政策报告里提取20个主题词，也是几秒钟的事。![](img/zhuanqian_e854ffb4027c395214bfa87e81484a19.png)

第五个功能：评判。想快速了解一部电影的口碑？把所有影评扔给GPT，它会自动打上“好评”“中评”“差评”，并附上不超过20字的理由。比如对《封神》的几篇评论，AI能一针见血地抓重点。![](img/zhuanqian_152c3edb6044fa996d846143ccc959df.png) 这招还能用来分析电商产品评论区，帮你过滤掉无用评价，只留下有用的参考。甚至可以把GPT插件商店里的插件全部AI分类，再通过API监控变化，第一时间收到上新或下架通知。![](img/zhuanqian_02b7450fc67dd2f0e421cf25a5f5e0a3.png)

第六个功能：格式转换。让GPT把文字变成Markdown、JSON、HTML，轻松搞定网页展示和代码开发。比如把“位右移”那段技术说明转成JSON，再把JSON转成带标题的HTML网页——过程就像变魔术。![](img/zhuanqian_6b514c0f9429615d204c67d8c94dda48.png) 你只需要一句提示词，连下载文件都帮你生成好。![](img/zhuanqian_1e61283bf32d82695717bcda4cf254a8.png) 用Code Interpreter模式，点一下就能预览效果。![](img/zhuanqian_a5da746d39fb62d1dd45d38f53e18408.png) 打开浏览器，一份漂亮的表格直接呈现。![](img/zhuanqian_00d10d710378911e766c1f67ee483b4b.png)

最后，再分享三个提示词常用格式，让你的指令更精准。

第一，三引号。当你给的文字里含有引号或特殊符号，GPT很容易犯迷糊。用英文三引号把待处理文本包起来，边界清清楚楚。比如让GPT用三个对仗工整且字数相同的排比句总结文案，它就不会找错对象。![](img/zhuanqian_42ed6a85b16784e116fc4045bf368dfe.png)

第二，XML标签。一次要处理两段相关文本怎么办？用<文章>标签隔开，GPT再也不会搞混谁是谁。![](img/zhuanqian_7fe9c054842ee95af77cf751dd354e1d.png)

第三，小节标题。别再写一长串小作文了。把任务拆成“角色设定”“处理步骤”“输出要求”等几个小节，结构清晰，AI理解更准。甚至可以用Markdown标题来强化层次感。![](img/zhuanqian_7a002df7c3f2612fc6845015e98cc4c1.png)

怎么样？这些技巧不用全背下来，只要用熟一两个，AI的交付质量就能明显提升。赶紧去试试吧。

很多人写指令，习惯一长段全砸给模型。可模型也需要“呼吸感”——你把要点讲清楚、把边界划明白，它理解起来就容易得多。

JSON、YAML 这类格式虽然严谨，却更贴近程序员；对普通用户来说，门槛有些高。这篇文章介绍一种人人都能上手的方法：用大白话 + 小节标题，把指令拆成结构分明的几个部分。

### 案例一：让模型帮忙优化标题

不妨假设，你想让模型评价并改写一个新闻标题。未经整理的指令可能是这样——

“我给你一段文字摘要，内容是：8月9日消息，快手分管研发的高级副总裁于冰近日表示，大语言模型已进入爆发期，是极具变革力的技术，有望走向通用人工智能（AGI）时代；跨模态内容的生成与理解是其中的核心能力。他还谈到，短视频和直播是最典型的多模态媒介，快手正依托平台根基在大语言模型方向全力投入。和这条资讯对应的新闻标题是：于冰谈快手 AI 战略：重注大语言模型。我希望标题既能让读者快速抓住主题，又要足够吸引眼球。如果现有标题达不到这两点，请你给出 5 个替代方案。”

一段话里塞进了素材、标题、要求。字数一多，层次感就消失了；人读起来费劲，模型也容易“晕字”。

换成分块结构后，长这样：

我会给你一段文字【摘要】和对应的新闻【标题】。标题应当让读者清楚把握内容主题，同时具备吸引力。如果标题不够好，请给我 5 个替代方案。

摘要：

8月9日消息，快手分管研发的高级副总裁于冰近日表示，大语言模型已进入爆发期，是极具变革力的技术，有望走向通用人工智能（AGI）时代；跨模态内容的生成与理解是其中的核心能力。他还谈到，短视频和直播是最典型的多模态媒介，快手正依托平台根基在大语言模型方向全力投入。

标题：

于冰谈快手 AI 战略：重注大语言模型

把【摘要】和【标题】分开，模型就不会混淆“背景材料”和“待改写的对象”，指令的指向变得非常明确。

![](img/zhuanqian_d5428a7fbdabfa72bc6917d318a615c3.png)

当然，像这种简短任务，分不分节对结果影响不大；你也完全可以不分。指令越复杂、越容易产生歧义，分节的价值就越明显。

### 案例二：让模型扮演角色

未经整理的版本：

请你化身为《狮子王》中的辛巴，需要了解辛巴的全部背景。现在请用辛巴的口吻向我问好。之后请沿用辛巴的表达习惯、思考方式与词语偏好。只以辛巴的身份回应，不要附加任何解释。

整理后：

【角色】你是《狮子王》中的辛巴，掌握辛巴的全部信息。

【任务】用辛巴的口吻向我问好。

【要求】模仿辛巴的说话方式、思维和用词；只用辛巴的身份回应，不写解释。

当指令篇幅达到上千字时，切忌把全部内容糊成一大段。像写文章一样分出小节，模型才不会“读串行”。这个例子本身很短，堆在一起也无妨；但遇到复杂场景，你就知道该用这种拆解思路。

### 小节标题的常见写法

最基础的模块化：用【】包住模块名，视觉上更突出。至于划分哪些模块，完全根据你的任务来。

可以套用的骨架：

【角色】：

你要成为xxx

【任务】：

生成一份xxx

【要求】：

1. 篇幅控制在xxx

2. 遵守xxx

3. 输出xxx

如果需要并列展示，可以用 -、+ 或 * 每条一行。这三个符号功能相同，选哪个全凭个人喜好。

```
【模块名】：
- 黄瓜不要皮
- 玉米不要瓤
- 茄子不要籽
* 黄瓜不要皮
* 玉米不要瓤
* 茄子不要籽
+ 黄瓜不要皮
+ 玉米不要瓤
+ 茄子不要籽
```

列表还支持嵌套。混用 -、+、* 可以形成多级标题的视觉效果；最终文档渲染后，符号本身没有区别。想表达从属关系，就在条目开头加四个空格或一个 Tab。

```
【模块名】
- 第一级列表项 1
+ 第二级列表项 A
* 第三级列表项 i
* 第三级列表项 ii
+ 第二级列表项 B
+ 第一级列表项 2
* 第二级列表项 C
- 第三级列表项 iii
```

有先后顺序的步骤，则用数字列表更清晰。

```
【模块名】
1.我是第一个要求
2.你是第二个要求
3.他是第三个要求
```

上面演示的其实是 Markdown 的列表语法。用什么语法并不重要，哪怕你对模型说“用代码格式输出”，只要它能理解，就是好指令。Markdown 的更多细节，后文单独介绍。

### 另一种常用模板：LangGPT

社区里流行一时的 LangGPT，也把指令拆成了固定栏目。其骨架可以概括为：

# 角色：Your_Role_Name

## 档案 Profile

作者、版本、语言、角色描述

### 技能一

技能说明

### 技能二

技能说明

## 规则 Rules

若干条约束

## 工作流 Workflow

先做什么、再做什么、最后做什么

## 工具 Tools

### 浏览器

可以发起搜索、打开网页、上下滚动、返回上一页，以及选定页面中的某段文字并引用。

### Python

发送代码后，会在 Jupyter 环境中执行，最长 60 秒；/mnt/data 目录可用于保存文件，但此会话无法访问外部网络。

### DALL-E

收到图像描述即生成图片；若未指定数量，默认生成四张，并整理生成图片所用的提示词。

## 初始化 Initialization

以角色身份出现，先问候用户，再介绍自己和工作流程。

用 LangGPT 写出来的指令长什么样？社区里有个“诗人”例子，作者 YZFly：

# 角色：诗人

## 档案

作者：龙哥；版本：0.1；语言：中文。

描述：诗人通过诗句传达情感、勾勒画面、讲述故事，富有想象力并善于驾驭文字。作品可以是纪事型的，如史诗中的人物故事；也可以充满隐喻，如《神曲》《浮士德》。

### 新诗方向

形式开放、意象丰富、直指内心。

### 格律诗方向

七字成句，源出民间歌谣。

### 短诗方向

五字一句，抒情叙事更见灵活，音节上奇偶相衬，自带乐感。

## 规则

作品基调积极向上；格律诗注意押韵。

## 工作流

先由用户以“形式：[ ]，主题：[ ]”指定诗歌形式与主题；再据此创作，包含题目和诗句。

## 初始化

作为诗人，遵守规则，用默认语言问候用户，介绍自己并说明工作流程。

这个模板来自 YZFly 的开源项目：https://github.com/EmbraceAGI/LangGPT

如今网上不少结构化指令都套用了 LangGPT 的框架。那个“诗人”示例在我看来相当精练——几乎没有废句，句句都起作用，属于高质量指令的样板。

反观有些长指令，看起来结构完整，实际上许多句子删掉也无妨。无效信息越多，模型的注意力就越分散，指令性能也随之下降。别因为排版整齐就以为它一定好用，关键要看每个字是否承担了功能。

### Markdown：天生的结构化语言

Markdown 的写法天然适合组织信息。把同样的角色扮演需求写进去，层级立马分明。

```
# 角色
请你扮演《狮子王》的辛巴, 掌握所有<技能>
## 技能
了解辛巴的所有知识
# 要求
1.请使用辛巴的语气、说话方式、思维、词汇和我沟通
2.只能像辛巴那样回答，不要写任何解释
# 任务
现在，请你用辛巴的语气和我打招呼。
```

几个常用语法值得记住：

1. 标题：最多六级，对应 HTML 的 h1 到 h6。

```
# h1
## h2
### h3
#### h4
##### h5
###### h6
```

2. 无序列表：按需选用 -、+ 或 *，作用相同。

```
* 黄瓜
* 玉米
* 茄子
+ 黄瓜
+ 玉米
+ 茄子
- 黄瓜
- 玉米
- 茄子
```

3. 嵌套列表：在上一层条目前加四个空格或 Tab，即可表达从属关系。

```
- 第一级列表项 1
+ 第二级列表项 A
* 第三级列表项 i
* 第三级列表项 ii
+ 第二级列表项 B
+ 第一级列表项 2
* 第二级列表项 C
- 第三级列表项 iii
```

4. 有序列表：适用于步骤明确的场景。

```
1.我是
2.你是
3.他是
```

### 绕不开的五个局限

#### 其一：输出内容会重复

![](img/zhuanqian_981cd5e0209b9ec5aeca40f0b514415f.png)

这更像是生成阶段的小毛病，许多人都遇到过。不必重启，让它继续生成完，最后把重复段落删掉。曾有人删完重复内容后剩 1022 字，基本符合要求（尽管字数统计有时并不准确）。后面还会介绍更高级的解决方法；不过这个基础手段很常用，先记住。

#### 其二：中文字数统计不准

![](img/zhuanqian_9f07784702cc9d8e3c0f510f4e4c557f.png)

OpenAI 官方也承认：模型对所有语言的字符计数都只能给出近似值，有时偏差还相当大；不过它统计段落数量和要点个数是准确的。

![](img/zhuanqian_885cdafabe2f8b71bf44477dd29e5d61.png)

![](img/zhuanqian_d7de9ca8947de9c10c8cca250dcfd4c7.png)

对策是借用现成的统计工具。Word 自带字数统计，或者访问在线字数统计小工具：http://zishu.qianwanku.com/。文案通常有明确的字数目标，比如不少于 1000 字，这类工具能帮你快速核对。

#### 其三：重写和改写效果不佳

根源常在原文太短。假设原文只有 100 字，模型可用的信息就这么点，改写只是在有限的字词间打转。这是因为模型的底层机制是预测“下一个更可能出现的字”。

想让改写效果好，可以在指令上做文章。三个思路供参考：

第一招：明确告诉模型可以补充哪些情节、融入哪些知识点。

第二招：换一篇较长的原文，让它压缩改写。

第三招：让它生成多段内容，你再合并、删减、取舍。

#### 其四：模型幻觉

模型产出的内容可能出错，也可能部分失真。所谓“一本正经地胡说”，指的是模型缺少可靠信息时，自行补全出看似合理却不真实的描述。这与训练语料和生成机制有关，误导信息、错误事实都可能由此产生。

对策是对事实性内容做独立核验。查证重要数字与关键细节时，尽量使用可靠来源，用批判性眼光人工复核。互联网上的内容本来就有好有坏，严谨的文案需要回到权威网站、知识库、书籍或论文中确认。

#### 其五：页面卡顿导致丢失输入

官网偶尔会卡顿刷新，辛辛苦苦敲进去的指令可能瞬间消失。

养成一个习惯就好：先在本地文本文件中写好指令，再复制粘贴到对话框，避免白费功夫。

我收到的反馈也很有意思。有人拿着模板套用，说省了不少力气；也有人很沮丧，说换个场景就不会了，甚至觉得AI只能写点心得，能干的事情太有限。这两类说法方向相反，病因却完全相同——没弄懂AI的运行内核。只要把这个内核补上，哪些事可以交给它、哪些事该自己判断、为什么结果不理想，你都能自己找到答案，不必再追着别人问。

当时我拿“读书心得”做演示，是想用一个最小例子把方法讲透，让大家看到这套生成文字的玩法可以平移到其他领域。但我漏掉了一个前提：很多人连“怎么平移”都找不到支点。他们缺的不是套路，而是使用AI之前需要先建立的最基础认知。所以在谈高级技巧之前，必须先把这块补上。这一部分如果真看懂了，你对大模型的理解，会超过不少天天刷资讯的人。

常见的现象是：新手总觉得AI像个笨小孩，答非所问，写出来的东西又空又平；高手却觉得，AI让熟悉的工作提速八成，还能带自己快速进入陌生领域，像多了一个24小时不下班的助理。我不是什么顶尖高手，但每天开着两三个账号并行使用GPT，已经很习惯。现在打开搜索框的次数少了不止一半，遇到问题先问它。等到AI联网、查证能力再成熟一些，传统搜索被取代一点也不奇怪。盖茨也做过类似判断：这场变革会像个人电脑、网络和手机一样，重新定义工作、学习、出行、医疗和交流方式。

既然还有人觉得它没用，那我们就仔细看看新手和高手差在哪里。

```
用好AI，核心的底层逻辑只有2点：
1.垂类行业经验
2.对AI的深度理解（理解=掌握AI的核心原理+调教AI的技巧）
二者，缺一不可
```

先说做运营的小周。他每天花两小时看AI内容，也见过用AI生成抓取脚本的教程。领导让他收集十个网站的数据，他让AI生成了一段脚本，可脚本拿到手，他不知道上哪儿运行，也不知道结果对不对，最后只能手工复制粘贴。问题不是AI不会做，而是他判断不了AI给出来的结果。换成一位懂编程的同事，拿到脚本先跑一遍，报错就按自己的思路引导AI改，很快就能交差。这就是差别：高手不一定比AI聪明，但知道什么是对的、什么是错的，也知道怎样把AI往对的方向领。反过来，如果连自己的需求都描述不清，AI再强也帮不上忙。

再说罗飞，一个做了十年公众号的老编辑，出手就是10w+，一篇稿子要磨两天。他也试过AI，觉得机器生成的文字像小学生的流水账，干脆放下。可如果他能掌握调度AI的方法，凭他多年的编辑判断力，完全可以让AI快速产出符合水准的稿子。他把关，AI执行，一个人就能顶一个小团队。

所以，所谓AI高手，不是只会喊口令，而是同时握住了两样东西：行业判断力和AI驾驭力。听完这两个例子，还觉得AI是个学历很高却派不上用场的博士吗？还觉得它跟普通人毫无关系吗？还觉得一个外行能靠它轻松超过专业前辈吗？显然不会。只懂AI不懂业务，连该让它干什么都说不清；只懂业务不懂AI，又很容易被提效的同行甩在后面。未来的机会，属于“内行+会用AI”的人。普通人的路，就是一面加深专业，一面练好AI。

那怎么让AI发挥最大价值？我最初用GPT时，也是从多轮对话开始摸索，没有捷径。后来渐渐发觉，有些问法在同类任务里反复奏效，于是我把它们整理成固定句式，每次只需替换关键信息，慢慢沉淀成可复用的模板。遇到相似任务时，直接套用并做修改审核就行。这个习惯来自程序员的复用思维，本质上是把好用的经验固化下来。

当然，不是所有工作都值得做模板。临时性的文档、一次性的杂活，每次内容都不同，把当时的关键对话保存好、方便以后查找就够了，不必为了结构化而结构化。

关于个人发展与AI变现，很多人还在观望。其实答案绕不开两条：一是行业积累，二是驾驭AI的能力。

![](img/zhuanqian_b9ce34e4c8bae90db0a57aa24867e489.png)

程序员如果业务扎实，再用好AI，只会越来越值钱；如果只想靠旧经验混日子，就算没有AI，技术换代也会淘汰人。AI和过去出现的很多技术一样，不神秘也不可怕，别被焦虑带着走就好。

再说一个普通上班族小张。他看到网上到处是AI课程，越看越慌。实际上，到今天真正下场的人依然不多；多数人只是学了个皮毛，没解决自己的真实问题，慢慢就搁下了。所以不必慌张。学AI的目标感和实用性，比学习的姿态重要得多。每个人身上都有可迁移的经验，哪怕看起来平常。比如一位宝妈，备婚、育儿、挑奶粉、选童装这些点滴经验，对准备结婚的年轻人来说就是宝。她完全可以把经验变成对话问答，或者写成内容投稿给母婴媒体，甚至自己开账号，用AI辅助产出，再接广告带货。

再说到头像定制。最早靠它赚到钱的人，多半本来就是做设计或修图的，他们有客户积累和审美判断，才会顺势用AI提效。让一个教师或医生凭空想到这个玩法，不太现实。就算现在入场的人变多了，也还有空间：别人做头像，你就做主题写真，山林、都市、复古、赛场、儿童动漫风；别人做标准照，你就做带剧情的婚纱主题，星际、海底、古风、童话；还能把一对情侣从相识到求婚的故事写成文字，再用AI生成插画，做成婚礼现场播放的绘本。生日、节日想送点特别的，也能用这套组合做出搞笑或动人的礼物。

关键在于做好调研，找那些竞品还没服务好的小需求。线上平台有圈层效应，只要你持续服务好一群同类用户，就会养出属于自己的口碑。首个项目走通后，交付和口碑都有了，再叠加技能或找人合作，就能从一个点扩展到更多可能。

看到现在，你对AI的认知已经过半。在实操层面，你已经握住两个关键要素：专业判断力和AI操控力。后面所有实战，无非是把这两个要素用在具体场景里。哪天你用AI效果不好，就从这两个方向排查：是我对这件事不了解，还是我没把需求讲清楚？找到卡点，问题通常就解开了。

最后说最受关注的调教方法。我把它浓缩成一个原则加三个技巧。原则是“角色代入”。让AI扮演某个身份，是官方也认可的有效做法。市面上讲AI玩法的内容，几乎都从这里出发。为什么有人学了还是不会？第一，不知道成品标准；第二，不会把大任务拆成小步骤。不知道标准，就判断不了AI给的结果；不会拆解，就指挥不了AI一步步完成。如果这两关过了，你就能从“和AI尬聊”变成“顺手就能指挥”，还能把过程固化下来，下次直接用。

顺便说清一个概念。网上所说的Prompt、指令、描述语，其实都是你输入给AI的那段话，不必咬文嚼字。重要的是把身份、目标、边界说清楚。

为什么身份设定这么关键？因为大模型是一个庞大的资料池，你问得越宽，它越容易给出四平八稳的空话。一旦你给了身份，它会在相关领域里搜索和调用知识，回答会实在很多。接着再给一个具体目标，它知道该把力气用在哪儿；再补上约束条件，它就知道什么能做、什么不能做。身份、目标、边界，三者相互配合。比如“请你当老师”和“请你当一名经验丰富的高考英语口语老师”，效果差别很大。

举个例子。你新建一个对话窗口，输入：请你扮演《狮子王》里的辛巴，用辛巴的语气、说话习惯和用词，和我寒暄一句。只用辛巴的方式回应，不要写任何解释。

这句话看起来一点都不玄，其实就是正常沟通。所谓技巧，不过是从大量有效案例里提取出的共同点。道理通了，应用自然就顺了。

有没有一种可能：你总觉得提示词写不好，不是因为你不够聪明，而是思路一直卡在“把所有东西硬塞给AI”这个习惯里。

真正好用的提示词，往往不是凭空“设计”出来的，而是先有了一批被验证过的优秀实战案例，再有人从这些经验里提炼出可复制的规律。你会发现，像角色扮演法这样的实战案例，跟前文推演出的3条原则是完全对得上的。先有经验，后有理论，这才是提示词技巧的正确打开方式。

很多人写提示词，习惯把角色、任务、要求全部揉在一起。提示词短的时候还好，一旦字数多起来，人看着都头大，AI理解起来更是费劲。更要命的是，这种写法耦合度太高，想改其中一个地方，整个结构都会受影响。

更好的做法，是把提示词拆成三个独立模块：角色、任务、要求。模块之间边界清晰，AI反而更容易get到你的意图。这就是结构化的【角色扮演法】提示词：

【角色】

请你扮演一个xxx，你必须了解xx的所有知识。

【任务】

现在，请你xxx

【要求】

1.xxx

2.xxx

3.xxx

模板里标黄的部分，就是每次需要替换的位置。你还可以用之前讲过的【小节标题】格式，把每个模块的边界标得更清楚，AI一看就明白：每一块的内容性质不一样。

但问题来了：知道了模板，脑子里却词穷了。到底能扮演什么？动画IP行不行？普通职业行不行？一棵小草行不行？用那种超级火的表情包软件，只靠表情和我对话行不行？答案都是行。如果实在想不出来，最快的方式还是“遇事不决，问GPT”。直接用一句话拋给它：

“我想让你帮我写一个xxx，但据说要给你一个角色让你扮演，才会更好，我应该让你扮演什么角色呢?”

这句话还能再进化一步，让ChatGPT直接变成你的提示词生成器。你只需要给它一个构建框架，再提出需求，它就会自动产出最合适的prompt。比如这样：

【海盐的ChatGPT提示词生成器】

【prompt构建框架】：

"""

【角色】

请你扮演一个xxx，你需要具备xxx能力和xxx特质

【任务】

【要求】

"""

请你扮演一位专家级的提示词生成器。你的任务，是使用【prompt构建框架】帮我生成最优秀的prompt。我会告诉你我要写什么内容，你需要先思考怎样超预期地写出来；如果是比较正式的内容，还要考虑引入相关时政政策来抬高维度。思考完毕后，把最重要的维度提炼出来，写进【prompt构建框架】的“要求”中。你给出的prompt必须最有价值、最能落地。当你和我互动后，你的输出要严格遵守【prompt构建框架】的格式，不许输出多余的话。

请先和我打招呼，只需要说：“嗨，主人，我是你的专属prompt生成器，请说出你的需求，我来帮助你生产最有效的prompt。”

学会了角色扮演法，也别以为万事大吉。角色扮演的真正意义，是让GPT从庞大的知识库里精准调取你需要的垂类知识，同时用你要求的口吻说话。但你可能会遇到另一个更头疼的问题：明明有个任务想让GPT做，自己却怎么都描述不清，总是词不达意。这才是真正需要调教的地方。

第一个解法：直接提问法。

别小看“直接提问”这4个字。大部分人都知道能直接问，但真到卡住的时候，反而不敢开口。海盐的建议是：先下笔，哪怕语无伦次地写出来，也直接递给GPT。它很聪明，你说得越乱，它越能从乱里抓住线索。这个方法特别适合“遇事不决任务”：你完全没思路，不知道该怎么指挥AI，也说不清需求。没关系，直接问就行。

这类任务有一个特点：不需要一上来就做到90分。一句话提示词能拿到60分，就已经赢了，主打一个省心省力。当然，想靠这种方式做到行业NO.1，绝对不可能。

那怎么把这60分的经验沉淀下来？很简单：

第一步，开发提示词。先用一句话去试，效果不好就换个说法再试；效果还行，就把这句话收藏起来。

第二步，抽象成模板。以后遇到同类场景，就把这句话里的变量提取出来，比如“写一个xxx”里的xxx，变成可以随便替换的占位符。这样，同类任务就能无脑让AI输出。

第三步，验证模板。调教出一套完美模板后，一定要新建一个对话框测试，防止历史对话对结果产生污染。这样才能得到高稳定、可复用的提示词。

举个例子。你想给公司新开发的键盘“机械姬”写一条广告文案，重点突出“技术与中国文化的结合”。先问GPT需要什么角色：

“我想让你帮我写一个xxx，但据说要给你一个角色让你扮演，才会更好，我应该让你扮演什么角色呢?”

然后再补一句：

“请扮演资深广告创意人，为我公司新开发的键盘‘机械姬’写一个简短有力的创意广告文案，突出‘技术与中国文化的结合’。”

把这次经验抽象一下，就有了一个通用模板：

【提示词模板：角色生成器】

【角色】：

请你扮演一个角色生成器

【任务】：

我想让你帮我写一个xxx，但据说要给你一个角色让你扮演，才会更好，我应该让你扮演什么角色呢?

以后用的时候，只需要修改变量。如果有些需求真的没有“要求”，别硬凑，不要为了结构化而结构化。

再看一个例子：用ChatGPT联网采集新闻素材。假设你想找3条2023年8月15日的AI重大新闻，并且按固定格式整理出来。

提示词可以直接写成：

请扮演新闻媒体资深编辑，现在要在互联网上搜索3条2023年8月15日的AI重大新闻。要求：1.格式为发生时间、20字新闻摘要、新闻参考链接。

![](img/zhuanqian_a7cc0356094ed2ceb694c8a362d16aeb.png)

这个提示词里其实已经用了角色扮演法，只是没有加小标题而已。不复杂的任务，完全可以不用格式。新手可能会先让GPT随便搜一下，结果发现输出长篇大论、格式难看，于是再加入“要求”去约束；两轮下来，一个通用模板也就炼好了。

如果你经常要搜索新闻，这个模板可以复用。把日期、数量、格式抽成变量就行。还可以让GPT访问你指定的网站，但要注意：GPT联网本质是靠爬虫抓取数据，如果网站禁止OpenAI爬虫访问，它就拿不到数据。所以最好提前测试，整理出一份你自己的常用权威网站清单。采集到一半如果因为长度中断，直接说“继续输出”就好了。

还有第三个场景：把ChatGPT当知识科普工具。比如大家经常搜“量子力学是什么”，但找到的解释往往又长又难懂。不如让GPT扮演小学老师，给小学生讲：

请你扮演一名中国的小学科学老师，给小学生科普一下什么是量子力学。

要求：1.使用一个常见的游戏小故事来做比喻，让小朋友都能听懂。2.字数不能太多，小孩子记忆力有限，太长了会忘记。3.最后给出和故事相对应的、科学官方的解释，有对比才会更清晰。

![](img/zhuanqian_b02ed73ed2bcb53c3057a2a5eb79c25b.png)

为什么选“给小学生讲”这个角度？因为小学生都能听懂的话，你大概率也能听懂。这就是实践带来的直觉。如果直接问GPT“什么是量子力学”，它大概率会给出冷冰冰的、像朗读科研报告一样的答案。一旦换成小学老师角色，效果立刻不一样。当然，如果科普的是近两年的新概念，记得开启联网功能，因为ChatGPT默认的知识截止日期是2021年9月。

这套提示词，对普通人做科普已经够用了。对要求极致内容质量的人来说，它输出的是灵感和初稿，可能省下约50%的工作量；要做到专业级、无歧义，还需要逐句打磨、反复择优，并且和权威资料对照。但如果你走“大力出奇迹”路线，60分就满足，那直接套用这个思路也完全没问题。

除了直接提问法，还有两个补充技巧要了解。

一个叫多轮对话法。如果你只做一次性任务，以后完全不打算复用，或者就是不想打磨提示词，完全可以像流水账一样和AI来回对话。这次不行就让它改，改完不行继续说哪里不行，直到满意为止。

另一个叫非结构化提示词。当你把提示词用到“人剑合一”的境界，就不需要形式上的结构化，随口一说，AI也能懂。结构化是为了表达更清晰，就像跟领导汇报时先列出一二三点；如果你不分条目也能让领导听懂，那自然也可以。

说完了直接提问法，再来看更进阶的解法：原子任务法。

什么是原子任务？就是不能再拆的最小任务，比如写一个标题、给宝宝起名字，这都是原子任务。而“写一篇文章”不是原子任务，它可以拆成标题、大纲、开篇、正文、结尾等多个子任务。每一个子任务都是独立的原子任务，最后再由这些原子任务拼出完整文章。

想要用好AI，底层逻辑只有两条：

第一，垂类行业经验。

第二，对AI的深度理解。

所谓深度理解，就是既懂AI的核心原理，又会调教AI的实战技巧。二者缺一不可。你必须知道高质量文案长什么样，AI生成得不好时，还要能指出哪里不好，并引导它往正确方向优化。

那如果换个陌生行业呢？你不需要短时间内变成大牛，这是不现实的。但可以通过方法论快速了解行业里的潜规则，写出比多数人稍好的东西，做到70分、80分并不难。从80分到100分，才需要长期积累，短时间内不必强求。

所以，第一步是先快速获取垂类行业经验。如果你本来就是该领域的专家，非常清楚高质量文案的标杆是什么，那这步可以跳过；如果你只需要70分，也知道70分大概长什么样，同样可以跳过。

剩下的事情就很简单了：大胆开口问AI，把好用的句子收藏起来，抽成模板，反复测试。这样一来，你手里的AI会越用越顺手，越用越懂你。早一点入局，早一点在自己的领域落地，壁垒就是这样一点点建起来的。

想迅速拿到一个垂直行业的实战经验，本质上就两件事：找到足够好的对标样本，和拿到可复用的方法论。

做任何高质量交付之前，脑子里必须先有画面感，知道最终要什么样。能力拆开看，其实是信息差加上落地执行。有了互联网，检索能力强的人几乎可以把大部分问题自己搜出来解决。

有人会说我搜东西总不如意，百度感觉不靠谱。没关系，这套海盐常用的检索打法补上就行。对绝大多数人来说，这套逻辑用下来就够用了。它能帮你实现认知对齐，同时把优秀案例和好方法都沉淀下来。

这里必须说投入产出比。举个例子，编程对零基础的人来说门槛，比写一篇公众号稿高得多。你靠搜索确实能找到三天速成课，写出点小玩意，但想做一个定制化强的网站还差很远。

如果做一个定制小站只能换回200块回报，就不值得花一周甚至更久从零研究编程。哪怕用法对了搜资料很快，入门也快，也没必要。

但如果你后续会频繁做这类小站，回报稳定且可观，投入产出比划算，那就值得用这套方法论猛冲。

<h8>1.1. 让搜索引擎真正为你干活</h8> <h9>1.1.1. 先把要搜的东西想清楚</h9>

高效检索的第一步，是把搜索词定准。

*   1.1.1.1.情景一 已知关键词直接搜

这是最省事的情况，词准就能直接命中。比如你确定要找可持续发展报告，直接搜“可持续发展报告”。

*   1.1.1.2.情景二 用关联词扩散

词不确定时，用相关概念组合。比如只记得某历史人物在明朝立过大功后来被流放，可搜 明朝 贡献 流放，就能把人物框出来。

*   1.1.1.3.情景三 向上找方法论【重要】

看高质量文案长啥样时，别只搜文案本身，要往上走，搜怎么写、什么特征、方法论。

比如想写余华《活着》读后感，搜“余华《活着》读后感”看了几篇还是没感觉，就直接改成“如何写好一篇优质读后感”、“优质读后感有什么特征”、“写好一篇读后感的方法论”。

*   1.1.1.4.情景四 类比打开思路

关键词搜不到时就横向类比。比如《活着》读后感找不到好的，就扩大到“优质读后感”、“影评”、“书评”，甚至小说读后感、书评都能提供参考。

*   1.1.1.3.情境三 向上抽象

描述太具体搜不到就往上提一层。比如比亚迪汽车市场分析报告搜不出，就搜“新能源汽车市场分析报告”，大盘里大概率包含比亚迪内容。

*   1.1.1.4.情景四 线索递进法

完全没头绪时，先用能想到的词试探。搜索结果会反哺关键词，你边看边搜，思路就清晰了。

比如研究 OpenAI ，先搜 openai，看到的维度会自动给你提供新的检索词。

*   1.1.1.5.情景五 借助 PDF

很多关键信息藏在白皮书、研究报告的 PDF 里，普通检索解析不全。这时用 filetype 指定 PDF 再人工筛，命中率会高很多。

*   1.1.1.6.情景六 翻页再看

答案往往在放弃的前一刻。搜索结果第3页、第4页甚至第7页，经常藏着真正好用的东西。

*   1.1.1.7.情景七 用专业措辞

要输入搜索引擎上实际会出现的词，而不是口语化表达。比如搜“头痛”而不是“我的头很疼”，更接近医学网站的用词。

*   1.1.1.8.情景八 多个AI交叉生成

不同AI在垂直领域的表现有差异。对标样本网上一时找不到，就让多个AI各自生成，拼凑灵感。

比如要一个五言诗，ChatGPT 不满意，就让文心一言、Kimi、智谱、讯飞、豆包、Claude 等轮流试，往往能拼出可用素材。注意通常是各家各出一句好句拼起来，很少有一家全篇完美。

<h7>step3. 提示词的4个调教心法</h7> <h8>3.1. 提示词里加入方法论</h8>

方法论是从理论层面抽象出这类优质文案的特征、技巧和写作方法。

方法论怎么来？

```
1.询问AI优质特征（利用刚刚学会的搜索大法，帮你扩展视野，觉得好用的直接拿来）
2.加入自己认为的优质方法论（人类的经验）
3.二合一为形成最终优质的特征列表，备用
```

把这些理论喂给 GPT 学习，或作为硬性要求让它按此执行即可。

很多人以为，写好 Prompt 靠的是把人设、背景、需求一股脑塞进去。其实真正有效的开发方式是反着来的：先出一个粗版本，然后一条一条往下删，每删一条都跑一次对照测试。删掉之后输出没什么变化，说明被删的是废话；删掉之后效果明显变差，才证明那句话真有分量。

有些技巧听起来很高深，但模型对它的存在毫无反应；换一种近义说法，输出立刻变样。这种细微差异靠感觉捕捉不到，必须做“单变量实验”：一次只动一处，用同一个测试题目反复跑，对比结果。超长指令往往删掉一大半，产出依旧稳定，那被删掉的部分就是典型的无效冗余。

正确做法是每条准则单独过堂。先跑一次原始版作为基准，再带着该准则跑一次。有效，就留下；无效，试着请模型帮忙换个措辞；换完依然无效，直接放弃，继续检验下一条。确认前一条真正创造了增量，才允许叠加下一条。长此以往，留下来的每句话都经过了实证，而不是靠数量堆出来的安全感。

## 准则放在哪：约束区，还是独立区

同一个最小目标，可以把准则写进“约束区”，也可以给它单开一个“准则区”。

举例，让模型为一本古典作品写一段开场白：

【Prompt 范式：开场金句：一句话制造记忆点】

人设：一位语言风格鲜明、擅长幽默与讽刺的作家。你对该作家的用词习惯和表达节奏了如指掌。

目标：用这位作家的笔调，为那部古典作品写一段开场白，字数不超过30字。

约束：

1. 用借代或隐喻，把读完原作的感受凝成一句有穿透力的短句，让读者瞬间共情。

2. 收尾要带一点暖色，不能全程压抑。

另一种组织方式：

【Prompt 范式：开场金句：一句话制造记忆点】

人设：同上。

准则：

1. 用借代或隐喻，把读完原作的感受凝成一句有穿透力的短句。

2. 收尾要带一点暖色。

目标：

1. 先读完上方“准则”，再动笔。

2. 以该作家的风格，为那部古典作品写一段开场白，字数控制在30字内。

这就是分块式 Prompt：用清晰的小标题把内容切成几个区块，模型解析起来更省力，结构也一目了然。区块数量可随需要增减。在“目标”区块中用【准则】这种显眼符号去引用另一个区块，相当于在代码里调用一个函数，模型会自动去对应位置提取信息。

每一条准则同样需要单独测试，只留下那些经过验证的真有效语句。

## 光讲道理没用，直接给范例

有些时候，准则写得再清楚，模型依然像“对牛弹琴”。你以为已经说明白，它偏按自己的理解跑偏。领导随口一句安排，下头十个执行者能给出十个不同版本。

这时候别继续抠字眼了，直接把范例拍上去。数学老师讲公式，学生满头问号，老师就换一道买菜算账的应用题来演示。模型也一样，你给它一段“标准答案”，它立刻知道要往哪个方向靠。

看这个写法：

【Prompt：开场第一段：一句话制造记忆点】

【人设】：一位文笔克制、观察冷峻的作家。

【目标】：参照下方范例与学到的手法，以该作家的风格，为某部经典作品写第一段。

【约束】：

1. 用一句精炼的感悟点题，字数不超过30字。

【范例】：

"""

河流从不催促船只，最终却把船送进大海。

"""

一个范例不够，就换一个再试；也可以一次给多个，甚至给一组反面对照，让模型自己分辨哪种更好。

## 缺什么，就锁死什么

如果你发现模型输出的初稿少了某个必要维度，不要绕弯子，直接在 Prompt 里加一条硬性规定。

例如，你要求每条信息都要带对应的人物姓名与时间，但模型总是漏。那就白纸黑字写上：

约束：

1. 每给出一个结论，必须同时列出对应的人物姓名与时间。

## 碎片化资料也能直接喂

喂范例的前提是，你手里有完整的对标文本。可很多时候，你只有一堆零散笔记，根本没时间整理成体系。那也没关系，手边有什么，就拿什么喂。

尤其是当模型储备里缺少某个对象的具体信息——比如某个品牌的营销布局、销售清单——你在外部检索到的东西本身也是一段段碎片。把这些碎片原样贴进 Prompt，模型反而能从中提取出像样的细节。

举一个实际例子：

【人设】：资深影评人。

【目标】：基于我提供的【参考资料】（均取自经典桥段），站在影片所在年代的美学与社会背景，写出50字以内的具体点评。

【约束】：

1. 模仿某位知名小说家的文风，援引资料中的年份与事件作为证据。

2. 用反转式表达制造记忆点，让人读完想转发。

【参考资料】：

"""

导演把时代变迁装进一个乡镇：1963年街巷杂乱却喧闹，主角的小吃店天天客满；1964年政治运动袭来，墙上刷满口号，街上人影稀疏；1979年小镇重新有了烟火气。镇子如同一只容器，它的每次变化都在重塑每个人的命运。

最难忘的桥段：一对恋人因为登记结婚被公开批斗，滂沱雨夜中男人冲女人喊：“别死！像条野狗也得活！”这声嘶吼让观众无法平静。那是一个容不下正常情感的年代，无数人只能以最低微的姿态硬撑。两人在生离之际喊出的那句话，粗粝却真实，一下子击穿人心。

"""

这说明，资料越碎越可以放心投喂。但有一个坑：模型在续写时会产生“词汇粘性”，优先使用你喂过的词。如果你塞入的竞品资料过多，它会不自觉地跑偏，把你真正要分析的主角晾在一边。要修正，一是调整各板块资料的比例，让主角占绝对大头；二是在 Prompt 中下死命令：“只能围绕主角展开，其余对象仅可作对比，不得反客为主。”

## 反复迭代，直到质变

别急着写出完美 Prompt。第一版跑出来效果不好，很正常。看哪里不顺眼，就改哪里，再跑，再改，再测。一个能在垂直领域稳定复用的 Prompt，通常需要经历多轮这样的循环。

那些看似一次就能成稿的高手，并不是天赋异禀，而是经验让他们在动笔前已经在脑中完成了预判和排错。普通开发者没有这份预判力，就用迭代来补足。

第4步：让模型跑出初稿——把调试完成的 Prompt 原样执行。

第4步：人工精修——删掉 AI 味明显的套话，删掉自己不喜欢的段落，逐条核对金句出处和事实细节，最后统一排版。收工。

将稳定的 Prompt 升级为通用范式——当某个 Prompt 的效果稳定后，把其中的变量抽出来（例如书名、人设、字数），它就变成同类任务的公共模板。以后再撞到相似需求，拿来就填。

## 复杂目标的拆分策略

如果一个目标可以切成多个最小执行单元，它就属于复杂项目。一口气吃不成胖子，让模型直接写5000字长文，效果通常会崩。最实用的办法是：一次只让它做一个小目标，把小目标调教到位，再拼装到一起。

因此，复杂项目的 Prompt，本质上是一串最小单元 Prompt 首尾相连，相当于一条 Prompt 链。

### 第一步：切碎

别让模型硬扛，先手动把它拆成一个一个不可再分的小块。拆分原则有两个维度：一是尊重模型的输出特性，二是紧扣稿件本身的质量要求，两者缺一不可。

比如，一篇1500字的文章，目标是达到本科在校生平均水准的80分。这个看似统一的目标，实际可以切成几个环节：

```
写标题：标题是文章的第一印象，需要吸引读者并准确反映文章内容。
写大纲：大纲是文章的框架，需要明确文章结构和主要观点。
写开篇段落：开篇段落设置文章基调，引起读者兴趣。
写正文段落：正文是文章的核心，逐一阐述观点和论据（可能需要设计故事、案例、数据等）。
写结尾段落：结尾段落总结文章主旨，留给读者深刻印象。
```

这5个环节的质量标准各不相同，无法用一套万能 Prompt 同时搞定。分开各自调教，才能真正对症下药。这种“拆得足够小再逐个击破”的做法，是追赶头部内容质量的快速通道。

### 第二步：逐个执行并拼装

把每个最小单元当成独立目标，用前面分享的调校方法逐项处理，最后把产出拼在一起，就能得到结构完整、细节扎实的成稿。拼接过程中沉淀下来的 Prompt，还可以继续演化为通用模板。

### 怎么才能演得更像？

关键是把人设做得足够丰满，用“边界约束”去定义它被允许做什么、被禁止做什么，自带哪些属性、绝对不能有哪些属性。

资历深浅就很重要：一个刚入行的新手和一个身经百战的老手，说出来的话气场完全不同。

人物怪癖也要写细：某个醉醺醺的人，回复时只能像喝高了发消息一样，满屏错字和病句，偶尔答非所问，并且不做任何解释。我的第一句是“你几点回来？”。

特殊风格也很有效：一个励志培训导师，开口必须频繁引用大师语录，才显专业；一个北京地陪，要用朋友聊天的口气，安排一趟有人情味、让人印象深刻的3日行程。

### 目标怎么设才不白设？

凡是又大又空的目标，都要先缩小，再交给模型完成。例如处理家庭内部矛盾，反面做法是笼统地问“怎么解决”；正面做法是把问题拆成几个具体场景，逐一请模型给出高情商沟通建议。

### 边界约束的更多用途

除了身份，边界约束还能用在结构、篇幅、语气、格式和内容维度上。

- 结构：要求分为3个段落，或者先给提纲。

- 篇幅：每个自然段控制在200字上下。

- 语气：像社交媒体大V那样开口。

- 格式：点名表格、JSON、Markdown，也可以附带链接、图表、emoji、process map、topology map。

- 内容禁区：禁止出现血腥、色情和死亡相关描写。

### 应对上下文遗忘

不论普通版还是付费增强版，模型的上下文记忆都有限度。对话一旦拉长，早期内容就会被慢慢淡忘，表现为“失忆”。

对策有两招：

1. 点它一句——发现它忘了，直接提醒刚才没记住的信息，然后继续聊。

2. 化整为零——如果是因为一次问得太多导致关联错乱，就把大目标切成若干小题目，让它分批回答。
