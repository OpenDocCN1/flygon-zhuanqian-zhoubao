# 《ChatGPT、换脸等 AI 工具带来的明星祝福等玩法升级》

你有没有想过，让一位当红明星对着镜头，用你自己的藏头诗，为你朋友的新婚送上祝福？以前这可能要花几万甚至几十万，还得看人家档期。但今天，在ChatGPT、Midjourney和换脸技术的组合下，这个玩法正在被彻底重构。

先说可行性。我特意在星球里搜了一圈，发现“明星祝福”相关旧帖有4条，“藏头诗”29条，“奥特曼”148条。但我要聊的不是这些老套路，而是一个能跑通的新闭环。别急，重点在第三部分。

先看看现状。名人祝福、网红祝福、举牌喊话，这几年在小红书、抖音、快手满地都是。价格却一路滑坡——非当红明星的报价，比三年前跌了80%多，2000块左右就能搞定。问题也很明显：非当红明星年轻人不买账；真当红的又请不起；有钱人干脆直接请到现场，视频祝福完全不够看。至于更便宜的举牌喊话，早就是套模板的批量操作了。

![](img/zhuanqian_d7d68db93e98cfca3980807227c178dc.png)

再说藏头诗。这东西更轻，现在靠AI调教就能做得相当好。我亲测，只要优化prompt，ChatGPT虽然后台资料九成以上是英文，但生成中文藏头诗完全够用。我花了半小时调教，让AI给“李月霞、郑格雷”写婚礼祝福，带上欢乐美好的情绪，一次出了5首。我选一首：

月光璀璨照夜霞，

霞映小鸟快乐家。

格局相合心相连，

雷鸣欢歌喜无涯。

不行就继续生成，或者自己挑句子拼，一次也只要5到20秒。

至于奥特曼，圈里已经聊得够多了。这是个全球排名靠前的大IP，衍生玩法多。但它有个隐藏秘密——版权归属特别混乱，小打小闹可能没人管你。不过想做长期生意的，还是别碰为好。

![](img/zhuanqian_5a25aabfc23c7fdf02eb2553bac3e35d.png)

重点来了。把真人明星祝福改成“AI换脸+场景情绪自由定制+诵读藏头诗+诗词画面轮播视频”，会不会是条新路？换脸技术现在已经很成熟了，成本还在降。除了技术，还有个低门槛玩法：让ChatGPT把藏头诗扩展成15秒短视频的分镜脚本，再用Midjourney画出5张图，每张放3秒，配上音乐，一个氛围感视频就出来了。比如上面那首藏头诗，可以变成：

画面一：暗夜中月光璀璨如银，洒在绚丽的夜霞上，瞬间点亮画面。

画面二：夜霞里一群小鸟在空中追逐嬉戏，快乐无边。

画面三：两个人手牵手，共同构建美好家园，心与心相连。

画面四：雷声轰鸣，闪电在画面中闪烁，雷鸣伴着欢歌，活力四射。

画面五：画面淡出，留下喜悦与温馨，幸福蔓延。

这样的15秒短视频，不用真人出演，想要什么情绪就有什么情绪。明星的每一句话都能随心定制，想怎么说就怎么说，不会出现念稿、疲惫、状态差、显老这些尴尬。视频里呈现出的状态，甚至超过明星的巅峰时期。

但这事要做大，必须合规。要想长期干，拼的还是执行力。去找愿意配合的明星，用打包价可能比分成更合适。合规的好处有三：一能放心扩大规模，二能守住高客单价，三能拿到“打假”授权——先睁只眼闭只眼，等时机成熟再索赔。明星自己也乐意：成本趋近于零，效果反而更好，而且看到先例后，跟风就更容易。

合规之后，多渠道分发是必然。这种组合拳视频，流程熟练了5到15分钟出一个，定价几十到几百元都行。ToB可以和婚庆公司、蛋糕房合作，高客单价再分成——婚礼祝福大概率比生日祝福更能卖出价格。ToC就更不用说了，渠道多得很，自己做或外包都行。

最后，如果你没有明星经纪人资源，怎么办？别忘了公共IP。像“孙悟空”这类可以免费商用的形象，用Midjourney放心做，没人找你麻烦。ChatGPT还能帮你梳理哪些IP能用。小猪佩奇、小黄人、迪士尼公主、星黛露、漫威英雄，这些都有明确归属；国产的超级飞侠、熊出没也是私有IP。但公共IP就不一样了，和祝福玩法结合，虽然没有明星那种鲜活力，却有厚重的文化力加持。

![](img/zhuanqian_2f95d7fac069e64568da638be48199a0.png)

如果你愿意，甚至可以自己开发新IP，用故事借力。这个思路还不成熟，欢迎高手指点。

我自己习惯做长期产品，最近刚开始学ChatGPT，越发觉得它是提效神器。上面这些想法，和我的项目有些相通，但我没精力亲自去试。有兴趣的圈友，可以做个小MVP试试水。当然，也欢迎拍砖打脸——能更快认识到自己的不足，比收到赞更让人开心。
