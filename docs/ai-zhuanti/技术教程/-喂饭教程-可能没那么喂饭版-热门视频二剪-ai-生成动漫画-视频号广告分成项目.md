# （喂饭教程-可能没那么喂饭版）热门视频二剪+ai 生成动漫画+视频号广告分成项目
龙哥在风向标里丢出“热门视频二剪+AI漫画化+视频号分成”这个玩法时，我当晚就上手了。虽然标题写着“喂饭教程”，但实际测下来发现很多细节还得自己一遍遍试，比如怎么避免被判搬运、怎么处理认证。不过好消息是：第三天就开始有收益了——昨天刚开通分成计划，粉丝涨了500多，今天已经有一个视频开始出钱。![](img/5a6bd473fc02fdabbd08886de4e88c0c.png "None")
整个项目核心就是三步：
第一步，热门素材做二次剪辑。说白了就是收集爆款内容，再通过剪辑去重，降低被平台判搬运的风险。
第二步，AI漫画转绘。把视频里的画面抽帧成图片，再用AI转成手绘或动漫风格，改头换面之后原创属性就强了。
第三步，开通视频号广告分成。前提很简单：满100个粉丝、发够10条视频、内容得符合视频号社区规范。
素材去哪儿找？抖音或视频号搜这几个话题就行：视频号里可以搜“#画一个世界”，抖音和视频号都能搜“#感人瞬间”“#感动瞬间”“#泪目”。这几个标签足够用了。平常利用碎片时间刷一刷，看到点赞过万的视频就转到自己的单人群里，等攒到一批再集中处理。刷多了算法也会不断推同类内容，等于越刷越好找。
实操中很多人会遇到“出镜人认证”的弹窗，这个怎么破？评论区里有人给了几条思路：
第一条，请出镜人本人认证，可是素材大多来自网络，压根找不到本人，基本走不通；
第二条，提供数字人的授权证明；
第三条，走官方认证通道，个人或企业主体都行。
另外还有一种临时办法：拍几个真人出镜的视频，去申请“XX博主/XX自媒体”这类官方个人认证，认证通过后认证弹窗会秒解。不过这个办法治标不治本，不是能反复用的，长期还是得想办法别踩线。
龙哥已经在评论区说可以开一期mini航海，估计过不了多久就有动作。对这玩法还没头绪的伙伴，不用等完整版教程，直接按这三步跑起来，边做边调。
