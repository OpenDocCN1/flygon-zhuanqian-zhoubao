# 从 Cursor 航海到上线变现：我做的这个 AI 文字转透明 PNG 网站全过程

## 参加 Cursor 航海后，我上线了一个 AI 文生透明 PNG 网站并接入了海外收款

作者：龙哥

日期：2025-01-20

大家好，我是赚钱透明人一鱼两吃，这是我第一次在论坛发帖。想跟大家分享一下我做的一个 AI 文字生成透明 PNG 图片网站的诞生和变现尝试。

点子其实来自 Cursor 航海期间。教练在分享里提到硅基流动这个大模型超市，可以直接调用各种大模型的 API。那上面主要是文生图、文生视频类的接口。后来我刷到一个国外站点能直接一键生成带透明背景的 PNG 图片，成品效果挺干净。我就想，能不能自己复刻一个类似的功能？

一开始觉得启动会很难，结果真正难的是后面的细节。

整个项目我是这么推进的：

先在硅基流动上对比了好几个图生模型，最终锁定了 black-forest-labs/FLUX.1-dev ，也就是 FLUX.1 [dev]。这是一个 120 亿参数的 Rectified Flow Transformer，能根据文字描述生成高质量图像。

为了防止 Cursor 在开发过程中“失忆”或者自作主张加功能，我提前写了一份 README.md，把产品思路、要调用的模型、请求地址、API 文档里的关键参数和整体框架都写进去。能不能完全用好这个文档我也不太确定，是问了豆包后照着做的一个计划说明书。

直接把包含 README.md 的文件夹拖进 Cursor，告诉它按文档要求做一个文生图网站。因为需求和接口信息都写清楚了，它很快就把首页跑出来了，测试起来也还行。问题随之而来：图片能生出来，但背景不是透明的 PNG。

血泪教训：用 Cursor 或 Windsurf 开发到一半时，一定要提醒它不要随意修改已有的代码和功能，否则它会抽风式地乱删乱改，气到想骂人。

接下来要解决的就是背景移除。

先问了 GPT-4o，得知目前没有直接支持生成透明 PNG 的大模型。Stable Diffusion 有相关插件，但需要配合 ComfyUI 操作，门槛太高。于是转向搜索免费的抠图模型，找到两个开源选手：RMBG 和 BiRefNet。个人体验下来 RMBG 的抠图效果更稳定一些。

难点在于我不会把本地模型改成 API 调用。折腾了几天没进展，最后在 GitHub 上找到了别人已经封装好的 RMBG API 接口，直接拿来用就省事了。

核心流程最终确定为：先用 FLUX.1-dev 生成图片，拿到图片地址后丢给 RMBG 做抠图，最后把处理好的透明 PNG 返回给用户。经过调优，我这边的批量 4 张透明图生成速度比对标网站还要快一些。

网站的基础功能跑通后，又用 Cursor 加了后台管理和中英文双语切换，这些部分就不细说了，都是靠咒语生成的。

最花头发的是海外收款和 Google 登录。

我在赚钱里搜过 PayPal、Stripe、Payoneer 等方案，都觉得门槛和资料要求对新手不友好。后来翻到《工具站出海》那篇航海手册，看到有大佬用 ko-fi.com 做老照片修复站变现。我去找鱼丸要资料，结果超纲了。于是自己注册了 ko-fi 账号，并绑定了 PayPal。

ko-fi 的程序通知功能我一开始也不懂，后来丢给 GPT-4o 解析才明白：用户在网站捐款后，ko-fi 会推送通知，我就能用它实现自动充值、发放积分。借助 Cursor 我把这个对接打通了，捐款就能自动到账。

注意 ko-fi 在国内需要🪜才能正常使用。

项目目前的变现情况：非常遗憾，透明 PNG 网站的收入是 0。虽然按航海手册做了推广，每天有 40-50 个 IP 访问，但一分钱都没收到。倒是另一个用 Cursor 建的网站 freepngzone.com 带来了 0.2 美元的广告收益，中间有几天没收入是因为我手贱把 Ads 的 txt 验证文件删了，今天才补上。
