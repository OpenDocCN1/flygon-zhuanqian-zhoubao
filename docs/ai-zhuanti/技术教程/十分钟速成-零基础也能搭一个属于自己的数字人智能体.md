# 十分钟速成：零基础也能搭一个属于自己的数字人智能体
> 很多人问我：不会写代码，能不能搞 AI 数字人？
> 今天这篇就手把手带你跑通全流程，全程拖拽操作，从文案到成品视频，一气呵成。
🎯 这个项目能干嘛？
喂一段口播文案进去，Coze 会自动帮你完成这些事：
- 从数字人库中挑选可用角色
- 自动发起视频合成任务
- 持续刷新进度，直到出片
- 最后把高清视频链接交到你手上
不露脸、不配音、不剪辑，几分钟就是一条能直接发布的视频。
适用场景相当广：
- 做短视频矩阵号，快速起量
- 帮本地商家做产品宣传视频
- 做知识口播、课程讲解类内容
- 打造情感陪伴类虚拟形象
## 💰 能怎么变现？
简单列几个方向：起号跑量、接定制单、卖操作教程、做社群陪跑。
本质上是一套“可复制的服务流程”，服务对象可以是新手博主、中小企业主，或者想做批量内容的团队。

## 🧩 工作流是什么？
拿做饭类比：洗菜、切菜、炒菜，每一步都有先后顺序。
工作流就是把这套顺序教给 AI，让它按步骤自动完成复杂任务。
比如：用户提问 → 自动查资料 → 做总结 → 生成图文回复。
完全不用写代码，拉拽节点就能搭好。

### 节点五：代码节点——提取选中数字人的信息
根据用户在问答节点的选择，取出对应的数字人完整信息。
结果：单个数字人全部信息
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_3c318da60856a2bd0dd864b6c02919bb.png>
Python 代码：
```
async def main(args: Args) -> Output:
params = args.params["avatars"] # 数字人列表
xuanxiang = args.params["xuanxiang"] # 用户选择的数字人
text = args.params["text"] # 用户输入的文案
optionName  = xuanxiang.split(',')[0].strip() # 提取出选项中的数字人名称 （浩然-专业, 缓慢自然讲知识, 男）
formatted_results = [] # 创建一个空列表，用于存储格式化后的结果
# 遍历 params 列表
for i, item in enumerate(params):
# 检查当前 item项目 中是否存在 "name" 是否等于 optionName
if item.get("name") == optionName:
# 构建一个结构化字典，进行赋值
result_item = {
"audio_man_id": item.get("audio_man_id"),
"bg": 1,
"figure_type": item.get("figures")[0]["type"] ,
"person_id": item.get("id"),
"text": text,
"width": 1080,
"height": 1920,
"name": item.get("name")
}
# 将构建好的结构化字典添加到结果列表中
formatted_results.append(result_item)
ret: Output = {
"result": formatted_results # 将格式化后的结果列表赋值给 "result" 键
}
return ret
```
