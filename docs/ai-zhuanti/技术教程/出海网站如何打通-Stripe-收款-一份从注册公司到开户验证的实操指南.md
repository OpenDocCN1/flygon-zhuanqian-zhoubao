# 出海网站收款被卡在Stripe？从注册英国公司到开户验证的全流程实操

大家好，我是龙哥，00后，坐标佛山，目前主要做运营。

最近，出海 Web 站和 iOS App 在航海圈里热度很高。很多朋友借助 Cursor 等工具，即使没有编程基础，也能快速做出网站或 AI 工具。

但项目上线只是第一步。真正准备通过数字产品、工具站实现变现时，不少人会被“如何收款”卡住，尤其是 Stripe 的开通。

我发现，关于这部分的完整教程并不多。网上虽然有不少参考内容，但部分帖子发布时间较早，操作流程、平台政策和所需材料是否还适用，都会让人不太确定。

我最近刚把整个流程走了一遍，也踩了一些坑，所以把从注册英国公司、准备境外手机号，到办理香港银行卡、申请 Wise 企业账户，再到开通 Stripe 的过程整理出来，供同样在做出海项目的朋友参考。

这篇内容更适合以下人群：

> 已经拥有网站，正在销售数字产品、运营 AI 工具站，但因为没有合适的 Stripe 收款账户而无法继续的新手。

需要提前说明的是，平台审核和政策可能随时调整，本文记录的是个人实操经历，具体以各平台最新要求为准。

# 一、整体需要准备哪些环节？

整个流程大致可以拆成五步：

1. 注册一家英国公司；

2. 准备一个可以接收短信的海外手机号；

3. 前往香港办理汇丰银行卡；

4. 申请 Wise 企业版账户；

5. 使用公司和 Wise 资料申请 Stripe。

为什么要准备这些东西？

- 公司主体能够让 Stripe 的账户结构更完整；

- 海外手机号用于注册和验证多个境外平台；

- 香港银行卡用于支付 Wise 的开户费用；

- Wise 可以作为 Stripe 的收款账户；

- 最终通过 Stripe 连接网站和数字产品业务。

# 二、为什么我选择英国公司？

从成本、注册便利性和后续维护来看，英国公司对于刚开始做出海项目的人比较友好。

## 1. 注册成本相对低

美国公司的注册费用通常在 500 美元左右，而英国公司通过 1st Formations 注册，包含服务费后大约为 77.58 英镑，整体成本更低。

## 2. 后续维护费用较少

美国公司通常需要支付年度续费以及注册代理相关费用，年费大约在 100 美元左右。

英国公司每年的确认声明费用约为 13 英镑，维护成本相对可控。

## 3. 注册方式更简单

英国公司可以在线完成注册，准备好资料后，在家通过电脑提交即可，不需要专程前往海外办理。

## 4. 税务和收款方面相对方便

根据我查到的资料，英国公司的离岸经营在一定条件下税务压力相对较低，涉及外币和欧元收款时也较为方便。

不过，公司注册、税务申报和实际经营涉及专业问题，具体情况还是建议根据自身业务咨询专业人士。

# 三、注册英国公司需要准备什么？

建议提前准备好以下材料：

- 护照；

- 苹果手机，用于安装 Credas；

- 一张可以进行外币支付的银行卡；

- 带有地址信息的银行卡流水；

- Gmail 邮箱。

我使用的是招商银行 Visa 卡，支付注册费用没有问题。邮箱方面建议优先使用 Gmail，尽量不要使用国内邮箱，以免后续接收邮件或验证时出现不便。

# 五、完成身份认证和地址验证

提交注册资料后，还需要完成身份与地址验证。

## 1. 使用 Credas 完成身份认证

首先在苹果手机上下载 Credas App。

打开后，使用注册邮箱中收到的验证码登录，并依次完成：

- 上传护照；

- 人脸识别；

- 使用手机 NFC 读取护照芯片。

这里通常只能使用护照完成认证。对于境外平台来说，护照是主要的国际身份凭证，身份证一般无法替代。

![](img/zhuanqian_433bbd87d38249a187a88e60b1c499d1.png)

## 2. 提交地址证明

我第一次提交的是招商银行卡流水，因为流水左上角带有地址信息。

不过，第一次上传后系统提示无法识别，随后平台发来了可接受文件的示例。

![](img/zhuanqian_b236ac94353938e9d83cc8c16db2fb5d.png)

之后我按照示例重新准备并提交了相关地址证明，最终完成审核。

# 六、准备一个海外手机号：giffgaff

很多境外平台注册时都要求绑定海外手机号，因此建议提前准备一张能够在国内接收短信的境外 SIM 卡。

我当时是在电商平台购买的海外手机卡和备用手机。

![](img/zhuanqian_322abb25ec86900ae73a69815fde0007.png)

![](img/zhuanqian_141143d7305b9b332ba16317de8f92b2.png)

如果你确定要长期做出海业务，这张卡还是很有必要的。除了注册 Wise，很多其他平台也会用到海外号码。

giffgaff 卡收到后，需要进入官网完成激活。

我选择的是低成本、基本不收月租的套餐，主要用途就是接收验证码。按照目前的使用情况，收短信一直比较稳定。

![](img/zhuanqian_58d7e0d9d66454837c5a255652c45f96.png)

激活时需要支付大约 10 英镑，我当时使用招商银行 Visa 卡完成付款。

有一个细节需要注意：

> 新卡刚插入手机后，可能不会立刻有信号，有时需要等待 5～6 个小时。激活后如果暂时没有反应，可以第二天再查看。

# 七、前往香港办理汇丰银行卡

接下来需要准备一张可以进行境外支付的银行卡。

我本人去香港办理了汇丰银行卡，中银香港理论上也可以作为选择，只是当时时间有限，没有同步办理。

## 办理前提

需要本人前往香港线下申请。

## 出发前建议准备

1. 在支付宝购买境外流量或开通漫游；

2. 携带充电宝，香港部分场所的插头接口可能不同；

3. 提前想好开户用途；

4. 保存过关凭证或小票；

5. 提前下载香港汇丰 App；

6. 规划好路线，优先选择距离口岸较近的网点；

7. 准备招商银行 Visa 卡的纸质流水；

8. 如果方便，也可以带上水电煤气等地址证明；

9. 携带身份证、护照等有效证件。

我当时提前准备了一些海外基金，并在银行询问用途时说明是用于海外股票或基金投资。具体准备方式要结合自己的真实情况，切勿虚构信息。

我去的是葵芳支行。到达网点后，直接向大堂经理说明要办理银行卡，取号排队即可。之后工作人员会进一步了解个人情况，审核没有问题的话，就会继续办理。

# 八、汇丰红狮子卡和蓝狮子卡有什么区别？

刚办下来的通常是红狮子卡。

这张卡主要用于存取资金，但没有线上支付所需的三位安全码，因此不能满足部分境外平台的支付要求。

简单理解：

- 红狮子卡：主要用于存钱和账户管理；

- 蓝狮子卡：具备线上支付功能，订阅 Cursor 等软件时，通常需要填写卡片背面的三位安全码。

建议到香港后准备并存入 500 港币以上，因为后续开通 Wise 需要使用香港银行卡支付一笔费用。

回到内地后，可以通过香港汇丰 App 申请蓝狮子卡。提交申请后需要等待审核，之后会通过 EMS 邮寄，也可以寄到大陆地址。

# 九、申请 Wise 企业版账户

## 1. Wise Business 的主要作用

Wise 企业账户适合需要进行国际收付款的业务，常见特点包括：

- 没有固定月费；

- 通常没有最低余额要求；

- 需要支付一次性开户费用；

- 支持多币种收付款；

- 可用于全球业务收款；

- 能够为 Stripe 提供收款账户信息。

注册入口可以使用下面的邀请链接：

https://wise.com/invite/dic/weizez4

## 2. 申请前需要准备什么？

申请 Wise 企业版前，建议准备好：

- 护照；

- 已经注册完成的英国公司；

- 香港汇丰蓝狮子卡。

其中，蓝狮子卡主要用于支付 Wise 的开户费用。

## 3. 注册时的注意事项

### 公司注册号

Wise 会要求填写英国公司的 Registration Number。

这个号码可以在 1st Formations 发到 Gmail 的邮件中找到，一般会包含在 PDF 文件里。

### 身份验证

个人信息要如实填写，身份文件使用护照，不要使用身份证替代。

### 支付开户费用

Wise 开户需要支付一笔费用，我当时使用香港银行卡完成。

如果没有香港银行卡，也有人会选择找第三方代付，但这种方式存在风险，建议优先使用自己的卡完成支付。

# 最后总结

整个流程可以概括为：

> 英国公司 → 海外手机号 → 香港银行卡 → Wise 企业账户 → Stripe

其中比较容易出问题的地方主要有三个：

1. 地址证明不符合要求；

2. 海外银行卡无法完成 Wise 付款；

3. Stripe 提交的公司资料、网站信息和实际业务不一致。

所以在准备材料时，尽量保证信息真实、前后一致，并提前把网站的服务条款、隐私政策、退款规则等页面补齐。

以上是我这次完整走完流程后的经验整理，希望能给正在做出海网站、数字产品或 AI 工具站的朋友一些参考。如果平台政策发生变化，具体要求仍然要以官方页面为准。
