当一款商品在 TikTok 上拿到千万级播放，基本可以断定它已经吃透了平台调性和用户心理。

我最近就盯上了一个播放量达 7800 万的案例——带贴纸的便携药盒。围绕这个品，我做了完整的溯源和复盘，今天就用它来说明 TikTok 广告选品的底层思路。

我是 pipiads 的大伟，本期重点聊 TikTok 广告投放的选品方法论。对任何电商平台而言，选品都是决定成败的第一步。

过去几年我每天会刷几千个商品，从国内的抖音、小红书到海外的亚马逊、独立站、社媒，我都亲手去验证过思路，也打爆过不少品。

爆品其实有共通的规律。今天先把 TikTok 广告投放的选品框架讲清楚，并穿插我实操调研的那款爆款案例，供大家参考。

# 一、TikTok 广告投放的核心信息

**关键词：强度 + 信息差 + 赛道趋势 + 多渠道验证**

TikTok 本质是短视频娱乐型 App，用户打开它最初的诉求是放松解压。一个商品能病毒式传播，前提是和平台气质合拍。而社媒平台最通用的抓手就是新奇特。怎么理解新奇特？

**强度：**

通过持续高强度的观察，了解当下投放市场的真实面貌：当前的主流品类有哪些、哪些品正在热销、为什么能火、我们是否具备差异化优势。

**信息差：**

当新品刚冒头时，能不能第一时间感知到，这就是网感。比别人更快捕捉到新品，就是信息差。

**趋势：**

看到一个新品后，要判断它的走向是上升、平稳还是下滑。通过长期追踪，锁定处于上升期的品。

**验证：**

不能只看 TikTok，要跨平台验证需求。比如 TikTok + 亚马逊等海外渠道，确认海外用户是否真实有购买意愿。

先用强度去了解市场趋势，再及时捕捉新品，锁定趋势向上的品，借助多渠道市场验证，如谷歌搜索指数同步上涨，再结合匹配度与优劣势分析，最终挑出匹配度高且具备优势的品去测试。

# 四、当前落地的选品逻辑

**（1）选品思路**

![](img/zhuanqian_9157a25034c32a86581f1ce83c1eb5a1.png)

**（2）投放方式**

**1、投放逻辑**

多测试，用概率换确定性，再放大

**① 广告账号**

**逻辑：**

1.  账号需要养，人群标签越精准，计划越容易跑起来；

2.  不同账号表现差异，本质是起号时抓到的用户群体不同，表现自然不同。一个账号至少跑满三天再决定否保留/放弃；

3.  因此账号尽量做垂直，一个账号聚焦一个人群的产品，甚至按产品来做账号隔离；

**方法：**

1.  有垂类账号优先用垂类账号；没有则需测账号，通常 3 个账号起测；

**② 广告系列（计划）**

不同计划触达的人群不一样

1.  新建计划可以触达更多样的人群

**建议建系列的方式：**

1.  不同兴趣分系列：如泛投 / 自动 / 指定兴趣 / 指定人群，分开建系列

2.  不同出价策略分系列

3.  计划衰退期及时新建计划

4.  多建计划 = 多找人群

**③ 广告组**

广告组是系列下的分支，人群基于系列衍生而来

1.  在表现好的系列下，多建广告组，在同一人群池里提高出单概率；

**④ 广告**

广告是广告组的下一层

1.  当广告组表现不错时，可复制其定向并搭配不同素材，让受众与素材更精准匹配，提升转化；

2.  广告组进入衰退期时，可尝试替换素材以延长生命周期；

3.  同步多复制广告组，匹配更多不同卖点素材：A 卖点对 A 用户无效，B 卖点可能正好击中用户，从而促单。

**（3）测试方法**

**爆品打法：多账号 * 多系列 * 多广告组 * 多广告**

1.  用概率筛选出优质账号/系列/广告组/广告，再在此基础上放大；

2.  放大核心通常是优质广告组 + 广告优化；

**品牌打法：少账号 * 少系列 * 少广告组 * 少广告**

1.  给系统充足预算去学习；

接下来用一个可复制的落地案例，带大家看一款爆品的成长路径。

1、**利润是第一性原理**

**选品层面**

投放广告建议优先选客单价较高的品。有些类目投放的单次转化成本要十几二十美金，低客单产品基本玩不转，除非靠自然流。

![](img/zhuanqian_4968afa614eb15ed490b894a078ecdfe.png)

pipiads 上投放猛的品基本都有利润空间。

选高客单价的品，生命周期更长，成功率更高，因为利润能覆盖广告费和各项成本。

2、**顺应平台调性，卖冲动消费**

TikTok 是娱乐型短视频，用户带着娱乐心态刷。建议主攻新奇特品类，普通品要和线下超市、各大电商平台硬扛，竞争极卷。

![](img/zhuanqian_6ded9afe4f3149ff5fdadf0949d06bb2.png)

尽量选择受众面广的品去测试，当前平台商业化标签还在积累期，受众越广越容易出结果。爆款元素是组合拳：情绪价值 + 功能性 + 热点 + 节日礼品 + 情怀。

举例：普通白 T 衫已经烂大街，如果加上鸡汤文案“看世界，做自己”，配上情绪图、赋予意义，再结合情人节礼物场景，“亲爱的，我会一直在你身边”，瞬间有了完全不同的感觉。

![](img/zhuanqian_04283c8077e2a59bfab202bc03b85f68.png)

单一元素不稳定，多元素叠加才更容易出爆款。

3、**避开容易比价的红海品**

随着比价习惯普及，独立站还有信任问题。我曾投 Spark Ads 开评论，就有人在评论区骂，原因往往是前人发过假货或不发货，锅被背过来。甚至会出现“某某平台更便宜”的甩链接行为。

![](img/zhuanqian_104b4b072b6a772a11a46ea09c199c1f.png)

尽量挖掘电商平台上不好搜到的品，或选用质量过硬、结合优质服务的品来建立信任。

即便能搜到，也可以靠标题重塑和包装差异化制造信息壁垒。比如绿色笔记本改名“柠檬南瓜 纯爱之光”，艺术感拉满，用户搜都搜不到，参考国内小说推文逻辑。

4、**情绪选品是核心**

调研和理解用户情绪是电商玩家的必备技能

1.  情绪共鸣带来认同

2.  系统化调研情绪

3.  持续挖掘大众的不同情绪点

4.  挖掘真实诉求

5.  把诉求与产品结合，是兴趣电商的关键

**可从细分市场切入**

① 如何找到细分人群的刚需

② 避开大类目红海，但也不做太冷门的品

③ 模式思考

细分选品的核心是：**用一款产品发散思维，精准定位。**

**案例示范：**

想做包，箱包是大类目，先不确定具体品类。通过发散思维为产品叠加元素来挖掘细分市场。

**先以 pipiads 为锚点找到热度不错的产品**

![](img/zhuanqian_932e395ad510f5beb1d381a7eadad802.png)

**拆解爆点：**

**节日：**母亲节、父亲节、情人节、圣诞节

**对象：**男士、女士、父亲、兄弟、上班族、朋友、闺蜜

**功能：**收纳、防 NFC/RFID 扫描、可追踪、便携

**场景：**户外、聚会、买菜、办公

**主题：**毕业、生日、活动、周年

有了框架后去市场调研，继续挖掘需求与反馈。

2.**避开大类目红海，在红海里找蓝海**

以女包为例，大牌竞争激烈，小卖家切入困难。除了女包，还可延伸到户外包、单肩包、手提包等细分品类。

需求可通过速卖通、亚马逊等平台的类目细分、头部卖家评论来研究。

3.**市场好卖就卖什么**

一模一样跟随：他吃肉你喝汤，不长久。虽然执行力强可能有机会，但目前不建议。

可通过差异化拉高上限：地域差异化复制，美国跑爆就换未投放国家测试；在此基础上做创新优化，产出新素材；寻找同类功能/相似款做一比一学习模仿。

**提炼思路，总结爆单规律，自己开品：**经过大量案例沉淀，总结爆单元素，自己打造爆款。

核心是：大市场厮杀激烈，细分市场很多人做得不够细。我们可以从供应链、营销等角度研究，先做到比对手更好。
