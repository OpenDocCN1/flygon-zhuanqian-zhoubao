### 步骤一：注册并配置WxPusher

1.打开 WxPusher 官网：https://wxpusher.zjiecode.com/

![](img/zhuanqian_36e527ba14b2b9ae937ce65a834995fc.png)

2.用微信扫码登录，白嫖首登自动注册。

![](img/zhuanqian_c184cbac01015d6dce3a48ff7bae92c4.png)

3.在后台新建一个“应用”，

![](img/zhuanqian_9625a7fb461d68fac1fbcc8b92a75ce8.png)

![](img/zhuanqian_b144ae3b45557171344162e1f5a88d43.png)

回调地址填写：

https://your-domain.com/wxpusher/callback

![](img/zhuanqian_0d8363580573870a582859db10033105.png)

确认后会弹出 appToken，这是应用的唯一凭证，务必保存好

![](img/zhuanqian_4457e997f5b28377eaecb9ade9b762f9.png)

随后页面会生成一个二维码，按提示完成关注，关注后才能收到推送

![](img/zhuanqian_14bc913c2c7d38474823a5ec51cb5178.png)

关注成功后会收到一条系统提示，表示订阅已生效。

![](img/zhuanqian_6f07a5e2b5645b8cc59e386ef763f6cf.png)

![](img/zhuanqian_938bcfc3bfecad8badba83c2d6dd7b57.png)

![](img/zhuanqian_54d891481793b97f2176796fae3b5fc7.png)

小程序目前无法接收订阅消息，按指引下载 App，点击上方红色按钮自动跳转安装

每天在 App 里查看推送

![](img/zhuanqian_35008768207445e5ecaab8a47e1cca2c.png)

安装完成后进行注册

![](img/zhuanqian_515aedb128bdbe4f25a5b1abeb66b15e.png)

接着绑定手机号

![](img/zhuanqian_1798cd2c12962435e891e6b9afdc484e.png)

![](img/zhuanqian_eaf94d2e2744b3050f40d8c68a04bfc8.png)

### 步骤二：获取微信公众号热榜 API

我踩过不少收费接口，最后锁定这个完全能白嫖的。

选它是因为个人使用每天有 100 次免费调用，足够日常。

![](img/zhuanqian_001a6234e65490e2f3ed2797cb91b0c0.png)

进入后点“申请接口”

![](img/zhuanqian_1bd82ba0a18eb669f520ca1821af8487.png)

### 步骤三：把自动推送脚本放到 GitHub

脚本的核心逻辑是云端定时运行：每天执行一次 → 调热榜 API 拉最新数据 → 调用 WxPusher API 推到微信。

代码已上传，需要就自取

1️⃣ Fork 仓库

访问：https://github.com/nancy4567891011/wechat-hotlist-pusher-public

点 “Fork”

![](img/zhuanqian_211563367fc7ffe64736b2510a96bedc.png)

Fork 到自己账号下，才能在你的云端定时推送

### 步骤四：设置定时任务

2️⃣ 配置 Secrets

进入已 Fork 的仓库

Settings → Secrets and variables → Actions

逐条添加以下 Secrets：

![](img/zhuanqian_ac1e73b676b039d3df8f43340c0c99e4.png)

注意要一条条单独添加

*   WXPUSHER_APP_TOKEN ： WxPusher 应用令牌

*   WXPUSHER_UID ： WxPusher 用户 UID

*   TIANAPI_KEY ： 天行 API 密钥

配置完记得把仓库设为私有，防止密钥泄露

![](img/zhuanqian_3ad683ba46da4397b6a3ef05b2bcdcff.png)

添加完成后状态如下

![](img/zhuanqian_a07f41554974d0ce9a05517618827bf7.png)

进入 ACTIONS 标签页，点击绿色按钮，选择测试模式 true，然后点 RUN WORKFLOWS，这是试跑；若要正式每日推送就选 false

![](img/zhuanqian_a483800818d3fb34937e73600c64bc76.png)

点击 Run workflow 开始测试

![](img/zhuanqian_7b69f6d03c5b1562e25e79956f6d28b8.png)

运行日志会多出一行记录。若微信绑定无误，应能收到推送。

![](img/zhuanqian_c3068bcf7fad9a2b15fe5001e7b91d4c.png)

手机端也会收到一条

![](img/zhuanqian_ba363c773bb66fb9401a1e791e9dabd7.png)

到这里，微信热榜自动推送就彻底搭好了！每天 9:00-11:00 之间，你的免费小秘书就会把榜单送到微信。
