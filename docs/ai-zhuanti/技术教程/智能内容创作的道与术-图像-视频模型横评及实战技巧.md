# 智能内容创作的道与术：图像/视频模型横评及实战技巧
# 开场话
各位好，我是来自龙哥盟的Gary曹淦，目前担任YouTube深海圈总教练。
“工欲善其事，必先利其器”，这句话放在智能内容创作上再合适不过。
带深海圈的过程中，我发现一个很典型的毛病：很多伙伴做视频有“路径依赖”。教程里写了用什么工具、填什么指令，他就照着能跑通；可一旦换了脚本、角色或题材，流程就卡壳。本质原因，是没有真正理解工具的能力边界。
对智能内容创作者来说，模型系统就是自己的双手。它们迭代极快，基本上是每月一个大版本，这其实是件大好事——模型能力有多强，我们就能飞多高。不管做YouTube还是其他平台，不管做的是哪种视频，持续跟踪AI工具的更新、摸清它们擅长什么不擅长什么，才能跟上内容迭代的节奏。
翻看了社区里此前的帖子，似乎一直缺少一篇系统讲工具+技巧的内容。所以这篇分享以5月图像/视频模型的能力对比为起点，带大家审视不同模型的产品特性与能力边界，并把AI视频制作中的常用技法讲透，最终帮你建立智能内容创作最重要的底层能力之一：理解工具、善用工具。
全文分成三部分：
1. 图像/视频模型性能与功能横评——覆盖12个视频工具、8个图像工具
2. 常用工具玩法与内容创作技巧——23个AI视频实用技巧
3. 视频模型竞技场——针对YouTube常见AI题材，对各家视频模型进行实测对比

### 16 提升视频画质
视频质量优化分两条线。第一，在视频工具里直接做超清处理，部分工具支持，这也是效果最明显的。
第二，在剪辑工具里处理。以剪映为例，有几个设置能改善观感：
1. 超清画质：不一定是正向提升，需要自己看实际观感；
2. 智能调色：让画面整体更亮、更鲜艳，有利于提升观看体验；
3. 提高导出分辨率和帧率（超分、补帧）：清晰度更高的成片，能提高基础推流权重——国内部分视频平台确实是这个逻辑，油管没明确说明，但也会有一定影响。

#### 案例2：房屋不塌陷事件
![](img/zhuanqian_176e8e07d622aae3263f6a921dc59535.png)
![](img/zhuanqian_c4381e52f9b2012a0f3e3b1bc624ed5d.png)
一只金毛狗站在路边，视线落在远处那栋木头房子上。房子年久失修，突然轰隆一声整个崩解，屋顶塌陷，木屑灰尘腾起，周边的树也被压断，房梁、窗框碎得七零八落，残砖碎瓦混着沙土一路翻落到公路路面，氛围宛如灾难片。
这是经过拆解后的 Prompt 写法。像“房屋坍塌”这种太笼统的短语往往带不动画面，可以把一个整体动作切成若干更小的动作片段，例如“年久失修”“轰然崩解”“房梁窗框碎裂”“残料裹着尘沙滚上公路”。

如果画面里出现了你不希望有的东西，那就干脆别在 Prompt 里提它。
AI 生成视频时，实际上是去提取关键词来理解指令。“另一只手始终空着不拿任何物品”这句话基本无效，AI 反而会把它理解成“手里拿着某样东西”；“拿着酒瓶喝酒”也是废话，因为手上本来就有酒瓶，这句甚至会让 AI 误以为“现有瓶子不算数，需要再生成一个瓶子”。
所以每一句 Prompt 都要有它存在的意义：
*   老人举手【动作前置，让画面产生变化趋势】
*   仰头喝酒【核心动作】
*   变成青年【关键变化，引导主体转换】
*   强化变身【放大转变幅度】
*   镜头旋转【运镜指令，增加画面动态】
*   动效画面【整体强化动态观感】

几条基础规律
Prompt 文化博大精深，我并没有资格讲什么高深理论，但实践下来有几条很朴素的规则，能显著提高出片效率：
1. 图片走向要和成片走向一致：无论用首尾帧或单图生成，画面素材始终是最关键的一环。图选对了，后面省一半力气。想做“走路/走秀”效果，素材最好就是迈步或至少站立的姿态；拿一张舞蹈姿势的图去生成走秀视频，大概率翻车，因为画面趋势与生成目标是拧着的。小鹿案例也一样，原图已包含两台车，“走向汽车”就成了没有明确指向的描述。因此选图时要把干扰项排除掉，找到合适的主体姿态。
2. 利用画面惯性：做首尾帧时，“惯性”效应很明显。如果首尾两张图变化幅度过小或过大，转场容易生硬，甚至像PPT切换。此时要给出能牵动画面变化的指令，例如“镜头拉远/拉近”“环绕运镜”“镜头左右平移”，以及能点爆动作的“女生抬手化成蒲公英”。画面一旦有了变化趋势，就不容易卡死成静帧。
3. 取其精华，去掉冗余：生成画面时，确保每一句、每一个词都有用途，不要出现“虽然但是”这类连接词。如果一个复杂动作没法用短指令说清，可以参考第二个场景的做法，把大动作拆成多个小动作，而不是堆砌多余细节。
4. 直接写结果，并把结果写具体：参考第一个和第三个场景，不要写“我不想要什么”，而是直接写“我要什么”。想表达“两个主体往反方向走”或距离远近时，可以把抽象关系具象化，比如把“远/近”写成“大/小”。
5. 图质决定画质：最终视频不够清晰时，先回去提高素材图片的分辨率。即梦能一键超清，MJ 也有画质增强功能，图片像素上去了，视频解析度才能跟着上去。

##### 复杂场景交互
最近我做了几轮 AI 视频模型的横向实测，把几个热门的生成工具摆在一起，同一段描述让它们去跑，看看谁更靠谱。测试并非图好看，而是盯着动作能不能完整、主体稳不稳、自然不自然以及细节是否到位。
第一组是基础场景的完成度。画面设定在一个田野边的洞口，一只宝宝在洞边挣扎，双手紧抓洞沿想要爬出，结果一松手直接掉进深不见底的洞里，镜头随后缓缓上摇收在洞口。这一段主要看动作完成度和主体稳定性。从结果看，智谱、Runway、可灵1.6 的表现更稳，而可灵2.0、Pixverse、即梦3.0 则在细节延续上更具优势。
第二组进入简单场景交互。素材是头大象用鼻子使劲吸水，情绪显得焦急，画面里还带点镜头晃动感。这段考核的是动作的自然流畅度、指令的遵循度以及细节真实感。即梦3.0、可灵2.0、可灵1.6、Runway 在整体节奏上更贴合设定，Veo2、Vidu、Pixverse 则在真实质感上各有亮点。
第三组提升到复杂主体动作。大象用长鼻喷水给干枯的田地浇灌，旁边围观的人群情不自禁鼓掌。考核点覆盖更广，动作完成度、主体稳定性、动作自然度、指令遵循度以及细节效果都要兼顾。即梦3.0、可灵2.0、可灵1.6、Runway 在动作闭环上更完整，Veo2、Vidu、Pixverse 甚至 Runway 也能在特定瞬间呈现不错的细节表现。
第四组是人物与特效结合的镜头。美丽的女生站在灯光闪耀的舞台上，手心的蝴蝶像施了魔法一样逐渐变成真实的蝴蝶，振动翅膀飞起围绕她旋转，女生自然抬眸凝视，镜头也微微拉远。可灵2.0、Vidu Q1、Veo2 在人物灵动性与主体稳定性上更突出，Runway、可灵1.6、Pixverse、即梦在指令还原上也有可圈可点之处。
第五组是比较夸张的拟人化创意。香蕉人双手撑在单杠上，表情痛苦地从双腿之间排出大量香蕉片，伴随黄色气体与液体一同落下。参考图提示是皮克斯风格的拟人香蕉，双脚抬起，从腿间掉落香蕉片，背景是厨房，镜头特写对准空中的香蕉人。即梦3.0、可灵1.6、Pixverse、Vidu 在这种奇葩创意上完成度相对较高。
彩蛋环节我也试了 Veo3。上线后为了深度体验它的能力，我模仿野兽先生的真人秀拍了一条片子，大家可以在下面链接感受一下，原视频链接：https://mp.weixin.qq.com/s/_nE-HdbWkKwumxW3d2ZONA。脚本是我写的底稿，用 Gemini 做了些优化，视频生成用的是 Flow，但没用新出的 Scene Builder 类似 Sora 的分镜功能，因为当时存在 Bug，很容易生成没声音的视频。所以所有片段都靠文生视频去拼一致性，导致人物会出现时不时变脸、风格漂移的问题。
即便一致性不算完美，这条视频也基本还原了我大部分的想象。要在 Veo3 之前做出同样效果，过去绝对是难以想象的工作量，现在我只花了一个下午，大部分时间都在抽卡和等待。
