# 拆解逻辑是什么

## 核心思路是 JTBD 用户任务理论 + 第一性原理

JTBD = Jobs To Be Done

![](img/zhuanqian_d81dbd61a3dac2b23d02e2ccdb1856b2.png)

https://hbr.org/2016/09/know-your-customers-jobs-to-be-done?ref=blog.helpdocs.io

## 具体会从哪些角度切开

*   核心用户画像，既要看买方视角也要看卖方视角

*   需求本源，多深挖需求背后的真实动机与关键洞察

*   异常点

*   机会点拆解

*   一句话收敛，分别总结消费者侧与生产者侧
