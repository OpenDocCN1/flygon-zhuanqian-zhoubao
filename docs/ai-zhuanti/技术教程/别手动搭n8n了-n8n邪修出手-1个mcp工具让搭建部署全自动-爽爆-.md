# 别手动搭n8n了，n8n邪修出手，1个mcp工具让搭建部署全自动，爽爆！

别再手动搭 n8n 了！这个“邪修”MCP 工具，能让 AI 帮你从零到一全自动部署工作流

兄弟们，最近我在折腾 n8n 的时候突然想明白一件事：n8n 里的工作流和各类配置，底层其实全是 JSON 数据。这也就意味着，AI 处理起来会特别顺手。只要我们能给它足够的节点资料和数据流转规则，以现在 AI 的编程能力，完全有可能直接替我们把工作流写出来。可问题是，n8n 的节点数量实在太吓人，想把这些东西整理清楚，光想想就头大。

结果我正翻工作流教程的时候发现，居然已经有人把这条路提前蹚通了。这个项目叫 n8n-mcp。

它做的事情很简单：把 n8n 的使用文档，以及 500 多个节点信息，全部打包成 MCP 工具集，并通过规则适配让 AI 可以直接调用。AI 接到你的任务后，会自己去查文档、理解节点用法，然后直接编写工作流 JSON 文件，最后还能通过 n8n 的 API 自动部署到你的服务上。全程你几乎不需要动手，n8n 都不用打开。

下面我就手把手带大家跑一遍这个“邪修”流程。

第一步，先找到 MCP 的安装位置。

理论上，凡是支持 MCP 的客户端都能用，但我个人试下来，还是放进 AI 编程工具里效果最香。这里我用 TRAE 做演示，其他工具也差不多。打开 TRAE，先进到 Builder。

![](img/zhuanqian_5e3f144983f6e21106c433ca4c3c1f7e.png)

然后把模式切到 MCP。

![](img/zhuanqian_3cc37709d26c3cff9f6ea2bdefe739b3.png)

接着找到工具配置入口，点击“添加更多工具”。

![](img/zhuanqian_d4e669f369c4cff7180de0b942b4eaf1.png)

在弹出来的界面里，选择“手动添加”。

![](img/zhuanqian_d304f2b0939ef278f12f7d4942fcb82c.png)

第二步，去拿 MCP 配置代码。

打开 n8n-mcp 的 GitHub 地址：https://github.com/czlonkowski/n8n-mcp，在里面找到安装代码。

![](img/zhuanqian_c8803ad27b4c8fb61d5437dd8d8260ee.png)

这里有两点需要按你自己的环境来改：一个是 n8n 的云端地址，也就是你自己部署的 n8n 访问地址；另一个是 API Key。顺便说一句，如果这两个参数不想配置也可以，但那样的话，最后就需要手动导入工作流文件了。

![](img/zhuanqian_ba07f218bcbf6df720779c8e8f10d6bc.png)

第三步，生成 API Key。

进入你的 n8n，在左下角找到“设置”。

![](img/zhuanqian_44846356f73d73fc7b5feca90919f5d1.png)

进去之后找到“n8n API”，然后点击创建 API Key。

![](img/zhuanqian_5a26b6a1b14717aa8ad1d8772f0fc6a1.png)

名称随便填一下，点创建，再把生成的秘钥复制出来，替换掉前面配置里的 apikey。

![](img/zhuanqian_c53ace8c5c544b43bc206d49605940ee.png)

第四步，正式安装 MCP。

回到编程工具里，把替换好的完整配置粘贴进去，点击确认，就会开始安装。

![](img/zhuanqian_1ae0441660433ff8fc165b5b26eeab56.png)

等一小会儿，看到 n8n-mcp 前面变成了打勾状态，就说明安装成功了。

![](img/zhuanqian_7c0b2c793f251eb1342956690b5809b1.png)

第五步，建立项目规则。

现在的 AI 编程工具基本都有规则提示词功能。找到“规则”，然后新建一个项目规则。

![](img/zhuanqian_5fda4e6c0fda742f05db7d17b248ed7b.png)

再次打开那个 GitHub 项目，找到 Claude Project Setup，这就是写好的项目规则提示词，直接复制。

![](img/zhuanqian_14c3cbcb7fe24766f46868ea44f84adf.png)

回到刚才新建的规则文件里，粘贴进去，保存一下。

![](img/zhuanqian_25c359c400fdb492e916e98b58aa31c6.png)

第六步，开始“邪修式”开发。

我给自己安排的任务很简单：让它写一个工作流，用来抓取头条热榜数据，最后保存到 Excel 里。你看它动作很熟练，会主动调用工具去查 n8n 文档和节点能力，再挑选合适的节点来搭建工作流。

![](img/zhuanqian_f41af0cf53d3952f1c31788422168e3d.png)

整个过程相当顺利。唯一的小插曲是，第一遍它没有直接把工作流部署到我的 n8n，我就在提示词里重点强调了一下，它立刻调用工具去部署，最后返回了一个工作流 ID，看到这个就知道成了。

![](img/zhuanqian_61f1d76d513ed07064e7b67dec527068.png)

第七步，去看看生成的工作流。

回到 n8n 页面，果然多了一个全新的工作流。

![](img/zhuanqian_e1522c9757755a0d81223740283de339.png)

点进去检查一下，节点连得挺完整。不过我第一次试运行是失败的，因为我给的那个网站是动态加载数据，普通抓取搞不定，需要模拟浏览器之类的操作，所以最终拿到的是空数据。

![](img/zhuanqian_b90f67af19ab554f8c863ffd3119e4db.png)

第八步，它甚至还能直接帮你改。

我又换了一个简单的网站，让它把原来的抓取地址换掉。它直接借助工具，在我现成的工作流上完成了修改，全程不让我插手。

![](img/zhuanqian_5402271b37e49f2bde5b62e61488d19e.png)

再次点开工作流，发现它不仅改了功能，连名字都帮我想好了。我按一下执行，运行成功！哈哈，这“邪修”功法算是练成了。

不过我也留意到，它抓回来的数据有一些小瑕疵：多个标题和多个链接粘在了一起，被当成了一条内容。这个我觉得挺正常，想让 AI 每一步都抠得那么细，确实有点难，但通过加强提示词基本可以解决。关键是大流程完全能跑通。我只测试了一两遍，不敢说一定有普适性，各位感兴趣的道友，可以亲自上手试试。

![](img/zhuanqian_327f73cf99a2308fa9ac868e388a48e4.png)
