# 看到 X 会员能屏蔽广告，我直接放弃了续费
作者：龙哥

作者：龙哥

日期：2025-07-22

前两天我提到自己用 AI 搭了个小工具，专门用来从信息流里淘金。底下就有朋友提醒我，其实可以直接开 X 的会员，里面就有类似的情报筛选权益。

我点进去查了一下，顿时明白了。当我发现会员的最大卖点之一就是「去广告」时，我当场就把开通的念头掐掉了。

对我来说，上 X 的核心诉求之一，就是看广告。

广告不是干扰，是最直白的情报板。谁在投放、投什么、怎么讲、砸多少钱，这些信息比正文还值钱。去广告，等于主动把情报源关掉。

评论区里大家反应也很有意思：

骁山：哈哈，别人去广告你反而要广告？

馆主：太对了。无论是微信朋友圈、知乎还是小红书的广告，我都当情报源在看。资本的投放方向，从来不会错。

张热烈啊：这就是反向操作了。

大海：大佬的思路确实和我们不一样。

戴忻：又被上了一课。

茹：想请教一下，您具体是怎么从广告里提炼情报的？有什么观看思路吗？

搞钱萌新：这脑回路绝了。

所以结论很简单：对我而言，广告本身就是内容。
