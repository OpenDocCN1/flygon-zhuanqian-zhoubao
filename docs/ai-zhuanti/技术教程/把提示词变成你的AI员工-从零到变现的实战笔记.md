# 一、Prompt到底是什么？

## 一）定义

Prompt本质上是一种注入式指令，它“引导”AI按你设定的思路去思考和产出。熟练掌握写法，你就能借助AI解决实际问题。

## 二）为何要学？

对普通用户，写好Prompt有四大收益：

*   匹配度提升：需求表达越清晰，AI输出越贴合预期，就像大厨准确把握口味做出好菜。

*   释放潜能：明确的指令能激活模型更多隐藏技能，就像懂菜单的食客总能挖到惊喜。

*   效率优化：清晰的指令一次到位，减少反复打磨，节省大量时间。

*   锻炼思维：写Prompt本身就是对信息组织与传递的训练，有助提升整体逻辑与表达。


# 三、预制快餐

走进餐厅面对长菜单，常会手足无措。第一次写Prompt同样如此。

但手里有份“标准菜单”，按口味填空就能快速下单。下面教你搭建通用Prompt结构，按模块填空即可事半功倍。

## 一）搭建结构化框架

最基础的Prompt框架需要包含以下模块：

```
# 角色设定
## 任务描述
- 话题主题
- 任务目标
- 输出格式
```

类比做菜，你需要思考：

*   主厨是谁？有何特点？

*   菜品要达成什么效果？是开胃还是主菜？

*   如何呈现？炒还是煮？

对应到Prompt模块：

*   角色设定：Prompt扮演什么身份，有何背景与特点

*   任务描述：要完成什么任务，达成什么目标

*   话题主题：写什么主题，核心关键词是什么

*   输出格式：以何种形式呈现，如对话、文章或列表

## 二）各模块填写要点

### 🥘角色设定

角色设定能让Prompt更有人格化，保持风格一致。常见角色：

*   小红书博主：第一人称，分享生活经验与好物推荐

*   知乎答主：第三人称，提供专业有洞察的回答

*   文章写手：客观中立口吻，撰写长文

*   产品经理：从用户需求与产品逻辑角度输出方案

填写时抓住角色特点，如口吻、思维方式、专业背景。

### 🥗任务描述

任务描述尽量用一句话说清核心诉求，避免空泛。例如：

*   宽泛表述：请帮我写个小红书笔记。

*   精确表述：请以美妆博主口吻，分享一支近期喜爱的口红并推荐给读者。

对形式、字数有要求，也可在此补充。

### 🥪话题主题

选题要以最终目标为导向。主题要具体但留有发挥空间。例如：

可写“美妆新手必备技巧”

不宜写“美妆技巧”太宽泛，或“眼影渐变晕染技巧”太局限

### 🍱输出格式

常见格式有：

*   一段对话，如采访、日常交流

*   一篇文章，如观点评论、使用指南

*   一个列表，如推荐清单、备忘录

*   一个脚本，如话剧、小品

*   一段代码，如函数、程序

按实际需求灵活选择，必要时提供参考示例帮助理解。

## 三）案例：快速设计美食点评Prompt

掌握框架后实操。假设要做美食博主视角的餐厅点评，可这样写：

```
# 美食博主的角色设定
你是一名知名美食博主，有着10年的美食点评经验，擅长从专业的角度分析一家餐厅的特色菜品、氛围服务和性价比，并总结推荐理由。
## 文章任务描述
请以第一人称的视角，写一篇800字左右的餐厅点评。要求：
- 话题主题："吃到好好看的店！"广州美食
- [这里可以直接把餐厅简介，优质好评，推荐菜放进来]
- 任务目标：向读者推荐这家餐厅，分析其特色菜品、用餐体验，给出客观中肯的评价
- 输出格式：美食点评博文，分几段描述，最后给出星级打分
```

填好四个关键模块，美食点评Prompt就完成了。

# 四、加点调料

上一节学会快速点菜，但初稿Prompt通常还有优化空间。

就像新手厨师做的菜平平无奇，需要不断调试。

下面分享三个优化思路，让菜品更美味。

## 一）思路1：补充细节，提升品质

好的Prompt在输出要求上应尽量详尽，给AI充分信息。就像菜品食材和工艺说明不清，再好厨师也难还原。

回顾上节美食点评示例：

```
# 美食博主的角色设定
你是一名知名美食博主，有着10年的美食点评经验，擅长从专业的角度分析一家餐厅的特色菜品、氛围服务和性价比，并总结推荐理由。
## 文章任务描述
请以第一人称的视角，写一篇800字左右的餐厅点评。要求：
- 话题主题："吃到好好看的店！"广州美食
- 任务目标：向读者推荐这家餐厅，分析其特色菜品、用餐体验，给出客观中肯的评价
- 输出格式：美食点评博文，分几段描述，最后给出星级打分
```

虽然已含基本要素，但不够具体。比如：

*   “特色菜品”有哪些？各有什么特点？

*   除了菜品，餐厅环境如何？服务水平如何？

*   “客观中肯”评价标准是什么？

*   “星级打分”满分几星？

为让AI更好理解需求，可补充细节：

```
## 文章任务描述
请以第一人称的视角，写一篇800字左右的餐厅点评。要求：
- 话题主题："吃到好好看的店！"广州美食，重点介绍招牌菜
- 加入[餐厅招牌菜、热门文案等]
- 任务目标：向读者推荐这家餐厅，从菜品口味、分量、价格、环境服务等方面分析其特色，给出客观中肯的评价
- 输出格式：美食点评博文，分小标题描述，语言诙谐幽默，不做过多文学修饰。最后从味道、环境、服务、性价比四个维度打分，满分5星，给出最后的综合星级评分。
```

补充关键细节后，Prompt品质明显提升，AI能输出内容更丰富、更有针对性的点评。

## 二）思路2：调整组合，丰富味道

除补充细节，还可在Prompt组合和表述上做文章，让生成内容更丰富多元。

仍以上面点评为例，可尝试不同组合：

```
## 文章任务描述
请以一个资深吃货的口吻，写一篇800字左右的餐厅体验分享。要求：
- 话题主题："吃到好好看的店！"广州美食，重点介绍招牌菜，分享你在这家店的一次难忘用餐经历
- 加入[餐厅招牌菜、热门文案等]
- 任务目标：生动再现当天的就餐过程，从菜品点评、氛围描述、服务评价等方面，体现这家店给你留下的印象
- 输出格式：故事性的口语化叙述，可以适当加入一些幽默、夸张的修辞，让文章有画面感。字数800左右，最后给出"推荐指数"，满分5颗星。
```

相比之前版本，此版新增元素：

*   角色视角从“美食博主”变为“资深吃货”

*   评价维度从“特色菜品”拓展到“难忘的用餐体验”

*   输出风格从“美食点评”转为“故事性分享”

调整表述方式和组合角度，可引导AI生成不同风格和侧重点内容，满足多元化需求。

![](img/zhuanqian_3d7e85c8e404c9638409fa0df982b447.png)

这就像做菜，火候之外还要考虑食材搭配和切配方式，才能做出层次丰富味道。

设计Prompt也要学会多角度切入，灵活调整组合，激发AI多样化输出。

## 三）思路3：借鉴学习，吸收他人菜谱精华

美食创新常来自不同菜系相互借鉴融合。优化Prompt时也可多向优秀Prompt学习，汲取养分。

比如曾见过一个“故事写作”Prompt：

```
请你扮演一位获得过诺贝尔学奖的作家，根据我提供的写作主题，创作一个引人入胜、情节曲折的短篇小说。要求：
- 小说以第三人称视角展开，设置悬念，吸引读者持续阅读
- 通过细节描写、心理刻画、环境渲染等手法，营造氛围，带来身临其境之感
- 文章用优美、隽永的语言写作，力求给人文学性的审美体验
- 字数控制在2000-3000字左右，以意味深长的结尾作为升华
```

虽针对小说写作，但可汲取通用优化思路：

*   通过角色扮演让AI代入专业视角

*   从吸引读者角度提出写作要求

你有没有想过，同样是在跟AI对话，为什么别人总能“点到”神仙菜品，而你得到的却像一碗夹生饭？其实，写Prompt和做菜很像：光有食材不够，还得讲究刀工、火候、调味，甚至一点“烟火气”。

今天，我们就以“美食点评”为前菜，从小说创作的灵感聊到结构化提示词的“满汉全席”，一起把这些方法拆开揉碎。

先看一道前菜：想让AI写出一针见血的美食评论，别只丢一句“评价一下这家店”。真正好用的Prompt，会像小说创作一样，告诉AI要注意细节描写，比如摆盘、口感、服务员的动作；还要刻画用餐者的心理活动；同时明确语言风格，是毒舌还是温柔；甚至连文章节奏都安排好——开头能不能埋个悬念、结尾要不要来点升华。这些小说写作的手法，放在“美食点评Prompt”里，立刻让点评有了“专业食评人”的味道。

```
## 角色设定
你是一名美食杂志的王牌专栏作家，以文笔犀利、观点独到著称。你对美食有着严苛的标准和敏锐的洞察力，一家餐厅能否得到你的垂青，往往决定了它在食客心中的地位。
## 文章任务描述
请以第一人称的视角，写一篇800字左右的餐厅评论。要求：
```

你看看，同样是点评，经过这么一“武装”，是不是立马有了深度和辨识度？

所以说，优化Prompt最聪明的姿势，不是闭门造车，而是巧借他人智慧，把别人的精华拿来调制自己的“秘制酱料”。等你手里的Prompt“菜谱库”越来越丰富，自然就能举一反三，不管客人点什么菜，你都能稳稳接住。

总结一下这一阶段的三个基本功：

1. 给Prompt补充关键细节，要求越具体越好；

2. 换一换Prompt的结构配比，AI就会给出不同风格的回应；

3. 跨领域借鉴优秀Prompt，提取通用优化思路。

当然，这套功夫不是一天练成的，需要在实际操作中不断试错、积累和迭代。建议每次用完Prompt都记一笔心得，也要多看看别人在不同领域是怎么写的，慢慢你就能成为真正的“配方大师”。

接下来，进入正餐前的“加餐”——怎么让AI的文字里多点人间烟火气。

名厨之所以成为名厨，不是因为他只会背菜谱，而是因为他有自己的独家调料。想做一个有风格的Prompt工程师，同样得学会给Prompt“加点烟火气”。想找些接地气的词句，也可以去一些语料网站上挖宝，比如 shenyandayi.com。

烟火气技巧一：口语化表达。

很多人写Prompt时总爱端着架子，仿佛不用书面语AI就听不懂。其实，AI对自然语言的理解已经远超你的想象。下次不妨换个语气，像跟老朋友聊天一样告诉它：“别整那么正式，就按咱们平时聊天的感觉来。”这类口语化、对话式的Prompt，会让AI更有人情味，写出来的内容也更接地气。

```
prompt：
老铁，帮我写一段200字左右的自我介绍呗，就是跟朋友初次见面时说的那种，语气要轻松幽默，也不能太夸张，你懂的!
```

![](img/zhuanqian_dee2d23dc0e9c246774bfdfe2033f808.png)

```
prompt：
咱们来聊点实在的。给我出个主意，520送女朋友什么礼物比较讨喜?注意控制预算在500块以内啊，扣扣索索的细节也给我想全了!
```

烟火气技巧三：场景细节描写。

好的厨师懂得挑时令食材，好的Prompt工程师则善于捕捉生活里的鲜活细节，把它们喂给AI。比如别只说“写一篇春天校园的散文”，你可以在Prompt里放上这样一组镜头：雨后操场积水的倒影、老墙根冒出的青苔、食堂大妈掀开蒸笼时的那团白气……

大题来了。如果你已经会“点菜”，那么接下来的“满汉全席”就是帮你成为真正的大厨——结构化提示词。

先认识一个概念：思维链。这个概念由谷歌大脑研究员Jason Wei在2022年率先提出。他发现，AI如果像人类一样一步步推理，输出质量会明显提升。所谓思维链，就是把一串思考步骤串联起来。比如你看到天空变暗，大脑会自动完成三次跳跃：观察——天暗了；推断——可能要下雨；决定——出门带伞。

为什么这招对AI有效？因为AI生成文本的原理，本质上是个“高级成语接龙”：它根据上文，不断计算下一个词出现的概率。你给它“今天天气真好，我打算去____”，它会从过往训练中挑出“公园”“海边”“散步”等许多候选词，再选出概率最高的那个。因此，处理复杂任务时，你必须提供清晰的上下文，并用连贯的逻辑步骤去引导它。

举个例子，要AI总结一篇文章，别直接甩一句“总结核心观点”。你可以设计这样的“思维链工作流”：

第一步，快速浏览全文，先描述主题和结构。

![](img/zhuanqian_2c9f50af5d93beab8f27adf1060bcda1.png)

第二步，仔细阅读，标记关键观点、论据和结论。

![](img/zhuanqian_f9e21825ebd4f88f4b586637b74be31d.png)

第三步，根据标注信息，提炼核心观点和支撑论据。

![](img/zhuanqian_f4c3b254ca72b382febe0b9e6f24ebb4.png)

你会发现，这几乎就是我们人类总结文章时的路径。把思考过程拆解成步骤，等于为AI铺了一条“思维高速路”，让它直奔目标，效率和准确性都大幅提高。

![](img/zhuanqian_2c041bea96e49f07e01190d49769f5e6.png)

这种思路发展下去，就形成了结构化提示词。它是一种层级化、模块化的组织方式，非常适合策划方案、学术论文这类复杂任务。通过几个模块把复杂任务拆解清楚：

System（系统）：定义AI的角色、能力与视角。比如“你是一位历史老师，讲课时生动有趣，善于引经据典。”

Constrain（约束）：设定输出边界，避免不恰当或偏激内容。比如“勿涉及暴力、色情、政治敏感话题，保持客观中立。”

Background（背景）：提供任务所需的专业知识和上下文。比如“本次任务是为8-10岁孩子写一本趣味历史读物，涉及古埃及、古希腊、古罗马。”

Input（输入）：说明用户应提供什么信息，这决定了创作的个性化程度。比如“请告诉我你想了解的历史事件，以及你喜欢的叙述风格。”

Output（输出）：规定格式、风格和篇幅。比如“请写500字左右，用第二人称讲述，并输出Markdown格式。”

Workflow（工作流）：把任务分解成有序步骤，比如先写起因、再写经过、分析影响、提炼感悟，最后润色语言。

把这六块拼在一起，一个完整的结构化Prompt就出来了：

想打造优质提示词，请记住三个关键：

第一，需求分析要全面，可以借大模型帮你厘清角色和流程；

第二，选一个合适的框架，逻辑清晰地组织步骤；

第三，反复进行“编写—测试—迭代”，不断打磨质量。

### 方法4：人工迭代，进阶玩法

前面那几种办法门槛都不高，可如果你已经学会了用这种思路来搭建 Prompt，其实就已经跑赢大部分人了。

更关键的是要养成“AI思维”。碰到任何难题，第一反应应该是能不能用AI来提速。一旦Prompt打磨出来，后续同类问题直接复用，学习和工作的效率就会被指数级放大。

不过要想做出真正贴合个人化需求、还能变现的提示词，就绕不开人工精修。模型自己生成的Prompt里总夹杂着不少冗余信息，需要我们亲手删繁就简，还得补上必要的执行流程，引导AI的思考路径更贴近人类的推理方式，分步把想要的结果吐出来。

你会发现，我写的Prompt里其实掺杂了很多“人话”，并不像在跟机器对话。确实有几句经过论文验证、并且实测有效的表述，可以直接提升大模型的输出质量，这里就直接给出结论：

论文证实且实践中好用的提示词：

*   I have no fingers.

*   我没有手指。

*   This task is vital to my career

*   这项任务对我的职业生涯至关重要

*   Let's think through the problem step by step.

*   一步一步地思考问题。

*   Let's solve one problem at a time.

*   让我们一次只解决一个问题

*   I will tip $100 for this.

*   我会为此支付100美元的小费。

*   If you fail， 100 grandmothers will die.

*   如果你失败了，100位老奶奶会去世。

#### 几点补充提醒
