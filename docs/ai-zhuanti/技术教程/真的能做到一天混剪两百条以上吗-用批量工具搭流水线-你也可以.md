# 前言
各位伙伴大家好，我是山川，这是我在社群的初次分享，还请多指点。
现阶段做单人全链路电商，大家或多或少都有说不出的难处，无论是店铺打理还是内容产出，都得不断精进。可最费神的，往往是那些看似简单却要反复做的琐碎操作。单兵作战说得热血，实操起来却容易力不从心。

2、思路说明
先理清逻辑：新视频是基于脚本拆解来生成的。在剪映里，需要把画面对应上脚本，才能形成新的混剪。但替换时会遇到时长不匹配的问题，例如商品展示位需要5秒素材，而你切出来的只有2秒或3秒，这时可以对素材做减速/加速处理后再替换，也可以把多个素材拼接后替换，剪映里替换素材时长必须大于等于被替换的草稿素材时长，否则无法替换。
因此，脚本中每个画面位都必须准备好可替换的素材。以第三步拆解为例：爆款前3s-人物讲解-商品介绍（外观展示+功能使用展示+价格优势说明）-引导下单。分类阶段已把对应片段整理好，下一步要做的是把片段拼接，让其时长达到可替换标准。
以AImiix做拼接为例，商品介绍整体约15秒，外观5秒、功能5秒、价格5秒，则先把每个子画面合成到5秒左右，必要时可加一层低音量配音合成，不影响后续替换与导出。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_c3e8058a96f48f57cb6d3aad406a6f17.png>
