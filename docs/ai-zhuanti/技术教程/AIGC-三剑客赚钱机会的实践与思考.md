# AIGC 三剑客赚钱机会的实践与思考
我是龙哥，最近一直泡在AIGC里，越玩越觉得这里面的机会比想象中要大。今天就把我这些天实操下来的心得、踩过的坑，还有解决问题的一些思路，一次性打包分享出来，希望能给正在观望的朋友一点启发。
先给不熟的朋友简单科普一下，AIGC这个听起来有点技术的词，全称是“AI generated content”，也就是生成式AI，简单来说，就是让人工智能直接帮你产生内容。比如说，让AI帮你续写一篇文章、照着一段文字生成一张图，或者让虚拟主持人代替真人出镜播报，这些都跑不出AIGC的范围。
现在圈子里最火的，就是这三样“技术活”：
第一样，ChatGPT。它专攻文字内容，文案、对话、构思、改写，几乎什么文字活儿都能搭把手。
第二样，AI绘画。主要代表是Midjourney和Stable Diffusion，你负责描述画面，AI负责画出来，效率惊人。
第三样，AI数字人。最近很多人拿它开直播、剪短视频，画面里看着是真人主播，背后其实也是AIGC在驱动。
这三块，也被大家叫作“AIGC三剑客”，是我觉得普通人目前最好切入的赚钱方向。我把更完整的操作细节、避坑心得和可复用的方法，写成了一篇3900字的实战长文，放在飞书文档里，想深入了解的朋友可以直接点进去看。
另外，我往期也整理过不少干货，像花三年搜集的4000G运营工具箱、啃完一万篇技术赚钱文章提炼出的实践指南、每天稳定新增150+好友的私域引流技巧等等，都在我以前的内容里，感兴趣的朋友可以去翻翻合集。
这一波AIGC浪潮，才刚刚拉开序幕。希望这篇复盘能帮你找到适合自己的切入点，早点把钱赚到手。有问题欢迎随时在评论区交流，我看到都会回。
