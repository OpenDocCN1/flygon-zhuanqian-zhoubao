# 为什么听完课产品没动静，一见面就起飞了？
## 为什么买了刘小排老师深海圈的课程之后产品起飞不了，但是去北京见了他之后产品马上就起飞了？
作者： 龙哥
日期：2025-09-29
# 开场
“小排老师是不是偷偷让朋友买他的学员产品？要不然怎么六六去北京回来就爆了，DHJ 去北京回来也爆了？”
赚钱群里有伙伴这么问我。
我回他：“你知道我那款产品是怎么样冷启动的吗？”
# 先说我是谁
大家好，我是北京 SCAI 实验室的西约，也有人叫我西西。刘小排老师《海外 AI 产品》第一期课程的学员。课程里我做出了人生第一款 AI 产品：adacpp.com。
为了方便理解，先简单介绍一下我的产品。

# 冷启动根本不在大众平台
我说：“你也知道我的产品门槛不低。核心用户是程序员从业者，或者想成为程序员的人。最边缘的也是家里不懂编程但想让孩子学 C++ 拿竞赛加分的家长。所以我哪能去 Product Hub 那种大众冷启动地丢链接，根本没人看。门槛高的东西必须去垂直场去做首发。”
我说：“小排老师直接给我指了一条路：阮一峰的公众号。我知道阮一峰，也知道公众号底部有自荐入口，但我一直没点进去。是小排老师点醒我，把所有线索串起来了。”
我说：“他让我去阮一峰的 GitHub 项目里投一篇自荐文，被选上就能上每周五的推荐，拿到一波精准流量。他还强调文章里要把痛点写死，放录屏，一眼就能看懂在干嘛。”
我说：“我周三熬夜写完投出去，刷新 GitHub 看到被选中，立马截图发给小排老师。心放下一秒又悬起来，琢磨阮一峰什么时候发、我的 adacpp 接不接得住。结果当天就来了几千 UV，后来还同步到 Twitter 上，每天稳定三百多 UV，我就觉得冷启动成了。”
文章到现在还在阮一峰的 GitHub 上，有兴趣可以自己去翻。
我说：“我就是这么起来的。”
我说：“再看兔老师的 citely.ai，小排老师完全没让她去阮一峰，而是让她冲比赛。因为产品调性高，比赛更能聚到大学生目光。还让她上大树的访谈，话题性一下就炸了，那篇采访直接万赞万藏。”
我说：“六六的《我在》其实最初在小红书拿到了第一批内测用户，小排老师却坚持让她转公众号。原因很简单，小红书天花板低，而且她做的是小程序，公众号文章打开小程序是天生绝配，转场丝滑。”
我说：“DHJ 的 evolink.ai 瞄准的是开发者，小排老师就让他们去开发者最扎堆的地方首发。”
我说：“你看，小排老师都是按产品特性给每个人配最短路径。看起来他秒回，其实是他太懂了，答案早就想清楚了。他这人就是喜欢默默帮人。”
我说：“他们去北京就起飞，不是因为北京有魔力，是因为见面才敢开口问。微信上不好意思问，见了面就问了，所以见面才起飞。你在微信上直接问，也一样起飞！”
![](img/cd535fd06bb02ac1c628b48bc33513ca.png "None")
以前我一直琢磨课程里“实现最短路径”这句话，甚至怀疑是不是病句。后来相信他不会写废话，就认定有深意。现在算是悟了。
需要声明一下：上面全是我自己的理解，小排到底怎么想的，我也不知道。
# 冷启动只是结果，不是原因
按这个逻辑，有人会问：那我现在去问小排冷启动点在哪儿，是不是也能马上飞？
我不这么乐观。
我们能冷启动，是因为我们先选对了产品。而产品选对，是因为它真的解决了用户痛点，也因为我们自己就是最合适的人。
拿我来说，我以前常年刷竞赛题，写题对我有吸引力，还做过编程辅导，特别清楚学编程的人卡在哪儿。所以做一个辅助 C++学习的 IDE 对我来说是顺手的事。再加上我做了一些面向国内用户的特殊适配，投到国内科技大 V 阮一峰那里才是最合适的。
兔老师是大学教授，平时既要自己写论文又要带学生写论文，论文写作的痛点她太懂了。她的产品既是帮自己也是帮学生，所以她做论文提效工具最对路。用户画像是大学生和教授，去创业比赛这种大学生聚集地曝光，转化自然高。
六六学的是心理学，对用户感知很敏锐。她做的是语言类产品，对文字理解要求极高，只盯国内市场。用户场景是手机端，所以选了小程序。选了小程序之后，公众号推广才顺理成章。
DHJ 做的是聚合类产品，她之前就在做支付聚合，聚合的逻辑门儿清，迁移过来找到自己的最优解。
所以，最短的冷启动路径是建立在最初的产品选择之上。
而产品选择，根子上取决于你是谁，你能为用户提供什么价值。
我记得 19 年在光华听过一节课，宁德时代的早期投资人讲为什么投宁德时代。核心不是投公司，是投曾毓群这个人，因为他太适合做这件事，这件事在他手上一定能成。
这个逻辑和小排教我们选产品的思路完全一致：找到适合自己的赛道，找到真需求，才能事半功倍。
# 我是怎么找到那个能冷启动的项目的
最后分享下我花一年时间找回自己的过程，大概三步：
1. 找到你喜欢的事情
2. 找到你擅长的事情
3. 找到有价值的事情
## 找到你喜欢的事情
做 AI Web 站之前我做过几个有点成绩的小项目，每次做出成绩都不开心。朋友说我天天换新花样，不知道图啥。
我一度在“先赚钱再做喜欢的”和“做喜欢的不赚钱”之间摇摆。后来我意识到，有第三条路：做自己喜欢且有价值的事，自然会得到金钱认可。
我当时甚至说不出自己喜欢什么，不知道去哪找。我嫉妒那个追星的室友，她知道自己喜欢什么。
我一度想从书里找答案，随手打开微信读书，看到《数学的雨伞下》，记下了“数学”这个词。但我发现我太弱了拿数学变现不了，而且兴趣很快就飘到心理学、艺术、历史、地理、脑科学……
直到读到《贪婪的多巴胺》，我才明白我喜欢的其实是新鲜感，什么新鲜我就追什么。
完成了第一个小里程碑，明白了自己的兴奋来源。如果你也找不到特别的兴趣，可能和我一样，就是爱新鲜。
## 找到你擅长的事情
继续读书，看到《如何找到想做的事》，书里说 想做的事 = 喜欢的事 ✖️ 擅长的事 ✖️ 重要的事。我这一节的小标题就借用了这本书，只是把重要的事改成了有价值的事。
我按书里的方法剖析自己，把过往成绩拆出来，总结出自己做得比较顺手的 100 件小事。
一个小技巧：别妄自菲薄。只要我做的事比身边的 10 个人都好，就算擅长。
我还请了几个信任的朋友来点评，可能会有彩虹屁，但我宁可信其有。初步列完后归类融合，最终得到一份擅长清单。
巧的是，就在那会儿赚钱里出现了盖洛普测评，我做了之后，结果和我自己总结的特质几乎一致，特别踏实。
## 找到有价值的事情
了解自己还不够，还要知道做什么。价值不只是对自己，而是对别人甚至对人类。我的判断标准很粗暴：别人愿不愿意为之付费？
那去哪找呢？赚钱不就是一个项目库吗。
我打开赚钱本想一个个看，先被 AI 出海吸引住，一眼就锁定了。怕草率又把其他项目过了一遍，最后还是 AI 出海最适合我这个 I 人：接触新鲜内容，又不用太多社交。
有时候对的方向就是这样，遇到之前不知道，遇到了立刻知道。
确定做 AI 出海后，机缘巧合遇到了北京 SCAI 招募和刘小排老师开课，于是有了 adacpp.com。
# 结束语
最后想说，很开心，很开心，很开心，很开心。
很开心遇到赚钱，很开心遇到小排老师，很开心在赚钱认识大家，很开心终于和真实的自己同行。
如果你也在迷茫，希望这篇笔记能帮到你，赶快找到那个超适合自己的项目~灵感急急如律令！
