# 别再硬干了，让工具替你把自媒体跑起来
作者：龙哥

这份是我长期实操沉淀下来的提效清单，全是亲测在用的。把它们串起来用，内容采集和整理速度能直接飙升几十倍，弯道超车不是口号。

先聊视频批量获取的核心方案 —— 【江湖】。抖音、小红书、快手都能覆盖，我以小红书来拆，思路迁移过去即可。

文末会把本次涉及的资源统一放出，先看用法。

上手路径很顺：安装完毕后看一遍教学视频就能开工。

![](img/zhuanqian_a1b7ef11c45521e7d03b3e5db695a7f0.png)

进入软件后的主界面是这样的。按教程进入【浏览器】功能区，登录好小红书账号后就能自由操作了。看中哪个号，直接“捉拿”，作品就被批量抓出来了。

![](img/zhuanqian_477ac124974469347d5e6af505a8b2d5.png)

![](img/zhuanqian_c8c47e5d0d6dec8f7da19151115142c8.png)

小提示：下载配置那里选【普通下载器】就够了，速度很顺畅，没必要付费。

我平常用到的入口就这几个：【主页提取】【单作品提取】【关键词提取】，偶尔会碰到【我的主页提取】。下面就围绕这四类展开，熟手可以直接略过。

## 【主页提取】

把目标创作者的小红书链接复制到输入框，点击【开始添加主页】即可。系统会自动抓取该账号的全部作品，我有一次同时塞进10个号，一次读出上千条视频，完全不用手动，心情直接起飞，重复劳动彻底解放。

有人可能会问上千条怎么处理？当然要先过滤，我的筛选逻辑后面会讲到。

![](img/zhuanqian_e1e718367af070999680f116112db4aa.png)

## 【单作品提取】

顾名思义，就是指定若干个视频来抓。设置里可以控制单次抓取数量，为了避免触发限制，我通常一次抓10条，间隔30秒让程序歇口气。

下方这个演示是我一次抓5条的效果，列表里已全部到位。

![](img/zhuanqian_c54f0cb0f93c136ac2a95e5dc4b9fdcd.png)

## 【关键词提取】

按主题关键词在全站检索素材。比如想找治愈向素材，就输入“治愈视频”等词，点击【开始提取关键词】，程序就会自动在小红书内检索相关内容。

还能限定时间窗口，【发布开始时间】【发布截止时间】都可以设置，精准度很高。

![](img/zhuanqian_92634361d149bac723b5948f330bd7fc.png)

## 【下载&筛选作品】

### 不做过滤直接下

不管是主页抓取还是关键词抓取，成果都在【作品列表】里。不加任何条件，直接点【开始下载作品】就行。

![](img/zhuanqian_2d8e3d51ffb769d421e3502408f7e2a1.png)

### 先过滤再下载

比如我只想要万赞级别的，就在点赞量栏填入【10000】，并打开【启用筛选显示】。原本5条里可能只剩1条达标。上千条的原始池经过筛选后，往往只剩几百条高质量的，效率感明显。

![](img/zhuanqian_64fef149577efce9f29cf8ca04674e4f.png)

#### 如何限定抓取的时间区间？

![](img/zhuanqian_318d308e5295bb727930632017af57a4.png)

操作也很直观：在【主页提取】里添加作者链接后，先设定【发布开始日期】和【发布截止日期】，再执行抓取即可。

看到这里，应该能体会到以前一件件扒视频有多低效了。接下来是文案批量提取，同样是免费的。

# 2. 一次性拆解50条短视频文案

主角是通义千问

https://tongyi.aliyun.com/qianwen/ 国内可用，注册登录即可。

![](img/zhuanqian_f7f3c056fceef732820ab1c82347b0a2.png)

我现在的数据池里已经积累了245条文案。之前公司让我7天内整理100条大健康脚本，我靠江湖配合这款工具3天就交付了，不然真要干到累瘫。

![](img/zhuanqian_c0cea435b98bfbe88e9391dc9759966b.png)

核心入口是【上传音视频】。

![](img/zhuanqian_cada12ac59edcc460561bf256d5adff6.png)

### 总结一句话：很猛

单次可投50个文件，单个时长最高6小时。把待拆解的视频统一放到一个本地文件夹，一次性拖进去，等结果就行。

解析后的稿件在 效率-我的记录-默认文件夹-新建 中查看。

![](img/zhuanqian_3978268c83606228900c021d5feb3c39.png)

进阶技巧：批量导出时点右侧批量，勾选需要的稿件，一次最多导出12条，约等于一页量。

追求条理的同学可以在导入前先把视频文件名改规范，解析出来的文稿名称会非常清晰。

![](img/zhuanqian_e0a676376b46a01e3e5172f171be3673.png)

不然上百篇混在一起，脑子很容易宕机。

## 导出时的细节注意

下载前记得把【发言人】【时间戳】的勾选去掉，否则下载后还要手动清理，非常麻烦。

![](img/zhuanqian_360fdd8fc76690acc7ed31c6b922c3cb.png)

### 不取消勾选的话呈现的就是这样，需要手工删

![](img/zhuanqian_1af74872eb062b620cf2f3d5d9b2698a.png)

通义还有不少隐藏能力，比如实时记录。开会时打开录制，最长可记6小时，自动转成文本，还能区分单人/双人/多人并生成全文大纲，值得深挖。

![](img/zhuanqian_6266cad509e490f15251d2df25e77cb2.png)

到这里，视频批量抓取和文案批量提取的闭环已经完整。

# 3. 批量转格式

做小红书治愈类账号的同学常需要别人的音频素材。视频抓完后打开【格式工厂】，把视频批量转成音频即可。电脑端软件，自行搜索下载即可。

节省下来的时间，可以用来陪家人、做自己真正想做的事。
