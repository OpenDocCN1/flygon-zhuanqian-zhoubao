# Youtube shorts（0-1小白教程）
刷到AI做视频就划走的朋友，先别急。
这篇文章是一个刚进赚钱一周的纯新手写的。我自己有本职工作，之前折腾过小红书手工博主，靠自然流量撑了一阵子，后来流量掉了，收入也跟着掉。进赚钱之后疯狂补课，才意识到自己过去踩的坑，基本都是吃了信息差的亏。
看了一圈，挑了个自己感兴趣也想试试的方向：YouTube Shorts。
说实话我对软件操作是真不熟，但花了三天时间，刷视频、看教程，居然把ChatGPT、Midjourney、Runway这些工具都摸了个大概。所以别一看到“AI”两个字就觉得门槛高，针对性去学，规律很快就上手了。
**起步成本也没想象中高：**
- 🪜：淘宝随便找家店，按需求买就行。
- 各平台AI会员：也是淘宝搞定，全部加起来两百多。
然后就是刷视频、啃教材、做笔记。圈里已经有很多大佬整理过教程，直接搜就行。
**我主要做两个方向：猫咪故事赛道 + 魔术变身赛道。**
先说猫咪故事，流程大概是：给ChatGPT设定好角色和背景信息，让它产出分镜场景，然后拿这些描述去画图。

<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_21118b02d8d18b35086e9f84ede1d396.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_2284a03b95d45b95f6b9491f60c6b3f4.png>
如果生成的图不满意，就在描述词里加细节，反复细化，直到满意为止。挑出满意的图，丢进剪映加音效和特效——特效怎么加，就看剧情高低潮自己判断了。
如果有耐心，也可以把图导入Runway做成图生视频，再剪进去，效果会更好。我随便剪了一条，其实大部分时间都花在生图环节，其他步骤都不算麻烦。
**变身赛道就稍微折腾一些，重点卡在Runway的图生视频变身环节。这里单独讲讲。**
先在Midjourney里用文字生成你想要的角色图，文生图教程自己翻一下，选几张满意的存下来。
至少要准备三张：变身前、变身中、变身后——你也可以做更多阶段。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_9a9139c96d873608ba49050791fea486.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_a85e626910446e1bed3b7330946850ed.png>
然后打开Runway，第一步，把第一张图放进首帧，输入描述词，比如“女孩在舞台中跳舞，女孩和狐狸变为一体”。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_267fdab7bef7318e61d554bedcf74470.png>
生成完保存，再把变身后的图放进尾帧，配上描述词，比如“女孩在舞台中央跳舞，她的脸分裂出狐狸和女孩”——听起来像绕口令，但确实这么写。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_9f9b2fcaa436e434c0e9521399e0201e.png>
接下来是重点：怎么让变身看起来丝滑？我试了好多次，这个方法是目前试过最好用的：
**尾帧生成完，千万别动它。回到首帧，重新导入第一张图，还用第一次的描述词，重新生成一次。**
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_f28d4f389479d4bf393f585b9ec4a5bf.png>
丝滑变身就成了。
如果还要继续变，就把刚才那张尾帧挪到首帧来，把原来的首帧图删掉，再在尾帧放第三张变身图，配上你要的描述词。我做的例子是一个女孩变成另一个女孩。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_a8c9ee8e84152a1bd910c45848da4d95.png>
生成出来就是这种感觉。
翻了很久的视频教程，发现别人生成都挺顺滑，我照着网上方法做却不灵，因为关键步骤没人提。给你们划个重点——
规律就是：首帧放第一张图 → 取消 → 尾帧放第二张图 → 再导入第一张到首帧 → 生成，第一步完成。然后把首帧第一张删掉，第二张尾帧调到首帧，第三张放尾帧，再生成，以此类推。还能再变回去。
最后按顺序拖进剪映剪辑就行。
