# 二、课程大纲编排的“三个要点”

那【自己列的内容】+【AI 生成稿】+【同行对标】这三样东西，到底怎么捏合？——记住三个要点⬇️

## <1> 使出全部力气，把课程最有吸引力的卖点全部亮在大纲里

学员在决定买不买之前，主要就是通过海报来认识你的课。海报是你的门面，而大纲又是海报的 C 位。最亮眼的卖点不在大纲里摆出来，还能放哪儿？塞进正文里？藏在讲课中？

酒香都怕巷子深，何况你还不是什么名酒的时候……

所以要点一：课程卖点，想尽办法也要在大纲里秀出来。
