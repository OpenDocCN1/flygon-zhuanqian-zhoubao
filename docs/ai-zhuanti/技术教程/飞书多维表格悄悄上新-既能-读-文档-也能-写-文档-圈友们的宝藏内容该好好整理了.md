# 飞书多维表格悄悄上新：既能“读”文档，也能“写”文档，圈友们的宝藏内容该好好整理了

最近发现飞书多维表格搞了个大动作——现在它可以直接读取飞书文档，还能在表格里新建文档。更妙的是，这个能力背后靠的是扣子 Coze 来打通。

说白了，这三兄弟都是字节系的。多维表格就像那个最小的弟弟，现在能用堂哥（Coze）的办法，去读亲哥（飞书文档）的内容，这关系还挺有意思的。

想直接上手的话，飞书官方已经做好了现成模板，点进去就有详细的说明。你也可以跟着我亲手跑一遍流程。模板链接放这儿了：[`bytedance.larkoffice.com/wiki/ENMkwOTiQiI9Cqk0pUbcOElMnrg?table=tbl8xOdyjTa2N5LY&view=vew9a4zvoj`](https://bytedance.larkoffice.com/wiki/ENMkwOTiQiI9Cqk0pUbcOElMnrg?table=tbl8xOdyjTa2N5LY&view=vew9a4zvoj)

## 先把模板拿到手

点开上面那个链接，直接点“使用”，一份一模一样的多维表格就会出现在你的飞书文档里，非常简单。

![](img/5f98026a93218a7dc2eaf0004f17cc6b.png "None")

## 场景一：让多维表格帮你“读”文档

### 先看表格长啥样

用来读取飞书文档的结构很精简，就三列：

*   第一列“飞书文档”：把文档链接贴进来就好；

*   第二列“要求”：写你想对这个文档做什么操作，本质上就是提示词；

*   第三列“AI 读取飞书云文档”：这里是最终结果的展示区。

![](img/ec0c9e929a6865d1453873aa08a3a697.png "None")

重点说说第三列。它用的是“字段捷径”的方式，把指定文档链接交给自定义指令去处理，而这个关键的字段捷径，幕后就是扣子 Coze 在发力。

![](img/746b3955f32abf8fb2521a35708a7de0.png "None")

### 实际读取试试

我拿云中江树老师的一篇飞书文档来试。把链接粘到第一列第一行，多维表格自动识别了链接，直接显示成文档标题。（[`langgptai.feishu.cn/wiki/VXmowI2boiqVFVkj9vlcNkhNnce?from=from_copylink）`](https://langgptai.feishu.cn/wiki/VXmowI2boiqVFVkj9vlcNkhNnce?from=from_copylink）)

![](img/216fde55c7a29a94e3978a2c44e9346e.png "None")

第一次点第三列，会弹出一个授权提示，需要跳去授权扣子绑定飞书文档。官方也说明了：**Coze 只会读取你填进单元格的那个云文档链接，别的文档它不会碰。**

授权完回到多维表格，刷新一下页面。

![](img/d14659ad6c4411c001efc801e3f533a0.png "None")

这时候能看到 AI 已经把原文档的内容读出来了，文字全都在，只是图片没法显示。

![](img/eafc2c127f7b596b7f75f4b09e85eda0.png "None")

### 用“要求”列给文档做加工

第二列“要求”其实就是你的提示词。因为在设置里已经指定把“要求”作为自定义指令，AI 就会按这个要求直接干活，把**处理后的结果**填到第三列，而不是先给你看原文。

比如我写“总结原文，列出十条重要的信息或观点”，AI 就乖乖按这个要求输出，不会多废话。

![](img/592bb523028230875fb5528e7e15d8f0.png "None")

所以“要求”就是提示词。想怎么玩就怎么玩：润色、总结、扩写、缩写、针对文档提问……官方模板里还有一堆示例可以参考。

![](img/d4e8074feb3754146e05e91edcf07ba8.png "None")

## 场景二：让多维表格帮你“写”文档

这个功能反过来：你往多维表格里贴一段文本，它能直接在飞书里生成一个新文档，把文本存进去。

![](img/4dafbe8bc3aaffae83af52c076812c7e.png "None")

结构更简单，就两列：第一列放你要创建的文本内容，第二列是生成后的飞书文档链接。第二列靠的是一个叫“AI 创建飞书云文档”的字段捷径。

![](img/086c6e6a62d82b6e0aa5f88ab5a52288.png "None")

## 两个功能打通：读取 + 创建

我对多维表格字段捷径的理解是：每一列都可以单独配置一个 Agent（字段捷径），行与行之间就像 Workflow 一样把这些 Agent 串起来。这样一来，每一行其实都是一个“Agent + Workflow”组合出来的高级智能体，多行输入还能实现 Workflow 的批量跑。说实话，能设计出这种玩法的，真是个天才。

基于这个理解，我们大可以在一张表里放多个字段捷径。把“读取飞书文档”和“创建飞书文档”串起来，看看效果会怎样。

![](img/baa896767d2c91bf05205888abca0b1b.png "None")
