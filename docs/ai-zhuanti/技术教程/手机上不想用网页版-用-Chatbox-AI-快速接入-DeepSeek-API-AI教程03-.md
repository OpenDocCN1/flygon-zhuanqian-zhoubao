# 手机上不想用网页版？用 Chatbox AI 快速接入 DeepSeek API【AI教程03】
作者：龙哥

上篇带大家把 DeepSeek API 接入了 Cherry Studio，但那套方案目前只支持电脑端，手机党想随时随地聊还真不方便。所以这篇就安排一个手机方案：通过 Chatbox AI 完成配置，从下载到跑通，全程手机操作。

先交代两个小前提：

- 苹果生态用户（iPhone/Mac）：直接到 App Store 搜索 Chatbox AI 下载即可，没有任何获取门槛。

- 安卓用户：如果官方下载页打不开或下载不顺利，可以改用文末的百度网盘 APK 安装包。

再说点底层思路。之前我们把 API 比作汽油，客户端比作汽车；但市面上的“汽车”并不只有 Cherry Studio 一种，能用来跑 API 的工具很多。我整理了一个工具对比表，各家的优缺点都列出来了，黄色高亮的是推荐选择。大家按需挑选就好。毕竟 AI 工具迭代太快，今天能用的产品明天可能就换了一波；只要把原理搞懂，将来无论换到哪个客户端，你都能无缝衔接。

![](img/zhuanqian_e99a655c39943ea54e94a75f554de868.png)

下面进入实操，全程在手机上完成。

## 一、手机下载 Chatbox AI

- 苹果用户：打开 App Store，搜索“Chatbox AI”后直接安装。

- 安卓用户：用手机浏览器访问 https://chatboxai.app/zh#download ，进入页面后选择第三个 APK 下载。

![](img/zhuanqian_0f3946b0f525320a2cf8b5c303517fb2.png)

点击下载按钮后，等页面加载完成，系统会弹出 APK 的保存提示，选择“保存到本地”即可。

![](img/zhuanqian_4f13a4c4682079373b79cd1cdf94a6b9.png)

如果下载页面一直不弹出，或者打开后白屏、只显示一串代码，那就直接使用百度网盘里我打包好的 APK：

链接：https://pan.baidu.com/s/1oRZMXdNjhQD1sJgrsdDfTg?pwd=1111

提取码：1111

APK 安装时，国内安卓手机可能会弹出“应用未备案”之类的风险提示，不用紧张，点“允许”继续安装就行。

## 二、在 Chatbox AI 里配置 API

打开 App 后，首屏会弹出一个选择页，点击第二个选项：“使用自己的 API 或本地模型”。

![](img/zhuanqian_42c8a843b62f09f16fe2c45ca8bb6a9f.png)

进入配置页后，把模型提供方列表往下翻，找到 SILICONFLOW API（硅基流动）或者 DEEPSEEK。如果你申请的是 DeepSeek 官方 API，操作原理和硅基流动也是一样的。上一篇已经教过怎么获取 API，还没拿到 Key 的同学建议先去复习一下。这一步只需要把 API Key 粘贴进去，然后在模型列表里选择 R1。上下文长度、温度这些参数先保持默认，暂时不用调整。

![](img/zhuanqian_dee14ecd516d71ec1fbc3095a69978a7.png)

![](img/zhuanqian_f532c9330fd2adc1636bc33460683fa1.png)

设置完成后，建议做一次“模型是否生效”的检查：回到对话界面，点击右侧的“新对话”或任意一个对话按钮，再点最上方的 untitled 区域，就能看到当前对话实际绑定的模型。只要前面的步骤没遗漏，下方显示的就是你填好的 API 和对应模型。想要修改参数，记得从设置入口进去。角色设定方面，可以自己找网上的 prompt 填充，也可以直接用官方提供的角色模板。像 R1 这类推理模型，反而不需要太花哨的结构化提示词，给一个明确的身份定位就够了。

![](img/zhuanqian_791cbc06a02943b92eda3fa12e7411bf.png)

最后分享一个实测小经验：手机端 Chatbox AI 调用硅基流动 API 时，偶尔会碰到“思考很久却不输出内容”的情况。这时候别傻等，点一下红色方块的“停止思考”按钮，再刷新一下，通常就能恢复。

到此，手机端使用 DeepSeek API 的完整链路就通了：下载、配置、验证、排障，一次搞定。有需要的同学赶紧拿起手机实操起来，把移动端的 AI 助手正式点亮。
