为节省大家时间，文中若有表述不清或操作模糊的地方，建议配合搜索引擎，或使用龙哥盟的搜索索引工具 [https://search01.shengcaiyoushu.com/](https://search01.shengcaiyoushu.com/)

# 0. 起点

我是在搜索「公众号」关键词时看到这篇启发：[)，里面讲了写情感类稿子的思路。

还没加入航海前，我就按这个方法试过几篇情感向，阅读寥寥，有时只能靠自己点赞撑场面，几天下来还是个位数，信心一度掉线。

反思后发现问题在于出发点错了：我不是从流量/转化/产品思考，而是从「我没流量」的焦虑出发。后来换个角度，盘点当下自带流量的时事热点，再把热点包装成情感向内容，效果立刻不一样。热点本身就自带关注度，值得all in。

下面是我完整的打法：从找热点、拆解、到用 ChatGPT 出稿并发布，部分步骤对新手来说偏繁琐，老手可直接跳过。

# 1. 找热点

赚钱站内搜「热点」能冒出大量方法。我汇总了3个常用渠道，对微信生态我更推荐第三种：

1. 百度热榜 [https://top.baidu.com/board?tab=homepage](https://top.baidu.com/board?tab=homepage)

2. 新榜热榜 [https://www.newrank.cn/](https://www.newrank.cn)

3. 微信搜一搜自带的热点

提示：微信热点其实就是搜一搜页面的发现入口，截图里排在最前的那条。如果没显示，去底部「页面设置」打开即可。

![](img/zhuanqian_c653ec7a52c26c684c4254963f79e443.png)

以微信自带热点举例来演示。近期热点条目很多，我挑了第3条：「浙江一处长地铁猥亵他人 被拘 12 日」，这类带「性」元素的社会新闻自带高点击潜力。拓展阅读可参考2023年3月航海的公众号爆文写作手册：[https://search01.shengcaiyoushu.com/docx/NHgUdKMcLoPz0VxSz8LcspWqnsg](https://search01.shengcaiyoushu.com/docx/NHgUdKMcLoPz0VxSz8LcspWqnsg)

# 2. 找同题材的爆款

点进选中的热点后，会回到微信搜一搜，记得切换到「文章」Tab，才能看到稿件信息。用电脑操作更顺手，直接把完整话题词原封不动复制到搜一搜。第一页基本都是通稿，往下翻就能看到10W+的稿子。

![](img/zhuanqian_91b16ea0b6bfe7604906634e72abb879.png)

多刷几分钟，3~10分钟内通常能筛出一批参考。

![](img/zhuanqian_7bdd7e41b1a068b5d2ae8b0348292ab9.png)

这类新闻事件往往出现得快，真正的高阅读稿件还没起来，此时入场，抢占空白窗口，比跟风更有机会冲10W+。把热点主线和已有的爆款写法结合，形成自己的角度，胜算会更高。

别犹豫，下场才有数据。

# 3. 用 ChatGPT 拆解并写稿

Tips：

1. 生成中断或字数不足时，输入「继续」即可，通常1~3次足够，勿过度。

2. 自己通读后做适当删改、增添钩子、金句，或加入关注/评论引导。

3. 粥左罗老师的话：ChatGPT负责速度，你负责框架，好+快=胜出。

4. 控制在1200字上下，太长完读率下降，影响后续推荐权重。

# 4. 配图、封面与标题

### 配图

事实类热点配图可去小红书、抖音找相关视频，下载后自行截帧插入文章。

操作示例：

1. 抖音搜索关键词，复制链接

2. 微信搜「抖音去水印」，任选一个小程序粘贴处理后下载

3. 本地视频可自由截帧，iPhone直接在相册拖拽找帧截屏即可，无需额外软件

情感、搞笑类稿件可用第三方编辑器，自带无版权图库、签名水印、自动导入公众号等功能，十分省事。

### 封面

参考B站何同学的测评，普通账号封面影响有限。我的建议：

1. 情感类文章，封面选自带吸引力的图片，如美女/帅哥等。

2. 实时热点，优先用小红书/抖音已验证的爆款封面，别人已用数据证明有效，记得抹去原作者信息以免被举报。

# 5. 文章发布

### 属性设置

1. 务必勾选「原创」，能提升推荐权重。

2. 分类选择精准标签，如社会>热点情感等，匹配人群画像可提高打开与完读。

3. 赞赏功能建议打开，增加正反馈与收入来源。

### 发布时间

新号基本靠推荐和搜索来量。热点类建议越早发越好，很多热文都是0点上线；情感类可在晚间饭后时段推送。

发布时务必选择「群发」而非「发布」。

### 推广

有大号资源可直接借势。无资源也不必慌，我发现微博带热点标签可带来免费初始阅读，+1的阅读也能触发推荐效应。

时间充裕的话，可同步分发到知乎、百家号、头条，用关键词带上公众号名称引流。
