# AI+兴趣+技能：做出自己的专属：跑步配速器小程序
你是不是也想过，把自己喜欢的事和会做的事结合起来，搞出点名堂？
今天要聊的这位主角，是个特别爱跑步的程序员。他之前总在模仿别人的项目，直到有一天，他决定换个思路——不再跟着别人走，而是从自己的兴趣出发，加上自己本来就擅长的编程技能，再借助当下最火的 AI 工具，做了个“跑步配速器”小程序。
就是这么一次“为自己而做”的尝试，结果出乎意料。
第一步，他先用 Cursor 快速做出了一个网页版的小程序。没有追求大而全，就先把核心功能跑通。然后，他通过自己的公众号加上网页链接的方式，把这个小东西推了出去，想看看大家啥反应。
结果呢？文章直接爆了。不仅收到了读者的赞赏，还顺带加了二十多个微信好友。对于一个自认为一直在“学别人”的人来说，这波反馈显然给了他一个很大的惊喜。
这件事其实挺有意思的：不需要做多复杂的项目，也不用等什么完美时机。当你把“兴趣 + 技能 + AI”这三样东西凑在一起，哪怕只是个小工具，也可能碰撞出意想不到的火花。
如果你也有自己的爱好，也懂点技术，或者正在学 AI 工具，不妨想想——你能为自己的兴趣，做个什么专属的小玩意？
