# 从懵到开工：我的副业启动第一周复盘

大家好，我是龙哥。机缘巧合下通过微信公众号刷到龙哥盟星球的推送，其中一篇《小红书蓝海副业-英语演讲定制实操经验分享》让我很有触动，于是报名了94期的体验课，并正式加入了这个圈子。

体验课结束到现在整整七天，我想把这周的真实心路历程梳理出来。写出来一方面是对自己这段时间的沉淀，也希望这份记录能推动我继续往深处学、往实处做。

**先聊聊我的底色**

我是80后，从业至今将近18年，一直扎根互联网的软件测试岗位。从早期的手工点点点，到自学自动化测试，再到自己啃Python过渡到编程，最后做到测试团队的管理者。回头看，我的自学劲头还算可以，但和星球里那些真正深耕的大佬比起来，深度和格局还有明显差距。后续如果有圈友的App或网站需要测评测试，欢迎来找我。

**离职后的迷茫期**

步入2025年1月，我实在受不了在原公司那种互相消耗的内耗状态，于是做了一个冲动的决定——离职。

春节的热闹结束后，现实感迅速袭来。我急切地想找到一条属于自己的路该怎么走，却又完全没有头绪。加入赚钱后，反而因为看到太多项目案例和玩法分享，让我的选择困难症更严重了。

为了破局，我花了三天时间集中研读星球里的精华帖和项目拆解，又用两天时间静下来梳理自己的思维，最终给自己定了两个可操作的细分方向：

**AI + 宠物赛道**

**AI + iOS App 开发**

为什么会锚定这两个方向？

在加入赚钱前，我差点就去加盟一家宠物实体连锁，后来在星球里看到关于实体铺开失败的案例，才惊觉贸然下场有多大风险。

从公开数据来看，宠物经济的热度持续走高，行业体量还在不断放大，长期看有想象空间。另一方面，在星球内部的内容分布里，宠物相关的话题占比并不高，属于偏小众的细分，但既然已经有前辈在讨论、有人在布局，就说明这条赛道是有生存土壤、值得长期深耕的。

AI和宠物结合的玩法也很多，未来的延展性很强，虽然目前手头还没有完全落地的点子。至于AI+网站/App的形态，则更利于触达终端用户，把前端流量和后端变现完整闭环起来。

方向大致敲定之后，最关键的就是别再纸上谈兵了。赚钱里常说的一句话我特别有感触：**“先弄脏双手，躬身入局”**，这正是我接下来要践行的。
