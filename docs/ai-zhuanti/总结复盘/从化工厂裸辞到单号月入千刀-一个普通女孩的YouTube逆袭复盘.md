# 从化工厂裸辞到单号月入千刀：一个普通女孩的YouTube逆袭复盘
大家好，我是龙哥，一名自由职业者，也是深海圈教练。
去年九月，我辞掉了稳定但压抑的工作，十一月正式加入赚钱，十二月跟着航海计划一脚踏进了YouTube的世界。打那以后，我就一头扎进了Reddit故事号这个赛道，靠着shorts视频，硬是把单个账号做到了月入千刀。最近反复翻看曹教练那篇《那些年的选择与努力，一个普通人在赚钱成长与蜕变的故事》，越看越有共鸣，于是想把这段经历好好盘一盘，分享给正在迷茫或观望的你们。
## 一、回望来时路：顺境与淬炼
**顺风顺水的前半场**
在曹教练那篇帖子下面我也留过言——对比他而言，我长期待在自己的舒适区里。回看我的成长轨迹，每一步都算顺利，像是被命运推着走，顺理成章地抵达下一个站点。读书时没心没肺，高考没考好，就任性地选了化工专业（说出来有点好笑，化学不及格的人去学化工了）。大学期间学业、恋爱两得意，也跟着大流去做了各种兼职，端过盘子、当过家教，还帮学弟学妹做过课程设计。
毕业后和男朋友一起投进了某500强企业的子公司，进了同一家公司，岗位相似、工作内容雷同。然后买房、买车、升职，结束了整整七年的恋爱长跑。一切看起来完美得不像话，可偏偏在这种时刻，我做了一个让周围人直呼看不懂的决定：裸辞。但要说清楚这个决定，得先聊聊化工厂的日常和我那岗位的真实面貌。
**高压淬炼的日子**
化工厂的工作，天然伴随着高危风险：高温高压、易燃易爆，这些都是家常便饭。也因此，管理岗采用的是轮休制度，手机二十四小时不敢关机，不管几点，只要现场有异常，一通电话就得从被窝里爬起来赶过去。真正属于个人的时间少得可怜。
我所在的岗位是工艺技术管理，放眼整个工序办公室，我是唯一的女生。我的任务是在保证装置安全稳定运行的前提下，死磕质量最优、产能最高、消耗最低、效益最大。工艺是生产的心脏，需要跟所有专业、所有部门协同作战。
说实话，我是个事业心极强的人——既然做了就要做到最好。我当时的念头很简单：成为这个工序的技术大牛，让大家一提到这个工序就能想到我的名字。我想证明，在所有人嘴里最苦最累的工序里，女生不仅能干，还能干得漂漂亮亮。
我也确实热爱这份工作：花几天几夜让数据曲线归位，推动自动化减轻人工负担，联合各方思维碰撞去解决一个个顽疾，倒推出每个动态因素的根源……每一次突破都让我觉得自己的价值被照亮。可是，现实的落差来得比想象中更快：
- 行业产能严重过剩，寒冬来袭，公司效益断崖式下滑，工资直接砍了五成还多。
- 团队成员陆续变动，组织结构不断调整，磨合期变得无比磨人——报酬变少了，活儿却更重了。
- 白天泡在低效的会议里，晚上加班做没有产出的琐事，能喘口气的时间只有凌晨，根本没有精力去自我提升。
- 找不到增长点，找不到突破口，价值感被一点点抽空。
- 长期高负荷运转，身体开始亮红灯。
- 生活变成一潭死水，没有购物的欲望，也没有活着的实感。
我忍不住问自己：我还这么年轻，这真的是我想要的人生吗？这个圈子像一口井——我尊重井底每一个人的选择，也理解他们的活法，但我就是想跳出去看看，井外面到底有什么可能。
所以，权衡再三，我提了辞呈。
**感恩清单**
这三年，我学到了太多，也旁观了太多人的故事与无奈。除了这些，我更想记下的是感恩：
- 感恩刚毕业就能拿到相对高薪的工作；
- 感恩赚钱顺利时攒下了足够的积蓄；
- 感恩没有沉重的房贷车贷压身；
- 感恩行业寒冬让我能更果断地做决定；
- 感恩双方父母的理解与托举，给了我闯荡未知的勇气；
- 感恩自己始终保有的那份自信——只要努力，就没什么到不了的远方。
## 二、踏上新征程
**初入赚钱**
说来有趣，最初是老公推荐我加入赚钱的。他大学时就关注这个社群了，甚至通过咸鱼渠道混过两次体验营，却始终没转正，总觉得欠了赚钱一张门票。我离职后时间大把，他就亲手把我这个“代表”送了进去。（顺嘴提一嘴：赚钱三天的体验营有积分机制，我拿了小组第一，换了一张400元的门票优惠，赚到了哈哈。）
**试错阶段**
十二月份，我同时报了小红书虚拟资料和YouTube两个航海。前者纯粹是因为门槛低容易上手，后者则是被龙哥的“超级标”加上老公的强烈推荐所吸引。
其实小红书虚拟资料我从十月份就开始动手了，折腾了两个月没见什么水花，差点放弃。正好赶上航海，我想搞清楚问题到底出在哪，就又报名了。航海期间倒是变现了四百来块，但我也终于弄明白为什么这个项目走不通——它的核心卡点在私域引流和即时交付，消息回复必须及时，这让我的时间被碾成了碎片，完全没法集中精力去学习、去成长。
相比之下，YouTube项目走起来就顺畅多了。我老公混迹网络的经验比我丰富，大学时注册过YouTube账号、发过游戏视频，虽然没变现就弃了，但走过的路每一步都算数，所以入局时几乎没有遇到什么卡点，前期推进得相当快。再加上AI的爆发把内容创作的门槛砸低了一大截，而YouTube前期的变现不依赖实时互动，节奏完全能握在自己手里。这些东西加起来，简直是为我量身定做的，所以我果断选了YouTube方向深耕。
**遇上波妮教练与深海圈**
做YouTube的路上，我特别想感谢波妮教练。因为之前的工作性质，我对加好友、微信聊天这类社交动作其实非常抗拒。真的感激波妮教练在航海期间主动链接了我。甚至在一月份，赚钱孵化YouTube私教陪跑（也就是后来的深海圈）的时候，波妮教练又私聊了我。当时我正卡在YPP开通的瓶颈上，看着满天飞的工具焦虑得不行，觉得根本学不完。而私教陪跑不但切中我的痛点，还带来了多元变现的路径和深度陪伴。我那时候心想：这么好的东西，报名费怎么也得一张赚钱门票吧？结果只要599，立刻付钱，哈哈。
在此之前我没有副业经验，也没参加过其他社群，更没给别的知识付费交过钱。但私教陪跑给我的体验是真的好——曹教练的干货输出、波妮教练的耐心答疑、一对一的深度咨询，还有一群同频的人一起碰撞切磋，整个氛围异常正向。所以当深海圈正式成立时，我毫不犹豫地加入了，还主动报名成了教练。
## 三、Reddit故事号的深耕之路
对这条赛道还不了解的朋友，可以去看老马教练的拆解帖——他讲得很细致。
**赛道对比**
从入局YouTube开始，我做过的项目不少：AI猫猫故事、达人秀、动物救援之类的AI视频我都试过。拿它们和故事号对比，差异非常明显。现在虽然也冒出了AI+语言融合的新赛道，但我还是想以自己亲手趟过的两种极端类型——重画面轻语言的AI赛道，和重语言轻画面的Reddit故事号——做个对比，分享一些个人经验：
| 维度 | AI赛道 | Reddit故事号 |
| 画面依赖 | 极高，依赖AI绘画生成质量 | 很低，素材相对简单 |
| 内容门槛 | 需要持续追赶爆款热点 | 更吃文案功力和选题直觉 |
| 成本投入 | 工具成本高 | 前期几乎零成本 |
| 稳定性 | 波动大，爆款后劲难判断 | 相对稳定可控，播放量有保底 |
| 适配度 | 适合有经验的玩家 | 对新生小白更友好 |
对我这种从传统工科转行过来的人，经验的匮乏让“追爆款”这件事变得很不可控，AI赛道的工具开销也不小。而Reddit故事号的优势一看便知：确定性高、稳定性强、前期投入低，完全契合我当前段位的需求。
**合理预期：先算账，再行动**
做任何项目，我习惯先算账——投入多少、回报几何，算明白了才能定方向、调预期。我是个耐受力和抗压力都不弱的人，只要结果在预期之内，我就能持续死磕。
所以评估赛道时，我更倾向Reddit故事号：它的工作流是标准化的，每一步都清晰可控；而AI赛道得靠“抽卡”碰运气出好效果。于是我开始算：这买卖值不值得我坚持做？
业内常说故事号“万年万播”——如果基础播放量按1万来算（互动观看次数），RPM取0.2，一天发3个视频，那日收入就是1×0.2×10×3=6美元。反推一下：我原工资一个月一万，折合每天就是10000÷30÷7.1≈47美元，那么我需要8个账号才能打平——而且这47美元还是8个账号的下限，行情好只会更高。
算完这笔账，我的目标瞬间清晰了：第一，先做满8个号；第二，让每个号都稳定达到万播的基本线。
**YPP账号开通之路**
YPP开通的门槛：1000订阅 + 一年内4000小时观看时长，或者90天内1000万次Shorts有效观看。
前面提过，Reddit故事号靠shorts积累到3000万次观看几乎不现实，所以我的破局点是观看时长——也就是长视频或者直播。幸运的是入局够早，正好赶上直播红利期，顺利拿下了第一座山头。
YPP开通我试了两种账号搭配策略：
- **故事号起号 + 故事号直播**：好处是账号垂直度高，直播间吸来的粉丝和内容核心用户画像高度一致，平均观看时长能干到30到35秒；缺点嘛，场观人数相对冷清，多数在几千甚至几百徘徊，得靠一场场去熬。
- **AI转故事号起号 + 非故事号直播**：非故事号直播（比如AI类内容）流量是真猛，轻松能做到单场上万人观看；但坏处也很明显——账号垂直度被稀释，会吸来大量印度等东南亚观众，既拖累后期数据表现，也压低了单价，前期RPM只能在0.17到0.2之间徘徊，远不如垂直账号值钱，而且观众画像的转换周期很长。
**变现阶段：从二创到原创的进化**
YPP开通只是万里长征第一步，怎么把第二个目标啃下来才是核心。我分别在文案打磨和视频呈现形式上动了刀。
**二创阶段**
刚入局的时候，我对赛道的感知还很钝。先照着老马教练给的方法，去找对标账号的爆款文案做二次创作，同时从Reddit社群里收集那些近期高赞高留言的故事当素材库。
但做着做着，评论区开始出现刺耳的声音：AI、虚假、抄袭。这说明什么？说明文案不够新颖、配音不够自然、故事缺少生活味——因为我抄的爆款，早被无数人二创过N遍了。想在这条路上长久走下去，必须搞原创，必须做出属于自己的风格。
**原创阶段**
做原创，第一刀得切在选题上——开头就抓住人，拉高“继续观看”的指标；第二刀则要落在内容上，靠故事本身的质量去推动完播率，也就是平均观看百分比这个数据。
**选题怎么切入？**
我有一个还没成型的思路：我发现一个规律——只要某个选题跑出过爆款，在YouTube上搜索这个选题，你会发现下面全是同题材的视频。于是我把一堆爆款选题收集起来，调用Google官方的YouTube数据分析API，用AI写了个简单的小工具，去统计某个选题在一定时间内的发布数量、播放情况，然后扔给Claude做深度总结，最后整理出一套“选题模型”，用来研判爆款选题的竞争烈度、制定执行策略。可惜因为API配额限制，采集的数据量不够全，这个思路暂时搁置了。以后有空可能会试试网页自动化采集，把这套模型补完，进一步提高爆款命中率。
不过核心结论已经拿到了：**爆过的选题，还能再爆，关键只是竞争度的问题——发得够多，总会踩中一个爆款。**所以我囤了一大批对标账号的爆款选题，建起了自己的选题库。

## Role: 药剂师
## Profile:
- writer: 李继刚
- version: 0.6
- language: 中文
- description: 你是一个 Prompt 药剂师，通过对用户的 Prompt 进行分析, 给出评分和改进建议，帮助用户提升 Prompt 的效果。
## Attention:
用户在努力学习如何写出优秀的 Prompt, 但遇到了难题, 不知从何改进. 你会尽自己最大的努力来尽可能详细地分析, 帮助用户学习如何进行分析, 如何进行优化. 你对自己的能力表现非常自信.
## Background:
用户基于当下认知写完 Prompt, 不知现在的写法有什么问题, 需要你来帮忙分析.
## Constrains:
- 提供准确的评分和改进建议，避免胡编乱造的信息。
- 在改进 Prompt 时，不会改变用户的原始意图和要求。
## Goals:
- 对用户的 Prompt 进行评分，评分范围从 1 到 10 分，10 分为满分。
- 提供具体的改进建议和改进原因，引导用户进行改进。
- 输出经过改进的完整 Prompt。
## Skills:
- 拥有理解中文语义和用户意图的能力。
- 拥有对文本质量进行评估和打分的能力。
- 拥有提供具体的改进建议和说明的能力
## Workflows:
- 输入: 用户输入原始 Prompt
- 分析: 你会以 ChatGPT 底层的神经网络原理的角度进行思考, 根据以下评分标准对 Prompt 进行评分，你打分十分严格, 有任何不满足神经网络需求的地方都会扣分, 评分范围从 1 到 10 分，10 分为满分。
+ 明确性 (Clarity) ：
- 提示是否清晰明确，无歧义？
- 是否包含足够的信息来引导模型生成有意义的响应？
+ 相关性 (Relevance) ：
- 提示是否与目标任务或主题紧密相关？
- 是否能够引导模型产生与特定目的或领域有关的响应？
+ 完整性 (Completeness) ：
- 提示是否全面，包括所有必要的元素来引导模型生成全面的答案？
+ 中立性 (Neutrality) ：
- 提示是否避免了引导性的语言或偏见，以确保公平、客观的响应？
+ 创造性 (Creativity) ：
- 提示是否激发模型的创造性思考和生成？
- 是否鼓励模型提出新颖、有趣的观点？
+ 结构 (Structure) ：
- 提示的结构是否有助于引导模型沿着预期的路径生成响应？
+ 语法和流畅性 (Grammar and Fluency) ：
- 提示的语法是否正确？
- 是否采用了自然、流畅的语言？
+ 目标对齐 (Alignment with goals) ：
- 提示是否与原始 Prompt 的目标一致？
+ 可测试性 (Testability) ：
- 提示是否能够被用于可靠和一致的测试？
- 建议: 你会输出三个具体的改进建议，并解释改进的原因和底层机制。
- 建议:  <建议内容>
- 原因: <改进的原因>
- 机制: <改进的底层机制和原理>
- 改进: 最后，你会输出经过改进的完整 Prompt，改进的地方用加粗的样式显示, 以供用户参考借鉴。
## Initialization:
"Hi, bro, 我是你的梦境药剂师, 给我看看你织的梦境吧, 我来给你加固一把~"

接下来，我直接在Monica平台里，用Claude 4配置了一个智能体来做故事创作。Monica智能体的出稿非常稳定，但随着选题的反复使用或相似度过高，会出现剧情重样、故事乏味的情况——每逢这种时候，我就会切换到GPT顶上。
从体感上说，Monica + Claude 4配置的智能体在稳定性上更胜一筹，而GPT的输出在字数把控上比较随性。至于内容风格的差异，大家可以直接感受一下——同一个“脱鞋”题材，两个AI给我的完全不同的答案：
**Monica Claude 4智能体**
英文：My friend's mom insisted everyone remove shoes AND socks before entering. "Bare feet connect you to the earth's energy," she explained seriously. I complied, thinking it was just hippie nonsense. Then I stepped on their hardwood floor and immediately understood. It was heated marble imported from Italy. 视频的外包装也有不少门道。Reddit故事的呈现方式相当多，空镜、解压片段、游戏录屏、AI生图或视频都有人做。不过在Shorts里，出镜率最高的是解压素材和游戏录屏。一个典型的解压故事号，基本由解压画面、语音、卡片和BGM构成。
解压画面我通常去Ins上手工收集。对，纯手工，一个个复制链接，再用SnapAny下载——它一次最多能存10个链接，用起来比哼哼猫更稳，关键还免费。为什么不写脚本批量抓？因为机器抓取的素材质量没保证，精细度远不如人工。
配音环节是我踩坑最多的地方。第一是语速。Shorts要在短时间里塞进更多信息，语速得在不影响清晰度的前提下尽量快。别只凭自己的感觉，要多听竞品账号的语音，多看评论区反馈。第二是气口。适当停顿能带出情绪，但也容易显得拖泥带水。研究一下对标账号，会发现他们不仅语速快，句子之间还咬得非常紧，所以剪掉多余气口很重要。第三是工具选型。最开始我特别在意情绪起伏，想让人声更有张力；后来转而追求温柔舒缓的音色；现在我更看重自然度——像美国人日常聊天那样，发音地道、语气松弛。
早期我用elevenlabs，但它的停顿太长，为了在有限时长里塞更多内容，我还专门做了个去气口的小工具，又用Au降噪、变速。说实话，除了把制作周期拖长，并没有实质提升。后来账号被封，原来用的音色在新号里也找不到了，我就琢磨：非用它不可吗？于是买了个“配音神器”终身版。测试发现，它对流量几乎没影响，而且操作流畅、出音也快。但配音神器的音色库有限，太多账号用同款音色，反而导致账号间缺乏辨识度，整体流量慢慢下滑。
之后很幸运看到木辞博哥分享的F5-TTS本地部署帖：https://scys.com/articleDetail/xq_topic/2852482418851551。这个方案能直接克隆对标账号的音色，出来的音频在语速、音色、自然度上都高度一致。换上F5之后，视频流量也跟着涨了。

不过本地部署F5-TTS偶尔会出现音频不稳定的情况。想要更稳，除了成品逐句听一遍，还可以从提示词层面规避——我在故事生成提示词里加了“TTS友好原则”，比如不要用全大写单词、不要出现$符号、用英文拼写替代等等。AI能解决很多问题，多和AI聊聊，往往能弥补个人思维盲区。下面是对标账号的视频，大家可自行感受。总之，多听多看，总能找到自己的不足和优化空间。
卡片和BGM相对简单。卡片模板直接用老马教练的Figma源文件，再根据自己的审美调整间距、颜色、底图。想做差异化，换几个图标，或者做成动态的，图标可以自己找。BGM直接采用对标账号用过的音乐，但要注意通用性。我之前把一个悲剧故事配了首很欢快的歌，结果评论里有人指出音乐与内容严重不符。想做得更讲究，就把BGM按故事情绪分类，不同剧情配不同曲子。
时长方面，Shorts上限是3分钟。现在故事号市面上大概有三类：30秒以内、1分钟整、接近3分钟。最近不少矩阵号都主攻近3分钟的长版，数据很亮眼。1分钟可以说是故事号的“原生形态”，也是竞争最激烈的赛道。那些3分钟账号更像是新物种。我自己也试过接近3分钟的长Shorts，跑出过一个百万播放，后面就回到基础流量。不同时长对数据的影响很明显，下面是我测试的一些片段，供各位参考。
