# 第一章 我是谁，为什么做睡播
## 1.1 自我介绍
大家好，我是 Fredrich，圈里也叫老杨或阿福。曾经在国企干了五六年亚非拉的翻译商务，后来瞎折腾了五六年直播与直播电商，现在专注海外社媒。
## 1.2 为何入局 TikTok
是被生活逼的。
2021年3月5日，我骑电动车上班摔伤，膝前交叉韧带断裂，手术住院休假。作为本该冲KPI的互联网人就这样躺平了。除了三个月掰腿的折磨和一年多的康复，基本就是躺尸。于是开始研究 TikTok。国内竞争太激烈，我自知没优势，好在能用英语，又懂产品。
入门是跟着圈内嘉伟老师的大航海资料，后续又看了 sky 老师的带货小航海，感谢赚钱，也感谢两位老师。
## 1.3 为何转向睡播
因为带货亏惨了。
2021年全年都在做独立站混剪带货，只播过两场直播，GMV为零。
2022年2-5月，开了两家小店，请了黑哥黑姐和一个刚毕业的小哥哥，直接亏到只剩内裤。好在学费不白交，玩出了不少思路。4月底升全球店后也没再继续带货。
2022年5月放弃带货，继续做短视频，从点大屏切入娱乐直播。顺带说下我们那位新加坡小姐姐，综合素质很强，豪爽得像个汉子。

### 为什么选睡播
会英语的主播价格高，愿意露脸的应届女生太少，我直接把门槛降到：只要是人，肯躺着动一动就行。
调研后发现 Twitch 上睡播已有两年历史。TikTok 当时全球只有四个人在做：澳洲一位，今年三月开始，现已是头部；意大利一位，已退出；印尼一位，技术很强；韩国一位，播期不固定。三个都是偶尔播，追竞品很累。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_2ea73ef67a980685a01476fac2d2fca8.png>
我用产品经理的思路拆解过，想新项目也可以从这些角度思考。
1）产品定位
一句话总结：恶搞让你睡不着。
分两种：
静播：安静祥和的环境，配点噪音和环境变化，主播夸张反应逗乐。缺点是用户被教育后起号难，因为互动弱。
热播：大家都知道不是真的睡觉，是表演，环境嘈杂，主播能跳能唱，把床当成舞池。
2）用户是谁
15岁以下：单纯，识破假睡就划走，付费弱，爱表现，引导一下能贡献数据，属于出力不花钱。
15-25岁：有零花钱，爱恶搞，明知是假也能为解压买单，是付费主力。20岁以上偏理性，只要表演解压就留得住。
3）用户价值
装睡被打扰后的夸张反应，满足用户内心的小怪癖，尤其在基督教国家效果好。
4）竞品在哪
TikTok 上做睡播的、做其他娱乐直播的，以及其他平台做睡播的。他们的布场、动作、控场、语言、道具，都是学习对象。没有运营能力，人少时还能活，人多了会被淘汰。
5）本地化怎么做
竞品少，少量差异化即可。
国内不缺道具，缺的是技术、外语和老外脸。
道具方面，雷电云灯国内少见，境外更难找，喷雾机能把间升华；泡泡机、星空灯是点大屏的残留。
音视频自动控制软件是自研，智能硬件没时间做，但够用。目前国内睡播基本都在用这套或同类。
照搬抄作业会永远不懂为什么用这些道具、为什么选这些礼物、为什么做这些动作。
最开始测试时软件未上线、道具也未加，画面简陋到不行，但在线峰值仍破万。那个号早期被泄露过，现在流传版本早已升级。

# 第三章 操作方法
核心逻辑：主播躺着假睡，在指定区域提示用户刷什么礼物可触发音效、灯光、动作、台词或道具。
为省人力，采用程序控制设备，无法控制的由主播或幕后运营补位。
## 3.1 软件
1）直播互动系统，或安排人工操控，区别是多一个人力和玩法丰富度；
2）直播用手机与互动系统需连接外网；
## 3.2 硬件
1）直播手机：iPhone 11以上，美版优先；
2）背景：雷电灯或烟花灯；
3）烟雾机；
4）泡泡机；
5）星空投影灯；
6）跳舞仙人掌，可选；
7）信息板：LED电子板、电视或KT板，说明礼物对应效果；
8）音响/声卡，接电脑播放音效；
9）电脑，跑程序；
10）手机支架；
11）耳塞、眼罩，可选，保护听力视力；
12）运营小号手机：iPhone 7以上；
13）面具、假发、义乳，可选。
## 3.3 辅助
床、枕头、被子、抱枕、毛绒玩具、充气锤。
## 3.4 运营思路
1、要批量复制，必须快速起号，先过新手和算法漏斗，把流量推向全球。
2、要打赏，必须持续刺激爽点，靠道具和表演。
3、要留时、要刷礼、要点赞，早期小礼物要丰富，后期可抬价。互动靠肢体和道具，越夸张越兴奋。可制造槽点话题给用户发声。观众爽点被拉高后，旧动作就失效。全球流量足够，人多不缺傻子。
# 第四章 为何值得做
从15年入行看，直播平台基本都从语音、秀场类内容起量，再做电商和广告。电商、广告是第二阶段，是平台变现手段。TikTok 公会招代理为何低调？因为平台想握住流量。
抖音早期流量大、商业化浅，那时不能盲从平台指令，要看清阶段。现在 TikTok 也在类似位置。对大多数想变现的人，娱乐直播是最快拿到结果的方向。参照国内发展，娱乐的红利至少还有两年，这两年不必深度挖掘一个项目，就能赚一桶金。点大屏、睡播目前仍是草稿阶段，草稿收益已如此，有开发和复制能力的人想象空间更大。
# 第五章 新娱乐项目的开发思路
看、拆、测。
看：国内外直播都要刷，国内玩烂的梗老外可能没见过。
拆：像拆App一样拆直播间，先看能否盈利，再看能否像素级复刻。拆够了自然有方法论。
测：MVP快速验证。

# 第七章 问答
Q：为何不做无人直播？
做过，3月测过，当时硬改手机少，Live Studio 不普及，折腾很久才用上。后来放弃，因对抗平台太累，我不做知识付费，娱播上线后搁置。无人能做，能玩多久看对抗能力。以后可能试半无人，参考抖音。
Q：为何不做店群？
做过，早期玩过几个英区店，没做东南亚因利润低，新加坡马来还行但拥挤。几家店被封，资金不足谈不到账期，抗风险能力弱，就放弃。
Q：娱播能做吗，有固定套路吗？
看你资源。在 TikTok 卖大牌通货，你拼得过工厂、渠道、品牌和资本吗？成年人别二选一，现金流和长线都要。我的经验是1+1+1：一条线赚钱，一条线开发，一条线做知识服务。知识服务我一直不收费用，导致身边人免费复制，很多间跟我无关。免费流量不稳，靠运营。项目生命周期2-6个月，不升级就死，所以要可复制、快速执行，门槛越高越好，看团队配置。
Q：一个睡播间成本多少？
手机2200，电脑3000，🪜100-2000，支架50，音响50，小道具500-600，床褥另算。
Q：不露脸可行吗？
可以。但没有脸，你的优势是什么？外语、唱歌、绘画、魔术、游戏，放得开吗？有特点就能用。
Q：国内主播转过来行吗？
非常行。镜头前不怯场，已超过99%的人。欢迎一起玩。
