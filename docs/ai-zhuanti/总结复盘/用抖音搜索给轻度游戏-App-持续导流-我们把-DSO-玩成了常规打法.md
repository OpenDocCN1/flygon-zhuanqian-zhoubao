**什么是 DSO**
抖音搜索优化，Douin Search Optimization
标准路径大概是这样：选词 -> 内容覆盖 -> 排名提升 -> 点击率打磨 -> 完播停留互动 -> 引导动作 -> 最终转化
**流量争抢分两层**
第一层是头部大词。这些词搜索量大，一上榜就能吃到大量自然搜，但盯的人也多，竞争最激烈。一旦守住排名，后续维护成本相对低。
第二层是靠新鲜度上位。抖音搜索对新发内容有短期权重加成，优质新视频很容易挤进相关词的前排。所以想长期占据核心词 TOP3-TOP5，就得持续上新保持活跃。
**第二条路是铺长尾**，这才是 DSO 的基本盘。长尾词单词量小、竞争弱，单条产出门槛低。用海量内容批量覆盖，把上万个小词都守在靠前位置，流量就会累积起来。哪怕一个词一天只带来1个精准用户，积1万个词就是1万/天，体量非常可观。^_

**搜索流量这几个点要记住**
1. 长尾词总量巨大，累积起来是稳定且低竞争的流量池
2. 自然排名目前以未登录 PC 端为准，手机端会有广告位且会千人千面
3. 新发内容有短期权重红利，容易把老视频顶下去
4. 合集本身权重集中，很多词第一位就是合集
5. 粉丝量不直接决定初始权重，但大号初始播放和互动更好，会间接影响搜索权重
6. 用 Dou+ 冲近期互动数据，能帮助提升搜索排序
7. 搜索结果前三名的流量占比超80%，内部大致按7:2:1分配![](img/f47527b17f25de991f51ae147c002a32.png "None")
8. 排名周期一般是1-10天上位，高热词波动大，7-14天后权重自然衰减，除非数据持续优秀
9. 内容质量分是硬门槛，质量差基本没机会
10. 同一画面、同一镜头反复用会拉低表现
