# 赚钱第二年，我把自媒体收益做到了怎样的水平

各位赚钱的伙伴大家好，我是龙哥。如今加入赚钱已满两年，上一次复盘距今正好一年。赶在续费的关键时间点，我想把过去12个月在自媒体这条路上走过的弯路和收获做个梳理，也向圈里的朋友们同步一下项目进展。表达可能不够精炼，还请多多包涵。先把去年的回顾放这里方便衔接。

回顾去年的主题定调，这一年粉丝增速没有爆发式增长，小红书单站目前维持在不到4万的体量，商业报价已涨到单条8000元，公开的广告合作超过100条，背地里的合作另算。定位家居领域，品牌方投放以产品置换为主，家里常用的家电家具基本都是免费拿到，几乎零成本使用。

除了主阵地之外，我也在做内容复用。同一段素材投放到全网，累计粉丝已突破10万+，变现效果还算稳健。到现在算是摸索出一套适合自己的生存打法。

# 全渠道分发的底层打法

我用的是 3×3 测试框架来做决策。

## 平台挑选中看三点

*   流量扶持方向，是否正在倾斜新兴内容赛道

*   商业化路径是否通畅，比如广告、带货、平台补贴

*   账户受众是否与我的内容人群重叠

## 内容迭代分三步走

*   初测分发，看自然流量反馈

*   数据验证，锁定播放能稳定破2000的平台

*   深耕运营，为每个平台建立独立的内容产线

## 收益结构分三个层面

*   直接收入：平台分成与带货佣金

*   间接收益：品牌资源沉淀与供应链置换

*   长期价值：搜索权重累积与私域导流

# 那“鱼”到底养在哪几个池子里？

以我自己为例，主战场仍是小红书，但我更擅长做短视频。那我就去找国内以短视频为主的阵地：抖音、快手、B站。再看哪些平台正在做内容扩张，得物、淘宝逛逛、支付宝生活号、百家号、爱奇艺、美团等都在往这块倾斜。

先把作品批量上架，观察平台反馈。一旦某个平台播放表现不错，就拆解视频的结构和脚本，尝试二创混剪或重新实拍。在完成全平台测试并验证收益后，我会建议大家除了主流平台外，优先布局下面这几类收益高且竞争相对小的垂类渠道，基本适用于所有赛道。

# 【四个被低估的高价值平台实操拆解】

## 一、得物

![](img/zhuanqian_f759195d5da3032e8c845123b673e02e.png)

• 流量与变现逻辑：双瀑布流推荐机制 + 视频号独立流量池

*   创作者激励，CPM大约在15-20元区间

*   品牌种草直投，广告单价大概是粉丝量的10%

*   平台福利包，年度购物券能省不少开销

![](img/zhuanqian_e21704102e08a91facd707009a924a49.png)

• 实操建议：

*   主推 3:4 竖版视频格式

*   平台正在大力扶持 AI 内容，做 AI 方向的可以同步跟进

*   提前与品类运营建立联系

## 二、百家号

• 收入构成：

*   流量分成，千次播放约3-5元

*   带货抽佣，家居品类平均转化约1.2%

*   星图接单，腰部账号月均5-8条任务 • 运营要点：

*   做知识付费专栏沉淀长尾

*   搭建 SEO 关键词矩阵

*   积极参与平台话题补贴活动

![](img/zhuanqian_d5010258eceeb0ea3bbc43409a09fd04.png)

千播收益不算顶尖，但胜在可批量矩阵化生产。

## 3. 淘宝逛逛

• 现状观察：

*   混剪类内容过审率能到85%以上

*   千次播放收益在0.5-1元左右

*   隐性价值在于导流，实测能为店铺带来约15%的自然流量增量 • 优化方向：

*   在视频中植入商品卡实现智能推荐

*   与品牌会员体系打通

*   参加逛逛造物节等平台 IP 活动

## 4. 支付宝生活号

• 收益模型：

*   独家流量补贴，CPM可达50元以上

*   本地生活分佣，餐饮酒店类目8-12%

*   商家代运营，年度框架合作20万起 • 避坑提示：

*   MCN 签约模式要慎重，自主运营实测收益高出约30%

*   内容重点放在生活服务类

这个平台我在去年的风向标里提过，强烈建议每个创作者去研究。千播收益非常可观，我上一年单号播放收益超10W+，正是被签约坑了一把，才提醒大家避雷。自主申请分成计划的流程见下图。
