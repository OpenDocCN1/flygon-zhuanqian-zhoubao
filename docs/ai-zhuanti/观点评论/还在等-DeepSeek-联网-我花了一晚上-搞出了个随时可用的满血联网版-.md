### 第三步：搭建你自己的智能体

模型搞定，接下来是最有意思的部分——拼积木。

![](img/zhuanqian_755d741aa82e825c931cfb1f718072a2.png)

想好一个霸气或者好记的名字，给你的联网版 R1 先署名。

![](img/zhuanqian_41bf2fced46e50efb4303a5fc96cd494.png)

进入配置后台，左侧菜单点“工作流”→ 添加。

![](img/zhuanqian_5fdc5369982456c536e72822286cfeff.png)

注意，这次我们要建的是“对话流”。

过去我写智能体教程，用的都是普通工作流，这次为啥换成对话流？

区别其实不难理解：

- **对话流**是专门为聊天场景设计的，能记住历史聊天记录，上下文连贯，适合做 AI 客服或对话助手。

- **普通工作流**更像一条流水线，适合处理那种按部就班的任务，比如批量导数据、生成报表、做图之类。

![](img/zhuanqian_084b7f030391f1519f86310f7845057e.png)

![](img/zhuanqian_f3dd27a9affee18c24f57fb9f8fc41a7.png)

下面这张图是我提前调好的完整流程，每个节点我都会展开说。

![](img/zhuanqian_3fb00fbfb34544822fae4a7c2c6b0969.png)

**节点一：开始节点**，不用动，默认就行。

![](img/zhuanqian_1e45d544f0ae6c6c003be2e04b8499f0.png)

**节点二：关键词提取**。我在这里用的是豆包大模型，让它扮演一个“关键词提炼专家”。

为什么要多此一举？因为人提问喜欢说一长串大白话，但搜索引擎更爱干净、精准的关键词。

我用的是一套最省事儿的“关键词组合法”。

打个比方，用户问“今年春节档票房最高的电影是哪一部？”，豆包就会把它压缩成：“今年春节档 票房最高 电影”。

![](img/zhuanqian_a8595e0745cd207bebae06f10dbf4e35.png)

提示词长这样：

```
# 角色
你是一位问题关键词提取专家，擅长从用户的问题中提炼出最合适的搜索关键词。
# 目标
你的目标是提取最能代表问题核心的信息，以提高搜索引擎的查询效率。
# 规则
1\. 保留问题中的核心概念和限定词
2\. 去除无关紧要的停用词（如“的”“是”“怎么样”）
3\. 优先选择可直接用于搜索的高效短语
4\. 确保关键词具备查询价值，并且尽量匹配搜索引擎的检索习惯
5\. 如有必要，可提供多个关键词组合
# 示例
## 示例1
用户输入：如何优化网站的 SEO 排名？
提取关键词：网站优化 SEO 排名 搜索引擎优化
## 示例2
用户输入：怎么修复 Windows 蓝屏错误
提取关键词：Windows 蓝屏修复方法
```

用户提示词如下：

```
根据用户问题：{{input}}，从中提炼出问题的关键词
```

之前我也写过几篇讲搜索技巧的文章，不同平台玩法不一样，感兴趣可以翻回去看看。

这里肯定有人要问：推理模型提示词不是越简单越好吗？为啥你写这么长？为啥不用 R1 自己来提取关键词，非要拉豆包？

问得好。但它不是所有活儿都适合干——

**推理模型强是真强，慢也是真慢，贵也是真贵。**

真正的项目里，成本和延迟得精打细算。

所以，像“提关键词”这种简单任务，我照样用普通大模型，而且别嫌啰嗦，把要求、示例都写清楚，效果最稳。

**节点三：必应搜索**。把刚提炼出的关键词丢给必应插件，实时联网搜索。

![](img/zhuanqian_6a137d7d1258b24e8c1ef70282c73015.png)

**节点四：DeepSeek R1 登场**。先在节点里选中我们刚开通的 R1 模型，把必应搜索结果的“webpages”内容和开始节点里用户的原始提问当成输入信息。

这里千万别忘了把提示词里的信息源锁死在网页搜索结果上。

提示词：

```
请参考网页搜索结果，回答用户的问题。
用户问题：{{input}}
网页搜索结果：{{webpages}}
```

![](img/zhuanqian_6ad0b5d7c673087410810ccba51a7f3a.png)

**结尾节点**：配置相当省事，把 DeepSeek R1 的输出结果原样放出来即可。

但记得给回答打开“流式输出”，这样回复就像打字机一样一个字一个字往外蹦，观感舒服很多。

![](img/zhuanqian_4dbd99ec411932ea5018d7a6fd4bb536.png)

写完了先跑一遍测试，看看有没有报错。

![](img/zhuanqian_75337fe3e682c9f1e468f23aaa93c175.png)

测试通过，右上角点击“发布工作流”。

![](img/zhuanqian_8d48d13a3a9b584ba7808fe5fbee0213.png)

发布成功后会弹窗提示，点确认，工作流就自动跟 Bot 绑在一块了。

![](img/zhuanqian_363464607ab0d926bac69c652c40d8b5.png)

接下来按需给智能体设定人设提示词，我这块没搞复杂，就强调了一件事：**每次都调用工作流**，确保答每个问题前都走 R1 + 联网搜索这条链路。

![](img/zhuanqian_a137e7b7d9845b79772f3e57332d584f.png)

填好发布信息、勾选分发平台，最后确认发布，搞定。

如果只是想自己用或者分享给朋友，不公开上线也没问题。

![](img/zhuanqian_90f97cd186813169d0a965a61969d268.png)
