# 摆脱内卷的真相：不是更努力，而是先把对手淘汰掉

最近重温了李笑来在《李笑来谈 AI 时代的家庭教育》里的一个观点，对“竞争”这件事有了更清楚的认识，也聊到怎么跳出内卷的怪圈。

很多人觉得现在到处都在卷，卷到喘不过气。说到底，竞争之所以显得“你死我活”，无非是两件事叠加：一是名额、资源就那么多；二是大家水平差不多。

以考公为例，岗位是固定的，报名人数却成几何级数增长，资源稀缺自然就卷。但更致命的是，考生之间实力差距不大，谁都觉得自己有机会，所以才打得这么凶。反过来，如果你本来就强到没人能追，就谈不上竞争了。

资源总量我们改不了，那是社会层面的事。但势均力敌这个状态，我们可以主动打破。怎么做？其实答案很朴实：把自己做成少数派，让实力碾压大多数人。

李笑来给出的路径是：不管干什么，就踏踏实实、专心致志地做下去，时间拉长。听起来粗暴，其实就是一种很高级的避战战术，甚至是降维打击。因为绝大多数人撑不住诱惑，会把精力耗在无意义的短线厮杀里。

他原话是这样说的：专心致志，本质上是一种避开竞争乃至超越竞争的做法。拿金融市场举例，长期持有就是一种典型的避战策略。大多数人等不及，看不到复利的乐趣，总想频繁进出，最后只能跟一帮同样频繁交易的对手玩零和博弈。

那到底要坚持多久？李笑来的经验是，三到五年，通常就已经筛掉绝大部分对手了。关键是选对战场，要选那种越做越有复利、有积累效应的事。

什么是积累？健身越练体能越好，读书越多脑子越快，写作写得越久，越写越顺、越写越快。举个例子，有人从2003年起就开始持续写公众号，十年下来，文章质量明显提升，产出效率是十年前三到五倍。如今每天花半小时就能在读书群里输出500到1000字的干货，而且全靠自己。

反过来，什么事没有积累？比如那些东奔西跑的应酬饭局，时间用完了，技能没增长，人脉也没有沉淀，纯粹消耗。控制这类无效社交，就是在为自己的长期专注腾空间。

所以摆脱内卷的逻辑很清晰：不去跟所有人同台竞技，而是选一条有复利的赛道，然后比别人更早、更久地待下去。用时间做壁垒，等大多数人自己掉队了，你自然就站上去了。
