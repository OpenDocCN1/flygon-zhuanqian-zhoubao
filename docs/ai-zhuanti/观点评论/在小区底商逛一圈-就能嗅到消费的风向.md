# 在小区底商逛一圈，就能嗅到消费的风向

上个周末我顺着自家楼下的商业街溜达了一圈，几家常年驻扎的小店状态变化挺有意思，聊聊我看到的信号。

第一家是那家我老婆充了两千多元会员的理发店，直接关门了。说实话，我早就觉得它撑不久，每逢周末去，店里冷冷清清。但店长话术确实在线，硬是把卡卖了出去。好在老板还算厚道，关店前把我们的余额帮我们平移到对面小区的一家门店里，距离也不算远。

第二家是百年义利的面包店，其实早就有点像社区小便利店的样子。这类以面包为主，顺带卖北冰洋、江米条这些老北京零食的业态，疫情期间靠着刚需勉强活下来，疫情后就显得很尴尬了，关门也在意料之中。

第三家是开了四五年的精品咖啡店 Craftcoffee。它没关，但做了个大动作：把门店三分之一的面积割出来，租给了AI学习体验中心。精品咖啡本来就不是靠翻台率吃饭的生意，大面积、重装修、卖高价豆，长期做下来没有网红流量基本很难自负盈亏。我猜它从开业开始可能就没怎么真正赚到钱。

第四个变化是增量。短短一年里，小区里多了两家健身私教工作室，我特意进去问了问，客流居然很稳定。我们小区本身就偏高端，周边还有几个写字楼，中午和下班后是他们最忙的时候。

把这几件事拼起来看就很清晰了。理发、面包、精品咖啡这类传统生活服务和轻餐饮，整体在收缩，客单价高、依赖办卡复购的模式正被淘汰。而运动赛道确实是这几年为数不多的真成长板块了，健身、私教、羽毛球、户外骑行这些需求在持续放量。

顺便聊两家我觉得靠谱的代表。理发这块，可以看优剪，全国门店规模最大，超过1800家，核心打法是不推销、不办卡。健身这块，可以看乐刻运动，也是全国门店数第一，同样坚持不办卡的模式。
