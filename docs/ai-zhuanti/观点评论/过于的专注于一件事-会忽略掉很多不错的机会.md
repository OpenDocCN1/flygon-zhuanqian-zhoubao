# 过于的专注于一件事，会忽略掉很多不错的机会

你有没有发现：当一个人只盯着手头那件事，其他不错的机会往往会从余光里悄悄溜走？这个道理，放到个人赚钱和公司战略上都成立，而我也是花了好几年才真正想明白。

把时间拉回 2014、2015 年。那时我已经隐约感到，人工智能会越来越热，于是脑子里冒出一个点子：既然 .ai 域名会因为 AI 浪潮而水涨船高，那我为什么不提前用工具批量扫一遍那些还没被注册的“关键词+ai”域名？先囤下来，等有需要的人来接盘，这门生意的赔率可以说相当可观。后来的事你也看到了，.ai 域名确实成了香饽饽，满大街的网站都在用。

但说实话，我当年并没有动手做。以前我总觉得，这怪自己执行力不够，一个那么好的机会摆在眼前，怎么就让它溜了？不过这两年再回头看，我慢慢意识到，问题的根源不在执行力，而在认知。

为什么说是认知？因为我对那件事只是一知半解，既没花足够的时间去搜集信息，也没认真判断过它的价值。这样下来，我既拿不定主意，也不敢下重注——包括押上大量时间。可话又说回来，谁也不是天生就能看透一个新事物，只要你愿意投入时间，理解完全可以做得非常深。我最后缺的是什么？时间。时间都去哪儿了？都被眼前那件“正在做的事”给占满了。

这件事给我敲了一个很响的警钟。从赚钱的角度看，如果过于专注单一事务，比如前几年我几乎把全部心思都放在龙哥盟上，那就会自动屏蔽掉大量潜在的好机会，这本身是一个巨大的风险。

所以这一两年，我会有意识地把自己从系统里拔出来，去搭建一个能让自己越来越清闲的系统。我还定过一个目标：未来每周只要在龙哥盟上花两天时间就够。为什么非要让自己闲下来？因为只有真正闲了，你才有空去打量外面的机会，才能静下心做研究、做判断，才敢出手，甚至下重注。

而对于龙哥盟来说，最核心的使命是什么？就是在别人都还没看到的时候，有人能看到那个机会，然后带动大家重视起来，带着大家一块儿进去。

说到底，个体的财富战略也好，公司的战略布局也好，都离不开两件事：一边脚踏实地走好眼前的路，一边随时抬头望向更远的天。
