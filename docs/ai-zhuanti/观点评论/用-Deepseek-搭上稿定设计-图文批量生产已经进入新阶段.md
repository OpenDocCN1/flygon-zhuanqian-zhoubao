## Deepseek 联合稿定设计做批量优质图文，人机博弈的时代真的到了

作者：龙哥

日期：2025-02-20

今天把我最近在用的组合玩法拆开说一下，就是 Deepseek 加上稿定设计来做图文的批量化生产，效率高到有点夸张。现在已经是人机混战的阶段了，想在一众内容里不掉队，就得先把工具链跑通。

把稿定设计和 Deepseek 串起来做海量产出，速度完全不是手工可比的。

**1、先在稿定设计里定好模具**

稿定设计入口：[`www.gaoding.com/`](https://www.gaoding.com)

挑一个自己看着顺眼的排版模版，先收入自己的工作区，接着点开批量套图功能。

![](img/3dc81af1059ca4863cff70d83155c9d5.png "None")

等系统把默认字段识别完，点击下一步，数据结构就会更精准，这时把数据模版下载下来，解压后能得到一个 Excel 文件。

![](img/36cc819dfd627226e8a7af79d1fdf03b.png "None")

![](img/cf9eecaaf15d22cb1b71d73a078b303c.png "None")

![](img/4e7136899dc4b8ade0de6b3daa8c3144.png "None")

拿到表格后，切换到 Deepseek 的对话窗口。打开 R1 深度思考模式，关闭联网检索，把刚才的表格模板直接丢进去，告诉模型你的具体用途，并说明输出要对齐什么格式即可。

把任务丢给 Deepseek 让它去填内容。

我实测比较顺手的提示词是这样的=“请依据这个 Excel 模版，帮我生成 3 套全新的英语单词教学内容，要拿去做教学用，保持截图的排版方式。表格字段是“页面 文本_1 文本_2 文本_3 文本_4 文本_5 文本_6 页面 1 教你一看就会的 记单词 cow + boy = cowboy 奶牛 男孩 牧童 rain + coat = raincoat 雨 外套 雨衣”，注意空格处要换成 \t\t？”

关于排版细节，建议自己多试几次微调，本文主要是抛一个思路。

![](img/be335145b6f54d5df7fb02a26b9d6eaf.png "None")

![](img/770ea66dcbdb2c1d29247ace2d74b9c4.png "None")

按这个流程跑下来，就能得到一份可以直接用的数据表。实际使用时可能还需要手动微调，毕竟这篇是抽空写的，没做到手把手的精细度。

如果发现 Deepseek 官方版响应很慢，可以考虑切到 API 版本，回复速度会快很多，官方偶尔会卡死。

**3、收尾**

这篇文章写得比较赶，细节部分可以去稿定设计官网，或者在抖音、小红书搜相关关键词，已经有很多创作者在讲类似套路了。现在不跟上技术节奏，很容易被拉开差距。

我自己在 24 年 2 月左右就开始用 AI 结合 GPT 做图文的大量输出。早早就判断这类工作会被平台化、自动化，现在应验了。

人机会战不可避免，最后比拼的是思维方式、信息获取能力以及能走量的工具组合。
