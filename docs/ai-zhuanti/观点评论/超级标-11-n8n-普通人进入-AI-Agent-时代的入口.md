# 超级标 11：n8n，普通人进入 AI Agent 时代的入口
上个月我在星球里做了一次摸底，问大家接下来最想啃的硬核技能是什么。排第一的答案出乎很多人意料——不是提示词，不是 Midjourney，而是 n8n、coze、AI 工作流。
我的判断很直白：通用大模型是巨头们的战场，跟我们没关系。真正的金矿在无数垂直细分场景里，那里需要大量 Agent 去填坑。这恰恰是普通人、蚂蚁雄兵能起飞的地方。
现在的 AI Agent 已经能把「有想法 → 生成内容 → 发布分发 → 营销转化」这条链路完全跑通，质量不输大部分人类创作者，而且成本能压到接近零。过去要人手盯着的环节，现在机器自己判断、自己执行。
越是来自实战沉淀的垂直工作流，价值越高，也越容易进化成可复用的 AI Agent。我自己就花了五位数买过一条 n8n 工作流来拆解学习，超级术里推荐的那两篇干货也都指向自动化。结合我对赚钱圈友的观察，接下来值得深耕的 AI 分成三块：
第一块，用 AI 造产品，网站、App、小程序。AI 做 Web 这条线我们现在已经带着一批人在实操突破。
第二块，用 AI 造内容，文字、图片、音频、视频、数字人、直播。这一块里最有爆发力的当属视频，我们从去年开始带大家做 YouTube，星球里不少人已经做出来稳定收入，有几位直接月入过万美金。
第三块，就是连接前两块的底座——工作流自动化。搭建门槛不高，不需要编程背景，搭起来之后下一步就是 Agent。
毫不夸张地说，未来最值钱的能力之一，就是能把业务流程变成自动化工作流的能力。围绕这个能力的工具组合，目前来看是国外的 n8n、国内的 coze，再加上 rpa。今天就重点聊 n8n。
**1/ 为什么是现在？**
过去的工作流只是「机械的手」，见到需要判断的点就卡壳，必须人工介入。现在 AI 的判断力在很多场景已经不输人，甚至超出。AI 的接入能力也决定了上限：n8n 能直接调用 Claude、Gemini、ChatGPT 等顶级模型作为大脑，而国内很多产品出于政策原因只能闭环在自家模型里。你愿意用工作流调顶级模型还是被限定在单一生态？
拿我买的那条 n8n 工作流举例，输入一个点子，一键就能跑完脚本撰写、配图生成、素材存储、视频合成、配音、自动上传 YouTube。背后是多款软件通过接口协同完成，这在国内割裂的生态里很难实现。
当然，国内自成体系也有机会。之前国平老师分享的小红书案例就很典型：自动识别评论里的意向用户 → 定向私信引流到微信 → 根据用户画像生成个性化话术引导成交，最终成交一套房。这种深度集成的闭环，价值同样可观。
**2/ 目前集中爆发的六大场景**
内容生产：AI+流程批量生成文章、脚本、视频、图像。
电商营销：自动生成图册、换模特图、AI 详情页、包装图替换。
数据处理：内容结构化、文本提取、信息分析，比如把小红书、B 站内容抽取整理成表格，@富贵那篇帖子就是代表。
分发同步：生成结果自动发布到多维表格、微信、YouTube 等平台。
智能接入：Coze 智能体接入、AI 客服、把工具封装成微信小程序。
全链路创作：从选题到成片的流水线作业。
说白了，只要你能把自己的工作流程梳理清楚，就能复制给机器。从产品开发到内容创作到流量获取，核心都是工作流。每一次爆款背后都是一个定制的工作流。
为什么做 YouTube 的圈友能在达人秀、山海经、动物救援、Reddit 故事这些赛道持续吃肉？因为他们把爆款识别和内容生产自动化了。能识别爆款并把它固化成工作流，你就掌握了财富密码。

这就是半自动化、自动化的魅力。
**4/ 怎么切入**
n8n 的社区生态极强，起步阶段完全免费，市面上大量现成的工作流可以拿来改、学、拆。收集能力强的话能挖到上千条营销相关模板。
具体的四个切入点：
a. 为中小企业、创业团队提供「自动化顾问+代建」。客服、财务报表、跨境电商、AI 内容生产，这些团队缺技术但有需求。单次收费几千到几万，闲鱼、Reddit、Fiverr、Upwork 上已经有人在卖。
b. 聚焦营销增长、短视频营销、AI 写作、AI 生成朋友圈、AI 客服、社群运营、内容分发等高频场景的工作流。
c. 把成熟工作流封装成订阅制产品。很多圈友现在在做出海 AI 产品，本质上就是在卖工作流，只是不自知。
d. 国内 n8n 研究还很早期，赚钱星球的内容已经算前沿，但和国外社区还有差距。做研究、拆解、分享，未来商业化路径清晰：咨询、定制、企业培训。
**5/ n8n 和 coze 的选择**
我把这条标定为 n8n，是因为我想让更多人去赚美金。如果你业务在国内，coze+飞书多维表格+rpa 的组合会更顺滑。上面说的所有机会，对 coze 同样适用。
如果这期航海的选题你留意了，会发现 n8n、coze+多维表格都在清单里。这不是巧合。
把工作流搭好，就是把你的时间变现。
