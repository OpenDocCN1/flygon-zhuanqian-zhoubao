# 抖音同款宝宝写真绘本爆了，19.9 一本卖出 3.2 万本，AI 模板+一键换脸就能复制
前两天在抖音刷到一条很会做父母人心的产品：把宝宝自己的头像嵌进绘本里做成定制版，一本只要 19.9，销量已经冲到 3.2 万。
我也忍不住用自己家娃的照片试了一单。付款后直接跳转到小程序，把宝宝的一张正脸照上传上去，系统秒级抠图生成大头头像，然后实时预览这个头像会在绘本每一页里出现的样子。整个过程几乎零门槛。
这个玩法让我瞬间想到一个可复制的变现逻辑：用 AI 做好固定的绘本故事模板，再嫁接一个自动抠图的人脸替换小程序。模板是一次性沉淀的成本，个性化只是在每本里换一张脸。
AI 绘本的标准化模板 + 用户自己的照片定制 = 高情感价值、低制作成本。尤其是宝妈群体，对孩子相关的纪念类产品几乎没有抵抗力，19.9 的价格更是很难让人拒绝。
