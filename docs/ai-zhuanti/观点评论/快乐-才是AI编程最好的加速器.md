# 快乐，才是AI编程最好的加速器

大家好，我是龙哥。

最近龙哥那边有消息说，大概9月份就会为AI产品铺路。在这个时间窗口到来之前，我真心建议你把AI编程学起来。为什么我敢这么说？因为我和绝大多数新手一样——看不懂代码，也听不懂英语，在这两道门槛前挣扎过不知道多少个来回。所以我很清楚，学习如果只有痛苦是不可能坚持的，它应当是快乐的、好玩儿的。我会告诉你我摸索出来的那套快乐学习法，等龙哥把路铺好了，你恰好能借势跑得更远。

## 工具选得好，弯路走得少

先说你最关心的：买哪两个会员就够了？我强烈推荐ChatGPT和Trae国际版。

ChatGPT：https://chatgpt.com/

Trae：https://www.trae.ai/

新手最需要的是什么？是大量的练手机会，同时还得考虑钱包的感受。ChatGPT一个月差不多55块（苹果手机切尼日利亚区礼品卡支付就是这价，礼品卡在闲鱼就有，星球里有现成的教程帖），Trae首月只要3美元，配两三个谷歌账号，一路陪你撑过新手期完全够用。

加起来一个月77块，除此之外，我不建议你再买任何会员了。真不是心疼钱——市面上所有叫得上名号的AI编程工具我基本都试过，上千块的学费早就交过了。这些AI产品目前没有一个值得你掏年费。说白了，现在的AI工具是在让你参与它们的迭代过程，哪怕你什么都没做出来，钱照样收，模型倒是被你的反馈喂肥了。而你自己能不能做出一个换得来钱的东西，那就是另一码事了。

记住：钱是买结果的，不是买过程的。找合伙人、招聘员工，同理。凡是背离这个原则的决定，本质都是赌博——赌一个不会来的未来。

更何况，小白拿AI编程做产品，不确定性只会更高。

## 先选路线，再谈努力

走SEO路线，核心就两件事：找词，以及把技术接上。

走产品路线，是找到一群具体的人，用一种极其优雅的方式解决他们的麻烦，保证体验丝滑到没有卡顿。但这底下的功夫是洞察、技术、审美和推广的综合，这里先不展开。

路线定下来之后，就持续打磨对应能力，把商业版图一块块补完整，直到拼图彻底成形。

## AI编程，零基础也能轻松上路

这里我想强调：技术你要学一点，但目标是“知道它是干什么、怎么用”，而不是成为大神。有这个底子之后，你才能和AI顺畅对话——毕竟你是要借AI的手去写代码，得尽可能用“行话”来对齐彼此的认知。你给的词越精准，AI越懂你。反过来就惨了，鸡同鸭讲，越调越上火，改到最后人麻了，直接弃坑。我有一阵子就是这样。后来专门回去修炼了一波“内功”，才发现几行简单的技术就能做出很惊艳的页面，从那以后学习的热情一下就点燃了。

小排老师推荐的清单是：HTML、CSS、JS、Tailwind、Nextjs、shadcn/ui。后面还会用到登录、数据库、支付一类的东西，对应的是Supabase和Creem。

我还特意规划了一条不太累的学习路线，核心就两个角色：AI私教 + CV工程师（对，就是复制粘贴工程师）。按这条路走，保证努力学习的你能完整走完全流程。

先说怎么拥有你的AI私教。你需要一个GPT会员——当然不开也行，GPT4o还是能用的，只是回复额度很快会触及天花板。

接下来大部分学习，都在这个对话界面里完成。

所以第一句该怎么跟AI说？我建议这样开头（为了方便你复制，关键对话我都会用代码块的形式写在下面）：

```
你好，我是编程小白，想做AI工具站，现在AI编程很火，有cursor、claude code、augment等AI编程工具，都可以借此加速开发网站进度，但是对于一个小白来说，还是需要自己懂技术，才能最大程度发挥出AI编程应有的能力，因此，我想系统的学习编程语言，知道什么技术可以做什么，我希望你担任我的AI编程老师，为我传道解惑，启发我，知道怎么和AI对话来完成编程任务。我希望你用XXX的语气教我。
```

想让学习过程更有意思，你还可以给它设定一个人设和语气。像我就搭配了一位“国学老师”，学东西嘛，先让自己舒服了，才能真正享受这个过程。

### 前端，从零破土

继续往下聊：

```
我要从头开始学，请你给我讲透，一次性不要讲太多，而是让我明白原理，和怎么使用
```

接着你会收到类似下面这种风格的入门讲义：

今日之课：HTML 为何物？

吾曰：HTML，乃网页之骨也。有骨，方能添肉（CSS）、注魂（JS）。今先识骨，后学肌理。

一、HTML：超文本标记语言（HyperText Markup Language）

📖 原理浅述：

HTML并非编程语言，而是“标记语言”，它的使命是“告诉浏览器这个网页的结构和内容”。好比写奏章要有格式——标题、正文、落款，HTML用标签把页面骨架标得明明白白。

二、HTML 结构总览（骨架图）

<title>我的AI工具站</title>

# 欢迎来到我的AI工具站

这里收录了我最喜欢的AI工具：

* ChatGPT

* Claude

* Cursor

* Augment

* Copilot

我们接着对话。

```
如果我要用AI编程去练习，我应该怎么和AI表达，才能做出想要的页面。
```

然后你应该会收到一句现成的“咒语”——赶紧复制，准备进入实战，开搞你的第一个网页。

```
请帮我用HTML和CSS写一个AI工具展示页，上面是一个大标题‘我的AI工具站’，下面是3个卡片并排展示，每张卡片包含图标、工具名、简介和一个蓝色按钮
```

打开Trae，把这句话原封不动甩给AI。

再送你一个做页面的万能技巧：当你拿不准自己说的AI编程能不能接住时，干脆别开口硬说。直接把解释权交给AI，用人话告诉GPT“我想做什么、想要什么效果”，然后请它帮你想：该怎么向AI编程表达才能精准命中？这活儿GPT很在行，它会生成一段指令，你只要复制粘贴，就能分分钟抄近道。

切忌跟AI编程拌嘴对骂。什么“你怎么不按我说的来”“我都说成这样了你还听不懂”——这种情绪输出偶尔能逼出一句正确的表达，但效率真的让人着急。我更推荐的，是借用翻译、复制粘贴，把自己送上快车道。在你还没组织好一句没有歧义的话之前，别在AI编程软件里随便开口。

到这一步，你要练的是举一反十、一通百通：先用大白话把自己的需求跟GPT讲透，再由GPT转述给AI编程。你在中间当个传话筒就好，CV工程师这门手艺，就这么练成了。

### 给产品一张好看的脸：UI/UX

光会代码还不够。真正留住用户的，不只是功能，还有体验。顺带吐槽一句：AI写的网页，十个里有九个都是蓝紫渐变，真的丑。所以UI/UX视觉这块，我提议你也补一补。

你完全可以像学编程那样，装成小白虚心讨教，这样说：

```
我想学习UI/UX视觉设计师的一些内容，丰富我的网站，但我是一个小白，请你担任我的老师，为我系统性讲解，是什么，有什么用，怎么用。目前我会AI编程。知道怎么和AI对话，能达到自己的预期。教我的时候请用XXX的语气与我对话。
```
