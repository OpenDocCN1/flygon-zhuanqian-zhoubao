# 开发拆解
## 1. 先把动作拆开
整个流程其实很清晰：
打开搜一搜搜公众号 -> 进入公众号主页 -> 滚动历史文章读取数据 -> 导出保存
这就是一个循环体，跑起来就能批量采集不同账号的数据。
## 2. 遇到的坑
第一个坑在搜一搜结果页。搜出来的账号不止一个，而且目标号经常不在第一位，不能傻乎乎默认点第一个。
所以得先做一轮元素识别，把账号名称做成变量传进去，精确定位到正确的账号对象上，这样才不会点错。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_5a4fea1b26057a7636170be7808e6c25.png>
第二个坑在历史文章页。目标数据有三个：发表日期、文章标题、阅读量。
我最初以为这三项是一个父容器包着，取完父级再拆子级就行。结果实际结构很散，完全不是同一个父级，甚至跨了好几层DOM。
没办法，只能分开抓。抓完之后还要对应上，这是最头疼的。最后的解法是记录每个元素在页面上的坐标位置，按位置排序，这样三项数据就能自动对齐了。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_a823bd29568e9d1afe2aa0c26b195fb5.png>
## 3. 调优细节
第一版跑通后才发现，Windows程序不像网页那么统一。Win10和Win11的界面控件结构有差异，同样一段逻辑在不同系统上会失效。于是又重做了几次适配，最终做到了双系统兼容。
另外为了使用更直观，我设计了双重保存机制。每个公众号单独生成一份表格，方便单独复盘；同时再汇总到一个总表里，所有账号的数据都在一个合集里，整体对比更方便。
# 源码怎么迁移到影刀
声明一下：这个迁移方法完全不改动影刀本身，只是复制粘贴文件，实现源码的转移。如有侵权联系我删。
因为影刀要看源码需要企业版，大部分人手里没有，所以分享这个曲线救国的办法，仅限学习交流，自己做更好的版本。
准备东西：
1. 安装好影刀
2. 已有的影刀程序代码包
## 1. 新建一个空壳程序
打开影刀，点击新建，选择 PC 自动化应用。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_52481a4d435136b49d1a8834746bbf38.png>
取个名字保存，就得到一个空白的程序项目。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_dfd4aa7a8f619d733dd4caf2f8657794.png>
## 2. 找到程序的本地目录
通过右侧的入口定位到程序的存储路径。这个路径就是你电脑本地保存的程序源文件。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_9c512bea97af8807498d1fc378988965.png>
进入对应的程序文件，找到 apps 文件夹，里面有一堆看似乱码的文件夹，它们就是各个程序的独立目录，文件夹名字就是程序的唯一标识，后续要用。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_202484d3fe2b66f47c7a1e160242cc0b.png>
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_cfc312e852cf3a972dc6bf6111eb36d1.png>
## 3. 替换源码
先去这个链接下载源码包：https://www.123pan.com/s/KtY7Vv-kQuzv.html
解压后找到 xbot_robot 目录里的 package.json，用记事本打开。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_e998845b3a32a15679f3f971069c6663.png>
把刚才新建程序对应的文件夹名称复制过来，替换掉文件里的 uuid 值，保存。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_e3156867e865d9fe3cc6fa9c645d6e6a.png>
然后把整个解压后的文件夹完整复制到你新建的程序目录下，保持层级一致，提示覆盖时直接覆盖。
## 4. 验证
打开影刀，回到你刚创建的程序，界面就能正常显示了，说明迁移成功，直接保存即可。
<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_ba7078bf4545d39de1337184d68415c1.png>
