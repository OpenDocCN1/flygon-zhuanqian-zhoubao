# 一、第一个号：KK神贴资料号
战绩：10天涨粉130，首篇笔记3w+阅读，导入两个500人群，变现400+
## 起号回顾
### 1、怎么来的想法
工作上被增长卡住，想找个副业试试。刚进赚钱时，看到很多副业项目第一反应是看不上，觉得有点low。985毕业，好歹一份体面工作，怎么去搞这些，后来被现实打脸，搞钱挺香。
群里一直在强调：先弄脏手，先拿到第一笔钱。
被@IDO老徐拉进赚钱后，手上摆着两个选择：美团圈圈和夸克拉新。我是社恐，朋友圈几乎不发，美团圈圈要拉人头，想想朋友会觉得我去传销了。所以选了公域的夸克拉新，没人认识我，压力小。
逻辑很简单：帮网盘拉新，一个用户5块钱。刚开始我也觉得这不就是砍一刀吗，太low了。后来真香。
当时没别的项目，就当练手。五一回家闲着，贯彻先弄脏手，先赚第一块钱的原则。
有人给了个小红书起号手册，说这个平台好上号。我就去试了。资料方向当时可选考证、英语、视频等，我都不熟。恰好群里有人在分享天涯神贴资料包，提到天涯社区永久关停是热点事件。我以前看过天涯KK大神写的地产预测贴，内容我熟悉。于是就定了做天涯KK神贴的小红书资料号。
赚钱里也有人说天涯帖子流量大，前端可结合夸克拉新变现，看着能赚钱就开干了。
### 2、实际操作
当时对小红书完全小白，基础认知就是模仿和抄。直接用一个老号发，甚至没养号，定位也还没想清楚。后来复盘发现其实走了养号-对标-像素级模仿-复盘迭代的路。

| 没准备好承接 | 精细化迭代 | 平台对抗 |

| 收益 | 收尾 |
| 拉了两个500人群 | 大概做到5月中旬，后续笔记审核越来越严，同行高赞贴也开始被封。KK神贴本身猎奇且有尺度问题，流量下滑明显，就停了 |
## 认知沉淀
### 1、先弄脏手，行动大于空想
对纯新人来说，先找个有流量红利的赛道上手，比看十遍教程强。我当时没看航海手册就上手，吃亏了，不然收入可能翻几倍。
别一开始纠结违规、工具、规划，要笔记完美了再发。我的第一篇就是先发再说，后面天天被警告、封笔记也照样干。先发第一篇，再慢慢优化。执行SOP和大佬教练在，不会就问，做了问题自然有解。
要先遇到问题，才有解决问题的能力。
### 2、爆过的选题会反复爆
爆过的东西会一直爆，我抄别人，别人抄我，大家都有流量。
### 3、你赚不到认知以外的钱
跟圈友@零一教练聊过，他做前端+后端变现，不免费送还能收费，我当时亏大了。据说还能用“资料整理不易，随意打赏”的话术，有老板直接打赏66块钱，就一个网盘链接。赚钱别有心理负担，你情我愿，别人愿意付费说明有价值。<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_6e9c2e44d0f04bf70bc0947c3ba71955.png>
当时小红书流量不行了算政策封禁，但抖音还能做。很多人抖音点赞上万，我模仿发了第一个视频，一天4000+播放，零星赞，没人要资料就放弃了。
我当时根本不知道抖音4000播放是什么概念，直到后来认真做抖音，我一篇都没上过4000。所以抖音还能再做，认知盲区真的赚不到钱。
认知在提升，初心也在变化。以前有人点赞我会很激动，现在已经很佛系了。见过更大的世界，才能驾驭更大的世界！
### 4、别人做大了，不代表没机会
我当时疑惑，这个项目有人赚了10万，还团队化运作，比如驴哥的AI绘画战队，那我还有机会吗？会不会流量被吃完？
互联网是推荐机制，几亿用户，100篇10w+也只是1000万用户知道。别人赚了就赶紧复制，别想别人做大了我没戏。这世界太参差了。

# 二、第二个号：AI绘画宠物赛道
战绩：30天内收入600元，粉丝1200，赞藏1.2w，跑通AI+绘画宠物赛道
## 起号回顾
详细过程我之前发过帖子，这里跳过。
## 认知沉淀
### 1、蹭热点要趁早
六一儿童节当天蹭，没流量。情人节当天蹭，没流量。端午节提前3天蹭，流量直接起飞，端午当天反而在降。
### 2、爆款会重复爆
端午火的划龙舟我一天发一篇，小号发也火。发了5篇，应该多发多开号把流量吃干。猫猫下雨天永远吃香，其他主题不行。
猫猫T台图一篇2w赞，跟进的笔记也能几千赞。小红书就是爆款逻辑，找到爆款就抄。
### 3、情绪价值 vs 实用价值
点赞多通常是情绪价值，收藏多是实用价值。不同号策略不同。
比如AI绘画要不要放Prompt？放了收藏会多。但内容决定粉丝是谁。你要吸引对MJ有研究的，放大Prompt；你要做面向小白的头像绘画号，就不要把Prompt放在台面上吸引同行。目标不同，笔记写法不同，吸引的用户也不同。
### 4、公域粉丝只是数字，私域才有价值
第二次错过流量才悟到，没沉淀私域的粉丝都是数字，没有价值。浪费了多少钱。
LTV用户生命周期价值，从获取到流失的全收益。必须沉淀到私域持续曝光、转化、复购。养宠人群高价值，沉淀下来发猫图+周边推荐能持续变现。
### 5、算投入产出比
后来我也放弃这个猫号了，心有余力不足。副业最终看ROI。
产出：金钱+认知+机会；投入：时间+资金+设备+机会成本。我的时薪=月薪/22/7，一小时做2-3张图，作图+沟通+交付+售后约1小时=90元，单靠作图跑不通。MJ月费、沟通成本不可控，ROI不划算。
猫号流量大但变现路径不清晰，产出比低。我原本想做矩阵+私域+猫IP，但我没产业链资源，也没绘画背景，对主业无助力。后来转向AIP和企业培训更合适。
### 6、耐心+迭代复盘
这个号30天才爆一篇。小眼睛不行，大概率内容质量问题。对标、找爆款、像素级模仿、找问题、迭代复盘，不会就问。小红书起号是可行的。
