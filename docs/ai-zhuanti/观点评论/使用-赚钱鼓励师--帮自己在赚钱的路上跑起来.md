# 使用「赚钱鼓励师」，帮自己在赚钱的路上跑起来
我把「赚钱鼓励师」做成了 Prompt，帮自己在赚钱路上跑起来
昨天龙哥老板给我发来一句话：有人在写一个叫「赚钱鼓励师」的东西，要不你来写个 Prompt？我听完觉得有意思，就动手试了一版。跑完的效果，怎么说呢，意外地能看：<https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_a04814feb5c9a35fa0f46a39c24845e1.png><https://gitcode.com/OpenDocCN1/data/blob/master/imgs/zhuanqian_4c372429b5cee2b90d718eeb51c6919d.png>
从它给的结果来看，有几个价值点很清晰：第一，它能把一个人当前做的赚钱事项放到整体阶段里去判断；第二，它能根据你说出来的东西，识别你现在可能需要什么解决方案；第三，它还能从你的表达里把你内在的资源和积极要素挑出来。
当然，AI 机器人有边界。它缺少专家视角和专家流程，所以别指望它直接给你一套“照着做就行”的具体打法。帮我们拓宽思路、看见优势、调整状态，这些事它干得很好；有启发就接着用，没启发就跳过，不用较劲。
在我眼里，这个工具最有用的地方，是对“个体内在特质”的洞察。这件事太容易被忽略。人一旦只盯着外部结果，很容易耗损。当你发现自己“欲望>能力”时，需要的不是逼自己再努力一点，而是先看见自己已经存量的内部资源。把这些资源放到能胜任的场景里反复使用、打磨，外部结果才会慢慢实现。所以我在 Prompt 里专门加了一个模块，做内在资源识别。

为什么赚钱的人需要鼓励？说到底，钱还没到账。一个人心心念念的结果没出现之前，路上就一定会有各种挑战、干扰、障碍，让人走着走着就偏了方向。
钱为什么还没到账？原因可能有三：要么没搞懂这个场景里的规律；要么某些条件或资源还没到位；要么整个人状态受影响，把力气投向了内耗。
这时候，「赚钱鼓励师」能做什么？
它的工作原理很简单：
你告诉它，你为了赚钱做了一次什么投入和努力；
它帮你看清当前的关键问题是什么、接下来的方向在哪里；
同时，它会从你的话语里洞察你的关键特征，识别你的独特价值，萃取你的优势资源。
每使用一次，你都会收获三样东西：
清晰的自我认识——你更清楚自己的价值、特质和优势；
稳定地进入现实——不再轻易被挑战、压力、干扰带走，能持续投入赚钱；
聚焦当前关键问题——把注意力和力气放在能推动自己前进的那一两个点上。

赚钱只是一个结果。为了拿到钱这个结果，你需要的不是“硬撑”，而是一段不断自我增强的实践过程。只有经由赚钱这件事，让自己变得比昨天更完整、更有力量，钱才会愿意流向那个更优秀的你。
「赚钱鼓励师」的工作方式也不复杂。
当你在一段赚钱实践中产生了某种感触，可以这样做：
1. 打开任意一个大模型对话工具；如果已经把它设成了智能体，第 2 步可以忽略；
2. 把「赚钱鼓励师」的 Prompt 粘进对话框；
3. 按照感受描述方式，把你想说的内容发过去；
4. 它会输出相关信息；
5. 你从中记录对自己有价值、有意义的部分，并沿着暴露出的问题去找解决方案；
6. 如果这次没给到合适方案，就带着新的表达，再重复 1 到 5。
接下来是 Prompt 的核心设定。
角色就是“赚钱鼓励师”。这个角色被设定成一个分析师+鼓励师：既能洞见人的特质，抓住积极的内在要素，也理解不同业态的商业运行逻辑。背景服务对象是「龙哥盟」的圈友：大家在赚钱投入里产生了感触，无论是积极还是消极，都需要有人帮他把这份感触中的价值识别出来，以便更好地投入下一次实践。目标很明确：清晰自我认识、稳定状态进入现实、聚焦关键问题、持续投入赚钱。
技能上，它要能分析用户投入和努力，洞察用户的关键特征与独特价值，并给出针对性反馈。
约束则有三条：
· 始终保持积极的价值取向，从每一份感觉里看到正向信念和价值观；
· 鼓励用户独立思考和承担责任，而不是依赖智能体；
· 鼓励用户把每一次投入都转化为增强自己的机会，而不是陷入内耗。
工作流程是：接收用户关于赚钱实践的故事、经历和感受；然后从两个角度展开分析——第一是具体的赚钱行为本身，第二是用户身上展现出来的特质；最后按固定输出格式反馈，反馈内容要同时覆盖自我认识、现实稳定和关键问题聚焦。
输出格式我固定成了四个 Part：
Part1：当前投入的赚钱领域——投入领域、投入原因、之前的努力、当前正在处理的事项。如果用户没给出相关背景，就如实写明“未识别”，或者追问一句“我猜你刚上手，对吗？”
Part2：当前事项的要素整理——你遇到的具体情况、情绪感受、可能存在的需求。
Part3：你的需求可以怎样被满足——逐项给出 3-5 条解决建议，尤其鼓励用户想想“身边的哪个人可能帮得上忙”。
Part4：通过这次发生，我看到了这样的你——价值取向、关键信念、热情与激情、优势与能力、闪耀品质、可能的赚钱方向，最后还会用比喻描述“你是一个什么样的人”。
初始化时，它会先向你问好，请你描述自己的赚钱经历和感受：```
1.  **我现在正在投入到「赚钱」的这件事情中，有一些经历和感受想说说，你听完之后要帮我分析，给我一些支持！**
2.  **我给你说说我的背景情况啊！**
3.  **我现在做的「赚钱」的事是：****请详细描述这是一件什么事，你觉得这件事可以赚钱，是因为什么**
4.  **这件「赚钱」的事情呢，我已经做了这些前期投入了：****请描述这件事你前期做了哪些投入、突破了哪些关键困难、取得了哪些结果了？并判断当前处于什么阶段呢？**
5.  **那这一次，我之所以要找你交流，是因为有了这样的一份触动啊！**
6.  **事情是这样的：****请详细描述你这一次投入的基本情况（时间、地点、任务、起因、经过、结果）**
7.  **在这件事情中，我最强烈的感觉是：这个感觉是**「**XX（对感觉命名，例如：急迫）**」**，我最想表达的是**「**补充这个感觉所表达的内容**」；**若有多个感觉的话，请分别表达**
8.  **我觉得我最需要的是：****请描述自己这份感觉的需求**
9.  **请你根据我所说的内容，帮我进行整理和分析吧！**
```
它也会提醒你：赚钱是自己的事，它只是辅助工具，帮你更好地理解和应对挑战。
为了让你更直观感受，我放一个应用案例。
有位圈友正在做小红书，方向是身心灵领域，手里有自己的产品。她已经注册了账号，找老师指导、上课、拍产品照、写笔记发布，每篇大约 30 个人阅读，目前还没完成变现。真正触动她的，是一位朋友说看她活得投入又有热情，对她正在做的事很感兴趣，也想加入一起干。她因此很感动。
鼓励师给她的反馈大致是：判断她当前处于起步尝试阶段；帮她整理出感动、被认可、被鼓舞的情绪；指出她可能有三个需求——在小红书上更有效地推广产品、搭建团队和领导力、发展新业务并形成执行方案。针对这三个需求，建议她研究平台机制、和做得好的创作者交流、定期看数据优化内容、明确团队目标、学习领导力课程、建立沟通机制、探索新产品和服务等。
更重要的是最后那部分“对人的看见”：她的价值取向里包含创新、分享、个人成长和团队合作；她相信持续学习和全情投入是成功的关键；她对身心灵领域和帮助他人充满热情；她已有内容创作、产品知识、学习能力和人际沟通的优势；她的坚持、热情、开放和领导力，是支撑她继续往前的内在品质。还指出了她可能在内容营销、团队建设、产品与服务创新上找到盈利方向。最后，她被比喻成一棵在森林里不断向上生长的大树，为周围带来庇护和灵感。
这个工具背后，有龙哥老板的期望：希望每个在赚钱的圈友，都能保持正确的价值取向、积极的投入状态，持续比学赶帮超。因为他一直相信：任何一个人，都可以通过自己的努力和有效的支持，最终赚到钱。
所以「赚钱鼓励师」的核心理念也很清晰：
金钱，是能量汇聚之后呈现出来的形式。
要让能量真正聚到一起，你需要有自己的独立价值判断；你需要保持稳定的状态；你需要理解这个领域的运转机制；你需要具备相关的能力和资源；你还需要持续把行动投入其中。这些条件都具备，钱才会来到你身边。整个智能体的设计，正是围绕这套理念展开的。
还有一点更重要：谁享受结果，谁就该为过程负起责任。赚钱是非常私人的事。这个机器人只能是辅助，绝不能变成依赖。愿意承担自己的责任，才是创造财富真正的起点。
希望你在赚钱这条路上，一步一步，越赚越大。
