# 用 AI 把一个月的活儿压缩到 3 天，我同时上线了词库模块和 49 本单词书
## 72 小时内，我靠 AI 把「鸭霸单词」App 的词库功能从零做到可发布，并配套出了 49 本单词书
作者： 龙哥
日期：2025-02-26
很久没更新了，最近把精力都放在了「鸭霸单词」App 的体验升级上。为了让用户能用上更丰富的词源和更清晰的学习路径，我决定上一个「词库」模块。说实话这个模块不算小，摊开来看至少要啃三块硬骨头：
1️⃣ 词库功能的研发
2️⃣ 单词原始数据的清洗与整理
3️⃣ 49 本单词书的封面视觉设计
过去我一个人要把这三件事串起来，保守估计得花上整整一个月。这次我全程让 AI 搭手，从代码到数据再到美术，最终在 3 天内就把闭环跑通了。
第一天，我用 Cursor 做 AI 编程。靠它把词库的核心逻辑、单词掌握状态的记录、朗读播放的联动等基础能力全部搭起来，模块级的功能骨架一天就成型了。
第二天，我让 Cursor 帮我写了一套 Python 处理脚本，把来源各异、格式混乱的单词数据批量规整成产品能直接用的标准结构。脚本跑完后我只做了人工复核和少量微调，就能直接入库。
第三天进入收尾。封面我交给 recraft.ai（）来画，统一风格下快速出图，一口气生成了 49 张成系列的单词书封面： 🌻 小学篇走花卉主题，寓意欣欣向荣。 🏀 初中篇用运动主题，象征茁壮成长。 ⛰️ 高中篇是户外主题，表达丰富多彩。 🐼 大学篇选动物主题，代表探索发现。 🏛️ 留学篇用建筑主题，呼应环球求知。
成品效果可以参考图 1、图 2，整体质感我自己也挺满意。这次的尝试让我真切感受到了 AI 全流程辅助的提效上限，也希望这段实战经验能给你一点启发。
另外透露一下，「鸭霸单词」App 的新版本很快就会推送，词库模块和统计模块都会一起上线，让你可选的单词更多，同时对自己的学习状态看得更清楚。 [`www.recraft.ai/invite/MHPpaaNNRx`](https://www.recraft.ai/invite/MHPpaaNNRx)
