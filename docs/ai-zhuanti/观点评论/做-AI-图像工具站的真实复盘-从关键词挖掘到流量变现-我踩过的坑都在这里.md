# 做 AI 图像工具站的真实复盘：从关键词挖掘到流量变现，我踩过的坑都在这里
大家好，我是老布。
过去几个月，我一直在摸索 Web 工具站，重点研究的是 AI 图像类产品。虽然目前还没有真正实现收入，但这段时间里上线了 7 个网站，也经历了找词、做产品、接支付、申请广告、研究竞品和获取流量等多个环节。
最近刚好看到龙哥发起龙珠悬赏，就把这段时间的一些实践整理出来，希望能给同样在做 AI 工具站的朋友提供一点参考。
这篇内容比较长，大家可以根据自己的需求选择阅读。
# 一、做网站的第一步：如何找到值得做的关键词
对于刚开始做 Web 工具站的人来说，关键词往往是最先遇到的难题。
我的做法比较简单：先观察榜单，再顺着榜单中的产品去挖关键词。
## 1. 从 AI 榜单中寻找产品方向
以最近研究的 AI 图像项目为例，我通常会先打开 Toolify.ai，进入排行榜，再查看 AI 收入榜，筛选出与 AI 图像有关的网站。
例如 pixelcut.ai，就是一个免费的 AI 图片编辑工具，包含抠图、修图、图片放大等功能。
![](img/4d329a785d60a9982e6a71418cc7420c.png "None")
找到目标网站后，下一步不是马上模仿产品，而是先看看它究竟依靠哪些页面和词获得流量。
这时可以使用 Similarweb，进入关键词研究，再查看着陆页。
![](img/05f58d41d69a5c2b5632ee966eed6f46.png "None")
输入 pixelcut.ai 后，就能看到该网站近一个月不同页面的点击表现，以及带来访问的搜索词。
![](img/7b819c72514625dac2a3cecfc387d97c.png "None")
比如其中的关键词“unblur image”，点击“所有关键词”后，还能继续看到与它相关的更多词。
这类相关词有两个价值：
第一，可以帮助我们拓宽选题范围；
第二，可以作为未来网站内页的选题来源。
![](img/85fd2067c08b051832c4789637b7ffd7.png "None")
## 2. 判断关键词是否真的有流量
找到关键词之后，还需要判断它的搜索需求到底大不大。
可以利用 Google Trends，把目标关键词和一个熟悉的词进行对比。比如这里将“unblur image”和“gpts”进行比较，可以发现前者的搜索热度并不低，说明它具备一定流量基础。
![](img/c9cba1fc1337284f7aa7095b63d71cb5.png "None")
接下来，还要确认关键词的竞争程度。
可以使用 Ahrefs 的 Keyword Difficulty 工具进行判断：
[`ahrefs.com/keyword-difficulty`](https://ahrefs.com/keyword-difficulty)
“unblur image”当前的关键词难度大约为 37。
同时，在搜索结果中还能看到 unblurimage.ai 排名第一。这说明已经有人围绕这个词注册域名、搭建产品，并且通过 SEO 获得了不错的排名。
![](img/b15fc1b65a5b941e87f99f3ff1ec690a.png "None")
按照这个方法，把 Similarweb 着陆页中出现的关键词逐个分析，就有机会找到：
- 有搜索需求的词；
- 竞争程度尚可的词；
- 已经在获得收入的工具站；
- 可以进一步扩展的相关词；
- 值得研究的产品方向。
# 二、拆解 unblurimage.ai：一个 AI 图像站是如何做起来的
下面具体看看 unblurimage.ai 这个网站，分别从页面、内页、博客、API 和流量来源几个角度进行分析。
## 1. Landing Page：从首屏开始围绕主关键词布局
打开网站后，第一眼看到的标题就是“Unblur Image”。
不仅标题如此，产品描述中也反复覆盖了 unblur image、sharpen photos、remove blur 等相关词。
网站首屏还放置了处理前后的图片对比，让用户一进入页面，就能明白产品解决什么问题，以及最终能够达到怎样的效果。
上传区域下面还提供了示例图片，方便用户不用准备素材，就能马上测试功能。这种设计在图片处理类工具中非常常见，也很实用。
![](img/b125ae9473296dacb615e53170a54130.png "None")
继续向下浏览，可以看到 Features 区域。
页面围绕核心词“unblur image”，进一步介绍了 Image Sharpening、Noise Reduction、Higher Resolutions 等能力。
每个功能都配有处理前后的效果展示，同时还会具体说明图片如何被处理、处理后能得到什么结果。
这些文字并不是简单介绍功能，而是非常明确地服务于 SEO。
![](img/604f5d67877325c8e6716ed82cc7d2d0.png "None")
![](img/06c1e8ae56578acc738bda03d7849282.png "None")
之后页面还包括：
- 使用方法；
- 使用该工具的理由；
- 用户评价；
- 行动按钮；
- 常见问题；
- 其他辅助说明。
整体看下来，最突出的感受就是：网站几乎所有区域都在围绕目标词展开。
“unblur image”在不同模块中持续出现，同时还穿插了 sharpening、high resolution、remove image blur 等语义相关词。
![](img/08f7fc3a4ced3a9d36702d1b7be002ec.png "None")
![](img/75d5e3aabed266ce66714e4e7af452e9.png "None")
![](img/dbb8558c798829d47dc151612134cdbb.png "None")
通过 AIDTK 插件，也能进一步验证它在页面关键词布局方面做得相当充分。
![](img/5c59fb772e0f03d4a27d0b8a32ffcd54.png "None")
从这个案例中可以总结出一个非常重要的页面设计方法：
**先确定一个核心关键词，再让整个 Landing Page 围绕这个词展开。**
无论是首屏标题、功能介绍、操作流程、使用场景、用户评价、行动召唤还是 FAQ，都应该服务于主关键词，同时自然覆盖更多相关搜索词。
相关词从哪里来？
前面通过 Similarweb 找到的扩展关键词，就可以整理出来，再交给 AI 辅助生成 SEO 文案。当然，AI 生成的内容不能直接照搬，最终仍然需要人工检查、修改和优化。
## 2. 内页：每一个页面都可能成为新的流量入口
当一个网站逐渐获得流量后，继续增加相关内页，通常是扩大搜索覆盖面的重要方式。
unblurimage.ai 除了主页面之外，还建立了大约 10 个与 unblur image 相关的功能页面。
![](img/f817dd226b0546c0f912822881857b54.png "None")
以 Blur Remover 这个页面为例，它并不是简单做了一个标题和几段介绍，而是重新搭建了一套完整的 Landing Page。
页面中的各个模块都围绕“blur remover”重新撰写，Features 区域甚至比主页中关于 unblur image 的介绍还要丰富。
![](img/96fb311c164b82dae435706ca642bde9.png "None")
![](img/cd698a9060e6d1886938b6b0136d328c.png "None")
![](img/de853c74562cd0615527cbce2d1db550.png "None")
这个案例给我的启发是：
**内页不是随便增加几个关键词和段落就结束了。既然每一个内页都可能承接搜索流量，就应该把它当成一个独立产品页面来认真制作。**
如果内页内容单薄、功能不匹配、用户体验差，用户很快离开，受到影响的不只是这一页的表现，也可能拖累整个网站的整体数据。
## 3. 博客：内容页面同样可以带来长期流量
以前我觉得工具站的博客并不是重点，但研究完 unblurimage.ai 后，我改变了看法。
一篇优质博客，本质上也是一个可以获取搜索流量的内页，而且还可能帮助用户理解产品、建立信任并完成转化。
这个网站的博客有几个地方值得关注。
### 第一，配图很统一
每篇文章都有专门制作的图片，通常采用标题加效果对比图的形式，视觉风格比较一致。
### 第二，内容更新持续进行
从页面记录来看，6 月 18 日、21 日和 24 日，网站连续发布了多篇文章。
![](img/2dc963309f8eafa566bf254f6d9f7211.png "None")
### 第三，文章内容足够详细
它的博客并不是为了凑数量，很多文章结构完整、信息密度高。
例如 6 月 21 日发布的《HD Photo Converter — Unblur Your Image with Unblurimage》，复制到飞书文档后，全文超过 3000 字。
![](img/e51f8827712068d30904da3e16796b6a.png "None")
从 ChatGPT 对这篇文章的总结来看，文章大致包含七个主要模块，每个模块下还细分了多个子主题，并穿插图片、图表以及 FAQ。
![](img/467610d425211b5d92c853859150317a.png "None")
实际阅读之后会发现，这些模块并不是简单堆砌标题。
例如 How to use 部分，既有文字说明，也有配图，而且在介绍具体操作时，还直接链接到网站功能页面。用户阅读到某个步骤，如果想马上体验，可以直接点击跳转。
这种设计既帮助用户理解，也增加了产品使用机会。
此外，网站还为 30 多篇文章设置了标签和分类，方便访客按照兴趣筛选内容。
![](img/565bc31fc0217584461f832570125869.png "None")
![](img/97b3fd49d49e4de1f479ad7940142f68.png "None")
拆解完它的博客后，我最大的感受是：
网站刚上线时，页面可以先满足基本使用，但一旦开始获得访问，就应该逐步把每个页面做得更扎实。
即使是一篇博客，也不要只满足于“发布过”，而要考虑它是否真正有帮助、是否能够获得搜索流量、是否能把用户引导到产品中。
## 4. API：流量只是开始，效果才决定留存
前面分析了 Landing Page、内页和博客，这些内容负责帮助网站获得曝光。
但用户真正使用产品时，最终体验如何，还是取决于核心功能，也就是 API 和底层模型的效果。
刚开始研究 unblurimage.ai 时，我也曾经觉得，既然 Replicate 等平台已经提供了不少图片处理 API，那么自己做一个类似产品应该并不困难。
但我实际测试了十几个相关 API 后，发现情况并没有想象中简单。
其中没有任何一个 API 的处理结果能明显超过 unblurimage.ai，甚至能达到相近水平的都不多。即便是 Google 搜索结果排名靠前的网站，实际图片处理效果也不如它。
![](img/9e74cb942af5fc7e25dcec70cefd1fa8.png "None")
这很可能也是 unblurimage.ai 能够在域名注册后短短几个月内，做到“unblur image”排名第一的核心原因之一。
该域名注册于 2024 年 11 月 7 日，网站在 11 月 22 日上线，之后大约用了 8 个月拿到目标词第一名。
那么，如何找到质量相近的 API？
我尝试过询问 ChatGPT，也测试过其他服务。在价格相近的情况下，始终没有找到更合适的方案。
后来在深海圈群里请教，小排老师的观点是：Replicate 上现成的 API 已经属于比较好的选择，如果还想获得明显更好的效果，可能就需要自己训练模型。
通过这个案例，我主要得到两个启发。
第一，如果不知道某个方向有哪些 API，可以先向 ChatGPT 询问，再结合实际测试。
第二，也可以反过来从 API 库中寻找产品机会。
例如进入 Replicate 的 Explore 页面，再打开 View all tasks，就能看到很多已经整理好的模型和任务类别。
![](img/b3f1dc2d1308840f20d695bd549039ee.png "None")
![](img/1b55181004a4ba872b55fd85db69e562.png "None")
点击某个 API 分类后，可以看到它对应的具体能力和相关关键词。
接着，可以把这些 API 信息交给 ChatGPT，让它分析：
- 这个 API 能解决什么问题；
- 适合哪些用户；
- 可以对应哪些搜索词；
- 有哪些产品形态；
- 适合制作什么工具站。
之后再拿关键词去 Google 搜索相关产品，继续使用 Similarweb 查看它们的页面和流量来源。
这样就形成了一条比较完整的选题路径：
**API 能力 → 用户需求 → 搜索关键词 → 竞品网站 → 流量页面 → 自己的产品方向。**
![](img/cc0ceee1599618b2f9edd5b70e6772bc.png "None")
# 三、unblurimage.ai 是如何获得流量并实现变现的
一个工具站能否赚钱，通常不是只看产品功能，还要看它能不能持续获得访问。
unblurimage.ai 的优势主要体现在几个方面：
- 页面结构清晰；
- SEO 文案覆盖充分；
- 内页建设完整；
- 博客持续更新；
- API 效果优秀；
- 同时在做外链和社交传播。
## 1. 社交平台冷启动
访问网站时，可以看到右侧有一个 X 图标。
点击后会发现，站长在网站上线当天，就已经在 X 发布了相关内容。
虽然这种方式带来的流量可能有限，但对于新产品而言，至少能够完成初期曝光，也是一种低成本冷启动方式。
![](img/e6367aa16a09711751a0dfbf866569b4.png "None")
![](img/572dc3742606660c70a678b553f1d3d7.png "None")
## 2. 外链建设
通过 Ahrefs 的反向链接查询工具，可以看到 unblurimage.ai 拥有大约 4.8K 条外链。
考虑到网站上线时间只有 8 个月左右，这个数量已经非常可观。
![](img/31d411687599ecf91e4ead0fe7cd9004.png "None")
进一步查看外链来源可以发现，其中一部分来自付费购买的 AI 导航站，例如 Toolify.ai；同时，也有其他相关网站为它提供了自然导流，比如 unwatermark.ai。
![](img/2417e2e5ceb0bf9a0daf37d7f2366692.png "None")
这里想特别说一下外链问题。
很多刚开始做 Web 工具站的人，由于还不确定产品能否成功，往往不愿意投入预算购买外链。
如果暂时没有预算，也可以先从免费外链入手。
具体方法是：平时看到一个与自己领域相关的网站，就通过 Ahrefs 的 Backlink Checker 查看它有哪些外链来源。
根据哥飞的说法，Ahrefs 展示的通常是该网站外链中价值较高的一部分。
因此，我们可以把这些网站整理下来，逐个尝试投稿、提交产品或申请合作，慢慢建立自己的外链资源库。
工具地址：
[`ahrefs.com/backlink-checker`](https://ahrefs.com/backlink-checker)
## 3. 网站实际访问数据
通过 AITDK 插件可以看到，unblurimage.ai 在 6 月的访问量约为 438.5K，也就是 43 万左右。
同时，平均停留时间约为 52 秒。
这个停留时长说明，用户进入网站后并不是马上离开，而是有一定比例真正体验了产品。
![](img/24259ce56f515179ccc0d7f29d349b76.png "None")
综合来看，我对它的增长方式理解如下：
**先保证产品实际效果足够好，最好明显优于同类产品；然后通过主页面、内页和博客覆盖关键词；最后把主要精力放在外链、社交媒体以及其他流量渠道上。**
正如龙哥曾经提醒的那样，做产品的人应该把大量时间用于思考和测试流量获取，而不是把几乎全部精力都花在产品打磨上。
# 四、做站 4 个月后的真实经验
到目前为止，我大约做了 4 个月 Web 工具站，累计上线了 7 个项目：
- 其中 1 个开通了 Google Ads，但后来因为收入无法覆盖成本，流量逐渐下降；
- 2 个接入了支付，但还没有产生订单；
- 其余项目每天访问量只有个位数。
所以，我还没有真正赚到钱，但这段时间确实踩过不少坑。
## 1. 该投入的时候要投入，否则无法验证产品
4 月初，ghibli 相关关键词走红，ai barbie doll 也获得了一些搜索需求。
当时我用一个周末接入 API，快速上线了网站。由于还没有接入支付，也没有设置使用限制，产品上线后很快就有人使用，之前充值的几美元 API 额度很快被消耗完。
因为担心后续用户增加会带来更高成本，我没有继续购买额度。
之后，我利用下班后的时间，用了 4 天接入 Creem 支付。但等支付功能完成时，网站已经没有什么用户了。
现在回头看，这种前期不愿意投入、总想着先赚到钱再继续的思路，并不适合做付费产品。
用户愿意付款的前提是产品能够正常使用，而且确实有价值。
为了节省几十、上百美元，让网站直接无法使用，实际上等于主动放弃了本来可能出现的机会。
因此，当产品已经有流量和用户时，该投入的 API 成本一定不能省。
## 2. 上线前先算清成本，避免做出无法盈利的项目
图片类网站通常需要一段时间才能看到效果。
五一期间，我又尝试做了一个 Instagram 相关的网站。项目上线后，虽然没有主动发外链，但仍然陆续有用户访问。
吸取前一次的教训后，这次我花了 50 美元，在 RapidAPI 上购买了 10 万次 API 调用额度，之后申请了 Google Ads。
![](img/f9eaf6ca067b5ef799649c7294c5f114.png "None")
由于网站流量表现还可以，Google Ads 一周多就通过了。
但很快，之前购买的 API 额度就用完了。于是我又花了 15 美元购买了 3 万次调用额度。
继续测试三四天后，我发现每天 API 成本大约为 4 美元，而 Google Ads 的收入每天不到 1 美元。
由于没有找到更便宜的 API 方案，我自己也无法采集 Instagram 数据，只能停止继续运营，后续网站流量也逐渐归零。
通过这个项目，我得到的教训是：
**凡是依赖付费 API 的产品，上线之前一定要先把成本结构算清楚。**
至少要提前确认：
- 单次调用成本是多少；
- 用户平均会使用多少次；
- 广告收入能否覆盖调用费用；
- 是否存在更便宜或更稳定的替代方案；
- 产品收费后，用户是否愿意为此付费；
- API 额度耗尽后，项目是否还能持续运营。
否则，即使顺利获得流量，也可能出现“访问越多，亏损越快”的情况。
# 五、最后的总结
这几个月的实践让我越来越清楚，做 AI 图像工具站并不是找到一个关键词、接入一个 API、做出一个页面就结束了。
真正决定项目能否走下去的，至少包括以下几个方面：
1. **关键词选择**
先找到真实存在的搜索需求，再判断竞争程度和商业价值。
2. **页面 SEO**
主页面、功能内页和博客都要围绕关键词建立内容体系。
3. **产品效果**
页面写得再好，如果核心功能不够用，用户仍然不会留下。
4. **成本控制**
API、广告、服务器和外链费用，都需要提前测算。
5. **流量获取**
社交媒体、外链、博客、导航站和搜索引擎优化，都应该持续尝试。
6. **快速验证**
不要无限打磨产品，也不要因为舍不得投入而让产品无法使用。先上线、先获得真实反馈，再决定是否继续加码。
目前我还没有赚到钱，但这些经历至少让我明白了一件事：
**做 AI 工具站，产品只是起点，流量才是决定项目能否生存的关键。**
看过不少做独立站或AI工具的朋友，一开始都容易踩进同一个坑：辛辛苦苦做了个免费服务，结果流量没多少，成本倒是蹭蹭往上涨。想靠免费攒口碑，前提是真把账算明白——如果连服务器、API、维护这些开销都没压住，那基本就是白忙一场。其实，在早期就设计一个付费入口，反而能走得更稳。当时我也觉得自己网站平平无奇，再看看竞品清一色免费，就只好放弃了这条路线。
🌐 免费外链虽慢，但绝不白费
网站上线后，不买外链、不投广告，想有曝光就只剩一条路：亲手去发免费外链。
记得六月初，我上线了一个生成png图片的小工具。头两天Google排名卡在76名上下，几乎没人点进来。此后十天，我每天下班后挤出时间发十来条外链，到了六月中旬再看——排名已经爬到56名左右。曝光和访问量虽然还是很低，但确实一天比一天多一点。
![](img/53f710683aff7c9eb2f9c4c38dc8b286.png "None")
这个实践让我彻底明白：外链见效慢，可它是真的有用。只要网站本身没烂到不行，外链数量一多，流量就会一点一点起来。关键是你有没有耐心撑到那一天。
⚡ 别自己加戏，快速上线才是王道
很多刚开始建站的朋友，特别容易给自己设置一堆障碍。比如：
- 明明用Nextjs写的项目，编程也谈不上熟，却在纠结部署平台用Vercel还是Cloudflare——听说前者流量一大就烧钱，干脆花好几个晚上研究后者配置；
- 明明自己站不多，看到对标网站又是内页又是博客还有一堆定价方案，就想着我也得凑齐这些，结果产品迟迟没落地；
- 明明没看过几个站、没分析多少关键词，就想把所有流程自动化，折腾来折腾去，连最初上站验证需求的目标都忘了。
我觉得，一开始就该把“快速上线验证”当作唯一中心。哪个部署方案最快就用哪个，没有内页？先发MVP。订阅逻辑搞不明白？那就干脆做一次性付费。看站、找词本来就是在积累感觉，站点数量不够之前，根本别考虑自动化那套。
🚦 搞流量，永远是头等大事
最后想再唠叨一句：对我们这些靠AI产品赚钱的人来说，什么最重要？流量。就像哥飞说的，40%时间找需求，30%写代码，30%做推广。龙哥说得更狠——把80%的功夫花在研究怎么获取流量上，而不是闷头打磨产品。
我自己最近就吃了这个亏。总想着做一个像unblurimage.ai那样大而全的东西，于是拼命找API、试API、写代码、调页面、加内页。结果呢？合适的API没找到，代码被AI越改越乱，内页多了一点，SEO文案反复推敲还是不满意，差点整得我放弃整个赛道。更要命的是，六月份上线的那个站，因为没继续发外链，排名已经掉了一截。
所以啊，真想走下去，就得快速上线跑通验证，然后把剩下的精力全砸到抢流量上。再根据用户反馈一点点迭代，别把自己关在屋子里，幻想“我做的产品大家一定爱”。
