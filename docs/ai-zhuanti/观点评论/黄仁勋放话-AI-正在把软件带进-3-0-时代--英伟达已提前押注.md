# 黄仁勋放话：AI 正在把软件带进“3.0 时代”，英伟达已提前押注
如果说过去十年的软件迭代是“写代码”，那黄仁勋眼中的下一场变革，更像是“教机器学代码”。这位英伟达掌门人给出了一个大胆预判：人工智能带来的新格局，会一点点拆解、重构我们熟悉的软件与硬件底座。
在黄仁勋看来，AI 的快速发展不会只停留在应用层，它会渗透到计算架构的底层逻辑。旧有的软硬件堆栈，将在这场技术演进中被逐步替代——不是一夜颠覆，而是缓慢瓦解。
那么英伟达在这个新时代里扮演什么角色？答案藏在他提出的“软件 3.0”里。这个阶段，软件的核心不再是程序员手动编写逻辑，而是让数据与算法共同驱动。而支撑这一切的主要算力引擎，正是英伟达手里最硬的底牌——GPU。
简单说，黄仁勋认为英伟达的未来，不在于某款显卡产品本身，而在于成为“软件 3.0”时代计算平台的基石。AI 越往前走，GPU 的角色就越从“图形加速器”转变为“智能引擎”。
当别人还在争论 AI 会不会取代程序员时，黄仁勋已经悄悄把公司的未来押在了“软件 3.0”上。这场变革，或许比我们想象得更近。
