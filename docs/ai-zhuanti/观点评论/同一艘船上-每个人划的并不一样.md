# 同一艘船上，每个人划的并不一样

最近刷到 @澄哥 的一则动态，忽然把我拉回了这几年在赚钱做志愿者的记忆里。

一切要从加了一个人开始说起。从那之后，我的志愿者轨迹基本就和他绑定在一起了。

很多人现在提到赚钱志愿者，首先想到的就是航海。但其实航海只是冰山一角。

我是最早那批吃到志愿者红利的人。当时加入的初衷很简单，想在自己做项目的空档，沉下去看赚钱到底是怎么运转的，顺便学学社群运营的方法论。

后来触点越来越多。大航海没听过吗？视频号大航海、现在的21天机制和续航计划，再到 Mini 航海。志愿者的形态在变，视角也在变。旁观别人做项目，比自己闷头做，更能补上认知短板。

从一开始跑4、5次志愿，到后来连带两次领队，评分都在A以上。慢慢地，我就被拉上了公众号爆款写作船，成了教练。算下来一共参与了6期教练志愿，收获确实不小。

有意思的是，赚钱志愿者的成长路径。很久以前这条路并不清晰，我算是赶上了空白期，直接从普通志愿者跳到领队，再跳到教练，两次跃迁，算是很典型的受益者。

顺带说一句，这么多年我加的星球不超过5个，但龙哥盟我每年都在续费。做生意的认知年年都在往上走，这点真得感谢龙哥盟，感谢![](img/afe1f037b78882661210f7ee12d90532.png "None")
