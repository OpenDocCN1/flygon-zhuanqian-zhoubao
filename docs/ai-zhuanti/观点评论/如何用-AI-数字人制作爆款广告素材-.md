# 如何用 AI 数字人制作爆款广告素材？
先晒个结果：最近我用AI数字人做广告素材，4天时间就烧掉了30万广告预算。说实话，在此之前我对AI几乎一窍不通，完全是从零起步。今天把这套玩法分享出来，希望能给同样在摸索的朋友一点参考。
先简单介绍下自己，我就是个再普通不过的上班族，在赚钱圈子里潜水好些年了，平时看多聊少。这次能鼓起勇气发帖，也是因为不少朋友在问，干脆写出来统一回复。
很多人好奇，这种传媒公司到底靠什么赚钱？其实逻辑很简单：甲方出广告预算，我们负责做素材、跑投放，最后按消耗拿提成。产品、发货、客服、售后这些全由甲方负责，剩下的素材制作和投放统统我们包了，核心目标就是把量跑起来，让消耗数字越滚越大。
关于数字人形象，大家也问得比较多。用自己的形象当然可以，但并不推荐。尤其是做爆款素材的时候，为了避免侵权纠纷，我们经常会把素材里的脸换成自己的，更稳妥。
投放这块，我最看重的是消耗，毕竟收入跟它直接挂钩。同时ROI也一定会盯，我的爆款素材投产比都还过得去，所以能持续跑下去；一旦某个素材ROI不行，毫不犹豫就停掉，不浪费一分预算。
从AI小白到能独立操作，中间确实踩了不少坑。其实只要把底层逻辑想明白，做爆款数字人素材并没有那么玄乎。希望今天的分享能带给你一点启发，一起在赚钱路上越走越稳。
