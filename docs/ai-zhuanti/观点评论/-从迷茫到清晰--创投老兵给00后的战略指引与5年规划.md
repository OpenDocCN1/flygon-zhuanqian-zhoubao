# “从迷茫到清晰”：创投老兵给00后的战略指引与5年规划
最近读到赚钱圈里张昭前辈分享的一篇关于创投思考的文章，触动很深，于是鼓起勇气加了前辈微信，争取到了一次宝贵的交流机会，这才有了下面这些思考。
张昭前辈常说，投资的本质就是找对人、做对事。人选定了，方向也定了，剩下的关键就取决于双方在合作中能否同频共振。所以那天的对话，也自然会围绕着“对人的判断”、“对事的判断”和“对合作的判断”这三个维度展开。
# 一、先看人：你骨子里有没有那股东西？
张昭前辈在文章里提起过，他会特别关注两类人。
一类是“苦大仇深”型。这里的“苦大仇深”，并不是说一定要出身多么贫寒，而是说天然有一种想要改写命运的紧迫感。这样的人起点低，韧性却极强，不用谁拿鞭子在后面赶，机会一旦出现，他们会自己拼命往上扑。反倒是家境优渥的孩子，选择一多，退路就多，专注力反而容易被分散，很难逼自己一把。
另一类是“主动求变”型。这个“主动”很重要，是你自己从心底里想要向前走，而不是别人推着你动。如果你自己都不想变好，别人凭什么拉你？前辈说得挺直接：他的项目，他从来不会开口挽留人。“这是你自己的项目，你自己决定。想搞就接着搞，不想搞就撤摊子，我绝对不留人。”想靠外力来逼自己成长，不如老老实实去上班，打工没那么复杂。
那天的交流里，有两个问题让我印象特别深。
第一个问题：你至今遇到过最大的坎是什么？我提了刚做直播时，因为执行标准太严，被主播当众指责是在PUA她，面子挂不住，心态也崩过一阵。前辈听完笑了，说这些还是太小了。他真正想听的，是那种“没有退路”的挑战——比如重病，比如家庭变故。工作干砸了大不了换一份，还有退路兜底。但人生里有些局，你闯不过去，就真的什么都没有了。那种被命运逼到墙角、必须绝地反击的经历，才是他想听到的故事。
他看我没能立刻答上来，便说：“你还要花时间想，说明你日子过得算顺了。你吃的亏，终究还是太少了。”因为人性骨子里就是贪图安逸、趋利避害的，没有外界压力，很少有人愿意主动把自己折腾得筋疲力尽。创业这件事，是需要一股东西在后面顶着的。这股东西可能是苦难，也可能是热情，总之你必须找到属于你自己的那份驱动力，否则真到了难关面前，人太容易跑了。
第二个问题：你的盖洛普优势是什么？我说没测过，也不太信这类测评，之前MBTI也是因为公司HR要求，走个流程才做的。前辈的反问很有意思：“你不认同这个意义，为什么还要去做？”我说配合一下罢了。他接着点了一句：“你老板安排你做MBTI，做完了，你到现在都没研究过它。这说明你对很多新事物的敏感度不够，敏感度不够，创新力就要打折扣——你的信息来源太少了，怎么创新？”
这句话给我的触动不小。新事物冒出来，第一时间去接触、花时间去研究、主动去跨领域收集信息，这些才是一个人保持敏感和创造力的根本。这是我从这次对话里捡到的第一个大收获。
# 二、再看事：你的“杂草”，砍掉了吗？
前辈问我最近在看什么方向。我列了三个：AI应用、小绿书（腾讯新流量入口）、疗愈赛道（今年做过一个项目，结果不错，明年还有合作空间）。
他没有直接评价我的选择，而是讲了个例子。高产的农作物，和低产的杂草，区别在哪？高产作物会把那些没用的枝枝杈杈全砍掉，养分集中往关键部位送。杂草呢？哪里都长一点，结果到处都长不好，最后根本没有一条清晰的主干。
“别什么都想要，你得先找到你的主干。”他说。
怎么找？不是拍脑袋，而是要对每个方向所需的资源、要具备的能力、最终的终局形态做判断，再反过来看看和自己手里的牌能不能匹配上。
关于**小绿书**，前辈他们是入局最早的一批，赚钱那次小绿书航海，5个教练里就有2个是他投资的。但他的结论很明确：绝大多数人在这件事上没戏。小绿书要做好，要么有极强的获取流量能力，说白了就是内容本事；要么有极强的选品能力，选品挂精选联盟是起步，走到后头一定拼的是自己的供应链和货盘，这就非常重了，不适合00后。所以年轻人顶多在流量侧还有点空间，但终局不掌握在自己手里，赚钱效率也高不到哪去。
再说**疗愈赛道**，前辈直接否定：线下，不是00后的主战场。疗愈客单价高，要求你对人性有极深的理解，否则根本控不住场。你的客户是那些中年男人和中年女性，个个都是人精，你要从他们手里拿几万几十万，没有足够的人生阅历和共情能力，你根本聊不到一起去。就算靠会销做了个场域出来，让他们买了单，这事也不可延续。你一个没结婚、没生娃的00后，和一群被家里鸡毛蒜皮折腾得够呛的人，能有多少共同语言？到最后你只能沦为销售角色。前辈给了所有00后一句忠告：“放掉所有幻想，专攻AI。别的都可以不用想，想了也没用。”
那**AI**呢？他拆解出两个方向。一是用AI工具提效，比如用AI写文案、做图文带货这类，不碰任何技术开发；二是借助Cursor、Coze这类工具做轻量级开发，做成小程序、网站或者小游戏去变现。但做开发有两个前提：一是对用户场景有精准的理解，能做出让人用起来舒服的产品；二是技术实现的能力。这更适合当作你赚到第一桶金之后的下一步，不适合在创业初期就冲上去。
一番分析下来，结论就清楚了：小绿书，别碰；线下，别碰；剩下唯一的正路就是AI赛道。杂草剪完了，主干露出来了。
# 三、定战略：敢想5年1000万，然后倒推
方向有了，前辈问：你的目标是什么？我大喊一声：5年，赚1000万！（梦总是要有的嘛！）
前辈说，有了目标，就要学会“以终为始”地倒推拆解。但大多数人有两种思维误区：一种是从自己现有的资源和能力出发，去拼凑一个能做的生意；另一种是站在今天的位置，去想象未来世界长什么样。这两种，都是错的。
“你应该先判断，什么样的业务模型，才能承载起5年1000万的目标？找到那个财富框架。哪怕你现在一无所有，也要先找到那个框架。”这是我最受震动的思维启发。
现在是2024年12月，从2025年开始计算，5年时间怎么分？第一年，大概率是摸索业务方向，最重要的是先生存下来，先解决吃饭问题。大家最容易在这儿犯的错，就是为了生存而放弃长线目标。前辈见过太多人，起初喊口号喊得震天响，结果半路看见别的赚钱门道，心一横就跑了。所以他说，这12月份你什么都不用干，给我先停下来，好好地做一份五年计划。看看AI这个主线上，到底有哪几条路可以通向你要的结果。少即是多。
至于后面4年，节奏大概是：100万、200万、300万、400万的净利润阶梯式往上走。每一步的挑战和关键难关是什么，现在就要开始想清楚。
前辈说“以终为始”这四个字的时候，我才真正理解：我们看似选择无限，其实根本没得选。因为同时满足两个条件的选项，本来就没几个。一，利润目标：赚10万的机会遍地都是，赚100万的选择也不少，但能让你赚到1000万的事情，真的不多。二是能力匹配：你的能力结构，客观上就决定了哪些钱跟你有缘。
这里还牵出我对“财富框架”的思考。财富框架其实就是财务模型。你要做50万一年，和你做1000万一年，毛利结构、净利水平、生意天花板是完全不一样的。有的生意，天生就到那个顶，你想继续变大，就得换一个框架来做商业。有一句话说得好——旧地图，找不到新大陆。就好比有人做小红书的陪跑低价课做到某个规模就卡住了，怎么办？你要换地图、换人群、换产品、换价格带。这就是换财富框架，才能把你带上下一个台阶。
# 四、谈合作：投资就是投人，怎么投？
方向定了，人也看了，剩下就是“能不能一起干”的问题。一旦合作，双方都会付出成本；如果团队磨合不好，对彼此都是消耗。
所以在绑定之前，判断合作伙伴，很重要。
前辈的筛选方法有两个。一是测评工具。他之前问过我盖洛普优势，我说没做过，也不信。他说，那你怎么跟你的上级、下级配合？我说更倾向于在实际的信息交互中判断人：基础岗看入职三天内的工作任务完成情况和日报就能摸个大概，高阶岗比如编导，就看对方在协作中反馈回来的信息质量。前辈听完只说了一句：“这样判断，时间会拉得比较长。”
二是情景测试。他问：“如果方向由我定，你负责坚定不移地执行，你行不行？”我说，第一步我得先认同这个方向，如果我内心有疑问，我会主动找您把思考对齐；第二步，一旦确认了，我就会全力以赴。前辈接着逼问：“那是不是说，在每次开始之前或者推进的过程中，我都需要先说服你？如果我认为这事是对的，以我的经验按我的节奏走才是最稳的，你却非要表达你的见解，怎么办？在那些紧急的时候，战机稍纵即逝，我还要浪费时间来给你解释，你怎么选？”
我想了想，回答：我选择听的。我聊起自己今年被领导安排过两个项目，当时我也没看懂，但我选择先干起来。因为他的实力摆在那，拿到的结果比我大。我没看懂是我的问题，我要在做的过程中去理解。用数据反馈去验证选择对不对，这个过程本身就是在学习。
前辈听罢，认同地点了点头，他补充了一句：“听话照做，从来都是最稀缺的品质。”我带主播、孵化IP这么多年，最后能拿到结果的，全是听话照做的。为什么？因为在那个领域，我比他们专业。你什么都不懂的时候，不要有那么多想法，先跟着做。等你攒够了经验，你开口说话才有分量。
人是成事的关键。合作是双向选择，开始之前，把标准和人选都看清楚，把原则都说清楚，往后的路才走得扎实。
# 写在最后
跟高手聊天，就像照镜子。他抛出来的每一个问题，都帮你层层剥开自己：你现在处在什么状态，你有什么思维惯性，你的软肋在哪里，你的成长空间又在哪里。
和张昭前辈这一个多小时的交流，确实受益匪浅。我学到的是，投资人看创业者，会从三个维度出发：怎么判断这个人值不值得投，怎么判断一门生意值不值得做，以及怎么判断双方能不能默契地合作下去。包括怎么砍杂草、定主线，怎么“以终为始”拆解五年规划，这些思维模式，比任何方法论都珍贵。
再次感谢张昭前辈的倾囊相授。也鼓励每一位还在摸索的伙伴，大胆去链接你欣赏的牛人。一次主动的对话，成本极低，但打开的可能是一只大宝箱。这是那种赢面极大、亏钱概率极小的事情，值得每个人都试一次。
