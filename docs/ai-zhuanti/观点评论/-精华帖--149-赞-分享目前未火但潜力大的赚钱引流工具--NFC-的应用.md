# (精华帖)(149 赞)分享目前未火但潜力大的赚钱引流工具——NFC 的应用
最近刷到一条特别有意思的分享，来自刘大猫，他说自己已经很久没在龙哥盟发帖了，但翻翻历史记录，当年他聊视频号、AI、快团团的时候，基本都还是没人关注的早期。2022年他写AI应用展望，那时候绝大多数人连AIGC是啥都不知道。
这次他带来的新判断是：一个还没被大众盯上，但未来一定会被广泛使用的赚钱引流工具——NFC。
听起来是不是有点耳熟？我们住酒店时，前台给的那张房卡，里面就装着一块NFC芯片。服务员在写卡器上录入你的房号，你拿卡一刷就能开门。它的本质，和蓝牙、二维码一样，都是用来记录和读取数据的技术。
既然这玩意儿并不新鲜，凭什么说它有巨大的商业价值？
刘大猫说，他前几天买了几张NFC贴纸，发现这背后藏着非常实用、能落地的商机。关键引爆点在于：苹果终于向这项技术松绑了。
以前iPhone对NFC开放得非常克制，主要是出于安全考量。所以支付宝的“碰一碰”支付，一直没被大范围推广起来。但现在苹果全面支持NFC了，安卓更是早就放开了。也就是说，现在每个智能手机用户，不仅能读NFC芯片，还能自己往芯片里写入各种数据。
打个比方：以前我们只能用手机去“识别”二维码，而现在，你可以亲手“生成”自己的二维码了。二维码在线上线下已经渗透到商业的每个毛细血管，而NFC的普及，才刚刚开始。
刘大猫自己做了几个最简单的尝试，比如在客厅贴一个NFC芯片，把家里WiFi密码写进去。以后来了客人，或者自己换设备上网，手机轻轻一碰，密码直接就弹出，再也不用念那一串又长又难记的字符。
听起来只是生活小便利，但这里面藏着不少普通人能上手赚钱的门道。
第一，帮别人“生成NFC”本身就是一门生意。回想二维码刚火那阵，“草料二维码”这个网站，就靠帮用户在线生成二维码，做得风生水起。等到NFC遍地开花的时代，完全可以用相同逻辑做一个“NFC版草料”，专门替小白用户完成芯片写入，让他们零门槛上手。
第二，企业端的玩法更广阔。基于NFC做业务流程管控、做营销活动策划，都是很好的切入点。商品的包装盒上、产品手册上、线下门店的物料上，只要能引导用户完成某个动作，放一张NFC芯片贴，体验感简直拉满。
所以，不管是帮人做芯片，还是帮企业落地应用，又或者把自己营销链路里的引流、私域转化环节植入NFC，都是值得研究的方向。
支付宝已经在为“碰一碰”做市场教育了，等更多用户养成这个习惯，NFC的生态会随之爆发。有兴趣的朋友，现在提前研究，正好能卡在风口前面。
评论区里还有圈友分享说，有人用NFC发小红书笔记——手机靠近卡片，自动读取里面的内容，点一下就发布，第一次见觉得太神奇了。也有人提到，自己手里还剩一堆测试用的贴纸，本来是想给老外客户用的。
看来，这个赛道确实已经开始被盯上了。
