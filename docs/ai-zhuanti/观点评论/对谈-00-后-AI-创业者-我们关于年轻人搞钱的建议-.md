# 对谈 00 后 AI 创业者，我们关于年轻人搞钱的建议。

大家好，我是龙哥。

读书那会儿，我身边人都在为进大厂拼命刷实习、改简历，而我已经靠自媒体赚到了第一桶金。如今自己创业，认识了更多做风口项目的朋友，看着他们不断抓住机会、不断盈利，再看看许多人仍然挤破头想进一个“不稳定”的offer，说实话挺唏嘘的。

时代早就变了。大厂不等于稳定体面，不少中厂大厂的核心业务甚至已经看不到增量。现在你不需要懂技术，AIGC会替你搞定；互联网把做生意的基础设施全铺好了，一人公司和个人IP的门槛前所未有地低。产能过剩的时代，缺的不是产品，而是能把东西卖出去的人。

所以，今天想和各位分享几条年轻人最该懂的赚钱认知。这些是我从一个校园博主走到创业者，亲自拿到结果后总结出来的，也和另一位00后AI领域IP@泛函聊完之后，梳理出的核心重点。

## 1. 真正拉开差距的，是这三项能力：写作、审美、算法思维

我过去三年成长速度很快，靠的从来不是文凭，而是这三件事。

**写作，不是要你当作家。**

不需要写出鲁迅级别的文章，也不需要拿什么作文大赛的奖。你只需要学会把自己遇到的困惑写出来，把自己的思考写清楚，就已经能解决生活中大部分问题。

困惑写出来，别人就能给你回应，帮你快速成长；思考写出来，别人就能看见你脑子里的东西。当你的思想能影响别人的思想，你就有了影响力，有了信任，而信任是可以变现的——做自媒体、做宣传、卖任何东西，底层逻辑都是这个。

**审美，不是要你做设计师。**

你不需要精通PS，但要具备基本的视觉判断力。知道哪些颜色放在一起不突兀，知道图案怎么摆看着舒服，懂得调整明暗、字号、留白，让信息呈现得更美观。

这样你能设计出一张好看的海报、排出一版舒服的图文，能给产品做漂亮的包装，能把简历润色得更有质感，能穿得大方得体，也能做出一套让人眼前一亮的PPT。

人是视觉动物，好看的东西，才会让人有耐心多看一眼。

**算法思维，不一定要会写代码。**

但你得明白互联网的推荐逻辑，知道平台凭什么给流量。我做小红书时就爱用算法去思考：一篇笔记数据好，就会被推到更大的流量池，比如点赞过100，进入下一级，继续表现继续推。理解了这套游戏规则，你自然知道内容应该怎么设计。

## 2. 去创业公司实习，比去大厂“镀金”更能让你懂赚钱

读研期间我在三家创业公司实习过，听到最多的一句话是：“这个产品有需求、有市场，所以我们要做。”

在大厂完全是另一回事。我实习时听到的大多是：“我们要做个xx，你去把xx做了。”没人告诉你为什么做、价值在哪。因为业务已经很成熟，你进来只是当一颗螺丝钉，维持运转就够了。

在创业公司，你才会真正对“行业”和“业务”有概念。你打交道的人是公司1号位、2号位，你能近距离看到老板怎么思考业务、怎么判断方向。而在成熟公司，你天天想的可能是“阿里好还是字节好”“运营好还是产品经理好”，视野容易局限在岗位本身。

大厂有光环，但未必稳定，也未必开心，中年危机照样会来。创业公司，其实是另一条值得认真考虑的路。

## 3. 别给老板打工，要给自己攒作品

你在第一份工作里得到了什么？记录下来，它会成为你下一份工作的最有力证明。哪怕做得不够好，也一定比一张白纸强。

“凭什么说你能做好小红书运营？这是我的账号，你看数据。”

“凭什么说你能胜任品牌岗位？这是我公开发布的一些观点。”

一个小红书账号，就是你的作品集。有了这个作品集，双方前期沟通成本会大幅降低。我经常收到私信问能不能去讲课，也会在找合作时直接甩主页链接。

作品集要体现你的专业素养和技能。你发表的观点，代表你对行业的认知；你拍的照片、写的文字，都是能力的证明。做业务相关的，一个个人IP就是一个最小的商业闭环。

人这一辈子都是在为下一份工作做准备，不管你有没有意识到。你对待当前工作的态度，已经决定了下一份工作的起点。所以，你的工作不是为了完成老板的任务，而是为了打造一件属于你自己的代表作。

## 4. 个人IP，是普通人最小的商业闭环

哪怕你只有100个粉丝，只赚了10块钱，你也已经跑通了“怎么来钱、怎么卖货”的全流程。有了这个感知，你接下来要琢磨的，就是怎么把100粉变成1万粉，把10块钱变成1000块。

你也不一定非要那么多粉丝。单价1000块的产品，有10个精准粉丝，照样能赚到钱。

这个思维能迁移到任何岗位上去，因为互联网早就把基础设施准备好了：平台给你流量，开店几乎免费，你只需要发出声音去吆喝。只要你在互联网上表达，你就是一个IP。

以上，是这次对谈后我整理出的重点。希望对你有一点启发。

赚钱的路有很多，但认知对了，路才会越走越宽。
