# 一.前期判断与调研【1.5h】

思路要放在大行业里找小切口，也就是在巨头光环下找垂类缝隙

这句话是今年暑假广州曹大分享会上的，我记到现在

## 1.市场体量与进场时机

体量我首选巨量算数，看全年曲线

是大众盘还是小众盘

【能被巨量搜到的，大概率已是大众盘】

是全年刚需还是季节性爆发

【看波段走势和峰值】

拿我熟悉的教育举例：

把巨量算数拉到一年周期

全年刚需的是雅思

中间有个异常尖峰，这种基本直接忽略，多半是同名干扰

![](img/zhuanqian_357eb7db5f13e997b57f5052360e4180.png)

雅思全年都在考，每月四次，申请季前需求最高

强周期的是四级

峰值很明显，一年两轮报名两轮考试

![](img/zhuanqian_51d8fdb35f69fde7e8708f18726be4d0.png)

那什么时候进场

有点像炒股，低位埋伏，高位收割

也就是均线以下往上走的阶段先吸精准粉，等到情绪最高点做泛粉

情绪顶点通常是考后，这个时候关注度虽高，但真正需要服务的人已经不需要了，围观的人居多

![](img/zhuanqian_caac38ae8c42ae45e9bc65d58d0d084e.png)

放一起对比能看出受众空间，四级盘子更大

但盘子大往往意味着大厂扎堆，个体机会变少

![](img/zhuanqian_d1857de719b5b728aab70983373e3f4e.png)

所以需要继续往下做竞品研究，进入第二节

### 近期是否出现低粉有效爆款

盘子大的赛道，近3-4天通常能看到素人低粉的变现型爆款

这个法则用来判断赛道是不是太冷

如果3-4天都没有像样的笔记，要么蓝海到没人做，要么赛道违规频发，号活不久

【也可能意味着全站都在被限，素人活一天算一天，类似保险、律师这种】

## 1. 给自己设限

最怕听到的一句话就是：我是新手，我不会，能做吗。

亲爱的，谁不是从新手过来的呢。

我到现在还记得去年赚钱让我去直播。那整整一周我都没睡好，第一次直播，体育课时我蹲在球场边一个人emo、焦虑。我把往期直播翻了个遍，B站上把沟通与表达的课刷了二三十遍，晚上做梦都梦见自己说错话被全网嘲然后惊醒。

那几天我每天都要跟青柠说一遍我好紧张。

舍友问我怎么了，我说周三晚上要直播，我没播过，压力很大，很怕。

她说，怕就别播呗，我肯定就放弃了。

我后来想了想，对啊，为什么非要硬上呢。

后来我发现，如果这次因为怕就缩了，以后每到人生岔路，我都会在逃避里错过更好的自己。

那天播了什么我早忘了，反正数据还行，人均观看9分钟，还给赚钱带了一单。

到今年，跟朋友约直播，早上说好晚上就开播了。朋友看着我熟练发预告、整理问题、摆灯牌，惊讶说你这是老手吧？我讲，没有，这是第二次。有了第一次，就熟了嘛。

就像上面说的香港身份选题拆解，我也是第一次在搜索框里敲下这个关键词。

## 2. 好奇心

初一那年我在加拿大上暑校。老师下课看到走廊外一排中国学生都在刷手机，忍不住感叹：guys，你们的好奇心去哪了！

后来我英语一直一般，但这句话我记了一辈子。

人家刚坐了十五个小时飞机到温哥华，却整天只盯着手机，对从没见过的世界一点都不想了解。

后来在赚钱认识了很多人，发现这些做得不错的人好奇心都强得离谱。

路边摆摊能算营收，路边银行能聊起投资，去SKP买东西能研究代购的汇率差能赚多少。

这些研究看起来好像没什么用。

但其实你已经默默攒了一堆珍珠。

等到某一天因为一个巧合，它们就被串成了一条项链。

所有的起点，可能就是某天刷到一个帖子，因为一丝莫名其妙的好奇，点进去搜了一下……
