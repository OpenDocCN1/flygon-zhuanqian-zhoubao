# 我，十年程序员，在杭州夜市摆摊卖AI三个月，终于看清了现实
大家好，我是一名写了十年代码的老程序员。之前一边上班一边折腾自己的应用，从短剧到社交，我独立写的产品不止一款，而且如今都在应用商店正常运营。后来越来越觉得精力跟不上，索性辞了职，把全部时间押在自己项目上。眼下业务还算平稳，只是用户增长找不到突破口，市场渠道也没太多新路，于是动了看看新方向的心思。
一次非常偶然的契机，我稀里糊涂就跑到杭州人流最密集的武林夜市，支起摊子“卖”AI。当时网上的AI被捧成了神话，我就想验证一下，这种高科技在线下夜市到底有没有人买账。结果摊子守了整整三个月，最深的体感是：虚拟世界里的喧嚣，和现实世界里的冷清，简直像两个完全不同的物种。
最开始几天就是大型尴尬现场。人流量是真大，但大家顶多瞟一眼，真正停下来问的都没几个，更别说成交。首战几乎可以算一败涂地。我不禁开始怀疑：满屏都在喊AI赋能、万物AI，这玩意儿是不是就是镰刀？后来冷静下来慢慢琢磨，心里又有了另一层答案——不是AI这个工具不行，而是我压根没找对打开方式。
网上那些AI应用，基本是用户主动凑过去找需求；可夜市不一样，路过的人凭什么停下来？我得让价值在一眼之间就被看见。想明白这一点，我彻底调整了思路，不再拿AI硬套，而是弯下腰去研究夜市人群真正需要什么。从那时候起，我开始动手写一套专门为夜市场景设计的小工具，也就是后来那个小程序的雏形。
开发过程踩坑无数。技术本身其实不是最难的，最难的是让一个完全不熟AI的人，也能毫无负担地用起来。摊位网络差、响应速度慢、操作步骤一多就没人用……这些细节随便一个都能让项目翻车。没有捷径，只能一次次拿真摊真人来试，把不好用的地方反复打磨。
三个月折腾下来，我对AI的看法彻底变了。它不是什么风口神器，更不是赚钱密码，它就是一个工具。能不能创造价值，取决于你有没有真的去解决一个具体问题。靠概念炒作起来的虚火，终归会散场。所以这个小程序我决定继续做下去，不是为了追热点，而是想看看在普通人的日常里，AI还能不能挤出更多的可能性。
这段摆摊经历，打碎了我原本对AI的美好滤镜，也让我重新看清了方向。如果你也在观望AI，别着急相信各路“爆炸干货”，不如找个离生活最近的地方，自己亲手试一次，让现实告诉你答案。
