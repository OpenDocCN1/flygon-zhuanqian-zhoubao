# 一年时间，我是怎么被赚钱重塑的？
作者：龙哥

作者视角：七天@龙哥盟

曾经的我，对自己的人生设想很简单：做一个写作者，出一本书，采访紫霞仙子那样的人物，采访那些闪光的名人。文艺，是我给自己贴的标签。

后来我进了大厂，成了那个在互联网公司里挣扎的年轻人。出于对“逃离大厂”叙事的共鸣，我甚至辞掉安稳的工作，去做线下青年社群。22年夏天，我在杭州几乎每周都办一场活动。最有记忆点的是那个为大厂离职者做的毕业展，最后一件“职场礼物”是一个实体的肉饼，策展人说，这是老板画给他的饼。

二楼我们还做了一个叫 B 面人生职业博物馆的展区，邀请20个人来讲述离开大厂后的20种可能。看着热闹，但模式问题很快暴露了：痛点抓得不准、线下成本太高、完全依赖主理人推动。做不下去。

23年初，我又投身到另一个为大厂转型人群服务的社群项目里，最后同样止步于看不到商业化路径。

也是2023年，我第一次加入了赚钱。虽然只有一年出头，但前半年我几乎没看，打开次数不到十次，信息密度太高，消化不动，差点直接放弃了。

转折点在24年的418续费决策。我给自己立了个笨目标：在赚钱上发布100个风向标，用这个过程强行训练自己的商业脑。

时间一晃，干满一年，我不仅要参与这届赚钱25年的418，还要负责内容运营和宣发的工作。更意外的是，每周都能近距离接触龙哥，跟他讨论内容、交流思路，连答疑解惑的机会都有。对我来说，这比上班的福利还实在。

再回到线下的社交场合时，我明显感觉到自己变了。聊项目，不再只说“有趣”“有创意”，而是下意识去拆变现路径、商业闭环、前沿玩法，有一套清晰的判断框架。

有位很久没见的老朋友见面就说：之前在你身上只感受到文艺女青年的气质，现在你头顶上怎么挂了个“行走的赚钱推荐人”的牌子。这句话挺准。

从对视频号直播的认知，到如何把流量、产品、运营打成组合拳，我现在讲起来已有模有样。谈不上炉火纯青，但绝对不是从前那个只用趣味性来评估活动的人了。

理解商业逻辑，理解变现本质，理解现金流和利润，理解一个好项目到底长什么样。我曾以为这条路会很遥远很陡峭。回头一看，不到一年，一切就从模糊到清晰了。轻舟已过万重山，大概就是这个感觉。
