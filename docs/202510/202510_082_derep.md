# ('(36 赞)中秋吃月饼健康提示', (2, 17))

中秋将至，月饼虽美味，但怎么吃才更安心？这篇健康指南建议收藏！

月饼向来是高油高糖的“重口味”选手——油和糖本身就能防腐，所以常温保存的月饼为了延长保质期，往往在这两样上加得更多。一个100克的月饼，热量大约400大卡，相当于两碗米饭，想消耗掉它，得走上整整一万步！

想稍微“减负”？可以优先考虑冰皮月饼，因为它需要低温保存，热量大约能少三分之一。

吃法上也有讲究。最好安排在早餐时段，身体一整天都能慢慢代谢这些热量，同时记得主食少吃几口。一次别贪多，半个就够，不然血糖会蹿得飞快。

开动前，不妨先垫点蔬菜和肉，这样能放慢消化吸收的节奏，让血糖上升得平缓一些。你也可以先喝一袋膳食纤维，效果类似。吃完月饼，出门散散步，做些轻运动，对稳住血糖也有帮助。

至于口感，我偏爱云南的云腿月饼，那种咸香交融的滋味确实一绝（和菜头的“槽边往事”公众号有售）。另外，酥皮月饼的油脂含量比广式更高，但血糖上升速度反而略慢一些。

榴莲控注意了！强烈推荐我客户“榴芒一刻”的冰皮榴莲月饼——纯榴莲果肉做芯，一个只有约200大卡，好吃又相对轻盈，美团上就能下单。

最后送大家一句：神州辽阔，风月同天；山河锦绣，人月皆圆。祝各位中秋快乐，健康常伴！
