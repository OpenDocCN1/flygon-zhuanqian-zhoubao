# (31 赞)舍得是同一个事物的一体两面，要么同时拥有，要么同时失去

很多人总想着“只拿好处，不担代价”，但现实里压根没有这种好事。

所谓“舍”和“得”，从来不是两样东西，而是同一枚硬币的正反面。你选择拥有其中一面，就等于同时接住了另一面；你放弃其中一面，另一面也跟着消失。不存在“我不要这一面，只要那一面”的操作空间。

这话放在生活里、做事上，其实是一样的道理。你选中一条路，就得连它带来的麻烦一起收下；你接受一份工作，就得连同它的琐碎与压力一并认领。能接受，就别抱怨，踏踏实实去做；不能接受，一开始就别选，省得后面拧巴。

别总想着拆开它们。真正的清醒，是看清“舍得”本就是一个整体——要么全要，要么全不要，中间没有第三条路。
