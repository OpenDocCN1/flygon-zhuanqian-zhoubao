# 别只忙着干活，要忙着攒“抄不走”的家底
作者：龙哥

读鲁梅尔特的《好战略，坏战略》时，被一段话点醒了。

企业买皮卡、买办公设备、租仓库、招高中生大学生、请律师会计师，这都是必备的经营要素，却算不上战略资源。因为对手想买就买得到，差不了多少，根本构不成真正的竞争优势。

真正值钱的，是企业在长期经营里一点点堆出来的、对手难以照搬的东西。不是花钱就能立刻到位，而是需要时间、投入和积累，复制成本极高。一旦拥有，就能形成持久的优势。

这就是战略资源的本质：我有了我才强，对手想有很难。

我想到一个很生动的例子。大约五六年前我服务过一位做坚果生意的安徽老板。他十多年前就开始大面积种植山核桃。山核桃不是种下去第二年就能收，它要十年左右才结果。

对他而言，那一片山林就是战略资源。时间改不了，十年就是十年。竞争对手今天才想种，明天才有果子捡。时间本身就成了壁垒。

这跟我自己的经历很像。我们其实也是在埋伏。

2013年我就开始做👸号，现在粉丝68万；2019年入场短视频；2022年开始写书，《营销笔记》《卖货真相》加起来卖了30万册+；2022年底起做读书群，现在已有247个群在运营。

回头看，这些并不只是工作记录，而是十几年间一点点攒下来的沉淀。粉丝、内容、出版物、社群网络，都是竞争对手短期内砸钱也买不来的长期资产。

可惜的是，很多创业者忙了好几年，停下来一看，账面累了，人累了，企业却没留下什么能用的家底。和刚进场的新玩家相比，并没有质的差距。

这才是最可怕的。

同样的问题放到个人身上也成立。你从业十年，沉淀下来的是什么？除了会做事、会加班，你拥有了哪些别人短时间追不上的资源、连接、口碑和复利资产？

战略资源不是买来的，是刻意攒出来的。想清楚自己在为十年后的自己准备什么。
