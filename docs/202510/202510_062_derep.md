# 先说结论：把有限的注意力投给能滚雪球的事，立刻远离那些“先甜后苦”的坑
作者：龙哥

很多时候我们不是不够努力，而是把力气错配了。

真正值得All in的，是那些当下看不见爆发、但时间越久越吓人的事。它们没有即时反馈，却自带复利属性，你投入的每一分心力，都会在后面被加倍奉还。

反过来，有些事表面上很香——马上能看到结果、马上能得到认同，甚至马上能赚钱。但扒开来看，它们消耗的是你的本金：精力被透支、判断被扭曲、长期竞争力被一点点掏空。短期赚一点，长期亏一大截，这种买卖坚决不做。

机会成本比履历更残酷。今天你在“短期甜蜜回报”为负的事情上花一小时，就是和你未来的巨大回报失之交臂。

选对赛道后，坚持才有意义。方向错了，卷得再狠也只是白忙。

—— 礼新：选择真的是很重要，方向不对，努力白费
