# 35岁被主业和副业夹在中间动弹不得？其实你是掉进了双避冲突的陷阱，能破局就两步

前几天刷到一个35岁朋友的提问，简单一句话，道尽了太多人的现状：主业已经榨干了所有精力，想做副业又完全抽不出时间，该怎么办。

看完评论区，我一下子被拉回了自己被困的那四年。那段日子我几乎每天都在和自己打架，最后差点被耗成人干。

后来我才明白，这根本不是“要不要辞职”的选择题，而是心理学里典型的双避冲突。好消息是，只要搞懂机制，破局路径很清晰：先把内耗止住、把能量补回来，再跳出二选一的死胡同。

**一、为什么越挣扎越卡住？**

表面上看是时间不够，其实是能量被双向吸干。

留在主业，是睁眼上班到家瘫倒的透支，是收入上不去的停滞，是每天抗拒的情绪磨损。
去搞副业，又是找不到下家工作的恐惧，是房贷娃娃的现实压力，是没有稳定现金流的焦虑。
两边都是坑，你想避开A就掉进B，想避开B又怕A。

库尔特·勒温说的双避冲突就是这个状态：两个选项都带负面结果，大脑在两者间反复横跳，决策点越近，焦虑和瘫痪越严重。
这像一个后台永远开着的程序，无声无息地吃电量。你每天都在纠结、内耗、自我攻击，心理资源却在持续流失。

霍布福尔的资源保存理论也印证了这点。注意力、意志力、情绪调节都是有限资源。长期消耗不补，必然进入资源耗竭。手机电量1%还想跑大型游戏，结果就是死机。

我当年就是这样。刚开始还有点劲，能见缝插针学东西、发视频，感觉像在黑暗里找到光。可很快工作收紧，领导期待变高，副业的时间被一点点挤掉。

最折磨的是那种循环的自言自语：不想上班→不上班会饿死→得做副业→太累了根本没精力。早上还没出门，大脑已经打了上百回合。到了公司，内耗只是隐身到后台，在开会间隙、上厕所、坐地铁时时不时冒头。下班回家直接宕机，只想躺平。然后又开始自责：为什么效率这么低？

这不是意志力差，这是心理能量被双避冲突点空了。

**二、我是怎么走出来的？先止损，再找路**

在国企干了18年，39岁那年我彻底裸辞。不是因为我多勇敢，而是实在耗不动了。那段至暗时期我连续失眠、肠胃紊乱、迟到被批评，副业的数据也不好看。被领导约谈的那天，我第一次哭到停不下来，才清醒意识到：再这样烧下去，起跑线都没了。

后来回头看，心理学其实早就给过答案。陷入双避冲突时，有两条基本方向：一是暂时退出冲突场域，给自己喘息；二是改变认知，跳出A或B的二元对立。

我无意识地走了两步：

第一步，先把能量拉回来。
第二步，等能量回来后，再去看第三条路。

很多人以为第三条路是某种具体方案，其实它首先是认知松绑。你可能会意识到：主业可以只是工具而不是归属；副业不一定要整块时间，碎片积累也行；我也可以先活下来，再慢慢迭代。龙哥说副业不需要整块时间，本质上说的就是认知升级。

但认知升级的前提是能量。累到只剩下苟活，你连学习、反思、试错的力气都没有。所以顺序不能倒，先照顾自己。

**三、能量恢复怎么做？先止血，再输血**

原则很简单：止损大于加油。你一边漏油一边加油，永远空。

止损的办法，分心理、行为、物理三层。

心理层面，主动降级投入。把工作定义成“生存工具”，别再幻想升职加薪。标准往下降，期待往下降，自责也跟着降。
行为层面，学会说不，拒绝无效社交和额外责任，划清工作与生活的边界。
物理层面，用假期、换环境等方式暂时离开消耗源。

补充的办法，就是把油加回来。
生理上，保证睡眠，真正放空，每天哪怕半小时散步。
心理上，做冥想、做喜欢的小事，重建掌控感。
关系上，多和能给你安全感的人待在一起。

我当年用的三个笨办法，至今觉得有效。

一个是心里罢工。告诉自己，我现在拿工资而已。以前的主动承担、上进心全部收起来，练习说“我不会”“我做不了”“太复杂我需要帮助”。效果立竿见影，上班的主动消耗少了，能量损耗也慢了。

二是建防火墙。下班就下班。手机调静音放远，领导消息先放三小时再回。工作资料不带回家，周末活动能不去就不去。这段被夺回的时间，终于属于我自己。

三是物理隔离，请了一段长假。这是止损加补充的组合拳。每天睡到自然醒，身体开始恢复；抽空试做一点副业的小项目，对副业的认知慢慢变了；每天走路运动，和家人好好沟通，思考真正要什么。能量回上来后，视野才清晰起来，我才看得见下一步。

**四、最后想说的话**

复盘这段经历时，我曾经很羞愧：拖延、拒绝、请假、最后辞职，看起来不体面。甚至觉得自己有点算计。

现在用心理学的视角看，那些选择不过是求生本能。我在无意识里把“离开场域”和“改变认知”做出来了，那些看似不光彩的策略，其实都是在保护自己。

如果你正卡在主业和副业的中间，每天被两种恐惧撕扯，请先对自己温柔一点。这不是你不行，是你的系统过载了。

先把能量救回来，再去找属于你的第三条路。你已经在努力了，只是需要一个喘息的出口。

我是欧欧，一个在商业世界里想活得真实的人。如果你也在这个节点上卡住，欢迎交流。
