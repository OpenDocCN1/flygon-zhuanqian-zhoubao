# ('(30 赞)我用 Sora2 API+n8n+飞书多维表格批量产出爆款视频！日播破 1w！', (2, 47))

国庆假期，大家都在刷Sora2的各类测评，我却偷偷搭起了一条“自动视频流水线”。靠着这套组合，我的视频号单日播放量直接冲上1w+！这波热度，我算是踩准了。

先说说自己：我是轩麟，坐标广州，主业是AI算法工程师，副业一直深耕n8n。9月份我同时参加了生财的n8n航海和垂直小号两个项目，连续打卡21天，拿下了“行动的巨人”称号，还在广州做了两场线下分享，另外输出过一篇n8n主题的公众号文章。说实话，加入生财才三个月，收获远超预期。

国庆当天我还人在外面，朋友圈一下子被Sora2刷屏，各种测评也是接踵而至。作为一直想在n8n领域做出点名堂的AI自媒体博主，我怎么可能放过这波热点？于是火速回广州，从10月2日到10月3日，连续两天反复debug、反复调优，终于把Sora2的API接口和飞书多维表格成功打通，并接入了n8n自动化流程。10月3日，我把用Sora2生成的三条视频发到了视频号，结果让我自己都吓了一跳——平时播放量一直不温不火的账号，当天突然像坐上了火箭，单日播放量直接破万，妥妥的异常值。

这次经历让我觉得，这套工作流太值得分享了。所以我把完整的搭建过程整理成了教程，希望能帮助更多圈友直接复刻。今天上午已经有圈友照着教程轻松跑通了，可见可复制性非常强。这里也特别感谢学长、教练一直以来的鼓励、支持与陪伴，还有圈友在Sora2 API调试过程中给到的关键帮助。
