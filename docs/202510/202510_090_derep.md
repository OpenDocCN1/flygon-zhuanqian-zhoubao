# (62 赞)转型期，不要着急，以年来记，给自己时间。
作者：龙哥

前几天看到一位读者的提问，挺有代表性的，分享给大家。

他今年28岁，坐标广州，做房产买卖，年收入30万左右。自己会做自媒体，擅长线上获客。他的目标很明确，想把年收入做到100万。在房产这条赛道上，他琢磨过三条路：做到城市头部、等楼市行情、转型做财经IP——但每条路都不好走。最近他参加了一场📕虚拟资料的航海活动，觉得平台有流量红利，可房产内容又容易踩规则红线，很矛盾。于是问龙哥，到底该继续深耕房产，还是转向📕电商，或者去看出海的机会？

龙哥的回答我觉得既坦诚又务实，核心说了几点。

关于房地产的未来，他说自己看不懂，但纵观身边认知比他高的人，对这个行业的整体判断是没什么大意思了。如果行业天花板很低，那趁早转换赛道可能反而是正确的决定。

关于📕虚拟资料这件事，他给了个挺妙的视角——与其说是在卖资料，不如说是用低成本的轻内容产品去满足一部分人的基础需求。所以这不仅是卖虚拟产品，更是低成本切入一个新行业的方式和入口。至于进去之后能做多大，完全取决于行业趋势和个人能力，有人可能一个月赚几千，也有人能把它滚成年入千万的大生意。

关于电商，他说长期不太看好，自己也不愿意做，可能因为习惯了做软件和内容类业务，不愿碰重投入、重货品的模式，毕竟很多电商的利润到头来都堆在库存里。但他也承认一个现实——电商可能是最让普通人赚到钱的领域之一，阿里巴巴那句“让天下没有难做的生意”，背后就是无数普通人靠它获得了收入。

关于出海，他提到现在更准确的词是“全球化”。他认为不管做什么方向，都要关注这个大趋势，理解世界正在发生什么，对投资、创业、未来的生活甚至孩子的教育，都有长远意义。

那落到这位读者身上，具体建议是什么？龙哥的第一条是：把你自媒体的能力继续放大，这是你的核心优势，有这项能力在手，很多事都会好办很多。第二条：找一个相对朝阳的行业，慢慢投入，长期深耕。第三条：关于100万这个数字，在寻找第二曲线的时候，别急着定这种定量的目标——定了其实也没用。不如定定性目标，比如“多了解几个行业，看看哪些长期机会更大”，这种目标才真正有引导力。

最后那句话，我很喜欢，也送给正在转型路上的你：转型期，不要着急，以年来记，给自己时间。
