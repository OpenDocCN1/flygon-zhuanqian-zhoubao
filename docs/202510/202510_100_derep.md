# (34 赞)先用“大猩猩理论”筛选掉 99%的标的，然后才有什么时候入场的 luxury。
作者：龙哥

很多人每天最纠结的问题，就是“什么时候上车”。但老实说，这个问题本身问得太早了。

真正的高手，第一步根本不是挑时间，而是挑标的。他们会用一套叫“大猩猩理论”的方法，先把眼前那熙熙攘攘的候选对象过滤掉99%。剩下那1%，才是真正值得你花心思去研究入场节点的对象。

换句话说，时机这个东西，从来不是首要问题。当你还没有筛选出对的标的之前，谈“什么时候买”纯属空中楼阁。就像评论区里那句精辟的总结：先确保做对的事，再研究如何把事做对。

顺序对了，一切才有意义。先用大猩猩理论把鱼龙混杂的市场筛得干干净净，留下一小撮真正有潜力的选项。到这一步，所谓“入场时机”才配得上称为一种奢侈——因为你有资格挑了，而不是被市场逼着碰运气。

所以，下一次再想追问“何时入场”的时候，不妨先问问自己：我面前这几百个选项，已经用大猩猩理论筛干净了吗？如果还没，那就别急着谈时机。先做减法，再谈时机，这才是真正的 luxury。
