# 每周只干四小时，两个员工躺赚千万美金：Sahil给出的答案让人豁然开朗
作者：龙哥

你有没有见过这样的公司？两个员工，一周只上四小时班，年利润却能轻轻松松做到千万美金。听起来像童话，但Sahil的确把这种“小而美”给做出来了。

一次交流中，有人向他抛出一个很现实的问题：如果一个人完全不会写代码，还能不能活成你这样？

Sahil的回答很干脆，给了两条路径。

第一条：别对代码抱有偏见。很多人一听“写代码”就觉得那是程序员的专属，但AI早就把这个门槛拆掉了。现在哪怕你是零基础，也能靠各种AI工具自己做软件。等到你稍微熟悉一点“无代码”或“AI辅助编程”的玩法，软件就会变成你的杠杆，撬动更大的收益。

第二条：内容就是你的另一根杠杆。这一点与纳瓦尔的观点几乎一模一样。传统的杠杆要么是劳动力，要么是资本，都需要付出不小代价；但像代码和媒体这类杠杆，却能以近乎为零的成本不断复制。不写代码没关系，你可以去写文章、拍短视频、做自媒体，这些内容都会随着时间产生复利，越积累越值钱。

说到底，Sahil能过上“两个人、每周四小时、年入千万美金”的生活，不是因为更拼命，而是因为他找到了真正可以复利增长的杠杆。能想透这一点，哪怕再小的团队，也能活出最自在的样子。
