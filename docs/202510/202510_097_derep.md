# ('(51 赞)为什么孩子努力学习十几年，长大后却赚不到钱？', (2, 30))

最近有不少年轻人和家长在后台问我同一个困惑：一个人从小学算起，一路读到大学甚至研究生，前前后后差不多二十年，可真正走进社会时，却发现自己那身本事根本不顶用。

仔细想想，这确实有点讽刺。假设一个人25岁才硕士毕业，刚开始打拼，再过10年到了35岁，就可能被职场“优化”了，说是“输送给社会”。所谓的赚钱黄金期，满打满算也就十年光景。而前面整整十九年的校园时光，居然没有一门课教过我们怎么面对社会、怎么赚钱谋生。这还不够荒诞吗？还不够魔幻吗？

有人可能会说，教育本来就是培养人才的。可现实是，传统教育更像是一条流水线，目标不是培养有独立人格的创造者，而是制造听话好用的“牛马”。那些顶尖名校之所以看起来厉害，无非是拥有一套最强“牛马”生产线。如果你自己跳不出这个框架，就很难有什么真正的突围。

再往深了说，教育产业本质上是一种人才筛选和社会分层的机制。被筛出来的极少数顶尖人才，还没毕业就被高薪offer盯着，有的被资本追着投天使轮，有的被导师和大佬递出橄榄枝。他们要么手握专利，要么发了顶刊论文，要么在顶级竞赛里拿名次。可绝大多数人只是普通学生，容错率低得可怜。读书路上的每一个岔路口——中考高考分流、高中选科、大学选校选专业、最后选择就业方向——都是分水岭。这些选择背后，其实藏着国家政策和行业周期的走势，而这些信息通常只掌握在少数接近核心圈层的人手里。普通人没有渠道提前得知，每一次抉择都像在赌。赌赢了，路越走越宽；赌输了，路越走越窄。当然，如果能不断提升自己搜索和分析信息的能力，多少能提高一点赢面。

看看现实中的例子：五年前土木建筑和会计还是香饽饽，如今就业却举步维艰；五年前新能源车辆工程一片火热，今天整个行业已经卷到天昏地暗；十年前计算机还是最有前途的方向，十年后大家都在聊人工智能；十年前考公考编是不得已的选择，十年后却成了挤破头的热门。至于哲学、音乐、各类管理学专业，如果没有殷实的家境，哪怕是985毕业同样很难找到好工作。而那些变化飞快的行业，普通大学的教学内容往往严重滞后，根本指望不上。想不被淘汰，就只能靠自己去卷实习、卷竞赛、卷社会实践。

说到底，学校只负责筛选，不负责教你赚钱。真正能让你在社会上立足的本事，从来都得靠自己拼出来。
