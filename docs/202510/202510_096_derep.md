# (57 赞)个人成长中努力与运气的归因智慧

你有没有认真想过一个问题：今天自己手里的成绩，到底有多少是靠死磕换来的，又有多少是搭了时代的便车、赶上了一点好运？

这个问题没有标准答案，关键在于你站在哪个时间点上。

如果你是在为未来做打算，那就别管什么客观限制，只管相信自己能把方向盘握紧。哪怕这种“人定胜天”的念头带有几分自我安慰，你也得死死抱住它——因为只有深信付出必有回报，你才会拿出全部力气去拼。

可要是你已经站在结果之上，回头复盘这一路，那就得换一套算法：你的所得很可能远远超过你的“应得”。这不是谦辞，而是一种清醒。你可以感谢自己，但更要感谢那些托举过你的环境、机会和贵人。

用布鲁克斯的话说：当你以行动者的身份冲锋时，大可以认为自己配得上每一个勋章；但当你以普通人的身份活在世上，就该明白那不过是一种必要的幻觉——没有外界的支撑，你根本走不到今天。

这恰恰印证了菲茨杰拉德那句经典判断：检验一流智力的标准，是看你能不能同时容纳两种相反的观念，并且照样正常行事。

努力与运气，看似水火不容，但真正成熟的人，会在前进时选择“相信努力”，在回顾时选择“承认运气”。这不是精神分裂，而是高级的归因智慧。

所以，最终的答案从来不是“努力更重要”还是“运气更重要”，而是你如何拆分这两种因素，才能对自己接下来的人生最有利。
