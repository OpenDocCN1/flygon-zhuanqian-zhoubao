# 月入过万却活得空心：一个靠自动化搬运起步的年轻人，在求突破

2025年10月9日，有个在赚钱里蛰伏了两年的创业者发出了这样的求救信号。

他是02年的那批人，初中毕业就被迫早早进入社会。第一份“成人礼”就是花钱去学东西，学了不少，效果却寥寥。2023年他正式加入赚钱，从此生活轨迹被改写。入圈后第一站是拼多多做虚拟项目，折腾了一年最终还是宣告放弃。

今年年初的现金流断裂成为转折点。为了压缩成本，他从苏州收拾行李回到了老家运城。靠着低成本的生存环境，他把项目又盘活了。

现在的状态是：月收入稳定在1万出头。

具体打法很清晰：运营着3个📕账号加1个闲鱼店铺，全是虚拟类搬运内容，靠自动化工具在跑，每天人肉介入的时间不到半小时。

另外还经营着一个B站号，参加了深海圈，本月光佣金加商单就已经有2000左右的进账，对他来说已经算是不错的补充。

眼下他最着急的不是钱，是方向。他被2025年的垂直小号风口点燃了野心，很想从搬运工转型成个人IP，目标瞄准👸号和YouTube，渴望拥有一个真正属于自己的声音。

但困扰他的问题也越来越重。

从2023年10月裸辞至今，他几乎一直在单人独居的状态下做项目。房子租在外面，生活圈子基本为零，没怎么参加过航海的线下活动，现实里几乎没有社交。

自动化把工作时间压到极致，于是空闲被无限放大。做完📕和闲鱼的日常维护，就开始进入B站的制作流程，一个视频周期大概4天。时间被填满，却仍然觉得日子难捱，每天都像在打发时间。

他坦白说，空虚、烦躁、累，觉得自己把大量本可以利用的时间浪费了。

于是他问了两个核心问题：像你这样赚钱的人，是不是每天也这么闲，还是早就把时间安排得满满当当？YouTube做IP这条路真的能走吗？如果你说不行，我还是会试。

他最后补充了一句：心理素质没问题，直说就好，我想要的是一条改善生活的方式。

龙哥的回复很克制。

项目层面没什么要特意调整的，继续做下去就好，坚持下来自然会越做越顺。

真正要解决的，是人的问题。

别再自己一个人扛着走了。认真去和几个志同道合、肯上进的赚钱伙伴建立联系，定期见面交流、玩耍。别让自己在创业的道路上孤零零地前行，找几个同路人一起走。

这也是赚钱接下来要重点发力的方向：推动更多线下组局、交流和聚会，核心目标就是让大家不那么孤单。

这是条很认真的建议，必须去执行。

评论区里也出现了不少共鸣。

有伙伴邀请他去赚钱联合办公空间，那里全是上进的人。

也有运城本地人伸出橄榄枝：我在运城，欢迎来聊聊。

还有经历相似的创业者现身说法：我也是23年裸辞在家做了两年多，孤独到煎熬，最后选择出去工作，不是为了钱，是为了社交需求。

提问者也回应说，他正准备开启情感类IP，同时也在考虑回去上班，不是冲着收入，是冲着人际连接。

这篇提问像一面镜子，照出了很多自动化时代的个体创业者：项目跑通了，收入达标了，生活却空了。
