# 还在一个字一个字“喂”AI？这套提示词玩法，让我两周做出爆款短视频

大家好，我是徐徐。

今天想跟圈内朋友分享一段挺特别的经历——作为一个刚接触AI视频和YouTube没多久的新手，我在短短两周时间里，走完了很多人以为要熬几个月才能走完的路。

先简单交代一下时间线：

9月9日，我的第一条视频上线；9月12日，也就是第四天，第四个视频的播放量直接冲上了一个让我自己都意外的数字；之后的七天内，又陆续有两个视频拿到了同样亮眼的成绩。依靠这波表现，我顺利开通了YouTube的初级合作伙伴计划（YPP）。

当然，我不是那种一条视频千万播放、直接解锁高级YPP的天选之子。跟那些大神比，我这个成绩真的不算什么。但反过来想，作为真正零基础起步的人，我这两周里踩过的每一个坑、试出来的每一套方法，可能恰恰是很多同样在门口徘徊的人最需要的东西。

所以我把自己的完整方法论整理了出来，放在这篇分享里。

这篇内容尤其适合下面这几种情况的朋友：

- 刚萌生做YouTube Shorts的想法，但完全不知道从哪里下手、要准备什么；
- 已经发过一些视频，但播放量总是卡在3万、5万、10万这个区间上不去；
- 做视频全靠手动一点点“搓”，时间花了一大把，心力也耗得差不多了；
- 还在靠肉眼刷别人账号找对标，不知道有什么工具能帮你快速定位赛道、挖爆款、做数据分析。
