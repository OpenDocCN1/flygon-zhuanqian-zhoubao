# (精华帖)(477 赞)习惯，就是一个人的命运

很久以前，我根本不信有人能“十年如一日”地做同一件事。比如每天阅读两小时，连续一千多天不断档，累计读掉一千多本——这种话听起来真的像在吹牛。直到某天我翻到自己的记录，才发现上面清楚写着：1717天，每天平均两小时以上，总计1077本书。更值得玩味的是，这些书其实并没有花满十年，因为“得到电子书”这个产品是2019年才上线的。

看着这个数字，我忽然理解了华杉老师。他就是那种每天早晨七点准时坐在电脑前写作的人，而且常年如此，从不间断。我以前觉得这种节奏只有“怪物”才能坚持，现在才明白：那根本不是意志力，而是习惯。

习惯，才是人生最底层的操作系统。

同样是人，你可以把他们分成“大柱子”和“二拴子”两类。同样是AI写代码，AI递来一坨不可维护的“屎山”，大柱子第一反应是骂AI没用；二拴子却在琢磨怎么把需求描述得更清楚、怎么驯服这个工具。几年后，大柱子从GPT-4一路嫌弃到Cursor，再嫌弃到Codex和Claude Code；二拴子呢，已经用AI做了不少真正完整的东西。

同样是如今流行的Vibe Coding，一个习惯张嘴乱讲，翻车了立刻回滚；另一个习惯先搞懂代码为什么不工作，再认真写清输入。几个月后，差距就已经肉眼可见。我身边有太多大柱子，在这个闪闪发光的时代，我只能祝他们好运。

同样是通勤一小时，大柱子顺手刷起了短视频；二拴子从包里掏出一本书。两年后，两人的知识储备就好像活在平行宇宙。

同样是读书，大柱子只在自己的舒适圈里重复；二拴子专挑自己不熟悉的领域开啃。两年后，一个原地踏步，一个悄悄重构了自己的认知地图。

同样是找创业方向，大柱子靠拍脑门、找偏方；二拴子在生活里收集每个人的抱怨。两年后，一个永远在问“哪里有什么需求”，一个手头堆满了做不完的真需求。

同样是做产品，大柱子先把东西造出来，再满世界找用户；二拴子先锁定用户，再动手开做。两年后，一个在冷启动里反复挣扎，一个被用户推着往前走。

同样是做流量，大柱子喜欢跟平台对着干、薅平台的羊毛；二拴子安安静静研究平台规则。两年后，一个号没了，另一个号立住了。

同样是刷👸号，大柱子看到好文章立刻点“收藏”，准备“稍后阅读”；二拴子从不收藏，直接就着屏幕读完。两年后，大柱子收藏了几百篇，却一篇都没有回看；他甚至没发现，自己真正喜欢的只是“收藏”这个动作。

同样是写工作记录，大柱子写的叫“日报”，是为了向领导交差；二拴子写的叫“复盘”，是为了给自己长本事。两年后，一个还在记流水账，一个已经迭代出好几个版本。

同样是投资，大柱子天天研究低买高卖；二拴子多年前就养成了定期定额买入标普指数、特斯拉和英伟达的习惯，买完就放着不动。十年后，一个在追涨杀跌的循环里消耗，一个默默吃到了复利的果实。真有二拴子吗？有。我的恩师傅盛在2016年前就重仓特斯拉和英伟达，一路拿到现在；龙哥也已经持续每日定投特斯拉很久。遗憾的是，在投资这场游戏里，这次我是大柱子。

习惯最大的价值，是让你不用反复说服自己。

大柱子不知道收藏了也不会翻吗？他会不知道刷手机不如读书吗？他会不知道定投比天天盯盘更省心吗？他都知道。可一旦没有养成习惯，他每天都要在脑子里重新辩论一遍“到底该干嘛”，而绝大多数时候，辩论的赢家是“算了”。

我写这些，是因为我最近又坏了一颗牙，第二颗了。很惭愧，我依然没有养成早晚刷牙两次的习惯，每一次刷牙都要靠自我打气。比起从小就把刷牙当作本能的人，我牙齿的下场可想而知。

我身上还藏着很多坏习惯。你要是看见了，千万记得告诉我。当然，如果我撞见你的坏习惯，也会大方指出来。

与君共勉。
