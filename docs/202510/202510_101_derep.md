# 卖飞阿里，真的错了吗？先看看这件事本质上在提醒你什么

每次大涨过后，总有人扒着涨停板截图来问：我上周把阿里清了，现在翻倍了怎么办？

先别急着自责。卖飞，本质上不是运气差，而是你的投资“根据地”还没建起来。

龙哥老师说过一句话很扎心：**你能不能把其中一种投资方式，看得懂，且做得到？能，这就是你的根据地；不能，你就没有根据地。** 这才是问题的核心。

评论区里一位读者戴维斯的经历就是典型复盘。朋友40美元左右开始定投，200美元左右就忍不住全卖了。大家都劝他别动，他出差时跟着同事一起清仓了。现在那只股票已经600多美元。虽然大家未必能拿到600美元的天价，但300-400美元的区间其实很现实。

为什么卖掉？因为最后那段疯狂的行情，谁也预判不了。股市最后那块钱的疯狂程度，真的难以想象。

阿里现在也一样。客观说，当前的位置还不是疯狂的顶点，故事远没讲完。但即便看懂了这个逻辑，真正能做到不被波动带走的人很少。**看懂和做到之间，隔着的是你的根据地有没有建立起来。**

所以，与其安慰自己“就差一点”，不如回头问自己三件事：
1. 我现在的持仓，我真的看得懂它在做什么吗？
2. 我能做到在它波动时不动心吗？
3. 如果做不到，那我需要先缩小战线，找到我真正能执行下去的方法。

卖飞不可怕，可怕的是每次都卖飞，且不知道为什么卖。把一种你能理解、能坚持的方式练成肌肉记忆，这才是避免下一次再出现“卖飞”情绪的根本解法。
