# 在香港靠一张嘴闯出来的局：被嫌弃普通话、主动砍半月薪，最后开出几家店

上周刚从香港回来，机场回程的路上碰到一位阿姨，聊起她在这里安身立命的往事，忍不住记了下来。

十多年前她举家从内地搬来香港，落地就撞上语言的墙。那会儿在街头讲一句普通话，回来的多半是白眼和冷场，想找份普通工作都显得格格不入。

楼下开了一家小吃店贴出招人。她鼓起勇气去试，老板听完口音直接回绝：不招讲普通话的。

她没走，留下了一句话：你开的是1万2的薪水，我只要6千。现在就上。

老板愣了一下，让她先试试。

头三个月，她把工作当成课堂。下班前总带一包零食分给同事，趁着打烊的空档央求大家一句一句教她粤语。听、记、跟读、敢开口，循环往复。三个月后，她已经能自如地和街坊、供应商、客人用粤语聊得顺畅。

会了，她就走了。辞职那天没多解释，只是开始到处看场地、记人流、算成本。

现在回头看，当年那个被嫌弃口音的女人，已经在香港把几个项目做起来了，店开在繁华地段，生意稳定。

环境从来不是挡路的借口。她没花时间抱怨歧视、抱怨难融入，而是把问题拆成最小的一步：先混进人群，再学会他们的语言，最后用自己的方式开局。

命运会给人设局，有心人靠行动拆局。
