# 对自己看用心，对别人看做事

这句话听起来像悖论，其实是成年人用来保全自己、也保全关系的分寸感：对自己论心不论迹，对他人论迹不论心。

说白了就是两套标准，用在两个不同的人身上。

**先说对自己。**
别拿结果审判自己。做砸了、没做好，先问一句：我当时是不是真想做好了？我出发点是诚心的吗？我尽力了吗？
行为是迹，心是心。对自己要论心不论迹，是因为你能看见自己完整的努力过程。给自己宽容的余地，是接纳局限；而论心，是不允许自己偷懒、自我欺骗。既不因失败就全盘否定自己，也不因一次成功就停止反思。

**再说对别人。**
我们看不见别人的内心。不要去揣测动机，也不要替TA找理由。只看他做了什么、结果是什么。
对他人论迹不论心，是理性也是边界感。做得好就认可，做得不好就指出，而不是因为“我觉得他人不错”就放纵不当行为，也不是因为“我觉得他有坏心”就否定所有付出。

反过来的做法，才是让人内耗的套路：
对自己只看结果，不看用心，容易陷入自责和自我否定；
对别人只看动机，不看行为，容易过度解读、情绪化共情，最后把关系搞得很累。

成熟的人，清楚地知道：动机和行动是两个维度。
对自己，以心为锚，校准方向，保持诚意；
对别人，以迹为据，守住边界，保持清醒。

一句老话总结：修己以诚，处人以公。对自己求心，对别人求迹，这就是分寸。
