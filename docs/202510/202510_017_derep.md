# 从零到能发：AI 短篇小说新手的实战上手路线

刚开始带AI小说写作课到现在，时间已经过去大半年了。这段时间里，我见过太多对AI短篇心动却卡在起步的同学。所以我把自己从接触AI短篇到现在沉淀下来的实操经验，全部梳理成了一份从入门到能稳定产出的完整指南。

这篇帖子会带你把整条链路跑通：短篇本身该怎么写、用什么工具更合适、不同工具怎么选，以及写完之后怎么投稿变现。篇幅拉满，基本把新人最容易卡住的环节都覆盖到了。

攻略成稿后，我也专门对照了市面上流行的航海手册版本。虽然表述和细节排序上会有差异，但最终能达成的效果是一样的，朋友们可以根据自己的习惯选择参考。

当然，写作这件事没有唯一标准。想在AI短篇这条路上走得更远，还可以回看我之前发的进阶干货，会更上一层楼。

对了，10月20日有朋友在评论区提了几个文档细节和操作上的小问题，我已经把修正版更新到飞书文档里了：[`x0vg1nkm75f.feishu.cn/docx/Vpytdci0Ao6PFsxnqsZczvsZnp5?from=from_copylink`](https://x0vg1nkm75f.feishu.cn/docx/Vpytdci0Ao6PFsxnqsZczvsZnp5?from=from_copylink)
