# 1998年10月，巴菲特在佛罗里达大学商学院的那场讲话

这篇演讲的整理稿被不少人二次传播，原文出自 [`www.yuque.com/for_lazy/thfiu8/bz0morrywdralfix`](https://www.yuque.com/for_lazy/thfiu8/bz0morrywdralfix) ，整理发布者是龙哥的收藏夹，发布时间为2023年08月18日。阅读入口：[https://mp.weixin.qq.com/s/c_WBjAvlmBYQaULmk72Cig](https://mp.weixin.qq.com/s/c_WBjAvlmBYQaULmk72Cig)

读完之后的评论区里，有一条留言说到了重点。

胖大魔 的话很直白：现实中确实能见到这样的人，有的人跟我同龄，有的人比我小十来二十岁，却被一些糟糕的习惯拖垮，改都改不过来，到哪都让人不舒服。他们过去并不是那样的人，只是习惯一旦沉淀下来，时间越长就越难撼动，最后几乎成了定格。

他提到巴菲特在现场的提醒：年轻人其实处于最好的窗口期，什么样的习惯要养成，什么样的品格想建立，主动权基本还在自己手上，关键看你怎么选、怎么坚持。

这场近三十年前的演讲，讲的依然是人生的底层逻辑：习惯会复利，好的可以托你上天，坏的会把你一点点耗空。窗口一旦过去，代价就高得吓人。
