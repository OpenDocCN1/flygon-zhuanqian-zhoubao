# 想听听一个「财富自由」程序员是怎么聊财富的？

今天这期推荐的分享，主角是被很多人熟知的程序员郭宇。

在播客里，他没有讲教你一夜暴富的捷径，而是从自己的经历出发，聊了什么是财富自由，以及身处自由之后，理财这件事到底意味着什么。

如果你也对「技术人如何看待钱、如何管理钱」感兴趣，这段内容值得完整收听。
