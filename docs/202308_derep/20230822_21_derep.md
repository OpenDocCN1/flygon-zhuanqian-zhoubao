# 赚钱小白，自己感觉找不到热爱，要去做什么

找不到热爱，方向感全无？作为赚钱圈的新人，这几乎是每个人都绕不开的一道坎。

看到别人做项目风生水起，自己却对各种事都提不起兴趣，做事全靠硬撑，心里难免发慌：“我怎么就找不到真正热爱的事？”

其实你不必焦虑，因为很多人正在经历或已经走过这段迷雾。

我也一样，正走在这条寻找答案的路上。特别懂那种“什么都想尝试，又什么都不持久”的无力感。所以，我专门翻了圈内几位前辈的分享，把几篇对迷茫期新手很有启发的文章，整理成了一份资料合集。

它不是给你灌鸡汤，而是帮你去正视“热爱”和“方向”这两个词——值得你静下心，慢慢翻。
