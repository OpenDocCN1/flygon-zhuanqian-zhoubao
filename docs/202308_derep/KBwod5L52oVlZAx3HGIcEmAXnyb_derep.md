上回聊到Google Adsense和Yahoo Feed，最近也有圈友在公众号复盘Google Cash的测试心得，在此提醒一句：海外淘金，切忌照抄别人步骤，否则很容易怀疑人生。核心是要学他解决问题的思维，而不是套他的操作。今天先讲个小教训。

2011年，我在做一个小联盟，跑了几天回本几十美金。有天在论坛看到有人发帖骂这个联盟是骗子，不结款，还有不少人跟风附和。我本来也准备撤了，免得自找麻烦。

临撤之前，我用Google查了下这个联盟的底子：域名年龄、whois信息、差评分布等。结果发现老外评价总体偏好，难道老外在集体演戏？再结合后台日数据和Facebook上的线索分析，我觉得项目大概率可做。

于是继续干，下个月顺利收款，和帖子里说的完全相反。这才明白过来，发帖的人很可能就是为了清场，自己独吃放出的烟雾弹。

此后我连续操作这家联盟两年，累计收入不低于10万美金。这个故事能告诉我们什么？分析力能帮你绕开弯路。

我给学员上课时反复强调，做联盟或做offer前一定要做背景调研：联盟FAQ、用户评价、offer详情页、域名历史等。这些就是操作说明书，不看说明就上，基本就是找雷。看过说明，能少踩很多坑。

分析力还能让你赚得更多。

前年有个做国外网赚的老手在圈里晒了张CJ联盟的收款图，金额很大，单号月入8911美元，还打了码。我当时就推断出他做的offer是什么。

我的逻辑是：假设他账号只跑一个任务，那8911就应该是该任务单价的倍数。于是对8911做因数分解，7×67×19=8911，单价大概率在这三个数里。

再去CJ里筛单，发现19美金的任务没有，7美金的任务有三个，把目标锁定在这三个上，立马去申请并测试。一个月半后收款锁定，A任务就是那位大神的offer。后来我跑了整整七个月，等到下架才结束。分析力重要不重要，大家自己判断。

怎么提升分析力，今天的赚钱主贴大家可以各自交流。

03-05年国内站长圈如火如荼，其中一个被我写进教程的项目就是淘宝拉新。当时一个新用户佣金8-12元，多个广告联盟都有，只要推荐成功就算钱。顺带说一句，淘宝能干掉当年的易趣，并非马云个人能力碾压，而是背后的资本更强。任何时候别过度神化个人，资本博弈才是主线。头条抖音能突围，也是因为张一鸣背后有足够资本挖技术、砸广告。

那个年代站长变现极其容易，主要靠移动彩铃。真正赚大头的不是站长，而是拿下ISP业务的玩家。更夸张的是，彩铃订阅无需二次确认，一堆人群发野蛮增长。好景不长，国家出手，ISP业务迅速萎缩，站长和代理集体哀嚎。但本土联盟如领克特、成果网随之崛起，CPA、CPL、CPS模式在国内普及，国内支付也直接跳过信用卡，由支付宝主导电商。

那段时间我自己在做什么？我也不知道，感觉一人吃饱全家不饿，每天无所事事。恰好美服魔兽世界开服了……

魔兽世界堪称伟大作品，今天的原神也能看到它的影子，只是搬到手机上。当时国外有个职业叫farmer，也就是中国最早的游戏打金。我一开始是自己找金币，后来发现能把金币卖给老外换美元，于是我在武汉大学门口的网吧包了个小厅，雇了几个大学生日夜打金。风光没多久，中国玩家涌入太多，金币价格暴跌，我又回到了纯氪金玩家的身份。

2005年九城拿到国服代理内测。我沉迷魔兽，生活极简：白天睡觉，傍晚起床，电话约朋友钱多多一起吃饭，回宿舍继续游戏。我们一个服一个会，我是会长，他是副会长。

我们因海外淘金认识，但从不谈钱，只打游戏。我不清楚他具体做什么，只知道几件事：一是陪他去银行托收一张4万多美金的支票；二是看见他账户里有200多万存款，还比我早拿到银行黑卡；三是我们每天去同一家饭馆吃饭，两人饭钱不到30元人民币，打车来回却远超30元，因为那家馆正好在我们两家中间。

有天钱多多突然说，我们这样活不下去，在浪费青春，天天打游戏混日子没意义。我问怎么办，他说去加拿大。我天生懒散，有吃有喝就行。问他去干嘛，他说赚钱更容易，青春该闯，而且我们两人一起比单枪匹马强。我觉得有理，问怎么操作，他说先问移民中介。

几天后他带我去湖北饭店的一家移民中介，人家很冷淡，只提了存款等要求，我还没听懂他就说走，这家不专业。后来找到另一家，看着靠谱。我要求不高，花钱办事、省时间、不考语言。最后定下走留学预科路线，规避雅思托福，材料全包。回头看，这家也很不专业，两个大学生去读高中预科，明显不合理。

签证之路开始，我最先拿到结果，被拒，理由是移民倾向。中介说这理由很常见，一般都能用。钱多多那边一直没消息，导致后面一系列麻烦。

我花了点时间在网上查资料，发现学习计划书很关键。我让中介把计划书给我，我用中文写好再翻译。顺带说下，被拒签没什么大不了，关键是搞清楚原因并用强证据反驳。我被拒的理由是移民倾向，我找出了03年办的安利经销商合同，翻译成英文，强调安利是美国企业，代表美国文化，我英文不好想先读预科过渡，再申商科，最后去美国看看。移民官估计觉得英语不好的留不住，于是第二次我顺利通过。这个思维后来被我认识的一位律师进一步深化。

那段时间，我父母最希望我别折腾了，他们觉得这次也没戏。我倒看得开，不签就没机会，钱多多也只是递表，还不如等。钱多多还调侃我：你拒了，要是我过了怎么办？毕竟中介说他条件更好，刚毕业留学很正常。

结果完全出乎意料。钱多多的签证被拒，还直接给了24个月内不得申请加拿大的信，等于进了英联邦黑名单。原因很简单：材料造假。留学签证包装材料是常态，中介就是干这个的。他倒霉在银行存款被质疑做了期限延长，担保金要满18个月，后来解释过去；接着怀疑父母关系不亲，因为他爸在北京，他妈在深圳，他在武汉，用户口驳回了；最后说成绩单造假，要联系学校核实，这下彻底没救。之后我咨询的律师直接评价：中介就是个傻X，把好案子做成死案。一流律师能成事，二流不成功但不会弄死，三流既不成事还弄死。我的律师属于超一流，专打上诉官司，但这个案子做到这份上也无力回天。

之后我的签证下来了，完全没想到。只有我自己清楚原因。当时我犹豫要不要去，毕竟要一个人过去，不想再创业。后来想着签证有效一年，先去看看再决定。

就这样，我阴差阳错、上当受骗、被哄骗到了加拿大。
