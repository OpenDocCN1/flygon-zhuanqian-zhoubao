# ('找到能力的放大器', (2, 10))

你有没有想过，同样一份本事，有人只能换来一份薪水，有人却能撬动整个行业的资源？差别不在能力本身，而在于有没有找到那台“放大器”。

最近读到龙哥收藏夹里的一条分享，点醒了我：真正聪明的人，都在做三件事——把手艺练到极致，把人脉铺向更远，把影响力一点点养大。这三件事不是孤立存在的，它们会互相加持，像齿轮一样咬合转动，最终让一个人从“被选择”变成“有得选”。

打磨手艺，是底层的底气；拓展人脉，是外部的杠杆；提升影响力，是让前两者被看见的扩音器。当它们叠加在一起，你就有了更多自由选择的余地。而选择权，恰恰是这个时代最稀缺的东西。

所以，别只顾着埋头磨刀，也抬头看看：你的能力，正在被什么放大？![](img/894d30a529e7c37bcd3392323c99941c.png)
