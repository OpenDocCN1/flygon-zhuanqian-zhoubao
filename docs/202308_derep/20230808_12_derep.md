# ('调整心态，降低预期，再逐步积累经验和认知', (2, 22))

凌晨的深圳福田，一间三十三块的青旅床位，厨房里煮着一把挂面。这位九月底即将升大四的年轻人，身上只剩四千一百块，手机里躺着三百多封没回音的简历。他读的是二本数据科学专业，会做点网页，剪过视频，拿过省里的算法奖，也曾被外包公司七天劝退。他问龙哥：“如果是你，手上有我这些东西，你会怎么走？”

龙哥没有给所谓的“搞钱路线”。他把提问的款项退了回去，说：晚上给自己加个菜。

他给年轻人的第一句话，不是“你要更努力”，而是“你先别急”。想赚钱这件事，越是想三天就见效，越是容易被那些“月入十万”的镰刀盯上。慌不择路的时候，坑往往是自己挖的。所以第一件事，不是找项目，而是调心态——把期待值从“翻身”调整到“活下来”。先找份能糊口的工作，这个不难。有了基本盘，再去想后面的棋。

有了饭吃，再做选择。如果你还不知道自己适合什么，就跟着航海走，一个项目一个项目地趟。但有一件事必须说透：别“假装在航海”。打卡打得很勤，动态发得很密，但真到动手环节就躲，遇到问题就绕，最后哄的是自己。这种人，龙哥说他不会去叫醒。道理讲一万遍都是耳边风，现实踹一脚就全懂了——事教人，一次就够。

他给这个年轻人留了一段很硬的话：你今天的处境，是你过去所有“无效努力”叠出来的。写了很久日记，剪了很多视频，参加了很多社团，但真正往深处扎根的事情，也许一件都没有。这不是努力不够，是方向太散。看上去忙忙碌碌，实际上和旁边刷手机的同学，本质上并无区别。真正的分水岭，是从“我感觉我很努力”变成“我确实做出了成绩”。

从今天起，把身上那层学生思维彻底剥掉。来到赚钱，就不要再用“我在学习”来安慰自己。这里的精华帖、赚钱认知、实战复盘，才是你往上走的路。看不懂很正常，先选择相信，然后你才会慢慢看见。不是等看懂了才去信，而是信了，才会真的懂。

评论区里有人说，每一句话都很扎心，但每一句都真实。也有过来人分享自己的起步经历：高二去饭店后厨帮工，一天赚八十块管三餐，一家一家问，问了三十多家才有人要。他和龙哥说的是同一件事：先放下身段，先解决自己的一日三餐。能养活自己，才有资格谈机会。

你的今天，是从昨天长出来的。你的明天，则从今天开始生根。之前种下的每一颗种子，无论好坏，都在此刻开花。往后的路什么样，说到底，还是看你今天往土里埋了什么。
