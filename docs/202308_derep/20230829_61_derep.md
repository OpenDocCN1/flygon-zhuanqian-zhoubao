# 134 岁的李锦记，如何穿越周期？

一家酱料老字号，凭什么能活过 134 年？很多人以为靠的是秘方，但真正让它穿越经济周期、时代浪潮的，是刻在骨子里的“变通”二字。

李锦记的故事，本质上是一个战略家的长跑。它不追逐短期的风口，而是习惯把目光投向远方——在别人还在观望时，它早已潜入未知领域，默默蓄力；当机会真正降临，它已经准备就绪，从容接住。

这就像那句老话：环境逼你改变，改变带来通路，通路通向长久。正是这份对趋势的敏锐与对准备的执着，让一个诞生于清代的小作坊，一步步成长为今天横跨全球的酱料帝国。

它用一百多年证明：真正的周期穿越者，不是运气好，而是永远比时代早半步，并且从不打无准备的仗。
