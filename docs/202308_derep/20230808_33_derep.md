# 微读挖粉记：两周多赚回入场费，还攒下2000位书友和8个群



分享人：许帅｜2023年7月31日

进赚钱这段时间，最深的感受就是：官方信号栏里藏着的都是真机会，千万不能只顾着收藏不动手。哪怕先跑通一个小项目，也比干看一百篇精华帖更踏实。

微读拉新，算是自己实打实跑下来的头一桩正事。前几天高杰师兄分享的微读方向信号上榜了，让我一下子想起6月那段经历——我和几位同路人已经在这条路上折腾了两周多。今天干脆把这段过程完整沉淀下来，给想在微读上挖一批高质量书友的朋友做个参考。

这篇文章主要解决两个问题：
1. 怎么在15天左右引入近2000个爱看书的人，并且把他们分装成8个微信群？
2. 怎么把这波流量变成收入，直接把当初交的会员费挣回来？

帖子下面，大家的反馈也不少。有人觉得这方向很有潜力，有人直接回了个“牛”字。

还有位朋友补充说：这套打法，对新手特别友好，特别适合用来挣第一笔零花钱。一是流程很轻，反馈来得也快，能快速验证想法；二是微读平台规则较宽，账号很少被限制；三是之前在这里学过的用户挖掘、吸粉、建群、筛选、成交技巧，都能派上用场；四是攒下的微信好友，以后测试新方向时就是现成的用户池。

另一位圈友则说，微读自带的人群属性，以及其庞大的用户体量，本身就是一座富矿。

作者也在留言里回应：实操过程非常好玩，算是小范围试了试水，并感谢了几位前辈的指点。
