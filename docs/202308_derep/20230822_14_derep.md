# 月薪 4000 被迫裸辞后，我靠龙哥盟航海做到 4W+，我抓住了哪几个关键？



月薪 4000，身上背着几万负债，还被公司摊牌了，你会选躺平还是再赌一把？

我是冰水煮青蛙，来自一个五线养老城市。2023 年初，这三个词就跟影子一样跟着我。最后我选择了all in一次。

其实离职前还有稳稳的 offer 等着我，但我更想试试自由职业，居家办公的那种生活。理想很丰满，现实很骨感。离职第一个月，我只到手 1000 多块。每个月看着银行卡的数字，焦虑几乎要把人淹没。

五一前我给自己立了军令状：这个月必须破万，否则就去跑外卖、去工地搬砖。时间一天天过去，目标却越来越远。看着别人晒出来的成绩单，我总会忍不住自问：同样在努力，为什么差距这么大？

转机出现在 4 月。龙哥盟出现了。2000 元的入会费，对当时的我来说是笔巨款，但我觉得这可能是唯一的救生圈，于是毫不犹豫地冲了进去。

事实证明赌对了。从月入 4000 到月入 4W+，这条路我走过来了。下面是我在赚钱之后的心路拆解，希望能帮到同样在迷路的人。

### 一、为什么我锁定视频号，并上了航海这条船

刚进赚钱，信息量爆炸，完全懵圈。还好团队推出了新手村任务。可一开始我压根不想参加，总觉得自己没成绩没东西分享，别人的问题我也帮不上，去了干嘛。

夜里问自己这个问题时，脑子里忽然冒出一句话：你来赚钱不就是为了赚钱吗？就你这畏畏缩缩的样子，能赚到钱？

当场被点醒。是啊，事情都是从小事起步的。没价值只是我自己臆想的。先完成再完美，真诚对待，结果不会差。

于是我跟着新手村任务闯关，做了一份未来一年的规划：

![](img/3b4a46c61eeb4b3b7589d5aed1bb5449.png)

第一条我写的是深耕视频号带货。当时手里正好有个粉丝快破千的视频号，之前还用它同步过其他平台的剪辑稿，也小有出单。想清楚后，我决定先把视频号这条线跑通，从 0 到 1 真正打通。

过程中也有差点跑偏的时候。新手村进行到后面，我看到 5 月航海有小红书和短剧 CPS，也心动了。后来我报名了 5 月航海的志愿者，这件事反而帮我做了取舍。志愿者要填第一志愿、第二志愿，而且不能实战航海，也就等于逼我三选一。

回头看，这其实是大多数新手的通病：既要又要。想吃小红书的红利，也想分短剧一杯羹，视频号还舍不得放。起步阶段，与其把鸡蛋撒到好几个篮子里，不如集中在一个篮子里死磕，把一篮子鸡蛋的价值最大化。

而且一个项目跑通后，底层逻辑是通用的。等以后有余力再去拓展，也会快很多。

### 二、模仿是新手最快的正反馈通道

0 到 1 最难的永远是第一步。我最开始用的是一个闲置很久的号，先试着发点泛流量看看数据，觉得数据好了再上货，应该是稳妥的打法。

结果数据惨不忍睹，连扶持的迹象都没有。索性破罐子破摔，直接上带货。我想清楚了，我的目标就是赚钱，引流这条路走不通就换一条，实在不行就换号。

行动之前我复盘了一下。之前那个号为什么会出单又违规？因为直接同步其他平台的剪辑稿。这次我给自己定调：必须做原创，哪怕是开头的流量内容。

但原创对我来说也很难，白发的视频基本就是感动了我自己，别人直接划走。缺爆款结构，没黄金三秒，基本一地鸡毛。

这时候我明白一件事：新手阶段，模仿是最有效、最快的成长方式，也是最快拿到正反馈的方式。

我找了几个同赛道的对标号，研究他们在带什么货、流量如何。意外发现一个品类流量稳定、转化也不错，而我手上正好有样品。于是我直接找到对方的爆款视频，一比一实拍搬运，文案和音频全部沿用。视频一发上去，播放直接冲到 2000+。

![](img/f00e97307020c51529f07c49aa8bd586.png)

老号和新号的差距一眼就能看出来。尝到甜头后，我连续三天用同样方法发这个品，每天播放都在几千左右，第三天终于等来第一单，佣金 90 左右，正反馈来了。

![](img/9ee0163ba4584a05a51fa689ec1cf0d8.png)

这第一单给了我很大的底气，我开始放大动作。

选品上我不纠结蓝海红海，就刷同行在带什么，记下来去选品中心找同款，重点看商家评分和销量。评分中档 4.2 分以上能入围，销量最好 1W+。之前第一单的品客单价太高不好出，于是我把客单价调低，聚焦 19.9、29.9 的低客单爆款。

样品买了 3 个挂在橱窗，用小号自买提升了点基础销量。收到货后我每天发 3 条，思路还是模仿爆款。流量基本稳定在几千，偶尔破万，出单开始稳定。

![](img/663a3a5948b96c5c0c30d8668b2f44a6.png)

给后来人的两点提醒：

1、流量来了一定要开播转化。粉丝没破千挂不了车的时候，开播是唯一的变现口。我当时没意识到，浪费了不少机会。
2、主动找商家合作。直接联系问是否可以寄样、是否能合作，大多数商家都会同意。有些会让你先买到一定单量再返佣，总之先搭上关系，对带货只有好处。

商家主动找上门的情况也不少。先看店铺和诚意，合适就合作，不合适就当学习。我现在出单最多的品，基本来自一位主动找我的商家。关系熟了后，新品或有流量的品他都会先寄样给我。

跟商家打交道核心是靠谱和真诚。我会第一时间出片，有特殊情况也会及时报备。商家能清楚感觉到你是认真在推还是敷衍。

有一次我拍了一个视频效果不理想，我立刻跟商家说了真实情况。后来我们合作越来越顺，流量好的品我会持续发，流量差的也会反馈。商家也会把最近有流量的视频发给我参考。看到别人爆单我会羡慕，直接跟商家说，商家常说坚持就能做到。

我最开始做的那个号，日出 100+ 单也出现过两次，这两次都离不开商家的持续支持。每当我快要放弃的时候，商家总会丢过来一句：看某某博主爆了，这个品还有流量，你再试试。

所以前期搞好商家关系，跟着商家走，有时候喝到汤比自己瞎选品更容易出正反馈。

### 三、航海路上不断撞墙，不断重启

到目前为止我一共做了 4 个视频号。

有个号我犯了轴：流量很好却没到 1000 粉，我偏要发纯流量。结果一条破百万，粉丝冲到 2000+，但违规了，自证后流量一直平平。我就暂时封存了它，把经验迁移到新号上。半个月，新号粉丝破千，佣金过万。问题不怕，怕的是卡在问题里出不来。

还有一个原创号也被判定非原创、优质视频不足。当时很懵，自己拍的怎么会非原创。后来想通了，原创也要做去重，文案要改，形式要变化。

最近又遇到新瓶颈：几个号陆续违规，官方发优化建议，流量下滑。但同类型的视频别人的号照样火。我准备再开新号，换赛道再试。做视频号就是在不断挑战自己，不能怂。想赚钱就得有亮剑精神，狭路相逢勇者胜。

### 四、一群人走得更远

特别感谢赚钱的航海、续航、再续航机制。选定一个方向后，就是死磕到底，用时间去磨，用坚持去换结果。只要一直不下牌桌，赢的很可能是自己。

一个人走得快，一群人走得远。航海里的大佬都是长期主义者，有实打实的成果。能跟着他们同行，我很幸运。珍惜每次航海机会，用 120% 的劲去做，不成功便成仁。

给还没出结果的伙伴一句话：先别纠结红海蓝海，找一个能坚持做下来的项目先上车。等你跑到一定程度，再考虑迭代也不晚。拖着不做，最后的选择大概率也不对。

很高兴在赚钱遇到大家，期待不久的将来，我们都能达成自己的目标，加油！
