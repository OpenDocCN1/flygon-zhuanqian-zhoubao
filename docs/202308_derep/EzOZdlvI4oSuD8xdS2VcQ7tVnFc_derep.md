抄完作业后发现，视频号达人玩法和两年前抖音KOC玩法几乎一模一样：刷、筛、加、聊。视频号目前没有成熟的第三方大数据平台，只能靠强执行力去刷号，直接私信要微信建立合作。核心就一个字：主动。

我们这条线是双线作战，店铺达人分销和直播自播同步推进。今天重点拆解店铺达人分销这套打法。

# 二、对项目本质的认知

视频号当下的三大优势：触达成本低且可重复打扰、数据私密性强、综合利润空间高。

视频号本质是依托微信生态的短视频+直播平台。2023微信公开课PRO披露，2022年视频号总使用时长已超过朋友圈的80%。直播看播时长同比增156%，直播带货销售额同比增800%。

官方对视频号电商的定位是社交电商、私域电商，年度GMV目标3000亿，上半年完成不到1000亿，空间很大。

平台目前功能和后端体验还不完善，像21年初的抖音小店，处于野蛮生长期，所以产品机会和类目机会非常多，比如评分体系才上线两三个月。

人群画像很清晰：主要集中在40-60岁，女性占比80%，我们内部叫“中年少女、老年贵妇”。这类人群在家话语权高、资金充足、追求品质、对价格不敏感、客单价200以上是常态。

为什么说视频号比抖音更适合KOC？因为时间壁垒还在。

抖音的信息已经被第三方平台打透了，品牌和达人都能在榜单上互相看到，渠道壁垒很难建立。视频号不一样，我的团队花一年时间BD了10万达人。对手想追上，就得一步步亲手把微信一个一个加过来。这一年就是护城河。

# 三、开店准备

开店入口在“https://channels.weixin.qq.com/shop”或直接搜索“视频号小店”扫码注册。

几个关键点先说清楚：

一个法人微信只能开一个店，一张营业执照最多开5个店。

个体户店铺适合自播，不能开通优选联盟，也就是没法和达人对接。

企业店适合做达播，营业执照经营范围带“互联网销售”即可，注册资金无要求。开店需要对公账户，部分特殊类目需报白：滋补、内衣、3C家电、茶叶、珠宝、酒水等。

保证金按类目定，一般5000起步，GMV超过50万自动上调到3万基础保证金。

运费险已全量开放，需充值后使用，不过当前赔付流程还不完善。

# 四、选品思路

不管哪个平台，选品都是项目成败的第一环。

结合视频号人群画像，推荐几类可操作的品类：

居家类：厨房用品、餐厨具。家居日用永远是各渠道的大盘，需求稳定，上限高。

文具玩具：下沉人群的核心需求除生活外就是孩子教育。文具客单和复购都不错，爆发力强。玩具同理，电动玩具需要3C资质，提前准备。

渔具户外：主攻男性用户，有钱有闲。渔具本体+周边，销量稳定。需要懂点专业知识：浮漂、鱼竿、鱼线、鱼钩、炮台、鱼饵等。周边如遮阳伞、钓鱼服、防晒衣也很吃香。

家用五金：生活属性强，面向男性，高客单高溢价。螺丝刀、工具套装、配件等，需求和渔具人群高度重合。

美妆：高龄人群护肤需求旺盛。难点在产品功效和资质授权，1688上能拿到授权。溢价高、可做私域复购，但别乱来，牵涉人身安全。

日用洗化：成人用品和儿童用品。洗衣液、洗手液、清洁液等，细分人群再细分产品。外贸去油类产品也能操作。

调味品：刚需，家家需要。花椒八角丁香等利润可观，售后几乎为零。

滋补茶叶珠宝酒水：利润大客单高适合沉淀私域，但开店门槛高，需要报白。

产品分三层：引流款、主推款、利润款。引流款用来降低达人首次合作门槛，提升店铺体验分。选引流款一定要严控品控，否则一次合作失败就很难再约。

# 五、供应链谈判

没有自有货源就去1688和拼多多找。

优先1688，找到生产厂家直接谈。合作模式很多，厂家相对守规矩，关键是前期把规则谈死。1688当天可发货，晚上出揽件，部分商品退换运费自理。拼多多发货慢，拼单后24小时发出，且存在好评卡带logo、价格波动、库存不稳等问题，易爆单断货。

找货源记住货比三家：看人群属性、是否一件代发、库存情况、发货时效、售后处理。厂家有圈子，可通过A厂侧面了解B厂实力，形成良性竞争。报价格时要让厂家感受到你在多方比价。不要得罪任何一家厂，爆单时多一个备选就多一条命。

一定要找到源头，不论1688还是拼多多，很多是经销商或无货源。可从退货电话、产品包装追溯源头。爆单后发不出货，钱没赚到还砸店铺。

别迷信供应链人脉。认识大厂老板不代表你能卖出去，懂选品底层逻辑比认识谁更重要。视频号商城初期商品卡曝光少，大量铺货没意义，品要精不用多，每个品都要精挑细选。

# 六、达人获取

目前合作的达人分直播达人和短视频达人。加人方式靠私聊，平台目前对私聊无数量限制，正好用来大量积累。

对接前准备好物料：手卡、货盘表、样品跟进表、达人跟踪表。老做抖店的都熟悉这些。

筛选达人看数据：场观、热度、橱窗表现，判断带货能力。

寄样标准举例，客单200+小家电：

1、场观>5000
2、热度>30可免费寄样
3、场观高的可重复寄样
4、寄样同时约定排样日期
5、小主播收费寄样，出单返款
6、详细记录寄样信息并跟进带货日

对接流程：

第一步谈合作。别发“您好在吗，有个商品想合作”这种没营养的话。正确话术：我是xxx店铺负责人，我们这款爆品xx、xx，已被xx主播带过，月销过xx，请问有合作意向吗？

第二步达人不回。能力好的达人消息多，易被忽略。除了发资料，要隔三差五回访。微信号要做人设包装，朋友圈多晒主播数据、发货视频、生活片段、公司活动，展示实力和温度。

第三步收样后无音讯。一定放平心态，骗样情况确实存在。可打电话沟通，比微信有效。若不想带，单价高就尽量追回或追回货款，减少损失。若达人拿样带竞品，直接刚，正面施压。

90%达人没有选品能力，只会跟风。我们要制造产品很爆的假象，让达人主动跟。达人最难的是0-1，直播怕低销影响流量，所以不轻易尝试。你亏一个大达人没关系，只要其他达人跟风，你就赢了。

人情世故要做：每周送水果，有娃的送礼物，过节送礼，生日记小本本。金钱和情绪双管齐下，达人不好意思拒绝。

规模效应明显：转化率随达人数量提升。一次发100个样品，要一起发，一起拍，一起播。达人粉丝重叠度高，集中推品转化更高。加到500个达人以下基本看不到成绩。2000+达人资源，你跳槽面试BD岗位就是带资进组。

达人标准与运营：

1、备3-5个老微信号，每天30个招呼，通过率40%，单人日增20-30个达人是及格线。
2、加人渠道：视频号团长后台达人广场、数据平台找微信号、评论区、直播间送礼。最高效是达人转介绍。
3、样品策略：弱势期新链接小达人免费发样做销量；中势期月销5000单以上免费，之下付费领样5单返现；强势期别装逼，维护好达人，竞品会用高佣金挖人。
4、SABC标签管理。S强关系有品就带，A合作过关系一般，B聊过未合作，C已读不回。月销几十万的达人不回也要每天问候。商务性别搭配，朋友圈真实有生活。

# 八、运营细节

常用工具：

1、哈士奇/至尊宝：找同款
2、神速搬家：上架产品，审核慢时用
3、逸淘：拍单软件，可设自动拍单退货
4、企业微信：客服用，实名300/年
5、代发软件：店管家、我打

平台规则：官方文档要看。虽然规则不完善，但视频号喜欢秋后算账，错类目上架现在不处罚，后面一刀切封店很常见。新手别因急于变现而松懈，熬不过黑暗就见不到黎明。

建议：

1、重视库存。宁可少赚也要保店。厂家说有1万现货，最多放3000跑。发货问题导致评分崩盘，前面工作全白费。
2、持续找达人沉淀资源库，加人找达人可拆分工作，避免员工带走资源。
3、出现一个单达人帮你赚20万，花10万回馈他，买流量、送礼、给坑位费、签约长约。达人圈子效应强，他觉得你靠谱会互相推荐，BD成本大幅下降。一定要舍得花钱。
