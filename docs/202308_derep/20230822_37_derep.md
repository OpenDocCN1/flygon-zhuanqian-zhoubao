# IT 上市公司市场总监转行做中医养生膏推广，轻运营实现月利润 2-3w

有个人跑来问我：有个副业，不用拍视频、不用直播，只需要用心发朋友圈，就能赚钱，你愿意吗？如果你发现这个副业背后有老字号品牌、专业医生团队做支撑，你愿意试试吗？我的选择是：愿意。正是这个选择，让我在兼职状态下，每个月的利润做到2~3万。

先交代一下背景。我之前在一家IT上市公司做市场总监，负责区域市场和政府关系，收入稳定但加班多、内耗也重。2020年为了先稳定下来，我从干了10年的管理咨询行业跳进IT行业。2022年春天封控在家，我开始认真问自己：除了眼前的工作，我到底喜欢什么？40多岁、三个孩子的妈妈，居然说不清自己的兴趣，挺惭愧。但也正是在那段时间，我在朋友圈看到一位中医主任医师的太太在推荐一款养生膏。这位主任曾任职于上海三甲医院龙华医院，也是上海中医药大学特聘教授。我有慢性咽炎，疫情期买药又困难，看到这个膏能润肺、缓解咳嗽和嗓子不适，瞬间种草。解封后试吃，口感不错，孩子也喜欢。7月我到杭州胡庆余堂国药号实地看了一圈，越看越踏实，于是决定正式启动这份副业。

为什么选胡庆余堂食养膏？核心是下面几点：

第一，品牌够硬。胡庆余堂是国企、百年老字号，也是全国唯一同时拥有国家级重点文物保护单位和国家级非遗的国药企业。创办者胡雪岩是有名的红顶商人，谈经商绕不开他。

第二，产品能打。它是食字号膏方，口感好。8款配方出自宋代《太平惠民和剂局方》，讲究道地药材，不加防腐剂。从小朋友到老人都能调理，尤其孩子见效快，复购率很稳，常常一个小孩子就把全家带进了调理状态。

第三，文化打动人。“戒欺”“真不二价”“采办务真，修制务精”“是乃仁术”这些价值观，不是只挂在墙上，而是落在经营细节里的。这种老字号文化让我有道德感，也有了使命感。

第四，专业托底。三甲医院副主任医师、中医博士王主任和尹主任等医生团队，负责指导辨证配膏，专业上不是裸奔。

第五，模式轻。线上加线下、零售加批发，本质是社交新零售。把朋友圈用明白，就能出货；以孩子调理为入口，往往能撬动一个家庭的长期需求。

第六，门槛低。3000元左右就能启动，没有资金压力。我当时拿了9000元，试错成本可控。

第七，成长价值。沟通能力、销售能力、人际交往、团队管理、朋友圈私域运营都会被逼着提升，还能补一补中医基础知识和养生意识，身边也能围绕一群医生资源。

运营上，我一开始就没打算搞得多复杂。我用兼职方式做，不拍短视频、不做直播，只深耕朋友圈和私域。因为做过市场岗位，微信好友超过7000人，这本身就是一座宝藏。我也纠结过要不要做视频、直播去引流，后来想明白：既然手里有矿，先把矿挖透。团队里另一位宝妈启动时只有100多个好友，靠线下拓展圈子和陌拜，做到月销3000盒以上。所以别急着羡慕别人，先盘点自己手里的牌。

真正难的不是方法，而是心理关。我刚开始不敢发朋友圈，怕朋友觉得我“混得不好”，怕被人议论。后来看到团队长们靠朋友圈做出了实打实的成绩，我选择先听话照做。再想深一层：一个人会不会继续跟你做朋友，从来不取决于你发不发广告；如果因为发圈就疏远你，这种朋友也不值得留。唯一要守住的原则是：别暴力刷屏。

怎么把朋友圈当成店来经营？我的经验是：微信就是你的线上门店，每天发的图文就是货架上的商品，让别人看见产品，也看见你的为人。发圈前，这几个动作不能省：做好分组。比如我现在在金融公司做大健康产业投资，原来的同事和客户就不会看到我发副业内容；头像换成有职业感的照片，增加信任度；文案最好二次加工，不要原封不动搬运，避免被微信折叠。

朋友圈具体发什么？我梳理了8类，可以交替着来：

1. 官宣要有仪式感。开启副业时发一条原创走心的官宣，给自己一个正式开场。
![](img/e4608a55aef8468052c9d2725efde366.png)![](img/0858acffdb5161f3632df60c079e25a2.png)![](img/aea77c198596bd0e710b124d3eb5ce4a.png)

2. 晒自用。没有自用就没有分享，全家每天打卡吃膏，你就是产品最好的代言人。
![](img/a3d02db3158744b67d3f6dd29e2e792a.png)![](img/d978d45fb22a868ae24e266dc79211b7.png)![](img/c9580736de9ea2067d9c560277c05495.png)

3. 晒产品。品牌文化、产品配方、成份、反馈，这些基础内容要反复讲，才能让潜在客户记住你。
![](img/a3cbc2a2714c2c39331be7f34d028ec5.png)![](img/56a11df6230b452887b21f8e7df2a664.png)![](img/39d09e1c67644dd68cedfe112827e2f9.png)

4. 晒学习。主业下班后，学舌诊、手诊等中医知识，把学习状态发出来。
![](img/7d9e3190e65b6f6566829c05e05926a8.png)![](img/1c3e0fa6158790c67b3e9f83b6aa3c2d.png)

5. 晒行动。一张搬货、打包、发货、收款的过程图，比十张产品图更有说服力。记得把过程拆开发：咨询、下单、收款、打包、发货，一个节点一条圈，营造出生意红火的画面；还要带上自己的印迹，比如家人或自己出镜，或者自己的头像、聊天记录；家里一定要有货，小货也要拍出大货的气势。
![](img/83ce17bbf65f437c345ad67b8943d743.png)![](img/53396a61ff76beb48f18c611ec2d2b77.png)![](img/0ab598e03c8c32e69e53fb3b8cfba36a.png)

6. 晒团队。一个人走的是岁月，一群人走的才是事业。晒医生专家团队、晒企业高管副业伙伴、晒优秀代理，也感恩团队长和专家的帮助。
![](img/3896be2471b747a2a06cdb0290da3046.png)![](img/fb280c88c21cb49b0a69545a32d72c74.png)

7. 晒收获。晒钱不是炫富，是结果证明；健康、人脉、成长总结、家人支持，都可以成为朋友圈的“成果展”。
![](img/6e4ac0d05df7d6cb572d9040e7ecbe2f.png)![](img/184b5dd8bd13c3412445db5c4588a96f.png)

8. 晒日常。发一些膏以外的真实生活，让别人认识完整的你，信任感就是这样一点点建立的。
![](img/bedbe689ee2dec8784c4770637872645.png)![](img/9ad8b8f168ee920f8c11dbe209fcb09a.png)

所有这些内容，落到三个核心词：人——让朋友圈看到不断有人咨询、合作；财——让人看到收获和回报；行动——让人看到你确实在卖力干。记住，朋友圈是你的店面，不是广告墙。

也有人说，做微商是不是可以不进货，只转发就能卖？我的看法是：开实体店不可能不进货。朋友圈就是你的实体店，连货都没有，客户怎么敢下单？身边人怎么敢跟着你干？适当囤货、理货、发货，营造出热火朝天的干事氛围，反而会吸引同频的人主动靠近。

而且，零售做到一定阶段都会遇到瓶颈，这时候就要把团队的念头提上日程。朋友圈不只是用来“卖货”的，更是用来“招人”的。当你把一个人作战，变成一群人作战，月利润才可能稳稳往上走。

一路走过来，我最深的感受是：面子是赚钱路上最大的障碍。我也有偶像包袱，太在意别人的眼光，后来发现所有客户和代理都是看了朋友圈主动来找我的。你不用讨好所有人，只要把专业、真实、结果持续晒出来，对的人自然会来。

如果你也想做类似的大健康副业，我的建议是：先盘清自己的现有资源，再用小成本去验证；选项目时一定实地考察，看清品牌、产品、专业和文化是否齐全；运营中别死磕短板，善用团队工具和小程序；最难的那道心理关，迈过去就是另一条路。
