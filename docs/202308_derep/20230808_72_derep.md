# ('我的人生信念：写在 30 岁', (2, 16))

最近偶然刷到龙哥的收藏夹，2023年8月1日发了一篇《我的人生信念：写在30岁》。说实话，第一遍看下来，很多点并没有完全理解，但评论区里一位叫谦墨的朋友留言让我印象很深。他说，看完很有触动，觉得给自己立原则这件事非常重要，哪怕现在还有些道理没想透。

这一点我特别认同。我们常常低估原则的力量，觉得人生要靠随机应变，可真正遇到选择时，能把你拉回轨道的，往往是那些提前写下的“我会怎么做”。三十岁不是定型，而是开始有意识地为自己划下边界——哪些事必须做，哪些事情绝对不做，哪些情绪要常提醒自己。

也许有些信念我们此刻还没办法吃透，但没关系。先把它们种下去，等到某天经历到了，你会突然想起那句话，然后真正懂它。这大概就是30岁写下这些的意义吧。
