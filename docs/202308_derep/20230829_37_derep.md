# ('2023 年本地生活上半年复盘：抖音短视频获客的新增长', (2, 29))

2023年上半年，本地生活赛道迎来了一波肉眼可见的躁动。市场变了，抖音的玩法也变了，很多实体商家在短视频里找到了新客源，也有不少人还在观望。最近读到楚川的一篇复盘文章，感触很深。

楚川是谁？用他自己的话说，是一个把品牌实操、短视频、直播推广揉在一起干的创客，而且下定决心要在本地生活领域深耕二十年以上。这篇上半年复盘，是他写给同行、品牌方以及所有本地生活从业者的，算是把团队这一路的真实经历摊开来讲。目的很纯粹：希望这些经验能给大家一些参考，也持续为这个行业发出一点声音。

为什么说2023年时间点特殊？因为大环境和抖音本身都出现了很多新变化，过去的套路未必好用，新的打法又层出不穷。楚川在文章里把团队的发展历程梳理了一遍，重点聊了聊抖音短视频是怎么重构实体获客逻辑的。在他看来，本地生活就是一座大金矿，但能不能挖到金子，关键看你怎么挖。
