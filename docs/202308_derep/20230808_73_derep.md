# B 站 12 年：做社区，共识比效率更重

在B站，内容生态是这样长起来的：用户凭兴趣自发创作，作品越攒越多，也就自然分出一个个主题分区；分区一旦有了雏形，更多创作者就会循着热爱加入，持续填充新作品，同时把更多有相同喜好的观众带进来。观众基数扩大，愿意生产的UP主也越来越多，二者之间的情感连接不断加深，共识越来越强，整个社区由此进入一轮又一轮自我强化的增长。

整整12年，B站用这个循环证明了一件事：做社区，共识的分量远高于效率。效率能换来一时的数据增长，却难以沉淀出真正的归属感；而共识一旦建立，内容、用户、创作者都会心甘情愿地留下来，社区自然越做越大。
