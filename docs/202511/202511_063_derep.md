# (44 赞)干货与割韭菜：我邪修二十多年混圈子的真话
作者：龙哥

说实话，跨境这个行当，名声不算好，可也没烂到根子上。

我在这行泡了二十来个春秋，从那个上网还靠电话线拨号的年代一直折腾到今天。有人骂我是把干货裹成糖衣的镰刀，还有人谢我带他们赚到了人生头一笔实打实的钱。外头的评价我向来懒得拾——你就算是张百元大钞，照样有人嫌它摸着手脏。闲话听多了，我反而练出一个本事：心里不搁事，自然省电。

收费和当镰刀从来不是一回事。真正的坑，是那种钱一到手就翻脸、压根没打算给你真东西的人。

2003年那阵，EBAY刚烧起来，我便挤进国内最早那批讲联盟营销的人堆里。当时一笔CPA能值几十美元，学费我定在四千块。价格谈不上亲民，可我开这摊子真不是冲赚学费去的。起因是论坛里一位朋友挂了批资源，买家拿回家一翻，东西确实没掺水，可就是不知道怎么使。后来我索性说：要不还是我来教用法吧，售后也包了。培训这档子事，我算是误打误撞踏了进去。

那阵子我脾气冲得很，二十几岁的年纪，浑然不知什么叫教学心态，碰见反应慢的学员甚至会上火。但正是那段日子教会我一个理儿：你想做别人的引路人，得先蹲到他的位置上看路。

那一轮轮风口，换得比衣裳还勤。淘宝和易趣正掐到白热化，每拉来一名新用户注册，就能拿到25块；EBAY敲钟那阵，单个注册用户值50美元；后来creditreport热起来，一单注册也能卖到25美元。项目换了一茬又一茬，我也在不断换。但在我心里，我教的从来不是某个项目本身，而是一套底层的思考方式。怎样分辨信息真假、怎么把自己放进合适的赛道、怎么用一个入口去撬下一个入口，这才是核心。不少人把我的名字记住，跟我当年赚了多少没有关系，而是那堂课替他们撞开了人生中第一道钱门。

这个圈子有个很妙的地方：待得越久，那些花花肠子就越藏不住。

太多人一边嚷着求干货，一边心里想要的分明是幻觉——一两句话就能点燃、照抄就能躺赢的那种脚本。可真东西哪会照剧本走？

干货无非两类：一类听着过瘾，落地失灵；另一类，能真正长出钱来。大多数人接不住实惠的东西，原因不外乎三条：一是被有心人往岔路上引，你一旦会了，别人碗里就少一口；二是手上功夫太软，方子递到眼皮底下也懒得去抓；三是底子没到，信息没毛病，可时间窗口已经关了。

这也是为什么许多人读完一篇帖子激动到睡不着，一到实战就兵荒马乱——因为干货靠的不是耳朵，是一双脚。

我带过那么多人，记忆最深的一个网名叫9527。当年EBAY那批玩家里，他是公认的头号狠人。后来他转战Google的广告投放，一路打到Google中国区的头号代理，功夫非常实。可再猛的人也有湿鞋的时候。有一回，他远远瞧见一位大佬靠跨境生意落袋八位数，心热得不行，也跟着冲进去做投放，结果三十天不到，百把万就打了水漂。后来我们仨约了顿长沙的饭局，我、蓝总，还有他，围一张小桌才把底细聊透：那位大佬做投放的预算，压根不是自己口袋里的，是用虚拟卡从旁的路子“洗”出来的。人家待他一点也不薄，每条信息都是实话，可惜他兜里没有对方那种底层家底。看得见的是热闹，摸不着的是底牌。

那次饭局让我彻底开了窍：话越少，越接近真相。到了那个层级，生意往往几句话就敲定，往后全看手上的功夫。网上流传的各种秘诀、捷径，包装得再精致，也不过是故事。

我这种性格装不来。有人讲我起点高，这我不抬杠——小时候家在武昌，离省政府就隔了两条街，985院校读的计算机，正儿八经的科班底子，身边朋友也大多是系统内吃公家饭的。可我也看过一觉醒来就封神的，也看过转头就摔下云端的。上午还晒着豪车，下午公司就没了。能撑到眼下的，没有一个拼的是运气，全凭一股落地功夫，日拱一卒。

钱这个标尺量不出成功的全部。真正的成功，是你不必看谁的脸色，能由着自己挑路走。讲心里话，赚钱本身并不让我上瘾，我上瘾的是造东西。搞出一套自己会跑的赚钱系统，再把思路散给旁人，看着他们也一点点变强，那种满足感比账户数字跳动带劲得多。今天还在挣钱，无非因为搞创造太耗银子，得拿它来喂养这份瘾。

这些年来我愈发觉得，几乎所有人心头都住着一个“急”字。一开口就是：“哥，有什么近路吗？”我的回答一直没变：有，但那条近路的名字叫“不走近道”。上路之前，先练出一身辨别力，养一对火眼金睛。真正搞到钱的人，从不会把搞钱的路数摊开给你看。有人号称靠币圈进账八千万，你验过仓吗？他建仓那晚，喊你了吗？网上干货从来管够，少的是一个替你说清“哪条路才是你的”的人。

晚点熟没关系，但别总在原地绊倒。那些年交过的学费，换一种说法，就是长大该付的账单。

入行这些年，我赚到过手软，也亏到过险些当裤子。头一回自己拉起公司，撞上一个清华读CS的搭档，融资、搭系统、组骨架，全是他一手推起来的。我俩一起做在线旅行项目，资金一度滚到八位数，最后一把火全烧完。钱是亏了，但那一仗让我把一门生意的里子彻底嚼透了。打那往后，我经手的项目几乎没再湿过鞋。人这辈子能碰上两三个真心拉你一把的贵人，一两个不做假的搭档，比独自扛十年有用太多。

真回望过来，最难的一关不在赚钱，而在活得清醒。别人的评价，少往心里搁；谁真谁假的口水仗，也别去蹚。这世上叫人害怕的，从来不是挨了哪一刀，而是从头到尾都分不出哪边是镰刀、哪边是太阳。

干货的本义，不是躺在那儿的资讯，而是你看得懂、也做得动的那一小撮真相。这个道理越早种进脑子里，你就越早从“猎物”名单上退下来。

赚钱靠的不是路数，是对人心的透彻。真正在塔尖上的人，不拜玄学、不赌运气，手里攥的是认知和判断。人活一生，最金贵的那件行囊，技术排不上，机遇也排不上，排得上的是那点看世界的清明。
