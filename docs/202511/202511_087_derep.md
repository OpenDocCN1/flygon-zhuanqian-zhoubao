# 别笑话“富废”，这可能是富人真正的滑铁卢

很多人以为，有钱了就万事大吉了。实际上，钱到手的那一刻，反而是一场隐形的考验。

当财富积累到某个临界点，生活里的需求基本都能被立刻满足。想要的不仅能拥有，而且品质会从“够用”一路升到“极致”。审美被养刁了，眼睛也越来越挑，对市面上大部分东西都提不起兴趣。

光是嘴馋、眼挑还不算致命。真正要命的是人的状态悄悄变了。曾经拼命打拼时那种吃苦的狠劲、扛事儿的耐力、拼到深夜的精气神，以及逼自己自律的紧迫感，都在富足的舒适里一点点流失。

创业初期，一碗泡面配一台老电脑也能满血复活；等到资源在手、选择主动，同一个人的意志力却可能连早起10分钟都做不到。

所以，所谓的“富废”，并不是钱花完了，而是人废掉了。富裕带来的松弛感，会把本该用来继续成长的潜力，慢慢耗成习惯性的懒散和挑剔。

提醒自己一句：别在安逸里把自己废掉。真正的潜力，一直都在下一步没被开发的地方。
