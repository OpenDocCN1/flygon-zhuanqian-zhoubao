# 两个月搞明白视频号卖书：用名人金句做图文矩阵，短视频+直播把佣金做到五十万
作者：龙哥

作者：许帅

先做个自我介绍，我是赚钱第七期圈里的一个普通玩家。过去几年里我折腾过票务代理、社群电商的优惠券分发、短视频带书、👸号流量主写作、📕虚拟货品、B站好物推荐这些赛道，基本都能从零跑通。

23年我发过一篇实操帖子意外拿到了龙珠，之前也有人问过。有赚钱约稿组的支持，今天就来复盘一下，我做足两年的一个副业方向——视频号书单。

这个玩法门槛不高，靠的就是坚持和一套可复制的方法。整整两年时间，我一个人操盘，养出了一个以名人语录图文视频为主的矩阵号，里面有8个账号粉丝都破了十万。

算下来总流水大概五十万左右。其中四十万是直接来自图书带货的佣金，剩下十万是创作者分成、线上培训、私域复购以及语录资料包的售卖。

对圈子里很多大佬来说这点钱不算什么，但对我而言这就是从公司职员走向自由职业的第一桶金。希望能给到跟我情况类似的伙伴一些实操参考。

下面主要讲的是现在项目的状态，以及做下来过程中踩过的坑、怎么解决的、中间的一些思考。做过类似方向或者有不同经验的，欢迎在评论区聊聊。
