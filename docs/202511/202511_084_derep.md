# 别再把钱和时间当成人生筹码了，真正值钱的东西你正在丢失
作者：龙哥

我们习惯用金钱衡量价值，用时间衡量成本，却很少有人意识到，这两者都不是决定生命质量的硬通货。

金钱可以积累，时间可以消耗，但只要缺了那个关键的东西，再多钱也买不回意义，再长的时间也只会变成空耗。

那是什么？是注意力。

不是你拥有多少注意力，而是你把注意力投向了哪里，又用怎样的方式去经营它。当你心不在焉地刷着信息流、当你在会议上想着晚饭吃什么、当你明明在场却脑子里全是别的事，你其实已经在透支生命了。这样的时间，哪怕有几十年加起来，也不过是浪费。

生命的真正货币，是你当下能否真正活在此时此刻，能否把专注力集中在你真正选择的事物上，并认真对待它。

选择关注什么，是方向；如何处理它，是质量。方向错了，再专注也是空转；方式不对，再投入也是一场消耗。

所以，与其焦虑钱不够、时间不够，不如先问问自己：我的注意力，今天用在哪了？
