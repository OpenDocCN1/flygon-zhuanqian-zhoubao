# (37 赞)我们比上一辈要过得更好，为啥还更焦虑？
作者：龙哥

越活越好，心里越慌？这代人的焦虑到底从哪来？

如果单看物质条件，我们显然比父辈强太多。可奇怪的是，大家似乎并不比以前开心，反而整天被一阵说不清的焦虑追着跑。这到底是怎么回事？

最近正好读了两篇清华学者的文章。一篇是孙立平教授的公号文，题目很直白，《一种屁滚尿流的生活方式》；另一篇是王天夫教授的论文，专门分析焦虑社会的深层根源。两篇放在一起看，会发现一个共同判断：我们已经进入了一个过度焦虑的社会，而且谁都没能幸免。

焦虑算是一种生物本能吗？算。它本来像身体的警报器，是用来提醒我们躲避饥荒、灾难、危险这些实实在在的威胁。只不过，在从前，这警报是偶尔响一次、过一阵就停；现在却变成长期嗡嗡作响，弥漫在生活的每个角落，想关也关不掉。

怎么判断我们活在了“焦虑社会”里？两个维度就够了。

一是纵着比。和历史上任何年代比，如今人们焦虑的范围更广，程度也更深。二是横着看。焦虑早就成了最常见的负面情绪，渗透进工作、教育、社交、婚恋等方方面面，谁也躲不开。

那问题来了：既然日子比以前好，为什么焦虑反而多？原因恰恰不是“过得不好”，而是社会外部环境变了。

第一个原因，要说到韦伯讲的“理性铁笼”。工业革命之后，社会对“成功”的定义变得极度单一：更高效率、更多财富。于是大家每天忙着比较、排名。评价一个成年人，先看他赚多少钱；评价一个孩子，先看他考多少分。至于情绪好不好、活得幸不幸福，反倒成了次要指标。一个家里一团乱但很有钱的老板，在别人眼里依然是成功人士；而一个没什么钱但日子过得有滋有味的人，反而常常被贴上“没本事”的标签。

第二个原因，是“风险社会”带来的残酷竞争。我小时候，也就是上世纪六七十年代到八十年代初，大家日子都紧巴巴，一年沾不了几回荤腥，得了重病也只能听天由命。但那时候的人反而比较淡定，因为社会变化很慢，穷得很稳定，也穷得很平均。大家心里有谱：明天不会和今天差太多，自然没必要焦虑。

再看看现在，社会变化就像是开了倍速，一天不学新东西，马上就有被甩下的慌张。我认识一位知识大V，按理说见多识广了。可面对AI这类技术快速迭代，他照样急得不行，生怕错过任何一个风口。这种不确定性压过来，全民焦虑一点都不奇怪。

第三个原因，是传播效率让攀比失去了边界。过去海淀妈妈们再内卷，充其量影响一小片区域；今天她们的焦虑通过手机屏幕，轻轻松松就传给了全国各地的父母。俗话说“又怕兄弟过得苦，又怕兄弟开路虎”，看到别人晒成绩、晒收入、晒精致生活，我们会莫名有一种“自己被抢了”的感觉。

有个对比很直观。我去马来西亚时发现，当地人收入一般，物质生活也谈不上丰富，但普遍不太焦虑。为什么？因为大家都觉得现在这样挺好，没人带头卷，幸福感反而高。可最近一批中国品牌跑去东南亚做生意，把内卷也带了过去，当地人也开始有了紧张感。

既然逃不掉焦虑，人一般怎么应对？动物遇到危险时，无非是吓傻、战斗、逃跑；人类浓缩一下，就两种策略：一种是“内卷”，相当于战斗；一种是“躺平”，相当于逃跑。

王天夫教授给出了更好的思路：焦虑没法消灭，只能学着共存。具体可以分五步走。

第一，承认焦虑是所有人的共性。它藏在基因里，是我们的生存机制。知道自己为什么会慌，本身就是一种安慰。

第二，别让焦虑推着你“瞎忙”。焦虑会让人行动，但行动要是漫无目的，忙完之后只会更焦虑。

第三，学着给焦虑画像。年轻人搞出“绿香蕉”表情包，用荒诞的方式把心里的模糊不安画出来，笑一笑，它就变小了。

第四，想明白成功有很多偶然因素。韦伯、罗尔斯这些大师都承认运气在成功里的分量。既然成功是偶然、失败是常态，你实在不必因为一时的挫败把自己逼进死角。

第五，试着当个“淡人”。别把社会灌输的那套成功标准当成唯一真理，自己心里要有一杆秤，建立自己的价值体系。

说起来容易，做起来也难。作者自己也讲过段子：公司业绩下滑、心里发毛的时候，他就去找做得比他还差的同行聊天，聊完回来，心情一下子就好多了。这大概也算一种“比较疗法”吧。
