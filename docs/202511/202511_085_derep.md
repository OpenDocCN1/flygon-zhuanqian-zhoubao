# 别让脑子跑太快，先把这几条思维底线立起来

信任、策略、自由，看似三件事，其实是同一套生存操作系统在不同阶段的显现。把别人的经验拆开看，会发现背后都是这三件事在起作用。

**第一条：信任不能一次性给完，得像银行一样持续授信。**

别轻易相信“朋友的朋友”“同学的同学”。隔了一层的人际链，本质上就是社会工程的渗透通道，坏人最喜欢借熟人背书混进来。

对所有人都要建立验证机制。哪怕是已经加过信任分的老朋友，也要随事件触发、定期复核。信任不是终身制，是需要不断续期的信用评级。

**第二条：人跟人的操作系统，根本不是一个版本。**

你以为的常识，对别人可能是惊雷。尤其是带着打工思维的人，他们的决策逻辑会让你意外到怀疑人生。

老板的思维是造局，打工的思维是求稳，这两者天然不在一个维度。所以协作前，先对齐方法论，再立规则和边界。规则是合作的底线，有边界才能进可攻退可守。

**第三条：优秀的人都在用同一套策略打怪。**

好人品背后，必有好方法。不是运气好，是体系在发力。

敏感且好奇。看到别人总能选中翻倍的标的，第一反应不是羡慕，是“他手里一定有套打法”。这就是信息嗅觉。

追本溯源。Know Why 先搞清楚为什么能赢，而不是只看结果。段永平那句话很对，先弄明白什么是对的，再去做。

知其善行。Know How 知道方向后，还要能落地。会判断还不够，得会执行。

换位造局。别总当局内人去看牌，要抬头看谁在发牌。用造局者的视角和心理去解局。

及时复盘。允许犯错，但绝不允许同样的错重复。好的人把复盘当成日常，把总结变成肌肉记忆。

**第四条：别被新故事迷惑，去信会赚钱的旧生意。**

市场上新故事永不缺席，真正能赚钱的却很少。太多所谓的创新，不过是换了包装的旧忽悠。

能穿越周期的，都是时间检验过的真生意。这就是价值投资的内核：不追概念，追现金流。

**第五条：自由是准备出来的，不是等来的。**

狡兔三窟，本质是给生活买保险。职业、身份、住所、保障、资产，都不要押在一个篮子里。

分散且低相关，像投资一样至少布局三个不互相牵连的板块，风险才能对冲。安全感的来源，就是选择的冗余。

**第六条：最终一切为自由选择权服务。**

能自己选路，是成年人最顶级的财富。所有努力的终点，都应该是让你过上自己想要的生活，而不是被生活推着走。
