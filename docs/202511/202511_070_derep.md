# 别在情绪上头时丢人，老祖宗这句话能救企业一命
作者：龙哥

最近翻到海天、西贝这些老牌子的舆论风波，越看越觉得一句话被验证了无数次：盛喜中勿许人物，盛怒中勿答人书。

说人话就是，情绪拉满的时候，闭嘴，别签字，别回怼。

人本就是个被情绪牵着走的动物。高兴到飞起、愤怒到炸裂、害怕到发抖、绝望到麻木，这些极端状态都会把理智直接拉黑。孩子被绑架的惊恐，谈恋爱时的飘飘然，被泼脏水的暴怒，重病时的绝望，签下天价订单的狂喜，都是一样的道理——身处其中，你的第一反应几乎都是错的。

西游记里孙悟空被牛魔王耍了那段就是典型。骗到芭蕉扇那刻他得意忘形，牛魔王一化身假猪八戒上门，他二话不说就入了套。得意到头脑发热，判断力就归零了。

企业家对自家公司，那份在乎不亚于对亲生孩子。孩子出事时父母不是更慌吗？公司一旦躺进舆论火坑，创始人往往正处在又惊又怒又怕的状态里。这时候拍板出的公关稿、回复、承诺，往往都是失控的。于是我们才会在新闻里看到那些明显不在状态的应对，措手不及，越描越黑。

这不只是企业家的通病。股市一天腰斩，专业十年的交易员也会手抖。道理人人都懂，巴菲特说别人恐惧时我贪婪，可真到恐慌蔓延的时刻，大多数人第一反应是赶紧跑路，先保命再说。

危机公关的本质，其实分两种：真出事了，被冤枉了。两种情况都会让人瞬间进入高度应激状态，最忌讳的就是在这种状态下直接开麦。情绪里做决定，通常又蠢又丢脸。

老话还提醒过我们，喜时之言多失信，怒时之言多失体。高兴时随口许诺，最后兑现不了；生气时口不择言，体面全丢。企业尤其经不起这一次。

所以真正的自救，不是嘴硬也不是硬刚，而是先把自己从情绪里拽出来。自己压不住，就把话语权暂时交给专业的人。冷静三小时，比发三百条道歉都管用。
