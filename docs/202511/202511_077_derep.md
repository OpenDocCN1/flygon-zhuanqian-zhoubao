# 给刚入场的创业者：关于股权分配的几句掏心窝子的提醒
作者：龙哥

最近在圈子里看到太多年轻创始人一上来就往股权上撒钱。

拉个人进来就说“来，咱五五开”；兼职搭把手，也画饼说以后给你股份；一个资源电话刚结束，就承诺人家未来可以拿分红；甚至一口气凑齐五六个合伙人，直接平均切割。听起来热闹，实则危险。很多团队的失败，不是做得不够努力，而是股权结构在成立那一刻就已经写好了结局。

说实话，如果没踩过坑，很难真正理解股权设计的分量。等意识到问题时，改起来往往代价巨大。基于这个原因，我想把这部分经验先整理出来，给还在起步阶段的圈友做个预警，免得大家重复走同样的弯路。

目前大家最关心的几个点，我也先记下来：

有朋友的公司现在持股是 55%、40%、3%、2%，直觉上觉得哪里不对劲，但又说不清漏洞在哪。

也有人问，股权真的绝对不能平均吗？

控股比例到底要做到多少才算安全？

初创小团队，3到10个人，怎么设计股权和分红权，才能真正留住人、让团队加速？养了一批很优秀的人才，一年下来大部分都走了，很焦虑。

还有人提出疑问，股权是不是应该严格按贡献大小来分才合理？

也有观点认为股权可以给，但创始人必须做到绝对控股。

这些问题都很有代表性。我先把大家的提问收集起来，回头整理一份更系统的梳理。

如果你也有类似的困惑，欢迎在评论区留言，我会汇总后集中解答。
