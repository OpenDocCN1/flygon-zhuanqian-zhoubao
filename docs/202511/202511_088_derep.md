# 把文字写给一个聪明的陌生人

马斯克那句“像给一个从未见面的聪明人发短信一样写作”，其实不是一句简单的写作建议，而是一套很完整的表达原则。

它至少包含三层意思。

## 第一，默认对方聪明，但不要假设对方了解背景

“聪明”，意味着读者有能力理解复杂问题，不需要你把每个概念都掰碎了讲。

“从未谋面”，则提醒你：不要默认对方知道你的经历、语境和前因后果。

所以，表达时既不能把读者当成什么都不懂的人，也不能把关键背景全部省略。你要做的是：给出必要的信息，然后迅速进入真正有价值的部分。

## 第二，短信式表达，核心是短、直、真

短信不是论文，也不是演讲稿。

它不需要长篇铺垫，不需要反复论证，更不需要用华丽辞藻掩盖空洞内容。

好的表达通常具备三个特点：

- **短**：只保留不可替代的信息；
- **直**：直接说重点，不在句子里兜圈子；
- **真**：语气自然，像正常说话，不端着。

少讲套话，多讲判断；少复述结论，多呈现你真正观察到的东西。

不是告诉别人“这件事很有意义”，而是写出你为什么这样判断，以及其中那个让人突然想通的关键细节。

## 第三，这是对读者时间和智力的尊重

这种写法，本质上是在追求更高的信息密度。

尤其在 X、Twitter 或 Grok 这类内容与推荐系统中，一条信息能否被快速理解、逻辑是否清楚、有没有独立洞察，都会影响它能否被看见。

只丢一个链接，或者只留一句没有上下文的话，读者不容易理解，算法也很难判断它的价值。

真正有效的内容，需要同时满足两件事：

既让人一眼看懂，也让系统能够识别其中的逻辑和洞察。

## 可以直接采用的写法

写作时，不妨遵循几条简单规则：

1. 一句话尽量只承担一个核心意思；
2. 删掉冗长背景，尽快亮出观点；
3. 把重点放在能让读者产生“原来如此”的瞬间；
4. 清理无意义的副词、形容词和套话；
5. 假设这段话会被未来的自己重新读到，十年之后，它依然值得保留。

如果一句话只是为了显得聪明，那它通常并不聪明。

真正有力量的文字，往往看起来很轻，却能让人立刻抓住重点。

比如饭局结束后，最有杀伤力的表达可能不是长篇描述，而是：

“昨晚，某某请某某到新荣记作陪，喝掉了一箱五十年茅台。”

信息简单，画面清楚，语气克制，凡尔赛效果却已经足够完整。

这大概就是“给聪明的陌生人发短信”的精髓：

不替读者思考，但帮读者迅速抵达重点；不炫耀表达技巧，只把真正值得说的内容说清楚。
