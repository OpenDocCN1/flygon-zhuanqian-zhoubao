# 从零到日更两篇可变现短篇：AI 写作实操拆解
作者：龙哥



作者：王大诗
发布于：2025-11-04

我是龙哥，做了十年产品、其中五年专注 AI 产品，业余写小说也写了三年左右。

今年 Claude Code 推出后，我基于这个工具搭建了一套专门用来写短篇的 AI 智能体，目的就是把创作的门槛和耗时降下来，让写作者的效率上去。

这次分享的核心就是：**0 基础也能跟着学会写短篇的专业方法，并稳定做到每天产出两篇有市场价值的稿件。**

我会从最基础的短篇逻辑和结构讲起，手把手带你建立可复用的写作框架。


另外我最近刚从山西搬到昆明，如果昆明本地有做创作、AI 或产品方向的朋友，欢迎线下约个局认识一下，互相交流。
