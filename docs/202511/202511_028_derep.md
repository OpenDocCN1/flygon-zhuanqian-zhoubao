# 外卖 CPS 杀出一匹黑马：两条视频点赞破70万，涨粉10万
作者：龙哥

最近，外卖 CPS 领域出现了一个非常亮眼的案例。

短短两条视频，单条点赞都超过70万，账号还新增了近10万粉丝。这个数据，无论放在外卖推广还是抖音 CPS 内容里，都相当有冲击力。

更值得关注的是，它并没有采用常见的“直接介绍优惠、展示商品、引导下单”套路，而是在内容形式上做了明显变化。

第一条视频借鉴了影视解说的表达方式，通过类似剧情讲述的节奏，把外卖内容包装得更有故事感；第二条则采用了早期科普节目的风格，用一种带有知识讲解感的方式呈现信息。

本质上，内容还是外卖 CPS，但呈现方式已经跳出了传统广告的框架。观众先是被视频的形式和节奏吸引，愿意看下去，随后才接触到其中的推广信息。

这也是它能够获得大量点赞、评论和关注的关键：不是一上来就“卖”，而是先把内容做得足够好看、足够新鲜。

对于正在做外卖 CPS，或者尝试其他抖音 CPS 项目的朋友来说，这个案例很值得参考。与其反复套用同一种广告模板，不如换个角度，从影视解说、科普节目、纪录片等成熟内容形态中寻找灵感。

当然，评论区也有人提到，相关视频可能存在隐藏旧视频、投流等操作，甚至有人认为这本身就是广告。但无论是否进行了投放，这种通过内容形式完成表达转换的思路，依然值得研究。

做 CPS，流量很重要，但怎样让用户愿意停留、看完并产生互动，同样不可忽视。真正有竞争力的内容，往往不是把广告说得更明显，而是让广告看起来不像广告。
