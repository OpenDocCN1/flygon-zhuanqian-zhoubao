# 如何渡过人生低谷
作者：龙哥

低谷期真的能熬过去吗？很多人都问过这个问题。答案其实不在某个惊天动地的道理里，而是藏在几个朴素到容易被忽略的动作里。

今天想和你聊聊，怎么在人生灰暗的时刻，让自己稳稳地站住。

**第一，手头要有一笔“不动款”。**  
这笔钱不需要多，但得够你在突然失去收入、面对变化时，依然维持现在的生活节奏。它不一定是存款数字，更是你敢说“不”的底气。没有这笔钱，很多决定都会变形。

**第二，试着悲观一点，而不是强迫自己乐观。**  
听起来反常识，但当你把预期压到最低，反而会觉得每一步都是赚到。凡事先想最坏的结果，提前接受它，心理防线就不会轻易崩塌。与其天天喊“会好起来的”，不如先承认“可能会更糟”，然后你反而踏实了。

**第三，做那些暂时不赚钱、但你觉得有意义的事。**  
可能是写点东西、整理房间、帮朋友一个忙，甚至只是看完一本搁置已久的书。这些事换不来钱，但会让你确信自己依然有创造和给予的能力——而这东西，低谷里最值钱。

**第四，别忘了滋养自己的小宇宙。**  
你不可能从一个枯竭的杯子里倒出水来。所以哪怕再忙再丧，也要留一点时间给那些能让你充电的事：散步、听歌、发呆、见舒服的人。你把自己养好了，世界才会对你和颜悦色。

说到底，低谷不是用来冲刺的，是用来蓄力的。就像古人说的：居安思危，未雨绸缪。把该准备的准备好，把心态放平，把自己照顾好，路自然就出来了。
