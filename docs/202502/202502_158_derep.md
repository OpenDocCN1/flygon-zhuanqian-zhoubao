# 戒烟，也可以这么简单
作者：龙哥

很多人以为戒烟是一场血拼意志力的硬仗，其实大概率是一场换句话的游戏。

核心就一句：从“我从来不……”开始。

你想停掉的习惯是什么，就把它直接填进这句话的后面。不是“我要少抽点”，不是“明天开始戒”，而是反向宣告一个已经成立的事实——我从来不抽烟。

听起来像心理暗示？实测下来，这套思路真的通用。焦虑时的刷手机、睡前瞎逛、嘴馋的宵夜，只要把对应的动作套进“我从来不……”的句式里，重复几次，大脑会开始配合演这出戏。坏习惯不是被硬拽掉的，是被重新定义掉的。

所以别再和自己较劲了。选一个你厌倦的毛病，填进这句话里，然后就这么认定下去。

你我都可以不再吸烟了。
