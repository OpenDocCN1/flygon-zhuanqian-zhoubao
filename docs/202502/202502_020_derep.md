# 视频号的 AI+中老年情感，一个被严重低估的赛道
作者：龙哥

**被低估的AI中老年情感赛道，有人靠它悄悄赚到钱了？**

最近在和一位视频号老玩家聊天时，他提到一个很有意思的判断：AI 和中老年情感内容一旦在视频号上结合，潜力远比你想象的大得多。

这位朋友从2022年就开始做视频号，做过搬运混剪，也在2023年研究过短视频挂车投流，2024年上半年更是把实拍好物推荐、口播带货、数字人带货试了个遍，下半年又折腾过短引微付费加挂车投流。可以说，主流变现方法基本都接触过，也拿到过一些结果。但真正让他反复提到“异常值”的，是最近这个方向——AI+中老年情感。

眼见为实。春节期间（1月25日到2月15日），他和搭档两个人，仅凭20个账号，在20天里就做出了纯利润，而且每天真正花在工作上的时间不超过3小时。用他的话说，简单到自己都惊讶。

为什么这么赚还容易被忽略？因为中老年用户情感需求旺盛，而AI又让内容生产变得特别便宜。不需要团队，不需要昂贵的设备，普通人也能快速批量产出内容。当然，这模式也有让人头疼的部分：账号消耗很快，差不多10天就要换一批。如果自己从零注册，注销后还得等30天才能重新投入使用，号少的人很难撑起来。他目前的解法是直接租号，带实名和橱窗的号大约300元一个。

有意思的是，评论区的反馈也印证了这个趋势。有人提到，市面上已经有不少三农账号用数字人带花草果蔬种子；还有人说总看到有人卖金元宝、金钥匙给中老年用户，之前没想明白，现在恍然大悟。这届中老年观众的情绪价值，正在变成明码标价的生意。
