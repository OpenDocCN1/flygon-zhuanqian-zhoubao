# 一个人靠AI两天“啃”完100篇精华帖，90张思维导图直接带回家

你的收藏夹里，是不是也躺着上百篇“留着以后再看”的好文章？

说实话，我以前也这样。这半年，我把过去刷过的帖子一篇篇翻出来整理归档，边整理边琢磨：自己接下来到底该往哪个方向走？是不是要继续做这件事？迷茫和失落都经历过——毕竟大家谁都不是神仙，没有人能永远电量满格。

直到我刷到圈友萝卜的分享——他带着一群人，整整忙了六个月，产出了200多张思维导图。这个数字一下子点醒了我：我手头也有资源，完全可以来一次自我挑战，看看自己多久能做出相近的东西？

于是，我直接拿【新人必读100篇】当了试金石。

结果出乎意料地惊喜：一个人，一套AI工具，两天时间，顺利完成90篇精华帖的思维导图。坦白讲，论视觉精美度，我的作品比不过萝卜团队，但核心观点都被准确提炼了出来。以AI目前能做到的速度和完成度来说，我认为这个效率已经相当能打了。

有一点想说清楚：我没有对帖子做任何过度解读，只是如实梳理了大佬文章里的核心论点。想深入研究细节的朋友，翻一翻对应的原文链接就行。

一个人赶工，难免粗糙。不少地方还没打磨到位，后续我会持续优化迭代。

这份导图，本来是想送给一位好友的新年礼物，转念一想，不如见者有份，就当是提前给大家拜个早年啦！
