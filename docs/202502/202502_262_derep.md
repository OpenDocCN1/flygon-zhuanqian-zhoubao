# 零代码，开发一个类 Copycoder 编程提示词插件

最近看到一篇很有启发性的文章，标题叫《零代码，开发一个类 Copycoder 编程提示词插件》。作者邬轼，硬是凭着一股折腾劲儿，把这件事做成了。

他是做 AI 产品运营的，对海外市场不算陌生。但就在 8 个月前，他还一度觉得自己和代码无缘。当时为了帮团队搭一个专属页面，他狠狠啃了一阵子编程书，结果依然写不出清晰可用的东西，光是前端框架的复杂度就把他劝退了。直到 AI 编程火起来，他才发现——以前想做又做不出来的网站、网页，现在都能靠 AI 快速落地。他试着用 Cursor 做了几个项目，居然一口气搞定了好几个网站、插件和 Python 脚本，别提多开心了。

而这个“类 Copycoder 编程提示词插件”的创意，正是他在做网站的过程中偶然冒出来的。整个开发过程，基本可以称得上零代码实现，更多是借助 AI 来补齐技术短板。
