# 3.明信片生成器

灵感来自野兽派和印象派的文生图，内置了 36 种绘画风格，色块明快、对比强烈，所以我给它起名叫明信片。#小程序://小微智能体/68tJgiaTyEUSkXn

输入“一只威武的狮子”，

![](img/ed9e92447927cd1d0010d435fdbb49cc.png)

输入“一只猫”

![](img/8414f528b506e92b91dc827437374881.png)

整体是先参照野菩萨分享的工作流复刻，再做二次修改。他在 6 月份就出了制作视频，我当时完全看不懂，直到做了前面两个小项目后才看得懂、跟得上。前面两个作品做完没做记录所以回忆起来比较零散，这次明信片从开工就同步截图记录，打算发到星球里，所以过程比较细也便于复盘。

1.打开扣子

![](img/641aa75c7f38202e048d243d3f34011a.png)

2.建立图片工作流，现在图像工作流已并入工作流总入口，图像流命名为 postcard，描述为“用户输入想要的物体后，随机调用不同风格进行图片生成”。

3.新增节点：添加图片生成节点，接入通用图片生成模型

4.设置起始参数

在开始节点定义两个变量：用户风格 user_style 和用户内容 object

![](img/0636317ccca47e67f3b99bf16ad4e545.png)

![](img/67f81696c61400264c619480f0ee9ab6.png)

5.图像节点参数配置：

![](img/eea9889c1122eed537e40a338f15d12c.png)

画幅比例选择 16:9 横屏

参数名：style, object

提示词写法：用双层大括号 {{}} 填入 style 和 object，让模型在提示词里动态调用风格与物体

负面提示词：使用通用屏蔽词 calligraphy, nsfw, blur, sign, border

![](img/3bf8ba9e828478f9ac3a7e5b3e564c34.png)

6.结果节点配置输出变量，把生成的图片作为最终输出

![](img/7c1bafdeeef7c6d318b49eeb2949fa74.png)

7.试运行，object 填“cat”，style 填“henri mattise”亨利·马蒂斯，法国野兽派代表，强调主观感受、不做明暗，常以大面积纯色涂抹和弯曲线条简化物象，画面装饰性很强

![](img/28a0e9922c8f95981a90cad078edf043.png)
