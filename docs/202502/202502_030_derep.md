# 用剪映AI数字人批量做口播引流，刚上手就忍不住记录下来
作者：龙哥

前两天打开剪映时，瞎逛到一个还没大面积开放的AI数字人入口，现在处于免费试用期，我就顺手体验了一波。实际用下来比我心里预期的顺滑不少。

这个功能点能干的事比表面看起来多。文案长度能先做字数预估，不会写完才发现超时；素材方面，你可以自带素材包让它按脚本自动对位，也可以直接让它从自家库里去匹配画面；背景音乐可以随意切换；输出时还能自动叠加音效、做重点强调。

就是基于这几轮的实测感受，我整理了一份从0到批量生产的实操流程，方便同样想快速起号的人直接照做。
