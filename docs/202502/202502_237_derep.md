# 创业做茶，我栽了，但服气

我是刘飞，播客“三五环”的主理人，早前在互联网大厂做产品。去年差不多这个时候，我跟超哥、乐克凑了个局，弄出一款袋泡茶，叫“三五杯”。前几天我们在小红书直播了一场“散伙聊天”，算是正式道别。结局挺体面：品牌关停了，钱没亏，反而小赚一点；我心里也没有怨气，反倒挺踏实。与其说创业，不如说几个朋友想一起折腾点有意思的事。

为什么会有做茶的念头？三个理由让我觉得这事值得试。

第一，需求是实打实的。过了25岁，健康焦虑就找上门了，少油少酒成了默认选项，看看元气森林三零饮料和轻食有多火就知道了。按健康建议，成年人一天要补1.5到2升水，折合成400ml的马克杯，也就是三五杯的量。白水太寡淡，甜饮料又容易腻，茶这种微苦回甘的东西，正好站在中间。我现在每天烧一壶水，拿普通杯子反复续泡，一天一两份茶叶就足够了。

第二，喝茶这事的“心理成本”太高了。一说好茶，脑子里立刻浮现茶盘、茶宠、公道杯，杭州那些茶馆还要分茶器，不同茶叶有不同流程，倒茶的角度和节奏都得学。可在办公室日常里，真有必要为一口微妙差别付出那么大成本吗？用马克杯随便泡，味道没差到哪去。酒店里的碎茶包难喝得劝退人，茶馆又贵又费劲。如果给饮品打分，白水是10分，碎茶包是30分，茶馆是90分，那大多数人想要的，不过是80多分的日常款。

第三，市场上缺一个靠谱的“买手”。茶叶品牌不少，但多是精美礼盒，适合送礼不适合自饮，而且盒子里的茶叶量少得可怜。供应链更深：你买到的“西湖龙井”可能是临安货，“杭州名茶”兴许是安徽来的。还有朋友亲历过，明明订好的茶，茶农都能连夜掉包。产地、季节、气候都影响风味，普通人想喝口踏实的茶，真不容易。

所以我们想做一款“简单”的茶。超哥是这个局的核心，我和乐克都偏内向，全靠他张罗；乐克（乐师傅）在供应链上很有经验。产品上，我们不搞山头、不编故事，只做清香淡雅的乌龙和普洱，老茶客可能嫌太素，但办公室新人上手刚好。茶包怎么泡都行，久泡也不涩，用户不必为“水温对不对、茶量够不够”而焦虑，这种压力本就不该转嫁给用户。我们还去掉了绳签，因为按我们当时的统计，超过70%的人根本不用那根线。这些设计也收到了真实的认可，有知有行的创始人孟岩、“银杏树下”的普洱猫都夸过。

那为什么还是停了？外部困难确实不少。茶是典型“喝过才知道”的东西，没法像数码产品那样靠参数种草；广告场景里，讲送礼比讲口感更奏效；短视频时代，茶又没有美妆和零食那种视觉冲击，直播间里只有“买一送五”才能跑量，但那不是我们想做的产品。我们也试过耐心做内容，可如今内容平台都成了广告场，不花钱的品牌内容几乎传不动，除非像“熏鸡”那样突然爆火。我们连自己的播客都没敢使劲推，怕朋友们只是捧场，而不是真的爱喝。

但这些都是能继续磨的问题。真正让我决定停下的，是那句老话：为什么是你？答案很明白——擅长和热爱，我没对齐。我能做出合格的产品和设计，却把“喜欢喝茶”误当成了“喜欢做茶生意”，高估了自己的热情，超哥大概也有同感。再加上体量小、成本高，包装快递的标准只能一降再降，产品上线后又要等好几个月才有反馈；营销上还得不断迎合平台规则，像在跟一团棉花较劲。这种感觉很无力，也对不住当初振臂一呼跟来的朋友。但硬撑下去，风险只会更大，所以超哥来商量收场时，我几乎没犹豫就点头了。

这段经历，我把它视作一笔宝贵的学费，也是一份真实的体验。它让我更确定：做播客、做独立开发，依然是普通人能借助的最大杠杆，就像《纳瓦尔宝典》里说的。现在回头看，需求判断并没有错，错的是我把自己摆错了位置。我依然相信，袋泡茶领域早晚会出现真正立得住的品牌，只是不一定是我们。

我们的品牌名叫“sawubona”，来自南非祖鲁语，字面意思是“我看到你了，你在这里”。这个因果很有趣：不是因为你在，我才看见；而是因为我看见，你才存在。就像王阳明说的：你没看这朵花时，它和你一同归于沉寂；你来看它时，花才一下子鲜活明白起来。

这些话也许不完美，但很真实。“三五杯”虽然结束了，但它是我寻找路上遇到的一处好风景。希望我的复盘，能给你一点启发。
