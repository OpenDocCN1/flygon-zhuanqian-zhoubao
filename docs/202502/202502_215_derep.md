# 同城才是📕最后的增量，我用20篇笔记给家人的牛肉火锅店做了一个自动获客的号

大家好，我是龙哥，专注📕运营到现在。

22年就进了📕航海第一期开始系统玩这个平台，从那时到现在一直在坚持。刚入行时做教育号，两个月就能涨30万粉丝；现在起一个号，一个月能有1万粉就已经不错了。流量成本越来越高，竞争越来越卷，规则也越来越严，这种变化是真切感受到的。

转折点在24年。我开始尝试把📕的流量导到线下、同城本地。做了几个同城项目后发现，线上纯交付的生意远不如线下交付好做，客户更真实，复购更稳定。

最典型的就是我帮家人操盘的一个账号。是一家做潮汕牛肉火锅的打包店，店里负责切好装好，客人自提回家吃，没有堂食这一块。今年年初才开始做📕，到年底，营业额直接比上一年多出了20万以上。稳定复购的客户里，最夸张的一位，一年就在店里消费了八千多。

为什么同城这么好做？

因为📕的同城搜索红利还在，尤其是低线城市。美团、大众点评都得砸钱买曝光，📕更看重你愿不愿意花时间去做内容。4线城市的内容供给几乎是空白，只要你愿意持续发，基本没有对手。

我这个火锅店的号，核心就靠20篇笔记把人设和需求打透，之后就是持续获客的机器。内容不求爆款，求的就是精准、同城、能被附近的人搜到。

评论区的朋友也提到，他把自家房子改成民宿了，美团根本不推，靠自己发📕在四线城市引流。说的很对，平台付费投放是一条路，但用内容抢占同城心智，才是现在最划算的红利期。
