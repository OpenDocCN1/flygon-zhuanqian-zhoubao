# 2024 年个人复盘：17 年打工人，40 岁出来创业，遭遇女儿生病、婚姻破裂，我是如何提升心力，走出阴霾的
作者：龙哥

有人晒2024年的成绩单，满屏都是“赚了多少”“又突破了几位数”。我为他们开心，但我也知道，世界的另一面，总有人在硬扛。

2024年，我也原本以为会是全力冲刺的一年。当了17年打工人，40岁才终于迈出那一步去创业。可命运没按预告走：女儿突然生病，婚姻也在最需要支撑的时候散了。所有的计划、事业节奏，甚至对生活的掌控感，一夜之间被冲得七零八落。

在最难的时候，我也怀疑过自己，很多个深夜被内耗填满，怎么都爬不出来。可身后还有孩子、有责任、有不甘心的梦，只能咬着牙，一件一件地把自己捞回来。

后来我发现，真正让一个人熬过去的，不是运气，不是时间，而是“心力”。心不稳，做什么都是乱的；撑住了心态，脚下的路才慢慢变得清晰。

所以我复盘了这一整年，把那些真正救过我的6条经验，和3个差点把我拖垮的坑，都整理了出来。不教人一夜暴富，只想告诉此刻也很艰难的你：

苦难不是让你低头认输的，而是让你学会，如何用更好的姿势站起来。
