# 前 言

从去年12月到今年1月，我实际跑了一圈发现：BNG游戏赛道在TK的流量比油管还猛。所以趁着这个机会，把TK运营的经验分享给大家。

通俗点说：油管靠长视频播放时长赚钱，TK靠短视频播放量赚钱。我自己试过，做BNG短视频最快半个月就能开通TK收益。

![](img/405e5455255420020ba2c3d319f38b9a.png)

## 那TK到底怎么起步？

我总结了九个关键步骤，不管谁来问，都逃不过这套流程：

**第一步**：买一台苹果手机，推荐iPhone SE2或iPhone 7（二手大概355元左右），往上更好。

**第二步**：自己动手刷机（后面有详细说明，赚钱上也有不少帖子讲过）。记住，该关的功能一定要关干净。

**第三步**：买个能下载TK和网络优化工具的海外苹果ID。注意！一定要和商家确认清楚：这个ID能不能下载TK。比如美区ID之前有段时间下载不了（截止2025年2月14日已恢复）。另外小火箭有些ID自带免费版，有些不带，价格不一样，买之前一定问明白。

**第四步**：登录ID，下载TK（先别打开）和小火箭。

**第五步**：软件下载完后，立刻退出这个ID。

**第六步**：手机环境基本就位，接下来要搭建家庭住宅IP（后面细讲）。

**第七步**：用小火箭扫码，获取独立站的IP。

**第八步**：手机网络OK后，打开TK准备注册。找个海外手机号接码平台，用海外手机号注册。这里有两个坑要避开：第一，注册时年龄一定要满18岁，建议生日选1996年之前的，否则以后开通不了收益；第二，提前注册一个outlook邮箱，把TK账号绑定好，免得以后账号丢了找不回。

**第九步**：养号。完成以上八步后，就是多刷视频、点赞收藏、保持账号像真人。注意，新号在保护期不能关注别人，得过几周才行，这个不影响。

---

另外，有个小细节很容易被忽略：

苹果手机给这台机器传视频时（比如用隔空投送），记得先在后台把TK关掉。别问为什么，照做就行。传完视频后还要记得关蓝牙。

# 二、手机设置与环境准备

TK在不同地区会有不同的内容和功能限制。把手机环境设置好，不仅能体验更丰富的内容，也能保证账号安全稳定。

**手机型号建议：** 苹果7以上（安卓建议用谷歌手机，还是优先推荐苹果SE、SE2）。

## 苹果手机设置要点：

1. **恢复出厂设置**，清空一切。
2. **关闭定位服务。**
3. **关闭广告跟踪**：系统14以下版本打开“限制广告跟踪”；14以上版本关闭“个性化广告”。
4. **修改语言、地区和时区**：语言改成英语、繁体或目的国语言；时区要和IP所在城市对应。
5. **必须拔掉SIM卡**，千万别插国内卡。

## 2.2 下载TK并注册海外手机号

### 2.2.1 怎么下载TK？

手机环境弄好后，就可以去下载TK了。先准备一个海外苹果ID（自己注册或买都行），登录时一定要点“不更新”。

登录成功后直接搜索TK并下载。

### 2.2.2 怎么注册TK账号、获取海外手机号？

刚开始用免费的outlook邮箱就行，每个IP每天能注册好几个，按流程来就好。

也可以用海外手机号接码平台：

主选：https://222sim.com/
