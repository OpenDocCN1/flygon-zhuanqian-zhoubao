# 想真正读懂用户，先把自己的立场放下
作者：龙哥

想要摸清用户想要什么、痛在哪，本质上就一件事：别坐在办公室里空想，去用户真实的生活里待着，用他们的方式去看产品。

如果你连用户到底在用产品解决什么问题都没搞明白，就贸然去设计、去创新，那准备工作就没做到位。

我印象很深的一个案例是儿童牙刷。按成人常理推断，小孩的东西应该做小做细才好拿。可真正蹲下来看孩子刷牙，才会发现逻辑完全不对。孩子的手劲小，根本做不到像大人那样三指捏握，他们是整只手掌包裹着刷柄在用。于是更让孩子好用的牙刷，反而是把柄更粗、更便于抓握的设计。

很多看似合理的功能，其实都是设计师离开使用场景的自我臆想。

汽车就是个典型。印度的街道狭窄颠簸，车身就得做得更窄更灵活；美国的长途公路坑洼多，耐用性就比外观更重要；国内的大路和社交语境下，车往往更偏向体面感。

护肤、饮食的偏好同样如此。中国市场对美白、防晒的需求旺盛，是因为文化里偏爱白净；欧美不少人追求健康小麦色，防晒品的接受度就相对平淡。泰国人爱吃陈米，中国人偏爱新米；国外对预制菜接受度高，国内却充满戒备。这些差异不是产品好不好，而是观念和生活方式不一样。

男人对女人的感受感到陌生，本国人对他国习惯一知半解，北京人看不懂江西人的表达，内向者难以读懂外向者的节奏，本质都是共情的距离。

易到创始人的反思也很有代表性。做出行服务时，他以为用户要的是豪华车型，像特斯拉、奔驰宝马那种。可实际上那段时间大众出行已经转向出租车场景的下沉。他之所以判断失误，核心原因是自己很久没坐过普通出租车了。

当你长期用自己的经验去套用户，你看到的永远是自己想要的版本。放下产品经理的视角，换成用户的视角去体验、去观察，你才会真正知道他们要的是什么。
