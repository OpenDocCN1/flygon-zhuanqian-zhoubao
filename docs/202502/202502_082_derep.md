# （ai 写作） 我用 ai 写爽文小说 赚到第一笔小说稿费的故事
作者：龙哥

写了五年稿子、几乎没碰过小说的我，怎么也没想到，过年期间随手接的一个小说单，居然让我赚到了人生第一笔“其他品类”的稿费！小说已经在番茄上架，800元稿费也顺利到账，客户那边确认无误。趁着这股热乎劲儿，我把用AI写爽文小说的全流程和变现心得，彻底摊开来讲。

这个单子来得其实很偶然。春节假期闲着没事，接了个小说任务，本来只想练练手，结果AI写出来的内容居然能直接交付，最后还真拿到了钱。目前小说已经在番茄平台发布，客户也把费用结清。整个过程比自己想象中顺利得多。

先分享几个关键经验。有朋友问过我用哪些工具，我自己实测了DeepSeek和GPT：DeepSeek擅长抠细节、补剧情，但完全依赖它容易跑偏，写出来的情节特别“抓马”，甚至前后接不上。GPT在逻辑连贯性上更稳一点。最优解是组合使用——先用DeepSeek做剧情发散，再交给GPT梳理润色，同时自己手动筛掉不合理的地方。这种搭配下来，整体质量和阅读连贯性都会好很多。至于Kimi的小说功能，我还没来得及试，暂时不做评价。

这次经历让我对AI写作有了新的理解：它更像一个高效助手，而不是来抢饭碗的。如果你也好奇AI写小说怎么变现，可以先去我的飞书文档看看全流程，动手试试就知道了。
