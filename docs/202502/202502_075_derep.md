# 用 4G 法则聊聊：怎么把人引进来、推起来、留下来

先做个自我介绍。我混迹职场多年，从传统行业跳到互联网，再到游戏公司，做的几乎都是 HR 相关的事情——人才发展、组织发展、招聘这些。中间也和朋友一起折腾过电商创业，没赚到钱又回到职场。最近一次离职后，借助老同事的资源，和团队一起创业做游戏配套业务。

2024 年 5 月加入这个圈子以来，我一直是潜水状态，看大家分享自己的经历收获很大。尤其是两句话让我触动很深，“发声等于发生”和“任何连接，先想能为对方创造什么价值”。所以，今天想从我最熟悉的人才激励这个角度，聊一个我一直在用的思考框架——4G 法则。

这个框架的本质，和德鲁克说的一样：**管理就是激发人的善意和潜能。**

它主要解决两个实战问题：

第一，招人时，怎么挖出候选人的真实诉求，并用对的方式把他吸引过来；
第二，带团队时，怎么对关键人才做针对性激励，让他更上劲、更愿意长期留下。

对创业者来说，这个逻辑落地的意义就三件事：
找准吸引点，靠什么说服优秀的人跟你一起创业；
找准激发点，用什么驱动他持续产出；
找准关注点，靠什么让他愿意长期绑定不走。

这个思路特别适合在成长期创业团队里用。因为在关键期，**一个真正能打的人，效果往往抵得上五个人。**

举个我自己的例子。离开游戏公司后，我一开始规划的是单干，做个体户式的独立创业。后来一位前领导找我加入现在的项目。她找我的理由很直接：我在这个赛道够专业、能扛事，在她认识的人里我是首选，1 个人能顶 3 个人。

而她打动我的地方也很具体：她知道我有创业的想法，给了我充足的自主空间，提供了有吸引力的合伙人股权，以及落地的生活保障。这三点正好覆盖了吸引、激发和留存。
