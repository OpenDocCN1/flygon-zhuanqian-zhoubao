# 🧧春节晒作业抽门票，结果出炉啦
作者：龙哥

开工已经两周有余，大家的节奏找回来没？

这段时间，我把大家的春节作业挨个浏览了一遍，1200 多份投稿，每一份里都藏着不同的生活片段和创业故事，真的太有料了。原帖在这里可以翻阅：

下面挑几条很有代表性的给大家看一下：

有圈友在自家门口随手拍了一张照片，光线和构图拿捏得刚刚好，远看竟有种富士山的意境。
还有人晒出了让人惊叹的减重前后对比，用实际行动诠释了什么叫掌握身体，掌握生活。
加入赚钱满两年的伙伴，航海训练营结束后持续深耕👸号，终于拿下了人生第一个五位数收入。
也有人分享了工作室深夜的灯光照，那盏灯就像一座灯塔，为前路未知的创业旅程指引方向。

更多精彩作业，欢迎回到原帖继续逛。

说回活动本身，这次我们准备了三张龙哥盟的入场券作为奖品。抽奖全程用了巨公摇号小程序，公开透明随机出结果。恭喜三位幸运圈友，接下来我会私信各位，同步奖品的领取流程。

———

这次春节活动做完，让我想起当初赚钱做社区的初心。

有人在事业的低谷期进来，借助社区里的资源和信息差实现逆袭，还把自己的经验回馈给后来人；
有人历经多次创业受挫，却依然没放弃初心，一步步在自我探索和事业探索的路上往前走；
也有人直接在这里遇见了另一半，携手朝着同一个目标奋斗，一起奔赴新的生活。

这些来自不同阶段、不同背景的故事，既是作者们自己的成长存档，也给处在相似困境的后来者提供了希望和思路。
