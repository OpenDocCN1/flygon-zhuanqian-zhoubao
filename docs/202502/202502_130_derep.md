# 京东杀入外卖：用高客单价打一场看不见的价格战
作者：龙哥

当社区团购的厮杀还在继续，京东却把战场直接搬到了美团和饿了么的主场。2月11日，京东外卖一登场就祭出全年免佣金+只招品质堂食商家的组合，这波操作表面看是温和入局，实则是在外卖行业的根基上动了刀。

### 第一部分：电商的打法，外卖的命脉

外卖长期被诟病的就是一笔笔“流量税”。骑手一单到手不到5块，平台抽成却能到26%。京东的0佣金，像是直接捅在了旧规则的痛点上。但这不是简单的烧钱。

京东玩的是另一套逻辑：用成本结构倒逼服务升级。

它把自营电商里“低损耗、高履约”的基因搬了过来，优先绑定连锁品牌、黑珍珠级别的餐厅，并把自己的冷链物流能力打包输出。久而久之，用户脑子里会形成一个等式：京东外卖=靠谱、干净、快。

这一步很准，直接瞄准了美团饿了么最赚钱的那批人。据测算，中高端订单虽然只占整体，但贡献的GMV超过两成。京东不需要全盘占领市场，先吃掉这30%的高端用户就够了。

更关键的是定位。别人还在靠满减抢学生和白领时，京东很可能用实体门店资质审核+京东Plus会员的绑定，把战场拉到家庭品质消费的赛道上来。品类、客单价、信任感全部拉满。

当然，免佣金不代表永远免佣金。等优质供给和用户习惯被培养起来，再收回“流量税”的窗口会一直在。

### 第二部分：高价值用户的悄悄“出走”

美团最新财报已经露出了疲态，交易用户增速跌到个位数，分层流失其实早已开始。京东这一冲，暴露出对手生态的三个软肋。

第一，商家关系不稳。杭州一位连锁烘焙的负责人说得直白：美团抽成24%，七成订单是自然流量。如果有平台能带来更高客单的客群，换地方有何不可？京东把物流数据、配送时效预测直接开放给商家，用B端数字化工具做挖角，这招很致命。

第二，场景被割裂。美团的到店和外卖能形成闭环，但边界感很强，更多是满足已有需求。京东不一样，它擅长“创造需求”。你刚在京东买了空气炸锅，下一秒页面就推半成品食材套餐，外卖极速送到。商品和服务的场景化耦合，是现有外卖平台很难复制的。

第三，用户的心智迁移。美团的高净值用户下单，第一看的是品牌，第二才是平台。京东自营多年的品质信任可以直接平移过去，用户选择会变得更“无脑”。当最优质的人群被渗透走，留下的就是利润最薄的盘子。

### 第三部分：外卖3.0的雏形已经显现

京东这次进来，搅动的不是份额，是估值逻辑。

从GMV崇拜转向CLV经营。当京东用电商的用户终身价值模型来考核外卖，美团4.5亿用户的基本盘就得重新算账。市场上已经有机构开始用“人均年利润贡献”来重估这个赛道。

物流标准会被改写。京东的分布式仓配一旦和外卖配送融合，“半小时必达+全程冷链”很可能成为新标配。问题是，美团2023年骑手成本已经占总收入的72%，对手想跟进，代价会非常痛。

合规成本也会抬升。京东用严格的商家准入做品控标杆，恰好呼应监管的明厨亮灶方向。过去靠大量小作坊冲量的模式，将面临合规压力增大和优质供给流失的双重夹击。

这场仗的伏笔，其实早在刘强东提出“无界零售”时就埋下了。京东要证明的不是自己能做外卖，而是高客单价的服务必须配得上高效率的成本体系。

美团和饿了么还在算补贴能守住多少份额时，京东已经在下另一盘棋：用20%的高净值订单，改写100%的行业规则。

终究，推倒旧秩序的不是更高的大楼，而是全新的一套语言。
