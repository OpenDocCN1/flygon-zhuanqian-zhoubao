# 别再被 DeepSeek 晃晕了，普通人翻身的路子就三招



最近后台反复被问到同一个灵魂拷问：DeepSeek 满天飞了，我这种普通人到底能拿它干嘛，会不会又乱了阵脚。

这个问题我太懂了。我这辈子至少卡了三次，每次卡住的感觉几乎一模一样。

第一次是 2012 年刚毕业。工业设计二本生，PS 只会点皮毛，连张像样的海报都做不来。能找的工作说没就没，全然没方向。

第二次是待过大厂之后。口罩后裁员降本，晋升通道堵死，身边都是汇报 PPT 的内卷。非嫡系、不会钻营、又看不惯氛围，想走又不知道往哪走。

第三次就是现在。DeepSeek 横空出世，第一反应是震撼，第二反应是焦虑，全网都在说变现，我却不知道先迈哪只脚。

三次死胡同，我的破局方式其实大同小异：别空想，先动起来，用行动换信息。

**第一次破局：没本事就靠堆量**

毕业那年夏天在武汉，我把所有招聘网站、校园宣讲、🐧 同城群能翻的地方全翻了一遍。简历改了一版又一版，从工业设计一步步放宽到只要名字带“设计”的岗位全申。

两个月下来，投出去几百份，最后在 🐧 群里捞到一个房地产广告公司的平面助理。1200 块一个月，单休，不包吃住，夏天 40 度还要跟着跑办公室。

条件差到离谱，但我去了。三个月里，CorelDraw、PS 实操全现场学会，然后直接跳槽。

这段经历教我的就是：从专业出发，把搜索面放大到最大，去试、去撞，只要试够量，机会自己会浮出来。

**第二次破局：想转型就去找活人**

大厂待不下去时，我没在网上瞎搜。我直接去问🛰️里关系铁的同学。

三条线索冒出来了：两个高中同学靠跨境电商赚到钱，一个在义乌创业的朋友手里有大量一线资源。我马上把孩子安排好，买了张火车票，直奔义乌。

朋友带我挨个见他认识的创业者。几顿饭下来，一个做饰品的老板指了条路：珍珠现在很火，去诸暨看看。我对首饰有点偏爱，当天就杀过去了，直接兼职做起珍珠生意，小赚了几万，还顺便问了跨境同学怎么把货卖到国外。

后来这事断断续续做，嫌精力不够就找了合伙人，自己当小股东坐着分红。

这一次最有用的不是技能，是主动找信息源。先找到一个微小突破口就立刻上车，在路上再根据喜好、市场和精力调整方向。

**第三次破局：面对 DeepSeek，先写再说**

DeepSeek 刚出来时我也蒙了。为了让自己冷静，我开始写东西，把疑惑一问一问抛出来，同时逼自己回答 DeepSeek 到底值在哪。

文章越写问题越多，读者也在问我，我的👸号一天只能更一篇，根本消化不过来。于是开了个知识星球，把思考沉淀下来，变现的苗头就出来了。脑子里现在已经冒出好几个细分方向。

其实大多数人现在都一样，不知道 DeepSeek 能干嘛。那就先做起来。开个👸号、视频号，把自己的思考先写出来就行。起码接下来几个月，这类内容流量都不差。我最近在写我爸从赤贫农民到千万身家的故事起点就是那么低，只要抓住一点机会就拼命去试。

说到底，我们最大的毛病都是想太多做太少。动起来之后，灵感和方向会自己追着你来。

总结下来，普通人面对迷茫时的通用解法就三条：

1、已有专业的人，把 DeepSeek 当成放大镜往深挖，技能变现、涨薪更快。

2、没有明确方向的人，去看大量案例，挑一个勉强有点兴趣的先试，边做边调。

3、实在没头绪，就先写文章或拍短视频，靠内容先做一个万粉号，方向会在创作中长出来。
