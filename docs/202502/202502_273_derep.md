# 一行代码也不写，使用 Cursor 开发一个俄罗斯方块游戏

你相信吗？不敲一行代码，也能亲手捣鼓出一款俄罗斯方块小游戏。

说实话，在 AI 编程工具出现之前，这听起来像天方夜谭。但现在，借助 Cursor，零基础的小白也能轻松做到。

星球里的大铭同学之前分享过一篇用 LocalIssues 管理本地 issues 的教程，不过很多圈友反馈说看得一头雾水，操作步骤不够直观。为了让大家更清楚地理解实际玩法，他专门录制了一个视频，手把手演示如何完全脱离代码，只用对话式的操作，在 Cursor 里从零搭出一个俄罗斯方块小游戏。

整个流程不需要任何编程基础，也不用理解复杂的语法逻辑，跟着视频一步步来就行。特别适合想尝试 AI 编程、又迟迟没敢动手的圈友。


别再只是围观啦，动手试试才知道 AI 到底有多能打。
