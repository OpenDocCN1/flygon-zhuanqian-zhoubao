# Deepseek 本地版部署教程来了

本地跑 Deepseek，显卡明明就在那里，结果后台却在偷偷用 CPU 硬扛，生成速度慢到怀疑人生？别急，今天这篇就是来帮你解决这个问题的。

核心思路很简单：用 Ollama 做本地部署时，把算力从 CPU 切换到 GPU，关键就两步——搞定 CUDA 环境，再做好相关配置。改完之后，模型就能真正用上显卡计算，输出速度直接起飞，体验顺滑不少。

这篇内容相对小众，但凡是热衷于自己动手折腾本地模型的朋友，应该都明白它的真正价值（懂的都懂）。我也亲测过了，“不可描述”的关键词是可以触发的，没有内容审核，限制也比 API 接口宽松很多。至于其他细节，你自己上手试试就知道。

最近我一直在忙企业内部的大模型本地化落地项目，所以实操类文章更新稍慢。这篇算是百忙之中抽空整理出来的，希望对正在折腾的朋友有帮助。
