# 在赚钱待了快两年，我才看清自己没起量的真实原因

各位龙哥盟的朋友大家好，我是林林，一个靠四处投稿赚稿费维生的自由写作者。

2023年5月社群做拉新促销时我进了群。当时脑子里只有一件事，想照着《纳瓦尔宝典》说的那样，赶紧摆脱卖时间的老路，去找第二、三、四条甚至更多条增量曲线。事后回头看，那个想法确实太理想化了。

我始终觉得，进群后被坑、翻车、交学费都无所谓，最要命的是像我这样翻车无数次却长期不回头看为什么。时间一长就形成了一个负向循环，甚至让我对赚钱的价值产生了偏颇的误判。

所以下面这篇文章，就是我对这两年血泪经历的梳理，也许你能从里面看到自己的影子。

## 一开始想全盘拿下，最后全盘落空

其实我早在2021年就听过赚钱。彼时就想着，等手头宽裕了再进来看看能不能开辟副业。2023年促销一出我就冲了，就是冲着多条赚钱路子去的。

进来后才发现，群里确实现存很多路径，哪怕是零基础、没资源的人也能看到快速变现的可能。我当时就想，既然进来了，不妨多开几个线，多铺几条曲线。

想法本身没错，多了解几种商业逻辑，多尝试是好事。但问题出在我一上来就把目标定为立刻赚钱。结果就是什么都抓，什么都抓不住。

航海项目上体现得最明显。我把📕运营、👸号写作、跨境电商、短剧推广好几个航海都报了名。报名那会儿脑子里都是盈利画面，拿到名额后呢，航海手册可能压根没细看，看了也基本没落地。

现在回头想，最核心的还是动机问题。我的能力、经验、时间、精力都是有限的。可我一开始并没有真正去体验项目，而是带着急于变现的心态硬上。这些项目本就不可能速成，反而让我内耗加剧，参与得越多，焦虑越大。

## 能嗅到风口，却守不住行动力

每天刷群、看帖、抓风向，我对当下的赚钱热点其实挺敏感的。问题是，认知有了，执行却跟不上。我一度天真地认为，只要知道风口在哪，钱也就到手了。

现实是，停留在知道层面，我只是在收集谈资。风口不会因为我懂它就自动分我钱。举个例子，DeepSeek刚火那阵子，我整天围着信息差转，分享、讨论、吃瓜，热闹得很，却没想过怎么结合自己的写作经验和能力把它变成实际产出。对我来说，那些社交货币一点用都没有。

这件事让我明白一件事：当我不是天赋型选手时，更需要做笨鸟。风口来了，不抢跑，靠信息差的优越感去撑场面，最后只会眼看着机会溜走。

## 迷信天赋加成，却缺了滴水穿石的耐心

我相信每个进群的人都有独特优势，也相信自己有。这种信念没错，但优势不被使用，就等于没有。

中国有14亿人，想法、认知、能力相似的人海了去。想拉开差距，拼的不是起点，而是持续的耐力。古人说滴水穿石非一日之功，偏偏我做事常常浅尝辄止。

比如📕那个航海，我明明有写作基础，却只想用AI批量生成文字、配图就发。发了三五篇没反馈就泄气了，完全没意识到复盘迭代和长期积累的意义。

慢慢地，我养成了一个坏习惯：做不快、赚不到就撤。主业没捡起来，副业也没做成，卡在中间反复内耗。

## 迷信“先做个垃圾”，却忘了垃圾也要升级

去年很火的一句话是“先做个垃圾出来”，不少人，包括我，只记住了前半句。于是长期输出低质内容，却忘了后半句是“再去优化”。

我做👸号写作持续了很久，但写完就发，从不回头看数据、看结构、看哪里能更精。输出量上去了，质量没上去，结果也就不见踪影，最后甚至怀疑自己是不是不行。

执行力重要，但盲目执行会变成无效苦劳。目标在变，市场在变，如果不随时校准方向，只靠蛮力，最后就是投入高、产出低。有时候我想到了却不去做，做了又不去想，这两者必须要同步。

## 最后说点心里话

我写这篇复盘，并不是因为在赚钱里已经赚到钱了。作为一个没有稳定收入的自由职业者，能挤出时间复盘，更多是想把之前踩过的坑整理清楚。

其实这两年也并非全无收获。通过发一篇精华帖，以及在群里多次中标风向标，我的商业嗅觉和信息判断力被锻炼出来了。写下这篇复盘，就是想把自己的短板摊开，未来能更有效地用好社群的资源，真正做到花小钱撬动大结果。

所以我也建议你，如果你在赚钱的路上遇到挫败，不妨像我这样在群里讲讲。把失败讲清楚、想明白，它就会变成你的认知资产，帮你在下一次机会来临时，反应更快、出手更准。
