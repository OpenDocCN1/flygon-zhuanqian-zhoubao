# 选对同行圈，能把认知拉满，感谢赚钱大学陪我开窍
作者：龙哥

原文链接：[`www.yuque.com/for_lazy/zhoubao/kq9z1krbi8pqexs4`](https://www.yuque.com/for_lazy/zhoubao/kq9z1krbi8pqexs4)

圈子里的小伙伴们大家好，我是龙哥。

今天想聊一个我自己踩过、痛过、最后才悟到的老生常谈：选圈子，真的决定了你能走多快。

刚摸到互联网的时候，我几乎是自己摸索前行的。那段时间的经历，说白了就是一连串的试错和坑。那些弯路后来反而成了我最早的互联网启蒙课，让我明白什么叫方向不对，努力白费。

后来我进入了赚钱。进入之后才真正体会到圈子的价值。好的圈子不只是信息对、认知对、价值观靠谱，更重要的是，它能把对的人聚在一起。你身边的人决定了你的天花板，在这里，你更容易遇到能点醒你、能一起干事的伙伴。

所以，回头看，能否在关键时候挑到一个正确的社群，对一个人认知升级的速度，以及变现做项目的效率，都会产生质的提升。

写下这段经历，并不是为了讲故事，只是希望能给正在路上犹豫的你一点参考。看完如果有共鸣，我们评论区聊聊。
