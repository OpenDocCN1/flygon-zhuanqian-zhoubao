# 在营销上，我建议大家别看太多书

**学营销？先放下那些书**

总有朋友跑来问我：“想入行营销，应该先读点什么书？”我的第一反应往往是：别急着看书，先去找件事做。

为什么这么说？因为公司里根本不存在一个叫“营销”的岗位。你也许能进入营销部、市场部或销售部，可进去之后就会发现，大家干的都是具体活儿：有的在直播间当助理，有的在设计商品详情页，有的负责用户访谈，有的盯着达人投放效果，有的在社群做私域运营，还有的埋头剪视频、跑线下门店、布置展会、整理货架。

所以，新人最该做的不是背概念，而是把自己手头那摊事做到足够好。什么算足够好？至少要比六成同行强，这才刚刚够到“合格员工”的及格线。

要是你连这样的工作都还没捞到，那就自己创造练习场景：试着写出一篇阅读量很能打的文章，试着在朋友圈把一批小玩意儿卖出去，或者做一张让大家忍不住点赞的新春海报。动手去做，比任何理论都管用。

我知道有人会担心：不学战略、营销、洞察、品牌这些大词，以后怎么往上走？其实大可不必。这些概念对第一份工作几乎没有帮助。唯一的例外是：如果你是营销专业刚毕业，正在投市场部的岗位，那记住几个术语，或许能在面试时让HR觉得你有点专业底子。

但真正进入具体岗位后，大多数人头五年需要用到的，根本不是这些理论，而是具体技巧、执行效率和趁手的工具。你有没有发现，办公室里总有人剪的视频播放量特别高，总有人管的门店顾客满意度特别高，总有人发朋友圈能收获一大片赞——这些本事，有哪一本经典营销书能直接教会你？

与其啃那些经典大部头，不如翻翻实操类工具书：超市的陈列怎么做、客诉怎么处理、陌拜电话怎么打、达人投放怎么选、餐厅怎么营造热闹感。这些看起来不够“高级”，却能立刻派上用场。

还有一个容易踩的坑：那些被奉为经典的营销理论，对新人往往最没用，甚至还容易养成嘴上谈兵的习惯。说起营销头头是道，落地却一塌糊涂。爱玛电动车的莫总讲过一件事：他们的市场部让小红书粉丝做到了行业第一，方法竟然是去音乐节支个小摊，只要扫码关注，就送一根荧光棒。没什么高大上，但就是有效。

营销从来不是坐在书斋里想出来的，而是一件一件做出来的。所以，少看点书，多干点活，路自然就通了。
