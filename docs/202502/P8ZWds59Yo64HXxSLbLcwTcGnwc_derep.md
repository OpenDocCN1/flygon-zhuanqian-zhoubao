年初在福州的这场全国聚会里，我完成了生财第一次线下主题分享，也是我个人第一次对着两百人讲。

当时定的题目是《躬身入局，把手弄脏》。

挑这个主题是因为我觉得这是创业路上最关键却最容易被轻视的心法。顺带一提，2024年我还做过一件印着“把手弄脏”的T恤，正好呼应。

到场的朋友背景跨度很大，行业、所处阶段、人生状态都很不一样。所以我没有列清单，而是用三段经历来说明我的想法，让每个人都能在故事里找到自己的映射。

# 1. 冲向南极点的较量

第一个故事讲的是上世纪初最后的伟大航海。南极点是当时唯一无人踏足的空白。历史只记住第一名，哥伦布、阿姆斯特朗都成了符号，第二名几乎无人提及。北极、其他大陆早已被占领，南极点成了探险家们最后的荣誉高地。

![](img/d9ab7d296bc0238836485f1834199e6a.png)

图中标注的就是目标点，路线要从南部的罗斯海 Ross Sea 切入，全程约两千二百公里。

这两拨人马的领队都久经沙场。挪威来的阿蒙森，和代表大英帝国的斯科特，各有成名履历。

![](img/97764f34d4649b321229533e30a63d59.png)

阿蒙森带了五个人。斯科特这边是英国上校，行头精致气势足，队伍有四十人。斯科特更早起航，1910年11月25日自新西兰出发，比阿蒙森早了两个月。

凭直觉，你会押注谁？

结果是阿蒙森先抵达。但这并非以少胜多的童话。

熬过五个月的南极冬眠后，双方几乎同时动身。阿蒙森五人组1911年10月19日出发，12月14日登顶。1912年1月25日，一个月后就安全撤回大本营。斯科特先出发二十人，路上减到十人，再减到五人，直到阿蒙森登顶后一个月才抵达。

![](img/7e753d114db3dfe2a1ccc5304504722e.png)

这已不是输赢，是生死。斯科特晚到让返程撞上致命暴风雪，被迫露营。饥饿、冻伤、精疲力竭，队员接连倒下。最后斯科特三人倒在距补给点仅十七公里的地方。

十七公里放到今天也就是二十分钟车程，可当时已无人能再挪动。斯科特有写日志的习惯，他最后一笔写道：“请把这本日志交给我的妻子！”随后划掉妻子二字，改写成“遗孀”。就此终结。

那个年代创业真的可能是生死问题。复盘，为什么阿蒙森能赢？

![](img/5fe71289ee3821aa4994f93000b7c091.png)

看几个细节。

补给，阿蒙森准备了三吨食物，五个人。斯科特只带了一吨。缺粮直接导致全队饿死，一吨压根没算路上的不确定性。

行进，阿蒙森用狗拉雪橇，狗靠舌头散热耐寒。斯科特用矮脚马，马靠体表散热，一出汗就易冻死。去程马匹死光，后来只能人拉，消耗巨大。

目标，阿蒙森只有一个，拿下南极点首登。斯科特目标繁多，要登顶，还要采岩石做科研，还要带回帝企鹅蛋。发散就失焦。

![](img/d74e921dd3169083d094763ec4b8945c.png)

![](img/bb4f6dfc26583d128d28854d5ddccf06.png)

![](img/f02bb7bde19aa731220aecbc80c9912c.png)

执行，阿蒙森定下铁规：每天前进三十公里，风雨无阻。斯科特则看天气，天气好一天走六七十公里，天气差就扎营。计划随时改。最后冲刺南纬八十七度时，他临时把四人小组扩成五人，物资却仍按四人准备。

![](img/92d7daa0c9ff6ed54abc7264853dc765.png)

阿蒙森在出发三年前日志里写：我们将在一月二十五日返回基地。三年后，他真的在1912年一月二十五日回到了基地。

这种对计划的推演、对细节的敬畏、对执行的刚性，是胜负的关键。

这和我们做业务、做航海、做创业一模一样。市场波动、竞争格局、运气好坏，就像南极暴风雪，所有人都在里面。

最容易的就是怪环境、怪天气。可天气一样糟，为什么有人杀出来？

你是要把命运交给天气，抱怨着停下，还是夺回主动权，每天走三十公里，雷打不动地往前？

![](img/a65137c8a856081e4bc1f53eb9b013eb.png)

# 2. 生财内部的新业务战役

第二个故事是生财内部的真实复盘，也算满足大家对团队的好奇。

上个月我一直在加班，我们在推进一个新业务，是生财今年的战略方向：往垂直、往深度交付走。

用户在航海后给了很多正反馈，期待在某个垂直赛道做深做透。教练团队也希望能和用户建立更长期的深度服务关系。于是我们在十二月航海结束后，启动了从零到一的新产品探索。

从零到一的核心是找PMF，产品市场是否匹配。

做了几轮测试，从定位到商业模式，从产品设计到服务设计，从合作方案到卖点提炼，方方面面都在试错。这个过程就不展开了。

![](img/f3139eec9ebaba691d0d9bf5ad6d11e5.png)

关键转折在一个周末的晚上。一轮小范围售卖测试刚结束，又没达标。过去半个月一轮轮不达预期，团队士气低落，甚至有人想放弃。有人觉得假设可能就不成立，有人想等过年后再说。

问题抛给了我，怎么办？

![](img/3929ca39150bcec3007a426beb6bf904.png)

我当时意识到这是分水岭。团队退缩，这事就死了；团队前进，这事才有机会。那句肌肉记忆冒出来：不能犹豫，犹豫就会败北。我直接说：现在不做，过完年一个月后也不会做，以后更不会做。拖一周就是无数个犹豫的开始，团队会彻底停摆。

大家想想自己的项目，是不是很多事卡在犹豫里，几个月一点进展都没有？

![](img/c90e573984f624973aaadf9abc87f3e2.png)

作为一号位，这个时候要做的不是喊口号，而是给团队定心丸。我说方向没问题，我有九成把握能做出结果。然后当天晚上就定了行动方案，立刻落地。

![](img/1c53e794950389145cfa92279f09aece.png)

一句话：趴地上把脉。我们又复盘了全流程，倒回去看用户聊天记录，看哪里出问题。然后我开始密集沟通，和执行同事、和亦仁、和教练、和用户，一条条对齐。

![](img/78717361b997bf6fb4bc079da4b4cef0.png)

![](img/c28908eed1dda16ac44dd2eede3721f9.png)

![](img/4a3cd769914fd407899238c77fe7686b.png)

![](img/45ddfc892991a62e2084062dec4f1847.png)

![](img/715ded33b4dd67cae899e2159ef4901d.png)

我自己下场干鱼丸。白天工作，晚上十八、十九点开始和用户一对一聊，到二十三、二十四点。拆解用户预期，做假设、做验证，一步步推进。

在福州见面会期间，还碰到了当时聊过的圈友华仔，晚上一起喝酒交流。

后来我才摸到关键假设，调整了产品定位。到了下一个周四，我们达成了PMF，现在进入交付期，用户反馈不错，验证了方向是对的。

![](img/734f131d1d821d95738f27c613e30eab.png)

![](img/3cb732bddfaebf9eba7ca7a4408b9760.png)

![](img/f513ddae6996228025cd24300ab7a084.png)

![](img/769b654d127a7ad72df07312f9ac46a4.png)

![](img/fccf323ab9792377e223f2de0beeef21.png)

我想说的是，项目是干出来的。战略只能大致对，战术必须在过程中不断校准，战略本身也可能被迭代。更重要的是要有勇气，在看不见的时候相信大方向，在迷茫时果断前行。

说创始人模式，我理解的就是没退路。作为第一责任人，公司垮了，自己的信誉和投入都搭进去。你能不能进入那种必死的决心去做，结局会完全不同。

# 3. 关于选择的勇气

![](img/7b6839d2f3104bb04b74217ffaae4b4c.png)

假如你有两位选择：一个是你关注多年的大V，现在给你一个全职合作的机会；一个是你已经在做的副业，已经有一定起色。你会怎么选？

![](img/04aeca85ae270b80859b37936bcf9fae.png)

大多数人会选择副业兼职，等财经圈站稳脚跟再全职。这很理性，能降低风险。

但故事主人公保彪做了相反的选择。他当时有自己创业的业务在跑，直接把业务切掉退出，然后搬到这位大V的城市，给他当了二到三年的助理。后来他成为了一名全网知名的财经博主，两百万粉丝，年收入远超当年创业利润。

分享这个故事，不是为了炫耀选择，而是讲勇气。他当时做的业务是助贷服务，帮外地炒房客加杠杆。2019年楼市还在涨，但这明显是信息差资源差的生意，活不过周期。而做IP、做博主，天花板更高。

这意味着战略要彻底重来，放下到手的现金流，跳进陌生但更有潜力的赛道，还可能失败。

靠算账算不清，这是大账，只能判断大方向大致正确。支撑他的，是敢于All in 的勇气。

当然中间也有挫折，分开过几次大的波折。但就算当时选择继续创业，他的人生大概率也一样会成功。珍贵的是那种敢取舍、敢放弃、敢从零到一的魄力。

勇气始终在，方向对错是事后才知道的。

# 4. 南极的故事还没讲完

最后回到南极。

![](img/1fd0be7dea1849c37dbd7c914f5af9bd.png)

斯科特不是第一次失败。十年前他就去过一次，因食物准备不足得败血症被迫放弃。那一次的致命伤，他又在第二次犯了。

我们是不是也被同样的习惯反复绊倒？

![](img/cb08152cb16bdb7b7241b06a8783abb3.png)

出发前十个月，两队都在南极设补给点，最远三百八十公里。这相当于现在的MVP预演。阿蒙森很顺利，斯科特问题不断：人员安排不合理又累又慢，路上冻死不少马，还让狗咬马。最后出发时他依然带了马。

还一个关键点，他的最后一次冲刺点位没按计划设，往前少了七十多公里。结合最后倒在补给点十七公里外，如果按计划布点，他可能就不会死。

![](img/a380a7281f9d9d198bad64a17e5a9ab9.png)

问题出现时，我们其实有无数次修正的机会。日常做业务，信号早已反复出现：你视而不见了吗？有没趴地上看清问题？有没识别到真正的关键点？

斯科特作为一号位，没把这些问题解决，才导致全军覆没。

![](img/9c668853001f0d4a6f031b424d428ae0.png)

还有个人要提：沙克尔顿。

他在南极点冒险前，是当时最懂南极的人。发现了罗斯海、罗斯冰架，证明是大陆。不能直达南极点，回国后被授予上尉军衔，高于斯科特。他曾请求加入斯科特的队伍，分享失败教训。

斯科特拒绝了，甚至不想见到这位前下属。

如果当时沙克尔顿在队里，或者两人谈一次，英国队可能不会死，也可能赢得南极点。

这告诉我们，开放、谦虚、降低ego，多重要。向对手学习都行。

![](img/87ddfc7e8f653c1212ae8d8f25c961d8.png)

也是我们的价值观：利他、真诚、开放。发声比闷声赚钱走得更远。因为你发声，会被同频的人看见。好机会天然是二八定律，强者更强。我们能做的就是被对的人看见，获得合作。

![](img/e4f86411e5250708380775218adecc02.png)

最后问自己：你真的行动了吗？你把每个环节摸透了吗？你听人说的就信了吗？你有没有亲手把业务搞清楚？

别让别人糊弄你，也别自己糊弄自己。

祝大家躬身入局，把手弄脏，2025一起生财有术！
