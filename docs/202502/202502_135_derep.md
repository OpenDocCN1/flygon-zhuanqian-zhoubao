# 做对的事，然后把事做对
作者：龙哥

很多时候，我们卡住的不是能力，而是方向。

段永平在和网友的交流里点破了一件很关键的事：首要的功夫，是挑对一件事来做。方向一旦跑偏，再怎么努力堆砌执行力，付出的成本只会越来越高。而一旦发现自己走错了，最理智的选择不是硬撑、不承认，也不是沉溺于“早知道当初…”的回溯，而是立刻调整。

他说，这可能是需要付出代价，但这个代价，往往是所有代价里最小的。

评论区里有人做了很好的延伸：别把时间浪费在为过去的选择后悔上。人生就是一系列连续的选择，错了就改，是把损失止损在萌芽状态的能力。纠结只会放大代价，行动才能把代价压到最低。

做对的事情，然后把事情做对。两件事，一件比一件重要，但都绕不开一个核心：发现错误时，敢于及时止损、果断转向。
