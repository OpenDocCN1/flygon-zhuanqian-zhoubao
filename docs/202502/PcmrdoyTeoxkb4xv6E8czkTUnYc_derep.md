# 一、从0到第一单的起步

我在杭州，今年春节选择留在本地。闲下来刷📕，发现一大波人要回老家过年，猫咪没法带走，纷纷在找人上门照料。灵机一动，这个需求正好能做。

我属于比较佛系的那种，没大张旗鼓地去冲量，所以接到的单子不多，但整个闭环我已经摸清楚了。以后逢年过节不想出门，想赚点外快的小伙伴可以直接照着做。

这项活儿基本只在法定节假日吃香，平时几乎没人找。看起来我忙了10天，实际上真正上门的时间每天也就三小时左右，赚的钱如下：

# 三、为什么春节能做

过年前的半个月左右，我就在星球里看到大量春节上门喂养的求助帖。查🛰️指数也能看到，临近春节搜索量飙升，需求是断崖式上涨。回溯数据大概从1月23号开始爬升，1月26、27号达到高峰，因为1月28号就是除夕了。

# 四、怎么找客户

我主要用📕，抖音思路一样，只是我没同步开。先说📕的玩法。

### 1、个人主页要一眼看懂

#### 昵称
直接改成“XX喵 可预约春节上门喂养”，一看就知道在做什么。

#### 个人简介
一定要写清楚服务范围，比如方圆几公里可接单。因为上门喂猫距离是关键因素，越近成交越容易。我只接3公里以内的，远的直接放弃。

#### 头像
放一张可爱猫咪照，目的性更强。

![](img/9647613aa16663ae19d085739a73f238.png)

### 2、用笔记把客户吸引过来

主页内容要分三类：服务介绍、成交证明、服务过程展示。

服务介绍类：写明你负责哪个地铁站周边，覆盖范围多少公里，收费标准，包含哪些服务。

成交证明类：放成交的聊天截图，头像可以打码或用小号模拟。

服务过程类：把客户发来的喂养记录截图借鉴一下，改写后发出来就行。

![](img/751905ec419a34b4ef6f7457cfffa824.png)

![](img/a404ecd88206dd24621ae46eb7653090.png)

![](img/a57def309a5b2910aafe0d792f46b051.png)

我参考了杭州同行的报价，3公里内单只猫30元/次居多。为了快速拿单，我也定30元。也有客户主动出价50元/次，还要求每天看一次。大部分客户习惯隔一天上门一次，也就是48小时一次。

超过两天一次的单子建议别接，卫生很难搞定。

### 3、主动去截单

频繁刷相关话题后，首页会不断冒出刚发的求助帖。发布时间越新，抢单胜率越高。私信时要突出两个点：我离你家近，且自己长期养猫有经验，出现异常能立刻处理。

# 五、从私信到收款的转化

有意向的要立刻拉到🛰️，别犹豫，拖一分钟就可能被别人抢走。🛰️里提前一周就要做人设铺垫。

朋友圈内容就三类：自己养的猫的日常照片视频、个人生活展示、过往喂养的成交截图。

这三类内容单独建一个标签组，只对新加的潜在客户可见。这样他们从📕过来，再看朋友圈，信任度直接拉满，定金就好收了。

最核心的一条：必须先收定金。别信什么“到了再结”“一会儿转你”。没给定金的，基本都是空谈。

定金话术直接用我图里的模版，记得收款后补充一句：定金一旦支付不退。

收完定金后立刻收集客户的上门信息，表格模板我放在后面了。

# 六、客户信息的管理

接单后要立刻分类排期。按一天8小时算，3公里内的单子包含路程平均要30-40分钟，一天最多排12到13家，再多服务质量会崩。

我用飞书和时光序来管理客户，信息一目了然。时光序还能标记已完成，还能按路线排序。

# 七、上门现场的细节

钥匙最容易乱。我是给每个客户的钥匙单独装进透明一次性自封袋，上面写小区名。开门后第一件事就是把钥匙放进自己包里，绝对不能落在客户家，不然就麻烦了。
