# 把 DeepSeek 接上自己的题库，它就能变成专属的试卷定制师



## 24 赞 把 DeepSeek 配上本地知识库，让它成为你的私人出题助手

作者：宁十七
日期：2025-02-13

对一线老师而言，组卷往往是最耗时的环节之一。聊过几位教龄不同的老师朋友，他们的说法惊人一致：一套完整的试卷，从选题到排版，通常要好几位老师协同作战，耗时好几天。

我最近在尝试用 DeepSeek 来解决这个痛点，下面把我摸索出来的思路整理出来，供大家借鉴。

结合本地知识库使用时，DeepSeek 在出题上的角色大概可以拆成两种打法。

一种是做“组卷高手”。把过去积累的历年试卷、练习册、校内测验等资料导入本地库，让 DeepSeek 在海量现有题目里按知识点覆盖、难度梯度、题型分布等要求进行智能筛选和重组，快速拼出一份全新结构的试卷。

另一种是做“出题大师”。直接给它知识点清单、教学大纲和出题规范，让它基于本地知识库里的教学资料进行学习和理解，然后原创生成符合教学要求的题目，实现从零到一的命题。

DeepSeek 配合本地知识库的用法远不止出题这一个场景，具体怎么落地，可以结合自己的教学场景和工作流程去延展应用。
