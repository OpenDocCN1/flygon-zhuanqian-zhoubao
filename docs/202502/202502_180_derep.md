# 📕上现在很火的「AI 宠物肖像」到底有多香？



## 精选笔记 · 80赞 📕最近刮起AI宠物画像的风

作者：瓜斯
发布于：2025-01-22

最近在📕刷到一个很有意思的现象，AI宠物肖像突然爆火了。一批专门做这类内容的账号应运而生，用很有趣的AI宠物写真引流，把用户拉到私域变现，单张宠物定制照定价大概在60元左右。靠着这种新颖的内容形式，既冲出流量也涨了不少粉丝。

这波热度并不是国内独有。放到海外电商平台上看，Etsy 上也有不少在售卖AI宠物艺术照的店铺，订单量看着非常可观。
