# ('关于读书群里的广告以及管理', (2, 15))

建群容易守群难。尤其是像我这号，手里攥着一百八十多个群的人，"防广告"三个字几乎天天挂在嘴边。你稍微松懈一下，各种垃圾信息就能把群搅得天翻地覆。

先说句实话：任何规矩，背后都是一笔账。一边是执行力、时间成本，一边是最终的防控效果。大家都爱讲"既不放过一个坏人，也不冤枉一个好人"，这话听着漂亮，但现实根本做不到。你想少冤枉人，那就得容忍漏网之鱼；你想把坏人全堵死，误伤好人就成了大概率事件。两头兼顾？不存在的。

就拿我这群来说，估计是被广告党盯上了，自动进群阶段就有不少人混进来丢广告。有人建议我搞进群审核，道理上是说得通，但你想过没有：我凭什么判断一个素未谋面的人今天是来读书还是来发广告的？这活儿根本没法干，成本高得离谱，纯属纸上谈兵。

所以我定了一个简单粗暴的原则：只要发广告，直接拉黑，这辈子别想再进我任何一个群。与此同时，系统里还挂了个自动踢人的机制，只要踩中某些关键词，机器就动手。这个办法确实可能误伤几个无辜的，但误伤概率很低，我实在没法二十四小时盯着群聊，顾不了那么多了。

还有个雷区：往群里甩自己自媒体链接的，一律踢。你别跟我说"我只是分享，不算广告"——咱都是干这行的，就没必要揣着明白装糊涂了吧？你把自己公众号、视频号往群里一扔，图的是什么？不就是那点赞和关注吗。真想分享，也容易，把想说的话敲成文字直接发群里，别带链接，我这关就算过了。

至于我为什么能踢得这么理直气壮？道理很简单：群是我私人维护的地盘，规则我定，无需解释。

另外还有几个我忍不了的情形。第一，名字改成广告口号的，已经踩到我忍耐的底线了。第二，用企业微信进群的，系统自动踢。加我好友也同理，我会删掉。商业上的事，大大方方聊不好吗？企业微信看不了我朋友圈，我发了宣传你也看不到，那你还呆在我这儿干啥？互相耽误。

我不避讳说，做私域、做读书群，背后有营销的念头在。可我也实打实给了大家价值。打个比方，桃树想靠猴子把种子带去远方，它拿什么当报酬？一颗肥美多汁的桃肉。咱俩未必是朋友，但利益交换、各取所需，这不丢人。做商业的，这点认知应该都有吧。

有人被拉黑了还想求情进来，我只回一句：不行。拉黑的意思，就是永不再接收；不然我警告一下不就完了？何必拉黑呢。

还有一类不太一样的广告——重病募捐。说实话，我也信很多病例是真的，但我照样踢。原因很简单，读书群不是筹款平台。人家做筹款有自己的渠道和阵地，我的群，不该天天飘着这些消息。

最后说一种更离谱的：一边在网上骂我，一边还偷偷蹲我群里的人。谢谢您嘞，您脸皮厚，可我气量小，就别怪我不讲情面了——一律拉黑，江湖不见。
