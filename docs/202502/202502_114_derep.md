# 东北旅游两个月，成交 20 多单，我的转化经验分享
作者：龙哥

两个月在东北旅游赛道拿下20多单，我这个零基础新手是怎么做到的？

先简单介绍一下自己：我是龙哥，一名00后教培老师。2024年4月加入赚钱，从零起步做境外游。到目前为止，7个月累计成交40多单，总流水80W+，转化率稳定在10%以上。

最近两个月，我把精力转向了东北旅游。这个项目的最大感受就是：模式不复杂，成交链路很短。顺利的话，两三个小时就能敲定一单；即便慢一些，两三天内也能完成转化。

为什么这个赛道对新手这么友好？我复盘了三个原因：

第一，客单价不高。东北旅游的普遍费用在2000到3000元，用户的决策压力小，下单更果断。

第二，决策周期短。因为是国内游，大家通常只在出发前1到2周才开始看团，目标明确，犹豫期很短。

第三，利润空间可观。每单的利润从200到1800元不等，虽然单笔不算暴利，但胜在跑量快。

对于刚入行、没什么资源的新手来说，这种“轻模式”特别适合用来练手、积累信心和实战经验。我的经验是：先跑通流程，再逐步优化流量和转化，每一步都能看到实实在在的成长。
