# 【项目实操全流程sop】TikTok短视频带货项目经验分享

我是阿瑞，大学期间就折腾过两回创业。大二时在学校卖电影票，组了个15人的小团队，每天下课后印传单，跑宿舍楼、蹲食堂门口给公众号拉人。被同学冷眼、被拒之门外、被主任训话都是常事。好在那会儿没放弃，后来再没跟家里要过生活费，原来每个月也就花2000多。最惨的是冬天进了批滑雪票，结果赶上疫情封校，学生根本出不了宿舍，票全砸手里，亏了3万多。

大三转做App拉新，本质上就是让同学下载App并完成大学生认证。比如京东一单给18元，我给代理分15元，自己只拿3元。得益于大二攒下的学生资源，中行、滴滴这类推广也接了不少。那阵子确实赚钱，虽然没细算，但一个月生活费能花到5000多，每周跟朋友聚餐基本我请客，边上学边赚钱，大学过得挺滋润。

毕业后我直接杀进电商，一干就是三年。2023年写过一篇精华帖，讲小红书起号开店出单全流程，还有半个月无人直播做到15万的SOP。只要认真看完并去执行的人，基本都赚到了。23、24年正好是小红书变现元年，我也跟着捞了一波快钱。

# 为什么后来盯上了TikTok

我完整经历过小红书的变现周期：早期从抖音搬视频就能出单，后来变成混剪，再后来实拍、无人直播、半无人直播，直到真人直播，整个红利期基本走了一遍，收获确实不少。

当时小红书流量非常猛，一个号一天发30条搬运视频，剪都不用剪，轻轻松松就能出单，最高一天卖到4至5万。后来搬运被判违规，只好转混剪。小红书上70%是女性用户，消费力排序是女人>小孩>老人>狗>男人，只要抓住女性需求就有得做。

我那时还带过一个二十多人的团队，可项目利润太诱人，员工一学会就离职单飞，根本留不住人。

再后来试过真人实拍，但没跑通，视频播放量只有几百，不出单，硬撑了两个月，快发不出工资时，无人直播来了。最长一次连播300个小时，电脑一直开着，烫到不敢摸。单场最高能卖几十万。但女装退货率太高，基本超过50%，加上自己囤货，家里压了几百件衣服，但最终账上还是赚了一些。

从半无人直播到最终只剩真人直播，我知道小红书这边该收手了。

![](img/b7f69dd08f93c3af9d5d0f59c81fff21.png)

我这人一向爱踩风口，很认雷军那句“站在风口上，猪都能飞起来”。所以一直在找新机会，现在找到了：跨境电商。

国内电商卷到什么程度？卖1万退8000，仅退款、同行恶意竞争、低价打到亏本。我只看利润，GMV再高也没意义。抖音千川把投放卡得很死，想让你赚多少就多少，永远在赚钱、保本、亏钱边缘试探。淘宝天猫这类货架电商，没供应链和资金根本别碰；拼多多更是“仅退款”重灾区。国内实在透不过气，只能看向海外。

而TikTok目前不需要营业执照，个人账号就能做，不用囤货、发货、售后，会剪视频就行。

# 一、项目战绩

以泰国站为例：单账号单月卖出13万单，总GMV 98万，佣金7.9万，折合人民币约16000元。当时我做了大约10个号，跑通7个，平均佣金3000到5000元。

![](img/7d7824f1c24de2d2166026577721f829.png)
![](img/a994266eed5811b7e542853fd385e684.png)

整个过程并不顺，大概花了1个月才跑通，感觉自己把能踩的坑全踩了一遍。

第一坑是网络。经常卡顿，用着用着直接断网。我试过市面上很多方案，最后确认必须科学上网，普通网络根本不行，光这一项就亏了差不多3000块。

第二坑是账号。注册完发现不能挂车，接着又碰到零播放、个位数播放。剪一个视频花一个小时，发出去却没有播放，太折磨人。

第三坑是视频判抄袭。我很用心剪了一条，结果提示原创度不够，涉嫌抄袭，直接扣24分，账号被封。

就在快放弃时，无意发的一条视频居然出单了。当时特别兴奋，连夜剪视频、往多个账号发，观察播放变化。慢慢试下来，单账号做到日均百单，而且很稳定。10个号成功率约70%，每个号每天发3条视频，剪一条大约30分钟。

# 二、新手从哪个国家开始

做TikTok首先要选市场。目前能做的国家不多，我习惯分成三类：东南亚、欧洲（主要是英国和西班牙）、美国。如果换你来选，会选哪？

我实操过的国家有泰国、越南、菲律宾、马来西亚、英国和美国。

先说马来西亚，我一开始以为是发展中国家，结果人家是发达国家，汇率约为中国的1.2倍。那边商品种类少，但利润高，选品却很难。我在国内精挑细选的商品，想上精选联盟，结果根本没有。马来西亚女性普遍戴头巾，所以选品得先看当地人文环境。基本上每个国家我都出过单。

美国市场门槛高，账号价格贵，粉丝至少5000，还不能机刷，必须纯自然流，一个账号就要1200到1500元，这成本让我也有点吃不消。但好处是美国人有钱，国内做的人少，一单利润能到30元人民币。资金够的话，美区值得试。

英国利润高，汇率是中国的十倍，但容易封号。我在英国被封了几个号，好在能提现，但要等3个月。英国政策要求原创实拍，混剪不行；网络要求也严，一旦发现位置错或网络错，直接封号。想玩英国得谨慎。

菲律宾和越南就不太理想，出单难。这些国家人口少，网购习惯弱，除主要城市外交通差，快递根本送不到，自然难做。

综合来看，泰国最适合新手。人文环境跟中国很像，身边朋友旅游都爱去泰国。交通在东南亚算发达，人口多、流量大，我最高一条视频做到了160万播放。

# 三、TikTok需要准备什么

硬件方面，先备上1到3台苹果手机，再通过电脑装爱思助手。别管你怎么折腾网络，TikTok官方都能精准判断设备和网络在中国，想风控你太简单了。所以干净手机环境永远第一。

安卓机倒不是不行，但华为、荣耀用起来很别扭。正经做跨境的都选苹果，iPhone 8以上就能跑，预算够直接上iPhone 11。

# 六、如何配置海外Apple ID

第一点：非常重要，严格按步骤操作，否则ID容易被盗。千万选独立ID，别碰共享ID。我自己就吃过亏，一开始用共享ID，导致账号零播放。共享ID等于共享位置，你网络没问题，可同一个ID的人不一定在目标国家，很容易违规。

第二点：修改海外ID防止被盗。具体步骤：用浏览器打开苹果官网 https://appleid.apple.com ，手机和电脑操作类似。登录你的Apple ID，输入密保信息完成验证。

# 九、TikTok如何养号

先优化个人资料。用户名好记、有辨识度，头像清晰有吸引力；简介写清内容定位，简洁吸睛；头像、简介、昵称都要好好弄，让别人快速知道你是谁、有什么资源、卖什么货。比如突出“源头工厂厂家”“自有货源”，也可以加点个人标签：“爱喝奶茶”“爱逛街”“自用好物分享”。

![](img/bbc0b0aa22c10aa5ce0c65c93ad5ea3a.png)

然后定内容定位。选自己感兴趣、能长期做的领域，比如美食、旅行、健身、教育，持续输出才能养出稳定粉丝。创作风格要统一，视频风格、剪辑、配乐尽量一致，增强辨识度。

当天还要刷15到30分钟视频，顺便找想推广的商品。文案用百度翻译或有道翻译成当地语言，千万别直接放中文。记住，你现在要以“外国人”的身份模拟当地环境。

![](img/c315ace1a8a2e229b4728dad54fe1034.png)
![](img/a4704e5f3c682592afa4d17453866068.png)

不同网址显示的语言不一样，多试几个。别一注册就发视频，养两天号再发。

最后是成人大脸验证。养号完毕必须做，否则发视频没流量。这个一定要严格按步骤来。我自己就踩过坑：网络不稳时去验证，结果失败，整个号废了，不能挂车。所以验证前确保网络稳定。另外找年纪大一点的，比如叔叔爷爷来配合，成功率更高。

# 十、TikTok如何选品

方法一：第三方选品工具FastMoss，会员费800元一个月。

![](img/23826d1db9e5c8887b72ce28616be30e.png)
![](img/c04d665e930887cdb7f9fb3c1c3aff8e.png)

随便点开一个商品，先看销量趋势，直线上升的值得跟品。再看流量来源，是商品卡流量还是短视频流量，据此决定推广方式。还要看这个品是自营账号发的，还是达人带货。

方法二：站内选品。刷视频，把自己的号刷成带货号的样子，看同行在卖什么，然后跟卖同款。点进链接看销量，低于3000的不要选，同时看近期评价。
