# 用扣子把 DeepSeek 接到自己的豆包里：零成本尝鲜与高频稳定两套打法
作者：龙哥

最近 DeepSeek 的对话质量很受好评，可是一旦并发上来就容易卡在“服务繁忙”。为了抢到可用时段，我甚至试过凌晨去挤。

我也折腾过本地蒸馏的 7B 模型，也接入过硅基流动的 API，体感都不太顺手。后来发现通过扣子平台做一层中转，既能把免费额度用起来，也能把官方赠送的 Token 接到工作流里，体验会稳定很多。

目前能跑通的两条路线：

- 日常轻度路线：扣子自带的免费配额，每天大约 50 次对话额度；
- 高频重度路线：借助火山引擎的推理资源，新账号通常会有 50 万 Token 的启动赠送，对应的是完整 671B 参数的完整体。

下面把两条路线的落地步骤拆开讲。

![](img/89d621377d750c43f912ebe46557235c.png)

## 路线一：零成本尝鲜

适合偶尔提问、找灵感、查资料的场景。

### 入口与建模

打开官网 coze.cn 完成登录。进入工作台后点右上角的加号。

![](img/4f8f3f39b47203c07c252fe6179263fd.png)

在弹出的面板里点“新建智能体”。

![](img/be73c9d1cc5dc56456becc69fec75797.png)

建模页面只用填个名字，方便自己辨认即可。

![](img/4da842fffa9673697d6c198dd4f3449e.png)

模型选择区先点开“豆包工具调用”，再在下拉里挑 DeepSeek-R1。

![](img/3fce80a1c286580a44874daee6b3756e.png)

配置完成后点右上角的发布进入审核页。

![](img/8cc01ea7d95e881c7358625ca7f6c2b1.png)

在发布页切换到豆包渠道，点击右侧的授权。

![](img/1b752fb29c50221337d7683a31a5d532.png)

在弹出的授权页登录后确认同意。

![](img/f00ebff58c2c58c9a050432fa0ed9103.png)

回到发布页，确认豆包的勾选框已打上，再次点击右上角的发布。

![](img/3edb862012f1cffe7070e94264739d07.png)

发布成功后打开手机或电脑端的豆包，就能看到刚建好的智能体入口。

![](img/eab635adc9d2f8358daddd520cdfc353.png)

这样一条每天 50 次的免费用法就通了。

![](img/9c63084894f485360c548944c3d10a7d.png)

## 路线二：基于 Token 的高强度用法

当提问量变大、需要长文本或连网检索时，建议走这条。

现在豆包侧对 DeepSeek 有活动，新用户可领 50 万 Token，够跑一阵子，且是与官网一致的完整版本。

### 火山引擎侧准备

先把扣子升级为专业账号，这是后续调度的前提。

![](img/faba4edf9b44bdbd18879d4ca82172e6.png)

![](img/bd365fa5ff1819ce6baf4c1dfd50f26f.png)

![](img/b1d1eacc6f48cd89f3a6eb450647c31f.png)

升级后界面会变成专业版样式。接着通过扣子页面左侧的链接进入火山引擎。

在引擎后台左下角进入开通管理。

![](img/b33cfb4c02a40f0efbcbc6e0db7f7298.png)

在服务列表里找到 DeepSeek-R1，点击开通。

![](img/94f2dc74b9935b49b2549d7e756b86ef.png)

确认模型名为 DeepSeek-R1 后点立即开通。

![](img/4297954f3b2e260ca2a2c5579245037a.png)

开通后回到引擎首页，左侧菜单选择在线推理。

![](img/1d8bd19e3a21ea3ebb777e01493c7d63.png)

在接入表单里填一个好记的接入名，点击下面的选择模型。

![](img/4208155386e0da72e02e55fe9674819b.png)

模型列表里确认 DeepSeek-R1 后点确定。

![](img/a7b88f068768e8090ef8275ba9b5d6e5.png)

最后点确认接入完成引擎侧配置。

![](img/2f20193e72b2ad3e35cd1f5cc1ae4a30.png)

### 扣子里建工作流

回到扣子，准备做一个带搜索的对话流。

![](img/264f10b0502730182e152c2d965c9f3c.png)

![](img/e8889c3a8f478ed40438f83564e8aa3d.png)

在工作流区域点右上角的加号，新建一个对话流。名字只能用英文，自己好记即可。

![](img/1fdc622e1e190c13b28704bf0a97e455.png)

![](img/006d4aa41c524b65423858f775c64dc1.png)

![](img/d15d574cd1d028ccb3ea8235d2759c1c.png)

工作流里需要三块：

- 一个大模型做关键词抽取；
- 一个插件做检索，这里用 BingWebSearch；
- 再一个大模型做最终生成。

![](img/908b0fc32f15103bf907f41b6b037321.png)

![](img/1f54550c5f63abf31385c908e50c05e9.png)

![](img/c56267f2f548527f189f602ecd5a3bd8.png)

![](img/479cd4297fecfa42dc8730c1dd91fd44.png)

把三块按顺序连起来。

![](img/cfcb76bed62200bec9fd8f7aa8c56f6f.png)

### 第一个大模型：抽关键词

点开第一个模型节点。

右侧模型可随便挑，豆包 Lite 就行。

输入参数里把来源设为 USER_INPUT，变量名填 input。

系统说明填：你是一个专业的关键词提炼专家

用户说明填：把用户输入的 {{input}} 提炼成适合检索的关键词

![](img/0412963f11681dd48add9dc7d625baea.png)

### 检索节点

点开 BingWebSearch，在输入处接上前一个模型的 output。

![](img/c1e7faa1ef0dd8c467bf992743c75ab3.png)

### 第二个大模型：生成答案

点开第二个模型节点，在模型选择里挑刚才在火山引擎创建的接入模型。

![](img/465a6bcfdbc5935124dddeaa6f7a2764.png)

在参数设置里添加两条输入：

第一条来源选 BingWebSearch，字段取 webPages；

第二条来源选起始节点，变量 USER_INPUT，字段名叫 pages。

![](img/433cea72c9bfa6cc98d7fdc8568fe2b1.png)

![](img/5a150ace5baf6371c33380c77e6ede94.png)

```
复制下方的提示词到你的大模型2的用户提示词中。
## 用户问题
{{USER_INPUT}}

## 搜索结果
{{webPages}}

## 开始分析
深度思考用户的问题，给出思考和答案

```

整体连线效果要与示例图一致。

![](img/c5c7ba751da191711684ff4c1f3ef070.png)

在结束节点选择第二个模型的 output，回答内容写 {{output}}。

![](img/3f3b9876be7531f7e3f00b634de73b31.png)

配完后点试运行验证。

![](img/fc14ea7ebed5d9618ca210f16df2aa22.png)

![](img/18bd0dfe87d0bffd11c02371998f228c.png)

验证通过就点右上角发布。

![](img/7d9471b3c98bf9a2d3c1102944281064.png)

### 接回豆包智能体

发布后会回到智能体页面。若没自动跳转就手动打开扣子重新进入智能体。

点添加工作流，把刚建好的流程挂上。

![](img/409e6b27c594b6ddb7b13d633148e4b7.png)

![](img/8da8cfa0062fd5a90553a012eded0ec1.png)

进入左侧的人设与回复逻辑，粘贴如下指令：

无论用户输入任何内容，立刻调用工作流 ds_user

注意 ds_user 要换成你自己的工作流英文名。

![](img/c6250073a3ec35899891504d1deaaa41.png)

自测无误后点击右上角发布，发布时只保留豆包渠道，方便移动端使用。

![](img/a016c3efe3ffc0724d673f6ef98ed476.png)

审核通过后即可在手机豆包和电脑豆包使用。Token 消耗较快时记得及时续费。

希望 DeepSeek 尽快改善高峰期的承载能力，让大家都能顺畅使用。
