# YC 的 AI 创业创意

创业圈又迎来一枚重磅信号弹——知名孵化器YC刚刚在官方推特上抛出了2025年春季的“创业者召唤令”。没错，就是那个传说中的 Requests for Startups，如果说投资圈也有“风向标”，那这份清单绝对算得上其中一个。它不是什么泛泛而谈的行业预测，而是一份实打实的“邀请函”：欢迎各路创业者直奔这些方向，去啃硬骨头、做突破。

今天这篇整理，就是想把YC这份春季招募的核心信息给大伙儿划个重点。它不是为了罗列项目，而是想告诉你，哪些赛道正被顶级加速器盯着，正等着敢想敢干的人去拆解、去重塑。如果你恰好站在创业的岔路口，或者正在琢磨下一个切入点，那这些方向值得你花几分钟仔细品品。

机会从来都是给有准备的人，而YC的这份清单，或许就是你启程前最好的地图。不妨顺着它的思路，想想自己的答案。
