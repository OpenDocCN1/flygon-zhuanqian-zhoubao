# 高效备餐指南：周末一次备好一周三餐，告别外卖焦虑
作者：龙哥

大家好，我是龙哥，一个纯粹因为兴趣而沉迷研究学习方法的人。老话说“人是铁饭是钢”，但真忙起来，别说按时吃饭，能想起来吃饭就不错了。外卖越点越多，三餐越来越没规律，不是吃撑就是随便凑合，偶尔还直接跳过。日子久了，胃抗议、精神差、注意力也集中不了，工作自然跟着掉链子。

后来我发现，只要把做饭这件事“前置”：提前规划、一次性批量做好，很多问题都能迎刃而解。健康饮食有了保障，时间也省了，效率反而更高。我自己就是靠这个办法，从一个天天外卖的“饭困生”变成了现在这样：每周只花一个周末时间，一次做出5天的菜（三餐加起来15份），平时吃饭只需要微波炉加热几分钟，而且营养搭配均衡，足够满足日常所需。

这样坚持下来，既不用担心外卖吃多了缺营养，也不用纠结每天吃什么。算下来每顿饭成本也就10-12元，真的不贵。最重要的是，省时省力，还能顺便控制体重、降低生活开销，一举多得。

其实很多人都尝试过自己做饭，可一到实际操作就卡壳：不知道怎么吃、吃什么、食材怎么算、计划怎么做、背后的原理是什么……各种问题让人头大。所以我把自己的研究和长期实践经验整理成了一份系统化的备餐指南，希望能帮大家快速建立起属于自己的备餐体系。

这篇文章累计13000+字，预计阅读25分钟。我重点介绍了两种主流备餐思路：一种是传统美式MealPrep，比较适合健身、增肌减脂的朋友；另一种是结合了膳食指南和日式备餐的高效备餐计划，更适合普通人的日常健康饮食管理。当然，我本人并不是营养学专家，内容主要基于个人学习与实践，如果有什么不准确的地方，还请大家以专业期刊和论文为准，也欢迎在评论区一起交流备餐心得，碰到的问题我会尽量补充到文档里。
