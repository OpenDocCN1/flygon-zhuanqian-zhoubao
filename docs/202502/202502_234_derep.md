# 闲鱼卖泛 IP 周边实操手册

在闲鱼卖“泛IP周边”居然能跑通？2个月试水500多，她把实操手册写全了

最近在赚钱星球看到一位叫维拉的朋友，刚来三个月，就在闲鱼试着开了个号，做了两个月，销售额也就五百多块。听着不多，可项目是实打实跑通了。她把整个过程沉淀成了一份实操手册，还跟赚钱合作发布出来，内容特别接地气。

说到“泛IP周边”，其实就是范围很宽。明星、影视、小说、漫画、动画角色……只要自带热度、有人喜欢、能让人产生购买冲动的，都能拿来做周边卖。这背后的逻辑很简单：有流量，就有交易。

这份手册不是空谈理论，而是手把手教你怎么做。从新账号该怎样设置，到选品时从哪几个角度切入，再到成交环节怎么一步步推进，全都有涉及。非常适合那些对周边有兴趣、又有时间去捣鼓的朋友，把闲鱼当成一个副业试水点，或者干脆用来熟悉平台的玩法。眼下正好是春节假期，趁有空研究一下，假期结束就能开始动手操作。

有人担心IP版权问题，评论区里也聊到了。其实只要小范围做，被找上门的概率很低；加上闲鱼本身版权意识就比较弱，特别是日漫之类的海外IP，更是很难追责。所以现在的选品玩法，说白了就是蹭热度，这也是能赚到钱的一个重要原因。

评论区还补充了不少有意思的思路。比如有人觉得，经济不景气的时候，用周边平替盲盒是个更划算的玩法；也有人用AI画图先测需求，再找厂家定制公仔，定价58到80元；还有人提醒，周边不止是玩偶，完全可以结合日用品，既有实际用途，又能比普通商品卖贵一些。要是想让销量再上一个台阶，放到小红书或抖音做直播反而更合适。

总之，闲鱼卖泛IP周边是个入门门槛低、操作空间不小的副业方向。哪怕一开始赚得不多，能把流程走通，本身就是对平台认知的一个提升，后面的玩法也就能慢慢延伸开。想看完整手册的，直接点击飞书链接就好。
