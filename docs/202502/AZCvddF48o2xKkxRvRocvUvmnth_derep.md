# 用清迈打卡数字游民的第一站，真的比想象中更香



原本只想试水一月，没想到一住就上头。把清迈当成远程办公的起跳点，性价比真的高，整体开销比大理还要友好，体验却明显更上一层。唯一让人犹豫的，是出境后的安全感，尤其王星事件之后，很多人会问东南亚还敢去吗。我的感受是，听到的版本和身处其中的版本完全不一样。别因为担心而裹足不前，带着焦虑出发也玩不好。

朋友开玩笑说，在清迈碰到一个华人，就相当于碰到九成的华人圈。我现在的状态挺自在，也会真诚邀请身边的朋友过来看看。

我本人是典型的关系型人格，建立连接、整合资源是我的常态。所以在清迈，我很快就摸清楚了这里的远程工作生态。大家基本都是背着电脑全球走的个体户、内容创业者，和赚钱圈的调性非常像。下面是我观察到的几类人：

## 在清迈常见的远程工作画像

**内容创业者**
咖啡馆偶遇了一对油管头部团队，两个人一个出镜一个剪辑。标准的游牧模式，素材随拍随走，后端团队分布在世界各地。

**一人公司**
认识一位做海外网红PR的女生，杭州人，冬天嫌冷就跑来躲避，待了两个月，五月还要再来。从早到晚泡在咖啡馆里开会，对接，杭州的卷她直接搬到了清迈。

**歪脖伞**
这类人在清迈随处可见。有早早财务自由的95后，也有经历过两次破产依然在创业的男生，还有做社群运营的。很容易有归属感，就像到家了。

**美股交易**
遇到一位在美国生活了二十多年的小哥，最近扎根清迈。他形容自己白天放空玩耍，晚上盯盘，节奏自在又惬意。

**摄影师**
春节期间一位摄影师朋友天天爆单。摄影技能在这里需求不小，旺季接单很猛，竞争也没国内那么激烈。注意的是，在当地接单要留意合规性与风险。

## 清迈旅居成本怎么压到5000内

我算过一笔账，含春节机票高峰，也能控制在5000元左右。淡季去更便宜。

**保险别省**
长期旅居一定要买境外意外险。我买的京东安联约200元。上次打网球虎口拉伤肿了，直接去清迈兰医院，有中文服务，效率高，唯一贵的是自费。但有保险兜底，心理很踏实。

**机票省钱**
江浙沪直飞清迈航班少且贵，春节单程近3k。我走香港转机单程1600。大湾区出发几百块很香。
曼谷转机是常见路线，也可落地曼谷坐大巴到清迈，更折腾。
别只盯携程飞猪，锁定航班后去官网和小程序蹲价格，平台经常被加价。

## 吃喝玩乐

## 出行
Grab和Bolt都常用，Bolt更便宜。摩的灵活，3公里约40-50泰铢，打车70-100泰铢。长期租摩托月租600-800人民币，必须持国际驾照，否则罚500泰铢。听说有3天宽限期，但别赌运气，摔车率很高。

## 换汇
Superrich或Mr Pirere汇率更好，地图可搜。塔佩门附近有支持支付宝微信银联的店，方便但汇率一般，建议带少量人民币现金。
