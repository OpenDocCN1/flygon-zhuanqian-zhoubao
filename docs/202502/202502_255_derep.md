# 我，一个零基础艺术生，靠 AI“测试类”小程序赚到了第一桶金
作者：龙哥

没想到吧，一个学艺术出身、连代码都看不懂几行的姑娘，只靠AI工具就捣鼓出了自己的小程序，还赚到了第一桶金！没错，我就是那个姑娘——兔子。

大约在2025年初，我灵机一动，决定做一个叫“人生密码解读器”的小玩意儿。由于完全没有编程底子，我干脆全靠AI来帮忙。核心功能一个半小时搞定，从零到正式上线也只用了十四天。更让我没想到的是，这个随手做的小程序，一篇帖子就带来两万多阅读、三千多个赞，注册用户将近两千人，顺带还让我有了点小收入。

很多人问我：零基础到底怎么做到的？其实路径特别简单：先用 Dify 搭好AI工作流，再用 Cursor 帮着写页面和功能，完全不需要自己从零敲代码。接下来，连🛰️支付、广告位这些看着很“专业”的东西，我也都硬着头皮学会了，还走完了ICP备案，真正体验了一把被动收入的感觉。

产品做出来之后，运营也不能落下。我在📕等平台分享自己的创作过程，没想到几天时间热度就上来了，阅读量一路涨到两万+，点赞突破三千。看着后台不断增长的用户数，说实话挺兴奋的。

这次经历让我认真思考：在AI时代，到底什么样的内容值得做？答案其实不只是“会写代码”，而是“会用工具表达创意”。任何人，哪怕只有艺术背景，只要敢想敢试，都能把想法变成一个可用的产品，甚至实现变现。
