# 7套AI万能指令模板拆解

### 1. 任务驱动型指令模板

适合目标明确、步骤清晰、时间与交付物都定的硬任务。想让AI稳稳执行，必须把做什么、用什么、做到什么程度讲透。

*   任务概述：用简洁语言点明目标和范围。
*   输入素材：说明AI需要的数据类型，如文字、表格、图片、视频等。
*   处理目标：明确要达成的结果或产出。
*   执行方式：有特定流程或技术要求就写清楚，没有则让AI自主选择。
*   交付规格：限定形式、篇幅、精度，比如报告、图表、总结等。
*   约束条件：时间、篇幅、预算、技术限制等。

示例：
任务概述：产出一份市场趋势分析报告
输入素材：近五年全球电子产品销售数据，CSV格式
处理目标：梳理五年变化趋势，预判接下来一年的走势
执行方式：1.数据清洗，去空值和重复项 2.时间序列建模分析趋势 3.输出结论
交付规格：一份含趋势图、预测和结论的PDF，不超过2000字，图表可直接嵌入
约束条件：报告篇幅控制在2000字内，图表清晰

提示：任务驱动型重在细节齐全，越具体越不容易跑偏，适合执行类场景。

### 2. 信息查询型指令模板

适合需要查资料、做概括、理清某个领域全貌时使用。AI负责检索、整合、提炼。

*   查询问题：把想问的事说具体。
*   背景补充：提供上下文，帮助AI抓住重点。
*   期望内容：说明想要什么形式的答案，文字、清单、表格均可。
*   格式偏好：对排版有要求就提前写明。

示例：
查询问题：概括过去五年全球人工智能领域的技术进展
背景补充：聚焦各大科技公司年度报告中的关键突破，尤其深度学习与自然语言处理方向
期望内容：对核心进展做归纳，并点明每项的影响
格式偏好：分技术进展、影响、未来趋势三部分，每部分用小标题呈现，语言精炼

提示：信息查询型指令擅长快速获取与总结，适合学习和调研场景。

### 3. 创作生成型指令模板

适合产出创意内容，如文章、小说、诗歌、脚本、广告文案、视觉等。要求既有创意又符合要求。

*   内容类型：明确要创作什么。
*   主题调性：说明题材、风格，如科幻、温暖、幽默、专业等。
*   格式规范：字数、段落、章节、尺寸等硬性要求。
*   额外要求：情感基调、目标人群、文风、结构等软性要求。

示例：
内容类型：创作一篇短篇小说
主题调性：未来社会人与AI共生的故事，探讨科技依赖
格式规范：约4000字，分四章，每章约1000字
额外要求：情节有悬念，结尾留有思考，人机关系为核心，基调探索又充满希望

提示：创作生成型指令用于需要灵感与规范并存的内容生产。

### 4. 数据分析型指令模板

适合海量数据处理、洞察挖掘、可视化呈现的场景。AI可通过统计与算法提炼价值。

*   数据来源：说明数据类型与格式，CSV、数据库、API等。
*   分析目的：想得到什么结论，趋势、聚类、预测等。
*   分析方法：有偏好就指定，如回归、聚类、关联规则。
*   处理流程：按顺序列出清洗、分析、建模步骤。
*   交付形式：图表、报告、数据摘要等。

示例：
数据来源：客户购买记录CSV，含用户ID、商品、购买时间、金额
分析目的：找出各品类购买趋势，预测潜在热销品
分析方法：清洗后用时间序列识别趋势，结合历史数据做预测
处理流程：1.清洗去重 2.聚类细分人群 3.机器学习预测未来销量
交付形式：销售趋势图、热销预测清单及分析报告

提示：数据分析型指令适合从数据中找规律并可视化输出。

### 5. 编程任务型指令模板

适合写代码、做功能开发、优化调试等技术类需求。

*   开发语言：Python、Java、C++等。
*   功能说明：清晰描述要实现的能力。
*   输入输出：明确接口与数据格式。
*   质量要求：性能、高效、可扩展、低延迟等。
*   文档要求：注释详细程度、文档规范。

示例：
开发语言：Python
功能说明：搭建用户登录校验接口
输入输出：输入用户名密码，输出校验结果成功/失败
质量要求：采用Flask框架，支持高并发，完善异常处理
文档要求：关键逻辑和异常处理处添加详细注释

提示：编程任务型指令覆盖需求、实现、优化、测试全链路。

### 6. 学习与教育型指令模板

适合系统学习新技能、规划课程、评估成果。

*   学习目标：想掌握什么技能或工具。
*   学习方式：线上课程、实战练习、理论学习等组合。
*   学习资源：推荐书籍、视频、练习项目等。
*   考核方式：项目作业、测验、报告等。

示例：
学习目标：掌握Python编程
学习方式：在线课程结合实战练习
学习资源：《Python编程：从入门到实践》+ Coursera Python课程
考核方式：完成3个编程项目并提交代码，项目后做小测

提示：学习与教育型指令帮助规划学习路径并检验效果。

### 7. 问题解决型指令模板

适合遇到实际困境，需要AI给出可操作建议。

*   问题陈述：把问题说清楚。
*   背景信息：补充相关情况。
*   解决期望：希望得到方案、步骤或建议的形态。
*   约束条件：预算、时间、技术、资源限制。

示例：
问题陈述：公司官网加载过慢，用户投诉多
背景信息：页面较多，图片未压缩，服务器响应慢
解决期望：提供包含图片压缩、缓存配置等在内的优化方案
约束条件：两周内落地，且不能影响现有用户数据兼容

提示：问题解决型指令强调背景+约束，确保建议可落地。

以上七套模板能帮助你在与AI对话时，把每个环节都说透、做实。灵活套用不同场景，就能把AI的效率拉满。希望对大家的写作和工作有帮助❤️
