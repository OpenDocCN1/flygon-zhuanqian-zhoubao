# 别跟我聊天赋，聊运气吧：小马宋创业往事第34章
作者：龙哥

原载：[`www.yuque.com/for_lazy/zhoubao/vd4gysxh5smgdeyh`](https://www.yuque.com/for_lazy/zhoubao/vd4gysxh5smgdeyh)

过去一年里，我把自己做人和做公司的经历拆成了33篇文章来写，时间线停在了2020年。靠一点努力再加上一点点运气，这个小团队磕磕绊绊地扛住了，没关门。

明年就是公司成立十年的节点。现在我要开始准备一本收录十年创业经历与作品的合集，于是这套创业简史的内容，就到这里打个结了。

不过2020年之后这段时间的体感，也值得摊开讲一下。

从2019年算起，前后三年我们经历了一波小爆发，年复合增速常年超过50%。即便2022年是最吃紧的一年，连续四个月零新项目进账，年度营收依然涨了三成左右。到了2023、2024年，增速明显放缓，只剩下个位数，大概十分左右。

跟团队聊起这事的时候我常会感慨一句：要是能早五年前入场做咨询，或许就能赶上行业上半场的高光，人才和现金流都会宽松很多，腾挪的余地也会大得多。但这种假设没有意义，现实就摆在这里，只能在手里的牌里把结果做到最好。这也是我反复提到的逻辑：好战略不等于必胜，它只是在给定条件下去追求相对最优。哪怕失败，也要控制住失败的代价。

我很推崇克里斯坦森的那本《与运气竞争》，核心意思就是用系统化的方法和持续的努力，去对冲外部随机性带来的冲击。

克里斯坦森是做创新研究的，熊彼得早年的创新论也讲了类似的东西。最近许小年在一次访谈里谈变革时也是这个意思，无论是国家还是企业，想要跑赢同行、拿到超额回报，唯一的路就是创新。

创新不只是指产品或技术，组织形态、服务逻辑、方法体系，任何环节都可以创新。

在既有赛道里反复打磨，算是一种内卷式的改进；而一场真正的外卷式突破，才有可能带来降维优势。从2021年起，我们就开始逼自己做这种外卷。

我开始持续写作，已经出了《营销笔记》和《卖货真相》，前者销量接近20万本。在得到上做了系统的营销课，团队加大了短视频和直播的投入，内部也在不断调整合伙机制和组织架构。2023年起我们每年办案例大会，私域的🛰️读书群运营了两年多，如今规模超过180个，还沉淀出了自己的品牌方法论和一套可用的营销工具。

芒格说希望自己每次睡前比起床时更聪明一点，这件事很难做到，但我们一直在朝着这个方向逼近。

公司每年都会出现新问题，我们也是在一次次解决问题中被迫成长。今年年会我跟大家说过，大多数中国广告领域的热店，红得过十年就很不容易了，我们明年就满十年了，未来能不能继续活下去，我心里也没底。

我唯一确定的是，不创新不革新，就没有明天。明年我们计划推出小马宋十周年创业纪实与案例合集，希望能尽快和大家见面。

我把之前的简史系列文章整理成了🛰️文档和打包文件，方便一次性回顾。
