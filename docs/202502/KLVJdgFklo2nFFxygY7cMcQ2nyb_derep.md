# 一、DeepSeek到底是什么

简单讲，DeepSeek是国内团队深度求索 DeepSeek Inc. 推出的通用大语言模型家族，项目启动于2023年，目标是冲破认知智能的边界。它在自然语言理解、数学推导、代码编写等方面表现已达国际顶尖水平，已发布DeepSeek-R1、DeepSeek-V2、DeepSeek-V3等版本。底层采用混合专家MoE架构，训练效率高、响应快、功耗低。

我自己盯过热度，春节这段时间DeepSeek的话题几乎天天霸占抖音热榜，有时冲很久，有时掉得快，但从未缺席。

它的出圈程度很夸张，曾一夜让英伟达市值蒸发4000亿美金，创始人梁文峰会见过总理，被曝遭遇不明网络攻击，被美国启动国家安全调查，也被多国相继限制使用。在国产AI里，这种关注度是独一份。

# 三、DeepSeek的提问方法

总结一句话：DeepSeek没有固定套路，多问多看它的思考链就够了。

以前我不爱看思维链，只看结果。现在才发现，提问技巧其实藏在思考链里，不知道怎么问，看它怎么想就明白了。

![](img/4763c898c03b89c3141853248ffa3b18.png)

比如它写打工人的七言绝句，思考链里写到【七绝四句每句七字押平声韵】、【再校对平仄是否合规】，这些就是提问要点。看完我就能提更精准的需求：我要一首关于打工人加班多的七绝，格式四句七字押平声韵，合乎平仄，第一句点题，第二句深化不敢离职，第三句转折比喻想躺平不敢躺，第四句收尾表达迷茫。

![](img/e45dfdcd67286de8039934173dcf9dea.png)

这样出来的效果明显更好。

《七绝·案牍夜》

案牍如山月影重，敢辞霜雪负春风。
身如倦鸟思栖木，雾锁长桥路几通。

# 通用提问六个思路

## 一、抛掉模板，真实提问

如果你手里一堆AI指令库，用在DeepSeek上只会觉得它平平无奇。

错误示范：你现在是短视频文案高手，请帮我写一条关于XX产品的推广文案，要吸睛共鸣。

![](img/c9d8ab872c5596aca031efe3f73934b5.png)

它写出来还行但很普通。

改成像聊天一样：我这款产品真的很好用，就是不会夸，你帮我写个文案让人看了就想买。我没开联网只选R1，它却能联想到H1是宇树科技的产品，文案更贴合。

![](img/5b6b7d72fb33dfc193fb76370c83dc96.png)

把身份、目标、顾虑说清楚，它给的内容才有启发性。

## 二、用好要素，提高效率

DeepSeek没有固定模板，但创作类型、体裁、情感基调、文化元素四个要素说清楚就行。

比如输入 诗词_七绝_绝望_打工人 ，它就会按这个调性写，还会在思考链里建议多改几版更流畅。

![](img/e71dff63ed711f99065ff2694b1bde7a.png)

再比如 短篇小说_言情_甜蜜_校园 ，它会生成相应内容，我很喜欢它那句“原来喜欢一个人时，连呼吸都会变成蝴蝶，轻轻落在对方颤动的睫毛上。”

![](img/0149512efc58fe343b064618bb5f7e25.png)

![](img/8ad85d94f17867a09f9931b1ba3f9ee9.png)

缺点也明显，写小说前2000字惊艳，后面容易崩塌，喜欢往里塞科技梗或诡异梗。

![](img/d056322585c9dac659071d2d8f3839f5.png)

![](img/cafa906947e728fa73aed5e1c6565b16.png)

## 三、说人话，别端着

问它 什么是AI？说人话！

它会说AI能学习、做决策、模仿人类技能。

![](img/bd2d9e570d30fada6521b58d276e83a2.png)

觉得它味太重就直接要求：说人话、用大白话、广场舞大妈能听懂、举三个例子、禁用术语、每段不超过一屏。

## 四、反向挑刺，让AI自检

问：你觉得这篇文案哪里不够吸引人？如果我是用户会怎么吐槽？

看完回复思路会更清晰，再针对性追问。

![](img/d897dccd2308da4b363e1fa612dffbf5.png)

我特别认同它的一点反思：过度强调性能参数而不是真实痛点，年轻人要的是“替我偷懒”而不是“看我多牛”。

卖给年轻人的东西，先想痛点再谈参数。

## 五、模仿大师，满足心愿

DeepSeek模仿风格很强，给个设定它就能写出很打动人的内容。

不知道你有没有刷到过那种“用奇怪方式让知识进脑子”的视频？最近我倒是迷上了一句话：待暮雪白头姑苏岸，当携天子笑，候君醉看，万家灯火。

![](img/ab5c84ee9000eb781d39fc2cf3d6e43e.png)

其实，让知识“换个样子”钻进脑子里，这事儿不光视频能做，现在让DeepSeek来，也完全没问题。

![](img/007bcb45b1d72da17f7e11599cf8d4b5.png)

就像这样，看完一句话，一个单词可能就再也不会忘了。

# 四、DeepSeek到底怎么用？给你几个实打实的场景

## 1、记英语单词，别再死记硬背了

你是不是拿着单词本翻来覆去就是记不住？试试让DeepSeek把单词编成故事，用故事对抗遗忘，效果出奇的好。

操作很简单：

第一步，把单词本拍张照，拍清楚点。

第二步，打开DeepSeek网页版或者APP，找到那个回形针图标，把照片传上去。

![](img/d20fe6acb7d66cc05fd2368be06b0402.png)

![](img/52c8e885dac462e6d73611cfe94f764f.png)

上面是电脑端的界面，下面是手机端的，别搞混了。

接着输入一句：请把图片里的单词列出来。然后点发送，图片和文字一起发过去。

![](img/ffe792be430dcfec18514be3e569841b.png)

第三步，让它把这些单词写进一篇科幻冒险故事里。你可以这样对它说：请用上面的单词写一篇科幻冒险小说，适合小学一年级学生阅读，并且把对应的单词标粗体，字数在500字用英文输出。

![](img/030a6d209974d795a7b4d762679d2f03.png)

瞧，这么一来，记单词是不是轻松多了？把单词放进故事里，记忆自然就串联起来了。

第四步，再让它出题巩固一下。比如告诉它：根据这篇文章出10道英文选择题，把答案统一放在最后面。

![](img/4af4c3368b3ef6fb43c7fad38dd11749.png)

原本枯燥的背单词，一下子就变成了闯关游戏。你也不妨试试：打开DeepSeek，上传图片，输入提示词。

你会发现，那些零散的单词不再是孤零零的岛屿，而是一片连在一起的故事大陆。

## 2、批量制作表格，告别手动重复劳动

每次要建一堆表格、填一堆信息，是不是想想就头大？现在有个超实用思路——让DeepSeek帮你批量搞定。

具体怎么做呢？

第一步：先跟DeepSeek说清楚需求。比如直接输入：“我要做一张30个人的表格，帮忙写段代码。”

![](img/e3ee3e83e3dea2a401dbdc23f5375193.png)

它生成代码后，你把30个人的名字发过去，它会立刻更新出对应的新代码，是不是很聪明？

![](img/f6227a4028e33f0f8c310cef9b8dd24c.png)

第二步：把工作表准备好。按照使用说明，你的模板工作表要先改名为“模板”。

![](img/c924770c27c3dd23e4c31952adf122b0.png)

打开表格，把工作表重命名成“模板”。

![](img/9b213a8cb55f08eb3e339fac020734e5.png)

然后点击上方的“工具”，在下拉菜单里找到“开发工具”。

![](img/24ccb4207db0e18898ac616e6def0dae.png)

继续点“VB编辑器”。

![](img/be2206bcdf5e510f8606a3b20cd312d7.png)

在左侧“模板”那个位置，点击鼠标右键。

![](img/d18e7353b5f9db950d4cb38749a60315.png)

选择“插入”，再点“模块”。

![](img/7cf067b833de47ab892d9bd02c53add5.png)

把刚才从DeepSeek那边复制的代码，粘贴到这个模块里。

![](img/a095ead164db4c9ae85af2a3c6e41787.png)

![](img/c063fe497f958ebc92e32dae91538b23.png)

然后关掉这两个窗口。最后点击“运行宏”，30张表格就全部自动生成啦！🎉

## 3、用DeepSeek做图，各种图表都能搞定

什么流程图、序列图、饼图、思维导图、四象限图、桑基图……它通通不在话下。

你只要输入一段简单的文字描述，不到一分钟，一张精致又专业的图就出来了。细节丰富，拿去汇报或者当设计素材都够用。

在现在这个AIGC爆火的年代，DeepSeek真的是妥妥的效率神器。无论是职场人、学生党还是设计爱好者，都能靠它分分钟画出需要的图表。

怎么用呢？

第一步：打开DeepSeek，输入提示词，比如“我要画一个某某流程图，用mermaid格式”。

![](img/083b8c95971693f82fd47461df6fb5fc.png)

关键在于“mermaid格式”这几个字。不管你想画什么图表，只要把这句“用mermaid格式”放在最后就行。想画柱状图就写柱状图，想画折线图就写折线图，漏斗图也一样。

![](img/f4731e42dd2db415e602b3c2ce782348.png)

第二步：打开draw或任意画图工具，把刚才DeepSeek生成的mermaid代码复制过去。

![](img/f8232b277bc6a0fa064fb96400b54288.png)

## 4、DeepSeek + Kimi，PPT自动生成

这个方法真的能省下大把时间。

“我是一位工作8年的新媒体工作者，工作中经常需要了解某个陌生的行业，帮我写一份关于机器人的行业发展趋势报告的ppt，ppt内容包括行业最新的研究报告、产业上下游关系、ppt内容大纲，最后以markdown的形式输出。”

你可以根据自己的情况稍微改一改。

提示词发给DeepSeek，让它先写出一份PPT内容，然后把生成的文本复制下来。
