# 关键词：数据分析

大家好，我是龙哥。玩👸号爆文满打满算已经一年多，前前后后累计赚到六位数。这段时间我拿一支超过100个号的账号池做了一次大规模测试，里面绝大多数是全新账号，只有个别是以前就在用的老号。我想借这次数据复盘，看看接下来该怎么调整，也欢迎同行们一起探讨、互相进步。

# 一、账号池分配情况

这次测试一共用了113个号。养号阶段的分布是这样的：文案方向32个、PLC方向34个、电工方向37个；另外还有10个号是直接起号跑的，领域集中在军事、生肖、星座等。

# 二、各方向的流量摸底

先看文案号：32个号，更新了16到18天，其中有13个号做了转领域操作——6个转向生肖、3个转向情感、3个转向星座、1个转向文案细分。最终结果是8个号稳定拿三位数流量；3个号先爆了一篇，之后也能稳住三位数；1个号爆了一篇直接废掉；还有1个号始终没起来。

然后是PLC号：34个号，更新了12到14天，只有2个转了领域，分别是汽车和军事。表现方面，1个号爆文后稳住了三位数流量，另外1个是今天才转，暂时看不出什么。

再看电工号：37个号，同样更新了12到14天，其中6个转了领域——3个转军事、2个转律例、1个转汽车。这波里面有1个号爆一篇后嘎了，1个号没起来，剩下4个号稳定在三位数流量。

最后看直接起号的10个号：更新了16到18天，结果只有一个老号爆出8k+阅读，其余账号最好也只是三位数。

# 三、几个关键判断

从这轮测试来看，养号效果排序是：文案号＞电工号＞PLC号；转领域后的表现排序也完全一样。

目前跑出来比较靠谱的跨领域组合有：文案转生肖或星座、美食转情感、Excel转职场。不过要注意的是，转领域这套打法很可能已经被平台识别了——结合我自己和身边同行的近期数据，转领域之后还能稳定下来的号，连10%都不到。

# 四、接下来的调整方向

眼下最让人头疼的问题就是起号之后稳不住，所以后面我主要会在这些方面下功夫：

1. 转领域后废掉的号，先试试助推券救一下，或者转回养号状态，再不行就换新的热门领域重新养。
2. 转领域之后必须做精细化运营，不能再像以前那样靠AI无脑怼量，这条路已经走不通了。现在宁缺毋滥，一天能稳住一篇高质量内容就行。
3. 从选题、标题、文章质量到排版，方方面面都得精耕细作。
4. 多去挖掘新的低粉爆款领域，直接起号，不折腾转领域。
5. 直接起号不是不行，但前提是要做足调研，多研究低粉爆款账号，靠精细化运营冲出来。
6. 养号领域还会继续扩，后面计划测试美食、Excel、Word这类小众方向。
