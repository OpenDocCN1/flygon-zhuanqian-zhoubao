# 诉讼记录背景调查，十个最常被问的问题
作者：龙哥



## 背景调查诉讼记录十问十答

作者： 张哥背调咨询

日期：2025-02-19

1，法院判决书多久能从裁判文书网撤下？刑事和民事有区别吗？背调平台的记录又要多久才能处理干净？

刑事类大概需要四十多天能搞定，民事类通常三周左右可以完成，背调机构的清除周期一般是十几天左右。想做的话越早启动越好，时间拖久了会耽误事。

2，下架之后会不会哪天又冒出来了？

只要你之后不再产生新的案子，这次下架就是长期的，不会再重新出现。

3，你们的实际操作流程是什么？

针对裁判文书网，我们会直接对接法院内部沟通流程，经院领导审批盖章后才会被移除。背调机构这边则必须走合规的法律程序，不是谁打个电话就能删的。

4，怎么证明是真的删干净了，能不能先试试？

做裁判文书网之前，我们会先请你自行检索一次，操作完成后你再检索一次，对比看不到才算完成。如果没做到位，费用全退。

背调机构的服务也一样，先用你指定的那家公司做一次全程录屏的检索，后续处理结束后再录屏复查一次，确保查无信息，否则全额退款。

5，指定机构清除了，换一家背调公司还能查到吗？

背调行业数据并不统一。只处理了其中一家，后续换了别的供应商去查，还是有被翻出来的可能。保持原机构不变的情况下，才是看不到的状态。

6，裁判文书网撤下就等于案底没了？

案底是公安内网的存档，想彻底抹除是不现实的，花多少钱都不可能。无犯罪记录证明照样开不出来。我们能做到的是，让你即便有案底，也不再影响正常求职流程。

7，背调公司的数据一定来自裁判文书网吗？

并不全是。很多时候裁判文书网已查不到，背调仍能查到。这是因为市场上数据商众多，各自保留的存档版本不同，背调会从这些渠道调取。原始来源最终指向最高法。裁判文书网先清干净更有意义，因为这代表案件已终结、国家层面不再追责，这才能作为和背调机构沟通的有力依据。

8，哪些类型的案件具备下架条件？

基本原则是案件已经结案。民事或执行类，只要标的履行完毕就算结案；刑事类，出狱或处于缓刑阶段也属于结案状态，均可申请。

9，我根本不知道下家公司用的是哪家背调机构，能不能先等链接再说？

建议先向HR侧面确认使用的供应商名称。如果实在无法提前确认，只能等到收到背调链接后再启动，因为需要额外约一周的操作缓冲期。

10，自己当原告并胜诉的官司，会影响求职吗？

会影响。只要卷宗里留下诉讼记录，无论原告被告，企业方一般都会认为候选人矛盾纠纷多，不利于团队稳定。
