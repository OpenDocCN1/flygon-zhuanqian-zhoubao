# 干了三年全职写稿，我才弄明白的5件事



# 开场白

各位龙哥盟的伙伴大家好，我是林林，目前是做全职撰稿快三年半的自由职业者。

这篇内容，可能给不了想靠写作赚钱的人一套马上能落地的变现教程，比如怎么写出高价稿、去哪接单、读什么书报什么班。

但如果你对全职写作这份职业好奇，或者正打算把写作当成主业副业来试水，接下来这些我一路撞出来的经验，也许能让你少走些弯路，更快地完成从零到一的跨越。

# 我的来路

在聊认知之前，先说说我的背景，方便大家带着坐标系去看后面的判断。

我跟写作结缘很早，初中时语文老师就把我们几篇写得不错的作文投出去，还把稿费亲手送到我手上。那时候我就觉得，写东西换钱好像挺轻松。

大学在中文系，专业课成绩一般，毕业GPA才2.8。大四期间我给“十点读书”写拆书稿赚外快，后来也自己开👸号记录大学四年。虽然没赚多少钱，但在同学间还算有点声量。工作太忙后就关了，现在想想挺遗憾。

毕业后我在银行待了一阵子，一边上班一边继续给“十点读书”供稿。后来发现银行的收入和成长空间都达不到我想3-5年后留学或创业的需求，于是2019年12月辞职，南下厦门做了一个月薪四千多的新媒体小编，边做边攒经验，又换了两三家小公司。

在BOSS直聘上找工作时我顺带发现了兼职单子，慢慢摸清了在网上接活的路数。2021年7月，我正式转为全职撰稿。副业收入有段时间稳定超过主业，才让我下定决心all in写作。

靠着攒下的作品集，2022年9月我拿到了一个月薪八千起的新媒体编辑offer，可惜没通过试用期。被裁后反而让我捡到不少自由接单的机会。

稿费的涨幅也很明显：2022年单篇从100元涨到1000元，2023-2024年间又从1000元涨到2000元，甚至接到过4000-5000元的广告软文，都是些行业头部👸号抛来的单子。

到2024年12月之后，工作量开始失控。一旦同时挂几个客户，精力就被掏空，稿子质量跟着滑坡。而看起来很高的稿费背后，甲方的品控要求也极其苛刻，他们经营多年，最怕口碑翻车。

这些压力让我把过去的经历重新捋了一遍，下面这几条是我觉得最值得分享的体悟。

# 真实认知

## 别把写作当苦力活，精致打磨比堆数量强

刚起步做写作副业时，我曾算过一笔账：一篇100块，一天写四五篇，一个月轻松过万。结果现实狠狠打脸。哪怕是百元稿件，甲方也不一定一次过稿。

更关键的是，长时间对着屏幕，缺乏运动和户外，精神会越来越紧绷，效率反而掉。后来我发现，客户要的是靠谱的产出，不是堆砌的篇数。你服务不了四五个低价客户，但可以深耕一两个高价客户，把时间用在刀刃上。

自由职业最值钱的就是时间，不像上班可以划水。一天没利用好，就是真金白银的损失。

## 稿费高，意味着买的是你的时间与确定性

高价约稿本质上是认可你的能力，也等于对交付标准提出更高要求。甲方花钱请你，不是为了自己再花大量时间改稿，而是希望你一次性把时间成本帮他们省下来。

所以遇到天价稿费的单子，要先想清楚自己能不能交付确定性。紧急稿件除外，那种情况双方都会进入快节奏配合，你需要的是暂时清空杂事，all in这件事。

高要求低回报的单子最致命，高回报高要求反而是良性循环。

## AI是放大器，不是代笔

很多人担心AI会让写作者失业。对我来说，新媒体写作尤其是靠推荐流的平台，算法能识别AI痕迹，一旦被判定，推荐量会直接受影响。这对真人写作反而是保护。

关键在于怎么用。我现在用AI做信息检索和整理，语音输入后让它转成结构化笔记，省下大量机械劳动。播客、视频、长文的核心观点也能快速被提取，效率大幅提升。未来我甚至想把这套方法整理成课程或书。

但直接让AI代写是自杀行为。编辑一眼就能闻出来，信任一旦丢掉，很难再捡回来。用得好是效率加成，用不好就是减分项。

## 给未来的自己留时间窗口

当初选择自由撰稿，很大程度上是看中了时间自由，想用写作养活自己，同时去做更有长期价值的事。

可这三年里，我把所有时间都押在了当下的交付上。朋友里有人一边接单一边做自媒体IP，慢慢形成了自己的品牌，而我在这方面几乎是空白。

不管做什么自由职业，都要给自己留出复利时间。多读书，经营一个属于自己的内容账号，无论是👸号、📕还是视频号，都是在为未来的议价权和选择权做准备。否则你会一直卡在瓶颈，竞争力停滞不前。

## 踩坑没关系，重复踩坑才要命

自由撰稿人踩的坑很多都是共性的。比如甲方反复提醒的问题，你还是会偶尔犯。虽然对方可能不说，但合作温度会慢慢变冷。

把踩坑的经验写下来复盘，是我现在最庆幸的做法。梳理一遍，你会更清楚自己的短板和致命弱点，下次遇到类似场景就能提前规避，让交付更稳。

# 收尾

自由职业没有标准答案，我的路未必适合所有人。全职写稿这条赛道上，我的打法也只是众多可能性中的一种。

不过把自己犯过的错、走过的弯路，还有能被复用的方法摊开来讲，对别人有帮助，对自己也是再认识。无论是做IP还是出书，这些素材都是未来的养分。

希望这些真话，对正在考虑这条路的朋友有些启发。
