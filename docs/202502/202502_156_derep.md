# 做难而正确的事
作者：龙哥

如果说有什么选择能让人生彻底不同，那大概是：挑一件难啃的事，但它是对的。

最近看到英伟达黄仁勋的一段话，心里被戳了一下。他说，要去做那些你从没做过的事，去选择你冥冥之中觉得自己非做不可的事，一切才刚刚拉开序幕。

难，常常是一道筛选门槛。真正有价值的路，往往不是最省力的那条。正确，意味着它经得起时间的追问，也经得起自己心里的掂量。

我们总习惯了待在熟悉的轨道上，重复可预测的日常。但那些注定要发生的故事，往往藏在你不敢触碰的未知里。不是所有难题都值得做，但值得做的事，没有一件是容易的。

有句话说：我们的故事刚刚开始。说得真好。无论你现在是卡住了，还是刚起步，只要方向是对的，哪怕走得慢一点，也没关系。难是常态，但正确是方向。

做难而正确的事，不是一句鸡汤，而是一种选择。每一次选择都像在给未来的自己铺路。也许此刻还没有回应，但你知道，所有刻意避免的难，都会换成另一种形式回来；而所有主动面对的难，都会变成你底气的一部分。

评论区有人说，刚经历的一件小事，对这句话更有感触。是啊，真正读懂的瞬间，常常发生在那些被现实狠狠磨过的时刻。

愿你也有勇气，去做那些没做过、但注定要做的事。故事还长，才刚刚开始。
