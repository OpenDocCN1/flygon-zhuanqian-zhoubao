# 一、提示词地基：BRTR法则（源自台风老师）

![](img/bc71cfe623ae3ea92237fd6c754ffdfc.png)

很多人觉得给AI下指令很难，其实用对模板就很简单。BRTR法则就是一个超好用的任务指令框架，本质是四个部分：背景、角色、任务、要求。背景就是告诉AI你当前遇到什么问题；角色是给它一个身份，比如专家、顾问；任务是明确你要它干什么；要求则是限定输出格式、字数、风格等条件。

换句话说，先让AI知道“你面对的是什么”，再告诉它“你是谁”，然后说“请帮我做什么”，最后补上“做到什么标准”。这样做，AI的理解成本大幅降低，回答自然更精准。对刚入门的小白来说，这套模板简直是救命稻草。

举几个例子：

**示例1：写产品介绍**
- 背景：我新上线了一款智能家居设备，能用语音控制家电，还支持远程操控。
- 角色：你是一位资深的科技产品文案专家，擅长写简洁有力的介绍。
- 任务：为这款设备写一段官网展示用的产品介绍。
- 要求：语言精炼，突出核心卖点；150字以内；适当用一些让人心动的词汇。

**示例2：问投资建议**
- 背景：我有一笔闲钱想投股票，但对策略和选股不太懂。
- 角色：你是资深的投资顾问，熟悉各类股票策略。
- 任务：给我一个简单投资策略，并推荐几只适合长期持有的股票。
- 要求：策略要新手友好；每只股票附理由和风险提示；总字数300字以内。

**示例3：做内容营销方案**
- 背景：我在负责一个电商平台的内容营销，想提升流量和转化。
- 角色：你是经验丰富的内容营销策划师。
- 任务：帮我做一份为期一个月的营销方案，重点是用有价值的内容吸引用户并促成转化。
- 要求：包含内容主题、发布时间、目标受众；要有明确的KPI（比如流量或转化目标）；总字数500字以内。

看到没？只要用BRTR把需求拆清楚，AI就能get到你要什么。

另外，和AI沟通还有两个必须掌握的原则：

**原则一：简洁明了**
问得越简短，AI处理起来越快，也越不容易跑偏。

错误示范：题目自拟，与侵权法中的监护职责有关，注意要落在具体点，不能宽泛……（又长又绕）
正确示范：我要写一篇报告，选题范围是侵权法中的监护职责，论点不要太宽泛，请给我至少三个题目。

**原则二：清楚明确**
给AI足够的范围和定语，它才能给出针对性的回答。

错误示范：请把以上文章写得更具体详实。
正确示范：请在以上文章中具体说明：XX战争是怎样取胜的？作者列这些例子想证明什么？

当然，想要高质量产出，光靠这两招还不够，必须耐心和客户沟通需求，再对AI生成的大纲和内容做人工润色修改。不同文章类型，操作方法也有差异，要具体问题具体分析。

#### 如何让AI少犯错？

- **要求附来源**：让AI引用或说明信息出处，并整合多个来源交叉验证。
- **人工审核**：再像模像样，关键内容都必须人工把关，尤其是复杂或敏感话题。
- **持续优化**：定期更新训练数据，引入领域专家知识，降低过时或错误输出。
- **限制范围**：遇到复杂推理或专业领域，给AI划好“答题边界”，别让它瞎编。

# 二、爆款标题：开幕雷击法

写标题的核心，就是“开幕雷击”——让你第一眼就被震惊到。

爆款标题的7个雷击要素：金钱/数字、性暗示、暴力、死亡、捷径、异常/悬念、民族主义。标题里只要出现其中2个，打开率基本就有保障，要素越多越好。

标题公式：**主人公（特征）+ 故事主干 + 结局或异常**

# 四、📕爆款写作指令

想做📕，可以直接把AI调教成“爆款写作专家”。指令里要求AI从多种风格中随机选一种（王朔、韩寒、王小波、咪蒙、亦舒、刘慈欣等）；再从语气里随机选（严肃、幽默、愉快、激动、温馨、轻松等）；再随机选开篇方法、文本结构、互动引导、小技巧、爆炸词。

比如开篇方法可以选“提出疑问”“使用数据”“悬念开头”等；爆炸词可以选“好用到哭”“绝绝子”“搞钱必看”“破防了”“YYDS”等。最后还要从生成的稿子里抽取3-6个关键词，用#号做成标签。

## 一、用AI写👸号文章

先拿👸号文章来说，操作其实不复杂。

第一步，把要写的主题、字数、面向什么场景告诉AI，比如“写一篇800字、用于校园演讲的稿子”。这一步很关键，信息给得越清楚，AI越能对准你的需求。

![](img/b612345f2351b80d6cc68e1613df82c7.png)

第二步，等AI生成初稿后，我们要从中挑出真正用得上的部分。举个我操作过的例子：让AI写一篇“决不轻言放弃”的演讲稿。它给了这么一段，大致意思是：站在台上，用坚定的声音喊出不放弃；生活里我们总会碰到学业压力、人际矛盾、自我怀疑，这些时刻最容易想撒手。但一旦放下，就等于向困难认输。反过来，撑下去，才能在一次又一次的挑战里看见自己的成长。成功从来不是一路顺风，只有咬牙坚持的人，才能体会到奋斗带来的甜头。爱迪生那句话大家都熟——天才是百分之一的灵感加百分之九十九的汗水。说到底，别怕失败，别轻易放下，持续努力，才能做出属于自己的成绩。

第三步，润色和修改。把AI那些“首先、其次、再次”之类的框架词拿掉，删掉重复啰嗦的车轱辘话，按照自己的表达习惯重新理顺。这步做完，AI味就没那么重了。

第四步，定稿交差。这样一篇👸号文章就算完成。

## 三、SPSS描述性统计分析实操

SPSS描述性统计，其实是分两类的：一类是非连续数值型变量，一类是连续数值型变量。原理都一样，只是鼠标点的地方不同。

第一步，把手里的数据整理成标准表格。

![](img/155ae361f57230d1f1e2a09ec7f1a31b.png)

第二步，按固定话术把问题和数据喂给AI。我的常用提示词是这样：假设你是一个大学生，在写某主题的论文，用SPSS对问卷结果进行分析，以下是你的数据结果，请你分析并完成小节撰写，不要分小标题，用完整段落，200字。同时提醒它“重点分析数据说明了什么结论”。

第三步，AI就会把分析结果返回给你。

![](img/754e3d7f0e26d58387ae5c2fd6b2141b.png)

一般来说，论文里第一块内容就是“描述性统计分析”，用来交代样本的基本情况，比如性别、年龄、职业分布。除了这些，还可以按照问卷的维度来拆，像训练情况、休息安排、伤病历史、心理状态、防护措施等等，用频率分析的方法挨个说明现状。最后把SPSS输出的表格用上，或者做成条形图、饼图，都很直观。
