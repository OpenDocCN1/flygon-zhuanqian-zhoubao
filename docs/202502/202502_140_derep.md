# 我做得到，所以你也做得到
作者：龙哥

godaddy 又一次自动帮我续上了那个老域名。那是我在网上买的第一个域名，大概是 2008 年的事了，当时我正读大学。

那会儿听说写英文博客能挣钱，我就去找教程。域名是什么、主机是什么，我完全懵。最后在淘宝花钱买了一台共享主机，折腾了好几天也没搞明白怎么把域名和主机连起来，沮丧到怀疑自己智商。教程里几步就搞定的事，到我手里全是 bug，最后只能厚着脸皮求卖主机的小哥远程救场。

域名和网站到手后，我开始自学 WordPress 怎么搭博客，然后日复一日写英文文章做 SEO 引流。流量慢慢起来了，第一笔五美元到账时，我高兴得不行。那种感觉现在都忘不了，好像看到了发财的曙光，前路一下子不黑了。

那个阶段没有同行交流，没有圈子，也没有论坛可以问。只知道有人在前面赚到钱了，就凭这一腔不服输的劲儿硬撑下来，然后跟自己说：我也能行。

网站早就不用了，但域名我一直续着。 partly 是念旧，更多是给自己打气：一个普普通通的人，只要肯一点点上手、一点点积累，真的有可能拿到过去想都不敢想的体量。

这份笃定，也是我一直做龙哥盟的底气。 我可以，那你也可以。
