# 看到亏损就慌？别急，亏损也可能藏着未来
作者：龙哥

很多人看上市公司业绩，习惯性反应就两个：亏损=坏消息，盈利=好消息。但真实世界的商业逻辑，远比这个二元判断复杂得多。**亏损不一定是坏事，盈利和增长也不一定代表公司前途光明。** 关键在于，我们要学会读懂数字背后的“为什么”。

举个例子，假设一家科技公司，十年前就下决心投入芯片研发，每年砸下上千亿真金白银。因为投入太大，连续多年账面都不盈利。可一旦它突然宣布攻克了7纳米制程，之前的亏损瞬间就变成了“战略投资”。国内确实就有这么一家公司，近两年在芯片上的投入每年都超过千亿。

反过来看另一类公司，主营业务一直赚钱，几乎从不碰新产品、不改进成本结构，利润表一年比一年漂亮。听起来很棒？但这样的公司很可能是在吃老本，未来一旦被颠覆，它的投资价值就会归零。所以持续盈利，未必等于值得投资。

再看一家奶茶企业，如果它把赚来的钱都投到茶山、柠檬园、包材工厂、水果改良实验室，甚至研发自动奶茶机，那它今年账面很可能是亏损的。但这种亏损，买的是长期竞争力，谁敢说它没有未来呢？

还有一个更容易被误解的概念——破产。一家公司破产了，是不是就没有价值了？真不一定。很多破产只是因为现金流断裂，而现金流断裂不等于公司本身没有资产、没有市场、没有翻身的机会。去年我采访过一位老板，他就投了几个亿，接盘一家已经进入破产重整的线下超市上市公司。理由很简单：那家超市缺的是现金，不是价值。

反过来还有更反直觉的情况：有的公司报表连续盈利，却忽然破产；有的公司常年亏损，却一直活着。玄机同样在现金流。说到底，在我们能看到的报表背后，会计规则其实给企业留了很大的操作空间，某种程度上，它是一场数字游戏。

这种“数字障眼法”在咨询行业也很常见。比如有人宣称“2023年上半年帮助上海某门店实现业绩同比翻番”，听起来厉害吧？但明眼人马上会追问：2022年上半年，上海还在封城，那家店说不定根本没营业，你拿什么做基数？再细问，是单月数据还是持续几个月？是同比还是环比？中间有没有搞过促销、投过广告？当数据被人为“处理”过，它骗起人来可以说毫不费力。

但遗憾的是，大多数普通股民和网友，对财务知识几乎零基础。看公司只看一个标题、一个市盈率、一句盈利或亏损，然后就用那点微薄的认知去搏杀。这种人炒股，结局几乎是注定的：靠运气赚的快钱，早晚靠实力赔回去。论聪明、论努力、论资金规模、论信息获取、论心态，普通人和那些专业投资机构的差距远不是一星半点。所以我的结论很直接：**普通人，真的不适合买股票。**

最后分享一位读书群群友的亲身经历，他在两家世界500强家电企业都做过中高层。他说，A企业的管理者喜欢买B企业的股票，反之B企业的管理者也喜欢买A企业的股票。为什么？因为大家都太了解自己公司的那些毛病了，而不了解对手的真实情况，网上看到的信息又基本都是被筛选过的利好消息，负面内容早就被公关删掉了。某种程度上，连内部人都看不清真相，外部普通人想通过公开信息赌赢市场，又凭什么？

所以，下次再看到“巨亏”或“大涨”的标题时，不妨先停一停，问一句：这个数字，到底是价值的体现，还是障眼而已？
