# 春节宅家阅读清单，40+本硬核书单收齐

离除夕不远了，拜年送礼、围桌吃喝之外，总有几段可以一个人安静的时光。与其刷短视频打发，不如挑几本有分量的书，让假期过得更扎实。

腊月里，龙哥盟的社群里抛出了一个话题：年假期间想读点什么。没想到大家的热情直接拉满，短短时间里汇集了四十多本不同类型的书单。把这些推荐梳理一遍，基本能覆盖一个长假的阅读量。下面这份合集供大家参考，也欢迎在评论区补充你的私藏。

**评论区精选**

小路：可以加上《人生设计课》。

七天@龙哥盟：确实值得多读几遍。

庄锦卫：补充一本非虚构，《深奥的简洁》约翰·格里宾著。作者从物理与数学、化学、生物、进化论等角度切入，讲微观到宏观的复杂系统如何呈现内在简洁：混沌边缘、自组织、生命起源与演化，都指向简单的运行规律。读完会觉得生命在宇宙中或许是必然，人类并不孤单，也是种奇妙的体验。

心净亦如心镜：若每本附一句推荐语，更容易让人产生阅读兴趣。

追梦：《小狗钱钱》值得翻。

妙妙想退休：《10x 增长》和《笔记的方法》读完后，像拿到了赚钱与学习的底座，受益很大。

抖音电商-时光：梁宁《真需求》。

陈亮：《智人之上》。
