# 时间有限，杠杆率无限：创业者管理效率的提升要点

“忙到飞起，却感觉啥也没干成。”这话是不是特耳熟？

最近有位刚离开职场、二次创业的老哥，在龙哥盟发了篇帖子，角度挺特别。他不聊融资、不聊产品，就聊一个扎心话题：**作为老板，到底哪些事必须自己干？哪些事干了也是白干？**

这位老哥自称“初入平安”，80后，在HR圈子里算是混到了金字塔尖——内部人才发展、组织搭建、招聘一把抓，年入百万那档。中间跟朋友折腾过两年电商，没赚到钱，老老实实回职场回血。今年又杀出来了，跟老同事凑了笔投资，做起游戏行业的配套生意。

他抛出的核心概念，叫**“管理岗杠杆率思维”**。

一句话总结他的观点：**时间永远不够用，但杠杆率可以无限大。创业者要做的，不是啥都自己上，而是找到那个能撬动最大成果的支点。**

你肯定也遇到过这些场景：每天像个陀螺，转个不停，晚上一复盘，产出却少得可怜；团队执行力拉胯，说了八百遍还是老样子；花出去的时间越来越多，回报却没见涨。

他的建议是：别急着埋头干活，先算算你手里每一件活儿的“杠杆率”。那些低效的、重复的、可以交给别人的事，果断放掉；把精力全押在能撬动团队效能的关键点子上。

说白了，老板的时间不是用来“做事”的，是用来“撬事”的。

帖子里他还贴了自己写的一篇飞书长文，干货更详细，链接放在文末。之前写过两篇分享，一篇拿了精华贴，一篇讲带团队的管理心得，他都一并贴出来了，感兴趣的可以去翻翻。

对了，评论区还有个小插曲：龙哥盟的创始人龙哥亲自现身点了赞，说“这类文章挺好的，多发，很多老板需要”。看来这思路，确实是戳中不少管理者的痛处了。
