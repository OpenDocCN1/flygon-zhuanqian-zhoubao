# 一人公司如何判断一个行业是否合适进入

### 一人公司怎么挑行业？方向对了，努力才有意义

大家好，我是龙哥，新年第一篇，咱们聊点实在的。

你身边是不是也有这样的人：明明自己也很拼，可结果总是不尽如人意？其实我以前也一样。做过几个项目，有的项目好像被好运推着走，随手做做就成了；有的项目拼到发际线后移，最后盘账还是亏的。后来我慢慢想明白，问题多半出在起点的选择上。

现在我对“赚钱难易”这件事的理解是：选对赛道，比死磕自己更重要。如果给影响收入的因素排个权重，我会认为“行业选择”能占60%，“个人努力”占30%，还有10%留给没法控制的黑天鹅事件。你可能会说，努力难道不重要吗？重要，但方向错了，努力不过是把力气花在打空拳上。

那么一个人或者一个小团队，怎么在进场前判断一个行业到底值不值得做？我把这几年思考的东西整理成了“三大方面、10个维度”的框架，专门针对轻资产、小团队的“一人公司”场景，尽量做到不吹不黑、直接能用。具体内容有点多，我放在了飞书文档里，有兴趣的可以直接查看：


有朋友在评论区感慨：方向不对，努力白费。这话虽然糙，但很真实。选择本身就是一种能力，把选择做对，努力才真正有价值。希望这篇整理能帮到你，也欢迎在评论区聊聊你的选行经历。
