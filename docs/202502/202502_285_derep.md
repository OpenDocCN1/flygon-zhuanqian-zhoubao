【给新人的商业启蒙：把信息不对称变成赚钱杠杆】----

嗨，我是龙哥，一个常年跟新人打交道的分享者。

这次收到官方邀请，到福建参加了一场圈友线下会，和当地朋友面对面聊了聊我一直很有兴趣的话题——把别人不知道的，变成自己能赚的。

整场交流，我特别想带大家理清四件事：

1. 同样起早贪黑，凭什么别人月入六位数，你却分文未进？
2. 真正值钱的资讯落差，通常藏在哪些不起眼的角落？
3. 面对每天扑面而来的消息，如何判断哪一条具备变现潜力？
4. 机会递到眼前时，要以怎样的方式去接，才能让它不断升值？

这次交流的完整讲稿，我整理成了飞书文档，需要完整版的朋友可以在原文中获取。

留言区里大家的反馈也很热闹：

有人对晓文的讲课风格赞不绝口；  
有人感慨“对新人特别友好，全程都是大实话”；  
有人对分享里那句关于风口的比喻印象深刻，说自己曾经也有过同样的状态，花了整整两个月才慢慢定住神；  
还有人留下一句“赚钱不是想出来的，是干出来的”；  
最后还有朋友送上了新年祝福。
