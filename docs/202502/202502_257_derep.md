# 四个人，一天半，搞了个AI吐槽网站

大家好，我是土豆君，一个整天跟代码打交道的全栈程序员。

说来惭愧，去年一整年没怎么折腾出像样的东西。不过今年一开年，倒是玩了个有趣的项目——一个AI吐槽大会网站。

这个事的起因也挺偶然。那天刀姐在一个社群里分享了一条脑洞大开的GPT吐槽回复，瞬间勾起了老大的兴趣。

刀姐说想做个小网页，两天搞定。我一看，这活儿哪用得着两天？一小时就够。反正这玩意儿听着就好玩，我当场就拍板接了下来，顺手把Demo版做出来了。

但事情当然没这么简单。

我那一版走的是极简风，干净是干净，可刀姐觉得丑爆了，说这质感根本配不上“吐槽”这两个字。她要的是那种带点游戏感、让人眼前一亮的效果。

行吧，那就认真来。

我拉上了圈里的百合老师负责UI设计，又请财猫老师搞定Prompt和接口支持。这一下，四人小队正式集结，各管一摊，配合得那叫一个默契。

最后只花了一天半，整个网站从无到有地立起来了。

上线那天的数据还挺争气——当天冲到了2.2K流量，连谷歌都主动收录了，这波属实是有点意料之外的惊喜。

对了，可能会有圈友好奇这名字——“AI吐槽大会”这个叫法，其实是亦仁老大最早提的。

整个开发过程踩了不少坑，也攒了不少经验，我整理了一份全流程复盘，写在了下面的文档里。想围观的朋友欢迎自取：
