# ('【星主的收藏夹】5 篇', (2, 13))

你是不是也经历过这样的时刻：明明关注了一堆公众号、收藏了无数条链接，真到要用的时候却怎么都翻不到有用的东西。信息堆成山，能派上用场的寥寥无几。

这位叫做“星主”的博主，在他的收藏夹里攒了5篇私藏内容，说是宝藏也毫不夸张。和市面上那些烂大街的推荐不同，这些内容是从海量信息里精挑细选出来的，每一篇都有它的分量，值得花点时间慢慢看，而不是那种刷一眼就划走的快餐货。

更值得一说的是，这些内容来自一个叫“懒人找资源”的公众号。虽然名字里带“懒人”，但做事一点都不糊弄，专门替大家省去翻找信息的功夫，把真正有干货的东西整理好送到你面前。如果你想省时省力又能挖到好东西，这个号的收藏夹，值得你专程去逛一逛。顺带一提，加入懒人专属群，还能解锁更多没公开的内容。
