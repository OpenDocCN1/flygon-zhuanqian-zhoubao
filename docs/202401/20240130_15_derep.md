# 为什么明明可以解决，而不去做？

有些问题明明看着有解，怎么就是没人动手？

最近我在读书群里跟人聊天，聊的是公摊面积、春运火车票这类话题。聊着聊着发现，大家真正该关心的，其实不是那些事本身，而是我们思考问题的方式。

先讲个最普遍的。

每逢春节抢票难，总有人喊：那就加开列车啊，多派点车跑起来不就完了？

听起来一点毛病没有。可要是跳出“乘客”的身份，替铁路公司算笔账呢？春运前后拢共几十天，要是照这个高峰去配车，平时那些列车基本闲置，购置费、养护费、人工费加起来，是个大到没边的数字。这笔钱谁掏？说到底，不是解决不了，是代价压根扛不住。

再说个小事。我的社群里时不时混进一些人，进群就发广告。有朋友支招：把入群审核弄严点不就行了？

乍一听很合理。可真要这么搞，我本人先得被审核请求淹没；要是让同事专职把关，他别的活就别干了。而且，就算一道道审，你也不知道对方进来是想聊天还是想打广告。想看他的历史记录？那得找腾讯调数据——这种事也许国安部做得到，反正我是没戏。

发现没有，人在抱怨的时候，常常只想着“该不该办”，压根没算“办起来到底多烧钱”。

其实这毛病，早就有。早些年农民种地要交公粮，把粮食上交国家；后来改成交钱。为啥？因为挨家挨户去收粮食，再一车车拉到国家粮库，那收集费和运输费，比粮食本身还吓人，根本收不起。浙江当年甚至主动提出，农税由省财政代缴，别去农民那儿收了——因为派人去收税的人力开销，比税钱还要多。

公益圈也有类似的事。很多人嫌机构从捐款里抽成，觉得不地道。可把救灾物资、旧衣物送到真正需要的人手上，背后是物流、仓储、人力一整套链条，有时候运费比那堆旧衣服还值钱。

想明白了这点，再看有些服装品牌把库存直接烧掉，也就不意外了——因为捐出去，运输和分发反而烧掉更多钱。我有个朋友开影院，他们的依云水从来不要钱。为啥？那些临期水要正规处理，处理成本高得离谱，品牌方索性免费送人，只要对方肯自己出运费就成。

有人还问过，义乌为啥不出拍立得相纸？评论区一句话点破：那东西太小众，需求就这么点，搞研发开产线，成本高到没边，谁会做亏本买卖？

所以啊，下次想吐槽之前，先停一下，问问自己：我看到的“完美方案”，是不是把一大笔隐形成本给漏掉了？心里装着成本意识再看问题，好多火气，自然就消了。
