# 爆文收益 70w+经验合集——选择对标的基础知识

三个月变现70w+，这位👸号爆文教练把“对标”彻底讲透了

见字如面。

我是越越，这次承担👸号爆文（原创）方向的航海教练工作；同时在 AiGC 生活化项目里，我也是一线实操者。很多人问我：👸号爆文到底能不能复制？我的答案很简单——能，但前提是你得先搞懂“对标”。

过去三个月，我用一个👸号账号持续运营，累计变现超过70万，单月稳定在8万以上。这个成绩不是我凭空想出来的，而是一步一步跑出来的。这一路，我的心态经历了五个阶段：迷茫、崩溃、探索、开窍、创新。刚开始完全不知道往哪使劲，后来怎么写都没量，再后来沉下心一点点抠细节，慢慢找到了感觉，又突然有一天像打通了任督二脉，最后开始尝试自己的风格。

因为自己踩过太多坑，所以我想把“查找对标”的经验整理成一个10万字的合集，分几次发出来。你现在看到的这一篇，就是整个合集的第一个板块——《选择对标的基础知识》，我写了12000多字，读下来大概需要20分钟。内容比较干，强烈建议用电脑端看，体验会好很多。

整个合集我规划了四个主题：先是打好对标的基础知识功底，这一篇就是这个环节；接着是怎么搭建一套对标素材库的SOP；再往后，会聊聊账号（文章）为什么会被别人对标；最后，是被对标后该怎么防范和维权。
