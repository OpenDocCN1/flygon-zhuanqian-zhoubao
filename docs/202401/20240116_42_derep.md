# 职场宝妈 0 基础，通过社群卖家庭教育课程，自卑内耗到 80 天突破月入过万

白天是格子间里埋头赶工的上班族，晚上回家还要无缝切换成带娃模式，中间再夹杂着和婆婆的各种“斗智斗勇”——这是不是很多职场妈妈的日常？

今天想给你介绍一位叫粒晴（sea）的姐妹，30岁那年，她决定不再跟自己较劲，不再用内耗和自卑消耗自己，而是花钱去学习，给自己一个翻盘的机会。

去年4月，她加入了赚钱。她说从那天起，每天都感觉自己在飞快地往前跑。更关键的是，系统学习家庭教育才3个月，就已经拿到了实实在在的成果：用户好评率很高，收入也突破了五位数。

她把这段经历拆成了4个部分，准备毫无保留地分享给同样在观望的圈友：

1. 零基础起步，怎么找到自己的定位；
2. 为什么说家庭教育还是蓝海市场；
3. 从濒临离婚到夫妻关系回暖，孩子也主动爱学习了，中间发生了什么；
4. 手头没有产品，凭什么3个月就能做到月入过万。

她说：“从自卑内耗到月入过万，我只花了80天。我能做到，你也一定可以。”
