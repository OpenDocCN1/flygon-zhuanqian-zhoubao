# 设计师下班做小红书，一年涨粉1.3w、副业月入过万！插画账号变现全复盘

> 来源：生财有术

大家好，我是十一。

去年，我和我的插画师队友一起，把一个小红书插画账号从零做到了1.3w粉丝，月副业收入稳定在1w+。

我们俩目前都处于自由职业状态——我做设计，队友画插画。这个账号，算是我们真正跑通并稳定下来的第一个插画设计类项目。

在这之前，我们也折腾过不少方向，踩过不少坑，总算慢慢摸出了一些门道。所以想把这段经历好好复盘一下。

我知道生财圈子里有不少设计、插画领域的圈友。同行之间其实都懂：我们这类人，动手能力往往不差，但运营偏偏是短板。所以这篇复盘，希望能给大家带来一些参考。

当然，除了做得顺的部分，我们遇到的卡点也一并写出来了。这些内容既能当经验看，也能当避雷指南看，欢迎大家一起交流讨论。

# 账号整体情况

从去年10月到现在，账号累计涨粉1.3w+。

收入来源主要是两个方向：接单＋线上插画课，月均做到了1w+。

# 账号定位与内容

在“账号内容与定位”这件事上，我们总结了四条比较实用的经验。

## 1、内容服从定位：先想清楚怎么变现，再倒推内容方向

这个道理很多做过账号的朋友都说腻了，但现实中我见过太多人（包括曾经的我们自己）完美绕过这个关键步骤。所以还是想再强调一遍：**先明确变现方向，真的非常重要。**

以前我们乱发内容时，脑子里只想着“接单”，但接什么方向的单？画什么内容？完全没概念。再看看那些我们喜欢的插画账号，基本都是创作者自己的日常创作，很好看、很小众、很有艺术感。于是我们也学着随便画，再蹭点热点话题发出去——结果石沉大海，越做越没信心。

后来我们想通了：想变现，就得先把变现方式想明白，然后倒推内容。如果抱着“先涨粉再变现”的念头，我身边无论是个人还是公司，最后都很难做出结果。

设计、插画类的变现路径，市面上比较常见的有三种：**接单、做课、卖资源。**

一开始我们只在“接单”这个方向上试过水，效果不好，于是转念想做课。

做课其实一直是我们想干的事。以前主业忙，这个念头总在脑子里打转，但始终没有真正启动。队友当了多年商业插画师，又是科班出身，底子扎实，讲课这块他挺擅长。

另外要知道，小红书的内容能不能爆，有一定运气成分，但我们能做的，是想办法提高爆的概率。最容易获得点赞收藏的，往往是那种“利他性”很强的干货内容。举个例子：我业余运营一个读书号，发单本书的内容，数据完全不确定；但如果发“某个主题的书单”（比如设计类、哲学入门、摇滚乐相关），因为一眼看去就有用，数据大概率不差。同理，做主题书单就是提高赞藏概率的一个方式。

既然目标变成了做课程，那我们就围绕课程来生产利他内容。变现方向想清楚之后，内容方向也跟着清晰了。

## 2、找到真正适合自己的爆款内容

具体怎么找到「爆款内容」的呢？

一开始我的想法很简单：把课程大纲列出来，照着里面的知识点去拆解、去更新内容就好了。比如五官怎么画、人体比例怎么处理、小动物怎么画……每个主题还可以继续细分出更多内容。

这个方向听上去可行，但对我和队友这种有点懒散的二人组来说，任务量还是太大了😅如果只是专心做一门课，倒还撑得住；可要是边做课边做内容，战线就会拉得很长，更新频率也很难保证。

于是我们开始狂刷内容、做大量调研，很快锁定了一个主题：「适合新手的插画风格推荐」。

具体内容是：推荐和解析一些国外插画师的作品。队友负责找插画师，我负责内容编排和设计——这正好是我作为设计师擅长的事。用心一点的话，日更基本没问题。

这个系列做出来后，利他性很强、画面很美，连我们自己边做边有收获。更妙的是，这个主题天然瞄准了我们想吸引的人群——**插画新手**，顺便还能调研一下大家更喜欢什么风格。

同理，我觉得这个模式或许也能复制到其他行业：把「拆解优秀同行内容」做成自己的内容，既利他、又完成了人群调研，还能顺便积累更新手感。

第一篇发出去就拿到了千赞。发了大概10篇左右的时候，账号涨了几千粉（具体数字记不太清了）。而且因为内容带“解析”属性，偏教学方向，很快就有粉丝主动来问有没有课程。

这算是我们“起号”的一个方式。不能说没有运气成分，但我觉得这个思路确实能提高起号和出爆款的概率。

## 3、用数据反馈倒推教学方向

前面说到了：「适合新手的插画风格推荐」这个系列，本来是冲着插画新手去的，后来变成了我们的“风格调研工具”。

内容的数据反馈非常直观——点赞收藏最多的，往往就是大家最感兴趣的。而大家最感兴趣的风格，就成为我们的教学方向。

这里有一个背景前提：以前我们接的插画、设计大多是商单，属于“甲方给需求，我们照做就行”，风格上什么都能画。但到了自由创作阶段，没有甲方需求之后，“画什么”反而成了难题。而通过做风格解析＋观察用户反馈，就变成了一个很好的锚定方式。

后来根据学员反馈和粉丝评论，我们又逐步加入了一些呼声高的新课程，比如小动物课，以及后续准备上线的小物件课、婚礼插画课等——全都是从反馈里来的。

当然，我们选择积极反馈去行动。至于那些消极的、恶意的、其实除了你自己没人会在意的评论，就别浪费时间理会了。

## 4、更新频率不够，就要有节奏地去宣传

这一点是提醒：当我们没办法产出足够多的内容时，就把内容攒一攒，留到招生期间密集发布。

为什么要单独说这个？因为这恰好是我们的一个短板。

插画设计类创作，短时间内能产出的内容量是很有限的——平时还要上课、还要画稿，真的很难做到日更。

所以我们现在的节奏是：画完先不着急发，平时保持每周两篇，到了招生期再集中日更，换取更多曝光。

# 设计/插画账号的接单方向

我相信大多数设计师、插画师都希望通过公域流量实现接单，但往往苦于不知道从哪开始。

所以也分享一下我们这个账号「接单」的几个方向。

这几个方向陆续跑通后，约稿的作品正好又成为小红书的发布素材——接单反哺内容，内容带来咨询，形成了一个良性循环，还是很省力的。

## 1、婚礼插画

这里必须感谢好伙伴@雪姨！

正好是在我们起号的阶段，雪姨找我给她朋友画了一组「婚礼插画」。我们结合准备教学的风格来创作，效果出乎意料地好。后来发到账号上，拿到了2000+赞。紧接着就有不少人来找我们咨询婚礼插画约稿。

这个市场需求真的很大。咨询者基本是新人自己或买来送朋友的，比起价格他们更在意质量——完全区别于小红书大量低价内卷的市场，舒服多了。

## 2、公司员工头像

另一个方向，也是雪姨帮忙介绍的生财伙伴：为某个公司的员工画定制头像，当作礼物送给团队（这样的领导和公司氛围也太让人羡慕了吧）。

这条内容在小红书拿到了6000+赞，还带来了一大波“有没有头像课”的咨询。

之后这类约稿也一直没断过。除了公司之外，也有不少个人来找我们定制“对公头像”。这个需求有些意外，但仔细一想又很合理——当大家换上属于自己的职业属性插画头像后我们发现，比起千篇一律的职业照，这种头像真的辨识度拉满！

## 3、红包封面

红包封面属于定制需求，加上有时效性（又碰上了过年），所以我们没有大范围在小红书宣传。但去年春节期间确实画了一些，现在又快过年了，正好可以给大家参考一下。

那段时间我们开始帮朋友定制红包封面，刚好赶上了视频号赠额的活动，今年可能还有，大家可以留意一下。

我们提供了「动态涂鸦」和「人物插画」两种风格，并针对兔年主题给出了可选文案和操作步骤。

视频号发红包封面的引流效果特别好，所以需求肯定不缺。我们没有在公域做宣传，基本靠朋友转介绍。就这样比较佛系地接，春节期间也画了十来个红包封面。

红包封面的实操，生财里有很多厉害的帖子，从前年到今年我一直都在追！非常推荐大家去做。这算是极其适合设计师、插画师尝试的“定制接单”项目：需求大、反馈快，也是很好的拓客和引流机会。

## 4、宠物插画

宠物插画这个需求，是从婚礼插画里延伸出来的。

找我们画婚礼插画的新人，很多会把自家毛孩子也放进画面里。这之后，陆陆续续有粉丝和学员说“小动物画得太可爱了”“我不会画小动物”，还有人提议我们开一门小动物插画课。

一切水到渠成，我们开始发布小动物题材的作品，最近也慢慢接到了宠物插画的单子。

后来发现，来约稿的人几乎都是自家狗子猫猫的忠实记录者，画完头像还会印卡片、做小徽章等周边。这个方向不仅意义感很强，而且复购率和转介绍比例都很高——我们画着也开心，毕竟自己也是动物爱好者。

# 转化与报价

以上是我们在公域/私域接单的几个主要方向。当然也有一些相对低频的需求，比如全家福、活动海报、动漫及艺人周边等，这里就不一一展开了。

下面分享一下目前的项目报价，仅供大家参考——如果要自己做，还是建议根据时间成本和预期收益来定。

我们平时“主业”以商单为主，报价是对公的。比如设计一张海报平均报价四五千。对方之所以愿意出这个预算，是因为商业插画有商业价值——要用于宣传、要露出、要延展。

但同样的报价放到小红书、放到个人单上就不适用了。毕竟个人约稿多为自用，尺度完全不同。

小红书上整体报价对商业插画/设计师来说偏低，但也有一个好处：接稿自由。约稿是一个双向选择的过程，能来找你的基本都是看中了你风格的人，沟通起来顺畅很多。

我们最终调整的价位，大概在接公司商单的1/4到1/3之间。大家也可以结合自己的商稿报价来定。

### 1、接稿方向及报价如下

婚礼插画（或任意双人情侣图）：半身400，全身600

个人头像：200/人

红包封面：200

宠物插画：50-100/张

### 2、课程报价：目前共三个档位

**① 录播课：99元**

长期招生。课程共10节，一次性打包给学员，配套留10张作业。作业点评以直播形式完成，每周1-2次，每次约2小时。

**② 短期直播课：199元**

包含头像、小动物等专项训练，课程时长在一个月以内。包含大约10-12次直播＋每周1-2次点评，同样每次2小时左右。

**③ 年课：549元**

为期一年的综合训练。每月设定一个主题，第一周上三节直播课，剩下三周用来布置作业和点评。点评直播频率大约一周一次。

这三个档的课程，定价放在市面上算是偏低的。第一年做课，说实话心里没底，不敢定高价。但经过一年的打磨，我们对自己的课程越来越有信心——教学上确实是掏心窝子在做。加上咨询了不少经常报课的学员建议，之后都会适当涨价。

### 3、转化数据

我们正式启动招生和接稿是今年3月份，到年底刚好9个月。这段时间账号月均收入稳定在1w+。

具体来说：专门用于约稿和招生的微信小号目前加了三百多人。因为都是从小红书询价后才加过来的，基本属于“确认要下单”的精准用户，加微信后的下单率约80%。课程＋约稿均价在400左右。

# 卡点与避雷

这个账号目前作为副业来讲，还是比较合适的——做的是自己擅长的领域，基本在舒适圈内。

但最近确实也卡在这里了，加上中途遇到过不少小问题，一并分享出来。一方面给大家提个醒，另一方面也希望寻求一些新解法，欢迎一起讨论。

## 第一个卡点：过度依赖小红书平台

目前我们90%的转化，都来源于小红书。

但小红书的流量，是不太稳定的。前期起号阶段流量很好，但从双十一直到现在，流量一直在明显下滑。

把所有希望寄托在一个平台上，很容易陷入焦虑。而且从小红书引流到微信本身就存在风险。

我们目前的打算是：做两个小号来分流内容——一个号以教学视频为主，同步分发到抖音和视频号；另一个小号专门做客服和招生。

## 第二个卡点：教学平台不稳定（CCTALK）

最开始选CCTALK，是因为它的操作和教学流程确实顺滑，最适合我们的课程。再加上很多有名气的插画师都在上面开课，当时虽然已经有点传言，但天真地以为“这么多大V都在，应该不至于”。

事实证明我们还是太天真了……刚入驻没多久就碰上大家网传的那些问题：提现困难、客服失联。一次结算到提现基本要一个多月——还是在不间断催客服、尝试举报的前提下。所以上了两个月后果断转战。

目前我们改用【企业微信】直播，配合【知识星球】布置作业，整体用下来很顺畅。

但企业微信也有个小插曲：用了一段时间后微盘内存满了，只有认证企业才能扩容，前后又折腾了一个多月。在认证通过之前，我们不得不把所有视频重新压缩上传一遍，极限利用微盘空间。好在赶在新课开启前顺利解决，否则又得让大家换平台看课，很影响学员体验。

## 第三个卡点：线下化的目标

我们希望在明年实现课程线下化：做成“画室＋工作室”的综合模式。

原因有三：

第一，线上教学客单价低。想要做高客单价课程，需要更长的打磨周期和更强的团队运营能力，目前我们二人小团队很难承载。而线下课客单价天然高出一截，教学内容也能更专业、更体系化——这正是我们擅长的。

第二，弥补线上流量问题。线下可以打开多种引流渠道（除了小红书抖音，还想做美团点评、线下活动等）。

而且现在的线下课基本集中在晚上和周末，白天的时间都是闲置的。做线下能把白天更充分地利用起来。

第三，因为主业是商业插画＋设计，我们也想有一个固定的场地，承载更多创作的可能性。

当然，这背后又面临很多新挑战：开店预算、场地选择、装修、店铺的运营宣传……预计要花上小半年来准备。如果真启动的话，希望到时候也能分享出来。

# 总结

为什么想写这篇复盘？

因为我深深感受到，身在设计、插画这个行业，确实是一个“可能性很多、困惑也很多”的过程。

很多人都想做自己想做的创作，但不知道从哪里开始，或者不知道怎么变现。

我们之前也试过很多方向：做潮玩、做动画、做周边，都没做成。回过头来看，多半卡在：时间成本太高、对市场了解不足、不够坚持、以及正反馈不够。

兜兜转转摸索了这么久，终于跑通了一个成型的项目。

这个项目有做得顺的部分，也有很多不足的地方。所以分享出来，希望能带来一点点启发，更欢迎大家一起来讨论。

这也是我潜水这么久，第一次在生财发文章，算是 i 人一个年终小突破吧。
