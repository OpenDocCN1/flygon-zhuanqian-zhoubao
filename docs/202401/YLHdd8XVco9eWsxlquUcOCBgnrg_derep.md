# 不会ps也可以：🛰️红包助力-👸号引流

👸号年度报告最近刷屏了，刚好我的手头红包项目也在推进中——这不就是现成的粉丝福利嘛，直接安排上。

![](img/f10bf73641475afaada352d2e5ab0700.png)

先说说平台。🛰️红包开放平台注册非常方便，几乎没什么门槛，强烈建议有👸号的朋友都去试试。最需要注意的是封面图规范，尺寸、大小都要照着要求来，别踩坑。

![](img/307311d9094c8f9ceb4bf0046dcf0c8d.png)

封面图怎么搞？现在AI生图工具太多了，我还在用老牌选手Midjourney。当然你也可以选吐司、创客贴这类平台，哪个顺手用哪个，完全没问题。

![](img/e5502bc4ab93e3f056c0d406f1eecee4.png)

把图调好、简单裁剪之后，就可以传到红包开放平台。上传完系统会自动展示效果图，最终什么样一目了然。

![](img/edaa66d2ee05346269d31c5bb6cbe0a2.png)

再说证明材料，AI作图这块儿现在很宽松，直接把生成的原始图片传上去就完事儿；如果材料比较多，记得先压缩成一个压缩包。

![](img/1df28eedb43b99b0bb84217d5c953c4f.png)

证明传完，提交审核就行，剩下的就是等待通过。

![](img/cbbc05c542483ffc9215d75d656bd956.png)

最后是引流这步。设置好领取时间段，用户只要关注你的👸号，到时候来领就行。序列号除了放👸号文章，抖音、📕这些平台也都可以铺开。毕竟“有便宜不占白不占”，冲着免费红包来的人，一定会很多。
