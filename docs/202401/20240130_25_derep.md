# 📕电商选品：这 5 种打法我真的在用



## 5 种适合📕电商的选品方法

作者：古辛
日期：2024-01-23

给📕做选品的实战笔记，方法都是我自己在跑，拿去用挺顺手的！

家人们好，我是龙哥，选品是我常做的事。上次我把抖音的选品思路整理出来，写了好几千字，没想到有伙伴反馈说干货感不够，有点小尴尬，不过也挺有动力。这次我把团队正在用的📕选品打法整理出来了，希望对也在做📕的兄弟姐妹有用，也别再翻车了，来试试。

先说个前提，📕本质是种草社区，平台确实有分发推荐，但和抖音比起来并不算那么精准。所以照搬刷抖音找爆款的方式来做📕选品，很容易事倍功半，效率会掉很多。

真正跑得快的做法，其实是把淘宝选品的逻辑搬过来，用在📕上。具体就是在📕里直接搜核心关键词来筛品。选关键词的时候有个小原则：优先锁定女性相关的刚需，其次可以考虑母婴儿童类，最忌讳一上来就去碰男性强相关品类。
