# ('一篇微头条赚 1100，一篇图文 300-2000', (2, 27))

你可能想不到，在头条号上写微头条和图文，也能闷声赚到钱。有人一篇微头条就拿到1100元，一篇图文也能稳定收获300到2000元。

比起公众号偶尔的“爆款神话”，头条号确实没有那种一夜炸裂的爆发力。但它也有自己的好处：对新手极其友好，不用天天担心“入池出池”的过山车式流量波动。头条的阅读量更平稳，更像一条缓坡，而不是陡峭的过山车。

正因为这样，头条号特别适合刚入门的写作者，也能当作公众号创作之外的补充渠道，两边一起发力，收入更立体。
