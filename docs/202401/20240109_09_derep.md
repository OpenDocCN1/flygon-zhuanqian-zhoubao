# Mac 用户想跑 RPA？不用买新电脑，这个云电脑方案免费又省事

这期 RPA 航海刚开营，社群里就有不少拿 Mac 当主力机的朋友被卡住了。uibot 没有对应 Mac 版本，影刀倒是有 Mac 版，可功能跟稳定性，和 Windows 版一比还是要逊色一截。

眼下临时买台 Win 电脑，加上物流要好几天；装双系统或者搞个虚拟机，又麻烦得很。那 Mac 用户到底怎样才能低成本、顺滑地开始玩 RPA 呢？

我自己也是在换了 Mac 之后才找到的路子——阿里云无影云电脑，免费而且上手快，主要有这几点好处：

1. 新用户能免费用三个月，总共 800 小时时长，足够学完 RPA 入门内容。
2. 相比其他云电脑，它的 Windows 环境更接近本地操作体验，环境配置几乎不用操心。
3. 有专门的 Mac 客户端，连上就能用，特别顺手。
4. 免费期结束后，199 元就能续一年，花费很亲民。

其实这个思路对 Windows 用户同样适用。云端配置好了以后，不会占用本机资源，随时都能远程连过去。如果你那台 Win 电脑要么带不动、要么冒出一堆奇怪毛病，也可以先靠云电脑救急，把技术学起来再说，没必要卡在环境配置那一步浪费时间。
