# 97 年草根离职创业一年月收 10 万的 16 点方法论总结
作者：龙哥

一位97年的草根创业者，2022年离职后自己单干，短短一年时间做到了月入十万。他叫刘掌柜，笔名铁柱。最近，他把这一路的经验浓缩成了16条方法论，在圈子里刷了一波关注。

去年8月，他凭借抖音餐饮招商的实操分享拿下了一颗龙珠；临近年关，他又从公域流量、私域流量、创业认知、心理建设和个人成长几个方向，整理出16条心得，拿出来与同行交流。

他的自我介绍很简单：97年草根，专注做流量生意。目前手上有三块自营业务——餐饮招商、情感、国学。餐饮招商业务2022年10月启动，第二个月毛利润就达到100多万，单日客户咨询量最高冲到500-600条；国学业务2023年6月启动，单日涨粉300；情感业务2023年9月启动，单日涨粉100。眼下，情感和国学这两块业务的净利润合计在8万元左右。
