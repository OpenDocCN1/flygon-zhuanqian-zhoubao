# 穿袜子还是先套裤子？从一件小事说开商业的效率逻辑

效率这件事，往往藏在最不起眼的细节里。

有人说商业的本质是什么？归结起来，就是把成本压到最低，把产出做到最高。谁最终能笑到最后，靠的不是一时的灵光，而是整体运转比对手更顺溜。

你看苹果。大家总以为苹果靠的是设计和创意，其实它的执行力才是地基。门店的标准流程已经做到极致，前线员工的评判标准几乎全在执行是否到位。真正的创意输出，其实集中在极少数核心团队里。

餐饮行业对效率的敏感度更高。

麦当劳、肯德基这类巨头，为什么拼命推一次性餐具？不是图省事，是省时间。碗不用洗，盘不用刷，服务员就能把更多时间花在翻台上。甚至有人总结过，中国的万店连锁品牌，都在用各种方法让“刷碗”这件事消失。

上周我到宁波，和星平鸡饭的创始人边吃边聊效率。聊着聊着就聊到碗碟。一张四人桌吃一顿，骨碟、小碗、饭碗、菜碟加起来二十多件，还不算甜品饮料的器皿，全要上桌全要回收。怎么减负？他们直接把一天八次翻台所需的骨碟，事先放进餐桌的抽屉里。服务员不用跑后厨去取，抬手就能上。省下半分钟，客单就能再多转一轮。

快餐就是在和时间赛跑。点菜、就餐、结账，每一个环节挤出三十秒，一天下来多接一桌客人就是真金白银。萨莉亚的服务员不上托盘，听起来不专业，算下来反而更快。省去把菜放托盘再取下来的动作，整体上菜节奏更稳。

省钱的打法也花样百出。

日本餐饮大量用临时工和钟点工，本质是把固定的人力成本拆成可变的。正式员工要五险一金，还要解决住宿，在北上这种高租金城市，这笔开销非常重。有人说萨莉亚一家店二十个岗位里十六个是钟点工。成本是降下来了，但要保证出品稳定、服务不掉链子，就必须有一套极其成熟的SOP和排班体系，这套体系本身才是护城河。

盒马的烘焙工厂把生产挪到夜里跑，理由简单：夜间的错峰电便宜。揉面、发酵、整形这些重复动作基本交给自动化设备和机器人，人工只负责最后的衔接。

椒爱水煮鱼门店多，活鱼现杀是卖点，但切片这一步现在用机器完成，过去三个厨师干一早上的活，现在几分钟搞定。

古茗早几年就开始研发自动调饮设备，现在奶茶行业很多手工环节已经可以机器化，摇杯、封口、配料都可以标准化。烘焙行业也是，现烤的口感要保留，但面团在中央厨房提前醒发冷冻，到店里只剩造型和烘焙两步。

甚至建筑工地也在优化。把泥瓦匠的泥水托盘垫高到胸前取物高度，减少弯腰次数，动作效率立刻提升好几个档次。

一位做中式点心的老板曾苦笑说，隔壁同行打包蛋糕的速度就是比我们快，我们怎么都学不会。这句话点醒了很多人：任何行业、任何流程，只要留心，总能找到让成本更低、时间更短、动作更省力的办法。

说到底，效率就是对动作多余部分的不断剔除。

最后回到那个看起来很闲的问题。早上起床穿裤子，你是先穿袜子再套裤子快，还是先套裤子再穿袜子更省劲？

评论区已经吵翻了。有的人说先穿袜子，穿上裤子就能直接下地，省了一次起身坐下的往复；冬天更要先穿，不然秋裤穿起来会缩。也有人说先穿裤子更顺手，穿袜子再穿鞋的弯腰动作同样要算进去。

其实答案因人而异，但思路一致：把一天 N 次重复的微小动作拆解出来，找到最省一次动作的顺序，就是效率。
