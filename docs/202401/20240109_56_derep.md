# 直播间看了10分钟就下单499元，这个数学思维课凭什么跑出4000W+？

最近教育圈有个项目特别值得关注：北辰做的K12升学规划方向，主推数学思维课，卖爆了。

一个很直观的场景是：有朋友刷到广告后点进直播间，本来只是随便看看，结果10分钟内就付了499元。

数据层面更夸张。抖音单场直播的场观能做到15万到20万，单场销售额落在75万到100万。本来以为抖音已经够猛了，结果视频号的数据比抖音还要再高一截。

现在这个项目不只在抖音和视频号播，百度视频也在同步开播，快手、小红书、B站也都有布局，基本把主流流量平台都覆盖了一遍。

最让人意外的是速度。项目从2022年8月启动，5个月不到，课程累计GMV就冲过了4000万元。

回过头看，核心打法很清楚：切入的是K12升学规划这个大需求，用数学思维课做产品，然后精准锁定付费意愿和付费能力都极高的群体——一二线城市、31到40岁的中产家庭，尤其是那些重视教育的精致妈妈。

这波操作，算是把升学焦虑和数学思维的需求，真正变成了真金白银。接下来的问题就是：这个路径还能复制到哪些细分赛道？
