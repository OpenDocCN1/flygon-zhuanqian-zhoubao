# 一个刚跑通的千万级利润方向：用短视频教培给企业输送人才
作者：龙哥

先说结论，我花了两个多月才把这个盘子搭起来，现在才刚刚起步落地。趁着手感还在，马上把思路拆给你。

这次做的不是给网赚玩家卖副业课，而是做 **短视频运营培训就业**。简单说就是招收职场人群，教他们自媒体运营、视频剪辑、账号操盘，然后直接对接企业做就业输送。

用户画像和之前那些创业副业课完全不一样，这是给需要找工作的年轻人做职业技能培训。

目前的收费标准定在 **5000 元/人**。交付方式是 **线下 7 天集中运营大课 + 线上 30 天陪跑辅导**，保证学完能上手。

进展到现在，口头报名的有 43 个，已交定金的 16 个。达到 20 人就能开第一期试点课，现在算是刚起步。
