# 一个月在印尼搭起十人本地直播团队，我的实操复盘

> 原文：[`www.yuque.com/for_lazy/thfiu8/lgrs2pirc3s592x2`](https://www.yuque.com/for_lazy/thfiu8/lgrs2pirc3s592x2)

出海这件事这几年已经迭代了好几轮。从早年的外商来国内采购，到中国商家把货卖出去，再到如今的整条供应链搬到海外。到了供应链出海3.0这个阶段，越来越多团队选择肉身过去，在当地建人。

我刚在印尼落地了一个Tiktok直播运营组。从落地雅加达到团队能正常开播，总共花了31天。带过去两名同事，其余全是当地招的。过程中有顺畅的地方，也有踩坑的地方，这里把经验摊开说，或许能给正在考虑海外建队的朋友一些参考。

### 先想清楚建队的逻辑，不然别去

在海外组建团队，比国内重得多。配套不全、规则不清、文化差异摆在那里。即便有当地伙伴牵线，也建议把整体成本按年算。遇到突发情况才不会崩盘。2023年印尼封了Tiktok，一夜之间倒了一批MCN，复盘下来基本都是当年冲进去搏一波的，长期主义的团队多半扛过来了。

所以要去就必须有清晰的本地化理由。我的理由很简单：做印尼语直播，国内招不到合适的人。这就值得落地。

但也不是所有事都值得落地。比如为了省2块钱海外仓费，自己去当地建仓，到底值不值，还要盘一盘，有没有可能直接在当地找2块钱的供应商。不同国家也各有门道，玩得转东南亚不代表能玩美国。资源有限就一次打透一个国家，别刚到德国就想着以此为枢纽辐射欧洲。

### 我的落地时间线和关键动作

12月5日晚上到印尼
12月6日拿房、拿办公室钥匙
12月7日开始办公
12月27日第一位本地员工入职
1月3日主播和中控到位开始试播
1月5日起本地员工稳定在10人左右：2个人事、6名主播+中控、2名KOL专员，后续还在扩。

能快起来，我觉得这几件事做对了。

**出发前先跟早鸟取经**
出发前我花了不少时间去对接已经待了几年的老团队，把他们踩过的坑都问了一遍。成功经验可能已经过时，但避坑清单是通用的。海关怎么解手机锁、怎么跟移民局打交道、哪家网不行，这些细节能省下大把时间金钱。也是因为提前沟通，办公室、住宿、设备落地前就准备好了。

**能提前确认的就别拖到当地**
办公和住宿：提前找中介或朋友帮忙看房，让对方视频确认面积租金。上头过一个案例，疫情期间人没到印尼就把5000平仓库租下运转起来了。夸张点的浙江老板，人还在国内就花了上百万美金在印尼建厂。

水电网络和部分设备：最好让中介提前搞定，别到现场傻等。跟同行拼租或转租更省事，之前的团队已经把个性化需求解决好了。设备方面，印尼买不了的高端麦、转接线从国内随身带划算；低端手机电脑当地买；灯具这种运费高的就地买。

公司注册：强烈建议出发前办好。XHS上、朋友圈里代办资源很多。到了再办要等很久，工作签也会被拖住。

招聘渠道：这是我最大的失误。想着到了再找，结果招聘网站开账号等了一周。这周除了补设备，基本在空转。本地业务靠本地人驱动，没有本地人什么都转不动。

**第一个招的一定是人事**
人事在海外几乎等于招聘引擎。招人速度和质量直接取决于人事。印尼我按朋友建议超配了人事数量。后来发现，很多团队的第一位本地人事，最后都成了业务骨干。

**工作语言怎么选**
我们内部统一用英语。会议、汇报、文档、即时通讯全英文。

其他团队常见做法有：老板配个中印翻译，员工用印尼语；管理层一人配一个翻译；大量招华人。总的来说我们选英语有几个考量：

团队本身有一定英文基础，虽然不地道，但沟通够用；
英语在印尼是筛选器，英语好的候选人通常综合能力更强；
避免过度依赖翻译导致管理失控。见过朋友公司翻译变二把手，制造很多矛盾；
最关键是省钱省时间。懂中文的印尼人稀缺且贵，放宽到英文，人才池立刻大很多。道理跟在国内招印尼语人才一样稀缺。

当然这不是唯一解，不同国家情况不同，要结合当地实际。

### 复盘踩过的坑

**时间预估不准**
等招聘网站一周是完全可以避免的。国内微信一喊人就到，印尼从签约到开户用了整整7天。提前跟本地团队打好招呼就能开通。

另外12月圣诞新年假期连着，很多候选人直接放假后再来面试。好比国内春节前开公司，节奏全乱。节假日一定要算进排期。

**签证细节大意**
印尼工作签的办公地址和住宿地址必须真实。我们一开始用了虚拟地址办签和营业执照，落地后再改，人均多花了2000人民币。头一次就把真实地址定好能省一笔。

签证类型上，旅游签、商务签变相工作在东南亚、美国都很常见，风险自担。关键是看当地查得严不严，自己做风控。

**产品和运营节奏脱节**
这个坑最大。产品组在国内，运营组在印尼，时间表没对齐。过去才发现没货可播。跨境备货以月计，代工以季计，前后端不同步会直接停摆。

### 最后说一句

海外成建制落地还在不断试错中。2024年我们计划在俄罗斯、德国等市场再起团队做电商，欢迎在海外已落地的朋友交流互通资源。
