# 心理疗愈师「迅速成事」的 4 大系统，缺一不可
作者：龙哥

你有没有发现，很多心理疗愈师赚不到钱，其实不是专业水平不行？

我混迹在好几个心理咨询师的社群里，见过各种背景的同行：科班的、非科班的、半路转行的、已经做了十几年的，都有。

最让我印象深刻的，是一位复旦心理学硕士。她做心理咨询整整十年，却始终没能实现高收入。她在一家平台接单，每天工作八小时，一个月到手也就一万出头。一旦离开平台，收入立刻归零。

问题出在哪儿？不是能力，不是资历，而是缺了一套完整的“成事系统”。想快速做出成绩，这四大系统缺一不可——具体是哪四大，这里就不展开了。


希望能帮到正在埋头努力、却始终没突破收入瓶颈的你。
