# 红包开放平台

注册门槛很低，强烈建议感兴趣的都去开一个账号。

重点要看清楚封面素材的规范，比如长宽比例、文件大小这些细节。

![](img/d89845f4eeb7228b617245fcd5626aa3.png)

# 借助 AI 出图

目前能生成图片的 AI 产品非常多，我个人还是习惯用老牌的 MJ 来制作。你也可以试试吐司、创客贴这类在线设计平台。

![](img/f65957cb9314a5f0ae6a17d4bc89a868.png)

把画面裁切好以后，就能直接传到红包开放平台系统里，系统会自动预览效果。

![](img/f7574a12d8a8844475d75149fa2a25b8.png)

# 资质证明

现在 AI 作品的证明材料很简单，直接把生成的原图附上即可。

也就是把这张图原样上传上去。

![](img/f65957cb9314a5f0ae6a17d4bc89a868.png)

# 提交审核

证明材料上传完毕就可以点提交审核了。

如果材料比较多，记得先打包成 zip 再上传。

![](img/2fae2d53c7b3009dbe67dbc603f6fd18.png)

# 引流逻辑

把红包的领取时间往后延，用户为了准时到账自然会先关注你的👸号，到点再来领。

而兑换码或者序列号可以分发在👸号推文、抖音、📕等渠道上。毕竟白嫖福利，参与度通常不会低。

![](img/2b71b71edf9f4a8651ab87c382688f12.png)
