# 无止境追求金钱的过程就是追求毁灭的过程
作者：龙哥

你有没有发现，身边越来越多人把“搞钱”当成唯一信仰？仿佛只要卡里的数字一直在涨，人生就没有白活。

但有一个观点值得停下来读三遍：一个人若是把赚钱变成没有终点的竞赛，那这场竞赛的尽头，大概率不是财富自由，而是自我毁灭。更扎心的是，当财富积累突破某个临界点之后，哪怕所有钱都来路正、看得清、晒得明，拥有者依然会被公众毫不犹豫地划到“对面”去。

为什么？

先聊第一层。无止境地追钱，本质上不是追求“够用”，而是追求“更多”。这个念头一旦启动，就是个无底洞——你会拿健康去换业绩，拿关系去换资源，拿睡眠去换机会。到最后，钱是越来越多，可那个会笑、会累、会爱的人却越来越模糊。这难道不是一种缓慢的毁灭吗？

再聊第二层。很多人觉得“只要我的钱干净，别人就没理由讨厌我”。可现实是，当一个人的财富量级大到足以影响环境、市场、规则时，民众对你的感知就不再是“这个人挺有钱”，而是“我和他之间隔着一道淌不过去的河”。哪怕财富的源头是合法经营、是天赋才华、是时代红利，那种无形的压迫感依然存在。大众仇视的往往不是你赚钱的方式，而是你那种“已经拥有了太多”的事实。

所以那位读者问“没懂这句话”，其实可以这样想：你身边如果有个人天天只想着赚更多，你迟早会远离他，因为他变得不像人了；而你身边如果有个人富到能左右你生活的方方面面，你也会本能地警惕他，哪怕他是个公认的好人。

这就是那句话的真相：追钱追到忘了人的边界，毁灭就开始；富到触碰到社会的边界，敌意就随之而来。

赚钱没问题，向往更好也没问题。但别让追逐变成失速的狂奔，也别让财富变成与众人隔绝的高墙。或许，这才是这段话想提醒我们的东西。
