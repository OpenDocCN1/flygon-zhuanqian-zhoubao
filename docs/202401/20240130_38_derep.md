# 2024 跨境出海：亚马逊和 Temu，到底该怎么选？
作者：龙哥

最近打开朋友圈，几乎被 Temu 卖家和第三方服务商的“晒单”刷屏——爆仓、售罄、销量翻倍的消息一条接一条，看得人难免心痒。

趁着旺季落幕、手头稍微清闲下来的空档，我决定抽时间把这股热潮仔细琢磨一番。

这段时间，找我聊天的卖家不少，问得最多的就是同一个问题：要不要换个赛道，去新型平台搏一搏？

每次被问到，我的答案都很统一：不看好。

为什么这么笃定？今天我就从跨境电商的大环境说起，带大家把局势捋一遍、把思路理清晰。

其实，不管你是刚进场的新手，还是已经做出过亿体量的成熟卖家，做任何战略层面的决定，都不能只盯着眼前的热闹。正确的打开方式是：先看清整体走向，再回到自身处境做判断。

所以，接下来我会沿着“宏观到微观、全球到个体”这条线，把自己对“新型平台到底值不值得做”的真实看法，完完整整地聊给你听。
