# ('公众号爆文核心逻辑分享', (2, 13))

为什么你辛辛苦苦写好的公众号文章，发出去却没什么水花？最近和不少圈友交流时发现，很多人都陷在细节里反复打磨，越做越迷茫。其实，问题很可能不是内容不够好，而是对整个项目的底层逻辑还缺一张完整地图。

这篇文章就是来帮你把地图拼齐的。作者毛韩在一次航海带教过程中，看到大家容易钻牛角尖，于是干脆把公众号爆文的运行逻辑拆成了两大部分：第一部分是核心公式拆解，第二部分是常见问题答疑。

先说说那个核心公式。如果公众号爆文真的有规律可循，大概可以压缩成一个公式，里面包含了五个关键变量，每个变量都卡在阅读链路的不同环节上：

领域选得对不对，决定了你能不能找到潜在读者群；
信息增量够不够，决定了平台会不会额外给你推荐；
选题和标题好不好，直接决定用户愿不愿意点进来；
内容质量高不高，则牢牢控制着完读率和跳出率。

你看，每一环都环环相扣，缺了哪一步，爆文都可能和你擦肩而过。当然，公式里的更多细节和操作思路，作者也整理得很清楚，完整版可以看飞书文档：
