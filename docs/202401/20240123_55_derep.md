# 赚钱商学院，能否成为10倍增长的破局点？

刚刚过去的北京航海家路演，让我对赚钱的战略方向有了新的认识。龙哥在现场分享了不少干货，特别强调了一个核心能力——赚钱的运营始终围绕社群展开，用“内容+实战+链接”的组合拳来交付价值。这种模式带来的结果很亮眼：口碑、续费率、交付体验，都不逊色于那些靠重人力堆起来的在线教育公司。当然，因为行业和模式的不同，体量上暂时还比不过它们。

路演结束后，我脑子里一直盘旋一个问题：如果赚钱在守住自身优势的同时，借鉴在线教育公司的成长路径和组织架构，能否把体量做到10倍？带着这个疑问，我结合自己的经验做了一次大胆的脑洞，仔细推演了这种可能性的成色。

这篇文章会重点拆解几块硬骨头：在线教育公司怎么建销转体系，怎么通过转介绍拉新，交付体系如何设计，以及什么样的组织模式能撑起这些环节。同时，我也会把这几套子系统的账算清楚。全文一万多字，感兴趣的圈友欢迎进来慢慢看，也请赚钱的伙伴们多指点。
