# 想把事业做大的创业者，牢牢抓住这三股劲

想成大事的人，往往不是单靠运气或点子。真正能走远的创业者，身上都藏着三股相互咬合的力量：身体的耐力、精神的定力、以及前行的动力。少了任何一环，路都会走偏。

**第一股劲，是扛得住的体力。**

创业不是温室里的细活，而是反复在大浪里被拍打的过程。一次次的危机、翻盘、重来，既是考验也是锻造。个人在这样的烈火里磨出了韧性，团队和公司也在这样的压力下被淬得更硬更稳。能扛住“大火”的人，自己的筋骨才够用。

**第二股劲，是收得住的心力。**

心一散，勇士也会退缩；心一聚，弱者也能发力。好钢材要靠火来淬，人心也要靠事来磨。把注意力从杂乱处收回，集中在核心一件事上，心力才不会涣散。心定了，判断才准，步子才稳。

**第三股劲，是走得远的愿力。**

一个团队的掌舵者，不一定是技能最顶尖的那个，但一定是愿力最强的那个。认知决定了你能看见多远的风景，而愿力决定了你能不能真正走到那片风景里。愿力就是方向感，是在无路时仍愿意开路的执念。

岁月很长，人生很重。所有积累的福报，其实都落在心念的那一寸空间里。

心念一起，愿力便生，万物随之生长。

何为正道？向内求，从心起。

带着敬畏走路，才是生命的正途。
