# 2024年TikTok卖家生存指南：把方向搞对，比埋头努力更重要

最近和TikTok圈里的朋友聊天，大家有个共同的感受：这行做久了，真的不能一套打法用到底。平台在变，风向在变，只有让自己也跟着变，才有可能吃到下一波红利。

有意思的是，不少亚马逊卖家跑来咨询时，问得最多的还是“怎么找达人”“怎么投广告”这类执行层面的东西。至于大方向对不对、市场该怎么选、节奏怎么踩，反而很少有人真正想过。

我自己带电商团队，2023年重点打美区，拿到了一些官方认可的成绩。但到了2024年，我们也会调整打法和策略。今天就把我的思考路径拆开讲讲，算是给同行们做个参考。

TikTok电商目前主要分两种经营模式：POP自营商家和全托管商家。如果按市场分，就是北美、东南亚、中东、欧洲。这篇文章先聊POP商家在各市场的机会，再说全托管在2024年还剩多少红利。

## 一、POP商家该怎么选市场

先说东南亚。过去一年，TikTok东南亚的市场规模是在稳步涨的，但2023年10月印尼那场关停风波，虽然现在换了方式重新开放，却暴露了不少隐患。所以2024年东南亚不太可能像美国那样猛涨，我预计上半年增速不会超过30%。

那普通卖家在东南亚还有机会吗？我的看法是：如果你的供应链优势不够强，别轻易进。现在能在东南亚赚到钱的商家，要么产品门槛够高，要么有Shopee/Lazada的底子，要么直接在本土有工厂和货盘。这个市场太吃供应链，普通人挤进去，大概率是被卷死。

英国市场反而是个突破点。大家都盯着美区，英国被冷落，冷落就代表竞争少，竞争少就能用有限的流量做出看得见的利润。我学员里已经有人从美区转向英区，用“自营+全托管货盘+达人带货”的组合，最近数据涨得不错。如果你有TikTok运营基础、又觉得美区太挤，英国值得认真考虑。

再说美国。大家都知道，2024年美区电商的GMV目标要翻10倍。乍一听像开玩笑，但看看现在的GPM、电商内容占比、商业化流量和直播比例，你会发现这个目标不是拍脑袋定的。

## 二、2024年美区POP商家的核心打法

现在美区电商大盘的成交额分布，从内容来源看，达人内容贡献了六到七成，商家自己拍的短视频和直播间加起来还不到两成。从内容形式看，短视频占了约65%，直播只有15%左右。两下一结合，答案就很明显：现阶段最该做的就是达人短视频。

但这里有两个麻烦。

第一，商家一窝蜂去找达人，达人已经不够用了。建联工具越来越多，邀约邮件满天飞，达人每天早上醒来邮箱里都是99+信息，你的合作邀约凭什么被点开？

第二，达人合作周期太长。从发邮件、谈合作、拍视频到发布，二十到三十天就没了。测品效率极低，万一这个品没跑出来，时间和人力全都打水漂。

怎么破？最简单的思路是：让产品链接的销量数据快速涨起来，在达人邮箱里脱颖而出。而除了刷单，最快起量、也最合规的方式，就是商业广告投放。测品也一样，与其靠自营短视频或直播慢慢试，不如直接用商业化广告快速验证。

事实上，2024年美区在电商商业化这块会爆发。团队在扩张、市场规模在涨、大盘ROI也撑得住，商业化流量就是巨大的机会窗口。

所以，我们2024年上半年的打法很清晰：用“短视频+商业化广告”快速测品，同时把链接销量拉起来，测通之后再去找达人做红人营销，把销量进一步放大。达人产出的那种原生感短视频素材，再拿去投商业化广告，效果还能再上一截。这样从0到1推一个品，就形成了一个正循环：既吃到了商业化增长的红利，又提升了达人建联的回应率，测品效率也更快。

但下半年就不能这么干了。

美区电商绕不开用户体验，而用户体验里最关键的就是履约时效。所以本土备货是板上钉钉的趋势，别指望虚拟仓或者跨境发货能长久。

一旦要本土备货，就得提前做备货计划。备货计划需要相对稳定的销量，稳定销量需要相对稳定的流量。TikTok短视频的流量波动很大，直播反而更稳。

现在美区GMV六成以上靠短视频，直播不到两成，这对平台和商家来说都不健康。没有稳定流量，就没有稳定销量，商家不敢备货，生意就没法规模化。所以2024年美区直播一定会被推上牌桌，这也是实现10倍增长目标的关键一环。

但直播不能乱进。现在美区直播大盘还没成熟，进太早会做得很累，进太晚又错过红利。如果一切按预期走，年中左右入场是比较舒服的节点。

要注意的是，年中进直播，不是让你找几个国内主播用英语硬播。平台已经在打压那些没有原生感的直播间了，绝大多数华人直播间都不算原生。直播做起来，最终要靠美国本土主播、本土团队、本土资源。

我在之前的文章里也提过，本土化运营有很多坑，最关键的是找到靠谱的本土合伙人。所以，如果想在年中启动直播业务，年初就得开始布局：搞定工作签证、物色合伙人、招主播、整合仓库资源。我们学员社群里，已经有人在美国把直播做到头部，有人从供应链侧切入，还有几个亚马逊卖家在联合筹备海外团队。

总结一下我2024年抓美区机会的步骤：

1. 上半年用短视频+商业化投流+红人营销打品；
2. 上半年同步布局美区本土资源；
3. 年中之后全力杀入美区本土直播赛道。

## 三、全托管还有机会吗？

有，而且有。

2023年是各大平台全托管全面开卷的一年。在TikTok全托管模式下，平台烧钱补贴，腰尾部商家囤货陪跑，真正赚到钱的有三类：头部商家——吃到了爆发式流量红利，日出万单；带货达人——全托管商品价格低、佣金不低，出单容易；消费者——买到就是赚到。

问题在于，头部商家是少数，大部分商家很难赚到钱。而且全托管商品还会跟本土商品打架，扰乱定价体系，所以大家开始怀疑这个模式到底有什么意义。

我的理解是：全托管最大的价值不在赚钱，而在于开拓市场、拉新用户。只要还有新市场开放，或者某个市场的电商用户还在快速增长，全托管就有存在的理由。

2024年正好有这样的机会。如果不出意外——虽然TikTok开新国经常出意外——年中的时候，全托管会开放法国、德国、意大利、西班牙、墨西哥、阿联酋等国家。所以，如果你在供应链上有优势，完全可以继续做全托管，等年中新市场一开，冲进去先吃螃蟹。

2023年很多人说TikTok不好做，2024年可能也难。但不管哪一年，总有人能做成。希望明年这个时候，朋友圈里晒成绩单的，是我们。
