# 小白从 0 到 1 跑通📕电商渠道，4 个月卖了 1000 斤福州鱼丸
作者：龙哥

标题：4个月卖出1000斤福州鱼丸，一个零售老兵的📕实战分享

大家好，我是龙哥。在传统零售行业做了12年产品经理，对货架、供应链、渠道这些东西再熟悉不过。但真正让我拿到第一个“小成绩”的，反而是📕上一门看起来毫不起眼的生意——卖家乡特产。

今年年初，我从零开始尝试在📕卖福州鱼丸。发第一篇笔记后第5天，有用户主动找过来；第8天，第一笔交易完成。没有爆款笔记加持，我也在不到两个月的时候把月销售额做到了五位数，第四个月直接冲到2万多。整个四个月，累计卖出去1000斤鱼丸，到手的变现是5万元。

很多人觉得副业要选风口，但我的体会是，真正容易拿到正反馈的是你身边本来就有资源的项目。比如你家乡的某样特色食物，只要你有货源、有故事，就能做。而且一定要坚持更新——我早期基本上一天发三篇笔记，靠数量去试。评论区也有朋友说，自己发了一百多篇才开始有起色，可见持续发比等爆款更靠谱。


希望我的经历能给你一点启发，也欢迎在评论区聊聊你的家乡特产。
