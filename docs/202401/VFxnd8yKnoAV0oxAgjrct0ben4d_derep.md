# 流量主这条路，我选择用长期主义走到底



自我介绍一下，我是周威，目前在杭州城西三墩附近。过去的身份是高考刷题的卷王、35岁的大厂员工，后来觉得不甘心，三年前裸辞在家自己摸索创业方向，一直在试错。直到加入赚钱，思路才逐渐清晰。

今年五月初我正式入局微信👸号流量主，到现在累计收益已经破一万。

这个数字和圈子里领先的大佬比起来确实很微不足道，我知道至少有十来个朋友已经做到月入五万。但每个人的起步和节奏不一样，我的经历或许能让还在迷茫的同行少走点弯路、少一些焦虑。

很多人现在都在说，流量主是快消品，随着参与者越来越多，这波红利很快就会结束。

我的看法恰恰相反，我从一开始就把流量主当成一个长期项目来经营。今天想跟大家聊聊我对《微信👸号流量主的长期主义思考》的一些体会，希望能给大家一些启发。

### 实操是怎么走过来的

进流量主之前，我其实也踩过不少坑，📕、抖音、闲鱼二手书都试过。五月航海启动时，我甚至报了📕赛道，一直到开船才幡然醒悟，我真正想干的是流量主。

原因很简单，流量主足够轻，轻到只要会打字就能启动；也足够纯粹，纯粹到核心就只剩文字本身。

入局前我就做好了心理预期，告诉自己如果一年能做到十万，那前九个月大概率只能赚一万，前八个月甚至可能零收入。这就是典型的指数型曲线。

从五月初到七月底整整三个月，我的阅读量基本没超过三百。主要是我固执地认为个人成长、个人思考这类内容有价值，肯定能行。说实话，现在回头看，当时的坚持也挺难得的。

转机出现在八月初的一次意外爆量。

那段时间我已经连续日更三个月，每天一篇，构思写作加发布至少要花三四个小时。想写的题材基本都写完了，有一天实在憋不出内容，烦躁之下看到了刀郎的新歌引发的舆论风波，便顺着情绪写了一篇带刺的观点文，标题也故意写得扎眼。

没想到第三天文章直接起飞了，迎来了人生第一篇十万加。那种迟来的正反馈让我猛地清醒：我以为好的，并不等于市场要的。

![](img/f93d2d18f201eefbc5a1e92755c75097.png)

于是我立刻调整方向，重新把航海手册翻了一遍，认真看了优秀船员的航海日志，还对照风向标。

在风向标里我看到了养老金这个方向，便直接切入。效果立竿见影，第一篇就破了四千阅读，我顺势开了两个号同时做养老金。

只是好景不长，养老金赛道到九月初就开始萎缩。我再次陷入迷茫，体制、历史、地理、心灵鸡汤、法律等多个方向轮番试水。

在这种乱试的状态下，我第三个号突然迎来爆量，于是我把重心集中过去，每天投入七小时以上做内容。虽然产能依旧不高，但这个方向的验证算是成立了，目前这个号还在池里，只有短暂掉池过。最近我还发现有两三个人在跟抄我的标题和选题。

所以当前我的核心工作，就是怎么把写作自动化和效率拉上去。

十一期间我开始研究影刀工具，已经实现了约三成的自动化，大大节省了时间精力。下一步目标是把选题和发布的自动化继续完善，整体自动化率冲到七成以上。

我的终极设想是，每天五小时内完成三十篇以上的写作、二十篇以上的发布，覆盖六个领域。

### 简单复盘三个阶段

这四个月我大致经历了三段：

第一段是自以为是期。直到第一篇十万加出现才结束。核心问题是不听劝、不照做、不了解市场。教训很直接：必须按航海手册和市场需求走，自以为是最耗时的。

第二段是选题摸索期。主要集中在养老金，选题零散没有体系，效率极低，有时一天只能更两篇。这个阶段的坑是盲目模仿别人，很快就会被淘汰。我对标的那个号现在已经停更一个月了。另外，当时如果早用 GPT4，或许效率会完全不一样，自动化也可能提前解锁。

第三段是深耕期。选定一个领域后加大测试力度，提升写作效率，向矩阵化、产品化、外包化演进。不能停滞不前，要持续迭代。不仅内容要多方探索，方法和工具也要不断尝试。

以上都是操作层面的经验，今天的核心是长期主义，我想重点分享三个认知：一切都是过程、快速学习调整、深耕行业研究。

1、一切都是过程

项目启动时我就明确了，一定要完整经历这个项目的全周期，哪怕单价跌到今日头条的水平我也愿意坚持。因为我太缺一次完整的行业体感。

不是为了流量主赚多少钱，而是为了以后做其他项目时，能清楚每个阶段该怎么做。

正如龙哥在现阶段强调的，不要沉迷长期主义和精细化运营，风口期拼的是规模、矩阵、暴力增长和花钱买时间。我把这句话看了十几遍，每次看都会更坚定地去做自动化、矩阵化、产品化。

2、迅速学习和调整

流量主已经做了大半年，算上前期酝酿快一年了。现在入局的人越来越多，赛道选题被快速复制，洼地很快被填平。

很多人会因此沮丧甚至退出，但我觉得这恰恰是检验学习能力的时刻，每个项目都会有这样的阶段。

所以我给自己立了规矩，不怕犯错，保持迭代，每天都要有改变。

龙哥讲过阶段跃迁的逻辑：

1. 先在第一阶段把钱赚到手，这是下一次尝试的资本；
2. 用第一阶段的实战提升认知，总结复盘，多花钱学习交流；
3. 积累多个第一阶段的经验后，才有可能真正迈入第二阶段，否则能力资源认知都不够，冲上去也会掉下来。

文章质量提不上去，就先提效率提数量，等数量达标再打磨角度。学习和调整永远在路上，这是任何项目最核心的能力。

3、深入行业研究，不撞南墙不回头

底层逻辑是，局部的正反馈会逐步扩散成整体的正反馈。

一个小建议，一定要参加航海，航海里有同行，能减少很多内耗。航海手册也要常读，因为它远超大多数人的认知水平，随着你认知提升，会不断读出新东西。

要对自己诚实，错了就改。很多人读了很多书做过很多事却进步有限，就是放不下自己的错误认知。

最后分享龙哥的一句话共勉：还在第一阶段的人，就好好做第一阶段的事，把第一阶段的钱赚到手。当认知升级时，你自然会看不上第一阶段的收益，然后等待第二阶段的到来。如果没有期待第二阶段，很可能说明第一阶段没有做好。

再补充三点个人体会：

1，我们追求的是持续而不是完美。写作时间过长影响健康和家庭就不值得了。所以我坚持每周运动四次以上，每次至少一小时，生活必须平衡。

2，不允许原地踏步。项目在变，不变就会被淘汰。我每天强迫自己尝试不同的选题、方法、领域和工具，迭代时间占写作时间的二到一。

3，质量和数量怎么选？这个问题本身就问错了。质量是通过无数次刻意练习迭代出来的，质量相对稳定后，效率越高、数量越多，入池概率越高。花猫说得好：有质量怼质量，没质量怼数量，没数量怼时间。我前面三个月颗粒无收，就是靠时间硬怼出来的。

最近流量主有点降温，我想用一句话总结：失败只是测试的结果，关键在于是否去测试并获得有统计意义的结论。好消息和坏消息同等重要。长期主义的路并不拥挤，真正暴富的反而是独木桥。
