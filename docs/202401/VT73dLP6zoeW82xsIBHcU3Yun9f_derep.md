# 成交的终极武器—潜意识营销

你有没有想过，为什么有的人卖什么都费劲，而有的人轻轻松松就能把几万、几十万的单子谈下来？差别不在产品，也不在话术，而在一个非常隐蔽的维度——用户大脑里那个不受他本人控制的部分。

我叫詹伟平。刚毕业那会儿做的是大客户销售，不到半年站上了公司销冠的位置。后来嗅到互联网的机会，转身做商业IP，靠纯内容、纯自然流量，在私域里攒下十多万精准粉丝。最近我们在招募线下合伙人和IP合伙人，客单价已经到五位数、六位数，照样一发布就有人主动来付款。这背后有一套我从没系统公开讲过的打法，今天全盘托出。

先说一个让很多人困惑的现象：同样的产品，同样的价格，换个人写文案、换个人去谈，结果天差地别。有人三句话就让客户掏钱，有人磨破嘴皮子还是被请出门。你以为这是口才问题？是技巧问题？都不是。真正的幕后操盘手，是用户的潜意识。别看他表面上在理性比较、认真思考，实际上他做的每一个购买决定，超过九成都是感性驱动的。

给你讲个特别直观的场景。你出差到一座陌生城市，从酒店出来找饭吃。旁边两家馆子，一家排着长队，一家空无一人。理性告诉你，人少的那家上菜快，等一等就能吃上。但你的脚，大概率不听使唤地走到了队伍末尾，甚至心甘情愿排上两小时，就为了一碗蛋炒饭。这就是潜意识在替你按下决定键。

再比如买空调。你一热，脑子里第一个蹦出来的品牌是什么？大概率是格力。市面上那么多空调品牌，凭什么你选它？不是因为你在货架前逐一对比了参数、拆解了压缩机，而是因为这个品牌早就被反复播种在你的意识深处，你一想到制冷，它自己就跑出来了。如果真按性价比算，大品牌溢价高，理性上未必划算，可你管不住自己，因为潜意识替你做主了。

所以啊，营销的本质，根本不是说服，而是操纵潜意识。说得更直白一点：让用户在某个需求冒出来的瞬间，第一个想到你。

那潜意识到底是个什么东西？它分两种。一种是与生俱来的本能，就像婴儿饿了会哭、嘴巴碰到乳头就会吸吮。另一种是靠后天反复刺激长出来的条件反射，就像初生牛犊不怕虎，但被老虎吓过一次之后，再看到虎影就本能地逃。

巴甫洛夫的狗你应该听过。每次喂食就摇铃，摇久了，狗听见铃声就流口水，哪怕面前什么都没有。这就是把铃声和食物焊死在了一起。潜意识营销干的事，本质上是一样的——把A和B强行拴成一对，让你看到A就自动想起B。比如龚文祥老师，天天喊自己是微商教父，喊到后来你想学微商，脑子里蹦出来的就是他。再比如我们孵化的亲子教育IP王老师，通过在头条做中长视频，第一个咨询的家长就付了四位数，一年积下二十多万粉丝。我们要做的，就是让所有想解决亲子问题的人，潜意识里自动弹出“王老师”三个字。

脑白金广告也是这个逻辑。你烦它，但你记住了它。它把“过年送礼”和“脑白金”反复捆绑，硬生生塞进一代人的潜意识里。讨厌归讨厌，人家销量说话了。

那普通人到底该怎么落地这套东西？我给你四条极其具体、极其粗暴的路子。

第一条：把每天九成时间，拿出去发广告。你一个人干，没什么好忌讳的，发硬广不行就发软广，你的曝光面越大，被你触达的人越多。知乎上每天至少回答三五个问题，没的答就把老文章翻出来重发；头条上每天至少发九条，以微头条为主，那玩意儿流量最大；👸号写完一篇，全网所有能留联系方式的平台挨个铺一遍。你花两小时做内容，就得再花两小时做分发。发，才是营销，写，只是生产。抖音、📕、🛰️群、线下地推，都是一个逻辑——天天高强度露面，才有后面的故事。

更重要的是，所有流量最后都要沉淀到私域，核心就是加🛰️。为什么是🛰️？因为它打开率最高，是你做深度影响最好的阵地。朋友圈是第一战场，每天发九条都没问题，不管发什么，用户每看你一次，就对你多一分印象。它看多了，你就不只是他列表里的一个人，而是他心里某个品类的代名词。然后配合👸号长文、🛰️群、一对一私聊，建立你的持续曝光系统。

别嫌👸号阅读量低。我给你算笔账：一百个日日夜夜来看你文章的，基本是铁杆粉丝了，哪怕一人一年为你创造一千块价值，那就是十万。你要的是十万块的收入，不是十万加的阅读量，目的搞清楚了，你就知道该不该坚持了。

第二条：搞清楚不同媒介的威力排序。有个著名实验测过，人与人的沟通里，语言占比只有微不足道的7%，声音占38%，而肢体动作占了55%。你可以回家做个测试：嘴上说“举右手”，但你自己做下蹲动作，看看对方跟着你举右手，还是跟着你蹲下去。大概率是后者。人就是这么被影响的，不看你说什么，看你做什么。


第三条：学着“弱传播”。很多人觉得，内容写得越专业越有面子。错。太专业，看得懂的人就少，反而那些看起来通俗、短小、有点粗糙的内容，跑得最快。你看🧣上一条新闻炸开，一定是短内容先引爆，知乎反而最慢，因为那儿的人偏爱长而深的分析。这个东西《弱传播》那本书讲透了，你去买一本回来翻翻。

核心就一句话：弱小的东西，最容易传播。水比石头弱，所以水流千里，石头不动。做内容也是，多替弱者说话，别站强者立场。男人打女人，新闻一出来，你第一反应一定是骂男人。一个被欺负的小女孩出现在故事里，传播力天然爆表。骑三轮车的老头撞上劳斯莱斯，哪怕错在老头，如果车主辱骂他，你猜舆论会骂谁？全世界都会站老头。哪怕你揣测老头也有问题，但大众不管，大众的潜意识里没有对错，只有强弱，弱者必须被保护——就像着火的时候老人小孩女人先走，男人永远垫后。这不讲道理，但这就是人性。

第四条，也是最容易被忽视的一条：潜意识里，没有对错，只有立场。你女朋友跟她闺蜜吵架了，你明知道错在女朋友。她跑来跟你诉苦，你要是直男上身，一条条给她捋逻辑，分析她哪儿不对——恭喜你，你很快就没有女朋友了。正确姿势是什么？先站她那边，坚定地站她那边，先把情绪接住，再谈道理。因为道理是留给立场站稳之后的人的。

对付用户也一样。用户说你产品不行，那就是不行，你先认同他，和他站在同一条战线上，后面才有对话的空间。在公司里想晋升也一样，老板的每一个决策，你都先表态站在老板这边，成为他的心腹，再谈利弊分析。等老板把你当自己人了，你的位置自然往上升。

最后收个尾。潜意识营销这盘棋，说到底就两步：先把面铺开，全网露脸，让更多人知道你；再把线拉深，把精准用户引进私域，用持续的内容去反复触达他。面越广，进来的人越多；线越深，用户为你掏钱的意愿和单次金额就越高。

天天发广告，天天收钱。站在用户这一边，满足他潜意识里的偏爱。时间一长，你会发现赚钱这件事，开始变得顺畅得不像话。
