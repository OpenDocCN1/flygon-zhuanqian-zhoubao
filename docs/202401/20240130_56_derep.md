# 找到幸福感其实很简单

最近看到一段话，越品越觉得戳心。

想过得舒服，不是因为你把什么都抓在手里，而是懂得做减法。

**先学会筛选，别总想着去改造。**
人和事都很难被扭转，消耗在“培养”上的时间，会让你越来越累。选择比改变更省力，能留下的自然留下，不合适就体面放手。

**保持对话，别让误会发酵。**
很多裂痕不是因为爱不够，而是因为没说。能说的就说清楚，不猜不演，多一点坦诚，比多做很多事都管用。

**把精力放在行动上，别被欲望牵着走。**
欲望是无限的，完成感是有限的。与其空想拥有多少，不如先把手头的事做好，踏实比空想更治愈。

最后，别把生活活成一个永远的待办清单。
把握眼前，把当下过成值得回味的样子，就是最大的幸福。
