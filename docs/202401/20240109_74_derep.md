# 如果我是董宇辉

假如把我放到董宇辉的位置上，我的应对思路其实特别直接：别去茫茫人海里大海捞针，而是回头看看那些早已和我们有过深度交集的人，从中挑出能一起走长路、谈长久的伙伴。

一个聪明人的社交策略，往往不是拼命扩展新圈子，而是把自己已经投入过时间、信任和情感的关系重新梳理一遍，找出那些真正值得继续托付的人。深度交往本身就是一种筛选，时间已经帮你淘汰了大多数不合适的人，剩下的，才值得你用心经营。

这也是董宇辉这类人在面对复杂局面时的一种清醒选择——不是向外突围，而是向内深耕。与其在不确定的关系里反复试探，不如在已有的信任基础之上，把重心放到最值得的人身上。简单，却很有分量。

这让我想起一句话：真正重要的关系，从来不是数量，而是深度。当我们把目光从“认识更多人”转移到“珍惜已深交的人”时，很多选择就变得清晰了。
