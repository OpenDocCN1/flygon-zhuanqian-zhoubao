# 两个月120多篇笔记，12月📕店铺GMV终于冲破5万
作者：龙哥

这是我今年做得最吃力的一次尝试。

从十月开始，我就全职把精力押在了📕店铺上。两个月的时间里，我几乎每天都在更，笔记总数干到了120多篇。过程很狼狈，数据也一直不稳定，可以说是边试错边往前走。

转折点出现在12月7号。那天店铺第一次单日破千，算是给自己一个比较实在的肯定。

而截至12月26日，12月的累计GMV已经突破5万元了。现在店铺的日常表现也趋于稳定，单日GMV基本都能稳定在2000元以上，峰值的时候冲到过4000多元。

这一路能走到这里，受益于星球里前辈们分享的经验贴非常多。今天把我的复盘和心得整理出来分享，希望对刚入局📕的新手能有一点点借鉴意义。
