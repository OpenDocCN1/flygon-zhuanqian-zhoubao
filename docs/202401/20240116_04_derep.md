# 劳力士为什么拒绝销售？

前几天听一位做挂钟的朋友讲起一件事：他去瑞士旅行，心想来都来了，正好给自己挑块劳力士。同行的几个人都看中了款式，结果店员却说：抱歉，这些表不能卖给你们。

他们当场就愣住了，甚至说：“我们一口气买20块，总可以了吧？”那可是几百万的单子，店员依然摇头。

放着生意不做，劳力士到底图什么？

其实，这是很多奢侈品品牌的常规操作，营销学里有个专门的说法叫“零售拒绝”。劳力士不少热门款不是有钱就能买，往往要先在品牌消费到一定门槛，才有资格拿到某些限量款。爱马仕的配货逻辑也是如此。

我们还有一位做护肤品的客户，他是LV的超级VIP，能通过品牌客户经理满世界调货，买到各种限量款。这个身份让他在主播圈很吃得开——因为他能帮那些小姐姐们搞定很难买的LV。

所以问题来了：奢侈品为什么宁愿少赚钱，也要把顾客往外推？

根源在于，奢侈品的核心卖点不是产品本身，而是身份标签。如果满大街人手一只，它还能体现什么身份？因此必须刻意制造稀缺，让只有少数人持有，才能彰显拥有者的地位。

一旦奢侈品敞开卖，它那层“奢侈”的光环就会迅速褪去。说到底，奢侈品的价值建立在社会共识之上——大家都认它是顶级的，它才是。一旦泛滥，它就和普通商品没什么两样。

可见，敞开售卖，反而是在毁掉自己的根基。
