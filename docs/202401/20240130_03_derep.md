# 想要100%稳妥，就别踏进生意场



## 要绝对的笃定感，就别出来折腾赚钱了

日期：2024-01-25

提问者说自己在赚钱圈子里待了两年，看过无数项目机会，却始终没把学费赚回来。最近和朋友毛韩复盘，发现问题根源很简单：从未真正死磕过一件事，不肯为一个项目投入大半年的时间去深耕。

再往下挖，退缩、跳槽式换项目，背后其实是一样的心理：【对自己能把这件事做成，缺乏绝对的信任】。

有意思的是，两人都是十足的程序员，对写代码能连续熬通宵，凌晨三四点躺在床上还在琢磨Bug怎么解。写代码时路径清晰，功能一旦实现，程序呈现的模样是可以预见的。

可一旦换到做内容、做👸号、📕这类自媒体创业就不行了。小到扫码注册账号这种鸡毛蒜皮的事情都可能卡住，遇到一点波动就开始自我怀疑。因为这条赛道没有标准答案，数据一来一回得反复琢磨，充满了未知。

朋友毛哥在做👸号时也卡在原地，直到一个转折点：他花钱报了另一个圈友的内训课，对方已经做出过成绩，还承诺做不出来就退款。正是这份“保底承诺”，给了他继续干下去的确定感。

可现实是，绝大多数创业场景都是无解题模式，很少有人能拥有“我100%能成”的笃定。正是这种确定感的缺失，才让很多人选择逃避，永远跑不出结果。

于是问题抛出来了：龙哥大佬，如何靠自己培养出这种确定感？或者有没有其他办法能拿到绝对的信任？

回答很直接：

没有。想拿绝对确定性，就回家躺平吧。赚钱，本就是勇敢者的游戏。

到今天，我做很多事的时候依然会怀疑自己能不能成，还是得硬着头皮往前试。何况是你们。
