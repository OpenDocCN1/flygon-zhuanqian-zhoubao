# 网盘拉新赚钱全拆解：渠道、代理、真实价格，这次一次说清

最近哈尔滨的热度不用我多讲了吧？作为哈尔滨土著，我也来点“实在干货”，聊聊我做了很久的网盘拉新。

我是闰土，先跟各位生财圈友报个到。准确算起来，我是在2022年11月5号正式入局网盘拉新的，到现在已经一年出头。上一次专门聊这个话题，还是5月6号。从那之后，一直有圈友来问我：后台可以开吗？代理是什么玩法？分销怎么做？今天就不卖关子了——咱们把网盘拉新怎么赚钱、代理和分销怎么跑通、真实行情价是多少，一次捋明白。

我这人学历不高，文笔也普通，所以全程用大白话讲。哪块没讲透，或者觉得跟自己的经历对不上，欢迎直接在评论区开麦。
