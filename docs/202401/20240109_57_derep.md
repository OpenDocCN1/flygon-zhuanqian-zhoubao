# 第二期风向标项目拆解作业：研学业务普通人如何入局

新年第一期风向标项目拆解来了，这次把目光投向研学赛道，聊聊一个很实际的问题：普通人到底怎么挤进这门生意？

这篇拆解出自辛禾，内容偏基础，但角度很全，不是干巴巴讲概念，而是把资料整合后融入了自己的思考。如果你正对研学感兴趣，不妨顺着里面的思路往下捋一捋。

全文从多个维度入手，先帮你看清研学的本质，以及这些年它一路走来的背景和现状；然后梳理出围绕研学展开的具体业务板块，让你知道这个领域里到底有哪些事可做。接着就是落地环节——一份研学产品该如何从零搭建，课程设计又有哪些方法论可以套用。当然，做任何项目都绕不开变现，文中整理了研学的几条变现路径，以及公域怎么引流、怎么转化。最后还贴心地给了普通人切入实操的几个切入点，降低上手门槛。

整体来看，这是一份非常适合新手的入门拆解，既有全景扫描，也有实操指引。
