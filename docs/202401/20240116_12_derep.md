# 从财务到写书到心理咨询疗愈导师，野蛮生长的我到底经历了什么？

回头看那些只敢在脑海里做梦的日子，我确实替自己着急过。不过更庆幸的是，后来我终于一脚踩下了刹车，转了个方向，然后一路横冲直撞地往前跑。从格子间里的财务，到埋头写书，再到成为心理咨询疗愈导师——这段旅程硬是被我走出了一种野蛮生长的味道。

想告诉你一个特别真实的感受：当你真正决定为自己而活时，一年做的事能顶过去五年。这不是什么玄学，而是当你心里有了那一团火，整个人都会像开了挂一样，停不下来。

所以，如果你现在正站在某个路口，犹豫着要不要迈出那一步，别等了。岁月不等你，就算路上掉几跤、淋几场雨，你照样能收获一个更成熟的自己，还有沿途那些原本看不见的风景。
