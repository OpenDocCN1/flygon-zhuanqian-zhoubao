# 把重要的事亲自做成“可有可无”
作者：龙哥



## 把关键环节做成不需要关键人的环节

作者： 龙哥

日期：2024-01-04

最近被一句话点醒，来自一位年利润数千万的老总。

他的说法很直白：凡是我判断对公司至关重要的事，我就会亲自动手，把它处理到不再重要。眼下我觉得人力这一块最要命，明年我打算把时间重点砸进去，把它打造成一个不用我操心的部门。
