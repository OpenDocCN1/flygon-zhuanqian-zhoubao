### 三、具体怎么操作？保姆级指南

**第1步：安装沉浸式翻译插件**  
这是一个开箱即用的浏览器插件，装上之后，几乎所有网页内容都能双语对照显示。

**第2步：找到入口并注册账号**  
安装后，浏览器右上角会出现插件图标。点进去，用邮箱或手机号登录即可。

**第3步：配置API Key（可选）**  
如果你想要更高质量的翻译，可以在设置里填入 OpenAI 或 DeepL 的 API Key。  
不填也能用，但精确度会差一些，适合娱乐阅读；关键资料建议填。

**第4步：翻译输入框内容**  
在社交平台、搜索框或表单里打字时，插件可以直接把输入内容翻译成目标语言，实现“中文进、外语出”。

**第5步：开启视频字幕翻译**  
很多国外视频平台（比如YouTube）没有中文字幕，插件可以实时提取并翻译字幕，让你轻松跟上内容。

**第6步：本地文件翻译**  
PDF、HTML、txt……直接拖进插件，就能完成机器翻译，保留原格式，阅读体验很好。

**第7步：🛰️输入法“边写边译”**  
在🛰️输入法设置里开启“边写边译”快捷键，输入中文时直接按一下，就能秒变英文或其他语言，方便又高效。
