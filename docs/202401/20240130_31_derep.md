# 阅读加速器：用 GPT 轻松驾驭长篇巨著

你有没有过这种经历？

花了好大力气学会用 GPT，感觉它啥都能干——画图、做数字人、聊得飞起，可真到自己的日常里，好像又用不上。工具很酷，但生活没变化，除了多会一个软件，似乎也没啥实质提升。

我之前做龙哥盟“GPT 提效”航海的教练时，发现不少学员都有类似困惑。后来我和领队国强商量，决定专门做一系列真实场景的演示，让大家看到 AI 到底能在哪些地方悄悄省时间，把节省下来的精力还给生活本身。

这次先聚焦“阅读”这件事。长篇巨著、外文文献、学习资料——以前翻开就犯困，现在完全可以交给 GPT 来当加速器。

具体可以这么玩：

- 用 GPT 快速提炼整本书或网页的核心内容
- 让 GPT 像导师一样带你精读一本书
- 把一本书浓缩成一张清晰的思维导图
- 生成一份可直接用的 PPT 大纲
- 读完一本书后，让 GPT 帮你出套测试卷
- 翻译外文文献，扫清阅读障碍

这些场景其实都有固定的 prompt 可以套用，我整理在文档里了，第一期先分享这些日常高频用法，希望能帮到你。

如果你有别的场景想要 prompt，可以直接在文档里留言，我会统一收集，之后的提效系列还会继续更新在龙哥盟。
