# 别人的评价不值一提，你有没有勇气为自己坚信的路买单



日期：2025-09-11

你好，龙哥。

年初先生失业，我们夫妻带着孩子从深圳搬回了老家一个四线城市。他在家扎进海外网站的搭建里，已经坚持了近半年，却仍不见回款。我在去年离职后也试过做公众号、接代写、玩闲鱼，唯有公众号带来过一点点收入，其它统统中途放弃。

最近我决定收手不再东一榔头西一棒子，想和老公合力把他的海外站打透，一来他一个人推进太慢，二来我自己也是试来试去耗尽精力。

现在我卡在了这里：是跟他一起死磕这个项目，还是我先回城里找一份三四千块的稳定工作过渡，让他继续在家摸索。今年以来我们收入基本为零，偶尔焦虑难免，也常要承受来自外界的质疑目光，两个人怎么都不去上班。好在家里积蓄还能支撑三四年无收入。

我的回复是三点。

第一，别人的看法真的不重要，关键是你有没有扛住议论的底气。

朋友圈里有句话我很喜欢，截给你做个提醒。我人生当中最大的突破之一，就是学会了允许自己被别人讨厌。

我可以成为让圈内人反感的掌舵者，我可以成为让员工不舒服的老板，我可以成为亲戚眼里的异类，我可以成为朋友口中挑剔的人。

只要我认定这件事是对的，旁人的目光就与我无关。

第二，搞项目不是赌博，别吊死在一根线上等奇迹出现。

做事要像种地，而不是像打猎。种地是日复一日的把问题一个个解决掉，油管视频也好，AI网站也罢，当你把这个赛道里的大部分坑都填平了，变现自然会来。高手的本质，就是把这个领域的难题几乎全都攻破了。

所以我会建议你先去找一份能覆盖日常开销的工作，把底线守住。与此同时，让你老公能更专注地去做项目、去试错。但前提是他不能闭门造车，要保持大量输入，泡论坛、看案例、多和同行交流。最怕的就是一个人闷头按着自己的偏执蛮干，最后把时间耗光。

第三，你们必须把过去频频放弃的原因刨出来。

如果不对半途而废这件事做一次彻底的复盘和自检，换一个再好的项目你也做不长。习惯性放弃本身就是最大的成本。
