# 【AI写作团队实战经验】招人、识人、面试、分钱深度解读！

最近很多做内容创业的朋友问我：团队到底该怎么搭？人该怎么招？钱该怎么分？今天就把我这大半年从“一个人干全部”到“广州大学城搭起全职写手团队”的实战经验，一次性讲透。先交代下背景：我是瑾糖，2023年底入局AI写作，2024年一整年都在跑自营盘，流量、销售、交付全是我们自己人啃下来的。目前单月营收稳定在50万上下，从0到100万用了三个月，现在还在往上下游深挖。

一、别再迷信“一人公司”了，那只是个概念

很多人拿“一人公司”当目标，觉得一个人就能撑起一个盘。但你细想，连李一舟老师都算不上真正的一人公司——他身边有助理、有经纪人，背后还跟着一个或自建或外包的投流团队。这样的人，怎么可能真的“一个人做公司”？

再说，能不能成规模，取决于你有多少精力。流量本身就分自然流、投流、直播流、图文流、视频流；你要是还想双屏操作，一边直播一边做视频，一个人根本拆不开。就算你咬牙扛下来，每样也都只能做到皮毛。

拿我们自己的成长路径来说，1.0阶段，两个人各自跑完所有环节，流量、销售、内容甚至交付都自己上。2.0阶段，后端开始分出去，前端还是各管各的。3.0阶段，我做流量，搭档做销转，后端直接外包。4.0阶段，流量团队里再拆出运营岗，客服也有人专门接了。5.0阶段，运营一人守一个方向，线索转达单列，客服按产品分配，后端则换成了我们自己搭的线下团队。

每一步拆分，都是因为一个人扛不动了。直播也一样，哪怕你只做投流，也得有人当中控、有人做辅助，否则你连喝水的时间都没有。

我有个做视频号的朋友，刚开始写稿、拍摄、直播全自己来。后来号越来越多，他就只做直播；再后来直播也让主播顶上，自己只管方向。他不是不想亲力亲为，是“累”这个字把他劝退了——一个人的精力天花板就摆在那里，硬撑只会卡死规模。

当然，小团队依然可以活得很好。比如抖音上那位头部烘焙博主，和她老公两个人，一个负责拍摄，一个负责运营兼直播，行情好的时候年营收能冲到3000万，佣金按30%算，一年利润接近1000万。这种内容驱动、能做爆发性单品的赛道，就适合2~3人的精锐小团队。

反过来，人力密集型行业、实体餐饮、小型工厂、服务业，永远要靠堆人来换规模。所以你会发现，真正存在的选项只有两个：要么做小而精，要么做庞大而厚重，压根没有“一人公司”这回事。

二、什么时候该招人？先看利润和人效，别为招人而招人

我们2024年初刚起步时，一个人全流程，每天最多能接2000多块的单子。一个人忙到脚不沾地，且项目本身有利润，这时候才可以把后端交出去，让自己回到流量和销转上。

很多人直接从流量和销转入场，后端经验不足，那就要另找合作。我们当时是忙不过来，先招了一个线上兼职的教务老师，专门对接后端客服和售后。为什么？因为售后成本一旦失控，你一天接的单可能从晚上处理到凌晨，还要自己找老师、扛客诉。更耗人的是情绪——夹在客户和老师之间反复传话，很容易被两边情绪拖垮。找个人承接这些，我们才抽得开身。

后端稳了之后，我们又发现一整天离不开手机，哪怕聚会、开会、出去玩都得抱着手机聊单。那时候一天大概能做三四千业绩，于是把运营和销转也放出去，先用线上兼职试水。运营一天50块，客服50块加提成。这类兼职多半是学生或清闲的上班族，反而能全天盯着消息；全职反而不容易做到。

找兼职的路径，第一优选熟人，稳定；第二去别人调教好的助理群里找，基础素养在线；第三才是在小红书发帖，但一定要筛。客服岗经手收钱，所以务必统一收款：我们用个人微信成交，客服用手机端，我们用平板或PC同步登录，所有聊天记录、收支流水都看得清清楚楚，从源头上防跑款。

新人带一周基本上手，这时候你就该从具体操作里彻底抽身，去解决更核心的问题。记住一个原则：先把盈利模型跑稳，再把一个人的人效用到极致，再考虑第二个。别听什么“提前储备人才”，那是利润极高时的玩法；你模型没正、人效没上去，多养一个人就是多一分消耗。

建议从兼职而不是全职开始过渡。全职要场地、要底薪，一个月至少三四千，全天接量还得两班倒，初期体系不成熟，兼职是更划算的选择。等培训体系跑顺了，客服和流量都稳定，再考虑自建线下后端。而且团队一定别贪大，小而精才是王道。

从兼职转全职，人效必须达到兼职的2~3倍。这里有个很实在的算法：如果你一个人月产出6万，全职最少要做到4万；做不到，就先别招。招第二个人前，给自己设一条人效底线：两个人至少做到8万，三个人做到12万，低于这个线就继续磨流程。如果你的个人月产出只有3万，全职做到2万，那还不如先自己把项目天花板抬高。

低人效的生意根本不适合扩张。你算下，假设一个人只贡献5000，想赚10万就得招20人，而20个人的管理需要完整体系，不然必乱。所以慢慢来，先兼职、再全职、把人效压榨到极致再招下一个。要时刻记住：招人不是为了撑场面，是为了利润。哪怕团队小，利润高，容错空间也大；团队大而虚，每个人一个月挣不到2000，业务稍有波动就垮了。我们一直说的“稳步向钱”，钱，是利润的利。

三、选人怎么避坑？先想明白要什么，再倒推标准

招人是搭建团队的生死线。很多老板一上来就看简历，觉得写得漂亮就行。但要知道，简历普遍被3~5倍优化过，我们自己就是帮人写简历的，太清楚里面的水有多深了。文笔好不代表能打，关键是看这个人过去做出了什么实际成绩，以及他在那个成绩里占了多少贡献。

所以，招人前先把预期放平：找一个“合格”的人就好，别追求完美。具体来说，先回答两个问题：这个人回来解决什么问题？他需要什么核心能力？然后顺着答案倒推标准。

比如运营岗，如果是要他去测试新业务、新方案、带来实打实的产值，那必须找有经验、有结果的人；如果只是执行层，有现成SOP，那要求就可以降。销售岗也一样，拉新拓客需要攻击性、野心、冲劲；维护老客户、做复购，就需要情绪感知能力强、有耐心的人。

我们那时候招运营，因为培训体系成熟，所以定位很清晰：实习生、执行力强、听话照做、不钻牛角尖、机灵。按照这个画像，我们锁定毕业半年到一年的年轻人——能力不强但守规矩，不像老油条油滑，有基本职场素养。又加了两道硬门槛：一是有互联网相关经验，公众号、淘宝、小红书甚至客服都行，工厂背景的连电脑操作都生疏；二是熟练操作电脑，这是底线。

渠道上我们主用BOSS直聘，100多块买一个岗位就能满足需求，性价比很高。小红书上发帖也试过，但转化不高，可能是我玩不转。关键一步是写JD：先梳理要什么人、解决什么问题、要什么能力和画像，再用GPT-2.5 Pro或Claude 4.1出初稿，手动修改；或者让AI参考同行同岗位JD优化。JD里一定要把业务内容、能力要求、福利待遇写透。如果连JD都不看就来问里面写清楚的答案，说明这人不用心，直接pass。

线下面试一次20~30分钟，一天面十个就占满了。所以前期筛选要做好，分三关：第一关，聊天时看细节，遇到上来连环逼问、攻击性强的，先把工作地点、薪酬、月休、社保公积金缴纳时间做成表格发过去，如果连简历都不肯给，直接淘汰。第二关，用DISC性格测试，这比MBTI更贴近职场。我们让应聘者在指定小程序测完发结果，这一步既能筛掉不愿意做测试的人，又能判断性格匹配度——比如我们招“听话照做+执行力”的人，IS型就更合适。第三关，把测试结果扔给AI，让它判断是否适配岗位。三轮都过了，我们才看简历，了解他的工作数据和团队相处情况，最后邀约线下面试。

说到底，选人的核心就是“想清楚自己要什么”。需求明确、画像清晰、工具用对、筛选到位，才能把招错人的概率压到最低。

四、面试像谈恋爱：先把难度讲透，再画能实现的饼

线上面试筛选完，线下流程也要设计好。我们之前一天约十几个面试，从早聊到晚，所以能前置的筛选全部前置。提醒一点，所有通过初筛的人都要明确告知“带简历来”，做不到的，也可以直接pass。

到了公司以后，不同岗位做一套情景题笔试。比如运营岗遇到封号怎么办？客户一直问价格、不加微信怎么办？销售岗遇到客诉怎么处理？客户加了不说话、确定付款但迟迟不付又怎么跟？把这些实战场景列出来，先笔试，再面聊。

我面试最看重两点，一是沟通能力，二是形象。沟通都讲不清楚的人，日常工作更没戏；把自己形象都打理不好的人，我很难相信他能把事做好。然后是聊预期：一定要把工作的难度、强度、复杂程度反复讲清楚，甚至往重里说。别怕吓跑人，不然他进来发现和想象不一样，第二天就跑了，你前期所有的沟通和培训全都打了水漂。

讲完难度，再给希望。这不是让你空画饼，而是给出真能实现的愿景。比如“做出成绩就让你独立带一个部门”——我们真的做到了。有个入职一个半月的同学，把本职工作做得很好，后来我单独安排他带一个两三人小组，下面人出的成绩，他还能抽额外提成。所以面试时既要让他对难度有预期，也要让他对未来有预期。那些想来摸鱼混日子的，听到强度自然就撤退了。

还有个小细节：发offer时一定设回复时限。我一般给8~10小时，比如下午2点发，晚上10点前必须确认。这样不会被拖住，他要是把我们当备胎，我们也可以立刻转向下一个候选人。

五、最后，钱分好了，团队就活了一半

招到人只是开始，真正让团队拧成一股绳的是利益分配和规则制定。从我的理解出发，老板在这个环节只干两件事：把方向、定规则。方向不对，越努力越偏；规则不清，多劳不多得，人心必散。至于更具体的“科学分钱”方法，每个团队基因不同，不能一刀切，但有一点是共通的——所有的机制都要指向利润增长和长期共赢。

团队管理说到底就是这两件事：让干得好的人拿得多，让机制替老板说话。希望我的这些踩坑经历，能帮正在搭团队的老板们少走几步弯路。

创业这些年，我最大的一个感受是：老板真的忙，但忙和忙不一样。前期你忙的是具体事务，是执行；到了后面，你的时间应该往方向、战略上收。如果一个老板永远陷在执行层，那团队撑大了也迟早会出问题。

记得三月份我和芝芝做月度复盘，发现当月我俩花最多时间的竟然是招人。那会儿公司还没有HR，芝芝在线上约人，我在线下当面试官，那段时间公司正是缺人的时候，我几乎70%的时间都泡在面试间里。复盘之后才猛然意识到：招人虽然紧急，但不一定非要我们来干。当时我们最该盯着的，是流量、客服销转和后端交付这些真正决定增长的事。而招一名基础人事，四五千块钱就够了，门槛不高，有基本沟通和执行能力就能把这事儿接住。于是我们复盘当天就决定招人事，没两天人到位了，从此再也不用我们亲自盯着招聘。省下来的时间，我们拿去定规则、撮合板块协作、盘后续的发展路径去了。

除了把控方向和定规则，老板还容易活成“救火队长”——流量缺人，上；客服活儿多，顶；下面的人忙不过来，自己还得亲自接待用户、上答疑岗。看起来尽职尽责，其实是在吞噬自己的精力。后来我们想通了，就赶紧搭体系：培训体系、带教体系、老带新体系，关键的是把每个板块的组长立起来，让组长去当那个“救火队员”，老板才能真正退居二线。

但团队的体系，最核心的还是分钱。钱分不明白，其他都是空话。员工拿不到该拿的，就不会有真正的自驱力。一个良性的分钱循环，应该是员工拼业绩→公司盈利→员工分得更多→员工更有冲劲。老板的任务，就是把这个循环搭建起来，并且维持住。

然而很多团队还陷在传统误区里。比如固定工资加固定奖金，奖金和公司业绩毫无关系，干多干少没差别；比如员工提离职了才用临时涨薪去挽留，这叫被动妥协，治标不治本；再比如公司一赚钱，全员普调，不分贡献大小，吃大锅饭，看似公平，反而最伤士气和公平。

那科学分钱到底怎么分？本质上要靠“不满足感”和“对比感”。你得让员工看得见：原来努努力，收入真的能差出一大截。利益差，就是最好的驱动力。

运营岗我们是这样做的：每天50个线索作为门槛，达到才有资格参与排行。榜上的奖金池拉开梯次：第一名拿第二名的两倍，第二名拿第三名的两倍。达不到门槛，连额外提成都没有。这个机制下，大家不光要低调达标，还想冲第一——有段时间一个小伙伴为了追上第一名的线索量，硬是加班到晚上十点才走。

客服岗也类似：按照历史业绩设置阶梯，做到15万，有提成有奖金；冲到20万，提成和奖金更高。同时用月度排行把差距放大，第三名的月收入可能只有第一名的一半甚至更少，这一下就把大家的冲劲给激出来了。

当然，激励绝不能盲目。也不是喊喊口号就发钱，必须和业绩、利润、毛利、回款周期挂钩。坚决杜绝大锅饭，更不能让员工为了个人业绩去损害公司利益。比如签单时擅自降价，这种情况绝对不允许。我们要的是员工在追求个人利益时，同步放大公司利益。

再一个，激励不能一刀切。基层员工，核心就是用利益差去撬动他们的动力；但到了中层，就要把他的收入和团队整体绑到一起。比如销售组长，直接跟团队业绩挂钩：团队月度目标50万，完成了，按总业绩的固定比例拿提成；超额了，比例再往上加。为了快速带新人，老带新的利益也绑得很死：新人入职前7天的业绩全部归带教老师，新人一旦通过考核正式留下来，老师还有额外奖励。

说到底，我就是用利益去搭班子，用规则去定流程。把科学分钱这件事做好，员工和公司才能形成真正的共赢。希望今天的分享，能对现在的你，或者未来的你有点用。
