# ('(57 赞)人生三种“货币”：知识、时间和金钱的转化与稀缺规律', (2, 33))

你有没有想过，我们终其一生，其实只握有三样东西——知识、时间，和金钱？

它们彼此连接，可以互相兑换，就像那句英文名言强调的：“在你需要某一样时，不妨动用另外两样来换取。”

举个例子：当你觉得脑子空空、能力不够，你可以砸时间埋头去啃，也可以干脆花钱请个老师带你。当你忙到连喘口气都奢侈，那就拿知识去优化做事效率，或者花钱把杂活儿外包出去。

而假如你此刻正被缺钱折磨，最靠谱的出路，恰恰就是另外两样宝贝——用知识武装自己，靠时间慢慢积累，财富早晚会回流。

这三样，像极了桌子的三条腿，缺一条就摇摇晃晃。不过别紧张，只要另外两条还结实，你就能稳稳撑住，继续往前走。

有意思的是，在不同的人生路口，你最稀缺的那一种货币也在悄悄变化。年轻时，大把时间挥霍不完，最窘迫的是钱包和经验；到了中年，攒下些钱，也攒了一肚子见识，偏偏时间像被偷走了一样，最不经用；等真正老了，金钱反而淡了，最要紧的，是拿知识和积累，去把剩下那些日子，活得更有滋味。
