# 40+零基础小白的航海首秀复盘：从完全不会到10万+播放，我只干了这几件事

作者：Aries😖H
发布：2025-09-16
原文链接：[`www.yuque.com/for_lazy/zhoubao/tnyr6i9isafurag1`](https://www.yuque.com/for_lazy/zhoubao/tnyr6i9isafurag1)

大家好，我是Aries。

6月才踏进生财圈，9月就直接报名了人生第一次航海。选了两条船：YouTubeAI视频 和 AI视频制作。3号正式起航，7号憋出人生第一条视频，到9月12号为止一共发了6条。

成绩有点出乎我自己意料：
YouTube这边累计播放破13万，订阅数98；
而微信视频号这边更离谱，5条作品累计播放120万，还意外通过了创作者分成，纯属惊喜。

本以为要等到变现跑通才能出来说话，结果领队大魔王和志愿者 Leo 丨站在雞蛋一邊一起点名让我来做分享。他们说得对，生财里最缺的不是大神案例，而是像我这样零基础、容易卡在起步就放弃的新人。我的过程，可能更能给同样第一次上船的你一点信心。

下面我就用大白话，跟那些跟我一样迷茫的伙伴聊聊我这半个月跌跌撞撞的实操记录。

先自检一下，你是不是我当时的同款？

1. 身上几乎没有能直接用在航海项目上的技能；
2. 平时不刷短视频，也不碰AI，对出海、上船全懵；
3. 没有现成的互联网变现玩法，之前一直在传统行业打拼；
4. 对新媒体、线上项目基本是零认知；
5. 年龄在40岁以上，总觉得自己已经错过窗口期。

如果以上有戳中你，那这篇复盘就是写给你的。
