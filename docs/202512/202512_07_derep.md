# 别再让“没钱”这句话，悄悄编程了你的潜意识
作者：龙哥

你身边是不是有个朋友，聊什么话题最后都能绕回“太穷了”“现在东西贵得离谱”“快破产了”。一开始你可能觉得他只是发泄，听久了你会发现，自己开始跟着心慌，甚至无形中把这种焦虑内化了。

这不是开玩笑。话语的力量远比我们想象的更可怕。

口头说出来的东西，会先成为一种习惯，再变成一种信念，最后沉进潜意识里当成默认设置。那些反复念叨匮乏、抱怨成本、强调无力的人，其实每天都在给自己施咒。每一句“没钱了”“买不起”“太难了”，都像是在心里盖了一块砖，把出口越砌越小。

你反复对自己确认限制，限制就会真的长成现实。你不断招唤匮乏，匮乏就会不断回头来找你。

这就是为什么，保持社交距离很重要。不是冷漠，而是保护自己的心理频率。少接触那些只会把世界说成一地鸡毛的人，多靠近那些谈解决方案、谈机会、谈成长的人。你的语言环境，就是你未来的预售广告。

停止用咒语给自己下套，开始用语言给自己点路。
