# 别让作业，偷走孩子的幸福感
作者：龙哥

昨晚和太太聊天时，她提到一些“海淀妈妈”的家庭：孩子每天写作业，常常要熬到半夜十二点，甚至更晚。

可北京初中生早上7点20分就要到校。算上起床、洗漱、吃早饭以及通勤，孩子通常六点半左右就得起床。假如凌晨十二点甚至一点才能入睡，睡眠时间显然远远不够。

这个年龄段的孩子，每天至少应该睡满8小时，条件允许的话，9小时更理想。偶尔一次晚睡问题不大，但把缺觉变成日常，身体和精神都很难长期承受。

所以我陪孩子写作业时，如果已经太晚，我宁愿让他直接查答案完成，甚至干脆不写，先去睡觉。作业不是不能补，睡眠却不是想补就能补回来的。

孩子的老师也表达过类似的观点：如果作业做到很晚仍没结束，家长可以给老师发消息说明情况，让孩子先休息。老师更看重的是孩子的健康，而不是为了完成作业，把睡觉时间全部牺牲掉。

长期严重缺觉，影响的绝不仅仅是第二天的精神状态。它可能让孩子更容易出现抑郁、情绪失控、学习效率下降、生长发育受影响、免疫力降低，甚至增加冲动行为。

哥伦比亚大学医学中心的一项研究显示，每晚睡眠不足5小时的中学生，相比睡眠充足的孩子，患抑郁症的可能性高出71%，出现自杀倾向的风险也高出48%。

很多家长之所以不停加码，并不是孩子真的已经无路可走，而是父母心里的期待太高。他们自己曾经成绩优秀，习惯了成为别人眼中的“学霸”，于是很难接受孩子只是普通人，甚至成绩落后。

我和太太的学生时代也算成绩不错。我高中时拿过全校第一，太太也曾是全县第一名。但我们从来没有要求孩子必须复制我们的成绩。

孩子一二年级时，成绩长期处在班级倒数前三，我还和太太说过：班里总要有人排在最后，为什么不能是我们的孩子？

现在他在北京一所普通公立中学读书，成绩大致处于班级中游。能认真努力就好，最后呈现出一个正常的结果，也完全可以接受。

很多人的焦虑，并非来自生活真的糟糕，而是无法接受自己比别人差。于是，家长之间互相比较，孩子之间互相竞争，大家一起被卷入一场没有终点的比赛。

但幸福从来不只取决于你拥有多少。

同样的生活条件下，欲望越少，越容易感到满足；期待越高，越容易觉得自己不够好。一个人真正的幸福感，往往来自“拥有的东西”和“想要的东西”之间的距离。

这并不是自我安慰，而是一种让自己和孩子都能过得更好的生活智慧。

当你总是向外比较时，幸福也就不再由你决定。你开不开得起宝马，未必决定你是否快乐；真正影响你心情的，可能只是身边的人开的是五菱，还是法拉利。

别为了几分成绩，让孩子失去睡眠、健康，以及本该拥有的童年幸福感。
