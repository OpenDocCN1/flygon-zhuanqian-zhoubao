大家好，我是龙哥，主要在 B 站做好物内容，目前也在参与 B 站好物深海圈。

从零开始做了两个多月，虽然暂时还没有拿到特别亮眼的成绩，但这段时间我一直在复盘流程、编写程序、制作工具，尝试解决选品、PPT制作、脚本整理、视频生产等环节中大量重复性的工作。

这次分享的重点不是“坚持就会成功”之类的泛泛经验，而是我亲自实践过、确实能够节省时间的操作方法。

内容主要包括：

- 如何提高好物选品效率；
- 怎样更快完成 PPT 和内容素材整理；
- 脚本创作与视频制作流程优化；
- 自己开发的提效工具；
- 影刀自动化程序；
- Python 代码及相关使用思路；
- 剪映视频制作的自动化方案。

如果你也在做 B 站好物，或者每天都在重复执行复制、粘贴、整理、排版等工作，这份经验或许能帮你重新梳理工作流，把精力放回到选品和内容本身。
