# 从20个问答出发，我试着还原龙哥的创业底层逻辑：产品、组织、个人成长与AI浪潮下的机会判断
作者：龙哥

你好，我是龙哥。

算下来，我在创业这条路上已经走过了七个年头，目前专注于企业级智能体（Agent）的定制开发。同时，我也是赚钱的老朋友了，加入这个圈子已经六年。2025年9月，我正式成为赚钱北京SCAI实验室的一员，另外还有一个身份——赚钱的航海家。

这段时间，我把龙哥关于业务认知、产品打造、团队管理、AI时代的机遇判断、自我觉察等多个维度的思考，系统地做了一次梳理。这些内容来源于我现场记录下来的20个问答，再加上会后的自由交流。我采用了OS（观察与自省）的方式，把自己这七年创业踩过的坑、正在推进的AI业务布局，和龙哥的观点放在一起对照、消化，最终沉淀出一套创业者可以实际拿去用的成长框架。

这份梳理不只是复述龙哥说了什么，更记录了我对这些观点背后的底层逻辑、当时的情绪变化，以及个人创业经验的理解和反思。我希望它是一份有温度的、可以反复翻阅的系统方法论。

它适合谁看？

- 正在创业路上的人；
- 专注AI领域的实践者（AI Maker）；
- 做运营和产品的伙伴；
- 想突破现有天花板的小微创业者；
- 想深入了解赚钱文化与底层方法论的朋友。
