# 在拼命往上走的阶段，别要安慰，要一盆冷水。

原文链接：[`www.yuque.com/for_lazy/zhoubao/qcswbqgl1rq40ifa`](https://www.yuque.com/for_lazy/zhoubao/qcswbqgl1rq40ifa)

作者：龙哥的收藏夹
日期：2025-12-12

当一个人正处在自我进阶的窗口期，情绪价值这东西基本就没用了。

我们碰到挫折，第一反应都是想找个人说软话：“别揍我，这锅不该我背，是环境太差、方法不对、赛道衰了、有人在背后捅刀。”这种安慰听着舒服，却等于把责任外包出去。

真正能推动你前行的反馈只有一个：问题在我。

愿意直面这个结论的人，才会去改、去试、去扛。越是斤斤计较当下舒不舒服、需不需要被哄，成长的脚步就越慢；反过来，越是能忍住被否定、被戳痛，迭代的速度就越快。

这不是冷血，是效率。
