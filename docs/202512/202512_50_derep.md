# 从裸辞到单月50万GMV，这个93年女生只用了16天：拼的不是天赋，是执行力

今天刷到一个让我无比激动的复盘帖——一位93年的深圳姑娘，裸辞后转型抖音自然流CPS，短短16天就做到了50万GMV。她说了一句特别戳心的话：“绝对执行力让我成为那个幸运的人。”

看到这句话，我忍不住想起身边很多想做副业、想搞钱的朋友。他们缺的不是信息，不是项目，往往就是那“把执行力拉满”的一口气。

这位姑娘叫纳豆，前金融人，在深圳打拼多年。今年她下定决心裸辞，开始摸索自由职业的路子。在此之前，她试过视频号分成、小红书电商、外卖CPS……每个项目都摸到了门，但总差最后那一下“跑通”的感觉。

直到今年10月，她遇见了抖音自然流CPS。

她回忆说，看招募帖的第一感觉就是：这个项目，跟我之前积累的经验全对上了！于是她给自定下目标，把执行力度拉满。接下来16天，她的成绩单是这样的：

3个账号，81条视频，3条万赞爆款，GMV从0直接飙到50万。

这中间当然不是一路顺风。流量爆过，也跌到谷底过。但靠着一轮轮复盘、一次次调整，她硬是把流量拉了回来。她说，整个16天就像坐了趟过山车，太刺激了。

如果你也想找一个能给你正反馈、能真刀真枪跑起来的项目，她的复盘绝对值得你细读。她会毫无保留地分享：

第一，她的转型心路，以及为什么选定了这个项目；  
第二，16天经历5个阶段的完整拆解：预热、摸索、爆发、低谷、爬坡；  
第三，3个账号81条视频背后的内容方法论；  
第四，流量掉入冰点时，她如何一步步自救杀回来；  
第五，现在入场的话，最值得优先抓住的关键点。

她说，希望这篇复盘能给你一些立刻能上手的参考，如果她的小成绩能成为你开始行动的推力，那就更好了。

我觉得，看完这篇帖，最好的感受不是“她好幸运”，而是“原来我也能走通”。说白了，很多爆款项目拼的从来不是天赋，而是你愿不愿意在别人犹豫的时候，先动起来。
