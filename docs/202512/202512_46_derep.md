# 双11期间23天用B站好物红包+引流玩法做到GMV破千万，净利润7万的实操复盘



大家好，我是龙哥，入局赚钱才几个月的新手。

从7月開始接触B站好物项目，到现在也就做了四个月多一点。没想到在双11大促期间无意间摸到了一套组合打法，从10月20号发现这个套路，第一天就冲出40多万的GMV，剔除退货后最终仍在35万左右。坚持用这套方法一路打到双11收官，整整23天累计GMV顺利突破1000万，个人到手利润7万。

11月2号我在深海圈连麦直播，把这套红包引流的打法给大家拆解了一遍。围观的同学反馈各不相同，有人直接靠它实现盈利，有人借助它把GMV拉到高位，有人收获了宝贵的实战经验，也有人因为操作偏差小亏了一笔。

从10月20号到11月11号，23天的周期里我也是实打实靠这个玩法吃到一波红利。现在回头看，机会窗口一出现就要全力抓住，一旦错过再想复制就难了。

双11的战役终于告一段落，我把这整套能做到千万级GMV的打法从头到尾梳理了一遍。里面包含了我个人的完整实操路径，和深海圈里其他同学的上手案例。基于之前的直播帖，我又补充了大量执行细节，完成了一版更完善的版本，现在全部公开出来，供做B站好物或同类带货项目的小伙伴参考。


在此特别感谢家蒙哥与龙哥老大提供的超级标，以及家蒙哥和赚钱联合打造的B站好物|深海圈项目提供的支持。
