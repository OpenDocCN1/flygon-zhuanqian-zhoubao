# (精华帖)(64 赞)（B 站好物）从月入 200 到双十一佣金 5W，GMV 637W+，赚钱新手 3 个月从 0 开始的复盘分享
作者：龙哥

标题：3个月，从月入200到双11佣金5W+，GMV超637W！赚钱新手如何靠B站好物超级标的逆袭？

你敢信？三个月前，我还在为月入200块发愁，可这次双十一，我竟然拿下了5W多的纯佣金，两个平台合计GMV超637W！我是龙哥，一个02年的互联网打工人，在赚钱潜水半年多后，终于踩中了B站好物超级标的这波红利。

10月9号到11月12号，京东平台带货GMV做到547W，淘宝平台也有90W，加起来637W+，做的是数码家电赛道。说实话，我自己都觉得像做梦。但回头看看，这段从0到1、再到1到10的旅程，其实每一步都有迹可循。

这次复盘，我特意把关键节点整理成了7个要点：怎么判断一个项目适不适合自己？起步阶段该做哪些事？0到1要怎么破局？选题有哪些挖掘方法？放量阶段容易踩哪些坑？从1到10怎么继续扩展？还有一份可以直接上手的启动清单。

作为新手，我也走过不少弯路。比如刚开始做选题完全没方向，硬着头皮摸索才找到感觉；比如放量时的节奏没掌握好，也吃了点亏。还好有圈友老师们的指点和鼓励，让我一步步走了出来。在这里真心感谢大家，也欢迎更多朋友随时交流，一起进步。
