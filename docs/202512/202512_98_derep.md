# ('(29 赞)不知道为什么忙碌时，不妨列一个清单', (2, 25))

当你感觉自己明明很忙，却又说不清忙了个什么劲儿的时候，试试先停下来，拿出一张纸，把事情写下来。

这招听起来简单到有点儿傻，但一百多年前，它就已经值两百万美元了。

1890年的匹兹堡，一场鸡尾酒会。钢铁大王卡内基正叼着雪茄，被人引荐来了一个叫弗雷德里克·泰勒的年轻人。泰勒当时以搞管理、提效率出名，卡内基半信半疑，丢下一句话：你能给我讲点管用的管理真东西，我就给你一万美元的支票。

泰勒几乎没怎么犹豫，回答说：先生，您就列出十件最该做的事，然后按顺序一件一件干。

一周后，支票真的寄到了泰勒手上。那一万美金按今天的黄金价算，差不多等同于现在的200万美金。

卡内基当时到底在想什么，已经没人能考证了。但这个故事的荒诞之处恰恰说明了一个道理：最值钱的建议，往往也是最朴素的建议。

泰勒后来成了科学管理的奠基人之一，他让你列清单，并不只是让你把待办事项堆一起。真正的关键是，在写下的瞬间，你被迫去做一次取舍：什么才算重要，什么只是看起来很忙。

清单的威力在于它能逼你对抗两种现代病：拖延和迷茫。写下来之后，事情从脑子里飘忽的层面落到了纸上，也就有了先后顺序，也有了备份，不会再被遗忘。

我最近在看《私家侦探》，虽然评分不高，但它戳中了一个很普遍的痛点。夫妻在一起久了，沟通会慢慢钝化，感受会被忽略。每天被工作、琐事填满，忙得不可开交，忙完才发现真正该关心的人和事，反而被搁到了一边。

其实很多时候不是生活太忙，而是我们从未认真盘点过自己的忙碌。把一天在做的事列出来，你会惊讶地发现：有些事很重要，有些事根本没必要，甚至有些事在悄悄消耗你。

忙到懵圈的时候，别硬扛，先列清单。把乱糟糟的脑子清空，你才会看清，什么值得你花时间去做。
