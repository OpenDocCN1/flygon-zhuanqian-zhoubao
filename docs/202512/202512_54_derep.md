# (精华帖)(79 赞)《b 站好物从佣金 2 位数到百万 gmv，只用了 30 天，我是怎么做到的》
作者：龙哥

谁能想到，30天前我的B站好物佣金还只有两位数？从赚到两位数的佣金，再到把百万GMV踩在脚下，我只用了一个月。

大家好，我是龙哥，一个入圈第二年的00后赚钱圈友。

先说说我走过的路：佣金从0到1000，我用了将近一个月。但从1000到月入过万，再到GMV突破百万，一个月就够了。双十一那波大促，我的总成交额冲到500w+，到手佣金6w+，同样只花了30天。

有趣的是，“一个月”似乎成了我的成长节拍。

账号刚起步那阵子，圈友@小源 从后台找到我，我们拉了个小群，毫无保留地交换想法和信息。没有这种不计较的互通有无，就没有我今天的成绩。

正因为我从分享里实实在在拿到了好处，我也想把经验摊开来，给更多圈友当垫脚石，大家互相激发，一起把这个盘子做大。


一路走来，收到不少圈友的认可和鼓励，评论区里也有人在问“新号没粉怎么办”——我的建议是：先找到对的人连上线，或者，直接买一批粉，把冷启动的坎迈过去再说。

一起加油。
