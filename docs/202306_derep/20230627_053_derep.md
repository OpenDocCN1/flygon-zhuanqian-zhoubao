# 啥都没有的全职宝妈，如何在航海结束当天收到第一笔收益？

哈喽，我是小梦。

先说我参加航海前的状态吧，用一个词形容就是“空空如也”——个人IP是零，内容作品没做过，能拿来卖的产品也不存在。身为全职宝妈，我每天围着孩子和家务转，心里却一直藏着个小念头：想做点自己的事，可又总觉得自己没什么拿得出手的本事，连“变现”两个字怎么落地都弄不明白。

那这趟航海，到底是怎么把我带上岸的？其实一开始，我也只是抱着“试试看”的心态上船。没有基础、没有经验，好在够听话、够认真，跟着节奏一点一点往前走。神奇的是，走着走着，我居然把项目从无到有地做通了，整个流程完整地转成了一个闭环——从找方向、做动作，到收到第一笔收益，每一步都踏踏实实走了一遍。而就在航海结营那天，这笔收益真的进了我的账户，真实得让我有点不敢相信。

我把这段经历写出来，不是想证明自己多厉害，而是想告诉你：像我这样三样全无的新手，都可以通过航海把一件事从无到有地跑起来，你也一样可以。
