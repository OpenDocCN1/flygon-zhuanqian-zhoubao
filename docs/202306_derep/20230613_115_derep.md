# ('时间管理的几个理论方法实践使用心得和经验分享', (2, 24))

你有没有感觉一天忙到晚，却好像什么都没做成？反正我是深有体会。作为一个有十几年经验的网络工程师，又要管工作、顾家庭、陪孩子，还得兼顾学习和自我提升，前几年我确实被时间压得喘不过气，甚至一度连赚钱的圈子都不敢续费了。直到这几年反复折腾、不断调整，我才觉得自己终于能掌控住节奏了，今年也重新回归了龙哥盟。

下面这些，是我踩了不少坑之后总结出的心得，希望能给你一点参考。

先说几个我最想强调的认知：

第一，时间比金钱更稀缺。钱花完了还能再赚，但是时间一旦流走，就真的回不来了。所以，得把时间当成最珍贵的资源去对待。

第二，时间管理不是一招鲜，它是一个循环改进的过程。学方法、去实践、做复盘、再调整，然后再学再练，慢慢打磨出适合自己的节奏，最后坚持成习惯。

第三，一定要有目标，而且要把目标写下来，经常回看完成进度。有目标和没目标，人的状态差太多了——有目标的时候，你会主动珍惜和使用时间。年目标、月目标、周目标、日目标都要有，定期检视，适当调整。

第四，事情永远做不完，只能优先做那些真正重要的。

接下来聊聊那些核心方法。我看了不少课程和书之后发现，所谓的各种流派，其实底层都是几个经典理论在做组合和延伸。搞懂这几个，再结合自己的情况去实践就够了。

“三只青蛙”：每天从年、月、周、日的清单里，挑出最重要的三件事，集中火力去吃掉它们。先解决那只最丑最大的，避免被琐事带着跑。

“番茄工作法”：25分钟专注干一件事，然后休息5分钟，再开始下一个番茄钟。也可以根据任务性质把番茄钟调长一些。这个方法尤其适合用来打败走神和拖延，靠一个个番茄钟让自己沉浸到任务里。

“GTD”：核心是把所有想做的事都收集到一个清单系统里，流程上就是收集、整理、组织、回顾、执行。这样做是为了让大脑从记忆负荷中解放出来，只负责思考。

“四象限法则”：按重要和紧急程度，把事情分成四个格子。优先处理重要紧急的，紧接着安排重要不紧急的，不重要但紧急的看情况处理，既不重要也不紧急的，记录一下就好，不必花精力。

“两分钟原则”：凡两分钟内能干完的事，别犹豫，立刻干掉。

“二八法则”：把注意力投在那些真正产生价值的20%的事情上，其他的不用太上心。

我个人的做法，是把这些方法串起来用，配合几个小习惯：

先用GTD把所有想到的事情都倒进清单里，清空大脑；再用四象限、二分钟原则和二八法则来做分类，确定哪些是马上要做、哪些是重点、哪些直接忽略；然后每天早上从清单里挑出当天的“三只青蛙”；在做青蛙任务的时候，开启番茄钟让自己进入专注状态，而且尽量把最难的青蛙安排在上午精力最好的时段，别拖延。

再分享一些我自用的生活经验：

早睡早起真的香。早起避开早高峰，到得早、打扰少，效率非常高。早上可以稍微运动一下，让全天精力更好。通勤路上的碎片时间也被我用来听书、看文章、做规划。睡前别刷手机，否则越刷越清醒。平时少扎堆闲聊、少看没营养的八卦群。每天固定给自己定目标，否则很容易被乱七八糟的事牵着鼻子走，到了晚上又觉得一事无成。年度目标要拆解到月、周、日，周期性地复盘和调整。重要的事尽量在上午搞定，下午处理些计划外的杂事或者休息一下，晚上留给家人。最后，身体是革命的本钱——睡眠和健康出了问题，再好的时间管理也撑不起来。

如果看完这些，你决定行动起来，可以参考这条路径：先找个时间，把所有想做的、要做的事统统列出来；然后按紧急重要度，抽出本月要推进的事；再细化出本周的安排；每天早起或睡前，回顾昨天的完成情况，顺手列出今天的待办清单；接着，坚持早睡早起，早点出门、早点开干；上午集中攻克重要的事；有条件就午休一小会儿，恢复精力；下午继续按计划推进，或者处理临时冒出来的事；晚上安心陪家人、学习或放松；最后，早点休息，别熬夜。

顺便推荐几本我觉得很受用的书：《高效能人士的7个习惯》（史蒂芬·柯维）、《时间管理》（吉姆·兰德尔）、《博恩·崔西的时间管理课》（博恩·崔西）。

有人问我，道理都懂，可就是做不到怎么办？我也还在练习中。就像评论区里说的，时间管理的底层其实是精力管理，方法学完了，还得靠慢慢养成习惯。好在你我都还在路上，多尝试、多调整，总能找到适合自己的节奏。
