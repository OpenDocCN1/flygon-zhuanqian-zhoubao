# 小红书账号被限流了？用一招实战自检就知道

原文：[`www.yuque.com/for_lazy/thfiu8/zu2rlouhd61czhbz`](https://www.yuque.com/for_lazy/thfiu8/zu2rlouhd61czhbz)

最近身边做小红书的人越来越多，普遍的困扰都差不多：笔记发出去后，播放量卡在几十、百来个不动，第一反应就是账号是不是被限流了、是不是出了问题。

基于操盘几十个账号的实操经验，这里分享一个快速判断账号健康度的自测方法，收藏起来备用。

思路很简单，就是用一个高流量且好做的题材去试探平台的推荐反馈。

具体操作是这样的：去找一个当前热度很高的话题，最好是能用最简单的形式呈现。拿一张纸和笔，手写一个容易引发评论和共鸣的提问或者观点。关键点在于内容必须原创，千万别用截图、搬运或者网上的现成素材，手写拍摄是最稳妥的原创证明，然后直接拍成视频或照片发布。

判定标准也很清晰。如果这条笔记的小眼睛播放量还是过不了 500，那基本可以认定是账号层面的问题，需要考虑放弃重建。如果心里没底，可以连续测 3 次，只要 3 次播放量都稳定在 500 以下，那就基本确定是账号受限了。

如果这条测试笔记的播放量能突破 500，说明平台的推荐通道是通的，账号本身没有被限流，问题出在你的内容选题、呈现方式上，需要从内容本身去优化。
