# 同城门店内容就做三类，循环拍就行

人设向、吸粉向、用户评价向。

为什么是这三类？

人设向负责攒信任。

吸粉向负责吃到同城推流，给账号打上地域标签。

用户评价向让观众看清楚你的服务是什么样，专业、划算、效果可验证。

一般配比是四个用户评价加一个人物介绍加一个吸粉，然后循环。

想把抖音、小红书做起来，关键是产出速度要快，并且要一直更。

「做生意需要不断的客流，绝不靠一条爆款吃半年甚至几年」

所以必须用框架填空，把素材往里一放即可。

## 人设向细拆

第一人称口述的人设，第三人称素材拼剪的人设。

## 吸粉向细拆

第三人称正能量素材，第一人称正能量口述，第一人称蹭热点头条口述。

## 用户评价向细拆

第一人称口述服务过程，第三人称口述服务过程，第三人称纯素材展示客户好评。

分到这层就够用。

眼镜店这么拍，大部分同城门店逻辑一致。最省心的办法就是直接对标同行一比一抄。
