# ('短剧 cps 世界的另一面：付费短剧买量', (2, 22))

标题：短剧CPS之外，还有一门更烧钱的生意叫“付费短剧买量”

先澄清一个误区：很多正在做短剧CPS的朋友，看到的其实只是蛋糕的一小块。在更上游的位置，还有一群靠投放广告放大收益的玩家，他们干的事叫“付费短剧买量”。

我是HEXIN，龙哥盟的老会员，已经在买量变现这个领域泡了11年。最近参加短剧CPS小航海，发现大家对这行的认知普遍缺了上游这块拼图，所以想补上这个视角，聊聊付费短剧买量不为人知的一面。

一、短剧到底是什么？

你在抖音、快手刷到的短剧，单集也就一到五分钟，制作谈不上华丽，但胜在剧情密、反转多、情绪拉满。所谓“戏剧性强”，拆开来说就是：矛盾要够尖锐，情节要够意外，演员的情绪要够外放。

国内短剧的源头，往前倒可以到2012年。但真正的引爆点，其实是2011年德国那部喜剧小品《屌丝女士》，当时火得不行，搜狐跟着仿了一部《屌丝男士》，主演是大鹏。从那以后，国内才有了“短剧”这种内容形态。不过那时的短剧，题材基本是青春、家庭、职场这些路子，跟今天要聊的付费短剧，完全是两个物种。

二、付费短剧是哪儿来的？

付费短剧和社交平台说的短剧，千万别画等号。它是2020年前后冒出来的，真正的前身，是得间、七猫这些小说App在抖音上的投放素材。

当时给小说App做买量，素材就两类：真人演剧情、直接晒第一章。后来那些投手发现，真人演出来的剧情素材成本虽高，但跑量效果出奇得好。谁第一个脑洞大开，决定专门拍短剧来做投放增长、靠用户直接付费来变现，已经说不清了，但真正把这事做成产业的，是嘉兴九州。

三、付费短剧都在拍什么？

题材看着五花八门，其实归纳下来就五类：赘婿、神医、战神、总裁、言情。其中前三种的量级和吸金能力，明显好过后两种。背后的核心密码，只有一个字：爽。

四、看付费短剧的到底是谁？

很多人做短剧CPS，却连用户长啥样都没搞清楚，我直接给画像：

男性占八成，女性只占两成；年龄集中在30到50岁以上；手机以安卓为主，买量圈习惯用设备价格来判断人群价值，这批用户的手机基本在一千到两千块这个档位。

把这几个指标放在一起，感受一下：收入不高，闲时不多，现实很难改变，但心里还有盼头，情绪又需要出口。我朋友说过一句很精辟的话：女性能靠购物宣泄，一二线城市的人能刷B站、看电影、充爱奇艺会员，有钱人更不用愁没地方消遣；唯独这批用户，只有几块钱、几分钟，看点“爽”的东西来撑过生活，付费短剧就是这么长出来的。

五、一部付费短剧是怎么做出来的？

整个链条不算复杂，核心五步：

第一步，选剧本；第二步，买版权。早期绝大多数短剧都是从小说改编的，所以找小说平台拿IP授权几乎是唯一选择。现在也有团队能自己写本子了，但没有IP加持，各有各的难处；第三步，定演员；第四步，拍摄加剪辑。拍摄大概需要五到十天，算上后期，二十天左右能产出一部能上量投放的剧。成本也是水涨船高，最早一部十万，现在已经到了三十万，请小明星的甚至能冲到百万。

六、这个生意里的角色怎么分工？

搞懂这几个角色，整个链路就通了。

版权方：相当于把小说版权拿到手、再把短剧拍出来的人。嘉兴九州是典型代表，南京花生书城、杭州容量也是这行的熟脸。

买量分销商：拿着版权方的授权，去抖音、快手、腾讯等平台投广告的人。有时买量分销商和版权方是同一家，比如九州，拍摄和投放都很强。花生则投放能力弱一些，干脆就作为版权方把剧大量外放出去，和分销商按九一分账。

短剧分销平台：比如麻雀、创作猫这类，可以理解成版权方的下游。关于它们，我了解得相对少些。

七、砸钱买量到底能不能赚？

从2020年算起，付费短剧买量已经跑了两年多，现在进场，红海无疑。早期买量，当天回本是常态；现在得把出价卡得死死的，首日回不到90%，后面基本就是亏的。

更要命的是单部剧的生命周期：好一点的撑几周，差一点的几天就凉。所以这门生意的核心，不是拍得多好，而是从拿到剧到这部剧退场，你对整个节奏的把控能有多快、多准。门槛已经摆在那了，手里没有一支成熟的买量团队，奉劝各位慎入。

八、那短剧CPS还能碰吗？

这行在赚钱圈里做的人太多，我不直接下结论，就说两面：

优点很实在：门槛低，连实名都不用。

缺点同样扎眼：

一是绝大多数付费短剧，首发权永远在买量分销商手里，你在分销平台看到的剧，早就在抖音上被跑过好几轮了，所以别指望靠它一夜暴富。

二是“能不能爆”这个问题，站在短剧分销的视角根本看不全。比如买量已经跑爆的剧，该不该接着做？那些成熟团队操刀的买量素材，有没有可以抄作业的地方？全网短剧素材去哪儿看？

把上游补上，你再回头想想这件事，答案可能就不一样了。

评论区里也有很多内行人补充了一点关键信息：短剧买量资金门槛极高，公司进场往往是千万级别；回本周期一般在1到3天，过了三天收不回来，后面基本没戏；扣掉分成和人工，利润点只有5%到10%，目前竞争激烈，行外人别乱入。还有人提到，平台手上的剧什么时候放给下游，是版权方说了算，这就是为什么别人拿到的剧永远比你的新。另有消息说，短剧已经出海了，变现方式和国内既有相似，也有差异——想继续深挖的，可以顺着这条线再研究。
