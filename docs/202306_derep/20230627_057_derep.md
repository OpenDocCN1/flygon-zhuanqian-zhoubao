# 结果不在终点，藏在重复与概率里

> 点子源自：生财有术 · 一位叫 Cris 的成员公开复盘（文字经大幅改写）

## 真正的原因，往往不在终点附近——收成=行为×概率

作者：Cris（2023-06-19）

【航行收尾时的觉察：想少一点焦虑，就早一点动手】

刚进这个圈子的时候，我特别容易慌：看到别人晒收益，自己却没有进展，心里就很毛躁。后来发现，与其反复纠结方法是否完美，不如先把一个动作重复到形成惯性，行动本身就是最好的定心丸。

说说这期公号写作航行的结果。整个过程接近尾声时，终于有一个账号被推荐池选中，截至6月15日，累计到手收益600多元。和那些单日就能赚到上千甚至过万的同行比，确实不值一提；也没能把报名费挣回来。但一切都在我的预期里。

为什么会预期到呢？

因为导致最终结果的因素，几乎从来不会紧挨着最终收获出现。它们藏在你每天重复的动作里，藏在你给自己积累的样本量里，藏在说不准的运气波动里。最终回报并不是某个聪明决策的即时奖励，而是你反复做了什么、以及它撞上了多大的概率，两个变量相乘后慢慢滚出来的雪球。

真正的诱因总与最终表象隔得很远；收成是好是坏，取决于你重复做了哪些事，以及这些事碰上了怎样的概率。

这个认知在我这轮航行里得到了验证。前期流量平平，我也没指望一夜入池，只是持续地写、持续地调整，让每一次动作都被统计进概率的基数里。后来入池，与其说是突然转运，不如说是前面那些看似无用重复的动作，终于等到了概率的响应。

有人问，情感类内容有了一些正面回应之后，私域承接和后续变现打算怎么做？我的想法是还没深入规划，趁现在有空档，先把账号矩阵铺开。亦仁在留言里鼓励道：零基础起步，三周时间就产生正向收益，这个苗头很好，后面大概率会越滚越大。我回了一句，这就开启下一轮。

另一位朋友说自己没跟着集体节奏走，只按精选指南来操作，用AI生成内容，新号几乎没有阅读量。我给的建议是，先保证每日更新不断档，让系统认识你。还有人说每天产出八篇稿子太累了，也有朋友表示自己同样处在冷启动期，除了自己几乎没人点开看；但只要熬到账号被选入推荐池，动力就又回来了。

这些互动让我更确认一件事：焦虑的对立面不是运气，而是手头正在做的动作。
