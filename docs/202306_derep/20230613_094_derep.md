# ('在加油站加油时被推销「燃油宝」的感想', (2, 20))

在加油站被推销“燃油宝”，我这种防备心爆棚的人，居然也乖乖掏钱了。

今年四月，我从唐山开车回北京，中途进加油站补油。刚加完，工作人员就开始跟我安利一款“燃油宝”，说能清积碳、让油更耐烧。说实话，当下我是信不过的，但最后还是买了一瓶。等到回了北京，上网一查，才确定自己交了“智商税”。

回头复盘整个购买过程，我发现这套推销其实设计得非常巧妙：我脑子里闪过的每一个犹豫点，对方似乎都提前准备了答案。那种“好像哪里不对”的感觉刚冒头，就被对方用话术按了回去。买到的未必是产品，而是一种“风险已被控制”的错觉。

想通这点，后背有点发凉：原来真正高明的骗局，不是让你完全放下怀疑，而是在你每一个起疑的瞬间，都递过来一个“合理”的解释。到最后，连你自己都找不出一个拒绝的理由。

评论区里也有人分享了自己的遭遇：有的被报价50元一瓶，还要硬塞两瓶再带四瓶；也有人做过汽车售后，说这类东西从厂家或外部拿货，成本可能只有十几、三十几元，到消费者手上却是一百多甚至更贵。看完更觉得自己交的学费，其实买的是教训。

做生意也一样：最高级的成交，从来不是强行说服，而是把客户所有拒绝的借口，一个一个温柔地拆掉。
