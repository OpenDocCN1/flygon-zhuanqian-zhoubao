# ('我是怎么从低谷走出来的？', (2, 14))

你有没有经历过那种感觉：每天忙忙碌碌，却始终看不到一点水花；看着别人接连出结果，自己却只能在原地打转？

两年前，我曾经就是这样一个状态。挤在星巴克的角落里，没有工作，没有方向，一个看似“无业”的年轻人。

今天我想和你聊聊，我是如何从那段灰暗的日子里一步步爬出来的。没有惊天动地的逆袭，没有普通人够不着的资源，有的只是一些用血泪换来的教训。

如果你也正处于低谷期，希望这篇文章能给你一点力量。

**敢于承认自己不行，才是翻盘的开始**

2019年年中，我解散了创业团队，宣告失败。但说来可笑，那时候的我并不觉得自己有什么问题——毕竟职场顺风顺水，创业也曾有过高光时刻。我不愿意面对自己的不足，更不愿意重新回去上班。

可问题来了：我不知道自己该做什么。

偶然间，我想起曾经冲动付费加入的一个社群，一个谈钱不伤感情的圈子——生财有术。

刚开始刷里面的帖子，我的心情很复杂。一边是惊喜：原来世上还有这么多闻所未闻的赚钱路子；一边是焦虑：怎么别人随随便便就月入十万，我却一事无成？

更糟糕的是，看多了帖子之后，我产生了三种错觉：

第一，我觉得“我也行”——光看的话，这些项目好像也没多难。

第二，我觉得“我资源很多”——毕竟能跟这么多牛人待在同一个社群里。

第三，我觉得“我有很多选择”——项目这么多，资源这么多，机会肯定少不了。

于是我开始约人聊天、挑项目。跟圈外的朋友聊时，我总是不自觉地“狐假虎威”：哎呀这个项目真的不错，我社群里有朋友做这个赚了多少多少……

听起来忙忙碌碌，其实空虚至极。

因为我慢慢发现：挑来挑去，不过是因为我根本不知道从哪里入手；聊来聊去，聊的都是别人的成功故事；看似选择很多，其实一个都抓不住。

看清楚这一点后，我狠下心结束这种“只看不做”的状态，选了一个当时门槛低、试错成本小的项目——抖音小程序。

那段经历教会了我两件事：

第一，认清自己的位置。不管你以前多厉害，换到一个新领域，你就是个啥都不会的新手。放低姿态，从零开始学、从零开始做。

第二，要有真下场去干的勇气。当观众很容易，当评论家很容易，但当实干家很难。因为实战会撕开你的所有伪装，让你看到自己有多不足。这个过程极其痛苦、极其反人性，但不经历它，你永远只是个自以为了不起的旁观者。

**优质的圈子，能让你少走很多弯路**

回头看，2019年年中是抖音小程序红利最大的时候。

当时有不少人踩中了这波机会，甚至刚毕业的大学生，都做到了月入十万。红利是真的香。

但我的剧本，却是另一个版本。

我花了1999元，通过圈友的介绍，加入了一个专门做抖音小程序的实战社群。回头看，这个选择至关重要——因为单靠我自己，根本走不到后面。

当时的条件其实不差：红利期正好、圈子也靠谱、课程系统全面、群里还有一大批拿到结果的圈友。

但问题出在我身上——我一直做不出成绩。

那段时间，连好朋友都来劝我放弃。他说他让员工做了半个多月，只赚了几块钱。换作以前，我可能早就不干了。

但好在，我所在的实战社群确实给力。老师会答疑、会指导，群里每天都能看到普通学员爆单的分享。这些活生生的例子不断告诉我：再坚持一下，你也可以。

这段经历让我深刻理解了“圈子的价值”。

很多人说“要相信相信的力量”，但相信不是靠喊口号喊出来的。当你迟迟拿不到成果时，你靠什么去相信？当你身边所有人都没做成时，你又凭什么坚持？

反过来，当你看到一群起步比你晚的人都在持续拿到结果，你还有什么理由不信？

而且，圈子的垂直度很重要。跟泛圈子的朋友聊，只能聊风口、聊方向；跟做同一个项目的人聊，才能聊可落地的操作细节。前者帮你开眼，后者帮你干事。

**专注，才是一个人的核心竞争力**

你可能觉得，敢下场了，圈子也找对了，还踩中了红利期，那不就该出成绩了吗？

并没有。

在这种条件下，我足足熬了三个月，才等到第一个正反馈。

刚进实战社群时，我天天看别人爆单。很多还是兼职带娃的宝妈，从时间和阅历上看远不如我。

而我呢？从基础来看，我以前创业时做过抖音，亲手拍出过不少百万播放的视频；从时间上看，我是全职投入，没有孩子需要带；从资源上讲，手上有七八张手机卡、七台手机。

当时我信心爆棚，觉得一周之内就能挖到金矿。

结果呢？三个月，日收益基本为零。偶尔有一两块，投豆荚还亏了一千多。

实在想不通，我约了社群里的一个老师做语音诊断。

老师问：“你做了什么玩法？”

我说：“三个号做A玩法，两个号做B玩法，还有两个号正在尝试新玩法。”

老师说：“先集中精力做一个玩法，三个号就够了。忘了你有多少手机多少号。”

然后就结束了。

我照做，第7天出了第一个百万播放视频，第10天日收入破千。

拿到结果的那一刻，我突然愣住了——

**“过去三个月，我一直在不同玩法之间横跳，居然从来没有在任何一个玩法上专注超过一个星期。”**

现在项目的竞争程度远高于当年，更要求深度专注才能出成果。但对新手来说，专心深耕一个项目的单一玩法，往往被严重低估。

“专注”不是专注在某个平台，也不是专注在某个大方向，而是专注在具体的一个玩法上，甚至是你当前玩法中最难的卡点上。

这也是为什么很多兼职做项目、空闲时间不多的人反而更容易做出来，因为他们没有那么多选择，也没那么多诱惑，反而更容易全身心投入。

如果你下场了却迟迟没有进展，不妨问自己：

·你每天的时间和精力，有多少真的花在了你正在做的这一个玩法上？

·你连闭环都没跑通，有什么能力去筛选、拼接不同教程里的信息？

·你盯着无数新项目看的时候，有没有想过：抓稳手里的一个，才可能改变现状？

**主动输出，是你给自己埋的最好的彩蛋**

做出一点成绩后，我第一时间写了篇保姆级教程发到社区。

动笔时其实没想太多。没有课要卖，也不知道加好友能有什么用，只是单纯想感谢这个平台让我看到了那么多信息和机会，也希望能帮到和我一样曾陷入困境的人。

但没想到的是，这篇帖子给我带来了三个意外收获：

写帖的过程，逼我系统地做了一次复盘。哪些动作有效、哪些无效，一下子就清楚了。之后很快就迎来了第二次、第三次爆单。

有人看到帖子后想跟着我学习，我就顺势做了之前那个实战社群的分销员，第一次尝到了知识付费的甜头。

公众号也收获了第一批粉丝和阅读量。

甚至现在做训练营的整套体系，也在那时候开始有了雏形。

更重要的是，这次输出让很多人看见了我，让我在搞笑号红利消退时，能及时找到新的机会。

**主动输出，从来不是纯利他。它帮你想得更清楚，也让更多人看到你，给你带来更多未来可能性。**

IP不是“打造”出来的，而是“活”出来的。你有什么干货，愿意真心分享，自然会吸引同频的人。没有干货，硬凹人设，最多割一次韭菜，然后就没有然后了。

**写在最后**

网上很多人说，要有长期目标，才能走得更远。

但对普通人来说，哪有什么坚定的长期目标？哪能一步步规划得清清楚楚？就算规划好了，又哪有能力全部执行？

回头看我的经历，很多机会、很多方向，都是“遇到”的，不是“设计”出来的。

我开始做项目的时候，哪想得到以后会做培训？开始写公众号的时候，哪会想到能日更这么久？做搞笑号的时候，哪料到这个项目这么快就会衰落？

**普通人该做的，就是踏踏实实把手上的事做好。在这个过程中，提升认知、积累能力、沉淀资源。然后，你才有机会看见更好的机会，也才有能力抓住它。**

所以，如果你此刻正和我当初一样，陷在困境里，别想太多，别精神内耗。

就先专注做好手头的事，跑通闭环，赚到钱，活下来。

等你做完这些，更好的机会，自然会向你走来。

与你共勉。
