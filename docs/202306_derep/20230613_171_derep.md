# 站在平台的立场看问题，你的推文引流会更顺

作者 文老师  
2023-05-31

最近在 5 月航海的小说推文群里，我把《从平台角度聊一聊推文技巧及高效化引流》这部分心得跟大家做了同步。这次聊的重点只有一个：换个视角去看。

无论是做小说推文，还是运营小红书店铺一类的项目，很多人都容易陷进细节里，整天琢磨那些性价比很低甚至有点“玄学”的操作，最后费时费力收效甚微。

其实在做任何关键动作之前，不妨先做一道思维换位：假如我是这个平台的产品经理，我会怎么去限制、怎么去引导这类行为？换位思考之后，很多问题的解法自然就浮现出来了。
