# 用后羿采集器在蝉小红采集行业信息的保姆级教程

用后羿采集器+蝉小红，手把手教你挖出小红书电商的蓝海品类

做小红书电商的都知道，选品和投放不能拍脑袋，得有数据支撑。可很多人卡在拿数据这一步。我摸索了很久，总算把一套“后羿采集器+蝉小红”的组合流程跑通了。今天就把这份保姆级教程分享出来，照着做，你也能把行业数据轻松抓到手，还能算出哪些品类有机会。

开始前的准备

首先，你需要一个蝉小红账号，个人专业版就够用。考虑到价格偏高，有个省钱办法：去官网把页面拉到右下角，能看到“领取7天专业会员”的入口，先薅一周试用。官网是 https://www.chanxiaohong.com/ ![](img/8bb3e58c67c233c8a69569b693b69480.png)

另外，需要一个叫“后羿采集器”的工具。它是免费的，到官网 https://www.houyicaiji.com/ 下载安装就行。 ![](img/eec5157c6bbfbf7757893b7d117f7936.png) 装好后登录，没注册的话先注册一下。 ![](img/3a70876700863850461bada57621caec.png)

采集操作流程

先在浏览器里打开蝉小红，想清楚要抓什么页面。做电商数据分析，一般看两个地方：品类库和商品库。 ![](img/d6287d99b0586d55d3bd2dcf66301d5a.png) 我这里用品类来演示。左侧点“品类”，再进“品类库”。 ![](img/62913630a5afe04d40afb1ecac5ae127.png) 进去后能看到所有品类的数据。 ![](img/4128a2090ee137505d9f042fb5dd283c.png) 下一步，把地址栏里的链接全选复制。 ![](img/273421422bbe08fa3c1094e8bf2ae08e.png) 如果不想手动翻，可以直接用这两个地址：品类库 https://www.chanxiaohong.com/categoryLib ，商品库 https://www.chanxiaohong.com/goodsLib 。后面按品类库来。

把链接粘到后羿采集器的地址栏，点“智能采集”。 ![](img/ac8cd4bd37e37a40ad1929f966236f1f.png) 这时会进入配置界面。 ![](img/1424d1a92aea6cef3c5df1b1d24b082d.png)

配置采集器

注意，采集器还没登录蝉小红，所以要先点“预登陆”。 ![](img/7c5d2e28ae755273443f627aa6ed762d.png) 弹出来的新页面里完成登录，再点“登录完成”。 ![](img/ceed686344f550118cd4f2491b0af37f.png) 后羿会自动抓取一些页面数据。 ![](img/616b986886f6814b70ff6ce03995ddd9.png)

如果你想改变统计周期，比如改成30天或90天，直接在后羿页面点是点不动的。 ![](img/614d4c755d5a345ebbb89e0cf7ddd64d.png) 正确做法是用“执行预操作”。 ![](img/4b01077708e8724ff7e0761ecddcd263.png) 点一下会弹出个小窗口。 ![](img/ae4018dd75ca01d45642a03a8fa0979c.png) 假设想选30天，就在窗口里先点一下“30天”，左上角会出现两条操作记录。 ![](img/dc5da36d0f13dec03951be67649db70b.png) 选择“点击一次该元素”。 ![](img/3c7d71f065dd2a8801d08e9b37ac0094.png) 这时流程面板里会多出一个自动点击动作，之后采集前它会自动帮你选中30天。点右下角“保存并退出”。 ![](img/63f7744c4408714ef782f14f57083511.png) 回到任务编辑页，周期已经变成30天。

接下来设置分页。点开“分页设置”下拉框，选“瀑布流分页”，让系统模拟滑动页面来加载更多内容。 ![](img/6c81110bda5152707aac3f697ddddb6d.png)

再点“设置采集范围”。 ![](img/d957b266e711581602ce4d7fca50cc47.png) 起始页选当前页，结束页选最后一页，确定。 ![](img/240564e7869a9f748edde4ad339395d6.png)

正式采集与导出

配置搞定，点击“开始采集”。 ![](img/d275134c1ecff2be5308b578c7f16e50.png) 弹窗里直接点“启动”。 ![](img/6ed82a43b94483b9095d797024567c2b.png) 采集就跑起来了。 ![](img/5aaf3a06c38e935ab271aef2a0b1b526.png) 品类库提供了2450个品类，全抓完大约15分钟。右侧能看到进度状态。 ![](img/5d2e1dc48576e3f29db9c2b68117cef2.png)

完成后，点“导出数据”。 ![](img/3b59025f8c4eef484dd1c8fcbf32fb9b.png) 选好保存路径，格式用默认的Excel就行。 ![](img/7f279b0bdd6bf46cac1cd5a3af2e4d59.png) 点“导出”，进度到100%就完成了。 ![](img/54b7419dddd32f3f301c14b705badc8b.png)

数据处理与选品分析

打开Excel，长这样。 ![](img/bc9bea2804d0afb40b80c1830377f91b.png) 先把没用的“字段1”“字段2”删掉。

这里有个坑：有些数字后面带“w”，比如9.9w，不处理没法排序。用公式把带w的转成纯数字，让9.9w变成99000。在E列第一行写：=IF(ISNUMBER(SEARCH("w",C1)),LEFT(C1,LEN(C1)-1)*10000,C1) ![](img/a1b1dcb7f6bd21dc510040bd79984b00.png) 填完效果立现。 ![](img/fffadfa8bb90540970b27fbaf43aa9a1.png) F列同理：=IF(ISNUMBER(SEARCH("w",D1)),LEFT(D1,LEN(D1)-1)*10000,D1) ![](img/cfb7a0a6bd8917d0e2f3fe3363559111.png) 这样1107.4w就变成11074000，E列和F列就能正常计算了。把这两列的公式复制到下面所有2400行。 ![](img/ff295a9d3c7552092ae7b4266f1e8a3e.png)

接着在I列写个公式，用F列的互动数除以E列的笔记数。 ![](img/a28883d8578bcc31360e13c8870584e5.png) 这个比值可以看作“机会指数”：笔记多代表做的人多，互动多代表用户兴趣浓；两者相除，数值越高，说明需求大、竞争相对小；数值越低，说明赛道已经非常拥挤。按I列降序排列。 ![](img/eb98be1f691b56b392e9db12a633e1fb.png) 你会看到婴儿油、课桌椅、悠悠球等品类，过去30天互动表现不错但笔记量不算多，这样的方向值得留意。

常见问题

导出时进度条卡在10.001%？我在两台电脑上都遇到过，换台电脑就正常了，推测是电脑上安装的某些基础软件不兼容。碰到这种情况，不妨先换个设备试试。
