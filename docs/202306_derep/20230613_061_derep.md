# 闲鱼无货源玩法另辟溪路之高客单冷门产品玩法

最近在龙哥盟刷到一篇闲鱼无货源攻略，看完只想说：这才是真正实在的干货帖。

作者百万先生，早年做过带货主播，单场三小时能冲到30万GMV，在线峰值破万人。后来因为身体原因，转型全职做闲鱼无货源电商。他19年就开始接触闲鱼，起初只是副业，一个月能赚四千左右；这两年索性All in进去，自己开多店铺，还带着身边人一起做，现在靠闲鱼每月稳定收入2-3w。

这篇教程不走寻常路，专门讲“高客单冷门产品”的玩法。他没有去贬低其他路子，只分享自己真实跑通的经历。有多详细呢？作者自己说肝了好几天，反复改稿，就为了给小白一套从0到1的完整路径。全文上万字，预计要读15分钟，但全程无注水。

有意思的是，评论区里有人说：“终于看到一个不再说自己月入十万二十万的实在人了。”作者也坦诚回应，看到那些高收益帖子自己也会焦虑，但他更愿意把实实在在干出来的经验分享出来，哪怕比不上圈内大佬，至少能帮到很多刚起步的人。
