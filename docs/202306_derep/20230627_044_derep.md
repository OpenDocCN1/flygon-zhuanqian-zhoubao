# 新手三步法，快速跑通小红书小说推文

> 参考源：[`www.yuque.com/for_lazy/thfiu8/vq0rqp8o89ckwugf`](https://www.yuque.com/for_lazy/thfiu8/vq0rqp8o89ckwugf)

大家好，我是周梦行。从去年年初开始我就一直在做小说推文，今天这篇就想把我踩过的坑整理成一份从零到一的实操快进包，帮刚入局的朋友尽快把项目闭环跑通。

做这一行最容易翻车的就是陷进自我欣赏里。推文本质是服务读者，不是做个人创作展。别追求花里胡哨的完美，先把有用的内容稳定地送到用户手里。这篇我只讲最核心的三件事：先找准对标账号，再学会复刻对标内容，最后搞定持续更新与账号运营。

另外，围绕小说推文的受众特性，我也回应了新手群里被问最多的两个实操疑问：作品最佳发布时间是什么时候？发布后要不要主动刷互动？具体判断逻辑和注意事项，这里有详细拆解：[https://i.shengcaiyoushu.com/docx/GH9Ndw1DCovqDzxF4GHcTeOTnbb](https://i.shengcaiyoushu.com/docx/GH9Ndw1DCovqDzxF4GHcTeOTnbb)

**读者互动补充**

龙哥 : 小红书上小说推文的账号挺多的，和抖音做这个赛道相比，有什么不同？

周梦行 : 优势方面，小红书用户偏年轻女性，晋江、LOFTER 这类女频内容更容易吃香；图文形式上手快，创作成本低；账号打法灵活，讲究短平快出内容。劣势方面，相比抖音，小红书的变现和引流路径更单一；男性向或非女频题材在平台上发挥受限；另外，把流量导到站外平台的风险相对更高。

CD : 小红书一旦爆了是不是就容易被限流？

胖大魔 : 人群画像很关键，小红书在耽美、百合、女频这些细分领域推起来很顺，抖音则是泛粉更多，老书虫大多已经有固定的阅读或听书 App 了。
