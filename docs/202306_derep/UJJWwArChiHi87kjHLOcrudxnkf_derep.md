# 自我介绍

各位朋友好，我是阿鸡。2023年4月18号我加入了生财，当时交完2000块的学费，距离发工资还有半个月，生活费省到极致还差300多块。5月5号我递交了辞呈，拿着5000块的离职结算是彻底all in创业。5月10号在视频号发了第一条内容，5月24号迎来第一笔成交，5月31号结算时，7天累计利润46000元。下面就是这次经历的复盘。

![](img/66f4a0876fd7c144e7b25d884f71e46f.png)

运气占了很大比例，但破圈的这段时间我也沉淀了一些可复用的东西。下面只讲我走过的路、用的打法和踩过的坑，不聊选品。选品的讨论生财里已经很多了，我就不重复造轮子了。

# 怎么开的局

我之前对视频号完全陌生，纯靠在抖音攒的剪辑经验去瞎试，没想到直接撞上了。过程其实很随意。

起步的灵感来得很突然。大概是进群没多久，刷风向标的时候瞥到一个赛道。那段时间我几乎泡在风向标和精华帖里，吃信息长肉。【风向标和中标真的要吃透，都是被验证过的捷径】

我怎么判断这个赛道能做？看到一个同行，账号的第一条到当时的几条，单月做了1200多单，粗略估算净赚两万多。私信他那天开始我就盯着他看了几天，又扒了好几个对标号，动辄几百单。算下来一个月七八万的体量，眼前一亮。

![](img/5cf06f760e055672d0251674a737ac36.png)

当时我手里就是个纯小白，连模仿都怕露馅，不找人带基本不动。10号那天咬牙上了，第一版视频做得极其粗糙，查了几篇生财的文章就开剪，拍完直接发，啥心思也没放。

前期根本没想着赚钱，就是当玩具玩。一天发一两条，播放两三百就歇两三天。突然有一条破了一万播放，涨了几十个粉，我兴奋得一天连发三四条。那会主业还在做小红书运营，对视频号基本是佛系。

后面断断续续更新，有天打开后台，提示账号异常飙升，明显爆了。粉丝冲到1000，橱窗开通，商品也上好了。开始到处求助，有人说去评论区引导下单，有人说赶紧开播。我全试了，当天就出了几单，赚了两百块。

![](img/a3155d0fc272e051f41441ff7ef1b020.png)

从那以后就停不下来了。流量像开了闸一样进来，下单量跟着一起涨。第二天800，第三天5800，最高一天破万。

![](img/d3bb11a85cb2178a9d20b687ce04abb4.png)

# 踩坑与对策

系统误判是常态。之前被判过字体过大、图文轮播违规之类的，我都是直接申诉。申述话术就三点：1.说明我有加入个人创意 2.把剪映的工程截图上传 3.承诺会整改。大部分都能过。

![](img/2fb2b6a7dd585f44f63b363e7f50a7b4.png)

6月1号账号被同行投诉，带货权限被封，数据直接断崖，当月后面就只出了一单。后来我用“怼脸实拍情感语录”的方式解封，权限又回来了。

![](img/0221c859e4ddcffd05b8c39a4bd6fe06.png)

这里吃过亏：解封后一个小时内我就发了条带货视频，结果一个小时不到又被下车。所以教训是，账号刚用怼脸实拍恢复带车权限，不要当天立刻发带货内容，隔个一两天再上车比较好，权重养一下。

还有就是爆款没及时变现。第一次爆的时候没马上开直播，东东教练说我浪费了大量流量，回头想想挺可惜的。

想做投放也很麻烦。挂车的视频一旦播放到十万二十万，马上被同行举报隐藏，投放根本放不大。所以放大只能靠矩阵。现阶段我也在探索不挂车、靠评论区+直播成交的变现方式。

新号养号节奏我现在是这么来的：先养几天再提速。

如果账号被限制挂车，可以连发11条怼脸录制的情感语录视频，一小时发一条。

# 我的体感

找到一个能打的品类，就要all in，别犹豫，窗口期很短。

视频刚有起色就开直播。会不会直播无所谓，先挂上车，把话说满就行。违规别碰，没单也算给账号加权重，别给自己太大压力。

多在群里说话，多问高手。别怕问小白问题，问了才有答案。认清自己是小白，学到的东西就是自己的。

另外一条很个人化的建议：跟对大哥、选对团队，多花钱买课，多破圈！

# 方法论精简版

评论区是核心，重要到不能再重要。带货视频可以自己用小号在下面做购买暗示，引导视频找几个号唱反调制造争议。负面评论不是坏事，是热度。

做混剪类非原创内容，创作成本低。剪映一套模板一个号发三条以上，别抠一两个视频抠到死。

一定要批量做号。靠一两个视频致富是运气，天时地利人和运气好才成。用数量击穿概率。

# 选修课：付费投放经验汇总

这部分是我咨询多位大佬后整理的，仅供参考。

## 基础条件

毛利最好大于70%，最好能到80%以上再考虑付费。

## 投放心法

视频号投流前期要抬高出价，把流量热度打出来，再逐步降价到目标ROI。流程是：测素材/测品->测出价->放量。

核心是保证流量不断。每个时段至少有一个计划在跑。测品一般早上开始，智能定向加热时长一般设8小时，6小时和8小时消耗差别不大。晚上12点可建12小时计划兜底，避免断流，除非你凌晨4点能起床补计划。

低客单难赚钱，高客单不好起量但不易亏损。新手建议从99元客单起步。

投放赚的是快钱，付费曝光的价值和自然流不一样。

定向问题：放量期再考虑定向，前期基本全推通投。即使人群定位在30-50岁，通投里90%以上也是这个年龄段。

付费视频必须强营销。

商品点击率及格线是2%。

自然流跑完再考虑付费，付费后视频基本不会再获得自然推荐，只剩点赞好友流量。付费很难反哺自然流。

结算周期：发货后10天自动确认收货，7天后收益打款。1号下单，2号发货，12号确认，19号到账。

卡赔付，单量尽量控制在6单以上。

计划何时停：

1. 单品利润60元，计划出价70元，预算200元。消耗50元出1单后继续消耗，到120元未出单，应直接终止。按出单后重新算成本。
2. 东东的经验：消耗70元不出单就停；空耗70元但出单且ROI小于1也停。

![](img/a4be8a3f3c57f894d1892c256293a833.png)

## 测品测素材

上3条素材同时测试，每条配3条计划。假设99元客单，智能加热出价900-1000豆。

三个计划要同时跑，视频审核通过后立刻建。

预算最低要出价X2取整，例如出价700豆，预算至少2000豆。

出价起点是客单价1.2倍或利润1.2倍，跑得动再压价。

停止标准：

叶迪峰：消耗到盈亏线即停。

小纸壳：

利润>100，消耗到利润的1/4-5元

利润<100，消耗到利润的1/3-5元

我的做法：空跑消耗到利润的1/2或1/2-5元。

## 测出价

第一批出价900，下一批可配3条850、3条800、3条750、3条700同时跑。找到能稳定消耗的出价后复制拓展，例如750基础上配700、650。若连续三次降价ROI仍亏损或不提升，果断换素材换品。
