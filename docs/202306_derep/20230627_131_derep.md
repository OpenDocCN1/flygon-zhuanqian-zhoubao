# 不亲手按快门也能做电商摄影：整合拍摄资源，月入十万的路径拆解



## 做电商摄影不一定自己拍，抓准商家痛点做资源整合也能做到月度十万+稳定回款

作者： 山木 

日期：2023-06-13 

从零散接单到成为商家长期合作方，我是这样摸清需求并把单子谈下来的。

如今我已把相机交给他人，每月到账仍在十万以上。

十年电商经验加上五年拍摄经历，经历过行业多轮波动，现在聚焦摄影培训，单月产出超十万。业务大致走过三段演进：先卖货，再卖方法，最后卖体系化服务，如图所示：

![](img/e25caf51cf7da36cebb575c1f6724fae.png)  

起初我只是个普通卖货人，靠服务费和佣金吃饭。随着电商对图的需求抬升，微商崛起，我顺势切入产品拍摄业务。

得益于早期的卖货认知，能准确把握商家侧的诉求——控制开支。我从用人、业务衔接、合作模式、场地四个角度帮商家降本，同时把业务版图扩到培训与需求匹配，把主动权握在自己手里，和商家形成利益共同体。

每次业务切换都紧跟行业风向与真实需求。若你也在电商或拍摄赛道，或正卡在项目瓶颈，我的演进或许能给你一点参考。

我的打法始终围绕两件事展开：一是电商，多年来我几乎跑遍线上售卖渠道，深知不同品类适配不同平台，也清楚电商对视觉素材的依赖；二是拍摄，当时行业乱报价、需求旺盛，这正是机会窗口。

以女装为例：一次外拍花费约五万，一季上新约百款。摄影师日费六千到一万二，化妆师两千到三千，助理五百，模特每小时一千二，八小时九千六，场地每小时两到四百，百件货需两天。相比之下，AI生成的模特图短期内难以完全替代。

回溯电商发展：2010年淘宝、2012年天猫、2015年微博、2018年微商平台、2020年直播带货。2020年前，图片是线上售卖的刚需。直播兴起后，内容形态变为图+视，预计视频需求将逐步反超图片。

2018年启动拍摄业务，契机来自微商平台爆发叠加过往沉淀。原因有二：
其一，外部摄影师产能跟不上内部节奏。云集、环球捕手、贝店增速很快，各平台调性差异明显，对视觉标准要求不同。彼时微博网红当道，摄影师报价高，优质摄影基地也增多。
其二，当时合作的商家朋友纷纷入局微商，拍摄需求集中，但多为外包。季度拍一次，自建团队不经济，相机器材投入也大。

于是我们先满足自身拍摄，再服务商家朋友。我们的综合成本低于同行，口碑带来转介绍。后来把成片投放到小红书、抖音、闲鱼，也吸引到新客咨询。

当下商家对拍摄的诉求越来越细分，专攻单一方向的团队反而能把整体成本压到最低。

除了主流平台，京东、拼多多、快手、视频号、唯品会、蘑菇街、单创、鲸灵、快团团、群接龙等渠道林立。渠道越多，流量越分散。大牌做八成份额的主渠道尚可接受，约三四个平台各设团队，但全覆盖不现实，更别提中小品牌、工厂、供应链了。不同平台对同一品类图的不同要求，正是合作的入口。

以服装举例：唯品会需要3D白底，淘宝偏好模特图，抖音商品页用白底为主，小红书需要穿搭场景。平台定位也不同，天猫主打新品高利润款，唯品会做当季清仓，其它渠道负责尾货消化。

我方现在做轻奢女装批发，用“轻奢女装”搜索可明显看出各平台视觉差异。刷够量后，看到一张图就能判断投放位置，这和网感相通。

在拍摄业务建立信任后，我们与商家做更深绑定。大品牌自建部门覆盖核心渠道，剩余精力不足的渠道就是我们的切入点。通常采用分成模式：对方供货一件代发，我们拿佣金。现今达人直播带货同理。

对中小团队、供应链、线下工厂而言，线上运营并非强项，生产才是核心。从这里开始，角色已发生变化：从被挑选的服务方，升级为与商家平等的渠道合伙人，在其原有业务不变的前提下创造增量。

回到拍摄变现的核心：站在商家立场降本求长期。服装拍摄成本高，一年至少四季，迭代快的品牌频次更高。AI可做模特图，但需白底源文件。从时间成本看，AI未必划算。如一天可拍百件，每件产出十五张精修，实际拍摄五张选十五，单日产出约一千五百张，还未计入模特IP、动作设计、效率损耗等，AI短期难以取代。

我们从四方面帮商家压成本：

一、人力侧
摄影师薪资通常一万到一万五不等，但岗位流动性大。自由摄影师日价四千到八千，有稳定客户三天工作量抵得上全职一个月。因此提供线下摄影培训，零基础十五天速成，结业后可覆盖日常拍摄。商家可从毕业生、美院、传媒院校招人，以月薪八千计，培训费六千九百九十九。首期投入一万四千九百九十九，后续每月八千。若员工留存满三个月，总成本已低于直接招聘。难度较大的拍摄我们提供指导，从效率角度继续降本。行业培训普遍存在，小红书可见不少，杭州报价约一万二，周期半月到一月；北京一万七至五万不等，周期一个月到一个半月。

二、业务承接
摄影师离职空窗期由我们承接拍摄，保证线上节奏不中断，商家可从容招聘与培养新人。

三、摄影师资源推荐
我们培训的学员和优质摄影师会形成合作网络。自身轻奢女装批发每月上新二百到五百款，拍摄需求大，优质人选会推荐给合作商家。有人疑问为何不全部自拍，原因有二：其一，摄影分工极细，人像、静物、3D白底、白底、模特、化妆、搭配、助理、制片、布景、修图、剪辑等，组建全能团队成本极高，专业细分才能把成本压到极致。其二，效率瓶颈，一天五十件可一队完成，五百件则需十队，合作比自建更高效。

四、场地
杭州自有两处棚，百平与两百平。自有场地直接免除商家场地支出。市场价约一千元/八小时，优质棚一千二至一千五。

若新人想入局拍摄，门槛不低，设备与技术双重消耗。相机镜头起步数万，加上灯光场地，对新手负担大。建议：
1. 先摸清本地产业带，比如皮草、围巾、零食等。以产品为锚点，找到商家未覆盖的渠道，研究该品类在该渠道的体量，体量达标后再研究视觉调性，再用拍摄+带货服务绑定。圈内也有可直接合作的流量方，发挥各自优势。
2. 选定一个拍摄细分方向深耕。只有做精一个赛道，才能把成本压到盈亏线以下。如3D白底图，我朋友已做到四十元/件，行业普遍八十到一百一十，因其只做白底，不碰其它。单点突破才能压缩设备与学习成本。
3. 视频需求将超图片，可提前布局拍摄与剪辑，避免在图赛道内卷。
4. 降低起步预期，不必想全包。要算单位时间成本，合作是效率最优解。有稳定合作方，现金流会更稳。

以上是我走通的路径，供参考。
