# 不靠中介，她亲手把娃送进全球Top10：留学申请全复盘

我叫绍芸。来生财已有九个多月，每天读圈友的分享，收获很大。这次想还一点干货：不找中介，独立帮孩子申请世界顶尖高校的硕士项目，顺便聊聊途中掉过的坑。

先交代结果：孩子拿到了英国一所全球Top10高校的硕士录取资格。

绍芸：你问到我擅长的了。我家孩子读本科时也是工科，研究生读的经济方向。当初有金融科技这个选项，但最后他本人定了经济方向。美国那边工科背景跨金融相当吃香，英国更看重金融科班出身，转经济会稍微吃力。工科背景的同学可以考虑金融科技、金融工程这类对数理基础有要求的项目，这类项目通常会在招生页面写明要求。

绍芸：还有，如果孩子计划出国读研，此刻就要抓紧——语言成绩和实习经历都很关键，实习尤其要有清晰的方向。大三的秋天提交申请，本科最后一年读完正好出国；等到了大四才开始张罗，时间就紧了。
