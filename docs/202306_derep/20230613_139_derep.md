# ('从月佣 602 到 5w+,我是如何从众人口中的内卷赛道低谷爬上来的', (2, 36))

“这行已经卷到天花板了，别往里挤了。”这类劝退的话，你是不是也听腻了？偏偏有位01年的姑娘，在大家都不看好的领域里，硬是把月佣金从三月份的602元，做到了五月份的5.1万，完成了一次漂亮的上坡路。

她叫猫嘉，目前人在广西，去年本科毕业后就全职做网络项目。五月份，她的抖音养生号创下个人新高——佣金冲到5.1万，直接刷新了她之前2.7万的月纪录。这个号没有真人露脸，内容全靠实拍素材加混剪，也不砸钱投流，就是踏踏实实吃自然推荐。

这个赛道里，唱衰的声音一直不少，很多人觉得已经没法玩了。但猫嘉不这么认为，她把自己从低谷爬上来的完整思路梳理出来，并且把每一步操作都拆成了可以照着走的流程，想帮同样困在这里的人打开突破口。由于内容篇幅较长，她把完整的复盘放到了飞书文档，需要的话可以直接移步查看：https://s31nx3n9vr.feishu.cn/docx/WPV8dkx5NoSXArxQd9YcfBAvnQc

她的评论区也热闹得很。有人说“优秀”，有人说“值得反复咀嚼”，还有人直呼“猫姐太牛了”。猫嘉自己倒是很谦逊，把成绩一部分归功于路上遇到的贵人，说“非常感谢一路上有他们的帮助”。这种互相托举的氛围，大概就是生财圈子的魅力。
