# 为什么现在是图文带货的黄金窗口

身边做短视频带货的老玩家应该都感受到了，抖音对图文带货有明显的流量扶持，而且图文目前是不支持付费投放的，所有人都在同一起跑线，这对新号、新人极其友好。五月份开始我身边的同行已经有人靠图文做到月入几万、上十万的规模。

![](img/2ffac6346dbc8a4e31bf282cdfe5978f.png)

# 图文带货的优势在哪

### 投入的时间成本极低

比起过去的视频混剪和真人口播，图文的制作门槛低了不止一个档次。一条带货笔记，3-5张图就能发出去，不用再花几个小时去剪辑、配音、调试。

### 制作难度非常友好

视频混剪对剪辑功底有要求，而图文基本人人都能上手。尤其是熟悉小红书做法的女性用户，会觉得这种形式非常顺手。

### 全场景都能做

图文全部是手机端操作，一部手机就能完成从图片处理到发布的闭环。通勤、地铁、午休摸鱼的碎片时间都能干。

当然，没有完美的玩法。我之前就说过，任何项目都有两面，只讲好处不讲风险的都是耍流氓。

# 图文带货的短板

### 不能投放加热

对于习惯花钱买流量的商家来说，这就是限制。不能靠烧钱堆量，只能拼内容和选品。

### 对封面审美有要求

懂小红书的人都知道，图文的生死线在首图。就像短视频的前三秒，封面不够抓眼，基本就被划走了。所以审美和排版能力很重要，不过在中老年书单、生活用品这类赛道，内容清晰比花哨更重要，核心信息突出就行。

# 如何选品和找到对标

PS：后面的图片制作方法都是建立在找到同行参考之后做的。选品和找对标的具体逻辑，我在之前的文章里写得很细，今天只补充关键的优化点。

之前我讲过用考古加找对标账号和商品的方法，但有朋友反馈考古加的成交数据不够准。确实，第三方工具的数据会有偏差，打仗时情报不准是大问题。

所以我对这个环节做了升级。

### 一、用考古加爆品探测功能做初步筛选

在电脑端考古加的顶部工具栏，有个爆品探测入口。

![](img/0f1031136ddb444fb0e8e764c9555b9a.png)

我们先把筛选条件设好，时间尽量选近期，然后选择自己要做的赛道。比如我是做图书的，就选图书，时间就选今天。

![](img/df07af194b59d2cbc6bfb840e72ac8cb.png)

如果这个品符合赛道，也正是我想做的。

![](img/dd2d24b638a2e2944a589f93f183f104.png)

点进商品页，点开作者头像，复制他的抖音ID。

![](img/06d45b924bfe80ffb179f6f33b340d2c.png)

接着需要一个抖音小店商家号入驻。抖音小店现在零押金就能入驻，有营业执照就行，个体户或企业都可以。实在没有执照的，可以去某宝代办几十块搞定。登录小店后进入【找合作】。

![](img/38a463187b4ecb76b59f5e1850942403.png)

把刚才复制的达人抖音ID粘进去，就能搜到这个达人，进入主页查看他的视频数据。

![](img/5fd51d2272797afff240fd5318cc4f74.png)

![](img/950a32bc195c54500ef9ff4f66bf99d4.png)

![](img/d06cc94d0294e1022a158eeb691c23fe.png)

这样就能看到这条视频在官方后台的真实GMV和播放量。我自己用自己的号测试过，数据基本是准的。把考古加和官方后台结合，才能筛出真正精准的爆款。

![](img/64b23d1a8eb2451662f54e9cb26e9452.png)

### 二、用创意中心找素材灵感

在达人端的巨量百应里，进入创意中心，选择爆款视频榜单，设定好赛道和时间区间，也能看到正在爆的作品。缺点是该榜单只收录视频，不包含图文，所以参考价值不如考古加全面。

![](img/aabc9642a95f578d40e8ea8066de43b0.png)

搞清楚一手情报后，就进入制作环节。接下来讲图片如何去重过审。

# 图片去重与过审实操

### 混图法

混图就相当于图文版的混剪，直接借鉴别人的素材。平台图文量大后，同质化限流很常见。针对这种情况，有两种处理思路。

##### 单图去重法

以我的一个对标图为例。

![](img/8f828cc2c81f629f122dc58ee83c0d70.png)

我会先去小红书找一张风格相近的图片，导入美图秀秀。

![](img/1297ee25be9c5df2e729c144240051fb.png)

再找一张比如咬开的梨子这类小元素图，在美图秀秀里抠出来，合成到背景底图上，这样就生成了一张有原创度的图。

![](img/1cbd5e685ee0e8ab28827e3901531c68.png)

![](img/d1b7865890585c79a306cbabd15d2df5.png)

![](img/e89c3bf055ee0a34981520b9b9d76c9a.png)

合成完后，按原图的感觉加上文字、贴纸、滤镜。贴纸随意加，文字往角落排一下即可，这样单张去重就完成了。

![](img/22fb4e1c9002073f75d6b6d17a0fa743.png)

![](img/f249f199eb6daadc25f915d214252563.png)

![](img/8074090aa2d814b3cd71e83fe136a072.png)

##### 拼图去重法

打开美图秀秀的拼图功能，我一般用4宫格。这种形式常用在零食、中老年汤包这类品类。导入四张图后点高级编辑，打开无缝模式，调节融合度，拉大缩小图片并调整位置，找到最舒服的排版。

![](img/764aeb7ecbf00570beeea124a6680ac6.png)

![](img/b2e6557cd74ce042b876806b7e469b1b.png)

![](img/f9592f2e74351e159f8b32d75d7455ef.png)

排版确定后，再加滤镜、贴纸和文字，一张拼图就完成了。

![](img/8889e63bf1fddd033d551e5bafe91587.png)

![](img/430cf972739a2bbd84c497549f582cef.png)

拼图相比单图，同质化风险更低。

##### 最后做画质增强

前面两种方法做好后，我会用“wink”软件把图片锐化提升清晰度。

![](img/9e9f9b97a37dd962d53f443da82d9113.png)

### 实拍法

这种需要一个俯拍灯，最好是iPhone 12以上的机型。收到商家样品后，直接照着对标爆款来拍。为避免撞图，可以在画面里加一些道具、花艺或者把自己的手放进去，再加上贴纸做差异化。实拍原创度最高，操作也最省心，唯一的缺点是等样品快递会错过爆品的黄金期，所以建议混剪和实拍结合用。

![](img/1f174de2744940b405a1d8fcbeba0096.png)

### 音乐选择

BGM一般直接收藏对标作品的音频，发布时选用收藏的音乐即可。
