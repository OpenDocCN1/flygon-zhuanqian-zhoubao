# ('如何从韭菜，长成年入 100W 的赚钱铁杆粉丝', (2, 25))

很多人刚进赚钱有术时，都以为花两千块买张门票，就能让龙哥手把手带自己年入百万——醒醒，这个社群早就不是那个小圈子了。它已经站到创业类社群的金字塔尖，那种带着几百上千人做项目实操的事，是小型社群才干得动的活。

作为一个交了三年会员费、被赚钱“割”过也“养”过的人，我不聊二手书，只想讲讲自己怎么从一颗绿油油的韭菜，长成连镰刀都砍不动的铁杆粉。

今天聊四个问题：龙哥的格局到底多大？如何在信息洪流里捞到干货和大神？项目怎么选才不踩坑？赚钱的本质到底是什么？

先说龙哥。别指望他像私人教练一样给你选项目、答疑难、保你回本。赚钱真正的价值，是三件事：比别的地方早一年嗅到风口；聚拢一堆真正拿到结果的人分享一线经验；靠航海计划一次性带几万人完成从0到1。

有句话我特别认同：航海手册才是真正的商业百科全书。学校老师讲的很多是纸上谈兵。我作为教练参与过二手书航海手册的编撰，拍胸脯说，它比市面上九成付费课都扎实。新来的朋友，直接看下面几张截图，别听我吹，自己感受。

再说怎么找内容。我也是懵了一年才玩明白。现在我的方法很野：

第一，凡是标着“保姆级教程”的帖子，只要这项目有航海手册，我基本刷到就划走，最多停留半分钟。你想想，航海手册是N个教练反复打磨、还有官方审核的东西，什么闲鱼保姆教程、抖音带货月GMV百万攻略，写来写去就是注册、选品、提曝光那些花活，哪比得过手册？小红书电商、抖音带货最近类似的爆款文特别多，先去看对应航海手册，剩下的再用下面的筛法。

第二，遇到真想看的文章，我点进作者主页盯三样东西：有没有精华帖——只有真心利他的人才能拿到；同一篇稿子在多少个星球群发过——两三个正常，全网同步那是营销号；看他发文的选题序列——今天“小红书年入百万实操”，明天“一个店月入10万”，翻来覆去秀肌肉的，懂的都懂。

真分享的人，看到别人写过的角度就不再重复。比如我在抖音国外育儿号项目上四个月赚了20万，本来想写复盘，结果发现已有同类好文，就果断放弃。赚钱不缺重复内容，缺的是自己的思考。

第三，我从不对“月入10万”“年入百万”的截图上头。你要让我P个日入过亿的图，我也能做视频版。我更在意这人写了什么、航海手册里有没有、群友怎么讨论、大家的差异在哪。如果全是手册里烂大街的流程，没观点没心得，那些截图就是废图。

再说选项目，今天还看见有人被抖音直播切片割了。我的原则很简单：第一，围绕自己的基本盘做衍生。我的基本盘是二手书，就顺着它去搞激活码这些周边，现在二手书月利润稳定在10W+。第二，新项目跟着航海走。龙哥估计每月都在琢磨该上什么项目，你放着年营收上亿的公司帮你筛好的项目不做，非去找个市场早就玩烂的，谁拦得住？

最后说赚钱的本质。这观点我憋很久了。我农村出身，小学五年级住校，每周回家走30公里山路，靠着考上211进了世界500强，干了8年，加薪升职，效益好的年份也到过年入百万，才在城市落脚。所以我很信二八定律。考上211，不是因为你上了学，而是你超过了80%的同龄人；年薪百万，不是因为你上班了，而是你干翻了80%的同行；赚钱同理，不是因为你做了某个项目，而是你的能力和付出超过了80%做同项目的人。

赚钱能是市面TOP10的社群，所以龙哥能赚钱。这次二手书航海，你要是把目标定在打卡12次，基本就废了——那是及格线。真想做出成绩，你的投入必须超过同船80%的人。

我是老瞿Qu，赚钱编号35610，加入604天，付费3次，只要赚钱还在就续费到老。当前精华帖4篇，2023年本着利他原则，目标冲10篇。

顺便求助：以前点头像能看到“加入多少天、发帖数、获赞数”这些信息，我靠它判断人靠不靠谱，现在知识星球App好像取消了？龙哥大大，能不能去沟通一下哈哈。

以上就是我从韭菜长成铁杆的真实经历，希望能给你点参考。有问题欢迎交流。另外，我之前劝退了50多个想加盟拉新工作室的朋友，那个让我亏了20万的项目，如果感兴趣，下一篇写写失败过程。

2023，一起赚钱有术。
