# ('ChatGPT 调教心流法的新大杀器——三体联动', (2, 26))

“万字直播稿，三分钟变成IP口播文案？” 你没听错，这就是我最新调教出的“三体联动”玩法。

先说说自己：我玩GPT挺久了，越用越明白它有俩天生的软肋：一是长文它就犯晕，动不动输出偏差、不听话；二是内容太“大众脸”，谈不上有温度、有观点。这俩毛病，在很多创作场景里简直是翻车重灾区。你换别的工具试？行是行，可底子还是3.5模型，逻辑硬伤根本没治好，所以把长文案拆开再整合，一直是老大难。

这两个月，我蹲在对话框里反复调教：语料一筐一筐地喂，思路一遍一遍地捋，提示词一个字一个字地抠，踩了无数坑，终于让我撞出了一个王炸——三体联动。用它，真的把“万字直播稿转成带个人IP风格的口播文案”给啃下来了。
