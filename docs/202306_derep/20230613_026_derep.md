# ('保姆级 Lora 炼丹教程，一站式整合包，让你实现真人模特定制', (2, 33))

不少朋友学会 Stable Diffusion 之后，大多还停留在“尝鲜”的阶段。我觉得，真正让 SD“为我所用”才是更有意思的事。

琢磨了很久，我终于从 SD 的实用功能里挑出了两个最核心的：Lora 和 ControlNet。简单来说，Lora 可以把你在生活里遇到的人、物件炼成专属模型；ControlNet 的作用则是帮你更精准地“操控”这个模型。两者一配合，SD 就能从玩具变成工具——想拥有属于自己的真人模特，或者把某款商业产品模型化，都完全可以实现。

我本人已经把这套流程从头到尾走了一遍，每一步都亲自验证过，才整理出这份教程，分享给大家。

今天这篇主要聚焦 Lora 的炼丹教学，后续还会推出 ControlNet 的讲解，不过那块难度会更高一些，可能要让大家多等一段时间，也请多多包涵。

教程包含了 Lora 的功能简介、具体炼丹方法，还有实操案例。你只要照着步骤一步步来，基本都能学会。
