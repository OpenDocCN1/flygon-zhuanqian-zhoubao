# 龙哥：易仁永澄老师航海起航仪式分享视频版

最近龙哥盟社群里，一段视频被不少圈友反复提及——就是易仁永澄老师在五月航海起航仪式上的那场分享，主题叫《如何破除障碍，点燃你的赚钱行动力》。

这场分享是在周一晚上进行的，当时不少圈友因为各种原因错过了直播。龙哥特意把视频版发了出来，方便还没看过的伙伴补课，尤其是正在航海途中遇到卡点的船员，很值得抽时间再听一遍。

视频发出来后，评论区一片好评。有人说这段内容“值得全文背诵”，也有人被老师的表达力深深感染。还有圈友坦言自己当时没赶上直播，看到帖子后马上点开了视频。更有人表示已经二刷了一遍，依然觉得收获满满。也有细心的朋友建议配上字幕，让学习体验更好一些——不过视频里老师的感染力，即便没有字幕也足够打动人了。

如果你也在行动的路上感到阻力，不妨点开这段分享，听听永澄老师怎么说。说不定某个卡了你很久的问题，答案就在这里。
