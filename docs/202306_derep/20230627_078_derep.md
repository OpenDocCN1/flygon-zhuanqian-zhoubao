# ('从加入赚钱有术到跟船航海，原来一直想找的社群就是赚钱有术', (2, 30))

直到今年三月，我才正式踏进赚钱有术的大门。回想起来，早在 2017 年就听过这个名字，但当时没当回事，还在满世界寻找一个“理想中的圈子”。结果这三个月，翻着航海手册、刷着大佬的精华帖，一口气跟完了三条航线，心里忽然冒出个念头——原来我兜兜转转要找的，就在这儿。

我翻出一封 2017 年写给未来自己的信，里面清清楚楚描绘了我梦想中的社群模样。对照现在，这不就是赚钱有术的真实写照吗？下面这封信，红色标注的“当初的梦想”，很多都在这里找到了答案。

未来的小伙伴：

在网络世界里，离你不远处有一群人。他们真正活成了你羡慕的样子：自己安排生活节奏，想工作多久自己说了算，想旅行了，背起包就带上家人出发。

这些是不是你曾经的向往？

我也在网络上尝遍了酸甜苦辣。还记得你为了理想生活，拼了命逼自己的样子吗？还记得分享经验后，陌生网友的真诚感谢？还记得半夜刷到一篇“秘籍”，兴奋到失眠？还记得靠推广赚到第一笔钱——哪怕只有几块钱，也激动半天？还记得被传说中的大佬回复时，心跳加速？还记得深夜里赌誓，一定要闯出点名堂？还记得那些嘲讽和白眼带来的无助？还记得最亲的人看你时，那期待的眼神和你许下的承诺？

网络这条路，从来都不平坦。所以你多想有这么一群伙伴：

缺引流方法时，有人甩你一个链接：“最新玩法都在里面。”
到处找项目时，有人告诉你：“别挑了，这里的项目随便选。”
听说一个牛逼的吸粉案例却没人请教时，有人直接拆解：步骤就是 12345。
想写出产品差异化卖点，有人提醒你：“从这几个角度试试。”
想解放双手、用软件批量操作，有人指路：“去这里下载。”

这不就是很多互联网从业者心里的乌托邦吗？如果你还在寻找这样一个大家庭，我想说：

赚钱有术的门，已经为你打开。

你看到这四个字，大概会想：赚钱有术是什么？听起来像网络流行的社群。但我想认真告诉你：它绝不只是社群。我没办法用几句话把它说透，因为每个人心里都有自己的定义。如果非要说一句话，那就是——赚钱有术是一个生态圈，一个属于互联网勇者的生态圈。

它虽然存在于网络，却无比真实。一切从真实出发，能给正在做项目、或准备入行的你带来想象不到的惊喜。也许你现在还不心动，因为你真正想问的是：在这个生态圈里，我能得到什么？

答案是：游戏式 100% 实战学习。

它像一场江湖闯关，把网游式的任务和真实赚钱结合起来，让你在“练级”中成长。整套体系分为四个模块：新手区、赚钱大航海、英雄争霸赛（在赚钱叫“龙珠榜”）、名人堂。

新手区，是每个人进来后的第一站。这里每期都有升级任务，完成才能真正畅游。规则很简单：

赚钱提供赚钱项目，手把手教你推广和成交——这不就是航海手册嘛；
赚到的钱 100% 归你，很多大佬就是从这里一步步提高了认知，赚到了以前不敢想的收入；
你只需要写下不少于 500 字的操作心得，这份心得会变成你的《个人成长档案》。参加过航海的伙伴，对打卡日志还有印象吧？
赚到钱后，才能兑换门票，正式进入第二模块。当然，赚钱还有更高阶的玩法，比如航海家俱乐部。

组队副本区，里面全是学习资源：大佬的直播视频、国内外最新的赚钱项目、各平台运营技巧、黑科技工具。你可以自由组队，边学边实战，还可能找到最适合你的伙伴。规则也很清晰：

每个队长有 3 个名额组建小队；
赚钱提供分类好的资源给所有队伍；
选好资源去实战，事先列出预期目标；
遇到问题就发到议事堂——也就是现在的各航海群；
议事堂有原则：必须写出小队讨论过的解决方案，再问最困惑的问题；
达成目标即通关，更新成长档案，然后获得英雄争霸赛的门票。

英雄争霸赛，是圆梦的地方。男生都有过英雄梦，女生都有过女王梦。在这里，你可以直接跟高手过招，赢了就有资格进入名人堂——赚钱的“龙珠榜”一直在等着你。规则是这样的：有个人赛也有团队赛；任务千变万化，包括淘宝、微商、文案、建站、SEO、各种渠道引流、海报设计、甚至写电子书；规定时间内最先完成的人或团队胜出，成为当期霸主；每半年一次，任何人都能来挑战；连续两期称霸，所有资源优先使用，还有现金奖励；最后更新成长档案，兑换名人堂资格。

名人堂，是网络大佬的摇篮。在这里你能得到：个人 IP 打造，赚钱会用全网媒体渠道帮你宣传；录制教学视频，赚钱帮你包装推广，利润五五分成，另一半进入英雄争霸赛奖励基金；上台做公开课分享，光是红包就可能日入过千；参加线下互联网峰会，每一期都有传说级神秘大咖；还能对接国内知名公司，扩大你的影响力。

如果你觉得这些就够刺激了，那下面这些更会让你尖叫：

你可以成为城市合伙人——以后你所在城市想进入生态圈的人，都需要你的推荐信；
你会获得现实世界里的人脉资源，这里每个人都真实存在，也许生命中的贵人就在其中。

所以，我再强调一次：赚钱有术绝不是一个简单的网络社群。它源自一个关于互联网未来的愿景，是未来网络生态圈的实景。它带着一种神秘又美丽的吸引力，跨越了社群时代。它走的每一步都因为有你的参与而更加真实精彩。

也许你还在犹豫，还在疑惑，还在观望。但赚钱有术就在这里。

套用一句流行语：没有你，我很好，你可以见证我们的未来；有你，我们更好，我们一起创造未来。

走进这个生态圈吧，一起畅游在充满机遇的网络世界。不远的将来，网上一定有你的名字。现在，打开这扇门的钥匙就在你手里——还要等吗？

这封“推广信”，其实源自一个朴素的愿望：我曾经希望自己所在的社群变成信中写的那样，可一直没有实现，于是继续找。直到赚钱有术航海最后一天，我终于能笃定地对自己说：那个梦想中的社群，我找到了。

真正参与下来，越发觉得：赚钱的活动，越投入，越值得。
