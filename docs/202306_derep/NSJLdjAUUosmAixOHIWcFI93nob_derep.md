# 公众号公域流量爆发+新流量入口

公众号的公域流量，好像正被撕开一个口子。

这次分享是我被龙哥老板拉来的，本来属于快闪付费内容，今天直接公开。不拉群、不搞培训，就是纯分享，大家当交个朋友。![](img/a7192205fd3e64bb1c41d1523bc56a9c.png)

最近公众号圈子里最热闹的，莫过于各种流量主收益项目一个接一个冒出来。不管是赚钱带着大家写爆文的航海活动，还是大家疯狂讨论的AI绘画热点，本质上赌的都是同一件事——文章阅读量突然暴涨。很多人一头雾水，搞不清流量从哪来，主流做法就是闷头更新，等着自然流量上门。说实话，外面这类培训收费都不便宜，其实内核都一样，我今天就免费把门道拆开给大家看。

先说个最猛的案例：有人直接用ChatGPT批量产狗血情感文，光靠流量主收益一个月就能撸8万块。![](img/6c6c131605f25de22d8b4ff184441cdb.png)![](img/da0ef08e5080c8013f926d4941161983.png)![](img/7697d1148025fea91765e18d5c53db80.png)

一开始我也以为这些流量来自SEO搜索，但翻了好多大佬的后台截图，发现根本不是那么回事。除非碰上超级热点，不然不可能突然涌进那么大的搜索流量。所以唯一的解释就是——推荐流量。你想想，全国有多少微信用户，就有多少个微信号，这个超级流量池，微信看样子是要慢慢放出来了。![](img/0f0b46ce50940d8c20b094200142bc74.png)

观察发现，99%的爆文流量都指向一个叫「看一看精选」的地方。这就是变量所在。我仔细研究了半天，这个入口通常会出现在三个场景里：

第一种最常见，你在公众号文章底下点“赞”或“在看”之后，页面里偶尔会刷出一些推荐内容。![](img/a7a8e2962b8eb54d53b8629bcad75240.png)

第二种是新冒出来的，在订阅号消息列表里刷着刷着，会蹦出一些你根本没关注过的号。我的号前阵子就遇到过，最近又没了，感觉还在内测。![](img/307f5401be8daa676cf7b1bd77d935c1.png)

第三种可能是这次爆发最大的源头——微信底部一级菜单里的「看一看」。以前我也好奇“精选”是怎么选出来的，现在我基本可以断定：只要内容被丢进这个入口，就等于是“精选”了。![](img/4e444e53d7a4d6802bf2ad298b891c90.png)

但这个“精选”更像是系统在做A/B测试。我刷了大量内容后总结出几个规律：第一，根本没人审内容；第二，新号老号都能进池子；第三，文章阅读量高低都无所谓；第四，哪怕不是原创，也有机会被推。

也就是说，不管你的内容是什么、账号是不是刚注册、粉丝多不多、原创不原创，系统都有可能把你的文章挂上去，然后用点击率来决定后续要不要继续给量。所以那些动不动就爆的文章，就是这么被一轮轮推起来的，靠的不是“在看”的朋友圈社交链，而是系统公域真金白银的推流。只有系统持续在公域里给量，才可能爆成这样。我在朋友圈晒过的那些案例号，全都是在看一看里刷出来的。![](img/e46a961d05c346efec07af335855929a.png)

而且这个推荐还带点学习算法的意思。刚开始进去啥都推，但只要你老点某类内容，比如美女图，系统就会疯狂给你推同类的。相当于系统已经帮所有创作者把目标用户筛好了，所以不管什么属性的粉丝，都有机会做，真的是任何属性。![](img/542e6211ad3b5a5d36b9c297a5849fc9.png)![](img/003e7671e0946390b154bcbd488b0a9b.png)

这也解释了为什么爆文写作和AI绘画最近这么猛：

一是标题党——现在流量最稳的题材还是婆媳关系、狗血男女关系、中医养生这类常青树，爆文写作就是踩着这个点。

二是配图——当文章里图片至少三张时，系统会随机挑三张展示在信息流里。AI绘画基本都给美女图，屏幕占比大，还抓眼球，点击率自然高。

三是更新频率——大多数教程都说坚持更新一周就能进池子。我估摸着，是看一看会优先推最近七天发的文章，你连续更新七天，等于每篇文章都有机会被丢进池子跑A/B测试。如果只发一篇，那当然只有一次机会，七天就是七倍概率。

大家可以自己去翻看一看，里面全是机会，唯一的门槛就是两个字：更新。现在已经有不少人开始批量操作撸流量主收益了，导私域也特别香。

玩法也很简单：不想标原创的，直接复制粘贴，一天八篇硬铺；想标原创刷高收益的，用ChatGPT洗稿，再配上至少三张美女图。整个项目说白了，难点就剩内容产出，剩下的就看各人发挥了。

除了看一看，还有另一个新流量入口，堪称微信版“知乎”——就是“问一问”。之前还在内测，回答得申请资格，现在已经全面放开了。![](img/7ca85fd75dcea69f8633a412abba96b0.png)

入口在搜一搜里面，要是你的微信里压根没显示，问朋友要个链接点一下就能解锁。现在它和知乎几乎一样，但平台缺内容缺得厉害，最简单粗暴的办法就是去知乎搬答案，直接复制粘贴过来。

关键是，回答问题时默认用视频号作为主体，视频号又能关联公众号，公众号再导私域，整个链路特别顺滑。这就像几年前的知乎，还能蹭SEO红利，目前基本是一片空白。![](img/84807f0d526dc6f4800a99da4a553081.png)

我已经看到有人开始批量铺内容了，各个领域都有人在答题。

流量密码已经摆在这了，能抓住多少就看各位了。具体玩法可以参考赚钱的爆文写作航海，记住：全新的流量入口就是全新的机会，趋势来了挡都挡不住。![](img/6944bb0976609f209ddbf6cad56ec0b4.png)![](img/5774c76c9bac4dac622e50a777f3ef6f.png)![](img/3bfd87be706ba395c6253b2c430a2e56.png)

赚钱的内容，一般比行业早半年，希望大家别错过这波窗口。
