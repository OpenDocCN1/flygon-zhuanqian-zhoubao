# 一个月薪 6000 的打工人，辞职在家创业三年做到七位数，我的实战路径

在生财里潜水很久，今天终于把我的这三年尝试整理出来，和大家聊聊。

我是白龙笔记。2022 年经朋友介绍正式加入生财，其实之前就听身边人说起过这个圈子，内容越积累越厚，我也终于按耐不住进来看看。刚进来的时候信息量确实很大，但很快我就摸出了自己的用法：先定一个研究方向，再用生财的搜索导航去找相关的文章、案例和同行，集中火力啃透一类问题。

我主攻的三个方向是个人 IP 搭建、小红书变现和知乎内容。因为有生财这个检索工具加持，学习效率被拉满了，学完就立刻上手。

这三年下来，有几个能拿得出手的节点：

知乎的创业板块，我的回答累计点赞破 3 万，账号粉丝也过了 1 万；小红书这边我做了幼师资料的细分赛道，这个项目让我有了规模化的落地，累计带了 336 位学员一起把事情做起来；个人的 IP 形象也在慢慢沉淀，越来越清晰。这些成绩，其实都离不开生财内容的输入，但更关键的是，我没有只停留在看。

我的核心方法就八个字：边做边学，专题深挖。先把目标领域锁死，再在生财里找资料、找人，对标学习，马上实践，实践出问题再回头查资料补课。这样循环下来，学习才不是空转。

说实话，居家个体创业的孤独感是真实存在的。评论区也有朋友提到自己一个人待久了会压抑。我的解法是制造交流的场景：定期写公众号和读者互动，在社群里输出和讨论，线下也会约附近的同行吃个饭聊聊。长远来看，我也想把个人工作室化，固定好流程也让自己不那么封闭。但本质上创业就是一件事很孤独，再热闹也过不去那些只有自己才懂的坎。所以保持内心安稳，既能和自己对话，也能和同频的人对话，这才是关键。
