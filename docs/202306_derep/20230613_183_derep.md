# 小马宋：为什么学了那么多，总是没结果？

你有没有发现，我们听过的道理越来越多，可真正改变的事情却越来越少？

前几天帮一家企业准备演讲提纲，对方说：这些案例我们都听腻了，能不能换点新鲜的？我说：那算了，实在没空重新编一套。其实我心里想的是——案例听没听过不重要，关键是你们听完做了吗？真正用起来的又有几个？

这背后藏着一个特别常见的误区：我们总以为“知道了”就等于“学会了”。但现实是，知道和做到之间隔着一条巨大的鸿沟，光听、光看、光点头，永远填不平它。

真正有用的道理，往往朴素到让人觉得没含量。减肥的秘诀永远都是“管住嘴、迈开腿”，可为什么满世界都是减肥失败的人？不是因为不懂，是因为做不到。你说回家别刷手机、多看看书，可手指就是控制不住，一晚上像被吸进屏幕里，最后只能安慰自己：明天再说。而明天，还是一样。

做企业也是这个道理。很多经营难题本质上没那么复杂，无非就是选定方向后，拿出力度和决心去执行。可现实是——大多数人知道目标重要，也知道该怎么做，但执行起来总是打折扣，马马虎虎、拖拖拉拉。

我之前在何加盐老师的名企研学营结业典礼上说过一句话：我们自己讲出来的话，必须先信，先做。不然就只是口号。

太多老板习惯喊口号，今天说以人为本，明天说尊重人才，结果员工工资还要压一个月才发。这叫哪门子以人为本？言行不一致，说再多漂亮话都没人信。

当然，也有让我欣慰的反例。有位朋友听了我的分享之后跟我说，他们原本也是这样压工资，但从那以后决定立刻改掉，不再拖延。

所以你看，道理从来不需要太多。只要你真正认同它，然后马上去改、去做，这才是真正的“知行合一”。![](img/6e2614d8dda6df165af2b9c5618640f0.png)
