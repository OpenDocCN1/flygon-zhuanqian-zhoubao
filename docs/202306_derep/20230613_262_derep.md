# 拼尽全力的一年，终于等来了第一个正反馈

你有没有过这样的时刻？突然被身边人点醒，然后像换了个人一样，开始认认真真去拼一件事。今天想聊的这位主人公叫感遇，她是一名互联网公司的运营主管，平时主要负责内容运营和活动运营。

今年春节之后，她看到身边一群“赚钱人”的状态，突然像被触动了一样，真正开始把精力扎进赚钱社群。以前可能只是围观，这次是真刀真枪地干起来。几个月下来，她真的拿到一个扎扎实实的结果。

她说，这个过程中最大的收获不只是结果本身，而是认知被一次次刷新。以前想不明白的问题，在实操里慢慢有了答案；对工作上的思路和方法，也有了不少正向的影响。这些变化，甚至比那个结果更让她兴奋。

回头看这一年多，她特别想把自己的经历和感悟分享给刚进圈的新朋友。她说，自己不是天赋型选手，就是一个普通人，靠的是一点点死磕和持续行动。如果你也正在摸索期，或许她的故事能给你一点力量。
