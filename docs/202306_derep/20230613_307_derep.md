# ('《广州线下聚会：AIGC 赚钱局交流心得》', (2, 23))

上周日，我参加了一场在广州举办的AIGC线下交流茶局，收获颇丰，赶紧来和大家分享几句。

聚会地点藏在火炉山艺术园里的“山舍”，环境清幽，老板热情，空间也足够大，体验感我可以直接给五星。唯一的小插曲是上山的路不太好找，但跟着百度导航开车倒也没费太大劲，也算是“好物藏在深山”吧。

这次最期待的就是见来来。线上聊得热火朝天，线下看到真人，感受确实更立体。AIGC这块我研究不深，能贡献的干货很有限，来来分享的内容对我也算是个新领域，抱着学习的心态来接触新兴事物，挺有意思。

其他圈友也很有看点。英卡和瑾糖是第二次在茶局遇到，其他人都是第一次见。自我介绍环节大家聊得很high，话匣子一打开就收不住，碰撞出不少火花。每个人身上都有亮点，听别人的故事，就像照镜子一样，要么提醒自己，要么启发思考，要么让人燃起斗志。

一、自我介绍环节的启发

每个人都有各自的节奏：年轻人敢闯敢冲，成家带娃的则更求稳。年龄、阅历、认知层次都不一样，自然就存在信息差和资源差。这也让我对职业、副业、家庭、资产规划等问题有了更深的思考。具体收获包括：

1、出书的完整流程、目的和运作套路——感谢来来、大牙

2、海南封关运作带来的启发（财税、茶馆、公司注册）——感谢Kane、来来，我还顺手想了个名字：徐海驿站

3、百万信用卡打造，居然可以做成教程类知识付费（比如在赚钱发帖、测试需求、建群运营）——感谢瑾糖、墨鱼

4、偏门投机的事，短期赚到的钱，最终会因为人性问题凭实力亏回去。——感谢所有分享的伙伴

二、心得感悟

线下茶局确实能链接人脉，但效率还需要再提高，而且时间成本不低，至少要花半天，组局官更辛苦，得提前准备不少物料。之后我打算重点消化赚钱论坛里的精华帖子，再去链接那些有结果的前辈。毕竟对上班族+有娃家庭来说，每天能挤出的时间极其有限。而赚钱的精华帖几乎都是万字长文，好像写得不够长就评不上精华似的。怎么在有限时间里高效阅读，是个值得研究的问题。如果你有好的时间管理心得，欢迎联系赚钱阿墨私信指教，先谢过了。当然，还有另一条路：让自己变成有结果的人，吸引别人主动来链接，比如前辈榜样刀姐（玩赚ChatGPT）、楠姐（自习室），但前提是自己已经跑通商业模式、拿到结果，并且写了精华帖被大家看到。

三、获得的点子

不是所有点子都能落地、都适合落地、都值得all in去干，但每个点子都有它闪光的一面，都有潜在的商业价值。我比较感兴趣的商业模式关键词是：轻量、自动运作、可积累、互联网化。

大家贡献了不少想法：抖音视频有软件可以查重（来来）、ChatGPT-4体验、文I（虚拟女友）、小而精的团队（赛马机制、阿米巴模式，5人规模）、结合AI实现活体认证视频（500成本赚5000）。

四、后续待办

5月27日的航海线下组局，如果时间不冲突，我打算收集市面上的ChatGPT变现模式、思路，甚至实操拆解，做成主题分享。希望参与者都是已经有一些实践经验的，这样碰撞出的火花会更猛。（感谢大牙、来来、瑾糖）

最后，再次感谢组局官来来，让我认识了一群在不同赛道上努力奋进的小伙伴们。
