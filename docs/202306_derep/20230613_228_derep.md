# 这份操作手册是什么

这套手册共分为四个递进阶段，每个阶段的内容环环相扣。如果你是零基础的小白，建议直接按照顺序从阶段一开始吃透。

手册的颗粒度非常细，是我带线下团队时沉淀下来的内部培训资料。目的就是让新人拿着就能上手，基本做到边看边做就能跑通流程。图文内容比较多，我拆成了独立文档，文档里还会嵌套子文档。遇到问题就点对应阶段，哪个环节卡住点哪个就行。建议用电脑打开阅读体验最好。

之后我会慢慢更新一些进阶玩法，但就算是起步做小红书电商，这四步基本功先跑通一遍，账号就能跑起来。
