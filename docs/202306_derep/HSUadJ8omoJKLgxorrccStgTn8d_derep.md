# ('新手做视频号，如何快速拿到正反馈，喂饭级教程', (2, 24))

新手做视频号，最想要的正反馈无非是播放量起来、有人下单、觉得自己这条路没选错。今天这篇直接上一份“喂饭级”实操教程，希望能帮你少走弯路。

先别急着抄方法，做项目之前得先看清自己的牌面：你有多少时间、能不能露脸、什么时候有空盯数据。我自己在体制内上班，副业只能低调开展，直播这种要实时露脸的玩法基本没戏，所以选了视频带货。

视频带货常见的有纯混剪、纯实拍两种，我用的则是两者结合。核心思路很简单：找同品类里已经被验证过的爆款视频，拆开分析，把最抓人的爆点保留下来，其他稀松平常的画面用自己实拍的片段替换。

这里有个很关键的原则：爆款视频前几秒，也就是大家常说的“黄金前3秒”，一定要拿来用。后面再接实拍内容，重点展示产品什么样、有什么功能，让刷到的人一眼就明白你在卖什么。为什么非要保留开头？因为能爆的视频已经替你把过关了：前3秒留不住人，后面数据很难好看，更别想爆；反过来，能跑出来的视频，开头一定有点东西。

那么爆款去哪儿找？我一直在用的是巨量百应，入口放在这。
![](img/35a7f3dbf90d841c16d2b2cc9c6f111a.png)
进去以后，类目很多，你做哪个行当就选哪个。一排没展示完，点“更多”就能看到全部分类。
![](img/8edd20a329b4870e6e2bccf664cee680.png)
我当时做的类目是“个护家清”。
![](img/2f167b8884aac636a6358e33603f78c8.png)
点开之后往下翻，类目底下挂着不少话题，找到跟你产品对应的那个。
![](img/c0bf28e5fdbdd349d3a08c0fefefb388.png)
比如我做的那款产品，对应的话题就是下面这个。
![](img/41ca339aefcda439451690e4b46a8ccf.png)
点进去再选好类目，同行就全都冒出来了。
![](img/c958eaf41590a83f36c4954da1fe799b.png)
这些同行近期的作品和营业额都是公开的，含金量很高，可以直接拿来当参考。
![](img/a79784e2e27a40eb72b80a8965d5d8ab.png)
能站在这里的都是已经赚到钱的爆款。看到这类视频，你心里该有数了：这就是值得抄的作业。如果不这么想，那我只能摊手了。

找到爆款以后，怎么拆解？别慌，新手最愁的就是这一步，我也从这个阶段过来的。先把视频弄到本地，工具用 IDM（全称 Internet Download Manager），网上随便搜就有。装完之后浏览器里会出现插件图标，看到它基本就算装好了。还有一步别忘：重启浏览器，说人话就是关掉再开。
![](img/e00ec0c0a1896ef96d5453b12fe70514.png)
我演示用的是谷歌浏览器（学名 Google Chrome），其他浏览器的用法大差不差。

回到巨量百应，打开你想下载的那条爆款视频。
![](img/735e610235ff83ed19c239d4732ee591.png)
我连自己做的品都交代出来了，点个赞不过分吧？
![](img/47fdce3c1e5fb2e2ff74654403133e72.png)
看到那个悬浮的小按钮了吗？点一下就能把视频保存下来。

视频到手后，打开剪映导入进去，接着点击“智能镜头分割”。
![](img/d25ae8f863446479dccc8419a9fa7eb0.png)
剪映会自动按镜头把片子切开。这样一来，整支视频一共用了多少个镜头、每个镜头拍了什么、爆点到底在哪儿，全部一目了然。

![](img/e03ed25b9b976209e78e6ad26b5bf34f.png)
看完拆解，接下来要判断哪些镜头你有条件自己拍，顺便留意他们拍摄时用的角度。然后就可以动手实拍了。
![](img/e621eb1ed99ada40d937f87fda545413.png)
我直接买了一批实物回来，反正自己也能用，不算浪费。设备特别简单，一个手机支架加一部手机就能开工，拍出来的画面和原视频里要替换的部分差不多就够了。

![](img/ef59fc3d11e73e4d72c34cdadd516c5b.png)
还得记得，同一个角度和背景用太多次，观众也会腻，所以拍摄时尽量让场景和角度丰富起来：餐桌上来一组、地板上拍一组、洗手池边再来一组，背景一变、角度一变，能用素材就多了。实拍完成后，把这些镜头嵌回原视频，把平淡部分全部替换掉，只留下爆点。

![](img/c622fcebbd262141abb324e4f7531fb3.png)
第一个号我是为了测试，每天只发一条，结果刚出了一单就被限流，之后播放量直接变成0。

![](img/2caa0b73fd39f2cae0958b50bd472d8e.png)
于是又启用了第二个号，这个坑我替大家踩过了，情况类似的可以参考。
![](img/06513ae83fc9eddd4ac59d06e83f0f1e.png)
![](img/b2ea096fb58b90daf857335cfdd57a7a.png)
第二个号我把发布时间定在早上8点左右。新疆的作息是上午10点上班、下午8点下班，我早上8点发完就没管。没想到这个号爆了，跑出15万播放，而且爆的时间也是早上。账号当时在我朋友手里，等我下午下班回家才看到已经爆了，评论区里好多人都在问怎么买。可惜已经晚了。如果当初把发布时间定在下午8点，我下班回家正好能守着手机开播，这波流量就不会白白浪费。可惜没如果，后来这个号也被限流，播放量又一次清零。

做副业就是这样，很多坑不亲自踩一遍根本记不住。这两个号操作方式完全一样，出单都很快，正反馈是确确实实拿到了。接下来要做的，无非是继续优化、反复迭代。如果你也在搞视频号，欢迎一起交流，一起在生财有术里往前走。
