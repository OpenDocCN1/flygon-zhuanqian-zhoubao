# 一、为什么我看好这条路

我一直的想法是，AI本质上只是工具。一部分人把它当笑话，一部分人用来省点事，我更看好它能让普通人完成过去做不了的事，并且直接变现。

在交流中认识了向南和荷包蛋糕，两人都做过很久的写作，我们三人一拍即合组了AI写作小组，实操下来确实跑出了结果。

糕老师本身有三年写作成熟期，过去稳定月入1万出头。借助GPT后效率大幅提升，叠上毕业季需求井喷，收入冲到月入近3万，如下图。

# 二、用三个问题拆懂盈利逻辑

1. 问：整个变现链路是什么？
答：拿单 -> 和客户对需求 -> 用AI出稿 -> 交付修改 -> 收款完结。

2. 问：单子怎么持续来？
答：现在最稳的入口是淘宝。搜索写作、代写相关关键词，直接私聊客服问是否招写手。

3. 问：一单赚多少？
答：价格跨度很大。短文类如演讲稿，单价一两百；高客单如论文，单价几百到几千。关键看到手比例。

一般平台会抽走40%，剩下60%给到客服，客服再分给写手，通常写手到手只剩15%到40%。

基于这个分成结构，我把副业分为三级成长路径：
初级当写手，练手型赚钱，目标日入200~300；
中级做客服，提成能提到60%；
高级分两路，一路做个人IP做私域拿一手单，一路自己开店接单。后面会详细讲。

# 三、实操全流程拆解

## 1.如何拿到单

1.1 进写手群
1. 在淘宝搜索写作、代写等词，直接问客服是否在招写手。
2. 招的话会拉你进群。
![](img/11663880ece62a7270e7bc10b88120b8.png)
3. 不招的话基本直接回绝，全程一两句话搞定。
![](img/d0976485735092810d6c17b80a5c67a5.png)

1.2 进群后接单
进群后客服会定时在群里发单，自己挑感兴趣的接。
![](img/7841741e9914c141ca11c2abdeb3c69c.png)
1.3 积累渠道
建议多加群，几十个群都很正常，选择面才大。记得把各家店铺、联系人、结算方式整理好，方便后面对账。
![](img/f4a06a2633e439c83cbee37f7a0858d0.png)

## 2.对需求的关键

客户很多时候说不清要什么，需要我们主动挖掘。信息越全，喂给GPT越准，返修概率越低。沟通时要灵活根据文体调整提问方式，例如：

* 确认标题
* 确认字数体量
* 确认写作风格
* 确认背景信息
* 确认客户身份和岗位
* 确认使用场景
* 以及其他定制化点

越细，越能一次过。
![](img/06c9c4bb39c5284c8992c2b5a8526861.png)

## 3.用GPT成稿

这个项目能长起来就因为文体多。演讲稿、实习报告、函授作业、征文、论文文科理科等等。每掌握一种文体的写法，能接的单就多一类，难度越高，单价越高。

你在实操中会不断积累各类型文章的套路，这是真正的技能复利。

## 4.修改环节

客户不满意时要快速定位：
* 具体哪一段不满意
* 期望达到什么效果
* 先给出你的修改思路再动手
![](img/c6cb673d9663c78dc6843d73f9d3eed3.png)

## 5.交付与结算

结算是靠记录。之前建的Excel表格这时就用上了。
![](img/514c4135e107fddb157f5d218f47d04d.png)
不同店铺结算周期不同，多是周结月结，很少日结。把结算日和对接人记牢，到点就去对账要钱。

# 四、写作实操案例：演讲稿

工具建议：ChatGPT官网。市面上的国产模型和镜像在逻辑连贯上还是差一些。

核心是提示词。同样一个要求，问法不同结果完全不同。

以演讲稿为例：
第一步：先让GPT输出演讲稿的定义和通用框架
![](img/2d763bfe888f23fc51e5a9e159a21a32.png)
![](img/b78f8622b7389799fdef8c8c2ac240fd.png)

知道了写法和骨架后，第二步整理客户需求
![](img/264dc12395cf7074a9d81f4ed26464a0.png)
图里客户已经说明了身份、用途、主题。那我们整理成：
身份：书记
主题：门诊开业仪式
类型：演讲稿
要求：3-4分钟约1000字

第三步：用GPT生成正文
![](img/25acf5758e3d77de30d90829108b51d6.png)
我的习惯是身份设定+角色设定+具体要求组合成提示词。

第四步：润色
机器初稿通常有两类问题：
1. AI感太重，不像人写的
2. 细节没对上客户要求

需要反复微调，扩写重点段落，去掉同时、其次、最后这类套话。初稿定稿后发客户，再按反馈修。

# 五、效率工具

流程跑顺后就要做提速。后来找技术做了个网页小插件，把常用的文体模板存起来，关键参数化。换单时只需改参数即可套用，省去重复描述的时间。

# 六、如何做大

## 1.升级成客服拿二手单
方法很简单，和店铺混熟后在招客服时应聘即可。客服一般能拿60%分成，你可以自己写也可以再分给写手，15%到40%自定。
注意：多数店铺要求客服每天在线至少三小时，可和店长协商。

## 2.做个人IP和私域拿一手单
IP是长期积累。我们认为最核心的一点是：把每一次单子都当成口碑资产。服务做好，客户会主动介绍朋友，这些客户的信任度和转化率最高。

## 3.自己开店接一手单
我们还在摸索中，不建议新手上来就开店。现在淘宝规则复杂，投直通车成本很高。
2023.10.14更新：实测开店推广烧钱严重，新人先从底层做起。

总结一句话，先从加50个写手群开始，跑通就有钱。
