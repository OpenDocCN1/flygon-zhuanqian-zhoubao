# 赚钱新人也能在小红书店铺跑出GMV：我的30天实战拆解

“在小红书做生意，本质上就是一场赚钱的拼图。”

我是步凡，目前大三。4月6号我开了人生中第一家小红书店铺，跑到5月6号，整整一个月时间，单店GMV冲到1.7万，净利润大概8000块。

这个成绩并不是我有多厉害，而是把赚钱里老师们公开的信息拼到一起后的结果。整理完后在航海群里分享，很多人私信追问细节，今天集中回复一下。

**关于1688没运费险，运费问题怎么解？**

回到我之前的思路。1688上的货，先看品质有没有优势。如果产品本身品相、功能是过硬的，那完全可以把价格抬一抬。好东西配得上好价钱，在小红书我基本都是按2倍左右来定价，利润空间自然就出来了。

**封面负责点击，内容负责转化，具体怎么玩？**

没有万能模板。不同品类、不同人群，对视觉和话术的偏好完全不同。你纠结的核心其实是：我的这个品，在小红书上用什么封面、讲什么内容才能成交。

我的建议是去看杉木老师写的关于色粉与目标用户差异的那篇文章，有非常具体的判断逻辑，结合起来用会更清晰。

最后说一句心里话，我不是什么大神，做的也只是中等水平。赚钱里比我年纪小、比我做得好的同学一抓一大把，我只是脸皮比较厚，敢于第一个站出来复盘。

真的要感谢在赚钱里持续输出的几位老师，还有涛哥给文章提出的宝贵建议，以及赚钱团队的阿蓝和各位志愿者在背后默默的付出。正是大家毫无保留的分享，让我能把百家所长汇成自己的方法。
