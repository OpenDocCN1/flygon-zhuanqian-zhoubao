# ('第二个“太二”？赖美丽的观察与思考', (2, 19))

前几天听说九毛九又悄悄孵化了新副牌——赖美丽青花椒烤鱼。作为太二的“同门”，它到底有几分成色？我带着好奇去探了探店，也顺便聊聊这类新品牌的一些观察。

先说选址。![](img/345b1b0a9352e10f3912c8b15d08ed38.png)

赖美丽开在黄埔大道西的马场路美食街，隔壁就是九毛九。这一带本身就是餐饮集聚地，门口停车位不少，离地铁站大约561米，周边一公里商务楼、高端楼盘扎堆，出入的多是高级白领，房价也稳居广州第一梯队。说白了，客群质量高，消费力也够强。

选好位置，门头就是第一道题。

先看门头。![](img/947863fecfa8a4ad5e2e9b83ff8c1578.png) 整体走简洁路线：IP形象、品牌名、品类名，再加上一整面白色灯箱，年轻感很足。门头要干两件事：把人吸引过来，以及告诉别人“我是什么店”。

引客这件事，赖美丽做得挺巧。

IP是一个笑容满面的女性形象，正抬手擦汗，热情好客的感觉一下子就有了。更妙的是手部会动，动态的物体天然比静态更抓眼球，而且手臂上下摆动，恰好强化了“忙着招待”的画面感。晚上那一整面白色发光背景更是显眼，远远望过去，很难不注意。

解惑也用了最简单直接的方式：名字后面紧跟着“青花椒烤鱼”，顾客一看就知道这里是吃烤鱼的。进门右手边还有一张“美丽说”海报，形式跟太二的“店长说”有几分相似，把产品卖点讲得轻松好玩。

进店之后，我重点看了三块：设计、物料、服务。

先说设计。![](img/6a0c464d282a8067d25e0147fdd326b0.png) 一进门就能看到活鱼池，池边标着“我只用活鱼”，一句话就把“新鲜”这个差异点立住了，和不少用冰鲜鱼的烤鱼店立刻区分开。![](img/d610329a739b207b577e1e0a7bbae6a8.png) 右边还有个小舞台，大屏幕循环播放鱼的来源和做法。据说以后可能请愿意分享故事的顾客上台，但目前还没正式启动。看到这个舞台，我第一反应是脱口秀，又想到胡桃里的互动点歌抽奖。如果后续真能把这类内容接起来，应该会是很有意思的体验。![](img/e61a1cedd8642d5161127a24f79347a6.png) 透明厨房现在已经很常见了，能看到食材处理全过程，顾客自然更安心。

物料和标语也很会做记忆点。![](img/2eb0f2087d849daf877dd10fb8aada3c.png) 店里不同角落都有那条鱼的IP形象反复出现，不断提醒你：我们家的鱼是主角。这种植入在原材料层面做出了差异化，还成了小朋友可以互动的小道具。![](img/2f49bcd3adfba334f73fd63b35d4290f.png) 原材料展示区用了“活泼文案+漫画”的组合，像是在跟你开个小玩笑，让人会心一笑，品牌好感度也在这种小细节里慢慢累积。![](img/995e8827d6a782986721a51183f0df0d.png) 桌上还有吃鱼步骤，太二当年也有类似设计。它不是为了增加麻烦，而是制造仪式感，让“吃鱼”这件事变得能被记住、被传播，也更有辨识度。

服务上也有自己的节奏。鱼上桌后，服务员先问好，慢慢倒入汤底，紧接着讲一整段吃鱼步骤。用餐过程中，店员也在留意顾客的情况，有人询问时不仅讲得耐心，互动也非常热情。

最后看看产品怎么制造记忆点。![](img/bd6243e477e235376516656c515a38fc.png)

烤鱼端上来，先听店员解释，再倒入汤底，蒸汽一下子升起来，确实有种新奇感。卖点上，“鲜活”和“弹”两个词出现频率极高，菜单、食材展示、服务讲解几乎都在反复强调。![](img/7402d65ef16b44d695131e9dbab27dd0.png) 另外还有一些少见的新奇产品，比如烤苹果、绿茄子，市面很少遇到，也让赖美丽和普通烤鱼店拉开了距离。

讲完这些，说说个人感受。

门头的视觉吸引力确实很强，但和顾客利益直接相关的卖点表达有点弱，导致“被吸引”和“被说服”之间缺了一座桥。就像看到一件很惊艳的东西，但我还不确定它是否比同类更能解决我的需求。

那个小舞台是我最期待的部分。氛围这件事，最重要的是“开启”和“闭环”，可目前它还没有真正跑起来。如果后续没有内容接上，这块地方就太可惜了。

赖美丽身上有太多太二的影子。借力成熟品牌，确实能更快建立认知，但借完之后如果没有自己的突破，那借来的就不是力，而是一把刀。

“鲜活+弹”曝光量很大，但从物料到话术，始终没有把“为什么鲜活”“为什么弹”“为什么要吃鲜活和弹”讲透，说服力还差一口气。这一点可以参考小马宋老师为半天妖提炼的“不用挑”，那才是把卖点做实、打进顾客心里的做法。

当然，这家店才开不到10天，还在打磨阶段，能做到这个程度已经很不容易。我作为旁观者，动动笔写写感受很简单，真正开店的人面对的事情要复杂得多。

谢谢赖美丽给了我一个全新的视角，也让我学到不少。如果有时间，我可能会再写写这个品牌为什么会出现，以及它背后的运营思考。希望它越来越好，越来越亮眼。
