# ('首次餐饮创业踩的坑', (2, 11))

最近听说了一件挺让人唏嘘的事：我一位前同事，麻辣烫店才开了不到两个月，美团同品类区域排名已经做到第一，但她打算这周六就把店关了。

起初我劝她再扛两个月看看，可等我去她店里转了一圈，改口了——关了吧，早点止损。

她是那种说干就干的姑娘，开店前也做了不少功课。可算完账之后她整个人都懵了：忙活两个月，一分钱没落着，等于白给员工、房东和外卖平台打了工。她说，创过业才知道，打工时那些困难根本不叫事。现在每天睁眼就是账单、差评、囤货、食品安全检查，焦虑到不行。

但她也不是瞎干，有些东西其实想得挺明白：

选品没踩大坑。没碰奶茶、服装这类容易翻车的项目，也没去搞重资产的门店。

开业前专门跑到别家店学习了半个月。

没直接盘店，而是选了美食城档口，投资少，压力小。

盈亏平衡点算得清清楚楚：每天必须卖60单才不亏，每天赚多少亏多少心里有数。

可惜，功课做得不少，坑照样踩了一堆。

第一个坑：对标对象选错了。

她上来就瞄准行业里最顶尖的店，照着人家的菜品抄。可问题是，你一个刚起步的小店，对标营收高你五个量级的巨头，根本学不来。真正该对标的是自己店铺周边区域做得最好的同行，或者那些刚开两三个月就做得特别好的新店。看一门生意，要盯的是：投了多少、赚了多少、能不能持续赚钱、有没有成功样本。找到样本，结合自身优势，照着打就行。如果发现某家店产品、运营都一般，但销量就是好，而你自信能做得比它更好，那直接复制它不就完了？

第二个坑：产品太多了。

东北麻辣烫，她上了100多个SKU。我听的时候整个人愣住了，她说同行比她还多。光冰箱就买了三个。菜品一多，采购难，后厨操作乱。很多品一个月卖不出20单，根本就是摆设。完全可以按销量数据来定品，卖不动的直接砍掉，这不香吗？

第三个坑：流量没研究透。

她主要靠外卖生存，但美团买量的玩法基本靠猜。今天冲300明天冲500，销量涨了跌了都找不到原因。这玩意儿确实难搞，平台规则、同行策略，很多信息根本摸不着。可正因为难，才更要花心思去琢磨，而不是瞎花钱。

第四个坑：关注错了细节。

她的包材——筷子袋、碗盖、外卖袋子，全都精挑细选，钱和时间没少花。食材也挑好的，这没错，但问题在于，她主打的是“量大实惠”。这类客户可能根本不看这些细节，再精致的包装也形不成复购。她的精力应该放在搞流量上。口味和包装很难跟同行拉开差距，只要品质说得过去，谁能把终端运营做好，谁就能赢。

第五个坑：调研不够深。

她看到东北麻辣烫火，头脑一热就冲进去了，开业了才发现自己在这件事上毫无优势。为了强调正宗，连麻将都要从东北运过来。选址时看到附近办公楼多，以为用餐需求大，却没调查到很多大公司都有食堂，也没发现3公里内已经有10多家同类店，其中还有杨国福、张亮这种头部玩家。

如果她能提前认识30个同行，摸清人家的成本结构和赢利方式，或者先去别人的店打打工积累经验，很多坑都能绕过去。

好在她还年轻，又是合伙干，亏得不算狠。这笔学费交了，就一定要长记性。创业是一场不断踩坑再爬起来的游戏，每一次坑都可能成为下一次跳板的支撑点。

祝她下次开局，能少踩几个坑，多赚一些钱。
