# 入场三个月，我总结出新手“不当韭菜”的门道

聊到“如何避免成为一颗韭菜”，我脑海里最先浮现的，不是大道理，而是一段真实的经历。

大家好，我是大闵。今年 3 月，我刚以纯小白的身份摸进赚钱有术。3 月 18 日，机缘巧合结识了老瞿——圈内公认最懂二手书的男人。再过一周，我们就认识正好三个月了，而我在这条细分赛道上，也总算做出了些拿得出手的小成绩。

5 月航海季，我有幸担任二手书项目的答疑官。那阵子，问题解答了不少、人也接触了各式各样、还专门做了一次分享。说起来，真正让我有感触的倒不是“答疑”本身，而是这个过程里看到的众生相：太多人正大步流星地走向“被割”的位置，自己却全然不知。

分享结束之后，陆续有朋友私信我，说喜欢我的风格和表达，想跟着我一起成长。非常感谢大家的信任，但说句实话：这面旗我扛不动。成长终究是自己的功课，别人替代不了，也背负不起。我很乐意敞开跟大家交流，但咱们之间永远是平等的关系——你不必仰望我，我也不想被谁依赖，互相照亮就好。

正因不愿辜负这份信任，我把“防割”心得整理了出来。丑话放在前头：它未必能帮你赚到钱，但大概率能帮你少亏钱。另外，我的文字一贯比较犀利，这只是个人风格，对事不对人，良药苦口，望各位海涵。
