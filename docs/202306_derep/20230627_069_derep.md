# ('关于就业还是创业的个人思考', (2, 15))

最近赚钱有术传来一个值得关注的消息：前内容负责人洛羽，正式告别了官方团队身份，转身成为一名普通圈友。

很多人看到这可能觉得是“离职”，但细看你会发现，这其实是一次身份的重塑——人还是那个人，目标也没变：继续在赚钱有术产出对大家有用的内容。

从“洛羽官方”到“洛羽圈友”，变化的只是称呼，不变的是一路同行的承诺。告别不是离开，而是换一种更合适的姿态，继续完成未竟的目标。

就像她说的，不论在团队内还是星球里，大家依然是一起在赚钱路上探索的伙伴。评论区也满是熟悉的鼓励声：

“目标清晰的人，做什么都带光。”
“清醒的人干清晰的事儿。”

没有不舍的煽情，只有满满的祝福和期待。毕竟，真正有价值的内容，不会因为身份的改变而停止流动。

加油，洛羽；加油，每一位在赚钱路上的人。
