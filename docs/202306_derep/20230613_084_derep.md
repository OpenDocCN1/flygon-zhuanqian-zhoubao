# ('假如给你三年的时间，你觉得考上 985 难还是年入百万难？', (2, 31))

给你三年时间，是想办法拿下一所 985，还是想办法把年收入做到百万？这两件事，哪一个对你来说更难？

这是龙哥在圈子里抛出的思考题。他让大家代入自己：从现在开始准备三年，你会押“985”还是押“百万年薪”？评论区很快就吵起来了。

站 985 的人不在少数。
林森说得很实在：能进 985，实力就已经说明了一切。
一个 ID 叫“果然靠谱”的朋友，也直言 985 太难了。
落日骑士想都没想：985 那边才是真难。
BO.A 同样跟票。

王舒林则是另一派：两个目标都不算事，简单得很。

小新的回答最有意思。他先扔出“不会”两个字，接着又解释了两句：自己一直站在红利那一侧，哪行赚钱就去干哪行。

所以你看，这不是一道数学题，而是一个判断题。有人想要确定的学历背书，有人想抓住不确定的机会红利。没有标准答案，只看你愿意把三年押在哪里。

轮到你了：选 985，还是选百万年薪？记得说说为什么。
