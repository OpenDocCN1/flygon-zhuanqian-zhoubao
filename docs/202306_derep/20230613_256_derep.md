# ('《让我年入百万的商业认知》', (2, 15))

我，土木工程专业出身，在房地产行业待了8年，说白了就是“工地搬砖”的。后来感觉行业不行，果断辞职，花了整整两年转型。最初我憋着一股劲想做个APP“干掉”知识星球，幻想着融资上市走上人生巅峰，结果几个月就黄了。阴差阳错，我扎进了二手书行业。说实话，我一开始根本看不上这行，觉得不够高大上，又脏又累又繁琐，好几次想放弃。可现实很打脸——只有它让我赚到了钱，而且越赚越多。

现在我有40多个闲鱼店铺在运营，每个店都上到3000多件商品，年利润100多个。当然，跟搞短视频和直播的大佬比，这不算什么。但对我来说，已经是从工地到“个体户”的重大跨越了。

在闲鱼二手书航海圈里，我猜大家最困惑的无非是这三件事：

1. 为什么我的账号就是没流量？
2. 为什么我自己都搜不到发布的商品？
3. 为什么有点曝光却不出单？

说白了，这叫流量焦虑。钱能解决90%的烦恼，而流量能解决90%的项目难题。现在这个信息爆炸的时代，平台不给你流量，你就等于不存在。

怎么根治流量焦虑？答案不是满世界求玄学秘籍，而是先搞懂平台的游戏规则。

平台到底握着什么权力？

想象一下：你作为顾客，在闲鱼搜一本书。平台其实只有两个操作按钮：第一，决定把哪些商品展示出来，也就是“曝光”；第二，决定这些商品按什么顺序排列，谁排第一。至于你点不点、买不买，平台真的管不着。

如果你自己是闲鱼老板，你会把流量给谁？

假设今天有100个人搜《平凡的世界》。平台一定偏爱那些成交率高的链接——因为顾客来了能满意地买到东西，下次才愿意再来，不然客户就被别的平台抢走了。而且成交以后平台才有钱赚，它也要活下去。但平台也不能只喂老链接，不然新商家永远没机会，平台迟早也会死。所以它会从100个流量里拿出大约30%给新上架的链接。万一老链接哪天突然下架，它还得靠新链接里的好苗子顶上。

所以你会看到两个现象：

1. 转化率高的链接会越卖越好。这就是为什么刷单一直被不少人当成见效最快的手段，但组织刷单已经写在刑法里了，碰不得。
2. 新上架的商品总会得到一点试验流量。这也是为什么做电商必须坚持每天上新。

平台除了赚钱，还有别的“小心思”吗？

有，而且很多。它故意把规则搞得很复杂，不然人人都去刷单和上新，平台就乱套了。规则背后，平台真正想要的是：

- 让你的服务更好。好评率高，它才敢把流量给你，用户体验好，客户才留得下来。
- 让你降价。哪怕每天降一分钱，也能让平台整体价格更有吸引力，引来更多人。
- 让你去完成它设计的小任务。做完奖励闲鱼币，闲鱼币能换曝光，等于让你花钱买流量。
- 让你优化商品详情。把图片、文案做得更吸引人，下单率自然就高。

你发现没有，平台手里唯一的武器就是曝光。它会用这个武器，引导你朝它想要的方向走。闲鱼甚至会在曝光量旁边告诉你“因为什么增加了曝光”，还塞给你一份卖家宝典，就差手把手教了。可即便如此，还是有人不信平台说的，偏要去请玄学大师，学一堆云里雾里的课程，最后越搞越糊涂。

为什么同样的书，别人有曝光，你没有？

接着用《平凡的世界》举例：100个搜索的人里，可能有30个人只是来比价，根本没打算买。如果你的链接碰巧被推给了这30个人，画面就很难看：他们不点不买，系统就会认为你的链接不行，转化率太差，于是慢慢断掉你的流量。两个看起来差不多的链接，因为系统推送的流量质量不一样，一个可能卖爆，一个可能直接废掉。

系统是怎么判断用户是否“优质”的？主要看历史消费记录。但系统也没法做到百分百精准，所以这里头有运气成分，我们控制不了平台给我们推什么样的流量。

回到开头的三个问题：

为什么账号没流量？因为你上架之后就在那儿等风来，啥也不干，运气又不好。好不容易拿到几个曝光，客户点都不点，买也不买，平台凭什么继续给你流量？

为什么商品自己搜不到？平台每天的流量就那么多，信息爆炸时代，不可能每个人都能照顾到。要么你的转化率高到它天天推你，要么这个商品冷门得只有你一个人在卖，它才会想到你。

为什么有曝光但没成交？曝光只是给你一张入场券。图片不吸引人、价格太高，用户一点就跑去买别人的了；也可能是平台根本没搞清用户想要什么，推了一堆不精准的人，自然转化不了。

那到底怎么提升曝光和转化？

底层逻辑聊完了，接下来就是干法。

1. 选品定生死。选那些有人需求、但卖的人少的商品，别去红海里硬刚。
2. 基本功要扎实。账号包装、图片、文案、价格，哪一样都不能拉胯。流量来了接不住，等于白送。
3. 做平台鼓励的事。它鼓励降价，你就每天降一分；鼓励优化详情，你就发布后再慢慢改；鼓励做任务，就把任务做满，用闲鱼币换推广。上架完就躺平，真的不行。
4. 运气不好就多试几次。系统判断用户不准，可能把不想买的用户都推给你，链接就废了。废了就下架重发，多来几次，总有一次系统把精准流量推给你，链接说不定就爆了。
5. 卖出去了别惹事。全是差评，纠纷不断，平台哪敢继续给你流量？做电商要懂得大事化小、小事化了，让客户满意，平台才敢把流量托付给你。

现在闲鱼、淘宝这些平台，用户都过亿了，代码早就复杂得像一个黑匣子，谁也说不清里面每个具体规则。但底层逻辑不会变：平台想要什么，你就给它什么——想要转化，你就做高转化；想要服务，你就做好服务；想要上新，你就天天上新。你把平台要的数据给到位了，平台不会吝啬曝光，因为它也离不开我们这些能留住客户的商家。

我是老瞿，龙哥盟里最懂二手书的男人。这些就是我眼里电商的底层逻辑，也是我每天在账号上勤勤恳恳执行的东西。用了两年时间，我完成了从职场到个体户的转型。2023年，希望链接更多圈友，一起搞钱。我始终相信：打工人的终点是个体户。但前提是，你得是个努力的人。
