# 日引流200+！贼安全的一套小红书引流技巧！

最近不少做小红书的朋友都在跟我吐槽：平台对导流行为的管控越来越严，一不小心就容易踩线。我自己也被问过很多次关于“引流违规”的问题。

之前我也写过两篇关于引流底层逻辑和套路拆解的内容，但那套东西理论性偏强，说白了就是“听起来有道理，真上手不知道从哪开始”。所以今天这篇，我决定掏点实在的——把我自己用了很久、至今零违规的引流打法完整拆给你。用这套方法，我公众号每天稳定进人一两百，微信好友增量也能维持在几十个，且全程没有出过任何问题。

![](img/174a9a6d9f84552f4b5728b04cfc0716.png)

直接上干货，全文分三块：玩法总览、执行细节、避坑提醒。

**一、这套玩法的核心逻辑**

一句话讲明白：先在小红书创建自己的群聊，靠引流笔记把人吸引进群完成初次接触，然后由小号在群内发布带联系方式的图片和话术，把用户引导到公众号，再从公众号筛选出真正有意向的人加到微信。

1. 引流笔记怎么做？

之前那篇理论文里详细讲过，这里不展开，简单概括就是：锁定爆款选题和封面风格，创作出能戳中用户兴趣、需求或痛点的内容，然后在内容里埋好“钩子”，让用户主动来找你建立联系。

2. 小红书群怎么建？

现在小红书建群没有门槛，路径是：小红书 → 消息 → 右上角群聊 → 创建群聊。

群名字很关键。一定要和你的产品/领域高度相关，并且让人一眼就知道群里有什么、能获得什么。比如我做副业方向的，群名就叫“副业项目拆解”或者“副业资料分享”。如果你有资料可以送，直接在群名里带上“xxx资料领取”这类字眼，用户看到就愿意点进来。

3. 群聊设置里几个容易被忽略的点

大部分设置保持默认就行，但下面这几项建议手动调整：

- “在个人主页展示”务必打开，不然别人进你主页根本看不到这个群，白白浪费流量；
- 系统默认的欢迎语可以关掉，没什么用，还影响进群体验；
- “进群确认”和“展示历史消息”两个开关长期开启就好；
- “关联笔记”是重中之重。不关联的话，用户在看笔记时看不到你群聊的入口，会损失一大截流量。记得把群聊关联到你的笔记——之前发过的、还在持续出量的笔记，统统可以关联上。

关于群禁言，这里多说一句：之前有人搞出“代开禁言”的灰色副业，导致平台上冒出一堆这类服务账号，严重干扰了社群生态，所以小红书直接封堵了这个功能。现在新群已经无法开启全员禁言了，之前已经开了的群还可以继续用。

**二、引流承接怎么做？**

做引流之前，先准备一张引流SOP图。常见的做法有：手写微信号拍照、把微信号做到背景图里、用键盘皮肤“抠”出微信号、让用户在评论区留微信号等。

这些方法我都试过，有效是有效，但都有风险——微信号容易被系统识别，且短时间内加人太多也容易触发限制。

我目前亲测风险最低的方式稍微绕一点，但胜在稳：

**核心思路：先引流到公众号做承接，再从公众号筛选用户转到微信。**

公众号的注册流程网上到处是教程，不赘述，搜“微信公众平台”跟着指引走就行。唯一提醒：一个实名现在只能注册一个号，不过可以绑定最多5个。

注册好之后，重点设置两个地方：

- 自动回复：设置关注后的自动回复话术，简单介绍你的优势和资料领取方式，末尾放上微信号；
- 菜单栏：设置一个“联系我”的入口，可以用链接形式，点开直接弹出二维码。

公众号的日常维护不是重点，有空就更新一下，没空一个月更一次都没关系。

**三、执行细节：用最低风险发布最直接的引流信息**

1. 小号当“工具人”

只要用主号操作，不管做什么都等于把风险往自己身上扛。所以我的做法是：风险全部转移给小号。

具体操作：
- 新注册一个号，昵称写成“XXX小助理”；
- 把小号拉进群，设为管理员；
- 每次有人进群，由小号发送群公告或引流SOP图。

全程操作都交给小助理，主号基本零风险。

2. 引流SOP图怎么做

给大家看看我实际用的图（名字部分手动打码）：

![](img/058419a77a94f472e90654070a928b98.png)

这张图一眼扫过去就知道怎么找到我，但整张图里没有任何一个直接的联系方式——我自己拿去当笔记发，也能正常过审。

制作也非常简单：
- 截一张手机通讯录页面；
- 截一张搜索结果页面；
- 用美图秀秀把两张图拼在一起；
- 然后用涂鸦笔把敏感信息涂掉。

思路延伸：如果你不想引流到公众号，也可以把微信名片截图，只保留头像和昵称，其他全部打码，再拼图，同样可以把风险压到很低。

3. 进群筛选

既然禁言功能已经失效，进群人员的筛选就变得格外重要。以下人群我是一律不放行的：
- 用系统默认昵称的；
- 同行（各行业自己判断）；
- 昵称里带“蜜桃”之类关键词的（懂的都懂，这品牌做qqny的，炸群非常严重）。

此外，一旦有人在群里发广告，第一时间撤回。广告太多容易被举报，群聊会收到平台管制。为了省心，我一般会引导大家尽量少发言，有问题直接加微信沟通。

**四、注意事项**

1. 人群再筛选

前面在小红书群做了一轮筛选，到公众号后可以再筛一轮——真正意向不强的人，一般不会主动加微信。如果你想再省力一点，直接在菜单栏和自动回复里写清楚你的付费项目，告诉用户“有需求再联系”，能帮你省掉大量无效沟通。

2. 一定要分流

别以为走公众号就万事大吉了，我曾经也加爆过好几个微信号。所以引流的同时务必做好分流准备：多准备几个微信号，备注加不上的就引导加另一个，避免流量白白流失。

3. 小号管理注意

小号简介可以@大号，大号也可以@小号，这个不违规。但小号千万不要去私信评论区的用户——私信是平台重点监控的地方，私信发太多很容易封号。有用户主动私信你，引导进群，进群后再引导去公众号。

一句话总结：所有私信级别的沟通，搬到微信里再聊。
