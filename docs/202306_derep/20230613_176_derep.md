# 一个人闷头做项目，怎么把内耗和焦虑转化成动力？



## 独自作战时，别让焦虑拖垮你——试试这条路径

作者：木婉  
日期：2023-05-25

《自己独自做项目，如何消除内耗、焦虑》

各位好，我是木婉，龙哥盟第5期圈友。

加入赚钱以来，让我触动最深的是眼界被打开了，同时焦虑感也迅速攀升。

你可能觉得奇怪：焦虑怎么还能算是收获？我能从这种情绪里挖出什么有价值的东西？又如何让它推着我往前走，而不是把我按在原地？读完你就明白了。

这篇分享的核心线索就一句话：情绪 → 思维 → 行动。

亦任大佬说过，焦虑其实是件好事，它是那股能推着你向上攀爬的能量。

更何况，感到焦虑再平常不过了——他自己每天都在焦虑之中，他认识的资产过亿的大老板们同样如此。这个时代，要是你一点都不焦虑，反倒不对劲。

这跟罗振宇无关，也不是互联网故意在渲染恐慌。真相是：只要你对成长有期待，对赚钱有渴望，想要挣脱当下的局面，就必然会经历疼痛与挣扎。
