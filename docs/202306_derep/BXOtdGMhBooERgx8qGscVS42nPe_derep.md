# 用代码把闲鱼二手书玩成自动收钱机：我的程序员式躺赚实验

> 来源：[https://r2rmt6mopc.feishu.cn/docx/BXOtdGMhBooERgx8qGscVS42nPe](https://r2rmt6mopc.feishu.cn/docx/BXOtdGMhBooERgx8qGscVS42nPe)

大家好，我是华少，生财的潜水员，三年了。

![](img/00ea3f0f217acf429c0bcc2eab3ca952.png)

过去总在下面看大佬们拆解项目，偶然连上了二手书圈的一哥老瞿Qu。看着他一年靠闲鱼二手书做到百万营收，却被上架、客服、发货这些重复劳动拖得焦头烂额。于是我决定从技术侧切入，帮他把这个项目做成真正可躺的状态。

与此同时，我也在2022年12月第一批拿到了6张出版物经营许可证，撬开了18个闲鱼二手书号，开启了自己的月入两万的半自动化运营。

我会点JavaScript、Java、PHP、Python、C#、Swift、Kotlin、TypeScript、Rust等上百种语言环境的搭建，也能顺手打开VSCode、IntelliJ IDEA、PyCharm、WebStorm、Android Studio、Eclipse、Visual Studio等近百款工具。路上有人问路叫我爷爷，我其实才18出头。

……开个玩笑，言归正传。

一、相识篇：从校园二手书到闲鱼无货源

2022年6月，我手里之前的项目日收益从八九千跌到一千左右，开始焦虑。加入了不少星球瞎逛，最后发现生财一个星球就够用，每天躺床上刷一会。

2022年6月20号深夜，星球弹出老瞿Qu的《二手书拆解》，标题朴素但点开了。

我当时在做校园社区SaaS，小程序里学生能自发发布二手书、线上付、校内自提，平台却拿不到钱。一直想接第三方二手书接口赚差价。

![](img/06335d4cf9d2e4cee1ec9122ea5ff49c.png)

![](img/2eda6f9f9e3b976df06ef1ac71a57f95.png)

聊了几天，深入研究后发现图书品类太分散，教材版本更是五花八门，想做到一键低价覆盖所有需求不现实。学生最终还是要在多个平台凑书。而且重资产运营成本高。

![](img/6646f476110f58c8b448ca761bb7d18f.png)

转思路做闲鱼无货源二手书的原因很简单：

1、模式轻。自己建仓要管仓库、管理员、客服、收货发货，全流程重投入，很容易被压垮。
2、客单低，决策快。咨询基本都是固定的几句话：还在吗、成色如何、哪里发、多久到。客服压力相对可控。

当时闲鱼图书类目还没完全开放，只能等。我提前进了官方群蹲消息。

![](img/963b71e0342e4a89b75eea494885dccb.png)

年底闲鱼放开白名单内测，我第一时间拿到了入口。现在已完全开放，有出版物经营许可证就能申请。

二、相知篇：痛点都一样，程序员只能自己救自己

拿到资质后才发现，上架、回消息、发货、售后全是体力活。对一个每天加班到深夜的程序员来说，这套流程就是劝退。

操作几天后我直接顶不住了。于是又去找老瞿Qu取经。

他的原话是：这些痛点我全有。二手书能赚钱恰恰因为它繁琐，没资本大举进入，小玩家才有机会。我工作室的上架、客服、订单都外包流水线了，我基本不管。

大佬的凡尔赛我懂了。但如果痛点人人都有，那我这个程序员能整点什么？怎么做到躺赢？

说干就干，开启程序员打怪升级。

第一步：把上架从体力活变批量活

![](img/8ed5ee47389954e54bd51509b45be334.png)

![](img/31c2099c10ae7936ed17997d83da142a.png)

闲鱼二手书不像淘宝京东需要精修图，核心就是把孔夫子上的优质实拍图搬运过来，靠信息差赚差价，本质是搬运工。

这我忍不了。

我去翻了闲鱼官方合作的闲管家后台API文档。四五天时间，把孔夫子上热销书目全部抓取，累计60万本书、6000万张实拍图，再结合API开发了自动上架工具。

人工一小时20-30本，系统一小时100-200本。省下的时间全用来选品定价。

![](img/657cef59223601853258b4ded138f7bf.png)

第二步：把订单从一团乱麻变一键流转

闲鱼流量分配均匀，对新人友好，但单店很难爆。想吃到更多流量只能多账号矩阵。身边做得好的基本十几个号起步，多的上百个。

账号一多，订单就乱。退货在哪找不到在哪。于是我做了订单中控系统：一键把收货地址同步到孔夫子，一键代下单，自动拉取孔夫子快递单号自动发货。

同时接入微信服务号推送，有单就提醒。看着手机弹出“老板，开单了”，正反馈拉满。

![](img/cb70a8b2d041455dfa07ecc106008f8a.png)

![](img/ba9f60454dc06cce0d86d8311d472c1c.png)

第三步：把客服从头疼变聚合

![](img/6f2bec284eba3f3dd13a1a1373c26519.png)

![](img/afeb8d9fc8ab7644d65a7a6014efa205.png)

开了20个闲鱼号，难道带20个手机出门？

闲鱼原生客服工具不够专业，我花几天做了个聚合聊天APP。自动抓取闲鱼站内消息推送到微信，直接在微信里就能回复。还能自动签到、保持账号活跃。

三、相爱篇：从自己赚钱到卖铲子

几个月迭代后，重复性工作基本被系统接管，只剩下选品和定价。

本打算把账号扩到100个，支架都买好了。结果生财圈二手书航海爆发，小嵩、王老实、感遇等人都出了成绩，加上航海项目，上千家店铺涌入，价格战卷翻天。

那就换个打法，做老瞿Qu背后的男人。我算过，系统能帮他省两个人，一个年成本十万，我收一万系统费很合理。系统一上线，就拿到了老瞿Qu的万元订单。

一边卖书一边卖工具，更香。

最后复盘四点：

1、闲鱼二手书不是暴利项目，但副业友好。配合工具，90%操作在手机微信内完成，基本能做到自动捡钱。

2、工具只是放大器。想赚得比别人多，必须深耕。图书玩法很多：绝版书、海外代购、杂志等，多测试多研究才有结果。

3、放大才是关键。闲鱼流量靠平台分配，有运气成分。单个号很难保证，靠账号数量去打概率。10个、20个、50个，逐步放大。批量起号时，手机建议买闲鱼个人非工作室机器，工作室机多带异常。

4、坚持是流量密码。闲鱼很看账号活跃度，每天上新、签到、及时回复。照做就能出结果，半途而废的人很多。

最后的最后：

感谢生财有术，让我潜伏这么多年。程序员文笔一般，关于二手书的具体操作前人已讲过，这里不再赘述。

这次航海期间，系统对生财圈友免费开放，配置教程也会同步。前人栽树，后人乘凉，祝大家一起生财。
