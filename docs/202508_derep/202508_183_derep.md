# ('(精华帖)(149 赞)0 代码基础，我是如何 build in public，用 AI 提效和变现的？', (2, 54))

上周二，我的人生第一张网页（HTML）正式诞生，朋友圈点赞刷了一整屏。那一刻的成就感，说实话，比中奖还开心。

很多人不知道，我其实是“代码零基础”的选手。我是赚钱的内容负责人七天，也是跟着AI一起成长的“养成系练习生”。今年4月接手AI传术师俱乐部的运营时，我特别没底：一个技术和理论都空白的人，怎么好意思和AI大佬们同台对话？

但这段时间走下来，我最大的感悟是：AI不是工具，而是最好的老师。小排老师有句话我特别认同——不是遇到问题才想起来找AI，而是任何事情都该先问AI。

我的学习方式特别朴素：找师傅、抱大腿。办公室的知行、瓜斯，SCAI实验室的dhj、大潘，都是我的“免费外挂”。就算你身边没有这样的人，赚钱的线上社群也藏着不少高手。

完整版里，我详细写了这5个月是怎么一点一点从零开始的、怎么拆掉“我怕学不会”的心理障碍、以及怎么在学AI的同时顺手就把Build in Public给做了。这里先把最核心的五条洞察拎出来：

1. 真正的门槛是心魔，不是技术。每一次突破，都是在把自己的心理阈值往上顶。多数人学不会AI，不是因为难度高，而是死在了“我到底行不行”的自我怀疑里。技术方法能被复制，但信心只能靠自己种出来。

2. 学AI这条路，是“问”出来的。我没有先啃理论再动手，而是边问边做边掉坑。问技术群、问懂行的朋友、问AI自己，哪里不懂补哪里。最适合普通人的学习路径，不是“系统学一遍”，而是“带着问题上手”。

3. 不是学好了才动手，而是动手了才会。现在的我已经能独立用Claude Code写页面，也能用自然语言让AI帮我部署内容分发系统的底层逻辑。这靠的从来不是“准备好了再出发”，而是“先跳进去，边做边学”。

4. 榜样的力量，比技能本身更强大。龙哥、林悦己、大树，他们做到了，我才慢慢相信“我也能”。技能路径千千万，信念却往往只需要某个人帮你“看见可能”。

5. 从Build in Public到Earn in Public。我一边学一边分享，一边实操一边社群化，身份也从“学习者”变成了“内容创作者+构建者”。当我在社群、朋友圈、即刻上公开建造时，我也在逐步积累自己的影响力和商业引擎。Build in Public不是终点，而是新商业引擎的启动键。

写这些，不是为了证明我有多努力，而是想告诉每一个完全不懂技术的人：只要愿意去试，你也能用AI提效、把产品做出来、把人生的可能性打开。因为“出发了才准备好”永远比“准备好了再出发”更真实。

下一个从0到1的人，很可能就是你。你不需要一次性掌握所有AI技能，只需要迈出第一步。要不要现在试试？做一个自己的网页，或者生成一个AI小工具？

愿意试的话，评论区留个言吧。我不是什么专家，但“从什么都不懂到做出第一样东西”这条路，我是真实走过来的。
