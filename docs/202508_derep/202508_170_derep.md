# 别再纠结选哪个项目了，先动手试一遍再说

很多人在赚钱有术待了很久，却依然觉得自己是个“小白”——航海跟了好几期，志愿者也当过，风向标发过几条，但几乎不输出内容。五年下来，回头看好像什么都没沉淀下来，这种感受其实并不少见。

有一位圈友就带着类似的困惑来找龙哥。他说自己跑通过几个小项目，赚过几百、几千、小几万，但都没能长久。公众号吃到过流量红利，后来数据下滑就搁置了；小红书店铺因为太耗精力、又没上工具，加上账号违规，也停了。目前他正处在产假后半段，想着重新出发，看中了几个方向：一是YouTube短视频和长视频，之前跟航海做过，最高到过2万播放；二是小红书虚拟资料，看别人模式跑通也想试试；三是小红书母婴号，已经发过一些笔记，有几百粉丝；四是公众号垂直小号，毕竟公众号曾是他收入最高的项目。他想让龙哥从时间、收入、难度、前景几个维度帮他选一个最合适的。

龙哥的回答非常直白：与其纠结选哪个，不如都先简单跑一遍，看看自己更喜欢哪个，哪个做起来没那么痛苦。试试又没什么损失，顶多就是搭点时间。哪怕项目最后没做成，你对这个领域的理解、判断力、以及学到的新技能，都是将来能派上用场的东西。

他强调了一个很实在的观点：每个项目都有人赚钱，也都有人赚大钱，但赚钱从来不是轻轻松松的事。就算换作他本人去做，也一样要认真钻进细节，仔细琢磨，找到突破口，然后拼命执行。没有哪个项目是可以靠“随便搞搞”就能出结果的。

龙哥提到前几天有位创业经验丰富、做出过很好成绩的朋友和他说，自己正在做一个海外产品，这两个月快被熬死了，如今才勉强做到网站每天出一两单。连这样的大佬做新项目都是这种状态，何况我们普通人？

所以他对赚钱这件事的态度是：既不想把它说得太难，也不想把它说得太简单。用一句话概括大多数人的误区就是——

**我们往往低估了短期赚快钱的难度，却又高估了长期赚大钱的难度。**

与其花时间焦虑“我到底适合哪个”，不如花时间去试、去撞、去感受。做起来不痛苦的那个，很可能就是属于你的那条路。毕竟，正确的事，只要能坚持下去，早晚会给你回报。
