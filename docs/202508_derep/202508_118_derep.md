# 从日本到美国：内卷做细节，外卷做格局

提到产品开发，日本和美国像是两个方向相反的选手：一个把劲儿往内使，一个把劲儿往外使。

日本选手的功夫，全在“内卷”上。这种内卷，就是把细节死磕到极致。所谓细节，不是功能做完就收工，而是功能之外，还要让使用体验更舒服、更顺手、更贴心，把使用者的感受和具体场景都考虑进去。也正因为如此，日本的产品和服务，从整体质感来说，确实很难在全世界找到对手。

一个直观例证是医疗。日本癌症死亡率全球最低，靠的不仅仅是医疗技术，还有医院服务里那些细到极致的体贴。超市里，食品用透明包装让你看到实物，旁边再放一个切开的模型，让消费者知道里面长什么样。我替太太买丝袜，结账时店员还专门跟我确认尺码。这种服务细节，恕我孤陋寡闻，在世界上其他国家真没见过。欧洲、美国、东南亚的服务都很一般，欧美甚至不如中国。

这次去熊野古道徒步，我住了五家日本酒店，顺手做了个实验。我把门开到只剩一条缝就松手，理论上关门力道最小，但这五扇门都安安静静地锁上了。我在国内一年要住上百家酒店，最常见的烦恼就是门锁不严：要么把门开大点借助更大力度甩上，要么自己撞一下。上周在深圳机场附近的希尔顿，我做了同样的测试，只留一条缝的门根本锁不上。

再说其他细节。五家酒店里，四家空调出风口不对着床——国内很多酒店恰恰喜欢对着床吹。酱油调料瓶倒完，最后一滴会自动回流，不会弄脏桌面。高层酒店窗外设计了逃生通道，紧急情况下可以破窗转移。我看过一套日本高层住宅，所有房间阳台都能打开，向上或向下攀爬，同样是逃生设计。一位做灾备大米的朋友完全照抄日本设计，可始终不理解为什么易拉罐只装了八成。日本公司的回答是：遇上洪灾时，罐子能浮在水面上。连这种极端情况都提前想到了。

酒店里还专门为儿童设置了按钮，楼道扶手也分成人和儿童两个高度。

有人会觉得，这种“内卷”是不是太小家子气？日本企业恰恰习惯通过持续微创新来改善产品，结果就是出了很多“神”：经营之神、清洁之神、寿司之神。但代价是，战略和技术层面的颠覆性创新不足，竞争的天花板也容易封住。

美国企业当然也有微创新，但它们的核心打法完全不同。它们靠颠覆式创新、高端技术和战略规划立足，产品服务的细节反而常常被忽略。美国人擅长用新技术打开一个又一个全新市场，把劲往外使。这种“外卷”，或许正是日本模式所欠缺的。

反观国内，很多创业者的产品细节还欠打磨。有位做餐具的创业者送我几只小碗，单只摆着非常漂亮，可一旦想摞起来就特别费劲，因为设计时压根没考虑收纳。细节决定体验，这一点我们确实该向日本学习。

所以我的建议很直接：小企业创新资源有限，不妨先沉下心来打磨细节，做微创新；而那些科技和互联网大厂，我更希望它们去啃高科技的硬骨头，用技术去卷更大的市场和更广阔的空间，而不是盯着路边的菜篮子和小商贩抢生意。

Ps：日本人连吃螃蟹，都为食客想好了怎么优雅方便地下口。这种细节控，实在让人服气。
