# ('(精华帖)(169 赞)2 个月内实现 Youtube1.5 亿播放量，赚回“2 倍”门票', (2, 47))

你见过一个06年出生的法学生，用五个月时间完成“普通到瞩目”的蜕变吗？  
前几天刷到一篇精华帖，被一个叫逸尘的少年狠狠惊艳到了。  

他在帖子里说，五个月前还只是法学专业的普通学生，刷着生财有术里的各种分享，越看越焦虑——别人怎么都那么强？  
可短短两个多月，他亲手做的YouTube内容矩阵就砍下了1.5亿播放量，不仅把门票钱赚了回来，还直接翻了倍。  

但真正让我意外的是他的态度：他坦言，生财带给他的价值，根本不是“两倍门票”能量化的。哪怕用“万倍价值”来形容，都不足以表达他的感激。  
带着这份感慨，他去了杭州生财总部，和七天姐深聊一番后，忍不住把自己五个月以来的经历与思考整理成了一份复盘，发出来和大家交流。  

亦仁老大在他的帖子下直接留言：可能要晋升为最年轻的传术师了。  
评论区里也满是佩服，有人说等他回重庆约饭，还有一位妈妈感叹：自己闺女也06年，都大三了，怎么还在天天刷手机？  

看下来最大的感受就是：人和人之间的差距，往往不是起点，而是你愿不愿意跳进一个高能的圈子里，把焦虑变成行动。  
这位少年，大概就是用五个月时间，把“别人家的孩子”变成了“自己”吧。
