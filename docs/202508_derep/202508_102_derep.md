# 新手也能玩转垂类小号？一个人的公众号从零到过万阅读，还接到商务合作，我把后台全摊开了



很多人看我现在发出来的数据会觉得不可思议，其实我就是一个典型的入门玩家。

我是达师姐，公众号这条路我是纯自己摸索的，没有团队、没有工作室，就我一个人守着一个号。从开号到现在一共发了 66 篇，全是自己在弄。结果居然已经有十几篇破万了，最夸张的一篇流量主收入直接到 300 元，更意外的事是，还真的有品牌找到我谈 PR 合作。

这篇我把后台的真实截图和过程全都放出来了，说实话我已经试过四次，想把这些东西分享出来，前三次都被平台吞了，这已经是第五次发了。希望这次能沉下来，让和我一样的小白看到，普通人真的可以做起来。

我的打法很简单，就是把公众号当成一个只属于自己的小圈子朋友圈去运营。定位垂直、坚持更新，别给自己太大压力，执行力自然就上来了。后续我也会把涨粉、过审、变现的细节梳理清楚，方便大家对照着做。
