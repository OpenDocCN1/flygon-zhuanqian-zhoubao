# 帮儿子所在幼儿园做小红书招生后，我看懂了操盘手赚“安稳钱”的正确打开方式和常见误区

> 来源：[https://ncn18orsgwl2.feishu.cn/docx/Yoradi6G4oDvgQxWChXcnrAinFd](https://ncn18orsgwl2.feishu.cn/docx/Yoradi6G4oDvgQxWChXcnrAinFd)

大家好，我是珍妮。履历上是留学转房产，后来被行业里的前辈一路带飞，接触过美业、教育等多个赛道。有的盘子我变成了自营，有的盘子我继续以代运营的方式在做，借着代运营也在不断孵化操盘手。

就因为这段经历，再加上这次我主动为儿子所在的幼儿园在小红书做招生，我才真正吃透了：操盘手想拿“安稳钱”，到底该怎么做、又最容易怎么错。

今天就用这一次幼儿园招生的实战，来拆解四个问题：

1）绝大多数操盘手现在到底在赚什么钱？
2）我为什么要亲自给幼儿园做线上拓客？
3）我当时做了哪些准备，效果怎么样？
4）想赚安稳钱，操盘手应该从哪个环节开始发力？

# 90%的操盘手，正在赚怎样的钱

很大比例的操盘手，逻辑很简单：哪个赛道哪个项目给的佣金高，就冲进去做获客。

可一旦项目方给的高提成，往往意味着几种可能：

A）转化很差。操盘手送过去的线索，项目方拿去测转化率，还要靠操盘手去优化话术。
B）获客还在从0到1。老板想用一个大饼把人拉来跑冷启动。
C）交付一塌糊涂。后端搭建不完整，问题不断。
D）转化还行、交付也靠谱、佣金还高。听起来很美，但老板做大后一定会想办法把操盘手替换掉。而操盘手既没有掌握上游供应链，也不懂转化环节，自然处境被动。
E）前期佣金能结，后面老板卷款跑路。
F）赛道本身就在平台红线上，刚一引流账号就被封。
G）交付普通，产品没有明显壁垒。

这种情况下，操盘手不敢真人出镜背书，只能做没IP、不能露脸的矩阵号。

平台越卷，矩阵号成本越高。大家都在写【伪素人第三方种草】、写【去IP化的营销稿】，读者越来越分不清谁可信，平台自然会压制。这类内容既不讨好用户，也不被平台推荐。

运营成本水涨船高，分到的佣金却覆盖不了成本。操盘手一旦没有掌握供应链，就很难在这个赛道长期立足，也就赚不到“睡得着觉的钱”，随时可能断粮。

那么，怎么才能开始赚安稳钱？我会在后面用幼儿园招生这件事来说明。

# 我为什么要帮幼儿园做线上招生

今年6月，幼儿园开了线上家长会。园方的意思是：深圳幼儿园倒闭潮严重，我们园也面临招生压力，下学期要降学费，还要加外教课。

腾讯会议里看不到老师的脸，但声音里的焦虑和无力感很明显：担心倒闭、担心关园裁员。

我儿子在的是深圳南山的普惠私立园，学费在当地算非常友好。园龄31年，挺过疫情和各种周期，肯定有自己的底气。

我线下见过园长和老师，第一次见面我就决定不再去看其他园。原因有两点：直觉，以及我用了三年、总共学了五年的石剪布模型。

这个模型能让我通过一个人的神态、语气、常用表情包、工作和婚姻的分享习惯，大致判断出他的特质、适合什么岗位、靠什么赚钱、能赚什么不能赚什么，以及合作时要注意什么。我们公司招人用人也一直用这套方法，很准。

那天见完园长老师，我就知道找对了。园子倒了，我2岁多的儿子就要换园，对孩子发展不利。下一家也不一定让我放心。真心认可这个园子，就想尽一份力，帮它渡过招生难关。

# 我做了哪些准备，招生效果如何

这次拓客我拆成了以下几步：

1）调研幼儿园赛道
2）主动找园长谈合作和佣金。未果。
3）不等回复，自拍短视频先发
4）获得信任，拿到招生素材
5）整理爆点给助理写稿
6）正反馈后找操盘手放大，我负责指导
7）写一篇公众号长文，植入教育观点+园名
8）招生后的意外收获

小红书上花不到3分钟看深圳幼儿园的笔记，就判断这个赛道有空间。

去年在广州航海家大会做夜话嘉宾时，我发过一份纸质资料：【如何判断小红书各赛道的引流卷王程度】。现场很多人边看边问，所以录音里听不到这部分分析。

## 7）写一篇公众号软文，植入我的教育观念以及这家幼儿园的名字。

光靠短视频和小红书不够。短视频承载不了长观点，小红书铺太多软文容易被当炒作。

我观察深圳家长习惯在微信搜一搜查幼儿园。搜一搜能搜到视频号和公众号，公众号长文更适合建立信任。

# 操盘手想赚安稳钱，应该从哪一步开始

从2020年开始试水创业，21年12月真正起步，22年放大。做留学自营盘和代运营、做房产、做代运营，我总结出：当我觉得自己在赚安稳钱时，项目通常具备以下特征，至少满足3条：

1）供应链在我手里，我了解交付，能自己优化产品竞争力。
2）哪怕我不擅长销售，我也懂转化全流程。
3）在打造个人IP和影响力，而不是匿名投喂客资。
4）项目本身对社会有价值，不只是两端赚钱。

反之，如果出现以下情况，就很难安稳：

1）供应链在别人手里，我只能教运营从小红书拉客。
2）签单多少别人告诉我，佣金每月结算，我看不到过程。
3）对供应链没兴趣，纯为了赚钱。
4）不花时间做影响力，沉在一线干活，被PUA“你不可替代”。
5）项目没有社会价值，甚至误导客户。

另外很多操盘手也在自毁安稳：

1）不学运营，只玩AI矩阵，稿子质量差，100个号不如别人2个精耕号。
2）会获客但不碰转化，被下游拿捏。
3）会获客又会剪辑，却没有靠谱供应链，最后只能卖陪跑私教。

我的这些体悟来自：

1）【做留学自营盘和代运营盘】的经历

做留学自营盘时我改良了供应链。2020年当雅思老师时发现写作批改是瓶颈。我搭建第三世界国家外教批改供应链，成本低，学生提分快，我白天上课晚上外包，口碑爆发。后来又做润色翻译业务，因为懂学生需求，产品一出就卖爆。即便小红书严打、AI来袭，2025年仍有转介绍。

代运营则不同，供应链不在我手里。甲方一个月烧40万投放，我一个小创业者不可能烧50万去对赌。资本在后面，我扛不住。

2）【为了让新人快速学会运营，一周六更打法】的经历

24年我一周六更运营打法，从24年3月1号更到25年3月31号，之后改为一周三更。因为要腾出时间做自营盘。

当时我发现运营人员会离职，矩阵号每三个月要迭代，自己信息茧房严重，买课也解决不了问题。于是把方法论沉淀下来，既服务内部团队，也对外输出。这个动作意外带来了大量市场正反馈，也让我明白：能持续输出价值，影响力自然会带来安稳。

我以前从未想象过，单纯靠不停迭代运营方法，就能真正变现。

结果就是因为坚持更新方法论，我才被市场看见。大家惊讶于我如何做到一周六更运营打法且丝毫不注水，IP就在2024年突然爆发了。

第一次参加广州航海家大会的线下聚会，大批人上来找我合照，那种场面把我直接整懵了。

IP起来之后，我才第一次有了底气。

在那之前，我长期被自我怀疑困着：

是不是我的运营真的不行？团队业绩下滑，是我拉低了水平，还是产品问题、平台问题？
有没有人会觉得我没什么不可替代，只是在一线做培训，所以我连提成该不该要都不敢开口？

现在这些纠结都解开了。

有人说我算账不行，我点头，因为我确实不行，心里毫无波澜。
以前有人说我运营不行，我会反驳也会怀疑自己。如今我平静了，因为我清楚自己在这方面很能打。
以前有人说我没不可替代性，我会辩解。如今别人再这么说，我直接换人。

2025年的我，已经懒得像从前那样内耗了。市场每天都在给我回正反馈，太忙太有劲。

3）【转型后做自营盘时，把销转抓在自己手里】的经历

2025年转做自营盘，我们内部做了很大调整。以前代运营的模式是客户加我微信后拉群给合作方，或者直接让客户去加合作方。

现在不一样了，所有客资直接进我自己或自家助理的微信。销转由我们自己来，收款后再把交付环节交给交付方。挑选交付方时，我只挑供应链可控的，交付不实在就直接不合作。

做代运营时，对方分我25-30%已算不错。如今拿到流量和成交权，成为甲方后翻身，我发现市场上大量交付质量过硬却不懂流量和成交的服务商，他们有人主动提出分我60-70%，甚至在自身已有IP的情况下，依然愿意分20-30%。这完全颠覆了我之前的认知。

当然，我们不会因为对方开出70%就真拿70%，交付靠不靠谱才是前提，先筛交付质量，再谈分成比例。

4）【帮我儿子的幼儿园招生】的经历

操盘手真正该出手的项目，是在不考虑佣金的前提下，你也愿意真心推荐、用真名站台的项目。项目够靠谱，你才敢赌上自己的名誉。

只有你敢露脸、不要钱也愿意为之背书的项目，才是你内心真正认定的项目。这种利人利己的选择，会带来市场的正反馈。

帮幼儿园招生的经历，让我更坚定了一个认知：

操盘手能稳赚不亏的基础，前提是找到优质供应链，并且自己愿意为之露脸站台。

# 总结：

把这些经历串起来，我发现能让操盘手长期稳定赚钱的，本质就回到了三件事：IP、供应链、销转。

1）打造属于自己的个人IP。
2）筛选靠谱的优质供应链，并且自己有能力去优化它。
3）把销售转化牢牢掌握在自己手里。

除此之外，什么没IP的泛矩阵号、靠AI洗稿起号、沉迷剪辑拍摄技巧、一辈子埋头在一线干活却不做影响力输出，都很难实现长久变现。

所以，在持续迭代获客能力的同时，我接下来会把时间花在广东线下实地筛供应链上，而不是只做一个在线上获客的人。我们团队已有擅长运营获客、擅长销售成交、擅长团队管理的人，现在唯一缺的就是优质靠谱的供应链。
