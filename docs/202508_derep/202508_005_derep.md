# 赚钱圈友的成长图谱：你现在修炼到第几层？

在赚钱这个圈子里，没有谁是一步登天的。每个圈友都是从零起步，在时间的积累中，一步步完成属于自己的跃迁。有人还处在最初的摸索期，像刚进游戏的新手玩家，在“新手村”里熟悉规则、积累经验；有人已经进入下一关，在“熟手村”里打磨技艺，但偶尔也会被瓶颈卡住，感叹难以再进一步；当然，也有人大方承认，自己还在“菜鸟期”，正在向各路前辈学习。

前些日子，龙哥在圈内抛出一个简单却耐人寻味的问题：此刻的你，走到了哪一步？这个提问像一面镜子，让不少圈友开始认真审视自己。评论区里，有人直言自己被困在熟手村，有人打趣说还在新手村打转，也有人恭恭敬敬地表示自己是新手小白，向大佬们致敬。可见，无论走到哪一步，敢于直面现状，本身就是一种成长。

那么，正在读这段文字的你，又修炼到了哪一层呢？是在新手村蓄力，还是在熟手村寻求突破，亦或已经找到了自己的节奏？不妨停下来想一想，或许答案就在你心里。![](img/d33d5ef22ae89b495eb224c7c8beda4d.png "None")
