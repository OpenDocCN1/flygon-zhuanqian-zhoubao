# (86 赞)龙哥回答：生完孩子重回职场，主业副业怎么选？

**产后复工，工资砍半，副业缩水，手握100万存款的她该怎么选？龙哥的答案很清醒**

最近看到一个很有代表性的提问。一位妈妈产后重新回到职场，半年过去，发现自己逐渐被“架空”：岗位换了，工资从五千六掉到三千。副业这边，也不乐观，孕前每月能赚两万三，现在缩水成一万二。更让她难受的是，原来主业和副业的精力分配是二八开，现在完全倒挂——八成精力被工作吸走，却换不来一点正反馈。

她说，这份工作让她特别内耗。领导不待见，资源不给，培养更谈不上，每天上班都靠一口仙气吊着。可要直接辞职，她又不敢，毕竟家里有1岁的娃，房贷几十万，心里没底。

不过她也清楚，这份工作并非全无价值：六险两金齐全，公司又是行业里的龙头，只是眼下跳槽未必有更好的机会，想等到整个行业起飞后再动，还得再熬一熬。副业这边，她做探店、达人团长商单撮合、达人培训、小红书探店直发等等，其他项目还在运转，唯独出门探店因为体力和孩子原因，频率大大降低。

在她犹豫不定的时候，龙哥的回复非常干脆：月薪只有三千，还留着它干什么？你存款加公积金已经是七位数的量级了，辞掉工作专心搞副业，哪怕最后赚不到更多，至少心情痛快，时间自由，还能多陪陪孩子。说到“不上班会恐慌”，龙哥更是一针见血：你恐慌什么？恐慌自己没有了一份收入又低又耗人的工作，然后开心得睡不着觉？

评论区也炸出了不少视角。有人说，这题最大的bug就是：为什么还要纠结留不留主业？也有人猜测，公司是不是不想给裁员赔偿金，故意安排个边缘岗位耗着你，逼你自己提离职。毕竟职场上的“软裁员”太常见了。还有网友精打细算地建议：别光拍脑袋做决定，把未来十年的家庭现金流好好盘一遍，房贷、保险、配偶收入、孩子不同阶段的支出全放进去，再分别按“上班”和“不上班”两种版本算一算，看看数字到底站在哪边。

更有人替她点破了藏在心里的担忧：怕的不是丢掉这份三千块的工作，怕的是从此再也找不到工作；怕副业哪天不稳定，收入说断就断；更怕年纪大了、已婚已育、离开职场太久，以后想回头都摸不着门。然而，评论区里压倒性的声音其实是：既然副业已经能带来现金流，为什么不全力以赴去把它做大？有网友说得更直白：工作嘛，也就那么回事，踏踏实实把副业搞起来才是正事，赚钱的路子多得很。

说到底，这个案例最扎心的并不是“主业还是副业”的选择题，而是很多人明明手里有牌，却被一份低薪又不断消耗自己的工作困在原地。真正的安全感，从来不是“我有一份工作”，而是“我随时有能力赚到钱”。

如果你也站在类似的岔路口，不妨先问问自己：这份工作，是在给你积累能量，还是在偷走你的能量？答案清楚了，选择自然也就清楚了。
