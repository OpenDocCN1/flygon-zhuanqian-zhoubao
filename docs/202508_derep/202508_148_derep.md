# ('(精华帖)(110 赞)《跨境新手看利润，投资人却看这几个关键指标》', (2, 36))

很多人做跨境，最关心的问题是“这单赚了多少？”但你有没有想过，有些钱进了口袋，反而是麻烦的开始。

十多年前，我在北大总裁班听过一个词，叫“吉财”和“凶财”。当时觉得玄乎，现在回头看，才明白其中的道理——有些利润，看着漂亮，却会把你的现金流一点点吸干；有些爆款，表面风光，却能活活拖垮整个业务。

注意，这不是危言耸听。

先说一个惊人数据：据说98%的纯TikTok卖家是亏损的。不是他们不努力，而是压根不会算账。把人工、水电、推广费一项项剔除后，账面上订单多到爆，最后一算，还是亏的。

再说亚马逊。很多卖家倒是会算账了，利润也显示为正，但公司照样因为“没钱”而倒下。为什么？因为亚马逊的生意不是简单的“营收-成本=利润”，中间还夹着一个要命的东西——时间。海运动不动一个多月，账期一拉长，错算的概率就飙升。本质上，这是现金流和库存周转的问题。

为什么利润很高，公司却倒闭了？
年赚100万，前期到底要砸多少钱？
什么样的营收是“好营收”，什么样的营收是“毒营收”？
以及，AI能不能帮我们解决这个问题？

这些我都整理在下面的链接里了。

我做投资的时候接触过不少财务知识，所以一开始就避开了这个坑。但我观察，90%的亚马逊个体卖家，从来没认真想过“现金流”这件事。

做跨境的人都说赚美金很爽，但链条太长，坑太深。货发出去，钱收不回来；爆款来了，赶紧补货，等货到了，热度也过了，剩下的全是积压品，还得继续交仓储费。更别提退货、投流、售后这些隐形成本。

别只盯着利润表。利润是面子，现金流是里子。里子没了，面子撑不了多久。
