# ('(41 赞)如何做一款成功的产品？', (2, 19))

在今天的商业环境下，人人都想做出一款爆品，但真正能跑出来的产品少之又少。那些能被市场记住的产品，到底做对了什么？如果你正在打磨自己的产品，不妨对照下面几个维度重新审视一遍。

第一，别只顾着钻研技术，方向比技术更重要。手里有再牛的技术，如果脱离了真实市场，也只是一堆自嗨的代码和专利。真正的起点，应该是市场的真实反馈，而不是实验室里的完美方案。

第二，学会从社交媒体上的热门话题里挖机会。大家讨论得越热烈，往往越藏着尚未被满足的隐性需求。热度不只是流量，更是需求的晴雨表，关键是你能不能从喧嚣中识别出那些还没被人做透的切入点。

第三，从自己熟悉的生活场景出发，看看新技术能不能解决那些一直让人头疼的小麻烦。但别急着动手做产品，先做一轮扎实的市场调研，确认需求真实存在、足够痛，再投入开发也不迟。需求没验证清楚之前，做得多快都是浪费。

第四，产品定位要足够尖锐，宁可聚焦一个小群体的一个明确痛点，也不要试图讨好所有人。如果你的产品没法用一句话讲清楚它是给谁、解决什么问题的，那它大概率还是一款不合格的产品。

最后，如果以上几点都没问题，还能做出一部分用户愿意持续使用、甚至离不开你的产品，那恭喜你，这已经是一款相当出色的产品了。成功没有捷径，但方向的正确、需求的真实、定位的专注和用户粘性，才是真正的护城河。
