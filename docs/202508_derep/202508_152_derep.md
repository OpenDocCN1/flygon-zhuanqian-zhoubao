# ('(173 赞)亦仁回答：改变就在一念之间。', (2, 23))

最近有人问亦仁：这两个多月你怎么突然在星球活跃起来了？除了发“超级标”，还不停往外倒干货，连公众号都重新开始更新了。大家都觉得你状态变了，到底咋回事？

亦仁的回答特别有意思，他说：转变的开关，往往只藏在一个念头里。既然是念头，那就别搞什么漫长的准备，想改，当下就能改。

他说自己做的事，其实是把脑子里那些“道理”给清理了一遍。比如“赚钱太难”“写作太难”——这些听起来很成熟的判断，真的是你自己想出来的吗？大概率不是。它们只是不知什么时候被塞进来的旧程序。既然能装，就能卸。卸掉以后，直接给自己装一段新代码：“赚钱嘛，分分钟的事。”“写作嘛，跟发朋友圈一个样。”甚至简单到像“我很帅”这种毫无逻辑的肯定——只要你肯信，事情就会顺着这个念头慢慢长出来。

很多人卡住，不是因为能力不够，而是对“改变”这件事想得太重了。但亦仁说，一旦你启动那个状态，后面的运转就会自动跟上。连内向外向这种看起来是天生的东西，都能在一念之间切换，还有什么是不能改的？

他还戳破了一个大多数人都没意识到的事实：我们从小到大的信念，99%都是被环境悄悄装进脑子的，根本算不上自己深思熟虑的选择。既然不是自己选的，那就不必死守。一切皆可为，一切皆可改。

那为什么我们总觉得启动很难？亦仁给出了一个很扎心的解释：长时间不写、不动、不表达，人的“自我”会被喂得越来越大，于是启动成本也跟着水涨船高。你会下意识觉得全世界都在看你，等你翻车。但实际上，根本没那么多人盯着你。那些想象中的目光，全是自己加戏。你就算发一篇文章满屏错别字，也没几个人会注意，更没人会专门跑来找茬。

所以你看，改变这件事，真没有想象中那么复杂。评论区已经有人开始行动了：先立个小目标，硬着头皮日更两周，结果越写越有料。也有人因为做了一件喜欢的事，表达欲猛增，每天凌晨四点就爬起来折腾。

转个念头，卸掉旧程序，然后迈出第一步。剩下的事，会让你的手自己动起来。
