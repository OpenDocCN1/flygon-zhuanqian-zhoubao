# 从零开始做AI代写34天，净赚4900块，有些真心话不吐不快

很多人一提到AI代写，第一反应就是：门槛低、上手快、随时能做，特别适合想搞副业的新手。这话没毛病，我也是这么入局的。

先简单交代下背景：我本职做了15年程序员，副业这块实打实是个新人。今年5月才开始琢磨副业方向，6月正式踩进AI代写这个赛道。没想到一周后就开了第一单，第一个月干了三周，纯利润3000块；第二个月刚跑4天，又进账1900。加起来34天，到手4900。

数字看着还行，但我想说的不是晒收益，而是这34天里踩过的坑、悟出的理儿，希望能给和我一样的普通上班族一点参考。

网上关于AI代写的说法，基本都绕不开那几句：没啥门槛、回馈来得快、时间自己说了算、新手拿来练手很合适。我自己跑了一遍，这些点确实都属实。但请注意，重点永远在“但是”后面——光看这些表面描述，跟实际干起来完全是两码事。

真正进到实操环节，你会发现这事儿远没有想象中那么岁月静好。那些“每天两小时”“轻轻松松月入过万”的爽文剧情，听听就好，别太当真。能真正赚到钱的活儿，背后都有看不见的辛苦。就像晓文老师那句话：所有项目都是背影杀手，一点不夸张。
