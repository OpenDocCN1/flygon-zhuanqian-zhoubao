# 03年非名校学长：在赚钱的这三年，我交出了一份怎样的答卷？

> 原文链接：……

大家好呀，我是辛亥。出身平凡，2003年出生，目前一个非名校大三学生。这几年我和合伙人小川一起扎在AI绘画和小说推文的方向上，矩阵号的粉丝量一点点攒起来，已经迈过了一个还不错的门槛。

不过，要论这三年最让我有成就感的，可能是我们跑得最好的那个账号，被收录进了赚钱小说推文的航海手册，成了大家研究的对标案例。这大概是对一个普通大学生最大的肯定了。

在星球里，我一直属于“默默关注型”。原因很简单——这里的牛人密度太高了。同为00后，很多同龄人的履历亮眼得让我不敢吱声。所以平时我很少发言，更多是在看、在学。不过，赚钱航海这条线我倒是没落下过，领队、志愿者都比较熟了，估计不少人都能看我这张脸眼熟，哈哈。

这次写下这些文字，是因为鱼丸找我约稿，想让我聊聊这一年在赚钱的收获和成长，讲讲组局背后的故事。我转头一想，自己来这儿的这几年好像还真没认真做过一次复盘，索性就借这个机会，把想说的都写下来，希望也能给屏幕前的你一点点启发。

详细的复盘内容篇幅比较长，我就先放在飞书文档里了，点击下方链接即可阅读。如果阅读过程中遇到啥问题，欢迎在评论区留言告诉我～

最后想谢谢评论区每一位给我鼓励的朋友。有人把我当作“遇见的第一个领队”，有人说我让他重新理解了志愿者这个角色；也有朋友不吝啬地夸我“优秀的00后”。说实话，看到这些声音，心里挺暖的，也更有动力往前走了。

我是辛亥，一个普通的03年大学生，如果你有什么想跟我聊的，欢迎在评论区找我呀～我们一起在赚钱这条路上，越走越远。
