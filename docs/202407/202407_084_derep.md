# 新手小白入局视频号，3 天卖了 13w，我做对了什么？
作者：龙哥

一个视频号新手，3天卖出13万，到底做对了什么？

大家好，我是龙哥，一个90后爱折腾的姑娘。在接触视频号之前，我完全是个带货小白，如今几个账号加起来总GMV已经超过20万。很多人好奇“3天卖了13万”是怎么做到的，这确实是我经历过的战绩，但爆单只是偶尔的高光，更多时候靠的是一条条视频堆出来的。

我现在的方向是美食混剪带货。就在最近一期航海活动里，我发了100多条作品，变现大概一万块，两个新号也只用了一周时间就攒到千粉。目前粉丝最多的老号有6万多，不过5月集中变现后，因为同质化和非原创问题被盯上，流量被卡到两三千，每天只能出点小单。

后来我决定走原创实拍路线。可我是个连饭都做不好的厨房小白，又总幻想拍出色香味俱全的画面，于是各种脚本和拍摄方法都试遍了，反而把账号搞得乱七八糟。没办法，只能开个新号重新开始，现在还在涨粉阶段，准备满1000粉后再带货。

回头看，我是4月初才入局视频号，所有认知全靠自己踩坑换来。如果当初能早点进到赚钱这种有经验分享的圈子，很多弯路根本不用走。现在多个号总GMV有20多万，要是早点懂平台规则，翻一倍都可能。
