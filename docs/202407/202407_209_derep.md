# 别再死磕目标了，先把系统搭起来

我们总习惯先给自己画一个终点：一年内体重降十公斤、三个月做出第一个产品、年底做到年薪百万。

听起来很振奋，问题是目标只是结果快照，它既不能告诉你明天做什么，也无法在你泄气时拉你一把。

真正能把你推向终点的是日常可重复、可执行的机制。

当系统跑通了，成果会自己发生。目标是悬在空中的愿望，系统才是地面上的路。有人用同样的时间，最后差距巨大，区别往往不在于谁的目标更大，而在于谁的系统更稳定、更经得起偷懒和拖延的考验。

与其反复升级你的目标清单，不如去迭代一个能每天自动运转的小闭环。先把“怎么做”做对，成功也就成了顺理成章的副产品。
