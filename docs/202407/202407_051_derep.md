# 一人公司，年入破亿，靠的不是忙，是玩明白了一套打法
作者：龙哥

你很难相信，真的存在这样一家公司：

工商登记上只有一位法人，一位股东，一位员工。没有办公室，没有流水线，没有下班群消息轰炸。就是一个人，坐在电脑前，轻轻松松躺赚一个亿。

听起来像段子？但这件事确确实实发生了。

在他这套体系里，流量是别人的，人是现成的，钱是自动到账的。他不需要招聘，不需要管理团队，不需要熬夜加班。做的事情只有一个：把已有的资源、已有的规则、已有的需求，串成一条闭环。

产品不自己产，销售不自己跑，交付全外包。他只做一件事，卡住最值钱的那一个环节，然后把整条生意链的利润都吸到自己手里。

别人的公司在拼人力，他在拼杠杆。别人的公司在拼内卷，他在玩的就是一套。

有人问他秘诀是什么。他说：别去做困难的，去做确定的。只要这套跑通了，一个人就能顶一千个人。
