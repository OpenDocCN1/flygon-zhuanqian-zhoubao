新手想用 Milvus 搭一个 RAG？我把操作拆成 9 步

最近我在跟着明白老师的基础写作课做练习，朋友正好想了解向量数据库 Milvus。于是我想，何不把这两件事合在一起？既能巩固课程，又能帮朋友解决困惑。带着这个想法，我用 Milvus 完整实现了一版 RAG，下面就是全过程。

先聊 RAG 是什么。它并非一个神秘的黑盒子，而是“检索系统 + 生成模型”的组合。文档会预先存入 Milvus 向量数据库，系统收到提示后，先用 Milvus 做向量相似度搜索，捞出最相关的几篇；再把这些文档和原始问题一起交给生成模型，让模型基于它们写答案。这样一来，回答不只是依赖预训练知识，还能紧扣最新、最相关的信息。Milvus 在高维向量检索上的优势也正体现于此：面对大规模数据，它仍能快速、准确地找到相关内容，从而提升生成结果的质量和相关性。

第 5 步，动手写一个 emb_text 函数。它的职责很简单：接收一段文本，输出一串能代表语义的数值向量。之后不管是语义搜索、文本分类还是聚类，都能拿这串向量干活。模型选用 text-embedding-3-small，属于效率和效果都比较稳的选择。
```
def emb_text(text):

return (

    openai_client.embeddings.create(input=text, model="text-embedding-3-small")

    .data[0]

    .embedding
)
```

第 6 步，创建 Collection。为了避免旧数据残留，如果同名集合已经存在，就提前丢弃。神奇的是，即使你不指定任何 schema，Milvus 也会自动建好三个东西：主键 id 字段、向量字段、一个预留 JSON 字段。这等于说，不用从零定义字段也能马上开工；而那个 JSON 字段还很灵活，可以容纳一些没有被 schema 定义的额外数据。
```

collection_name = "my_rag_collection"

if milvus_client.has_collection(collection_name):

milvus_client.drop_collection(collection_name)milvus_client.create_collection(

    collection_name=collection_name,

    dimension=embedding_dim,

    metric_type="IP",  # Inner product distance

    consistency_level="Strong",  # Strong consistency level

)
```

第 7 步，遍历文本行，逐行生成向量并插入 Milvus。这里有个小心思：text 字段并没有出现在 schema 定义里，但因为动态字段特性，Milvus 会自动把它塞进保留的 JSON 字段。从使用角度讲，它就跟预定义字段一样可以直接访问。动态模式的好处就在这里：不需要修改 schema，也能灵活扩展字段。
```
from tqdm import tqdmdata = []

for i, line in enumerate(tqdm(text_lines, desc="Creating embeddings")):

    data.append({"id": i, "vector": emb_text(line), "text": line})

milvus_client.insert(collection_name=collection_name, data=data)
```

第 8 步，在集合里搜索问题，找出语义上最接近的前 3 个结果。调用 milvus_client.search 方法，将问题通过 emb_text 变成向量，limit=3 控制返回数量，相似度度量采用内积（Inner Product，IP），并通过 output_fields=["text"] 让结果带上 text 字段。整套逻辑靠的是向量相似度，而不是关键词匹配，所以能捞到语义相关的内容。
```
question = "为什么要写作"search_res = milvus_client.search(

collection_name=collection_name,

data=[

    emb_text(question)

],  # Use the `emb_text` function to convert the question to an embedding vector

limit=3,  # Return top 3 results

search_params={"metric_type": "IP", "params": {}},  # Inner product distance

output_fields=["text"],  # Return the text field)

retrieved_lines_with_distances = [

    (res["entity"]["text"], res["distance"]) for res in search_res[0]

]

print(json.dumps(retrieved_lines_with_distances, indent=4))
```

第 9 步，构造让大模型理解任务的用户提示。提示词里设计了 {context} 和 {question} 两个占位符，前者由 Milvus 检索到的文档替换，后者则填用户真实提问。同时，提示语会定义模型的身份——“你是能回答问题的 AI 助手”——并引导它优先依据给定上下文来作答，而不是依赖记忆里的旧知识。这就是 RAG 能够提升回答质量的关键。
```
context = "\n".join(    [line_with_distance[0] for line_with_distance in retrieved_lines_with_distances]

)

SYSTEM_PROMPT = """
Human: You are an AI assistant. You are able to find answers to the questions from the contextual passage snippets provided.
"""

USER_PROMPT = f"""
Use the following pieces of information enclosed in <context> tags to provide an answer to the question enclosed in <question> tags.
<context>
{context}
</context>
<question>
{question}
</question>
"""

response = openai_client.chat.completions.create(

model="gpt-3.5-turbo",

messages=[

    {"role": "system", "content": SYSTEM_PROMPT},

    {"role": "user", "content": USER_PROMPT},

],)

print(response.choices[0].message.content)
```
