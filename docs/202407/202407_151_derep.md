# 反思我自己的路径依赖

最近听了一门进化论课程，里面讲到的一个概念让我反复回味了好几天——“路径依赖”。

举个很直观的例子：最早从海洋爬上陆地的生物里，最成功的那一支演化成了四足动物。后来，这支动物又分化出了鸟类，甚至还有一部分重新回到了海洋，比如鲸鱼和海豹。但问题就在这里：这些“回头下海”的家伙，其实已经被它们祖先的身体结构牢牢锁死了。

你可能会想，鲸鱼要是能长成鱼类的样子，那才是最理想的水下形态吧？但事实是，它不可能做到。因为它的祖先是四足动物，已经拥有了四肢骨骼，所以哪怕海洋生活再需要流线型的鱼身，它也只好带着这套“老底子”去适应环境。相比之下，海洋里数量最多的辐鳍鱼类，从来没上过岸，自然没有手掌结构，人家反而天生就是最佳配置。

再看陆地上飞的：昆虫为什么那么多？因为它们有膜翅，没有骨骼，轻便灵活。而鸟类的翅膀、人类的手、马的蹄子、鲸的鳍，说到底都是同一种原始结构演化出来的，基本框架相似，功能却天差地别。它们不是不想变成“更完美”的样子，而是路径依赖不让。

听这门课的时候，我脑子里突然闪过了昨天开会的场景。当时我做了个决定：让新媒体同事把重心全面转向短视频，👸号内容生产往后放。

这其实不算什么石破天惊的新认知，短视频成为传播主流，早有苗头。但我们为什么拖到现在才调整？说白了，就是路径依赖在作祟——我们团队当初是靠着👸号起家的，自然对它有感情、有惯性，哪怕👸号和短视频的传播效率早已拉开巨大差距，还是舍不得放下。

而那些一出生就做短视频的媒体，压根没有👸号这层包袱，他们走得当然更干脆。

企业也好，个人也罢，想要彻底抛弃过往积累的经验、能力和资源，真不是动动嘴皮子那么简单。这大概就是进化论给我们上的最生动的一课：你的历史，就是你的天花板。
