# ('熊的策略与猎豹的策略', (2, 12))

昨天用桃子聊了聊竞争壁垒，今天想再从动物世界里找点关于企业经营的灵感。前阵子听吴伯凡老师的课，有一段比喻特别有意思：有的企业像猎豹，有的企业像熊，背后其实是两种完全不同的生存哲学。

先说猎豹。它是哺乳动物里的速度之王，从牙齿到肌肉再到身型，全是为高速追捕猎物而进化出来的。这样的极致专注，让它一度成为草原上的顶级杀手。但专注也意味着脆弱——猎豹的食谱太窄，基本只能吃肉，而肉在自然界里从来都是稀缺品。别被纪录片误导，草原上的狮子和老虎，大多数时间其实都在饿着肚子找下一顿。放到商业里，那些只做一个领域、精益求精的公司也一样。就像只布局酒店业务的企业，品牌很垂直，运营很专业，可一旦遇到疫情这种黑天鹅，你很可能会发现：根本没有第二条现金流。

相比之下，熊是另一个路子。熊的硬件条件真不算好：跑不过猎豹，灵活度不如猴子，个头比大象小一圈，眼神还差，于是落了个“熊瞎子”的外号。但它吃的范围极广，肉也吃、素也吃，能上树掏蜂蜜，能下水捉鱼，还能扒拉出蛤蜊当瓜子嗑。要是真到了万物萧条的冬天，它干脆找个地方冬眠，等来年回暖再说。这几乎就是企业“开源节流、降本增效”的动物版本。

熊没有一个特别拿得出手的独门绝技，但它的食物选项多，生存概率反而更高。东边没收获，西边能补上，怎么都不至于被饿死。这是自然界给我们的提醒：单一经营的风险是实实在在的，但分散风险也未必非要自己张开臂膀做一堆业务。你完全可以通过股权投资、保险配置、房产持有等方式，把“万一”发生的损失摊薄。永远别把所有鸡蛋放在同一只篮子里，这句话对企业家成立，对普通人也同样成立。

说到底，让自己的收入来源更多元，本身不就是一种很好的经营策略吗？
