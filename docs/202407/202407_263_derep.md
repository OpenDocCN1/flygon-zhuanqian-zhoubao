# 十个人合伙，股权怎么分

10个人合伙创业，股权怎么分才公平？这套“三步走”方案值得一看

话说合伙创业，三五个人最常见，超过五个已经算“小团体”。如果一下子来十个股东，事情就变得微妙起来。最近有人跟我咨询，说他们十个人打算一起干，项目是做POS机、收银系统这些，启动资金不多，五万左右就能跑起来。团队成员都是销售出身，而且大部分还是前同事。大家把资源凑在一起，想搞一个平台型公司：先用现有项目切入市场，之后把贷款、信用卡等业务嫁接进来。没有生产、没有技术，本质上就是个“中介公司”。

人一多，问题就来了。股权怎么配？谁来当老大？怎么才能让每个人都服气？

先说说底层逻辑。股权分配有几条铁律：第一，必须有一个核心决策人；第二，股份不能平均分配；第三，合伙人之间要平等相处；第四，团队要保留创业者的基因。但在十个人的销售团队里，这些原则落实起来困难重重。销售出身的人，习惯把业绩当唯一标准。可公司不止有销售，还有运营、管理、组织建设、人才培养一堆事。业绩好不代表综合能力强。打工的时候，出了问题有领导扛，有同事帮；创业后，所有风险都要自己承担。碰到搞不懂的就去补课，不会做的就开口请教，事情拿不准就多商量。

比较特殊的是，这十个人能力处于同一水平线，分工也几乎一模一样，既谈不上互补，也没有谁明显比谁强。硬要从中选出一个老大，怎么选？直接任命？谁来任命？每个人都觉得自己行，或者想推自己人，很难达成一致。大家投票？看似民主，搞不好就成了拉帮结派。公司还没开张就先窝里斗，以后迟早散伙。按能力标准选？真正的“带头大哥”需要整合资源、搞品牌、聚人心、定战略、拉融资，还得有精神领袖气质。说实话，这些特质在这十个人身上还真不容易看出来。可大家之前都没当过老板，潜力再怎么大，也需要环境去激发。

再从股权数字看：如果硬选一个人当老大，给他51%，剩下九个人分49%，人均只有5.4%。这么点儿股份，很容易让人心里不平衡，干着干着就不想出全力，干脆坐等分红。所以，怎么让分配体现公平、合理、激励，才是核心。

我的建议分三步走。

第一步，先“平分”定基础。这里的“平分”不是要平分股权，而是先按100%均分十份，每人暂定10%作为启动形态。接着把100%拆成两部分：一部分对应资金投入，一部分对应人力贡献。比如资金占20%、人力占80%，具体比例看项目对资金和人才的依赖程度。然后，依据过去的业绩或发起人身份，先定一位首任总经理。其他人各自认领岗位，或者干脆大家都先做销售，辅助性的杂务另外招一个专职人员处理。

第二步，用动态考核来“算”股权。设一个考核期，比如3到5年。每年的分红，先按照原来的资金/人力权重，把资金收益按出资比例分掉；人力贡献的部分，则按各人业绩在团队总业绩中的占比来分。等考核期结束，把每个人在整个周期里的总业绩累计起来，算出真正的贡献比重，那就是最终股权比例。当然，每个阶段怎么考核、业绩怎么核算、分工怎么量化，都要提前写清楚，不能只停留在思路框架。对总经理也可以用“轮值”机制：轮流坐庄，任期内考核公司整体业绩，还有人员流失率、外部资源配合度、目标达成情况等指标，同时约定出现哪些情况就必须“下课”。有了规则，公司才能自己转起来。这样既没有偏袒，又鼓励大家多贡献——干得多，分得多，股权和话语权自然也会变大。

第三步，用协议把一切固化。动态期结束后，形成稳定的股权比例，这时要赶紧完善公司治理结构，比如决策机制、管理流程等。为什么？因为一旦股权固定，有人就会懈怠：反正我有20%了，可以歇一歇。所以对股东的激励要覆盖到公司运营的方方面面，不能只盯着股权。具体操作上，前期可以先注册公司，把大家商量好的规则写进股东协议，签字画押；等满期确定比例后，再去工商部门做变更。股东协议内容越细越好，否则后患无穷。另外，十个人的公司大概率选不出一个绝对控股的大股东，可能只是选出一位总经理，他的持股份额未必最高，这就容易引发决策争议。所以，议事规则、决策权和最终控制权的问题，必须在协议里提前说清楚。

总结一下：这个案例的股权设计逻辑是“先平分、再拉开差距，以贡献论英雄”。难点不在于分多少，而在于规则怎么定。规则设计得不好，公平性和激励性都无从谈起。股权设计永远要一事一议，人数相同不代表方案相同，人不同、项目不同、能力不同，结果必然不同。说到底，股权拼的是思维方式，不是比例数字。创始人要站在人性的角度去思考，用规则去回应人性中的利益驱动。兄弟情谊未必长久，利益关系反而恒定。商场上，敌人可能变为朋友，朋友也可能变成敌人，最终都是围绕利益在博弈。企业是动态发展的，合伙人之间的股权、职责、能力，都不能一成不变，应随着企业成长不断调整。
