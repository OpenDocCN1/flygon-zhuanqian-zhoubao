# 别躺在过去的功劳簿上：德鲁克给管理者的第一课

很多创始人做到一定规模后，都会遇到一个隐形陷阱：用昨天的胜利，去解释今天的问题。

彼得·德鲁克早就点破了这一症结。要做到真正的事半功倍，管理者首先要学会做的事，不是去堆砌新的目标，而是先做一次干净的减法——果断放下那些已经失效的过去。

说什么过去？就是曾经让你突围、让你赚钱、让你被认可的那套方法、那套打法、那段辉煌。

当这些经验从资产变成包袱时，它会悄无声息地占据你的注意力，让你把时间浪费在重复验证旧成功上，而不是去寻找下一个真正重要的事。

所以德鲁克的逻辑很清晰：要事为先的前提，是先清空。

先有勇气承认：过去的成功不等于未来的通行证。敢于主动告别不再创造价值的历史，才能腾出空间和精力，去抓住当下真正关键的那一件事。

这篇观点来自创始人必读系列，德鲁克：管理者要敢于摆脱过去的成功。
