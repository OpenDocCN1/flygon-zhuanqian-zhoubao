# 短视频爆不了，直播卷不过，抖音电商还有什么红利？

短视频难爆款，直播太内卷，抖音电商还能怎么赚钱？

大家好，我是龙哥。  
算下来，我在这行摸爬滚打已经有8年了。一年做到三五百万GMV，每天发货一千多单。  
不过，别误会，我不是什么正规军出身——高一就辍学了，因为成绩实在不咋地，感觉也考不上好大学。第一份工作是在快递点搬货，那时候好多老小区没电梯，纯靠一身力气吃饭。

搬了几年货，总想着怎么搞点更轻松又赚钱的路子。脑子一热，听人说加盟快递店能省心，结果年纪小、没见识，十几万加盟费直接被人坑走了。  
学历低，工作也难找，只能天天泡在网上刷招聘信息，投了无数遍简历之后，总算有家电商公司愿意收留我。

当时我就拎着行李从杭州去了广州，从最底层干起，两三千的客服执行也做，一两万的店铺运营也干，后来还做到月薪十几万的运营负责人。很长一段时间都是凌晨三四点才下班，睡醒又直接回公司。  
干了差不多两年，因为分钱没谈拢，加上家里想让我回杭州，我就干脆出来自己开公司了。到现在还能活得挺好，动态持有50多个抖音号、20多个天猫店、300多个淘宝店。做电商的朋友都懂，店铺数据就像过山车，总有波动。

这些年总有人问我：项目怎么选？怎么做起来？
