# 两个美妆产品的创新案例

两个美妆创新产品，本来都有机会做大，最后却一个掉队、一个被反超。读完小马宋分享的这两个案例，我最深的感触是：不会运营，创新可能只是给对手铺路。

先说第一个案例。有一家原本给海内外品牌做代工的假睫毛工厂，自己研发了一款非常省事的产品：不用胶水，也不用磁力贴，直接把假睫毛往眼皮上一贴就行。对嫌化妆麻烦的女生来说，这体验简直友好到不行。产品一上市就爆了，📕、抖音上到处是热门笔记和短视频。

但这类产品有个致命问题：太容易被模仿。就算你申请了发明专利，在当下的商业环境里，同行也不见得会当回事。更要命的是，这家公司是生产型基因，做供应链很在行，做品牌和电商运营却是短板。结果，后来者一拥而上，很快就把他们甩在身后。小马宋聊起这事时挺惋惜：如果当时提前找到一支成熟的电商运营团队，趁着对手还没反应过来，集中力量做推广、拉店铺权重、把品牌声势打出来，完全有机会守住这个品类的第一名。可惜他们没准备好，风口一过，优势也跟着没了。

第二个案例更像一场“一个人的赛跑”。一位做印章生意的创业者，发现美妆博主自己搞了一种“萝卜章”，可以在眼睛下方直接盖出假睫毛。他依托自己多年的制章经验，迅速把这种玩法商品化，做出了更好上手的“下眼睫毛印章”。去年，这个产品成功登顶品类第一，他的年利润从原来的几十万元一下子飙升到几百万元。

不是说他不重视推广，实际上他做过好几年电商，也算懂运营。可公司实在太小，几乎全靠他一个人，就算有心，也没法搞出快速、大规模的投放。到了今年，同行终于注意到这块市场，两家做美妆的商家直接做到了类目第一、第二，他被挤到了第三。

把这两个故事放在一起看，结论其实很一致：产品创新是起跑线，运营能力才是分水岭。你辛辛苦苦替市场打开了一扇门，如果没能利用好短暂的窗口期、把品牌心智占住，最后的果实很可能被后来者摘走。窗口期很短，不会等你“准备充分”。
