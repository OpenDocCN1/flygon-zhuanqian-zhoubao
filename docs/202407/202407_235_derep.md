# 一条百万播放视频，撬动 10w+GMV，挣回 10 倍赚钱门票，我都做了哪些事？

从“门票还没回本”到“赚翻十倍”，一个赚钱圈友的航海复盘

在龙哥盟，有位入圈两年的圈友叫白也。他用一次航海，把自己从“门票还没回本”的尴尬境地，拉到了“赚回十倍学费”的漂亮位置。

刚进赚钱那会儿，他就定了个小目标：一年内把买门票的钱挣回来。为了这个目标，赚钱圈里的精华帖子他没少刷，风向标更是天天盯，每逢航海必上船。📕店铺、👸号爆文、视频号IP带货，这些热门方向他都蹚过水，可结果始终平平淡淡，那个小目标也一直没兑现。

心态快崩的时候，五月份的视频号口播带货航海来了。白也说，自己当时有种说不清的预感——这趟船跟以往任何一次都不一样，要是不登船，往后肯定拍大腿后悔。于是，他二话不说就报了名。

而后的故事，简直像开了挂。一条视频做到百万播放，带出来的成交额突破10万，算下来，赚到的钱已经是当初那张门票价格的十倍。从“颗粒无收”到“盆满钵满”，连他自己都说，这一期收获远超预期，但同样也踩了不少坑。

如今新一期航海马上要起航，白也趁热打铁，把上一期的经验教训做了一次完整的复盘。他特意从一个普通船员的视角，把整段旅程重新捋了一遍，既讲环节里的亮点，也不遮遮掩掩自己的失误。想看的圈友，直接去他的飞书文档：
