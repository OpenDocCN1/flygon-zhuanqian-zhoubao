# 钵仔的Midjourney知识宝典(进阶版）

Midjourney 进阶手册：参数精讲 + 一单完整的二次元头像定制流程

如果你已经能熟练操作 Midjourney 的基础功能，下一步自然是琢磨怎么把生成效率提上去，甚至把技能变成接单能力。这份进阶手册就围绕两条主线展开：一是把几个实用参数的逻辑讲透，二是用一个二次元头像定制案例，带你走一遍从沟通到交付的全流程。

先说一句：这篇内容不是给新手的，建议先掌握入门篇的写词规则再继续阅读。

一、参数拆解

1. 锁定画风：--sref

在做人像类需求，或者想稳定复制某种视觉调性时，--sref 很有用。拿最近热门的简笔二次元职业形象图来说，写出描述词并不难，真正难的是让所有成品保持同一套画风。--sref 等于把某张样图的视觉特征直接借过来复用。

使用前提：切换到 V6 引擎，V5 不生效。
操作格式：--sref 图片地址

实际操作时，先上传一张目标视觉样图，写好你的描述语句，然后在末尾加上 --sref 空格，再贴上这张样图的地址。
如果不会获取地址，去入门篇里关于图片上传的章节补课。

有人会质疑：直接把样图当底图不行吗？为什么多此一举？这个问题留到实战环节讲。

2. 画风影响强度：--sw

--sw 专门配合 --sref 使用，单独写没有响应。
格式：--sref 图片地址 --sw 数值

数值范围是 0 到 1000，一般可以先设在 500 左右，再根据生成结果微调。如果省略 --sw，系统按默认值 100 运行。

3. 多份样图混合

想借鉴某种效果又不想完全撞车，可以同时传入多张画风不同的样图，让 MJ 自己融出有原创感的调性。
格式：--sref 地址1 地址2 地址3 ...

当某张样图的权重要调高时，在对应地址后加 :: 和数字。例如 --sref 地址1::5 地址2::3，权重范围 0.1 到 5。
这个参数同样能配底图使用，适合头像类定制：源图地址 + 描述词 + --sref 样图地址。

4. 锁定人物特征：--cref

遇到一张人物脸部很棒、但背景或周边元素不行的情况，--cref 可以让人物保持不变，只替换其余内容。特别细的瑕疵，还是交给 Photoshop。
前提同样是 V6 引擎。
格式：--cref 图片地址

需要注意：--cref 更适合拿 MJ 生成的图作为人物基准；如果用真人照片，五官有概率被扭曲。我实际测试下来，皮克斯质感的效果还可以，二次元画风就有点不稳定，可能和样图调性有关。

8. 批量出图：--r

当你确认手里的描述词能稳定出好图，或者想同时查看多组候选，可以用 --r 省去反复点击刷新。注意必须在快速模式下使用。
格式：prompt --r 2，数值在 2 到 40 之间。--r 2 代表让 MJ 连续执行两次出图任务。

发出命令后，MJ 会弹一个确认框，点 yes 就开始。

如果描述词还有瑕疵，但想先看看多组效果，用 Edit Template 按钮，在弹窗里挑选要修改的部分。
这个按钮会按预定批次显示对应份数的描述词，方便你在生成前检查拼写和逻辑，避免出图结果跑偏。

二、实战案例：照片转二次元

很多客户不想直接用真人照片当头像，又想保持自己的辨识度，所以“照片转二次元”成了热门需求。以前这事需要绘画功底，现在靠 MJ 和几段描述词就能完成。

接单时，最好让客户提供脸部清晰、没有水印和贴纸的照片。否则以 MJ 的不可控性，什么事都可能发生。

### 生成参考图

把整理好的词条和用户的真人图一起丢进MJ去出一张参考图，为什么要先垫图而不是裸词生成？

![](img/bdeb2cd90d9bc92369c25a8970d77831.png)

![](img/8b57b39eb4efc5c2c85521f62e6861eb.png)

皮克斯风格最难把握的就是发型，即便提示词里写了发型，如果参考风格里的人物是卷发，很容易把卷发带出来，甚至把发丝方向画反，细节也会跑偏。

![](img/b891696ce0fe93557da9533ab9f5b1a8.png)

![](img/4789dc3215999e3005c8fbcb8e1ea391.png)

![](img/cd504d9910dfdce58a0dce8aa807ae15.png)

能明显看出眼睛左右反了，手势也反了。生成出来是镜像的，再加上参考风格里的人物是卷发，导致结果头发也跟着卷。所以重新出参考图时一定要垫上用户的真人原图来引导。

需要注意的是，如果垫图后效果已经足够还原皮克斯风格，可以直接收工。下面的步骤只适用于垫图后风格还不够像的情况。

### 选择成品图

选图有讲究，因为关系到与四维图的相似度。挑选AI结果时先从整体面部五官看起：鼻子→嘴巴→下巴→眼睛。若画出来是反向的，可以用PS或美图秀秀翻转一下，让方向与原图一致，方便用户对比。

![](img/bd5b42f3f8ca5d4bdd03a41c7c0ffdfa.png)

小技巧：即便画得不是百分百像，只要话术好，用户通常都很满意也会买单。

特别提醒：用户问男孩女孩时不要回答，哪怕AI画出来像女孩也不要说。相关法规禁止告知宝妈胎儿性别。

### 去背景

把选好的图导入PS去背景，方便后面加文字和统一色调。导入后先看右边的图层有没有锁，有锁就点一下解锁，否则无法编辑。

![](img/8be1be509e922e8424c3c884fc072271.png)

然后右键左边快速选择工具，切换成魔棒工具。

![](img/471d20f0c3bf433b891230c1714256d9.png)

点一下图片中的背景，就能选中背景，按键盘上的【Back】删除键即可去掉背景。

![](img/b9eeed5bc3931f2fc6debf821294da50.png)

![](img/48bba0654f69797242e0bdbb86157ea3.png)

### 制作单个表情内容

去完背景的图先放着，点击左上角的小房子回到PS主界面，再点新建按钮，新建一个240*240的画布。

![](img/ad42941bd9bee586bfb1a7165822a9a2.png)

![](img/748c3825f7ba29052cb0f03ed3dc029c.png)

画布背景色可按喜好选择，创建后颜色就固定了，若想改可用矩形覆盖。

![](img/f9b8e0bd988803e3a340ce7aebed257f.png)

创建好后把去背景的表情拖进240*240画布里，调整到合适大小。

如何把去背景表情拖进新建画布的演示视频

![](img/d0fcb83bd44f44339bf21dc802ee82dc.png)

如果缩小后周围露出其他表情的残影，可用右边的套索工具，右键切换到多边形套索，把表情框起来，按Ctrl+J抠出。

![](img/215a0e3526557d9163b028f368cef535.png)

抠出来后会多一个图层，这是你框出来的表情图层，把下面的图层隐藏，就能得到周围空白的单个表情。

![](img/15723b7c3fcb023b2bd99d84b28bb0ab.png)

![](img/8c91e1915b034b1395f4e4371566c2ed.png)
