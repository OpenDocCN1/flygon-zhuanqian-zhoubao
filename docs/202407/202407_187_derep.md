# 离职后转型做📕个体服务商，半年变现 15 万，我是怎么跑通的？
作者：龙哥

“离开公司以后，你靠什么赚钱？”这是我最近被问到最多的问题。今天统一回答一下。

先自我介绍：我是龙哥，2022年4月加入赚钱圈子，如今已经是第三个年头，也是我成为自由职业者的头一年。

我的答案很简单：辞职后，我转身做起了📕个体服务商。没有团队、没有办公室，全靠过去几年在品牌、运营、市场推广方面攒下的经验，为📕上的品牌方提供陪跑服务。从零开始一步步把模式和路径走通，半年时间累计变现超过15万。


如果你当前正好在公司承担品牌、运营、市场相关的工作，也在考虑未来的独立发展路径，希望我的经历能给你一些方向感。
