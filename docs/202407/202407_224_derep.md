# 创业八年，三次出发，两度归零：从百万身家到跌入谷底，再把营收追回千万

这篇是这个系列的第三篇。

过去这些年，我创业三次，失败两回。最风光的时候，账上躺过七位数；最狼狈的时候，整个人几乎被清零。后来一步步把营收重新做到千万级，这条路，我走了整整八年。

上一篇文章发出去后，收到不少朋友的点赞和私信，真的很感谢，也让我有了继续写下去的动力。也有朋友说，上篇好像刚起个头就结束了，读得不过瘾。那次我的确更偏“上帝视角”，冷静地把动作上、决策上的错误一条一条单独拎出来看。这次我想换个角度，把镜头拉近一点，多写写失败时心里那些真实的声音——慌过、不甘过、也迟疑过，再说说那股让我重新站起来的劲头。中间还会补一些当时的记录和截图，让整个过程更有现场感。

现在是2024年6月21日晚上8点46分。按我这个码字速度，这篇写完估计又要到凌晨。先说一声谢谢，愿意花时间读到这里的朋友，也希望大家如果觉得有收获，就顺手点个赞——你们的反馈，就是我把这段经历继续讲下去的最大动力。
