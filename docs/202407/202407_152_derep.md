# 互联网赚钱的野路子，我告诉你一个超狠的！
作者：龙哥

这两年经济啥情况，大家心里都有数。不光是普通人兜里紧，我身边一堆老板也垮了。以前开百万豪车的，现在蹬共享电驴；以前住独栋别墅的，眼下挤在出租屋里。

说到底，这轮淘汰掉的，大多是那些门槛低、同质化严重的买卖。比如低端加工厂、建材装修这类，本质就是倒个手赚差价。以前行情好，能撑起大富大贵；现在整个大盘往下走，链条上每一环都榨不出油水，连王思聪被前任要抚养费，对方都说“先熬过今年再看”。

链条从上到下都在缩紧，站在最末端的普通打工人，自然最吃亏——利润一薄，工资发不出，公司撑不了几个月就凉了。

可偏偏这几年，一夜暴富的新闻全是从互联网上冒出来的，比如那个突然爆火的郭有才。很多人搞不懂：网上红了凭什么有钱？钱从哪来？又是谁给的？

答案就在“线上经济”四个字里。说白了，这是一种影响力变现的模式。谁影响力大，广告商就追着谁投钱，跟明星代言一个逻辑。更别说火了之后，光靠粉丝每天的打赏，累计起来就是普通人一辈子够不着的高度。

这种模式的妙处在于，三言两语讲不清。但你得明白，正因为讲不清，才能让一个人在经济下行的环境里，随时保持进账的状态。

反过来看，如果你干的活儿太简单，谁都能一眼看懂，那竞争必然惨烈。你捅我一刀，我踹你一脚，最后大家一起玩完。

所以，真正能赚钱的事，一定是去做别人看不懂的东西。然后沉下心，在里头悄悄潜伏、狠狠深耕。等你赚到钱了，外人看得眼红，却不知道怎么抄，一时半会儿挤不进来，更别说替代你。他们只能干瞪眼，看你大把捞钱——这就叫护城河。

不管是线下实体，还是线上项目，都得守一个原则：做长期利他的事，去深耕那些别人嫌难、看不透的赛道。

前阵子天热，几个老友晚上拉我喝酒吃宵夜，醉醺醺地问：“你现在不上班怎么还活得这么滋润？”我说我在搞私域IP和视频号带货。他们一听“带货”俩字，眼睛都直了，借着酒劲喊“带带兄弟”。

我说行啊，先拿10万本金出来。一听要本金，他们就缩了：“我现在就是没钱啊，有钱还找你带？有没有不要本钱的路子？”

我没多话，直接甩出我这个👸号给他们看：“就这个号，每天写写文章，一年也能弄个几十万。你能坚持200天，天天写吗？”他想了想说：“能！但得给个保底吧，没保底谁干？”我说：“没有保底，没人管你死活，爱干不干。”话说到这份上，他们自然没戏了，之后见面反倒开始阴阳怪气。

说实话，我表面挺烦，心里却乐开花——我知道，我跟他们之间隔着一条又长又宽的护城河，看得见，摸不着。它的名字，叫长期主义。
