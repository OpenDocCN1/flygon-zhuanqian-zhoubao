# ('桃子为什么有桃肉？', (2, 11))

早上在酒店吃早餐，水果区摆着几只桃子。我盯着它们，忽然冒出个怪问题：桃子为什么非要长出一大包桃肉？

你可能会说，果实不都是为了繁衍吗？可细想想，豆子这类东西才叫“为后代着想”——黄豆里储藏的养分，全是给那颗豆芽准备的。桃子却不一样，桃肉被摘下来不吃，过不了几天就会烂掉，它根本不给种子供营养。那桃树费这个劲，图啥？

图的是传播。

植物最头疼的事就是自己不会动。种子如果都落在同一片地上，大家挤在一起抢阳光抢养分，那跟自杀没区别。所以植物为了“搬家”，各出奇招：柳树把种子交给风，苍耳浑身带刺蹭过路动物，椰子让海浪替它流浪。而桃子的策略，是把果实变成一道美味。

鲜嫩多汁的桃肉，其实就是桃树给动物开的“辛苦费”。动物吭哧吭哧吃掉果肉，把桃核丢到远处，或者随着粪便排出去，桃树的基因就这样被搬了家。这么一看，猴子相当于桃树的渠道商，桃肉就是桃树付给渠道商的佣金。

这个道理放进商业，一样适用。品牌和经销商之间，最先要谈拢的，不是感情，而是利益怎么分。

再拿辣椒打个比方。辣椒长出一身辣味，却恰好遇上不怕辣的鸟类，鸟能吃它，飞得又远，自然而然帮着把种子散播到四面八方。因为鸟类对辣毫无感受——辣本来也不是一种味道。

除了人类，自然界所有生物从来不做多余的事。它们活一辈子，只遵循一个原则：花最小的成本，活下来，并把基因传得尽可能多。而且一个生物不会面面俱到，只会死磕一种优势。蝙蝠夜里觅食，干脆牺牲视力；狮子要速度要爆发力，就不去浪费能量长角——角是防守型武器，牙是进攻型武器，两样都想占，反而都差。

企业做战略，比生物复杂不少，但内核是同一个词：取舍。蜜雪冰城要把低价做到极致，就砍掉水果茶这些复杂品类；茶颜悦色靠服务体验立身，所以一直坚持直营；霸王茶姬要砸出品牌势能，就专挑A类商圈开店；古茗追求单店日均流水，宁可不去北方市场；瑞幸专注外带和外卖，也就不太在乎门店店面形象。

而不少奶茶品牌，只是赶上了行业红利开了一堆店，始终没练出核心竞争力。等到风口退去，它们只能被那些目标清晰、策略聚焦的对手，一家家慢慢熬干。

一颗桃子，嚼到最后，嚼出的是商业的底层逻辑。
