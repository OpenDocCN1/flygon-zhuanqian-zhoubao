# 一次通宵，点亮了一个被忽略的小生意
作者：龙哥

说实话，最近太忙，难得能坐下来写点长的。

这个项目说起来有点戏剧性，完全是某天熬夜刷手机时，一条随手看到的短视频撞出来的灵感。

当时我带着几个兄弟从零开始搭团队去试水，没想到一路跑通后，至今已经连续六个月稳定在赚钱的状态，而且增长的势头还在往上走。

很多人认识我，都是因为📕获客这块。21年就入局了，到现在服务过的老板累计三千多位，算是比较熟的赛道了。

去年11月那会儿，我在刷内容。有一位博主对着镜头吐槽，她准备把那个有10万粉丝的抖音情感号给放掉了，反而要把一个粉丝只有几千的小号认真做起来。

原因很简单，她之前在小号上试着推了一个脖套，结果直接炸了，单品销售额就干到了两百多万。

看到这个数据我当时脑子嗡的一下。那种被数字打醒的感觉太强烈了。

我当时就像个挖宝人一样，把她的后台数据从头到尾扒了一遍，越看越觉得不可思议。这种爆发力哪是普通的投放能解释的。

后来我偶然又碰到当时发现的那位博主，现在人家已经成了这个赛道的头部玩家，赚钱的规模只比那次更夸张。

开窍这件事吧，真需要一记重锤。
