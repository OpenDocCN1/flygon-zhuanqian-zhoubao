# 20岁985在读生自述：三年把“考试机器”变成月入5万的知识付费创作者

好久不见，赚钱的朋友们，我是枕棠。

现在22岁？不，今年刚好20岁，985学校大三在读，同时也在做时间管理教练。最近把自己这三年的变化整理了一下，从一个极度自卑只会刷题的985学生，到一边拿着奖学金一边靠知识付费做到月入5万，这个过程比我想象的更曲折，也更值得记录。

我其实在赚钱沉淀了快一年多，正是这段时间对商业的理解被彻底打开，才让我敢把“读书”和“赚钱”同时做到位。之前因为有点完美主义的毛病，一直不好意思出来说话，直到梨云老师一直鼓励我，这才花了整整一个月时间，把这篇经验梳理成体系。

从整体思路搭框架，到逐字撰写、反复修改，再到最终排版，几乎是用了一个月的空闲时间打磨出来的。内容我没有藏私，前面先讲清楚了我理解的知识付费商业逻辑，给完全不懂的小白一个上手路径；后面则把自己实操验证过的进阶打法，拆成【定位、产品、流量、转化】四个关键环节，尽可能把我在自媒体创业这条路上踩过的坑和拿到的心得，全盘摊开。

全文比较长，我放在飞书里了，方便大家系统阅读。

最后想说声谢谢。

最开始是七小哥拉我进赚钱，前期给了我大量一对一的指导，各种提醒和建议我都记在心里。

叶叶老师帮我做过盖洛普强项分析，并直接把我选为她的时间管理教练，这份认可才让我确信时间管理这件事就是我的优势，后面的方向才一点点清晰起来。

梨云老师在📕运营上给我了非常具体的点拨，帮我突破公域获客的瓶颈，也让我真正理解了做自媒体的底层逻辑在什么地方。

当然还要感谢龙哥老师和整个龙哥盟社区，提供了这样一个可以放肆学习、碰撞思想的平台。没有赚钱，就不会有现在的枕棠。
