# 黄仁勋谈心法：无知与信念，都是顶级竞争力

很多人以为成功者无所不知，事实恰恰相反。

在最新一次访谈里，黄仁勋分享了一个反常识的底层逻辑：无知，本身可以是一种超能力，而坚定的信念，同样关键。

他说，当你真正建立起一套属于自己的核心信念体系后，你的生活会进入一个持续迭代的状态。你不是在固执地死守，而是在每天用现实去检验你的假设。这一路走来，我就是这么做的。

信念给你方向感，让你敢于在不确定的世界里出手；无知则逼你保持好奇心，承认自己不懂，从而持续学习、持续修正。

最重要的一点是，保持可塑性。如果外部世界发生了变化，数据和事实告诉你旧的认知已经失效，那么你的判断也必须同步更新。信念不是用来盲从的，是用来被验证、被升级的。

无知让你谦卑，信念让你前行，两者合一，才是长期主义者的生存法则。
