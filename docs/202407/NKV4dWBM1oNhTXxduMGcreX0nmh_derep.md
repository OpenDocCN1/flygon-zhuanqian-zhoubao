# 一、短剧项目是什么

## 1.1 短剧的本质

你在短视频平台刷到的那些上头小剧集，其实大多改编自网络小说。每集一到三分钟，节奏快、情绪拉满，就是我们常说的短剧。核心就是高潮不断，不拖泥带水。

## 1.2 赚钱逻辑

各家短剧推广APP会提供正版素材。我们把素材拉到网盘，再做二次创作混剪，去重后分发到各大自媒体平台。用户在平台上付费解锁剧情，我们就能拿到对应的分成。

目前能直接挂小程序链接的只有抖音和快手。视频号、📕之类不支持挂载，就得用艺术码跳转，把用户导流到充值页观看。

## 1.3 可操作的平台及门槛

发布渠道主要是抖音、快手、📕、视频号。抖音需要500有效粉丝才可挂载，其余三个平台零粉丝就能发。

## 1.4 用户怎么充值

抖音、快手用户直接点视频左下角的链接即可付费。视频号和📕则需要扫我们生成的艺术码完成充值。

# 二、账号准备与运营

## 2.1 项目工作流

### 2.1.1 视频制作的三种打法

1.搬运：直接下载爆款再做简单处理再发。风险很高，大概率违规，不建议碰。
2.混剪二创：目前主力做法。用推广APP里下载的正版素材进行混剪、剪辑后发布。
3.解说原创：基于素材混剪，再写解说文案配音。解说时长需占视频总时长30%以上才算解说。

新人建议从混剪起步。混剪一条约30-40分钟搞定，解说一条要1.5-2.5小时，但变现提升并不明显，性价比低。等混剪熟练后，再考虑做解说加分。

### 2.12 抖音发布流程 以兔兔短剧为例

1.按教程把视频剪好
2.打开选剧APP进入推广计划，选择剧集申请推广
3.视频发出半小时后点dou+查看状态，大致有四种结果
——视频不可加热，直接设成仅自己可见，约10%会这样
——提示侵权，直接隐藏换剧
——可加热但没流量，继续发
——可加热且流量起来，做好评论区引导

### 2.13 抖音准入门槛

需实名且拥有500有效粉丝，老号新号都能用。
老号粉丝画像要偏极端，男女比例最好9:1，不要5:5或6:4。
新号建议养号3-5天。百万播放很容易触发违规禁言，放心解封后继续用。一个百万播放的视频通常能变现4位数，下面是员工的实拍数据：

## 2.2 养号要点

### 2.21 环境与实名

同一地点批量注册会被判定为工作室，影响流量。最好做到一机一卡一号。

### 2.22 养号步骤

1.前3-5天正常刷视频、看直播，模仿真人使用习惯
2.第6天修改头像、昵称、签名、地区。四件套没有固定模板，签名可以空着。头像建议清新纯欲风，开挂载前切记不要违规。账号表现要像普通用户，不要过度暴露短剧属性
3.第7天起开始发布混剪作品

养号目的就是让系统判定为真人操作。养号期间可做神评论提升权重，每天控制在20条内。

![](img/96ad8a6b1a4537632217d936e4d418e6.png)

补充：新号或长期未用的老号不要直接改资料，先活跃几天。老号作品要隐藏，原作每天隐藏不超过10条，不要删。

### 2.23 凑满500有效粉

2024年4月16日起，抖音个人号开通商品推广需要有效粉丝≥500。

有效粉丝指真实、活跃、兴趣相关、地域分散，且通过优质内容吸引来的粉丝。

涨粉方法：
1.前期先发拉新内容，不挂载，既能有收益也省去刷粉成本
2.市面上也有刷粉渠道，使用前先确认账号其它条件达标

## 2.3 开通挂载权限

粉丝达标并实名后，就能在兔兔短剧APP里授权挂载。进入推广计划，点击任意剧集申请推广，跳转抖音确认合作。后续发片按此流程走，点击上传视频完成任务即可带充值链接。想推哪部剧，就在APP里搜哪部申请。

# 三、剪辑发布与变现

账号粉丝量10万/5万/1万以下均可测试，发布时间一周内，点赞几百到1万，视频时长12-30分钟越长越好，最好半小时。

开头选择：
要先想清楚目标人群，用什么钩子留人
1.有冲击力
2.内容能支撑悬念，逻辑通顺
3.正向找开头，遵循去废话原则，快速切入
4.反向找开头
好奇、悬念、钩子层层拔高
不能用的开头：打耳光、床戏等同质化内容

开头处理：有内容的片段变速1.1-1.2，画面感强的1.4-1.5，倒序拼接增强衔接感

剪辑时删掉拖沓片段，控制总时长25-30分钟，最好半小时

删减原则：
1.去转场，去掉每集开头结尾的衔接
2.删减非主线剧情
①回忆桥段直接删
②无用铺垫直接删
③配角单独镜头删
④啰嗦拖沓片段删
⑤重复剧情删
硬指标：3集内容内至少有2个15秒以上的片段+2个8-15秒的片段
跳集4-5集可拆分处理，保证逻辑不乱

粘合标准：画面连贯、BGM连贯、故事连贯

结尾钩子选择悬念和好奇心，让用户想追下一集

解说原创不建议新手直接上手，门槛高见效慢，有文案底子再尝试

发布页出现蓝色小图标即代表小程序挂载成功，才有收益。话题可写“看一个片段追完整部剧、短剧推荐”等+剧名。发布后左下角看不到链接很正常，去评论区查看即可。视频较大，上传需要时间，发布期间保持在线防止失败。

![](img/0dfb480687f8163dc85502b0e8e27e51.png)

发布后一小时点分享-上热门dou+，若显示正常投放界面即成功

![](img/e9d1ba1ca48c279c320f3812465d7860.png)

## 3.2 转化引导

播放过万才有引导价值。评论区可用表情、文字引导用户追更，参考同行做法。评论区要维护，负评巧妙回复如“后续更精彩”。自己评论后长按置顶，用小号去评论区自检是否显示正常。

![](img/ecaa7e13237aed6106e50a0b2adaf730.png)

## 3.3 发布时间

一天发1-3条，间隔至少3小时，避免连发封号。黄金时段：中午10-12点、下午15-17点、晚上19-24点。晚上流量大，用户更易冲动消费，至少保证一条在夜间发布。

## 3.4 数据查看

短剧充值有3天退款期，平台数据有延迟。可先在抖音小程序推广计划-我的-任务中查看实时订单。3天无退款后同步到短剧APP，次日可提现。
