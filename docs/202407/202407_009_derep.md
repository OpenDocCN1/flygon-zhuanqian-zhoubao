# 差点背上 20 万债务，到单人公司做到百万营收、拿到赚钱精华：我用两年时间换来的成长复盘



## 从濒临负债 20 万，到个人公司年入百万并获得精华帖，我在赚钱的两年蜕变之路

作者： 安七

日期：2024-07-22

《从差点负债 20W，到一人公司创收百万、斩获精华帖，复盘我在赚钱的 2 年成长经历》

大家好，我是龙哥，应届毕业，毕业一年做到双百万。

昨天登录赚钱才发现，自己的一篇帖子被加精了。这个节点让我觉得，是时候把过去的经历好好梳理成一篇长复盘了，这对我来说也是个新的里程碑。

精华帖地址在这里：

这次的分享和我之前发过的笔记不太一样。我想把自己在赚钱的完整轨迹摊开来讲讲，从一个完全的新手到最终拿到实打实的成果和精华认可，中间都经历了什么。

写这篇的初衷很简单，希望那些正在赚钱里找项目、迷茫找不到方向、或者进展还没放大的朋友，能透过我的故事看到自己的可能性。

为了让大家更好阅读，我把整个过程拆成了四个阶段：

1/ 懵懂期——把赚钱当成一本能赚钱的词典来查
2/ 受挫期——被骗上万后醒悟赚钱思维，开始疯狂测试项目
3/ 起步期——遇到贵人指点方向，确定基调，加入赚钱航海，跑通最小可行产品
4/ 深耕期——成果开始放大，获得官方赋能
