# 我亲手做垮的一个项目：阅读书签全复盘

大家好，我是友恒，谐音“有恒”，一个04年的大二预备生。大一上学期我靠闲鱼卖羽绒服赚过些钱，最好的时候单月利润超过两万，一单能赚一百左右。但羽绒服太受季节限制，过完年我就没再做了。大一下学期我没什么方向，日子过得晃晃悠悠，直到今年4月25日，我加入了龙哥盟。

在赚钱里从来不缺成功故事，但今天我更想分享一个真实的失败样本。我或许属于圈子里最不起眼的那类人，可我从来不打算一直待在最底层。
![](img/0bebae687a91d0ea6d783240499f7a1e.png)

这个失败样本，是我最近亲手做垮的一个项目——阅读书签。故事的起点，要从加入赚钱前那三天体验期说起。有天我在“中标”板块刷到一篇关于阅读书签的文章![](img/4acc0c920f98d531915aa3d68da4e9a3.png)，看完后我转身就跑到📕去找那个账号，发现对方就是纯个人号，而且我在其他平台几乎没看到同款产品。他帖子下面的评论基本上全是夸赞，商品评价全绿，零差评，销量也非常漂亮。![](img/dce693b103d602c19bcc4a0ce3754b45.png)![](img/0da86f05eac877c69743e2cc564350bb.png)

那一瞬间我冒出一个念头：这是个机会，是个我能够得着的机会。也正是因为这个，我选择花钱加入赚钱。

还有一件很巧的事：那个📕博主大概是2023年12月就开始做这个产品了，而我到2024年4月才看到风向标。后来才知道，早在24年1月，圈里就有朋友发过同一个风向标。这说明风向标的含金量，真的不容小觑。![](img/a6c0e4a3eef627629c8ce52e77da21d3.png)

项目启动第一关是货源。我先去1688找类似产品，但代发价太离谱：一张卡片0.8元，五张4元，运费还要9元，基本没赚头，所以我直接否了这个方案。![](img/736611ffd9587932c85da39a8d1bac80.png)

既然代发没戏，想做大就只能自己拿货自己发。我从淘宝买了一张个体户执照，然后开始到处找货源。我先去卖类似产品的老板那里谈批量价，结果对方报完价，我发现就算批量拿，利润依然低得可怜。![](img/bb98e9e834343099aa654b29ac26b1d0.png)

找了好几天，我偶然发现这个产品的材料是PVC板，于是掉头去找生产PVC板的厂家。价格一下子就缩了好几倍，一张卡片的成本只要0.23元。之前那个老板说“不可能”，但我真的做到了。![](img/a41beec59589a8d86a23a818cc814d6b.png)

到这一步，项目才算真正有了可做的空间。我直接下了5000张的订单，之后又按卡片尺寸去定制包装盒、买包装贴纸。整个过程也挺折腾的，就不展开说了，反正很多辅料是在拼多多上找的商家。![](img/7e240f07404ccca2a5706b0f5b933894.png)

有个小插曲：我前期所有支出加起来，竟然刚好等于赚钱的票价。但这只是开始。要命的是，我还是个学生，几百斤的货根本没地方放。宿舍又在五楼，把东西从校门口一趟趟搬上去，差点没把我累死。![](img/2e5ac398c4a9aef8162ee3e0ec94624f.png)

后来我见缝插针，能塞的位置全塞了，最后只有包装袋放在活动室，其余全部堆在寝室里。![](img/a6600bc3807860c72ac6775ee5109e46.png)

产品大概就是这个样子。为了拍出好看的图，我专门去图书馆拍了一堆产品照![](img/585e17923ed7d2bed161cdcd29eb31df.png)，每张图都调过亮度、对比度，又用AI给店铺起了名字、设计了头像，当时自己还挺满意。![](img/d5753aaf808028fbe2a033d4ecee9387.png)

紧接着是物流。我一开始完全没有头绪，问了好几家快递，最便宜也要8元起步。我也在赚钱里发过求助![](img/58de04d0a4b6cdd1948f16843cc80340.png)![](img/7746bbf139d3624fd39aaa7b88befff9.png)，有圈友提到云仓，但我所在的城市根本没有。后来我找到一个专门做大学生网单的兄弟，他愿意按5元一单合作，我第一次就充了100个单号。![](img/9d66ca46bd56b9bfe57a60652fd1be68.png)

到这里，发货渠道算是通了。一套书签的成本：卡片2.7元，运费5元，加起来7.7元。我当时想的是，等单量大了，运费还能谈，于是硬着头皮继续干。

主战场我选了抖音，因为那时候抖音上没人做这个，我觉得短视频平台更容易把它推起来。但抖店的门槛实在不低：保证金2000，又花了1000刷体验分，自然流量依然很差，几乎不出单。我也试过去找图书类博主合作，可能是我找得不够多，也可能是方法不对，愿意回复的少之又少。只有一位博主愿意把商品挂橱窗，确实带来了成交，但只是个位数。那阵子我感觉特别累，精力明显跟不上。

📕那边一直有零星的订单，但真正让我意外的是，拼多多成了出单最多的渠道。靠自然流量，每天能有7单上下，多的时候超过10单。只是拼多多有个很烦人的规则：不参加活动就不给推流，我只能参加。最开始几单是亏本在出，后来按7.7元保本出，再后来卖8.7元，一单只赚1块钱。![](img/da532d39c614b6427edf1f7ed2183e41.png)![](img/100f9318abbf1f631a603b46f59025ff.png)

前前后后，我一共出了一百多单。![](img/cbc864484d1da13ca4a920930aa5a455.png)![](img/a1eb9ba170ea43aecb0743c433243ef1.png)

到6月十几号，我把商品下架了。原因有二：一个是拼多多实在太恶心，非要我开“自动跟价”，不开就限流，开了就很容易真的亏本；另一个是那阵子在备考期末，精力实在顾不过来。后来抖店和📕也都陆续下架，这个项目就此画上句号，连投入的本钱都没能收回。

复盘后我最深的感受是：这类产品客单价偏低、利润空间太窄，个人卖家很难做出好结果。但对我这种学生自发货来说，优点也很明显——总投入不算高，没伤到元气。

大一上学期我在闲鱼攒下的3万块钱，现在只剩两万出头。回看这四个月，我确实一事无成。可我不觉得自己是废物，我多少还是有点执行力的，只是大多数时候在孤军奋战。我希望能在赚钱里连接到更多圈友，找到愿意和我一起努力的伙伴。如果你也和我境遇差不多，欢迎来找我，咱们一起聊聊想法，一起往前冲。

这篇文章不只是在分析失败，也记录了很多具体问题的解决办法。很多教程喜欢讲大道理，一到容易踩坑的细节就一笔带过，而我是真真切切把整个流程走了一遍。如果它能帮到我，那挺好；要是也能帮到正在努力的你，那就更值了。
