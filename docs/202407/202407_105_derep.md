# 刘润对话李丰：未来真正能活下来的企业，靠的不是站队，而是看见另一面
作者：龙哥

这两天重读了刘润与李丰的那场关于企业未来的对话，核心其实指向一个很朴素却被很多人忽略的能力。

李丰在专栏里强调，想要判断未来谁能走得更远，先得打破自己的认知舒适区。不要只围着自己认可的逻辑打转，而要刻意去找那些与自己判断相悖的声音，去了解那些自己未必欣赏、未必同意的观点和做法。

换句话说，就是主动翻转视角，去审视硬币的背面。那些在未来环境里更具韧性的企业，往往不是因为它们始终正确，而是因为它们习惯了在自己熟悉的叙事之外，多留一双眼睛，去观察不同立场下发生的真实。

这不是迎合，也不是妥协，而是一种清醒的认知训练。当一个企业愿意去接触自己本能排斥的信息时，它才真正有机会看清风险、捕捉拐点，而不是在同一个判断里越走越深。
