# 技能分两种：学完就封顶的，和越用越滚雪球的
作者：龙哥

上周刚做完团队的年中复盘，有个同事跟我吐槽：刚入司那年感觉自己每天都在飞，现在第二年却觉得成长变慢了，甚至有点迷茫。

我跟她聊了两个词，叫对数型技能和指数型技能。也是我们日常工作中最常见的两种能力曲线。

对数型技能的特点就是，起步很快，后劲不足。

比如打字。会打字就能随时沟通、效率翻倍，这个能力学会后确实能受用一辈子。但它的成长路径就是典型的对数型。你练第一个月，进步肉眼可见，跟不会打字的人相比简直是降维打击。可一旦过了那个坎，再怎么练，也很难跟同样会打字的人拉开差距。一个月后，天花板基本就到了。

咨询里头的很多知识点也是这个逻辑。像线下门店的亮度问题，大众餐饮就得用那种能抗强光的招牌。这个要么你知道，要么你不知道。知道就是知道，不知道就不知道。没有中间地带。

当一个人的工作包主要是对数型技能时，他的核心优势其实只是“知道”和“不知道”的差别。一旦你把这个点分享出去，优势就没了。

我们就遇到过这种事。之前复盘过甜啦啦的点单优化技巧，发出去两年内，几乎所有看到案例的同行都学会了，瞬间同质化。

但能持续不断地去发现、提炼出这种技巧的能力，就是另一种东西了。现场诊断问题、举一反三、把一次经验变成下一次判断力的能力，这就是指数型技能。别人到场只能看见现象，你能看见规律，而且这东西藏在脑子里，不说就没人懂。

经营、战略就属于典型的指数型。知识体系庞杂，需要长时间的浸泡，还要反复在真实案例里验证。时间越久，复利效应越明显。

前几年学经营，可能学得特别慢，甚至觉得自己没长进。但到了某个临界点后，理解会开始加速，判断会越来越准，后劲极强。这就是指数型增长的特征。

所以我的建议是，在职场里先用对数型技能建立信心和价值感。你得先会那些立刻能用、立刻能体现效率的硬核小事，才能让人觉得你靠谱。

但要想形成长期护城河，就必须持续投资指数型技能。比如对商业本质的理解力、对战略的嗅觉。这类能力没法靠读一本《竞争战略》就顿悟。书都在那摆着，但能把知识转化为壁垒的企业和人，少之又少。

陈沛杰 : 是否可以这样理解？

对数型技能，S 型曲线，价值天花板低，有就行了。

指数型技能，J 型曲线，价值无天花板，永远要精进。

学习任何技能时问自己：这个能力练到极致会怎样？

配置自己的技能列表：S 型如果是刚需的，得掌握几个，比如开车、打字，AI 很可能更早干掉 S 型技能，最终还是要聚焦 1-2 个 J 型，而且是 AI 不易干掉的。
