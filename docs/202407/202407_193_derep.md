# 4 人团队：6 个月 抖音图书从单月亏十万到月 GMV 两千万
作者：龙哥

**4人小团队，半年把抖音图书从月亏10万做到月GMV两千万，他们做对了什么？**

在抖音做图书，亏钱并不稀奇，稀奇的是亏到月亏10万还能翻盘，而且只用6个月，就把月GMV冲到了2000万。更让人意外的是，这个操盘团队一共只有4个人。

这是千万哥-JIAM分享的真实复盘。他自称98年小伙汁，常驻广州，还半开玩笑说广州圈友可以来撩。他透露，这篇文章其实2023年就写好了，一直拖到现在才完整发出来。

整篇内容分两部分看：既包含2023年从0起步做新项目的操盘逻辑，也加入了2024年团队对市场的最新观察和判断。

如果你手上做的就是图书业务，可以直接跳到第八部分——那里是他今年对图书行业规划的核心思考。但如果你真正想搞懂的是抖音短视频付费打品，建议别跳，从头到尾啃一遍。这套方法论完全可以迁移到图书之外的赛道。
