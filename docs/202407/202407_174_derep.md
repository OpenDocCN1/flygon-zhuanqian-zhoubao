# 小红书航海结束后，我给Mac用户自制了一套实用小工具

各位伙伴，在下香君！作为今年刚迈进生财圈子的小萌新，五月的航海算是我在这里的首秀。整趟旅程下来，闭环是顺利跑通了，可离期待的“大结果”还差点火候，心里难免有些小失落。

但换个角度想，这趟船没白上！翻着航海手册，我反而脑洞大开，接连捣鼓出了几件挺趁手的小工具——尤其是Mac用户们，这回可算轮到你们享福啦！实不相瞒，我自己就是Mac党一枚，教练们推荐的那些工具，几乎都是照着Windows习惯来的。Mac用户想省事？只能一边跑流程一边自己动手改呗！

所以我干脆撸起袖子，边跑边搓了几款小工具，现在把完整整理都放在飞书文档里了，想参考的朋友点击下方链接即可：
