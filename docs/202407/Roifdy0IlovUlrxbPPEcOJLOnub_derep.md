# 熬夜刷到一条200万业绩视频后，我靠短视频带货赚到100万：3个爆单模板+1个怪招
作者：龙哥

最近一直在忙项目，已经很久没静下心写长文了。今天想聊的这件事，说起来还挺魔幻——它是我某次熬夜时撞上的一个小商机。都说人开窍需要足够的刺激，这次的刺激，确实够猛。这个项目从0到1跑通以后，到现在已经稳定盈利6个月，业绩还在往上走。

先交代一下背景：我这几年的老本行是📕获客，从21年就开始带团队，前前后后服务过三千多位老板。原本以为自己已经见惯了流量玩法，可去年11月那个深夜，我还是被一位博主的一段视频给“电”到了。

她在镜头前碎碎念，说自己打算放弃那个10万粉丝的抖音情感号，接下来要把一个只有几千粉丝的小号认真做起来。原因也很直白：她之前随手测了一个脖套，居然卖出了200多万的业绩。我当时愣了愣，顺手用考古家翻了一下她的后台数据，整个人瞬间清醒——这爆发力，根本不像一个小体量账号能做到的。

这个小商机是怎么冒出来的？
![](img/7e92a2a17e50e32066b63fb9ad937404.png)
![](img/ef4ede668d538f1d6343f216ee332ed8.png)

后来再去看那位博主，她现在已经做到行业头部，利润同样惊掉了我的下巴。

说起来，我22年也做过抖音个人IP，粉丝大概3万出头，所以我很清楚：抖音的流量和变现，从来不是一回事。200万的单月业绩，如果走直播路线，至少需要2到5个人轮班配合；而她也只是发了一条挂着小黄车的视频，就直接做到了这个数字。利润空间还相当可观。这算什么？这就是带概率的暴利——基本功只要过关，拍100条视频能爆2条。当然，现在这个红利已经过去了。

再放一个当年的例子。22年我在🧣上互关了一位美食博主，叫“秒变食神”，她做创意小菜，主打画面感，好看，但未必好吃。变现主要靠挂车卖调料，200多万的粉丝体量，每月差不多能赚30万。拿这个和“一条视频200万业绩”放在一起看，短视频带货的暴利程度，瞬间就有了轮廓。

当时做这行的人很多，我一度以为风口已经过了，没想到23年又烧了起来。那天深夜，如果那位博主没有提到具体业绩，我大概率会像往常一样，手指一划就翻走了。可就是因为多停留了两分钟，这个项目到现在已经给我带来了100万+的净利润。

方向有了，接下来就是验证和搭建团队。

到了23年6月，我们正式开始测试带货。第一个月，主要在磨合文案、拍摄和选品，一共卖出了78单。数据不亮眼，但流程跑顺之后，第一个大爆款说来就来。那是一款非常冷门但利润很足的S型牙刷，单价39元，毛利大概30%。一条视频上去，直接带来8万多利润；有整整一周，每天醒来都能看到1万多的佣金进账。再往后两个月，账号基本进入爆单节奏，搓澡巾、静电刷子，一个接一个跑出来。

说回正题，分享一下我总结出来比较好用的短视频带货模板。

比较好用的短视频带货模板
![](img/08db10e2acda3bde8e4ae75a275647e8.png)
![](img/38f8b405decb873ae9fa125e05e34154.png)
![](img/94c002f472dd6535de83f8555990338c.png)

先坦白，能跑出来也有运气成分：我的文员本来就有直播底子，既懂内容又会写文案；加上我从身边朋友手里要了几个热门品，账号摸索一个月就开始爆单。我们当然也不是一开始就拍得多精致，而是从很粗糙的1.0版本，一点点磨到3.0版本。所以刚开始做，千万别追求完美，先让事情跑起来，再慢慢优化就行。

第一个模板，我叫它“3秒可视化模板”。文案第一句想抓人，确实很难；但用前面两三秒抓人，就简单多了，尤其适合新手。如果产品本身够猎奇，那就把最吸引眼球的东西放到最前面。例如S型牙刷，我们开头用的就是很让人好奇的画面：面部抖动幅度非常大，一个普通日用品被拍出了“从没见过世面”的感觉，用户自然想继续看下去。这个模板，几乎可以套用到任何价格的产品上。

![](img/dba2358ee5894fb79443d3dded29f8bb.png)

为什么好用？因为短视频的停留数据太关键了。前3秒能留住人，用户对产品产生好奇，后面才卖得动；一旦开头抓不住人，就算爆品在手也白搭。具体怎么安排？要么从产品卖点出发，要么把使用过程放大到足够夸张。

说起这个爆品的发现，也挺巧合。文员在刷一位卖牙膏的博主时，注意到S型牙刷特别吸睛，但她去后台一查，发现卖这个品的人并不多。我让她赶紧找商家寄样，她居然凌晨就去对接了。拿到样品后，我满脑子想的是：怎么拍，才能让人一眼难忘。

一个这么奇怪的品，开头就得演出一种“这玩意儿我从没见过”的震惊。我们用了黄金三秒，放了两个夸张动作，画面张力十足，用户看到后会忍不住好奇：牙刷怎么还能竖着刷？文案上，我先说“我自己也没见过”，然后拿出普通牙刷做对比，让观众想到自己平时用的牙刷，顺势点出普通牙刷伸进去打圈的弊端，再介绍S型牙刷的卖点——竖着刷也好刷。紧接着抛出第一次用时的质疑，再把设计原理讲清楚。这一套下来，用户心里的疑虑被打消得差不多，最后再补上其他卖点，让人产生猎奇感，货自然就卖出去了。说白了，这正是我玩自然流量直播时常用的勾子框架。

流量跑完之后，那条视频一共带来近10万佣金。而且这个模板不是偶然，今年5月我们又靠它打爆了一个品，单品业绩同样冲上100万+。

第二个模板，叫“适当争议爆单模板”。我们的第二个小爆款是搓澡巾，利润大概2万多。那条视频的文案是故意设计的，第一句话就精准圈住人群，同时把南北方的争议引爆。文案写的是：“南方有品位的女生们~~~~”说者无心，听者有意，有人觉得刺耳，再加上搓澡巾本来就是一个常年被拿来讨论南北差异的产品，不爆反而奇怪。这个模板，各种价格的产品都能用。

![](img/7489bca61b434e5972dd28566cfd88de.png)

操作要领是：先找到真正的矛盾点，写出一句足够有力、但又不会被举报的话术，同时做好控评；评论里保留一些吐槽但不激烈的网友评价，让评论区的底层数据动起来，成交数据自然就跟上来了。尤其是像搓澡巾这种冬季必买、自带风俗习惯、还带着地区文化对立属性的低客单品，购买决策非常轻，人数一下子就上去了。

这个模板值得二次验证。我又照着同样的逻辑，把一个低客单的搓澡巾再次卖爆，靠的就是开头那一句话，瞬间点燃评论区。由于那个品根本没法投流，全程都是自然流量。后来我就总结出了一条经验：评论区的争议，是能直接刺激销量的。

第三个模板，叫“三秒秀痛点模板”。那条视频的设计感很强：文案和产品动作完全同步。第一句话是“发明这个梳子的人，真的是配享太庙”，讲到第3秒，梳子上的头发正好掉下来。伸缩梳的核心卖点是头发瞬间掉落，而梳头发的最大痛点就是捡头发，这就等于把痛点前置到了最开头。画面设计很妙，品也跟着爆了。

这类产品在塑品时，只要先找到痛点，再通过行为动作和语言把痛点放大，就很容易卖爆。毕竟只要有头发就需要梳子，只要头发掉得多就需要这个产品。评论区再保留一些能让网友集体讨论的问题，大家会自然聊起来，流量数据一上来，成交数据也会跟上。这个模板很适合抓人眼球的日用品，甚至只靠空镜展示痛点也行。

小白完全可以照搬这个模板，因为它不用真人出镜，难度不高，只需要一个简单的模板开头，就能把产品卖动，而且比很多精致视频更接地气。

再说一个我们常用的加分项：借助道具放大效果。那个卖了100万业绩的电风扇，拍摄时就加了干冰。这个创意是文员自己想到的，干冰一加，电风扇的视觉效果被大幅增强，很多用户就是冲着那个夸张的“龙卷风效果”下单的。

![](img/dd9f3d8b3fa6797120ffc46650bd0049.png)
![](img/0be5e7b5cd13cdb749f1bac7557efae8.png)

还有一款牙膏，拍视频的时候故意戴了一个很抢眼的发箍，目的就是让用户多停留一会儿，业绩也跟着起来了。这个品利润不错，也再次说明：画面带来的停留，真的太重要了。

![](img/c19d55ca6ebb9ddec9dab3d55b019501.png)
![](img/c6ba034e98668ebb7815eb53cc7e1500.png)

最后，我再说一个压箱底的偏方。很多人拍短视频时，会不自觉地带出营销味，包括我们的爆款，一开始也是这个状态。那人在什么情况下会完全没有营销感呢？答案是：在很困、特别想睡觉的时候。

让我赚到10万佣金的那条S型牙刷爆款，拍摄时间就是凌晨。当时我困得不行，手机一架，10分钟就拍完了，第二天睡醒才剪辑，结果爆了。那款牙膏的视频，同样是在凌晨拍出来的。在那个状态下，你唯一的念头就是赶紧拍完去睡觉，表情和状态反而自然得不得了。你们说，是不是还挺神奇？
