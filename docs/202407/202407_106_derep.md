# 管人的核心，是管情绪

很多人管理团队，盯的都是KPI、流程、奖惩制度，却忘了最底层的杠杆其实是情绪。

你对下属说了什么不重要，重要的是他听进去的时候是什么心情。心情对了，执行力自然上来了；心情错了，再完美的方案也会被阳奉阴违。

管人从来不是管行为，而是管行为背后的情绪动因。一个人为什么拖延？为什么消极？为什么不敢说真话？往往不是能力问题，是他在害怕、委屈、没安全感。

所以真正会带人的人，做的第一件事是情绪诊断。

开会前先感受房间里的气场，是松是紧，是有劲是泄气。复盘时不急着找原因，先让情绪落地。有人需要被肯定，有人需要被倾听，有人需要被授权兜底。情绪对了，人就活了。

管理者的情绪更是放大器。你焦虑，团队会慌；你平静，团队才稳。你的一个眼神、一句语气，能瞬间把士气拉满，也能瞬间把人打退堂鼓。

别再谈什么高情商技巧了，管情绪的核心就三件事：先稳住自己，再看见对方，最后把情绪转化为行动的能量。

因为会管情绪的人，才真正会管人。
