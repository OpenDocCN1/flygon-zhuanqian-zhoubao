# 金融老兵离场，在Crypto世界里找到第二次职业生涯
作者：龙哥

各位圈友，我是龙哥。曾在传统金融机构里做了十年分析师，2021年年中决定切换跑道，投入Web3创业。这是一篇迟到许久的复盘，我会尽量把一个传统金融人的观察、试错和判断讲清楚，希望能给正在观望的伙伴一些参考。

（声明：本文提到的任何内容均不构成投资建议。投资有风险，入市需谨慎！）

去年夏天，我告别了做了十年的分析师岗位，正式启动了Web3创业。彼时的宏观环境远没有今天这么黯淡——中概股还没遭遇大规模回撤，港股也没有跌到接近2008年金融危机的水平，日元依旧坚挺；而“元宇宙”还停留在模糊的概念阶段，NFT也仅仅是一小部分人讨论的词。

### 为什么离开老本行

我之前所在的公司，同时涉足传统金融、风险投资与前沿科技。2020年疫情一来，业务线陆续缩水。客户普遍缺乏安全感，比起投资回报，大家更在意保住本金，谁也不敢把钱投进持续下探的市场里。

不过，也正是因为在金融和科技两个领域都有积累，2021年上半年，我对市场风向的变化保持高度警觉。我几乎每天都泡在研报里，试图从信息中筛出真正有价值的信号。

### 当时重点关注的四个方向

**跨境电商**——这个行业今年最贴切的形容恐怕就是“卷”字。亚马逊封店潮直接洗掉了一大批卖家，Shopee砍掉了不少校招名额，TikTok那边的价格战也打得惨烈。2019年那种随便铺货就能赚钱的年代已经不复返。沉淀之后，行业比拼的是供应链和品牌力。SHEIN能跑出来，靠的就是极强的供应链整合能力，收获了大量海外用户。国货出海这件事，我认为长线依然有戏。

**VR/AR**——谷歌、腾讯等巨头陆续下重注做VR研发。为什么这个赛道突然升温？核心原因是元宇宙概念在2021年爆发，VR被视作进入虚拟世界的入口。谁先攻下技术壁垒，谁就握有Web3布局的主动权。不过，设备笨重、体验粗糙等难题还没有解决，现阶段离大规模商用还有距离。但顺着元宇宙的热度看，VR、AR、虚拟人和数字人赛道的爆发，只是时间问题。

**新能源**——新能源车今年彻底破圈。马斯克靠着特斯拉冲到全球首富，蔚来和小鹏也先后在纽交所挂牌。无论从日常渗透率还是政策扶持力度来看，新能源都处在长期上行的通道里。对有技术积累的朋友来说，这正是搭上红利的好时机。

**Web3**——如果要给Web3一个简单的定义：它是一套基于区块链的互联网生态，并且可以和现实世界产生互动。2021年元宇宙、NFT、DeFi轮番刷屏，国内外科技圈集体亢奋。马斯克收购推特之后放话要做Web3社区，Meta等大厂也在持续加注元宇宙。虚拟与现实交融的趋势已经肉眼可见，这个过程会催生无数新岗位，也给了很多普通人翻身的机会。

### 从观望到下场

老业务持续萎缩，公司账面越来越难看，如果不找新出路，可能真的要走清算程序。就是在这段时间，我接触到了Web3——它像是黑暗里突然透进来的一束光。

2020年货币大放水之后，一级市场反而陷入一种尴尬：好项目稀缺，大量资金追逐少量标的；创业公司这边，融资难、烧钱快成了常态。二级市场的处境更惨烈，2022年3月进入加息周期后，不管是互联网大厂拿着期权的员工，还是重仓中概股的投资人，资产普遍缩水八成。公司能做的只有降本增效，硬扛寒冬。看看今年校招的惨状，就知道现在有多卷了。

在那之前，我也跟风试过TikTok跨境电商（GB站）。TikTok直播功能刚推出来的时候，不少VC同事很兴奋，觉得可以把国内直播带货的打法复制到欧美。但大家都忽略了语言文化差异、高昂的海外人力成本、同行之间的低价搏杀。最终项目被拖成烧钱机器，客单价低、利润薄，怎么算都撑不住。现在TikTok把战略重心挪到了东南亚，我依然选择观望，不急着进场。

![](img/7390f5ba809c80fb8127ed27b8af0d5b.png)

真正让我转向Web3的契机，发生在2020年之后。老业务流失严重，公司必须另找出路。其实我早在2015年就接触过加密资产，但当时只是关注区块链技术本身，Web3的概念还没有成形，我也觉得早期项目泡沫太大。后来一位分析师老友跟我聊起DeFi，我突然意识到：这不就是和我金融本行最贴近的应用场景吗？再加上每个季度的研报里，Web3、元宇宙、NFT出现的频率越来越高，我开始认真重估这个领域，兴趣也是一天比一天浓。

![](img/c8b1e4f2f0dac16fe8e56d1c24aac555.png)

跟两位合伙人通完气之后，我决定单独开一条Web3的业务线。我利用以前在金融圈积累的人脉，找到了几个国内Web3初创团队，以新人的姿态扎进去。我的逻辑很简单：只有亲身参与项目，才能真正理解这个行业怎么运转。那段时间我也频繁出入各种Web3线上线下的分享会，认识了不少专注这个领域的VC。从他们那里我确认了一个信息——国内已有一批企业在做Web3尝试，基础设施也在肉眼可见地完善。

![](img/89bba2d8c20502873589bb6eda52699a.png)

当然，大环境仍在收缩。更多企业的探索方向，是把NFT和营销、社交、众创经济结合起来。不少大厂已经推出自己的NFT产品，并试着与线下实体打通。这恰好符合国内一直提倡的“以虚促实”的产业方向。这些观察让我越来越坚定：Web3不是一阵风，它是未来。

![](img/6698b3fa2a678f94ed138c253a30cea3.png)

### 钱正涌来，但熊市也在眼前

我们公司是被形势逼到Web3这条路上的。靠着过往的金融履历，启动资金拿得还算顺利。但新的麻烦紧接着来了：赛道怎么选？团队架构怎么定？有句话说得好，选择比努力更重要。可做选择的前提，是你的资金体量能够支撑你盯住哪条赛道。我虽然亲历过两轮牛熊，但从来不敢说自己的判断一定对，说到底，就是用前沿眼光去押一个大概率。

目前Web3一级市场的真实状态是：钱很多，但值得投的项目很少；真正优质的项目，也根本不缺钱。过去十年，Web3累积了大约3万亿美元的流动性，这个量级几乎可以跟传统风投投出的所有初创公司总估值相提并论。大批专注Web3的基金横空出世，不管数量还是增速，都刷新了行业纪录。有些机构甚至跑出了超额收益——Multicoin就是典型，业绩压过不少老牌传奇基金，手里握着大把现金弹药。

![](img/0638667fd3b723d4c5c7c72ac21376b3.png)

回头看2015年，DCG募了2500万美元，那已经是当时Web3领域名列前茅的募资纪录。现在再看，私募市场上体量已经完全不同了。Polychain、Paradigm、a16z、Multicoin、3AC这些专精玩家，单家管理的资金就是几十亿甚至几百亿美元。红杉、软银、Coatue、老虎、光速这些传统大牌PE和风投，也已经悄悄入场。另有一组数据值得留意：全球大量对冲基金计划五年内把7%的资产配置到Web3；连养老基金这种大体量资金，也开始考虑直投。新旧资本同时加速涌入，这个市场的分量没人敢小瞧。

讲完光明面，也讲讲阴影。任何市场都有熊市，Web3也不会例外。2022年开年，整个行业就在全球加息和地缘冲突的夹击下进入寒冬。不过，经历了2014年、2018年两轮深熊和2021年暴涨的洗礼，市场的心态已经成熟了不少。

![](img/bdb32e611bbd7f23261cf7de011b5c9d.png)

现在的参与者对利空利好的反应，不再像以前那样大起大落。天量资金进场和流动性池增厚，也确实让涨跌曲线平滑了一些。但这轮熊市里，市场照样跌掉了超过40%的市值。被称作“超级蓝筹”的ETH，在2021年12月24日到2022年1月24日之间，一个月蒸发掉46%的市值。刚进圈的新人看到这种跌幅，很难不慌。但老手们的反应却相当平静——这和他们经历过的那些动不动一周跌掉八九十的行情相比，确实温和太多了。

但熊市不会放过任何人。那些上了杠杆、借钱投资的人，真的会破产、会崩溃，甚至会抛掉手上所有头寸，对这个市场彻底失去信心。这个圈子永远人来人往，有人骂着离场，也有人踩着前人的“尸体”进场，幻想着自己能抄到底，等到下一轮大牛市。可现实真有这么简单吗？市场的脾气就像大海，平静时给人希望，翻脸时吞噬一切。能活着穿越牛熊的老手只信奉一句话：敬畏它，和它共舞。

如果你是刚踏入Web3的年轻团队负责人，请务必保护好你的伙伴们，别让市场崩塌的连锁反应波及到每个人。最近的FTX暴雷就是活生生的教训。现在有太多团队把弹药花在表面功夫上，真正该做的事反而一塌糊涂。所以我想借这个机会提醒所有Web3从业者：别浪费子弹。如果你打算去一家有抱负的Web3公司，签约之前，一定要问清楚两件事：公司的赛道是什么？账上的现金能撑多久？在弹药充足的“基建类”公司工作，熊市里绝对是更稳妥的选择。熬过漫长的黑夜，等到太阳升起，你会拿到属于你的那份回报。

### 写在最后

今天的Web3风投，跟传统VC已经不是一个打法。它更像是“资金+孵化+资源对接”的复合体。熊市里，我们公司既做VC也做项目方。从金融风控的角度讲，必须给自己留足容错空间，如果在早期就把所有筹码压在单一方向上，风险很难控制。如果各位有Web3.0资源对接的需要，或者正在寻找相关机会，欢迎联系我交流。

篇幅所限，今天就分享到这里。之后我会不定期在赚钱更新Web3.0的相关内容，欢迎感兴趣的朋友随时来聊，共同进步。感谢阅读，下期见！
