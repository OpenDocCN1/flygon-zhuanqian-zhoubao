# 合伙创业股份怎么分？一个四C测算模型，五个执行步骤，教你算出公平数字
作者：龙哥

很多创业团队在分股份时，靠的其实是“拍脑袋”。谁名气大、谁嗓门大、谁出的钱多，股份就向谁倾斜。但这种分法往往等到公司开始赚钱、准备融资的时候，变成合伙人之间内耗的导火索。

我在社群里翻了不少相关讨论，大多数都在讲理念，很少能给出一个可以照着算的路径。于是整理了一套经历过多个项目验证的测算方法，希望你看完之后，至少能把自家公司的股份结构从头到尾拉出一张清晰的表。

先看两个常见场景。

场景一：三个人想联手做一个覆盖全国的餐饮连锁。有人擅长开店和渠道，有人手里握着独门配方，还有人只愿意掏钱、不参与日常打理。如果你来把握方向盘，是按出钱比例切，还是另想办法？

场景二：四个背景完全不搭边的人凑到一个项目里，分别管产品、管市场、管运营、管融资。每个人都有不可替代的资源，谁也不觉得自己应该少拿。作为牵头人，你拿什么标准让对方心服口服？

如果面对这些问题，你只能凭感觉给答案，下面的内容建议认真读完。

# 一、四C动态测评到底是什么

我推荐的这套工具叫“四C动态测评”。它不适合所有公司，但对于刚起步、团队经验还不多的新项目来说，非常友好。它能把模糊的直觉翻译成一组可以坐下来讨论、争辩甚至计算的数字。

C取自Capital的缩写，意思是创业投入本质上都算资本。资本可以拆成两类：一类是人的资本——能力、经验、行业资源；另一类是钱的资本——启动资金、抗风险能力、后续融资空间。拆开之后，就变成四个评估角度：兜底者身份、职能重要性、精力倾斜度、资金贡献度。这四个角度不是等权重的，会根据行业差异在各自的范围内浮动。

![](img/86936afb478c8488aed5017e653d4f43.png)

**第一，兜底者身份。**任何公司都需要一个最终做决定的人。如果项目失败、欠了供应商的钱、发不出员工工资，最后谁来还债、谁来收拾烂摊子？这个人才是真正的掌舵者。他对公司拥有整体控制权，对外也只有一个最终声音。这个维度通常在总盘子中占10%~30%。

**第二，职能重要性。**不同赛道的胜负手差别很大，有的在研发，有的在销售，有的在供应链。团队必须在“到底哪个职能决定项目死活”这件事上达成一致。产品背景的人容易高估研发，市场背景的人容易高估增长，这种分歧不会写在脸上，却会在公司做大之后集中爆发。趁着还没赚大钱时把重要性排个序，成本最低。经验数值在30%~40%之间。

**第三，精力倾斜度。**全职和兼职只是最表面的判断，更核心的是每个人愿意为项目押上多少时间、资源和社会关系。哪怕同为全职，有人是在玩命投入，有人只是上班打卡，得把预期讲在前面。占比通常在10%~25%。

**第四，资金贡献度。**从公司注册、租场地、招人到产品上线，每一步都要花钱。愿意掏出多少钱，直接反映一个人对项目的信心和风险容忍度。这个维度占20%~50%。

![](img/4b992642f9f28d34f6888d4a4ff9acf3.png)

需要说明一句：上面这些区间来自大量案例的统计，不是铁律。不同赛道、不同城市的参数会差很多。真正落地的时候，要由项目组内部共同锚定一个彼此认可的数值。如果分歧过大，就启动自评加他评来收敛，必要时请第三方主持讨论，别让熟人之间的面子耽误正事。

# 二、五个步骤拆解一个实战案例

下面用一个真实项目完整走一遍流程。

![](img/87d6d7cd8c42a2449dced0b5f6f58652.png)

项目背景：三人打算合伙开一家青少年体适能培训机构。预期启动资金200万元，已经看中了大型商业中心里一个300平米的铺面，计划做成城市首家标杆店。

三位成员的情况如下：

阿哲：做过低龄儿童游泳项目的品牌加盟，懂培训行业的招生、教务和续费逻辑。他是牵头人，全职投入，自己出50万元。

大雷：之前在本地生活服务平台负责商家推广，擅长新店品牌形象塑造、线上投放和门店获客打法。他全职加入，但不愿出钱，想用自己的市场能力来换股份。

老胡：在体制内上班，家里拆迁后资金实力很强。他很看好阿哲，愿意投资150万元，但没法全职参与。

如果由你拍板，这三位分别拿多少股份合适？先把结论公布，再逐步还原计算过程。

![](img/15859acf067aca3df9fd399280f86d63.png)

**第一步：给赛道定性。**项目属于什么驱动类型？可以从两个维度判断：是核心技术驱动，还是资金和规模驱动？是几个成员完全从零起步，还是有上级集团在背后托底？体适能培训非常依赖场地和门店品牌，很难靠某一项独家技术甩开对手，扩张本质上考验的是资金复制能力和运营标准化能力。因此定位为资金驱动型、自主创业型。

![](img/799123b32525d9512ba40ea987793007.png)

**第二步：收集创始成员的基础信息。**角色、过往背景、全职还是兼职、负责板块、出资金额、可动用的社会资源，全部录入一张信息表。这个环节强调数据透明，谁手里有哪些牌，直接摊开看。

![](img/e8d76da515f4c0e8a84cad5670ac4bd6.png)

**第三步：敲定四个维度的占比。**为什么这个案例最终定成：兜底者身份15%、职能重要性30%、精力倾斜度15%、资金贡献度40%？并不是套公式，而是三个人分别做自评，再互相打分，反复讨论之后共同锚定的结果。没有这个前置共识，后面算得再精细也没有意义。

![](img/35b537e85d261b5c7180f5bcfc3822ba.png)

**第四步：为每个人在四个维度上打分。**按1到10分评判，同样包含自评和他评。

兜底者身份：这个分数几乎没悬念，阿哲拿10分。他全职投入、自己出钱，还要负责找场地、搭团队、对接各种资源。项目如果黄了，他损失最大。

资金贡献度：按实际出资额等比换算即可。老胡150万元，阿哲50万元，这轮没有争议。

精力倾斜度：如果只看全职兼职，阿哲和大雷都是全职，但两个人的职责深度明显不同。阿哲要盯整体产品设计、课程迭代和项目落地，大雷主要聚焦品牌包装和门店运营。老胡人在体制内，只能用业余时间对接后续投资资源。三方最终达成6:3:1。

职能重要性：阿哲要搭建整个产品模型和服务流程，是整盘生意的地基；大雷决定门店开业后的客流量和品牌声量；老胡的钱解决了第一轮启动资金，而且之后还能带来投资圈的人脉资源，相当于兼任融资角色。大家互评出来的结果是7:2:1。

![](img/8cd60b8bd7c71eba9a36e1418585df38.png)

**第五步：加权合并，算出最终比例。**把第三步确定的维度占比，乘以第四步每位成员在各维度上的得分，逐项累加，就能得到三人的总股比。最终结果如下。

# 三、最后提醒一句

测算出来的比例，只是一个相对公平的初始分配方案，并不等于工商登记那一版。要把股份真正落地，后面还有一系列配套协议需要设计：决策权要不要绑定牵头人、是否预留期权池、分红和追加投入如何处理、有人中途退出时股份怎么回购、纯财务投资人有没有优先清算权、后续融资能否强制稀释老股东股份。每一项都会影响实际的收益结构和控制权，不能把模型结果直接当成法律文件用。
