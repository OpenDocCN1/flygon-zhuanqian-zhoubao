# 一、重新理解🛰️好友

想年入100万，怎么实现？
有人说要找到1万个客户，每人买100块的东西；
有人说找100个客户，每个人贡献1万利润；
还有人说成交1000个客户，他们每人买100块，再多成交几次；
也有人直接说做梦……

你真的认真想过这个问题吗？有没有想过，其实自己也有机会做到年入百万？
说实话，这个目标不轻松，但确实不是天方夜谭。前提是你先敢想，定了目标再倒推方法，说不定路就出来了。

算销售额有个公式：销售额=客户数×客单价×购买频次。
按第一种思路，你得找到1万个客户。就算你转化率做到了30%（这已经相当厉害了），也要接触3.34万个新客户，摊到每天就是得新增91个客户，才有可能摸到百万营收。
按第二种思路，你需要100个客户，差不多每4天搞掂一单，就有戏。
这么一算，你是不是也惊了：天哪，我简直太缺流量了，赶紧去搞流量吧！

但回味一下你会发现，以前的我们太看重"客户数"这一个指标，把客单价和购买频次晾在了一边。公式里明明写得清清楚楚，购买频次和另外两个变量一样关键！
商业世界还讲28法则：20%的客户贡献了80%的利润。说白了，复购比拉新更值得花力气。

想凑齐1万个客户太难了，你得不断拉新、培育、成交，像个永动机；但找到100个客户容易多了。只要你搞定100个愿意在10个月里每个月给你掏1000块钱的人，年入百万就落地了。
再分享两组真实数据。之前418推广龙哥盟的时候，我公司共有4万🛰️好友，我私人号有3万好友，基本都做私域增长相关。但结果呢？我的私人号转化了80人，公司的资源只转化了20人。公司那边的资源明显更多，成交却是我的1/4。
还有一组：我一个朋友🛰️上只有800个好友，每个月照样成交20多万；另一个朋友好友数3万，月成交却只有5万。前者好友数是后者的接近40倍，成交额反倒不到人家的四分之一。

这两组数据，你品出什么了？
这也是我今年最大的认知转变之一：有信任感、有粘性的好友，远比一堆泛泛之交值钱。
所以今年我开始重视线下，重视面对面的关系沉淀。到广州以后，我只做了4场增长饭局，深度聊了差不多50个人，结果做出了30万的业绩！
而且因为跟用户聊得深、了解透了，合作方式也慢慢长出来了——客单价从以前的几千块，做到了现在的10万块。

我以前操盘群勾搭项目的时候，踩过一个特别大的坑：只给引流产品定了价，后面压根没有高客单价产品接着。实际上，一个客户只要成交了，就有机会产生复购。你要是只有一个SKU，等于亲手把复购的路给堵死了。
所以一定要给自己设计一个高客单产品，利润空间翻上几番不说，这个产品摆在那儿，本身就是一块"站台招牌"，品牌力一下子就被拉高了。
赶紧重新盘一盘自己的产品结构吧，看看是不是能增加一个更高客单价的产品？是不是能加一个让客户反复购买的产品？
然后静下心来，认真去了解你的用户，别一天到晚只想着批量成交。

私域的本质，是长期又忠诚的客户关系。
什么样的关系才能又长久又忠诚？
不是只有用户单方面了解你，而是你们彼此走进对方。
把用户当成朋友，关系才会越走越近。

我的增长饭局为什么现场满意度那么高？
因为我从头到尾都抱着纯利他的心态，到场的每一位朋友，我都帮他们认真拆解流量难题。
有不少朋友正因为围观了我们的饭局流程，也动了自己做局的念头。
当彼此互为客户，这段关系自然就走得长远。

有了这些对私域好友的新认知，你就会发现：其实我们真没那么缺流量，缺的是深度的沟通和真正精准的客户。

# 二、没资源、没资本，第一批客户从哪里来？

前几天我重新翻了小马宋老师的《朋友圈的尖子生》，里头有一段是讲李倩老师的。
当时李倩老师在青山资本做天使投资，小马宋就很纳闷：你都在做投资了，为什么反而拼命强化自己在营销领域的认知，把自己往品牌营销专家的方向打造？
李倩老师的回答很有意思。她说这是个人品牌差异化的打法。她在投资圈里算是"后进生"，那怎么才能挤进尖子生的行列？她观察到一个现象：这个行业里，投资人最值钱的东西其实是流量。
理由是，投资人手里都不缺钱，缺的是好项目。当一个人创业者面前摆着好几个选择时，凭什么选你？当然是因为你有别人没有的优势。
在倩老师看来，投资圈里最大的区别就是流量：创业者在选投资人的时候，看的是你能不能在关键的地方真正帮他一把。
所以她才刻意去放大自己在品牌营销上的标签，这样一来，她就是营销圈里最懂投资的，又是投资圈里最懂品牌营销的——这种差异化的身份，天然就能吸引流量。而且这个吸引速度是几何级的。
她跟别的投资人不一样，她能为创业者提供的，是国内最顶级、最细致、最周全的品牌服务。这就给了创业者一个非选她不可的理由。

你看，个人品牌立起来了，流量是不是就跟着来了？
我自己也一样。在做"增长女黑客"这个IP之前，我🛰️好友只有可怜巴巴的200多人，想找工作估计还得去招聘网站上投简历。可当我有了这个标签以后，很多牛人、大咖反而主动找上门来，给我牵线搭桥、对接资源和项目。
个人品牌一方面直接给我带来了流量，另一方面也让我在各种交往中，快速和别人建立起了信任。
在我看来，垂直领域的专家，完全可以是普通人去够的一个目标。做个人品牌就是普通人最好的切入口！也是普通人起盘最好的起点。

那定位想好了，第一批客户到底怎么攒？
最近有个赚钱圈友来问我：他内容输出一直很稳定，但总是破不了圈，下单的都是身边朋友。他想开一个付费知识星球，可是不知道怎么给星球找到第一批用户。
咱们群里是不是也有卡在这儿的兄弟？
当你手里有内容，却只在自己的朋友圈打转，而且内容还没有好到朋友看了就主动帮你转发的时候，你想向外拓展新用户，几乎寸步难行。
不光做内容的朋友，做产品、做服务的也一样。只在自己的小圈子里发广告，客户从哪儿来？

这种情况，说白了就是冷启动难题。
没有流量怎么办？借。
去哪儿借？我自己验证下来，下面这三个地方最管用。

## 1、去公域平台
把内容发去视频号、👸号、知乎、📕、抖音、快手、B站这些自带流量池的平台，还有行业网站、自媒体平台也行。这些平台上流量本来就摆在那儿，只要你的内容够好，目标用户自己就会找过来。
内容还可以换着花样去表达：图文不行就来音频，音频不够就上视频，图片也行，多换几种形式轮着发。
我有些文章，发在自己👸号上只有一两千阅读，复制到"人人都是产品经理"网站上，反而冲到了几万阅读。而且我做的事特别简单，就是把👸号内容搬过去，稍微改一改。
只要内容有真东西，平台都是欢迎的。
所以说，在没资源没资本的情况下，学会做内容营销，具备写作和拍短视频的能力，就是我们抓住流量的基本功。
这里重点推荐一种内容营销的打法——知识营销。以前做生意喜欢打硬广，现在流行什么？输出你产品的知识，用知识把精准客户吸过来。
特别是那些客户要想很久才敢下单的品类：车、房、家具这些大件，还有各种高客单价产品。最好的营销动作就是持续影响他、培育他，让他在漫长的决策过程中感受到你的专业，等他信任你了，订单就顺理成章了。
另外，短决策产品也照样能用这套思路，日化、食品、服装、美妆这些品类，用知识做转化的例子也比比皆是。

传统销售是什么？主动推销，发硬广，上来就介绍业务，大家普遍反感。知识营销是被动引流——把自己的推广内容化，包装成"分享"、包装成"硬核干货"，甚至连自我介绍都是吸引人的钩子。只要内容真有价值、名实相符，大家不但不抵触，反而很喜欢。

那还有别的路子吗？

## 2、去当群红
我一直觉得，普通人做个人IP，最好用的起盘方式不是去做抖音、📕、知乎、👸号，而是踏踏实实把"群红"做起来。
为什么这么说？
因为抖音这种公域平台的逻辑是算法筛选，平台只会让那些最聪明、最勤奋的创作者冒头，替平台产出好内容。
你要是直接杀去公域，面对的是无限竞争——同行太多太多了，想闯出一片天难比登天。除非你嗅觉敏锐，找到市场空白，或者你的对手还没踏进来的领域，你才能吃到一段时间的红利。但请注意我的措辞，是一段时间！
因为公域做得好的那帮人，太会研究数据了。你这边测出内容模式真香，那边就有一大批人开始抄作业、研究怎么变成自己的。
所以你只能赚到那一阵子的增长红利。如果你没有持续创新的能力，或者没能在这段红利期快速攒下用户信任和规模优势，分分钟被人赶超，淹没在人群里。
这种故事我们见得太多了。抖音上一夜爆红的人有多少？大浪淘沙之后，真正长红不衰的又有几个？
更别说我们这种普通人，没资源、没资本、能力一般、才艺也平平，凭什么跟那么多创作者抢肉吃？

但群红不一样——社群里的竞争是有限竞争。
一个线下社群，成员通常就十几个、几十个，多的也不过几百几千人。你完全有机会在这几十个人里把自己的标签和特点亮出来，让大家记住你。
所以，一上来别总想着做"网红"，先踏踏实实当个"群红"！
在一个几百人的社群里把名气做出来，让大家都认识你、信任你，铁杆粉丝很快就会出现，合作也好、买单也好，都是顺水推舟的事。
我自己的个人IP就是这么起盘的：先把经典案例打出来，再把案例复盘成方法论，然后进各种付费社群，在群里尽量做贡献、分享干货，让大家通过案例认识我。就是靠着这个笨办法，我拿到了龙哥盟、混沌这些社群的推荐位，也因此得到了大量社群成员的认可和信任。
正因为这样，我也特别感恩这些社群的组织者，平时也愿意反复推荐他们……很多事情，本来就是互相成就。
我身边很多人，也一样靠这条路把个人品牌做出了名声。
这种模式最大的优点是容易复制，比去做抖音简单太多了。
所以我才敢下这个结论：普通人做个人IP最理想的起盘方式，真不是去抖音、📕、知乎、👸号刷存在感，而是先把群红做好。
那怎么找到目标客户聚集的社群？我之前专门写了篇文章聊这个，大家可以去看看：https://mp.weixin.qq.com/s/YqUc8g83Jx4hUa_AdBm_Tg

不过很多人方法听了不少，一落地就不知道从哪儿下手。
问题往往出在最基本的一环——他们根本说不清自己的目标客户是谁。
就像刚才提的那位朋友，我问他目标客户是谁，他说有两类：一类是艺术爱好者，潜在买家；一类是艺术创作者。
这就是典型的没把目标客户想明白。
为什么这么说？
艺术爱好者和艺术创作者，这两个词都太泛了。
你拿这两个词去搜社群，绝对搜不到——因为压根没有人拿这种词给自己的社群命名！
那该怎么做细分？
比如把"艺术"逐个往下拆：绘画、音乐、摄影……到这一层还远远不够，继续切：绘画可以分成素描、油画；音乐可以分成钢琴、吉他。
当你细化到"素描""吉他"这个颗粒度的时候，再去搜社群，是不是一下子就容易多了？
把目标人群弄清楚，是做销售、做推广的绝对前提。
分析自己的目标客户到底是谁，这件事值得我们花大把时间去死磕。

聊到这儿，有人要问了：阿may，我社群加了一大堆，流量也没见涨，怎么办？
那就轮到第三种方法了。

## 3、去抱大腿
我的投资人是写《裂变式创业》的宗毅。宗大一直反复讲一句话："人生不要只靠自己傻傻奋斗，一定要有老师，一定要有贵人，否则没有任何机会成功。"这句话我也想送给所有正在打拼的朋友。
我们确实平凡，但如果能与牛人为伍、遇高人指路、获贵人出手相助，那照样有机会变得不平凡。

那大腿怎么抱？
在这方面，秋叶大叔是我学习的标杆。我从2015年就开始关注他，这些年我亲眼看到他身上那股极强的"主动抱大腿"意识。
他本人也在多个场合大大方方承认过：只要遇上比他强或者跟他互补的资源，他的第一反应就是凑上去勾搭一下，看看能不能一起整合资源、搞点事情。
比如他16年写过一篇文章，里面提到了两个人。
一个是阿文。秋叶发现阿文做PPT的水平一流，而他本人也是做PPT的，按说俩人该是竞品，可大叔的第一反应不是防备，而是赶紧勾搭。于是他找到阿文合作做PPT课程，后来阿文直接成了他的事业合伙人。
另一个是阿何。大叔看到阿何的"职场充电宝"👸号涨粉飞快，立刻跑去链接（顺便说一句，阿何老师就是当初推动我做个人品牌的那个人）。
到今天，秋叶大叔抱过的大腿已经数不清了，除了比他厉害的人，还有名人、有资源的企业，像百度文库、百度云、新浪🧣、新浪微盘、微软Office、金山WPS、锐普PPT、PPT美化大师、网易云课堂、网易有道笔记、腾讯、🛰️、罗辑思维……都跟他有过合作。

那我们普通人应该抱什么大腿？我认为要分两层：
1、抱行业的大腿——这是站对风口；
2、抱行业里有影响力的人的大腿——这是找准贵人。

那具体怎么抱呢？
抱大腿千万不能想着用钱去砸，因为大腿根本不缺钱。拿宗大来说，人家身家不知道是我的多少倍，我就算把全部家当掏出来，也够不上他的百分之一。
那用什么换？答案是你得去创造资源、创造价值。
对普通人来说，把一身本事练好，就是最硬的方式。

# 三、怎么撬动10个铁杆粉丝，换来1000个客户

我平时用得最多的招数是裂变。
传统流量红利早就吃完了，获客成本一路狂飙，裂变确实是当下成本最低的获客手段之一。
你要是还在怀疑裂变的威力，看这张图就能明白：![](img/6f3079b4528c7c71e7100f20caff8492.png) 把裂变真正跑通了，那威力真的不可估量。

那具体怎么玩？
我之前打磨过一整套裂变课程，这东西严格来说是一套组合拳，三言两语很难讲透。
今天就先给大家拆一个大框架，重点是掌握底层的结构逻辑。

在我看来，裂变分两种模型：
![](img/2d4ad0d6c0b0fc84889df50186dc513c.png)

裂变这件事，玩法其实分两大类。

第一类叫团队裂变，属于自上而下的结构。讲个大家都耳熟的故事就明白它的精髓了：

怎么迅速拉起一支部队？

毛主席叫来林彪，说：给你个司令当当。

林彪问：兵呢？

主席笑了笑，说：你去找三个军长来。

林彪立刻领会，敬礼说：保证完成任务！

回来后林彪对三个人说：给你们个军长干干。

三人异口同声问：部队在哪？

林彪回：你们去找三个师长来。

三人笑了，握手敬礼：保证完成任务！

随后三个军长各自招来三个师长，九个师长各自招来三个旅长，二十七个旅长各自招来三个团长，八十一个团长各自招来三个营长，二百四十三个营长各自招来三个连长，七百二十九个连长各自招来三个排长，二千一百八十七个排长各自招来三个班长，六千五百六十一个班长各自招来三个战士……

很快，一支近六万八千八百九十人的集团军就成型了。

这个例子就是团队裂变的典型画像，层级分明、上级推荐下级。微商团队、经销体系、社交电商里常用的扩网逻辑，本质上都是这个样子。

![](img/5be74c89eb3f153489bb9252520e029f.png)

这种结构能让人趋之若鹜，最核心的钩子就是诱饵足够诱人——躺赚的想象。

抢先一步入场的人，后期就有可能坐享其成，一个人带起千军万马并非空谈。我身边就有个做社群团购的朋友，就是因为早进场且执行力强，现在一个人月入一百万元，净利润，远超市面上不少百人公司的盈利。这个故事一放出来，自带吸力。

![](img/d730fbc235d74fc6dde3ab2bdbdb04a7.png)

所以机制设计得当，保证底端有货可卖、有单可成交，靠这种模式确实可以做到指数级扩散。

![](img/8badd2ef5f907a3aeeaa35834af7b7cc.png)

第二类叫用户裂变，属于自下而上的扩散。用户之间是社交网的关系，A认识B、B认识C，关系是网状的，不是树状的。

![](img/e8a97c6214021fbcca2496772b8e2378.png)

用户裂变玩的是圈层渗透，往往要因人而异设计不同的玩法。

![](img/a931f97a414828749f80b30f13c6dfc7.png)

我研究用户裂变做了五年多，总结下来主要有两种表现形式：

![](img/a5b37945dca7f7ce7faeb95a05629ea0.png)

第一种是口碑传播，用户没有任何利益驱动也会主动帮你分享。

第二种是利益驱动的裂变营销活动。让员工、渠道、老客户因为明确好处而去分享。

比如活动里可以这样设计：扫码加🛰️送一份用户真正想要的福利，愿意分享到朋友圈就兑现，但绝不强制。福利必须够价值，否则引导再多也没人动。

像我们现在在推的时间捐赠社群，如果开放分享，很多人愿意主动转发，因为觉得内容对朋友有用。

做裂变活动，本质上围绕三种机制来打：

![](img/ece7e508444fee64bf24e41829133985.png)

不同的机制对应不同的路径。我们公司做裂变工具，所以积累了不少打法，常用的是基于企业🛰️的任务宝玩法，也就是好友裂变、赠礼冲榜裂变，基于服务号的分销和赠礼玩法，也就是活动裂变。大家在市场上多半都见过。

但做裂变最关键的问题是，真正有多少人会持续行动去分享。很多活动失败，不是设计不好，而是只撬动了第一层，到了第三层就断了，根本裂不动。

![](img/2a6ee8742f27acff01744b118b841c83.png)
