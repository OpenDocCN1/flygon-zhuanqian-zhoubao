# 【生财认知】

## 【精华】【364赞】搞钱的心法

新年好，我是小排。工作一直很忙，很久没过来跟大家交流了。借着开年的节点，把最近的一些体悟补上。

市面上很多讲心法的文章，其实讲的是方法论。这次我说的，确实是心法。

核心就一句话：你得有种近乎盲目的自信。因为这种盲目的乐观和自信，对创业者来说，是理性的选择。

# 一、看看生财里的顶尖玩家

有没有发现一个共性：赚到钱的大佬，在分享时对自己认知极其骄傲。在他们自己的赛道里，自己就是天花板，别人都是陪练。

比如静水流深，本名惰惰。他那篇《分享3个单人就能做的海外赚钱案例》，语气相当强势，自信到近乎傲慢。可以自己点开感受下。评论区我和他聊过几句，他的回复大概就是“懒得跟你掰扯，我没义务教你，我说的就是事实，你爱信不信”。[https://t.zsxq.com/0arOdzNJq](https://t.zsxq.com/0arOdzNJq)

再比如盗坤，近半年直播里常说“有人说做电商要啥啥啥，抱歉，那你是小弟，我才是大哥”，口头禅还喜欢把别人的教学法贬为“花拳绣腿”。

还有跨境杨少那篇《独创：必胜法之四步打造一个百万爆款》，写作风格和静水流深如出一辙，文中直言“竟然有人大言不惭说这是必胜法”。

我是在吐槽他们吗？完全相反，我很佩服他们。

这种“舍我其谁”“在我领域我就为王”的气场，才是创业者该有的底气。

再看体育界的例子。

# 二、体育圈的启示

前几年男单羽毛球基本就是林丹和李宗伟的二人转。

一个公开的现象：李宗伟在决赛里总输给林丹，尤其是关键战。据统计，两人职业生涯交手37次，李宗伟输了25场，其中包括两次奥运决赛。

李宗伟的技术比林丹差？未必。业内普遍认为两人技术在伯仲之间，甚至有人觉得李宗伟更全面。

那为什么总是输？

他不是输给林丹，是输给了自己。

林李大战其实是两场球同时进行，一场是球场上能看见的那场，另一场是李宗伟内心和自己的对抗。如果潜意识里就不信自己能赢林丹，内战就先输了，外战自然也输。

高尔夫也有类似的故事。

老虎伍兹，曾经不可战胜的世界第一。

2010年，澳大利亚记者罗伯特·鲁瑟提奇出版《不可打：老虎最狂乱赛季内幕》，把伍兹的性丑闻细节全扒出来。用他自己的话说，这故事拍成电影能媲美007。

紧接着就是离婚消息。丑闻离婚后两个月，他丢掉世界第一，随后几年跌出过世界前100，还多次传出退役、长期休战。

丑闻前后的伍兹还是同一个人吗？对对手来说，已经不是了。

过去他光芒万丈、无懈可击。丑闻后，他的潜意识和对手的潜意识，都不再把他当成完美无敌的存在。他输掉了内在的比赛。

# 三、两个自我，两场战役

从这两个故事能看出什么？

这个框架源自《身心合一的奇迹力量》，原名The Inner Game Of Tennis。一位网球教练写的，中文名翻译得偏玄学，被很多人误会。

人有自我一和自我二。自我一是理性的表层自我，自我二是感性的、潜意识的部分。

任何比赛都是双线进行：外在比赛和内在比赛。内在比赛最容易被忽略。

当我们说“我要怎么做”“我今年目标是什么”时，说的是自我一。很多人忽略的是，如果自我二，也就是潜意识，不认同这个目标，就会在内战中落败，内战输，外战必输。

我每年都会定一个跑步减脂的目标。

像我很多人一样，2022年的目标只是把2021年的年份改了一下，2021年又只是把2020年的改了一下。

但2022年我真的靠跑步减了10斤。

差别在哪？2021年前，这个目标是自我一拍脑袋定的，自我二并不买账，甚至抗拒。到了2022年，我潜意识里开始喜欢上跑步，愿意去跑，两个自我统一了。内战赢了，目标自然完成。

再回头看盗坤、静水流深、跨境杨少的表达方式，是不是就通了？

作为顶级赚钱高手，他们早就身心合一了。你看到他们言语里的张扬，其实是内战已赢。潜意识里早已固化“我就是这个领域的王，舍我其谁”的霸气。

# 四、不够霸气怎么办

别慌，心理学有办法。

心理咨询师武志红说过：你曾经达到的高度，就是你能达到的高度。

当你感到怂、不自信时，去翻看自己过去的成功经历，唤醒成功记忆。

比如优秀的销售员，开工前会先挑容易成交的单子或优质客户，先制造一次成功体验，这份体验会带动全天状态。

失败不是成功之母，成功才是成功之母。

说个我的小故事。

我今天在科技行业能混得不错，可能都得感谢我二姨1997年炒股赚了8000块。

那年她赚了钱，买了一台电脑。当时电脑稀缺，我小学三年级就整天霸占着打游戏。

小学四年级学校开编程课，最熟练的就是我这个三年级就玩电脑的。

初中再开编程课，最强的还是那个小学就接触过的我。

高中信息竞赛，最容易拿成绩的还是那个初中就在编程的我。

大学导师选项目人手，最先想到的也是高中编程基础好、有案例的我。

毕业找工作，最容易找到的也是大学积累经验丰富的我。

我常想，如果1997年我二姨没炒股或亏了，我现在可能跟科技行业无缘。一切都是机缘。

我也没辜负这份机缘。一个成功体验连着下一个成功体验。成功，确实是成功之母。

你也一定有过成功时刻。做新事前，花点时间把它们翻出来，唤醒潜意识，它会带你走得更远。

# 五、用生财的正确姿势

前段时间，亦仁发起了一个讨论，大家都在说自己怎么用生财。大部分回答停留在方法层面。

从心态上，该怎么用？

我的答案是：别跪着学，要俯视。把自己当国王，把生财的帖子当奏折来看。

毛主席说战略上藐视敌人，战术上重视敌人。跪着学生财的人，内战先输了。

你见过盗坤、静水流深去小心翼翼地评论“老师好，我看了您文章很有收获，围观您朋友圈，请教个问题，能否指点，不胜感激”吗？他们根本不会。他们一这么做，内心的比赛就已经输了。

战术上要重视。学习别人的帖子、请教问题时，可以说“老师您好，我想请教下文中某点”，这来自自我一。

但战略上，潜意识里要相信的是“朕刚看完你的奏折，有亮点，朕满意。但朕才是这个领域的王者，快详细展开，朕看看如何让朕的江山更强”。

创业本就艰难，盲目的自信和乐观是理性的武器。永远别低估一个高估自己的人。

学会了吗？别拖了，新年已开始，快去翻翻新的奏折吧！

祝愿大家新的一年内心澎湃“舍我其谁”，赢下内战，大展宏兔！

## 【116赞】未来3个月，普通人能抓到什么机会？

大家好，我是花爷。

过年时看到生财已定下下一场线下会的场地，我也在想去年线下的遗憾，今年春天一定要补回来。

花爷在开工会上跟团队说：

我相信春天来了，先干一个春天再说。

因为这个春天，很可能是今年最重要的3个月窗口期。

普通人可能感受不深，但做生意或投资的人基本有共识：

未来3~6个月，是疫情相对平稳期，之后才会迎来第二波峰值。

这个平稳期能持续多久，可以参考香港的数据。

![](img/e65b1ebbf9a0a09a41238621baf64371.png)

香港和内地一样，第一次大规模感染就把八九成居民都感染了。

随后香港进入了2~3个月的平静期，平静期后才进入第二波。

香港的第二波没有第一波那么猛烈，但持续了5~6个月，感染规模约为第一波的50%。

所以共识是，至少2023年春天会是一个相对稳定的期。

之后就不好预测了。

因此很多生意人都在盯着23年春天的节点。

今天就简单聊聊未来3~6个月，普通人能把握的机会。

# 1.

第一个是旅游。

花爷其实在2022年底就说过旅游会回暖，还讲过普通人做旅游分销的事。当时真有会员去做了，赚到钱后跑来报喜。

2023年初，旅游爆发概率极大。

2003年非典后，旅游就直接反弹爆发。

今年春节国内旅游人次达3亿，恢复到2019年同期88.6%的水平。

到春天基本就能完全回到19年水平。

行业数据也明显：出境机票订单量涨258%，入境预定量涨632%，国际酒店预定量同比涨177%。

未来3~6个月，如果你本身在旅游行业，就要开足马力，抖音直播、小红书图文、知乎等渠道全部用上。不会的赶紧学，还来得及，这些景点自带流量。

![](img/24cb6fc0267e2c3764a22fc4f74786a2.png)

如果你不是旅游从业者，想分一杯羹怎么办？

最简单就是做分销。机票、酒店、景点分销都是现成入口。大家出门本来就要买票订房，在你这买你就拿佣金，直接吃大趋势。

另外酒店、旅游套餐的套利，这几个月都很热门。

# 2.

第二个是健康。

疫情平稳期为什么依然看好健康？新冠的意义不只是催生新冠药，而是让大众意识到健康的重要性。疫情后，大家对健康的重视只增不减。

再加上春季本来就是疾病高发季。气候多变，微生物繁殖，学校开学人口流动增加，春季极易生病。约60%的过敏发生在春季。

在这种环境下，保健养生需求会显著提升。

去年就有好几个保健品品牌在抖音销售额破亿。

现在抖音直播卖得最好的是什么？化妆品？服装？

依旧是保健品。

诺特兰德的维生素片连续两个月稳居抖音直播单品销量第一。

健康赛道里，普通人最容易切入的是保健养生带货。

我们社群之前带会员做小红书带货打卡，不少人就是发几张养生花茶的照片，就有人询单了。

养生书单、养生茶、推拿小课、小产品，都是普通人可操作的品类。

自己做养生馆、健康生意的，也要赶紧研究线上渠道。健康类客单价高、利润率高，看身边的中药房春天搞不搞膏方节就知道了。

餐饮的爆发其实大家都能感知到。
