# 七天十万粉、五万现金，我是从围观席上杀出来的
作者：龙哥

落笔这篇时，我进赚钱快三年，却是头一回想把经历摊开来说。十月本该是收获季，别人都赶在月底上岸，我却拖到快月底才登船。那一期我报了三个任务：个人IP、共读、还有🛰️生态里的商品带货。结果挺讽刺——我花心思最多的个人IP，全网才一百来个关注，换来四千块；共读倒是顺顺利利；最没空管的带货线，从10月28号开到11月7号，四个号加起来利润破了五万。

先说来路。我在北京待了整十年，最后做到一间滑冰场馆的区域负责人。冬奥会那个大熊猫形象的亮相晚会，节目是我一手盯出来的；后来又接过奥组委的活儿，去美国协调归化队员。我这边负责的朱易没冲到顶，另一组带回的那位滑雪明星倒成了家喻户晓的名字。2019年我转去杭州，跟着发小直浪学电商，自己试着开直播，网上能搜到的野路子差不多都试遍了，还是没跑出名堂。直到上了某位导师的课，思路才逐渐清晰。2020年自己的盘子稳下来，开始接托管和陪跑，业务多到忙不过来。2021年贪快扩张，底裤都赔没了。这行的真相是：能活下来的托管公司，要么手里有硬货盘，要么背后有愿意分利的品牌方。这个道理，我栽了跟头才明白。现在项目全部停掉，我在长沙休整，偶尔接些陪跑，找新的出发点。

登船前，我把所有业务按了暂停，打算闭关三十天。可惜前二十天，精力几乎全被个人IP吃掉了，带货那条线自然而然成了“围观”。谁料恰恰是这个“围观”，让我放下了预期，反而容易出东西。拿到任务包后，我把群里的聊天记录从头到尾捋了三遍，手册被翻出毛边，站内搜相关词搜到手指发麻。几位老玩家写的复盘文章，每篇起码看五遍，越读越有味道。把所有信息拼起来，能看到一个大趋势：自七月起，很多操盘手都在说收入变差，纯搬素材的号被清理得厉害。这项目的本质，不过是去别的平台找好内容，搬到🛰️生态里换流量和成交。至于为什么收入下滑，我猜一是进圈的人太多，带货短片泛滥；二是平台开始严打重复搬运，不少号被判零播放。既然大路上挤满了人，我就往小路探。

我所在的带货群，赚到钱的船员不少，可多数像买彩票，爆一次然后熄火。大多数人做的是商品短片，靠搬运堆量去赌概率，前期确实能见着钱，后期容易被封，做一波流。商品型内容本身也不容易爆。有位前辈的比喻特别扎心：大家都在同一片水域打渔，坐船的人收大网，岸上的人只能甩鱼竿。这次航海参与者上千，照每人五个号、每号十条商品片来算，水里得添几万条雷同内容。这种密度下，单打独斗就是送。于是我不拼货，拼人群；不硬搬，做重组。四个号同时跑：A号盯二十到三十岁的职场新人，刚出校门，面子薄、钱包也薄；B号攻三十五到四十五岁，怀旧八九十年代；C号围着五十岁往上的阿姨转，用亲情说事；D号是正经卖货号。结果A、B两天播放量破百万，七天内各自越过千万的门槛，到五号六号才真正开始进账，合计两万多；C更猛，第三天越过千万的门槛，隔了两天又冲到四千万单日，一周时间累计过亿，六号开播，到手近三万；D发了二十来条没水花，看其他号都跑起来了，就先放一边。粗略合计，七天涨了约十万粉丝，口袋里的利润五万出头，还在慢慢涨。

关于内容方向，我心里有一套四象限的拆法，把内容分成情绪、趣味、价值、稀有。情绪是让观众看见自己：喜、怒、哀、乐里继续切分，小孩的闹、青年的怒、中年的重、老年的淡，有钱人的倦、穷人的慌，每一支都能往下长。趣味靠反差：白发老头板着脸讲俏皮话，实验室里冒出荒诞结果，都容易让人停下手指。价值给人实在收获：教你烧菜、做表格、接电路，看完不亏。稀有吃信息差：北方人少见南方那款酸角点心，很多人只在传说里听过那种花瓣如血的石蒜科花卉。四个象限往细了分，能长出上千条路。新手常栽在“都想做”上，想一网打尽，结果每条都没影。其实只抓住一个细口，就足够跑通。

想做的事再具体一点。我的做法是先定目标人群，然后从各内容平台里找原材料。从热门内容App到问答社区、种草平台，再到海外产品，都能当原料库。早期上课时我留了份思维导图，现在拿来拆解很顺手。爆款不是凭空冒出来的，底子里多是同一套骨架。这活儿不是凭空发明，而是把别人的骨架拆开，按自己的定位重新蒙皮，再顺着平台脾气调整。连续做四五十条以后，你会慢慢留意到一些没上热门但画面或配乐很讲究的片子，脑子里会自动蹦出拼接的方法。这种手感和判断力急不来，是我前几年做号磨出来的。每天拆一条，时间长了自然见效。

流量起来以后，不少人私信向我请教。我反而观察到一种陷阱：有些人对内容理解得很透，却想得太远。一会儿想情绪号靠什么盈利，一会儿担心亏了收不回来，一会儿要把手里的资源全押上。那些“远处的大山”还没到脚下，先把人压住了。没想太多的人，闷头执行，反而更快摸到钱。我自己有两招赶走内耗。第一，想不明白赛道怎么赚钱，就去看对标账号，看人家怎么跑通盈利，照着抄；第二，不盯着后台焦虑。我给自己的任务是每个号每天至少十组素材，一天只看一次数据，用来判断这一带的用户喜欢什么调性。别忘了，在别的平台火的内容，搬到这儿未必有声量。

号跑起来后，我亲自主播三天。坦白讲，一开播就是收入，一小时能顶好几千，确实容易让人沉迷。但我清楚，如果每天泡在直播间，内容的产出会断掉，流量迟早被自己耗死。加上三个号同时热起来，我只能挑表现最好的那个先播。等到热度从峰值缓下来，直播时长砍到三小时。巧的是，一个南方直播基地的团队在那时找上我，他们正照着我的打法复制。长沙、北京、广州、云南都有人在下场模仿，实在卷。我干脆把加🛰️的人都聚到一起聊，聊着聊着就动了合作的念头。最初也考虑过雇专职主播，可好主播价钱高、账号生命周期难判断、练一个主播的成本也高。基地的优势是现成主播和成熟货源，不如把号交给他们的主播播，选品走他们的渠道，货品成本也能压下来，我只管流量，按比例抽成。试用合同很快就签了，到十号基地代播满三天，我每天都能坐着收钱。

往后怎么走，我心里也画了张图：死磕内容和流量，把号养熟，找合拍的人一起扩量，成熟了就送去基地直播，我不再被镜头捆住。帮基地打造几个可复制的样本案例，再携手去跑商家。当年托管生意冒进扩张的教训太痛，这次不会再犯。寒冬里，学会借力，当一个温饱有余的超级个体，就很安心。

最后，给那些还在泥里挣扎的朋友递句话：🛰️这个内容生态的红利还早，别急着退场。我一个旁观者都能找到缝钻出去，你带着手艺和耐心，只会更稳。找一个细分的群体，沉住气去拆解，扎进去，这个冬天也有火烤。
