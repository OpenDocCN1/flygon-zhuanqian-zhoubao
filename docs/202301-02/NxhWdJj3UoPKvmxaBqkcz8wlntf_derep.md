# 六个维度，看透一门生意值不值得做
作者：龙哥

之前在社群里答应过会持续产出，今天写一篇关于“生意拆解”的思考。上次聊盲盒时点到过一个框架，这次把它完整展开。

任何能赚钱的模式，在我看来都能放进六个衡量维度：拉新效率、成交效率、履约轻松度、单笔收入、利润厚度、回头客比例。这六项覆盖了一门生意从“让人知道”到“让人再买”的全过程。满足的项目越多，生意越健康；能占到四样，基本就算及格了。

先聊拉新效率。它看的是：你投入多少时间精力，做了多难的内容，最终换回多少关注。同样是获客，发一条个人动态可能只用几分钟，但能让成百上千人看见；录一条视频可能花二十分钟，能带来几千次播放；做一场数小时的直播，场观能到上万；整理一套现成素材交给上百个推广员分发，每人也能获得几百浏览；用三天打磨一支拆解短片，播放量可以破万；用一周雕琢一篇种草长文，阅读量能上万；用两周拍一支老板访谈，播放量能到十万。这些都是用相对低的投入撬动大曝光的典型。

再聊成交效率。它取决于成交环节对专业技能的依赖，以及能不能同时面对很多人。带链接的种草视频、文章，用户看完可以直接下单，属于一对多的自动成交；把访客引到私域，用在线商城交易，也基本不用费力。常见的做法还有：先靠内容或开播把人聚起来，再导入私域慢慢培育，用私聊、群发、电话、线下碰面或会议式销售来收单。线上销售这套动作完全可以流程化，按固定脚本执行即可，线下才真正考验个人控场和说服能力。比如说做设计，往往要跟客户反复沟通很久；卖房，辛辛苦苦带看多套，最后客户也未必找你签单。所以，专业门槛越低、越能批量触达，成交效率就越高，本质上是在节省销售时间的消耗。

然后是履约轻松度。衡量标准就是完成一笔生意要占用你多少时间和人力。佣金代发的内容，发货和售后都归商家，你不用亲自处理；卖学习资料或便宜的课程，客户付款那一刻履约就结束了；做社群或知识圈子，则需要长期维护、持续产出内容；做实战营和长期陪伴服务，要精心设计流程、答疑辅导；做生产或代理，得跟供应链、质检、售后打交道；装修一套房子，一个施工队至少忙活一个月；开发一栋楼盘，一群人得忙上半年。占用时间越少、投入人力越少，履约越轻松。

客单、利润、回头客这三个维度比较好理解，这里就不展开了。

下面拿几个实际项目套一下这个模型：

第一类：拉新快、成交快、履约轻松、单笔低、利润厚、回头客少。

网文分销。把小说精彩片段分发到各内容平台，引导读者去阅读平台开通会员，赚推广分成。单月收入通常一千到两万。它的素材到处都是，照模板发就能带来搜索曝光；读者输入专属码开通会员后，佣金自动结算；全程不用自己交付；客单就一二十元；利润能到五成以上；基本没有复购。

学习资料1.0。卖考研、高考等学科资料，单月也是一千到两万。素材同样简单易得，格式固定，自带搜索曝光；把用户引到私域商城转化；付款后自动发资料；客单十几到几十元；利润五成到一倍；几乎没有重复购买。

第二类：拉新快、成交快、履约轻松、单笔高、利润看情况、回头客少。

学习资料2.0。单月两万到百万。相比1.0，多了一步：用资料攒下大量精准用户，然后把线索转卖给高价课程合作方，赚取渠道收益。交付由合作方完成，自己只守着获客渠道；利润率大约一成；基本没有复购。

第三类：拉新快、成交快、履约看情况、单笔偏高、利润不薄、复购不错。

减脂食谱项目。单月十万到两百万。在热门内容平台发减脂食谱，素材简单量大，模板化；转化用标准化网销；如果卖成品，几乎不用履约，如果做减脂陪伴群，则需要有督导员持续跟进，履约会重一些；单笔从几百元到上万元；利润三成以上；因为减肥总要反复，复购表现自然好。

第四类：拉新慢、成交快、履约重、单笔高、利润厚、复购看情况。

商业拆解IP（包括小徐和我自己）。单月十万到两百万。做项目拆解需要大量时间和高质量信息渠道，很难批量产出内容，所以拉新效率偏低；成交环节用标准化网销即可；但后端社群、长期陪伴和合作服务都要投入专业精力，履约偏重；单笔从几千到几十万；利润七成以上；复购方面，长期陪伴通常一锤子买卖，社群则能产生续费。

第五类：拉新快、成交快、履约轻松、单笔高、利润极厚、复购弱。

卖课模式，以李一舟为代表。单月十万到五百万。录制口播视频门槛不高，开播时挂上课程链接就能成交；课程卖出去就算交付完成，顶多连麦答疑；单笔几千元；利润率接近100%；课程偶尔更新，但复购很少。

总结一下：

任何项目都能放进这六个维度来拆。

拉新效率高，说明内容生产的复制性强，可以做矩阵、做培训，把这一环单独拎出来放大。

成交和履约效率高，说明从销售到服务都能标准化，不依赖个人天才，只要曝光进来，就能稳稳接住。这种情况下，收入高低主要看曝光规模。学习资料和减脂食谱就是典型。

反过来，如果三个效率里有一项明显偏弱，生意便难以批量复制，只能靠抬高单笔金额、加厚利润、提高回头率来补。商业拆解IP就是这条路子。

所以，不管你做的是存量生意还是打算启动新方向，都可以用这个模型过一遍，看看短板在哪。搞懂底层逻辑，才知道劲儿该往哪儿使。
