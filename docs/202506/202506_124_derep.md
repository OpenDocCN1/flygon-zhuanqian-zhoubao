# 【抖音】1 篇

这周最让人头疼的，不是工作没做完，而是想找点好东西，却不知道去哪翻。别急，新一期的资源精选已经悄悄上线了。

这一期我们从抖音这个宝库里，只挑出了1条内容。别看数量不多，这条的含金量是真的高——凡是刷到的人，基本都后悔没早点看到。省下来的时间，可比你漫无目的刷半天值多了。

所有好东西都装进了一个链接里，点开原文就能直达，不用东拼西凑、挨个平台乱找。链接用的是语雀文档，排版干净，手机上滑起来很顺手，收藏起来也不怕丢。

当然，这还只是冰山一角。更扎实的干货都藏在『懒人找资源』这个公众号里，还有一个人人都说香的『懒人专属群』，群里时不时就丢出压箱底的存货，基本属于“伸手就能拿，拿来就能用”的程度。

如果你也受够了在网上瞎转悠、好东西总擦肩而过，那就直接关注公众号、进群蹲资源。链接已经放在下面了，自取即可。好东西不等人，早点进去，早点省心。
