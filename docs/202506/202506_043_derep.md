# (41 赞)一文讲透雇主责任险，企业避坑指南
作者：龙哥

各位朋友好，我是龙哥，混迹赚钱圈两年了，干保险这行满打满算第十个年头，做的是独立第三方保险经纪，各家公司、各类产品和渠道资源都能对接到。帮企业省下的保费累计超过两百万，协助理赔的金额也突破了两千万。

2023年4月，经语文王老师引荐进了赚钱，时间不算长，收获却相当大。感谢龙哥老师搭起这个台子，也感谢在这里遇见的靠谱伙伴和年轻朋友，用我自己的话说，脑子像被重新打开了一遍😁。前阵子有圈友在群里说，公司一名已离职的实习生出了状况，差点被人套话赔上一大笔。看到这条我心里一紧，既替恒一老铁没掉坑里感到庆幸，又觉得这类麻烦碰上的圈友恐怕不少——而这正好是我吃饭的本事，于是想写点东西，帮大家把坑标出来。

在谢总和语文王老师的鼓励下，我整理出了这份讲稿，同步给圈里的朋友们，希望大家护好自己，也护好公司，少踩坑、别踩坑。

下面我用最直白的话说清楚几件事：雇主责任险到底是个啥？能保哪些情况？哪类企业最该配？它跟工伤保险、团体意外险差在哪儿？买的时候又该盯紧哪些细节？
