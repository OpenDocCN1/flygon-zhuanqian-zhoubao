最近被一个点点通透了：

## 【AI+RPA = 拥有了大脑🧠，也长出了双手👐】

AI 能帮我们写、能帮我们想，但现实里还有一大堆离不开鼠标键盘的体力活。公众号要排版、商品要上架、图片要批量处理，这些流程每次都得手把手走一遍。Ctrl+C、Ctrl+V 反复来回，累得要死。看到别人视频里手一放，屏幕自己跑、自动抓取评论、自动回复，真的太想学会了。

#### 第一步：让 RPA 学会抓数据

RPA-打开网页

![](img/0d46ba6cf78f2bb6424a58b0e36d47e3.png)

RPA-设置 Cookie

![](img/88ffa43e5205289c63371601c6614124.png)

RPA-筛选数据

做法就是把你平时手点的一步步复刻出来：填输入框、点按钮、鼠标悬停等等。用【Ctrl+鼠标左键】点选“捕获元素”，RPA 就学会了这个动作。

以我的例子来说：进小红书 → 输入关键词 AI → 搜 → 切换到视频 tab → 按评论数排序 → 得到当天排名靠前的列表

![](img/79d413d8abaeaca409acd4a6776ae1d5.png)

RPA-循环相似元素

列表里每一项都要点进去拿视频链接、博主名、点赞、收藏、评论，最后再点左上角关闭。所以要用“循环相似元素”。

![](img/3b5c9434d58d7fe09276cb38295a211f.png)

⚠️ 小技巧：框选相似元素时，用【shift+鼠标左键】把一整组都圈起来，红框会套住全部。在循环里按顺序执行：打开 → 提取字段 → 关闭。

如果一页不够，可以先加滚动加载更多，再套循环♻️。

![](img/26fc2352d66a5c3ba0b5cf22f854217a.png)

![](img/9dd4d0820508f206e122edb726272530.png)

#### 第二步：给飞书多维表授权

教程：https://rpa.bazhuayu.com/helpcenter/docs/vPhs0M

视频教程：

要点提醒：

1. 去 https://open.feishu.cn/app 新建一个应用
2. 拿到 App ID 和 App Secret
3. 给机器人开通飞书多维表权限
4. 在多维表里 右上角… → 更多 → 添加文档应用 → 输入刚建的应用名
5. 多维表 → 分享 → 设为所有人可编辑【⚠️我试过仅打开权限还是写不进去，只有改成可编辑后机器人才有写入权，这个点官方还没明确回复】
