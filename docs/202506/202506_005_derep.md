# 两周从零到上线，我是如何用 AI 把“不会编程”变成“做得了网站”

作者：李澹归
日期：2025-06-08

又来了，报个到。我是龙哥，最近跟着小排老师在做网站的路上狂奔了两周，这篇就是我的实战复盘。

我本身是 0 编程基础的纯小白，目标就是想搞清楚：一个完全不懂代码的人，该怎么用 AI 把产品想法变成能跑的网站。复盘下来，主要聊了三件事：我的成长路径是怎么搭起来的、怎么和 AI 沟通才能真正写出能用的代码、以及这段时间内踩到的几个好玩的点。

比如 Cursor 泄露的系统提示词到底能玩出什么花？AI 能不能自己去扒一个网站结构然后复刻？遇到 Bug 后让 AI 自己定位、自己改，这套思路我也拆开了讲。对正在学 AI、想上手做网站的朋友，应该有些参考价值，也算对下一轮技术浪潮的一次试水。
