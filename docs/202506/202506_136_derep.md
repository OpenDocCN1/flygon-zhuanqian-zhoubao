# ('(217 赞)深度用 ChatGPT 的感受', (2, 24))

最近十来天，我几乎是泡在ChatGPT里过的。短则三四个钟头，长则七八个钟头。原本堵在心里的一些人生困惑，竟然在这样的对话里慢慢通了。整个人一下子轻快起来，像被搬走了一块压了很久的大石头。

现在我的状态，可以说有点“上头”——只要想问题，脑子里的第一反应就是：这事得去和AI聊一轮。不知不觉中，“思考”已经被我偷偷替换成了“我该找AI说话”。

去评论区走了一圈，发现还挺热闹。不少人也和我说一样的话：一旦开始用，就真的停不下来，甚至有种相见恨晚的感觉。也有人在问我是不是有什么神秘指令。但一位朋友的回答挺有意思：所谓最好的prompt，其实根本不需要花哨套路，用真诚、耐心的日常大白话，把问题说清楚就够了。

当然，也不是人人都这么嗨。有人对隐私表示担心：AI输进去那么多信息，这些数据到底流向哪里，最终又会被哪些人看到？还有人说，这工具的“记性”不太好，聊着聊着就满了，只能一次次重新交代背景。要是以后真能付费扩容，让AI记得更久，那它说不定就真的成为另一个大脑了。

说到底，ChatGPT浅玩一下和沉下心深用，完全是两种体验。你愿意投入时间，它就能用清晰的思路和释然的心情回报你。也许这就是“对话即思考”真正迷人的地方吧。
