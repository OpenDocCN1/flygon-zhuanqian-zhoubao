# 0 编程基础，2 小时用 Cursor 做出抖音爆款视频采集插件
作者：龙哥

最近又发现一个让人惊喜的案例：

即使没有任何编程基础，也能借助 Cursor，在短短两个小时内做出一个实用的抖音数据采集插件。

这次使用的是 Claude 4。相比之前通过 Cursor 调用 Claude 3.7，整体体验提升非常明显。过去经常需要反复调试，做出来的插件偶尔还会出现无法正常运行的情况；而这一次，不仅开发时间大幅缩短，操作过程也轻松了不少，最终效果反而更加稳定。

这个插件主要用于采集抖音爆款视频。

只需要输入关键词，它就能自动抓取相关视频信息，包括：

- 视频发布日期
- 视频标题
- 视频链接
- 视频点赞量

采集完成后，数据还会自动整理并保存到 Excel 表格中。

对于做短视频、内容运营或账号分析的朋友来说，这相当于多了一个自动化素材库工具，能够大幅减少人工搜索、整理和记录的时间，搭建素材库的效率可以提升很多。

没有开发经验，也可以尝试借助 AI 编程工具，把自己的需求快速做成小插件。
