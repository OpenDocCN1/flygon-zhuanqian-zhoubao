# (精华帖)(207 赞)都说洞察力重要？那些总能洞察用户的人，到 底是怎么做到的？

商业世界里，如果只能挑一项最值钱的能力，我会把票投给“洞察力”。但很长一段时间，我都觉得这玩意儿靠天赋，天生没有就学不会。

直到上周，我旁观了一位消费品创业者做用户访谈，才发现：洞察根本不是玄学，它是一套有章法的动作，能拆开、能练习，而且步骤比想象中简单。

当时，我们一起和一位哺乳期妈妈聊天。她正被奶瓶折磨得不行——试了一堆牌子，没有一个让她满意。她最关心的，就是喂奶时能不能排气，别让宝宝把空气混着奶吞下去，否则就胀气。

她讲了几个奶瓶的槽点：

有的奶瓶有排气孔，但容量只有60毫升。新生儿第一周喝30，第二周瞬间涨到60，等于买来只能用两周，太不划算。

有的奶瓶排气孔设计在瓶盖侧面，半夜喂奶时得摸黑把孔转到正上方，不开灯很难对准，开灯又会把全家人吵醒。

还有一个奶瓶盖子是方形的，必须四角对齐才扣得上。有一天凌晨她困到迷糊，以为扣好了，结果一倒过来，奶哗啦全洒了。一手抱着哭闹的宝宝，一手还要清理一地白花花的奶渍。

另一个奶瓶排气孔长在瓶底，每次放冰箱，都得找个东西把孔堵住，不然特别容易坏。

就在这时候，那位创业者突然问了一句：“你对奶瓶体验的在意，是不是绝大多数都发生在半夜这种极端瞬间？”

“你想要的好奶瓶，是不是就是能让你少一个操作、少一个意外？”

那一瞬间，这位妈妈明显被击中了，拼命点头说对对对。

创业者接着补了一句：“所以你要的是绝对可靠。只要你认定一个奶瓶足够可靠，你就会买它。”

“可靠”这个词一出来，我们所有人都有种顿悟感。产品怎么做，马上清楚了：排气孔不能放底部，因为容易出问题；瓶身可以做成不对称形状，让排气孔的方向在黑暗里也能靠手摸出来；盖子设计成不用看就能轻松扣合。广告怎么做也清楚了：不用展现什么完美场景，直接拍深夜、手忙脚乱、不必看就能操作的画面，每个细节都在暗示“这奶瓶靠谱”。

这就是洞察带来的巨大威力。

回头复盘整个过程，我发现了一个关键：用户描述的是对一个个奶瓶不满意的“现象”，但现象本身不是洞察。真正的洞察，是现象背后的那个原因，是那种“只要照着做，就会有效”的东西。

那位创始人的做法，是听现象的同时，一直在追问：这些现象背后有没有一个共同的原因？现象可以千变万化，但原因往往少得多，而原因背后的原因可能更少。当她找到一个极简短、又能解释所有现象的原因时，洞察的雏形就出现了。

但这时候想出的原因，也可能是错的。还需要验证。怎么验证？最直接的方法，就是把这个原因讲给用户，如果换来一句“对对对，我就是这个意思”，那么洞察就坐实了。

概括一下，总共三步：

第一，听用户描述，收集各种现象；  
第二，寻找原因，用更简单的原因去解释现象；  
第三，把找到的原因讲给用户，用对方的反应来验证。

走完这个“收集—归因—验证”的闭环，你也有机会碰见真正有价值的用户洞察。所以别再迷信天赋了，洞察力，真的可以练。
