# (172 赞)一条超级标让赚钱把 B 站搞崩可吹嘘
作者：龙哥

以后谁再说龙哥盟只会闷声搞钱，我第一个不服——人家这回直接靠一条超级标，把B站给整崩溃了！这事儿说出来都能当谈资吹一阵子。

说出来你可能不信，一条标书，竟然让B站服务器都扛不住了。这波操作，属实有点炸裂。

事情就是龙哥在2025年6月12号发的动态：因为一条超级标，赚钱直接把B站搞崩了。评论区也是一片沸腾，有人直呼“牛”，有人问“不会真催崩了吧”，还有人调侃“都是你们的错”。有人没看懂问“啥标”，也有人纳闷“为啥”。但不管怎样，这波“搞崩”的成就，已经拿下了。
