# 从剪辑新手到百万播放：我的视频号直播航海复盘
作者：龙哥

大家好，我是龙哥。

今年3月，我参加了视频号直播航海。在应宝芙的邀请下，今天想把这段经历完整记录下来，也希望给正在考虑参加直播航海的朋友一些参考。

先简单介绍一下自己：

- 龙哥盟第3年会员
- 有5年私域社群运营经验，涉及教培、大健康、知识付费等领域
- 曾经通过一次航海项目赚回赚钱门票
- 目前正在寻找一条能够长期发展的自由职业方向

这次航海对我来说，最大的突破是：一个几乎没有剪辑基础的人，靠着持续更新，最终做出了百万级播放的视频，账号也成功增长了1万多粉丝。

一路走来并不是一帆风顺。期间经历过反复试错、踩坑、调整，也不断推翻原有认知，再重新搭建自己的内容方法。

但正是在这些不断尝试的过程中，我逐渐积累了一些实操经验和阶段性心得。接下来会围绕内容制作、账号运营以及后续变现方向，和大家分享这次航海中的真实收获。
