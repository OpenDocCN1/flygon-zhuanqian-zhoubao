# (73 赞)凯文·凯利：当你陷入困境时，就做这一件事

明明已经走投无路，你却还守着旧想法不肯松手？凯文·凯利给出的建议恰恰相反：越是困境，越要敢于让自己“变心”。

他说的变心，不是见风使舵，而是面对重要选择时，坦然承认思路该升级了。能随时修正自己的判断，不是道德瑕疵，反而是一个人真正想明白的标志。

很多人还有一个通病：新点子冒出来的瞬间，觉得热血沸腾，可转头就忘。凯文·凯利提醒，一个新鲜构思从诞生到消失，往往不过五分钟。如果你不在这个窗口期立刻行动起来，它就会被日常琐碎彻底吞没。所以别等“准备好”，先抓住那五分钟。

至于那些真正重要的事，它们通常不会追着你跑；反过来，天天追着你跑的事，往往没那么要紧。凯文·凯利给出的方法是：别用救火的心态去做重要的事。越重要，越要沉住气，按自己的节奏推进。

困境里最需要的，不是更用力地老路狂奔，而是给自己一次换个想法的机会，并趁机抓住那五分钟的灵感。你上一次改变想法，是在什么时候？
