# (23 赞)n8n 整合 FastGPT 补知识库短板

暑假临近，我的教培业务即将迎来一年中最忙的阶段。📕和👸号都得铺开暑期相关内容，可内容生产依然是让我头疼的老大难。

其实我早就把业务流全部搬进了 n8n，但坦白说，n8n 在知识库这块一直是个短板。之前也分享过，目前最适合个人或中小团队的本地知识库方案，还得是 FastGPT。而它最近更新的 MCP Server，刚好可以开放给外部工作流调用——这不就找到了补短板的办法吗？

具体做法：把 FastGPT 作为知识库底座，通过 MCP Server 接入 n8n 工作流，让内容生产时的知识检索和调用直接跑通。详细文档我放在下面了，感兴趣的可以看看。
