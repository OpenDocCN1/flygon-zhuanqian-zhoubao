# (46 赞)YC 合伙人揭秘创业成败与每日进步秘诀
作者：龙哥

YC 合伙人：所谓坚持，其实就是“今天比昨天多走一步”

“坚持就是一切”是 YC 最常被引用的信条。但最近一位 YC 合伙人给出了更清晰的操作版：你不需要咬着牙硬扛什么惊天动地的大事，只要保证自己每天都有一点增量——新知识、新办法、新尝试，哪怕很小，也算数。能做到这一点，即便你以前栽过跟头，或者走过不少弯路，最终离成功也不会太远。

这话传到评论区，不少人直呼“被点醒”。有创业者直言，“坚持”这个词太空洞了，没有抓手，真正要盯住的，是每一天里那种微小的向上移动；也有人特别补充：前提是方向得对、方法不能歪，否则再使劲也可能白费，前进只能算“一丢丢”。更有人当场把这条原则落到行动上：那就先坚持每天打开龙哥盟，让自己的信息来源今天也比昨天好一点。

成功的秘诀，往往听起来简单到不像话，但做起来全靠日拱一卒。每天学一点、做一点、变一点，时间会帮你把“坚持”两个字，变成看得见的未来。
