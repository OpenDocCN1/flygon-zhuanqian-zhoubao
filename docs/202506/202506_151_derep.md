# ('(65 赞)血糖问题继续研究：控血糖就是控衰老', (2, 25))

你有没有想过，为什么同样吃一碗饭，有人血糖像过山车，有人一直平稳？很多人把控糖当成“糖尿病人才需要做的事”，但最新的研究和临床医生都在反复强调一个观点：控血糖，本质上就是在延缓衰老。

为什么这么说？因为血糖的大起大落，对身体来说是一场又一场的“暴力冲击”。血糖一冲高，胰岛素就得拼命加班，长期下来胰腺就像被无限压榨的社畜，迟早扛不住，糖尿病就这么来了。血糖波动大的人，心血管出问题的概率也明显更高，皮肤也更容易冒痘。反过来，那些血糖一直平稳的人，大脑活跃区域更大，反应更灵敏——说白了，就是更聪明。

更扎心的是，血糖如果长期偏高，身体里会产生一种叫“晚期蛋白糖基化终末产物”的东西，你可以把它理解成细胞代谢后的“垃圾”。这种垃圾会加速全身器官的老化，让你比别人老得更快。所以，控血糖=控衰老，真不是危言耸听。

那升糖指数（GI）到底是怎么来的？简单讲，科学家拿50克纯葡萄糖当参照，把它的升糖能力定为100，其他食物都跟它比。测定方法是找一群健康志愿者，空腹8小时以上，喝下含50克葡萄糖的溶液，然后在第15、30、45、60、90、120分钟分别测血糖，画出一条曲线，再用微积分算出两小时内这条曲线下的面积，就是这种食物的升糖指数值。葡萄糖几乎是人体吸收最快的物质，用它当基准，很合理。

不过，看懂GI还不够，生活中要注意的事情更多。我总结了几条非常实用的经验：

第一，吃饭顺序比你想的更重要。GI测的是“单独吃某样东西”，但现实里没人这么吃。先吃蔬菜，再吃肉，最后吃主食，能明显平缓血糖波动。如果进食时间拉长一点，效果更好。

第二，只看GI不看分量，等于白看。西瓜GI高达73，但每100克只含8克碳水；香蕉GI只有52，可每100克含22克碳水，快是西瓜的三倍。你吃同等重量，还真未必是西瓜升糖更多。在家正常切一两片西瓜，完全没问题。

第三，吃起来甜不代表升糖快。水果的甜味主要来自果糖，果糖感受上最甜，但它在体内的代谢路径不一样。相反，有些水果不咋甜，碳水却很高，比如人参果，吃之前最好用薄荷健康之类的工具查一下。

第四，果糖其实也有坑。它会绕过胰岛素，直接冲进肝脏，变成脂肪堆积起来。多项研究显示，果糖摄入过多，会推高尿酸、引发炎症、损伤线粒体、导致胰岛素抵抗甚至脂肪肝。很多饮料用的果葡糖浆就是重灾区，每天喝一罐就是极限，再多麻烦就找上门了。水果里的果糖因为有纤维陪着，危害小很多，但喝果汁、喝饮料是最差的选择。

第五，饭后别急着躺，动一动更好。运动能降血糖，“饭后百步走”确实有科学依据。但运动也是一门技术活，瞎练反而容易受伤——马拉松跑者的横纹肌溶解、足底筋膜炎、膝盖损伤，新闻里都不少见。先学会怎么科学运动，再迈开腿。

第六，血糖这东西，个体差异很大。有人吃某样东西就蹭蹭升糖，别人却没事。最靠谱的办法，是自己戴一个动态血糖仪，记录15天，你就能摸清自己的血糖规律：什么时候会高、什么时候会低、运动该做多少，心里全有数。我也打算自己戴一个试试。尤其是市面上那些号称“低GI”的产品，检测报告到底是咋来的，我严重怀疑很多机构的商业道德，还是自己实测最放心。

第七，别光盯着高血糖，低血糖同样要命。高不好，低也不好，忽高忽低更糟糕。之前就有网红因为低血糖去世，这事真不能不当回事。

第八，别拿“巴菲特天天喝可乐活到90多”说事。基因强大的人就是能扛，可那是人家命好，个例不能推翻普遍规律。也有人极度自律照样早逝，这都是基因决定的，看个例没有意义。

最后，真心建议家里有糖尿病人的朋友，备一个动态血糖仪，三分钟测一次，随时掌握身体情况。这是我好几位医生朋友强力推荐的，我岳父现在就在用，确实管用。品牌我就不推荐了，市面上正经医疗大厂出的，基本都没问题。

血糖稳了，身体才能年轻得久一点。从下一顿饭开始，把顺序调整一下，把份量看清楚，把糖控住，也就把衰老按住了。
