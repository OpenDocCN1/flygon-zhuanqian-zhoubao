# AI原生时代的内容生产：别急着让AI“干活”，先重新设计整条流程

前天晚上，社群里的消息一直没断：有人在调试网络，有人在赶制第二天的“课前作业”，凌晨一两点还有人发“终于搞定了”。要不是亲眼见到这种备战状态，我还以为这是哪个高三班级的考前冲刺夜。

但这场“大考”的科目，是AI原生。

过去半年，风向转得极快。眼看着大家从“万事不决问AI”，一步步走向“让AI独自跑完、我们只做把关”，这种变化连我都有点措手不及。所以这次大课，主办方特意请来了三位真正在一线跑过AI业务的人——包子、叁斤、楚川，让他们把AI原生时代的内容生产逻辑，一层层拆开讲清楚。

这篇笔记，是我在这场高密度课程里记下的核心。内容比较长，建议先收藏再慢慢看。


## 01 | 包子：当AI的“伯乐”，别只当赶马的人

包子老师是典型的超级个体，一个人撑起一整条内容线，产出效率比很多百人团队都高。整场听下来，心里最重的一击不是某个炫技操作，而是开场那句认知纠偏：

**大多数人并非不会用AI，而是仍旧按旧世界的习惯在指挥它。AI跑得越快，你手头的“半成品”反而越多，自己也越累。**

做到AI原生，不等于让人去迁就AI，而是让AI长进你的业务骨骼里，成为生产链路的一部分，而不是外挂在旁边的一件工具。

![](img/56018c639b6cb56ecd95fa05f543ded5_0_0.png)

### 1. 听懂“apple”之前，先别谈原生

课上有个类比特别直观：你听到“apple”这个英文词，脑子里先把它翻译成中文“苹果”，再去想象苹果的样子——这不叫母语者的思维。只有当你听到“apple”，不经过任何翻译，立刻明白它指的就是那个圆圆的水果，这时候你才算在用母语者的方式思考。

AI的用法也一样。

把AI当工具，是写文案、做客服、查资料，本质上是给旧流程多加了一颗按钮；而AI原生，是让AI变成一个环节，长在整条生产链路内部。

**AI原生，不是让AI帮你把旧活干完，而是让你把这份活重新设计一遍。**

通向原生有很多把手：知识库、上下文、工作流、人机分工、数据驱动。真正能放大能量的做法，是把手叠起来用。比如包子就把知识库、AI音乐、AI数字人组合在一起，做出了趣味感很强的报考专业介绍视频；再往上，他甚至搭起了一整套升学SaaS，AI在直播优化、自动回复、客服系统里全程跑着。

### 2. 千里马常有，“伯乐”太少

AI的能力上限，已经高到可以看作一个全能型专家。但为什么到了很多人手里，它就跑不动？真正的问题不在AI身上，而是我们一开始就给它套了太多绳子。

课上把这根“缰绳”拆成了四股，可以对号入座：

*   路径依赖：习惯把工作切成A、B、C、D、E，只让AI碰其中一小段；
*   工具视角：把AI看成写写文案、做做客服的软件，而不是一个有判断力的协作者；
*   信任不足：只给它很窄的上下文，只许它回应眼前这一个问题；
*   控制欲太强：目标、资料、判断、拆解、推进、验收全攥在自己手里，AI只能听命行事。

松开绳子，不是让AI乱跑。真正的放开，是给它一条能跑的赛道：**完整的现场、清晰的目标、明确的边界、可检查的结果。**

### 3. 为什么用了AI，人反而更累？

包子讲了一个自己踩过的坑，现场不少人听完都说“这不就是我吗”。高考前有一批视频要赶，按老流程走——写稿、录制、剪辑、字幕、特效，时间根本不够用。他第一反应是让AI来帮：写稿快、起标题快、整理素材也快。每一步都提速了，但最终视频还是出不来。

为什么？

因为AI交出来的全是半成品。稿子有了，未必适合口播；口播顺了，未必适合上屏；上屏文字有了，视频风格又接不住。半成品的零件越堆越多，最后还要他这个“总装工”来收尾。当时他说了句很扎心的话：**“我以前最强的能力——剪辑判断，恰恰变成了这条流水线上最大的瓶颈。”**

### 4. 真正的转变：把自己从生产链里抽掉

他做了一个关键实验：先不追求完美，让AI从头到尾输出一版——文字、上屏、数字人口播、画面节奏、特效剪辑，全部交出去，他只坐在屏幕前看最终的成片，判断大方向。

结果确实不完美，但已经“不是不能用”。不完美没关系，重要的是它第一次从一堆“原材料”变成了“成品”。手里有了成品，人才能做判断。

从那一刻起，分工彻底变了：

*   AI承包：批量执行、初版生产、素材整理、组织拼接，跑出第一版；
*   人只把守：方向、标准、审美、业务判断、终审验收。

最后他拿到的不是一条视频，而是一条可以复用的视频流水线：资料进入 → AI生成草稿 → 系统预览 → 人工审核 → 修正沉淀 → 下一单复用。

现场还有几个可以直接带走的认知：

*   工作流不必自己从零构思，可以直接问AI：“针对这个项目，你觉得咱们怎么分工更合理？”让AI先把协作方案拉出来。
*   先跑通最小闭环，再谈生产闭环。一张图能跑通，只代表这条路存在；能做到每天稳定批量产出、失败可重试、结果可追踪，才说明它变成了可以放心交给团队天天走的产线。包子后来把流程搬到云端，挂上飞书，@一下就能出活，那是从“在家试做一道菜”到“餐厅后厨稳定出餐”的质变。
*   AI Coding的核心，是用自然语言把事讲清楚。提示词模板的价值正在下降，真正稀缺的，是你能不能把“要什么结果、什么不能碰、谁负责什么”描述得足够准确——准确到让AI都挑不出问题。

## 02 | 叁斤：把个人经验，变成一台7×24小时运转的获客机器

包子解决的是人和AI之间怎么分活，叁斤解决的则是活干完之后，经验怎么沉淀成AI随时能读取、还能持续进化的资料中枢。他给这套系统起了个名字叫AI内容获客系统，但坦白讲，本质跟获客关系不大——**它不是教你做爆款，而是让你手里那些零散的个人经验，自动长出复利。**

### 1. 为什么老板一定要自建AI资料中枢？

叁斤直接戳了几个几乎每个老板都会痛的伤口：

*   **经验记不住，也留不下。** 和客户聊完，对方提了10个需求点，当场只能记住最要命的1—2个，回来就剩个模糊印象；上课学完，笔记零零散散，过几天再想复述，步骤已经拼不回来。
*   **经验全在老板脑子里，团队复制不走。** 小团队和个体户最大的难题，是招人难、带人更难。产品卖点、客户案例、做事套路全装在老板一个人的脑子里，员工想帮忙也使不上劲。让员工写📕、朋友圈，写不出老板心里那套东西；老板自己下场，又缺少专业运营的感觉。
*   **AI用了一堆，却落不到自家业务上。** 谁都知道现在的AI很强，但没人告诉你该怎么把它接进自己的生意。工具安装了不少，最后真正在用的还是ChatGPT、Claude的网页对话框——聊完关掉，下次又从零开始。

而有了一套资料中枢，链路就完全不同：客户聊完，所有需求自动沉淀；课程学完，语料自动提炼成方法论，反复调用。**一份输入，哪怕只是一段录音，可以被循环利用无数次。**

这里他特意强调了一句：**真正的差距不在模型。** Claude、GPT、Gemini、DeepSeek谁强谁弱，真没那么重要。模型迭代太快，今天最强，明天就可能被超越。真正能沉淀下来为你所用的资产，是这一整套系统，而不是某款模型。

他举了个客户的例子：做旗袍定制的老板。以前款式卖点、客户案例全装在老板脑子里，员工写文案只能平铺直叙堆材质。搭好资料中枢之后，AI自动从库里调出产品卖点、客户画像、定制过程，写成结构清晰的文案——同一批运营、同一个产品，差别只在于背后有没有一套“懂卖点”的资料库。

### 2. 这套资料中枢，具体怎么建？

整套搭建过程，可以拆成“选工具→搭骨架→喂内容→三个进化机制→跑通闭环”五步。

#### Step 0：两个核心工具就够了

*   一个能操控本地文件的AI客户端：可以选Codex，也可以用Claude Code，任选其一，不用纠结；
*   一个本地化的知识库：Obsidian，支持结构化展示、移动端同步（iCloud或云同步均可）。

为什么说非Obsidian不可？因为知识库的核心前提是“AI能读”。Notion、飞书这类云文档，数据在云端，AI读不到；Notebook只能查，不能往里补；Cursor和Trae不能可视化，也不能移动端同步。用一句话来记：**Git是给AI看的，Obsidian是给人看的，两者搭配使用。**

#### Step 1：搭骨架——六个底子库+访谈机器人

先建好六个最基础的库：①个人老板说明书 ②产品库 ③客户需求库 ④素材案例库 ⑤方法论库 ⑥内容生产库。这是地基，一定要有。

刚建好的时候，里面是空的。这时候跑一遍“访谈机器人”，让它像采访一样把你问一圈，把你的信息自动归类填进去。从此，AI才第一次“知道你是做什么的”。后面所有自动分类、自动剔除无关内容的逻辑，都从这一步长出来。

#### Step 2：喂内容——把别人的好东西也收进来

*   图文内容（👸号、推文）：用网页剪藏插件，在浏览器里一键采集进Obsidian；
*   视频内容（抖音、📕）：用工具抓逐字稿，会员还能直接同步到Obsidian。

收进来之后，再跑一遍音频整理技能，自动归档成方法论。

#### Step 3：三个进化机制

这几条是整套系统的精华。资料库存久了，会有三种毛病，要用三个机制来治：

*   **让AI调取更准 → 主题分类+双标签。** 不要按来源分，比如“某本书的笔记”“某位老师的课”——AI写销售文案的时候，根本不知道哪本书在讲销售。要按主题分：销售归销售、运营归运营、内容归内容。每篇素材再打两个标签：来源标签（证明从哪来，可追溯）+应用标签（未来用在哪）。
*   **让素材不重复调用 → 三次封顶机制。** AI是会偷懒的，写10篇可能反复调用同一个老案例。规则写死：一个素材最多用3次，用满自动滑入“已过时素材”区。不删除，特殊情况还能调回来。这样一来，素材库就像一条流动的河，有进有出，越跑越厚，而不是一潭死水。
*   **让知识库自我进化 → 定期跑体检。** 六个底子库是通用版本，不会自动贴合你的业务。让AI针对你的业务做一次全面体检，它会告诉你目前缺哪块内容，再由你拍板补齐。

#### Step 4：跑通音频处理闭环

把一段录音丢进“待处理”文件夹，跟AI说“帮我处理”。它会自动判断是长录音、短录音还是多方对话，分配深度或轻量处理，产出选题、方法论、需求素材，再分流进六个库。这一步通了，整条链路才算真正跑通。

### 3. 最终形态：五步自动复利飞轮

把所有环节串起来，就是一个会自己长大的循环：

**输入（聊天/录音/课程）→ AI自动处理并沉淀进六个底子库 → 调用技能产出多平台内容（👸号/📕/抖音按需发布）→ 分发 → 数据回流复盘（拉取点赞/收藏/评论数据，让AI提炼出哪些标题和开头表现更好，沉淀为新的方法论）**

每跑一圈，资料中枢就厚一点，产出的内容也越来越像你本人写的。

### 4. 技能的三个聪明玩法

如果说知识库是“矿藏”，技能就是把淘金动作固化成流水线的压路机。叁斤分享了三个很值得抄的设计：

1.  **让技能织成一张网。** 每个技能跑完，自动推荐“下一步该做什么”。你不用费心去记自己装了多少个技能，跟着AI给出的推荐链路往前走就行。
2.  **十个对标账号取标题。** 起标题最费时间、也最看运气。把10个风格差异尽可能大的对标账号标题喂给AI，正文写完，让它一次给出10—20个标题候选，起标题从此变得可控。
3.  **让AI反向学习你的修改。** AI的初稿你改完之后，别急着直接发。让它对比“初稿vs终稿”，分析你的改动遵循了哪些原则，再沉淀进风格库。你每改一次，AI就更像你一分，下次要改的地方就会更少。

另外还有两个值得记住的方法：

*   做技能不需要懂原理。把流程手动跑一遍，告诉AI“帮我固化成技能”就行；如果你还没有现成流程，可以让AI去GitHub搜现成的方案，它会结合你的定位告诉你哪个合适、有没有风险。
*   保留“半自动”，不要强行“全自动”。重复的活交给AI，但“写哪个选题、发不发、好不好”这类关键判断，必须始终握在人手里。

叁斤也提到，知识库怎么搭，赚钱星球里已经有不少分享。但方法听再多，也不如动手。所以课程安排了整段实操时间，就是让大家都打开对话框，把自己专属的知识库先跑起来。接下来，进入楚川的部分。

## 03 | 楚川：AI内容工程化，把内容做成工业流水线

下午压轴出场的楚川，恰好补上了前两位老师反复提及、却始终没有展开的那块拼图——**判断力**。

包子讲的是“让AI接管生产链条”，叁斤讲的是“搭一个能复利的资料系统”。楚川问的却是更底层的那一问：资料库里到底要装什么，AI写出来的东西才真正像你，才敢让你放心地把判断权交给它？

### 1. 三位老师的两个共识

听了一整天，你会发现三位老师的路径虽不同，但有两条判断高度一致，这或许就是AI原生的底色：

*   **共识一：把整条生产链路交给AI主导。** 不再是人一步步做、AI来打杂，而是把写文案、做素材、出图、剪视频、整理沉淀这些大量执行交给AI去跑。人从一线“亲自做”，退到幕后“设计调度”。
*   **共识二：人退到把关者位置，负责审美和品味。** 叁斤说“半自动而不是全自动，关键判断永远由人拍板”；楚川说得更直接——在审美和质检面前，AI无能为力。所以他们反对一键生成成品，对纯自动化保持警惕。人用半小时审100条素材、100张图、100条视频，融进去的是审美、质感、品味和判断，这是AI替代不了的。

合起来就是一句话：**AI负责大规模生产，人负责最终判断。**

### 2. 最核心的新知：知识库最值钱的，是藏在里面的判断力

楚川把资料库拆成三层，指出大多数人只做了前两层，恰恰缺了最关键的第三层：

*   第一层，信息层。产品参数、定价、使用场景、通用知识——让AI知道你卖什么；
*   第二层，故事层。深度访谈、创始人经历、用户案例、研发故事——让AI知道你是谁；
*   第三层，决策层。用户洞察、竞品认知、自身竞争力、失败教训——让AI替你拿主意。

**这一层，才是整套系统真正的灵魂。**

为什么你的资料库总不太好使、AI常常一本正经地胡说八道？因为你只填了第一层的内容——产品参数、大盘数据、基础知识。AI看不出你的特色，自然做不出你真正想要的东西。一个很典型的例子：“益生菌对肠道有没有帮助？有帮助，但对你没用”——这就是最无效的知识。

什么是判断力？是客户嫌你贵的时候，你准备怎么回应；是内容生产时，AI该从哪个口子切进去。拆开来看，它由四块组成：**用户洞察、竞品认知、自身竞争力、失败教训。**

楚川特别强调，失败教训这一块在知识库里被严重低估。如今AI帮他写口播稿、聊公司战略时，会主动提醒他：过去你遇到类似的情况，是怎么想、怎么解决的。这种对话发生得越多，判断力就长得越扎实。

#### 判断力怎么建？两套资料库+具体来源

这是一套比“六个底子库”更聚焦的分法：

*   **IP型资料库，用来获客、做内容。** 判断力的来源包括：人生转折点、高光时刻、失败教训、被质疑的经历、客户嫌贵时的应对逻辑、三观分析、做人底线。
*   **项目型资料库，用来卖货、做运营。** 判断力的来源有两块，可操作性很强：一是竞品分析——竞品发了多少内容、主打什么卖点、用哪些关键词、走什么链路；二是至少收集500条差评——每一条差评背后，都藏着一个“用户需求未被满足”的缺口。把差评和竞品链路放在一起，可以倒推出适合自己的1～3条路径。

从差评切入用户视角，去补竞品没注意到的地方，天生就有一批种子用户等着被你打动。这也是ROI越做越高的根本原因。

### 3. 判断力怎么让文案长出“人味”？一个真实案例

同样写“跑步”，豆包直出的内容是“跑步教会我的道理”——教科书式的鸡汤，哪篇爆文里都能遇到。但当它加入判断力之后，AI挖出了受访者访谈中的原话：“逼自己跑5公里”“缠了多年的鼻炎慢慢好转”“感受到身心自由生长”——一篇文章立刻有了人味。

结果也很硬核：后者篇幅是前者的2.5倍，拿下了她第一篇10万+爆文（目前阅读已到16万）；4个月里，出了4篇10万+。

而搭建这套东西，用的全是朴素的动作：收集朋友圈高频词、句式、比喻 → 做一次两小时的深度访谈 → 录音转文字 → 交给Claude整理成三万字 → 沉淀出金句库和内容模板。没上Agent，没做复杂动作。

### 4. 判断力会自己进化：结果回填+借力

判断力不是一次写死的，它会越用越强。背后靠的是两个机制：

*   **结果回填机制。** AI帮你设想了10个切入角度，你用了其中6个，且效果很好。把结果反馈回去，AI就多了一层认知——“这个方向可以走”。资料库自己就完成了更新。
*   **借力机制。** 看到别人做出爆款，立刻拆解，融进自己的框架，测试有反馈再迭代。新工具、新流量打法，全都这样被吸收进来。

所以这套体系是越升级越强的。大模型迭代、新工具出现、别人的爆款方法论，都能不断被卷进同一套体系里，持续进化。

### 5. 最后是一个被低估的认知：知识库“没有边界”

楚川最后抛了一个格局更大的观点：**别把知识库锁死在“做内容”这一件事上。** 它最终应该长成你整个业务和认知的操作系统，帮你做更准的决策，跑通更稳的模式。

对传统行业而言，这件事的价值更夸张。把知识库直接接到那些“老渠道”上，相当于给旧管道装上翅膀。和同水平线的对手相比，你已经是降维打击。
