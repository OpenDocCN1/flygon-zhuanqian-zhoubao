# RPA+ChatGPT 自动制作赚钱日-周报&个性化定制关键词推送发帖

捣鼓了好几天，终于把 RPA+ChatGPT 这个组合玩出了点门道——能自动搞定赚钱向的日/周报，还能按你自定义的关键词给你精准推送相关帖子。

目前稿子还差个尾巴没写完，不过等不及先发出来给大伙儿看看，想知道圈子里有多少人对这个感兴趣？具体的操作文档和飞书链接放在下面了，感兴趣的圈友自取。

评论区有老哥也用影刀做 RPA，说太有共鸣了——搞 RPA 最关键也最磨人的地方，就是反复调试。特别是拿 ChatGPT 来配合的时候，网络环境、浏览器种类、哪怕是同款浏览器的不同版本、魔法地址的差异，都可能在编写时跑得好好的代码突然报错。有时候核心功能就 20 行代码，但为了容错和异常处理，硬生生能写出 200 多行。
