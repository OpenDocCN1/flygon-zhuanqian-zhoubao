## 教外国人打造个人 IP，5 人团队年入千万实操复盘

作者：欧佑铭 931

日期：2023-11-09

国内的付费知识赛道早已红海一片，出海却截然不同。只要你能吃下信息差和认知差，把执行力跟上，抓住风口，在海外变现往往比国内更顺。

我现在主做教老外玩 TikTok、做个人 IP 的生意。这个在国内很难做大，同样的交付在海外可以收 4999 美金/人，包含课程、1v1 咨询和训练营。过去一年到上月累计服务 268 位客户，5 人核心团队年收入破千万。

下面把出海全程踩过的坑和落地做法尽量摊开说，在不触碰保密协议和数据红线的前提下，分享选品思路、团队配置、日常运营、后端转化和各平台的优劣，给想出海的人一个避坑参考。

大家好，我是欧佑铭。生财的新人，文笔一般，各位圈友多担待。说的不对的地方欢迎开喷，我脸皮够厚。

今天不扯虚的，把产品逻辑、团队搭建、运营维护、后端变现和各种载体的利弊全盘讲清楚，开船了。

# 一、创始人的出发点和定位

我走过前三家 MCN 的主理人，创业 13 年，企业咨询 8 年，见过太多起落。

我常说一句：选赛道，不要选项目。举个例子，抖音上中视频计划、CPS 短剧、好物分享……这些都是项目，项目本身无好坏，但生命周期短、波动大，还极度依赖操盘方的能力。像 CPS 短剧的某头部机构前阵子不是爆雷了，创始人拿了钱跑路。

之前有人问我能不能抄，我只回了一句：商业逻辑不对，盘面不对，就是击鼓传花，看谁最后倒霉。

太多人盯着项目跳来跳去，却没想过自己的基本盘和长期规划。

**1、为什么要出海**

1、我的创业背景是进出口贸易，跑过不少国家。虽然不算专家，但比大多数人更懂海外老板的思维。核心是汇率。同样做课程+训练营陪跑，国内定价 4999-6999 人民币，需要一通开播、短视频、引流、成交、压单的组合拳。在欧美、北欧、南美等汇率高的市场，卖一单 USD 就顶国内 7 单，投入的时间精力成本却几乎一样。

2、国内卷到内耗：拼服务、拼价格、拼包装、还拼黑同行。

3、心理压力。并不是每个人都能扛住情绪高压。你看网红崩溃的例子很多，连女王 COCO 都抑郁，李佳琦直播翻车。关于翻车原因我另有视频分析。眼不见为净，人家各说各的语言，出海能避开不少国内情绪消耗。

4、出海更容易出圈。资本主义社会贫富差距赤裸，谈钱、谈阶级差距在海外就是事实，而不是国内部分人说的制造焦虑。我们恰恰是利用了这种情绪。

5、我认同一个原则：做难而正确的事。难在于出海有壁垒，魔法上网就筛掉一大批人，没有壁垒 TikTok 早被国内做抖音的卷成一锅粥。正确在于世界的四条赚钱法则：赚信息差、赚认知差、赚执行力、赚核心竞争力加风口。

6、老外先天表达欲强。容貌焦虑、镜头恐惧普遍较弱，这是做 IP 的天然优势。

所以我教 TikTok 运营，本质是信息差+认知差+执行力+风口的叠加。

怎么理解？国内知识付费已经卷到 6.0 了，我把国内成熟的方法搬运、改写、再发，这就是信息差。认知差是国外还在玩完美、如新、美乐家那套 2.0 的模式，这就是认知差。执行力就是矩阵更新，风口就是短视频还在高峰期，元宇宙和脑机还没成熟前，短视频依然是主战场。这就是我对这个项目的理解。

**2、项目定位**

项目形态是出海知识付费，内容主轴是成功学+降维打击。

核心用户是教老外或海外的华人在 TikTok 上做 IP。

目标区域集中在英美、德法、新加坡、加拿大、澳洲。汇率低的地区不做。

用户画像：有钱的企业家、高管、有基本盘的人，有学习意愿和付费能力。没有兴趣、没有一技之长的人直接过滤。口碑在互联网很关键，不能什么人都收。

运营打法：借鉴国内全媒体运营，带他们做海外全媒体。

比如 X、FB、YB、IG、Threads 等公域矩阵引流，承接用 WhatsApp 和 LINE。虽然 LINE 在日韩多，但社交工具要覆盖，不用也可以，但不能没有。

定位和底层逻辑讲完，下面进入实操。

# 二、实操拆解

![](img/77d00d28d7aa8cba4ce4cac7328e1cba.png)

**1、硬件**

个人做的话一台 iPhone 7-8 就够用。

团队作战建议人均 5-10 台，看运营量。工作机不用太好，500 元左右能搞定。京东自营选择多，别去本地水货店，附近维修点买二手更靠谱。

**2、网络**

魔法上网我不教，100%有封号风险，自行搜索。

**3、账号工具**

准备 Outlook 或 G 邮箱，最理想 Gmail，全平台通用。Outlook 也行，注册限制少。

**4、TikTok 养号**

几十台机器实测，发现养号没那么玄。只要有稳定机场就行，机房、私宅、机场都试过。号很玄学。TikTok 注册不像抖音麻烦，号发现不行，0 播放或 <100，直接换号，别浪费时间。初始 200-1000 播放算正常号，可以用。

**5、内容**

我是做知识付费的，定位不同内容不同。对标国内抖音头部大号，直接切片他们的操盘手视频，别发主号物料。吸粉期过后把视频下掉。也可以先发无钩子的版本，有流量再跟上自己的实拍。

**6、多平台分发**

TikTok 以外，有精力就注册 WeChat、YouTube、Telegram、LinkedIn、Threads、X、Facebook。道理同国内 B 站、抖音、快手、视频号、小红书一起发，哪个爆就猛攻哪个引流。

**7、私域承接**

LINE、WeChat、WhatsApp 都要准备。WhatsApp 在 23 年 5-7 月因电诈问题大面积封号，我们也中招。后来改用实体卡，一机一卡。测试过 Tmobile、LYCA、ATT、Simple，最后用 Ultra，月租 3 美元。手机卡稳定后注册海外 APP 畅通。手机要刷机、归属地设成本地。具体设置自行搜索，海外团队不存在这个问题。

![](img/22719554b76bfd5605390e6718ee02bd.png)

**8、收款**

跨境回款不闭环一切白搭。海外收款相对容易，国内监管严，人均购汇 5 万上限。PayPal 容易被风控冻结，虽然钱不会丢，但资金长期卡住。而且 PayPal 不想让钱流进中国。

我们试过万里汇、Ocean、PingPong、花旗 Xtranfer，虚拟类基本被拒。电诈问题严重，虚拟产品直接被拒。

最后走中转迂回。我爱人做跨境电商，有贸易单号。通过 Xtranfer+物流单号回款，贸易类管控宽松，虚拟类严格。我们这边统计学员真实地址寄一本书做实体发货凭证，问题就绕过去了。方法总比问题多。

**9、课程承载与商业模式**

交付价格统一 4999 美金，课程+1v1咨询+训练营。

平台选择踩过很多坑。Teachable、Kajabi、Systeme.io、Thinkific 各有优劣。费用、手续费、操作难度不同。

[`teachable.com/`](https://teachable.com) 升级 PRO 可免手续费，前期免费版够用，但抽 10%。

[`systeme.io/`](https://systeme.io/) 新手友好，一体化，近两年崛起。

[`www.thinkific.com/`](https://www.thinkific.com) 和 Teachable 接近，价格和细节功能有差异，看习惯选。

![](img/024a7b710e4cd1449799f762452e6045.png)

仅解决课程承载，还要闭环流量。

单纯靠自有账号不够。新媒体要么靠作品出奇，要么靠体量碾压。制作周期、人本成本很高，最后选口播，性价比高。完成比完美重要，能持续周更日更比追求爆款更靠谱。用量去怼，提升爆款概率。AI 人像也能用，但我坚持真人出镜，做信任背书。

矩阵操盘手借鉴博商和参哥打法，操盘手几乎都是海外，不做交付只做引流成交。有一套 FAQ，通过内容+评论区截流。不培养，只筛选，学员转操盘手。

国外重邮件！Email! Email! 国内被微信、钉钉、飞书取代，海外邮件营销依然是核心。我们用 ClickFunnels 做核心邮件营销。有些平台自带邮件功能则不用。

操盘手都是我的老学员，信任基础好。我收 4999 USD，给 30% 分润，4 个客户回本。最快老师一周赚 1.5 万 USD。美国现在用美分的日子，1.5 万 USD 是顶级 iPhone 几台的钱。

销售模式只有一级分销，无乱七八糟制度。引流社群成交 50% 抽成，续费 50% 分账。因为我讨厌一次性买卖，没有长尾很难持久。引流为你做嫁衣谁愿意？高手也不愿跟不分钱的人合作。

人聚钱散，钱散人聚。钱赚不完，人品格局是长期资产。阿米巴模式的关键是 IP 魅力+分钱干脆+舍得。别把别人当傻子，否则自己最傻。

# 后记

做项目或选细分赛道，保持三个心态：

第一，长期主义。现在全是存量市场，没有野蛮增长的风口。没有基本盘和团队的人抓不住。别指望今天做明天爆。我的项目跑了 3 个月才摸清节奏，平台、汇率都不可控，做好风控。

第二，兼职就坚持，All in 就盘好基本盘。资源、现金流、学习力、止损点、周期算清楚。长期零反馈只会内耗。

第三，最快成功是找到对标。会搞就搞，不会就学习、咨询、找有结果的人付费。别人几秒能给答案，你自己摸索要几周。用钱换时间还是时间换空间，自己选。

“教人赚钱的都是想赚你钱的人”。评论区常看到这句话。点开头像，要么抖音做成朋友圈，要么私密号，内容不成形。无非职业喷子、黑子、没脑子。我用经验换你执行周期，不行？又不是你爹妈凭什么白嫖？白嫖只有两种可能：你是美女我有图，或你背后资源我有利可图。

成年人要现实。别想复杂，做 IP 和国内一样，不难，难的是主理人敢不敢熬，敢不敢持续周更日更。给自己 30、60 天就别干，现在除非现象级+实事+运气，否则基本盘+时间磨出来。

一天 24 小时，时间从不偏袒人。你把时间花在哪，成长就在哪。没有白费的努力，背后没有捷径。搞它盘它，现在开始！
