# 在编打工人如何用大闸蟹零售+代理双线操作，走上财务自由



## 体制内打工人的副业实录：从卖大闸蟹到做代理，我是如何一步步实现财务自由

作者：帅彬
日期：2023-11-03

大家好，我是赚钱的帅彬。今天把《体制打工人副业靠大闸蟹零售和代理两步走，实现财务自由之路》的完整记录分享给大家。

我家和大闸蟹的渊源很深。姨夫在水产养殖这条路上已经深耕16年，我爸也从10年前就开始养蟹，当年地租便宜一次性签了10年。眼下合同快到期，明年亩产租金势必上涨，考虑到年纪原因，我们也在盘算着是否要缩减养殖面积。

而我自己在互联网上帮卖大闸蟹，算起来正好第五个年头。起步很简单，就是从朋友圈试水开始，靠第一批吃到的老客口口相传慢慢滚动起来。

做这个生意，最值钱的就是复购。只要品质不掉线，客户自然会一直回来。我粗略估算过，复购率长期稳定在九成以上。早期为了建立信任，我也常把断脚蟹、次一点的蟹送给客户，或者以极低价格处理掉。正是这份不玩套路的诚意，让客户愿意从散蟹一步步升级到买礼盒装。

今天的分享里，我主要聊三件事：大闸蟹品质到底该怎么把控、一线养殖户这些年真实的心路历程，以及加入赚钱之后对我生意带来的具体变化。
