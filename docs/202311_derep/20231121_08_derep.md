# 别再争论品效合一，广告本身就生来一体

> 原文：[`www.yuque.com/for_lazy/thfiu8/acqb8vfckr2il9lm`](https://www.yuque.com/for_lazy/thfiu8/acqb8vfckr2il9lm)

问到现在做推广，渠道和玩法都换了个样，哪些该动、哪些该守？

我的看法很简单，变的是形式，内核没变。

二十年前，一家品牌只要敢上央视，名气就能全国扩散。随后铺货找代理，动销自然跟上。那时广告值钱，不是因为技术多先进，而是因为认知差。别人不敢投，你敢投，你就赢在前面。

现在不一样了。没有一个媒体能像过去的央视那样一锤定音，全民共振。媒体碎片化了，流量分散到无数平台。广告的即时爆发力下降了，不是广告失效了，是环境变了。

这也催生了新的打法。

比如暴肌独角兽这个品牌。把市面上常见的零食、重庆小面这些东西，都改造成低热量版本。他们几乎不做大投放，而是去抖音、小红书、电商上狙击长尾关键词。单一个词可能只带来几十万、上百万的销量，看起来不起眼，但成百上千个长尾词叠加起来，总盘就滚到几亿规模。配合强大的供应链，小单也能赚钱，反而避开了正面厮杀，利润被稀释的风险就小了。

说到品效合一，大家的第一反应是：信息流一推，转化立刻来，这才叫合一。对吧？

但品效合一的周期，从来不是按天算的。

你在深圳前海立一块200万一年的大牌子，当天可能看不出效果。但你每天经过，两年后会陌生吗？十年后还能没印象吗？这就是典型的品效合一，只是它的回声很长。

喜之郎就是个活例子。很多年没怎么投放了，你去超市买果冻布丁，名字第一时间还是它。过去十几年累积的广告记忆，在今天还在替它成交。那笔投入的效用，延迟了十年才兑现。

我自己也一样。来这做访谈、出去做演讲，表面是分享，本质也是在给我的咨询公司做品牌。今天跟你聊两小时，不会立刻变客户。可也许三年后、五年后，有个老板突然想起“几年前看过小马宋的访谈”，需求一来就找过来了。这不也是品效合一吗？只是账期拉长了。

所以第二点要承认：不是所有投放都白费，但不是所有企业都有无限的预算。

钱有限的时候，人性就会偏向能立刻看到GMV的玩法。抖音投放、大主播带货，效果当月就能算清。传统媒体就难说，它很难像央视时代那样一炮而红，也很难立刻量化。

于是要做取舍。一方面按预算能力去做分层，另一方面，如果经济状况允许，别完全放弃传统广告。它感知慢，但对长期心智占位的作用，是互联网短期投放补不上的。

如果你非要要一个立刻能看见、立刻能算清的品效合一，那只能押注互联网。传统广告做不到即时反馈，但它在时间上替你存钱。
