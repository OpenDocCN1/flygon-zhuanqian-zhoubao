# 中老年国学知识付费，如何从亏损做到年入近百万？

> 很多人不知道，这个看似“冷门”的赛道，其实藏着一条闷声赚钱的路。

最近跟朋友聊起知识付费，发现大家都在盯着年轻人市场，却忽略了一个被严重低估的群体——中老年人。尤其是“国学”这个细分领域，更是少有人真正讲透。

今天，我就把我们团队做中老年国学知识付费的完整经验拆开揉碎，从行业前景、引流方法、转化成交到交付落地，全部分享出来。不管你是刚入场的新手，还是已经在这个行业里摸索的老手，都能从中找到自己想要的东西。

先说结论：我们现在的销售团队一共21人，整体利润还算可观，投资方也比较满意。但你可能想不到，这个项目真正核心的就三个人——一个管业务，一个管管理，还有一个只管出钱、啥也不干。你品品这个组合，是不是有点意思？

项目刚启动时，我们也亏过钱，但后来硬是做到了接近百万的盈利。
