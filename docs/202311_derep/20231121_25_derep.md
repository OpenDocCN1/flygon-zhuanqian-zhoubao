# ('助力圈友成功转型 AI 提示词实现薪酬翻倍', (2, 23))

这两年就业市场有多冷，不用我多说。可就在大家普遍求稳的氛围里，我身边一位朋友却走出了让人意外的路子：他离开大城市回了老家，身份也从写Java后端代码的传统程序员，切到了人工智能有关的新赛道。最让人意外的是，他的收入并没有因为城市降级而缩水，反而在原有基础上增加了五成左右，公司还免费提供食宿。各项福利折算进来，实际到手的回报，差不多是过去的两倍。

他的新老板对他也寄予了很高的期望，甚至觉得把岗位界定为只做提示词，范围太窄了。于是，入职岗位被直接改成“AI赋能工程师”，职责边界也随之打开。下面这封offer截图里的部分细节，可以佐证这个结果。

![](img/106bf1d4c80b21171a765e93ce67971e.png)

我早前整理过一份面试准备的资料，里面讨论了不少具体方法。今天的分享，则完整还原我陪着他从定方向、改简历、挑平台、跑面试到谈待遇的全过程，看看这些好结果是怎么一步步落地的。

先想清楚往哪里走，后面的动作才有意义。

他最初来找我的时候，方向感很弱。自己的老本行Java可以做，运营类的岗位也在考虑，还有一些贴着AI标签的新角色，感觉好像都行，但真要去投的时候又觉得哪条都不够确定。我带着他花了很长时间，把过去的项目经历、技能特点、性格偏好、兴趣方向全部倒出来梳理了一遍，又结合我对接下来几年行业走向的观察，一条条地做排除。最终，所有讨论集中到了一个明确的交点：提示词方向的岗位。

这个结论不是拍脑袋来的，而是一层层筛出来的。方向一旦清楚，后面所有动作都能围绕同一个目标展开。

![](img/e1f305c9b34c97e92a39d4a66d2f572c.png)

方向定完，才轮到简历。他原来的材料可以说是典型的“裸奔版”，内容单薄，项目经历被压缩成两三行字，整体看不出任何亮点。我们对它进行了一次彻底的推倒重做。先对照目标岗位职责描述，把匹配的经历挑选出来，让每一段内容都在回答你能胜任的理由。然后，在文件和格式细节上也做了统一规划：文件命名按“姓名+求职岗位”的格式；交付一律使用PDF；内容板块依次排布基本情况、学习经历、实践经历、获奖情况、个人总结、资质证书；每段经历都按当时的处境、要解决的问题、采取的做法、最终达成的成效这样的顺序来写；资质部分只保留含金量高、和所投岗位对口的证书。这些细节单独拎出来都很小，但叠在一起，就能让一份简历从“随便写写”变成“认真准备过”。

![](img/225811e83df51fc09e5a5e7051ed501d.png)![](img/8bda971e8c8d141c6c45af9b686a447b.png)![](img/6a9367ee6a6f97c61e29c989f0ab1bfd.png)

简历打磨好之后，另一个问题是把它送到对的人手上。

很多求职者喜欢在招聘平台上广撒网，同类职位下能投出去几十份。这样做的结果往往是消息石沉大海，投得越多越挫败。我们换了一条完全不同的路径：停止海投，改成瞄准目标公司的定向触达。每天的投递集中在工作日上午八点半之后进行，因为这个时段新发出去的消息更容易排到对方列表靠前的位置；下午三点到四点之间再做一轮补充。周末和节假日基本不投，避免被其他消息盖住。

在平台选择上，Boss直聘这类可以实时沟通的工具是我们的首选。虽然它也有些不尽如人意的地方，比如部分功能需要借助会员才能使用，但它的反馈速度和对简历阅读状态的追踪体验，是当前整个渠道里最好用的一个。其他传统招聘网站也会同步维护，但不是主力渠道。除此之外，技术社区、内容平台、熟人引荐这些非公开渠道也值得留意，很多好机会并不会挂在招聘平台里。

主动联系对方时，消息文案也经过了仔细设计。我们把它分成四个层次：第一层说清楚自己是谁；第二层讲明白自己选择这家公司的具体出发点，最好结合对方最近的业务方向或者团队特点来说；第三层直接亮出自己的经验亮点，证明自己足以挑起这个担子；第四层表达认真加入的诚意。整套信息控制在几行字以内，但每句话都有信息量。

举个例子，开场可以这样写：“王总，上午好。我是小李。在平台上看到贵司正在招提示词方向的人，很认可贵司在内容生成方向上的积累。我过去三年一直在做文本生成的落地应用，对提示词结构设计、效果调优这些环节都比较熟悉。这次投递不是随手一试，是研究过团队背景后认真做出的决定，非常期待能跟贵司多聊聊。”

如果简历发出去后收到的是拒绝，也别急着重复投递。等上大约半个月，用这段时间把简历再优化一轮，再尝试一次。要是对方一直没有读取消息，也可以考虑在几周后换个新账号重新建立联系。

简历标题同样是可以被优化的小细节。我们通常这样写：学校有优势的，把学校名放前面；有大公司履历的，把公司名和年限亮出来；能快速到岗的，直接标注“随时可入职”。格式用PDF，附件里不要捆绑任何作品压缩包。作品可以用在线链接的形式存放，或者生成二维码附在简历里，方便对方按需查看。通过邮件发送简历时，正文不要留白，至少附上一段简单的说明。

面试环节，我们把它当成一场信息战来打。

准备阶段最关键的动作，是把对方这家公司从头到尾研究一遍。这个过程，和我们平时研究一个行业里的案例很相似。这家公司靠什么赚钱？核心产品是什么？岗位描述里反复出现的关键词有哪些？老板过往有没有公开分享过项目经验？公司目前的经营状况健康吗？这些问题通过官网、招聘页面、企业信息查询平台以及行业公开内容，大多都能找到线索。假设这家公司体量不小，还可以通过它的竞争对手来侧面判断。

我们还把面对面交流中可能出现的各种问题，逐一做了预演。跟老板聊到的每个话题，我们都提前过了一遍。此外还设计了一个容易加分的小动作——带了一本书作为见面礼。选书而不是选别的礼物，是因为书的主题和岗位方向天然挂钩，比茶叶、钢笔这类物件更能体现用心。而且只带一本，因为不确定现场有多少人，一本既能代表诚意，也不会有刻意的感觉。

会面当天的表达方式也提前做了规划。他不会夸夸其谈，而是用坦诚的态度和扎实的技术理解去展现自己。有一个细节值得提一下：在交流过程中，他会适当管理对方在AI这件事上的期待值，明确指出AI只是一个提高效率的工具，并不是无所不能的万能方案。这种清醒的认知，反而让老板觉得他成熟可信。在随后的考察阶段，他很快掌握了与数字人有关的新方法，这种上手速度，本身就是能力最好的说明。

至于着装得体、表达清楚、不要随意打断对方、会谈末尾主动抛出几个问题、回来之后及时给对方发一条消息表示感谢，这些属于每一场面试都必须守住的底线。另外，去任何一家公司之前，建议养成查工商信息的习惯，提前确认经营状态，能帮你避开不少环境糟糕的团队。

很多公司的问题看起来五花八门，其实都绕不开几个固定的维度——离开上一份工作的原因、对所投岗位的理解、假设情景下的处理思路。把这些维度提前备好，临场遇到新问题也不会慌。所有高效的面试表现，归根结底都来自准备够深。

说到待遇问题，很多人容易踩坑。我的建议是把谈判拆成两个时间点来看。

第一次发生在交流还在进行的阶段。这个时候双方都还在揣摩彼此合不合拍，收入话题更多是试探，不需要急着讨价还价，给出一个期望范围就够了。

第二次发生在面试通过、对方明确发出录用意向之后。这才是真正谈条件的窗口期。这位朋友的情况比较典型：整个交流过程对方都没主动聊收入，直到老板亲自打来电话，并且表示要为他安排行程时，我们判断时机成熟了，才把待遇议题正式摆上桌面。这种主动不仅没有显得冒失，反而传递出一种职业化的态度。

![](img/25c01fb83fb40bd07a45fc746c52a271.png)

如果对方给出的待遇方案里有存疑的地方，想要进一步追问，又不想留下斤斤计较的印象，可以使用一套递进的追问逻辑：先表达对这份工作的兴趣和认同，再以了解情况的角度提出疑问，最后把问题收回到合作意愿上，让对方愿意继续聊下去。

![](img/71b88d24e2756434851b3bb62f187830.png)

还有一种更常见的情况：口头谈好的待遇迟迟没有落到纸面上。如果HR超过三天没有发正式通知，与其守着，不如由我们来带节奏。话术上要处理好分寸，既不制造催促感，又让HR意识到你在等待确认。具体怎么表达，这里也有一套可复用的模板。

![](img/1f4037e582930157be84e9eabeeee7b7.png)

到这里，整个求职过程算是画上了一个句号。

这段辅导大约花了两个来月。这位朋友前后只完整参加了两次面试，其中一场有名额是因为对方团队里有人临时转岗顶掉了，另一场就顺利拿到了offer。与其说是运气，不如说每一步都踩在了点上。

老板后来还专门提到，他在几次沟通和试用考察里表现出来的上手速度、闯劲和灵活性，是他被最终相中的关键原因。而“AI赋能工程师”这个新头衔本身，也说明老板对他的期待远不止当一个执行者。他不仅仅学会了一套面试动作，更重要的是理解了职场里识别人才的底层逻辑——主动性、学习速度、认知清晰度，往往比存量经验更能打动决策者。

如果要把整段经历提炼成几句话，我会这样归纳：方向要先理清，不能边走边看；简历要按岗位来裁剪，不能一份模板通吃；面试前要把功课做足，仪态、话术、应对思路都要提前走一遍；投递要有策略，跟进要及时；待遇问题要掌握节奏，该主动时不能等。以上这些，才是他拿到结果背后真正的支点。

末尾想和正在找工作——特别是琢磨着从老本行转向AI赛道的朋友多说一句：行情再冷，窗口也没有完全关上。方向清晰、准备充分、动作到位，就是你在这种环境里最靠得住的筹码。

每个人的职业轨迹都不一样，但有一些东西是通用的——抓住看得见的可能性，想清楚每一步的选择，在关键节点不犹豫。祝大家都能走到自己想去的那个位置。
