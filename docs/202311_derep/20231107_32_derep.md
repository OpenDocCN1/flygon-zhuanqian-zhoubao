# 视频号伪原创账号的新机会：从英文育儿书单到认知思维，换个赛道照样涨粉

大家好，我是秋海。这次能当视频号涨粉航海的教练，是因为我之前写了两篇英文育儿书单号的经验帖：一篇讲单日利润过万，一篇讲一年做到120多万粉丝、月入两万。距离发帖差不多半年，这个项目已经变了，借着航海的机会，我想聊聊这些新变化，希望能给你带来点启发。

英文育儿书单号出现一年多了，现在的玩法基本分两种：
一种是找演讲视频，靠对口型再拼上其他素材，剪成一条完整个视频；
另一种是直接用AI生成。

先说第一种。这种自己去搜集素材做伪原创的方式，目前看最稳妥，在各个平台都能拿到不错的流量，也比较容易过平台的原创审核。

再说AI方式。据我所知，市面上能用的AI方案基本都要花钱，国外有Heygen、Synthesia、D-ID，国内有闪剪、硅语、KreadoAI。AI生成的视频放抖音上能正常推荐，但在视频号容易踩雷，要么触发真实性验证，要么被判原创度低。我观察下来，加上一些圈友反馈，原因大概率是AI人物和模板就那么几套，用的人一多，内容重复了，平台就判定为非原创，然后限流。如果能定制AI当然好，只是现在定制成本太高，放在这个项目上不划算。

自从在赚钱分享了这个项目，赛道明显卷起来了。现在再入局，起号难度比以前大不少。

但换个角度想：这个项目的内核，就是追爆款文案。一个爆款文案，换一种表现形式，大概率还能再爆一次。比如把爆款视频的文案改成图文发出去，照样有流量。照这个逻辑，别的赛道的爆款文案，套上英文育儿书单号的皮，同样有机会再火。

我已经看到抖音上有人用这套方法做思维认知类内容，涨粉和变现都不错。视频号上中老年用户多，国学、情感这类内容也吃香，想换个方向的话，这些都是可选的。

重点是，这种新玩法在抖音和视频号上都还算蓝海。和英文育儿书单号不一样，认知思维面向的主要是中年男性，或者说，目标受众彻底变了：宝妈们对英文书单那套已经审美疲劳，那就换一群人，用他们爱看的内容，配上英文育儿书单号的外壳。

如果你对这个方向感兴趣，可以去抖音看这两个账号，他们的粉丝大多是最近一两个月才涨起来的。

这两个账号的底层其实还是划线书单号，只不过把其中的爆款文案换成英文，再用英文育儿书单号的模式做成视频。

除了这类账号，文案还有一个很实在的来源——带货书本身。划线书单号里那些书，一本就能提供几百条文案，翻成英文后足够做很多条视频。而且书里的文案都是精挑细选过的，天然容易引起共鸣。用书上的文案既能避开和别人重复，还可能撞出自己的爆款。像《句子迷》《句子星球》和各类语录书都是这种素材库。

用书本文案还有一层好处：一旦视频爆了，你可以马上发带货视频或者开直播接住流量。因为文案出自书里，和商品高度相关，转化率自然更有优势。

要是你敢真人出镜，也可以自己录口播，慢慢积累个人IP，这对账号长期运营帮助很大。

不过要清醒一点：混剪对口型本质上还是伪原创。流量视频在视频号还能正常推荐，但挂车视频审核更严。我有的时候会收到“作品优化”通知，说推广素材难辨真假，或者用了无关素材拼接。这些都是平台政策收紧之后才冒出来的。这个项目还能做多久，说到底要看平台的态度。

![](img/b23c5271056732092509a79b8bd7262d.png)

真遇到平台政策调整，除非你打算放弃某个平台，否则就得顺着平台的意思走。钻空子只能赚一阵子，想长期做，必须跟平台站一边。

英文育儿书单号走到今天，也是一路改过来的：最开始搬运，视频被删；后来用演讲视频，却音画不同步；再后来加各种素材混剪，做成伪原创；之后，就该往实拍方向走了。

所以，政策调整未必是坏事，反而可能是机会。每次调整都会劝退一批同行，只有能跟着调整、不断改变的人，才走得更远。

我的建议是：用伪原创快速把号做起来之后，要尽快转向真原创。视频号对原创的要求，在几个短视频平台里算最严的。今年还推出了类似公众号“流量主”的“创作分成计划”，说明平台对原创内容是真金白银在支持。

这次想分享的重点，就是一套长期运营思路：用伪原创起号，然后跟着平台政策不断升级玩法。涨粉从来不是终点，变现才是。想要更稳定、更长久的变现，不和平台对着干，往往是更好的选择。

在航海里，最重要的是尽快拿到正反馈。做符合平台规则的内容，正反馈才更容易出现。这些细节，大家可以多翻实战手册，跟着手册动手操作，大多数问题手册里其实都写了。

每次航海都是新起点，希望大家敢于下场，不要站在岸上观望。犹豫不会带来结果，行动才会；在行动中获得反馈，再用反馈校准方向，才能把航海的价值最大化。我后来能发现英文育儿书单号，也是因为一次一次实操攒够了经验，最后那些线索自己连成了线，变成属于我的蓝海项目。

顺便回应两个圈友的问题：有人问“11月会不会被重点打击？”我的判断是AI生成类玩法有风险，对口型混剪目前还能做；还有人问“被判非原创，开不了带货资格怎么办？”建议持续更新原创内容，过段时间一般会重新开通。

以上就是我今天的分享，谢谢大家。
