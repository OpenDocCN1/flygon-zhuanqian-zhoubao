# 一个 GPTs 汇总站，是我怎么一步步搭起来的

> 原文：[`www.yuque.com/for_lazy/thfiu8/alen2rlanlcxi3wm`](https://www.yuque.com/for_lazy/thfiu8/alen2rlanlcxi3wm)

## 30 赞 我是怎样做出来的这个 GPTs Store 站点

作者：啊洛
日期：2023-11-16

一、站点的搭建部分

我用的是 WordPress 来快速起站。

主题直接选了 WordPress 里能免费使用的套装，满足基本需求完全够用。

建好域名后做点基础设置，站点雏形就出来了。

核心就是把导航菜单搭起来，再把页面排版调一下。可视化编辑里稍微改改就能按自己的喜好呈现，也可以先空着后面再细化。

二、数据的收集环节

采集范围是全网。

主要目标是抓取以 [`chat.openai.com/g/g-`](https://chat.openai.com/g/g-) 为开头的分享链接。

信息源覆盖了 Google、Twitter、Reddit 以及其他各类相关站点，全部跑一遍后做一次去重清洗。

拿到链接列表之后，我写了一个 Google 插件里的脚本，批量去 ChatGPT 端把每个 GPTs 的具体信息抓下来。

这一步耗时比较长，而且后续还要持续做增量更新。

三、数据写入

把从 ChatGPT 端扒下来的结构化信息，通过调用 WordPress 的接口程序做批量导入，直接写入数据库。

这样就形成了现在大家能看到的 GPTs 汇总站：[`gpt-stores.com/`](https://gpt-stores.com)

四、谷歌插件与向量检索【审核中】

站点上线后，我顺手把整批数据做了向量化处理。

基于此又做了一个 Chrome 插件，让它直接嵌入到 ChatGPT 的操作界面里使用。搜索体验类似原生插件，在 ChatGPT 页面内就能即搜即用，界面元素也是参考官方风格做的。
