# 读了上千本书，依然没成长？我找到了最核心的症结

这篇文章，写给在赚钱有术里持续学习、却越学越迷茫的创业新手。

你身边是不是也有这种人：书单拉得老长，一本接一本地啃，可一到真刀真枪的实战，脑袋就一片空白。甚至你自己就是这样——读了一千本书，回头看看，生活和创业几乎没有丝毫改变。

我最近花了二十多个小时，专门研究“读书这件事”，顺手翻了二十来本书。最大的触动是：过去我总以为读书慢、记不住才是问题，现在才发现，真正的差别根本不在速度快慢，而在于你翻开书的那一刻，究竟想得到什么。

说白了，很多人一直在“享受型阅读”，而不是“学习型阅读”。前者是跟着情绪走，读得爽、看得入迷，读完整理不出可复用的东西；后者是带着问题读，读完后能提炼出模型，并且马上想办法用到自己的项目里。

下面这四个问题，才是从“读过”到“读透”的分水岭：

1. 读书读到什么程度，才算真正有效？
2. 怎么用一份阅读时间，换回一份实实在在的价值？
3. 书里的道理，怎么才能落到你自己的项目里？
4. 从“享受型阅读”切换到“学习型阅读”，究竟该怎么做？

很多小白恰恰卡在起点：误以为翻完一本书，就代表掌握了一本书。没有目标、没有输出、没有迁移，书读得再多，也只是给自己一点心理安慰。
