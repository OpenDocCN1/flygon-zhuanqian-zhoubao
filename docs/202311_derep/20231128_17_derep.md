# ('蜗牛的投资进阶路', (2, 10))

最近生财有术圈里，一篇题为《蜗牛的投资进阶路》的分享被不少人转发。作者蜗牛是位90后投资者，自称“周拱一卒，不断进阶”。在生财圈子待了大半年，他最明显的感受是：这里藏着太多自己从前不知道的搞钱信息渠道，思维一下子被拓宽了不少。

这次分享中，蜗牛完整复盘了2016至2023年的投资进阶路——最初买基金时，账户收益停留在四位数；后来换到可转债赛道，一路把盈利做到了六位数。整篇内容足足2985个字，记录了他这些年摸索试错、逐渐成长的实战心得。

想读全文，可以通过飞书文档查看：https://ganbt59fz5m.feishu.cn/docx/ENf6dEsXrotd7Vxc3cjcyOQ3n1c

评论区同样很有看点。有人留言说阅读链接需要权限，蜗牛很快回复“再试试看”；有圈友感慨“日拱一卒，持续迭代”很有启发，蜗牛则幽默回应“周拱一卒也不错”；还有刚开始学理财的朋友吐槽术语太多看不懂，蜗牛建议先从可转债入手，因为各种条款和套利玩法都相对明确。

当然，也有资深玩家认为这样一步一步进阶太费精力，其实还有第三阶、第四阶。蜗牛回应得很淡然：投资和其他领域一样，想要更上一层楼，本来就不容易。
