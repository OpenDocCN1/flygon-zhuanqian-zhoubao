# 8组 中老年知识付费

中老年知识付费这阵风，越吹越猛了。最近挖到一个很有意思的案例：有人靠“周易”这个人设，5天卖出50张太岁符，还全是私信和朋友圈成交，路径顺得惊人。

这位叫陈龙的博主，IP定位是周易命理师。他发现，一旦客户在咨询交付环节体验过“神奇”——只需要出生时间，就能比自己还懂自己——信任感就直接拉满。有了这层信任做地基，后续带货变现就丝滑多了。

更妙的是他的客群结构：直接下单的中老年其实不多，但很多是子女替父母买。尤其临近春节，40岁以上的人普遍信命，讲究提前化解犯太岁。他打了个比方：太岁爷是道教里的神明，道教像一家企业，太岁符就是当年的值班经理。2024年，属牛、狗、兔、龙（包括本命年）的人容易犯太岁，诸事不顺，这就是痛点。

他的产品是太岁包或符咒，背后资源是正一派的天师亲自制作，他赚的是差价。这几天刚跑通最小闭环，5天50张，靠私信和朋友圈就完成了交付，路径非常顺。

再看整体赛道，有人总结了中老年知识付费的拆解框架：需求、流量、营销、变现。

需求无非三件事：身体保健、兴趣爱好、社交陪伴。

流量分线上和线下。线上靠短视频、直播，发老年人感兴趣的内容，用自然流或投流获取；线下租场地做教室，通过社交媒体或本地生活平台引流。

营销路径很清晰：先用体验课吸引，再按学期复购，最后推1对1高客单私教，平时组织活动、比赛来增强黏性。

变现主要引流到私域，卖课、体验活动、带实物货（经络拍、艾灸包、毛笔、字帖、乐器等）。还有异业合作，比如组织老人参加旅行团。

具体案例也有几个。

个人博主“杏林老杜”靠发养生知识视频、开直播，挂橱窗卖老年人生活用品，品类很杂，手里攥着3个粉丝群，私域沉淀做得好。

再往深挖，有人做了一张中老年知识付费思维脑图，发散了不少方向，其中有两个典型案例特别醒目。

一个是宠物账号“哮天犬养狗”。粉丝只有8300多，视频54条，从2023年8月更新至今。最近30天销售额却做到10万到25万。主打产品是宠物用药（比如迅销土霉素片），还拓展了益生菌、维生素、鱼油、消炎药、驱虫药。粉丝画像里小镇中老年居多，男性比例更高。

它的优势是制作简单：宠物视频+产品展示+AI配音就完事。但劣势也明显，门槛低，容易被模仿。机会在于：城市宠物配套服务贵，自己动手用药更省钱；三线以下城市宠物医疗匮乏；平台目前对宠物医疗限制不多。威胁则是未来平台可能要求资质认证，监管会收紧。

![](img/739827afa13b243b53ec8e865439e528.png)

另一个是“社保养老小百科（收徒一起打假）”，粉丝18万，作品114条。付费服务卖了299×18+199×254=55928元。视频形式就是口播+PPT解读。

它的优势是便捷，线上沟通省时间；有专业团队的话还能提供政策解读、养老规划等综合咨询。劣势是刚学会上网的中老年在下单和沟通上有技术门槛，而且不见面可能导致服务满意度打折。机会是中老年化趋势不可逆，社保养老配套服务越来越全，网络工具也方便视频沟通、直播答疑；各地政策不同，地域特色服务更有竞争力。威胁是个人信息安全监管可能趋严，同行竞争也会越来越卷，必须持续优化服务。

总之，中老年知识付费这个赛道，看着传统，其实玩法越来越多样。无论是靠玄学人设信任变现，还是切宠物、社保这种细分的实用需求，核心都是抓住“信任+产品”这个组合。谁能让用户先信你，再把产品顺滑地带出去，谁就能赚到钱。年底正是家庭决策的高峰期，这一波机会，可别错过了。
