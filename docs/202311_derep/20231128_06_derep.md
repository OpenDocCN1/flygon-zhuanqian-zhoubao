# ('如何树立正确的商业思维（连载一）', (2, 18))

最近和不少创业路上的朋友聊天，发现一个很普遍的现象：大家业务能力挺强，但对商业的底层逻辑、公司治理这些事儿，心里却没多少底。往往是几个哥们儿一合计，觉得项目能行就直接开干，边做边摸索。结果呢？开头是兄弟合伙，最后却闹成仇人散伙，实在可惜。

我是昊布斯，算是个连续创业者，也是天使投资人。这些年我花了一百多万去上各种老板课程，自己也干了将近二十年的企业，涉足过旅游、软件、设计施工、新媒体这些行业，一手创办了两家年营收两千万的高新技术企业，辅导过三十多家创业公司，还投了五家互联网公司。所以对“商业思维”这件事儿，多少有点自己的体会。

就在上周六，我作为组局官，张罗了龙哥盟的第二场线下聚会，一口气和大家分享了整整四个小时的干货。内容主要拆成了六个板块：

1. 怎么建立正确的商业思维
2. 股权这件事为什么不能忽视
3. 财富怎样安全地“搬家”
4. 在海南注册公司有哪些好处
5. 不同股权架构各自是为了解决什么问题
6. 双层公司架构到底怎么搭

聚会上讲的前两块内容，我已经整理成了一份文档，大家可以直接点这个飞书链接看：[`sv5wqvnml89.feishu.cn/docx/VWcpdgFhfoPrG0xDD9IcEUoTn6d?from=from_copylink`](https://sv5wqvnml89.feishu.cn/docx/VWcpdgFhfoPrG0xDD9IcEUoTn6d?from=from_copylink)

这次分享涉及股权、财税和商业思维，说实话比第一场要深入一些。有些年轻圈友现在可能还用不太上，以后再做分享的时候，我也得琢磨琢磨怎么调整内容，让大家都能带走更实用的东西。

帖子的最后附上了圈友们的反馈。看到大家都说收获不小，我心里也挺高兴。以后有机会就多出来分享——越分享，越快乐😆
