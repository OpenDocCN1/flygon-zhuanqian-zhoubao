# ('公开制作竖屏思维导图 3 个月后，应邀开办训练营', (2, 26))

坚持把竖屏导图公开做了3个月，我居然从“查无此人”变成了受邀开训练营的人。

大家好，我是罗卜，赚钱研学社联合创始人。今年4月18日正式成为赚钱圈友。刚加入那会儿，我几乎没什么存在感——5月跟着航海、做志愿者，依旧没混个脸熟，那阵子迷茫了整整三个月。

转机出现在8月。胖大魔邀请我参加赚钱研学社的共读《亦人益语》，我开始尝试每天把读书内容做成竖屏思维导图，并公开发出来。慢慢地，越来越多圈友看到了这份输出。

到8月航海开启前，我又组了一个导图小分队，专门把航海手册和高手分享整理成竖屏导图。航海结束后，这份能力被“搞钱女孩”的陈雪老师注意到，她邀请我为她的用户开办竖屏导图训练营，教大家掌握这个技能。

借这个机会，想和大家分享一点真实感悟：公开、持续地输出，真的会被看见。也很感谢赚钱这个平台。

本来这篇分享有8300多字，内容较长，包括我做竖屏导图的经验和心得，我全部放在飞书文档里了，感兴趣的朋友可以直接查看：[`dakhb269es.feishu.cn/docx/NUgXdxjluoux3LxTFK8cxKTWnyb?from=from_copylink`](https://dakhb269es.feishu.cn/docx/NUgXdxjluoux3LxTFK8cxKTWnyb?from=from_copylink)

参加过训练营的朋友也留下了不少好评：有人夸我讲解细致、点评耐心，还给每一个作品提修改建议；有人说课程是“保姆式教学+答疑”；陈雪老师也夸大家进步神速，收获满满。看到这些，真觉得一切都值了。
