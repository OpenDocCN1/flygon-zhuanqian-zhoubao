**小杨哥是谁？什么是直播切片和 IP 切片？**

小杨哥这个名字国内基本无人不晓，看过他搞笑短视频的人更是数不胜数。百万点赞是常态，播放量动辄上千万。

![](img/a19f5a1b12db89e976cac9220157d6a7.png)

作为抖音头部网红之一，他的粉丝早已突破一个亿。

![](img/919fcd2ab6d670a7998c9754dddb16d1.png)

在大家都以为搞笑号走不下去时，他直接用搞笑带货完成转型，杀入抖音直播电商。

2021 年联合合伙人创办了三只羊网络科技有限公司，旗下孵化了一批主播账号，同时通过授权直播切片的方式，批量制造了大量的矩阵号。

![](img/a19108db075787623d668c0df898e476.png)

矩阵是怎么做的？说白了就是把直播画面拿来剪辑分发。这就是常说的直播切片。不少矩阵号的粉丝量也很可观。

![](img/7272fbb75d37ca2939f90ae3c97eae63.png)

今年 4 月，“疯狂小杨哥”直播基地在杭州博地中心正式开业。直播间里他还透露：“7 月我们将改名为三只羊控股集团，要去赚外国人的钱，因为 TikTok 后面也要做电商。落户杭州是为了整合更优质的资源，把产品、品牌、人才等从安徽老家带过来。”

![](img/e9b20552c00d6905f59b05015b72bb78.png)

那他们准备怎么进军 TikTok？

答案还是老手段：直播切片！

直播切片的概念前面说过，就是把整场直播拆成一个个短视频。但不是随便切一段就能用的，必须要有辨识度，比如强大人脸记忆点，观众一眼就能停下来。

所以严格来说，我们现在聊的直播切片矩阵，本质上是 IP 切片的一种分支。什么是 IP 切片？举两个例子就清楚了。

樊登读书，大家都不陌生吧？最早的 IP 矩阵开山鼻祖。用个人极具影响力的演讲画面直接切片成短视频，迅速引爆，本质上观众认的是这个人，买的是他的内容。

![](img/048b7c8e0e75f7d908f11c0bb59574d2.png)

樊登是偏视频讲座的，那再说一个直播切片的鼻祖，李佳琦。

我印象里直播切片的玩法最早是从李佳琦的洗脑直播画面火起来的。

一句“OMG！买它！”就能让无数女生疯狂下单。最早的抖音带货视频只要一插入李佳琦的“买它”片段，转化率立马飙升。

![](img/d4ba64125375dd76586a435cec23b842.png)

因此现在的头部主播直播间都很爱请明星做客，吸睛效果好，给内容增添话题度和趣味性。

**怎么拿到授权？授权有什么用？**

看到这里有人可能会问：直播切片听起来很香，为什么非要用小杨哥？直接拿本地大 V 的直播画面不香吗，人家是本地人，带货应该更有优势吧。

逻辑没错！去年确实有一波人这么干，直接用本地博主的直播切片甚至拿来直播。

结果 Tk 收到了大量投诉，平台开始严查，一经发现直接封号。

所以做直播切片，授权是底线。不授权，一次举报就能让你清零。

除了保号之外，授权还有实际权益。目前我们合作下来，可以拿到白名单权限，也就是 0 粉也能带货；同时出现平台误判也能走官方通道申诉。Tk 动不动就误杀，能申诉回来真的很关键。

授权怎么拿？目前主要走机构签约，不面向散户。个人玩家可以挂靠在我们这里，已完成授权，后续拉群对接即可。

**直播切片在 TikTok 到底怎么玩？**

说了这么多，最关心的一定是实操。**“少废话，直接告诉我怎么干。”**

要在 TikTok 上做名人 IP 的直播切片，可以按这三步走。

**第一步：先把授权搞定**

前面强调过，不授权等于白干。去年我们吃过太多亏。这篇文章以我和小杨哥 IP 的签约合作为例来说明。

**第二步：开通带货权限**

签约有两个核心要求，一是获得使用授权，二是把账号绑定到对方的 MCN 体系下。所以前提是先把带货权限开起来。目前主要有 3 种路径：

●**1、自有 TikTok 小店****（签约要求绑定 MCN 的话此路不通）**

如果之前申请过 TikTok 小店，就可以在小店后台绑定账号，绑定后即可开通带货。

优点是 0 粉就能开权限，缺点是一个店铺最多挂 5 个号，1 个官方号+4 个渠道号，还是本土店，跨境店配额更低。

●**2、账号粉丝达标自主开通 TikTok Shop 带货权限**

账号达到 1000 或 5000 粉即可在后台申请开通。

东南亚国家一般是 1000 粉，美国是 5000 粉门槛。

![](img/a606b14c302e4365252a48d7f58c995e.png)

●**3、由 MCN 机构代开电商权限**

把账号 UID 和 HandleID 提交给 MCN，就能申请 0 粉开通。

![](img/9a736f9b9f18529952b1619b5adaa9fd.png)

三种方式区别在哪？

前两种区别很明显，就是有无小店和粉丝门槛。第三种的优劣要重点说下。

通过 MCN 绑定和结算，回款更快更安全，做矩阵时账号变多，逐个提现很麻烦，MCN 统一收款再结算给你。另外账号万一被封，原有佣金也不会被吞掉。缺点也很明显，必须找靠谱的 MCN，不然佣金被卷走就麻烦了。

**为什么直播切片能成？局限性在哪？**

很多人会疑惑：

视频都是中文的，怎么在海外还能火？

内容这么本土化，怎么还能出单？

![](img/6acf14e9b715430522ba88215e41f0dd.png)

我来解释一下这个玩法为什么播放和转化都在线。

首先，国内头部网红在海外也有天然流量，比如 YouTube、Facebook 等都会有二次传播。李子柒就是典型例子，在国外比国内还火。

其次，直播画面本身就是团队精雕细琢的，笑点密集、梗多，作为娱乐内容看下去的成本很低，容易传播。

再者，TikTok 上中文内容人群基数很大。华人不少，印尼有 1300 万华人，泰国 900 多万，马来 700 多万，新加坡虽然只有 300 多万，但占比高达 76%，去过新加坡你会发现不用英语也能交流。抖音上也有讲粤语、闽南语、潮汕话的本地号，虽然普通话受众最大，但方言号照样有流量。

![](img/e30aa4b1170af4ad2ce9f507d7211626.png)

那这个玩法有什么局限？

最大的瓶颈是受众。直播切片目前最吃香的还是华人或亚洲人群，欧洲用户对这种内容并不感冒，这是文化差异决定的。所以建议优先投放华人占比高的城市，东南亚是首选，新加坡表现尤其好。

目前测试来看，素材重复度可控，小杨哥的内容娱乐属性强，契合 TikTok、抖音这类以娱乐为主的平台，拿流量相对容易。
