# ('四年发了八千条朋友圈，销冠的成交心法', (2, 20))

四年下来，朋友圈里积累了整整八千条动态。别急着说“太能刷”，对于这位销冠而言，每一条都是她成交路上的垫脚石。

她叫梁靠谱，生财有术的首席医官。没错，医生也能做销售，而且做得比专职销售还出色——无论是分销生财产品，还是推粥左罗老师上万元的客单新课，抑或卖自己的课程和产品，她都能拿下销冠，单单 CPS 一项，每年就能赚到七位数。

最近，她受邀来到粥左罗老师的直播间，把这几年的成交心法倾囊相授。这场分享被整理成一万三千字的完整逐字稿，而且由粥老师的社群团队操刀整理，科班出品，含金量不言而喻。

在靠谱眼中，销冠既是一个结果，更是一种态度，一个早已融进骨子里的好习惯。她用四年八千条朋友圈，把这种习惯练成了本能。
