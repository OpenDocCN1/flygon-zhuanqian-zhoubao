# ('(88 赞)神奇的十年', (2, 13))

**十年，凭什么神奇？**

如果把时间轴拉长到十年，很多商业疑团都会变得清晰——但可惜，大多数人连三年都等不起。早在2011年，贝佐斯就一针见血地指出：几乎所有公司都在围绕三年规划做文章，所以三年赛道挤满了人；而愿意以七年为期去布局的玩家少之又少，恰恰是这些少数派更容易脱颖而出。巴菲特也有一句流传甚广的话：如果一支股票连十年的持有耐心都没有，那就不要动买入的念头。放到企业经营与投资理财中，一旦你真正切换成“十年视角”，成功或许只是水到渠成的事。

不过，评论区里也有不一样的声音。有朋友认为，与其空谈十年，不如把目标拆得足够具体：用三年跑通流程，三年做Web，三年做App，最后攒成一个过亿访客的海外站，App只是配套，真正的功夫在流程、团队和营销。也有朋友直言，这种长期主义对急着赚钱的普通人来说过于奢侈，他们没余力把小生意养成大事业；他更愿意相信复利的作用——每年增长一倍就行，不需要十倍，因为每年一倍，已经是在赚过去所有时间的钱。

这些观点看似矛盾，却正好映衬出龙哥的提醒：人的脑子里要同时装下多种观点，哪怕它们彼此对立，也要知道各自的边界。不极端推崇短期，也不盲目迷信长期，任何决策都是平衡的艺术。说到底，十年的神奇不在于“等”，而在于你能否用长期视角，把每一个当下都算计清楚。
