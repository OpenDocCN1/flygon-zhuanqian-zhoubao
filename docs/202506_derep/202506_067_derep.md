# 百万笔记里看懂 Get 的取舍逻辑：四项新功能，为用户还是为同行？

作者：龙哥的收藏夹
发布日期：2025-06-12

Get 笔记的笔记量刚刚突破百万，这个节点上，团队把四项最新上线的功能拿出来做了公开复盘。

核心判断很简单，也很直接：做产品不能只考虑业内会不会叫好，更要回到使用者真实的场景，看他们能不能真用上，会不会主动用上。

百万笔记的体量意味着用户习惯已经稳定下来，这时候再做增量，不能靠堆砌功能来博眼球，而要做减法和取舍。四项新功能背后，其实就是一次关于“讨好同行”和“服务用户”之间的权衡。
