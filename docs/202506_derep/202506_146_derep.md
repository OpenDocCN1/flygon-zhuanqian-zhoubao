# ('(精华帖)(191 赞)用喜欢的事打造复利系统：成甲的五个“非典型赚钱观”', (2, 39))

你有没有发现，很多人聊赚钱，张口就是“某某项目一夜暴富”“单笔赚了多少”，但我越来越觉得，真正的财务安全感，根本不靠某一次“大丰收”。

成甲老师的分享，正好点破了我心里一直模模糊糊的想法。他说自己并不关心单笔交易的最大金额，也没有特别多“赚大钱”的故事可以讲。因为单次收益的爆发，很大程度上是运气和环境在起作用，偶然性太强了，没法复制。

他看重的是另一件事——打造一个能反复发生、长期稳定、不断创造价值的收入系统。哪怕每次赚得不多，但只要能够持续滚动，细水长流，自然就能形成一条健康的收入曲线，足以支撑一种安全、富足的生活。

所以，他的经验不在“赚大钱”这个维度，而在“如何建系统”这件事上。他举了两个自己的产品案例，特别有说服力。

第一个是《穷查理宝典》慢读会。他本来每天就要读这本书，学习和思考本身就是他的日常。后来他把这个过程做成了一个产品，现有50位稳定会员，会费从最初的每人每月900元，涨到了现在每人每月2000元。一些会员已经跟着学了好几年。对他而言，成本几乎可以忽略不计——反正自己也得学，只是顺手把学习过程开放给了别人。结果呢？每个月有稳定收入，还结识了一群志同道合的朋友，大家在交流中越来越信任彼此，形成了一个自我增强的正循环，做起来很开心。

第二个产品是“复利日知录”。他持续把芒格的思想用到生活中，每天记录自己的思考和实践，然后把文字分享给感兴趣的人，形成了一个社群。每一期运营四个月，收费499元，每期都有几百人参与，复购率很高。这件事的底层逻辑也是同样：把自己本来每天都要做的事，转化成能带来稳定收益的产品。

在更大的“万物社群”里，他们也一直在用这个思路做产品。核心就是：做自己喜欢的事，同时获得经济回报。这样的系统反脆弱能力很强，外界再怎么波动，只要长期价值还在，现金收益就会保持稳定，不会轻易被环境冲垮。

再往深一层看，成甲对“机会”的态度也很有意思。他不是那种整天追风口的人。他不会去预判什么赚钱机会，因为未来本身难以预测，很多时机根本不是能判断出来的。更重要的是，他已经找到了自己正在做、也喜欢做的事，那就不需要再左顾右盼，只要持续在那个方向上用力就好：每天提升一点知识和技能，加深对用户的理解，不断优化自己、改进帮助用户的方式。把这些做扎实了，对他来说就是最好的赚钱机会。

他特别提到一个对比：与其想着“一年翻10倍”，不如追求“每天改进1%”。一年下来，每天进步1%，累积起来是37.5倍的提升，比10倍还要夸张。当然，价值提升不等于立刻变成现金流，中间还有其他变量，但长期来看，你的收益一定会跟价值挂钩。所以，想赚100万不如做好每天的小改进。

说到创业的压力和坚持，成甲的态度也很通透。创业本身是他生活的一部分，不是为了赚多少钱去做自己不喜欢的事。如果逼自己做不喜欢的事，最后可能既没赚到钱，又很痛苦，当然想放弃。但他做的事情本来就是自己热爱的，为什么要放弃？放弃之后去过不喜欢的生活？这逻辑说不通。

至于怕陷入困境，他受了芒格的启发，反过来想——“我知道自己会死在哪里，那就别去那儿。”所以他会花大量时间做预防性准备，防患于未然。应对风险，主要不是靠临场调整心态，而是靠提前准备。当然心态也重要，芒格说“保持低欲望是幸福的关键”。他已经在做最喜欢的事了，乐趣本身就很饱满，极端风险也有了应对，那创业中的收入起伏，自然也就不算什么过不去的坎。

如果回到十年前，成甲想对自己说一句话：更勇敢、更诚实地去做内心真正喜欢和相信的事。真诚和善意，以及与人共赢，是最踏实的依靠。

回头看，他的这套“非典型赚钱观”其实一点也不复杂：不追单笔暴富，不猜风口，建一个喜欢的系统，每天进步一点点，提前防范风险，然后安心地做下去。这些朴素的道理，落到日复一日的行动里，就是最扎实的复利人生。
