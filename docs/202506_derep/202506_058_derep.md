# (17 赞)不上班搞钱的从 0 到 1 自救指南

最近刷到一个很有意思的现象：不少刚离开职场的人，明明能力在线，简历也漂亮，可一旦真正“自由”了，反而集体陷入了同一种焦虑——不知道该干什么。

前几天就看到一位从大厂离职的女生，履历非常亮眼，也很早加入了龙哥盟这样高能量的社群。按说资源、视野都不缺，但她依然在星球里坦诚地说：很迷茫，不确定下一步从哪里下手。

其实这不是个例。我自己在做“访谈100位离职的朋友是如何搞钱的？”这个项目时，也经常收到粉丝私信：刚裸辞，每天醒来不知道做什么，感觉除了上班，自己什么都不会。

这种状态太正常了。从“按月拿工资”到“自己找项目”，完全是两套生存逻辑。打工的时候，任务是别人安排好的；一旦开始做自己的小生意，所有环节都要自己定义。这种思维切换，几乎每个人都要别扭一阵子。

也正是因为踩过这个坑，我把这段时间的观察和访谈经验，整理成了一份《不上班搞钱自救指南：从0到1的破局行动手册》。里面不是什么大道理，就是从心态调整、方向选择到具体落地的实操拆解，很适合刚开始摸索的朋友。
