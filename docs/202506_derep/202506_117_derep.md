# 从建材老炮到AI出单：纯小白如何用21天在陌生领域赚到第一笔钱

大家好，我是刘雄飞。以前我一直泡在传统建材行业里，这几年市场越来越缩水，加上互联网电商一波波冲击，我一直想找个新赛道，却总也摸不到门。

后来有一次看直播，偶然刷到了赚钱有术，我留意了很久。去年双十一，看到航海项目启动，心里那股对新知识的冲劲一下子被点燃，我果断报了名。第一次出海，我就选了个最硬核的——ComfyUI文生图。说实话，AI绘图对我来说完全是另一个世界，一开始心里特别没底，又迷茫又紧张。

但我始终记着一句话：“别想太多，下场去干就行了。”于是，我跟着航海的节奏走，也在志愿者们的引导下一步步推进。整整21天，我每天坚持打卡，从最初连AI概念都云里雾里，到慢慢能上手基础操作，再到这次航海完成从0到1的转变，最终拿到了三位数的收入。每一步都不轻松，但每一步都特别踏实。
