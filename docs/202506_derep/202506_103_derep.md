# 小红书最近爱“整活”了，这几类违规我团队踩了个遍，分享一下自救经验

> 原文：[`www.yuque.com/for_lazy/zhoubao/mvk6ctzv7gn0airv`](https://www.yuque.com/for_lazy/zhoubao/mvk6ctzv7gn0airv)

各位好，我是更绪，一个在成都做小红书生意的 00 后，目前在龙哥盟担任特级传术师。团队日常的重心基本都压在小红书上，电商带货、线上获客、本地生活账号运营以及品牌投放全都做。

大家应该都感觉到了，最近平台的风控动作明显变频繁了，规则有时候看起来也挺“玄学”的，我就不评判对错了。但对做电商、做获客、做投放的朋友来说，影响是实打实的。

今天就把我们这段时间在实操中撞到的高频违规问题梳理出来，顺带聊聊我理解的平台逻辑，以及我们现在在用的应对办法。更详细的内容我整理成文档了，飞书好读版在这里可以对照查看👇：[`o7nsrridj4.feishu.cn/docx/C8kJdZv2qoMrSrx2Eb8ch3UtnIb?from=from_copylink`](https://o7nsrridj4.feishu.cn/docx/C8kJdZv2qoMrSrx2Eb8ch3UtnIb?from=from=from_copylink)
