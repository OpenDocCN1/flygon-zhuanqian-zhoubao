# (精华帖)(275 赞)创业先算账，助力出村圈友选项目

## 项目做一个换一个？你缺的不是执行力，是开跑前那本账

我是许老师，日常负责赚钱的投资孵化业务，同时也是联合办公空间和 SCAI 实验室的首席服务官，主要帮个体创业者把已经跑通的项目，再往上推几个量级。

入驻联合办公空间三个月，前后聊了近百位个体创业者，越聊越发现一个共性：大家的单点突破能力都不差，但很多人似乎总被困在“从零开始”的循环里。两三个月换一次方向，起得仓促，收得潦草，始终没有完成从 1 到 10 的跨越。

为什么会这样？我拆解下来，主要是两件事。

第一件事，是缺少杠杆意识。项目做到 0 到 1 之后，不知道怎么借力放大，机会窗口白白浪费。这一点我之前的文章里详细说过，这里不展开。

第二件事，才是真正要命的：选项目时太随意。要么选了一个天生天花板就很低的赛道，怎么使劲也做不大；要么这个项目想要放大，需要的能力你恰好没有。于是 0 到 1 是跑通了，杠杆却始终加不上去，最后只能被迫换项目，重新来一遍。

归根结底，就是动手之前没有把功课做足：行业没调研透，账没算清楚，也压根没想过从 1 到 10 具体该怎么打。

这篇文章，重点就是聊三件事：选项目时怎么做调研、怎么算账、以及拿到账之后怎么拍板决策。这个主题我线下给联合办公空间的入驻伙伴们做过一次分享，反响特别好。好几个人听完之后真的回去重新调研、重新算账，做项目的节奏立刻稳了，业务也一步步有了起色。现在整理成文字版，分享给更多圈友。

不过有一点先说明白：这篇文章是写给已经“出村”的圈友的。什么叫出村？我的定义是——你已经完整跑通过一个项目的 0 到 1，赚到过至少 1 万块钱，执行力当然不缺，下一步的目标是年入百万。

对这样的你来说，眼下最该做的不是多出手，而是少出手、出对的手。把选项目的周期拉长，投入足够的时间去论证和调研，减少出手次数，把每一次的胜率顶到最高。

如果你还在新手村，先别照搬这套逻辑。这个阶段，你最该做的是找一个赚钱圈里有人跑通过、今天就能上手的项目，少纠结多行动，亲自下场跑一遍流程，把最真实的体感攒到手里。说白了，新手阶段选什么项目，大概率以后都会换，做项目本身就当练手。真要选，翻翻我之前那篇讲选项目的文章，按里面的几步判断来，也足够用了。

如果你也一直在 0 到 1 的循环里打转，不知道怎么调研，也算不清自己项目的账，那这篇内容就是为你准备的。
