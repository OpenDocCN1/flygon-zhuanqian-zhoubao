# ('(247 赞)生财圈友欲打造世界级 AI 产品', (2, 25))

昨晚在深圳的一顿晚饭，亦仁被席间一句话深深触动。

同桌的几位兄弟都在做AI产品，聊到兴起时，有人突然冒出一句：“咱们生财圈友，一定能做出在世界范围内都叫得响的AI产品。跟赚钱关系不大，重要的是做出一件让自己从心底感到骄傲、感到值了的作品。”这话不是旁人总结，而是那位圈友自己的原话。

亦仁感慨，这句话像一束光，照见了一群人正在发生的转变。过去大家聚在一起，聊得最多的是怎么赚钱；如今，越来越多圈友开始带着全球视野想问题，像创业者一样打量世界。更难得的是，那种底气是许多人此前从未有过的——哪怕在2017、2018年那些被看好的年份，也没有今天这样的信心。

这份心气也落到了行动上。他们组建SCAI实验室时，目标同样清晰：打造具备全球影响力的AI产品。

亦仁相信，AI正在把创造巨大价值的机会交到更多人手上，未来，“一人独角兽”从不只是想象，而会真正走进现实。能赶上这个AI时代，亲眼见证这一切，实在是件幸运的事。
