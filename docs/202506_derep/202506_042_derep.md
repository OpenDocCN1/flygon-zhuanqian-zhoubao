# ('(精华帖)(110 赞)泡泡玛特全球火，IP 衍生品前景广', (2, 31))

**一年涨十倍，Labubu卖爆全球：被低估的IP衍生品生意，到底有多大想象空间？**

我是黄海。今天聊一个我跟踪很久的赛道——IP消费，还有那家让不少投资人直呼“没看懂”的企业：泡泡玛特。

十二个月，市值从200亿港币冲到2000亿，十倍涨幅，港股市场风头无两。等大多数人回过神来，这波行情已经走完了。但真正值得琢磨的不是K线，而是它背后那个事实：一家中国本土成长起来的IP企业，把Labubu、Molly这些玩偶卖到了世界各地，来自境外的营收猛增，成长的上限被彻底打开。

**一、IP衍生品，正在从小众走向大众**

今年现象级的IP是谁？哪吒。票房过百亿，先拿下中国影史第一，再闯进全球影史前十，顺带把全球动画电影票房冠军也收入囊中。观众散场后意犹未尽，周边自然被抢。泡泡玛特反应极快，影片上映同步就上了哪吒主题盲盒。标价69元的限量款，转手在二手平台能卖出十倍价；导演饺子亲手签名的全球限量10张卡牌，单张成交价破十万。

盲盒、手办、卡牌、毛绒玩偶、积木——这些形态可以统称为IP衍生品。这个市场的潜力，成熟国家早就跑通过：一部头部IP影片的总体收益里，衍生品能占到六到七成，票房反而只占三到四成。回头看看国内，眼下IP影片九成以上的收益仍押在票房上。这块落差，就是接下来的增长空间。

资金已经用行动表态。泡泡玛特过去一年在港股中国公司里表现几乎最亮眼，市值早已越过千亿港币。同赛道的52toys、做积木的布鲁可、做卡牌的卡游，也都在上市路上排着队。

**二、判断行业冷暖，别只盯冠军**

我看行业有个习惯：不看领头羊多风光，而看中间那批玩家活得累不累。IP衍生品正好属于“大批参与者都在同步盈利”的类型。就连名创优品这种靠十元店起家、原本卖日用百货的企业，近两三年也使劲往货架上加IP衍生品，想把自己重新包装成IP公司；旗下潮玩品牌TopToy更是直接冲着泡泡玛特去。

有次逛泡泡玛特门店，我特意问店员：店里最便宜的东西多少钱？回答是39元，上百元的商品随处可见。而且这些都不是限量珍藏款——那种只会被炒得更凶。抛开IP这层光环，盲盒里的摆件说到底是流水线上量产的普通工业品，谈不上科技含量，也没什么实用功能。

那低线城市怎么办？泡泡玛特的态度挺坦率：不急。官方口径是，自动售货机铺一铺就够了，重资产开店的投入产出比不划算。重心放在高线城市和境外成熟市场——那里的人对IP衍生品接受度更高，门店更来钱。

名创优品的经营数据也印证了这套逻辑：大环境承压之下，高线城市门店的同店表现还算稳，低线城市就吃力得多。道理不复杂，IP衍生品相当一部分买家是尚无收入的学生群体，拿零花钱买玩具，对他们而言本身是一种消费升级。高线城市年轻人购买力更足；到了低线城市，一个七八十元的玩具，很难支撑反复购买。

不过低线城市并非没有生意。春节我在贵州一座县城看到，卖IP周边的小店挤得满满当当，门口全是拆卡牌的孩子，9.9元一盒六张。卡游的招股书披露，主要成本无非纸张加印刷油墨，毛利率却能到八成以上——9.9元一盒照样有钱赚。积木的逻辑类似，单价也压得低，所以卡牌和积木在低线市场的销售潜力，其实比盲盒还大。除了盲盒摆件，毛绒玩偶、卡牌、积木这些形态都还在早期阶段。除了盲盒，你更看好哪一类IP衍生品？评论区聊聊。

**三、日本的启示：经济越慢，IP消费越热**

为了把行业看透，四月底我专程飞了趟日本，跟当地从业者深聊。为什么研究中国的IP趋势要去看日本？因为全球最能赚钱的IP——宝可梦，出自日本企业；日本在IP产业上的全球领先地位至今没动摇。每次去东京，秋叶原我都会留足时间，那是日本IP产业的心脏地带。

这回待了一整天，聊出三个关键判断，也让我更明白泡泡玛特为什么能在全球冒头。

第一，日本动漫真正腾飞，是在90年代泡沫破灭之后。“失去的三十年”经济低迷，可人们待在家里的时间多了，追番、消费IP内容的时间反而更宽裕。经济最糟的阶段，恰是动漫最兴旺的阶段。如今日本有近半数国民在消费动漫内容——它早就不是宅男圈地自萌，而是全民性质的精神消费。日本动漫的成长轨迹，就是一个从宅男小众走向大众主流的过程。眼下动漫仍是日本少数还能在全球领跑的产业，境外市场每年为它带来5万亿日元进账，而这一切都是近三十年里发生的。

中国的动画电影市场是最近十年才长出来的新事物，一切刚起步。2025年春节的哪吒，是中国第一部真正有全民影响力的动画电影。无论宏观环境怎么变，IP这类精神消费都有机会扛住周期。

第二，IP行业的竞争规则很特殊：你不必次次都赢，只要有一次赢到足够大，就能靠它吃很久。日本有家企业叫东映动画，名字你可能陌生，作品你一定熟悉——七龙珠、海贼王。仅这两个IP就贡献了公司七成以上的进账，而且都是几十年前的老作品。此后东映再没做出同等量级的新IP，就靠这两棵老树年年收全球授权费，一直收到今天。

更极端的例子是，有些知名IP压根不需要故事。Hello Kitty最早只是一个形象，没有动画和影片托底，照样红遍世界。日本同行告诉我，三丽鸥曾一心想给Hello Kitty编织大量故事，结果接连失败，因为消费者不买账——没人愿意看见Hello Kitty愁眉苦脸，大家都想把美好的情感寄托在它身上，与它共鸣。

道理相通，泡泡玛特当下最当红的Labubu就是不能开口的。一旦开口，想象空间就收窄了，那股魔力也随之散去。它就是个造型简单的玩偶，谈不上多少互动，恰恰因此，每个人心里都能装着一个属于自己的Labubu。手握经典IP的企业是幸运的，不必太过操劳，消费者会主动替它完成解读，企业只管坐在这座宝藏上持续收钱。当然，从零造出一个经典IP才是最难的——一旦爆款出现，把它推向更远的动作，往往由消费者自发完成。

那么问题来了：世上IP千千万，最终能沉淀为经典的为什么屈指可数？一个IP要扛住时间、广泛流传，背后究竟靠什么？不少人说这是门玄学，你的判断是什么？评论区见。

**四、文化出海，这轮跟风终于吹到中国**

IP创作是国家软实力的组成部分，也是文化竞争力的重要标志。扫一眼亚洲，能产出本土文化产品的国家也就四个：中国、日本、韩国、印度——宝莱坞的国际声量同样不可小觑。

泡泡玛特当下最热的市场在东南亚，当地人对IP产品的审美偏好更容易受中国影响。但杀进日本就难了。我在东京逛过好几家泡泡玛特，店内客流稀少，日本消费者兴致不高。症结很直白：日本本土IP产业极度成熟，当地人压根不需要买舶来品。同理，在中国大卖的哪吒2到了日本同样遇冷——当地观众对中国IP缺少认同。

但这只是个别市场，不影响泡泡玛特征战全球的大盘。除了日本这类少数国家，绝大多数地方并不具备原创IP的能力。泡泡玛特打进东南亚乃至欧美时，还意外收获了一位国际巨星的免费助推——Blackpink的Lisa。据说品牌方没掏一分广告费，全因Lisa本人偏爱Labubu，买回家后在ins发了条动态，没想到直接引爆，她也就乐意接着发。这种无心插柳的举动，据说仅凭Lisa前后几条社媒内容，一年就为Labubu带来逾十亿元的全球销售。

全球文化消费的跟风效应极强。过去这种传播红利的受益者是好莱坞电影、日本动漫，如今终于交棒到中国IP手上。
