# 别再低估你脑子里那句悄悄话的分量
作者：龙哥

我们总以为改变人生靠的是外部条件，实际上，真正起作用的往往是每天对自己说的小话。

先放下对完美的执念，给自己一个够用就行的粗糙雏形。当你不再卡在“必须完美才开始”，行动的闸门一下子就开了。你会惊讶地发现，那些你以为需要很久才能做到的事，居然就这么推进下去了。

行动一旦动起来，能力也在悄悄被激活。那种“原来我也可以”的感觉会不断放大，你的效率会变高，敢想敢做的范围也会随之扩大。人生的版图，也因此变得越来越清晰，越来越宽。

与其等准备就绪，不如先用一个不完美的开始，给自己一个自我暗示：我已经在路上了。
