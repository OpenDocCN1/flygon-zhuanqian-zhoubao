# 新手小白搭建网站常见问题以及实操过程（不讲专业术语，只谈实操过程） 副本
作者：龙哥

最近在搞一个网站搭建的项目，很多朋友来问具体的细节。今天就把大家关心的常见问题、实战操作和快速套模板的方法一次性讲清楚。这篇文章不讲高深术语，只讲怎么落地，全程以实用为主，实操部分靠截图演示，内容有点长，耐心看完。

# 一、服务器放在哪里？

服务器大致分三类：国内、香港、国外。

**国内服务器**
好处是访问速度快，百度容易收录，在🛰️里也不容易“爆红”，而且第一年成本低，几十块就能体验，但续费偏贵。坏处是备案要等二十天左右，限制也多——个人备案的网站按规定不能带支付功能，这跟咱们的定位天然冲突。另外，用你的身份备案第二个站，第一个站必须整改到完全合规，比较麻烦，建议换个没备案过的人的信息。

**香港服务器**
不用备案，会搭建当天就能上线。速度比国内略慢一点点，基本没感知。内容几乎没限制，想放什么都可以。缺点就是百度不收录，但谷歌不受影响；在🛰️里容易爆红；腾讯云、阿里云这些大厂卖得贵，一年差不多两三百。

**国外服务器**
适合做海外业务的朋友。同样免备案、没内容限制。有个省钱渠道：去闲鱼搜“aws”，有亚马逊服务器的活动，验证海外信用卡能白嫖一年，但偶尔要验证账单，验证不过就可能失效。不过总体还是比直接买便宜太多。缺点很明显：国内访问太慢，排序是国内＞香港＞国外，而且不适合做国内项目，🛰️里也容易爆红。

综合来看，如果你做的是我这种项目，首选香港服务器。国内备案周期太长，等备案下来，劲儿都过去了。

# 二、备案到底要不要？

最大的区别就是：备案能做百度收录，不备案不能。但我建议做不备案的站。

备案前后要花二十天，很多人备案完就开始拖，一拖又是十天半个月，等于晚了一个月。百度收录带来的流量又慢又卷，我去年给资源站更新了一万篇专门为SEO写的文章，到现在效果也没多少。百度还要求原创，咱们的内容基本是搬运，很难被青睐。而且备案网站有不定期的审查，光“不能有支付”这一条就把路堵死了。之前我被告知整改，没理，后来也没再找。

万一被要求整改，可以先拖一个月看看反应，期间一定勤备份。

**关于“爆红”**

爆红就是在🛰️里直接点网站链接，出现风险提示。原因基本是：内容本身有问题、被人举报、在🛰️里暴露次数太多且被很多人同时点开。

对策：
1. 发链接时提醒对方复制到浏览器打开。
2. 用缩短链接工具（比如缩我网 suowo.cn）生成短链，注册后把链接放进去，选“全部推广环境”，有效期设永久。
3. 实在不行就上域名防遮罩，原理是类似中转页面。我没实际用过，下面找的教程供参考。

**备案的注意事项**
电话问网站用途，就说个人博客、旅行日记之类，千万记住自己说的类型，不能涉及盈利。
备案站一定要在宝塔面板里设定时备份。

![](img/d0de328c57b577b59e87c43ae78c2761.png)

如果内存小，保留最新一份即可；备份频率建议一周一次。被警告整改时可以拖一拖，但备份要从一周一次改成三天一次。

# 三、服务器商家怎么选？

一句话：宁买大牌，不买杂牌。谁也靠不住。我以前推荐过无忧主机，这牌子从零几年开始干，去年跑路了，官网还能打开收款，就是没人服务，最恶心。所以我只推荐大厂，腾讯云阿里云这种，跑路也会退钱，但续费贵。相对安全又实惠的，我推荐西部数码，域名和服务器都在那买。别去淘宝找便宜货，很多做站的服务器挂在别人名下，哪天店铺没了你的站也没了。

域名别选太长太绕口的，比如我的ip叫旺仔，域名就是wangzaizyk。长度长不影响收录的话无所谓，后缀也不用非得com。

# 五、域名和服务器怎么连？

购买后两者是独立的，需要做域名解析。注意区分A解析和别名解析：虚拟主机用共享IP，走别名解析（CNAME）；有独立IP的服务器用A解析。解析生效一般十分钟，不生效就删了重来。一定要做www和@两条记录，默认是@，不加www会打不开，这个问题当初也让我头疼了很久。

# 六、文件怎么上传？

网站的源码、主题、图片，都可以通过虚拟主机的文件管理进行上传。

![](img/0efbb34f185fa2e0586b0abd1261ec84.png)

![](img/e8fd9f018c86ec5d03358a8ee8fdf1fc.png)

如果用的是我课程里的宝塔面板，数据库导入可以找到对应位置。宝塔面板相当于你和服务器之间的“翻译器”，我装了之后基本不去服务器后台了，看文件比本地直观得多。虚拟主机装不了宝塔，大家按自己环境来，我最近两天也会出一期虚拟主机的网站搭建教程，朋友圈会通知。

# 七、主题源码该不该用“开心版”？

我用的是子比主题，官方三个域名授权599，而开心版免费。我的站就是开心版，跑了三四年没出问题。虽然官方一直在更新，但新版本加了论坛之类的东西，太复杂，我还是喜欢简洁的旧版。

常见问题：
1. 被官方发现会清空吗？不会。我三四年没有任何事，就算万一被查，数据都在数据库里，补个授权就行。平均一个域名不到200，这个概率99.9%不会发生。
2. 正版优势？持续更新，但我个人审美不喜欢新版。如果实在不放心，去官网买正版也可以。我的心态是：没赚到钱之前，能省则省。

# 八、网站自动更新怎么做？

目前我知道的免费工具有高铁头、影刀，收费工具也有。

**高铁头（不推荐）**
它是火车头的免费版。原理是在网站根目录放插件，从源码内部调用权限更新文章。优点是发布极快，三秒一篇，我去年用AI批量生成的10000篇文章几小时就发完了。还能采集别人的网页发布，更适合做收录的站。缺点是灵活性差，不够人性化，像影刀能做的复杂采集它做不了。

**影刀**
比高铁头慢，平均一分钟一篇，但比手动快得多。手动更新敲键盘冒烟也就这速度。最大的好处是：自己写一次影刀脚本，能举一反三，一通百通，会一个就会第二个。

**收费脚本（200/年，是我找别人买的）**
现在我的站就在用这个，基本不用管，自动采集中创、福缘、冒泡的项目并更新。时间紧的朋友可以试试，时间宽松就自己按课程配影刀，能省两百块。

# 九、收款接口怎么弄？

子比主题我用过两种：支付宝当面付和虎皮椒。

**支付宝收款**
免费申请，但容易触发放款限制，我用当面付那阵子经常被限。

**虎皮椒**
稳定，不会出现支付不了，绑定👸号后还有订单通知。缺点是要渠道费：支付宝88元，🛰️118元，每笔抽1%。

最划算的组合：先开通免费的支付宝渠道，等订单多了再上虎皮椒，能省下不必要的成本。

# 十、做网站最核心的是什么？最忌讳什么？

**核心：引流**
网站搭出来，相当于有了产品，不等于能赚钱。做生意就两件事：产品和引流。你只完成了第一步，第二步才是要长期坚持的。类比开店铺，柜台上得放货吧？网站就是你柜台上的商品，如果不去引流，就像天天擦玻璃、上新品，就是不开门营业，纯粹自嗨。

这是我去年学员发的截图，今年他数据库丢了，只能放旧图。

![](img/ca64f4cc9bede4e687ade7d2a870778d.png)

**忌讳：等和懒**
等：今天搭建等一会，更新文章等一会，引流等一会，机会就这么没的。
懒：我不推荐备案的一个原因，就是不希望大家把希望寄托在极小概率的“百度收录”上。新手靠自然流量吃饭最可怕。你去搜百度收录教程，稍微专业的都十小时起步，更别说实操。更新几篇文章就想来流量？概率极小。

# 十一、熟练搭建网站的核心是什么？

有会员说一定要学会搭建网站。我说你以后是要给学员搭建，还是有很多IP要操作？如果不是，就没必要把时间耗在搭建上。我的网站2020年搭好，到现在没怎么动过源码。除非录课，否则我永远不想碰搭建了。

想熟练，没捷径，唯手熟。花5块钱买一周服务器，再花几块钱买个垃圾域名，一周时间足够搭建二十次网站。练完二十次，就算一年不碰，看文字教程也能秒懂。

# 十二、收录到底做不做？

有大佬说备案好、每天更新项目就有自然流量。但我实践过，加上学员和熟人反馈，没见谁靠自然流量一年赚超500块。已经备案的朋友可以锦上添花；没备案的朋友，别画蛇添足。

需要对接合作的话，可以找多多推名片。
