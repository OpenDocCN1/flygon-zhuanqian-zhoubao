# 高能量的创始人，是怎么做到的？
作者：龙哥

**创始人如何保持高能量？答案藏在“暂停”里**

在创业这条路上，我们总以为那些能量爆棚的创始人仿佛永动机，永远不会疲惫。可事实是，无论多强大的人，内心的电池也终会耗尽。

真正聪明的做法不是硬撑，而是敏锐地察觉自己的低谷状态，主动给自己“充电”。这里的充电，不是喝咖啡、打鸡血，而是学会刻意留白——给自己按下暂停键。

所谓留白，是一种主动选择，是从自动驾驶的惯性中抽身，回到当下，去感受正在发生的每一刻。它是一种“存在”的能力，而不是“行动”的延续。

当你每天被密集的会议、决策和消息淹没时，你的大脑早已进入自动导航模式。而暂停，就是让自己从这种模式中切换出来，重新找回对当下的觉察。唯有如此，能量才能重新流动起来。

所以，如果你也感到精力所剩无几，不妨试试：停下来，不勉强，留白片刻。这也许就是你重返高能量的起点。
