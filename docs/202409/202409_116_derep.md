# 如何利用黑科技软件批量制作及发布📕图文

没时间也能做好📕？这套黑科技“流水线”了解一下

刷📕时，是不是总羡慕别人日更不断，而自己因为工作忙根本没时间做图、发文？大家好，我是千韭，平时最喜欢捣鼓各种黑科技工具。今天就来给大家实际操作演示：如何利用软件，把📕图文从制作到发布全部批量搞定。这套玩法，简直是留给上班族的副业神器。

需要的工具一共就五样：一是WPS里的PPT功能，二是可画用来做设计，三是一个批量生产图文的软件，四是一个专管📕图文发布的批量助手，五是天翼云SK5IP。把它们组合起来就行。

关键的是，这个套路跟行业没有关系，任何领域都走得通，底层逻辑完全一致——拼的就是谁的手机更多、账号更多。而且因为大量操作都被软件接管了，你不必天天费神，反而很容易坚持下去。
