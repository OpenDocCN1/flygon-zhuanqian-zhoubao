# 下班两小时，我靠京东这个官方活动，副业月入过万

你是不是也曾在商场、广场遇到过有人拿着小礼品，请你扫码下载京东 App？

说实话，我之前也好奇：这些人到底在图什么？一个月能赚多少？背后是什么逻辑？

直到我认真研究了“东东大赛”这个官方项目，才发现，原来这就是一条被很多人忽视的副业路径。我自己实操下来，每天下班花两小时去推广，收入在 200-1000 元之间波动，一个月过万并不夸张。

这个项目不需要走任何第三方后台，权限直接在你自己的京东 App 里，推广和提现全部官方通道，很省心。

玩法也很简单：线下地推，邀请那些从未下载过京东、或者超过 365 天没在京东下过单的人，用你的推广码完成一笔一分钱购物。每成功一单，你就能拿到 9 到 20 块的佣金。本质上，这跟赚钱圈里分享的京东拉新逻辑一致，但区别在于，这是京东官方的活动，合规且稳定。


另外我也想多说两句心里话——

这个副业确实还能赚钱，但前提是你愿意动起来，它很吃个人的执行力和沟通能力。如果你只是抱着“躺赚”的心态，那还是别浪费时间了。

我分享这个信息，主要两个目的：

第一，下次你再看到有人在街边送小礼品拉人下载京东，你会明白他们做的是什么生意、变现逻辑是什么。这本身就是一个信息差带来的认知升级。

第二，如果你之前就想知道这类推广工作怎么加入、怎么操作，那正好，下班后多一份额外收入的路径，我已经给你铺好了。

怎么选，看你自己。但我建议，把这篇文章当作一个信息差知识来读，不强制你立刻去执行。
