# 全职妈妈的逆袭：一年重启职业，靠运动康复做到月入二十万



## 从伸手要生活费到单月入账二十万，我的运动康复之路

作者： 琴琴 Tiny

日期：2024-09-04

从曾经的家庭全职者，到如今月入二十万的运动康复从业者。

大家好，我是琴琴，运动康复领域深耕近十年，累计授课超过两万小时，服务会员保持零差评。

要特别感谢一位老朋友，是他极力推荐我进入赚钱。进入之后，被这里的高质量信息量和强烈的商业驱动氛围彻底震撼到。

最近三个月，我把自己的经历梳理了一遍，鼓起勇气拿出来和你分享。

我原本是一个全职宝妈，用一年的时间重新杀回职场；从业绩挂零的低谷到迅速成为团队销冠；从给别人打工到独立创业，实现月入二十万的跃迁。

这一路每一步都走得很扎实，改变的不仅是收入数字，更是内在的心态与格局。

现在回头看，我坚信无论未来遇到怎样的难题，都能迎刃而上，勇往直前。
