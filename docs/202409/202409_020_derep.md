# 在视频号做知识付费，穿越周期的项目拆解来啦
作者：龙哥

标题：98年小团队靠视频号卖AI课，专攻都市银发，如何从0跑出成绩？

最近赚钱圈里有一篇拆解帖挺火，讲的是在视频号做知识付费，怎么穿越周期。作者耿堃，一个98年的年轻创业者，早前一直在公司做打工人，钻研的是搜索引擎优化和投流。今年四月，他才正式启动视频号项目，和女友组成两人小团队，瞄准都市银发人群，专卖人工智能课程。作为一个对自媒体和视频号完全没经验的新手，他硬是闯出了一条路。

视频号一直被视为当下的红利赛道，而耿堃作为奔跑在一线的创业者，也切身感受过平台规则的多次变动，以及项目前期不赚钱的空窗期。他提到，自己刚入局时承蒙不少圈友和大佬指点，少走了不少弯路。因此特意写下这篇拆解，既是回馈赚钱社群，也是给还在观望的朋友们一份参考。
