# 第一次做视频号带货长航海的志愿者的翻车复盘
作者：龙哥

第一次当视频号带货长航海志愿者，我把自己整“翻车”了

大家好，我是薄荷 Heidi。今年6月，我主动申请成为视频号带货长航海的志愿者，满怀期待地踏入这场47天的旅程。当时想的是，等结束后一定要写一篇“优秀志愿者经验帖”，结果没想到，最后交出来的是反面教材式复盘。

龙哥曾分享过一句让我印象深刻的话：当你把所有精力都投进一件事情，哪怕结局不理想，那份经历本身也足够独一无二。在我身上，这句话得到了充分验证。

先说最扎心的三项数据：
- 我们小组的航程里程数，原本高居榜首，后来一路跌到第5名；
- 47天里，免押金且全程满勤的伙伴只有2位；28位免押金成员中，成功上岸者仅11人，一眼看去没到半数；
- 还有1位自己交押金的船友，最终没能闯关成功，999元押金直接打了水漂。也就是说，付费上船的人群里，我们小组的“上岸率”是0%，实实在在的0%。

坦白讲，这些数字一度让我感到尴尬。但评论区没有一边倒地嘲笑，反而有人说，从我做的那堆表格里能看出认真与负责；有人说，敢把失败摊开讲，这本身就是最有价值的经验；还有人提醒，47天超长打卡本来就考验意志，能坚持到最后的都是勇士，而里程数排名并不代表航海的真正价值，关键还是每个人有没有回到自己的初心。

这些声音给我很大触动。作为志愿者，我的确做了很多功课：表格、记录、进度追踪，一样没少。可结果依然不如人意。这让我学会了一件事——把自己该做的做到位，然后坦然接纳任何结果。输赢只是事情给出的反馈，并非对我们这个人的判决。愿意直面问题、解决它，才是向前走的最好方式。

9月航海很快就要启航了。写下这些，是希望给同为小白的志愿者一点启发。
