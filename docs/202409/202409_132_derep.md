# 所谓成长，就是不断找到第二曲线
作者：龙哥

你有没有发现，无论一家公司还是一个人，增长这件事从来都不是一条直线往上走的。

再风光的企业，再火爆的业务，总会在某个时刻撞上一堵看不见的墙——速度慢下来，数据不再好看，甚至开始原地打转。这个拐点躲不开，也绕不过。它的出现，可能是内部组织僵化、活力衰退，也可能是外部市场风向变了、对手更凶了，或者干脆是新技术横空出世，把老玩法整个掀翻。

但真正拉开差距的，不是谁先撞墙，而是谁能在撞墙之后找到出口。一旦跨过这道坎，新一轮的增长就会被重新激活。

这个能让你再次起飞的新方向，就是“第二曲线”。

说白了，成长从来不是沿着一条路走到黑，而是在第一条曲线见顶之前，就主动去开辟第二条曲线。对个人来说，同样如此。你的技能、你的赛道、你的舒适区，都有它的天花板；真正让人持续成长的，是那种不断寻找新可能的意识。

所以别等增长完全停滞才着急，也别在旧地图上执着于找新大陆。保持敏锐，看见变化，然后大胆去画那条属于你的第二曲线。
