# ('一次失败的陌生拜访：社交礼仪的重要性与教训', (2, 23))

一次搞砸的“贵人见面”：能力再强，不如懂这两个字

今年八月初，我好不容易盼来一次线下拜访张哥的机会。严格说，这是我的第一次登门，也就是大家常说的“陌拜”。为了这次碰面，我足足准备了两月，心里想着：只要能聊得顺畅，被点拨两句、顺势提携一把，也就是分分钟的事。

可结果呢？一手好牌被我亲手打烂。

问题不在嘴笨，而在“做人”。

首先，我两手空空就进了门，一点见面礼都没带；其次，聊天过程中，我还不自觉地拿纸巾蹭桌面，一遍又一遍。这些小动作，让张哥明显有些皱眉。后来他跟我直言：他愿意帮一个人，那人也许没有背景、没有资源、没有能力，但有一点必须具备——会做人、懂礼数。

听到这里，我彻底明白了。这次机会，被我活生生作没了。现在回头想想，真想抽自己几个嘴巴。

我把这段经历写出来，是希望每一位准备拜访大佬的兄弟姐妹，别踩我踩过的坑。贵人点拨的机会，不是随时都有的，错过了，这辈子可能都难再遇见。

当然，我心里对张哥是充满感激的。他在百忙之中抽空和我聊天，给了我非常中肯的建议；更难得的是，他当面指出我待人接物上的毛病，说我人情世故的短板太明显，以至于很难把伙伴凝聚在身边。这句话像一盆冷水，一下子把我泼醒了。过去我总以为，自己混得不好是因为没有战略眼光，找不到好项目，才导致收入时常断层。现在才明白，根源根本不在眼光，而在为人处世的根基本盘。

最后，还要感谢帅气又大方的张哥，在我整理这篇文章时，又耐心地给了我不少指导，让观点更清晰、脉络更通顺。真心感恩。

也顺带回应一下评论区的朋友：有人开玩笑说，拜访他不用讲那么多规矩，请吃顿饭就行。哈哈，规矩虽不必繁复，但该有的礼数，真的不能少。
