# 王川：论“非常挑剔”与“非常自由”

你有没有发现，一个人越是懂得筛选，反而越容易获得真正的自由？

真正厉害的人，往往对交往对象有着近乎苛刻的标准：只愿意与那千分之一最顶尖的个人和团队同行。这不是傲慢，而是一种清醒的选择。

正因为如此挑剔，他们才从琐碎无效的社交中省下大把时间，换来难得的闲暇与从容。而这份自由，恰恰成了他们持续积累见识、沉淀财富的土壤。

更妙的是，当知识和资本在这一过程中不断增值，他们的眼光会变得更敏锐，标准也会变得更高——于是更加挑剔，也因此更加自由。循环往复，一个人就这样活出了别人难以企及的层次。
