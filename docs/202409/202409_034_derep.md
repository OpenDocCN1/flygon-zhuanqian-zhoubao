# 长期主义的实践为什么这么难
作者：龙哥

为什么我们总是喊着要长期主义，却常常半途而废？答案可能很扎心：不是意志力不够，而是你没得选。

资源匮乏的真相，其实是选择权的匮乏。当你的选项少得可怜，现实就会逼着你走上那条“最容易走”的路——哪怕那条路和你的长远目标背道而驰。嘴上再怎么说要坚持，身体却会很诚实地倒向阻力最小的方向。

就像投资这件事，很多人失败，根子上就是一个字：穷。因为穷，心态容易崩，动作容易变形，原本该守住的纪律守不住，该等的时机等不起。所以，长期主义不是靠喊口号就能做到的，它需要一定的资源来支撑选择的空间。没有选择权，所谓的长期主义，不过是空中楼阁。
