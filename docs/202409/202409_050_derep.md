# 从负债百万到财富自由之路（二）：二次创业还债与红利利用

这是《从负债百万到财富自由之路》系列的第二篇。上一篇讲了我第一次创业是怎么把日子过成大型事故现场的，这一篇接着聊聊，欠了一百多万之后，我又是怎么靠抖音直播一点点爬上来的。

说实话，欠债到了一百多万这个量级，靠打工还钱根本不现实。唯一的路就是接着折腾。所以我又回了创业这条赛道，搬去朋友那儿，和另外两个兄弟组成了最原始的“草台班子”。当时抖音直播还没完全爆发，但短视频带货已经很火了，我们决定往这个方向钻。问题是兜里一分钱都没有，凡是高投入的事全做不了。于是我们选了“服务商”这条轻路子，帮做抖音的人办千粉、开蓝V认证，一个月能赚五六千，生活开销勉强够。

后来为了省成本，我们干脆自己养号再卖。白天的日常就是混各种业务群、加人、发朋友圈，同时剪明星、吃播、美女的混剪视频，等粉丝涨到几千就出手。那段日子我们做出了好几个几十万粉的吃播号，内容全是韩国吃播博主的视频，粉丝不算精准，但标签是美食类。

接着无人直播技术开始冒头。一次意外尝试，我们用OBS推流开了场直播，五分钟内直播间就涌进一千多人，购物车咔咔出单。那几天卖掉了20多万的蛋黄酥，佣金到手五六万。我当时的第一反应是：我去，钱还能这么赚？

但我们还真没把直播带货当回事，只认为“混剪+无人直播”这条路能走。于是慢慢砍了服务商业务，专心做号。白天剪视频发视频，晚上开播。2020年疫情爆发，我没回家过年。因为负债，压力巨大，就算身边有家人也感到窒息。后来我跟着两兄弟去了怀化老家，换了地方也没用，经常聊着聊着就掉回低落的情绪里，只能靠酒撑着。

年后我们揣着一麻袋萝卜回长沙，就怕封城没菜吃。好在长沙解封很快，我们恢复了工作。可这时候全国都在搞直播潮，大量直播公司冒出来，原来的无人直播玩法开始被管控，越来越难做。我们又回到了几乎没收入的状态。

就在此时，一个朋友找上门，说株洲有个档口老板想搭直播团队，问我们去不去。到了这种时候，哪还有感不感兴趣一说？有口饭吃就谢天谢地了。于是我们去了株洲。作为运营团队，我们有工资、有免费住宿，项目成了还能拿40%分红。

档口是卖服装的，所以我的第一个赛道就是服装。那会儿整个档口都在流行直播带货，但我们压根不懂真人直播，更不懂服装。从选品、拍摄到直播，全部从零起步。2020年的直播特别玩“玩法”，而我们既不懂平台算法，也没有套路，只知道有什么货就上什么货，拍视频、平播。这样硬搞了两个月，完全摸不着头脑。直到偶然看到一个盗版培训课，才知道抖音原来还有算法。

认认真真啃完课之后，我们开始用“马扁”的打法去做自然流，效果出奇得好。以前我们几乎没见过50人在线，那一场居然做到了几百人，再后来千人在线、万人在线。那一刻我激动得以为自己马上就要起飞了，还债之路好像就在眼前。但我对抖音的理解还是太浅显，以为有人看就有销量，结果产品转化跟不上，账号流量越来越差，最后全剩一群薅羊毛的老粉。之后换了好几个号，结局一模一样。

这个过程中，股东作为投资人，几乎我们提什么要求他就给什么，也很少施压。但快半年了，别说赚钱，他反而亏了差不多100万，谁都知道这项目大概率成不了。我们最后友好散场，那天晚上他还特意请我们十几个人吃了顿饭。说实话，这种格局我很服气。

团队散了后，我留在了株洲，不打算再创业，而是以打工者的身份进了一家公司。我当时的想法是：哪怕不要工资，只要能学到人家的本事就行。所以有两个月时间，我一直泡在那家做得不错的学习。也正因为在里面拼命参与各种核心环节，我才拿到了第二笔投资的机会。

当时公司让我独立运营一个新账号，用的还是他们已经很成熟的“自然流+短视频”打法。我已经跟了两个月，操作起来很顺，幸运地做成了三个号，一个月加起来GMV差不多800万。这个数据给了我底气，但我也清楚，我进来的目的是学习，不是上班。所以我趁数据好看的时候发了个朋友圈，说想找新的投资人。就是这个朋友圈，吸引了我现在的股东。他主动找过来，我们很快成立了新公司，我也离开那家学习公司回到长沙。

这是一个全新的起点，但对我来说，也可能是最后的赌注。那时候我的忍耐力已经透支到了极限，再失败一次，我真不知道自己还有没有勇气撑下去。

那是2020年9月，抖音自然流还在红利期。我在服装上栽过跟头，知道这个赛道难度太高，于是换到食品、百货。服装比食百难多了，同样的玩法切过去，几乎就是降维打击。我们用矩阵模式跑，第三个月GMV就破了千万。拿到这个结果时，我彻底释然了，因为这次是真正以创始人身份打出来的成绩，利润差不多有12%。中间虽然也跟随市场变化做过玩法迭代，但本质上我还是自然流玩家。

到了年底，有两件大事。第一，我拿到了第一笔季度分红。作为技术入股，我是第二股东，但还是分了五十多万。那天距离过年还剩八天，我原以为自己会兴奋得跳起来，可真等钱到账的时候，内心反而异常平静，只有一个念头：该结束了。第二，是项目方向的调整。作为自然流出身的玩家，我太清楚流量模式有多不可控，经常这个月赚钱下个月亏钱。正好那时付费投流开始兴起，我考虑一番，决定把公司重心转向付费。

转付费还有一个原因：我的股东有过投资鲁班团队的经验，在打法、人员、货源上都能配合。这对我来说太重要了。直到今天，我也不认为所有成绩靠的是我自己，而是因为我有个好投资人，他本身有资源，还愿意信任我、给我试错的机会。

付费摸索期并不长，但代价很痛。我们一开始选错了内容方向，坚持实拍，而当时其实混剪投放就能拿量。就这样亏了将近170万。直到2021年2月，团队才终于跑出正数据。付费投放一旦通路跑通，后面就是一路高歌。GMV从一个月几百万，很快冲到千万，到5月份月销已经到7000多万，我们一跃成了高消耗玩家。放到今天几乎不可能想象，这就是赛道红利期的威力。

那一整年，我不仅还完了负债，还进入了快速吸金阶段。公司连续半年盈利，一路向上。我的事业也终于完成了从0到1的跨越。

回看这段历程，我最想说的是：初次创业可以失败，但一定不能失败到没有翻身的能力。我自己就差点掉进这个坑。负债一百多万，出身农村，全靠13张信用卡和几个同学的借款才勉强周转。如果不是恰好撞上抖音红利，我真想不到还有什么项目能让我一年多还清债务。所以，人真的可以犯错，但千万别犯回不了头的错。除非你也像我一样走了狗屎运，误打误撞踩上平台红利。

市面上有很多创业鸡汤，总爱把成功者写得英明神武，好像选赛道全靠敏锐眼光。但说实话，我接触那么多人，包括我自己在内，除了雷军那种积累深厚的顶级创业者，能靠经验做判断之外，大部分初级创业者都是摸着石头过河。只是事后复盘的时候，很多人喜欢给自己镀一层金，把自己包装成高瞻远瞩的样子，好显得自己聪明罢了。

比如我自己，完全可以承认，我对抖音根本没有预判，完全是蒙着进来的。连开播都是意外测试出来的，事先没有一点规划。现在回头看19年到20年那一年，确实很low。因为负债，做什么都没底气。我好歹是本科毕业、从深圳大厂出来的人，结果毕业三年就沦落到睡上下铺。连六十块钱三楼的按摩都舍得去，按脚的大姐比我大二十岁，还动不动挑逗我，现在想想都起鸡皮疙瘩。

可哪个创业者没有低谷期？每个真正拿到结果的人，都注定要走过一段没人说话的阶段。那段日子，物质上无从谈起，底气上也低人一等。但只要熬过去了，当你过上全新的生活，这些经历就会在心底提醒你：你已经成熟了，千万别再回到过去那种日子。

低谷的时候，身边人总喜欢劝我们“不要焦虑”。我们谢谢他们的关心，但也清楚，人在失利之下不可能不焦虑。就像有人说“心情不好就出去旅游一趟”，可你只是心情不好，我是穷得叮当响还欠着债，旅游回来只更焦虑。我的应对方法有两个：第一，把眼前的工作做好。忙起来就顾不上胡思乱想，看看那些天天喊焦虑的人，多半是闲得没事做。第二，人总有空闲的时间，那就去找让你开心的事，哪怕要花点成本。我那时候喜欢泡吧、喝酒、撩妹子，一闲下来就用这些方式逃避烦恼。不是鼓励大家学我，但道理是一致的：给自己找点快乐，才有力量撑过去。

我还总结过一条规律：那些被打趴下却又能站起来的人，往往有两个特征。第一，被打得够惨但没被打死，还有翻本的机会；第二，就是不信命。这几年我身边不少朋友，其实已经不算创业者了。项目不顺后，他们开始相信自己这辈子搞不出什么名堂，于是放弃或者守着自己的老本行，一天天将就着过。而真正做得好的那些人，身上都有股劲——不说改变世界，就是“我命由我不由天”。遇到困难，不怕，继续干；今天不成还有明天，今年不成还有明年，大不了大器晚成。这种人，极少做不起来。

所以，如果你想做点大事，或者正卡在低谷里，请相信我：你可以什么都没有，但绝对不能不认命。这股气看不见、摸不着，但它能撑着你走完最难的那段路。如果连它也丢了，那结果大概就是平平淡淡老去。
