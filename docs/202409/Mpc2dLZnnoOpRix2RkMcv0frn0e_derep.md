# 👸号爆文复盘：两个月用“热点+情绪+立场”写出489万阅读，我的实操全记录

大家好，我是李小强，平时做用户增长。身边朋友对我的评价大致是两个：第一，比较感性，遇到能提升认知的内容就忍不住付费；第二，脑洞大、能坚持，认准一件事就愿意猛磕时间。我自己心里清楚，属于“啥都懂一点，但都不深”的类型。项目能跑通，却很难持续放大，归根结底就是正反馈不够、试错成本太高，说白了，选项目和打法出了问题。

这次能下定决心复盘，主要是受猫哥触动。其实我在这个社群已经待了一年多，之前一直“潜水”，总觉得自己没啥可输出的。这次想认真留点东西，也就不套什么模板了，直接讲人话，欢迎大家拍砖。

## 我是怎么一步步走进👸号的

去年10月，GPT正火。我试着用它去头条上找那些刚发布、点赞高的文章，改一改发到👸号，账号一下子就“活”了。不过那段时间挺累的，每天下班还得手写7篇稿子，到家基本精疲力尽。账号连续爆了两周就停了，我当时反而松了口气：总算不用手动搓文了。后来想在社群里找个技术大佬帮我搞成全自动，一直没遇上合适的，账号就断更了。

今年6月，我在社群里看到猫哥写的一篇RPA自动化写稿的文章，还直播演示了文案号一键生成。我马上联系了猫哥，用三个号发了一个月文案。猫哥推荐我去学RPA，我就花了一周啃初级内容，发现确实能自己写程序实现，但改bug、调迭代太耗时间，根本不擅长。后来兔子鱼老师给我介绍了猫哥的陪跑营，感觉就是照着我需求设计的。巧的是，那个月我正好出了一篇170万阅读的爆文，有收益，果断报名。

刚进营的时候，学习资料多得吓人，群里又是一群打了鸡血的学霸。我一边亢奋一边担心自己跟不上，经常在群里问很基础的问题，但大家都很热情地帮忙。猫哥的直播讲解很实用，兔子鱼老师天天给我们“打鸡血”。那段时间，指令学习、软件操作、爆文选题、自动化生产、代运营分成模式、自营多账号……全都跑了一遍。

9月，我在猫哥的群里立了个flag：年底前副业收入要超过工资。结果这个月就做到了。以前我总觉得自己是运气好才做成事，心里不踏实。这次亲身体会到，成功确实有迹可循，大家可以按需自取。

## 我每天都忙些啥

半手搓账号每天要选题、写稿6-8篇；自营小号每天养号、稳定更新；代运营也要同步发文章。白天上班9小时，剩下的时间基本全押在副业和学习上，每天至少6小时。好在上班的地方离家近，幸福感很强，不然真撑不住。

以前我是那种倒头就睡的人，现在别说睡到自然醒，每天凌晨还在干活，早上5点多就自动醒了——一半是因为家里的猫，一半是因为五点👸号收益更新，潜意识根本不让我睡。这两个月几乎零社交，除了喂猫铲屎、简单打理自己，其余时间全在👸号上。如果你是上班族，同时搞2-3个号应该不难，我纯粹是号铺得太多。

## 爆文的门道，哪些值得抄作业

### 起号：先让平台觉得你“像人”

新号确实有方法。猫哥有句话让我印象很深：如果你的排版和内容比别人更像真人精心编写，平台就会给你推荐。这里面的关键就是内容吸引力和排版。我两次起号，一次靠文案号，一次靠Python号，本质上都落在这两点上。大家起号可以想想：什么内容能轻松批量做到80分以上，又刚好是平台缺的？大部分能符合这两个条件的，就属于不错的起号方向。我现在已经有两个小号这样跑起来了。

### 爆文怎么写：我的三次实战验证

第一篇爆文是怎么来的？文案号转领域后，有两天内容阅读量过了千，我判断账号已经进流量池了。后来有天晚上，我发现一个对标号连续两天更新同一个话题，篇篇10万+。我立刻判断这个话题肯定能爆，于是模仿了它的标题、信息提炼和开篇片段，封面也特别注意，如果拿不准就直接参考对方标题封面（注意不能用人家的版权内容），但正文表达和主体内容自己重写。结果刚发出去阅读量就破千，第二天开始疯涨，连续三天跑到173万才停。之后整个账号回落到一天几百阅读，那段时间感觉账号像“静默”了，我以为号死了。但第二天又可能回到一万阅读，要么还是几百。后续又更新了两周，基本没啥大起色，不过能明显感觉到，不同话题带来的阅读量差别很大。

那阵子心态确实有点浮——从大爆到归零，落差需要时间消化。猫哥鼓励我加号做代运营来平衡心态，另一个方向是多做号。之前我一直卡在生产，现在生产已经不是问题，于是开始批量养号。

第二次爆文，是我仔细拆了自己第一篇爆文后找到的方法。那篇文章最大的特点是情绪植入和观点立场鲜明。于是我又挑了个同类型话题，照方抓药，果然马上又爆了。第三篇，我在原来的基础上继续加信息增量，继续复制“热点话题+情绪+立场鲜明”的打法，还是成了。

写得多了会发现，网感是真的存在。看到某个内容，看数据、看噱头，就能大概感觉出它放到自己账号上能不能跑起来。现在日常更新，每天都有几千、上万的阅读。

陪跑营对我的价值很大。第一，一群人在路上，精神上不孤单；第二，信息能交叉验证，一个人遇到的卡点不一定是真问题，多几个人都遇到了，那可能就是规律，能大大降低试错成本；第三，交流容易碰撞出火花，别人随口一问，反而会激发你调动过去的经验。

### 账号基因：别跟系统的判定拧着来

每个账号确实有自己的“基因”。系统一开始把你定义成什么方向，它的话题偏好就会很明显。同样一篇文，我让朋友去发，效果就不好，因为我们的受众年龄、性别和起号内容差别很大。前期话题可以广一点，多测试；后期就顺着账号偏好，把某些话题吃透、做遍。一个话题能辐射多少内容，就全网找素材，做到覆盖。

### 人性：做爆文要先放下自己

这次做爆文，我特别强烈地感受到：要克制自己的人性，尤其要甩掉“好学生”“老好人”的思维。我以前是中规中矩的人，怕在大众面前出糗，还带点讨好型人格，生怕错别字、偏激观点惹到谁。评论区一有不好的声音，我的自尊就会炸毛。但爆文需要的恰恰是放大读者的人性，顺着或逆着他们的情绪来。这要求你先放下自己的潜意识偏好，真正去想读者需要什么。从“知道”到“做到”，真的是一段很长的距离。

### 分析账号：让数据告诉你答案

有了十篇八篇的数据后，就可以重点分析自己账号喜欢什么话题了。点赞、收藏、分享、互动，都要看。爆过的内容，继续发大概率还能爆。话题可以迁移，可以联想，关键是找到自己爆文的框架，然后“旧瓶装新酒”。特别是要逐字逐句拆自己爆过的文章，看观点怎么输出、语言怎么表达、情绪怎么传递、结构怎么搭——这些完全可以模板化。

### 关于收益的几个关键认知

老账号万次阅读收益大概在30到100之间，我也有单价很低的号；新号大概30左右。想提高收益，几个点很重要：

1. 文章长度：👸号好像改版了，内容低于1000字也可能有2个文中广告，所以没必要硬凑长文。
2. 完读率：我的账号完读率在70%-80%，个人觉得这个数据对单价影响很大。
3. 持续稳定增量：文章持续稳定增长，单价才会稳步上升。好几篇爆文都验证了一个点：总阅读高，不一定收益高。
4. 老年群体：比如我妈60岁，会把视频广告当内容认真看，误点广告的概率也不低。
5. 文章互动性：情绪和立场可以带动互动，进而给文章正向加持。最好在结尾或者文章里增加一个互动场景话题。
