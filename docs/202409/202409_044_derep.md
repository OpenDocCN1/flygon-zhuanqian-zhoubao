# 创意，本质上是在找更聪明的解法



以前在广告圈待着时，我对“创意”的理解很片面，脑子里浮现的都是戛纳获奖的那种惊艳作品。直到自己出来创业，才慢慢明白，创意其实在更高一层，它就是把问题解决得更有效的方法。

我最常拿来举例的就是暴风影音那次招聘。

当时人事找到市场部，说要为招产品经理投放广告。奇怪的是，已经投了很久，简历却寥寥无几。我们停下来重新审视需求：人事真正要的不是一则广告，而是能直接联系到候选人的电话。跟总监聊完，他直言，只要把产品经理的联系方式给他，他自己就能去挖人。

思路一转，方案就变了。

那会西少爷肉夹馍正火，店面扎堆在中关村和各大科技园区。我们和西少爷联手推出了一个“产品经理专属餐”，凭产品经理名片，9块9就能吃一顿，差价由暴风补。仅仅三天，我们就拿到数百张名片，活动花费不过几千块。同期在招聘平台投广告，花费和效果都远不及这个。

这就是典型的用更聪明的方式解决问题。

最近家里也出了一个小案例。

我岳父岳母要去马来西亚看女儿，英语几乎不会，过海关我们又抽不出身陪同。我第一反应是花钱请个陪同人员全程带队。可我太太想出了更顺手的办法，直接申请国航的轮椅接送服务。这样老人从出发机场到抵达机场，全程都有工作人员护送进出。

同样解决通关焦虑，一个方案更重、更贵，一个更轻、更省心。

所以说到底，创意不是花哨，而是更优的解决路径。
