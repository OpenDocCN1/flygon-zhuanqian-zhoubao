# 同样是教培巨头，为什么学而思没能诞生董宇辉？
作者：龙哥

两个月前，我受邀去学而思做了一场营销交流。席间聊到一个很有意思的话题：新东方转型后能把直播带货做得风生水起，还捧出了现象级主播董宇辉，为什么学而思却做不到？

创始人张总回答得毫不犹豫：“我们做不了，这家企业没有这样的禀赋。”

这句话，也印证了我之前的判断。一家公司能做成什么、做不成什么，往往不是靠一时的运气，而是由它长期积累的“基因”决定的。

不信你可以换个问法：为什么学而思没有出过罗永浩、李笑来、李丰、古典这样的名人？他们有一个共同身份——都曾是新东方的老师。

新东方当年的打法是“名师策略”。从选拔到培养，都极其看重老师的个人表现力：课上要有氛围，段子要讲得精彩，跟学生的互动要有化学反应。正是这套标准，让新东方成了名师大本营。罗翔也曾在新东方任教，脱口秀演员刘旸也有过这段经历。我见过徐小平老师两次，他那份即兴演讲的感染力，放到今天来做直播，也完全有头部主播的潜质。

学而思则完全不同。它走的是“标准化课程研发”路线，核心竞争力不是某个老师的个人魅力，而是那套被反复打磨的教研体系。只要有一定学历基础，培训一两个月，老师就能照着标准流程上台授课。

我孩子小时候上过学而思旗下的摩比思维，我在教室里旁听过不少次。最直观的感受是：不同的老师，讲出来的内容几乎一模一样。课堂节奏、互动环节、教具演示，全都是提前设计好的。老师当然也会临场发挥，但主体部分就是标准化交付。

本质上，学而思是用教研的确定性，替代了名师的不确定性。

我在《营销笔记》里聊过一个观点：企业能不能做大，要看标准化和供应链能不能形成规模。按摩就很难标准化，所以很难大规模复制；霸王茶姬的标准化程度高于喜茶，因此跑得更快。

新东方的名师模式，优点是老师自带流量，招生更容易；缺点也很明显——交付质量依赖个人状态，而且名师一旦有了名气，很容易自立门户。这跟今天直播电商高度依赖头部主播、大主播动不动就单飞，是同一个逻辑。

当然，也不是说名师模式就完全做不大。我们有个客户智博教育，走得更极致：几万学生，只有几位名师讲课，再用“名师直播授课+线下班主任辅导”的双师制，把个人能力放大到了极致，也做到了山东专升本市场第一。

但在大多数市场里，标准化仍然是更容易做大的那条路。

看看两家公司当年的业绩曲线就知道：新东方2006年上市，学而思2010年上市。学而思的总营收一直低于新东方，但增长速度在上市后明显更快。两者的差距不断缩小，到2017年，学而思的市值已经反超了新东方。

我2011年创业做在线教育时，学而思还找我聊过收购的事。我当时见过他们几位董事会成员，坦率地说，我们的模式还没被验证，不值得收购。在当时的我眼里，学而思的模式确实比新东方更“高级”。

但我现在不会轻易下这种结论。企业发展很像生物演化：一种动物能在特定环境中占据优势，不是因为绝对“更好”，而是因为它适应了那种环境。一旦环境发生剧变，优势可能变成劣势，劣势也可能变成新机会。生物只能靠漫长的进化来应对，企业却能快速掉头。

教培行业变天后，新东方的名师基因恰好和直播带货的潮流严丝合缝，于是出现了董宇辉这样的超级主播，俞敏洪自己也成了头部。而学而思长期积累的是教研能力，想转到直播这条赛道，自然要吃力得多。

这就像硬币的两面。新东方吃到了名师红利，也要承受大主播单飞的明星风险；学而思没能诞生董宇辉，却把教研积淀转化成了学习机、网校和图书出版的好业绩。如今的新东方也早已不靠纯名师打法，而是投入了大量标准化研发，但在这条赛道上，学而思的经验曲线依然领先。

所以，两种模式没有绝对的好坏。只要善于适应经济环境，各自发挥长处，都能活得很精彩。

这两家公司的故事，恰好说明一个道理：企业经营没有统一答案，成功从来不是一条路走到黑。我在《营销笔记》里特别强调过一句话：营销的营，首先是经营的营。

自然界里，狮子吃不到海豹，鲨鱼也抓不住羚羊。与其羡慕别人的猎物，不如把适合自己的事做到极致。我们为企业做战略咨询时，也从不会套用某个成功的模板，而是回到企业本身，找到它真正适配的路径。

评论区：
- 流水线上长不出董宇辉，但能长出学习机。
- 新东方赌的是一个人的爆发力，学而思赌的是一套系统的确定性。
- 名师模式是个人杠杆，标准化是组织杠杆，没有对错，只有场景。
