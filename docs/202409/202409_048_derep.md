# 5 万字长文，从负债百万到财富自由之路（一）

聊一个我朋友的故事吧，从云端跌到谷底，再从谷底爬回山巅的那种。如果你现在正为钱发愁，或者正迷茫该不该创业，建议你耐心看下去。

他曾是深圳光鲜互联网公司的运营，月薪过万，日子安稳得让人挑不出毛病。可他偏偏在人生最顺的时候踩了个急刹车——为了爱情，辞掉工作，回了长沙。你以为这是浪漫小说开头？不，这是催债电话的前奏。

回长沙后的第二个月，他揣着五十万存款扎进创业大潮，没做任何市场调研，就凭朋友一句“这行来钱快”，把全部身家砸进了🛰️群广告生意。那阵子他天天买设备、上项目、交学费，花钱如流水。现实很快教会他做人：亏到发不出工资，靠信用卡硬撑，撑到七月，公司关门，负债一百二十七万。

你看，他踩的坑我们太熟悉了：看着别人赚钱就眼红，根本不看清自己有几斤几两，更没想过万一输了怎么办。他后来总结，这哪是创业，分明是拿命赌运气，赌输了还不上岸，总觉得下一把就能回本，结果窟窿越补越大。

一个人负债百万，当天晚上坐在长沙梅溪湖的石头上，看着行人牵着手，想起自己刚失去的爱人，心里堵得说不出话。为了省钱他搬去朋友那儿，和两兄弟挤上下铺，白天醒来看到满桌烟头和没洗的碗，晚上靠喝酒才能入睡。他后来说，那时最怕的不是还不起钱，而是在一个又一个看不到希望的黑夜里，怀疑自己这辈子就这么完蛋了。

不过这人骨子里有股拧劲儿，活人可以被打趴下，但不能认命。他硬是撑住了。之后的故事像开了挂：二次创业踩中抖音风口，从零翻身，不仅还清所有债，还成了抖音电商行业的头部IP，拿了“最佳直播操盘手”，出了书，开了四家公司。甚至在30岁那年想明白一件重要的事——世俗的名利都能放下，真正重要的是和自己和解。

关于这段经历，他特别掏心窝子地给了几条建议，句句扎心：

第一，别恋爱脑。谈恋爱可以，但你得先在事业上立得住。你自己立不起来，感情也容易跟着崩。

第二，别什么都没想清楚就创业。你连自己要做什么都不确定，全靠道听途说，那跟闭着眼睛跳悬崖没区别。真想干，趁着上班时就做准备，骑驴找马，攒资源、积人脉、练本事。

第三，圈子一定要干净。常和赚快钱的人混，你做事的思路也会被带偏。他那时候为了面子，没钱还硬请客去夜场，事后自己恶心自己。

第四，凡是教你“稳赚不赔”的项目，九成都是坑。哪有什么轻轻松松的暴富？好消息真要轮到你头上，先问问自己配不配。那句话怎么说来着——我们这种人都能听到的项目，不是骗局，就是早被人玩烂的收割局。

第五，动手前先想清楚自己最多亏得起多少。创业失败很常见，能爬起来的人，往往都是摔了一跤但不至于摔死，而且死活不肯认命。当初他要是肯在亏七十万时止损，撑死了欠二十万，打工两年就还完了；但他一直拖到亏了120万才收手，才把自己逼上绝路。

第六，看不清项目是不是还有机会，就花五千块请五个懂行的朋友吃饭，把你的真实情况摊开讲，听他们的判断。当局者迷，旁观者的建议能让你一下清醒。

有些路，得自己摔过才会懂。可如果别人的血泪教训能让你少摔一次，那这故事就值了。你还别说，有时候人生掉到谷底不是坏事，因为接下来每一步，都是上坡路。
