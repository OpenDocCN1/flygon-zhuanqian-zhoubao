# 被骂上热搜？赚钱团队的这封回信，值得每个创业者看看

最近，朋友圈里有人在骂赚钱，好几个朋友都截图转给我看了。

说实话，这事儿我没怎么往心里去。骂我，没问题；骂赚钱，也没问题。你但凡去知乎上搜一搜，骂赚钱的内容早就铺天盖地了，多一个不多，少一个也不少，哪怕多一两百个，也不影响什么。

我是真的觉得，骂声往往藏着一种“恨铁不成钢”的在乎。真正的失望是什么？是沉默，是无视，是悄无声息地转身离开。有时候我甚至会刻意去即刻、🧣上翻翻那些吐槽赚钱的帖子，反而能从中冒出一些新灵感。

赚钱到底要往哪走、现在走到了哪一步，我相信真正了解它的人心里自然有一杆秤。前阵子有个大IP来赚钱办公室，看我们团队规模时吃了一惊，说一直以为就几个人，没想到已经有大几十号人了。我当时的想法很简单：想交付做得够重、够好，想走向未来，那钱就该砸在团队上。这是我的长期主义。

结果团队反过来给我定了KPI：每周必须写多少篇帖子。得嘞，那正好借这机会，把一些想法摊开来聊聊。

**第一件事，怎么看“借鉴”赚钱？**

借鉴没问题，模仿也没问题。谁不是从对标高手开始的？说句实话，世界上绝大多数商业模式，本质上就是“复制”。但我还是希望稍微有点自己的东西，别叫“航海”、别把视觉搞得跟赚钱差不多、别把赚钱精华作者的文章原封不动搬到新社群再发一遍。一模一样，多没意思，对吧？

**第二件事，怎么看社群之间的拉踩？**

在我这儿，不存在“竞争对手”这个概念。我从来没把谁当对手，你可以问问赚钱团队，我一直这么讲。我眼里只有两种人：用户，和学习对象。别人有做得好的地方，我就去学。

我一直坚持一个判断：只要你在真正为自己服务的用户创造价值，价值观是正的，那不管你从赚钱学到不少、还是从赚钱带走用户，我都觉得没啥，甚至那些口碑好、价值观正的产品，我还会主动推荐、主动背书。但要是抱着“我来赚钱就是来挖人的”这种念头，那对不起，发现一个踢一个，踢一个挂一个。来这里，先交个朋友，顺便再谈生意。

**第三件事，怎么看各类社群、知识付费产品，包括合伙人产品？**

我一点意见都没有。产品形态从来不是关键，关键是内核——解决了谁的问题？对方满不满意？我自己不是目标用户，就不好评价具体好坏。

有些合伙人产品确实让赚钱受到了一些冲击，那只能怪我自己——没及时想清楚用户需求，没把商业模式设计好，导致一部分人离开，这非常正常。我不觉得任何做合伙人产品的人有错，至于商业上走得通走不通，时间会给出答案。

**第四件事，怎么看社群里的价值观？**

我觉得做社群，得承担起一份责任。不光是教方法、给技巧，更重要的是帮成员建立能支撑长期发展的价值观：真诚、利他、开放、长期主义。

大家是因为信任才聚在这里，你就更应该把真正相信的东西讲出来。这个世界的基本规律就是：真诚打败虚伪，利他打败利己，开放打败封闭，商业世界更是如此。

千万别给用户灌输错误的东西——叫他们去别的社群偷流量，教他们爆粉的手法，告诉他们怎么写文章包装自己——这些玩意儿短期可能有点用，但长期来看，反噬一定是加倍奉还的。

说到底，所有胜利，最终都是价值观的胜利。

实体终将消亡，虚拟才能长存。创业也一样，任何业务都难逃生命周期。腾讯、阿里、Facebook、谷歌，放在时间的长河里，终有一天也会消失。而对创业者来说，一个业务能活三四年就算很好了，短的可能只有三四个月。

那靠什么穿越周期？靠团队。阿里有句话叫“借事修人”——流水的业务，铁打的团队。一个业务接着一个业务去打磨团队，团队越来越强，发现机会、抓住机会的能力自然越来越强。但团队也有老化的一天，核心的人也会慢慢退到幕后，那时靠什么在弱肉强食的丛林里继续走下去？

靠使命、愿景、价值观的传承与迭代。这些虚拟的东西，永远不会消失。

从终局看，一流创业者拼的，就是谁的使命能解决更多问题，覆盖更多人群，解决得更刚需、更高频，谁就能活到最后。

说到这里，我也想坦白一件这两年里我犯过的最大的错。

表达欲下降，输出变少，特别是在“什么是对的”这件事上，讲得太少了——不管是对团队还是对社群。结果显而易见：

一是团队文化被稀释，大家眼里全是事情本身，遇事容易争对错、起冲突，却找不到做事的深层意义。二是社群文化变淡，整个圈子越来越功利、浮躁，从赚钱引流到某些圈子里居然成了“政治正确”，坚持赚钱那套价值观的人越来越少——真诚、利他、开放、空杯、长期主义、日拱一卒、实战赚钱。

对不起。这完完全全是我一个人的错。作为两个组织的负责人，把文化立起来、传下去，是我推不掉的责任，而过去两年，我松懈了。

好在，我意识到了。意识到，就是改变的一半。我也没打算试图改变谁，只是把我觉得正确的事说出来。你认同，欢迎留下；不认同，下一期开始前随时可以离开。

本质上，我们这群人是因为价值观相同而走到一起的。而当这样一群人聚在一起，那个能量，远比你想象中要大。
