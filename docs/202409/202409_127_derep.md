# 夜市摆个玄学摊，每月多赚2W+，保姆级实操指南
作者：龙哥

大家好，我是龙哥，常年做玄学培训。进了赚钱圈子这么久，一直没认真输出过干货，实在不好意思。最近有位学员去市集试水玄学摊位，效果意外得好，我整理了一下，分享给各位。

先说说成果：她只在晚上出摊，两个月下来赚了5W，相当于每月额外多出两万多，还顺势加了150个本地付费用户，这还没算后续转化的上万元课程。今天重点聊两件事：第一，出摊前需要置办什么；第二，摆摊时怎么收费。

## 一、出摊前要准备什么？

### 1. 选品：先定盈利模式，再找摊位

很多人喜欢先把摊子支起来再看卖什么，这个顺序错了。正确做法是先想清楚靠什么变现，再根据变现方式去找对应的摊位。

地摊生意的本质是“短平快”，单个客户最多给10到15分钟。要么聊完就走，要么买完就走。看起来围着很多人，不一定赚钱，一个个轮着来才有效率。

选品要便宜、交付轻。咨询类可以选占卜、塔罗、面相、手相——这四样在玄学圈里虽然排位不高，但胜在快。产品类就卖朱砂手串这种，单价不过百，搭配咨询一起卖。

记住一点：哪怕在富人区摆摊，客户心里依然觉得这是地摊。再大方的人，在摊位上的消费也会设限。只要完成一次交易、拿下对方，这个摊位就算成功了。

### 2. 选址：跟着目标人群走

选址要跟着产品走。先定人设，想清楚为谁服务，再去挑地方。

三个关键词：方便停留、流量大、年轻人聚集。除此之外，最靠谱的办法是自己去调研，看看同行都扎堆在哪，照着找就行。

### 3. 摊位布置：三步到位

首先，视觉效果一定要亮，bling bling 的那种，让人老远就注意到你是这条街最靓的摊。

其次，让人一眼就明白你做什么。比如放个大太极图案，大家一看就懂。别让人猜，人都是出来玩的，谁愿意费脑细胞琢磨你是干嘛的？一懒得想，就走了。

第三，设置唯一付费点。就是说，客户来了只有一条路可选：要么看手相，要么算塔罗，要么买手串，别整太多选项。一多客户就要纠结，还要问“手相和面相有啥区别”，一纠缠，时间全浪费了。

做好这三步，摊子基本上就稳了。

### 4. 穿搭：和摊位调性一致

做东玄的，穿道袍或中式衣服；做西玄的，走女巫风。总之，视觉上一定要搭调，让客户觉得你专业。

这些东西备齐，再带上你做法事用的法器，出摊绰绰有余。

## 二、摆摊时怎么收钱？

### 1. 基础定价要亲民，且一定先收款

定价别太高。我学员一开始30一卦，后来涨到39，这基本就是地摊的心理价位。你甚至可以更便宜，只要能保证10分钟交付完毕。

务必先收钱再开口。玄学卖的就是信息，话一说出口，信息就不值钱了。别嫌便宜，地摊本来就不是收高价的地方，关键在后面。

### 2. 设计升单路径

摆摊的本质是“单位时间×单价”。她现场是这么升级的：30元的占卜，可以加钱升级到398元的全盘分析（含八字和星盘）。一个晚上能接两单全盘，收入就破千了。

万一特别忙，可以先把钱收了，约第二天到工作室或者线上交付。但最佳做法是当场交付，因为夜市客户不是专程来算命的，回家睡一觉冷静下来就可能要求退款。

加🛰️后的后续转化也很重要。客户今天做了个30元的咨询，觉得你靠谱，加了🛰️，你凭什么让他以后继续付费？

我学员设计了玄学培训课程，教别人学玄学，转化效果还不错，客单价也比较高。另外还有祈福产品，比如魔法蜡烛、道观法事等，都是很好的二次转化点。

### 3. 引流要靠信任，不靠赠品

最后说说引流。学员两个月加了150个付费用户，全是现场聊完主动来加的。她没送任何小礼品，设计的原则是：你觉得我有用、以后还能帮你，再加我；否则就别加。所以加过来的用户信任度极高，其中80%是女性。

玄学是终身价值的生意，圈内常说“1000个付费用户就吃穿不愁”，现在来了150个，基础已经打得很好了。
