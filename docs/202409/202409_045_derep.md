# 只因忽略这些“小细节”，有老板与5000万擦肩而过

有位在五百强企业耕耘了十余年的资深管理者，既做过CFO又当过CEO，转型创业后专门帮老板们规避财务风险、搭建管理框架。这些年她前前后后接触了上千名创业者，从刚起步年入十万的新手，到已经站稳脚跟年赚上千万的老手都有。一番总结下来，发现大多数人身上都藏着几个要命的“小毛病”。

哪几个毛病呢？一是定目标全凭感觉，脑袋一拍就定了，完全不做推演和验证；二是对财务风险既不上心也不懂怎么防，等到出了问题才追悔莫及；三是压根没把组织架构和内部控制当回事，公司内部一盘散沙。

这几个毛病乍一看都不起眼，尤其创业早期，很多事情还没定型，一个人单枪匹马也能撑起局面。在这个阶段，赚个十万二十万，甚至做到年入百万都是有可能的——因为规模小，靠个人能力还兜得住。

但问题就藏在后面。一旦业务往前冲，规模上来，这几个“小毛病”就会被无限放大，变成吞掉利润的黑洞。有老板就在这上面栽了大跟头，事后一算，错失的何止几千万。

这位有着CFO烙印的咨询顾问笑着说，自己最大的职业习惯就是严谨，笔下写的每一个数字都经得起推敲，不是随便说说而已。
