# 【赚钱心态】2 篇

你有没有发现，很多时候卡住我们的，不是信息差，也不是执行力，而是一种看不见摸不着的东西——心态。

钱是流出来的，不是堵出来的。同样一个机会，同样的圈层，有人接得住，有人只能看着它从指尖划过。差别在哪？差在底层的“赚钱心态”。它像水下的暗流，不显山不露水，却决定了你能在财富这条路上走多远。

这次给大家整理了两篇关于“赚钱心态”的干货，全是过来人实打实的体感总结。视角很真实，没有什么虚头巴脑的大道理，更像是踩过坑、翻过车之后，才沉淀下来的思考。无论你正处在起步的摸索期，还是已经有了自己的小盘面，这两篇都值得你花几分钟好好读一遍。

内容不长，但后劲很足。心态这件事，早一天打通，路就早一天变顺。
