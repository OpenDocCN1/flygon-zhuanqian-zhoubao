# 听说有人靠“搬课”闷声赚了一笔？这招真能抄！

5月自驾去甘肃，路上实在闲得慌，就琢磨着搞点副业。当时手里正好有一个达人分销的业务板块，积累了两万多达人资源，而且之前就有靠卖课跑通的案例。于是，我决定照着老路再走一遍。

第一步，搞到一门好课。我直接在抖音上找了一门同行里口碑不错的课程，原价499元，先买下来。接着又去淘宝花了15块，搞到了网盘高清破解版。这样，课程资源就到手了。

第二步，搞流量。我的方法很朴素：去抖音搜索讲达人分销的知识博主，挑他们点赞量最高的那条视频，把文案扒下来。然后用Word重新写成更容易读的口语化版本，再配一张主题鲜明的海报。文案和海报一起丢到📕上，结果没想到，稀里糊涂就跑出了几百万播放量。

后面的事就顺理成章了：后台咨询量冲到600多，导到🛰️的有100多人，最后大概成交了50单。

整个过程谈不上多复杂，关键就是选对爆款、改好文案、找到流量池。至于具体细节，评论区有人问，我也没想到大家这么感兴趣。
