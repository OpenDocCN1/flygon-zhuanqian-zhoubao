# ('如何通过抖音卖几百万非遗拓片', (2, 16))

你可能从没听过“传拓”这门手艺。

说白了，就是用墨和纸，把刻在石头、铜器、陶器上的图样“搬运”到纸上。这门技术从宋代那会儿就传下来了，既有考古的讲究，也有艺术的味道。我做的牌子叫竹庐拓艺，佛像、碑刻、画像石、铜器铭文、陶器刻字、瓦当纹样，什么都碰。这几年我们试着把老花纹做成适合现代人家的装饰，慢慢也趟出了一条供应链。

线上我们只开抖音，一年做到几百万的盘子，一件货的均价大约在1000到1200块。线下手里有两个展馆，上海一家、郑州一家，后面还打算去北京和广州落子。抖音这个品类里，我们数据排在前头。但说句心里话，线上只是开胃菜，真正的重头戏在展厅里那几万、几十万的大单上。

这事儿的起点，有点意外。

当时我们义务帮河南省残联拍些宣传短片，镜头里扫到一位老师傅，他是非遗传承人，专攻拓印。那片子发出去，莫名其妙就火了。我们顺手挂了个链接试试水，头一个月就做出了50万的成绩。后来接触的匠人多了，发现一个很普遍的事儿：活儿做得是真漂亮，卖货是真不会。慢慢地，有人跟着买了车，有人回村里翻盖了房子。看着这些变化，我心里踏实，觉得这条路有奔头。

说起干过的行当，那可多了。

最开始在古玩圈儿里混，河南头一家的中州古玩城，当时做青铜器、高古玉、高古瓷的那帮人，基本上都在我们那一带。后来给字节跳动、小红书、支付宝、腾讯这些大平台做内容供应，还对接过CCTV、各大卫视和美国国家地理频道，前前后后管过接近200个账号。再往后，内容从稀缺变成了泛滥，老业务就慢慢淡出了。还搞过一阵直播卖货，卖珍珠、卖名牌包，最拼的时候带了20个主播杀到诸暨山下湖村蹲点。

回过头看，早期一直在帮别人攒局：帮古玩城的朋友出货，给平台当内容供应商，替厂家吆喝带货——兜兜转转，却没给自己留下一个牌子、一款自家的东西。碰到非遗传拓，我们才算想明白：不管行业怎么变、规则怎么改，把东西做好，才是永远不会翻车的那块底牌。

这些细节讲太多没意思，我更想说的是思路。

先看平台。

最早我们卖拓片，单价也就几百块，同行还在卖几十块，那阵子天天心里发慌。

![](img/98d4f0bd6825d8907392e7a82792aef8.png)

后面我把价格往上拉，是因为琢磨出了平台的套路：抖音正从兴趣电商往货架电商转，现在直播间考核的是成交单量，所以你看那些低价热闹的直播间，人挤人，买的人却不多。往后平台的逻辑大概率会向天猫、拼多多看齐，谁转化强，就给谁流量。我们的直播间大几百人同时在线，1000次观看能做出4000到6000的GMV，偶尔还能冲到一两万。所以我有底气说，高客单一定是接下来的方向。

再说说做什么货。

你的东西是卖给谁的，决定了它该长什么样。上海那家展厅所在的地段，房价20万1平米，90平就要近2000万，就算二线城市，一套房也得200万起步。你说这种人家，会在客厅挂一幅几十块的复印画吗？不会的。他们要的是有年头儿、有说头儿、能镇得住场子的物件。所以我们做设计，就往这个方向靠。

另外还得让人有炫耀的余地——真正懂拓片的没几个人。各位猜猜这幅画上刻的是什么字？

![](img/79729a74d65ef37c30eed526cef17a10.png)

答案就是“中国”二字。这是迄今为止能找到的最早出处，出自西周青铜器何尊，铭文里刻着“宅兹中国”。专家们读到这四个字的时候，像挖出了一封写给千年后无数中国人的信。三千年前，它被铸进青铜器里、埋到地下；三千年后，这方寸之间的几个字，成了960万平方公里土地共同的名字。你把这故事一说出口，谁听了不心动？

书画圈里有句话：三分画，七分裱。我们在装裱上，下了不少死功夫。

![](img/8280bf1838403c69c35290fdfda7070b.png)

一个画框，硬是做了八层：最外层是实木框，为了挑这个木头，我们试过二十多种，最后定了俄罗斯黑松。第二层是亚克力面板，接着是卡纸、拓片、背纸、龙骨架，再加一整张封板，最后封上防尘条。这套材料拿去找人手工裱，随随便便上千块下不来。所以收到货的客户，都会觉得比家里同等价位的画高一截。

做这个项目的过程中，我们还摸索出一个特别稳的品类：信仰。甭管经济上行下行，有信仰的人一直都在。富人有富人的寄托，穷人有穷人的念想，这个需求躲不开。而且这类内容的播放量出奇地高。

![](img/e4045d3d32e43ed5c986dbc2008893c2.png)

有一款西方三圣，卖了一千多件。

![](img/bee6476f4dfd8de658c0eb2f77cb13a5.png)

装上框之后的版本，一件能到近3000块。

![](img/a2c97c9120dd86415c3fb554afff1fb4.png)

说万物皆可拓，真不是吹的。明年打算再上个妈祖像——要知道全球信众两个亿，这市场多大，不用我多说。

然后是人。

抖音后台给我们的标签很明白：新锐白领和中产家庭。这两拨人手里有钱，又讲究生活质感。我们顺着这个路子开发了唐卡系列、心经、佛像、大师题跋的拓片，定价过千，反而卖得更快。还有个有意思的细节：后台订单的手机尾号，一水的连号——88888、6666、00000、9999这种。每次上新品，价格都有往上抬的空间。前阵子刚出了一单6666的，还有几个明星客户，一买就是好几万的东西。

![](img/e66a52a4275ab0ab5143d1da2c81f1ed.png)

照片里那两位，大伙儿认出来没？

抖音的流量，说白了就是靠短视频往直播间引。

![](img/ab8b78d1f4ab62acd2083b3c730696c1.png)

我们手里攥着十几个抖音号，小红书、快手、视频号也各自养了8个。内容主要拍产品。直播间改过好几版：最早老师傅在后面现场拓，主播在前面讲，可就是卖不上价，背景太糙了。后来琢磨出味儿了——这行当吃场景。现在布置了佛堂、玄关、茶室、书房这些实景，感觉一下就对了。到今天我还在琢磨怎么把场景再往上提一提。

成交主要靠5个直播间、分在不同城市，全部通过直播完成，然后再把客人沉淀到私域里。平时也会用平价商品引流、免费赠送拉人气，再加上线下展厅搞活动来逼单。

这产品的卖点，说白了就是文化和场景。线下展厅隔壁挂着娘本唐卡，贵的那幅逼近千万，便宜的也得几十万，我们的作品就摆在一起卖。当场景对了，便宜的也能卖出不便宜的价。就像在生财有术里混圈子，你跟谁站在一起，你的价值就不一样。

线上说白了就是个入口。我们的平价拓片，最主要的作用是获客。等客户从线上认识了拓片、体验过它的美，再到上海、北京、广州、深圳的展厅里去感受实物，几万、几十万的高客单，都是在线下接住的。

合作的路子也铺开了：线上准备启动精选联盟，给产品分门别类。本来我们就有一批几百块的产品，适合达人带货。有个同行，就靠一条短视频卖了几千单，自己实在没精力铺量，所以接下来想找信仰类、历史类、非遗类、书单类的主播一起玩。线下，已经有好些5A景区、寺庙、画廊和茶室在谈合作。

明年，线下肯定要重点砸。高客单商品，线上引流、线下成交是正解。我留意到一个空子：红星美凯龙、居然之家、宜家这些家居卖场，油画、山水画摆得满坑满谷，唯独找不到一张拓片。如果把拓片做进家居场景里，前景大得吓人。

![](img/8e9be52c92eda80f403d98d4c28eb527.png)

再往后，还有研学和体验这两条路：拓片研学可以申请各地区的非遗文创补贴，全套流程和资料我们都备好了；拓片DIY体验店加上线下门店的模式，也能让这手艺活起来。你们视频里看到的，是一位乌克兰姑娘在体验用小篆拓《心经》，完了还去参观了拓艺馆——那种跨越文化的好奇，看得人心里一暖。

文化类的东西，确实难做。一般人不敢碰，又是手工活儿，成本压不下来，慢工出细活。我们敢做，戴着一点使命感，知道这事儿得靠时间熬。我脑子里经常想的一个画面，是日本那种“文人空间”——里头全是宋朝的极致美学，器物也好，书画也好，都是老祖宗留下的好东西。我们希望，传拓能成为这种空间里的一抹墨色。

现在竹庐拓艺馆手里有大小石印版上百件，一天能拓出300来张，一年销售额接近2000万。就是受限于场地和资金，暂时没法放开手脚。我们想找志同道合的人搭伙，把这门手艺带到更多地方。谢谢各位。
