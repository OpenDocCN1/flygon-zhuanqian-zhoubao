# 起源

项目是我去年下半年启动的。当时中医养生类带货在视频号还挺吃香，一个做朋友正好在跑这个赛道，用三個号试了几个月，流水做到十万上下。他把从冷启动到转化的整体路径完整复盘给我听，起号方法、内容节奏、选品逻辑都很清晰。听完后我脑子里冒出一个想法：这套打法完全可以提炼成可复制的SOP，然后用技术去放大。

于是我们分工明确：他主导内容方向和选品把控，我负责技术落地，把素材加工、成片合成、投放发布全自动化。内容的人味和技术的效率合到一起，矩阵化就顺理成章了。

# 路数

带货垂类虽然品类不同，但底层打法高度趋同。我自己吃过中医养生和教育类目的亏，起跑、养号、引流、挂车、放量，这一套链路是可以固化下来的。

在内容形态上，原创 > 二次剪 > 搬运。我们选定的策略是：直接对标当下表现好的爆款进行再创作。视频大致分两类，一类负责吸睛拉流量、涨粉和打标签；另一类负责带货转化。把同行近期验证过的热门片子当作母版，1:1还原，基本能保证基础分。

一条视频拆下来其实就六个构成单元：底图/底视频、标题、主体画面、口播文案、字幕层、背景音乐。标题通常包含主副两层。以我们最早用的中医引流母版为例：
- 底图：中医名家肖像，局部放大做模糊处理
- 主标题：请稍等，xxxx
- 副标题：无
- 主体画面：同款名家肖像
- 口播：国医大师xxx
- 字幕：不显示
- 音乐：不使用

# 自动化实现

## Step1、模板拆解

先把母版拆成可替换的零件库，如上所述，任何片子都由这几类元素拼合而成。

## Step2、素材搜集

针对拆解后的每个零件，去构建相似的素材池。背景图、主体画面、BGM等都要准备多版本。比如第一版母版需要名家肖像，第二版用的是中医场景实拍片段，素材采集方向就按这个来。

## Step3、自动合成

素材池齐备后，就能写生成脚本。模板越做越多，公共逻辑会被抽象成底层组件，后续新模板基本就是组件拼接，几分钟就能上线。抖音上大部分不依赖重特效的作品都能被还原，关键在于拆解是否到位。

为了避免同质化，我们在生成时加入了差异化机制：
1. 每个零件在库内随机抽取
2. 多片段模板中，每个片段的截取区间也随机滑动
3. 混入自拍的随拍画面作为扰乱信号

这样产出的每一支片子都具备独特性，原创校验基本都能顺利通过。

## Step4、自动分发

有了稳定产出能力后，人工上传显然低效。我们做了跨平台分发系统，成片生成即推送至抖音、视频号的多账号，实现同片多用。目前系统运行平稳，人工介入主要集中在选品和模板迭代，这两项本身也能方法化。剩下需要盯的是数据表现和账号健康度。

模板形式千变万化，但拆解后都能收敛到上述元素。内容生产和分发稳定后，扩量成本很低，复制到新赛道也只需更换素材池和母版。

# 收尾

内容自动化从文字时代的文章生成器开始，经历图文批量，到现在视频化，思路一致。除了带货，这套能力也可以用于品牌宣传、服务推广、引流获客、SEO 等场景。

免费流量越来越卷，单点突破难度加大。矩阵化用数量对冲波动，数量的前提是能持续稳定输出高质量原创。自动化生产比人工剪辑在成本和效率上更有优势，这也是我持续投入的原因。
