# 【生财认知】

## （149 点赞）《 如何面对增长的问题》

写在前面。

不可否认，我们正处在一个重要节点的后半场。如今百废待兴的氛围依旧浓厚，几乎所有人都开始盘算：新的一年里该怎样实现增长。但我想先提醒你一个事实，真正让大量企业增速放缓的拐点，并非始于疫情。增长乏力的苗头，在 2019 年就已出现。

疫情只是把原本存在的矛盾放大了，并不是根源所在。而时至今日，重新开放后的中国和世界，与三年前早已截然不同。无论体量大小，增长都有天花板，没有一家企业能够永远指数级上升。

因此，企业家们常问我一个问题：如何实现增长。

之所以这个问题反复出现，是因为我们已经习惯了长达 40 年的高速发展，就像每天习惯三杯意式浓缩，换成拿铁立刻觉得寡淡无味。

你要认清现实：绝大多数企业在绝大多数时间里，都是零增长的。绝大多数人也很难实现升职加薪。即便在美国这样最成熟的经济体里，一个本科毕业生一生平均的晋升次数也只有 1.5 次。

所以走过这一步之后，我们需要重新校准对增长的认知。

下面这段文字，摘自两年前的朋友李靖的一次演讲分享，与你共勉。

完整演讲有所删减。

谈到增长，我们最熟悉的思维框架就是：提升效率、获取流量、实现增长。经典的 AARRR 模型就代表了这种思路。

这几年，无数企业都困在这一套逻辑里：融资、拉新、变现、再融资，反复打磨效率、追逐流量。

时间一长，很多人都产生了一种疲惫和无力感，像被鞭子抽着狂奔，明明拼尽全力，却很难再见到实质性突破。产品还在做、流量还在找、组织还在优化，能力也在提升，可始终卡在原地。

这就是典型的增长瓶颈。

瓶颈期的一个普遍特征是：越想增长，离增长越远。

举个例子，某个在淘宝做零食的品牌，借势起来后为了维持势头，只能不断扩品、靠新品去拉新流量。

结果是，每个品类的原料采购量都做不大，规模效应出不来，无法给用户提供真正的性价比体验。即便销售额上来了，信任却在流失。同时公司需要成立大量项目组、采用不同的工作流程，管理复杂度急剧上升，创始人甚至开始怀疑自己的管理能力。

但又无奈，增长是必须的，停下来势能就掉，硬扛着走吧。往往扛过来的不是突破，而是更深的恶性循环。

用一句话概括，就是我们被自己想要的东西绑架了。

我们都明白，真正的增长来自于抢占大趋势、创造用户超额价值赢得口碑，以及持续的积累与沉淀。

可一旦被增长预期绑架，就会丧失这些习惯。开始投机跟风、算计得失、抢资源抢流量，却不再做开创性工作。结果离增长越来越远。

进而恶化成自我怀疑，觉得不够狼性、不够拼，于是过度压榨自己，生活在焦虑、FOMO 的恐惧中，更难专注、更难热爱，最终优势也被耗尽。

这是一个典型的增长怪圈。我也曾深陷其中，反复思考如何破局。我的结论是，破解增长焦虑的唯一路径，是把视角从“追求增长”切换到“创造价值”。

我的老师宁向东教授曾推荐我看《雍正王朝》，九子夺嫡的情节极具启发。

康熙朝的太子和八阿哥就深陷这个怪圈。他们拼命想拿到皇位，于是拉拢更多大臣、攻击竞争对手、回避所有吃力不讨好的任务，比如追缴国库欠款这种有政治风险的事一概不碰。

结果，这种争权行为反而耗尽了他们最宝贵的资产——皇帝的信任，离皇位越来越远。

反观四阿哥，他的谋士邬思道提出一个反常识的战略：争是不争，不争是争。想着如何争权，反而离皇位更远；不去争权，而是想着如何为大清创造价值，才能赢得信任，这才是真正的争。

当四阿哥用这种贡献的视角去看待夺嫡时，行为自然不同：主动揽下苦差事，关键时刻不落井下石。这些选择最终帮他赢得了皇位。

电视剧与史实有出入，但给了我一个重要启发：视角转换会带来质变。核心在于从“抢夺”的视角，变成“贡献”的视角。

同理，面对增长焦虑、长期增长困局，短期增长其实容易，算账就行。长期增长却极其困难。破局的关键不是找方法，而是转换看问题的角度。

最难的转变，是从“我要如何得到增长”变成“我如何成为一个值得被奖励增长的人”。只有进入这个视角，才能去做真正利于长期增长的事：把握大势做开创、关注用户提供超额价值、长期积累。

否则方法再多，喊再多长期主义也没用，问题不在大脑，而在那颗“心”。

那么怎么切换视角？

曾鸣教授曾说过，现在的战略核心是面向未来、面向用户。而大部分企业和个人的出发点是面向过去、面向自己、面向资源，这本质上就是“抢夺”的视角。

要摆脱这个视角，需要三种勇气：面向未来的勇气，而非面向过去；面向用户的勇气，而非计算利弊；积累价值的勇气，而非抓取资源。

1、面向未来而非面向过去的勇气

我一直好奇，为什么很多开创性的创始人做到一定规模后，会变得守旧、裹足不前，最终陷入瓶颈。

前段时间聊过一个消费品公司创始人，他每天忙于渠道、联名、找便宜流量，却在我问“你觉得行业未来三年最大的机会是什么”时愣住了。

创业早期他对未来有清晰判断，规模起来后，反而失去了对趋势的感知，开始在资本驱动下盲目追求规模。

这背后有一个身心灵课程里提到的观点：你如何理解过去，就决定了你如何应对未来。

公司复盘时常问：过去我们坚持了什么才走到今天？暗含的假设是继续坚持就能创造明天。总结出很多方法论和价值观，这没错，但随后用历史经验决定未来，往往就自我设限了。

我还记得研究生时读的柯达案例。当时很多人认为柯达成功是因为坚持成像品质和性能，这反而限制了它进入数码相机市场。事实是，柯达最初的成功是创始人伊士曼发明了便宜、便捷的大众相机，把相机从专业工具变成大众产品。成功的关键是便捷性，而非高品质。

如果复盘时多问一句：“过去我们抓住了什么机会、打破了什么惯例，才走到今天？”视角就会完全不同。

每个有成就会的公司和个人，都曾抓住趋势、做出开创性突破。但一旦成功，就容易忘记这一点，误以为靠日复一日的重复动作成功，只要继续提效、改正缺点就能复制成功。

当成功没到来，就会怀疑自己不够狠、不够坚持，进入更保守、更自我设限的循环。

回顾过去没错，但巨大的增长一定来自巨大势能下的开创性行动。

历史上成功的大公司几乎都与当时最重要的势能结盟：LV 推出轻便耐磨旅行箱，抓住 19 世纪欧洲火车普及的机会；耐克赞助顶级球星，抓住电视转播崛起的机会；索尼抓住晶体管技术突破，开发随身听。

持续增长的公司也是如此，LV 后来成为大集团，正是因为抓住全球化趋势，率先全球直营。

这个道理很简单却被广泛忽略。进入“追求增长”的视角后，会产生一个信念：只要我还是昨天的我，就能复制昨天的成功。

基于这个信念，就不敢尝试。一尝试就不是昨天的自己，就怕失去过去的成功。

即便尝试，也带着过去的包袱，害怕不用已有资源就不能成功。

当年智能手机兴起，微软看到趋势，却想做兼容 Windows 软件的手机系统，而非以手机为核心重建系统。这个包袱拖累了 Windows Phone。

换个视角，如果目标不是追求增长本身，而是基于长期方向把握趋势创造未来，会不会不同？

苹果的 iPhone 其实是颠覆了自己的 iPod，亲手终结了 iPod 去做新业务。

宝洁最初只是卖肥皂，若按过去定位，就是深耕肥皂，很难有今天的宝洁。正是因为看到广播媒体兴起带来的全国品牌机会，才打开了更大空间。

甚至中国历史也是如此，南宋以后文化开始自我封闭，用过去定义自己，而汉唐则保持开放、兼容并蓄。

核心判断是：你觉得过去的你和未来的你，哪个更大？只有相信未来的自己更大，才能洞察趋势、不断开创，看到市场扩容、需求迁移、渠道变革和技术渗透带来的势能，并顺势创造价值。

2、面向用户而非计算利弊的勇气

在追求增长的心态下，还有一个典型困境：陷入无休止的利弊评估，怎么算都算不出最优解。

品牌该多品牌还是多品类一品牌？互联网公司该推矩阵 APP 还是一个旗舰？消费品该重线上还是线下？

把视角换成“我该如何解决用户的问题”，答案会清晰很多。

电视广告场景下，用户需要一个品牌代表一个品类，记忆方便，口播要简洁、有利益点，这时定位聚焦是必须的。

而在淘宝买零食，用户想要一店多买、打包带走，这时一个品牌代表多个品类更合适。

要不要做品牌，也取决于用户场景。买空调后悔成本高，需要品牌背书；买茅台招待客人，品牌本身就能传递价值。

增长的本质是用户持续选择。但追求增长时，我们会把简单问题复杂化，只算自己的得失，反推给用户什么，结果越来越累。

一个 APP 为了提高频次降低流量成本，给用户加一堆不需要的功能；一个集团为了增长强行多元化，做自己不擅长的行业；一个家具公司学宜家做体验式门店提高停留时长，却忽略了宜家当年解决的核心需求是“一日之内在异地拥有一个家”，这个需求在中国可能完全不同。

我们总在学习打法和模式，算自己的收益，却忽略了核心客户最关键的需求，如何围绕它迭代自己。因为太想增长，视角全在自己身上，于是离顾客越来越远。

这就像八阿哥，每一步都在算自己得失，而不是看大清和父皇真正需要什么，所以越走越远。

3、积累价值而非抓取资源的勇气

增长焦虑下的第三种做法，是所有动作都指向资源抓取，而非价值积累。

《雍正王朝》中，太子和八阿哥越怕当不上皇帝，越去抓短期资源，比如投机派大臣。结果丧失了最稀缺的长期价值——皇帝的信任。

很多瓶颈期的企业和个人都会这样。

一个品牌越焦虑越降价促销、让利渠道，短期销售额上来，品牌势能却被砸掉，八项规定后大量中高端白酒就是例子，只有茅台把品牌看作最重要资产。

一个职业经理人越焦虑越要更大的权力、管理更大的业务，想靠资源证明自己，结果什么都做不好，信任流失。

一个互联网公司越在乎盈利，每笔投放都算短期 ROI，不打平不投，反而错过能带来巨大变革的机会。我的朋友曾说，字节跳动的增长部门优化的不是 ROI，而是抓住机会的速度，因为时机才是最大成本。

我们花太多精力去追逐无限流动的东西，而非稀缺不变的东西。

对阿哥来说权力是无限的，可皇帝信任是稀缺的。对品牌来说销售额是无限的，可用户心智里的高端定位是稀缺的。对科技公司来说资本是无限的，可关键机会是稀缺的。

当我们想追求增长时，更容易在数据上找安慰感：党羽数量、汇报线长度、销售额、DAU。越寻求安慰感，越去抓取容易获得的资源，而这些资源恰恰是无限的、不值钱的。

于是我们用有价值的东西换没价值的东西，真正的竞争力越来越少，增长越来越难，为了缓解焦虑又继续抓资源，形成死循环。

要打破循环，就要识别在当前环境里，什么最稀缺、最不流动：是品牌、是数据、是稀缺供给、是人才。围绕这些优化目标，才能形成正向积累。

结语

可持续增长之所以难，是因为很多人一旦成功，就不再做当初让他们成功的事情。

前些天在共读群里听人谈策略，有位群友说他的策略是“带一万个人赚到钱”。我心里咯噔一下：这更像一个目标。目标只要写出来就行，策略得回答路径和资源怎么配。要是定目标也算策略，那我定个“公司年营收百亿”就能交差了吗？

策略这个词语义太杂，我一般不看定义，只看它该有的功能。

首先是制造相对优势。少年投石手面对全副武装的巨人，拒绝了国王给的装备，因为他知道穿上重甲反而笨重，他的胜机在灵活和远距离。于是用一发石子打中对方要害。他说不出宏大的理论，但每一步都踩在“怎么赢”上。

其次是提供一条铁律，让所有行动都指向同一件事。冷战期间，美国人拿莫斯科练过一套教科书级的阳谋：逼对手多花钱。莫斯科地盘极大，防空网维护费用惊人，经济却相对脆弱；华盛顿强在技术和钞票。于是美方的动作全部服务于一句话：增加对手的防卫成本。先推进远程轰炸机计划，并不需要大量生产，只要让对手感到威胁，对方就得掏钱升级防空系统。后来在阿富汗，美方把毒刺导弹交给抵抗组织，几万美元一发，换掉对方几百万美元的直升机。再后来，美方和产油大国协商增产，压到油价下跌，堵了依赖原油出口换汇的苏联财路。所谓星球大战计划，同样是诱使对手参加一场无底洞式的军备竞赛。每一步都不重复，但内部逻辑严丝合缝。美国在国际棋盘上没怎么跑偏，重要原因就在这里。

再次是放大器，发挥你本身的禀赋。街角夫妻馆子，别去跟大牌连锁拼标准化。它赢在现炒、锅气、亲切和人力成本弹性。把这几样做到极致才有的打。昔日的朝鲜水师迎战庞大舰队，若在开阔水域对冲必败，于是把战场选在狭窄水道，让对方数量优势排不上用场，自己的大船和精兵却在单挑中占优。

这期会员日谈亏钱，我想起芒格那篇“如何保证过上痛苦生活”。我交易多年，赚过也交过学费，于是试着模仿他写一份“体面亏大钱指南”。

低级的亏法有两种：一是打一枪换一个地方，亏得稳定但金额不够，还显得不成熟；二是把钱押进违法勾当，结局是钱没了人也失去自由。真正考手艺的是，保持体面、还不像傻瓜地巨亏。这套流程分三步。

第一步，选一个天生适合亏钱的项目。先看概率：如果统计告诉你七成人亏钱，就是好场子；期权更妙，大部分人爆仓。万一大牛市进场也不怕，只要拿住不卖，总有一天跌回来。最好连产业链里的头部玩家都在挣扎，这样你亏了可以推给大气候，赚了还能自夸实力。

再看认知：挑你根本没弄懂，或者“以为懂了”的项目。名词越玄乎、故事越宏大、宣传越像天上掉馅饼越好。若有入会费更佳，先每月固定流血，才有动力追逐回本。当年一位农妇贷款拜大师，就是标准示范。进阶版是买“看上去安全”的产品，比如年化五个点的理财，底层却藏了对冲、衍生品；或者每次买热门球队，赢了小钱，爆冷一次吐光。亏了也容易措辞：行情不对劲、裁判不得体，反正不是自己笨。

位置也要选对。利益上，去当规则制定者的对手盘，人家设计规则时不会亏待自己，倒霉的是后来者。认知上，离一手信息有多远离多远：不读原文，只看转述；不学整套框架，只抄金句。把巴菲特、索罗斯、彼得林奇炖成一锅糊，再搭配“从不复盘、勤勉反复踩坑”的习惯，就能又亏钱又显得很努力。

第二步，让亏损金额配得上野心。严格止损的单笔2%太文明，一辈子也亏不出名堂。正确姿态是抱着“不会发生”的侥幸，一把梭，上杠杆。小概率事件一旦兑现，直接毕业。怕被视为赌徒，就用频繁交易代替，每天来回一次，手续费也能一年磨掉四成本金。想进阶，还可以替别人的债务做担保，把“败光自己”升级成“拖垮全家”。

第三步，坚决死扛。中途赚了？千万不能止盈。浮盈只是一串数字，落袋才算真正赚钱。电影里那个暴发户运气好到买垃圾股都能涨，但期限逼得他割肉；你反正没有期限压力，就攥着别放，等到情绪退潮，自然亏回去。中途亏了？更不能止损。找几个死多头的观点给自己加戏，逢低再加仓。最后你还可以拉一份“朋友误我、KOL误我”的甩锅清单，把巨亏变成段子。

反过来做就能变成富翁吗？也没那么简单。高手的账户也常有回撤，他们只是把亏损控制在可承受范围内，并把它当学费。但把这套反着用，至少能避开最烂的结果。赚钱各有各的路，赔钱的路径倒是惊人一致。

有人天天问哪里有生意，其实高利润生意常常就在身边，只是没人多看它一眼。

朋友开打印店，说隔壁做广告招牌的常常更晚收工。听他抱怨，新店开业、老店换手，都要重新做门头，一块招牌几千元，一条街总有几家开开关关，订单不缺。据说有一个只做门头招牌的连锁，已经铺了七十家店。

一个四线小城的摊贩，没有门店，一辆改装电动三轮和一台烤炉，傍晚开始卖现烤串。原料是面筋粉，成本不高，一串三元。口感全在酱汁，酱不好就没有复购。日销不算夸张，但毛利可观，遇上节假日更赚。

为什么大多数人找不到热爱？这个问题值得一直挂在桌面。很多人并不是没有热情，而是太早接受了别人递来的标准答案。一个人若是从来没被允许按自己的节奏探索，热爱只会越藏越深。

最近受邀到朋友家里做客，现场正好有一位年收入破千万的老哥在分享心得，我把印象最深的部分整理出来，和大家一起聊聊：

先把要不要做这件事想透，这一步最关键。

惰性从何而来？无非是正向回馈太弱。设想一下，如果你每天下班时口袋里能多塞进一万现金，你会想偷懒吗？只会比任何人都更上头。回馈感不足的根源，通常是投入的量不够猛。

量上不去又是什么原因？可能是行动力拖后腿，视野不够开阔，规划不够清晰，对细节的预判也不够到位。

把这些表象剥开，真正卡住人的核心，常常是热爱感缺失。

对一件事没有温度，没有由内而外的兴奋感，却想把它做到顶尖？随便试试，就能赢过在同一赛道深耕十余年的老手，现实吗？道理其实很简单。

最终还是想要的决心没到位，对赚到钱的向往不够，对资金的紧迫感不够强烈。

所以困住的人其实只有两条出路。第一条是尽快搞清楚自己真正着迷的是什么，锁定后持续深挖。第二条是即便暂时找不到热情也没关系，就直接冲着赚钱去，少一点别扭，少一点自我消耗。
