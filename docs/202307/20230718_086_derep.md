# 别只盯着同行，西瓜才是冰淇淋的劲敌
作者：龙哥

据说今年冰淇淋的生意不太理想。原因说来也简单：开年四五月异常阴冷，闷热来得迟了，等到真正热起来，旺季的黄金档位已经错过了不少。

很多人直觉上会把冰淇淋的爆发期划在七八月，但真正的高峰其实是四月接档五月，一直延续到八月。真正让销量掉链子的是六月。因为六月是西瓜集中上市的节点，而西瓜对冰淇淋的冲击，比想象中要致命得多。所以说一句大胆的话，西瓜就是冰淇淋的直接竞争对手。

这其实很好解释。波特五力里反复提到替代品的威胁，而在中国的消暑场景里，西瓜就是最经典的替代品。国人几千年来的降温首选就是西瓜，一到上市季，它会连带着把饮料、冰淇淋、甚至酸奶的销量一起带下去。

我前不久聊到一位做酸奶的创业者，他也提到一个很有意思的现象。酸奶的六七八月恰恰是小淡季，原因不是气温不够热，而是西瓜抢走了消费者的胃口。同样是降温解暑，同样是吃在嘴里的爽感，西瓜赢了性价比和饱腹感。

克里斯坦森提出的“消费者任务”理论把这件事说透了。用户买的不是产品本身，而是产品能帮他完成的那件具体事。任何能完成同一件事的东西，都能成为竞对。

方便面被美团外卖挤压，本质上都是“快点解决一顿饭”的任务。出租车在部分城市被共享单车冲击，也是因为“短距离快速出行”这个任务被分流了。休闲游戏和短视频的厮杀，更是“打发碎片时间”任务的内卷。现在火起来的营销私董会，本质上也在分走一部分营销咨询公司的份额。

归根结底，还是那句老话：客户不需要 1/4 英寸的钻头，他要的是 1/4 英寸的洞。

每天多想一步，才能睡得更踏实一点。
