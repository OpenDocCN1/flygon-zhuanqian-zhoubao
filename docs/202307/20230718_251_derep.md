# 别再傻傻抄同行了！我在抖音评论区挖出爆款情感文，月入6000+
作者：龙哥

大家好，我是龙哥。今年2月才正式开始写爆文，大约一个多星期账号就跑进了流量池，第一个月拿到了6000多块，现在👸号总收入也过万了。

情感类文章的写法，航海手册里讲得很细，我就不重复了。今天专门聊聊我自己摸索出来的选题方法。

最早我也跟大家一样，去某些平台找情感素材，但那边很多文章根本不是故事型的，质量也参差不齐。而且大部分人找素材就是盯着同行，别人爆了一篇马上照搬。我自己第二天就能看到好几篇类似的文章，换皮不换肉。跟风的人一多，流量就被摊薄了。我也试过模仿，效果真不行。

都说故事源于生活。有次跟亲戚吃饭，我二姨特别八卦，把村里那点事说了个遍。最惊悚的是，村里一个已婚妈妈，为了赚钱去大城市打工，结果跟人跑了，还生了孩子，过年都不回家。后来跟原配离了婚，两个孩子扔给老人带，爹妈都不管，听着都心酸。

要不是亲戚亲口说的，这种狗血剧情我都不敢信。一直以为只有电视剧小说里才有，没想到现实比剧本还狠。

后来我刷抖音时突然灵光一闪：每次看到情感纠纷的新闻，评论区总有一堆网友讲自己或身边人的真实经历。这些故事能不能拿来当素材？

核心思路就是：用关键词去各平台搜情感故事，同时关注后续发展、评论区里的引申故事，把素材库不断喂大。

具体我是怎么做的呢？

在抖音搜关键词。我发现情感故事里婆媳矛盾最多，那就搜“婆婆”加上一个情绪词或动词，相关视频一大把。![](img/012498ba337695c3711926446d0f198e.png)

搜出来不能直接抄。这类视频有个好处是受众精准、已被验证过，但素材可能比较旧，或者是别人从其他平台爆文改编的，直接套用很难有阅读量。而媒体号经常转发别人的视频再加个标题，虽然跟营销号类似，但媒体号自带流量，评论区特别精彩。![](img/eaeefb8986459741c2f9d13b34e33702.png)

比如大象新闻那个视频，18万赞，评论区有32395条留言，说明大家都有共鸣，很多网友把自己亲身经历写了出来。我在截图里圈出的那条评论，内容不算长，但已经足够当素材了。

顺着这个思路继续搜，我还挖到了前阵子的一个新闻。![](img/aeee1fa0106055c48bbcc06457c8b79a.png)搜索下拉框里出现“XXX事件后续”，说明关注度很高，大家都想知道结果。我也好奇点进去，可没后续。那老规矩，翻评论区，果然还有相关评论。![](img/117f063caa3f8b6ed745d6eb398f2076.png)

其中一条评论是最新发的，我觉得也能用。搜的过程中，好多人提到“曹心柔”，我一查，内容相当精彩。![](img/3a8667c02bf3187b538ce4ffaa473885.png)

那是个情感调解视频：恶婆婆把儿媳妇手臂打断，还跟两个女儿一起把人赶走，结果儿子再娶的第二个儿媳妇特别强悍，给婆婆“灌大便”，还把小姑子们轰出门。后面的更刺激，大家可以自己去看。

视频评论区虽然一片佩服，但也有不少人分享身边类似的事。![](img/e1bcbaae98f6fb8cd1feab089aa35f05.png)我刷到的那条评论，发布才20分钟，新鲜热乎。当然，拿来用也得自己改编。

后来我去B站搜“曹心柔”，找到了这个调解视频的出处，里面还有很多素材。我把这些新闻再丢回抖音搜一遍，看看视频下面有没有网友补充故事。![](img/260f5350811eb78645afac37a6a16ec7.png)

素材到手后，就可以创作了。

我再说下改编流程。之前我拿一个节目的新闻直接写成情感文，效果很差，后来查了下，才发现人家节目组自己就有👸号。这里拿曹心柔的故事演示一下。

航海手册列出爆款文的8个要素：有曲折、有情绪、有信息增量、关于民生、明星名人、性、暴力、金钱。曹心柔的故事，至少符合曲折、情绪、民生、暴力、金钱这几条。

先把素材里发生的事捋一遍：1、曹心柔刚结婚就被婆婆和大姑姐们打；2、丈夫在家被姐姐打，甚至想跳粪坑自杀；3、婆婆骂孙子骂儿媳；4、婆婆把前儿媳胳膊打到骨折；5、前儿媳一个人养全家8口还被虐待；6、曹心柔忍无可忍，拿搅屎棍和马桶栓收拾婆婆和大姑姐，把人赶出门；7、婆婆见她就怕，再也不敢找茬，还想缓和关系，就找调解员来；8、婆婆和大姑姐放话，将来家里拆迁，一分钱都不给儿媳儿子孙子。

大概就这些。然后按手册里的故事公式来创作。

我觉得儿媳、前儿媳、丈夫都能当主人公，看你想选哪个视角。我选了儿媳当主角。

手册里讲“开幕雷击”7要素：金钱数字、性暗示、暴力、死亡、捷径、异常悬念、民族主义。我取的标题是：“我二婚遭恶婆婆百般刁难，婆婆意外瘫痪在床，我的一番举动，让婆婆浑身发抖！”

标题定好，就按故事模板搭框架。如果直接写纪实内容可能太平，需要自己加反转剧情，比如：

小芳有个幸福家庭，在城市买房，结果碰上恶婆婆和作妖的小姑子，还被婆婆告知村里拆迁没她丈夫孩子的份。后来婆婆意外瘫痪，小姑子根本不照顾，反而恶语相向。小芳没有落井下石，反而悉心照料，婆婆感动得浑身发抖，当场承诺拆迁补偿都给他们。

核心剧情总结一下就是：我叫小芳，32岁，二婚嫁到农村。因为离过一次婚，我特别渴望有个幸福圆满的家，将来能在城里买房。可刚结婚就发现摊上了恶婆婆和爱作妖的小姑子，我不甘示弱，天天吵架。实在过不下去想离婚，但看着2岁的孩子，又咬咬牙忍了。后来婆婆意外瘫痪，小姑子不但不管，还骂她，甚至一走了之。我一开始也不愿意照顾，但看她实在可怜，就勉强搭把手。没想到婆婆被我的所作所为感动，浑身发抖，还承诺以后家里拆迁补偿全给我们。

我的分享就这些。只要老老实实按航海手册来学来写，别自己瞎搞，多在群里交流，不懂就问教练，先赚个100块还是很容易的。
