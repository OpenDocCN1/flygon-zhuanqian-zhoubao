# ('人人都能学的卷王“大法“', (2, 14))

从十八线小县城到年薪百万的清华“卷王”，这中间只隔着十年的“狠”劲。

今天想跟大家聊聊一个真实到扎心的逆袭故事。主人公叫刘文怡，今年刚加入生财圈，还是枚新人。5月份她报名了线下实体引流航海活动，可惜因为人在美国，任务完成得并不亮眼，只签下一单，金额7.5万。她的队长闫君却觉得她身上有太多值得挖的东西，于是给她额外布置了一个作业：把“卷王”的方法论分享出来。这才有了那套人人都能学、行之有效的“卷王大法”——也就是今天这篇一万字的干货长文。

刘文怡说，小时候的她，不过是十八线贫困县城里一个毫不起眼的普通女孩，整天埋头做题。但后来，她一路杀进清华，拿下六位数奖学金，还拿到美国常春藤distinction特等学位，成了名副其实的“卷王”。把她的十年时间轴拉出来看，几乎每一格都塞满了硬核成就：

2012年，以全市第一的成绩通过司法考试，进入税务局；2013年，遭遇车祸、第一次收到病危通知，却在病床上啃下三门注会科目；2014到2015年，又先后通过注会专业阶段和综合阶段。2016年，拿下税务师资格，随后顶着压力辞去公职。

2017年，她独自跑到外省，参与操作超过14亿瑞郎的跨境收购项目，以及百亿房地产投资信托基金（REITs）的税务筹划，同时负责多家上市公司的税务筹划工作，线上税务讲座累计超10000分钟。2018年，她在美国全程经历了一家巨头企业某业务板块的IPO，单次线下培训学员突破一万人。2019年，考过经济师、签约人生第一本书，还第一次给税务局讲课并收到感谢信。

2020年，她一边怀孕生娃，一边考下资产评估师；第二次与病危擦肩，随后拿到清华和北大双offer，最终选择清华。同一年，她通过合法合规的税务筹划，为集团每年增加数十亿利润，并在孕期获得提拔。2021年，她从税务总监晋升为事务所合伙人，拿到清华奖学金，有了自己的百度百科，还受邀站上三所顶尖财经高校的金融硕士讲台。2022年，她从社恐练成社牛，被国资委、检察院等聘任为国企董事、外部专家，同时进高校和中税协授课，成为省税务局干部学校的外聘老师和独立商业讲师。2023年，新书《一本书读懂税务筹划》出版，第三本正在路上，还拿下四个清华校级实践金奖、清华卓越毕业生和常春藤特等学位。

这哪是普通人的简历，分明是开了倍速的人生。

刘文怡把这套方法论拆成三个部分：卷出来的成果、一路走来的过程、持续“卷”的核心要素。在她看来，这套方法并非天才专属，而是人人都能学、行之有效的“卷王”之道。她特意说明，这篇万字长文的出发点是利他与分享，经验全部毫无保留，干货密度极高。想拿走完整版的朋友，可以直接去云文档看：https://kdocs.cn/l/cvBfeemTjOfy

评论区里，队长闫君评价：厉害的人干什么都厉害，你更是如此。有人感叹她把“卷”字发挥到了极致，背后全是血泪；也有人反思自己平时舍不得下狠手，其实是在找借口，看完文章如醍醐灌顶，直呼感谢遇见；还有人说她的潜力仿佛没有上限，佩服得五体投地。

所以，别总说自己做不到，先问问自己：是不是对自己还不够狠？这个女生的十年，或许就是最好的答案——起点再低，也能靠方法加上一股狠劲，硬生生卷出一条路来。
