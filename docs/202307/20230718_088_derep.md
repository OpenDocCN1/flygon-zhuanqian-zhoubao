# 广告费率只有 5%的电商生意
作者：龙哥

你见过广告费只占营业额5%的电商吗？别急着说不可能，台湾有个家具品牌“居家先生”就做到了。

我们当初去调研时，客户随口提了一句：他们的ROI能做到1:7。听到这个数字我挺震惊的，放在内地，这回报率别说卖家具，卖房子都值得砸广告。1:7，意味着每投1块钱广告能拿回7块钱，绝对是很多团队梦寐以求的成绩。

很多人觉得电商没有中间商，应该又便宜又赚钱。真相恰恰相反，流量成本高得吓人。那些号称年销几千万、几个亿的新锐品牌，算完账常常不赚钱——钱全烧给平台了。不信去看看完美日记的财报，连年亏损，流量有多贵一目了然。

但总有人能找到别人看不见的路子。居家先生一年销售额大概10亿，几乎全走线上，抖音还占了大头，可全年广告投放只花掉营业额的5%。为什么能做到？因为这团队从来没拿过投资，从一开始就没打算烧钱换增长。

他们真正厉害的地方，是找到了一波流量红利，并且做了很多别人做不了的事。用我常讲的一句话概括就是“人无我有，人有我无”。只有跟别人做得不一样，才能彻底跳出竞争。

具体怎么操作？

他们锁定了一大批电商平台上的非主流搜索词。这些词背后对应的需求，是大路货满足不了的。因为每一类需求量都很小，绝大多数品牌不愿意专门开生产线，就算找代工也麻烦。说白了，这就是一个长尾市场。

但他们有供应链上的独家优势——能做出来，还能赚钱。哪怕一个SKU一年只卖几百万，也没问题。靠着几百个这样的“小众SKU”叠加起来，一年就做出了10亿的盘子。

听起来好像不难？其实难得很。比如你做冻干速溶咖啡，找三顿半的代工厂下单，100万订单工厂乐意接，因为东西一样。但如果你做一个全新的产品——像我们早年做过的烈酒酒心手工巧克力——根本没有工厂愿意代工，你砸200万订单也没人接。

这就是这门生意的微妙之处：大品牌看不上，小团队做不了。不是真没人能做，而是做了不划算。所以他们在这个缝隙里扎下根，一天天长了起来。

这种战略，不同的人有不同的叫法。迈克尔·波特叫它“差异化战略”，小林一雅说“小池大鱼”，沈帅波讲“做不了高峰，就做孤峰”。说到底，竞争的最高境界不是打赢对手，而是根本不用打——因为大家玩的不是同一个游戏。

再举个服装行业的例子。服装卷成什么样大家都懂，但有个叫“龙牙”的品牌专做战术服装，硬是没什么对手。这就是一门好生意：人无我有，人有我无。

希望这个故事，能给你一点不一样的启发。
