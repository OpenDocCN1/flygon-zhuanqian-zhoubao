# 做商业 IP，别只图好看，这三条才是硬逻辑
作者：龙哥

做品牌吉祥物，尤其要落在生意上，IP 设计其实是有套路可循的。归结起来就是三件事：让人一眼能认、让人一下能分、让人自然能联。

第一，找个有原型的载体。消费者不是艺术家，陌生的东西记不住。IP 得站在大众已有的认知上，先让人觉得“哎，这个我见过”。 

第二，必须有不可复制的独特性。市面上的猫、熊、兔子已经太多了，如果和别的品牌长得差不多，那钱就白花了。差异化才是记忆点。 

第三，要和品牌业务产生关联。IP 不能是空中楼阁，得能讲清楚“为什么是它”和“它跟我们的产品有什么关系”。

就拿居家先生来举例，他们卖的是家居用品。家里最常见、也最能唤起生活感的动物是什么？自然是猫。所以团队直接把猫作为原型切入点，先把熟悉感拿到手。

接下来解决“像谁家猫”的问题。居家先生本身定位是高审美的设计品牌，普通萌猫太路人。于是设计师把超现实大师达利的艺术气质注入到猫的形象里，把达利的标志性造型和猫融合，形成了一个全新物种——达利猫。这样既有辨识度，又在调性上对上了品牌。

最后做关联闭环。达利猫的耳朵造型，被刻意设计成与居家先生原本的“家” logo 呼应，视线一转就能联想到品牌。原型、独特、关联，三层逻辑就完整了。![](img/2c604c6f3670dbe33bc6e4a8afb8d77c.png)
