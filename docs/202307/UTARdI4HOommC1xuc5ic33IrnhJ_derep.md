# 先做功课、定制心意礼、线下深聊：一个赚钱新人可复制的同城破冰打法
作者：龙哥



大家好，我是龙哥。线上我算社牛，线下却有点社恐。5月27日是我第一次去福州同城会，用定制书籍破冰的方式，很快就跟一群有钱、有见识、有格局的圈友建立了联系，碰撞出了好几条新业务思路，也为以后合作埋下了种子。

参加线下见面会，很多人第一次都会卡壳：想提前准备却不知从何下手，想送礼不知道送什么，准备不足现场就变透明人。最后没链接到人，没拿到新认知，没解决卡点，反而陷入几个月的社交自我怀疑。

不少组局官写了大量经验，今天我换个角度，从参会者的视角聊聊：赚钱新人去同城会，到底该怎么准备。

# 一、为什么要走进线下见面会

从龙珠见面会到航海同城会，再到每年拉新会，赚钱一直在做线下。龙哥和小伙伴的推动下，今年线下场已经覆盖北京、上海、广州、深圳等40多个城市。只要你愿意，总能和圈友面对面聊。

尤其是赚钱新人，为什么非去不可？

## 1、用真人链接高质量人脉

同城会里的人大致分三类。

**成熟创业者**，商业产品体系已成型，对讨论议题有清晰判断。他们来是为了扩大影响力，链接同频伙伴，并捕捉自己视野外的风向。

**上升期创业者**，业务在增长，版图没完全稳，常常卡在某个点上。他们带着具体问题来，找人解惑，找更强的势能伙伴突破。

**起步期创业者**，可能还没成体系的业务，甚至还在找方向。他们来听大佬分享，从别人的路径里找灵感，为未来发展先搭关系。

无论处在哪个阶段，只要方法对，都能在聚会上链接到想链接的人。

“线上聊一千遍，不如线下见一面。”面对面是最快建立信任、加深印象的方式。线下链接后保持跟进，对业务拓展、客户拓展都是加成，甚至直接促成合作。

## 2、在现场补认知、破卡点、抓风向

赚钱线下会是难得的开眼界窗口。

**认知升级**。每次活动前都由龙哥和负责人做流程规划，主题紧扣当下风向，比如北京场就围绕“ChatGPT应用及探索”展开。自我介绍破冰、自由讨论之外，还有主题深聊和大牛分享，在碰撞中你的眼界会被拉高。

**卡点突破**。做产品的人都懂，不是线性增长，平台期就是卡点。有的人十天半个月就冲出去，有的人卡一年半载还在原地。经验告诉我，高两个层级的指点几句，就能理清思路进入下一波爆发。线下会恰好提供了这种请教机会。

**风向感知**。赚钱的风向标通常比市场早半年。线上刷“风向标”板块可以，线下跟圈友聊，更容易get到新理解。老圈友常说，别小看线下“吹牛”的内容，一年后很多就成了真红利。

## 3、把影响力从线上搬到线下

互联网创业，无论是自媒体、知识付费还是做商业，都不是拍张200块的头像就自称导师。

影响力来自成绩和输出。在线上，很多新人推荐自己不够清晰，隔着屏幕破圈难。线下有介绍、有讨论、有细节互动，每一个小举动都是自我展示的机会。

影响力强化了个人势能，也为后续业务带来更多可能性。

# 二、我是怎么准备见面礼的

## 1、送礼，为什么有效

作为新人，怎么在第一次见面就超预期破圈？我为每一位参会圈友准备了一份专属书籍，并在扉页手写寄语。

礼物不贵，但定制化体现了心意，手写的话会在对方读到时把你和聚会场景一起唤起。

![](img/896d4874ea456fee55d2f4314137002f.png)

我一直相信人比钱重要。比起口头惦记，一份精心挑的小东西更能拉近距离。

我平时也习惯送礼：医院里给实习生买饮料水果，社群里定期抽奖节庆定制。久而久之，影响力在累积。

实习生跟我配合更细，社群粘性更高拉新更有劲，合伙人之间像家人一样互相托底。这种“小投入”让主业副业都更顺。

## 2、送书的复盘打法

想把礼物送到心坎，要做三步。

**先做功课，了解对方业务。**

送礼前知己知彼，礼物才贴心，也能成为聊天入口。了解业务对后续合作也利好。

我习惯给每个新朋友做备注：🛰️名片标签里记清他在做什么、可能怎么合作。加起来上千个好友，也能快速对应。

怎么快速摸清？

1.见面前群里自我介绍是第一手资料，加好友时顺手打标签。
2.我主张“主动才有故事”。加完就打招呼、约见面礼，同时聊业务。介绍自己，也了解对方，在聊天里自然定位到合适的那本书。

**再挑到位的礼物。**

对老合伙人，我会选旅行特产或符合性格的小物件；对新朋友，我更倾向书。

* 书不容易踩雷。生活好物可能重复，吃的可能不合口味，书对创业者基本是刚需。
* 书的意义在认知。互联网创业需要持续输入，送书等于送认知，很适合圈内互赠。
* 价格更可控。第一次见面，价值太高对方有压力，太低拿不出手。书的意义大于价格，不容易尴尬。

具体做法：

1.在豆瓣、知乎、📕上按对方业务做功课，筛出口碑好、质量高的书。最好是自己读过，能聊出心得的。
2.下单后寄到自己手上，再写扉页赠言，最后带去现场。
Tips：哪怕已经有地址的老圈友，我也建议先寄给自己再写字。一张亲手写的卡片，比直接邮寄更有温度。

![](img/ca43a98c47dc78f36e757a60ed9cec64.png)

**最后，线下以书会友。**

准备完礼物，还要对书做二次了解：核心观点、口碑、亮点在哪。现场送书时就能对上话。

比如给做文案的朋友送《爆款文案卖货指南》，就可以说：“看到你在做这块，这本书我觉得很匹配，我读到XX那段很有共鸣……”顺势聊到他的业务，也介绍自己的业务，破冰自然。

# 三、一次落地的体会

这次“送书”让我快速链接到高质量圈友，也提升了个人存在感。结果很满意。

想强调的是，别带着太重的功利心去准备。长期提升影响力、获得认可，需要三种心态：

**利他，持续真诚帮助。**

赚钱的核心就是利他。用自己的价值和内容不计回报地帮助别人，连接才会持续。我从做自媒体起就坚持：加人就送礼，看到干货就转给合伙人，每天发5条高质量朋友圈。真诚的交付和陪伴，让信任成为势能。

**互换，建立平等关系。**

“势能相近是交流，势能悬殊是请教。”沟通前先想能给对方什么：同频伙伴可交换认知，势能更高的大佬若暂时无业务价值，一个小红包致谢也是一种尊重。有来有往，关系才长久。

**真诚，是真正的必杀技。**

我用几句话成交过三位数产品，也用30分钟语音成交过五位数。秘诀不是话术，是专业+真诚。目的性是可以有，但真诚必须放在前面。虚假的奉承和真诚对话，一眼就能分辨。真诚积累的是口碑和信任，是IP的根基。

别靠套路，靠真诚利他去链接，更得人心。
