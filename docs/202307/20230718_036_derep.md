# 我用📕干了一年无货源：销售额近60万，净赚30万的真实复盘



## 📕无货源实操一年，我是如何做到30万利润的

作者：苏木
时间：2023-07-28

各位朋友好，我是龙哥，今天来聊聊过去12个月我在📕上的变现经历。

起步阶段我走的是一条无货源的路子，完整跑下来一年左右的时间，总销售额大概在五十多万到六十万之间，实际到手的利润在30万上下。等模式跑顺之后，还能通过一些打法去构建自己的壁垒，我个人觉得这个玩法对普通人很友好。年入百万对我来说没实现，毕竟也没到那个量级，但做到10万到20万的年收入，我觉得是可期的。

这次把经验拿出来，主要是两个想法。一是想认识更多思路合拍的伙伴，一起探讨怎么把这个盘子做大，一个人闷头搞真的很容易孤独和泄气。二是也想看看有没有靠谱的供应链资源，我可以帮着把货卖出去，具体合作方式文末会说到。
