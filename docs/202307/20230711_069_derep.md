# 一个互联网老兵的实战笔记：零基础如何切入猎头这个行业

很多人看完《猎场》后都会心动，猎头听起来高大上，那普通人能不能从零开始做？能，而且我就是一个例子。

我是大卫，现在是生财的新人，但互联网圈子里已经摸爬滚打十几年了。北漂十年，待过百度、京东物流，做过产品和市场运营，也曾是百度某BU里最年轻的P7。

去年我从北京回到合肥，干脆自己组了一个猎头公司。公司体量不算大，但整个团队确实是我亲手从无到有搭建起来的，而且是从一个完全陌生的赛道里一点点试出来的。

正因为是跨行创业，踩过的坑和摸索到的路子可能对刚想入行的人更有参考价值。想把这段从零到一的经验沉淀下来，分享给需要的人。

篇幅有限，文章里没办法展开太多细节，完整的梳理和实操思路我都整理在了飞书文档里了。
