# 那次让人心跳骤停的星期四，海南证照出问题后该怎么自救
作者：龙哥

大家好，我是龙哥。很多人好奇我名字后面为什么要加Qu，主要就是为了区分，省得总被叫成老翟、老霍、老崔。

5月做航海，7月做续航，闲鱼旧书这条线帮不少人跑通了流，甚至有朋友已经组了小团队。结果上个星期四，圈子里突然炸锅：不少人用海南办理的出版物许可，状态全部异常。

随之而来的是闲鱼账号被扣分进黑屋、商品批量下架，严重的直接被永久封禁。也有极少数账号暂时没动静，但基本都只是时间差的问题。

这篇文章我拆成三部分来聊：

## 一、证照出问题，先弄清来龙去脉

### 1、为什么会出现异常

办出版物许可，前提是要先有主体，通常是个人工商户或公司，然后拿主体去申请许可。最关键的环节是经营场所，监管方要求必须是带商业属性的办公地址，纯住宅不行。

因为实地核验流程繁琐，很多卖家选择找中介代办。代办的打法一般是在偏远地市利用当地扶持政策、资源关系去跑，地址多为租赁来的，甚至部分是虚拼的。一旦该区域出现售假、纠纷被投诉集中，监管就会介入，重则整批清零。海南就是典型案例，因办证门槛相对低，中介大规模集中办理，最终引来上级注意，2022年那一批证被整体吊销。

几个常见疑问：

#### 1.1、海南那批证是假的吗？
不是伪造的，都是正规核发的。被吊销后就等于没有资质了。吊销原因就是违规办理。

#### 1.2、我只卖网上，难道也要有实体地址？
是的。按规定注册主体必须提供商业用途的地址，便于监管可追溯。

#### 1.3、中介说开网店九成不会被上门，是真的吗？
中介为了成交肯定会这么讲。是否上门取决于：有没有被投诉，投诉量大了必查；当地市场监管的执行力度；是否触发区域性整顿。虽然大概率不会查，但没人能打包票。

### 2、异常后怎么操作

#### 2.1、证照异常了，闲鱼还能用吗？
海南那批证其实早在几个月前就被注销了，只是闲鱼拖到7月才开始执行清理。可能是外部压力加上平台开始严管。

如果只是扣分封店七天，可以本人重新办一张许可替换上去。但如果是永久封号，且无法完成注销或与支付宝解绑，那就算换了新证，这个账号也用不了了。原本一张证能带三家店，现在只能带两家。

#### 2.2、会不会影响个人信用？
一般影响有限。只要在三年内完成注销，通常问题不大。我自己的习惯是异常后一年内就处理掉。

#### 2.3、能修复吗？
不建议修复。修复成本往往比重新办理还贵，所以普遍做法是注销。注销费用市场价在200-300元左右，海南近期找中介注销能压到百元以内，视地区而定。也可以回头找原中介谈，良心点的能免费代注销。

## 二、怎么降损止血

经过两轮实操验证，闲鱼旧书这个赛道上手快，人均月赚两三万是可行的，但上限不算高。既然我们已经默认了“代办证可能翻车”这个风险，就要提前布防：

1、地址必须分散。山东之前也出现过批量查处，海南也出现过。我手上三十多个号，这次只伤到三个，就是因为各地证分散开。

2、能用真实小城、乡镇地址就尽量用。批量出问题的都是中介扎堆的热门城市。本地小地方，只要店铺不被频繁投诉，稳定性高很多。

## 三、项目卡住了，心态怎么稳住

证照被封、店被关，难免会烦躁焦虑。可有些规则改不了，就只能接受。就像谈恋爱，不可能十全十美，做一个生意也得接受它的缺陷。

把出版物许可出问题当成这个生意里本该有的风控环节，心态就会稳很多。做内容号的每天都在赌账号寿命，习惯了不就好了。

也有朋友做无货源模式，上家发货延迟就想自己建仓。其实对比一下：

有实体仓的卖家长处：
1、发货速度快，货在手里。
2、退货处理相对简单，不需要中间沟通。

短板：
1、资金压力大，百万级囤货。
2、链条很长：从学校废品站收书、运输、上架、维护数据库都要人管。
3、打包发货的人工成本高。
4、进货受季节限制，只能靠毕业季收一批，200吨的库爆款很少，多是杂项。
5、每年约两成书籍卖不出去变废品。

无货源模式长处：
1、零囤货、零库存、轻资产。
2、全网货源为库，品类远比单仓丰富。
3、不用管收货、仓储、打包，一个人就能运转。

短板：
1、发货比自有仓慢一点，但提前采购基本可控。
2、退货需要和上家对接，流程多一层。

一对比，无货源的吸引力就很明显了。愿意花几百万建仓吗？实体商回收成本也就两三块一本，加上人工、仓储、物流，一本净利润也就三五块，只能靠走量。收书旺季像搬砖一样累，书又重，还得在校园垃圾堆里翻找。

相比之下，无货源那些所谓的麻烦，根本不算事。

所以，做一行就爱一行。坦然面对赛道的短板，把长处放大。

我经常一次性买很多书，被实体老板拉黑或者骂我做二手的，完全不生气。因为我不用日晒雨淋去收书、累成狗，还赚得比他们多。想想确实活该被吐槽，哈哈。

我是老瞿Qu，龙哥盟最懂旧书的那个。2023年，希望能链接更多圈友，一起把钱赚明白。
