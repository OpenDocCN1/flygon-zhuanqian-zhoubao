# 从一把包浆豆腐起盘：职场宝妈如何把副业团购做成百万GMV
作者：龙哥



## 作为药企市场妈妈的我，为什么能用包浆豆腐撬动百万元团购？

作者：小野
日期：2023-07-04

大家好，我是龙哥。白天在国内前五的药企做医药互联网营销，晚上是两个娃的妈妈，业余还经营着自己的副业。能把本职工作、育儿和副业三件事同时运转起来，我常觉得这是互联网时代给妈妈们的一份额外选择，是龙哥盟这类社群让可能变现的道路多了起来。

目前我手上有两个快团团账号在跑，一个主打美食、一个主打母婴，累计GMV接近150万；同时也在尝试大健康品类的产品服务。之前复盘过一次我的两年副业路径《新手宝妈，职场副业两不误，跑通📕引流和私域卖货，累计利润30万+的经验复盘》。

今天想重点拆解我做团购的起点——包浆豆腐。也就是一个不起眼的云南小吃，如何成为我进入私域团购的敲门砖。复盘下来，这段经历对我帮助很大，也希望对想入局团购、或正卡在瓶颈期的朋友有点参考。

一、先立住人设，云南美食博主才是我的开场白

我是昆明人，毕业十几年了，一直想把家乡的味道推向更多人。从2015年起我就开了「小野食堂」👸号，分享云南美食和本地好店，后来工作爆满就停更了。

![](img/f5707f555218594ba14272f0b539ff98.png)

2021年初，孩子出生两个月，带娃比想象中轻松。盖洛普优势里“成就感”排第一的我坐不住，决定启动副业。第一念头就是卖云南特产。

闺蜜帮我联系到建水的包浆豆腐货源。当时大众对它认知很低，但吃起来很有记忆点，猎奇感强，我就抱着试试的心态先上了。

我记得很清楚，1月19日那天，我发了一条朋友圈建了个「小野食堂云南美食」群，把亲戚朋友全部拉进去，一下子有100多人。随便拼凑了点素材，草率做了个团文，就正式首发包浆豆腐了。

![](img/a52ea0a97a6a8c586bd30723ea2beb8c.png)

回头看，起步时我做对了一件事：先给自己一个极窄的标签——云南美食团长。

之前断断续续的美食👸号，加上朋友圈长期表达对吃喝的热爱，已经在我的人际圈里形成了美食相关的印象。带着这个既有认知去卖货，转换成本几乎为零。

做私域团购的早期，我的建议是别急着铺品，先把定位想清楚。

二、把一个单品做到消费者脑子里

2.1 讲好故事，比硬广更值钱

开团后就要推。我第一条包浆豆腐的广告是一篇长文，跟闺蜜一起写的，蹭了当时春节档热映的《送你一朵小红花》的话题。

![](img/df59a6f9c677d62ef9169590b0ea18c5.png)

这篇文带来了第一波好评。

![](img/8edc0eafb0d995c23af5fa213d3ed0e7.png)

也带来了第一单63个订单。

![](img/0915f39199fbe12d5505af3361c9b21d.png)

一个团品讲透它的故事，远比生硬报价更容易让人心动。

我常用的几种讲法：

1、蹭热点讲。比如当时就是用电影话题切入，再带出包浆豆腐；
2、把卖点融进场景讲。卖点要反复说，但别干巴巴罗列。可以把优势拆解到不同使用情境里去讲。
![](img/7801064e7850e56a4c5132de909993c3.png)
3、讲用户痛点。吃的东西每个人动机不同。玉米不能只说香糯，要说粗粮助瘦。把场景和痛点点透，转化会快很多。
![](img/a43679342c5850d30c702efed4bbbac7.png)
4、讲自己的真实体验。团购的核心是团长的人设，亲自吃、亲自测，把使用感受拍出来，信任感会高很多。
![](img/81aaac6ba979264bb4a180c7e84e04fa.png)

2.2 用持续曝光把心智占住

因为真的喜欢包浆豆腐，接下来一段时间，我几乎每天都在朋友圈和群里讲它怎么吃、为什么好吃、别人怎么追着要。

![](img/317b5505c2174968d4914e7d6dea418e.png)

好评不断，最后过年停发时群里一片“求开售”。

![](img/5755fe3f067912cbce3c8645a1ba7b79.png)

那段时间我也上了其他云南好物，但投入精力最多的始终是包浆豆腐，销量也最高。

![](img/ce74f960622ff2cf248cc32adcd36631.png)

这印证了一点：想做出爆品，先把故事讲圆，再用高频重复去占领用户心智。

过年两个月卖了200多单后，我发现不能常年开团，开太久大家会觉得理所当然。后来改为每月只开一周，制造稀缺感，反复推。

![](img/e79e894f2dbd65083a14177b13c23950.png)![](img/361b87ea727c46c023035e6639d58fdb.png)

产假结束上班后时间被压缩，每月只卖三四十单。但有趣的是，只要我一推，就总有新用户进来猎奇，老用户复购率也极高。很多人想吃包浆豆腐，第一反应是找我。某种意义上，我在私域里成了“云南包浆豆腐代言人”。
![](img/d73c47582b9484dd85e55903bf4cc6d4.png)![](img/83a6589522d9970672f714942379473a.png)

后来供应链断供很久没有开团。直到去年12月在赚钱航海里看到忘忧惠团的星宇也在卖包浆豆腐，我立刻在朋友圈发了声。老客户没忘我，又收了70多份的订单。
![](img/9e17c145635f52bca4f3915d98ad63ca.png)![](img/2c78b1022066cc0f0f29a94ffe7f4921.png)

定位和心智一旦立住，就等于拿到了客户的信任存折。

2.3 把团品当礼物和奖品用

社群免不了抽奖。我发现最好的奖品就是正在推的团品。介绍奖品本身就是一次种草，参与者即便没中奖，也会被反复种草。

另外，可以把团品定向送给核心VIP试吃。今年5月我把云澜挂耳咖啡作为礼物发给了60多个VIP，带来了不少心智沉淀和后续复购，很多人现在还在等复团。
![](img/71bfe5d66c8f773fa71d1735ac0eba0c.png)![](img/bd78247db0389bd09b0aac793ccdd39b.png)

2.4 好评要用起来，没有就造起来

刚开团时我没想过会收到这么多反馈，但好评截图是转化最重要的信任状。

![](img/8b899b059b196b3536b31af3f4c2ce3c.png)![](img/c5d2cdd1d4bfa319b49cc40aa76fd99f.png)

团购的本质是信任+从众。好评截图就是证据链。集中推一个品时，一定要收集反馈并循环使用。

没有好评怎么办？主动创造。问问已收货客户的感受；让家人小号下单晒图；把产品拿到办公室分享让同事给反馈。产品本身过硬的前提下，好评绝对能带单。

2.5 爆品先行，再做扩品

起初美食团只做云南系，也出了几个小爆品：咖啡、鲜花饼、西双版纳玉米、云南米线……每个都卖了百来单。

但一个人既要管供应链又要做营销，确实扛不住。当时能帮卖云南货的大团长很少，我就把定位从云南美食延展到全国特色美食。
![](img/497f7359ddbb571d8e6a1a03c525e4c1.png)

当时也纠结过要不要扩定位。后来想通了，有了清晰的人设和爆品作为根基，再去延展并不会突兀。关键是要说清楚为什么做、基于什么立场做。

三、用户要多，持续引流不能停

团购业绩由复购和人数共同决定。引流是我一直做的事：

1、公域里找同频。我从备孕就开始在📕输出真实生活。选题就在生活里，精准。账号现在700多粉，但已经沉淀了约一两千🛰️粉丝，变现近40万利润。

比如我发了《南京鼓楼医院助产士才会告诉你的待产注意事项》，就建起了一个近500人的鼓楼医院孕妈交流群，后来母婴团购群就是从这里长出来的。
![](img/dda13c0e2e6d3c71bb14cc2edb75190c.png)

2、主题交流群导流。围绕用户生命周期建群，如备孕、孕期、妈妈交流、二手群。建好群后需要主动告知自己有团购群，并讲清价值和背景。群公告长期挂着，滚动吸人。
![](img/8b851b28991c2ab3565ab99625f8eacf.png)![](img/708feaccdf49f62941cbc6cda139e4a3.png)

3、线下圈子转化。小区、学校、活动现场都是天然场景。我曾办行业会，把个人二维码投在大屏上，只加🛰️才能进会后群，当晚加了300+同行。试吃、公益赠书、小区团购群，都能快速撬动信任。

四、品类再多，也别丢了最初的热情

两年多下来，我每天都在上新开团。有一段时间我陷入机械式运营，每天发图发文，却离最初分享家乡味的初心越来越远。

复盘后我意识到：团品可以很多，但爆品不能只有一两个。团购的规模是由无数细分品类的爆品堆起来的。

所以我现在的操作是：在一段时间内锁定核心团品做主线，用预热种草-开团宣传-自用分享-客户好评-促单复购的节奏去打透。坚持下来，口碑会滚雪球。

五、一句话总结启动团购的四个关键

第一，打造你的爆品。结合私域定位，先集中做一两个数据表现突出的爆品，建立口碑和信任。

第二，扩品要大方。有了爆品后，勇敢拓展品类和赛道，甚至重塑IP。

第三，引流要持续。无论是内容还是线下，都要不断把同频流量注入私域。

第四，保持热爱。把每个团品都当作爆品来对待，用户能感受到你的用心。这种热爱汇聚起来，就是口碑和财富。
