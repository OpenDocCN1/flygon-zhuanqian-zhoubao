# 一人公司看似光鲜亮丽，但并不是所有人都干的来
作者：龙哥

很多人看到“一人公司”四个字，脑海里浮现的可能是自由、轻资产、说走就走的生活。但我必须泼一盆冷水：这事儿看着很美，真不是谁都能端得稳这碗饭。

我本人是从去年五月彻底切换到一人公司模式的。所谓公司，其实就我和爱人两个人，在小区门口的写字楼里租了一间一百平米的办公室，就这么把“一人创业”落到了实处。和过去带团队的日子相比，收入确实降了——以前十来个人跟着我全国各地跑，一个月大概能进账三五十万；现在俩人对着一台电脑吭哧吭哧干，普通月份也就八九万，碰上大型发售会翻几倍。但你要问我后不后悔？我的答案是：不后悔，而且幸福感比以前强太多。

为啥？三个原因。

第一，离家近了，终于能做合格的父母。以前一年到头在外面飘，孩子全靠外公外婆带，被惯得没边儿。现在每天睁眼就能看见孩子，陪他玩、管他学、听他叽叽喳喳讲幼儿园的琐事。孩子的变化肉眼可见：性格变得特别开朗，能自己啃完大部分小学课外读物，还能自己交到小区里一堆朋友。前几天他刚从幼儿园毕业，九月份就要上家门口的公办小学，接送陪读更是离不了人。

第二，身体像换了一台发动机。三餐在家吃，办公室走过去五分钟，外卖彻底戒了。每天下午五点雷打不动和一帮球友打匹克球，一周再加两次羽毛球，周末带孩子逛广州。以前呢？一周飞两座城，天天外卖，累得像条狗，简直是拿命换钱还没命享受。现在不敢说满血复活，但至少状态好了太多。

第三，心里不慌了。没团队后，最大的固定成本就是每月六千块房租水电，几乎可以忽略不计。所以我敢用五年、十年的周期去做一件事，像盖别墅一样，每天添一块砖。我相信五年后我能建起一个专注少儿教培营销与运营的个人商学院。虽然中间也无数次动摇过——比如我选的目标客户比其他人群付费意愿弱、执行力差，经常想换个赛道——但每天晚上想千条路，早上起来还是走老路。因为心里那根弦没松：就想用商业的策略，帮校长们实现教育情怀。

今年初我建了一个付费星球和社群，叫《一人公司年赚百万冲千万》，但没刻意招生，就是随手记录些心得和方法。

可实话得撂在这儿：一人公司虽然好，但不是人人hold住。下面这六种人，趁早别碰。

**一、比打工时还懒的人**

打工时怕迟到扣钱，闹钟一响就弹起来，连早饭都不吃也要准点到公司；领导布置任务，能主动加班到深夜，就为了那点加班费和晋升机会。可一创业呢？九点半才晃到“公司”，下午五六点就撤了，因为没人管了。这种人做一人公司，纯属送人头。一人公司也是公司，你既是老板又是员工，事没人替你扛，活没人替你干。打工都不是最顶尖的，创业怎么可能成？连打工那点状态都延续不了，更别指望翻盘。

**二、时间管理一团乱麻的人**

上班时大部分事都被人安排好了，当颗螺丝钉就行。可一人公司呢？产品、流量、成交、交付、内容、朋友圈、短视频、客户咨询、办证报税……一天几百件事扑面而来。如果你还是被事情推着走，不计划不规划，等着你的只有死路。所以必须学会清单管理：年计划、季计划、月计划、周计划、日计划，一个都不能少。我自己每年要做无数张思维导图，每天用空白本写工作清单，桌上摆着番茄钟，电脑屏幕贴着四块小白板，就是为了让每一分钟都清楚该干嘛。现在我的状态是：干活全力以赴，打球全力以赴，玩也疯得起来。

**三、缺乏自律的人想都别想**

有人打工时就爱摸鱼，刷短视频、群里灌水、看小说，创业后没人管，直接放飞自我。一个人坐在办公室或家里，对着电脑七八个小时，眼睛盯着屏幕，手却无意识地刷了八十个网页。二十分钟刷一次视频，半小时玩一局小游戏，一天就这么废了。一人公司的资源、时间、专注力本来就少得可怜，再管不住自己，跟谁比都没竞争力。你必须比打工时高效十倍，才有资格存活下来。自律就是把有限的注意力砸到最重要的一两件事上，做到一百二十分。否则月底算账，可能还不如打工赚得多。

**四、不爱动脑、抗拒学习的人别凑热闹**

打工时可以靠手脚勤快混日子，因为有个SOP，有模板，照着做就行。但创业没人给你模板，你要写文案、做海报、做PPT，一切都要自己憋。对很多人来说，动脑比加班还痛苦。你让他加班到十二点没问题，让他想一个问题，他立刻消失。更别说每天看书一小时、进高能量圈子、花钱买课、做笔记、画导图、输出文章视频课程了。这个世界成功路上从来不挤，因为99%的人都是内容的消费者，只有1%的人在做创造者。而一人公司创业，是真正的脑力体力双重消耗，七十二变、八十一难全得自己过。如果你一看思考就头疼，还是安心当个勤劳的搬砖人吧。

**六、情绪化太严重的人没好结果**

有些人自尊心强又傲娇，只能听夸奖，一听批评就委屈一整天；特别在乎别人怎么看你，情绪跟海啸似的。这种人千万别创业。创业是九死一生的活儿，各种意外、挫折、负面评论、同行使坏、精心准备却无人买单……多得你想骂人。你看到的大咖光鲜视频，不过是十倍美颜后的滤镜。那些憋屈的、无助的、日更一百天粉丝不过千的日子，没人愿意讲给你听。我2003年开始创业，到现在整整二十年，真没觉得多美好。一年365天里，可能只有那天是有采访、上报纸、买车买房的高光时刻，剩下99%的时间全是煎熬。烦到极致，我也想过跳楼。但又能咋办呢？路是自己选的，扛呗。我修炼了二十年，这几年才慢慢做到情绪稳定。现在遇到妖魔鬼怪，我都笑笑，然后该处理处理。

尤其要提醒：夫妻一起创业的，情绪稳定比什么都重要。夫妻创业比合伙人创业难十倍，因为二十四小时绑在一起，家事公事私事炖成一锅粥。一不开心就甩脸子、不解决问题、把坏脾气往外倒，开心是合伙人，不开心就说“老娘是老板娘你咋滴”。这种内耗比一个人内耗还要命。所以我和爱人早就约法三章，提前打预防针，把边界感划清楚。不然，还不如各干各的。

一人公司这回事，看着是自由，实则全拼自律和心力。晒出来的美好只是冰山一角，底下是日复一日的孤独打磨。能撑下来的，都是狠角色。
