# 从零开始到视频号月入佣金十二万＋，一个电商新手的实战复盘



## 一个纯小白如何靠视频号做到月佣金 12w＋ 的全过程拆解

作者：李百万  
日期：2023-07-11

我是李百万，目前同时在视频号和📕一线冲。2023年4月18日我正式进群后，就进入了白天打理📕号、夜里埋头啃赚钱内部视频号精华帖的节奏，把学到的东西不断补短板、沉淀成自己的打法。

结果就是，5月份我个人在视频号这一块的收益直接破了12万＋。当下我也在带一批实操学员，30多人已经开始跑起来，有不少人日入已经稳定在几千甚至上万。今天不聊📕，就把视频号这条路是怎么跑通的，摊开来讲。

2022到2023年，视频号带货绝对是当红赛道之一。当时我还在西安做民宿，疫情一波反复把生意打得七零八落，心里又急又慌。后来厦门的一个朋友透露，他和搭档两个人做视频号，扣掉房租成本后，人均日收益能稳定在2000左右。

听到这个数字我直接心动了。反复请教他、再上网搜资料才确认，这个赛道盘子够大，而且门槛低、可在家操作、基本没什么启动成本。

于是在2022年底，我直接关了民宿，背着负债开始创业。朋友那边因为怕分利润，不太愿意拉新合伙人，我也能理解。当时自己也没付费学习的意识，要是早点花钱拜师，说不定就能更快上手了。

只能自己硬啃。先大批量进货、开播测品，一场场直播下来就盯点击率。实际跑起来才发现坑太多：直播技巧为零、话术不会、产品包装不会，直播间冷冷清清，连续半个月零成交。那段日子焦虑到失眠。

没路了就只能解决一个算一个。直播不会就通宵刷直播课，运营不懂就死磕案例和玩法。慢慢把不会的地方全部补齐。
