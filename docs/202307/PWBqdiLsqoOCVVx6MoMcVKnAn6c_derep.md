# “日赚1块钱”无人直播推广小游戏
作者：龙哥

这年头，网上到处是“月入百万”的暴富神话，看得人热血上头，仿佛明天就能走上人生巅峰。但冷静下来想想，大多数人不就是一介草根吗？想靠一个信息差就翻身上岸，哪有那么容易。

有人要开喷了：“连梦都不敢做，你还能干啥？”

行，我承认，我就是个普通人。以前也幻想过手上的项目能月入几十万，后来确实做到过，可惜只是昙花一现。没点真本事，靠运气捡来的钱，最后总能凭实力亏光。

别老盯着那些年赚百万的大项目，每天抓着一个项目踏实干，从日赚一块钱起步，也比一直“找项目”强。市面上项目千千万，有人挤破头想进去，有人却拼命想出来——适合自己的，才是最好的。

（发完牢骚，说正事。）

这阵子刷抖音，总能看到“全民来找茬”的无人直播，流量挺猛。可能是我多看了两眼，系统就疯狂给我推这类直播间。

![](img/6cfec785d3bb48cccdd1e03935a1395d.png)

看多了，心就痒了：这也太简单了，我上我也行。结果，真试了一下，分分钟搞定了。

先说说收入吧。我扒了一堆同类账号，发现真是同号不同命。有的账号像平台亲儿子，一开播就爆流量，一场下来利润500到2000；普通账号嘛，一场几十块就不错了。

互联网的尽头就是玄学！玩流量久了都会懂，有些号天生就是“天选之子”，发啥火啥，普通号只能干瞪眼。没办法，有的人一出生就在罗马。

准备环节也不复杂：

1. 一个千粉抖音号，新号老号都行，买也好刷也好（渠道自己找，刷千粉大概一百出头）。
2. 账号实名必须用自己或家人的，不然提现麻烦。
3. 一台闲着没事干的Windows电脑——抖音直播伴侣不支持Mac，当然你装个双系统或虚拟机也行。

# 开干！

第一步，刷到同类直播间，先观察下流量。如果还不错，就截图拿素材，然后用美图秀秀改吧改吧。

第二步，🛰️搜“纯色背景图”，找一堆壁纸👸号，挑一张颜色跟素材搭的，保存下来，再塞进表格里当背景。

第三步，录音。把直播间话术写进word里，用直播的调调念出来：“家人们……”口齿要清楚，别像读课文，感情要饱满。录个十分钟左右，剪映里拼一下，循环播放就行。

![](img/843bb9a51e68b2d466425aab666b06f4.png)

第四步，背景音乐用🐧音乐里那首“杨戬擒悟空”，单曲循环。

第五步，下载抖音直播伴侣，登录千粉号。

第六步，添加素材窗口，把你那个表格放大铺满直播间当背景。

第七步，把做好的找不同图片拖进去，调整好位置。

第八步，打开直播伴侣右下角的“游戏推广”，添加“全民来找茬”。

第九步，开播，设置讲解卡片。搞定。

操作步骤我就不截图了，都是点开就能看到的东西，别来问，问就百度。

几个小提醒：

录音情绪要饱满，别像没吃饱似的，这关系到观众停留时长。找不同素材呢，直接挑别人直播间已经火了的，市场验证过的东西，不会错。录一次音能用一周以上，素材别换太勤，纯色背景图两三天换一次就行。但如果某个素材突然给你带了大流量，那就死磕它，别乱动。

新号有流量扶持，有的当天就起飞，有的得坚持个三五天。反正就是烧点电费，成本低到可以忽略。稍微有点流量后，游戏厂商就会主动来私信你，给补贴，可能还有中介，不过无所谓，多赚一块是一块。他们会给你开通游戏广告分成80%（抖音内是60%），线下再单独补贴每个下载0.8元，平均下来推广一个游戏下载量能赚一块多。

![](img/fec4e9c2f5ac54fadfa7d31735dc6651.png)

注意了，如果中途直播被中断，被判了录播处罚，那就老实等三天再播，然后重新录音、重新找素材，再来一遍。

这个项目操作性很强，难度几乎为零，收入就看账号命了。想多赚点就多弄几个号，总会碰上“天选之子”，开播即巅峰。暑假快到了，也可以让你家小侄子、小外甥女体验下，靠自己的努力赚到互联网上第一个一块钱。这项目虽然不长久，但至少能让人感受到流量的魔力。

标题说“日赚1块钱”，那是保底的——只要你操作了，100%能赚到，赚不到我补给你。

真的不想再制造焦虑了。以后我分享东西，就打算从1+1=2开始讲，简单点，踏实点。

刚才那段吐槽算是跑题了。但风向标的价值我还是认可的，世界很大，不同人看到的信息差不同，结果也千差万别。我也开始多参与多分享吧。

你看，就这么个小项目，只要行动起来就有收益。现在很多人说“勤劳不能致富”，我倒觉得，不是叫你别勤奋，而是说光动手不够，脑子也要动起来，执行力才是关键。要是再加点运气、选对方向，那可能就真富了——当然，这只是我的个人看法。
