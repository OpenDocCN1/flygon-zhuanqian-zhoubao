# 用一页图读懂营销 4P 里最重要的“渠道”和“推广”



## 一张图讲透营销 4P 的渠道与推广

作者：小马宋
日期：2023-07-12

在地铁站外看懂渠道和推广。

前几天路过西直门凯德茂的地铁口，发现泸溪河把点心摊搬到了出入口。品牌在商场南门有固定店面，那个位置恰好吃不到地铁的人流。

但我连续几天上下班都看到，早晚高峰时段，他们会推车到地铁口现场售卖。甚至我妻子也在这儿买过两次，客流量看起来很可观。

站在营销视角看，这就是一次门店渠道的灵活外延。真正的客流在地铁口，门店不在客流的核心区，那就把销售点直接挪过去。

线下店铺的租金，说白了买的就是门口的人气。

在 4P 模型里，直接推动成交的两个关键要素就是渠道与推广，它们的共同逻辑都离不开一件事：先拿到流量，再让成交变得更顺畅、更快。

渠道的本质是搭建一套让交易能够发生的组织体系，推广的本质则是设计一系列让交易能够发生的动作。

拿泸溪河这个案例来说，西直门凯德茂的商业体和本店的加盟商，共同构成了它的渠道；至于让员工推着小车去地铁口现场卖点心，这就是一次典型的推广活动。![](img/5ad6da19761da5bbc640bbe0dcd8040b.png)
