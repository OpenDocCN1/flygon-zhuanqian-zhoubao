# 被别人抄袭怎么办？

被人抄袭了，到底该怎么办？

商业圈里最让人头疼的，大概就是“抄袭”两个字。

不过我的看法可能不讨喜，但却是实情：人类世界根本绕不开模仿，甚至可以说，文明能延续到今天，靠的就是一代代人的模仿与传承。

这话不是我说的，是法国传播学鼻祖塔尔德提出的。

你看，文化和风俗因为模仿才得以流传，商业同样如此。

德国早期靠仿制英国货起家，中国互联网起步阶段也是学习美国模式。可到了移动互联网时代，风水轮流转，美国巨头反过来开始模仿中国企业了，比如抖音，就被他们盯着一通学。

再比如，某品牌刚推出一个外观设计，没过多久，满大街都是同类仿品。这家企业气得不行，可又没辙——因为这是逃不掉的规律。

如果你觉得自己的外观是首创，别人抄就是不要脸，那不妨也反过来问问自己：你用的口味、写的文案、定的产品形态、走的加工工艺，难道就没有借鉴同行吗？你敢拍胸脯说，你做的每一样东西都是百分之百原创？

我不信。

喜茶的芝士奶盖、春水堂的珍珠奶茶、瑞幸的生椰拿铁、塔斯汀的中国汉堡、椒爱的椒盐水煮鱼、好利来的半熟芝士——这些不都被模仿个遍了吗？那它们当初“借鉴”别人的时候，算不算无耻？

再说丰田的TPS，你学不学？算不算抄？华莱士的合伙人加盟制，你研究研究，算不算抄？直播风格、包装写法、短视频剧情、私域玩法、客服话术，如果都是别人先想出来的，你还会照用吗？

所以说，只要身在商业里，模仿就避免不了，你不可能样样都原创。

真正的策略应该是这样：一方面，学人要快；另一方面，让想抄你的人难上加难。

戴森就是典型。它靠工业设计加上一堆技术专利，组成了一道保护墙，也只能勉强守住。

最后讲个真事。前阵子我认识了高樟资本的老范，他最近在读者群里也开始每日分享，不过做了创新——把内容做成带二维码的图片。他发给我看，我说这就是模仿律嘛。我呢，最近把小宇宙播客从“小马宋”改成了“小马宋商业观察”，也是受了“老范聊创业”这个名字的启发。说白了，我们不过是在互相模仿。

既然这样，就讲点对等原则：你抄别人的时候，别那么心安理得；别人抄你的时候，你也别咬牙切齿。
