# 小和尚、老者图片会说话升级版教程

最近不少圈友都在问：之前那版“图片会说话”的教程，人物描述词到底该怎么写？CT 软件怎么装、怎么用？视频合成那一步怎么老出错？

别急，升级版来了。

这是云天大佬结合市面上各路玩法重新整理的一套流程，整体思路做了个大换血，核心就一个字：快。

先说变化最大的几个点。以前用 Midjourney 出图，得等生成、等挑选，来回折腾很费时间；现在直接改成“以图生图”，不需要你费劲写描述语，拿一张参考图就能快速出图，速度几乎是秒级响应。

再一个是视频合成环节。之前的流程里 CT 那套操作相对繁琐，很多人在这一步卡住。这版教程直接绕过它，改用 did 这个思路——把图片和音频导进去，一键生成动态视频。操作门槛降下来，效率却提上去了。

整套流程跑下来，比原来快至少 20 倍。熟练之后，基本 10 分钟以内就能搞定一个视频，这个速度放到内容生产里，效率提升是肉眼可见的。

很多圈友关心的音频问题，评论区也给出了答案：did 自带的音频效果就很不错，不用另外到处找工具。有人试过好几款文本转语音的工具都不满意，其实可以试试 did 自带的，省事且效果好。
