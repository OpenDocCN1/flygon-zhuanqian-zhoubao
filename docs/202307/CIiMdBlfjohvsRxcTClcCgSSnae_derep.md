# 没有货源、没有团队，我靠📕一年赚了30万

> 来源：同原文

大家好，我是苏木，一个90后，今天想跟你聊聊我过去一年在📕上赚钱的真实经历。

先亮个底：这个项目我刚起步时就是纯“无货源”模式，自己一个人跑了一年，总销售额差不多50多万，不到60万，到手利润大概30万。后期靠一些方法慢慢搭起了自己的护城河，我觉得这套玩法普通人完全可以复制。别指望靠它年入百万——我反正没做到——但一年赚个10到20万，问题真不大。

今天愿意掏心窝分享，主要有两个原因：一是我一个人折腾太久了，确实孤独，想多认识一些同频的人，一起聊聊怎么把盘子做大；二是想找更多靠谱的供应商朋友，说不定我能帮你多卖点货。这个我放到最后详细说。

## 一、我是谁

我叫苏木，90后，简单交代下背景。

2015年我去深圳创业，运气不错，陪跑了一家集团从3个人的小团队做到500多人，年营收20个亿，整个过程我都深度参与。当然，集团是有那么多人，我自己直接带的也就30来号人。

后来觉得太安逸了，就跟同事跑出来单干，结果血亏三年，把之前赚的200多万全赔了进去。赔到第三年，我开始怀疑人生：是不是我能力不行？怎么一离开平台就废了？

过年回老家，我把自己关起来反思了一个月。结合过去的经验和真正想做的事，我给自己定了三条规矩，符合才做：

- 要有积累，要有复购，而且积累能成为你的护城河。
- 要有潜力，要有门槛。
- 坚决不做短线——这个后面我会解释为什么。

亏过之后心态反而稳了，就像大熊说的那句：“慢慢来，比较快。”

## 二、从知乎每月2000块的小正反馈开始

进赚钱之前，徐宿老师推荐我做知乎好物。我就跟着写自己最喜欢的运动类产品，结果第三天就出单了。可惜品类天花板太低，一个月也就2000多块。比起当时动不动月入五万十万的大神确实不够看，但我当时真的很开心。

做了三个月，账号进了知乎行业前10，好物收益却始终卡在每月2000到3000：

![](img/7bb5924124c9ca9720d096101ad80f71.png)

说实话，多赚两三千当然香，但我不满足。深入研究后发现，我在知乎选的这个赛道上限就摆在那，再怎么扑腾也赚不了大钱。

## 三、转战📕，第4篇笔记就爆了

既然知乎赛道不行，我就花了一周时间去别的平台试水，还是跑我熟悉的运动品类，最后锁定了📕。

我花两天把📕相关类目的爆款笔记和关键词整理成一份脑图。具体赛道现在还在赚钱，不方便公开，但后面我会教大家怎么判断一个赛道能不能做。

刚进📕时，我先注册账号默默看了一周数据，第二周才发了第一条笔记。发完当天下午硬是没敢打开看，到晚上才鼓起勇气瞄了一眼：点赞31，收藏18，评论6条。

看到这个数据我心里就一句话：成了！虽然还不知道怎么变现，但我知道📕绝对大有可为。

果然，第四条笔记直接爆了，当天冲到8000赞，最后停在1.7万赞。因为当时不知道怎么变现，只好先往微信引流。

![](img/ea6b6b693c193a7c979913ee3ddfe88d.png)

后来我开始尝试让这些来咨询的人掏钱，主要两块收入：

1. 红包：别人发红包问我专业的购买建议。
2. CPS带货：类似淘宝客，有人问某样东西怎么买，我直接推荐CPS链接。

第二点完全是意外发现。在那之前我压根不知道CPS是什么。只是咨询的人实在太多，我解答完，他们懒得自己找购买渠道，顺口问我有没有链接，我就去京东联盟、淘宝联盟生成转链给他们，钱就这么赚到了。

事实证明，人真的懒。一旦对方信任你，你赚钱的机会就多到挡不住。

![](img/eb045d830606a0bc2f1d659fcd8cf894.png)

红包变现也很简单：微信上有客户咨询，我解答，对方发红包打赏。这样一个月也能搞到小一千，我第一次感受到📕粉丝的付费意愿这么强。

![](img/344b22858a5c4e98839be68212503c2c.png)

等粉丝涨到500的时候，主动来找我谈合作的淘宝商家渐渐多了。聊了几家后，我开始不满足于单纯接广告——我觉得这件事能长期做下去，只要我把供应链抓到手、把成本降下来，它完全符合我这篇文章开头定的所有条件。

而且你做得越久，积累越深，利润就越高。

想明白这一点的那晚，我兴奋得整夜没睡。我知道，我终于找到了可以长期干的变现模式。接下来，该我上场了。

还记得我前面说的那三条规矩吗？只要符合，就是一个好生意，值得死磕：

### 1、有积累，有复购

我发现这个赛道的用户特别精准，来咨询的粉丝都能沉淀到我微信号上。因为我持续输出内容、长时间耐心解答问题，信任基础很强，很多人直接转账下单，连链接都不点。

![](img/7823d25291c165bef1d63475af8bc416.png)

一年时间，我微信好友里📕来的占了七成。到后来人太多实在回复不过来，我只能加已成交的客户——时间应该花给为你买单的人，而不是白嫖的人。

![](img/39ec6bfa4ba08cd9ebc0af328dd9e006.png)

上面这些就是直接转账的截图。有信任基础，成交真的不难。只要有需求，他们就会来找我。

### 2、赛道要有潜力、有门槛、有护城河

有潜力就是要选对行业，这个大家都有自己的心得，我先跳过，重点说说门槛。

我理解的门槛不是“一般人进不来”，而是“一般人能进来，但想做好、赚到钱，得下真功夫，扛得住不赚钱的日子”。否则谁进来都能立刻赚钱，那凭什么轮到你？真有这种好事，大概率是关系户，不是因为你能力强。

做的人多，说明行业吃香、有潜力；不是谁都能做好，这才是门槛。你做得越久，积累越厚，护城河就越宽。

我知道肯定有人想问：你凭什么跟比你早做了十年的前辈竞争？别急，后面我会回答。

### 3、不做短线

什么是短线？就是今天有个热点活动，赶紧去蹭一波流量赚快钱。

短线最大的诱惑是来钱快；最大的弊端是，贪欲被放大，情绪不稳定，最后被情绪支配。

更重要的是，赚过快钱的人真的回不去了。短期内变有钱会让你迷之自信，觉得自己干啥都能成，看不上小钱，结果99%的人都会亏到怀疑人生。

我以前在行业里见太多了：风口期你好我好大家好，风停了，曾经的兄弟为了钱翻脸撕逼，也不知道拿什么维持高收入，最后负债收场。

所以我宁愿细水长流，赚一辈子的钱，而不是赚一阵子的钱。

好，前面展示得差不多，下面讲讲具体过程。

### 4、再说说变现模式

找到变现模式后，我开始找一件代发的货源，谈利益分配。当时单量小、不确定性强，前期利润很低，但我还是果断做了——我知道后面的利润空间很大，因为客户在我手里，我就有话语权。

正式开始当天就出了第一单，赚了20块，而且完全不用垫资：客户先转账给我，我才去下单一件代发，售后也由对方处理，我就赚个差价。

我每天坚持做同一套动作：输出内容、引流、成交，像复读机一样重复。一个月后效果就出来了：订单变多，复购出现，转介绍也有了，正循环就这么跑起来了。

### 5、怎么选交易平台，降低客户的戒备心

当然也有客户对私下转账不放心，想走平台。我当时选了两个：快团团和闲鱼。

选快团团，是因为客户下单后钱马上到你账上，不用等收货，资金周转很舒服。

选闲鱼，是因为没手续费、基本没售后问题，到账时间可以商量，回款也快。

还有个原因是我当时真穷，只能靠这种快进快出的平台滚资金。从手上一分钱没有，到半年后能自己拿货回来再发货，全靠这套模式滚出来的。没钱又想做生意的朋友可以借鉴下，不懂的也可以找我聊。

不过一件代发也有不少坑。比如发货地址跟你所在地区不一致，虽然问题不大，但多多少少会影响客户信任；还有发货时间完全不受你控制，特别被动。

做满一个月后，收入稳定在每天100左右，卖利润高的品能到三五百。但很快问题就来了。

当时口罩原因，好多地方发不了货，要不就是收不到货。更离谱的是，货发出去了到了当地又被退回，一来一回快递费白搭，每天退几单就白干了。

真的非常搞心态，但环境就是这样，没办法，只能提前跟客户沟通好，勉勉强强做下去。

可接下来这个问题更让我绝望：还是因为口罩，工厂产能不足，直接断货，一件代发直接停发——你有货给不了，每天一堆人问你要买东西，你没货可发。你能体会这种感觉吗？完全无解，只能等时间解决。

### 6、手里必须有持续能卖的产品

因为我一直卖固定的几款产品，一旦断货，我就特别难受。

既然无解，那就想想以后怎么应对。

还记得上面留的问题吗——你凭什么跟比你早十年进入这个行业的前辈竞争？

这个问题看起来跟断货毫无关系，但你往下看。

因为是行业原因，这些前辈几乎等于工厂的“大客户”，所谓客大欺店，他们客户多，在工厂那边有绝对优先权。这问题也基本无解。

我想了很久，某次洗澡时忽然灵光一闪：既然比不过，那我换条路走不就行了？

要知道，新客源的数量，直接决定了你的老客户数量、复购和转介绍这些关键数据。

那思路就清晰了：

一件代发货源不稳？我干脆换成跟新客户更匹配的货源，工厂配合度更高、发货时间更有保证。

现有客户量比不过？不比了，直接釜底抽薪——从新用户下手。用自己的长板去竞争，不敢说一定赢，但胜率肯定更高。

因为一个行业的新用户数量是有限的，比如一个月就100个，原本全归前辈们。我在中间插一脚占了10个，他们就只剩90个。理论上，只要我的占比慢慢提高，超越前辈只是时间问题。

当然这个打法只在📕有效，其他渠道暂时做不到。

### 7、📕开店，搭起自己的商业闭环

为了彻底拿下📕这个渠道，趁官方推店铺的时候我赶紧上车，自己开了家店。个人店铺很好开，基本不用资质，交1000块押金就行——甚至可以先不交，提现时再交。先把生意做起来，后期开店门槛只会越来越高。

顺便讲讲开店的好处：

1. 可以光明正大引流。
2. 平台发优惠券，客户省钱更容易下单，成本平台替你扛，太香了。
3. 成交更容易，可以直接推商品。
4. 店铺有各种活动，参加就送免费流量券。
5. 店铺放着不推，也有自然流量成交。

到这一步，我的商业逻辑彻底跑通了，生态位也明确了。接下来反而简单：持续输出符合定位的内容，不断强化自己的IP，让更多人看见。

换掉工厂后，我根据客户需求优化了店铺商品结构，利润直线上升，从一单20块，到40、50块，再到利润率10%，最高能到50%。

但之前在集团的眼界告诉我：后面还有更大的隐藏利润，只是需要更多资金。我的目标就是吃到那些隐藏利润——多少有点“屠龙少年终成巨龙”的意思。

去年虽然口罩问题导致各种麻烦，生意不算好做，但成绩我还是满意的：一年50万流水，加上广告和咨询的转账，收入还挺可观，创业失败之后我总算过了个肥年。

刚才说到怎么筛选赛道，我的方法很简单：先问自己有没有兴趣，再看市场有没有需求。

## 四、📕赛道筛选方法

这套方法非常简单，普通人只要看两个基本指标就行：

### 1、看笔记总量

一个赛道是红海还是蓝海，看笔记总量就知道。

行业词在5万以下的属于小众领域，竞争小，流量也小。如果你本身有积累，进去很容易出成绩。比如古风服饰：

![](img/502495b4e07496f88781a7181cb54d96.png)

行业词在10万左右的，属于比较优质的赛道：有流量，有竞争但不激烈。如果自己有点积累，出圈只是时间问题。比如干鱿鱼：

![](img/de5358a4085b83548fe431a6236c3cd0.png)

行业词超过50万的，就是热门领域了。流量大，竞争也大，得有团队或者极高品质的内容才有机会脱颖而出——当然，做成大V之后回报也是巨大的。比如民宿装修：

![](img/87b9d3b9b3984bcac53bf65f7728a57f.png)

### 2、怎么判断一篇笔记值不值得投

不同行业标准不同，按中位数算：互动率10%算优秀，值得投薯条；5%算正常；1%到3%就说明笔记质量该提升了。

这个比例怎么算？每篇笔记都能看到“小眼睛”（浏览量），用（点赞+收藏）÷小眼睛数×100，就是互动率。

举个例子，下面这篇笔记：点赞64，小眼睛986，64÷986×100=6.5%。互动率不算特别高，不用纠结，直接准备下一篇就好。

![](img/3b29ce3f364cd540e5db2c2d6f10a0f1.png)

再看这张：点赞1266，小眼睛10851，1266÷10851×100=11.7%，这还没算收藏就已经超过10%了，肯定值得投薯条。

算互动率的真正意义，是帮你更清楚地看到用户喜欢什么内容。找到用户的喜好，创作出来的笔记数据会明显不一样。
