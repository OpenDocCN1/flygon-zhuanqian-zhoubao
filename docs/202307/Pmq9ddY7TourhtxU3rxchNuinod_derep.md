# 📕可复制矩阵玩法分享
作者：龙哥

先晒个成绩：上个月我们整个淘客盘子到手74万多，其中📕这一块，15个员工在做，人均产出1.5万以上，这一项加起来就超过20万。

前几天我去拜访了本地一对夫妻档，两个人做📕刚满一年，现在每个月佣金稳定在10万上下。说真的，📕确实是普通人切入互联网最容易上手的一个平台。

在正式拆解之前，我想聊几句题外话。为什么很多人做项目，做着做着就没下文了？为什么反复换赛道，却始终没赚到理想的钱？你有没有认真想过，之前做过的那些项目，最后给你留下了什么？那真的是你想要的吗？我觉得，人至少要去运营一件收益能持续半年、一年、两年、甚至更久的事情。

下面我按几个维度把整个项目拆开讲：

1. 📕项目是什么？为什么值得做？
2. 启动前要做哪些准备？
3. 📕精准淘客的完整操作流程
4. 代发时的注意事项

咱们一个一个说。

先看平台本身。📕本质上是年轻人分享生活方式的社区。平台用户里，90后占了72%，一二线城市用户占50%，分享者数量超过4300万，男女比例目前是3:7。这些数据的核心含义就是：用户消费力很强，商机很大。我们之前从闲鱼、快递、📕等不同渠道引流，对比下来，📕来的粉丝购买力最强。现在一个200人的📕粉丝群，市场价能到1500到2000块。换句话说，这些粉丝哪怕你不做淘客，直接转手都能变现，而且需求量很大。当然，这涉及买卖公民个人信息，不建议大家碰。

![](img/dbd305fcad1b131ed07d0402cb68701c.png)

那📕项目到底是什么？简单来说，就是分析我们需要的用户流量特征，借助📕把公域流量导入私域，再完成转化和成交，最终获得收益。

为什么选这个项目？因为它见效快，一周就能看到反馈；投入低，回本也快；收益能长期持续；流量基数大；粉丝一旦进入私域，基本不需要维护，属于被动收入；也不需要什么营销技巧，全程靠机器人自动发单，用户直接去淘宝下单，我们赚商家佣金。

前期要准备什么呢？设备方面，手机和电脑是必须的。账号方面，📕、🐧、🛰️都要提前准备，而且最好多注册几个，可以用家人的手机号来注册。软件方面，淘宝联盟（新号需要花30到40元左右升级一次）、京粉、发单机器人（一个月0到10元）、拉群机器人wetool（一年20到40元）。

具体的操作流程，可以分成五步。

第一步，下载淘宝联盟和京粉。要注意，淘宝联盟新注册用户佣金很低，必须做任务才能升到高佣。如果不想自己做，也可以找人代做升级。

第二步，买一个发单机器人。市面上这类淘客发单工具很多，价格一般在5到10元一个月。按照每个机器人的教程，把你的淘宝联盟和京东联盟账号授权给机器人就行。

第三步，下载wetool，用来自动同意好友申请、自动拉群。

第四步，准备📕手机。最好是一机一号，不要连WiFi，苹果机最稳，没有的话安卓也能用。苹果6s这个级别就可以，600块钱左右一台。每台手机配一个🛰️号，如果能双开，就配两个。

📕养号：注册完之后，先给账号打标签。你想引流什么方向的粉丝，就多刷那个方向的内容。推荐母婴、好物推荐、宠物这几个类目。养号周期大概3到7天。

🛰️号至少准备4个。每个人可以实名认证3个账号，不算难事。这里分三种情况：活跃老号最好，可以直接接粉，每天上限200人；沉默老号需要养号一周，比如带出去遛弯、扫码付款消费、每天跟3个以上好友聊上5到10句、在🛰️群里说话、朋友圈点赞评论，总之要模拟真人操作；新注册的号最弱，接粉数量少，可以提前注册放着备用。

第五步，发帖引流。拿好物推荐粉举例，具体内容我就不在这展示了，免得号被炸。大家可以参考这种模式：把上百元的东西，用几块十几块包邮的方式发出来，很多人会心动，然后问怎么买。看到留言后，可以私信引导，或者在评论区留一个导流号，再在导流号发帖，把🛰️或👸号留下来。但一定要注意规避敏感词，下面会说到。

![](img/49d97f73ed948133096b07ca507335df.png)

再来说说代发的注意事项。所谓代发，就是花兼职佣金让别人帮你发帖，这样可以把粉丝数量无限放大。代发那边通常是2块钱发一条，一条任务需要发到三个帖子上。检查的时候重点看几件事：账号有没有过违规记录、账号发过什么笔记、注册时间有多久，还有试发一条看看推荐量。如果你打算做美妆类，强烈建议找兼职代发，因为美妆类特别费号，最好别用自己的号发。

![](img/fd9ef84269e911ba2635b2c369570c7d.png)

最后是运营层面的几个提醒。

第一，避开各种专业术语和极限词。比如淡斑、美白、抗衰、超、绝对、微、vx、第一等等，这些都是敏感内容。同时也要避开明显的引流词，比如🛰️号、二维码、手机号、链接、点赞、评论、收藏、私信、回关等。

第二，私信引导时，尽量把🛰️号做成图片。比如拍一张照片，把🛰️号印在图片上。不过需要说明，做成图片也有一定风险。

第三，团队配置上也说一下吧。我们这边一名员工管10台手机，📕项目共有15人在做，内部采取三人小组的竞争机制。
