# 十分钟一条口播视频百分百起号分享

今天不绕弯子，直接上实操。我是王不也，20年上的大学，23年6月7号正式毕业。做互联网IP有些年头了，之前那个号叫“小鱼”，三个月做到30W变现。家在河南，一直信奉一句话：互联网要玩就玩高利润、强引流的狠活。

先简单交代一下老底子：闲鱼无货源、螺旋起号、矩阵日入2K，美女号全自动变现单号日跑1K；小红书虚拟资源日入600+；单号单人暴力引流300+，均日单人引流200+；视频类项目拆解、口播项目拆解，能做到百分百起号，日引流500+创业粉。现在公众号改名叫“大若随笔”，这一篇全当见面礼，直接给干货。

说回正题。大家刷短视频应该都见过那种纯视频的项目拆解，一两分钟讲一个项目，很常见。我以前也在做，但最近工作室碰上两个问题：一是资金要重新调配，二是母盘对接卡壳，人手也紧。这时候最需要的就是一个能批量复制、不费人、引流还猛的路子。所以我把之前的玩法重新揉了一遍，换成口播来讲项目拆解，效果出奇的好。

先说说纯视频拆解为什么难搞。第一，太费时间了。看起来就一两分钟，但对不会剪辑、软件用不熟的人来说，前期一条视频做个两三个小时很正常。第二，稿子能力跟不上。自己写不出东西去洗别人的稿，做出来的内容百分之九十干不过原作者的。说白了，你只能吃别人剩下的流量。第三，剪辑门槛高，学着学着就放弃了。

所以我把两个玩法拼在一起：用口播的形式讲项目拆解。纯视频流量大但泛，口播流量小但精准，合在一起，既能保证起号，又能让来的人都是创业粉。

具体怎么做？先讲作品制作。

第一步，账号主页照着同行抄。前期别秀什么原创力，找到一个你看得上眼的同行，把他的个人简介、背景图、置顶内容全部对标复刻。等你玩明白了平台规则，再慢慢加自己的东西。

![](img/627a131d65bfd06ae71580fb7aea4b1f.png)

第二步，稿子怎么来。我用的就是你手机里那个“轻抖”小程序，微信直接搜，免费白嫖。复制抖音作品链接进去，就能把文案提取出来。唯一的缺点就是每提一次要看十几秒广告。但PC端没有免费通道，手机端无限用。想自己写也行，但记得查一下平台违禁词。

![](img/e6f30ffc006aba5347c702d9d54e5e84.png)

第三步，做口播视频。提回来的稿子不能直接念，要洗一遍，把废话挤掉，只留核心信息。视频长度压在1分钟以内，太长完播率就崩。我这边习惯先单独录音频，因为要戴头套、开脸部特效，画面根本不用重录。录完音频，用剪辑软件把速度调到1.3倍左右，为什么？因为这会让整个人的节奏提起来，观众觉得你带劲，完播率也高。

![](img/6e00eb463d41f410fa37e141e21d739a.png)

![](img/d551f29e7676184cf9cc8240cd34e6cb.png)

配乐选节奏感强一点的BGM，但音量一定不能盖过人声，这是个容易被忽略的细节。

![](img/1144ce0912572182e6a142ea4bd71072.png)

然后说平台避坑，这部分是重点，一定要记好。

做抖音，前期千万忍住，别引流、别在主页挂联系方式。等粉丝到500左右，就去搞蓝V认证。认证完开个五六秒的直播，下播后进创作者中心，点开粉丝管理，就能开粉丝群了。平时要做主页展示粉丝群得等1万粉，但蓝V号可以直接在评论区甩群链接，这就是好处。不过群的运营要注意，别用跑作品的号去发引流信息，找个没实名的号挂个管理，让它发。

最后说点掏心窝子的话。引流这事，你得坚持，也得懂得筛选，在一个领域做透、做出名堂。别总想着换赛道。就说最不起眼的闲鱼，我一个号一天也能稳定引20到30个创业粉。

![](img/519d98f2c17bb10a685293adc811e311.png)

有人看不上闲鱼来的粉，觉得是垃圾流量。但现实是，我那个19.9的APP合伙人招了七百多个人，其中百分之六十都是从闲鱼上买票上车的。这个转化率你应该掂量一下。19.9本来就是入场券，后续这些人往社群里沉淀的比例大概有15%，其中买了千元以上客单价的有8个人。所以我的态度很简单：只要对方有创业意向，就是潜在客户。你现在转化不了，就从自己身上找原因，去优化转化流程。蚂蚁腿再小也是肉，别嫌钱少。

再说下养号，说实话我从来没养过。新号第一天就点赞两条和国家、正能量相关的视频，然后搜索“项目拆解”，随意点一个赞就行，全程两分钟。第二天直接发作品，就这么简单。

以上就是我最近这段时间实打实跑出来的经验，希望能帮到想入门的朋友。欢迎来跟我交流，大家一起在网赚这条路上走得更远。
