我直接上RPA机器人来解决，半小时就搭好了。只要你把合集里的第一个视频地址丢进去，机器人就会接力把后面的视频依次抓取，全部自动下载且自带去水印。

# 怎么用，三步走

## 1、装好机器人

下面这个 json 就是整套下载合集的 RPA 源码，保存到本地后按常规方式导入即可。

https://download.rpastores.com/rpa/excel/%E4%B8%8B%E8%BD%BD%E6%8A%96%E9%9F%B3%E5%90%88%E9%9B%86-823.automa.json

因为抖音前端经常改版，旧版本可能失效，建议用下面这个最新版链接下载，遇到用不了的情况可以联系我 v:dahuzirpa 免费领更新版。

## 2、用 Chrome 打开合集页

直接在浏览器打开你想下载的合集地址就行，例如：
https://www.douyin.com/video/7247524784454667577

## 3、运行机器人

在第二步打开的页面中启动机器人。

启动后它会按间隔自动逐条下载，文件会保存到浏览器默认的下载文件夹。
