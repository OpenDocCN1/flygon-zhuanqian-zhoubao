# 定制AI指令月入10万？这个新职业正在闷声发财

你有没有想过，让AI替你写文案、做内容，你还因此月入十万？这不是异想天开，而是正在发生的事。故事的主角叫袁六伟，他的标签很多：两万多名学员的阅读教练、得到领读人、前花生日记浙江区运营总监。如今，他又多了一个身份——国内最早一批靠定制指令月入十万的工程师。

今年6月，他接下了3个企业级指令定制单：一个用于📕文案，一个用于自媒体长文，还有一个用于抖音短视频脚本，报价从4000元到6000元不等。7月订单更多，有位艺术类客户甚至愿意为“中文说唱”指令支付10-20万元。除了定制业务，他还把指令训练营、付费咨询、指令社群等变现路径全部跑通，准备将SOP公开，带着大家一起把市场做大。

为什么企业愿意掏钱买指令？因为账太好算了。聘请一位资深文案，年薪加福利最少要30万；而一套成熟的指令，老板自己就能在几分钟内搞定高质量内容。袁六伟曾为客户定制过“房琪式”文案指令，一分钟能产出2-3条还原度达85%的旅游文案，长期看边际成本几乎为零。如果你是老板，你会怎么选？

很多人好奇，他学AI也就半年多，凭什么能接到订单？其实他起点和大家一样，只是多做对了几件事。第一，保持学习。每天雷打不动花2-5小时，读论文、刷推特、逛即刻，关注👸号AI博主，人工智能相关的书也一本不落。这让他坚定相信，AI是千载难逢的机会。第二，持续输出。他在各平台写免费文章，在付费社群做分享，不求立刻回报。他的第一个定制客户，就是在一个收费不低的📕训练营里，被他分享的内容打动，主动找上门的。第三，用专业做差异化。当大多数有资源有流量的KOL都在做通用AI变现时，他切入了自己更擅长的指令设计。毕竟，他多年的阅读写作教练经历，让他调教出的指令质量远超普通人的自动生成。所以，AI变现最正确的姿势，就是“AI+你的专业所长”，既不内卷，又能收高客单价。

报价其实并不神秘，核心看两点：给客户创造的价值和你的调教成本。假设一套指令帮助客户实现10倍提效，而客户以前外包给乙方一年要花50万，那么收3-5万完全合理。调教成本包括训练成本和推理成本：训练需要喂入大量高质量语料、方法论和案例；推理则是反复测试，看指令在不同模型、不同行业、不同产品下的输出效果。拿人打比方，上学接受教育就是训练，上班解决问题就是推理。一个优秀的指令工程师，说年薪百万一点也不夸张。

关于Prompt的未来，圈里有两种声音：一种认为AI会越来越智能，Prompt会变得不重要；另一种认为Prompt会像编程语言一样催生专门职业。袁六伟的判断是两者并存。就像手机拍照越来越专业，但摄影师依然离不开相机。在科研、数据分析、技术开发、内容创作等复杂领域，用户需要更精确的指令，也就需要专门的指令工程师来设计优化。即使未来有大平台把指令封装好，每个细分领域的专业指令，依然得外包给懂行的工程师，程序员未必做得了。

想成为指令工程师，门槛并不高，不需要编程基础，只要你足够懂一个领域，又善于写作，就有机会。具体能力可以概括为“一个中心、三个基本点”。中心是CHAT模型，这是一个可复用的元指令，它的核心要素是角色、背景、目标、行动——先告诉AI它是谁，再给足上下文，说清要实现什么目标，最后明确要它做什么。这四个要素的英文首字母正好组成CHAT。这跟领导下任务一模一样，难怪有人说，能用好AI的人往往具备管理思维。三个基本点：一是细分领域专业，比如调教带货文案，就必须懂高转化文案的逻辑；二是会表达，能把专业经验翻译成AI听得懂的语言；三是会给指令打分，即使面对不熟悉的行业，也能判断指令优劣。袁六伟甚至开源了一个打分指令，按明确性（30分）、实用性（25分）、创新性（15分）、结果稳定性（15分）、通用性（15分）五个维度评估，让AI帮你打分并优化。

有人担心，自己辛苦开发的指令会被别人抄走。袁六伟却毫不担心，因为他很清楚，自己的核心竞争力不在指令本身。就算别人拿到他的指令，也不一定能解决自己的问题，更不一定能持续赚钱、开发客户、上台讲课。真正的护城河，是专业能力、表达能力、运营能力和商务能力。他敢把高价值指令开源，就是这份底气。正如他常说的：你有本事，就把我的本事拿走。

这个市场到底有多大？计算机时代有程序员，AI时代就需要指令工程师。AI商业化分三层：最底下是卖算力的英伟达们，中间是各类模型公司，最上面是AIGC在不同领域的应用。指令就处在应用层，是用户与AI之间的管道。这背后是一个万亿级别的市场，哪怕一个小公司只切一个细分赛道，比如📕文案、抖音脚本，一年也能带来几百万纯收入。袁六伟现在拥有84位指令工程师和上游B端资源，他决定 all in 这个方向。

未来已经到来，只是分布得并不均匀。
