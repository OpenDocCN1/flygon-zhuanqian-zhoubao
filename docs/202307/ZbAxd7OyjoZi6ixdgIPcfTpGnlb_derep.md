# 3年投资回报10倍的行业，普通人的机会在哪里？
作者：龙哥

最近陆续看到不少朋友在聊3C数码租赁（尤其是手机租赁）的风向，也有人翻出我2021年底发过的资源对接帖子——当时我就在找流量合作，客单价高、回报也高。

我自己在这个行业摸爬滚打了四年多，今天干脆把操盘Top级项目的经验、机会、风险和心里话都摊开讲讲，希望能帮大家找到适合自己的切入点。

## 这个行业到底在做什么？

简单说，就是让人们不用一次性买断手机或其他电子设备，按月付费就能使用。有点像租公寓——你每个月交租金，享受设备的功能，但不用承担所有权。无论是想尝鲜新机型，还是临时用一阵子，这个模式都挺合适。

## 赚钱吗？答案是肯定的

大家最关心的就是钱。手机租赁确实能赚钱，而且通过复利滚动，收益相当可观。按我们内部的测算模型，三年时间投资回报可以做到10倍左右——比如投入1000万，三年后债权规模可能接近1个亿。

## 赚钱的逻辑是什么？

本质就是租赁——碎片化转移使用权，所有权不转移。目前主流玩法有三种：

1. **租完归还/买断**：比如手机采购价1万，12个月租金8000，到期买断金5000，租金加买断金合计1.3万。
2. **租完即送**：比如采购价1万，12个月租金1.3万，租完手机直接归客户。
3. **短租模式**：按1到6个月灵活租，满足临时周转或备用需求，随租随还。

充电宝租赁、电脑租赁、游戏机租赁也都属于这个赛道。

## 两大风险必须盯紧

第一是**行业风险**——行业调整、政策变化、监管趋严，这些不是我们能左右的。

第二是**风控风险**——欺诈用户、逾期率。逾期率控制得越低，利润空间就越高。说白了，行业变化我们管不了，但逾期率是我们能拿捏的，把它控住，利润自然就上去了。

## 机会藏在哪儿？

这个行业其实是一个生态，每个环节都有赚钱的门道。从流量、软件开发、风控、手机发货、资金对接、自己下场做业务，到司法起诉，都能赚钱——投入可大可小。我根据自己的从业经验，把看到的机会列一下：

1. **流量**：目前行业CPS大概500左右，直播、短视频、私域、🛰️生态、支付宝生态、📕、线下渠道都能做。
2. **软件开发**：租赁平台开发维护、三方数据服务、短信服务、电子合同。
3. **风控**：三方数据供应、征信服务。
4. **手机发货**：全新机供应、二手机供应。
5. **资金合作**：一定要找靠谱且稳定的资金方。
6. **直接下场做业务**：入驻别人的平台，或者自己搭平台，两种方式各有利弊。
7. **司法起诉**：跟律所或法院合作，处理逾期追偿。

这些环节都有人做得不错，利润也相当丰厚。只要你的优势能对上一个环节，就有机会。

## 三个关键点：流量、风控、资金

租赁业务的命门就这三个：找到精准用户，控制住风险，有足够资金买手机。

- **流量**：现在大部分流量还是来自支付宝——首页、芝麻信用租频道、支付后页面都有入口。不过随着玩家变多，直播、图文平台、线下也都在抢流量。
- **风控**：常见的是机审（三方大数据+征信）加人工审核。下盘是一个实盘风控策略，把进件用户按数据模型分成ABCD档，或者做成类似芝麻分的评分，用来预估正常还款和逾期概率：

![](img/98a4c19d4e0200fd4fee33408b8764a6.png)

风控策略本质上是在风险和收益之间找平衡，不是追求零逾期、零坏账，而是追求利润最大化。我们一般通过大数据机审、人工审核、保险服务、司法起诉等手段来控风险、提收益。

- **资金**：主要来源有自有资金、融资租赁公司资金、金融租赁公司资金、金融保理资金等，资金方年化大概12%到15%。

这三个点就是整个租赁业务的卡点和瓶颈。没有用户，赚不到钱；有用户但风控不行，租出去收不回来，也赚不到钱；用户和风控都好了，但没钱进货，照样赚不到钱。
