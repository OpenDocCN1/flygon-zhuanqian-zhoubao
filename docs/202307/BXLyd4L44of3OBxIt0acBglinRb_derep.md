# 别再苦等广告了！这款 Chrome 小插件，让我轻松存下抖音无水印视频

> 平时刷抖音，是不是经常遇到想收藏的视频，结果保存下来还带水印？更烦的是，用那些在线工具或小程序，下载几个就得看一遍广告，效率低还闹心。

## 为什么我会动手做这个插件？

说实话，我的日常工作经常要从抖音找素材。以前图省事，都是🛰️里搜个小程序直接下载。偶尔下几个还能忍，一旦量大，广告弹个不停，时间全耗在等待上了。作为一个干了多年技术的“老手”，琢磨着与其天天受这气，不如自己写个浏览器插件，既能自用，还能当练手项目。

## 开发前以为很简单，实际上踩了不少坑

刚开始想得挺美，无非就是三件事：

1.  找到页面里视频的真实地址和接口
2.  选个语言写个下载工具
3.  做得简单好操作

可真动手才发现，第一步就直接“翻车”了。打开调试工具，确实能找到无水印链接和网上说的接口地址，但试了下发现，现在的链接后面都加了动态令牌，必须逆向出 JS 的生成逻辑才能继续。我这多年后端+管理背景，玩逆向真有点力不从心，果断放弃这条路线。

![](img/2c3594fc6a69d1ce38a4c2ffb7198605.png)

![](img/817a751368f81cb1052cf9f3de42d2c8.png)

然后想着要不找现成的第三方接口？Google 上还真有，注册了个平台一看，基本都是按次收费。虽然对稳定服务来说这其实是不错的方案——专业的人做专业的事，省时省力，费用也还能接受。但我就自己用用，没必要花钱，就暂时搁置了。

![](img/95b752f115cfe10c163f4fbf3fb0363e.png)

最后我选了第三条路：直接用 Chrome 插件解析页面加载完的 DOM 结构。这招简直就是天然优势，页面上的任何元素都能直接操作，装个插件就能用。缺点是纯前端实现，功能没那么灵活，但自用足够了。

搞定地址后，又遇到个新坑：视频地址分两种。一种是正常的 `https://` 格式，直接下就行；另一种是 `blob:` 格式，根本没法直接下载，会报错。查了下网上的方案都挺麻烦，最后做了个容错处理：碰到 blob 地址时，就单独打开视频详情页，抓取 https 协议的地址来下载。奋战两天，终于搞出了初版，用起来超级简单——点个按钮就行：
