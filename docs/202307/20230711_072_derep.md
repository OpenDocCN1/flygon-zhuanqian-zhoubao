# 有货源手里拿着书，怎么玩绝版二手书



## 有货源玩家的绝版书实操拆解

作者： 一游  
日期：2023-07-05

很多人以为我是龙哥，其实我只是比不看书的人多看一点。我对二手书的关注，是从一个付费课程开始的，当时没钱交学费，只能到处搜资料。后来进了二手书交流群，才系统了解绝版书的操作。赚到第一笔钱后我就一直做下来了，到现在已有三年。

这三年里我踩过很多项目，最后发现一个道理：不是先有兴趣才去做，而是先做了、有了正向反馈，兴趣才会跟着来。

现在闲鱼二手书航海报名的人很多，私聊我想要付费带的人也不少。我就说一句实在话：先严格跟着航海的步骤走，等自己尝到甜头再去深挖行业，找真正能一起走下去的战友。赚钱的价值就是帮你避坑，别自己给自己找坑跳。盲目花钱学，只会让钱包更瘪。先把定位定稳，再去专精。

下面这部分，是专门给已经有货源、想做更重的模式的同学看的。

### 一、先说清模式边界

目前我还是更建议新手做无货源，轻、快、好上手。有货源的绝版书玩法门槛更高、操作更重。但如果你手里能稳定拿到书，玩法是成立的。

绝版书在二手市场始终有需求。版本停印、存量稀少，需要鉴别、清洗、修复，价格往往能高于原价。下面就从筹备、选品、注意事项三个维度展开。

### 二、前期筹备

**1. 平台怎么用**

绝版书的闭环基本绕不开两家：多抓鱼和孔夫子旧书网。

通常思路是：多抓鱼收，孔夫子卖。原因后面会讲。

**多抓鱼是什么**

多抓鱼是一家主做二手书回收与交易的平台，核心服务有：
1. 回收旧书，用户寄书到指定仓，多抓鱼评估后给价；
2. 在线购买，可以搜索购买他人在售的二手书；
3. 线下门店，部分城市可到店选书；
4. 快递取件，支持上门收书。

它的优势是交易便捷安全，且有专业评估鉴定，减少了假书和品相风险。

**为什么在多抓鱼拿货**

1. 成本低：回收价评估后，绝版书经常能以远低于市价入手；
2. 品类全：覆盖面广，基本能搜到各种冷门书；
3. 操作方便：手机电脑都能下单；
4. 品相可控：平台会检验，正版保障，基本八五新以上。

**为什么在孔夫子卖货**

1. 人群精准：孔夫子是国内老牌二手书平台，买家多是硬核书迷，愿意为绝版买单。闲鱼用户更偏性价比，宝妈学生为主，付费意愿低。
2. 价格更高：孔夫子有鉴定背书，打击盗版，信任度更高，成交价更好。
3. 发货省事：扫书背二维码就能自动填充书目信息，只需补实拍图、价格、品相三项。
4. 免营业执照：个人开书摊无需证照和保证金，平台抽5%手续费，不抽运费。更大的好处是售前售后沟通少，用户默契度高，适合没太多时间做副业的人。

**2. 货源怎么找**

① 废品回收站
和家附近回收站老板谈，按斤收书，我一般是2元/斤。用孔夫子扫码系统快速筛选有差价的书。适合一二三线城市。

② 孔夫子上门收书
孔夫子👸号里有上门收书服务，定位后可以看到附近有人发布闲置书，凭图片先用数据库判断利润，再线下交易。

③ 闲鱼打包清库存
搜关键词“搬家 书”，很多人搬家会整批出书。用孔夫子数据库核验是否有溢价。

④ 图书馆置换
目前我只知道深圳。深圳图书馆有换书活动，每月能用低成本书换到一些绝版书。

**3. 怎么判断绝版**

核心一句话：市价高于原价的就是绝版。打开孔夫子APP扫条形码，看最低成交价即可判断。

### 四、上架与运营注意点

**孔夫子上架**

1. 品相要写实：划线、破损、污渍都要如实说明，别隐瞒。
2. 图片清晰：至少3张实拍，描述详细。
3. 价格明确：写清是否含损。
4. 退换货：二手书原则上不退，若买家态度好可特例，但邮费由买家承担。

上架、擦亮等细节航海手册已讲，这里不赘述：https://search01.shengcaiyoushu.com/docx/R8eUd7TcModS7RxYaogceiZgnOb5

**物流**

刚开始可以用孔夫子在线发货，后期量上来就和本地快递点谈，4-6元/单比较常见。
