# 普通打工人，靠内容创作三板斧做干货型图文，平均月入5000+
作者：龙哥

我是📕干货型图文博主王多维，一个普通打工人，靠内容创作三板斧，硬是把副业收入做到了月均5000+。去年不到半年，出了20多篇千赞爆款，最夸张的时候连续4篇都是千赞。今年2月到6月，累计变现2.5万多，平均每月超过5000。对白天还要上班的人来说，这笔钱真不少。更要紧的是，这套玩法完全是我0基础自己摸索出来的，现在做一篇图文只要半小时到1小时，数据却比大多数人好。巅峰时爆款率能到80%，一篇笔记涨粉几千。下面我把自己的经验完整拆开讲。

一、定位：先认清自己，再想怎么变现

做📕，第一步不是找赛道，而是做人设定位。人设定位就是告诉读者：你是谁，你能提供什么价值。定位定了，人群就定了。我曾经也学过三步定位法、四步定位法，但归根结底，定位的本质是跳出认知局限，用上帝视角看自己。

我给自己定位的过程很简单：刚毕业，当过四年班长，211本硕，学历虽然不算顶尖，也超过了大部分学生；平时爱研究个人成长，所以我就成了“老学长”。这个身份让我有东西可写，也是我的天然优势。那些天天说这个赛道好、那个赛道火的，如果自己不能持续输出，最后就是炮灰。

但这里有个坑，我踩过：商业化定位。我一开始没想清楚靠什么赚钱，选了PPT类干货笔记。这类笔记干货确实足、信息密度大，可广告位很少。和我同量级的博主动不动月入过万，我还卡在5000多。所以正确的定位必须是人设定位+商业化定位，你既要清楚自己是谁、能提供什么价值，也要想明白未来靠什么变现。

二、号设化：让每一个细节都长在定位上

定位想清楚后，昵称、头像、背景图、个人简介都要围绕它来设计。当时有个账号让我特别受触动：昵称就叫“学习方法”，头像也是绿黄配色的“学习方法”，简介一句话“持续分享拿来就用的学习方法”，此外还放了联系方式和引流引导。每篇笔记第一句是“用学习方法把你变成学霸是我的责任”，评论区还引导浏览和关注，整个风格高度统一。那一刻我意识到，细节做到位，真的能赢。所以我把这些细节研究得很透，贴出来给大家参考。

![](img/9783bf02e42e2b172bc7c89044b19460.png)

先说昵称。三个原则：避免重复，方便搜索；简单上口，2到6个字，别用繁体字特殊字符；全网一致。起名方法有很多：真名或简称，如李子柒、房琪kiki；兴趣领域+昵称，如绵羊料理、旁门左道PPT；专业岗位+昵称，如收纳设计师万万、设计师楠哥，有地域性的可以加城市，像南京英语韩老师；产品/品牌+昵称，如秋叶PPT；昵称+社群/栏目，如初六电台；标签+昵称，如超乐观小黄、学习委员小陈。天马行空的风格不建议。当然，起了好名字不代表就一定能火，但好的昵称确实能让大家记住你、搜到你、关注你。名字有价值，好名字最好全平台注册，尤其是名字唯一的平台。

再说头像。原则是真实、有个性、传递情绪价值、和定位契合。可以用个人生活照、形象照、品牌logo、卡通形象或萌宠。要注意清晰、传递正面情绪、不带引流信息、别频繁更换。比如恺恺学长的头像是戴着“加油”的看书卡通，又可爱又励志；小李的学习干货用真人看书照，特别贴定位；鹤老师说经济用卡通形象，和视频画风一致。

研究完这些，我最大的感触是：总有人抱怨📕不行、是不是被限流了，但很多人在这些看似不起眼的细节上下了大功夫。所以每次数据不好，我都会提醒自己：不是平台不行，是自己没做到位。连这些基础都不肯研究，怎么做好呢？

个人简介我也看了100多个账号。总结下来，要素包括：我是谁，简单自我介绍；我有成绩，数字化表达；我有影响力，数字化表达；我的愿景是什么；我能帮你什么；账号发什么内容；提供资源引导关注；联系方式。写法上，有成绩的个人IP，就突出厉害的经历和成就；还在成长的，就把愿景、内容和你能提供的陪伴、信息、交流价值讲清楚。不用全写，注意排版，多用表情和回车，清晰就好。

三、用稿定设计打造笔记形式

📕对审美要求很高。我尝试过很多形式，最后发现干货型图文最适合我：不用拍照、不用修图，确定好模板后就可以直接套内容。当时我看到一些博主的封面和内容都很好看，决定模仿他们。

![](img/017a18858671850652ebc67e3f7149c5.png)

![](img/ec5efbd15326d9c3cdc8469d8ef55d76.png)

我的工具是稿定设计，用了一年，不充会员也能模仿出90%的📕干货型图文。朋友还笑我是“图文笔记卡卡西”。早期我试过很多形式，反复调整后才确定了自己最常用的一款。

![](img/1f2afd03889f6cd428c82e0b8389dd7b.png)

拆解是核心，要拆到极致。如果模仿出来的数据不好，先想想是不是模仿得不像，而不是怀疑方法。自己从零创作一种形式其实很难，我更建议结合主流形式一点点改，加入自己的元素。100%复刻，再加自己的创新，成功率才高。现在看到一篇笔记，我基本能判断它是怎么做出来的，模仿个八九不离十。

![](img/3f08b712e0a76a7434139c0f6b82151b.png)

具体怎么拆解？拿一个封面举例。先在稿定设计里新建一个3000*4000的画布，导出图大概3到5M；嫌大就用1500*2000，导出约2M。背景图需要那种暗色、静谧又有质感的图，我一般去Pexels找。上传后感觉不对，因为图片太亮、字不明显，字体也不对。这时候就要用醒图把图片调暗、加颗粒，用识字体网识别原图字体，比如江西拙楷（仅供学习演示）。稿定设计里没有这个字体，就自己找资源导入。最后把原封面放到同样大小，一比一临摹字号和行距。内页也按同样的方法搞定。

四、三个选题方法

笔记形式固定后，选题就成了关键。我的选题方式有三种：

第一，从自身定位出发。我是老学长，就不断挖自己大学经历里的优势，把自己的成绩变成内容。这个方法的核心是深挖自己，用真实经历带数据。

第二，从受众人群出发。我的粉丝主要是大学生，所以必须了解他们的节奏：比如准大一新生拿到通知书就憧憬大学生活，大一大二关心暑假安排，大三大四关注秋招，最近是计算机等级考试报名，12月有四六级。跟上人群的状态，选题就有了。

第三，用爬虫辅助。用后羿采集器、📕笔记采集等工具，爬取关键词下的笔记，按点赞量排序，取前面的几个主题。这种选题往往自带爆款基因。

五、内容三板斧

前面的铺垫再多，最终还是要落到内容上。我总结的三板斧，新手看完就能上手。

第一板斧：资源整理。就是把别人发过的内容整合一遍，加上自己的理解，比如《10部历史纪录片》《100部高分电影》《10部金融纪录片》《看完就能自律的10本书》《女性成长必须养成的100个小习惯》等。关键是找一个切入点，不能太直白。像这篇，4月发的，现在还有接近4万赞，一下就把号做起来了。罗翔、辩论赛这些主题也可以这样操作。

![](img/61030bddfcd68f3da33d3668ae01399d.png)

第二板斧：道理列点文。比如《20个学习习惯》《15条生存指南》《30条信息差》《20条潜规则》《15条必备技能》。这种内容最好写：从知乎、👸号、📕里找素材，把金句用自己的话重新讲一遍，再配上自己的笔记形式，很容易出爆款。像聊天话术、职场潜规则，都是换了种形式和场景。

![](img/4c075061adac9516c377fdbe2d8d30c4.png)

![](img/c4e12054064238b8bec2cfe90a9f7e46.png)

第三板斧：分论点式。

这就是我的完整打法：先做人设+商业化定位，再用号设化让细节为定位加分；用稿定设计快速搭建笔记模板；用三种方法稳定找选题；最后靠三板斧持续产出。普通人想复制这套路，不需要太多天赋，只需要把细节研究到位，然后坚持执行。

总分式结构，说白了就是一个总论点后面接多个分论点的写法。比起前两种写法它看起来更复杂一些，实际上本质上还是前者的组合。举个例子，我之前拆解过的一篇笔记，博主现在正处于快速涨粉期，笔记发了130多篇，已经做到5万粉丝，还有一条笔记收藏破了116万。

这种写法的高明之处就在于能把零碎的干货点拼接成一个完整的信息块。它的可复用性极强，一张图就能在好几条笔记里反复使用，性价比拉满。

同一种选题，三种呈现方式其实都可以用。但如果想让人设更鲜明、更有记忆点，第三种总分式往往更吃香。因为信息密度高、维度多，天然就提供了更多体现个人风格和场景感的空间。

# 七、总结与反思

我运营📕一年多的感受是，对新手来说，干货型图文内容上手门槛最低。既不用太在意拍摄场景，也对审美要求不高，而且复用效率惊人。我最快时20分钟就能赶出一篇推广笔记，反馈也相当不错。

当然这套打法也有短板，就是品牌展示的位置太少了。plog类内容一张图就能露出一次，而PPT类的图文笔记往往只有2-3张长图能放广告，这就直接拉低了接商单的几率。

我现在也在尝试探索新的呈现形式，既能增加露出位，又不让PPT笔记变得更难做。等有成果了再来跟大家同步。大家好，我是多维，期待和你互关！
