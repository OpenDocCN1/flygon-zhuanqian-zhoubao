# AI图片说话项目保姆级教程-个人实操分享
作者：龙哥

最近不少朋友问我，那些照片里的人物是怎么张嘴说话的。其实这类玩法已经跑通了，特别适合没什么经验的普通人。我这个号做到第三天，就进账了299元。

这个项目市面上叫法很多：有人喊它AI虚拟人，有人喊它动态照片，还有人叫图片口播。规则都一样：找一段文本，配一个形象，再用工具让它像真人一样读出来。名字无所谓，能跑出结果才是硬道理。

我真正动手是6月21号，到6月27号，红书号多了500个关注，B站破千，抖音也涨了348。🛰️短视频那边比较倒霉，连着两个账号被处理。除了这个渠道，其它平台数据都在持续往上走。

有几点感受挺深：B站能涨这么快，完全在我的意料之外；另一个号晚了三天才开始做，成绩也不差，说明现在入场还不晚；到27号为止靠带学员进账299，中间有两单我主动拒了，觉得对方不太合适，现在想想有点后悔。

新号一般三四天就能稳定起量，做下来最大感触是对小白极其友好。我每天花约一小时做四条视频。晚上把素材丢进云端文档，早上统一制作，再到各平台分发，平均每条约15分钟。整个过程不需要真人出镜，只需要准备三样东西：文本、人像图和合成工具。

先说文本。

文本是这条链路的核心，我觉得它的份量至少占五成。好素材本身就是流量：哪怕不用虚拟人念，只把文字配上音乐和照片发出去，也有机会火，只不过账号记忆点会弱一些。

我目前主做禅意语录，画面风格大致像下面这样：

素材不难找。去抖音、红书、🛰️短视频搜“禅学”“佛学”之类的关键词，能翻出一大堆。把它们存进文档，就是源源不断的弹药。更省事的方法是直接参考热门同行，毕竟他们的素材也是从平台收集来的，但一定要做好查重隔离。

牢记一个原则：优先选那些已经被验证过流量的素材。爆过一次的东西，换件外衣重新发，大概率还会爆第二次。

当然，现在做禅语号的人太多了，文本同质化很严重。假如你先发的人已经火了，你再发很容易被判成抄袭。怎么破？我的工具是ChatGPT，让它做二次微创作。

举个例子，网上有一句很流行的话，大意是：有位师父讲，幸福其实不难，总共没几个字：被惦记、能归家、饭点有热菜。这句话好多号都发过，你也想用，那就请ChatGPT在原文基础上扩写三五十字，加一段对忙碌生活里的温暖细节的感慨。

这样一来，原本的爆款内核保住了，表达上又和别人拉开了距离。

文字短的这样处理就行。篇幅比较长的文本，方法留到视频合成部分再说。

除了禅语录，周易、情感口播、商业认知、人际处世，甚至一切历史上曾经爆火的短内容，都能用这种模式重做一遍。

接着聊虚拟形象。

形象可以用MJ或SD生成，会画图的人应该轻车熟路。这里不谈具体教程，只讲两个容易被忽略的问题。

第一，形象要贴合受众。我做禅语号，目标用户偏向银发族，所以选了一个小沙弥，人们对可爱孩子的天然好感很容易迁移。如果做周易方向，可以做一个白胡子老者，最好有几分仙气；做道学方向就请道童出镜；做情感口播适合温婉的女性出家人。关键是让目标人群看着顺眼。

不要自己闷头乱猜，动手前先去各平台逛逛，看同类号在用什么样的形象，直接对标。

第二，形象真的要精细吗？说实话，有些粗糙到一眼假的视频，照样有几十万播放，留言区还一片真情实感。我一开始也卡在形象上，用MJ试了三十几个都不满意，直到刷到那些画面拉垮的作品才想明白：完美主义可以保留，但更重要的是先入局。先取得一些正向反馈，之后再逐步调整。按各位做图的能力，成片水平不会比市面上那些差。

然后说视频合成。

文本与形象都备好了，该让人物开口了。

目前可用的工具有D-ID、CT8的CrazyTalk以及HeyGen这几款。我的习惯是用HeyGen，操作非常简单，成片质量也比较靠前，缺点是免费额度用完后要付费。如果不想花钱，可以用CrazyTalk，它是免费的，教程去搜索引擎找一下就有，云天有个项目拆解里也详细讲过。

下面按HeyGen来走一遍。

打开官网，点页面右边的登录按钮，拿邮箱接一下确认码，再想个密码，注册就完成了。

接着创建自己的虚拟形象：在“My Avatar”里上传照片。我建议图片比例用2:3。

把文案粘进去，然后选择声音。声音的筛选顺序是：国家、性别、年龄段、风格，选完还能试听。满意后点“Select”，再点“Submit”，大约一分钟后视频就渲染好了。

补充一句篇幅较长的文本怎么处理。如果让ChatGPT硬改，怕破坏原本容易爆的节奏，我的做法是叠一层自然风光底图，让人物做个渐显渐隐，这样就基本能过机器审核。更详细的方法可以看知乎上的一篇教程。

整套流程跑下来，门槛并不高，适合一个人操作，想放大也适合矩阵化。

再说变现。

我试了好几个平台，体感是：红书App的学员转化最顺畅，抖音及🛰️短视频偏电商，B站吸粉最快但我暂时还没找到变现角度。

带学员方面，红书的咨询人群最精准。具体做法：建一个群聊，名字就叫“零基础短视频交流”，发视频时把群入口挂到作品下方；再安排一个小号进群引流，避免大号出问题。

![](img/cc075c4177daf0a23f9e94f134d92e0d.png)
![](img/a1c3ed2e3475bb9f27bc1543a59a569b.png)

电商方面，根据账号定位卖产品。禅语号卖佛珠、香品、玉石，情感和创业号卖书，诸如此类。目前这块我还没跑通，打算下周开始试。另外我有一个大胆的设想：留言区经常有人把我的虚拟角色当成真孩子，老夸它可爱，那不如直接用这个形象做短视频带货口播，比单纯挂购物车更有引导力。别以为所有人都分得清AI和真人，现实是留言区里确确实实有人信以为真。不要用你自己的认知去推断所有人。

![](img/a7cd5e62a6f06a36f902a656bffa092e.png)
![](img/baf6d7edabe338fa7d9bd577dea907fe.png)

还有一种流量变现方式，来自云天的分享，我还没完全弄明白，大致是挂载某种轻应用去变现。这里技术人多，如果感兴趣也有开发能力，可以一起来搞。

最后说点碎碎念。

我入局之前是先定人：瞄准银发人群，再倒推他们会被什么素材吸引。那段时间天天刷周易、国学、佛道一类的东西。直到某天在🛰️短视频刷到一种对口的东西，突然像是挖到宝。再到其它平台多看了几个，又看到有人已经在红书布局禅语号批量矩阵，而且做了才一个月左右。

![](img/ff28d79be861c935eedf6f281509f162.png)

听说有人靠矩阵一个月吸粉六位数，真有点离谱。其实这套技术五月就有人在社群里分享过，早看到的人早就吃到了红利。

所以，早就是优势。今天先聊到这儿，百钞祝各位早日跑通。下次见。
