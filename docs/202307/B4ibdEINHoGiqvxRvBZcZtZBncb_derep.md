# 230719 | 副业×AI案例 02：ChatGPT批量重写小说开篇，10篇/分钟，人工真的追不上

> 来源：飞书文档（原文链接见评论区）

这段时间我一直在琢磨一件事：把各种副业和GPT放在一起，能不能长出新的作业方式。转了一圈，发现小说推文依然被不少人悄悄捡起来做，连生财也在项目规划里给它留了个位置。能被反复拎出来，这类项目通常门槛不高、又能真实跑出需求。只是系统聊过这个角度的人不多，那就由我先开个场，说说怎么借GPT把这个赛道的产出速度提上去。

![](img/5014938a38b9a33786e4c27042d25047.png)

先交代一下背景。去年我跑过一阵推文，只运营一个账号，拿到过一点小结果，运气占了大半。后来因为杂事停掉了。其实当时最想做的是日程整理、复盘点、自我提升这类账号，结果没试出来，挺遗憾。现在我把重心放在“AI实战”类的事情上，误打误撞倒找到了适合自己的路，也算塞翁失马。这段经历没必要拿出来显摆，毕竟跟生财各位真大佬一比我啥也不算。但至少说明我对推文项目有亲身体感，不是凭空说话。

![](img/8935f5ffaf49d3356e191d940bb432ea.png)

要把这类推文内容做成爆款，关键我只看三样：选文、画面、开篇。

选文没什么技巧，选的文本身能拉到多高，基本决定作品能飞多高。但被验证过的题材天然容易二次爆发，所以选文归选文，构不成你的独家优势。最实用的办法是盯几个选材眼光毒辣的同行账号，反复跟发，发得多了，手感自然就来了。

画面指的是文字以外的一切表现，比如手工类视频、极简排版、AI批量出图，都算。这层东西只负责给内容加分，不是主角。反而要小心：画面做得太出彩，用户留言区全在追问素材，没人聊情节，转化反被带偏。这个环节够用就好，能稳定批量出图/出片就行了，别投入太多精力。

最难也最值钱的是开篇。同一篇文，有的开场一秒被划走，有的开场让人停下，差的就是改写功力。而这份功力天然形成壁垒：你能在三秒内用一句话勾住陌生人，流量就归你。人工改写最大的问题是波动大，灵感一断就拉胯。让GPT接手后，只要方法喂得对，它次次都能按套路稳定输出。

这个项目最省心的地方在于，码字的人早就把重活干完了。我们不需要解决产品问题，要做的只是把适合长阅读平台的内容，批量转换成适合竖屏视频刷着看的版本，而转换的胜负手就是开篇。

![](img/e0ac3bd942991aa0c8d644954c6ed803.png)

# 教GPT改开篇的完整步骤

## 第一步：先让它接总任务

我会先给ChatGPT交代清楚：这是两段式合作。第一段我以“现在开始学习”为口令，把一套改写作品开篇的方法完整教给它；它学完后要复述出自己的理解和心得。第二段我会抛来一篇新作品的样本和具体要求，它要用我教的方法完成改写。如果它听懂了，就用它自己的话把我让它做的事说一遍。

![](img/a7b99e6fb7ef58590000460deecb96ac.png)

## 第二步：喂一套可复制的学习方法

这一步我借用了社群里的部分方法梳理，特别感谢@周梦行 的分享，只是把不适合直接丢给模型的话术重新包装了一遍。

我给它喂了一个示范开篇，再用三个问题带它拆解：

第一，故事里真正吊人的悬念在哪？最表面的冲突是：高考全市第一的女孩，志愿却被亲妈填成了普通本科。这份反差足够醒目。

第二，能让这篇文从同类里跳出来的核心点是什么？这种偷偷替子女改升学志愿的剧情早就被写烂了，继母作梗、妹妹搅局也不新鲜；但“母亲可能是自未来回来的”这个设定很少见，所以必须把悬念重心压在她身上。

第三，怎么改？把“母亲来自未来”这个钩子提到第一句，再用一些带情绪的小词，比如“偏偏”“居然”“硬是”，给句子加劲。

按这个思路改出来，改完后的开篇第一句，会类似“母亲竟然来自未来，而且她来回跑过很多次”这种效果。

![](img/3ebae4df7fcc36ede2dba8d0c691aa4e.png)

## 第三步：丢一篇新开篇，提要求

我会再给它一篇新开篇，并提出三条限制：必须按照前面的流程走；回答里要写清楚它发现的悬念点、核心卖点和最终改法；全文控制在40到60字之间。

# 收尾工作没那么复杂

正文也可以优化，但不是每篇都必须压短。写网文的人天生懂怎么抓读者，只要用户点开，通常会被一路带到底，这就是广告里的滑梯效应。开篇这关过了，后面就稳了。

再用句易之类的工具查一遍敏感词，基本就能发。

# AI自动化带来的变化

小说推文门槛低，所以赛道很快就卷起来。想活得舒服，就得在降本和增效两头下手。

降本方面：选文模板和视频生产流程，社群早就有人分享；最费人的还是改稿。人写一版要半天，GPT几秒钟就能给，差距是碾压式的。

增效方面：好的改写套路并不少，但人脑学一个方法需要悟性、状态，GPT却学完即用，输出又快又稳，最后成品完全不虚人工打磨过的东西。
