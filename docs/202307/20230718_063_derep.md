# 新手也能玩转：用家政店群撬动京东家电代下和除甲醛，一套组合拳打到首个百万



## 零基础如何靠家政店群+京东家电代下+除甲醛组合，拿下人生第一个100万

作者： 三俗 

日期：2023-07-26 

我最早入局的是美团上的家政店群模式，第一年下来净赚了30万。跑着跑着发现一个很有意思的现象，服务客户的同时我的🛰️好友池在源源不断地变大，这就给了我一个思路：家政只是第一次生意，复购之外还能不能做二次收割？

仔细一扒数据会发现，家里刚装修完的客群占比相当高。这类人群的消费能力非常可观，而且需求是连着来的。拿一套100平的房子举例，做家政服务我能拿到大概150元左右的中介抽成，这只是开胃菜。

真正的大头在后端。客户刚入住，家电是必配项。油烟机、冰箱、彩电、空调、热水器……一套全屋下来至少5-8台。我跟京东家电做代下合作，单台平均能抽到200元左右的佣金。关键是价格能做到京东官网的3到8折，客户一下就心动了。一旦第一台家电通过我成交，信任这道坎就过去了，后续他家的整套家电基本都会跟着我买。

等家电装完，聊到新房异味、新家健康，顺势切入除甲醛服务。这一步的利润最厚，一个客户下来净利润轻松在1000到5000元之间。家政带来流量，家电完成信任沉淀，除甲醛实现利润收割，三者一环扣一环，把一个刚需客群的消费链条吃透了。

家政店群是入口，京东家电代下是转化，除甲醛是利润放大器。用这套组合，我从0起步把第一个100万做到了。
