# 如果王慧文更早修成第二套内功，或许结局会不一样
作者：龙哥

创业这条路，绝大多数人把全部精力都押在了同一件事上：如何把事情做大、把钱赚到。没错，这套“赚钱武功”必须刻苦练，投入九成五的时间去磨都不过分。但真正能让一个人在高潮低谷都走得稳的，往往是那另外五成里藏着的东西。

龙哥曾说过，每个人从踏上创业这条路起，就该同时修炼两种武功。第一套，面向市场、面向结果，是养家糊口的硬功夫；第二套，则是面向内心的修为，是让自己在喧嚣里依然充盈、安定的软实力。赚钱的武功决定你能否活下来，充盈内心的武功决定你活得是否通透。

王慧文的故事给无数创业者提了个醒。当第一套武功练到极致却遭遇变故时，若没有第二套武功做底座，溃败来得会格外决绝。焦虑的时代里，能向内求、能让自己保持饱满，本身就是稀缺的能力。
