# 一、知识博主的私域长什么样

## 知识博主的私域定义

大家对私域这个词都不陌生。

我的理解是：长期留存、可反复触达、可多次变现的🛰️生态。做抖音、📕、视频号的博主，真正赚到大钱的，都把核心放在了私域。

私域的好处很直接：

“不用开播”

“能沉淀铁粉”

“节省大量时间成本”

“成交可以自动化”

“高客单的蓄水池”

“维护好就能持续复购”

公域像空气，鱼龙混杂来来去去。私域像氧气，一旦拥有就很难被替代。

1，差距会越拉越大
同行10万粉在公域，私域可能只有2000个学员。
你同样10万粉，私域沉淀了2万人。
你即使停更，基本盘还在；他们一停更，直接散伙。

2，复购价值就是私域价值
我们每两个月上一次新课，就能激活老学员，自动成交200单以上，轻松带来10万+利润。

3，5万好友的威力
我的学员珍爱姐，做洗衣店运营这么细分的赛道，她是我早期教的前三名学员之一，没有什么光环，就是个宝妈。
做抖音一年只做私域，9000粉丝，月利润十几万，反而超过很多百万粉博主。
原因就是用户粘性强，复购率高，还有老带新效应。
细分赛道根本不怕没钱赚，关键看你怎么运营。

## 为什么知识博主必须做私域

公域负责赚快钱，私域负责赚大钱。
公域卖的是信任，私域卖的是利润。两者联动，钱就来了。

举个例子，你的引流课卖399，抖音加📕一个月能卖300多单，私域再卖200单，引流课收入就是20万。
再往上推一个利润课2499，从引流课转化过去，转化率30%-40%，能出37万。
最后再放一个1万的高端1v1服务，成交10单，就是10万。

算总账：
公域月入=300×399=12万
私域=200×399+37万+10万=55万
私域收入是公域的5倍。

# 二、我们私域转化能稳住30%的核心秘密

## 每天稳定加100+粉丝的办法

加粉，说到底就是把人加进来。

第一种是被动引流。通过📕、抖音的粉丝群，引流群、评论区挂钩子，粉丝主动加我。我的🛰️号每天被动加粉100+很正常。
核心靠钩子，比如免费领资料。这是最省力的加粉方式。但一个号一天被动加粉别超过100，不然容易封号。可以多备号，用渠道码区分。

![](img/0b3faf4c2ea5d906d198d55d23d82550.png)

第二种是主动加粉。短视频下面放线索，用户留信息，每月能有几千条线索，都是我们主动去加的。
主动加粉的通过率就看申请话术。一定要完整一致。
比如我的抖音号是宋老师帮你做课，加好友时只写“宋老师”，通过率会很低。
一定要写全：我是宋老师帮你做课，给你发做课宝典。
不要写“宋老师（不听语音）”，这种会让粉丝觉得🛰️里的你和视频里不一样，有距离感。

![](img/d017747d3909b14eff32158e73229a9f.png)

## 加上之后第一句话说什么，决定转化高不高

很多老师都卡在加进来之后不会聊。有的发2-3个资料就没下文，有的直接发自我介绍，有的根本不说话等对方问。
这些做法都会浪费粉丝。

我们有一套【破冰话术模板】，能解决90%的开场问题。

我们的破冰逻辑分三步：

第一步，建立信任。
自我介绍要短，只说核心标签就够了。他们是从不同平台加过来的，人设要稳定。
我是宋老师，全网最大的知识付费做课卖课博主，头部教育公司总监。

第二步，给福利。
他们本来就是冲着资料来的，你一定要给。资料建议干湿结合，把你的产品信息嵌在文件里，文件里也要强化人设背书。
很多同行拿我的宝典去当模板也没关系，模板就是生产力，能用就拿，但请尊重下原创。
礼物收了之后，粉丝会有点愧疚感，后面你问问题回复率会高很多。

第三步，抛一个能互动的问题。
比如：您现在做什么课程？您是直播卖课还是私域卖课？
问题要具体，要能选或者能简单回。

两个小技巧：
1. 用语音说，信任感会更强。
2. 问题要有交流感，不要像机器人，简短自然最好。

## 破冰之后，5分钟内如何推进成交

信任建立后，推进方式有三种：

第一种，提问。
不同产品对应不同需求。对方已经买过几百单做课课程了，你还卖他做课，就不成立。要抛3-4个问题，把痛点和背景摸清楚。

第二种，解答问题。
很多老师一加到🛰️就开始不停解答，甚至打半小时电话。你把问题全解决了，他为什么还要付费？
我早期最大的教训就是，加到高意向客户就打电话，聊了三天人跑了。
记住，不付费学不会，答案不能全给。可以说这个问题课程里有详细拆解，需要咨询可以进课。

第三种，描绘愿景。
卖课的物料一定要齐全：学员案例H5 http://s.xlb-growth.com/0Sfcm、课程详情页、好评截图、试听课。
一对一销售，要么卖愿景，要么卖痛点。让他们看到行业蓝海，看到前辈已经成功了。
销售路径在于不断打磨，多聊多迭代。

# 三、私域神器，助你卖课破百万

## 神器1 标签

这是最容易被忽略的利器。
会用，运营效果翻倍；不会用，私域就是一团乱麻。
我一个5000粉的🛰️号，前几天清理僵尸粉只有30个，全靠标签管理。
一个5000粉的号，我建了20多个标签，发朋友圈就能做精细化运营。
比如开营倒计时，对已购课的客户就屏蔽，避免打扰。买过A课没买B课的，也要屏蔽。日常生活动态则不用屏蔽。
一天发10条朋友圈也能精准触达。

标签怎么分？
先按意向分，我常用abcd：
s-高客单深度服务
a-引流课学员，社群服务
b-高意向但没成交，后续可触达
c-低意向，白嫖为主

再按课程分：第一期学员、第二期学员、私域学员等。
再按渠道分：公域直接成交、📕咨询、朋友转介绍。不同渠道属性不同，聊法也不同。

标签打得越细，用户管理越清晰。无论是你自己管还是团队管，都有明确的归口。
一定要坚持打标签。断断续续做，系统就会乱。开始就要养成习惯，给每个新粉备注。

![](img/2a5931ff958454d1a49b8ca3b56d2ba4.png)

## 神器2 数据表格

![](img/632eacb9366974e5061615a1bda637af.png)

我们工作群每天都会汇报，核心看三件事：当日加粉数、首条回复率、当日成交额。
通过这张表，能看清引流和转化的数据。
要有数据留存意识。每个月给自己定个引流目标，比如月加1000好友，月底复盘是否达标。
没精力的可以让助理来监控。过程可控，月收入就可控。

数据稳定后就要放大体量。比如一转率稳定了，一个月最多卖200单，那就应该上新品，再卖200单。没有稳定就复盘当月动作。

# 四、提升转化率的超实用工具

第一，收款工具。
做私域卖课，必须有一套完整的收款体系。收钱卡壳，成交就失败。
早期我们被风控过，一天卖十几单，几十单群转，风险很高。
现在大单尽量走对公，合规合法，还能开票。
也可以开通🛰️商务号、支付宝企业收款。
或者用小程序交付，比如小鹅通、荔枝微课、千聊，直接链接付费。

第二，看课工具。
我们现在主要用学浪和小鹅通。
学浪适合公域短视频直接买课，前期冲销量，可以挂优惠券。
小鹅通是私域老师的标配，直播卖课交付体感好，就是价格偏高，前期对老师不友好，还收流量费。
前期也可以试试千聊、荔枝微课，或让学员去学浪看课，注意跳转流失问题。

第三，提效工具。
私域量大了服务会吃力。用好工具就能解决。
我们现在用wetool、飞书、石墨、标准化客服回复工具等。工具圈子里很多，可以私下交流。
