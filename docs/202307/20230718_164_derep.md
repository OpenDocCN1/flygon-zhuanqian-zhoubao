# 美团张川：做了 8 年平台，我总结了平台的 5 道坎
作者：龙哥

如果还有人觉得，做平台就是“建个流量池，坐等收钱”，那美团张川这几年的经历，可能会颠覆这种想象。

张川在平台领域摸爬滚打了整整八年，最后给出的总结是：平台真正要跨过的，是五道坎。这五道坎并非单纯靠砸钱、投广告或短期拉新就能迈过去，而是藏在平台运转的底层逻辑中。平台的价值，远远不是一个所谓的“超级入口”就能概括的。

从“流量为王”到“久久为功”，这中间隔着的是对商业本质的深度认知。张川的经验，正是给所有平台创业者提了个醒：别把平台当捷径，真正的路，在于跨过一道道坎。
