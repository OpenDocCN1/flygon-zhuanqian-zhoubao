# 一周从零起号到变现，这份复盘带来了什么启发？

今天来聊一个真实的小项目实操复盘，分享者是“机构总督”。他写这篇总结有两个原因：一是想给刚入门的新手打打气，让大家相信自己完全有能力赚到钱；二是想借复盘的机会，磨炼自己的写作技巧，顺带提升总结能力。

实际成绩相当亮眼：快手号用了40天涨到1.2万粉丝，带货量突破200单；抖音号粉丝也超过了8000，最近刚开通橱窗，已经出了40多单。其中单条视频的表现最突出，播放量冲到113万以上，点赞量也达到了1.3万多。
