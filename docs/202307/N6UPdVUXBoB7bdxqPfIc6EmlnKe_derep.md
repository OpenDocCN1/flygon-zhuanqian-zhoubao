# 用AI撸百家号动态的实操复盘：我是怎么做到月入一千到两千的



最近用AI做👸号，流量意外地不错，日常到账大概在三百到一千五之间，和头部作者比起来差了不少，但坚持几个月下来收益也很可观。

![](img/d264d977393f2b6faac8d4644d07e95b.png)

跟👸号相比，号能不能起来很大程度上靠运气。我手上开了三个号，只有一个算起量。反而是AI批量做百家号的动态，对新手更友好，起步阶段一个月赚到一千到两千，门槛并不高。

今天是7月9号，账面已经到手五百多了，上周单周就接近六百。

![](img/2a14f42ef947290d0ce0f35b9b8bf018.png)

👸号用ChatGPT起号的思路给了我启发，六月份我开始试水百家号。为了省心，我主要发动态。虽然单篇收益不高，违规风险却很小。

我白天还有正职，创作时间有限。上了AI之后，同样的时间产出直接翻了好几倍。

我在这边主要用GPT写社会情感方向的稿子。一个月下来，百家号出了三篇十万加的图文，和十八篇十万加的动态，其中两篇动态更是破了百万。图文的单价明显更好，建议有条件的可以同步做图文。

下面把我的完整流程拆开讲。

# 一、工具配置

## 1.首选GPT
到现在为止，GPT依然是我用的最顺手的模型，尽量用它。

## 2.备选工具
cloud、文心一言、讯飞星火这些也可以轮着用。

# 二、选题与素材的获取方式

刚开始写时最头疼的就是每天写啥。
其实规律很简单，爆款里藏着爆款。先把赛道定下来，我选的是社会情感。

然后我去批量关注这个赛道的账号，大号小号都加。关注名单里有张晓磊、寻情记、不吃珍珠的小肥等。

我主要看他们的阅读量和发布时间。测试期我会把当天的热文和往期的热文都收集起来。

所有收集到的素材我都丢进一个选题库，用印象笔记在管理，就像这样：

![](img/39762946eb6026fe1b99cb19c4e430fa.png)

# 三、具体操作步骤

先多看几篇同一主题的爆文

一篇爆文很容易找到同题材的其他文章，把它们拉出来对比阅读，找出差异点，判断自己如果重写，落点要放在哪里。

## 1.先让AI拆解爆文
把整理好的爆文丢给GPT，让它先做一次拆解分析

![](img/0a93702bdb6286abd7ab5a11430babb0.png)

![](img/5fb6d5dc4c5b0a2531edc9e36b49aeb0.png)

把GPT给出的结构化大纲仔细过一遍，看看哪里可以做出差异化。

## 2.生成新大纲
再下指令，让它结合头条的爆文逻辑，重新拟一个新大纲

![](img/2820adb3982c3e3dbd8729400c427540.png)

这样就能得到一个全新的写作思路。

## 3.反复微调
对结果不满意就继续让它改，满意了就直接进入撰写。

## 4.补强结尾
大纲确定后，我最容易卡壳的就是观点收束。于是再让GPT单独写一个收尾段落。

![](img/ed98861191ca08d43f2f9db26e3eb2d8.png)

做百度动态，核心是数量而不是完美。不要一条动态反复打磨。
