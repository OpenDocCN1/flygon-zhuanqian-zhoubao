# 如何零成本生成会说话的图片短视频，AI数字人
作者：龙哥

最近刷短视频平台，经常能刷到那种老人或小和尚讲人生道理的片子，说实话做的人已经挤破头了。我琢磨了一下，决定换个赛道试试——用美女配情感语录，不管结果如何，先干起来再说。

因为是头一回尝试，不想一开始就砸钱，我折腾出了一套几乎零成本的制作流程。唯一的门槛就是：你得有足够的邮箱和手机号来注册账号。整个方案里，美女图片、情感语录的配音、AI数字人全部都是自动生成的。为了能批量产出视频，每一步我都用批量操作来完成：先把情感语录搜集好存进表格，然后批量生成语音，下载音频和字幕，最后统一合成剪辑，这样下来，每个视频几分钟就能搞定。

## 一、美女图片怎么来

我用的是腾讯智影。注册就送1000金币，每天还能免费生成3张图，生成一张图只要20金币。另外，智影还有一个隐藏功能：可以去掉AI数字人视频上的水印，效果还挺不错。

如果你不知道美女图片该怎么描述，可以直接去智影的AI绘画广场逛一圈，看到满意的关键词就复制下来，稍作修改就能用。等生成到满意的美女图后，还能用图生图功能调整发色、背景这些细节。

## 二、情感语录的语音

语音这块我用的魔音工坊。注册送一天会员，会员每天能生成80次语音，用兑换码SVIP888还能再换一天。我的建议是先把情感语录找好（百度一搜一大把），存到文档里再批量生成，这样最省时间。

配音生成后，记得下载无损wav格式和配套字幕，后面剪视频要用到。

魔音工坊的具体操作：打开官网注册登录（自动送一天会员），点“软件配音”。

![](img/d6dced91176302053f3e5718f0fc85e9.png)
新建项目，取个容易识别的名字。

![](img/28d9512ccdebb24ed15dc006b467d6f5.png)
新建作品。

![](img/a77a6c5fc621b9aa07ba0744515a4106.png)
填入文案，选配音人员。有付费的也有会员免费的，我觉得免费的就够用了。也可以按分类筛选配音员，更快选到合适的。

![](img/35af243897b0929392bfc0b2e97f5679.png)
最后生成配音，下载无损音频和字幕。

![](img/b763c9d9f266f931c04602b6f8bc1158.png)

## 三、AI数字人生成

数字人我选的是D-ID平台。用邮箱注册，每个账号送20学分，差不多能生成2分钟的视频。所以这就需要多准备几个邮箱，批量注册、批量生成。D-ID生成的视频会带水印，用智影就能抹掉，其他去水印工具也行。

具体操作：打开D-ID官网，用邮箱注册（学分用完就换个邮箱，我用的是企业邮箱）。注册后点Create Video进入制作界面。

![](img/0b8b97f13c6138f0d3da3e260337392a.png)
点ADD上传做好的美女图片。

![](img/071f24f67cb6f07c8b0d3e8f2cf97741.png)
点Audio上传情感语录的语音。

![](img/94b8474b3936181e304da5942c74948d.png)
点GENERATE VIDEO生成视频。

![](img/f1815d619b383f00108b93bb3eefcffa.png)
生成后先预览，确认没问题就点DOWNLOAD下载。

![](img/e5fbece0da43a9e285d01b84ba9c30d9.png)

D-ID出的视频带水印，可以用智影去除（每天免费3次，用完可以邀请新用户注册，新号送3天会员，期间每天能免费60次）。打开腾讯智影官网，点“智能抹除”。

![](img/a2e304b31798c991337e0603d00cfc3e.png)
上传带水印的视频。

![](img/a49da3aea4f4cf74a25ceb85fd3756a0.png)
添加水印框，选好水印位置，点确定就能抹掉。

![](img/2e8646ee36ede3b185714057d97c9410.png)

## 四、视频剪辑

视频做好后还要加字幕。我用的是剪映，简单又顺手。

打开剪映，把去完水印的视频导进来。

![](img/de92431ea9edff71c9e905de619c2f94.png)
点“文本-本地字幕-上传”，选魔音工坊下载的字幕文件，拉进剪辑轨道，再调整字体和大小。

![](img/4bce6414c11c1f9fef4cf9f2d468711d.png)
整体预览一遍，没问题就可以导出视频了。

![](img/8378293f0d478bf9f473d743da504b1f.png)
