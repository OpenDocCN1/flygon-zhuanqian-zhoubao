# 手绘短视频引流玩法
作者：龙哥

很多人最近都在问手绘短视频怎么做，刚好我们团队最近也在跑这类内容，实测下来数据挺不错，就抽空整理了一套完整玩法分享出来。这套思路适用于各大平台，也能套用到不同行业做流量获客，感兴趣的话可以直接拿去试。

目前这种纯原创的手绘视频，发到抖音、视频号、快手、📕、B站、西瓜等平台都没问题，热门概率也很可观。跟传统的PPT式内容相比，手绘形式在观感上明显更有优势，视觉冲击力更强，也更容易抓住用户注意力，算是一种比较有新意的引流玩法。

今天我会用创业粉的方向来拆解整个流程。如果你本身就在做创业粉，那这套内容基本可以拿来就用；如果你做的是其他领域，操作逻辑完全一样，只是把里面的内容替换成你自己的行业素材就行。方法本身是固定的，但思维得灵活，举一反三才是关键。另外建议先小范围测试数据，跑通之后再批量上多账号操作，这样爆款的几率会高出不少。
