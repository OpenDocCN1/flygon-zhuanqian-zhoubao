# 当黑狗缠上来时，这份抑郁自救长文或许能帮你撑过去

最近刷到一篇被反复转发的深度整理，标题很直接：万字「抑郁」自救指南，看这一篇就够了。原文收录于 yuque.com/for_lazy/thfiu8/fm89znezlmq2e3i2，作者是龙哥的收藏夹，发布于2023年7月28日。

文章开头引用了丘吉尔那句广为流传的比喻，“抑郁就像一条黑狗，一有机会就咬住我不放”。作者在引用的后半段补了一句自己的解读：哪怕这只黑狗凶猛难驯，也并非只有被拖垮一条路，它会累、会松口，人也可以学会与它并行、共处。

这篇长文的链接是 https://mp.weixin.qq.com/s/LebtpKJ0auS70LmQ_KPm1w 。
