# 一、起号是怎么打的

1、起步先啃资料。我先花了几天时间把航海手册和赚钱群里大佬的精华帖通读一遍，把能看懂的要点和一头雾多的地方都摘抄下来。

2、有点底之后开始逛号选品。刷着刷着看到一家睡衣，款式很可爱。我就去扒了下这个账号的内容风格、单品销量，以及同款在其他平台的售价，发现价差有十几块，利润空间还行。睡衣又不像外出服那么容易产生退货纠纷，我就决定先从这个品类入手。

3、有目标地刷品类。刚开始会陷入选择困难症，觉得这个账号的排版可以学，那个账号的封面可以抄，这个款能跟，那个款也能跟，看得眼花缭乱。后来我告诉自己别挑了，先跑起来再说。于是锁定了几家风格相近、笔记形式简单、销量还不错的账号作为参照。

我没有硬照着“粉丝少销量高发帖少”这种标准死抠对标号，因为实际刷到的号基本都有一定粉丝量。有些数据漂亮的号，素材不好找，我也就没太咬死标准。选品时我优先看能不能找到和对标笔记高度相似的高清图或视频，再看利润和近期动销，两个条件都OK我就定下来。

4、开店后做像素级模仿。按教程开通店铺后，我开始全方位对标。头像、昵称、个性签名、笔记标签，商品标题、主图、辅助图、详情页的排布，甚至是细节图是特写还是半身还是全身，图片顺序都尽量一致。尤其图片质量要高，有质感，宁可少放两张也不能传模糊图。很多人直接把其他平台的详情页搬过来，我在这一步多做了加工。

我还刷到过一个卖小风扇的账号，详情页全是淘宝蓝的科技感海报。作为女生受众，我的感受是：别给我科普工艺技术，我只想看好不好看，效果能不能一眼get到。对直男运营来说，这个点很容易踩坑，可以多观察一下女生平常在看什么内容。

我卖的是可爱风睡衣，账号人设也往可爱亲和上靠。头像用的是一个网红小朋友，签名也是奇奇怪怪的可爱语气，文案、客服聊天口吻都保持统一。像个会聊天的小姐妹，用户的戒备心自然会低很多。

5、文案是怎么批量做的。按精华帖的方法做爆款拼装，先把对标账号的高赞笔记全扒下来整理到飞书表格里当素材库。起初我还在手机发布页直接写，效率极低。后来改成在表格里集中写，写5条再一次性发到手机上。再熟练后就摸清了套路。

整体结构大概是：热门金句式标题 + 材质夸奖 + 图案夸奖 + 穿着场景 + 情感收口，比如“舍不得脱！买！！”，“舍不得脱”几乎是标配，还有“一杯奶茶钱”。

我会先把标题模板比如“这件xxxx我可以夸1000遍！才xx💰”做语序、语气词的各种变形，再批量填充材质、图案的描述词，反复组合，速度就上来了。

标题的杀伤力很大，封面一样，标题好就能多很多曝光。所以我会把自己店铺里表现好的标题回收再改写。同时我会定期以买家身份逛店，文案的迁移不局限于自己卖的品类，只要点赞高、能改写的，我都收集回来。

还有一个细节：6个款式拍摄角度一样，有些反而封面效果更好。我后来就固定用那张转化最好的图做封面。

6、怎么实现首单破冰

我发现一家客单35-40的店铺里，有一款售价十几块的商品销量10w+，我就想低价先拿下第一单，给自己一点信心。

我的考量是：客单低，万一翻车也好维稳；价格低容易出单，出单后账号有权重，后面推高价也更顺；退货成本也低。确实后面也翻车过几次，但当作练习也值了。

我发的第1条笔记是用别的款混剪，花了一个休息日精雕细琢，结果发了两条就停了。后来对标号用4张产品图+文字，我不想被判定搬运又没太多时间，就开始用一键成片。封面沿用对标封面，加个底色和文字。文案照着对标风格写，没想到就起量了。

我觉得能起来是因为家居服用一键成片观感不错，而我的品类是可爱风，我选的模板偏轻快治愈，节奏感好。尺寸不符、滤镜过重、曲风不搭的我都会直接跳过。

一键成片选4-6张图，还能调顺序、拼图重组，产出多样化，重复率很低。要注意自动生成的视频封面长得很像，我单独建了个相册，每发一条就立刻删掉，避免混淆和重复。

整个航海期我只用了3个工具：剪映、龙猫去水印大师、互传app。互传很方便，苹果安卓都能用，电脑网页版也有，传原文件很快。

7、高频客服问题的话术

1）店铺新开，多多短信没处理好，客户气急败坏
话术：宝贝，是这样的，我们产品多渠道在售哈 笑哭.jpg 都是我们家的。📕店铺刚开，物流系统还没完全搭好，所以先用多多第三方打单，很抱歉，后面就不会啦。您确认收货后我们给您补差价哈。不同平台定价不一样，很正常叻。
一般听到退差价，客户火气就下来了。

2）问电话号码、地址、取件码怎么回事
回复：物流系统小故障，程序员正在修，抱歉。您是已签收了吗？收到就好。还没取的我把取件码发您，有问题随时找我。如果客户还纠结别人家有取件码，就说自己是客服岗，具体流程不太清楚就行。

3）面料长度等细节问题，一开始答不上来我就去别的平台伪装买家去问，然后复制粘贴。常见问题我会整理成库。手机商家端可以建话术库，但我用讯飞输入法的常用语更顺手。

# 二、我用过的动作和心法

1、统计高频点赞出单时段，定时发布。我卖家居服，7:00、9:00、21:00、23:00这几个点反馈最好，我就集中在早晚发。

2、看到高手说同款升级也好卖，于是我把短裤款换成长裤款上架，没主动带也偶尔出单。学一个点就能多赚一笔。

3、没实名绑定也能下单。我给自己下单匿名评价，也发动朋友下单，贴个假物流让她确认收货后发我写好的评语帮忙评价。

4、差评处理：先私信协商，同意删评后截图申诉。可以先关注对方账号提高触达率再发私信。私信一次只能发一条，撤回不能重发，要一次性把道歉、原因、方案都说明，态度要软。

![](img/738063fbf82a9959b7f304191b7ea2c5.png)

5、我用主号去刷对标号和笔记，然后用小号去关注，避免被对标号发现。

补充小技巧：
逸淘插件装不上可能是杀毒软件拦截，装好后要拖到扩展里。
实况图笔记现在很火，但只支持iPhone8及以上、iOS11以上，且📕为最新版，安卓不支持。
安卓俯拍角度倾斜会变成横版。
逸淘里能看到售后订单直接找上家退款，但有时候上家已拍单未发货，买家已退款，就要去📕商家后台核对。资金到账一般是买家/系统确认收货+7天无售后，系统确认收货为10天，差不多半个月到账。

# 三、航海踩过的坑

1、起初定价太低，价格还写在标题里。没算运费险，扣完只剩3块利润。上家是pdd本身价格就不高，很难换货。后来只能改价，把标题里的价格改掉，好在影响不大，依旧在出单。

2、短信问题。PDD升级后，即使我用逸淘把客户号码中间4位改成0，地址电话改了很多次，还是会收到短信。一开始我很慌，用了上面那套话术基本都能安抚。有一次客户直接把问题写到评价里，我吓坏了，当时已经出600+单，只能下架链接重新上一个一样的，把所有笔记链接都换掉。销量肯定受了影响，后来逸淘出了付费虚拟号码功能，设置后基本就没了。

这个功能刚出来时我没重视，后来发现之前设置的虚拟号码过期了，变成真实号码了，得重新设置。另外习惯在PDD下单，突然去1688下单会忘记付款，提醒我要警惕惯性思维。

3、低价带高价的思路是对的，店铺起来后客户常问有没有吊带、套装。但我当时太追求精细化，非要找到最显高级的图做像素级模仿，浪费大量时间错过流量。后来我明白，不能一上来就地基精装一步到位，要分主次。

4、盲目批量。上次看奇杰老师日产200条视频教程很心动，准备了一个品类收集素材花了很久，结果发了几条数据很差就放弃了。

5、选品和找对标是核心工作，但号起来后我就慢慢不做了。我当时甚至想“怎么还在刷啊，快去搞号”。实际上能持续出单的产品都是前期选品和对标文案的结果。新手前期哪怕笔记发得慢，也要留时间做调研。学习帖我也是前期执行就很少看了，创新度不足。

# 四、我的个人收获

1、会求助，用好身边资源。刚开店装插件卡了我很久，焦虑得不行。第二次再遇到，找了程序员哥哥几分钟就搞定。省下的时间刷对标写笔记爽多了。

2、面对陌生事，先怕后做。现实困难远没有想象中大，硬着头皮开始就渐入佳境。

比如航海期间手机扬声器坏了，我焦虑两天怕收不到信息导致扣分，结果十分钟就解决，能震动就行。

比如实拍，我一直想着像素不好、背景不好、只有一件被穿过的样品，拖了很久。某天闲聊无聊，顺手把床单铺平把睡衣摆好咔嚓几张，就完成了。确实粗糙，但迈出了第一步，后面再买背景布装饰就行。

写这篇帖子我也拖了很久，觉得很难，现在不也写出来了。

面对挑战时，对脑子里唠叨的小人喊一声“食屎吧你”，直接开干，慢慢就会顺。

3、对自己的每一点进步要认真对待。我翻行动日记才发现，开店传链接、用软件拍单改号、找差评买家、库存是否可见这些琐事都花了不少力。第一次出单时我不敢置信，后来熟练了就觉得理所当然。别忘了最初的付出，要对自己说“谢谢你，超棒的”。

4、对自己诚实。别总说就玩玩无所谓，有关系。怕别人的期待、怕失败的眼光，会让你把事情做成玩票。把态度摆正：我就是要认真做这件事，不怕失败，不在乎别人怎么看。

有天晚上我觉得自己思考太慢，抄了笑来老师一段话：“很多聪明的人以为自己很笨，因为他们能感受到自己想明白一件事要花的力气，而别人看起来灵光一闪。人们看不到脑子里发生的事，所以自信不足的人会误以为自己笨。而别人反应快，看起来很聪明。”于是我告诉自己，思考慢很正常，大多数人都是要花时间的。

我只是行动偏慢，改个东西要费劲，有时会歇菜一两天，但没关系。保持平静，像饿狼盯食物一样盯住目标就行。

5、新手判断不准，多试。有次我同时发多条视频，其中一条我并不看好甚至想弃，结果数据最好。坚持也重要，有条笔记我困了随便发，结果意外爆发。

6、要看标杆的数据。起号前我会统计对标账号累计发帖数、单条数据、目前销量。高手分享时我也会扒他过往经历。这样前期没出单时我就知道是投入不够，不会过度焦虑。

7、高手建议要多号多品，我执行不起来，因为上架、剪辑、写文案都不熟练，需要积累。

8、看帖真的有用，能多赚钱。

9、群里碎片知识不要只转发，要码下来过脑再执行，否则就是无效动作。

10、做事难，是因为过程中会冒出很多之前不知道的问题。表面看是上品发笔记，实际要学插件、拍单软件、处理细节，学习成本很高。

“赚钱是最好的修行”，这句话我现在有点体会了。
