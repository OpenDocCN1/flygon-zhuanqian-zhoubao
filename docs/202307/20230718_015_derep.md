# 没地址也能拿到电商执照？手把手教你线上自助办

> 原文：[`www.yuque.com/for_lazy/thfiu8/au6wcixcgypglml4`](https://www.yuque.com/for_lazy/thfiu8/au6wcixcgypglml4)

最近私信里被问爆的一个问题：做网店却没有门面，怎么申领开店资质？之前不少人花两三百买现成执照，现在批量出事，想清掉都清不掉。为了避免大家踩坑，我把自己摸索出来的零成本线上办照流程整理成笔记，觉得有用就点个赞收藏。

先说坑：网上那些几十上百块包办的执照，注册地往往在偏远小区，看着便宜实则风险很大。后期如果不再运营需要退出，注销费用可能要几千；放任不管则会被列入经营异常，甚至产生税务追缴。

其实完全可以自己在线申请，流程并不复杂，大概几分钟就能走完。

广州的小伙伴可以直接跳到第5步，或微信搜索“广州市一网通企业开办平台”，进入后在底部选择个体类业务。

第一步，打开浏览器搜索“政务服务网”，进入对应省份的站点。

![](img/0083dbe286e9dd128a48e4f17bd20887.png)

第二步，使用个人身份登录。

![](img/624a551af7216f1bbefe76c27a91f43c.png)

![](img/65abfd38f98f2a95d3141e2424e18695.png)

第三步，在站内检索“营业执照”，点进“个体工商户开办登记”。

![](img/c02f68ab9dc5d7a29846e0ca93f1db2a.png)

第四步，选择“网上办理”。

![](img/45b311edc3a66011865e43ad2079e929.png)

第五步，用微信扫码授权。

![](img/828a46c7a6623452fc3ad180ba6f131d.png)

第六步，点击开业登记，选择“网络零售”类目。

![](img/dc2a90a56b7526014261558a3b3050f0.png)![](img/3f471c702952306aaeb3d67ade897722.png)

随后按页面提示填写个人信息即可，操作很直观。

提示：各省平台界面虽有差异，功能逻辑基本一致，按上述思路查找即可。如果对线上操作没把握，也可以到当地市场监管所现场办理，工作人员会现场指导。

提交前请准备好：
* 拟用名称 2-6字，建议备2-3个备选；
* 主营类目，按名称对应的行业确定；
* 网络经营地址证明，见下文各平台出具方式；
* 资金数额；
* 经营范围，可参考同类商家；
* 自然人身份证正反面清晰照，四个边都要拍到，无反光，原图上传，以及手机号、邮箱。

各平台开店证明获取方式：

**拼多多**
1.1 进入商家后台，左侧菜单找到“店铺资料”。

![](img/43971c12c031de2f3ff84127192cfb6f.png)

1.2 进入“主体资料”，点“开具入驻证明”，下载打印后可到税务部门线下办理。

![](img/db2c4d2aaec5092050147ce254ca683e.png)

**淘宝**
2.1 打开淘宝首页，右上角点“联系客服”选择卖家通道。路径也可走：卖家中心-店铺-经营资质。

![](img/4746c72ff4fde93ce05dadea312b5c32.png)

2.2 在服务中心搜索“工商要求淘宝提供店铺证明，该怎么办？”

![](img/37371a4996e215bc446a5158ac6efcd8.png)

2.3 按指引进入链接：[https://openshop.taobao.com/tools/certificate.htm#](https://openshop.taobao.com/tools/certificate.htm) 直接下载。

![](img/18acfc9816d6a2ca10c2d74baa3116c7.png)

**抖音**
目前有声音说抖店不认此种资质，但仍有可操作路径，供参考：
1、进入经营号网页版商家后台申请，系统会自动推送营业执照登记提示。
2、点击下载入驻证明。
3、页面弹出开具须知，点击下载即可。抖音网络经营场所证明获取流程：打开抖音-我的-创作者服务中心-商品橱窗-联系运营提交申请，具体证明需线下对接相关部门开通。

常见问答

01 有哪几种证？怎么判断办哪种？
主要有个体经营执照和公司法人执照。个体适合个人小规模经营，流程简便，税负相对轻；做网店时不需实体门面，只需填写店铺网址即可。公司法人适合合伙或想做大做强的，流程更繁琐，税负更高，但能实现风险隔离，后续账务和行政工作也更多。

02 需要填写实际门面吗？
实体店需要真实场地，需提供租赁合同或产权证明。网络零售类执照不需要，只要提供网店链接即可。

03 自己办要花钱吗？
本人操作免费。线下代办通常报价600-1000元，和网上200元买一张的不是一回事。网上低价买的，短期方便，长期注销困难且风险高，不推荐。自行线上办理并不难，按本文指引即可。

04 多个店铺需要多张证吗？
不需要。申请时可点“新增经营场所”，把多个店铺和平台一并添加。

05 找不到申请入口怎么办？
多数地区已支持网上申办，各地进度不一。若未找到，可致电当地市场监管局确认是否需线下办理。

06 办完是不是马上要记账报税？
对，资质核发后需要进行税务登记并按期申报。若暂未完成税务报道，可先不做账，但存在合规风险。另需注意，每年必须完成工商年报，具体操作后续会更新，欢迎持续关注。
