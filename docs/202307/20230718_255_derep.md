# 你的“坏情绪”，也许正在偷偷帮你
作者：龙哥

你有没有过这样的时刻——

明明已经很努力了，却还是感觉自己什么都做不好。

看到别人轻轻松松就拿到了结果，自己却连第一步都迈不出去，于是忍不住在心里骂自己：“我怎么这么没用？”

可你有没有想过：也许问题不在你“不行”，而是你根本不知道自己手里拿的是什么牌。

我是龙哥，一名全职盖洛普优势教练。过去这些年，我解读过3000多份优势报告，给企业做过20多场工作坊，帮不少创业公司做对了人岗匹配，也陪很多大厂的朋友升职加薪、走出内耗。

我太想跟你推荐盖洛普优势这套工具了——它真的能给你提供一种看待问题的新思路。![](img/fff05865d4e41a966cd4c50981eb5703.png)

最近我在逛赚钱精华帖，看到不少圈友在聊负面情绪、内耗、自我怀疑。这不就是盖洛普优势最擅长的领域吗？

荣格说过一句话：我们懂了很多道理，却依然过不好这一生。原因很简单——我们对自己那藏在水面以下90%的部分，几乎一无所知。而盖洛普优势，恰好可以帮你看见它。![](img/40d9befda99eb0355e6713c1e51bae32.png)

很多人陷入负面情绪，无非两种状态：

一种是我好想像别人那样，可我偏偏做不到；
另一种是我讨厌自己这样，可我又确实就是这样。

要解决这个问题，道理上只有一条路——接纳自己，接受你本来的样子。

但难就难在，我们根本不知道自己是副什么牌。我们只看到别人的牌打出了王炸，却不知道自己为什么摸不到；我们以为跟大佬手里的牌差不多，但死活想不通差在哪儿。

在赚钱这个又卷又优质的圈子里，迷失太正常了。

就像你骑着一匹马走天下，今天听人说往东走最好，明天看圈友说往西走才对，后天又觉得南方艳阳天真美，大后天大佬告诉你北方才是天堂。

一个月之后你发现，自己还在原地。于是你开始骂自己：是我不行，是我太差，不然怎么一分钱都没赚到？

人这个东西，本质上是情绪脑和理智脑的拉扯战——就像大象与骑象人。

情绪脑就是那头大象，负责你的本能反应、不由自主的习惯、你的“自动巡航系统”，说白了就是你的潜意识。

理智脑则是骑象人，负责逻辑、计划、语言、推理——你的显意识。![](img/a317b6c0cd34603fda31e35a23a25493.png)

举一个特别日常的例子：白天累了一天，晚上躺床上反而不想睡，短视频一刷就是大半夜——这就是大象挣脱了缰绳，在没人管的时候尽情撒欢。

了解自己的优势，本质上就是去了解你的那头发脾气的大象。只有看懂了它，你才有机会去干预它、引导它，而不是苦哈哈地靠意志力硬扛。

靠意志力硬改自己是什么结局？改十年也改不动，到老了只能悔恨：要是当年在赚钱再拼一点就好了……

你想想，一个骑象人根本不了解自己的大象，怎么可能到达目的地？只会被大象带着跑，享受短暂的快乐，丢掉真正的目标，然后反过来怨恨自己、否定自己。

这种感觉叫什么？叫“你应该”和“你想要”天天在脑子里打架，越打越累，越打越内耗。

而盖洛普优势的价值，在于它提供了一整套关于34项才干的语言体系。![](img/3cb1907741ee034dfb11e7e554738fcf.png)

它还提供了一个测评工具，帮你搞清楚：

你是哪种人？你的同类在哪里？你天生自带的加成是什么？你跟同类跟别人差在哪儿？

如果你从来没有清晰认识过自己，大概率会像盲人摸象——摸到耳朵觉得是簸箕，摸到尾巴觉得是绳子，摸到大腿觉得是柱子。

你对自己的了解，永远是片面的、临时的、随机的。你从来没有用完整的、全周期的、多维度的视角看过自己。

所以德尔菲神庙的石柱上才刻着“认识你自己”；苏格拉底才整天喊；山本耀司也说——搞清楚你的牌，很难，但太重要了。

通过盖洛普测试，我才第一次如此系统和彻底地看到：哪些事我确实行，哪些事我暂时不行；我是谁，我不是谁。

我不再纠结那些我做不好的，而是专注自己天生有优势的地方——然后把这些天赋打磨成能力，变成市场上可交换的价值，去换我想换的东西。

盖洛普最妙的是，它是一套信度效度都很高的性格“语言”。如果说星座、MBTI、DISC 像 CT，那盖洛普就是核磁共振。

没有牛顿力学这套语言，我们解释不了万有引力，理解不了鸟为什么能飞、苹果为什么往下掉，更别提载人航天了。

缺少盖洛普才干的语言体系，你很难说清楚自己是谁、喜欢什么、适合什么。接纳自己、看见他人、优势互补、无条件的自尊自信自爱，统统无从谈起。

这个过程极其重要——只有当你看到了自己的全貌，你对自我的评价才会客观、稳定。

不会天天自我攻击、自我消耗、自我怀疑，你会清楚地知道：哪些自己擅长，哪些自己不擅长，而那些不擅长的部分，其实也有办法借力。

稳定的自我确信感，会带来稳定持久的行动力。

不了解自己，接纳就无从谈起；不接纳自己，喜欢就无从谈起；不喜欢自己，行动就无从谈起。

所以，如果你正在被负面情绪困扰，不妨从优势的角度看看——你的障碍、你的内耗、你迟迟动不了的问题，背后很可能藏着一个你从没意识到的天赋才干。

喜恶同因，优劣同源。一旦你看到了它，改变就开始了。

比如，你的战略才干没有得到满足，就会一直想看到全局地图，才愿意启动；
搜集才干靠后的人，天然怕复杂信息，但你也许很擅长线下交流、链接牛人；
搜集才干太强，你总想把4000条精华帖全都装进脑袋，结果越囤越焦虑；
学习才干特别猛的人，容易一头扎进知识的海洋，学到头晕眼花；

思维才干靠后，你消化信息的方式可能是跟人聊，而不是自己闷头反刍；
思维才干靠后加搜集才干囤积欲太强，你什么信息都舍不得扔，最后把自己压垮；
搜集和学习才干都很强，就像海绵掉进海里，对知识的渴望超过了你的承受力；

适应才干突出的人，常常在截止日期前才爆发；体谅才干强的人，容易被情绪困住，没法像机器一样说启动就启动。

拖延这件事，不同才干的人原因完全不一样：

适应才干受环境影响很大，旁边人都不动，自己也不想动；学习才干是满足于“知道”，不太愿意“做到”，于是拖着；完美才干是觉得自己的产出还不够好，还想再修一修；体谅才干总是共情别人的情绪，成了大家的树洞，天天承受苦水却不忍拒绝，自己的事一拖再拖；思维才干则是大脑没想明白就绝不行动——“因为我还没理解，所以我不能上手。”

专注才干靠后的人，特别容易被带跑：适应、排难、理念才干突出的人，各有各的理由换目标。

排难和适应才干是“救火队长”，解决眼前问题太有成就感了，所以优先级天天变；
理念才干一个人头脑风暴很爽，学习才干享受过程不在乎结果，积极才干对结果总是乐观，行动才干想都不想就先开始，这四个才干都有三分钟热度的可能。

完美才干强的人，总想找到高手并向他们靠近，但需要掌握链接方法；纪律才干强的人，特别想要一个SOP。

关系建立象限突出的人，很在意别人怎么看待自己；交往才干喜欢深度交流，对陌生社交很头疼。

和谐才干强的人，对大佬又敬又怕，不敢提问，不敢打扰，生怕留个坏印象；
追求才干强的人，非常希望被看见、被认可，但在赚钱这么多高手堆里，又觉得自己实在太渺小。

适应才干很强，意味着你对环境的适应力极强，但自驱力不一定强——遇强则强，遇弱则弱，一个人待着就容易躺平。

审慎才干总是怕有风险，于是很少展露自己；执行力象限关注做事本身，而不关注展示自己。

学习才干三分钟热度，搜集才干囤积欲极强，什么都觉得以后有用——如果你家里人也这样，反而能理解你；如果家里人这些才干都靠后，就很能难懂你。

学习才干愿意为未知付费，积极才干容易太轻信，所以都踩过坑。但踩坑也是一种成长，关键是要建立自己的支持系统，比如找“第三方”帮你评估。

责任才干不会拒绝别人，和谐才干不想冲突，体谅才干太能共情，总是把别人的感受放在自己之前——这三种人最容易情绪超载，更需要了解自己的模式，搭建情绪支持系统。

排难才干总觉得哪里都是问题，看哪儿都像钉子；审慎才干看到的风险最大，迟迟不敢迈第一步；成就才干一旦闲下来就无聊到抑郁；交往才干最怕孤独；体谅才干最怕不被理解；思维才干最缺独处；学习才干最怕没有进步的机会；积极才干需要一团和气的氛围；沟通才干没人聊天就难受；竞争才干一看到别人比自己强就心慌；取悦才干不能认识新朋友就憋得慌；专注才干一被打断就火大；公平才干看到潜规则就想拍桌；审慎才干看事情进展太快也焦虑；自信才干一被人指手画脚就炸毛；完美才干最怕老板总盯着自己的短板；统率才干被叫“压住别发火”的时候格外痛苦。

这里头有个“内耗四件套”：审慎、和谐、体谅、排难。

这些都有可能让你不开心——但重点是，如果你不知道自己为什么不开心，你就什么也改善不了。

审慎才干担心风险，完美才干担心不够好，战略才干担心路径不够优，分析才干担心数据有假。每个人都有自己专属的“滤镜”。

竞争和追求才干，总会拿自己跟别人比，在新的环境里，不自觉用自己的短处跟所有人的长处比，很容易产生“我哪哪都不行”的自卑感。但一旦找到自己能赢的赛道，他们的冲劲和爆发力也是惊人的。

审慎才干总在担心最坏的情况，哪怕身边的人全都赚回票价了，还是不觉得自己能行。

前瞻才干不爱白日做梦；回顾才干只信自己亲身验证过的事——所以他们特别相信“先赚一块钱”的力量。

战略思维象限突出的人是“想多做少”，脑子里爽完了就等于做完了。

思维才干强的人，总觉得必须总结出“干货”才能开口，却完全没有意识到，那些生动的踩坑经历同样珍贵。

分析、思维才干的人，总觉得还不够理解、没法应用，所以永远在成为专家的路上，迟迟不肯发声；

前瞻才干想得太远，提前焦虑，没办法活在当下；

行动才干享受“从不动到动”的过程，但维持一件事情恰恰让他们痛苦。

执行力象限的人对产品的关注远大于对客户的挖掘；纪律才干依赖既定流程，容易路径依赖；专注才干需要具体指令，理解不了战略才干的“最优路径”思维。

执行力象限埋头干活，忘了抬头看路。

责任才干容易把责任边界越扩越大；关系建立象限总觉得所有人的情绪都得自己负责。

排难才干强的人总会觉得：找人问是最麻烦的启动方式，自己动手最快。

完美才干靠前、执行力靠后的人，只爱做自己擅长的事，很烦事务性工作。

成就、战略、分析、审慎、信仰、公平、取悦、统率、交往——这些才干跟“做事有结果”高度相关。

所以，看清自己，才能看清别人，才能以目标为导向，找到能跟你互补的人。

追求才干的人最需要被认可、被看见、被夸奖，无法忍受被无视。但请记得：圈友闪耀是真的，可你也有自己独一无二的发光点。他很好，你也不差，甚至未来你们还能互相成就。

信仰才干强的人，容易把世界看成黑白对立，讨厌跟自己三观不合的人。

很多人看取悦才干都觉得他们厉害，但纯取悦才干也有自己的痛点——他们很难跟人建立深度链接。

情绪能量低的时候，潜意识就像脱缰的野马，意志力全线溃败。这时要做的是让突出才干开心起来——潜意识开心了，人就好了。

焦虑的根本原因是丢了罗盘、丢了节奏、不相信自己有优势。慢慢找到自己的情绪支持系统——当你完全沉浸在自己热爱的事情里，你感受到的是心流，而不是焦虑。

分析才干和审慎才干强的人，总想一眼看到底，但真实的需求都是做出来的。

我遇到过两个来访者，小A和小C，都觉得自己太拖延。但他们的拖法完全不同。

聊到这里，我想起自己第一次被教练时的感觉——当时我本想挑战一下教练，看看这是不是玄学。

结果打脸来得很快：解读的时候我感觉自己被一道雷劈中了。

我从来没想过，过去所有行为的背后，竟然有一条贯穿始终的暗线。那些我一直无法解释的举动，全都被一一串了起来——准得像算命。

但我还是不服，我觉得这就是“巴纳姆效应”——用模棱两可的话让你觉得准，就像“你是个坚强的人，但偶尔也会脆弱”。

这份不服，反而让我开始较真地研究盖洛普的信度、效度、准确度和颗粒度，最后没想到，自己一头扎进去，成了全职的盖洛普优势教练。

最后补充一句：星座、塔罗、MBTI、九型人格、八字、人类图这些工具，其实也都可以作为自我认知的入口。

工具没有高下之分，关键看你怎么用。当然，盖洛普优势的确yyds——用过了核磁共振，还会想回去用听诊器吗？

但了解自己，从来不是终点，前方还有很长的路。

笨功夫还是要花的——只是你终于懂得，怎么聪明地下笨功夫。

盖洛普优势，只是一个帮你看见自己、认识自己、接纳自己、发展自己的工具。它不能保你成功，但它能让你不再跟自己较劲。
