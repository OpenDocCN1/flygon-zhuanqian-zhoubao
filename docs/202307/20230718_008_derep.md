# 【赚钱心态】4 篇
作者：龙哥

你有没有想过，为什么有些人忙忙碌碌却始终攒不下钱，有些人看似轻轻松松却能越赚越多？差别往往不在风口，不在技巧，而在那一层看不见摸不着的心气。

最近我翻到一份关于“赚钱心态”的系列笔记，整整四篇，一口气读完，后劲很大。它没有直接扔给你一堆赚钱套路，而是把压在每个人心上的那些旧枷锁，一件件掰开给你看。原来阻碍我们变有钱的，很多时候不是能力，而是默认运行的那些念头。

其中让我反复琢磨的有几个点：第一，别把“安稳”当成免死金牌。很多人不敢尝试，不是因为没有机会，而是太害怕那一点不确定。可财富向来偏爱敢于接受波动的人。第二，要有“配得上”的底气。面对贵的东西、好的圈子、大的机会，第一反应如果是“我不行”“我还不配”，那机会自然绕着你走。先把心里的天花板抬高，行动才有可能跟上。第三，学会看长不看短。赚钱是一场长跑，一时吃亏、一时没回报，未必是坏事，很多关键拐点恰恰藏在耐心的后面。第四，别让面子在钱包前面带路。太在乎别人怎么看你，就会花力气去表演安逸，而不是专注解决问题。

这份系列里没有鸡汤，只有一遍遍掰开揉碎的复盘。它让我意识到，所谓赚钱，与其说是向外寻找方法，不如说是向内清理淤塞。心态顺了，财路才不会被自己亲手堵住。

如果你也觉得自己不缺努力、只缺转机，不妨也去翻一翻那四篇内容。静下心来对照一下自己的念头，也许答案就在里面。
