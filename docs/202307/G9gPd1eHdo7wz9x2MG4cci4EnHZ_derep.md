# 手绘短视频引流玩法，通用各大平台、适合各行业引流，一条龙全过程分享给你

最近总有人在后台问手绘动画类内容怎么操作，正好我们工作室这段时间也在主推这种形式，跑出来的数据还不错，我就把整套玩法整理成了这篇教程，想做引流的伙伴可以直接照着试。

这类纯原创的动画短片，像抖音、快手、视频号、📕、B站、西瓜视频这些主流平台都能发，反馈也相当可以。用PPT翻页做出来的东西跟它没法比，手绘动画在视觉上要生动很多，也更容易抓住用户注意力，算是当下比较有意思的引流路子。

下面拿创业粉账号来做示范。如果你正好做这个方向，整套流程可以直接搬走；做其他领域也完全一样，无非把素材换一换。方法本身是固定的，人得学会举一反三。另外提醒一句：别一上来就铺量，先小范围试几个号，等效果稳定了再放大，出爆款的概率会更高。

先放几个我们做出来的案例截图：![](img/175c0ba1a8568334cab88d706e139d6f.png)![](img/4d74e1caaafe47711cd93e80b6245248.png)![](img/822d285ea0e295829b03efc62b8ee5c8.png)

每个领域要做的画面不一样。我建议多去找同类账号，不用管对方原来用的什么形式，重点是把高赞作品的文字稿抓出来，再做成自己的手绘内容。平时多存一些这类账号，专挑爆款下手，二次爆的几率才高。

开工前先把工具备好：

小程序类：配音神器Pro（负责文字转语音），轻抖去水印（用来扒文案、去图片/视频水印），带壳截图plus（做手机样图）。
软件类：文本星火（给文案降重），剪映（最终剪辑），万彩手影大师（手绘合成的主力软件，付费使用，个人版一次性买断价299元。前期不用急着买，闲鱼或淘宝上租个周号也就三十来块，先用顺手了再决定要不要入手）。

![](img/31bcf93326a92b17f31e71067e7ce86a.png)

先来扒文案。找个同行的高赞作品，点分享按钮拿到链接。在微信里搜“轻抖去水印”这个小程序，进入后把链接粘贴进去，工具会自动解析出完整文案。全文复制后发到电脑端备用。

![](img/cac1e015d96337523af4593eb1bbe078.png)![](img/e876d1080b0ac740e4c651814851910a.png)

文案拿到手之后，不要直接使用，得先做降重改写。这里有两种方式：

方式一：用文本星火。把原文贴到对话框，在开头加一句要求：“这是抖音上的文案，我想做相似内容，请帮我改写成原创稿，字数控制在800。”字数可按原文调整。生成结果复制进文档，把错别字和不通顺处修一下，再根据内容去配图。

![](img/036b20b99d32d1724e358667d9e57180.png)![](img/e7b0ae9fc87944138300a9dc3e3a976d.png)

方式二：手动改。把扒到的文字重写一遍，调整语序、换掉重复出现的词，核心意思不动就行。改好之后，到各个内容平台找对应的配图；图片带水印的话，同样用轻抖这个工具，它支持多个平台的链接解析，把链接丢进去就能把水印移除。

文案改完后，记得把文本放进轻抖的敏感词检测功能里过一遍。其实“最”“亲”“钱”这类字眼是完全放心的。

![](img/4eb00f768ee67a18080e8596f429190e.png)

接下来做配音。电脑端打开配音神器Pro（先在微信里搜小程序，扫二维码登录电脑版），把定稿文本粘贴进去。音色方面，“云飞”这个声音很适合这类内容，语速设成1.1倍速，点生成语音，下载下来即可。

![](img/cde651ff31ae7407642dff466b12b081.png)![](img/2f54b83a51ad8a1b1cfe51f546ffcff8.png)![](img/2113b6cdec0d32c0e72ed0c741465f3f.png)![](img/724653940fd554283eea1ee36d6e01b2.png)

接着制作手机样图。打开“带壳截图plus”小程序，选好机型，把素材图传进去，生成后选高清保存。所有图都弄好，再通过QQ统一发到电脑。

![](img/ad85dbbbac83f5a60508220bbdbe9b33.png)![](img/e1675956b480597614c97c4597e984ce.png)

最后就是手绘动画的合成了，这里用到万彩手影大师。下载地址 http://www.animiz.cn/hand/ 。这软件不买会员的话，导出时会带上平台水印，建议先在闲鱼、淘宝或拼多多租个天号或周号试用，等完全熟练了再决定是否入手长期版。

![](img/1b61f62513efbab944fe410d97f8eeaf.png)

打开软件后，按这个流程走：

一、新建工程。把图片、音频、文案等所有素材统一放进同一个目录。打开万彩手影大师，点左上角的蓝色“新建项目”，选择横屏、自定义工程，再点完成。

![](img/9e9c5e6e911c623284f4a2f77269d9c6.png)

二、铺背景。在背景轨上插入一张底图，纯色或带风格都可以，然后把这段拖长一点。

![](img/abccd04a4dbbc16fb0e3cbd739744fab.png)![](img/91877144fa6515f66b7f9088d66ab981.png)

三、导入音频并生成字幕。点人物旁边那个小菜单按钮，选“语音识别”，导入配好的音频，等识别完成后把音频轨拖到最左边对齐。

![](img/6a8c4df1c19c5d2d1207874766128efd.png)![](img/8bec490fcfeebaeed34a2d4f426c76a7.png)

接着右键该音频，选择“转化字幕”。再任点一条字幕，把字体、颜色改好，点“同步样式”，所有字幕会自动统一格式。

![](img/9f36a4c3fcc58c469d8d738216b34e56.png)![](img/20c5da49922fe6f89401d98117a8e734.png)

四、加开头文案。点窗口右上角的“文本”入口，输入标题，设置好字号、样式和位置；把这层字复制一份，改成第二段话。

![](img/fc5461160aa978cfc19e72d374427508.png)![](img/c148d300f76ea71f1e6f75c32ce2492d.png)![](img/2ddd6a746a83d83f37fc84d25899b07a.png)

五、对齐画面。把对应的画面素材拖入轨道，位置和大小调好，并让画面内容和音频讲的话匹配。不知道怎么配图时，就回看对标作品用了什么类型的图或视频，到各个平台去找；手绘插画也能直接在网上找，下好后拉进软件。

![](img/980c54f5e53fd2868092da8b2d249d1f.png)

六、页面转场。第一页编辑完了，在动效轨道的末尾位置点击“+”，添加一个清场特效，选个你喜欢的样式，右侧把“清除多行”设为“是”，再调一下大小和位置。

![](img/d9570c17ea5b0173817ac5e223bf168d.png)![](img/8a380697cb777aaa8a607c2ab1e3ef1e.png)

后面的页面都按这个套路来：每一页加文本、找配图、和音频对齐；一页完了就加清场特效，再做下一页。放什么素材取决于文案本身，多练几次手感自然就出来了。

![](img/ea2d856589ad384ee386315ce87ef74f.png)![](img/427bf67c4fc3a7c8891fdb553899b713.png)

全部编辑完成后，点发布，给视频命名，分辨率设1080P、帧率60。如果开通了会员，可取消勾选平台水印，然后指定导出位置。

![](img/3c612c78c7417856a2239937ef14dbff.png)

接下来用剪映收尾。把成品拖进去，画幅改成9:16竖屏，上方黑边处加一个标题，字体别太花哨，用“新青年体”黄色就行，位置定了就不要再动。再从库里挑一首BGM，音量调低一些，适当加几个音效，最后按1080P、60帧导出。发出去之前参考同行用的标签，但标题要自己改一改，不要直接抄。

![](img/f1fb64e4df8fc90083d50738a93896f6.png)![](img/f1b99de962b1c8fc2590974d9b49d308.png)

引流思路因平台而异，拿抖音来说：

第一，埋钩子要有节奏。开始两条作品只做纯输出，不要带任何引导。到第三条再埋引子，片尾补一句“完整资料已发到主页群组，想看的自取，下次见”。建好群后把群的邀请链接固定在评论区；能开蓝V就开，稳妥一些。

第二，私域承接。用户进群以后可以私聊沟通，把关系进一步加深。此时给对方发个人联系方式时注意写法：在“地球号”和号码之间加一个空格，降低被系统识别风险。加上好友后，再引导对方关注公号领取资料包。公号有了粉丝基础，后续还能接广告变现。

整套流程操作起来不难，看完之后抽空跑一遍，有不懂的再交流吧。
