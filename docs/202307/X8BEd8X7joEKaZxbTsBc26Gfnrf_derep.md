# 发售策略怎么打

做了一个多月，产品基本成型后，我开始定发售策略。

没有营销的发售不是好发售。

定价策略：99元/年。人数每增加30人涨价199，直至365封顶。这是我第一个低客单产品，必须打好样。

前期在社群内部消化内测，同时在朋友圈同步进展。每天看朋友圈的人很多，如果一个产品从0到1全程晒出来，会让大家有参与感，见证你的成长，后续成交会更顺。

有营收一定要在群里报喜。能量守恒，自己变优秀，身边人会向你靠拢。去群里报喜等于势能崛起，就像学校里成绩好的同学，大家都想靠近。运气好还能带一波成交。

## 成交话术实战

### 垂类用户

大佬推荐过来加你的，都是精准流量，群里见过你，知道你是谁。成交链路很短。

我用的话术是给选择题，不要给问答题。

先问：是否来入手xxx社群的？

如果对方说是，直接给选项：原价xxx，现在转账199即可，支付宝还是🛰️？

常见两种反馈：买和不买。

买了就说：感谢信任，送你一份见面礼xxx，然后自我介绍，引导看朋友圈。

不买就说：没关系，以后还有交流机会，初次见面送你一份见面礼xxx，跟上自我介绍。

不管成不成，自我介绍要到位，并引导看朋友圈，占据用户心智。给选择题是把主动权拿回来。之前靠谱说过，合格的销售要占据主动，客户问什么答什么那是工具人。

### 非垂类用户

这类加你后80%会先翻朋友圈。先打招呼，等对方回，送个小礼物，再根据反馈发自我介绍。朋友圈保持人设、生活、认知、产品四类内容，每天定时更新。时间久了，感兴趣的人自然会来下单。

## 不回消息的逼单

超过48小时没回的，要制造“将要删除”的触达感。这类用户后续基本没交集。提示不回复将删除，能激活一部分人，再按上面话术分类回复。没回复的直接删掉。

这样我又激活成交了3单。
