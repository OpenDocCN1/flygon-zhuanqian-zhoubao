# YouTube 值得做吗？我的答案很明确

YouTube 这个平台，到底值不值得认真投入？我的答案很明确：值得。

这场讨论，起因是风向标群里的一次闲聊。当时有人抛出 YouTube 这个话题，大家的反馈相当直接，观点也非常鲜明。我把自己整理的详细说明放在了飞书文档里，想深入了解的朋友可以直接查看：[https://rlwxa0zgke.feishu.cn/docx/LjgAddKHUoKrlTxa1Egc62QKnRf?from=from_copylink](https://rlwxa0zgke.feishu.cn/docx/LjgAddKHUoKrlTxa1Egc62QKnRf?from=from_copylink)![](img/c4d7c11d4cdc0419e2bff06ad929dd42.png)

![](img/cade92e57110abcee1828d64fe2ab6e2.png)

评论区同样很有看点。有人催我赶紧回来把坑填完；也有人坦诚地分享了自己的观察：YouTube 对新手而言并不算友好，平台的规则和处罚机制相当严格，一旦账号被判违规，后果可能很严重，甚至连账号内的收益都难以提现。此外，虽然 YouTube 的流量池巨大，但并非人人都能分到一杯羹——如果你的内容不够扎实，系统凭什么给你推荐呢？千粉、4 万小时播放时长，这些硬性指标并不是轻轻松松就能达成的，除非你真的有好内容加一点运气。可即便如此，他也承认一个事实：YouTube 粉丝的价值，是很多其它平台无法比拟的。

也正因如此，我依然认为 YouTube 非常值得投入——粉丝含金量高，意味着长期积累的回报也会更丰厚。还有朋友直接给了三个字母：Yyds。![](img/894d30a529e7c37bcd3392323c99941c.png)
