# 很多人所谓的人脉,其实是个笑话
作者：龙哥

大多数人引以为傲的“人脉”，很多时候只是一场自我感动。

你翻翻自己的🛰️，是不是躺着很多“大牛”？当初加了🛰️，聊过几句，就以为关系到位了。可等到你想请人家帮个小忙，才发现对方既想不起你是谁，也不打算为你费什么劲。

真正的人脉，从来不是这么算的。

第一，认识多少人不是重点，有多少人认识你才是重点。如果你只是对方通讯录里的一个名字，那这段关系连门槛都没迈进去。

第二，多少人认识你也不是重点，重点是在你有难处时，有多少人愿意站出来。记住你不代表在乎你，肯不肯为你出手，才是关系的试金石。

第三，那些比你厉害、能拉你一把的人，不一定会是你的人脉；反倒是那些你能帮得上忙的人，才更容易成为你真正的圈子。人脉的本质，不是索取，而是相互成全。

你可能会问：“那我怎么才能帮到别人呢？”答案很实在——你能帮到什么人，取决于你自己有几斤几两。你的能力、你的价值，决定了你吸引来的关系是什么质量。

我是一枚爱写作的设计师，既没有耀眼的头衔，也没有一长串金光闪闪的朋友圈。聊这个话题，多少有点战战兢兢。有朋友建议我：你既然爱写作，又是设计师，不妨就立一个这样的标签，在设计圈子里专门讲讲写作。这倒是个好方向。

但我始终相信：想清楚了，路就通了。认知上的改变，会推动行动上的改变，行动最终会带来结果。

写这篇文章，也源于一位朋友的反馈：“你写的这些我都亲身经历过，只是没想得这么透。”这让我很受触动。把感悟写下来，既帮读者绕开一些坑，也让我自己把问题看得更清晰。所谓利他，归根结底也是利己。

如果你也曾因为“人脉”二字焦虑过，不妨和我一起换个视角：先别急着认识谁，先想想你能为谁创造价值。等你真的成了那个“有用”的人，人脉反而会主动向你靠拢。
