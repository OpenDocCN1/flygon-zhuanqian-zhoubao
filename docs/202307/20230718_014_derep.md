# 带货短视频全网素材寻找途径，个人&团队全攻略！

做带货短视频，最让人头疼的往往不是拍摄和剪辑，而是素材到底从哪儿挖。尤其是跑矩阵号的朋友，每天都在“扒视频—改视频—上计划”的循环里。素材链路顺不顺，直接决定你能不能持续出单。

我是书豪，坐标杭州，赚钱龙珠圈友，95后，创业已经四年，每年都能稳定做到年入百万。今天这篇内容，我想把自己整理出来的带货短视频素材寻找渠道完整盘一遍。它不单适用于抖音、视频号，同样对📕店铺的同学有参考价值。我自己一边做抖音短视频矩阵，一边打理着30个📕店铺，最大的感受就是：素材渠道越顺，店铺内容供应就越稳定。

而且这方法不分规模大小。你是单枪匹马的自由职业者也好，是养着五六个剪辑师的内容工作室也好，还是几百号人的电商公司也好，核心玩法全都一样。太阳底下无新事，哪有什么独家秘诀，无非是把公开的渠道用得够透。

下面直接上干货。

**第一个渠道：快手**
先拿商品词去搜，比如「吸油贴、艾草贴、草本贴、去湿贴、脂流贴、肚脐贴」这类。用商品词搜回来的素材，往往和产品契合度最高，基本可以拿来就用，少数内容稍微改一改就能投。![](img/d9f912933c81cac53e5ef8920d378ba9.png)
在综合页里，你可以按自然排序、最新发布、播放最多来回切换着刷，把能用的都捞一遍。![](img/b7565cd08240f680e39912072d85d280.png)
直播板块也值得蹲一蹲：找到同类产品在播的账号，去它主页翻历史视频，也能间接扒到不少素材。![](img/b0a0433e3a0eb965e6bdb209c1feed25.png)
另外，用功效词搜索也能打开新思路，比如「减肥、瘦肚子、瘦身、暴汗」。这种方式更容易挖到不一样的内容框架，像之前流行过的故事性片头、3D动画，不少就是从这类词里冒出来的。

**第二个渠道：抖音火山版**
直接搜商品词，现成素材随手就能拿到。![](img/427e94d90a108d44749af4407eae1551.png)
也可以通过搜商品词找到正在播的账号，关注后进主页间接获取视频。![](img/4f9cec1ff37208d20ca24517a3fdb89b.png) 这里有个小技巧：把其他账号全部取关，只留这一个，你就能把它发布过的所有视频完整刷出来。
更省事的做法，是直接把在播号的抖音ID输进火山版，精准定位素材。![](img/e18748eb08c285a2ebbf9633d10a2e83.png)

**第三个渠道：抖音**
在抖音上动手，通常有两条路径。一是直接拿商品词去搜在播号，找到后把账号ID复制下来，切到抖音火山版搜索——这时候默认是按点赞量从高到低排序；然后关注这个号，再回到关注栏里翻，就变成按发布时间先后顺序展示了。
二是顺着同行的账号命名习惯反向找号。很多同行喜欢把「形体管理师」「形体老师」「身材管理」这类词写进昵称。![](img/4888202a0b2345178a522ac35766718a.png)![](img/c452af42f08987699a1950b88de94ba6.png) 按这个思路锁定账号后，操作一模一样：ID复制进火山版，点赞排序，关注看发布。

**第四个渠道：抖音罗盘**
登录入口在 compass.jinritemai.com/login。![](img/066b7617b1abe8faebce65e4d459db0e.png)
进去之后，重点关注三个类目：个护家清、食品饮料、美妆。![](img/e3e9c060e9ae91917f4be9f698f2f164.png)
榜单方面盯住两个就够：直播商品榜、短视频带货榜。![](img/eaff2f70b7eadff2ee9c33f43981f9a5.png)
锁定对标素材后，依然是老流程：用火山版搜抖音ID，再关注后看完整发布列表。
