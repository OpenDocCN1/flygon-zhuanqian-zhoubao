# 从零到百万，一个02年大学生做IP的真心话

各位圈友好，我是龙哥，02年生人，还是一个在读大学生，同时也算是个终身学习者。现在手上带着两个工作室，一个做📕电商直营，另一个专门跑流量。今年21岁，能走到这一步，说实话挺知足，但也知道自己还得继续往前跑。

把时间拉回一年前那场线下见面会，那晚我见到了自己一直很崇拜的拱卒哥和狗哥，更重要的是认识了一位让我特别感恩的姐姐——靠谱姐。当时几位互联网前辈随手给的一些建议，到现在都让我受益匪浅。![](img/0ce3e4cc5ccfc2c0f3c587c01230d19a.png)

如今再回想这个IP是怎么一步步长出来的，心里全是感慨，真没有外人看到的那么轻松。靠着这个IP，我用了不到一年时间赚到人生第一个一百万，也开了第一家公司。下面是今年的收益截图：![](img/df3c67c25ded961b3801a08b44670fc4.png)

再算上手里积攒的私域流量资产和工作室项目资产，百万这个关口已经跨过去了，我现在朝着的方向是八位数。

最近不少熟悉我的朋友知道我已经到长沙了。之前我一直在东北运营直营工作室，敢一个人跑来这座完全陌生的城市重新开始，一方面是因为和兄弟们有过承诺，另一方面也觉得这里是下一段旅程的起点。前段时间在长沙的第一场赚钱见面会上，我还分享了不少自己做📕的心法和实操。

这一路走来，少不了兄弟们的帮衬和贵人们的提携，但最关键的前提，还是自己得够强。只有自己立住了，别人才愿意拉你一把；别人愿意信你、跟你，这本身也是一种实力。

做IP整整一年，我也给自己做了个系统的复盘。初心从来没变过，依然是知行合一。在我看来，IP一定要做自己真正热爱的事，创业本质上是创新，而不是消耗自己——这就是我走出的差异化路子。接下来，就照着自己梳理好的方向一步步走。

我最大的护城河，是和这些人一路建立起来的信任关系，以及对“真诚利他”的坚持。这既是我认可的价值观，也是赚钱的价值观。越分享，越幸运，一起龙哥盟。
