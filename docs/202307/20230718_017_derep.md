# 当二维码也能成为艺术品：从零到专属艺术码的实操全记录

最近AI绘画的进化速度简直让人跟不上脚步，Midjourney和Stable Diffusion两大平台轮流占据热搜，各种玩法层出不穷。几个月前，社区里就已经有朋友分享过用AI做艺术二维码的思路，看得人直呼惊艳，但我当时卡在“电脑跑不动、云端不会配、SD完全没基础”的三重困境里，一直没敢动手。

直到本地大面积停电在家办公受阻，我索性跑去网吧集中突击。靠着圈子里大佬们的经验帖，我在网吧电脑上从零啃下Stable Diffusion的基础用法，跟着一步步实操，反复试错、调参、生成，最后愣是跑出了数百张效果图。


从工具选择到提示词设计，从二维码可读性保留到艺术风格迁移，全程手把手拆解，希望能帮到同样是电脑小白、想入局却不知从何下手的你。
