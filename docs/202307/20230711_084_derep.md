# 智力平平又恰好拥有进取型人格的人容易出成绩

你有没有发现，真正在投资里赚到钱、活下来的，往往不是那些最聪明的人，也不是那些反应最慢的人，而是一种“中不溜”的普通人——智力不算拔尖，但骨子里有一股不服输的进取劲儿。

太聪明的人，学什么都快，但也正因为快，他们很难对一件事保持长情。今天研究个股，明天迷恋K线，后天又跑去追热点、搞价值投资，看起来十八般武艺样样都会，实际没有一样真正精通。最要命的是，他们总在切换方法的过程中，把自己最初看好的、最该拿住的资产给弄丢了。

而太笨的人，又走向另一个极端。别人一点就通的道理，他们非得真金白银亏上几回才长记性。更糟的是，有些人用错误的方式赚了钱，还误以为是自己的本事，最后在错误的路径上越走越远，把底裤都赔进去。

最理想的状态，是那种两头都不沾、却有自知之明的普通人。他们不会飘，也不会自我怀疑，清楚自己的能力边界，然后把简单的事、擅长的事反复做，加上时间的复利，最后往往能收获意想不到的惊喜。

我在二级市场待了8年，见过各路大神来了又走。说实话，最稀缺的本事，不是找机会，而是“什么都不做”。

没错，当行情没有机会时，能管住手、什么都不做，其实是一种顶级的本事。

不信你问问自己：假如这一生只有20次下注的机会，你还会那么轻率地做当下的决定吗？如果每次出手都用这个标准来掂量，那想亏钱都难。

可惜，99%的人做不到。而那些真正能做到、把每次下注都当回事的人，我真的没见过一个亏钱的。

记住：等待，本身就是一种仓位；不动作，才最考验功力。
