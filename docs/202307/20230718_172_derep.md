# 做重要的，核心的事，别把精力浪费在最不重要的事情上
作者：龙哥

你有没有发现，很多人忙忙碌碌，却一直在为最无关紧要的事打转？

听过一个特别妙的比喻，至今印象深刻：假如你想让一只黑猩猩上台发表演讲，绝大多数人的第一反应是什么？大概率是先去搭一个漂亮的演讲台。可这件事的根本目标，从来不在台子本身，而在于如何让猩猩学会开口。

这个例子一下子点醒了我——做事要直击要害，别在细枝末节上耗尽心力。

想做抖音账号，常见操作是先把罗德的麦克风、整套拍摄设备、甚至背景装修全部安排上。但说真的，这些恰恰是最容易搞定的部分。真正该做的，是用手机随便拍一条粗糙的视频，立刻检验你的内容和策划功底。毕竟抖音能不能火，拼的不是画面有多精致，而是内容本身够不够吸引人。

再看减肥，多少人先下单体脂秤，再发个朋友圈立flag，然后入手动感单车，却唯独没有认认真真开始运动。

这就是我们大多数人的真实写照：专挑简单、轻松、能快速获得满足感的事情做，结果离目标越来越远。想要真正见效，就得去啃那块硬骨头，做那件最关键的事。

正如有人所说：财富属于勤奋且忙到点子上的人。把时间花在刀刃上，才是最大的效率。

做核心的事，做重要的事，别让精力白白耗在那些最不重要的地方。
