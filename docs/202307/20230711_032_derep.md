# 没有靠爆单，抖音养生号上个月照样拿下 3.7 万佣金，6 月运营复盘来了
作者：龙哥



大家好，我是龙哥。00后，01 年生人，去年刚本科毕业就辞掉体制内的想象，全职搞网赚，现在常驻广西。

这几个月的主战场是抖音养生赛道。很多人以为养生号必须靠一个爆款起飞才有钱赚，其实不然。6 月份我账号没出过一单真正意义上的爆单，整体走势非常平稳，也很安稳地做到了月佣 3.7 万。

![](img/9b94d4aa6c6f80498a8b8258c806d568.png)

关于这个垂类怎么选品、怎么跟品、怎么把控转化路径，我在上个月的复盘里已经拆解得很细了，有需要的可以回看：[https://wx.zsxq.com/dweb2/index/topic_detail/214482851828451](https://wx.zsxq.com/dweb2/index/topic_detail/214482851828451)

爆单当然香，但爆单本质上还是吃运气。这篇 6 月复盘，我想讲的更实际一点，就是当运气没来的时候，你的账号凭什么还能持续变现、稳定出金。
