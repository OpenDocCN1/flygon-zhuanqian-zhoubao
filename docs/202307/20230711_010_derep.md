# 从 3000 元到 300 万的 10 个赚钱思维

三十岁这天，理白送了自己一份特别的生日礼物：把七年自媒体摸爬滚打攒下的全部心得，浓缩成十个关于财富增长的底层思维。从月薪三千到年入三百万，从普通医学生到自由创业者，这条路他走了整整十年。

他说，三十岁是个微妙的节点——往前看，古训“三十而立”像根无形的鞭子，催着你必须做出点成绩；往后看，少年心气还没散尽，身体却已经开始提醒你，青春不再。但与其被年龄绑架，不如坦然面对自己的野心和焦虑，给自己装上勇气的铠甲，继续进化。

五年前他决定从传统行业跳进互联网，身边不是没有质疑。但他始终相信，人生和赚钱本质上是一回事：哪有百分之百确定的航道？站在原地等待风平浪静的人，永远只是漂泊者；只有扬帆出发，迎着风暴喊出“我就是风暴”，才有可能抵达新大陆。

这十个赚钱思维，正是他从零到一跨越阶层的过程中，反复验证过的底层逻辑。没有高高在上的说教，全是一个普通家庭出身的年轻人，踩过坑、摔过跤、又爬起来之后的真实复盘。他把自己比作聚光灯下有影响力的人，但同时也是那个愿意蹲下来跟你分享细节的同行者。

有人说，平凡人做不成不凡事。理白不信。三十岁，他给家人买了房，每年抽出几十天去旅行，身边有稳定的事业、相爱的伴侣、志同道合的朋友。他说，这些不是运气，而是选择对了赛道，用对了思维。

三十而立，立的不是财富数字，而是那份认清了生活真相，依然敢往前冲的勇气。愿我们都能像他一样，迎着不确定的风浪，做自己的航海家。![](img/fffedf6f586e12ca0ed61bed4bcb521e.png)
