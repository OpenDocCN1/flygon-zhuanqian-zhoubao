# 手指尖的“幸运”：一门藏在开奖背后的隐秘生意

“叮——恭喜你抽中话费券！”“刮开查看你的专属惊喜”“系统检测到你有一份奖品尚未领取”……如果你经常用手机，这样的弹窗信息一定不陌生。它们出现在各式App里、聊天小程序里、甚至扫码支付后的跳转页上。

![](img/f478edc061d20c1efab7a499eb3f1bb2.png)

![](img/9eb847e7c2ddc65a692c61c7da1bf33b.png)

简单来说，这是一种以“开奖”为钩子的广告形态。在广告行业里，凡是能让用户产生实际操作的广告都能挂上“交互”的标签——比如可玩式广告、视频内互动等等。但今天要剖析的，是一种最极简的交互广告：只用一个“抽奖”动作，完成从点击到转化的大部分环节。

它精准地踩中了用户的什么心理？好奇、捡便宜、想要即时反馈。用户以为自己白捡了奖励，拿了红包、白酒、话费，但在这一来一回之间，拉新和创收的目的已经静悄悄地实现。

![](img/986e329daecce0573ea7bb4fc737af9f.png)

## 一切的起点：一个关于积分商城的故事

2014年，一家做软件服务的创业公司，最初的目标是“让天下没有难做的运营”。当时，不少App都在用虚拟分值激励用户活跃，可用户攒了一堆积分，却不知道该去哪里花。这家公司从中捕捉到了机会：做一套积分兑换商城系统，开发者只需接入一个Web页面，就能把商城和自家积分体系连通。

商城里有两类商品：一类需要开发者真金白银采购，比如话费充值；另一类对平台来说零成本，但用户依然觉得有吸引力，比如视频网站体验会员、电商平台新人券。用户既可以用积分换购，也能免费参与开奖碰碰运气。开发者则通过设定每日抽奖次数，来引导用户回流。

这个兑换中心很快在市场上走俏，不少知名应用（例如外卖平台）都是它的客户。

转折来得有些偶然。某天团队里有人提了一个想法：“那些提供新人券的品牌，我们帮它们输送了用户，它们光给券不掏钱，是不是该反过来向我们付费？”

思路一打开，这家公司立刻找上门，向有获客需求的品牌方要新人券资源，并按实际带来的新用户数收费。测试结果出人意料：用户抽中“价值不高”的小面额券后，后续转化表现反而很不错。这个模式随后从积分体系中脱离出来，变成了一项独立的广告变现业务。这家公司就是兑吧——2019年在香港挂牌上市，股票代码01753.HK。顺带说一句，那一年创始人才28岁。

## 链条：“三方”的分钱逻辑

先从用户端看，完整流程是这样的：

![](img/11729ef7f6a6ecc633f90e6b845fdb46.png)

整个链条上，站着三种角色：流量的持有者、预算的持有者，以及撮合两端的服务商。这个中间服务商做的是一门“差价生意”——低价盘入流量，再高价转手给预算方。

那么问题来了：市面上所有广告服务商不都是靠差价吃饭吗？这种“开奖式”广告又特殊在哪？

关键在于位置。多数广告平台卖的是标准货架——开屏页、横幅、插屏、激励视频，位置固定，格式统一。而开奖式广告几乎不介入这些热门展位的争夺，反而专挑那些无人问津的边角位置下手，为开发者创造增值收入。

![](img/4397784b162347bdedd6b98c39c593c4.png)

这些边角位置有多不起眼？小到连一条标准横幅都放不下，常规广告素材根本伸不开腿。但放上一句“你有奖励待解锁”“一条私信等你查看”这类暗示性文案，却能勾住不少人点进来，然后以一个转盘或开奖页面承接。效果反倒出奇地好。那为什么主流广告巨头不来抢这块蛋糕呢？我认为不外乎两个原因：

1. 非标位置的天花板太低，主流平台收入大头始终来自标准广告位，不值得额外投入精力。
2. 这种玩法的运营成本比普通广告平台高出好几个量级，下面会详细解释。

## 两端的合作流程，简单到有些“粗暴”

先看流量持有方（也就是App开发商）：

1. 敲定计费方式——平台方通常希望用CPS（按真实转化结算），部分时候也接受CPC（按点击结算）；
2. 平台运营与开发者一起，挑出产品里适合放活动入口的位置；
3. 开发者拿到一条Web跳转链接，自己控制跳转逻辑；
4. 开通一个管理后台，开始跑量、看数据、等结算。

不难察觉，这种玩法对App本身的侵入程度极低。不用集成SDK，一条链接就能完成变现，测试周期极短，这也是它早期能快速扩张的重要原因。

再看预算方（也就是广告主）：

1. 确定出价方式和价格——大体量平台基本采用智能出价（ocpc），同时敲定考核口径；
2. 提供转化落地页，并预先充值；
3. 平台旗下运营团队负责产出创意素材；
4. 同样开通后台，开始跑。

跟传统广告渠道相比，这里的操作负担几乎可以忽略。做过App流量变现的人都知道，标准广告位只接一家根本喂不饱，接聚合要调Waterfall层级、设Bid Floor底价，繁琐得很。但接这种抽奖式广告，逻辑完全不同——觉得收益不满意，就再找一家同类型服务商分流测试，谁给的结算价高就倾斜更多量，简单直接。

而预算方那边同理：如果你去腾讯广告等DSP平台自己投，不找代投的话，每天得自己做素材、建计划、盯后台数据。但在互动平台上，说好考核目标，后面的事情都有平台方优化师帮你打理。

## 流量的三次转向

### 第一转：从线上App到线下空间

因为这种玩法对入口门槛要求不高，能承载的信息量也极少，所以天然适合从线下场景截流。饮料罐/瓶盖上的活动贴纸、扫码支付后跳出的领奖页面，都是早期被验证过的操作。其中最成功的案例，要属快递面单上的二维码。有几个可以公开的数据：扫进来的用户参与开奖的比例超过90%；平均每一位扫码用户，能为平台创造1元以上的广告收入。

### 第二转：从直谈媒体到大平台开户采买

早期，各家平台靠商务逐个去找媒体或流量方谈合作，在对方产品里放上活动入口。但这种打法想在短时间内起规模非常困难。后来大家发现了一条捷径——直接到快手、百度、爱奇艺这类超级流量平台开户，以广告主身份采买流量。

头部的开奖式广告公司，高峰期每天在快手的买量消耗能达到500万以上。这里有个关键差异：普通广告主在大平台投的是商品或服务广告，而互动平台投出去的是一条“抽奖页面”。素材天然可以做得更具悬念和诱惑力，点击率比寻常广告高出不少，竞价时也更有底气。

说白了，以前是用CPS/CPC的方式从开发者那里进货流量，如今变成用oCPM的方式到大平台买量，底层逻辑没有本质变化。变的是角色定位——平台此时不再像平台，更像广告主的代理，用抽奖给广告主的落地页做了一层前置包装。

这个变化带来三个连锁反应：

1. 流量稳定性打折：直谈媒体一旦谈定往往长期稳固，但大平台投放随时面临竞争，没有一劳永逸的说法。
2. 利润率被摊薄：直谈模式下和媒体八二分成，平台还能留下20%甚至更多的毛利；走大平台投放的路子，跑到最后可能只剩个位数的返点。
3. 资金门槛大幅抬升：利润薄了只能靠走量，大玩家还能撑住，小玩家不得不找第三方垫资公司。但凡上游出现坏账，亏损会相当惨重。

### 第三转：从腰部App到头部大厂的外围生态

早期做商务的人更偏爱找二线App合作——一线大厂不带人玩，二线量级又足够。但随着流量进一步向头部集中，这条路也越来越难走。于是大家转头去寻找头部大厂生态里的“外围”流量，也就是公众号运营方和轻应用开发者。

不过，跟轻应用开发者合作也有不少麻烦：从App跳转Web需要加域名白名单，拉高了平台服务新广告主时的沟通成本；同时Web页内无法完成支付、无法触发下载，等于又排除了一批高客单价的预算方。最终结果就是，这块流量的商业化效率始终不算高。

## 什么样的预算方适合在这里投放？

老实说，开奖式广告对广告主的匹配范围相当狭窄。

两个硬性条件限制了候选者：第一，广告要被包装成奖品形态，自身必须具备足够清晰的利益点；第二，因为Web页面拿不到设备和用户信息，做不了精准个性化推荐，广告必须足够“普适”。

举个例子：装修公司想投互动平台基本等于烧钱——你没有办法把广告精准送到潜在购房者面前，每一笔预算都在打水漂。而电话卡这种品类就“普适”得多，十个用户里有八个觉得自己话费太贵，天然存在需求缺口。

所以你会发现，能长期在这个渠道持续投放的广告主，来来回回就那么几类。有些是跨越周期的常青树，有些则是吃准特定政策窗口期、突然爆发的高价值品类。

**常青品类：**

1. 二类电商，尤其是茅台镇系白酒。名字里蹭上“茅台”二字，转化率就相当惊人。落地页通常是一个货到付款的登记表单，单个线索成本大概在6元，货到付款298元拿10瓶。听说这一单做下来基本不赚钱，利润全靠用户二次复购。能让人反复下单，是不是说明这酒的口味确实有点东西？

2. 彩铃服务。带着传统增值业务的影子，本质上靠连续按月扣话费来赚钱。

3. 保险。

**几个有明确爆量窗口的品类（不只局限在互动渠道，但在该渠道效果格外突出）：**

- 2020年：返利网+支付宝卡包。那会儿支付宝还没有限制卡券发放，这张大额卡券发到用户手里，点击后直接跳进一个电商返利页面。借支付宝的信任背书，电商转化效果出奇地好，背后的买量能力也极强。

- 2021年：水滴保、联通大王卡。水滴保赶在上市节点冲业绩，投放力度异常凶猛，做了“赠险+首月免费”的设计，但多多少少有点引导用户持续扣费的嫌疑。联通大王卡则恰好赶上5G商用初期，运营商都在抢用户，愿意为每个激活用户付出100~120元的成本，而互动平台上一个办卡表单线索只要15~25元。

- 2022年：权益卡和盲盒。说句实话，这两类已经滑向灰色地带。盲盒的底子是博彩擦边球，不便展开。权益卡更是赤裸裸的障眼法——对外宣称29.9元充100元话费，实际上到手是一堆5元抵扣券，一个月还用不掉几张。这东西利润厚到什么程度呢？我听说有代理商在2023年春节期间靠它进账破亿。

## 想入局？先看清楚三道门槛

第一道：技术研发门槛。

一个能正常运转的平台，技术架构上至少包含三块：

1. 内部运营管理系统——维护广告投放参数（地区、操作系统、网络环境、预算限额等），以及广告位的屏蔽规则；
2. 供给方与需求方的门户后台——核心功能就是数据透明化，让预算方看到钱花哪了，让流量方看到钱从哪来；
3. 活动引擎——要能支撑多种不同样式的抽奖玩法，并且允许运营人员灵活配置策略。

其中最关键也最考验功底的是第三块。活动界面看起来谁都能做，但真正的转化率天差地别，极其依赖设计细节和运营的数据分析能力。

第二道：商务资源门槛。

平台本质上是撮合生意，要同时握住预算端和流量端，这就陷入“先有鸡还是先有蛋”的经典困局。具体到这个细分领域，预算方相对集中、触达难度不大，所以核心矛盾永远是流量从哪来。

这是一场滚雪球的游戏：左边滚大预算方，右边滚大流量方，平台的基本盘才会越来越扎实。所以，如果你手里正好有一款流量不错的App，且已经在用这种广告方式变现，完全可以考虑自己把这层差价赚回来；如果你本身就是广告代理，既懂预算方的需求，又能对接一些流量渠道，同样有机会试水。但如果两头的资源都摸不到，那还是别惦记了。

第三道：运营能力门槛。

这个行业本质上由运营驱动，平台的生死几乎押在运营团队的水平上。业务链路里任何一环都值得反复死磕：广告位选在哪，决定量级的上限；入口素材怎么测，决定点击率；抽奖活动怎么设计，决定转化率；选择哪些广告主、什么素材风格，决定利润与成本；给媒体端的分成比例怎么调，决定合作关系能否长久。此外还要保持对行业的敏锐触角，不断追踪新出现的广告类型和新冒头的媒体渠道。

还有一条绕不开的红线：政策合规。做广告，尤其做带有明显诱导色彩的开奖式广告，就要随时准备好面对监管。互联网空间不是法外之地，底线永远不能碰。

## 普通人能做什么？

自己搭平台困难重重，那普通玩家还有位置吗？换个角度：不需要当平台，而是让平台为你服务——你可以站到预算方，也可以站到流量方。

如果你手上有自己的产品，或者能代理某个产品（面向大众用户、可包装出利益点），完全可以去接洽这种广告平台做投放。这个圈子里能接触到货源的朋友应该不少，二类电商的一些爆款单品，确实是在这种渠道上被验证过的。

而且眼下恰好处于互动广告预算相对匮乏、出价竞争不充分的阶段，说不定正是一个低价买入流量的窗口期。

## 说说我们自己

考虑到国内监管政策的不确定性，也为了在更广阔的天地里建立差异化壁垒，我们从2022年开始彻底退出了国内业务，全面转战海外。

目前我们的业务覆盖印度、印尼、菲律宾、美国、巴西、墨西哥、俄罗斯七个市场，投放的广告类别以游戏为主。如果你对海外市场也有兴趣，欢迎评论区留言，说不定能碰撞出一些新的可能。
