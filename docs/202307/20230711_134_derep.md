# 情感类公众号从 0-1 起号的经验分享

文笔不出彩也能把情感号做起来？我从零起步，复盘月入3500的完整心得

我入互联网这行差不多快十年了，做过不少运营岗位，后来一路做到运营总监的位置。但说句实话，我的文字功底一直不怎么样。今年二月份，我抱着“逼自己养成写作习惯”的想法，报名了公众号爆文写作航海。当时真没指望靠这个赚钱，谁知道写着写着，正反馈就来了，还真让我拿到了变现结果。

做号的那段日子，说实话航海期间一直没什么收入，就是闷头日更。真正的起色是在航海结束以后。四月份，公众号给我带来了差不多3500块的收入，其中表现最好的一篇，阅读量冲到了8万左右，那篇的收益大概是800多。现在我跟朋友聊天常开玩笑：连我这种写作水平的人都能拿到结果，你怎么可能不行？![](img/6aab36878966abd1e759ab3c1d95289d.png)

我的公众号是二月份才注册的新号，当时为了开流量主，花了500块买粉丝，然后跟着航海的节奏一天一篇地更新。我相信不少朋友跟我当初一样，从零开始，账号没什么真实积累，靠买来的粉丝硬扛，更新了挺久也没看到什么水花，难免打退堂鼓。但我想说，这时候放弃真的早了点，再撑一撑，光就来了。

今天我就把自己这几个月的摸索整理一遍，给还在起步期的朋友一点参考，帮大家尽快跑通从0到1，拿下第一个100块的收入。因为我目前只做了情感类这个方向，所以下面分享的思路，基本都是围绕情感号来的。

先说冷启动。如果你是有老底子的账号，有自己积攒的真实粉丝，那不用想太复杂，每天跟着节奏更新就行。但如果是跟我一样的新号，靠买粉开通的流量主，那可能要经历一段不太舒服的启动期。这个阶段确实难熬，每天点开后台，看到的都是自己贡献的阅读量，挺打击信心的。我当时在这个阶段试了两个动作，坚持了几天之后，后台数据肉眼可见地好起来了。第一个动作，是找五到十位散布在不同城市的朋友，让他们在微信上搜索并关注我的公众号。第二个动作，是请这些朋友在订阅号消息里点开我的文章来读，在阅读的时候别着急滑，按照平时刷手机的正常速度往下翻，方便的话再顺手点个赞或在看。如果朋友当天没在订阅号里刷到我的推送，也不用刻意提醒，等系统推荐出来了再看就行。我自己后台统计了一下，那段时间每天差不多有十来个朋友帮忙做阅读，坚持了大概一周，我就注意到账号开始进池子了。![](img/01f01edf442b86d5c27b9006b8521e57.png)![](img/6652be768d058cae3237775af28b378d.png)![](img/a2956927e006a8b6364239259ab47b00.png)文章入没入池，其实特别明显——阅读量一下子就是几十倍的增长，前后对比一目了然。![](img/41b4a2c7cd06be55f240b6c067efd72c.png)

再聊内容。想靠账号赚钱，内容质量必须立得住，而内容好不好，选题占了很大的比重。那好选题从哪来？我自己主要用两个办法：一是拆同行的爆款，二是去别处找故事。

先讲拆同行。这一步千万别省，上来谁也不看闷头写，效率其实很低。我当时给自己定了条规矩：至少找十个以上的对标账号，把它们近三个月的文章全部扒下来，按阅读量从高到低排好，整理成一份文档。![](img/a6f42471bed580a9757a1f4e21288bcc.png)对了，扒数据的时候一定要连阅读量一起扒，不然这份数据就是废的。我用的工具是weixinzg这个网站，它是收费的，你们如果有更合适的，欢迎推荐给我。接下来，把那些阅读量过万的文章逐一读完，按照【开头标题】【主人公】【故事主干】【结局】【链接】这五个维度去拆解，把关键信息填进自己的素材库。![](img/302e10fa519918d68e4deec7b7d5e02b.png)这个方法能帮我们快速摸清某一类内容里数据最好的那些作品都是什么样。然后我们把这些故事里的性别、地域、年龄、人物关系、结局做一些替换，比如把男人换女人，城市换农村，母女换父子。经过这样一调整，手里就能攒出一大把可用的新选题。

这里再分享一个小技巧：为了避免洗稿的风险，我一般会把关键要素浓缩成一段话，把故事主线和重点讲清楚，然后交给ChatGPT去扩写，让它帮我生成一篇原创故事。什么叫做“一段话故事”？举个例子：女人离异后带着女儿嫁给了一个男人，但是女儿对继父一直有偏见，很早就离家自己闯荡。后来女人去世了，留了一笔财产，女儿本来想着回家跟继父争这笔钱，结果没想到继父一分都没要，全部给了女儿。原来继父这些年一直都把女儿当亲生的疼，是女儿一直误会了他的用心。就这一段话丢给AI，很快就能产出一篇1200字的文章初稿，你再自己动手修一改，半小时左右就能做出一篇原创来。

关于怎么找对标号，如果你刚开始没什么头绪，可以先去新榜上面逛逛，不过我自己感觉在新榜找号挺耗时间的。还有一个办法，就是在微信的“看一看”里找跟自己风格接近的文章，看完后点个“在看”，系统就会顺着你的口味推荐类似的内容。顺着这些推荐点进公众号，看看近期数据，表现好的就留作对标，数据不行的就直接换掉。![](img/f2e6bbd1cd9ee360a2dc2846d4ba01c0.png)用这种方式圈定对标账号，速度会快不少。

再来说说看故事这条线。除了在公众号里找选题，小红书、知乎、今日头条也都是素材来源地。我最近翻得比较多的是知乎，因为知乎是问答式的，内容很集中，想找素材或选题都特别高效。而且现在知乎上很多回答本身故事性已经很强了，读着读着就能激发灵感。找情感类内容的话，可以试试“匿名”“烦心事”“秘密”这类关键词。比如说有一个问题叫“匿名说说你最近的烦心事”，底下光回答就有三千九百多条，够你慢慢挖好一阵子了。![](img/08f880ee1ccca0f4be54a3791c60e8d2.png)在问题下面挑选题的时候，优先选点赞高的回答，选好之后就按前面说的ChatGPT方法做二创就行。另外，如果你发现某个问题评论区特别热闹，一定要把评论翻一翻。原因有两个：第一，大家的讨论能直接帮你找到文章要立的观点；第二，评论区里常常有人讲自己的真实经历，顺手记下来，这又是新的选题。今日头条也是同样的套路，情感栏目下的评论很多都值得细看，遇到点赞特别高的用户留言，一定要收藏起来，放进选题储备里慢慢用。

说完选题，再讲结构。老师给的框架其实已经很完善了，我们直接照着套就行：一个故事=标题+主人公+故事主干+结局。这里的主干要包含三个东西：梦想或目标、挫折或意外、惊喜或反转。我自己在这个框架基础上做了个细化版本。就拿1200字的文章来说，我通常分成三幕来写。第一幕大概200字，负责开场、铺垫和触发事件。比如开头会写：“我叫丽云，今年34岁，离婚之后就带着女儿去了深圳打工。”这就是个开场。然后做点背景铺垫：我是从农村出来的，爸妈生了三个孩子，我下面有一个妹妹和一个弟弟。农村家庭多少都带点重男轻女的思想，我爸妈尤其严重。自从弟弟出生，我和妹妹就再没享受过轻松的童年，不是在干农活就是在干家务，稍微偷个懒就会挨打。我初中毕业就辍学了，妹妹也一样。在外头打了好几年工，挣的钱都寄给了爸妈，说是要攒着给弟弟盖房娶媳妇。接下来就是触发事件：“我20岁那年，家里给我定了一门亲事。”到这里，第一幕差不多就写满了200字。第二幕是整篇文章的核心，大约800到1000字，主要把触发事件延展开。比如定亲之后发生了什么，路上遇到了什么坎，是遇上了不靠谱的丈夫，还是婆媳间各种矛盾，或者迟迟生不出孩子，又或者后来过上了好日子等等，这些都在第二幕里展开。我自己一般会安排两个到三个转折。可以先是嫁了个不怎样的男人，再一转，婆婆的态度也不好，最后再一转，生了个儿子之后，这家人态度变好了，但自己也看透了这家人的嘴脸，最终选择逆袭。第三幕差不多100字收尾，用来写一点感同身受的话，或者向读者求助，再或者是抛出一个讨论。讨论的话可以先立一个小观点，然后让大家聊聊；也可以直接问一句：“你们觉得我这样做对吗？”给文章留个开放式的结尾。

再说排版，这块其实没什么复杂的，记住三个要点就行。第一，文章里不能通篇没有重点标记，在转折处、关键信息处，该加粗就加粗，甚至加粗换个颜色都可以。第二，文字千万不要一大段一大段地堆在一起，要学会切成小段，让读者看起来舒服，阅读压力小一些。第三，如果是做中老年情感方向的内容，头图尽量不要用外国人，用中国女性面孔的效果会更好。这也是我自己测出来的，算是个人的一点经验，供你参考。

最后，还是忍不住多啰嗦几句心态的事。做公众号这几个月，还挺磨人的，心情曲线基本就是起落落落落起。这种情况真的太正常了，我们唯一能做的就是把内容打磨好，然后坚持更新。这里要特别强调一下，日更是非常关键的，千万别断更。先闷头更它一百篇出来，每更满30篇就停下来做一次复盘，然后接着往下写。相信坚持一段时间之后，结果自然会给你回应。我是Adrian，也祝各位老板在2023年都能找到属于自己的门道，赚得盆满钵满！
