# 单人日收益600＋，游戏掘金，保姆级项目分享

最近不少圈友在问：有没有那种门槛低、当天就能见钱、不需要什么文采和技术的副业？刚好，我把自己团队正在跑的一个“游戏搬砖”玩法整理出来了，全程手把手拆解，已经跑通了一个多月，目前一个人管二十多台手机，每天稳定入账600+。不敢说能让你一夜暴富，但作为保底收入、缓解焦虑，绝对够格。

一、这项目到底在搞什么？

说白了，就是利用番茄小说App里的“游戏中心”，下载几款指定游戏，然后靠脚本自动刷里面的广告，每次广告会给几分到几毛钱的红包。量一多，收入就上来了。

这个路子适合谁？

手头有闲置安卓手机的朋友（苹果不行），现在没有稳定项目、想快速拿到正反馈的人，都可以试。别指望赚大钱，但每天稳定的零花收益，能让你踏实不少。

能做多久？

这类刷广告红包的模式其实在市面上存在好几年了，具体还能活多久没人能打包票，但以我们这一个月跑下来的观察，再撑个一年半载问题不大。玩法可能调整，底层逻辑不会变。

二、开工前，这些准备一个都不能少

1. 手机：一台安卓机就行，4G或6G运存都能跑，配置不挑。鸿蒙/安卓系统都可以，但苹果设备直接pass。

2. 双清：如果是新手机，跳过这步。双清就是关机状态下按住开机键+音量上键七八秒，进入恢复模式，恢复出厂设置三次。华为是这样，其他品牌自己百度一下。记住：双清前先把家里路由器关掉半小时（不是关手机WiFi），等手机清完再开网。双清的作用是防止平台检测到异常后降低红包金额。不是每天清，我们一般两天一次，团队一人管二十多台也忙得过来。

3. 🛰️实名：每台手机要配一个🛰️号，用于提现。建议提前在电脑上备份🛰️数据，后面刷机恢复会省很多事。

4. 下载游戏：双清完一小时后，再下载要跑的游戏。游戏最多装五个，具体从哪找、装哪些，下面细说。

5. 养标签：五个游戏装好后，用🛰️登录，开始“养机”。我们养的是百度广告标签，不养的话，系统给你乱推广告，收益就飘忽不定。操作方法是：脚本挂上，跑120分钟，休息30分钟（把后台清掉），这样算一轮，重复三轮。之后系统就会优先推送你养好的百度系广告。

6. 接码：刷广告时配合接码平台，每个游戏接三五个验证码，目的是让红包金额更稳。我们每天每台设备都接，一天不低于30块。接码后，红包可能从几分涨到几毛，非常关键。

7. 提现：别攒！刷完一个游戏的全部广告（大概一两小时就到上限），再去刷下一个。当天刷完当天提，攒两天很可能会提不出来。

三、实操全流程，照着搬就行

第一步：进番茄，找对开发者

打开番茄小说，点“我的—游戏中心—首页”，每个手机显示的游戏不一样。重点来了：点进游戏后，要看开发者地区，优先找济南和厦门的，杭州等其他地方的不选（具体原因我们也没深究，听话照做）。游戏类型选“消消乐”这类，别选合成类，合成给钱少。选五个，全部🛰️登录一遍。

注意：打开脚本前，确保后台没有游戏在运行，一定要清空后台。脚本120分钟自动停，停后再清一次后台，让手机休息30分钟，继续跑。三轮养完，就可以正式开赚了。

第四步：开刷红包

进入其中一款游戏，先正常玩一局，随便点。结束后会弹出“过关红包”，点领取，此时会看一个广告。广告看完，出现“看广告翻倍”的按钮，接下来就是不断重复：点看广告、等它加钱、自动关闭。我们可以用自动化编辑器设置自动点击“×”和“看广告翻倍”，一直重复，直到这款游戏跑到上限（大概一两个小时）。然后换下一款，继续同样操作。五个游戏都跑完，再统一提现。提现时会弹广告，这个广告不给钱，也可以用编辑器录制提现脚本。

第五步：编辑器用法

自动化编辑器官网/安装包：http://www.autoeditor.cn

第一次使用要先注册账号，这样你录制的指令会存在云端，以后刷机重登还能用。录制方法很简单：打开编辑器，开启录制，手动操作一遍点击“×”、点击“翻倍”的流程，保存后让脚本自动执行。录音可能普通话不标准，但照着做就能通。

第六步：接码平台

重点：看第一个广告时，如果弹出需要手机号，就去接码平台接个码。接码平台压缩包在文章里，操作是：进入“业务中心”，选“百度云”，先在别处打好字再粘贴进去（平台内打不了字），然后获取手机号。有些广告只需手机号，不需要验证码，不收费。一个码才一毛多，却能让你红包稳定在几毛一个。稳定时，一个游戏一小时能跑三四十块；不稳时，跑五六个游戏也才几十块。

四、收益到底多少？

我们目前二十多台手机，一个人负责。单台每天最低30元，状态好跑过七八十。按最低30算，20台就是600+一天。提现额度有三毛、五毛、两块不等，每次提现都要看广告，照样让编辑器自动操作。素材里那个416922红包，换算成钱就是41块，有的游戏直接显示金额，有的用“万”作单位。

五、入局建议与放大思路

先别急着买设备！用自己的手机手动跑一遍，不装脚本不搞编辑器。因为天天用手机，本身就在养机，比如你常看抖音，系统会推抖音广告，你直接刷游戏红包就行。手动跑出几十块，有信心了，再仔细读文章上脚本。很多人看个大概就乱下载，结果被平台检测，红包巨小，纯手动反而容易建立信心。

放大方式：一台手机跑通后，再加设备。一根网线连两台手机，算一组。我们这边拉网69一个月，再加一根10块，相当于89三根网线。如果两台连同一路由，其中一台红包变少需要双清，先别急，等另一台也不行了，两台一起清，这样省事。

其他要点：

- 养机时后台绝不能让游戏在跑，否则钱会很少。
- 每台手机🛰️在电脑备份，刷机后恢复，不用验证。
- 游戏安装包也备份，双清后直接安装，不用再进番茄找。
- 风险：这毕竟薅羊毛，随时可能失效。最大成本就是设备钱和网费，别一下铺太多，量力而行。
