# 第一阶段

# 一、选品思路

很多人觉得，账号上怼满500本，三千本自然就会有单。其实能出单不等于能持续出单。选品才是基础。

## 1.选品方法一：用小号卧底对标同行，这个是我常在用的

准备一个纯买家的小号，千万别用自己的卖家号去逛，别人一眼认出是同行直接拉黑。

1. 连续3-5天，用小号搜一些热词，比如官场小说、考研资料、七年级上册教材、初一教材这类近期走量的品。
2. 看到卖得好的店铺就点关注，把商品的收藏、评论也都互动一下。
3. 这样闲鱼会给你打上买书用户的标签，首页就会一直推相关书。

每天用小号观察闲鱼在推什么、哪些同行在起量。我一般直接搬“想要”数量超过50的品。锁定后马上找货源，拼多多、孔网都可以，尽量避开多某鱼，基本都是带箱子和二维码的翻新货。

4. 找到货源后1:1搬运上架，同行的标题描述怎么写的我基本照抄，适当换个说法即可。有自己的好文案也可以替换上去。

# 第二阶段 精细化运营

# 一、每日必做功课

每天都要复盘上架的品：

1. 零曝光零浏览的，直接下架，不浪费位置。
2. 有曝光有浏览但没人点想要也没成交的，要去优化。图片、标题、描述、价格，哪个环节劝退了用户。
3. 有销量有曝光的单品，每天用闲鱼币去推。我一般直接拉满10000币，大概4块多，能烧两三天。
4. 对于有销量有曝光的30个品，每天开超级擦亮，2块钱一天，出一单就回本了。
5. 小幅降价0.1-0.1之间，让用户手机收到降价提醒，更容易点进来。

# 二、多店铺联动打品

把已经跑起来的店铺里的商品全部复制到正在运营的店铺里，再按每日必做的流程再优化一遍。

1. 看哪个店铺的订单收货城市集中，比如A店广东广州收件最多，那新开的店铺就把发货地设置成广东广州，以此类推。
经常会出现一个客户问完我所有店铺的情况，有人会选价格高的下单，有人会选本地发货的下单。

# 三、服务细节

1. 回复和催付
回复慢等于把客户往别人家推。

已读不回就先发一个“亲”，看是不是秒已读。如果是，说明还在犹豫，可以问“亲是不是有什么顾虑呀”，顺势强调我们的优势。

消息未读就多发几次，别等客户自己走了。

发货要快，优先对接发货快的供货商。

售后问题能协商就协商，几块钱的小问题直接把书送人换个好评。金额大的就适当补点差价，千万别给客户找麻烦的机会。处理好了，回头他还会感谢你。

2.

总结下来就是：先批量测品铺货，再多店铺复用，最后靠日常精细化运营把单吃稳。
