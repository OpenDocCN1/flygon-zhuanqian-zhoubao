# 为什么YouTube非常值得你做？

YouTube到底值不值得投入精力去做？我的答案非常明确：值得，而且越早做越好。

先别急着划走，我想从一组真实数据讲起。你看到的这张截图来自 SocialBlade（网址是 https://socialblade.com/），它本身不是官方产品，但所有数据都通过 YouTube 官方 API 抓取，再用可视化的方式呈现，可信度很高。

![](img/fb3956461ae7cf4e1f76c496cbae4174.png)

可能有些朋友看到英文就不太想看了，没关系，我帮你把背后的数字拆开聊。如果你已经是个成熟的内容玩家，这段可以直接跳过。

先说大盘：YouTube 的全球月活跃用户接近 20 亿。但注意，这 20 亿人绝大多数只是看视频的观众，真正去注册频道、上传内容的，只是其中一小部分。而这一小部分创作者里，又有相当多的人要么没有达到加入 YPP（YouTube 合作伙伴计划）的门槛，要么因为内容不适合投放广告而被拒之门外。

接下来是几个关键的数字：

YouTube 平台上的频道总数约有 5900 万（59.1M）。这个数据其实并不等于创作者人数，因为一个公司可能运营几十个号，一个做矩阵的人可能手握上千个频道。频道背后对应的是谁，平台是保密的，所以 5900 万只是“频道”的体量，不是“人”的体量。

真正能通过 YouTube 赚到钱的有多少？我找到了 YouTube 官方博客的一篇说明，原文在 https://blog.youtube/inside-youtube/responsibility-good-business-and-creator-economy/ ，下面是我的转述。

早在十四年前，YouTube 就推出了 YPP，这是业内第一个开放的变现计划，只要符合条件就能加入并开始赚钱。YouTube 会把收入的一半以上分给创作者。直到今天，YPP 依然是全球创作者经济的重要驱动力。加入 YPP 的创作者可以通过十几种变现方式获利，包括广告分成、商品销售等等。过去三年，YouTube 总共向创作者、艺术家和媒体公司支付了超过 300 亿美元。目前，全球有超过 200 万创作者加入了 YPP，他们中有技术博主，也有演艺明星，很多人在其他平台上可能根本没有机会。

重点信息我帮你划出来了：全球只有 200 多万个账号在通过 YPP 获得分成。换句话说，20 亿观众、5900 万频道，就算去掉水分只算 2000 万真实创作者，真正拿到平台分红的也只有 200 万。这个占比，小得惊人。

那我们做一个粗略的平均运算：300 亿美元除以 200 万创作者，人均分到 15000 美元。

![](img/d90b136a59a044d481aa72a3f8b49b93.png)

按当前汇率折算，也就是差不多 10.8 万人民币左右。

这说明什么？说明这个赛道的天花板极高。确实有人靠 YouTube 全职创作，年入十万、几十万、百万甚至千万，都真实存在。虽然竞争激烈，但它是一个低成本、普通人能参与的赛场，完全有机会实现弯道超车。

顺便分享一点我的亲身体验。我自己在做 YouTube，之前也发过帖子详细记录每天的涨粉和收益变化。说实话，当我看到“200 万”这个数字时，第一反应是意外——这么大一个平台，竟然只有这么少的人真正在赚钱。

还有一个更令人震惊的数据，同样来自 SocialBlade：海外版抖音 TikTok 的创作者账号总数也只有 100 万。TikTok 火不火？当然火。但绝大多数人只是在上面刷娱乐视频、看小姐姐，真正认真创作内容的人少之又少。人群在聚集，内容被大量消费，创作者却稀缺，这本身就是一个巨大的机会信号。

有人可能会说，TikTok 变现还不成熟、渠道有限。但请记住一句话：有人的地方就一定会有钱。当年 Facebook 被质疑不知道怎么赚钱时，扎克伯格面对董事会“卖掉公司”的压力，坚持不卖。他说自己也不知道未来如何盈利，但只要用户保持高速增长，迟早能想出赚钱的办法。马化腾当年也有类似的故事，这也是中国创业者非常熟悉的一段往事。

所以我个人的结论很清晰：YouTube 值得当作长期项目来做。你在国内赚的是人民币，在海外赚的是美金。同样的努力、同样的视频、同样的播放量，放在不同平台上，收入能一样吗？国内很多赛道已经卷到不行，头部几乎拿走了所有利润。如果你也觉得在国内卷不动了，YouTube 确实是一个值得认真考虑的赛道。

有时候，榜样带来的动力是无穷的。我看到某位创作者的收益图时，更加坚定了自己继续做 YouTube 的决心。
