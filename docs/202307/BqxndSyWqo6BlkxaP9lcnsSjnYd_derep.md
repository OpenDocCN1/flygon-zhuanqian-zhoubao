大家好，我是乔帮主。最近几个月我把重心放在AIGC的实操上，把踩过的坑和可复制的打法整理了一下，希望能给还在迷路的朋友一点参考。

AIGC也就是AI Generated Content，生成式AI的简称。简单说就是用AI来产出内容，文生文、文生图、AI主播这些都算。

现在市场热度最高的三个方向，可以看成“AIGC三剑客”：

1. 用ChatGPT来做文本生成；
2. 用Midjourney、Stable Diffusion这类工具来做图像生成；
3. 用AI数字人来做直播和短视频，本质上也是AIGC的一种形态。

# 1、AI不会淘汰你，但会使用AI的一定会淘汰你

AI能火起来，本质是因为它能替代大量重复的体力脑力工作，帮我们把时间空出来去做更有意义的事情。

今年ChatGPT和AI绘画被疯狂传播，很多同行都开始焦虑，担心自己被取代。

把它们当成一类新办公软件就好理解了。和Word、PPT这类工具一样，它们只是被动执行，人必须在前面指挥。它现在还做不到真正自主思考，所以至少在当下，你不会被AI直接干掉，但一定会被会用AI的人干掉。

工具的特点就是放大效率差。当别人用AI把你一天的工作量压缩到一小时，你的旧打法和旧价值还能撑多久？竞争优势很快就会被拉开。

# 2、人工智能和人工智障仅一字之差

我自己做IP、写文案、写朋友圈、写星球文章，内容产出需求很大。但很长一段时间我都把ChatGPT当成高级搜索引擎来用，调用起来很生硬。

再牛的模型，不会用就等于摆设。核心在于调教和喂数据，你要结合自己的业务场景和工具特性，持续训练它。

ChatGPT和AI绘画的用法其实同理，都靠提示词和数据喂养。Midjourney出来好几年一直小众，为什么去年到今年突然爆发？因为ChatGPT把写提示词的门槛拉平了，任何人都能用自然语言生成出专业级的图像指令，AI绘画才跟着起飞。

所以AI绘画用得好不好，背后考验的是你调教ChatGPT的能力。

以用ChatGPT写爆款标题为例，我总结了四个环环相扣的步骤：

1. 找流量池。别直接问“餐饮行业标题怎么写”，要先找方向。比如用巨量算数查行业相关词，取前十热词，再扩展出十个关联词作为后续研究的素材库。
2. 喂养素材。在抖音搜这些关键词，挑出半年内点赞最高的视频，提取标题作为训练语料。用由大到小的逻辑，先让模型理解抖音生态，再理解行业，最后分析热门标题规律，多轮迭代效果更好。
3. 安插钩子。明确人设和目标后，让模型生成标题，再用钩子公式润色，开头才有抓人效果。
4. 组装内容。按标题直接让模型搭建正文，反复优化。明确告知产品卖点、目标人群、语气风格、语言要求，不满意就继续指导修改，直到可用。

很多人在提问时无效且泛化，问的问题百度都能搜到，或是张口就问大而空的问题。这就是在浪费AI和自己的时间。学会精准提问，才能把AI的价值和别人的价值都榨出来。

否则你拿个高级工具当聊天机器人用，最后AI就被你用成了人工智障。

# 3、AIGC真的不是一个好的赚钱项目

我实话实说，AIGC是个好赛道，但它本身不是一个项目。

电商、知识付费IP、线下实体，这些才是项目。技术只是工具，价值在于把它嫁接到具体的产品、流量和转化模式上。设计师用AI绘画出图做产品图、宣传图、Logo图，钱才进来。

整天研究插件、研究参数、研究技术，离赚钱反而更远。技术+业务才闭环。

把AIGC当项目来做，目前能落地的只有知识付费卖课。用工具的好坏存在信息差，可以做培训赚钱。但流量在哪？

最后能把课卖出去的，基本都是已有流量的大V。普通人没有背书、没有影响力、没有成熟课程，靠AIGC割信息差几乎走不通。

另外，企业级落地目前也还很初级。抖音和📕上充斥着贩卖焦虑的内容，教你用ChatGPT写代码、做小程序，基本都停留在个人提效的Demo阶段。

要像Docker技术那样，真正打通研发测试运维形成DevOps体系那样深度嵌入企业流程，ChatGPT还差很远。它现在更像一个覆盖全部门的通用增强工具，企业级应用涉及管理、流程、人员协同，距离成熟落地还有时间。

# 4、数字人直播，是个很好的机会和方向

在三剑客里，数字人直播是相对低调但机会很实在的一环。

最近有朋友咨询我，他公司主播成本高、流动性大、管控难，问能不能用数字人替代。我觉得这是个真实且可规模化的需求，加上元宇宙趋势，数字人将成为常态，就做了系统研究。

目前市面上比较成熟的方案主要有闪剪和硅基。刘润用的就是硅基的真人定制仿真数字人，硅基价格较高，月费约五千。闪剪性价比更友好，一年两千左右就能让一个数字人60分钟视频在直播间循环。

这里有两个常见坑：

1、一些独立部署系统，卖几万一套软件，业务能不能跑通都是未知数，先被割一笔。
2、纯数字人直播极易触发平台风控，落地难，基本是割韭菜玩法。

比较靠谱的实操方案有两种：

1、半无人+数字人直播。提前把数字人、脚本音频、背景素材的视频做好，放到直播间循环播放，同时在画面里投一个真人客服或助理。直播画面因为有真人存在，画面帧会持续变化，不容易被风控。客服平时可以刷手机、看书，有人提问再回复。成本低、可复制、好管理。
2、数字人+实时直播。数字人视频投屏到一个实时拍摄的场景画面里。比如本地门店直播，对着店铺实拍，数字人负责讲解，店主想露脸时随时撤掉数字人上镜，灵活性很高。

赚钱逻辑很清晰：搜一下闪剪、硅基，你会发现做数字人的厂商很多。他们的产品差异、应用场景、落地配置方法，都存在信息差。代理软件、做落地咨询、做场景解决方案，都是可变现的点。

核心能力一是熟悉技术和配置，能结合业务场景落地；二是获取流量。现在普通人只能从公域做起，通过打造数字人方向的IP积累影响力，沉淀私域。

更高级的玩法是，等咨询量起来后，和有成熟直播带货业务的团队深度合作，免费提供数字人技术交付，采取分佣或股权合作模式，把技术变成了获客和变现的杠杆。
