# 十年行业经验，教你如何在二手笔记本行业淘金
作者：龙哥

在二手笔记本这个圈子里摸爬滚打了整整十年，今天想来跟大家聊聊，怎么在这个看似不起眼的领域里找到属于你的机会。

先介绍一下自己：我叫史提芬周，今年春天刚加入赚钱这个大家庭。要说对二手笔记本的熟悉程度，在这个社群里我大概排得上号。

咱们做副业的人，谁不需要一台趁手的笔记本电脑？它不仅是生产力工具，更是日常搞钱的刚需装备。而二手笔记本最大的好处，就是能帮我们省下一大笔预算。说实话，现在这年头，守住钱包就等于赚钱。

这篇文章就是想帮大家解决两个问题：一是教你怎么挑到靠谱的二手笔记本，二是告诉你如何通过回收、销售、租赁这条链条在二手笔记本行业里赚钱。

顺便说一句，这篇文章的诞生还得感谢我闲鱼二手书航海小组的伙伴们，是他们一直催我写点干货。这种互相推着往前走的感觉，真的特别棒。

想要更系统的内容，可以翻翻我的飞书长文，十年经验都在里面了：深耕行业10年，带你了解二手笔记本电脑行业。
