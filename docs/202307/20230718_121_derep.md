# 帮游泳馆卖了 1000 张门票，佣金四位数

游个泳，顺手拍了条视频，结果帮游泳馆卖出了1000张门票，佣金直接四位数入账——这件事就真实发生在我身上。

熟悉我的朋友都清楚，我一路折腾过闲鱼无货源、快手电商、抖音电商，每个方向都拿到了些结果。最近，我又盯上了抖音团购这个本地生活的新机会，没想到第一个月就给了我一个惊喜：每天只花1到2小时，月收入轻松破了5000。

很多人好奇我是怎么从零开始的，其实核心逻辑就藏在“长尾效应”四个字里。一条再普通不过的游泳视频，在抖音团购的流量加持下，居然能持续产生订单，这是传统渠道完全无法想象的。我把整套操作流程、踩过的坑、以及副业思维的心法，都写成了一份保姆级教程，保证新手看完就能直接上手。
