# 3. 底层逻辑是什么

抖音SEO说白了就是抢占搜索结果页。找到用户真的会去搜的词，用这个词去做内容，把排名做进前五，就能吃到持续不断的被动搜索量。这种流量比信息流更精准，因为是带着明确需求来的。账号前期推荐量起不来时，搜索流就是一个非常稳的补位方案。关键词布局越多，稳定流量池越大。📕同理，下面这张就是📕的搜索数据截图。

![](img/421aad2ecb0ed2f8c55f5ea215696dd3.png)

# 4. 可复制的方法论

## 1、选词要双向验证

一个词得同时满足两点：有人搜，且能变现。举个例子，搜【📕教程】的人，本身就带着学习意图，很适合做引流收徒、卖社群、卖课。

## 2、如何找词

最粗暴有效的方法，就是抖音搜索框的下拉推荐。先定行业，再看下拉里哪些词被高频联想。

![](img/533e632f1f74edd773ef1cbc90a36c25.png)

判断词的热度需要工具辅助：

第一个是巨量算数，免费用的，显示的是指数不是真实搜索量。经验上指数除以2大概就是真实量级。

https://trendinsight.oceanengine.com/

![](img/c91cf7faae0d732a4e9ed874e3c17f2a.png)

第二个是巨量广告推广后台，需要有广告账户。数据和百度竞价类似，是真实的日搜索量，我当时是借了朋友的号看的。

https://ad.oceanengine.com/

![](img/9815526ca503ec943f4340628d1162da.png)

## 3、排名规则

账号权重影响很大。蓝V号在同等内容下，搜索排名普遍优于普通号，就像👸号认证号搜索优先一样。

合集比单条视频更有排名优势。普通号想抢一个词，可以一次性发3-5条组成合集去卡位。

![](img/599e0f2185491333dafcde5aa4db37a6.png)

## 4、视频怎么拍

内容必须是原创，不能搬运。可以参考对标号的表达方式，但必须用自己的理解重写。搬运既不利于转化，也容易被判重。

视频的开头和结尾要高频复读关键词，强化关联度。

![](img/09b38310334471106d7bd69c6a3be60c.png)

形式上可以图+配音+PPT混剪，也可以真人出镜口播加案例图。抖音SEO拼的是体量和速度，内容质量达到及格线即可，重点是低成本高频产出，坚持就能吃到红利。

![](img/a6b3614f080b030b3f5c66bb953c148b.png)

## 5、发布细节

合集创建时，合集标题、视频标题、描述、标签里都要布局目标词。以【📕教程】为例，我的实操标题是这样的：

## 7、如何保住排名

随着同关键词内容增多，排名会慢慢下滑。长期保位有两个办法：持续往合集里追加视频，保持更新频率；定期用DOU+再加热巩固。

# 5. 带货的玩法

做带货，选的是商品词。条件是：搜这个商品词时，商品本身排在前四，但商品主页还没有达人视频挂载。也就是说商品有搜索热度，但暂时没人做内容承接，如图。

![](img/d84063b2e7641ba31b64dcb22ce6053e.png)

![](img/ce012ffcf41f714f6d992894166809ab.png)

这时去找商家申请样品，拍一条过关的视频挂车发布，然后把视频链接交给商家，让商家把你的视频设为商品主页的展示视频。

用户搜商品词，先看到商品，再看到你的视频，点进来了解后基本都是走你的挂车成交。只要商品排名稳定，你的视频就能持续吃佣金。

这块逻辑有点绕，多看几遍就明白了。
