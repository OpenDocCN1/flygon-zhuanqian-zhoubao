# 家政做入口，家电代下+除甲醛做变现，小白也能跑通的组合项目
作者：龙哥

来龙哥盟满三年了。三年里，我用“家政店群 + 京东家电代下 + 除甲醛”这套组合打法赚到了七位数。今天第一次在社区发帖，也算把这边的利他精神接棒传下去，希望正在找项目的你，能从这里拿到一些真正有用的东西。

### 一、先讲透京东家电代下

很多人第一次听到“京东令牌价”会懵。其实它很好理解：京东有很多线下加盟专卖店，店主手里有一个官方内部账号，可以用接近批发价的裸价拿货，这个价格就是令牌价。折扣通常在3到8折之间，中高端家电的差价尤其大。通过这个内部账号下单，商品依然从京东直营仓发出，和你在京东APP上自己下单没有任何区别。

![](img/a55554a0bea1a8f53a5760a336b6ea0b.png)

想拿到令牌价，常见的有两个入口：

1. **本地京东专卖店合作**：主动找店家谈，说自己做装修，手里握着一批新房客户，能给他的门店带来销量。谈成之后，订单直接走他的内部账号。缺点也很直接：只能服务本地，跨区域串货不被允许。

2. **找圈内的“CC”**：CC是最早一批做京东代下的人，手里汇集了全国各地的令牌账号资源。从CC这边下单，基本可以全国发货，不用受地域限制。

![](img/be15181d3d201e239d0638ac2e0395b5.png)

### 二、京东令牌之外，低价家电还能从哪来？

令牌价并非万能。很多家电型号根本没有令牌价；令牌价本身也在实时变动，今天有折扣，明天可能就没了；客户下单那会儿，你未必能立刻查到对应低价。所以想靠代下吃饭，还得有备用渠道。

有资金实力的人会利用这个缺口玩“囤货”：发现某款热销家电有令牌价，就批量买下几十台甚至上百台存在仓库。等这款机器没有令牌价了，囤货就变成价格优势——客户有需求时直接从仓库发货，机器一样，售后照旧。

另外，品牌方不会只给京东供货。天猫、苏宁、国美以及线下经销商、代理商都有合作渠道。这些渠道名气可能不如京东大，但内部价有时候比京东令牌还便宜。

![](img/c6b600885e4972fa18e9b0323e10ff51.png)

关于售后，国内大部分家电都是品牌售后。就算订单挂在京东名下，实际处理者还是品牌方；你联系京东客服，客服也是去对接品牌售后，和自己拨品牌400电话没本质区别。

### 三、如何用家政店群精准抓到买家电的人？

要买家电的人，绝大多数是正在装修新房的业主。他们装修完第一步通常是找开荒保洁，之后才轮到买家电。家政店群正好切在这个时间点上。

云家政的玩法是：在美团开一家纯线上家政店，接单后派给群里的保洁阿姨，你从中抽成30%左右。小单赚几十块信息费，大单能赚几百甚至上千。开店成本很低，基本就是一张营业执照加一笔“商户通”费用——一二线城市6800，三线城市3800，四线城市1000。一个城市跑稳后，可以马上复制到其他城市，一个人同时管4个城市也忙得过来。而且商户通可以随时退，风险成本被压到极低，说是“一本万利”真不为过；运气好遇到合适的城市，一个月内就能回本。我自己有个四线城市的店，开店只花了1000元，营业执照没花钱，每个月能做3000元左右。别小看四线城市，竞争小，反而更容易做起来。

![](img/268abd096ef0b6b3ed49dc6d1d071e2b.png)

线上家政店是天然入口。客户来电咨询时，用“加🛰️发具体位置”这个理由，很容易把人也加上。加过来之后，朋友圈营销就是第二层变现；或者搞活动私信客户：只要把我们的家电优惠信息转发到自己的业主群，就可以立减50元。保洁利润确实少了一点，但裂变效率很高——业主群里全是要装修、买家电的精准用户。

![](img/81f89cd824c68c135bb6e43bfe8c6f5b.png)

### 四、除甲醛如何带来多重变现？

除甲醛的利润相当可观，我用的是“直营 + 共享”两条路。

直营最简单：家政客户进来，先送一次免费甲醛检测。很多人愿意占这个便宜，基本不会拒绝。这么做的好处是双重的——既能提高家政成交率，又能顺理成章地介绍除甲醛服务。

共享模式则更省力。做家政店群时，你会认识当地不少保洁阿姨，每个城市的开荒单基本都被她们消化。开荒时她们会和业主待好几个小时，趁这个时间推荐除甲醛，成交率天然就高。那不如把利润让给保洁，把除甲醛仪器和药剂租给她，自己赚设备和药剂的钱。担心设备不够用？完全没必要，网上就有专门出租除甲醛设备的。平时在群里多教保洁怎么操作，她们接单时也会更专业。

这套玩法从获客到成交再到多重变现，每一步都踩在真实需求上。不需要太重的投入，小白也能照着落地。
