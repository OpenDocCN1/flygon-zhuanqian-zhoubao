# 用情绪日志拆解内心的“自动反应”，把不合理的信念慢慢瓦解
作者：龙哥



## 如何通过记录情绪日志，最终战胜不合理的情绪“信念”

作者： 小宝 

日期：2023-07-19 

START 

前言 

情绪本身没有对错，它只是身体发出的信号，学会正确读懂它很重要。

![](img/04f8303ed496d297a7c4e1831ee1018d.png) 

不过，若一种情绪长期占据主导，就要警惕了。像迷茫、焦虑这类感受，短暂出现是正常的提醒，意味着生活出现了波动，需要被关注和处理。比如公司突然裁员，一时找不到合适的工作；又或者长期被工作压得喘不过气，想换环境……

这时，情绪是在提示你：该行动了，该做出调整了。

可一旦你长期沉浸在焦虑、迷茫、痛苦、不开心、压抑里，就危险了。放任不管，生活只会越走越窄。

ONE 

先做情绪日记

今天要分享一个非常实用的自助工具：坚持写情绪日记，帮你慢慢走出负面情绪的漩涡。

第一步是觉察。把当下的情绪状态用文字记录下来，再抽离出来像看别人的故事一样审视。

可以按下面这个框架来写：

1. 情绪：刚才我经历了什么情绪？用一句话描述它。
2. 程度：这种情绪的强度我给几分？1到10分。
3. 情景：我是在什么情境下感受到它的？
4. 想法：这个情境触发了我哪些负面念头？
5. 生理：情绪上来时，身体有什么反应？
6. 行为：我当时做了什么？或者想做什么？

举例：

小王坐地铁时被后面的人撞了一下，早餐撒了一地。虽然工作人员很快清理了，但他整天都闷闷不乐，工作状态也很差。于是下班后，他打开电脑把这一天的情绪写了下来。

![](img/e331fbd2846d473dd6d8c4174e7ec0fc.png) 

写日记的意义在于，用客观的记录来锚定事实，再用理性的视角去审视内心，弄清楚在特定情境下，为什么会出现这些想法和情绪，从更高的维度去觉察自己。

这种练习需要持续进行，比如坚持一个月，每天记录，定期回看复盘。

TWO 

理性拆解消解情绪

记录完情绪后，下一步就是分析它。可以用下面这四个问题来对照：

1. 支持：有什么证据在支持我这个负面想法？
2. 反对：有什么证据在反对它？
3. 反思：如果我的朋友遇到同样情况，我会怎么劝他？
4. 再定义：经过反思，现在回头看，当时的严重程度还打几分？1到10分。

沿用刚才的案例：

![](img/7fc150b2811ec44130881239bf60eeb6.png) 

这就是一个自我消解、自我分析的过程。把场景还原出来，用理性的目光逐项审视，再给出新的解读。这次，小王的愤怒值就从8分降到了5分。

养成习惯后你会发现，很多让你郁闷、不爽、暴躁、愤怒的情境，其实根源都在于你当时的心态和解读方式。

现实往往没有你想象的那么糟糕，大多数时候都是自己在“加戏”。

这是一个不断【训练】的过程。

用“理性”替代“感性”，借助表格的梳理，一次次看清事实。用旁观者的角度审视每一个发生在自己身上的细节。

经过反复训练，再遇到熟悉的触发情境时，你就不会再被情绪脑牵着走，而是能迅速切换到理性视角，控制当下的反应。

THREE 

定期归纳找根源

当日记积累到一定量时，可以把它们打印出来，找共性、提炼规律，顺藤摸瓜找到底层根源。

举例：

小王定期复盘后发现，每当遇到有挑战的工作任务时，他都会感到巨大压力，因而错过了好几次升职加薪的机会。

再往深里挖，他发现自己面对挑战时，下意识就会逃避。背后是因为他害怕失败，潜意识里觉得失败了就等于没用。

为什么会有这种模式？在持续记录和审视下，他终于找到了源头。小时候做有难度的作业做不好，妈妈就会责骂他笨，甚至不让他吃饭。

因此，每次遇到难题，小王就会用各种借口躲过去，以避免责罚。这个模式在成长中被不断强化，形成了[不合理的信念]，导致一有挑战，第一反应就是逃。

这一步很难，需要不断与自己对话，持续审视，直到直面那个根源，才能真正战胜它。

FOUR 

主动去挑战它

找到根源后，就要制定行动计划，慢慢改写这套固化的思维模式。

这很难，因为它已经伴随你多年，不是短期能扭转的。要有耐心，像记录情绪一样，给自己时间，逐步攻克。

![](img/ccd9be0f41350f469715806d7e8fcd07.png) 

举例 

现状：遇到新的工作挑战，我就会选择放弃。 
程度：放弃值 9 分。 
行动：下次再出现类似情境时，我尝试对老板说：好的，我试试看。 
目标：通过实际行动打破逃避的限制性信念，还原事情真实难易程度。 
结果：过程中我遇到了不少难题，也多次想放弃，但我坚持下来了。虽然结果不完美，却也没有想象中那么糟。老板还夸我项目管理有天赋，并给了我新的机会。也没有出现我担心的会被批评打击的情况。 
去执行后的程度：放弃值降到5分了，感觉松了一口气

这类行动计划需要反复练习，不要指望一次见效。给你自己一些时间，通过一次次的练习，你会慢慢摆脱旧的思维模式。

开始真正掌控大脑，面对问题时先理性分析，而不是像过去那样，还没思考完，习惯性反应就已经替你做了决定。
