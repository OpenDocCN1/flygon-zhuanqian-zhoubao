# 【决定📕流量好坏的因素】

今天想跟大家聊一个很多📕创作者都特别关心的问题：到底什么在左右笔记的流量？

先做个自我介绍吧。我是艾小飞，一个从农村走出来的95后，身上还背着债，创业折腾了好几次，被人叫“打不死的小强”。也不夸张，反正就是越挫越勇那种。

这篇不聊操作细节，也不讲一堆流程，只想分享一个思路层面的东西。

先别急，直接看一组图。同样是沉浸式开榴莲，光看封面，你更愿意给哪一个点赞？

![](img/b349552381fc7b7c07bb67b28a983fb2.png)

是不是第一个更有意思？

那它们的实际数据差距有多大呢？

![](img/107b4e3a9a9f44a8d16f875c1333a75f.png)

为什么差这么多？

仔细想想：一只猫在开榴莲，这画面可不是天天都能见到的。但如果换成一个人去开，是不是就觉得稀松平常了？这背后其实就是“反常识”的力量。

透过这个对比，我想让你明白一件事——决定流量好坏的底层逻辑，说到底是内容的品质。

那好内容又是怎么养出来的？

在我看来，一篇内容要想打动人心，至少离不开三样东西：人设、情感和温度。

再来看一个例子。同样是项链，你更心动哪一个？

![](img/0bcf22375b61f5dd48150512be7411a1.png)

第一张图，是自然地带出产品的使用感受和想法，就像朋友聊天一样。第二张图，直接甩了张价目表，什么也不多说，整篇笔记读下来干巴巴的，像说明书。

假如你正打算买项链，你会点进哪一篇？

差距就是这么来的。

做📕也是一样的道理。想获得更多流量，就得在内容里注入人设。

人设是什么？说白了，就是让读者感觉对面站着一个活生生、有情绪、有性格的人，在跟你面对面唠嗑。

人设看不见摸不着，但它像人的气质一样，隔着屏幕都能感觉到。

好多新人刚发笔记的时候，内容都像机器人写的，又硬又冷，没有情感也没有温度。可用户偏偏就喜欢有灵魂的东西。

如果你要在📕卖货出单，就不能只顾着说产品卖点，还得加入自己的真实感受和吐槽。而这些感受和吐槽，恰恰构成了你的独特人设。

既然知道了有人设的内容能直接决定流量走向，那具体该怎么做呢？

账号定位和选题方向这里咱不展开，今天重点讲两个直接影响流量的核心元素——封面和标题。这两样搞定了，流量基本不会太差。

先说封面。

同样都是丝袜，下面这两张，你认为哪一张更能让你停下来看一眼？

![](img/79ba25a905b85fa3969c5b494d138e54.png)

同样都是卖搓澡神器的，你会点哪个？

![](img/13edfbeba78309b0c65522d920b01728.png)

再看看它们各自的数据：

![](img/6d4b8fcf4f9adac8ef2f96981d97a75f.png)

差别怎么这么大？

你是不是也发现了，这两张图的封面都有个共通点：画面里传达出来的场景，生活中极难碰到。谁家狗狗会穿丝袜逛大街？你洗个澡，哪来那么多泥垢能搓下来？

所以这组对比想告诉你的是：封面只要比同行更反常一点点，你就有可能多接住一大波流量。

再说标题。

直接上图。同样卖内衣，你觉得哪个标题更让人想点进去？

![](img/b65d3bdaa0dda1342b5f65fa34d8c4d2.png)

虽然我是男生，但如果站在用户视角，第一个标题明显更能勾起我的下单欲望。

你看第一个标题，它把人群的需求、痛点和价格都清清楚楚点出来了；而第二个标题，只说了一个“便宜”，并没有戳中用户真正在意的点。

所以起标题的时候，不妨多去提炼用户的需求、痛点和他们关心的价格。

要是价格本身不占优势呢？那就想办法突出画面感。比如“穿上之后男朋友一直夸好看”“出门被追着问链接的xxx”这类表达。

今天这篇聊得不算长，主要是想提供一个不太一样的思考角度，也通过几组直观对比，让大家看清：同样的产品，为什么数据会天差地别。

同时也希望你明白，📕的流量密码，本质上握在内容自己手里。往后做笔记的时候，不妨朝着这个方向去发力。
