# 把一个为爱发电的装修围观群，成功变成商业化社群，我都做了什么？

我叫土豆妈，在体制内做幼教，特别能折腾房子。五年里买卖了六套房，三套重新装过。去年我连续报名两期经营训练营，前后坚持了五个多月，让一个原本只出不进的看房群，变成140多人交费加入的收费圈，试出了十来种收入路子，到现在利润超过了五万。

2020年4月，我成为赚钱会员。头两三年，绝大多数帖子我读得半懂不懂，只敢躲着看。不过我会跑去线下活动，反复参与实战项目，经常翻看精华内容。不知从哪天起，原先晦涩的东西忽然能读通了，这种进步不是一下子的，是慢慢泡出来的。

更早之前，我带过一个数百人的代购群，卖海淘母婴用品五六年，攒下不少忠诚客户。现在回想，那时我完全不懂怎么管群，一句不想干就把群清掉了，悔得不行。那些妈妈们购买力强，复购又高。

怀二胎那会儿，我试着蹭各种免费妈妈群引流量，结果群里全在吐槽家里人、传负面消息，买东西只挑便宜的。我推荐什么都被顶回来，根本带不动货。最后实在忍不了，把那个群也清干净了，顺便把消耗我的人和事一起踢开。

两次碰壁让我认了两条理：一是别跟预算紧张的人做生意；二是愿意交钱的人，本身就是最好的筛选结果。

可就算懂了这些，我的家装旁观群还是老样子。九块九的进群门槛没有拦住沉默，房子装了快两年，群里依然没什么人说话，基本靠我自己硬撑。我那时天天发愁：群该往哪使劲？日常怎么调动大家？群里的价值怎么变成钱？完全没方向。

转机来自龙哥随手写的一句牢骚话。他说忙到没空搭理家装。没过几天又劝大家试试做家居领域的内容博主。我盯着那两句话出了神：折腾房子这么磨人的事，能不能有人从头陪着走完？

这个行当里，有设计公司、施工班组、团购博主，可他们都只管流程里的某一段。真正需要的是有人一路兜底：开工之前怎么挑设计方和施工班组？铺砖选什么？地板用什么？出了问题怎么和商家谈？下单怎么压价？住进去以后软装如何搭配？养什么花省心？小孩的杂物如何收？这些琐事都得有人给句准话。更别提装修中那些憋屈、崩溃的瞬间，也需要一个能接住情绪的地方。

这让我想起当年带过的妈妈群。一群新手妈妈凑在一起聊养娃、互相推荐好物、也互相排雷。说穿了就是一种主题陪伴。养娃能这样，家装凭啥不可以？

这么想着，我迈出了第一步![](img/226b9db5b9f100da74c41dd6ea8dd235.png)。心里的定位也清楚了：搭一个既有实用知识、又能接住情绪的家居陪伴圈![](img/2b06c43ef88e92fab717f837444a8f18.png)。

我是2023年1月看到新一期运营实战通知的。那时我家那套105平的二手屋因为特殊时期，断断续续施工了快两年，旁观群还是靠热情撑着，一点收益都没有。前几回参与项目让我学到一课：想要结果，就得赶在开营前动手。等课程讲完再起步，节奏太慢，自信也会被拖没。所以我决定先把粗糙的框架搭起来，再等实战开跑后按手册和教练的指导校正。我的原则一直是：先上手，再优化![](img/17b1d19867042fd6baba8a68d90dc8c9.png)。

那轮实战很像游戏新手引导区，攻略、教练、外援都备齐了，有疑问就去问，做错不怕，重来就好。所以我很想对新来的朋友说：先别管结果，去报名，去干。否则容易陷进“看懂了但手不听使唤”的坑。

我在过年前就召齐了头几位核心成员。等实战正式开启，靠着手册，群的主要架构基本立住了。剩下就是边做边调。

那一轮我做了六件事。第一，理清定位。教练条Sir发过一张定位表，简洁又清楚，谁要做群都应该静心填一遍![](img/ef9f9280c35ba0c2aa881e47d8ff67ae.png)。

第二，每天输出。每天的家装干货都提前定好主题，不重样![](img/d407774532380022bc6a2c0547fce2fc.png)。

第三，沉淀内容。每天讲完的要点会由我丈夫和助手放进在线文档，方便成员回看。我不擅长做整理，这部分交给他们，半年攒了差不多六万字![](img/c2e76fb677afeae6e62d7720e57ff472.png)。

第四，招募海报。我请赚钱圈里一位叫热爱的朋友帮忙细化卖点，做了一张拉新图![](img/a733cfa009a8fc67f548c6f9bf4df231.png)。

第五，专属表情。学那边的做法，让群友一起贡献点子，再用ChatGPT帮忙生成口号和图案![](img/8aaac8af7f53aeea53ecc66c363e6a04.png)。

第六，定价拉新。原本想一年收365元，刚起步没底气，改成99元早鸟费用，满一百人后调到199。第一期招进来四五十人。如今回看，这个价格确实便宜了。

当然毛病也一堆。最烦的是内容跟不上。我定的规矩是天天要有新干货，撑到次月就开始词穷，每天为了找主题发愁。单靠我一人积累终究有限，比如有群友问独栋别墅的采暖、净水怎么配，我确实给不出实操经验——毕竟我还没住上大宅子。

其次是活跃度反而降了。我成天甩出大量图文，信息太密，大家干脆不打开。有人说术语太多看不懂；也有人家里还没装或已经收尾，内容压根用不着。

再就是收入路子太窄。只靠收门票，钱少得可怜，还要发愁第二年怎么续费。说白了，赚不到钱，群主很难一直贴脸输出。

第一轮结束后，我反复想过：白天上班、民宿要管、俩娃要带，分给这个群的时间实在有限。拉新和后端建设都要精力，硬撑着两边抓不现实。想了很久，我不再急着拉人，而是选择先把现有的圈子做厚：把内容、课程、知识产品一点点补齐，把赚钱的路子铺开。

两轮之间，我的更新一直没停，慢慢调整。五月新一期报名时，我几乎没犹豫就上了车。这次我是带着上轮的困惑来的，目标具体多了。

报名前我把见过的各类群都盘了一遍：不收费的地带、低门槛的学习健身打卡群、中高门槛的项目训练营、再往上还有高端咨询群。可在家装这个类目里翻来翻去，愣是没有一个像样的参照。博主们的粉丝群基本是随意聊天，商家群只有买卖双方闲聊，没人认真经营。没有样板，我决定从一个最细的环节开始改![](img/5e9be11f558cce50ad906e6396907d50.png)。

破局我重点抓了三件事。第一，每天写复盘。我从2020年12月末开始在公开平台记录当天所得，一直写了600多天，生二宝那天也没断过。头一轮我打了20天卡，唯一漏掉那天是刚满一岁的娃突然高烧，我抱着娃跑医院，回家一头睡死过去。第二轮我把21天全勤拿满，总分排在第二位。这一路遇到的问题、彼时的思路、处理的手法，全都在记录里![](img/84efb66e69a9f6e2831941892c1363fb.png)。

顺便说句题外话，航行期间我见过不少人打了两三天就消失，有人报了名压根没开始，也有人每天凑一篇流水账，翻来覆去就一句感受。这种日记写了等于没写。写不出来，多半是没真正下场做事——如果你每天都在群内处理问题，怎么会没素材？复盘不是交差，是写给本人看的提醒。不要小看每天那几分钟，坚持满21天再回看，你会看到明显的变化![](img/99b334eea1c19cc90c50eaa586b92dd3.png)。

第二，找高手请教。许多运营灵感不是憋出来的，而是看别人的记录冒出来的。除了教练和嘉宾的分享，我也会翻其他成员的打卡，尤其是标了精华的。碰到做得好的，我会主动搭话，围观对方的主页，能省不少弯路的工夫。比如快闪活动这种玩法，我第一轮完全没概念，同期有位叫安安的同学把筹备过程拆解得清清楚楚，最后积分榜第一。这种笔记看一篇，比自己闷头试十次都管用![](img/b9d40c35212e826df99ae36d4b3b0dda.png)。靠近优秀的人，交换思路，成长会快很多![](img/c8d2a2dd1ae79025fc4d54ea4f20c11f.png)。

第三，把单口相声改成合家欢。单靠我来讲会腻，不如让更多人上台。我借用那边的嘉宾开讲和优秀成员交流的做法，把新版手册反复读了几遍，再把我那个群里的细节逐一抠出来改。

对比3月和7月的月排表，改动很明显![](img/46df7c3f833577fdfcadf29f27e2001d.png)：干货和好物穿插上；用接龙提前收集大家关心的话题；每天开讲的时间点固定，内容更短更准；每周请一位群友讲自家案例；邀外部行家来开小灶，互相带流量；增加成员访谈，把口碑传出去；周末和节假日不再硬性更新，让大家都喘口气。

节奏理顺后，群里渐渐稳住了。持续输出大半年，我不再为选题头疼，成员也习惯了这种步调。每次有人来做分享，总能带动一轮热烈的回应![](img/028818ecc755d12d0c4c3d7f1a2eb4ef.png)。

进了第二轮，我的重心明显转向赚钱。除了门票，能试的路子都试了一遍。

卖货是最容易起步的。在私域卖东西门槛不高，但分寸必须拿捏，不能像拼单群那样刷屏。我接了团购小工具，不压货不操心售后。关键是让带货跟着日常内容自然走——聊到厨房收纳，顺手放上自己用了觉得好的几款，成员随手就下单了。4、5两个月，收费群外加一个不收费的拼单群，进账一千多![](img/41099e5344f50f77d8953549d880f13b.png)。

品牌合作那条线也通了。618之前，群里不少人都想买买买，直接点名让我开团。我账号粉丝不多，不要紧，群里有资源的人多啊。我找了长期在家电领域测评产品的2y合作：先请他在群里做一场自动扫拖机的纯技术讲座，不带货，反馈很好；再通过他对接品牌资源。百来号成员的群，真正下手的虽然不多，但刚需用户基本都被接住了。单量不算大，从种草到成交的闭环算是跑通了。这种分佣模式，以后可以多复制几次![](img/56b0680b0ed21cbe7f32f8b6722b38a5.png)。

设计佣金这块属于天降馅饼。上海有个业主，160平的房子想做设计。他先是在知乎刷到我，又从一个内容平台找到我，加上微信。围观一阵后进了群，多方比较，最后决定找我合作过的事务所做设计。合同经过几轮拉扯，从最初报价谈到七万多，我也拿到了一笔中介费。这比一件件卖货划算多了。做家居内容的人，完全可以对接靠谱的装修团队或设计事务所，提前谈好返点。当然，不该赚的钱我不碰。六月就有一家装修公司找过我，返点高得吓人，还承诺进店发红包，但他们要求全款付清再开工，这风险我不愿意让客户担，所以推了。

七月初做成员访谈时，又捡到一个好消息：一位跟了我十年的老粉，对我合作过的那位设计负责人特别认可，她那套120平方米的新居马上要交钥匙了，十有八九也会签同一家。

持续输出半年，也把我的个人IP立住了。我能提供的经验慢慢整理成付费咨询，话题包括买卖房子、学区选择、家装定位、旧宅翻新，定价999一次，一次三小时。往根上说，就是能陪你把家慢慢弄好的身边人![](img/b8af26c2ddb44bb23e265fdd134e7b30.png)。

最意外的，是有人让我做全案。那位群友在上海内环有一套130多平的出租屋，之前低价包给中介，收回来想重新装一下，用低成本把租金抬上去。但他没时间，也一直没有碰到合适的人。聊过几次后，他认我民宿房东的视角和改造经验，委托从一次咨询一路升级成出租定位加全屋改造的整体方案。我给了三套方案让他选，你们猜他选了哪个？![](img/4e9262f1c4f891f7e862c958b13c9d5d.png)

我这种没上过设计课、连画图软件都不熟的人，怎么敢接这种活？答案就是找对搭档。在赚钱圈里认识了做设计的郭老师，聊了一次就合拍，立刻决定一起干。项目管理式合作，彼此信任，谁擅长什么就负责什么，别的不用多想。

目前全案还在推进，细节先不展开，等收尾了我再回来汇报。

回到起点，我建这个群那天，是2023年春节假期末尾。我带着两个孩子从外地返沪，汽车还在回程的路上，新群刚刚冒出个雏形。彼时的我压根没指望它能赚到钱，只是抱着试试看的心态。半年过去，回报远超预期。用心经营一个圈子，确实比想象中有奔头。

当然，这个群还有很多可以打磨的地方。但那又怎样？边跑边修，继续折腾就是了。

接下来想做的事很清楚：把攒下来的东西持续放出去，铺到公号、小红书、知乎这些大的内容出口，一边做内容，一边把个人品牌立起来；之前那条从零起步、一点点试出来的路径，后半程要试着放大成十倍、百倍的规模。要补的课、要打磨的细节，还多得很。

在赚钱这段航程里，能找到一股把自己往前推的光亮，就足够了。方向一旦定了，就别来回摇摆；脚步不停，收获迟早会来。

最后，送圈里伙伴一句话共勉：路线认准了，就走到终点，那里会有你该得的回报。
