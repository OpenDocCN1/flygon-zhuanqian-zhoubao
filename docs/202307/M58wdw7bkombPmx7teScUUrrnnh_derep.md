# 明星切片授权分发，月GMV破千万？这个“躺赚”渠道生意，我把0到1全盘托出

![](img/64d20a7daebc10f77a32292f1e2233da.png)

各位圈友，我是小金叔叔。做过微商、教育、私募，算是个连续创业者。目前在杭州，主攻抖音直播卖课、明星切片授权，以及视频号直播、店群、投放，还有小红书投放。平时也折腾一些自动化工具，比如自动扒视频号上闷声赚钱的商品、批量把抖音热卖品搬到小红书/视频号、自动追踪视频号10w+爆款视频等等。这篇文章点赞后，私信我就能免费体验。

![](img/6745291c971b1780e3919f368e85798c.png)

有段时间没分享了，今天把最近半年多一直在跑的“躺赚”项目拿出来聊聊——直播切片渠道分发。目前我这个渠道后台累计授权的用户已经超过10000，剪辑大军每月能在这条渠道里跑出千万级GMV，利润也相当可观。更关键的是，这套生意闭环从0到1，只有我和我爱人两个人搭建。接下来我把整个过程复盘一遍，毫无保留。

## 缘起

去年我刷到不少网红、明星在放直播切片授权，最有代表性的就是小杨哥那类，据说不少帮他剪切片的人月入几十万。当时我第一个念头是：能不能往上游走，不自己剪，而是做渠道方，靠分发授权赚钱？

没动手之前，我也觉得这事儿不靠谱——我一个普通人，上哪找明星团队？人家凭什么给我面子？但凭着“谁也不服”的劲儿，加上一个圈友帮忙牵线，居然真的谈下来了。接触后才发现，这行当时有个巨大的信息差：一边是需要铺量的达人和明星，一边是嗷嗷待哺想切片的剪辑号，两边却隔着一道信息墙。因为切片玩法刚出来，达人端急需铺量，所以给我的门槛并不高。回头看，这本质上就是信息差红利。

![](img/40524c9ca57cc9e367c1d8c75edf8fe5.png)

## 授权分发怎么做？

最开始，对方只给了我一个光秃秃的链接。凡是从这个链接进来的用户，都算我渠道的。每天腾讯文档会同步一份数据表，谁申请了哪个明星的授权，我要一个个跟进、帮忙搞定授权。

后来我把拿到的授权整理成专属申请入口，往社群和抖音铺。帖子套路很简单：《今天XX授权开放了，点下方免费申请》。算是发得比较早的，广东夫妇、郝劭文、金星这些，都赶上了。接着副业圈的KOL也注意到，有人拍短视频宣称“做XX切片能暴富”，有人干脆把项目包装成“日入过万”的天价训练营，报价998。但我的授权渠道不收费，所以链接传得非常快，记得才一个月光景，后台就涌进几千个申请，真把我惊到了。

## 爆发式增长后，我上了自动化系统

人一多，麻烦跟着来。授权流程本身很重：要绑定MCN机构，再做扫码、验证码……每天还有几百人加我微信小号，靠手动根本忙不过来。于是我就想着，能不能用系统自动化解决？

后来我用wetool搭了一套自动化流程：批量自动通过好友申请，然后发一个简单问询，让对方选ABC，只有明确回答“是”才进入授权环节，之后就是自动拉群、自动开通。因为机器人秒回，效率一下子拉满，而且24小时都能授权。同行还在靠人工，我这边半夜都能自动处理，客户体验比同行高了一截。

## 凭什么赚钱？

这边给剪辑方的授权不收一分钱，收入全靠渠道返佣。商品佣金的大头归剪辑方，通常是50%，而渠道只分到其中5%。听着很薄，架不住量大——后台经常有账号仅用一周时间，GMV就能冲到百万级。比如这个账号，粉丝才4000多：

半年下来，后台渠道收益已经相当可观——说实话，这半年真没花我多少精力，很多时候都是系统在自动运转。上个月因为业绩不错，平台方又多给了我家几个渠道名额。说句实话，这波能跑起来，主要靠平台红利和明星效应，跟个人能力关系不大。关键是切中了明星网红的真实痛点：以前达人卖货全靠直播，下播就没收入；现在有了切片授权，哪怕人不在播，也有一堆剪辑号帮你卖。

而且每个明星刚开放切片授权时，粉丝还没被各种切片“洗”过，平台上相关素材也少，剪辑不容易重复，跑量更容易。所以很多人抢着去拿授权，想赚第一波钱。明星方为了冲量，早期分成也拉得很高——比如当时美妆达人“美希”开放切片，佣金分成高达85%。

## 普通人还有机会吗？

你可能会问：这种机会还会再来吗？答案是会。一方面，每个月都有新面孔的网红、明星开始开放切片授权；另一方面，视频号的机会已经来了。

既然重新写，就再补充点新进展。目前我这个切片渠道已经滚到1.5万+剪辑人员，但签约的明星网红只有十几位，视频素材根本不够这么多人分。于是又衍生出一个新需求：去签更多博主进来。多签一个博主，就意味着多一份渠道佣金，而且是持续的。

核心逻辑很简单：让明星网红愿意开放自己的直播内容，供剪辑团队拿去做二次创作。这样哪怕他们没有开播，商品依然能通过大量授权剪辑号持续出单。这条生意链路的重心，已经从“拉剪辑人头”彻底转到了“签更多明星网红”。如果你手里有相关商务资源，这不又是一门赚钱的生意吗？
