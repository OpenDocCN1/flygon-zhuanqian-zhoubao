# 【能提升60%销量的测品思路】
作者：龙哥

我是龙哥，一个从农村走出来的95后，身上背着负债，在创业这条路上多次跌倒又爬起来，熟悉我的人都喊我“打不死的小强”。今天要跟你聊的，是一个帮我📕店铺订单量涨了60%的测品玩法。

这两年我陆续做了十多家📕店铺，越来越意识到一个事实：测品是所有人绕不过去的关卡。但奇怪的是，专门讲这个内容的干货特别少。我自己也踩过不少坑，花了不少冤枉钱。直到前不久，我试出一个新思路，验证之后效果很不错，才决定把它完整整理出来，包括优缺点、操作步骤、注意事项，尽量做得细致，让你看完就能用。内容会比较长，为了让你不觉得无聊，我会结合自己的真实经历加图片来解释。先放个目录，方便你跟上节奏：

先说你能得到什么。这套玩法可以帮你测试出自己选中的产品，用户到底买不买单；同时它能带动账号流量和店铺销量；更重要的是，这个思路能复制到不同产品和各种场景里去复用。

说起来也挺巧，这个方法是靠需求逼出来的。我以前测品的方式特别“原始”，效率很低，总想找一个更快更省力的替代方案。有一天我照常刷📕，刷到一篇水果四宫格的笔记![](img/9b76c220e8767742f2253bdc3f42b4ca.png)，就是让你从四张图里挑一个你最喜欢的。我看完评论区之后觉得很有意思，又好玩又有互动，而且他那条笔记的评论数量，居然比点赞和收藏加起来还要多。这个小细节让我冒出一个念头：是不是也能用这种“四选一”来做测品？

我马上就去搜关键词“极限四选一”，翻了很多热门笔记，发现它们的共同点都是：评论比点赞多，流量根本不缺。这不就是我一直想要的效果吗？于是我开始想拿个产品来试试。说来也巧，那阵子我在抖音刷到一条视频![](img/9d41732f9a3653d26a561bcc08a026d0.png)，说的是从2023年7月1日开始，路上骑电动车都得戴头盔，而且必须是经过3C认证的，不然被现场抓到要罚款几十块，甚至可能扣车。这是政策带来的新需求，短时间内肯定会有很多人搜和买。我早就想开个头盔店，但一直缺一个高效率的测品方法。这个新玩法的出现，正好把机会送到了我面前。

接下来是大家最关心的部分：具体操作流程。一共六步：收集素材→裁剪拼图→发布笔记→筛选淘汰→确定产品→开店卖货。

第一步，收集素材。就拿头盔来举例，我照惯例先在📕搜“头盔”两个字，点进“最热”那一栏，从热门爆款里找颜值高、符合新规的头盔![](img/1575129b8e8e576988ce76e7d2f9b7c1.png)，我选了10个，截图当作素材备用![](img/149937c7708c0b150a7c5e7e842d7978.png)。

第二步，裁剪拼图。我用的工具是美图秀秀，从10张产品图里随机拿4张，用拼图模式做成一张四宫格图片，并且标上序号![](img/b4119e3146ea13bb1dd95f8d18167d36.png)。

第三步，发布笔记。我观察到一个规律：很多热门前排的标题都很简短，而且爆款经常是重复的。为了省时间，我也去模仿那种风格，尽量简单好懂。我写的标题是：“极限四选一，你会选哪个”。就这么简单，标题越简单，用户越容易快速做选择。话题标签也很关键，它直接影响测试流量。我一般会在内容区选几个和产品、选题相关的话题标上![](img/a8baa92d4776567966dcfb0e73ce6c08.png)，然后就可以发布笔记了。

第四步，筛选淘汰。笔记发出去大概3分钟左右，就会有第一波人进来看并且留下评论![](img/ccefcd388ca0a57bcda0aaf6da3746df.png)。我从评论里找出大家最不喜欢的两个，把它们淘汰掉，然后再用另外两个产品图片拼成新的四宫格![](img/5b81689480172b104af25ce7181a0631.png)，发布第二篇笔记，继续用第一轮的方式淘汰。

第五步，确定产品。这样反复利用用户的评论反馈，最后选出来两个大家最喜欢的产品。到这一步就可以开始标价测试了。怎么标？你找到货源之后，在进货价的基础上加价20%到50%，把价格直接标在两张产品图上，看用户更愿意为哪一个价格买单![](img/e3da59ed0e76516910c2c7318a34e4a4.png)。

第六步，开店卖货。最后从这两个产品里，根据评论数据选出最受欢迎的那一个，找到对应货源图片素材，去开店上架商品![](img/c24dd7bc69e8f7e68577df3b521b3912.png)，然后发布种草笔记开始带货。

再来说说优点。我想很多人做测品的时候，包括我自己在内，大多数都在做无用功。为什么？因为我们总觉得自己选的产品就是最好的，用户肯定会喜欢，结果经常被现实打脸。我经常说要杜绝“自嗨思维”去选品，但说来好笑，自己偶尔也会掉进这个陷阱。但这个测品思路，能让你更真实地了解用户：他们喜欢什么、不喜欢什么、不喜欢的原因是什么。这样一来，你能高效选出他们满意的产品，订单数自然也就上去了。同时，标价这一步可以帮你测试用户能不能接受你的价格。如果能接受，你就放心开店卖货；如果不能接受，你可以适当降降价，但别降得太低。一个产品如果连利润都没了，你折腾它还有什么意义？在我看来，做📕电商利润率低于10%的项目，我根本不会考虑。

它还能顺带帮你测出账号流量是否正常。如果你发出这类型互动很强的笔记，流量都上不了100，那多半是账号权重出了问题。

当然，没有哪一个玩法是完美的，有优点自然就有缺点。这个玩法有可能会收到系统违规提示，内容是说你“诱导用户评论、点赞、收藏”![](img/69f5d2cbb1111056f2e81e13be80b040.png)。我不太确定是被人举报，还是系统自动检测到的。但后来我用同样的素材和文案再测品，笔记流量依然正常，也没有再收到违规提示。

接下来聊聊测品时要注意的问题，我总结了十条。

一、选同种类的产品。千万别拿不同品类的产品放在一起测，那样会显得很乱，用户根本看不懂这张图要表达什么。你看下面这张图![](img/9d3d5d99ff71b4fec3befaf2f1f554f5.png)，如果是你，你能看出它们之间有什么关系吗？

二、选颜值高的图。选图非常重要，如果图片不好看、颜值不高或者拍摄角度不理想，都会干扰用户的判断，最后反馈给你的数据也会偏差。给你们看个对比![](img/5046fdc02b95afe32e87142228429618.png)![](img/347582d6fde8912af9db75f621c0f4cd.png)，如果是你，更想点哪一张进去看？

三、选无字的纯图片。选素材的时候一定要挑无字纯图，别选那种带文字的。因为拼出来的图就是封面，封面花里胡哨的话，很难抓住用户注意力，笔记流量也会受影响。继续做对比![](img/2e703663bbcc490a41811489c667c1f9.png)![](img/bee2ad26277f9063817c5d02f23145af.png)，哪个封面更吸引你？对比完感觉是不是立刻不一样了？用户也是这么想的。

四、选拍摄角度一致的图片。角度统一会让人看起来整齐又舒服![](img/4ea9ef5a3f19326357dcaaba303ea339.png)![](img/7354633c3f77cbaafa77a5e7eabd7ca4.png)。再给你们看个反例![](img/a7f748109eb8c52a931620e866b432ab.png)，感受一下差别。

五、不要急于标价。📕是种草平台，用户永远先看颜值，再看价格。你价格再低，产品不符合审美，用户一样不喜欢。记住这个顺序，先看颜值再看价格，千万别搞反。

六、优先选图文。图文形式比视频形式更适合做测品。一张图能快速地找到自己喜欢的产品，而且图片被查重的风险比视频低，不容易被判违规。

七、有话题比无话题流量更高。我专门用话题做了测试，发现用了话题，流量会更好。什么是话题？就是下面这种![](img/e0b03e609725a8a63c3f5324c5a547e5.png)。在测试的时候添加产品相关话题，不仅有更多流量，还能吸引到话题里本来就有兴趣的人，人群也会更精准。

八、如果发布流量低怎么办。如果你测品时流量连100都过不了，那大概率是账号权重出了问题。可能是你之前有违规操作，比如短时间批量发布笔记、有引流私域的行为、被判搬运等等。如果你连续发三篇以上流量都突破不了100，那建议你直接重新注册一个新号，用同样的图片和文案再发一次，你会得到一个惊喜。一定要先把账号流量测正常，再去开店卖货，因为店铺90%的流量都来自笔记。

九、笔记爆了怎么办。如果笔记爆了，除了引导评论之外，你什么都不要做。不要去修改编辑，不要去上架产品，更不要删除这篇笔记。

十、把控好发布时间。前后两条笔记发布的时间至少隔30分钟以上，单个账号当天发笔记不要超过10条，否则会被强制隐形限流。如果你想同时测多个产品，可以多注册几个账号分开测，同时关掉WiFi，别在同一个网络IP下集中登录。

说完注意事项，再讲讲这个玩法给我的启发。

最大的启发是：真正用行动去为用户着想。我老是会提醒别人，要多站在用户角度去思考，不能自嗨不能自嗨。但选品选久了，人很容易陷入“自我感觉良好”的思维陷阱。这个四宫格玩法，是真正用行动把选择权交给用户，让他们来帮你挑产品，这样既能节省大量时间，也能提高测出爆款的概率。

第二个启发是可以延伸到很多场景。比如你🛰️里有很多私域客户，但不知道推哪款产品他们会更喜欢，你完全可以发个朋友圈四宫格来测试。又比如你的产品一直没人问津，也可以用这个方法看看，到底是产品本身没吸引力，还是价格让人接受不了。一直测、一直调整，直到找到问题解决它。你可以举一反三，看看能不能把这个思路套到你的产品和场景里。看完如果对你有用，记得回来帮我点个赞。

最后做个总结。我觉得这个玩法特别适合那种“自嗨型”选品的人，它能帮你比较轻松地测试出用户真正喜欢的产品，也能让你感受到用户的真实想法。用户给你的每条评论，都在帮你撬动更多推荐流量，最终让店铺销量变得更高。这套方法不止能用在红薯上，还可以套到很多产品和场景里，核心就是举一反三。
