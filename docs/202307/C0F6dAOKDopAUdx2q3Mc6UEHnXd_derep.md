# 一、先定目标：要的是能产生价值的指令，不是模板

先说一个认知：一套好的指令，不是市面上常见的“套个设定、写个任务描述”那种模板，也不是几个关键词拼一拼就完事。它需要一轮轮反复调教，最后再提炼成一段简练指令——本质上是一个先做加法、再做减法的过程。![](img/536bdb7d81f04631cdc64e80a457c696.png)

我们打磨AI指令时，盯的不是“形式上符合要求的文案”，而是真正能产生商业价值的东西。只有守住这个原则、目标足够清晰，才能在一堆高手中间长期赚钱。

拿这套📕提示词举例，我们最终想要的是这样一台“机器人”：从内容方向选择，到标准爆款文案制作，全部自动完成。我们只要把需要推广的行业或者产品告诉它，它就能吐出高质量、容易爆的文案。

# 二、一个目标拆成四步

显然，一套提示词很难包办所有事。所以，我们把大目标拆成了四个关键子目标：

1. 内容方向选择
2. 内容方向对应的文案生成
3. 爆款元素融入文案
4. 高质量批量二创

再分别用四套提示词去实现。

这里要特别提醒：关键目标的拆分，最好由对这个行业有深度理解的伙伴来完成。如果你暂时没有，那就去龙哥盟找该行业的高质量经验帖，看看经验贴是怎么把行业关键节点拆出来的，再让AI去复刻。龙哥盟真的是一座宝库。

我是📕千人实战营的合伙人，对📕爆款逻辑有些自己的理解，所以上面的拆分，本质上是把我对爆款内容的感悟复刻了一遍。说到底，一套优秀的AI指令 = 专业能力 + 优质AI指令能力。哪怕你不具备某个赛道的专业能力，也可以借用别人的专业能力来完成这一步。

# 三、一步步把阶段目标变成现实

## 1. 摸清GPT的认知边界，先喂基础信息

所有大语言模型，本质上都是在用过往信息做拆解分析。所以它的数据库很可能覆盖不了你提出的新问题。

ChatGPT训练数据的时间截止点是2021年9月。你如果问它“支付宝短视频”这类之后才上线的东西，它很可能一头雾水。那怎么确认它对📕是否了解？直接问它一句就行。

![](img/cf9765dff11b928e540b54d2519638b5.png)

好了，确认了：GPT知道📕。

你可能会问：既然它知道，那下次是不是不用再单独问一遍？真不是。提问有两个作用：

第一，探测GPT的认知边界。如果它不了解某个信息，我们就去搜索，然后手动输入让它学习。

第二，让它学习自己刚说过的内容。只要你在一轮对话里单独点出“📕”，最后生成的结果，会比只在任务描述里提一句“📕”更优质。因为GPT会把你回答过的每一句话，都作为后续交互的参考。

如果这一环GPT说不知道📕，那我们就得手动补信息进去，让它学习。之前开发“AI比赛评委”提示词时，就留下过这样的记录：![](img/9571c3878de8b0f207c1593c231e4044.png)![](img/d99d2b3bf1334c858dac83b760d50ada.png)

## 2. 把专业能力嵌入GPT

基于我对📕的认知，选内容方向的第一步，是明确你写的东西到底给谁看。![](img/63aef561a1ccd91d7227d6b4ded8be66.png)

同样基于我对📕的认知，一个好的内容方向，往往会迎合人性的弱点，或者戳中人性的恐惧点、丑恶点。比如“一个人的点菜水平，暴露了她的层次”——这是我在📕刷到的一篇爆款，当时内心相当震撼，就决定一定要用GPT复刻这种能力。

于是，在让GPT完成用户画像分析后，我继续让它做了一轮深度分析：![](img/0585354116f811860594111d07eccf13.png)![](img/9c27712915ce99fcdadefa5553e19e0b.png)

到这一步，GPT已经掌握了做爆款内容的内核，专业能力嵌入成功。别看就是几句看似简单的提问，背后是几十万字的学习再加上持续实践才浓缩出来的。

如果你没有目标赛道的专业能力，我们也摸索过一条路：把别人的专业能力复刻出来，再交给GPT。因为篇幅有限，这里先不展开；感兴趣的人多，后面我单独开一篇聊。

## 4. 规范输出 + 持续调试

还记得前面说过的GPT的重要性质吗？只要它回答过某句话，后续和你的交互里，它就会主动调用这些内容。

经过专业能力嵌入和优秀案例引入，这个“机器人”已经具备生产爆款内容方向的能力了。最后要做的，是给它一个输出模板，让它的产出格式稳定下来。![](img/6dc02db25efd63c23cd776ae2c227911.png)

如果输出还有问题，就用列点的方式，把问题明确抛给ChatGPT。![](img/23c64d8798e39d82fb625af527b09985.png)
