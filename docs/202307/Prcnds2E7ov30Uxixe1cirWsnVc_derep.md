# 0. 前言

先做个自我介绍，我是入了生财群没多久的小白，被大家的分享氛围带进来，也想把自己这段时间的踩坑经验抛出来。

我本职是程序员，97年，校招进了腾讯，后来跳到外企 ZOOM，今年已经离职了，现在在到处试水，还没定下来方向。

这次要聊的电瓶车充电桩，和生财群里常见的项目不太一样，我也觉得它并不适合所有人，后面会说为什么。不过既然有人问起，我就把我了解到的情况整理一下。

需要说明的是，下面内容都是我以一个普通运营商的视角来复盘的，不一定百分百准确，有做这行的朋友欢迎指正。我自己并不是真正去做这个的，最初是想给深圳的一个团队做扫码充电的软件系统，后来合作谈崩了。之后我投了点钱给一个合伙人去做线下桩，现在我只负责看数据。

软件系统没做成，但这两个月我全程围观了设备选型、装机、谈点位、收电费的全过程，也顺带听到了不少关于电瓶车充换电柜和汽车充电站的说法，后面也会简单带一句。另外扫码充电系统的技术架构我基本吃透了，有兴趣可以私聊。

# 安装方式分两种

电瓶车充电桩的铺设大致分集中式和非集中式两类。

一种是集中式，像小区门口、工业区、商场侧面、村集体空地那种，需要搭棚子，有时还要硬化地面做水泥底座。

![](img/61e2369c7a4239e9e003e992c12c29d5.png)

另一种是非集中式，直接贴在城中村民房的外墙上，只要房东点头就能装。我合伙人现在主攻的就是这种。

![](img/35ac62532093a638ac21632c3d6a24bd.png)

# 设备生态大概什么样

这个赛道分上游硬件厂商和下游运营商。厂商负责造，运营商负责铺点位抢流量，我合伙人就是扮演运营商的角色。当然也有厂家自营。

大家熟知的星星快充、特来电、云快充，其实都是做电动汽车充电站运营的。电瓶车这块我接触到的厂比较多，几乎每家都在做电瓶车充电桩、充换电柜和汽车慢充，只有少数头部才做汽车快充，因为成本太高。

我沟通过的厂家有江西赣州的驴充充、郑州的 UU 充电、叮叮、深圳的龙马充电、嘉满电、鸿嘉利等。实地看过驴充充、龙马、嘉满电。

驴充充算是规模最大的，品类全价格中庸。质量如何我不敢打包票，毕竟没长时间跟踪。广东本地还常见小兔充充和猛犸充电，前者在深圳几乎随处可见。

找一家厂谈下来，资料、报价、参数都是现成的。这个行业干了好几年了，整体质量在可控范围内，除了一些老旧设备，每家基本都给2年质保和设备险。

选设备我建议两点：

1. 选有一定市场体量的品牌，别选太冷门的，怕厂家后续甩手不管
2. 最好选用户充值流水走自己公司账户的方案。现在大部分品牌是用户扫码后钱先入品牌公账，再定期提现给运营商，中间隔几天。如果设备量少无所谓，几百台起量的话资金池风险就大了

# 电瓶车充电桩的真实账

这是我了解最深的部分。

## 花钱

设备费：一台10孔的电瓶车桩，市面价400-500元左右，也有249元的特价款，驴充充最低款268元。

辅材费：电线、插座、数码电表、公示牌、穿线管等，约500元。

人工费：非集中式点位，跑点子的人一次200-300元，装机一次200-300元。长期团队一般底薪+提成。还有油费、房租、给房东买点烟酒的人情开销。

电费：非集中式一般直接和房东结算电费，不分润。电价1.1-1.5元/度，也有极个别能拿到0.6元的成本价。集中式的物业一般要分润，否则合作不长久。电费结算多为月结，也能谈季度结。

维护费：100台规模，一个月大概有1-2台出状况，可能是设备损坏、房东要求撤机、点位太偏没人用要拆走。主要是人力成本。

其他：要搭棚或硬化地面成本会上去，但这些位置通常是好位置，值得投入。

综合算下来，不搭棚不硬化，一台桩落地成本约1500元。

## 赚钱

以我自己在深圳装的一台非集中式桩举例，4.8号装的，设置1元充2小时，在深圳广州比较常见，这个价格可随时调。

![](img/881dcd3fee2af54664f8201e57506503.png)

![](img/68809f4498f434b49c919ad8cda47ddc.png)

这台桩稳定后每天大概20元收入，已经算高了，能跟一线城市平均水平持平。城中村民房的点位，稳定后最低5元/天，正常7元/天。

如果小程序和服务号是自己管，还能有流量主的额外收益，我们现在不是自己管所以这块算不清。规模做大还能发展代理。

这个生意拼的是量，一台两台意思不大，几百台起量后收益才真正可观，而且装完基本就是躺收。

我知道深圳坪山有人装了150台，一年流水93万，他本地关系硬，点位好。普通点位达不到。单台桩收益一般要2个月后才稳定，跟位置强相关。

## 风险

设备险厂家会配，场地险需要自己买，因为存在起火风险。虽然室外相对安全，但万一烧到周边电瓶车就麻烦了。长期做必须买，玩票的可以忽略。

政策风险也存在，比如深圳坪山要外墙走天然气，就要求拆除充电桩。拆了设备可以迁移复用。

总体风险可控，装下去基本都有收益，差的是收益高低。单台成本不高，抗风险能力强。电瓶车充换电柜逻辑类似，汽车充电站完全是另一个量级，更谨慎。

## 市场现状

和驴充充的人聊过，全国整体市场已经很卷了。深圳绝大多数小区已经覆盖，城中村走几百米就一个点位，渗透率70%-80%了。我合伙人转战广州白云，城中村基本空白，小区才被占满。

深圳18年开始大力推，所以品牌扎堆抢占。现在一线城市空间很小，二线还能啃，三四线就不太行，因为安全意识弱、监管松、电动车禁摩影响需求。

我个人看法不一样：只要价格合适，用户还是愿意用，拉电线或推上楼充电太麻烦；监管不严反而利于铺设；禁摩确实影响用量，但各地差异大。

最好的市场当然是一线，人多电动车密需求大，但竞争也大。要不要做，看你有没有资源。能拿到物业、居委会、消防等硬关系最好，没有的话只能跑城中村市场，体力活为主，大部分人吃不消。想做多大也决定了玩法。

最后提醒一下，规范价格的充电桩确实能减少电瓶车楼道充电引发火灾的风险，这是正向价值。

## 标准和合规

严格的城市比如深圳，对设备和安装有明确要求。今年电动车协会联合消防在推新标准，我拿到一份征求意见稿。

大部分地区管得松，只要不出事故就行。该标准挺严的，估计也是为了清退小玩家。

# 电瓶车充换电柜简单说

我了解不多。充换电柜主要服务外卖骑手这类高频用户，普通用户需求不大，但利润高，因为有电瓶押金能快速回本。

深圳征求意见稿也提到要大力推充换电柜，目标2025一栋一柜，能不能实现另说，主要是更安全。

能找到好点位放的话，单柜不含电瓶大几千块，不合适还能挪地方。

# 汽车充电站

我只去龙岗看过一个站，听老板聊了点。中山有个地皮想做，所以去取经。

一般2年半左右回本，主要成本是变电站，所以选址要近变电站。场地租期最好8年以上。

很多站会接入小桔快充这类平台获取流量，平台抽成不低。初期设备以慢充为主少量快充，后期看数据再调整。慢充枪约5k，快充枪3.5-5w。

投入和玩家门槛都高，巨头都在，个人很难玩。

# 总结

电瓶车充电桩是吃资源和体力的项目，本地有关系最香，没有的话要靠人海战术，长期坚持才能有规模利润。玩票装几台赚点零花钱可以。

优点是投入低、收益稳定、可半托管。装好基本就是睡后收入。

以上是我这两个月看到的，以电瓶车桩为主，肯定有遗漏和偏差，欢迎指正补充。
