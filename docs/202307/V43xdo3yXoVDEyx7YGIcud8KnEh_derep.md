# 声音一键“换皮”，RVC 保姆级实操攻略来了！
作者：龙哥

最近好多人在问：怎么把自己的声音实时变成另一个人？其实一个叫 RVC 的开源项目就能搞定。它是 B 站 UP 主“花儿不哭”的作品，对电脑配置比 SVC 温和太多，普通机器也能玩得非常开心。原理就是根据你选好的模型，对声音做实时转换，延迟一般几十到几百毫秒，具体高低由电脑性能和你的参数决定。

项目地址：https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI

先聊硬件门槛：

- 显卡：GTX 750Ti 以上就能跑，有 RTX 更好。
- CPU：越新越流畅。
- 麦和声卡：有条件就上，没条件用耳机也不是不行。

## 二、基础设置与参数详解

变声的完整路径是：声音源 → RVC → 虚拟声卡 → 硬件输出。

![](img/5682a57d2fb74622eede81ea88976c12.png)

接着做路径配置，跟着下面的占位图一步步来。

![](img/0734b516110433e88227a3806a9d39d3.png)

![](img/26afe1160ace50216b31c47fbc06acf7.png)

到了 RVC 配置界面，其实大部分参数不用动，新手建议只碰“音调”，其他保持默认就够用。

![](img/6475ccb24d6a66e1064b5b01932272f5.png)

**几个关键参数，我给你翻译成人话：**

- **响应阈值**：往左调更好，往右容易卡顿、吞字，不过也会带一点降噪效果。
- **音调设置**：男变女 +12，女变男 -12，不变调就设 0；左右滑动还能改变声音粗细。
- **底模音色**：拉得越高越贴近推理源和底模音色；想要说话清楚，建议 0.2~0.5 左右。
- **音高算法**：选低延迟能压低延迟；选高音质延迟可能到几百毫秒，可以通过拉高“高音质占进程数”来弥补。
- **声音延迟**：右边延迟高，左边延迟低，但别低于 0.5，不然内存会炸。
- **淡入淡出长度**：控制尾音长短。设太小容易断字，设太大声音会糊。
- **额外推理时长**：往左拉声音清脆但偏干，往右拉尾音变长、声音更润。建议调 1，配置够的话直接拉满，咬字会更清楚。
- **输入降噪 / 输出降噪**：都不太推荐开。想要降噪，建议用 RTX 显卡自带的 NVIDIA Broadcast，整合包里能直接装。

配置好后，点“开始变音”就能用了。

## 三、常见配置问题

1. 选输入设备、输出设备的时候，结尾一定要选 **MME**。
2. 播放设备和录制设备的格式必须一致，比如麦克风、扬声器、入梦扬声器、入梦麦克风，这四样统一成 44100 或 48000 都可以。

![](img/b664a888fe14a6cd586577c90b94c53a.png)

![](img/e0ffa1dbd3035a9299f5c4833c7bb9e4.png)

3. 要是想立刻听到自己变声后的效果，把“侦听”勾上就行。

![](img/6d63edee373c4b312f7fbf5d2b70d4ba.png)

## 四、自己动手训练模型

想训练专属模型，电脑配置建议至少四核 CPU + GTX1060 以上的 N 卡。

![](img/ba963a267d7ccaf7d762f437919c70d4.png)

### 1. 准备素材

素材可以各显神通自己找。语音至少 10 分钟，但建议录到半小时左右。录音时普通话尽量标准，咬字要清楚，否则最后效果会发糊。

如果素材有背景音、伴奏等噪音，先处理干净。直接用整合包内置插件就行：

1. 选择素材路径。

![](img/17ceb281b8b9727893c8bc28d2de4b90.png)

2. 选择处理模型。

![](img/918d33f9e3394bbb8c6410cca733ef1b.png)

3. 设置输出路径。第一次处理完选第一个文件夹，第二次处理完选第二个文件夹。

![](img/09765f14ab4262974e7a21cda1433b63.png)

### 2. 开始训练

把第二次处理好的文件夹位置记下来。注意，要的是文件夹位置，不是一个音频文件的位置。

然后设置训练参数，点“一键训练”即可。

![](img/b763aa991079d9a835da208c3bd181a3.png)

训练过程中别关控制台。进度可以看控制台，也可以看 Web 页面。

![](img/c1dbf7e62837c06cfffa33ba3c9d69f7.png)

![](img/0944ea0a6c4816c98db75dad58fefd87.png)

![](img/6fa16dd4b64625101033d0dc148e5c96.png)

![](img/bb91dc8190d9ea764aa471bee774cc43.png)

### 3. 找到训练好的模型

训练完成后，去整合包解压目录里找这几样东西：

1. 进入解压后的文件夹。

![](img/f288d78710dfe19bb90942b2cebd010d.png)

2. 打开 **logs** 文件夹，把里面的 **index 文件**和 **npy 文件**保存好。

![](img/d750635890fd12046ee15c5c5329de65.png)

3. 打开 **weights** 文件夹，找到最终训练模型，保存下来。

![](img/d4dd0d2ada5755c7412da2e0d5c582d0.png)

到这里，专属模型就训练完成了。

一些小建议：

- 优先用 **V1** 训练，V2 有时会找不到训练完成的模型。
- 优先用 **40K**，用 48K 可能会出现电音感。

## 五、用自己的模型变声 / 转换音频

加载自己训练的模型很简单：

1. 选 **pth 模型文件**。
2. 选 **index 索引文件**。
3. 按前面说的设置 RVC 参数。
4. 点击开始音频转换。

![](img/621521ef6054d9e7a755c16694756731.png)

如果只是想用整合包直接转音频，打开 Web 端，设置参数就行。

![](img/827c532e39fe38d2b6fdbfc62511745a.png)
