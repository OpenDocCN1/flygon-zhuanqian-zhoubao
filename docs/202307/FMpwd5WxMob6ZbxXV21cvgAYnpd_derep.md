# 一、这两个项目靠什么赚钱

先拆📕商单。变现链路很清晰：快速起号，粉丝做到1000，开通蒲公英，接品牌广告单。千粉账号一单广告的价格，基本落在150-180元；粉丝量级越高，客单价也跟着往上走。

再看多多视频V计划。它的玩法和抖音中视频计划很像，平台按有效播放量给创作者结算。你可以直接在站内做号，也可以走站外认证：抖音或快手10万粉、📕5万粉就够。每个月还有300-750元保底收益。V计划分V1到V5五个等级，同时区分原创和二创。站外认证过来的账号，基本都是V4起步，V4的原创内容每万次有效播放6元，二创3元。

两个项目怎么组合呢？核心思路是带着学员在📕把号做到5万粉丝，然后拿这个成绩去认证多多V计划。日常发在📕的视频，首发到多多视频上再赚一笔播放收益。整套打法真正的关键，其实是📕快速起号。

# 二、动手前必须理解的底层逻辑

先认识📕的流量大盘。目前它的月活超过了1.3亿，86%以上是一二线城市的女性用户。这群人的消费能力和消费欲望都非常强，所以品牌方把📕当成营销重地。换句话说，这是一个帮用户做消费决策的平台，用户质量和垂直度在市面上很难找到对手。当然也正因为软广密集，平台内容生态受到了影响。

📕账号分两类。一类是专业号，由大小商家或品牌完成企业认证，比如咖啡店、水果店、书店、美妆品牌、服装品牌等，申请成功后有专属身份标识、更强的运营能力和营销工具。另一类是个人号，个人注册、无需认证，但日常权益完全不受影响。

# 三、快速起号实操全流程

## 1. 养号：打地基

📕是公域平台里管理相当严格的一家，千万别用做其他平台的惯性思维去对待它。养号节奏按照这套来：

- 总共养3天。
- 前两天每天刷1小时同行领域的视频，点赞、评论、收藏、关注的比例控制在10:3:5:3。
- 怎么判断养好了？进入编辑资料往下滑，会看到账号等级。如果一级任务都做完了还是升不到“薯北鼻”，说明号没养起来，也就是俗称的“天残号”，这种号很难有流量。
- 第三天开始修改资料：简介、名字、性别、头像、地区、背景图。

设备规范也要重视：一部手机只能登录一个账号。平台能识别手机串码并自动绑定账号，一台手机频繁切换多个账号，很容易被盯上判定为营销号。尤其是这台手机运营过违规或封号的账号，再拿来登录新号，基本100%被限流。另外，多账号运营时不要图方便连同一个WiFi，尽量用流量，否则也容易触发营销号判定。

## 2. 起号前先看三个硬指标

- 粉丝满1000；
- 单篇笔记播放量超过2000；
- 账号没有限流记录，也没掉出专业号状态。

## 3. 五种起号打法

### ① 动漫号 / 影视搬运号（更推荐动漫）

素材首选去抖音找。选号标准记好：
- 找100万粉以下的原创博主；
- 视频必须无水印，同行还没搬运过；
- 确认博主在📕没有账号，不能直接用他的专属名字或头像；
- 有些水印很淡，要仔细看；
- 优先选当前数据高于账号平均播放的视频；
- 优先拿续集，或者把视频头尾切掉。

想找到更多同领域博主，可以在已关注博主的页面，看系统推荐的其他博主。

去重用剪映，按这套组合拳做：
- 空镜头：叠在原视频上，透明度10%，关声音；
- 滤镜：清晰度滤镜强度拉到70-100；
- 扫光素材：选9:16的比例，透明度10%；如果用16:9，注意结尾容易带抖音水印，同样关声音；
- 变速：原视频倍速调到1.1，声音变调；
- BGM：随便铺一条音乐轨道覆盖原视频，原声关掉。

发布频率：1000粉以前每天3-5条，过千粉后每天1-2条。发布时段集中在中午12点、下午5-8点。

### ② 游戏号（推荐）

选素材盯四个关键词：高清晰度、高辨识度、易复制、有梗。

- 高清晰度：去水印工具不会改变原始画质，所以源头一定要找高清素材。
- 高辨识度：优先找特点强的博主，比如声音特别有记忆点，粉丝量在5万-20万之间最理想。大博主不一定比干净的小博主好用；如果你觉得他有潜力，在📕开个小号帮他推广也没问题。
- 易复制：有些博主会把个人ID、独特元素嵌进视频里，处理起来很麻烦。这时可以反向操作：把📕ID改成和原博主大差不差的昵称，比如对方叫“蛋仔狼宝”，你就叫“蛋仔狼崽”，营造出他来📕开小号的错觉。
- 有梗：这个不强求。作者大号发过蛋仔派对爆款视频的对面视角，小号发过打游戏时微信弹窗“分手”的消息，都是靠梗意外爆的。

去重方法和前面完全一样。游戏方向优先选蛋仔派对、我的世界、迷你世界。

### ③ 漫画图文号（较推荐）

这一个方式难度比前两个稍高，但好处是原创度高、流量持续性好，熟练后一篇只要10-30分钟。操作步骤：

- 下载podo漫画、酷爱漫画、动漫之家；
- 选一部适合18岁左右女性口味的漫画，言情、偶像、虐心向优先；
- 从漫画里挑3-5张足够吸睛或猎奇的图片；
- 标题用“漫画名+一句简短的概括”；
- 文案直接用漫画作品信息里的简介；
- 发布时加滤镜/特效、配温柔的BGM、放📕自带表情，发布时间同上；
- 对标账号：933076827

### ④ 娱乐综艺号（较推荐，但注意别碰违规）

这个方向跟影视号的选材逻辑基本一样，反馈非常好。实操细节如下：

- 内容定位：明星综艺＋新闻八卦；
- 对标关键词：明星综艺、明星娱乐、综艺八卦、综艺吃瓜；
- 找更多同领域博主，同样从关注页推荐入手；
- 去重在前文五步基础上，还要额外补三招：加背景图，并单独给背景图挂特效（星星、烟火这类）；9:16长屏裁掉上下部分，16:9不用动；结尾有Logo的话直接删除。
- 对标账号：4297497929、6165667428

### ⑤ 盘点号（超级推荐，但制作时间更长）

盘点类视频有一个特殊结构：它由多个独立片段构成，片段间没有强关联，所以只要打乱顺序、改掉开头，就能把搬运内容做出很高的原创度。

准备素材时，可以选动物科普、搞笑梗、迷惑行为等内容；然后用关键词去百度、快手、抖音、📕找一张合适的背景图。

剪辑流程：
- 背景图放主轨道，加落叶、星星一类特效；
- 视频素材放背景图上一层，把每个片段切成分段；
- 将视频和音频顺序整体打乱，比如1换3、2换1、3换4、4换2，自由组合；
- 换开头：盘点类视频原本开头常是混剪片段，去素材库搜关键词补一段新开头；
- 封面用背景图，并在图上写标题；
- 原视频标题改成“原标题+1/2”；
- 视频较长建议分两段发，既能提升原创度，也更利于涨粉；
- 尺寸统一调成9:16。
- 对标账号：1580172441

# 四、📕流量分配机制详解

## 1. 笔记审核机制

笔记发布后，平台先激活“黑盒机制”，按规则识别敏感词、违规词和低质量图片。一旦命中，审核直接失败、不给曝光；机器判断不了的内容会被标记为疑似违规，进入人工审核。审核不通过，笔记就进了“小黑屋”——限流，个人主页不再展示。你可以把笔记分享到微信，点开看是否还能正常访问，以此判断是否被限流。正常审核时间是几分钟到十几分钟，如果避开高峰后仍然审核很久，多半是转人工了。

## 2. 笔记推送机制

审核通过后，平台的AI语义系统会对笔记做拆分：内容归类、打兴趣标签、收录关键词，随后推到粉丝首页和用户首页。系统会先给大约100个精准用户看，如果初始曝光阶段互动不错，笔记就会被推进更大的曝光池，表现越好推得越广。

这里要画个重点：互动权重公式=点赞1分+收藏1分+评论4分+关注8分。点赞、收藏、评论合计占6分，但关注权重最高，足足8分。所以必须在私信、评论和个人简介里引导大家先关注——关注后私信数量不受限制，还能顺带给账号和笔记加分。这套计算结果会持续影响首页推荐次数。前100个精准用户的互动很关键，发布后18-24小时的互动表现，也决定了笔记能否走向更大的流量池。条件允许的话，可以准备几个不同ID的小号去评论区互动，能起到助推作用。

## 3. 笔记排名机制

笔记排名就是用户搜索关键词后，内容在搜索结果页里的位置。排名越靠前，被点击的可能性越大。搜索引擎通过爬行抓取把笔记存进数据库，笔记审核通过后一般就会被收录。

有四类情况可能导致笔记不被收录：
- 账号多次违规，整个账号受到限制；
- 笔记重复率太高，被判定为搬运非原创；
- 笔记里出现大量广告营销用语；
- 发布后频繁修改：修改会触发二次审核，容易掉收录；而且二次修改的内容必须比第一次更优秀，如果改差了很可能被限流。

注意，搜索页的评分体系和推荐页不同，除了互动量、转粉率，还要看内容相关度和搜索点击率。想提升排名，可以这样做：

- 提高视频原创度：围绕热门内容展开，适当重复关键词，次数要结合视频本身调整；
- 提高笔记质量：优质内容能持续带来长尾流量；
- 提高互动量：互动好的笔记，在“综合”和“最热”里都能排到前面；
- 抓住黄金时期：发布后18-24小时互动高，会被判定为优质笔记进入更大流量池。

## 4. 笔记权重

笔记权重看起来神秘，拆开就三点：

- 原创度：低于60%时，不仅降权还会被限流；
- 互动率：即曝光与互动的比值，权重顺序是关注＞转发＞评论＞收藏＞点赞；
- 内容标签：关键词和内容的关联度要匹配，相关性太小会被当成恶意引流而降权；视频内容表达够优质，再配合互动率，权重就会上去。

## 5. 账号权重

账号权重被降，笔记很难被推荐。下面这些操作最容易踩雷：

- 一台手机登录多个账号；
- 昵称有广告或违规词；
- 个人签名放微信等联系方式（🧣和邮箱可以）；
- 头像违规、不清晰或带二维码；
- 私聊时发微信等联系方式或二维码；
- 多个账号共用同一个局域网。

反过来，这些行为可以养高账号权重：

- 持续输出原创笔记，会被判定为优质账号；
- 提高账号活跃度：让用户阅读你的多篇笔记并产生点赞、收藏、评论等互动；
- 保持定位，别随意切换内容主题；
- 在正文里嵌入话题性或互动性内容；
- 在评论区主动引导，作者自己留言或安排人留言；
- 持续做系列化高质量内容；
- 提升账号等级，等级越高权重越高；
- 让赞藏率保持在稳定水平；
- 善用新号扶持：新账号发布前几篇笔记时，平台会有特殊流量倾斜。

## 6. 📕首页推荐逻辑

📕首页是瀑布流，核心依据是内容相似性：你爱看A内容，系统就推带相似标签的B内容。推荐系统会参考你曾经的浏览记录，重点根据点赞、收藏行为做判断，并且反馈非常实时——刚点赞了一个早餐笔记，首页马上就会出现相关内容。

视频和图文的形式也会影响推荐：视频笔记的关联推荐都是视频，不会推荐关键词相似的图文笔记。你多给几个视频点赞，首页很快就会被视频覆盖。

系统判断两条内容是否相似，主要看两点：

- 内容标签相似：系统读取标题、文案关键词、参与话题等信息来判定，其中相同话题和相似关键词的权重很高；
- 素材相似：视频笔记在APP端首页点进去下滑，就能看到相似视频；图文笔记可以分享到微信文件传输助手，再点进分享链接，下方也会出现相关内容推荐。感兴趣可以自己动手验证一下。

这篇内容信息量不小，每个环节都能直接照做，建议先收藏。如果有细节想深入交流，评论区见。

当一个话题下聚集了大量文案风格高度趋同的笔记时，平台基本会把这个话题池里的内容整体推给用户。反之，如果某个话题下相似的内容体量不足，系统就会跨话题去寻找关键词相近的笔记来进行补充分发。

### ② 图片相似度也在起作用
图片相似度也是一个隐形推荐维度。推测的抓取逻辑是：在短期内没有关键词重合的笔记可供派发时，系统会倾向于推送图文样式、视觉风格相近的内容。这个机制只作用于图文笔记。

所以创作者一定要先研究关键词池，搞清楚该词下已有的相似笔记长什么样，争取在系统第一次冷启动测试时就拿到不错的互动表现，进而更快地进入下一轮流量分发。同时，通过拆解这些相似笔记和对应博主，可以快速勾勒出目标用户的画像，帮助账号更快调整内容定位和生产策略。

# 七、决定内容能否爆发的三项核心指标

这三项指标，基本决定了你的笔记能否出圈，以及能火到什么程度。

分别是：点击率、互动率、搜索结果点击率。

## 1、点击率
推荐逻辑一般是先窄推后放量的。平台会先把笔记推给几百人左右的初始用户，比如500人上下，观察打开内容的比例，这个比例就是点击率。专业号的初始推量会比个人号少一些，通常在500到1000之间。

点击率靠前的笔记才会获得更大的推荐量。

📕并没有开放曝光量数据，所以我们没法直接算出点击率。

## 2、互动率
当笔记被推到相对更大的群体，例如1万人时，假设点击率均值10%，互动率均值1%，那大约会有10个人产生互动。系统会根据这一组数据判断内容是否值得继续扩量。

点击率和互动率共同决定了内容是否会被更大规模投放。

## 3、搜索结果点击率
刚发布时点击率普遍不高，难以获得大量推荐，但一旦进入搜索结果页，就更容易被精准用户点开。如果被点击的概率很高，系统就会持续向精准人群推送，并在搜索结果里给予更好的排序。

这也能解释为什么有些笔记阅读量看起来还行，互动却极低；又为什么有些笔记前期没什么量，过段时间却突然被推成爆款。

建议反复研读，把📕的流量推送机制吃透，对账号运营和爆款笔记创作都会更有掌控力。
