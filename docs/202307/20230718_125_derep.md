# 普通打工人做干货型图文，平均月入 5000+

别再以为📕只有颜值和种草才能赚钱了。一个普通上班族，靠做干货型图文，硬是把副业做成了稳定收入源——平均每个月进账5000多块，这个案例足够真实也足够接地气。

这位创作者叫王多维，本职工作之外偷偷做📕。他最亮眼的战绩，是连着出了4篇千赞爆款，单篇商单报价最高冲到2800块。去年就已经开始持续变现，今年过完年短暂停了阵子，从2月到5月，连续5个月稳定月入5000+，这才敢大大方方把经验分享出来。

他分享的内容非常系统，基本覆盖了从0到1的全流程：

- 个人定位与账号人设怎么打
- 账号的“号设化”运营管理思路
- 如何用稿定设计搞定笔记视觉排版
- 三个亲测好用的选题技巧
- 干货型图文的内容创作方法论
- 总结复盘与避坑反思

这套玩法特别适合想引流、想接广变现、或者刚入门的新手朋友。他本人也说，这次分享实操性很强，对新人非常友好，希望和大家多交流。

如果你也好奇一个打工人是怎么在20分钟内写出一篇千赞爆文的，可以顺着他的思路去研究一下。完整版内容他已经整理在飞书文档里了，有兴趣的可以直接翻看。
