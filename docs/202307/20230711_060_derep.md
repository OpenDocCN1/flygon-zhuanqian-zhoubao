# 从背负五十万债务到单月两百万销售额，我用三年时间在多多无货源店群里走了一遍

作者锦李，天津。

大学毕业后我在国内一家上市女装公司做督导，2018年选择辞职All in电商。过去近三年的时间里，我的主战场一直是拼多多的无货源店群模式。经历过店铺数量冲到近五百家的巅峰，也碰到过被合伙人卷走全部资金的至暗时刻，直到今年才完成逆势翻红。

一路走下来，我能总结出的只有一个字：坚持。坚持到今天，终于等来了转机。

下面这篇内容，我把无货源模式从零起步的实操路径梳理了一遍，专门给电商圈的萌新做参考。
