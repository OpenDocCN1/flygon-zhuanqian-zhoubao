# 为什么大部分📕新人卡在原地？问题就这三点

看过太多📕新人账号后，我越来越确定一个事：做不起来、变现不了，本质上只有三个坑。

我自己是云舒，一个一直在试错新方向的产品人。📕上我三个月就把理财、大学生活、职场三个不同定位的号从零做到千粉，总变现也过了两万。

今年六月我开始接账号诊断，短短两周时间梳理了将近 350 个新人号，还做了十几个付费深度咨询，收入也有一千多。后来因为企业号认证和沟通成本变高暂时停了，但这批诊断的复盘很有代表性，总结出来跟大家分享一下。

真正拉开差距的，几乎都集中在这三件事上：

**第一，账号想讲什么，自己心里没数。**
很多新人一上来就发，容易把内容做成大杂烩。既想讲干货，也想做生活，又想蹭热点，最后用户看完记不住你是谁，平台也分不清该把你的内容推给谁。定位模糊，流量就散。

**第二，不会站在巨人肩上学。**
📕不是凭空原创就能火的地方。头部都在跑通的选题、结构、封面、钩子，都是可以被拆解复用的。新人常犯的错误是怕被说抄袭，所以从零开始瞎写。结果效率极低，走弯路。会模仿的人，先学会借鉴表达方式和节奏，再加入自己的观点，起步会快很多。

**第三，扛不住起步期的寂寞。**
前两三篇没爆、点赞寥寥很正常。但很多人一两周没反馈就开始怀疑、焦虑，然后直接停更。账号就是靠持续积累才会有复利。心态一崩，之前所有的准备都白费了。

这三点其实是环环相扣的：定位不清导致不知道学谁，心态没调整好又学不下去。所以想做起来的话，先把方向定死，再找对标去拆解，最后给自己一个坚持的底线。
