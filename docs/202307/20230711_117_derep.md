# 关于我开了 3 家轻食外卖店亏了 40W+这回事
作者：龙哥

> 别人都在教你怎么赚钱，今天我想聊聊怎么“避开亏钱”——用我亲身踩过的坑。

我在杭州某大厂做互联网运营，合伙人曾是项目经理，后来搞支付创业。当时我们聊了大半年，觉得大健康是未来趋势，于是决定先从门槛不高的餐饮切入，做轻食外卖。整个项目从头到尾都是用互联网打法来推：前端怎么引流，后厨怎么做品控，全是我们自己从零摸索。那段时间，钱是真金白银地亏掉，累也是真的累到不想说话。

前前后后开了三家店，最终亏了40多万。不过也不是完全没有成绩：复购率做到了31.1%，在杭州余杭区的同类外卖里长期排第一，评分4.9，还经常占据美团、饿了么的榜单。当时在梦想小镇还开了一家店，我自己叫它“梦想店”，名字很美好，现实很骨感。

现在把整套方法论和踩坑记录整理成了文档，包括制作SOP等等，都是真实数据说话，没有夸大也没有虚假。如果你也对轻食、减脂餐、外卖店感兴趣，建议看完这份分享，也许能帮你少走一些弯路。
