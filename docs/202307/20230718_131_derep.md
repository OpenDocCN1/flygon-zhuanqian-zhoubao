# 从 0 顾客到破百万收入，如何把一家初创小店做成当地知名品牌？

三年前，我在台湾恒春盘下一间近千平方米的旧厂房，月租只要两千元人民币，却砸了六十多万元改造。开业第一个月靠三款特色产品天天爆满，最便宜的产品一天能卖出一千五。但新鲜感一过，客流几乎归零。后来起起落落，还碰上疫情，最终却做到营收破百万，在高雄黄金地段买了房，最后把品牌卖了几十万。这篇复盘，我想分享我做对了什么。

![](img/9602e1b0c3717fab55c56902c3a8e7a6.png)

做实体真的不是做自媒体，它需要你投入大量金钱和精力，更要求你比任何人都懂用户和产品。下面我从产品与品牌两个维度来拆解。

## 第一步：选对赛道

刚开始有资源，产品简单又能体现在地特色，拍脑袋就做了个园区，只卖三款产品。结果前几个月人潮不错。可新鲜感退得太快，游客也减少，营收马上跌下来。复盘后发现问题出在赛道上。

### 研究政策行情

别觉得小餐厅不懂政策。像屏东有青年创业补贴，特定产业也有福利。我们查了官方资料，发现“文化+旅游”是被鼓励的方向，正好符合我们的调性。后来就是靠这个拿到政府媒合的机会。还要观察周边有没有新楼盘、工业区、产业聚落。这些信息能帮你评估风险、选准时机。

### 填补市场空白

接着去调研。我们看了当地名店，也研究了台湾其它景区做得好的店，画了一张竞品对比图

![](img/c36cf8a47f8c46dbd9d71ecb024aed3c.png)

拿来分析。发现很多店只有网红氛围，没把文化做深，有的甚至没有爆款产品，主打拍照好看。我们的装修不适合文青风，干脆走阳光温馨路线。当地能做伴手礼的店极少，把文创和餐饮结合起来的更是凤毛麟角。餐饮是红海，但红海中也有空白。找竞品要有参照物：有区域就对标区域名店；没区域就按品类找，比如做水果茶，可以看喜茶、奈雪、一芳。看到空白先别冲，蓝海可能是商机，也可能是深坑。我找到了台中一家对标店，产品形式类似，验证可行，才定下“在地文化+文创+餐饮”的路线。

## 第二步：吃透用户和产品

方向定了，就要解决人和货的问题。早期最贵的单品不超过60元人民币，但优质客人的单次消费却能到500到800元。什么样算优质？付费意愿强、认同品牌理念、愿意买新品。这些数据哪来？如果是实体店，CRM系统能调；我们靠的是进店聊天，从销售过程里摸出年龄、职业、城市、需求，甚至他们喜欢的竞品。把优质客户画像扒出来，发现主力是来自台北、台中这些六都的家庭或团体，年龄30岁以上。有了画像，获客渠道、内容方向、产品设计就都清晰了。

另外，顾客选你，未必是你家好吃，而是你的品牌满足了他的某个意义。《品牌翻转》里说，人们买的不只是产品，而是意义。我们问自己，除了吃还能提供什么？是家庭度假的温馨，是送人的体面，也是上班族回家后的一点放松。这些才是内功。

产品要小步快跑。最初定位卤味，招牌茶鸭蛋卤了15天，卤汁继续卤别的东西，成本可控。镇上有家卤味店没我们好吃，却总有游客买，我们也加了鸭舌鸭翅。老客夸好吃，可一个月下来销量平平。试了几次，果断放弃

![](img/0c2a56473e0d593e8bc2c41726ec712b.png)

原因有三：和店内风格不搭；卤味在人心里是宵夜，不是下午茶；定价偏高，新客难接受。后来我们盯住客户拍照分享的需求，把文化、趣味、颜值做进餐点。按人数设计套餐，菜单首页引导购买，把蛋并进套餐，降低价格敏感度；再放几个成本低、价值感高的产品，下单率明显起来。儿童套餐用饮料替代茶，再送互动玩具，孩子在园区吹泡泡，家长就在旁边拍照。我们还定制了鸭脚模具，做鸭脚饭团，撒起司炙烧或淋鹅油香葱，配鸭胸肉或卤肉，做成日式定食，好评很多

![](img/6180f84d21bc5931bc7b08af3ae1297a.png)

出餐不用专业厨师，按SOP走就行。餐点里的农产品再做成“吃饭礼盒”，二次销售。伴手礼定制周期长、起订量大，好在以前做品牌认识内地厂商，能接小批量订单，我们用预购制，先下单再生产，过年轻松卖出将近200套。这期间，IP形象“一颗会走路的鸭蛋”也立起来，结合场景讲在地故事，还吸引了不少网红来打卡。不断上新、不断试错，像喜茶、奈雪、瑞幸一样，抓到爆款就集中火力推。

## 第三步：文创品牌玩法

做品牌最好找一个文化母体。可口可乐1931年请艺术家创作圣诞老人，霸占了圣诞节这个母体；茶颜悦色从名字到包装都在强调古风茶文化。文创就是从主题深挖，同时打造超级符号。我们的超级符号就是那颗有鸭脚的蛋——垦丁热，就让它戴墨镜喝冷饮；有民俗景点，就做“场景+文化”的内容。

具体怎么玩？我总结了几条

![](img/64933bd1aafec907cb08c09ac9c3fbf6.png)

第一，附加价值。脑白金卖的是孝心，不是褪黑素。我们也拆过自己的附加价值：园区景色、月琴体验、朋友聚会的场景、一杯让人“度假”的饮品。这些情绪价值能留住人。茶颜悦色的文创也是干这个的。

第二，破圈。品牌前期别烧钱教育市场，有了用户基础再往外走。小米花了200万改logo，最开始讨论的只有设计师和米粉，后来媒体跟进，破圈成了大众事件

![](img/718b6fa97508964eacdee14a89bebce6.png)

破圈有三种方法。其一是异业合作，找价值观、调性一致的品牌联名。永璞咖啡6年做了400多次联名。我们选的是屏东一家麻油店，都拿过“屏东十大”荣誉，都在推在地农产品和文化包装。唯一不同是他们时间更久、受众更广，联名后互相导流。联名不能乱来，阳光风的我们不会找摇滚或工业风的品牌，那样不伦不类。

![](img/d7d78ef15f12a7ea3de884b8bfe9bafe.png)

破圈活动要有重合受众，才能跨圈传播。其二是KOL合作，我们多用中腰部和长尾达人，大部分免费。台湾博主往往缺素材，我们提供故事和探店资源，他们很愿意帮忙。后来入选政府“十大好店”评选（600家选10家），官方给了MCN资源，有50万粉的Youtuber拍片，甚至引来海外粉丝谈加盟。内容最好用测评或故事呈现，别硬广。其三是用户自发传播。产品好看、好吃，客人随手拍照发社交媒体，老客每年会带来三分之一的客人。我们的Google评分4.7颗星，近500条好评，没请水军、没送小礼物。靠的就是真诚服务——早期客人少，我亲自带他们逛园区、讲文化，积累信任，客人自然愿意给好评。

回头看，一家小店能活下来且活得好，无非是把赛道选准、把产品做进内心、把品牌做成文化。这条路虽然慢，但每一分积累都算数。

做一家有记忆点的店，不能靠一句话介绍完。

我们现在的起步打法很简单，先把好东西说清楚。因为这里的东西是真的吃不到外面的，所以一进店我们就带客人站在展示区前，把食材从哪来、怎么做的、为什么不一样，一点点摊开来讲。

B、门店体验这块我们放在后面细讲，核心就一句话：你要让客人感受到这家店和其他店不一样的态度。

去过很多店的人都知道，第一眼的感觉其实来自店员和客人的互动。你是敷衍走流程，还是真的在乎客人感受，这决定了品牌能不能被记住。产品再好，体验拉胛，口碑撑不了多久。我见过太多例子，东西不错，店却做不下去，就是败在体验上。

3. 产品打磨的底层逻辑

先说清楚，我们卖的文创产品本质还是消费品。

消费品的特性就是快，口味和审美转得很快。所以必须保持灵感在线，定期上新，持续做小测试，看哪款能打，为品牌引流。喜茶、奈雪、永璞、瑞幸这些头部玩家，新品速度都很快，就是为了不断刷新消费者心智，刷存在感。

今天分享两个实操点：怎么做出一支爆品，以及怎么让人持续有新品想法。

1. 怎么做出爆品

乔布斯那句老话我一直记着：产品人别被营销人干掉。未来拼的还是产品，产品是1，营销是0。

在我们不断试错上新过程中，出现过一款单品口碑炸了。忠实客群体很大，朋友聚会、度假开party，大家宁可不要便宜的手摇杯，来我们这里买贵一倍的饮品，一次就是几十杯。甚至有人自备冰桶，一次搬二十几瓶回北部。

这款单品的营收占比后来冲到了三分之一，在同品类里本地形成了一个小风潮。

它是怎么来的？

A、爆品研发靠洞察

瑞幸的生椰拿铁就是典型。它把咖啡奶茶化，同时抓住了颜值即正义，精准打中年轻人。营销上又紧跟热点，IP联名+品类创新，比如和椰云集团的土味包装联动，和哆啦A梦联名，一波接一波。

创业品牌可以学的是：先看清你的客人是谁，他真正想要什么。

我们店外区很大，客人从车位走到柜台，热晒是真实痛点。他们要的是极致解渴、清凉感。以前的茶能解渴但不够惊艳。后来我们做酸甜解渴、香气更清爽的方向。

就这样生出了柠檬茶。屏东本身就是柠檬产区，这款茶老少皆宜，除了嗜槟榔的酸味受众外几乎人人能喝。毛利大概在60%左右，而且不需要教育市场，手摇杯店和商超都有认知基础。

为了解暑，我们把冻乳酪蛋糕的概念换掉了冰淇淋，做了柠檬和茶味的乳酪蛋糕。造型用了《猫和老鼠》里的奶酪形象，和茶饮搭配，清爽不腻。

B、爆品的内核是品质

现成半成品不加工很难长久。品质稳定和供应链可靠，决定这款爆品能否持续爆。

对我们来说，供应商要过两关：品质是否达标，有没有服务过大型企业；能不能持续稳定供货。

很多人会问，初创公司上哪找这种合作方？

多跑原料展会，加入行业协会，线上搜行业供应商清单，资源都是找出来的。

台湾的食品供应链相对成熟，有中间商提供半成品。我们初期也找他们，安全有保障但成本偏高。

中间有个转折，疫情期间业绩吃紧，我们去县里工商发展促进会求助，他们给了不少资源，还介绍了蛋品和柠檬原汁的供应商，成本直接降了20%左右。

那个柠檬原汁供应商几乎垄断了屏东种植和生产，主要销往美国日本，甚至是迪士尼乐园的供应商。鸭蛋供应商也是台湾知名点心公司的供应链。背书就是广告。

C、配套动作让产品更爆

配套指线上营销+线下引导话术。

我们线上做得一般，线下话术花了心思。

客人一进店，我们会先问要不要做产品介绍，如果要，就重点推爆品。点单时引导加购。连锁店的套路，单店照样用。

门店销售不要问你要不要买，而是问你要带一盒还是几盒？

有活动时提醒客人加购送礼，点单时建议组合成套餐打折，接受度超过50%。

推爆品时，我们会用真实客人的例子增强说服力：这款原料很牛，牛在哪？这款很火，火在哪？Party必备，有客人专门带冰桶装满回家。十个里大概有一个会照做。

想把单店业绩拉起来，需要一点幽默感和员工个性，让客人觉得亲近。

2. 让新品源源不断

A、保持输入

我们2021年做的乳酪蛋糕，就是内地网红款的变形，模具好买、流程简单、成本可控。后来全联超市也做类似品。

食品行业很多时候是先在小圈层火，再扩散到大众。比如当年的西西里咖啡，美式+柠檬，也成了咖啡店常驻品。

灵感渠道很多：Pinterest、Instagram、Pinkoi、小红书、淘宝、TikTok、花瓣网，都是很好的矿。

B、找到主轴，再发散

大部分品牌都是先定主轴，再围绕它做延展。

医疗器械的主轴可能是精准检测，后续所有产品都围绕检测技术、疾病场景、设备规模去做。MUJI的主轴是简约实用自然，围绕这个做家居、文具、服饰的全线扩张。

我们自己的主轴是：在地文化+农特产品，用可爱纯真的视觉表达。

研发时先提炼关键词，可以是产品特点、异业联名、公司价值观，只要和品牌相关。先脑暴创意，再验证可行性。这个方法对产品开发和营销活动都适用。

![](img/36b01eeb970656fa850608ea8857cf4c.png)

C、跨界结合

大部分消费品的创新都来自跨界。周黑鸭出口红，马应龙做服装，江小白和雪碧联名，都是把不同调性的产品拼在一起制造惊喜。

跨界成功往往有共通点：产品组合、价值观互补、流行元素叠加。

落地时要回到现实：

1. 利润够不够？
2. 能否带来业绩增长？
3. 能否帮品牌破圈传播？

四、建立竞争优势

竞争优势是让企业卖得动、跑赢对手、强化品牌的重要基础。

当别人说起港口茶，会想到我们；当别人说垦丁有在地特色的店，会提到我们。

给三个新品牌可用的方向：

1. 初创期的成本管理

单店不具备规模效应，成本管理就更关键。

1. 开业初期先用半成品或中间商，除非你定位是精致下午茶或烘焙。
2. 客流稳定后按用量估算，和源头厂商谈长期稳定采购。
3. 时令菜和需冷藏的原料要控量。
4. 别因淡旺季差价囤保质期短的货，要算坪效。

两个小例子：初期别贪多做品类，思考有限原料怎么组合。我们用柠檬原汁做出柠檬茶、柠檬茶冻、柠檬乳酪蛋糕，再组合成套餐推销。

主食也用半成品，按份预分装，烤箱油炸几分钟出锅，味道比料理包好得多。

2. 产品与服务深耕，输出差异化价值

1. 产品唯一性

前面讲了很多开发思路，核心是做出别人没有的点。

我们的柠檬茶只有三种原料：港口茶原叶、屏东产带皮冷压柠檬原汁、蔗糖。内地的手打柠檬茶、鸭屎柠檬茶，也是在命名和品类上建立唯一性。

lululemon只做瑜伽服，这就是它的壁垒。

2. 体验营销

当功能趋同，就要靠体验分层。即便产品有唯一性，体验仍是留客关键。

我借用梁宁的峰终定律：人们评价一段经历时，高潮和结尾决定整体感受，过程容易被忽略。

宜家就是典型，样板间是峰值，一元冰淇淋是终值，人们忽略了逛累的感受。

我们的销售流程峰值在客人喝到好喝的产品后，店长开始讲用料、工序、在地故事，还设计互动环节，让客人闻到卤汁香气。

终值是离店时，我们帮忙指挥交通，或送园区鸡蛋花等天然纪念品，让人带走念想。

这些细节不起眼，但同类店做不到，这也是我们Google评分能到4.7的原因。

3. 聚焦目标客群，打造渠道优势

新品牌启动时，要用最少的接触点撬动市场。接触点就是销售流程的每个触达环节。

![](img/fcdbdba86082e1e10d482a374a3e0366.png)

从消费者旅程看，品牌接触点包括传播露出、线下渠道、产品本身。

我们结合优质客群特点和可渗透的接触点，来思考传播和销售渠道。

A、反推住宿点

买得多或后面还要赶行程的客人，我们会问住哪里，提供配送服务。聊天时也会顺带问最近住的新民宿、饭店。

我们发现高消费客群集中在高档民宿和五星饭店，于是整理名单，和饭店礼品部对接，摆我们的礼盒、茶叶。业绩虽小，但客单价高，还带来慕名客。

B、锁定优质群体

复购率高的客，主要集中在家庭、车友/遛狗聚会、企业团建。店面大、氛围休闲，像个中转站。团客客单约50-100元。

淡季我们就用团体客+伴手礼组合拉业绩。经工商发展促进会牵线，我们接触到中小企业的年员工旅游需求；旅行社淡季安排定制团，把我们设为停留点；联系中高端车友会策划行程；宠物中心和宠物社团也带来团体游。一个客户圈一传开，就源源不断。

C、用户习惯倒推传播渠道

看客人在社交媒体怎么刷、喜欢什么内容，就去那里。

附近有家嘻哈风格的店，客群年轻个性，他们在台北夜店投放广告，精准匹配。

我们的客以妈妈群体为主，晚安养颜茶很受欢迎，于是和冥想、Yoga团体、连锁舞蹈教学做异业联名推广。

每一个体验、每一个触点都在定义品牌。前期可以大胆开脑洞，实践中用三条标准筛选：

1）是否有品牌说服力，能持续产生订单；
2）接触点越少越好；
3）ROI是否值得投入。

总结

以前谈品牌很空，现在做品牌才知道，表里如一、每个接触点都下功夫才是关键。
