# ('战略不是定目标，重要的是选路径', (2, 17))

很多老板谈起战略，第一反应就是定目标：明年营收翻倍、市场地位冲前三、产品线再上新。但目标本身并不能让你赢，真正能改变战局的，是你选择哪条路去抵达终点。一个团队的目标可以一模一样，因为路径不同，结局可能天差地别。所以，战略真正的内核，是路径选择，而不是数字设定。

为什么实战中聊战略和管理，总觉得像隔着一层雾？因为成功的过程很难复盘——你很难精确指出，到底是哪一步神操作让整个局面盘活了；但失败却非常鲜明，几乎每个坑都有迹可循。每次踩坑复盘，都能提炼出一条“绝不能再犯”的教训，一层层叠起来，就变成一份专属的 Stop Doing List。

别小看这份清单，它的威力远超那些宏大的目标。它能让你在错误的路上及时踩刹车，也能让你在面对诱惑时保持清醒。不想走弯路，先知道自己有哪些路不能走。这本身就是最好的战略。
