# ('陈启宗：创造可持续地产商业新模式的几点思考', (2, 23))

市场是一面镜子，你怎么对它，它就怎么回你。真正愿意敬畏市场、跟随市场规律的人，最终会发现钱正流向自己的口袋。这个判断，来自陈启宗关于地产行业可持续商业模式的思考，也是他反复强调的底层逻辑。

陈启宗这份题为《创造可持续地产商业新模式的几点思考》的分享，并没有把目光只停在短期收益上，而是更关心一套模式能不能持续运转、能不能穿越周期。在他看来，地产想走出一味拼规模的老路，就必须从“尊重市场”出发，重构商业规则的每一个环节。
