# 一、一场睡播带来的业务新路线

我2008年从电网海外业务、2B外贸转到互联网直播产品开发，后来才自己下场做 TikTok。

2021年3月因一次突发情况入局，起步是 TikTok 短视频。

（1）短视频 + 独立站带货
2021年5月到2022年2月，先做短视频矩阵导独立站，站是 wordpress + woocommerce，用 AliExpress 一件代发。
那段时间流量很猛，硬伤是转化差，外国人看了视频不买单，只能靠量取胜。期间学了剪辑、搬运等各种技巧。

（2）短视频/直播 + 独立站/英国小店带货
2022年2月开了4个小店，除了老路子外尝试直播。运气好的一次跑起来了，便开始投人手，直播间外包给老外，一小时400块。4个月总营收1000多人民币就止损退出了。
这个结果跟团队能力有关，也有人跑出来成绩。

（3）娱乐直播 + 私域 + 独立站带货
真正的转折从5月开始，先做了照片墙互动游戏直播，后来跟同行做了点大屏项目。

![](img/758b1cf1d1c7784a4d85d8515d178a97.png) 

【照片墙互动游戏，逻辑是谁点赞或者送礼物就上墙，有各种不同形状的照片墙】

![](img/83212e761a1bbe8c9497ed35609f386f.png) 

【点大屏项目，逻辑是谁送礼或者谁活跃就点谁的个人空间展示他的视频内容，让别人去关注他】

前两个项目没赚大钱，但数据反馈不错，找回了当年做秀场策略开发的感觉。于是双线并行：一是把抖音的互动小游戏大量搬到 TT，二是自研第一个秀场项目：睡播。

互动小游戏的原理很简单，用户参与就有感，送礼越多体验越强。电脑跑程序，手机对着屏幕播，纯无人，24小时稳定在$20-500不等，玩法越新收益越高。

![](img/83212e761a1bbe8c9497ed35609f386f.png) 

睡播的玩法是主播在直播间睡觉，有人送礼就触发音效、视频、烟雾灯光等特效，制造被吵醒的感觉，主播会配合搞怪、跳舞、扮演被惊扰的状态，用户反馈很好。

运营策略也很粗暴：矩阵直播间，有流量就开，没流量10分钟后重播，薅 TikTok 的急速流。新奇形式很容易被推。

最好的一个小时能到200多美金，扣掉平台50%抽成后到手；普遍水平一小时130美金左右，一天1000多美金。这还是普通间，澳洲的 Jakey 一周能撸3-5万美金。

成本呢？小游戏完全无人，一间只要一台电脑+一台手机，额外成本是买代码和找程序员改代码。

睡播也差不多，电脑+手机+一个能动的真人主播，40人民币/小时，直播间搭建500块搞定。电脑都是人人租的，150一个月，再加一个互动程序。对比之下直播带货就不香了，直接放弃。

这段时间我们定的原则是：要么真人零参与，要么主播只要能动就行，互动全交给程序，把成本压到最低。睡播主播40块一小时，后续自播项目都沿用这套逻辑。

私域是放弃带货后的第二条线。最初带的成人用品，比如等身硅胶 WW，售价1000-3000刀，成本1000多，物流2000左右。

随着娱乐直播间越来越多，粉丝进福利群的人也多了，直播场景里的道具也变多，我们发现观众经常问场景物品哪里买。

于是把人拉群，美女主播的粉丝群里 WW 转化特别好，后面又加了主播形象定制的抱枕、小薄毯、手机壳、耳机等。

最后发现同样的定制品，放在独立站上，用户也很愿意用自己喜欢的图片来做，所以又选品做单品站，并摸索了下谷歌SEO。

到现在，模式是扶持合作达人直播矩阵，粉丝进福利群二次开发带定制产品，测好品就放到单品独立站。形成了矩阵直播+矩阵独立站的闭环。

# 二、TikTok 的现状与机遇

TT 上机会确实多，但不是谁都能抓得住。

从2021到现在，我见过太多人进进出出，包括我自己。2022年不做店群、不做无人直播、不撸商家仅退款，任何一条认真做都是千万级别的利润。

我当时拿5台无人直播手机在跑，后来怕连累MCN被封就停了。6月测过20个本土店，也因忙娱乐直播没深耕。机会很多，抓不住也是白搭。

（1）TT 的大盘
1、流量层面，TT月活大概15亿，重头在美国、东南亚和南美，这也是平台重点布局的区域。
从商业化看，印尼是TT电商本地化做得最好的，跟抖音在国内的布局很像，商城、团长、MCN、公会全上了，是海外电商的标杆。
其次是其他东南亚国家，美国受政治因素影响谨慎，南美基本还是处女地。

![](img/93863497cbfdb64fd5fe9f12707333d1.png) 

2、平台动作，电商仍是商业化主线。之前的商家店铺模式在东南亚外基本被抛弃，现在主推全托管，简单说就是商家供货给 TT，TT 自营卖再分润给达人。

听起来完美，实际很难。用户电商教育不足、购物属性不够，TT在用户心智里就是看达人卖廉价货的地方，很难转。
而且闭环需要足够利润，要么压商家和达人，要么提溢价，TT目前都解决不好。再加上 Temu、Shein、AliExpress 的挤压。

作为小玩家，我的判断是：平台电商 TT 自己都没理顺，商家乱战等于火中取栗。大玩家看不上，小玩家没资源拼。达人想喝汤只能看平台补贴什么时候结束，可以兼职玩玩。

（2）TT 的机会点
平台本质是娱乐流量生意，是靠视频和直播展现个性，好玩新奇才能留住人。
有人输出内容，没人就当观众，流量就这样形成了。

很多人拿抖音类比，觉得抖音上的业务都能复刻到 TT。
只对一半。抖音上长出来的带货需求，是基于用户教育和前置条件的，拿 TT 类比不合适。

更准确的说法是，所有和流量相关的抖音业务都能在 TT 复现。电商最不适合，因为转化链条长、供应链长、售后长、账期长、履约成本高。

不带货、只玩流量，想象空间就打开了。

1、秀场娱乐直播
直接变现打赏。欢聚、赤子城、雅乐出海多年，秀场依然坚挺。
现在 TT 直播个人只要千粉就能开，不用实名，好做 IP，账号可以周抛月抛，矩阵上机真人都OK。
有能力的可以签本土公会拿资源，没能力的个人直播找项目就行，抖音快手 BIGO MICO 一大堆项目可搬。会点技术把互动效果加进直播间，更有优势。

2、游戏
一种是游戏直播，有能力的做小游戏互动无人，没开发能力的露脸打游戏做半无人，对主播要求低，会点外语即可，东南亚华语区也能播。
另一种是做免费游戏网站，用短视频或直播导流，靠广告变现。爽文网站同理。

3、独立站导流
独立站能绕开平台电商定位和调性限制，不受履约约束。
玩法一是矩阵内容薅免费流量，短视频矩阵或无人直播矩阵都可以，无人直播还能活。
玩法二是广告投放，做优质短视频投 TikTok 广告导流转化。大力出奇迹是矩阵，技术流是投放。

4、达人带货
目前不看好，但有手就行，适合从抖音平移。平台现在调整策略，东南亚流量变少，新自营商城会给大额补贴，入门玩家可以玩。
国内鼓吹达人带货的可以忽略，赚钱圈很多 MCN 可免费挂。不想挂 MCN，东南亚有虚拟账户可回款。

5、做公会
官方跨境公会难搞，信息不公开。买的话很贵。有资源想本土发展，本土公会资质反而容易，推荐搞。
国内想玩玩可以搞野生公会，不叫公会，就是招一堆人自播，自己管理、分成。能玩多大看项目和策略。

6、本土电商
本土店铺依然能做，未来电商会向本土靠拢，跨境要自己干。关键是供应链，搞不定可以盯全托管平台的商品。

7、培训
理论上最赚，但我放最后，现在大部分人赚不到钱，培训也难做。做得好的要么项目在跑，要么就是割韭菜。
