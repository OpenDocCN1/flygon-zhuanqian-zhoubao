# 贫民背景如何拿到 qs19 的名校 offer？

高考只有369分、家境也很普通的我，后来却拿到了QS排名19的世界名校录取通知书。很多人觉得不可思议，但我想说：起点低，真的不代表终点低。

最近在龙哥盟再次露面，距离上一次分享已经快三年了。没想到还能被“CCTV”翻牌，受宠若惊。这次不聊搞钱，想跟大家聊聊一个特别的话题——贫民家庭出身的人，到底怎么逆袭拿下世界名校offer？

我把自己的完整经历和操作路径都整理成了一份文档，细节很多，包括怎么规划、怎么申请、怎么克服资源匮乏的问题，想看的直接点链接就好：
