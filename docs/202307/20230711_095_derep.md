# 图片数字人视频制作全套教程

一张图就能做出爆款视频？图片数字人全套玩法拆解

大家好，我是郭耀天，圈里人都喊我郭少。混圈四年，最近看到有圈友在研究“老人语录”视频，自己也跟着琢磨了一阵子。今天不绕弯子，直接把我实操下来的细节全部分享给大家，熟练以后最快三分钟就能出一条片子。

最近在视频号和抖音上刷到不少小和尚、老人讲经典语录的内容，一开始我还以为是真人实拍，后来仔细研究才发现，这些视频全都是靠一张图片生成的，圈内管这个叫“图片数字人视频”。现在的工具已经能让你在几分钟内批量产出这类短片。不少玩家利用视频号的“展示功能”拼命往👸号导流，我认识一个兄弟，靠这波操作硬生生做到了两千万👸号粉丝。

不过目前视频号的展示功能入口已经被关闭了，你可以打开自己的视频号，点右上角看看有没有开通展示功能。要是你还开着，恭喜你，赶紧全力运营，别白白浪费这波红利。![](img/4333f0d8d8387fd9d7f769219bfa00d9.png) 就算没开通展示功能，账号做起来之后照样能带货、做其他变现，涨粉速度依然非常可观。

一旦开通了展示功能，就意味着视频号火了之后，粉丝关注视频号的同时也会默认关注👸号。![](img/2003d08f9642ea9b988f0cb1ff9de12d.png)

下面说说我最近研究的制作细节。目前这个玩法偏国学方向，但实际上各行各业都能套用，大家可以根据自身情况灵活选择。核心逻辑就是用图片快速生成视频。其实抖音火的时候就有类似的玩法，只是以前的画质不够好，现在借助AI绘画能直接产出高清人像，整体质感提升了一大截。

过去大家习惯从网上找图片，再经过各种处理做成视频；现在主流做法是用AI绘画工具直接生成高清人像。绘画工具里，行业天花板依然是Midjourney，不会用MJ的同学也能用搞定设计、无界AI等替代品，只要能生成高清人像就够用了。

视频制作软件这块，国内有闪剪，但效果一般。国外主流是D-ID和Heygen。Heygen成本太高，我目前没测过，一直用的D-ID，出片效果非常到位。有朋友说D-ID也不便宜，下面分享一个低价甚至白嫖的玩法。

方法一：无限注册账号拿体验额度。一个体验账号大约能制作10个视频，配合“无限邮”这类工具，注册一个主邮箱后，在地址后面随便加个数字就能变成新邮箱，验证码依然发到主邮箱。用完一个就再换一个注册，白嫖起来特别方便。

![](img/71d29cafe88ce0775f5c5e16f36271e3.png) 使用D-ID时如果打不开，可以开魔法，毕竟是国外平台，多试几次一般都能访问。

方法二：去淘宝低价买权限。嫌麻烦的话，直接找人代开会员就行，买最低门槛的，大概38元。开通时会让你提供支付链接，对方会绑定一张支付卡，注意千万别绑自己的卡，因为支付不需要密码，扣款速度很快。当对方帮你开通最低权限后，那张卡还挂在账号上，这时候你再去点升级、付费，就能直接开通最高级权限，可以制作一百多个视频，够用很久。多开几个账号囤着，用这个方法能省下几千块。![](img/a394a5719be8d48cb97496135b8a84e3.png)

接下来是制作流程。打开D-ID登录账号，把准备好的图片传上去。系统是英文界面，可以网页翻译，也可以下载一个“火山翻译”插件，这个插件很给力，很多难啃的页面都能直接翻译。然后点击创建视频。

![](img/00ed852a9013349795ba45f8960cfec0.png) 进入创建页面后，上传你前面用AI绘制好的数字人图片。这里我实测过，目前只能处理人物图片，其他类型的图生成不了。

![](img/6e70c5cd5307aedcdb4e2238cfeb1597.png) 图片选好后，点击右上角添加音频。你可以用系统配音，也可以上传自己的声音，更常见的操作是去抖音、快手搬运热门音频，直接下载下来。这里有个小技巧：系统能直接识别视频里的音频，不需要你单独提取，所以直接传视频文件就行。

![](img/6ee34f9ef2a7c54259e31df84296e044.png) 音频或视频传完后，点击右上角的“生成视频”，等一分钟左右，一条作品就出来了。

![](img/9f82ed6e2b3d7c0a720712c4d52f7385.png) 生成后点下载，你会发现视频带了logo，需要借助剪辑软件处理一下。

![](img/d3c6fa50ca28dd55c9aaa88f8a2b1a2b.png) 把下载好的视频导入剪映，用“识别字幕”功能把字幕提出来，再调整一下文字展示样式，一条视频就搞定了。新手全部走一遍流程大概十来分钟，熟悉之后三五分钟就能出一条。

![](img/fbd105b56e8bd6c2e5b2d27d0e8b9ae2.png) 你看，一张图片就能变成一个完整的视频。这套玩法无论是做霸屏还是做引流都很能打，尤其是前面提到的视频号导流👸号。而且它不只限于小和尚、老人语录这类内容，很多领域都能复制，选一个适合自己的赛道就行。目前这个玩法好像还没有人系统公开讲过，我估摸着后期会有大批人涌进来。

最后多说一句：你刷到的很多爆款视频，背后可能根本不是真人，只是一张AI生成的图。所以掌握一点AI技能真的很重要，能做的事情太多了。尤其是当你需要大量视频做推广时，这招能让你快速量产；用来带货也很香，比如卖书，自己录一段音频，再借助系统生成视频，就能实现带货。

操作过程中有任何不清楚的地方，欢迎留言交流。
