# 全自动生产小说推文动漫视频教程，门槛极低
作者：龙哥

最近挖到一个很香的实操教程：用一套全自动流程来做小说推文动漫视频，门槛比你想象中低得多。更妙的是，这套方法不只服务于推文视频，拿去生成美女图片也完全没问题，妥妥的效率神器。

整套流程需要准备的东西非常直白：一个 GPT 账号、稳定的“魔法”网络环境、Stable Diffusion，再加上作者免费分享的那套程序，基本就齐活了。值得注意的是，这套方案是作者在 Windows 系统上亲测跑通的，苹果电脑理论上也行，但因为没有实际使用过，所以如果遇到问题，不一定能给大家提供解决方案，这点要提前心里有数。

作者没有整那些虚的自我介绍，纯粹是来分享干货的。具体的操作细节，都写在飞书文档链接里了，大家可以直接跳转查看。不过这里要提醒一下，评论区里有人反映最初没开权限进不去，后来作者调整了才好；另外也有人提到网盘链接可能被和谐了，如果你打开后发现内容丢失，那大概率就是链接失效了，需要留意一下。

总之，这份教程的价值在于“全自动 + 低门槛”，对于想批量做小说推文视频或者搞美女图片素材的人来说，是一个很值得去试的路子。链接已经附在下方，趁还能访问，赶紧去看。
