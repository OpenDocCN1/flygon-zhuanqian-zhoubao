# 📕店铺靠笔记带货破百万营收，我做对了什么？

前几天刷到一个搞📕的朋友晒后台数据，单月营收直接冲到七位数，更狠的是——没投过一分钱流量，也没开过一场直播，纯粹靠图文笔记和短视频带店铺货，女装、家居、女鞋、水果轮着卖，月月都破百。

我赶紧逮住他聊了一下午，把这套打法掰开揉碎整理成一篇实操干货。如果你也在做📕电商，或者正准备入场，以下这些思路很值得你琢磨。

先说下这位朋友的情况：做了三年多互联网内容，精通抖音和视频号，今年📕风口一来，果断下场。结果几个月内靠笔记带货连续突破百万月营收，靠的什么？用他的话讲——“有结果的数据，永远能告诉你什么是对的。”


评论区里问题也多，我顺手挑了几个关键的回答放这儿：

- 关于女装毛利：T恤类基本在20%~40%之间，连衣裙这类更能打，40%~80%的利润空间一点不虚。
- 关于水果利润：比女装薄，大概10%~30%，但好处是容易出单、客户复购也勤，走量很香。
- 关于选品对标：直接对标站内的爆款就行，别舍近求远。
- 关于原创度被判弱：大概率是你的素材已经被站内搬太多次了，换一批新素材，多上点实拍内容，或者把搬运素材和实拍混剪在一起；另外视频比图片更容易过原创检测。

把这几条记好，📕这条路你至少能少踩一半坑。一起继续在互联网里挖金子吧。
