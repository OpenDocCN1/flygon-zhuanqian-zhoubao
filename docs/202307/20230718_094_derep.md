# 赚钱新人从抖音亏损到转做视频号利润 50W+心路历程

大家好，我是龙哥，一个今年刚迈进赚钱圈子的新人。说实话，今天能坐在这里和大家聊这些，我自己都有点意外。

回想起来，我的经历算不上光鲜，甚至有点曲折——最早在抖音上做项目，亏了不少钱，后来才狠下心来转换赛道，把全部精力投到视频号上。从去年十月份开始，我一步步摸索，到现在累计变现已经突破了50W。具体拆开看的话，视频号短视频这块，三个月做到了25W+；视频号小店呢，四个月也拿下了25W+。跟圈里那些真正的大佬比，这点成绩真的不值一提，但对我来说，算是一个阶段性的交代。

刚加入赚钱的时候，我几乎一直在潜水，默默刷着各位前辈的分享，越看越佩服。今天终于鼓起勇气，把自己的心路历程写了出来，既是对过去的一段复盘，也希望给和我一样迷茫过的朋友一点参照。第一次发帖，有什么不到位的地方，欢迎大家多指点。
