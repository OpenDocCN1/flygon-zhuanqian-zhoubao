# 腾讯游戏为啥做出不了《原神》？
作者：龙哥

最近逛社区时看到一篇关于腾讯游戏与《原神》的讨论，观点挺有意思，结合于冬琪的那篇长文，我把关键内容转述一下。

2023年米哈游推出《星穹铁道》，据说很快就能坐上游戏行业第二把交椅，越过网易，直接逼近腾讯。首月流水高达30亿，直接把《王者荣耀》的巅峰纪录给压下去了。

腾讯当然没闲着，也尝试做类似《原神》的产品，但始终没成。按理说，腾讯不缺钱、不缺人、更不缺流量，怎么就做不出米哈游那样的游戏？

问题的根子，出在腾讯的游戏基因上。

过去腾讯游戏能赢，靠的是“赛马”加“考核”这套打法。简单说，就是利用自己钱多、流量多、但高层不太懂游戏的特点，用资本把大量人吸引进来，人多了总有真才实学的冒出来。然后用几十个指标盯着每个工作室，跑得好的就大力扶持，年底发奖金，有的工作室据说能拿到100个月薪水。重赏之下必有勇夫，于是腾讯就这么筛出了好几匹“好马”。

这套机制本质上是用80分的游戏配上100分的渠道去赢。在米哈游出现之前，大家拼的是渠道和运营，那自然没人干得过腾讯。所以，腾讯几乎没遇到真正的威胁。

但米哈游不一样——人家直接做出了120分的游戏，质量碾压同行，哪怕渠道一般，照样能火。甚至因为口碑爆棚，各个渠道反过来求着米哈游上架。

那腾讯为什么做不出这种级别的产品？说到底，在腾讯游戏体系里，赚钱是第一位的，渠道是王牌，好玩反而排在后面。大家的心思都花在怎么设计更多收费点上——收费越多，赚钱越多，资源就越倾斜。在这种机制下，不可能诞生120分的作品。

米哈游的第一追求是“好玩”，先把产品做到极致，其他都往后放。可腾讯做不到这种纯粹，因为当你埋头琢磨怎么把游戏做得更好玩时，隔壁同事正拿着100个月的年终奖炫耀——这种诱惑，没几个人扛得住。

今天先聊到这里，关于米哈游的创作机制，后面可以再单独展开。这篇原文将近两万字，感兴趣的话可以自己搜来看。
