# 月入十万＋的冷门信息差赛道，这个职业我赌十年

很多人问我现在还能做点什么项目，既不用重资产、也不用人海战术，还能稳定吃几年。

我最近在跑的一个方向，叫中医疤痕修复师。

第一次听到这个名字的人很多，但这个赛道正在悄悄起量。和陪诊、产康、移动美容师是一个逻辑，都是轻服务、强需求、靠个人就能启动，不用租店面、不用囤货。

我自己切入这个项目不到一年，反馈很清晰：需求真实、复购自然、客单可控。信息差还在，整个市场基本还是蓝海状态。

现在国内已经有几家机构在做这个赛道，体量已经做到一年几个亿的级别，但真正下场的人依旧很少。按我的判断，未来3-5年会是爆发窗口，生命周期至少能看10年，属于那种稳定持续变现的类型。
