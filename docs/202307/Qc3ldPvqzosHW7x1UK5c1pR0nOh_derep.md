# 四、具体操作拆解

## 1. 选品

确定能做之后，我立刻去考古加里找品。选品的心得星球里已经很多了，这里就不展开重复。

## 2. 素材准备

品敲定后，我把对标的素材全部拉下来做去重处理，然后新建一个号开始发作品。

判断标准很简单：单条基础播放能到 500 左右，就说明号和素材没问题，去重也过了，可以继续上量。

我是在 7 月 19 号中午 11 点发的第一条，播放破 500，下午两点又发了第二条，数据稳了就直接开播。

## 3. 直播节奏

直播前期没有自然流量很正常，我们要的不是直播推荐，而是短视频导流，所以核心是把直播时长拉起来。

新号可以报名新主播扶持，首播坚持 20 分钟就能领优惠券，有助于留人。

话术其实不用太讲究，等素材真的炸了，基本不用讲，坐着回答评论就行。把通用话术改改就能用。

直播时要时刻盯着视频号后台的推流情况，如果没推流就立刻补新素材。只要一条素材能爆，就反复怼，短视频只要持续来人就别下播。

直播间环境不用讲究，手机支架一架，背后贴张图就开。实在不想露脸就把图放大，主持人出声即可。进来的观众都是短视频带来的精准粉。

# 五、我踩过的两个坑

## 1. 样品问题

最致命的就是样品。素材一旦起量，必须第一时间把正品样品准备好，没有就找个同款替代，不然会被判定违规。我就是因为样品没跟上，直播间直接被封。

![](img/90c85d8a4d0fd0607f0b64e00193410c.png)

## 2. 不要盲目投流

这是血亏的一课。按我的实测，这类素材投抖加很容易被判定不过，导致加热权限被关，还会拖累自然播放。

# 六、小结

这种一波流玩法比较伤号，想长期稳定就得养一批账号轮着用。

整个链路里，素材 > 选品。只要短视频能爆，哪怕是偏门小众的品也能卖出去，区别只在于卖得多卖得少。

选品一定要选低价冲动型，价格是用户犹豫的最大点，别给对方思考的空间。

说到底视频号没什么新鲜玩法，去年这个时候也是一样的套路：短视频爆了直接开播，当时很多人都赚得不错。
