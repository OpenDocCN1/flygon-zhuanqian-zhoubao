# ('李善友：你是否感觉自己被困住了？', (2, 18))

你有没有过这样的体验：明明很想往前迈一步，却总感觉脚下像灌了铅，整个人被一种说不清的无力感笼罩？其实，这种“被困住”的处境，李善友老师总结过，无非就是三种类型：一是脑袋里思路打结，认知层面卡了壳；二是道理都懂，可就是迈不出那一步，行动跟不上想法；三是内心被情绪堵住，精神上动弹不得。

而且，很多时刻，有些感受是语言根本没办法讲清楚的。那种憋在胸口、找不到出口的滋味，恐怕比任何词语都更难熬。这时候，其实还有第二条路可以走——不一定非要靠嘴说出来，而是可以借助你创造的作品来表达。把那些无法言说的东西，揉进作品里，让它替你发声。

就像评论区有位朋友说的：太真实了。他自己跟这些“卡点”缠斗了十几年，才一层层突破过来。那种内耗的滋味，经历过的人才懂。

如果你也正卡在原地，不妨想一下：究竟是哪一层卡住了你？或许，答案就藏在你要创造的那个作品里。
