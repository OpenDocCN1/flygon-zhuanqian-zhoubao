# 普通人做项目总焦虑？读完100篇赚钱精华帖和十几个大佬成长史，我提炼了5个破焦虑的方法论

> 原文：[`www.yuque.com/for_lazy/zhoubao/sww9dg95ipig65w8`](https://www.yuque.com/for_lazy/zhoubao/sww9dg95ipig65w8)

最近整整一周都在焦虑里打转，回头一看，除了东想西想、自我消耗，几乎没推进任何事。心不定，事儿就全散了，连刻意练习都没做到。

我脑子里塞满了要做的方向：视频号减脂直播、视频号短视频、小红书提高代谢、小红书中医养生减脂、小红书心理减肥、抖音带货、英语涨粉视频……一堆点子，却没有一个锚点。

于是我换个方式，把赚钱的精华帖从头翻了一遍，结合市面上的项目案例和自己的现状，一路顺着人物线往下看。

陆续梳理了这些人：刘小排的AI与机器人创业、小鹅00后大学生做AI年入百万、沈小善的减脂电商、徐宿2020年起做知乎好物转小红书商业知识教练、梨云深耕小红书的MCN广告机构、黄小刀的ChatGPT创业、荷包蛋糕00后AI创业者、紫菜19年起做倒爷尝试百种小生意、陈雪雪姨从广告到倒爷再到短视频搞钱学姐播客、张可粒知乎写作AI写作教练IP创业、盗坤的淘宝生意与抖音MCN公司。

看完这些故事，我发现普通人做项目时焦虑的根源，都能被这5条经验对上：

**1. 风口会变，做项目要看当下，而不是过去的辉煌。**

不同年份、不同赛道的机会完全不同，借势当下主流才是关键。2020年知乎好物、外卖CPS、淘宝客是真赚钱，等到小红书起来、抖音短视频起来，注意力就迁移了。现在再去做知乎写作，平台规则和用户注意力的转移已经让这条路很难跑通。

从文字到图文再到视频，注意力在持续迁移。做项目核心就是顺势而为，踩住当下，而不是沉迷过去的案例。

**2. 每个优秀创业者都掉进过坑，穿越周期的能力比起步更重要。**

焦虑时总觉得自己问题特别大，看完别人的总结才发现创业必经低谷。流量、运营、产品，哪个环节都可能翻车，风口赚的钱后面也可能亏回去。

梨云2022年花3个月做涨粉18万的变现账号，因异常限流直接掉线，之后她重新研究、找对标、换赛道，现在做数码带货MCN月入20万。

徐宿2020年知乎好物起家，2023年转小红书，后靠商业教练沉淀优势。

盗坤早期做淘宝蓝海，后竞争激烈转抖音达人带货，成立MCN继续突破。

困难不是个例，是常态。决定成事的是能否持续解决问题，而不是一帆风顺。

**3. 行业会换平台会换，真正值钱的是周期里积累的能力。**

看完这些大佬的关键词总结会发现，他们今天做的事和5年前完全不一样。平台变、赛道变，但底层能力在叠加。

大佬和普通人同时看到新机会，大佬赢面更大，因为执行力、网感、写作、表达这些软硬实力已经练成了。平时不练，关键时刻根本接不住机会，就像平时不练肌肉，别人递来绳子你也抓不住。

梨云能快速把知乎理性内容改写成小红书感性笔记，就是因为有写作基础和账号运营经验。

徐宿转战小红书能迅速复盘框架、知识体系、文案产品运营，是多年沉淀的结果。

紫菜记下北京所有校区地址、尝试上百种赚钱小生意，连用信用卡都能变现，都是一次次小闭环堆出来的思维。

错过往往不是运气问题，是能力储备不够。先把小事做成闭环，垫脚石才会在下一次机会来临时出现。

**4. 看起来毫不费力，背后都是持续的奋力输出。**

你必须很努力，才能看起来毫不费力。像水面上的鸭子，表面优雅，水下双脚不停扑腾。

微博热搜、抖音年入百万的少年，很多人会觉得是天赋、家底、资源加持。但精华帖里的大部分大佬都是普通人，没有超常buff，靠的是韧性。

很多时候没有退路，负债、童年记忆、工资养不活梦想，只能用创业的不确定性去搏更大的收益。

盗坤做抖音前期投入大量人力，账号要放大时却被封；沈小善实体轻食店倒闭后转型电商，每天干到凌晨；小鹅还在上大学，周末赶着回校路上听课，星巴克从早坐到晚脖子酸痛。

对比这些持续复盘、坚持输出的付出，我连能拿出手的努力都没做到，就先焦虑了。信息轰炸让我们觉得月入10万很容易，一点困难就内耗。真正拉开差距的，正是在别人觉得难的时候还能坚持走到终点。

**5. 焦虑时，把视线从小我拉到大我。**

之前一周焦虑，我刷抖音小红书假装自己很忙，实际什么都没产出，越刷越焦虑。直到开始读精华帖，从小我切到了大我，看见更大的参照系，焦虑感立刻下来了。

流量卡点、业务不顺？盗坤初期不出单就研究平台规律、找数据、不断测试；木易留学业务受口罩影响负债，背着压力做淘宝几个月只下楼吃饭；小鹅因家庭原因高中哭到躲被窝，同龄人玩乐的年纪她已经开始创业。

这些事在创业者眼里都是必经的修行题，别人扛过来了，你想要的目标也必然要经历。

就怕比你优秀的人比你还努力。天才是99%的汗水加1%的灵感。赚钱里有大量真诚输出的商业知识和信息差，读完后信心和行动力都上来了。

破焦虑的核心就是行动：一焦虑就具体化，边走边干。像小排老师说的，保持盲目自信，相信自己能成事。

看完帖子后我也开始落地：
我手上变现最快的还是知识付费，把原本纠结的心理减肥赛道打开到营养吃瘦。

现在每天至少更一篇小红书、视频号短视频测试内容；公域没流量时，把私域沉淀的用户做3天吃瘦营激活，130个用户已入营；每周5次直播，对标修改话术提升出单。

同时也在尝试短视频带货，把日常好物挂橱窗。低成本试错，多开一条收入线。

在不焦虑的状态下，心才定得下来，事才能做成。减脂服务是长期赛道，我会持续投入。大部分人高估一年的变化，却低估十年的复利。

人和人最大的差距是心力差距。王阳明带弟子爬山，90%人倒在最后10米，不是体力问题，是心累。写下这次焦虑的过程，我发现问题都有解法，也希望能给同样焦虑的你一点力量，相信自己，未来是向上的。
