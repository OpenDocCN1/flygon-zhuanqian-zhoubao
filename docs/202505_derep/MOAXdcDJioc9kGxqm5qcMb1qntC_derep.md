# 一、n8n到底是什么？

可能有些朋友还没听说过n8n，但Coze、Dify这类工作流平台你应该不陌生吧？n8n就相当于它们的“威力加强版”——内置了400多款工具，社区生态开放，各种好玩好用的社区节点特别丰富；就算这些还不够，一个HTTP请求节点，基本能通过配置搞定你所有需求。最关键的是，它是开源项目，本地部署完全免费。

![](img/103ec25a1d629c9b70660ed5adf0fc72.png)

这是我自己用来批量给英熙娃娃换装的工作流。接下来我会从部署开始，一步步带你搭出这样一套自动化工作流。

# 二、本地部署其实很简单

n8n一共有三种玩法：

1.  官方云服务：要充会员，功能最全；
2.  本地部署：支持npm和docker两种方式；
3.  自己的服务器部署。

虽然官方服务功能最全面，但对于我们大多数人来说，部署一个社区版已经完全够用了。考虑到不是每个人都买了服务器，这次咱们就挑最简单的Docker方式来讲。用Docker部署的好处也显而易见：

*   能在干净的环境里装n8n，不污染系统；
*   更方便配置你自己喜欢的数据库；
*   避免因为操作系统不同产生的各种疑难杂症——Docker提供了一套完全一致的环境；
*   以后要迁移到新主机，也非常省事。

## 1、下载Docker Desktop

先去官网（地址：https://www.docker.com/products/docker-desktop/），根据你自己的系统下载对应版本，然后一路下一步装好就行。

## 2、部署n8n

先打开Docker Desktop，确保它在运行。然后打开Mac的终端或Windows的cmd，把下面这两行命令粘贴进去，回车，等镜像拉取完成、容器跑起来，n8n就安装好了。没错，就这么简单。

```
docker volume create n8n_data

docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

# 三、搭建你的生图工作流

## 1、先拆解工作流

![](img/1f66de55434b25b123d1d4d9f418cf1f.png)

大家看这个工作流，它主要由这么几个模块组成：

| 开始模块 | 每个工作流都必须有的起点节点 |
|---|---|
| 改图提示词生成模块 | 负责生成图片提示词，并整理提示词格式 |
| 出图模块 | 今天讲两种出图方式，各有利弊 |
| 上传网盘 | 把生成好的图自动传到谷歌网盘 |
| 循环 | 加上循环体，就能连续出图，实现批量生产 |

这两种出图方式，简单对比一下：

**第一种（gpt-image-1）**
- 出图速度快且稳定；
- 可设置的参数多；
- 输出格式规整，后续基本不用加工。
- 但按token收费，相对贵一些。

**第二种（另一种API方式）**
- 按调用次数收费，价格相对便宜；
- 但API输出的JSON包含信息特别多，需要自己额外提取需要的内容；
- 没有单独调整图片长宽比的参数，只能靠提示词控制，有时候会失控；
- 还有一定概率生图失败。

以上就是整个工作流的基本模块。接下来一步步实操。

配置完成后再测一次，图片就已经上传到网站了。![](img/7bbcfb3aa714b27bbb51bd977d53e0b1.png)

### 四、加上循环

所有节点都测试通过后，就可以接循环来批量生图了。添加一个 Loop Over Items。![](img/c90493b29502a9687fe5fafabedf71d0.png)

添加后会出现一个组件，把里面的 Replace me 删掉，让工作流首尾相连。![](img/3b75b062e1125f4398bcd81213bec097.png)![](img/57bb0de1b7dd2b256bbc89be14bfb28c.png)

配置页的数据不用管，等整个工作流开始跑，它就会自动循环；注意需要手动停止。![](img/71ca2ccf7e7b99ffd133c2b6c6d60804.png)

#### 需要注意

gpt-4o-image 偶尔会生成失败，那样后面节点拿到的全是空返回。如果想让循环一直跑下去，最好把画图节点后面的所有节点都设置为“出错时跳过该节点，继续后续流程”，这样就不会因为某次没出图而中断整个循环。![](img/6e238172c4af36d98658160006cd0a75.png)
