# (271 赞)视野大于认知大于财富。 视野，就是见过。读过的书、见过的人、走过的路、加过的社群，最后变 成了一个人的视野。

**先拓宽眼界，再升级认知，财富自然跟上**

很多人把赚钱当成第一目标，但真正决定你能走多远的，其实是另外两样东西：**眼界和认知**。而这两者之间，眼界又排在认知前面。

什么叫眼界？说白了，就是你“见过”的东西。你翻过的书页、打过交道的人、亲身走过的路、加入过的圈子——这些经历慢慢拼在一起，就成了你眼里的世界有多大。

一个人如果只盯着眼前的一亩三分地，很难想象更大的可能性。反过来，当你主动去接触新的信息、新的圈层、新的活法，思路才会被打开，判断力才会跟着提升。

所以别急着追财富，先问问自己：我的眼界够宽吗？我的认知配得上我想要的生活吗？把这两样修炼好了，财富只是水到渠成的结果。

就像评论区有人说的：抬头看天，才有视野；低头实干，才有深度。认知从来都建立在见识之上。也有人感慨，哪怕日子紧巴巴，也要咬牙留在能给自己带来新信息的圈子里——因为那束光，能照进生活和内心。

站得越高，看到的世界越辽阔。等你真正登上山顶，会发现连地平线都不再是边界。
