# ('(精华帖)(267 赞)做副业：如何月入 3000 到 20000？', (2, 36))

裸辞后想快速赚钱？先别急着跳，把副业跑通了再走。

最近有位朋友问我：如果直接辞职，怎么才能迅速搞到钱？我结合自己做项目和带人做项目的经验，写了一份完整路径，放进《赚钱宝典》里，今天分享给同样在纠结的你。

副业不是一上来就辞职，而是先保住主业，用业余时间试水，找到真正适合自己的项目，再考虑把副业转正。冲动裸辞的后果往往是：几个月过去还没定下方向，房贷、养娃、伴侣、父母、朋友圈子各方压力扑面而来，心态一崩，动作就变形——要么病急乱投医随便找个项目干，要么干两天又灰溜溜回去上班。

副业必须落到具体项目上，走完四步：发现、筛选、跑通、放大。先建一张项目清单，再按标准过滤。对准备辞职的人来说，最重要的标准是能否快速跑通，也就是快速赚到钱。赚钱的公式很简单：钱=产品×获客。

产品怎么选？优先级最高的是分销，也就是先卖别人的东西，别一上来就自己研发。做课、做社群、做文创看着光鲜，但耗时烧钱，可能产品还没成型，人已经撑不住了。分销让副业变轻，先跑起来，先见到钱。实体商品像快团团上的日用、食品，不用囤货发货，只操心怎么卖；知识服务像龙哥盟星球推荐、网盘拉新，交付不用你管。

另一条原则是选可复购的产品。一次性买卖意味着永远在找新客户，累且难以持续。可复购的产品大多具备高频或刚需属性——海鲜水果、坚果调料、保健品、儿童零食、文具、宠物粮、美妆、家庭日用品，以及知识服务类的家教、语言学习、健康管理、健身私教、心理咨询、家庭保险、旅行定制、账号代运营、企业内训、创业陪跑、记账报税、法律咨询，都算。

产品不用自己造，又能复购，接下来就一件事：找到第一批客户。先从微信好友开始聊，别一开口就想着去小红书抖音引流。近处的客户都接不住，远处来的流量更接不住。一对一交付的，标注好目标客户一个个聊；批量交付的，拉个群统一沟通。

做到这儿，第一块钱就来了。钱不多，但这是正反馈，证明这事能成。稳定月入三千到五千，是完全可以实现的。稳定下来，才算跑通，你也就有了不靠工资也能活的底气。

跑通之后琢磨放大。别一口吃成胖子，刚赚一万就想年入百万。从月入三千稳到两万，就是放大。放大的四种路径：产品不变，客户变多；产品不变，客户不变；产品变多，客户不变；产品变多，客户变多。第一点最基础，先想办法搞更多客户。第二点靠提价或提高复购频次。第三点要慎重，精力散了容易全盘皆输，除非你已经和三百多个客户建立了深度信任，加卖一两款产品自然有人买单。第四点等你有了助手、团队、社群再考虑。

获客怎么搞？一句话：到平台，用内容，留钩子，加微信，做成交。平台不限，抖音、快手、视频号、B站、公众号、小红书、知乎、头条，只要有人就有机会。别只盯着当下最火的平台，豆瓣、闲鱼、贴吧、知识星球甚至即刻，都有人在引流。老平台当基本盘，新平台当试验田，两者结合才稳。

内容不必追求文采技巧，先破除“我没什么可说的”心理障碍。记住三个字：真敢说。说自己的故事和真实感受，哪怕平凡失败也是你的一部分；别管语法修辞，先表达出来，不要试图讨好所有人；用口语，怎么写就怎么说，语音转文字也行。社交媒体本质是社交，不是写作。

钩子可以是免费群、资料包、工具指南、热点合集、知识库、抽奖、优惠券、试用装、测试报告——目的是把人引到微信私域。公域账号容易被限流删号，私域更安全。当然公域能直接变现也不必非要引流，能赚到钱的就是好域。到了微信，成交靠朋友圈、一对一私聊、群分享三种方式。

别忘了一件事：无收钱，不赚钱。很多人学了一堆，最后临门一脚没做，客户想付钱都找不到入口。把你的收款码和支付按钮大方展示出来，让市场给你最快的反馈。不必等自己变得多厉害才开始收钱。

目前一个对普通人友好的组合是：小红书引私域+快团团分销+微信群/朋友圈/视频号成交。当然仅供参考，每个人要结合自己的能力和资源来选。

当你稳定月入两三万，就不会再纠结找工作，而是操心时间分配和找助理组团队。到那时，你只需要保持节奏往前走。

所有项目都遵循这个逻辑：先发现项目，才能选择项目；先选择项目，才能跑通项目；跑通之后才能放大。如果不知道去哪里发现合适项目，龙哥盟这里有全网最全最新的项目拆解，以及配套的案例、人才、经验和工具，可以帮到你。
