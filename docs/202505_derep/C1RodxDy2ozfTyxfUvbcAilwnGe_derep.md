# 闲鱼月利润破万后，我是怎么绕开“一请人就亏”的坎，把团队带到30人

很多玩闲鱼的朋友，都会在一个节点上犯难：收入稳定了，人却快累垮了。每月利润能做到一万元上下，但选品、采购、回复、发货全得自己来，时间根本不够用。想找帮手，又怕利润被人工费吃掉，更担心辛苦带出来的人回头变成对手。这种纠结我太懂了，因为我也是从这个阶段一步步爬出来的。

从2019年开始，我用6年时间，把闲鱼从副业做成了主业，再从独自一人做到今天30人的团队，手里管着400多个账号。中间踩过无数坑，也总结出一些能落地的经验。这篇文章不打算写成流水账，只聊几个最关键的选择，特别是从1个人到10个人的过渡期，哪些事可以让别人干，哪些事必须自己抓。

先说结论：请人不会让你亏，乱请、瞎放权、缺流程才会让你亏。

## 一、第一次请人，请的不是“全能手”，而是“替代重复”

我第一次请人时，心里特别清楚：我最烦的是回消息。从早到晚，手机一响就头皮发麻，遇到“到手刀”的买家，十几条语音砸过来，真能让人崩溃。所以我的第一位助手，就是客服。这不是拍脑袋，因为客服工作最容易被标准化，也最能快速帮我省出时间。更重要的是，核心环节——选品和打爆款——还在我手里。第二位助手我找的是高中同学，让他管账，因为财务必须放给信得过的人。

我们当时的配置就三个人：我负责选品上新，客服处理买家消息和售后，财务负责下单、进货、对账。最开始几个月，每月总利润大约1.5万，扣掉5000工资，净赚和之前单干时的一万出头差不多。区别在于，我不再需要事事亲力亲为，每天最多花一小时发链接。

这个阶段最重要的原则是：老账号要攥在自己手里，新账号才给新人练手。老账号是你辛辛苦苦养起来的，权重高、转化稳，是全身上下最值钱的资产。一旦你把它交给新人，稍有失误，轻则掉收入，重则把号搞废。很多人请人后利润不升反降，九成是这个原因。

## 二、想扩大团队，先得想清楚为什么要扩大

第一个小组稳定后，我其实满足了一段时间。在县城月入一万多，身边很多人还拿着3000块工资，我觉得已经不错了。直到后来加入“赚钱有术”，看到不少同龄人每月流水几十万、上百万，才意识到我所谓的“小富即安”，不过是在舒适区里自我感动。

我认真反思，为什么收入一直卡在一万上不去？答案很扎心——懒。明明知道哪些产品能爆，就是懒得去上；每天有稳定收入，就不想再折腾。我意识到，如果继续靠我自己拼体力，天花板就在眼前。所以我决定把运营的活也慢慢分出去。

可招运营最怕什么？怕他学会之后自己单干。我的对策不是严防死守，而是从源头上选人。我很少直接招“闲鱼运营”，而是以“美工设计”的名义招聘。想做运营的人往往有创业冲动，而设计人员更容易接受执行型工作。面试时我会亲自把关，看对方性格稳不稳、野心大不大。操作上，我提供选品思路和内容方向，设计负责把图和标题做得合格，我审核后统一发布。表面上他是设计，实际上做了不少运营的活，但核心按钮一直在我手里。

财务岗我也坚持放自己人。万一有员工打听进货渠道、利润空间，第一次旁敲侧击，我当天就会请他走人。因为带着“学成跑路”目的来的人，你教得越多，自己死得越快。

## 三、解决三个现实难题：夜班、出错、复制

团队开始变大的时候，三个问题立刻摆在面前。

第一是夜班。以前都是我一个人熬，实在熬不动了。县城又找不到专职夜班客服，于是我们改成轮值：运营、客服、财务都排班，值班的人把手机带回家，一晚补贴30，有事就处理，没事可以睡觉。效果不错，前提是招人的时候要看中责任心。

第二是财务出错。订单一多，最怕错单、漏单、重复进货。我们的方法很土但很有效：列一张单子，每个客户和产品都登记，进货一项项打勾；发货后统一记录快递单号。填单号的时候，运营和财务双人复核，一个念单，一个录入，基本杜绝错误。工具再多，流程才是护城河。

第三是复制。我慢慢意识到，靠一个人管几个人是管不大的，得把团队拆成小单位。我们的小组标准配置是：1个运营 + 1个财务 + 3个客服（白班2人、夜班1人），预算有限就1人兼任运营和财务再加2个客服。小组里的分工非常清楚：运营管内容、上新和数据，财务管采购、发货、填单号，客服管消息和售后。当这套结构跑通，赚钱的就不是某个人，而是整个结构。结构越能复制，盘子就越稳。

## 四、账号不够用，才真正限制规模

小组跑顺后，我面临的下一个坎是账号数量。闲鱼这个生意，做到后面就是拼账号：你有1个号，别人有10个，他有100个，完全不在一个维度。光靠优化转化率和客服话术，弥补不了账号基数的差距。所以，我开始想尽办法囤号。

我试过三种方式，都可以参考：

一是员工开号。和员工一对一谈，用他们自己的身份注册，账号归团队统一运营，给一定保底费加提成。这里注意，千万别在办公室集体动员，否则会形成“别人不开我也不开”的僵局，私下逐个聊反而成功率高。

二是入股模式，也就是外部找一些人，出几千到一万，签协议，约定保底收益和出号数量。本质上不是要钱，是要号，有点像代运营，对方出号和本金，我们负责操盘，双方都省心。

三是个体工商户，这是目前最正规的路径。一个身份证能申请5家个体户，每家可以绑3个支付宝和3个闲鱼号，算下来一个身份证最多能开出15个号。很多人不知道这个空间，试过的人都已经靠这个把账号池做大了。如果不想员工持号，找亲戚朋友代办也行，手续不复杂。

## 五、人多了，管理靠系统，不靠吼

账号多了，人也多了，30个人的时候，再像从前那样挤在一间房里，已经行不通。人多容易闲聊，也容易抱团，小地方还容易被盯上。我的办法是：把办公室分成两间，客服一间，我和运营一间，财务单独坐，减少不必要的信息交叉。同时，用群控软件统一管理设备，上品都走草稿箱，运营下班前把内容排好，第二天客服一键发布。

管理上，我采用小组长制。小组长从内部选拔，优先选那些主动分享、有责任感的人。任命时明确告诉大家，日常工作找组长，只有大事才来找我。这样既给了我喘息空间，也让团队有了层级。

设备管理也关键。举个例子，我们现在的设备管理是运营负责制。每个运营管约130台设备，直接上百控群控软件上品。

其中100台分给客服用，30台留给自己做新品测试。每天晚上统一开软件上品、养号。设备管理的几个要点：每台设备都要打标签，责任到人；客服是售后第一责任人，发现问题立刻处理；运营每天抽查退款订单；设备故障马上报修、更换。我曾经有一批设备断网，客服没当回事，丢在一边，结果售后差评涌进来，账号权重掉得很厉害。从那以后，我定下规矩：设备问题直接跟考核挂钩。

做到400个账号的时候，团队大概是这样：每个客服组7个人，包含1个组长，配备100台设备，人均管15个号；每个运营负责2-3个品类，对接一个客服组；财务则与运营一一对应。运营的工作方式也变了，不再一个个选品，而是参考同行爆款找规律，用群控批量上新。最重要的不是某一个号多能打，而是整体投放量够不够。100个号每个每月卖100块，就抵得上一个号卖1万，而且更抗风险。

## 六、合伙制可以试，但别迷信

2022年我们试过合伙人模式，刚开始效果不错。但时间久了，问题就冒出来：创始人稍微松懈，合伙人就开始摸鱼；分账规则不清晰，对账对到头大；执行节奏不一致，效率反而更低。所以后来我放弃了纯合伙，改成自营为主、合伙人为辅。如果你自己执行力很强，又想尝试合伙，也不是不行，但一定要想清楚：合伙人模式能不能成，关键看创始人能不能持续带着大家往前跑。

## 七、最后一句真心话

6年时间，我最深的体会是：一个人可以赚点小钱，但想赚大钱，必须靠一群人。而带一群人的能力，不是天生的，是踩坑踩出来的。

如果你现在依然在纠结：要不要请人？员工会不会跑？工资会不会付不起？我能不能管好团队？我想说：所有人的开始都是一团乱麻，没人天生就会。别等到万事俱备再动手，先跑起来，边跑边修，路自然就顺了。你缺的不是完美方案，而是一脚踩下油门的勇气。
