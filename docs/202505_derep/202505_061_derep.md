# ('【赚钱认知】11 篇', (2, 12))

关于赚钱这件事，很多人其实不缺努力，缺的是一层窗户纸——认知。

最近看到一份非常扎实的“赚钱认知”合集，整整11篇内容，把那些关于赚钱、商业、思维的底层逻辑讲得很透。不是那种泛泛而谈的成功学，而是真正贴近实操、能让人停下来思考的干货。

这份合集来自龙哥盟星球，原文可以在语雀上查看（链接：https://www.yuque.com/for_lazy/zhoubao/uc3axdt779dmeenw）。

如果你也在寻找关于副业、成长、商业模式的真实经验，这份合集值得收藏起来慢慢看。公众号“懒人找资源”和“懒人专属群”中也能获取到相关分享。

认知到位了，赚钱只是水到渠成的事。别再埋头苦干，先抬头看看方向。
