# 一步步把流程搭起来

## 1. 进入 Coze

官网入口：https://www.coze.cn/home

## 2. 发起一个项目

左侧栏切到你的空间列表，右上角点“新建”。

![](img/6b59fae178bf4dace86b9ba157688f90.png)
![](img/a52daaf8e6388ad312382df1abdd41a9.png)

点确定后，画布上默认就有“开始”与“结束”两个端点。

![](img/dc9c4247c86d2ade2d5292e2cd3620c4.png)

## 3. 配置各节点

### 开始节点

![](img/9769c687be81f7fa31aa87b62e29b384.png)
![](img/09f02207e3d78380b54a392ce9d96ffc.png)

这个节点里要挂一个基座模型，提示词可以参考下面这版：

把你设定为一位有扎实学术背景的心理领域研究者，同时也是小红书上做动画科普的红人，擅长用黑白简笔画小人把深奥的理论讲明白。你负责输出两样东西：第一，封面标题，要求6－8个字，适配3:4竖版封面，主题抓人，比如“收入越高越心累”；第二，一段完整的心理故事，包含场景铺垫、心理动因拆解和应对方案。专业术语必须翻译成大众语言，内容要有实证依据，不能随意发挥；每篇至少给出3个能落地的认知方法，并且每个方法配一个生活案例。案例要从真实生活里挑有共鸣感的典型场景。全文采用先总后分的写法，开头制造情绪钩子，结尾给出行动建议。除了心理内容和线条小人相关的画面创作，其他问题一律不处理。

### 镜头拆解节点

这个节点本质上还是同一个模型，只是单独起了个名字叫“镜头拆解”。

![](img/08b335e7a0211e982d93c17ed8f7e8ad.png)
![](img/347e3ef785c1698146bf0d43556f3d82.png)

提示词参考这版：

你是一位专门做心理动画的导演，拿到{{desc}}之后，先按语义切出适合配音的短句作为字幕；然后为每条字幕补一个英文翻译；再给每条字幕配上黑白线条小人的详细画面说明，动作、表情、场景都要可执行。如果某个动作描述得太模糊，就主动细化补充；接着为每个镜头设定合理时长，让整条视频节奏舒服。只处理简笔画动画相关内容，其他请求不回应。

### 配音节点

这里调用语音合成插件 speech_synthesis：

![](img/8756e6b7e7455a543bce0bca99402e1e.png)

由于每条字幕都要单独生成音频，所以该节点采用批量模式运行。

![](img/e3f249cd4c2b8e5b90f965e654221d9d.png)

里面有两个参数要固定：speed_radio 和 voice_id。

![](img/5f0f4ec3cfa8aaabfeb66a19ef3b1872.png)

批量模式的并发数要改成1，否则容易错乱。

![](img/79a16a43f75e128648d832725dbc5191.png)

想换声音的话，可以在内置音色库里试听后再定。

### 画面生成节点

画面部分也是批量产出：先生成高清图，再自动抠掉背景，最后把中文、英文字幕和图一起排进画板里。

这一组一共三个组件：

![](img/b7156d1089ea71038aba9018c0fc20af.png)

具体参数按这些截图来配：

![](img/aec157b12f0650690614917821396ab6.png)

![](img/a287d4194687239a6406afce950aea4a.png)
![](img/5b2019c61ace507e74fcb04d661387d1.png)
![](img/b680b1dcceea37ddb5ad7d2afcad06cd.png)

画板里两个细节：画黑色固定框时，先拖出一个矩形再精调尺寸，蓝色起点代表图片素材，需要再往右挪一点；如果要让字幕跟着变量走，就先填好文字内容，再点左上角的 x 关联目标元素。

![](img/e619d7bc1e1e123f2265b762423e2ef8.png)

### 写入剪映

把剪映的两个导入组件先接好：

![](img/97c31ab78958f82396fb2ed46194db7b.png)
![](img/e34bf79ee9e33e65ce9f261d3f2ea99b.png)

草稿这边只需要建一次，所以参数设为“单次”。

![](img/678fa0a51f258750c6eac907551c58f8.png)

图片有很多张，要逐张加进去，所以参数要选“批量”：

批量模式下，先把画面组件和配音组件的输出作为数据源；然后在输入配置里，img_url 要下拉选择 easy_create_material 组件提供的图片地址；audio_url 也是一样的挑选逻辑。

![](img/80286ba49da6fd5d413c38bf743e8d8e.png)
![](img/8e97cdf29fc5a8616f85a4a21c360dbc.png)
![](img/31a489229ec8470684fa178f23df3637.png)
![](img/f32cdd5ca6a685c0d53c871af99c94d4.png)
![](img/b865a5b51c94df3844c474d8dfbb85c2.png)

同样，批量模式的并发数也设成1。

![](img/76da195b2a60d7936b9bd3931158f103.png)

走到末尾节点时，选择“导出剪映素材”。

![](img/0ff16c20f95d4f6b828fb7a3713bb55b.png)

运行成功后会吐出一个链接，复制这个链接，丢进剪映配套工具，点下载即可。这个配套工具就是社区里常用的辅助下载器，下文统一叫它“配套下载器”。

![](img/98ab7d28767332537510d67923efa34a.png)

# 复制这套玩法去别的赛道

批量跑一段时间后，最容易遇到的问题就是内容同质化。解法也不难：给角色换皮。把线条小人换成刺猬、狐狸这类更有记忆点的萌系IP，观感立刻翻新。

![](img/ef24176788a0858dd0a6a12e3dadd4f9.png)

心理赛道之外，只要内容本身有干货、画面有美感的领域，比如养生、科普，也可以完全套用这个模板，专业感和观赏性都能拉满。

高龄治愈画风示例：

![](img/5770fcfe7b476df1350c5afaba4e8396.png)

还能把整套流程打包成扣子平台里的应用，客户打开链接就能调用，内部细节完全不用露出来。

![](img/0e604e91d3067baf4f4ff6157283e9fe.png)

# 发布与分享

流程搭完想扩散出去，有两种路径：做成 Bot，或者做成应用。选 Bot 的话，以后可以做更多扩展，比如多个流程互相引用、模型跟不同流程串联。选应用的话，拿到分享链接的人可以直接使用，但不能查看背后的流程设计。

# 实操中容易踩的坑

有时候会碰上“引用不了前面节点的圆点接口”的情况，解决办法是把两个节点的连线重新接好：上游右侧的圆点接口，要接到批量组件左侧的圆点接口上。
