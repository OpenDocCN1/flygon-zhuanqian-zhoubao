# 建立自己的智囊圈

问我最宝贵的资源是什么，我会说是我在微信上的那群人。

一个账号打通，能把几乎所有卡点对应的解决者找出来。关键时刻有人点醒，帮助判断和决断。产品方面问许老师，笔记端的问题找富贵，矩阵扩张问柠柠，朋友圈文案写不下去时找虎牙。

基本没什么事是发条消息解决不了的。买飞书模版、车被剐找修车、搬家找收纳、处理闲置首饰，全都靠圈内朋友帮忙。

说到人脉这件事，前几天和Albert边吃椰子鸡边聊，他给了我一个更高维的理解。他举了龙哥的例子：Albert是一个更偏倾听的人，而他会主动去问对方对某个想法的看法。

我追问动机，他说每次准备启动新项目，他会同时找五个已经拿到重大结果的人，听他们怎么看这个赛道、如果由他们来做会怎么走，然后校准自己的视角。这五个人最好基因不同：做产品、做运营、做流量、做IP，这样才不会被单一视角带偏。

我问，如果五个人说法完全相反，甚至和我自己的判断背道而驰怎么办。他说，先拆解对方建议背后的出发点，迅速做出判断，快速跑通验证，拿到真实反馈再迭代。不要在纠结里消耗时间。

这句话直接让我第二天就推进了一桩搁置半年内耗的事。

那怎么让通讯录里出现愿意回你消息的好手呢？

第一步，打开 scys.com，输入关键词，筛点赞最高、带航海家标签的，联系鱼丸拿方式。第二步，发一份靠谱的自我介绍，要做到业务清楚、有点成绩、态度谦和愿意学。第三步，抛一个有质量的问题。

什么算有质量？情绪向的提问比如“AI写东西适合我吗，零基础能入行吗”就很低效。高质量的例子是：我已经在AI写作成稿端跑通闭环了，目前的拿单情况是这样【附数据图，记得转成图片，别用飞书链接，多一步登录就流失】，现在该深耕一个品类还是横向扩品？

更省事的办法是去赚钱线下大聚会，带着问题现场找对的人。问完记得加联系方式并补自我介绍。熟人的熟人往往能带来答案。

注意边界：别探隐私、别过度索取、保持价值交换。如果你还没在龙哥盟里认识人，就先从认识五个同圈的人开始吧。

# 定期和比自己高十倍的人线下对齐

那顿椰子鸡还带来一句刺痛的话：想保持高速成长，就要做朋友圈里最菜的那个。

找标杆也是同样的逻辑。你现在月入十万，就要研究月入百万的打法；月入百万，就看千万级的路径。别只盯数字差，要看行动差。比如他一天进千量，你只进百量，他多了哪些平台；你只做闲鱼小红书，他已经上了电商；他一天十个号三百篇，你一天三个号。转化率20%到40%的差距，往往能通过观察话术、成交节奏补齐。

这种信息线上很难拿到，真正含金量高的东西都在线下小范围交流。我复盘后发现，每次快速跃迁的顿悟，几乎都发生在活动前后，路上、晚饭、包厢闲聊时发生的。

今年三四月对我影响很大的几段对话：北京时，damo老师说，你们年轻人做事看似混乱却很蓬勃。

![](img/002d8a00f62ce9f35b1726d24becfe38.png)

紫菜说：赚钱里大部分跑通闭环的项目都能做到百万以上利润，只是普通人缺组织力和执行力的认知，难以把小生意做成大生意。

lemon说：所有事情都能用数据去验证。

富贵说：做用户画像不能用粗标签，要具象到：女性20-30岁、原生家庭条件差、是否有创伤、单身或恋爱脑、伴侣关系，收入水平、消费习惯、受教育程度……你要赚钱，脑子里要有她的模样。

刘小排说：传统互联网学到的是冷兵器，赚钱学到的是热武器。用热武器的打法回传统互联网就是降维打击。

他还开玩笑说：小鹅在群里装完逼一分钟关机了吗……

![](img/6d36a33ee6f5a0c46dbb319f75a3e0e9.png)

跑题了。总之，定期和高于自己维度的人线下见面，并提高质量高密度的提问，是加速成长的方式之一。

# 成为他人视野里最专业的那个

我的业务增长基盘是复购和转介绍。经常躺着就会有人来加我说“听xx说你很靠谱，我想让你帮忙……”

每个人的信息视野都是有限的：理发不会跑太远，家教不会跨城找，订酒店也不会翻到平台榜单十页之后。所以当你的专业在别人的可达范围内成为最优解，订单就会自己找上门，钱变成被动的副产品。

其中有两个要点：

①尽可能进入他人的视野。我喜欢看电影，曾加过几个影迷群，聊着聊着大家都知道我擅长家教，经常给我介绍学生。后来入赚钱，每次线下我都主动帮忙收会场、采访、整理稿件，只要参加过活动的人，大概率会记住我。在持续贡献的过程中，我自然进入了他们的世界。

②大方把你的价值讲清楚。很多同学自我介绍要么信息过载要么含糊避重就轻，这会错失机会。不要用模糊的标签去博注意力，别人听不懂你在做什么就不会找你。

有次我对象参加活动自我介绍，说“我做AI产品”“看好AI自媒体最近在试”。我当场想说，这等于没说。

后来他重新梳理了介绍。在330线下认识了大客户，在418直播间隙介绍了自己的站点，当场就有千万级玩家说“今晚最大的收获就是认识你”。在生态里，位置决定资源流量。

# 知识的裂缝

最近和朋友聊付费课程，我们都花过不少钱。有共识：好课可能贵，但精华就一两句话，能帮你跨过当下的卡点。

为什么讲师能说出这种话？因为对知识裂缝的理解不同。

拿交易举例，理想曲线是平滑的A，真实曲线是坑洼的B，里面全是细小的缝隙。在这些起伏里，投资者经历痛苦、兴奋、失落，对应大量操作细节。项目的底层逻辑其实都差不多，学两天就能复述。但决定结果的是实操中对细缝的体感。

比如私域的核心是转化，但转化点在哪？可能是朋友圈背景的一句话，可能是加微信后的第一句回复，可能是置顶引导，可能是公众号的跳转路径。

![](img/874edf169dd84e7160ed2f1f044b52fe.png)

再举个小例子，小红书店铺用虚拟资料导流，怎么把加V率提到90%？很多人会发短信通知。怎么发？分成三行：

我是xx

加微信xxx

领取xxxx

这样做的好处是方便复制，不会被当垃圾拦截。这些细节都是大量实操堆出来的体感，对没经验的人来说几乎想不到。

常有人问我你不用上课吗？当然要。赚钱活动基本都在周五或周一，正好撞考试。2024年我长期处于上午上课下午登机，提着行李回教室，在酒店背资料的状态。

# 找到注定的礼物，承受不确定性

“盈亏同源”第一次听是在传术士线下老大讲话时。意思是他因为懒得操作把大饼拿了很久赚到钱，也因为懒少做了动作而错失收益。第一次听只是印象深刻。

后来在孟岩老师的播客里再次听到，冲击很大：“所有命运赠送的礼物，早已在暗中标好了价格。”

![](img/31f53a69dbf6a528ceb2d74cdbd11a66.png)

盈利和亏损是同一决策在不同市场条件下的两面。因重仓获利，也可能因重仓回撤；因分散躲过极端亏损，也可能因分散错失高收益。任何策略的优点和缺点绑定，无法只取其利。投资里高收益、低风险、高确定性不可能兼得。想要高额回报，就要承受波动带来的焦虑、自责、后悔。永远没有完美方案。

想要得到命中注定的礼物，就要支付对应代价。他用《风吹半夏》里的女主举例，从码头到废钢再到自建钢厂，赚过钱也几乎没有安稳日子。无数个节点可以停下，但她没有。她不断创造，与世界的不确定性交手，在波澜里拿结果。

![](img/c91c9fbd3ea3089ce3f7625a68869a48.png)

为什么？因为她知道自己要什么，所以能坦然接受所有波动和痛苦，这是寻找礼物过程中必须经历的体感。

听完那期后我睡不着。原计划寒假去深圳，然后回西安恢复平常上学，暑假再去赚钱。我收拾好行李刚落地西安，住酒店过渡，第二天上课。突然觉得坐不住了。

我一直恐惧同学目光、老师尴尬、往返机票成本。那天我觉得这些都不重要了。每月机票两千起步，代课八百，杭州租房……我都接受了。

从灵感出现到举家搬到杭州，我只用了三天。创业是一种生活方式，永远在路上、永远在学习、永远和痛苦的不确定性交手，在起伏中找信念。我愿意支付代价。

今天刚好是我加入赚钱第二周年，就写这些吧。第三个年头再见。
