# ('(118 赞)项目转型的问题', (2, 16))

做项目最怕的不是眼下赚不到钱，而是面前摆着两条路：一条能稳定赚钱，却把人钉死在工位上；另一条看着能做大做强，但结果完全不可控。

最近有位圈友就卡在这个岔路口。他的状态很典型：直播这边，主要靠他自己一个人耗时间死磕，一年下来能有50到100万进账，但说白了是“用命换钱”，停播几天收入就断；短视频那边，可以招人搭班子，理论上能规模化放大，可这条路究竟怎么走通、能走多远，他现在心里完全没底。为了让大家给出更靠谱的建议，他还特意把前因后果整理成长图发了上来。

更有意思的是，龙哥没有直接给答案，而是说自己专门请了一位在这个问题上更有发言权的人来聊聊。评论区也瞬间变成了“世另我”现场：有人感叹这问题简直就是自己问的，坐标苏州想约着面基；有人分享说直播实在太消耗精气神，自己播了几年后放下后整个人都轻松了；还有不少人直接“插个眼”，等着蹲后续答案。

其实说白了，这就是“确定性”和“想象力”之间的拉扯。直播是拿个人时间换钱，天花板肉眼可见，但胜在稳定；短视频是靠团队撬动增长，空间大得多，但对应的是更大的未知。没有哪条路天然正确，只有你能接受哪种代价。

换作是你，会守着年入百万的忙碌，还是把赌注押给一个不确定的未来？评论区聊聊。
