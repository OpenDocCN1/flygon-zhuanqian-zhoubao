# ('(40 赞)马斯克「第一性原理」拆解引擎', (2, 22))

5月3号晚上，我鼓捣的第一款智能体正式亮相，名字叫“马斯克「第一性原理」拆解引擎”。同一天，我把它发到了朋友圈、赚钱、即刻和推特，配上介绍文案，邀请大家来体验。

三天后的数据有点出乎预料：推特上那条推广内容拿到了13万阅读，累计400多名用户上手试过，使用次数超过1200次。现在去Coze搜“马斯克”或“第一性原理”，最受欢迎排序里它常常占据第1位。

说实话，我一直不是那种热爱钻研技术的人，平时更关心怎么搞钱。但我有个习惯：有需求就想去解决。我自己想要一个能按第一性原理帮我拆解问题的AI助手，翻遍了Coze也没看到合心意的——好多智能体的提示词只有一句话：“扮演马斯克”。既然找不到，干脆自己动手。

我先在Gemini上搭了一个能用的版本，用着顺手，就想着国内平台也一定有人和我想法一样。于是又花了一个下午，把方案搬到Coze上。老实讲，国内大模型和国外还有差距，为了把体验尽量拉近，我反反复复试了好多遍，才拿到一版自己满意的效果。拿给女朋友试，她一下被打动了，说以前用AI都是直接要答案，这次居然被AI一步步带着思考，给了她很多看问题的新视角。

这给了我宣传的底气，但心里仍有顾虑：怕文案写得太夸张，怕技术圈大佬吐槽，有点像刚做自媒体时不敢露脸、刚搞钱时不好意思收钱。不过这些坎儿我早就跨过好几回了，咬咬牙，所有平台都发了出去。后来的结果证明，多平台发布是明智的：朋友圈、赚钱、即刻上反应比较平淡，真正把体量带起来的是推特。那边的流量让更多人体验到了这个智能体，后台也收到不少正向反馈。能切实解决一部分人的问题，那种感觉真挺爽；要是还能顺便赚到钱，那就更爽了。

当然，眼下还没用它变现。但我心里清楚，小需求背后也藏着商机；把一个个真实的小需求解决掉，才有能力发现和搞定更大的需求。评论区有人问智能体怎么赚钱，我的看法是：目前最现实的路径，是企业级定制化智能体服务。

这次经历，我给自己记下了几句话：一，别把注意力花在与业务无关的技术上——除非必要，能花钱解决的就不硬学，做个AI降临派，等AI把技术问题变简单，再用最低成本去利用它；二，做一个能发现需求、也有信心和本事解决需求的人；三，如果你对自己发布的东西没有半点尴尬，那你肯定发得太晚了。

谢谢龙哥老大——五一假期我把他在2022年至今公开发表的内容都读了一遍，收获很大，尤其是上面第三句话，往后应该会一直推着我往前走。也谢谢 @dontbesilent，从去年关注到现在，他重塑了我对商业和搞钱的认知，至少帮我多赚了五位数；从他身上我学到了“拥有解决一切问题的决心”。也是看他做智能体，我才动了折腾一把的念头。还想谢谢女朋友，她的鼓励和陪伴，一直是让我敢往前冲的底气。

一个非技术人做的AI小工具，谈不上高深，但这背后关于需求、行动和心态的复盘，也许对你有用。
