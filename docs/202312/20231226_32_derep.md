# 影刀项目代码免费共享，这个操作思路值得收藏



## (41 赞)影刀项目源代码的共享方法

作者： Rio

日期：2023-12-18

先说一个痛点：影刀免费版的限制确实让人有点难受，自动化流程只能自己埋头写，别人写好的东西没法直接用；创业版价格直接奔着几个 w 去，初创版又得靠不停邀请人才能解锁。

那有没有不花钱就能搞定脚本分享的路子？答案是有的。

这篇文章聊的，就是针对免费社区版用户，怎么互相传送代码实现脚本共享。

出海项目开跑之前把这个技能掌握住特别划算，以后航海中产出的脚本，大家都能互通有无。

直接上操作步骤：

# 1、把脚本打包

先打开项目，对着《主流程.flow》点右键，选择显示这个，再点文件所在文件夹

![](img/e8c65bda9f956eb1268d6a0650679fd6.png)

把文件夹打开

![](img/388ec00a073c8962cca3dfba5342f021.png)

找到 xbot_rebot 的父文件夹

![](img/f821cb169683ba10c6602b3bd5336099.png)

这个目录里装的就是整个项目的全部代码，把整个文件夹打包压缩，这个压缩包就是代码的全部内容

![](img/480374e226d658bd7e4cdb88421ef7fc.png)

# 2、把脚本装进来

拿到作者的代码压缩包之后，新建一个项目，不管是手机应用还是 PC 应用都行

![](img/7e5cf56e18235e204e207590418439d7.png)

还是同样的操作，右键《主流程.flow》，点显示这个，进入文件所在文件夹，再往上进到父文件夹

![](img/4177ab979694e2c2b79adffe40319065.png)

把这三个目录整个删掉

![](img/f87d78ff247e929b04eab5d11ce7b624.png)

然后拿来流程 1 里的代码包，放到这个目录下，把那三个目录解压到父文件夹里。说白了就是：旧的全清掉，新的整体放进去

![](img/f75b20f5afde6df6d3858093a4674dd8.png)

切回影刀，给项目起好名字，方便之后找回这个项目

![](img/b765f272b52e06d36e0a1daf7d87f04e.png)

接着退出项目，再重新进去

![](img/2fce9a349875dcd2e42654d0c1f55b55.png)

![](img/1845a48bc1cd777ae238f60c7322d6ce.png)

这时候就能看到，所有流程和元素都已经就位，跑起来完全没问题

需要留意的一点：如果原代码里用到了市场上的指令，还是得自己手动装一下，具体装哪些，跟作者确认一下就清楚了

![](img/d77d09c97dbbf2b21f161b6491cfd740.png)
