# 进入赚钱 1 个月，我是怎样被割韭菜的
作者：龙哥

加入赚钱还没满月，我就被狠狠上了一课：599 元，买来一个教训。

事情的起因很简单。作为刚进圈不久的新人，我刷到一篇加了精的帖子，讲的是声音克隆项目，看着挺像那么回事，脑子一热就付费了。结果呢？对方收了钱就变了脸，第二天我再沟通，基本等于对牛弹琴，维权也以失败告终。

说白了，这就是拿新手当韭菜割。

我把这段经历写出来，就是想告诉同样想做声音克隆、或者有这方面业务需求的朋友：千万别找他！市面上有更专业、性价比更高的选择，别被那种看起来高大上的帖子唬住。

这篇文章发出来后，评论区也热闹。圈友“小天”说，他之前从另一个朋友那儿听说了我的遭遇，实在看不下去，就主动来帮忙。他买过两次烂尾楼，维权打了五六年交道，还代表业主搞定了其中一套，跟政府部门交涉几十次，经验相当丰富。他说，也不图什么，就是觉得能帮一点是一点，万一这点光能照亮别人呢。

还有圈友“Rio”一眼看穿：那个声音克隆，一看就不靠谱。“辰安”也提醒大家：但凡有人分享具体项目经验，还若有若无地引导你去找他，十个里起码有七个都藏着付费课。年底了，捂紧钱包，哪来那么多免费保姆级别的真诚分享？还有人说，一小部分人确实是把平台当跳板。

回头想想，我踩坑，主要还是因为不会分辨。但我也想借“小天”那句话收尾：遇到事别怕事，别闷头吃哑巴亏。如果你也碰上类似的情况，该维权就维权，该发声就发声，因为你掉的坑，可能远比你想的贵。
