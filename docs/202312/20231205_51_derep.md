# 新手做自媒体，别追风口，先把阅读和写作的基本盘做实

大家好，我是理白，一个白天看诊的医生，晚上在自媒体上写作，目前全网粉丝累计约25万。最近在赚钱圈里认识了不少想入局的新人，他们私聊我的问题几乎都一样：信息太多太杂，精华帖、风向标、老手心得看得眼花缭乱，进到这个赛道像走进了宝库，反而更焦虑、更怀疑自己、找不到方向。

上个月我有幸和赚钱的嘉宾老师连麦，围绕新人怎么在自媒体这条路上站稳脚跟聊了很久。把交流后的思考沉淀下来，结合我自己的底层认知，整理成了今天这篇长文。核心就一句话：不要只盯着热点和变现，先把自己的基本盘夯实了，盘子大了，收益自然会跟着起来。

我把这个体系拆成了三大盘，每个盘里各有三把关键钥匙。

第一盘是写作盘。做自媒体，输出能力就是货币化能力。这里需要的是加法思维、减法思维和乘法思维。加法是持续积累素材和观点，减法是把复杂的东西讲简单、讲清楚，乘法是让一篇内容在不同平台、不同形态上复用放大。

第二盘是阅读盘。输入决定输出上限。需要练的是深度能力、广度能力和迁移能力。深度让你读透一个领域，广度让你跨界看见连接，迁移让你把别人的方法变成自己的方法。

第三盘是人生盘。长期主义才能扛住波动。这里要建立圈子认知、品牌认知和稳态认知。向上社交去找机会，向下兼容去结善缘；用作品持续经营个人品牌；保持情绪和财务的稳定状态，才能走得更远。

这篇文章足足有一万两千字，是我把和大佬碰撞的火花和自己的实操经验都摊开了写。2023年已走到尾声，寒冬将至，正是为来年布局的最好时机。希望这针强心剂能给正在犹豫的赚钱一二年级的朋友一点底气。

我们一起把基础打牢，术才有可依，术才有可赚钱。
