# 在📕聚光里，还藏着 N 个百万级的捡钱机会
作者：龙哥

这篇文章的雏形，来自 11.11 航海家郑州局。当时我以组局官和分享官的身份，把最近在📕聚光投流的一线体感，以及对多个行业赛道的横向观察，整理成了一份分享内容。

整个调研，是围绕📕聚光眼下这一波红利窗口展开的。结果挺有意思：很多赛道在📕上已经跑通，而且是真金白银落地出结果的跑通。

更关键的是——这些百万元量级的聚光投流赛道，放在当下的其他平台，红利几乎已经绝迹；但📕不一样，机会多，竞争还不算激烈，属于相对蓝海的地带。

所以我把话放这儿：百万级别，是捡钱级别。

而且，这个百万只是起步，远不是天花板。

顺着这条线，我还想聊几个问题：

- 怎么跟着趋势演变去发现新项目？
- 我们做调研的方法到底是什么？
- 为什么📕客户的消费能力这么惊人？
- 在平台投放，本质到底是在做一件什么事？
- 新手想快速上手聚光，应该从哪入手？
