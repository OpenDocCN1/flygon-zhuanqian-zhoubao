# 封号之后，我不找中介自己办下了出版零售许可（实操全记录）



qiaoyan，赚钱圈两年资深潜水员，今天头一回上来冒泡。这篇内容如果没有@何遇 的催促，可能永远安静躺在我的草稿箱里。

今年三月份，我满怀信心开始做闲鱼旧书生意。当时为了少折腾，执照、图书零售资质这些全交给中介去办。店铺好不容易有起色，出单也稳定了，结果一夜之间三个账号被平台同时处理，其中人气最高的一家店直接被封。老玩家也许觉得封号不过是小事一桩，但对我这种刚出道的小白来说，打击足够让我原地emo好几天。

冷静之后，我咬咬牙决定：不再依靠中介，自己把证办下来。

办证第一道坎是场地。按规定，注册地址得是实际存在的商业或非住宅类物业，普通住宅没办法直接用。我把周围的亲戚朋友全问了一遍，看谁能提供一个非住宅性质的场地。正发愁的时候，有位圈友分享了他的做法：拿自家车库申请成功了。车库属于非住宅产权，完全可以拿来做注册地址。

我当时就想起好几年以前买过一间商铺，房子虽然烂尾了，但不动产权证已经办下来了。正好符合条件！于是拿着这本证开始了整个申请流程。

因为房产登记地在嘉兴，我按嘉兴的规则办理。各地细节可能会有出入，但大体流程是相通的。下面就把我跑下来的流程完完整整交个底。

**先讲官方依据。** 主要涉及三份文件：
一是《出版管理条例》第35条，明确做出版物零售业务需要经过县级出版管理部门批准；
二是《出版物市场管理规定》第10条，要求这个业务向注册地县级出版部门报批；
三是国发〔2014〕50号文第30条，把它归入后置环节，也就是先拿执照再办证。

**再说申请条件，其实就三条：**
1. 已经完成市场主体登记，执照在手；
2. 执照里明确写有“出版物零售”的经营项目；
3. 注册地址得实际存在且固定。

**需要准备的资料也不复杂，列出来给各位参考：**
· 设立申请表（政务平台可以直接下载模板）；
· 执照的影印件；
· 经营者本人身份证明影印件；
· 注册地址不动产证的影印件；如果不是自己的物业，还要附租房协议影印件或免费使用证明；
· 代办人身份证明影印件（若委托别人跑腿，现场出示用）；
· 代办委托书（同样只用于代办场景）。

我有现成的申请表格模板，需要的话可以私我。

**接下来是执照的线上申请。**
进入本地政务官网（浙江的朋友可用“浙里办”），用个人身份登录。

![](img/c2b35612eafbcfab06a7f9c00d0096ac.png)

在查询栏输入“个体工商户”。

![](img/521b6283db5636ccd7cdcd2637439060.png)

在返回的结果里选择“个体工商户开业登记”，选中自己所在的区县，接着点“在线办理”并进入正式申报页面。

![](img/f6bda80442db5fe462b9f3e40bbe4729.png)

授权确认后，先做“名称录入”，把注册地址所在的街道选对。

![](img/3db7f8b30c862009a42397983fafd624.png)

选好市场主体类型、冠名方式，再给你的小店起个名字。

![](img/2a888403a73bcfbdf832643809d79962.png)

随后进入详细资料填写环节。

![](img/bf69cc25d79847ff435e9622fe2ad4bb.png)

这里必须多说一句：街道名称真的很关键。我之前就栽在这一步，因为填错街道，被驳回来三次，每一次都是同样的原因。所以大家在填写前，一定先跟街道方面核对准确名称。

其余就按真实情况填写。
手机号填自己的，保证随时畅通；
组成形式选“个人经营”；
注册地址的产权情况如实选择即可，一般不会遇到实地核查；
问是否需要实体执照时，建议选需要；
业务范围按自己的生意来勾，不过请记住：售书属于出版物零售，之后还要单独跑一趟线下窗口去申请出版零售许可。

这些填完，跟着页面提示一步步走，遇到需要上传产权证明或租房协议的地方，照做就行。

提交后一般过一两天就能看到审核结果，顺利的话，实体执照会寄到手上。

最后一步，拿上执照和申请材料去注册地所属的办事大厅办理出版零售许可。如果自己走不开，可提前签好代办委托书，让代办人带着资料去现场。

整个流程顺利的话，七天左右就能收官。

希望这篇经验贴能帮到正在为办证头疼的圈友。其实只要把资料理顺了，自己跑起来并没有想象中那么难。祝大家都能少踩坑、一次过！
