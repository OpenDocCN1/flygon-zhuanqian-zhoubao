# 王川：论气急败坏, 恼羞成怒之投资大法

越让你抓狂的新技术，越可能是你的财富机会

遇到那种让你瞬间爆炸、恨不得摔手机的新技术，先别急着骂街——这很可能不是来气你的，而是来给你送钱的。

王川有个反直觉的观点：越是让你暴跳如雷、怒火攻心、却又无能为力的新东西，越有可能成为你的财富加速器。

背后的逻辑很简单：如果一件事能让你一直憋屈到想骂人，那绝大多数人也会经历同样的烦躁。情绪面前，人人平等。但机会往往藏在情绪的裂缝里——当所有人都在原地跳脚、抱怨世界变得太快时，你要是能迅速把气压下去，抢先一步调转方向，去认真钻研、理解并押注这个新叙事，那么你就能把那些迟早也得被迫转型的人远远甩在身后。

说白了，这就是一场“谁先冷静，谁先吃肉”的游戏。新技术从来不会等你准备好。它让你恼火，恰恰说明它正在改变规则。而规则改变的窗口期，正是普通人改命的黄金时刻。

所以，下次再遇到让你血压飙升的新东西，先忍住那股想砸键盘的冲动，多看一眼，多研究一下。也许这一眼，就是你甩开别人的起跑线。
