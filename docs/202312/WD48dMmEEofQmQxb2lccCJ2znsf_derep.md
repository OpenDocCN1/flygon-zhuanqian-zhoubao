# 📕宠物科普，我是怎么靠个人IP在红海里活下来的



# 一、我是谁

大家好，我是虾饼，目前在📕做宠物科普。2021年底我辞掉工作all in账号，到现在已经合作过200多个品牌，雀巢、皇家、百利这些国际大牌都在其中，单号单平台变现已经破百万。

之前在赚钱做过一期从0到1的起号复盘，分享了当时靠图文+爆款模板快速涨粉的打法，https://t.zsxq.com/14SCGaKqW，那套方法现在新手依然能用。但起号之后如果还想继续做，想和一堆同质号拉开差距，让个人IP能长期吃这碗饭，就必须把内容壁垒做起来。这是我这两年一直在做的事。

# 二、宠物图文赛道发生了什么

先说下我眼中的📕宠物科普图文这条赛道的变化：

*   **2021年及之前**

属于真·蓝海期，内容只要不踩雷基本都能获得不错的数据，典型的爆款模版长这样：

![](img/82030e7f070dc4477b6b6a6e5301df05.png)

![](img/7e7010e21dab8a3d8b663ed9d0390f83.png)

*   **2022年**

平台开始扶持宠物科普，参加官方活动就有额外流量扶持，整体环境很好。笔记形式也开始丰富，手账风、备忘录、原创手绘多了起来：

![](img/211859595a1b18a27b51520d7af6b92f.png)

![](img/13af04df399c21a91760004150ed3bb4.png)

*   **2023年**

扶持取消了，直播带货和品牌投流抢走了大量流量，图文自然流量大幅下滑。机构号和专门做引流的个人博主大量涌入，竞争白热化。主流的图文形态变成这样：

![](img/73ed2b5ee689a081fe3dcb746afc4d2b.png)

![](img/975e8c6e8ea3a81b9e48b0736440446f.png)

![](img/218608801f5652d2536324a97ac53df1.png)

你会发现，图文笔记最致命的问题就是人设感弱，可复制性太强。爆款一出，全网洗稿，搬运速度比原创还快。用户根本分不清谁是源头，也记不住你的账号。

这种玩法对于只想做引流的团队号来说无所谓，反正可以批量开号。但对个人来说，变现路径窄、起号成本高，如果不主动提高门槛，迟早会被同质化淹没。我入圈那一批人，现在还在更的已经没几个了，而我的账号依然能稳定每月五位数收入。

# 三、我是怎么做高门槛的

下面这些方法都是我调研+自己实操验证过的，短期看不到明显爆发，但长期来看就是护城河。观察现在做得好的宠物科普IP，他们基本都在做这些事。

## 1、让账号有记忆点和人设感

### 1.1 个人简介要立得住

简介里要把你的标签、专业背书和当下状态写清楚，增加真实度和信任感。比如：

*   学历背书：利兹大学营养学硕士
*   进修状态：临床医学在读中
*   近期近况：兽医博士备考中、上海老破小改造中
*   观点标签：生骨肉喂养支持者、环保主义者

![](img/dfa3ac13880a29bc16c11f89a5799dfb.png)

![](img/e6ecc08d5971e6b59586cb8765b5e70c.png)

### 1.2 内容里要有你的痕迹

*   固定Slogan
*   开场白：哈喽大家好我是那个反养猫焦虑的XX
*   中间记忆点：固定的口头禅、表情包、特定金句
![](img/7c6013352e81bf6f47b3574e4e5d4b41.png)
*   收尾话术：今天的分享就到这啦，喜欢的话点个关注，我是你们的XX，拜拜拜拜
*   形象统一：穿搭风格、气质、说话节奏、口音
![](img/9d8553e3c48f54e73e1d1f4d30e457e7.png)

![](img/3656e558f018fc39d1db14e4689e46b3.png)
*   其他细节：常用特效、固定BGM
![](img/e5015d641f2b9b775c8af0b0e31c9bc2.png)

## 2、内容形态升级到视频

图文只能传递信息，视频才能把人设立起来，壁垒自然就高了。

### 1. 不露脸口播

适合刚转型视频的新手，保留一点神秘感，降低拍摄压力。

### 2. 露脸口播

把脸露出来，用户会更快把你和账号关联起来。去年亚宠展我才深有体会，露脸的博主在现场很容易被粉丝认出，合作机会也明显变多。

我是怎么练口播的分享一下：

*   口播技巧：真没必要报班，先拍再说。拍完看回放调。我自己就是这样摸索出适合自己的角度和语气。
*   画面：手机前置很亲切但太糊、很随意；后置好点但美颜后还是糊，需要光线很好。后来直接上相机，拍出来质感完全不一样。用不起相机就用手机后置。
![](img/eebf575cb0dfe793125fc250a855f7d4.png)

![](img/2357552387e7426421176a681ae65242.png)

![](img/a02adfb3b3acf1b2759960b9d880bd4d.png)
*   姿势：我体态一直不好，后来养成习惯每次只拍一两句就停下来回放，提醒自己后脑勺往后收，下巴内收，肩膀放松，衣领居中。刚开始很僵，后面就自然了。
*   语气：我平时跟朋友聊天很活泼，拍出来就显得很跳脱。试了几个状态，最后发现冷静淡定的语气更适合科普人设。
*   台词：不想背稿就看着提纲一句句念，保持情绪，后期把废话剪掉就行，情绪不会断。
*   剪辑：一定要有一套固定的“魔性”剪辑风格，变声、bgm、转场特效都可以。剪映电脑版我用得很顺手，傻瓜操作效率高。

## 3、内容做深、做真、做准

别做水号，靠画面和选题堆流量。核心是原创、实用、严谨。

### 1. 不做水号

水号逻辑和图文爆款模板一样，套一个“这5种人类食物猫绝对不能吃”这种选题，堆素材+重后期，换个人就能拍。品牌方现在很排斥这类账号。
![](img/3b192df7521ad354b4e3c0c7d0b90292.png)

![](img/964eb1b30eb5fe6d4f87bb6d90086b6b.png)

### 2. 原创要有个人的思考

别只搬运爆款选题，要把自己的经验、阅历塞进去。举个例子：
关于猫咪能不能吃谷物，我会讲自己去参观某工厂、听某位老师讲座后形成的看法，并在什么情况下成立。
再比如分享玉米须能当猫草的发现，会说自己是在读哪本书/哪门课时看到的，然后自己实测猫咪反应。这样的内容才有温度和辨识度。

### 3. 内容要解决真问题

去搜索、评论区、粉丝群里扒用户真实的痛点，直接做成选题。既能涨搜索流量，也能提高粘性，用户才会为你的解决方案付费。
![](img/a27e5f9c3effd875a2200aa44f3c2efb.png)

![](img/c797441e0f72f97adb797684d4e433e1.png)

### 4. 保持专业严谨

做的时候要对照自己之前的观点有没有变化，论据是否站得住脚。专业感和人设是互相映照的，不能为了流量乱说。
![](img/802a745b125c3ef880f4eadd2d2e3bb0.png)

内容稳定后，再慢慢把画面质感提上去，调性上去了，报价自然上去。

### 5. 内容规划要升级

图文号早期多是引流+科普混搭。现在要升级为：个人经历分享、学习过程记录、用户问题实操解答、热点解读。这样的矩阵才更立体。
![](img/c856a1ebdda8984263b7cda63a083a45.png)

## 4、持续补行业知识

IP越做越专，知识储备必须越做越深。

*   读学位：国内农校有成人兽医教育，毕业可考职业兽医；也可以申请海外营养学、动物学进修。
*   考证：宠物营养、行为学培训机构很多，证书不被国家承认，但能作为title背书，注意甄别机构。
*   网课：行为学课程最多，📕搜关键词就能找到。
*   看资料：谷歌学术、petmd、默克兽医手册、豆瓣猫组、知乎。
*   参加展会：它博会、亚宠展、深宠展，都是获取一手信息和人脉的好地方。

# 四、额外的小心得

## 1、选赛道和心态

建议做自己真正热爱的赛道，并坚持下去。信息太多很容易焦虑，我做自媒体两年，变现主线一直是接推广。虽然很多人劝我做团购、直播，我也试过，但我更享受做内容，所以选择放弃。

2023年下半年宠物推广确实少了，品牌砍预算转直播，我也没慌。新手铲屎官一直在进场，总有品牌需要靠科普博主做专业背书。

行业层面，《2023巨量引擎宠物行业白皮书》显示，相比美日，中国宠物市场增长空间还很大，现在入场完全来得及。
![](img/a3a84276e124d81fa63d282231b84a3d.png)

## 2、主动展示个人能力

要抓住一切机会证明你的专业价值。我会在朋友圈定期更新：
数据表现、带货战报、学习笔记截图、PR对我专业认可的聊天记录、粉丝对内容和产品的反馈截图。这样PR能清楚看到你获取新知、做内容、影响用户的能力。

## 3、要不要挂机构

挂机构的好处是商单量会变多，机构会把你放进博主库打包给品牌。蒲公英平台机构手续费6%，个人10%，钱到手快慢另说。

通常分成到手后博主60%机构40%。但两个坑一定要避开：

简介里不要放机构联系方式，否则资源全被机构截胡。自己接的单跟机构无关。
别指望挂了机构就能躺平做内容。机构一个编导管十几个博主，很多是实习生在做，质量很难保证。听到“我们号数据很牛能带你飞”这种话要三思，你可能只是人头KPI。
