# 那笔一万元的微天使，为什么让我在凛冬里有了温度
作者：龙哥



## 我是怎么拿到龙哥盟老板龙哥的微天使的

作者：书豪

日期：2023-12-08

2023年11月29日，龙哥哥通过🛰️给我打来了一万元的微天使。

![](img/f8f2f88aa9db065314738034901dad2e.png)

那天上午十点半，我在公司楼下抽完一支烟回办公室，手机弹出一条转账信息。龙哥哥投了我。

一个身家过亿、带领全国顶级创业社群的创始人，愿意用一万元押注我。对我而言，这远不止钱的问题，是认知上的加冕。

我在龙哥盟的全国见面会见过龙哥哥，却从未单独聊过。那段时间的背景是，赚钱官宣龙哥哥准备拿出100万投100位航海家，我心里其实一直憋着一股劲。

真正的一对一发生在11月7日。我去了杭州EFC赚钱总部，单独约到了龙哥哥，在会议室里聊了整整三十分钟。那次并没有当场拿到投资。直到22天后，11月29日，钱才到账。

11月7日那次，我把过去四年全职创业的盘点摊开说了。

从2020年1月1日开始做独立创业，靠编程类👸号的垂直红利，滚到了约300万启动资金。第二段创业进抖音，卖过1000万的家清品类。现在重心落在📕电商，手下带了30个📕店，都是笔记打法在跑，同时📕和快手的无人直播也在测试。现金流、团队情况，我也一并做了汇报。

随后我抛出了一个很现实的问题：今年28岁，想在30岁前攒够1000万的本金，基于现在的业务和电商大势，还有没有机会，怎么走。

龙哥哥的回应很直接：两年的时间，实现1000万是可行的。但目标要抬高到1500万，按六成的落地去执行，最终就是1000万。

我追问为什么要抬到1500万。龙哥哥只说了那句老话：取乎其上，得乎其中；取乎其中，得乎其下；取乎其下，则无所得矣。

我也把当下的焦虑讲了。我很慌，很难受。因为现在做的电商项目本质是红利项目，没有壁垒，没有护城河。📕百货赛道对手越来越多，卷到极致。增量平台的艰难，我算是真切体会到了。

听完我的两三年规划定位后，龙哥哥告诉我：沉下来，把业务能力扎实地做起来。

他还送了我一句到现在还记在心里的话：十倍增长往往比两倍增长更容易。十倍思维的核心是找准阻碍发展的那一个关键因子，直接把它干掉。我们做事时默认很多东西不可被颠覆，实际上一切都可以被质疑。两倍增长是回到原点，一项项剔除障碍。

11月19日赚钱杭州航海家聚会，我又跟龙哥哥碰了一面。作为赚钱的学生，我当时满心都是焦灼和渴望：这个社群里机会处处都是，我该如何在当下的电商环境里杀出自己的路。

11月29日拿到微天使的那一刻，整个电商寒冬都好像暖了一点。这笔钱给我的是极大的精神认可和推力。

我的长处并不明显，我擅长的只是对感兴趣的人和事主动出击并持续坚持。2023年将尽，这件事让我对创业有了更深一层的思考。未来想脱颖而出，认一个靠谱的大哥、一个靠谱的老师，真的非常重要。跟随大哥的节奏，用心做事、持续贡献，在共赢里把自己的能力价值推到极致。毕竟21世纪第24个年头要来了，电商的丛林法则早就变成小圈子抱团取暖。

还有一个让我觉得可笑的小插曲。朋友问我，龙哥投你一万，这对业务发展有什么用？

我反问他两个问题：如果你手里有一个亿，要投100万给人，你会全部押在一个项目上，还是拆成100份投100个人？哪种方式的天花板更高，安全边际更可控？

别用自己的视角去揣度大佬的投资逻辑，要去换位思考。格局是什么，就是这个。

我记得龙哥哥说过，赚到1000万之后，也可以拿一点钱出来投人。能穿越周期穿越平台的，是人，不是某个具体的电商项目和技术。项目和技术不值钱，长期价值有限。

我想，接下来一年，我要带着团队在内容电商里硬啃、深耕。

决战，厮杀。哪怕冲向高山途中倒下，也比原地畏缩吃老本的人强。失败了拿经验，成功了拿钱。

最近心态如履薄冰。内容电商和各大平台的流量分发规则千变万化。今年2月入场至今，经历过📕的第一波红利。那段时间靠矩阵号无脑发笔记，一天几千块的流水轻轻松松累积了第一桶金。少年得志容易忘形，我一口气做了上百个号，还拉了团队。红利就是红利，现在再努力也抗不过趋势。

这波经历让我切身感受到了电商红利的甜，也感受到了趋势残酷的一面。

之后我疯狂报课，几千到几万的课程我都上了，只想用钱换经验补认知。

这几天在杭州拜访了不少百人规模的电商老板，大多数日子不如从前。双十一后全平台掉量、投产下滑。最震撼的不是掉量，而是大家对明年普遍没信心。耳边最多的是：全民消费降级，只有拼多多在涨，别的平台都在学多多打低价、降利润。

凛冬已至。大团队都在开源节流，缩衣减食，裁员，放弃大GMV幻想，只看利润。

我就在想，一个没资源、没经验、没人脉的小白，在这种夹缝里怎么活？

唯一出路是进化成超级个体，一个人能顶一支团队。兴趣电商的逻辑其实很清晰：运营驱动、内容驱动、产品驱动。

这三环以前都要配很多人。现在如果能刻意训练自己的选品、内容、剪辑、运营能力，把复杂模式做成简单流程、标准化，就能顽强活下来，等待下一波红利。

兴趣电商的底层说难也难，说简单也简单。

在我看来，大致有三种驱动方式：运营玩法驱动、内容驱动、产品驱动。

现阶段单兵作战，能做的就是把这三大模块拆解、流程化，放弃大GMV的执念，追求利润。

未来我想死磕内容驱动商业的核心逻辑，把优质内容在全域电商平台分发，去选利润最高的平台。虽然像打游击战，但可以在多平台切量滚动资金、滚动团队，积累平台体感，1-2年把内容能力做到极致，才有可能穿越平台、穿越周期。
