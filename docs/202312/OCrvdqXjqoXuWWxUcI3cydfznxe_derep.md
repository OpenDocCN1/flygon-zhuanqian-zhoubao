大家好，我是龙哥。

进入赚钱后，我一直践行着“主动、真诚、利他、空杯、开放、日拱一卒”的理念。跟着这个方向去做，收获、成长和收入都在不断提升。

上个月我发了篇《AI+简历修改首月盈利7000+的一个文章》，反响很好。随后受邀作为实战嘉宾做访谈分享。访谈结束后，私聊里不断有人来问：有没有群、能不能带一下、教一下话术和指令、怎么回复客户、能不能付费学习...

这些需求我都没办法满足。直到在圈友@摸鱼掌柜的提点下，我们联合发起了一场免费的【AI简历实操打卡营从0到1】。

由掌柜搭盘、我负责内容，我们一起在👸号和朋友圈投放后，147人报名入营。12天打卡周期内，上岸率达到85%，出单率33%，学员最高变现过4位数。

这次打卡不仅把AI简历赛道做了升级，还把电商与AI结合出了不少高阶玩法。下面把从0到1搭建打卡营的完整复盘，以及AI简历的延伸玩法，整理出来供大家参考。想小范围组局的朋友可以直接照搬。

希望这篇复盘能让更多圈友受益。

# 1. 启动前的准备

### 1.1 先定初衷和目标

在写出《AI+简历修改首月测试盈利7000+》这篇拆解之前，我也没想到这个方向能起量这么快，跨行业适配度这么高。既然已经验证可行，就应该把玩法系统化、全面化。

我和摸鱼掌柜当时定了两个很朴素的目标：

其一，让更多普通人看到简历修改这个低门槛赛道，把玩法升级成一套可复制的方法。

其二，用超预期的交付换取社群成员的信任和付费意愿，为后续转化做铺垫。

# 2. 打卡环节的设计

### 2.1 报名流程要极简

我们采用四步走：

1. 转账缴纳报名押金
2. 填写飞书表单登记信息
3. 🛰️打标签便于群发
4. 通过标签批量邀请进群

![](img/b4207a12a0b569aa2977cb31da939001.png)

人力有限、人手不足的情况下，报名环节越简单越好。降低门槛的同时，也方便后续数据统计和押金退还。

### 2.2 押金机制

宣传文案里就明确规则：押金398元，12天共8次作业，打卡难度不高。金额设置既能提高完成率，又能保证营内质量。

# 3. 课程内容搭建

### 3.1 课程信息透明化

考虑到学员水平参差不齐，打卡表、上课时间、作业截止时间等全部写清楚，减少无效沟通，也减少基础问题的反复提问。

### 3.3 打卡机制全流程打通

提前说明打卡时间、作业安排、资料包、押金退还规则、激励制度和活动原则。用规则保障活动有序进行。

# 4. AI+简历赛道的高阶延伸

### 4.1 简历+职业发展指导

职业发展指导指的是提供一对一的职业规划支持，包含咨询、技能提升、行业趋势解读等，帮助客户拿到offer，属于高客单收费项。

![](img/3a419c22fe80bd76df8b0e6f8d8ba54e.png)

![](img/a2151c8555aff1f4d023b2b24ccf6c63.png)

市场情况来看，淘宝、拼多多、📕上已有不少人在做。具体价格：

1. 个人咨询：按小时计费，300-800元/小时不等
2. 在线培训：基础课500-1500元，高阶课可超2000元，主要集中在抖音和📕

### 4.2 面试辅导

帮助学员提升面试表现，包括姿态、表达、答题技巧等。

变现方式：

1. 一对一辅导：180-600元/小时
2. 在线课程：300-1800元不等
3. 高级会员：月费300-900元，年费3000-5000元

# 6. 上岸率85%的关键

### 6.1 把话说清楚

落地靠的是一份执行手册。做到小白照着做就能走通，每日待办、注意事项逐条列明。我们制作了详细的AI简历打卡实操手册，越细节结果越好。

![](img/752ce59a0e48bc391f4d55ba88b67a3e.png)

### 6.2 课程节奏合理

在掌柜经验下，我们预估了每份作业耗时，提前设想各种突发情况，留足时间，并禁止水作业，保证学习质量和出单概率。

### 6.3 每日提醒

信息流爆炸，很多人会把群静音。每日改群昵称提醒、群内发作业链接，双重通知确保不掉队。
