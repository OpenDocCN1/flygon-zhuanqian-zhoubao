# 不靠天赋靠“心机”？我靠这“三心二意”，8个月👸号赚到7位数

> 很多人问我，👸号爆款写作到底能不能赚钱？我的答案是：能，而且可能远超你的想象。但前提是，你得先守住项目的“下限”。

大家好，我是龙哥，龙哥盟的资深圈友，也是👸号爆款写作航海的教练。

前段时间，航海结束了，但我发现，坚持到终点的船员其实不多。很多人在中途就下了船，尤其是👸号爆款写作这艘船。

为什么他们放弃了？

说白了，就是被每天几块钱的微薄收益磨光了耐心。为什么会只有几块钱？因为很多人把精力全放在了找“指令”上，总想着一夜暴富，却完全没搞懂爆款背后的底层逻辑。他们不愿意下笨功夫，更不愿意下“呆功夫”。

找指令的本质是什么呢？就是想走捷径。可等捷径走到头，发现前面根本没路，只能回头再找新项目，如此循环往复，一年就这么蹉跎过去了。

所以，今天我想分享的这篇文章，核心就是帮你守住这个项目的收益下限。只有下限稳了，你才有资格去谈上限，否则每天看着几分钱、几块钱的进账，任谁都没有坚持下去的动力。

而想要守住下限，你必须拥有“三个心”——日更的心、模仿的心、复盘的心。有了这“三心”，再加上“两个意”，你才能在这个项目里游刃有余。

# 一、持之以恒的日更心

最近做👸号流量主项目，我又把日更捡了起来。有学员跟我说，不用GPT真的很难做到日更。确实，但我还是想分享一些自己日更的心得，让这件事变得不那么“费意志力”。

我平时常用的日更方案有六种，希望能给正在纠结的朋友一些启发：

**1、把“正确的废话”翻来覆去地说**

听到这句话，你可能以为是直接复制粘贴自己的旧文。其实，我看了一些日更大佬的文章后才明白，真正的“反复说”是有讲究的。

它不是让你把旧文章原封不动地搬过来，而是拆解自己过去写过的文章，结合这一段时间的新认知，重新融合，给出更有说服力的解释。说白了，道理还是那个道理，但你换个案例，换个场景，就能写出一篇全新的文章。

**2、给自己策划一个系列内容**

我有个屡试不爽的方法：一周定一个主题，把这个主题拆解开，每天只写其中一小部分，周末再做整合细化和复盘。比如周一讲一点，周二讲一点，一直讲到周五，周六汇总，周日复盘，一周的内容就这么轻松搞定了。如果再配合ChatGPT，效率还能更高。

**3、加入一个你欣赏的星球**

比如我关注的V先生星球，哪怕是他2019年的老内容，现在翻出来看也常看常新，每次都有不一样的感悟。

**4、坚持大量阅读**

持续输入新知，是打破认知天花板的唯一途径。我现在在🛰️阅读上的时长已经达到了1036个小时，也想找同伴一起阅读的朋友，欢迎一起。

每一次发现新知，对我们旧的认知都是一次洗礼。

**5、关于立flag这件事**

说到立flag，我不禁想起2020年。那是2021年元旦，我经历了一整年的目标搁浅，面对即将到来的新年，心里充满了迷雾。最终，一番犹豫之后，我决定还是要立目标。

为什么不立？因为不立，所有的目标基本注定完不成；立了，就算完不成，至少也能完成个七八成。这笔账算下来，当然要立！

于是，2021年1月3日清晨6点，我开始认真策划如何立这个flag。立什么目标？立给谁看？立在哪儿？立多久？这些问题列了个清单。

鉴于2020年👸号只发了12篇，且绝大多数集中在前半年，我定的目标是“周更”，保证每周稳定输出一篇，而不是把任务堆积到月末。这个flag要立多久？我的答案是：一年。立给谁看？以往都是家人、朋友，但熟人往往不好意思责怪你，效果很差。这次，我选择立在龙哥盟星球。

![](img/c7d507027b108272061e39408a072615.png)

我决定把目标公开发布，让价值观相近的星友监督自己，甚至还有人会成为“催更小能手”。

目标定好了，位置选好了，但总觉得还缺了点什么。我妈一句话提醒了我：“要是跟前年、去年一样完不成怎么办？”我一拍脑袋，对啊，缺个惩罚措施。罚钱？罚多少？几千几万？对熟人起不到作用。想来想去，灵机一动，既然把flag立在龙哥盟，不如让惩罚措施也和龙哥盟有关。

当时星球近18000人，压力山大。但冷静下来一想，看到的人其实没那么多。算下来，可能就100人点赞、50人关注，就算最后有100个人监督，一个人200元，也就2万块。心理预期有了，那就发！

回顾整个立flag的过程，我其实用到了5W2H分析法。

- **what（什么目标）**：👸号周更
- **why（为什么立）**：立比不立更能达成目标
- **when（什么时间）**：一年，从1月4日开始
- **where（立在哪里）**：龙哥盟星球
- **who（立给谁看）**：18000个赚钱之友
- **how（怎么立）**：利用5W2H分析法
- **how much（罚款多少）**：一次完不成，给看到的人每人200元

这套方案，对于急需改变现状的人，是真的很实用。正因为今年后半年👸号做得还算不错，所以我打算趁热打铁，在这里再立一个flag。不同的是，这次我给自己定的是日更目标——断更一天，在群里发不低于100块钱的红包。

还是按规矩来：
- **what**：👸号日更，粉丝达到1万
- **why**：立比不立更能完成目标
- **when**：一年，从1月1日到12月31日
- **where**：龙哥盟星球、我的👸号、flag小报童
- **who**：60000个赚钱圈友、不到2000个👸号粉丝
- **how**：5W2H分析法
- **how much**：断一次发100元红包，最终完不成发不少于2000元红包

# 二、大胆创新的模仿心

做👸号流量主，很多人的误区是一上来就找低粉爆文，然后洗稿。我必须说，找对标是对的，但别找那种质量差、AI味儿太浓的文章。多去研究真正的好文章，对你提升写作质量才有实质帮助。

![](img/0a0f71007e0a6a3505ecebd412f2b94b.png)

找到对标之后，怎么模仿？正确的模仿需要关注三件事：模仿的时间、模仿谁、模仿什么。

**01、什么时候模仿？**

为什么大家都爱找低粉爆文账号？因为对方权重低，模仿它，你自己短时间内阅读量也能起来。在别人起号阶段模仿人家的爆款，确实是一条捷径。

有人问我👸号流量主现在还能不能入局。这要看项目处于大市场的什么阶段——前期、中期、还是后期。前期反馈数据极少，都在摸索中前行，你走快了就是先行者，当然吃的土也最多。中期参与者变多，分享的信息多了，参照物清晰了，你有防坑手册可以参考，做起来没那么难，但竞争也起来了，比如情感领域已经卷成一锅粥。到了后期，你需要自己做筛选，从同行分享中拨云见日，虽然踩坑少了，但竞争已经很大了。

所以，时机很重要。时机对了，你的努力会有倍增的效果；时机不对，努力可能付之东流。目前👸号流量主项目正处于中期，虽然eCPM有所下降，但单价依然比其他平台高，对新手来说，仍不失为打开副业大门的好选择。

**02、模仿谁？**

从谁那里模仿？模仿一个人还是多人？模仿对了，就能最大限度不绕远路。曹大有个“面包屑理论”，很适合学赚钱这件事——从这个人身上学一点，从那个人身上学一点，慢慢丰满自己，一个项目的知识点就通了。

找对标账号也是如此。别只盯着低粉爆文账号，也要去找大号里的长期爆款，学习那些常规爆款选题。

**03、模仿什么？**

小到标题、封面图、文章结构，大到选题、内容规划，但👸号流量主项目的真正难点在于掌握爆款逻辑、熟练运用技术要领。这里的“技术”并不单指AI指令，也包括指令背后的技术要素。很多人对技术不感冒，学不会，还有畏难情绪，其实不必。掌握了爆款逻辑照样能做这个项目，GPT的用处如果仅仅用于生成文章，那真是大材小用了。

**04、模仿的三个阶段**

我们模仿的初衷，是尽快入局，避免同质化竞争。有句话说得好：平凡的艺术家模仿作品的表面，卓越的艺术家会进入作品，从内部“盗走”作品。

模仿分为三个阶段：
1. 单纯的照抄式模仿；
2. 根据实际情况进行变动；
3. 本质性转移，得到新的创意。

看到不错对标账号，起初都是照抄。中期就要融入个人知识与经历去调整，用你熟悉的知识来增加内容的独特性。最后，形成自己的东西。

往大了说，腾讯🐧就是从照抄到本土化改造再到本质性转移的样本；英雄联盟也是如此，最终日活破亿。往小了说，我们每天面对不同行业的信息差，第一步不都是模仿吗？所以，照抄不可怕，可怕的是永远只停留在第一阶段。潮水褪去时，谁在裸泳就一目了然了。

只有进入模仿的第三阶段，你才真正建起了防守反击的铜墙铁壁。

# 三、回顾初衷的复盘心

**1、复盘的价值**

复盘有两个核心价值：一是避免犯同样的错误，比如航海手册里的违禁词清单；二是找到规律，比如每次群发都记录数据，哪篇阅读高、哪篇赞转高，用这些数据反哺后续创作，效率自然更高。

**2、复盘逻辑**

- **实际发生了什么？** 做了什么动作导致阅读量过万、点赞过千、涨粉1000？加了什么标签、关联了什么热点、标题用了什么关键词？还原全过程，结果导向地回溯。
- **差异原因是什么？** 为什么昨天的文章和今天的文章阅读量差很多？对标账号做了什么而我没做到？
- **从中学到了什么？怎么改进？** 总结经验或规律，提出具体的行动改进建议。

**3、复盘常见误区**

很多人不写作，一到复盘就头疼，恨不得把所有认识的字都搬上去凑字数。其实复盘也有方法。先看看常见的误区：

- **目标不清**：看着别人10w+，赶紧上船，却没想过自己做👸号要用什么定位。上了船才知道“选题”是第一课。是做情感还是娱乐？做热点还是兴趣？日更还是隔天更？上船前完全没想过。
- **没有目标**：还有一部分人，看到龙哥老板说赛道红利就抱着试试看的态度，做一个月行就继续，不行就撤，典型的赚快钱心态。

**4、如何复盘？**

联想有一句方法论我一直沿用：从三个方面来复盘。

- **小事及时复盘**：小事因为牵扯因素少，可以及时复盘。但也因为小，很容易被忽略。大多数船员都是等到周末才复盘，而周末复盘已经是阶段性复盘了，错过了在搜集素材、发布文章、查看阅读量这些小环节上及时复盘的机会。比如，经过一周发现自己选的领域根本不适合自己，阅读量起不来，那就说明选题出了问题，要立即修正。再比如，我教船员一个方法：当预感一篇文章要爆的时候，打开后台数数，10秒内阅读量过百，很可能是大爆；只有几个几十，估计是小爆。当然，不是每篇都这样，刚开始经验不足可以这么做。

- **阶段性复盘**：大事不能等到结束之后才复盘，要在过程中阶段性地进行复盘。否则最后的结果大概率与设想相距甚远。阶段性复盘的好处是，信息新鲜、记忆深刻，基准更准确。具体到👸号运营，就是发满7篇文章后做一次阶段性复盘。账号成熟之后，也可以转向对账号本身的复盘。

- **事后全面复盘**：航海这件具体的事情结束后，必须进行全面复盘。没有事后复盘，事情只算做完了一半，你付出的时间和金钱并没有完全收回效益。

说到底，不管是小事及时复盘、大事阶段性复盘，还是事后全面复盘，本质都一样：只要事情有了结果——不管是阶段性的还是最终的——就可以复盘。有动作就会有结果，小动作有小结果，大动作有大结果。

# 四、流量主收益

说完了“三个心”，咱们来聊聊“两个意”。有了它们，你才能真正驰骋上限。

第一意，是“流量主收益”。这是大多数人的主战场，也是第二意的前提。影响流量主收益的核心要素，主要集中在打开量、完读量和点击量。每个动作背后还有小动作，每个小动作都有优化的必要。具体细节在这里不多展开，大家可以去看航海高手分享的内容。

# 五、读者心意

第二意，是“读者心意”。

很多人用AI写文章，完全不顾阅读体验，甚至有人说排版没用。你发了几篇没排版的文章爆了，就断言排版无用，这是把运气当能力了。阅读体验是读者的基本需求，如果你能满足读者更多、更高的需求，就会收获真金白银的心意。

具体表现在：比如文章打赏和付费。一篇文章足够好，读者才会为你掏钱。当然，付费文章会减少文中广告的流量主收入，这需要账号具备很强的信任感。大多数刚开号的船员不具备这个条件，所以，先把读者体验做好。

最后，我想说：

做👸号爆款写作，从来不是靠拼天赋，而是靠“心机”。守住“三心二意”，你就守住了收益下限，也就拥有了驰骋无限上限的资本。共勉。

很多追剧的朋友可能都留意过：同一部英剧或美剧，常常存在两个版本，被删减过的随处可看，而完整版却不容易找到。可偏偏有不少人愿意为了看得更爽、更完整去想办法。于是，这部分不小的需求，就催生了一个低调却赚钱的玩法——夸克网盘拉新。

再往大众需求上看，国内每逢热播剧上线，或者哪位明星的新剧开播，粉丝们想第一时间追更，又舍不得动辄几十块的会员费。这时候，有人专门做起腾讯视频、爱奇艺、优酷等平台会员的中转生意，顺手还能卖电影票、演唱会门票一类，赚的自然也是个差价。

如果愿意做内容，小说推文也是一条路子。跟单纯的情感爆文相比，它更稳妥，风向也相对安全，不容易踩雷。

至于带货，这个玩法已经被聊透了，不用多展开。

内容创作者还可以走知识付费的路子，把粉丝导进私域，再用像“小报童”这类轻便的工具承载内容，把过去几个月的实战心得打包成产品。我自己就试过这招，把8个月的运营经验做了系统梳理，反响还不错。

小程序变现也同样有人闷声赚到钱。

还有一个更高效率的操作：把👸号文章里的主旨精华，单独拎出来制作成短视频，放到👸号次条，再顺手一分发到视频号，就能获得视频号的分成计划收益。反过来，视频里的文案也可以扩写成长文，再次变成👸号的推送素材。一鱼两吃，循环往复，内容不浪费，流量不白来。

聊完这些共通的玩法，再说说特殊赛道的独门变现路径。比如做旅游方向的账号，除了接景点推广广告，还能直接升级成帮景区做整体营销方案。我手里一个旅游号，就接过一个破万的项目，拍视频加推广打包，一次回血不少。

希望这篇内容，能给还在咬牙死磕👸号流量主项目的圈友，带来一点新的思路和方向。
