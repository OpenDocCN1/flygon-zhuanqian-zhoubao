# 两个人暑假 6 月中旬-8 月卖西安演出门票，截止目前合计利润 20 万

标题：暑期档卖西安演出票，两个人三个月净赚20万，这个冷门生意有多赚钱？

大家好，今天分享一个我们亲测真实、并且还在持续运作的搞钱路子——西安演出门票倒卖。严格来说，我们不是倒卖，而是帮游客解决买票难的问题，顺便赚点服务费。从6月中旬干到8月底，我和搭档两个人，合计利润到了20万。这个数字不算夸张，但确实是一条被很多人忽略的蓝海赛道。

先说背景。最初是五一假期的时候，我发现景区火爆，演出票一票难求，于是试着在小红书发帖帮人代买。结果假期一过，流量骤降，小红书账号也有些小违规，基本废了。后来我转战闲鱼，又看了一圈抖音、视频号上的同行，发现闲鱼获客最直接。6月前后用老号发帖，咨询量慢慢涨，到了6月下旬明显感觉旺季来了。有一天，我们拿着差不多100张客户的身份证去窗口买票——我闲鱼接了30多张，我弟和我高中同学从小红书分别带来50张和20张左右，那天我和我弟净利润就有八九千。尝到甜头后，又加了个闲鱼账号，继续在平台上引流。

这个项目的核心，说白了就是搞到票源。我们主做《长恨歌》，其他热门演出和景区门票也捎带手做。关键不是卖给谁，而是你能否从底价渠道拿到票。我们合作的票务公司已经做了8年，票源稳定，利润空间自然就出来了。在旺季，门票紧缺，客户根本不怎么看价格，谁能出票谁就能赚钱；淡季则要靠沟通话术，因为大家都比价，价格战在所难免。

操作流程其实不复杂。客户在闲鱼搜到我们，下单付款（大多数是全款含服务费），然后我们下午上门取证件。高峰期一天要跑几十个酒店前台，后来实在忙不过来，就让表姐夫帮忙跑腿，每张5元，再开车30多公里送过来，跑一趟100元。7月以后，景区排队越来越夸张，我们找到了线上出票渠道，客户只提供实名信息就能买票，也就不需要再取证件了，轻松了一大截。

说到线下排队，那真是拼体力。7月排队才十几个人，到8月初每天两百多人在那耗着，有的旅行社直接雇十几个人专职排队。最狠的时候24小时两班倒，凌晨4点去都排不上号。我们五一后找了个代排团队，从通宵排一人100元，涨到8月中旬的200元，想挤进前十名，成本更高。窗口政策也变过两次：五一时突然说每人只能代买5张，我当晚还去机场接客户，收到30张证件直接崩溃，还好家里人去排队化解了；8月下旬又改成一证一票，排队的人基本全歇菜。

这个项目的前景，目前看还是很乐观的。除了《长恨歌》，其他演出像《驼铃传奇》《千古情》《复活军团》都有钓鱼执法风险，我们碰到过三次，同行也碰过，每次罚起步3000元。但《长恨歌》暂时管得不严，估计至少还有一两年的窗口期。旺季集中在春节前后、五一、6到8月、国庆、元旦，加起来能有四五个月，淡季也能做，每年只有停演那个月没收入。现在旅游刚复苏，同行竞争慢慢多起来，但还不算激烈，空间和时间都还有，属于红利期。

我身边也有人做类似的事。有个外卖骑手也是误打误撞进来的，跟我差不多时间起步，现在利润估计有15到20万，他8月那会儿量很大，每天出几十张票。后来他找了个票代合作，结果被借走2万加7000订票款，那票代是老赖，法院执行名下0资产，血亏。我们合作的那个代排队阿姨，6月中旬到8月底，光排队买票（一天真正买票过程就10分钟）平均日赚2000，整个暑假大概15万，因为高峰期她团队一天要用30多个人。前期我把这项目分享给高中同学，他有一天小红书来了客户，请假一天陪客户吃喝玩乐加买票，当天就赚了4000多。我们接待过的客户也五花八门：有《长恨歌》的演员、开半年会的30人公司团、大小旅行社、公安局小领导、陪游公司，甚至还有保密局的。

看到这，估计有人问，普通人能上手吗？真能。实操路径很简单：先注册闲鱼，有条件就搞三个号，配三个支付宝收款；把账号包装好，发一些有质量的帖子，提高曝光；然后等客户来咨询，下单后找渠道拿票，赚差价。从订票到演出结束，最长一周回款，流动资金1000到2000元就够。信息差就在这——大多数人根本不知道这行存在，都知道热门景区难买票，但没想过可以帮人买票来收费。目前做这行的，基本都是旅游行业的本地人，或者家里人干这行，不然很难摸到门道。

风险方面，核心是选品。《长恨歌》基本没风险，高低价卖都行。其他演出就容易招来钓鱼执法，尤其是闲鱼上，景区会扣一级代理的保证金来罚款，然后一级代理再找下线要赔偿，一层层传下去，所以不熟悉的人不敢合作。再就是跟游客之间的纠纷，比如订票后跑单，或者沟通不清导致投诉。我们也就遇到一次跑单，大部分人在成交前讲清楚都没事。态度真诚很重要，基本不会赔本，回款也快。

最后说说放大。西安这套玩法可以直接复制，甚至放大到外地热门景区。多个社交平台矩阵运营，收益能翻倍。总之，这个项目目前知道的人不多，看起来不起眼，但真金白银的利润摆在这。如果你也想试试，趁红利期还没过，赶紧入场。
