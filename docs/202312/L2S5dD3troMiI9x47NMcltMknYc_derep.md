# 闲鱼半年210万流水，我把踩过的坑和跑通的方法一次讲清
作者：龙哥

哈喽，我是龙哥，圈里朋友都这么叫。01年生人，踩进线上生意快6年。初中那会儿倒腾过微商小商品，十七岁带着几百人团队做护肤品牌；2020年特殊时期，我从学校退了出来，跑去广州做直播业务，管理过5000平的直播场地。那五年运气不好，盲目扩张，把老本都赔了进去。今年3月重新出发，扎进电商领域，踏踏实实干了几个月，账面利润回到接近70万。

新手跑这个赛道，能做到什么程度？我自己测出来的数据是：品类毛利平均三成。

接下来聊聊我转去闲鱼的原因。

2021年年初到2023年3月，我一直在广州硬撑着那一摊直播生意。场地租金和人力成本像漏水的桶，我迟迟不肯放弃，总想着翻盘。直到清盘那天，兜里只剩三千多块，连住处的房费、水电都成了问题。

复盘成因，还是微商时期的成绩让我飘了。风口给的甜头，让我误以为自己是天选之人，于是跨界去做完全不懂的直播，把赚到的钱全砸进去，凭感觉烧，不回到现实里看账本，最后只能梦碎收场。

3月那天，事业清零，感情也在同一时间结束。我整整失眠了一周。22岁，我不愿意被父母安排回去复读，更不想当一个灰溜溜的逃兵，让别人看笑话。

选闲鱼，是因为我清楚自己的位置：从大风口淘汰下来的人，卷不过那些还在牌桌上的高手。快手、某音、视频号、种草社区，这些平台我全都试过，也都赚到过一点钱。可它们有一个共同的问题——规则变太快。今天研究明白的打法，明天就失效。我追了两年多，追到心力交瘁。

没有团队帮我拆解套路，也没有专业运营带的班底，我的方法都是自己刷平台刷出来的。这确实是短板，但市面上比我弱的人还有一大把，真正赚钱的人是少数。

我还有胆量、有风向感，兜里留着两百万可动用的钱，也有五年管理经验。3月种草社区刚好起势，我把闲鱼、某多、种草社区一起跑了测试，最后是闲鱼给了我最强的正反馈。

![](img/8a892e527f8c1fdf2b92d064f55afeb4.png)

关于心态，先说一个观点：项目太多，诱惑太大，流量永远在追新概念。我也心动过，但我管住了想赚快钱的手。选方向，不需要盯着别人赚了多少，而要盯着自己能不能赚到。一条赛道很热闹，不代表你能分到一杯羹；一条赛道很普通，与你合拍，你就能一直做下去。

我受够了大起大落的日子。直播这行几年给我最大的教训是：今天赚到的，明天可能连本带利吐回去。辛苦做起来的号，说封就封，实名认证作废，想出力都没地方使。反复经历这些，人会失眠、焦虑，身体先垮掉。我现在只想做稳定一点的生意，稳稳当当地做下去，不求一夜爆发，但求天天有进账。

闲鱼适合我这种想法。它不会让你一夜之间暴富，但规则稳定，就算违规，大多只是下架一条链接，不会让你被暗戳戳的限流磨到失去方向。坚持每天更新，结果不会太差。结果差异来自货盘与毛利，选品很重要。

下面把我亲测过的品类按热度排一排。图片越多，说明想买的人越多，转化也越稳。

第一类：数码电子。包括U盘等存储产品、手机、相机、摄像机、扫描设备、平板、手提电脑、办公PC、打印设备、CCD、显示屏。核心人群是白领和学生，需求稳定，利润也不薄。我现在主做的就是这个方向。

我自己主做手提电脑。12个人的小团队，现在每天保底出20台，一台毛利约六百元，一天毛利总额约一万二千块。客单价1800到2500元，三天左右回款。这个品对小团队很友好，流量也猛。闲鱼曾经给过百万级的推荐位，平台改版之后，新号发的第一条帖子都可能冲到几万到数十万浏览。

![](img/b522580fbb5d43c7e7a3efb130d96fdf.png)

第二类：汽车用品。常见的有车辆举升器、牵引绳、胎压监测、备胎、灭火器、应急灯、警示牌、急救包、随车工具箱、驾驶录像装置。有车一族复购稳定，客单不高，适合新手练手。缺点也明显：毛利薄，东西杂，女生如果对车不太熟悉，上手的难度会高一些。

第三类：母婴用品。像宝宝餐具、摇篮、抱毯、婴儿推车、早教玩具、清洁养护用品、抓握训练玩具，毛利能到三成以上，宝妈做起来有天然优势。

第四类：办公类家具。写字台、人体工学椅、午休躺椅、电竞座椅、组合柜、小边几，上班族采购很密集。

第五类：应季物品。天冷了之后，电暖毯、床垫、加湿设备、绒毛拖鞋都会走俏。

第六类：租房刚需。立式灯、靠垫、空气清洁设备、加湿设备、清洁机器人、桌椅、便携收纳架、木质鞋架、木质床、木质沙发。现在大城市搬家频率高，这一块几乎全年都有需求。

把这几类放在一起，按季节排品，用心维护，结果不会辜负你。确实，这平台给不了你一夜暴富的刺激，但安安稳稳保证生活没问题。

上百单之后，我开始总结流量规律。真正能把东西顺利卖掉的前提，是这五样：品有需求、定价有竞争力、懂一点基础运营、能扛住枯燥的执行、心态磨不烂。实用技巧我挑三个说。

第一招：多次小幅降价。经常有伙伴来问，东西挂了很久没人理，是不是品不行？很多时候不是品不行，是曝光不够。平台对频繁调价的商品会比较敏感，每次降一点价，都会重新给一次展示机会。发布的时候别把底价亮出来，先定高一些。比如你想卖2100元，就挂2500元，然后每隔两三天降几十元，这个过程里浏览量会慢慢爬升，成交概率也随之上来。

第二招：用实拍，不要用网购白底图。闲鱼的整体氛围是二手交易，买家对那种P得很精美的官方图反而警惕。手机拍照要清楚，首图背景干净，细节图多给几张，能挡住很多售后纠纷。滤镜可以开，卖衣服要谨慎，色差是一大吐槽点。

![](img/d0fc8fb3b10e4eac2e4504d2ba5663c7.png)

图片的美观度直接决定系统给不给你流量，用户会不会点进来，跟以前做短视频封面同理。找图片素材我习惯去种草社区搜索关键字，平时多积累“网感”。想做客单价高的伙伴，图片更要讲究。闲鱼目前正向数码类倾斜，图片好看，再加上官方助推，等于闯过了一道窄门。

![](img/e2095bb894d671885a1b190c1f585dc9.png)

第三招：文案要短，关键字要准。前期起号时期，文案清爽一点，平台更容易识别。如果你别的平台有现成链接，直接搬过来，把关键字顺序微调，因为同行已经帮大家验证过了哪些词好卖。结构参考：品牌/品类/规格/颜色/新旧/出售原因/是否包邮。

再聊聊怎么提高成交概率，以及怎么让客户更快信任你。

第一，主页要当成店面装修。账号资料尽量真实、完整。做数码的，账号名到头像，都要往这个方向靠。模糊头像、风景照、动漫头，很难拿下客户。女生用清透有网感的照片，挂上“学姐”人设；男生用阳光干净的照片，挂“学长”人设；也可以把自己包装成工厂直供。这三种身份在平台上都很讨喜。

背景可以用工厂实拍或者有质感的生活照，和头像风格统一。千万别在背景上晒现金，那种炫富风格很容易让人举报，也容易触碰红线。

第二，商品文案要精细。标题写准，描述写细，搜索露出的机会才多。不要过度吹嘘，真诚是第一原则。最简单的提升办法还是看同行，他们卖得好的帖子，文案结构直接照着套用，关键字调一调就行。

第三，回复咨询积极一点、活一点，不要像客服机器人。先了解客户买来干嘛、预算多少，尤其客单价高的东西，信任建立起来，成交是自然的事。前面用打字，熟了可以发短语音，语音条不要太长。这个小技巧能提高三成成交概率。如果是团队作战，多招一些有亲和力的女生做客服，效果往往比男生更好。

选品能力决定你能走多远。做这个生意，选品的权重极高。条条大路通罗马，但路的宽窄、远近差别很大。评估一个品，看平台容量，看自己愿意投入多少精力。下面分两种模式拆。

先说不用囤货的代发模式。

第一招，抄同行的作业。新手最怕没方向，那就照搬已被验证过的方向。同行能把某个品做起来，说明市场确实在给反馈，而且不违规。跟着成功者走，能省下大把试错费。

具体操作：你身边一定有一堆东西，比如桌子、手机、耳机、水杯——随便挑一个作为起点。在闲鱼里输入这个词，筛出“我想要”数量最高的帖子点进去。接着看这个卖家的主页，观察她近期在卖什么、什么卖得好，抄下来去某多找同款。顺便翻一翻她过去上架过的宝贝，也许会有新思路。再看看她关注的那些同行在卖什么，顺着线索继续搜。这样循环几轮，选品库就满了。

这个流程我跑了无数次，每跑一轮，都能捡到几个不错的品。

第二招，盯平台趋势。如果实在没方向，点进平台官方的卖货栏目，看看近期什么品类热度在涨，官方数据本身的含金量很高。除了榜单，还有一类“家里闲置物品变现推荐”列表，里面全是普通人在卖的东西，能带来不少灵感。

再讲我自己在做的直供模式。它的好处，我一条条说。

第一，供货稳定。链接爆了不用慌，合作久的厂家能接住，不怕断货。

第二，利润越做越厚。拿手提电脑举例，代发一件只能赚200上下，直供价能谈到500到1000。

第三，垂直一个方向，平台给的推荐更精准，能吃到阶段性的流量红利。

第四，账号更安全。直供店被误判的概率低很多，我身边有号单帖浏览量破百万。

第五，货盘集中，不容易分心，反而容易做出深度。

![](img/d2b0d1e4eb32bb52ee8342e912617bef.png)

手里还没有稳定供应链的伙伴，不用慌。先用代发模式测出一个爆品，再拿着销量数据去谈合作，路会顺很多。只是这个过程要沉淀，别着急。

不管代发还是直供，都得算清一笔总账。产品需求度、成交难度、流量规模、退货比例、单件毛利、封号风险、日常要投入的时间，这些变量全部要过一遍。

利润高低直接决定你的天花板。举两个例子对比一下。卖几十块的小商品，需求高，但一单只赚五元。单号一天出十单，到手五十元；同时开三个号，每天一百五十元，每月四千五百元，和进厂打工差不多。换一种单件能赚二百元的品，单号一天出五单就是一千元；三个号跑满30天，月收入直接甩开多数上班族。

这就是选品拉开差距的地方。

退货比例也要纳入考量。拿投影机的行情来说，我早年是靠这个品赚到闲鱼第一笔启动资金五万元。可如今它的退货比例相当高，三百台里可能有五十台会退回来，等于利润直接砍掉一部分。挑货盘，别只看毛利，要连退换售后一起算。

最后聊聊做这门生意需要什么样的底子。

第一，资金准备。2000到5000元起步，先算清楚手头的钱能撑多久，再谈以后招人扩量。

第二，心态准备。一句话送给大家：凡是杀不死我的，都会让我更强。别留太多退路给自己——线上创业的门槛比实体店低多了。太容易碎的心，撑不过封号、限流和无人问津的日子。各行各业都有各自的苦，工地上晒过、流水线上熬过、书桌前端坐过的人，都懂这个道理。换一种角度，吃过的苦都是在铺路。

第三，圈子准备。一个人走得快，一群人走得远。我平时不太冒泡，今天把这些讲出来，也希望能认识更多有趣的朋友，彼此照应，互相借力，一起往前跑。最后说一句：别因为慢就停下，每天动一点，时间会给你答案。
