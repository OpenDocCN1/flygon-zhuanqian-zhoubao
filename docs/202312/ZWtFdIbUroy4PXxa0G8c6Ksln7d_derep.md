# 自媒体新人，如何利用阅读写作基本盘，撬动百万收益

今天想跟各位刚起步做自媒体、或者已经写了些日子但还没找到爆发点的朋友，聊一个很实在的话题：怎么把“阅读+写作”这个基本功，真正变成能撬动百万级收益的支点。

先自我介绍一下，我是理白，白天在医院上班，业余时间做自媒体，全网积累了三十来万粉丝。这条路我是自己一步步走过来的，所以接下来讲的每一个字，都是我从真实经历里摸爬滚打总结出来的。

普通人想靠某个项目或技能翻身，门槛最低的其实就是写作和阅读。但它有个前提——你得扛得住长期主义。只要你愿意持续做、坚持做，结果大概率不会差。我自己就是最好的例子。

今天分享的核心框架是三个基本盘：写作基本盘、阅读基本盘、人生基本盘。每个盘里都有三个关键要素，加起来一共九个。这九个点，是新媒体新手最该吃透的东西。

先说写作基本盘。

写作这一层，对应的是三个思维：加法、减法、乘法。它们是层层递进的。

**加法思维：先疯狂输出，再谈方向**

很多新人一上来就问我：“该写什么文体？什么题材？从哪儿入手？”我的答案很直接——别想太多，写就完了。你很难在起步阶段就找到自己最爱的赛道，所以必须靠加法思维去试。先写够十篇、一百篇，你才可能看清自己想走哪条路。

我管这个阶段叫“如饥似渴期”。五六年前我刚入行，第一个月就写了27篇文章，那时候稿费才50块一篇。为了这50块，我逼着自己每天都交出一篇能投出去的稿子。这个过程里，我既要输出自己的想法，又要满足编辑和市场的要求，只能不停地试错、调整方向。职场文、亲子文、情感文、校园文、干货文、科普励志文……我全都写过。

还记得有天晚上，我为一篇文章卡住了第三个论点，愣是想到凌晨四点。后来我干脆下楼绕着操场一圈圈走，边踱步边琢磨。就是靠这种笨功夫，才攒出了后来的小成绩。

加法思维就像滚雪球。想滚出大雪球，得有长长的坡和湿湿的雪。坡是量变，雪是你在量变里收获的一点点成长。你从山顶扔块石头，它只会一路下落，不会变大；但如果在雪山上滚雪球，它会越滚越厚。不知不觉间，你可能已经攒下100篇稿子，其中10篇上过十万级大号，1篇冲过千万级流量。

这就是加法——用大量输出，为自己攒下选择的底牌。

**减法思维：做取舍，选最优解**

当雪球滚到一定程度，加法阶段的任务完成了，就要开始做减法。

“选择和努力哪个更重要？”我觉得，不够努力的人根本没资格谈选择。因为你的选择空间太小，努力没到那个量级，选择摆在你面前你也接不住。只有积累够了，你才谈得上衡量和取舍。

举个例子。我一个月能写30篇稿子，一篇200块，到手6000。如果我不满足于这个数，就得判断：这30篇里哪些写得最顺手、时间成本最低？哪些题材上限更高、更有增长空间？在加法阶段攒够了选项，才能用减法筛出最优解。

人生最难的不是在对错之间选——对错一目了然；也不是在错与错之间选——那是没得选，说明你加法没加够。真正难的是在“都对”的两条路里选一条。

选A，可能三个月没收入，但之后能力爆发；选B，当下有持续正反馈，却容易让你沉迷战术上的小赢，忘了战略上的布局。我发过一条朋友圈：很多人拿不到大结果，不是因为他不行，而是因为他持续地“行”，一直在小正反馈里爽着，反而错过了真正有长期价值的机会。

比如AI来了。有人觉得它是猛虎，用它写作是浪费时间；有人把它当效率工具，用来搜标题、找素材。最后打败你的不是AI，而是会用AI的人。这就是取舍。

**乘法思维：加杠杆，一鱼多吃**

就算你有了加法和减法，还是会撞上瓶颈。哪怕稿费涨到一篇2000，你依然困在“打工者思维”里——用单位时间换单位价值，不管你是给老板打工还是给自己打工，本质都一样。《富爸爸穷爸爸》里把人为四象限：雇员、自由职业者、投资人、企业家。雇员和自由职业者，说到底都是在卖时间。

想破局，就得引入乘法思维——加杠杆。我花一小时，能不能换回十小时、一百小时的价值？

比如直播。你播完，注意力就散了。但如果你把直播切成短视频分发到视频号，再把内容整理成文字发到👸号、📕、抖音、知识星球，就能获得二次曝光和持续传播。这就是杠杆。

那具体怎么加？我给了三个方向。

第一，写文案。朋友圈文案、视频文案、带货文案都算。我卖过很多产品，客户问过的问题我都会写成文案发在朋友圈，后头再有人问，直接甩链接就行。我还给某瓷砖厂家写过一篇带货文案，稿费500块，最后带来60万阅读、300万营业额。虽然我只拿固定稿费，但这让我看清了文案的杠杆威力。

第二，做账号。公域的抖音、📕、头条，私域的星球、社群、朋友圈，本质都是账号。账号有长尾效应。我2019年发过一篇帖，到现在都有人点赞、加我微信咨询。这就是时间复利。

第三，写书。书有书号、有纸墨香，能被正统行业认可，也是个人专业度的最好背书。相比卖课和做号，写书获取用户成本不高，但影响力放大效果极强。想深耕自媒体的人，值得认真考虑这件事。

接下来是阅读基本盘。

我把阅读的定义放得很宽：看书是阅读，看文章是阅读，看综艺影视是阅读，跟人聊天从对方身上捕捉信息也是阅读。本质上，阅读就是信息摄取。它有三个能力：深度、广度、迁移。

**深度能力：一厘米宽，一万米深**

“一万小时定律”听起来吓人，但在互联网时代，一件事坚持1000小时，你就已经是半个专家。想做好账号，先别急着发愁内容，去大量涉猎你感兴趣的东西，把它和你的专业结合，读十本二十本同领域的书，用刻意练习倒逼自己掌握技能。

深度能力有两个方向：把书读厚，再把书读薄。

把书读厚，是你读一句话时，能联想到某个人、某个观点，能看见它背后的引申含义。比如《高效能人士的七个习惯》这类经典，甚至孙子兵法、论语，值得下大力气去啃，把每一句的隐藏意思都挖透。

掌握了读厚，自然就能读薄。我现在看一本书，有时一趟飞机就看完了。为啥？因为书里80%的观点我早就在别的书里见过，只需要看那20%的增量就够了。当你对一个领域钻研得够深，许多书在你面前就跟一张纸似的，里面的大部分内容你早已了然于心。

就像研究生写论文，查重率太低反而会被认为没有价值——因为你跟全世界都不一样，说明你没有站在前人的基础上。本科生是一个圆，研究生是圆上射出的一条线，博士生是线上多出的一个点。那个点，才是你对未知的微小试探，剩下99%都来自继承。

所以经常一本书的精华就一两页。你能记住某一页的一句话，就是收获。做业务也一样，你的井可能只有一厘米宽，但深到能让你拥有极强的判断力。

**广度能力：社交货币与共情**

有小伙伴问我：“读书是死磕专业好，还是读杂一点好？”我的建议是：先深后广，也可以交叉进行，但深度是广度地基。

广度最大的好处，是让你拥有更多“社交货币”——谈资。做自媒体要表达，脑子里不能只有本专业那点东西。比如网络热词“好了是闺蜜，不好了是敌蜜”，很多人还没反应过来，我早就把它写进朋友圈了。我爱看《甄嬛传》，经常用里面的桥段做选题。这些广泛的涉猎，让我和用户之间多了很多触点。

深度一层，广度还能练出“共情”。举个例子，两人做育儿赛道，一个是专业医生（我），能聊产后护理、雌孕激素、疤痕修复；另一个是普通宝妈，她真实经历过生产，只要说一句“我痛过，我经历过，你没资格跟我聊”，我就输了。因为她能共情，我不能。

所以我特别愿意去修炼自己站在别人立场上思考的能力。我学过盖洛普、MBTI，不只是分析自己，更是理解别人。当一个人做出超我认知的举动，我第一反应不再是“他三观不正”，而是“他何以至此？他为何如此？”当你开始思考成因，就更容易理解对方。

很多人好奇为什么我和梁靠谱做成交像推土机。其实核心就是我们和用户不是“买卖关系”，而是一对朋友，并肩去面对这个世界。这也是成为一个好的自媒体人、好销售、好表达者必须具备的能力。

**迁移能力：把一切变成生产资料**

迁移能力是深度和广度的结合。你要活成T形人才——竖线够深，横线够宽。在这个基础上，还得具备一个本事：把和你相关的所有东西，都转化为生产资料。

看一本书，金句变成你的句子；看一部电影，打动你的情节变成你的写作素材。我看电影看到男女冲突，会去聊男性思维和女性思维；看综艺，会提炼哪些选题能帮自媒体人获得流量。随时随地获取素材，随时随地包装输出。

再进阶一点，迁移能力还包括分析自己的情绪——用框架和系统来控制情绪，而不是被情绪牵着走。

最后说到人生基本盘。

这个盘里藏着三个认知：圈子认知、品牌认知、稳态认知。它们决定了你能在这条路上走多稳、走多远。圈子决定你被谁影响，品牌决定你被谁记住，稳态决定你能扛过多少起伏。这九个关键元素，每一个都值得反复琢磨、刻意练习。

从写作到阅读，再到人生，本质上都是在给自己加杠杆。希望今天这一场分享，能在你心里种下一颗种子——从现在开始，盘活你的基本盘，总有一天，你也能撬动属于自己的百万收益。

先说一个真实的场景。

有人加了我微信，直接甩过来一条群发式的硬广。

如果你换作一般人，大概率会有两种应激：要么怼回去骂一顿顺手拉黑，要么干脆已读不回直接删。

我选的第三条路：用一套预设的框架来消化情绪。

遇到这种事我也会不爽，但我提前给自己写好了一套SOP。面对广告骚扰，我只做两件事。

第一件事，反向营销。

只要对方来推销，我就反过来扒他的痛点。一般敢用群发骚扰的，基本是流量不行、方法论不行，还带着点心虚。我会直接点破，并且顺手教他怎么玩得更好。很多时候这种教学就是成交。

因为绝大多数做这种低质打扰的人，已经到了山穷水尽的阶段，而且心里清楚自己做得不对，愧疚感一上来，心防就很容易被打开，我就顺势把他转化了。这种操作我已经用熟了，成交率不低。

第二件事，遇到油盐不进的。

我也不会让自己失控。我会用一句带点调侃的话回过去，然后把这段对话截图下来，整理成朋友圈素材，反向为自己创造增量。

用这两种打法，情绪基本都被转成了现金流，要么当下变现，要么沉淀成未来的内容资产。

这其实就是一种情绪迁移：先把情绪问题拆成思维路径，再把思维路径固化成SOP。做多了自然成长。

迁移能力还有一个层面，是跨界互用。我常拿《甄嬛传》来打比方，也会混进学医时学到的逻辑，再牵到商业上，就是把复杂的东西讲得通透。能把一个难的点讲得又简单又让人听懂，输出价值就上去了。刘润老师能把商业拆到人人都能听懂，就是迁移能力的典型。

这是阅读基本盘的第二部分。

✅ 第三部分，人生基本盘。

人生基本盘我总结成三个认知：圈子认知、品牌认知、稳态认知。

### ❤️ 第一个，圈子认知。

圈子要做两件事：向上社交，向下兼容。两者要同步。

向上社交是去找机会，向下兼容是去结善缘。大佬愿意带新人，很多时候是看到了可能性，是在结善缘。像某些权力场里，大佬把女儿嫁给更有潜力的年轻人，本质上也是在做权力迭代，把影响力扩散出去。

向下兼容的本质，是把善意和影响力播撒出去，换来口碑。做IP、做知识付费，除了赚钱，还要赚到钱买不到的精神层面的财富，而这份财富往往来自于口碑的自来水传播。当然要筛选。

向上社交要有的野心，就是要超过曾经的自己。张潇雨说过一句狠话：三年内打不过你曾经的老师，成长就不够彻底。这句话很夸张，但方向是对的。要保持超越的心态，往更好的圈子迈进。

我们加入顶级社群、新媒体变现圈，本质上就是在换水环境。圈子不同，聊的话题、资源、人脉都不一样。马克思说人是社会关系的总和，你身边的人决定你的一生。

我觉得一生会遇到三类人：

#### ⭐ 第一种，贵人。

大佬给了产品、给了机会、给了契机，你才抓住。像粥老师跟我连麦，洋哥给我拉新机会，都是贵人。

跟贵人连接时，要时刻展示你的可能性、潜力、向上生长的动力。

#### ⭐ 第二种，好人。

大部分人都是好人。进入好圈子后，很多人会自发帮你传播，成为你的超级节点。有的人和你差不多，甚至不如你，但会无条件支持你传播你的影响力，这种人要珍惜。一个超级个体背后，往往是另一个超级个体。

#### ⭐ 第三种，小人。

见不得你好、嫉妒你的人，必然存在。我发过一次朋友圈秀恩爱，就有人莫名其妙过来骂。没交集，也不知道哪冒出来的。自媒体做起来阅读量一高，这种人就更多。

我当时的做法是打个标签回一句“好的，下次注意”，然后归类，不再理会。过一两个月我会定期清理好友，但不会因为一时情绪就删。

这类人多半生活不顺或情绪在崩，容易发泄。硬刚只会让自己陷进去。说难听点，他的命不值钱，你的账号和时间值钱。

我把这类人叫“恶贵人”。他的出现是风险信号，保持物理隔离，别直接冲突，就避开了不可控的风险。疯子的行为用常理解释不了，离远点就是渡劫。

圈子认知归根结底是善待各种人，向上谋机会，向下结善缘，圈子就稳。

### ❤️ 第二个，品牌认知。

个人品牌就是你不在场时，别人怎么评价你。在场大家都会给面子，背地说什么，基本就是你的品牌。

品牌就是持续做你认为对的事。割韭菜、骗人、PUA，这些是底线红线。不为恶、不作恶是起步。

影响力越大，越要克制。黑历史会无限复读，所以要珍惜。

建立品牌没那么难。知识付费就是最容易的一条路。你会什么、做成过什么，就能帮别人复制。靠某套方法减了20斤，就能帮更多人减20斤。不是只有100分的人才能教课。

80分可以教50分到70分，60分可以教0分到40分。个人品牌像往湖里扔石子，一圈圈涟漪扩散，某个时刻共振起来，传播就起来了。帮到的人越多，钱自然就来。

当你站在那里，别人就知道你的话有分量，你的决策有人跟随，你的背书值钱。你持续给价值，你就是有价值的人。

人脉的本质也不是认识多少大人物，而是你能帮助多少人。当你能帮很多人时，你的人脉网络自然就是最强的。

### ❤️ 第三个，稳态认知。

稳态是生物学里的动态平衡。一个人也一样。

以我为例，我的主业是医生，用确定的时间换确定的回报和安全感；副业是创业，用不确定的投入换不确定的可能性和未来。这两者构成稳态。

理想的主副业稳态是：主业让你能在副业里对不喜欢的客户说不，副业让你能在主业里对不喜欢的工作说不。

现在环境下，我不建议没准备好就裸辞。能辞职大概需要三个条件：

*   第一，副业收入已经稳定超过主业。
*   第二，手上至少有3-6个月的现金流，能扛风险。
*   第三，副业收入是稳态的，比如每天一两千到两三千，而不是今天100明天10000。

时间利用率越高，平衡就越好。现在更讲长板协作思维。不是补短板，而是把各自的长板拼起来，做出更高的木桶。在好圈子里，用好商业模型搭好系统，就是在建立稳态。

在有限的岁月里，在无限游戏里，建立一个能穿越周期的价值体系，这才是稳态。
