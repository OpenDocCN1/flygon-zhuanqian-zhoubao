# 外籍乘客的待遇
作者：龙哥

最近某航空公司的操作惹出了争议：一位日本乘客迟到却能顺利登机，而同时间赶到的中国旅客却被拦在舱门外。舆论焦点多半落在“凭什么区别对待”上，但我想换个角度聊聊——规则本身够不够透明。

说实话，差别待遇在任何社会里都算不上新鲜事。拿美国名校来说，藤校录取时对校友子女、大捐赠者后代高看一眼，这操作摆到明面上，大家虽然会议论，但至少知道游戏规则就是这样。再比如美国理发行业，必须持证上岗，而证件极难考取，且协会为了维护既得利益，故意控制发证数量。这合理吗？我认为非常不合理，但你得承认，人家把规矩写得明明白白。

回到国内，少数民族考生享受加分，北京公务员子女可优先择校，这些何尝不是一种“偏心”？汉族家庭或者普通市民觉得不公，完全可以理解。可这类政策是提前公示的，谁都知道它的存在。至于政策本身合不合理，那是另一个维度的讨论——你可以反对，但起码不会让人一头雾水。

反过来看那些被广泛接受的“优待”：铁路给学生半价票，星巴克和海底捞也专门给大学生折扣。凭什么没上大学的人不能享受同等优惠？你也可以说这不公平。但抱歉，规则就是这么定的，它清清楚楚写在公告栏上。

所以真正的问题在于：如果航班公司明文规定——只要飞机尚未推出，外籍旅客可上机，中国籍旅客不行——那我们当然可以抗议、可以吐槽，至少人家把条条框框晒出来了。规则即便再不近人情，只要公开透明，我们就知道如何应对。新加坡地铁内喝水会收到天价罚单，美国不少地方禁止在户外拉晒衣绳，瑞士某些老宅晚上十点后冲厕所都算违规……这些规矩听着离谱，但都白纸黑字在那里。

再回看历史，美国早年间对黑人的压迫就是通过法律明文确立的，正因如此，后来的平权运动才有了明确靶心。真正可怕的，是那种藏着掖着的歧视。今天的美国社会，对黑人的不公反而变得隐晦，不再落于条文。国泰航空的空乘人员就是典型——他们长期对讲英语者和港籍乘客殷勤备至，对内地乘客则冷脸相待。这种潜规则从不明说，却真实存在，叫人越发憋火。

说到底，明明白白的差别对待，我们至少看得清边界、找得到争取的方向；而暗地里的区别待遇，才最容易让人无力反抗。以上仅是一家之言，未必正确，欢迎交换看法。
