# 站在普通人的立场去设计教程，站在用户的视角去设计流程

做教程时，别把自己当成高手；做流程时，别把自己当成管理员。真正让内容受欢迎的秘诀，就是切换视角——教程要按普通人的认知来设置，流程要按用户的真实体验来规划。

很多创作者都会陷入误区：因为自己早就熟悉了操作，于是默认别人也同样熟悉。结果教程写得像说明书，术语一堆，步骤跳跃，普通人根本看不懂。教程的意义不是炫耀专业，而是帮助不懂的人理解，所以每多一个步骤说明，每加一个细节拆解，都意味着更少的人卡在半路。

而在设计流程时，又恰恰相反。流程不是给老板看的结构图，而是给具体操作的人使用的路径。如果流程只顾着系统化、规范化，却忽略使用者的直觉和习惯，用户就会觉得繁琐、冰冷，甚至抗拒执行。好的流程应该像一条顺畅的滑梯，让用户不费脑就能滑到底。因此，设计的每一步都要问：用户在这一步会怎么想？他的下一步期待会不会落空？

说到底，教程要“向下兼容”，流程要“向上适配”。前者以普通人的能力为起点，后者以用户的感受为终点。能同时做到这两点，你的内容自然会赢得人心。
