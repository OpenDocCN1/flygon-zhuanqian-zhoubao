# 95 年斜杠女青年靠商业文案小赛道，月收入突破十万

一个95年出生的姑娘，硬是靠“商业文案”这个小赛道，把月收入做到了六位数。她叫容棪，带着“斜杠女青年”的标签，目前主要做商业文案服务和AI训练营。不靠别的，单商业文案这一块，她平均每月进账3-5万；遇到双十一这种大促节点，还能直接冲到十万以上。

这条路的起点，其实很朴素。大学时的容棪就喜欢写东西，参加比赛拿过一些奖，接着便开始琢磨：能不能靠写作赚点零花钱？她什么都试过——写小说、代运营公众号、在本地创业服务中心做采编……凡是和文字沾边的，几乎都趟了一遍。试了一圈她发现，对新人最友好的，其实是商业文案：进入门槛低，市场上要的人却多，往后也很有搞头。

真正让她遇见“专业选手”是在2019年。那年她刚入职一家大厂，岗位是内容运营，日常工作里第一次接触正经的商业文案，顺带把副业也铺开了。在这个岗位做了两年全职内容活儿之后，她决定离开，跑去云南住了半年，一边休息一边接单；后来又在成都做了两年工作室，现在人在杭州，彻底走在了自由职业的路上。

前阵子双十一刚过，容棪晒出几笔大额收入，说零碎小单就不展示了。扣掉分给工作室小伙伴的那部分，她这个月又冲破十万。
