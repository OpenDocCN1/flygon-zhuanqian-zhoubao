# 从互联网炮灰到月入过万：我靠“人力资源代招”翻了身

各位赚钱圈友，我是“一术”。进圈已经600多天了，当初纯小白一个，如今算是熬成了持续创业者。这中间认知和见识都涨了不少，最该感谢的是赚钱这个环境，也特别感谢龙哥老大的无私分享。说实话，龙哥盟真的是创业者的福地。

刚加入时，我在基础资料里写了“3个月变现100万”，也因为这个被邀请分享过两次。但两次我都放了大家鸽子，不是故意摆架子，是真的看到圈友们的水平后自愧不如。后来我明白了，那100万里运气成分最大，不是我能力有多强，而是恰好踩中了行业风口。这里悄悄爆个料，那个风口行业是“债务协商处理”。

既然已经踩中风口，为啥还要换赛道？很简单，2022年初我就从那个项目退出来了。当时百度信息流的获客成本已经让人没法玩，最初25块钱一个加粉，后来涨到200块一个。行业本来就优胜劣汰，我这水平只能认输退场。吃过大亏后我彻底想通了一个道理：能力配不上财富的时候，赚来的钱迟早会凭实力亏光。

2022年我也没闲着，教培、抖音截流、小红书矩阵、群控，凡是和流量沾边的事基本都折腾了一遍。每天都在研究平台规则、顺应规则，确实有成长，但也得到一个血泪教训：手里没有本钱的时候，不要硬着头皮创业。抗风险能力太弱，平台随便一个小改动都能让你心态崩掉。最稳妥的路是老老实实上班攒钱，从副业慢慢过渡到主业。

回头看，互联网项目我确实摸爬滚打了不少，但到头来身心俱疲。很多风口红得快凉得也快，我想找一个能做长久的事业：不被某个平台的规则绑死，可以把互联网当成辅助，但不能完全依赖它。像我这种对互联网不算精通、只是“懂一点”的人，这种模式才更踏实。

后来我盯上了人力资源代招。为啥选这个？疫情之后，企业招不到人、求职者找不到工作的现象太明显了。尤其流动性大的基础岗位，几乎全年都在挂招聘。我们要做的，就是同时满足这两头：让求职者不再为工作发愁，让企业不再为岗位缺人着急。有过招聘经历的老板应该都有体会，一个岗位挂出去，每天来打招呼的人络绎不绝。有需求、有市场，这个方向能走。

再说，大牌招聘平台都在布局RPO，说明行业前景被资本看好了。目前国内人力市场还没有真正的巨头，也没有上市公司，跟着这些大平台走，至少证明市场还有肉吃。我们这边对求职者完全免费、完全利他，所以变现非常顺滑，典型的“羊毛出在猪身上，让狗来买单”。

接下来是实操经验，这些是我踩坑无数之后换来的，今天真诚分享出来。如果哪里讲得不对，大家多担待。

人力代招大致分三类：蓝领、白领、高端猎头。蓝领主要对接学历较低的求职者，多数进厂做计件工或简单重复劳动；白领是专科以上学历，担任客服、销售等基础岗位；猎头则专门挖专业领域的技术人才。

我们团队做的正是基础白领岗位，业务模式很直白：帮企业招人，收佣金。目前团队11人，每月营收差不多35万，靠的是电销加互联网平台引流。对外我们叫“官方岗位推荐官”，先用话术把岗位推出去，建立信任之后，再通过私域做长期的内推。

如果个人来做，基础领域不复杂，不需要研究高深的平台或市场规则。核心就是把招聘平台账号开好，岗位挂出去，然后多渠道收简历、约面试。新手第一个月，一般能收30到50份简历，成功入职5到8人，对应月收入5000到8000元。随着操作熟练、账号变多，收入也会往上涨。每个招聘账号成本约300元，投入和回报基本成正比。团队这边，目前加粉率约20%，一个员工每月能加600到800个粉，个人产值3到5万，投入产出比挺不错。

新手怎么接单？这个行业的核心就是一个字：快。你必须比企业自己招得还快，才能体现价值、拿得到佣金。初期没有单子，可以找人力资源公司合作，玩法有点像现在流行的线上民宿分佣。怎么找人资公司？有个传统办法很省力——你假装求职者，去招聘平台投简历，会有大量HR主动来约你。如果对方给的面试地址和平台登记地址对不上，大概率就是代招机构。加上微信后，谈成合作的机会很大。互联网渠道也简单，和找对标账号一个道理，搜招聘内容找到对应的招聘账号，直接加V沟通，最好优先找本地的。谈合作时要确认三件事：返佣政策、结算时间、保质期。大部分岗位是一次性返佣，入职就给钱；也有的工厂按小时返，比如对外给20块一小时，返给人资2到5块，只要员工一直在职，返佣就持续。但这种按小时返的模式我个人不喜欢，总感觉在变相剥削体力劳动者，当然见仁见智。

如果自己去企业拉单，新手大概率搞不定。我当时为了证明决心，加盟了一个大品牌，花了十几万，疼是真的疼。现在所谓的“大品牌加盟”，基本都是招聘平台自营，像BOSS直聘、智联、猎聘、58，加盟费普遍在几万到十几万，对个人很不友好。不过平台现在要的是市场份额、数据、用户量，钱反而愿意分给加盟商。所以圈友还是要理性，投资有风险，创业有风险，赚钱里牛人很多，多了解多聊再决定。

我目前做得比较顺了，就把这些平台的服务商身份都拿了下来，主要目的是保证岗位供应充足。如果有企业福利很好，我会跳过平台自己直接对接，佣金能多上浮10%到30%。其实拿一个平台就够了，成为岗位推荐合伙人以后基本不缺订单。后台会清晰显示保质期、佣金，期满自动结算。

接下来讲选岗位。开一个岗位要花100到300元会员费，选错等于烧钱，新手最容易踩坑。我总结了三个关键点：一看需求量，需求量小的岗可能几天就停招，岗位白开；二看面试场次，如果今天约到的人要等三五天才面试，对方大概率已经被别的公司抢走；三确定好方向，主推白领还是蓝领。白领在意五险一金、晋升空间和氛围；蓝领在意时长、包吃住和辛不辛苦。想清楚方向再开岗。我们团队曾靠一个企业岗位吃了一年，因为对方六险一金、面试通过率极高，所以选对岗位太重要了。岗位其实很多，前期多花点耐心。整个流程就四步：选岗位、和PM确认细节、定渠道、对接求职者。很简单，多劳多得，简历越多、面试越多，佣金越大。

![](img/a3760cc8dbd5a76e28ed9b11e57efa65.png)

最后说说两个阶段的玩法。入门玩法是注册BOSS直聘等主流招聘账号，开通岗位会员，把岗位福利待遇抄到招聘平台，可以略微包装一下吸引人，但不能离谱。接着对接求职者、约好面试时间，面试通过并熬过保质期，钱就到手了。保质期一般3到5天，也就是说求职者待满3到5天，你就能算佣金。很多圈友自己招过人都懂，一个月稳定入职七八个没问题，月入过万就是这么来的。流程不复杂，唯一要注意的是BOSS账号注册要场地验真。基础配置很简单：一间放得下桌椅电脑的空房间，一块40×60的KT板招牌，25块钱搞定，再加一张营业执照。一个执照能开通3个BOSS招聘账号，个人用绰绰有余。如果能借到朋友场地，成本直接归零。话说回来，这些招聘平台现在已经算红海，90%的团队都在用这套打法。

资深玩法就是去快手、抖音、小红书开账号矩阵，做短视频或直播来招聘。这些平台流量天然巨大，而且不算违规。

实际上，还有电销、账号矩阵、兼职群发、城市代理、全网卖项目招商、创业粉引流、兼职粉引流等很多玩法，我就不班门弄斧了。这个项目对小白来说，不可能一夜暴富，但胜在多劳多得，月入过万不难。对圈友来说，可玩性就大多了。

我是一术，一个走在人力资源行业前端的普通人。第一次写自己的行业，文笔有限，讲得不清楚的地方别介意。如果大家对这块有兴趣，后面我可以再写一篇“新手零成本入行”的实操文，内容包括：对接当地人资公司的话术和方法、引流同城求职者的方法及话术。最后，感谢赚钱、感谢圈友们的知识分享，你们的经验成就了现在的我。也欢迎对人资感兴趣的朋友来找我交流。
