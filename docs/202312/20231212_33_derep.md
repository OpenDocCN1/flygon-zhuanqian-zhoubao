# ('视频号直播间批量添加敏感词、隐藏视频、百应转达 人(插件和 JS 版)', (2, 37))

做视频号直播的朋友，天天为直播间违禁词发愁？手动一条条加太痛苦了。之前有人分享过JS版工具，有圈友反馈不太好用，于是作者干脆做了个插件版，用起来更省心。

插件支持几件事：一是批量导入敏感词，把违规词一口气全部设置好；二是批量让视频隐藏或重新显示，管理素材很方便；三是多了一个“巨量百应转达人”按钮，直播过程中转人更快捷。现在插件版和JS版都放一起了，还有操作视频，大家直接去飞书自取。
