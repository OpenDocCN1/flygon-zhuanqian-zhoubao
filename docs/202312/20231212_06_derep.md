# 做生意顺应人性，修行自己就要对抗人性

很多商业的本质，其实是读懂人，而不是改造人。

听一期老范和周百见的对话聊到知识付费，能听出来一个很现实的逻辑。周百见最初靠吐槽知识付费出圈，后来也入了局。她说不少付费博主内容并不差，但光堆干货很难卖得动。现在卖得好的，并不是直接教你成功，而是给你一种“我也能成功”的错觉。仅就商业而言如此。

为什么？因为真正让人成功是反人性的。人都想一夜暴富，却不愿意付出相应代价。而制造“你离成功很近”的感觉，恰好迎合了人性，因为谁都想发财。

人天生贪心、求快、好捷径，痴迷于一招打遍天下的神话。几年前创业浪潮里，就有人跟我聊想做沙拉、健康餐。我直接告诉他做不大。不是健康没需求，是人性本质上更爱垃圾食品。汉堡、烧烤的门店永远比沙拉多，这就是现实。

人性的洞察无处不在。朋友分析小宇宙的孟岩老师基金为何卖得好，说平台用户女性居多，女性更关注稳健理财，男性则更执着于一夜发财。这种差异，恰恰是产品打中的点。

看问题有两种路径：一种是理性，到最后是数学和逻辑；另一种是感性，到最后是人性。而创业、学习、健身这些事，在初期都极度反人性，没有内啡肽回馈前全是咬牙硬撑。只有不断与自己的惰性对抗，才能走下去。

我自己也每天在跟自己打仗。游戏、短视频、美食、各种发财的诱惑，时刻在消耗注意力，一不留神就陷进去了。

其实很多领域里拿到一个小确幸并不难，只要你真能沉心研究、反复练习三五年，超过九成的同行并不难。难的是，绝大多数人过不了人性这一关。而人性挡住别人的地方，恰恰就是你的机会。

评论区里也有不同的声音，有人提出顺着人性修自己更可持续。有人靠罚款打卡坚持运动479天，有人用惩罚机制逼自己读书写作。意思是不要硬碰人性，而是用制度牵着人性走，也能把事做成。顺势而为，利用机制，比单纯对抗或许更长久。

无论怎么选，核心都一样：看懂人性的生意，能赚到钱；战胜人性的自己，才能活得更好。
