# 一、不同价格带，话术骨架不一样

**低客单价：先养习惯，再拼价格**
核心是让用户觉得划算、好用、敢买。
顺序一般是：先塑品 -> 建立信任 -> 上优惠 -> 最后逼单。

**中客单价：先找痛点，再给方案**
核心是让用户觉得我懂他、能解决问题。
顺序一般是：需求引导放大痛点 -> 塑品 -> 建立信任 -> 逼单 -> 互动收口。

**高客单价：别硬造需求，重点在价值感**
核心是把产品讲成值得买的。
节奏建议：需求引导30秒 -> 产品介绍1分钟 -> 价值塑造1分钟 -> 建立信任1分钟 -> 逼单 -> 互动。

# 二、话术结构的实操拆解

**1. 需求引导**
先把场景丢出来，让观众对号入座。
比如：
你是不是明明买了好多条丝巾，每次出门还是挑不出一条拿得出手的？
要去参加婚礼了，你随手拿条路边几十块的围巾，真的说不过去吧？
过年朋友聚会，人人都精致起来了，你总不能寒酸。花小钱买条纯桑蚕丝围巾，瞬间体面。

**2. 价值塑造**
核心逻辑就是锚定一个大众认知的贵物。
比如：一匹蚕吐出的丝量等于别人4条；和白娘子赵雅芝同款；手工一针一线钩织出来的。让价值自己说话。

**3. 产品介绍**
至少拎出3个用户痛点，配上3个对应卖点。介绍到福利款时一定要点明链接位，比如主播现在讲的是福利款，直播间3号链接已经挂上来了。

**4. 抓注意力**
直播间里的人可能在做家务、吃饭、划手机，话术太平就直接走了。必须敲黑板。
来，姐姐们看我哈！
接下来我说的内容只讲一遍，听好了！
主播现在给姐姐们戴一下演示下，眼睛别眨哦！
我给大家看下这个细节，姐姐们别走神听好了！
很多姐姐上次没抢到，下播后就彻底没了哈。

**5. 互动**
互动是平台判定直播间质量的重要信号，有停留才有推流，有互动才有转化。而且愿意互动的人，更容易进入购买状态。
刘姐姐又来了欢迎哈，最近是不是晚上睡不着翻来覆去？跟主播说说，我给你对症推荐。
直播间有第一次来的姐姐吗？第一次来的扣个1，让主播看见。
觉得主播讲得在理的公屏扣个666。
认同的扣1，不认同的扣2。
已下单的姐姐打个已拍，让主播看到。
想要的姐姐公屏扣个想，我们就备多少货。
人少的时候一定要点名互动、定点互动，人多热情高的时候就别过度互动，节省时间直接转化。

**6. 建立信任**
尤其是视频号的中老年客群，线上付费习惯还在养成，过去被坑过的经历让他们很谨慎。所以要用人货场来托底。
公司是丝苑集团，前身是中国丝绸集团，国企背景，做丝绸100年了。
我们做这个品类已经25年了，全国95%的XX都从我们这里走。
全国有300多家门店，百年老店，今年才第一次上网卖。
是丝绸协会创始单位，证书专利齐全。
在🛰️大平台上拍，资金不到我们账上，7天无理由退货，钱原封不动退回。

**7. 憋单与放单**
憋单是制造供需紧张的感觉。讲完产品一定要憋一下，憋多久看氛围，氛围到位了再憋就流失。建议来个30秒的微憋单，放单时用5个数倒计时。直播时点开【讲解】同时把商品弹出来，并用手机演示下怎么下单。很多年长用户光听不看下方链接，这个动作能大幅提升点击率，这是我几百场试验出来的经验。

**8. 逼单**
尽快过年了，现在下单年前就能到！
今天拍，明天一早我就安排打包，直播间姐姐优先发货！
今天拍下再送价值88元大礼包，已拍的姐姐公屏打已拍，马上加赠。支持7天无理由退货，并且运费我们承担，你可以先免费试戴。
姐姐们手速太快了！库存只剩2单了，还有3分钟主播就下播了，下次来价格就不一样了！很多姐姐之前错过后来后悔，联系客服都补不上了！

逼单要看现场。购买热情高就反复逼单，穿插卖点加速节奏。热情低、新人多就回到互动、停留、塑品、憋单的循环里。直播间的人是流动且没耐心的，内容闭环要小，重点反复强调。讲完一个小案例一定要拉回主题。

用户下单其实要同时被说服三件事：
必要性：为什么要买，而不是不买。
稀缺性：为什么要买我的，而不是别人的。
紧迫性：为什么要现在买，而不是以后。

**9. 常见违规点**
广场能看到很多擦边玩法，但建议还是按规矩来。
敏感词别碰：最、第一、顶级、首发、100%等绝对化用语。
画面贴图别超过1/3。
必须有实物出镜，不能只有贴图。没有样品就用替代品手持出镜。
绿幕+视频混用容易被限流。

**10. 应变：把失误讲成优势**
尽量展示真样品。实在没有时别慌，自信是关键。你对产品没信心，客户更不会信。
如果被问到2号链接没样品，可以这样回：
姐姐们，这个款现在真的太紧俏了，样品都被抢光了。
这款原价上千，我们直播间样品申请很少，材质和1号链接完全一样。
