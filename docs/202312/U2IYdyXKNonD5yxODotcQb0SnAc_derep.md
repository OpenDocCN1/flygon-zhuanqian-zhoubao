# 别再手动存视频了！手把手教你搭一个抖音创意收集机器人
作者：龙哥

做短视频编导的朋友，是不是经常遇到这种情况：刷抖音刷到一堆好选题，赶紧手动保存、记分类、写数据，忙活半天才搞定一条，要是下班了，干脆拖到第二天。

今天分享一个超实用的自动化工具，能帮你把这些重复劳动全部省掉。这个工具是我一位客户朋友开发的，经他授权，我补全了操作细节，整理成一份保姆级教程，感兴趣的话你也可以自己搭一个。

这个工具是建立在飞书多维表格之上的，同时用到了飞书集成平台和飞书开放平台。它能自动收集短视频创意，把BGM一起存下来，还能自动提取视频关键词、打上标签，最后自动存进多维表格。对了，去水印功能也支持。

## 为什么会想到做这个？

MCN公司的编导部门，平时创作选题要刷完抖音热门视频，然后手动保存，再手动记录分类、互动数据等信息，最后录入多维表格。这套流程又慢又枯燥，重复性极高，而且经常来不及记。最快也要2分钟才能记录一条创意，要是下班在家，基本就拖到第二天了。

## 方案怎么定的？

开发前主要调研了三件事：第一，创意视频从哪里拿，PC还是手机；第二，平时怎么给视频打标签，需要哪些信息，比如互动数据、作者、发布时间、视频分类；第三，怎么才能全自动跑起来。

## 开发者踩坑心得

最后附上防踩坑指南，免得你走弯路。

- 抖音视频信息接口是手动抓取的，存在接口失效或更新导致集成流失败的风险，以上案例仅作分享。
- 下载的抖音视频不能大于20MB，如果超过20MB，需要用飞书集成平台的分片上传连接器。目前这个方案采用的是下载低画质视频来规避。
- 如果出现不返回challenge code的情况，先发布集成流，再填写第一个节点（网址触发器）里的回调地址，同时要把开放平台机器人事件订阅里的key清空。
