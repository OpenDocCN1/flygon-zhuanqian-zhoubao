# 拍脑袋，该怎么拍得漂亮？

真正聪明的人，从来不是非黑即白地做选择，而是能在脑袋里同时装下两套相互冲突的想法，并且照样把事情推进下去。

这份并行思考的能力，本质上就是给直觉装上校准器。很多人把“拍脑袋”当成蛮干，其实最高级的拍脑袋，是带着概率在拍脑袋。贝叶斯思维就是那个校准器，它让我们用先验经验做起点，用新证据不断修正，而不是一根筋到底。

普通人完全可以用它来过日子。比如出门要不要带伞。天气预报一开始说下雨概率50%，这是你的初始判断。走出门看到天色骤暗、空气发闷，这就是新证据。结合过去多年“阴沉天基本会下雨”的经验，你会把概率主动抬高到80%左右。于是带伞的决定就从玄学变成了可追踪的更新。决策依然快，但底气不一样了。

这套逻辑放到工作里同样好用，尤其是产品经理这种天天在信息不全里做赌注的角色。刚立项时，你基于调研和用户访谈，觉得某个新功能有70%的胜算，这就是先验概率。开发到一半，竞争对手忽然上线了几乎一模一样的功能，这就是强证据。按照贝叶斯更新的思路，你必须把“对手已出”这个事实喂回模型里，重新算一遍。结合历史数据，很可能胜算会从70%回落到50%甚至更低。于是资源分配、优先级排序、迭代方向都能跟着立刻调整。

不管是带伞还是做功能，核心都一样：先有判断，再用新信息不断修正判断。先验不代表固执，更新也不代表摇摆。能同时容纳“我想成”与“可能不靠谱”两种念头，并且让概率自己说话的人，才能把看似随意的拍脑袋，拍得既快又准。
