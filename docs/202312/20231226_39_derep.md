# ('你可能不喜欢抖音-TikTok，但它做成的事情，确实是空前绝后的', (2, 34))

就算你对抖音/TikTok没什么好感，甚至有些抵触，也不得不承认，它做到了一件事，放在整个互联网史上都是头一遭。

今年美国网络广告市场的格局，出现了一个堪称分水岭的变化：谷歌和Meta这两大巨头加在一起的广告收入份额，首次降到了50%以下。过去整整十年，这个比例从未被撼动过，如今却悄然改写。

要知道，广告市场的蛋糕就这么大，你多拿一口，别人就少咬一块。这背后可没有什么“共赢”的童话，而是一场赤裸裸的零和博弈。那么，究竟是谁从这两家巨头的嘴里，硬生生分走了这么大一块？

答案只有一个——客场作战的TikTok。一个外来者，在别人的地盘上，硬是撕开了一道口子。

这，才是它真正让人服气的地方。
