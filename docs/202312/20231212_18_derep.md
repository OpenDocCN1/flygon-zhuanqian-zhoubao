# 假唱与商业道德

前阵子，假唱又成了热议话题。其实关于这件事，我想换个角度聊聊：真唱还是假唱，或许根本不是最核心的问题。

我年轻时候在炼油厂上班，还参加过市里组织的职工合唱比赛。说实话，我天生五音不全，就是凑数去的。大家排练了好多次，结果到了正式比赛现场才发现，根本不用出声唱，只要对口型就行，现场放的是之前排练录好的音。我当时挺惊讶，但也很快想通了——因为所有参赛队伍都心知肚明，这是大家默认的玩法。

后来我才知道，春晚也干过不少次这事儿，甚至很多届都这样。想想也能接受，毕竟观众又没花钱买票，而且媒体早就公开聊过这个话题，算是大家都知道的秘密。大张伟也大大方方承认过，自己上春晚就是假唱。

所以你看，演唱会假唱的问题，真不是“假”本身，而是你有没有坦白告诉观众。这就跟买卖东西一个道理：顾客在意的不是东西是真是假，而是你有没有让他清楚知道情况。

比如说，有人花五十块买了个“路易威登”的包，那他也明白这是仿货。只要卖家明说这是假的，交易中就没撒谎。至于卖假货合不合法，那是另一码事。

放到营销圈里，现在满屏都是带着误导味的宣传。比如网上那些便宜到离谱的“原切牛排”，内行一眼就看出不对劲——那个价位根本不可能是原切。那它是什么？多半是掺了大豆蛋白的调理肉。但说实话，掺大豆蛋白本身不算缺德，美国那边牛肉、鸡肉制品也常这么干。关键是，你必须把配料老老实实写清楚，买不买是顾客的选择。

再比如吃火锅必点的蟹棒，名字带个“蟹”，其实一丁点蟹肉都没有。可人家包装上写明白了，这是鱼糜制品。只要不硬说自己是蟹肉，就不算骗人。

还有网上特别火的蟹黄面，其实也有点把消费者绕进去的意思。你翻一下配料表就明白了，里面主要就是鸭蛋黄和胡萝卜——鸭蛋黄模仿蟹黄蟹油的样子，胡萝卜模仿蟹黄一块块的口感。想吃真蟹黄？建议先看看配料表再下手。

咨询行业同样如此。你拍着胸脯跟客户讲“这么干肯定能成”，这本身就是忽悠人。因为没有任何人能保证一个项目百分百成功，商业世界没有“一定”这回事。

所以商业和营销上，你可以卖品质好的，也可以卖品质差的，甚至可以卖非常次的产品。但有一条底线不能碰——你不能做不实宣传，不能骗人。这才是真正的商业道德问题。

美国上市公司搞注册制，核心逻辑也一样：你只要如实披露企业的真实经营状况就行，赚不赚钱反而次要。假唱可以，卖“假肉”也行，但前提是，得让顾客知道实情。

有人会抬杠：那直播美颜算不算假？这确实也是假，我们见面寒暄说“久仰久仰”也不怎么真。但合不合适，社会有一套集体价值观在那儿管着呢。演唱会假唱，全社会基本都反感；春晚假唱，算是有争议但能忍；直播开美颜，观众普遍知情，社会也能接受。化妆也是“造假”，但没人觉得有问题。

所以说到底，道德不道德，得看当时的社会价值观怎么认。
