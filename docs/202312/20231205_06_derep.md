# 做营养师副业的五点实操自检

原文：[`www.yuque.com/for_lazy/thfiu8/ffg99lp1pv2as9vi`](https://www.yuque.com/for_lazy/thfiu8/ffg99lp1pv2as9vi)

大家好，我是龙哥。昨天和几个小伙伴聊了营养师IP怎么起盘、怎么变现以及怎么拿到正反馈的问题，有人反馈挺受用。今天借这个平台，把这些心得也分享给那些想做营养师副业，或是已经在做营养师但还没理清商业路径的朋友们。希望能带来点启发，也欢迎一起交流。营养师这条赛道，抱团共创才会更好玩。

先说个背景，我带的私教学员背景很杂。有美国本硕连读的科班生，也有在职考证、想转行的老鸟，还有本就在行业里做运营、做产品的非一线营养师。我的合伙人也是个在平台上有点粉丝量但没什么流量的小V，还有实体店和培训机构的老板纯因信任找过来。

大家都带着热情和期待，但热情归热情，规划还是要落地。

**第一，别一口吃成胖子。**

最近我在陪学员们打磨第一个微型产品，最深的体会就是先认清当下再谈下一步。

我们团队自己也在做2024规划，3月和10月会做两个事件营销。但12月的地基没打牢，那两个月就容易成空中楼阁。

所以12月启动、月月迭代，比只盯着明年大目标更重要。一个月的积累决定了下一季能不能站得住脚。

**第二，先要流量还是先要钱？**

这点是从第一点延伸出来的。群里很多人都在做个人IP，也有了些成绩。

粉丝量能证明专业度、秀实力，但如果目标是商业变现，粉丝量只是手段。

精力有限的情况下，与其两头空，不如先抓住一个能落袋为安的点。一鸟在手胜过百鸟在林。知道林子里有鸟，先抓到一只再说。

不要最后粉丝没起来，钱也没拿到。心安理得的躺平，也比盲目内耗强。

**第三，内容必须能接住产品。**

一定要有清晰的产品承接，不然内容再好也白搭。

比如我一个做上班族减脂的学员，产品就是帮上班族减脂。可以做课程、训练营都行。

内容可以很宽泛，围绕上班族关注的热点去做：大厂裁员、平台波动、年终奖、年底加薪等等。这些和产品看似不相关，却是精准人群的流量密码。

最终成交都在私域🛰️里，能不能被加进来是关键。被加了，时间到了成交就是自然发生的事。

所以反复问自己：我有没有一个能承接流量的具体产品？我是不是在为这个产品做内容设计？成交有玄学，但前提是你先做了。

另外，关于咨询边界也说一句。有些问题三言两语能讲清，有些讲不清，也别指望别人免费帮你讲清。知进退，少白嫖也少被白嫖。

**第四，先做起来，再谈壮阔。**

最近合伙人的学员做增肌项目，首单499就到手了。

有人还在纠结是做减脂还是减重、是选增肌赛道好还是其他赛道好，选来选去不如先做一个。

好坏不在于赛道本身，而在于你能不能先做出一个结果。哪怕12月你只做了一件小事，副业多赚了1000块，或是收了一个99元体验，都能证明你走通了第一步。

**第五，正反馈要主动去建。**

正反馈可以是专业解决了问题拿到了报酬，也可以是别人对你的认可。

但前提都是你先行动了。正反馈多，说明方向大致对；正反馈少，可能路径不对、圈子不对，或是需要更多时间沉淀。

没有人会不喜欢被肯定。自己给自己建立奖励机制，同时主动收集外界反馈，别让自己做着做着就泄气、进入负循环。

少贪心、少好高骛远，每一步都有成就感，循环滚起来。或许2023的最后一个月，你就能先感受到那份精彩。
