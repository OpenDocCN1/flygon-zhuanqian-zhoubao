# 【龙哥盟分享】小红书无人直播挂商品及开播实操

### 小红书无人直播到底怎么跑？从1688铺货到开播挂车，这份实操请收好

很多圈友对小红书无人直播有兴趣，但卡在店铺开通之后那一大堆细节上：货从哪里来、怎么搬上架、订单怎么发、开播时商品又该怎么挂？今天这篇就来捋一遍完整玩法。内容来自龙哥盟的实战分享，亲测可参考。

先说开店。按照航海手册完成小红书店铺注册后，第一步别急着铺货，先想清楚主体：个人店、个体店还是企业店。主体影响后续资质，类目的选择更关键。我自己开店时类目选得少，后来想换品只能反复补类目，每次都要等审核，一般3天左右，特别浪费时间。所以建议一开始就把可能卖的、甚至将来想做的类目都勾上，一次性审完，后面就省心很多。

店铺开好后，选品我走的是1688路线，铺货靠小红书服务市场里的工具完成。服务市场入口在这里：https://fuwu.xiaohongshu.com/serviceHome 。我用的工具叫“无忧铺货”，链接放上：http://hongsnatch.4k5.cn/SnatchCps#/Offer_Link 。这类插件功能都差不多，基本都有免费试用，觉得顺手再付费，价格也不贵，折合下来一个月就是一杯奶茶钱。

![](img/2444de4608f00c3060c61c787688ffeb.png)

无忧铺货的操作很简单。进入工具，选“商品链接铺货”，然后回到1688商品页复制链接。链接可以一次复制多条，系统提示最多支持100条；注意每条链接单独一行，别全部挤在一个格子。复制完点下一步，界面会展示准备铺货的商品图，把左边的小方框勾上，再选“选中铺货”或“全部铺货”就行。之后系统会自动跑铺货，等一会儿即可。如果看到“任务失败”，点进去查原因，绝大多数情况是类目不对。这里再次体现类目前置的重要性：加类目的入口在千帆后台 https://ark.xiaohongshu.com/app-system/home ，具体路径是：店铺—品牌类目资质—类目管理—新增类目—添加类目。![](img/3fa93d6d6fa6a8c9ec64e738ed59ce44.png)![](img/e082a0ff59f7f9a161c943bf974f8bfa.png)![](img/646718a669d25c58b1b9374893f7cb25.png)![](img/5f59b74a851c8cab579e932e261ce3e0.png)![](img/f91a7ac4c4157621db5a74ac7a7b7a0e.png)

铺货成功的商品不会直接上架，而是先放进仓库。你可以用手机打开小红书，进店铺看全部商品，到“未上架”列表里确认。有时候商品会提示审核不通过，![](img/c7dff6bb14f8c75bc071fb42ee0f8698.png)![](img/7c0c09495fef157454c6d2eb69e5d502.png) 最常见的原因是1688的图片带水印，小红书审核过不了。解决办法是“洗”一遍详情图：用手机编辑商品，或者去千帆电脑端调整详情内容和图片，系统会明确告诉你哪些地方不合格，跟着提示改就行。改完别忘点“上架”。

想边做边学的话，小红书电商学习中心有大量免费视频教程：https://school.xiaohongshu.com/course/list?categoryNo=20210515002&jumpFrom=search01 ，搜你关心的关键词就行。

商品搬完，接着就是采购和发货。我一般用“逸淘”来批量下单、自动发货。第一次使用会提示装插件，网页会自动弹出下载入口，按自己浏览器选择对应版本，比如我用谷歌就下谷歌版。![](img/e0faa2d85bd133658aa55f187830a248.png)![](img/8bc09e76cdb9f258aa7738619673d610.png)

装好插件后，用小红书店铺账号登录逸淘，系统会把待发货订单展示出来。接下来点“关联宝贝”，把从1688找到的货源链接复制进去，页面会跳出1688登录弹窗，登录授权成功后基本就打通了。需要留意的是：很多商品有多个SKU，务必选对要买的规格，别等下单了才发现买错。![](img/b0cd0fdbb7c80e2069d8f30aa2de0995.png)![](img/bb597e88d43e00709662e41d48adcf61.png)![](img/b3e2d64b6c66ce5b46a63edf748bf5ee.png)![](img/4a3e5bcd5dd3e5cd7b46140c85cf5268.png)![](img/2e4fb128008f5edd36448be9cda209f4.png)

如果输入链接后提示“链接错误”“无SKU”之类，无法下单，很可能是你在1688拿的不是“一件代发”选项对应的链接，回去检查页面，切换到一件代发入口再复制。

确认无误后，点“分销下单”，弹窗里会显示要买的商品，快速核对品类，没问题就点右下角蓝色“分销下单”按钮。我习惯把所有订单合并付款，付款前会再进1688核对买家信息；左边那个1688按钮也能直接跳到网站，方便切换查看。![](img/106652c87aee8d0e9ffd1713dd8277c1.png)

发货方面，逸淘界面右边有个红色“开启自动发货”按钮，打开之后系统会自动监测：只要上游发货了，订单就会自动同步发货状态，不用一直守着。![](img/6e076fc4cd8feaf53bfd471778d4674d.png)![](img/d1d7a0d726c6d9a14a05790b808a546e.png)

到这里，很多人的卡点就来了：物流模板。无人直播对发货地特别敏感，如果买家看到的发货地和1688实际发货地对不上，平台可能判定你是无货源，轻则限流，重则处罚。我之前就连续两天开播被提示无货源，后来看到圈里曜文大佬发帖子才反应过来，幸好只是限流，没扣分没罚款。![](img/8592d7f672be8711d7b52614de7d7a20.png)

我的做法是提前在千帆电脑端维护地址。如果同时选了好几个品，那就把地址库管理里的多个发货地都新增好；1688页面一般能看到具体市、区，按这个填个大概即可。然后把“发货默认”和“退货默认”都打开。开播前，今天准备播哪个品，就把它对应的发货地设为当前默认地址，这样买家看到的发货信息就和1688一致了。![](img/4be6f3d932fd5ff9f814d2012494356c.png)![](img/9a613393dc79c3964aa182c5a324b000.png)

运费模板也要提前设好，主要控制偏远地区送不送、要不要额外收费。我一般默认偏远地区不配送，把常见偏远省份加进模板就好。这个设置的关键作用在于：万一爆单，能少一堆麻烦，偏远订单的售后和退货尤其难处理。

手机端的模板设置不如电脑端细致。入口在千帆App首页，往下拉点“全部工具”，再找“物流设置”，相关模板都在里面。这里提醒一个细节——退货地址。因为发货地址是按1688大概填的，并不是精确门牌号，买家申请退货时，系统会弹出这个不具体的地址。所以我会在退货地址字段里做一小段说明，让买家先联系我拿详细地址。顺便问问退货原因，顺便做一下产品调研，等于多了一个售后机会。![](img/246d000b7e1b418497d2185f2312d86e.png)![](img/35b0f7bdbfe3b545802a7cee0459aed7.png)![](img/f248fd89d66a1f90bca70a9c9ad48e77.png)![](img/604092eba61c079786ce975585a093ce.png)

优惠券也要记得设置。打开小红书App，从主页的“管理店铺”进去，往下拉找到“优惠券”，点+新建。按照需求选择店铺通用还是指定商品；推广渠道我一般选“店铺新人券”。接着设置有效期、领取数量等信息。最后一定要拿别的账号测试一下：优惠券能不能领、下单能不能正常抵扣，避免实际用不了。![](img/ab261ea03cacf76561e1aa59f46fef66.png)![](img/ebb246fb55061afa089a2eb425468bc1.png)![](img/d8eb2d5382328e81a3226bba986b9c64.png)

开播流程其实很固定。先把商品正式上架，再把物流工具切换成要播商品的发货地。![](img/0d8e900eadf4c175f9d7376bf76c78e5.png) 然后开播，进入直播间后把商品上架并开启“弹卡”，让商品卡片能正常弹出去。![](img/06b69d260e15696c792faa94f41ef1a3.png)![](img/3c8194585c0e58916c83d93b4163387a.png) 在直播间里可以领直播奖励、做任务拿薯钻，薯钻后续有用，还能通过任务获得直播曝光卡。![](img/4a3301f726815fbff0cd1ff5c6222d4f.png)![](img/c05914f9965a2bb4d3d5c6f24312bc55.png)

曝光卡这类道具有使用有效期，别攒着舍不得用。路径是：直播界面右下角点“更多”，选“直播送礼”，再打开“背包”，就能看到所有道具卡，在有效期内用掉即可；后续任务会继续补。![](img/b881f6230b01f7bbd19b0c91608306c4.png)![](img/742b0facad1d798620ce62bdf9a6545a.png)![](img/aa222cec8b824d28c721313186c9722e.png)

结合之前分享过的“抖音直播录制放到小红书无人直播”内容，完整的链路就是：选好直播间—用江小二工具箱录制直播内容—用剪映查关键词—用OBS和小红书助手开播。店铺侧则是：先把商品上架到小红书店铺，提前建好物流模板，开播前切到对应模板，开播后记得弹卡、领任务，结束后再复盘当场直播数据。
