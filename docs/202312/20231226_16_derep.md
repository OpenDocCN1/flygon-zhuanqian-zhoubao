# 从教培老师到20万副业收入：我靠「葡式成交」把📕咨询直接变现



## 教培人做副业月入破万？我用这套成交逻辑一年变现20万

作者：葡萄
日期：2023-12-20

大家好，我是葡萄。先做个自我介绍，我目前在📕专更教培销售干货，粉丝量1.9万，今年靠做副业实现了20万的收入。

这20万的构成是这样的：私教业务占了约三分之二，剩下的三分之一来自社群运营、课程售卖以及分销合作。

回头复盘一年的成交数据，大概服务了近40位私教客户。其中真正从社群、课程里低价转化上来的，不足10个。大部分客户，都是📕私信引流进来，加到🛰️后，1天内甚至3天内就直接成交了。

这让我意识到，比起花时间做长线孵化、低转高的高客单成交，我的强项其实是「快刀斩乱麻」的当面谈单。

谈单，对我来说就是降维打击。

如果你也在做知识IP或销售，应该都踩过这几个坑：客户咨询时热情很高、付费能力看起来也不差，最后却莫名流失；一个客户要养很久、反复建立信任才能推进；明明产品过硬、流量也不差，就是卡在最后一步谈不下来。

针对这些痛点，我整理出了一套自己的成交方法论，内部叫它葡式销售法则。
