# 闲鱼数码赛道半年 210 万销售额技巧

半年210万！闲鱼数码还能这么玩？01年小白掏心窝分享

大家好，我是龙哥，01年生人，当初从电商小白一路摸索，过去半年在闲鱼数码赛道做到了210万销售额，到手利润差不多70万。这期的内容信息量比较大，我打算分开几篇慢慢讲。

最近总有人抱怨闲鱼封号严重、流量掉了，觉得没法做了。但我的亲身体会是：如果你愿意在一个类目里深挖下去，其实一点问题都没有——至少我们目前的数据报表一直很健康。每一年都有人说环境变差，可每一年照样有人悄悄赚钱，不是吗？


下面回答几个被问爆的实操问题。

不少小白问我：电子产品在闲鱼本身卖不起价，无货源到底要去哪里进货？我的常用路子是：
第一，拼多多，专门找低价商品下单；
第二，返佣平台，利用链接佣金赚差价；
第三，阿里巴巴，联系源头工厂，加🛰️慢慢聊，看能不能谈到更合适的供货价；
第四，多混一些华强北数码资源群，积累靠谱的商家，时间久了自然有门路。

不过也要把丑话说前面：无货源的利润空间注定比不了那些有源头渠道的卖家，别抱太大幻想。

至于发货模式，也有人问是自己囤货还是工厂代发。我们目前是两条腿走路：大部分货自己备起来发给团队，少部分特殊型号来不及囤货，就让工厂直接帮忙发。能做到这一点，是因为合作久了——前后累计跑了起码2000台货，工厂给我们的价格有优势，而且发货从来没断过，彼此都很信任。

对了，关于很多人担心的“乱封号”问题，不用太焦虑，我之后专门出一期讲怎么降低风险，感兴趣的记得先关注我。

最后想说一说“大环境”这件事。财富从来不会凭空消失，它只是从一个地方流到另一个地方。无论什么时期，总有人在赚钱，只不过你不在那个圈子里而已。那些天天喊环境不好的人，往往是在上一波风口里赚到了钱，如今风口转移，老赛道收益断崖式下跌，自然得出结论说是环境的问题。聪明人不会去抱怨，他们会去观察现在赚钱的人在做什么，然后主动靠近。
