# 手把手教你使用影刀RPA批量获取📕低粉爆款的商品！全自动解放双手！
作者：龙哥

标题：我用几个星期写了套影刀RPA脚本：自动筛选📕“低粉爆款”商品，从此告别蹲品

如果你刚做📕电商，大概率卡在选品这一步：数据平台动不动就是会员费，新手买不下手；自己一个个盯对标账号，又累又重复。如果你也懂一点影刀RPA，这篇文章会很对胃口。虽然下面代码量看着有点多，但真正的难点只有思路。我玩影刀前前后后才几个星期，能写出来，说明真的不复杂。

这篇不打算让你“复制粘贴就跑”，因为脚本是在我的手机环境里调通的，换个设备很可能跑不了。我更想把整个设计思路讲透，以后遇到其他平台的抓取需求，你也能自己搭出来。文末会放上代码参考。

先说我为什么想做这个：📕电商新手最怕选品，付费工具太贵，只能手动翻对标账号，看到销量不错就跟着上。这活儿动作重复、耗时间，特别适合交给RPA去跑。注意，凡是放之四海皆准的原则：一切重复性操作，都可以考虑交给影刀RPA。

我的筛选标准是“商品销量超过100，店铺粉丝少于200”，这个思路参考了书豪分享的选品方法。![](img/0734104d07072397d60163fa86f8a3ba.png)

动手写代码前，我在手机里完整过了一遍人工流程：
1. 打开📕App，点击左下角的购物入口；
2. 等待商品列出来，点进第一条商品链接；
3. 先看销量，大于100才有继续的意义；
4. 点店铺图标看粉丝数，低于200就返回并记录/分享链接，高于200就回购物页看下一个；
5. 销量不达标也直接返回，看下一个商品。

别小看这个流程，把它画成流程图，写代码时脑子才不会乱。每一个环节再拆成子流程，以后改起来、排查报错都轻松很多。![](img/b58c1f1ee29c715591ca58c3e7aab6c4.png)

接着配置环境。电脑端在影刀「设置中心」里找到「自动化插件」，安装Android自动化组件；手机端开开发者模式、USB调试，连电脑时选文件传输。第一次连接影刀手机管理器，会自动往手机装插件，一路点同意就行。我用的是小米9A，具体操作可以看官方文档。![](img/a294a1dffbbe92b6d58125e9b4dc75e7.png)

真正写代码的第一步，是让手机稳定连接上影刀。这步不通，后面全是空谈。连接失败就回头查官方文档，实在搞不定可以找官方远程协助。我当时用模拟器折腾了挺久，最后还是请人帮忙才弄好。![](img/1baa6a3aba67f48a83a1b789203b0568.png)![](img/6c10890760b75503678a3c8da793f166.png)

连接成功后，打开📕App。这里直接用“打开手机APP”命令，包名那栏如果是空的，先在影刀手机管理器里打开📕，再点按钮获取。接着用捕获元素的方式抓到购物图标的坐标，点它进入商品阵地。我加了2秒等待，因为手机卡的时候页面可能还是空白。![](img/1bae861e379fd8d148e68eaec87524ac.png)![](img/e933445696da06b93f73e4f1a081a69c.png)![](img/4ab61374a063c5999ec076ed4cfacfad.png)

接下来进入第二部分：获取商品链接列表。我用“获得相似元素列表(手机)”命令抓取当前页面的所有商品，把列表命名为“商品链接_element_list”，然后交给“循环相似元素(手机)”去逐个点击。![](img/0a7e238b468933bbd8178c7bf621e048.png)![](img/9c0aa2c4135a5499a52043cead5192b5.png)

第三部分最核心，要先搞定两个关键元素的定位：已售数量和粉丝数量。直接用界面捕获经常不稳定，或者换个商品就失效。所以这里用XPath定位：
- 已售：//*[contains(@text, "已售")][1]
- 粉丝：//[contains(@text, "粉丝")]/preceding-sibling::
捕获时记得把定位方式选为“Xpath”。元素齐了，后面的判断就可以按流程图走了。![](img/b8dd45ce7b95de98d6ef9855162b11ec.png)![](img/a70dd7e7dfaf0da861e9f34175b515c2.png)![](img/75e7cdc0e70b8700463c9793512efa7e.png)

到了判断环节：读出已售元素文本，常见两种样子——“已售4.4万”和“已售328”。带“万”就提取数字再乘以10000，没带就取数字部分当销量。利用IF判断是否大于100，大于就继续进店铺页面拿粉丝数，粉丝数同样要处理“2.8万”和“3266”这两种格式。为了不把主流程弄乱，我把获取粉丝数量单独做成了子程序，随时调用。![](img/5e9db7a2b310f4663a4155a146623486.png)![](img/721a923eb71b5853d4f9ec08a796b3be.png)![](img/8e55bda75158a54e6c367c0e0e233360.png)![](img/996d472ea09915c892506e9b892245a8.png)![](img/2ca499abec4e5733f265d2b076b7b81c.png)![](img/f14bf6e8109e665a2ce3104e44489762.png)

接下来是分支：
- 粉丝少于200：从个人主页返回商品页，点右上角三个点，再选“分享到🛰️”，发到指定的好友或群，目标链接就到手了。![](img/a49bd08a2d07040939ce2618f16e9b9c.png)![](img/3a22f356396e21e686e17b86e4286d6e.png)
- 粉丝大于200：返回两次，一次回商品页，第二次回购物主页，继续下一条。
- 销量小于100：没必要留下，直接返回购物主页。别忘了当前还在商品详情页里，必须先返回到购物页再获取下一组链接，不然会报错。这个逻辑用IF/ELSE包起来，清晰明了。![](img/d14b48a6c35d41aca5558dd2115a66de.png)![](img/e6d681f9ef0a643101602b72909cf7c1.png)

基础版本跑通以后，进入调试阶段。先看脚本有没有报错、是不是会空转、抓取逻辑对不对。改代码前一定要备份，我是备份了好几个版本才敢动。![](img/2fd8bf7fcd550eff800cad8a6db3932f.png)

我踩过四个比较典型的坑：
1. 匹配到多个元素，无法唯一定位。有的商品页面会出现两个“已售”，解决办法是在XPath最后加[1]，取前一个。
2. 循环时下标超过最大值。多半是手机卡在了个人主页或店铺页，商品列表没取到。解决方法是在循环里补上返回购物页的动作。
3. 商品没有已售信息，销量为0，元素直接获取不到。在“获取元素对象(手机)”里加个判断：已售数量为0就跳过这次循环。
4. 商品主图太长，已售元素在屏幕外面。加一个“屏幕上滑”动作，把元素滚出来。![](img/ff4d24e72b3b0112041f4c6492657c63.png)![](img/851bf99e7e3e9f9140c3c5646a45bf21.png)![](img/682477e65802b83817869d2f8ecef256.png)![](img/675807675ee3562779f37da4691a604d.png)

想要它全天候帮你干活，就得加循环和定时。我在最外层套了“无限循环”，用全局变量控制次数，再配一个自定义对话框，让使用者自己选择抓取次数，包括无限抓取。退出条件设置好之后，就能固定次数跑或一直跑。定时运行直接在影刀主页面的“触发器”里设置，每天定时、隔几分钟跑都随你。![](img/482bdd4612e866287218f2e7e0721666.png)![](img/6acb2cbcffec21851b81f0b5d606984f.png)![](img/2a1558fa45930cb49d8c8fd57931041e.png)![](img/11ed9588115c4c947dbac97e5bbcc0cd.png)![](img/0c6ad087faef1573bd3c7510684120d8.png)![](img/b30f2ad6ab502ce15c24fae06839938c.png)![](img/cbc9dfd469ad21e516ab59fadaad07bf.png)![](img/967df534ad418309961d76179524b390.png)![](img/8d9f527abc9347a95367cdd0fe31fbbf.png)

选品脚本最怕遇到页面异常，我再用Try/Catch做兜底。简单解释：Try里的代码正常时，Catch不会触发；一旦Try中报错，立刻进入Catch处理。我的做法是先记录错误信息，再判断是哪一类问题。最常见的是卡在个人主页拿不到商品链接，那就连按两次返回，再做一次上滑刷新，让脚本回到正常状态，继续抓取。![](img/36e3534dab74aaced486ce6fb1c97c3a.png)![](img/f23a8b262538dd61be42a3a380c83c82.png)![](img/a5ab3d005eb0106bcdb448a7502cea4f.png)
