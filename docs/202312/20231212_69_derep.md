# 搭班子-定战略-带队伍
作者：龙哥

联想集团过去一年的成绩单很直白：营收 4240 亿元人民币，净利润 129 亿元人民币。

数字背后，管理层反复提到的核心方法论其实只有两条线。

第一条线是做事的框架：搭班子、定战略、带队伍。先把合适的人配齐，再把方向锚定，最后把人带起来走。

第二条线是校准的机制：复盘、批评与自我批评。做完就要回头看，问题摊开说，责任摆上台。

这两套做法，就是联想集团管理实践里被不断强调的重点。
