# 学渣三个月做出30门大学课程，GMV破100万：这个野路子，我服了

你敢信吗？一个对专业课程几乎一窍不通的学渣，竟然在三个月里做了30门大学期末复习课，营业额干到了100多万。这个项目我已经做了快两年，除了口罩那段特殊风口期，现在每天都有稳定的管道收入。

先说需求。现在的年轻人上大学，谁还没翘过几节课？到了期末，最怕的就是挂科。我们做的“不挂科”系列课程，就是抓着这个痛点：不整虚的，短时间录播课，直接划期末考试重点。学生从头到尾看一遍，两三个小时，心里就有底了。卖点就一句话：认真看完，不挂科。刚需+便宜，转化率自然差不了。

## 找合作老师，才是这个项目的生死线

整个项目最重要的环节，就是找人帮你录课。这一步，我给它打95%的重要性。一开始我试过豆瓣、大学老师、同学介绍、B站，各种渠道都聊了，合作率惨不忍睹，聊50个人能成1个就不错了。后来灵光一闪，去闲鱼搜“工程力学辅导”，结果直接打开新世界。前后聊了大约100个，确定了25个老师，质量还都很高，好几个是专业课成绩排在前十的研究生。

![](img/39be23204887ba8e72f8033fdd6da3f8.png)

跟这些老师对接时，有两个小细节决定了成败。

第一，打招呼的话术。我最早的破冰文案，只顾着说“有报酬”，但没说多少，回复率极低，差点就放弃了。

![](img/e74f29275ec6c1d32c3514933416b220.png)

后来改了思路，把报酬金额直接写明白，比如明确数字，回复率马上就上来了。

![](img/cb407cdfaf7242be78c1775d7aa1f2d0.png)

人都这样，具体的好处比模糊的承诺管用一万倍。

第二，合作讲解的话术。闲鱼上所有动作，目的就一个：把老师加进微信，然后深入聊。在微信上准备一套标准话术，沟通效率能提高很多。主要讲三点：一，合作内容：我们做大学生期末专业课复习课程，看到你之前在闲鱼上发布了辅导的帖子，觉得你专业功底扎实，想邀请你参与；二，合作方式：报酬丰厚，录一门课给5000块（具体根据课程的受众和难度定）；三，制作流程：整理考试重点，做成PPT，再对着PPT录讲解。

## 试课—合同—交片，每一步都是避坑指南

正式开工前，先让老师录5-10分钟样片。看样片主要看四点：PPT是不是我们要的样子；讲课风格学生能不能听进去；设备有没有出问题；还有哪里需要优化。样片过关，就签合同。合同不是走过场，一是让老师觉得靠谱，有信任感；二是让老师有压力，能按时交片。

等课程交付后，审核人员必须一集一集全部看完。很多老师会带“嗯、啊”之类的口头禅，后期要剪干净。更重要的一步：正式上架之前，先拉一批学生免费看，谁能找出课程里的问题，就给现金奖励。这一步太关键了。因为我本身不懂这些专业课，知识点有没有讲错根本判断不了。让真实学生来找茬，就能把错误提前揪出来。我们后来做的30门课，几乎每一门都有错。早先没搞这个环节，直接上架开卖，结果差评一大堆，退钱退得心在滴血。后来加了这一步，才把质量兜住了。

细节都搞定，再把详情页、封面弄好，就可以上架卖了。

## 流量不用多，一个精准平台就够了

这个品类的关键词就两个：大学生+课程。最合适的平台是B站。我们也在别的平台试过，效果一般，B站用户最准。玩法是：把每门课的前3-5节免费放出来，当引流款，然后在简介里埋钩子，把想看完整版的人引导到公众号，最后在微信做转化。虽然B站现在也能直接卖课，但把人引到私域，以后能做的事情就多了。

账号搭建也有讲究。卖课账号的昵称要显得专业，像“期末帮”“猴博士”“大学答案君”“蜂考”这种，好记也不掉价。而且B站昵称和公众号昵称最好保持一致。还有，名字别搞太复杂，容易被别人截流，白白损失流量。

具体到发布内容，先看B站投稿工具界面的截图：![](img/4a3daaf7337d3af826193f35df0511ea.png) 这里从上到下框出的五点，就是最关键的五处设置：

1. 勾选“自制”，防止视频被偷偷盗发。
2. 分区要选对，B站会把视频推给相应人群。
3. 标题尽量多铺长尾词，哪怕用户搜一个很小众的词，也能摸到你的课，多一次曝光就多一次转化。
4. 标签和分区作用类似，帮系统识别你到底要推给谁。
5. 简介里要留钩子，还要引导大家评论、点赞、投币。

最后也是最重要的，B站同类视频特别多，封面一定要做得足够吸睛，不然就算被推荐了也没人点。

## 私域成交：公众号装个小鹅通就够了

流量引到公众号之后，嵌一个小鹅通，整个闭环就完整了。小鹅通的设置很简单，真正要上心的还是公众号本身。三个细节：

第一，账号要做认证。认证号可以直接跳转第三方链接，没认证的话就多一步，每多一步就会流失一部分人，路径越短转化越高。第二，自动回复要按照固定结构来：先欢迎语，再介绍你的账号，最后放课程链接。第三，菜单栏不要浪费。放上课程入口，再加上自己的二维码，说不定会有意外的商务合作找上门。

## 最后还是想说两句

知识付费这个市场，每年都会冒出新花样。只要内容过硬，你就有机会占一席之地。我今天讲的这套玩法，不只能做大学课程，其他类目完全可以照搬。还有一点，和老师合作尽量一次性结清报酬，别用分成模式。分成模式短期看省钱，但后面课程做大之后，想再做分销合作，会非常麻烦。

以上，就是我这个“学渣”的全部家底。拿去用，不谢。
