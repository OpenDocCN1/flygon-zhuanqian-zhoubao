# 如何申请国外edu邮箱

各位朋友好，我是龙哥。今天分享一个国外edu邮箱的申请干货——美国自由大学。目前美国那边已经全面开放了，想拿的赶紧动手。

第一步，打开 https://www.liberty.edu/ ，找到申请按钮，直接点进去。
![](img/c82c5071ffac4a3cfc9609c91236c1df.png)

进来后，记得把学习模式选成online在线课程。
![](img/769004dddb04c4e07f6939bbb5a19573.png)
![](img/00b6540585fb8b82b9270e3cd844ec0e.png)

接着是选择学习内容，建议选信息技术大类下的应用开发方向，稳妥。
![](img/03f3c85c3dbc0e65fae659364f9164e0.png)
![](img/be71c7db9c3320ec21204e06f118c591.png)

但后面会卡在需要美国身份信息这一步，别担心，用这个美国身份生成器：https://fauxid.com/，轻松搞定。
![](img/217c6fa4ed8d86543f7d4fae81c86441.png)

生成的时候，年龄范围设在18到24岁之间，国家就选美国，州选阿拉斯加，然后点击生成。名字尽量用两个单词的组合，年龄控制在20岁上下，成功率更高。
![](img/21974232327ace6188cec121a3095903.png)
![](img/0b9403f4bd33ac5f792c06554bab1d6f.png)
![](img/a80b37b7dfd06205e49168fba80a1ebc.png)
![](img/66efc21ba113f73476a4586d17f39691.png)

身份信息填好之后，学号就发下来了。
![](img/c8f4fc1531b0e64b6b3f507b0cec1e22.png)

再往下走，进入学生证的填写流程。
![](img/a86dccc243446d912c4262954dedd780.png)

现在，你的edu邮箱已经到手了！
![](img/0858d3f3b3ead4b5f6e54fc7ad6deded.png)

不过先别急着登录，系统后台还要处理一会儿，通常等待15到20分钟就开通了。
![](img/9680a3d02a355c1461cc64a30a5edce9.png)

开通后，还需要做一道安全保护设置。
![](img/810dcd4ebac6237f97d10bb081942f7c.png)

此时拿出手机，去Google应用商店下载安装 Microsoft authenticator。
![](img/d645a3e9ef7bae8179e21c91e0430188.png)

打开这个应用，扫描页面上的二维码，完成登录。至此，这个邮箱就正式属于你了。
![](img/d29e1935606208e74dc2af0ae1cea1cb.png)

最后提醒一句：要是你会脚本或RPA，完全能批量申请，效率直接飞起。
