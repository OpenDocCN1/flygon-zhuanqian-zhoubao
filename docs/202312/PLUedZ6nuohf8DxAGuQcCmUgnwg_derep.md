# 在📕引流的人，十个里有九个栽在这个误区上
作者：龙哥

![](img/4d23985cccd5e495fde0d2b71aeeb20e.png)

各位好，我是龙哥，平时主要研究📕引流。

今天想聊一个很普遍的思维误区。不少做📕的朋友都有这种想法：“先别管自己卖什么，甚至还没想好卖什么，反正先想办法把人都加到🛰️，等好友攒够了，以后肯定有机会变现。”听起来好像没啥毛病，对吧？

先别急着点头，我用两个真实案例做对比，你看完就明白了。

先说我朋友A。他在📕上做了一个主打省钱福利的账号，粉丝量不算多，但几乎每天都有几十个人加到他🛰️。他的思路很简单：先囤人，等以后有产品了再慢慢推销。后来，他看到别人在卖赣南脐橙，也心动了，于是天天在朋友圈发广告，还挨个给以前加过的用户群发推销信息。结果呢？消息发出去两个小时，一条回复都没有。

他觉得不太对劲，就用清理僵尸粉的工具把好友筛选了一遍，结果发现，一大半好友早就悄无声息地把他删了。

再说我朋友B。他的账号专注在📕上卖珍珠，笔记内容从一开始就带有非常明确的目的性，所以每天主动加他的人，基本都是想买珍珠的。某次他想做一次促销活动，同样群发给这些用户，结果回复的人超过了一半，其中大约20%的人当场下单。

两个案例放在一起，差别是不是很明显？一边是没产品、漫无目的地引流；另一边是产品明确、带着目标去引流，最后的收益天差地别。

为什么A会翻车？那些用户当初加他，是为了薅羊毛、捡便宜；他突然卖起比市面上还贵的水果，人家当然不会再把他留在通讯录里。而B从一开始就表明了“我卖珍珠”，用户清楚自己的添加目的，所以群发不但不掉粉，反而能实打实地促成订单。

讲了这么多，其实我想纠正一个很多人都会踩的引流坑：如果手里还没有明确的产品，真的不要先去📕盲目引流。这样不光赚不到钱，还会让你越做越心累。

正确的思路是什么呢？不是急着加人，而是像B那样，先把几个问题想清楚：你打算具体卖什么？你做📕是为了什么？你想吸引哪一类用户？这些用户有什么真实痛点？只要你提前把这些想明白，变现能力自然会超过那些无产品引流的人。

如果你还不知道该卖什么，我在这给你整理了7个方向，供你参考：

1. 送给男生当生日礼物的单品；
2. 改善女性脾胃问题的养生茶；
3. 实体店倒闭清仓处理的二手家具；
4. 定位中高端的过年送礼礼盒；
5. 赣南脐橙；
6. 带磁吸功能的对联；
7. 主打助眠功效的养生茶。
