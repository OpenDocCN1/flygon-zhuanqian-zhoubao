# 为什么思维模型，决定了你能赚到多少认知红利
作者：龙哥

很多人都在拼信息，拼执行，却很少有人回头审视自己脑子里的操作系统。

王川的观点很直接：真正值钱的资产，不是你知道多少事，而是你用什么样的框架去看事。思维模型的丰富度与可切换性，才是个人长期竞争力的底层来源。

当你的底层模型单一、僵化甚至错位时，再聪明的分析、再努力的执行，都只是在错误的方向上跑得更快。问题看似被解决了，根子上却在不断制造新的问题。反过来，一旦模型足够多元、足够灵活，同一个事实会被你看到更多可能性，决策的容错率和上限都会被拉开。

这件事本质上是一个链条：你从哪里来信息，决定了你能装进什么；你用什么模型来处理信息，决定了你能提炼出什么；你再用怎样的执行力去落地，才决定结果是水花还是涟漪。

所以，与其焦虑错过信息，不如先升级你的思维模型。信息接收渠道、思维模型、执行力。![](img/21de372a77ea1f441c613f7316831ae1.png)

这三者缺一不可，但思维模型，是前两者能否变现的放大器。
