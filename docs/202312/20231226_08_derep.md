# 工厂招焊工，一个人头提成1700：被人看不上的劳务行业，正在闷声赚钱

提起劳务中介，很多人的第一反应是“水太深”“黑中介多”，但这行偏偏藏着一批闷声赚大钱的人。我现在干的，就是这个赛道里最接地气的分支——帮工厂招蓝领工人。每成功入职一个焊工，我至少能拿到1700元佣金。目前我们团队做了3个劳务IP，全网粉丝加起来20万左右，每天能收到300多条咨询，每个月的利润稳定在3万元以上。

很多人觉得，招几个工人还不简单？实际上，流量、转化、工厂资源，哪一环掉链子都玩不转。如果你是个纯小白，我建议先找家大点的劳务公司干上一个月，把里头的门道摸清楚了再自己下场。

我是八和，一个普通劳务中介。2023年2月接触这行，7月15日才全职投入。到11月底，我们三个人做的劳务IP在全网攒了约20万粉丝，用了不到五个月，把月利润做到了5万；现在每个月还能稳定新增3万左右。

先说说这行的大致情况。劳务行业分几条线：低端岗位主要靠工厂付出的工价差赚钱；中高端岗位，比如央国企、事业单位的就业，赚的是求职者给的中介费；还有一部分专业人才岗位，由甲方出猎头费。低端市场里又分社会工、学生工、日结临时工，其中社会工还能拆成普工和技工，焊工、叉车工、缝纫工、CNC编程这些都算技工。我选中的，正是焊工招聘这条细分赛道。

说白了，劳务中介就是帮工厂解决用工问题，同时帮工厂控制用人成本。工厂是我的甲方，工人是我的“商品”。我通过各种渠道把合适的人送进厂，面试入职，然后拿我该拿的那份招聘费，就这么简单。

做这行，核心就三件事：前端能把人招来，中端能完成转化，后端有工厂资源接着。三样都得硬。

传统劳务公司大多靠渠道商一层层分单。跟工厂直接签合同的叫“一手单公司”，一手单下放给其他中介或机构就成了“二手单”，二手单还能继续往下分给门店、个人代理。我们目前只做二手单。一手单利润确实高，但容易被工厂绑死，还得操心工资垫资、工伤风险，规定时间交不上人甚至要赔钱。二手单虽然被剥了一层利润，但胜在自由，全国范围的生意都能接。

现在获客的主阵地已经转移到了短视频和直播。由于平台对劳务行业限制很严，我们所有短视频都是自然流量，完全投不了广告。主要阵地是抖音、快手和视频号。最开始80%精力都扑在抖音上，因为抖音来的工人质量最高，转化最好。快手则带有明显的地域属性，像云南、贵州、甘肃那边的工人，很多都习惯刷快手。而且快手还有“快招工”板块，能聊工资和保险这些敏感词，抖音完全不能碰。

短视频大致有三种玩法：

第一种，80%实地探厂+20%口播。我们主要采用这种，直接去厂里拍车间、宿舍、食堂，画面真实，工人看了更容易信任。同时，自己也能判断这个厂到底能不能全力推，工人去了能不能留得下来。不过多数工厂不让进厂拍，这就要看资源关系硬不硬了。

第二种，办公室纯口播。这类账号最多，同质化严重，你抄我我抄你，而且不能提高薪、高工价这些敏感词，只能靠标题吸引人。

第三种，工人剧情纪实类，比如驻厂人员带工人办入住、接送工人、处理日常琐事。这种内容比较吸睛，但吸引来的很多并不是真找工作的工人，还特别吃运营和剪辑，没有团队很难做。

视频内容主要是展示岗位、要求、薪资、吃住、福利这些工人最关心的点。文案里的敏感词一定要特别注意，我8月和9月就因此被封了3个号，损失不小。目前短视频的入职率大约2%，也就是100个咨询能成功入职2个人，我们现在的日客资量稳定在300以上。直播也可以做，但成本更高，要养主播、搭直播间、做账号报白，流量上来之后，更考验公司的转化承接能力。

中端转化环节，客服团队是重中之重。我们公司现在正处于扩团队阶段，最近招客服带新人确实很累。从后台收到陌生咨询，到工人最终入职，路径大概是：客资—有效客资—加🛰️—报单—面到—体检—入职—回访—稳岗，每一步都有人流失。流失原因很多，比如快过年了焊工想回家明年再出来；也可能是工厂待遇不够吸引人；最关键的是客服的沟通能力，能不能把一个工人匹配到合适的工厂，非常考验人。

我们要求客服必须足够耐心，能快速判断工人需求，所有工厂信息熟记于心，报单后要跟单，入职后要回访稳岗。毕竟工人在职一天，客服就多拿一天提成。现在我们所有工作都靠表格管理，核心拼执行力。

比如：客服接到工人咨询，要迅速问清年龄、有没有焊工证、是二保焊还是氩弧焊；🛰️和客户信息表的编号、标签必须完全一致；每天的客资数量、工人回访情况、在职情况都要登记清楚。

后端交付，说白了就是工厂资源。我刚开始做劳务时，几乎天天踩坑，遇到的坑各式各样。送过30个人进厂，一个月后只结回来500块；也遇到过面到200人，却没有一个厂愿意接收的情况。所以我深知，有几个有实力且诚信的一手单公司合作，实在太重要了。

我们是从电子厂、空调厂起步，慢慢做到锂电池厂、新能源工厂，现在做各大重工企业。资源是一点点用真金白银垒起来的。等你招人能力稳定了，很多一手单公司反而会主动找上门。在新能源之都安徽滁州，我们做到了当地劳务圈都认可的程度。

怎么判断一个厂能不能送？第一，看工单信息，什么厂、干什么活、薪资多少、规模多大、吃住如何，看一眼就能筛掉大半。我们只做“实单”，凡是出现“保底工资”“补差价”这类字眼的，基本都是垃圾单，套路太多，工人根本拿不到全额工资。第二，先送两个工人过去探探路，通过他们的反馈就能知道：驻厂服务好不好、面试流程是否顺利、活好不好干、吃住跟工单信息有没有出入、有没有额外扣费、离职会不会扣工资。第三，看一手单公司发工资和招聘费是否及时。

说到赚钱，招一个工人到底能给多少？其实逻辑很简单：工人上班挣工资，我们挣招聘费。举个例子，工人11月1日进厂，12月20日发工资，那我们在12月21日到25日之间，就能结算11月的招聘费。工厂一般会给3到6个月的费用，普工费用大概每小时1.5到2元，焊工每小时2到3元，一个工人每月工时260到280小时。算下来，一个工人能带来多少利润，心里就有数了。

小白想入行怎么开始？我给你几个建议：第一，找个大劳务公司干一个月，把全流程摸透；第二，手里有工人资源的，直接找行业里的大IP合作，就说“我有人，没地方送”，找我也可以；第三，照着这篇文章的链路自己试，整个半成品流程我已经毫无保留写出来了；第四，在乡镇有基础的朋友，可以学我们开线下门店，目前我们已经开了3家，直营和联营都有，大家一起出钱，更容易把事做成。

最后说说风险。这一年我踩过的坑基本都在这里了，想入行的人一定要留心：

第一，刚入行时处于边缘地带，没人带你，接触不到好工厂，只能做垃圾厂，留存率低，白忙活。这个行业公关能力很重要，得学会融入圈子。

第二，工人到了却没厂安排，尤其是年后初三开始那半个月，全国几亿蓝领扎堆出来找工作，工厂资源不够就会造成工人滞留。所以一般10月份就要提前多找工厂和一手单，防患于未然。

第三，一手单公司“洗人”，把我们送进去的工人找各种理由开除或调走，这很常见。要么自己做一手单，要么跟一手单搞好战略合作，否则很难避免。

第四，工厂会把小时工转正。一旦转正，工厂就不用付劳务费了。一般厂里会有30%到40%的转正比例。如果你还想继续在这个厂送人，结款也稳定，那就接受吧。

第五，一手单驻厂人员服务不好，导致工人流失。上个月我们送了一个常州厂9个人，其中3个跟驻厂吵架，光赔礼道歉、安抚工人就忙活半天。客服气呼呼地说以后有那个驻厂在就不推了，但这种事只能反馈给一手单老板，很无奈。

第六，工厂临时停招。工厂报缺口时一般会报双倍，比如缺10人说缺20，因为要留着余量。结果我们这边工人还在路上，那边已经招满了，只能临时调厂或者放弃。

第七，封号风险。手机号、🛰️号、抖音号都可能被封。电话打多了封，🛰️加多了封，敏感词说多了也封。只能多办卡、减少电话频次、多养号。

第八，客服团队不好招。劳务行业形象本来就不好，黑中介和骗子给行业抹了不少黑。我招人时会提前问对方能否接受这行，还要看能不能熬过培训期，背工厂信息、梳理客资、随时回工人消息，业务手机基本不离手。

第九，一手单不发工资、不结账。我们遇到过这种情况，处理办法是先把工人工资核对清楚，然后我们垫付。但不会默默做好人，而是准备两个抖音号，拿1万块钱做投流，把这种事变成一波流量。

这行的故事和坑还有很多，有机会再慢慢写。希望这篇文章能帮到正在观望的人，也欢迎想入行的朋友来找我交流。
