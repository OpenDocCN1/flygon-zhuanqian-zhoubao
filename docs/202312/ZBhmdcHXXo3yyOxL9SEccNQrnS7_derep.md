# 一单9.9-299，搭子经济：被忽视的小众赛道，正在闷声赚钱

大家好，我是笑笑。之前我在赚钱分享过“搭子经济”，主打陪伴，后来被赚钱的风向标列为了中标，今天继续给大家拆解这个项目的玩法。

很多朋友对“搭子”这个词还不太熟悉。其实它完全可以理解成年轻人社交文化里的新代名词。吃饭有饭搭子，减肥有减肥搭子，出门旅游有旅游搭子，去健身房也有健身搭子。说白了，就是找一个在某个兴趣点上合拍的人；只不过现在的年轻人更习惯去短视频平台找陌生人，来补足身边没有同频朋友的情况。

年纪稍长的人可能第一时间会想到人人网、🐧空间。人本身就是社交动物，不分男女老少都有社交需求，只是时代变了，社交方式也跟着变。对16-30岁的年轻人来说，“搭子”成了他们很自然的社交身份。

我们盯上这个细分市场后，第一反应就是怎么变现。最初参考了以前的同城相亲项目，慢慢演变成了搭子项目，也可以叫交友项目。

![](img/49d107e274550c2a30eb959d4b550eb7.png)

赚钱里面大佬很多，应该都见过前几年火的同城相亲玩法：女生进群不花钱，男生进群要交9.9到39.9的门槛费，理由是防止下头男、避免有人进群发广告。

可惜后来各大平台对这类账号和内容围剿得厉害，相亲项目只能收场。

没想到今年冒出来一个更小众的赛道，就是搭子项目。玩法跟相亲很像，女生免费，男生收门槛费。我们测试了一下，效果非常明显，流量也比相亲项目好很多。

项目原理不复杂：在抖音、快手、📕发内容，把公域流量引到私域，然后转化，一单从9.9到299。

![](img/76ce507a76ba3c29a7a6328c00f6c67f.png)

![](img/564bf704a84c79cc323392083455e67a.png)

还是用之前风向标中标的那张图来举例：📕笔记点赞只有31个，评论区却有400多条留言，市场需求有多大，一目了然。通常发几个作品，一个新群就能变成百人群。

📕的引流方式有很多，粉丝群、@小号、评论区引导、私信手写🛰️号拍照发过去，都能把用户引到私域。这些方法不能说100%安全，但实际用下来效果不错，毕竟📕账号很容易注册。

再说一个我们目前正在跑的抖音玩法。

![](img/78ee5902afb404eea145ead7fa661787.png)

![](img/ecac323fe25103ec855a4586cd8b5ceb.png)

![](img/f3eb3bff431fe84aeb4d7e4ba05627be.png)

就是抖音自带的小猪特效，再配一段文字，2-3分钟就能做好一条作品。别看点赞只有几百，流量却出奇地高。四百多赞的视频，评论区能留下七千多条留言，这些人全是我们的潜在客户。

导流到👸号的常用方法包括背景墙、评论区@小号；置顶视频风险太高，容易封号，不建议试。👸号里搭建一个小程序，用户就能自助下单，全程不用人工干预。

我们现在跑的就是这套自动化变现后台，后面会讲一下不搭建系统也能玩的版本。

目前验证下来，背景墙和评论区@小号还比较安全，但新号别直接导流，否则很容易被封。

用户到👸号后会看到这样一个界面：

用户自己选择所在地区，就能进群，一个人收9.9到29.9。标题里说的299一单，是收徒的费用。用户到了私域之后，还能继续做二次变现。

我们做的是全国搭子群，每个地区都有对应社群，有专人维护。普通人如果做不了这么大规模，就只做当地的搭子群，发作品时带上定位，客户会更精准。虽然出单量比不上全国群，流量也没那么猛，但当副业来做，一个月多几千块还是很香的。

这个项目目前我们还在操作，也欢迎大家来交流。执行力够强的朋友，看完应该就能自己跑通了。希望各位圈友都能有点收获。
