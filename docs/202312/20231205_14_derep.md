# 连续五天，我都没洗头
作者：龙哥

> 作者：小马宋  
> 日期：2023-11-30

上周末我开始低烧，不巧的是，公司里好几个同事都中了甲流，我太太和孩子也先后中招。我赶紧吃了速福达，也许正是这个原因，恢复得挺快，周二就回公司上班了。

可头发，我已经五天没洗了。原因很简单——有人提醒我，感染期间别碰水洗头。

这话是从哪来的？我隐约记得，去年疫情刚放开那阵，网上传言有人康复后洗了澡，结果人没了。

那这说法有科学依据吗？我个人觉得没有。要真有这事，医生早就郑重警告所有康复期的病人别洗澡别洗头了。

但即便如此，我还是没洗。

为啥？说到底，这就是件小事。洗不洗头对我来说影响不大，我也不想费劲去探究它到底是不是真的。

做任何事，都有赔率。注意，赔率不等于胜率或概率，它说的是：你赌对之后能赚多少倍。当然，生活不比赌场，既有正赔率，也有负赔率。

比如，你开车蹭了别人的车，对方下来劈头盖脸骂你傻逼。这时候，你是冲上去对骂，还是忍口气，老老实实走保险流程？

当然得忍。因为吵架的正赔率低得可怜，吵赢了，最多爽那么几秒钟。可最坏的结果呢？对方暴怒，掏出刀来，后果不堪设想。

正赔率那么小，负赔率却几乎无限，这种事坚决不做。

那再换个场景：如果康复后三天内洗头，有百万分之一的概率会死，你洗不洗？

我肯定不洗。

概率虽小，可负赔率太大，赌不起。更何况，不洗头对我的生活也没啥影响，我何必非要去证明那个说法是真是假？

商业场上，就有人专门拿这个逻辑来“吓唬”客户。比如做战略时，他会跟你说：“你现在这么做，偏离了原来的方向，迟早把公司搞垮。”这个假设出来的负赔率，让老板一听就发怵，决策不敢拍板了——毕竟公司倒闭这种后果，谁扛得住？

所以你看，在公司发展这件事上，唱多很难讨巧，因为你说好，别人将信将疑；但唱空却容易“押中”——公司早晚都会走向终结，你只要咬定这家公司不行，熬也能把它熬到倒闭那天。

负赔率，因为吓人，所以特别好用。

今年只剩最后一个月了，祝大家开开心心。
