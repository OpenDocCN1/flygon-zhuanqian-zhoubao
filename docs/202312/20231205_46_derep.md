# 一、闲鱼怎么选品

做闲鱼，选品占七成，技巧占三成。选品是运营的核心。以下品类可直接参考：

**01. 摆摊物料**

涉及电器、饰品、原材料、家具、家居百货等。现在摆摊创业很火，📕上摆摊清单分享很多。可以同步上架摆摊用品、夜市用品。通过📕搜索“摆摊工具清单”等词，或在拼多多检索，都能挖出不少可上架产品。

![](img/906417b6adb5ae0331f661b1e17656d6.png)

**02. 商用家具**

开店必备，需求稳定。可按门店类型找关键词。如美甲店需要美甲椅，美容院需要美容床，服装店需要试衣间、落地衣架、模特，酒吧需要酒柜、酒桌、吧台，这类商品也容易出批发单。

这些品是我实际跑过的爆款，新手可直接复用。

![](img/295d5c2d9372aeec1ee500b15cad20c4.png)

**03. 商用电器**

开店刚需，在闲鱼上也走得动。相比家用，商用电器利润更厚。平常去饭店就可留意：冷藏工作台、商用切菜机、后厨工作台、和面机、面条机、商用电磁炉、煮面桶等。

![](img/aca4410c692ea323f3cc0889167f7fc6.png)

**04. 家居生活类**

家具大家都熟悉，自己熟悉的品卖起来快。家具类用户最常问的是安装、品质、气味，其他问题不多，新手沟通成本低。

家具品类优点是利润高、售后少。

建议把同系列家具打包成套卖。比如沙发、床、衣柜、电视柜、酒柜、橱柜、茶几、桌椅，一套出图。客户咨询其中一件时，可直接推整套。整套成交的利润远高于单件。

举例单件赚300，十件就是3000，体量完全不同。我自己就卖出过多套，所以建议找成套货源。

家具品类很广，款式风格各异，拼多多搜索关键词即可找货。

![](img/35ac5acd09621a03495e06fe6c599cb5.png)

**05. 生活家电**

家电售后少，选择面广，对新手友好。日常常见的电器均可操作：豆浆机、榨汁机、早餐机、破壁机、电磁炉、微波炉、洗衣机、电饭煲、冰箱等。

每个大类下还有细分，如冰箱有双开门、三开门、嵌入式等，离生活近，卖起来更顺手。

![](img/bf57845e9c3c4e56c2796c81fd6cec32.png)

**06. 运动器材**

同样好卖。提醒一下：器材价格跨度大，从几块到上百都有。建议挑高客单高利润的，放弃低客单低利润的。一直倡导做高客单，低客单费力不讨好。

![](img/6df0aeb017a7418f9a6121101ebc9a8e.png)

**07. 户外露营**

一直重点推荐的品类。现在露营很火，前段时间带的户外露营小推车流量很高。帐篷、烧烤架、卡式炉、天幕、野餐垫、爬行垫等都能上。

![](img/b08300352530f14f392e625f980995ea.png)

**08. 宠物用品**

品类也不错。如宠物美容台、烘干机、洗浴池、笼子等，操作简单，新手可试。打卡营选的猫爬架转化就很高。

# 二、产品标题怎么写

标题影响曝光，务必先说清卖的是什么，再叠加营销词和长尾词。有些标题写得晦涩，顾客看不懂自然不点。

营里不少同学起初标题就不达标。

![](img/92bb4cbd3d7e80d5b930624dc68f506f.png)

![](img/09dddf06f8c4fe3ab475ed4c8cca333a.png)

**闲鱼标题怎么拟？**

闲鱼标题上限30字，约60字符，显示约一行半。

结构为：营销词 + 品名关键词 + 长尾词。

营销词：清仓处理、工厂清仓、公司散伙、急售等，贴合闲鱼二手属性。

品名关键词：前几字必须写明卖什么。

长尾词：是关键词的延伸修饰，不是凭空想，是在闲鱼或其他电商平台搜索框里抓取的。

以收纳箱为例：

闲鱼搜索“收纳箱”，可以看到联想词：

![](img/20a0ed7e6779e56719d9fa27192a7e51.png)

同品种不同叫法，收纳箱也叫储物箱，搜“储物箱”看看：

![](img/1e65f0efdf19b35fb10f451ea32734f4.png)

再到拼多多查：

拼多多搜索“收纳箱”：

![](img/68ce443ee9ec99bbbab29048f6c115a6.png)

点进去会发现另一个叫法“塑料箱”。那塑料箱也是关键词。

![](img/0d7e815cb2a0599fee01879e042eae2a.png)

继续搜“塑料箱”，会出来更多长尾词。

![](img/b0a76090155c07f5e42c6dad55d9fcfb.png)

综合下来，收纳箱标题可写：

**特价清仓特大号收纳箱储物箱塑料箱超大衣服收纳箱万能杂物收纳箱**

悄悄说，收纳箱现在可上闲鱼，平时就好卖，换季期会更好。

**标题小技巧：**

1.30字内不加标点，直接连写。关键词和长尾词最关键，很多同学随意写，影响曝光。

2.可参考拼多多同行标题，搬到闲鱼调整顺序。建议挑销量约100左右的标题，兼顾热度与竞争。仍遵循营销词+关键词+长尾词。

3.标题尽量不带大品牌，有利有弊。

先看几组案例：

以上文案均有问题，下面拆解。

文案直接影响转化。曝光有了，没人问，多半是文案问题。

文案组成：标题、转让原因、产品卖点、规格尺寸价格、发货售后。

1.标题。参照第二部分。

2.转让原因：清仓、搬仓、超市倒闭、公司破产、创业失败、实体倒闭等，符合平台调性，能让买家觉得捡漏。

3.产品卖点：写5-6条即可，可参考拼多多商品描述及评论区的用户评价。

![](img/28988808d06bb4d1ab82c9b4d8ce052a.png)

提醒：卖点很多不要全堆，写成小作文不可取。抓住核心点，3行半左右最佳。

4.规格尺寸价格：排版要整齐，尺寸对齐尺寸，价格对齐价格。若规格繁多，挑7-8款写，其余引导点“我想要”咨询。

5.发货售后：拍下默认发款式一，价格***，如需其他款，点击右下角“我想要”联系改价。务必写清，很多人不会联系。

本交易仅支持邮寄，拍下后**小时内发出。可过滤自提、看货需求。

偏远地区不包邮，运输破损包退换，请拍照留证联系处理。

大件是否包安装、是否送货入户，根据实际补充。

# 四、产品图片配法

注意：以实拍为主，尤其是首图！

闲鱼有二手调性，实拍图更吃香。自己对比，同一款商品，实拍首图和商家图，哪个“我想要”更多。以遮阳伞为例：

![](img/40f17645235d6a9355258be409f588cf.png)

![](img/e94b9f4015eacd50c486afca75f68779.png)

具体做法：

1.首图：高清，比例建议1:1或3:4，完整展示。我偏爱1:1。

首图可叠营销词，如急售、不要了等，可参考同行。

选图原则：必须完整、清晰体现商品。卖凳子主图却桌子更突出就不合适。

建议从评论区找图，MD5后用稿定设计或美图秀秀加滤镜、裁剪，做出吸引点击的首图。

什么首图能点进去？自己多刷闲鱼，哪个是你想点进去的，答案就出来了。

2.其余八张：尺寸无强制要求，比例不同展示会不一样，不必纠结。

第2-7张用实拍，可为整体、局部特写、效果图组合。

第8-9张放尺寸图与款式图，款式多可拼图。低价引流款一般放第九张。

图片可在各电商评论区找。淘宝图通常比拼多多清。爆款可考虑买回实拍。如我卖饮料柜，就是超市现拍的。为成交想办法，闲暇也在琢磨优化。

# 六、产品价格制定

新手常纠结定价，高了怕卖不掉，低了怕没利润。建议遵循：

1.做低价引流，利润可给10%左右，价格不必压太低，约第二档的55%即可。

2.其他档位利润加20%-30%。

做闲鱼，很多细节看着不起眼，却直接决定你能不能赚到钱。今天把压箱底的干货翻出来，聊聊定价、发布地址、成交话术这几件大事。

先说定价。数字不只是数字，它会影响顾客的点单欲望。我的习惯是让价格落在吉利的尾数上，比如9、8、6。我自己最爱用9收尾：199、299、399。别小看这一块钱的差别，标200、300、400，买家心里的感觉就是“贵好多”；标199、299、399，接受度立刻不一样。还有，有些数字要避开，像250、148这种，不少顾客会介意，一不小心就把人吓跑了。

再说说起步阶段怎么做。那时候别太挑，能出单就尽量出单。因为每成交一单，店铺的权重就会往上涨一点；权重高了，后面流量和转化就是水到渠成的事。我自己有个真实案例：一个产品刚开始定价低，出了几单后我再把价格稍微抬起来，利润马上就变厚了。不过有个雷区要记住——正在热卖的产品，一定一定不要改一口价。想调整可以改文案里的价格，但不能大幅变动。

还有更重要的一点：尽量做高客单价的生意。同样的时间和精力，卖贵的东西回报高得多。闲鱼平台是千人千面的，你长期卖低价货，系统就会给你打上“低客单”标签，以后推荐给你的都是爱捡便宜的客户；反过来，你卖高客单产品，系统就给你贴“高客单”标签，吸引来的都是购买力更强的买家。

说完价格，再讲发布地址。这个细节很多人不当回事，几十个选品全填同一个地方——自己的居住地，这么做真的不行。

发布地址的四个原则：
第一，别发去小城市。比如你住在农村，就把地址填到村里，这等于把曝光掐断了。尽量选一二线城市，人多、需求大、曝光高，成交率也会跟着上来。
第二，不知道怎么选地址的，去百度指数搜一下，看看你的产品在哪些地方热度高。
第三，不同产品别聚在同一个地址，尽量分散开。
第四，如果某个选品爆了，赶紧多挂几个链接，把发布地址放在不同的城市。

地址选择的参考链接也一并放上：`mp.weixin.qq.com/s/7nx364Y4cwXROcYe7WKe3Q`

最后聊聊成交话术。很多店就是输在这一步——客户来咨询了，结果因为回复不专业，订单溜走了，特别可惜。客户来问的时候，你要让他感受到你的专业、靠谱和自信。摆正心态：你有需求，我刚好有货，我们是平等的买卖双方，不是谁求谁。

遇到砍价千万别松口太快。比如售价1500，对方刚说“便宜点”，你就直接让200，换成你是顾客，你敢下手吗？销售一定要换位思考。

话术从哪里学？最好的老师就是同行。闲鱼同行、淘宝同行、拼多多同行都可以。我刚开始做的时候，收集了不少同行的话术，然后改成符合自己性格的说法，需要时直接发给客户。当然，优秀学员分享的现成话术也完全可以拿来用。
