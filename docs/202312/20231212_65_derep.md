# ('新手营养师如何快速入行，并找到为自己付费的前 3 个客户', (2, 30))

哈喽，生财的圈友们，周末快乐！我是营养师阿悦。

“怎么用最快速度进入一个新领域”“怎么低成本跑通一个最小商业闭环”“怎么早点拿到正反馈”，这些大概是每个想转行、想搞副业的人都在琢磨的事。

如果你对营养健康赛道感兴趣，也想把它做成副业，那这篇内容或许能给你一点启发。我把它拆成两块来讲：

1. 快速入行：怎么高效获取信息并行动起来  
2. 从 0 到 1：怎么找到愿意为你付费的头三位客户

先说入行。这里有个特别直接的办法，四个字就能概括——人、事、网、书。

具体怎么用这四个字去落地，篇幅有限，我整理在下面的文档里了，大家可以直接点开看：
