# 别只站在自己的安全区里看别人的反应



## 共情，从一次被狗追的早晨开始

作者： 小马宋

日期：2023-12-14

今早出门遛弯，被小区里两条没拴绳的狗给整破防了，这件事让我把共情这件事想明白了。

我刚下楼，迎面遇到一位邻居在遛狗。狗没拴，她的爱犬在我身后突然炸毛狂吠。我下意识站住，身体紧绷。狗却没停，还一路跟着叫。

邻居摆手说：没事没事，你别管，它们就叫叫，很快就走了。

我真的很难做到她说的那样平静。身后跟着两条不明情况的狗，一直在叫，我脑子里全是会不会突然扑上来咬我。回头驱赶几次没用，我只能捡起路边的小石子往远处丢，让它们离我远点。邻居当场不悦，转身带着狗走了。

其实大家的出发点都没错，只是站位完全不同。

对她而言，这两条狗她太熟了，往常从没咬过人，现在也就是叫两声。她会觉得我小题大做，明明解释过了，我非但不走，还动手赶狗。

对我而言，几年前在五道营胡同地铁口，曾经有一条狗从背后无声扑上来把我咬了。那天晚上我一个人跑去打狂犬疫苗，记忆太深了。所以现在只要有狗在身后跟着叫，我的大脑会自动拉响警报，根本做不到淡定往前走。只有等狗彻底远离视线，我才敢迈步。

狗主人希望我先走，可她自己却没把狗带开，这个落差我接受不了，所以只能自己制造距离。

做营销、做产品，本质上就是在做共情的练习。就是要暂时放下自己的专业经验，去用用户的视角和恐惧度去看问题。

你做家具，闭着眼都能拧好一个衣架，觉得说明书写得够清楚了。但对一个第一次装的人来说，看半天图都懵，这就是典型的用自己的熟练度去要求小白。心里嫌用户笨，其实是自己忘了初心。

再比如儿童牙刷。很多大人觉得孩子应该用很细很小的牙刷才对。可实际上孩子手劲小，需要整个手握住才能控制，这就要求牙刷柄要足够粗。大人用自己的手感来设计，就是共情断档了。

真正好的共情，是先承认对方的恐惧是真实的，再去想办法解决问题，而不是先教育对方“你想多了”。

希望这段经历能给你一点启发。
