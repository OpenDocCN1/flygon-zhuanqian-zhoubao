# 从零到百万：一个理工男在视频号带货的稳健突围实录



## 从零起步到年入百万，我在视频号里走了这一年半

作者：肖肖

日期：2023-12-08

《从零到百万：一个理工男在视频号带货的稳健突围实录》

嗨，我是肖肖。很多人叫我60分主播逆袭的理工男，我本人也是参加过12次航海实战的船员。

2022年7月我踏进视频号带货这个赛道，到现在正好一年半。这一路我把短视频和直播的各种玩法都亲自上手轮了一遍，每隔一段时间就对打法做迭代升级。临近2023收官，我想把这一路踩坑、试错、突破的经历整理出来，和大家一起复盘总结，也给大家在2024年入局视频号做个参考。

这段时间里，我给自己定了两件大事，都圆满了。

一是业绩层面：从一张白纸开始做到300万+的成交体量，主要靠自然流，个人实打实的收益已经突破百万。

二是个人层面：从赚钱社区的纯新手，一路成长为万人航海实战项目里的视频号带货教练，最近还被邀请去带了一期训练营，200多位学员跟我一起上手直播带货，也收获了不少亮眼的结果。

我不觉得做成超级个体有什么好炫耀的，我一直坚信真正能走远的是团队化运作。但我也明白，创业的第一年能不能把0到1跑通太关键了，个体的能力是后来做规模化团队的基础。下面我就把这段打怪升级的真实经历摊开讲，希望能给同样在创业路上摸索的朋友一些启发。
