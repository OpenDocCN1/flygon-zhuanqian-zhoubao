# 视频号直播带货需千粉，汇总一些目前的解决方案

最近，视频号直播带货热度很高，我们团队也一直在这个赛道里摸索。但就在前两天，一个新规突然落地，直接卡住了不少人的带货路——没错，说的就是“千粉门槛”。

其实前几天就有风声说直播带货要满1000有效粉丝，当时还半信半疑。结果昨天一开播，系统就弹出了提示：有效关注量需达到1000人才能继续带货。也就是说，现有的带货权限显示的是橱窗功能可用，但直播带货这个入口还没解锁。

不过，官方提示里也留了一个口子——要么冲粉丝，要么开店。具体来说，解决方案无非两种：

第一种是按部就班攒粉，围绕1000个有效关注的目标持续发力，靠内容或运营手段把粉丝基数做上去。

第二种就是直接开通视频号小店。这也是官方认可的路径，等于是绕开千粉限制的“快捷通道”。
