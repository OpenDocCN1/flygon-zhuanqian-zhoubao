# 搭子群生意：一杯奶茶钱，换来一群人的陪伴
作者：龙哥

最近，赚钱圈子里有人分享了一个“同城搭子群”的风向标，直接被评成了中标。今天就把这套玩法从头到尾拆给大家看。

如果你在一二线城市生活，尤其是独自打拼的年轻人，肯定懂这种感觉：朋友圈翻到底，也找不到一个能约出门的人。想认识新朋友？线下又社恐，遇到心动的异性连开口打招呼都要犹豫半天。

于是“搭子”这个说法就流行起来了：一起吃饭的饭搭子、一起旅行的旅游搭子、一起打卡学习的学伴……年龄差不多，又都在同一座城市，上班摸鱼能聊几句，周末也能约着去吹吹海风、爬爬山、唱唱歌，既填补了孤独感，又不会太有社交压力。

这种内容在📕、抖音、快手特别吃香。笔记看着点赞不多，但评论区的活跃度高得离谱。随手发两三个作品，就能拉起来一个上百人的同城群。

目前跑下来，主要人群集中在16到30岁。

赚钱的模式也简单：组一个同城交友群，女生免票进场，男生收9.9到29.9元一位，理由就是“过滤广告号，也防止混进来的下头男”。一杯奶茶钱的门槛，绝大多数男生都愿意掏。

而且这个玩法全国都能复制，不用挑城市，也不用什么特殊资源。选一个城市，做几条能勾起共鸣的内容，把评论区的人引进群里，基本就能跑通。
