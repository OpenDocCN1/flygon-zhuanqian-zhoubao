# 每家公司都要做的数据型盘点文案怎么写？
作者：龙哥

每到年底，不少公司都要迎来一场“年终数据汇报”：给哪些用户提供了多少次服务、创造了多少收益……数字倒是清清楚楚，但怎么让读者一看就觉得“这成绩真牛”，才是真正考验文案的地方。

菜菜给出的解法很有意思：不硬想漂亮话，而是让ChatGPT来当帮手。她专门训练了一个“让数字变得有血有肉”的AI助手，专门负责把冷冰冰的数据改写成用户有感知的表述。据说效果非常好，连提示词都整理成了现成模板。
