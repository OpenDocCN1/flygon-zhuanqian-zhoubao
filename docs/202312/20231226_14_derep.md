# 别碰！在小红书上卖INTO YOU假货，可能直接把自己送进去

> 这不是危言耸听，而是一个真实发生在圈友身上的案例

大家好，我是常驻杭州的书豪，平时主要带小红书店铺和直播的航海项目。最近航海报名已经开启，感兴趣的朋友欢迎一起上船，我会全程陪跑。

今天不聊运营技巧，想认真给各位提个醒：关于在小红书卖假货的法律底线问题。

有个朋友前阵子找我求助，说他在小红书上卖INTO YOU的一款唇泥，结果被用户举报售假，整个人慌了。

我第一反应是问他：卖了多少钱？有没有跟供货方确认过货源？

他说已经卖了五位数，而且跟厂家核实过，的确不是正品，连防伪码都没有。进货价10元一支，他挂19.9元卖。就像下面这类账号的操作。

![](img/963e660f003b5af85a63dea36b1df2bb.png)

听完我后背一凉，赶紧让他把库存清零、立刻下架，同时联系了我家里的专业律师，看看这事到底多严重。

律师听完细节后直言：再卖下去，就是刑事犯罪风险。

我还抱着一丝侥幸追问：真有这么严重吗？

律师说，正品在淘宝旗舰店卖39.9元，你卖19.9元，价格差了一半，这在法律上基本可以判定为“知假卖假”。

他给出的建议非常明确：立刻停手，彻底放弃这个品。

原因有两点：一是品牌方在当地公安系统里资源深厚，被盯上是迟早的事；二是销售假货金额达到一定程度，必然引起警方关注。

律师还跟我讲了个真实案例——他之前有个客户，卖的是日本优衣库的仿冒品，最后被抓进看守所，在里面天天以泪洗面。当时卖同样货的人一抓一大把，但总有人会成为那个“幸运儿”。

千万别赌自己运气好。

我把这件事分享出来，就是想让更多圈友知道：假货看着再暴利，也不过是悬崖边捡钱。只要踩到刑事红线，这辈子可能就毁了。

合法赚钱，才是长久之计。

留得青山在，不怕没柴烧。哪怕一个生意再赚钱，只要法律风险高企，果断放弃才是聪明人的选择。

我那朋友听了律师分析后，当天就下架了商品，及时止损。因为信任，他愿意听劝。

各位，这个时代机会从来不缺，但一切机会都必须建立在法律底线之上。

在小红书卖假货，价格比旗舰店便宜一半，搜索流量高确实很爽，可一旦出事，失去的可是人身自由。

赚钱的路长着呢，不必拿命去赌。

2023年即将翻篇，希望大家面对暴利时，都能多一分冷静，别让贪念盖过了判断力。

这个时代永远有我们意想不到的机遇，前提是——我们还能自由地留在牌桌上。

最后，小红书店铺和直播航海正在招募船员，我会在航行期间全力护航。也祝所有上船的朋友，遇到困难时都能迎难而上，别被未知吓得退却。
