# ('【赚钱心态】4 篇', (2, 11))

想赚钱，先别急着学技巧，看看你的心态有没有“卡壳”。

我见过不少这样的人：天天熬夜加班，项目也认真做，可一到钱上就各种别扭——不好意思谈钱、不敢报价、赚到一点就怕失去。结果呢？辛苦没少，钱包却没鼓起来。

说白了，金钱上的困境，大多不是能力问题，而是心态问题。

最近在语雀上看到一份非常不错的资料，主题就是“赚钱心态”，一共4篇文章。它没有给你讲那些虚的鸡汤，而是从很实际的视角，帮你拆解那些藏在习惯里的思维墙。比如对风险的恐惧、对高收入的配得感、对长期主义的误解……每一篇短而有力，读完会有一种醍醐灌顶的感觉。

如果你也觉得自己一直在忙，却始终没留下钱，强烈建议抽空读一读。链接放在这儿了，自取就行：https://www.yuque.com/for_lazy/thfiu8/zlz0vverxf9fvpyi

记住，财富的起点，从来不是某个项目，而是你如何看待金钱，以及如何看待值得拥有金钱的自己。
