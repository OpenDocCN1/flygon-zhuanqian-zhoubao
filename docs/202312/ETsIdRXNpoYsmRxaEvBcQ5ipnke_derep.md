# 个人养老金制度为何要出来

1. 人口结构加速老龄化。出生率下滑、预期寿命拉长，中国养老保障承压明显。劳动人口在收缩，养老需求在扩张。

第七次全国人口普查数据显示，截至2020年11月1日，60岁及以上人口占比18.7%，65岁及以上人口占比13.5%，深度老龄化已近在眼前。十年间老年人口净增8640万人，预计到2030年前这一数字还将再添2.23亿。与此同时少子化加剧，2021年出生人口仅1062万，同比2016年腰斩近半，降幅43.6%。

![](img/6da83899a6504352af18c2a73b6264f9.png)

2. 既有养老体系难以独扛。现行体系主要靠基本养老保险、企业年金与个人储蓄支撑，抗老龄化与抗支付压力的能力不足。

“十四五”规划明确提出构建多层次多支柱养老保险体系，提升企业年金覆盖面，规范发展养老第三支柱。2022年11月25日，人社部、财政部、国家税务总局联合发布个人养老金先行城市名单。参加个人养老金是在享受国家基本养老待遇之外，额外增加的一条补充通道，既能帮助个人提前布局养老资金，也能享受税收激励。

3. 养老金支付压力在累积。老龄化背景下，制度可持续性考验加剧，寻找新的增量补充模式成为必然。

4. 推动个人养老金制度落地。为缓解财政与企业负担，激励个人为自身晚年储备资金，个人养老金制度应运而生。

5. 参考国外成熟做法。美国401k、澳大利亚超级年金等个人养老金模式，已有长期运行经验，为中国制度设计提供了借鉴。

为应对上述挑战，个人养老金制度正被逐步推广，以助力养老保障体系长期可持续。

# 个人养老金到底是什么

个人养老金是国家政策背书、个人自愿加入、市场化运作、发挥养老保险补充作用的制度。实行个人账户制，缴费完全由参保人自行承担，可自主挑选符合规定的储蓄存款、理财产品、商业养老保险、公募基金等金融工具进行投资，实行完全积累，按规享受个税优惠。

# 中国养老的“三支柱”框架

![](img/94bd908a2dd606435e2f2db39dba3363.png)

1994年世界银行在《防止老龄化危机》白皮书中首次提出养老三支柱概念。当前中国三大支柱为：

第一支柱是国家主导的基本养老保险，含城镇职工基本养老保险与城乡居民基本养老保险，为老年人生活提供底线保障；
第二支柱是企业年金与职业年金，在国家监管下由市场运作，企业年金由企业发起，职业年金为强制建立，起到补充作用；
第三支柱由个人掌控、以扩充养老供给为目的的金融类产品，涵盖政策优惠的个人养老金、养老理财、商业年金保险等。

2022年5月，国务院办公厅发布《关于推动个人养老金发展的意见》，标志着第三支柱个人养老金从试点走向常态化。11月，人社部等五部门联合印发《个人养老金实施办法》，进一步明确了发展第三支柱的政策路径。

# 三支柱运行现状

## 第一支柱覆盖面大、替代率偏低、成长空间受限

中国2021年正式进入中度老龄化，65岁及以上人口占比14.2%。（图表1）上世纪90年代基本养老保险制度建立，成为当下第一支柱的主体。但人口出生率持续走低，2022年仅6.8%。（图表2）少子老龄化将成常态。

![](img/b24a84ed3acb362e64e22a6e35c36c1a.png)

![](img/fe2932ef3bc89e701d820588b78f814c.png)

截至2022年末，基本养老保险参保人数达10.5亿，（图表3）年度收支规模超12.6亿元，累计结余超过6万亿元，在三支柱中占比最重。社科院预测，城镇职工基本养老保险基金累计结余将在2027年达到约7万亿元的峰值，随后快速回落，可能在2035年前后耗尽。

## 第二支柱覆盖人数有限，作用释放不足

在第一支柱压力加大的情况下，政策鼓励企业共担养老责任，第二支柱应运而生。然而企业年金与职业年金覆盖人数仍然偏少，（图表4）补充作用尚未充分发挥。

![](img/9a44e45a0130691128a83bb0ef077725.png)

## 第三支柱体量待扩，发展空间广阔

个人养老金是壮大第三支柱的核心抓手。在老龄化加深、国家养老资金趋紧、社会保障需求攀升的背景下，个人养老金获得政策重点支持。

个人养老金由个人自愿参与、产品多元，包含专属养老保险、养老储蓄、养老目标基金、养老理财等。在第一、二支柱基础上，第三支柱有望打开养老金融零售市场。

![](img/8161009c0292ff05ed47b5d571669c7b.png)

政策层面，自2022年起试点推行个人养老金，试点城市居民可按需向个人养老金账户存钱。每年最高缴费额度1.2万元，通过税优政策提升吸引力与覆盖面。

据人社部数据，截至2023年6月，开户参与人数超4030万，平均每户缴费约2000元。中国社科院副会长金维刚指出，从36个试点城市情况看，参保人数占符合条件总人口的比例不高，开户后实际缴存比例与人均缴存水平仍有提升空间，说明政策仍需扩面、增量，市场潜力巨大。

2022年以来，为应对外部经济不确定性，央行多次降息，存款和结构性存款收益率下行。为了实现长期养老储备，居民开始寻求存款之外的资产配置方式。随着保障体系完善，需求端持续放量，多元化养老金融产品将成为除传统存款外的重要养老储备渠道。

# 谁适合开户

1、已在中国境内参加城镇职工基本养老保险的人员
2、已参加城乡居民基本养老保险的劳动者

重点人群建议：

◎有税收节省诉求的人群：税前年收入≥9.6万元，参与后可享受一定税优空间
◎希望提升养老金替代率的人群：国际经验显示，退休后养老金不低于退休前70%，生活质量才更平稳
◎需要强制储蓄约束的人群：借助账户封闭与税优机制，培养长期储蓄习惯

# 参与的价值点

1、养老补充
三大支柱发展不均衡，养老资产总规模不足，养老金替代率持续走低，长寿时代养老需求进一步抬升。

2、个税优惠
自然年内可在1.2万元额度内向个人养老金资金账户缴存，缴存额可在应纳税所得额中税前扣除；领取时按3%的低税率缴纳个税，实现税款递延。

# 操作流程

1、自主开户
通过商业银行手机App最快一分钟完成，资金账户支持后续更换银行。

2、自主缴存
自愿向资金账户存入资金，自然年上限1.2万元，享受对应税优。1月可在“电子社保卡”小程序下载缴费二维码，3-6月可在“个税App”完成抵扣申报。

3、自主投资
可选择储蓄、商业保险、理财、公募基金四类产品，账户封闭运行，投资期间收益暂免征税。

4、条件领取
满足以下其一即可支取：达到基本养老领取年龄、完全丧失劳动能力、出国定居、国家规定其他情形。领取时由银行代扣3%个税。

可按月、分次或一次性领取，资金划入本人社保卡银行账户，身故后账户资产可继承。

# 投资参考

## 可投范围
仅限银保监会或证监会批准并在人社部及行业平台公示的四类产品：储蓄产品、理财产品、商业养老保险、公募基金。

## 各类产品特征

| 品类 | 形态 | 优势 | 劣势 |
| 养老储蓄 | 整存整取、零存整取、整存零取 | 安全性高 | 单利计息，收益偏低 |
| 养老理财 | 以固收为主，兼顾混合类 | 起购门槛低 | 收益不确定 |
| 商业养老保险 | 年金保险 | 在打破刚兑环境下确定性相对更强 | 缴费周期长，锁定时间久，不易转投 |
| 公募养老基金 | 养老目标日期基金 | 市场向好时收益弹性大，灵活性相对较高，到期可转投 | 收益不保证，波动风险高 |

# 个人养老金常见问答

Q1：工作生活地不在试点城市，能否去试点城市开户买产品并享受税优？
只有在试点城市参加职工基本养老保险或城乡居民基本养老保险才有开户资格。无锡客户要去苏州开户，需满足在苏州参保，否则无法开户。税优需当年缴存并在个税App录入抵扣信息后，按实际缴存额享受递延优惠。

Q2：灵活就业人员能否开户？怎么开？
灵活就业人员若在中国境内参加城镇职工基本养老保险或城乡居民基本养老保险，且参保城市为试点城市，可参与个人养老金。可通过商业银行App线上开通。

Q3：建议在哪家银行开户？
建议选择首批获个人养老金账户资质的23家银行，含六大国有行、12家股份制行、5家城商行，可在银行App个人养老金专区一次性完成资金账户与资金账户的开通。

Q4：退休前社保中断的年份，还能继续缴存吗？
可以。社保缴纳仅是开户前提，中断年份不影响税优享受，后续变化以届时政策为准。

Q5：个税抵扣机制有何特点？
实施前：个税=（税前月收入-五险一金-专项附加扣除）×适用税率
实施后：个税=（税前月收入-五险一金-专项附加扣除-个人养老金缴存）×适用税率

Q6：抵扣操作步骤？
第一步，获取缴费凭证，通过国家社会保险公共服务平台或开户银行App查询打印。
第二步，个税App“扫一扫”扫描缴费凭证二维码录入信息。
第三步，选择“通过扣缴义务人申报”并推送给单位，提交后可在“个人养老金扣除信息管理”中查询。

Q7：已买基金能否中途赎回转投保险？
可以。发起基金赎回后，资金回流至个人养老金资金账户，再用账户资金购买保险。

Q8：商业养老保险的优势？
安全性高、长期锁定利于长期规划、长周期可发挥复利、提供身故/全残/失能保障、整合风险保障与健康养老服务。

Q9：增值部分要不要缴税？
投资环节收益暂不征税。领取环节无论领取方式或额度，均按3%最低税率缴纳个税。

Q10：政府延迟退休，个人养老金领取是否同步延迟？
按现行政策，领取个人养老金需达到领取基本养老金年龄。
