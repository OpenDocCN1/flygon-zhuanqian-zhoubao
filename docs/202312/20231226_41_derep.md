# ('怎样在大公司混成中层干部？', (2, 15))

在大公司里，想从“高不成低不就”的中间位置站稳脚跟，其实没那么复杂，就盯紧三件事：战略、人才、组织。方向看得准，人能带得动，架构理得清，这位置基本就稳了。

有意思的是，有人一针见血地指出：创业公司的管理者，满脑子想的是怎么把生产力拉上去；而大公司的中层，真正琢磨的是怎么把生产关系理顺。两种环境，两种玩法，经历过的人都懂。

所以别总埋头干活，中层的位置，拼的不只是执行力，更是这盘棋的布局。战略定方向，人才聚合力，组织保运转——这三样抓牢了，自然能混得风生水起。
