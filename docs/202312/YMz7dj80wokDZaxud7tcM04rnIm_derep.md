# 从亏光本金到赚到千万：一个程序员在Web3牛市初期的实战复盘

我是龙哥，程序员，研究生阶段读的就是区块链相关专业，在这个圈子待了六年多。现在一边在互联网大厂上班，一边在链上找机会。过去我亏到过两次归零，如今账户已经实现了千万级正反馈。我主要做GameFi、空投和套利，喜欢用代码抓Alpha。像RACA批量打怪、扫货开蛋、Luna链上套利、Arb空投，这些项目每个都给我带来过百万以上的收益。Web3是互联网之后的下一个新大陆，眼下正值牛市初期，未来的增长空间还很大。

总有人问我：你能赚到1000万，不就是因为运气好、撞上风口了吗？我承认运气和风口很重要，但一个人如果每次风口都能踩中，背后一定有一套逻辑。这套逻辑不是什么玄学，就是不断学习和复盘。我把自己从2021年8月24日发布第一条视频开始，就持续在YouTube和🧣记录操作过程。起初我只是一个在Web3里薅羊毛的普通玩家，分享的也是基础操作。

![](img/60b117c9ef27fca3f1e0aa6fa603e65e.png)

后来我慢慢悟到一个道理：信息要快，行动要狠，两者叠加就像印钞机。执行力是什么？是你看到一个消息后，有没有立刻动手。记得前阵子新铭文铸造的消息刚出来，圈内人都在疯狂mint，有人却说“我等吃完饭再打”。结果等他吃完饭，铭文已经打完了，二级市场价格直接翻了50倍。币圈就是这样，晚一个小时，可能就错过几倍的收益。信息差又是什么？是你能不能比别人更早拿到有价值的消息。我读研时参与过不少区块链项目，还拿过以太坊开发社区的激励，于是决定用代码和脚本来找机会——把自己变成链上科学家。

2021年底，RACA链游全网刷屏。我们写了软件批量开蛋，把数学模型算清楚，只要期望值为正，钱足够多时概率就会变成确定。后来官方做市场维护，暂时关闭了挂单功能，整个市场只能买、不能卖，元兽价格一下子被拉起来。我们趁这个时机，钻了系统空子，把被官方锁在市场里的元兽提前弄出来，再赶在价格高点抛售，账户第一次有了百万u。之后我们把同样打法复制到MOBOX、Defina、Valk、Jojo、飞船、BNBHero等链游项目中。

![](img/53b3260cb47968a94d77d1b39ba772bf.png)

除了链游，我们也去刷空投。DYDX、ZENLINK这些机会相对确定，赚的核心就是信息差。我们写了全自动刷交易量脚本和网格策略软件，收益基本在3-5倍。

![](img/00a78d6f6ef0d986f13f3da810a1ffe1.png)

2022年Luna崩盘，大家应该都不陌生。我们早就把UST和Luna的经济模型研究透了，所以很清楚暴跌背后藏着巨大套利空间。旁人只盯着那98%的跌幅，我们却靠着信息差，两天之内套现超过100万美金。当时全网没有一个人放出这套套利方法，等我们做完了，网上才出现各种“马后炮”。套利逻辑说白了，就是同一资产在不同链、不同交易所之间存在价差，有差价就有获利空间。

![](img/715013a7ce72b3fa08ed60b8ec0ae0d9.png)

2022年的NFT同样有过短暂狂欢，freemint、白名单、打图这些玩法一个接一个冒出来。我们开发了自动化打狗工具和批量脚本，一边抢在散户之前扫货，一边全自动复制大V的买卖操作。凭这些工具，我们用很低的成本累积赚了100多个ETH，按当时价格大概折合100万人民币。

![](img/2207145ff17fbe999a8c753c9a1d1597.png)

去年年底到今年，空投一直是热门。Aptos和Arb的空投让不少人财富自由，我在Aptos空投里拿下了30多万人民币，也就是四万多美金。

![](img/185837355ae574401e4da77da96cdc88.png)

今年还有OK打新SUI这样的间歇性机会，我们单号赚了10万人民币。当时通过借币质押来抽签，顺便把OKB下跌的风险也规避了，基本上属于低风险高确定性的操作。这种大资金能参与的确定性机会，一年也就几个，亏钱的概率微乎其微，关键看执行力。一个号赚10万，搞到10个号同时中签，那就是直接100万。想想大厂里那些P8、P9，全年无休地加班，税后到手也不过100来万。Web3的魅力就在这里：门槛足够低，普通人也能吃到早期红利，一个个暴富故事不断上演。

9月份的时候，Friend.Tech突然火了。我们盯着那些高收益账号的操作逻辑，搞出了一套自动交易和监听抢购脚本。我们会先看推特账号和钱包地址靠不靠谱，再决定买不买，同时把进出的时点也设置好。假使某个大V开始砸盘，我跟着抛一点；他继续砸，我就继续抛；直到他清仓，我也清仓。说白了，就是通过监听FT上的每一笔交易，再把自己的策略叠加上去。后来脚本机器人内卷得厉害，我们干脆反其道而行，批量自己开盘，专门收割那些机器人，一波操作两头吃。

![](img/129fbb6e7bb4b1976e5663ef9d9fb1c0.png)

进入11月，铭文赛道一片繁荣。我们早在5月就盯上了Ordi和BRC20，赚了大约60万。最近山寨链上的铭文也开始爆发，我们用脚本批量铸造，用极低的手续费抢占先机，到手利润基本是10倍起跳。

![](img/1e5dfe505da47dc049165a48181e01b5.png)

回头看，每一年都有几次能改变命运的机会。马上就是2024年比特币减半，真正的疯牛或许就要来了，普通小散户完全可能借势翻身。我对区块链这个行业始终心存感激。现实世界被房地产和传统行业裹得严严实实，普通人很难找到向上通道，而一个全新赛道往往能带来奇迹。所有新东西都要走完四步：质疑、理解、成为、梦醒。拿铭文举例，刚出来时我心想：这东西真的有意义吗？怎么感觉历史在倒退？后来看到那么多人靠它赚钱，我开始尝试着去理解，自己也跟着成了一名打铭文的人；再往后，泡沫散去，铭文终将回归它原本的价值。链游、NFT，哪一个不是这样循环？我们能做的，就是比别人更早地看见新事物，并且敢于理解。哪怕投研能力弱，也要想办法找大佬带路，把质疑变成深度思考的动力。等其他人还在犹豫时，你早已成为新事物发展中的一员。

想赚钱，必须比别人早动一步；想赚钱，还要专挑有门槛的事情做。这片巨大的黑暗森林里藏着无数未知，也埋着大量机会。机会从来不缺，缺的是认知、信息差和执行力。安静复盘，该拥抱泡沫的时候就别犹豫。

Web3牛市已经露出苗头，2024年这个比特币减半的大年，值得所有人期待。记得关注我，后续我会把这些项目的原理一个个拆开讲清楚，这篇内容就当给大家的索引。视频版介绍也准备好了，欢迎来连接我。
