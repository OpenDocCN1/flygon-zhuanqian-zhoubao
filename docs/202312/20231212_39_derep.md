# 小红书卖脐橙，新号从0到出单只花了5小时，我的完整复盘

> 你是不是也这样——眼看年关将近，钱包却没鼓起来，心里急得不行，却又不知道该从哪儿下手赚钱？

昨晚，有朋友私信我：“飞哥，快过年了，我又慌又迷茫，到底做什么才能挣到钱？”

没过多久，又有人来问：“飞哥，最近有没有靠谱的副业？想赚点奶粉钱，不求多，能落袋就行。”

说实话，成年人的焦虑，多半都是钱闹的。

现在网上的知识付费课程一抓一大把，动不动就喊“日入几百上千”，收费还不便宜，普通人挑来挑去，根本分不清哪个是真金、哪个是镰刀。想找个正经副业，又怕被割韭菜。

所以我决定把自己最近一次实操完整拆出来——我用一个全新小红书号卖赣南脐橙，从发帖到成交，全程只用了5个小时。

一单利润只有14.2元，但我跟你说，这生意投入低、跑得快、还好复制。那些“大V”看不上这种蝇头小利，恰恰给咱们普通人留了一道缝。新手小白拿来练手，再合适不过。

为了让你看得更清楚，我先列个提纲：

1. 我为什么偏偏挑了脐橙来卖？
2. 产品怎么定位？人设、价格、封面、标题、模式，每一步我怎么想的
3. 从发帖到成交，中间踩了什么坑、做对了什么
4. 最后，我想对每个想赚钱的人说几句心里话

先说第一个。

我为什么选脐橙？不是我有多懂水果，而是它恰好满足了三个条件：季节快到了，人人都有需求；原产地直发，供应链成熟；利润虽然薄，但走量空间大，最关键的是——不需要我先囤货，没有压货风险。

再聊定位。

产品定下来了，怎么把它卖出去？我给自己定了一个普通人的身份——不装大佬，不炫富，就做一个真实分享的买家。因为小红书用户对“真诚”特别敏感，信任感往往就藏在细节里，比任何话术都管用。

价格上，我不搞低价竞争那一套，定个合理的价位，既不吓跑人，也留出利润空间。封面必须抓眼球，标题要让人忍不住点进来，服务模式上走简单直接的路子——客户问得清楚，我答得干脆，下单流程越顺越好。

帖子发出去之后呢？说实话，一开始数据挺难看的，阅读量低得让人怀疑人生。但我没急着下结论，把帖子当成一次流量测试，继续盯着后台看变化。

转折出现在第5个小时——有人来私信咨询了。

然后呢？付款成功。

你看，这一单就这么成了。

我把整个过程琢磨了一遍，发现赚钱的逻辑其实就是这么几步：

**先动起来，别光想——** 多少人卡在“不知道做什么”这一步，其实做起来才知道路在哪。

**动手之前先想清楚——** 产品、人设、渠道，起码心里有个谱，不能瞎冲。

**想好了就去测——** 用最小成本验证，一篇帖子就是一次测试，数据会告诉你答案。

**有了反馈就拼一把——** 别怕单小，跑了才知道结果。

**跑通了就赶紧复制——** 把一套方法打磨顺畅，用同样的路子去放大。

所以啊，别小看一单只赚14块的小生意。它背后藏着一套可以反复使用的方法论，这才是真正的财富。
