# 手把手教你空手套白狼，卖虚拟商品出海

你有没有想过，不花一分钱，就能拿到一整年的飞机上网会员，甚至还能把它变成一门小生意？最近我刚好挖到一个很野的路子，分享给想尝试出海搞钱的朋友。

先介绍一下故事的主角——Boingo Wireless。这是一家专门帮机场、体育馆、医院等大型场所搭建无线网络的美企，全球超过一百万个WiFi热点都有它的份。如果你经常坐国际航班，八成用过它的服务——机上WiFi就是按半小时、一小时甚至全程来收费，价格还挺肉疼。合作的航空公司也非常多，从亚洲的国泰、新加坡航空、日本航空，到欧美的汉莎、美国航空、维珍航空等，几十家都在名单里。

重点来了，Boingo和万事达卡搞了个合作：部分持卡人可以直接免费开通一个Boingo账户，然后在支持它的航班上免费用网。

操作起来并不复杂。打开活动页面，需要填一张万事达卡号。目前网上流传的可用BIN码前六位有：557914、527669、519394。如果你手头没有合适的卡，可以用一个叫bincodes.com的网站，它能按算法生成有效的万事达卡号，轻松帮你通过验证。

拿到账户之后，路子就宽了。你自己旅游出差可以用；不想用的话，挂到闲鱼上也能卖；要是想做出海生意，直接丢到Fiverr或国外的二手平台，标价99美元左右，因为这可是整整一年的免费使用权，这个价格并不算离谱。

当然，有人会担心风险。借用圈里一句话：你不赚钱，才是最大的风险。此处不构成投资建议，但思路已经很清晰了。如果对这方向感兴趣，可以点点关注，后续我会继续分享这种简单接地气的出海玩法。
