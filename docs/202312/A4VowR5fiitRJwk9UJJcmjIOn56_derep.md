# 清迈长居实操笔记
作者：龙哥



很多人第一次把清迈当作远程工作的落脚点，原因无外乎开销可控、气候宜人、节奏慢，更有一批全世界的数字游牧者常年驻扎于此。出发前把下面这些事理顺，能省掉不少现场麻烦。

## 行前准备

### 签证类型与要点

电子旅游签证是我本人采用的方式，全程自己操作耗时约十天左右，费用在240元人民币左右，可累计停留60天，比免签多出一个月。办理材料相对繁琐，建议直接查阅泰王国驻华使领馆官网的清单。

小贴士
* 若行程尚不确定、时间紧或不擅长自行准备材料，可在国内的电商平台购买旅行社提供的代办或加急服务，提升灵活性。
* 出境时航空公司通常会核验返程凭证。若不确定回程日期，可先订一张可全额退票的头等舱机票，落地后再办理退款；或先订一张飞往东南亚邻国的机票作为过渡。
* 落地签可续期7天，但续期记录可能影响后续签证申请。若确需续期，可先飞往周边国家再转旅游签入境，办理速度最快可达一天。
* 2023年9月25日至2024年2月29日期间，泰国对中国游客实施5个月免签，每次入境可停留30天，适合短期探访。

参考官网：选择赴泰目的并查询所需资料 - สถานเอกอัครราชทูต ณ กรุงปักกิ่ง

### 行李清单

电话卡
方案一：当地运营商AIS，服务稳定。机场或古城的营业厅均可办理，SIM卡约50铢，30天30G高速套餐约200铢，记得主动要求更经济的套餐。
方案二：行前在国内电商购买Happy卡，按停留时长选择，到手即用。
方案三：我个人长期居留，选择了True卡。
True卡申办流程：关注“小移在泰国”👸号下单，我选的是基础档，约合人民币50元/月，需绑定护照信息。国内3-4天寄达，入境后自动激活，续费可通过🛰️或支付宝充值。孟买信号普遍优于清迈。

![](img/39a372747576c1d1dd4841de758de7d7.png)

现金：开设本地银行账户对游客而言流程复杂，清迈日常消费多以现金为主。出发前可在中国银行或工商银行预约少量泰铢，招行暂不支持兑换且需提前两天预约。机场汇率偏低，建议只换应急金额，入境后再到市区兑换点换取。多数兑换点仅收现金，可用电子支付的点位汇率较差且有最低起兑额。

衣物：以夏装为主，叠加1-2件薄外套即可，清迈冬季并不寒冷。注意寺庙着装规范，女士避免短裙，男士避免短裤。

插排与转换头：长期办公者建议自备。泰国插座兼容国内两孔插头，若自用插排为三孔则需携带转换头。

### 泰国礼仪禁忌

多数泰国人信仰观音，不食用牛肉；狗肉亦被忌讳
头部为神圣部位，切勿触碰他人头顶
小费以纸币为主，硬币多用于乞丐，常见金额20铢
王室地位崇高，切勿对皇室影像指点或负面评价
入寺需穿长裤长裙，拖鞋需更换，不可攀爬或拍摄佛像
公共场所禁烟，酒店需确认指定吸烟区
交通靠左行驶，自驾或骑车必须佩戴头盔
每日8点与18点会播放国歌，需原地肃立
右手为洁净之手，递送物件宜用右手
签名忌用红色，因当地习俗红笔多用于墓碑文字

# 逛吃与出行

整体玩法可从经典路线、市集美食购物、艺术生活、自然生态、长居贴士五维度展开。经典线路与交通可参考相关攻略，Lonelyplanet的Chiang Mai travel板块亦很经典。

餐饮建议：不必死守清单，直接打开地图搜周边，评分4.4以上且评价数超50的店铺通常稳定可靠。按摩店同理，关键词为massage。地图结果偏西式口味时，可与大众点评数据交叉比对，更贴近中餐偏好。

出行
* Grab与Bolt均可绑Visa，Bolt通常更便宜
* 双条车不推荐，拼客绕路严重，且司机英语有限
* 山地车月租约50铢/天，可询Thai Charoen Motorbike
* 摩托车月租约150铢/天，无国际驾照被查罚500铢，但可获三天宽限期

清迈适合慢住慢品，希望这份笔记能帮你避开弯路，把精力留给真正值得体验的事。

清迈长住，怎么玩得不游客？

很多人第一次到清迈，都在景点打卡和咖啡馆轮换中度过。想真正住下来、认识同频的人，其实不用靠运气。下面这三个入口，是我从一份清迈生活攻略里扒出来的，亲测思路管用。

第一，手机装一个 MeetUp，把地区切成清迈。上面会冒出各种线下活动：工作坊、分享会、登山约伴、兴趣小组，看到感兴趣的直接报名。

第二，谷歌上有一份很多人转发的共享文档，专门汇总清迈的远程工作者社群和活动线索。找到它之后，等于拿到一张本地活动地图，能省下不少瞎逛的时间。

第三，Facebook 上的清迈活动合集页更新非常快，覆盖也广，几乎是全英文。英文阅读没压力的话，这是抓一手活动信息最直接的地方。

如果你想在清迈住得更深一点，阅读是很好的入口。原素材里那份书单有几十本，我没有全部铺开，只把最有代表性的书拎出来，按主题分类。

打底通识，先读段立生的《泰国通史》，结构扎实；再配合田禾、周方治的《泰国》第三版，能快速搭起对泰国的基本认知。

文学线索，可以从《泰国文学简史》和《泰国现代文学史》入手；想读轻松一点的，翻《泰国民间故事选》或《泰国谚语译注》都很有意思。

历史纵深，想放更大的时空坐标里看，《图绘暹罗》和《琉璃宫史》很值得读；《季风吹拂的土地》则把东南亚近现代史讲得很有画面感。

政治制度，《当代泰国政治》和《泰国民主政治论》属于比较扎实的基础读物。

人类学与社会，《逃避统治的艺术》和《弱者的武器》是这套书单里的“高光”，作者詹姆斯·斯科特的观点相当颠覆。

族群华人，想理解华人在南洋的处境，可读《泰国华人社会》和《南洋华侨与闽粤社会》。

傣泰山地民族，人在泰北绕不开这个话题，《傣泰民族研究文集》《泰国北部山地民族舞蹈文化研究》都可以翻一翻。

宗教民俗艺术，《泰北佛教史》《泰国传统文化与民俗》能帮你理解寺庙、节日背后的逻辑。

语言教育，《泰语构词研究》《泰国教育制度与政策研究》相对学术，适合研究型读者。

原素材里完整书单还涉及政治、族群、音乐、艺术等许多方向，限于篇幅就不逐一列举了。按上面的分类去找，基本不会踩雷。

另外，原素材给了两把“钥匙”：一份中南半岛数字游民报告发布在 Mirror，逛一下就能找到；B站上伯爵也有一个讨论“古代东南亚为何没有中国化”的视频，角度很独特，值得一看。

看到这里，你大概好奇我为什么对这些这么熟。简单交代一下背景：我叫小燕，本科是一所擦线985；2019年从美的跳槽到一家创业公司，在HR、运营之后转去做产品。赶上公司允许全员异地办公，我有了将近两年边工作边旅居的窗口。国内住过DNA基地、大理、海南，泰国则是我海外长住的第一站。

但清迈住得越久，越发现“换地方生活”并不能自动解决问题。我遇到一些把远程办公当成退路的人，本来在原有的轨道上卡住了，选择出走更像一种逃避。这话也是说给我自己：那段时间我和我妈关系很拧巴，我拼命往外跑，想靠新鲜环境攒能量，本质上也是绕开问题。后来想明白了，与其不停更换坐标，不如回到原来的系统里，把该面对的事一件件处理掉，顺便认真搞钱。

业余时间我喜欢户外，探洞、溪降、爬山、跳伞、潜水、飞拉达、攀冰玩过不少。最近在学怎么好好沟通，也练内观和冥想，都是为了修好和重要的人之间的关系。如果你也在经历类似困局，欢迎来和我聊聊。

这份攻略和书单先到这里，评论区也可以补充你的清迈私藏。
