# 0基础小白做视频号，20天自然流量做到25万GMV，我是怎么起步的
作者：龙哥

先说结果：一个完全没有直播经验的新手，用视频号自然流，入局20天就做到了25万GMV。

我是龙哥，今年2月才通过@苏夏的引荐认识了赚钱。刚进来的时候挺兴奋也挺迷茫，参加了两次航海实战营，信息量太大，反而更犹豫该选哪个赛道深耕，最后一直处在看、学、观望的状态。

转折点在10月。那次参加选品航海，让我认识了一批真正做事的人。也是这条线上的缘分，促成了我报名了@Erik教练和@肖肖教练联合带队的视频号进阶训练营。带着0基础的身份硬着头皮上课，终于在直播上拿到了第一波正反馈。

写下这篇复盘的时候我其实没什么底气。赚钱里随便刷刷都是百万千万的战绩，我这点体量说出来可能连成绩都算不上。但正因如此，我更想把自己从零到一的这段过程完整交代清楚。哪里绕了弯路，哪里是真正起效的，我都一五一十写在里面，希望能帮到同样还在犹豫的新手，少走些弯路，早点看到回响。


再次感谢赚钱这个让我开眼的平台，也非常感谢Erik教练和我的师傅@肖肖，是你们把我从观望推到了行动。

* * *

评论区有朋友说，拼劲十足做什么都能成事；也有大佬点评，有天赋又肯学，不成功都难。我仍在路上继续打磨。
