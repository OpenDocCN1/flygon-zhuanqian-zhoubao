# 当创业把我逼到轻度抑郁，我是怎么把自己拉回来的



## 创业伊始我抑郁了，后来靠这三件事扛过来

作者：苗子¹

日期：2023-12-01

没错，个人转做互联网创业的前期，我一度陷入了轻度抑郁。当时谁也没告诉，包括家人。怕他们担心，也怕自己在文章里写出来被误读。现在回头看，其实也没有那么可怕，把过程说清楚，希望能给同样在起步期挣扎的朋友一点参考。痛苦熬过去了，就真的只是过去了。

个人创业和打工最大的不同，在于脑子永远停不下来。特别是刚起步的阶段，躺下后脑子里全是各种想法，翻来覆去睡不着，天亮才迷糊睡着，第二天再继续颠倒。日复一日，焦虑感就慢慢堆上来。

2018年我从线下实体老板转到线上全职创业。那种黑白颠倒、自我消耗的状态整整持续了大半年。实在扛不住就去看了心理医生，结论是轻度抑郁，伴有神经衰弱的症状。

医生叮嘱我必须规律作息、别熬夜、保持情绪稳定，否则容易恶化。那句话说出来的时候我心里咯噔一下。我一直是个很开朗的人，抑郁这种词在我认知里只存在于剧里。拿了药回家后，我开始大量翻阅网络资料、逛论坛贴吧，看别人是怎么一步步走出来的。

**看了一整晚，反而安心了不少。**

第一，轻度抑郁属于可以自我调节的范畴，并不等于无药可救。

第二，大多数出现这种情况的人，都是生活或工作压力过大，或给自己设限过高的人。简单说，就是想得太多、扛得太死的人。

看完这些，我对自己能走出来有了基本信心。

顺便分享一个我常用的泄压法：当胸口憋着一口气散不掉时，我会直接开车去隔壁城市，下高速随便找一家酒店住一晚睡个好觉，第二天再回来。基本就能重置状态。这个习惯我到现在还在用。

当时我强制放空了两天，在隔壁城市的酒店里什么也不想。回来后才开始冷静梳理创业方向。

我很清楚，这场“病”本质上是我自己逼出来的。我必须改变这种逼自己的方式。

前期创业者很容易掉进两个坑：一类是拖延症晚期型，一拖再拖；另一类是过度自律的透支型。我创业初期就是后者。那种一人扛一家公司的节奏，长时间没产出，三个月不到就会进入自我怀疑的死循环。一边是信心崩塌，一边是现金流的压力。

后来我做了三个关键调整，帮助我慢慢走出来了。

**第一，捡回跑步这个出口。**

并非为了装热爱运动，而是必须有一个能把身体和脑子清空的渠道。上学时我练过体育，慢跑一小时甚至更久对我来说不难。跑步的同时我会放陈安之、刘一秒这类励志音频，反复给自己洗脑。身体累了，脑子也静了，晚上才能睡得着。

**第二，把债务和现金流摊在阳光下规划。**

说出来不丢人，当时最大的焦虑源就是每个月的还款。我把全部财务情况算清，给自己按最坏情况做了一张生存表。通过支付宝借了10万元，这笔钱只够我维持一到一年半的基本开销和还款。

有了这笔缓冲，我才敢给自己定更实际的目标：今天做什么、这周要完成什么，这个月需要通过什么方式达成多少收入。坚持一年后要到达什么状态。

这里的借钱操作不建议盲目模仿。我只是运气好加上努力才撑了下来，要是赚不到钱，这笔债就是另一场灾难。

**第三，深扎在实战里，接受慢反馈。**

这点听起来虚，却是最核心的。我的焦虑就来自两件事：短时间看不到结果，短时间得不到反馈。而根源是行动太少、积累太少、跑的项目太少。

有了第二步的资金缓冲，我才有了长达一年半的试错窗口期。别人常说负债的人更上劲，不负债的人更稳，我当时就是靠这份“不得不”的压力被逼着不断试错、迭代。

正是这三件事的组合，让我的心态慢慢回正，给了自己一个足够长的缓冲期，最终走出来并拿到了一点成绩。

说起来好像没做什么大事，但执行时的煎熬只有自己知道。现在想起来也挺感慨。

这个话题可能不性感，但我认为是互联网新手创业者几乎都会撞上的坎。

最后用三句话总结：

创业要给自己持续做心理建设；

创业要先确保基本的生活安全垫；

创业要学会布局、规划和接受慢反馈。

感谢阅读，希望能对现在的你有点用。
