# 不再盲目立flag！一个996工程师靠“自我管理”做副业，一年半赚了8W+

我是龙哥，白天是打工人，晚上是副业探索者，一名地地道道的工程师。

从真正踏进副业圈子到现在，已经一年半了。目前我在做📕博主，同时运营着“大学有术”成长社群，副业收入累计8W+。这笔钱在别人眼里可能不算什么，但对我这样一个被996压得喘不过气的工程师来说，能拿到这个结果，已经很满意了。而且，今年定下的年度任务，我也已经全部搞定。

回顾这一路，从纯小白到小有成绩，我最大的心得就是：一个人得有自己的规划和清晰的行为目标。2024已经近在眼前，身边不少朋友已经在动笔写新年计划了。我之前在📕上看到，有人从10月就开始“布局2024”，可大部分人的规划，只是把想做的事列出来而已，写完之后根本不会再看，自然也不会产生什么改变。

正因为如此，我一直在摸索一套更科学、更系统的年度规划方法。慢慢地，总算有了成果。用自己试了一年，发现这套方法确实更合理，也更适合副业新人。
