# 做项目，拼的不只是方法，更是思维

上次分享了单账号靠自然流量，在身心灵、国学这个赛道做到月入 1.8w 的实操拆解后，陆续收到了不少朋友的反馈和提问。有做得风生水起的，也有迟迟找不到感觉的。聊得越多，我越发现一件事：哪怕你把步骤掰开揉碎喂到嘴边，结果依然逃不过二八定律。

我是樾樾，坐标郑州，算是连续创业者了。大学毕业就开始折腾线下少儿培训，后来转到线上教育，一直泡在知识付费这个圈子里。

之前写的【身心灵国学板块】是我们直营项目之一。最近还在对接嵩山的线下场地，打算把正念冥想线下课也做起来。特别感谢生财这个平台，能让同频的人互相遇见、互相链接。

说实话，沟通的人一多，差异就特别明显。有人听完就能执行，有人看完还是原地打转。同样是保姆级的教程，有人出单轻松，有人就是跑不通。

昨天晚上又收到一位圈友的消息，说今天出单特别好。我一边替他开心，一边也在复盘：到底是什么拉大了人与人之间的差距？想着想着，干脆打开电脑，把这段时间跟圈友交流的心得整理一下。为了码字方便，我还特意把刚做的长美甲剪了——这篇帖子，希望能对大家有点启发。
