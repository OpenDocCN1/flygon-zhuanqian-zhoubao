# 11 个月通过小学资料项目收入 20w，引流 8000 老师家长粉的深度复盘

从游戏宅到20w营收：小学资料项目11个月全复盘，我是这么干的

哈喽，我是拾一。今天想跟你聊点掏心窝的话。谁能想到，一个曾经只会窝在寝室打游戏的“废柴”，竟然靠着整理小学资料，在11个月里攒下了20万收入，还让8000多位老师和家长成了我的粉丝。别急着惊讶，这篇复盘就是来交代整个过程的。

先交个底。我是2022年下半年才开始琢磨副业的，如今已经成了全职的自由职业者，靠着网赚养活自己。这一路走来，坑没少踩，捷径也偷摸走了几条，最无奈的是，明明好几次感觉到风口就在眼前，伸手过去却抓了个寂寞。好在跌跌撞撞之后，总算找到了靠谱的玩法。

所以这篇文章，我想把小学资料项目的底子翻一遍。全文大概5500字，既有零基础新手可以直接上手的起步指南，也有适合老手切换视角的新思路。目录先放在这：个人经历、前景判断、实操SOP（养号→信息设置→选题→内容制作→发布→引流→变现与交付），最后是总结。想看完整图文版的话，可以点我的飞书链接：https://rb2nh1gqd0.feishu.cn/docx/SUgJdtqCAoSKmWx1JoScSNKBnSe?from=from_copylink

不少朋友会好奇，这类虚拟资料项目到底怎么跑通？方法其实不复杂，从养号、信息设置，到选题、内容制作，再到发布、引流和变现交付，每一步都有各自的讲究。至于项目前景，我在飞书里做了详细分析，这里先卖个关子。

评论区里，安俊和Hz都夸了句“优秀”，我都有点飘了。A Jana关心资料从哪里来，我答：从拼多多、淘宝、闲鱼上买，或者参考同行的内容，再把这些资料重新加工成自己的版本。肥仔梁问账号有没有做企业认证（图书类），奇艺顺势聊到，自己也做小学资料，办小红书图书资质只要900。这些小细节，或许对你们也有参考价值。
