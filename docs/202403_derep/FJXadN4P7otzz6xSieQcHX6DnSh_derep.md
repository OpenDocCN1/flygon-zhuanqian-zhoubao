# 一、为什么这轮技术变革值得认真对待

今年春节假期，OpenAI 没有给业内留多少反应时间，直接甩出了文字生成视频的 Sora。它带来的冲击比 ChatGPT 当初还要猛，因为 ChatGPT 只是让人在文字层面觉得新鲜，Sora 却在尝试理解画面背后的物理逻辑。一位商业观察家的观点是，Sora 学的不是像素点，而是现实世界怎么运行。

顺着这把梯子往上爬：如果引擎能从视频里学会物理规律，接下来会不会装上摄像头去读真实场景？假如满大街的公共摄像头都变成它的眼睛，世界会发生什么？再进一步，如果全球的监控数据都被接入，又会怎样？

Sora 最值得重视的地方，不只是视频效果，而是它可能把通用智能到来的速度大幅提前。这才是 OpenAI 一直渴望的终局。

去年3月，有知名投资人说 ChatGPT 标志着“iPhone 时刻”，把移动网络时代正式拉开。腾讯那位创始人后来在股东大会上讲得更重：这不像十年一遇，更像几百年一遇，放在历史上和发明电一个量级。

面对这样的变革，大多数人关心的问题其实很具体：我能站在哪个位置？从哪里切入？要做哪些准备？这篇文章想试着回答。

# 二、为什么单独聊非工程背景的人

技术变革刚起步时，八成以上招人需求都砸向研发，尤其是算法方向。第三方招聘平台的数据显示，2023年前8个月，生成式内容领域的新增职位同比增长了139.76%，平均薪酬41.09万。技术门槛最高的三个细分方向是深度神经网络、图像识别和语言理解类算法，平均薪酬分别达到55.78万、55.10万、53.31万，全部超过50万。

![](img/5c30b43400a59d19c3413e84ae1db501.png)

数据一亮出来，很多人的第一反应是“跟我无关”。因为这些职位基本默认要求硬核研发能力，普通非工程背景的人确实很难够到。

举个我亲历的例子。2015年腾讯内部培训时，我认识了一个姑娘，1990年生，北京理工大学毕业，性格很安静。她最早在微信团队，6年前跳到字节跳动做TikTok，年薪百万。最近几年，还有做底层引擎的创业团队不断想挖她。原因不难理解：地基没打好之前，整个行业都在抢能打地基的人，这类人当然会被高溢价追捧。

但这条路对人文类背景的人几乎不可复制。眼下这轮变革也带着很强的“精英浓度”，主角们动辄来自顶尖名校、顶级大厂，普通人连入场券都很难摸到。

所以技术人才我反而不太担心。我更想聊的是：没有工程背景的普通多数，要怎么把这一波的机会接住。

# 三、非工程背景的人，手里其实有两张好牌

先讲一句听上去像鸡汤的话：接纳自己，可能是成年人最难的修行。我们太容易盯着自己的短板，却忘了把长板看得清清楚楚。每来一轮新技术，就有人后悔当初没学理工。但我越来越相信，每个人都有属于自己的能力圈，能走到最后的，都是把擅长的事做到极致的人。

现在能跑出来的应用，几乎没有单一技术驱动的，背后一定是人文与工程互相借力。苹果那位传奇创始人，做产品时的美感、对消费者心理的拿捏，再加上他对工程的理解，这才造出了改变行业的手机。

对非工程出身的人来说，有两张牌尤其值钱。

第一张，是人文感知力。第二张，是连接社会与商业机会的嗅觉。当生成式工具成为基础设施，能理解技术边界、又能理解人和社会情绪的人，会变成稀缺资源。他们可以在新媒体、教育、艺术这些领域里，通过人和机器配合，把创造力和产出效率一起拉高。

一个特别实在的切入口是：任何组织都需要跟各种外部角色打交道，比如监管方、公众、出资人、合作方。于是政务沟通、媒体对接、品牌传播、用户关系、战略研究这些职能，天然适合人文背景的人。OpenAI 每次发布都像扔下一枚舆论炸弹，监管沟通和舆情应对必须有专人顶着；上一次 GPTs 发布，怎么把发布会做得像苹果发布会一样有感染力，又是品牌部门的大考题。

# 四、可以下注的方向

先把心态摆正：你可以把现在的生成式内容团队，看成当年的短视频应用或社交软件。曾经移动网络时代有哪些分工，今天基本还会重新长一遍，只不过名字和技能要求变了。

## 4.1 内容与用户维护方向

这个方向现在招人最多的，是几家早就跑通业务的老牌平台。业务盘子固定，它们需要往里面嵌入新的生成能力。

![](img/2f51ee9b09f0f0c79047ef407e5802a5.png)

其中 360 动作很猛，它的创始人一直惦记搜索生意，早年错过机会的遗憾被多次写进书里。现在他几乎天天在公开平台露面，活成了生成式内容的头号推销员。360 自家的智能搜索，主打给用户一个又快又准的答案。

![](img/4868c8a71182818041422c2472aa1ecb.png)

另一款名叫天工的助手型搜索产品，基本逻辑和 360 一致，职位需求和职责也高度相似。

![](img/35f1b3f7f08c91ad2db2d4f3c6b3ebfc.png)

百度在招聘页面上没把话说清楚，我打听到的情况是，这个角色归在知识图谱与笔记类产品下面，大概率是基于百科词条做内容维护。

![](img/410133f0e3da82dff16537d262d915a3.png)

那些新锐创业团队，目前反而没有全职做内容维护的岗位。原因很简单：它们还在打磨技术基础、拼命拉新，根本顾不上后续留存和活跃的事。比如某家团队的实习职位就很能说明问题，内容维护不是它的重心。

![](img/84ba31888fe6dc76c168b2844f38d431.png)

## 4.3 内容作者服务方向

这个方向通常出现在各类视频与社区平台，指的是服务那些靠生成式工具做内容的作者。

## 4.4 产品支持方向

老牌平台在这个方向上招人多，新锐团队和小机构相对少。而且产品支持这个活儿，经常和内容维护、增长获客、社区管理混在一起，名字叫法五花八门。

## 4.5 品牌、政务与商务方向

砸钱买量的职位，前面已经算进增长方向了。等产品进入稳定期，应该会释放出更多品牌建设类的角色。

政务关系这一块，目前最大的客户在企业和公共部门，普通消费者更多是体验和造势。公共部门的逻辑很清晰：必须用国产的技术底座，并且要本地化落地，核心诉求是保障信息资产不外泄。所以谁能把政务关系维护好，谁能拿下标杆型政务工程，谁就能在这个市场里卡住位置。

这个角色非常吃积累，越老越值钱。它跟你会不会写代码无关，只看你是否长期深耕政务线，手里有没有对政策的理解和人脉资源。

## 4.6 商务拓展与销售转化方向

所谓的行业总监，说白了就是面向大型机构的销售。企业级生意绕不开这个角色。我有一个前同事，在一家办公协作软件公司做KA客户经理，中间空了半年，最后硬是靠过去履历拿到了一家新锐团队的同级职位。

![](img/491988c0895d6fc8726e2485c2c8962d.png)
![](img/aa9138ee2789f795d8dba529b2842d4d.png)

这个方向特别依赖人脉积淀，也特别考验人情练达。

另外还有一群人，靠视频直播、十几秒的短内容、私域群聊来做变现。这类工作主要出现在教人用生成式工具的训练营、知识付费社群和咨询机构里，往往由几个头部个人品牌撑起一家小团队。它们的目标非常直接：根据产品找关注度、放大关注度。这些角色最能看到钱，做得好的年薪五六十万甚至上百万都不稀奇。在知识付费类机构里，日常维护用户只是表面功夫，真正的核心是把用户转成付费客户。

## 4.7 产品规划与安全合规方向

产品规划类角色的需求量很大，薪资也普遍比内容维护类高。在生成式时代，做产品的人除了要懂目标人群，还要懂一些底层技术，能把用户诉求翻译给研发，同时还要理解生意逻辑和设计。招聘要求里常常写着编程类学科或相关专业优先，但绝不是硬门槛，过往经验更重要。市面上有不少相关课程，质量参差，报名前需要自己掂量。这份工作日常少不了和多方拉扯，如果你本身喜欢据理力争，可以试试。

![](img/8d4bcae17fdc555550710cd54b3db5f9.png)

安全与合规方向，会涉及意识形态风险与伦理问题。之前做过类似工作的同学，迁移成本不高。但缺点是内容重复度高，随着智能审核的效率提升，这个领域的晋升空间越来越窄。而且这类工作比较依赖人力规模，武汉也有不少，其他像天津、成都、西安等次一级城市同样是聚集地。

![](img/5677173e9fce3da39fd1990939361f6c.png)

字节跳动这边也有一个方向类似的产品规划角色，负责社区内容治理。大致要求是：大学学历，积累了五六年相关经验，能和工程、数据、法务、市场等团队紧密配合，关注监管趋势，英语能当工作语言，能适应快节奏。

## 4.8 知识传授与基础支撑方向

讲师和顾问类工作，核心拼的是个人溢价和圈里的名声，否则很容易被当成低回报的劳动力。这类机会现在多在各类付费课程、垂直社群和在线培训机构里。在招聘网站上直接搜，量不算多。

![](img/c2b7d2b6c6f53f7ffee44efe6f2e206b.png)

还有一个曾经被吹上天的角色：提示词设计师。去年聊天机器人刚火起来的时候，大家觉得这是未来，结果今天再看，它已经变成了一个相对基础的支撑岗。日常跟人打交道少，做久了容易枯燥。

![](img/3d4e2c1497c5c2ed65b0d3b91c1d25a6.png)

某家新锐团队对这个职位的要求大致是：配合研发进行样本筛选、内容标注、成果验收和逐步优化；建立一套关于画面质量的评判标准；还要能熟练使用多种绘图生成工具，有一定的审美，能理解业务目标，具备把需求落成可执行方案的能力，并且对生成式内容有热情。

数据标注员则更基础，也是人力密集型。

![](img/819479cda673ac8327bce391081e5646.png)

至于人力、法务、办公室事务这类通用职能，跟生成式内容关系不大，但所有机构都需要。我就不一一贴图了，对谁感兴趣自己去搜。

# 五、入场前要避开的几个深坑

第一，如果选面向大众消费者的团队，先判断它的业务能不能撑住。底层能力是不是配得上野心？有没有自带现成关注度？国内用户愿不愿意掏钱？如果后劲不足，业务一关，最先被优化掉的可能就是你。

第二，如果选面向企业客户的团队，要警惕泡沫的存在。企业级落地的路径比较短，各方人马都在抢地盘。我整理了一些信号：某搜索巨头宣称和几百家企业结盟；某云厂商宣布和七家伙伴在能源、电力、交通等行业推进；某通信巨头在气象、矿山等领域发布合作；某社交巨头和几十家企业共建；还有一家语音技术公司，首批接入了上千家企业。过去大家公认，通用基础引擎会走向赢家通吃，最后形成少数几个底座加众多应用的格局。一旦进入下半场，泡沫就会逐个破裂，之前扩张太猛的人才阵列也可能缩水。有内部人说，不少老牌平台都是先设一个新业务小组把人招进来，业务一段时间做不出成果，就是批量裁撤。所以，想挤进大平台的人，先想清楚这个小组的人员规模是不是已经过剩，自己会不会成为下一批被优化或调岗的人。

第三，如果选垂直领域的企业客户，小心那些“假自研”的包装。很多号称自研的垂直引擎，其实是拿多个公开或不公开的底座，用自己行业的资料做微调，并不是真的从零写起。所以本质上没有那么多“行业专用专家引擎”，更多是“行业专用的智能体”。比如某办公软件号称自研，实际是接入了多个外部引擎再调优；某金融公司的开源底座，是在一个开放框架上训练出来的；某教育公司出过自研的数学引擎；某修图应用的美化引擎，也是基于通用的生成技术微调而成。

# 六、如何快速摸清一个行业

这个方法是我在公司内部带人用的，已经有不少人靠它完成了转行。有人从某985高校的建筑专业转去做农产品直播的内容策划，也有应届文秘专业的学生，用两个月转进了面向成年人的线上培训用户维护。

篇幅关系，先讲到这儿，剩下的我们下篇再继续。

最近总有人问我：转行到底怎么做才能成？我身边有两个让人印象深刻的例子：一位30岁的市场营销从业者，直接跳到某独角兽机器人公司当上了CMO；另一位做地产设计出身，只花了两个月就进入智慧城市赛道，转做政府公关。他们靠的，从来不是海投简历。

很多人转行时，把时间全砸在改简历、练面试上。但对足够聪明的人来说，这些只要稍微点拨就能通。真正的难点，是行业调研和公司调研——也就是搞清楚对方到底靠什么赚钱。正确做法是：先广泛打开前端的口子，了解目标领域，再逐步收窄，一个案例一个案例地筛，最终锁定适合自己的职业坐标。

什么叫“适合”？职业目标必须拆到四个维度：行业、领域、公司、岗位。比如“互联网行业→读书领域→平台型公司微博→市场运营”，这才算清晰的坐标。而不是笼统地喊“我想做运营”“我想当产品经理”。行业和商业模式不同，同一个岗位可能完全是两个物种：出版公司招产品经理，本质是图书编辑；互联网公司招产品经理，是围绕核心产品真刀真枪地操盘。两者的天花板，一个天一个地。你愿意当编辑，还是去大厂做产品经理？

选行业就是选趋势。记住这条排序：行业 > 公司 > 岗位。别以为调研只是投资人的事。我们每个人都是自己的CEO，也是给自己未来下注的投资人。押进去的是三年、五年甚至十年的青春，折算成人民币得有多少？不好好调研，怎么敢往前冲？

好在现在有AI工具和麦肯锡工作法，能大幅提升调研效率。我也整理了一批靠谱的信源：

媒体：腾讯科技、腾讯新闻潜望、极客公园、36氪、虎嗅、晚点latepost。比如《中国大模型现状：一面狂热，一面冷峻》那篇报道，就把投资结构和创业公司分类讲得很清楚，顺着线索定向深挖就行。

播客：张小珺商业访谈录（作者是腾讯科技资深记者，正好是我大学同学）、科技早知道、疯投圈、散装智能。同样的思路，可以迁移到公众号、视频号、微博、B站。

微信搜一搜：强烈推荐，直接搜目标行业和公司，谁用谁知道。

投资机构：源码、奇绩、真格、蓝驰、五源、红杉、今日资本，重点看它们的投资项目、公号和创始人演讲。

接下来是“跟人学”的实操。

怎么找到想找的人？这是最底层的搜索技术。自媒体上，抖音、视频号、知乎、公众号、B站搜关键词，凡是愿意出来分享的，通常有干货也有表达欲；职业社交平台有脉脉、领英；付费渠道可以试试知识星球，或者直接红包开路，但注意红包可能让你的身价被打折，自己权衡；熟人介绍也别忘了，找同事朋友帮忙留意，或在朋友圈求助，都很有效。

怎么接触一级招聘市场？第一，主动写内容输出观点，发到脉脉或朋友圈，会定向吸引同频的人来聊。第二，参加线下活动，创投机构、目标公司、社群都会办。第三，花钱上创投类课程。第四，求助猎头，把猎头分组可见，看谁会主动联系你。

再分享一个挖联系方式的小技巧：用天眼查或企查查查目标企业，如果留的是手机号，那大概率是创始人或高管的私人号码。直接加微信，说明求职意图，附上简历就行。这个思路出自职场作家七芊的《精准求职》。

顺便说说招聘市场的一二级之分：一级市场由投资人、创始人、公司高级决策层组成，更看重性格和价值观；二级市场由HR、猎头、中层和普通员工组成，更看重学历和垂直经验。两者逻辑不同，甚至完全反着来。

怎么和目标公司的人搭上话？直接点：打开脉脉，搜目标行业岗位，比如“碳中和”“大模型”“教育”；加对方（买会员能加更多人），先展示你的优秀背景和资源，再说明诉求，比如请教或者内推；争取拿到微信；加上后开门见山，再亮一次优势和需求。发红包也可以，但别让自己掉价。每天加5个人，坚持一周，聊完35个，你会豁然开朗。
