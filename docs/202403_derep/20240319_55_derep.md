# ('只工作不上班第一年，职业生涯规划赛道从月入 1500 到年营收 50W，我做对了什么', (2, 44))

“不上班只工作的第一年，我竟然从月入1500做到了年入50万。”如果你也在咨询行业里摸爬滚打，这篇复盘或许能给你一点力量。

我是员子姐，独立职业生涯规划师，也是盖洛普优势教练。说起来，我2019年就加入了赚钱，那时候刚成为全职妈妈，正处在职业的迷茫期，想看看人生还有什么可能。也是在那时，我撞见了“职业生涯规划”这个赛道。

2023年，我正式开启自由职业：不上班，只工作。第一个月收入只有1500元，第二个月却直接突破五位数，全年营收做到了50W+。这背后靠的是“生涯规划+个人优势”两套视角的组合，让我不断调整方向，最终跑通了适合自己优势的商业模式。现在，我真的过上了一边玩、一边赚、一边陪娃成长的日子——也把自己活成了最想展示的那个成功案例。

当然，过程并不轻松。作为咨询师，我踩过很多坑，也多次痛苦到想放弃。但每次熬过去，都会离理想的自己更近一步。

这次我把自己过去一年的经历完整梳理了一遍。如果你也是生涯规划师、心理咨询师、优势教练、高考志愿填报师、家庭教育指导师……苦于变现难、不会设计产品体系、被一对一咨询的收入天花板压得喘不过气，强烈建议你读一读。里面会讲到：

- 如何用复盘思维放大优势，找准自己的定位；
- 怎样打破一对一咨询的上限，把时薪做到4位数；
- 自由创富的生涯规划师/优势教练，成长路径长什么样；
- 给想入局的伙伴的真心建议。
