# ('视频号如何混剪自然流3个月不死号卖88万', (2, 22))

视频号纯自然流混剪，三个月跑出近90万GMV，账号还活得好好的。这篇实操复盘，希望能帮到正在迷茫的人。

我是初孟，一个在创业路上反复摔打的人。

这些年我做过淘宝店群、抖音店群、抖音视频号矩阵，又碰过拼多多食品百货无货源店群，几乎条条路都在交学费。最难受的是2023年下半年，我把准备结婚的钱投进最后一个项目，结果血本无归，另一半也差点离开。那段日子每天啃馒头，日常开销全靠对象的美团月付硬撑。

![](img/2caeb295ad900a7c55567bf402a457ba.png)

年底我又不服输，跑去搞抖音千川带货，结果又亏了差不多20万。当时身边有位大哥对我说：“先活下来，活下来才有希望。”哪怕每天只赚十块钱，一个月下来也有三百；如果每天能赚五十，一个月就是一千五。只要有事做，就还有翻盘的可能。

也是从那时起，我决定挑一个投入最低、几乎零成本的方向。没有团队，没有预算，只有一个人、一部手机、一台电脑，就这样开始做视频号。

连注册和开播都是现学的，每天只盯一个目标，一点一点往前拱。好在有大哥一直在身后指点，带着我从零开始，走过0.1、0.9，最后把整个转化闭环跑通。

先晒成绩：截止2024年2月29日，我的几个账号总成交GMV是895600元。

![](img/f5bafcdb5cd585e1c8272c7d9ac73d9a.png)![](img/f278b64f1c9aa8214bfec4db7446ac47.png)

其中单账号累计营业额做到了553900元。

![](img/d059c61108d978545e204eda342dc02d.png)![](img/d2bfc35730abbbd7a6784be7ef899b40.png)![](img/04c460c20f427f0c9d93681506b3f2cd.png)![](img/d8f99f7e537433a85e16c4b307f57c64.png)![](img/042161fb83e42eaa44035a5703677a75.png)![](img/7affb66af1c274dbef25d50756dde57c.png)![](img/483e5cc95219652c2de757b35b876909.png)![](img/79e5730f84e5f2d3a9a3ce077ef2c160.png)![](img/9b99b1bdc83ddfb86c0556a43dee077d.png)![](img/3fee5c6590927d3c9a6c63eafcc3a78a.png)

下面直接把视频号混剪自然流的完整操作流程拆开讲。

第一步，选品。
电商人都明白，品没选对，后面全白搭；素材没处理好，再好的品也推不动。选品我会先用蝉妈妈这类数据平台看趋势，找当季爆品、应季品和能长期卖的品。视频号主流人群在40-50岁，所以产品必须贴合他们的需求。现在正值开春，最猛的就是种子类目。

![](img/ede0f16f0cea83b21e6574c80a413861.png)

抖音正在跑量的爆款，只要人群和视频号对得上，搬过来十有八九也能爆。

![](img/998217211b4fe6b523655c998068db2e.png)![](img/948fcdacebf74333a91736912525b9e8.png)

第二步，找素材。
品定好之后，就去全网扒相关视频素材，越多越好。浏览器建议用星愿浏览器，有些电脑直接就能装。

![](img/12b0981d532cc92ed3d47a384e3191e5.png)

如果星愿用不了，就用电脑或手机上的去水印小程序，抖音、快手都能下无水印视频。

![](img/1e460299db98e9c419418da088765a64.png)![](img/0d7fc2d4b0c99334667d8468884c81c4.png)![](img/eb050a98a0180392a2a4049e2712735a.png)

第三步，拆素材。
这步需要PR和ME配合，PR负责场景编辑检测自动拆分，ME负责批量导出。注意ME必须装在C盘，否则联动不起来。操作路径：新建PR项目，导入素材，拖上轨道，右键素材选“场景编辑检测”，再点“从每个检测到的修剪点创建子剪辑素材箱”。电脑配置一般的话，素材别一次全选，几个几个来。

![](img/9dd14eba8f3c5e0555eb3a064cafa7ea.png)![](img/074fe4555ac836ef52c31dadba8ce363.png)![](img/ce290b9b4e3147a5dcd42a9cbb83749c.png)![](img/59ab32f24e74ed0b282925d01fff40e7.png)

点确定后等电脑自动拆，拆好的片段会进素材箱。

![](img/aa0466d927ce39b74767411ef3d50497.png)![](img/1bd97056a7f75bdeccaab9cfed944f9d.png)

选中素材箱按Ctrl+M弹出导出设置，点“队列”，让ME自动联动导出。队列跑完后，在ME里点类似播放键的按钮就能输出全部片段。

![](img/871a09d333d3501c2d74c8c1c06043e0.png)![](img/577ec1541dbdf37af3499ee0c2f9120f.png)![](img/75cb4c52c46e8ca7f20a6b3e2ef830f2.png)![](img/adf621c3328b2e260416ccacc27169dc.png)

第四步，分类素材。
拆好的片段按镜头分门别类，后期剪辑会从容很多。

![](img/52f35044f746a1dc3c961a0325f37d83.png)

另外要提前拍一些画中画素材，手机随便拍点什么都行，每条视频都要叠画中画，所以多拍点存着备用。

![](img/882df64dbc1ccce1b8d9c6b5362b2f0a.png)

扫光素材可以自己做，也可以直接用现成的。

![](img/ab16adec02f79e7c6634b4f9f18d064c.png)

第五步，剪辑。
用剪映建工程，把每个分类的素材文件夹拖进去。基础手法包括：随机给片段做镜像，适当放大局部，保留主体。字幕也全部重做：能去字幕的先在线处理，去不掉的后面用贴纸压住，再用剪映根据原声重新识别。然后叠四层自己拍的画中画，每层透明度调到1%，长度与视频对齐；四角各放一个会动的贴纸，位置压在角落不干扰画面。接着加4个热门特效、4个人物滤镜，再铺扫光素材，透明度1%。有条件的再补抖动和闪光特效，闪光可以做三层。

![](img/96309f12871a423932a3711ea232c3f6.png)

工程文件大概长这样，搭建好之后先自己完整过一遍，有明显问题再调。

![](img/0b25c95d74bd56f79aa8590b97ca90b6.png)

第六步，发布。
电脑端登录视频号助手后台，直接上传视频，标题写不写都可以。

![](img/65a433caf42f98bd57efbc1fe86b6290.png)

发布时机看账号状态：流量稳定的号随时可发；流量不稳的号，优先选早上4点、10点、下午3点、傍晚6点。手机发布注意画质：安卓用数据线从电脑把文件拖进手机，千万别用微信传，会压画质；苹果用电脑装爱思助手，数据线连接后导入视频，再在手机上发布。

第七步，开播。
开播前先把商品挂好，商品ID自己准备。草稿箱里放3条视频；直播中如果当前视频还在跑流量，就别急着补，等跑不动了再补。粗略判断标准：开播半小时后，5分钟内新进人数少于10个，就把草稿箱里同样的视频原封不动再发1个。点直播可能会触发人脸识别，用别人实名号的话，要先让对方扫好人脸，你登录后不要反复切换设备，否则还要重新验证。

直播前还可以做一个透明背景的价格贴图，贴在直播间角落，方便观众直接看到优惠价。

![](img/c185bc4bd3551a15d44cd4d28e1e0b69.png)

做法也简单：打开创可贴，新建空白画布，输入文字，背景选透明。

![](img/7e101750045085a2025c8d25538a64f3.png)

填上你想突出的价格，调整尺寸，导出PNG。注意不要用会员字体。

![](img/142760954c594db75d38b6e79e9f0ce0.png)![](img/d90ec9cacfc8209def7ab3b116c34820.png)

直播标题按“视频同款xxx热卖中”来写，分类选“购物-综合电商”，封面用风景图，别放产品图或美女图，避免被系统误判。样品不一定非要原品，找个外观接近的包装也行；没有就用美团、饿了么急买，或把商品主图打印出来折成小立牌。开播后一定要点“商品讲解”，不然用户没法直接下单，这一步太重要了。

![](img/047716bee832d001a14937852d5a4f05.png)

最后说点心里话。
项目能跑起来不是运气，而是一个字：熬。我做这个号的初期，每天凌晨3点闹钟响，4点多发视频、开播；扛不住就眯一会儿，下午接着剪素材，夜里再发一轮。那段时间总觉得自己做得不够、速度不够快，但即使没有结果也照做，做着做着结果自然就来了。创业就是这样，成功可能只是一次偶然，但偶然背后是无数次的重复和修正。这套方法不吹嘘，是我一步一步踩出来的。

目前我也在做视频号付费直播板块，直播间每天稳定5个左右，开年到现在已经稳了近一个月。平台眼下还在放量，自然流肯定是最优选，能跑出自然流的账号要格外珍惜；但付费流量此刻也很稳，只要占住某个产品的坑位，基本每天都有消耗和收益。我的付费流量打法，下次再和大家细聊。
