# ('“自媒体社牛狠人养成专栏”——如何提升自信，让自己遇事不怂？', (2, 32))

“自媒体社牛狠人养成专栏”——怎么才能底气十足，遇事不再发怵？

很多伙伴加了社群之后，常年潜水，哪怕买了课买了服务，也不敢开口提问。私下问起来，要么觉得群里大神太多，怕自己说错话丢人；要么生怕打扰到别人，顾虑给人留下不好的印象。

其实，这种“怂”，完全可以通过刻意练习扭转过来。今天我想和你分享几个非常实用的方法，帮你从骨子里长出自信。

**先解决根本问题：让实力配得上你的野心**

底气不足，说白了，很多时候是能力还没跟上。但这里要分两种情况看。

一种情况是，能力确实还有提升空间。这时候，恰恰要感谢你的“不自信”，它在提醒你：该补课了。

我自己早期混圈子时也一样，看别人赚得盆满钵满，自己发言、链接人脉时总怕被瞧不起。但我也因此意识到，必须重构产品体系和流量打法，才能打破收入天花板。后来我才从低客单转型做高端私教，学会了快闪群玩法，摸清私域运营的规律，直到去年十月突破了月入十万。

如果你也处在这个阶段，不妨换个思路：看到别人成绩的同时，也去看看人家背后的付出和成功逻辑，再对照自己的投入，尝试复刻路径。

就像很多人只看到我月入十万的风光，却没看到我常年熬夜处理消息，每天排满了一整天的学员安排，忙到脚不沾地。

另一种情况是，你其实有能力，却完全没意识到。这时候，你需要借助“第三视角”来重新认识自己。找几位靠谱的朋友或同行，请他们用几个关键词，或者直接给出优劣势评价，帮你拼凑出更真实、完整的画像，减少认知偏差。

**给自己装一套“自我激励系统”**

不要只盯着“大目标”看，也别忽视“小进步”。大成就值得庆祝，但每一点微小的正向反馈，都是你自信的基石。

我们合伙人社群里，一直鼓励大家积极报喜。有人写出了百万阅读的人物稿，也有人只有十万、一万阅读，但只要突破了过去的自己，就值得被看见和肯定。

别总指望一夜暴富式成功，那是极少数人的剧情。一个万粉公众号的诞生，可能是十个千粉，也可能是一百个百粉，甚至是一千个十粉堆出来的。方向没错，快慢根本不改变终局。

所以，不要拿别人的节奏来捆住自己的信心。你自己去做了，去拿到了成绩，哪怕慢一点、小一点，都已经是赢家。

**练就“接得住失败”的本事**

如果你承受不了失败和批评，就会把行动前的恐惧越放越大，最后越来越怂。

其实，失败真没那么可怕。任何事都只有两种结果，成功和失败都只是概率事件。哪怕你觉得有百分之百的把握，也可能翻车。

更重要的是，失败一定有原因，找到原因，就能翻过那道坎。

我刚开始转型做私域时，一天发七八条朋友圈，连续几周一单都不出。但我当时特别享受那种“失败”状态，因为这意味着我的成长空间巨大。那段时间疯狂试错，让我清楚了哪些文案没人看、哪些话术没吸引力。正是因为踩过这些坑，我才更懂新手起步的难处，也才能给学员更接地气的交付。

成功不会永久，失败同样不会永久。这单没成交，就努力下一单；这个赛道没跑通，就换个方向继续死磕。自媒体打的是持久战、游击战，稳住心态，好运自然会来。

**先从某一个“单项自信”开始攒**

自信是多维度的，如果你觉得全面自信太难，那就先从写作、表达、运营等某一个方面下手，就像拼图一样，一块一块拼起来。

我最初的自信心，完全来自公众号。账号顺利跑起来后，我就有了继续尝试的勇气：既然投稿文能写好，那私域文案凭什么不能？人物稿凭什么不能试试？

慢慢地，你擅长和自信的领域会越来越多，覆盖面越来越广，遇到事自然也就不会再“怂”了。

最后送你两句话：成为自媒体狠人没那么玄乎，就是一个字，做。心态上也只需要记住——不要太把自己当回事。

真的没那么多双眼睛盯着你，你也不会因为一两次失败就一蹶不振。相反，你越怕，越容易错失机会。把注意力收回手头的事，干就完了。

希望今天的分享，能给你一点往前走的勇气。
