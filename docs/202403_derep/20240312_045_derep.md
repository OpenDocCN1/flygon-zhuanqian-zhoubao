# 这些年来在在线教育上的思考和理解-知识付费到底应该肩负什么使命？

零投放月销1200万后，我聊聊知识付费的使命

我是泰来，做产品出身。2018年，我扎进少儿在线教育，成了国内最早一批做这个方向的人。半年时间，没花一分钱买流量，月成交额做到1200万，毛利率85%以上。当时心里有个挺朴素的愿望：等将来孩子问我工作是干嘛的，我能很骄傲地说，爸爸是做教育的。

现在回头看，如今知识付费圈子里那些玩法——私域裂变、体验课转正价课、学完退费、老带新、分销体系——都是我们七八年前玩剩下的。看着一个个新玩家踩进同一个坑，我甚至能脑补出他们背后的SOP长什么样。

当时这个赛道里最典型的三家，刚好走了三条完全不同的路。VK在直播课上势头正猛，斑马在AI课上势如破竹，我在的伴鱼做的是三层结构：第一层靠投放获客加变现，ROI能到1.2，用绘本APP的免费阅读做钩子，把人一步步转化成订阅会员，再到连续订阅；第二层不再花钱买量，把存量用户导进AI课，从童谣体验课一路做到系统课，再横向扩科，自然拼读、英语、进阶数学、音乐、美术、围棋都安排上；第三层还是吃存量，开辟1V1直播业务，订阅用户和AI课用户都可以往1V1里导。

VK就简单多了：投放拿1V1线索，然后首次转化、续费，一条道走到黑。

斑马是另一套：投放AI课，体验课转系统课再续费；之后开始无投放拓科，比如学完英语的续费用户导到数学；最后还有一层幼升小导流，把用户源源不断输送给猿辅导的K12，一吃就是十二年。

那几年，不少同行在资本加持下烧钱扩张，最后倒的倒、跑的跑，我们靠这个结构稳稳活到了最后，还长期待在前三。

结果也很直接：同一个买量周期里，投入一万，伴鱼能收回来十万；VK只能收八千；斑马只能收五千。

有人会问，VK和斑马这么亏，怎么活下来的？VK靠现金流，一年流水70亿，但一直没能长出新业务，常年亏损。斑马靠服务和续费，也靠拓科，回本周期一年半，但人家把幼儿续费设计成了三年，三年之后再无缝续到猿辅导K12。伴鱼是当月就回本，当月十倍产出，转介绍贡献30%，分销贡献50%。如果再加上像猿辅导那样的长生命周期，收益还能再上一个台阶。

我在伴鱼做AI课的那段经历，放到今天的知识付费行业里，有些数据至今还很难被超越。不投放流量，月入1200万+，毛利率85%+；体验课转正价课的转化率做到40%；社群运营一个人管1500个用户，还要兼任班主任；行业里第一次有人把学费返还、体验课转大课、续费、跨科引流设计成一套组合拳，后来的模仿者只学了壳，最后大多烂尾；让老学员当班长带新一期学员，这套机制也是我们第一个跑通的；体验课完课率超过90%；转介绍率达到30%，净推荐值70；线上教育二级分销是我们首开先河，一半收益都来自分销。

数字好看是不是？但更让我在意的是，孩子们上完课真的能见词能读、听音能写、主动开口。商业上能打，交付上也真能出效果，这才是教育该有的样子。

后来大家都知道了，双减一来，少儿在线教育基本就没了。但那些被验证过的模型、打法，却被搬到各种教育产品上反复用。我相信大多数教育产品一开始是有初心的，只是慢慢发现，让成年人给自己花钱学习，比让家长给孩子花钱难多了。于是产品不断妥协，营销越来越猛，知识付费最后就成了“韭菜炮灰”的代名词。

所以我想认真聊聊：知识付费到底该扛起什么？

我的答案很干脆：好的知识付费，应该具备四种能力——养活自己的能力，丰满他人的能力，推动进步的能力，疗育社会的能力。

我自己习惯把知识付费分成两类：通识和技能。

通识类的例子很多：语言、性格、收纳、养颜、养生、职场软技能、沟通口才、女性成长、人文历史、前沿动态，都算。技能类也清楚：考公考研考编考级，程序语言、设计、产品、运营这些就业培训，还有个体经营、商业增收、短视频变现、副业。通识是长见识，技能是端饭碗；通识让人轻松从容，技能让人严肃甚至窘迫。通识是铺开的面，技能是往下挖的井。所以通识类的好评度和NPS普遍更高，技能类收费更贵，但真正学成的人却更少。

如今这个领域已经被各种乱象搞得口碑崩坏，爆雷事件层出不穷，而且大多集中在技能类，本来就不安定的社会情绪，又被添了几把火。

在我看来，知识付费最根本的出发点，是生产力的提升。交付之后，也要真的让人生产力变强。落到现实里，它的价值就是压低失业率、创业失败率，顺便减少社会上的不稳定因素。我拿这把尺子衡量新项目值不值得做。

王德峰有句话让我印象特别深：科学要形成系统，靠的是哲学。做商业也是一样，得回到最根本的地方，用哲学式的思考和精神去提炼总结。想通这一点，知识付费的初心就清楚了：生产力的发展，是一切的原点。要发展生产力，就得先充实自己；想充实自己，就必须在环境、思维和认知上不断刷新。

我一直觉得“知识付费”这四个字是个伪命题——知识本身一直都在，不用付费它也存在。你付费，买的是三样东西：一是往深处求知的路径，二是更快的获取速度，三是给自己设一个“损失标的”，逼自己学完，学成了钱还能退回来。

眼下AI在快速升级，经济又在往下走，我心里那个念头越来越强烈：做一个融合经验学习、知识学习和科学学习的平台，暂时叫它“创业在街边”。它不是纯商业项目，而是社会型企业，专门服务个体户、经营管理者、创业者，解决他们学经验、学技能、学技术的真实需求。

比如一个年过35的中年人，想知道开店选什么项目靠谱；一个餐饮店老板，想学怎么在抖音卖团购；一个服装店老板，想知道怎么把生意做得更好；一个足浴店老板，想把自己做成同城IP。这些都是可以坐下来好好学的东西。

这个平台的最终目标，就是实实在在降低某个区域的失业率、创业失败率和各种不稳定因子。这事值得一直做下去。
