# ('和陌生伙伴，每周六早晨的分享复盘会，让我收获价值千万', (2, 28))

刚从西藏回来一个月，人还在休整期，正好赶上年度复盘和规划的时间点。今早照常开完周例会，突然想认真聊聊这个每周六早晨的分享复盘会——它看起来跟“搞钱”没什么直接关系，但这些年我的很多变化，都跟它深深绑在一起。

可能和很多搞副业、做项目的人比起来，我做的事太“土”了，是最传统的行业。但恰恰是靠着这个早起复盘会，我开始摸索着转型互联网。按写爆文的套路，这时候该甩出具体数字来制造冲击力，可说实话，我从这个例会里得到的东西，已经没法用数字简单衡量了。时间紧的话，直接看重点标出的部分就行，其他都是闲话。

一个项目成不成，带头人太关键了。我这个人选项多，又是处女座，还自带“圣母心”，特别容易焦虑。从2022年7月开始，到现在540多天，每个周六早上，雷打不动地参加分享复盘会。哪怕做爬宠直播时凌晨两点才下播，早上六点半照样爬起来开会。今年大年初一都没停，大家线上互道早安，接着该复盘复盘、该分享分享。正是在这个过程里，我的思路慢慢变清晰，开始有了“余闲”去做真正想做的事——生活不再只剩搞钱，还多了很多意外的突破。

有意思的是，开会的这些伙伴，我现实中一个都没见过，哪怕有人就在北京，也始终是“网友”。大家是通过另一个组织认识的。这540多天里，烦躁、愤怒、无数次想放弃，都经历过。但请相信，任何一件小事，只要坚持下来，都很伟大，也很有意义，哪怕是“每天按时吃饭”这种小事。

**为什么开始？**

说白了，是当时的直觉告诉我：我需要。

我以前是个“没脑子、全靠体力挣钱”的人。虽然知道复盘重要，工作中也会复盘，但只限于赚钱相关。生活又不止搞钱，还有很多别的。对于人生规划，我一直停留在“想想”的状态，甚至只是焦虑的时候才想一下，跟“复盘”完全不沾边。所以我需要借助团队的力量，帮我把人生这事儿想明白。

**它到底带来了什么？**

搞钱就不多说了，至少我不再像以前那样瞎忙，有了更多时间去尝试新项目，先聊点基础的。

**1. 认知被彻底刷新**

从“知道”到“真正做到”，我花了至少三年。

以前我认为搞钱最重要，其他都无关紧要，后来发现自己总在处理紧急事件，根本没空判断未来的方向。

以前我认为早起会降低效率，直到坚持两周后，哪天不早起，反而一整天都又忙又乱，毫无效率。

以前我认为跟一群不相关的人开复盘会纯属浪费时间，直到翻看记录，发现我一直在肉眼可见地改变。

**2. 心理舒适度极高**

有个朋友说过一段话特有意思：心情烦闷的时候就听听别人的惨事，总有人比你更惨，对比之下自己的事就不算事了。

每次听到伙伴们分享工作中的糟心事、家庭里的烦闷，你会发现：原来大家都一样，谁也没比谁过得好多少，遇到那些问题，基本也就那么解决。

从贴近生活的具体案例里，内心得到了平衡。同时又满足了一种“窥探”心理，慢慢的我更专注自己的日子了，很少再被外界牵着鼻子走。

**3. 身体反而变好了**

有位老师讲：智商不在一个水平的人，根本构不成竞争，最后拼的都是体力。

智商是动态的，所以朋友们不用太担心，你依然有机会跟雷军等一线大佬比拼。前提是，你得先活到那时候，身体得扛得住。

我第二次创业时，仗着年轻用力过猛，在准备冲击全国市场的高峰期，面临过“继续拼还是保命”的选择。那时才真正听懂老师那句话。

很多时候开完早会，时间还早，我就下楼跑跑步，身体就是这么慢慢好起来的。

**关于早会的几个怪问题**

**为什么必须是早会？晚上或者白天不行吗？**

马云有句话：“睡前道路千万条，醒来还是走原路。”晚上夜深人静，看似适合规划，其实更适合小酌和感慨人生。感慨跟复盘关系不大，白天攒下的各种情绪会影响判断，带着情绪做的计划，大概率执行不了。就算当时激动得睡不着，一觉醒来基本忘光。

白天某个时间段更难坚持，电话、微信各种事情随时打断你。但早晨不一样——想打电话都不知道打给谁，发微信也几乎没人立刻回复。反而因为没人打扰，所有事经过一夜沉淀，心情指数最低，最适合思考和决策。定了方案之后，白天去推进就行。

**早起不了怎么办？早起一次没精神一天怎么办？**

我也不是晨型人，我超爱晚睡，觉还特别多。就算早起了，晚上照样不早睡，但中午会补个觉。

刚开始确实痛苦，坐起来要缓半小时，结果又睡着了。但90%的情况是，哪怕睡着后又醒了，也比别人早，那段时间依然清静。习惯成了自然，就好了。

**为什么要跟别人一起开？怎么开？**

我信不过自己能坚持那么久，所以一定需要伙伴的力量。现在很多训练营也是这个逻辑，就是陪伴社群，链接很弱，纯粹的弱链接。

复盘和分享时，各讲各的，不对他人的事评判。流程结束后有自由交流时间，遇到感兴趣的话题可以继续聊，偶尔也会聊聊热点。我觉得“不评判”特别重要，会让人感觉舒服。不像早期那种私董会，提问、逼问、给建议，心理不够强大真的很难消化。

这种形式更像是自己做自己的复盘分享，同时听着别人的故事，很容易找到生活里的共鸣。
