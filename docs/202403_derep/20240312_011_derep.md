# 为什么总是技术合伙人被踢出局？

合伙人被踢，为什么技术背景的总是首当其冲？

赚钱社群里隔三差五就有技术出身的朋友来诉苦：要么自己被合伙人踢了，要么身边搞技术的兄弟被踢了，然后跑来问我到底该怎么办。

其实，把创业想成婚姻就通了。关系破裂，别急着骂对方薄情，说白了就是你的价值撑不起对方的需求了。合伙人出局，根本原因同样只有一个：价值不够。

技术人谁没做过创业梦？可惜的是，很多技术人看世界的角度只有“技术”。代码写得好、产品做得稳，就觉得万事俱备。可创业这件事，技术不过是其中一块拼图。市场、销售、运营、管理、资本，每个环节都可能让一家公司翻船。只抱着技术思维往前冲，迟早要交点学费。

简单介绍一下自己：我是昊布斯，2005年入行创业，服务过多个TOP10央企，亲手搞出两家年销售额2000W的高新技术企业，也帮助超过600家企业实现业绩增长。我的主业是企业咨询，专门解决合伙、分钱、股权、薪酬、管理这些让老板头疼的事。

不管你是技术岗还是业务岗，只要正走在创业路上，或者心里萌生过创业念头，这篇内容都值得你多读几遍。读懂了，也许你就不会成为那个“被请出局的人”。
