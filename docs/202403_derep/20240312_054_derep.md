# ('大部分创业公司失败的路径', (2, 14))

创业这条路上，真正能跑到终点的团队少得可怜，大多数人的故事都是同一个剧本。

先看悲剧版是怎么写的：

1. 创始人在某个瞬间被一个问题击中，下意识觉得“把它解决掉一定很有价值”；
2. 于是找了三四位行业老手或潜在用户聊了一圈，大家反应很一致——“确实烦，太需要了”；
3. 接下来就是熬夜通宵苦干几个月，硬把一个产品造出来；
4. 上线后忙着推广、修故障、看反馈，销量总算动了那么一点；
5. 可惜增长始终温吞，离“养活团队”差着好远；
6. 最后不是钱花完了，就是耐心磨没了，只能收拾包袱离场。

再看成功的那群人是怎样操作的：

1. 同样是灵光乍现，认定某个问题值得做；
2. 同样去跟几个业内人或潜在客户验证，确认这痛点真实存在；
3. 差别从这里开始——他们只花一到两周就做出一个“能用”的版本；
4. 然后抓紧推广，把用户反馈一条条收回来，借机摸清需求本质和市场水温；
5. 刚开始那个具体场景可能同样不赚钱，但他们沿着用户反馈一路改，一步步向 PMF 靠近；
6. 把上面这套动作反复跑，迭代一轮再一轮，直到某一次恰好撞上真正的产品-市场契合点。

说到底，成功的创业者不过是在把自己的血槽耗尽之前——不管是钞票、时间还是心力——抢先找到 PMF。所以真正决定生死的是速度：快速做出，快速收集反馈，快速掉头调整。

顺便补一个小知识：PMF 就是产品-市场契合。评论区查到，刚确认的。
