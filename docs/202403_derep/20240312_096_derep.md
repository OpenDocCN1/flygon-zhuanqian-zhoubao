# 没太上心做两个月，TikTok全托管却先给我交了月入过万的答卷

先简单说说我是谁。95 后，创业这条路基本没停过，一直在电商里摸爬滚打。大学毕业后扎进深圳，先后在亚马逊、速卖通等主流跨境平台开过店，成绩中规中矩。后来竞争越来越卷，回到国内转战抖音电商，也算是吃到第一桶金。

TikTok 全托管上线已经有一段时间了，赚钱里大家讨论得挺热，但真正落地的详细复盘却很少。恰好我把它当成一个小测试项目去跑，到现在整整两个月。说实话投入精力并不算多，却已经有了月入破万的体感，今天把实操的真实感受整理出来，供大家参考。

我把更细的数据和操作步骤整理在了飞书文档里，感兴趣的可以直接看细节：[`lpt8zt3scl.feishu.cn/docx/Tvsxdt6gSoobVvxP6FwcCLB0nwd?from=from_copylink`](https://lpt8zt3scl.feishu.cn/docx/Tvsxdt6gSoobVvxP6FwcCLB0nwd?from=from_copylink)

从这段时间的跑下来，有几个点特别想强调：

关于回款，大家最关心的就是钱什么时候到账。目前的结算规则是订单完成妥投后次日就开始结算，基本是日结，资金回笼速度挺让人安心。

关于选品，有人问半成品类目为什么出单拉胯。我自己对这个赛道不太熟，但从兴趣电商的逻辑来看，新奇特、强视觉的品更容易被推爆，半成品的转化门槛会更高一些。

关于货源，有朋友问没有货能不能做。全托管模式平台会协助拿货，但备货环节还是绕不开的，自己要有库存意识。

两次转型让我越来越相信，平台红利期不是靠拼命加班抓住的，而是靠早一步试水、早一点验证。TikTok全托管对我而言，就是这样一个“没怎么费心却先出成绩”的项目。
