# 别关起门来造车，要开到车流里去

大家好，我是小七。这次航海家大会的现场摄影由我负责。当时翻了下大会相册的浏览数据，现场300多人，相册浏览量居然超过了72259次，那一瞬间真的被震住了。能得到这么多前辈的认可和喜欢，特别特别开心，谢谢大家！

这次经历让我想明白了一件事：把自我放小一点，一定要学会表达，把注意力放在解决具体问题上，别整天陷在“我是不是不够好”的内耗里。做项目没有捷径，就是反复投入、硬扛、找方法。以前的我，特别爱逃避问题，不敢正视，总想绕个弯子过去，结果被巨大的 ego 困在了原地。

说实话，我挺笨的。那次答应帮大家找照片，3000多张我一张一张地翻，好不容易快找完，网页一自动刷新，之前选好的全部归零。速度慢得离谱。在这之前，我根本不敢让别人看出我的“差”和稚嫩，不敢跟人深聊，怕问出什么傻问题，怕大佬们太忙会嫌我烦，怕被看不起、没人跟我玩，也怕没法靠近想学习的人。

第一次见涛哥就是这样。终于见到本人了，打完招呼后嘴唇动了动，却一个字都说不出来。但慢慢接触下来才发现，他是真的毫无保留地分享干货，会认真帮你拆解卡点、给指导。他让我把摄影作品发给他看，我紧张到后背冒汗，最后居然得到了肯定。再走近一点我更发现，大家都特别真诚，现场交流氛围好到爆，没有人因为我只是负责拍照的圈友就无视我。甚至有大佬主动来加我，说要帮我宣传，给我介绍业务。郭晓文老师当场问我拿二维码。那一刻真的受宠若惊。

特别感谢涛哥、陈雪姐、容姐、秀儿姐姐推荐我来负责这次航海家大会的拍摄，让我有机会跟这么多厉害的人产生链接。确认消息的那一刻，我开心到直接跳起来，提前两天就到了杭州，跑去公司对接细节，机票也立马订好，对这座城市充满期待。

把自己彻底打开，敞开心扉，然后勇敢去做。亦仁有句话我很认同：所谓“出来混”，关键不是混得怎么样，而是你得先出来。这真的是我一个普通青年最大的体会。如果不主动走出去，不去见人、不去感受、不去尝试，一直待在熟悉的旧环境里，很难有新的变化。做项目也是这样，方法重不重要？重要。但比方法更重要的，是你他喵的得先动手啊。不开始，怎么知道自己行不行？能迈出第一步，就已经赢了一半。

很多时候，新的改变都是由新的人带来的。去见具体的人，去真实地感受，去走进车流里。别人不敢开口，你先开口，赢一半；别人不敢出来，你先跑出来，又赢一半。创业者本来就是十次里九次都会遇到失败，我们走的是一条人更少、也更难走的路。选择有很多，但能让我们心甘情愿做一辈子的热爱，少之又少。愿我们都能在自己热爱的领域里，关掉噪音，坚定地走自己的路，持续发光。

人生没有白走的路，每一个看似不起眼的节点，最后都会塑造出现在的我们。赚钱这件事没有考卷，没有统一模板，也没有标准答案——就像我们这没有标准化的人生。很多东西只能一步步走，一点点试。路真的是可以被走出来的，创业者完全可以蹚出属于自己的一条道。马哥那句话没错：别关起门来造车，要开进车流里。

真的非常感谢亦仁老大创办了生财有术，让我们能聚在这里，一起成长，让创业路上不那么孤单。这里不仅有认知提升和各种搞钱项目，更重要的，是有一群并肩作战、有血有肉的同行者，是难得的心力补给站。你们想象不到，一个普通得像张白纸的大学生，第一次看到生财时的狂喜——感觉整个世界被打开了一扇巨大的门。在这里，能看见项目、信息差，提升看问题的角度，但最珍贵的是：有人陪你一起走。

婧姐说过，写文章就要写到连自己都不好意思看；想打动别人，先打动自己。我也问过自己：只是按快门拍拍照，难道21岁就要这样干到60岁吗？就像年轻的医生，该多主刀，还是多问诊？涛哥的答案是：一定多主刀。要选长期的事，虽然那像开刀一样痛，痛彻心扉，但改变之后，能受益一辈子。

学习和赚钱，道理是相通的。成绩和金钱，不是我们要拼尽一生去抓的东西，而是把整个流程跑通之后，自然会长出来的结果。婧姐那天说得特别好：别总把钱当目标，她就是钱本身，只要不断做真实的自我，足够真诚，赚钱是早晚的事。成绩也好，钱也好，都只是工具和手段，不是终点。

还有一件事，让我特别难过。我一个很好的兄弟，家里条件还不错。他爸爸中午骑电动车出门吃饭，在路口等红绿灯时，突然有个精神失常的人从背后冲过来，拿着割草的镰刀，朝后脑勺就砍了下去。万幸的是命保住了，但花了很多钱，人到现在还在病床上。这件事让我清楚意识到：生活里，我们真的不知道下一秒来的是一颗糖、一场意外，还是一段平淡、一份苦难。这些东西，跟金钱、名利、权力都没有关系。

所以，祝大家在忙着搞钱的路上，偶尔也停一停，多看看身边的人。健康、快乐、有钱、有闲，才是最好的状态。小鹅说得也很有道理：很多事现在觉得不重要，是因为我们还年轻。但生命长短不定，终有结束的一天。站在十年二十年的尺度看，挣钱一定是短期里最重要的事；可站在更长的维度看，我们最想要的是健康、快乐、选择的自由和内心的平静。

只要大方向没错，持续地坚持、保持，时间就会成为最好的朋友。时间，也是最大的壁垒。我相信，命运就是靠一个又一个向前的动作，在漫长的日子里被改写的。保持健康，保持平静，保持学习，一直待在挣钱的轨道上，长期来看，一定会赢。身体和健康，才是我们最大的本钱。

而且，很多东西真的不用等全部准备好再开始。难道非要确定了工作才去一座城市？非要租好了房子才开始做事？非要备齐了工具才肯动手？这些事当然重要，但绝不能成为行动的阻碍，也不该成为不敢开始的借口。

因为这次机会，我直接从深圳留在了杭州。各位老板如果有拍摄相关需求，请记得找小七！我是“小七定格摄影”，I see you——定格生命中的每个精彩瞬间。目前提供：手机摄影课，教你怎么用手机拍出大片，帮你对象拍出好看的照片；摄影社群，答疑解惑，教你摄影最核心的东西；还有摄影服务：个人品牌形象照，适合超级个体和创业者，需要头像和海报照片的朋友可以找我；活动会议跟拍，婚礼乔迁等庆典跟拍；纪念照，给父母长辈拍一张能代表他们故事的“人生照片 pro”；还有短视频拍摄相关服务。用有温度的镜头，去看见你。

在生财办公室和大家一起学习，我每天都干劲满满，这里的氛围实在太好了。算下来，今天刚好是我加入生财的第7个月，继续向前辈们学习。祝大家，一起生财有术！
