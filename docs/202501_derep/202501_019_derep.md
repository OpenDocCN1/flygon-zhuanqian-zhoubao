# 副业小白参加虚拟资料航海迅速跑通项目

去年国庆，我还是一名前端程序员，正忙着写代码。放假回来，却收到了一纸裁员通知。说实话，那一刻反而松了口气——因为在那之前，我已经隐约感觉到，行业里的机会正在肉眼可见地变少。

与其焦虑地继续投简历，我决定换一条路：做副业。

但副业这事，说说容易。没方向、没资源、没人带，一个人瞎摸索很容易放弃。转折点出现在我加入了龙哥盟的航海项目——特别是这次虚拟资料的航海实战，彻底改变了我的处境。手册里把整套玩法的底层逻辑讲得明明白白，再加上教练们把踩过的坑、试错后的经验都毫无保留地分享出来，我一个毫无经验的小白，竟然就这么稳稳地跑通了从 0 到 1 的第一步。

如果你想了解我是如何从零起步、如何选品、如何定价、如何做流量，我把完整的项目实操记录整理成了一份文档，放在了飞书里，点击下方链接即可阅读——希望我的经历，能给你带来一点力量和参考。

这条路我自己走了一遍，虽然也有波折，但既然我能行，相信你也一样可以。

如果你也在经历裁员降薪、对未来感到迷茫，不妨从一个小项目开始，试着为自己拼一次。
