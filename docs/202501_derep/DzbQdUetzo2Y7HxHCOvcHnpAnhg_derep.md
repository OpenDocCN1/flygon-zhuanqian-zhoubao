# ('2025年Q1微信小店带货达人闭门会', (2, 20))

2025年第一季度的微信小店带货达人闭门会，信息量不小。先说明一下，内容仅限行业交流，别拿去商用。
![](img/15e710e1eead0f11246132cb8e3ca79f.png)

先回头看看上期会议提到的问题，解决了哪些。

关于带货分，平台改了不少：商品评分在整体权重里降了，新增了品退率、带货违规评分和带货举报率三个参考维度；计算周期从90天压缩到30天。更贴心的是，带货分一旦异动，系统会精准告诉你具体是哪一单、哪一款商品惹的祸，溯源方便多了。
![](img/db3b784ee58e31e9c77dbbad4e843d0c.png)

违规加热限制这块，也做了优化。
![](img/2b827a347b436a6cd095a773f2d5621e.png)

平台券和主播券有了新调整。
![](img/65f72412f5b07e680c0299fd04bd37df.png)

客服添加流程变得更合规了，粉丝服务工具也升级了——微信小店带货助手小程序今年会加入客服助手功能，达人可以直接给下单过的粉丝发消息。
![](img/8c12b1ca0411be372478f3745e3ed1a4.png)

官方的重要信息接收渠道，以后认准“微信小店带货助手”服务号。上面可以看学习专刊、查关键词、一键呼叫带货端客服。这套服务辐射所有在微信生态里做带货变现的人，不管你是视频号、直播间、小程序、公众号、社群还是分销推客，都能用。平台现在明显在鼓励达人做全域经营。
![](img/3cacbaf7b1b643e160339bff73dc3d7e.png)

官方还放了标杆账号供大家学习。微信小店带货助手里有个成长中心，里面有赛道标杆案例、优质同行推荐和账号推荐。
![](img/746cb2048b64fa668e3724ab1e6a4211.png)

接下来是带货业务的最新进展。先说数据：从第三季度到第四季度，达人带货GMV涨了140%，分销规模增速13%。这些数据比较敏感，官方不允许拍照，所以现场没图。
![](img/e2e8a701c33092e9832d89440278bb2d.png)

平台鼓励的达人路径也在演进：2022年之前靠私域起号；22到23年靠内容、人设和信任起号，再转直播带货；24到25年走向全域经营。什么叫全域达人？就是在微信生态里，短视频、直播间、公众号、小程序、社群私域各个场域都能看到你，每一样都拿得出手，不偏科。这样的人，平台会重点扶持。
![](img/f2c944c51b09ac875eacbaebca05cb7b.png)

讲讲标杆案例。比如“谢谢你来了”，用切片加矩阵短视频，再配合订阅号图文长内容，把好话题真正做出了好内容。
![](img/ea0d11dbc22e5d74d2d6b2209bfa636b.png)

“跨国·夫妻”走剧情演绎路线，一个月能做出千万以上的成绩。
![](img/06a801dd07c637e0b674f4f5f836e91e.png)

“红粉佳人”主打心灵思考，带女装，靠信任背书，从9月开始每个月增幅都在100%以上。
![](img/aeb9d6b9e511364c78ea189bcfbb85df.png)

还有一些长期老达人，在视频号做流程展示，在公众号做图文拆解，把微信生态彻底吃透。
![](img/81cd6f0ddbc1799b29451888462d8cad.png)

不少老达人反馈流量卡住了。平台说得很直接：这么大的业务盘子，不会针对某个达人卡流量，明年会更丰富达人生态。平台要主动牵引内容，帮赛道达人出圈，请老友互相连麦、老友空降。
![](img/6e507aafee6a3d0212262dbbcbbe9291.png)

赛道达人标杆案例也安排上了。
![](img/f1400728f1d7b5e2a3dd89408d06dce5.png)

职业达人最关心的问题，一个一个聊。

推流核心指标：今年新客，也就是非粉丝用户的指标，权重很高。GPM要能打，订单要多，商品单价也不能低。
![](img/5f971c87bf3ff368ffe5299626fffcb8.png)

粉丝指标怎么提？白菜GG的做法值得参考，目标是把“暂无偏好”的未下单用户变成新客。核心四招：内容偏好、直播引流、货盘匹配、价格优势。比如福袋送贴合的农产品，低价引流品最容易拉动新客点击。下沉用户对手机、平板车价格没感觉，但你说小黄鱼菜市场卖多少、我这里给什么价，他马上就有性价比判断。
![](img/2e353f5bdfae2b08c0e4403bbf6aa220.png)

再看小韩夫妇和楠姐，主攻老客复购，靠的是粉丝粘性、选品复盘、售后服务。视频号有一个特点：粉丝一旦信任你，就会一直跟着你买。
![](img/d947757282cf44b3a600a40b59fad2a1.png)

短视频重要吗？重要。一来能拉新，二来短视频带货的转化率本身很高。
![](img/e4415f22e7bdc09b9a41301b2f49821c.png)

预约怎么做才有效？做专场没错，邀请节奏要拉密，但时间别拉太长。有洞见是：公众号图文能做预约，短视频投放也能预约，像胡小群讲数字就是这么干的。
![](img/b104c35a1a7d4109a453196f4ef10b2e.png)

同时要注意，平台现在改了推送机制：用户不打开微信，就不推直播预约，不再像以前那样不打开也强提醒。
![](img/dd3c4215843a13983676e4448660b3a0.png)

再聊曝光转化率。乡村婷婷一家人的直播间像连续剧，一家人故事慢慢展开，主播还会说“我们采纳了粉丝建议做了哪些改变”，用户有参与感，甚至能影响剧情走向。乔教主则坚持真实场景，不加滤镜。
![](img/318849c6a72766427bf6630138c455d0.png)

人均观看时长也有门道。乡村晶晶妯娌俩的做法是开播先做内容可看度，不急着卖货；品格世界朱晓平则是先回应粉丝问题，观众反响很热烈。说到底，先聊粉丝想听的、关心的，别一上来就推销。
![](img/d7c1d15c839df3666fae200edbca1c36.png)

矩阵账号能不能做？能做，但必须是垂类矩阵，而且要错开定位，做出差异化内容，不然就是自己人抢自己人。
![](img/e3f89684b12f392da8a9acc35ad4014f.png)

接下来是生态治理。

规则治理产品变动不少。微信小店交易中心服务号已经上线，违规了看不懂规则可以直接找客服，还有“以考代罚”，不合理的规则也会下线。
![](img/88987e62fdf22cb3e7e52cd686603198.png)

治理重点之一：不正当营销。官方展示了违规案例。
![](img/a3ae4c7c56c053be8530de4df54fc7bf.png)

治理重点之二：虚假宣传。同样有案例警示。
![](img/3a52c2ae13cb931ce7d4183adede7c65.png)

官方在大场高发违规上特别提醒了几个检查项：样品要和商品详情页保持一致。
![](img/a01176f0e55432e9a023421c3fd8a363.png)

禁用词一个都不能有。
![](img/0f41b8db116689f5743f8303ca01dd12.png)

抽奖必须用官方工具福袋。
![](img/63ff71a5e2d42f11fc940812d2f43172.png)

“扣1才能领福袋”这种虚假领取条件属于违规。
![](img/d429b71ca2fbafedb8643959e37beb5c.png)

直播间展示的产品和话术，不能出现未经授权的官方证书或logo，比如自称央视展播品牌就违规。
![](img/2ac0c33c518984910d1b11b92e746924.png)

加热方面，违规会导致计划不可二次加热，所以别频繁创建又取消。
![](img/aef73055290974640232315d0e5397ba.png)

再看新产品玩法。微信小店带货助手升级后，注册流程5分钟就能完成。
![](img/a61f743574ec985468fa48697f95f827.png)

达人成长中心是重点，包含优质同行和账号推荐，还有达人训练营，能为不同阶段达人定制成长计划。
![](img/6530e89b811eb098d788b1d1dfc33387.png)

政策方向也来了。达人拉新从1月1日到2月底。
![](img/5bfa04167d5435e9d162e3f7064f9884.png)

达人跃升有激励。
![](img/5c4c5964a0f6660cef42f24240a88042.png)

达人大场也有激励。
![](img/38ea0eb2f86606527e4fb1a5ad21d2bb.png)

带货者服务商机构方面，平台提供一切好工具，帮服务商和达人赚钱、分钱。
![](img/6a548bb6b36398fff9ccb91fec331969.png)

达人训练营会做线上双选会，达人、带货机构、服务商三方互选，各自展示自己的案例和成绩。
![](img/9784454433eb6fb6b9200fee2694cb89.png)

服务商常见模式有两种：从0到1孵化达人，或者签约头部、只帮成熟达人放大。
![](img/eebff4a0c073dbae5f4e7453d5e142cb.png)

在线分账功能会根据服务商等级开放不同能力，Q1重点上电商MCN在线分账，这个从去年说到现在，希望2025能落地。
![](img/08d67e15ba4c50724a12ed40637cca8a.png)

同时继续鼓励全域经营：视频号、公众号、服务号、橱窗开放生态，让达人多场景做运营变现，服务商所有功能都是为了让机构和达人更信任彼此。
![](img/6cafd07da9ba95ef5779cfe7302e0c60.png)

最后是吐槽会。账号被仿冒、被盗播卖货，一方面及时举报反馈，另一方面优质达人可建直播人脸库，非本人账号开播会被掐断，功能开发中。
![](img/b80f9f3257f0d1bdde0a9a9dedbb0081.png)

直播间福袋有异常用户？黑灰产薅福袋基本集中在同一地区，提交订单号给客服，技术会排查拉黑。
![](img/a7619de23d7c4f13ffdfe6c9849eb9ed.png)

福袋发放问题也在处理中。
![](img/f1b087a81d0fff7bce78089e2ef4824d.png)

微信小店客服问题：违规处理客服入口已上线，人工客服早10点到凌晨2点在线，解决不了会升级工单给总部团队，超过48小时可再次反馈。企微客服只能推名片，没有二维码。
![](img/bac2ddc5137dcb1872238ecb5876e8bc.png)

大场要提前报备，机制春节后上线。
![](img/3d4a7737227b844c2190644ac88d3480.png)

账号数据管理体系会把各端数据汇到微信小店带货助手，并做权限隔离，明年推进。
![](img/b034babf6a73beb24e4a57d4445c6e4c.png)

老账号开播不通知粉丝，平台听到了。
![](img/bf86c1b930d9f93c62a909eb24ff746c.png)

平台解释：短视频和直播不区别新老用户，关注栏刷不到是因为千人千面，不推送就是最近用户不怎么看。
![](img/008dfd03f5ef54911c2762fd012fe0cd.png)

服务商与达人解绑，反馈想要冷静期，平台说明年给3到5天挽留期。
![](img/a0cd813a5c9d7c88d3cfa9170d132122.png)

硬广问题要重点说：做大场预告，整条视频全是“我有优惠、我送东西”，吸来的都是羊毛党，对长期经营不健康。硬广明确不允许，展示产品时长不超30秒，要软性有可看性，比如卖珍珠项链，要挖故事而不是直接硬推。
![](img/b683a261b0e1a7edc604279501f6be70.png)

改规则能不能提前通知？平台会提前在规则中心公告，7天反馈期加7天公示期，明年还有柔性治理（以考代罚），多关注微信小店交易规则中心。
![](img/29803e26dfa778ea738a076ce04dbd1a.png)

更多问题，官方说了，一个一个解决。
