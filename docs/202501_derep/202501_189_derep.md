# 用 Cursor 把付费混剪软件干掉，我自己写了一个自动混剪工具

> 原文：[`www.yuque.com/for_lazy/zhoubao/mumagkq21oir4mlo`](https://www.yuque.com/for_lazy/zhoubao/mumagkq21oir4mlo)

大家好，我是 Burning，杭州新青年夜校的负责人。

今天分享一个我自己搭出来的短视频批量生产工具，初衷很简单，就是为了把我们夜校的短视频做得更快、更省钱。以下案例都是以夜校视频为例，但我的混剪思路其实是从生财里那些风景口播视频的批量剪辑方法里学来的，大家可以根据自己的情况判断能不能用，欢迎评论区聊聊优化点。

我们夜校的短视频套路是固定的：大概每 3 秒就切一个课程画面，底下配口播音频，再加上标题字幕。走一遍完整的批量流程，大致有四步：

1. 先把所有素材的分辨率和规格统一
2. 把长视频按 3~5 秒的长度切成片段
3. 依据配音时长，随机挑片段来拼接
4. 最后丢进剪映模板里一键批量导出

这四步以前我全靠现成软件在跑，其中第 3 步和第 4 步还是要订阅付费版。最让人难受的是第三步，看起来功能很基础，结果每月 69 块的软件只能把所有切片堆在一个文件夹里乱混，导致同一个课程片段可能在同一条视频里出现两次，而且生成速度慢得离谱。

所以我就用 Cursor 自己撸了一个简易版，大概花了一天。核心改动是：给每一类课程切片单独建一个文件夹，然后在生成时根据音频长度，从对应文件夹里随机抽取片段进行匹配。现在已经打包好了 Windows 版本，可以直接用。

说实话，我上学时学过一点编程，但搁置多年早忘光了。Cursor 的体验非常顺滑，根本不用去记各种语法细节，调试全靠对话就能搞定。前两三天我都上头了，比打游戏还上瘾。关于怎么用 Cursor 做开发的一些心得和用法，我整理在了飞书文档里：
