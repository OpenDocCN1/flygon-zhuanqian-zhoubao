# 星主副业剪彩文字稿

当很多人感叹创业越来越难时，有人却选择在逆风里租下整层办公室。龙哥盟乔迁剪彩当天，龙哥说了三句话，句句值得回味。

他说自己很幸运，第一次创业就把公司做了八年，而且还在变得更好。为什么能走到今天？他讲了一个亚马逊的习惯：每次开会，现场都会放一把空椅子，坐在上面的是“用户”。龙哥盟的墙上贴着5000位圈友，背后还有星球里更多一路同行的伙伴。没有他们的信任和支持，这家公司走不到第八年。

他特意感谢了生命中的贵人。创业早期，遇到难关时，是冯老师、曹政老师等嘉宾默默出手；有些话不能跟圈友讲，也不能跟同事讲，只能找大黄这样的朋友聊聊，聊完心里就松了。在最一无所有的时候有人选择他，在创业最难的时候有人信任他，这份支持让他扛过了许多想放弃的时刻。

他也要感谢自己。这么多年，一直没放下那个念头——帮助像他一样的普通人。中途不是没动摇过，但咬咬牙，还是撑了下来。

公司叫“索益”，代表着他看重的信念和价值观。他借乔布斯的话说，即使做到第八年，赚钱依然在不断推翻自己。张一鸣有句话叫“Always Day One”，内容推翻过，航海推翻过，连线下活动的方案上午还在重新讨论。这种永不止步的折腾，正是这家公司的底色——永远朝使命靠近，永远朝愿景靠近。使命很简单：陪更多年轻人找到自己热爱的事业。

有人问他，为什么大环境不好还要逆势扩张？他说这不算扩张，是一次重要的探索。花成本拿下一整层办公室，是想传递一种乐观：悲观只是情绪，乐观是行动。带着更多人积极往前走，才是他真正想做的事。

接下来的一年，赚钱会做很多尝试：把航海做得更深、更透、更细，让不同圈友真正躬身入局，把手弄脏，在实践里赚到钱。团队和圈友都会得到支持，目标是帮助他们成长起来，成为创业者，成为赚钱的超级案例。

对于未来，他有三个期待。三到五年内，龙哥盟要成为全球最权威的情报分享平台，一天之内涌现上万条赚钱机会，让机会不再稀缺。赚钱也要走向全球化，成为全球最被信任的创业者社群，用心陪伴和赋能更多创业者。最后，他希望能真正帮助十万人开启副业、开启自己的事业，获得实实在在的成长。

希望有一天，所有圈友、同事和伙伴，都有底气说出：赚钱的机会，就在我们这里。
