# 不会代码，不会设计，如何用 Coze 开发一个 AI 应用发布到微信小程序？从 0 到 1 的完整实操教程

零编程、零设计基础，也能把 Coze 上的 AI 应用直接搬到微信小程序里？我亲身试了一遍，真不到门槛。

以前我在 Coze 上搭了不少工作流和智能体，但每次要使用都得乖乖打开网页登录，总觉得差了点意思。心里一直琢磨：要是能做成微信小程序平时随时点开用，该多方便。可我对微信小程序开发完全是个外行，光研究页面布局就能劝退我，所以这事一拖再拖。

最近 Coze 更新了一个让我眼前一亮的功能——可以创建应用并直接发布到微信小程序了。虽然目前这个功能还不算特别成熟，但我自己上手试了试，不得不说，后劲真大。

最关键的是，像我这种从来没碰过小程序开发的“小白”，居然也能靠简单的拖拽操作，就搭出一个自己想要的应用，几乎不用再为页面花费大量时间，这种掌控感太治愈了。

如果你也有自己的想法，但一直卡在“不会搞开发”这一步，那现在正是趁热打铁的时候。这篇教程会带你从零开始，一步步把微信小程序做出来。内容相当扎实，估计一口气做不完，建议先收藏，再慢慢跟着动手。
