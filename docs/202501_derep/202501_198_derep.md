# 传术师见面会复盘｜AI怎么学、赚钱思维怎么练、人脉怎么链接，这一趟杭州没白跑

去杭州之前，我以为这只是一次普通的圈友聚会。直到参加完传术师见面会回到成都，脑子里还在不断回放那些观点——这场活动带来的信息密度，远远超出了我最初的预期。

先做个简单的自我介绍：我是绿子，常驻成都。这篇复盘想从AI应用与学习、商业认知、人脉链接、自我成长几个侧面，把我这次收获最大的内容整理出来。如果你没能到现场，希望这篇文章能带给你一些可落地的启发。

在AI的应用和学习上，现场一个很务实的观点是：别把AI当成聊天玩具，而是把它嵌进自己每天的工作流里，让它真正替自己处理重复劳动。这和坚持阅读是同一套逻辑——真正的学习从来不靠一时热血，而是持续的输入和迭代。

说到赚钱思维和商业判断，最戳中我的一个提醒是：不要被短期的热闹牵着走，试着建立自己的分析框架。每次做决定前多问一句——这件事放到三年后，还重要吗？这个视角一下就让很多焦虑变小了。关于怎么判断别人给的反馈是否值得听，更有效的方式是区分信息背后的动机和事实依据，再对照自己的实际处境做筛选。而一个人稳固的底气，往往不是靠外界的掌声堆出来的，而是源于一次次的自我确认：承诺自己做的事，就一定能做到。

在项目实操层面，如何筛选一个好项目？现场嘉宾反复强调的核心是“真实需求”四个字，找到需求和自己优势的交叉点，才有可能做出持续复利的事。万一遭遇公关危机，大家给出的策略也十分一致：第一时间出面，坦诚面对核心矛盾，用行动重建信任，而不是想办法遮掩。

链接优秀的人这件事，我也有新的触动。真正高质量的关系，往往是从主动分享开始的。当你愿意真诚地展示自己，许多机会和“信息差”会在对话中被自然拉平。现场提到的“建联四步法”，把人与人从最初接触到长期协作要走的路讲得很透彻，具体的操作细节我已经同步放在文档里了。

针对00后朋友，嘉宾们给的建议也很实在：职业生涯的头五年，别把短期收入看得太重，多把精力花在可迁移的能力、个人信用和对行业的深度理解上，这些都是未来真正的杠杆。
