# 京享红包项目实战指南

最近，老秦分享了一个叫“玩赚京享红包”的实战项目，看起来挺轻量，但收益却很能打。简单说，这不是让你去领个红包自嗨，而是靠推广京东官方发放的京享红包来赚佣金。下面我把这份SOP整理成一篇易上手的实操指南，想快速跑通的直接看后半部分的“实操链路”。

先划几个重点：
- 京享红包是京东官方优惠券，完全不是第三方平台的东西，可以放心玩。
- 后面提到的“京粉”和“京东联盟”都是京东自家的营销工具，一个主打APP端，一个主打PC端，都不是外来平台。比较推荐大家用“京粉”。
- 核心目标不是自己领红包，而是把专属链接发出去，有人通过你的链接领红包并在期限内下单，你就能获得佣金。
- 想立刻动手，直接跳转到“生成专属红包链接”部分即可。
- 注意：咱们推广的是红包，不是具体商品，也没有层级关系。

整个项目的底层逻辑其实很清晰：把你的专属京享红包链接发出去，用户一旦点击领取，就和你的推广关系绑定了。接下来只要他在有效期内用红包在京东买实物商品，你就能分到佣金。相比直接推商品，红包因为有锁单机制，出单容易不少。

关于京享红包本身，有几个关键点值得记住：
- 它是京东发的优惠券，能在购物时直接抵现。
- 无门槛、全品类、可叠加，而且使用优先级很高。
- 所有京东实物商品都能用，和其他优惠券、京豆等也可以同时用。
- 佣金不是固定的：有的订单只有1分钱，有的能到几十甚至几百块，上限相当惊人。
- 收益统一在京粉APP里查看，下载方式后面会说。

![](img/e009efc3e90f0d37ff14f6ecb4fcc9f6.png)
![](img/f974072cbee0e7b291b285e648bcf277.png)

那它跟普通红包/优惠券有什么不一样？京享红包是直接抵扣现金的，而且只在大促期间发放，能和东券、京券、京豆等任意优惠叠加。最关键的是，只有京东联盟的京享红包才具备跟单能力，京东平台上其他活动发的普通红包是跟不了单的，所以推广佣金自然也无从谈起。

它的发放时间不是天天有，主要集中在这几个节点：
- 京东618
- 京东双11
- 京东年货节

关于提现，流程也比较简单，但要注意中间要经过京东钱包。

第一步：实名认证
- 打开京粉APP，底部菜单栏点“佣金”
- 点“前往实名”
- 按要求填好实名信息

![](img/9c2006144e08036763b3fc5deb98fd5b.png)
![](img/24fc7b49fc03993aa5339803bcb5e5fb.png)
![](img/7f25bf16231e88d3eae9890183c66571.png)

钱会先到京东钱包，如果想转入银行卡，还要在京东APP里再操作一次。

第二步：提现到京东APP的“我的钱包”
- 京粉APP底部“佣金”→“提现”
- 输入手机验证码，确认后钱会到京东钱包
- 打开京东APP，找到“我的钱包”

![](img/17c4cae1735b9154402fa2aeb899b10d.png)

第三步：提现到银行卡
- 打开京东APP并登录，注意登录手机号必须和京粉账号一致
- 底部“我的”→“我的钱包”→“余额”
- 绑定银行卡，然后选择“提现”

![](img/a04f1b9c6dcdcaa27e9f997aed45af5a.png)

接下来是最重要的部分：生成自己的专属红包链接。

总的核心步骤只有三步：
1. 下载京东官方推广平台
2. 注册登录
3. 生成专属京享红包链接

APP端和PC端都能生成，但老秦强烈推荐用APP端，因为操作起来最省事。

APP端生成链接的实操流程如下：
1. 下载“京粉”APP

![](img/a5635a740ea998fc30b04e76687d1381.png)

2. 注册登录。建议选“京东登录”，如果还没装京东APP，先装一个并登录；当然用手机号注册也行。

3. 点首页的“焦点图”，进入“京享红包”活动页，再点活动页右上角的“分享赚”，就能生成自己的专属链接和推广文案。

接下来是大家最关心的推广玩法。

朋友圈推广：直接发文案+链接，老秦亲测效果很不错。他自己用的文案很简单，还给出了好几个参考模板，比如“京东红包来袭”“省钱秘籍”“京东福利大放送”“京享红包购物无忧”“别错过”之类的风格，海报放正文，链接放评论区。

知乎好物推广：简单说就是在知乎回答或文章里插入红包卡片，读者点击领了红包，你就能拿佣金。不过开通好物推荐有条件：创作者等级≥5级，账号注册满90天，过去90天没有违反知乎社群管理规定，而且仅限个人账号。

开通权限后，插入京享红包的方法：
1. 在知乎APP里点内容编辑框的“钱袋子”（收益）标志，进入好物推荐选品页。
2. 在选品页选“红包”，找到要添加的京享红包。
3. 点“添加”，把红包卡片插进内容里。

另外别忘了，活动期间每天可以自领红包，一天三次。方式一：用自己生成的专属链接或海报扫码领，自己买也有佣金；方式二：打开京东APP，搜索框输入“京享红包”，直接领三次。

最后把常见问题也过一遍：
- 订单佣金是多少？不固定，有的只有0.01元，有的几十上百元。
- 有没有像淘客那样的初/中/高级？没有，不分等级。
- 必须绑定京东账号才能用吗？对，要用京粉并选京东登录，因为佣金提现到京东钱包。
- APP端怎么生成推广？看上面第五部分（生成专属红包链接的实操）。
- 为什么用了京享红包却没跟单？如果商家设置了推广计划，点击跟单有效期为30天；其他情况只有12小时。领取红包到下单间隔超过12小时，就不会跟单，但红包本身还能用。
- 用户先点了我的常规链接，但付款时用了别人发的京享红包，算谁的？算红包发放者的。因为京享红包、优惠券、京东超市卡的跟单优先级高于常规推广，只有京东支付券没有跟单能力。
- 为什么不选淘宝天猫红包？因为京享红包操作更丝滑，淘宝要复制口令多一步，而且很多人对淘客带货有抵触，大概率不点。
- 有没有高佣金的单子？有，群里很多朋友都出过高佣单，老秦自己就出了一单150+的佣金。

![](img/3613a0e4bfaa5d2e62ba55db5db36868.png)

- 无门槛红包能叠加吗？在有效期内可以。
- 提现必须绑银行卡吗？要的，完善个人信息、绑卡后，先提现到京东钱包，再提现到银行卡。
- 预售商品尾款用京享红包，会改变跟单结果吗？不会。预售以付定金时的跟单结果为准，而且定金支付时不能使用京享红包。
- 用户裂变分享怎么算？推广者甲推广京享红包，用户领了再裂变给别人，别人通过裂变链接领取后下单，佣金照样归甲。
