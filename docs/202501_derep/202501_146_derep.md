# 6000 字帮你做好公众号 IP 选题问题

公众号IP到底该怎么选题？这可能是不少创作者心里一直没解开的结。

有意思的是，公众号航海这艘船已经航行了两年，算得上项目里存活最久的一个。我在船上待了七期，一期领队、六期教练，但不管是航海手册还是高手的领航分享，几乎都没把“选题”这件事系统讲透。

这一期航海主题是IP，选题的权重瞬间就不一样了。普通爆文和IP爆文的本质区别在哪？普通爆文的账号更像消耗品，掉出流量池，注销重来成本很低；可IP爆文不一样，你辛辛苦苦立起来的人设、讲过的故事、攒下的关注，一旦因为选题失误被踢出池子，这些积累就面临碎裂的风险。

所以，做IP爆文必须有“选定一条道走到底”的心态。我也不反对“先完成再完美”，只要你出池后还能持续更新，那当然没问题。但更聪明的做法是，在项目启动、按下发布键之前，就把选题重视起来，一次做扎实，免得以后反复做无用功。

这篇内容会从九个层面，帮你拆解公众号IP的选题方法。可以说，选题上花的时间越多，后面走的冤枉路就越少。特别是做公众号爆文IP项目的人，请一定把选题当回事。
