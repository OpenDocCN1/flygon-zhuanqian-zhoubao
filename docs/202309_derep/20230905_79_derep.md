# ('创业者一定要敢于“千军万马”，用大团队做大想象', (2, 25))

很多创业者习惯了一个人埋头苦干，总觉得团队小才好管理，人少才更灵活。但真正想干一番大事，恰恰要敢于拉一支“千军万马”般的队伍，用大团队去承载大想象。

一个人能看到的边界有限，一群人才能把视野推到更远的地方。当你敢于把摊子铺开，把各路高手请进来，你的想象力就不再是脑子里的空想，而是落地成真的一系列动作。怕的不是人多，而是你根本没有“指挥千军万马”的气魄。

创业这条路，从来不是比谁更孤独，而是比谁更能聚人、用人、成就人。把小项目做精固然没错，但如果你的目标足够大，就别让“小打小闹”的思维锁住自己的手脚。敢不敢让团队变大，本质上就是你敢不敢让梦想变大。![](img/118b1c6eb8314e9fdf74d0b9a01c80ae.png)

真正厉害的创业者，从来不只是自己冲在前面，而是带着一群人往同一个方向狂奔。要明白，你的想象边界，往往就是你的团队边界。想要做出行业级乃至世界级的事，就得先有“千军万马”随你出征的胸怀与魄力。

记住，不敢用大团队的人，撑不起大局面；不敢做大想象的人，走不进大未来。![](img/1c37d505930596d12a88ab23e11aa07a.png)
