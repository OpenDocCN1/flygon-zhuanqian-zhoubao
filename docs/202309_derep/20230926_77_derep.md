# ('真正正确的投资方法只有一种，和资金量没关系', (2, 23))

很多人都有一种错觉：钱少的时候，应该用一种“小资金玩法”；钱多了以后，再切换成“大资金策略”。但真相是，真正正确的投资方式，从头到尾只有一个版本，跟你账户里有多少钱没有半点关系。

这一点，段永平早就看明白了。他讲得很直接：真正正确的投资方法只有一种，和资金量无关。

如果你现在手里能用来投资的钱还很少，那唯一要紧的事，就是好好攒钱，把第一笔像样的本金攒出来。但这绝不意味着，本金少就能理直气壮地换一套“歪门邪道”去操作。

错的不会因为资金小就变成对的。盲目赌风口、追热点、频繁短线，这些动作并不会因为你本金少就变得合理，反而容易让你更快亏光。

所以，别把“资金量小”当成走弯路的借口。方法只有一套，先承认它，然后老实积累本金，才是真正该走的路。
