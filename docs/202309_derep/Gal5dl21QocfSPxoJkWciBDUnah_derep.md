# ('使用体验和训练语料包下载链接副本', (2, 18))

最近在折腾 ChatPan 的时候，攒了不少真实感受，也踩了一些坑，写出来给同样在玩的朋友们参考一下。整体来说，体验是值得肯定的，但有些细节确实需要自己摸索。

先说遇到的问题。第一个就是对话记录没法删除，这让我有点纠结——如果不支持清空会话，那是不是意味着一个账号最多只能做九次训练？希望官方后续能加个管理入口。

再一个，训练的时候要注意时序：必须先上传好语料，再开始对话。因为一旦对话已经启动，再往里面加新的资料，它基本是接收不到的，至少我试了不行。

关于喂语料的方式，我也试了几种。那种问答型的表格格式，说实话我没太搞明白，填了问题和答案进去，它识别不了。反而用 docx 文档，只要内容写成百科或叙述性的说明，它就能理解得比较清楚。

还有就是语料本身一定要严谨。比如你想让它知道“赚钱有术”的星主是谁，如果照抄龙哥的自述“我是赚钱有术创始人和星主”，但文档里又出现了别人（比如鱼丸），AI 就会困惑“我”到底指谁。所以最好写成“龙哥是赚钱有术创始人”，用明确的名字而不是人称代词。

这让我想到写代码时反复给同一个变量赋值——第一次 a=1，第二次 a=2，最后问 a 是多少，它肯定回答 2。ChatPan 也有类似的感觉，所以语料里别出现前后矛盾的定义，信息越清晰，回答越准确。

总的来说，它的工作机制很像让 AI 做阅读理解，你给的语料就是它的参考材料，材料质量决定答案质量。
