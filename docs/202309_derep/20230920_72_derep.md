# ('学会这招“顶级复盘”，你的成功将事半功倍', (2, 22))

为什么你明明拼尽全力，却总觉得进步缓慢？有些人把日子过成了单曲循环，有些人却能不断跃迁升级。差距不在努力程度，在于有没有做复盘。

真正顶级的复盘，并不是简单回想，而是用结果倒推差距，再让差距牵出方法，最后把方法沉淀成可复用的经验。最近看到一支特别值得分享的视频，来自龙哥的收藏夹，专门把“顶级复盘”讲得很透。看完你会感叹：复盘不是对过去的交代，而是给未来装上了探测雷达。

掌握了这套心法后，同样的付出，回报会被成倍放大。建议先收藏，再慢慢消化，真的能让你少走很多弯路。
