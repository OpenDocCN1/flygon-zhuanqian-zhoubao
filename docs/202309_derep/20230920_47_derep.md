# 小红书起号首单落地笔记

> 原文：[`www.yuque.com/for_lazy/thfiu8/gvnsuuu4u7zadq6z`](https://www.yuque.com/for_lazy/thfiu8/gvnsuuu4u7zadq6z)

嗨，我是书豪，现在在小红书店铺航海担任带教，95 后，做了四年连续百万年收入。公众号矩阵是我第一桶金，抖音个护家清类目做过千万元GMV，今年在小红书开了30个店铺，合计利润约90万。

一、心态搭建

带队期间发现不少伙伴对小红书很感兴趣，却因没有经验、目标不清，半途而废。

项目要成，得抓住两点：

**1、预期校准，先定一元目标**

我常说，航海期别把期待拉太高，先赚一块钱即可。

不管是小红书店铺、公众号流量主还是视频号带货，新事物的开头，最决定坚持度的就是预期管理。

带着高预期入局，基本就输了心态。赚到第一万元看起来很近，但只有先拿到第一块钱，完成从0到1，1块钱的正向反馈会让你真切相信自己有能力做到。心态稳了，往第一万冲的信心才会扎实。

目标越小越容易上车，动力才更足。心态松了，胜率自然提升。

**2、把持续做成打卡**

第二点是延续性。打卡不是为了退回押金，是为了把选品、找上家、上架、发笔记、测款、出单、发货、售后、放大爆款这些具体动作跑通闭环。

每天自检：航海手册研读了吗？优秀学员日志复盘了吗？群里的信息同步了吗？他人踩坑我能否规避？

一点点堆叠运营小红书的能力。兄弟们，笔记不持续发，出单无从谈起。纸上得来终觉浅，绝知此事要躬行。

二、操作总线

心态成型后，来看新手跑通店铺的五步闭环：

第一步：选品
第二步：商品上架
第三步：素材制作
第四步：笔记发布
第五步：对接供货

**第一步：选品，成败关键**

两条路径：

路径一：人工跟品。直接刷发现页，按三条跟品原则筛选：
1、号粉量≤200
2、最近七天单条带货笔记点赞≥100
3、该笔记关联商品销量＞100
刷到符合的就点赞收藏，系统会越推越多。

路径二：数据工具灰豚。进入笔记查找-笔记搜索，勾选低粉爆文&带货笔记，时间框定近七天。
![](img/f513dc12d67c8d39b7fe1039a29e49a7.png)

也可以用关键词快速定位，如搜“搓澡神器”，直接锁定一批低粉对标账号。

新手选品别想太多，别带着成见。数据比直觉可靠，市场自会投票，爆品就是大众真实需求的体现。

**第二步：商品上架**

上架用蚂蚁搬家插件，照流程走一遍即可上手。
![](img/892b95f4d8b26b26b70ca0dcc1e65e85.png)

**第三步：素材制作**

要会混剪。给一个单品批量备10~15条视频。素材可在小红书站内扒爆款，再去抖音快手找同品爆款素材，混剪成自己的。

细化技巧在案例部分展开。

**第四步：笔记发布**

节奏拉满。每40-60分钟发一条，单号单日至少发10条测款。单品一般2-3天测完，不行就迅速换下一个。

**第五步：对接供货**

出单后再找货，首选淘宝和1688。拼多多目前对无货源商家不太友好。

找法：
1、下载主图，以图搜淘宝/1688
2、用至尊宝全网比价

筛选标准：
1、价格取中位，避开最高和最低
2、店铺品类垂直，主图清晰优先
3、销量<50且评价少或刷单评价的避开
4、销量>100、有真实评价、客服响应快的优先

这五步就是我带团队和教堂妹的标准SOP，新人照做即可。

三、案例拆解

用【小白鞋清洁膏】演示一遍。

通过灰豚和低粉爆款法都能筛到。接下来拆【解忧丑精灵】的爆款。

![](img/fae66c839511d8af70116c04590d173f.png)

1、标题
爆款标题：！！太太太太太太太牛🐂了！擦不干净算我输！?
标题不必原创，直接借鉴。

2、封面
封面文案：干洗店不会告诉你的秘密
抄袭手法：加贴纸、调滤镜、改对比度，伪原创即成。

3、视频脚本
“看看啊看看啊，这是卖家秀，哇，我买咯。再好的洗涤剂，它也是洗不干净的。包括这种泡沫清洗剂……”

音频可直接复用。

制作思路：
第一步，下载原爆款视频；
第二步，保留音频，画面去抖音搜“小白鞋清洁膏”找爆款做混剪。

两点核心技巧：
1、定品后至少测≥12条笔记，把对手最火的脚本混剪4条。
2、多模板组合测试：多找几个爆款的封面+标题，做三组不同封面标题组合去跑。

解忧丑精灵账号靠多组封面标题测试，最后一条冲到2945单。别测三五条就放弃，也许第十条才爆发。小红书长尾流量很强。

![](img/43a1020c9b817f5fd6edf97824f8dda2.png)
货源也很简单，保存主图去1688以图搜，即可看到进货价。想比价就用至尊宝全网搜。

四、操作注意点

1、无货源还能做吗？
可以做，估计还有半年窗口期。操作上避开从拼多多下单发货，减少面单和短信风险。

2、能不能用抖音混剪那套？
目前依然有效。选品在小红书找，素材在抖音找的打法仍可跑，建议选小红书跟的人少的品去混剪。

3、内容创作
新手别盲目创新。别人的脚本是市场验证过的。爆款结构固定：前三秒给痛点或猎奇，中间展示前后对比效果，最后引导购买。这套公式很稳。

4、常见违规
最常见是搬运痕迹重。混剪要做深度处理，图片也要二次创作。用淘宝买家秀的图视频可提升原创度。
