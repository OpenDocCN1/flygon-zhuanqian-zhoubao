# 女儿的路，我用十年试错才走出来：从一毕业就换工作，到做自由职业年入六位数

大家好，我是舟小刀，90后，两个龙凤宝宝的妈妈。今天想把我这十几年跌跌撞撞的工作史摊开来说说。从一个换工作像换衣服的职场新人，到现在靠自己做自由职业稳定拿到六位数年收入。这条路并不光鲜，但如果你也曾迷茫、卡住，或是担心生完孩子就再也回不去职场，也许我的经历能给你一点参考。

01
我的人生剧本很标准：好好读书、上大学、找份安稳工作。只是叛逆来得晚，高中时就开始摆烂，从重点班一路滑到普通班，高考砸了。好在过了三本线，可家里在小镇，三本学费太贵，最后我爸拍板让我去医学院读大专检验。我没别的专业想学，也只想先离开家再说。

结果换专业也没逃出医学圈。大学基本就是放养状态，上课发呆，想着下课去哪玩，考试前临时抱佛脚。实习一年学到的东西，比三年在校还多。那时候我就觉得，很多同学毕业也不干本专业，我也可以找自己喜欢的。

毕业后靠实习老师介绍，我进了县城妇幼保健院。白天忙的时候一刻不停，空闲的下午我就拿着小本子画画。被同事一句“你画得真好”点醒后，我脑子里只有一个念头：我要去学画画，离开这眼就能看到头的生活。说走就走，先斩后奏把工作辞了，跑去杭州学画。

02
那会儿国产动漫还没现在火。学完才发现，没有3D建模很难进好公司。老师说要继续深造得交钱，我的积蓄已经见底。于是我换了个思路，先赚钱再说。听说房产销售收入高还包住，我就去了上海陆家嘴的房产公司。没人带，每天早九晚九跑盘，刚毕业嘴笨，带客户看房都不知道怎么开口。不到一个月我就撑不住了，组长拼命挽留，我还是头也不回地走了。

之后我跟发小一起开始了穷游。广西的高速上搭过顺风车，西双版纳景区卖过照片，长沙文具店打过工，广东夜市摆过地摊。日子很自由，也很不稳定。回来后我在本地动漫园画儿童动画，工资不高但清闲。朋友在上海的医疗公司做客服，说可以远程办公。我心动了，觉得这就是自由。结果到岗才发现，除了地点能选，其他和坐班没区别。

攒了点钱，我和朋友一拍脑袋租了间小店卖衣服，连客流调研都没做就开业了。几个月后关门大吉。再次回归找工作，学历一般、履历全是跳槽，选项不多，最后又回到了销售。后来我对出国相关话题感兴趣，进了一家移民公司。算是我打工经历里最舒服的一段，老板平易近人，办公室氛围轻松，还能身兼培训、招聘等多个角色，待久了同事都成了朋友。

03
真正被按下暂停键的是结婚生子。我成了全职妈妈，特别是头一年，两个孩子要24小时看护，半夜轮流哭闹、吐奶、发烧，累到崩溃。白天看着手机里的招聘信息，我满脑子都是：等孩子大了，还有公司要一个年轻时到处跳槽、生完娃又断档好几年的宝妈吗？那种无力感很真实。

孩子一岁半时，我先回到了夜班客服，一天上一天休。利用上班的空档，我试过副业。看到写文章能赚钱，我就去系统学了自媒体写作。粉丝不到100的时候，知乎接了几篇稿，赚了两千块。虽然不多，但证明了我还能靠自己产生收入。

写作这条路我很快判断不现实，短期内很难成体系。转而我盯上了闲鱼带货。朋友早年靠电商在老家买了房，这让我相信电商能短期见效、长期可做。我给自己定的目标很小：第一个月赚一千，后面每个月稳定进步。

闲鱼就是碎片时间堆出来的，半夜都在回私信。第三个月我做到了月入过万，于是辞掉了客服，彻底All in自由职业。

这次我学乖了，不再三天打鱼。做垂直账号也做杂货铺号，多号一起运营。运气好碰上扫地机爆发期，跟了一个有官方授权的同行做小红书引流。有一篇笔记带来100个精准咨询，成交30多单，那天净利接近两万，而且是引导到官方旗舰店下单，无需垫资。后来还参与了代下单差价，靠内部优惠额度和活动差价，单品就赚了一万多。那段时间像捡钱，每天睡很少，手机震个不停。但也让我明白，选品决定一切，好的产品配上合适的打法，月入过万不是玄学。

04
回头看，前二十几年最大的问题是阅读量不够、思考不深，做事三分钟热度，总想着找捷径偷懒。我清楚自己不要什么，却很模糊自己真正想要什么。人说一生有七次改变命运的机会，我大概已经错过了好几回。认知决定收入，这话一点都不假。

现在我想把视野拉长，给自己做五年、甚至十年的职业规划。每天踏实把当下做好，因为未来就是由无数个今天堆起来的。

焦虑和痛苦确实把我逼得成长更快，这两年积累的经验超过之前浑浑噩噩的十年。但如果能重来，我希望自己能早点清醒。时间对每个人都公平，年轻时少一点弯路，就能多一点笃定。

如果你也处在迷茫期，希望我的这段经历能让你少走一点冤枉路。喜欢就点个赞，让我知道这篇文章真的有人需要。
