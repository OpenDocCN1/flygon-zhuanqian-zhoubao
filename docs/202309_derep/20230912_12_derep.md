# ('【赚钱心态】4 篇', (2, 11))

真正拉开人与人财富差距的，从来不是技巧，而是心态。

最近在知识库刷到一个系列，叫“赚钱心态”，一共4篇。每一篇都不长，但读下来有几个点特别戳人，我把它浓缩成4句话，分享给想赚钱又总是卡住的你。

第一句：你觉得自己配不上，钱自然会绕开你。很多人嘴上想搞钱，心里却全是“我不行”“我运气不好”。这种匮乏感把自己牢牢锁死。记住，敢想，才敢成。

第二句：慢，就是快。总盯着三两天翻倍的快钱，反而容易被收割。真正的赚钱心态，是愿意做难而正确的事，把时间当朋友，等复利开花。

第三句：钱是怎么来的？是帮别人解决问题后换来的回报。别再只想着“我要什么”，多想想“我能给什么”。价值给到了，收益是顺带的结果。

第四句：亏损和失败不值得怕，怕的是心态崩。高手不会一亏就怨天怨地，而是把每一次受挫都当成交学费，然后迭代自己。

这4篇赚钱心态，表面在讲赚钱，内核在修认知。心态正了，动作才不会变形。如果你也在瓶颈期，不妨对照这4句话，看看自己卡在第几层。心对了，财自然就来了。
