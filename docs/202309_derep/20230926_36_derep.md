# 30家店、90万利润，我的选品避坑复盘

我是书豪，坐标杭州，龙哥盟龙珠圈友，连续四年的年收入都在七位数以上。现在我在小红书上经营着30家店，累计利润做到90万。

今年8月，我有幸担任一场面向平台商家的航海活动教练，带的是接近2000人的队伍。在活动期间，阿蓝老师邀请我做了一次图文分享，主题正是我这30家店的选品经历与踩坑总结。

![](img/58fb71136db51015920249e77c13e125.png)

做这个平台的电商大概8个月，我们走得远没有想象中顺利，岔路没少走。如果能回到红利刚刚起来的时候，我会更早、更坚定地把重心放在“百货+个护家清”这个方向上。

我们早期碰过益智解压玩具、女装、文胸、身体链、情趣玩具、项圈等等小众品类，后来才逐渐锁定百货和个人护理家居清洁。数据最诚实，真正撑起利润大头的，其实是百货和个护家清。

这篇内容，就是我对这8个月选品教训的复盘。我一直相信越分享越幸运，希望我趟过的雷，能帮大家少踩一些。
