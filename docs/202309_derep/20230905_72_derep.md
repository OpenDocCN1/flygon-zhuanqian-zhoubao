# 一个独立创造者的五年

一个时代到底算好还是算坏，从来都没有标准答案，关键看你用什么视角去审视它。今天要分享的这篇文章，来自“龙哥的收藏夹”，标题是《一个独立创造者的五年》，里面有一个非常笃定的判断：如果把目光投向全球化的 SaaS 领域和那些独立创造者，那么这无疑是一个黄金时代。

为什么敢这么说？因为如今那些跑在世界各地服务器上的一行行代码，已经成了一种新的“阿基米德支点”。过去我们只能靠实体资源慢慢堆，现在一个人依托数字能力，就能远远撬动曾经不敢想象的庞然大物。互联网把杠杆递到每个人手里，这大概是创造者最容易借力的年代。

作者用五年时间，实实在在地走了一条独立创造者之路。一路上具体经历了什么、沉淀了哪些认知，原文里有更完整的答案。不管你是刚冒出独立创造的念头，还是已经在这条路上走了很久，都值得停下来读一读。
