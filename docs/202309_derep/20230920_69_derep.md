# ('12 小时发起一个社群，创建一个 1400+人社群，难吗？', (2, 31))

你相信吗？从零到1400多人的社群，只需要一个白天加一个黑夜的时间。不是痴人说梦，而是真实发生过的操作。

昨天，条形马教练和刀姐小助理在航海群的一次直播中，顺带手就发起了一个全新社群。谁也没想到，仅仅12小时后，这个社群的成员数已经冲破了千人大关，直奔1400+而去。听起来像是天方夜谭？但这事就摆在眼前。

我本人正好以船员兼参与者的双重身份亲历了全过程，今天就把我的复盘心得掏出来和你聊聊。必须说，这次行动并不复杂，关键在于有清晰的打法和可复用的路径。过程中有不少要点都来自那本《社群发起人航海手册》，里面有非常详细的拆解，我把飞书文档链接也放在文末了，感兴趣的话可以直接去翻阅。

很多人觉得搞一个大型社群难如登天，要筹备几个月，要策划各种活动。可这次经历却告诉我：只要方向对了，12小时足以撬动上千人的聚集。所谓的“难”，往往只是因为我们还没掌握那套已经被验证过的方法。

如果你想试试，也别光看我在这儿说。真正动手做一次，你会发现，原来拉起一个几十上百人的圈子，并没有想象中那么遥远。敢不敢用12小时，也去创建属于你自己的那个社群？
