## 如何用一个 Prompt 把互联网文章的阅读效率拉满

作者：刘子荣

日期：2023-08-30

**嗨，我是子荣，现在主要做 AIGC 企业培训，刚好在推动一场有上市公司参与的 Prompt 调教大赛，有兴趣的可以来聊聊。**

企业本质上都在追一个目标：降本增效。说白了就是用更少的人、更短的时间，把事情做完。今天就聊一个实操点：怎么靠一个 Prompt 让刷网文的速度起飞。没用上 ChatGPT 之前，我大概一天能啃 3 到 5 篇干货；用了之后，阅读量完全取决于你自己的胃口。

**文末我放了一个已经调试好的结构化 Prompt，稍微改改就能套用到书籍、报告、长文档上。**

用 AIGC 工具的门槛其实很低，像打篮球一样，人人都能运球。这是大众水平。

能稳定投进球，训练时命中率有五成，这算入门了。

真厉害的是在实战里依然能保持五成命中率，这才是高手。

我长期混在赚钱社群，几乎每天必刷“龙哥收藏夹”。里面全是经过一轮筛选的精华，信息密度高，特别适合碎片时间阅读。

下面我以收藏夹里的两篇内容为例，具体演示了操作思路，完整呈现我在飞书里整理的版本，阅读体验会更好：[`hi1qdkhiesc.feishu.cn/docx/Kg2Vdoxk8ochlQxaogWcKqHmnLh?from=from_copylink`](https://hi1qdkhiesc.feishu.cn/docx/Kg2Vdoxk8ochlQxaogWcKqHmnLh?from=from_copylink)
