## 如何借助 ChatGPT 的 Code Interpreter 做出视频特效并写出可用的代码

作者： 易焘

日期：2023-09-04

ChatGPT 在今年 6 月上线了一个让人眼前一亮的功能 Code Interpreter，如今名字已改为 Advanced Data Analysis。它的 Python 在线运行和数据处理能力给我带来了不小的冲击，我甚至开始怀疑自己此前在航海专栏里分享的 ChatGPT 编程方法是不是已经落伍了。

但实际上手后，我的感受是又惊又憾。功能很强，却也不是万能的。只要需求稍微复杂一些，它就会暴露出和 GPT-4 默认模式一样的通病。推测其底层的推理逻辑本质上还是来自 GPT-4。

下面我把近期用 Code Interpreter 把静态图玩成各种动态视频特效的实操经历梳理一遍。前半段主要讲它如何揣摩意图、独立生成 Python 脚本并自动执行，产出基础的视频特效；后半段则聚焦它为实现图片隐形效果而编写的一款 Chrome 插件案例，从中可以看到这项能力的上限和短板。

为了更直观地呈现测试的对话过程和最终的视频成品，建议直接前往文中附带的完整链接查看。
