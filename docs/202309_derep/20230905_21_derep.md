# 商业拆书稿或者读书笔记很难写？送你一个 prompt，五分钟成稿

你是不是一听到“商业拆书稿”或“读书笔记”就开始焦虑？憋了半天写不出一段话，好不容易写完又觉得像流水账。别慌，今天分享一个简单粗暴的prompt，能让你在五分钟左右完成一篇像样的稿件。

先介绍一下自己：我是枫晓陌，微软认证AI工程师。接下来这一年，我打算用AI去融入一百种不同的工作场景，让大家实实在在感受到AI的便利。你想让我用AI切入哪个领域？写作、阅读、小红书、健身、朋友圈、简历、热点分析……都可以留言告诉我。下一站，我会聊聊小红书。

其实拆书稿现在依然有市场，只是没有前几年那么火了。知识付费刚刚兴起的时候，一篇稿子能开到万元稿费。那现在读书笔记又靠什么赚钱呢？我给出了几个可以尝试的方向，聪明如你肯定能举一反三，从这些思路里再延伸出更多玩法。话不多说，我们继续。![](img/e7b27554ff8cd20444ba3dbcd1b13a83.png)

可是大多数人的问题是：笔记写得太烂，或者花的时间太多。怎么破？我把常见的拆书套路——5W1H、蒙太奇、笛卡尔分析、洋葱阅读——全部揉进了那个prompt里。哪怕你是零基础小白，也能快速达到60分的水平，状态好一点冲上80分也不奇怪。剩下的分数就要靠个人慢慢修炼了。毕竟AI再厉害，也只是辅助工具。有一种叫“审美感”的东西，AI暂时没法跟你产生精准共鸣，很难生成百分之百让你满意的作品。

我自己的设计思路很简单：本身我并不精通那些拆书方法论，那就去问AI，或者直接上网搜。![](img/af638d10a0ada45c72cf9be79cf50eb0.png)

我连续问了几个AI，发现每个给出的答复都不一样，从中挑一个自己最顺眼的就行![](img/45f1ee24459233bfe1fb31dce4a4e998.png)。当然，如果你本身就有更成熟的方法论，或者是知道某些更牛的拆法，那更好——直接把这些方法沉淀成prompt。

下面是整套操作流程（Workflow）：

1. 用户先把书籍信息发过来。
2. 如果我的数据库里有这本书，就继续聊；要是没有，对话就到这里结束。
3. 根据这本书推荐三种合适的拆书方法，并讲清楚为什么推荐。
4. 用户选定方法后，由AI输出拆书稿大纲。
5. 用户指定要写哪一部分，AI就针对这部分单独输出。
6. 用户确认拆书内容是否OK。
7. 如果用户有反馈，就按反馈再修改调整。
