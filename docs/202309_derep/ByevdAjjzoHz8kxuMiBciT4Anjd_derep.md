# 一个大学生，把少儿编程课开进了社区和学校

我是胖虎。大学期间我做过一个挺有意思的项目：把人工智能和少儿编程教育送进社区、送进学校。今天想把这个经历拆开聊聊，希望对想做轻资产创业的朋友有所启发。

用一句话概括就是：把社区里闲置的公共空间用起来，给孩子们提供公益、普惠性质的编程和AI启蒙课程。

这件事的起点，要从我的专业说起。

我当时在杭州师范大学读计算机师范专业，按正常路径，毕业后大概率当信息技术老师。大二升大三那年，我在QQ空间刷到朋友发的教孩子电脑课的照片，突然觉得，既然以后要当老师，不如提前去接触真实的孩子和课堂。于是我去线下的少儿编程机构应聘助教，后来一路做到了带课老师。

课教了一段时间，我算了笔账：上一节课才挣100块，课件自己做，课后还得给孩子和家长答疑。这活儿的核心环节我全都干了，钱却被老板拿了大头。既然如此，为什么不自己搞？

我和两个一起上课的朋友一商量，决定出来单干。但大学生想创业，最现实的问题是没钱。租店面、搞装修、买设备，哪一样都是大开销。所以，我们一定要找一种接近零成本的方式切入。

有天我闲逛，在杭州某个小区边上发现了一个叫“文化家园”的地方。

![](img/89ab371c14ffe837915914f69f6b5f32.png)
![](img/742294ef4eedbecd95dc80f71f140c0f.png)

门口立着易拉宝，上面印着免费给老年人上葫芦丝课、给孩子上素描课之类的活动。我一下被吸引了：像这样的场地，原来是社区服务点。社区每个季度都有活动数量要求，也愿意对接外界资源进来搞活动。

再仔细说说社区这个概念。我后来查了不少资料，也实地跑了很多地方。在浙江，几个小区组成一个社区，几个社区组成街道，几个街道再组成区域。每个社区一般都有配套的服务场馆，休息区、小教室、活动区是标配，条件好的还会有图书馆、健身房。

![](img/2c050031301ff54b009a311afe8023fe.png)
![](img/09720f02faf95bbc90be04793fe8e75a.png)

这一下就通透了：社区有空闲场地，居民有服务需求，我们正好有师资。那我们是不是可以借助这些场地，面向社区里的孩子做AI和编程科普？

就这样，我们开始联系社区，用空闲教室开公益课。前期完全免费，目的只有一个：把流程跑通，把队伍练熟。

![](img/d0ca641c4f975329e361449b4598e11f.png)
![](img/00ebaf3efc289f74a75b231ee02cc1c1.png)

慢慢地，孩子们学出了效果，家长和社区都很认可，希望我们能长期做下去。于是，公益课顺其自然地转成了付费正式课。没有门店、没有装修，社区里的小型教培机构就这么长出来了。

这个模式有三个突出优势。

第一，天然被信任。老师、社区、家长、孩子，几个角色离得非常近，上课就在自家楼下，接送方便，安全也有保障，家长很难不放心。

第二，社区愿意配合。社区会主动帮我们做宣传、招学生，活动数量上去了，社区的政策指标完成了，人流量也起来了，是双赢。

第三，成本低到不可思议。除了师资，我们几乎不需要其他投入。孩子自己带电脑来上课，就算租一台电脑，一个月也只要60块钱。

模式跑通以后，我们把流程整理成标准化方案，开始在更多的地方复制。短短半年，杭州、海宁、长沙等多个城市都有了类似的活动和课程。大多数社区都是先上几节公益课，然后顺理成章开正式班；单个社区的在读学员通常在10到40人之间。有些社区干脆把活动经费拨给我们，让我们办短期的科技类活动。当然，也有个别社区只做了公益课，因为各种原因没有形成正式班。

![](img/42ba8f821c402561bbf59cd79e81611a.png)
![](img/0094e9a8eaefed0ae8de29a8f6b0e497.png)

这里面的利润空间，我也拆开算过。

一种是社区付费办活动。办一场科技活动，社区给4000到8000元经费，扣掉老师课时费、礼品和耗材，成本基本能控制在1000元以内，剩下都是利润。

一种是公益课转正式课。成本主要是课时费和器材，转化到的学员越多，利润就越高。因为成本低，我们收费也可以压得比机构低，这个价格优势很有杀伤力。单看一个社区，一年有20名学生，营收就能做到10万以上，主要成本还是老师的课时费。

还有一种模式，是流量变现。有了在读学生，就等于有了一个精准的本地社群。晚托班、承接活动、异业合作，后面能延伸的方向很多。

这个项目不像互联网产品，不太可能一夜爆发，但只要把模式打磨好，在靠谱的地方一个个复制，就能做得比较长久稳定。如果手里有10个社区在稳定运营，一年至少能做出100万的营收。

说到人员要求，门槛其实不高。最核心的是老师：要会教孩子，要懂少儿编程。更往上走，还要能清楚地表达自己的想法，并做出像样的合作方案。对标来看，20岁左右的大学生只要愿意学习，完全具备操作条件。

那现在还能入局吗？可以，但选城市很重要。

新一线城市的社区教育发展已经比较成熟，社区对服务和活动质量要求很高，没有积累和专业度的团队很难进去。南方二三线城市反而是更好的选择。北方的社区建设普及程度相对弱一些，优质社区资源不那么好找。

方向上，政策也在持续加码。新华网曾经报道过杭州推进未来社区建设的情况：杭州市计划到2025年底，让未来社区覆盖约40%的城镇社区；到2035年底，基本实现全域覆盖。从2019年启动以来，杭州已经创建了300个未来社区，累计建成省级未来社区62个，受益居民接近300万人。社区场景，还有很长的路可以走。

![](img/91f7719af86f1c264eb7dd02e5b42792.png)

社区之外，我们也把同样的思路做进了学校。简单来说，就是协助学校打造人工智能示范校，相当于把培训机构开进学校内部。

学校的门槛会比社区高不少，需要更专业的老师，方案也要更具体——比如怎么帮学校带比赛、怎么把科技节办出效果。

我们的一般操作是：先面向全校做公益课招生，吸引学生来体验。体验结束，再用组建校队的名义开设付费班，家长报名后，每年光课时费就能带来几十万的营收，成本里的大头仍然是老师课时费。

![](img/0d2fe933e8b800b69f523ef6fb800fc6.png)
![](img/41087a71a36504840b60c28a11324a74.png)

除了课程，学校还有硬件采购和项目打造的需求，比如创客实验室、科技节、设备采购，这些我们也能接，利润空间也不小。

科技节本身不怎么赚钱，它的意义在于做品牌、造氛围，为后面的深度合作铺路。

设备采购则是另一种玩法：有些白名单比赛需要机器人等器材，学校可以直接采购，10万以下的设备学校自己做决定，我们对接厂家，利润能做到30%左右。

如果碰上几十万的创客实验室搭建，过程就要复杂一些，要走流程、上会、招标，周期比较长。但一旦做出来，和学校的绑定关系就会更深。

![](img/9b4e74f938d5440874552517801ced50.png)
![](img/f55734fe93fcd830f4dd0502255218c1.png)

整体逻辑其实很朴素：围绕学校的需求做服务，方案要踩准点，老师要靠谱。不一定非得是名师，优秀大学生如果对AI教育有一定认知，同样能撑起来。

写到最后，我想说一句：无论少儿编程+社区，还是人工智能+学校，模式本身并不复杂。但如果你把思路打开，是不是可以延伸成“X+社区”“X+学校”，甚至“X+Y”？互联网上的各种项目，无非也是在做组合、迁移、重整。

这件事对我最大的启发是：好的模式，不一定多新奇，关键是找到合适场景，然后耐心跑通。

我是胖虎，长期关注并深耕AI+教育。感谢观看，2024，一起用AI破局。
