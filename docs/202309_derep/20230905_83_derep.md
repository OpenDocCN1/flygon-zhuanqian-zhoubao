# ('让你受益匪浅的名家写作经验', (2, 15))

标题：写不出来的时候，不妨看看作家们怎么下手

最近在“龙哥的收藏夹”里看到一份腾讯文档，里面整理的全是作家前辈们关于写作的私房经验。翻完之后有点意外：原来这么多老一辈的写作者，都认认真真写过“怎么把一篇文章写出来”这件事。

文档里没有那种高深莫测的套话，更多是实打实的创作心得——从灵感到落笔，从结构到修改，怎么把一个模糊念头变成清楚明白的文字。虽然例子大多围绕文学创作展开，但对现在那些一提笔就发怵的职场人也挺有参考价值。

我认识不少做技术的朋友，越来越不愿意写东西。倒未必是骨子里排斥，更多是打开了文档却不知道写什么，憋了半天写不出两行，最后干脆放弃。这时候去看看作家是怎么拆解写作这回事的，可能就会发现：原来那些写得好的人，也不是靠灵感砸中，而是有一套可以慢慢摸索出来的方法。

写作这事，说到底是一门可以练的手艺。一个卡壳，不必硬扛，翻翻前辈们的经验，或许就有下笔的冲动了。
