# ('2023风口摆摊项目：卖灯笼、发光发簪', (2, 21))

今年试了几个小生意，最让我意外的是两款“带光”的小物件——会亮的发簪和祈福竹灯。一个适合晚上出摊，一个自带好彩头，利润空间都很可观。

先聊聊赚钱这件事。我直接对接了源头工厂，第一批拿了一千支簪子，单价压到四元出头，零售定在二十元，几乎没人杀价。偶尔有人试探着问，只要愿意拿两支以上，我最多让两块钱。单支毛利基本稳定在十六元左右。

但这份利润是踩出来的。最早我在网购平台分批测试，第一单买回一百六十九支，其中两家的货折合五块七一支，质量很差，直接退掉。之后又把七八家店铺试了个遍，能勉强留下的只有一家，单价五块五。

最离谱的是踩到一家店，前后仅买了二十支，坏的就有七八支，价格还要五块七。细节处全是问题——掉色、珍珠脱落，最后整单退回。前前后后折腾了三回，全是质量问题。我干脆花了一整晚去找工厂，终于锁定现在的合作方。实拍对比图我留了一整套，做工、质感、价格，差距一眼便知。

工厂现在的款式，都是摆摊时用手机原相机随手拍的。整体走复古雅致的路线，拿在手里像一件精细雕琢的小器物，戴在发间衬托出东方美。夜里打开灯光，整个人像笼罩在薄薄的光雾里，仙气四溢。

![](img/5793db1e9209125b13735290f115d7a8.png)
最早那批网购测试共一百六十九支，两家的货折合五块七一支，品质太差，直接退了。后来陆续试了十家左右的店铺，勉强合格的一家也要五块五。

![](img/2e780ab09fd6945207601aefea4eaba3.png)
最坑的是某家店，二十支里有七八支有问题，价格还标五块七。掉色、珍珠脱落都是小事，细节完全经不起看，最后只能整单退。三次退货全是因为质量不过关，气得我连夜联系工厂，才找到现在这家。品质提升一大截，进货价反而更低，实拍对比图都留着，差异不用多说。

款式方面，现在最受欢迎的有四个系列。

![](img/924669531f2788532ffeef1d84a6761e.png)
中秋当夜穿一袭汉服，发间再簪一支亮闪闪的簪子，走在街上就是活脱脱的“月中来客”。不局限汉服，普通连衣裙、改良国风衣装都能搭，日常出门也毫无违和感。晚上出门相当于自带迷你补光神器，拍照出片率直接拉满。

![](img/aaa3bdff16d8a05607e12a1673cead58.png)
生肖兔那一款，金属雕出的小兔圆润可爱，身上嵌着一个福字，下摆悬几串细珍珠。金兔配白珠，清冷如月中仙兽；换红珠则是一派喜气的纳福兔，兔年佩戴特别应景。

![](img/c3b28cca7cc39399f490d2a840ba281f.png)
还有一款取自屋檐上翘的楼阁造型。体量虽小，轮廓却分明利落。换上不同颜色的珠饰，风格也随之切换：白珠清冷脱俗，红珠端庄富贵。

![](img/afeac3fd6f8ecf7604386bae2e396219.png)
灯笼形那一款最有东方韵味，金属质地的镂空球形灯身百看不厌。金色灯罩搭白珠，温润优雅；换成红珠，则明艳吸睛。更妙的是走路时会发出清脆的声响，像铃铛，又像风拂过屋檐。

![](img/1ec2a852cfe80ceb08a57d3124eeb390.png)
莲灯款则是把花灯元素直接浓缩进发饰里：圆形框架内端坐一朵鎏金莲花，下方垂一缕红流苏。点亮后宛如一盏象征圆满的小灯笼，别在发间格外有味道。

![](img/8c3d90f956b2c676bcc5eeecb722f1e5.png)
这几款的共同点是簪杆和吊坠衔接处都做了一朵手捻莲花，莲座下挂着不同样式的灯笼饰物，远看像一位素手纤纤的仙子提着花灯。

材质主要是合金加高光珍珠，颜色饱满、光泽度好，单支戴或叠戴都各有风味。发光原理很简单：拔出绝缘片即亮，插回即灭。每颗灯珠能稳亮四五个钟头，随后逐渐变暗；要求更长的续航，可以加购备用灯珠。

再讲竹编灯笼。进货价同样四元多，零售十五元一只。

别看它不起眼，设计灵感来自潮汕老式竹灯。当地话里“灯”与“丁”同音，“竹”与“德”同音，因此它被赋予人丁兴旺、德泽绵长的祝福。即便新式灯饰花样再多，潮汕人节庆时仍爱挂这种老式竹灯求个好兆头。

![](img/403601237da3da7103ce68eda7f2e972.png)
其中有一款木簪灯特别出彩：黑色提杆顶端饰有彩珠和盘花结，竹编灯身由一根金属丝悬在流云纹饰板下，底部再缀一枚白润的莲形坠子，整体气质古朴大气，像古画中仙女的配饰。

灯光是柔柔的暖黄色，夜里亮起，像为周身镀上一层薄纱，站在灯下自带主角光环。

![](img/9aef90a318078d7399d59d30fa008801.png)
它的用途可以归纳为四类：一是寓意讨喜；二是当挂件或摆件，车内后视镜、书桌角落、店铺展架都合适，随手一放就很出挑；三是拍片道具，氛围感信手拈来；四是婚嫁场景也能用，求婚、领红本、摆喜酒都能拿来装点，制作新娘花球时挂上一只，别致又应景。

选址上，我的主场在大学旁边的学生街，这里人群密集、消费力稳定。假如附近有学校、公园、夜市，出货都会很快；景区更是加分项。人只要聚过来，围观的人会越来越多。

出摊节奏上，我固定晚上八点开摆、十点收摊。白天要练车、打理二手平台、写文章，摆摊只能安排在夜里。每晚两小时，流水大概三百元。

![](img/228959768f6413ed81e113fbac747631.png)
一天中卖得最猛的是七点到八点半这个区间。天完全黑下来之后，灯光一亮就是最好的广告，路过的人远远就会被吸引过来。

另外还有两款八元、十元的测试品在售，效果好了再专门写一篇。

![](img/c17138612005d790f662f0817d079101.png)

陈列方式也很关键：一只藤编提篮，内部铺泡沫板，将簪子和灯饰依次插好即可。纸箱、泡沫箱太掉价，我用的是一只提篮，另备一只小背篓，再盖一顶草帽做点缀。货多时背着、提着都方便，到了地方放下就能开卖。

![](img/262e2994e26bf6f3aaa24f3531256d34.png)

![](img/879c47ad2748cc278b22d8713a85a021.png)

最后聊聊新手最容易踩的坑。第一，地域差异明显，动手前务必去踩点，否则很容易出现囤货滞销。第二，消费力决定定价，消费偏弱的地区，灯笼只能卖十元、发簪卖十五元；我所在的学生街，奶茶普遍二十元一杯，普通工艺簪子也要二十五到三十元，因此我的定价一出来，顾客基本直接掏钱。第三，位置选择要灵活：交通路口、夜市、景区、公园、学校附近都有机会，但不同位置主推商品不同——学生多的地方发簪走得快，公园外面小朋友多，灯笼又更好卖。第四，沟通能力很重要，多摆几次，话术自然就有了。

社交平台上抱怨摆摊亏钱的人不少，大多败在没考察、没经验。这篇就当提前避雷，入局前多做点功课，总没有错。
