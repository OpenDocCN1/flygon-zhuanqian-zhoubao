# 十分钟进账12万美元后，我决定认真写这部连载（第八篇）

那一年，我只花了十分钟，账户里就多出了100万人民币，折合下来大概12万美元。这并非故事的开头，而是我这个系列连载的第八篇。

我是静水流深，在英文工具站这边担任教练。之前在杭州的线下聚会上，我曾经对龙哥表过态：以后要多贡献一些真正有价值的出海内容，让龙哥盟这个社区变得更“有货”。今天的文章，就算是来履行这个小承诺。

先交代一下过去做了些什么。此前我分享过一篇“三个适合单人操作的海外赚钱案例”，后来又拿出一个新项目：还是一个人就能扛下来，按我的判断，跑通以后同样能稳定达到月入一万美元。不过即便这样，还是有人存疑。所以这次我特意挑了一个正在跑的真实项目来当例子。

其实这个项目，早在一年前我就在自己的星球“丝绸之路”里给会员们提示过多次，他们本来也可以下手，只是没人把盘子做到我这么大。

ChatGPT热度刚起来的那段日子，我还在龙哥盟发过一篇独家内容，结果因为题材比较敏感，被星球官方拿下了。上个月写的那篇跟 Wise 推荐项目有关的文章，倒是反响不错——里面提到一天不用干活也能进账一万英镑以上。这次也顺便谢谢所有点赞和支持的朋友。

再往前几天，正好是高考，龙哥丢出了一个让大家争论很凶的问题：考上985和年入百万，到底哪条路更难？我的系列开篇就是从这个问题聊起的。说来也巧，这套连载最初是航海活动时我对船友们的承诺，这次逮到机会，我就索性把标题换掉，以后固定在“那一年……”这个主题下更新，也会一件一件地，把二十多年来国内外互联网圈（尤其是海外那边）的亲历和隐藏机会讲给大家听。没看过前文的朋友，可以回头翻第二篇到第七篇。

因为平台限制，这期的完整正文发不上来，我已经把内容整理到飞书文档，想继续往下读的可以去那边查阅。

希望这一路的回顾，能给大家带来一些实实在在的启发。

最后照例声明：这个连载完完全全是虚构的，万一和现实撞了车，只能说是纯属巧合。
