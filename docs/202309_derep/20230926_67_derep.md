# ('24 岁医护转行， 从 0 开始，摄影师私域变现经验', (2, 28))

“从护士到摄影师，月入2千到3万，她只花了一年。”  
这不是夸张的标题党，而是广州摄影师林海盐的真实轨迹。

97年出生的她，曾经是一名医护工作者。和很多人一样，每天在忙碌和重复里打转。后来她选择裸辞，重新出发。从最初月薪2000的迷茫期，一路做到如今稳定月入30000+。到现在，自由职业已经两年了，微信私域积累了8000多位好友，收入也从四位数跃升到了五位数。

很多人以为摄影是光鲜的爱好，但在她看来，这是一门可以认真经营的小生意。最近她把自己从零开始做摄影师的经验做了一个系统梳理，想告诉更多人：哪怕行业不同，底层的玩法其实都是相通的。

关于这段经历，她拆解成了几个关键环节：  
1. 个人背景  
2. 为什么会选择摄影这条路  
3. 摄影师赚钱的主要方式  
4. 第一批客户从哪里来  
5. 怎么给产品定价  
6. 销售环节怎么做  
7. 交付阶段怎么做好  
8. 给新入行摄影师的真心建议  
9. 创业以来的感受

内容很扎实，篇幅也比较长，为了方便阅读，她把完整版整理成了石墨文档，有需要可以点开细看。如果觉得有启发，记得先点赞再收藏。

评论区里有人问：拍照时的化妆是找合作化妆师，还是自己搞定？她回复得很干脆：合作，专业的事交给专业的人。

从她身上能看到的，不只是转行的勇气，更是把热爱和商业结合起来，一步步放大自己价值的过程。2023年下半年，希望每个人都能在喜欢的事情里，赚到更踏实的钱。
