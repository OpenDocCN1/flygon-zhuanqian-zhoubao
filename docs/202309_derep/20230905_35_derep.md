# 单日广告分成吊打原创两年？公众号流量主收入暴涨10倍的三个关键

公众号爆文航海马上启程，很多朋友已经在摩拳擦掌。但据我观察，绝大多数人运营时只盯着两个数字——文章阅读量和流量主收益，其他数据指标一律无视。结果呢？大把流量白白打了水漂。

先讲一个刚发生在我身上的震撼对比：一个搬运类公众号，单日的流量主广告分成，直接超过我原创号整整两年的累计进账。更关键的是，它的阅读量并没有突飞猛进。这说明一个道理：哪怕阅读量纹丝不动，广告收入照样能迈上新台阶，关键全在打法。

聊聊我的反面教材。2021年，我注册了个人公众号，流量主顺手开通后就再没打理过，彻底听天由命。整整两年，文章阅读量停在几百也好、冲到几千也罢，文末广告收益始终低得可怜，攒下的分成几乎可以忽略不计。
