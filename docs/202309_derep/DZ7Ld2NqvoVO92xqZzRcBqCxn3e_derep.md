# ('19 岁大一学生 如何靠赚钱 做抖音 K12 项目两月小赚 2 万块并获得长尾收入？', (2, 44))

19岁，大一，靠抖音做K12项目，两个月赚到2万块，还躺着收长尾收益——这事是真的，而且路径可以复制。

今天这篇文章，来自一位刚上大二的03年小伙“安俊”的实战复盘。他用亲身经历告诉你：小白怎么在抖音知识付费里挖到第一桶金？教育IP怎么做才能不招人骂、走得远？全文信息量很大，我帮你把最有价值的干货都拎出来了。

先说结论：他做的是高考物理赛道。高中时物理就是他的强项，等于自带“知识货源”。大一闲着没事，随手发了个抖音视频，没想到第一条就爆了。后面越做越顺，不仅赚到了钱，还攒下几百个学生私域，现在对接项目持续有收益。

他总结的爆款视频逻辑，非常值得琢磨。核心不是特效多炫，而是文案要用“助人型”。比如“大家有XX问题可以分享出来”“一人分享一个高中踩坑经验”这类话术。为什么火？因为所有人都多少有点分享欲，评论区你一句我一句，视频互动率飙升；学生刷到也会忍不住翻评论，完播率自然高。加上热门特效的加持，新号能快速打标签、起权重。

除了这种起号用的爆款模板，他还有几个长期能用的视频套路：

背景视频类：找优美的风景或电影片段当背景，配合方法类或情绪类文稿，AI字幕+背景音乐，简单剪辑就行。像“睡不醒的平盖尔”就是靠这个模板，第一条视频直接涨粉百万。

课程回放类：把自己录过的课直接发，成本几乎为零，标题记得埋关键词，比如#高考 #物理 #电场。

技巧总结类：要么是“秒杀”式简洁公式，要么是超漂亮的手写笔记，视觉冲击力强，特别吸引学生。

直播回放类：剪直播切片，加特效，关键词加上“家长必看”“学习方法”——因为很多家长会刷到，他们也是买课主力。

那源源不断的模板从哪来？就一个字：抄。多刷对标，把系统推给你的爆款同行，拆解、模仿、再组合，形成自己的新模板。很多细节只有自己动手做了，才能真正变成自己的。

引流也不复杂：个人简介留微信或公众号；建粉丝群慢慢导流；背景图放公众号名字或微信号。三条路都简单有效。

产品端他列了一长串：虚拟资料、学习方法课、六科全程课、心态梳理课、冲刺方法课、单词训练营、早起营、全科答疑群，还有高客单的一对一陪跑和志愿课。价格从7.9元的资料包到2499元的一对一陪跑都有，分层非常清晰。

怎么把用户黏性做起来？他有套私域心法，特别值得学。

加好友后先送一份资料，最好再发一段语音，亲切感直接拉满。然后用9.9元的小金额资料做超价值交付，有人买完资料后，转头就报了2499的陪跑课程，这就是信任的力量。

公众号要设置免费资料领取，比如单科学习方法、背单词方法论，先把人留住。更新频率保持一周一更，周五晚或周六发，因为高中生只有周末摸手机。内容分两类：一类是学习方法干货，别藏着掖着；另一类是鼓励和思维类文章，比如“如何成为一个内心强大的人”“高中生最大的思维误区”。学校里的孩子普遍压抑空虚，一篇能给他们精神充电的文章，比什么营销都管用。这也是好教育和纯割韭菜的区别。

推课程不是乱推的，讲究时间点。高三刚开学推全年方法课，高三上推六科全程课，寒假推心态梳理课，高考倒计时100天推冲刺方法课，75天推学科冲刺课。期间穿插训练营，每个节点都正好扎在需求上。

定期视频号直播也是利器。直播只解决情感问题和学习问题，千万别在直播间卖课，那是用来升温感情的。题目要起得让人不得不听，比如“即将进入高三的你，不听这场直播一定会后悔”。多露脸输出，教育IP很快就立起来了，转化率也会高得吓人。

他说现在K12赛道单卖课程和陪跑营已经很卷了，更看好一对一陪跑。高三学生真正缺的不是课程资源，B站一搜一大把。他们缺的是一个懂自己的人——被排挤、校园欺凌、内卷焦虑、心态崩溃、恋爱问题、老师压力大、模考考砸了，这些跟家长没法说，但一个成绩优秀的学长学姐却能接住。所以很多家长愿意花4999甚至5999，因为高考只有一次。

最后，关于教育IP怎么做长久，他给了几条很实在的建议：

第一，死磕私域。一个教育IP吃一辈子完全可能。高中粉养在公众号里，高考完无缝转大学内容，再推出软实力课程，甚至直接对接考研、四六级、流量卡、创业粉的渠道，发个朋友圈就能赚佣金。

第二，保持周更和定期直播。大学内容偏向《教你成为大学面试的神》《最快脱单的方法》《上大学前一定要看完》这类。课程也变丰富：志愿课、恋爱营、自媒体营、速过四六级营。情感到位了，四年都在你碗里。

第三，学会挖人。高中培养的好苗子，毕业后直接招进工作室，帮你录课、运营内容。你只需要维持IP，输出价值，把重心放到大学软实力或职场内容上。这个模式能滚很久。

第四，别用“割”的思维做教育。割一波快钱，然后呢？如果你是真心喜欢教育，完全可以走“高中—大学—职场”的IP路线。你培养出几百个几千个思维提前觉醒的学生，他们未来会变成你巨大的财富。而且他们成功后，还会反哺你、长期跟着你。这不是赚钱，这是一笔牛市投资。

第五，要有价值观。比如他推荐的“树成林”，他们专门开了一门大学思维课，把“利他”种进了每个学生心里。统一的价值观，才是IP最深的护城河。

以上，就是一个19岁少年用真金白银换来的全部经验。如果你也在做教育IP，或者正打算入局抖音知识付费，希望这篇内容能帮你少走很多弯路。

想建立这种价值观，其实不用喊口号。每隔一段时间，各地会有人主动站出来，组织一场属于这个城市的“树成林”聚会。来的通常是一些观念前卫、愿意利他、有核心分享精神的大学生，大家围在一起聊天、认识新朋友、交换手头资源。说到底，这就是IP带来的向心力：大家发现彼此是因为同一个IP才坐在一起，对它的信任感和依赖感自然越来越强。这样的教育IP，是值得被记住的。

说白了，这套玩法和赚钱各地的同城群聚会没什么两样。每办一次聚会，都是在给官方IP增加曝光，也在给同频的学生搭一个可靠的连接点，双方都赚到了。对于官方IP来说，这是持续的曝光和推广；对于圈友也就是学生来说，等于拥有了一个信得过的圈子。

这里顺便推荐两个对标账号：“树成林”和“小万物”。

简单讲讲这两个公众号的来历，不感兴趣可以直接跳。

先说“树成林”。它是20年年初创立的公众号，主理人是树林同学。他长期在B站发背景模板类视频，还会定期开直播，靠着这种日复一日的输出，养成了一个辨识度很高的IP。![](img/0e00e078db919407bebc787bd8c3d01c.png)（到这个时候体量已经不小了，那个模板是真的火）很多粉丝对这个IP有了深深的依赖感，大家可以自己去B站搜“树林同学”，评论区、弹幕里一眼就能看出那种粘性。大家一有学习上的困惑、情绪低落，就会去看他的视频、蹲他的直播。2021年有一条视频在抖音和B站双双爆了百万赞，那波引流直接进入疯狂状态，后面他就顺势用公众号做用户粘性，再出课程变现。据说到那时，这位UP主的个人纯利润已经赚了1000个W。更重要的是，IP本身足够让人信赖，很多粉丝会继续复购大学阶段的产品，像《恋爱训练营》《IP训练营》《沟通训练营》等等。他还会从产品用户里挖人进公司，帮着运营高中内容，甚至出版了《生物知识清单》这类高中书籍。

再说“小万物”。这个号的老板原本是树成林的一位合伙人，就是抖音上的“睡不醒的瓶盖儿”。他出来单干以后，复制了树成林两年前的玩法，现在视频又爆了，流量也顺理成章承接到了公众号。大家可以多留个心眼，看看这个号接下来是不是也会把用户往大学方向引导。![](img/ab7c4253073428fe7afff8b25e479744.png)这两个公众号目前都属于能长期存活的优质教育IP，生命周期很长，发展上限也很高。

接下来聊聊：怎么讲出人听人爱的课程？

做课程之前先明白一个前提：后续IP要复购，产品必须做得更好。前期为了控制成本，可以用飞书录课。导图我先放给大家，大家先仔细看一下导图内容，我再逐条用文字展开（导图可以放大）。

第一，要先讲why。你得先告诉学生，为什么要学这个？它跟之前学的内容有什么关联？这样做有两个好处。

第一是预习。有个我也解释不了的现象：一个东西我第一次见过，第二次再看到的时候，会莫名精神起来——哎？这个我是不是在哪儿见过？举个例子：如果你特别爱看赚钱的文章，某天老师上课突然提到赚钱的创始人龙哥，哪怕你正在钓鱼，也会立刻清醒，竖起耳朵听老师讲什么。

第二是让学生学的东西自带知识体系与框架。学生知道当前知识点在整个框架里处于哪个位置，就不会学得那么懵。就像我现在给你们讲内容，一开始就把思维导图摆出来了。

第二，为什么要用类比和打比方？

如果是给零基础的学生讲，比如寒暑假第一次接触这门课，那就必须用类比和打比方。背后的原理可以这样理解：一个神经元就相当于一个知识点。大脑要接受、理解、记住一个新知识点，最有效的方式，就是让新神经元和旧神经元产生连接。给你举两个例子：

先说一个圈友场景：有人之前做过小红书电商，这是他的旧神经元；现在想做视频号，这是新神经元。你怎样让他快速理解视频号？直接告诉他，视频号带货本质上就是小红书电商，不就是选品、混剪、矩阵那套打法吗？新旧神经元一旦链接，他马上就通了。

再比如，想让学生理解什么是圆周运动，这是新神经元。你可以说游乐场里的摩天轮就是典型的圆周运动。好了，旧神经元被唤醒，新知识点也就长进去了。

不知道你们有没有遇到过那种老师，尤其是大学老师，上课纯念PPT、纯念课本，讲题就照着答案讲。这样的课，学生大概率是学不明白的。为什么？因为老师没有给类比，学生大脑找不到连接的旧神经元，自然理解不了。

第三，为什么上课要带上学生视角？

从小学、初中、高中到大一，我最怕的老师就是那种自嗨型，东讲一点、西讲一点，完全没有框架性。学生学起来特别懵，甚至不知道这节课属于教材里哪个章节。如果学生产生这种感受，他对你的产品会非常失望，后续产品大概率就不会再买了。所以讲课的时候，一定要时刻关注自己的知识体系是否完整。本质上就是同理心：你想让学生满意，就要想想学生喜欢听什么样的课。谁不希望自己的老师讲得有条理、能带着自己真正理解知识点呢？

再分享几个小技巧。

关于收款码。收款的方式很多，但容易受到限制。我这里推荐我当时用的办法：用营业执照办一个企业微信收款码，基本不会被限制，提现的时候交点手续费给腾讯就好。而且这个收款码看起来颇有排面，能间接提高转化率。![](img/d8ad427ea6c89a80d51656026120350b.png)

关于引流：到底是引流到个人微信还是公众号？我说说个人观点。流量大的时候用公众号，流量小的时候用个人微信。但也完全不用纠结：如果流量少、只能引流到个人微信，你依然可以发公众号内容，然后把公众号文章分享到朋友圈，再把人吸引过去关注；如果流量很大已经导到了私域，后期再用课程筛选一波，把人导到微信私域就好。

最后是几段经验之谈。

第一，沉淀技能。大一上学期的时候，我其实没想过要靠自媒体赚钱，只是对自媒体感兴趣，在公众号报名了一个“IP训练营”课程。就是那次课，搭建了我对抖音平台的认知和运营方式。也正是这次积累下来的技能、基础和经验，让我第一次发抖音视频就有了一种莫名其妙的网感。总结一下：这其实跟参与赚钱航海是一样的，别抱着“参加一次航海就要立刻赚钱”的想法。一次次的航海，是在帮你积累技能、积攒经验，等哪天技能叠加到一块，自然会开始爆发。比如有位圈友去年参加过视频号带货的航海，混剪、找素材、去重、选品这些能力都练过，今年再上手小红书电商就能赚钱，如果不赚钱，那真是老天爷不给脸了。

第二，会抄。当时刷视频的时候，刷到一个关于高考学习的视频，数据特别亮眼，而且模板非常简单。我当时就在想，别人能发，我为什么不能？再结合自己赚零花钱的想法，念头一碰，说干就干，直接搬了那套爆款模板，结果第一个视频就爆了。“抄”这个字大家可能听腻了，我换个词叫“生产者思维”。其实高三的时候我买过各种学习方法课程，那时我就有意无意地以生产者视角去琢磨：这个内容到底是怎么引流的？它怎么就能让我心甘情愿付费，还让我关注它的公众号一两年？所以，大一下学期我开始正式做的时候，脑子里已经自带一套很简陋的SOP了。方法就是观察对标，用生产者思维去分析它的运作方式，并假设自己是对方：如果我是他，这事儿是怎么做到的？

第三，诚恳请教。当时大一下做K12，自己并没有接触到多少圈子，互联网思维也比较贫瘠，包括怎么承接流量、怎么打造产品，都是一头雾水。比较幸运的是，当时遇到了赚钱圈友行一、一尘学长、泽豪，我很诚恳地向他们请教，得到前辈们非常耐心的指导，然后我从他们的建议里汲取经验，再拿去实操，最后拿到了结果。在这里也感谢当初那些帮过我的前辈，也感谢当初那个敢于向上社交提问的自己。

第四，先干再说。只要有初步想法、有初步SOP，先干起来，先完成再完美。干的过程中再去翻赚钱的文章，优化自己的SOP和行动，在行动中慢慢修正。我那时候就是只带着一个初步SOP，没深入思考太多细节，就上手模仿同行的视频了。先完成再完美。

第五，多看赚钱。赚钱的内容真的非常庞大也非常齐全，但要记住，没有任何一篇文章能直接给你一套完整SOP。你需要在自己所从事的领域里多刷文章，慢慢形成初步的项目体系，然后靠实操下场、踩坑拿经验，不断补充完善。我也是看了圈友分享的文章，学到了很多细节，转化率也因此提高不少。何以赚钱？唯有实战！

回过头来看，我们赚到第一桶金并不难。因为在某个方面，我们多少都会比别人优秀一点。重要的是，并不需要达到专家水平才有资格教人。可能你听过这样的话：高考没到600分就不要做高考教育类。我觉得这个观点是错的。从数据来看，能考上一本的，除北京以外，基本也就10%到30%。而且大家要相信一个很朴素的道理：80分能教70分，70分能教60分，60分照样能教20、30、40、50分。
