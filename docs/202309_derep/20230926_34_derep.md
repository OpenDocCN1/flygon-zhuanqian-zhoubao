# 别跟平台硬刚：一年做到1.2亿GMV，小红书聚光投放的实战拆解

小红书上能做的生意其实远不止内容种草那么简单，但提到聚光投放，真正讲透的人却很少。

正是看到了这块被低估的流量洼地，我和苏铁花了很长时间，把过去一年投放出来的经验沉淀成了一份实战手册【小红书聚光投放红宝书】。

这本手册大概8万字，核心都是我们每月实打实投放数百万预算跑出来的打法，再加上多位一线投手的投放技巧合集，对聚光投放的底层逻辑、操作路径和优化细节做了系统拆解。

读完之后，你会发现小红书投放并非玄学，而是一套可以复盘、可复制的体系。
