# ('关于 AIGC 商业化的 13 个非共识认知', (2, 24))

关于AIGC商业化，这13个“非共识认知”值得反复琢磨

最近，AI产品圈里有一篇长文被传阅，作者是黄钊（hanniman），一位有11年AI、14年互联网经验的资深产品人。他把对AIGC商业化的观察浓缩成13条“非共识认知”，读起来挺颠覆，仔细想又很有道理。我转述如下，适合收藏下来慢慢看。

一、看AIGC的价值，别只盯着省了多少时间和人力，那是效率属性；真正要紧的是转化率提升了多少，这是利润属性。

二、很多AI项目做不出来，往往不是技术不过关，而是行业纵深know-how不够。技术可以补，认知壁垒很难短期突破。

三、看起来情感AI不够“硬核”，但它可能是现阶段最易摘到的低枝果实，商业回报未必比大模型本身差。

四、如果目标是提升转化率，虚拟人可能会带来巨大的增量空间，这种“空降”红利比很多人预期的更猛。

五、关于Agent，现在的“单体智能”主流路线存在隐患；更值得尝试的是“多体智能”——好比鸟群或复杂系统，单个智能体不需要多强，甚至可以低于人类个体水平，但通过群体协作，能涌现出超过人类团队的集体智慧。

六、AI产品设计有个特殊方法论：最后一公里由用户来完成。产品经理要做的，是把框架搭好，把定义空间留给用户。

七、“iPhone时刻”要打问号。现在还没到AI 2.0的品类爆发期，那些说法更多是大佬们的PR用语，别太当真。

八、除了“场景、用户、需求”，AI产品还要引入“关系”。关系一旦定清楚，约束条件和需求属性也就随之明了。

九、处理人机关系有个口诀：使用AI时，把它当成一个“人”来沟通；设计AI时，把用户当作AI系统来拆解。角度一换，方法自来。

十、未来AI公司的划分，不会是传统的To C / To B，而会变成To人 / To AI。服务真人，和服务AI智能体，是两种完全不同的生意逻辑。

十一、AI商业模式没有速成法。要么是“打井模式”，选一个点深挖到穿为止；要么是“毛毛虫模式”，每次爬升一截，完成一次跃迁。想短期吃成胖子，不太现实。

十二、现阶段做AI，对标互联网是错位的，更该对比通信/IT行业。它们的成长节奏、市场教育与盈利周期，更有参照意义。

十三、将来真正的AI 2.0/元宇宙社交产品，核心看点不是“人机社交”，而是“AI与AI互动，人去围观和消费AI生成的内容”。那不是游戏，更像一种生活方式。

这13条认知，每一条都可以延伸出很多思考。如果你也在做AI方向的产品或投资，建议把这份清单收藏起来，定期对照复盘。
