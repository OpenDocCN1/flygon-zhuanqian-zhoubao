# 赚钱有术里的一句话，让我单月入账15w+

大家好，我是行舟。做了三年抖音编导，今年3月辞职，开始做自己的号。目前粉丝7.2万，8月单月变现15w+，背后其实踩了不少坑。

之前因为没有成绩，我一直不好意思在赚钱里开口分享。后来无意间看到赚钱里的一句话，照着执行后，收益突然涨了十几倍，一个月就做到了15w+。这句话具体是什么，我会在下面的飞书正文里细说。

先放上完整内容：https://lspknkwu7b.feishu.cn/wiki/ALctwvFqpiIRBvkiOXPcNyAgnzb?from=from_copylink

今天想聊的是：普通人怎么从0到1，做一个能赚钱的抖音号。这也是赚钱教会我的——真诚利他。我因为赚钱拿到了一点结果，也想把方法传递出去，给更多和我一样的普通人一点希望感。

为了让你看得更清楚，我会按时间线把整个项目拆开，尽量把遇到的每个问题、对应的解法都写明白。看完之后，怎么策划账号、怎么设计变现产品、怎么快速起号，这些大家最头疼的事，基本都能找到一套可以直接用、能落地的思路。
