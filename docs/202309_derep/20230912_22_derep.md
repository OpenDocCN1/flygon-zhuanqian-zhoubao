# 指令工程师的新宠：从 0 到 1 了解结构化 Prompt

最近逛社区的时候，你有没有被一些看起来像代码的 prompt 指令刷过屏？乍一看有点像编程语言，细看又好像有某种规律。不少朋友在后台问我：这玩意儿到底是怎么写出来的？其实，这就是所谓“结构化 Prompt”。

我是一个互联网公司的企业培训师，平时的工作就是和各种知识打交道。前段时间我刚好系统研究过结构化 Prompt 的玩法，自己也动手写过几个，算是有了一点小心得。趁着这波热度，我就把自己梳理到的信息整理出来，给想入门的朋友一份接地气的参考指南。

这篇内容我会按四个板块来讲：

1. 结构化 Prompt 到底是什么（概念拆解）
2. 为什么越来越多人推荐用它（核心理由）
3. 怎样才能高效地写出一个结构化 Prompt（实操方法）
4. 结构化 Prompt 和普通文字型 Prompt 的区别在哪（对比分析）
