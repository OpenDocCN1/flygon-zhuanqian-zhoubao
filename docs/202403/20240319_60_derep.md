# 不是所有选择都值得反复纠结，分清单向门和双向门
作者：龙哥

贝佐斯在给投资者的信里，对“决策”做过一个很清晰的分层。

他说，世界上存在一种决定，一旦迈出就回不头了。这类选择是单向门，走进去之后发现不对劲，也无法回到出发点之前的状态。恰好是因为不可逆，所以必须放慢节奏，慎之又慎，多角度权衡，甚至需要集体讨论来对冲风险。

与之相对，绝大多数的日常决策其实是双向门。你可以先迈进去试试水温，觉得不合适立刻调头，成本也有限。正是这种可逆性，让这类决定不必层层上报，完全可以交给团队一线去拍板、去试错。

归根结底，判断一个决策该不该你亲自扛住，关键看它是不是单向门。是，就慢下来；不是，就放手去做。
