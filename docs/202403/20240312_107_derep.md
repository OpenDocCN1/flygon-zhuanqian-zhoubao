# 尽量不要通过「向他人证明自己」的方式去构建影响力
作者：龙哥

想建立真正的影响力？先别急着向别人证明你自己。

这件事很难走通，原因很现实：在理性层面，别人很难准确衡量你的价值；在感性层面，也没多少人真心在意你的情绪。你永远不可能让所有人都满意。更麻烦的是，一旦陷入“证明自己”的循环，你会被迫做许多低意义的事去讨好别人，结果时间被消耗、精力被掏空，机会成本高得惊人。

还有一层被忽略的风险：“证明自己是对的”很容易变成执念，越聪明的人越容易中招。这种执念像一把双刃剑——低谷时能推你一把，但也会让你越来越偏执，忽略掉真正重要的事。

所以，不如换一种策略：把力气放在“为他人提供帮助”上。你的价值，不是靠说服别人来确认的，而是靠真正帮到别人来实现的。用心服务他人，就是最好的影响力。
