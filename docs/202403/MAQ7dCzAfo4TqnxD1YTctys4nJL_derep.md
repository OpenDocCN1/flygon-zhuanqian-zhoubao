# 一个从0到负数的实战复盘：我想明白了，赚到100万以前我缺的不是机会

> 来源：[https://wxbxp20afbt.feishu.cn/docx/MAQ7dCzAfo4TqnxD1YTctys4nJL](https://wxbxp20afbt.feishu.cn/docx/MAQ7dCzAfo4TqnxD1YTctys4nJL)

这是我第一次把自己的踩坑路公开出来写成复盘，算是一份从负数起步的思考笔记。

先说结论，如果我想真的赚到100万，在动手之前，我得先具备这几件事。

# 一、先把自己看明白了，别用错力气

知己知彼，才能不白费功夫。

奇怪的是，我们总觉得摸清别人难，摸清自己很容易。跟别人相处久了还能看走眼，而跟自己相处最久的人，偏偏最容易被自己骗。

回看我做过的一堆项目，死的根源之一就是启动前对自我的判断失准。我总信“逼一逼就对了”，却忘了我不是那种能被外力逼出来的人。只有自己发自内心的想做，才会持续；否则哪怕已经到了退无可退的地步，最后也只能摆烂。

想赚100万，第一步不是找项目，是先把自己盘明白：什么能做，什么不能做。

怎么判断能不能做？我现在用的笨办法是把项目拆成关键动作，然后给自己打分。

举个还算成的例子，小红书做个人号变现。
人设搭建 我给自己6分
找对标号 我给自己7分
像素级抄作业 我给自己7分
日更 我给自己6分
网感 我给自己8分
总分34分。我之前定的经验是，总分超过60%，才值得上。

再看一个翻车的例子，闲鱼电商。
账号包装 9分
找靠谱上游 2分
天天上新 2分
定价 5分
售前售后话术 2分
发货 3分
总分23分，根本不够。尤其是“天天上新”这一步，我开始前以为自己能打7分，结果实际连2分都不到。

这种打分肯定有失真，后来我才发现要靠两件事校准：一次次的实操经验，以及对自己底层特质的理解，比如细不细心、有没有审美、能不能坚持。

# 二、别空谈目标，先做具体的事，再去复盘

计划和复盘的前提，是你手上真有一个正在进行的东西。

“一年赚100万”这种目标太大，拿来做计划只会脑子发懵：我现在该看书还是先调研还是直接上手？信息太多根本下不去手。

不如直接挑一个项目先干。目标变具体了，计划自然就具体了。

比如小红书，我把目标拆成“一个月涨粉1000”，计划就变成了：找20个对标号，建一个选题库，按节奏发。

复盘就是看计划执行下来哪里顺哪里卡。我这个人是典型的P型人格，做完整计划对我来说很吃力，执行到一半就乱了，更别说复盘。于是我决定把这段时间的经历摊开来复盘一次。

## 起点

2023年6月，我从体制内的授薪律师变成独立律师，收入没了，自由大了。
小红书正好帮我接到几个案子，我就想着独立后好好做内容。结果这是我第一次高估自己的执行力。
独立后我没去研究图文怎么发、视频怎么拍，更做不到稳定更新。因为时间太空反而更散，最后什么都没产出。焦虑慢慢冒出来。
第一次“逼自己一把”宣告失败，卡点是执行力。

## 转折

一个睡不着的夜晚，我满脑子都是案源、生计、钱途。有的焦虑是杞人忧天，有的焦虑是自己作的。我属于后者，明明有路可走，就是不敢迈步。
那晚我遇到了生财，报了三天体验营。那三天打开了我的认知：原来钱可以这样赚。
之后我交了学费正式加入，幻想着能赚到第一桶金。但又犯了老毛病：没系统看使用手册和精华帖，看得越多越乱。后来是靠七小的整理帖才理顺。

## 第一次试水

在生财的第一单是做快手直播切片。身边人都在做，都说赚钱，我就觉得这是唯一真相。
花了980跟了个项目，目标月入过万。
现实是：每天剪辑至少两小时，久坐压抑；播放量差，出单少，评论区全是负面；我又高估了耐心。
两周就放弃了。复盘：剪辑不熟练、平台不熟、没意识到堆量有多重要、耐心和执行力不够。

## 第二次试水

切片失败后我对线上有点失望，跟朋友去线下做了POS机。朋友说随便做做也有几千。
我花1666加入了团队，后面又花5000买设备学习。做了几个客户后天气变冷、身体扛不住，加上本身就懒，就停了。
复盘：没提前做行业调研，POS属于监管行业不好做；我是个I人，不适合电话轰炸和跑线下；我给自己定过成本线，现场被忽悠后又破规；坚持不足，被拒绝一次就怂了。

## 沉寂期

POS机后我又陷入停滞。钱花了心里难受，更难受的是我发现自己有重复的卡点，却说不清是什么。怕再折腾又白忙，于是停下来读书。看了创业、财商、理财，眼界是开了，但手里没项目，还是迷茫。
复盘下来，预期和结果总差太多。核心问题还是：不了解自己、不了解项目、不会解决问题、总幻想、执行不到位。

## 再出发

2024年3月春天，我又报了几个方向：海外短剧、闲鱼高客单、有知有行投资课。短剧和切片像，闲鱼我也翻车过。这次想从哪里跌倒就在哪里爬起来，给自己一次重新校准的机会。

# 三、极致和专注，别贪多

最近在读雷军的创业史，翻来覆去就是两件事：专注和极致。
极致就是把一件事做到再也优化不了；专注就是做一件事时心里只装这一件事。
我之前爱用“死磕”这个词，后来觉得它太硬。拆成极致和专注更清楚。
小红书说的像素级模仿就是一种极致，新手的第一步就是把好东西抄到位。
专注就是一心一意，像对待伴侣一样对待项目，别一边吃碗里的，一边惦记锅里的。少即是多。

# 四、执行要带脑子，也要发自内心

1. 带思考地执行
每个动作背后都有逻辑。知道怎么做，还要知道为什么这么做，做了会怎样，能不能更好。我们是项目的主人，不是执行机器。
2. 发自内心地执行
我不算勤快人，不喜欢被逼。想改变，就得找自己喜欢或至少不排斥的方向。
如果项目要花钱，前期一定要调研透，别带着“逼自己赚钱”的恶心心态去做。
如果项目零成本，可以多试试，试多了自然知道适合自己的是什么。
发自内心并不容易，因为人心会变，这就又回到第一点：要认识当下的自己，也要预判未来的自己。

# 五、信息要取舍，别封闭也别被淹没

刚加入生财时，我一天刷几百帖，看到的项目越多越想做，结果什么都没做成。后来又一刀切不看，认知就落后了。
现在我的做法是：只看跟当前状态和在做的项目相关的精华，偶尔看风向标。既不被信息关掉，也不过载。

# 六、对链接的理解要正过来

对E人来说，链接是本能。对我这个I人来说，链接很费劲。我不知道说什么，怎么互动。试过加人、刷朋友圈，结果本末倒置。
后来我明白，链接是结果，不是目标。当你真诚、利他时，链接自然发生。
想做朋友圈运营，就发有价值的内容，而不是为了存在感发废话。先相信自己的价值，分享出去，价值才会放大。

# 七、给失败一点时间

三国里曹操说过：失败不可怕，可怕的是心气败了。
失败多了，你才知道怎么成功。失败的价值不在失败本身，而在复盘和改进。
对自己耐心一点，对失败耐心一点，别急着变现，欲速则不达，慢即是快。
