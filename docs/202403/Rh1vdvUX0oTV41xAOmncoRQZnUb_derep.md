# 新公司法落地后，赚钱老板们必须搞懂的45个关键点



新公司法已于2023年12月29日完成修订并生效，它是我国社会主义市场经济运行的基石性法律。赚钱圈里不少朋友走的是超级个体路线，但一旦触及融资、合伙，就绕不开公司法里关于股东责任、股权流转、利润分配、表决权等一系列规则。

为此我们梳理出新公司法核心45问，帮各位老板对有限责任公司建立起基础认知，先把潜在风险挡在门外。

温馨提示：本次问答仅面向有限责任公司

# 公司基础概念篇

# 1、公司和股东到底是什么关系？

公司由股东出资设立，用全体财产对外承担债务。股东仅以认缴出资额或所持股份为限，对公司负责。

老板们要明白：这是公司法的第一性原理。举例来说，公司注册资本100万，负债1000万，公司先用全部财产承担，资不抵债破产清算，股东最多补足认缴的100万。

成立公司本质是建防火墙，将个人风险与公司风险切割，从一人承担转向公司主体承担。

# 2、怎么判断一个人是不是股东？

设立阶段，公司章程必须载明股东名单，登记机关据此公示。设立后公司要备置股东名册并记载主体、持股等信息，同时向股东发放出资证明书。

实践提醒：套路多，有人自称股东但工商信息里并无其名，必须谨慎。内部认定以股东名册、章程、出资事实和权利行使综合判断；对外则以登记信息为准，具有公示效力，对善意第三人有效。

# 3、往公司账户打钱就等于成为股东了吗？

资金投入是否构成股东资格，要看三个维度：出资流程是否合规，如增资是否经决议、股权转让是否完成变更登记；资金是否稳定，是否存在抽逃情形；是否实际行使股东权利，如参与表决、分红等。

老板注意：有钱的人常说“这个项目不错，快打钱”。为避免肉包子打狗，投资入股一定要备注出资款、打入公司账户、签署协议并完成登记。仅对私人转账、仅🛰️沟通、名册与章程未变更、未行使股东权利，通常不被认定为股东。

# 4、虚拟股权和真实股权有何不同？

股权激励中常见的虚拟股，与实股逻辑相反。实股需工商登记公示，虚拟股不登记，主要依公司与员工的约定，操作更灵活，不改变公司股权结构。

注意：虚拟股权一般不参与经营决策，只享有约定的分红权益。实践中让员工为虚拟股权付费或承担经营风险，通常不被支持。可约定获取分红的条件及丧失情形，例如离职后不再享有。

# 5、公司资金能放进个人账户吗？

公司不得另立账簿，资金不得以个人名义开立账户存储。

现实中公私混用、财务制度缺失，在一人公司或小股东查账时风险极高。

# 6、分公司和子公司怎么选？

子公司具备法人资格，独立承担民事责任，与母公司隔离。分公司无法人资格，债务由总公司承担。

业务扩张到异地时，选择不同会影响风险边界，子公司风险独立，分公司债务会上溯至总公司。

# 公司设立篇

# 1、公司登记有什么法律效力？

设立公司须依法申请登记，变更事项须办理变更登记。未经登记或变更，不得对抗善意第三人。

这是新法修订要点，实践中“一股二卖”颇多，出资方未及时变更登记、未行使权利，后续转让人已登记且为善意，股权可能就此易主。

# 2、设立公司时有哪些要提前想好的事？

有限责任公司设立时，股东可签署设立协议，明确设立过程中的权利义务。

这是新增规定。发起设立常因分歧中断，提前约定可最大限度降风险。

# 3、公司没设立成功，钱能要回来吗？

公司未成立，法律后果由设立时的股东承担，多人设立则承担连带责任。对外，各发起人对设立费用和债务承担无过错连带清偿责任；对内，若无约定则按分红比例分担。

给自己一个问句：失败怎么办。新法预留了空间，建议提前约定出资比例、期限、未出资责任、设立失败退还出资、费用承担与结算方式等，例如协议签署后1个月内完成注册，否则退还投资款。

# 4、设立期间以个人名义签约，责任谁担？

有限责任公司设立前的民事活动，其后果由公司承受。若股东以个人名义对外签约，第三人可选择向公司或股东主张。

设立股东因履行设立职责致人损害，由公司或无过错股东先行赔偿后追偿过错方。

建议设立期尽量以公司名义对外签署。

# 5、夫妻一方在公司设立中担责，另一方要担吗？

一般不需要，除非债务属于夫妻共同债务，如共债共签、事后追认等。

共同债务认定严格，除非配偶参与经营、担保或追认，通常不牵连。

# 6、公司章程有什么用？

章程是公司的小宪法，股东意思自治空间很大，如利润分配、对外担保、决议效力等。

公司法一半讲资本一半讲治理，除强制性规定外，大量事项可由章程约定。切勿套用模板，应按自身需求定制。

# 7、法定代表人必须股东担任吗？

法定代表人按章程由执行公司事务的董事或经理担任。

新法放宽了限制，不再限定董事长、执行董事或总经理，董事高管均可，与是否股东无必然联系。

# 8、法定代表人变更要注意什么？

董事或经理辞去其职务，视为同时辞去法定代表人。法定代表人离任后，公司应在30日内确定新的法定代表人。

法定代表人以公司名义行为后果由公司承担，因职务过错致害由公司先担责再向法定代表人追偿。

新法解决了此前易僵局的问题，更换法定代表人不必修改章程，也不需原法定代表人签字。

# 组织机构篇

# 1、有限责任公司必须设监事吗？

可按章程在董事会内设审计委员会，行使监事会职权，不设监事会或监事。董事会中的职工代表可进入审计委员会。

规模小或股东少的公司，可设一名监事，或经全体股东一致同意不设监事。

# 2、股东会、董事会可以远程开会吗？

可以采用电子通信方式召开并表决，公司章程另有规定除外。

飞书、腾讯会议、🛰️群等均属法律允许的范围。

# 3、决议效力有哪些情形？

违反法律行政法规的决议无效；程序违法或内容违反章程的可撤销；未召开会议、未表决、人数组成不足、表决票数不足等情形决议不成立。

被确认无效、撤销或不成立的决议，对善意相对人形成的民事法律关系不受影响。

小股东易被大股东压制，注意程序合规性与内容合法性。

新法将监事由强制项改为选择项，可设审计委员会或直接不设。

# 4、董监高的责任有哪些？

公司成立后董事会应核查出资，发现未按期足额出资应书面催缴，未及时履职致损需赔偿。

董监高与公司交易需向董事会或股东会报告并决议通过，其近亲属或控制企业交易亦同。不得利用职务为自己或他人谋取公司商业机会，除非报告并获决议通过。

不得自营或为他人经营同类业务。控股股东、实际控制人指示董监高损害公司或股东利益的，与之承担连带责任。

新法大幅强化董监高义务，建议防范资源外流，做好人、钱、账、渠道管控。

# 股东出资篇

# 1、出资要在章程约定期限内完成吗？

有限责任公司注册资本为登记的全体股东认缴出资额，股东应按章程缴纳。新增认缴注册资本需在5年内缴足。

存量公司过渡安排自2027年7月1日起执行，剩余出资期限超过5年的需在过渡期内调整至5年内，调整后最迟缴纳期限为2032年6月30日。

# 2、有限责任公司股东可出资哪些形式？

可货币出资，也可实物、知识产权、土地使用权、股权、债权等可货币估值且可转让的非货币财产，但法律禁止除外。

非货币出资需评估作价，货币出资需足额存入公司银行账户，非货币需办理权属转移。

股权、债权出资在新法中被明确列出。

# 3、股东未足额出资，其他股东要负责吗？

设立时股东未按章程实际缴纳出资，或实缴非货币财产价额显著低于认缴额的，其他设立股东需在出资不足范围内承担连带责任。

注意“坑队友”风险，你出资了，合伙人未出资，你也可能要担责。

# 4、未到出资期限转让股权，责任如何划分？

已认缴未到期股权转让的，由受让人承担缴纳出资义务，受让人未按期缴纳的，转让人承担补充责任。

若股权转让时存在未缴出资或高估作价情形，转让人与受让人对出资不足部分承担连带责任，但受让人不知且不应知道的除外。

股权转让需谨慎，受让人通常承担第一顺位责任。

# 5、未出资的股东会失权吗？

公司可发书面催缴书，宽限期不少于60日。宽限期届满仍未出资，公司经董事会决议可发失权通知，自通知发出日起股东丧失未缴出资对应的股权。

丧失股权应依法转让或相应减资注销，六个月内未处理由其他股东按出资比例补足。公司可按章程限制其分红、优先认购、剩余财产分配等权利。

# 6、抽逃出资有什么后果？

股东应返还抽逃出资额，致公司损失的，负有责任的董监高与该股东承担连带赔偿责任。

# 7、能按认缴比例分红吗？

有限责任公司可按实缴比例分红，也可按认缴比例或其他方式分红，未特别约定时按实缴比例分红，按认缴或其他方式需全体股东一致同意。

股东未履行出资或抽逃出资的，公司可合理限制其分红、优先认购、剩余财产分配等权利。

持股比例不等同于分红比例，可通过章程另行约定。

# 股东权利篇

# 1、股东知情权范围有哪些？

有权查阅、复制章程、股东名册、股东会记录、董事会决议、监事会决议及财务会计报告。

可要求查阅会计账簿、会计凭证，需书面说明目的。可委托中介机构查阅。可对全资子公司相关材料行使查阅权。

新法扩大了查阅范围至会计凭证，主体上可委托中介，无需股东在场。

# 2、表决权如何行使？

股东会由全体股东组成，是权力机构。股东会决议原则上按出资比例行使表决权，章程可另行规定。

表决权是核心权利，公司法采用资本多数决，但章程可约定“一事一人一票”等例外，并在特定情形下回避。

# 3、股东滥用权利会怎样？

股东应遵守法律、章程，不得滥用权利损害公司或其他股东，滥用应赔偿。

控股股东、实际控制人、董监高不得利用关联关系损害公司利益。

股东滥用法人独立及有限责任逃避债务严重损害债权人利益的，需对公司债务承担连带责任。多公司实施的，各公司承担连带责任。

控股股东滥用权利严重损害公司或股东利益的，其他股东可请求公司按合理价格收购其股权。

新《公司法》正式施行后，很多游戏规则悄悄变了。无论你是小股东、大股东，还是准备入场的投资人，以下几点值得花几分钟看完。

先说分红。以前小股东最怕什么？怕大股东左手倒右手，把利润藏在关联公司，或者弄个空壳公司背负债，明明公司赚了钱却一分不派。现在不一样了，如果控股股东滥用权利，导致公司不分配利润，小股东可以请求公司回购自己的股份——这是新法给的一件重要武器。

分红也不是想怎么分就怎么分。如果公司不按规矩向股东分配利润，拿到的股东得把款项退还；要是因此给公司造成损失，股东以及负有责任的董事、监事、高级管理人员都要承担赔偿责任。过去最多是退还，现在加上了赔偿，堵住了“借分红掏空公司”的路。

分红时间也有硬要求：股东会作出分配利润的决议后，董事会必须在六个月之内把红利发下去。当然，一般主张分红得先有一份股东会决议；否则法院可能认为分配盈余属于公司自治而不支持。但要是大股东滥用权利导致不分配、损害其他股东利益，那又另说。

再看股权转让。新法把原来的“同意权”拿掉了：股东之间互相转让，想转就转，不用别人点头。对外转让时，只需书面通知其他股东，把转让数量、价格、支付方式和期限等讲清楚，其他股东在同等条件下有优先购买权；三十天内没答复，视为放弃。多个股东都想买，先协商购买比例，协商不成的，按转让时各自的出资比例来行使权利。公司章程有特别规定的，从其规定。另外，受让人从被记载于股东名册那一刻起，就能向公司主张股东权利。

转让手续也明确多了：股东转让股权后，应当书面请求公司变更股东名册；需要变更登记的，还要请求公司去登记机关办理。公司拒绝或在合理期限内不理睬，转让人、受让人都可以起诉。同时，公司要及时注销原股东的出资证明书，向新股东签发出资证明书，并修改公司章程和股东名册。注意，这次修改章程不用再经股东会表决。如果公司压根没有股东名册或出资证明书，也别慌，通过修改章程、实际行使股东权利并完成变更登记，同样能达到效果。

公司章程能不能直接禁止股东对外转让股权？不能搞绝对禁止。有限公司有人合性，允许适度限制，但股权本质是财产权，必须能流通。想限制可以，但得留下救济出口，比如由公司回购，否则“绝对禁止转让”的约定会被认定为无效。

签股权转让协议，别怕麻烦。支付方式、股权是否真实完整、有没有权利瑕疵或抽逃出资、其他股东的优先购买权是否处理干净、公司和原股东之间有没有特殊约定、变更登记和付款谁先谁后、税费谁承担、保密义务、违约责任、陈述与保证、争议解决条款，都要写清楚。协议漏掉核心内容、表述含糊、多份版本不一致，或者股权上有质押等权利负担、持股关系复杂、交易还要走审批，这些都会拖累交易，甚至让目标落空。说到底，股权交易是一笔投资，内部要看股权结构，中观要看公司盈亏，外部还要看行业前景。

夫妻一方名下股权，登记方能不能单独处分？可以。公司法认可的转让主体是股东本人，不是整个家庭。配偶对股权所代表的财产利益有间接权益，但股权本身不是夫妻共同财产。所以离婚时不知道对方有股权、或不知道股权值多少钱，签了“各自名下财产归各自所有”再想反悔，很难。

员工持股常见的“人走股留”条款，离职就得退回股权。这种条款只要不存在法定无效事由，并且征得员工同意，就是有效的。想让它靠得住，最好让持股员工签字确认。

一人公司转让后，债务怎么办？先按双方协议处理；没有约定的话，转让前发生的债务由原股东在出资范围内承担，转让后的债务由新股东在出资范围内承担。但无论股权转没转，只要股东不能证明公司财产独立于个人财产，都对公司债务承担连带责任。实践中一人公司股东经常被一并起诉，就是这个原因。夫妻持股容易被视为利益一致、实质单一，也有类似风险。选择公司类型，一定要结合业务实际。

自然人股东去世后，合法继承人可以继承股东资格，除非公司章程另有规定。这个问题容易被忽略，最好提前想清楚。

减资的程序要记牢：先编制资产负债表和财产清单，股东会决议后十天内通知债权人，三十天内对外公告。接到通知的债权人三十天内、没接到通知的债权人公告后四十五天内，都可以要求公司清偿债务或提供担保。减资原则上按股东出资或持股比例进行，除非法律另有规定，或者有限公司全体股东另有约定、股份公司章程另有规定。违法减资的，股东要把收到的钱退回去，出资被减免的恢复原状；给公司造成损失的，股东和负有责任的董事、监事、高级管理人员都得担责。今年减资是个热点，但千万别为了省事踩线。

增资时，老股东在同等条件下有权按实缴出资比例优先认缴；当然，全体股东也可以约定不按这个比例来。

公司合并，合并各方的债权债务由合并后存续或新设的公司承接；公司分立，分立前的债务由分立后的公司承担连带责任，但公司在分立前与债权人另有书面协议的除外。合并分立之前一定要做尽调，把资产负债表看清楚，别花大代价买回一个坑。

简易注销通道好用，但前提是公司没产生债务，或债务已清偿完毕，并且全体股东作出承诺。公告期至少二十天，期满无异议，二十天内再去申请注销。股东承诺不实的，要对注销前的债务承担连带责任。所以律师看到公司未经清算就注销，反而高兴——追股东责任的路径打开了。

其他几个高频问题也要提一下：公司对外担保，要按章程规定由董事会或股东会决议，章程设了总额或单笔限额的，不能超限；为股东或实控人担保，必须经股东会决议，被担保的股东不得参与表决，由出席会议的其他股东所持表决权过半数通过。大股东一家独大时，很容易暗箱操作对外担保，章程才是最重要的防线。

股东在公司上班，能不能拿报酬？能。股东以个人身份接受公司管理、提供劳动，就与公司构成劳动关系或劳务关系。实践中缴社保、签劳动合同、定期发工资，基本会被认定存在劳动关系，公司不能白用。报酬问题最好事先约定清楚。

最后说股权代持。实际出资人和名义股东签的代持合同，不存在法定无效情形的，就有效。实际出资人履行出资义务后，可以就投资收益向名义股东主张权利；名义股东拿股东名册、工商登记来否认，法院不支持。但实际出资人想变更登记、成为登记股东，必须经过其他股东半数以上同意。代持风险就在这：名义股东才是法律上的股东，实际出资人不是。想避险，一要慎选代持人，把道德风险和税务风险都考虑进去；二要签一份详细严谨的代持协议；三要参与公司经营管理；四可以用个性化章程限制名义股东处分股权，比如不得擅自转让或质押。

新公司法信息量很大，这篇文章只挑了股东最关心的几个点。真遇到具体问题，还是要找专业律师把关。
