# 视频号小众赛道实操复盘，床上夫妻情感动漫对话玩法，变现可观新手看完即可操作

大家好，我是龙哥。今天来聊一个我们去年在视频号上跑通的小众赛道——夫妻情感对话动漫。简单说，就是把夫妻躺在床上或窝在沙发里聊天的场景，用动漫形式做出来，专门打共鸣感。当时这个方向做的人还不多，只要执行力到位，靠创作者分成计划拿收益基本没什么问题。可惜过年期间停更了一段时间，账号慢慢就废了……所以这次我把整个玩法重新整理出来，做一次完整实操复盘，分享给大家。

这类短视频在视频号上流量相当不错。核心卖点就是“床上夫妻对话”这个场景，天生吸引人点击。内容形式也很多，可以是躲被窝里聊，也可以是瘫沙发上聊，30到60秒就能搞定。再往大了说，情感对话赛道还能延伸成医患对话、司机乘客对话等，很多变体都值得尝试。

第一个板块：项目介绍

夫妻对话动漫是很有意思的短视频形态，因为特别贴近生活，天生带有亲和力，平台给的流量也不低，非常适合用来起号。市面上甚至有人拿这个玩法做收费培训，价格还不便宜。其实只要作品能跑起来，粉丝量、点赞量上去了，变现根本不是问题。

![](img/158de695e3f52c68da9163cb1dcb278c.png)

做到后期，完全可以不露脸、不直播，依然有多种变现渠道。平台方面不用纠结，优先在视频号和抖音同步更新，时间充裕的话，也可以顺手同步到快手和📕。

![](img/b7b80a4addc15c2a41dca0c4665a1055.png)

第二个板块：前期准备

先说账号。建议准备两个🛰️号，直接在🛰️里开通视频号。注意一机一卡一号，两个号同时养，哪个号推荐量高、点赞多、跑得快，就主推哪个。这就是赛马模式。

![](img/055bbd7a024614cf9003349e545d529f.png)

视频号的原创收益功能，粉丝满100就能开通。具体的快速涨粉方法，可以参考我星球里发过的那篇文章。

账号设置可以直接参考同行。视频号的简介里可以放🛰️号，方便引流到私域做成交。同行怎么设置，你就怎么模仿，也可以去抖音看看，把合适的做法拿过来用。

![](img/0c980a845cdd680daeeb9ff848fce543.png)

找对标账号的时候，直接挑那些已经火了的视频去模仿。昵称要有辨识度，比如“某某动漫”“某某夫妻情感对话”。头像、背景尽量用动漫人物，资料简单介绍下即可。前期不要留联系方式，尤其抖音，权重不够时留联系方式容易封号，等权重起来再留也不迟。

![](img/99c1e8f6463a7bbf07cc6d39918392e7.png)

第三个板块：操作流程

开始动手前，先把素材备齐。可以自己去📕、抖音、快手找，也可以去淘宝买动漫素材。我这里也准备了一份现成的，网盘自取：

链接：https://pan.baidu.com/s/1yC_jJRFiz7Mk2YwX7Dyw6Q?pwd=sgti
提取码：sgti

![](img/ca34fa0c35c137c836cf30250aef24e7.png)

制作软件要用到“画世界Pro”，自己下载就行。这款软件是收费的，有成本，想做的话可以提前评估一下。

来看软件界面。打开之后第一次是空白画布，点中间的加号，会出现很多尺寸，比如9:16、3:4、1:1。抖音一般用9:16竖屏，横屏就选16:9，根据发布平台来定。大部分时候选9:16。另外强烈建议配一支电容笔，不然很难画出细腻效果。

![](img/a872a59ca51766e2feb510bee0ee1590.png)

左边工具栏先熟悉一下：第一支笔，笔刷流量直接拉满到100，最常用的是圆珠笔；第二个柔边笔基本用不上；第三个是橡皮擦，用于擦掉多余的颜色和线条。

![](img/8dce23b0dfeeedf0f899ee9f09bd10ec.png)

再往下是色盘，从左到右颜色由浅到深，下方滑块控制明暗。柳叶笔基本用不到，可以忽略。旁边那个方块图标里藏着一堆重要工具：移动、选区、滤镜、油漆桶、吸管、形状、动画、导入，这些后面都会用到。

![](img/c534de12160db43334cb2bf318751dfd.png)

底部S是调节笔刷大小，一般常用7号、8号。下面的O也要注意，它控制的是颜色深浅，拉到最底颜色很浅，往上拉就变深。

![](img/8f4ad2f3a463df813d2693daa6088116.png)

右上角第一个是图层功能，可以新建图层；不需要的图层可以点眼睛隐藏，也可以直接删除。背景色可以调整。有一个开关叫“修正抖动”，这项务必要开启——安卓用户记得打开，苹果用户就不用管了。开了之后线条会更顺滑。

![](img/e72f58bcdb57fcfd49a6a022676b1d6e.png)

箭头是导出按钮，一般导出PNG图片格式，做动图就导出GIF。还有锁定图层、洋葱皮功能。洋葱皮打开后，当前图层正常显示，其他图层半透明，方便制作动画帧时对齐位置，但日常基本用不到。

接下来是完整的人物制作教程：

1、找素材。可以打开📕搜索“Q版人物”，里面有很多好看的角色。素材库里的图也能直接用，喜欢哪个就保存哪个。

![](img/26b072fdda5abf71efb9bfe8f6b91428.png)
![](img/b2e909e85509547da0669ac1c49b8e36.png)

2、画头部。打开画世界，新建9:16画布，把选好的图片导入进来。然后新建图层，把原图层的透明度调到70左右。画笔用7号或8号，O拉到最大。

![](img/25dbf7c1291220da9520ed119b9f6664.png)
![](img/b222bde27fb64e3162ddfbda7f58fabc.png)
![](img/a954820ecdaa0100ee54a8f94d76b918.png)
![](img/265ca318b085dcbe9df5a781c0315fee.png)

3、描线。选中图层后，用“形状”里的“曲线”功能去勾勒轮廓。注意要在复制出来的图层上操作，不要直接画在原图上。线条接口一定要接好。耳朵如果直接画不好看，就用曲线沿着轮廓勾，熟练之后会越来越好。画错了就撤回重来。头发、脸、发饰都按这个方法描出来。

![](img/7f3970a34af4f6429376868db52e9b06.png)

4、填充颜色。线稿画好后开始上色。先把原图图层移到左上角，再把透明度拉高。填色之前，先复制一层线稿，在复制出来的图层上涂色。

![](img/36fd1a0d5641026a9099791528bf59ba.png)
![](img/1b3c34541ed297baf38b49be1886d1bf.png)

头发颜色可以自由选，用油漆桶填充。如果把握不准色差，就用吸管吸取原图上的颜色，再填上去，这样颜色几乎能和原图一致。

一些边角没填满的小地方，可以把画布放大，用画笔补涂。要注意：填色图层一定要放在黑色线稿图层的下方。涂的时候细心一些，把白色空隙填满，整体就差不多了。

![](img/f8ede3955b7ec6446cfe40dcdac915c5.png)
![](img/5a809d0b9c6f8f17ba7fd0acd8291652.png)
![](img/a4540d5914cde01a074ec6d54ed4c581.png)
![](img/0676c497d7c87cbccf9ee50f46a5baab.png)

头发搞定后，用同样方法涂发卡。发卡颜色可以参照原图，也可以选自己喜欢的，油漆桶填充后再用画笔修一下边角。

![](img/f7814858adcdf65222774a1d461f5906.png)

接着涂脸。新建一个图层，选粉嫩一点的颜色，类似肤色。如果拿不准，可以吸取原图脸部颜色来填。耳朵也要一起填充。

![](img/0e0ff8c5f1d7711348d0684582d3ce9b.png)
![](img/f6b99294587ba112611f351772e46660.png)
![](img/7df153167966ce09b08e7cb57a1bcee1.png)

5、加阴影。新建图层，把颜色调得比肤色稍深一点。用钢笔沿着边缘轻轻打上阴影。脸上、耳朵不要打太多，一点点就够，这样人物会更有立体感。

![](img/fc8a11b6e297d68dd6a09d7b3a2e109f.png)
![](img/e9226f0dc820614c3cb3b1a7da1f62c2.png)

头发阴影也是同理。新建图层，用吸管吸取头发颜色后稍微提亮一点，再用钢笔沿头发边缘勾画。

![](img/699ca267406bb02ed2cd7d9f6e4e7ae1.png)
![](img/7672eaabb4ab655c88eb98c48b06bea7.png)

接下来加腮红。先新建图层，吸管吸取肤色后往红色方向略调一点，然后拉到最亮。用“形状”里的椭圆，在两边脸颊各画一个小圆。再点击“滤镜”，选择“高斯模糊”，模糊度调到6或7，打勾。然后把腮红移动到合适位置，适当放大或缩小。

![](img/0500cc1b56d3f2b0208e381ff4bf5d2d.png)
![](img/9c9d8e9b9b8f7bdd43023b6cfb834141.png)
![](img/deffc873d579ec19e9e626e9287bb9ce.png)

一边腮红调好后，复制图层，用移动工具放到右边。这时腮红偶尔会跑到脸外面，解决办法是：把两个腮红图层向下合并；再把腮红图层拖到脸部图层的上方，点击箭头隐藏，超出脸部的部分就能自然消失。

![](img/4625b03b712415c742ebcf6728af3167.png)
![](img/94dc5962388f22f1e8bb6044e0bc52b5.png)
![](img/b78fe6d0ba99230837906375aae79222.png)

腮红完成后，就可以删除原图了。选中原图层左滑删除，关掉背景，点右上角箭头导出PNG格式，保存到相册。同时把模板保存为草稿。

![](img/c2027fc8f2461277ec2e17913b7edf2c.png)
![](img/a5a7dabbf5b370dc44945e0f1f3a7e3a.png)

6、画身体。再新建9:16画布，先把刚才做好的头部导入进来放到上方，再导入身体参考图。把身体图层拉到头部的下面，移动到合适位置，确定后把头部图层隐藏。然后在身体图层之上新建图层做描图，透明度调到70左右，选黑色，笔刷大小调到8号，用形状里的曲线工具去勾勒。衣服画好后，把原身体图层移到最上面，不透明度拉回100。

![](img/84a7d9d4acf6993c62b727d0a5346604.png)
![](img/eef99ad61bf26030aea1e24e80e69645.png)
![](img/25b7eddb094c721cd700ccedb24cce72.png)
![](img/c50da2cbbcccee963bd0bde97616e4b0.png)
![](img/c8c126a57e1dce351d866b0d3d9b9365.png)

填充颜色和头部是同样逻辑。新建图层放到衣服线稿下面，用吸管吸取原图衣服颜色，稍微加深或提亮，再用油漆桶把衣服、鞋子、袜子、包都填好。注意要点击所有相关图层去填充。

![](img/ccf5798dc37e26bcfb528334fe02d880.png)
![](img/6158bdd56be9544851eacbdfc9172fba.png)
![](img/f07b958cc8a8186ddf6a3f9407715879.png)

然后把头部图层的眼睛打开。手和腿的颜色要用脸部肤色来填，如果觉得太亮，可以适当调暗。衣服阴影也不能省：在衣服图层上新建图层，选一个比衣服颜色稍深一点的相近色，画笔调到7号，在裙子、袖子、手部位置轻轻扫过。做好后保存草稿，再继续后续操作。

![](img/0a08f1527c2c117cd74e4b81269058af.png)
![](img/fe49dc4ca33dc7310c775bc158667533.png)

下面做表情动图。

先导入女生的表情图片，确定后用“选区”里的套索工具，把一个表情比如“哭”选出来，剪切，新建图层，确定。然后把原表情图层的眼睛关掉，把截出来的表情图层拖到最上层，不然会被遮住。

![](img/2fd2ce4c4c5ca61bdc48dce7b08b727a.png)
![](img/52c066a14201398953d182d8c8916c35.png)
![](img/c7ee2088e9db805d903076b2363e45ec.png)
![](img/5335db8fb5e4d413a1314583b06ed31b.png)
![](img/f10adef1aa8b0077b20aab8d850874d4.png)

接着点工具栏里的“移动”，把表情水平翻转，调整大小和位置，也可以旋转。确定后再用同样方法把“张嘴”的表情截出来放进去，再加一滴眼泪。哭的表情做好后导出PNG。再把“闭嘴”表情图层打开，导出PNG。最后保存模板。

![](img/ea98631f6a8079c0f116b7eb4ffbb59c.png)
![](img/f2acb37120a5b5a4646bd44cf45ca665.png)

保存好了之后，重新打开画世界，新建9:16画布，把“张嘴”“闭嘴”两张PNG都导进去。删掉多余图层，背景色设为图层里没有的颜色。点“移动”并选择“自由”，把图层稍微往上拉一点点，不要太多。然后点“动画”，删除封面帧，再点击“设置”里的“从图层建立帧”，帧秒设为6秒，动画效果就出来了。最后点右上角箭头导出为GIF格式，存到相册。

做完之后关掉，再制作眨眼的动图。不需要重新保存，直接打开刚才保存的模板。把三个图层都关掉，只保留所有表情图层并拉到最上面。用选区选出正常眨眼的眼睛，剪切，新建图层，水平翻转，放到合适位置。确定后，在睁眼图层上新建一个图层，颜色选黑色，拉到100，再用“形状”里的曲线画出闭眼效果，打勾。

第四个板块：变现方式

这个玩法的变现路径非常清晰。前期可以直接靠视频号创作者分成计划拿收益，播放量上来就有钱。同时视频号简介里可以放🛰️号，把流量导向私域做成交。等账号权重和粉丝量上来之后，不露脸、不直播也能解锁更多变现玩法。总而言之，内容跑通以后，收益空间还是相当可观的。

好了，这次实操复盘就分享到这里。觉得有用的朋友可以点赞收藏，后续我还会继续拆解更多视频号玩法。

先从眨眼动效开始做起。把睁眼的状态先隐藏，让闭眼图层单独显示，这样闭眼帧就呈现出来了。接着把闭眼时嘴形和眉形单独圈出来，再与闭眼主体合并成一张完整的闭眼图层。睁眼和闭眼两张图分别保存为PNG，点导出、选相册、确认后退出编辑器。

![](img/b0fda5377bdac230c9c0d45604d5b73e.png)

重新进入软件，建立9:16的画布，把刚才生成的睁眼、闭眼素材都导入进来，先把底部自带图层清掉。背景色要特别注意挑选，选用画面里完全没有出现过的颜色，后期抠除会更干净。

先把闭眼图层隐藏，复制睁眼图层6次，再把闭眼图层打开置于中间位置，上下各放3个。点开方块进入动画面板，删除封面帧后使用从图层建立关键帧的功能，时长调到6秒，执行后眨眼序列就自动出来了。右上角导出为GIF动图，保存到相册确认后保存模板。全部做好后新建文件夹命名为“短发女生”，把模板统一归档。

再来看场景制作的办法。

抠背景的步骤：打开画世界新建9:16，先把要用到的素材导入，整体构图先理顺，比如窗帘、床、杯子等物件依次拖入描线。确定后先画窗帘：新建图层把不透明度降到70%，在新图层上操作。用形状工具描边，曲线好用就用曲线，怎么顺手怎么来，接口处一定要闭合，不然后期上色会出问题。窗帘描完进入下一步。

![](img/cf814765cddde0b268f1988b24b5e259.png)

![](img/07536345df295acb6e3b497538436e35.png)

![](img/3ca32604638e34d719e374dec030c825.png)

描好后把原图图层移开，填充不透明度调回100%，再新建一个图层做调色。颜色可自行决定，也可用吸管取原图的色调稍作加深再填充，不必完全照搬。涂完窗帘就算完成。接着删除原图层，把窗帘的线稿层与上色层向下合并，这样就能随意移动了。

接下来制作床：新建图层描床并上色，细节尽量精细。上色时记得全选图层再填充。完成后删掉原图，把床的描线与上色合并。还要加入被子，窗帘与床的摆放位置可以自由调整。把已做好的被子导入，布局调好后导出为PNG存相册。务必分别保存图层，窗帘单独保存、床单独保存，均导出为PNG。

最后是视频剪辑与发布流程。

先找配音素材：打开抖音搜索情感动画，挑近期点赞高的视频直接点赞收藏，也可关注发布者，后续可直接复用其音频。

找到音频后打开剪映点开始创作，把准备好的图片放入选高清添加。此时画面是黑的，需要额外加入背景：点加号在素材库搜索风景，比如夜景、窗外风景，收藏后加入。加入后选中后续素材向左滑找到切画中画，素材就会落到下层轨道。再点前方白色区域把它拉到开头，关闭背景素材的原声后拖动到合适位置。

![](img/56bb08c276ef87976097443c5669e822.png)

添加音乐：之前在抖音收藏的可以直接用抖音收藏导入，或复制链接到导入音乐粘贴后解析使用。音乐时长控制在20至30秒内，别超过四五十秒。无声音的尾部要分割删掉。背景是视频无法直接拉长，可复制多份：工具栏右滑找到复制，多复制几份。

把人物素材加进来，拉到和音乐对齐，多余部分删除。然后添加头像：点新增画中画，例如女生开口说话的片段导入后右滑找到抠像色度抠像，选取蓝色，强度约6到10，阴影适度调到10左右后确认并拖到合适位置。

再添加男生部分：点新增画中画，例如开头睁眼后面哭的表情。先导入男生睁眼闭眼的视频做抠像色度抠像，用取色器选色后缩小放到合适位置。男生后面也可再加一个哭的表情。所有表情与音频必须对齐。最后给整体视频加暗角效果：右滑找到调节暗角，调到15左右即可，四周会略显沉。导出时注意对齐，设置1080P、帧率60、码率较高导出。

这类项目的变现方式比较多，常见的是：

1、创作者广告分成计划。动漫风格内容容易引发观众回忆与讨论，评论区互动多，经典台词也易引发共鸣。广告由腾讯系统自动匹配，无需手动干预也不影响播放，只要声明原创发布即可。视频号广告分成目前仍属蓝海红利期，建议尽快实操。
