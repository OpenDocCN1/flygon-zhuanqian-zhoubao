# 原钉钉副总裁创业杀入 AI Agent 赛道，获亿元融资

在AI创业的热潮中，又迎来了一位重量级玩家。曾担任钉钉副总裁的资深行业大佬，近期正式下场，将创业方向锁定在AI Agent领域，并已顺利斩获亿元级别的首轮融资。

这条消息在创投圈引发了不少关注。从大厂高管到独立创业者，这位曾经的钉钉核心成员，选择在人工智能最热的赛道上开启新旅程。亿元融资的落地，也意味着资本市场对AI Agent方向以及这位创业者的双重认可。

据了解，AI Agent被视为继大模型之后的下一个关键应用方向，不少技术团队和资本都在积极布局。此次前钉钉副总裁的加入，无疑会让这个赛道的竞争更加有看点。大佬的履历背景、对行业的理解，再加上真金白银的投入，后续会做出怎样的产品，值得保持关注。
