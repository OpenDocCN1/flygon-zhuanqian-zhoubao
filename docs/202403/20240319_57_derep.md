# 想活得久、活得好，这套长寿组合拳可以抄

最近刷到一份很干的长寿笔记，核心就三句话：想长寿，运动、饮食、睡眠，一样都不能少。

**先说运动，别只会一种。**
真正对寿命有帮助的是三维训练。
心肺耐力要跟上，比如慢跑和间歇冲刺跑，能把心脏练得更强。
力量储备要够，比如深蹲和负重爬山，让身体不轻易被岁月偷走肌肉。
柔韧和稳定性也要练，普拉提、瑜伽这类动作能保持关节灵活、身体不僵。

**再说饮食，少即是多。**
逻辑是间歇性断食，总体吃得更少。
配上低糖，减少身体的代谢负担。
同时提高蛋白摄入，守住肌肉和修复能力。

**最后是睡眠，节律比时长更重要。**
保持昼夜节律，早睡早起让身体有规律。
夜间睡够 8-9 小时高质量睡眠，是修复的黄金时间。
中午补充一个短暂小憩，快速回血不犯困。

长寿 = 运动 + 饮食 + 睡眠，三者叠加才有效。
