# 一年裸辞创业，我把知识管理做到月入5万：一切都归功于朋友圈
作者：龙哥



大家好，我是龙哥，现任知识管理教练，也是“知识管理五维模型”的提出者。

圈内朋友也叫我A大、A哥，叫法随意，舒服就好。

我之前在互联网公司做了五年半的设计师，一年前选择裸辞出来单干，主攻知识管理这条赛道。凭内容创业，我终于实现了自给自足的创业目标。

创业满一年，累计营收已经超过30万，今年1月单月首次站上5万+。

![](img/5f7da536dd3c20e7b6ed7e5099333042.png)

和现在相比，去年5月之前的我，每个月到手也就五六千，房贷、信用卡、分期压得喘不过气。

我当时的心理预期很保守，只要一年能做到月入1万就算成功。

结果不到一年，月收入直接翻了十倍，完全超出了我的设想。

回头想想在职场的时光，恍若隔世。也就是一年前，我还在做着每天995的生活。

那时候一天工作十多个小时，需求紧的时候直接通宵，把全部业余时间都榨干了，只为拿到一个好绩效、争取升职加薪。

现在每天工作3到5小时就够了，剩余的时间完全自由，看电影、打游戏、避高峰去旅游、养猫养花，都是我的日常。

可收入反而远超了曾经的工资。

很多同行好奇我1月份的营收结构，我梳理了一下，刨除老学员复购和CPS分成，80%的收入都来自朋友圈。

这80%里，绝大部分是我的IP知识管理一对一私教课，剩下小部分是刚起步运营的年度陪伴群。

所以，朋友圈无疑是我1月营收的核心引擎。

今天的分享，我就重点拆解一下，我在朋友圈做了哪些事，才让它拥有了吸粉又吸金的力量。

# 一、为什么我必须聊朋友圈

第一，正如上面所说，朋友圈是我每个月营收最稳定的来源，绝大多数成交都源自这里。

第二，我几乎不主动私聊推销，成交大多是被动进来的：有人直接私信说想报名，有人甚至上来就付款了。被动咨询的环节，我会用谱子销冠的聊天框架，转化率非常高。

第三，好多粉丝在评论区和私信里告诉我，他们特别爱刷我的朋友圈。

印象最深的是一个学员，被动进了陪伴群后跟我说：“你的内容和别人不一样，感觉很走心，所以想支持你。”

![](img/721144f9718e4180ae250cecbc890bb7.png)

还有一位做俱乐部的朋友，加我三天后就发来表白：“忍不住一直翻你的朋友圈，太有魅力了。”

六天后她看到私教发售的硬广，主动找我付了全款，期间我们没有任何谈单过程。

![](img/21a31074f64bf654c238a809b0171b64.png)

初一那天，我又被动成交了一单私教，她也是直接说想报名，而此前我俩只互相做过自我介绍。

![](img/66449072f5964f25197376aff38de0a2.png)

类似的反馈还有很多：

“刷你的朋友圈对我是一种滋养。”

“每天看你更新，有种想成为你一样的冲动，连追瓜都上瘾。”

“我是被A大的朋友圈吸引过来的，什么时候能出个21天打卡就好了”

“A大的文字有种魔力，把我深深钉住了。”

![](img/4b6d2ee6730719e0348a5b6e808950db.png)

1月5万+的突破，和朋友圈运营必然有强关联。那它到底为什么能成交？

# 二、朋友圈能成交的底层逻辑

我带过很多私教学员，他们常问我：我也有产品，也在发圈，为什么没人来问我？

这个问题归结起来就两类：

1.只在有产品时才发圈
2.发圈持续了，却很少露脸

先说第一类。

#### 1.有了产品才开始发圈

根源是一个错觉：定位和产品没确定，就不配发朋友圈。

等我准备好了再开始说。

实际上，这是一种本末倒置。你平时不发声，突然一天丢个产品出来，基本等于自说自话。

假设一个人长期不更新，某天突然发一个私教/社群/咨询的官宣。即便你正好有需求，你会直接买吗？

很难。陌生、没印象、没好感、没信任。

需求再强烈，决策成本也会吓退你。你会在心里反复质问：他能解决我的问题吗？靠谱吗？三观怎么样？会不会收钱就消失？

风险太高，人都是损失厌恶的。

我很多学员的成绩，都是从日更开始的。哪怕没定位、没产品，先把成长过程可视化，再做分销也能先赚点零花钱。

举个例子，我第七期私教的一个学员，裸辞做自媒体起步，零基础无定位，在我的督促下坚持日更。日更一段时间后去分销大佬的报童产品，一周轻松赚了三千多。

定位和产品当然重要，但绝不能成为你展示自己的阻碍。你得随时随地让更多人看见你。

芷蓝姐说过：再忙也要每天发圈，哪怕少也要发，就是为了让人记住你。这个时代，爆款不值钱，持续输出才值钱。

没人会记住你一年前的那个爆款，只会记住每天都在写字的你。

持续不间断的输出，才能不断展示专业和人格，积累记忆和信任，等你推出付费产品才有人买单。

再看第二类。

#### 2.持续发圈，但不展示自己

这是另一个典型误区。学员们确实在发，但朋友圈里找不到“他是谁”。

比如我正在带的一个学员，每天更新的内容无非是：早安鸡汤、产品卖点硬广、分销广告、偶尔几张美图。

问题不在于广告多，而在于几乎看不到她的真实存在。

我自己有在Notion里统计朋友圈的习惯，内容类型、发圈时间、点赞、咨询、评分全都记。日更半年后我发现一个惊人规律：高赞的几十条，几乎都在讲“我”。

一条加入了我的经历、故事的朋友圈，点赞量会明显高很多；没加入“我”的，基本沉没。

广告本应没人点赞，但当我把产品软广和我的故事、学员互动揉在一起时，依然能拿到不错的互动。

我越来越坚信：朋友圈的核心吸引力，就是围绕“你”展开。

靠谱说：你会筛出和你情绪共鸣、经历共鸣、价值观共鸣的人，他认可你这个人，自然会认可你的产品。

在私域，IP永远先于产品。

芷蓝姐说：内容一定要紧紧围绕自己，“真实”是内容创作者最无法被复制的武器。工具、逻辑、文笔都能抄，真实的生活抄不了。

小鹿说：IP的本质是，用户是奔着你这个人来的。同样一个产品，他更愿意信你，这就是IP的溢价。

客户爱看的关键，是你有没有把真实的自己摊开：生活状态、价值观、学习感悟、成长轨迹。每一次自我展示，都在让用户眼熟你、认同你、喜欢你、信任你。

大家不是讨厌广告，而是讨厌像机器人一样冷冰冰的复制粘贴文案。

我记得去年帮赚钱拉新时看到的现象：很多人去朋友圈分销，发的不是人，是链接。结果不仅没人买，还会被私信问：你是不是进传销了？被盗号了吧？割韭菜呢？

原因很简单，他们之前几乎没运营过朋友圈，没展示过自己，用户对他零认知。

把时间倒退两个月，如果他们一直在朋友圈晒生活、晒圈子、晒学习感悟、晒小成就、晒加入赚钱后的真实变化，再去分销，情况会完全不同。至少没人会怀疑。

我第五期的一位学员，在我的指导下持续展示真实自我，很快收获了几个铁粉，其中一个加好友第一天就被朋友圈种草，直接买了赚钱。

第六期专注身心灵赛道的学员，一开始输出很卡，到后来能无痛输出大量带自己的内容。她后来跟我说：“文章和朋友圈发出去，第一次见面的朋友直接付费，一周收了7500。”

持续发圈很重要，持续展示真实的自己更重要。

# 三、怎么展示自己，才能让朋友圈既吸粉又变现

知识管理的良性循环，除了输入书本内容，更要沉淀个人经历。个人经历是你亲身踩过的路，是独一无二的资产，比二手感悟更容易打动人。

一旦抓住心，在他有需求时，更愿意用付费来靠近你。

具体可以从这8个方向去做：

### 1.分享你的生活
美食、做饭、风景、宠物，一切有温度的日常。让用户感受到你是有血有肉、会生活的真实人。

### 2.分享童年故事
童年记忆是共通的，能唤醒情绪共鸣。

我常在传统节日发童年相关的记述。比如七夕会说小时候跟外婆学说的牛郎织女听悄悄话的故事，中秋会说父亲骑二八大杠买苏式月饼，吃五仁时挑掉红绿丝的细节。互动都很高。

### 3.分享弱点与软肋
IP不是完美无缺的人设，而是完整的真实。把内向、社恐这些缺点说出来，反而更受欢迎。

其中一条关于社恐的分享，就有超过5位客户跟我说是因为这条被打动才下单的。

![](img/8e085921624988abbcfe93abeca0fca9.png)

![](img/78213acdadbbb80746c4f21682373915.png)

### 4.分享烦心事及化解过程
把烦心事拍成朋友圈小电影：先有冲突，再有转折，最后有收尾。大家爱看这种有起伏的真实叙事。

比如有次跑公积金把材料带错了很郁闷，后来顺路逛了逛心情好了，就把它写成了朋友圈。每个“肥鸭子”都能变成生产资料。

![](img/6091ae0258421ac1fcb43cdacc9422e1.png)

### 5.分享小成就
过往的、刚发生的都行。用一次次小突破告诉用户，你一直在成长。大家喜欢看普通人变得不普通的过程。

比如我第一次被赚钱邀请做高手分享、第一次被思念老师邀请社群分享；第一次拿航海巨人、拿前三；2023年在flomo输出100万字……这些都是可展示的成长痕迹。

### 6.分享和学员、产品的故事
把广告故事化。电视剧广告会用剧情带产品，我们也可以。

比如熬夜做涨价海报，可以发成产品故事，顺带暗示即将涨价。拿到学员好评就发用户证言，收获首单就发成交故事，温和地提醒别人咨询。

### 7.分享问题与解决过程
直接给实用价值，建立信任。

我曾把pdf资源管理的痛点和解决办法整理成一条朋友圈，帮助到很多人。遇到棘手问题也可以先发互动圈征集智慧，解决后再发复盘圈，既提供价值又提升曝光。

### 8.记录生活里奇妙有趣的事
任何有感触的瞬間都要立刻记下来。

招线上小助理时发生的一个离奇故事，我当场记录下来创作，发出去收获大量点赞，后面还有两个人主动咨询私教并成交，一条故事带来了5k+营收。
