# 回来上班，别先定目标，先搭好系统
作者：龙哥

假期结束，很多人第一件事就是给自己列一堆要达成的目标：这个月要瘦几斤、要多做几个项目、要涨多少业绩。目标看起来很负责，但复工期的真正问题往往不是缺目标，而是执行到第三天就断链。

目标只能算系统的末端产物。系统才是每天能让你稳稳前行的底座。目标问的是“到哪里”，系统问的是“怎么做、怎么持续”。

节后最需要的是可重复、可自检的运转方式，而不是一次性的冲刺宣言。你可以保留目标，但要把它拆解进一套日常机制里：固定的复盘节奏、清晰的工作拆解、能及时反馈的数据。

系统的价值不在于瞬间的高光，而在于可持续的改进和成长。当流程跑通了，进步就不再靠意志力硬撑，而是靠习惯自然累积。

别让今年的复工，又从雄心勃勃的目标开始，然后悄无声息地回到原点。
