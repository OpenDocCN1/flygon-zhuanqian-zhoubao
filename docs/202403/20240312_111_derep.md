# 万店体量下的用户运营，他讲透了

杨鑫是锅圈会员业务负责人。最近，他围绕线下加盟连锁业态做了一次分享，聊的是自己对这个领域用户运营的理解，还有锅圈现有会员体系从搭建到运转的底层思考。

在这类覆盖数千家甚至上万家门店的业务里，用户运营往往不是单一的门店课题，而是一套需要通盘考虑的系统工程。杨鑫讲到的很多视角，可能正是品牌方和加盟商都在关心的问题。

如果你也从事会员运营、用户增长或连锁零售相关行业，这篇内容值得点开看看。
