# 全职自媒体3年，从负收入到月入10w+，这6条经验让我赚到了买房钱

嗨，我是卿久。97年出生，中文系毕业，全职做自媒体已经三年了。我运营着两个👸号，粉丝加起来超过18万。靠自媒体，我累计变现70w+，现在个人月入稳定在4w以上。今年我正准备在长沙看房，计划给自己和家人一个安定的家。

但你可能不知道，三年前我还处在负收入的状态。那时候刚结婚生子，婆婆又生病，各种意外接踵而来。每个月房贷、房租水电、妈妈帮带娃的辛苦费、宝宝的奶粉尿不湿，加上日常开销，轻松超过一万。这意味着我每个月至少要赚到两万，账户才有结余。那段日子让我明白了一个真相：单纯省钱，根本救不了自己。

今天把我的经验整理成6条，希望能给同样在自媒体路上摸索的你一点力量。

## 1. 别总想着节流，开源才是根本

我算过一笔账，当你的必要支出就压在一万多时，再怎么省，生活质量也会被压到谷底。所以我把重心从“省”挪到了“赚”上——想办法提高收入，直接解决核心支出问题。

你也可以先列出自己的必要开销，再算算需要多少收入才能存下钱。然后尝试一些灵活的自媒体副业：我的学员里，有人靠人物稿写作单篇阅读上百万，收入过万；有人靠📕接广，月入四位数；还有微头条、得物这些新方向。机会一直有，关键是你愿不愿意下场。与其看着别人赚，不如主动出击，把那份“开源”收入拿回来。

## 2. 敢合作，才能放大自己的优势

一个人的精力实在有限。我做过不少产品，但一直没碰写作课和公域课，因为忙着交付私域、👸号和发售，已经分身乏术。去年10月，我和几个朋友决定深度合作。一开始是双人私教产品，后来升级成三人合伙人。她们有很强的成绩背书，交付也靠谱，而我恰好有私域经验和用户信任。

合作最重要的是彼此信任、各司其职。我们三个人分别负责自己最擅长的事，把一个重交付的高客单产品做得稳稳当当。今年我们都突破了月入10w+，收入比之前翻了好几倍。而且，多了一个能一起承担压力的同行者，这条路也不再孤单。所以别怕分钱，敢于把利益分出去，才能用更少的精力赚更多的钱。

## 3. 搭建团队，别做孤胆英雄

常有人问我时间管理的方法，说实话，我并不自律，效率也低，常常完不成目标。我真正靠的，是一个帮我把琐事解决掉的团队。小助理们负责做图、管社群，我则集中精力做成交、做规划。

每个超级IP背后都有一群人在支撑。与其单打独斗，不如花钱买别人的时间，把自己的时间用在更有价值的地方。你才可能真正轻松地赚到钱。

## 4. 付费借势，突破收入天花板

一个人闷头摸索，很难看到更高的风景。想赚到更远、更高层次的钱，就必须借势。借势借的不只是影响力，还有眼界、认知和圈子。

这几年我加入了不少高端社群，认识了以前接触不到的人，也接住了不少流量。我也经常帮学员推流，辅助他们发售产品。很多人因此从0流量做到私域几百上千人，从没有产品到建起自己的社群，逐步打造出自己的IP，突破了原来的收入限制。找一个信任的导师，付费学认知，主动靠近贵人，赚钱这件事，本来就应该争分夺秒。

## 5. 销售能力，是你最值钱的本事

在自媒体圈，会交付的人不少，但能把产品卖出去的人不多。所以我今年还特意进了销冠群，继续磨炼销售谈单技能。

只要分销做得好，到哪儿都受欢迎。我在很多次大型拉新活动中拿过TOP3，不仅有分红和奖金，还获得了大佬的认可与关注。更重要的是，自己的产品也越卖越好，收入一路走高。私域是未来的主战场，销售能力就是你的护城河。别只顾着输出，也要学会把自己卖出去。

## 6. 用外部监督，留住赚到的钱

会赚钱，也要会存钱。我这个人花钱比较随性，经常东买西买。为了存钱，我把钱交给信得过的学长保管，让他监督我。我负责赚，他负责管，一进一出，才有了今天买房的底气。如果你没有可以托付的人，就存银行定期，或者用强制储蓄的工具，把未来的自己“锁”在安全区。

## 最后

支撑我走到今天的，其实是一份责任和执念：我想给家人更好的生活，也想真正拥有一个属于自己的房子。所以我愿意熬夜打磨方案，愿意硬着头皮和形形色色的人交流，也学着跟各种负面情绪和解。

少抱怨，少内耗，认真做事，回报一定会在某一天悄然而至。希望我的经历，能为你增加一些前行的底气。
