# 两年了，我在赚钱把门票翻了十倍

两年过去了，我依然记得刚被拉进赚钱时那种眼花缭乱的感觉。作为一个程序员，我以前从没想过，自己有一天能在赚钱把门票钱翻十倍拿回来。

先声明，这篇不是引流，纯粹是一篇复盘。我是 koalabear，平时话不多，性格有点闷。在进入赚钱之前，我唯一碰过的互联网项目就是跟着雪姨撸货，偶尔赚点零花钱，至于什么项目玩法、流量逻辑，基本是两眼一抹黑。2022年4月才过几天，雪姨就把我拽进了赚钱。刚进去那阵子，那些精华帖看得我目不暇接，几乎天天都在搜自己感兴趣的内容，各种赚钱路子倒是了解了不少，可回到现实中，我却完全不知道自己能做什么，更不知道该怎么用好这个知识宝库，甚至对“航海”都没什么概念。


回头看这两年，我很庆幸自己当时没有只看不做。虽然跟圈里很多大佬比还差得远，但至少我从一个纯小白，变成了也能帮身边人拿到一些小成绩的人。有圈友开玩笑说，我的经历可以叫“程序员赚钱回本指南”，想想还真有点贴切。更让我开心的不是数字，而是自己真的在成长。

特别感谢思蒙，后来带我入了短剧的局，让我又多了一些可能性；也感谢雪姨，如果不是她拉我进门，我大概还在门外打转。还有那些给我点赞鼓励的朋友们，谢谢你们的认可。未来的路还很长，一起慢慢走吧。
