# 家有一娃，赚钱如麻！新手宝妈做抖音，一年橱窗带货 11 万单历程分享
作者：龙哥

自从有了娃，很多妈妈都幻想过：一边陪着孩子长大，一边还能自己赚点钱。我运气不错，这个幻想在抖音变成了现实。

我是龙哥，龙哥盟圈友，编号93967。2023年6月才正式加入这个星球，之前一直默默潜水刷大佬们的经验。说句真心话，这个平台的认知、能量和实操干货，真的把我这个新手“喂”大了不少。

这篇文章是我在星球里的第一篇投稿，大约六千字，把我做抖音一路走来踩过的坑、摸出的门道，全部摊开讲清楚。不管你现在已经在做抖音，还是正准备进来试试，我相信都有参考价值。

先亮个数据吧：2023年2月，我才正式入局抖音，定位母婴赛道，做纯短视频带货。就这么一路拍视频、挂橱窗，一年下来，累计卖出了11万单。可能有人觉得这数字不大，但作为从零开始的普通宝妈，我已经很骄傲了。


顺便说一下文后评论区里的热闹：豪叔连说“太棒了”，我也开心地回了一句“感谢”。湘帆说自己刚做母婴号不久，看完感觉非常受用。也有圈友抛来一个尖锐问题：“以你现在的经验，哪怕打个三折，还敢从零重新做一个号吗？”我的回答是：“只会更快。”毕竟在抖音里沉淀过的人，那些方法、手感、敏感度都是实打实的优势。正是这份底气，让我今年敢直接立下30万单的目标。

还有朋友留言问能不能带绘本，想要联系方式，这里统一回复：主页都有，直接去看就好。
