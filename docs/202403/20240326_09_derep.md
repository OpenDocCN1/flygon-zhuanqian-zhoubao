# 5 分钟制作漫画小说短视频，小说推文项目，全流程手把手教学
作者：龙哥

最近是不是也刷到过不少漫画小说短视频？我特地去看了一圈对标账号，点赞量一个比一个夸张，这阵风确实够火。

说到底，做这类视频的核心目的就是给小说导流。但这里得提醒一句：热门小说基本上都有版权，不能随便拿来就做，拿到授权才是关键。好在现在主流平台基本都开放了版权授权通道，走正规渠道并不难，不用自己到处找门路。


顺便把评论区高频问题一起答了：腾讯智影的动态漫画功能，记得要用电脑网页版，在首页就能找到；推文视频里用的小说文案，直接用原文是没问题的。
