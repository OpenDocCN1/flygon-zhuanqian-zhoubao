# 📕两年做了 2700W 营收后：我对「留学行业的趋势分析」

从1500元启动资金，到两年做到2700万营收——留学行业真实的赚钱窗口，可能和很多人想的不一样。

大家好，我是珍妮。

2022年到2023年，我和团队在📕上布局教育赛道，合计做到了2700万营收。我算是这些项目幕后的运营操盘手，平时主要做📕矩阵号的运营；上一期《老板避雷手册》精华帖，也是我写的。后来，我又和龙哥盟的圈友陈铭 Ivy 合伙创业，2022到2024年间持续输出过不少实战复盘。

今天分享的内容，是我对留学行业趋势的一份梳理。

提前说一句：文里标亮的关键点，不只是留学赛道能用，其他行业的老板也可以对照找思路。
