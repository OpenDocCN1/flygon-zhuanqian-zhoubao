# 决裂 16 年，傅盛再会周鸿祎
作者：龙哥

### 十六年后再同框，傅盛首次回应大模型，一句总结点破真相

当年从奇虎360出走的傅盛，与周鸿祎反目十六年；如今两人再度坐到一起，外界都在猜他们会聊什么。让人意外的，傅盛没有翻旧账，只说了一段关于大模型的话，却被业内认为是近段时间最清醒的判断。

他当时的原话大致是这样的：“对GPT也好，对大模型也好，永远别低估它的潜在爆发力——这个方向一旦进入拐点，进步速度会剧烈到超过所有人预期；但话又说回来，也别把眼下的它看得太高。每一个新技术，刚出来的时候大家都亢奋得不行，预期被拉满之后，一定会有一阵子遇冷回落。”

这话放在今天的AI讨论里尤其值得细品。现在一边是铺天盖地的“AGI马上到来”论，另一边是“大模型不过尔尔”的唱衰声。真正在一线操盘过产品的人，反而会给出像傅盛这样有张力的判断：长远看要敢想，短期看要克制。

有评论区的朋友也补了一句：“回落之后，才是真正百花齐放的时候。”这话跟傅盛的观点恰好形成一个闭环。
