# 用“门徒制”做裂变，个体创业如何一年半从一人干到四十人团队月赚几十万
作者：龙哥

很多超级个体做到瓶颈期都卡在同一个问题上：一个人能扛，但扛不住规模化；招人又怕失控，扩张就变形。

这套门徒式裂变打法，就是为了解决这个过渡期而生的。

我把自己团队从 1 个人起步，到现在 40 多人，月度利润稳定在数十万的这 1 年半实操经历完整拆开。如果你正想从一人 IP 往项目化、团队化走，这套思路基本可以照搬。

整个分享围绕五个关键点展开：

一、我团队的真实增长轨迹是怎么从 1 人走到 40+ 人的
二、门徒制不是谁都能进，筛选标准是什么
三、从 0 到 100 人的裂变团队搭建操作手册
四、这种裂变模式在跑起来后会遇到哪些坑
五、未来这套模式还能怎么演进和放大

全文接近八千字，是对过去运营的深度复盘，不是鸡汤。

如果你现在正焦虑团队搭建、公司规模化放大的问题，这篇内容值得通读。
