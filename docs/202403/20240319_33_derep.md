# 大模型赛道正在抢什么人？普通人能搭上这波10倍增长的快车吗？
作者：龙哥

最近我和两位在大厂做AI产品的朋友深聊了两个小时，信息量很大，忍不住想分享给各位。

先直接说结论：目前行业里招聘需求最旺的，依然是技术和产品经理岗。技术岗各地都有，产品经理则基本围绕自家产品来招，开出的薪资普遍在30K到60K之间。

不过，随着底层基建越来越成熟——也就是不需要做到百万DAU就能推向市场公测的阶段——运营类人才的需求会迅速爆发。最常见的三类是：产品运营、内容运营、增长运营。

很多人问产品运营和内容运营到底差在哪？我的理解是：产品运营更像全局操盘手，而内容运营更专注于内容维度的深耕。详细对比我放在评论区了，有兴趣可以点开看。

再说增长运营，尤其是广告投放方向。以Kimi为代表，这个岗位的招聘力度非常猛，优先级极高。这说明融资一到位，就要立刻投流获客、跑规模了。普遍要求是：有字节跳动、拼多多这类极速增长型互联网公司的增长实战经验，或者做过百万级预算的投手。
