# 年度复盘：手握百万粉矩阵，为什么我这一年还是亏了十六万？
作者：龙哥

大家好，我是龙哥。18年开始玩短视频，19年靠法律号冲到两百万，22年宠物科普矩阵总粉丝破三百万。做知识类IP、做流量我有一套自己的打法，但变现一直是我的短板。今天就用我写科普稿的那种直白劲儿，把我自己的账给拆开来。

我明明手里有好几个能吃流量的垂类号，还一直在接商单，结果2023年净亏十六万。这事要是搁在我刚入行时我肯定不信，但它发生了。我复盘出来，就是想给同样在路上的人提个醒。

# 一、先说现状

现在主营的就是宠物科普自媒体，教猫狗养法的那些号。

目前能稳定跑的三个号：

宠物知识讲解员：抖音113万、快手45万、B站13万、视频号1.8万、📕5万
宠物冷知识-小北：抖音48万、B站8万、视频号1万、📕3万
猫布理先生：抖音26万、快手5万、B站2万、视频号1万、📕6万

另外还有两个签约号：西西里的猫50万粉丝、宠物情报局30万粉丝。

粉丝看着体面，但品类太像了，所以大家一起掉进了同一个坑。

# 二、这一年到底哪里出了问题

**1、商单断崖式下跌**

过去这几个号基本靠广告活着，广告占比95%，流量补贴只占5%。2022年最顺的时候一年靠广告能赚上百万。赚到钱的当下，我从长春搬到了杭州。

搬过去后，成本直接翻2.5倍，收入却只剩之前四成。广告少了，钱就断了。焦虑到极点，我就想着去开拓新路子。

**2、新路子没跑通**

四五月份试过建猫车群做私域，引流到群里几百人，根本没互动，直接放弃。看到直播带货火，我也冲了。杭州的直播运营和主播薪资极高，自己招人养不起，于是我和女朋友自己上阵，我管运营商务中控，她上镜。播了八个月，一算账：不赚钱。

因为我们俩全扑在直播上，短视频内容就得补人。团队一度拉到八个人，看起来热闹，其实把亏损的坑越挖越大。

**3、涨粉停滞**

八个人里，除了我俩，其他六个是三個后期三个运营。每人管一个老号加一个新号。结果新号全部起不来。老号还能每月带来千万级播放，但粉丝不再涨。

对于靠广告报价吃饭的账号，粉丝不涨=报价不涨。钱赚不到，人就散了。团队里有人看不到希望离职，新号也只能砍掉。这时候我才承认：我之前在宠物科普这条赛道的方法论已经失效了。方法论一失效，要么革新，要么等死。

**4、成本失控**

全年支出60万。还在长春时一年只要20万，到了杭州直接三倍。毛利其实有44万，算下来亏16万。最大的两块是人力和房租，其次是投放。一年豆荚就烧了五万左右。我们自己都没意识到营销费用已经吃掉了这么多。

# 三、我现在怎么补救

**1、广告少了怎么办**

其实不是少，是回归正常。我的号是特效+剪辑的无真人账号，最多算卡通IP。2020-2022年国产宠物粮爆发式增长，广告主抢投放，我们接到手软。现在行业增量萎缩，获客成本上去，我们这种账号自然没竞争力。

我的对策是加附加值。利用我对宠物营销和食品的了解，给品牌方打包投放+营销策划+产品咨询+宣传片，提升报价理由。另一方面，我开始自建品牌，用自己的号给自己打广告。一个视频成本300-500，做获客比给别人打广告划算得多。

**2、变现渠道没起来的解决**

做了一年直播我才明白，抖音直播里货才是一切。有个品牌给折扣，间人就几千；不给折扣，几百人，甚至播到三十人。宠物类佣金又低，根本撑不起团队。

所以决定自建品牌专供自家直播间，自己定价，自己做“破价”。同时把私域沉淀的人也导向自有品牌。

**3、涨粉难怎么办**

接受现实，大环境不给饭就别硬扛。老号维持性运营，保成本。把资源抽出来找新赛道。我下一步瞄准的是旅游类IP，已经在筹备，计划在大航海计划之前先试水。

**4、开支怎么降**

收缩。团队从八人砍到三人，都是编导运营，后期找离职同事兼职，或者自己上手粗剪。房租两年合同交了动不了，其他开销全部砍掉。能外包不招人，能降就降。新项目没验证前绝不扩张。

# 四、最后把账算给自己

公司层面：
管理上我是个I人，不爱开会，员工做几个月就开始松懈，积极性拉不起来，后面必须补这一课。
业务收缩导致收益变差，激励给不到位，整个团队精气神在往下掉。

个人层面：
执行力不够。23年就想做个人IP带徒弟，一直拖到现在。
私域里有上千人，却一直纠结怎么变现，搁置至今。
判断力不足。宠物科普赛道23年后几乎没有新号起来，我却一年后才反应过来这是天花板信号。
同样低估了直播带货的门槛，学了八个月才觉得刚入门。
认知偏差。过去太顺，以为是能力，其实是站在了风口。现在每一步都会先算六个月的现金流，能不能扛过去。
管理太随意。盲目招人，人效跟不上，只需要四个人却招了六个。
定位漂移。我是内容运营出身，却去干直播运营，把擅长的丢了，导致老号流量下滑，收益跟着掉。今后要回到内容本身。

创业每个月都焦虑，但焦虑也是成长的证据。常说一句话送给大家：哪怕你拼尽全力没爬到一百层，回头看你已在五十层，而目标是二十层的人可能还在十几层。人生就是在追上和超越中不断往上爬。

我是卢卡卡，一个还在路上短视频内容创业者。这次复盘就到这里。
