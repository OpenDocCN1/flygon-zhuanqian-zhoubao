# 我的数字人变现实战：从起步反复试错到月入破百万的路径复盘
作者：龙哥



大家好，我是龙哥，数字人赛道的一名老玩家。说实话，我到今年2月才真正把数字人当成主业来做。头一个星期全是撞墙期，各种翻车，最后才抓住转机，拿下人生第一笔数字人收入：5万块。想了解我前面踩过的坑，可以去翻我之前在赚钱写的旧文，有详细过程。

起步摸到路子后，我就开始复制那套可行的打法。只是很快发现，玩俄罗斯美女带货的人越来越多，获取流量的成本在抬头，竞争已经进入白刃战。为了避开红海，我把目光转到和中国关系比较好的市场，比如巴基斯坦。试了几天后发现流量明显回暖，竞争者稀少，于是直接把这套模式批量铺开。除了做短视频带货，我同步做了私域承接，成交走🛰️和支付宝，不需要垫货，利润更纯，复购和转介绍也很高。

![](img/940da4a30338d7ddcae93eb5d6898263.png)

数字人赚钱不只有带货这一条路。做数字人本身门槛就不低，选平台更是让人头疼。像国外的heygen，一分钟大概要2美元，国内的主流平台要4-5块人民币一分钟。对于刚入局的新手来说，光是成本就扛不住，很容易直接劝退。我每天要做20到30条视频矩阵，成本必须压下来。折腾了好久，我把单分钟成本压到了0.1元，这个过程相当磨人。

因为成本问题困扰的人太多，大家都来问我用什么平台、怎么低成本做。我一开始担心教太多会抬高竞争，但后来发现手上能用的工具不少，于是出了两个选择：只给平台名单，收99元；名单加实操教程，收199元。没想到反响极好，每天都有人来求购，变成了一条稳定的副线收入。也正因为此，我开始在各平台发短视频做引流，平台售卖成了我的第二增长点。

![](img/8a6be17cc2350d04b34f29b5ad4bde03.png)

光靠海外美女带货、私域收割、卖工具信息这几招已经不够用了。竞争一上来，利润必然被稀释。所以我开始找新的变现组合。其中一个突破点是书单推广。之前有人用图生数字人做得不错，给了我灵感：用气质沉稳、有阅历感的老者形象来做书单口播，或许会奏效。

我马上开干，玩法和之前海外美女带货其实大同小异，就是换了人设和脚本。声音克隆在11labs上几分钟就搞定。没想到效果炸裂，项目第二周，数字人整体营收就突破了20万。

![](img/5c2cb74dcb954c0f3a1e18b9b07bfe62.png)

有了海外美女带货、书单带货、私域成交、卖号和平台信息等多条线，我依然没有停手。经验告诉我，躺在成绩上就是倒退，只有持续破局才能保持获客和变现。持续探索的过程中，赚钱圈里的小楠给了我很大启发，他拉我进入中老年养生保健品这个垂直赛道。虽然他主攻无人直播，我做短视频口播，但本质都是带货，互相交流价值很大。小楠把他手上跑出来的爆款和后台数据都拿出来分享，我特别感激。

这给了我一个新想法：用海外老年人的形象来推养生品。落地后效果不错。更关键的是，小楠有长期无人直播积累的线下供货渠道，佣金能拿到售价的一半左右，结算也快，远高于正规渠道。

与此同时，我发现很多做数字人的创作者卡在了平台的出镜人实名验证上，最后都来找我。起初我靠发红包帮忙，后来发现需求很大，于是做成服务：99元代过，199元手把手教。这条线又给数字人变现拓宽了一环。

![](img/6a0d5355093986180ce125626814b8a5.png)

做到第三周，我手上的变现方式已经包括海外美女带货、书单带货、海外老人带货、卖平台信息、出镜人验证服务。但我依然在找下一跳。观察下来，数字人内容基本都是口播，我就想有没有别的形态能带来更大流量。

这时我注意到国内有不少唱歌博主靠翻唱在短视频平台吸量。于是我尝试让海外美女数字人去唱歌变现。坦白说，这段是最折磨的，找能克隆歌声的工具太难了，市面上能用的网站屈指可数。

后来和圈友聊天被提醒了AI孙燕姿，B站上铺天盖地的翻唱视频基本都靠声纹克隆。我顺藤摸瓜找到了GPT-SoVITS这个开源项目。对我这种新手来说完全是新领域，我啃YouTube、B站、CSDN的教程，最后本地跑通了人声训练。折腾了一周，歌声克隆问题终于解决，海外美女唱歌变现的路径也就此打开。

如果守着旧打法，我的天花板很快就会到。越努力越幸运这句话在我身上挺准。我在数字人上的持续深耕也引起了身边人的关注。3月8号那天，我抓住了数字人商单的一个新机会：为商家做私人定制。

那天朋友陈姐看到我朋友圈在晒数字人，问我能不能帮她做一个。她在抖音卖家具，传统拍摄要请摄影师、化妆、现场踩点，成本高效率低。我先给她做了一个样片，报价1万元，送10个定制模型，她立刻就付了。这一单让我意识到，企业定制市场非常大。很多老板不懂AI，但他们愿意为提效和省时买单。

![](img/70674661d07bde35d29615f13a1073de.png)

成交那刻我都懵了，以为只是个偶然。结果我把案例发到赚钱分享，被龙哥大佬点名认可，中标了。瞬间明白这不是运气，而是真正的商机。商单客单价常在五位数，线下老板对提效的需求非常刚性，而且他们对AI和互联网的认知有限，正好是窗口期。

被确认后我马上行动，开始排查身边的线下实体店老板挨个触达。3月11日又接下一单，再次在赚钱分享并得到龙哥大大的认可，再次中标。这让我彻底确信商单是可以持续深耕的赛道。龙哥大大也说过：“任何龙哥盟提到的项目，100%都能一年赚到100万以上，我说的，不接受反驳，除非你比我钱多。所有的原因都从自己的身上找，不要去质疑项目选的对不对，项目没问题，在具体碰到的问题上想办法，碰到一个解决一个，封号就想办法不被封号，放不大就想办法怎么放大。”

3万元开启4S店销售新纪元，数字人如何重塑汽车营销？

短视频已经成了商家连通用户的关键渠道，但传统拍摄既费时费力，有时也表达不清卖点，尤其在竞争激烈的汽车销售行业。

我一个球友开的是知名4S店，店里销售形象都不错，但做抖音宣传片时，产品讲解和口播表现一直不理想，每次拍都要花大量时间成本，效果却平平。

他几乎要放弃时，看到了我朋友圈发的数字人商家定制服务。设想一下，一个永远在线、表达流畅、能标准化展示每款车型亮点的数字人销售，这不正是他想要的吗？

他决定试试，我很快给他做了三套数字人样片。效果远超预期，稳定性碾压真人销售，还省了大量时间和成本。

他当场表态，今年的短视频营销要全面上我的数字人方案。这次合作我为他定制了15个销售模型，成交价3万元，合作正式启动。

这个案例既验证了我的技术，也证明了数字人在汽车行业的应用潜力。随着场景越来越多，数字人能以更低成本带来更高营销效率。

变革正在发生，AI正在重塑销售和营销的游戏规则。

目前已有家具店、畅销书作者、4S店老板，以及医生、教师、律师等个人IP的客户找我下单。他们都希望拥有专属数字人，因为这能省下录制时间，大幅降本。除此之外，餐饮、美容、健身、教育、旅游、房地产等线下行业对定制服务的需求也很旺盛，这类订单动辄五位数甚至六位数。

很多人问我，PONY，你在数字人项目里一路跌倒又爬起来，靠的是什么？其实就两点：

1. 奖励自己。当你立了年入百万的目标并实现时，你会想了很多犒劳自己的方式，这种正反馈很强。

2. 惩罚自己。很多人忽略了这一点，但没有自我惩罚很难做到位。我喜欢睡懒觉，不爱跑步，偏爱打篮球和爬山。为了目标，我每天5点起床复盘规划，睡眠不足5小时，6点必须出门跑5公里，这个节奏要保持到年底。

为了逼自己不放弃，我把承诺发到朋友圈：做不到就给点赞的朋友每人发1000元红包，目前已有20多人点赞。我是个信守承诺的人，为了不破财，我今年必须完成目标。曹大说过，要想成大事，就得对自己狠。我有信心完成目标，因为我已经All in在数字人上，你呢？该对自己狠一点，为目标冲了。

与此同时，我还在研发数字人离线生成系统，这个项目已经接近尾声。主要解决商家定制时的痛点，比如商家想自己生成和修改视频，以及批量长视频的高制作成本。通过把商家定制的模型导入离线软件并开放操作权限，商家只需输入文案就能自主生成任意长度的视频，后续增模也可以付费开通。
