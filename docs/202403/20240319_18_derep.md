# 节日联名也能玩转社群拉新：一个私域小白的600人增长复盘

大家好，我是龙哥。38 女神节的联名活动已经落幕三天了，这次用联名营销的方式，我在短短的节日周期内为社群带来了累计 600 多人的新增，今天就把从预热发售到营销裂变再到后续承接的完整思路拆开讲给同样在做线上社群的朋友听。

这套打法，最适合两类人群：一是刚起步的私域新人，想快速启动一个陪伴型社群；二是已经运营到百人规模以上，但被增长瓶颈卡住的老群。简单来说，基础越扎实、影响力越大，节日的放大效应就越明显。尤其是手里有高客单价产品可以承接的团队，完全可以把这个模式复用到接下来的各种大型节日里。
