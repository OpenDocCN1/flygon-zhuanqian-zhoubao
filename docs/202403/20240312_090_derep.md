# 2024，AI+教育方向的信息和思考

2024年，我眼中的AI+教育：方向、实践与赚钱思路

大家好，我是龙哥。在少儿编程和AI教育这块儿摸爬滚打了好几年，也开过两期线下班，专门带孩子们上手ChatGPT和各种AI工具。今天聊AI+教育，我不扯那些宏大的教育变革，只聚焦一个切面：中小学阶段的基础教育。想跟各位分享我在这片领域看到的真实现状、脑子里冒出来的点子，以及下一步打算试水的事，当然也绕不开怎么才能从这个方向里赚到钱。算是抛砖引玉，希望圈里的朋友也能甩出更妙的思路。


文章发布后，评论区反响不错。有人问：用ChatGPT教小孩子，现在到底赚不赚钱？我的回答很直接：目前是按人头收费，还没跑出规模，做了几期拢共也就十万左右的营收。另外也有朋友说，她脑子里转的好几个想法都跟我撞了，这感觉挺好，继续多交流。

还有一位深耕AI教育的朋友，特意提到“刀姐”设计的那个产品。他觉得游戏天生就能抓住孩子的心，再搭上AI来激发创造性，简直不要太有吸引力。我也特别期待，就等着刀姐把它做出来了。他还补充了一句：创造力说白了是玩出来的，而且得在无限制、没有标准答案的玩里才能长出来。这话我举双手赞成。AI教育值得持续探索，想聊的朋友随时甩私信给我。
