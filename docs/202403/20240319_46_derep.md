# 春节带零基础妈妈做社群年货，我的5000块首单复盘

大家好，我是龙哥，郑州圈的同学。今天想把去年的春节经历整理出来，顺便和大家分享一下：我是怎么在年货季，带着完全没接触过互联网的老妈，通过社群卖年货，拿到人生第一个5000块的。

这篇复盘大概5000字左右，阅读起来大约要20分钟。写出来主要是为了回顾当时的思路，如果能给正在想带家人一起做点小生意的朋友一些参考，就更好了。

一切的起点是我在群里看到@七小转发的@易凡团队的年货项目。点进去看他们的交付手册，感觉做得非常细致靠谱，于是我就报名参与了。后来我发现单纯做海鲜大礼包有点单薄，年货的需求其实很广，所以我又自己去找了几家质量不错的补充货源。

为了让老妈能上手，我帮她开了两家线上的小商城。这样一来，基础的年货品类基本就能覆盖了，也不怕顾客追问没有。

这个过程中，@孙策策哥给了我很多关键性的提醒和鼓励，让我和我妈的信心都上来了。很可惜当时时间和精力有限，没能把他的部分建议全部落地，但我一直都有及时反馈，真的非常感激他的关注。

@陈龙龙哥对我妈的小店也给了很大的支持，他说过一句话我一直记着：信心比黄金重要一百倍。这份帮助我会一直记在心里。

另外还要谢谢@拱卒和@梁靠谱靠谱姐在选品和话术上的点拨，希望以后有机会能一起合作。最后的文字也得到了@凡灵逸尘铭尘的帮忙审阅修改，很感谢每一位信任和支持我的朋友。
