# 别指望招人来拉动业绩，先招人来把时间还给你

很多人创业做到某个节点，第一反应就是：业绩上不去，赶紧招人。

真正的玩法恰恰相反：招人的目的不是为了直接做大业务，而是为了把你从低价值重复里解脱出来。

当你把琐碎、流程化、可复制的工作交出去，你买回来的不是一个员工，而是一块可用的时间。这段时间你才能去做只有你能做的事——那些高杠杆、你擅长、你真正喜欢、回报也最高的核心环节。正是这些环节在决定公司能不能进入下一个量级。

反过来说，如果招人只是为了填坑、替你多干活，那本质上是在透支你的精力。业务不会因此加速，只会把你越拖越慢。

所以换个角度想：招聘 = 用钱换时间。先解放操盘手，后谈业务增长。
