# 我用影刀 RPA 做了个多手机抖音自动发布机器人

一天60条抖音，我靠影刀RPA全自动搞定

最近公司要做矩阵账号，每天得在抖音手机端上传视频。一个人要照顾20台手机，每台每天发3条，算下来就是整整60条。这种全是重复操作、又耗时间的活儿，让我直接扔给了RPA去处理。

利用影刀RPA，我搭了一个多手机自动发布机器人。核心做法我梳理了一下，其实不只是抖音能用，换到快手、小红书、视频号这些平台也完全没问题。更详细的流程和配置，我已经放到飞书文档里了，有兴趣的可以直接点开看看：[`ood4bblwty.feishu.cn/docx/GknKddubGoB4dXxbIKgc5psSnOC?from=from_copylink`](https://ood4bblwty.feishu.cn/docx/GknKddubGoB4dXxbIKgc5psSnOC?from=from_copylink)
