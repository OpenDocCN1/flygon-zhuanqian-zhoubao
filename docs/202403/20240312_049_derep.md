# 从焦虑到自信：一个北漂宝妈的读书逆袭，意外收获了第一笔过万收入

谁能想到，当初只是为了让疲惫生活里透口气而翻开书本，竟会在一年多后带来这样一份惊喜？

我，Miss 董，一位在北京打拼的程序员，同时也是个每天在职场与带娃间来回切换的妈妈。2022年起，我给自己定下了一个小目标——每天抽出时间，安安静静地读几页书。

没想过什么宏大的意义，不过是觉得生活有些窒息，想找个出口。可这个看起来很不起眼的动作，却像多米诺骨牌一样，轻轻推倒了我人生的第一张牌。

思维在不断阅读中变得开阔，情绪也稳定了许多。更让我没想到的是，依靠这些沉淀下来的内容与感悟，我竟然迎来了自媒体道路上的第一个“里程碑”——单次变现，稳稳破万。

回顾这段经历，最深的体会是：改变从来不是惊天动地的，它就藏在你愿意为自己花的那一点点时间里。

哪怕每天只读十几页，日积月累，也足以帮一个迷茫的普通人重新找到方向，甚至打开一条意想不到的成长路径。
