# 别指望赚钱这条路能按剧本走

做项目，尤其是拿钱的那种，十之八九都会偏离你最初的设想。

流程会变，时间会拖，突发状况会接踵而至。计划赶不上变化是常态，不是意外。

所以第一件事，是先把预期拉回现实。遇到偏差先别急着崩溃，先承认它、接纳它，然后继续往前推。

如果这点波动就能把你打乱，那说明你还没被现实毒打够。

很多时候，我们需要的不是更完美的计划，而是更稳的心理。

**先看状态，再看事情**

做事的状态，其实就三类。

一种是推进状态，做的事情刚好在能力边上，有点挑战但能驾驭，人很上头，很有劲。

一种是遭遇状态，突然撞上一块大石头，难度超出了当前能力，情绪就容易乱了，要么甩锅要么自责。

还有一种是规划状态，它是给遭遇状态准备的刹车键。停下来问自己：这件事现在到底是什么样？我希望它最终变成什么样？

项目跑偏，恰恰就是从推进掉进了遭遇。这时候别硬扛，先切到规划状态，把目标重新校准，再重启推进。

**结果不理想时，用四个问题把自己拉回来**

长期做目标管理的经验沉淀下来，其实就四个自问：

我的现状到底是什么样？
在这个事上，做成什么程度我才算满意？
如果我只实现一个具体的可交付结果，那是什么？
要达成它，我的时间和精力该怎么投放？

满意和想要的结果不一样，满意才和你的内心绑定。先搞清楚满意线，再去分配资源。

**执行力的真相**

执行，最大的瓶颈从来不是认知不够，也不是第一步迈不出去，而是心力。

知道步骤的人很多，能在波动里保持行动的人很少。

执行大致可以拆成三段：果决开启、赋能当下、嘉许总结。开启要快，当下要沉下去干，结束后要做复盘和自我认可，形成正反馈。

准备要做充分，但心里要装着最坏的打算。空杯心态不是放弃，而是让自己有弹性去接住所有不如预期的事。

赚钱这件事，本质就是在不断接受偏差中前行。淡定下来，继续干就是答案。
