# 李录给青年的 33 条建议

**经营好自己，才是人生中最大的一笔投资**

很早以前就听人提过：李录先生给青年人整理了33条建议，与其说是投资心法，不如说是一份实用的“人生决策清单”。最近它又被“龙哥的收藏夹”翻出来，依然值得反复研读。

作为顶级投资人，李录的视角从来不是教你如何一夜暴富，而是如何持续做出正确的选择。他谈“能力圈”，劝人别在不擅长的地方消耗自己；他谈“复利”，提醒你耐心等待时间的回报；他谈“诚实”，希望你能直面自己的短板；他谈“自律”，让你拒绝那些短期舒适、长期昂贵的东西。

这些道理看似平常，落到具体行动里却很有分量。比如：
- 你每天花几个小时刷手机，是投资还是消耗？
- 你身处的圈子，是在托举你，还是在拖拽你？
- 你正在做的事，三年以后还能不能产生复利？

这33条建议，就是一套帮你回答上述问题的工具。它不是鸡汤，更像一面镜子，照出你当前决策的含金量。

你不需要成为专业投资人，但一定要把自己当作最重要的资产去经营。认真选择每一条路径，耐心等待时间的答案。

记住：你既是自己人生的投资人，也是唯一的操盘手。这份清单值得收藏，更值得逐条践行，别让它只在收藏夹里吃灰。
