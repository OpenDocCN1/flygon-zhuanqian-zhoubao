# 98后河北小村青年：从辍学到月入数万的自我迭代笔记



一个初中便离开校园的农村孩子，如何摸索进线上生意圈，把月薪从几千块拉到三五万区间，并与一批头部玩家建立联系？这是一份关于不给自己设边界的真实样本。

## 启蒙篇：读书无用论的代价

主人公出生于河北乡村，千禧年后成长。彼时他觉得书本知识脱离实际，家里经济也吃紧，初中学完便彻底告别课堂。

这里想对家长说一句：孩子成长不仅是身体和分数，还有价值观的塑造。学历，对普通人而言，仍是最省力、最稳妥的上升通道。

## 16-17岁：三地打工，理想被现实打磨

十六七岁时，他先后辗转四川、北京、西安三座城。做过批发市场门店的帮工、跑过外卖、修过电动车。

听闻大城市机会多满地捡，真正踏进去才明白，机会的获取取决于个人条件的适配和眼界的宽度。一圈下来，底气被消耗殆尽。他给自己立规矩：先学一门能活下去的手艺。

## 17-20岁：工厂流水线与成家

十七岁下半年到二十岁上半年的区间，他在老家常年童车厂做流水线作业，期间步入婚姻。

表层平淡，内里却有一句话一直在刺他，那是“醒醒”留下的质问：“难道就这样过完一生？”这股不甘，后来成了转折的燃料。

## 20-22岁：触网试水，裸辞的昂贵学费

二十岁下半年，他第一次接触网络经济，首个方向是试玩类任务，因操作不佳成效有限，于是前往郑州想与几位同行人抱团。相处后发现彼此并不合适做长期的事，他便留了下来。

年底时经一位朋友牵线，在郑州落脚并拿到一份与互联网相关的工作。带着对平庸的不满，他干了半年便辞职创业，自认年轻冲动。此后游荡一阵，偶然在社交空间翻到旧时做试玩积累的经验。

那段时间他接触过拉新、试玩、任务兼职等多种形态，在他看来这些都称不上真正的项目，更像是零散的活计。

## 疫情期：回乡蛰伏，收入曲线陡升

随后他回到农村老家。疫情三年，他在乡下待了两年半。靠着若干小生意，月收益从5千左右逐步攀升至3万到5万波动。期间添了孩子，他个人并不十分想要，但安稳的环境和家庭意见让他顺势接受。

## 24岁后半年：裁员决策失误，损失六万余

待腻了乡下，他解雇了仅有的那名助手，搬到邯郸市区谋发展。招聘花了两月多时间，自己又习惯性松懈，手上还有积蓄，业务停滞。

复盘时他直言：此番操作亏了六万多，核心原因是阅历不足，竟放走了唯一的伙伴。于是得出结论：做重大抉择前，一定要多听听前辈经验。

## 入局赚钱：闲鱼试错与视频号踩坑

2022年4月18日，他加入龙哥盟。首月就上手闲鱼，第三天即产生成交，第七天盈利过百。做了一个多月就收回成本后，他去尝试视频号带货，一个月下来仅赚几百元。

反思后认为自己第一次做内容创作与剪辑，必然要交学费。后来他觉得这类模式不够长久，便放弃了。

如今回望，他自嘲当年太过年轻，有钱不赚实属愚蠢，并强调长期主义是一种需要训练的能力，而非口号。

目前他重新运作闲鱼，招了两名同事管理二十个号，也在探索小红书方向。对他而言，最初带他入行的路径和龙哥盟这个社群，就是他眼中的星辰大海。

## 核心复盘

- 文凭优先。对大多数人来说，这是上升最快、最稳、最省力的路径。
- 城市环境决定上限。即便身边没有同频者，也比待在人人都安于现状的地方强，否则冲劲和执行力会被悄然侵蚀。他坦言疫情三年打击了执行力，重建需要相当时间。
- 不设限则不困。他的经历证明，哪怕起手牌不佳，只要敢干就能翻盘，但路线错一步就会差之千里。
- 他相信，具备尚可的学历，置身于有活力的城市，身边有一群向上的人，保持自我不设限，就能迎接属于自己的未来。
