# ('《去创业吧，你会发现其实你也没有那么喜欢钱》', (2, 24))

辞职近百日，我终于想通：让我上瘾的并非金钱

二月初，我搭起了一个属于自己的社群。起初数据涨得很漂亮，我甚至产生过一种“离开公司是最好的决定”的得意。可三月一开局，平台就给了我当头一棒——账号被限流，原来每月能进一百多号人的社群，忽然只剩几十人，收入也以肉眼可见的速度往下掉。夜深人静的时候，我忍不住怀疑：这一步是否迈错了？

往回看，当初会有辞职的冲动，理想主义当然占了一部分；但更现实的刺激是，薪水不算差，副业也够糊口，却不得不天天承受领导的压制。那会儿我对未来没有任何宏大想象，只想拥有一份踏实、干净、可持续的事业，靠自己的双手稳稳养家，不求暴富，但求日子能细水长流。

那个月的意外并不只有限流。接踵而至的是大量投诉与举报。一位朋友跟我讲：拼搏的人最难熬的往往不是起点，而是爬到中途的时候——落在后面的人会眼红你，跑在前面的人想顺手把你除掉，毕竟你盘子还小，踩掉你花不了多少成本。那段日子里，我真动了重新回去上班的心思，甚至拿自己开玩笑：索性去当个吃软饭的，少奋斗几年算了。

随后我渐渐认清了内容行业的一个真相：精致又小的摊子，长期看很难活得下去。摊子小小的，利润也薄，做久了连自己都会想放弃；不想把摊子铺大，又永远会被人从背后踩住。既然已经坐在这张牌桌上，就只能逼着自己一路长大，长到旁人轻易推不动为止。

前几天，和一位科技企业的老总吃饭。他说他最初的打算只是做点小买卖，让妻儿能过上好日子，老人也能有所依靠。可真开了张才发现，公司好像永远都在开局，新问题一个接一个，逼着他不断升级自己。创业这件事似乎没有折中态——要么别碰，要么就全情扎进去。

最近，朋友圈里有人问：给你一千万现金，你肯交出什么代价？早几年我看到这种问题，只会觉得矫情、无病呻吟，心里想的是“谁此刻给我钱，我什么事都愿意做”。如今我却要先掂量一番：要赔上多少睡眠？要熬白多少根头发？要吞下多少个失眠的夜晚？这些成本加起来，未必比一千万轻。

我们社群里有一位跟我年纪相仿的朋友，也在创业，这段时间被焦虑缠身。他在各大平台没日没夜地发内容，新增关注却在慢慢减少，于是他开始不停办线下碰面会，甚至琢磨着要去海外开拓华人生意。看着他，我会不自觉地想：就算走运做到了他的体量，是否最终也会滑进同一种节奏？一想到那种整年紧绷的日子，我对年薪千万的向往竟然淡了——当然，我也未必真能达到他的高度。

上周，社群邀请了一位专做直播间卖货的达人来做内部分享。私聊时她说：你根本不知道我过去扛过了什么。要是把这些经历原原本本讲给你听，你大概不会对我现在拥有的一切那么心动。

某气泡水品牌的老板最近发了一条视频，讨论度很高。大意是：做买卖的人根本没有真正的护城河，从头到尾都会挨打，唯一的护城河就是比对手更能扛。今天让你头疼的坎，别人改天也会撞上；等你把那些自认为过不去的关卡全熬过去，护城河就慢慢长出来了。

这样想通以后，我反而轻松了不少。人生这盘棋，拼到最后，看的是谁更能熬、谁活得更久。上班如此，单干也是如此。平凡人的项目很难有秘密，被抄、被打、被围攻，都是必经之路。能被人多看一眼，起码说明你还值得被研究；这本身也是一次难得的向内省视。

绕了一大圈，我终于重新相信：人要做成点事，还是得有点信念和向往。那些东西听起来虚，却能在最黑暗的阶段把你托住，支撑你一道一道解开眼前的问题，并最终长出自己的甲胄。

说到底，就是熬而已。也许我真正喜欢的，从来不是钞票，而是不惧一道道难关、始终没有逃开的我。
