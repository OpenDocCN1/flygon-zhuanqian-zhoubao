# 一张会引流的艺术二维码，到底是怎么被玩大的？



## 《从一条朋友圈到被大佬加微信，我的艺术二维码意外爆了》

作者： 吉果
日期：2023-03-20

大家好，我是吉果，平时做插画，也在赚钱里混日子。最近朋友圈的自我介绍里悄悄多了一个新身份：艺术二维码设计师。

这个标签是怎么来的？说起来很随意。我在整理旧图时翻到了一张很久以前给自己做的艺术二维码。那天发朋友圈正犯愁发什么，就随手把这张图发了出去。

没想到这一发，直接让我亲身体会了什么叫圈友梁靠谱的号召力，什么叫表达者红利，什么叫一键式导流，什么叫圈层带来的杠杆效应，以及什么叫被行业大佬主动加微信时的手忙脚乱。

原来一个普普通通的二维码，只要做成艺术形态，也能成为吸睛的引流工具。

今天这篇就想聊两件事：一是艺术二维码在实际场景里的引流效果，二是我亲身经历下来的使用利弊，供想尝试的朋友参考。 [https://tgxl0sxo7f.feishu.cn/docx/AoT0dlRipo0RN6xDSo3cdckpnyf?from=from_copylink](https://tgxl0sxo7f.feishu.cn/docx/AoT0dlRipo0RN6xDSo3cdckpnyf?from=from_copylink)![](img/b04b13c4de7d6d58379b68809f5600be.png)
