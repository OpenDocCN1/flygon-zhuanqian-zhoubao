# 知识管理实战：我从资料整理航海中提炼的30条心得



## 《30 个知识管理技巧》

作者：张达达  
日期：2023-03-31

前几天阿蓝私聊我，说我在航海打卡坚持得很完整，还发来了一张电子奖状鼓励。这件事让我决定把这次梳理资料的复盘记录下来。

航海里我看到不少人走进了和过去自己一样的误区，太在意形式感，非要照搬别人的模板。其实知识管理的本质是为自己省事，没有唯一的标准答案。下面这 30 条，都是我从观察到的典型问题里总结出来，结合群里伙伴们的讨论整理成的实用清单，希望能帮到你。

1、当下实在不知道该把资料归到哪里，就先建一个叫“杂学”的临时文件夹统统丢进去，每周抽空统一归类，攒得多了自然就明白归属；

2、一条资料能对应多个主题，就别纠结放哪一个，直接善用标签和关联功能，让它同时出现在几个文件夹里；

3、保持清晰的闭环：输入 → 处理 → 输出 → 归档，写得不错的内容最终要落位到对应的分类；

4、学一门学科，书本理论和实践经验是配套的，别拆开存放，整理是为了更好用，不要为形式而形式；

5、照片类素材建议放到云盘里管理，iCloud、Google Drive、腾讯云、百度云、阿里云都可以，听说 Billfish 这款工具也不错；

6、可以借鉴他人的目录结构，但别完全照抄，只有你自己最清楚自己需要什么；

7、整理的目的是方便调用，而不是做得好看、也无关虚荣心；

8、摘抄金句时若涉及多个维度，就多打几个标签，后续定期归并整理；

9、整理归根结底是为了用，不是为了囤。打标签是为了更快找到，定期梳理能把相似内容聚拢，也能推动内化；不整理的话，下次遇到同类内容又会重复收藏。循环重复：

10、不知道记录什么？先看自己当前卡在哪，围绕具体问题去找相关知识，而不是被动等灵感；

11、很多资料不必都存，时效性强的尤其如此，关键是提炼它的源头，去理解核心概念并沉淀到知识库里，更像种树，关注主干和枝杈而非每一片叶子；

12、别执着于单一工具，按需组合更高效，飞书、印象笔记、Notion 适合做沉淀，Flomo 适合随时随记，网盘适合存放海量视频；

13、工具本身不重要，重要的是先明确你要解决的问题；

14、桌面堆满文件时，先规划好框架和分类，把高频使用的挑出来，其余的慢慢归位；

15、沉淀某个领域的知识，建议按初阶、进阶、高阶分层记录，并配合实践；

16、整理完不代表知识就属于你，必须通过回顾、记忆、实操和输出才能真正消化；

17、别硬性划分工作归工作、学习归学习，要问自己这份资料在自己的知识体系里该安放在哪里；

18、全平台统一很理想，做不到也没关系，可以在多个平台各自建立分类；

19、旧资料整理起来总让人头疼，越早动手越好。最省力的办法是断舍离：先规定新资料统一进一个平台，然后把旧平台的资料按优先级排序，只搬迁高频常用的，其余留在原地。日常偶尔回想起来能用的再迁移，每周固定整理一个文件夹。时间一久，你会发现真正有价值的都被搬走了，剩下的都是边缘内容，看看你三年前的🛰️收藏就明白了；

20、合适的知识管理过程，本质上也是自我成长的过程；

21、想保留群聊里的干货，可以另建一个专用🛰️群，把需要的信息转发过去，每天整理一次；

22、一条资料多个地方都想放，也别纠结，直接打多个标签，或者先搁置处理其他；

23、听书或听播客时遇到亮点，可以先用手机录音，再用飞书转文字；

24、Flomo 适合记录灵光一现，设置定时回顾，用到时再调用；

25、长文不必全搬进知识库，挑最触动你的点总结一下即可，原文可留链接；

26、桌面分区需求可以直接搜索“电脑分区桌面壁纸”，能找到不少分区工具；

27、觉得🛰️收藏难用可以试试 Cubox，把各平台收藏集中管理，体验会好很多；

28、信息越多越要学会取舍，果断断舍离；

29、别怕错过，真正重要的信息迟早会再次出现，没出现过的可能本就不那么关键；

30、知识整理的终极意义，是让生活过得更好。

如果这些观点对你有启发，欢迎点赞交流。
