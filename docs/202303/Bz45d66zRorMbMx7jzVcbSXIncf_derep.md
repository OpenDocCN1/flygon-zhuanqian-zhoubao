# 【新人参加见面会后必读】如何正确利用见面会获得的信息？

从线下聚会回来之后，我劝你先别急着“冲”。

有人从活动现场回来，兴奋得像握住了财富密码；也有人回来没两周，就陷入自我怀疑。这两种状态，我都经历过。

我的来历：写过九篇被加精的帖子，混圈三年多，线下活动跑过四趟，之后应该还会接着去。圈友常开玩笑，说我是“最懂新手的那个人”，因为新手踩过的坑，我基本都踩了一遍。

头一回参加完活动，我和几个同期伙伴都跟打了兴奋剂似的，觉得前途亮得晃眼。可接下来小半年，大家一个接一个走进低谷，没谁能幸免。当时我们没想明白一件事：会场上的话都是真的，但真话不等于全貌。

这篇文章想聊的，就是如何消化现场收获，别让它变成情绪包袱。

来现场的人，目的其实分三类。第一类，主业已经跑得很稳，想借此把圈子撑大、见见想见的人，顺带了解一些平时看不到的信号；第二类，业务正在爬坡，带着具体问题来，想找到解法或能拉一把的人；第三类，还没找到像样的方向，甚至没有方向，就盼着能发现点门路。

前两类人手里有判断力，通常不会被带偏。最需要小心的是第三类。假若你属于这一类，请往下读。

我到现在还记得那种眩晕感：怎么到处都有机会，随便听一个都像能把自己拽出当前的生活。台上各位发着光，我坐在下面，一边羡慕一边自我怀疑。回到自己的一亩三分地，怎么看手头的事怎么不顺眼：赚得少、不够体面、没有积累。“换！”这念头一冒出来，我就开始压缩原有业务的精力，转头去试现场听到的一堆新门道。试了一轮才醒：哪来完美生意，想省心、长久、门槛低、收益高样样占全，根本不现实。

原因就在这：活动上每个人能敞开讲的时间都极短，台上台下，几分钟、几句话，只能挑最亮的部分讲。换作你，你肯在大伙儿面前揭自家短处吗？多半不肯。围观者一多，讲述者越是只挑好听的说。

于是整个场子传出来的声音，大多是“我干得不错、这方向有赚头”。新手听进耳朵，很容易把这些当成全貌。就像只看果子表皮光滑，便顺手忽略了背面的疤痕。

再叠加两重认知偏差：一是新人只盯着结果看，比如“日入XXX”这类数字，对从零到一的过程没有概念；二是没实操过，想象不出执行路上有多磨人，估算难度时自然往低处走。一边把收益想得过高，一边把难度想得过低，现实和预期之间就被拉出一条深沟。

落到具体动作上，新手最容易踩三个坑。

第一个坑：冲动付费。差距感让人想立刻追上去，想追上去就得学方法，知识付费于是成了最顺手的动作。我不反对付费，甚至一直赞同为有价值的经验付钱。但在情绪高点做决定，买回来的课大概率吃灰。不如先把那股兴奋劲放凉，等恢复正常水平，再判断要不要买。

第二个坑：频繁换盘。我当年回来，第一反应是把自己手头的事说得一文不值，又觉得听来的每个机会都比手里强。这哪是理性决策，分明是“总觉得下一个更香”在作祟。真去试过之后才看清，别人那摊事也有说不出的苦，自己原来的活儿也不是一无是处。圈里有个朋友说得特别绝：拿渣男心态对待生意，最后多半谁都留不住。你也不妨问自己一句：在现在的行当里，你已经做到最靠前的位置了吗？如果还没，凭什么说它不值得做？

第三个坑：中途泄气。想象你尝了一口果子，本以为又甜又脆，入口却酸得要命，你大概吐掉就跑了。可若是早就知道这果子酸甜参半，你反倒愿意接受，慢慢品它的味道。方向也一样：在会场上听到的门道，不是不能碰，甚至值得大胆尝试。真正关键在预期别太满。预期太高，撞上现实的糙砺，人很容易掉头撤退；预期贴合实情，提前把艰难算了进去，碰上麻烦反而能咬牙撑住，直到做出结果。

所以，整篇浓缩起来就八个字：抬头望天，低头赶路。这也是我头一回跑到线下会场时，在门口看到的话。抬头望天，是让你知道世界很大，山外有山。但也别忘了，天上飘着云，云会遮住视线，你看到的晴朗未必是天的全貌。明白这一点，就不必为自己离天太远而慌张，也别幻想一步到位。低头赶路，是允许路程很长、坑洼不断，可只要持续迈步，一天挪一点，走得久了，别人抬头时望见的就是你。

路再长，一步步走也终会到头；总不放弃，想要的日子就越来越近。

最后替线下活动说几句公道话：它确实能开眼界，也确实能让人和人之间的链接变实。跑了四趟，我愈发相信一件事：网上聊得再多，也比不上碰面握个手。我也亲眼见过，上一场还在酒桌上吹牛的熟人，下一次再聚，已经把事情做成了。当外界风向不好时，有这样一个能互相托一把的场子，很难得。以后有活动，我还会去。

写这些的初衷很简单：别让一次开眼的机会变成消耗自身的起点。带上清醒的判断，才不辜负那些发光的分享。
