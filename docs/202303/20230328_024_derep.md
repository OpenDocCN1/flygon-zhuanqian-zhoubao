# 关于社区分区设计的一些想法
作者：龙哥

作者：孤月 | 日期：2023-03-28

作为常驻用户，我几乎每日都会打开社区，从中获得不少帮助。新一期快来了，平台多半要有调整，于是把平时想到的问题整理成文，供各位参考。

先聊聊主页面的栏目设置。导航顶端安排了动态、精华、中标、风向标、收益周报和星球板块。其中精华与风向标最靠前，也可看出它们被优先重视。

进入星球板块后，又分出“航海日常”“实战派”“资源对接”“求助答疑”“项目可行性”“茶馆”等细分区。航海日常与实战派基本停更，最新帖还停在2022年。

本期强调实战的小航海，在星球内却没有太多展示。参加过的人知道，训练营的产出多写在各期航海日志中，存放得很散，优质心得与好消息会被淹没。想翻出来，必须按照“活动主页→特定航次→资料室→精选日志”的顺序逐层点击，步骤太繁琐。

我提议，顶部导航能否专门开一个“小航海”入口，集中放高手拆解和精选日志。营期进行中和结束后，用户都可以在此发帖，记录个人实践情况；对高质量复盘，也可用积分奖赏来鼓励。

现有奖励机制重点是精华帖和风向标两处，它们在导航上的曝光也最高。精华帖如今依旧以长文为主；虽然年初负责人做过规则调整，希望引导短而精的作品出现，但从页面看，长文仍占大头。

由此出现了尴尬：有人发布一篇普通帖文，达不到精华标准，又不能长期留在首页，于是被挪入“茶馆”。但茶馆入口很深，从主菜单要绕好几层才能进入，阅读率自然上不去。

被看好的风向标同样有问题。因为激励较强，每天都会涌出大量风向标，且没有归好类。浏览起来零零碎碎，有东拉西扯之感；完全不看又怕漏掉干货，只看中标又觉不全。若能再做一次细分类，效果应该会更好。

设想某位用户想写项目复盘，内容够不上长文深度，放茶馆会沉底，放风向标又不合适，当下并没有理想分区可去。

整体上讲，社区对归类这件事不够上心。虽有项目库，但库内很多资料仍停在2022年，收进精华文章的只有少数项目。更何况不仅精华文章需要归类，普通帖文也应有清晰去向。没有好好归类，各类内容就都堆到首页、精华和风向标里，读者取舍不易，阅读压力随之变大。

不少用户的积极性还能被进一步调动。当前访问频率最高的是首页动态、精华帖和风向标，其余分区比较冷清。若能尝试更多激励玩法，让其他分区也有足够曝光，或许整体产出会更旺，互动也会更高。

下一期训练营多半还是重头戏。如何沉淀营内涌现的好内容，如何鼓舞大家亲自下场并彼此切磋，这些都是团队可以去琢磨的地方。

愿社区越办越好。以上只是个人浅见，若有不当，请多谅解。

评论区也有几条意见值得记录：有人反映，在索引站用关键词能搜到文章，然而打开后无法定位到原文所在位置。另一人回应，该情况已报给团队。产品同事补充，训练营资料主要依赖索引工具，高手拆解会另外发帖；建议🛰️内打开时设置浮窗，或使用电脑端体验更佳。一位做海外招商的朋友说，自己此前完全不知道要绕这么多层才能看到日志，这个痛点确实真实。刘哥建议，检索和归档功能需要继续强化。团队里也有人表示，不少建议已在讨论或落地中，内容展示与归类是新一轮优化重点；风向标的问题，团队表示目前可在飞书文档中作临时参考。最后有人提议，搜索可接入AI接口，用联想推荐替代简单的关键词查找。
