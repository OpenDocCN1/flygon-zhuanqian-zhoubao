# 数字人直播，真的已经进入应用期了吗？

各位好，我是 龙哥，好久没冒泡了~

最近在抖音上频频看到数字人直播间，呈现效果非常逼真，画面流畅、互动自然，不懂行的人很难分辨内核是真人还是模型在驱动。

话题火起来后，朋友圈和社群里讨论度也明显上升，大家最关心的几个点集中在：

1. 组建一套数字人直播的成本区间大概是多少
2. 这类虚拟主播在平台规则下是否会被判定为违规
3. 虚拟形象能否按照真人形象进行一比一的定制开发……

正好近期我一直在做数字人直播的技术梳理，也结合了去年无人直播的实操经历。今天就把我调研到的实际表现、隐含风险，以及落地可行性的判断思路，整理出来和大家分享。
