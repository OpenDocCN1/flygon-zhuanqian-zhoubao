# 归队手记：离开两载、空窗数月后的再出发
作者：龙哥

发表于：2023-03-31

这一周，社群主理人在张罗老圈友回归，问我当初为什么选择加入。我迟疑片刻，竟然说不出一个明确的理由。连最初的出发点都模糊不清，后面的路自然容易原地绕圈。

后来我意识到，加入一家公司、一个社群，甚至建立一段亲密关系，底层逻辑都差不多：先想清楚自己期待什么，再弄清楚对方能给予什么。把两边列出来做比对，重叠的部分越多，双方的匹配度就越理想。

以下是我当前梳理出的答案。

这个社群能给我的：

**1. 知识储备层**
- 跨行业的创收信息已被系统整理
- 很多内容在常规搜索工具里完全找不到
- 相当于一部专属的生意思维百科
- 最关键的是，内容作者本人可以直接寻访、请教

**2. 人脉连接层**
- 云集各路真实搞钱的实践者
- 大家目标一致，且都付出了学费证明自己勤恳，哪怕仅结识一下也很有价值
- 可以在较近距离内观察头部玩家怎么思考、怎么行动

**3. 行动助推层**
- 来自资深者、同路人、后来人的持续推动力
- 实战案例极丰富，便于学习和借鉴
- 有固定的小组同学，能互相补位、补齐短板

我期望从这个社群获得的：

1. 靠我自己无法构想出的创收方向
2. 在信息尚未大面积流传前就接触到那些苗头
3. 别人从想法到落地的全过程，尤其是执行中的细枝末节
4. 有经验丰富的老手直接带队操练项目
