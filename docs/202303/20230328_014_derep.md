# 关于时间打理的底层思路与落地方式

主讲人：Erik | 2023.03.28

时间这件事，大家嘴上都说重，行动上却常放空。

说它重，是因为人人明白一天只有 24 小时，同样一段时段，有人能产出清楚的成果，有人却耗在杂事里，差别全看怎么用时。

说它易放空，是因为市面上的方法论太多，听上去都很对，用到自己身上就卡壳，不知道该怎么开局。

我对个人节奏的好奇大概始于十多年前，一直在想怎样让工作有条理、生活不被吞噬。受 Ray Dalio《原则》影响，思路变得清晰：先锁定几条不可动摇的底线，再拿真实场景去打磨动作。如此反复迭代多年，慢慢沉淀出一条简洁且能长期坚持的操作路径。
