大家好，我是乔帮主。这轮航海终于收尾了，总共跑了11条线。

11个航海项目，10条线全勤打卡21天*10=210次，加上1次同城航海聚会打卡，合计211次。里程累计航海2240里，其中精选13次。

在🛰️群里分享过1次，赚钱星球分享3次，👸号发了6篇推文。21天内把10个航海项目的全部手册学完，还跟帖学习了上百次群里大佬的分享，每个项目都照着SOP真刀真枪跑了一遍。

中间也出现过动摇、泄气、摆烂、想退出的时刻，最后靠目标驱动、持续执行、自我激励、圈层正反馈硬是把卡打满、成功上岸。

借这个机会，把这段经历复盘一下，也算是给自己留下一个高光记录。

# 1、21天定的逻辑是什么

航海为什么是21天而不是30天、20天或15天？

因为21天定律，也叫21天法则。重复做一件事21天就能养成习惯。

研究显示，大脑形成一条新神经通路大约需要21天。当某种行为暗示重复21天以上，就会形成习惯；重复90天以上，就能固化成稳定习惯。所以大家常说，一个新习惯或新理念的成型与巩固，至少要21天。

# 2、你最想从航海里带走什么

有人奔着结果来：引流、赚钱。
有人奔着成长来：学技能、看行业。
还有人奔着人脉来：整合资源、碰撞合作。
我三者都想要，但这并不是我最核心的诉求。

2020年我辞职创业做社交APP，因为技术团队认知偏差和过度自信，项目最终流产。至今回想起龙哥说的“亏钱套路之非要做个产品”仍有共鸣。

2022年我打算切入知识付费赛道，开始做同行对标研究。那一年也接连遇到两件变故，整个人长期处于精神内耗里。

创业大哥一直劝我回去上班，他说：“公司有平台、有圈子，你才有归属感。你一个人单干，没平台没圈子，很难成事。”

我认同这句话。每个创业者都要走过从0到1的过程，但过程确实需要外部环境支撑。

为了找到一个能提供正能量、能给我正反馈的平台和圈子，治愈内耗。这才是我在赚钱参加航海，并用21天定律来达成最想拿到的东西。

# 3、我是如何挑项目的

报名不是越多越好，没规划的盲报只会浪费时间，最后还容易陷入负面情绪。

除了治愈内耗，我第二个目标是成长：学到能用的技能，了解行业和引流平台的一线SOP，为后续布局做准备。

所以筛选标准很简单：补自己的短板、对当前业务有帮助。越选越顺手，最后10个项目+1个同城聚会就成了11条线。

# 4、211次打卡、2240里是怎么来的

## 4.1、时间怎么排

我每天工作大概12小时，其中2小时写10个项目的日志复盘，6小时左右做航海实操，剩下的4小时处理其他事务。

航海刚开船时，10个航海大群+10个通知群，信息直接爆炸。我第一三天试着看满所有消息，结果根本跟不上20个群刷屏的速度。

![](img/d7e4538b1265054e059066e8e6c60272.png)

后来我只盯通知群里同步的高手分享和优秀船员的打卡记录，把关键信息提炼出来，做了大幅降噪。生活里也是这个道理，学会信息降噪、减少无效社交，把专注力放在真正重要的人和事上，才是高效工作的底座。

从商业视角看，这些看似独立的航海，其实是一套变现闭环：底层是时间管理+资料整理+同城聚会，前端是抖音+📕等公域引流，后端是👸号+朋友圈+社群承接变现，再叠加Web3入门+AI绘画&ChatGPT做持续迭代优化。

搞清这个知识网络后，每个项目就都是赚钱路径上的一个环节，环环相扣。知识积累、内容输出和打卡自然就有章法，不会手忙脚乱。

## 4.2、目标驱动 + 持续的执行力

21天里不少圈友已经拿到流量和收入，不用羡慕。光鲜数据背后都是付出和磨难，也需要对应的能力支撑。

我只是赚钱路上的小学生，主要任务是学习、参考、复制成功经验，提升认知力、执行力和专业力，找到可执行的路径。

大部分圈友都是新手，航海前要先做足功课，摸清自身能力、定方向，再制定目标结果。有目标就不会被别人的节奏带跑，进而焦虑、摆烂。

持续执行是关键。只要执行到位，再难的事也能磨成事。对比社群里《玩赚ChatGPT社群精益创业的七天实录》里那批小伙伴的执行力，以及第一波吃到ChatGPT红利的人，我自己直到这次航海才真正把ChatGPT用起来，确实愧疚。

## 4.3、自我激励

21天只是成功路上的一个切片。目标驱动之外，执行力需要自我激励+圈层正反馈来维系。

很多人坚持不下去，理由都是工作忙、时间不够。其实那只是不想做事时找的体面借口。

![](img/5f4b6815a19c1c1f66559d4ea4b512c3.png)

![](img/5799cf8a182ab9c18c36a41eebdef6b4.png)

动力不足、执行力下滑，本质是赚钱欲望不够、刺激不够而已。

龙哥那句话很像鞭子：“如果有人在你身上绑了颗炸弹，要求一年内必须合法赚到100万，否则引爆，你会怎么赚？”

## 4.4、圈层正反馈激励

自我激励之外，需要圈层的正反馈。最核心的方式是分享，坚持利他。

把自己的成长、心得、收获、正能量持续输出，就会筛选出志同道合的人，获得尊重和支持。马斯洛需求金字塔顶端的归属与自我实现，正是这种持续的燃料。

![](img/952ce791c9d99ab7c35a889ede6b65a7.png)

我在👸号爆款笔记、资料整理、📕、社群运营等群里做聊天分享，在知识星球、👸号、朋友圈持续输出干货，收到了大量圈友的支持、感谢和实操反馈。利他即利己，动力自然不断。

比如《利用技术思维，高效打造资料&素材军火库，持续提升你的内容输出火力》在🛰️群和星球分享后，得到125个点赞和200篇打卡作业的正面反馈。

# 5、11个航海，我具体收获了什么

在赚钱这个平台上，通过航海汲取能量、获得志同道合者的正反馈、治愈精神内耗，这已经是我最大的收获。

当然在项目层面也有很实在的产出：

1. 资料整理航海：梳理了个人资料素材库的知识结构，把4T工具箱整理出来分享。意外发现航海资料库是座大宝藏，以前只看星球帖子，现在多了长期内容创作的弹药库。
2. 抖音图文、📕IP、📕爆款笔记航海：只发了两篇笔记，数据很一般，但完成了从0到1。以前不知道图文怎么发，这次把细节跑通了。
3. 时间管理航海：最好的时间管理不是为管理而管理。用目标驱动+执行力+自我激励+圈层正反馈完成11个航海全部打卡，这本身就是最好的答卷。
4. 👸号爆文写作航海：搭建起个人IP👸号体系，推送6篇原创，建立了私域承接的基础盘。
5. 社群运营航海：对社群搭建、规划、目标有了清晰认知。对IP社群帮助很大。特别是群里《如何做好20%的组织架构，让社群自生长》那次分享，收获巨大。
6. 朋友圈运营航海：王子冯老师总结的观赏价值、情绪价值、专业价值，让我对朋友圈运营豁然开朗。明白它像做内容一样需要素材沉淀、长期迭代，从此有意识积累朋友圈素材，稳固了私域转化模型。
7. Web3入门航海：之前几乎零接触，这次系统学习后没有在风口掉队。
8. AI绘画&ChatGPT航海：玩了Stable Diffusion，和圈友一起定制个人形象出图工具。ChatGPT已成为写作和标题生成的日常辅助工具。
9. 同城航海聚会：线下交流最深的感受是三人行必有我师。择善而从，不善而改。
