# 《聊聊你做闲鱼二手书项目失败的 100 种可能性》
作者：龙哥

昨晚有位社群成员发来私信，说从我去年12月发出的一条内容里得到了启发，如今每月靠它多赚了六千多。讲真，那篇东西连操作指南都算不上，只是给了一个风向。但这股劲头让我确信：执行力在线的人，放在哪个领域都能跑出来。

![](img/e4329bd5194cbe3a59b8e7df270265cb.png)

我于是回头查看自己去年12月留下的那篇内容，确认就是那条简短的行情消息。今年3月我又补了一份更详尽的拆解，讲旧书生意的五种玩法，比如不压库存的转售、绝版书捡漏这一类。现在闲鱼对个人卖家的入驻也更宽松，App里找到认证招商的页面就能提交申请。

不过我更想聊的是：为什么这个生意听着不难，做起来却总有人中途离场？旧书我是龙哥，换个赛道，失败的脉络也大差不差。假若你在这个社群蹲了挺久还没见到回头钱，对照下面几条，看有没有中招。

第一个劝退点：把难度想得太低。

有人听说我靠旧书做出七位数收入，就以为每天挂几条链接，等着系统派单就行。真正上线后，冷启动的寂静比想象中难熬。两星期不见订单，信心就开始晃动，随后丢下一句：“这项目就是个坑。”据我观察，一些口碑极好的陪跑营，学费收几千，结营之后真正出单的人不到一半；能做到月入过万的，更是个位数比例。短视频带货的人，谁没陪葬过几个小号？闲置书账号被限流、被封禁，同样会来。没有这种心理准备，前半个月的冷清就能把你打回原形。

第二个劝退点：对平台规则没当回事。

大家都迷信捷径，总觉得用程序自动传商品就能躺赚。可违规书目、一物多发的警告一天堆出好几条，然后一封就是七天。很快这个副业就画上了句号。时间久了你会发现，成熟的平台都在收紧粗放玩法；老老实实按规矩走，平台反而愿意分你流量。

第三个劝退点：盲目相信技术工具。

我见过很多做旧书的同行，也跟一位被圈内当成榜样的朋友聊过，他到现在仍是人工逐本发布。我们工作室的模式也差不多：请了几个大学生，负责筛图、填资料，手动挂商品。而同期迷信采集群控的那批人，最后几乎都没有声响。

![](img/44afaab4fd26f909a28a90843657c6cc.png)

你想过没有，买家搜到一本书，看到满屏结果时，手指会落向哪里？一般人的第一反应，是划掉那些零“想要”且标价高、封面又不吸引人的条目，然后在剩下两个之间选：一个胜在画面是真实拍摄，还有人气的标签，很容易制造从众；另一个胜在价格低，已经有几条“想要”，配图也讨喜。工具自动上架的东西，一是内容质量天然弱于人工；二是每天发上百条，根本没空给商品做数据，比如随手点几个“想要”；三是更不会先定低价换来销量，等数据漂亮了再逐步抬价。输，就输在这些细节上。

第四个劝退点：把找书源当成主业。

每隔几天，就有人来问我要供应商的联系方式，前前后后至少几十次。

![](img/822bf659fdbde0f5e64e14121924b839.png)

最让我不解的是，有人翻遍各种群聊、帖子，天天都在找，找得特别认真。这种努力其实是一种逃避——用“搜集资源”的忙碌感，掩盖不敢直视业绩的恐慌。找到渠道的瞬间会有些许安心，可真到成交阶段，照样被打回原形。

创业两年多，我最大的感受是，现在不缺产品。对一个新手来说，书源根本不是壁垒。把有限的精力投到流量和成交上才是最划算的；只要你能稳定卖货，供应商会主动来找你。与其自己从零做知识付费，不如帮成熟社群拉新，后者简单得多。

第五个劝退点：总想搞重资产。

昨晚有个大一学生非要连麦聊，开口就憧憬几千平方米的旧书仓库，还规划了一整套愿景。我把他劝回去了。实业当然值得尊敬，但那是有了底子以后的事，新手阶段还是尽量玩轻的。

我有一间上千平的仓库，但它的盈利能力，反而不及我在小区里用三十个闲鱼账号做代发——后一种模式不占资金，利润还更好看，这话说起来有点讽刺，实体却往往投入大、耗神多、毛利薄。

![](img/a26a91ac84ba32cde14c0b52a335672f.png)

最后一条，覆盖了第六到第100种失败的可能：总等着别人来逼你赚钱。

“我上传500本，大概能有多少回报？”
“要运营多少账号才能月入一万？”
“现在起步做旧书，还赶得上吗？”——这问题，我12月被问一次，1月被问一次，2月被问一次，3月又被问一次。
“跟着你干，能保证我赚钱吗？”
“我打算辞职全职做这行，可不可行？”
“一开局就搞工作室，目标年收入30万，靠谱吗？”
剩下的几百种问法，翻来覆去都是同一个意思。

![](img/e7fdca4cb19dc9906ee5c9d10edfc73e.png)

社群主理人龙哥发过一张图，我深表赞同。钱这东西，别人教不会，只能自己在实践里练出来；要是一件事从头到尾都有标准答案，那大家何必上班、何必搬砖？读书时，老师可以用请家长威胁你；上班时，老板可以用扣工资逼你。可成年后，谁又有义务来逼你发财？没有的。你只能对自己下手。

我是老瞿，持续在社群里死磕旧书这门生意，希望2023年能链接到更多同路人。下一篇准备聊：怎么把旧书这样一个微小的类目，用一套标准化工序，放进普通小区里做成年利润七位数的生意。
