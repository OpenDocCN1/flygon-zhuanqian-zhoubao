# ('《 ChatGPT 和文心一言的影响力都被低估了》', (2, 27))

《GPT和国产大模型的真正冲击，可能还在后面》

那个午后的一通电话，到现在仍让我反复琢磨。

我和一位沪上老友，以及一位创办过多家科技企业的连续创业者，聊了差不多一个钟头。放下电话后，我意识到自己对世界的感知存在明显的盲区——很多变化已经开始，我却像最后一个知道的人。

那位创业者从去年10月就开始拿GPT做各种小实验。那阵子，国内几乎听不到相关讨论；到了今年年初，热度突然飙升，他已经是场内人了。他在电话里讲了几段话，我一边听一边记：

——海外科技圈早已默认大模型是新一代基础设施。有人甚至放话，三年内软件开发岗位会大幅缩水。那些低端、重复的活儿，被工具取代的速度远比想象中快。

——大模型的智慧程度被严重低估。尤其在中国市场，很多人只把它当成聊天玩具。可一旦联网，它已经懂得通过社交平台上的互动，让真实用户帮它跑任务。这不是“更会聊天”，而是“会指挥人”。

——未来三到五年，最值得押注的方向就是大语言模型。当初被炒得火热的元宇宙，和它完全不在一个级别。错过这一轮，下一轮不知道要等多久。

——很快，市场上会出现各种“大模型使用指南”“调教课程”和训练营，甚至出现专门帮人调教模型的职业。

——国产大模型没有想象中那么弱，尤其是百度的AI助手。大众习惯拿它当段子找乐子，却忽略了一点：在中文环境里，它能完成的任务其实很多，也更贴近普通人的需求。别总盯着海外。

他也坦言了自己的焦虑：世界变化太快，自己刚做出一款基于大模型的产品，整个市场的风向就变了。不过，他眼里仍有大机会：在三四线城市和广大县城，AI基础教育几乎是空白，谁能用最简单的话讲清楚大模型，谁就能占领这片信息洼地。而我们这些常驻一线城市的人，往往把身边的热闹误当成世界的全貌。

挂电话之前，他半开玩笑地对我说：“授予你联合创始人的身份吧，你去社交平台上好好讲讲这些事。”这句话让我猛然清醒：无论技术如何更替，能搞定流量和分发的人，永远都是稀缺资源。我自己离这个标准还很远。平台规则在变，用户口味在变，内容创作没有终点——每一天都是新的起点。

顺手把评论区的碰撞也记在这里：有人说大模型迟早重构软件行业；也有人说AI才是元宇宙的底座，而元宇宙是数字世界与真实世界的整合体；还有人争论第四代模型是不是去年出炉的，最后达成共识：在那之前，早就有了初级版本。
