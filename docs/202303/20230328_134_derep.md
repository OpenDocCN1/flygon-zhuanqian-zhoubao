# AI 拉高生产效率后，普通人的 Web3 机会要从哪里找？

前几天我做了一场闭门分享，主题斟酌了很久，最后定为：AI 改写效率天花板之后，普通人还能从哪个角度切入 Web3。

先介绍下自己。我一直待在 Web3 赛道，做产品出身，现在也参与数字资产投资。在某个偏实战的搞钱社群里，我负责航海版块的内容策划和陪练，日常带人拆项目、梳理逻辑、一起做操作演练。

三个月前，我分享过一版《在 Web3 里怎么变现》。那之后自己下场跑了几个月，体感更新了不少：AI 把生产效率往上推了一大截，但紧接着被改写的往往是协作方式与分配规则。对普通玩家来说，真正值得盯住的不是最前沿的算法突破，而是新规则切换时短暂出现的空档。

为什么这样说？算力、大模型这类重资产，终究会往头部集中；但人与人的协作关系、利益怎么分，每隔一段时间就会重来一轮。谁更早看清规则走向，谁就能先占住入场位。

分享结束后，讨论区留下不少追问，挑几条有意思的摘录放在这里。

有朋友提问：Web3 底下的分支很多，NFT、DeFi、链游、投研、机构投资都在跑，你个人主要做哪个方向？

我的观察是：圈子没想象中那么大。大陆范围内，够得上「Web3 活跃玩家」的，估摸也就一万上下。这个口径要求对方看得懂公链、会研究项目、实际下场参与；单纯买卖筹码的，我没算进去。

对方补充道：你这风格明显偏社区向，DeBox 和 RichDAO 里都能看到你的身影。

我回应：算是项目开发和社区运营两边都沾。人数已经这么少了，再细拆没太大意义。说穿了，眼下还在跑的这些方向，底色全是数字资产的金融逻辑。

另外有圈友反馈文档链接打不开，主办方在下面回复：我刚试过没问题，你重进一下？另一位表示：我反复试了几次，还是报错。
