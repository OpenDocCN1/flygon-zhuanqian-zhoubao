# ChatGPT 插件时代，流量入口可能正在改写

我是龙哥。早上翻社交动态，满屏都是关于 ChatGPT 开放第三方扩展的热议。细读之后，一个判断越来越清晰：这也许意味着大量类似 SEO 的新机会正在长出。

先说参照物。在内容分发赛道上，抖音和 TikTok 算得上最典型的样本，它们把兴趣匹配和主动查询结合得很到位，让用户感到“被读懂”。

而 ChatGPT 开放扩展能力后，人与模型的交互核心非常单一——搜索。一次对话就是一次目标明确的检索，检索等于精准，精准背后是更高的转化概率。熟悉数字流量运转规则的人，马上能嗅到接下来的变局。

我觉得这不只是新增一个入口，更像是比抖音/TikTok 分发逻辑更高阶的形态，定制能力更突出。关于这一点，我做了完整分析。

![](img/462e86f0a333aa576e128129e80f8747.png)

讨论区里也有不少干货。一位叫 D 的读者说，他已经把模型调教成自己的私人助理，追问训练方法；一位署名张老师的读者点出，长期依赖会演化为信任，信任恰是商业的开端。技术派读者 Yuti 则提到，早期 NLP 主要用 RNN，GPT 基于 Transformer，担心旧书是否过时，作者回应说可以从第七章切入。云飞还介绍，他的做法是把高频文字工作拆解成标准流程，再转成 prompt 模板逐一打磨；如果不想自建环境，在网页对话框里反复调教也能做到。有人问是不是在本机跑 GPT-3，他澄清是 3.5。

当“对话即搜索”成为默认入口，流量分配的新一轮洗牌，可能已经在路上。
