# 《普通人买卖旧书的赚钱机会分享——二十年淘书经验分享》

聊个挺有意思的副业路子：普通人倒腾旧书赚钱。

这事儿纯属个人兴趣误打误撞，我玩书二十来年，买着买着，也卖着卖着，攒了不少经验，一直想系统整理一下。以前在线下活动里跟朋友唠过这事儿，他们觉得挺新鲜，催我写出来，可我这人拖延症晚期，脑子里翻来覆去构思过无数遍，就是不动笔。后来立了个flag，说写五千字，逼自己一把，这才终于落笔。

我真正对旧书这圈子开窍，得追溯到高中时代。学校门口有个老大爷常年摆书摊，摊上时不时有七八十年代的竖排繁体老书，古典文学居多，偶尔也有特殊时期的鲁迅单行本、红封面小册子。那是我头一回见着线装书，大爷手里还有本清前期石印的，他说是孤本，后来还给我复印了几十页，我自己学着装订成了线装模样。带着这股好奇劲儿，我在网上查资料，2004年注册了孔夫子旧书网，混论坛、结识同好，又陆陆续续接触到出版圈、书店圈的不少朋友，算是正式入了行。

# 一、旧书到底从哪儿冒出来的

想在网上开个小旧书店，或者闲时收收书换点零花钱，货从哪儿来？渠道其实不算少。

**挨家挨户上门收。** 孔网有回收功能，但简陋得不行，信息也少。早年那些旧书店门口大多挂块牌子写着“回收旧书”，量大店主还能上门去拉。老一辈的版本学家，几乎都是从书店学徒做起，挨家收书、日积月累练出了辨别版本的硬功夫。现在最常见的倒是收旧货的顺带收书，这些人多数不懂书，收到就转手给书摊或者废品站。

**凌晨四五点的书摊。** 老书摊市场的热闹七八十年代那会儿是真不得了，后来因为各种原因，路边摊整治得没了影儿。2008年之前我还经常逛摊，后来习惯网上买书，去得就少了。现在多数城市统一搞集中旧书市，一座城市一般就剩一个，周六日开张，北京潘家园、南京朝天宫都是这种路子。摊上的书价格实在，来源大多是收旧货的自己拿来卖，或者有人从废品站挑回来周末出货，也有经营不下去的旧书店在摊上清库存。懂行的人都知道淘书得赶早，凌晨四五点的摊上才有好货，晚了就被人抢光了，大白天还在的，要不价格离谱，要不就是没人要的普货。

**废品站的捡漏玄学。** 废品回收站里的书，基本都是收旧货的人倒腾过来的。早些年真是遍地是宝，我记得2004年那会儿，还从废品站翻出过一批特殊时期的邮票。废品站最大优点是便宜，论斤称，老板不识货就赚翻，老板要懂行就得斗智斗勇。

**网络平台。** 网上想捡漏挺难，不能一概说没机会，得专门细说。主要难点在于平台活动太多，不少店主双十一之类的节点低价囤书再正价卖，比出版社进货渠道还便宜。

**新书店和出版社的库存。** 跟新书店合作进货，买他们品相不好或者滞销的书。出版社库存里更有好东西，但需要你有出版社发行渠道的关系。

**图书馆淘汰。** 不少图书馆会把旧书处理给二手书店或专业机构收点回收费，价格不高，毕竟书都用旧了，有些还破损了，另外图书馆若裁撤，肯定也得清书。

收书的时候得有取舍，书的质量和品种得把关，顾客才能满意，同时成本得算清楚，卖价才有利润空间。传统旧书行当的规矩是教材和教辅不收，新出的杂志也不要，不过如今不少店专做教材教辅，别人说过我就不展开了。

# 二、价格高低到底由什么决定

二手书定价，大体逃不过这几点：

**版本和印量。** 稀少的版本和印次价值高，物以稀为贵，价格自然上去。市面上老说什么“绝版书”，这话其实不准确，任何一种书的某一版本身就是绝版了，只有印量又少、市面上找不见、自身价值还高的书才值得收藏、卖得上价，有些书印了几百本照样一文不值。

**品相讲究。** 品相直接影响价格。封面、页边、页角若有磨损、撕裂、污渍，价格就得往下压；反之洁净完整，价格往上抬。收藏的人往往不是为读，为的是藏和展示，讲究十品、全新、未拆封，觉得残破的书就丢了它承载的历史文化价值。还有一点很实际：藏书是投资资产，品相好才保值增值。一本全品相的书价格往往是普通品相的N倍，这些苛刻的藏家要是买到不合心意的品相，是真要求退货的。

**稀缺性与市场流通率。** 说到底稀缺性是流通率在供需关系上的体现。市面供大于求的，价格跌；供小于求的，价格涨。但也有书具备独特性，比如存世极少的孤本、不公开发售的内部版、特殊渠道的供给品——六七十年代专供毛ZX和部级干部看的大字本就是典型——还有曾经公开发行后被禁、不许再加印的，以及特装定制版等等。![](img/7894bf70cb75f6b0b8b41c46b77920d7.png)

**附加值。** 书里有没有附带额外的好东西，比如作者签名——尤其是名家签赠名家——还有藏书票、毛边本这些，都是加分项，对价格影响很正面。签名版、特装书、藏书票这一摊子需求，值得单独开一篇细聊。![](img/50c10bbef576265957bd6b989791dc15.png)

# 三、普通人的差价路数

## （一）跨地域搬砖

**港台往内地。** 港台有大量内地没能出版的书，有些能通关，有些能人肉带进来。内地说起来做港台书的大商家也就两三家，个性化需求他们根本服务不过来，这就给个人留了口子。![](img/0feee01f048a45f9702ad13abfeeb5f7.png)![](img/e334d4d097c0f860120c025b9e8dc516.png)
靠着地理位置，广州深圳不少人在做这生意，人肉去港台书店淘书运回内地。也有跟对岸出版社预定定制特装本、包库存书的，除了孔网之外，那几个人在🛰️群卖得风生水起。

**日本往内地。** 日本二手书业发达得惊人，神保町古书店街、世田谷书店街、新宿旧书街，名头响当当。中日历史渊源让不少中国古籍书画在日本有着丰富的印刷出版物，比如比较出名的二玄社书法法帖。淘的书的门类也多，还有人专门做侵华史料，在日本能找到大量稀缺的第一手资料。孔网上那家“沫沫小姐的书店”，干的就是这门生意，常年在日本各地淘书运回国卖，感兴趣可以搜来了解。![](img/c482114a0aac9be94fa17fb89b169961.png)

**欧美往内地。** 西欧尤其流行过真皮装帧书，用牛皮包书壳，看着高档精美，这传统能追溯到中世纪，到19世纪末20世纪初臻于巅峰，那会儿欧洲印刷装帧技术都在起飞。真皮书成本高，价格也漂亮。这套装帧工艺在杨小洲、俞晓群和王强的推动下已经进入中国市场，可以关注下草鹭的出品，新发的真皮书一般是680元起步，我早几年在网上买的欧美真皮书300块上下，现在价格也翻倍了。欧美的旧书集市和知名旧书店都有珍本可淘，运回国内加价卖就行。

## （二）平台间穿梭

不同平台倒卖二手书是常见的玩法，但不是说稳赚不赔。你需要对市场有足够的敏锐度，能看出哪个平台价格有空间，还得了解书的价值，判断买入后有没有升值潜力、该定什么价。道理就这些，各平台多逛多看基本就能上手。主流平台的路数，给大家指几条道。赚不赚钱看悟性，就算不赚钱也不亏——好书留下来自己读、送朋友都挺好。

**孔网进货，孔网出货。** 孔网新书广场常放签名书，看中了就下手，大名家的要靠抢，一般的也能卖完。看到销量不错的款、准备卖断的，跟着下一两单，货到了再上架到自己孔网店铺。孔网逢年过节有礼包活动，打包均价都挺低，可以入手。平台上那些标价明显低于正常行情的书，有时是店主不懂价，有时是想快速出手，盯着新上架的便宜货买进再上架到自己店里就行。拍卖这个口子也有漏可捡，平台多了、大家注意力分散，而孔网的拍卖关注度不如以前，竞价不激烈，很多人拍完忘了结拍时间，认真盯着还是有机会。不懂的书就只碰两三百块以内的，只要低于过往销售价就行。

**中图网（或其他买书平台）→孔网（📕同理）。** 中图网在孔网也有店，别忘了他们的书少一本是一本。淘书团里虽然好书不多，但偶尔有好货价格不高，眼光得练。去年红楼梦毛边本，598抢到手，转手在闲鱼或者孔网加价300到500，都是被秒的。![](img/a7da232cc10a765f4b23d47ef5e469df.png)![](img/0ba43cd63e79669defffc3f978432007.png)

**孔网→闲鱼/微店/📕。** 孔网上买的港台书不能在孔网上架，可以自己开微店或者闲鱼用点小技巧卖。我从前年开始偶尔在📕晒书，就300来个粉丝，也卖了几十本出去。

**ebay→孔网。** 从国外平台买外文书回孔网卖，港台书不让上架，外文书可以。利润空间在欧美到内地的路子说过了。

**多抓鱼→孔网。** 多抓鱼预定稀缺书再卖到孔网，这事儿很多搞培训的纯属误人子弟。多抓鱼标稀缺基准和定价，都是扫的孔网数据，可孔网标价普遍虚高，光看两个平台价差判断，问题很大。而且预定显示的价格和实际结算价格差多了——比如一本稀缺书预定200块，等两年到货，可能要付400块，平台总是比你想得聪明，中间那点利润没想象中诱人。鱼的价值和获鱼成本也得算：早期卖一本未拆封新书就送几条鱼，现在为了推新书买他们的书才能有奖励鱼，还越给越少。把卖书亏损（跟孔网比）和买新书成本一起算，预定书再出二手的收益真没多少。还有必须吐槽——多抓鱼的包装太水了！苦等几年的一本稀缺书，寄回来可能已经损坏或者品相不佳，这种书就算跟孔网有价差，品相一打折扣，实际利润也大幅缩水了。但这并不意味着多抓鱼完全没有机会，关键在于你能不能找到平台没有注意到的稀缺书，用较低的成本（不用鱼或者少量鱼）买到再以合理的利润出手。即使要预定，也得挑价差极大的那种，普通书几十块钱差价，真不如去工地搬砖。

**从个人手里收，在朋友圈卖。** 五六年前我联系上一个香港作家港版书的渠道，100多块入手，加价50出手，后来这书转来转去，现在有的已经破千了。有些书想买的人就是买不着，加价也甘愿——这心理外人很难理解。搞收藏的可以为一只花瓶卖套房，也能为了一本书搭进去几个月工资。我认识一个温州朋友，就靠左手买右手卖的节奏，上班之余做副业，兴趣赚钱两不耽误。![](img/169c3df33dc0450680c91efd361f7d6d.png)

**给书店供货。** 有货可以往书店供应。![](img/08852a759a71e25e6dec3a3e17f2cfa7.png)![](img/a76e5be0511b7e97b988ae33aaff4078.png)

**网上找货，视频号拍卖。** 手里有好书就能在线拍卖，可以关注布衣书局、鱼书房二手书店、悠小鱼这几家。上面的路子都能用来进货，也适合做私域。![](img/13459780772b85b3ffbb8b9bd5ec2e37.png)

## （三）修复增值

古籍修复能赚钱，如果会一点简单的修复，能不能买品相一般的书回来修一修再卖呢？能。尤其是90年代、2000年前后的书，修复难度并不大。

# 四、说点注意事项

先强调：做这行一定要懂版本知识。

搬砖的收益要计算隐性成本。买书的邮费、手续费得合计清楚，卖书还要空出平台佣金、税费，这些都吃利润。所谓绝版书，靠扫平台价差不靠靠谱？得看风险和波动性——市场行情和书的价值是波动的，可能买贵了、可能卖亏了、可能根本卖不掉，全都有风险。至于无货源能不能做，考验的不是对书的理解，这事儿别人发过不少帖子，就不展开了。

# 五、需要办资质吗？

年销售额5万以下不用办。多做几个平台，每个平台卖几万不也挺省事？再加上平台引流、🛰️成交，不也顺畅？个税按平台规则来，但真注册了个体工商户就得正规纳税，这个绝不能含糊。要正经经营，鼓励大家守法合规搞；业余搬砖赚个万把块钱，真不必大动干戈。平时听到的因为缺出版物经营许可证被查的案例，基本都是因为卖了不该卖的书，仅此而已。
