# ChatGPT 周边生态：浏览器插件这条赛道怎么打



## 《ChatGPT 应用生态之浏览器插件观察》

作者： 三林 
日期：2023-03-24 

大家好，我是龙哥，目前在龙哥盟团队做产品经理，主要负责航海相关产品。上周三晚上我在「英文工具站」航海群里做了一次小分享，主题是围绕 ChatGPT 产生的第三方浏览器插件：它们在做什么定位，体验上有哪些值得玩味的地方。

先说为什么浏览器插件会成为一个很合适的切入点。ChatGPT 目前的核心承载还是网页端，插件本质上是对网页的增强。是在用户原本就很熟练的使用场景里做体验升级，顺着习惯走，用户接受度自然高。相当于站在官方产品肩膀上做加法，把原生的短板补齐。

这次梳理了十多款插件，整体可以归为两大方向，一类是提示词模板类的，一类是效率工具类的。具体名单和截图见文末附图 ……

从这批产品里，我总结了几条自己的心得：

1、开发者的工作重心正在迁移，从过去的面向 Google 编程，到现在面向 ChatGPT 编程，这个转变身边的开发者都感触很深。

2、ChatGPT 更像一个魔法百宝箱，而能打开它的钥匙就是 Prompt。好 Prompt 就是流量密码，也是变现密码。

3、浏览器插件只是一种载体。等 API 真正开放后，想象空间会更大。甚至可以说，一条 Prompt 就是一个 Mini Tool，一套 Prompt 就是一个 Mini SaaS。

4、回到自身，先思考业务里有哪些真实痛点，然后大胆用 ChatGPT 给自己和团队赋能。

5、最后一点也最关键：考虑到原生产品体验的局限和内容安全风险，建议优先考虑出海做产品。这也是我们坚持做英文工具站的初衷。

———— 注：文中的「插件」特指 Chrome 等主流浏览器的扩展，并不是 ChatGPT 凌晨刚开放的 Plugins 能力。新的 Plugins 体系变化很大，我计划再另写一篇来聊。
