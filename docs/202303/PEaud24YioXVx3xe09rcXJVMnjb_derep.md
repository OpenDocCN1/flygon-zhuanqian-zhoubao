# 一、ChatGPT 准备工作

## 一）基础知识储备

ChatGPT 刚火的时候，评论区最高频的问题集中在怎么注册、怎么用、要不要下载等。想做这条赛道，必须先把基础打牢，了解注册流程、使用方法以及常见问题的处理方式，最好自己整理成图文教程方便发给粉丝。

如果自己没时间写，也要学会搜集整理网络上已有的公开教程，做到粉丝提基础问题时能立刻回应，建立信任感。

## 二）引流闭环搭建

在抖音、快手等平台引流到个人微信，创作者无所不用其极，用图片、键盘字、藏头诗等方式引流，且随时面临封禁风险。

视频号则不同，主页可以直接留微信号，虽不合规但平台执行相对宽松，更关键的是能与企业微信打通，搭建从视频号到私域的自动化链路。

核心路径是：视频号 -> 微信客服 -> 企业微信 -> 个人微信。下面按步骤说明。

### 1、注册企业微信
先准备一个企业微信账号，个人也能注册，只是权限会受限。

流程：安装企业微信移动端 -> 用微信登录 -> 授权登录 -> 输入管理员手机号和邮箱 -> 填写公司名及管理员姓名 -> 创建成功。

### 2、完成企业微信认证
未认证的企微只能加 200 个客户，认证后上限提升到 5w，必要操作。

![](img/5be6014aa107217d4914961138c7d3a3.png)
认证需要营业执照，个体或公司皆可，年费 300 元/年。

流程：手机企业微信 -> 工作台 -> 管理企业 -> 企业信息 -> 前往认证，按要求提交资料，等待审核不通过则按意见修改重交。

### 3、视频号绑定企业微信
绑定后一个企业可挂 1000 个视频号，一个视频号只能被一个企业绑定，且主体可以不一致。

流程：企业微信 -> 工作台 -> 视频号 -> 绑定视频号 -> 输入视频号账号 -> 由视频号管理员扫码或微信授权确认。

![](img/79f80fc6e48065a0b87ac94ec26a6562.png)

### 4、开通微信客服
绑定后可把视频号私信升级为客服。接入后可在主页、直播间商品页、橱窗、小店等位置接入客服，点击即可咨询，且具备：

* 可配置机器人、欢迎语，实现自动回复
* 支持手机/电脑双端回复
* 可一键邀请客户添加企业微信
* 多个视频号可统一接入后集中回复

流程：企业微信 -> 工作台 -> 视频号 -> 接入微信客服 -> 选择视频号与客服账号 -> 完成接入。

![](img/83fdc2aba4e196e1fa4ff39be966eab5.png)

### 5、配置自动回复
这是关键词自动问答的核心。

流程：企业微信 -> 工作台 -> 微信客服 -> 机器人 -> 录入知识库 -> 添加问答 -> 完成。

![](img/d523a4740e209be988a94462c6b43e22.png)
配置好后，只要私信包含关键词就会触发自动回复。比如直播时私信回复“进群”，即可弹出群二维码，比直播间直接挂码更安全。

配置时要多写相似问法，保证语义相近也能触发。

### 6、设置客服欢迎语
先在自动回复里建一个带企业微信二维码的关键词回复，再设置欢迎语。

参考话术：点我添加客服微信，回复后自动推送带企微二维码的引导语。

流程：企业微信 -> 工作台 -> 微信客服 -> 设置欢迎语，引导用户添加企业微信，并在高频咨询处嵌入“点我添加客服微信”关键词。

![](img/77ae342ee3ac332739b6f5b0813963e4.png)

### 7、企业微信欢迎语
用户通过客服进入企微后，企微会自动推送欢迎语。

流程：企业微信 -> 工作台 -> 客户联系 -> 欢迎语，简要介绍产品服务，控制在手机一屏内。

结尾附上个人微信二维码，并提示：企微回复可能延迟，有急事可加个人微信联系。

![](img/d8d0c5adcf10ba1e2d4f891146e6e58e.png)
至此，视频号私信 -> 企微 -> 个人微信的自动化引流就完成了。企微消息量大时可不主动回复，重点维护加到个人微信的客户。

# 二、ChatGPT 快速起号

## 一）账号基础设置

### 1、昵称
视频号已禁止新账号直接使用 ChatGPT 关键词，可用 Chat / GPT 结合其他词。

例如 Chat聊天助手、GPTAI智能机器人等，也可让 ChatGPT 帮忙生成。

![](img/624ab7730e4ac145130e588c46dc4cfc.png)

### 2、头像
基本沿用 OpenAI 或 ChatGPT 官方图，同行通用。

### 3、简介
简介可留微信号，便于合作与咨询。文案里堆叠 ChatGPT 相关关键词，提升搜索权重，多参考头部同行写法。

## 二）内容创作方向

根据实操，ChatGPT 主流内容分两种：图片截图和录屏问答，其中录屏问答占比更大。

### 1、图片截图类（现阶段不建议做）
做法：截取完整的 ChatGPT 问答截图，加标题、音乐、贴纸。

注意时长控制在 10 秒内，约 7 秒最佳，短视频利于提升完播。

可做模板固定音乐贴纸，后续只需换图改标题，单条制作约 1 分钟。

![](img/981d378304c7c58ff94ddb55bea3a809.png)
实测视频号对截图类内容不友好，建议放弃，转做录屏问答。

![](img/04e8a5dd7ac5d4469bb79a39ebe63ceb.png)

### 2、录屏问答类
做法：全程录屏 ChatGPT 回答过程，导入剪映裁剪头尾，用变速压缩到 30 秒内，再加标题、音乐、音效、贴纸。

可做模板固定特效素材，后续只替换上层录屏素材。注意比例，学长使用横屏 3:4，保证观看清晰度。

![](img/2b1aeff9130ffa69796af5301bf922dd.png)

### 3、核心要素
选题比剪辑更重要。选能引发共鸣、共情或争议的话题，如赚钱、写情书、旅游攻略、会被取代的职业等，播放表现更好。

选题枯竭时多看同行作品。风格统一也很关键，标题排版保持一致，否则粉丝难以形成辨识度。

## 三）承接流量

### 1、转化引导
简介挂联系方式。评论区要维护，每条视频引导评论，并针对高频提问如下载方法、使用教程进行统一回复。

### 2、直播预约
主页至少保留一条直播预约。短视频爆了才能承接流量，提前挂好每周固定时段的预约，例如每周五 20:30。

预约人数不足或不想播可随时取消。

# 三、ChatGPT 高效直播

短视频吸粉，直播变现。爆款视频后必须挂直播。

我此前几乎没直播经验，靠短视频流量被迫上场。共开了 9 场，有效 8 场，总场观 62.5w，直播涨粉 3.3w，单场最高破 20w+。

![](img/36405c1564a7b15e780d18092cb9df99.png)

![](img/432fff6189084a303d49fc8eaf86dfdb.png)

## 一）直播封面
封面要直观说明直播主题和用户能获得的价值。学长采用简洁粗暴的文案风格。

![](img/b45f520731773b965dcce7986cf53cfe.png)

## 二）直播工具
无需第三方，PC 端微信自带视频号直播工具即可。

![](img/7413053d2541a8526dd805591e7644ee.png)

### 1、画面源选择
浏览器登录 ChatGPT，在直播工具中选择对应浏览器窗口作为画面源。

![](img/0210bd1cb65238f12a7665f177ddbde5.png)
设置完成后白框区域即为直播画面。可拖拽缩放，文字大小适中即可。

## 三）直播内容与机制

### 1、内容形式
直播机器人回答评论区提问。观众在评论区提问，主播用 OCR 识别文字复制到 ChatGPT 让其作答。

### 2、回答规则
起号期人少时有问就答。流量上来后评论太多时，改为优先回答粉丝团成员，粉丝团无问题时再随机抽普通评论。

可设置插队机制：刷指定礼物可插队优先回答。规则要在直播中反复提醒，新进观众才不会懵。

### 3、直播安全
严禁说直播违禁词，具体可参考视频号直播规范。医疗、股票类问题坚决不答。

在 PC 端视频号助手 -> 直播 -> 直播管理 -> 敏感词中设置屏蔽词，含敏感词的评论会自动过滤。

## 四）直播氛围营造

### 1、互动聊天
机器人作答间隙有空档，可趁机闲聊或推广产品，话题结合当前回答内容，拉近距离。

### 2、背景音乐
全程放舒缓音乐，避免冷场。

### 3、问题上墙提示
要告知观众当前回答谁的问题，下一个是谁，可将问题上墙。排队时间长时要告知当前排队数量和预估等待时间，并引导插队。

### 4、截屏提醒
回答结束后提醒提问者截屏留存，有价值的问题才提示。

### 5、福袋抽奖
用福袋留人，15 分钟开一次奖，奖品设账号或现金红包。参与条件可设关注或粉丝团。进场时主动引导参与抽奖。

### 6、群发红包
通过微信群给私域用户发红包，吸引直播间观众入群。

* 开播前设置指定微信群派发红包
* 主播引导入群
* 入群后领取红包

*   想要拿到东西的观众必须先进群，我们一般是把群二维码在画面里闪一下，几秒钟就切走，然后让客服私聊回复进群关键词，引导进群后才发放。

![](img/2ddb1954246a183c243a519f01c62f64.png)

### 7、挂直播预约
视频号直播间本身就能推预约功能，开播前一定要把预约位挂上，再配合一些话术引导，下一场直播就能带一点基础冷启动流量进来。

# 四、ChatGPT 变现玩法

下面分享的都是学长亲测可行的变现路径，其他思路大家可以自行拓展。

## 一）代注册服务
虽然教程已经公开了，但很多人嫌麻烦或不会操作，这就形成了需求。

对客户来说，代注册的价值是直接拿到带自己邮箱的账号，而且省时。客户提供邮箱和密码，我们来完成注册并交付，收取服务费。

这个业务的人工成本偏高，流量起步阶段可以接，等量大了建议直接卖成品号，或只做高价代注册。

## 二）账号售卖
卖账号是最基础也最常见的变现方式，找上游拿货赚差价即可。

ChatGPT 官网号的价格已经很透明了，批量100个起拿在1.5~2.0元/个左右，零售价浮动较大。

国内版我们走的是内部开发，不需要上游。采用月卡制，29.9元/月。最大优势是无网络限制，普通用户也能直接用。

市面上的小程序、网站版国内 ChatGPT，价格参差不齐，体验也各不相同。

账号售卖的核心是把发货自动化，减少人工。学长经历了两个阶段：淘宝自动发货和发卡平台发货。

### 1、淘宝自动售卖
当时用的是阿奇索自动发货软件，实现24小时秒发、不漏单不重发，月租15块。

现在淘宝已经不建议上架了，ChatGPT 相关商品属于违禁品，即使不写关键词，被检测到也会扣分、要求补保证金，二次违规可能扣保证金甚至封店。

![](img/68143a9594461ecd05a5910915e9ada0.png)

如果手上淘宝店铺很多，对风险可控，也可以继续尝试，毕竟首次违规不一定扣保证金，且淘宝对买家有天然信任感。

### 2、发卡平台售卖
发卡平台本质是小型交易平台，注册后相当于拥有自己的店铺。

在后台录入 ChatGPT 账号密码，客户下单后平台自动推送信息给客户，完成全自动交付。

这样就绕开了淘宝+阿奇索的链路，也规避了上架风险。平台会收取3%~5%的服务费。

平台很多，学长使用的是多彩生活自助发卡网，选择靠谱、大体量的即可。

## 三）Plus 升级
普通号和 Plus 号的核心差距：

![](img/f502e1fb91e4ee96df2b3613de7b1df2.png)

GPT-4.0 发布后，Plus 才能用 GPT-4.0 模型，这也成了升级的主要卖点。

官网升级价是20美元，但国内微信支付宝无法支付，于是产生了代升级业务，收取服务费。

## 四）课程售卖
ChatGPT 爆火后催生了大量相关课程。变现方式分两种：分销别人的课，自己做课。

学长前期是兼职做自媒体，选择分销。市面上课程质量参差不齐，分销前要甄别。学长主要带的是《玩赚ChatGPT》，因为参加过首期，认可社群价值。

课程售卖主要在微信/企业微信私域完成，通过直播或短视频引导粉丝加微信/企业微信，再在朋友圈发资料引导下单。

朋友圈私域运营学长不太擅长，这里就不细说了。

近期学长在筹备自己的付费课，打算用文字手册+直播课+群内答疑的组合，手把手教视频号做 ChatGPT 类账号及直播。

## 五）付费咨询
没精力做课也能通过付费咨询变现，为客户解答 ChatGPT 相关问题。

账号做大有背书后，自然有人找上门。学长定价是199元/小时，超出部分100元/小时，已成交多单。

咨询前一定要做好交付预期，提前确认客户想问的问题，做好准备。不擅长或不了解的问题宁愿不接。

## 六）付费写稿
写稿需求量很大。学长在产品页没挂这个服务，也有客户加微信询问。

接单前先沟通需求，毕业论文或重要性高的不接。确认字数和特殊要求，按字数收费，自行定价。

交付时把 ChatGPT 生成的稿子汇总到飞书文档发给客户，满意付款，不满意可小修，建议总修改时间控制在半小时内，超时直接放弃。

不接毕业论文，风险太大。用 AI 写的文章若达不到要求会影响毕业。

建议接演讲稿、发言稿、短小论文这类查重要求低、风险小的单子，赚点小钱。

变现思路：短视频展示 ChatGPT 问答，内容就是写各类稿件。视频号主页留微信，客服引导加微信，就会有客户主动找上门，适合时间充裕的人。

## 七）广告合作
账号有流量后，商务主动找上门的情况很多，常见的有带课、带国内 ChatGPT 网站、带书等。

价格按自身情况谈，也是常规变现方式。

# 五、做号踩坑经验
学长做 ChatGPT 账号一个月，踩了不少坑，总结如下。

## 一）团队协作
账号做大一人扛不住，必须组团队，分工协作效率更高。

学长流量起来后在星球招了两位伙伴组线上团队。三人各司其职：学长负责引流、短视频、直播；一位伙伴负责账号运营、售前售后、Plus 升级；另一位负责国内版网站的开发。

## 二）提升效率

### 1、在线文档
产品介绍必须用在线文档。

好处：一是方便多人在线协同，不用担心版本问题；二是多设备实时更新，粉丝随时看到最新版。

## 三）防搬运
账号做大必会被搬运，减少不了，但可以提高难度。

### 1、加水印
剪映剪辑时添加文字水印，文本->文字模板里有【这是水印】模板，换成自己的视频号账号名称即可。

![](img/de1a6ef6aa4de0a588a80c5a82ee2724.png)

### 2、申明原创
视频号对已认证或参加原创计划的账号，首发内容会得到保护，后发相同内容会被降权。

申请原创计划后平台会自动维权。若别人搬运，系统会判定为搬运。

发布动态时勾选原创声明即可。

![](img/a46b6999861d7c179b302aa3486a40c4.png)

可在 PC 端视频号助手 -> 扩展功能 -> 原创保护记录 查看详情。

![](img/7c0b29e45752781d742352e805a1d934.png)

目前视频号已无原创计划入口，附上链接：https://channels.weixin.qq.com/mobile/original_plan.html#/ 复制到微信打开。

## 四）安全意识
做自媒体一定要懂规则，避免限流违规。

### 1、短视频安全
参考视频号官方文档《微信视频号运营规范及视频号常见违规内容概览》，避开违规选题。

### 2、直播安全
参考《微信视频号直播行为规范及微信视频号禁止发布的营销信息列表》。

直播别说违禁词，可在网上搜各平台通用黑词。PC 端视频号助手可设置直播敏感词，含敏感词的评论不会展示。

### 3、风控意识
主要指微信/企业微信风控。

大量异地收款会被风控：2022年3月1日起个人收款码不能经营收款，远程异地收款会被判定经营收款，会限笔数甚至冻结资金。

短时间加好友过多会被判定诈骗风险，学长的两个企业微信因此被限制私信、群聊和加好友功能，一个恢复3天，一个10天。

具体阈值官方未公布，与账号权重有关。平时多养号备着，流量来了好承接。
