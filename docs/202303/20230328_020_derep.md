# 从移动端投放视角切入英文工具站的出海打法复盘
作者：龙哥

作者署名：非洲水手

这些年我主要在海外增长赛道摸爬滚打，工作重心长期放在工具类与游戏类产品的付费拉新上。累计操盘的投放预算体量达十位数美元级别，日均消耗流水曾触及六位数量级，投放素材的累计产出过五位数，独立负责上线的产品数量破百。目前任职于一家顶级 Web3 机构，负责出海用户增长方向。

今年正好是我在龙哥盟社区的第五个年头，亲眼看着一波又一波优秀同行在这里捕捉到新机会，拿到第一笔美元收入后持续放大。这种来自一线的实战验证，比任何方法论都更有说服力。

刚刚收官的赚钱三月英文工具站航海实操活动中，很高兴和 380 位志同道合的伙伴一起拆解海外市场的玩法逻辑和落地细节。和这么多人聊怎么把投放效率转化为稳定的美元现金流，本身就是件很提神的事。

我长期混迹于移动出海的圈子，所以本次分享的切口更偏向 App 买量，希望能给聚焦英文工具站的同学带来一些另类的思路碰撞。特别感谢龙哥盟与主办方的安排，也恭喜每一位参与者顺利完成航程，祝后续持续增收！💵💵💵
