## 我的 ChatGPT 写作六步法

整体拆成6个环节：

1. 先固定写作风格，后续可复用
2. 选题孵化
3. 生成大纲
4. 分段扩写
5. 整合内容并人工润色
6. 拟定标题

下面配图里的 prompt 可直接借鉴。

### 1. 训练写作风格

把航海手册里的爆文模型、开屏钩子等核心套路，全部喂给 ChatGPT 进行学习。

同时也可以从公众号挑选几篇高赞范文直接喂进去，让模型模仿语气和节奏。
![](img/2cf8f534d3c47e29af87d9051fbc94c6.png)
![](img/7d73ca97e7cb94d81442b3199c35eae8.png)

### 2. 选题孵化

找一篇已爆的公众号文章，把它的核心情节抽出来丢给 ChatGPT 作为案例，让它基于此拓展出多个选题方向。不好就继续提修改意见，反复迭代到满意，再由自己做最后的人工微调。

用上这个思路后，故事素材再也不愁，源源不断。

![](img/248208aa6a66921ab670efa70203a0df.png)

### 3. 写大纲

把确定的选题丢给 ChatGPT 让它列出结构。大纲不满意就要求它重写，直到符合预期为止。
![](img/693d34d091f5f10e7a1648b54a5dae5c.png)

### 4. 详写各部分内容

可以明确告诉它重点描写点、篇幅要求等限制条件，让它分段展开。
![](img/2cf947cdc61de5827d0519cbac7a0f50.png)

### 5. 合并内容，人工润色

人工介入是必备环节。ChatGPT 生成的各段落衔接常常不够顺滑，多余信息也多，需要自己删改整合。

### 6. 写标题

标题建议自己来。之前让 ChatGPT 直接出标题效果一般，可以先让它提供几个备选作为灵感再自行优化。如何让它生成更抓眼的标题，目前还在摸索中。

## 使用心得总结

1. 务必用 GPT-4。对比3.5，生成质量提升明显，唯一缺点是速度。
2. 不要追求全自动批量生产。整篇丢给模型生成的质量会明显下降。
3. 一篇从构思到上线，我通常花1到2小时。主要是 GPT-4 响应偏慢，经常等模型。晚上效率更差，网络不稳。
4. 整体工作量分配大约是人工占4成，AI占6成。人工负责选题定调、情节把控、润色调整、标题撰写和发布；AI负责主体内容生成。
5. 单论文字产出，ChatGPT 能完成8成以上，人工主要做删减和衔接。
