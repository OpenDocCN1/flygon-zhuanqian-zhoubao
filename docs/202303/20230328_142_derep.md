# 《抖音快手无人直播月入百万是真的吗？》

标题：《不露脸直播间，月成交200万？这位玩家晒出半年真实战绩》

在抖音、快手这类平台上，总有人喊：不用真人出镜，也不用实时互动，挂个视频就能把钱赚了。真有这么神吗？最近，一位做无人值守直播的玩家晒出自己的成绩：入行半年，三十多台电脑同时在线，月成交额稳定在200万上下。


不过最有意思的是留言区。有人抛出一个特别实操的问题：提前存好的音频，怎么才能让电脑识别成 Mic 输入？作者答得也干脆——买一个直播1号的小盒子，淘宝上就有。问的人当场表示：最近就动手，等赚到第一桶金再来请作者喝茶；作者也笑着答应，说等着。

话说回来，把账算清楚再入场也不迟：不露脸直播不是躺赚，设备调试、平台规则、选品留人，一个环节不扎实都可能翻车。想尝试的人，建议先把那份飞书文档从头到尾读完，再决定要不要干。
