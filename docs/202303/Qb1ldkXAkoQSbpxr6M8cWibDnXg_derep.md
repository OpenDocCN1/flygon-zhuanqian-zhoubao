# 靠卖床品+做校园墙，半年净赚10w+：一个普通大学生的从0到1复盘
作者：龙哥

大家好呀。如果你还是个在校大学生，不妨看看我的经验，说不定能给你一些搞钱的灵感；如果你正卡在某个项目的瓶颈期，也许我的踩坑和破局过程能带来一点启发；当然，如果有幸被行业前辈看到，也希望你们多多指教。

说句真心话，这点收入在各位大佬眼里可能根本不算什么，没什么值得炫耀的。我写下这篇文章，更多是为了给自己这段时间的赚钱经历做个拆解与复盘，也希望能帮到一些和我当初一样迷茫的大学生。

## 一、从0到1的搞钱经历回顾

### 高中阶段：闲鱼初体验

高三那年上网课，兜里没钱又不想跟家里张嘴，就顺手下了个闲鱼，把亲戚送的一双阿迪鞋和几件衣服挂了上去。没想到一个星期不到就卖掉了，瞬间感觉打开了新世界的大门。

后来我开始研究护肤品，想在闲鱼上卖自己的闲置，结果发现价格太贵根本没人买。反而看到有些卖家卖得特别便宜，一打听才知道这行水深——几百块的护肤品，进货成本居然只要二三十块。我找了一个号称“跟正品同原料”的货源，卖了几单，赚了差不多一千块。后来有买家察觉出问题，加上我自己心里也过不去，就没再继续。虽然这事有点黑历史，但它让我意识到：互联网上确实有搞钱的门道。

![](img/ed3e07e8278716c9236789b555ebddeb.png)

### 高中阶段：网拍刷单那些事

后来我又入了“网拍”的坑，说白了就是帮淘宝商家刷单。当时交了299元入会费，坐在教室第一排，上课下课都抱着手机接单。我一口气养了四五个淘宝号，一单七块钱，虽然累得手忙脚乱，但一天也能挣一百多。那段时间赚的钱全被我买护肤品了，床上堆了一大堆。

可惜后来因为操作太频繁，🛰️号被封了一个月，加上知道这行有些乱象，我就放弃了。高考完那个暑假，我还考了驾照，又到快手拜了位十万粉的师傅学剪辑励志文案。做了一个多月，粉丝还是只有一百多，实在坚持不下去就停了。

但那段经历让我认识了一位从厂里流水线走出来的短视频博主，他把号做到一百多万粉丝后卖掉，一边打工一边做副业。他亲口跟我讲这些故事，再加上我当时看了很多励志文案，心里便埋下了一颗种子：以后绝不去厂里打螺丝，一定要闯出自己的事业。

### 大学阶段：练演讲、搞地推

我本人是从山西小村庄考到湖南一所二本院校的，家里条件一般，但心里总想走出去看看，所以特意选了南方的学校。小时候我特别内向，高中时又碰上一位爱打人的老师，差点辍学；后来进了高中，我一边跟“狐朋狗友”混，一边又跟好学生玩，性格慢慢变得外向，但口才还是很差，那时候就意识到会说话有多重要。

开学前，我在贴吧认识了学校迎新群的群主学姐，顺便代理了她卖的被子，卖出了十几套。也是这个学姐带我进了一个教演讲口才的机构。刚进去时普通话一塌糊涂，我就天天跑宿舍楼、操场、大街上练，还让同学帮我录视频，一点一点纠正。后来从五十多个学员里脱颖而出，学会了主持，甚至开始负责给培训团队做摄影摄像。这段经历虽然辛苦，却是我长这么大第一件特别有成就感的事。

![](img/3d2440ca375b8ec99a8044af8b088bd4.png)

到了大一，我遇到了美团地推的契机。那天有人在宿舍敲门，让我们帮忙下一单美团蛋糕，订单的钱原路返还，还送饮料。我试了之后，软磨硬泡问出他们每单的利润，接着联系到老板，把室友和几个同学组了个地推小分队。老板看我们年轻有冲劲，给了每天一百多单的量，去掉礼品成本，一单能赚五块左右，我每单抽一块。我们跑食堂、跑路上、挨个寝室敲门，一个月下来能挣两千多，生活费完全够了。那学期忙到上课天天卡点冲进教室，但成长也是飞速的，我还用赚来的钱入了几个付费知识星球，给自己换了一台苹果13。

## 二、新生季床品项目全拆解

### 1. 为什么选床品？

一是听别人说校园床品特别赚钱，比如去年卖我被子的学姐，一个暑假就赚了一万多；二是我在抖音看了一些大学生创业博主，加🛰️后发现他们朋友圈天天晒学员反馈，业务里就有床品这块，利润相当可观。我当时正好靠着地推攒了点钱，脑子一热就交了5000定金，想去线下公司学一学。

![](img/f83b3ba597cc6c94c9511e12647fa020.png)

暑假一到，我就跑到了那家线下公司。他们专门做大学生的各种校园业务，床品的货源是由合作棉被商提供的。到了之后，我建议大家做一个小程序来选品，后来床品的整个销售流程都靠它跑通了。

![](img/0657f497471299165fde889bbc2efb4d.png)

### 2. 全渠道“围剿”新生流量

做校园床品，最重要的窗口期就是新生开学前，想赢就得先布局。先看看去年新生群在百度上的搜索结果，就知道这场仗有多激烈：

![](img/e40a3224eb8f3670c92fe55b126fa15b.png)

我的策略很简单：凡是新生会搜索的平台，全都要留下我的影子。百度贴吧、🐧群、📕、🧣、抖音、B站、知乎、今日头条……能铺的都铺一遍。

**百度贴吧：**
我先在学校贴吧发了个介绍学校的帖子，在图片里放了本校🐧新生群的二维码。做新生群的同行大约有十个，但我开局有个“外挂”——之前跟吧主关系好，刚开战的十几天，我让吧主把同行的帖子全删了，可以说是非常霸道了。可惜吧主为人正直，不愿掺和这种利益纠纷，他觉得只要帖子有干货，对新生就是好的。后来他就把我的小吧主下了，同行们立刻开始疯狂发帖、顶帖，我也只能天天顶排名，争取在百度首页露脸。

**🐧群排名：**
高中毕业生习惯用🐧搜群，把🐧群的排名做上去，流量自然来。这里有三个关键：
- 群名和群资料要从学生视角出发，比如“XX学校新生群2022”；
- 群主、管理员、群内活跃人数都会影响排名，每天都要在群里喊话刷等级；
- 群资料务必填满学校各类信息，越全越好。

![](img/10ae4c1ec7ae5bfc4d2201d40d137d5d.png)

靠着这套打法，七月中旬流量一度爆发，每天进群两三百人，几个群加起来超过3000人。我也意识到暑假一过，群就废了，得赶紧把流量导到更私域的地方，于是开始盘算做校园墙。

**📕：**
我用图文介绍学校的录取分数线、宿舍几人间、校园风景、食堂美食等，结尾都会引导大家进群，说群资料里有更全的内容。

![](img/ebbcaa42ec2e2155e02b5455796843c0.png)

**🧣：**
玩🧣的女生多，我就把贴吧的帖子、图片和新生常见问题搬运到🧣，再砸大量时间顶帖，让内容保持在本校🧣的最前面。那段时间，我几乎不是在顶帖，就是在去顶帖的路上。

![](img/b4d4379ea75522c95f96d99368379271.png)

这样一来，只要有人搜索我们学校的相关信息，基本都能撞见我家的内容；想了解更多，就会自然流入🐧新生群。

### 3. 从流量到成交，床品怎么卖？

流量进群后，如何让新生信任我们并愿意买床品？

我和合伙人学姐还有另一位兼职同学都设为管理员，有人申请进群时，我们会先加好友再同意入群，以“热心学长学姐”的身份解答问题——从学校情况到录取概率，知无不言，言无不尽。这一招既真的帮到新生，也累积了信任，一举两得。有时候一天加200个好友被系统限制，我就解除了继续加，一边加人一边在群里欢迎新人。

等大家确认被录取后，我们开始在朋友圈和空间里展示“学长学姐也在做床品兼职”的形象。但刚开头的十几天几乎没什么单，因为离开学还早，新生们都不着急。当时在线下公司呆了快一个月，每天房租、生活成本压得人喘不过气。西安的夏天热得发慌，我每天就是重复顶帖、发帖、整理学校资料、回答学生问题。虽然公司里有空调、能对接货源、认识志同道合的朋友，但关于自己的新生群和床品销售，真的没学到什么捷径，全是自己一步步趟出来的。有天晚上十二点多回住处的路上，看到路灯下一位老人，突然觉得自己一个人怀揣梦想跑到这座陌生城市，快一个月还没什么起色，跟他也差不多。那晚躺在出租屋里，彻夜难眠。

![](img/94fef3d7c953804bb3f0d5877b88fafc.png)

到八月份，终于等来了第一波小高峰。那几天一天能出十单左右，产品有449的六件套和598的九件套，一单利润大约180。我每天疯狂发朋友圈、主动私聊，稳了一周，每天十单。后来订单陆续增长，我还把引流方法教给在淘金星球认识的一个大学生兄弟。他执行力超强，很快起好了两个学校的新生群，十几天做到两千人，还帮我管了一个附属学校和一个湖北学校的新生群。其中一个人数五六百的群被本校学生发现群主不是本校的，被举报了，但在附属学校找了一个有影响力的代理，卖出三十单，附属学校也卖了十几单。

离开学还有十天时，累计大约两百单。我从公司回了家，一个人继续在群里发公告、发动态、主动私聊，十天又卖了近一百单。最牛的一天出了二十单，纯利润接近四千，当时真的激动坏了。后来让公司又发了三十套到线下，最终一共卖出三百多套。

### 4. 搞定校园快递站，解决物流难题

三百多套被子可不是小数目。暑假里我就提前联系了校内的几家快递站——有顺丰、邮政和一家菜鸟驿站。顺丰单个要35元，太贵；邮政店里已经塞满了开学季的行李；菜鸟老板一开始也说放不下，但看我一个大学生挺不容易，答应帮忙，开着大车和我去中转站拉了整整四大车被子。车上的只是一部分，还有不少分散在各个宿舍楼。

我懂这是人情，所以经常给那位大哥带好吃的、买烟，也会请帮忙的同学喝奶茶、吃饭。开学当天，我雇人骑电动车把被子送到各个宿舍。没想到送了几套，人家嫌太热就跑了。我只好自己顶着大太阳送了一整天，连水都没喝一口，晚上十点多还拉着舍友一起送。等最后一件被子送完，整个人瞬间轻松了。

## 三、校园墙：从0到1的私域阵地

做新生群的时候，流量都在群里，但群这东西暑假一过就沉寂了。我想把人都导入私域，于是做了个决定：搞校园墙。

我在🐧群里把校园墙设为管理员，@全体成员加好友，把人先引到🐧墙；但🛰️私域价值更大，我又建了🛰️新生总群，再按学院拆分成多个分群。通过校园墙🐧号发公告，引导大家加我🛰️，然后拉进对应学院的🛰️群。

![](img/3f9252af736b8c84a4961ea5ce53e527.png)

两个🛰️总群加各个学院分群，群主都是我，影响力直接拉满。下一步，我计划用一场活动开启裂变。

![](img/81e88556561c6ec49573033653a5be82.png)

![](img/006bca4f6a2aa1753a2701069da4dba6.png)

我策划了一场投稿活动，用现金奖励吸引大家参与，拉来了一百多位同学。刚开始投稿踊跃，但两天一过，新鲜感就没了。我就在抖音上一个一个私信本校的高颜值小哥哥小姐姐，请他们帮忙拉人参与。果然，主动才有故事，万能墙的投稿量终于稳定下来了。

![](img/a9cefc2a89ce5c276339808d666e3d83.png)

接下来，很快有人找我投投票活动的推广。我通过朋友圈、🛰️群、🐧空间等渠道推了小半个月，浏览量做到十几万，广告费算下来有一万多，同学们刷礼物刷了近三万。但那个小程序开发商竟是个骗子，最后只邮寄了前七名的便宜奖品，说好的智能手环一个没发，还人间蒸发。那个接项目的学院主席自掏腰包买了一百多个手环补上，而骗子那边靠这个活动赚了四万多。网上骗子真的多，我又交了一笔学费。

![](img/05f55e38986d2d776b5f3bef77e7b247.png)

现在，我的校园墙已经稳定运营了七个多月，学校的老乡群、快递代拿群、洗衣群、唠嗑交友群基本都由我们团队在维护。墙号🛰️好友5000+，🐧好友2500+。平时会接一些靠谱的商家推广，一个月差不多十条，单条🛰️128元，加上🐧一起是168元；偶尔也帮朋友推驾校和校园卡业务，收入虽不算高，但胜在稳定。

## 四、个人发展方向规划

读万卷书，行万里路，阅人无数，名师指路。虽然靠自己的努力赚到了点小钱，但这段经历也让我看清了身上的很多不足。接下来，我想多读书、多思考、多复盘、多交益友。成长这条路虽然荆棘密布，有时会走得慢一点，但我永远不会停下来。

下学期的规划是在学校多读书、多思考，同时尝试📕电商；暑假如果有机会，我特别想去杭州闯一闯，接触更多优秀的公司和优秀的人。如果有老板愿意给个实习岗位，我包吃住就行，绝对嘎嘎努力。

最后，真的很感谢赚钱这个平台。虽然我加入还不到一年，但看了很多大佬的分享，给了我很多思路，我也都运用到了自己的项目里。希望2023年能和赚钱的圈友一起冲冲冲，一起搞钱！
