# 当平台红利收敛，内容操盘手怎么打开局面
作者：龙哥

文 / 白杨
时间：2023-03-20

上周厦门一顿饭，聊了整整五个多小时。对面是一位操盘过抖音四百万级商业账号的操盘人，从短视频到知乎再到种草平台，从变现逻辑聊到未来怎么突围。回来后把脑子里最触动的几条拎出来，和大家同步下。

1. 做内容基本分两条路。一种是自己成为IP亲自出镜，另一种是做平台、做资源、去找人。聊到的这个团队就走第二条路，他们更像伯乐，专门挖掘有真实阅历、有表达潜力但还没被看见的人。关键是出手时机，要在对方尚未成名、需要支持的阶段就建立联系。

2. 合作关系的黏性不是靠合同维系，而是靠持续的帮助。当创作者处于低潮期介入，信任的基础会打得更牢。后续随着账号成长，出现瓶颈时能调动人脉与资源去兜底，在关键节点给出实质性支持，关系才会越来越稳。

3. 先厘清自己天生擅长定调，还是擅长落地。这个分工想明白了，协作效率会高很多，后续冲突也会少很多。

4. 创始人选择的赛道会在无形中给团队打上烙印。比如做快周期的项目，团队节奏自然偏快：收完一波就盯下一波，追求快速变现的刺激感。一旦周期结束，空窗期就会带来整体性的焦虑与浮躁。所以业务的特质会反向塑造组织气质，选赛道时必须有清醒认知。

5. 保持对外交流与学习，作用远超预期。结合自身实践，最有效的模式是走出去看做法，归来后立刻实践转化。若只是沉浸在出差的新鲜感里，却缺乏落地能力，反而容易虚耗时间、滋生膨胀感。

最近收到花爷寄来的《开眼》内刊，龙哥老师的两句话特有感触。一是愿意付费去筛选多元优质的信息源，并主动沉浸其中；二是把自己的思考通过不同渠道输出出去。结合他此前提到新人入场常因羞涩而沉默，我决定在这次交流后，第一次把自己的理解写出来，尝试先沉淀再表达。[胜利]![](img/c6e2beb43a3780d960cc4b08dc2093eb.png)
