# 月流水冲上20万，关于短剧推广我想说点真心话
作者：龙哥

先交代一下背景：我最初做短剧，第一单只赚了19块钱，现在个人月收入已经到了3万+。这个转变，只用了大约一个月。说真的，我很庆幸自己及时上了这趟车。

![](img/c25e28e64531abea6feaef54a663c512.png)

上个月刷到这个项目后，我没多想就下场试水，跑通第一笔收益后，立刻来赚钱分享了。之前放出来的实操路径到现在依然有效，而且又冒出了新渠道（后面会说到），旧的影响不大，还能接着用。

后来不少圈内圈外的朋友也一起入场，大多都拿到了阶段性的成果。

先晒晒我自己的成绩单：
1. 项目本身的收益，1万+
2. 陪跑收的费用，4万+

其中保证金已经退了1W+，还有一部分也即将要退；最后真正变成学费的，才算是我的收入。

再看整盘账：有人月入过万，有人只赚了几百几十，还有人看了一眼就放弃。从现有数据来看，单账号的中位数收益基本在几百到一两千之间。

因为我们整体战绩不错，短剧官方后来也直接把授权给到我这边，到手的佣金也比之前的渠道还要更香一点。

下面分三块来聊聊，从项目到个人，钱到底是怎么赚的：
1. 数据说真话，这个项目到底值不值得做；
2. 赚不到钱的人，多半栽在同一个坑里；
3. 个人要赚钱，关键是抓住机会，聚焦放大。

## 01. 用数据说话，项目到底行不行

目前陪跑群里有220多人，90%都拿到了结果。虽然抖音后台能看到226条收益记录，但里面有十几个人是同时跑多个账号，去掉重复的，真实出单人数占比大约就是90%。

给大家看几个典型样本。

![](img/60bb065507a1ea38113fd276e82f679c.png)

这是她3月份的收入。我和她聊的时候是3月19号，可以确定这个月破万没问题。

聊天记录也放一张：

![](img/3ff7ef5b099abb11bfd4949d3b7a3a6f.png)

再晒几个其他账号的收益截图：

![](img/5aa35a407f9ac246dfca66c11235b22e.png)

![](img/5b8b70bd99a9e120a0ea10d68edb3b13.png)

图就先放这么多，赚钱圈里的人都懂，收益图放太多反而有营销嫌疑。

看几个汇总数据就够了，截止目前：
1. 拿到收益的人，85%以上；
2. 收益超过200块的，现在有53%（因为新人在不断进来，比例会波动）；
3. 收益超过1000块的，24%；
4. 收益超过1万块的，一共有5个人。

总体来看，这个项目现在还处在早期红利期，赚钱的难度确实比想象中低很多。

结果我很快就发现自己被打脸了：明明简单到不行的事，照样有人做不出成绩。

## 02. 赚不到钱的人，总是那几种

我第一次跑通项目时，脑子里冒出来的念头是：这也太简单了吧？只要是个正常人应该就能做。

和朋友聊起来，大家也有共识：准入门槛几乎为零，但天花板高得很。

![](img/e9ac8d88e108a74027710ae4f3d36a20.png)

单账号想赚点零花钱很容易，但想凭一个号发大财，可能需要一点运气；不过批量复制非常容易，尤其是有项目经验的人，基本等于捡钱。

所以身边确实有人上手后，每天都赚大几百，甚至上千。

![](img/29e7ab34bc59f0378f044584938422fe.png)

我一直用的是保证金模式，只要对方爆单，我就把保证金退回去。也因此收过不少感谢红包，还有人连续发来两个大红包：一次是爆单时，一次是提现时。

![](img/7fd7c5312109c25526e3b7b82245167f.png)

正因为这样，我办陪跑营时真是铆足了劲，希望每个人都能把保证金拿回去。要是真能做到100%返还，那这成绩我能吹一辈子。

![](img/7de84d480b2e7129333bc9b1d478ccff.png)

那阵子，我每天能睡五六个小时就知足了，还经常半夜回消息。

![](img/4ae46d341055bea541cc88ff1fe5ba6b.png)

![](img/57b4780d12a00de8ad583beff3f1f44e.png)

但现实往往不按剧本来。

![](img/ffe218aa5e9a8612ae8b70ddff986641.png)

有人进群后，好几天连视频都没发，就跑来说不干了。

也许是看到别人进群两天就赚了几百块，自己已经坚持三天还颗粒无收，觉得受了委屈吧？

![](img/74f646d7e83fb13c7c98424538d8a543.png)

我后来想通了：连赚钱这么高质量的人群，航海打卡这么简单的要求，都始终有一批人完成不了。

更何况我这个群里，除去赚钱过来的，其他人的整体质量大概率是比不过赚钱的。

我为什么这么清楚？因为我亲眼见过、亲身参与过赚钱的交付，既当过学员，也当过志愿者和教练。

赚钱这么强的团队，能把打卡完成率做到90%，都是一次次迭代才拼出来的。我一个小喽啰，单打独斗也没什么经验，想做到100%出单率，纯属痴人说梦。

后来跟一个朋友聊完，我也慢慢释怀了：有些人你再怎么拉扯都没用，不如把精力留给那些愿意学、愿意干的人。

![](img/860fa9c5e6b11dcbf6b8c0e722366b6c.png)

但话说回来，既然收了人家的保证金，我总归还是要负责。所以后来想进陪跑的人里，我拒绝了不少类似这样的情况。

![](img/841c21b84a5e90d73a9104b2e4a12991.png)

说实话，我怎么会不想赚这个钱？我缺钱啊，没出身、没资源，多来点钱哪能不愿意？

但我更想赚负责任的、长久的钱。

谁不喜欢钱多一点呢？包括这次来分享，我也有点私心，希望赚钱里靠谱的朋友能多过来几个参加陪跑。

但我不希望那种大概率做不出成绩的人进来，因为我收了你的钱，不管你自己觉得值不值，我心里都会过不去。

你要是没赚到钱，哪怕我不收费，你也不会觉得我做了什么，反而可能觉得我能力不行；但只要你赚到了钱，就算我收了费，你也会觉得值，咱俩都开心。

这就引出了第三点。

## 03. 个人赚钱，还是要抓住机会，聚焦放大

个人想赚钱，光努力不够，更重要的是选对方向，然后聚焦放大。

说白了，站上风口，猪都能飞。

但问题在于，风口就在那里，有人看不见，有人看见了却抓不住，只能眼睁睁错过。

![](img/e4b7cd758a2c1f9c6fedf65061adbb42.png)

比如这次ChatGPT，刀姐、凡灵逸尘、yk这些高手，看到机会就全力上，变现都是六位数起步。

我一个普通人，眼红不？那肯定眼红。

但嫉妒？完全不存在。

因为机会明明就摆在那儿，我看见了却没抓住。更现实的是，以我目前的能力，根本接不住这种量级的机会。

说白了，在ChatGPT这件事上，我连猪都算不上。

表面看，他们只是抓住了风口；实际上，这些人是早就练就了各种内功，攒足了资源，只差这么一把风。

所以我干脆先把眼前的事干好，在自己的领域里一点点积累影响力和能力，先挣他个几万块再说。

可能大佬的护城河有几万米深、几万米宽。

我们做不了那么宽，但可以做到一米宽、一万米深，把大佬们看不上的缝隙先填住。

在自己的小领域里，借上小风口，深度聚焦，慢慢放大。

对我来说，之前做游戏时积累的短视频认知，就是这次短剧项目的“内功”。

少去盯着别人的风光，踏踏实实练自己的绝活，总有一天也能闯出一片天。

也许有人会问，这次这么多群友拿到结果，是不是因为你带得好？

真不是。

首先，是因为项目本身就简单，容易上手，容易出结果，这是最大变量；

其次，虽然一开始我没收费，但保证金机制天然筛掉了一部分不认真的人。最后进来的，很多都是自己有主动性、愿意实操、愿意下功夫的人；

最后，才轮到我那1%的功劳，也就是帮忙排排雷、答答疑、做做后勤。

我只做了这点事，但大家看我每天在群里回答问题、统计数据，忙到连自己剪视频的时间都没有，就都在劝我涨价。

![](img/9ad0d04d7aa34a3230fae512d5f400bb.png)

那一刻，我再一次真切感受到了赚钱这句话的分量：

1. 利他，是最大的利己；
2. 真诚，是最有效的套路。

真的很感谢赚钱给我这个机会，用几千块的门票，就让我学到并亲身体会到这么宝贵的道理，不然我可能还困在自己的小世界里打转。

也是因为赚钱，我从月薪3000的上班族，慢慢变成自由职业者，学着用创业思维去看问题。

最后就说一句：

如果赚钱能一直续费，我希望这个期限是一万年。
