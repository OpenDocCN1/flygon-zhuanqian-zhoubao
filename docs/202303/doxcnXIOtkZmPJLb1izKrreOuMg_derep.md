今天在拓跋勇的群里，勇哥确认他手动发一条大概需要两三分钟。确定了这个耗时我就放心大批量操作了，原本还想等一批发完看数据。

# 二、基础

![](img/51f87d4d6054346ba980c59f6f84d53e.png)

AMZON POST 是去年亚马逊推出的测试项目，仅针对在美国站拥有活跃店铺的品牌备案卖家开放。

目前免费，但需要先完成店铺创建并上传商品链接。

我很早就听说有人通过大量上传与产品相关的图片，获取大量站内免费流量。

但我一直没尝试过，一是当时上班公司不重视，没有建店也没有素材；二是组建团队时，成本和精力不足以兼顾。

现在我有更多时间，也具备了基础认知，可以比较快地完成海量帖子发布。

# 五、图片

是不是觉得我漏掉了，那么多素材从哪来？

很简单，你不需要真正拍摄或精修自家产品，只需找到同类场景和目标受众即可。

比如我在《蓝海产品方法论》中提到的几类人群：教师、司机、护士、父母等。

其实顾小北关于精细化运营的文章给了我启发，可以自行搜索：亚马逊如何巧用post，让新店0-1。

这和潮汕牛肉丸的抖音打法类似，批量发布与产品相关的视频，只要有免费流量，商品链接就能曝光，受众越精准越好。

最初我打算做定时发布，后来算下来太麻烦，不如直接用最简单的延时方案，脚本里我设置了两分钟，也就是 200000 毫秒。

大量获取相关图片的方法：

第一步，打开谷歌浏览器，输入 google.com

第二步，搜索无版权图库

第三步，在这些站点搜索产品关键词

第四步，安装插件后右键会出现操作按钮

第六步，按顺序点击图中红框

第七步，点击全选和下载选中

# 六、注意

AMZ POST 图片规范是

*   Image size: 640 x 320 px or larger

*   Aspect ratio: Between 1:2 and 2:1

*   File format: JPG or PNG

*   Color format: RGB

不建议在图片上添加文字。

请仔细阅读亚马逊官方 POST 规则。
