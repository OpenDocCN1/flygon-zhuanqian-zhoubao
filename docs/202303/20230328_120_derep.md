# 我把两百多个ChatGPT折腾了一遍，才发现提示词该这么写
作者：龙哥

大家好，我是龙哥。混赚钱圈子快四年，目前带着一支十五六人的队伍。去年冬天开始把精力放到ChatGPT的落地应用上，到现在差不多四个月，前前后后试了超过两百个不同的对话机器人。

这阵子最深的体感是：ChatGPT的使用门槛已经低到几乎人人都会，但能不能让它真正替你干活，拼的是你下指令的精细度。提示词校准得准，它是利器；校准得糙，它就是聊天玩具。

围绕怎么校准，我沉淀出三层心得，分享给圈里的朋友。

第一层：它听得懂你的大白话，但你把需求拆成有逻辑层次、像伪代码一样清楚的分步指令时，它发挥最稳。平时宁可多写两行，也别让它猜。

第二层：它懂通用表达，但换成你们行业内的专业词汇，回答的含金量会明显上升。跟它沟通，别怕说“行话”，行话反而让它更懂你。

第三层：它中文没问题，但用英文写提示词往往效果更好。很多我说不清的需求，翻译成英文丢给它，常常一击即中。

这三条叠加起来，基本决定了你和ChatGPT是“碰运气”还是“稳赢”。我自己验证下来，最终产出质量提升非常明显。

至于那六个可以直接套用的实战技巧，我整理成了一份飞书文档，入口放在语雀原文里，需要的圈友自行取用即可。
