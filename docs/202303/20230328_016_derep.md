# 为什么要使用指纹浏览器？

做跨境电商运营时，经常会遇到这几类情况：

1. 单台电脑需要登录同一平台的多个店铺，比如同时运营多个亚马逊店铺。
2. 单台电脑需要登录不同平台的店铺，比如既有亚马逊又有速卖通。
3. 单台电脑需要登录同一个社交平台的多个账号，比如多个 Facebook 账号。
4. 单台电脑需要登录多个不同社交平台的多个账号，比如 Facebook、Instagram、Twitter 并用。

在这些场景里，风险最高、必须重点防范的是第1种和第3种，也就是在同一台电脑上操作同平台下的不同账号。

因为绝大多数平台都不允许一人多号，所以我们要做到平台检测不到是同一个人操作的多个账号。这一点对国外平台同样适用，国内平台也一样需要警惕。

那怎么解决呢？

核心思路就是给同平台的不同账号做环境隔离，用不同的浏览器环境+不同的IP，也就是不同宽带网络，来实现账号隔离。

给每个账号分配一个独立的浏览器环境，再给每个浏览器环境分配一条专属的IP。这样账号之间就互相独立了，平台就难以识别这些账号来自同一台电脑或同一条网线。

![](img/2e8be1c7d2f1796843478437f7fdcd2f.png)

# 有哪些账号隔离方案？

举个例子说明。

假设我有两家亚马逊店铺，想避免店铺关联。传统做法是：买两台电脑 A 和 B，拉两条宽带 C 和 D。A电脑配C宽带登录第一个店铺，B电脑配D宽带登录第二个店铺。

这样确实能隔离，但成本高、操作繁琐，要在多台设备间来回切换。

目前行业里主流的替代方案有两种。

第一种是 VPS。租用云服务商的 Windows 服务器，比如阿里云、腾讯云，通过远程桌面操控。浏览器环境和IP都不一样，也能隔离。但远程操控卡顿明显，使用体验较差。

第二种是紫鸟浏览器这类指纹浏览器软件。可以在同一软件里开出无数个相互隔离的浏览器环境，再为每个环境绑定一条独立IP。

优点是流畅不卡顿，IP可以直接在软件内购买，搭配过程简单，价格相对 VPS 便宜，且支持设置账号权限，方便团队协作。

现在业内普遍采用的就是第二种方案。

不过要注意，紫鸟浏览器因政策限制，无法访问 Facebook、谷歌等国内屏蔽的平台。

# 什么是浏览器的指纹？指纹浏览器有什么用？

浏览器指纹是一种识别技术，通过浏览器各种配置和参数来辨别用户身份。比如 UA、时区、地理位置、IP、语言等。就像人的指纹能区分个体，浏览器指纹也能区分不同的浏览器。

它有什么用？可以记录用户的UA、时区、地理位置、IP、语言等信息，帮助网站精准识别和标记用户，从而实现个性化推送和广告定向。

简单说，如果你在同一个浏览器里登录同平台的多个账号，比如同时登录两个亚马逊店铺，亚马逊完全可以通过浏览器指纹和IP信息判断出这两个店铺出自同一台电脑，很容易判定关联进而封店。

指纹浏览器可以同时开启多个独立浏览器环境，并自定义修改指纹参数。这样就在同一设备上安全使用多个账号，降低关联风险。

另外，指纹浏览器也便于团队协作：同一个浏览器环境可以被不同电脑的多人同时打开，账号信息保存在环境内部。

需要强调的是，不同平台的安全风控强度不同。即便做好环境和IP隔离，也不能 100% 杜绝关联，但这是实现账号隔离最基础的要求。

# 什么是住宅 IP？什么是服务器 IP？什么是动态 IP？什么是动态住宅 IP？什么是手机 IP？

为了后面内容更好理解，先普及几个IP概念。

住宅IP也就是家庭宽带IP，说法不同而已。住宅IP是由运营商ISP分配给家庭用户的地址。

住宅IP带有地理位置属性，但并非固定不变。多数情况下运营商会动态分配，路由器重启或网络变动后IP可能更换。而且分配的IP不一定在你实际所在地区，因为IP资源有限，可能给你分配其他区域的地址。

因此，家庭宽带IP本质上是不固定的，随着时间地域轮转变化，所以也叫做动态住宅IP。

数据中心IP也叫机房IP或服务器IP，本质相同。由IDC机房、企业专线、云服务器提供。

数据中心IP特点是固定、稳定在线，但号段多为连号，难以灵活更换，在业务风控中易被识别。

静态住宅IP是固定不变的住宅IP，需向运营商单独申请，企业用户为主，价格昂贵，个人使用不划算。

动态住宅IP的安全可信度高于静态住宅IP，因为它就是真实家庭宽带，更贴近真人环境。

手机IP是质量最高的IP，来自真实手机和基站，更接近自然真人上网。动态手机IP则会自动变化。

综合安全性排序大致为：

手机IP > 住宅IP > 服务器IP

日常运营中，住宅IP或服务器IP已足够。服务器IP最便宜，动态住宅IP价格更高，静态住宅IP最贵。

选择哪种IP要根据业务场景和平台风控强度来定。

另外提醒一个避坑点：市面上很多号称静态住宅IP的，其实是服务器IP冒充。真正的静态住宅IP供应很少且价格高。

# 不同的 IP 是怎么收费的？

各服务商收费标准不一，下面是常见情况举例。

静态服务器IP一般按月收，一个月几美元到几十美元不等。

动态住宅IP一般按流量消耗计费，比如1G流量约10美元。

静态住宅IP一般按月+流量双收费，比如月费20美元，另加1G流量25美元。

# 常见问题答疑

最后整理几个大家问得最多的问题，方便自查。

**Q：同一个IP可以同时配给多个浏览器环境吗？**
A：技术上可以，但要注意：多个环境共用同一IP时，最好别在这些环境里登录同一个平台的账号，否则很容易被风控判定为关联账号。

**Q：检查代理成功，是不是所有网站都能正常打开？**
A：不一定。不少IP服务商会有自己的网站屏蔽策略，比如IProayl的IP就打不开Facebook。这种情况下只能换服务商，比如可以试试这个：[rola-ip.co](http://rola-ip.co)。

**Q：检查代理显示成功，但打开浏览器后Facebook还是访问不了，为什么？**
A：一般有两个可能。一是像上面说的，IP服务商屏蔽了那个网站；二嘛，可能是你本机网络也需要开梯子，开了之后再试往往就通了。

**Q：用hubstudio检查代理时提示“该IP已被使用过”怎么办？**
A：意思是这个IP之前已经在hubstudio上被人添加并记录过了。如果是动态IP，基本不用在意——就算没有这个提示，这个IP也可能被其他人通过其他软件用过。如果是静态IP，而且打算用来注册重要账号或者高风控账号，那就换个新IP更稳妥。

**Q：不同的IP服务商有什么区别？**
A：主要差别在价格和IP质量。通常越便宜的IP越容易被滥用，质量自然差一些。稳定性也有差异，有的很流畅，有的经常卡顿。另外，有些服务商的动态IP并不会乖乖在指定州或城市变动，可能在全国范围内乱跳，这点要留意。

**Q：不同IP类型该什么时候选？动态住宅IP和服务器IP怎么挑？**
A：没有绝对标准，得看自己的使用场景和平台风控强度。举个我自己的做法：发帖、聊天这类社交账号用服务器IP——因为刷帖聊天很费流量，服务器IP是包月不限量，用起来划算；不常用或特别重要的账号，用动态住宅IP——这种是按流量计费，不用就不花钱，既省钱又相对安全。

**Q：动态IP每次打开都不一样，真的没问题吗？**
A：问题不大。国外普通家庭的宽带IP也不是永久固定的，也会变动。只要IP在一个固定区域里变动，比如始终在同一个城市范围内，就不会带来什么麻烦。

**Q：动态IP池会不会用完？不同浏览器会不会撞到同一个IP？**
A：IP池当然会被分配完，但会有循环更替机制。如果多个浏览器都用同一个地区的动态IP，确实存在一定的概率撞上同一个IP。不过就像刚才说的，国外宽带本身也会变IP，所以不用过于担心。

**Q：我有Facebook和Instagram账号，能放在同一个浏览器环境、用同一个IP同时登录吗？**
A：当然可以，平台都不一样，不存在关联风险。

**Q：在IP服务商那里买的是美国IP，为什么hubstudio测出来却是别的国家？**
A：这种情况挺常见的。一方面要看服务商的IP质量，靠谱的服务商测出来的归属地和购买时标注的通常一致。但不一致也不一定全是服务商的错，因为各家用的IP归属数据库本来就可能不同。我的建议是：如果懒得分歧，就以hubstudio的检测结果为准；如果每次测出来的位置都不一样，那就赶紧换服务商吧，反正市面上选择很多。

**Q：什么时候用紫鸟浏览器，什么时候用hubstudio+IP服务商？**
A：核心看平台和运营阶段。提醒一下：紫鸟浏览器内部也提供多种IP。比如你要注册亚马逊店铺，这时风控极高，紫鸟的服务器IP可能不够用，通常得买它家的宽带网络。但如果是已经注册好、运营了一段时间的亚马逊店铺，再迁到紫鸟配个服务器IP，问题一般不大。另外，注册亚马逊这种高风险操作，我个人强烈建议用自己家里的真实电脑和宽带。至于运营Facebook、TikTok这类社媒账号，那就只能走hubstudio+IP服务商这条路了。

**Q：怎么判断一个IP是服务器IP还是住宅IP？**
A：可以用这个网站查询：[https://scamalytics.com/IP](https://scamalytics.com/IP)。输入IP后点查询，如果是服务器IP，ISP Name通常会显示服务商名字，比如“深圳市腾讯电脑系统有限公司”这种：

![](img/dff3a828d6ad90539ed65539cf27080e.png)

如果显示的是下面这种：

![](img/6abcff5d7c7e3685b9541c4e1fd4a571.png)

去百度搜一下公司名，能查到是香港的宽带提供商，那这个IP就是住宅IP。

![](img/24b86d6f0037edc717a098684cedbb04.png)

其实大多数时候我们不用自己判断，IP服务商早就帮你分好了类别，毕竟两者价格差异很大。另外，这个网站也能辅助判断IP的“干净程度”。

数值越高，代表这个IP被用过的次数越多、历史越“脏”。当然，这个指标只能参考，平时不用太纠结。只有当你要运营风控极其严格的平台时，才值得提前查一下自己的IP垃圾值。
