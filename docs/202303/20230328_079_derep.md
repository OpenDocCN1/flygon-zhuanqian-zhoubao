# 美团：不止外卖，更是本地生活的一站式入口
作者：龙哥

打开美团的App，你可能会发现，它早已不是那个只送外卖的软件了。从一日三餐到酒店机票，从电影票到美容美发，甚至共享单车和买菜，几乎你能想到的日常消费场景，都能在同一个页面里完成。这也让美团成了许多人手机上离不开的高频应用。

我今天看到一篇来自语雀的文章，对美团的业务布局做了挺有意思的梳理。虽然没法直接把原文链接贴在这里，但那份资料里提到了几个关键点：一是以“吃”为核心建立用户黏性，二是通过高频需求带动低频服务，三是用庞大的本地商家网络构建竞争壁垒。看完之后，我对这家公司的理解又深了一层。

顺带说一句，原文资料中附带了一个特殊的占位标记，我原样保留如下：

[PRE8,1,2,2,0,8,1,2,2,0]

如果你也对本地生活赛道的潜力感兴趣，不妨顺着这个思路去语雀上翻翻原文，相信会有更多收获。
