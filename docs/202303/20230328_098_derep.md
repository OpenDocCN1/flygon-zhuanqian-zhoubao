# 24小时从灵感到上架：我是怎么靠小报童一周卖出80份年费专栏的



## 《一次被好奇心推动的内测：6天80单，1.5万营收是怎么来的》

作者：白杨私人号
日期：2023-03-22

很多人问我，付费产品到底要准备多久？我只用了一天。不是吹牛，是真的从看到工具到上线成交，压缩在了24小时内。现在这款年付199的专栏，内测6天已经卖出80单，流水1.5万。还没开始正经投放，预计4月才会全面放量。等用户做到几百上千人，我会再做一次复盘。今天先把路径摊开。

**第一步，我对市场的味道特别敏感，而且敢立刻下单体验**

2月10号那天我加了孙哲老师，后来才知道他也在龙哥盟。翻他的朋友圈时，我第一次撞见“小报童”这个东西。完全没概念，但第一反应就是：好奇。

我先付费订阅了他自己的专栏。为什么这么快？因为内容正好是我缺的那块，再加上整个订阅体验、支付链路、排版呈现都让我上头。我就是那个典型的用户，我爱了，别人大概率也会爱。

订阅完我立刻去研究规则，发现可以自建专栏。我们公司本身就是做知识付费的，内容储备非常厚。那一刻我就笃定了方向。那晚我直接熬夜把产品骨架搭出来，第二天一早就给创始人过了一遍，当场拍板。申请当天就交上去，第二天就通过了。

**第二步，产品定位：把最拿手的变成可复购的年费池**

为了判断切口，我前后订阅了十几个同类专栏。大部分都在讲某个平台玩法，卖点很具体，定价多为39到99的买断。

我反着来。我做199/年的订阅制。内核是把公司现有的知识模型做成一个合集，沉淀下来。公司每天都有新内容产出，这个专栏就是一个沉淀库，专门放那些不适合丢到社群、朋友圈或者做成课程的内容。

它本质上是个引流款。低客单，服务的是私域里吃不下大课的用户。可以理解为我们生态里的下沉人群。我们的主线产品定位很高，不可能拿几百块的东西去朋友圈狂发。小报童的优势正好是静默成交，转发到朋友圈就像转发👸号一样体面，链路短、调性好、用户自愿。

专栏刚上线是季度付，30天后才开放年付。3月13号年付功能一开，我就同步上了分销。分销比例我设了50%，灵感来自老徐老师的玩法。很快就有用户通过分销成交，验证是通的。

**第三步，行动速度就是护城河**

执行力是我一直以来的强项。从小就不服输。长大后也会犹豫，比如纠结名字、怕不好意思推、怕亲戚朋友看到尴尬、怕没人买。后来我发现，我每次真正赚钱的时刻，都是没有反复纠结，直接开干。

把问题一个个解决掉，经验就堆起来了，自信也就长出来了。你迈出去解决一次困难，下次对这件事的掌控感就从0到100。这种闭环很真实。快一步，就是快一整条路。

**第四步，巧合堆出来的机会**

二月对我来说像被安排了一样。先是孙哲让我知道小报童能做专栏，后来又遇到老徐老师，发现了龙哥盟，再加上芷蓝姐、星月哥、梁靠谱等人的朋友圈，都在用小报童或星球。不同人给我不同的拼图，我脑子里产品雏形一出来，外界的资源就跟着到位了。瞌睡就有人递枕头。感谢这些相遇🙏![](img/7f788f7f35a0fdb347100e87d0d183e8.png)
