# 抖音资料类账号运营复盘与思考

各位朋友，笔者胖猫在此打招呼。算得上生财社区的老成员了，四年时间一直在这里学习交流。现在定居首都，在一家聚焦健康产业的公司负责药品流通管理相关业务。业余时间我尝试过的内容变现形式比较多，曾运营过微信平台的原创号，做过导购联盟，也试水过短视频直播带货。去年起把副业重心转向了抖音上的资料型账号，最终做到了六位数营收。

最近刚落幕的一次航海项目中，我有幸再度被邀请上船参与精选内容共学环节，于是把这一年做资料账号的实操细节整理成了一篇公开复盘。

若你正在关注内容型变现赛道，希望这篇记录能为你提供一些参考思路。

再次对生财社区表达谢意，也祝愿每位朋友都能把理念落地。
