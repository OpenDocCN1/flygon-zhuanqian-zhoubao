# 【其他】

平时刷到零散的知识点，是不是总有一种“哇，这个有用”又转头就忘的感觉？真正厉害的人，往往都会做一件事——把那些不好归类、却又特别实用的小技巧，统一收进一个“杂货铺”里。

今天想分享的，正是这样一个宝藏角落。它被命名为【其他】，听起来毫不起眼，却是很多人悄悄收藏的“万能口袋”。许多没法放进大分类里的干货、冷门经验、实用技巧，都安安静静地躺在里面，等你去发掘。

感兴趣的话，不妨点进来看一看：[`www.yuque.com/for_lazy/thfiu8/ioco4tluubmpq2i5`](https://www.yuque.com/for_lazy/thfiu8/ioco4tluubmpq2i5)

别让有用的东西，止步于“看过”。真正拉开差距的，往往就是这些被忽略的边角料。收藏起来，随时翻翻，说不定哪一条就能帮上大忙。
