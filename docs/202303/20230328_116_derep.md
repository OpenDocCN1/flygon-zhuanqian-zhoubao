# 《十一场远航全勤二百一十一次，我终于站上了新起点》

伙伴们好，我是老乔。这次一口气报了11个航向项目，总算靠岸了。趁着热乎劲儿，把这段经历复盘一下，也给自己留个纪念。

在这21天里，我同时参与了11场不同的航程。其中10场我都做到了每日签到，一天没落，累计210次；另一场是同城线下聚会，签到1次。总签到次数定格在211。所有里程加起来有2240里，并有13条内容被评选为精选。

在这个周期内，我还在社群内部做过1次分享，在付费社区发布过3篇长文，在自媒体账号推送过6篇文章。每天跟着航海手册走，10套手册全部啃完，另外还旁听了上百次群内高手的经验拆解。

每个上船的人都有自己的算盘。有人想直接换取结果，比如引来流量、赚到钞票；有人想要成长，学技能、看行业；还有人希望通过结识同伴，完成资源拼图，找到合拍的搭档。

坦白讲，上述目的我也有，但都不是我的核心诉求。我真正想要的是一个可以长期栖身的环境，一群气味相投的伙伴，在彼此的正反馈里，把精神上的疲乏一点点消化掉。这也正是我决定投身赚钱、连跑21天的根本原因。

这趟航行并没有让我收获大量关注，也没带来可观的收入。可成功的路本来就不是一口气跑完的，更不是三周就能定型的。至少，这21天的持续投入，让我的人生轨迹出现了明显的转折。

一次航程搞不定的困局，就再来十一次。持续在海上，才是破解之道。
