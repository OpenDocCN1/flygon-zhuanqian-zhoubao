# 《航海复盘：利用剪映+达芬奇+影刀 RPA 提高混剪效率》
作者：龙哥

三款工具接力，混剪也能跑成流水线

这一期视频号带货实战告一段落。我当初定下的佣金目标是一千块，结算时几个账号合起来也不过刚过一半。作为刚下水的新人，谈不上什么心得，只当是给大家分享一条赤脚蹚过的路。

头两天，我完全没碰剪辑。靠考古加挑品，看着顺眼的就搬到视频号。不敢铺开，只拿一支测试号试水。播放量倒挺给面子，有的视频逼近一万。可欢劲没过，平台就来问有没有医疗推广，要提供证明。我自然拿不出，这支号直接废掉。

后来又开了新号继续搬，以为绕开医疗就行。结果第二天冲出一条过万视频，卖了2单。正高兴呢，再发布新片，播放量直接躺平。平台提示内容质量不行，让我交10条原创自证。这号没被封，但已形同虚设。

到第七天，我终于不再信搬运。实拍条件不具备，眼前只剩二剪和混剪两条路。当时我连这两个词有什么不同都搞不明白，还特意去问AI。之后开始手动混剪，目标一天10条，实际从早上九点干到半夜也凑不齐。好在每条基本都能过审。有一回发出去半小时零播放，我以为号又完了，结果只是这条片子凉了。直到第三个账号，才终于爆出一个十万播放的视频，成交二十几单，佣金两百多。混剪方向得到验证，但效率太低——伺候一个号已经手忙脚乱，那个半废的号更没工夫管。

交代一下各工具的熟悉度。剪映老早装在电脑里，但从来没真正用过；达芬奇这名字一听就“大神专用”，我一直没敢下载；影刀RPA倒是认真自学了一星期，为了群发和自动加好友，写过几个小流程，但没带来实际收益。

第10天，我在日志里看到有圈友说，达芬奇自带一个“场景剪切探测器”，能把视频按切换点自动拆开。我做好物带货，画面切换本来就多，哪怕前后镜头完全对不上，拼起来也不难看。这不就是给我准备的么？赶紧装好，结果那个功能入口我硬是找了一整天。查资料、问AI，得到的回复都好像这东西简单到不用提，反而显得我很蠢。

到了第12天，在两个软件之间来回折腾两天后，我实在受不了了。当时甚至想，就算视频先不发，也必须把流程理顺。让RPA介入剪辑的想法越来越强烈。动手前我先把动作列清楚：一、自动切分镜头；二、对切出的片段做翻转、缩放、位移、滤镜；三、把原片解说词提取出来修改；四、把原片标题提取出来修改。前两项在达芬奇里做，第三项在剪映里做，第四项可以直接从下载的标题里拿，或者用哼哼猫导出。

齐杰老师有句话：料备好，菜才好做。前面这些只是备料，真正“炒菜”的环节如下。

第一步，处理旁白。打开字幕夹这个备料库，挑一段合适的解说词。想省事就沿用原声；想多一点差异化，就把文案丢给语音合成工具；再讲究一点，先让GPT改一版再合成。多账号铺量时，就多换几套声音和文案。我当时用的是微软的语音服务，装的是1.5.2民间版，官方版前两天取消了，不然加个外部插件会更香。

第二步，处理标题。打开标题库，可以直接用原来标题，但记得清理非视频号平台遗留的@符号。也可以丢给GPT，让它按需改写。需要多账号分发，就多准备几版标题。

第三步，进剪映。把旁白拖进来，再把切好的片段文件夹也拖进来，顺带放上提前准备的文字模板。稍微对齐，让画面和旁白能对上几帧；如果没有配音，连调整都省了，直接导出备用。为了加大去重效果，我一般会上下各裁一刀，垫上虚化背景。原片字幕通常在下方，所以用达芬奇时要把画面往下压一点，再在剪映里裁一刀，黑边和字幕就都被挡掉了。

接下来把备料的流程写出来，方便想实操的朋友少踩坑。

先是文件夹规划。在桌面或某块硬盘上建五个目录：源头素材库、完工素材库、账号环境库（每个账号的登录浏览器放在这）、账号发布库（每个账号要发的成片放在这）、剪辑工作库（里面再分片段池、字幕池、原始池）。目前素材是手动抓取的，去抖音、快手找品，每款商品挑8段视频，用下载器抓进源头素材库，然后跑一遍流程，把名称同步到片段池和字幕池。

![](img/7e02a00f55258631c80916cef3eee235.png)

达芬奇的场景探测器有个毛病：成批处理不同分辨率的视频时容易崩溃，不清楚是电脑配置还是软件bug。所以新抓来的素材得先统一预处理，顺便把旁白提取出来，把标题改成合规名称。注意名称里不能有空格，否则达芬奇不认。这一步是用RPA在剪映里完成的。处理好后，素材还在源头库，只是规格和名字变了，字幕池里也同步出现了旁白文本。

这一步算是全程最核心的去重操作。达芬奇里有些板块不能靠自动化点选，只能用鼠标按坐标点，所以我特意在中转环节加了一个文件夹叫“原素材夹”。流程开启时，源头库的第一个文件目录会移进原素材夹，处理完再移到完工素材库，所以平时原素材夹空着。具体操作：先在达芬奇的媒体面板里切割场景，把拆好的片段加入媒体池；再进剪辑面板，调尺寸、位置、旋转、翻转；随后到调色面板，在色轮上调一组参数，不会问AI即可，再让每个片段都套同样的；最后渲染导出。

![](img/f6e887ecdae1b4904a1bc68529003321.png)

导出的片段还是按原始顺序排的，这对混剪很不利。所以我又用RPA做了一次随机抽取重命名，把顺序彻底打乱。

到此，备料完成。

第19天，跑几天后觉得还是麻烦，因为每个流程都要手动启动。于是又用一天时间把所有步骤合成一条总流程，终于省事不少。

第20天，又意识到流程光省事不够，还得稳定。之前从没做容错，心想自己用无所谓。可一旦报错就要手动归位文件、清理多余命名，反而更折腾。于是又花大半个晚上补了容错机制：流程启动时先复位初始状态，这才稳下来。

第21天，发了几条视频后，我开始写这篇复盘。偶尔看一眼后台数据：其中一条4000播放就出了4单，是全程转化最好的一次。不过暂时没打算直播，等写完复盘，再去琢磨那条视频为什么这么能打。

这篇复盘就到这里。我很少动笔，刚开始都不知道怎么写，只能想到哪写到哪，文字粗糙，请包涵。如果能让正在赚钱路上摸索的你少走一段弯路，就值了。
