# 《过程本身就是奖赏》



## (586 赞)《过程本身就是奖赏》 

作者： 龙哥 

日期：2023-03-27 

他从不给自己找对手，也不把龙哥盟归入任何同行范畴，内心没有应战的紧绷，也少有危机感的牵引。对他人收入高不会心生羡慕，对自身增速慢也不会焦躁。既不会因低谷而贬低自己，也不会因小成而自视过高，骄矜和赶路的冲动都与他无关，收益最大化从来不是目标。

他只想做一件独一无二的事，让人觉得好玩、投入其中便能忘我，且对别人有实际帮助。做这件事时，他全盘接纳各种情绪反应：愉悦、平淡、甚至近乎崩溃的时刻，都被视作生命经验的组成。走这一趟，体验即是意义。

留言里有读者用一句话点出了精髓：爱我所爱。

这句话让我更清晰地get到他的状态：当一件事情被真正喜爱，终点的好坏就不再是评判标准。旅途里的颠簸、阴雨与晴光，都是馈赠。那些曾被归为弯路的挫败，事后回望也都是风景。

我们从不白忙一场，感受本身就值得。
