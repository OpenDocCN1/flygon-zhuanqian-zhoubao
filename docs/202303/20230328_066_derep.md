# 《📕店铺运营——有货源模式的玩法》

没有合适岗位，这个宝妈就自己走出一条路：玩具设计师开店，首月流水破10万

Jing是两个孩子的妈妈，因为育儿很难找到合适的岗位，于是决定自己走一条路。她把“为自家孩子设计玩具”当作定位，也把每天陪玩、手作的过程拍成内容，做成产品入口。她的货源于自己的设计，属于典型的有货源IP玩法。

2022年11月，她在某个种草平台开了家小店，并接入社群拼团工具做转化。开业头30天，流水冲到六位数；过了约半年，整体业绩再翻一番。没有投放预算，也没有团队，她只是把人设立稳，把内容更新坚持下来。

不少人问她：一定要先养号、涨粉，再考虑开店吗？她的经验是：不必。从零开始也能边做边改，边运营边积累，让模式跑起来最重要。

这个例子最有价值的提醒，或许就是：不必等到万事俱备才敢开始。手边有产品、脑中有灵感、愿意保持输出，就已经具备了最朴素的创业条件。
