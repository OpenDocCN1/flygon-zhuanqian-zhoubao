# 从零到一：一个平凡人靠📕起盘付费群组，月入八万的真实复盘

## 62赞 《普通人做📕，从 0 到 1，起盘我 0 元成立一个社群，单月变现 8w+的经验》

作者：刘晨昊  
日期：2023-03-27

大家好，我是龙哥。曾做过投资、做过战略，现在转型做内容创作者，单月变现已过八万。很乐意和赚钱的朋友多交流，笔记、📕、抖音以及视频号都可以聊。相信随着 GPT 这类生产力工具的普及，个人品牌必然走向多平台化，之后我也会继续探索私域玩法和公域矩阵，欢迎多来互动。

一、心态建设

1. 要给自己留出试错窗口。我从接触抖音到真正沉淀，耗时接近半年，期间一直在摸索，从未中断。举个小例子：程前早期还在西安街头跟小摊贩对话。自媒体时代最吃香的就是个体IP，即便没有现象级影响力，像我这种微影响力也能明显感受到流量带来的价值。于是不断提醒自己要坚持，能做到的我也可以做到。谁不是从普通身份起步的？所谓的超级个体，前身基本都是临时搭的团队。

2. 他人的经验只能参考，路还得自己走，不要半途而废。

3. 观察下来，做内容做得风生水起的人，现实生活往往比较拮据。我本人当时职场遭遇滑铁卢，账号反而起飞了。所以如果你现在处境不太好，别焦虑，这很可能就是创作的素材。

二、开号前的准备：放下顾虑，直接开干

1. 上线首日，我在平台发布了三个不同赛道的共计五篇笔记：职场向、宠物向，我养了两只猫，以及英语学习向。测试后发现职场内容的互动最好，尤其是关于互联网公司招聘和内部情况的分享，虽然没立刻爆号，却捕捉到了一点感觉，于是锁定该赛道深耕。

2. 次日，我发布了《平凡人进入投行咨询，野路子反而更合适》，算是正式找到了平台的语感。这与此前半年在抖音的两个月试水密不可分。语感只能靠大量练习来获得，第一篇不行就第二篇，第二篇不行就第三篇，直到摸清出圈的办法。另外抗压能力很重要，最好在生活压力较大的状态下——我前期在抖音推进缓慢，正是因为当时工作还算稳定，手底下带团队很顺。后来在平台快速突破，恰逢生活陷入低谷：团队解散，自己也差不多要离开。

3. 总结一点：该平台本质上是标题驱动的。标题足够抓人，成功率接近九成九。按照二八原则，每天将八成甚至更多的精力放在选题打磨上很有必要。我没有刻意研究对标号，而是从自身擅长的领域挖掘。那个标题之所以有效，主要在于“平凡人”与“投行咨询精英”的人设反差强烈，“野路子”又带好奇心，看的人会觉得不看可惜。

4. 可以去看我置顶视频里分享过的干货，我觉得还算扎实。
