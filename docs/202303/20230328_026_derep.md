# 嘉宾话音刚落，我的图已经甩进大群

每次参加线下聚会，我都是那个坐在角落里拼命敲字的人。别误会，我不是走神，而是在把每位分享者的内容快速拆成一条条要点。通常嘉宾刚收尾，我手里这张结构清晰的关系图就已完成，转头传到活动群里。

正因为这个动作，常有圈友私信问我：“你是不是开了什么外挂？”其实没有，这只是多年练出来的记录手感。做这件事的收益也不止一层：自己复盘效率提升，现场伙伴能第一时间拿到梳理好的信息，还会有人顺着这条产出加我好友，形成很自然的被动曝光。
