# 从0到1涨粉，我是怎么跑通的

## 定位是怎么一点点琢磨出来的

先说心态这块。

我做自媒体快半年了，从抖音折腾到📕，一直在试错，从没停下来过。顺便八卦一下，程前以前还跑到西安街头去采访小商贩。自媒体这个时代，个人IP的红利真的很实在，不需要做到现象级，我这种还算小众的体量，也已经能切实感受到流量的甜头。所以给自己一点耐心，坚持做下去，我能找到的路，你也一样能摸到。谁起步不是个普通人呢？那些现在看起来光鲜的个体，本质上都曾是草台班子。

别人的成名路径只能参考，最终还是得自己撞。

我发现做得好的同行，生活往往都经历过一段比较困顿的时期。我当时职场很不顺，正好就把号给起了。如果你现在也感觉卡住了，也许这正是创作最好的养料。

起号前的试探，我就是闷头上。

📕第一天我就发了三条赛道，总共五篇内容：职场、萌宠我有两只猫、英语学习。测下来职场内容的数据最好，尤其聊互联网内推、招聘内幕这些话题，虽然没爆，但有了手感，于是就把重心押在这条赛道上。

第二天发了《普通人进入投行咨询，野路子才是最合适的》，算是正式上道。这个网感的养成，和我之前在抖音折腾两个月密不可分。网感就是靠刷出来的，第二篇不对就第三篇，第三篇还不行就第四篇。要有抗揍的能力。前面抖音进展慢，是因为那会儿工作还算顺心在带团队。后来📕能快速起飞，恰恰是生活被逼到墙角，团队没了，自己也要跑路的状态。

我最深刻的体会是：📕是标题的战场，标题对了基本就成了。毫不夸张。按二八法则算，每天把80%甚至更多的精力砸在选题上最值。我没刻意找同行对标，而是围绕自己擅长的领域去挖。那个标题之所以能打，就是因为制造了强烈的人设反差：普通人 VS 投行咨询精英，野路子、冲突感，读者一看就想点进去。

因为自己想跑路，不太想一直写纯职场，而且从涨粉那天起我就琢磨变现，账号本身就是为了赚钱、为了离开原有工作。所以后期的选题会更泛化，不会死磕职场，怕误导人。尝试的方向有：

这一轮帮我完成破圈，圈外的人也开始关注我。

由于自己有跑路诉求，我也会主动去访谈已经跑路成功的人，大量拆解案例。这段时期内容变成了：

总结我的涨粉经验：

先快速测试赛道，精准打一波人群，再用大众话题破圈，然后结合自身思考持续迭代内容重点。从来没有一次到位，到现在还在调。IP本身就是一个不断生长的东西。

找到自己的支点特别关键。对我来说是行业研究和竞品调研，这是我能持续产出的地方。每个人都有自己的支点，找到它就找到内容的方向。

我也在思考粉丝到底追的是什么。刘晨昊在她们眼里关注的可能是在投射未来自己：我正在做她们想做的事，说出她们想说但没说的话。

欢迎你告诉我你关注我的是什么原因。我现在也在探索抖音转型，由图文转纯视频，适应感很差。在商业模式和产品已经成型后，更要想清楚定位到底是什么。我目前的关键词是：30岁、北漂7年、普通人、想通过职场跑路。有新的点醒也非常欢迎。

## 内容怎么做，我常用的三种写法

案例拆解类
先抛结果：他一年做了多少万
再拆路径：他是谁、做了什么、定位是什么、解决什么痛点、具体怎么做、获客怎么做、内容有什么亮点、引流方式、销售话术、直播间和私域的朋友圈怎么打
核心是站在用户视角去体验一遍，再用大白话讲清楚。

## 变现我是怎么设计的

商业模式选择：

卖服务
1对1咨询：📕上想接单分分钟的事
社群：对前端获客要求极高，但运营成本几乎恒定。运营500人跟运营100人成本差不多。缺点是📕一旦限流，收入会立刻掉。我前期能快速拉起验证了能力。社群主理人要有鲜明风格，视频感会更强

卖课
录播课边际成本低，但首制成本高，还要和大V竞争。粉丝量、转化率是关键。目前卖得好的录播课大多在20万粉级别。我自己的录播课定价几百块，付费200多，转化按10%算也就几万收入，动力不大。是否值得看个人精力。

训练营/大班直播课：最容易做出高客单和差异化，属于非标产品。你先收钱再交付。比如IP系列训练营就很适合做账号人群。

卖货：现在电商平台竞争白热化，除📕外无货源玩法很难。建议有自己的货源，做中高客单。

卖广告：目前📕广告变现集中在家居、美妆、服装、美食、萌宠。品牌预算也紧，大达人也在卷。做副业可以考虑，主业不建议。

小建议
适合自己的才是最好的，可以组合打法
前期别铺太多SKU，先把一个产品口碑做起来
想专做社群，一定先解决流量问题
其他模式对流量的压力会小很多
也可以学李一舟一次性收割，每个人节奏不同
口碑好的课程第二年顺势拉社群也行，前提是先服务好一小批人

# 0元起盘付费社群，我的四步预售法

## 私域引流和避坑

🛰️号
新号必须养号，规则很多，不细讲了。别学我一个月封两个号
每天朋友圈条数、通过好友频次和数量都要控制
常规动作：🛰️运动、抢红包、常视频
老号一年以上，一天通过好友别超过200个
一个号的存活机会就那么几次，好好珍惜私域资产

## 为什么朋友圈IP比公域IP更关键

关注你的不算你的用户，加你好友的才算
朋友圈能不断强化记忆，也是在变现时提醒用户你有产品
到了朋友圈你就是用户的朋友，不是几万粉的遥远大V
公域IP难做，朋友圈IP门槛低。你只要比用户朋友们有见地一点点，就显得很专业
朋友圈怎么发：少用专家腔，多写个人感悟；不用天天刷转账截图，你的存在本身就是提醒；频率早中晚各2-3条就够，多了反感
核心是让用户觉得你是朋友，而不是一个卖货机器

## 素人起盘社群，预售四步

Step1 亲近用户，适当被白嫖
起盘前一个月开始引流到私域，1对1聊过每一个人
打造朋友圈IP，和用户真实互动

Step2 打造钩子并预热
发朋友圈说我要出一本搞钱小册子，敬请期待
期间每天发一点进度，制造围观和期待

Step3 筛选高潜用户
朋友圈说小册子做好了，需要的点赞我会一一私发
目的三重：不想看册子的基本不是核心用户、能知道潜在付费人数、方便一对一私发顺便推社群
当时我300多个好友，100多个人点赞
私发册子时顺带告知：我有个社群产品一个月后上线，现在优惠100元，只要499，要不要买
初创社群要先把100人的盘子拉起来，比赚钱更重要。价格不能高。没有公域加持的纯私域高价圈子很难做大

Step4 算转化判断模式是否成立
我当时的转化很高，100人里一周内50人付费。因为前期铺垫了一个月。后期佛系加人，一天加20人大概有3人买单，整体转化依然不错
📕1600群 - 🛰️800 - 付费会员不到160，各层级转化大家可以自己算。这个转化率在教育产品里算很高的
