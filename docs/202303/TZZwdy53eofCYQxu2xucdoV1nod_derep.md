# 赚钱圈友关心的20个问题（杨涛、龙哥）230329
作者：龙哥

最近看到杨涛和龙哥的一场长对谈记录，围绕圈子里常被问到的二十个话题展开，涉及做事心态、判断项目、逆袭案例、新人融入以及下一阶段的打法。我把读下来反复回味的部分整理成自己的理解，分享给你。

先说一个反常识的点，为什么已经有稳定收入的人还愿意把自己摸索的路公开？关键在市场结构。做的是存量盘，分享等于分蛋糕；做的是增量场，分享反而带来更多连接和可能性，开放的姿态更容易撞上运气。

谈到失败，杨涛的说法很直接：出手十次，有九次会空，这才是常态。把这个预期提前装在脑子里，行动时就不会被吓退。真正起作用的不是宏大的规划，而是第一次拿到正向回馈，哪怕金额很小，也会在心里种下“我能做成”的印记。小小的胜利会产生惯性，成功会自己滚雪球。

心理韧性怎么养？没有捷径，只有经历。扛的事情越大，遇到的阻力越硬，心量也会被迫打开。回头看过去觉得难以跨越的节点，现在回想起来只是“就那样”。这种耐受力像体能训练，练多了底线自然抬高，不好的事也可能成为成长的养分。

关于日常工作状态，两人很坦诚。杨涛的有效产出窗口其实很短，信息输入和他人求助占据了大部分时间，他在尝试把碎片时间利用起来。龙哥则每天投入时间很长，但深度工作大概五小时左右。杨涛还提到一个朋友的打法：把效率和时长都做到别人的三倍，让对手追不上。

心态上，杨涛也做了调整。早期他也是拼命型，现在更倾向于避开那种靠纯苦劳就能出结果的赛道。因为只要努力就有回报的方向，很快会被一大波更能吃苦的年轻人填满，竞争成本太高。

真正赚到钱的人，身上有哪些可复制的特征？姿态低，会真诚请教；好奇心强，碰到新东西立刻去找懂的人聊；选择和主流不一致；状态松弛而不是紧绷；思考直指本质，不绕弯子。

让我印象深的两段逆袭经历。家蒙入圈时几乎零基础，看见知乎好物有人做得出来就跟着试，头几个月收入微薄但他坚持下来，后来这条线成了年入数百万的支柱。期间杨涛建议他换赛道，他依然深耕原选方向。另一位是原本做酒店管理的郑小焦，通过圈内链接到一位前辈，跟随学习后人生轨迹改变。两件事都指向同一个逻辑：想要跃迁需要机会和贵人，但机会和贵人之前，你需要一直在线，让自己的努力被看见。每个人的坚持窗口不同，有人能扛三月没水花，这份耐心本身就是稀缺能力。

信息处理上，杨涛说看得多了以后，扫一眼就能判断内容是否有增量。别人需要几小时才能过完的内容，他半小时就能完成。他不追求逐字精读，只抓信息增量。龙哥补充，人与人的差距很大程度上是信息摄入量的差距，数量到一定程度，质量自然显现，脑中会自动形成模型。每天花半小时到一小时浸泡在圈子里，久了会成瘾，零散的点会逐渐连成线。

为什么没有大规模🛰️群？早期试过，缺乏主题的闲聊群价值有限，还会分散注意力。现在保留的群都带明确主题，比如航海群、活动群。圈子体量大了后，同时运营几百个群风险很高，团队在探索更轻、更低成本的社群运营方式。

第六期像大课加陪伴，有人问是不是有人在后面推着走。杨涛说赚钱终究是自己的事，不动手谁也帮不了。圈子里有种玩笑说大家都希望被按头逼着做事。早期他们尝试过讲课布置作业检查作业的模式，后来取消了，主要原因是可带的人有限，教练和志愿者精力不足，且初衷是让更多人上船体验，而不是筛选。

线下交流这几年较少，第七期会走两个极端：要么做大型联结局一次连接很多圈友，要么做六到八人的小而深的聚会。有机会会在多座城市做五百人局。线上聊一百遍不如线下见一次。想参加小局可以找鱼丸了解各城市负责人。原则是明确主题，人数控制在八人内。龙哥常在广州、深圳、杭州、厦门活动。

对于长期脱离社会的人群，比如全职妈妈，最好的入口是航海。这里有手册、有教练和志愿者，还有同伴。选择上不必纠结，随机选一条即可。哪怕从运动打卡开始，坚持几天感受到变化，力量感就会回来。报名数量没有上限，听闻有人一年报三十多条，但更合理的建议是单次一到两条，集中火力先拿到结果。

圈子现在四万多人，团队在做资源库，帮助快速定位人和内容。但在信任没建立前，直接链接效率不高，更稳妥的是先连接一两个枢纽型节点再外扩。龙哥提醒，圈子里好人多，但涉及资金往来要格外谨慎。

怎么判断项目适不适合自己？杨涛以自己为例，做赚钱之前试过几十个方向，直到社群才找到更匹配的方向。判断力不足时，不必追求最优解，挑一个不反感的先做。试错本身就有收获，至少能排除不合适的路径。与其在纠结里消耗，不如把时间投入一条航海。

龙哥补充，不是每个人都能找到热爱，有偏爱已属幸运。在不讨厌的基础上找相对偏爱，先做出结果赚到钱，才有资格谈热爱。

风口和长期项目怎么选？杨涛认为风口并非不能碰，能抓住就做，但前提是时间价值还不高。若时间价值已提升，更值得在一个方向长期深耕，赚持续的钱。龙哥提醒要想清楚在多大时间里要什么样的回报，是沉淀资源还是短期变现，目标清晰再行动。

带着项目进来想找合伙人或投资人，需要满足两个条件之一：能让圈友快速上手获得价值，或者已有标准流程可复制放大。否则难以规模化。

老人很卷，新人怎么冒头？很朴素的路径：写内容、做志愿者、在见面会中提供价值，持续输出会被看见。

招人时机怎么把握？杨涛说确定性高就立刻组建团队，把执行交给别人，自己腾出思考空间。新人阶段不建议招人，会成为额外成本。龙哥提到时薪思维，个体一人做事有大半时间被琐事占据，若月入十万，时薪约两千，请一个时薪一百的助理处理杂务，是用钱买时间。

第七期的三个重点方向：信息源持续升级，把更前沿的机会分享出来；航海体系优化体验、参与连续性和时长灵活性；项目孵化从航海家俱乐部扩展到整个圈子，未来可能每天上百个项目同时落地，更多人能参与。

给零基础新手的三步建议。第一步盘点手上的牌：资金、可支配时间、亲友资源、现成产品、过往专业、技能。第二步建立基本认知：赚钱本质只有流量和产品两件事。第三步别被平台绑架，所有平台都是工具，用来卖货或引流都可以。个人建议从📕起步。

最后关于选择。杨涛说赚钱人的本分不是去追最优项目、最优团队、最优搭档。找最优解成本极高，且当下的你可能承载不住。项目都有优缺点，能打到六十分就先冲。等你配得上时，合适的选择会自然出现。

最后两句话送你。或许做不到因为相信所以看见，但每个人都可以因为看见所以相信。当你真正开始行动时，你会爱上那种向前推进的感觉。
