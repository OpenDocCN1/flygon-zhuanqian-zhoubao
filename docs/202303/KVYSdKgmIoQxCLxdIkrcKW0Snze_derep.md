# 不写代码，也能把 GPT 接口接入业务：一套能提效、能变现的实操参考

内容参考自飞书公开分享。

ChatGPT 是很火，但多数人并没有真正参与进去。想站上这波机会，要么让效率翻倍，要么直接做出可收费的产品。最简单的做法，是把 GPT 接口放到一条自动执行链里。

下面用一套可落地的自动变现案例说明。哪怕你完全不懂编程，也能让自己的业务处理速度快上很多。

为什么不建议从 RPA 或编程学起？因为大多数人的第一道门槛就在这里。GPT 在商业场景中的价值，很大程度体现在“省人省时”；如果不用自动执行，等于砍掉自己的一条腿。

希望这篇分享能打开思路，帮你也实现业务跃迁。

## 适合谁读
- 想用 GPT 接口做自动变现的人
- 想用 GPT 接口降低重复工作的人
- 没有编程基础，但愿意使用拼装工具的人

## 模式速览
整套逻辑其实很简单：自动收集需求，把需求传给 GPT 接口，等结果回来后，用工具自动保存、推送、发布，必要时还能接手机硬件、Webhook、IFTTT。本质上像一个“半定制机器人”。

它不只能做付费问答，也可以用做免费获客、收集整理素材、发布到社交平台，或者在微信群、👸号里扮演自动助理。工具基本不需要花钱。

必须强调：本文展示的是思路，不是唯一方案。普通人最容易上手的是可视化拼装平台，关键要把自己的业务场景和工具结合好。

这次拿“自动付费咨询/问卷初筛”举例：访客提交问卷，内容进入电子数据表；Make 平台调用 GPT 接口产出结果；结果再写回数据表；最后通过邮件或 WhatsApp 送到访客手中。也就是四步：收集、加工、回写、交付。

## 准备清单
1. 支持问卷的产品，例如谷歌 Forms、Notion
2. GPT 接口密钥和机构 ID
3. 一个电子邮箱（Gmail 或 Outlook）
4. 注册一个 Make 平台账号（同类服务还有 IFTTT）

## 实战演示：做一个自动起名工具
假设我们要跑通一个小产品：用户填写起名需求，GPT 返回名字，再自动投递到用户邮箱或 WhatsApp。

### 1. 先做问卷
谷歌 Forms 有个方便之处：用户提交的字段会自动落在绑定的电子数据表里，所以我们只需要把问卷地址公开。

新建问卷，取名为“xxx黄大仙AI起名”。

![](img/86d45d64994b37b7a147313d5ca6c2e4.png)
![](img/0845e5ce2c6e02eee651ab46340dfcbc.png)

用户提交后，数据表会自动生成对应字段。

![](img/e044c58975b050d1aaa88010ad4ac8de.png)

建议设置四个字段：称呼、手机号、邮箱、具体问题。称呼方便后续打招呼；手机号可以接 WhatsApp；邮箱用来收取最终结果；问题栏放一个填写示例，用户更容易上手。

字段配置好以后，在“回复”区域把问卷同步到电子数据表。

![](img/6c95abb1e07087ee3591aaf0c72daf5f.png)

接下来可以把问卷放出去：直接邮件发给用户、公开问卷链接、或把嵌入代码放进网站。

![](img/b5303cabdd247760eda54df892110119.png)

用户打开链接后，看到的就是这样的页面。

![](img/a81e85a9cf054bcd065c93a3862079e0.png)

### 2. 获取接口权限
进入 OpenAI 控制台，登录后点击右上角头像，找到 API keys 入口。

![](img/4371144f02a487880fcba21a9a3ada4b.png)

生成密钥后立即保存，不要等需要时再找。

![](img/d8e65028f23bc7913ba258bae03594e2.png)

再去 Settings 里复制机构 ID。

![](img/45e5385775f27ab9b30c5c5331ad039e.png)

### 3. 在 Make 上搭执行链
Make 是一个可视化的自动连接平台，可以把各种互联网服务拼在一起，操作方式就是拖拽、点击。

![](img/54156890d7fa28a583b2b721f4355081.png)

注册后，免费档位可以建两条执行链。

#### 3.1 新建场景与触发器
Scenario 在这里表示一条完整执行链。点击新建场景，开始搭建。

![](img/1df6b21d1b123784359a3ab8eafc1ac1.png)
![](img/873f40faffd59a4c8ce0395e691cbfac.png)

右侧会出现服务列表，搜索“Google”可以找到所有谷歌相关产品。

![](img/0c28ac648c0c8b1a2b90a64d5e572b4e.png)

选择谷歌 Forms 的“监控新提交”事件。只要有人提交问卷，这条链就会启动。可以把它想象成餐厅接单：客人点餐，店员记录，后厨制作，端上桌，最后结账。

![](img/b3e69a8858288af546a8c55f238f7e21.png)

第一次接入需要授权你的谷歌账号。

![](img/7ca54920a9349c5e371734a20c0b7b74.png)
![](img/b59c2926341a0a86d9bb07dec1c60f53.png)

授权结束，再指定要用的电子数据表和工作表。Limit 控制单轮运行最多处理几条数据。比如每 15 分钟跑一轮，这轮来了 10 条提交，如果 Limit 设成 2，本轮只会处理前 2 条。你可以根据业务量自行调整。

![](img/9233a675ffc8a07b9df761ef98dade8d.png)

#### 3.2 接入 GPT
再加一个节点，把 OpenAI 接进来。

![](img/36f1cc2c6ee5eafb7dc450b7b3b37365.png)
![](img/db81cd8570c9f31bf5b8422bcea49ed6.png)

OpenAI 节点可以做多种事：回答、编辑、合规判断、生成图片。这里选用“执行问答任务”，把访客的问题当作指令传过去。

![](img/5411f5bdd0f596a243287aa0efa7ece9.png)

第一次使用会要求验证，把接口密钥和机构 ID 填好并保存。

![](img/e51a22c757a977a1ad8020de051dfc74.png)

模型可以按需选择，Playground 里也可以提前测试。本示例选的是 davinci-003。

![](img/a01fffdbff5eeb5cf8b4e945e876c856.png)
![](img/0d756cc6b34b907fe355459fb3d7e1bc.png)

Prompt 就是发给模型的指令。如果你在 Playground 里输入访客问题，模型会给出答案；现在把问卷里的“问题”字段变成变量，就能实现批量生成。Max Tokens 控制单次可返回的内容长度，设置太短或留空，回复可能会很短。Temperature 控制创造性，示例填 0.8。

![](img/0d981a1aae7375d885f4f1001505ba5e.png)
![](img/5c090d2792e896026cac3a25a70f805e.png)
![](img/bd0164473b0ea49a743ea28ac43fadf9.png)

这些参数都能在 Playground 页面上对照调整。

![](img/258e754df601a7dd0cbe7709256403ec.png)

#### 3.3 把结果写回数据表
再加一个谷歌电子表节点，将模型生成的文字保存到对应行。

![](img/60f2c4ce4116e6c4cceec65166a555e3.png)
![](img/a293a3be43a45e4567697fe0978a291d.png)
![](img/02eddf87f2be58a176525cc44332b0d5.png)

Row number 这里选变量 Row Number，确保答案落在访客提交的那一行。OpenAI 返回的取值在“Choices - text”中，把它写入“答案”列即可。

![](img/20d6f5095636791557415081f1ee737e.png)

至此，收集、加工、保存已经走通。还差最后一步：把结果交给用户。

#### 3.4 自动投递结果
增加一个 Outlook 邮件节点。首次使用要授权你的邮箱，然后选择“新建并发出邮件”。

![](img/3e7a2ce65ec09de066926511950e6e54.png)

主题按业务填写；正文可以引用用户称呼和 OpenAI 生成的“Choices - text”。

![](img/410052adc91175457bc71a62012275a1.png)

注意：这段内容本身没有排版，直接发出会挤在一起。建议在需要断句的位置加上 HTML 换行标签 `<br>`。下面就是一个没加标签的反例。

![](img/cd13f657f6e14723b029a1fb69c2f214.png)

收件人字段选用用户在问卷中留下的邮箱地址。

![](img/e1c82ade92e06784ed912e5d6803c83f.png)

上述步骤都配好后，从接收问题、调用 GPT、到邮件送达，整条链路已经闭环，全程零代码。WhatsApp 消息的配置思路也一样，这里先不展开。

![](img/4bdc2c26957a2896ce50936217d3fcc1.png)
![](img/e58d6108454d31c8a9c7110563184a50.png)

#### 3.5 运行执行链
Run once 可以让它立刻运行一次。

![](img/922206cf7da7b71263e2a741f80fa70f.png)

也可以设置定时，默认每 15 秒触发一次，时间可以按需改。

![](img/d82c7c357cd53c6aa176bea089f31ca6.png)
