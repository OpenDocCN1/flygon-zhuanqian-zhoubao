# 《从水果店倒闭老板到千万级站外服务商我是怎么做到的？》
作者：龙哥

《从开垮水果店到千万级站外服务商：一个亚马逊老兵的翻身复盘》

大家好，我是海豚出海的合伙人Rick。总有人问我：“你是怎么从一个连水果店都能干倒闭的普通人，一路折腾成千万级站外服务商的？”这篇文章，就把我的真实经历和这几年摸爬滚打总结出的站外推广干货，一次性聊透。

2012年快毕业时，我对未来一无所知，唯一的想法就是先考个雅思。倒也没什么宏大规划，纯粹觉得多个证书，无论出国还是找工作都多块敲门砖。凭着临时背下来的几篇口语范文，我竟然混进了一家外贸公司做业务员。2013年，一个高中同学找我借钱开奶茶店，这句话像根刺一样扎进心里：他成绩一直不如我，怎么一毕业就创业当老板了？而我的职业生涯好像一眼就能望到头。不甘心，就是这两个字，让我第一次动了创业的念头。

![](img/201072f6c87f1f03e641367d06c05680.png)

第一次创业，我选了开水果店。有一次去佛山同学家，路过百果园随手买了几个水果，一结账快两百块。当时脑子里只剩下一个念头：这也太暴利了。于是脑子一热辞职，接了一家店。结果呢？不懂选址、没有经验，十几万转让费砸进去，每个月房租水电近两万，水果损耗又大，现金流很快断裂。我试着转型做企业下午茶，早上六点起床，七点在地铁口发传单，九点半去科技园扫楼，下午骑着电动车一家家送货，晚上六点回店里守到十二点收摊。这样起早贪黑撑了一年，还是没赚到钱，最后只能低价转掉。第一次创业，以惨败收场。

![](img/b871988b23b21f3554ab40469f2d1806.png)

就在这个时候，老东家准备开拓海外市场，觉得我懂技术又懂英语，让我回去担任外贸部销售经理。我又回到了写字楼。但那种“不想平庸过完一辈子”的念头始终没有消失。2016年底，我去美国加州圣迭戈参展，认识了一位当地华人，两人聊得特别投机。他说自己很后悔移民，当初留在国内，发展肯定比现在每月拿四五千美金强得多。回国后我们一直保持联系。2017年初，我开始接触亚马逊，两人一拍即合，辞职合伙干，这便是我的第二次创业。

![](img/55476d92928351415c12c4a17b64cbef.png)

他是美国人，熟悉当地消费习惯，负责选品；我负责运营和供应链的杂事。第一年基本在交学费：开店、进货、上架几个listing，慢慢熟悉平台规则。2018年上半年，我们做了一款LED灯插座盖板，拿货价很便宜，却可以卖到29.99美金，链接上架当天就能出一百多单。可惜只卖了半年，被美国牌子Snappower告了专利侵权，平台直接删链接。2018年下半年，我们又换成ACK户外折叠刀——十几块成本能卖二十多美金，体积小、重量轻，而且是意大利品牌在美国没有专利，所以卖得异常火爆。后来平台开始严查主图，说刀尖太尖，链接被下架。我们就反复重上，开始还能撑一段时间，后来一上架就被抓。

![](img/b0698a74597b4e54a73d59ebed62dd95.png)

就靠这类“短命爆品”，2018年到2019年，我们赚了两百多万。人在赚钱的时候最容易飘。2019年我开始追热门品：背背佳、游戏手柄、卷发棒、热风梳、计数跳绳、拉力带……哪个数据好就做哪个。最典型的是背背佳，第一个月靠测评资源怼了两百多个好评，单量涨得极快，但产品质量不行，评论一路掉到3.5星，两三千条评论也救不回来，光是这一个品就亏了四五十万。后面的热品也都是同一个剧本：跟风、砸资源、亏损。最后压倒骆驼的最后一根稻草，是店铺因为二刷违规被封，申诉不回来，之前赚的钱全数吐了出去。

复盘这次亚马逊失败，我总结出三条血泪教训：第一，不能吃平台红利的老本，早期政策宽松可以打擦边球，平台越来越严之后，认知必须跟着升级；第二，产品为王不是口号，你看到的热销数据别人也看得到，没有产品力优势，最后拼的就是谁能卷；第三，拿货模式没有沉淀，不垂直深耕、不建立供应链壁垒，别人跟卖你的爆款只需要几天，你根本挡不住。

亏到后期，我们连仓储费都付不起。为了清库存，我找过站外服务商，花500块钱发20个群，试了两次几乎没出单。既然花钱效果差，那就自己研究。我的美国合伙人常年混迹Facebook群组和Deal站，我们开始自己去对接群主。Sweet Deals Finder主群有80多万粉丝，一帖只要8美金，加上其他大大小小的群组，我们持续发了两个月，总算把库存清完，回款十几万，挽回了部分损失。（顺便提一句：Sweet主群后来挂了，图片里是现在的副群![](img/40f73368aa518622356687210d433541.png)）

清完库存后，我对亚马逊还抱有执念，但已经没有资金再从头来一次。回去上班？不甘心。这时候转机出现了：有个卖家群在找测评申诉服务商，我当年玩过不少规则边缘的操作，对各种申诉流程熟门熟路，顺手接了下来。只收1000块，帮对方把店铺救回来了。他觉得我靠谱，把我推荐到多个培训机构内部群，客户一下子涌进来，申诉生意越做越顺。

![](img/504f2b0700c9ddb229f67b9830d9633a.png)

但做了一段时间，我心里始终有根刺：申诉本质是赚信息差，是在卖家最危难的时候赚救命钱，这不算我真正想做的事。加上经常有客户问我：“你们做不做站外？”我自己也因为清库存尝过甜头——有些产品站外打折之后，居然还有利润。再看看站内广告费肉眼可见地暴涨，我越来越确定：站外推广才是趋势。于是，我砍掉申诉业务，彻底转型做站外服务商。

刚开始转型，我的想法很朴素：我是卖家出身，如果我是卖家，我一定希望效果付费。就这样坚持了一年，结果是市场教会了我做人：做站外的人越来越多，效果逐渐下滑，利润几乎被摊平，甚至遇到有客户连续推了一个月还不付款。最后，我也只能随大流改成套餐付费。想坚持理想，也得先活下来。

经历讲完了，下面聊点硬的。

站外推广到底是什么？核心绕不开“亚马逊联盟”这四个字。亚马逊本身就是全球最早、最大的联盟营销平台之一：平台搭好交易场，卖家提供产品，博主、群主、内容创作者贡献流量，成交后大家分佣。这三方构成了完整的联盟生态。所以，别再说站外推广没用了——亚马逊自己每年都在花巨额预算从站外买流量。![](img/6137c4c1f2342252855bd7bc99a6a701.png)

早期亚马逊缺流量，给联盟客的返佣非常猛。当时的博主喜欢建群，把亚马逊自营产品分享给粉丝，赚取佣金。后来平台上了社交折扣，卖家开始主动让博主推广，博主的赚钱模式也从单纯佣金，变成了“既拿返佣又收发帖费”。这就是如今站外推广的雏形。

![](img/adfef33faac5fccfea206d41faa46688.png)

为什么要做站外？我总结为三个核心目的。

第一，辅助站内运营。具体有七个用法：新品广告不出单，先用站外折扣激活链接；配合秒杀，秒杀前拉排名，秒杀后延续出单；站外价格低，买家留评概率更大；想冲击上一个排名阶段，用站外补足持续单量；刷单留评怕风险，站外大量低价单可以稀释留评率；有些产品利润厚，站外打折照样赚钱，还能稳定排名；研究互补竞品投放的站外渠道，跟着投，有机会跟BS榜链接绑定FBT。从平台的角度看，你能从外部带新客并成交，平台当然愿意给你的链接加权。

第二，清库存。很多人指望平台Outlet，名额少、选不上、效果不可控，但仓储费一天天在烧；线下收库存压价极低，通常只有一折，还越来越挑剔。相比之下，站外清库存更可控，有些品类甚至能在清理的同时保有利润。唯一要注意的是折扣叠加问题，一个不小心就是额外损失。

第三，做品牌。站内广告费越来越贵，利润空间被严重挤压。早年亚马逊好做，是因为信息差：卖家少、平台缺品类、流量靠联盟客从外面拉进来。如今信息差消失，首页早被评论过万的老品占据，你的新品凭什么进流量池？买家看不见你，产品再好也白搭。品牌才是终极流量池，就像平台上的苹果耳机、耐克，它们从来不依赖平台喂流量。说白了，推广这条路没有尽头，酒香也怕巷子深，没有红利的时候，比的就是耐心。

站外渠道大致分两类：一类是泛流量，靠大折扣冲单量；一类是垂直精准流量，靠粉丝信任做品牌。对应下来，就是流量推广和品牌推广。

先说流量推广。

![](img/2f5d8739ff7dfaa7b143d5a4ff128fa4.png)

FB群组是最高效便捷的入口，发帖快，靠量博概率。群组怎么运转的？早期群主建群卖货分佣金，但单一品类根本养不活团队，于是多个管理员分工协作——有人负责拉粉丝，有人负责发帖，把群做成综合群，什么品类都发，保持活跃度。这也是为什么垂直类目群组极罕见的原因。发展到今天，FB群组的折扣基本40%OFF起步。

FB主页。

![](img/fdda9fdaac21880f5931d296f19bcdb1.png)

有些主页只是群组配套，但也有不少博主专门经营主页，他们会收集粉丝想要的折扣再推荐产品，粉丝粘性比群组强得多。同等粉丝量下，主页效果往往好于群组。这些人才是真正的FB博主，而不是把普通群管理员包装成“红人”的服务商话术。

Deal站。随着FB封号风险增加，很多群主开始自建网站或App做促销发布。这类渠道通常偏向特定类目，如电子、玩具、母婴，受众男女比例也比较均。像Slickdeals、Dealnews、1sale、Techbargains这些老牌站点，流量大、审核严，发帖收费从几十到几百美金不等，适合客单价高或有清货需求的卖家。![](img/a096f071d2c1ec031bb6e2f1065501e8.png)

再说品牌推广。

PR软文是门槛相对低的一种：找新闻网站、行业媒体发新闻通稿或产品评测，在用户信任的场景里安放品牌信息。

KOL网红。

![](img/607c71e318cc04f998223c749d21bed3.png)

海外主流平台主要是Facebook主页、YouTube、Instagram。找网红时最好模拟真实用户搜索场景，去发现那些深耕垂直领域的关键意见领袖。网红的粉丝信任度极高——例如我平常很少买买买，但很喜欢樊登老师，所以总在他的直播间下单。粉丝把一个博主的信任迁移到品牌上，一条优质内容带来的影响能持续几个月甚至更久，这才是品牌的长线资产。

众筹则适合“单品引爆品牌”。Kickstarter和Indiegogo是两条常见路径，先找官方编辑沟通，提交ID设计图、3D结构图等资料，审核通过后上线预售。![](img/425744cab6677810ec10b0aabc315eb2.png)但别指望平台给你免费流量，前期全靠自己导流：一是找垂直网红给早鸟价，让他们把粉丝带去众筹页；二是联系行业杂志或网站发软文；三是混官方社群或第三方社区做推广。众筹成败往往就看第一周导流，第一周起不来，后面基本翻盘无望。真正的网红很在乎粉丝体验，会认真拍摄、真实测评，所以报价偏贵。但他们一条帖子的长期品牌价值远超十次机械转发——当然，如果你只是想冲一波快单量，这条路不合适。

最后回到那个问题：站外推广，找服务商还是自己做？我的态度是：没有绝对答案，但你可以从我的经历里借鉴。最早我花500块找服务商发20个群，效果为零；后来自己一个群一个群聊下来，反而成功清完了库存。不是说服务商都不行，而是这个行业信息水分很大，你必须懂得分辨。预算充足的，多看服务商案例和反馈，问清楚资源明细，别只看报价；有时间的，我建议从FB群组这种低门槛渠道开始，自己先跑通流程，以后再找服务商，你也知道钱该花在哪里，效果好不好。

从一个水果店的倒闭老板，到千万级站外服务商，中间踩过的坑数不胜数。希望这篇文章能给还在跨境电商路上摸索的你一点真实的参考。下次再聊！

学完站外怎么玩之后，很多人都会纠结一个问题：到底是外包给服务商，还是自己操盘？

刚入行的卖家，十有八九会先找服务商。好处是省心，设置好折扣报上去，剩下的就交给对方去跑。

可问题也明显：

1. 数据打码看不清，资源到底发到哪儿了心里没数
2. 出单时间集中爆发，很难配合店铺的整体推广节奏
3. 没有针对性做渠道匹配，产品适合哪个群组、哪个 Deal 站，服务商不一定真的懂

效果不好时，就只能换一家再试一家，试来试去成本只高不低。

有些老手会同时找几家服务商一起投放想拼效果，结果我们实操中发现，多个服务商的资源池重叠率非常高，花了三份钱，见到的还是那一份流量。

这几年在一线服务客户的过程中，因为处得比较熟，经常会帮客户拆解他们在别家投放过的渠道。拆着拆着就会发现重复发帖的情况很普遍。还有不少老客户自己也懂站外，也知道哪些群组质量高，但因为人手和时间有限，联系不上管理员、发不了帖，最后也会找我们帮忙指定渠道。

于是我们开始尝试一种新的协作方式：把客户指定想发的群组，以及我们评测后觉得匹配的群组，都整理成一张清单。客户每天根据预算自己挑着上贴。这个模式对那些深耕站外、懂研究的卖家来说，推广成本直接下来，效果也更可控。我们这边也能更精准地验证不同品类适配的渠道，不用为一两次波动承担太大压力。算是互惠互利。

![](img/9406a0c01023344ad42273c514235fd2.png)

其实我们调研下来发现，大部分卖家内心都更想自己掌控站外。自己找资源、自己发帖，想发就发，不想发就不发，发多少、什么时候发，全部自己说了算，这样才好配合运营节奏。

但自己来做，门槛也不低：

1. 资源需要长期搜集和筛选，耗时耗力
2. 跨时区对接，经常要半夜跟国外管理员沟通
3. 很多优质群组已关闭私信，不再接新人
4. 单个帖子报价偏高，产品线少的卖家摊下来不划算

团队大、品类全的还好，可以慢慢养资源。小团队把大量精力放在这里，投入产出比真的值得吗？

基于卖家想要自主可控的真实需求，加上之前用表格做透明化指定上贴的尝试验证了可行性，我们希望把这套合作思路做大，让更多人能用上。但表格方式太繁琐，客户操作不方便，客服也扛不住沟通量。于是我们把它产品化，做成了网站。

![](img/6d152d49fe029fb7378254b86a01773b.png)

这是我搭建的站外投放平台：

海豚出海
www.haitunchuhai.com

它恰好解决了资源、时间、成本这三大痛点，真正让卖家可以自己做站外。平台上集中了数百个 Facebook 群组和 Deal 站资源，全部透明化展示。每个渠道都标注了受众画像、粉丝规模、适合投放的品类等标签，帮卖家省去自己研究的时间。

想发哪个群组，直接在对应页面下单，几分钟就搞定，第二天看数据反馈即可。再也不用花几个月慢慢积累资源，也不用半夜爬起来跟管理员对线。

而且因为我们是长期稳定合作、帖子量大，单价比卖家自己去谈还要便宜。做站外既省心也省钱，过去只有自建团队才有的能力，现在个人也能做到。

![](img/b23cc6d8fe99b1a6a92eb70568d304c3.png)

1. 平台化运营大幅提升了效率，降低了人力成本，这部分节省直接让利于客户
2. 我们向管理员批量采购帖子套餐，价格被拉到很低，有的 30w 粉丝群组低至￥9.9，投入门槛极低
3. 资源完全透明，卖家可以自主决定发多少、什么时候发，流量可控，能精准配合推广目标
4. 分类标签清晰，选好渠道下单只需几分钟，第二天查反馈就行，时间成本极低

海豚出海的核心就是帮卖家实现省时、省事、省钱。

案例二：不投广告，只做站外
Facebook 群组效果波动大，同样的组今天好明天差。为了保证稳定出单，有些大卖每天会下四五十个组。我们统计过，全上一次约 3000+人民币，约 $400，帖子 3 天内能发完。

这大概相当于一个链接一天广告费的一半，剔除挑品不发的组，上帖率能到 70% 左右。如果产品本身有站外利润，这个打法基本每天能稳定贡献 100+ 单，且站外回评高，一天能回 4-5 条评论。既稳定又能积累口碑。

案例三：新品冷启动
现在亚马逊推新品难，品类饱和、广告贵。平台虽然要收广告费，但也需要单量和评论来维持链接健康度。新品上架初期可以少开广告交个基础量，重点在于稳定获取单量和评论。

站内广告贵，站外就成了性价比很高的补充。有了海豚出海，相当于拥有了一个迷你站外团队：低成本拿单、可控数量、还能索评。
