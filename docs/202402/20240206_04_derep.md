# 傅小闲思维篇 关于赚钱这件小事
作者：龙哥

生病休养的那段日子，加上年底团队同时推进几个新板块，傅小闲在忙碌中抽空写下了一篇关于赚钱的思考。没有高深的理论，更多是亲身踩过坑之后的大白话总结。

上次他分享过📕的一些玩法和数据分析的方法，这次则把目光转向了更底层的思维层面。他聊到，很多人辛辛苦苦忙了一整年，却总感觉离赚钱还差最后一口气，问题可能就出在一些看不见的思维惯性上。

他在文章里梳理了几个特别值得琢磨的点：为什么你总在距离赚钱一步之遥的地方停下来；那些已经被无数人做过的老项目，到底还能不能重新入局；身边的环境和圈子，是如何悄悄改变你的判断和选择的；想要拿到结果，为什么只比同行多走一步就足够；跳出熟悉的行业，反而能帮你绕开最拥挤的竞争区；测试项目该保持怎样的节奏，才不至于错过真正的机会；以及，把大佬从神坛上拉下来，其实才是学习的开始。

除此之外，他还特意讲了公司在搭建SOP流程时常踩的一个误区——流程本身是工具，不是目的，如果为了规范而规范，反而会拖住团队的脚步。

这些内容他没有在帖子里完全展开，而是把整份思考放进了飞书文档。如果你也在为“赚钱这件小事”感到困惑，不妨直接点开看看，也许某个角度就能帮你打开一扇新门。
