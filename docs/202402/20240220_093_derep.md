# 风向标拆解第3期 | 📕上，手作饰品为什么能卖爆？

原文：[`www.yuque.com/for_lazy/thfiu8/zw9khbnsu2bvwwnk`](https://www.yuque.com/for_lazy/thfiu8/zw9khbnsu2bvwwnk)

作者：加加
日期：2024-02-05

最近把📕上的手作饰品板块翻了个遍，整体的玩法大致分两大路数。

一类是强调「手工在场感」，博主自己上手制作，直播间里现场串珠、编织，做完就戴上展示效果，过程即内容，转化也直接。

另一类则是走心灵加持路线，核心卖点是寺庙开光，用文化和信仰背书来提升信任感和溢价。

在这些品类里，我注意到了一个很细分的爆款赛道：宝宝别针。

它同样归在手作饰品里，却切中了非常精准的刚需人群。主要是孕期女性自用，或是亲友赠送，核心诉求就是祈愿孩子平安顺遂。

因为材质、做工的差异，这个品类的客单价区间在290元到1000元以上不等。单看数据，已经有款式累计销量逼近一万件。

把「宝宝别针」这份礼物属性，和「寺庙开光」的增值服务叠加在一起，故事感一下子就立起来了。既有情感价值，又有仪式感加持，价格带自然就能拉高。
