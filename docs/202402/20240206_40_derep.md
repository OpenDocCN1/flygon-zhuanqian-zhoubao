# 为什么我笃定，2024年图文类副业，微头条能跻身前三

大家先认识一下，我是徐言随谈。

在今日头条做微头条的内容方法论是我主推的板块，目前全网销量第一，累计流水过五十万。账号矩阵上，心理情感垂类排到头条前三，带货月单破万，佣金十五万。👸号做流量主一年也能稳定在五十万左右收入。过去这几年我带的人已经过万，真正帮助他们把自媒体做成了副业。

我开过微头条写作营、头条引流营、头条带货营，也做过📕和👸号的训练体系，现在的重心都放在国内外自媒体的最新风口挖掘上。

过去半年，我几乎把全部测试精力都放在了微头条的商业化变现上。

结果很明确：平台的图文激励正在加速上涨。去年这个时候，一千次阅读的收益大概在三毛上下，最近我带的一个学员就诞生了篇爆款，单价已经接近四块钱，这个水平基本和👸号的分成了。单价翻了十几倍，这就是风口来临前的信号。

基于这个趋势，我的判断是，2024年的图文赛道里，微头条绝对能冲进前三名。
