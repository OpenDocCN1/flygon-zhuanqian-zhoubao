# 教室里真的能用上 GPT 吗？我访谈了三位一线教师，给你一份真实提效笔记

大家好，我是胖虎。

过去我做的是 ChatGPT+自媒体这条线，最近把航行的主题调整成了 ChatGPT 提效，视角也随之发生了变化。

对大多数普通人来说，用好 GPT 并不是堆砌花哨功能，而是要先搞清楚它能做什么、该怎么用、怎么把它养成一种工作习惯，再真正落到日常的场景里。

我本科读的是师范，现在也还在教育行业里，身边认识的老师不少。最近一段时间，我一对一聊了三位在一线带课的老师，听他们吐槽日常工作痛点，记录下来需求，再用 ChatGPT 的能力去试着解决。

这些都是发生在真实课堂和备课场景里的案例，不是理论推演。结合老师的具体诉求和 GPT 的实际可用边界，我梳理出了可直接复用的提效做法。
