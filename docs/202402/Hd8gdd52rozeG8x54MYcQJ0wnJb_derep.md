# ('风向标拆解第3期-视频号高销量的知识付费怎么玩？-薄荷Heidi', (2, 34))

最近我一直在拆解视频号里那些卖爆了的课程，发现一个很明显的趋势：知识付费正在被视频号悄悄推上风口，尤其是教培类内容，价格不低，销量却很惊人。

拿“白瑞的亲子教育”这个账号举例，数据相当能打：一门“沟通情商课”定价399元，卖出1.6万单；一套“10大关键育子能力”定价299元，销量1.1万单；还有“培养优秀男孩/女孩”系列，以及“菁英男孩/女孩66堂课”，定价在298到598元之间，销量从几千到八千多不等。一个有意思的细节是：男孩家长的购买力明显更强。

很多人以为“选育儿赛道”就是选题，其实不是。选题不是选领域，而是选“你在这个领域里，解决了谁的什么问题”。白瑞的定位很清楚：专注亲子教育，专治家长养娃的焦虑。

课程详情页也别糊弄。漂亮、有质感的页面真的能提高转化率，毕竟“颜值即正义”在卖课这件事上同样成立。而标题更是决定用户点不点进来的关键。比如“能成事儿的表达课”，就比干巴巴的“职场沟通课”有欲望得多。白瑞那门“10大关键育子能力”，副标题里塞满了“系统课程”“实操解决方案”“科学育子方法论”，让人立刻想知道:到底怎么帮我？

怎么判断需求是不是真的？两个笨但好用的方法：第一，去看学浪、荔枝微课、千聊、腾讯课堂上同类课程的销量。如果没人卖或者卖不动，可能是蓝海，也可能是没需求。没会员工具就先等等，等做起来再投资。第二，去翻评论区。用户自己吐槽的痛点，才是最值钱的需求。比如“带孩子看医生，一刻都坐不住，到处乱摸”“孩子情绪稳定但是学渣怎么办”“女孩沉迷游戏怎么破”——这些全是课程大纲的灵感来源。

课程大纲决定了用户买不买。怎么挖出他们真正想要的东西？先把标题量列三倍，去微信群里做调查；再用百度指数、微信指数、巨量算数这些工具，逐词对比，看看哪些关键词搜索热度更高，用数据代替感觉。

好内容是被好问题逼出来的。直播连麦就是最划算的调研。白瑞把男孩养育的痛点拆得很细:性格养成、男女差异、翩翩公子养成、潜能开发、幸福修炼、父母必修课。适用人群也故意划得很大：0到22岁的父母、对男孩未来绝望的家长、盼孙成龙的祖父母、教育从业者……几乎把能收割的角色全包了。标题更是句句戳心：“儿子四五岁不敢一个人睡，正常吗？”“男孩到了大学还要不要管？”“单亲妈妈怎么培养男孩？”——每个都想点进去看。

卖课直播间的玩法也有门道。内容不用多，15分钟反复讲就行，反正直播间停留时间不超过3分钟，老粉早买过了，不用管，系统会不断推新人进来。用福袋和资料把人留住，抓住贪小便宜的心理。人少就继续讲干货，人一多就开始憋单：限时优惠、马上卖完，制造紧张感，让用户“脑子一热”就下单。直播连麦咨询更是绝活——先戳中家长的焦虑和愧疚，再共情，最后给出买课解决方案。那位哈尔滨大姐不用套路，光靠情绪感染力就让直播间的父母觉得“日子还能更好”，这其实就是情绪价值。

课后还有“报喜连麦”环节，无论真假，声泪俱下的感谢直接变成活生生的买家秀现场，比什么广告都好使。

卖课的平台怎么选？免费好入驻的，用千聊、荔枝微课，实名就能开，但平台不给你流量。想要平台流量就去学浪，但对资质要求高。小鹅通功能全、不收佣金，能上传课程还能做训练营，就是贵，年费最低六千起，白瑞用的就是它，方便反复回看。CCTALK、喜马拉雅入驻简单，但更适合艺术类和成人课程，其中喜马拉雅以音频为主。

课程产品一般分三层：流量型课程负责暴露专业、拉曝光，价格几十到几百；利润型课程给想升级的用户递梯子；高净值课程则是一对一的贵价交付。白瑞线上课集中在299到598，线下小班见面课一千以上，三个层级都占住了。

变现也不止挂链接这一条路。小鹅通适合私域视频课；知识星球做付费社群；小报童适合图文，手续费15%；元空间适合视频音频变现，手续费8%。后续还能做咨询、社群、干货图文，多元开花。

给想入场的老师几条实在建议：第一，选一个你真心喜欢的领域，不喜欢你撑不下去。流量差也没关系，至少是你想说的。第二，学会对标账号。别抄头部，也别抄两年前起号的，要找同赛道3到6个月起来的、粉丝不超过20万的新号，研究粉丝画像，内容形式可以跨赛道移植——有人在车上讲减肥能火，你就能在车上讲财经。记得给对标账号点赞互动，养号让算法推更多同类好号给你。第三，学完赶紧做个轻量产品扔到市场里验证，别等完美，先有再有优化，离钱越近越好。第四，逼自己干以前不敢干的事：图文转直播，室内转室外，不断复盘。第五，卖课话术要踩准五个点：他是谁？他怎么了？会怎样？怎么办？为什么找你？这些都要理直气壮地说出来，你的资历和成绩该秀就秀。

最后聊点扎心的话：知识其实不值钱，值钱的是套路。人性就是贪、懒、怕、嫉妒、恐惧。用户不爱吃蒸土豆，你就给他做成炸薯条；不喜欢听历史，你就给他讲奥本海默的情感八卦。知识付费的核心不是知识量，是信息密度——浓缩、痛点密集、故事刺激，让他一秒钟有三个爽点，他才看得下去。还有，别老想着先做产品再做流量，最难的不是生产，是卖；最值钱的不是内容，是注意力。把内容做得足够有话题，吸引足够多的人，平台才愿意给你推流，有了流量，你卖什么都行。
