# 靠流量变现思维 4 年做到月营业额 200w+的心得

**四年做到月入200万，这位95后把他的流量变现“道”讲透了**

最近看到一位山东的95后短视频创业者，分享了自己从大学毕业到月营业额突破200万的经历，个人觉得挺有启发。他叫子凡，刚好赶上短视频红利，一做就是四年。

他在龙哥盟待了一年，前几天刚跑完行舟老师的抖音老板IP航海，回来后结合自己这些年的实操，整理了一份笔记。他说，这份内容主要是给那些准备入局抖音、但还没什么方向的朋友看的。

聊到框架时，他用了“道法术器”的体系。不过这次分享的重点，是“IP流量变现”中的“道”，也就是从0到1阶段，你需要搞清楚的那些认知问题。换句话说，基本把所有常见的坑和底层逻辑都覆盖了一遍。

那哪些人适合看？他觉得主要有两类：
一类是刚接触抖音的小白，可以从头搭建一套完整的认知框架，避免自己乱摸索走弯路；
另一类则是已经做了抖音的老板，如果一直停留在研究技巧、抠细节的层面，却始终炸不出大动静，那这篇内容或许能帮你跳出“术”的局限。
