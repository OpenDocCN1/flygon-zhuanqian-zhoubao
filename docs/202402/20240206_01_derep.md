# 【赚钱心态】4 篇

搞钱之前，先把“心态”这块地基打好

你有没有过这种体验：方法学了一大堆，工具也囤了不少，可一到真正要下手的时候，心里就是莫名发虚？或者越是急着赚钱，越容易浮躁、焦虑，最后反而什么都没做成。


这4篇内容，比起手把手教你操作，更像是在帮你清理大脑里的隐形阻碍——比如对金钱的恐惧、对失败的预设、对机会的判断偏差。很多赚不到钱的人，不是能力不够，而是心态上先败了。

这份内容源自一个语雀文档，原链接我直接放在下面，方便你一键跳转。如果你正处于副业起步、项目转型，或者长期努力却始终没看到回报的阶段，那这4篇非常值得静下心反复读几遍。想搞钱，先修心；心顺了，路就顺了。
