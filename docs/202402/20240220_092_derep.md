# 风向标拆解 | 花艺绿植类账号，年后这波是不是又能起来了
作者：龙哥

大家好，我是龙哥。今天这期风向标拆解，跟大家聊聊一个很有意思的方向：花艺、绿植赛道，过完年是不是又到了可以冲一波的时间点。

先说结论。生活品质在升级，大家对生活美学的追求也在变强，花艺和绿植的刚需和情绪价值都在同步提升。特别是碰到情人节、母亲节、春节这样的重要节点，市场对花艺产品的爆发式需求是很明显的，年后正是布局和承接这波热度的窗口期。

我也是第一次做这种类型的项目拆解，思路上肯定还有很多粗糙的地方，欢迎大家在评论区多指点、一起交流优化。
