# 视频号涨粉慢？别急着学套路，方向选对才是关键

做视频号的人，最头疼的往往只有两件事：不知道往哪个方向发力，不知道怎么让粉丝涨起来。其实大多数人涨粉慢，真不是不够拼，问题多半出在方向没选好，再加上一些信息差还没被大多数人发现。

我是龙哥，平时就爱研究各类副业项目。今天这篇，是把我亲测的一套实战打法送给你，围绕“视频号创作者分成计划”，从挑方向到吸粉，全程拆解到位，看完就能去试。

有人问我为什么突然写这个？因为我去年11月和今年1月，连续带了两期“视频号创作者分成计划”航海。带圈友的过程中，发现大家最普遍的问题，就是不会挑方向、不懂涨粉的套路。偏偏计划配套的手册，这块讲得又不详细。于是我就抽空把经验整合了一下，写成了一份尽量完整的操作攻略。

这份攻略能帮你解决什么？主要有两块：
第一，突破选方向的瓶颈。我把去年我们实际跑过并拿到结果的几个方向都列了出来，包括它们是怎么被我们看中的、收益情况如何、变现方式有哪些。你顺着这些案例去发散，自然能打开自己的思路。
第二，找到“自带涨粉属性”的方向。我举的例子都是真实跑出来的，方向选对了，一天涨100个粉只是起步，几天涨几千、甚至几万都很正常。

说白了，涨粉快真没什么高深技巧。就是“方向选得比别人好”+“信息差拿捏得比人早”，这两条凑齐，结果想慢都难。

另外，有圈友跟我吐槽：“涨粉不难，难的是开通创作者计划。”我也把快速通过计划的方法一并写进了这份攻略里，帮你把最后一关也趟过去。
