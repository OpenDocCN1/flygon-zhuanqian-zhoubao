# 风向标拆解第 3 期｜Sukie：📕爆款手作饰品，到底藏着什么运营秘密？
作者：龙哥

> 原文链接见文末

Hi，我是 龙哥，主业传媒运营，副业📕成长博主。

最近，雍和宫手串、灵隐寺手串、深圳水贝珠宝市场这些话题接连出圈，让手作饰品这个赛道一下子涌进了大量目光。但真正让人好奇的是：这些看起来差不多的手串、项链，凭什么有的能卖出爆款？它们的运营思路有什么不一样？盯准的是哪一类人群？利润空间又能做到多大？

因为是第一次做拆解，我没有给自己设太多条条框框，完全从感兴趣的角度出发，把手作饰品分成了玄学手串、文玩手串、星座手链、串珠手链和其他类型五大板块，并且重点拆了三个有代表性的手作账号。

需要提前说明的是，这次拆解主要基于我个人的理解和一些浅层市场观察，尤其是利润测算部分，肯定有不少偏差。欢迎有经验的朋友指正交流，咱们一起探讨。
