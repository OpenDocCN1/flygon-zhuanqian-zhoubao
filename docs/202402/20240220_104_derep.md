# 风向标追踪·第3期 | 13万粉丝卖出78.6万单，小红书这家店如何做到？

这一期拆解的主角，是一家小红书店铺：粉丝量只有13万，累计销量却达到78.6万单；粗略一算，成交额已经超过3000万。
