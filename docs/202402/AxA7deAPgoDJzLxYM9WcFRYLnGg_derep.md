# 一个人、一部手机、每周三条视频，我在销售这个红海里做到年净赚30万的底层逻辑
作者：龙哥

> 这篇内容写给还在焦虑的职场人看。当你总觉得大佬们手握几十万粉、月入七位数，自己被卷得看不见出路时，或许问题不在赛道，而在打法。

一年前我也一样，刷到那些矩阵号、超级IP，每天都在感叹钱难赚了，心里也犯嘀咕：我的赛道这么卷，还有机会吗？

老师梁靠谱说过一句我一直记着的狠话：每个行业的天花板至少都是几个亿，我们只要吃到其中几百万的份额，就完全不用去讨论卷不卷了。

我就是赚钱里那个不起眼的销冠。用梁靠谱和理白来形容，就是凤雏级别的存在。论影响力、证言、粉丝，我跟他们比就是蚂蚁和大象。更别说那些平台大V，一个月粉就比我一年涨的多。

但就是在没粉丝、没私域、一年加🛰️不到五百人的情况下，我到手的年利润是30万，扣完CPS是实打实落袋的。很多GMV上千万的团队，年利润能分到几百万都算不错，还要分给一堆人。

我没有矩阵，不直播带课，也没有所谓的爆款人设。就是一个账号、一个人，每周发2-3条视频，就把这笔收入做稳定了。

现在把我踩过的坑和走通的路拆给你。

**先说结论，省流版：**



第二，有头部同行，别躲，反而要贴上去，做好他做不了、没空做的事。

我教的是销售，年卡要一万多。靠谱大佬的销冠群终身才5999，我照样能把他的销冠群成员成交过来，而且还给他分CPS。为什么？因为我能做谈单前的颗粒度服务，客户A/B/C怎么谈，我提前帮你梳理清楚。一对一的细活，大咖没精力交付，我们就能捡漏。

第三，传统卷行业从0到1，别求大而全，先从一个小缺口钻进去，有成绩了再提炼优势放大。

我一个纯小白，就是从银行理财经理这个细分切进去的，后来有了“忻妈”这个名号，大家都知道我会做大单、会搞高净值客户。第一个10倍回报的赚钱门票，就是这么一点点写帖子攒出来的。

比起在群里喊牛逼，迅速拿到一个可验证的结果，更有存在感。

# 第一部分：我是怎么给自己定位的

开始做IP纯粹是因为我三无：没天赋、没产品、没时间。

赚钱很多玩法我看不懂，直播带货我也玩不转，主业年薪几十万，不可能all in。最大的困惑是：想赚钱，该怎么赚？

后来想通一件事：教人赚钱的钱最好赚。带货不适合我，那就卖思维。

决定用销售教练这个身份上场时，外面都在说知识付费不行了。但我看到的事实是，头部销售博主，一门几百块的课能卖上万份，这还是没上得到。

于是我开始野蛮试错。第一阶段定位太泛：泛销售技能提升。面试是销售、恋爱是销售、跟孩子谈判也是销售。结果直接扑街。大赛道的新人想冒头，全靠运气。关键是你得先从某个点“冒出来”。

后来我转向垂类深耕：只教银行理财经理卖货。

这个赛道也有博主，但做过理财经理、业绩过硬，和只会培训的人不一样。就好比奥运冠军当教练，效果自然不同。定位一垂直，涨粉就开始了。虽然私域引流不多，但成交率能到50%。


所以社群里的我换了一层定位：教人卖大单、教人谈高净值客户。销售教练很多，专做有钱人的少，这个差异化就让我脱颖而出。

总结一句话：赛道用户面广，就在公域先做垂类起家，在社群里适当放大、更有记忆点。

# 第二部分：我的客户到底从哪来

2022年我🛰️有一千多人，60%是我授课的学员。因为认可我，课后加我方便咨询。但他们不能是我的客户。工作原因，我的个人IP卖课和咨询，必须屏蔽他们，不能收费。

这就产生一个灵魂拷问：我的客户在哪？答案是公域。

别指望社群是第一客户来源。职场IP和副业IP的核心诉求完全不同。副业群里分销一个玩法就能赚钱，因为大家在一个池子里换资源。赚钱就是典型。但职场IP解决的是职业问题，副业群里一大半人不上班，你教做PPT、写汇报，对他们没意义。

我一开始就踩坑了。万元社群里人都有付费能力，我的人设口碑也不差，但还没到无脑打钱的地步。当时推的《5步学会电话约访》课程，还有每月可提10个问题的知识星球，都卖得一般。

不是圈子不行，是节奏不匹配。


记住，社群是主理人的私域，不是你的。

另外，卖自己的话，朋友圈的产品可见度至少要30%。很多人不好意思发广告，但没人会翻你每条朋友圈。不展示，没人知道你能解决什么。

在社群里要做的不是反复推销，而是保持存在感，多发干货、活跃氛围。等他主动沉淀到你的私域，了解你的产品，才是真正的准客户。

# 第三部分：我卖的产品就三类

到现在产品体系很简单，归纳起来就是三类：知识星球、公开课、私教。

第一类是轻交付的答疑型。完全在我的射程内，学员提问我回答，不需要准备。这种可以定价很低，作为引流。我星球从149涨到365，远低于我个人咨询的价格。

第二类是共性问题的SOP化解决，也就是课程。能解决60-70%人的共性问题，前期梳理辛苦，做出来就能复用，基本一劳永逸。课程和星球组合，还能抬客单价。

工作量上我算得很细：三位数到一两千的训练营+答疑，平均每个学员每天消耗我不超过5分钟。一期三周收100人，人均500块，一个月净赚三四万，扣掉CPS和助理成本也划算。这类交付时间投入高不值当。

第三类是小范围深度交付，也就是私教和小VIP群。收费大几千到上万。重交付的核心是解决个性化、高价值问题。

SOP能解决的都是常见卡点。私教解决的是疑难杂症。比如身价几个亿的企业主想问家庭传承、资产隔离这种隐私且复杂的财富配置方案，这种交付才值大钱。

# 第四部分：我的引流和成交SOP

大多数人引流靠免费资料，我试了两个月就不用了。流量增长慢点，但质量高。我要的是高客单价人群，不是话术党。

银行理财资料引流确实多，但要资料的人和真心想提升销售业绩的人重合度很低。90%会耗费大量时间无效沟通。花几块几十块买话术的人，诉求是拿话术搞定客户，不是学销售逻辑。

所以我用一个3-5分钟的筛选话术，筛出认可我思路的人。

第一步打招呼+引导：先自我介绍，金融销售培训15年+，主要服务理财经理和保险客户经理，帮助业绩提升30%以上，人均做到100万期交。问他卡在哪：约不到客户、客户考虑不成交、单子做不大。

第二步测信任度：谢谢信任，问他是喜欢主动学习的人，还是需要被推着走的人。

第三步需求匹配：给你三条路，私教陪跑季度/半年/年，帮你梳理客户和沟通方案；知识星球一年提问权限+文章更新；《三步学会一面签单》《5招电话约访》《ChatGPT赋能大额保单》等课程。让你选。

这个SOP避免了我变成免费答疑工具。很多粉丝会让你先介绍课程，你说完他回一句“再考虑一下”。这是典型的买家系统，我的《三步学会一面签单》里拆解得很透。

# 第五部分：我怎么把每天工作控制在1小时内

刚开始做私教，我每周要通一小时电话，问十万个为什么，很累。副业的初衷是轻松赚外快，不是第二份卷。

我给自己定了规矩：每天额外工作不超过两小时。

在服务20个私教时，我开始优化。个性化辅导占比不能超过50%，共性问题全部沉淀成星球文章或小群分享，用30%的时间解决统一能拆解的问题。

交付学员不做情绪垃圾桶。开场就立规矩：可以聊执行困惑，不能把没行动的emo甩给我。私教是带结果，不是心理咨询。一小时心理咨询两三千，我的私教一年才万把块。

后期我用带销售团队的思路来管理私教：
先分层，基础好领悟力强的当标杆；
再设阶段作业，量化数据看差距；
然后定期复盘团队共性问题；
最后放弃“圣母心”，带不动的放手，偶尔看一眼别丢了就行。

大师兄杨涛说过，副业没达到主业5倍收入且影响主业，不如留一份保底工作。我现在主业保住，副业和主业高度相关，心态、产品、预期都清晰很多。

第三年混赚钱，我不再羡慕月入七位数的人。赚钱和有钱是两回事，我要的是后者。节奏比速度更重要。

一起赚钱，是生长的生，是生机的生，是生活的生。
