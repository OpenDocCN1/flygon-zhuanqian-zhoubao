# 与1688 CEO面对面：新的一年，他决定押注这四个方向
作者：龙哥

最近刷到一篇关于1688 CEO的独家对话，信息量不小。很多人还在观望，但掌舵人已经把未来几年的牌面亮了出来——今年集中精力干四件事。

重点是什么？他直言，平替类生意还有大约三到五年的红利期，跨境板块同样会迎来一波三到五年的好行情。换句话说，这两个赛道的窗口期，正好重叠在这一轮机会里。

对于想做点事的人来说，这句话值得反复琢磨。与其这山望着那山高，不如在窗口期扎进去。当然，细节和拆解都在原访谈里。

如果你也在纠结“平替到底指什么”“跨境怎么切入”，评论区有人问了同样的问题，回答也很直接：去看原文，答案都在里面。
