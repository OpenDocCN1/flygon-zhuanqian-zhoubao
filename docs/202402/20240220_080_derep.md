# 懒得记帐？有人靠一个 iPhone 捷径轻松卖了 12 万

你可能想不到，光是“偷懒”这件事，也能变成一门赚钱的生意。

这个拆解主要从四个角度来展开：

1. 流量是怎么打通的？
2. 产品解决了什么痛点？
3. 利润空间怎么算？
4. 项目怎么起步、怎么放大？
