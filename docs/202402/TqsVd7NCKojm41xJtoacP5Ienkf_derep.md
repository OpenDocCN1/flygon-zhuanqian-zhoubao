# 零露脸零拍摄，靠 ChatGPT+Canva 可画 10分钟就能搞定100条短视频
作者：龙哥



最近刷到一波配风景的金句视频，感觉效果很不错，就去 YouTube 上找了下制作思路，还真有现成的玩法。工具组合很简单，就是 ChatGPT 3.5 搭配 Canva 可画，记得提前做好网络环境。

# 先把100条金句一次性写出来

金句部分交给 ChatGPT 来负责，常见方向是爱情、失恋、友情这类情绪话题。先喂一个写作框架让它学会套路。

语录模板一：

请按照我下面教的方法来创作语录。

每条语录由两段构成。第一段负责勾起好奇心、引发思考，第二段负责点题、给出落脚。

参考示范：

例一：第一部分：如果你真的喜欢一个人…

第二部分：...你就得学会放手

例二：第一部分：真正的友情就像一朵花...

第二部分：..它会越长越旺，永远不凋谢。

如果你理解了，就回复

![](img/399b38e64fa31030363f5c8b01a44efa.png)

![](img/1623bd9576c33e0be2596c3cae741042.png)

模型很快学会了格式并给出示例，可以开始实战。目标主题定为“友谊”，受众锁定在20-30岁的群体，看看效果如何？

![](img/6e8c203e03d5eac73c0d7d277e55929f.png)

ChatGPT 的理解度超出预期，生成质量很在线。

为了后续批量操作，最好把结果放到表格里管理。于是再给一个整理指令。

语录模板二：

请把这些语录整理成 Excel 表格，按以下字段分列：

主题（友谊），第一部分（填写语录的第一段），第二部分（填写语录的第二段）

![](img/2c4e782b960d9e9a45e54c9ca24f5f67.png)

整理成表格完成，Verey Good.

由于 ChatGPT 3.5 单次输出有字数限制，避免超时卡顿，这次只让它先产出20条。

![](img/01b4cd2e8302a3544c64d9ceb9412cbe.png)

20条产出后，继续追加生成。

![](img/9beae505a090f8344a8cdd10e499d607.png)

反复追加，直到主动询问是否已达100条。没满的话它会自动补齐，直到凑够100条。

![](img/f258460acf72d944da7b5623dba963d2.png)

100条金句全部搞定，一键复制到 Excel 备用。

# 用同一套模板批量做100条短视频

## 先搭一个可复用的视频模板

打开 Canva 可画登录账号，进入首页 > 视频 > 手机视频 9:16，建一个空白画布。

![](img/e1dfc68d97417e6c8fa758929b435005.png)

在素材库里搜“大自然”，筛选视频类素材，右键设为背景。

![](img/27c6acb98a76c301d517cb1a56f964a4.png)

背景视频就位后，新增文字。文字 > 添加文本框，自行调整字体、字号、特效等风格。

![](img/5bf06be9519b064e738aaefac5b836d1.png)

整条视频时长控制在20秒左右，但两段金句用不到这么久，拖动视频左边缘把时长压缩到10-15秒。

![](img/b46039b7f4d90823a87d80799589d81a.png)

接下来设定第一段文字出现时长，右键点击文字选择显示时长。

![](img/5abf2df5a95df3850746491d596941d4.png)

可以看到第一段文字的展示时长大约是8.6秒。

![](img/5d36c5481c0878d9157832bd2a5ac438.png)

第一段时间确定后，把第二段文字往上叠放到第一段上方，并把起始点拖到第9秒。这样第一段结束会停顿0.4秒，再自然切出第二段。

![](img/386393c7717dca3ac556c24c22f638b6.png)

到这里，短视频的通用模板就算是做好了！！！

## 启动批量生产

模板完成后，点击上方 应用 > 批量创建。

![](img/f2fe355b185c671c310768b5ab5ecc2e.png)

数据源可以手动录入，也可以把 Excel 里的语录导出成 CSV 直接上传。总共100条左右，这里为了演示直接手工粘贴。

![](img/c37c6408e14031c565e8d54a68b0f8b5.png)

然后右键进行数据关联，把“友谊”关联到主题字段，其他字段依次对应。

![](img/2678be9b814828fea61a160faf26b2e8.png)

点继续后，可以看到关联数据列表，一共119条，意味着将批量生成119条视频。

![](img/4bdd83b558c00db044f5b297fca9649a.png)

最后进入导出环节，注意一定要选择把页面下载为独立文件。演示这里一次性生成上百条，实际使用时建议一个模板先生成10条，100条视频分10个模板轮换发布，内容更有层次感。

![](img/2f062efff01e63e00af80789f16b8403.png)
