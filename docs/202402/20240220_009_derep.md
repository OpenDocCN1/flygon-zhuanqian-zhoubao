# 悄悄花了3万块，这个二孩宝妈闷声搞副业5年，现在工资翻倍了
作者：龙哥

前几天刷到一个挺触动我的分享。

一位在职设计师，同时也是两个孩子的妈妈，年纪不算小了，在职场里也摸爬滚打了许多年。她用五年时间偷偷折腾副业，没敢告诉老公，前前后后投了差不多三万块，如今总算把主业薪水翻了一倍，也终于找到了自己真正喜欢且擅长的赛道。

她说自己成绩其实一般，跟圈子里那些月入十万的大神比，压根排不上号。但她还是想出来讲讲，因为她在社群里泡久了，发现太多新人跟她当初一样：迷茫、焦虑、不知道从哪里下手。哪怕她的经历只能帮到一两个人，也值了。

她给了两条特别实在的建议：

第一，先干起来再说。别管项目最后能不能跑通，哪怕只从0走到0.1，你也会知道自己卡在哪一步。不去做的话，连发现问题在哪的资格都没有。

第二，试过一圈之后，挑一个自己做得最不烦、最有感觉的方向深耕。能让你坚持的，永远是那个不讨厌的事。

全文写得挺长，但很多人说看完很受触动。评论区里不少人也提到，那种想往上冲却被家人泼冷水的心情，真的只有经历过才懂。还有人感叹，字里行间都是那股不服输的劲儿。

不管怎么说，迈出第一步，就已经赢过昨天的自己了。

细节和完整内容，她放在了飞书文档里，感兴趣的朋友可以自己去看看。
