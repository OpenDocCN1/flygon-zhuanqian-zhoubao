# 别让别人的尺子，量出了你的人生
作者：龙哥

真正绊住普通人的，从来不是天花板，而是那把被众人沿用的统一尺子。

与其耗费心神去迎合既定的评判维度，不如把时间用到挖掘自身的长板上，找到那份只属于你的价值感。等你真正杀出一条自己的路，站到新的赛道上回头再看，会发现那些曾被奉为圭臬的标准，不过是路边一缕掠过的浮云。

想被看见，就做稀缺品，别去排队做流水线上的零件。艺术品之所以珍贵，是因为无可复制；标准件之所以廉价，是因为处处都有。

![](img/21de372a77ea1f441c613f7316831ae1.png)

这句话放在创业上，意味更重。创业者最硬的底牌，不是资源多、运气好，而是在环境嘈杂、局面艰难时，仍能穿透表象看清本质，并敢于做出那个正确的选择。
