# 2023 年，小众心理行业知识付费赛道实现营收百万，我的复盘总结
作者：龙哥

2023年，我终于跨过了百万营收的门槛。很多人问我做对了什么，其实外在数字的突破，背后是内在认知的全面升级，以及一个个旧卡点的打通。

我是龙哥，一名优势教练。2019年开始全职扎根小众的心理教育赛道，一路没有大厂背景，也没有商业导师带路，全靠自己摸索。所以这篇复盘，我特别想写给那些和我一样起点普通、渴望靠内容创业突围的朋友。

这一年，上半年和下半年完全是两个色调。上半年我生活在灰色里，看着圈子里很多人做得比我好，哪怕自己营收其实不差，心底里依然没法真正认可自己。6月跌到谷底，自我否定到夜不能寐。也许是触底反弹，我决定先取悦自己：开始运动、约老朋友见面、线下拜访了几家厉害的公司。状态慢慢回来了，日子也重新有了彩色。

真正的转折，是下半年推出了两个高客单价产品。靠着之前的经验积累和私域沉淀，月营收一下子翻了四五倍。这里也要特别感谢龙哥盟开出的个人优势挖掘大航海，让盖洛普被更多圈友认识，也让我获得了更多信任。

支撑我卖出高客单价产品的，是这八个方向的认知成长。

**一、团队管理：从盯事到盯人**

以前我眼里全是事，总觉得活干不完，哪怕有助理，思维也停留在执行层。后来我慢慢懂了：管理者的重心不是自己做完多少事，而是找到合适的人，激发他们把事做好。

想清楚盈利模式和业务流程同样重要。以前我只分任务，不设标准，伙伴做着做着就容易没有动力。现在我愿意把业务规划和目标同步给他们，明确告诉他们我期待什么、不欣赏什么。当大家有了目标感和标准，执行力反而不用催了。

优秀的人加入，真的能让1+1>2。2023年团队来了两位很出色的伙伴，一位热情又有亲和力，客户对她的朋友圈赞不绝口；另一位擅长战略和执行，帮我顶起了一大块业务。她们不仅解放了我，也让营收有了质的飞跃。2024年我会继续提升人才密度，希望团队高手如云，成为盖洛普领域顶级品牌。

**二、战略思考：想不清楚就别瞎卷**

以前我也尝试每天更新朋友圈、做📕，看起来很努力，其实都是局部战术，不会有突破。因为在战略没想明白之前，所有努力都可能是在浪费。

战略听起来抽象，说白了就是你想用什么计划实现目标。它决定了你每天的动作，也决定了精力的优先级。是服务少数高客单人群靠口碑裂变，还是走流量营销路线，又或者养团队支撑产品体系？每种选择，获客思路、产品组合、投入重点都完全不同。

战略的本质是放弃局部利益，跟自己的本能对抗，拒绝短期诱惑，追求全局最优解。当我想清楚要用团队撬动增长时，就主动砍掉了一些看起来赚钱的事：一对一咨询陪跑、日更朋友圈、一时的影响力，都放下了。

现在做决策前，我会先问自己：这件事能撬动杠杆吗？把精力省下来放到哪里收益更高？想清楚了就不会盲目模仿别人，甚至会推翻之前的一些努力。我的优势战略很简单：做自己最有优势的事，招最认可我的团队成员，服务最认可我的客户，让每个人都能做自己擅长的事，获得商业成就和人生意义。

**三、心态内核：不被同行带节奏**

以前看到别人破圈、影响力越来越大，我会羡慕，也会着急，怕客户被吸引走，怕自己不够优秀。后来被一位朋友点醒：差异化竞争，就是同行都在做什么，你就别做什么。

从那以后，我更专注思考自己的优势，打造优势的稀缺性，不轻易被别人的动作带着跑。心态稳了，内核就稳了。

**四、数据思维：用数据代替直觉**

我以前对数据极不敏感，做事全凭热情和直觉。从2023年7月开始，团队记录了每一个好友的添加时间、成交时间、成交周期、渠道来源。有了数据，我才看清哪个渠道粉丝质量高，哪里的投入回报高。

比如数据告诉我，老客户转介绍转化率最高，所以我把重点放在回访老客户和深挖需求上，而不是盲目冲公域。后端交付和分销体系稳了，2024年再重点做公域流量。

**五、交付成本：找到口碑和效率的平衡**

很多新人容易犯一个误区：交付过重，没时间做流量和影响力，营收下滑，然后内耗。但交付太差口碑又会崩塌。IP做到一定阶段，必须平衡交付成本和客户口碑。

我的控制成本经验是：
1. 低客单产品不做重运营，一个人能交付就好，比如小报童；
2. 提高客单价，筛选容易出结果的优质客户。高客单客户认知成熟、诉求明确，花钱买的是经验和信息差，给了方法就会执行，很快出案例，不用你操心太多情绪价值。而有些客户只付几百块却像割肉，你给了大量干货还嫌不够，恨不得你一次性解决所有问题。遇到这种客户，怎么做都很累。
3. 把常见问题做成SOP，客户问到就引导看文档；把优秀学员带出来，让他们回答小白的基础问题。
4. 未来计划做资源整合型的高端圈子产品比如合伙人，这对IP势能和流量要求比较高，等流量和销售团队组建好再推。

**六、人性利益：研究人心才能成事**

人性不是勾心斗角，而是换位思考：你处在对方的位置，也会做出同样的选择。比如老实干活但不懂汇报，很难得到领导认可；比如交付之外，还要用一些小技巧让客户觉得“占到便宜”；比如想留住人才，要在对方有单干想法之前，就悄悄站在他的位置替他算好账，让他觉得留在团队收益远大于自己单干。

想做大事业，就要顺应更多人的人性，才能获得更多支持。这门学问我还只是小学生，未来要继续在事上修炼。

**七、销售思维：不付费不解决问题**

我不是销售出身，以前有两个痛点：不知道怎么聊才能让客户付费，遇到不舒服的客户会内耗。后来泡在销冠群里拆解成交聊天记录，两个都解决了。

第一个痛的解法：把客户的问题看成需求，围绕他最关心的点，预设他买产品后会得到什么好处、不解决会怎么耽误他。好的销售要替客户分析利弊，规划最有利于他的方案。成交的底层逻辑是：客户得到的未来收益 > 他心中的预期价格，而且最好结合他最迫切想改变的痛点。

比如客户问：“工作不适合我，但身边人都说适合女孩，我该辞职吗？”以前我会认真帮他分析问题，现在我知道，正确做法是预设成交后我会怎么帮他解决，解决后他会变得多好。不付费不解决问题，这不是功利，而是人性规律：免费得到答案，就不会有付费的冲动。

我会先初步分析他的处境，确认工作确实不适合，只是外界的噪音让他迷失；再举案例，比如银行职员测了盖洛普后转了文案策划，医学研究生结合专业背景去了美妆公司做研发；最后自然引入产品，建议他加入优势圈，有教练解答、有案例参考、能借助第三方力量破局。这样既有专业温度，又不失商业动作。

第二个痛的解法：快速判断对方是不是好客户。如果沟通很费劲，一直要你承诺确定性、索取情绪价值，我会直接劝退，一点不内耗。收了谁的钱，就是选择未来被什么人占用时间。IP要保护好自己的心力，不要谁的钱都赚。好的客户会养人，会倒逼你成长得更快。

**八、时间记录：像管钱一样管时间**

我以前对时间没概念。连续记录10个月后，我知道自己每天有效工作时间只有4-5小时，一个月约120小时；回娘家娃黏着时不到3小时。有了记录，我会：
1. 把有限时间聚焦在重要的事上；
2. 根据上月营收算时薪分薪，比如算出一分钟值8块钱后，就果断放弃取快递这种小事；
3. 复盘时间花在哪里，是否匹配目标。

时间管理和财务管理一样，先记录才知道日常消耗，再预算下个月。比如招人之前要想到管理成本会上升，面试筛选会占用近期时间，业务要相应减少安排，不要一边招人一边忙大型活动，否则两边都顾不过来。

以上就是我2023年的思维突破。很感激自己最内耗的时候依然没放弃找出路，终于守得云开见月明。那些想不通的卡点，现在都融会贯通了。跨越痛苦之后，你会更自信，因为你知道自己能解决一般人解决不了的问题。

2024年，我的期待很简单：营收10倍增长，成为盖洛普优势细分领域第一名。也祝你在新的一年找到自己的节奏，实现10倍增长！
