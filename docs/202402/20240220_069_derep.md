# 风向标拆解第 3 期：靠 Notion 模板年收入 100 万美元，通过资料整理变现的路径如何？

在这个信息爆炸的时代，把“整理资料”本身做成生意，听起来像不可能？但风向标拆解第3期告诉我们：这事不仅可行，而且能赚得相当惊人。

这一期的选题聚焦一个典型玩法——通过Notion模板，有人做到了年入百万美元。不过，拆解时并没有只停留在概念上，而是拿出一个更接地气的真实案例：有人专门做《人民日报》精读笔记，分纸质版和电子版两种形式来卖。结果怎样？这位卖家在📕上运营了两个月出头，两个店铺加起来卖了129万多人民币。

换句话说，资料整理变现的路径并不只有一条。像Notion模板那样偏工具化的产品能赚钱，像精读笔记这样偏内容化的产品同样能跑通。关键是抓准需求、选对渠道、快速验证。
