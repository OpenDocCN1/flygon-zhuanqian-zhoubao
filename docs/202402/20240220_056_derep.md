# 什么是战略
作者：龙哥

真正的高手，都在用这3步定义战略

很多人一提“战略”，就觉得是高管们画的宏大蓝图，离自己很远。其实，战略没那么玄乎。

说白了，战略就是三件事：先把真正关键的问题找出来并定义清楚；再围绕这个问题，设计出一套靠谱的解决方案；最后，把有限的精力和资源集中起来，用行动去把这些关键问题一个个干掉。

核心在于“关键”二字。不是所有问题都值得上升到战略层面，你要做的是在纷繁复杂中找到那个“牛鼻子”，想明白它为什么会成为瓶颈；然后基于对问题的透彻理解，制定出真正合理、可行的路径；最后，别贪多求全，必须有所取舍，集中优势力量去打歼灭战。

问题定义不清，方案就是空中楼阁；方案再漂亮，没有聚焦的行动，也只是纸上谈兵。只有把问题、方案、行动串成一条完整的链路，战略才算真正落地。

所以，别把战略当口号。它就是：把问题找出来，把方案做出来，把力量聚起来，干成。做到了这三点，你就是自己的战略家。
