# 风向标拆解第3期 | 📕卖童裙：2600粉如何靠直播卖出1000+件



今天拆的这个号，账号名叫星月公主，专注做洛丽塔风儿童裙子。玩法很典型：📕只做图文视频引流，不挂车，全部转化走直播带货。

为什么要看它？因为光看数据就很扎眼。粉丝才2600，59元的裙子月销破千，62.99元的款也卖了400多单。低粉、无投流，靠的就是直播在硬扛销量。

# 一、流量目前是怎么跑起来的

## 1. 图文视频部分

近30天，也就是12月到1月，只更新了29条内容。图文基本都是裙子细节图，或者挂在架子上的上身照，拍摄手法很基础。视频里真人出镜的只有8条，其余都是假模特展示，背景就是一墙的裙子。

点赞最高的一条，是个打包发货的照片，配文写“这姐妹一口气抢了12件，坐路由器上了吧”，点赞52。

能让用户点进店铺的核心诱因，就是洛丽塔裙本身的吸引力。小女孩看见那种层层叠叠的公主裙，根本抗拒不了。现在的图文质量其实还有很大提升空间，如果能在春节前抓住“穿上就变童话公主”的情绪点去做内容，绝对能再上一层楼。

## 2. 直播带货部分

12月播了70场，1月播了49场，感觉有点掉速了。过年本是童装的旺季，这个播场数有点保守。

直播间布置很简单：后面挂满裙子，前面是主播站着展示。基本保持每天开播的节奏。

如果能把直播间场景升级得更精致、更像一个公主衣橱，把展示的款式和搭配做得更上镜，转化率肯定会更高。

# 二、这个项目怎么上手、怎么放大

## 怎么上手

核心就是两件事：稳定直播 + 持续发图。

每天固定时间开播，把漂亮的裙子一件件展示出来；每天多发图文，用视觉把人吸进来。

开店门槛：
1. 先开通店铺。个体工商户入驻是2000元，企业入驻1000元，再加上平台2000-5000元的保证金。
2. 可以一人多店，一个人运营2-3家店，每家都需要独立营业执照。

选品思路：
1. 赛道要够垂直，比如只做洛丽塔裙、只做公主裙。📕用户要的是「美」，美+质量在线+定期上新，回头客自然就来了。
2. 整体节奏：选品 → 测品 → 持续发图文视频找爆款。多看同行15天内涨势快的账号，学习模仿，把图片拍得更美。就算没有直播，一个爆款图也能自带销量。
3. 图文起号要点：画质清晰，至少2张图一张封面。没模特就拍细节，拍得精致就行。
4. 连发策略：一天至少发5条图文，用数量去撞爆款概率。
5. 口播直播：每天播4-5小时，把图文带来的流量承接住，完成转化。

## 怎么放大

矩阵化是关键。
1. 多店：一个人开2-3个店，分散风险和品类。
2. 多号：一个人带5个号，每天25条图文，工作量可控。直播资源有限，可以挑1个流量最好的号做直播转化，其余4个号靠图文沉淀私域和销量。
3. 多平台：📕跑通后，内容同模复制到视频号、快手、抖音，撬动更大盘子。

# 三、总结

一个只卖小女孩裙子的号，粉丝才2600，图文平平几乎没爆款，直播场次也算不上激进，但依然能把59元的裙子卖到1000多件。这足以证明📕做童装的门槛没那么高。

结论很简单：赛道够美、选品够准、内容够勤。能模仿爆款、持续做爆款，销量自然会上去。
