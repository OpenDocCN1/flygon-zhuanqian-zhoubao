# 为什么吵架的两个人，都觉得自己有理？
作者：龙哥

为什么两个人争得面红耳赤，却都觉得自己占理？这其实是“思考陷阱”系列里一种挺常见的现象：很多时候，你们争论的压根不是同一件事，而是各自心里对同一件事的定义和标准根本不一样。

比如之前某个知识App把LOGO换成了猫头鹰，网上立马吵成一锅粥。有人喊“丑到没法看”，有人却说“越看越有味道”。可这类争论真的会有结果吗？不会。因为好看与否本来就是主观感受。你可以说美，我就能说不美。想想看：一个染着彩色头发的杀马特男孩，一个穿着亮片舞裙的广场舞阿姨，他们那身打扮在你眼里或许很“辣眼睛”，可在人家自己看来，那就是妥妥的时尚。没人会穿一件自己都觉得难看的衣服出门吧？

所以说，想评出谁对谁错，第一步不是急着吵，而是先给“好看”定个公认的杠杠。比如咱们可以约定：随机挑1万人出来投票，超过80%的人认为好看，那就算它好看。至于这1万人怎么挑、从哪儿来，那是后面还能继续掰扯的问题，但至少有了统一标准，讨论才有办法往下走。

同样，今天有人力挺定位理论，有人拼命反对，两边都觉得自己理由充分、底气十足。可细看会发现，他们说的根本不是一回事。反对派举的例证，在支持派看来反而印证了定位的威力；支持派讲的观点，传到反对派耳朵里就成了东拉西扯。说白了，不先把“定义”和“验证标准”确认清楚，双方只是各说各话，谁也赢不了。

所以再遇到分歧，不妨先停下来问一句：我们说的好、坏、赢、输，到底按什么标准来判定？把尺子对齐了，再谈观点。如果谁都不愿意对齐，只顾着找各种理由证明自己没错、捂住耳朵不听别人，那就是另一个“认死理”的故事了。

这事儿放到“中医是否科学”的争论里也成立：反对的人说先按双盲测试来验证；支持的人说那是西医的尺子，中医有自己的辩证法。两边各自拿不同的标准较劲，吵到最后变成“你科学不科学”“你的科学不适用中医”的循环。说到底，任何讨论，先定标准，再分对错，才有意义。
