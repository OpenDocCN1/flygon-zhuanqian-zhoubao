# 2023 总结：30 岁，结束 8 年北漂回老家创业，我把人生过的稀烂
作者：龙哥

三十岁那年，我做完了人生中一次重大的“断舍离”——告别了八年的程序员北漂生活，打包回到一座三线城市，决定凭自媒体闯出一片天。如今回头看，这段经历没能让我逆袭，反而把我按在地上狠狠摩擦了一通。我把自己的“翻车现场”分享出来，希望能给同样动过“裸辞创业”念头的人，泼一盆冷水。

说起来，这个决定并不是心血来潮。真正的引爆点是在2022年：大环境不好，内卷加剧，下班越来越晚。每次回老家，亲戚们都会灵魂拷问：你在北京996图什么？工资再高也没生活，买不起房、落不了户，早晚不得回来？我也反复琢磨，这些年一直像牛马一样被使唤，被PUA，还要担心35岁被优化，实在受够了。我骨子里就向往自由，“打工是不可能打工的”这句话始终在心底回响。于是在22年底，我暗自立下flag：拿完年终奖就撤，去看浪浪山那边的海。

为了说服自己，我还列了三条“铁证”：一是居家办公那阵子，从早到晚电话会不停，半夜十一二点还在开会，生活和工作彻底搅成一团，一听到会议铃声就心慌。二是得了新冠也只敢请一天假，第二天晕乎乎继续干活，否则活儿还是自己的，还要被赖延期。三是周末必须秒回消息、随时处理线上问题，不然就是“工作态度不端正”，绩效等着垫底。那段时间，我真是如坐针毡、如芒刺背、如履薄冰。这哪儿是生活？分明是耗命。

真要辞职时，身边有人劝我：环境这么差，别放着自己程序员老本行不做，跑去搞什么自媒体。我当时根本不以为然，心想程序员干到35岁就是天花板，趁现在30岁，正是创业的好年纪，这步棋走得太有远见了。当然我也不傻，辞职前做足了功课。我翻遍了互联网上的各种项目：工具站、知乎好物、闲鱼书、📕带货、抖音带货、抖音IP、👸号写作、短剧CPS、小说推文、知识付费……最后得出一个结论：抖音流量最大，想当风口上的猪，就选它。我还花钱混了不少知识付费圈子，报了两门培训班，花了小一万。资金也备好了，最坏打算是一分不挣也能撑三年。我甚至自信地想：三年都做不成？不可能吧。

计划也做得像模像样：年计划、季度计划、月计划、周计划、日计划，一应俱全。每天几点起、几点锻炼、几点学习、几点做业务，全排得明明白白。我还提前预想了各种风险——进展慢怎么办、拖延怎么办、家人反对怎么办、朋友约饭怎么办……这组合拳打下来，我觉得万事俱备，只差大干一场。

![](img/9eda59e63ccf52cfe37f3569580b25ca.png)

没想到，现实上来就给了我一个大耳光。今年4月，我正式辞职。辞职当天正好是清明节，小雨淅沥也没浇灭我的热情。我按计划早睡早起，锻炼、学习、搞项目。可没过多久，我发现自己焦虑了——是的，严重失眠，晚上11点躺下，要到早上6点才迷迷糊糊睡着，还时不时心悸。我完全想不通：没了老板管、时间自由、没人PUA，怎么反而睡不着？后来我明白了，对于从小被学校管、工作后被公司管的普通人来说，自由职业根本不是想象中那样。我自己总结了几条赤裸裸的真相：第一，你比以前上班还忙，因为所有环节都是你一个人的事——账号定位、选题、脚本、拍摄、剪辑、选品、商务、客服、社群，连个帮忙的人影都没有。流量差、违规、转化低，全得自己扛。第二，时间多到不会用，每天光学习就忙得团团转，却看不到产出，人被沮丧吞噬。第三，没人给你定目标了，你根本不知道现在做的事跟赚钱有什么关系，整天迷茫、自我怀疑。第四，以前做熟悉的工作，完成了有成就感，还能得到同事认可；现在从零开始，写作、表现力、营销全都要练，落差巨大。第五，你像被社会丢进了孤岛，不属于任何群体，没赞扬、没尊重、没倾诉对象，连骂你的人都没有。第六，钱包一天天瘪下去，更没底的是——不知道哪天能挣到钱，甚至不知道还能不能挣到钱。所以，我真心奉劝所有想裸辞创业的朋友：千万别干这种傻事！裸辞创业九死一生！稳妥的路子是一边打工一边做副业，等副业收入能比肩甚至超过工资了，再走也不迟。要是你说工作太忙没时间搞副业，那我只能说：挤时间，每天少睡一小时，周末别全用来躺平。如果这点困难都跨不出去，那创业路上的难题只会难十倍。实在太难，就老老实实打工吧。

但当时我已经辞了，只能硬着头皮往下走。我开始吃助眠药、喝中药，有所缓解也没根治。拖着半条命坚持了半年多，一半时间学习，一半时间实操。做了两个自媒体号，第一个因为违规被封，第二个流量惨淡，路越走越黑。每天晚上不想睡觉，害怕天亮，因为睁眼又是一片黑暗。

![](img/8bd07010e38e541918fae5738314d2c4.png)

真正的崩溃出现在11月。因为各种琐事跟媳妇闹了别扭，我觉得她在我创业最艰难的时候，不但没鼓励，反而拖后腿。那几天我像泄了气的皮球，彻底心死。在创业的重压、八个月零收入的恐慌、焦虑失眠的折磨下，我认输了——失败，彻彻底底的失败。这感觉就像在一艘大货轮上打工，受不了压榨，终于带着救生艇跳海寻找自由，结果高估了自己，被大浪掀翻，濒临溺亡。

放弃后那几周，我整个人废掉了：熬夜、暴饮暴食、不运动，整天拉上窗帘躺在床上刷手机，只想麻痹自己。可这样下去不行，既然不想碰创业了，就得找个工作先续命。刚开始找工作，心里特别不甘——三线城市哪能跟北京比机会、环境和薪资？可我已经快溺死了，救命要紧。于是海投简历，结果惨不忍睹：本地根本没几家招人的，折腾一个月，真正靠谱的面试竟然只有一家。好在最后拿到了offer，是家刚创业的小公司，十几个人，薪资只有原来的三分之一多一些。但收到offer那一刻，我居然很激动，觉得终于活过来了，能喘口气了。

现在上班一个多月了，公司氛围不错，不加班，七点前大家都走了，离家也近，骑共享单车十分钟。神奇的是一直困扰我的焦慮、心悸、失眠全好了，每天按部就班做熟悉的事，不用操心多余的问题。但心里难免有落差：本来北京好好的工作被我作没了，这一年本该攒下不少钱，结果钱花了，人差点“嘎”了。入职前，北京的同事问我要不要回去，说那边正忙。我让他先问问情况，自己也纠结：要是能回去，该不该回？毕竟北京一个月抵老家三个月。但同事后来回话：年前不招人了，可能年后有变动再联系。我一下不用取舍了，也许这就是命运的安排。我也想问大家：如果机会再来，你是选继续北漂，还是留在老家？

![](img/21de372a77ea1f441c613f7316831ae1.png)

经历这一遭，我终于懂了——山的那边还是山。也许海永远看不到，也许这辈子都看不到。但现在我学会和自己和解，接受自己的平庸，同时还得继续跑。在这个阴雨连天的世界里，没伞的孩子只能拼命奔跑。

希望我的故事，能成为你们的路标：避开裸辞创业这个大坑，先站稳，再起飞。
