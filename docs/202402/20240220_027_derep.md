# 二、选品思路

这个爆品是我按书豪教练教的方法，找到的关注无人直播账号后，半夜刷到的。不同时段刷到的品不一样，我的做法是早上起床刷一次，晚上睡前刷一次，凌晨醒来第一件事还是刷一次。那晚两三点刷到一个新号，播几天就出一千多单，直播间素材也很好找，利润也OK。当时就把链接保存好，第二天开始做素材并开播。

好品+好素材，起量会很快。第一个号真正播了三四场就被判定录播了。个人号容易上榜，早上六七点流量特别好，我多次冲到个人榜前十，最高到过榜一。后面起的第二个号也是走的这个品，如果不是临近年底受货源和素材限制，本可以再拓展同类款。

等一个品跑顺了，对标账号、直播素材、供应链都熟悉了，再去测同类款，转化也还不错。

素材拿法和处理心得：

1.别去跟一堆人一起打的爆品，很容易废号。最好挑那种刚起势还没太多人跟的品，类似低粉爆款的逻辑。
2.素材处理不需要太复杂，调一下比例、改个参数、镜像翻转就能用。也可以自己每天录点生活小视频，透明度调到1，用画中画叠加到直播素材里，保持新鲜感。
3.消音我试过一两次，太费时间还处理不干净，后来直接放弃，优先找干净的直播间素材。

# 三、女装货源与售后博弈

货源对接一般走1688，我老公在服装批发市场附近，自己本来就有拿货发货的渠道，所以直接找本地档口谈。女装我比较谨慎，起步时利润率设在了50%以上，按50%的退货率来算。就算最差情况档口不退货，我的利润也能覆盖成本。

没想到这次退货率爆表，账号生命周期又短，售后一下子炸了。因为突然爆单，仓促找的新厂家，做工粗糙但单价又不低，导致退货扎堆。前几天大批量进货，后几天大批量退货，大多数厂家都吃不消。最后厂家只退了一部分，我自己压了两百多件。

接着我又开了两个号，但当时同款的人太多，素材重复度高，很容易被判录播或触发宣传绝对化，号始终起不来，差点想认栽放弃。

过段时间后，对标号基本都废了或者转去打新品，这款基本没人播了，我也以为凉了。结果某天刷到一个新号，用更低价又开始重新推这款，爆单后手里也压了库存。那号三四天就卖了几百单，我立刻照着策略复盘。不断优化封面和标题，点击率拉到4%，平均停留时长超过30秒，后面单场观众破2万+，峰值在线300多人。

这次我重新和厂家谈，把库存一起清掉，但要求对方承接我的大批量退货。发货上我也收敛了，设置15天预售，分批发出，避免退货堆积，虽然售后周期拉长了，但能扛住。

# 四、小红书打品复盘

1.女装类目，利润率低于20%的别碰
2.1688或其他平台下单，尽量线上付款留凭证
3.别轻信厂家口头说能退，必须在手上压一部分货款，陌生厂家通常不同意，所以要多谈或有自己的供应链优势
4.能自己发货、有稳定合作厂家的，起初一定要控单量，尽量拉长账号生命周期，后面多备几个号来承接退货和库存
