# 当“新老人”开始追巡演，银发研学市场正在被点亮

银发人群的规模在持续放大，手头的可支配收入也在同步走高。这一批有闲暇、有消费力的“新老人”，正一家家走进原本不属于他们的消费场景，也让银发经济的想象空间被一次次打开。

这正是风向标拆解第三期聚焦的命题：带着爸妈去巡演，老年研学需求被满足的机会如何。
