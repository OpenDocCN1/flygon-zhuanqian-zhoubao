# 盲订四天，150 人查看，转化 54 人付款，一场变现 22 万的合伙人产品发售
作者：龙哥

你敢信？盲订仅仅4天，150人浏览，54人直接付款，一场合伙人产品发售硬是干出了22万的成绩。

我是龙哥，19岁那年赚到了人生第一个一百万，20岁几乎走遍全中国。这些年我一直在折腾，也一直在往前走，这次发售合伙人产品，算是一次比较完整的实战输出。

说实话，这次结果我自己也挺意外的。四天时间，150个人看，54个人愿意掏钱，转化率接近36%，单场变现22万。很多朋友都在问我是怎么做到的，所以我把整场发售的思考、节奏和策略，都沉淀成了一份深度复盘。
