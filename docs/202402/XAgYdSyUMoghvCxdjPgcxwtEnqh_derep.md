# RPA+视频号无人直播涨粉保姆级教程

最近不少人都留意到，视频号对新账号的流量扶持力度相当可观，很多人趁这波机会快速积攒粉丝。我亲自跑通了两轮，基本摸清了背后的逻辑，而且这套玩法人人都能上手，直接复制就能用。后来我担任航海教练，也一直在琢磨怎么把RPA和实际场景结合，今天就专门聊聊：如何用RPA搞定无人直播，让自己睡觉的时候也能涨粉。

先来拆解一下视频号涨粉的核心玩法和步骤。

## 一、视频号涨粉原理与 SOP

### （一）设计钩子

钩子要围绕你所在的领域来定。比如我是龙哥，我的钩子就是“免费领AI资料”。

![](img/a3dc578db242e344882470f015152312.png)

### （二）布置直播间

1. 封面要带上钩子文案。
2. 主题直接写“领取AI资料”这类明确引导。

![](img/e7ef190b85176295f5d7bc58c1ba160f.png)

3. 如果做无人直播，就关掉摄像头，背景换成提前做好的钩子图。
4. 开播后可以用【文件演示】功能，把背景设为高清图。
5. 挑一首自己喜欢的歌当背景音乐。

### （三）设置抽奖

开福袋抽奖能明显提升互动率。后面我会细讲怎么用RPA全自动设置福袋，真正实现无人值守涨粉。

参数建议参考这些：

1. 礼物分配选“拼手气”。
2. 总礼物数自己定（注意是总数，不是单份数额）。
3. 中奖名额设1到5个，看直播间热度和在线人数调整。
4. 开奖时间设1到5分钟。
5. 参与方式勾选“关注主播”。
6. 确认金额后发起。

我实测下来，每1到2分钟抽一次福袋，效果最理想。

![](img/cb6c1f3562d3886c1ead7e5307f3ff85.png)

### （四）怎么拉人气

权重数据主要看：点亮灯牌、刷礼物、评论、引导关注和点灯牌、直播间被转发到各个平台、观众停留时长等。

可以找一些互助群一起做数据。开播后把直播间丢进群里，发个小红包，互相上灯牌、点赞，再挂机3到5分钟，这样平台就会觉得你直播间很活跃，自然愿意多推流。

另外，新号记得把官方赠送的流量券用掉。

![](img/f27ca2347d4ab3e63234446f893d530a.png)

![](img/e71850b56cd44b6d0c8559d043b491b6.png)

# 二、RPA 自动设置福袋

下面直接进入正题：怎么用7行RPA指令实现福袋自动设置。非常小白，有手就行。

## （一）提前准备

这一步要手动完成：在手机上先创建好视频号直播，点开始直播；然后把福袋抽奖规则手动配置好。就像这样：

![](img/9cb00d45d44b96ad55c60390ac02724f.png)

## （二）用影刀连接手机

打开影刀的【手机管理器】，把手机连上。

注意：需要安卓手机，打开USB调试，部分机型还要关闭“禁止权限监控”选项。

![](img/0af7c0b5295d105eda4e5773f8f1fc9e.png)

![](img/96655b72f665b9a2b4d39e44d363606b.png)

![](img/52feff4d1ccf61bf00074a8c46ee8a58.png)

![](img/6645c6b24359c6d57764d9b09208da5b.png)

## （四）拉入【连接手机】指令

![](img/88275bdd03985a55035411dc0946e664.png)

![](img/65e3f8abe11716daa7e6389ea3cb8aab.png)

## （五）拉入【无限循环】指令，让它不停跑起来。

![](img/a993fb7a696569ba5ca2b283b74cee9d.png)

## （六）拖一个【点击屏幕（手机）】指令，用“找图”方式点中福袋按钮。

![](img/7ea67ffa90160f0a4c6c331a4048d221.png)

## （七）再拖一个【点击屏幕（手机）】指令，用“找图”方式点中支付按钮。

![](img/04bd1d4d237aaa8421c99c2744e34aa7.png)

## （八）继续拖一个【点击屏幕（手机）】指令，用“找图”方式点中兑换按钮。

![](img/9ebc45e023d91ec710b3946e0f2a7fe7.png)

## （九）加上【等待】指令。比如你设的是1分钟开奖，那就等70秒再继续下一步。

![](img/b6fa67bf34d56ede18dd7abb53a6ff6a.png)

## （十）因为开奖后系统会跳出中奖名单弹窗，所以再加一个【点击屏幕】指令，点弹窗之外的地方把它关掉。

![](img/32f8540ba052d0d90392096a688d6d09.png)

坐标位置可以在手机管理器里移动鼠标获取。
