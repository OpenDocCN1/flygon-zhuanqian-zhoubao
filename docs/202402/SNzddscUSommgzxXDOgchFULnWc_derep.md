# 手把手教你制作海外美女数字人
作者：龙哥

最近这种海外美女数字人视频，是不是刷到过很多？颜值又高，流量也猛，我在2024年年初靠着这个玩法赚到了第一桶金。今天就把一整套制作流程你给拆开，从零开始，手把手带你把视频做出来，想上手的直接跟着走就行。

第一步，先去搞模板。我一般直接去油管上找。什么样的模板能用？注意看两个点：一是人物要正脸出镜，有清晰的面部特写；二是后期字幕不能挡住人物。比如你看到一个视频，人脸和特写都没问题，但字幕跑到画面正中间，后期怎么裁都去不掉，这种直接放弃。反过来，第一个视频虽然也有字幕，但完全不挡人，这就是合格模板。

第二步，做数字人模型。这一步我用的是 AnyLang 平台。之前也有人推荐 HeyGen，但现在那个平台风控严格、价格涨得厉害，对文案也管得紧，索性就换到这来弄。操作不复杂，把刚才下载的模板传上去，等个两三分钟，模型就生成好了。

第三步，搞文案，这步决定了你的视频能不能拿到流量。怎么找？直接在视频号里搜海外美女数字人的热门账号，比如“艾琳莉娜”。我挑了一个有上千小心心的视频，也就不到20秒，但点赞、评论、转发都不低，说明文案很能打。那怎么拿到文案？简单，手机输入法都有语音转文字功能，视频放一遍，文案就直接出来了。拿到以后，建议你稍微改一改，做个去重，这里为了演示我就先跳过了。

第四步，做音频。把文案粘到 AnyLang 的文字框里，下方选音色。这个平台有个我很喜欢的地方：所有音色都支持多语言。不管你是中文、英文，还是西班牙语，都能正常合成，甚至自带一股“老外说中文”的口味，特别自然。因为我们模板是女声，这里就选个女音，比如 Bella，点 PLAY SCRIPTS 试听一下，挺好，就用它。

第五步，合成视频。点 SUBMIT 确认，再等两三分钟，数字人视频就出来了。但注意，这个平台生成的是 16:9，而且右下角会带水印，所以还得去剪映里加工一下。

第六步，后期处理。打开剪映，把视频拖进来，先裁剪比例。如果想发视频号和快手，选 3:4；发抖音就选 9:16。裁剪完，画面也记得调成 3:4。然后加字幕：点文本、智能字幕、文稿匹配，把之前拿到的文案粘进去，点开始匹配，几秒就自动对好了。接着调整字幕大小和字体，遇到太长的句子要分两行，别让它占太满，最后摆到屏幕上合适的位置。

字幕搞完就加背景音乐。原视频背景乐是《我爱你中国》，如果你不知道对方用的哪首歌，可以下载一个网易云音乐，用听歌识曲功能识别。搜出来后，选第一个纯音乐版本加进去。不过原视频声音和背景乐叠一起要调音量：原声建议调到 10，背景乐调到 -10，这样听起来刚刚好。

最后做封面。回看文案，最抓人眼球的是哪一句？这句话在这里：你们喜欢这样的丈母娘吗？我们把进度条拖到出现这句的位置，选个好画面，全屏截图。然后把截图拉到视频最前面当封面，稍作调整。再播放一遍，整体感觉立刻就有了。最后导出，一个爆款海外美女数字人短视频就算完工了。
