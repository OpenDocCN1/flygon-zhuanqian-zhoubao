# 自己备婚 DIY 婚礼，一个月赚 3W+，全程复盘玩法
作者：龙哥

别人分享搞钱项目，她直接把自己婚礼做成了赚钱案例

今天要说的这位姑娘叫艺荷，自由职业刚满8个月，全网积累了2W+粉丝。别看她粉丝量不算顶流，却因为自己操办婚礼，一个月往兜里揣了3W多。她说整个过程虽然累，但回忆满满，幸福加倍。

她复盘了整场婚礼的所有环节，可以说是把“DIY”玩到了极致，资源也被她压榨得干干净净。下面是她的完整流程拆解，未婚的朋友们可以拿来当参考：

1. 为什么要自己办婚礼——先交代背景；
2. 婚礼从头到尾的步骤梳理；
3. 婚纱照怎么拍；
4. 定方案、定风格，顺带敲定四大金刚（主持、化妆、摄影、摄像）；
5. 备婚时间表+家人朋友分工；
6. 婚品采购，专门挑那些能营造现场氛围的小道具；
7. 喜糖盒自己设计、自己定制；
8. 电子请柬和婚礼氛围视频全自己做；
9. 婚礼场地布置亲自动手；
10. 连主持和背景音乐也自己搞定。

每一个环节，都是她亲自策划、亲自对接，没有任何外包。整套流程看下来，真的会感叹一句：这哪里是结婚，分明是在用运营思维做项目。
