# 别再把通缩当成罪魁祸首了
作者：龙哥

很多人一看到物价下跌就紧张，觉得是通缩来了要拖垮经济。但真相往往被反了过来。

通缩从不是经济滑坡的起点，它更像是一场衰退已经发生后的回声。需求萎缩、企业裁员、居民惜购，这些衰退的信号先行上场，价格才在最后跟跌。说白了，是经济先冷了，价格才跟着降，而不是价格先降把经济给冻住。

把因果关系弄反，就容易用错药。盯着价格数字去救火，却忘了去修复真实的收入和信心问题。
