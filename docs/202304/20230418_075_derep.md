# 《全方位拆解一个互联网医馆项目》
作者：龙哥

各位圈友，大家好！

之前聊过我们团队，线上线下都折腾过一些项目，算是一路在创业圈里摸爬滚打过来的。今天想分享的，是去年一个挺有意思的尝试——互联网医馆。

坐标放在成都，时间是2022年下半年。我们当时决定把传统中医馆的业务搬到线上，从模式设计、团队组建，到获客、转化、运营，每个环节都做了详细记录和复盘。整个过程有踩坑也有收获，所以想把完整的拆解内容分享给大家。
