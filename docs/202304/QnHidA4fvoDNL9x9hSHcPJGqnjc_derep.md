# AI让逝去的亲人“开口说话”？照片加音频就能做出动态视频

如果有一天，你能再次看到已故亲人的脸、听到他们熟悉的声音，甚至看到他们对着镜头轻轻说话，你会觉得这是一场梦吗？其实，借助现有的AI技术，这已经可以做到了：拿出一张旧照片，配上一段原声素材，就能合成为一段带表情、带声音的动态影像。这不是影视特效，而是普通人照着步骤就能完成的操作。今天，就把这套完整的落地方法分享给大家。

整套流程的核心逻辑很简单：照片 → 语音合成 → DID生成原生视频。先用图像技术处理好照片，再用AI合成声音，最后通过DID平台把两者拼成一个有动作、有声音的视频。

## 这个项目到底是做什么的？谁会需要它？

很多人在亲人离开后，只能靠静态照片和旧语音回忆过去。AI图像处理、语音合成和视频合成技术，恰好可以将这些零散的素材，变成一段“像活着一样”的影像。生成的视频不仅观感逼真，更重要的是，它承载了使用者的情感寄托。

谁会对这种服务感兴趣？答案很明确：逝者的子女、亲属、挚友，以及所有渴望用更真实的方式去怀念故人的人。他们的核心需求，就是想在影像和声音中，再次触碰亲人存在过的痕迹。目前市面上有没有类似的平台？确实有，但真正做深做透的不多。如果打算进入这个领域，前期的市场调研必不可少：了解竞品如何收费、目标市场规模有多大、潜在客户画像是什么。

说到底，这是一个情感的出口，也是一门有温度的生意：为有需要的人提供有声视频制作服务。落地的流程大致是：收集照片和声音样本 → 用AI工具处理照片 → 合成语音 → 将声音与画面同步 → 生成视频 → 后期优化调整。推广上可以通过社交媒体、广告投放、老客户推荐等方式触达目标人群。同时还要根据用户反馈不断打磨服务，提升视频质量和体验，才能走得更稳。

盈利模式也不复杂：直接按服务收费，也可以推出定制化套餐和增值服务。随着怀念需求日益被关注，这个方向的市场潜力和变现空间都相当可观。未来还可以尝试与虚拟现实技术结合，带来更强的沉浸感；或者开发一些更具纪念意义的特别版本。

## 第一步：准备好一张照片

照片通常由客户自己提供。这里有个关键提醒：照片必须清晰。如果原片模糊，就要想办法修复，比如使用老照片修复工具。这项操作可以额外计费。

## 第二步：合成亲人的声音

声音素材由客户提供，要求是至少一分钟的原声视频，越清晰越好。接下来使用百度飞桨平台完成语音合成。具体操作如下：

先用百度账号完成注册并登录AI Studio。![](img/2db1c5e107f11e15b67585d889ea77c5.png)

进入主页后，在搜索框输入关键词“有手就行”。![](img/9a6565a4a119dcad58924df51990d343.png)

在结果列表里找到对应的语音合成项目，点击进入。![](img/b4a82a8cd7086ccd6b47a88b8e1e440e.png)

进入项目后，先点击“运行”。![](img/aa19e153145007c72e45b2c2e6da37e6.png)

运行环境选择32GB配置。![](img/a01211ad12044e2028b15443d0e5b939.png)

随后再次点击“运行”，等待系统自动安装依赖。![](img/9d0d55bb251fea9e277c9d8eaa63299a.png)

稍等片刻，下方会显示运行时长和结束时间，这就说明环境已经准备好了。![](img/8cee9071581ee58e41e8be331a7f323f.png)

接着找到左侧任务栏的最后一个选项，双击它。![](img/3fe3375fa6c8f12036dea5b0d0025360.png)

在弹出的操作菜单中，选择“在浏览器打开”。![](img/aff1d4642c20e7e44ecc47afc0a5ec2b.png)

至此，你就进入了正式的语音合成页面，可以开始合成了。![](img/d7d854deef454ffa66d5c8787c705640.png)

这里有几点需要特别注意：
- 音频格式优先选WAV，MP3也可以，但需要额外用音频处理软件做降噪（搜一下就有很多工具）。![](img/3a2c6456a7bc106a6f32510f794a1cd3.png)
- 将准备好的音频文件上传到平台。![](img/c5195021de0aa027bae9078a4fa09802.png)
- 上传后点击“检验”，确认音频是否合规可用。![](img/c16cb70bf9c38d8fe8d9f89e05cc5202.png)
- 接着训练并导出模型。注意：训练次数不是越多越好，具体请参考 https://www.bilibili.com/read/cv19722919?spm_id_from=333.999.0.0 ![](img/d2ea6bf9541da569ff15d419acd5af4d.png)
- 然后开始音频合成。![](img/41697094a12a718721495025dad680b3.png)
- 完成合成后，将生成的语音下载到本地。![](img/834b9cc29f9195d54543c92a382ca2a3.png)

再次提醒：如果暂时不继续使用平台，合成结束一定要退出，避免占用资源。

## 第三步：用DID生成视频

声音和照片都准备好后，进入DID平台完成最后一步。

需要知道的是，每个DID账号最多只能生成5分钟视频，用量大的话可以多注册几个账号。官网地址：https://studio.d-id.com/

登录后，先创建一个新的视频项目。![](img/8bb6aec35d812d6011560339af4c2e0d.png)

接着上传客户照片，并点击该照片素材。![](img/07b6b3d3f884ba44b1a61d5918f71c8c.png)

然后把上一步合成好的语音文件上传到对应位置。![](img/73fb22911d5849754b05a026e20fdfe2.png)

最后点击“生成视频”，等它渲染完成，直接下载即可。![](img/1ea712aabd906f8fb0354c08d071206e.png)

就这样，一张静默的旧照片，变成了一段会开口说话的动态影像。整个流程并不复杂，真正重要的，是耐心处理好每个细节，同时也要明白这件事背后承载的情感重量。如果你正好有怀念的人，或者想把它发展成一门副业，完全可以按照这套方法试一试。也许，这就是很多人等了很久的一份安慰。
