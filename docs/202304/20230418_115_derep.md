# 《砂石厂老板如何潜伏赚钱 2 年，找到适合自己的项目并赚到“第 2 桶金”》

在龙哥盟这个圈子里，我潜伏了整整两年，一直没吭声。直到刷到龙哥给新人回帖的那一条，我这个连续三届的“老学长”终于坐不住了，决定把自己从“媳妇熬成婆”的全过程写出来。这篇文章，我整整磨了三天。

![](img/fca3ec1c65420eee2c284a3827cddc2b.png)

就是上面这个帖子，让我特别想跟刚进圈的兄弟们聊聊我的经历。

我是龙哥，人如其名，老实巴交。主业是开砂石厂的，在这行摸爬滚打多年，靠着一股韧劲赚到了第一桶金。但生意做到后面，总想再找条新路，让钱生钱。于是，我开始在龙哥盟里“潜伏”，每天看帖、琢磨，也不怎么发言，就想找到真正适合自己的项目。

两年下来，我的想法慢慢清晰了：不是所有风口都该追，也不是所有项目都适合自己。你得沉下心，在自己熟悉的领域里挖，找到那个能跟现有资源互补的方向。后来，我确实找到了，也实实在在赚到了“第2桶金”。这个过程里踩过的坑、悟出的理儿，我都写进了下面这份文档里：
