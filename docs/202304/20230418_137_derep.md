# 抖音弹幕游戏直播已经起势，这可能是未来两年最能赚钱的直播玩法

大家好，我是龙哥，龙哥盟第五期学员。

去年还在写美妆品牌从零起步的干货，今年我的重心已经完全转到抖音直播公会运营上。

2022年我先切入的是娱乐直播赛道，折腾了大半年，效果平平。可到了年底，我踩中了一个正在加速爆发的赛道——抖音弹幕游戏直播。火热程度不用我多说，看赚钱社区的讨论热度就知道。

今天就把这个项目拆开讲清楚，到底为什么它会成为下一个吸金窗口。

过去做娱乐直播，门槛高、竞争卷、变现慢。而弹幕游戏直播的逻辑完全不一样。它用低成本的游戏互动+弹幕指令，把观众从旁观者变成参与者，留存和打赏转化直接拉满。主播不需要颜值临门一脚的压力，也不需要高超的才艺，靠的是控场节奏和社群感。

我从美妆项目转战直播公会，最初也是走了弯路。但一旦切到弹幕游戏，数据是肉眼可见地起来。用户停留时间长、复播率高、付费意愿强，这几个核心指标全对上了。

我判断，弹幕游戏直播的风口已经确立，不是未来会不会红的问题，而是现在进场能不能跑在前面。按照现在的增长曲线，接下来24个月，它会是抖音直播里吸金能力最强的形态之一。
