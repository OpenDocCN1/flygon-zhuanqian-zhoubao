# 《线下小聚复盘：赚钱的个人核心竞争力》

在风口日新月异的时代，能够稳定获得收入的秘诀，往往不在于追赶下一个热点，而在于打造自身那些几乎不会过时的硬实力。这是一种无论你换到哪个赛道，都能随身携带的资产；也是当大环境不理想时，能支撑你守住一小片领域的力量。

为此，在一次线下同行的交流之后，我越发觉得，与其焦虑外界的变化，不如花时间巩固自身内功。这里说的内功，不是指某项具体技能，而是当所有外部条件都改变时，你依然能拿出来用的判断力和积累。有了这份积累，你在切换赛道时不至于从零开始；在大家都没机会时，你也能找到适合自己生存的缝隙。
