# 凌晨四点生火掌勺：一个乡镇包工头的日常，远比你想象的沉重

回山东处理家事那几天，抽空和堂弟坐下来聊了聊他这些年的营生。

最初他和人合股搞挖沙船焊接，行情顺的那几年攒了些积蓄，后来市场转冷，本钱又赔了个精光。我们黄楼镇素来有花木之乡的名头，他干脆转身做起绿化工程的分包活儿——说直白些，就是自己跑项目、回村里临时招人，带着一帮乡邻栽花种苗的领头人。

活儿多在省内转，偶尔也跨到邻省。按株计价，甲方给一毛多，落到工人手里七分，他挣的便是这薄薄一层差价。回款才是真正让人揪心的地方：工人工资必须当天兑现，甲方却常常拖着，碰上爽快些的先付一半，余下的只能赊账——这笔垫资，成了他心头最沉的负担。

工人的吃住行也全压在他一个人身上。为多省几个铜板，饭菜得自己动手，天不亮就在工地旁架锅生火。若是路程近的项目，凌晨四点就得摸黑把车发动起来，拉着大伙赶路；为抠出成本，他添置了一辆面包车，挤不下也硬塞——真按核载跑，一趟根本拉不完，可要请个司机，那点辛苦钱就打了水漂。四点钟爬起，路上再颠簸两三个钟头才能到。

收工后杂事一箩筐，能合眼五个钟头就算老天开恩。

在山东乡下，年入几十万，搁当地绝对体面。可这钱是拿命熬出来的：垫款的风险自己担，一天十几个钟头耗在工地上，一年到头没个喘息的空档；找活儿是他，握方向盘是他，掌勺是他，端茶倒水还是他。

报纸杂志和影视剧里的包工头，多半一副狡黠面孔。可像我堂弟这样的人才，恰恰是这行当里最寻常的模样。

国内劳动力大军中，还藏着数不清的乡镇小包工头和打工者。他们换来的报酬，说到底仍是超负荷体力付出的折现——况且我家乡那一片的底子，在全国已经算殷实了。

能发声的人，多半扎堆在省会与一线都市。可他们眼里装的是写字楼里的剧本，嘴里讲的也只是少数人的切片。而像我堂弟这样的角色，恐怕才是那部分被折叠起来的真实乡土。
