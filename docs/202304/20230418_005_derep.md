# 和一位艺术教育者聊了整个下午，我的创作认知被推翻重来
作者：龙哥

清明小长假，我领着娃去见了一位搞艺术教学多年的前辈，从午后一直聊到傍晚。此人眼界开阔，讲的东西密度很高，我回来梳理成几条，供做内容、做创作的朋友参考。

**一、卖作品其实有两条截然不同的路**
第一条路，把画作推向富裕藏家圈。这类买家掏钱，图的是"我和你们不一样"的稀缺标签，走这条道的人多半奔着成为有名气的艺术家去。第二条路，把作品交给普通人，比如连环画、商用视觉设计等等。说实话，后者成功的几率反而更大——因为前一条赛道的山头太窄，挤不下多少人。

**二、动笔之前，先补足底层的学问**
哲学、逻辑、语义学、传播理论、政治学、符号分析、心理学，这些门类都得系统过一遍。只有把底子打扎实了，你才明白一件作品凭什么被大众接纳。举个例：颜真卿的字相当端正规矩，凭什么受人敬重？因为彼时儒家思想是主流，儒家反感张狂，讲究的是尊卑有序。作品能打动人，说到底是价值观对上了频率。

**三、媒介本身就是影响力的管道**
他带的所有孩子，有一本书是绕不开的——麦克卢汉的《理解媒介》。理由很直接：艺术说穿了，就是借某种介质去作用于别人。这话让我吃了一惊，头一回听搞艺术的人认真谈媒介。偏偏传播和营销也建立在媒介认知之上，聊到这儿我们有了不少交集。

**四、介质换了，打法就得跟着换**
他老早就安排学生拿iPad画画，近来又带着大家玩AI作图，老派画家看了直摇头。可他搬出《理解媒介》来回应：介质是艺术不可分割的一部分。壁画靠墙面被人看见，岩画靠洞窟被人看见，纸本靠流传被人看见——没人看得到，艺术就不成立。当下的介质在哪里，你就该拿起哪里的工具。

**五、时间壁垒来自专注**
时间既稀缺，又是最难跨越的门槛。一个年轻人哪怕天分再高，也不该什么都碰。先定下一条创作主线，花十年上下往深里做。从功利角度看：十岁起步，到十八岁攒出一个门类的作品，只要脑子不笨，全球哪所名校的艺术专业都够得着。

**六、数量本身也是护城河**
品质当然要紧，但产量同样能筑墙。作品太少，影响力就撑不起来（个别例外不谈）。瞧瞧蔡志忠——老外想了解中国文化漫画，绕来绕去总先撞见他，因为老庄、孔孟、四书五经他全画了个遍，体量摆在那儿，你躲都躲不开。他指导过一位学生改编名家科幻小说，后来借助AI提速，两三天就能产出一本短篇科幻漫画，等积累到一定规模，壁垒自然而然就立住了。金庸、阿西莫夫也是靠写作速度快、产出足够多，才站稳脚跟。

**七、挑书要有标准**
有些书扫一眼目录就够，有些书压根别碰。时间是最金贵的资源，别浪费在低效阅读上。

**八、单打独斗的人，最大的软肋是生命本身**
对超级个体来说，终极风险就是生命画上句号。所以健康管理和意外防范得放在心上。多子女的家庭，传承上风险分散些；公司和组织有足够的备份冗余；个人则只能靠自己多上心。

原本想请他录一期播客，可他死活不肯露面，只好先用文字把要点记下来分享。
