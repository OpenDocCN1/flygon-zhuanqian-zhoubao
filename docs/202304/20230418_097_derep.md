# 加入赚钱第3天，我搞定了自己的副业规划

大家好，我是壹千。刚成为龙哥盟第七期新人的第三天，想分享下这段时间的真实经历。

我今年35岁，目前在一家餐饮管理公司任市场部负责人，品牌策划、营销这些工作都归我统筹。主业其实已经看到头了，工资也差不多到了本地同行业的最高线，两年下来基本没存下什么钱。人到中年，上面老人下面孩子，这份收入也就勉强维持收支平衡。大环境不好，就业和经济的压力都摆在眼前，我总忍不住想：万一哪天工作没了，手上又没积蓄，日子该怎么过？越想越不安，也正是这股逼人的焦虑，让我下决心开启一份副业，去外面寻找更多机会。

其实副业这个念头早就有过，但始终没什么头绪。直到有一天刷即刻，看到@IDO老徐的帖子，他写的那些副业赚钱内容瞬间引起我的兴趣，可我对赚钱这件事还是半懂不懂。恰好那段时间龙哥盟在拉新，就这样，我和它意外结缘。

起初看到星球门票价格并不低，我犹豫了好几天，总担心自己是去送韭菜的。为了安心，我特地去知乎、即刻查了一轮口碑，发现虽然也有质疑的声音，但大多数人都是认可赚钱的。心里的石头放下后，我直接找老徐预留了名额。2023年4月3日晚8点，我正式成为赚钱圈友。

进圈前，我做了很多心理准备，把所有期待都压得很低——哪怕这钱只换回认知上的升级，我也觉得没白花。毕竟一个人永远赚不到认知之外的钱。但万万没料到，认知升级来得这么快。刚进圈那会儿，因为早有心理准备，我并没有像许多新人那样被大量信息搞得慌张，反而有种挖到宝的兴奋，整个人开心到不行。这地方，完全长在我的兴趣点上。

按照老徐和鱼丸的指引，我先翻了一遍《第七期新人指南》——虽然是给新人看的，但内容密度和深度都不容小觑，尤其延伸阅读数量惊人，想短时间内全吸收不太现实。所以我给自己定了一套阅读策略：

- 先把新人指南大致翻个遍，并填好会员信息表；
- 只挑感兴趣的“推荐阅读”粗读，不碰延伸贴；
- 精华帖和风向标争取都快速过一遍，看到对胃口的先存起来；
- 把碎片收藏归好类；
- 接着狠心砍掉大半，只保留眼下能用上、自己够得着的东西；
- 拿思维导图做结构拆解，把底层逻辑理顺；
- 最后选出个位数项目，准备实际操作、验证试错。

这会是我在5月航海前的主要节奏，目前还在持续整理。同时，我没忘记进来的初衷——升级认知。偶然翻到一篇《想体验龙哥盟，可先看这28篇精华帖》，给我的帮助远超预期，甚至想说，就算只看了这一篇，我已觉得值回票价。

几天下来，我最想记录的几个收获：

1. 用预期、擅长、喜好和资源来选项目，这是@杨涛说得最透的；
2. 先把公众号备好，热点一变就改名，再到赚钱里找变现路径，能迅速接住流量，源自@郭晓文的分享；
3. 把精华帖索引工具当搜索引擎用，关键词一搜就能解决问题，@小新对这个用法总结得特别好；
4. 不知道喜欢什么，就挑不讨厌的事干，边学边教，@龙哥的小故事里有答案；
5. 月入几千的小项目别嫌小，正因为可复制，反而藏着做成大项目的可能，这也是@龙哥的观点；
6. 赚钱的驱动力无非愿景或痛苦，要找到自己非做不可的理由。@港妈金侣的案例最震撼：全职宝妈，没专业没定位没爱好，20个月变现170w+，边跟人学边开营教；
7. 还有一句忘了出处的话，直接击穿了我的心理防线：“当你的水平到了60分，就能给40分的人当老师。只要有信息差，你就拥有价值，而价值就是赚钱的入口。”这话跟@亦然说的、@港妈金侣做的，完全对上了。

这些收获，基本为我下一年的折腾铺好了路。我自己也基于这三天的体会，借鉴领路人@IDO老徐的变现思路，再加上对所处行业痛点的理解，粗略画了一张副业变现框架图。它有没有用还不知道，但至少让我接下来不再迷茫，知道从哪里动脚了。
