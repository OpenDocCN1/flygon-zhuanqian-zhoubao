# 《通过办理 ICP 备案，挖掘到一个可以长期稳定，月入过万的副业》
作者：龙哥

上个月陪朋友处理了一次ICP备案的糟心事，没想到从中嗅到了一个长期稳定、月入过万的副业机会。

朋友想在视频号上架课程，必须有ICP备案。我先在淘宝上找代办，问了两家：一家报价800，另一家500。因为800那家是本地公司，我们选了贵的。结果资料交到华为云后台时，代办说营业执照含“食品经营”类目，必须移除，否则谁也过不了。

后来别人又给我推了两个代办：一个看经营范围很多，直接抬价至1000才肯办，还放话说“注册时选太多范围要付出代价”；另一个则说必须去掉“教育咨询”类目，不然办不了。最后经朋友引荐，找到一位靠谱的代办——域名费自理，认证不通过就退款，最关键的是营业执照经营范围一个字没动，顺利通过了。后来在视频号航海群里聊起，一个圈友说他花了600块在淘宝办的，可见这个行业的定价完全没有标准。

因为每次和代办沟通，朋友都会拉我进群，整套操作我全程看在眼里。当时就想，代办理ICP备案是不是能做成副业？本来想推荐给朋友，但他最近太忙，我就整理出来分享给各位圈友。

先说背景：现在视频号上架虚拟课程必须有ICP备案或认证，没备案就上不了架。需求明摆着，自然有人专门做代办。赚钱里想办这个的圈友恐怕也不少。

什么是ICP备案？全称是Internet Content Provider，网络内容提供商。可以理解为向大众提供互联网信息业务和增值业务的电信运营商，需经主管部门批准才能正式运营。抖音、视频号上传课程都要提供ICP备案网站截图，需求不小。注意还有个ICP经营许可证，要求更高，对公司成立时间、社保等都有硬性规定，这里不展开，以后有条件再对接这类资源。

办理ICP备案的流程不复杂，但比较繁琐。客户付费后，我们在淘宝下单，才开始处理。第一步是去阿里云万网注册域名（https://wanwang.aliyun.com/domain/tld），进去后查询心仪的域名是否被注册，没被注册的就可以选，费用不高，一年几十块。

②准备购买域名所需资料：公司营业执照、经营范围、创始人姓名、手机号、身份证、能接收验证码的邮箱。

③填写资料后等待审核。
④审核通过后完成付款。

⑤法人下载阿里云APP，进行人脸识别验证。

![](img/c185441b1282aa2cf109b6f25ea1a46a.png)

账号密码与注册万网的一致。登录后点击底部“控制台”。

进入后选择“ICP备案”。

![](img/4c1e03073ca04d01c579364b32157750.png)

按页面提示填写资料。

在“是否涉及前置审批”类选项里，选择“网站应用服务”。

![](img/9a8317b84e65c30131704756ed18333b.png)

后续需扫描上传身份证，所以要提醒客户带好证件；法人需要找白色背景拍照上传，然后等阿里云审核。审核期间会有电话回访，务必接听。

![](img/cbf0f6c7428381e402876022597fead5.png)

如果审核通过，但营业执照中有些类目需要许可证而实际没有，就要提交承诺书。承诺书模板可以在万网那边找，不同省份要求不太一样。

![](img/0d099779e583c2e5ca978e68b516290d.png)

提交承诺书后，等通讯管理局审查。

![](img/ef14fc2cc55639014c008b88c7d5884a.png)

期间留意短信。收到后点击短信中的验证链接，才能进入备案排队流程。

![](img/400252c55df567d15e85b7af7114fee5.png)

短信验证完成后，就进入通讯管理局审核。通常7到20天能下来，大部分一周左右即可完成。阿里云APP可以查看进度。

![](img/06e18575337b630b3d8b959d1f9358a9.png)

没问题就能通过；有问题就按提示调整。大部分问题出在经营范围上——营业执照里列了但实际未经营的类目，需要写承诺书说明。

备案查询网站：https://beian.miit.gov.cn，输入营业执照名称即可查看是否备案成功。

注册域名建议选阿里云，华为云审核更严格。市场上代办费贵的800，便宜的500，建议定价：原价800，公司十周年限时优惠500，办不下全额退款。

做这个项目，除了掌握流程，更要学会获客和谈判，尤其是利用线上平台低成本引流。

第一种：淘宝获客。
在淘宝开店很关键，因为很多客户线下来不了，直接转🛰️信任成本高，有个淘宝店方便收款。如果暂时开不了，可以找财务公司合作，客户拍他们的链接，再统一结算。我做调研那会儿，淘宝还能搜到ICP备案，现在已经搜不到了，但用作收款入口还是可以的。

![](img/839116a02ddf8e10f94e35c2ec3b52ea.png)

第二种：📕获客。
📕是我认为最适合获客的平台，方法简单——分享ICP备案的办理流程。很多人看教程也办不明白，这时我们就出面代办。

![](img/184ea28e3b179e58098ca36f1b625384.png)

![](img/b3ab7ea67b59e9942170322fcabede76.png)

淘宝下架相关搜索词后，流量流入自媒体和搜索引擎。搜索引擎推广费钱，个人玩不转，📕自然成了最好的选择。多号矩阵、内容模板化，获客效率很高。

做📕账号注意三点：
1. 形象要专业。头像、昵称、简介、内容调性，都要显得很“行家”，让人一眼信任。
2. 不能只发教程。更要晒实力，比如每天都有客户的备案成功截图，这样的内容最能吸引精准客户。教程引来的多是白嫖党；说“多少钱能办下来”，来的才是付费用户——内容决定人群。
3. 引流路径要清晰。在文章里或评论区留下钩子，小号互动带节奏，让客户主动加你。

第三种：客户转介绍。
我们就是被人介绍找到代办师的，私域转介绍同样重要。朋友圈要用心经营。有些人加过来不会立刻下单，会默默观察一阵。朋友圈分享办理动态、多晒成功案例。开始加客户前，可以先把十个同行的朋友圈学习一下，模仿发十多天，再让新客户加进来，不会看到空白号，能快速建立信任。

客户咨询时要有耐心，啰嗦的客户不代表不买，她身边可能还有同样需求的朋友，反而带来转介绍。

这个项目的收益不止代办费。深挖客户需求，还能延伸出更多变现路子。

1. 与财务公司合作。
ICP备案的前提是有公司，但有些客户没有公司，需要先注册，这就衍生出公司注册、代理记账、地址挂靠、各类资质办理等需求。我们遇到的第一个代办，就因为承诺书写不好一直过不了审，还去变更了经营范围——这也是财务公司的业务范围。和几个财务朋友聊过，一单分成至少500，具体看情况，既能拿CPS分成，也可以直接卖线索给财务公司。

2. 平台入驻相关。
课程博主做完课程，要上架到各大平台——抖音小店、橱窗、视频号、📕商店。他们的时间宝贵，愿意付费找人代操作。像龙哥风向标里提到的多账号实名认证、绑定50个员工号等，都能作为延伸业务。最近📕店铺很火，食品类要食品经营许可证，卖书的要出版物经营许可证，这些都可以对接，自己走一遍流程就知道怎么申请。

![](img/a7f5ca716b26f56767f3d319e80bd9ec.png)

3. 与知识付费平台合作。
办理ICP备案的大多是知识博主，他们也需要线上平台交付课程，可以对接这些平台的销售。目前了解小鹅通能返10%。最近抖音不能上架课程，很多人转而买小程序。

4. 课程与社群。
很多客户想卖课但没有现成的课程，需要学习怎样快速做出课程，我们可以在朋友圈分销相关课程。有些老师会做课但不会卖课和运营社群，同样可以推荐对应课程，包括龙哥盟拉新，都是精准需求。和客户交流时还能发现更多需求，自己接不了就介绍给他人赚佣金。

平台竞争越来越激烈，政策动态不断调整，很多副业只能做一阵子。但帮人办业务这件事，我觉得能长期做下去——只要在互联网上做生意，就离不开这些证件；制度越完善，需要的证还会越来越多，这是个潜力不错的项目。

新朋友如果暂时不能全流程自己干，也可以找人合作，有人专门办ICP，有人专门在📕获客，分工协作赚钱更快。希望这个思路能帮到圈友。赚钱航海里有很多朋友有这需求，用心服务好他们，不仅收入稳定，口碑带来转介绍会更源源不断。

评论区里也有不少经验：有人说万网备案比较省心，前期阿里会预审，不合规的地方会打电话指导修改，改好就行；还有人说自己做过腾讯备案，成本就是域名叫备案码的钱，有条件的可以企业🛰️领域名，接近零成本。这类经验真诚，供大家参考。
