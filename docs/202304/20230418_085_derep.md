# 一次“反常”的决定，就能把运气和人生掰回来

看完我那场见面会的分享，有朋友私聊说，这番话正好撞在他们低谷的点上。整理出来放这儿，给还在迷茫期、卡住期的你。别把它当心灵鸡汤，当一个可以立刻上手的操作手册。

# 第一部分：能让你起死回生的动作

别绕弯子，最简单也最有效的一件事就是：

主动去做一件，以前的你绝对不会做的事。

门槛要低到今晚就能执行：

周末你向来宅着，这周就出门逛街晒太阳。
你习惯焦虑刷手机，那就给自己列一张高质量放松清单，按着做。
以前只买地摊价的衣服，这次去实体店试穿，认真配一套。
花点钱吃顿一直想吃却嫌贵的菜。
染个一直心动却没敢染的颜色。
今天手机一放，提前睡觉。
起个大早听听鸟叫。
去那个住了很久的城市，走一条从没走过的路。
说走就走也行，想看就去看演出。

进阶版：
做一个过去不敢选的决定，大到职业、感情、求学方向。
尤其是对那些让你犹豫、好奇、念念不忘的事，花钱去体验它。越是那种心里会嘀咕“有点肉疼、有点社恐、不一定有用、以后再说”的，越要现在就付费去参与。

# 第二部分：我的第一次摇滚现场

这个转捩点，我用现实的版本讲给你听。

二月工作受挫，像是主业最后一点火苗也被浇灭了。奇怪的是我没沮丧，反而松了一口气。没了期待，就不会失望。2月19号那天我对自己说，这几年活成了为了让别人满意的卷王，从今天起，为自己活。

没几天，公司负一楼戴着耳机，随机蹦出一首很夏天的摇滚。我当时就想，这歌应该在现场听，一群人一起跳。顺手点开网易云评论，发现这个乐队2月26号在上海有加演。我疯狂去拉朋友，结果全都忙、都约满了。

按老习惯，我大概就放弃了。我甚至不是铁粉，只听过两首歌，还不知道主唱叫什么。

但脑子里一直有个声音在说：想换运、想改现状，就必须去做一件从前绝对不会做的事。

于是我定了票，人生第一场摇滚 live，必须去。

之后的每一步都像开了挂。

去现场的路上刷到小红书上也在找同行的小姐妹，两分钟就约上，见面超合拍，一路聊到嗨，演出也一起看了。
没听过的歌，反而给我了最强的共鸣和力量。
和一群同频的人一起蹦自己最爱的歌，那种纯粹的快乐是高浓度无杂质的。
进场前我对乐队一无所知，出来时已经抱着一张专辑，因为觉得他们值得。
签售时我跟主唱说，今天是我二月最棒的夜晚。他笑了说，来，抱一下吧。那个意外的拥抱，和一句“你很紧张啊别紧张，自拍慢慢来”，让我第一次真切感受到，台下的情绪，台上的人也能感受到。
当晚还进了个迪士尼饼饼群，收了一堆可爱表情包。
回家路上短信提示：刚买的两瓶身体乳到了。

所有美好的事，就在那个我决定“反常”的一瞬间，在同一天里集中发生了。那晚我兴奋到三点才睡，写了三篇小作文，一直在感慨宇宙对我太好了。

后来我才明白，理想的人生体验，其实就是：随心而动，被热爱推着走。
它只需要一个和从前不一样的决定，加上260块钱。原价220，闲鱼加了40。

以前不明白“想成为那个人，现在就做成那个人”，不明白“活在终点”是什么意思。
也不明白那句老话：A和B两点之间最短的距离，不是直线，而是把纸折起来，让A和B直接重合。

现在全懂了。
不是显化某个具体的物质或结果，而是显化一种感觉。
显化当你已经拥有想要的一切时，你此刻的感受，然后就沉浸进去。

主唱在签名上给我写的是：To Amy，每天活在热爱里。
我觉得，我已经做到了。

# 第三部分：为什么管用

我没学过系统心理学，但回头看这串反应是有逻辑的：

第一步，改变行为。
第二步，不经意撞到美好的意外体验。
第三步，配得感上来。
第四步，认知被改写。
第五步，行为持续改变。
第六步，形成习惯。

最后，人生跟着变。

当你有意识地去做不一样的事，你就已经换了版本，相当于跳到了平行宇宙的另一个自己身上。

见面会前我总结过如何保持高频，后来安澜点醒了我，我改成“如何保持觉察与清醒”。

别追求时时刻刻都快乐顺利。阴郁、颠簸、失落都是生活的一部分。
生活像过山车，你不知道下一秒是上坡还是下坡，硬要停留在高点的本质是对真实生活的恐惧和逃避。这种恐惧会投射到关系里、到金钱里、到你和世界的关系里。

# 第四部分：保持清醒不掉坑的日常打法

1、日复盘日记
记今天有没有做自我肯定冥想，情绪稳不稳定，有没有负面潜意识冒出来、是因为什么。写感恩和成功日记。
修正潜意识的路径我简单说下：觉察-改写-找到擅长-发挥擅长-改命。

2、冥想
我常做的是自我肯定、观呼吸、身体链接、排负、动态冥想。喜欢的老师有李欣频。推荐的小宇宙/小红书账号：灵柒的小宇宙、冥想猫。

3、sub 潜意识音频/能量音频
用来强化正面潜意识。

4、修行与输入
《因果的真相》《了凡四训》，以及B站、小红书上身心灵领域的优质分享，有选择地吸收。
接受一个基本法则：不进则退，需要终身练习。厚德载物，磨难是在扩容心量。

5、现在就活在热爱里，不要等以后
用五感把自己带进理想人生的感觉里：气味、听觉、视觉、触觉。
主动体验：现在就做那些你本来打算财富自由后、升职后、变美后才要做的事。
比如我一直想等自由后再香薰蜡烛自由、香水自由、有钢琴。所以现在就用小样、偶尔买贵的蜡烛，把自己放在那个状态里。
住处弹不了琴，就先听曲、了解音乐家。
想去的live和旅行，买得到票就走，攻略现在就开始。

显化的本质不是显化一件事，而是显化那种“已经拥有”的感受。用五感去找感觉，就对了。

6、终极心法：把这份好东西分享给需要的人，帮他们解决问题，让他们也受益。
