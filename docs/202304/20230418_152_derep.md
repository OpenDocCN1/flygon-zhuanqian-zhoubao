# 《0 电商经验如何使用兼职低成本快速打爆美团电商》

标题：没碰过电商、靠兼职团队低成本入局美团电商，我一个月做到了10W+

先自报家门：我是龙哥。一直以来做的是高校市场和线下实体，手里的校园渠道和兼职资源比较丰富。去年下半年线下生意受外界影响基本停滞，偶然在龙哥盟看到一篇讲美团电商的帖子，这才第一次对电商有了真实感知。

因为常年带兼职团队，我最不缺的就是“快速把人力组织起来”这个优势。看完帖子后没有犹豫，直接小成本试水。没有电商背景，也没有现成打法，全凭“先下场、再优化”的思路硬闯。结果比预想中顺利，进场第一个月，收入就冲破了10W。

这件事让我最大的感触是：有时候能带你入行的那个人，比你自己埋头摸索重要得多。所以格外感谢刘家齐大哥的分享和邀请，也谢谢龙哥哥让这么多圈友看到机会。具体操作细节我放在飞书文档里了，想深入了解的可以直接去看。

评论区里刘家齐大哥给我捧场，我说都是刘总带得好。龙哥哥也建议他可以再写一篇，给新来的圈友讲清楚美团电商目前的现状、之前航海圈友的战绩，以及现在进场还值不值得。如果这篇更新出来了，应该能帮更多人少走弯路。

如果你也是电商新手，手里有能快速调动的兼职人力，或者有线下资源可以转化，美团电商确实值得认真了解一下。
