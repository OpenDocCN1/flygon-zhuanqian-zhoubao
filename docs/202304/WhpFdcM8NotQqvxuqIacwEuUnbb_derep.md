# 一、龙哥对各航道项目的说明

直接沿用龙哥的原话整理：

2月航海你会选哪条船？

篇幅不短，但对要报名的朋友很关键，请务必耐心看完。

上课开始了，各位同学准备好记录本，我来点一下二月的航海重点，周六要点名。

先纠正一个常见误区：参与某条航海并不是只有想学新东西的人才需要，已在实操的人同样适合报名。正在做的人可以来看看同行做法，认识更多伙伴，也能把自己的经验分享出去，互相启发。

航海主题预告后，有圈友私聊我，说之前跟船找到了方向也有了收益，想在这个赛道持续深耕，有没有更长期、更专属社群的进阶版？

可以，有这个需求就满足。等手头事务告一段落，我会安排深耕版航海，服务想在单一赛道持续放大的朋友，当然是收费的，而且价格不会低。既然已经验证方向并有回报，花这笔钱是愿意的，对吧？

深耕版还没上线，这次先正常推荐本期航海，下面依次介绍选题，请配合理解我布置这些主题背后的逻辑。

一、🛰️/视频号赛道
1. 视频号带货与快团团社群拼团
这两条玩法已趋于成熟，圈内已有不少人变现，赚多赚少取决于执行力，专注投入月入数万的机会不低，少数高手可达月入六位数以上。
2. 朋友圈运营与社群运营
只要把公域流量导进私域，精细化运营是必修课。做得好坏直接决定私域价值高低，大多数人都在及格线以下，流量看着大实际转化很差。
本次社群运营模块特邀条形马老师共同撰写手册，系统拆解社群运营的底层原理。
3. 👸号爆文创作
核心不在于追求爆款，而在于🛰️调整分发机制后，多版块推荐带来的垂类增量，诸如中老年情感、明星八卦、壁纸表情包等，阅读量会显著提升，依靠流量主即可形成稳定现金流。
另外可从抖音等平台导流到👸号，再通过流量主变现。该方向考验选题判断与快速产出能力，强者多采用矩阵化、产品化、外包化打法。

二、📕/美团赛道
1. 📕爆款笔记与📕IP
📕热度持续升温，外训越来越多，去年我带几千位圈友入场抓到窗口期，红利不会永远存在。抓住机会的人请记住：赚钱时别小富即安，要all in放大投入与精力，眼下赚到的钱更多是平台红利而非个人本事，窗口会关闭。
两条船思路相近，边学边做边复盘，无论是新手还是已在操作，都可继续报名。
近期有位圈友会分享他如何做到日引流万粉，供大家参考差距。
2. 📕店铺
目前有实操案例，在📕开店起步可无货源，有基础后可聚焦垂类深耕做专业店，需配合爆款内容，IP加持更好。
整体而言，矩阵化才是赚钱关键。把月入1万的模式放大100倍就是100万，中间要跨过无数门槛。
3. 美团电商
逻辑与📕店铺相似，正值电商平台对商品与店铺考核相对宽松期，无货源搬运多被睁一只眼闭一只眼，是草根的窗口。
美团正大力做电商，平台开店机会增多，据反馈相比几个月前星球刚有人分享时，现在竞争已激烈很多，新手入场难度上升。

三、抖音赛道
1. 抖音SEO
搜索流量放大带来生态级机会，SEO相关玩法将在抖音重演。本期会讲基础原理与实操，商业机会需要大家自行挖掘。
2. 抖音高客单服务/图文引流/游戏推广/小说推文
这几条都是稳定有人在赚钱的老赛道，之前开过多期航海或有大量精华帖，每个方向都有人在同时变现。已在做的别轻易换，不确定选哪个就随意挑一个，都能有产出。

四、趋势/出海赛道
1. AI绘画/ChatGPT
我强烈建议所有人学会并熟练使用ChatGPT，最好达到高手水平，这绝对是生产力工具。AI绘画也很推荐上手，一晚能入门，后续精进慢慢学。
2. Web3.0入门
仅针对资产体量较大、对完全亏损无影响的圈友做的非责任建议，做少量资产配置即可。Web3内部机会很多，新手多为猎物而非猎人，请做好自我保护。
3. TikTok短视频带货
原计划做TikTok Ads爆品航海，评估后难度过大，先延续短视频带货航海，已在做或想做的人可一起交流。
4. 英文工具站
长期来看这是闷声发财的赛道，年入千万美金并非不可能。如果我不做龙哥盟，我会去做英文工具站。门槛在于综合技能要求高，需要产品运营与技术经验，适合评估后选择。

五、实战技能/个人成长
1. 时间管理与运动锻炼
按需报名，自行选择。
2. 资料整理
单独强调一下。
很多圈友缺乏专业知识与输出能力，属于只看过猪跑没摸过猪的人。
比如让你设计一套社群运营课程，你做不出，但让你在网上搜集整理优质的社群运营文章并清晰呈现，你大概率能完成，我愿意为此付费，因为能省下大量时间。
所以没有专业背景的人，学习资料收集与整理的技能，这类脏活累活整理好的成果，反而有人买单，因为大多数人太懒。
3. 线下实体引流
疫情后线下实体正重启，2023年线下增长明显，流量竞争加剧，商家愿意为引流推广付费。学会此航海，有实体可自用，无实体可做服务。

六、链接/交流/学习
1. 精华共读
读近期的精华，质量很高，也感受圈友能量。
2. 风向标共读
强烈推荐。如果你想知道我的商业嗅觉从哪来，我会说熟读风向标三千条，你的眼里全是机会。这是练商业思维的船，压力不大，跟随做笔记即可。
想找没多少人知道的闷声发财项目？龙哥指向风向标。
3. 同城聚会
航海期间会组织4-8人的小型同城交流会，复盘2022，聊聊2023赚钱计划。想在本地认识常联系的圈友，可从这次报名开始。

以上是本期航海的简单介绍，希望对你有帮助。

一句话总结：在一个正确的圈子里，保持心态，跟着学习、开眼、实践，多分享多帮助别人，赚钱是自然结果。但高手背后多年积累，积累的内容无非就是上面这些。

预祝报名顺利，船上见。

# 为什么最终会锁定这七条

经过两轮筛掉，剩下快团团社群团购、朋友圈运营、👸号爆文写作、图文引流、游戏推广、小说推文、AI绘画/ChatGPT。

说实话我选它们有一个最直白的共同原因：现在太缺钱了，收入来源几乎为零，再不搞点生活费就要回去打工了。

前几天龙哥回复圈友“做什么能赚100万”时说得很透：

第一步，给我转5万，我告诉你一个稳赚百万的方法；
第二步，玩命执行。

第一步占10%，第二步占90%。
https://t.zsxq.com/0bRq3lCD4

第一步是高手带路，这七个方向都是被认可能赚钱的。第二步是死磕，选定就全身心干下去。

龙哥也常说，一个项目别人能赚100万我赚不到1万，原因只有我不行。不行的根源就两点：看得不够多，试得不够多。
https://t.zsxq.com/0bFuu3vAS

涛哥也讲过类似的意思：实干的人比研究的人更容易赚钱。研究家会想这个赛道红了没法赚了算了吧，实干家直接上手干了。赚钱项目库里大部分项目，月入两千是有手就行，关键是真的去做。

我自己也挺典型的。20年年底就知道知乎好物，21年中期大家都在唱衰的时候，实战群里一个新手一直坚持，最后一个月好几万。22年初我偶然打开知乎，看到一条21年初写的文章在22年初给我带来了38元收益。为什么我当初不坚持下去？说到底是执行力差，秒执行能力太弱。赚钱里没有赚不到钱的人，只有不愿意执行的懒人。

心理建设做完，开始七选一：

①快团团社群团购、②朋友圈运营、③👸号爆文写作、④图文引流、⑤游戏推广、⑥小说推文、⑦AI绘画/ChatGPT

从赚钱可能性来看，⑦AI绘画/ChatGPT排最后，相关能力我太弱。②朋友圈运营排倒数第二，它本身不能直接变现，还需要有产品兜底，我现在没有。

剩下五个，①③属于🛰️系，④⑤⑥属于抖音系。

①快团团能更快拿到现金，但需要从零学，还要经营信任和引流；
③👸号爆文是我现在就在做的，知识储备能复用，有协同效应。
