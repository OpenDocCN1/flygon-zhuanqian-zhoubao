# 山城首聚圆满，赚钱重庆线下局已落幕

文 / 辰奚 2023年4月14日

给正在关注赚钱的山城伙伴们报个好消息：经我们筹备的重庆首场线下交流，已于4月9日顺利完成。久聊于屏幕前的熟面孔，终于坐到了同一屋檐下，面对面碰撞。

一切的开端要追溯到3月25日的全国见面会。那次活动后，各地伙伴纷纷自发组建本地同城小组，重庆这边响应同样迅速。一个🛰️群从开创时的寥寥数人，短时间内壮大至四十余人。人数攀升的热度也点燃了线下相见的念头。经过群内多轮讨论，我们敲定了日期，决定先把这第一场聚会办起来，为后续的山城活动探路。
