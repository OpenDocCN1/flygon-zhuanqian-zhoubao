# 普通人也能做付费社群：我用2个月把19.9涨到199，收了200+人，变现近万



大家好，我是新侠。本职工作在苹果供应链的一家上市公司做中层，带20多个工程师和50多个一线普工，平时擅长数据分析和团队管理。副业则是在网上折腾各种小项目。

![](img/2b230eed026590d6a2edde71133e9fd0.png)

今年我突发奇想想做一个创业类社群，一路抄、学、改，最后搭起了一个互联网项目付费群。

用两个月时间，从19.9起步一路涨到199，最后累计吸纳200多位付费会员，总流水9900+。这个数字还没算微信和支付宝的零散收款，算上大概还有一两千。

最初用的是一个系统店铺，后面换成了小鹅通来运营。

![](img/e949ba3127252b98148203a18925bb89.png)

小鹅通系统截图

![](img/61abca1629b97f389a1b30ddedbf3756.png)

与此同时，在4/2我把整套思路和方法手把手教给了完全零基础的小舅子。

4/6 他就完成了首单，闭环跑通，只用了4天。

![](img/281ea0b54b62b55c555fd8829415c404.png)

跌跌撞撞几个月下来，终于摸出了一条可行的路，也验证了这套打法普通人照样能复制。

下面我就把项目里踩过的坑、解决思路和一些思考完整复盘一下，希望能给你启发。

# 一、初探期

去年下半年开始，我尝试做抖音创业IP，用PPT拆解项目来做内容。

就PPT这件事，我自认在同类博主里能排到前5%，毕竟在上市公司干到中层，每天跟国内外客户开会，PPT做不好真的不行。

![](img/9fcc1dbc470ecad196bfdefcf48848b1.png)

这个赛道的战绩是：首条内容3000播放，第13条冲到6.1w自然播放，第20条直接被封号30天。

![](img/6e56254a13061d4d555d1480431fab3f.png)

![](img/c5b23027741d81122f1b9f61ec22b6e2.png)

工作很忙，我基本每天晚上8点后下班，用2小时做PPT、配音、剪辑。之前已经丢过2个号，也没赚到一分钱，心态差点崩了，恰好公司又一堆破事，就先放下了。

不过这段经历也没白费：

1、系统学习了抖音IP的玩法，对互联网项目的前端引流和后端变现有了自己的框架。

2、坚定了要做创业赛道，目标人群就是创业和网创用户。

3、确定了最终想做一个创业类付费社群作为核心产品。

# 二、第一次试水，免费群

2023年1月

引流方式：

当时做法很粗暴，就是微信爆粉+群发广告，最后拉了100人进群。

社群交付：

用微信群为主，搭配一个免费的知识星球放一些创业感悟和项目教程。

![](img/eea510d814e157ee4c3263de5c4d0251.png)

![](img/25a54cd69cf5c8525ff076e1a67f6f5c.png)

![](img/1012275c76baabafc1e1329996392693.png)

![](img/9cc190cd3bc8a35f6dcdb2dc9b476e77.png)

遇到的问题：

1、群里几乎没反馈，要么发广告，要么没人说话，全靠我单向输出，特别累。

2、付费意愿还没测，但感觉大概率很差。

我的判断：

1、免费群随时可以停，没有负担，干脆先停掉，考虑收费模式。

2、一个项目起步就做不到变现，那就没必要启动。

# 三、首次付费，19.9创业群

2023年2月

引流方式：

知+

在知乎看到有人发创业群文章，里面嵌知+卡片，引到微信私域再付费进群，价格在9.9到19.9之间。

![](img/86aa8e18ba817aa078b1fb1696f18dd5.png)

既然产品内核都差不多，我就去拆解了几个同行的路径。

1、大多数是跳👸号，自动弹出付费进群的收银页。

2、少数是直接加微信，靠话术成交。家蒙老师就是这样，他的转化看起来更高，我现在还在用。话术特别真诚，这里分享已获得授权。

![](img/c3d3e0f43d212158f584fc48e5bcb6bc.png)

![](img/0a1f1dc02e4ca9cce50ef1d599a715d8.png)

社群交付：

微信群+网课系统。网课系统既能当收款页，又有论坛功能方便沉淀干货。知识星球最低50元起，我这个群才19.9，用不起。

![](img/1a09375ef81cac0045091f837b504f2b.png)

![](img/411164d88592d584e8ee103360e6f143.png)

遇到的问题：

1、知乎投放素材很难过审。后来参考家蒙老师的写法，减少对付费群的描述，增加对群内具体项目的介绍，通过率才上来。

2、投产比亏损。投300+，进群收入约100。算上👸号留存的30+，创业粉单价10元左右还能接受。

我的思考：

1、19.9我还能扛，但要上合伙人、代理，这个价格没吸引力。

2、缺乏0成本或正向投产的引流方式，规模化很难。

3、用户其实愿意付费，我发过一个199的打卡项目，11人报名。

# 四、涨价到39元的创业群

2023年3月

引流方式：

创业图集号，投放抖音、小红书、快手、视频号。

3/18加入赚钱后，看了航海实战的创业项目IP手册，结合之前的高老师课程，对引流有了新理解。PPT拆解太费时间，图集号一篇15分钟搞定，更适合我。

抖音和快手效果不错，单号每天能给👸号带来10-20人。视频号前期有扶持，两周后因文字多被限流。小红书目前没起量，还在摸索。

![](img/642b558e85ad8d23a38bb5a425c70c05.png)

社群交付：

换成小鹅通。之前网课系统的论坛免费用户也能看，体验不好。小鹅通旗舰版自带圈子功能，和知识星球类似。门票低于50元知识星球不支持，所以先用小鹅通。

缺点是鹅圈子不能直接跳转网页，要复制到浏览器，体验不如知识星球App。长远看价格上来后还是要转回知识星球。

遇到的问题：

1、整体挺顺的，我把社群当口碑产品做，服务超预期，好评很多。

![](img/f298980bc2aaad703eead56225d62805.png)

![](img/14fe5e03107aa7e6db5aae422795ed5c.png)

![](img/379dc30c1cca6e432ff9324d3dd4b8f0.png)

2、推出598的项目打卡，卖出9份。

3、开始梳理前端后端体系和合伙人机制，想把盘子做大。

# 五、再涨价，199实战营

2023年4月

项目梳理：

3月底用2天时间重新梳理了前端+后端，并把社群价格提到199。

先看思维导图：

![](img/e6c34fe3d6d8f9341c7332ff705aa1c5.png)

1、 流量端

*   个人IP

抖音图文+PPT拆解，是基本盘，必须保留。

*   创业粉快速引流法

核心就是去项目直播间连麦，用话术把观众拉到私域。只要话术对，引流非常猛。经历多轮优化后，结论是少套路、多真诚。

![](img/988a3389726ec13f378995f746b5ba8e.png)

从直播间加来的粉丝，后续的话术和朋友圈配合很重要，是成套打法，这里后面会讲。

除了自己连麦，还可以做流量合伙人，招兼职去直播间读文案引流，按效果付费。我还没实操，但已看到团队在做，可行性很高。兼职者一天引50人就能有不错收入，我这边用极低成本拿粉丝。

*   其他流量玩法 付费和免费的后期都要测。知+我还没死心，打算再测一次，有结果再更新。

2、转化

*   营销

话术+朋友圈+👸号。

话术分进群后、成交后、未成交三套，经过测试整理成SOP。

现在的打法：先发直播间项目的介绍，额外送项目教程，绝不提付费社群，在福利里埋钩子引导看社群介绍。

![](img/03b4d6e9be1a2405114a3f2d2d0cd2cb.png)

朋友圈营销也很关键，以前我最讨厌发朋友圈，现在发现转化里近70%来自朋友圈。

*   成交

分佣设二级。喜欢渠道收益的逻辑，我也希望合作伙伴能从渠道获益。

合伙人机制暂不开放，需要把社群销售作为主要盈利渠道，达到一定GMV后才升级，有资格招合伙人和拿渠道收益。单纯靠拉人头不做项目，容易变割韭菜。

成交后流程：发交付手册、权益、群规、收集信息拉群欢迎，标准流程。

![](img/5f8f72b70c06d0a2da85dcf6b36c79da.png)

3、产品

*   199社群

我刻意弱化社群的个人IP属性。如果我是合伙人，卖一个个人IP太强的产品会心里膈应，除非IP维度极高。所以社群微信服务号、小鹅通都去掉了个人微信、👸号等联系方式，只留一句“联系你获取资料的微信对接”。

涨价到199后，之前的轻交付撑不住“超预期”。要么持续高质量打卡，要么请嘉宾分享，我目前都做不到。于是选择对接2-3个落地的搬砖项目，让成员只要执行就能有收益。同时坚持每日干货分享和信息差输出。

*   高客单项目

还在规划阶段，但大方向定了。社群做好信任和交付，后续高客单成交会顺很多。

项目手册：

参考赚钱航海手册，开始做自己的项目手册，为招募合伙人铺路。创业项目IP部分框架借鉴航海手册，内容是自己实操总结。

![](img/40867675b7ce5610d645128ffc5a136e.png)

操作步骤、连麦话术、加人后话术、成交话术全部标准化。

![](img/eb7d167af39ff9b173fd446b3f5272ef.png)

第一个合伙人测试：

拉小舅子入场，他之前完全没接触过互联网。

4/2一天时间做网创认知和项目操盘分层讲解，把项目手册过一遍。讲解过程没课件，边讲边梳理，也算为本文做准备。

网创认知

*   互联网能赚钱

对零基础的人，先建立“互联网能赚钱”的信任，否则没法继续。

*   走正道，不碰灰黑黄

要敬畏法律，这是做人的底线。

*   向有结果的人学习

抄、研究、创造、发明，制造业和互联网的底层逻辑一样。

*   赚钱就是复制

能赚1块就能赚100块，要么自己重复100次，要么找100个人复制。

*   学会为知识付费

聪明也能成功，但会绕路浪费时间，有时花钱最省事。

项目操盘层次

*   自己做项目

分搬砖类和积累类。问卷、点赞属于搬砖，出卖劳动力；做自媒体、电商则能积累经验。

*   卖项目

项目跑通后整理成SOP卖出去，收益更高，只要服务到位不算割韭菜。

*   做渠道

卖项目同时辅导用户变现，分成收益。

*   做体系

不自己卖，让别人卖；不自己铺渠道，让别人铺。

*   投资

看人下注，提供人脉、流量、资金。

结果是4/6第四天，他报喜首单199成交。

# 六、当下的问题与思考

1、分销问题。

为后续分销，我用小鹅通收款，即使自己收。但很多人直接微信转账，我得退回去再发二维码，和客户说微信不收，体验很差。咨询刘驴老师后回复：自己玩怎么收都行，招代理就必须体系化。

![](img/4a54eb694da426c9e62bb34a6ef1071b.png)

![](img/f719d20f7ca4c0d9d837b70509258843.png)

![](img/9f37aa55aa647f15af878dc4000b26cc.png)

2、社群对接项目从打卡变免费对接，社群直接收益会下降。打卡体验一般，会影响成交率，这是个需要权衡的点，先标记后续再优化。

3、资源对接不足。优质项目我有几个标准：免门槛、能给管道收益、最好有二级分佣。免门槛一条就淘汰一大半。

4、基本盘不能丢。最近忙别的没更新视频和图文，流量立马掉。要提醒自己基本盘是根本。

另外PPT拆解账号的赞粉比约1.5:1，图集号约5:1，IP属性更强。后续做哪种还在犹豫，👸号日更也没做到，👸号其实也是很好的私域工具。

问题不少，但创业就是边做边改。先动起来，一个一个解决，结果不会差。

“必成”！加油！
