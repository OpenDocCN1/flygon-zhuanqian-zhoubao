# 普通人的赚钱418拉新复盘：从20人到179人，这套路径真的能复制

分享人：IDO老徐

先说背景。去年我第一次接触赚钱418拉新，折腾到最后成绩也就20人左右。今年活动才开始三天，目前已经拉到179人（见图1）。短短一年，多出来150人的增量，靠的不是天降流量，也不是短视频直播，而是下面这些笨功夫。

第一，先攒信任。去年我集中精力做了一个百元内的案例库，前前后后积累到5000位付费用户，并且把他们的🛰️都加上了。这批人，成了我今年拉新的基本盘。

第二，给邀请人备足福利。这次我准备了七重邀请权益，权益明细见图2。

第三，别单打独斗。我清楚自己就是个普通人，没什么大流量，又不玩短视频、不出镜直播，一个人推来推去效果有限，所以特意找了一批合伙人来一起推。给合伙人的权益也给得很足，具体见图3。这些人从哪里找？就是我每天更新的👸号、知识星球和付费社群。

第四，凡事提前做。看图2、图3的发布时间就知道，3月17日我已经把整套玩法和福利方案抛了出来，提前了半个月做准备。

第五，把运营交给靠谱的人。活动落地环节太多，一个人根本忙不过来。我从付费社群里请来飞巴当操盘手，他有实操经验，之前也帮我操盘过活动；另外又安排了5位群管理员，负责围观群秩序和内容分发。这5位小伙伴全程跟下来，直接对齐了玩法，最后也加入了赚钱。

第六，用日更换来持续积累。过去一年，我把免费星球日更到了1万人规模，慢慢吸引过来一批潜在用户。

第七，👸号每天更新，也持续带来了一些新伙伴。

这套东西拆开看，就是一条普通人也能模仿的复刻路径：

- 照着上面的思路走，只要真去执行，拉来10个人并不难。
- 再按这个节奏沉淀一年，一年后冲击百人拉新量级也是有希望的。退一步说，哪怕没有418这类节点，这套逻辑平时照样能用。数据只会更好，关键还是看执行力。

实话实说，我目前还在上班，没有太多时间精力做精细化运营，很多地方做得比较粗糙，转化率其实还能再往上提。如果你时间更充裕、细节做得更细致，大概率会跑得比我好。

以上是一点阶段复盘，希望能给即将开始拉新的朋友一点参考。
