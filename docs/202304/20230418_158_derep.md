# 从副业到县城第一：一位宜昌姑娘用私域把家乡腊肉做成爆款的自白
作者：龙哥

最近在赚钱群里看到阿黛的分享帖，点赞破百，标题很实在：《我是如何将腊肉卖到县城同类产品 top 级的》。

她自称赚钱里的萌新，却已经用私域把家乡特产做到了本地同品类的顶尖位置。

阿黛是湖北宜昌的土家族人，现在定居郑州。早年她的主业是房地产开发管理，之后自己创业做过销售公司。卖家乡腊肉这件事，从 2015 年起一直是她的副业，而且每年只集中卖三个月。就是这样一份“业余”的坚持，让她在 2018 年把自家腊肉在县城的同类产品里推到了头部。

她自己也坦言，在赚钱这种大佬扎堆的地方，这样的成绩拿不出手，但过程对像她一样的互联网小白很有参考价值，所以愿意把实操细节拿出来聊，也希望前辈们多给点指点。


评论区互动也很有意思，有人点赞“针不戳”，也有人反馈需要权限访问，阿黛连着回复说自己是新手正在研究如何设置权限，调试好后让大家再试试。

一个不靠全职投入、只做季节性私域的案例，却能做到本地 Top，值得所有想做家乡特产的小伙伴拆解。
