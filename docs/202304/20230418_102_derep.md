# 新人如何从龙哥盟起步：我的赚钱体系梳理笔记



作者：虚十七
发布时间：2023-04-06

大家好，我是老猪。2019年时我在Shein负责产品，2021年跳到一家出海公司做日活千万级的短视频和工具类产品。最近我终于在龙哥盟里实现了第一笔变现。

刚进圈的新人，很容易出现我当初的两种状态：

一是刷完精华文章和风向标，整个人肾上腺素飙升，仿佛明天就能开单赚钱；
二是每天的输入量爆炸式增长，看完就忘、学完不会用。

如果你也中招了，不妨看看我这份《龙哥盟赚钱体系梳理（新人启航指南）》。

这几天我反复精读了大量精华内容，结合自己的产品和商业思考，把零散的经验拼成了一套完整的赚钱框架。整理过程很痛苦，但也很有收获。目前这版是1.0，权当抛砖引玉，供刚起步的圈友参考。
