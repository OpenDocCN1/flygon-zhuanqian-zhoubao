# 从副业到县城同类第一，我的这几年腊肉经
作者：龙哥



我是龙哥，土家族宜昌人，现在定居郑州，目前是赚钱新人。

年轻时主业在地产开发管理，后来自己做销售公司，私域带货家乡特产一直是副业，从2015年起每年只做三个月，2018年便把县城同品类做到头部。这个成绩在赚钱的大佬圈里不值一提，但作为过来人，愿意把来龙去脉拆开讲给同样起步的新手看。

先放上微店和近年快团的到账图，多数大额是公转私。

阿黛家山货的起步轨迹

老家在鄂西南深山里，挨着川渝边，山高路险。88年才通电，98年我爸那辈硬是挖出一条摩托车道连到矿山公路，再连到318国道。2009年沪蓉高速通了，小镇才算被世界看见，高铁也随后来了。以前去成都得两天，现在几个小时。

小时候嫌山里苦，九岁就寄读，往返几十公里。发誓要出去。后来扎根郑州，十几年没挪窝。

二十出头进地产，先写文案，后做策划，再到营销总监操盘项目。2012年离职干自己的地产顾问销售公司，十几年卖过上百万平。我前东家居易国际在北方挺有名，我也拿过2006年感动人物、2010年郑州市楼盘推动力人物。

地产给了我钱，也给了我做事的习惯和营销的功底。山货是怎么起来的，其实很偶然。

2014年底，我和第一个合伙人分手，分得体面，但钱包和情绪都受损了。那年我已不算年轻，之前拼得太狠，身体透支，2006年查出股骨头坏死至今未愈，也还没生育。2015年我选择休养。

12月和两个闺蜜喝咖啡，她们说你闲着不如网上卖腊肉。回头想，我那时真老实。她们都回过老家吃过我家腊肉，觉得好又不好意思开口，就推我一把。我一口答应。毕竟身上有故土情结，父母那时正跟我住郑州，回趟老家反而更念旧。

我去查资料，才发现我们平常吃的土家族腊肉，已经被《三联生活周刊》连续两年年货榜单推荐。产地很多，我们做法不一样，是用花栎木在瓦屋土墙里冷烟慢熏，色泽金黄不发黑，口感香软，老人小孩都吃得下。文章点名湖北宜昌长阳，最正宗的是榔坪镇。

美食家朋友来家里吃过，后面写书盛赞是“溏心”口感。我整理了文字，设计了LOGO，请了摄影师回山里拍。直接用我的名字阿黛命名，到现在八年了。

这八年也算有一点点成绩，货卖到港、非、法、日、泰等，也在不断修错。但一直没系统梳理，这次借机会做个总结。

阿黛家第一年，我出发去印度前把产品上架了，签证机票都定好了。那年起得晚，过年又早，线上只卖了一个月，我在印度半个月，影响不大。

第二年腊肉季，我刚生完孩子躺在月子里，也照样卖。那时没有山里的发货团队，是先把货一股脑寄给我，我再分装寄出。

第三年又接了个地产项目，营销期正好撞上腊肉季，但前两年打了底，山里的保障班子搭起来了，也顺利扛过。后来猪瘟、疫情，每年都有幺蛾子，都过来了。

有3000个有效🛰️好友，就等于开了一家不用付房租的大店，这成本直接变成利润。更可爱的是它的可持续性，产品年年有，用户年年复购，现金流特别舒服。

这些年地产也在做，卖得再好要账都难，行业普遍被拖。唯独电商，钱先到再发货，是能一直做下去的生意，不用换赛道。

好事多时，难处也多，有些事必须守住，方向有底线才打得牢。首先是品质。

1.     品质是根基，决定复购

核心卖点是什么不重要，品质过关才有复购。

现在信息爆炸，客户见多识广，糊弄不了。乡村产品的卖点多是生态、绿色健康，说了就得做到，不是口号。客户用订单投票，好就一直买，不好买一次还拉黑。

比如阿黛家的腊肉，年猪肉价格飞涨，一车肉从三万多涨到八万多，涨了两倍多。有人建议我换冻肉，说冷库肉便宜。我第一次听说这种操作，企业会囤冻肉等缺货时放出来。我直觉冻过的肉组织坏了，即便按传统熏法，口感也会差，吃得出来。

我也缺钱，降低成本利润立刻多，但我坚持用当年新宰的鲜猪肉。客户能尝出差别，这是地基，不能动。

生态就是生态，不用催熟剂膨大剂，不以次充好，年年同一标准，客户是有感知的。

做农产品免不了看天，有时产量链出问题，这时正好回头把环节的BUG修掉，完善护城河，为丰年准备。

![](img/66a2e38496a03ef521f804ca34a3446b.png)

2.     有规划、有资质，慢慢把框架填满

做事先把目标想得长远点，不是立刻完成，而是步步推进。

就好比考试，一开始想考100，最后考90；一开始就想60，最后只能60。梦想要大，积累要稳。

第一批客户通常是朋友熟人，他们信任你，也愿意背书。但别盯着熟人患得患失，朋友没买就怪他，你认识的人也就那点。真正的市场在陌生人身上，世界很大。

第一步还是靠朋友带头买和宣传，不能辜负这份信任。他们用人品为你担保，产品好，陌生人自然跟着来。市场一扩大，就得摆脱家庭作坊的形态。

我建议办个体户，不复杂，还有免税扶持。好处是单位团采要发票，客户多了也会有投诉要执照食品经营许可，提前备好省心。

阿黛家现在注册了农产品公司，办了食品经营许可。连自家养的猪，也要求去镇上定点屠宰，出入库、熏制、销售都有记录。可查可追。后来硬是把食品生产许可证也办下来了，进商超也没问题。

这些证照是国家监管的信任背书，让产品更正规。

![](img/0b56b2369c3d59d8941fd0bf3ea19f84.png)

3.     包装和体验，是转介绍的关键

确定产品和价格后，下一步是包装。农产品怕磕碰，先保坚固，再谈美观。农产我建议极简，别过度包装，朴素干净让人觉得用心就行。

量少时就按需采购，阿黛家腊肉就是普通牛皮纸袋加LOGO发货，年底才换大礼盒满足部分体面需求。

售后体验要时时在意。东西好不代表可以忽略细节，服务也是产品的一部分，现在选择太多，细节决定口碑。

表姐叔叔帮我发货，从省钱角度想，一个袋子塞三个，鼓鼓囊囊难看。客户收到就不想转赠。我后来规定，1-2个用小袋，3个及以上用大袋，经过测试最合适。

还有次我爸妈替我寄香港礼包，标签贴得大小不一，我回家发现赶紧撕了重贴。

物质丰富，人们眼光更高，返璞归真可以，但审美要跟上。品质加体验，客户才乐意买来送人，主动帮你传播，这就是正循环。

![](img/0c1481a50124eab3da003aaf694b2755.png)

4\. 个人IP从真实场景长出来

个人IP就是让人知道你是个怎样的人，可信、专业、有温度。不是一蹴而就。

对普通人来说，🛰️朋友圈最直接。口号是“个人即品牌”。经营好它，半年到一年效果就出来。

经营不靠摄影技术和文采，靠勤奋和真实。分享山里的风景、自己的生活、村里的活动、产品的生产过程。

生产过程最有故事。腊肉只冬天卖，但故事从小猪仔开始讲。粮食野菜喂养、环境无污染、有机种植、撒种除草、果实成熟，蜘蛛网和果实一起长大、鸟鸣声……不喊口号，用画面让用户看着长大，到成熟期自然想买。陌生人加你也能看到这些，信任就建立了。

农产品有季节性，还可以用场景营销。我是产品的代言人，随时站台。

当季推广之外，我办过山谷产品发布会，带KOL回山里吃年猪饭，杀年猪是土家族仅次于春节的大事。去朋友公司煮腊排骨腊蹄子请几十号员工吃，好吃他们就发圈，和“优质食材极简烹饪”核心卖点一致。

食品也可以跨界CP，豌豆、松茸季节不是腊肉季，但我在美食工作室做腊肉豌豆洋芋焖饭、腊肉松茸洋芋焖饭分享，让人时时想起我。还去西藏林卡、野餐、音乐节做焖饭、做诗会，不刻意但顺手嫁接产品，扩大曝光。

内容节奏我总结成：先发一篇方便转发的开售文章，截图发圈提示；再发订单截图讲故事；第一波发货的场面要渲染；买家秀来了一段长内容，互动要跟上。

朋友圈一天至少5条，少了就沉了。群发硬广败好感。

和朋友关系要妥善，有些圈内有名气的朋友很积极，我就会互动；有些默默买从不提，我也尊重，购买本身就是支持，不能为了流量伤感情。

5.跨界联合，共享流量一起变现

做到一定规模会遇到瓶颈，影响力有半径。很多人有认知壁垒，岳云鹏在相声圈红到发紫，不听相声的人根本不认识。明星都要出圈，道理一样。

突破方式就是跨界联合，共享客户资源。

售楼部招待业主做家宴，我去供应腊肉，原本互不相识的人有了接触。

还有做德国厨具的朋友，锅好看但硬卖不动，需要内容。我家腊肉主张优质食材极简烹饪，理念契合，我出镜拍煮菜视频给他的客户看，他的客户被腊肉吸引，我的客户被锅吸引，转化实现共赢。

联合前先判断客群匹配度，买奢侈品包的人和爱砍价的人不是同一群体。

![](img/abdc1741e3420317328872e9714cb7a9.png)

6.建渠道降成本，做可放手的生意

我的产品不适合上淘宝京东，门槛高、投入大，几十万起步，非标品产能也扛不住大流量。

微商说“睡后收入”，就是建一支稳定销售队伍，自己不干也转。但这很难。微商产品利润极高，成本二十几卖三四百，利润空间支撑分级。农产品非工业化，品控严格产量有限，也囤不了货。

那就找有固定客源的人，让利合作。

茶叶做得好的朋友，喜欢烟熏味的顾客会接受腊肉，我让出利润给她推荐；一个有关系脉络的姐姐，能中事业单位年终福利单，我把腊肉放进礼盒提升价值；京东管采购、美食博主，都谈好利润代发货处理客诉，也成了销售大头。

个人精力有限，必须借助这些力量，才能卖得比自己更大。

![](img/c26a9651d6963e4fd83c71f31426760d.png)

7.公关与售后：换位思考，给出超出预期的解法

销售会遇到各种奇葩问题。

我以前以为全世界人都像我们土家族一样天天吃腊肉，后来发现很多人第一次吃。北方客户收到原生态连毛没去的腊肉完全不会处理，只有冬天才想吃，再加上过水真空包装夏天也不好运，所以主战场就定在一年两到三个月。

客户会问要不要放盐，说明书写得很清楚，要出水就是去盐，还是会问。有人问辣不辣，我们腌肉只放盐，腊肠才放辣椒。还有人问是不是连袋子一起隔水蒸，包装上明写开袋即烹，蹄子排骨都是去毛清洗切块真空发货的，也有人真不看。

前几年我分分钟想翻白眼，现在心态好了。换位思考，疑罪从无，给出比预期多一点点的解决方案，是售后也是品牌形象。

有些你觉得再平常不过的小事，对很多人来说却是新鲜的，口味这件事更是仁者见仁。比如酸甜咸辣的阈值，每个人感受都不一样，经常有人追问到底有多酸有多辣，听起来有点无奈但很正常。这种时候别急着辩解，耐着性子把门道讲明白，把客人教明白了，他才可能真心喜欢上。每一个被你讲明白的客人，都是你手里的份额。

另外，物流时效这口锅也很常被背。时效我们管不了，但心态可以管。你得主动帮忙查、主动跟进，让客户感受到你在解决问题的态度。要是包裹真的丢了，先别跟他讲流程，先补发再去跟快递公司扯皮理赔。别把客户推给快递去对峙，那体验直接崩了。

说到体验，这就是典型的一环。我自己就经历过。爸妈生日定的蛋糕，商家找的跑腿送货，路上师傅一颠，奶油全糊了，恶心到不行。爸妈没打开就签收了，我回来一看直接投诉。结果店家回我一句，去找跑腿吧。这句话一出，我就彻底拉黑了这家店，之后再没买过任何东西。

一年下来，家里长辈生日、朋友聚会、日常的面包点心，加起来就是一笔很可观的消费。丢一个客户可能无所谓，但这样的方式流失十个一百个，就是大出血。接到投诉，先把自己换位过去，如果是我遇到同样情况，想投诉，我会希望对方怎么处理？选那个能让我舒服的方案就行。

其实大部分客户都很讲理，真正想占便宜、想讹人的只是极少数。真碰上了，认了就认了，先把面子给他稳住。至于以后要不要继续做，可以再观察。俗话说的好，嫌价格贵的人，往往才是真买家。事儿多的不一定不付钱。所以心态放稳点，多一点包容，多一点大方，只要你的解决方案比客户预期的好一点点，他就有可能变成铁粉。一次糟心事也能变一次口碑。

道理谁都会学，关键是会不会用。照本宣科没用，得挑对自己有用的点，结合实际情况灵活变通。

以前央视天气预报前后广告要几个亿，现在谁还看电视。变化这么快，还死守着老教授几十年前的营销课，就有点不合时宜了。

市场才是最实在的老师，不用迷信什么权威。尊重常识，沉下心去真实接触自己的客户，效果自然不会差。
