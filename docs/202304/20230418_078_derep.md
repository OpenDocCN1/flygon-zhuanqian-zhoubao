# 别小看闲鱼卖旧衣，她靠这个攒下了10万+
作者：龙哥

你有没有想过，衣柜里那些“买时心动、穿时冲动”的衣服，其实藏着一笔隐形收入？

今天想跟你分享一个很实在的案例。一位叫阿黛的朋友，起初也是实体行业出身，经历过红利期，也挨过行业下行的苦。转型路上卖过家乡腊肉，一斤赚几块钱，跟以前年薪百万时的体量完全没法比。但正是在这种落差里，她练出了一个习惯：**随手能赚的小钱，就顺手去赚**。

这个习惯带来的意外惊喜，发生在一次换季整理中。

郑州的春秋短得像开个玩笑，很多衣服一年到头也轮不上穿一次。她随手拍了些照片挂上闲鱼，本来没抱期望，结果前前后后竟然卖出十几万。更让她意外的是，这行还有不少姑娘专门在做，收入也挺可观。

这事听起来简单，但背后有几个点很值得琢磨：

1. **别只盯着大钱**。做成大生意之前，先让自己具备赚小钱的能力。小钱试错成本低，没成也不亏，一旦哪个方向反馈好，就能复制放大。

2. **落差是常态，接受它就是成长**。从管上亿销售额到一斤腊肉赚几块钱，心态调整过来后，反而更踏实了。

3. **别光想，先动手**。起心动念的那刻，就去做。换季整理、拍照挂链接，这些都是顺手的事，但做着做着，机会就来了。

4. **闲置也是资产**。不用的东西放在那里只是占地方，让它流动起来，既能回血，也能让需要它的人捡个便宜。闲鱼上甚至有人专门收二手再转卖，一转手就是几千块的利润。

说到底，真正的财富不是一锤子买卖，而是你对待每件小事的态度。小钱赚得顺手了，大钱自然会找上门。千里之行，始于足下——这句话放在赚钱这事上，再合适不过。

如果你也想开始，不妨就从整理一次衣柜开始。
