# 为什么你在赚钱圈里一直没看到钱？

原文：[`www.yuque.com/for_lazy/thfiu8/em56vkahgl8ixahm`](https://www.yuque.com/for_lazy/thfiu8/em56vkahgl8ixahm)

作者：李鲆  2023-04-05

进到赚钱，很多人期待的是躺赚，结果是真亏。钱这件事，本质上是你综合能力的兑现，是脑力、体力、运气和持续投入叠加起来的结果。付出不到位，回报自然到不了位。

赚钱既要动脑子，也要动手，更大头是耐下心来当苦力。市面上主打轻松搞钱的，基本都是拿来诱惑人的话术。

智商中等没关系，关键是方法对路，并且能扛住时间。只要方向不偏，长期主义几乎能把任何事做到位，包括在赚钱上实现变现。可惜最难的永远是坚持下去。

收入的增长轨迹通常是先慢后快，像滚雪球。起步阶段流量少、收益低很正常，熬过积累期才会出现跃迁。但多数人扛不住前期没反馈的焦虑。

做成一件事至少需要90天来验证，可现实是绝大多数人连21天都撑不住，更别说三天。没有即时正反馈，意志就开始松动。

刚入圈就花钱买课、买工具，花完就开始怀疑自己被收割，满脑子都是负面。那这笔钱基本等于沉没了，你的心态也已经先输了。

想得太多只会原地内耗。行动前你会有无数顾虑和方案，真正开始上手后真正卡住你的不过三五件小事。

不懂装懂最容易折腾。还没成为领域的内行之前，自己的灵感和创意大部分都会变成踩坑的代价。

一点小挫折就想撤退的人，注定和结果无缘。

总习惯抱怨环境、怪平台、怪大佬的人，永远找不到改变自己的入口。

还有一种是表演式学习，看似很卷实则在自欺欺人，行动是假的，努力是摆拍的，这种伪勤奋换不来任何现金流。

熟练度不够就是等于不会。不会，自然赚不到。

鲆说：去找有结果的人照做，选定一个赛道深扎进去，亲手把事情做脏做透，允许自己试错直面问题，用量来换胜率，用时间来换复利。对普通人来说，这就是唯一的成事逻辑，也是唯一的变现路径。
