美妆赛道已经卷到发紫，还能分到钱吗？我之前一度觉得美妆MCN早被做烂了，变现窗口基本关上。现实却恰恰相反，只要你吃透门道，千粉级别也能开始赚钱。

# 一、自我介绍

我是美妆编导小萌。独立孵化过不少美妆达人从0到1，也带过10万到100万的跃进，更操盘过头部达人，双十一三个月纯广告收入近两千万【不含直播】，还帮过很多素人做全广告运营。

孵化下来发现，素人孵化其实是可以复制的流水线，核心是方法对了。

# 二、美妆行业的现状

美妆孵化现在是名副其实的红海，甚至可以说红到发黑。但只要品牌持续放钱，市场盘子就会一直扩，玩法也会层出不穷。

说白了，美妆【本文所指美妆包含护肤】就是女性刚需的消费项。美妆博主天然就是个割韭菜的赛道，素人爱好者靠它赚点副业也是常态。

现阶段，千万粉左右的顶尖美妆博主基本还是那一批人，想上去需要天赋、爆点时机和大量投放加持。

垂类美妆能到千万粉的，通常都沉淀了1到3年的内容积累，很少有速成的。

中腰部则多是老牌达人或专家型账号，比如护肤博士、专业化妆师这类有背书的。

最适合素人切入的是小体量达人，比如近两年火起来的学生党美妆号。几千粉到几万粉的垂类小号大量出自这里，那个年龄段的女生既青春又爱玩手机，追求变美的时间和欲望都很足。

总的来说，这块蛋糕很大，抢的人也多。

# 三、红海情况下，如何做一个有变现能力的美妆账号

（1）情绪驱动型，人设精分+搞笑表演
这种博主个性极强，靠情绪冲击带动观看，内容自带加成。

早年我们带没什么特色的素人时，最常用的人设就是精分美少女，简单说就是好看的搞笑女。

这种人设因情绪张力强、感官刺激足，至今也没被淘汰。

举个例子，我带过一个达人，蓝海期做到80万粉就卡住了。后来我帮她重定位成帮学生省钱的种草机，人设精分，内容风格走闺蜜悄悄话分享，包装上用B站陈吃饭那种荧光大字综艺风，精准锁定13到23岁的学生人群。

内容全部围绕学生党展开，很快出了60万+点赞的爆款，粉丝破百万。之后持续强化宿舍场景、买校服、沉浸式学姐感，持续输出开学宿舍好物、平价面膜、过年穿搭等十几万到百万赞内容，涨到300万+。

达人本身上限可能一般，但只要策划抓准人群痛点，持续深耕吃完这波红利再迭代就行。

现在红海下，这类账号策划和表演要求更高，不再是只有精分性格就能火，需要性格+干货+新形式的复合。比如陈圆圆超可爱就把精分性格推到极致，叠加社牛感和同框连麦教学的新形式，涨粉极快。

总体来看，精分搞笑类情绪冲击强的账号，入门门槛低，回报也快。

（2）技术实力型，化妆师或护肤专家
很会化、懂专业知识，视觉冲击力足。即便口播一般，通过配音和剪辑也能补足。硬实力放在那，至少能立住一个美妆基本盘。

一点提醒：妆容展示要避开擦边，不要做给LSP看。受众必须是女性，内容才能延展到好物分享、种草拔草。

比如零吧啦，早期以变装为主，但她本身妆前妆后对比冲击力极强，后期在爆款变装基础上加入彩妆好物分享，再逐步加教程、小技巧，比如新手轻泰妆、保姆级遮瑕。

从纯展示到展示+口播，再到加入海边度假Vlog等生活片段，提升可看性和粘性，满足了爽感、利他性和趣味性。

从商业化看，技术型账号每条视频广告位很多，妆教一步一个产品植入自然不突兀，种草力强，反馈也好。

（3）重度囤货型，时髦的消费者向KOC
这类人对买买买上头，爱逛、爱测、爱冲浪，会第一时间尝试流行产品。

其实把舔狗行为升级，就能变成资深体验官。对某类品类或审美有偏执，买遍全网，也就成了意见领袖。说出来的话虽不一定全对，但声量大，持续经营就能做大，还能不断迭代。

以温仙女为例，身边很多人囤面膜都是箱数的，但很多美妆博主自己用过的都有限。温仙女始终走在潮流前端，会看网红在用什么，主动囤货测试，也会接我们的安利去测评，并给出主观输出。

她试过的品类极多，即便抛开大博主身份，也是典型的重度消费者。数据上观众最爱看她的开箱、好物分享和雷品吐槽。所以我们把开箱吐槽固定在排期里，稳定输出后，还延展到美甲、穿搭等女生爱好的领域，出了74.4万赞的美甲爆款。

类似的海淘小众开架等细分切入点，也能先做深再做宽。

# 四、 什么样的人适合做美妆账号

（1）有眼缘，也就是颜值在线的青春美女。平台里随处可见的网红潜质素人就是货源。
（2）有记忆点，也就是“丑”的有特色。脸上带硬伤，比如痘肌、眼睛小、嘴大，不化妆很邋遢，一化妆判若两人。屏幕前的感官动物吃的就是这种反差。
（3）会说话的素人。能逼逼、能聊，能用情绪冲击留人，像当年的陈圆圆。

选人时我们会让应聘者发一段自拍视频，并填一份超详细的个人资料表，从基本信息到恋爱次数、分手原因、喜欢的明星、爱用的产品、讨厌的产品、最看重什么、梦想是什么，全盘问清楚。

目的就是判断她适不适合做博主，适合什么定位，最好能提炼出1到3个关键词，把人设收窄。

# 五、如何做美妆账号的内容策划

首先做基础定位：用一句话概括账号，定主谓宾。

比如张一一就是深唇口红种草机，简介直接写定语。定位清晰，别人一眼就知道你在做什么、赛道在哪，精准度决定上限。

再定表现风格，可以顺着达人个性，也可以人为创造。

然后定艺名，多备几个，搜一搜抖音看重名情况。叠词一一二二好记，但现在更推荐独特但好打的字，符号少、拗口字少。

关键要想清楚你要收割谁，至少明确性别和层级：学生党、时尚白领、贵妇等。

接下来找对标，模仿是创新的起点。像造星一样给达人一个身份，美妆有学生妹、高冷御姐、毒舌gay哥等。可以跨平台对标，风格对标一个、内容对标一个、包装对标一个。

（1）热门玩法

抖音上美妆相关黄榜热点很多，比如春天就必有早春穿搭、旅游必备好物。当热点出现时立刻跟进，流量精准且有机会上榜借势破圈，这需要预判能力。

（3）过往爆款选题

女生三大诉求：变白、变瘦、变美。每年必爆的美白秘籍、三步冷白皮、军训好物、防晒好物，选题年年换皮，本质不变，越来越沉浸、越来越夸张。

个人账号的旧爆款也值得复刻，持续做能强化人设。温仙女早期想做硬核技巧分享，成本高效果一般，后来我们总结发现产品安利、吐槽和抓马故事更受欢迎。于是每月安排一条人设观点输出，比如出门遇到搭讪的抓马故事，做到64.3万+赞。

在粉丝热议她颜值和DO脸话题时，结合女性变美话题，做了“我的变美历程”，现象级百万赞，每年复讲依旧爆。

总之，多复盘自己的爆款，没爆款就先抄别人的，有了就升级迭代，吃完红利再换。

# 六、美妆账号的门槛和想做的一些建议

商业化对美妆博主来说基本不是问题，除非是个假号。最简单的判断就是男女粉比，男粉多基本是LSP，不如去做颜值直播。美妆号核心是吸女粉，有消费基础就能变现。

几万粉到十几万粉的流水线素人也能接广告了。

一种稳赚的真美妆博主是会化妆的达人，特别是会画当下流行的氛围感美女妆。小达人哪怕妆容千篇一律，只要手艺在，品牌合作不少。

最后一点，做一定要坚持。单一方向至少测试5到10期再下结论，不要频繁换跑道。
