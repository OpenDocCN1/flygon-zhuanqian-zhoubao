# 《新手团长快速“脱臼”的几个步骤》
作者：龙哥

做快团团帮卖，啥体验？有人欢喜有人愁。今天要聊的宝藏小鹿，就是那个先把愁全尝了一遍，最后活成欢喜的人。

小鹿原本也是个普通帮卖团长，去年2月份入行，如今已经冲到了河南地区前八十。这背后，是整整一年多“踩坑踩出来的血泪史”。她遇到过根本不靠谱的上游供货方，发来的货和图片差了十万八千里；体验过售后慢得像蜗牛，催一次要等三天；还撞上过发货后物流信息直接消失的魔幻操作。说实话，换谁都想撂挑子不干了。

但小鹿没走。她把每一个坑都当成学费，慢慢摸清了哪些供货团长值得跟，哪些必须躲着走。如今，她身边留下的都是靠谱搭档，而她的客户也对她信任有加，哪怕她推什么，都愿意跟着买。用她的话说，这些才是做团长最大的底气。

这次大航海快团训练营，小鹿受邀请专门写了一份经验帖，名字就叫《新手团长快速“脱臼”的几个步骤》。她把这一年多摸爬滚打总结的要点都倾囊相授，从选品到售后，从避雷到留客，全程干货，没有废话。帖子发出后就收获了190个赞，评论区里也是一片“666”，有同行说“正在做快团团，收获很大”，也有人好奇这跟拼多多后台开通的快团团是不是同一个，还有不少人催她聊聊引流。

小鹿也大方回应，自己正在尝试📕，目前加人还不够稳定，还在努力中。看得出来，就算是前八十的团长，也依然在学习的路上。
