# 1500块投入、一周回本、至今仍在进账的“匿名信”小项目

嗨，我是 bin。今天把压箱底的一个实操记录翻出来聊聊——匿名信公众号项目。这玩意儿我第一次听说是在2022年7月，一听就来了兴致，当场决定下场试试。

先直接甩收益：我在这个项目上其实没投入多少创作精力——发出去的作品一共也没超过10个（懒病犯得厉害），但累计进账已经破万。手里现在用的是第二个管理系统，截图留了个纪念；旧系统里还躺着五千多没提，太久没登录过。而且直到现在，这个赛道依然有不少人在默默操作，长尾流量的威力比想象中还要大，红利并没有一次性被吃完。

![](img/ac91afe6afc0706ede7ccc1854eb97dd.png)

这生意怎么赚钱？逻辑并不复杂——客户通过微信公众号里的短信系统，给别人发送一条带签名的匿名短信，我们这边每条成本大概六到八分钱，卖出去则是九毛九到一块五，毛利润率在93%左右。收到短信的人如果好奇，还能顺着公众号直接回复对方，一来一回互动就有了。整套盘子由公众号、短信系统、引流账号三个部分组成，前期拿1500块左右就能稳稳转起来。

下面聊聊实操。

**一、把交付端跑通**

交付基本全靠提前部署好的公众号自动完成。你需要准备：一个公众号、一套短信系统、一个微信支付商户号。

第一步，先到微信公众平台注册服务号，交300块认证费，名字和头像提前想好，提交后等着审核通过就行。

![](img/6c0876ae3432956788139c16eac001e9.png)

第二步，去微信支付注册商户号，匿名信收款全靠它。

![](img/14f112f0ae6288aff18efe82ae3a1045.png)

第三步，把短信系统对接上。市面上的系统选择非常多，挑个界面看得顺眼的就行。我当时选的是第三款，域名需要自己注册。一般情况下，淘宝搜“匿名信源码”就能找到一堆店家，服务器、域名、短信通道都会一次性配齐。

![](img/d8a9beb63ec73bd2ad93e1a2567bdc9d.png)![](img/28d0fe7c8076175f9b3e962274631f83.png)![](img/41b894f7684f99566c0063de79fdfeb4.png)

拿到系统后，把公众号ID和微信支付密钥填进后台。技术人员会一对一带着你部署，小白也不用担心流程复杂。

![](img/e1553983d912d2218ac0b742726fee5d.png)

最后给公众号做点小装修。我用的工具是“芝麻小客服”，依次设置好关注后自动回复、关键词回复、底部菜单栏，全部搞定就能直接上线营业了。

![](img/ba9473e5a43cce07f61a94acb3ace486.png)![](img/0ecbb4c95de3b6a2875c23cd295de3c6.png)

![](img/3960ac2934587e29a98ff0ab767bfdc6.png)

**二、把流量引过来**

交付端弄好后，剩下就是把人带进来。我是7月28号完成部署的，30号才开始正式尝试引流，结果一个星期都不到，投入就全部收回来了，更夸张的是当时拢共只发了一条视频。

![](img/1c79ec860265d53acaf994df1923e155.png)![](img/ade795124b02bcb291e0e66e28c59b99.png)![](img/53afdbfbdcd795f5b965b727ccc731f7.png)

最笨也最有效的路子，就是去抖音、快手这类短视频平台找现成爆款，直接照着改编就行，别不好意思。爆款的内核说到底就是一个字：“丧”。故事越伤感，越容易让人代入，共鸣感一起来，情绪就跟着跑了。同样的玩法搬到Soul、小红书上一样好使，只要你会编故事。

![](img/5520c9e4da9021a07f1c708aeb865ed3.png)![](img/5bc18c4e19c106609e8813554a02ec3c.png)![](img/e4acca9877aaea78ce2d598aa5dc2664.png)

讲到引流，生财这边的大牛太多，我就不班门弄斧了。想深挖的朋友翻翻历史精华帖，再结合这个项目去实践，会有更妙的收获。

![](img/f663ea19fffd92be555174dc8fb5926c.png)![](img/d98452da5a851e57dcf73a258e131a74.png)![](img/65d45d6ffe38a800affc3ba5773ddb0a.png)

一句话总结：内容不过是药引，真正卖的是情绪。故事全靠编，把目标用户的情绪点戳中，感性冲动一上来，你那边的单子自然就来了。

**三、怎么变现更舒服**

变现方式不复杂，最直接的就是卖短信赚差价；玩得花的可以接广告，也可以做二次转化。比如当时就有一个塔罗师傅主动找过来合作，一般情况下都可以接。你也完全可以自己开一个塔罗算命的业务，把链条做完整，用户进来之后还能往更深处挖。

![](img/d0d41106a9ab92b8728255e79bffd0ee.png)![](img/3302625c05fd425c0c0010425e0fe474.png)![](img/850f08d79314189819beceac389687ca.png)

还会有同行过来找你发广告，我嫌麻烦就一直没有接。

![](img/600652778fc8787b9747e73face25b16.png)![](img/11be6bd96c1831b1c08b8fab33d22eda.png)![](img/11e908cebf3127917da436aed4cc92f6.png)

这个项目最猛的时候，一天的流水上过两万。除了真金白银，公众号本身还会沉淀粉丝价值，后续再塞点情感挽回之类的服务，想象空间一下子就能打开。

**几点提醒**

用户如果发违规内容，短信通道一般会直接拦截，你也可以在后台开启手动审核，基本谈不上法律风险。资质门槛也不高，办个个体户几十块钱就搞定，微信商户可以走对私收款。

整体看下来，这项目真的很有意思。我也就认认真真玩了一阵子，后来转去做别的，但它直到今天还在给我带钱。对零基础的朋友来说，相当友好。我的公众号叫“一封传信”，感兴趣的可以瞅一眼，就写到这啦。
