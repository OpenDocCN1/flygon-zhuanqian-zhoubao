# 用几段闲聊，聊聊我眼中的龙哥盟
作者：龙哥

嗨，我是龙哥，2018年就进来的老成员。以前主攻设计，现在两地间跑，杭州和义乌来回晃，当前重心是抖音带货。圈里可学的东西太多，这回不谈干货，就随便唠唠，让脑子松一松，从另一个角度看看赚钱。

## 几次对话，勾勒出圈子的气质

2019年准备赚钱视觉标识时，我和龙哥聊了很多。他提到圈里发生的一些事：有人在这里学到新本领，后来月入破万；有人碰到长期的合作伙伴；有人靠着别人的复盘少走弯路；也有嘉宾坦诚地讲自己的经历。这一切都源于日常的交流。

有个细节我印象很深，赚钱的背景图为什么用卡通风格？龙哥说，他不想让这个地方带上铜臭气。这些从聊天里流露的信息，恰好成了后来设计思考的依据。设计本质是交流，标识不只是图形，它要把最核心的东西提炼出来，用视觉传达出去。

那次交流后，我整理出龙哥对这个社群的看法：

1. 赚钱讲的“术”要走正道，合规合法，三观正。
2. 方法多、覆盖面宽、信息更新快、人脉连接深的互联网社群。
3. 可以大方聊赚钱，谈钱不伤感情。
4. 希望通过这个圈子影响更多人，让更多人形成赚钱思维，生活过得更好。

虽然和钱相关，但龙哥更希望它是一个有温度有情怀的集体，真实分享，真诚链接，交流自然。

## 为什么现在写这篇

最近航海家介绍里，几位朋友提到了赚钱的logo，都说好看很经典。我听了挺开心，跟龙哥说这logo扛得住时间。聊着发现自己好久没在社群里写东西了，于是有了这篇文章，很高兴能这样认识大家。

## 五年过去，当初的设想都实现了

2019年做赚钱日历，才有了后来大家熟悉的那套视觉调性。每次线下见面会线上活动，看到那抹赚钱绿和物料，感觉特别亲切。记得当年一位朋友说“咱们一起爱护他，陪他长大”。现在看来应验了，赚钱被赋予了生命，越长越好。大家一直维护着它，样子没变，只是更大了。老朋友应该能懂那种感觉。

那年龙哥跟我聊他对赚钱的期待：做一个真诚、有温度、聊赚钱的社群，不要铜臭，三观正、方法多、覆盖广。五年后回看，他都做到了，而且越做越好，一直践行自己的价值观。

当时人数不到六千，现在四万六。最初提出的价值观已经深入社群，坚持长期主义，一点点改变，扎进每个人的心里。这件事很有分量。陪伴六年，见证成长，当年描绘的画面都成真了。

当年全国见面会、城市聚会认识的朋友，很多现在小有成绩，看着他们一步步起来，很庆幸路上有人同行。也有慢慢疏远的朋友，彼此祝福。

## 免费做一个标识，到底赚了没有

为什么无偿给赚钱做logo？龙哥说我有格局有前瞻。最根本的是我认同他的为人以及他践行的信念，他对商业的观点影响我很大，有时一句话就解开我的困惑。能和大佬交流本身就是学习，这个过程很值钱。所以我觉得是我赚到了。

后来被验证了。龙哥的下午茶能拍出七万多，这几年去EFC基本都是他请客，加起来几十顿。直到现在，他仍是我创业路上的导师，泼冷水、指方向、一起想方案，都源于2019年的那次合作。

## 为赚钱做品牌设计，回报远超想象

替赚钱做的品牌设计，回头看是我投入最值的事，后面惊喜不断：

1. 经常蹭龙哥的私人饭局
2. 龙哥带着爱人专程去义乌指导两天
3. 参加曹大的分享会并上台
4. 参加小马宋老师的私人饭局
5. 赚钱多次推荐、龙哥背书，促成五十万以上的成交
6. 认识很多优秀创业者，赚钱好友占🛰️好友约四分之一，从业务延伸到生活
7. 找到二次创业方向，圈友大力支持，得到一群高度信任的兄弟

在赚钱合作的伙伴十个以上，都很顺畅，有几次见面就签约付款。二次创业从选项目到合作，圈友都支持，因为有信任和背书，效率很高。想法一致、频路相同，事就成了。

真诚是最强武器，利他做事往往带来惊喜。不求回报的付出，收获常常超乎想象。

## 从设计到电商，赚钱一直陪着

因某些原因，2021年我从杭州搬到义乌，也从设计转到电商。第二个事业也是在赚钱项目库里找到的，天天浸润，对业务有判断。很幸运遇到当时做抖音培训的高欣，没收我29800，还跟着蹭饭。也因赚钱的背书很快成为好兄弟，尽管他比较内向。

后来跟着SKY老思做过一段时间TIKTOK，也做出成绩，一个月做到全国第五。去年初龙哥带爱人来义乌，两天一夜帮我梳理战略和思路，连带团队、思考问题都教了，受益很大，也给这条陌生路打了底气。

商家岛的时明、高欣、帅张、小喵、直浪、玛丽阿姨、SKY老思，多次来义乌看我，有时带团队来帮忙，用各自专长帮我团队成长。他们是我创业的智囊团，帮理思路、补盲区、接资源，践行了互帮互助真诚利他，创业不再孤单。

还有HEXIN、茄子、靠谱等太多朋友帮忙，一切源于赚钱这个圈子。我们只是其中一个缩影，相信还有很多类似的小圈子，互相支持鼓励真诚对待。

刷朋友圈看到圈友在某个城市办活动，很感慨，大家不只是工作交集，也走进生活。我现在圈子大半是赚钱的人，相处四年多，情谊越来越深，创业路上不孤单，有后援团的感觉很好。

## 现在在做什么

义乌的直播团队，专注丝巾围巾品类，主攻50+人群，抖音为主同步视频号。单间GMV三百万，日销近万单。天猫渠道和品牌化在布局，私域专家小喵帮我搭建私域，已见成效。头疼的问题跟初创都一样，缺合适的主播。我们做的香云纱、丝巾品类也在丰富，有服装配饰资源的欢迎交流。

这两年摸索抖音直播带货，对跨行创业和直播有心得。龙哥说过在中国把一件事做好，一年至少千万利润，团队小，先把一件事做精就不易了。现在我深耕一类，争取做出成绩。

最近在想做赚钱的事还是做值钱的事，看阶段不同。每个阶段节奏要根据团队能力和实际情况调整。这一年还是想靠深耕品类赚到钱。

这两年有踩坑也有结果，路子很接地气。我的经验如果对圈友有用，乐意交朋友。义乌供应链资源也积累了一些，需货源的可对接。

干货圈里很多，找实战高手虚心学。多看多听多干，别浮躁焦虑，常泡在赚钱总有收获。我人笨进步慢，但待得久，看得多惊喜自然来。

有次问龙哥为什么对项目判断力强，他说看得多就有感觉，很多时候是本能。没错，多看看会有惊喜。精华帖、风向标、项目库够看了，如果像我一样拙，就沉下心慢慢浸泡吧。
