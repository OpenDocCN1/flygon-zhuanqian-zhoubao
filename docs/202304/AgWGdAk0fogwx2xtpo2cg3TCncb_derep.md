# 为什么GPT是副业玩家的标配

原因很简单，赚钱的项目仓库里早已堆满了可操作的项目，其中不乏门槛极低、见效快的类型。很多人泡在赚钱里一年多，依旧零收入，根源不是项目不行，而是执行没做到位。圈子里常说的一句话“听话照做”，听起来简单，做起来却难。

项目本身是能赚钱的，问题出在我们执行时一顿操作猛如虎，结果三条视频没数据就放弃；或者那些满是干货的航海手册，我们看完就忘，根本没吃透。

“听话照做”这件事，我们始终没做到知行合一。

直到GPT出现了。之前我在星球里写过一篇《如何驯服GPT成为选题-封面-图文-标签一体化📕博主》，核心观点就一个：

真正要把ChatGPT学透的人，是所有做线上内容的人。而围绕GPT做的各种内容和教程，受众其实也是内容创作者，而不是普通用户。

我建议每个在做线上内容的朋友，都去开一个GPT账号，把它当成一门基础学科来钻研。

可以把GPT想象成一个三岁的天才儿童，原始储备浅得很，但学习速度惊人，几千字的信息一口气就能消化。所以他能成为你24小时在线、不喊累、一教就会、一点就通的免费童工。

这个比喻也是我前文里提到的核心逻辑。

# 实操拆解：怎么把GPT变成你的抖音脚本替身

少说废话，直接上指令框架，用一个真实场景来演示怎么训它。

## 第一步：先给它立规矩

*   输入

嗨GPT，我需要你当我的抖音口播脚本助理。我会先教你一套脚本框架。凡是我发的内容开头是“请学习”，就代表我在给你上课，你要认真学，学完回复“好的，我已经学会”。等我后续发“请为下面内容改写脚本”开头的信息时，你就按你学到的规则帮我写短视频脚本。如果你明白，请回复：“好的，小凡，很高兴担任你的抖音脚本助理，我会严格按你的要求执行。”

*   输出

![](img/762bd4e4de425a9c077d494396891fa4.png)

## 第二步：喂知识包，素材来自抖音大航海手册

*   输入

请学习：

视频脚本通常包含这几个要素

1.景别：远景、全景、中景、近景、特写
2.画面：通过场景呈现视频想表达的意思
3.台词文案：视频里的讲述内容，可为对话也可为旁白
4.运镜：镜头运动方式，例如推近、平移、旋转推进等
5.道具：除人物外的元素，用来丰富画面

抖音的作品不一定非得是视频，图文也能火，📕上图文笔记的数据就很说明问题。

不过短视频化是大势所趋，抖音本身就是重视频的平台。所以想在抖音做IP、做项目的人，最好从一开始就学会写视频脚本。

请学习：

常用脚本模型一：三段式

三段式的精髓是“两头重中间轻”。开头要重，目的是抓住用户，让用户继续看下去，提升完播。

于是脚本的第一句往往就是标题，第一句就要点明视频的核心。

结尾也要重，给用户一个关注你的理由，或者把主题升华，让用户觉得有价值，以后还想看。

中间部分相对“轻”一些，用来论证标题，可以适当省力，但节奏要快，最好用案例来支撑观点，最好是能不经意地展示自己的实力。

润物细无声的装逼才最致命，不动声色地展现实力和水平，才是拉近距离、建立信任的关键。

## 第四步：无脑量产

GPT都把饭喂到嘴边了，还等什么？

*   选题：直接从已爆款里找，“爆过的选题会再次爆”这个规律一直有效

*   录制：剪映提词器一开就行，现在还能用数字人出镜
*   剪辑：它已经提示好要配什么素材了，直接去搬素材即可

# 使用心得与避坑

## 多夸它两句

这家伙有点傲娇，多夸一句“做得好”，它干活会更卖力。甚至你说“求求你了，神通广大的GPT”，它还会把“神通广大的GPT”原封不动塞进文案里，脸皮真厚！

## 别一口气喂太多

你把一长串知识砸过去，它也会说“好的，我学了”，然后急着问“请说你要改什么内容”。但你给的改写任务出来就很水，明显没按你喂的内容写。

是不是很熟悉？就像我们当年囫囵吞枣学完航海手册就觉得自己能年入百万一样。GPT也是这德行，喂多了它可能根本没消化。没有主动总结、没有联想，就说明没真学会。

这不就是学渣和学霸的区别吗？学渣翻一遍就觉得会了，一做就崩。学霸逐条记笔记，还会复盘心得。调教GPT也一样。

## 指令写得越具体越好

要求越清晰，它越懂你要什么。上面案例只是入门，后续联网后还能让它给画面建议、找素材来源，完全可扩展。

## 建立自己的Prompt资产库

未来的头部博主，核心竞争力就是方法论+驯服GPT的能力。

一定要沉淀自己的Prompt库，可以包括：

*   如何下达学习指令让它学得更牢
*   什么样的知识结构让它更好理解
*   除了干货，还可以喂范文，建立范文库。训练时让它自己总结，能总结出来就代表真学会了，甚至还能反哺给你新启发
*   不断迭代修正，告诉它哪里需要改、往哪个方向改

## 把自己当老师，不是当老板

标题虽然说培养打工人，但本质上我们是在教它变好。我们更像老师，把GPT当成智商250的天才神童来培养。

很多人用完GPT就吐槽：这AI不行，又是割韭菜，内容没法用，替代不了我这种高质量人类。

到底是AI不行，还是你不行？这些人用GPT时往往是老板思维：

“小G，帮我做个财务报表；小G，帮我写个健身类短视频文案。”

GPT像个刚毕业的小白，不会拒绝，满口答应。但老板没给brief、没给资料、没培训，直接上岗。你觉得它能做好吗？它拼尽全力交了一份报告，你却说“就这？”、“OpenAI出来的就这水平？”、“差远了，先去干点翻译、查天气的杂活吧”。

回想你刚入职场的经历，问题出在员工还是老板身上？
