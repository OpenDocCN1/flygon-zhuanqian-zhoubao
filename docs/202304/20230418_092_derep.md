# 你的创业高度，决定了你能赚到多少钱
作者：龙哥



## 《你创业的层级决定利润的天花板》 

作者： 孙策 

日期：2023-04-06 

每年我都会出去走走，看一看市场里谁在起势。会发现很多优秀的创业者突然就冲上来了，直接把自己甩在后面。回头复盘我自己，从16年入局到现在七年了，年均产值其实很平，太多业务是在原地打转，并没有实现年年攀升。

所以我开始琢磨一个问题：营收可以有起伏，但创业的段位必须向上走。

![](img/f80934582a0d3710c990fbc42336d04e.png) 

当下绝大多数人卡在的，就是第一层：跑通一套能赚钱的闭环。

这类叫流量套利型生意，典型就是🛰️淘客、抖音混剪带货。先用内容把流量引来，再在私域成交抽佣。这种模式门槛最低，入局的人最多，也最容易被复制。一旦有人赚到钱，后面马上跟一波。

天花板很低。团队也搭不起来，因为人才进来很快就能摸清全流程，转身就走；就算你花时间培养出来了，也留不住。最后形成一种人来人走的平衡。

而且这种模式只能往下兼容新手，容不下大佬一起玩。做的人特别累，得盯着每一个环节、每一处细节。回头一看，兜里多了点现金，却没留下任何可复用的东西。

![](img/d8f2fc0c7d3c64dc6f4e3437c88ccacb.png) 

第二层是产品型创业。

核心是先做一个产品，用产品来获客、变现。比如把一个👸号做成产品、把一个抖音号做成产品、做一个小程序、做一个工具、做一个IP。

做产品的创业者比做流量的少很多，因为产品自带护城河。产品就是你的根据地，可以往上吸引高手，也不用怕高手离开。因为人走了，沉淀也留在产品里。

产品会自我进化，靠自身去吸量、去赚钱。

向上吸纳人才和向下容纳求职者，只差一字之别，实质却隔着一个维度。

到了这个层级，创始人可以松绑，只抓关键节点，剩下的交给体系去跑。年利润做到千万甚至几千万，是常态。

![](img/cb8e2a8d4e89cfb78d80ed1745ea556c.png) 

前两层其实都还停留在垂直赛道里。很多人做到头部后，开始反哺整个赛道，做供应链、做团队方法论、做打法输出。

现在主流打法是业务+个人IP。到了这层，不仅业务成了壁垒，你本人也成了这个赛道的代名词。占据了这个位置，第二个人永远只能做第二。

这时候你赚的不仅是业务的钱，更是整个赛道增长的钱。话语权和定价权都上来了。

![](img/b145f987f55af90baee2232deb41ef4d.png) 

但前三层都有个致命伤：业务有周期。很多模式两三年就过时，这也是成熟创业者最大的焦虑。

第四层是做成行业，对冲周期。把一个类目升级成行业。

比如电商。十几年来经历了淘宝货架、短视频推荐、直播电商等无数小周期，但电商这个大盘始终在涨。行业内既能筑高壁垒，又能引领创新。

到了这个段位，小周期的波动已经影响不到你了。

![](img/83a6ce8093c5edb0ca47ef96f74d337a.png) 

道生一、一生二、二生三、三生万物。

第五层是要找到贯穿行业的最源头，找到自己的道，进而构建生态。

新能源汽车里，理想、小鹏、蔚来三家，我更看好理想。现在市值也印证了这一点。理想找到了自己的道：家。围绕家做产品矩阵，形成生态互推。

也有创业者把道找在服务上，做成服务宇宙；把道找在抖音上，做成抖音宇宙；也有人找到永恒的载体，比如社区。社区里的具体业务会换了一波又一波，但社区本身一直都在。

这个层级的创业者，已经做到知行合一。

![](img/90195ca3836abf20e3d60df0ec01856a.png) 

第六层要看两件事：活得够久，以及推动一个领域向前。

阿里巴巴说要活102年，特斯拉说要加速世界向可持续能源转变。推动一个时代，需要几代人的投入，需要持续的资源和人力。所以长寿本身就是能力。

![](img/9b683f75a3d46d76d829405a8478f824.png) 

第七层，则是见天地、见众生、见自己。

在道家是成圣，在佛家是成佛。达到本来无一物，何处惹尘埃的境界。

最终回归到做人、做事的本心。

归根结底，低水平重复就是原地踏步，不进步就是退步。
