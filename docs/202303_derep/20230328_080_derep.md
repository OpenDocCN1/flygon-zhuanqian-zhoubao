# ('《美团电商的优势和门槛详解，如何提高入局概率？》', (2, 26))

他早年就职于美团，一干就是八年，管过上百人的销售与运营团队。离开大厂后，他独自闯荡，再从一个人打拼变成带着小团队经营电商，这段路大约走了一年半。

这次他受赚钱老朋友静伟的邀请，以教练身份加入二月份那期电商实战，并把自己的观察整理成长文，内容直击很多人最关心的问题：美团这个平台上的电商机会到底有多大，弱点在哪里，入场门槛有多高，以及怎样提高成功概率。他特别提醒大家，动手之前，既要看懂项目的真实面貌，也要想清楚自己的资源和状态。

项目之外，他对公司经营的基本功也有不少心得，比如招人怎么招、规范怎么建、执行中怎么盯、薪资结构怎么设计。这些都是他亲手带团队、管理规模一路扩到上百人的过程中反复验证过的经验。
