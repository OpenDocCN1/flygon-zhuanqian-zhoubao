# 创业两年后，我对“为内容掏钱”的看法彻底变了

> 原文：[`www.yuque.com/for_lazy/thfiu8/ne9v8i8g9qing1ec`](https://www.yuque.com/for_lazy/thfiu8/ne9v8i8g9qing1ec)

群里又弹出一条续费提醒，点开一看，又到了该交钱的日子。算下来，我已经是第三次付费了，时间过得是真快。

先简单交个底。我是老瞿，圈里人都知道我在旧书这个行当里泡得最久。大学毕业后我进了地产行业，待了八年，做到区域运营负责人，年薪过了百万。后来辞职创业，第一笔拿了100万融资，半年就败个精光。接着又折腾了一轮，想把钱赚快回来，拉新、薅羊毛之类的路子试了不少，三个月烧掉20万当教训。从那以后我认了命，老老实实做旧书，两年下来，年景好的时候能落下一两百万的利润。现在旧书这摊子已经稳了，我又开始琢磨，是不是该换个更大的赛道试试。

刚进这个社群的头一年，说实话我的状态很拧巴：

- 那些文章一篇比一篇长，像论文一样，我根本看不进去；
- 到处有人说自己一年赚了几百万，我第一反应就是吹牛；
- 试了两天没搞到钱，开始觉得这东西是智商税；
- 一生气把App删了；
- 过了几天又焦虑了，偷偷装回来接着翻。

为什么会有这种状态？现在回头看，原因其实很清楚。

第一，我原来的背景和这里的玩法完全不搭。我是传统行业出身，对互联网项目天然有距离感。人学新东西的时候总是痛苦的，离开学校这么多年再啃陌生领域，难受是正常的。反过来想，如果待在一个社群里全程都觉得很轻松，那可能真的是在浪费时间。

第二，当员工当久了，自己搞钱的能力早就锈住了。上班是什么感觉？你第一天入职就知道自己的活是什么，周计划月计划年度计划都给你排好了，干不好有人催，迟到了有人扣钱，你不需要自己驱动自己，跟着系统走就行。我当年做运营，一半以上的精力都在摸鱼，活丢给下面的人，自己喝喝茶、拍拍马屁就过去了。但是自己做项目完全不是一回事，地上没有路，全靠自己踩出来。没有人在后面盯你，时间一长，很多人连怎么干活都忘了。

第三，总想着把搞钱这码事外包给别人。典型的心态是：你说的方法我照做了，怎么就没结果？你到底能不能给我打包票？我做了万一没成呢？这些话背后是什么？是打工思维。花了几百块钱就觉得钱该由别人帮你赚，其实你买的是信息，不是保证。没有人能替你成功。

现在做了两年，我对付费学习有了自己的理解。

第一，别跟着别人的话跑，要学会自己拆解。任何一个生意，你要能说出它的好、它的坏、对人的要求，再去对照自身够不够得着。拿旧书来说，它最大的优点就是很快能看到成交，可能几天就有第一单，但坏处也很明显：事情琐碎、赚头有限，一个人认认真真干，月入一两万基本到顶了，想要更多就得组团队。再拿带货视频来说，前期特别熬人，一两个月没动静很正常，可一旦有起色，一条爆了的视频带来的收入可能顶得上旧书干好几个月，而且不用天天处理客服消息。

第二，玩法是分档次的。低段位的是旧书这类小生意，动手就能看到反馈；中段位的是直播、带货视频这类，需要一点内容感知力，开头难，后面空间大；高段位的是个人品牌，得靠长时间的沉淀积累，一年拿下一百万也并非夸张。每个人要先掂量掂量自己在哪个段位，再去找对应的玩法。一个纯新人起步就去追着大佬学做IP，报一堆课，基本不会有结果。

第三，做什么方向，一定得是自己选的。付费学习的真正作用，是让有经验的人帮你挡掉一部分坑，把前期的流程给你捋顺，让你少走几步冤枉路。但最怕的不是走冤枉路，而是因为走得艰难就丢掉一个本来不错的生意。路是你自己挑的，没赚到钱，先反省自身的判断和付出。有人问“兜里就剩5万块，有没有办法推荐一个稳赚一百万的买卖”，这种问题一听就是还没想通。

熬过那段拧巴的日子，又花了一年提升认知，我现在可以讲一句实话：这个社群是我见过质量比较高的创业圈子之一。如果你到现在还觉得什么都看不懂、什么都做不了，那多半是参与得不够深、做得不够多。

每次续费的时候，我脑子里都会演一出小剧：

我往椅背上一靠，跟鱼丸说：让龙哥来一趟。
龙哥推门进来，我说：今年拨给你两千预算，你要给我办好这几件事。
第一，保证我掌握最前沿的项目消息，至少要比其他人早看到一年；
第二，把社群里这么多创业者都鼓动起来，让他们把自己正在搞的事情讲给我听，我有时间就翻一翻；
第三，每月组织一次实战，我心情好了就参加；
第四，每周给我交一份精炼总结，别让我自己跑到信息堆里去找重点。
听明白没有？

希望接下来的一年，能在这个圈子里碰到更多同频的人，大家一起搞事情。
