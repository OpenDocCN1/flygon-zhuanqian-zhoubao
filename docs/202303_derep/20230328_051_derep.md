# AI分身的迭代速度和价格下探超出预期

最近在研究 GPT 的落地方向，因为我本身在做内容输出，主攻方向自然就落在了虚拟人身上。跟投行、科技圈以及一线的创作者聊了一轮，收获了不少顿悟，整理如下：

1. 升级速度惊人。初次看到实拍的成果时我被震到了，外观、神情、动作的自然度已经无限逼近真人，相似度恐怕能到接近百分之九十九的水准。

2. 认知差往往来自信息滞后。你觉得眼前这技术很炸裂，很可能只是自己接触晚。跟不同圈子的人对齐后才发现，内部早已有团队把这套东西玩到审美疲劳了，多交流可以避免成为最后一个吃螃蟹的人。

3. 这条赛道并不是新鲜事。17 年前后就有团队在尝试相关方向，当时打着元宇宙的旗号讲故事，但受限于技术成熟度很快就沉寂了。

4. 当下最夸张的是价格洼地。首次建模的投入在数千元级别，之后按时长计费，一分钟成片的成本可以压到两元以内。更关键的是，市场上不少自称自研的服务商，本质是渠道商。中间再加几层分销，单价还能继续被打下来。

5. 好的是逼真度可以拉满，坏的是它造不出真正的好内容。IP 的核心永远是内容，而不是皮囊。现在即便反复调教，也很难超过本人的上限，所以指望靠它短期内复制一个网红几乎不现实。现阶段更适合刘润、张琪这类已经具备影响力的头部人物做人格延伸。

6. 技术再强也怕缺场景。资本目前最焦虑的就是缺乏可落地的应用、流量接入口和好讲的故事。没有高阶场景加持，再逼真的分身也只能被降维成电商直播里喊促销口令的工具，没有额外溢价。

说到底，这事跟我在798看到的那批清仓瓷器很像。放在合适的语境里，它就是值几百上千的艺术品；找不到定位，它就只是几十块一件需要赶紧处理的库存![](img/3b927ccc621b83014e7013276a63778f.png)
