> 原文：[`www.yuque.com/for_lazy/thfiu8/cgwwlsiya6d44g1s`](https://www.yuque.com/for_lazy/thfiu8/cgwwlsiya6d44g1s)

作者：柯小南
日期：2023-03-22

这一次上海本地的线下聚会结束后，召集人把前后工作拆成三大阶段做了总结，对想做同城链接的人很具参考价值。

一、启动准备期
核心工作集中在场地、人数、时段、交通、动线和提醒事项这几个维度。场地选择上，同时满足讨论和聚餐需求，优先考虑带独立包间的餐饮场所。人数确认后敲定具体日期，并把地铁与自驾两套出行方案梳理清楚，附上周边停车信息和导航要点。

筹备期召集人输出了一份PDF并在群里置顶了通知。通知里写明：

欢迎大家参加生财上海见面会
我是本次召集人柯小南，是程序员圈里比较另类的存在。现在在互联网行业深耕，业余做自媒体创作，很想和各位成为朋友～

+ 地点：交通大学周边
+ 时间：2023-3-18 14:00
+ 周边休闲：港汇广场、美罗城、太平洋百货等
+ 交通
地铁：10/11号线交通大学站1号口出，步行约700米；1/9/11号线徐家汇站15号口出，步行约400米。
自驾：附近小区停车约10元，需提前登记车辆数。

通知中还贴出了各线路末班列车的发车时间，以及一张地铁线路示意。

为了避免现场冷场，召集人在会前呼吁每位到场者提前想好可输出的内容。沟通的两个主轴是信息互换和变现思路。除此之外也可以涉及心路历程、发展规划、技能进修、行业观察、生活小窍门等，目标是保证全员发声，而不是单向倾听。

二、现场执行
当天安排了专人做记录，把关键观点实时沉淀下来。

时间线安排：
13:45-14:00 签到
14:00-14:30 个人破冰介绍
14:30-14:45 特邀小节目
14:45-18:00 深度碰撞
18:00-20:00 晚宴交流
20:00-20:10 压轴小节目
20:10以后 自由留场

现场控场的要点有：
自我介绍压缩在2-3分钟；
晚宴人数稳定后再与餐厅做最终确认；
自由讨论阶段按总时长做人均分配，超时要温和介入；
点菜尽量人人参与，避免口味冲突；
合影时喊口号提气氛，并准备自拍杆或手表等辅助拍摄工具；
持续关注夜间回程的交通末班时刻；
如条件允许，准备流程PPT会让衔接更顺滑。

三、收尾复盘
会后做了三件事：整理会议纪要、逐一收集参与感受、向全体致谢。

四、反思与改进方向
可加入破冰游戏加快热场；
拍照环节要更充分；
把控主题主线，避免偏离；
会前摸清各人职业背景与擅长领域，提升对话质量并减少无效社交。
