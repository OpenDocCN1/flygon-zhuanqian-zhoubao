# 分销榜前三的00后创业者：我如何用七年时间深耕学生私域，做到小报童推广一千单

> 原文：[`www.yuque.com/for_lazy/thfiu8/zfrb3a7xeob9ctyi`](https://www.yuque.com/for_lazy/thfiu8/zfrb3a7xeob9ctyi)

上轮龙哥盟项目精选 x 小报童的推广战报出来了，分销榜前三名无一例外都冲到了千单级别。实打实的数据背后，是方法论的问题。我约到了第一名的操盘手乔合，聊聊他是怎么打下的这一片学生市场。

今天的主角，乔合。00后，线下实体起家，互联网摸爬滚打已有八年。物联卡、扩列、羊毛、淘客、潮牌……他几乎踩遍了年轻人的流量洼地。赚钱社区里他此前分享过《年轻的实体店创业者，如何用互联网思维破局疫情影响》，从QQ空间起步一路迁移到庞大的私域联盟。如今他已是赚钱项目精选上一届分销榜的头名。

以下是这次对话的精简记录。

一、为什么锚定学生群体

问：你涉猎那么多圈层，最后为什么把重心落在学生私域上？

乔合：我今年23岁。最早16岁的时候就是在做游戏软件分享，纯粹爱好。那批最早跟来的就是同龄的初中生高中生。我对这个群体的心理很熟，知道他们在想什么、喜欢什么。后来公司方向慢慢就围绕学生需求来做项目了。

问：带学生做变现，外界总会说割韭菜，尤其未成年人，你怎么看？

乔合：韭菜这个词，说的是投入产出不对等。我们给学生做的项目都是小而美，定价主打188到388这个区间。学生回本快，第一次就能赚到零花钱，信任感就起来了，后续复购自然发生。

比如我们带的“188带你做闲鱼”，学生上手快，十天左右就能回本。项目群里天天晒收益，氛围一带动，更多人就跟进来了。我们的群甚至直接叫“韭菜大队”，就是自嘲。几千块的客单价对学生是压力，周期拉长也容易没反馈。于是我们先用低价建立信任，回本后再推荐2588、5888的高客单课程。现在的梯度是188-288-388-588-2588-5888。

问：你会长期做学生IP吗？

乔合：已经做了七年了，会一直做下去。学生知识付费赛道，大佬看不上，普通人觉得没钱。现在入场的人几乎没有。学生不是没有消费能力，是要你去激发他们赚钱欲望。就像幼儿园小孩都知道钱能买糖果。

一年有结果的项目人多，五年才有结果的凤毛麟角，十年才有结果的就是一片空白的蓝海。学生这块就是后者。

问：做学生变现最有成就感的是什么？

乔合：比我买跑车更爽的是，看到学生用自己的零花钱搞定了生活费。父母之外，最希望孩子赚钱的可能就是老师。

问：有没有想过放弃？

乔合：有过。这个赛道需要极强的IP沉淀。很多付费学生是从初中跟我到毕业，我看着他们长大他们看着我长大。如果你要做学生IP，就得做好一年不赚钱的准备，持续打造个人信任。这是复制不了的。

我的引流打法很多人听过，但没有第二个人能复刻。

问：如果你的弟弟妹妹进了你这样的社群，你会怎么说？

乔合：在自己能力范围内，多看看外面的世界，你可能会发现另一片海。

二、项目筛选与运营打法

问：你筛选学生付费项目的标准是什么？

乔合：主要看五件事：操作难度、平台规则、项目是否安全绿色、可否批量化、周期与利润。

举个例子，去年我们推的百度答题项目收了近千个学员。为什么选它？

操作门槛低，就是机器人给答案，学员稍微改写后发布索取佣金，本质是改写复制。平台也欢迎专业答主。项目安全，模拟器多开、找亲友实名就能批量。周期长，背靠百度。实测一小时30题，一个号一天赚20多，188的课程一周回本。

问：你的40-50万粉丝来自哪里？不同渠道差异大吗？

乔合：三大来源：学生扩列粉、QQ软件游戏粉、羊毛线报群体。画像高度重合，15到20岁之间。学生容易被带节奏、社会经验少，简单说，他们没那么多心眼子。

问：学生和赚钱总对立，除了知识付费还能怎么延展？

乔合：知识付费本身就是引导他们做副业。早期我们做淘客，后面延伸到流量卡、潮牌。劳务和求职我们也想过，但用户还没到那个阶段，转化率掉得厉害。不如做刚需。

学生不一定会做项目，但总会跟你买点东西走链接赚分销，或者买一双潮牌球鞋。年轻人谁没一双AJ。

三、赚钱的价值

问：赚钱对你有什么帮助？

乔合：三方面。第一，帮我获取整理好项目信息分给学员。第二，认识了大量圈友，他们购买我的知识付费。第三，链接到赚钱大佬，合作两个项目变现30万+。

问：赚钱还能怎么帮你？
