# 为了在赚钱圈被龙哥看见，我一年搞到6张证、18个闲鱼号专门卖二手书



哈喽，我是小游，深圳一个靠卖二手旧书糊口的潮汕女生。

2023年我花了两千多块报名了赚钱，原本发誓一定要把学费赚回来，可最后还是没做到。赚钱里项目实在太多了，看得我总以为自己也能像大佬那样，随便拎一个项目就能年入几百万几千万。结果一次又一次，给龙哥充当了回款工具。只要航海打卡跟不上节奏，我心里就开始打退堂鼓，坚持不下去了。

所以今年我本来是打算不续费了。看着那些花样百出的项目，我反而更觉得自己啥都干不好。就算今年龙哥放了不少福利，我也硬是攒着钱包，暗暗发誓不再让他从我这儿捞一分钱。 ![](img/57252e175158ec19491326ef2337e343.png)

![](img/7b901f824c12a687f993305cec70062b.png)

直到我刷到龙哥发的一条动态，心里咯噔一下，觉得不能再让去年那两千多打水漂了，至少得让龙哥知道我这个人。

![](img/ea3b34a6a0f988c04ab1f620e7af5221.png)

说实话当时也没啥具体招，只是有个念头放那儿了。后来闲鱼突然开放了二手图书的官方入口，我立刻觉得机会来了，这应该就是我在赚钱里发第一篇干货的契机。目标很简单，先让自己的名字在赚钱里冒个泡，看看能不能被大佬瞥见一下。

之前我一直在做二手绝版书的单打独斗，比上班赚得多一点点，但想做大总是被各种小麻烦绊住，规模一直上不去。

今年图书入口一开，我就厚着脸皮动员家里人一起办证，把营业执照和出版物经营许可证全给整齐了。

到现在手里一共握着6张资质，一张资质能认证3个闲鱼店铺，加起来就是18家店，全在做二手图书的无货源模式。

无货源的好处就是启动成本极低，可以跟着市场口味随时调整书目和数量。但这条路也有坑，货源好坏不稳定，库存说没就没，还随时可能被同行掀起价格战。想玩好，必须得有市场嗅觉和风险意识。

我的打法跟星球里小嵩分享的那套思路很像，只是我更粗暴一些，就是直接大量上架，撒网捞鱼。

正常一个闲鱼店铺能挂500件商品。今年开学季，闲鱼为了推图书，搞了个上架上限从500提到3000的活动。活动期间我用了一些扩容手段，把10个账号的额度都提到了3000，剩下的8个账号维持在500。

现在这18个店都在慢慢出单了。下面放的是其中两家店最近7天的流水，净利润在三成到四成之间。

可能在各位眼里这点成绩不算什么，但对我来说，这是我第一次认真想变好、想变强踏出的第一步。

龙哥老师，您有看到我的这篇记录吗？

就算您暂时不认识我，但您做的这个星球，以及您随口的一句话，都在不经意间给了我推一把的力气，让我愿意去追梦、去扛压力、去变得更坚韧。真的很感恩，您的存在本身就像一股劲儿，让我面对生活挑战时更敢往前走了。

今天内容可能有点啰嗦，后面我会持续更新二手书这块的实操笔记，目标是7年之内在这一块做到专业的程度。

也欢迎做书的同行来聊聊，一起把钱挣明白。
