# 二、如何定位爆款？

先推荐一个抓取标题的工具：后羿采集器

以 #大学生 话题为例，用后羿采集器抓取了101条该话题下高赞笔记标题，对标题与点赞数做归纳，能看出不少可复用的规律：

![](img/9ce80f6f61a577adb958c73adfcd6bd7.png)

![](img/298ba40ba9c9e814ceedf2a5cd509423.png)

从截图可以看出，很多爆款标题只做微调、换种说法或改个标点，就能孵化新爆款。

所以，基于爆款做改造，是普通创作者起量最快的路径。

我也对这些标题做了拆解，举两个例子帮助理解：

① 寒假开学千万别忘记带这些东西！

主体：大学生
事件：开学
强调点：开学物资，可口语化为“开学要准备的东西”
修饰词：详细、贴心、必备、易遗漏、不可忘、必须

改写方向：
开学容易忘记的东西（贴心版）都在这里了
即将开学的在校生要带到校的东西（全网最详细版）
开学要带哪些东西收藏这篇就够了

② 来自大学期间赚到小钱的学姐建议

主体：大学生，信息面向学弟学妹/在校群体
事件：大学期间赚钱
强调点：
小钱可换成零花钱、奶茶钱、经济独立、副业
学姐建议可换成过来人经验，如“忠告”、“劝告”、“超全方法”、“肺腑之言”

改写方向：
大学期间赚到小钱的学姐忠告（内附超全方法）
大学空闲时间学姐教你如何轻松赚奶茶钱
建议你没课的时候这样赚零花钱（再也不用向父母伸手要了）

拆解要点总结：

主体：越精准，流量越准。锁定在校群体作为主体，点击人群几乎完全匹配，相关性强更易触发点赞评论收藏，进而进入更大流量池。
心理学上的自我参照效应即此原理：人更关注与自身相关的内容。选题可横向延展到老师、医生等职业，纵向细分到小学、中学、大专、本科、研究生，或大一、大二，或细化到具体专业。

事件：可围绕周期节点展开：开学、放假、寒暑假、节日、热点、季节。比如“周一优秀的女大学生都在干什么”，一年52个周一都能延展。

强调点：在事件中抓住关键点，用形容词去共情用户的痛点、痒点、难点。

# 三、如何提效？

后羿采集器适合打基础，培养网感。多看多感受，逐步对爆款选题产生敏感度。

# 四、如何使用灰豚数据？

# 六、反思与进一步优化

(1) 选题方面：

用灰豚数据筛选近一期和总榜热度话题，在话题里找图文笔记、点赞高、作者为素人的爆款。发布时间集中在近一个月内，且符合账号人设、时间线、事件线、对标线的要求。

即标题和关键词在灰豚数据里查找近30天、近7天按赞数排序，优先参考低粉爆文对标。关键词在标题、正文、小文案中累计出现至少3次。

(2)内容方面：

参考已验证的爆款内容。

想获得持续搜索流量，选题后必须做搜索优化。

这两篇笔记搜索流量只有1%，数据很差。

![](img/e06bd74d16dc9d2c01aa75892a818c69.png)

![](img/f97927d47f1eba3c3e25ea151c040344.png)

其中一篇过英语四级的万赞笔记，搜索流量达61%，并提示“在笔记标题及正文中提炼笔记重要信息，有机会提升笔记曝光量”。

![](img/0d42f08996a83ae6f009e2f517e0abbd.png)

笔记覆盖热词在标题、文案、图片内容中出现不少于3次，更容易拿到搜索流量，也会因点赞收藏行为获得更精准推送。

关键词判断准确，推送用户就更精准，触发三连后笔记会进入更大流量池。

后来遇到数据差的问题，我认为是标题关键词和关键词频次不足导致无搜索和推荐。于是改标题改文案重发，数据立刻回升。

搜索来的用户更容易点赞，点赞增加推送，搜索越多推送越准，起量越快。

![](img/5fbaff0d6eac239e3fb93d67fed0c840.png)

热词搜索量高，既是标签也是关键词。

通过以上方法，做到了7天内60%爆款率。

![](img/9b81ad30e173147078f382e1c8f3e273.png)

关于标签的额外发现：

(3)如何让流量更稳定？

被标签收录后流量会更稳定。

标签帮助系统识别笔记分类，越垂直越好。比如大学高数资料，标签可为#高数#高等数学#大学高数#高数期末复习#高数笔记#高数复习资料

笔记被收录后会持续获得搜索流量。

并非所有笔记都会被收录。以前我选关注人数最多的标签，认为流量池大。但后来发现可以反向操作。

类似知乎，新号不建议回答关注上万的问题，权重低容易被沉。小红书新号权重低也难被大标签收录，但平台有流量扶持，爆的概率仍高。

策略是选小标签更容易被收录，被收录后会先推给关注该标签的人并获得搜索流量，再逐步进入大流量池。

最佳实践是大标签定垂直领域，小标签做精准收录，配合好选题内容，流量会更可观。

# 七、一些碎碎念

做小红书前我做过知乎，积累了3.5w粉丝。后来知乎改版红利期过去，我才迁移。刚开始我以为自媒体就是粉丝越多赚得越多，给自己定了一周涨粉目标，每天写几篇回答。没有内容分析工具，走了很多弯路，但最终成了。

老师曾说过，好坏经历都是财富。知乎的弯路成了我的运营经验，后来带学员、做用户运营、社群运营。

运营底层逻辑各平台略有差异，但不变的是用户思维，为用户着想。

现在各平台都有创作者中心和数据分析工具，应该去挖掘使用，让内容创作更高效。

全靠工具不可行，没有船也要游过去。“不会用人的领导不是好领导”，要学会授权，但没有员工时工作也要能进行。

ChatGPT亦然。用工具写爆款，把工具当你的员工，你作为老板是永远不可替代的。
