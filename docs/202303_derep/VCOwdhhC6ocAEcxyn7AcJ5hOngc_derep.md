# 饭局上听到的10条财富心法，来自投上百亿的老前辈

前阵子有幸跟着一位投资牛人学习，他手里过过的案子包括理想汽车、刚上市的小i机器人。最近一次饭局，老师随口聊了不少东西，我回去整理了10条财富心法，今天分享给你。

老师原话：具体建议挺贵的。所以今天聊的，基本都是底层逻辑，很多道理可以平移到其他领域。

## 1. 想不当韭菜，先练耐心

大多数人找“干货”，恨不得今天看完明天就赚钱。但凡需要时间慢慢养出来的本事，都没耐心碰。可真相是：真正值钱的东西往往特别简单，只是需要日积月累。

你看那些一夜暴富的故事、e租宝、爆雷的P2P，历史上那么多金融骗局，无非是利用你想快速改变的欲望。人性不变，于是前赴后继。

往深了想，底层其实是恐惧——怕被时代丢掉，怕错过机会，更怕别人超过自己。

可你要是能在恐惧里还沉得住气，气度就开始养出来了。慢慢有了分辨真假的能力，也有了不当韭菜的定力。这个过程需要真刀真枪地练。

只要你不当韭菜，时间一定会给你回报。

## 2. 做事和赚钱，是两种思维

这世上有两种脑子：一种用来赚钱，一种用来做事。

赚钱思维擅长分析、运筹、配置资源，军师、参谋、交易员、套利者都是这一挂；做事思维擅长冲在一线、遇水搭桥、死磕细节，绝大多数职业都属于后者。

这两套思维很难同时长在一个人身上，但真正的牛人可以打通，该冲锋冲锋，该布局布局。

赚钱思维起步快，年轻时也许很风光，但最后能成大业的反而少。你要是真有志向，不如去创业、去做事。别忘了，赚钱的同时还得修炼能接住财富的系统，健康、冥想、时间、人脉都是，否则容易反噬。

## 3. 赚钱的本质是壁垒

真正赚钱的人，都是闷声发大财。

赚钱的本质是稀缺。你占据了资源稀缺的位置，当然越少人知道越好。等大家都看到了、竞争饱和了，利润也就薄了。

所以要有壁垒：技术得做专利布局，商业模式得做势能，金融市场得有数据模型。

钱永远流向资源最集中的地方，门槛极高。壁垒之上的人躺着收钱，壁垒之外的人压根摸不着门路。

赚钱有两种：要么自己建壁垒，要么挤到别人壁垒后面躲着。好企业就是壁垒，投中好企业的人就是躲在壁垒后面的。

普通人建技术壁垒很难，那就先积极参与前沿技术；自己没本事建，就花钱请别人帮你建。

## 4. 情报，比项目重要

当一个项目大多数人都说好，往往就不是好时机了，大概率已经错过了最佳投资窗口。

那该对什么敏感？情报。

顶级情报在规则制定者手里。情报每往外面传一层，价值就跌一分。你要做的，是想办法靠近能定规则的人。

投资圈有句话：投资就是投人。我做的事，就是找到站在趋势上、能提高成功概率的一群人，把钱投进去。这群人在哪、做什么项目，根本不重要。

## 5. 投资极简原则：谁来接盘

投资就一条：谁是接盘人？

“接盘”本来是中性词，后来被市场玩出了无奈感。可事实上，每一轮市场上涨，都是一波接一波的接盘人抬起来的。参与的人越多，市场和社会价值就越大。

接盘人群画像越清晰，保障就越高，想象空间也越大，就越值得投。比如Nasper接腾讯，赌的就是中国大市场和腾讯生态。

投资种子、天使、VC、PE，规模轮次不同，本质是一条极度内生的流水线。好项目早在内部就被分完了，有的甚至从第一天就是资本策划出来的。

种子天使赚的是下一轮接盘的钱，后期大资本等着好项目进场。大家各司其职。

如果你没想清楚谁来接盘，那你就是最后一个。

## 6. 以事聚人，关系才值钱

怎么看一个项目成不成？

先列出成功必需的条件，然后翻一遍人脉，找到能满足条件的朋友，真诚地发出邀请：来，一起干，利润平分。

一起把事情做成了，彼此都了解更深，赚得皆大欢喜，感情也更牢靠。就算没做成，也无非两种情况：

一是能力或资金还没到，那就继续攒、继续磨；二是格局不够，那以后别考虑一起合作了。

有意思的是，一起亏过的人，反而会在互相安慰里感情越来越深。将来随便一个机会，就能赚回更多。

## 7. 不同年龄，不同的财务打法

财富累积，说白了就是资产和资本的相互转化。

先用健康、劳力、知识去换金钱资本，再用金钱资本去买证券、房产、贵金属这些资产，接着用资产换更多资本。周而复始，越滚越大。

中间的技巧就是会计、金融、投资、眼光、心理素质，这些都可以通过财务规划练出来。

老师给了一个年龄段的小例子：

20到30岁，刚入社会，收入不高也不稳，除了活命，钱要全砸自己身上——学东西、攒经验，越快把自己价值抬高越好。工作两三年后收入会明显上涨，记得永远留10%备用，剩下的可以结交有效人脉、做一些小规模投资。30岁前的原则：激进，以小博大，重点考虑发展前景。

30到40岁，是资产暴增期，风控要严格，稳健和激进各一半。通常十年至少翻一倍。

40岁以后，一切以稳健为主，善用复利。

## 8. 你会配置时间，才能配置人生

该配置的远不止金融资产。人最宝贵的财富，其实是时间和精力。怎么花，才是决定人生质量的大事。

健康，是现在也是未来最大的资本。无论什么时候，都要把时间和精力分配给健康：锻炼、饮食，一样都不能少。

家庭，是稳定的根基。对伴侣最重要的是陪伴和沟通。事业大小不重要，家里和气，幸福就跑不了。每天都要留出时间，和伴侣好好说话。

事业上，想保持竞争力，本专业要持续投入，尽力做到业内拔尖，形成长板。上班要全身心投入，利用一切机会磨专业。

然后，再挑一个未来不会被AI取代的方向，开始学习。每天下班固定投入两小时，练后备技能。一条主线加一个技能，两条长板足够建立优势。十年后，人脉、财富、名声的腾飞基础就有了。到时候再根据情况做延展。

## 9. 你自己，才是最大的资本

个人加傍身财，等于个人资产提升。

按照资产和资本互相转化的逻辑，如果你的个人价值大概率上涨，那你的信用就是看涨的。配上傍身财，个人品牌提升更直观、风险更低。

这句话可以直接测出来：你把什么当成自己最重要的资本？

请永远记住：你自己，永远是信用最高、最靠得住、最有价值的资本。

有了这个认知，做选择就容易了：

花钱让大脑升级，花；
花钱让能力增值，花；
花时间精力让自己颜值提升，花；
花时间精力让自己气质出众，花。

## 10. 用会计公式，盘点你自己

怎么判断自己这个阶段是增值还是贬值？

用最基本的公式：总资产 = 净资产 + 负债。

比如18岁那年，你只有时间这个净资产，记下来：10年。

每过一年，你有没有多习得一项技能？如果有，总资产就是等值甚至升值的。

比如：总资产 = 时间9年 + 营销知识。
如果没有，那就是贬值，总资产 = 时间9年。

可以自己锚定一个起点，按实际情况记笔数。技能类可以用打分制，满分10分。

比如起点：总资产 = 时间10年 + 健康5分 + 颜值7分 + 视频剪辑5分 + 人脉。一年内如果饮食健康、锻炼频繁、学了穿搭、形象知识，颜值随便加；视频领域不断更新、刻意练习，分数也加。

这么一眼看下来，自己到底是增值还是贬值，清清楚楚。
