# 01 新手是否适合入场做 Etsy 

我的判断是：不建议贸然入局。

原因主要三点：

1.仅凭国内资料基本无法完成 Etsy 的注册。
2.即便凑齐了海外资料，也不能保证一定能注册成功。
3.即便侥幸注册成功，平台风控极严，店铺很容易被停用甚至封号。

很多新人会问我：我是新手想做 Etsy，该从哪开始？

我的统一回复是：没有海外人脉就别轻易开始。因为一旦开始就会陷入开店-封店的循环，最后精力和资金都耗空，还要放弃平台，得不偿失。

那么什么情况下才适合做 Etsy？

当你有愿意配合的海外朋友，并且能借助对方的真实信息和环境来操作时，才是新手入场最稳妥的方式。

# 02Etsy 注册所需准备的资料 

# 资料准备 

证件照、邮箱、电话号码、地址信息、付款卡、收款账户、手机动态验证码工具、商品图片、网络 IP、浏览器指纹环境。

# 资料详细说明 

# 证件照片： 

可选用驾照、护照、身份证等。

# 邮箱： 

建议用海外邮箱，不要用国内的 QQ、163 等。

Gmail 虽然常用但封号风险高，更稳妥的选 Outlook 或其他海外邮箱。

# 电话号码： 

需要的是目标国家的号码，仅用于填写，不必能收验证码。

可在网上查到对应国家的公开号码用于填写。

# 地址： 

须是真实可查的地址。可在海外房产网站或点评网站上查找。

# 付款卡： 

可使用信用卡支付，也可选用以下服务商提供的虚拟信用卡，成本更低。

万里汇付卡、PingPong 福卡、连连越达卡、Payoneer、空中云汇的虚拟卡。

注意：这些虚拟卡都要求账户有余额，若账户从未收款，通常无法开卡。可通过 Bkbpay 贝卡帮、某宝等渠道获取。

使用前务必核对卡头，卡头必须与注册国家一致。

例如注册美国店铺，卡头也必须是美国的。

利用 [bincheck.io](http://bincheck.io) 输入虚拟卡号前 6 位即可查询归属国家。

![](img/46a0fdaa904a35fea93b5243a9925a70.png)  

# 收款账户： 

推荐服务商：万里汇、连连、PingPong、空中云汇、光子易。

注意：开户货币种类要与目标国家货币一致。美区 Etsy 需要通过 Plaid 验证，目前虚拟收款账户基本无法通过，暂不建议。

# 手机验证器： 

注册最后一步需二次验证，可用 Google Authenticator 或 Microsoft Authenticator。

国内安卓机安装不便，建议使用 iPhone 下载。

![](img/e187e32d17a371dc235e4f5d5fdd0a9b.png)  

注意： 

1.不建议用手机短信验证，若使用的海外手机号到期未续费，将无法接收短信导致账号无法登录。
2.验证器数据保存在本地，手机丢失或恢复出厂设置后数据无法找回，建议将验证二维码截图备份。
3.也可使用 Enpass 这类密码管理工具保存一次性验证码，并绑定云盘，即使手机丢失，只要账号在就能恢复。

# 产品照片： 

这是最容易被忽略却很关键的一点。Etsy 定位是手工品和复古品，图片必须能体现这一点。

判断标准不是你自己认为是否手工，而是平台能否看出是手工。

最直接的方法是拍摄制作过程，并将过程图作为主图。

最好再保留一份制作视频，之后遇到审核时可用于申诉。

若使用网图，注意修改文件名，并使用工具修改或补充图片元数据。

图片元数据修改工具可用 MagicEXIF。

从网上下载的图片元数据通常为空，修改后会产生数据。

# IP 网络： 

常见的四种注册运营方式。

第一种，注册时用动态住宅 IP，店铺稳定后再切到固定 IP。
第二种，注册之初就用小众服务器 IP，后续保持不变。
第三种，全程使用动态住宅 IP，成本较高。
第四种，通过当地朋友提供专属电脑远程操作，这是最理想的方案。

使用 IP 前，先确认 IP 归属目标国家，并用 [scamalytics.com/ip](http://scamalytics.com/ip) 查看垃圾值，绿色最佳，黄色一般，红色不可用。

建议注册时使用动态住宅 IP，因其环境最干净。

IP 服务商不做具体推荐，可自行搜索。若不知如何选，可选价格较高的，价格越高使用者越少，风控风险越低。

# 浏览器环境： 

建议使用指纹浏览器，如 Adspower 或 HubStudio。

# 04Etsy 注册中的注意事项和常见问题 

# Etsy 注册中的注意事项 

1.付款卡和收款卡尽量选择小众渠道。大众平台使用者多，卡头重复率高，更易触发审核。小众渠道相对更安全。
2.Etsy 的审核是综合打分，身份信息、IP、环境、付款卡、收款卡、商品等多维度计算欺诈风险分，分数越高越容易被审。
3.最安全的运营方式是所有信息、付款、收款、环境都使用当地真实信息，这通常需要与当地人合作分成。
4.注册成功的核心是真实资料和符合标准的商品，其中最容易被忽略的是商品合规性。关键不在于商品是否真手工，而在于能否让平台判定为手工。
5.目前不建议注册美国区 Etsy，会触发 Plaid 验证，市面上虚拟收款账户基本无法通过。
![](img/3e754d090a3a499517814764df926f88.png)  

6.若注册时出现此提示，多为 IP 问题，需更换 IP 服务商，同时更换注册邮箱和密码，避免关联。
![](img/6ae8c909ffd26ac96118e4351973f59b.png)  

7.店铺被暂停时，建议通过邮件申诉，成功率通常高于在线客服申诉。

# Etsy 注册的常见问题 

# Q：用国人注册的美国公司、英国公司、香港公司再注册 Etsy 可行吗？ 

A：经过大量测试，部分成功部分失败。

若已有现成资料可尝试，但为此专门去注册公司成本较高，不建议。

# Q：如何判断网图是否已被 Etsy 他人使用？ 

A：可在手机下载 Etsy App，App 端具备以图搜图功能，可先扫描确认是否已有同类。

# Q：想要一个稳定的 Etsy 店铺，最靠谱的做法是什么？ 

A：最稳的做法是全程模拟正常用户行为。假设你有一个在澳大利亚的亲戚，那么操作方式就是：

做 Etsy，归根到底是在和风控博弈，它更像一个概率评估，而不是非黑即白的规则题。想让店铺活得久，就要让系统判定你是当地真实运营者，而不是跨国机器人在远程操控。

目前最吃香的打法仍然是靠人。找一个在目标市场有常住身份的亲友，用他家里的电脑开机、用当地的网络环境和地址段、用他本人的身份证件照去完成开店，再用他名下的实体银行卡和信用卡把支付闭环跑通。店铺落地后，全程通过远程桌面回这台本地机器去操作。

这种链路的优势是闭环完整且难以撞重：唯一可靠的身份信息、本地终端环境、干净的家庭网络、真实的付款与收款通道。四项同时到位，系统给的异常分会明显下降。唯一不便在于资金，先会进到亲友账户，需要二次转出，且部分地区会产生额外税负，收款人若非欧美本地身份则税负会更明显。

变通办法是先用亲友通道把店铺养熟，等经营稳定后再把收款端切到虚拟收款服务，比如万里汇这类产品。钱就能直达自己账户，且税务环节相对简化。

常被问到：没有海外亲友，能否在国内单干？理论上可以尝试，但风险陡增。

Etsy 开店其实有六个核心抓手：干净的网络线路、能还原当地浏览环境的终端伪装、不会被判定重复的身份资料、背景干净的付款卡、背景干净的收款卡、以及产品图不被平台收录过的「独图」。

环境伪装可以靠指纹浏览器去做，独图也能自己拍或从未上站的视频截图。真正难啃的是网络、付款、收款三件套。

网络部分，若在国内就得向服务商采购海外线路。市场上大致分数据中心线路和家庭线路。数据中心线路常见于阿里云、腾讯云、Google 云、亚马逊云等，成本低但特征明显；家庭线路是运营商分配给真实家庭用户的地址，更接近日常的电信移动网络，更像真人，但价格昂贵且真假参差，假住宅线路不少。

付款收款现也有虚拟卡和收款服务商兜底，例如用万里汇的万里付卡作为付款通道，用万里汇收款账户作为收款通道。

即便以上都齐了，也不等于店铺一定稳。平台的风控本质是一套欺诈分模型，证件、IP、卡片、操作习惯越不像本地正常用户，分值越高，越接近阈值就越危险。规则我们看不到，只能靠细节降分。

理想参照是：一个美国人开美国店，用家里的电脑、美国住宅网络、自己的证件、自己的实体信用卡、自己的银行账户收款。资料唯一、卡段不被滥用，真实度才高。

所以诸如「能否用香港信用卡给美国店付费」「能否用英国资料开美国店」「没澳洲信用卡能否开澳洲店」这类问题，没有标准答案，只能说能试，但成功率与资料本地化程度强相关。条件允许就尽量全本地化，没条件就得接受随时被封的风险。

买资料、买店铺更不建议。资料是否被多卖、是否重复是黑箱，重复资料极易触发拦截。店铺交付时未封不代表后续安全，封因也难以归咎到资料还是操作。

没有海外人脉的，建议暂时别碰这个平台。封店率极高，花几个月做起来的店被整体清零的案例太多，得不偿失。

港澳相关：实测中国护照直接申请香港站基本不通过。用中国人持有的香港公司执照去注册，成功率不稳定，有人成有人败，失败居多。有现成香港公司可以尝试，但要做好被封准备；没有就别专门去注册。

出单就等于安全吗？不等于。大量卖淘宝 1688 通用货的店铺，运营一段时间后仍被抽检下架。Etsy 会不定期抽查产品合规，核心是是否符合平台对原创手工的定义。定义主观，最终由审核员裁定。

稳妥做法是能自拍就自拍，不要盗用站内图，也不要直接搬运国内电商图，必要时做二次处理。风控没有绝对安全，做得越贴合平台要求，存活概率越高。

为何有的明显非手工店还能活？仍是概率问题。假设封店阈值是 60 分。A 店资料真实但付款收款全虚拟，基础分 50，卖蔬菜类目再加 10 分就到线被封。B 店是百分百真实美国店，基础分 10，同样卖蔬菜加到 20 仍在安全区。随着店铺年限和销售额提升，平台容忍度会逐步提高，相当于分数会被稀释。

自制产品自拍仍被封，常见诱因有：订单短期暴涨、大量未发货、客户投诉与侵权、差评扎堆、未缴纳平台费用、资料与环境不合规。即使进入稳定期，平台仍会不定期复核。

发货问题：国内发货、英国店从英国发货，技术上都可以，具体物流打法另述。

店铺被暂停或无法登录的处理。平台对高风险店通常分三级：假期模式、显示暂停、直接无法登录。分值越高处理越重，申诉难度也越大。

判断是否正常，最简单的办法是前台搜索自己的店铺名或产品名，能搜到即为正常状态。

高频封店原因：产品不符合手工定义、收款账户未在 30 天内验证、账单未在每月 21 号前支付、客户投诉侵权、订单长期未发、单量短期增速过快、信用卡异常、资料重复或被多次使用、IP 频繁变动。

运营避坑清单：店铺名、运营者姓名尽量不改动，密码、收款、邮箱变更频率要低；广告预算逐步抬升，新店别上来拉满；严禁刷单；图片优先原创，杜绝电商平台素材和同行照搬；前期只上纯手工，后期再考虑半手工或工厂货；30 单左右店铺相对更稳；价格上架时确定好，用折扣调价；新店日上架建议不超过 3 个；远离侵权；后台 CASE 要及时响应；差评及时沟通，必要时部分退款或补寄；新店首批产品尽量不改动；避免全店统一低折扣；客户留言 24 小时内回复；发货填写尾程单号，避免轨迹显示中国始发；超期发货会降权甚至封店。

新店养号：创建后建议静置 7 天，7 天内被暂停才需要启动申诉。

# 申诉流程

首先，点击联系 Etsy 支持。

点击 learn more here，点击 contact Etsy support

![](img/3426c4a786134d058df8f9518dc9fc55.png)

![](img/d0b6c2c70b0e211f153fff9810989940.png)

拉到底部，点击联系支持。

![](img/34ab4e7d46f9675a27524cef9f8662ba.png)

![](img/5c0b161c3343a6be0a0082a701fe1009.png)

![](img/0cb304ca4edc09555722ec29f48e15a7.png)

![](img/ae1b9cc44f3c0e85d4590c21aa9aa0c5.png)

![](img/c77c8927691ceacc11ddfa9fbf3947da.png)

![](img/b407e8200c316e3816f140286b9388cf.png)

选择邮件申诉。

![](img/174a604d32c5b7b445ebc0b960e96a4b.png)

进入申诉页面，第一个框先打勾。

![](img/95407e28c8d4b7b87c623dc0b1d41520.png)

然后开始写我们的申诉内容。

申诉的内容我们就如实填写自己的情况，申诉内容的长短并不会直接影响最终判定结果。

如果是新店被暂停，那么在附件的地方，可以选择上传产品的手工制作视频（要上传的话最好在申诉中先进行说明），如果没有那就不传。

写完之后点击 Send。

申诉之后，Etsy 会给你发送一封自动邮件（发送到注册时的邮箱里面），过几天之后就会再发一封审核结果的邮件。

Etsy 现在回复邮件的时间越来越慢，7-14 都有可能。

申诉后一般有两种情况。

第一种是店铺恢复：

![](img/6af8f2758d87c216ce8cb7cb9d79abb2.png)

第二种则是店铺被封：

![](img/ffb1645f264d22ceadd05f833bf6ba09.png)

申诉说明：

1.如果 7 天内店铺没有恢复（红色暂停标识消失），且没有收到邮件回复，可以再追加一份申诉。
2.店铺恢复之后，可以到前台搜索一下产品或者店铺名，如果能搜索到，那么恭喜，可以开始正常运营了。
3.即使申诉成功，并不意味着你的店铺就可以一劳永逸了。Etsy 会在店铺出首单，三四单，十单，三十单，百单，甚至千单左右都会再次审核。如果审核不过，则会再次暂停店铺或者直接无法登录账号。
4.除非特别原因（产品侵权，客户投诉等），不然 Etsy 很少会说明暂停店铺、封店的原因，所以我们只能自己排查这个店铺信息和运营行为，看是哪里有问题导致的。

Etsy 发货物流和指纹浏览器用法，住宅 IP、服务器 IP、动态 IP 的区别，以及如何选择 IP，这些内容后续再展开。
