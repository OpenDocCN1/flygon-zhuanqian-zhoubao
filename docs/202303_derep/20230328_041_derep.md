# 《普通人参与 Web3 的低门槛方式》

“想进 Web3 先别纠结门槛，直接上手才是解法。”

我是 KangKang，一名深耕 Web3 投研的全职 Builder，目前负责 [PRE*]Crypto Alpha[/PRE*]，手握 [PRE*]7颗龙珠[/PRE*]，亦是 [PRE*]四期圈友[/PRE*]。

入行算下来也有三年了，起步时我也只是个在岸边看热闹的围观者。没有速成法，全靠实战里踩坑、校准，慢慢拼出了自己的探索路径。2 月我加入了 [PRE*]Web3入门航海[/PRE*] 活动， [PRE*]3月8日[/PRE*] 受邀在内部做了一次复盘分享。分享落地没多久，3 月 22、23 号，团队就拿下了本年度首笔 [PRE*]七位数收益[/PRE*]，差一点运气就能触到八位数。

这次经历给我的启发很直白：Web3 的准入门槛其实被夸大了。拦住大多数人的，既不是技术，也不是信息，而是不敢第一时间下场。不上手永远体会不到逻辑，多试几次，方向感自然就清晰了。

能走到现在，很大程度上要感谢社群里那些带路的前辈。是他们帮我搭起行业认知骨架、梳理发展脉络，让我快速形成系统判断，才敢把职业重心彻底搬过来。也很感谢航海领队的邀请，给了我一次把所学沉淀出来、分享给更多人的机会。

希望还在观望的你，能尽早找到一条适合自己的航线，真正开始行动。
