# 2. 视频号生态全景

微信视频号2020年1月内测，2022年初开始在微信内放量提权。核心原因是2021年底政策调整，将流量分配从MCN手中收回改为普惠制，新号注册就有流量扶持，创作者才愿意持续入驻。

我团队上一航海周期刚结束抖音小店短视频带货，就嗅到视频号流量放大的信号并all in。22年下半年全网涌入视频号，和抖音快手相比，信息差和红利期明显。虽然从赚钱开始我们已经卷了半年多，红利依然在，只是对内容质量和更新速度要求更高。

我们从22年初起就开始测试视频号，前端做账号矩阵跑爆款当季高毛利品，后端搭店群做承接。前端以矩阵起爆款为主，波动大但空间远大于抖音。后端先后接入微信小商店、有赞、爱逛、魔筷、微店官方及第三方，累计30余家，从铺货起步到精细化运营。

2022年12月1日起，视频号清退所有老微信小商店及第三方店铺，只保留视频号小店。目前我方仍在运营20多个视频号小店及部分旗舰店，并跟进官方规则。

今年年初视频号上线了店铺评分和达人橱窗评分体系，带货机制和生态进一步规范。

## 2.1 平台迭代与市场变化

![](img/890b88379de138d8e5cb0b51edbcf16f.png)

2022年1月18日，链接功能上线。直播间可推送直播预告、公众号文章、红包封面、企业微信名片、广告气泡等多种链接，同一时段只能挂一个，可自由切换。

2022年1月24日，第一场付费直播诞生。腾讯NBA自2020年2月入驻视频号，已累计直播123场，2021-2022赛季总决赛观看人数近500万。

2022年3月初，蓝V账号可在主页添加服务菜单，为企业提供了类似官网的服务入口。

2022年3月中旬，直播PC端中控台升级，支持实时在线、观看人数、观看次数、点赞、评论、分享、送礼、成交等数据，指标5秒刷新，趋势1分钟刷新，公众号身份开播还能看新增粉丝。

2022年7月18日，原生信息流广告上线，可导向品牌小程序、原生推广页/H5、商品下单页。

2022年7月21日，视频号小店正式上线，成为橱窗上架主载体，原微信小商店逐步退出橱窗。

2022年8月初，“帮上热门”功能上线，类似小红书薯条、抖音DOU+。

2022年8月17日，“视频号小任务”上线，广告主通过视频号活动找创作者投放，按效果结算。

2022年8月下旬，微信豆采买流量券能力全量开放，可在开播页“更多”找到创作者流量包。

2022年11月2日，上线视频号优选联盟，类抖音精选联盟，需企业执照才能入驻，个体户暂不支持。

2022年12月1日，带货仅限优选联盟内的视频号小店产品，第三方店铺彻底退出。

## 2.2 运营者视角的时间线总结

2022年3-5月：搬运即可爆，支持无人/半无人直播，店铺店群铺货模式吃香。

2022年6-8月：简单混剪还能爆，无人直播被严打，半无人易被判定低质。店铺开始查刷量、重复铺货。

2022年11月：新号扶持周期缩短，后端开始清理微信小商店及有赞、爱逛、魔筷、微盟、微店等第三方。

## 2.3 短视频带货视角

选品要更快，看谁先搬谁就是原创，务必规避侵权。

混剪建议打乱素材组合，抖音可过，视频号审核更严，需加入实拍元素。目前我们验证实拍素材+高赞标题效果不错，有条件的建议从仿拍过渡到原创。

## 2.4 直播带货视角

我们主打后端店群+带货矩阵号，视频先起量，再开播转化。这种模式转化稳定，也在测试0作品冷启动直播，靠人货场+少量投流起号。

投流起号不稳定，平台投放精准度有限。建议短视频与直播配合，小额多次测素材再放量。

## 2.5 后端店群视角

后端正在走规范化：

1. 个体户无法入驻优选联盟
2. 企业入驻保证金门槛高
3. 提现走企业对公，财税成本上升
4. 退货投诉率超标当天清退

# 3. 视频号变现路径

接下来讲实操玩法。航海手册里已讲得很细，这里做精简。除了直接带货，私域沉淀的价值更高。部分圈友做中高端客单，利润反而高于纯带货。

## 选品核心是真实需求，选品能力大于运营能力

永恒的四个需求：男人求成功、女人求美丽、老人求健康、孩子求聪明。

确定细分类目，满足刚需，再测匹配度。

建议每天固定1小时刷品，把账号标签设为目标人群。例如做中老年品，就把账号设为50岁，点赞50岁会看的内容，持续刷取系统推荐，记录到表格。每天至少分析10个以上账号。

不要只刷一个平台，视频号、抖音、快手、小红书、拼多多多平台交叉参考，算法和人群差异明显。

## 数据工具要常备

百度指数、巨量算数、微信指数，覆盖全网热度，可看活跃度、搜索量，辅助决策。

过去我们店群60%订单来自达人，40%来自自有矩阵或圈友合作。多数达人自助上架，成交后才知晓，联系调整佣金时回复率低。也有从抖音邀约来的达人，同视频换平台发依然带货，视频号保证金仅100元/号，每人可绑5个微信=5个号，共500元押金。

相比后端的客服、拍单、供应链、压款、税务、售后、打假，后端人力和资金压力更大。

短视频带货三条铁律

1. 选品要反复确认人群、需求、利润
2. 多号测试，一人可实名5微信=5视频号，轮换测品交互，勿单号单品

# 4. 直播相关打法

真人直播、半无人直播、纯无人直播三类玩法，细分很多。

半无人可分视频+真人音频、真人出镜+音频、视频+真人出镜+音频等。我们都测过，没一招通吃，产品、人群、成本决定玩法。

不建议新手做无人/半无人。抖音可容忍半无人，视频号管控极严，且惩罚不可逆。抖音快手封号可养分恢复，视频号违规即便显示3-7天限流，解封后流量也会持续衰减，只能换绑重来。

当下更稳妥的是视频爆了再引导开播成交，话术简单，可参考圈友分享。

# 5. 投放相关

赚钱搜【视频号 投放】有大量干货，这里只说要点

1. 投放不稳定，易跑不出、跑飞，赔付机制弱
2. 部分账号无法投或0消耗
3. 标签不够精准，不适合大额放量
4. 更适合起号和刷标签，锦上添花不能雪中送炭，承接能力必须到位

我们经验有限，主要靠视频测品，视频导入直播间转化率最高。

圈内已有投放监控工具，可多账号监控、自动关停跟投，提效明显。

# 7. 对视频号的整体感受

1. 流量红利：标签不如抖音稳，但起号起流量相对容易
2. 利润红利：行业普遍比抖音贵1-3倍
3. 人群红利：三四线+中老年触网少，信任高，退换货少
4. 私域红利：视频号引流微信极其容易，私域做到位利润是5-10倍指数增长

上次航海有圈友做护肤品，成本20卖99，一单50件近5000元。近期我们合作达人爆的定制品成本10-20，售价50-120，前后端都有利润且可复购，这类品需多测才能持续。

# 8. 2023年运营建议

1. 内容运营：短视频+直播结合
2. 形式迭代：搬运→混剪→仿拍→实拍
3. 私域运营：互联网尽头是微信，视频号天生适合引流微信。私域优先级高于内容建设，有能力者重仓私域
4. 投流放大：系统不稳定但在快速成长，少量多次优化模型
