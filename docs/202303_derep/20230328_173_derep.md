# 陪人看病如何变现？我梳理了 11 种落地玩法

赚钱有术四期老成员，在下静水。过去一年多，我基本都在陪诊一线打转，对这类服务的赚钱路数也算摸出了一些门道。眼下陪诊话题越来越热，一些圈友也已经下场试水。借这个机会，我把摸过的路子归纳成 11 种，分享给各位。

这次分享，我想顺便完成三件事：
其一，给准备入行的朋友提供一点方向和启发；
其二，广州是华南区域的医疗重镇，我进出医院多次，把亲身体验整理成了附件，外地朋友想到广州就医，可以参考；
其三，专家号挂不上的时候，还有几条备选通道，也会一并列出。

评论区里也有不少有意思的反馈，摘几条：

- 有圈友感慨：大学毕业生又多了一条可以落脚的路。
- 一位朋友因为家中长辈就医频繁，多次往医院跑；他提到曾在B站看过陪诊从业者的分享，说生病的状态和健康状态差别很大，这行要跟形形色色的人打交道，复杂且有风险。
- 有人说，每天都像在补新知识。
- 也有人表示，看完大开眼界。
- 还有人对文中那个“限制性措辞”很感兴趣，觉得这个说法用得妙。
- 有位从业者直言，整天与病患待在一起，容易积攒负面情绪；玄学里称之为“病气”，因为很多患者给人的感觉确实和常人不同。
- 另一位圈友接着补了一句：戴护身符也有用；玄学认为生病是负能量缠身，科学叫能量场失衡，有有益和有害之分。
