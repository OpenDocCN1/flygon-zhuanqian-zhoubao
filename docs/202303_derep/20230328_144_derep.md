# 一、什么是鸡血石

鸡血石对很多人来说比较陌生。简单来说，它是中国特有的稀有印石，因石质中鲜红色斑块如鸡血般命名，主要产自浙江昌化和内蒙古赤峰巴林一带。昌化鸡血石位列中国四大国石，与寿山田黄、青田冻石并称“印石三宝”。

历史层面，鸡血石自古被视作富贵祥瑞之物。清代康熙、乾隆等皇帝及后妃多用昌化鸡血石制宝玺。近现代郭沫若、吴昌硕、齐白石、徐悲鸿等大家都与之有缘。其影响力遍及五大洲，在日韩新加坡等华人圈认可度极高。

# 二、为什么选择鸡血石

我老家就在昌化鸡血石主产地玉岩山脚下，家族做鸡血石线下生意已几十年，积累了货源和渠道。

2021年线下行情低迷，父亲的传统生意并不好做，而抖音兴趣电商正迎来爆发期。两家同行提前入局两个月就有了不错成绩，证明即便像鸡血石这样的小众品，在抖音也有受众。

叠加家族资源、市场验证，以及加入尹晨俱乐部后对电商前景的认知，我女朋友果断停掉当时还在亏损的短视频项目，转为主播身份试水鸡血石直播带货。到现在她仍说，尹晨像一盏灯指引了方向。

选定赛道后就要死磕执行，也要抱团取暖。好的圈子如赚钱、尹晨俱乐部，赋能感很强。

# 三、鸡血石直播的几个阶段

## （1）前期准备：设备和入驻基地事宜

鸡血石在抖音属于特殊商品，需报白并提供营业执照。文玩类目基本都要入驻官方质检基地。

我们入驻的是抖音青田石雕基地。很多人觉得基地报白麻烦，要交质检费、不能直发，但质检证书能有效解决用户最关心的真伪问题。初期基地审核松，后来标准收紧，不合格直接驳回。对高客单文玩来说，走基地是信任背书。

设备上别过度投入。我们起步就是两盏灯加一部手机，在15平米不到的小房间就开播了。创业初期要控成本，盲目租写字楼只会增加失败概率。

## （2）第一阶段：随便发发，几十个作品，粉丝 1000+

起号我们直接用了父亲的老号，他此前发过几十条鸡血石视频，粉丝刚好破千，满足了开播门槛。

建议新手起号先养号，让新观众知道账号在做什么。我们后来因违规被迫换小号，零作品零权重，开播后自然流量几乎为零。

## （3）第二阶段：转型人设 IP 账号，确定手播形式

正式开播前，我们重新梳理定位。账号名、简介、角色分工全部明确：父亲是掌柜，负责选品定价；女朋友是主播，是“石痴掌柜的徒弟”，负责文化传播；我负责运营发货客服。

之前账号全是商品图，后来加入真人出镜，讲解鸡血石历史与收藏价值，逐步建立人设。参考珠宝直播的手播模式，我们也采用手播，降低新手主播的镜头压力。21年8月2日，用最低成本正式开播。

## （4）第三阶段：实打实送福利，积累忠实用户

21年8月2日开播时我们都是小白，平播硬播。女朋友为此恶补了鸡血石书籍，第一场直播就准备了一页纸的专业介绍。鸡血石品种多、非标品多，每件都需要单独讲解。

小众品早期自然流量还不错。第一天没出单，第二天就成交了一枚4000+的印章，之后几天单价几千到上万的订单不断，验证了赛道需求。

前期玩法很粗暴：开播截屏送一枚昌化石印章，中途再送一枚，收官再送一枚，一场送三枚。当时成本200-300元/枚，真实送出。靠着福利聚拢了第一批铁粉，日活稳定，权重提升。

我们还持续发抖币福袋稳人气。高客单直播，讲解一枚印章要5-10分钟，容易流失。高人气能提高停留和转化。半年下来场观稳定在3000+，平均在线30+。到21年底，我们还在吃自然流量红利，未投流也能稳定成交。

## （5）第四阶段：流量瓶颈，开始进入千川投流

送礼活动做了6个月成本扛不住后停止，22年初遭遇流量瓶颈。自然流量递减，老粉占比高，场观跌到1000+，在线剩十几个，连续十天零成交，焦虑感爆棚。

22年2月底尹晨和郭郭来直播间指导后，我们开始尝试千川投放，并调整活动逻辑。送礼成本转投流：一条计划做极速推抢人气，两条计划做达人相似找精准人群。

鸡血石日成交1-2万，爆时5万，投流预算只能控制在1000左右。投法以达人相似为主，可用蝉妈妈或小店后台精选联盟找文玩类达人。

## （6）第五阶段：增加趣味性，开始推出拍卖形式

平播讲品成交率低，于是引入拍卖。鸡血石印章非标独一无二，非常适合价高者得。拍卖款一般定价1000左右，薄利走量；拍卖结束后连带讲解高货，价值数万。

我们拍卖不设托，保持真实。鸡血石本就小众，信任比一时成交更重要。有时出价未达预期也会发链接。真实玩法带来复购，很多客户低价拍到满意后会回头买高货。

平播依然保留。最难的是进直播间第一眼不喜欢就走，价格一高就走。容易的是遇到识货的客户，一眼相中直接付款。犹豫客户我们会给私下更优惠价格促成下单。

推出拍卖+讲品组合后，22年9月我们做到抖音石雕类目第一。只要需求存在，再小众也能变现。

## （7）第六阶段：增强人设，打造场景，从手播到真人出镜

21年8月到22年底我们一直手播，成本低、门槛低。但浏览珽珽紫砂、达观说器等优秀间后发现，摄像机+真人出镜更能拉近距离，产品还原更清晰。

2023年初我们重新装修直播间，升级专业设备，从手播转为真人出镜，人设曝光度明显提升。我们是鸡血石赛道首家用摄像机直播的同行。

直播本质是人货场。场景差异化能提升停留和成交概率。

# 四、关于用户如何承接进入私域实现复购

私域我们做得很少，但重要性不言而喻。目前下单客户基本没有主动引流，仅靠客户主动加微信。团队仅3人，精力有限。

加过来的客户非常精准，多为几万元的高货需求，由父亲一对一成交。经微信成交的金额已超百万。信任建立后复购率很高。

今年我们已在杭州临安开设实体艺术馆“石痴鸡血石艺术馆”，线上线下互相背书。高客单交易更需要线下看实物确认的环节。

# 五、新人想做的门槛和建议

鸡血石属于蓝海，综合利润约30%，不算高但能养活团队。真正的暴利在赌石，不展开。

门槛在于资源与专业度。鸡血石矿产受限，多年封矿，家族沉淀几十年才有货源。选品难度大，每块石头的定价、品类、讲解都需要专业知识，我们到现在对价格认知仍在学习中，选品仍由父亲把控。

印石赛道可延伸到寿山石、青田石等文玩品类，有资源的可尝试。我们手里还有一批冻石资源想做文创，若有伙伴可合作开发。

# 六、关于抖音鸡血石直播的经验分享

做高客单直播近一年半，我们仍在摸索。主播自己说就是在硬播，播多了才有感觉，能抓住有意向用户。

给新手的建议：别犹豫，早开播。每播一场就是一份经验。我们起步时也不确定线下行情差，线上能否打通。做了才知道，每个阶段都有资金、设备、场景、流量、成交等难题，关键是解决问题并坚持。

相信平台的红利，也相信小众品也能成交。我们还在路上，一起加油。
