# 赚钱与成长，我用四年保险创业悟出的 13 条心得

> 原文：[`www.yuque.com/for_lazy/thfiu8/pl9lncggggue1h31`](https://www.yuque.com/for_lazy/thfiu8/pl9lncggggue1h31)

大家好，我是小冯妮儿，赚钱做保险的首席经纪人，做了四年保险创业。

1、钱和成长像一对矛盾体，互相拉扯又互相成就。最理想的状态是去赚能带你变得更好的钱。只盯着赚钱，容易沦为提款工具，价值感被掏空；只谈成长，不顾生计，又会陷入经济焦虑。

2、刚起步时，让赚钱这件事占更大比重，是非常必要的。第一笔收入带来的手感与底气，远比项目形式、商业模式重要。

我就是稀里糊涂靠写公众号赚到第一笔可观收入的，从那以后心里一直有个声音：赚钱其实没那么难，我也能做到。这个“我也能行”的信念成了强心剂。之后无论碰到什么坎，我都敢硬扛，关关都能过，路路都能行。

3、涛哥说过一句话我很认同：赚钱是最好的修行。因为赚钱是结果，而要拿到这个结果，你必须不断升级打怪，去面对世界的不确定性。这个过程会逼着你成长。所以说，目标是手段，走过的路才是真正的收获。

4、生活充满变数，每一段阶段不一定能带来收入，但一定能沉淀能力。把每一次挫折都当成一份礼物，接住它，你的心力会越练越厚。

我卖了四年保险，见过太多人生切片：问了不买的、买了后悔的、不买后悔的、理赔后嫌保额不够的……最终领悟到无常才是常态。与其对抗，不如臣服当下，相信一切安排自有其道理。

5、不要把赚钱当成唯一目的。如果你已经解决了温饱焦虑，就要把创业和副业的成长价值提上来。人类不能像机器一样只为赚钱而活。物质稳定后，人会本能地寻找更高阶的人生意义，那就是自我实现。

6、如果暂时没找到人生大方向，就先选一条能持续向上攀爬的路，在走的过程中慢慢找。只要业务水位在抬升，你会不断遇见更优秀的人、更开阔的视角。思想的碰撞会一点点修正你的三观，把你推向正确的方向。

7、想让收入持久，核心是找到自己发自内心的热爱并深耕进去。很多生意到最后拼的都是耐力。比如做个人IP，每天写东西、拍视频、刷朋友圈，就是日常。没有持续的热情去支撑，就很难坚持下去，很快会迷失初心，甚至在离成功很近的地方因为体力不支而放弃。

8、赚钱要顺着天赋走，做那些不需要靠意志力硬撑就能做好的事，成功率会高很多。我天生就是个话痨，爱聊天是本能，而保险的本质就是要聊够足够多的人。这件事对我来说是自然流露，不需要逼自己。

9、怎么卖得更贵、更有底气？去和更广阔的世界碰撞。价格等于价值，而价值不是自己喊出来的，是当你服务的人越来越多时，你越来越感受到“被需要”。

举个例子，简历修改对你是手到擒来的小事，但对刚毕业的求职者来说，可能直接改变职业轨迹。当你和不同的人交换认知，体会到自己的专业在别人生命里是刚需时，你的自我认知会不断被强化，敢收价的底气自然就有了。

10、敢收钱，才是最负责任的表现。帮别人做事却不好意思收费，看似善良，实则给自己留了退路。收了钱，就有责任，就不能敷衍了事。你必须逼着自己真正解决问题，有了压力，才有动力把它做到位。

11、收钱也是对自己的保护。要是免费回答太多问题，就得想好被白嫖后的心理落差。从咨询到下单中间隔着很长的距离，问的人不一定买单。要么做好心理建设，就算最后没成交也心甘情愿交个朋友，要么就用收费来筛选心态。清晰边界，才能避免受害者心态。

我意识到这点后，后来都很大方地把费用说清楚。既保护了自己，也对客户负责。

12、想赚更多钱，先投资见识。能卖高价的人，往往不是天生自信，而是亲眼见过别人卖成什么样。我刚入门时，认识的前辈专门盯着国内福布斯富豪榜去卖保险，冲着亿元保单去的。那一刻我的认知被打开了，原来天花板远不止我看到的那么低。

13、切记不要为了赚钱而赚钱，尤其是当赚钱和成长出现冲突时。如果有一笔钱让你心里不舒服，哪怕不缺钱，也宁可不要。赚到不合适的钱，很可能后面会有反噬。记住：只与对的人合作，只赚对的钱。
