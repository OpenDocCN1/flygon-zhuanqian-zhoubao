# 现象级MMORPG游戏里，变现的切口藏在哪



大家好，我是姚麻。好久没在赚钱更新了，正好杭州线下见面会要来了，先来刷个存在感。

今天聊一个题：当市场出现一款现象级的MMORPG，以马上要全平台公测的逆水寒手游为例，能从中撬到哪些变现机会。

先给不常玩游戏的朋友科普下，MMORPG说白了就是【选个角色，刷怪升级堆属性，能跟别人组队、进本、打架】的养成型网游。

从早期的魔兽世界、问道、征途、天龙八部，到后来的天涯明月刀、剑灵、九阴真经、龙之谷、逆水寒，都是这个赛道。

我个人的第一桶金就是大学时靠天涯明月刀端游打出来的，手游上线那年又赚了小几十万。

6月30号逆水寒手游要全面公测，我觉得是个窗口期。虽然我自己没精力再去卷，但赚钱圈里肯定有人感兴趣，就把思路捋清楚给大家参考一下。

# 一、先看底层逻辑

其实很简单，变现公式就一句话：需求 + 流量 + 交付 = 赚钱。

先说流量。逆水寒手游公测期的热度流量，毋庸置疑是顶级的。端游当年就封神过，天刀手游上线前半年也是全网爆，天刀的冷启动也一样。逆水寒手游上一次内测时，游戏圈的讨论度已经很高了。

这三点叠加下来就一个结论：盘子大、玩家多，只要肯做，流量自己会来。

什么是现象级？逆水寒手游这次出来绝对算得上现象级，非托非软文。能火多久另说，但开局的势能是实打实的。

再说玩家画像。国产MMORPG的共性是【肝、氪、上头，沉没成本极高】。这批玩家里有一大撮人，对数值有追求，但要么懒、要么肝不过来。

于是就形成了两种解决方式：充钱解决，充钱解决不了就花钱找人。

拿天刀和逆水寒举例，能稳定玩下来的玩家，自费加代费算一起，几千到上万很正常，这叫平民。十几万几十万氪的，市面上到处都是。玩着玩着花几百万上千万的也不稀奇，开服大半年到一年，每个区的榜前几基本都是这个量级。

总结就是三点：需求旺、付费意愿强、客单价高。

最后说需求和交付。只要用户有痛点，你能提供解决方案，就能收费。之前在视频号航海讲选品思路时我说过一句话，选品就是找需求。

下面我结合游戏实际玩法，把玩家常见的需求点、对应的交付方式、以及拉流方法都拆开讲。

不同玩法对人的要求不一样，看完后大家按自身情况挑一个去做就行。我自己做过或比较熟的就多讲几句，不熟的就简略带过。

统一说明下流量闭环。无论是游戏内还是第三方平台来的流量，最终都要沉淀到微信做沟通和交易，这是私域的终点。

# 二、具体可操作的五种玩法

## 1. 日常代练、代肝、托管

MMORPG里日活任务很多：日常本、周常本、主线支线、成就收集。特别是网易系，肝度拉满。

开服初期大家都还新鲜，时间一长重复枯燥的任务就让人想吐，但又不能不做，不然就掉队。与其自己受罪，不如花钱找人代做。

门槛是最低的，只要是个正常玩家愿意花时间就能上手。缺点是累、天花板低。

日常代练按号包月一般几百块，按天算30-50块左右，开服高峰期100/天也能接。靠量吃饭，积攒一批稳定客户，一个月也能做到大几千上万。

更高级的是大号托管。碰到大方的大佬，一个月几千起步，你负责玩他负责氪，体验很爽。能抓住几个靠谱的大号，收入很可观。

但大号和普通号区别很大。你必须把游戏玩透，不能让大佬白花钱。同样充20W，必须让他战力碾压别人才有价值。每天该做的一定要做完，号主上线看到全是完成的任务，没有红点，想找事做都找不到，这才能稳住大佬的信任，好意思开口要高价，还能介绍更多号。

引流方式很基础：游戏公共频道刷广告、贴吧论坛发贴、混进帮派群、吃瓜群、组队群，改个备注说接日常托管，平时多潜水偶尔冒泡，总能有单子上门。

## 2. 搬砖工作室

游戏机制决定了单号产出金和材料的上限。想比别人强，就得靠人民币。

一种是直接充点券换金，再用金买材料装备。另一种是找玩家买金，但正常玩家自己都不够用。

这时工作室就有了价值。利用多开+脚本，用大量小号刷日常赚铜钱和材料，再挂到藏宝阁或线下卖给玩家换人民币，简单说就是打金。

举个例子，一个普通玩家一天也就打50金左右。用多开器一台电脑挂10号，五台就是50号，一轮3小时，一天8轮，就是2万金产出，挂上去就能变现。

![](img/20e2e0c98036391cd8b8b6adb6419ae8.png)

线下交易更灵活。商城兑金约1块10金，藏宝阁1块15金左右，你直接交易给玩家1块20金，绕开平台抽成，玩家也愿意。

这里的数值仅供理解，真实工作室的规模、产值、售价我没实操过不详。金价会随供需波动，越到后期金价越低是规律。

门槛在于设备、软件、账号。设备软件花钱就能解决，账号是难点。逆水寒手游用网易账号登录，一个号能注册5个角色，起号要准备几十个账号以上。网上有批量注册渠道，找不找得到自行探索。

引流基本靠广告轰炸，也可以去排行榜私聊大佬问是否需要收金，量大且易形成回头客。

## 3. 看号、教学主播

游戏刚开服时，大部分人都是小白。职业搭配、装备技能、剧情副本流程、礼包怎么买、花钱怎么花、隐藏成就怎么拿，这些都是刚需。

看号教学主播就是萌新导师，用领先的理解经验去带人变现。

你也是小白怎么办？4月28日逆水寒手游二测会开，有条件的花大几百上千买个测试资格，先玩一波，公测就是老玩家了。

不想花钱就去斗鱼虎牙看二测直播，多逛抖音B站把各路攻略整理成文档：职业特性连招、副本攻略、资源点汇总、氪金技巧等等，形成自己的知识库就能开播了。

实在想偷懒，等公测后边玩边看同行，拿同行文档改改用，也能先起步，就是会慢几天，可能错过热度窗口。

变现方式：直播打赏为主。斗鱼虎牙常见是办卡6块看号、飞机100块插队。

看号指观众把号交给你，你帮他诊断问题，换装备、换技能、该买什么礼包、用什么心法，一般几分钟一个，一天几十个号很正常，排队插队都很多。

教学主播卖的是文档和群。办卡进粉丝群拿全职业副本攻略，或直接卖收费群，还能做收徒、1v1高客单教学。

![](img/4a86767959a6b9e67aab3b5a00d88e61.png)

一般能做起来后，看号、教学、托管可以一起做。看号是前端，用号主的充值情况判断其经济实力，顺势推托管或账号打造。能接到冲榜的大佬，直播间效果和热度都会拉满。

平台差异：抖音可能能播，但不能明挂QQ微信，得先导到抖音粉丝群再转到QQ/微信。抖音流量更大但大佬比例略低。配合直播切片发短视频，能放大引流效果。

要注意，看号是开服前一个月的红利期，之后玩家都熟练了需求会断崖式下跌。所以不能只做看号，必须转成教学导师IP，并承接托管打造，才能做长久。

## 4. 职业代打

MMORPG都有PK竞技。逆水寒有1v1也有3v3，有段位和排行榜，段位给奖励加成，排行榜是装逼利器。

代打就是替号主打竞技场，和LOL王者代练上分一个逻辑。

需要代打的两类人：一类是平民手残/妹子，自己打不动但想要最高奖励段位；一类是大佬，号猛钱多但不玩，觉得充这么多钱上不了榜没面子。

主要收费模式：

1. 代打段位。按段位数量收费。以天刀为例，数字段1-9段几乎没钱，试剑-造极期50-100/段，武痴-求败期100-300/段。从1段打到求败24段，打包2000-3000很正常，前期价，后期跌到500-800。

2. 清币收费。每周竞技场周常需完成场次拿奖励币换资源。按周100-200、包月500-800、包赛季几千收。

3. 按时收费。比如飞机100块打半小时，火箭500块插队2小时，或微信转账按时长算。

4. 代打冲榜。针对大佬，冲区服/大区赛季前十，前十收五位数，大区前十收大五位数不等，看行情和号主议价。

5. 赛事代打。每个赛季官方有竞技赛事，天刀的剑荡八荒就是典型，16强拿银剑、4强金剑、冠军冰剑，还会全区通报，荣誉感极强，所以报价很高。

## 5. 帮派管理、指挥

帮派/公会是MMORPG的核心玩法，直接影响玩家体验和资源分配。大佬愿意花钱把帮派做强，管理体系会照搬公司化运作。

管理层和指挥官领工资，帮众做KPI发福利，还有HR专门挖人，挖一个大佬给多少钱都有标准。

做管理其实技术含量不高，关键是先找到一个真大佬在烧钱的帮派，和大佬搞好关系，其余都是套用其他游戏公会的制度，协调活动、处理矛盾即可。每天打游戏还能拿月薪几千上万，甚至有管理在KPI上做手脚截留福利的。

指挥官负责野外群架、宣战、帮战，是另一个核心岗，能力强的一人带队，弱的就几人分工。

以上五条线，都能在逆水寒手游公测期找到机会。选哪条，看你的时间、技术和资源承受度。

先聊几句帮会战斗的岗位排法。大多数时候，正面战线要配一位总负责人和一位副手，分战线再另出一个人牵头，加起来就是三个核心位。资金宽裕的帮会还常常单设一个机动岗，专管野外遭遇，但这属于可选项。

想当上这个带头人，门路其实不复杂：多看、多学、多下场。去视频平台搜实战录音，认真琢磨别人是怎样报点、怎样调动阵容、怎样抓时机，把常用打法和底层机制摸透，再自己开麦历练一阵，及格线很快就能碰到。

但从及格往上游，就得真正花心思了。一方面要和管理层联手，把队内默契和纪律一点一点养出来；另一方面得坚持做战后回顾，哪儿出了岔子、哪儿打得漂亮都记下来，补齐短板、放大长处，进步才会持续。

等到你能独当一面了，不妨试着做内容：把高光的战斗片段剪成短集锦发去抖音，把整场思路理成回顾视频放上B站。运气好能被大老板相中，运气一般也能借机结识一批同行，往后开个交流小圈子、带带新人收点费用，都是顺理成章的事。

报价通常是两条路：按月谈定总额，或者按场次结算。拿《天涯明月刀》手游的前中期来说，一名普通带团队长的单场行情大约是两百元，一周三场、一个月十二场就是两千四；整月包断一般在一千五到三千之间，具体看怎么谈。

有了名气之后，单场开到五百到八百并不稀奇，我甚至还见过月度两万的价。等版本步入后期，多数会回落到百元一场，整月大约一千到一千五。

讲点我自己的经历。当年认真玩这款手游时，我自己拉扯起一个帮会，请不起指挥官，只好亲自顶上。帮里都是普通玩家，没有财力雄厚的靠山，硬是靠纪律和拧成一股绳的劲头，从低分组一路攀到最高档次，冠军也拿过几回。现在回头想，那段一起拼杀的日子还挺让人动容，都是青春。

后来在这个小圈子里混出点名堂，不少打PK的老板都来邀我过去带团，最高的单场开到过一千。

## 6.副本代打

这里讲的不是大家更熟悉的PK代练，而是专门帮人通关副本的服务队伍。

现在的厂商很少再做那种属性不够就硬卡住的“数值关”，更偏爱设计“机制关”：怪物数值并不离谱，真正考验的是玩家对机制的理解和队员间的配合。在装备成型之前，不少人的操作和默契都撑不起开荒，一卡就是好几天，于是代练队伍应运而生：登进客户端，替全队把副本打通。

还有些老板为了拿首个通关或者竞速纪录，自己实在打不出效果，干脆请一组磨合成熟的代练上号。

费用可以参考早期《逆水寒》的十二人团队本“舞阳城”：一个号五十到一百元，一车坐满就是六百到一千二；要是还掉落了值钱的可交易道具，另外再加钱。

按手游端副本的节奏，熟练队伍十五到三十分钟就能清完一车，按二十分钟估算。单子足的时候，一天跑十五到二十车很常见，均摊到每个人头上，日入几百上千不是问题。

想拉起一支过关的队伍没有捷径：先找四五个固定队友起步，最多能扩到十五人；多看别人的通关思路，自己多练多磨，集中肝上几天基本就成型了。接单的渠道还是老几样：在地图频道刷存在感、进各类群发公告、能开播就开播、再把录制内容同步传到抖音和B站。

## 7.定制图与宣传片

画师这门生意一直有热度，主要工作就是按玩家的要求或者游戏角色的形象，画出让人满意的头像、壁纸。以前这行有门槛，至少得会画，风格还得够全。

现在省事多了，直接上AI出图就成——反正这种客户又不追究源文件，只要出图快、画面够好看就行。

价格方面没有固定标尺。纯手绘那阵子，我见过最低三十元一张，也见过五百元一张还得预约排队的。

流量可以从小红书做起，多晒作品，毕竟愿意为头像花钱的大多是女玩家；抖音也同步发，万一哪条视频爆了，单子能接到手软。

![](img/f89714769bd69e37e7a2ff0b9e7b7b48.png)

宣传片则是“导演”上号录制游戏内的实况镜头——作品风格可以到抖音/B站搜“云小叠”参考——再用调色、踩点剪辑、加特效这些手段，做出一段几十秒到几分钟不等的成片。常见的类型有帮会宣传、情侣纪念、好友纪念。

![](img/2136577ba0a759593d87e932036dba4e.png)

报价一般按秒或分钟计，也有人直接开一口价。我和“导演”交集不多，只认识一位做得比较好的，全网粉丝加起来几十万，她的标准就当个参考：一分钟以内按每秒三十元算，或者打包一千五一条；一分钟以上的部分按分钟收，两千到五千一分钟，看客户需求浮动。如果你对剪辑后期比较熟，这个方向相当值得碰。

画师和导演还能顺手接一些主播的定制小单——做开播用的底板图或者封面。通常是从游戏里截一张帅图，抠成无背景的素材，再把主播昵称和联系方式排进去，一张收费一两百真不算多。

## 8.外观与家居定制

这里有两种打法：一种是走原创路线，自己把这些琢磨透，形成一套个人技能，然后四处发布作品吸引关注，再去卖定制化、高客单价的服务；另一种是走整合路线，把市面上常见的现成资源收集打包，一份卖个几块十几块，走量也能卖得很好。

## 9.建社群

这个玩法和具体产品的内容关联不大，核心是借着游戏的热度，把游戏当成一个引流的入口，靠各种群沉淀人群，再考虑后续的转化。

常见的有讨论群、吃瓜群、CP群，开放拉人权限，稍加引导就能迅速把很多群填满。

后续怎么做，要看你的用户画像，通常是18到30岁的年轻人。第一种思路，假设我本身是卖复刻品的微商，需要的客群恰好和游戏人群重叠，那就借游戏的名义把玩家先圈进群，加上好友，再用朋友圈慢慢渗透转化。

第二种思路，还是继续围绕产品做深度运营：在普通群之上，再推出一个高门槛付费群，入场费288元；群内定期组织小规模内战、趣味赛、各种主题聚会，让愿意花钱的人能享受更好的社交圈层。

也可以和做其他项目的人合作——你缺流量，我手里正好有群，允许对方在群里合理推广，商量好分成比例就行。不管选哪条路，用建群的方式都能沉淀出精准的游戏用户，之后筛选付费人群是水到渠成的事。

## 10.主持“扒一扒”

每一款MMORPG都是一座微型社会，情感纠纷和利益冲突永远不缺：今天有人装渣男玩消失，明天有人被扒已婚带俩娃还处CP，后天榜一大哥被爆借钱氪金，大后天又传出某帮派安插卧底的消息……吃瓜群众从来不嫌事大。

所谓主持818，就是给对线双方提供一个公开舞台：圈定一个语音房间或直播间，把双方拉进来，维持发言秩序，最后做一番收束总结。平时没专场时，就经营一个爆料号，多发抖音、多建八卦群。

收费的玩法很灵活：主持人先收五百主持费，不为过吧？语音房间的管理位可以卖188，买下之后能随意上麦、拉人、开自己的小房间；整个频道的冠名权，在几千上万人同时在线的时候，一天收一千也不过分。

如果是直播间，那就更简单了——只要人气的盘子够大，光是收礼物就能收到手软。

这行的难点在于两点：第一，整场过程中怎么尽量抽离个人情绪，保持中立，只做好自己分内的事；第二，遇到大瓜的时候，怎么发动更多真实用户去游戏内外帮你扩散。

## 11.工具类小软件

我不懂开发，就只讲两个印象比较深的方向。

一种是脚本类。比如前面搬砖工作室提过的自动挂机、自动跑任务脚本，不管是卖给工作室还是卖给散人玩家，都有不错的市场。

另一种是类似连点器的抢资源脚本。有些活动会产出限量材料，想拿全看手速，可抢的人太多、手快的人也太多，那就挂脚本，一抢一个准。

以《天涯明月刀》为例，每周日帮会活动结束后，本服拍卖行会放出有限的稀有铸造材料。假设全服排名靠前的几位都急着做高级武器，每周一共就二十份，根本不够分。这时候你带着代抢脚本找上门：“帮你抢一个，加价两百”，对方大概率不会拒绝。

还有一种扫码登录辅助工具。腾讯系的产品基本都是QQ或微信登录，iOS用户想上别人的号，就得靠这类工具生成二维码，原理好像是模拟成平板设备。通常用一个微信公众号来承载，登录链接藏在文章原文里，收益来自页面广告和公众号本身的流量。不过这个可能要打个问号——网易系的产品大多不用这么折腾，直接给账号密码或者扫码就行。

## 12.主播经纪

这个不用我多解释。只要一款产品有热度，想开播的人就不会缺，趁流量高峰把主播经纪班子搭起来，多签一些人，后面安心吃礼物分成就可以了。

## 13.账号交易与租赁

虽然网易有官方交易平台藏宝阁，但第三方渠道始终有人用；租赁那边更是如此，官方可不会支持租号，不想氪金的玩家又想体验满配大号，就只能靠租。

租赁我没有深入了解。账号买卖的话，有实力的团队可以做第三方账号交易平台，赚的是服务费，但必须承担账号被找回后的追责兜底。引流方式一般是找游戏主播在直播间挂广告，可以参照“盼之”的做法。

最后做一个收尾推荐。我个人比较看好的几个方向，基本都是门槛低、好上手，而且可持续、可复制、收入天花板也不低：

1. 鉴定估价、教学类主播；
2. 用AI出图做定制画师；
3. 建群做运营。

具体怎么挑，最终还是得看自己的实际情况。每个人的想法、能力、资源都不一样，能玩的花样肯定不止上面这些，以咱们这些搞钱人的脑洞，肯定还能翻出更多新玩法。

但不管选哪条路，放在这个时代，我都会建议你尽量做到全平台分发。不需要多么精心的策划，哪怕是随手录屏、随手截图，简单剪一剪发出去，也可能带来意外的收获。

如果做的方向跟具体玩法深度绑定，那能开播就一定去开播；把直播录像同步发到各处，让人先看到直播间，再从直播间沉淀到个人微信。只要在抖音、B站攒下几千几万粉丝，直播间的热度就不会差，而且这种自带站外流量的主播，很容易拿到官方合作资格。

如果方向和具体玩法关联不大，那就盯住这么几个渠道——游戏里的各类频道、各种群、抖音、B站、小红书——不断把人往自己的池子里导。

偏技术流的PK代练和带队指挥，可以多留意官方比赛；斗鱼、虎牙、抖音也会不定期办赛事，能报名就去报名。实力弱些就当见世面、长本事；实力强的更别犹豫，要是拿个好名次、在大众面前露一把脸，那就真是应了那句老话，“扶摇直上九万里”了。

最后再说一句：以上这些内容，都只是从我个人《天涯明月刀》PC版、《逆水寒》PC版、《天涯明月刀》移动版的经历出发，结合这几年做线上项目攒下的体会，引申出的对《逆水寒》手游商业转化的一些推想，中间也混了不少碎碎念和回忆。

有兴趣的朋友可以多做做功课，提前准备，有想问的也欢迎随时来聊；没兴趣的就当看个热闹好了。
