# 《不懂流量的新手：怎么从零开始到接 3 个小红书商单》

零基础、没流量，普通人如何做到小红书商单3连？这位圈友的故事值得一看

很多人觉得在小红书上接到商单很难，但一位叫九七的圈友，用亲身经历证明：普通新手也可以。

九七的主业是在外企做实体零售，副业刚刚试着做小红书。2022年4月18日，ta加入龙哥盟，到现在快一年了。用ta自己的话说，自己绝对算普通人的代表——参加过三次航海，两负一胜；之前在抖音、视频号上也都没做出成绩，一度“翻车”。直到把精力放到小红书，才终于看到正向反馈：粉丝突破2800，成功接到3个商单。

九七说，这个转变得益于心态的调整。所以ta特别强调：做小红书，正确的心态比方法更关键。

围绕这次经历，九七从四个方面做了复盘：新手如何起号（核心中的核心）、怎样通过数据做复盘、接商单需要走哪些流程、以及如何摆正心态。由于内容比较长，ta把完整版放在飞书文档里了，想要细看的朋友可以戳：https://i.shengcaiyoushu.com/docx/DkhmdTVHzooWfCxMGqEc6gxknOe

有意思的是，九七还把很多“第一次”献给了龙哥盟：第一次当志愿者、第一次做分享嘉宾、第一次发文……用ta的原话说是“从哪里来回哪里去”。这份真诚也让许多圈友点赞。

如果你正在小红书上摸索，不妨从调整心态开始，再一步步踏上正轨。下一个幸运儿，可能就是你。
