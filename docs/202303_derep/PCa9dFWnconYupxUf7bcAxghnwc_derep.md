# 普通人买黄金，最大的坑你可能正在踩

你有没有想过，金店里那些金光闪闪的首饰，真的是在替你存钱吗？还只是让你花钱买了个开心？

买黄金这件事，第一步不是挑款式，也不是比价格，而是先问自己一句：你到底为什么买它？

是想送自己一条漂亮的手链，给伴侣买一枚戒指，纯粹图个喜欢和纪念？还是说你相信黄金还会涨，想把它当成一种理财方式？

这两个目的，可是完全不同的两码事。搞不清楚这一点，后面每一步都可能走偏。

![](img/5b6da9e3677b18953e525df99c37d502.png)

如果你只是去某大福、某大生买了个镯子、戴了条项链，就以为自己是在做黄金投资——那可真是一个误会。首饰就是首饰，跟投资是两回事。当然，你完全可以既买饰品犒劳自己，也拿出一部分钱做黄金投资。毕竟比起许多珠宝，黄金首饰的保值能力确实不赖，而且这几年款式越来越年轻化，谁看了不喜欢呢？

好，先来说说首饰怎么买。

很多人下意识觉得，买黄金首饰就要去大品牌旗舰店才放心。但你有没有发现一个奇怪的现象：同样是某个生肖吊坠，有的店一口价三千，有的店却敢要一万多——到底差在哪？是品质真的有差别，还是一种错觉？

敲黑板：这是不少新手买黄金踩的第一个坑——只看标价，不看克重。

先讲一个可能颠覆你认知的道理：黄金价值跟品牌其实没多大关系。不是什么牌子越大，金子就越值钱。黄金好不好，取决于它的纯度，而不是柜台装修得够不够豪华。

我们国家把黄金成色分成几个等级：AU9999、AU9995、AU999、AU995。AU9999也叫“赤金”或“万足金”，纯度极高，但因为太软，市面上反而少见，不太适合做饰品。而我们最常见的AU999，含金量99.9%，也就是常说的千足金，市面上最流通的就是它。

一般来说，含金量在99.6%以上的黄金，才能称为24K金；低于99%的话，就不算足金级别了。

所以买首饰，第一件事不是问“这件好不好看”，而是看它的钢印标识上写的含金量是多少。正规店铺的黄金饰品上都有标记。看懂这一点，你才能判断自己手里的金子，到底是真值钱，还是只买了个样式。

接着就是价格怎么比了。以最常见的AU999千足金为例，同样一个生肖挂件，一家店卖3000，另一家卖5500——你会觉得贵的那家不划算吧？但如果告诉你，便宜的这件只有5克，贵的那个却有10克呢？这么一看，是不是另一家反而更良心？

所以记住，同一规格下，折算成每克多少钱，才是真正有价值的比较方式。

总结一下，买黄金首饰的核心逻辑很简单：价值看规格、看克重，少看品牌。大品牌不会让黄金本身变得更纯，款式和工艺才是溢价的来源。如果是小克重的饰品，几十块的差价真不用太纠结，挑你喜欢的就好。但如果是买金镯子、金链子这种大件，那就得多跑几家店，每克差个几十块，总价差距就出来了。

说到这，再聊聊普通人怎么投资黄金。

投资黄金，主要分两条路：一种叫实物黄金，一种叫线上黄金，也就是纸黄金。

实物黄金顾名思义，就是看得见摸得着的金条、金豆子。一般四大行或者大金店都有售。买回来你可以放家里，也可以存在银行。要用钱的时候，可以卖掉换现金，也可以自己提走。这种投资方式通常偏“一次性”——很少有人三个月两头就把金条倒来倒去，大多数人是拿个三五年，等金价涨到一定幅度再出手。

实物黄金的好处很直白：比首饰便宜。因为金条的价格更贴近国际金价，不像首饰还叠加了工艺费。而且买完放几年也不用打理，省心。

但缺点也很明显：不灵活。万一你买在了高价区，就只能巴巴等着回本。另外，要是放在银行保管箱，一年还得交个几百块管理费。通常标准大约在300元左右一年。

再来看看纸黄金是什么。

你可以把它理解成“看不见的黄金投资”。以前还得专门跑银行柜台咨询贵金属业务，现在方便多了——手机银行APP上就能操作，或者开个证券账户买黄金衍生品。它不给你实物，但可以让你根据金价涨跌随时买入卖出。手机上全搞定，不用跑来跑去，也没有保管成本。

价格走向上，纸黄金和实物黄金基本同步。但纸黄金的优势在于灵活度高，手续费也低。比如黄金ETF，也就是黄金场内基金，就能作为一种低门槛工具。

看过去这几年的行情就很有趣了。2020年8月那波，黄金ETF开始从高位回落，实物金条也跟着跌，之后一直震荡。到了2021年3月几乎到谷底。再之后从去年年底开始有所回升，而最近这一个月涨势尤其明显，甚至突破了新高。

假设你是在2020年七八月买了实物金条，恰恰买在了山顶上。直到今年二三月份，价格才刚刚涨回当初的本——中间那两年多，你的钱几乎一直在原地踏步。但如果买的是纸黄金呢？跌到低点的时候，你可以做一两次加仓拉低成本；中途涨幅可观的时候，还可以适当减仓锁住利润。就算同样是从最高点开始买，经过低点摊平，整体回报可能就完全不一样了。

再从费用上看，纸黄金没有保管费。如果走证券账户购买，手续费低的渠道可以谈到万分之0.5%，一笔交易最低可能只要一毛钱。

当然，从整体回报率来说，黄金比不上某些股票和基金来得猛。但黄金最大的价值在于它的“避险属性”——对普通人来说，它的波动相对稳健，不至于让人夜里睡不着。另外看长期数据，从2016年到今年2023年，黄金价格差不多翻了将近一倍。这个成绩，对比不少银行理财产品的收益率来说，确实更有吸引力。

彩蛋时间：

最后送你一个额外的判断。前面说了，无论是首饰、金条，还是纸黄金，它们背后的定价逻辑本质上都跟着国际金价走。那现在的黄金处在高位还是低位？适不适合下手？

我个人看法是（此处纯属主观判断，不作任何理财建议）：短期来看，从三个月到一年的维度，金价应该还有一定上探空间，但如果没有特殊外力推动，涨幅未必特别大。不过要是国际上一出点什么动荡，或者美元开始贬值，那黄金价格的想象空间就会一下被打开。

就当前走势而言，上涨的趋势基本已经确认。如果想寻找相对低一点的入局位置，可以留意3月13日到17日这几天的价格情况——参考意义可能比较大。
