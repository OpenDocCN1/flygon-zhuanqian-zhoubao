# 坚持的动力来自对未来的迷茫

### 真正让我一直没放下的，是看不清的明天

如果你以为我挤进这个圈子，是为了搞钱和提升认知——那我也曾这么以为。结果加入“赚钱”九个月，钱包没鼓起来，体重倒是实实在在地涨了。

我是小雨。上一次冒泡是在五月，这一次再出现，我整个人圆了一圈，心态也松了一圈。

前几天，我在一场视频号直播连麦里做了一次主题分享，认认真真准备了三千字的讲稿。今天上午，雪姨在社群转述了涛哥的一句话：人生有轻重缓急，先做写作、表达、逻辑、网感、社会关系、销售，最重要的能力，是写作和表达。

这句话一下子戳中了我。我就是那种满肚子话想说，却很少有机会站到台前的“I 人”，写作和表达，几乎是我为数不多的出口。

翻翻这段时间的社群打卡、👸号更新，还有一篇篇逐字稿，零零碎碎加起来，估计早超过二十几万字了。看完雪姨转述的那段话，我忍不住把之前的讲稿重新改了一遍，带着一点“希望被更多人看见”的小私心，把它分享到这里。

认识我的人总说，我这张嘴不说脱口秀有点可惜。所以，如果你最近压力大，不妨打开看看，说不定还能找到点乐子。
