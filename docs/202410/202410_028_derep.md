# YouTube到底多赚钱？YPP门槛、分成比例、AI批量玩法一次讲透

大家好，我是龙哥，目前运营着一个3.4万粉丝的YouTube频道“AI进化论-花生”。昨天看到龙哥发了一条关于YouTube的风向标，正好我过去一年已经把YouTube当成主要阵地，就来分享一些真实经验和圈友关心的信息。

先说基础门槛：想靠YouTube变现，需要加入其合作伙伴计划（YPP）。条件并不高——频道达到500个订阅，同时满足以下任一条件：过去365天里长视频累计3000小时播放量，或者过去90天内Shorts累计300万次播放。

一旦加入，广告分成相当可观。视频开头以及中途展示的广告，创作者可以拿走广告主支出的55%；即使观众开通了YouTube Premium、看不到广告，你也能从会员费里分到一部分。我自己的一个ChatGPT教程视频就是例子：千次播放收益4.6美元，最终分成1678美元；而同一期内容放在B站，收入还不到500元。差距真的非常大。

除了广告，YouTube的变现方式还有很多。频道可以开通类似“包月会员”的服务，在视频简介和评论区挂广告链接也不会被平台屏蔽。这意味着商单、卖课、推广联盟佣金都能正常做。对我个人而言，广告费反而只是零头，真正赚钱的是通过频道获取AI咨询客户和AI课程订单。原因也很简单：YouTube的用户质量和付费意愿明显高于B站，同样的内容在这里更容易卖出高价值服务。

流量方面，YouTube目前拥有20亿月活，是全球第二大流量网站，而第一名的Google本身就是它的母公司，自然会持续给YouTube导流。更难得的是分发机制很科学，不像B站或被TikTok那样需要赶热点；只要内容做得足够好，系统就会不断推送，形成稳定的长尾流量，甚至时不时给你带来惊喜爆发。

很多人关心AI能不能批量做内容。老实说，我现在这个露脸主账号的制作成本不低，不适合也不建议所有人复制。我继续做它，更多是把它当成一个发声窗口，同时让它持续为我带来咨询和课程用户。但如果目标是批量生产，确实有很多低成本的赛道可以切入，比如白噪音/BGM背景音乐。不少人工作、学习、睡觉时都有听背景音的习惯，这个赛道机会依然很大。就像截图里的“Relax Jazz Cafe”频道，完全是近一年借助AI做起来的，现在月广告收入接近3万美元。制作方法也不复杂：用文生图工具生成画面，再用图生视频或剪辑软件加上动效，音乐用Suno生成，最后混入雨声、雷声、风声等白噪音，四步就能搞定一条视频。

不过这类赛道最大的优势是门槛低，最大的劣势也是门槛低——一旦大量人涌入，竞争就会非常激烈。想突围，要么比大多数人做得早，要么做得比别人更好。我更倾向于后者，目前已经在用Cursor把文字和音频内容生产自动化，视频方向的自动化还在探索中，欢迎感兴趣的朋友一起交流YouTube内容出海。
