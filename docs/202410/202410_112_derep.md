# ('海外游戏买量创意设计工具使用指南', (2, 18))

哈喽，生财的各位朋友，我是千张没有皮，一个从计算机半路转行的海外游戏广告创意人。2019年正式踏入游戏出海买量领域，如今带队做投放，这几年团队经手的广告预算加起来也有好几个“小目标”了。

作为刚加入生财的新成员，看到亦仁大大挂出的龙珠悬赏帖，主题正好是“以研究项目为前提介绍工具和实际应用”，瞬间来了兴致。一直以来，我日常工作的一大重心就是借助各类工具帮团队更快更好地达成目标，提升大家的工作效率。既然圈子里关于游戏方向的专业内容不算多，不如借这个机会，把自己平时的工作流彻底梳理一遍，把各个环节里常用的工具和网站都晒出来，给大家当个参考。

整个梳理会按照“市场调研 → 创意输出 → 需求管理 → 设计制作 → 数据复盘”这条完整链路展开，包含的工具将近100款，还配了大量图表和跳转链接。提醒一句：内容比较多，强烈建议用电脑端打开，阅读体验会舒服很多。

这份指南适合谁看？如果你是谁看？如果你是手游出海的中小团队老板，或者对游戏出海充满好奇的伙伴，再或者做电商/工具出海的朋友，那应该都能从中找到有用的东西。
