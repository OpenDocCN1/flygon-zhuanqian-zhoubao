# 挣钱与个人及组织能力的持续提升
作者：龙哥

你发现没有，很多人一谈“赚钱”，就只盯着银行卡里的数字涨没涨。

但真正拉开差距的，从来不是那个结果，而是结果背后的东西。

钱，说到底只是能力兑现后的一个副产品。如果一定拿它当衡量标准，那它衡量的也是你过去一段时间的成长质量——你解决问题的能力有没有变强，你手里的资源有没有变厚，你所在团队的整体战斗力有没有升级。

我特别认同一个观点：相比“挣到多少钱”，更值得放在心上的，是“挣钱的这个过程中，个人和组织的本事有没有持续变强”。因为结果是一次性的，今天赚到了，明天可能就没了；可能力是复利式的，一旦长在身上，未来还会不断帮你创造新的结果。

所以，别再把目光全部锁在那个最终的数字上。把精力花在提升自己，打造一个更能打的组织，让每一步都有积累，每一次都更专业。当能力真正到位的时候，赚钱其实是一件很自然的事。

过程对了，结果不会差。
