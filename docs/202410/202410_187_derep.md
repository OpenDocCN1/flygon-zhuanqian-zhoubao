# 聪明不是大改，是只改 5%
作者：龙哥

很多人卡在“想变好，却怎么也动不了”的死循环里。根源不是没决心，而是目标定的太满。

一心想要 100% 翻身，才会反复拖延、反复失败。真正能走出来的人，从来不去撬动全部，他们只做一件小事：先完成 5% 的微调。

5% 看起来不起眼，却是撬动惯性的支点。一次微小的行动，会产生微小的正反馈，正反馈会带来下一步的行动。滚雪球就是这样起步的。

聚沙成塔，积水成渊。没有人能一步登天，所有看似巨大的蜕变，都是无数个不起眼的小动作堆起来的。

所以，行动时别盯着终点的大目标去焦虑，要把注意力落在最小可执行的动作上。今天只做一点，明天再做一点点，连续的小步伐会自动把你带向大的改变。

大目标是方向感，5% 的改变才是脚下的路。抓住 5% 的努力，用它去撬动剩下的 95%。

真正聪明的人，从来不求一步到位，他们只求先动起来，然后让正循环自己长出来。
