# 网盘拉新还能这么玩？不写文、不剪视频，手机党也能轻松上手

很多做项目的人都有一个误区，觉得想搞流量就必须拼命做内容。要么码字，要么做图，要么录音频，要么剪视频。可网盘拉新这个赛道，偏偏有一种“反常规”的玩法，以上这些统统可以不用碰，照样能把拉新做起来。

这个方法叫“资源无脑分享”。

说白了，就是不需要你绞尽脑汁写文章，不用费心做图片，也不用碰音频和视频，甚至连对标同行这件事都可以省掉。你只需要一部手机，把资源分享出去，就能参与网盘拉新。不管你是刚入圈的新手，还是已经跑通项目的老手，这套玩法都适用。

那收益从哪来？常见的有三类：第一是拉新收益，分享的资料被新用户注册转存，你就能拿到；第二是转存收益，老用户每天转存你分享的资源，你也有收益，而且这个收益是按天计算的，只要你每天分享、对方每天转存，你就能持续获得；第三是会员分成，如果对方转存时因为空间不够或批量转存受限而开通了会员，你还能拿到分成。不过要注意的是，转存收益有有效条件——对方必须是当天第一个转存你资源的人，这笔收益才算你的。

还有一个关键点，千万别忽略：分享之前一定要先对接网盘拉新渠道，申请到自己的推广码。不然你忙活半天，分享出去也是没有收益的。
