# 新手小白📕从0-1复盘

都说📕是普通人的机会，可真正从0开始走一遭，才发现路上全是坑。今天想把我这几个月的经历完整复盘一遍，给同样懵懵懂懂的新手一点参考。

先说结果：我的第4篇笔记突然火了，5500多个赞，第6篇也有800多赞，还接到了两个商务合作。听着好像挺顺利？其实中间我踩过的坑，一个比一个大。

3月28日那天，我加入了赚钱。整个人像打了鸡血一样，每天刷着帖子，脑海里全是一夜暴富的剧本。实际上呢？手都没伸出去过，只是偶尔看看内容，就觉得自己已经牛得不行了。

七月，航海活动如期而至。因为新手群完成任务可以免保证金，本着“便宜不占白不占”的心态，我挑了价格最高的视频号带货，另外花了199块报了个闲鱼高客单。担心同时做两个项目会顾此失彼，我还专门把闲鱼手册认真啃了一遍。结果你猜怎么着？闲鱼两个号第一天就都出单了，一单9块9，一单900多。视频号我奋战了7天，然后果断放弃。航海期间我反复纠结：闲鱼要当客服，好麻烦；视频号看不懂，但好像来钱快，怎么办？我想用亲身经历告诉你：新手真的别学我，别总怕错过赚大钱的机会。挑一个你能看懂、能上手的项目，直接开干，别让乱七八糟的信息干扰你。

航海结束后，我又把闲鱼给弃了。原因就是之前看过一句话——要做自己喜欢的项目。我就因为这个，完全没想过自己当时最该干的是先赚钱，而不是挑三拣四。

到了八月，我报名了视频号口播。把手册和高手领航翻了一遍，觉得哇塞，这钱也太好赚了吧！结果刚开始就发现规则变严了，按老套路拍特别容易违规。一开始觉得好难，不知道拍什么，就把各种类型都试了一遍，看哪个数据好就定哪个。思维类出单了，但拍起来太费时间；采访类数据不错，剪起来也顺手，我就决定走采访路线。信心满满拍了二十多条，一条都没爆。我又开始怀疑是不是形象不合适，于是我在三个号里挑了一个，换成新形象，拍了一条爱国内容，直接爆了。之后用这个形象继续拍，数据又不行了。那段时间特别焦虑：要不要再换赛道？是不是拍得还不够多？怎么才能快点涨粉、快点赚钱？纠结来纠结去，最后还是换回了思维赛道。不得不承认，我是龙哥，七天里出了两条十万加播放的作品，粉丝也涨了一千多。可高兴没几天，又卡在了带货文案上，完全不知道从哪下手。

十月，新一期的航海又来了。我已经彻底把视频号丢在一边。选项目时又犯了老毛病，当时摆在我面前的有AI写作、AI特效直播、📕虚拟资料和coze工作流，感觉每条路都金光闪闪。到底报什么？哪个来钱快？最后选了coze和📕虚拟资料，可心里还惦记着K12，一个普通人也能月入过万的好项目，红利期呢，但我一点都不懂。结果coze根本没精力看，虚拟资料又觉得好难：要写笔记，笔记咋做？朋友圈怎么经营？还要引流、建资料库、设计话术，一单就赚一点点，真的能赚到钱吗？那阵子我焦虑得要命，既想赚大钱，又什么都不会，还想抓住红利。可你凭什么觉得好事会落在你头上呢？

不出意外，这次航海我没跑通。因为我一直在心里暗示自己：我不喜欢引流，不喜欢盗版笔记，这项目没信念。航海结束，整个人像被掏空了一样，什么都不想干，觉得这辈子完蛋了，钱挣不到，项目学不会。每天晚上熬夜刷帖子，盼着有个赚大钱的项目突然出现来拯救我。当然，没有。

后来无意中翻到往期航海，发现有“早睡”这么个项目。心想不能再这样了，至少早点睡，养养身体吧。我宝宝还那么小，我要是垮了，她多可怜。结果早睡坚持了3天，又不行了。后来想了个办法：每天晚上9点，让老公把我的手机没收走，不然就记他一次，顺便没收他的手机。他这一点倒是做得很好，一次都没让我逮住机会。到今天我已经连续早睡19天，整个人的状态好多了。

转机出现在我刷星球的时候。我看到了梨云老师的精华帖，觉得太有帮助了，刚好有私教课，就毫不犹豫报了名。结果一开课，我的第一反应是：天啊，我要退款！这跟我以为的完全不一样。我以为会是每天解锁一课、布置一个实操任务、有人监督着跑通项目那种。没想到面对的是好多课程视频，我完全懵了：这么多课，怎么学？前三天我硬着头皮看，心里一直纠结要不要跟老师开口退款，但实在没勇气，也觉得钱不能白花。好吧，学！看不懂就去问老师，她让我先看“怎么学习”那一课。我给自己定了个小目标：先把所有课看完，看看老师到底怎么带。三天大脑风暴之后，终于看完了。老师让我选赛道，我根本不知道做什么，她推荐了一个。定了赛道就开始装修账号，不知道怎么弄，就重新回课程里跟着操作，慢慢找到了感觉。接下来是制作第一篇笔记，天啊，这怎么做？反正就是遇到困难就找对应课程，跟着课程一步步来。当时做第一篇内容，我整整磨了六个钟头才发出去，后面就越来越轻松了。

回过头来，我想把这次的经验好好写下来，以后做任何项目都用得上：

一、做项目前，先把手头的课程和资料整体过一遍，心里有个大概框架，知道里面讲了些啥。

二、开始动手做，遇到具体问题，比如不会写标题，就回去把相关课程认真听一遍，记笔记，跟着做。

三、不定期回看课程。我现在每天都会听一节，每次都能有新的收获。

还有一点，我这两天刷星球，发现那些项目跑得不错的小白，也并非一帆风顺。他们也会焦虑，数据也会差，但他们最终都有一个共同点——坚持。

学习其实有三个层面：

第一层，停在信息表面。好比别人告诉你香蕉很甜、很软、是黄色的，你知道并背下来。

第二层，你去把香蕉拿过来，剥开，亲自尝一口，才真正明白那个味道。

第三层，是信念。我就是相信自己这辈子可以通过努力改变人生。而有些人，从心底里就不相信自己能赚到钱。

我前面两次航海能跑通，一方面是因为听话照做，另一方面是心里坚定地认为自己一定能做到。后来没赚到钱，恰恰是因为我压根不相信自己能把这个项目做成，所以早早就放弃了。

这是我第一次发复盘帖，也算是一种进步吧。
