# 从睡广场到月入十几万，我是怎么撞上「AI+做课」这条黄金赛道的
作者：龙哥

嗨，大家好，我是龙哥，一个85后的奶爸。

有人认识我的时候，我还在北京奥运会当志愿者，后来生活被压到谷底，半夜只能躺在广场凑合过夜；也有人是在我月入16.5万的高光时刻认识的我。中间的几年，像坐过山车一样，跌宕、迷茫、反复试错。

现在，我把重心完全押在了「AI+课程制作」这条垂直赛道上，并且和「玩赚新媒」的负责人 @芷蓝 正式搭档，开始对外提供「AI做课卖课」的全程陪跑交付服务。

写这篇复盘并不容易，从列大纲、整理素材到成稿，我花了一个多月。回头再看自己的轨迹，真的像放电影一样：志愿者的理想主义、流浪街头的至暗时刻、第一次实现高收入的狂喜，随后是方向失焦的低谷与尴尬转型，直到AI做课的商业闭环被打通，遇到贵人合作，才真正迎来职业上的第二春。

说到底，这条路不是灵光一现，而是被现实一脚一脚踹出来的选择。
