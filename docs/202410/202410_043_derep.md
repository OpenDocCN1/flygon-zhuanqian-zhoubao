# 牛市下的北交所：广阔天地 大有可为！浅谈长期坚持后到爆发式的过程
作者：龙哥

这段时间北交所的热度居高不下，我想结合自己这些年的真实经历，聊聊长期耕耘与机会爆发之间的关系。

先简单介绍下自己：我叫老吴，既做过金融也搞过互联网。早年在某商业银行当网点行长，对零售业务的门道还算熟悉。虽然顶着“行长”头衔，但收入也就是比普通上班族略强一点。房贷、车贷、装修、养家这些开销压下来，手头真没攒下几个钱，日子过得紧巴巴的，银行的任务指标还像山一样重。2017年起我开始做副业，第一份副业就是股票经纪人，一直做到现在。至于现在的生活状态，这里就不多展开了。

这些年走下来，见过太多形形色色的人和事。有人确实像金子一样，迟早会发光；也有人怎么扶都扶不起来。说实话，金融和互联网这两个行业，并没有外界想象的那种一夜暴富。所有的收益，本质上都是靠时间一点点熬出来的，靠持续不断的积累堆出来的。所以别被那些虚头巴脑的繁荣景象骗了，真正聪明的做法是在自己擅长的领域里沉下心深耕，耐心等着属于你的那个爆发点。

现在网上的赚钱教程一抓一大把，但说穿了，大部分就是借着“赚钱效应”来放大流量。换个角度想，你自己当老板就明白了：生意无非是先做0到1，再把1后面不断添零而已。看似花哨，底层逻辑就是这么简单。

古人讲得好：“自古驱民在信诚，一言为重百金轻。”做生意最忌讳的就是丢了诚信。另外，打铁还需自身硬——技术知识要过硬，人脉圈子要够广，更重要的是学会感恩朋友、感谢自己。正是因为这些年的沉淀，让我们练就了靠谱和真诚的底色，才能够在一次次机会来临时敏锐地发现商机，也才有那个底气去迎接挑战。
