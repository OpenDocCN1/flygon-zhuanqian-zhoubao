# 采访分享，利用身边资源轻创业

毕业两年就创业，靠身边资源轻折腾：这个山西小伙的复盘值得一看

大家好，我是龙哥。上周跑到沧海哥公司坐了一下午，虽说是两个赛道的人，但都是自己出来搞事业的，绕来绕去发现很多共同困惑和收获，互相也交换了点能量。刚好他那边会员有需要，我就答应来做个分享，顺便逼自己复盘一下这段日子，也算治治最近懒得动笔的毛病。

最初是怎么走上这条路的？其实大学时就折腾过创业，现在回头看很幼稚，但就是那会儿，心里那团火被点着了。毕业时有朋友拉我一起干，我掂量了下自己，觉得火候不够，还是先上班沉淀两年吧。那两年进步很快，算是有了一定的底气，就辞职和朋友正式开干。刚开始真没什么方向，碰巧有个跟中小学合作做人工智能示范校的机会，对方给培训费，这业务我熟悉，于是先接了再说。

创业这一年半，苦是真的苦。要死不少脑细胞，很多事只能一个人扛；要低着头去求人，面子和尊严常被按在地上摩擦；要逼着自己不断更新，容不得懒散。更难受的是，这些苦吃完了，结果可能还是空的。可后来我想明白一件事：这就像玩一款无限游戏，升级、打怪、换装备、学新玩法、开新地图、认识新队友。玩着玩着，你会越来越清楚自己擅长什么、适合什么。创业后我的视角也被撑大了，看商业、看人性、看社会运行，连对自己的认知都清晰了不少。

有人问我方向怎么找。我的答案很朴素：方向是做出来的，不是想出来的。毕业那阵，我听说抖音能赚钱，就去拍 vlog，五个多月只攒了80来个粉，赚了不到20块；后来又试视频号书单号，这次算开了点窍，十小时出单，每个月能稳定赚几千块；再做📕个人IP，写自媒体和面试技巧，因为不专业加上体量太小，只赚了几百块。2023年初 ChatGPT 火起来，我跟着一路分享工具和玩法，靠卖账号和课程分销，很快过了万。再后来开过实体水果捞店，然后才真正迈入创业。选科技教育，是因为对这个领域门儿清，创业初期各方面资源都紧，当然选最有把握的。每一段经历，不管成不成，都会留下点能带走的东西。小成功特别养人，攒多了，勇气和判断力都会上一个台阶。

我也被问过：性格内向是不是不适合创业？我现在做的是线下生意，几乎天天要见人谈合作，还有不少政府体系内的领导。去年为了跑项目，一个月跑遍浙江各地级市和部分区县的教育局，30天喝了20回酒。我本来酒精过敏，但那种场合不喝真不行，喝完还得硬撑。酒桌文化好像是绕不开的坎，年轻小伙愿意喝，才会被看作有冲劲、有拼劲，前辈也愿意带一带。不过这一年多见了形形色色的老板，我越来越坚信，创业跟内向外向没有本质关系。能不能踏实把事做成，能不能把话说明白，能不能尊重别人的利益和人性，这些才更重要。

说到合伙人，我的搭子其实就是大学一起折腾的那位。我俩从学生时代就攒下了信任，这比什么都值钱。平时也会吵，会意见不合，但目标一致，都是为了业务更好、个人更强。我们俩一个偏“攻”，他气场足，专门去啃硬骨头、打通关系；我偏“守”，更在意业务跟团队匹不匹配，复盘和协同抓得比较多。找合伙人说白了就是互补，两个人一起往前冲，成事的概率总要大一些。

后来为什么从少儿编程切到研学？核心还是算账。中小学合作里，全职教师成本太高，课排不满就亏；兼职老师又不稳定，想再往上做教研，得砸不少钱，加上教育行业监管越来越严，这条路越来越难走。研学我们其实早就试过水，高校研学有现成的对标案例，还有校友资源能争取到学校支持，而且收钱就干活，现金流非常舒服。算完这笔账，就果断重仓投入。说到底，两个项目都在教育大范围里，只是更偏向素质教育了。我自己从县城考到杭师大，才第一次体会到教育资源差多远，所以现在做内容，也特别看重孩子的综合能力。

说到轻创业，我想说一点：资源真不必往外找，先从身边挖。我作为一个外地毕业的大学生，刚起步能靠的就是同学、学弟学妹、老师和母校。大学时我跟学院老师处得不错，毕业后也还在走动。创业初期，办公室房租打了对折，还申请到了市里的补贴；又通过跟学院谈合作、答辩，拿到了校内的办公场地。需要找老师来上课时，学弟学妹特别相信我，主动帮忙张罗。千万别小看他们，论干活技能，很多同龄人一点不差。后来重心切到研学，之前合作过的学校因为校长熟，合作基本无缝衔接；那些区县教育局和教培机构，也都是以前跑出来的关系。再因为是师范院校，学长学姐和老师经常帮我们搭桥，学院对接的很多是企业老板和校长，这事聊起来就容易多了。到现在我愈发相信，你做过的事不会白做，没有人脉就从身边攒。我做事的出发点从来不是榨取谁，而是学校、学生和我们自己三方都得到好处。一所大学背后能撬动的资源，超乎想象。轻创业就是要反复琢磨：哪些现成资源能借力？哪些投入可以省掉？

说到成就，说实话我现在还没有资格谈成就感，接触得越多越觉得自己还差得远，公司能活着就知足了。倒是踩过两个大坑，值得拿出来说。第一个坑是自嗨。小团队创业，没有利润一切免谈，流量一定先于产品。我曾在研学项目上花大价钱打磨产品体系，课程设计得很专业，结果市场根本不认。后来学乖了，丢掉完美主义，边做边改，先把流量盘活，手里有了现金流再慢慢优化。第二个坑是轻信别人。跟人合作，不能光听他嘴上的承诺，要用眼睛盯着他做的事。去年暑假和一个渠道签了五千人的招生协议，落地和管理都是我们，结果对方压根没招来人，团队白白空转，经济上也亏了一笔，跟学校部门的信任还受了伤。所以别把宝押在别人身上，关键时刻自己得有充足的能量和预案。

贵人这个话题，我也想多说两句。我现在的投资人，是大学时就认识的一位老大哥。最早因为少儿编程，我去他公司做兼职老师，后来才有了更多合作。毕业时他建议我去他公司上班，或者给我安排去处，但我还是想去互联网行业试试水。他当时撂下一句话：你得让自己更值钱。我记住了。后来我在外面扎实干了两年，确实变值钱了，回来跟他以合作的形式创业，他投入资金和资源。说白了，没人无缘无故帮你，先让自己值得被帮。另一个贵人是上一家公司的老板条形马老师。我的岗位是用户运营，但机会比较全栈，直播运营、人事行政、甚至公司盈利数据分析我都碰过，这让我对整个盘子的运转特别敏感。平时贴身观察他的做事方法，比如苦练基本功、敬畏文字、保持迭代，至今都是我手里最好用的工具。创业后遇到麻烦，我常常会想：如果是马老师，他会怎么处理？以前有些决定我理解不了，后来才明白，是自己段位不够。

心力这件事，我也算有发言权。业务推不下去、队伍不知道怎么带、工资眼看发不出来的时候，一个人坐在办公室发呆，那种心累没法形容。后来我才弄懂，心力就是内心的承受力，它不是天生的，是不断被捶打、不断恢复后练出来的。心力憔悴其实是个信号，说明你要长出新的东西了。疼是因为要蜕皮，蜕完皮就是新的自己。所以我也渐渐学会不硬扛，累了就看书、运动；如果连动都不想动，那就干脆打打游戏、出去走一圈，哄自己回血。只要目标明确是调整状态，什么方法都可以试。

最后，对想轻创业的朋友，我想说：我不劝所有人都去搞副业或创业，但希望你能拥有不依赖公司、独立从市场换钱的本事。低成本试错很划算，输了不心疼，错过才真可惜。把它当成游戏，结果可控就大胆上，大不了再开一局。别总盯着最终结果，去拿一个个小阶段的成果喂自己。真正拉开差距的是思路：高手会去拆解因果，普通人急着追问结果，庸人只会在嘴边反复念叨“如果”。真正做事的人，都是先下场、再调整、把预期放低，这样反而容易遇见惊喜。

谢谢你看到这里，如果觉得有收获，就点个赞吧。
