# 别轻易踏进股市，这几个原因我劝你听进去
作者：龙哥

原文链接：[`www.yuque.com/for_lazy/zhoubao/shmmxu7i4lfwv061`](https://www.yuque.com/for_lazy/zhoubao/shmmxu7i4lfwv061)

每次市场热闹到让人心痒的时候，我总会出来说两句劝退的话。今天市场又沸腾了，我把自己的体验证明总结一下，信不信随你。

1、我 1995 年就开始炒股，一直到 2009 年中间还专门有一段时间在家全职研究。听起来像是老股民，实则账面上赚过的，最后算总账还是亏。2010 年我彻底把炒股戒掉了。

2、想明白的很简单：我智商平平，投机都是业余的，没有系统训练，没有时间去深挖行业和公司，信息渠道也有限，更别提资金体量跟机构和大户比起来根本不在一个量级。各方面都被碾压，还凭什么觉得自己能赢？想清这点后，我就不再浪费精力了。

3、这并不代表现在开户就一定亏，甚至你现在冲进去，很可能短期内闭眼都能赚，账面数字看着很漂亮。但问题是，钱一旦进场，你的心态就变了。赚了想赚更多，亏了想扳回来，这种心魔，十个人里有九个半管不住，最后赚的钱基本都会吐回去。

而且你只会看到别人晒盈利，很少有人出来讲亏损。赢了到处说，输了闭口不谈，这是人性。

4、有人会说，我模拟盘赚得挺好的。模拟盘和真金白银完全是两码事。模拟盘里你割肉、反手、加仓都可以刀枪不入，一旦是自己的钱，情绪立刻就炸了。模拟盘的果断，真盘里根本复制不了。

5、2005 年那轮大牛市，我也实打实赚过一笔。当时我真的觉得自己有点东西，后来回头看，那不过是行情送的，不是能力。

6、学了几个 K 线、波浪、缠论、价值投资、高频交易的名词就觉得自己入门了，太天真了。你只是认识了几个词，并不代表你懂市场逻辑。

7、我认识一个投资赚到九位数的朋友，他主张年轻人拿一笔可以承受损失的钱去股市练手，说「反正赔了也能长教训」。我的看法相反，大多数人即便亏了大钱也不会真正反省。赚了就觉得自己天赋异禀，亏了就归咎于运气，从不认错。

8、现实是反差的。普通人上班一个月挣三五千要计较半天，可在股市里赔掉三五万却跟丢几张纸一样轻松。很多人生活里抠门到不行，一进股市就疯狂。有钱人也一样，钱花不完，亏掉的往往都在投资上。钱消失的速度，远超你的想象。

9、玩上股票后，赚了会觉得工作太累太苦，赔了又提不起精神工作。久而久之，连安稳吃饭的能力都可能丢掉。

10、更致命的是时间成本。一旦持仓，你会控制不住地反复刷新行情，时间就这样被一点点吞掉。

11、这里我得说清楚，我说的戒掉是戒掉「炒」股。我手上仍留着少量仓位。这些标的我买来不是为了博涨，而是拿来收分红，按买入价算每年 5-10% 的现金回报。我把它当作分红权，而不是股票。这部分资产在我全部身家里的占比不到一成，就算归零也无所谓。我可以一个月不看一次涨跌。至于买了什么，不方便透露，而且现在买也复制不了当时的回报。

12、股市确实有人赚钱，但极少数。最可怕的是，每个人都坚信自己会是那个少数幸运儿。

13、劝年轻人时，得到的回应总是像复制粘贴：第一，这次不一样；第二，我不一样。

14、最近几天的市场确实创造了新景象，但请别忘了，过去几年股市同样上演过历史级行情。

15、以上纯属个人经历分享，不算投资建议。因为看着别人赚钱，自己不参与，真的难受。买了就认，输了就认。

半年前我和一位做投资的朋友聊过股市，那时A股还是一片哀鸿，大家感兴趣可以去听那期播客。
