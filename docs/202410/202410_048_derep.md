# 创业早期或创业新手不要找合伙人
作者：龙哥

创业刚起步，尤其是第一次创业的人，先别急着把“合伙人”三个字挂在嘴边。很多项目死掉，不是因为没人帮忙，而是因为错把“培养”当成了“筛选”。

早期团队要的不是为明天储备的人才，而是今天就能扛事的人。当然，也不是完全不看未来潜力，但前提是这个人本身就有成长的底子。选人这件事，永远比育人重要。

一个人适不适合做合伙人，从一开始就决定了，不是靠后续花时间打磨出来的。不合适的人，你再费劲带他、教他，进步也极其有限，反而让大家身心俱疲。

所以，别用几个月的辛苦去赌一个有潜力的“未来合伙人”，不如在选人时下足功夫。找到与当下阶段匹配的人，同时确认他有成长思维，这对创业公司来说，才是最省力也最正确的路。
