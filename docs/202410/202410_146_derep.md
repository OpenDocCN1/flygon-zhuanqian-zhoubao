# 如何透过几个标准、筛选出合适的合伙人
作者：龙哥

身边真正厉害的人，到底是靠后天的刻意培养，还是本身就自带光芒？关于这个问题，我最近在根源老师的分享里看到了一个很犀利的答案。

根源老师深耕知识付费和私域运营已有两年半，但他坦言，十年前他还不是这么想的。那时候他和老师争论，说只要肯教，人人都能成长。结果老师点醒他：人才从来不是训练出来的，而是选出来的。他们原本就是人才，只不过刚好被你发现而已。

所以，挑选合伙人也好，搭建团队也罢，关键往往不在“带人”的手段，而在“选人”的眼光。与其花费大量心力去改变一个人，不如用一套清晰的标准，一开始就把对的人挑出来。
