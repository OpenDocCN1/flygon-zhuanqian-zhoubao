# 让一周任务清晰可见，效率翻番的周计划法（附规划表）
作者：龙哥

大家好，我是龙哥。

经常收到小伙伴的私信问：一周的事情好多，怎么安排才能不凌乱？效率到底要怎样提升？之前答应过大家要认真整理一篇干货，今天终于把它写出来了，当作一次统一回复。

先简单介绍一下自己：我是01年中文系在读硕士，当年以总成绩第一名的排名顺利上岸，同时也是【婷久她】姐妹花成员。目前全网积累了12万粉丝，服务过1000+付费用户，持续在📕、B站、👸号这些平台上做内容创作和引流，比较擅长的方向是把公域的流量导到私域，再完成转化。

关于“提升效率”，我最想分享的一个思路是：与其靠意志力硬撑，不如靠“看见”来推动。试着把一周的任务可视化，让接下来7天要做的事情都清清楚楚地摆在眼前，优先级、时间节点、推进状态一眼就能扫到，不用再反复回忆自己还有什么没做完。

这种“看得见”带来的掌控感，会大大减少纠结和拖延，也是让效率翻番的起点。我自己常用的是配合周计划表来操作，表里已经留好了填写规划的空间，也把使用思路整理好了。
