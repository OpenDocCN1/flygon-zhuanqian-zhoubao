# 股市情绪分析与投资参考：从上海证券交易所年鉴数据看市场参与者盈亏情况
作者：龙哥

我是龙哥，今天想分享一个让我眼前一亮的视频。

前阵子市场热得发烫，这两天虽然冷静了些，但身边盲目乐观的人还是不少。正好看到一个博主把上海证券交易所二十多年的年鉴数据翻了个底朝天，从中梳理出相当有价值的判断。他重点分析了企业、投资机构、大散户和中小散户这几类参与者的真实盈亏情况——谁在赚钱，谁在亏钱，数据说得很清楚。这些结论放在当下的行情里，特别值得大家冷静思考：如果你现在入场，是站在哪一边？
