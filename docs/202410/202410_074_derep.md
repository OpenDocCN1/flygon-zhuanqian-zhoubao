# ('AI 自媒体赛道，153 个头部公众号文章采集与分析', (2, 28))

前几天看到亦仁那篇“超级标的”内容，他给AI赛道指了个新方向：专攻垂直领域的AI资讯或工具类账号，后期靠接商单或别的方式变现。这个思路让我挺受触动，于是琢磨着，能不能先做一轮摸底，看看现在那些做得不错的AI KOL到底是怎么跑的，或许能帮自己更好抓住这波机会。

我一直想干一件事：把全网和AI相关的第一手消息、工具测评，以及头部AI博主发过的所有内容都收集起来，做个系统性梳理，摸清这个领域的真实状态。于是先从公众号下手，目前已搞定的工作有这么几块：

第一，抓取了153个在AI垂类排行榜上靠前公众号的全部历史文章。数据总量早过了7万条，里面包括原文链接、阅读数、点赞数、发布时间这些关键信息。

第二，用AI跑了一遍文章摘要归纳，顺带做了软文识别。

第三，针对每个公众号单独做趋势拆解，看它是从哪个时间点开始爆发的，阅读量曲线如何起伏。另外还用Claude生成了可视化图表，每个号的阅读量走向、爆款文章都一目了然，并整理成了独立的账号分析报告。

整个操作链路和细节，我放在飞书文档里了，想看的可以直接点进去。

说真的，这活儿干下来，最大的感受是：AI自媒体这行比想象中更有章法，头部玩家们的路径是有迹可循的。希望这份调研能给同样在看这个赛道的朋友一点参考。

评论区也是热闹，有说“膝盖收下”的，也有问最后的PDF用什么工具生成的，还有位朋友问“截图里怎么没我的号”，作者马上回复贴了截图，大家一乐。总之，这份来自一线数据的分析，确实值得花点时间读一读。
