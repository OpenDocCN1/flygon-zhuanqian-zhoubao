# 春秋战国时期家族战略的传承与实现
作者：龙哥

最近在高铁上重温《资治通鉴》的解读，看到一段关于韩国崛起的故事，很有感触。很多宏大的目标，往往不是一代人能够完成的，它可能需要一个家族、一家企业，甚至几代人共同接力。

这个案例发生在春秋战国时期。那时的韩国，起初只是晋国的一个家族，直到“三家分晋”之后，才正式成为诸侯国。而促成这个身份跃迁的，是一套跨越六代人的长期战略。

一切要从韩康子说起。他拿下成皋之后，心里便埋下了吞并郑国的宏图。但他没有仓促动兵，而是先埋下伏笔。韩康子时代，国都定在平阳（今山西临汾一带）；他的儿子韩武子继位后，才把王城迁至宜阳（今河南洛阳宜阳县一带），一点点缩短与郑国的距离。到了韩景侯手里，他获得周威烈王册封，身份从“子”升为“侯”，实现了从家族到国家的转换，随后又将首都由宜阳移到阳翟（今河南禹县附近）。再往后，韩烈侯、韩文侯两代继续守成经营，直到韩哀侯登位，趁郑国的保护国魏国正与楚国交战，才终于出兵收拾了郑国。

六代人，一个方向，这大概就是“战略传承”的原始版本。放到企业经营上，道理也一样：你可以定下百亿的愿景，但不一定能在自己的任期看到结果。只要后来者沿着战略方向走，不冒进、不折腾，一天进步一点点，同时持续积攒实力、垒筑壁垒，实现目标的可能性，远比古人高得多。

有人可能会问：难道灭郑必须迁都吗？秦始皇横扫六国，也没见他把首都一路搬到前线去。我的理解是，韩国当时的财政和军事底子不厚，最怕的就是漫长的补给线。古代运粮效率低得惊人，据说从后方送二十车粮食到前线，最终能剩下一车就十分不错。运粮的民夫、护送的士兵，一路都要吃喝，耗损极大。所以聪明的打法就是“因粮于敌”，直接从敌人手里抢粮。抢下敌方一车，相当于后方送来二十车。迁都到离郑国更近的地方，等于提前为战争压缩了补给的距离。

与其说这是一个家族的谋略，不如说是一种跨越世代的长期主义。起点低一点没关系，只要方向明确，每一代人都不停步，时间终会把目标带到眼前。
