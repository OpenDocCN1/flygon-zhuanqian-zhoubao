# 亲子研学旅游怎么搞高客单？一个暑假80万GMV打法拆解
作者：龙哥

最近，一位圈友分享了自己跑通亲子研学赛道的经历，很有借鉴意义。这位朋友的本职是广告公司的客户数字总监，平时也在探索平台流量玩法。今年暑假，他重点发力亲子研学方向，结果短短一个半月就拿下了80多万的GMV（按另一说法是变现84W）。不少人在评论区追问利润空间，他也大方做了回复：佣金比例15个点，扣掉2.5万的投放费用和1200元的认证费，到手利润差不多9.4万元。成本结构相当清晰，主要就是投放支出和企业蓝V认证，前期的内容选题都是自己包办，后期才增加了一名实习生，每个月运营成本只多了3000多元。

这个案例之所以值得关注，在于它走的是“高客单”路线：亲子研学本身单价高，结合流量运营，小团队也能撬动相当可观的回报。作者把整套流程整理成了飞书文档，想深入研究的朋友可以直接查看：[链接]。

评论区还有不少互动，有人直接问“GMV80万，成本结构和利润是多少？”，作者也都逐一解答，信息量很足。整体来看，方向选对了，哪怕是个小项目，也能做出让人羡慕的成绩。
