# 李想两万字回应一切：我们如何造车？

最近，李想的一篇两万字长谈，在不少人的朋友圈里刷了屏。

整场对话听起来是在讲“我们如何造车”，但真正的落点，更像是在说一家企业从成立到变大，所遵循的那套信任逻辑。

他把这层逻辑讲得很直白：公司刚起步的时候，目标范围不必铺得太大。团队内部的人真心认可方向，早期消费者中有一部分愿意用实际行动来支持，这就足够支撑企业走完最关键的第一步。

但要成为一家更大规模的公司，情况就完全不同了。企业必须走出原来的小圈子，面向整个社会去争取理解。大众未必都要成为你的用户，但他们需要知道你是谁、在做什么、为什么要这么做。来自社会层面的理解，是一家企业做大的先决条件。

读完最大的感受是：李想回应了很多，最后的结论却很聚焦——先让内部的人和一部分用户相信你，再让更大的社会读懂你。造车如此，企业成长的许多关卡，大概也是同一个道理。
