# 零成本闲鱼月入2w+，这个女生的副业经验真的适合小白

在生财有术的圈子里，有位叫周玉英的成员，加入已经三年。过去两年，她一直以志愿者身份参与社群工作，没想到这个角色竟然帮她找到了副业方向——不花一分钱做闲鱼，今年8月收益超过两万。

她说，如果把这段经历拆开来看，大概有四个关键部分：

**第一，先想清楚自己适合什么，再去挑项目。** 很多人做副业没结果，不是不够拼，而是定位出了问题。

**第二，她曾试水小红书电商，但经过一段时间的实践和慎重思考，最终决定退出。** 不适合自己的赛道，及时止损也许是更好的选择。

**第三，接触闲鱼后，她发现这几乎是零门槛、零成本的机会，于是果断把它当作新方向。**

**第四，为什么闲鱼能做出成绩？她总结了三个要点：**
- 原本只是21天的志愿者任务，她坚持做了两年；
- 保持“听话照做”的踏实心态；
- 始终牢记教练强调的三个基本点。
