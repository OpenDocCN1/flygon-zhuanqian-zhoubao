# 航海项目执行路径的100条提效指南1.0

最近龙哥在社区里聊到“工具使用指南”，我立刻想到自己囤的那些“电子粮食”——书签攒了5000多条，网盘塞了几个T，再不拿出来晒晒就发霉了。大家好，我是木木（张子安）。自2021年参加了龙哥盟的航海项目后，我渐渐发现，很多圈友的瓶颈不在认知，而是一些特别具体的小工具、小操作。所以，我按照“项目调研→项目0-1→项目1-10”这条执行路径，把压箱底的提效方法整理成了《航海项目执行路径的100条提效指南》1.0。

这份内容适合以下三类朋友：第一次参加航海的新手；短视频或图文赛道的内容创作者；以及对“如何高效搜资源”有执念的人。如果觉得有用，建议先收藏，再慢慢对照着操作。

一、项目调研：用数据看清方向

做项目之前，数据摸底很关键。宏观数据可以看国家统计局官网（即中国统计信息网）、中国产业信息网、前瞻数据库；要找行业报告，阿里天池、199IT、艾瑞咨询、QuestMobile、Mob研究院、豆丁报告网、CBNData都是不错的选择。如果你想溯源上市公司财报，年报问答平台也很好用。英文够好的话，还能直接访问美国政府公开数据网，不🪜也能打开，里面的数据集相当全。

拿到数据后，还要会分析。综合类平台推荐飞瓜、蝉妈妈、5118、极客增长、新榜、微信指数。分平台看：抖音用巨量百应、抖查查、考古加、巨量算数等；视频号用友望、新视；📕用蝉小红、灰豚数据、千瓜、新红。至于数据采集部分，原文档是用截图展示的，就不在这里复述了。

二、0-1阶段：从0到1，先解决“找”和“做”

先说资源搜索。我最想推荐的是飞书飞行社，里面沉淀了大量知识库，覆盖AI、行业报告、出海、运营、项目管理等主题，一网打尽![](img/5c8568796f4f5e56dda6dfd4782a5608.png)![](img/e24bf78341115e1cd945da3aba1c5975.png)。此外，AI知识库导航可以帮你找到各种教程；需要透明背景图的话，也可以去免抠图片网。图库方面，Pixabay、Pexels、Hippopx、Stocksnap、菜鸟图库、Piqsels、Burst都能用；视频素材可以看Videezy、Mazwai、Mixkit、OpenFootage、Coverr、freepik。

资源下载部分同样是图片教程，需要的话去原文档查看。

接下来是内容处理环节，这里有不少实用小工具。图片无损放大用bigjpg、MagicStudio或PhotoZoom；抠图用remove.bg、美图抠图、稿定设计、photokit等；压缩图片可以试试压缩啦和Recompressor；网页长截图用Fullpage blitz插件，几乎一秒截完，还支持复制下载；把图片按行列分割可以用在线分割器![](img/efb82c5b2bb05fa3aa60c54fb7c52b26.png)![](img/9163391525dd7b35855e34925b28e7ff.png)；做金句卡片用Retro Card![](img/71323563afc8f6c12c43755c4edf1215.png)![](img/5e505f056c7393d6bfbbafed3a9a4e5f.png)；生成大字卡片用Slogan Word![](img/fd228cb4f7c8b1f56bbe3a177123773c.png)；还有disksing的字幕截图生成器，能做出电影字幕质感，非常适合做鸡汤笔记![](img/7799fcac7630a6c635b2a1eaf47f57e5.png)![](img/d564f45f495e6942161f5325177beea0.png)。

三、1-10阶段：个人提效与团队矩阵

到了放大阶段，个人和团队的需求就不一样了。个人提效方面，可画（Canva）很适合做同类型卡片套版，还能批量出图![](img/bd6c96e9fb8c126ca1313fc093cb9a06.png)；流光卡片插件则更轻便，在推特、即刻、🧣网页版选中文字后，右键就能生成卡片，还能二次编辑![](img/71c17b57410512e23cfdbb3e64f8ec2a.png)![](img/9caae673102e5497f3685bc72d6d99f0.png)；快手可灵AI新增的“对口型”功能，我强烈建议口播作者试试，上传音频就能让画面和声音完美同步![](img/eb0fe210b0f7a2dccbfdd45f68550125.png)；PodLM可以把URL、文本、文档一键转成专业级播客，支持多个大模型，还能设置多说话人模式![](img/af130a624f4e5467730fb6f0f7aaf207.png)![](img/7467cf55f0e635c3357b2f4e6d65fa5f.png)；另外，一位即刻开发者用cursor一小时做了一款AI播客生成器，堪称NotebookLM平替![](img/bf1dd6fab8c2bb30a85e13486de2d801.png)![](img/0b588a498c0c66bfbbdfa1d1f834501f.png)。

团队矩阵方面，小绿书可以通过COZE工作流+RPA实现图文自动生成和多👸号发布，新手也能做到矩阵化运营；📕的矩阵技术SOP、批量注册蓝V号、找货源和混剪技巧都有专门帖子可以参考；推特矩阵则可以用指纹浏览器+Playwright+AI搭一个自动养号、互动、定时发推的机器人。

四、日常办公：那些不起眼但超好用的效率工具

Windows本地搜索用Everything，速度快到秒出结果；在线批量重命名用webrename，免安装，支持大文件；Umi-OCR是很能打的离线OCR工具，免费开源，支持批量识别![](img/895d22528711cc03904cd1c57c78698e.png)；录屏推荐Screenity，免费且功能丰富；PDF去水印的话，图文教程、在线工具和视频教程都很齐全，搜索关键词就有。

五、如何快速找到适合自己的工具

授人以鱼不如授人以渔，下面这招真的值一个赞。

搜索框大法：在赚钱、微信、即刻、推特、抖音、📕等平台直接搜你的需求，大概率能找到现成答案。以即刻为例，搜“AI探索站”“Chrome插件分享站”“JitHub程序员”这些圈子，里面就是垂直的工具池![](img/296a2e67ef21856fb764bd3ba7c870c0.png)。微信搜索也别忽略，先翻聊天记录，你会发现航海群的老前辈早就解答过很多次了；如果没找到，再用“搜一搜”功能，可选视频号、朋友圈、👸号等内容源![](img/47d6ae682ae89df039ec3d19d8ac7925.png)![](img/bad4cdb08f0e775b8cec68632efcf4d2.png)![](img/c94dc8a3f68424d3c52341b3e5dca61f.png)。AI工具搜索优先ChatGPT，也可以用豆包、Kimi（复杂需求用探索版）、智谱清言、腾讯元宝。浏览器就用百度、谷歌、必应、搜狗、搜狐等。

无限流论坛：如果你想要更精准的资源，可以逛这几个论坛：GitHub（全球最大代码托管平台）、吾爱破解（国内软件破解和逆向工程首选）、CSDN（中文开发者社区）、NGA玩家社区（别被名字骗了，里面从职场到厨艺什么都有）、值得一读技术博客、V2EX。

工具不在多，顺手就好。希望这份指南能帮你把航海路上的每个小波折都变成顺风局。你还有什么压箱底的神器？欢迎在评论区分享。

你有没有过这样的体验：逛一个技术论坛，就像掉进了一个没有尽头的兔子洞。页脚总藏着“友情链接”，点进去又是一个新论坛，再点，又是下一个……就这样一层套一层，仿佛互联网版的套娃。我管这种神奇的生态叫“无限流论坛”。逛一圈下来，你收获的远不是几个帖子，而是一整座取之不尽的工具宝库。

实际上，这些还只是我“互联网收藏夹”里露出的冰山一角。

老话说“工欲善其事，必先利其器”，这话不假。但我也想提醒一句：别让自己被工具绑架。很多时候，我们沉迷于收集各种神器、追求极致效率，结果反而被这些折腾得精疲力尽，本末倒置。

我自己搜集工具的固定套路大概是：先在各个平台逛一圈找线索——筛掉不合需求的选项——把看着顺眼的拉出来跑一遍测试——最后才把真正好用的留下来。这一套流程走下来，时间成本其实不低。而且对不少任务来说，压根不需要什么花哨工具，老老实实用笨办法反而更快更稳。

还有个挺扎心的发现：随着库存工具越来越多，里面不少“宝贝”其实一直躺在角落吃灰，根本不会被打开第二次。所以趁着这次机会，我把这些年攒下的“干粮”拿出来晒晒，同时也期待大家能加入分享的行列。越分享，越幸运；一起共建，别当那个只知道囤货却从不消化的“电子仓鼠”。
