# 零代码玩转小红书热门内容挖掘：Cursor实操笔记

做账号的朋友都有一个共同点：天天盯着热点。常见的做法是把小红书里几篇高分帖子缝合一下，或者把抖音高赞视频的文案扒下来重拍，再就是把公众号爆文改写一遍。但人的精力实在有限，光靠手动翻找效率太低。技术大牛会自己写爬虫，而编程小白往往只能羡慕。现在有了Cursor这种AI编程工具，哪怕没有技术底子，也能生成一套能跑通的采集程序。本文就以小红书K12教育板块为例，演示如何借助Cursor收集6小时、12小时、24小时、近3天及一周内的高人气内容，再从中提炼规律，反哺选题。

这套方案同样适用于美妆、穿搭、美食、家居、宠物、母婴、科技、汽车、健身、减脂、旅行、职场等各类目。

Cursor官网：https://www.cursor.com/，打开首页就能直接下载。官方标语是“The AI Code Editor”，核心价值就是让AI帮你写得飞快。虽然采集脚本一般用Python来写，但Cursor支持各种编程语言，这里我们统一用Python做演示。

## 一、流程拆解

宏观上看就四步：先获得平台原始信息、把清单导出、让脚本去页面里抓详情、再针对不同场景做进一步分析。脚本这部分，你可以手写，也可以全权交给Cursor，新手走后者最省心。

## 三、实操全记录

### 3.1 先下载一份榜单

我选择灰豚上的小红书热门内容库，筛选K12细分方向，把最近7天的帖子榜单导出为CSV，作为分析的起点。

![](img/e3a95ee2e3142175da6c876c5c30f36c.png)

![](img/6595f93dba8ac526115872b61d00adc2.png)

### 3.2 把多张表合并成一张

如果你下了好几份榜单，那么需要先合成一个大表；只有一份的话可跳过。合并工作交给Cursor：按Ctrl+K（Windows）或Cmd+K（Mac），在弹窗里用大白话描述需求。例如：“本地某目录下有若干CSV文件，表头完全一样，列分别为链接、标题、标签、点赞量、收藏量、评论量、分享量、发布时间、内容形式、博主昵称、关注量、博主主页。请用Python写一段合并程序，把全部文件合并，按点赞量倒序排列，并以链接列去重，最后保存前5000行。”

![](img/d5a4866c77da6959de3d88e00248f321.png)

生成代码后点Accept，再把路径改成自己的实际目录，执行。多个榜单就被整合成一份完整列表。

不过，此时的表里还看不到正文和标签。虽然可以复制链接到浏览器里慢慢看，但灰豚免费版一天只给10次查看配额，而我们的清单可能有几千行，显然看不过来。最稳妥的办法，依然是让脚本去批量获取每篇帖子的正文和标签。

![](img/15a949d6f727845ad05b51f70c423e05.png)

### 3.3 抓取正文与标签

压轴步骤来了。哪怕你从来没写过代码，也可以完全依赖Cursor。即使运行时报错，也可以把问题直接抛回给它，直到程序跑通。

在开始之前，要认识两个固定的HTML标记：小红书站内帖子页里，id="detail-desc"对应正文，id="hash-tag"对应话题标签。记住这两个键就够。

随后继续用大白话向Cursor提要求：“读取指定路径的CSV文件，第一列是小红书帖子链接。循环打开每个链接，提取网页中id为detail-desc和id为hash-tag的内容，把它们追加为新的两列。注意hash-tag可能有多个，要全取；detail-desc和hash-tag都可能是空的，为空则写空值。最后保存为新文件。”

![](img/23c922cb417fe3a7578d72808839e5e9.png)

如果中途出错，可以在代码区域选中相关片段，让Cursor立刻修正。我第一次执行时就是因为请求没带Cookie而失败。于是选中发起请求的那段代码，让Cursor重写，绿色高亮处就是修复后的内容，点Accept就完成了替换。

![](img/c7c9fa3c2c3921abbb9cb2dee82bb481.png)

![](img/07e1ae9e950e66492df20dfa5b30a323.png)

如果遇到完全看不懂的报错，或者代码之外的问题，也可以按Ctrl+L呼出对话窗口，把报错信息黏贴进去。比如我当时不知道Cookie去哪找，AI直接告诉我：从浏览器里复制，再填到代码里的指定位置。

![](img/ed6fd8fc8f2fa4c544d6d9c8fdeee5f8.png)

如此循环：报错、让AI修、再执行。直到控制台开始打印日志，就可以安心等它跑完，顺便泡杯咖啡。

![](img/df8ef585969e944f299a2fddbfbf6052.png)

程序收工后，新文件里已经多出了正文和标签两列。

![](img/099bc42a87004fb250b70f39b7eba9fd.png)

到此，采集任务圆满完成。接下来就是如何利用这些物料做内容。一篇小红书帖子的成败，通常由标题、封面、正文三个部分决定。下面分别讲。

### 3.4 标题的窍门

#### 3.4.1 统计高频词

先请Cursor对汇总表里的标题列做一轮高频词统计。需求写得很简单：“把标题列拆成单词，统计每个词出现的次数，按次数从大到小排，并带上对应的标题示例。”

![](img/68346e31fe5118b33225086545144ea8.png)

执行结果非常有参考价值。比如“假如 你 从”这组词出现了13次，相关热门标题清一色走的都是“从某个日期开始备考/做某件事”的路线，像那批带日期和考试关键词的帖子，基本都用了同一套句式。

![](img/a7059aef349ef58e771884c39814efc0.png)

![](img/8cb6b98094cb4164d7225c96a28a8c41.png)

看到规律后，你就能照着填写自己的赛道关键词，批量产出新题目。

#### 3.4.2 让AI改写

当然，也可以把收集到的热门标题直接丢给Cursor，让它仿写出一批新标题，再人工挑选最合适的。

### 3.5 封面模仿对象

封面决定了点击率，最值得借鉴的是“小号出爆款”的那批案例。比如只有一两百粉的账号，如果某篇内容突然火了，大概率是它的封面套对了某种模板。因此思路有两步：

1. 筛选出关注量少于500、点赞量大于1000的帖子；
2. 把其中前20或前50篇的配图下载下来，集中放进一个文件夹。

![](img/06f4a58d44ab5ac32feb884a7360b024.png)

![](img/576c1dab16332863dce46ac86e8fffe3.png)

![](img/3a52eb57a0131814702476084d795e56.png)

这样一来，细分赛道里那些小账号高赞帖子的封面就被批量汇总了。你可以快速浏览，分析最近的封面趋势，照着做就行。

![](img/99876a6d328f9e5bcb207c814d9f20da.png)

![](img/9defea95a438b8c750bd3c7fea3c0b48.png)

![](img/398e8ee008d79ea1c1c31cef21892e5e.png)

### 3.6 正文的仿写手法

正文层面，主要就是仿写。操作分两步：
1. 找到与目标选题相关的原文正文；
2. 让AI按照仿写指令生成一份相近风格的新内容。

正文素材在前面已经存好了。我们随意挑一篇，比如那篇讲考研英语阅读规划的笔记，把它的完整内容复制进新文件，然后在指令框里输入仿写要求。画面上红色部分为原文，绿色部分为AI生成的仿写结果。

![](img/3bdfb147f007c13f37f8e92599f35d70.png)

![](img/78b18940b75092c39da46c34c2cdfb11.png)

如果仿写结果里有哪个词或者某段话不合适，可以直接在文稿上改，也可以单独选中该区域交给AI重写。同样，红绿两色分别代表修改前和修改后。

![](img/ababa65ad93bb01c16a68db09e8a654b.png)

### 3.7 筛选热门标签

发帖时应该带什么标签？直接让Cursor对标签数据做汇总就好。

具体需求：“读取指定路径的CSV文件，取标签列，该列格式是‘#七年级上册语文,#新初一,#月考,#名著考点’。先把标签按逗号拆开，再统计全部标签的出现次数，找出出现最多的500个，写入txt文件。”

![](img/d8c402ce001f87aad546faca52cab6e1.png)

完成后得到的txt，就是一份高质量的话题热度清单。

![](img/85d15942284f587df7854ec7c5f415a9.png)

## 四、热门商品的挖掘示例

### 4.1 先拿销量榜

灰豚有商品销量榜、直播销量榜和销量飙升榜，而销量数据是笔记带货和直播带货的合计。如果想只看笔记带货的品，必须把直播部分剔除。我以近期“家居百货”类目昨天的销量为例，先在榜单里选好品类并导出数据。

![](img/cb83a34d8716dbd7523ff9a16b443581.png)

### 4.2 过滤直播带货记录

现在要做的就是过滤。把“只保留笔记带货商品，去掉直播带货商品”这个需求告诉AI。

![](img/46f9ae1abf0e233a139e716ac455be5d.png)

如果执行过程出错，或结果不符合预期，就把报错信息反馈给AI。同时为了便于观察，可以让它加入必要的打印语句，这样每一步做了什么都能实时看到。

![](img/edb815842eca9031b19f8479aa174371.png)

等程序跑完，得到的表格里就只剩下笔记带货的商品销售记录。

![](img/af51f43d0c9f1a01dd5d430df2bf7613.png)

### 4.3 还能做更多

在灰豚的详情面板里，还有笔记分析和直播分析两个入口。如果想继续了解带货商品背后的笔记和直播表现，可以从这里入手。
