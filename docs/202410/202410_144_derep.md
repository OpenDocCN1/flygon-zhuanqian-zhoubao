# 宝妈从 0-1 做闲鱼的心路历程

大家好，我是松庭，一个因为“双减”政策被迫离开职场的宝妈。今年4月我加入了龙哥盟圈子，6月初次报名闲鱼航海，9月又跟了一期。今天想把自己做闲鱼从0到1的真实经历摊开来讲讲，希望能给同样迷茫的朋友一点参考。

在接触闲鱼之前，我试过小红书上的百货类目，也碰过AI绘画，结果都不太理想。那阵子整个人挺低落的，觉得自己做什么都不成，赚钱更是没影，信心一点点磨没了。后来经人介绍了解了赚钱，第一次航海时看到有闲鱼项目，听人说这是最快能拿到正反馈的方向，我当时还想：我都做过小红书了，这个应该不难吧。

结果现实狠狠给我上了一课。同批的伙伴陆续出单，我却一直没动静。我心里反复嘀咕：别人行，我怎么就不行？到底哪里没做对？后来我沉下心，把直播回放一遍遍听，针对店铺的问题在群里厚着脸皮提问，慢慢调整优化。每天就做固定的几件事：上新，撤掉曝光差的链接，认真服务每一个来咨询的顾客。渐渐地，询单变多了，但那时候我反而不那么急着出单了，甚至觉得自己可能就这样了。

直到有一天，一个买家收到货后很满意，主动晒了图还写了长长的好评。没想到这个链接突然小小爆了一波，涌进来500多个“想要”，整个店的销量都被带动起来了。当时我做的还是低客单价商品，看着卖得热闹，月底一算账面，利润只有3000多。

【为什么又参加了第二次闲鱼航海】

记得不胖教练说过一句话，大意是：如果你不清楚链接是怎么爆的，迟早会露馅。这句话像警钟一样在我脑子里敲，逼着我去补基础。

那时候店铺正要从低客单价往高客单价走，中间有不少迷茫的地方，需要教练指点。而且闲鱼上跟人聊天推销的话术，其实到哪儿都用得上，这方面我自己挺薄弱。再加上赚钱的教练确实负责，所以综合考虑，我又报了一期。

【关于选品】

我原来上班的公司是卖拖鞋的，所以一开始闲鱼也上拖鞋。但拖鞋这行售前特别麻烦——每个人脚型不一样，尺码问题问个不停。后来换成6月航海推荐的品类，效果还是平平。教练说要在生活里找灵感，那时正好是大夏天，我看仓库里到处用冷风机，就试着挂了个链接上去，结果6、7月份卖得出奇地好。

从那以后，我就开始留意日常用到的、看到的东西。有一次刷视频，看到一个博主用的小玩意挺方便，第二天我就去闲鱼上架了，还真卖出去两单。平时我也会刷闲鱼，看到“想要”数量过千的链接，也会跟着上一波同款。另外，客户来咨询时经常会问“有没有某某东西”，这种需求我也会记下来上架，询单效果往往不错。

【关于销售话术】

刚开始上架时，我对产品几乎不了解，就去评论区找图，标题内容改一改直接挂上去。很多功能自己都不清楚，等到有人问了，我再转头问商家。就这样问得多了，慢慢也摸透了，后来都敢接客户的闲鱼电话了，单子也逐渐多了起来。

不胖教练有两点我印象特别深：

第一，不要被客户牵着走；第二，要在聊天中自然地把自家产品的优点讲出来。

不能因为想成交就把姿态放低，点头哈腰的。我卖的东西，服务靠得住，真有质量问题，我该解决就解决。但绝不为了出单就夸大服务和产品质量。对客户有原则，对自己也有原则。

【关于售后】

说实话我很怕售后，退货不赚钱还搭上时间，搞不好还影响店铺权重。但该来的总会来，分享三个真实例子。

第一个：客户收到货后觉得用着不方便，想退货。沟通后可以退，但运费由客户出，他也答应了。结果货寄回来时发现有磕碰，PDD那边不肯全额退，要扣一笔损失。客户不乐意，认为这是物流的责任，不肯承担。后来客户申请了平台介入，我也同时申请了PDD介入。最后闲鱼客服把钱全退给了买家，还额外补偿了我125元；PDD也全款退了对我的收费，加上9元运费。最后一算，这单反而赚了134元。

第二个：客户收到货发现所有桌脚都不平，要退换货。有了上次经验，我知道尽量别走物流，即便最后能退钱，沟通的时间成本也耗不起，所以就提出现金补偿。客户开口就要200元，一副没得商量的样子。拼多多那边只肯给20元，我和他们磨了好几次，总算同意补偿150元。剩下50元我自己掏呗，从利润里扣掉，这单赚了10元。

第三个：客户买回去发现买错了，自己掏运费给寄回来。我在PDD上申请退款和退运费，收到货后，运费居然也退给我了。这单利润80元。

总结下来：退货退款避不开，但都有解决办法，PDD的售后其实很给力，只要会沟通，基本不会吃亏。

回看我的闲鱼之路，走得不算快，问题也不少。但这就是真实的状态，我接受，也愿意改。一切都是慢慢长出来的，哪怕步子小，只要在动，就离目标近一点。每一步，都算数。
