# 闲鱼高客单，我的“思维换单”实战复盘

你是不是也觉得，在闲鱼上把高客单价的东西卖出去，靠的全是选品、文案和降价？我以前也这么想。直到第一次参加生财航海实战，选了闲鱼高客单项目，才发现：真正让你持久出单的，不是那些表面技巧，而是你看待项目的那套思维方式。

第一天我只用了10分钟翻完航海手册，就动手实操。结果不到半小时，就有买家来咨询，第一单就这么成交了。之后每天投入1小时左右，基本天天都能出单。

期间我最深的感受是：你得到的每一个结果，都是你思考方式的外在投影。每当我换一种思路去执行，订单数据总会往上走一点。这件事最有意思的地方，就在于你能不断拿真实结果，去检验和修正自己的认知。

我很认同一句话：向有结果的人学习，学的不是他的招式，而是他如何拆解问题。因为正确的思考路径，才是你得到好结果的关键。而这套思考方式是可以被“带走”的，换个项目照样能用——这才是它最值钱的地方。

上周末我在航海社群里分享了这些心得，大家反馈说很有启发，所以今天也同步发到星球上，希望能帮到更多圈友。详细的分享内容见：https://x6rsxr7w3l.feishu.cn/docx/NnfydjJyJoF8s8xT0ahcmHDQnHg?from=from_copylink&reRdXZ=1

另外有朋友问货源从哪里来。这点不用担心，航海有提供。比如我做的二手机，是从市场上回收别人用过的手机，再由一位专门做二手机的圈友供货，和普通电商批发不是一回事。

如果看完有启发，别只顾着收藏，试着把里面的思维用到你自己的项目上，结果会告诉你答案。
