# Coze 快速制作 MVP 产品：自动总结公众号内容并定时推送到微信

不会写代码，也能快速做一个能用的产品？拔刀刘教练用亲身经历告诉你：完全没问题。

作为Coze提效大航海的带队教练，他正带着2300多位船员一起实战。这次他分享了一个非常实用的案例——给自己的公众号做个AI助手，自动生成内容摘要，按设定时间推送到微信，全程不碰编程。

文章里他把自己做产品的思路全盘托出：怎么从零拆解需求、怎么梳理工作流、怎么一步步把这个工作流搭出来，甚至在1:1复刻指南里也写得明明白白，照做就能拥有一个同款bot。如果你卡住了不知道去哪儿找方案，他还讲了如何借助AI搜索来查找解决办法。

评论区里大家的反馈也很有意思：有人遇到RSS链接失效的问题，他直接回复说换成自己的RSS源就行；也有人卡在AI改写时报错——提示从空值提取字段失败，拔刀刘老师说这个问题他在做别的bot时也撞到过，后来已经有了解决思路。改装一下Prompt，每天自动接收喜欢的公众号推送总结，确实很省时间。

对了，不管有没有报名这期大航海，航海手册都值得翻一翻，原文链接他贴在文里，感兴趣的可以自己去看。
