# 为什么说营销理论是一门“放羊型”学问？

在判断一个理论是否科学时，我们通常会看它是否经得起验证、能否重复出现、能否做出预测，还要足够简洁、自洽，并且具备可被推翻的空间。换句话说，科学理论必须允许自己被证伪。

举个例子，“品牌理应成为一个品类的代表”这个说法看起来有道理，因为它确实符合不少现实案例。但它经不起证伪的考验。雅马哈在乐器领域是头名，在摩托车市场也做到了全球第二；亨氏不仅是番茄酱的全球第一，还是婴幼儿米粉的全球第一。这两个活生生的例子，已经把这个命题给反驳掉了。

如果一个理论不允许任何质疑和反驳，那它就不是科学，而是宗教式的话术：只要信，不要问。

当然，也有少数理论是整个推理体系的地基，比如逻辑学和数学。它们被普遍认可，自身不能被证伪，却是用来证伪其他理论的基础。

在王立铭老师的《进化论五十讲》里，我读到过一个很有启发的分类：理论分为“盖楼型”和“放羊型”。

盖楼型理论有四个关键特质：先验性、确定性、还原性、建构性。先验性和确定性是一组：盖楼要先画图纸，再按图施工，理论先行，然后照着理论解决具体问题；只要步骤一致，盖出来的楼也完全一样。还原性和建构性是另一组：高楼可以层层拆解，还原成钢筋、水泥、电线、电器这些基础元件，这叫还原性；而建构性则是反向操作：给你这些基础元件，按给定方法就能把楼重新搭起来。牛顿力学、电磁感应、元素周期表、原子核结构模型，都属于这种盖楼式的理论。

可惜，真实世界里的问题，大多不是盖楼型理论能轻松搞定的。有个笑话很能说明问题：农场的鸡不下蛋了，农场主请物理学家帮忙。几天后物理学家说：“虽然没找到你的农场出了什么问题，但我们解决了‘真空中的球形鸡’的下蛋难题。”鸡是否下蛋，影响因素太多了。

盖楼型理论擅长处理的是变量很少的简单问题。比如算出五大行星的轨道，只需要质量、距离、速度这几个数据就行。但要说清楚“女朋友为什么生气”，靠几条定律根本做不到。

营销问题恰恰属于后者，也就是放羊型理论。

营销没有先验性和确定性。你无法预判一条小红书笔记究竟能收获多少个赞、多少条转发、多少回收藏，哪怕素材一模一样，发布后的结果也可能千差万别。

放羊型理论的思路是：坦然接受世界的复杂性，承认营销是由多种因素共同推动的，放弃把复杂系统硬塞进几条公式里，转而用一套足够复杂的话语体系去描述复杂系统的运行方式。所以《营销管理》写了六百多页，很多人还是没读懂，而一条数学定理可能只需要几句话。

放羊型理论也有四个重要特征：边界性、不确定性、还原性、涌现性。

边界性说的是某个复杂现象出现所需的前提约束。羊群虽然变化万千，但必须有足够的水、草和空气才能存在，这是羊群系统的基本边界；至少可以判断，哪些地方不可能出现羊群。营销问题更复杂，但也有边界。以纯净水为例，今天它的主要渠道几乎注定是线下，因为单价低、每公斤货值太低，快递物流成本太高，线上卖不动。

不确定性，指的是复杂现象无法被百分之百精确描述。羊生小羊，雌雄比例接近1:1，但具体到某一次生公还是生母，就是随机事件。门头越大越显眼，但两平方比一平方到底“显眼”多少，算不出来。

涌现性，则是在系统变得庞大复杂时出现的全新规律，这些规律在较小规模时根本不存在。一百人的部落可以同心同德，可一旦到了一百万人，可能就会冒出阶级、党派、军队，这是看一百人组织时完全无法预测的。营销也有类似现象：花一万块做抖音，可能就卖出两百单；花一千万做抖音做宣传，说不定就成为现象级事件，虽然无法提前预测，但它确实会涌现。

所以，任何营销理论都应该尊重事实，而不是硬撑着证明自己永远正确。真正该做的，是根据事实不断提炼新的规律和方法。品牌能不能同时做很多品类？你犟也没用，事实就摆在那里。
