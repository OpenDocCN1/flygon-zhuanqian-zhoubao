# 缓解拖延的小技巧：先行动起来，超越大部分同行
作者：龙哥

你有没有过这样的体验：明明有一堆事要做，却总是拖到最后一刻，甚至干脆放弃？总想着“等我准备充分了再开始”，但那个“充分”永远等不来。

其实，破解拖延的钥匙特别简单——别想太多，先动手做两分钟。

这几年我发现一个有意思的现象：身边那些做出成绩的人，未必比谁聪明多少，但他们的执行力往往只比别人快那么一丁点，就能甩开一大截。很多人不是不努力，而是启动太慢，惯性太大，稍微遇到点阻力就踩刹车。

我们到底在怕什么？说到底，是对未知的恐惧。面对一个陌生的项目，心里没底，觉得自己搞不定，于是用“我研究研究”来搪塞。可实际上，研究来研究去，最后还是没动作。那个“研究”不过是拖延的借口——怕做不好，怕被人笑话。

我自己就是重度拖延患者。前阵子办线下见面会，因为从没做过，心里发怵，一直拖着不肯推进。直到有位嘉宾的档期只剩某一天有空，时间被迫定下来，事情才像齿轮一样开始转动。硬着头皮翻过那座山，回头才发现，那种拖延和逃避，其实源于对庞大系统的未知——你根本不知道第一步该迈哪只脚。

后来我学到一个特别管用的“2分钟法则”：如果一件事你觉得有难度，最好在2分钟内去碰它一下。能2分钟做完的，就咬咬牙做完；做不完的，也先干上2分钟。别小看这短短两分钟——打开空白文档、摸一下鼠标、跑几步路、穿上运动服，甚至只是把文件导入软件。做完你会有一种“我已经开始了”的暗示，挫败感瞬间减轻，自责和否定也跟着消散。

这方法有多灵？我写这篇文章时，本来憋着劲想一口气写完，结果拖了三天没动静。第四天下班前，我花了2分钟用语音把想法粗粗录了下来，扔进编辑框；第五天再花25分钟整理发布。你看，一个拖了五天的任务，最后不过是“2分钟口述+25分钟整理”而已。

还有个细节：我每天会把待办事项写在纸上，但经常有完不成的。以前我只会往后推，现在哪怕没做完，也先为它花2分钟打个底——给文档做表头、打开录音软件说上两句、把视频素材导入剪辑软件排好序。每个“小事”都让我觉得充实，下次再上手时，阻力就小了一大半。

那个著名的TED演讲者Tim Urban说过，拖延者的大脑里住着一只“即时满足猴子”。而“2分钟法则”，就是驯服这只猴子的第一步。多来几个2分钟，再庞大的项目也能被你一点点啃下来。真正的前进，从来不是憋个大招，而是从一次微不足道的“动一下”开始的。

所以，别等了。现在就花2分钟，去做那件你拖了很久的事吧。
