# 【赚钱技能】如何透过几个标准、筛选出合适的合伙人？
作者：龙哥

聊到合伙人这个话题，很多人的第一反应是：靠谱的人太难找了。今天想结合我自己十多年来的合伙经历，分享一套筛选合伙人的实用方法，希望能给你一些参考。

先交代一下我的背景：我深耕知识付费和私域运营两年半，更早之前有十几年的自由职业生涯。让我印象很深的是，十年前我和老师争论过一个话题——人才到底是选出来的，还是训练出来的？当时我坚持认为人才可以培养，但老师一句话点醒了我：“人才本来就是人才，去哪都是人才，你只是恰好遇见了他。”所以，筛选永远比培养更重要。

我对“合伙人”有明确的定义，必须同时满足三个条件：第一，拥有决策权；第二，名字和身份出现在公司制度或合同里，明确写着“合伙人”以及对应的股份；第三，分润方式不是固定底薪，而是按公司总利润的一定比例分成。只有符合这三点，才算真正意义上的合伙生意。我入行第一份工作就和老师合伙，表面上是助理，实际上三个条件全都满足。此后十三年，我的每一个项目几乎都是以合伙形式推进的。很多人说合伙容易散伙，但在我看来，合伙比单打独斗更有创造力、机会更多，成功率也可能更高；以我的性格，独自承担所有风险反而更危险。

不过，并不是所有项目都急着找合伙人。关键在于时机。项目还没跑通、变现路径还不清晰、甚至连自己都在纠结“要不要做”的时候，千万别找合伙人。方向都不明确，找来就是添乱。我见过很多新项目创始人，刚起步就把合伙人找好了，跑来问我该注意什么。我的回答通常是：先一个人跑通，合伙人不用急，否则只会增加吵架概率，项目也不见得跑得更顺。什么时候该找？当你有了稳定现金流，但明显感觉某个能力不足，或者遇到了不知道如何突破的瓶颈——这时候，合伙人就能补上那块拼图。

合伙人从哪里找？我强烈建议从一起做事的人里找，比如项目合作中认识的人，或者公司里与你默契、能力相当的员工。这种关系像大学同学慢慢变成恋人再走入婚姻，顺理成章。如果找一个完全陌生、只是听说很厉害的人，前期磨合会非常痛苦，风险很大。我自己也经历过拆伙，但始终认为第二种来源更可靠。

还有一个关键问题：找比自己强的，还是和自己差不多甚至稍弱的？我的经验是，如果你主动发起合伙，就别找比自己厉害的人。对方比你强，迟早会把项目带向你完全没想到的方向，因为强者天然更有主导权。真遇到大神，可以给他顾问费或一点点股份，请他做顾问，但别用合伙的形式。最好的合伙人，是与你势均力敌或稍逊一筹的人。

接下来，是我筛选合伙人时最看重的八个标准，供你参考。

第一，有没有失败后爬起来的经历。我喜欢和曾经失败过的人合作。失败让人谨慎，也让人看问题更周全、细节考虑更深入。能重新站起来，说明他真正吸取了教训，也调整了某些坏习惯——那些东西，没经历过大的挫折根本学不会。

第二，有没有拿到过结果。早年我带业务团队时，遇到过一些很能说的人，观点天花乱坠，方案一套又一套，当时我觉得挖到宝了。结果一周都出不了业绩，理由还特别多，方案越提越多，就是没有产出。从那时起，我就特别在意“过去的结果”——赚钱也好，做出过什么成绩也罢，那是硬邦邦的数据检验。哪怕是刚毕业的年轻人，也能从他的人际关系看出端倪：能不能随时约到朋友、需要借钱时有没有人愿意借小数目。这同样是结果的体现。所以，过去有没有结果，是我判断一个人靠不靠谱的重要依据。

第三，至少相处半年以上。选合伙人本来就高风险，大多数合伙散伙不是因为生意做不下去，而是人吵崩了。所以，我只会从相处超过半年的人里挑。这半年不能只在线上聊天，还要一起出去玩、了解他的圈子、去他家里坐坐。观察他的性格、生活习惯、处理事情的方式，以及这段时间里状态是否稳定。哪怕他只是一个普通上班族也没关系——能力可以培养，但好习惯和好特质需要时间沉淀。如果相处不足半年就想合伙，千万别用“一起赚钱”来磨合，那是最大的风险。

第四，他在别处的风评如何。合伙人往往来自老朋友、社群或朋友介绍，这时候很容易调查：问问他在其他社群的口碑，有没有负面评价，比如借钱不还、过去合作不欢而散、在社群里和人激烈争吵。当然，传闻未必是真相，但如果听到风声，我会花更多时间观察。反过来，如果这个人完全没有任何印象和评价，其实也很可怕——过去一片空白的人，往往让人难以捉摸。大原则是：没有坏评价，就先放进参考名单。

第五，看他面对当前事情的态度。我曾经招过一个人，项目已经成熟了，他也表现得很积极，最后他说：“给我一天时间，我辞职马上跟你干。”当时我觉得这人执行力真强，后来合作才发现，他远没有想象中优秀。复盘后我才明白，那种“马上抛下一切”的反应，恰恰暴露了不负责任。真正负责任的人会怎么说？他会说：“我很想合作，但手头的事需要时间交接，最快也要一个月。”他不会因为眼前的利益就丢掉责任。所以，一个人对待已有事务的态度，暴露了他的责任心。

第六，能力重要，还是特质重要？我的合作前提是长期，哪怕以后生意不做了，最好还能做朋友。这样来看，好特质比超强能力重要得多。能力好指的是编程厉害、销售一流、文章写得漂亮；特质好指的是人品端正、愿意沟通、遇到问题不逃避不消失、消息必回、情绪稳定、尊重每一个人。不是说能力不重要，而是两者相权，我更看重特质。真要找能力顶尖的人，可以招聘员工或小主管，但不需要让他当合伙人。正因为有这套标准，我甚至选过一些社会经验不多、但特质出色的年轻人做合伙人。

第七，用短期合约来试错。如果感觉人不错，但有些指标拿不准，项目不做又心痒，那就用“试用期”思维：先签半年合伙协议。合适就继续，不合适就到期拆伙。我甚至建议，合作关系可以一直走下去，但合同最好半年或一年一签。这样每隔一段时期就能优化合作方式，既约束彼此，也避免被绑死。

第八，感觉对不对。这是最玄学的一条。有的人明明没什么缺点，人也挺好，但你在他旁边就是浑身不自在，说不清哪里不对，只能解释为磁场不合。如果出现这种感觉，哪怕前面七条全中，最好也果断放弃。

最后说一句：合伙做生意的失败率确实很高，我也承认。但如果在合伙前期愿意花更多时间筛选，成功率一定可以大幅提高。就算最终没做成合伙人，也很可能成为非常好的朋友。

我是根源，一名拥有2万+实战案例的心理咨询师，12年线下销售和团队管理经验，2022年转型线上做知识付费。如果你觉得今天的内容有用，也欢迎翻翻我过去写的那些关于变现、私域、成交的文章。
