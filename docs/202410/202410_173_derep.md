# 闲鱼一鱼三吃，我在赚钱赚到的第一桶金

最近经常听到一个说法：消费降级，闲鱼崛起。确实，身边越来越多的人开始精打细算，闲鱼的流量也随之水涨船高，早已不只是个人卖家出闲置的地方，而是成了一波懂行者闷声搞钱的“新大陆”。

以前我也对闲鱼没什么特别的感觉，觉得卖卖旧货而已。直到自己真正下场，才发现这里的机会比想象中要多得多。作为一个完完全全的普通小白，我把从加入赚钱航海开始，到一边学习一边实操，再到逐步优化细节、稳定产出收益的整个过程，完整地梳理了一遍。可以说，这是我靠闲鱼赚到的第一桶金，也是我在赚钱里最有成就感的收获。


当然，这一切离不开赚钱航海提供的实战场景，也离不开教练和圈友们的耐心帮助。没有他们，我可能还在原地打转。

如果你也对闲鱼这个方向感兴趣，或者正在寻找副业突破口，不妨看看我的复盘，希望能给你一点启发。
