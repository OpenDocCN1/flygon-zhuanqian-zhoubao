# 从设计跨界到运营：90天，我如何熬过至暗时刻，等来爆发

“人类最强大的不是核武器，而是豁出一切的勇气。”这句话，是我这三个月最真实的注脚。

三个月前，我从设计岗一脚踩进运营的未知领域。说实话，当时我对运营一无所知，唯一确定的是——我想做自媒体，我想实现财富自由。认真，是我面对迷茫未来唯一能拿出的态度。

转岗没多久，正好赶上钟哥提出“鱼丸教练IP”的新概念。我当时心里一颤：这不就是我想要的吗？既能提升认知、做出成绩，又能把自己打出去，机会就摆在眼前。

我当时的想法很直接：“这么好的机会，肯定一堆人抢着做吧！”既然学运营是学，学做IP也是学，那干嘛不选个更带劲的？拼一把，看看自己能走到哪。反正学到就是赚到，最坏不过拍拍屁股走人。

钟哥让丸子们把想做的业务发给他，轮流谈话。我是最后一个被谈的。当我说想做IP时才知道——整个团队，只有我一个人提了这个想法。

也许是命里注定。用赚钱的眼光看，这就是“风口”。抓住风口，就等于抓住改变自己的机会。别看我现在说得轻描淡写，其实过程一点不轻松。

我花了一个月反复摸索“小红书达人变现”“小红书百货电商”项目，颗粒无收。整整一个月，没有任何结果，各种困难轮番上阵。那段时间，我每天都在自我怀疑、自我开导、再自我打气，循环往复，像一个没有出口的死胡同。人生跌入至暗时刻，表面开朗，内心却在阴暗地爬行。每天给自己列Todo，不断复盘、优化，硬扛着往前走。

但我始终相信，上天不会亏待努力的人。在我研究第三个项目【小红书虚拟资料】的第三周第一天，终于出单了！而且接下来的整整一周，持续稳定变现。

成交第一笔时，我激动得一直笑，恨不得告诉全世界。第一时间告诉钟哥，告诉所有帮过我的人。突然被互联网数据认可的我信心爆棚，立刻复盘，举一反三。

然后，爆文来了。一篇、两篇、三篇……像突然握住了流量密码，发一篇爆一篇。

再后来，因为一次特殊的机会，我成了28个船员的教练。我从没当过老师，从小到大只教过妹妹。我就用教妹妹的方式，把我懂的全部分享给他们。出乎意料地顺利，活动结束时收到很多学员的感谢和赞美，还得到同事和上司的认可。

更让我开心的是，回访发现，坚持完7天学习的一些学员，已经成功引流并实现变现。

现在，我即将成为mini航海近400个船员的教练。这几天一直和搭档杨杨、钟哥张罗内测，想把准备做足，帮船员们突破行动壁垒，持续输出，拿到结果。

加油！不管你现在正经历什么，想做就去做，别怕。

人这一生，能抓住的机会就那么几次。不试试，怎么知道自己能突破到什么程度？在保证基本生存的前提下，想做什么就去做。兵来将挡，水来土掩，为自己拼一把。

我的时间应该花在看更广阔的天空、呼吸更新鲜的空气上，而不是等到60岁还在拧螺丝。
