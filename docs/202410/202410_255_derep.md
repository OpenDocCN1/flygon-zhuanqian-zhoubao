# 如果赚钱也打排位赛，你敢来组队吗？

最近我在填“赚钱分”时，脑子里突然冒出一个奇怪的想法，结果中午躺下后翻来覆去怎么也睡不着，干脆爬起来把这个脑洞认真捋了一遍。

灵感其实来自几个方向的叠加：之前参与过风向标小组共创，平时也爱玩有排位赛的游戏，加上最近航海志愿者刚推出了老带新的玩法。把这几样揉到一起，我忽然觉得——如果赚钱也能像游戏排位一样，是不是会变得更有趣，也能顺手解决不少社群问题，让大家的关系更紧密？

顺着这个思路，我越想越觉得可行。排位赛里自然要有技能卡、积分、段位这些设定。圈友们可以自由发布一场“排位赛”的内容和报名要求，感兴趣且符合条件的人直接加入。等队伍满员，一场航海闯关就正式开始了。

这样一来，最大的好处是：不知道从哪下手的新手圈友，可以快速跟着经验丰富的“船长”一起出海。当不了路飞，当个索隆或者乔巴也很有参与感嘛。社群氛围会明显变浓，游戏感更强，平台方只需要维护好排位体系和奖励规则，剩下的交给玩家们自由发挥。组队的姿势也很多样，既可以自己发需求拉人，也可以随机匹配缘分队友。

说实话，我的赚钱分写得实在太少，所以特意把脑洞写成文章，算是变相延展一下内容。目前这纯属个人构思，不知道官方会不会采纳，也不知道能不能真正落地。欢迎大家在评论区一起讨论，毕竟开脑洞本身就很爽。
