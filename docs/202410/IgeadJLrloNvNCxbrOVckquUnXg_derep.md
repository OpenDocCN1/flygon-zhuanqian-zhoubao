# 把赚钱当成排位赛玩，赚钱社群会不会更上头？
作者：龙哥

这个想法是在填赚钱分的时候蹦出来的，午觉怎么都睡不着，脑子里一直转。源头是之前风向标小组的共创思路，加上游戏里的排位机制，最近航海志愿者推的老带新玩法也给了灵感。

把排位赛的概念套进赚钱，就觉得挺带感。既能解决现在不少痛点，也能让社群玩起来更丰富。因为赚钱分写得太少了，我就干脆写成文章来展开一下。纯属脑洞，想听听大家怎么看。

## 排位赛是个啥

核心就三样东西：技能卡、积分、段位。

圈友可以自己发起一个排位赛，写清玩法和要求。符合条件的圈友报名，凑够人就开船出发。感觉就像没法当路飞，就去当佐罗、乔巴一样，有位置可上。

这套体系自带 DAO 的味道。有人想单开需求组队，也能靠系统随机匹配。随机匹配会参考积分和段位，尽量把水平相近的人分到一起，不然体验会差。

运营成本也不高，只要把排位规则和奖励维护好就行。社群氛围会更浓，游戏感直接拉满。

## 具体怎么跑起来

**像线下组局一样玩线上**

现在线下活动很多人去不了，要么没时间要么就副业玩家。排位赛就能解决这件事：发布一个主题，凑齐五个人就开船，开始冲分。

怎么算分？以赚到钱为第一标准，复盘质量也可以折算积分。一年一个大赛季，一个月或21天为一小赛季。比如现在是赚钱第八期，那就可以叫赛季8。每个赛季都有段位排行和积分排行。

排位赛主题要过鱼丸审核，避免有人捣乱。五个人互相打分，打分长期靠后的就限制发布和参与资格。

**和现有的航海体系结合**

大家都说航海的人太多，面面俱到不可能。有人觉得难、没反馈就直接弃坑了。

用排位赛或小组的方式攒积分升段位，就能自然筛选出真想搞钱、副业能力强的人。真正想玩的人能进入更高级的玩法；打卡都成问题、只会围观的人就暂时被调出来，但还能围观排位赛船员的日志学习。

一期结束大家互相打分，打分也是积分的重要参考。想抱到大腿、进更好的项目，就得认真干、真贡献。

## 这套玩法能带来什么

**老带新，小组互补**

五个人一组，强弱自然混合。刚入局不知道从哪下手的人，可以立刻跟上一个懂行的人。强的人在教的过程中也能学会总结和表达，一期下来双方都变强。

而且强弱不是绝对的，技能不同就是互补。会PS的、会剪辑的、会RPA的、会编程的、会社群运营的，凑在一起一个项目就能跑起来，成功率比单打独斗高太多。新人有明确目标，有榜样可以对齐，参与感也强。

**线上排位更灵活、反馈更快**

像我之前分享过闲鱼一个月赚2000的小项目，信息差很小但上手快。按排位赛的逻辑，我可以直接发一个需求：懂闲鱼、能及时回消息的来。五个人凑齐就开干，当天就能跑。

成本几乎为零，不用等一个月收尾后再写文章排版分享，等大家都看到就卷完了。排位赛能让好点子第一时间找到合适的人，快速验证，跑通后再放大延展。

**信息量可控，协作更顺**

航海大群几百人，禁言群+大群，忙的人根本爬不动楼。漏看一天就彻底掉队了。能力强时间多的人能自己跑通，普通人就只能沉默。

五人小群的排位赛就清爽多了。听船长的指挥，在小群里协同，信息密度刚好。

如果嵌进航海体系，就是一艘大船上比赛龙舟。航海是大船，排位赛是小龙舟。教练负责写手册和答疑，领队带志愿者，志愿者带船长，船长带船员。小组只剩五个人，沟通效率完全不一样。

**参与感和执行力被点着了**

小组就是一个微型项目组，各司其职互相推着走。航海里有不少人连12天打卡都坚持不下来，排位赛天然就是筛选器。

因为是奔着赚钱去的小组，大家会更上心。排名靠前的小组可以受邀到大群分享，船长比船员更想表达。带人也能倒逼自己在项目管理、表达、沟通上快速成长。

说白了，就是把“赚钱”做成一个可玩、可比、可成长的游戏。
