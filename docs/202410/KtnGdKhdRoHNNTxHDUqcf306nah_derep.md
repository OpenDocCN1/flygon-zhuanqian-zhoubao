# ('《如何善待恶贵人，增加项目赚钱的稳定度？》', (2, 23))

做项目的人，大概都有同一种感受：赚钱本身就不容易，想稳定地赚，更是难上加难。但还有一种更憋屈的情况——明明是自己亲手埋下的雷，最后却炸在了最关键的节骨眼上。今天想跟你聊聊一个特别容易被忽视的话题：如何善待你生命里的“恶贵人”。

先自我介绍一下，我是根源，在知识付费和私域运营这个赛道里摸爬滚打了两年半。这一年多，和明白老师、陈雪美女一起做俱乐部，成绩还算稳定，会员净增长和复购数据都说得过去。之所以想谈“恶贵人”，是因为我曾经就在这件事上栽过大跟头，而且栽得很惨。

那时候我做某个项目，顺风顺水，赚得也多。人一飘，就容易目中无人。用“嚣张”来形容当时的我，一点不为过。公司体系里有三个大团队，我的团队规模比另外两个大得多。只要遇到其他团队的人，我总有一种莫名的优越感和气焰。开领导人会议时，我甚至会借指导自己团队的名义，故意去挑另外两个团队的毛病。当时的我，对“贵人”的定义很简单：能帮我赚钱的，就是贵人；不能帮我赚钱的，比如另外两个团队，在我眼里只是衬托我厉害的道具，根本不算什么。

现在回头看，真是蠢得可以。谁也不可能一直站在高点。大概风光了两年，一个大环境的变化让我的团队出了问题，赚钱变少了。人一落魄，风凉话就来了，而且说风凉话的正是我曾经看不起的那两个团队。那时候我天天后悔：如果当初不这么嚣张，哪怕稍微善待他们一点，也不至于被这样落井下石。最直接的影响是，团队的业绩和凝聚力每天下降。原本只是1%的缓慢下滑，因为周边那些攻击和冷嘲热讽，直接变成了每天10%。一分钱难倒英雄汉，一句风凉话，也能击垮人心。

还有一个更早的事。大学时我跟一个朋友合租，说好水电费平摊，结果该给钱的时候他耍赖不给。我当时年轻气盛，直接去找他爸妈要钱。钱是要到了，关系也彻底完了。他打电话来骂，我没接，心想绝交就绝交，这种人根本不值得交。结果一个月后，我去做魔术表演，他带了一帮人来闹场。表演毁了，钱没拿到，后续本来能接的商演也全没了。

类似的事让我明白了一个道理。涛哥有句话说得特别准：跟一个人接触之后，你要让自己只有两种结果——要么在对方心里印象加分，要么至少不扣分。千万不要因为某句话、某个行为，在别人心里扣了分，否则很可能在某个时候，得罪了所谓的小人，也就是我所说的“恶贵人”。

从那以后，我对贵人的看法彻底变了。我把贵人分成两类：一类是善贵人，一类是恶贵人。善贵人给你助力，恶贵人给你阻力。善贵人帮你一次，可能给你加20分；但恶贵人只要抓住机会来搞你一次，可能直接让你变成负100分。想一想，如果那时候我没处理好那些关系，放到今天做项目的场景里：直播播到一半，突然涌进一群人闹场；或者我加盟开个餐馆，开张那天善贵人送花捧场，结果一帮人提着油漆上来就把店泼了。这个带头的人，可能就是当年被我伤害过的人。你敢说他不来了吗？他可能等这个机会很久了。

更可怕的是，很多恶贵人，是你自己在不知不觉中“制造”出来的。比如对方没还钱，你心里不爽；有人说你课程不好，你当众怼回去；学员按协议退费，你虽然有理但言语刻薄；直播时状态不好，敷衍地回答了问题；或者心情不好时，学员来提问，你一个“喔”字就带过了。这些看起来都是小事，但每一件小事，都可能在你未来的路上埋下一个恶贵人。

那到底该怎么和恶贵人相处？我总结了五条实战经验。

第一条，保持60分的礼貌。说实话，要我们真心善待每一个恶贵人，真的很难。他们做的事、说的话，就是让人不舒服。但你千万别恶言相向。有人来挑刺，说“你这什么烂课”“你这个烂产品”，你要做好该有的礼貌，不让自己言行落下把柄。而且你要知道，并不是所有善意都穿着善意的外衣。有些人习惯用“反义词”表达善意，比如我老婆早上总说“你不抱我，我讨厌你”，但我心里明白，她其实是在表达爱。所以，这60分的礼貌，对任何人都要守住。尤其当你不知道对方是不是“小人”时，多一分礼貌，就能多避免一分未来的麻烦。

第二条，用道歉去削弱对方的防御系统。当恶贵人来挑刺时，我会先问自己：说什么样的话，能让对方不仅不反对我，内心还会觉得“这个人够大气”？最好的方式，是首先道歉。请注意，道歉的目的不是承认“我做得不好”，而是为了降低对方的心理防御。因为在沟通里，潜意识中的防御系统，才是阻碍信息传递的核心。人与人之间建立信任的第一步，就是打破这道防御。所以我通常会先说“对不起”“很抱歉让你有这样的感受”。这些话都是中性词，尽量别用过激的表达。一旦你情绪激动，说出口的话就可能激起对方的逆反心理，或者正好给了对方想要的把柄，他们甚至会把这些记录起来，日后继续讹你。

举个真实的例子。之前有个学员，他的课程被人批评“内容空泛”，他来找我求助。我给他示范了一个回复：很抱歉让你有这样的体验。你说到的“空泛”，其实我在写课的时候也有同感。你这句话点醒了我，这门课确实应该在细节上做得更到位。因为我能做到，并不代表别人也能做到。如果别人做不到，很可能是我步骤拆得不够细，或者我用太主观的方式在写课。真的很感谢你给出建议，让我有机会把课程打磨得更好。我能不能知道，具体是哪个部分让你觉得不完善？如果你愿意告诉我，会对我帮助很大。你看，这段回复既道了歉，又摆出了解决问题的态度，这时候对方就很难再来针对你个人挑刺，沟通也有可能往更好的方向发展。

第三条，接受世界的多样性。很多时候我们生气，是因为事情没达到自己的预期。你花几个月打磨课程、精挑细选产品，结果客户不但不感谢，还各种投诉、想退款，换谁都会火大。但这个世界本来就是多样的。就像我看“漫才兄弟”的脱口秀，明明那么好笑，满票200票，他们还是只能拿到197票。我总在想：那3个人为什么不投票？但转头一想，每个人家庭背景、成长环境都不一样，思维方式和处理问题的态度自然不同。有时候不是自己不好，而是我们得接受，人和人就是不同的。当你真正认识到这一点，恶贵人出现的那一刻，你心里就会有所准备，甚至对他们的过激反应多一份体谅。

第四条，事归事，情绪归情绪。这两件事一定要分开处理。人在被指责时，情绪特别容易上头，情绪一上头，基本就没什么好下场。处理事情，和发泄情绪，完全是两码事。一个真正成熟的人，要能掌控自己的情绪：什么时候该生气，什么时候不该生气，什么时候该开心，心里要有数。如果控制不了，你很容易亲手给自己制造一个又一个恶贵人，随时在身边爆炸。

第五条，负面声音的出现，就是进化的开始。一个软件如果没有用户给它找bug，它就不会升级优化。人也一样。如果没有负面反馈，你就会觉得自己很棒，根本不需要改变。正是因为这些声音，你才会回头审视：我的课程、我的产品、我自己，到底出了什么问题？为什么有人会给出这么差的评价？当你有了这个认知，恶贵人出现的那一刻，你甚至可以从讨厌他，变成感谢他——谢谢他们用这种方式提醒你，哪里还可以做得更好。

说到底，善贵人给的是好的影响，恶贵人给的是坏的结果。对善贵人好，谁都会；难的是，别让那些原本无害的人，因为你的不当处置，变成你的恶贵人。我们需要的，是在那些不起眼的细节上，多一分小心、多一分礼貌。积攒更多的善缘，减少不必要的恶缘，赚钱这条路，才会走得更稳、更远。

希望这些经历和心得，对你有一点启发。也欢迎你跟我一起讨论，你遇到过“恶贵人”吗？是怎么处理的？
