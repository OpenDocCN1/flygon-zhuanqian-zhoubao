# 创业十六年工具整理与分享：从旧工具到新趋势的梳理与更新
作者：龙哥

大家好，我是龙哥。创业整整十六年，手里也攒下了一批又一批的工具。前阵子看到龙哥老大发的悬赏活动，说实话，我一开始挺犹豫的。原因也很简单：清单里相当一部分工具已经很有年头了，有的早就下线或失效，怕拿出来不但没用，还容易误导圈友；再加上像自媒体、AI 这些新板块的工具，我又一直没来得及整理进去，总觉得还不到分享的时候。

不过转念一想，这反而是一个难得的机会——正好逼自己把这些年攒的东西从头到尾好好捋一遍，攒出一个属于自己的“工具武器库”。要是还能顺手给圈友们带来一点点帮助，那怎么都不算亏。

于是我用了一周左右的时间，把当初收藏过的每一款工具重新翻出来过了一遍。那些已经停服、过时或不再适用的，全部清理掉了——这部分目前已经完成；与此同时，新工具也在不断补录进来，这块还在持续完善。今后这个工具库我会长期维护，后面也会把具体的使用心得补上。如果哪位圈友发现有错误或失效的地方，欢迎留言或私信告诉我，我会马上修正或删除，提前谢谢大家。

关于分类，我主要按两条线索来组织：一条是事业发展阶段，另一条是工具的实际使用场景。

事业阶段大致分成四段：学习、打工、创业/副业、投资。不同阶段对工具的需求完全不一样——比如学习阶段更看重知识管理，打工阶段则讲究执行效率和提效工具。投资这层我目前还没有真正走进去，所以这部分工具就先占个位，等以后有积累了再补全。

我一直觉得，脱离场景来谈工具没有意义。工具本质上就是拿来解决问题的，而一款工具的功能也往往不止一种，不同功能要对应不同场景。就拿 5118 来说，功能非常多，怎么用完全取决于你当下的需求。所以在每个阶段下面，我又按不同需求/使用场景做了更细的整理，方便圈友按图索骥。

当然，分类只是为了更快地找到合适的工具，不一定要死抠某款工具究竟属于哪个标签。只要在真正遇到问题时，能想起“这个场景可以用什么工具”，目的就达到了。

最后说点实在的，因为这次悬赏时间到本周五晚上七点就截止，时间确实紧张，所以我就先把现有工具库开放出来。这个库我后面会持续更新补充，如果你觉得有用，麻烦动动手指点个赞，就是对我最大的支持啦～
