# 零基础启动播客？这份从0到1的实战经验请收好

如果你正琢磨着开一档自己的播客，却不知道从哪儿下手，那今天这篇分享或许能帮到你。

我是双菱，一名刚上路的主播，最近把自己从零起步做播客的完整心得整理了出来。之前我在播客打卡群里简单聊过，这次特意发到星球上，也是想着大家若有疑问，可以随时补充进文档，让内容更完善。

这次分享不是空谈理论，而是以我和明白、根源夫妇一起录制的几期节目作为真实案例，把整个流程掰开揉碎讲清楚——从最初怎么定选题、如何与嘉宾沟通，到正式开录、后期剪辑，再到最终上线推广，每一步都有可参考的实操细节。
