# 创业后才意识到的隐形成本

开公司之前，很多人想象中的成本是房租、工资、进货这些明面上的开支。可真等自己当了老板，才发现有一堆意想不到的地方在悄悄“吃”钱，而且每笔都不小。

最近看到龙哥分享了一张截图：公司人数到了一定规模，如果没有聘用残疾人员工，就得缴纳残保金。赚钱今年光是这一项就交了大概10万块。他把这个截图发到航海家群，结果不少老板都表示自己也交了这笔钱。

这件事挺值得聊的。对于还没创业的圈友来说，提前知道哪些地方会花钱，能少踩不少坑。于是龙哥在群里抛出一个问题：有哪些成本，是你开公司之后才意识到原来这里也要花钱？或者费用高得超出预期？

如果你是老板，肯定深有体会。哪怕你还没开公司，只是做副业或自由职业，也会发现现实和原来上班时的想象完全不同。很多思维上的差异、认知上的冲撞，都值得拿出来聊聊。

龙哥顺手举了赚钱的几笔年度开销：招聘平台几万块，协同工具几万块，企业通讯软件几万块，办公室物业费每个月几万块，数据服务几万块，每个月电费将近一万，保洁阿姨一个月也要好几千块……![](img/5466f6c75cb4b0bb88821487dc4e0eca.png "None")

评论区里的老板们也在不断补充：员工的实际聘用成本，远不止offer上写的那点工资，再加上五险一金，人力开销直接高出一大截。还有人说，开公司以前以为税的成本就是开发票那点税点，其实还有各种进项税、附加成本，导致一开始业务报价没报好，还以为自己赚了很多。另外下午茶、团建、聚餐这些看起来零零碎碎的花费，加起来也是一笔不小的数字。

看了这些才明白，创业不光是拼能力、拼产品，更是拼对成本的理解。很多钱只有在真正自己付过之后，才知道原来“隐形”的代价这么重。如果你正打算创业，不妨提前把这些账算清楚，至少别让利润在不知不觉中被吃掉。![](img/21de372a77ea1f441c613f7316831ae1.png "None")
