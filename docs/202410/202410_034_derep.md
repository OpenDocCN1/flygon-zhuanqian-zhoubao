# 航海新手图鉴：出发前我是天选，出发后我成“全力已负”

你有没有过这样的瞬间？每次报名航海之前，心里都燃着一团火，觉得自己就是被命运挑中的那个人，注定要在这次航程里大展拳脚。

可真正开船之后，画风突变：这个我学不会，那个我看不懂，甚至从“有点兴趣”变成“不太喜欢”……当初信誓旦旦说的“全力以赴”，最后只剩下一句“全力已负”。负数的负，辜负的负。

最近看到一位新手小白的分享，简直把这段心路历程讲到了骨子里。评论区里一片“这说的就是我”的共鸣，也有人一针见血：哪有什么项目能让人一夜暴富？更多时候需要的是耐心，是稳扎稳打的笨功夫；迷茫期谁都会经历，但只要咬着牙往前走，早晚会有开窍的那一天。

所以，如果你也正处在“全力已负”的阶段，不妨告诉自己：这不是终点，只是航程里的一段暗流。调整好呼吸，把“负”再变成“赴”，继续往前开。毕竟，真正的天选之人，可能不是永远不会累，而是累过之后依然选择出发。

共勉。
