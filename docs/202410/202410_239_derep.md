# 6 年脱口秀从业者真诚纯干货，想讲脱口秀看这篇就够了
作者：龙哥

做了6年脱口秀，我从后台搬椅子到给一线厂牌做现场导演，也亲眼看着徐志胜、童漠男、鑫仔这些名字一步步被更多人知道。但我自己，依然是个“不好笑”的演员。

今年脱口秀的热度又回来了。

但说实话，这个行业真的很缺人。你们在热搜上看到那些“脚趾抠地”的表演，在线下圈子里，人家可能早就被当成“天花板”了。

脱口秀难吗？难。难在每一次都要跟自己的人性较劲，把尴尬、脆弱、愤怒拿出来当素材。可它的回报也真高——头部演员年入千万不是神话，上过节目的，基本也不用再为生计发愁。

这行，前期投入大，后期回报猛，是一条越走越宽的蓝海赛道。

如果你也动过“上台试试”的念头，我这个老从业者的经验或许能帮你少走弯路。我把这些年攒下的干货都放在下面的链接里了。


当然，标题说“看这篇就够了”纯属标题党。想真正讲好脱口秀，得靠长年累月的死磕。没有足够的沉淀，想一夜成为付航，还是早点洗洗睡吧。
