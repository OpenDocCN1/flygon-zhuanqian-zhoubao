# 零基础也能一天上线企业网站？这个AI编程工具太香了！

大家好，我是龙哥。

前不久，我拿下了某个考证项目的官方代理资格，需要搭建一个公司官网来推广课程，顺便做百度SEO，给自己多引点流量。按以前的套路，必须自己画产品原型、找设计师出UI图、再让前端开发写页面、后端开发做逻辑，整套流程走下来，花时间不说，预算也蹭蹭上涨。

后来在一个偶然的机会里，我看到了Cutter，抱歉，是Cursor——听说它号称“不用敲一行代码，网页自动生成”，于是立马去查资料学习，亲自试了一波，结果真的有点惊艳。

具体怎么玩呢？我先挑选了一个同类竞品网站作参考，用截图插件把页面整个抓下来，再把这批截图丢给Cursor，它很快就帮我生成了前端代码。就这样，整个企业官网只用了一天时间就正式上线了。原本要花给设计师和前端工程师的几千块费用全部省下，效率提升了不止一个档次。

尝到甜头之后，我又拿着同样的思路，用一天时间做了一个很实用的网页截图插件，顺带把插件官网也搞定了。讲真，Cursor彻底颠覆了我对做网站的认知，它比我想象中更适合零基础人群。


另外，评论区里有圈友问我“后面会不会有Cursor编程航海”，我的想法是：如果大家热情够高，下一期很可能就会安排上。听说龙哥还让大家在国庆期间学习这项技能，趁假期动手试试吧，掌握Cursor，人人都是程序员！
