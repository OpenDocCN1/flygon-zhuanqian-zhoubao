# 牛市旗手：我在北交所长期蛰伏，等来单日套利30万
作者：龙哥

大家好，我是龙哥。经常有人问我：你凭什么能在北交所一天赚30万？答案其实很简单：在别人没注意到的地方，我硬生生熬了很多年。

我干过金融，也碰过互联网。曾经是某商业银行的网点行长，对零售产品业务门儿清。2017年我开始做副业，第一份就是股票经纪人，一直做到今天。别以为银行行长多光鲜，我那时的收入也就比普通打工族强一点而已。买房、买车、装修、养家，钱像流水一样出去，兜里剩不下几个钱，银行的任务指标还压得人喘不过气。

现在大环境不好，很多人收入缩水、工作没了、房贷断供。我没有资格教谁创业，但我想讲讲自己“熬”出来的过程。也许你能从中看到，一个人在自己熟悉的领域里坚持久了，真的有机会等来爆发。

这些年我见过太多人：有本事的，真金不怕火炼；扶不起的，再好的机会也接不住。金融也好，互联网也罢，哪有什么一夜暴富？所有表面的光鲜，都是时间给的沉淀。别被外界那些虚伪繁荣迷了眼，在自己的赛道里深耕，爆发只是时间问题。

网上的赚钱干货固然多，但大多数只是拿“赚钱”当幌子做流量生意。说来说去，还是从0到1再加N个0的逻辑。想真正赚到钱，自己先得硬：专业、认知、人脉、耐心，缺一不可。我也很感谢一路上的朋友和自己，正是多年养成的靠谱和真诚，让我能在一次次机遇中看到商机，也有底气接住挑战。

## 我的入场：从2015年那轮牛市说起

要吃到行业的红利，先得跳进来。2015年大牛市，我进了股市。一轮折腾下来，股票上没赚没亏，反倒是打新让我赚到十几万。当时规则是，账户里有股票市值才能用资金参与新股申购。我绕了点弯，用银行信贷资金入场，赚了十几万。这里也要提醒，直接转钱炒股是违规的，别学我。

印象里，一位朋友因为中了一只新股，直接赚了十几万。新股的爆发力，真是能让人上瘾。我也因此一直盯着新股。新股不是没有破发案例，可大多数时候都在赚钱。在我心里，这就是一条低风险配置的思路。后来我又接触存款冲量、证券冲量，认识了不少资金套利的高手。人越分享越幸运，我对北交所打新的理解，也是在这个圈子里逐渐从0到1，再不断放大。

## 北交所的底层逻辑，一次说清

北交所，即北京证券交易所，2021年9月3日注册设立，是国务院批准设立的国内首家采用公司制运作的证券交易所，受中国证监会监管。它主要承担深化新三板改革、支持中小企业创新发展的任务，目标是打造服务创新型中小企业的主阵地。目前国内几大证券交易板块——上交所、深交所、创业板、科创板、北交所，都在证监会体系内，属于正规军。

北交所打新的流程很简单：有股票账户 → 开通北交所权限 → 新股发行时参与申购 → 上市交易 → 核算盈亏。

现在北交所申购，几乎成了低风险理财的首选玩法之一。看历史数据：最近40次申购上市，只有1个破发，且只亏几百块，后来又涨回来了。在牛市加持下，新股翻10倍并不稀奇。更难得的是，只要资金把握好，我们有机会做到满额中签。这就是一个确定性很强的可放大生意。

## 从寒冬到春天：好项目不怕晚，但得熬得住

北交所打新从2021年就有，但早期破发多、流动性很差，市场认可度也不高。真正好起来是2023年，我也是从2023年底开始入局。那段时间股市一片哀嚎，许多人谈股色变，个股跌跌不休。后来和朋友一聊才发现，北交所打新是真的香：只要控制好风险，几乎等于稳赚。

即便在行情很差的时候，账也能算明白。我如果拿100万资金打新，一次平均收益1000元，资金占用2天，银行贷款成本约180元，理财成本约100元，一单净赚800到900元。如果放大到1000万，每次净赚约1万；一个月有两次机会，轻轻松松赚2万，扣掉成本还有1.8万。这种资金套利，在低迷市场里也算是暴利了。

尝到甜头后，我把本金从一两百万慢慢滚到一千多万——家族资金、银行信贷、收购客户资金都用上了，规模一度到两三千万、上亿。每笔赚个几万，稳稳当当。在北交所大爆发之前，靠着这套打法，我近一年累计赚了近20万，中间北交所还停过几个月。算下来，相当于40多天、每天进账5000元。这种“动动手指”的套利，难道不香？

## 牛市启动：坚持的人终于等到风来

2024年9月24日，美国降息、东风35导弹试射、国家启动股票回购增持贷款机制，牛市正式点火。北交所借着这股东风一路狂飙，整体溢价大幅抬升。低估值、盘子小、科技属性强、打新资金聚集，这些特点让北交所成为这轮牛市中冲在最前的旗手。

## 北交所优缺点一览

先看优点：
- 不用持股也能申购新股；
- 按策略操作，基本能做到100%中签；
- 破发概率极低；
- 容易走出爆发行情，博取超额收益；
- 当前最热门的板块之一；
- 中签后留存资金少，100股大概只要1500元以内。

再看缺点：
- 资金门槛不固定，牛市越热，打新资金要求越高。比如最近一只新股，低于160万基本没机会；
- 没有专人测算，很难精准预判中签概率，盲打等于白费利息；
- 开通权限需先有股票账户，且满2年交易经验，再加日均资产50万（活期也可以）；
- 申购时必须全额冻资，通常2天或4天不能动用。以下是个别账户的资金占用示意：

## 新股必中策略：把“碎股”玩明白

北交所打新与A股、深市完全不同，它不看持仓，纯靠资金说话。其中有个关键概念叫“碎股”：如果你的获配数量不是整百，比如210股，那200股属于正股，剩下10股就是碎股。正股直接分配给你，碎股会被统一收进碎股池，再做二次分配。因此，我们可以靠精确控制申购金额，去卡“碎股门槛”，多拿额外的100股；也可以分户打新，提升总中签率。

大多数人只会无脑申购，不懂测算资金和中签率。要做到必中，就得研究公司发行规模，预估申购资金量，倒推需要多少钱能拿下一签。这就是北交所打新真正的技术含量。下面是我的部分中签记录，每个账户都有命中；其他合作账户太多，这里就不逐一晒了。

## 算一笔收益账：为什么大家愿意玩

我们按资金占用2天来算：理财利息是每天每万5毛，100万也就一天50元，两天100元；信贷资金占用两天的成本约200元。但同样100万，最近打新一次收益普遍在1500到2000元以上。收益和理财比，相差15到20倍；和贷款成本比，相差7到10倍。这仍是保守数字。再看铜冠矿建：投入150万打新，中了400股，发行价4.33元，本金1732元，最后盈利12775.87元，而信贷资金成本只要300元，收益差高达42倍。市场热钱越多，打新收益或许可以维持，但抢食的人也多，中签难度自然水涨船高。

## 做大做强：我如何撬动更多资金

放大规模的关键，是从市场上找同频资金，让那些能看懂低风险套利的资金方参与进来。资金放在他们自己的股票账户里，打新结束可以立刻转出买理财或还款，占用时间一般就两天，不影响后续使用，而且回报可观。实际操作中，主要有两种模式：

### 纯合作模式
客户的钱在自己账户，我承诺保本；没中签，我赔理财利息；中签若亏损，我来补；最终收益七三开。我为什么敢这么承诺？因为500万本金的理财利息，也就500元左右，完全兜得起。

### 资金收购模式
有些资金方不想承担破发风险，就把资金使用权按固定价格卖给我，钱依然在他们账户。行情不同，两天费率从万6到万10都有。比如你有500万，按两天万10成交，我付你5000元，你实际理财成本约1000元，等于稳赚4000元。此后赚亏都归我，盈利你返还，亏损我补上。当然，这笔钱最后能不能顺利回来，就得看合作方的信用了。

说到底，赚钱的逻辑就是：收购资金 → 新股上市卖出 → 资金方归还盈利 → 核算盈亏 → 按约定分成。

## 普通投资者如何参与

我在这个圈子里已经摸爬滚打近10年，从从业者到操盘手，再到把北交所打新做成项目。这不是短时间能速成的，需要从底层理解市场各种规则和概念。所谓赚钱，赚的就是认知差；当市场行情来了，认知足够的人自然被推上风口。

如果你是资金型或资源型客户，比如手头有100万以上的灵活资金，又是金融从业者或有资源，那可以直接考虑共同参与。这类打法风险最低、收益最稳，相当于把一套认知反复复制，赚市场给的知识红利。

如果你是风险偏好型、资金量不大，也可以尝试用小资金去收购大资金。几千一万多，就能撬动几百万上千万。不过我有自己的风控底线：收购一个亿，成本已经很高，不太愿意继续加码。市场里确实有一些资金中介报价偏高，留有情绪溢价空间，但我更倾向把风险和收益分散到不同新股上，把生意做长久。再说，我们圈子里大量资金型客户和“信息差”客户，他们只求省心，愿意拿稳定前段收益。这种玩法的整体风险收益比，在我看来还是比直接炒股强。

## 我们的优势

专业能力方面，我们几乎不会出现打不中新股的情况；风险控制方面，合作客户的风险由我们全盘兜底；资金收购方面，我们会针对单只新股测算可能收益和最大亏损，给出完整方案；执行层面，牛市行情下如何获客、如何放大、如何控险，我们都有充足经验。谈钱不伤感情，一起赚钱才增感情。面对确定性机会，就该全力冲刺；上天递到手里的饭碗，别轻易撒手。而我，愿意做那个领头的头狼。
