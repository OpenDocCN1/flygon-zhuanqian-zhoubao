# 真正的高手，都有一份“不为清单”
作者：龙哥

不知道你身边有没有这样的人：看起来做事不紧不慢，但几乎从不在同一个坑里栽两次。

他们不是运气好，而是手里握着一份属于自己的“不为清单”。这个思路，段永平讲得很透彻。

段永平的核心逻辑大概是这样的：想要少犯错，靠的不是反复提醒自己“别出错”，而是持续去做对的事情。那什么叫做“对的事情”？其实就是当你意识到某件事是错的，就立刻停下来——哪怕这个停下来的代价再大，也一定比你继续错下去付出的代价小得多。

很多人觉得“止损”很难，是因为心里总抱着“再等等说不定就回本了”“已经投入这么多了，现在放弃太亏了”的念头。但段永平这句话点破了本质：当你发现走错了路，回头越早，损失越小。任何一次及时止损，从长期来看，都是成本最低的选择。

所以他特别强调：每个人都应该有一份 Stop Doing List。

这份清单上列的不是“要做什么”，而是“不做什么”。它像一道护栏，在你冲动时拉你一把，在你想侥幸时给你提个醒。

你可以试着写下自己最近最常犯的错，然后问自己一句：这件事，我现在愿不愿意马上停止？

答案越果断，你离“少犯错”就越近。

人生不是赢在做了多少事，而是赢在少做了多少错事。真正拉开差距的，往往不是你加了多少班，而是你拒绝了多少不该做的事。

现在，不妨给自己列一份“不为清单”吧。
