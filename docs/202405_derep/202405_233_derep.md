# 第一次做护航员，就带出了小组里程断层第一？我复盘了这21天

大家好，我是柏寒。之前写过一篇过去一年实战的经验总结，很幸运被加精了，今天继续来聊聊我的另一段经历。

3月航海刚结束，我作为生财有术的志愿者，第一次登上了“视频号中老年知识付费（书法国画）”这条船。没想到，从没当过志愿者的我，最后带着我们小组跑出了全舰队里最亮眼的里程数据——不是第一，是断层式领先的那种第一。领队给的评价是优秀志愿者，A+档。

很多人问我：第一次做志愿者，凭什么能做到这个成绩？

静下心想了想，这21天里我其实没做什么惊天动地的事，就是把每个微小环节都抠到位了。今天把这些思考整理出来，一方面是自己的复盘沉淀，另一方面也希望能给准备尝试志愿者角色的朋友们一些参考。

详细的过程和记录我放在下面这个飞书文档里了，感兴趣的朋友可以点开看看：

最后想说的是，没忘了这是所有人的共同成果。感谢生财团队、各位教练和领队的支持，也谢谢每一位船员愿意参与和信任。还有所有并肩作战的志愿者伙伴们，你们的存在让这段旅程真正有了温度。

第八期五月航海，咱们继续出发！

评论区有人问我心得，简单回两句：

有朋友说我是“细节控”，其实做志愿者就是这样——你多想到一步，船员就能少踩一个坑。打铁还得自身硬，自己先把项目跑通、把方法吃透，才有底气去带动别人；没有调查就没有发言权，只有亲自下水游过一圈，才知道水流哪儿急哪儿缓。

也有人翻完了我和船员的所有聊天记录，说催打卡这件事背后全是责任心、同理心和耐心，情绪价值直接拉满。作为生财新人，这篇帖子让他提前感受到航海是什么样子，花两小时读完觉得特别值。

还有位同样做过志愿者的朋友留言，说她带的小组上岸率也不错，但看完我的复盘才发现细节上差距挺大，下次再带船要把这些经验用上。能得到认可，真的挺开心的，谢谢大家的鼓励。

祝每个人都能在自己的航道上顺风顺水。
