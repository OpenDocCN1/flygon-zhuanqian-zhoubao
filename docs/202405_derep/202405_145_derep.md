# ('从纠结挣扎到 40 天 13w 到矩阵崛起，我在视频号的逆袭之路', (2, 34))

从反复纠结到视频号矩阵爆发：我如何用40天做到13万佣金

先自我介绍一下，我是唐威。

在赚钱这个圈子里待得越久，我越发现，很多人的困境不是不努力，而是把大量精力耗在了“选哪条路”上：是不断换项目去找机会，还是守住一个项目咬牙深耕？

这个问题，我没有标准答案。但我想把发生在自己身上的变化分享出来，或许能给你一些不同的参照。

早先前我在视频号上也折腾了很久，试来试去都看不到起色，整个人其实挺纠结的。直到后面换了一种打法，不再单点死磕，而是用矩阵的方式去运营视频号。矩阵跑通之后，结果来得比想象中快——40天时间，佣金做到了13万，整体GMV是21万。

回过头来看，那段“没有成果”的日子并不算白费。每一步积累都会在某个节点变成燃料，关键是要遇到合适的项目，然后全力投入，再靠矩阵把优势放大。与其把战线拖得很长，不如集中火力，打透一个点。

当然，这种事情没有什么一蹴而就的奇迹。看起来是40天爆发，背后其实是对平台、品类、内容反复测试后的厚积薄发。有朋友比较好奇佣金率为什么能达到61.9%，答案可以从选品里找——比如爆氧粉、管道疏通剂。

最后想分享一句我很认同的话：流水不争先，争的是滔滔不绝。项目是工具，节奏是自己的；找到那个能持续出结果的方式，比什么都重要。
