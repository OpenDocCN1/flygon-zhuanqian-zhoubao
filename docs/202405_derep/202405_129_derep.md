# ('打通任督二脉：学会《矛盾论》，实现月入 10w 的收益', (2, 29))

你有没有想过，一个人从普通打工人跌入失业低谷，再翻身做到月入10万+，靠的是什么？今天我想分享的，不是鸡汤，而是一套真正帮我“打通任督二脉”的思维方法。

我是张波。2023年4月18日，我加入了赚钱这个圈子。那会儿我还是个再普通不过的上班族，后来经历了失业的灰暗期，再到如今月收入稳定突破10W。这一路的心酸和成长，只有自己知道。

回看这一年多，我写过一篇《扬帆正当时：小白的赚钱之旅，一年成就月入十万的梦想》，把这段经历完整记录了下来。写那篇文章的初衷很简单：希望刚进圈的新朋友，以及进了星球却依然迷茫的伙伴，能从中获得一点启发，2024年咱们一起赚钱，一起奔着共同富裕去。

很多圈友问我：到底该怎么选项目？怎么落地？怎么行动？这些问题，我在读教员的《毛选》时，从《实践论》里找到了答案，于是写下了第二篇《实践检验真理：如何通过亲自实践，实现月入 10w 的收益》。

但光有干法，光有实践，还不够。想要走得更稳，还得有一种更圆融的处世和做事方式。这个灵感，同样来自《毛选》，就是《矛盾论》。所以今天这篇，我想聊聊“矛盾”——怎么看待矛盾，怎么用矛盾思维来做自由职业、做自己的项目。

说白了，最近那些热门事件，本质上都是各种矛盾集中爆发的结果。如果我们能学会用矛盾的观点去思考问题、拆解问题，很多看似无解的难题，都会找到突破口。如果说《实践论》教你动手去做，《矛盾论》就是教你如何在做的过程中看清主次、把握关键。这两个工具一旦真正掌握，可以说，就没有解决不了的问题。

当然，有些内容不能写得太直白。大家如果能领会其中的精髓，很多现实中的困惑，自然就通了。

这个系列目前有三篇，后面也许还会再写一篇，就看实际情况了。
