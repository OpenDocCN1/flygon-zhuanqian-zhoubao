# ('三年圈友，在抖音半真人直播实现月入过万', (2, 21))

在赚钱有术泡了整整三年，我终于撕掉了“信息焦虑”和“怕失败”这两块狗皮膏药，靠抖音半真人直播，实现了月入过万的小目标。

作为一个老圈友，我的故事大概和很多人一样：先是被项目打击到怀疑人生，接着刚进圈时像刘姥姥进大观园，什么都新鲜，然后面对满屏项目却不知从何下手，默默潜水、自我怀疑，最后咬牙重整旗鼓，尝试各种副业慢慢尝到甜头。每个阶段都有酸甜苦辣，但现在回头看，每一步都没白走。

相比圈里的大佬，我这成绩真不算啥。折腾三年，也就勉强月入破万。在赚钱这地方，这数字可能连榜单都上不去，但对我来说，它是我所有付出换来的最实在的认可。

写这篇东西的时候，我翻了下三年前的状态，那会儿我绝对想不到，一个电商小白也能走到今天。发出来不为别的，就想以老圈友的身份，记录一下自己这几年的心路历程——从亢奋到恐慌，从焦虑到和解，再到重新出发。虽然成绩不大，但或许能给还在迷茫的圈友一点共鸣和启发。

特别感谢靠谱姐和白哥，亦师亦友，帮我审稿提意见，真的是生命里的贵人。也谢谢赚钱有术这个平台，让我在茫茫大海里抓到一丝光亮。
