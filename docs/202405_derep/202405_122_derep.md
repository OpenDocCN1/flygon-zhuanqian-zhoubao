# 从零到七十万：一个80后网络小白的生财三年复盘

> 原文：[`www.yuque.com/for_lazy/zhoubao/fuqw2tevgel1oztt`](https://www.yuque.com/for_lazy/zhoubao/fuqw2tevgel1oztt)

前段时间收到生财寄来的手机壳，手感比想象中要好很多，先给官方点个赞。

随后又看到亦仁老师手写的7条原则，读完当下内心很是震动。内容里说的几乎都是我这三年在生财里跌跌撞撞走出来的真实体感。

加入生财已经三年有余。这三年来尝试过的项目并不少，也有几个能见到回款的，但因为成果不算亮眼、自己又怕写不好，一直没敢发声。这次赶上418节点，就想把这段经历整理出来，既给后来进来的朋友一点参考，也算给自己一个阶段性复盘，给生财交份作业。

这篇东西最早是4月17号开写的。第一次写这种长文，文笔又一般，心里没底。4月19号初稿出来后，我先发给了鱼丸，想请内部同事把把关，看看有没有不妥的地方。万万没想到，我发给的是机器人...足足等了好几天才收到官方反馈，结果等到回复时星球刚好处于禁言期，后面又撞上五一假期继续禁言。
