# ('新人如何高效玩转赚钱有术？我在赚钱历练一年的深刻感受', (2, 28))

标题：新人怎么快速玩转“赚钱有术”？我在圈里泡了一年，掏心窝子聊聊

大家好，我是飞掌柜，见字如面。

去年我误打误撞进了赚钱有术，当时纯纯小白一个，连“风向标”是啥都搞不清楚。可一年下来，不管是焦虑时的方向、心态、动力，还是做项目时的产品、流量、运营，我都像换了个人。要是让我把现在加的社群全退掉、只留三个，我第一个锁死的一定是赚钱有术。

五一那会儿，我组了两场赚钱新人局，跟50位伙伴把社群的角角落落都拆了个遍。交流中发现，太多人守着金山不会挖：精华帖那么多到底先看哪篇？风向标到底有什么用？航海实战怎么才能深度参与、拿到结果？自己手上有资源又该找谁对接？甚至有些老圈友付费好几年，却一直站在门外，真挺可惜的。

所以我把这一年的使用心得写了下来，主要想帮三类人：

- 刚来的新人：快速搞懂社群的搜索、精华帖、风向标、航海实战、同城聚会这些核心板块，搞明白龙珠、航海家、微天使是什么，知道自己该进哪些群、赚钱将来会长成什么样。
- 组局官：如果你想线下办局带新人上手，可以直接拿我这份内容当底料，再加上你自己的理解做成PPT或物料。我把线下分享用的PPT也放飞书了，供大家随便取用。
- 其他圈友：你要是平时忙，没系统性研究过赚钱，这篇能帮你查漏补缺；如果你已经是老玩家，那直接去按自己的节奏找项目赚钱就行。
