# ('把目标写下来，完成的概率是没写下来的 8 倍', (2, 24))

你收藏了那么多干货，却还是不会做？试试先把目标写在纸上。

最近有位刚加入生财有术的圈友向涛哥求助，说自己刷了大量内容，反而越看越迷茫。他遇到几个典型问题：感觉每个帖子都很有说服力，怎么分辨真假？什么都想试试，到底该从哪开始？看的时候觉得懂了，合上手机就忘光，收藏等于吃灰，怎么才能把知识变成钱？还有，目标到底怎么定才算清晰？涛哥的回答特别接地气，我帮你把精华做了个整理。

关于分辨信息，涛哥说，可以先选择相信，直到你发现破绽。你的大脑和身体其实自带判断力，现在只是信息量还不够。等你持续浏览、对比同行一周，那种“适不适合我”的体感会自己长出来。

新手最该做什么？打开 scys.com 看航海手册，初期只看这个就行。挑一个你不反感的方向，然后开始“事上磨”。记住：躬身入局，把手弄脏。只有能改变你行为的信息，才配叫知识，否则就是一段文字而已。

遇到看不懂的地方，别急着碎片化学习。抽一整段时间，在电脑上打开官网，搜关键词，找精华帖，慢慢读，一边读一边顺手做摘要。读完后，你手里就有一份自己写下的框架。接着照着框架尝试复述、口述或写下来，卡住的地方再回头查，直到胸有成竹。

如果某个大佬的观点特别合你胃口，就点进他的名字，翻阅他过往所有输出，或者在搜索框里输入他的ID，你能找到他生产过的全部内容。分享者分两种：运动员和教练。有人自己的成绩很牛，但不一定会教人。你要找到那个讲解方式对你胃口的人，然后跟着他的线索走下去。跟人学，永远是效率最高的。

上手的路径就三步：通读精读，归纳整理，学以致用。

至于“画面感”怎么建立？涛哥用一句话示范：我，杨涛，要在12月31日之前，通过卖书，赚到两百万。你也可以套用这个公式：我，某某，要在几月几日之前，通过什么方式，赚到多少钱。如果你现在写不出来，没关系，那是正常的。给自己一周时间，去定下数字和方式。具体的画面会带出具体的目标，具体的目标会延伸出具体的路径，路径对应操作，操作对应问题，问题最终对应解决方案。所谓落地，就是让每一步都踩在实处。

涛哥说自己信“言出法随”，当你把目标写下来的那一刻，会莫名获得一股力量。全球顶级目标管理大师特雷西·鲍文也说过：把目标写下来，完成的概率是没写下来的8倍。

所以，别只忙着收藏了。花一周时间，写下一个具体的目标，然后开始吧。奔跑吧，少年。
