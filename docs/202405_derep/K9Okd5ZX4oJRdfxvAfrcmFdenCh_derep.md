# 我训练ChatGPT写短视频分镜头脚本，它的表现，让我惊讶

我让GPT-4出拍摄执行单，它连机位示意图都一并画好了

我这个人有两样瘾：看书，拆电影。怎么个拆法？倒不是纠结剧情，而是盯着构图琢磨：机位凭什么放这儿？前景里那杯咖啡有什么用？光该打向何处？为何先贴脸再拉开？这习惯是从电视台传下来的。当年组里有个摄像组长，绰号黑哥，肤黑脸更黑，技术却神。他接一篇稿子，瞄几眼就能说出该用哪些角度，偶尔还冲到现场指挥机位。我既怕他又服他，只好不断回看经典片，研究每一帧背后的设计逻辑。后来我离了体制，遇上竖屏内容爆发，于是又捡起写稿、统筹、剪辑的活儿。所有环节里，最让我头疼的不是写稿，而是把文字变成能用开拍的分工表。

举个例子：之前为一家教培机构的数字化管理工具做推广。文字稿只消写好管理者与授课教师的对话即可，但实拍前，那张执行单必须细到：人物站在哪一区，摄像机离人多近，屏幕要叠加什么字，某句对白对应哪一组视觉。我曾经为这种事耗掉大半天。这就是我当时做的那张执行单：![](img/46ba259cc7230fef6b475d50fd0fe786.png)

这次我决定让GPT-4来试。我先给它设定了一个身份：资深视觉统筹。我要求它具备七项特长——把书面词句翻译成视觉片断、拿捏大场面/半身/面部特写的切换、用简洁文字说明每段表演、列出实拍需要的物件与地点和出镜者、读出每帧情绪并配贴片字、判断摄像机应当架在何处、把所有信息讲得井井有条。然后我规定了输出结构：先给一张明细，列清使用物件、拍摄地点、出场人物；随后给一张总表，每行是一个独立拍摄单元，包含场地、机位、出镜者、示意图像、表演指示、物件、贴片字、对白，以及这行内容对应原稿里的哪一句。我又塞了一条示范短片：大意是“别总逼问教师为何没人续班，先把服务抓牢”，里面把每个角色的神态和动作都写透了。最后我设定运行规则：收到我用引导符包住的稿件后，按六个环节推进——先拆句、列单、排序、补细节、画图、汇总；每完成一个环节都要问我一句“这步可以吗”。开场白我设成：“我已就位，请发原始稿。”

指令发出后，GPT-4立刻进入工作状态。![](img/1c2804c54fccf06a75f9aa940d694c73.png)

终于，它把所有内容汇总成一张结构化总表。![](img/ee4f65d00196be06da2241be503edb36.png)![](img/c942922bc7c76b19ad9487f09fe9bbbc.png)![](img/5d40d12e7a90cf71298ff5262ea5b237.png)![](img/ab580a9b820500873c52c032ed14db3e.png)![](img/2d2f9f33d41bef636633dbcb43046962.png)

整套操作下来，也就一杯咖啡的功夫。从前我手写同样内容，至少耗掉一个上午。这件事再次印证了一个想法：大模型能否替代复杂工作，取决于作业流程够不够清楚、标准能不能描述。只要这两点成立，机器完全可以帮你扛下大半。与其自己挠头，不如试着把稿件丢给它，让模型给你出一套完整拍摄蓝图。
