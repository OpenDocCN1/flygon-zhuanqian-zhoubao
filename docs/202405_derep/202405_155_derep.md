# 从零到4.4万粉20万变现：我用一年多时间，把读书写作做成小红书稳定现金流的实战复盘



## 新手入局读书写作赛道，还来得及吗？我用一年多4.4万粉丝、二十多万变现来回答

2024年3月，在广州的赚钱馆，我鼓起勇气问涛哥一个看似基础的问题：
读书写作这个赛道，现在做还有机会吗？

涛哥的回答很直接：别问我这个问题。

【先停下来思考一下，读书写作这条赛道，市场需求还在吗？现在入局是不是太晚了？】

随后涛哥把问题抛给了全场：
什么样的课程，是可以持续卖上一百年都不过时的？

大家面面相觑。
涛哥给出了答案：音标课。

想想看，雪梨老师的英语音标课，营收就突破千万。同理，中文也有26个字母，有汉语拼音。只要语言还在，就会有学习需求。

由此反推，阅读和写作的需求，是不是同样属于那种“长青型需求”？

答案是肯定的。

而且这条赛道从来不缺成功案例。赚钱圈里，粥左罗老师、Scalers的嘉宾、明白老师等，都靠读书写作实现了破圈和变现。我自己也是从读书写作起步，赚到了人生里第一笔10万、50万。

更关键的是，我的起点和里程碑几乎都与它绑定：
文化领域首个特等奖得主、
第一笔1000元青云计划奖金、
第一次办付费读书会、
并在读书会里结识了现在的投资人……

在这样的背景下，我怎么还能怀疑这条路？

事实上，去年我已经All in小红书的读书写作博主赛道。

一年多的时间里，粉丝从0涨到4.4万，累计变现超过二十万。

也是在那次见面，涛哥对我说，你已经不是新手了，是老江湖了，该出来写一篇真正干货的精华帖。

于是我把这条赛道里我验证过的变现模式和实操方法，全部整理出来，希望能给正在观望或准备入局的朋友一些清晰思路。
