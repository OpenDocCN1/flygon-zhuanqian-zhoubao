## 账号准备

### 账号相关

1. 先用自己实名注册，一人最多可实名20张卡，移动、电信、联通、广电各5张。其余可借用亲友卡，前期基本够用。
2. 后续可通过渠道批量采购实名号，渠道很多，需要可提供。
3. 注册必须用四大运营商实体卡，移动/联通/电信/广电，切勿用0月租卡或物联卡，注册时走手机流量，别走WiFi。
4. 批量注册时不要集中在同一地点同一时段，分散操作。
5. 注册首日不要大改资料，先养号再完善。
6. 账号尽量固定设备登录，避免跨机登录增加风控。

### 手机养号

5G环境：①一机一卡一号 ②换IP：开启飞行模式
WiFi环境：①一个IP最多承载3个平台账号 ②换IP：重启光猫
优先5G网络，一机一卡一号。

### 养号流程，养三天

1. 正常刷短视频，不要看直播。
2. 像真人一样刷，喜欢什么刷什么。
3. 早中晚分时段刷。
4. 每天带手机出门走动，顺便刷三次以上，每次20分钟以上。
5. 随手拍原创小视频发上去，不要搬运对标内容。
6. 第四天开始实名、刷粉、开橱窗，具体按各平台规则执行。

### 电脑网络

1. 宽带100M以上，账号越多建议多拉线路，电信、联通、移动、铁通混用。
2. 一台电脑对应一个平台一个账号。
3. 同一网线下不要超过3台机器同时直播，避免批量违规和卡顿。
4. 切换账号建议重启光猫换IP。
5. 切换后百度搜“IP”确认是否更换。

# 四、录制与下载素材

## 1. 下载录播素材【江湖工具箱】

目前实测最好用的是【江湖工具箱】，手机号码注册即可，免费。

![](img/653cc55ac64d1187b2f5e8d915ec3238.png)

常用功能：1.抖音直播录屏 2.抖音短视频下载 3.小红书作品下载

![](img/983e0fd8c96e904d6eede7a719caca37.png)

导入需要监控的直播间链接批量添加即可。

![](img/6827a57c82b840b31480883eabb2cf4a.png)

可多监控几个间，前提硬盘够大，我们下载的都是蓝光级别，每个素材10GB+，储备要足。

注意事项：

1. 录制时长最好一小时以上，越长越好
2. 素材要分前中后剪辑，做防查重处理
3. 清晰度必须是高清，低质量会被判定为劣质直播

## 2. 【实时转播】独家方案

实时转播软件是我们内部自研，暂未对外开放，仅做打法分享。需要试用的朋友可找我领试用激活码。

实时分发直播的核心逻辑，其实就是拿下抖音直播间的推流地址，然后把这路信号分发出去同步到其他平台。打个比方，账号只在抖音开播，我们就能把这条直播流同步到快手、视频号、小红书、淘宝等多个平台去。现在这套方案用下来，最大的好处是基本绕开了平台对录播素材的重复检测，因为每天播的都是当天实时产生的新内容，不太可能出现和别人撞素材的情况。

![](img/e770566958d4934d486c8e5b8176877a.png)

![](img/d90fe132332bf318eb6918fc13510e37.png)

我们的工具会实时盯着你指定的直播间，一旦主播开始开播，微信就会立刻推送【XXX主播已开播】的提醒，结束也会推送【XX主播已下播】。整体延迟大约在5秒左右，和源站几乎同步，可以做到一起开播一起结束，风控方面基本不用担心。

![](img/518f8cb9161ea8571e4b5e645111c902.png)

# 五、直播视频素材怎么处理

1.【江湖工具箱】导出的视频原始格式是ts，直接丢进OBS用会有兼容问题，所以先用格式工厂转成MP4；

打开格式工厂，点击MP4

![](img/b29559fef329a40f1046c1e2b0ecc2c8.png)

添加文件，选中要转换的素材，并记得修改好输出保存路径，避免找不到文件

![](img/15c8b99344c9be448d5ec2de5b4fe892.png)

点击“确定”

![](img/00625bf642d47d93f68c3369e3dad3b7.png)

点开始就等转换完成

![](img/5ded353d67c183533e6816f5304384d7.png)

2.1 第一种做法是把素材导入剪映，用“音频转文字”功能把语音识别出来，检查里面是否含有各平台敏感词，比如抖音、快手、小红书等，找到后做剪辑处理，前后衔接自然即可；

![](img/240aa2d7f2146c650a483b2089bd01f1.png)

2.2 第二种做法是借助【飞书妙计】把直播素材导入，导出成文档后搜索关键词，再回到剪映里对画面进行删减拼接；

![](img/aa47bf26d4a7349efa1aa0a8f6c83281.png)

3.早期复用素材比较多的时候，我们会在视频中间插入一些中控口播音频，像“是的”“对的”“没错”“今天拍，明天发”“姐姐们”“抓紧拍”这类短句，用来做查重规避。示意如下图：

![](img/a5310ff9f770681a732325b67b17e60f.png)

4.给素材加画中画也是常用的规避手段，既可以在前期剪辑时加上，也可以在OBS里实时叠加。OBS里操作的可控性更高一些。

把视频素材拖到主轨，或者把鼠标放在素材上点“+”也能添加进去，同时记得把原视频静音

![](img/bb1600a0473f3756b862befa6c3a27f8.png)

素材类型主要分两种

1.一镜到底型视频

需要把多条一镜到底的片段并排组合，保证画面切换自然流畅

2.多镜头型视频

每个画面相当于一个镜头，需要先拆分镜头，做抽帧处理，再重新调整不同画面的顺序

注意：无论哪种类型，都要做掐头去尾处理，把视频开头和结尾的小段裁剪掉【红框部分】

![](img/283b96c367c0e1a6e97dfc750ef3c26d.png)

对视频进行“裁剪”，选好合适的比例后点“确定”

![](img/e4d3aaa40d2e0205a59262a64442b493.png)

![](img/57145e6aedda2bb7630755a3f9fb4233.png)

选中素材后，在右上角工具栏可以调节变速

![](img/453025544dc482fcf7a04a21894e4ca3.png)

![](img/9f3ec2ad83991da8273ae39a49b19ccd.png)

在剪映左上方菜单点“贴纸”，下载后点“+”添加，把特效拖到和视频时长一致。选中特效后可在右侧调节大小。同理可添加滤镜，也能在搜索框直接搜特效名字

![](img/41718a60a05c618601daf554097830d1.png)

![](img/b782e55207707264ddd5ff2e05f7872b.png)

![](img/c9b7f2a23c3e74888cdfa709c8f00e51.png)

点红框里的三个开关，打开主轨磁吸、自动吸附和联动，方便素材对齐

![](img/083ecac51796e491645011f473d548c1.png)

把扫光素材放到主轨上方做画中画。横屏素材配横屏扫光，竖屏同理。扫光素材时长要和主视频保持一致

![](img/b18d624a0034719bbd1ef5e11d3e98ad.png)

选中扫光素材后，在画面设置里点“混合”，把不透明度调到1%；

点左上方“音频”，左侧有各分类音乐，也可直接搜索曲名，点“+”添加合适的BGM

![](img/8ee19ef6be9f11034f69a611023b6376.png)

![](img/3c4e1943cee6a500c0a1fd5a045c71f0.png)

如果音乐里带有人声解说或旁白，选中音乐后右键“识别字幕/歌词”，再修改字体、字号、样式，让字幕和画面搭配协调

![](img/7a2162171f9755a23bc3713ebbb7b232.png)

把音乐时长裁剪到和视频一致，混剪就完成了

![](img/8ecb6545deca4dd6027c591a24f582e3.png)

# 十、总结

去年我们跑了一整年的全平台矩阵策略，在多个主流直播平台都取得了不错的结果，并对接了小二资源。今年开始尝试无人直播这套打法，主要是想摸清平台动向。做无人直播踩过不少坑，最大的难点是没流量，其次是违规问题。流量方面，现在可以通过各平台的起号方法来破局；违规方面，我们自研的实时转播软件能有效规避素材查重，加上其他技术手段，基本可以覆盖风险。如果一套素材一天能卖1万多，那根本不用担心违规，被举报也只是换个号的事，号的成本很低，利润摆在那里就够了。

只要平台有流量，就值得去测。希望大家都能拿到结果。最后祝龙哥盟越来越好。

既然在这里收获了不少，也该回馈一下了。虽然一年只写一篇帖子，但都是用心整理的。
