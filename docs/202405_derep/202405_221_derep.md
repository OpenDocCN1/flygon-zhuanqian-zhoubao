# 李翔《详谈：沈鹏》附录 | 俞军的 PM 十二条心法

整理自：龙哥的收藏夹
2024-05-10

1. 产品经理的起点，是先做一个用户。

2. 所有判断都要回到使用场景里，用用户的视角去审视问题。

3. 用户体验不是某个点的好坏，而是从头到尾的一条完整链路。

4. 只做能产生真实结果的功能，拒绝形式化的堆砌。

5. 产品要去挖掘真实存在的痛点，而不是硬去发明需求。

6. 产品决策里，勇敢划掉什么，比加上什么更关键。

7. 用户习惯很难被改变，好的设计是顺势而为，不是强行教育。

8. 聚焦大众用户的核心需求，在关键环节实现差异化，先上线跑起来，再用反馈迭代。

9. 给用户一个可预期、可信赖的稳定体验。

10. 遇到方向不确定的问题，先看行业里已经被验证的做法。

11. 默认用户不愿费脑，把选择和思考都替他完成。

12. 不要塞给用户不需要的东西，多余的功能本身就是一种干扰和伤害。

读者共鸣：

柱石 : 第 11 条：把用户当成傻瓜，别让用户去思考和做选择，提前替他想好。
如果能早点彻底吃透这一条，每次面对用户提出的那种超出边界的苛刻要求时，就不会有那么大情绪波动了[流泪]

洲同学 : 第 6 条很有分量：决定放弃什么，往往比决定做什么是更难也更重要的。
```
      这句话在这几年中深有感触，而且我还是陷入其中的困境。特别讨厌自己一点拍个抖音又想要人设又要客户又要小白学员，【既要又要还要】追求完美，结果往往是什么都得不到，样样都通，样样稀松。
     既然自己做不好，那就先沉静下来，好好的学习，学习赚钱圈友的思维模式，做事方法。跟着航海一起走。
    断舍离中告诉我们，时间很重要，要学会不做什么，舍弃什么，做些当下重要的事。
```
