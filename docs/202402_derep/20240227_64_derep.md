# ('段永平 2023 问答录（104 条', (2, 20))

最近又翻到段永平在2023年留下的那批问答录，一共104条，常看常新。有人把他奉为商业偶像，也有人把这当行动指南，评论区里不少人说“每一条都值得反复琢磨”。

这里面最戳我的，是他对时间、下注和纠错的三段表达：

他说，要做那些让时间站到你这边的事，别急着要结果。五年、十年、二十年后，你会明白当初那些选择的真正分量。慢一点，反而快。

他又说，所谓赌，是胜率只有四成八的时候还硬上；而真正值得出手的，是胜算超过九成的时候。这大概就是投机和投资的本质差别——不是胆子大小，而是赢面高低。

他还说，发现错了就要赶紧改，哪怕代价再大，那也是最小的代价。拖着不认错，才是最大的成本。

这三句话放到一起，其实就是一个完整的心智模型：站在时间长河的一侧，只在赢面足够大的时候重注，并且永远不跟错误死磕。

完整的104条问答，来自这篇长文：[`mp.weixin.qq.com/s/884uyQ_fK7aLllsWfC487Q`](https://mp.weixin.qq.com/s/884uyQ_fK7aLllsWfC487Q)，值得静下来慢慢读。有网友评论说，这是“里面每个点都值得用起来”的干货，我也这么觉得。
