# ('风向标拆解第 3 期--选题 4《小红书高销售量手作饰品都是怎样的运转逻辑》', (2, 40))

你刷小红书的时候，有没有被雍和宫手串、灵隐十八子刷过屏？这几样东西，销量高得吓人。可同样是手作饰品，有的卖家却怎么也卖不动。到底区别在哪儿？

这次的风向标拆解到了第3期，第4个选题，我们就来扒一扒小红书高销量手作饰品的生意经。

拆完之后发现，市面上的热卖手作饰品基本分成两拨：一拨是像雍和宫手串那样，带宗教和民俗属性；另一拨是纯粹拼颜值、拼设计的装饰类手作。这两拨看似都在卖饰品，实际上的获客渠道、定价逻辑、目标人群，却是南辕北辙。

更关键的是，同一种饰品，在不同的平台和赛道里，价格能差出一大截。具体怎么差的，手串和纯装饰类饰品的运营门道又在哪？
