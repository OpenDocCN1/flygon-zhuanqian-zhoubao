# 一、起点：一串粉晶手串，打开女生生意

## 1、入场：追星女孩变成第一批好友

虎牙接触网络很早。初升高那年，她因为追星开始刷微博和QQ，加了一大批同龄同好。这些人后来成为她做生意的第一批基础用户，很多人到现在还留在她的列表里。

某天，她在QQ好友动态里看到一张粉晶手串的图，一下子被吸引。价格接近300元，对学生来说并不便宜，但她实在喜欢，就攒钱买了下来。最初只是觉得好看，没想到后来人缘桃花变得很旺，也在这时遇到了现在的男朋友，两人已经在一起五年。

![](img/43826f164c5a91103ad2779bb1f2b1e2.png)

她说，女生对亮晶晶的小物件几乎没有抵抗力，如果再来一点玄学色彩，更容易心动。她自己用下来觉得不错，想赚点零花钱，就顺手做了代理。第一单出得很顺，因为列表里都是同龄追星同好，消费意愿强，也知道她想靠自己的努力去看偶像，所以都愿意支持。

高三毕业那年，她决定认真经营这份小生意，把阵地从QQ搬到微信。当时好友给她的评价是：不像满屏刷广告的卖货人，更像一个认真生活的女孩。靠着这种真实感，她在同类卖货的人里很快被看见。

## 2、探索：量起来后，天花板也到了

水晶生意稳定后，她的模式是零售加招募分销。团队越来越大，来找她讨教的人越来越多。但她给同行的收费一直很低，算下来很耗精力，赚得却不多。

这段时间并非白费。她积累了大量不同行业的真实案例，亲自带着这些人跑通一个一个闭环，也为后来的转型打下了基础。

真正让她想改变的，是她发现原有模式已经没有上升空间。继续做下去，只是在原地消耗自己。她很清楚：不改变，就是退步。

## 3、进化：从卖货的人，变成教卖货的人

在无数次代理答疑和同行交流中，她发现自己很享受教别人。也有不少人劝她：你适合去做教学变现。

她开始有意识地付费向优秀同行学习，哪怕当时“知识付费”这个词还不流行。她一点一点搭出自己的产品体系：先做社群，再做训练营，最后做私教。

她的定位也慢慢清晰：陪不同阶段的人找到自己的方向，并把个人影响力变成可持续的生意。

如果用她自己的话说，水晶生意是命运推了一把；后来的转型，却是她主动抓住的。

# 二、方法：让用户看着一个人慢慢变好

虎牙能卖水晶成功，转型教学也成功，根本原因不是某个技巧，而是她把自己做成了“养成式博主”。

## 1、为什么养成式路线适合普通女生

养成式博主，就是把自己的真实进度公开。做了什么、遇到什么坑、学到什么，都摊开展示。用户看着一个人从零开始变强，会产生很强的代入感。

她举过一个例子：某内容平台上有一位博主，最初分享的是穿戴甲，几乎没什么流量。后来她开始发自己学习打扮的过程，还非常“听劝”，别人提出建议她就认真改。再加上性格幽默、前后反差大，慢慢从完全不会收拾自己的女生，变成能教别人变好看的人。

为什么这样的路线容易火？虎牙觉得原因有两个：一是普通人更容易在素人逆袭的故事里看到自己；二是人天生对“看着一个人变好”有好奇心。选秀综艺能火，也是同一个道理。

虎牙自己也是这么走过来的。她用水晶陪女生变幸运，用塑形产品陪女生变美，用教学内容陪女生变有钱。她的粉丝跟着她一路升级，从围观到付费，从付费到加入她的团队。

## 2、1000个深度用户，靠三类内容沉淀

虎牙很欣赏一本讲“1000个超级用户”的书。她的经验是：真正让生意稳定运转的，不是几万个围观者，而是1000个愿意反复买单的深度用户。

她的用户来源很杂：早期是QQ好友，后来有短视频平台吸引来的泛流量，再有各内容平台沉淀下来的精准用户。40多万人经过反复筛选，最后剩下的核心支持者，才是她真正的基本盘。

她平时只发三类内容。

第一类，是自己的经历和价值选择。用年度总结、阶段复盘、个人观点，让别人看见一个越来越专业的形象。专业方法到处都能学到，但“这个人如何走到今天”的经历，只属于她自己。

## 3、贵人体质：先让自己值得被帮

虎牙在《繁花》里看到过一句话：成功三要素，是贵人扶持、贵人鼎力扶持、贵人持续鼎力扶持。她觉得这话既幽默又真实。20岁时，她拿到过龙哥给的万元微天使投资，也被几位知名播客邀请做过访谈。

![](img/0422000a4721ab1c3f11d99935471248.png)

她说，吸引贵人的第一个心法，是先让自己成为有价值的人。人际关系像跷跷板，一方太重、一方太轻，关系就难以维持。与其等别人来拉一把，不如先让自己值得被靠近。

第二个心法，是主动选择更好的圈子。她每年在向上社交上的投入有5到6位数。她相信一句话：你的收入，约等于身边常联系的10个人的平均值。在优秀的圈子里，哪怕暂时迷茫，也会被周围人的行动力带动。

她筛选圈子有三个标准：看价格门槛，看是不是大IP发起，看是否匹配自己当前阶段。

最后，虎牙把自己的成事逻辑浓缩成三句话：奔赴热爱，做真实的人；择一米宽，掘万米深；借力打力，强强联合。她的故事没有捷径，只有把信任一点一点存起来，再用信任换增长的长期主义。

选圈子这件事，我现在回头看，其实就是三条筛选线，缺一条都会走弯路。

第一条线看价格。大多数时候，价格能大致映射价值，贵的圈子资源和人脉质量通常也更扎实。但贵不等于盲目跟，终究要结合自己的阶段和预算去判断。比如我当年跟着做的赚钱、玩赚这类头部高客单社群，本身就是市场口碑和排名都很靠前的存在，圈子里的含金量自然看得见。

第二条线看IP。直接从自己熟悉、信任、长期关注的大IP入手，基本不会错。赚钱是我通过合伙人柠柠带我进去的，玩赚则是大师姐靠谱推荐的。都是我认可很久的头部人物，有他们的背书，我少走了太多试错路，反而能借势加速破圈。

第三条线看需求。现阶段你缺什么，就去什么类型的圈子补短板。我决定做知识付费后，就只找知识付费方向的高质量场域。

迷茫想转型的那会儿，我加了赚钱有术这个互联网赚钱最大社群，就是想多看机会，多对标前辈经验。刚入行做课程大纲、学员权益设计时，我直接付费请了一位路径高度相似的前辈带我，花钱买经验，稳赚。后来要把业务从10做到100、组建超级团队，我又花钱向一位入行早我四年、团队搭建特别强的同行学习。

说到底，加入一个好圈子，本质就是通过付费给大IP做向上链接。这是最快拉近距离的方式，既能拿到高价值内容，也能进入优质社交关系，一举多得。

### 3）懂得感恩，给正反馈

最后，也是最关键的一点。贵人指点一定要感恩，贵人的话要落实，还要主动给正反馈。

大佬们真的不缺礼物。最打动他们的，是你用行动和结果证明他的指点没白费，持续用成长回馈他。每次有进步，第一时间分享喜悦，让他知道你的成绩里有他的功劳。定期做成长复盘汇报，是最好的正反馈方式。

但也要注意分寸，不要大事小事都去打扰。把关键人留在关键时刻用好，才是对高人价值的尊重。精简沟通，提升效率。

持续保持自我成长、向上链接、持续破圈，还能携手用户共同成长，为学员用户持续赋能，这样的局面何尝不是双赢。

# 三、虎牙成事心法：奔赴热爱、极致利他、借力打力、强强联合。

最后，跟大家分享我创业以来总结的3个成事心法。

正是靠这3个锦囊，我从0到1积累了40w+私域流量，穿越周期，用杠杆撬动了千万变现。

## 1、从0到1：奔赴热爱，真实做自己

从0到1的起点，其实源于追星带来的水晶生意。因为喜欢，我才开始做，第一批忠实用户和朋友圈就这样形成了。

到现在，我一直做的一件事没变：以初心为圆心，以热爱为半径，坚持做自己热爱的事，真实呈现成长轨迹，带更多女孩走我走过的路，帮助她们实现经济独立。

所以从0到1的心法很简单，奔赴热爱，做真实的自己。只有真热爱，才能扛住漫长时间，走得更远。

在热爱里成长，在真实中输出，你会吸引到同频的伙伴，一起相互赋能，成为高粘性的成长型IP。

## 2、从1到10：择一米宽，掘万米深

有次访谈主持人问我，为什么我看起来一路顺风顺水。我的回答是：择一米宽，掘万米深，每一步都算数。

做水晶，我从十八线小代理起步，到后来带百人团队日结五位数的一线销冠。做知识付费，决定单干到现在不到两年，学员超千人，合伙人50+，帮他们完成0到1、1到10、10到100的跃迁。

我都是亲自下场跑通闭环：引流、成交、交付，全流程自己打透，再从真实代理和学员案例里复盘迭代，沉淀出一套可复用的交付体系。

不管哪种模式，都是先定领域，再持续深耕，不断完善放大。专注一个点深挖，时间与努力会替你把IP做大。

## 3、从10到100：借力打力，强强联合

到这个阶段，必须放下单打独斗的思维，切换到合作共赢。

创业初期我也想做六边形战士，什么都自己扛。后来才明白，没人能样样精通，资源整合才是关键。

我擅长后端转化，就把流量端的内容教学交给更合适的人。比如引流训练营项目就是和合伙人共创，各司其职，放手后效率更高，效果更好。有引流需求的学员，我就对接专业的老师，既让学员满意，也能拿到CPS收益。

与其做全能个体，不如拥有一支各司其职的超级团队。我的核心团队只有5人，都是从合伙人里筛选出来的。有做整理归纳的，有做流量战略的，有做沟通成交的，有做内容写作的。遇到核心任务，大家各司所长，目标一致，执行极快。

今年我们合伙共创的Girls'Power女性创业者成长陪伴社群，从定位策划、规则设计到内测落地，全员群策群力。上线后资料官、气氛官、内容官分工明确，运营很快步入正轨，不断裂变增长。

合作才能共赢，成就他人即成就自己。无论哪种形式，强强联合、相互赋能才是从10到100的答案。
