# 优雅“拍脑袋”的秘诀：让对立观点在脑中共存

做决策的时候，你是不是也常陷入两难？要么反复纠结，要么干脆眼一闭心一横，凭感觉“拍脑袋”。但真正的高手，却有一种更高级的“拍法”——他们能让两个互相矛盾的观点在脑子里同时存在，却丝毫不耽误果断行动。

有人总结过：一个人的认知层次是否顶尖，关键看他能不能让两种相互对抗的观点在脑中并存，并且继续照常行事。这句话听起来有点“人格分裂”，但实际上，它是一种非常实用的思维功夫。

这种能力，与哈佛大学积极心理学导师泰勒·本-沙哈尔所说的“多面兼容思维”高度相似，也有人称它为“多面共存思维”。说白了，就是能把那些彼此毫不相干、甚至正面冲突的概念、想法和观点，统统收进脑子里，再把它们整合成一套属于自己的行动逻辑。

投资界大牛巴菲特，就是这种思维最典型的代言人。他的投资方式看上去相当矛盾：一边坚持组合投资，从来不单押一只股，靠“一篮子”策略来分散风险；一边又极度聚焦，把最大比例的资金放在确定性最高、赔率最诱人的公司上。“既分散，又集中”，这两条看似相反的路，在巴菲特手里却拧成了一股绳。

所以，所谓“优雅地拍脑袋”，并不是毫无章法地乱拍一气。而是你脑中装得下各种复杂的、甚至互相对立的信息，嘴上却能干脆利落地定下方向。真正的决策高手的本事，从来不是消灭矛盾，而是带着矛盾往前走。
