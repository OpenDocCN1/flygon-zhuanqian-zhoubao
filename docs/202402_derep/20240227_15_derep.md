# ('加入赚钱一年，收货第一个十万，视频号 3 天收益 6w 的分享', (2, 33))

加入赚钱一年，我从一个纯小白，到赚到人生第一个10万；就在前几天，视频号带货3天，又带来了6万收益。

这一路，真的挺不容易的。去年5月加入赚钱后，我先试了抖音图文带货，又做视频号带货。过程中有过焦虑，也有过担忧，但最终收获的喜悦，让一切都值得。

马上30岁了，说实话，有时候也会慌。短期的玩法、不稳定的收益，总让人看不到头。但后来我慢慢明白：想，都是问题；做，才有答案。山重水复的迷茫，往往多走几步就柳暗花明了。边干边调整，才是普通人最靠谱的路径。

在这里也要真心感谢龙哥盟这个圈子，氛围真的很好。尤其是王十七老师和团队，经常大半夜还在给我们答疑、帮忙找资源；还有孟总，以及所有一起战斗的小伙伴们。2024，咱们继续一起赚钱。

今年的重心仍然在视频号上，我想通过矩阵或者合作的方式，把盘子做大——说白了，就是多建几个号，让收益更稳定。另外，下个月考完试，我还打算去线下系统学一下半无人直播。如果你也在做视频号或抖音半无人直播，欢迎来链接，咱们可以互相学习。
