# 风向标拆解第 3 期--小红书 PPT 模板店铺-

这期风向标拆解第3期，盯上的是机会3里的一个方向：小红书上卖PPT模板的店铺。你猜怎么着？有店居然卖出了50万+件，这赚钱路子挺值得研究。

说起来，我原本也翻过不少实物类店铺，但对我来说，没有货源，又要发货沟通，实在太麻烦。所以更偏向虚拟产品。正好在星球风向标里看到PPT模板在小红书的卖法，又去网上扒了扒类似项目，于是有了这篇拆解。
