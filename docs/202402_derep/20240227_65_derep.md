# 江南春：我对战略的 27 点体悟

江南春曾用27条体悟，拆解他对战略的理解。把这些观点连起来读，不难发现一个共同的指向：企业若想活得长久，不能只靠运气或短期的爆发力，而是要在三件事上持续下功夫。

第一，是拥有足够长远的视野。不为眼前波动所困，敢于提前布局，看得清终局的人，才不会被中途的噪音带偏。

第二，是具备与环境共舞的韧性。市场随时在变，没有一劳永逸的解法，只有不断调整姿态、快速适应，才能活过一轮又一轮洗牌。

第三，是走出一条以价值创造为引擎的增长路径。不迷信流量的虚火，不迷信概念的包装，而是让每一次增长都沉淀为对用户的真实价值。

所以说，长期主义本质上是一种能力组合：方向感、适应力、价值心，缺一不可。江南春的这27点体悟，说到底讲的正是这个道理。
