# AI 如何驱动用户增长？聊聊最具竞争力的 AI 项目！

嗨，各位朋友，新春好！我是乔帮主。新春伊始，我想借这个机会，和大家认真聊聊AI领域一个相当值得押注的方向——AI营销，以及它到底如何推动用户增长。

过去的这两个月，我在不少线下活动里，像项目路演、社群聚会、年底年会，反复分享过AI在营销维度上的实战经验。今天，我把这些心得集中做了梳理，写成一篇文章分享出来，也期待能给更多在AI浪潮里寻找机会的朋友一些启发。

这篇分享的核心，是讨论一个极具竞争力的AI项目：AI营销。为什么我这么看好？因为在当下流量成本越来越高、增长越来越难的环境里，AI能够显著提升营销的精准度和效率，这可能是当前最现实的破局手段。不管你是自己创业，还是负责公司的运营增长，又或者正在寻找副业方向，都能从中看到潜力。

完整内容我已经整理成了文档，放在飞书里。建议用电脑浏览器打开阅读，体验会更流畅。同时，文档里还附赠了过往整理的好几批干货资料，像黑科技工具箱、技术赚钱实践指南、私域运营手册、ChatGPT商业机会盘点等，全是实战沉淀，值得一并收藏。

最后，祝大家在新的一年里，都能借AI之势找到自己的增长引擎，财源广进，好运连连！
