# ('小红书卖苹果卖了 300w，三农账号怎么做？', (2, 24))

在小红书上把苹果卖出300万？三农赛道到底藏着哪些机会？

今天看到一篇很实在的拆解，作者是大道至简，聊聊如何把农产品账号做起来。

300万的苹果销售额，这数字本身就够吸引人。更关键的是，作者作为新手，愿意把自己摸索的思路公开出来，光这份分享精神就很值得点赞。

内容干货不少，作者还专门准备了飞书文档，想深入了解的朋友可以直接点链接看完整版：https://t5ldp2gatt.feishu.cn/docx/MmfldbSF4oNglGxLXlxclv2bnxf?from=from_copylink

目前帖子里还没有人留言，平台可能还在审核中，感兴趣的话可以蹲一个，看看后续会不会有更多讨论。

说到底，从这个小案例能看出，农产品在小红书不是没有搞头，关键是你有没有找到正确的玩法和切入点。
