# 一、赛道现状

雍和宫手串、灵隐寺手串、深圳水贝珠宝批发等话题持续发酵，手作饰品赛道正迎来高光期。兼具文化内涵与潮流设计的串珠单品，在Z世代里拥有极高人气。

深圳水贝作为珠宝供应链核心地，也反映出市场对高品质手工饰品的强劲需求。创业者可以依托本地供应链优势，打造兼具文化寓意与市场契合度的产品，借助社媒种草和电商渠道扩大触达，提升品牌记忆度和用户复购。

本次拆解聚焦手串和手链。依据灰豚数据的全行业流量盘面，手部饰品赛道极度细化，已占据饰品品类整体流量的40%左右。

![](img/eefb2208c03bc3d7d2964e8be54e96f4.png)

手串的来历：手串源自古老宗教，原本是念经计数的工具，后逐渐演变为文玩物件，如今已是流行饰品。

文玩手串和时尚手链的差异：

佩戴位置都是手腕，但材质、工艺、佩戴动机和文化底蕴差别明显。文玩手串更强调材质的天然性、工艺的独特性与传统文化的延续；珠串手链则更偏向视觉时尚感和当代流行文化的表达。

# 二、手串

从2023年2月起，雍和宫景区门票预订人群中，90后、00后占比过半。

当下年轻人沉迷玄学，遇到瓶颈就想躺平，运气不好就怪水逆。

他们在努力与加班之间选择上香，在依赖他人与自我疗愈之间选择求佛。

## 1、玄学手串：年轻人扎堆财神殿

寺庙祈福的热度直接带动了周边衍生品。根据灰豚数据，在雍和宫、灵隐寺相关话题中，手串内容占比近半。明星同款效应更推高了追随热度。

产品特征：多采用菩提子、香灰瓷等寓意吉祥的佛珠串制，外形中性百搭，不同组合对应不同寓意，多数求完后会在寺庙加持开光。

核心人群：沉迷玄学的95后、00后，以及追星群体。

变现情况：均价在200-300元区间，多为线下售卖。小红书目前仅见普陀山官方账号在进行线上露出。

## 2、文玩手串：盘起来，年轻人玩真的

盘串的风气愈演愈烈，部分源于寺庙拜佛潮，部分受新中式美学推动，再叠加宁静、白敬亭等明星带货，文玩手串成为新宠，相关话题播放量突破14亿，甚至在小学生群体中流行开来。

变现情况：均价10-30元，1688拿货价约2元。以两家各1万销量的店铺测算，单店利润约8万-28万。

# 三、手链

在梳理手串数据时发现，佛珠、木质手串仅占手串整体的10%左右，珠宝手串和手链才是流量主力。

![](img/c81e261c553b967db502948e7944bb4b.png)

基于此，也对部分手链品类进行了拆解。

## 1、星座手链

星座手链依托西方占星理念，为十二星座匹配对应玉石或水晶，兼具装饰与“转运”心理暗示。

![](img/d5231ed67a2996b3c462ea2b800e5db0.png)

![](img/b301730a12d899925052d304a9281577.png)

![](img/01932c933e935d89bcb7404be161ae23.png)

产品特征：晶石串珠为主，设计偏女性化。

目标人群：喜星座文化的女生。

变现情况：以太阳石为例，1688同款约30元，售价79元，利润率超60%。

近几年MBTI成为主流话题，星座讨论有所下降，但灰豚数据显示“十二星座”话题浏览量达54.3亿，30天内相关笔记超3000条。

# 五、其他注意的点

1、保持足够垂直：

根据目标客群明确细分赛道，饰品品类庞杂，新手建议先聚焦单一垂类，如只做朱砂文玩、只做沉香、只做珍珠等。

![](img/2c0c065a0a490771a28fadf194be5768.png)

![](img/85b7dff85ded3dad7d8fd57902eee818.png)

![](img/176a5825abdf0bae652d14f41f393687.png)

2、结合人群标签植入关键词：

带上考研上岸、生肖、新年祈福等强关联关键词，提升内容热度，也能拉升低价手串的溢价空间。

# 六、总结

命理玄学内容属敏感范畴，入局玄学手串需严格把控文案尺度。

手串与手链的边界并不绝对，珍珠手链可附加好运寓意，木质佛珠也愈发时尚。核心在于：用什么样的饰品，用什么方式，卖给什么样的人。用户痛点是根本，要持续输出、跑通变现闭环。

拆解中也可见，饰品赛道细分众多，新手建议先以无货源模式线上试错，避免前期重投入。
