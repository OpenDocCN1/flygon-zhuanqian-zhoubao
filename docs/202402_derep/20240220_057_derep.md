# ('李竹：穿越周期的早期投资策略', (2, 16))

有人说，周期是考验，也是筛子。真正能穿越牛熊起伏的人，靠的从来不是等待和叹息，而是持续行动的信心。

投资圈里有个说法：悲观者往往更早看到风险，但乐观者才有机会抵达未来。时间的复利不偏爱聪明人，它偏爱那些在低谷仍然肯往前走的人。

那些选择躺平、被动观望的人，可能会暂时感到安全，但也会错过低点布局的机会；而积极行动的乐观主义者，愿意在不确定中做决策、试错、积累，最终会被时间奖励。

这就像穿越周期——不是等风来，而是自己先跑起来。每一次看似“太早”的出手，每一次不被理解的坚持，其实都在为下一轮上升期积蓄势能。

请记住：时间会证明，站着不动的人赢了争论，但走着的人赢下了结局。
