# ('风向标拆解第 3 期选题 10 花艺、绿植类账号，过完年是不是又有机会', (2, 37))

风向标拆解第3期来啦！这一期我选的是第10个选题，围绕花卉和绿植类账号来聊。很多人都在问：过完年，这类账号还有机会吗？我的答案是：值得再瞅一眼。

先交代一下背景：我是小Q，头一回做项目拆解，因为个人对花卉特别感兴趣，就挑了这块。结果越拆越上头——真正买单的，人均坐标一二线、年龄集中在35-40岁的小姐姐们，她们对花可以说毫无抵抗力。而且这个赛道基本都是靠直播带货跑量，但有意思的是，爆单直播间里坐着的，十有八九是男主播。

这一点，是不是挺反直觉？

关于账号怎么定位、直播怎么打、人群怎么抓，我把详细拆解都放进了飞书文档，想看的自己去拿：
