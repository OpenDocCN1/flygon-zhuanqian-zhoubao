# 为什么“空降式提问”永远得不到想要的答案
作者：龙哥

我们每周在群里聊问题，表面上是解答，更多时候是在一起找思路。可是说实话，有一类提问，我真的回答不上来。

典型的问法是这样的：我们是做 XX 行业的，现在全行业内卷严重，请问这个行业到底怎么破局？

这种提问听起来很急切，实际上却没有落脚点。因为哪怕是同一赛道里，成功的公司走的路也完全不同。

拿奶茶举个例子。古茗的强项在供应链、组织打法和门店运营的效率；麒麟大口茶的差异化在于产品本身的独特性；蜜雪冰城则靠极致的成本控制一路扩散。三个公司都在一个行业里，却靠的能力完全不一样。

如果你照抄这句话问我：我是龙哥，你说奶茶该怎么做出名堂？我也只能沉默。因为能不能做起来，取决于三件事：行业本身的规律、你企业的基因、以及你面对的顾客是谁。行业不同，打法不同；企业能力不同，路径就不同。

而当你抛出“行业怎么破局”这个问题时，往往并没有先想过一个关键点：我擅长什么？我手上的资源和能力，有没有可能在这个行业里形成差异？

只有先审视自己，才是站在现实的基础上思考，而不是停留在对美好结果的幻想上。

我通常会反问一句：你有哪些优势？得到的回答却常常是：我也没什么优势。那这就更难了，如果连可用的杠杆都没有，又凭什么期待突围？

想要靠一个笼统的问题拿到可执行的答案，本身就是不现实的。我们做判断需要前提，需要细节。

好比你跟医生说我肚子疼，问我该怎么做才能不疼了。医生不可能回答，因为疼的根源可能是胃、肠、肝、肾，也可能是结石、膀胱、子宫等完全不同的原因，没有定位就没有处方。

再比如你问我，我很穷，怎么才能变富？有人靠技术吃饭，有人靠经验变现，有人靠人际关系，有人靠外貌，有人靠经营，有人靠情绪价值。发财的路径本就因人而异，你要做的是识别并放大自己的长处。

不交代背景，不说明手上有什么，就想索要致富公式，我真的给不了。

所有的有效答案，都是建立在具体事实之上的。这点，应该不难理解吧？
