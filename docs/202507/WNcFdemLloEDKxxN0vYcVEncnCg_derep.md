# 前言

今年一月底要清理两张闲置执照时，我在星球检索 个体注销 公司注销 执照注销 等词，结果清一色是代办广告，能照着做的手把手帖子几乎没有。

那时我就下定决心，自己跑通全流程再写一份新手可复用的笔记，省下那笔冤枉钱。

数月后，两张执照均已注销成功，我现在有资格复盘。

## 一、我曾花1500元让别人代注销公司执照

第一家公司是2020年办的，办完即开对公，为的是批量申请公众号，前后折腾小半年。两年后不再需要，咨询了杭州一家较大财税公司，报价1500，便直接委托了。

典型的信息茧房。

![](img/5c2990b44afe412f916fb8f2ee370b2b.png)

当时我压根没意识到，其实自己就能去办注销，根本无需他人代劳。异地不便跑动或实在没时间的除外，大多数情况都是多花钱了。

## 二、后来新办的个体户和人力公司执照也得注销

业务调整后，我又在杭州办了一张个体户执照和一家人力资源公司执照。

个体户这张走过对公、开发过票、还缴纳过社保，后来社保关系转走了。

人力公司也开过对公，且拿到了人力资质。

2025年2月，业务试探失败，挂靠地址续费价格高，这两张执照彻底闲置，需要注销。站在你的角度，有对公、发票、社保的记录，是不是也会本能地找财务代办？

我当时就是这么想的。

记住，先在网上走一遍注销流程。填错了也没关系，系统会有专人审核，驳回时会明确指出问题点，看不懂还能直接打电话。全程不需要找任何财税中介。

我的个体户第一次线上提交就卡在清税证明上，去钱塘区税务局，窗口人员一次就帮我理清了，我只负责签字。

回家等系统更新后再次提交，公示20天后注销完成。

![](img/7700a8e663c17172dd9f4201bf3d0666.png)

人力资源公司第一次走简易注销，公示20天后因为地址异常没续费，只能转一般注销，公示45天。期间去了两次临平市民之家，主要解决税务和变更注销类型的问题。

PS：税务窗口有好几个辅导员，表面是答疑，实际操作都上手帮我们做了。

我问：代注销的公司真的会操作吗？

对方：怎么可能，都是我们窗口在处理。

明白了吧，代注销本质就是跑腿，税务问题必须现场解决。适合不差钱的老板或外地执照，本地自己跑更划算。

![](img/cd92fc1bb6f29a21fdb07ecb611ada16.png)

两张执照注销后，浙江政务网也登不进去了，所以没法截图。真的不用怕，直接干，按照流程走，只要线上提交了就会有人审核指导，你完全不用去咨询财税公司。

不管是地址过期、异常经营还是税务异常，先线上提交，专业人员会带你一步步改。否则你去问代办，他们一定会说情况复杂，加钱处理。不信可以自己问问。

回来路上跟两个朋友聊起这事，他们也完全不知道可以自己注销，还以为必须找财务公司。这两天赶紧把文章整理出来，希望能帮到和我一样预算紧张的朋友，把钱花在项目上多香。

# 🔥公司减资完整流程，最低省500～1000

公司减资为什么重要大家都懂，现在实缴要求越来越严，之前随便写的50万、100万，大部分人根本拿不出。将来要注销就不用减，长期持有就必须减，不然五年后要实缴到账。

## 普通公司最低能减到多少？

以我这种主要给家人交社保、对公账户只发工资流水、没有其他业务的公司为例，最低能减到多少？

👇我直接电话问了审核员：

我：普通公司最低能减到多少？

对方：按万为单位，也就是起码1万，

我：我看代办说能减到1000？

对方：不建议太低，减资要审核的，过低会被查。

我：公司需求只是交社保

对方：1000不太建议，2000-3000起比较稳妥。

总结：纯线上无实际经营的公司可以适当降低，但最稳妥是减到1万。因为减资公告要45天，金额必须和公告匹配，被驳回就得重新公告再等45天。

## 代办报价情况

我咨询过的行情，代账加减资一起最低500-1000，一年代记账一般1500-2000不等，看地区和公司规模。

自己操作，至少省下500-1000，省钱就是赚钱。

PS：减资变更里我发现变更后5年内缴清即可，那么大资金的公司能不能分次减？这个我没验证，有兴趣可以自己测或问官网客服。
