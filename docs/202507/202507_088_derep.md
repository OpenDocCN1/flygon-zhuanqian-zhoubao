# Youtube 中长视频怎么玩？我把这一路摸出来的经验摊开了说



作者：木辞
发布日期：2025-07-07

先来做个自我介绍，我是龙哥。最早是从 Youtube Shorts 入局的，后来进入了深海圈，特别感谢方波妮教练和 Gary 教练的带路。不少圈里的朋友之前用我分享的 VPS 教程低成本拿到了 YPP，这次趁着龙哥大佬的龙珠悬赏，把我这段时间在中长视频上的研究心得整理出来。

简单报个底：手上现在有 50 多个 YPP 账号，累计操盘过上百个 Youtube 账号，对平台的理解不敢说精通只能算有点体感。大部分账号我都交给了小伙伴日常运营，我自己现在主要聚焦在 Youtube 中长视频赛道的探索和拆解。


下面是我在实操中会用到的核心工具链和操作思路，会把流程拆成可复制的环节，希望能给同样做中长视频的你一些参考。
