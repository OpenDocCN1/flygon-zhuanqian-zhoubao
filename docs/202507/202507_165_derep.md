# 年营业额500w+，直播切片还能做吗？95后李子把全套玩法拆开讲透了

大家好，我是龙哥，95后自由职业者。很开心能来到赚钱这个圈子，总算找到一个信息密度高、正能量充足的搞钱组织。

这篇文章，我准备把自己这一年来做直播切片短视频带货的完整过程，从头到尾复盘一遍。诚实地讲，我正是靠这条赛道，做到了年营业额500w+，月收入稳定在六位数。操作上全程依靠自然流量，不花钱投流；偶尔视频爆了，也是商家主动来帮我推。


肯定有人会问：“去年才开始起步，现在入局会不会太卷了？”我的看法是，凡是能出现在大众视野里的赛道，基本没有不卷的。去年切片已经不是蓝海，这是事实；但同样在去年，新的账号照样一批批跑了出来。今年年初我也在持续做新号，依然验证可行，身边拿到大结果的人同样不少。哪怕放到当下，我观察到的市场上，仍然有不少达人的切片流量相当可观。

至于我为什么一开始选择切片？最根本的原因是，我想借助这个入口，把短视频带货的底层逻辑学扎实。但如果要客观给建议：除非你打算在短视频带货这条路上走长远，否则我更推荐新人优先去研究AI相关的项目。
