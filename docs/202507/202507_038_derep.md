# 六年素食，终在一瞬间放下

前阵子碰到一位老朋友。他很早就开始了纯素生活，一坚持就是六年。

起初的出发点并不是养生，而是信仰。他是因礼佛而吃素。

让他转念的，是去年的一趟非洲行。

他和孩子在当地，孩子不小心把一块饼干掉在了地上。非洲的地面厚厚一层土，这块饼干很快就被埋了进去。

没两秒，附近的当地小孩冲上去把饼干扒出来，直接就塞进嘴里吃了。那一幕让他一下子清醒了。

这么多人连饱饭都吃不上，自己却在计较这口那口，实在太矫情了。

回头想想，这六年素食也给他身边的人添了不少堵。聚餐要特别安排，外出要提前打听，朋友们总是要迁就他的口味。

他说这其实是用自己的坚持，把麻烦转嫁给了别人。

我告诉他，这样的放下挺好的。有些事，重在内心，而非形式，不必太钻牛角尖。

想想历史，佛陀在世时是托钵化缘，有什么吃什么。佛教早期本就不戒荤腥，真正推行食素戒肉，是南北朝梁武帝时期的事。

这让我想起一家打着环保旗号的餐厅。老板说店里每一块砖、一块瓦都是拆旧房回收来的，用来彰显环保情怀。

但算一笔账，光是把这些废旧材料收集、清洗、运输的成本，就早就超过了直接用新材料的费用。形式做足了，实质却没什么意义，最后不过是情怀作祟。
