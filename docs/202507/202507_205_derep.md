# (16 赞)7 天裂变 2000 人私域发售实战复盘
作者：龙哥

你有没有发现，现在公域流量的获取成本越来越高，想要靠纯投放或自然流量把盘子做大，越来越难了？真正的机会，其实藏在你的🛰️好友列表里——别人的私域，就是我们的公域。

最近刷到摄影师海盐的一篇实战复盘，她用了整整7天时间，靠一场发售活动成功裂变2000人，新增🛰️好友600多人。这个成绩在圈内看起来不算夸张，但如果你知道她背后3年做了30多场大大小小的发售，私域从最初的1000人做到现在1.4万多，累计变现几十万，你就会明白：这套玩法不是碰运气，而是一套可复用的方法论。

海盐说得很直白：对于中小IP来说，私域发售是最高效的获客和转化方式，也是决定你能走多远的核心能力。她这次把经验总结成了一套标准发售模板，任何阶段的内容创作者都可以直接拿来设计自己的活动。

整套流程被拆成三个阶段：准备期、转化期、追销期。每个阶段对应的目标不同，环节设计也要跟着变。准备期解决的是信任和预热问题，转化期负责把潜在用户推向行动，追销期则是在原有成交基础上做深度挖掘，让单次活动的价值最大化。

评论区里也有不少真实反馈。有人因为看了她早期的复盘帖，第一次尝试社群发售就招募了256人，转化率达到10%。还有人问她怎么统计拉新数据，她直接分享了用机器人工具的方法——这些细节都说明，她的经验不是停留在PPT上的理论，而是经得起实操检验的干货。

如果你也在做IP，或者正准备启动私域运营，不妨去研究一下这份发售模板。记住，当公域的流量红利逐渐消失时，真正能撬动增长的，是你对私域用户的深度经营。海盐的这场7天发售实战，或许就是你下一个爆款活动的起点。
