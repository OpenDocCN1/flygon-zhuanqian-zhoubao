# 空手起家也能做代播？一个互联网小白的杠杆逆袭路

说实话，23年我裸辞那会儿，手里啥也没有。

也没资源、也没人脉、甚至可以说是彻头彻尾的互联网新手。创业的第一步，我瞎猫撞上了视频号的爆发期，一头扎进了视频号带货这个赛道。

本以为只是先找个活干，结果在实操的过程中，我敏锐地捕捉到了一条被忽略的需求：代播。

从零到一，我没砸钱、没靠关系，就是靠着一套借力打力的思路，把代播团队硬生生搭了起来，用的就是最原始的杠杆思维。

从一个两眼一抹黑的小白，到最终带出年营收千万级别的团队，中间到底是怎么一步步撬动的？我把从发现机会到空手套白狼的全过程，都整理在了这篇复盘里。

如果你也正卡在没资源、没背景的起步阶段，这篇内容或许能给你一点启发和参考。
