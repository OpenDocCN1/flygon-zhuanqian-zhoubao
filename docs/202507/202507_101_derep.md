# 两套判断法，帮你看清项目能不能做10倍
作者：龙哥

作者：阿星 | 2025-07-05

大家好，我是龙哥，9年深耕知识付费赛道，K12和幼儿教育都做过，现在在一家职业教育头部机构担任业务负责人，主要管职业技能培训这块业务。

4年前我从无到有主导过一个技能培训项目，4年时间累计营收做到两个亿，业务目前仍在持续跑。今天想把这几年沉淀的东西拿出来聊聊——我用哪两套标准来判断一个项目是否具备十倍放大的可能。

这篇文章的灵感来自上周六下午两点，瑾糖总牵头的线下交流局。席间听到几位圈友的真实困扰，基本可以归纳为三类：

圈友A，已经把几个项目从0做到1跑通了，但卡在放大环节，不知道怎么把1做大；
圈友B，0到1是跑通了，可一旦要放大就得换客群，担心失控；
圈友C，线下模式验证OK，项目红利很足，很想把这份势能复制到线上。

看到大家的共同焦虑，分享欲一下就上来了，也顺带给自己做一次方法论的复盘。秉持着多分享多幸运的心态，就写出来了。
