# (101 赞)无代码实现 X 海报生成插件核心功能
作者：龙哥

有时候，惊喜就藏在细节里。龙哥昨天帖子的那张海报，其实并非出自什么设计团队，而是他自己捣鼓出来的一个小插件。

事情得从日常习惯说起——刷X时经常刷到值得分享的好内容，但平台偏偏不提供海报生成能力，分享起来总差点意思。于是干脆自己动手，做了个插件来补齐短板。它有三项本事：把推文一键生成为长图海报；顺带完成英文到中文的翻译；还能自动高亮重点，让阅读省力不少。

更厉害的地方在于，龙哥并非编程老手，在AI编程工具的帮助下，只花了两三个小时就把核心功能跑通了，期间他没有写过一行代码，甚至没看过一行代码。评论区有人猜是不是Claude Code，他给出了肯定的答复。

网友们的反馈也很有意思。有人建议给海报加上网页二维码，方便想看原文的人直达；有人感慨这插件精准踩中了真实需求，而且生成的海报本身还能带来传播效应；还有人说自己看到图片和视频的第一反应就是AI作品，紧接着就好奇是哪个AI做得这么好。也有朋友分享过类似尝试，做的是网站版，对比下来还是插件更趁手。

一个小插件，解决了分享痛点，也让人再次体会到：在AI时代，想法到成品之间的距离，从来没有这么近过。
