# 二、钱从哪里来

用户在你的 Agent 里保存了你放的网盘链接，你就能拿到佣金。不需要盯盘，纯被动收入。

现在的结算标准：
- 移动端拉新：8元/人
- PC端拉新：3元/人
- 移动端转存一次：0.45元
- 新会员充值分成：20%
- 老会员充值分成：10%

注意：PC端保存、🛰️小程序里保存的链接，都没有转存收益。![](img/ad7d336b7ad43de0964be93ff943663c.png)

# 三、搜索流量从哪里进

入口一共三个：Agent 名称、Agent 简介、你上传表格里的关键词。![](img/6765c7157d1737dbf391dc9a406a7bf9.png) ![](img/5fac70039df5f1fdd175341fc2791010.png) ![](img/e50e27983646f1cacce85d5ba6415f28.png) ![](img/ee12d2141d08040c2dc907beaa501ff9.png)

整理表格时，只用第二个模板，示例和黄色注释先全部删掉。之后 Agent 会根据用户搜索词自动发对应的链接。如果遇到敏感词，表格里写真实文件昵称，网盘里的文件昵称则改成缩写、代号之类的。![](img/60932acaa341b156afde5e4fc872c5aa.png)

# 六、搭建全流程

## 1. 注册账号

打开[百度智能体平台](http://agents.baidu.com/)注册登录。![](img/5f949ed37e24f62fe697b7fa97c3b199.png) ![](img/b64521c1f7ceeceb506816074c8bdede.png) ![](img/86f3cf6526ca0bf7756dd0db206367b6.png) 有弹窗直接跳过。![](img/553a853675346bc0f9b2f9ee100d32f6.png)

## 2. 基础参数设置

**名称**：把赛道关键词放进去，但别写“资源”两个字，防风险。

**简介**：建议抄同行，关键词尽量多堆。

**设定（角色逻辑）**：
方法一：用现成模板，打开复制：![](img/9af7929ac3a00f1f71a59eaf483e8731.png)
方法二：抄同行。![](img/1ab3c100bbb123415aac20014caba416.png) ![](img/92e93e200468f41e459ea28c15f7eabe.png) 把同行的角色逻辑复制下来，![](img/cde52a3702b0b67d3cf698ff99679603.png) 丢给豆包或其他AI工具，让它按这段逻辑改写成“分享XX资源”的角色设定，![](img/6751bcaa468dea165793cb981ae09521.png) 再把结果贴回来，点“AI优化”，![](img/02b65feb143f55981e370e7c1ffeba13.png) ![](img/ca4323250bb6ea3b17d56f14151dbc92.png) 然后点“使用”。![](img/0787da059ac194cabf36e6c85efa104d.png) 注意：等之前的黄色提示消失，功能才正常。![](img/13d15b53d6e1548d9d2d77d5b094a3da.png) ![](img/edc2516dd1602a8059a63ad1a5402862.png)

另外，设定里要强制加一句：所有回答都从知识库调取。如果一直不成功、界面报错![](img/838e5f41925d3a8bed81db1ce4c20a57.png)，就重新新建一个 Agent；或者先不加知识库，发布过审后再补。

**开场白**：模仿同行写。开场白问题写3个，直接填本地资源库表格里的关键词，内容不要带“网盘”两个字。比如你做旅游攻略，本地关键词是“云南旅游攻略、丽江旅游攻略、大理旅游攻略”，就把这三个填成开场白问题，引导用户按这种模式提问。![](img/be7d0cfb18f06080f60eab02936a452f.png)

**自动追问**：开不开都行。![](img/215b253db30c7df54cd55d407d805d8f.png)
**快捷指令**：忽略。
**联网搜索**：关掉。![](img/993d519d6c37fa3fbde16010559af490.png)

## 3. 知识库（网盘链接调用）

![](img/71c0c66a44bd3e27f43ce22475eaeb7d.png)
上传你做好的表格。第一列表头命名为“xx资源名称”，第二列命名为“XX资源链接”。第一列写用户会搜的关键词，第二列直接放合集链接即可，不用一个资源单独分享。当然，不怕麻烦也可以拆开。参考旅游攻略的例子：![](img/097753bd86adcd88108421c651691e08.png)

最新提醒：表格标题里别出现“网盘”两个字。![](img/8e9862e3e3f5f90e589c7d7d60f7c125.png)
不想自己整理资源，就上闲鱼、淘宝、拼多多买一份，让卖家发百度网盘，转存后再上传。

插件、工作流、数据库：全部忽略。长期记忆：开或关都行。![](img/39e7dce2a0f2c85748704e2fb9d8eac9.png)
声音、背景、线索转化、商品挂载、链接挂载：也全部忽略。![](img/c7e526a2235ae27e2b3926304d7c601d.png)

## 4. 测试

所有配置完成后，点右侧测试窗口，随便问一个问题，看 Agent 会不会回复知识库里的网盘链接。能回复就说明配置没问题。也可以发布后再测，偶尔会有 bug。![](img/f23258940d6dc3f664a5d088c07d6e81.png)

## 5. 发布

测试没问题，点右上角“发布”。访问权限选公开访问，部署平台不用管，设置完点发布，等审核上线就行。![](img/bd6545fe03e6de452cfb48f301e2777e.png) ![](img/16ce3a68e88905f2844fd1cdbfa8eefa.png) ![](img/e05f7ef87c42c534e14bd1513aa36703.png)

## 6. 发布后的排名影响因素

1. 使用次数和对话次数。![](img/bf626d3b7170302357502e960953f321.png)
2. 选细分小众赛道，搜索流量基本全归你。
3. Agent 名字、简介、表格里的关键词能否被搜到。
4. 网盘里别放🛰️引流信息：轻则被屏蔽，重则整个链接被和谐。
5. 每天上去优化，按系统给的推荐方案走；顺便翻翻用户对话，把高频关键词补进知识库表格。
6. 后台做任务拿流量包和曝光，有机会上24小时热门，爆一次权重就起来了。
7. 后台站内信提示资源违规，直接删掉对应链接即可。

# 七、账号绑定

百度要求必须绑定渠道才有推广权限，所有地方都一样，不绑做不了。我用的渠道是这个，邀请码：847276。

![](img/cfb3fc5a9aa10b3c76091067f0276bd5.png)

把绑定用的链接复制出来，用浏览器打开就能看到当前账号的 uk 标识，直接填入 UK 就可以快速完成校验。

校验不过关的话，就换一个号码再试。

![](img/db3c6d381dc03ed9254986e91468022b.png)

校验成功之后去提交会员申请，通常 1 到 2 天就能到账，容量立马可用。

![](img/a4f114021d02aacda112c7d4c5a007db.png)

百度网盘的扩容机制里，新账号第一次申请会员是固定的福利，会直接附赠 14 天 SVIP 且自带扩容额度。之后想要再扩容，就只能靠数据指标达标来触发自动赠送。

https://mp.weixin.qq.com/s/K1awvs3T_cZhEaRwJozgJA

另外的获取方式：

百度 500G 扩容包，每月可领一次：

https://pan.baidu.com/comps/view/MV84NTZfMTAzMF8yODU2X29ubGluZQ

应对存储不足的思路：

批量准备手机号去注册百度网盘账号，批量申请会员并领取扩容额度，等空间填满后即便会员到期，文件也不会立刻丢失。

若存放的内容体量较大，建议拆分到多个账号的智能分享体系中去托管，降低集中风险。
