# (138 赞)来帮小排的新产品 Fast3D 打榜

今天刷到一个很有意思的消息：小排团队的新产品 Fast3D 正在 Product Hunt 上参加榜单竞选，目前势头很猛，就差大家的临门一脚了。

圈子里很多朋友已经帮忙投过票了，龙哥也亲自下场号召，说每个人都来捧个场，把这个新品送上榜首。

先别急，投票其实很简单：把官方给的链接复制到浏览器里打开，找到 upvote 按钮点一下就行。如果页面提示注册，注册后再操作就好了。

投完票之后，还有个福利别忘记领。你可以去“刘小排r”这个👸号的后台找小排，把你 Fast3D 账号的邮箱和投票成功的截图发过去，他二话不说就会送你一个月的 VIP 会员作为答谢。当然，直接在相关帖子的评论区留言同样有效，一样能对接上。

顺带一提，评论区已经有不少人晒出了“已投票”的截图，还有人表示投完之后意外获得了一个“风向标”徽章，看来这波支持真的能带来好运。
