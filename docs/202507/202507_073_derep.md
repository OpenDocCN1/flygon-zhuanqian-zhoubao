# 海外新站上线后，如何用谷歌工具追踪真实数据？
作者：龙哥

很多人把海外网站发布上线后，就开始等待流量到来。

但网站上线，并不意味着接下来只能“等结果”。尤其是刚上线的新站，更应该主动观察用户行为，用数据判断网站是否正在被访问、哪些页面更受欢迎，以及用户在站内停留了多久。

这篇内容主要介绍：如何借助谷歌提供的工具，持续监控海外网站的访问情况。

## 新站上线后，别只盯着流量

完成网站发布只是第一步，后续的数据跟踪同样重要。

你可以通过相关工具了解：

- 每天有多少用户访问网站
- 用户主要从哪里进入
- 哪些页面获得了访问
- 用户在网站上停留了多长时间
- 网站上线后的整体变化趋势

相比于被动等待某一天突然出现大量流量，持续记录和分析这些数据，更有助于判断网站当前的问题与机会。

## 适合刚上线的海外网站

本文分享的方法，主要面向刚刚上线不久的海外新站。

如果你的网站已经运行了几个月，或者已经积累了一定访问量，也可以进一步搭配更专业的插件和分析工具，获得更加丰富的数据反馈。
