# 新手也能一个月做千万播放？我的 YouTube 短视频从0到爆款实操
作者：龙哥



## YouTube 新人入局中阶指南 + 加入赚钱四个月的成长复盘

大家好，我是龙哥，一个刚起步的 YouTube 创作者。运气和努力撞上了——我在航海结束后仅一天，发布第 23 个作品就冲上了千万播放。截至现在，累计播放已经突破 3000 万，订阅数也来到 3 万+，并成功开通了高级 YPP。

这条帖子本意是想聊 YouTube 爆款的方法，后来干脆把过去四个月在赚钱里学到的东西一起梳理了。回头看这段时间的转变，真的很感谢能遇到赚钱这个地方。

关于赛道的选择，我踩得很细。整个一级细分赛道我迭代过一次，而二级细分赛道的试错次数，少说也有十五次以上。正是这种不断收敛和试探，才让我在 AI 动物这个垂类里找到了能持续放量的点。
