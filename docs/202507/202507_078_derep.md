# (9 赞)一键保存素材到 Obsidian 笔记工具分享
作者：龙哥

刷到好内容时，最怕的是什么？大概就是恰好遇见一句值得收藏的金句，或者一篇想留底的干货教程，结果得先在手机和电脑之间反复横跳：复制、切走、新建笔记、粘贴、再切回来。几趟下来，收藏的热情就熄了一半。

这位圈友每天都得消化大量图文信息，同样被这套“复制-切换-新建-保存-切回”的流程折磨得不行。于是他索性用 Claude Code 给自己写了个小工具：复制好的素材，直接就能送进 Obsidian 里指定的文件，基本等于“复制即保存”，省掉了中间所有多余动作。攒素材这件事，一下子从“麻烦事”变成了“顺手事”。

他把开发心得和完整细节整理成了文档，说是单纯享受动手做工具的乐趣，但顺手也帮到了有同样需求的圈友。这个分享还收获了 9 个赞。想试试的话，点开原文链接就能看到具体做法。
