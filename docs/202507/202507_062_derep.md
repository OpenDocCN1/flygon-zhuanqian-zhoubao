# (29 赞)用一招“学习导航器”提示词，把 Claude Code 变成带练教练

作者：云舒的 AI 实践笔记  
发布：2025-07-08

原文：[`www.yuque.com/for_lazy/zhoubao/ifrmuc863iekywme`](https://www.yuque.com/for_lazy/zhoubao/ifrmuc863iekywme)

最近在琢磨 Claude Code 该怎么用得更顺手，特意翻了翻官方文档，还看了小排老师的 Claude 使用手册。🤣 理论看了不少，但一想到要自己到处找练习项目就犯懒。作为一个典型懒人，我干脆反向操作：做一个提示词，让 AI 帮我定制实操项目，我只需要跟着走就完事了。

折腾下来诞生了“学习导航器”这条提示词。它的逻辑很简单，把任意学习资料拆解成一份清晰的学习路线图，再按章节拆成可执行的练习，带着你一步步练。实测下来上手很快，跟着做确实挺顺的。
