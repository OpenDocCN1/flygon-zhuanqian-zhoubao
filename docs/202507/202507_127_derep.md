# 阿里正在悄悄把所有消费业务，收拢成“一个淘宝”
作者：龙哥

阿里最近启动了一场并不高调、却意义深远的组织调整。

随着飞猪、饿了么相继纳入阿里中国电商事业群，阿里旗下与消费者日常生活相关的业务，正在逐步集中到淘宝这一核心平台之中。

换句话说，淘宝不再只是传统意义上的购物入口，而是开始承载更多消费场景：买商品、订餐饮、做旅行，以及其他与生活消费有关的服务，都可能在同一个体系内完成。

更重要的是，这些业务未来不再主要依赖集团层面的协调，而是统一由中国电商事业群负责推进，交由蒋凡直接统筹。过去相对分散的业务板块，正在被纳入同一套经营逻辑和竞争体系。

阿里并没有像以往那样，公开宣布一项声势浩大的战略口号。但从业务归属和组织安排来看，一个可以称为“一个淘宝”的新阶段已经悄然开始。

这与曾经的“One Ford”“One Microsoft”，以及今年吉利提出的“一个吉利”有些相似：当外部竞争环境发生剧烈变化，头部公司往往会重新收拢资源、减少内部割裂，把最核心的品牌和平台重新推到战略中心。

对阿里而言，这次调整的重点，也许不只是业务合并，而是重新回答一个问题：

面对越来越复杂的消费竞争，阿里究竟要以什么作为统一的用户入口和增长核心？

答案正在变得清晰——以淘宝为中心，把更多消费业务连接起来，形成一个更完整、更集中、更具协同能力的“淘宝生态”。
