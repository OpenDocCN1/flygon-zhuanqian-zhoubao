# 准备了一年，高考季七天入账三万+：我的志愿填报实战复盘



我们总是失败，但偶尔会赢 - 尼古拉斯.涛

先做个自我介绍，我是大鱼，赚钱三期老成员。今天想聊的是高考志愿填报这个项目。刚过完旺季，数据已经出来了：一个星期大概有三万多收入。

说实话，这条路走来并不顺。之前我跑过十四趟航海，抖音游戏推广、📕旅游、海外短剧，样样都碰过，样样都没做成。失败才是常态，能活下来就是胜利。

正因为被封号、被禁播练出来了抗打击能力，后来我连着做了三次航海志愿者。和不少搞出成绩的圈友交流后发现一个规律：能稳定变现的，无一例外都是在某个项目上深耕很久、一直扛到爆发的人。

于是我在赚钱里找了个能长期做、每年必复现的赛道：高考志愿咨询。

## 项目为什么能做

每年上千万的考生，背后就是上千万个焦虑的家长。他们对孩子学业上心，却对院校、专业、录取规则几乎一窍不通，最终都得找一个靠谱的高报老师来把关。

这个市场足够大，也足够分散。哪怕是张雪峰这种头部大号，每年能服务的家庭也有限，根本不存在一家吃掉所有需求的情况。留给普通人操作的空间非常足。

## 知识储备是第一道坎

志愿填报本质是重知识的生意。我为此储备了快一年，这不是夸张。

学习渠道很杂，张雪峰的专业解读、包子老师的大明白专业系列、框框老师的课程体系等等，网上随便一搜一大把。甚至去某多多花个一两块钱，就能买到打包好的资料。

口碑是长线生意的基础，知识不扎实，讲错一次就完了。

## 什么时候开始做、怎么引流

理想打法是短视频+直播双轮驱动。我起步晚了点，视频做得少，几乎全靠直播带人。

首批开播其实在去年12月，但那会儿家长的注意力都在提分上，直播间能有二三十人已属不易。白天要上班，只能早上6-7点播一场，晚上8-9点播一场，吭哧吭哧播了一个多月，也就攒了100来个🛰️，效果平平就暂停了。

5月中旬看到同行间人数开始井喷，我又重新开播。话术风格怎么来的？就是先抄后超，多看同行直播，多模仿，多上台，播多了手感自然就出来了。

一个多月下来，节奏和风格都稳定了，抖音最高在线200人，视频号最高在线300人。

6月中到6月底这半个月是爆发期，直接拉来一千多个精准家长。期间抖音封过好几次号，视频号却很稳，因为我们引流目的就是加🛰️，平台判定为正向行为。

引流话术没什么技巧，就是一句“加我领资料”。进群后先发资料包、自我介绍、服务清单，有需求的家长会主动私聊咨询，成交路径非常顺。

## 做完之后的三点教训

第一，错过了流量高峰。6月下旬家长咨询量爆炸，我却还在保持原来的直播频率，白天照样去上班。其实那一周如果能请假全天开播、疯狂加人，收益至少再翻一倍。流量来了就要用盆接着，不能用碗。

第二，一开始不敢谈钱。刚加好友时不好意思收费，家长问啥我就答啥。结果很多人把免费当理所当然，后期在群里提问我没及时回，就被冷嘲热讽，还影响了新人的观感。要学会提前划清付费边界，拒绝白嫖。

第三，低价贱卖时间。一对一的志愿填报本来不便宜，但我第一年做不自信，硬是出了个999的套餐：给数据、给方法、帮过方案。实际操作下来，很多人反复改方案，耗费的时间和一对一差不多了，收入却只有五分之一。后续必须提价，自己的时间值这个价。

## 未来打算

高考填报是个典型的季节性项目，一年就集中在6-7月。淡季发短视频保持热度，旺季开播收割，其他时间完全不耽误本职工作。

给自己定个小目标：每月在赚钱更新一次复盘，积极参加会员日，不再当潜水员。
