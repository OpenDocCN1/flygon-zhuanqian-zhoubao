# 深度使用 AI，再学会编程，你会看到一个全新的世界
作者：龙哥

有一个趋势正在越来越清晰：

未来的人，可能会逐渐分成两种——善于使用 AI 的人，以及还没有开始使用 AI 的人。

而在真正使用 AI 的人群中，还会进一步拉开差距：有人只能把 AI 当作搜索、问答和辅助工具；有人却能借助 AI，把想法直接变成产品。

我自己经历过两次非常明显的能力跃迁。

第一次，是连续深入使用 ChatGPT 两周。那段时间，我发现许多过去长期困扰自己的问题，开始有了清晰的思路和答案。那种感觉就像突然多了一位随时可以交流、分析和启发自己的伙伴，个人能力得到了大幅增强。

第二次，是连续使用 Claude Code 两周。

这次带来的冲击更大。它不只是帮助我解决问题，而是让我能够直接动手，把一个个真实需求做成产品。那种兴奋感、掌控感以及价值释放，是第一次体验的十倍以上，甚至超出了原本的想象。

因此，我非常认真地建议大家做好两件事：

**第一，真正深入地使用 AI；  
第二，开始学习 AI 编程。**

不要只停留在“听说过”“偶尔试试”的阶段。真正的变化，往往来自持续投入和反复实践。

AI 编程确实存在学习门槛，刚开始可能会遇到各种报错、卡点和挫败感。但这并不意味着它遥不可及。只要愿意一点点跨过去，很多过去只能依赖别人完成的事情，今后都可能由你自己做出来。

你可以开发网站、制作工具，也可以把脑海中的需求变成真正能使用的产品。

如果你现在开始行动，三个月之后回头看，很可能会发现：这是今年听到过的最值得执行的一条建议。

评论区里，有人已经开始用 AI 做网站，哪怕此前完全没有编程基础，也取得了不错的成果；有人在学习过程中多次被难题击退，却靠着持续行动重新找回动力；还有人分享说，面对困难时不再逃避，而是选择突破，久而久之，信心和学习能力都会不断增强。

至于 Claude Code 到底能做什么，答案其实很简单：

**凡是你有需求、愿意动手尝试的产品，都可以成为它的应用场景。**

不要被“编程很难”吓住。真正重要的不是一开始就什么都会，而是先迈出第一步，然后在不断解决问题的过程中，逐渐进入这个正在打开的新世界。
