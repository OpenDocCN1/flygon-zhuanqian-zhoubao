# 放弃抢地上的草，方壶把 SPA 做成了长颈鹿
作者：龙哥



一年前，一个做 SPA 的创业者花钱来找我做一次线下咨询。之后他一直用🛰️跟我同步进展。昨天在杭州跟他碰头回访，过去十二个月，他创立的品牌方壶已经在业内有了名气，国内不少头部商业地产都在主动邀请入驻。

究竟发生了什么变化？我当时跟他聊了什么？他又做了哪些实操？

先交代一下前情。我👸号的读者大概知道，我是个按摩的重度使用者，关于按摩、采耳这类话题写过不少。就是看了我一条评测采耳店的短视频，他才找到我。后来他告诉我，那条视频被他反复看了十几遍，字幕都被他抄出来打印了。

说实话，思路并不复杂，只是大多数从业者困在原有模式里太久，没有往外看。

先讲个圈内笑话：长沙最好吃的自助餐不在饭店，在按摩店。因为按摩店卷到连吃都吃得香。

这其实就是种内竞争。生物学上同类之间的厮杀最惨烈。草原上羚羊和羚羊打得最凶，羚羊和长颈鹿根本不抢同一个资源。传统 SPA 就是一群在地上抢草的羚羊，而高处的树叶几乎没人采。

你要做的，不是去抢那把草，而是长成长颈鹿。

过去的按摩店是什么模样？街边大店面，重装修，服务项目堆满，进门一群人喊贵宾，店里昏暗看不清路，沙发电视小吃齐全，主打商务社交。技师还得兼职卖卡。客人多为中年男性，营业到深夜，技师累垮，年轻人尤其是女性基本不来。

这群中年商务客，就是传统按摩店的草。那树上的叶子是谁？是年轻人和女性。

方壶做的选择很简单：放弃草，迎接叶子。做一个不像羚羊的 SPA。

没有前台，推门就是沐足接待区，动线直接进按摩间，空间被压到最小，成本自然下来。按摩房极简，没有电视没有沙发，连装饰都只剩一个插座，因为这里只做一件事：按摩。也没有自助餐，把钱和精力全放在按摩本身。

油品换成植物精油，不再用矿物油。技师不推销、不办卡，客人舒服，技师才能安心做技术。

按摩服务的标准化问题一直是行业痛点，方壶把动作拆解成近三百个标准手式，新人一个月培训就能独立上岗。

连细节的体感都在升级。按摩服的面料和做工很好，很多客人体验完直接想买。服务时间在晚十点就停止不再接待新客，醉酒男性也不接受，让技师有正常的作息和休息。

按摩风格也做了反转。去掉过去那种追求“猪叫”式大力、刮痧出痕的硬派手法，转为以舒缓、放松、恢复为主的柔性服务。装修上也放弃富丽堂皇，整体极简。...还有很多类似的微调。

结果是，方壶开出了一个新物种。

在上海开的三家店里，顾客结构发生了明显改变，90后占比达到一半，复购率高，女性客人尤其多，生意自然水涨船高。
