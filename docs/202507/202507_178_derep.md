# 越来越难得的，是那些持续向上生长的人
作者：龙哥

真正值得珍惜的朋友，不只是陪你吃饭、聊天、热闹的人，而是那些在最近几年里，依然保持思考，甚至不断提升认知与精神状态的人。

因为一个人想要保持清醒、持续进步，并没有想象中那么容易。

生活里有太多力量，会把人拖向松懈和麻木：重复的工作、消耗性的社交、无休止的短视频、随处可见的抱怨与焦虑……时间久了，人很容易停止思考，习惯躺平，把“差不多就行”当成生活常态。

所以，当你发现身边有些人没有被环境同化，没有在忙碌和琐碎中逐渐下沉，反而还在努力学习、主动反思、保持热情，甚至比过去更加清醒和有行动力时，请一定好好珍惜他们。

你看到的，可能只是他们此刻的从容与成长；但你未必知道，他们背后为抵抗那股无形的下坠力量，付出了多少自律、挣扎与心智上的努力。

在一个越来越容易让人疲惫、麻木和随波逐流的环境里，愿意持续向上的人，本身就已经很珍贵。

所以，遇到了这样的人，别轻易错过，也别忘了告诉他们：

“你一直在变好，这件事真的很难得。”

当然，如果你正是那个还在努力向上、坚持思考、没有被生活磨平的人——也请允许我认真地说一句：大家都应该珍惜你。
