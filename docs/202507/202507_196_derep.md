# 被队友“偷偷报名”后，我这个零基础宝妈迎来了意外蜕变
作者：龙哥

大家好，我是龙哥，坐标河南洛阳。在视频制作这件事上，我真的是彻底的“小白”一枚，在此之前连剪辑软件都没怎么碰过。

然而，就在今年4月18日，我那个“先斩后奏”的队友，悄悄替我报了一个学习项目。等到我知道的时候，名额已经锁定了——木已成舟，只好硬着头皮上。你说这是不是一种另类的“绑架”？但也正是这次意想不到的“被安排”，让我一脚踩进了一个全新的世界。

这是我第一次参加航海学习，主题是视频制作。21天的时间里，我从手足无措、不知道怎么下手，到一点点摸索、拆解、模仿、练习，慢慢找到了感觉。过程谈不上轻松，但每一步都算数。我把这段经历里的复盘、思考、小成就和踩过的坑，都认认真真写进了一篇长文里，想更详细了解的伙伴可以直接点开下面的链接：


如果你也是一位带娃的妈妈，或者也是一个什么都还不会的纯小白，希望我的故事能给你一点点力量——有时候，被人推一把，反而能走得更远。感谢那个偷偷报名的队友，也感谢没有放弃的自己。
