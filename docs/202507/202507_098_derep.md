# 每个想成事的人，都要过这一关
作者：龙哥

最近后台总有人问我：“龙哥老师，我刚开始做项目，遇到一堆问题，是不是我不适合干这个？”

我特别理解这种心情——因为到现在为止，我自己做新项目的时候，照样会被各种卡点绊住，照样会感到沮丧。这不是新人的专利，不是经验不够的标签，它是每个在路上的人都会撞上的路障。

区别在于什么？在于你怎么看待它。

有人把挫败当成“我不行的证据”，于是停下来；有人把它当成前行的路牌——哦，这条路还没通，那我换种方式再试试。

多年的经历告诉我：只要你在认真做事，问题就是常态。今天这个卡住了，明天那个出岔子了，没完没了。但这恰恰是好事——因为那些真正做成事的人，不是遇到的困难更少，而是他们默认了一个事实：**挫败不是小插曲，它就是主线剧情的一部分。**

想过关？那就得一次次弯腰、拆解、调整、再来。没有捷径，只有“持续想办法”这四个字。办法也许不是立刻出现，但只要脑子还在转、手还在动，就总有松动的那一天。

评论区有句话我印象深刻：“把手弄脏，把手弄巧，把眼打开，把心放宽。”说得真好。遇到卡点的时候，别急着怀疑自己，先承认——这就是在修炼。刚硬的壁垒，每翻过一个，你的护城河就深一层。

还有一个很实用的建议：卡住的时候，别一个人硬扛。拉几个人建个小群，大家一起碰一碰，也许别人一句话就点醒了你——你以为的绝境，在别人那儿可能早就趟过了。

所以，如果你现在正卡在原地，别慌。深呼吸，睡个好觉，明天继续想。只要你不把挫败当成终点，它就永远只是一段必经的上坡路。
