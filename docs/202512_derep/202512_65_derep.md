# (精华帖)(61 赞)普通人做 IP 的踩坑经历：从职场焦虑到年入 30 万的实战路径

**从职场焦虑到年入30万：一个普通人的IP踩坑实录**

我是咏舒，做了15年设计师，也是龙哥盟5年的老圈友。收到约稿时，我像给自己做了一次深度的三年总结。回头看看，很多问题都看清了，未来的路也清晰了不少。

2020年，我还在公司上班，对未来的职业发展充满了不安。也就是在那一年，龙哥盟给我推开了一扇全新的门。2022年，裁员的大潮袭来，我没有犹豫，直接转进了知识付费的赛道。可是起步真的很难：开直播，直播间里空无一人；做产品，9块9的课也卖不动。后来我咬牙花了8万块，系统学习个人品牌打造的底层逻辑，同时学会借助圈子的力量，慢慢把年收入做到了30万。

这三年，流量、产品、销售、交付，每一个环节的坑我几乎都踩了个遍。但也正是这些踩坑经历，让我彻底摸清了一个小个体IP到底该怎么成长。

今天把这段经历和心得完整分享出来，希望能给正在这条路上摸索的朋友一些参考。
