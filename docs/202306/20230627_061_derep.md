# 短剧CPS这门生意，到底值不值得做？我把其中的门道和雷区都捋了一遍

最近大半年，我身边不少做内容、搞流量的朋友，都开始把目光投向付费短剧。说实话，这个赛道确实热得发烫。我自己也为了摸清门道，前前后后充值了好几百块，把各类热播短剧刷了个遍。

平心而论，这东西确实上头。每集只有一两分钟，一部剧看完差不多就是一部电影的时长，但节奏飞快、反转密集，特别适合现在大家碎片化的空闲时间。而这些短剧的底子，基本都来自那些爆款网文。穿越、赘婿、逆袭这类题材占了绝大多数，故事框架也都大差不差：一个现代人意外穿越到古代，被家里人各种刁难，然后靠着现代知识碾压全场，最后功成名就、抱得美人归。

再说说这背后的生意盘子。据我了解，现在付费短剧每月的用户充值规模大概在15亿左右，未来冲到30亿一个月也不是没可能，这么算下来，一年就是300亿以上的体量。可能光说数字大家没概念，2022年全国电影总票房也才204亿，也就是说，短剧市场的“吸金能力”很快就要超过大银幕了。更吸引人的是，它的分销佣金给得极高，普遍能做到50%到80%，而且没有退货、售后这些麻烦事，比起传统的电商带货，看起来确实香多了。

短剧的观看场景主要分两类：一类是抖音投放，把人导到抖音小程序里看；另一类是引流到🛰️小程序。推广的玩法也差不多，都是靠剪辑那些最勾人的片段——往往还有点擦边，比如男女主角暧昧的戏码——做成短视频投出去，用户能免费看十几集，后面就得付费解锁了。抖快这类平台上的短剧一般比较短，12到24集，每集三五分钟；小程序端的通常是一百集左右，每集一两分钟。

从我自己的体验来说，🛰️小程序的转化链路有点吃亏，只要你切出去回个消息，入口就找不到了，用户很容易就丢了。虽然理论上还能通过历史小程序翻回来，但绝大多数人没那个耐心。

至于具体的赚钱方式，说白了就是做“二创分发”。你加入一个分销平台，拿到授权素材，自己重新剪辑成引流视频，发在抖音账号上，挂上剧场的链接。只要有人通过你的视频点进去充值，你就能拿一半甚至八成的佣金。这个模式几乎零成本，不需要投钱，靠的自然流量，会剪辑就能干。做得好的个人达人，一个月能挣六七万，头部玩家能做到二十多万。

我三月份去拜访过一家做切片业务的公司，他们跟我讲了个真实案例：宁波一个在物业公司做行政的姑娘，平时就爱看爽剧，顺手剪了条推广视频，一晚上就赚了六千多佣金。可见对会剪辑的人来说，短剧分销确实是那种投入小、回报高的路子。

其实短剧这行从去年下半年就开始萌芽了。最早版权方拍完剧，主要靠👸号裂变和买量，但ROI很低，一直没做起来。转折点在去年九十月份，抖音星图官方下场，把版权方和达人撮合到一起，用竞价投放的方式，规模一下子就起来了。

当时星图那边的内容消费运营负责人分享过，这波能火起来，核心是三方面：第一，短剧太缺流量，但平台上影视类达人号一大把，两边的需求正好能对上；第二，版权方跟达人合作是按CPS结算的，对他们来说这笔投入亏不了，回本周期也短，所以舍得砸钱；第三，现阶段每天在星图的投放量级已经有五千万，但整体利润只有10%左右，大家其实都在跑马圈地抢市场。

接着聊聊产业链上的角色和机会。

最上游是版权制作方，像九州这种公司，就是从番茄、晋江、起点这些网站买小说版权，再翻拍成短剧。眼下拍一部剧的成本大概30万，早时候10万就能搞定，但现在入局的人多了，竞争激烈，光剧本就从几千块涨到了两三万。而且没人能保证哪部剧能火，版权方只能玩“广撒网”，同时开拍好几部，再拿出去投流测试，跑出数据了再加码。头部的公司一个月能产出30部剧。

这个行业目前是典型的爆款逻辑，一九分化严重——十个剧里能爆一个就算不错。抖音上10%的短剧消耗了90%的投放预算，越是低成本越难出爆款。

版权方拍完剧后，通常先自己投放一波，等跑不动了才放出来给外部渠道分销。有的会走星图竞价，达人接单推广；也有一批外部中间商，搭个小程序，从版权方拿授权，再招剪辑达人来做分销，本质上和当年淘客体系里的淘宝联盟差不多：左手搞定货源，右手招募渠道，从中抽成赚差价。比如上游给80%佣金，他们给下游60%，自己留20个点。

但对普通达人来说，找外部平台合作有个隐患，这个后面说。

再说下游分销达人这一端。现在星图其实挺缺达人的，官方也在拉更多人进场。但达人之间的收益差距非常极端，大概10%的人拿走了90%的钱。多数中小达人其实是陪跑，发了不少视频，收入寥寥。

从数据看，每千次播放大概能带来一块钱的佣金，跟粉丝量没直接关系。也就是说，有个1000播放就有1块，1000万播放就是1万块。头部达人能跑到上亿播放，单条视频收益十万以上，但同时也能涨粉涨得飞快。

如果想当剪辑达人入局，最关键的能力是“选剧”——你得能判断哪部剧有爆相。选错了，视频再努力也没流量。另外还要注意选新剧还是老剧。老剧被剪过太多次，很容易触发抖音的查重机制，直接限流。

如果问整条链路上最赚的是谁，那还得是上游版权方。但门槛也高——一部剧30万，十部就是300万，还没算投放预算。这基本是有资金实力的公司才能玩的游戏。

不过随着入局者变多，纯投放模式会越来越难，版权方也会更愿意走CPS分销。这时候，做中间分发平台对中小创业者来说倒是个不错的位置。投入不大，关键是把系统搭好，上能拿剧，下能招人，赚的就是佣金差。

但这种中间商最大的难题，是拿到好剧，最好是独家。否则下游达人肯定挑佣金高的平台走，你的利润会被不断压缩。想留住人，要么佣金有竞争力，要么你有别的粘性，比如给达人做培训、提供更多素材供给。

对于个体户或者自由职业者，还是老老实实做终端分发者更稳。成本低、收入上限高，难点在于怎么搞到更多账号，做出能拿到自然流量的切片内容。

最后聊几个坑，都是我跟业内朋友交流出来的心得，不一定全对，大家做个参考。

第一个坑：资金不够厚、投放能力不够强的公司，千万别碰上游版权。看着有门槛、收益高，但很可能投进去几百万连水花都看不到，最后巨亏。

第二个坑：中间分发平台，千万别搞多级分销。短剧跟电商导购不一样，电商是人人都会买东西，靠庞大的自购人群都能撑起GMV，所以多级分销能把盘子做大。但短剧不是人人都会消费的内容，真正能出业绩的永远只有那10%的达人。如果你搞多级分销，佣金被层层分走，终端达人拿不到足够多的钱，做得好的那批人迟早会跑，跑去佣金更高、层级更简单的平台。这个模型里，“拉人头”的团队长价值其实很低，但还在抽血，长期看反而削弱平台的竞争力。

我也见过一些中间公司自己养一大堆剪辑账号，招全职员工做切片。说实话，ROI大概率不高。短剧切片特别考验网感，公司里拿固定工资的人，跟外面靠这个吃饭的兼职达人比起来，爆发力差太远了。这就好比“家猪”和“野猪”的区别。所以与其自己养人，不如多去外部招募分销者。

第三个坑，对终端达人来说，选对合作平台真的太重要了。短剧分销不存在给用户返利，所以后台数据非常不透明，很容易被上游扣量。你明明带来了100万的充值，最后结算告诉你只有60万，你连反驳的依据都没有——人家说多少就是多少。这中间，版权方可能扣一点，中间平台可能扣一点。

不过好消息是，抖音星图给的佣金很高，而且基本不扣量，对达人们来说肯定是更有吸引力的选择。

所以未来短剧中间分发平台的出路，我觉得很可能在“多任务分发”上——把切片当成一种获取流量的手段，除了短剧，还能接IP带货切片、小说推广、游戏分发等等。做成一个综合性的切片分发平台，差异化反而能走出来。

最后送大家一句话：风口确实在，但别一头扎进去不看路。适合你的位置，才是好位置。
