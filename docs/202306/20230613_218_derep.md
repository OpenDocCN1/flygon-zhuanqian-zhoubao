# 带货短视频-文案如何创作？素材活用，改编成自己的带货文案——之人民日报， 看完学会举一反三！

大家好，我是龙哥，专注教辅赛道短视频带货。上次那篇《从“抄”到“超”》入选精华之后，不少圈友私信催更，问我带货文案还能怎么拆。正好今天刚做完一条视频，我决定把改编过程完整记录下来，手把手带大家实操一遍。

![](img/9166f7d9ca19fc15502738d5fcbac7ce.png)

先说背景：我刷到一条快手爆款，视频主题是“2023中考加油”“中考押题卷”，播放量已经冲破110.2万。这条视频的文案逻辑不复杂——借人民日报对中考作文的总结，抛出六大可能考的方向，瞬间抓住考生和家长的注意力。我那时正好在带《人民日报教你写好文章》这本书，于是决定把这套思路移植过来，做成自己的带货视频。

它文案里抛出的六大方向包括：传统文化、科技创新、人间大爱（尤其母爱和爱国）、绿水青山、时代英雄、青春奋斗。

但直接照搬行不通，因为原视频的产品和我的书未必匹配，而且部分词还容易卡审核。所以，关键一步是拆书。

![](img/9af6d41bc9ce80bd17eb8996d2c81032.png)

什么是拆书？一句话：把书中的精华提炼出来，再用简单、有逻辑的方式转述给听众，让所有人都能一听就懂。放在带货文案里，拆书就是帮你快速找到“卖点骨架”。具体怎么拆？别一上来就全文通读，先翻目录，目录往往就是现成的文案大纲。

![](img/a064fb48d17c829813aea70bdf2d9e9d.png)

![](img/cb265850d4743fb6427dcbfdbb0d3fe7.png)

我翻完《人民日报教你写好文章》的目录后，从里面挑了六个和中考关联度高、又不容易踩雷的方向，替换成：文化传承、科技前沿、故土情深、美食文化、大爱真情、青春之歌。这里提醒一句，挑选时尽量避开“乡村振兴”“绿水青山”这类敏感词，不然投流审核很麻烦。

方向确定后，再补上产品介绍和催单理由：这本书背后的人民日报，一直是中高考作文圈的风向标，书里把范文和素材都准备齐全了，从现在到考前，每天背上一两篇，上考场绝对用得上。作文想拿分，核心就是素材积累；其他科目临时恶补可能来不及，现在最该做的就是稳住心态，把该背的范文一篇篇吃透。祝所有考生金榜题名！

文案成型后，直接对着镜头录出来就能发布。有圈友问过：不真人出镜行不行？我的答案是：出镜转化率确实更高，跑千川也不容易被掐。

![](img/594b3b097f042562ec29d29cadd7f37b.png)

痛点疑问放开头，
卖点展示跟上咯。
逐一详解很上头，
点击下单好理由。
