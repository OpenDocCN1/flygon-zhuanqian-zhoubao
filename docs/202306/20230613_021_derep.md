# 环境从不温柔，我们也不必做娇弱的花朵

生活中流传着一句看似很有道理的话：“选择大于努力”。于是很多人被这句话绊住了脚步，一直在寻找“正确”的路上徘徊，仿佛选对了方向，不费力气就能收割成果。

为什么我们一见到别人晒战绩、晒收益，就忍不住想冲上去“链接”一番，好像下一秒就能复制暴富传奇？说穿了，是人性在作祟——趋易避难，又急功近利。九成以上的人都在做着一夜发财的梦，所以这种反应并不稀奇，也不必自责。关键在于，我们要学会让理智回笼。

不能一边吐槽“镰刀太多”，一边又嫌自己参与的航海项目进展太慢。扪心自问，是不是太心急了？

生财从来不是温室，我们也不该是那些需要被精心呵护、不经风雨的花朵。那句话怎么说来着——生财是我家，环境靠大家。

有些人的代入感实在太强，一看到“别人能做成”就觉得“换我也行”。想起前几天刷小红书，刷到一篇关于“素人起号并非天方夜谭”的分享，博主讲得确实不错，我便好奇点开了她的主页，一看不得了——人家是某世界五百强的总监。

很多人看到“素人”两个字就兴奋了：我也是素人啊！那我肯定也行啊！但想得太简单了。博主确实是素人，不是明星也不是公众人物——这话没毛病。我们也是素人，但素人和素人之间的差距，可能从地面到天顶，岂能画上简单的等号？

我有个不算好的习惯，就是八卦：喜欢去百度百科翻名人的履历，研究他们背后的家庭背景、成名前的经历，看看他们到底是遇了贵人，还是从小环境熏陶得好。

那位五百强总监，能把一个部门带好，我相信把她放到其他赛道也大概率不会输。因为那叫“成事的能力”——一种底层能力，她早已拿在手里。我们要做的是照照镜子，问问自己：过往的这些年，我做成过几件事？如果答案不太理想，那就意味着我们要拿出更多的时间和代价去补课。别人用一个月、一年才能做出来的成绩，你也许需要两个月，甚至两年。这个心理建设，必须提早做好。

我不是来泼冷水的，恰恰相反，我是希望你看清楚所有真相之后，再去对抗曾经打败你的焦虑。少一点对自己不合时宜的期待，多一点对自己的约束和要求。

类似的场景，在小红书里随处可见。比如，你会刷到无数标题写着“宝妈通过 xx 项目月入过万”。第一反应是不是：宝妈都可以？我不会比宝妈差吧？

但请别忘了，宝妈可不是“只会带娃、啥也不会”的代名词。世界五百强里有宝妈，金融圈里有宝妈，学校里有宝妈，普通小公司里也有一抓一大把的宝妈。她们的时间管理、抗压能力和人生阅历，或许比你想象中强大得多。

去年我一度被短视频里的某个“独立带娃离异妈妈月入十几万”的故事激励到了。确实热血沸腾，仔细一看人家也的确有两把刷子，是个精明干练的女强人。我自问能力相距甚远，并没有天真地觉得“她行我也行”。我们太容易只看见别人头顶的光环，而忽略光环下面那些支撑它的细节。当然，也会有人说：那我目标不高，不求月入十万，只要能赚个几千块零花钱也行。

如果你真有这样的想法，恭喜你，大概率能做成事儿。我想，这也是生财让新手去参与航海的原因所在——躬身入局，把手弄脏，先跑通一个最小的项目、赚到第一块钱。

这次我参加航海就明显感知到，人和人的差异从来不只印在成绩单上。翻翻那些优秀学员的日志和高手的分享，人家做项目前画的思维导图、准备的各种模型表格，专业程度堪称小型创业公司。而我呢？里面好多航海工具，听都没听过。但我并不焦虑——知道了一个小红书笔记下载工具，我就觉得自己开了眼界；学会用它，对我来说已经算进步。没发笔记的日子我不会自责，笔记数据不好也不必怀疑自己。接受不完美的自己，才有可能变得比昨天更好。

科比有句话我很喜欢：“总是有人要赢的，那为什么不能是我呢？”只是我们都清楚，这句话背后是他日复一日挥洒汗水、凌晨四点开始训练的故事。能看见前方路途的坎坷真相，却依然选择出发——那样的勇气，才配叫“真正的勇敢”。
