# 新手怎么避开智商税，不被反复割韭菜？

最近在二手书航海项目里做答疑，我发现一个挺有意思的现象：很多问题手册里白纸黑字写得清楚，可就是有人不翻，张嘴就问。这让我忽然想聊聊“韭菜”。

“韭菜”最早是个金融词，泛指那些被“专家”忽悠去买股票、买理财，亏了钱还不长记性的普通散户。放到做项目、搞副业的圈子里，就成了另一类人：学费交了不少，课囤了一堆，最后啥也没学到，白白被收割。

为什么总有人被割？我最大的感触是：很多人连最基本的阅读能力都没有。买东西不看说明书，拿到新东西就等人喂。除此之外还有几个常见特征：出了问题就怪环境、怪平台、怪老师，反正不是自己的错；时间都花在刷视频、打游戏、追八卦上，从不坐下来读点书；不想吃苦，只想要偏门捷径，买彩票、赌博、考证、囤课——课通常只看前两集；最可怕的，是救世主思维。被割了就要求平台为小白兜底，甚至让项目方交保证金来“保护”自己。

说实话，这种帖子我见过，看完挺无奈。辨别信息和筛选方向，是一个人修一辈子都修不完的功课。做选择题永远比单纯解题重要：小到睡前看书还是刷手机，大到去哪个城市、进什么行业、选什么人同行，都是选择。每一个选择，最后买单的人只有自己。别人可以帮你，但别把“靠别人”当第一反应。能稳稳托住你的，只有你自己。

韭菜的宿命，通常从一句话开始：“0基础宝妈，一台手机，轻松月入过万”。这几个词没有一个符合常识，可偏偏能勾出人心里那点贪念和懒意。人性的七宗罪，市场里都备着；而最容易让人变成韭菜的，就是懒惰加贪婪。这也是为什么总有人觉得：自己一交钱进场，行情就跌。其实不是市场故意针对你，而是你带着短期暴富的预期，自然对波动格外敏感。

怎么摆脱？说白了就靠两种能力：学习钻研的能力，和解决问题的能力。

先说学习。入局前，把项目研究透：分析市场，看看别人成功和失败的真实案例，列出所有可能的卡点，想清楚能不能解决、代价多大。等真决定下场了，就放下杂念去做，小步快跑，跑通一个闭环，再复盘、再修正。顺序也很重要：先研究再行动，和先行动再研究，结果天差地别。有人连航海手册都没读三遍，没有资质就去上架，不看禁售书单就开卖，一天内给自己搞出一串违规。没资质怎么办？等时机，把该办的办了。“答案太简单”反而没人信。

再说解决问题。被割以后，找平台、骂镰刀确实解气，但这种解释除了让你当时舒服一点，后面只会让你越来越怨，甚至看到机会先想到风险。你该做的，是向自己要一个解释：这个坑为什么踩？哪一步判断错了？能让你下一步做出正确选择的那种解释，才是好解释。

然后就是积累实力。缺乏耐心并不可怕，可怕的是你根本没有“输得起”的底气。如果注定要交的那点学费，只占你资源的一小部分，你还会焦虑吗？所以年轻时，少把钱花在纯消费上，多花在提升自己上。最好的投资，永远是自己。

还要警惕两件事：一是富贵险中求。这个时代信息渠道很多，想验证一件事并不难，别总拿命运去赌。尤其是学生，不要借钱去冒险。人一旦缺钱，目光就会变短，任何“快速回本”的标题都能把你钓走。二是高回报陷阱。有人借你100，第二天还110；另一个人借你100，第二天还200。排除所有关系因素，你会借给谁？我肯定不借第二个，因为这太像赌徒了。可很多人选项目时，偏偏喜欢低投入高回报、今天交钱明天回本。这种项目，十个里有九个是镰刀。

把时间线拉长一点，焦虑就会小很多。别总跟别人比，跟自己比就行。也别老想着“先拥有一切，再开始行动”；正确的顺序是“先行动，后拥有”。小孩学走路时，不会研究先迈左脚还是右脚，也不会拿自己和邻居家孩子比较。他直接走，走着走着，就会了。

还得说说贪和懒。“贪”拆开就是“今贝”，当下就想得到，付出一分就想收获十分。市面上所有智商税，都是给又贪又懒的人准备的：三天玩转抖音、五天短视频带货过万，听着荒唐，却总有人信。懒的本质，不是身体不行，而是大脑先摆烂了。大脑是人体的耗能大户，它不积极运转、不创造价值，其他器官就会觉得吃亏，于是集体罢工。那些每天只睡几个小时还精力旺盛的人，不是天赋异禀，而是大脑被调动了起来，整个身体都跟着创造价值。

但大脑也有自己的毛病：它特别爱走熟悉的路。越熟悉越省力，越省力它越喜欢，这就是舒适区难逃的原因。甚至有人说，人类文明史其实就是一部懒惰史。所以别用意志力硬扛懒惰，你扛不过大脑。更好的办法，是找一个能和现实利益接轨的领域，让大脑自己算出“值得做”。一旦大脑主动思考、主动创造价值，人自然就勤快了。

韭菜的进化，大概分三步：先听大多数人的话，再参考少数人的意见，最后自己拍板。刚开始你什么都要问，报了很多班，加了很多群，慢慢你会发现，大多数声音都是车轱辘话，说来说去没新意。甚至有个规律：当某个行业的高手开始大规模讲课卖课时，这行业往往已经在走下坡了。所以新手也不用到处求神拜佛，好的航海手册已经把该讲的讲完了，甚至够你录成一套比很多收费课都实在的视频课。随着踩坑越来越多，你渐渐能分清谁是真大佬、谁是镰刀。等到你自己做成过一些事，积累起判断力，你未必知道什么一定能做，但什么不能做，你心里会很清楚。

走到这一步，你基本已经从韭菜堆里爬出来了。这条路越往上越孤独，因为想把任何事做到极致，都得学会独处。不要让这份孤独变成焦虑，它是你进化的陪跑者。

最后想说：错过有时候不是遗憾，可能是躲过一劫。别贪心，你不可能什么都拥有；也别灰心，你不可能什么都没有。听人讲话就像啃甘蔗，一多半可能是废话，但只要有一点点营养能长成你自己的肉，就值了。

愿每个新手，都能少交点智商税，早点从韭菜变成农夫。
