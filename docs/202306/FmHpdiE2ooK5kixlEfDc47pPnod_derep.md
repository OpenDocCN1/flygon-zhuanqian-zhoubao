# 十九岁，手里握着第一桶金



十九与百万放在一起本该格格不入，却真实地落在了我身上。你好，我是高尚坏孩，十九岁，双非大二在读。

童年里我普普通通，学校里爱出风头交朋友，家里帮父母守摊。小学三年级就常去网吧，十八岁能名正言顺刷身份证上网，曾是我很长一段时间的梦想。就是这么个丢进人群里没人会多看两眼的普通人，一年半时间拿下人生首个百万，现在账上还有五十万可动用资金。写这篇，不是炫耀，是想把从街头小摊到互联网的突围讲清楚。

### 起点：长沙街区的小门面

2003年12月出生在湖南四线小城，一岁后随父母到长沙落脚。爸妈在百货市场租了间门面，正是招牌歪斜、地面凌乱、炒菜声与招揽声混在一起的市井摊位。初中前，我的世界就是这一条街。![](img/086f722c97cce8d5405cebae4bee7a8f.png)

父母是地道的小商贩，连家长会都尽量回避，常挂在嘴边的是“好好念书，以后进办公室”。正是他们让我第一次看懂生意经：原木砧板不掉屑不开叉，顾客嫌价高时怎样夸块料；顾客起身要走时又追到门口说“算了算了，收摊生意，亏一点给你”。每一步操作，我都从小看进心里。

### 童年的“赚钱”记忆

小学二年级迷上穿越火线，当时进不了网吧，只能投币机，一块钱玩二十分钟。偷偷从收银抽屉拿几块钱，第二天就有上网费。三年级被带进网吧玩英雄联盟，为了省路费往返都打摩的。那段时间拿出来的数额比以前大很多，我对“想要的东西得自己想办法”的理解就来自这些不体面的经历。

### 青春期的落差

小升初后，我说想去A校，那是一所以混子著称的学校，因为就读的小学是长沙最差的几所之一。父亲却执意报了B校，长沙前五的中学，共八个名额，报名十七人，我挤了进去。

进校第一眼的落差很刺眼：同学脚上阿迪耐克，手腕卡西欧，我穿的是五十块量脚定制的土皮鞋，还带魔术贴。三年里自卑与虚荣反复撕扯。父亲开面包车来接我，我假装在教室；穿了一年特步七波辉后，同样价位我换成莆田阿迪。喜欢过几个女生，她们明媚的模样让我早早明白富养的含义，自己却觉得配不上。

暑假预科班，同桌父亲是小学校长，课间刷苹果手机看英文搞笑视频，手里还有任天堂游戏机。我用尽力气才求来的vivo X5放在他面前总显得黯淡。英语课上人家游刃有余，我连基础都不稳。

初三成绩下滑，想拼一把，主动要求父母送我去校外机构补课。一节四百六十元，父母一次交了五万多，只上周末。课堂上看到全日制学生一天六节课，我忽然意识到父母赚钱有多不容易，也更清楚自己的无力。那个阶段发的朋友圈，我自己都分不清真假。![](img/c968d8f896b5f9f89d6c396c150e239f.png)

### 职高的转向

中考失常，我进了当地职高，对口高考班。虚荣放下后开始真正读书。三年沉闷，却是黄金期。爱上写诗没什么功底，堆砌华丽辞藻，却填满了内心空洞。读诗读散文后，自律感慢慢回来，一个点被点亮，线与面随之铺开。

高中养成了记录习惯，抖音段子、歌词、小说大纲、创业灵感，记了满满几大本。那段时间的文字现在看很青涩，却是思想的痕迹。

高二做代刷网，卖🐧群机器人授权与刷赞服务。防沉迷上线后，很多人无法游戏。我花三十八元学到一个小漏洞，以五十八到一百八十八的价格帮三四十人解除限制。这是第一次凑齐四位数，虽然截图已删。![](img/4fc7f7a2af4809a70d5e79a1dea6839e.png)

同年同学小李带我接触樊登读书会，之后一年我基本听完2013到2020年的内容。盗版，抱歉。影响最大的是《终身学习》和《百岁人生》，至今思想松动时还会翻出来。![](img/ce9c8b03491e57c14374ad0e38b80255.png)![](img/911d8e13a354ddeba79f6ca04a28088b.png)
当时还拍过一些翻书照片，偏爱带故事性的内容。![](img/923734568244bf1ee5ba94cf443bdddd.png)

### 大学前的摸索

高考进了所二本，规则感更强。毕业暑假没去考驾照，在家研究抖音。先拍搞笑短片，观众不买账；再做观点号，画质差形象糟观点偏暗，最终封号。三个月一无所获，整整高中积累的素材在平台上全失效，自尊被按在地上。![](img/c01a97d93eda6da5344c6ddc7d0eefd4.png)

理想主义养不活人。刷到“白嫖的知识”账号，画面简陋内容搬运无需真人出镜，我立刻跟进。前十几个作品数据惨淡，差点放弃时一个视频冲到九万播放，之后作品基本稳定在五千起步。听小说剪辑成为常态，直到某条二十分钟剪辑的视频接近六百万播放。

六百万人，我十辈子也接触不到。二十分钟的剪辑换来六百万人停留半分钟，让我确信互联网值得长期深耕。主页留下联系方式，开设培训，收费一百八十八到三百八十八，招到几十位学员，流量被迅速利用。

### 贵人与起伏

学员中有一位提问极勤，不问剪法，而是摸整套打法。我曾以为是同行，后来得知他是旅游服装连锁品牌森萃的老板，身家千万以上。疫情让门店亏损，婚姻也出现问题，带着两个孩子想在网上再创业。我们线下彻夜长谈，第一次坐宝马。他提供了许多方向，后来合作：他批量起号，我在校招剪辑师，组建二十人团队，每月带来约一万元利润。![](img/c2cdd49168ae53557593777711d0de64.png)

剪辑项目因缺乏持续盈利点且同行卷入而中断。随后我转做拼多多与淘宝代设计小人头像，静态六十元，动态一百八十元。起初在拼多多找外包，后来对方嫌单价低不合作。![](img/8f3a1ec412c3df694f619213a9f53f1d.png)于是从学校招设计学院学姐，单图付十五到二十，自己赚差价。二十一年开学后月入接近两万，也是身材管理最好的一段时期。![](img/fd4c22456cb7df305b9f9a46fb82a832.png)

随后尝试无货源玩具店，深切体会到“仅退款”的威力。坚持两个月关店，期间设计的业务被忽略，投流不会，同行抢客，收入归零。整夜失眠反复问自己拼多多到底是谁在赚钱。轴劲让我没换平台，终于想通：退款必然亏损，能否卖一种退款也不亏的品类？答案是肯定的。

### 首个百万的来源

于是押上全部精力做拼多多虚拟电商。从一家店起步，单日峰值破两千，后期九家店日均一千到两千。人生第一个一百万就这样累积。玩法大佬们分享很多，我不再赘述。

二三年六月二日，我主动关停该项目。九家店里五家因导流被限制，需手写保证书并将保证金从一千涨至五万一，若继续就要补缴二十五万；淘宝实验店也接到售假违规通知。虚拟的版权与售假问题始终是最大暗雷，最终选择止损。![](img/8c49bbdd222f9d24fd3bb8d3fcffc3b5.png)

### 当下与未来

很累，但工作室伙伴说得好：只要每条回复都可能促成成交，谁都愿意忙。生活的不确定性才是生活的本质。📕无货源做了一个月没出单，我深知稳定来自上班，而圈内人默认不甘落后。我不到二十岁，为何要给自己的人生提前盖棺？网上流传“赚钱重要还是旅游重要”。![](img/03b9f26bb3f64f7e7594f40e3d7c0899.png)![](img/3bc4b83ccadc47c4850923ed39d1f138.png)![](img/36d202f70f3f6ac2cb134d0ebc4cc5ac.png)我的答案是先赚钱再旅游。大学两年，同龄人还在纠结感情与考试，我已去过二十座城市，每座都停留一天以上。

目前工作室主攻📕电商，师从行医老师。但抖音个人IP始终放不下，去年中旬重启过，也交过学费，因忙碌没坚持。现在时间宽松，想再探一次。

### 十九岁的七点自白

一、感恩。把帮助过自己的人记在心里，因果与缘分我都信。那位贵人现正筹备餐饮品牌，几十年商场沉淀不是我能比，只能持续提升，总有一天能回报。

二、先把一个侧面做到位。迷茫时别让情绪抢舵。挑一个方向先点亮，线与面自然延展。健身也好读书也好，先动起来飞轮才会转。

三、不被世俗条框绑住。法律是底线，其余的眼光与规矩可以绕。高考前迟到要罚抄手册，复习时间宝贵。我会顺手拎垃圾桶盖假装刚倒完垃圾回教室，或说“老师让我去取练习册”，顺利进门。清楚规矩的代价后，学会破局是生存技能。

四、反思与记录。我建了星球每日复盘，得失写下来防止迷路。

五、别把自己逼到极限。项目倒闭后我每天刷圈焦虑不敢停，回头一想，连我这种有点成绩的人都慌，何况还在校的同学或背负房贷车贷的人。要学会抬头看看走过的路，允许喘息。大器晚成也是一种成功。

六、懂得“乱”花钱。王者的日活上亿，是社交也是展示面。我氪了三万多到贵族十，累时开一局，皮肤任选队友刷大佬。算过账，一万局约等于四百一十六个工作日，时间成本极高，所以先确保不缺钱再消费。

七、成果要敢于展示。炫耀不是消费主义，是对努力的尊重，也能让更多普通人看到一条可行的路径。

写到这里想说，别给自己下定义，也别轻易认命。十九岁挣到一百万不是天才，只是始终不肯服输。路上既有偷钱的黑历史，也有赔钱睡不着的狼狈，但这些都不妨碍继续向前。慢一点没关系，别停。

很多人骨子里还活在“财不外露”的老思维里，我的看法恰恰相反——在当下的互联网环境里，赚到钱就应该敢于露出来。

微商晒奥迪，晒着晒着真开上了布加迪；讲师公开变现，晒着晒着报名的学员就滚雪球一样变多。炫耀并不是虚荣，它本身就能帮你破局。

炫耀带来的第二层价值，是源源不断的正向回路。我第一次尝到钱的滋味时，并没有想过日后会赚更多，只是发现穿得体面一点，整个人会更挺拔。大一那会儿就开始买名牌，后来钱花完了，反而更焦虑，这份焦虑把我推着往前找路、找方法。要是赚了钱一分不花，感受不到那种被反馈滋养的快乐，很快就会松懈下来。

**8. 学会为知识付费**

这一点我最有体感。大部分人花钱买吃买穿没问题，唯独到了要为服务、为知识买单时就开始抗拒，这本身就不合理。白嫖来的东西不叫知识，那只是资料。只要一听要交学费，就觉得对方是来割自己韭菜的，这种思维里根本装不下双赢，更容易滑向盗版和投机。

**9. 学会为别人省时间**

具体表现就是别再发一个“在吗？”就杵在那。做电商也好做私域也好，这两个字是我最不想看到的开头。真想沟通，先把问题说清楚，把需求摆明白。这个时代时间就是钱，你无缘无故占着别人的时间，不说是谋财害命是什么？

暂时就梳理到这里，后续我会继续补充。

最后解释下为什么叫“高尚坏孩”。字面意思很直白：做大事的底线要高尚，但方法论上要敢于撕开世俗的规矩，敢于做那个打破规则的“坏孩子”。
