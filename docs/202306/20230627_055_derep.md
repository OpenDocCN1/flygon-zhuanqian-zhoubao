# 17分钟进账5600块，那个曾经亏掉20万的大学生，终于想通了一件事

大家好，我是老刘，一个在读大二的学生。因为名字和“铁道游击队队长”同音，朋友都叫我队长。最近搞网赚总算搞出了一点名堂，也得到圈内不少老哥的认可。扛不住大家的怂恿，我决定开个👸号，把这两年踩过的坑、流过的泪、赚过的钱，都掏心窝子讲给你听。

回过头看，那些让我差点崩溃的弯路，其实都成了后来的台阶。从最高月入10万，到单场17分钟进账5600，我越来越确信：只要咬着牙不松口，低谷也会翻篇。也许你现在经历的光景，就是我曾经的至暗时刻——但愿我的故事，能给你一点温度。

![](img/4179b7dc286edf0575700a56e9adb678.png)

2021年暑假，我第一次听说“网赚”这个词。在知乎刷到一位学长的文章后，我激动得加🛰️、转账，一气呵成。我虽然是个小白，但花钱买经验从不心疼。第一个项目是拼多多虚拟商品，我连4.1万的保证金都准备好了，结果平台突然严打版权，项目直接作废。半个月后，我又报了快手小游戏。一开始心气很高，做一个月就想放弃；看到群里别人晒收益，我又逼自己再撑一个月，还是没水花。最后我才明白，那会儿压根没把心思放在上面。

![](img/e6e8411d4f7ea7099ddb9dcdb1e18f72.png)

做小游戏期间，我顺手把中学时的校服挂到了闲鱼。长沙冬天挺冷，学校一件冬季校服就要320块，全套下来两千左右，我那些二手校服意外好卖。没几天，夏季和春秋装全卖完了，冬装也在天气转凉后被拍走。

![](img/526a72b60c1e3dbe2f556d47b6a8ac32.png)

再后来，有陌生人私信我，让我帮忙销盗版护肤品。我照着别人的文案和图片稍微改改就发，一个月能落袋三四千。但这种钱终究不干净，号很快被举报，平台也在清剿盗版。我换了几个新号，没两天又被封了个干净。

![](img/2bc3d103a2318de9dfd8f83b8db7534a.png)

闲鱼之外，我还买过一个6000多粉丝的抖音书单号。当时单纯地觉得，有粉丝就能变现，结果买回来一单都卖不出。后来又有骗子撺掇我发广告文案，10块钱一条，一天三四条。干了快一个月，号因为涉嫌医疗美容违规被封，连我自己的实名都卡住了。从2021年10月起，我才知道互联网还有“违规封号”这回事，也再不敢去贪那些快钱。

倒是那颗想搞钱的心，一点没凉。我花时间研究了一圈新方向，转头冲进抖音赛道。二话不说，入手几台手机，备好一批电话卡，准备大干一场。

![](img/a18b920c5d90b5e8329fb5de4280168c.png)

当时我满怀期待地开启了剪视频的日子，专门做曾仕强大师的国学内容。白天黑夜都在剪，发起来不要命，那股劲自己都被感动。

![](img/886b442eceb6b4d81d07838ccc358203.png)

可国学号的涨粉速度实在让人崩溃。我每天发三条视频，三个月只涨了1000粉。实在扛不住，我又开了个罗翔哲学号，重新踏上另一条涨粉长征。不知不觉，2021年就结束了。我一查账单，半年居然花了差不多20万。春节过后，账号还是慢如蜗牛，感情和学业又同时出问题，多重夹击之下，我毫无意外地抑郁了。

![](img/1a0b423c732169e8d6aedf20bc1b5e39.png)

但最暗的夜里，光也最容易出现。

![](img/f5f93937c6eaa92d62df4c1589c4d00e.png)

四月底，我的罗翔号突然爆了一条几百万播放的视频，后面每条都有几十万播放，几天时间涨了7000多粉。五月开始有收入，每天稳定几百块。那种快乐让我一个人躲在房间里看天花板，比谈恋爱还享受。

![](img/7b3ed327acf588dc28069ffed336d47a.png)

后来在朋友带动下，我开始碰黑五类产品，号很快就爆了，单日佣金冲到16000。那种春风得意的劲儿，比高考上榜还痛快。但黑五终究是黑五，钱赚到了，号也没了。

![](img/6109494d10951242aaba3984ac388b65.png)

赚到钱后的第一个母亲节，我给妈妈转了1000块，她感动得不行。那一刻我特别满足——能让家人分享你的成果，这大概就是赚钱最大的意义。

![](img/b080cb059b6168a1ff62dd51e4336628.png)

六月份，我又加了几台手机，多办了一堆电话卡，正式转战禅学、佛学赛道。卖禅学挂件，说白了就是“贩卖信仰”。我把原来的罗翔号和曾仕强号全部改成了这个方向，从此过上了日入四位数的生活。

![](img/11e92f789a8e04c6611df46c072ee21e.png)

人一旦有了成绩，仿佛全世界都变得和善。我每天心情都好，摔一跤都觉得是大地在跟我打招呼。五月份那会儿，我还跟班里的组宣委说，只要班级搞团建，我就赞助2000块。虽然平时我很少出现在教室，但能和大家一起乐乐，也挺好。

![](img/4cc8ac50485c5362f544f45a4e217541.png)

去年八月下旬，平台又开始打压“贩卖信仰”这类项目，月收入一下掉回几千。我只好继续寻找新出路，在几位头部高手那里付费学了无人直播和半无人直播。十月底，我带女装跑通了无人带货，三个号一周赚了好几万佣金。就是换了种玩法，赚钱的感觉依旧很香。

![](img/d09310e463d3a717d7a559ec1ccceb05.png)

无人直播做了两个月，平台又开始风控，录播容易违规。我顺势去做音浪，一天也有四位数进账。今年年初，又干了几天黑五，三天变现两万多。我还试过男粉直播引流，一天能加几百人，出粉单价约12块，但怕踩缝纫机，最终没卖粉也没继续。现在我又做回直播带货，玩的是半无人以及介于无人和半无人之间的路子，依然是暴力玩法，连续一个星期日入五位数。有时候往群里丢个收益截图，一群小伙伴排着队喊“大神”“带飞”，说真的，那感觉是挺爽。

![](img/c00f1c7b52d4fa15a6b93a9140963d8f.png)

不过爽归爽，学业和赚钱的矛盾也越来越明显。我只好带着笔记本去上课，坐在教室最后一排，一边开直播，一边当客服。这个学期的成绩已经滑到班级后面，可面对金钱，我只能先妥协。前几天，我在教室直接开了直播，17分钟进账5600块。截图发到群里，整个群都沸腾了。很多人说我不务正业，说我赚钱太轻松——可这两年我老了不少，头发也白了许多，这些又有多少人知道呢？

![](img/c21c61b4cfabec73cdcb9b4f26e20cbf.png)

但我真的很知足。至少我从网赚的坑里爬了出来，也算走上了相对顺的路。总有人问我有什么秘诀，说白了就是专注加坚持。但如果你没有足够强的抗压能力和意志力，最好别碰网赚。钱赚到位以后，心态反而更稳了，我越来越珍惜那群同频的好兄弟。我早就和行一约定，等本科毕业一起去读MBA，继续破圈、向上。虽然距离毕业还有两年，但对我来说时间就是真金，我甚至认真考虑过辍学去搞钱。

现在，我在校外租了一层楼开了公司，带了几位外地兄弟学直播，群里还带着10个徒弟。最近有不少人想拜师，但我做的项目太“暴”，不敢随便带太多人。收徒全看缘分，人品好是第一标准。

![](img/f0408b5cfe24061229ea05b0421b4345.png)

感谢所有遇见，让我经历了大喜大悲。过程虽然折腾，好在结局不赖。昨天有老兄问我，这辈子赚多少钱能满意？我想了想，回了一句：一个小目标吧。平心而论，网赚这条路不轻松，赚到钱的人不少，可更多人还在门外绕圈。只要跟对人，守好心，踏踏实实不回头，认准一条路死磕到底，就总会等到收获。

也许你正在走我走过的路，也许我也正走在你的前方。共勉。
