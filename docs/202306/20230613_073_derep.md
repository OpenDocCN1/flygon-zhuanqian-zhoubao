# 一、个人背景与转型铺垫

我出生在海南一个偏远的小村子，家境贫寒，交通闭塞，父母务农，家里四个孩子我最小。

2012年考上大学，是村里第一个女大学生。虽然只是普通二本，父母却很高兴。

在父母眼里，上了大学在农村很有面子，那时大学生稀缺，他们以为读完四年出来工作，薪资会更高，也能拥有一份体面的工作。

现实却是，当年大学生遍地都是，普通二本毕业能拿到的薪水也就四五千，而且岗位极不稳定。

大学专业并非我所爱，毕业后也无法从事对口工作，只能去做普通文员。毕业前满怀憧憬，毕业后才发现梦想很丰满，现实很骨感。

工作一年后，我明显感觉到一眼望尽头的打工生活不是自己想要的，一度陷入迷茫和焦虑，对未来感到迷失。

为了生存只能继续上班，同时在业余时间寻找合适的副业来增加收入。

我不满足于单一工资收入，工作不久就开始接触理财，后来通过写作分享理财经验，这些年坚持下来也收获了一些成果。

理财收益从0到十万+，自媒体从0粉丝到全网五万+，存款从0到和搭档一起攒到百万。

幸好工作一年就意识到存钱和理财的重要性，后面才有机会攒钱和搭档在广州买房。

![](img/aafae6ef21de288091731164cf663cdd.png)

这是我们以前想都不敢想的事，我们俩都是农村出来的人，别人家买房可能靠几个亲戚，而我们只能靠自己。

如果当年没有接触理财，没有足够的存款，我可能至今还困在办公室里过着暗无天日的日子，也不可能有转型的勇气和机会。

# 二、为什么要开课

今年我一共推出了两门理财付费课，分别是【新人小白理财入门课】和【可转债进阶投资课】。

三个月内一个人靠朋友圈就招到100个学员，促使我开课主要有三点原因。

1. 长期布局

2020年我就开始尝试知识付费，当时没什么经验，只是小打小闹，并没有长线规划。

正好那段时间我接触到可转债打新，发现这是一个相对低风险高收益的赛道，虽然很多人质疑“低风险高收益”的存在，但确实有这个品种。

我一边自己坚持打新变现，一边带学员一起操作，有人已经变现五位数，而且很多人坚持到现在。

无奈2022年6月中旬政策收紧，可转债参与门槛提高到两年交易经验加十万元资产，后来者就进不来了，我这部分的咨询收入也停了半年多。

计划赶不上变化，加上去年👸号广告变现变难，我隐约感受到一丝危机，才下定决心做自己的课。事情逼着你改变，也是在为长远打算。

![](img/24ce651e742669cd7ec7c8b4b7907182.png)

2. 同行带动

近两三年，同行里掀起一波开课潮，身边的自媒体人纷纷加入做课阵营。

我之前没正式做过课，但长远看做课更划算，一次制作多次售卖。

对我这种有财富思维的人极具吸引力，在同行影响下，我也想开始打造自己的付费产品。

一开始不完美也没关系，先完成再优化，后续慢慢迭代，关键是先行动起来。

3. 前期沉淀

开课前我有四百人左右的付费用户，来自之前带打新和知乎变现的，算是积累了一批种子用户。

正因他们的信任，我才有了被需要的感觉，也大概知道开课后他们会感兴趣，所以才有了开课的决心并付诸行动。

课程上线后报名人数比预期还多，两个课程连开两三期，累计报名破百。

没有前期积累，我不敢贸然开课。且这两年市场行情不佳，能报名的大多是出于信任和认可，不是单纯冲课程。

在普通人身上，信任不是凭空产生的，都是靠日常点滴积累起来的。

# 三、从0到1做一门课的方法

有了想法我就开始动手。做一门课远比写篇文章复杂，普通人如何从零开课？

我总结了五点实操经验。

3.1 明确课程定位

1) 找到自身独特优势

起初我想做【自媒体写作】方向，后来发现竞争太激烈。

身边七八成人都做写作变现，我的👸号才一万粉，别人几万到十几万，文笔也更强，明显没有优势。

我没有写作优势，但发现身边的号主很少做【投资理财】课程。

我恰好有五年理财经验，收益十万+，带过不少人打新债，直觉这块需求很大。

与其在红海里硬拼，不如选自己擅长的蓝海，于是把定位放在投资理财，再按不同阶段人群细分。

2) 洞察用户痛点

很多朋友说想学理财却不知道从何学起，也有人反馈打新债中签率越来越低。

这些需求和卡点，有的是私信告诉我的，有的是朋友圈评论，还有的是我在别人👸号留言区看到的。

现在大家理财意识比过去强，不再把钱塞床底或只存银行，但怎么选是个难题。

网上课程太多，理财又涉及真金白银，大家想学又怕被骗，所以迟迟迈不出第一步。

也有人想自己摸索，又怕走弯路亏更多，我的课程正好能解决这些顾虑。

3.2 列出课程大纲

我的每门课一般十节左右，每章两千到三千字，图文结合，内容太长学员容易疲劳中途放弃。

从第一章到第十章，由浅入深，由易到难，层层递进。

想写课前最好先列个大致大纲，围绕大纲展开。大纲像树干，有了核心才能开枝散叶。

如果想到哪写到哪，会越写越乱，越写越痛苦，最后耗费精力写成一堆。

宁愿多花时间打磨大纲，也别漫无目的乱写，好大纲能事半功倍。

3.3 确定课程形态

1) 图文课程

知识付费形式有视频、语音、图文，根据自身情况选即可。

我更倾向图文，语音不方便，视频制作门槛高，图文适合实操，边看边操作不用反复暂停切换。

2) 社群陪伴

每门课我都配了答疑交流群。单有课程省心但缺少学习氛围和老师连接。

社群能聚拢一群志同道合的人，有氛围也有激励，学习效果和体验完全不同。

3) 不定期加餐

学习期间我会根据情况加餐，多结合自身经历分享。这样学员吸收知识的同时更了解我，增加信赖感和学习动力。

3.4 上架流程

现在能上线知识付费的平台很多，比如小鹅通、千聊、荔枝、得到等，有免费也有收费。

新人建议先用免费平台降低成本。我是玩赚合伙人之一，可以和其他合伙人免费共用小鹅通，个人单独买一年要好几千。

上架步骤并不复杂，内容编辑好后按系统提示操作即可，尤其图文课程，对有👸号排版经验的人来说更简单。

3.5 做课踩过的坑

1) 过度追求完美

很多人希望课程完美无缺，但这种心态往往写不出来或写得很痛苦。我刚开始就是这样。

先接受不完美，才能有勇气迈出第一步。没人能一上来就写出完美课程，过程中总会遇到挫折，走弯路也能改。不如当勇敢主义者，不要当完美主义者。

2) 想全是问题，做才有答案

写课前我做过付费咨询，带过两百多人打新变现，也运营过两百多人的知乎变现社群。

真正动笔时，还是会担心写不出来、卖不出去、不够专业被说割韭菜等问题。想太多差点放弃。

回头看，想到的全是问题，实践了才有答案。很多事没开始就被想象难倒了，其实做了才知道怎么迭代。

# 四、如何卖出100份课程

课程做完只是开始，后面要推广销售。再好的课没人知道也卖不出去。

需要持续分享，让有需求的人想起你并选择你。以下是我的单兵作战经历。

4.1 制作课程海报

写完课就要准备推广，海报必不可少。

我在稿定设计平台做的，有大量模板，按风格选好后微调即可，设计小白也能上手。

自己做海报好处是产品有变动可随时改，省时省钱。虽然不算精美，但对普通人够用。

![](img/f2a8506100eaffd20b617ebf23272e9c.png)

4.2 打造吸睛文案

海报是绿叶，文案是红花。我总结四点经验。

1) 长短文案结合

文案都我自己写的。宣传分为长文案和短文案，👸号招募文案约1500-2000字，做一两篇模板后可微调。

朋友圈则每天发200-500字左右，一天2-5条。

长短结合才能兼顾深度和阅读体验。开头要抓人，结尾要有力，才能促进转化。

2) 软硬文案结合

朋友圈广告大家想到微商就反感。软文能促单，硬广会让人屏蔽。

不要把朋友圈做成微商渠道，平时也要分享生活、观点、学习片段，让人感受到你是有血有肉的人。

3) 直击用户痛点

痛点一：存不下钱

“你是不是每个月想存钱却月光？一年到头口袋空空？”

巴菲特说，你赚的钱不是你的，你存下的钱才是。

学理财不能立刻暴富，但能提升认知，改变大手大脚习惯，比同龄人早攒下第一桶金。

![](img/51558837531fb49e889910e4350053a0.png)

痛点二：收入单一

“你是不是想在工作之外开辟第二收入，却苦于没时间不知从何起？”

理财能实现第二份收入，且不需辞职也不耽误工作。

抓住“存不下钱”“想增加收入”等痛点，更容易引发共鸣。

4) 用自身经历背书

无论朋友圈还是👸号，亲身经历才是最强背书。

我有五年理财经验，收益十万+，累计收益率约38%，从租房到和搭档在一线城市买房，从身无分文到存下百万，这些都是真实变化。

在朋友圈输出前后对比，能让别人觉得真实、励志，从而留下深刻印象。

4.3 销售技巧

1) 早鸟价

早鸟价能制造抢到就赚的感觉，促使犹豫的人尽快下单。

我第一批入门课和可转债课都用早鸟价，效果不错。

2) 阶梯涨价

课程采用阶梯涨价，第一批最优惠，后续每期涨价，如119-149-199，每次涨30-100元。

临近涨价时很多人会集中下单，亲测有效。

3) 名额倒计时

每期招20-30人，朋友圈文案会写名额-1、-2，让潜在学员感受到紧迫感，促进成交。

![](img/bdf43d030c84094b8b4af7ff0b38c989.png)

4) 晒社群氛围

晒群内氛围和学员好评是很好的社会证明。很多人喜欢抱团取暖，看到别人都在学，更容易下单。

![](img/d367626f4b208dde9714feb437b447ec.png)

5) 真诚是关键

技巧再多也需要真诚打底。技巧大家都会，但真诚不是人人都有。

技巧加真诚分享，才能打动普通人。信任和认可是一切成交的核心，没必要搞太多套路，真诚就是最大技巧。

![](img/ed3243e844dbbc7d82875ca720e0acf2.png)

# 五、如何给产品定价

定价要结合用户群体，看他们的付费意愿和付费能力。

我的读者大多需要副业，经济条件一般，有意愿但能力有限，所以定平民价更合适。

如果用户付费能力强，价格可以更高，成交会更果断。

我之前社群价格过低只有几十块，现在不好涨价，只能逐步来。两门课价格大概在200-600元区间。

很多人问我，一个普通女生是怎么从办公室文员转型成自由职业者，还卖出了100份理财课程？其实回头看看，我的课程定价也是慢慢涨上来的——从最开始几十元，到现在几百元，虽然步伐不算快，但每一步都走得心里有数。有了这些摸索和积累，以后尝试做四位数价格的课程，也不是没有可能。

今天这篇，重点聊聊我是怎么维护和交付用户的。

两门理财课，我都建了陪伴社群，时长分别是30天和180天。在学员学习期间，我会在群里答疑、定期加餐。说白了，陪伴、答疑、加餐，这些本身就是售后交付的一部分。社群里还设置了实操闯关和财富读书打卡奖励，通过积分的方式调动大家的积极性。此外，我会尽量帮学员跑通学习到变现的闭环，让他们在课程期间就能收获第一笔理财收益，哪怕金额不大，也能大大增强信心。

第一件事：用心答疑。

不知道你有没有遇到过这种情况——课程或者资料里明明写得很清楚，但新人就是不看，直接跑来问。我是怎么处理的呢？一般分两种情况。

第一种，如果我自己特别忙，而学员问的问题课程里恰好有详细说明，我会让他们先把相关章节看两遍，还不明白再来找我。但语气一定要委婉，最好再夸两句，不能直愣愣地说“我现在没空”。举个例子，有个学员之前已经教过她两三次其他问题，我就会说：“这块课程里专门讲到了，你这么聪明肯定能看懂，看完还有疑问随时来找我。”

![](img/e5b365c4c83a4ebf43dfa1ffc14e7bb8.png)

第二种，如果时间比较充裕，我能回复就尽量回复。哪怕对方当初付费并不高，我也会认真对待。我自己就是从零开始走过来的，所以特别理解新人问的那些问题和焦虑，不会觉得不耐烦。教新人确实很花时间，但这也是他们愿意报课的原因。而且，教别人的过程，反而能帮自己巩固知识。通过他们的问题，我能了解大家的学习进度和困惑，既更懂用户，也能倒逼自己迭代课程。

除了专业上的指导，情绪价值也很重要。

很多新人会有顾虑，比如担心学不会、担心本金太少。我都会表达理解，并用实际行动告诉他们：学习期间我会一直陪伴大家答疑。除了学习上的问题，偶尔也会遇到生活上的倾诉。前段时间，有个小伙伴遇到伤心事，只想找个人聊聊。我听她讲完，简单开导了一下，她心情就平复了不少。后来我建议她把这段经历写出来，我帮她发布在👸号上。正好她也想给孩子赚点奶粉钱，就这样把悲伤变成了实实在在的收入。需要情绪价值的时候其实不多，但被需要的时候，我很愿意出一份力。

![](img/fc944c33f51e0121dff7e02ba7ff319f.png)

让学员完成闭环，是我特别看重的一点。

这两门课都有同一个闭环：学员不仅能学到知识，还能在学习期间把学费赚回来。有些执行力强的伙伴，甚至赚回了10倍学费。当然，不是所有人都能做到，因为每个人情况不一样——有人没有本金，自然没法钱生钱；有人有本金却迟迟不动手，同样赚不到钱。通常来说，只要有一定本金又愿意照做，赚回几倍学费并不难，而且本金只需要1到5万，压力不算大。

我也越来越珍惜回头客。

我见过有些老师，把学员招进来就不管了；也见过特别珍惜付费学员的导师。做自媒体这几年，我慢慢发现一个规律：学员第一次付费体验好的话，后续有需求还会回头找你；如果体验很差，可能就没有下次了。打造个人IP，从来不是一锤子买卖，尤其是创业初期，更应该维护好老客户，因为他们可能成为你的铁杆粉丝。我有一门课，老客户回购率能达到40%到50%。在流量还不够多的时候，用心服务好老客户，比开拓新客户容易得多。而且老客户成交特别顺畅，基本简单问两句就下单了，因为彼此已经很熟悉，很多人甚至直接转账。

![](img/e6a17a453efd06fc1062496516a81eb5.png)

所以，别觉得付费结束就完事了，也别让学员需要的时候找不到你。每一个付费用户，都可能成为你日后最坚定的支持者。我常常觉得，和学员之间不仅仅是利益关系或师生关系，有时候更像是互相治愈。当我们认真赋能、看着他们越来越好，自己也会很有成就感，会觉得这是一件长期且有意义的事。

最后，分享几点个人总结和感悟。

心态要稳，这是第一点。自媒体这条路上人太多了，初期总会遇到各种问题。一个乐观的心态，能支撑你一直走下去，而不是一碰到困难就想退缩。虽然自媒体看起来没门槛，但没门槛恰恰是最大的门槛。看到大量人涌进来，别人进步比你快、赚得比你多，心态不好很容易崩溃和内耗。稳住心态，才能继续往前冲。

持续学习也很重要。最好的学就是教，因为有了教别人的责任，自己自然也保持提升。尤其是自由职业以后，发现要学的东西实在太多了：怎么设计课程、怎么运营社群、怎么写招募文案、怎么交付学员……初期全靠一个人完成。只有不断学习，才能更好地赋能学员。

还要随时拥抱变化。去年打新债提高门槛以后，我大半年没有理财付费业务。后来我觉得不能一直这样耗着，于是开了可转债进阶投资课，想着既然中签率低了，就换一种方式参与可转债投资。在此基础上，又专门开了一门针对新人小白的理财入门课，这才有了现在的课程收益，以后也能持续变现。做自媒体也是一样，平台随时在变，与其排斥变化，不如主动调整。打新债不能做了，就想想别的路子，而不是站在原地抱怨。

破圈成长，也让我受益匪浅。今年3月，我加入了玩赚合伙人，主要是想突破原来的圈子，给自己换一个成长环境。在那之前，我一个人做自媒体基本靠死磕，一路走得很辛苦，也容易放弃，遇到问题还会内耗。后来偶然认识了理白，知道了玩赚合伙人，考虑几天后决定加入。那时我刚卖课赚了一万多，然后又一次性全花了出去，下了特别大的决心。那是我历史单次付费最多的一次，但我觉得非常值——终身制，还能链接到一群比自己厉害的人，得到他们的指点，比自己死磕强太多了。也是因为这次付费，我认识了很多优秀的人，比如理白、芷蓝、靠谱，从他们身上学到了不少商业思维。

想成为什么样的人，就进入什么样的圈子。喜欢玩游戏就加入游戏圈，喜欢搞钱就加入赚钱星球、玩赚合伙人这样的圈子。和厉害的人在一起，哪怕暂时赚不到钱，也能学到很多宝贵的经验。

还有一点，永远相信自己。无论什么时候，不要因为自己资历浅就停止前进，也不要因为农村出身而自卑。人生的任何改变，都源于你相信自己；如果不相信自己，机会摆在面前也抓不住。我和队友都是农村出身，因为相信未来会更好，所以收获了幸福和房子；因为相信能存到100万，所以真的存到了100万。相信自己，再加知行合一，你也能收获不一样的自己。

我很喜欢自由职业，也知道这条路不容易。虽然前方有困难，但我知道现在的每一步，都在往更好的未来走。我相信，只要坚持下去，用5年、10年甚至一辈子的时间去做一件事，结果一定不会差。赚钱圈里有很多厉害的人，做事情很快就能拿到成果；但我相信也有一部分人像我一样普通、后知后觉。即使是蜗牛，只要朝着目标慢慢爬，总有一天也能到达想去的地方。

以上，就是一个普通女生从办公室文员转型自由职业，并卖出100份课程的经历。感恩在这里与大家相遇，祝愿我们都能在这个圈子越来越好。不管赚钱的速度是快是慢，都希望你能收获不一样的自己——除了金钱，还有认知和成长。
