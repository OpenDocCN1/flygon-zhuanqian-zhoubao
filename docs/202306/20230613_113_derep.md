# 零基础短视频剪辑，5分钟就够了
作者：龙哥

刚碰短视频的时候，最头疼的就是“剪视频”三个字。尤其这次参加📕店铺航海，身边不少小伙伴都在问：搬运来的素材到底怎么快速剪？其实真没想象中难。

我是龙哥，赚钱2023新人，自己平时做带货混剪，正好把这套对新手比较友好的方法整理了出来。你只要愿意动手试，基本5分钟就能完成一条基础视频。

分享真的会有回响。我这次就是先被鱼丸小姐姐 @鱼丸 指路，看到了奇杰大佬讲“批量思维”的帖子，里面提到“单人日产200条”的玩法。第一眼会觉得那是高手的事，但其实拿来拆解之后，新人也完全能蹭到思路。奇杰大佬的帖子有三个版本，我都放这儿：

新手别急着挑战进阶版，先从我整理的基础稿入手就行。文档里字不多，重点全在操作截图，跟着步骤过几遍，慢慢就顺手了。我自己的体感是：等基础打牢再看大佬的思路，效率至少提了20倍，现在状态好的话，一天能剪10条左右。
