# 【其他】5 篇
作者：龙哥

今天不聊热门分类，聊一个容易被忽略的宝藏角落。我最近在语雀上刷到一个文档，标题特别朴素，就叫“【其他】5篇”。

说实话，很多人在刷内容时，都会下意识跳过“其他”这个分类。但我的经验是：那些无法被轻松归类的文章，往往藏着最不一样的惊喜。这个文档里不多不少，正好收了5篇独立内容，没有刻意包装，也没有煽情标题，就是安安静静地放在那里，等你点开。

如果你也喜欢那种“不确定会读到什么，但一读就有收获”的感觉，那这份合集很适合你。想看的可以直接戳原链接：https://www.yuque.com/for_lazy/thfiu8/utr483mzrftbvnsg
