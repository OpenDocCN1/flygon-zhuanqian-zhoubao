# 《初中毕业的汽修店老板，折腾抖音一年分文不进，按照这个方法一个月营收十万元——人人可复制的同城号方法论。》

汽修店老板在平台折腾一年零成交，换个打法月入十万：一套可落地的引流方案

你有没有见过这样的老板：守着开了快二十年的汽修门店，以前从来不愁客源，靠街坊口碑就活得挺滋润。可疫情一来，进店的车骤然少了，老顾客慢慢消耗干净，他才开始发慌，琢磨着要去线上拉新。

今天要讲的主人公，是我合作伙伴的亲弟弟，咱们叫他亮仔。他干汽车维修快十九年，一直在市区经营一家维修铺子。早些年买卖好做，他压根没想过去主动找客人，每天自然上门的活儿都干不完。疫情之后，进店量肉眼可见地往下掉，他心里清楚，再指望老顾客带来新顾客，迟早要坐吃山空，于是决定到网上闯一闯。

![](img/37514e195e4876d724f192d0444c848a.png)

受到我搭档的影响，亮仔2022年年初就注册了抖音。他以前从不玩这类平台，只是听说上面人多。自己平时爱看搞笑段子，见到别人随手发个恶搞片段就能拿到几十万赞，便天真地认为照着抄也能火。

可对一个毫无拍摄经验的人来说，做出一条像样的片子难度不小。光学会剪映就耗掉好几天，还得准备文案、挑选配乐、处理画面，白天又要修车，精力根本不够分。费尽心思完成一条发出去，播放量却少得可怜。期望越高，摔得越疼。连家里人都嫌他瞎折腾，净耽误正事。

一年下来，他一个顾客都没从平台上捞到。事后他自己复盘：那时候的思路压根就是错的，光顾着仿照搞笑玩意儿，却从没思考过靠什么商品来成交，也就是按照人气思维在做，而不是按卖货的视角；再说每天要搭进去大量时间和力气，没办法长期坚持，最后断更也就是必然了。

有了这次惨痛教训，他才明白一件线上老手早就清楚的事：拍东西最终是为了成交，而成交的前提是先有一个具体的产品。

2023年3月，亮仔加盟的连锁品牌总部，派了一位运营老师到店里。老师来了以后头一件事，就是定出明确的目标产品：199元的机油保养套餐，还送一次全车安全检测。等检测暴露了哪些零件老化、哪些部位有隐患，车主多半会愿意接着做维修和深度养护。

内容的方向随即转变，所有内容都围绕这个套餐展开。总部早就拿到了平台同城团购的商户资格，门店可以直接把团购链接挂到网上，顾客下单后进店消费时核销，款项由总部统一结算。亮仔只管拍片子和卖套餐，至于人进店以后怎么追加业务，那是他的拿手好戏。

怎么拍又成了新问题。亮仔一开始尝试口播，一条内容从开始到结束都是他自己对着镜头说话。他又不爱用提词设备，只好强背稿子。背稿子太磨人，每天要耗很多时间，这种模式多半干不了几期。

总部考虑到底下门店的老板们普遍学历不高、对网络工具也陌生，便琢磨起一套低门槛、省时间、谁都能上手的拍摄方式。最终的办法很朴素：他只在开场那一小段和收尾那一小段露脸，中间全部用图片和影像素材拼起来，配上画外音解说。

别轻视这点小调整。对总部来说，这个做法解决了全国几百家门店复制难的大问题。亮仔只需要背熟开场和收尾的两小段话，中间的内容照着稿子念就行，声音留在画面里就好。这样产出的东西，既有真人露面带来的可信度，又能把产品讲明白，制作难度也被压到极低。

人人都说做抖音要往死里拼，但为什么就是做不到？说到底，是执行门槛太高了。

![](img/9d62c6816f6c637ebd61b08cffc359b9.png)

我自己做第一个片子时，足足花了九个小时。一整天什么都别干，全耗在这上面。就算知道必须稳定更新，可这实在太反人性，坚持不了几天。对于亮仔这种没学历、不懂网络、学得也慢的店主，给他讲什么账号定位、权重、投流这些术语，通通没用。他需要的，是一套今天学完明天就能用的方法，并且这套方法能让他一直做下去。

这套方案最珍贵的地方就在于此。当然，总部如果想花钱做精致影片、包装个人IP，也不是不行。但那种高成本内容只对小部分人有效，对绝大多数普通老板来说，真正管用的还是能轻松落地的玩法，容易照做才是一切。

具体操作简单到没法再简单：总部每天把文字稿发给亮仔，他照稿朗读，再补上开场和收尾的出镜，最后用手机里攒的素材混编一下，十分钟收工。按照这个节奏，他在三十天里录制了近三十条内容。2023年4月，他通过这个平台卖出了21份199元套餐。

![](img/09015e39c7203fccd85cf30518404ca6.png)

上面是网上下单的数目。另外还有79位车主并不是在平台下单，而是刷到短片后直奔店里，也表示想体验这个199元套餐。亮仔每回都会问新客是从哪里知道这家店的，所以这些数字都有实据。

单月卖出一百份，在维修行当里算相当不错了。而且这个套餐本来就是引流款，利润特别薄，顶多挣点手工费，真正的进账在后面，也就是车辆进店后的增项消费。汽车维修的需求往往滞后，顾客来时只想做个基础养护，可一检查，刹车片薄了、底盘渗油、皮带老化等等问题全冒出来，这些毛病他平时根本看不见。既然关系到安全，大多数人都不敢拖着不治。

这件事也折射出一个道理：我们总讲要带着卖货的目的去做推广，但往往被自己狭隘的成交思路给框住。像维修业这类生意，引流产品根本不用赚钱，只要能把人请进店，后面自然有无数种办法产生收益。所以你的靶心应该改成精准客流，内容的呈现方式也要跟着调整。哪怕顾客进门前一分钱没花，只要他来了，就已经赢了。

事实上，不少顾客压根不在线上付款，看见短片直接开车就来了。他们中相当一部分人还会顺手做其他养护和修理业务。2023年4月，光是从这个渠道来的顾客，就给店里带来十万元流水，而且这些人全都沉淀在亮仔的好友列表里，往后还能反复触达。

![](img/e2ca889b82d6fcaf7e9b6626f7232899.png)

一旦看到正向反馈，拍片子的阻力又小，亮仔现在一点都不排斥更新，反而天天盼着拍。他们门店还在谋划下一个引流产品。

我们给线下商家做辅导时，常常按我们固有的理解替他们定制计划，再命令对方执行。如果效果不好，就怪对方不够配合，甚至反问：同样一套打法，别人能成，你为什么不行？可仔细想一想，我们充当的是教导者的角色。师父没把徒弟带好，怎么好意思把责任都推给徒弟？真正到位的服务，应该站在执行者的位置去设计，摸清他的文化水平、学习速度、可支配的时间，把方案做到随手就能用的程度。

做抖音，持续输出才是正道，其他都属于花哨技巧。我们总说线下商家做线上内容，本质上就是到街上发广告页，要不断把店里的靠谱师傅、拳头项目和门店信息亮出来。可我们太在意广告页本身的设计了，总觉得文案要惊艳、画面要精美，却忘了把广告页真正递到路人手里，这个动作本身也有成本。

去街上请人发广告页，一天也要付人工费。而在线上平台发内容，人工成本藏在写文字稿、拍摄、后期处理、背台词这些琐碎步骤里。步骤越多，你越不容易把内容发布出去。反过来想，如果街上有一万个免费帮手替你派发广告，你只需要承担印制的钱，生意自然红火。平台上的那些“帮手”成本，其实由你本人决定。

这件事给我一个很大的启发：这套拍法，往本质上看就是再熟悉不过的到店打卡内容，只是把拍餐厅换成了拍修车铺，坐在镜头前的人变了而已。这类内容早就是红海，但这套模板完全能搬到其他行业重新用。

为什么我们之前没往这个方向想？因为我们被固有专业视角框住了，觉得这种形式老套、不上档次。可对真正需要它的人来说，好用比高端重要得多。

放下身段，去理解客户到底需要什么样的指导，站在他们的角度设计路线，让他们用最少的代价、最小的阻力持续行动。只要对方能轻松上手，坚持就不再难，成功的概率自然水涨船高。这恐怕才是每一个靠服务吃饭的人最该琢磨的事。

祝各位读完有收获。
