# 手把手教你用AI给淘宝模特一键换装，零基础也能轻松搞定
作者：龙哥

> 来源：保姆级教程，亲测可行

如果你经常逛淘宝，一定对那些穿着各种服装的模特图不陌生。其实，这种图不一定需要真人拍摄，用AI就能生成，甚至连衣服都能随意替换。今天我就把完整流程拆解给你，全程干货，建议收藏。

## 一、先把环境准备好

这里用到的工具叫SD，全称是Stable Diffusion，是目前开源圈里特别火的AI绘图框架。我们平时说的“跑图”，基本都是在它的图形界面Web-UI上完成的。那要怎么装呢？

### 1. 硬件要求

先说重点：不是每台电脑都能跑得动。SD依赖显卡，最低配置是16G内存、40G硬盘，显存至少4G。达不到这个门槛，后面会很卡甚至跑不动。

### 2. 软件安装

新手建议直接用整合包，省心省力。这里推荐B站UP主秋叶的整合包，链接和提取码如下：
- 视频教程：https://www.bilibili.com/video/BV1iM4y1y7oA
- 百度网盘：https://pan.baidu.com/s/1_ibEk2OpKHxmEg4AnFOpSA 提取码：c132

下载解压就能用，具体步骤看视频就行，不多啰嗦。

## 二、挑对模型，事半功倍

### 1. 模型分两类

SD的模型主要分两种：
- **Stable Diffusion主模型**：管生成效果，几乎所有功能都靠它。
- **外挂VAE模型**：类似风格化滤镜，能让画面色彩和细节更好看。不是所有主模型都要配，但配对了效果翻倍。

### 2. 去哪里找模型

推荐去C站（https://civitai.com）找，不过需要🪜。本教程用的主模型是`beautifulRealistic_brav5`，很适合生成亚洲人，尤其是日韩系服装模特。VAE用的是`orangemix.vae`，这两个模型文末都放了网盘链接，不用🪜也能下。

下载完成后，打开SD安装目录，进入`models`文件夹。

再回到`models`文件夹，进`VAE`文件夹，把VAE模型也放进去。

![](img/8ce4749f99919dd587d48d9a57543489.png)

回到Web-UI，点一下蓝色刷新按钮。

展开模型列表。

## 三、生成一个原始模特

想换装，先得有一个“底子”，这个底子就要靠SD的**文生图**功能。这也是SD最基础、最核心的功能。

在Web-UI里点一下“文生图”标签。

![](img/57d09b1378588b783c5f32ba99b3db2f.png)

页面上会出现一堆参数。

![](img/57571cf81617c251dce4d648e554eccc.png)

这些参数决定了图长什么样，我们来调一下。

### 正向提示词

这次先让AI生成一个穿毛绒外套的女生，所以在正向提示词里写：

```
(8k, best quality, masterpiece, ultra highres:1.2)
Photo of Pretty Japanese woman in the (style of paul rubens and rebecca guay:1.1) (melancholy winter snow:1.4),(shot hair:1.3)
```

### 反向提示词

反向提示词填：

```
(worst quality:2.0)
```

括号里的数字代表权重，1到10之间，数字越大AI越重视这个描述。

### 勾选面部修复

在提示词下面有三个选项：面部修复、平铺图、高分辨率修复。一般只勾**面部修复**。高分辨率修复虽然方便，但显卡不好容易爆显存，所以咱们先出小图，后期再单独放大。

设置完直接点右边的“生成”按钮。

![](img/cdb3494cf9640caafcffc78ae43d02ef.png)

等几秒钟，你的AI模特就出来了，效果大概长这样。

![](img/3173bc3ca7108293a2df6ad2f8529fe9.png)

## 四、给模特换上新衣服

模特已经有了，接下来就是重头戏——换装。

### 1. 进入图生图

点击预览框下方的“图生图”按钮。

![](img/f0b0bc87bd2ded113b3fb7f534103538.png)

### 2. 打开重绘工具

跳转到图生图界面后，左侧就是刚才生成的模特图。找到“重绘”按钮，点开后右边会出现一支画笔。这时候鼠标会变成一个黑色圆圈，说明可以开始涂了。

![](img/6379e828ac663b6dbfd87fed16a4e38c.png)

### 3. 涂出蒙版

我们要把模特身上的衣服全部用画笔涂黑，尽量别涂到皮肤和背景。这一步叫“绘制蒙版”。蒙版的作用是告诉AI：只有这个区域需要重画，其他部分保持原样。涂好后的效果参考这个。

![](img/8cf4fd86424e28c52bb8ea8e81470c8d.png)

### 4. 修改关键词

接下来替换提示词。如果之前的关键词里有描述原服装的内容，记得先删掉。然后加上你想要的新衣服描述。这次我让她换碎花长裙，所以添加了：

```
a long skirt printed with flowers
```

![](img/e1cbc42d6f5a1fafa88e2b5be01125d0.png)

然后像文生图一样点“生成”，AI就会自动把蒙版区域的衣服换掉。我是这么生成的：

![](img/d7de29f27172e6ea26fd86d7e005fb5b.png)

能明显看出新裙子和原来完全不同，裙摆部分也出现了碎花图案。接下来提升一下画质。

## 五、高清化处理

### 1. 后期放大

还记得之前文生图时分辨率设成了512x768吗？这是为了照顾显卡性能。出图之后再放大也不迟。

点击预览框下方的“后期处理”。

![](img/2b2cb771e9d2db87d30e0093f5372897.png)

把缩放比例调成4，表示放大4倍。`upscaler1`和`upscaler2`是放大算法，具体用哪个可以自己多试试，看哪个效果顺眼。设置完点生成。

![](img/67fcbc39299813a6af3407cdceec20b3.png)

### 2. 查看成片

高清化后的图会显示在右侧预览窗口，点文件夹图标就能直接定位到图片所在位置。

![](img/92f08b897dcae90da25e55985fdcfa4f.png)

打开图片属性看下，分辨率已经变成2048x3072了，从模糊小图变成了清晰大图。

![](img/709802efe080b5983b58ba527ccc24cc.png)
