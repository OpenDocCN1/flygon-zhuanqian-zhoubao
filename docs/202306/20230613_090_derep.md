# 【赚钱认知】12 篇
作者：龙哥

为什么有些人拼尽全力却始终赚不到钱，有些人轻轻松松就能把生意做大？说到底，还是认知的差距。最近在语雀发现了一份很值得细读的资料——《赚钱认知》合集，里面一共收录了 12 篇，专讲那些藏在实际搞钱背后的思维模型和判断方式。

这 12 篇内容，不灌鸡汤、不讲空话，而是帮你看清从“想赚钱”到“会赚钱”之间，到底要跨过哪些认知门槛。把它读完，你会发现很多过去的困惑，其实都是思路没打开。
