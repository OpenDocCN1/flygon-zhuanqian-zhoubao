# 闲鱼二手书插件分享：自动填写表单数据
作者：龙哥

最近才注意到闲鱼上卖二手书这个玩法，深入了解后发现，这一期航海计划里正好也有，可惜当时没赶上报名，现在只能自己对着航海手册慢慢摸索着来。

决定做这个方向之后，我当天就下单申请出版物许可证，现在差不多快批下来了。在等证的这段时间，我先把流程走了一遍，参考了几个热销榜单，每天手动上传一些书籍。跑了几次下来，最大的感受就是：很多填写项其实是千篇一律的模板内容，完全能靠脚本自动搞定，这样录入效率会高很多，选书反而能更用心。

其实这个脚本的雏形早就有了，只是一直拖到周日才动手实现。不过这次倒没有自己从零开始敲代码，而是直接让 ChatGPT 来代劳，结果意外地靠谱，帮我省下了大把时间。

目前脚本已经实现的功能包括：
1. 自动匹配分类
2. 自动选定店铺
3. 自动写入商品标题和描述
4. 自动勾选“立即上架”

后面还打算加上自动检测书籍是否属于违禁书的功能。

评论区不少朋友也很感兴趣，有人问有没有闲鱼平台的关键词库，目前我这边还没有收集；还有人问能不能做批量给不同买家发送相同消息，来挽留潜在客户，比如附赠一些优惠或赠品之类的；另外有读者反馈飞书文档里的视频好像无法播放了，这个可能得再检查下。

总之，这套自动填表的工具，能把重复劳动交给机器，让我们把精力放在更有价值的事情上。如果在做闲鱼二手书，不妨也想想哪些环节可以自动化。
