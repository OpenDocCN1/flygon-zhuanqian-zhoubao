# 高考两天摆摊卖花，真能赚到钱？这份实操攻略请收好！

又是一年高考季，敏锐的生意人早就盯上了校门口这块“香饽饽”。有人问：高考期间卖花，到底靠不靠谱？我的回答是：非常靠谱！

如果你正想找个副业练练手，那高考季绝对是个好机会——考场上孩子们奋笔疾书，考场外家长们焦灼等待，这时候一束寓意美好的鲜花，就是最好的情绪出口。

**为什么偏偏是花？**

十二年苦读，就盼着这一刻能改写人生。考场外的家长比考生还紧张，他们急需一种方式来表达祝福、缓解焦虑。鲜花，无疑是最合适的载体。

当考生走出考场，看到父母捧着带有祝福贺卡的鲜花，紧绷的神经瞬间松弛下来，拍照发朋友圈留念，这仪式感直接拉满。高考一辈子就一次，这份需求真实存在。

**卖给谁？搞清楚对象**

别想当然以为是考生——他们才不会给自己买花。真正的买家是家长，尤其是40到48岁这个年龄段。想清楚用户是谁、买花干什么，你才能理顺从进货到销售的全流程。

**卖什么花？首选向日葵**

推荐三种：向日葵——寓意“一举夺魁”；莲花——寓意“好运莲莲”；蓬莱松——寓意“放青松”。

但我更建议你只卖向日葵。根据以往数据，向日葵是绝对的爆款，其他品种销量惨淡。想稳稳卖完不压货，就选热门款。可以搭配尤加利叶、蓝星花等配花，颜值高了，家长才愿意掏钱。

**去哪里进货？两条路**

网购：美团、多多买菜下单，性价比高、速度快，基本次日上午就到。不建议淘宝拼多多，运输闷热容易损坏，理赔麻烦，而且3-4天的物流时间根本来不及。

本地：一家家问花店比价格。高考期间花价必然上涨，尤其向日葵这类热门花，很多地方会缺货。多问一句供货量和价格，并且多备几家供货商，避免被动。想便宜就去花卉批发市场，没有批发市场的城市，厚着脸皮问花店老板，或者网上搜、朋友圈问，总能找到经销商。

**怎么选花？以向日葵为例**

选大尺寸：同等价位里挑最大的，花店也是按尺寸定价的。

选饱满度：选三度开放程度，太生的花苞卖相不好，没人买。

选无凋谢：花瓣外缘无枯萎迹象，花蕊不发霉，叶子硬挺，没有黑点，叶子保留三分之一到二分之一，茎秆粗壮，基部无干缩。

**进多少货？**

300支就够了。再多不好摆，搬运也费劲。

**成本多少？**

以广西柳州批发价为例，300支起步，单支可压到3元，成本约900元。包装费100元，水桶10个约100元，贺卡、喷壶、收款码等杂项100元内。总成本1200元左右，封顶不超1500。小成本副业，大家都能接受。

**花到手后怎么做？**

醒花四步：
1. 摘掉烂叶，根部斜剪45°，缺水严重可开十字刀。
2. 花头朝下，泡水1小时。
3. 转过来深水醒花4-8小时，别太久，会烂根。
4. 醒完浅水养，水里滴几滴84消毒液，有条件的放保鲜剂。

向日葵容易烂根，记得经常剪根。

**在哪卖？**

选当地有名气的学校门口或对面马路。注意城管和警察可能维护秩序，提前踩点，多准备几个备用位置，不能摆就马上转移。千万别选垃圾桶旁边！

**什么时候卖？**

第一天上午首场考试结束后。这时家长和考生都还紧张，愿意花钱买个好彩头，拍照纪念。而且看到别的家长都捧着花，自己空着手多少有点尴尬——别人家孩子有的，自家孩子也得有。

**摆摊要带什么？**

收款码：提前去文印店打印微信和支付宝收款码，还可以加上微信二维码，引导客户进私域。

喷壶：天热花容易蔫，喷水能让花瓣显精神，还能延长保鲜。

剪刀：修剪过长的花枝或不好看的部分。

包装纸：牛皮纸或透明纸，现场包。

花桶：去菜市场买几个水桶，或者买几个好看的垃圾桶也行，便宜。高考用完还能挂闲鱼二手卖掉，回点血。

折叠桌：家里有就带上。

贺卡/笔：可以提前在网上搜高考祝福文案，存手机备忘录，字数别太长。

广告牌：找块厚纸皮，干净面上用马克笔写“鲜花，xxx元”，或者写句好听祝福语，用两种颜色笔写更醒目。

透明胶：消耗品，多备几个。

**怎么运到现场？**

有车就开车，方便。没地方摆时，打开后备箱简单布置就能卖。没车就打车，提前和司机说明情况；或者找朋友、父母帮忙搭一程。

**要不要包装？**

必须包！有包装和没包装，档次天差地别。去文具店买牛皮纸或透明纸，现场包即可。不会包？网上一堆教程，比我专业。

**卖多少钱？**

单支成本3元的话——

单支定价9.85元：引流款，寓意考985，吸引围观，引发从众效应。

两支+尤加利叶定价21.1元：寓意考上211。

六支整束+配花定价98.5元：主力利润款，大力推这个。

**遇到砍价怎么办？**

基本不用担心。家长看到寓意这么好，很乐意接受。很少有人会砍价。

**简单话术参考**

“叔叔/阿姨您好，这些花都是刚采来现场包的，很新鲜，送给孩子，祝他高考一举夺‘葵’、金榜题名！您看看需要哪束，我帮您装上。”

“价格真不贵，98.5元代表您的心意，送花给孩子，让他缓解紧张，争取考个985，一举夺‘葵’！寓意特别好，看中哪束我给您包上。”

**怎么竞争？**

主动打招呼：家长在门外等两个多小时很无聊，主动聊天，聊着聊着就可能买个花。

嘴甜：多说感同身受的好话，让他们别紧张。

抢好位置：好位置直接决定客流，去晚了位置偏，销量就惨了。

**注意细节**

朋友圈预售：减少损耗，还能扩大渠道，朋友可能推荐给身边的人。

闲鱼售卖：选几张好看的花束照提前发布，流量不小。

抖音直播：蹭高考热点，直播卖花、教选花，或者聊聊高考话题，快速涨本地家长粉，还能做后续变现。

发小红书：把从想法到摆摊的经历写成笔记，这类内容很受欢迎，尤其女生卖花，涨粉后也能变现。

线下引流私域：家长买花时引导加微信，方便后续节日订花复购。搞个小活动，比如加好友送个牛皮笔记本或高颜值笔。

**怎么减少损耗？**

选阴凉处，避免暴晒两小时。水桶里加水和几滴84消毒液保水。

**两天卖不完怎么办？**

剩几支就送朋友或自己养。剩得多就在朋友圈或闲鱼低价处理，尽量回本，别亏太狠。

**能赚多少？**

300支全卖完，除去成本，大概能赚2000-2500元。比上班一天强点，还能锻炼能力，就当体验生活。
