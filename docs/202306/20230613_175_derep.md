# 一顿商学院老同学聚餐，给我的八个实战提醒

上周晚上和商学院的老同学、老朋友们碰了一面，饭桌上的聊天比课本有意思多了。把当晚被点醒的几个关键点捋出来，跟大家分享：

1、做一件事前，先掂量动机。分清是“想要做”、“一定要做”，还是“非做不可，不达目的不收手”。只有最后一种执念，才真正能把事情推到终点。

2、信念感是外放的。自己心里先没底了，外界再好的资源、再顺的风，都像逆风一样难以借力。

3、别待在舒适圈里原地踏步。要主动向上寻找参照物，拆解头部玩家的打法和商业逻辑，先找个对标抄作业，再想办法超越。

4、认知是圈层状的。你现在能看到的是内圈，往外还有更广的可能性。持续拓圈、破圈，去触碰新的信息边界，才是成长的关键。

5、长期的口碑来自信任。基于信任的推荐才经得起时间考验。真诚输出、利他分享，看似无我，实则最后回馈最大的是自己。

6、先立目标，再找路径，不要被情绪带节奏。目标感是通用底层能力，有清晰方向，团队即便起点不同，也会朝同一个好结果收敛发力。

7、事业、健康、家庭不是取舍题，而是共生关系。一个支柱稳了，另外两个会得到反哺，互相赋能。

8、道、法、术、器缺一不可。人生的不同阶段侧重点不同，但总要在某个维度做到足够深、足够专业，才有真正的壁垒。

饭后评论区老同学也都在补充：向内求很重要，冲冲冲！
