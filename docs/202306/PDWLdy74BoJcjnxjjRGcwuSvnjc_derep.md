# 花了两万多学费，从设计师到副业IP，我总结出这些大实话
作者：龙哥

我，数学考过78分，却头铁选了数学专业；后来转行做设计，又稀里糊涂跑通了副业IP。这些年花在知识付费上的钱，加起来超过2万。今天就聊聊这些钱都买到了什么。

## 一、我的“学费”账单

高考志愿是我瞎填的：信息与计算科学，听着高大上，其实就是80%数学+20%计算机，一个理学专业。要知道，我高中数学150分的卷子，最低拿过78。数学78，我报了数学专业。数学78，我报了数学专业。![](img/2a3bebe795b17730604ef6d73062dcb5.png)

那会儿笃信“读书才有出路”，于是硬着头皮读了快3年，几乎天天泡自习室，居然还拿过两次奖学金。现在回想，真是典型的“读书读傻了”。要是当时有现在这种搞钱觉悟，说不定早成了百万粉博主……开个玩笑，别当真。

到了大三，面前摆着三条路：数学老师、程序员、考研。我全都不想选。因为从小有个艺术梦，我一心想做设计。查着查着，偶然接触到了UI行业，又碰巧看到一个设计大佬在开直播课，听了几节就果断交钱。第一笔高额付费，就这么给了求职——5999元。![](img/e53d4030c62bf2655aae2a20f8111136.png)（那时候叫夏令营，其实就是现在的训练营。）

这笔钱放到如今也不算小数目，更何况是2017年。父母一度怀疑我被骗，我死说活说才让他们点头。好在运气不错，师傅靠谱，教得也好，三个月的训练营真把我这个门外汉带进了设计行业。

后来我自认为过了新手期，可能也听腻了之前老师的课（那个课不设时限），再加上朋友圈总有人晒入职BAT，就有点心痒痒，想去看看所谓的高阶课到底长啥样。于是第二笔高额付费，为了升职加的buff——3780元。![](img/465183af7eb30fd0baaf748331436937.png)

结果挺意外：内容对我来说太基础，很多知识点早听过了，只是换了个讲法。课程本身不差，只是不适合我，更适合纯小白。但钱不能白花，我当时本来就是冲着研究人家的交付模式去的。这一研究，我心里冒出句话：就这？那我也能教。设计师的终点，果然还是卖课。![](img/936e90da39c9e0a0bb4fd94d0993e904.png)

当然，这话有前提：不讲流量端，单说做PPT、站上讲台讲课，我在公司做过不少技术分享，这点自信还真有。设计圈的老手都清楚，底层方法论翻来覆去就那些，换身皮、换个姿态而已。这次经历，也为我后来做设计IP埋下了伏笔。

再往后，设计圈和自媒体圈都绕不开那个“某日记星球”，我当然也进去“观摩”了一圈。加上各种知识星球和资料，光主业相关的花费，保守估计1.2万。觉得多？还没完——副业这条路上，我做过外卖CPS、淘客、IP训练营、视频号、闲鱼、📕虚拟、📕无货源，还付费学过写作课（没错，就是那个你以为我天生会写的东西）。各种星球更是数不过来，分散在不同时段，少的三四百，多的三五千，有被割的也有被认真带的。有些项目连课都没报，买几块钱盗版课就下场了；有些就买来了解下玩法。就当1.5万吧，实际上只多不少。![](img/be2eca868108a05581bfca736334e07d.png)（嗯，这本书我已经熟读并背诵了。）

七七八八加起来，2W+就这么花完了。写这些不是卖惨，而是想说：这些学费，足够让我对知识付费这件事有点发言权。

## 二、训练营和私教，到底在卖什么？

知识付费的形式很多，小到一份文档、一段音频、一场直播，大到训练营、私教陪跑。从主流看，绕不开这两种：训练营和私教。

### 训练营：小班课的真相

有个看了我上周精华帖的朋友来问我：训练营是不是就是交钱、拉群、甩资料，剩下的全靠自己造化？对新手特别不友好。这话对一半，也不对。

训练营本质就是小班课，一对多。通常由一两个或三四个老师带班，资料就是上课内容，包括文档、录屏、直播。说交付好的，基本指的是课程内容完整、体系化。老师也会在群里答疑，群里问、私聊问都行。当然，这是不割韭菜的营。割韭菜的营，交完钱就人间蒸发，没人搭理你。

这种模式下，成材率逃不过二八定律：只有10%到20%的人能做出成绩，剩下的80%基本陪跑。别怀疑，不管课程是百万大佬还是千万大佬发售的，也不管内容多完整多独特，定律都一样。我自己就做过那80%的陪跑，我承认我没那么神，做啥成啥。

为什么会这样？原因很多。有些人报名前根本没有了解过项目、课程和老师的授课水平。只是觉得“跟着报，就能赚到十万八万”，冲动付费后，拿不到正反馈、坚持不下去、卡住了不知道问题在哪。群里不敢说话，鼓起勇气问了又听得似懂非懂，怕丢面子不敢追问。社群里的热闹跟自己无关，闷头做没成绩也没人交流，最后失望、沮丧，怀疑自己被割。

想想看，这个场景是不是很像12年义务教育？社群就是一个小班级，同样的老师、同样的课，但不同的学生、不同的基础，注定会分出三六九等。成年人世界也一样，个体差异往往就决定了你的上限。学生时代总有人考前随便翻翻书就拿高分，那是天赋型选手；也有人靠勤奋堆出好成绩，那是努力型选手；还有一群人怎么努力都平平无奇，说难听点，真不是读书的料。放到项目上，就是不适合——当然，你得先达到努力的标准，再谈适不适合。

再看看训练营里那些赚到几十万、上百万成绩的学员，老师的作用更多是辅助，别天真地以为全靠老师教得好。起决定性因素的，是学生自己。严格说，是互相成就。人家自身硬实力强，执行力拉满，甚至已经组建了自己的团队，学习能力和悟性都在线，自然能成事。师傅领进门，修行靠个人。能带你入门，就是传道授业解惑能做到的最大贡献了。任何项目、任何技能的学习，都是这个理。

更何况，很多人的学习能力、认知能力和悟性，真没到“给一份课程就能全吸收”的程度。新手要的不仅是课程喂到嘴边，还得嚼碎了喂。所以，很多训练营主可能是个厉害的大老板，但未必是个合格的好老师。学员一多，也确实很难照顾到每个人的权益。

如果你真想报某个训练营，也认准了某个人，我的建议是：
1. 降低预期，别以为一进去就能赚多少；
2. 钱都交了，就放下面子，不耻下问，反正没人在意你，不问亏的是自己；
3. 这种形式更适合有一定基础、自学和沟通能力的人；
4. 适合本身就喜欢一群人一起做项目、认可社群氛围的人；
5. 甚至可以先去搞个盗版课感受下，自己先跑跑看；
6. 最后也是最重要的——坚持。

### 私教陪跑：保姆级服务

现在很多新手甚至老手，会遇到这些问题：课程某个地方看不懂、实操时误解了某个步骤、做着做着就想放弃。训练营里的一些坑，私教确实能填上。

私教的意义更多在陪伴。它不只教知识和技能，还提供情绪按摩、持续跟进，有时候1V1被催着打卡，自己都不好意思偷懒，相当于被动提升执行力。说白了，就是保姆式服务。当然，我说的是不割韭菜的交付。

因为交付重，这类服务价格也不便宜，普遍两三千，有的直接到一两万。如果你真有决心做，又怕在训练营里成为陪跑，可以考虑。但请记住：赚钱最终靠的还是自己。私教也好，训练营也罢，你主观能动性跟不上、执行力拉胯，神仙陪跑也救不了。

## 三、不付费，就真的学不会吗？

很多人调侃，自己报了一堆项目，钱没赚到多少，倒学会了知识付费。那曾经的韭菜，现在赚到钱了吗？小白做项目，一定要付费吗？

### 先搞清楚“小白”和“普通人”

大家常说的“小白”，指没做过任何副业项目、对互联网玩法毫无概念的人。“小白”其实是针对项目而言的。但有个更值得关注的维度——你是怎样的“普通人”？

最近总有人跑来问：A项目、B项目、C项目，我该报哪个？我是小白，哪个更适合我？小白我懂，但“普通人”你普通到什么程度，我真不懂。举个例子，你想做视频电商，最基础的就是剪视频。拿抖音带货来说，你连100个视频都没产出过，就没资格说没效果、没爆款、赚不到钱。而剪100个视频的途中，你会经历：学项目变现逻辑、学剪辑技能、学爆款逻辑、学选品思路、学时间管理……全是细碎的东西。做项目不是看个文档、听门课就完事的。

再说说“普通人”本身。我不了解你的过往、职业、背景、性格，也不知道你为了搞钱愿意牺牲多少玩乐、能吃到多少苦。咱们先不谈赚钱，就说学剪视频这件事：你的学习能力够不够？你剪视频感不感兴趣？能不能继续做下去？学习和坚持都是反人性的。在拿到正反馈之前，你不知道自己能不能扛过项目前期那段痛苦、煎熬、暗淡的寂静时光。这几个词我特别加粗加黄加红，希望你能多念几遍。所有项目都是这样，谁要是跟你说哪个项目赚钱很简单，那基本是在骗你。

负责任地说，没有人能替你判断什么项目最适合你。赚钱这条路，你得自己走，多试、多体会，只有自己下场，才知道哪里是坑、哪里有路。而你能比别人多坚定一点、多执行一点，就已经不普通了。这个道理通用。把项目名换掉，把“视频”换成对应平台的内容产出，全都成立。比如闲鱼，不要上来就问能赚多少、难不难，先问自己：为了赚钱，选品、上品你能坚持多久？闲鱼的上品，就相当于抖音的视频。以上这些，浓缩成一张图就是——![](img/eb51676e38b96a1c366e9f920549c6df.png)建议你点开大图，多看几遍。

### 为什么你会付费？

相信大家🛰️里都加了不少IP或知识付费从业者，他们朋友圈10个里大概8个是这样的画风：![](img/76dbcdfefd9e1861e59c36d6c946d25c.png)不是订单截图，就是聊天截图，要么就是付款截图，再配上👸号一整套组合拳。赶上红利项目，更是猛打猛推。![](img/29d2fb3bfb7508e4c23d9e6eb504663d.png)就差直接喊：快打钱！打完钱你就能像他们一样赚钱！一次两次你还能忍住，天天刷，很多人就真信了。

这就是典型的从众效应，说人话就是随大流。好像大家都在跟着他学，好像大家都赚到钱了，于是你开始怀疑自己的判断：别人都行，我为什么不行？掏钱，加入！但我要说，晒单截图不一定都是假的，这个需要你自己判断。只是，那些做出牛逼成绩的人，背后的付出你看不到，他们也不会告诉你。

你能看到的，是不断渲染付费的重要性，以及付费之后赚钱有多简单。实际上呢？报名后你才发现，离成功还差了一大截执行。试了几天，没有正反馈，放弃，找下一个项目，被对方的话术继续迷惑，又掏钱，再试几天，又放弃，循环往复。很多人总是迷恋付费和开启新项目，却从来不思考每个项目到底为什么失败。说到底，多数冲动报名都是因为“跟着做就能轻松赚大钱”的幻想，几万甚至十几万。醒醒吧，不存在的。

你有没有想过，付款之前，你根本不知道产品服务到底是怎样的？你只看了几张订单截图，就开始幻想自己也能立刻赚钱。大多数人只是被营销推着付款，连“我愿意为这件事付出多少时间”都没认真想过。

### 那到底要不要付费？

如果自学能力差、信息获取能力也不行，经济条件又允许，付费确实能帮你短期内快速上手。我入行设计时感触很深。小白阶段什么也不懂，隔行如隔山，最快的方式就是找人带。与其花大把时间自己摸索，付费是效率最高的路径，没有之一。我现在能写文、做IP、有正反馈，也都是交了学费换来的。

问题在于，怎么选对的付费对象？割韭菜的太多，防不胜防。知识付费水深，甚至有人直接把知识付费和割韭菜画等号。给你两个筛选原则：

#### 少关注结果，多了解过程

不要只看他说了什么、有多少人付费、哪个月入过万。也别被百万豪车、千万生意晃花了眼。我不是说这些都是假的，而是说：这些和你自己能不能做成，真没太大关系。它们只能当参考，不能当依据。你跟他混，能不能成，最该关注两件事：一是自己的执行力和付出能有多少；二是他的交付过程和服务质量。这两点足够了。

其他东西，基本都是为了吸引你付费而生的营销内容，利用的是人性中的懒惰、贪婪和慕强。这就像买彩票，明知道中不了，还是想试一把。现在你总该明白，为什么明知是坑，还前赴后继往里跳了吧？那有没有一个IP，真能教出随随便便赚几十万几百万的学员？当然有，梦里什么都有。

还有一种特别好筛选的：如果某人的朋友圈除了晒单、晒收入之外什么都没有，那大概率是割的。不信？自己去付个费试试，被骗了再来给这篇文章点个赞。

#### 小心大V陷阱，别盲目迷信权威

上面说了，把握住那两点就行。权威和大V，不代表就一定适合你。前阵子，一个设计师朋友跟我聊他做的📕无货源，已经坚持一个多月还没出单，这是很多人都会碰到的状态。他付费了一个粉丝20W+的大V的📕电商陪跑，够权威了吧？这是他跟我吐槽的聊天记录：![](img/94fd0dc027e4f7972dcc4cb376406d0b.png)![](img/536a1c53cc978587b03b9d0fd2368b1a.png)说好百分百全程陪跑，最后只安排了个助教，进去问问题，回得慢不说，翻来覆去就“好的”“是的”“可以呀”。你说这种服务算不算割？但现实里真的很多。具体内容我都打了码，点到为止，容易得罪人。我只能说，这行水深，你真把握不住。多思考、多对比、多分辨总没错。

### 关于试错

不管你是第几次做副业项目，失败了也好，没做起来也罢，都要尽可能多参与。在这个过程中学到的技能、提高的认知，都是你未来探索下一个副业的资本。跨出第一步，就已经迈出了舒适圈，在我眼里就是成长和进步。

### 付费了，就一定能赚钱吗？

这几乎是每个新人报项目前最爱问的问题。能理解，毕竟花了钱。但这问题真被问烂了，也被答烂了：赚多赚少，全靠自己。

我免费带过一些朋友做项目，真免费，相当于陪跑。本来不想带，但对方硬要我带，碍于关系和情面，我答应了。他本职是Java开发，也算互联网同行，我本能地觉得他基础认知应该没问题。结果打脸来得太快，做了三天，他这么回复我：![](img/9984574a760056d9e3d39200d5930644.png)（淘客项目）后面那个否认四连，着实把我震撼到了。他账号才发了4篇，没有一篇是按教程走的。看在关系份上，我也没好意思回什么。所以你看，就算有人免费带，自己不配合、不努力，什么项目给你都白搭。

大多数人都想两三天就看到结果。我直接说：整个地球上都没有这样的项目，死了这条心吧。做电商也好，其他项目也罢，数据总有波动，一下山峰，一下谷底。很多人想一夜暴富，有赚100万的雄心，却连认真干一周的欲望都没有。如果真是这样，那就放过自己吧。躺平也是一种生活方式，不是所有人都需要副业、需要搞钱。有时候躺着真的挺好，何必折磨自己？又想搞钱，又不想付出和坚持。相信我，放弃也会让生活轻松很多，幸福不一定非要赚大钱。最后送大家一句话：坚持，是最难的基本功，请好好修炼。

## 四、为什么那么多IP都在做训练营？

最后从IP的视角说一句：为什么大家都爱做训练营？答案很简单——一对多，最省成本，一次时间可以卖给很多人。而绝大多数人的本性是懒的，你去看那些训练营、打卡营，有成绩的、坚持打卡的，永远不是大多数。所以训练营的交付成本低，自然成了很多IP的选择。

说到底，只要样本量拉满了，那个真正能出成果的少数群体，完全足够支撑起下一轮招生宣传。顺着这个思路去看，做知识付费绕不开训练营模式，这点很正常，我也会做。

真正卡住人的点不在这里，而是在付完钱之后怎么克服自身的拖延。毕竟变现是自己的事，报了营也不能指望讲师天天追着你完成作业。

最终是选择当那醒来的二十，还是待在躺平的八十，主动权一直在自己手上。

### 别总拿别人来膈应自己

我自己深耕知识付费这块也有一段时间了，坦白说，就算交付做到每天检查作业、验收成果，坚持下来依然很难，这里面有外部原因也有个人原因。

同一批学员，有的人领悟快一周就开单了，有的人还在纠结怎么选品开局。这种差距，本质上是背景、资源和执行力带来的学习速度不同。

所以无论是报营还是买服务，变现的路从来都不轻松。不要只盯着那些晒成绩的案例去焦虑。尽量屏蔽掉别人的收入、别人的进度、别人偶尔的爆款项目，保持自己的节奏，老老实实把当下这一件事做好，才是最有效的成长方式。一旦开始横向比较，情绪只会把你拽进焦虑里。

### 流量够狠，晒单就够了

我自己的体感很直接，一张订单截图发出去，咨询量立刻上去。现阶段知识付费招生最有效的手段，依然是晒单。

不晒的话，没人知道你的战绩，甚至不知道你卖什么。晒了之后，就会有部分人缺乏判断直接冲进来报名，哪怕他其实没时间没执行力。最终买不买，决定权在他。

这就是所谓割韭菜的逻辑：只要手里有精准流量，就不用写长文、不用琢磨交付内容，每天发订单截屏、付款截屏、好评截屏就行。

剩下的事就是持续引流。割一轮是一轮，市场上永远不缺冲动消费的群体一批接一批，这也是大量营销号能长盛不衰的原因。

作为设计师，我今天把话说开：这种截图，我一天能批量给你做几百张，做出来还很难被识破。
