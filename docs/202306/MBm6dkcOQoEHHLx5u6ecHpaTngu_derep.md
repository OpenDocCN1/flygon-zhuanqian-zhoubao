这项目本质上是信息差加技术差，甚至带着点“暴利”“躺赚”“空手套”的味道。那它到底做什么？一句话：帮国内想用 Spotify 的人顺利用上它。

估计有人要问：Spotify 是什么？简单说明一下。你平时用的 QQ 音乐、网易云、酷狗，都是国内音乐平台；而 Spotify 是全球范围的头部音乐平台，跟 YouTube Music、Apple Music 是同一梯队。只是它在国内名气不大，普通用户接触得少。字节也模仿它做了个“汽水音乐”，界面都差不多。搞跨境、出海、独立站的朋友容易把它和 Shopify 弄混，但它俩完全不是一回事。至于哪个软件更好，我不评判，自己日常也不用，我只在意一件事：市场有没有需求？有没有商机？能不能赚钱？

光看关键词，对需求的认知还很浅，下面逐一拆开说。

先讲“Spotify 怎么注册”。聊这个之前，提一嘴今年最火的新赛道ChatGPT。你觉得注册一个 ChatGPT 账号难吗？你说不难，我很理解，因为你在生财有术，这里有航海、风向标、保姆级教程、无数精华帖。作为头部搞钱社群，生财沉淀了海量信息，哪怕你没刻意关注 AI，被动也吸收了不少。但别忘了，这是典型幸存者偏差。实际上，ChatGPT 都发布大半年了，大部分普通人依然没用上，也搞不定原版注册。

原因就俩字：门槛。所以市场上才有卖号、镜像站这类生意，他们解决的就是这个“门槛”。Spotify 和 ChatGPT 一个道理，同样有高高的使用门槛。它还没进入大陆市场，官方封锁了大陆 IP 访问。普通用户别说注册了，连下载都费劲。想要注册成功，你需要一个靠谱的“梯子”，还得有原生 IP 才行。很多人连官网都打不开，就算开了“魔法”，也会被系统提示检测到代理行为，导致注册失败。这种“IP 质量检测”现在已经很常见，TikTok 甚至更严苛，还要检查设备环境、语言等；Steam、Instagram 这类平台也有类似的机制。

![](img/1c0bc4bd2c5bdb02749b03d5f3032ed1.png)

但这种门槛对我来说不算啥事。搞一个 IP 质量高的工具就解决了。很多事你知道，不代表别人知道；你觉得轻松，别人可能觉得比登天还难。尤其是你自己擅长领域里那些习以为常的操作，其实对普通人来说都是障碍。这背后就是信息差/信息不对称，而且“不知道”的一方往往是绝大多数。平时不刻意想，感受不到这一点，但这个现象一直存在。这背后的道理，可以用“专家盲点”和“知识的诅咒”来解释，亦仁之前推荐过飞书的《认知偏差手册》，维基百科也有专门词条。

再顺着讲：Spotify 注册和 ChatGPT 注册逻辑相同，最大的区别是——普通用户搞定注册、下载后，以后用 Spotify 听歌完全不需要“梯子”。就这么一件“小事”，竟然构成了这个项目利润的54%——25.2万，全是纯利润来自代注册。注册需求讲完，其他几个需求简单带过，篇幅有限。“怎么解除14天限制”相对次要，放到后面再说；“怎么下载”也好理解——Spotify 在国内应用商店上架极少，安卓得去 Google Play，iPhone 得用外区 Apple ID；“怎么充值会员”也麻烦，不支持微信、支付宝，得用海外银行卡付款，跟 ChatGPT 付费一个道理。

先用最小 MVP 验证需求。我只做两件事：搞定注册、搞定下载，让客户能真正用上。会员等增值服务暂时不做。说干就干，我找来老朋友@涂白，用 PS 做了一张海报，方便引流时发给客户，既能替代沟通话术，也显得专业。@涂白是我初中同学，从那时起就在互联网上折腾，特别厉害的一个人，我懂的他懂，我不懂的他也懂，之前搭档过，很靠谱。起步时没有正反馈，我不敢把价格定高，试探性地标了4.99元。

最小 MVP 跑通了，从0到1完成。正常人都会想到放大。@涂白 当时正好项目空窗期，有好事哪能忘了兄弟？拉他一起入伙，五五分成。两个人并肩作战，远比一个人单打独斗强。我这人最大的毛病就是懒，但懒恰恰是推动效率的引擎。所以我决定把整个流程做成全自动化：售前、成交、交付、售后，统统自动。

引流来了，怎么接？先幻想一下：万一每天流量真做到1000人，个人微信号肯定接不住。好友数上限、每日加人限制、风控问题，开小号也很麻烦：养号、防封、设备管理，全是我不熟悉的领域。而且微信功能太少，不能群发，管理效率极低，用第三方工具又怕风险。

淘宝行吗？也还行，但我还是放弃了：第一，没有私域积累，同行虽然能引导客户进私域，但链路长且对抗平台规则；第二，淘宝此类目竞争者多，价格透明，蛋糕不大却很多人分；第三，对交付场景不便利。想来想去，公众号服务号完全满足需求。

![](img/a3e987bc195a22d7b93102d8fec1681c.png)

![](img/e95039cfb120b5ac5a629aada2e044cb.png)

先说说之前的交付方式：客户加微信，话术聊完转款，我再手动发下载链接，再人工注册账号。效率太低了，天花板一眼可见。

为了替代人工手动注册，我搭了一个“在线自助注册 Spotify 账号”的 H5 页面。这个页面除了官方注册需要的常规项（邮箱、昵称、密码等），额外增加了一个“注册码”输入框——用户必须购买注册码才能用这个网页注册。原理其实简单：前端 JQuery 一把梭，后端 Java 写逻辑，再买了“原生 ip 代理”，模拟 HTTP 请求，将用户提交到我们服务器的注册数据转发到官方服务器，本质上是“中间人代理”。

![](img/0b7142be54650c1f03da43e57a3c886f.png)

但坑还是踩了不少。一开始走网页注册协议，必须过 Google Recaptcha 验证码，这个验证相当恼火，我去对接了打码平台，后来发现移动端注册根本不需要验证码，于是脱壳、逆向 APK，扒出另一套注册协议，成本大幅下降，速度反而加快，算是降本增效了。另一坑是，最初用魔法工具的内核 V*ray，单独跑在服务器上，开放端口给 Java 程序做代理，结果 IP 重复率高而且不稳定。后来才醒悟可以直接买“原生 IP”，稳定性秒杀之前一切问题。所有注册障碍，我们都帮客户清理得干干净净，让对方创建 Spotify 账号像注册 QQ 一样简单。人嘛，天性就是图省事。且不说绝大多数人根本搞不定；就算搞定的，也得花时间研究。痛点就在这里。而我一分钟就把这事办完了，这就是价值。

再往下：用户付款后，怎么把链接发给他？我从 Github 找了一套虚拟产品自动发货商城源码，简单调整后，买了腾讯云的域名和服务器，直接部署。用户下单后，系统自动发给他一个包含注册码的链接；下载同理，只是换成安装包链接。支付渠道最初对接虎*椒，后来转向微信官方接口。

![](img/47517d682c6153949d6f770a7f2ca2e8.png)

整个路的最后两块拼图：会员充值和解除14天限制。背景先说一下：Spotify 在不同地区的曲库、会员定价都不一样。不开会员的话，不能自选歌曲，只能像电台一样随机放，还只能试听片段，中间还插播广告。很多同行一开始就在做会员代充，因为大家都看得到差价，这是显而易见的商机。但这同时也是一个“思维陷阱”，如果我也被这个视角锁住，就不会发现盲区里那个最大的需求：注册账号。因为更多人连“用上都做不到”。而我先替他们解决账号问题，之后等他们体验完，自然而然会遇到“充值会员”这关。有了第一次成交和信任基础，再回来复购就很顺理成章。

会员充值的麻烦在于外币银行卡。我们实在没找到好渠道，干脆找了几个同行谈了下，让对方赚点佣金，做起了合作：定价半年69，整年129，利润在四成左右。接着照搬注册那条路径，我又写了个自动充值网站，让用户下单后自动完成。

![](img/a65d5f29bcf233a9d8d22dab63d576b3.png)

前人常说，你很难赚到认知以外的钱。但这次我发现，信息差一直在，只是看谁愿意躬身下场，看见“没意思”需求背后那一条完整的路。

在真正选定Spotify之前，我把七八个软件的需求挖了个遍，花了一周左右做分析、测试和验证，结果全部没成。最后才把目光落在这个音乐软件上。这个项目看着简单，其实里面的弯弯绕绕不少。

![](img/7c87de6b6900ed1e42438dc3e73fc0de.png)

先说会员这块的技术。开通会员比注册账号复杂多了。Spotify的Premium分成单人、双人、家庭组等好几档，家庭组是性价比最高的选择。主账号付款之后会生成一个邀请链接，最多拉进五个子账号，子账号不需要再付钱，就能共享会员权益。那我们要做的事就很清晰了：准备好已付费的主账号，把客户的账号自动拉进家庭组。但“自动拉人”这件事，包括管理主账号的家庭组，处理起来有相当多的细节。

![](img/fccdc2bb57e0df07f137234d62a35ad4.png)

这是当时的程序流程设计图。期间考虑过克隆号，但会员稳定性太差，放弃了，最后决定主要靠协议实现。

![](img/2c3d1803aeedf645a9e1686c220960f6.png)

会员开好后，系统会通过微信模板消息告诉用户，同时引导他添加专属客服。

再解释一下那个坑了无数人的“14天限制”。这个限制是怎么回事？第一，Spotify不开放大陆注册，必须走海外IP；第二，账号的归属地会随IP自动变化；第三，用户在国内直接登录，系统会认为你在国外“旅游”；第四，官方允许你旅游，但只给两周，时间一到还不“回国”，就封禁登录；第五，如果你开了会员，这个限制就不存在。说实话，一个听歌软件搞成这样，我们也很不理解。这个限制是大量用户的痛点，也给售后挖了不少坑，因为总有人不愿意开通会员。于是我们做了一个在线解除限制的网页（见上图），但并没有拿它收费，只是拿来解决售后问题。

![](img/b2f02d0d1cf87afb18c0a4c233f7ed5c.png)

具体玩法很简单：用户把账号密码填进来，我们自动帮他“回国登录”一次，就能再续14天“国外旅游”时间。怎么实现自动“回国”呢？我用Auto.js写了一个安卓脚本，部署在云手机上。用户提交之后，Java后端通过WebSocket和安卓脚本通讯，把任务推送下去，脚本自动用代理登录Spotify。完成后微信模板消息会自动推给用户。

![](img/2550624f493e4f1ffcca6e5a9df3bb5d.png)

后来客户量上来了，脚本这套流程渐渐有点跟不上。我们索性逆向了一套Spotify的APK协议，直接靠网络请求完成登录，不需要脚本了，效率一下子提高了很多。这个环节非常耗时，因为Spotify用的是Protobuf，不是普通HTTP，做过逆向的同学应该知道有多么麻烦。

![](img/aa4965a27f3f8d22a4c6c156392ad240.png)

业务自动化做完了，我还迷上了“监控一切”。商城代码和服务端代码都是自己写的，想怎么改就怎么改。于是我就接入了Bark，给iPhone加系统级推送。现在用户下单我能立刻知道，程序坏了也能立刻知道，代理IP或打码平台资源不够了、库存不够了，都有推送提醒。还能设置不同的分组、图标和铃声。后来我陆续加了十几项监控，一切尽在掌控的感觉，太舒服了。做到这个程度，日接一千单完全不是问题。

![](img/d32d398ef848d64bda5ad374a3d71f86.png)

然后是售前优化。成交的基础是信任，售前决定了转化率。公众号是我们最大的流量入口，而关注后的自动回复是用户看到的第一个信息，重要性不言而喻。当时规划了未来多条引流渠道，所以必须想出一个通用文案，不管用户从哪里来都能无缝衔接到下一步。这条欢迎语后来证明效果不错，甚至被好几个同行直接抄走了。

![](img/84787a30e6892e2738657db825e0168f.png)

我们还针对每个需求单独写了导购文章，放在公众号里，手把手教用户怎么一步步解决，顺顺利利走完交易流程。商城里每件商品下面，除了文字介绍，都配了一个视频，把购买全过程、买完能得到什么、有什么效果，甚至怎么用微信付款，全部展示得明明白白。这些看起来很简单，却让我们的转化率一直保持在70%以上。

![](img/9c89a1183b0e62ad92365daafe034184.png)

客户基数一大，什么人都会遇到。最好的办法，是把每个客户都当成小白，当成“三年级小朋友”。然后换位思考，模拟用户走一遍全流程，把所有卡点提前解决。核心原则就是：降低客户的决策成本和理解成本，用户路径越短越好。任何多余步骤都在损耗转化。

![](img/2505eefa391d0d9e89f5fb3ae9117119.png)

售后我们分成四块：第一是前面的14天限制；第二是Spotify的风控，新号注册后几天内可能会被官方随机重置密码，客户必须重设；第三是会员代开相关；第四是各种琐碎问题。前两块我们都做了在线小工具，引导客户自己去操作，自动化解，不需要人工介入。其余大部分靠企业微信的“微信客服”接到公众号，再加智能回复过滤掉常见问题，最后人工处理剩下的部分。

![](img/95aac145cc65c3ba5bc0ec8e850deb51.png)

项目跑顺以后，进入引流放大阶段。我们最初想的是全平台覆盖，包括百度SEO、贴吧、微博、豆瓣、小红书、抖音等等。后来真正重点做的只有小红书，其他基本没碰。公众号做到了七万多订阅，但说出来你可能不信，我们总共只发过不到五个笔记加两个视频。很长一段时间里我们完全没引流，但流量一直没断过，公众号每天照样新增两三百个关注，特别反常识。后来分析加问卷调查，发现了真正的流量构成：第一，用户自发分享，在抖音、小红书、微博上帮我们喊；第二，帖子数量够了，质变就来了，一搜Spotify，我们基本霸屏；第三，约24%是老用户带新用户。当时没做任何引导、奖励、激励，就有这么多人主动宣传。

![](img/b1bae0ff73f21b8b25feb451bc76495a.png)

知道真相后，我们赶紧给用户发红包表示感谢。之后每一次流量小爆，都想办法找到发帖的人，发个红包。后来红包越发越多，干脆写了篇文章搞裂变返利，发帖就给12元，基本覆盖了注册和下载成本。奖励金额我们设得很高，但算下来照样赚钱。效果那叫一个好，甚至有用户在某篇笔记下面问我们是不是买推广了。其实我们也试过小红书付费投流，但手续太繁琐，没搞定就放弃了。

![](img/041f659b29ad90e6a08bf9bb5f3d4bdd.png)

说实话，在引流这件事上我们投入得很少，也很惭愧。我们明明知道这个阶段引流非常关键，却把精力花到了别处，主次不分。现在想想，就像一边清醒一边喝醉，不然数据会好看很多，深刻反省。

![](img/eac14efd729e8106bf89af203a6fbf75.png)

“风”来的时候，一切都是最好的准备。装上订单推送那会儿，提示音响起总是很兴奋，一小时也就一两单。后来多次小爆，最高潮时每一分钟都在响，人慢慢就脱敏了。项目跑了三四个月，到了12月14日，起风了。记得那天下午，手机上的订单提醒响个不停，差不多十秒一单。我一开始没多想，让它响了俩小时。后来觉得不对，因为根本停不下来，频率还在不断上升。再往后，订单跟加特林似的连续喷射，一个订单还没播完，下一个就来了。最后订单量太大，服务器直接被搞爆，损失了不少单。放点聊天记录，感受一下当时的心情。

那波流量持续了两三天，最后的数据我没记太清，但总之顶得上之前一个月的GMV，还不止。那一刻真的觉得，钱像是从天上掉下来的。我们还调侃，之前的最高记录也不过才一万。事后复盘才发现，来源是一位艺人在Spotify发了新歌，粉丝疯狂打榜，然后某位大V发了条微博，推荐粉丝来我们公众号，于是粉丝蜂拥而至。我的思考是：赚钱是指数级增长的，前期少一点慢一点很正常，但某一天你可能会赚到过去一年的收入；“领袖效应”这种事是可以主动制造的；“水能载舟，亦能覆舟”；再小的需求，也不要轻视。

![](img/637f7350c738296a88f2218741925ba9.png)

项目背后的事，远没有表面这么光鲜。我踩过一堆坑：需求挖掘阶段，我先试了七八个软件，花了整整一周都无果；备案折腾，等待审核、调CDN、对接支付渠道、搞公众号各种配置；网站因为部分元素像Spotify官网，被谷歌认定是钓鱼欺诈，所有iOS用户都打不开，申诉审核了一两周；网站程序前前后后改了400多次；新注册的域名被微信拦截，跑去官方论坛发了好几封邮件，折腾一周才解开；还有同行直接照搬文案和图片，再加价格战截流……这些只是随手就能想起来的，冰山一角。很多困难是我一开始根本预想不到的，做着做着才冒出来。如果真有人在一开始把全部困难摆在我面前，我大概率会被吓退。但回头看，那些坑都是垫脚石。那些没打垮你的，终究会让你更强。所以前期别想太多，问题来了就解决，逢山开路，遇水架桥就好。

![](img/b3d1aef50b88f6ad2a3e5a3fc1111cdc.png)

然而后面来了一尊真杀不动的大佛。1月10日左右，公众号因为举报被永久封停。我们急了十分钟，启用备用号。2月16日，备用号也被封了。第二天想了想，主动放弃，不再折腾。Spotify毕竟只是一个没进大陆市场的听歌软件，被封可能因为政策收紧，也可能就是被恶意举报。既然封了肯定有原因，没必要和平台对着干。虽然之前很多同行还在闲鱼、淘宝或公众号上做，但我依然选择退场。为什么不破不立？不赚最后一分钱，见好就收。

最后做个复盘总结。我的问题很明显：一是完美主义陷阱，把大量精力耗在细枝末节上，忘了抓重点；二是事必躬亲，没有早点招客服，人力杠杆没用好。这个项目暴露出来的思路其实可以举一反三，比如怎么变通成新项目？如果你是操盘手，会在哪个环节做得更好？怎样进一步放大？矩阵？强化关键环节？和同行合作做上游？把客户变成盟友？这些都是可以继续聊的问题。
