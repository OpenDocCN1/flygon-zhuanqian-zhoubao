# 单店90天冲到100W，小红书不囤货开店实操全拆解

先说结论：这个项目不是理论，而是我们真跑出来的。团队里表现最好的那家店，不到90天，成交额做到近100万，毛利超过50%。文章比较长，但每一步都能直接照着做。

## 选择这个平台的原因

每一轮电商风口起来，都会催生一批靠着信息差赚钱的卖家。从早年的淘宝，到后来的闲鱼、拼多多、抖音，再到跨境电商，每个阶段都有赢家。但到现在，老牌平台竞争已经白热化，新卖家想短期内拿到成果，明显变难了。

而种草社区的逻辑不太一样。用户在这里不是先比价，而是先看真实体验和分享，被内容打动后就顺手下单。一条内容如果爆了，订单往往会跟着上来。整个过程很直接，不用像传统货架电商那样被反复比价。这也是我们选择集中精力做这个平台的核心理由。

平台自己也在发力。今年4月开始内测笔记分销带货功能，逢年过节和大促还会给商家额外的流量扶持。![](img/bfad4442bdd440af933374cb4a168007.png)

想拿到内测资格，只要满足两个条件：第一，关联账号的粉丝数到1000；第二，店铺完成实名认证。这两个门槛都不高，按对方法执行，权限会陆续开放。

## 团队成绩和试错成本

我们去年11月正式入场。刚开始也是摸着石头过河，有个店铺发了一周的内容，浏览人数还是十位数以内，全靠反复优化才等到起量。那段日子确实磨人。![](img/89b1d792beda6fc2c50878d8fb935bcf.png)

好在一个季度的坚持换来了结果。目前最好的单店，上线不到三个月，成交额接近100万，毛利率在一半以上。像这样的店，我们手里有十几家。整个项目组只有5个人，每月净利保持在30万左右。这件事给我最大的启发是：生意行不行，不取决于人多不多，而在于模式是否足够轻、打法是否足够准、能不能稳定复制。

如果你正在琢磨新方向，不妨用这个模式做个低成本测试。开店保证金大多数品类只要1000块左右，试错的代价很小；但错过一个窗口期的代价，可能会非常大。

## 一个耳饰案例

说个我们真实跑过的例子。当时在站内搜索“耳钉”，按销量排名看到一款耳饰，前台展示7000多件，点进详情是7764单。随后到1688找同款代发渠道，单件含邮成本约6.3元，站内卖48元。![](img/b7ca690759b71e4c4da5c0dd986abf64.png)

单件利润就是48-6.3=41.7元。乘以7764单，总利润超过32万元。![](img/365961b9d734f7e0198778da44e93f74.png) 对，就是这么一个不起眼的小饰品，净赚30多万。![](img/86dd87116f6b5bc2254f87a9e15e5f93.png)

这笔钱可以用来买一辆还不错的车，也可以在三线城市付个首付。对大多数普通人来说，这可能就是改变收入水平的机会。而且这还只是冰山一角，其他类目里同样藏着很多高潜单品。

## 选品：先看热门，再用工具验证

选品决定成败，这句话在哪个平台都适用。我们的方法可以分成三条线。

**第一条：对标其他平台的热卖款。**
打开PDD，首页有清晰的类目导航，比如手机、食品、百货。每个大类下还有细分。拿百货举例，里面会再分出日用百货、家庭清洁、个护、收纳等。如果想做抽纸，先在PDD看几款高销量的抽纸，参考评价和整体走势，然后去站内搜抽纸，看这个品类在这里的热度和成交表现。如果两边数据都健康，基本可以确定是一款值得做的品。其他平台（淘宝、抖店）也按这个逻辑操作。

如果看中某个品类，可以从站内按销量找到标杆产品，然后去1688用识图找货源。![](img/c6f86efcd0153bc5c556d97a7d1d65e3.png) 比如你选择防晒帽，找到一款支持一件代发的产品，成本20元，定价39.9元，和竞对基本持平，这款品就可以开始做了。![](img/68948cf17bb327578d0fcf2919ccec52.png)

**第二条：盯住站内推荐位。**
能持续出现在首页推荐的内容，通常已经被系统判断为“值得看”，说明有不少人在关注。这些品拿来做试水，成功概率会更高。

**第三条：借助数据工具。**
灰豚、蝉妈妈都可以。这里重点说灰豚怎么用：

打开笔记检索，搜索范围除了笔记图片其他都勾上，过滤掉已经删除或隐藏的内容。时间可以选择近24小时、3天、7天、30天甚至90天，我们一般以7到30天为主要参考窗口。![](img/6d9fd9c1db9bc1f4233428c47873ed85.png)

想更精准，可以直接用产品词去搜，比如搜“耳饰”，只看笔记标签里带“耳饰”的那些内容，样本会更垂直。![](img/88058b5be1f613564bd9b964c055b75c.png)

搜索框下面还会出现关联搜索词，比如从“耳饰”延伸出“耳钉”“珍珠耳钉”“镶钻耳钉”，这些都是可以拓展的方向。![](img/e6f09de26d2c192a1f8c47a5cf0c0486.png)

还可以按笔记分类去逛。时尚类目下面有穿搭、发型、鞋靴、箱包、配饰、珠宝等细分。重点看近7天的数据，90天的也可以简单过一遍，有些类目会出现二次爆发。![](img/0a7a7c5fe1457f30686c53b0a0a53a3e.png)

另外，低粉爆文也能通过高级筛选卡出来。用点赞数、收藏数、评论数、关注数这些维度组合筛选，能发现不少潜力标杆。灰豚的数据偶尔有延迟，属于正常现象。![](img/6891f34d3973051f2644ca885467aa18.png)

## 写内容：别搬运，要重组

做内容的第一原则：参考热门，但不复刻。现在平台查重很严，直接复制粘贴很容易被判定非原创。

**视频素材处理**

视频素材需要混剪。但混剪不是简单加个滤镜、切两刀、换首音乐。比较稳妥的流程是：先把视频分割成小段，重新排列段落顺序，再给每段加上转场特效，最后叠入一层画中画，透明度调到1左右。这样一个流程走下来，才算真正做过处理。

视频格式支持MP4、MOV、MPV，画面比例建议16:9或9:16。![](img/e280c01d982f4073404ffc26b1dbefec.png)

**图片素材处理**

图片也要经过处理。先确认没有水印，并且足够清晰。处理的第一步是加滤镜、调整色彩明艳度，这个动作会直接改变图片的MD5值，让图片变成“新文件”。如果图上还有多余文字或杂物，可以用站内的消除笔清理，或者用符合氛围的贴纸挡住。图片尺寸推荐1:1、3:4、4:3，其中3:4观感最佳。

**文案重组**

笔记就是“画面+文案”，文案又包括标题、正文和话题标签。来用防晒帽举例。

我们拆解了几个高赞同行文案。第一个博主写道：“两个字，神帽！整个夏天都不怕晒，只要一杯饮料的价钱，还送眼镜和口罩。”![](img/1cda3c16edd7ee6059ee2301c19a1143.png) 第二个博主说：“直接宣布，这是我今年夏天最爱的防晒帽，春天的紫外线也很厉害，防晒要趁早。”![](img/8489945aa3d95006464f036ca27be356.png) 第三个博主反向安利：“千万别买它，我怕你被晒黑——因为防晒力太强，想晒黑都难。”

把这些亮点重新组合，可以写成一条新文案：
“两个字：‘神帽’！我宣布这顶防晒帽是我今年夏天的首选。千万不要买这个防晒帽，我怕你晒不黑！它颜值在线，防紫外线能力也很强。入夏以后，硬核防晒必须安排上。”

话题标签也可以参考竞对的亮点标签，直接合并去重。组合出来就是：
#防晒 #防晒帽 #防晒分享 #遮阳帽 #夏日必备 #夏日穿搭 #平价防晒 #物理防晒 #帽子 #帽子推荐 #百搭帽子 #平价帽子 #显脸小的帽子

标签词覆盖到位，配合文案就是一条完整可发布的笔记。

## 有货源怎么做

有自己货源的商家，同样适用这套打法，只是省掉选品环节。先到站内搜索产品的核心词，看这个品在这里的受众反馈和竞对成交情况。如果同行能稳定做到500单以上，说明需求成立，可以准备3家店同时铺货。以水果为例：自己有水果渠道的话，先去站内搜“水果”，研究爆款内容和销量靠前的商家怎么布局，再照着同样的框架上架自己的产品。
