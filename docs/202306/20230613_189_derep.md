# 我靠一个“每天发一张图”的约定，把跑步从三分钟热度变成了日常
作者：龙哥

过去我对自己的跑步，总结起来就是一句话：心很热，脚很懒。

闹钟响了想起晚，天气热了嫌闷，空气差了说雾霾，反正理由永远比脚步多。久了之后我甚至默认了，跑就一定是跑几天的“热身运动”，心里早就准备好了放弃的台词。

这次不一样，我已经连续跑了远超自己预期的时间。翻来覆去想，差别只在一点：我找了个每天互相交作业的跑友。

我们俩都是话不多的人。每天就两张配图，一张是今天的轨迹截图，配一句简短的“已完成”。没有唠嗑，没有督促，也没有谁迟到谁就罚款的规矩。

就是这么轻的互动，却把一件事钉死了。因为今天的图必须发出去。

所以哪怕早上出门赶不上，我就改到晚上灯下跑；下雨不想淋就绕着走廊慢跑；夏天太晒就挑一排树荫来回折返。办法其实一直都有，只是以前我只会找理由。现在目标只有一个：把属于我的那张图交上去。

有意思的是，他从没催过我一句，也没指责过我偷懒。为什么最后还是坚持了？

后来才明白，人人都想变好，只是身边太多拖延、摆烂、抱怨的声音，慢慢就把正向的人衬成了异类。环境一旦变得消极，坚持就变得费力。

而我们每天的互相打卡，无意中搭起了一个小小的正向场域。潜台词很简单：你可以随便找借口，我却在为我们说好的事不找借口。

看到对方照常发图的那一刻，自己心里会咯噔一下。那种“不争气的自己又冒出来了”的不舒服感，比任何外部压力都管用。我不想因为自己的松懈，把我们一起维护的这份清爽氛围给弄脏了。

就像走在一条被擦得干干净净的路上，你手里捏着鼻涕纸也会一直攥着等垃圾桶；可如果马路本就脏乱，一张纸随手就扔了。核心不是意志力有多强，而是你不想成为破坏环境的那个人。那种自尊心和责任感，才是把习惯撑下去的真正推手。

所以习惯到底是靠意志力硬扛吗？我现在觉得未必。环境和文化的影响，可能比想象中更大得多。

对个人、对家庭、对公司、对一座城市，都是如此。我们需要的也许不是更强的自律，而是一个让人不好意思偷懒的环境。![](img/5d534f6aaafbf2c5badc32571b24329b.png)
