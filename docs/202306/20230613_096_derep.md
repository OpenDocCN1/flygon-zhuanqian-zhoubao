# 一次想升舱的经历，让我看清了国航和南航的经营思维差在哪
作者：龙哥

作者：小马宋
2023-05-31

最近连续在路上跑，上周去广州开会，主办方订的是国航的经济舱。我到机场后就想着能不能加钱升到公务舱。结果这一番操作下来，国航和南航在经营上的差距，真的是一目了然。

先说工具。南航的APP里有「登机口特价升舱」这个入口，点开就能操作。国航的APP上这个功能图标放了很久，但一直是摆设，点不开。

再说地面推广。南航在值机柜台会有专人主动帮忙推销优惠升舱。国航的柜台这边，完全没有声音，问了才说。

再说价格策略。南航在帮你升舱时会第一时间先查有没有 999 元的优惠升舱名额，并且会提前把这个优惠舱位的服务限制讲清楚。国航这边，柜员说要先算一下，最后报给我一个 2100 元的手续费。我当时就说，我现在打开携程买公务舱也就 2100 元。她回我一句，那您随意。我当时气就不打一处来，转身就走了，打算上飞机再试试。

结果上飞机才发现，国航是机上不允许升舱的。南航以前我坐过，机上是可以直接升的。我就问空姐为什么南航可以，国航不行，她只是礼貌地笑了笑。

单独聊聊南航的地面服务感受。说实话，到现在为止，我见过最拼命在值机口推升舱的，就只有南航。

去年我从大兴飞深圳，值机的小姐姐先让我升了明珠舱，说商务舱已经满了。安检出来没多久，她🛰️给我打电话，说商务舱又空出来一个位子，可以直接帮我改签值机，🛰️转钱就行。就这样，我又从明珠舱升到了商务舱。

这种「能多赚一点是一点」的主动性，在别的航司身上很少见到。可能和员工的激励机制有关，但就旅客的实际体验来说，南航确实要更让人舒服。

这件事让我又想起我之前画过的那个「高效经营铁三角」：战略定好了方向，创新和效率才能变成真金白银的超额利润。

国航和南航，战略方向没准是差不多的，但把一个升舱小动作做出来的差异，就是创新能力和经营效率的差别。
