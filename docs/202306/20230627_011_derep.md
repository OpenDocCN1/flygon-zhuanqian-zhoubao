# 为什么同一条赛道，有人颗粒无收，有人却收获满满？——我的📕航海复盘

大家好，我是常常，一个和你一样在赚钱路上不断探索的同路人。

今天想掏心窝子聊聊我在航海实战里踩过的坑、尝过的甜。尤其是想借这个机会，好好问问自己：为什么2022年我拼了老命扑在抖音大航海上，最后却两手空空？而转身投入📕运营后，反而拿到了实实在在的结果？

如果你正准备上船，或者正在犹豫怎么开始一场航海，甚至已经在路上却感觉使不上劲，那么这篇内容或许能给你一些参考。毕竟我连续跟了4期📕航海，不敢说多厉害，但至少踩过的坑、攒下的经验，都还热乎着。

我把这些心得浓缩成了四个关键词：**动机、目标、行动、心态**。这四点，是我反复复盘后觉得最关键的胜负手。

**先说说动机。** 你为什么要参加这次航海？是想赚钱，想学技能，还是单纯好奇？动力不一样，坚持的力度就完全不一样。我当年做抖音大航海，更多是“看见别人赚钱眼热”，动机不纯，遇到困难就缩了。而做📕时，我是真想搞懂这个平台的玩法，想验证自己的内容能力，所以再难也愿意啃。

**再说目标。** 别把“赚大钱”当成唯一目标，那太虚了。我当时给自己定的是：21天里，做出多少篇笔记、涨多少粉、跑通多少个数据模型。目标越具体，执行起来越不慌。

**然后是行动。** 想一千次不如做一次。📕那几期，我几乎每天都泡在选题、写稿、复盘数据里。不是说多苦，而是你做的每一个动作，都会变成反馈，反馈又会修正你的下一步。反观抖音那会儿，光顾着收藏各种方法论，真正动手做的没几个，自然没结果。

**最后是心态。** 航海不是匀速直线运动，前两天鸡血满满，中途难免倦怠，最后几天可能想躺平。我就是这么过来的。但后来我习惯了：数据低的时候，就去看看爆款找感觉；没灵感了，就跟同船的战友聊两句。允许自己卡顿，但别允许自己放弃。

除了这四个点，我还给自己排过一份21天的航行规划，按“调研-起号-优化-迭代”的节奏走，亲测有效。想参考的朋友，可以从我文末附的资料里找到详细版本。
