# 策划 3 天，5 天落地，2 天收款 54 万复盘报告（流程框架）

3天定方案，5天执行，2天到账54万——我把这场卖课发售的完整复盘翻出来了

去年六月底七月初，我手上正好有一个知识付费课程要推。当时没有太多预算，也没有庞大团队，就靠自己一个人做策划。花了3天时间排出一个7天的发售方案，最后真正收钱只用了2天，进账54万。

最近整理资料时翻到了当时的记录，决定把这个过程完整写出来，也算是一次深度复盘。

你可能注意到一个奇怪的地方：服务号粉丝明明很少，阅读量却很高。原因很简单——朋友圈里转发的文章，全部用的服务号链接，而不是订阅号。

接下来是关键的路线图。整场发售的主线是👸号文章，其他动作都围绕这条主线做分支。

时间安排是：

- 预热期：让更多人知道我要搞事，但又不透露具体要卖什么。
- 第一天：释放结果，展示收益截图，文章底部留钩子，引导第二天来看。
- 第二天：放出实时查看数据的地址，告诉用户要收人了，正式价格三万多，但准备50张2万块的优惠券，想拿券得先花1000块买。
- 第三天：不发文，让子弹飞，让信息发酵。
- 第四天：做筛选，讲这个项目并不轻松，把头脑发热的人挡在门外，同时宣布第五天正式发售。
- 第五天：正式开卖，讲价格、权益、名额。
- 第6-13天：集中收钱。
- 第14天后：宣告发售结束。

👸号一共发了4篇文章，分别是：

第一篇《流量复利系统》日增粉200+，日赚1000+——用高数据抓注意力，底部引导加企业微信，留钩子说第二天能实时看数据，这个诱饵很带劲。阅读原文跳转到第二篇，那篇文章的阅读量有两千七。

![](img/59725f21296d14625b5bbf2672acfeb0.png)

第二篇《流量复利系统》邀你查看实时收入数据——用实时数据建立信任，视觉冲击强。同时透露最终价格是3X980，释放1000抵20000的抵扣券，还在屏幕上倒数剩余名额，制造紧迫感。两天收到17个付款。

第三篇《流量复利系统》日赚1000+背后的故事——因为前一天反馈太好，所以故意劝退一波，让用户冷静。同时告知第五天才是正式发售。结果抵扣券退了2个人，但购买人数从17涨到了35。

第四篇《流量复利系统》对赌协议——直接成交。

朋友圈的玩法很简单：昨天👸号发了什么，今天再发一遍，配上数据、预告。主要引导预约第五天的直播。

微信群就是把文章和数据丢进去。企业微信做群发、承接流量、打标签。视频号直播在第二天到第四天只开一会，不讲干货，只释放钩子，邀请预约第五天。第五天直播讲解，后面持续直播讲项目。

这套流程背后，核心是多米诺技法。四篇文章就是四块骨牌，第一块倒下带动第二块，第二块带动第三块。每篇文章底部都留了钩子，把下一篇文章串起来。主线是👸号，其他渠道全在为文章赋能。环环相扣，每一环都比上一环更能植入用户的心智。

那怎么保证发售100%成功？

两个办法。第一，永远准备一套B计划。A计划执行后反馈不好，就补数据，等数据恢复再继续。第二，发售流程照走，但最后不卖产品。如果每一环数据都很差，就把计划走完，当做一次分享会，用户也不知道你到底在做什么。

失败的经验也是经验，踩坑多了就会避坑了。

最后是底层逻辑。

多米诺原理有三个关键词：节点、链接、叠加。

节点就是那四篇文章。节点没设计好，第二块骨牌就推不倒。

链接就是每篇文章底部的钩子。为了让链接更牢固，需要配合群发动作，第二天再加强一次。

叠加就是剧情一环接一环往前推。前提是故事剧本得够好，如果是烂片，观众看个开头就走了。

做局理念要用到AITDA模型：

A——attention，抓住注意力；
I——interest，激发兴趣；
T——trust，建立信任；
D——desire，刺激欲望；
A——action，催促行动。

这场发售其实是“局中局”。每篇文章都用AITDA写，四篇文章连起来也是一个完整的AITDA。做局就像行军打仗，你是诸葛亮，给敌人挖好坑，等着他跳进来，不费一兵一卒就赢。

做局，就是先胜后战。
