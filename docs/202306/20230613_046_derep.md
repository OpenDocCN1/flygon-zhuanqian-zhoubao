# 两个月涨粉5万+，我踩过的坑和用上的方法
作者：龙哥

大家好，我是龙哥，这是我在赚钱第一次开帖。最近两个月我开了个抖音知识账号，粉丝从零一路涨到了5万多，过程中悟到的一些点，今天整理出来和大家聊聊。

先说个反常识的认知：做抖音，别一上来就想把自己包装得高大上。

很多准备入局的朋友，拍视频前第一件事就是西装革履、把办公室布置得豪华、把布景做得商务感拉满。看起来是加分，实际上是给自己挖坑。

场景调得越高级，观众对你内容的预期就被抬得越高。举个例子，你在豪车、落地窗的背景下说话，观众潜意识里已经默认你接下来要输出80分的干货了。可如果到最后你只讲出了60分的内容，那落差感会直接让人划走。

反过来呢？如果你的人设定位很接地气，大概只有30分的期待值，你却能稳定输出50分的内容，观众立刻会产生“卧槽，这人有点东西”的惊喜感。

这就是我说的体验差。不是给用户差体验，而是给用户一个预期之外的惊喜差，让情绪产生波动。

用一句话概括就是：比大神更让人上头的是民间高手。比起西装笔挺的成功学说教，大家更愿意听一个看起来很普通的人讲出让人醍醐灌顶的哲学。

所以人设可以总结成一个公式：像观众，但比观众强一点。

这个定位特别容易吸粉，而且粉丝粘性强。我自己用上之后，账号调性一下就变顺了，评论区互动和完播率都起来了。

再说第二个痛点：同质化。

现在抖音上同个话题基本被玩烂了，想靠堆内容硬刚，几乎不可能。怎么破局？还是回到体验差这个点上。

其他人都在讲车参数、讲选购技巧，你能不能在讲车的间隙，顺手给人一点情绪价值？一点安慰、一点共鸣、一句放松的语气？

当你能提供别人没有的感觉时，关注就有了理由。与其每天研究同行怎么做，不如想想自己能带来什么不一样的观感。

最后说一句心里话，做短视频最怕的就是焦虑然后不动。行动本身就是最好的解药。希望这段分享对正在犹豫的你有一点帮助。
