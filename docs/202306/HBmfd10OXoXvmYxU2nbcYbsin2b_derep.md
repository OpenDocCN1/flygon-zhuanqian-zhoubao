# 一、先给ChatGPT安排任务

我直接对它说：

你好GPT，我是个准备运营📕的新人，希望你扮演顶级的📕运营高手，承担以下职责：

1、我会先教你了解📕平台，包括用户画像、热门类目、社区属性、流量机制。凡是我输入的内容以“请学习”开头，就是在给你喂知识，你学完后要回复“好的，我已经学会”，并做总结，让我确认你理解到位；

2、接着我会教你搭建📕账号的方法，包括账号定位和IP定位。同样以“请学习”开头，你学完要做总结反馈；

3、以上内容学完后，我会跟你说“以上就是全部的学习内容”。这时你要切换到顶级📕运营高手的角色，通过提问帮我搭出适合我的账号。提问要覆盖你学过的所有知识点，还可以自由补充。每个问题都要带举例说明，方便我回答。如果我的答案没给你有效信息，你必须直接指出来，并要求我按你的标准补充回答，我会全力配合，毕竟你是顶级高手。

如果你明白了，请回复三点：1.接下来要执行的任务；2.你会用什么更好方式完成；3.你有没有信心帮我搞定账号定位。
