# 我是如何抓住 🐧 点赞小需求，结合自动化插件做起了 2W+的私域流量？
作者：龙哥

很多人觉得🐧只是小孩子的玩具，赚不到什么大钱。但我在🐧这个“学生阵地”上，偏偏折腾出了2万多私域流量，还顺利变现了。

你可能想不到，一个看似不起眼的“名片点赞”需求，配合自动化插件，就能把大量学生用户聚拢到自己手里。玩空间的学生普遍在意点赞量，装个插件成本又不高，我们用免费送赞引流进群，再用自动回复话术引导加好友，慢慢就把私域堆起来了。

🐧这类高用户量平台，私域潜力一直很大。哪怕我现在转去做别的方向，手里依然握着16个🐧群，每个群至少1000人。这些存量流量，随时能支撑新项目放大变现。

这篇文章，我就把当初怎么发现“名片点赞”这个小需求，又是怎么用自动化插件做起来、最终跑通变现闭环的完整过程分享出来，希望能给正在做私域或选项目的朋友一点参考。

# 一、起点：从卡盟代理到尝到流量甜头

2015年，我还是初中生，通过朋友接触到卡盟钻，开始做代理帮人积累客户。当时客户都有质保期，一个月、两个月、三个月，我就自己在备注里标好到期时间，方便判断钻掉了还在不在质保期、能不能续补。

![](img/0203332e223aeb2f5e08096d5d03713f.png)

当时不满足只赚代理差价，我拿出给客户刷钻一点一点积攒的零花钱，搭了个分站。分站价格288块，至今记得清楚。别人想在我的分站下再搭子站，还得额外花钱买额度——普通分站额度10块，专业版20块。

![](img/42c542c57bfcfdb2fd7c2189f74b6710.png)

学着同行去贴吧发帖、在🐧群刷广告，又找朋友搞了个免费群发机器人，慢慢分站有了订单，代理也越来越多。当时我把一部分代理引流到🛰️，说实话那时候哪懂什么“引流”“私域”，只是单纯觉得🛰️好友太少，想让自己好友多一些。

![](img/4db4547d57861aa04e16bbfb0628e403.png)

![](img/e335a846427784f9b17f5c4ccb88e1b5.png)

代理多了以后，我也学着同行建群管理。2016年8月11日创建的群，到现在还在，只是里面的人渐渐都不说话了。

![](img/1a0b5568eea881d14ebd8a80822ee79f.png)

后来卡盟行业越来越难做，大平台渐渐消失，我们这种小分站也只能退场。退场后我开始做“撸羊毛”，靠以前卡盟积累的人脉收徒、卖教程，在🐧空间和朋友圈宣传。很快收了十几位徒弟，每人100块，当时作为学生特别满足了。再加上我一直讲诚信，客户和代理都很信任我，没当徒弟的也会买我的教程，定价8.88、18.88、28.88不等。

从那时候起，我就深刻体会到：流量，真的能带来好处。

![](img/50c67edd365536b2ef27ad3e6b1fe1de.png)

# 二、地基：群CPA的两年历练

最开始做🐧只想赚零花钱，但慢慢不满足了，想要电脑、想要好手机。试过各种赚钱路子，发现都只是小钱，开始琢磨稳定的大项目。

2017年，通过一个哥们接触到群CPA，当时没多想，一个字“干”。结果一做就是两年，还给后来的项目奠定基础。

我们的模式很简单：想赚钱但不会引流的人负责建群，我们负责引流。合作伙伴只需要提供群，我们不会动任何东西，明确跟他们讲只挂CPA文件、不收一分钱、纯帮忙引流，大家都很乐意合作。

![](img/01aabfaf26453698de8fbb814c6519c2.png)

很幸运，我们算是第一批做群CPA的人，当时知道这个思路的并不多，用现在的话说，站在了风口期。一天引三个群，群里挂上CPA文件，平均每天收入100到150以上。

![](img/2ddafbf06d25eb1779ea62f361e29ac6.png)

后来拉人太快，平均4小时就能满一个2000人群，满了就换群。腾讯也开始察觉异常，限制拉人、封群。合作伙伴那边也出问题——群满了就把我们踢出来。朋友觉得这方式扛不住了，让大家停一两个星期，他去找关系想办法。

就在这个过程中，我接触到了“多开群”：一个🐧即使不是年费超级会员，也能卡出20-30个2000人群。我把赚来的钱买了不少多开群号，有的号里有五个2000人群，有的号有十几个。

![](img/7ac12e4d34fbe626cf47a2194c56de62.png)

![](img/f128a2939086c5940d56f418cb21dae7.png)

当时感觉要起飞了。但群资源还没用完，CPA平台就出了扣量通知——嫌我们🐧群质量太差，用户下载后平均不到十几分钟就删，不愿意收我们的量。加上同行越来越多、群泛滥、腾讯封群，这个小圈子最后就散了。

![](img/d67326804d0da0c131af241aca7e5775.png)

# 三、引路人：遇见“浏览号”

2020年7月，我遇见了我的引路人——也是贵人，成了好朋友。我们亦师亦友，一起琢磨🐧的各种玩法。

我在🐧做的最后一个项目，叫“浏览号”，也叫人气号，本质就是把流量引到私域。每个🐧号有几千好友、上千个群，发一条说说有几千浏览、一千到两千点赞，就是浏览号。又分小浏览和大浏览：小浏览只有几百浏览、100多个赞；大浏览几千几万都有。

![](img/3e54c66d66e8e51cad4907a87b7143a8.png)

![](img/f2f29d49ecee3488041681e8adbc81d5.png)

因为做过群CPA，做这个项目时资源特别充足，不管是群还是机器人🐧号都不缺。朋友讲的插件框架、浏览号玩法，我都能快速听懂、立刻上手。

为了让大家更容易理解这个项目，我列了五个问题：操作流程、变现方式、遇到的困难、做过的事、快速上手的技巧。

**（1）操作流程**

准备要引到私域的🐧号，加上框架插件，配好话术，在群里触发关键词就能引流。刚开始就是一套复制粘贴的做法。

🐧号必须有等级、且真人用过，才能扛住腾讯的封号冻结。我们的收号方式，就是在群里打广告、或者发空间说说。

框架插件相当于一个软件，登录🐧后配置好话术，🐧就变成全自动机器人，能模拟真人聊天，各种功能都有。最早用的插件是全网同行都在用的，后来腾讯打击变严，我们找了人写代码做自己的插件。

![](img/7bc95bcf4fba572b324ed8b5b0f4032a.png)

我们设置的话术都围绕“名片赞”。只要群里有人发“互赞”“赞我空间”“空间互赞”这些关键词，机器人就自动艾特对方，回复提前设定好的话术。加上好友后，话术会提醒对方已经送赞成功，说拉我进群还能继续获得更多名片赞；最后再触发关键词，引导对方进我们的互赞群，并强调进群还能免费领赞。

**（2）变现方式：三条路子**

第一种，把浏览号卖给市场上有需求的老板。做起来的浏览号，市场上很多老板专门收，一般行情是0.4-0.5元一个浏览。先发条说说测试价值——比如一条说说有5794浏览量，那就是5794×0.4=2317元。当时两个号加起来接近3000多，相当暴利。

![](img/f36dcd00916cb261cd78a5bda328d8a9.png)

第二种，给微商老板推号。刚开始大家做浏览号都是直接卖给老板，十个号就卖十个号。后来起号越来越难，大家就不怎么卖号了，改为帮微商老板推广号码。怎么做？把做起来的浏览号挂上话术，放到群里裂变，有人加机器人好友，就自动触发话术：“加××××××也送赞（××××××）”，其中××××××填老板需要推广的🐧号。

![](img/a6212bffd9bfc03b816a0affa5828306.png)

还有一种推广方式，就是发🐧空间说说，吸引人来主动加好友。群里推广和空间推广价格不一样：群里一个人头0.15元，空间一个人头0.3元。

![](img/cf71815be59cbea84f452eb8aa40fe1f.png)

靠这种方法，我和朋友的收入大幅提升——他一个月3万左右，我一个月2万左右。支付宝交易记录太久找不到了，只能放部分🛰️交易记录。

![](img/9668f1a67c0d713b3b7747472a1d89c1.png)

第三种，挂自己的代刷网吃佣金提成，类似淘宝客——有人下单我们赚差价。代刷网是个能刷各种🐧业务的网站，特别吸引玩🐧的学生，价格合理，加上学生本来就喜欢名片赞、空间赞这些，自然会下单。

![](img/0056aee266aa30250597bce68adbf33a.png)

推广代刷网主要靠机器人话术加🐧群。两种方式：一是有人申请进群，机器人自动艾特对方，提醒这个网站可以免费领名片赞、说说赞；二是设置机器人定时艾特全员，宣传网站。

![](img/0f7e93b90ffc15c5a9b0890b4472fc70.png)

![](img/0f3fa5b36d8b45ffbab7917a3f8809e0.png)

![](img/a5834404d212d9ed077ed00e499299db.png)

代刷网最高一天收入300元。那段时间每半个月左右就能提现3000多块，流量好的时候，真正体会到了“躺着也能赚钱”的感觉。

![](img/c67586787b9a3511f7dd96205518b982.png)

![](img/7960a53897efcc2edc5e0f9bb83017d5.png)

**（3）遇到过的困难**

腾讯一纸通告，各大框架都被关停，没有框架，整个操作模式直接崩盘。🐧本来就是聊天工具，腾讯凭什么让你在里边赚钱？所以封号、封群越来越猛，解封规则也越来越复杂：身份证冻结、人脸识别、好友辅助都用上了。当时市场解一个🐧号最高要50块。

一个身份证只能解5个🐧号。我自己有40多个号，朋友有60多个。市场价太高，我们就去群里找学生帮忙解，解开一个给15、20块。后来才知道，一个号一旦被某人的身份证和人脸解过，就等于绑定了，以后再冻结还得找同一个人。我们不懂规则，乱找人，结果后面再冻结找不到人，损失了很多号。

最难的时候一天冻结20多次，刚解封一个小时又全被冻了。没想过放弃，但心态真的被搞累了。再加上名片赞被腾讯限制刷不了，连普通互赞群也莫名其妙被封。那段时间我直接停工两周，只想保住剩下的🐧和群。

**（4）我们做了哪些事**

知识付费，是解决问题最快的路子。框架问题，我们是从同行那打听到，原来还有人在偷偷经营框架，只是不能拿到明面上。

🐧冻结，我们花钱买“料子”来解冻。所谓料子，就是只要有一部手机加购买到的资料，就能无限解冻号码。办法总比困难多，加上腾讯平台慢慢松懈，我们挺了过来。

那波打击淘汰了一批人，而我们赚到了钱，就想着更大胆操作。框架一直是我们心里的顾虑，于是找了熟人写代码做自己的插件，还用小众的不起眼的框架，前后改了七八次，投入了1万多块。

**（5）如何快速上手这个项目**

任何时候都要有感恩之心。我和这位朋友，就是因为一个小问题、一瓶饮料钱结识的。所以我总觉得，人真的要时刻心存感激。

如果我当初没做过群CPA，不了解框架插件、多开群，也没收过🐧号当机器人，那朋友跟我讲这些的时候，我肯定一头雾水。但正因为做过，这些东西我全都有、全都懂。

当时我手里已经积累了一些名片赞群，尝试新项目时就直接在老群里打广告——“进×××××群免费领取名片赞”，靠这招快速拉起了第一个互赞群。

我还有十几个多开群号。做这项目时，多开群号已经很难低成本拿到了，而我手里至少有十几个。只需要一套流程、一点时间，就能把80多个2000人群全部引流满。

![](img/56677536b3c8d75121cadfc0a8732af6.png)

靠着以前做CPA积攒的资源，我迅速做起来一批🐧号。那时每个号一天最少有100个人加好友，最高能接近2000人加好友。

![](img/6fbcc04355e84b26177fe27334cf8010.png)

![](img/d5b84bf1c1231e90f6b95c3d8089f697.png)

![](img/0afdb9adfa8c47e7b68dec68d74323d1.png)

当发现这些资源和设备我都具备时，做这个项目对我来说真的就只是个流程，只需要静静等时间沉淀。

到现在，哪怕我早已转型，我的群还在每天帮我宣传代刷网。

![](img/2082ecb926c73945074875a776aece3f.png)

哪怕自己不做了，流量依然归我所有。代刷网每天都有正常收入，隔段时间就能提现1000到2000，权当零花钱用。

# 四、经验总结

现在手里还有16个群，每个群至少1000人。我转型做了别的项目，但群一直在运转，不会因为我不做就停下来。发条说说，浏览量依然稳定在1000以上。我不玩了，不代表学生不玩了。

等我研究新项目需要人的时候，往群里艾特一下全体成员，再加上群主的头衔，别人天然就多一分信任，新项目实操起来自然更顺手。

还记得做🐧时，身边人说得最多的就是：

“都什么年代了还在玩🐧？”
“你多大了还玩🐧？”

可正是这个“过气”的软件，让我攒下了能长期复利的私域资产。

“都21世纪了，还玩🐧？我身边全是🛰️。”

这话我听过太多次了。也有人问我：🐧到底能干什么？它哪有🛰️方便？又或者，带着满脸不信来一句：“靠🐧赚钱？别逗了。”

说真的，2015年之前，我也会这么想。但那年我一头扎进🐧，从此再听到这些质疑，就只是笑笑。

有些人只看到🐧是“小学生玩具”，却不知道这“玩具”让很多人月入几万、十几万；有些人瞧不起玩🐧的学生党，却不知道这批年轻人正是很多懂行的人眼里的宝贝。

老一辈渐渐都跑去了🛰️，新生代却是🛰️、🐧两头顾，甚至不少年轻人把🐧当主战场。所以，哪怕到了今天，我也从不敢说：🐧没机会赚钱了。

答案恰恰相反：🐧的流量池又大又深，像块巨大的蛋糕，谁都想来分一口；只要有想法、有办法的人，就能把公域流量引进自己的私域，照样风生水起。

聊到这里，我想认真谢谢一个人。没有他，可能我早就不干这行了。我俩之间，我最常说的两句话是：“插件更新花多少，钱我出。”和“这阵赚得不错，转你点钱潇洒一下。”

最初我们还一起凑钱做插件，后来他成了我特别铁的兄弟，他甚至再也不让我分担开发费用，插件一有新功能就直接发过来给我用。他从不在我面前提钱，但我心里清楚：那是他应得的部分。他不说，不代表我能装傻。我走到今天，一半的成绩都是他帮衬出来的，他是我遇到过最棒的合伙人。

只是，那阵子靠“名片赞”猛冲的日子里，腾讯越来越严，以前一个号一天刷十几万不成问题，现在刷个一两百都常常要耗一整天；再后来，框架一挂🐧号就被冻七天。眼见这条路彻底堵死，我和他干脆转去了别的事情上。

那个项目，确实没法再做了。我写下这篇，算是给自己的🐧生涯做一次告别。

感谢你在屏幕前看到现在。现在我已经换到新的领域继续打拼，但🐧那段时光，我一辈子都忘不了。是它让我长大，让我懂了太多，也让我知道，网络并不全是冰冷的代码，还有温暖。

我这段网络故事没有太多惊涛骇浪，唯一拿得出手的，大概就是那颗不甘心、摔倒也想再爬起来的劲头。我希望你也有。
