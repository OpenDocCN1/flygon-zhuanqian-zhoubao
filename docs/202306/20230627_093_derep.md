# 用 AI 给淘宝模特换装，这套 SD 思路我整理出来了
作者：龙哥

最近团队在打包 AI 相关的实操课，我顺手把做淘宝模特 AI 换装的流程梳理了一遍。核心工具就是 Stable Diffusion，思路和参数细节我都放到了飞书文档里。

如果你也在做电商图、模特试穿类的内容，里面这部分经验可以直接复用。觉得有收获的话，麻烦帮我点个赞。

**评论区互动**

曹超峰：大佬，模特生成出来之后，能不能直接套用指定的衣服？比如我手里有一张实拍的服装图，能不能让模特穿这件，而不是让 AI 重新编一套？

彦灵：可以，但要做定向训练。想让模型严格还原一件特定服装，就得为这件衣服单独炼一个 LoRA，并且把过拟合程度拉满，这样生成时的还原度才会接近原图。
