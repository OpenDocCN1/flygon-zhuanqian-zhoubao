# 淘宝做高客单无货源，一单利润轻松破千



## 淘宝高客单无货源玩法，一单利润四位数

作者：Markberg 
日期：2023-06-15

今天聊一个在淘宝做无货源但主攻高客单的思路。现在电商内卷严重，淘宝竞争更是激烈，普通人想从低客单品切入很难起量。但换个打法，做高客单就完全不一样了。

一单赚一千很正常，运气好碰到大单，利润直接飙到一万多甚至两万起，这样的收益堆起来，抵得上别人卖几十上百单低价产品。

核心逻辑就是用高客单的利润率，抵消掉低客单需要的高成交量和重运营的压力。

**评论区精华回顾**

台桓：退货问题怎么处理？
梁欣：你自己先采购再发货，时间来得及吗？退货是不是也要倒手？
一只微微笑：全程建议顺丰

Markberg 回复：
物流我们统一用顺丰，时效和体验都稳。店铺发货时效要提前设置好，能做一件代发的品类就把发货天数压短，一般设置7天内发货完全合理。

退货流程分两种情况操作：
第一种是一件代发直发给买家的，可以直接让买家退回给我们的上家源头；
第二种是先发到我们手里再发货的，这类退货先寄回我们这边，确认后再统一退给上家，七天无理由的窗口期要利用好，不会卡死。
