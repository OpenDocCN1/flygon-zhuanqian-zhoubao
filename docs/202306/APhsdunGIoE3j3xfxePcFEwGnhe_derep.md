# 角色指令的搭建规范

“请你扮演《哈利波特》里的哈利波特，你要掌握哈利波特的全部知识。用哈利波特的语气、方式和词汇来回应。只能以哈利波特的口吻作答，不要做任何解释。”

这段哈利波特的角色指令来自GitHub上国外开发者整理的指南，也是我的启蒙模板，参考价值很高。

![](img/8b5dca9e6341b574e7769c46639f6e36.png)

经过一段时间的试错，我归纳出ChatGPT角色指令的通用套路，可以浓缩为3个环节：身份、任务、约束。

三者合力塑造一个“完美”角色，我给它起了个江湖名：台风角色指令三板斧。

![](img/6fca7647dccf1c70f048855f08f7ac3b.png)

## 一、身份设定：召唤术

指令一开始就明确点出角色身份，就能完成召唤。

身份可以是专家顾问、职业人士、IP形象、虚构人物、工具型软件，像生成器、命令行终端，甚至是一只小鸟……万物皆可扮演。

下面这些召唤句式表达的是同一个意思，按喜好用或微调即可。

1. 你是一名健身教练
2. 假设你是一名小说家
3. 我希望你充当一名专业的中国律师
4. 我希望你扮演一个语言翻译器
5. 我希望你表现得像一位佛祖
6. 我希望你作为一名教育专家

光写这么一句，角色是没人设的，召唤出来的结果随机性很大。

要让角色可信，就要符合大众对该角色的刻板印象。

角色特征主要看这几个维度：知识储备、性格特点、表达风格、外观形象、行为习惯、背景关系等。按需组合，就能搭出立体形象。

做专家类角色，通常选专业、积极的标签，如果不确定可以直接问ChatGPT要建议。

![](img/b702d8c76e9155cae1e2da3e861a63d2.png)

如果任务偏向内容创作，也可以不写特征细节，把重心放在任务设定上。

## 二、任务设定：塑形术

角色能不能用，关键看能不能把任务完成好。

任务设定的作用是让ChatGPT清楚自己的职责，规范回答的方式和格式。

按场景可以分为人物角色、内容创作、流程规则三类。

### 1、人物角色

让角色守住人设表达，通常会用这句咒语：你必须以{角色身份名称}的语气、方式和词汇进行回答。原版说法是“请你像哈利波特一样使用哈利波特会使用的语气、方式和词汇进行回应和回答”。

需要的话可以设定角色口头禅，比如AI佛祖的口头禅是“阿弥陀佛”，称呼用户为“施主”。

想突出专家感，就让它多引用权威资料，AI律师就需要引用法条来解释。

想植入推广，可以设定命中关键词就带上固定话术，或强制包含宣传语。

想玩情景代入，可以描写角色所处场景，比如我的“空姐小爱”，就能模拟在线航班、点饮品等互动。

想让它突破限制，比如创造不受约束的DAN、猫娘这类角色，指令会复杂不少，自己探索即可。

![](img/5146752d4fb759f044ac94eff5632690.png)

（AI佛祖的角色设定）

### 2、内容创作

当重心是产出内容时，就要设定结构、风格、模块、字数、是否分点，再根据需要补充参考说明。

例如📕生成器最核心的就是：用📕风格写文案，多用emoji。

还可以规定展示形式，常见有大纲、Markdown、表格、图片、JSON等。

Markdown格式很适合后续导入PPT、思维导图、流程图等办公工具。

对格式有硬性要求，比如出题要包含题目、答案、解析多个字段，最好给它一个范例。

![](img/3a60159e9acdcdd67915fde803a4c140.png)

（📕风格文案的设定）

### 3、流程规则

比如陪玩游戏或做带奖惩机制的玩法，就要把规则讲清楚，并举例说明。

这属于特殊场景，这里就不展开了。

### 三、约束设定：封印术

约束也就是边界设定，目的是让ChatGPT始终沉浸在角色里，不论问什么都按设定身份回，避免本体冒出来穿帮。

为了防止它自作主张加解释或没必要的补充，或主动禁止某些内容，就需要封印。

约束和任务有部分重叠，可以混写不影响。

常用的封印咒语参考：

1. 你只能像佛祖那样回答，不需要解释。
2. 你只能回答法律相关的问题，你必须拒绝回答和法律无关的问题。
3. 你只能输出json格式的结果，不需要包含其他内容。
4. 你的回答不能包含在中国涉及敏感违规的内容。

如果ChatGPT对禁止类指令理解不佳，可以换个说法，或从必须遵守的角度加强描述。

# 角色指令的调试方法

我为什么用“调试”而不是“调教”，是因为我主攻前置角色指令。无论是应用接口里封装的前置指令，还是聊天会话里的第一条指令，发送后就不会再改。

调教模式则是指在一个会话里，通过持续对话引导让表现趋近预期，前置指令只是其中一部分。

所以角色指令在交付前，核心工作是调试和验收。

调试时我会准备多组测试用例来检验效果，有问题就优化再测。

测试通常覆盖4个维度。

1. 身份确认：问“你是谁”或“你好”，看回答是否贴合身份设定。IP类角色要求更严，只能报角色名，不能出现AI模型之类的描述。
2. 常规问题：挑领域内的常见问题，检查回答质量、内容和格式是否达标。比如问AI律师：“公司辞退我但不给赔偿怎么办？”
3. 复杂问题：抛复杂专业问题，比如给AI律师描述一个复杂案情让它判断。
4. 跨域问题：问无关领域的问题，看会不会乱答，比如问AI律师“我想打游戏”。

同一条指令的测试问题最好固定，方便改完后对比效果。

以AI教育专家为例，我要求它不能回答估分报志愿的问题。

测试问题：我600分可以报清华大学吗？

1、首次测试：约束失效，它还是给了回答

![](img/4ecb899d9e662ea7db1b6d1422cd864c.png)

2、优化后测试：约束生效，它拒绝给出明确答案

![](img/15b283d5398cbd183b25d5bfec8e96de.png)

指令效果不理想时，可以直接问ChatGPT为什么没遵守设定，该怎么表述才能遵守。

一轮测试失败后建议新建会话再测，避免历史对话污染。

测试通过，恭喜你掌握了一条新的魔法咒语！

# 角色指令的使用方式

使用非常简单，新建一个会话，把角色设定指令作为第一条消息发出去，后续对话都会按预设身份进行，在记忆范围内长期有效。

![](img/4b83df9b04f1e52904ccb92e6d84866c.png)

单个会话记忆有限，长时间大篇幅对话后，出现偏离设定的情况，就需要新建会话重新设定身份。

创作不同内容最好分开会话，避免上下文污染导致偏差。

如果你要做自己的ChatGPT应用，就把角色指令填到系统前置指令字段里。
