# 围绕大平台做小工具，一直是一个可以闷声赚钱的事情
作者：龙哥

你有没有发现，真正的“闷声发大财”，往往藏在那些不起眼的小工具里？尤其当它们依附于大平台时，更是如此。今天要拆解的，就是一个堪称教科书级的案例——一个围绕微软TTS做出来的Chrome插件，据说背后可能只是一个人。

先把时间拉回2021年。微软上线了一套文本转语音服务，多语言支持，还能调节情绪语气，合成效果逼真到让人怀疑人生。普通人基本听不出机器味，直接把同行甩出好几条街。最开始时，官网上还能免费试听：你敲一段话，它就给你读出来，听完大家都忍不住喊“牛”。但奇怪的是，微软偏偏不给你下载按钮。更绝的是，后来连试听都没了，直接让你注册账号，甚至绑定支付方式。

这就是典型的“吊胃口”：好听是好听，可你带不走；后来连听都不让听了，想从浏览器开发者工具里找线索也断了路。

痛点摆在这，有人就看到了机会。一位开发者（大概率是个人）做了一款叫Downloader for Microsoft™ Text-to-Speech的插件。原理其实不难猜：微软虽然砍掉了试听入口，但后台接口大概率还留着。这位作者找到了它，然后让用户输入文本、配置选项，插件一调用，直接返回MP3文件。技术上不复杂，但赚钱的关键在后头。

他是怎么变现的？第一，把这套能力封装成Chrome插件，借助Chrome、Edge的插件生态，一键铺向全球用户。第二，建一个官网，敞开胸怀迎接互联网流量。第三，接入Stripe自动付款，全程无需人工干预。特别有意思的是，他还特意接入了支付宝，方便国内用户付费——八成是位中国开发者。

那到底能赚多少？数据很现实：插件主页显示1万+用户，官网报价按月2.5美元，按年18美元，用支付宝稍微贵点，可能是手续费高。按20%的转化率、均价2美元一个月来粗算，月入大概4000美元，折合人民币差不多2.8万，几乎等于干赚。别较真精确数字，数量级对了就行。另外，SimilarWeb显示插件官网月流量1.5万，而且来源主要是中国。不得不感慨，咱们国家的开发者抓这类机会的手感，真是越来越准了。

这种“大平台+小工具”的打法，也许不是暴利，但胜在轻巧、自动运转。谁又能说，下一个悄悄赚钱的人不是你？![](img/4951a729604562ce4635fc7856c4ec1f.png)
