# 用公司福利卡做中间差价，我最高一天赚5000，累计到手7万多

## 公司福利卡券倒卖变现实操全记录，单日峰值5000元，总收益超7万

作者：阿龙（原 Mi）
日期：2023-05-25

把企业发放的福利卡券低价回收再高价卖出，逻辑很简单，启动门槛也不高。核心就是两头撮合：一头是急着把福利折现的内部员工卖家，一头是想低价入手的外部买家。自己卡在中间赚取价差。渠道搭建起来后，闲鱼、贴吧等平台就能持续导流。

下面把这个福利卡券变现的玩法拆开讲清楚，用8个常见问题带大家理顺全流程：

一、这个项目到底能赚多少？
二、赚钱的环节分别是什么？
三、货源从哪来？
四、怎么把人引进来？
五、怎么用免费流量？内容怎么做更能吸粉？
六、变现方式有哪些？
七、新手上路有哪些实操建议？
八、门槛和风险点在哪？

# 一、项目始末

2020年之前，我还在国企待过。那段时间国资委在统一调薪，公司就把一部分工资折算成福利发放，主要是携程卡、京东E卡和普康宝积分。

我发现大部分同事真正想要的是现金，而不是这些卡。于是我开始尝试帮他们折现。

一开始只能去咸鱼上碰运气找货源。聊下来才明白，员工手里的福利卡大多希望快速出手，普遍愿意比面值低一些卖。于是我就能吃到中间的差价。

做着做着，我就建了个🛰️群，把有卡想卖的同事和想要低价买卡的人拉到一起。慢慢就形成了稳定的交易闭环。

最高峰的时候我一天能净赚5000，后续累计收益超过7万元。只是这个模式很容易被复制，后期同行越来越多，利润就被压下来了。

不过只要手里有稳定渠道和资源，这条路依然能做。持续拓圈、转发信息、找新合作方，竞争力就能维持住。

# 二、利润能有多少

举个万人公司举例给你算笔账。假设你能触达3000名员工，每人每月到手500元的携程卡，按1个点算：
3000 x 500 = 150万流水，1个点就是1.5万利润。

赚钱主要看两头压价：
1. 上游回收价要谈到位。跟回收商谈的时候，把预计人数往大里说，有量才能拿到更好回收价。
2. 下游出售价要锚定市场。去咸鱼、转转看同类回收行情，可以比平台价低一点点，有案例背书买家更信任。

举个例子，之前某公司突发福利发普康宝积分，利润一度能到5个点；携程卡这类常见卡，2个点比较常见。中间的差就是你的。

# 三、赚钱能拆成哪几个动作

1. 先锁定一个种子客户，最好是国企内部的亲戚朋友同学。
2. 确认能顺利变现的卡种，比如京东卡、携程卡、加油卡等，操作简单到账快的优先。能薅羊毛的朋友也能给你建议。
3. 去对接上游回收商，谈回收价。
4. 和种子客户谈收购价，给他一个相对有吸引力的价格，让他愿意配合。
5. 让种子客户在部门内部扩散，可以适当发个小红包刺激。
6. 再让被扩散的同事继续扩散，利用利他心理，同事间传播很快。

选卡有个原则：要方便员工兑现，同时保证你的利润。比如京东卡回收价低，可以换兑换比例更高的卡种。如果公司福利种类固定，只能去拓展更多的回收渠道。

# 四、货源怎么解决

货源本质上就是员工手里闲置的福利和积分：
1. 企业直接发放的福利卡或积分，比如可兑换京东、携程的积分。
2. 突发性福利，像我当时做的普康宝，不同公司叫法可能不一样，这类项目利润高但后期容易被卷。
3. 银行权益类，比如存款送的高铁贵宾厅、飞机休息室权益。我认识的人靠贵宾厅权益变现一个月3万。

# 五、引流怎么玩

流量主要靠种子客户破冰。
认识一个刚拿到福利积分的公司员工，帮他一次变现，他就会帮你主动扩散。因为大家都想把卡变成现金，传播速度极快。

核心是建立可信的上下游链路，让员工相信你能安全快速帮他折现。

# 六、免费流量怎么获取，内容怎么设计

直接去搜索目标公司的相关讨论区，比如咸鱼、贴吧，发变现广告。做法就是放一张变现成功的截图，关键信息打码，留下联系方式。

# 七、变现除了倒卖还有什么

除了直接做差价，还可以学羊毛党操作。
比如你95回收京东卡，97卖出赚2个点；也可以自己用卡去下单买保值或会升值的商品，比如手机，买完转手再卖，利润能做到5个点左右。

# 八、新手入局建议

最关键的是先把种子客户谈好。上游价格能谈就多谈几家，价格不满意就换。突发福利刚开始量大，上游容易压价，所以一定要多备几家回收商。

保障自身利润是第一位的。

# 九、门槛和风险

门槛：几乎没有，只要肯执行。
风险：主要在第一次合作。我的第一次合作找了额度小的上游试水，万一出问题自己兜底。至今没碰到过骗子。

风险可以转移，第一次合作可以要求上游先打款，或者小额先行。需要靠谱上游资源可以私信我，目前赚钱圈里有做代下家电订单的，他们持续需要京东卡。
