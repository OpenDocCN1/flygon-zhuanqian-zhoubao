# 那个在泥坑里把自己头发揪住往上拽的人
作者：龙哥

作者阿黛的自述，讲的不是鸡汤，是真刀真枪的生存样本。

十六七年前，股骨头坏死确诊书砸下来，两条腿已经歪出五厘米。一个人住进医院，一个人扛完治疗。没有网络没有电视的那个月，她没等死，也没等救。她做了两件看起来很小的事：一条帘子把它拉开男女分治，让自己能安心康复；把科室的年终工作报告润色一遍，让医生护士记住了她。四年后临床治愈。后来她站在了珠穆朗玛峰上，两次。

很多人把股骨头坏死叫做不死的癌症。病友疼到下不来床，换了人造关节也回不到从前。她成了那个例外。例外不是运气，是【成就2】【专注4】【追求9】堆出来的结果。她就是那种能揪着自己头发从泥巴里爬出来的人。

硬，还得有软。硬到什么程度不会把自己掰断，靠的是【适应1】。她很快认清现实，在能控制的范围内选最优解。激素把她胖了七十斤，满月脸。她跟世界和解，也和解了自己对美的标准。以前穿高开叉旗袍多一斤都不行，后来在教练监督下日行万步、健身房啃下来五十斤，生完孩子又回来，又在琢磨再减回去。

股骨头坏死生孩子在医生眼里是高风险。她照样平安生下，孩子健康聪明，没有被多年治疗波及半分。

去年十月她开始在视频平台做分享和直播，帮同病相怜的人。她上过几次小热门，攒了一批铁粉。做这件事她发现人与人的心性差距真的夸张，有人动不动就投降，有人能狠到自己都怕。变现她在规划，但红线很清楚，不做医托不卖药。

历史学家许倬云说：拿自己身体能用的部分，心智能用的部分，都动员出来。她说自己是勉强做到了。

这里插一个她反复提到的故事，《世界尽头的咖啡馆》里的海龟。

凯茜海边度假，看到绿海龟，觉得自己细长条穿着蛙鞋肯定更快。她拼命划，十分钟后海龟把她甩出去几百米。连续几天都追不上。后来她才看明白，海龟从不硬顶浪。浪打向岸时，它浮起来轻轻划水，借力站位；浪往回走时，它加速一程，顺势前行。它和海融为一体。凯茜一直逆水死划，累到最后连顺浪的机会都没了。

所以逆境里别总往死里冲。要放平心态，做该做的事，不拼命消耗，攒劲等窗口。生命本就是有起伏的流动，环境有高有低，人的状态也有。认清大势，跟着节律走。想冲的时候一心一意干，想歇的时候心安理得躺。这是可控范围内的弹性，是谋定后动，是在不同模式间平滑切换，保持动态平衡。

跟生活握手言和，不拧巴本身就已经是胜利了。

她从不放弃目标，但会顺着【适应】走。这份分享，送给正在被放弃怪缠上的每一个人。
