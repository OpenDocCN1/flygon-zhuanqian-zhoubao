# 线下组局全流程操作手册，看这一篇就够了
作者：龙哥

如果你也想组织一场高质量的同城线下交流局，却总被流程细节搞得手忙脚乱，那这份实战经验可以直接抄作业。整个流程被梳理成“组局前”和“组局中”两大阶段，每一步都写得很清楚。

## 一、组局前：准备工作做扎实

### 1. 组局官的核心动作

组局这件事，需要一个明确的“总控人”，也就是组局官。他要在双数周的周二晚上9点到10点，确认本次组局的主题、目标、时间，并发起组局官报名。主题要具体，目标要可量化，比如“AIGC在电商领域的变现讨论”，人数定在10人左右，讨论出至少10个可落地的变现方向，同时收集10个实战难题，再对应给出10个解决方案。

场地方面采取“三选一”机制，最终拍板一个最合适的。接着根据场地与物料做预算清单，拉群、发起群收款，并引导大家先自我介绍。组局的初步流程和议题也要同步给每位参与者——这一步通常安排在双数周的周五晚上9点到10点。到了周五晚10点到凌晨，组局官还需要把执行方案细化完毕。

关于物料和到场，第一次跑通的经验是：坐G1003次高铁，42分钟到广州，12点抵达；下午1点物料由搭档Mo.gz带到会场；组局官与Mo.gz在1点开始布置现场；2点准时签到并暖场。这套流程跑熟之后，物料可以直接存放在场地，后续组局官提前半小时到场即可，参与者2点到场就能直接开聊。

### 2. 选址逻辑：确认“山舍”

选什么样的场地直接决定了活动体验。建议结合参与者人数、时间限制、场地环境、设备条件以及费用来做综合判断，确保场地能满足整场活动的需求。

### 3. 组局官的任务清单

**每周二晚9点到10点**
- 锁定主题，比如“AIGC赚钱局——电商行业如何用AIGC变现”
- 设定目标：10人局、产出10个变现路径、收集10个难题、讨论出10个解法
- 明确时间：2023年5月13日14:00-16:00，大概率会延到18点，之后可自由聚餐深聊
- 预估费用：人均70-120元
- 发起报名链接（首期用的是圆梦空间地址）

**每周五晚10点到凌晨**
- 拉群，并让参与者在三个备选场地里做出选择
- 按人数和需求定场地，确保空间、设备、时间都匹配
- 制定详细预算，发起群收款
- 核实押金，24小时没交的直接移除群聊
- 组局官带头做自我介绍，引导大家在群里暖场
- 同步流程、议题、时长与注意事项，明确活动纪律：全程紧扣主题、友好交流、真诚分享；结束后每人需要反馈心得；费用按AA制结算，多退少补，放鸽子的话押金不退
- 提前发放路线指引，把关键地标和环境照片发到群里，方便大家认路
- 完成详细执行方案

**物料准备**
除了PPT，还需要印刷海报、姓名桌签、拍照横幅、手持牌，以及一份参会者手册——手册要包含会议概述、完整流程和所有参会者的介绍，打印后现场人手一份，并配一支笔。

### 4. 收支管理

组局官还要记录整场收支，形成清晰的账目表。这里不展开记账模板，但务必要留痕，方便后续公示和退款。![](img/bec8e816d1890dc3ded1ec8c45251bf8.png)

## 二、组局中：现场执行不跑偏

### 开局规则（5分钟）

活动开场，主持人要定下几条硬规矩：
1. **真诚开放**：放下伪装，坦率面对自己和他人。
2. **全程投入**：手机统一上交保管，全程不碰手机；组局官安排专人录音，结束后分享录音文件；主题分享阶段保持安静，答疑时间专门开放提问。
3. **互帮互助**：大家带着问题来，一起找解法。每人提一个自己在AI电商应用中遇到的难题，比如“AI怎么做详情页”“AI怎么替代模特”“AI怎么出产品图”；再给一个对应解决方案；最后分享一个自己从0到1跑通的AI电商落地案例。
4. **拒绝空降**：不接受没报名的人或临时带朋友入场。

### 自我介绍（30分钟）



评论区里已经有参与者表示：“上交手机”这个动作确实能让所有人更专注，强烈建议沿用。

一场高质量的线下组局，不在于人多，而在于规则清晰、准备充分、每个人都有收获。照着这份SOP走，你也能轻松复制出一场干货满满的局。
