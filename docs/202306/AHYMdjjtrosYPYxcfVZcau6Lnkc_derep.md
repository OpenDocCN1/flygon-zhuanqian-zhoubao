# 1.探索初期：两次失败的选测品经验积累

2022年3月视频号带货和微信小店开始在各大社群热起来，我当时也去注册了营业执照开了店，但并没有深入去研究。看到身边圈友陆续做出成绩后，8、9月份我就想上手试试。

一开始我看了不少视频号带货选品的文章，心里有数但没动手，认知还停留在纸面。选品全凭主观感觉，觉得好就上，完全没实操验证。发了几个视频，做了几个号就开始焦虑，盯着后台没流量没转化，心态崩了。别人做起来就觉得自己不行。后来明白，听再多不如自己先做。

我当时的打法很简单，就是刷视频号和直播间，找自己能直接上手、门槛不高的品，先试水。

第一款选了水草鱼缸。自己觉得很有把握，跟对象说别人能做我也能做。结果直播间布置普通，话术没准备，视频播放差，直播间人越来越少，最后只能收手。

![](img/ff8f0e551d5a93b6e1a415705d44c2f6.png)

第二款是鲁班锁、马蹄铁这类益智玩具。看到有个博主直播间场观常年几万，视频点赞也有好几百。我立刻在拼多多下单拿样品，信心满满开播。下班后连播一周，场观两三千，弹幕也时有时无，就是没人下单。做视频号带货这件事，我开始有点打退堂鼓了。

![](img/beda3d408f13e0184f9862320693cee1.png)

# 2.初步正反馈：模仿热门视频，成功开出第一单

经历了两次测品失败后，我开始收敛，选品不再靠感觉，而是看数据。把近期各平台上爆过的、正在热销的品都整理出来，自己建了个选品群，用小号去收集记录。

![](img/60c5e9a660a7853e6973bec0b51920fc.png)

![](img/4c94d151be16d59342ede9fd5fcb3c53.png)

当时有个风向标帖子说的是拉线地龙，一个地摊前一群人围着老人玩耍的视频，文案是“纯手工，3元一个5块两个贵吗”。这个视频在抖音火了，搬到视频号也火了，评论区全是“怎么买”“在哪买”“上购物车”。需求很清晰，我就去抖音、小红书、快手找素材，直接搬运，联系后端谈佣金上架。播放量有几千上万，但全网素材就二三十个，很快就用完了。于是我开始自己拍，在陪孩子玩的时候顺手录，脚本照搬。播放稳定但没爆过十万，直播因为样品展示不直观，也很难转化。

好在还是出了第一单，通过私信成交的。这次让我明白，干巴巴的产品展示没人看，视频必须有让人想看、想买的钩子。我决定换品继续。

用同样的方法刷到一条黑檀木吊坠定制的视频，点赞2万，评论2700多条。

评论区全是“怎么定制”“多少钱”“怎么下单”。在抖音快手搜关键词，发现大量相关需求，拼多多上销量和评价也不错。

![](img/6c42d60bb06b0a7e99e0a3e4dfe9d903.png)

感觉品相不错，我立刻记下来。视频号上已有视频里出现的人名，也帮我避免了重复搬运。反馈来得很快，星期天晚上搬运半小时后，就有四五个人私信问购买，当天就出了第一单。

打工人最难受的就是周末玩一天，周一又要上班。我提前攒了20条视频草稿，有空就发。结果上班时看到播放从20万飙到100万，心里痒得不行，下班回去私信已经两百多条。预约直播人数也到了两千。我没走商品链接，直接引流到微信，侥幸没被判定违规。转化了几单，当天利润一千左右，转化率太低了。于是联系后端@未来 上品，他没饰品类目资质，上链接审核失败。感谢圈友帮忙提醒，我让他先用微信小店上架，我发链接或二维码给客户自助下单。转化还是不高，还是导流微信成交靠谱。

这里分享两个小技巧，对象想出来的。为了减少频繁加好友，她只通过明确要付钱的客户，后期流量下来再慢慢通过，朋友圈还能做二次转化。

![](img/bf26af034a49bc5488a91eb290aa4753.png)

第二个技巧是讯飞输入法的快捷回复。可以建项目分组，比如老照片修复、光盘修复、吊坠定制，分组管理，处理99+私信时效率翻倍，强烈推荐。

# 3.及时复盘：直播间单日佣金一万+

在瓜哥的指导下，我和对象一起优化了微信引流和成交话术，也解决了上品和置顶视频的问题，每天直播后复盘。

![](img/81eeb2eb0ea63a8c8aca7aa408afaa21.png)

首先，我去私信了几家有饰品资质的店铺说明情况，折腾了好久才确定合作，后台审核又等了一天，终于成功挂上视频号小店链接。

## 3.1优化视频号引流到微信的话术

第一版话术是介绍黑檀木的寓意。流量上来后就换了第二版，直接干脆。

第二版话术格式：微信号+款式+价格+刻字信息备注格式+收货地址。还有个细节，话术发完后我会单独再发一遍微信号，方便客户复制，提高成交率。

## 3.2做置顶视频，引导下单

因为白天要上班，只能晚上播，白天的流量就浪费了。我们拍了一条置顶引导视频，手把手教用户怎么下单、怎么备注刻字。用黄色背景配黑色大字，标题写“吊坠购买，下单流程”，醒目又清晰。这条视频后来贡献了2500+佣金。

## 3.3优化直播流程和话术，GMV倍增

### 3.3.1直播前的准备工作

直播前我先把产品的热门款式和尺寸摸清楚了。最畅销的是夫妻款，其次是兄弟款、兄妹款、姐妹款、姐弟款、三人款、一家三口、四口、五口款，主推夫妻款。

黑檀木吊坠图案很多，为了方便客户和我们出单，我把品类归为三大类，5个SKU：夫妻款/兄弟兄妹姐妹姐弟款/三人款/经典一家人款。

![](img/0f47e05fc5a545efea3365c0140bb865.png)

![](img/98adacc8772829ffb595d364223e3d6c.png)

定价：88元一对，三块128元。

### 3.3.2直播话术优化，GMV成倍增长

这个品类目前没人做直播，我们没有参考。第一次直播预约3000人，高峰期七八百人在线，我完全hold不住，又慌又兴奋，话都说不清楚。实际就出了几单。

后来人数稳定在80人左右时，我慢慢讲，讲材料、尺寸、颜色，“项链绳子是紫色，紫气东来，寓意好”。第一场每小时出十几单，利润四五百。对象提醒我别自嗨，客户不想听这些。我才醒悟。

我们倒推直播流程，只讲客户想知道的。出单的关键是引导下单，尺寸材料可以讲，绳子颜色寓意就没必要。直播间人流动快，要几分钟一个循环，快速教用户下单。

二是提升停留和互动。买这个品的人群多在40-60岁，不太会直播购物也不懂定制。于是我引导：“想买定制吊坠的朋友扣1，不会下单的扣2，主播手把手教。”然后点名互动，提高粘性。

90%订单是夫妻款，话术简化为：介绍产品+cue人问款式+引导点购物车下单+循环。两人配合，一人播一人助播。助播会发，“吊坠是黑檀木，5.3*2.6*0.8cm”“88元一对，前10名送礼盒”，每次出单就发“又有一位小伙伴下单啦”。经过几次迭代，每小时GMV翻倍。

### 3.3.3把握直播节奏，7小时260单，单日佣金破万

最开始要求客户先备注再付款，每晚要花一小时核对后台信息，常有人备注错、发给客服。视频号私信不能连续发，客户以为被拉黑就去退款。我们改成先下单再备注。这样单位时间出单效率大幅提升。

周日下午五点开播，一小时后在线从一百猛增到四百，维持三百左右，明显是视频爆了。这个时候不能被弹幕带跑，要控节奏。我把流程反过来：“想下单的扣1，不会操作的扣2，先不要点购物车，我们分两步，先下单再刻字。”然后演示点购物车、选款式、直接下单，下单后在直播间报已下单，再教怎么备注刻字。反复循环。手播不露脸，直接对着屏幕操作。

就这样，300多单，销售额两万多，当天佣金过万。

# 4.项目复盘：抛砖引玉

下播后我们会及时回私信、联系客服和厂家。但刻字内容繁琐，姓名生日生肖等，一个人就要八个信息。商品因评分低被下架。有用户投诉刻字错误，要求重刻。直播时账号被举报强制下线，我也被限流。

厂家的原则是客户自身问题不负责，比如备注错误不退换。客户没备注姓名，他们会电话微信沟通。总体还算可以。我这边积极沟通，讲理的就解决，不讲理的也不纠缠，偶尔自己掏钱重刻一对。好心态比一点小钱重要。

7天直播佣金2.9万，微信引流出100多单佣金6000。后来平台对同质化内容限流，手翻吊坠展示的视频流量骤降。我就去请教商家，用灯箱补光拍摄，也去户外拍，播放有了但转化一般。

我的想法是下一步要优化内容，加入故事线。像修手机博主那样，“客户寄来2010年的手机，里面有她和奶奶的合照”，类似“陈先生和李太太相爱多年，特意定制一副黑檀木吊坠”。用工厂加工的真实素材剪辑会更可信，暂时还没做。

前段时间厂家给我发了个两万点赞的视频号链接，也是桌上翻吊坠的老形式，没想到还能玩。我已经在接触AI绘画做持续变现，就没继续。

整个项目下来，最大的体会就是不断复盘、解决问题。小结几点：

1.陌生的领域不要怕，多找对标拆解，先赚到第一笔钱建立信心，再持续优化
2.选品看数据，测品更关键。精选联盟、考古加都是好工具
3.黑檀木吊坠之外，其他定制品也能挖，比如定制画像，注意刻字信息别太复杂
4.内容要升级，发散思考，加故事提升播放
5.流量很短暂，机会来了就要拼命抓住
