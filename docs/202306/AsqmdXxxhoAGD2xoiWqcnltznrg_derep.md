# 图文二创还能玩哪些赛道？两套打法帮你把全盘理清楚



大家好，我是龙哥，圈里人叫我最懂新手的那个。

今天早上刷到@盗坤 坤哥抛出的图文二创相关讨论，底下互动挺猛。https://t.zsxq.com/0fTbH430T
借着这波热度，我也整理两组马上能上手的操作，让你对图文二创这件事看得更立体。

文末有彩蛋，別着急划走。

所谓看清全盘，其实就拆成三问：

1. 剔除服装赛道以外，还有哪些品类能用图文二创带货？
2. 品类确认后，怎么快速锁定一批同类型账号？
3. 锁定之后，怎么把对手账号的真实表现扒得更细？

## 一、靠考古加先把可做的品类和样本账号找出来

先上工具：抖音第三方数据平台 考古加 https://www.kaogujia.com
没有权限的话可以扫码领7天试用。

![](img/211a61770bbd5ddde61ef12f86d70423.png)

筛选思路放下面了，照图走就行。

![](img/c324a5d8e97216c9e8ac928d13f3d708.png)

具体拆解：

1. 进入视频入口，打开筛选页面。
2. 条件里勾选图文，只抓图文二创形式的内容。
3. 时间维度选7日，捞出近一周爆过的图文。
4. 电商标签逐个点开，挨个一级类目扫一遍，看除了服饰外还有哪些品类在做图文二创带货。服饰这种大盘下面还能再细分二级品类，比如鞋履、箱包等。![](img/fec7579191726ac762c6abdd63368d6d.png)
5. 进入类目后，同时翻内容视频和电商视频。
* 内容视频：未挂小黄车的，通常是引流或私域沉淀，会导到🛰️成交。
* 电商视频：已挂小黄车的，直接在站内闭环变现。
6. 循环第4、5步，把不同品类里走私域和走站内两套打法账号都收齐。

> 别只看不动，直接照着跑一遍。
理论不用堆，流程跑通，你自然就豁然开朗，还顺带学会了找参照账号的路子。

## 二、拿到参照账号后，用巨量百应把数据补齐到官方口径

考古加的数据面很广，但多数是估算，不够准。
这时候就要上官方工具做交叉：巨量百应。

### 巨量百应能看到什么

1. 账号整体带货画像：累计带货天数、短视频/直播/橱窗出单结构、近7/30/90天带货总额、粉丝规模 ![](img/b580911e2b47ff5c8f6b1f7351012fbe.png)
2. 单条短视频拆解：发布时点、播放、互动率、销售额、种草人数 ![](img/e894a02d3ff3571889d64b5f44ab9b5a.png)
3. 选品与投放策略：账号做了哪些品？每款用了多少条内容去推？ ![](img/9ebddd299616f88d77b6c92920962fdf.png)
4. 单品追踪：针对某个爆品，投了多少条视频、分别什么时间发 ![](img/199aab9c7c68ded7a9682303c36fc8ee.png)

以上全是官方口径，可靠度高。

### 怎么开

门槛很低，只要有一个可挂橱窗的抖音号。
现阶段开橱窗条件：0粉丝 + 完成实名，基本等于零门槛。
路径：我页右上角三横 ➡️ 创作者中心 ➡️ 变现任务 ➡️ 去带货，按指引完成实名与银行卡绑定即可。

有了这个号，就能用巨量百应把参照账号的数据完整扒开。

## 三、看清楚之后怎么学？照着守破离来

能看全只是起点。
如果你按上面两步实操了，半小时内就能沉淀两项硬技能：

1. 用考古加定位图文二创的类目及参照账号
2. 用巨量百应把参照账号的表现拆解干净

有了这两项，你就能复刻同行的打法。

## 写在最后

常听到反馈：看了很多帖子更焦虑了，现实却没变化。
