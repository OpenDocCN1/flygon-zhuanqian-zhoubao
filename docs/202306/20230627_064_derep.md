# “分享”这件事里，藏着很多钱

你知道吗？最近我回看自己写过的那些内容，突然意识到一个真相：我现在能拿得出手的成绩，几乎全都来自同一个习惯——毫无保留地把自己会的、懂的、踩过坑的东西，摊开来写给别人看。

我心里一直有个很简单的念头：只要读者想学，就能从我的文章里学到真东西；只要读者想照着做，就能真正落地。因为那些东西，都是我自己一步步试出来、总结出来的。

我慢慢发现，但凡我带着这样的心态去写，哪怕只是复盘一段自己的经历，那篇文章都会在之后给我带来意想不到的影响力，甚至有人会主动帮我转发。

有一次我正埋头写文章，手机🛰️一直闪。我本来不想理，但看到是君言群的消息，就随手点开看了一眼。结果第一眼就看见一句话：“这人我一搜，居然就在咱们群里。”

我当时就好奇了——这是谁呀？赶紧吃瓜。点开图片一看：![](img/c6d26aa0a85ea2685221ddd300b94495.png)

原来那是我写的文章。下面全是艾特我的、夸我的。我盯着屏幕组织了半天的语言，愣是不敢回复，哈哈。

但那会儿我心里特别清楚，自己做了一件挺有意义的事。那篇文章发出来的时候确实带来了一些转化，我以为那就结束了，文章也会随着时间沉下去。可没想到，它还能在后来继续发酵，影响到一群又一群原本不认识我的人。

从那之后，加我好友的人越来越多。我没有急着转化，因为我知道，这些人都是认可我、跟我同频的人。未来我们之间一定会发生点什么，产生更深的连接，那比直接赚到钱更值钱。

真诚又有价值的内容，是会在同频的人中间自动流动的。看到的人就像挖到宝藏一样惊喜，会像珍惜钱一样珍惜它。

后来我做尾货生意，也把自己的经验顺手写了出来。结果没过多久，好几个人做尾货的 APP 主动来邀请我去做客，把我拉进他们所有的群，让我在里面发尾货。那一下子，我的客源和货源都丰富了。我一边收货，一边跟别的源头卖家谈合作，帮他们卖货，自己做个中间商，美滋滋。

我还把在闲鱼卖尾货的经验复盘完，发到了👸号、知乎和卢松松平台。有一天，知乎上突然有个读者跑来评论，说看了我的文章，8 月份赚了一万多。![](img/7fff7fb8442b942741438e92204f552b.png)

做知乎好物的时候也一样，我把自己的方法毫无保留地写了出来。可能被知乎编辑注意到了，本来只有 8 个赞的文章，突然就爆了，到现在已经两万多赞。很多人跑来给我反馈，说深受启发。后来我做起知识付费，相当大一部分付费用户，都是被那篇文章吸引来的。

说到底，对于真正的真知灼见，人们从来不吝啬点赞，甚至愿意真金白银地支持。

还有一件事，对我影响特别大。当时我花差不多三万块买了一个同行的产品，这里叫他小 A 吧。虽然我买了他的产品，但我并没有让他帮我做什么，反而把自己的一套核心机密分享给了他，帮他解决了一个当时特别棘手的难题。

我们其实是同行，那套方法对我们双方来说都很关键。但我不仅把方法告诉他了，连同文案、细节全发过去了。说实话，我自己也不知道该不该这么做，毕竟是竞争关系。但当时我就一个想法——先把问题解决了再说。

结果当天晚上，他就把方法落地了。更有意思的是，他其实并没有完全理解那套玩法的精髓，但还是照样去做了。

我的这个方法，是根据我自己的阶段和目标设计的。想用好，就必须根据自己的实际情况去调整、去套用。但他没想那么多，直接照搬，很多地方改得漏洞百出。

如果是当时的我，看到这么多漏洞，我肯定会在意别人怎么看我，会觉得别人这么做肯定有一套完整体系，我要先把体系研究透了再落地。

但他就这么干了。后来他在这套方法的基础上慢慢迭代，最后彻底为自己的事业创造了巨大价值。

这件事教会了我两件事：

第一，敢干。你评估一万遍、深思熟虑一万遍，都不如自己动手去干一遍。

第二，学东西学的是思路。什么是思路？就是看对方做了什么取舍、想了什么过程。这么学，进步特别快。

这两点后来成了我能做成一些事的关键。但如果没有当初那次真诚的分享，我永远也学不到这些东西。

说到这儿，你可能已经心潮澎湃，想马上去分享点什么。但再一想，又觉得自己好像没什么值得分享的。如果你也有这种感觉，那就记住一句话：别对自己的内容做评价，更别给内容设限。

第一，别评价它简不简单。

我以前总觉得，太简单的东西不值得分享。直到有一次在赚钱看到了这个：![](img/5c838a17daddfa6c869712d03d3500ae.png)

102 个点赞，下面还有人留言求网址。其实这个网站我早就知道，要是我自己，我肯定觉得这有什么好说的？但人家分享出来了，还爆了。

所以啊，别总觉得自己分享的东西含金量不够、难度不够。思路错了。只要对别人有用，简单的东西更要分享。不要不屑于分享那些你觉得很基础的东西。

还是那句话：你的常识，可能是别人的盲区。

第二，别评价它靠不靠谱。

前段时间我在赚钱发了篇文章，发之前心里直打鼓，总觉得自己那点所谓的经验，真的靠谱吗？

但后来看到很多大佬，把每一点小成绩都认真复盘，分享给大家，这给了我很大的鼓励。于是我也发了一篇。结果龙哥大佬给我点赞了，我特别激动。![](img/74bd609df54b3bf3116a50ee886ed50c.png)

如果我没发这篇文章，就不会有这么多人认可，龙哥大佬也不会给我点赞。

所以，你总结的那点所谓的经验，真的靠谱吗？答案其实很简单：发了才知道。
