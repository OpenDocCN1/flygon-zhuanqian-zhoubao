# 裸辞一年，从带娃宝妈到月入过万，我只是把“左手育儿，右手事业”活出来了
作者：龙哥

大家好，我是龙哥。

2023年6月，正好是我离开职场满一年的节点。回头看那段从2022年6月到现在的旅程，变化大到我自己都不敢信：一个职场妈妈，辞掉工作开始创业；月收入从归零到稳定过万；家里从背负债务到攒下首付买房安家。

很多人问我怎么做到的。说实话，我起点并不漂亮。年龄不小了，没什么出众的外形，也没有高学历和硬核技能，更谈不上资源背景。就这样一个普普通通的中年宝妈，却在一年里做到了两件我从前觉得不可能的事：一是真正有了自己的学员，并推出了自己的知识付费课程；二是把自己摸索出来的这条路，变成后来者能借鉴的微光。

没有一蹴而就，只有每天在育儿间隙里坚持打磨内容、陪伴学员、把经验变成方法。这一年最大的感悟是：创业不靠颜值，靠的是持续输出和真诚的陪伴。
