# 如何从 0-1 成功地做起来一个项目
作者：龙哥

如何在闲鱼从 0 到 1 跑通一个项目？今天换个角度聊聊。

很多人把闲鱼仅仅当成清闲置的地方，其实里面藏着不少细分机会。老瞿 Qu 就是一个典型案例。他专攻闲鱼二手书，年销售额做到了 500 万元以上，整体利润率大概 30%。他自己调侃，是“龙哥盟最懂二手书的男人”。

为什么偏偏是二手书？因为这个赛道正在迎来一波明确的需求红利。大学教材的管控逐渐放开，大学生对二手教材的接受度越来越高，再加上整体消费心态趋于理性，越来越多人愿意买二手书。换句话说，需求还在往上走，而且远未饱和。

更关键的是，这个类目和闲鱼上多数普通选品不一样——它有一道准入壁垒：出版物经营许可证。单是这一张证，就能挡掉一大波想进场的人。老瞿的观点很直接：如果你暂时打造不出属于自己的独特优势，那就别错过那些自带门槛的项目。门槛本身就意味着竞争会小很多，也意味着后来的玩家没那么容易抄作业。
