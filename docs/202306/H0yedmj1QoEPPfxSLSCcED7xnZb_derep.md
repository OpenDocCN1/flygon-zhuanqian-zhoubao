# 小白友好向——5分钟快速上手视频剪辑

小白别慌！五分钟吃透视频剪辑，这份保姆级上手指南直接抄作业。

很多刚接触剪辑的朋友，总是卡在第一步：选什么工具？怎么开始？今天就把我压箱底的工作流全摊开讲，保证你跟着做也能快速上手，少走弯路。

## 一、工具怎么选？

### 主力组合：PR + 剪映

一个负责快速产出，一个负责效率精修，配合起来很顺手。 ![](img/4285d81f716271f00cb13b7964767d2f.png) ![](img/71ecbc4ec477c88dd9d86e43e181989d.png)

**剪映**：桌面端专业版完全够用，界面直观，适合新手快速出活。官方直接下载就行。

**PR**：这里放一个百度云资源，供大家取用。  
链接：https://pan.baidu.com/s/1n08I03YjDhwyGnFqtQ7ovw  
提取码：eakd ![](img/1103f99663ac3964b127051852e3a2cd.png)  
安装不太会的，参考这篇教程：https://zhuanlan.zhihu.com/p/456842774

### 辅助工具

- **LosslessCut**：无损剪切神器，专门用来快速分割素材，还能把每段单独批量导出。GitHub上有开源版，Windows用户直接下载。缺点就是得手动一段段切，不像剪映能智能识别，但它胜在能一次性导出多段。 ![](img/cebc653d21d7cef40ab4d708ccd7dbc4.png)  
  使用教程可以看这个：https://v.douyin.com/UaoJWcJ/

- **哼哼喵**：付费但很好用的去水印工具，下载抖音素材很省事。  
  不想花钱的话，用小程序「抖快助手」代替，每天能免费提取20条。

## 二、小白最顺的上手路径

### 先玩熟剪映PC版，这是最快出效果的起点

下载后，一定要去「剪映学习中心」刷一遍基础操作，先看“新手必看”就够用了。  
https://www.capcut.cn/learning ![](img/119e9d9c1d577dbe94c63143b02d3185.png)

想学进阶功能，直接去抖音搜「楠哥的课」，想学哪个功能就搜哪个，基本三分钟搞定一个。  
https://v.douyin.com/U5W2SwC/ ![](img/47d7c7f7442b02e7eda4c0483d6ae106.png)

接下来实操：

1. 点「开始创作」进入编辑页。这里有个很赞的地方——剪映可以直接导入PR的工程文件，尤其方便后面加字幕。 ![](img/1c6e7064d14b8558f82008431467cc84.png)
2. 从「导入」选好素材，拖到主轨道上。 ![](img/ff6c62b3df565df0c2726ce96c71b0da.png)
3. 接着就是常规操作：分割、翻转、放大、变速等等。 ![](img/56a8e2228e657510efcc7fd2fe2fbc13.png)![](img/ffbe147f7f789d3f3b369c4311f43133.png)
4. 快捷键给你放这儿了，保存成肌肉记忆效率翻倍。 ![](img/850ff0bc5b410ff006ec0fcce6719b12.png)

### 字幕怎么处理？

粗剪完毕，先做音轨分离：快捷键 `Ctrl+Shift+S`，然后选中音频，右键→「识别字幕」。 ![](img/1c2cad2ade7a4a0452ef968cd81224e6.png)  
字幕出来后，可以自由调整样式和字体。 ![](img/14d37db890945f954027e3c316ed64c5.png)

### 想换音轨？

用字幕功能的「朗读」重新生成一条音轨，就能把原声替换掉。 ![](img/c24eeb20ba75860c6283fb061d089abc.png)  
记得把原来的音轨关掉。 ![](img/9163d4be45f01d346741783d61325b84.png)

### 怎么加BGM？

去抖音创作者中心，翻「热歌榜」或「飙升榜」找爆款音乐。 ![](img/f9a7b7d353516771a3bd6234e85da87d.png)  
然后在剪映「音频」→「音乐素材」里搜到它，点小加号添加，注意开头要对齐。 ![](img/962ba24e86d425490a454bd972da6aa4.png)  
太长的部分用 `Ctrl+B` 切断删掉。 ![](img/e12cb5c0315afc29aae3236af25a8321.png)  
选中音频调音量、淡入淡出：口播视频建议BGM音量-15，人声+8；纯BGM卡点素材就BGM+8。当然，以自己听感为准。 ![](img/d80f40b0fa994aa77f800a45d3a310ce.png)

合适的地方再加点音效，氛围马上不一样。 ![](img/a1024ad395efb39462456289e88b3930.png)

### 加分项：贴纸、转场、滤镜

在关键位置加个引导下单的贴纸，转化率说不定能涨。 ![](img/f9ec19050cd1a2a47584eac49dc2e847.png)  
转场和滤镜按需添加，顺便还能帮视频去重。 ![](img/4ee9a749e4a861c00329f7ca3ca195dc.png)

## 三、进阶：用PR把效率拉满

### 基础设置一定要做

先给项目取好名字，选好存储路径，方便之后找源文件。咱们做竖屏视频，记得设成9:16。 ![](img/72c7723544a66e1fe09d5a839b539e0d.png)

### 新建序列

在项目面板里「新建序列」，取个能认出来的名字。 ![](img/85435def58853514420921232a29a8e0.png)![](img/4e3e3779b9fd84d2f176ff0adee36656.png)  
重点来了，基础设置四步走：  
1. 帧率选30  
2. 帧大小填1080×1920  
3. 像素选方形  
4. 保存预设 ![](img/fb7cb032991277367761800f214283e2.png)

### 导入素材

直接把素材文件夹拖进工作区就行。 ![](img/1bc250376e94fd496a6a57924a8421d3.png)  
把对标视频拖进来时，因为分辨率不一样，选择「保持现有设置」。 ![](img/c2bb717c849d814debd37c2ca4c9ee8e.png)  
然后调整帧大小： ![](img/dfc721334119b60c1bc0e4c31dd27a6b.png)  
选「缩放为帧大小」，让尺寸保持一致。 ![](img/8fcfd67e9967ac1db5d7cf181850b18a.png)![](img/69beaa48d31003a237b21e562dd7a48b.png)

### 分割素材

PR里分割用的是「剃刀工具」，快捷键是英文输入法下的 `C`。  
也可以用「打标工具」（第二个箭头，快捷键 `M`）先在素材上做标记，方便后面按标记切。  
分割逻辑参考两点：  
- 关键帧的位置，也就是画面有明显变化的地方；  
- 口播一句话结束的位置，做到音画同步。 ![](img/44fa5fb4db70498031cd26e9bbf2d228.png)

### 素材混剪三步走

1. 双击素材，让它显示在上方的「源」窗口；  
2. 用两个小括号键（`I` 和 `O`）标记需要的画面范围；  
3. 把标记好的素材拖到序列里。提前打标，效率极高。 ![](img/0adef9eff5d7e495f962815c52c5460b.png)

完成后检查有没有跳帧，跳帧一般出现在分割点的左右两侧。之后就可以在PR里调色了。

### 导出

`Ctrl+M` 直接导出。

## 四、剪映+PR联动，过审率更高

PR粗剪完，用剪映打开这个工程文件，所有粗剪内容都在。 ![](img/02e125f50a1d7f608d2c49dbf9a04f7d.png)  
精剪环节就回到剪映里操作：  
1. 提取字幕  
2. 朗读字幕  
3. 换BGM  
4. 镜像、缩放、裁剪  
5. 滤镜调色  
6. 加贴纸 ![](img/fb3b2355887347a0882ff402316d2192.png)

说明一下：这套流程只是我最顺手的组合，你可以按自己的习惯调整，PR也有不少好用的插件。  
剪映的痛点是没法直接从预览素材里快速选中想要的片段，这点PR很方便；  
PR的痛点则是字幕、镜像、缩放、贴纸、滤镜这些对小白不太友好，远不如剪映点几下就完成。

## 五、PR里最实用的三个技能

### 超级键

在「效果」面板里，主要用来做绿幕抠图。可以自己造一些素材，顺便给视频去重。 ![](img/c7f3faf3900eb6a8ac7c8cc0f9995487.png)

### 高斯模糊

也在「效果」面板里，适合遮挡字幕、LOGO。有时候素材自带字幕但和我们口播对不上，就用它调整模糊度盖住。 ![](img/6aa92fdaa36619953f115c33f83b5891.png)

### 曲线工具

在「颜色」面板里，相当于自定义滤镜，能随心调整视频色调。 ![](img/24feb049accb54b1d319d03970cc4999.png)
