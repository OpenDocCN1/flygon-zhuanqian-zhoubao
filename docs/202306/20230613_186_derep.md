# 以赚钱为目标，新手在小航海中应该怎么做？

你有没有这样一种感觉：

航海刚开始那几天，整个人像被塞进了一个巨大的信息仓库，精华帖、手册、嘉宾分享、群聊记录……铺天盖地，看完一篇还有十篇，收藏了等于学会了，结果一天下来脑子嗡嗡的，真要动手却不知道该干啥。

但说实话，那股子“开眼”的兴奋劲儿过得也快。一周过去，是时候冷静下来想想了：小航海这个产品，到底怎么用，才能真把它“吃”出价值？

今天不扯虚的，就聊一个最扎心也最现实的话题——

**如果你奔着赚钱来参加小航海，作为一个新手，到底该怎么打？**

当然，聊打法之前，先把目标这件事掰开了说。

启航仪式上，@易仁永澄 那场分享里有个点特别戳我：目标这东西，它不只是一个“方向”，它更像是两样东西——

第一，它是你突破舒适区时那股子心力的来源。人都是怕疼的，没有目标撑着，遇到不舒服就想逃。

第二，它是一个锚点。有了锚，你才知道注意力该往哪儿放，什么该看、什么可以不看。

关于目标的重要性，其实道理大家都懂。但问题是，多少人只是“懂”，却从来没认真想过，自己这趟航海，目标到底是什么？

毕竟，道理不进脑子、不拿去用，再多也是零。

那咱就说个最实在的目标：**把这趟航海的报名费赚回来。**

你会发现，一个目标一旦具体到这种程度，很多原本模糊的选择题，答案会自己浮出来。

**第一个问题：报一个航海，还是报多个？**

我猜，很多新手的第一反应都是：多报几个吧，开开眼，感受感受不同项目。

如果你的目标是“开眼”，那没问题，多多益善。

但如果你的目标是赚钱，是“赚回学费”，那这个问题其实就没得商量了——**只报一个。**

为啥？

你想想看，“赚回学费”意味着什么？意味着你在这 21 天里，至少要完整走完一条流程：理解这个项目的最少必要知识 → 掌握必要技能 → 投入足够的资源去执行，并且在过程中把挡路的难题一个个拆掉。

你扪心自问一下：这事儿，一个新手在三个礼拜里能搞定吗？

真的，能在一个项目上把这条路趟通，就已经非常非常不容易了。你哪来的底气觉得，自己可以在几个项目上同时趟通？

再说了，同时报多个项目，你大概率会遇到下面这种场面——

比如你同时报了视频号带货和📕店铺。刚开始学视频号，正一头雾水呢，突然刷到一篇帖子，说📕无货源爆单了。你心里痒不痒？要不要放下视频号去瞅瞅📕？

好，等你真把注意力挪过去，又开始从头学、又开始一头雾水的时候，又刷到一篇文章，说有人视频号爆单了。你咋办？再挪回去吗？

这就是咱们常说的“反复横跳”。

从一个啥也不懂的新手，变成一个能靠搞定一个项目赚到钱的人，中间那一段路，叫“突破舒适区”。突破舒适区是啥滋味？是你必然要经历学不会、没反馈、甚至想放弃的难受劲儿。

而就在你最难的时候，另一个项目就在你手边，那个诱惑太大了。

大到你根本分不清，自己是在做选择，还是在逃跑。

所以，把“赚回 199 学费”这个目标拿出来称一称，答案很清晰：21 天，全心全意砸在一个项目上，赢面远比你左顾右盼要大得多。

换个角度想，小航海里任何一个以赚钱为主题的项目，只要你做通了，做顺了，赚回来的可远不止这几倍学费。

所以，想赚回学费，你根本不需要知道很多项目、不需要懂很多项目，甚至不需要精挑细选去找到那个最红利、最“适合”你的项目。

有了目标，你就有了判断力：这件事该做吗？它服务于我的目标吗？

**第二个问题：一个项目就够了吗？不够。**

把注意力收束到一个项目上，这只是第一步。因为就算你只管一个项目，那堆资料还是能把你淹没。

小航海的每一本手册、每一位嘉宾的分享，内容都做得非常扎实。但是——请注意这个“但是”——那是对于已经赚到过钱、脑子里有一套自己判断框架的大佬来说的。他们看一眼，就知道这个方法适不适合自己、那个细节怎么落地。

可新手没有这个框架，也没有这个判断力。

所以，你大概率会遇到下面这些情况：

- 选品方法这么多，每个听起来都好有道理，我该用哪个？
- 这位嘉宾说往东，那位嘉宾说往西，做法完全不同，但好像都能赚到钱，我到底听谁的？
- 好家伙，如果把所有玩法都学一遍，时间全花在“学”上了，哪还有功夫去“做”？

发现没有？我们不但容易在不同的项目之间横跳，还特别容易在同一个项目的不同玩法之间横跳。

那怎么办？还得再收一收。

回到我们的目标——赚回学费。请问，要实现这个目标，你需要把整个项目全搞明白吗？

真不需要。

你只需要搞定一个项目里的**一个玩法**就够用了。

想把学费赚回来，咱们不必当一个博学多才的老师。

那这意味着什么呢？意味着——

当你听了几个嘉宾的分享，下定决心要跟着某一位的玩法走之后，其他嘉宾的分享，哪怕呼声再高、口碑再好，你都可以不听了。

意味着当你选定了一套打法之后，别人用另一套打法出了成绩、晒了收益，这些信息也通通和你无关。你只管把自己选定的这套玩法学透、做透。

专注，从来不只是“你要做什么”，更是“你可以不做什么”。

当你把注意力从“这么多项目”缩小到一个项目，再从一个项目缩小到一个玩法的时候，你会发现，焦虑感真的会退潮。不是因为你变强了，而是因为你能看到路径了。

所以，如果这篇文章只能让你记住一句话，那我希望你记住这句：

**如果你的目标是赚回学费，你不需要懂那么多，你只需要搞定一个项目的一个玩法就够了。**

这，就是搞钱新手参加小航海的正确姿势，也是把我从新手期拽出来的那个朴素道理。

我是郭晓文，一个被说最懂新手的人。希望这篇小作文，能帮你把悬着的心放下来一点。

想慢慢变富？咱们在这条路上一起磨。
