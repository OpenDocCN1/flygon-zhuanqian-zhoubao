# MJ 风格图鉴合集：名字看不出感觉，出图才懂
作者：龙哥

作者 白翼撒旦 在 2023-05-30 发起了一则整理帖，主题是围绕 Midjourney 的各类风格画风做一次系统性的图样盘点。

这次汇总的初衷很简单，就是想把散落在各处的风格关键词和视觉效果集中起来，方便大家快速get到手感。作者本人复盘时提到一个最真实的体验：光看风格的名称，往往很难产生具象联想，但真正跑图之后，差异立刻就变得明晰可辨。希望这份笔记也能帮到正在摸索风格语法的朋友。

对原文有兴趣的可以移步查阅，原文出处：[`www.yuque.com/for_lazy/thfiu8/dklcsm4bgznyg4b8`](https://www.yuque.com/for_lazy/thfiu8/dklcsm4bgznyg4b8)

帖子发布后也引发了一些讨论：

春风王锐 表示这个整理很强，并提到之前见过有人用表格形式做过统计，后续会尝试搬运过来。
水木目 觉得哥特风格气场很重，像是直接从恐怖片剧照里截出来的，有趣。
作者 白翼撒旦 回复认同，哥特调性确实很适合做鬼片氛围，尤其是配合 stop 指令在生成功能停止前截取，制造出若隐若现的模糊鬼影效果，氛围感直接拉满。
咖啡色 感谢分享，表示内容实用程度很高。
芳小姐 称赞整理非常用心，体现了认真、努力和利他精神，并向作者致敬。
作者 白翼撒旦 对此表示感谢并回馈鼓励。

整体来看，这份 MJ 不同类型风格的图样分享，核心价值在于把抽象的风格名词转化为可视化的结果对照，帮助创作者少走弯路，更快找到自己想要的视觉语言。
