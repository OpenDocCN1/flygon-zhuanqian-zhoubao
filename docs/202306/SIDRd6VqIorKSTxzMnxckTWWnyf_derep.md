# 如何生成自己的儿童绘画故事
作者：龙哥

你是不是觉得给孩子做绘本既要有画功，又得会讲故事？其实这些都不需要。只要一条简单的提示词，AI就能帮你生成一个专属的儿童绘画故事。要不要试试？跟着我一步步来。

这次示例的主题是“The Lost Boy and the Rainbow Pig”（迷路男孩与彩虹猪）。

第一步：打开ChatGPT，前往插件市场，查找并安装“Stories”插件。
![](img/409b3cc5c781f582e8deb7ce404766a7.png)

第二步：选中该插件后，键入指令：“迷失的男孩和彩虹猪”。
![](img/b37aca6063c53ae042a8545164007782.png)

第三步：点击它给出的链接，进入绘本生成界面，稍作等待。
![](img/71a4cd19fa40b7e9df1db3b3c04cdf8c.png)

等待的过程中，故事会慢慢渲染出来。

这里有两点要提醒大家：一是目前绘本只支持英文展示，可以用翻译软件辅助阅读；二是你可以主动要求生成若干页的绘本，数量可控。

总结一下：完成故事之后，还能定制精装实体绘本（目前仅限美国地区），并放到亚马逊上销售获利；在国内，如果做母婴或图书相关内容，也可以用它来吸引流量。
