# 我通过流量主每月被动收入超 5W 的历程分享
作者：龙哥

从月薪3000到每月被动收入5W+：一个普通程序员在老年小程序赛道的实操复盘

大家好，我是龙哥。做小程序开发快五年了，过去三年基本都泡在老年私域粉和👸号、小程序流量主这条赛道上。想起三年前大四实习那会儿，一个月到手也就三千块，谁能想到几年后，我能在不影响本职工作和个人IP业务的前提下，同时兼职打理几十个👸号和小程序。

今年二月份上线了一款小程序，现在这样正在持续盈利的老年小程序，我已经做到12个了。![](img/d684d0f62841db1acbeaa65762a9a607.png) 再看这张截图，是我今年新开的一个老年👸号的收益，类似的号，我手里一共有15个。![](img/5f4bceb0097b1a0ce615bea0db72d65c.png)

在龙哥盟这种高手如林的地方，这点成绩或许算不上啥。但对我来说，一个普通人在当下这个阶段能取得这样的结果，心里确实挺知足的。所以这篇内容，我想把自己如何从最初的一片迷茫，到慢慢找准赚钱方向，再到把老年私域粉的引流和变现路径彻底跑通的全过程，逐一分享给大家。
