# 才讲了十几分钟，我就让全场一百多个人放下手机了

最近被一所大学邀请去做了一场行业分享，结束后整个人有点恍惚，也想把这件事说清楚。

场地不大，坐了大概一百来号人。开场前我随口聊了两句，问问大家学什么专业、几年级。还没正式开始，我就注意到画面有点尴尬——差不多一半的学生低着头在刷手机，对我抛出的破冰问题几乎零反应。

我好奇问了一句：你们是为什么来听这个讲座的？全场安静。能立刻说出我名字的只有两个人，其他人显然是被动来的。那个氛围，就像脱口秀演员憋了几个包袱，全场一点回响都没有。

散场后跟带我的老师私下聊，才明白规则：来听一次这样的外部讲座，可以算作一个课时。学校每年有指标，必须邀请一定数量的行业人士进校园。所以这次邀请，更多是完成任务。

明白了来龙去脉，我当场做了两件事。

第一，我直接叫停了。然后对全场说：手机先放下。如果你们继续刷，我就不讲了。想走的现在就走，我只讲给愿意听的人，哪怕最后只剩一个。别误会，我不是你们的老师，不受教学规约约束，也没有课时压力。我今天可以马上离开，不耽误你们。

话说完，刷手机的手都抬起来了。我顺势反问：平时在课堂上也都是这个状态吗？你们的任课老师是怎么坚持下来的？前排坐着的老师尴尬得直点头。

第二，我把准备好的PPT关了。那批听众是市场营销的大一新生，我原本的案例和框架对他们来说太超前，根本接不住。

于是我换了个角度开讲，不用PPT，就聊一个很直接的问题：你们学市场营销一年了，有哪一点能真正帮你把自己卖出去？有哪一点能让你更接近一份工作，或者解决一个现实里会遇到的麻烦？如果没有，那过去这一年到底在做什么？未来三年还想继续复制这种状态吗？

我觉得对这群刚入学、眼神里全是迷茫的孩子，讲营销术语没意义，给点能用的东西更实在。我临时聊了一个多小时，最后有多少人真正听进去了我也不确定，但结束后确实有不少学生主动上来交流。

说实话，我挺难受的。大部分学生上课就是这种半放空状态，不知道该怎么学，也学不到可迁移的技能，等到毕业的时候连自己能做什么都不清楚，然后再感慨就业难。

当然也有例外，现场就有几个同学在外面跑咖啡馆、做自媒体的，眼神就不一样。

后来邀请我的老师跟我说，你是第一个敢直接制止学生玩手机的外部嘉宾，而且这场反馈是最好的。

我没有万灵药，只希望能喊醒十个八个孩子，让他们不再在大学里虚耗。我这趟才算没白跑。
