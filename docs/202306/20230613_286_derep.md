# 《小红书电商单人月入 6k 实战分享》

小红书电商现在还能做吗？我的答案是：能，而且一个人一台手机也能跑出不错的结果。这件事不是我拍脑袋说的，是我自己真金白银跑出来的。

先简单介绍一下自己：我叫行一，一个还在读大三的普通人，同时也是珠宝私域直营团队背后的操盘手。目前手上有两个团队，一个主攻高客单流量，像是命理和珠宝，命理这块最近停了，重心放在高端珠宝上；另一个是电商直营团队，刚组建两个月，团队一共五个人，净利润已经突破了十万。现在手里还有不少账号在稳定出单，平均算下来，一个人管一个账号，每个月赚六千块没什么悬念。

很多人好奇我是怎么起步的。说实话，我是今年二月中旬才接触到小红书电商，第一号做起来出奇地快，第五天就爆单了。看到跑通了，我马上按流量团队的打法搭建电商团队，分工很清晰：有人专门扒素材、剪视频；有人负责账号和客服，一个账号会多管几个，建议至少一个人手里握五个号；还有人管发货和售后。就这样，一套直营团队就跑起来了。

再聊聊选品经验。我最早打爆的产品是内衣，那个品类真的是自带流量，早期只要发视频就能出单。当时我把同行的号几乎都装进对标库里，认真观察了一个月，做了不少数据对比。但现在内衣赛道已经卷得不行了，还有同行恶意举报，不太好做。所以我现在把主要精力放到了女装、童装、女裤和女鞋上，这些品类里我有一些供应链资源。打法也在升级，从原来的纯搬运慢慢向实拍转型，最近还在研究直播和付费投流。
