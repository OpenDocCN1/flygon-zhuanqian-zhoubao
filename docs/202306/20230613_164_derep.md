# ('如果你想回老家开个小店？我在下沉市场学到的生意经', (2, 26))

前阵子我在唐山乐亭认识了一位老哥，他在小县城靠餐饮生意赚到了千万身家。聊完合作，我对下沉市场的理解彻底刷新了。今天把这些真实经验整理出来，或许能给你一些启发。

这位老哥我们暂且叫他M。三年前他看完一篇关于战略逻辑分析餐饮的文章，决定下场开餐馆。经历了三年疫情，反而越做越稳，在当地已经成了有口碑的招牌店。M一直研究一线品牌的营销打法，也琢磨增长，但总觉得只学到表面。我们交流时，他给我上了一堂特别接地气的下沉市场生意课。

第一，三四线开店可能比一二线更赚。房租只有北京的四分之一，营业额能做到一半，算下来利润率反而更高。一家小店，一年净赚二十万以上并不稀奇。

第二，产品必须做出差异化。M开的是熟食卤肉店，这类轻加工食品本身差别不大。他到处找秘方、请教厨师，最后改良出一款招牌酱猪头，软糯入味、肥而不腻，能用勺子舀着吃。靠着这个单品，他和其他熟食店拉开了距离。

M不是厨师出身，学的是设计，毕业后回老家做装修，靠整合本地资源成了规模不小的承包商。后来发现餐饮有机会，转身投入，如今开了熟食店、卤味火锅店和烧烤店。他跟我说，只要肯花心思、肯干，小地方照样能靠创新活得很好。

有意思的是，M是华杉的忠实读者，《华杉讲透孙子兵法》翻来覆去读了三遍以上，对书里的理念特别认同。可见写书也是一种深度广告，能悄悄教育市场，还能吸引客户。

M还说，华与华最让他佩服的一点，是餐饮老板能听懂他们的话。很多老板学历不高，听到品牌资产、波士顿矩阵这些术语就头大，但“超级符号”“购买理由”“持续改善”一听就明白。照着他们分享的案例一步步改，进店率和复购率都上去了。把专业的东西翻译成能落地的方法，这种本事确实难得。

说到大牌下沉，M这条街曾经来过双汇熟食、紫燕百味鸡，最后都没干下去。原因有三：直营店店长是打工心态，拼不过创业的小老板；熟人市场排外，本地顾客一听不是本地口音，慢慢就不来了，还可能有人故意找麻烦；加盟店的产品和供货又不灵活，跟不上变化。一线品牌在市中心也许通吃，到了小城，“强龙不压地头蛇”是实打实的道理。

下沉市场对价格极其敏感。便宜就是硬道理。大牌为了品质把成本堆上去，定价高，消费者不买账。而在本地人看来，对品牌的感知没那么强，价格实惠比什么都有说服力。

人情市场更是关键，分成三层。第一要搞定顾客：小地方熟人社会，东西好、老板会来事，口碑就传开了。第二要搞定同行：赚钱别太张扬，太招摇容易被人眼红，有人闯进店里说吃坏了肚子，开口十倍赔偿，不然就举报，你怎么办？第三要搞定工商管理：《狂飙》里那种事并非虚构。不会搞关系，城管、环保、工商天天上门，说你不合格，生意根本没法做。M的原话是，本地公务员一个月就三四千块，真以为靠工资活？

所以外来品牌想开店，最好开进商场。商场会替你处理消防、排污、卫生这些杂事，也没人来找麻烦。

M还给我讲了一个他亲手把对手挤走的案例。斜对门开了家新熟食店，装修和产品都照抄他，开业促销抢走不少生意，第一天就少了三千流水。员工急得要命，M却稳住，观察了几天，发现自家生意正慢慢回暖，而对手的进货量一天比一天大。于是他将计就计，连续六天看着对面搞活动不吭声，第七天自己突然备了大批货，热销品半价，喇叭、传单、地推全上。对面一看生意被抢，正等着新一批货卖，结果囤的熟食全砸手里——保质期就两天，当天营业额直接崩盘，保守估计亏了上万。那家店没多久就关门了。M说这就是孙子兵法的“一战而定”，不打拉锯战，找准时机一仗解决。

还有一个细节：M的卤味偏重油重盐，在一线城市会被骂不健康，本地人却爱得不行。可见大牌进入下沉市场，拿一线经验根本行不通。像元气森林这种无糖饮料，在当地明显卖不过康师傅、统一。一线到三线，消费认知差距可能是断层式的。

M本来计划把重心转向卤味火锅店，我劝他重新想想：熟食店标准化程度高、复制成本低、投入小、市场大，有潜力做成千家万家店；火锅店操作复杂、投资高，连海底捞也就开了一千多家，天花板很清楚。M听了如梦初醒，决定先把熟食店单店模型打磨好，再走加盟路线。

最后我自己最大的感触是：经营的底层逻辑和落地执行，永远是那个“1”；品牌、营销、设计、产品规划这些，都只是后面的“0”。没有前面的1，后面再多的0也没有意义。
