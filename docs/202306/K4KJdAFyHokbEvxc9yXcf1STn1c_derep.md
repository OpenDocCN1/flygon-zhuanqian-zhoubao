# 别只盯着眼前的数字，真正的答案都在过程里
作者：龙哥

大家好，我是龙哥。第一次以赚钱新人的身份走完一期航海，今天想和大家聊聊：新人到底怎么才能快速“把手弄脏”，以及这一路我到底想明白了什么。

先放战绩：我报的是👸号爆文项目，航海快结束时终于有一个号进了流量池，到6月15号累计收益600多。和那些日入三位数、四位数的圈友比，确实不值一提，门票也还没完全赚回来。但这完全在我的预期内，至于为什么，往下看你会找到答案。

![](img/e39d83aae187d0d8923a38f7e127ee17.png)

刚进赚钱那几天，说实话，整个人都处在亢奋状态。满屏的玩法、案例、拆解，我像饿了好几天一样猛刷，脑子里反复冒出来的声音全是“哇，这也能行”“这个好像适合我”“我上我也行”。就这么刷了半个月，兴奋劲儿反而退了——看到越来越多新人已经晒出成绩，我的焦虑占领了高地。

后来我认真想了想，焦虑的本质是什么？无非是你想要某个结果，可要么能力跟不上，要么干脆没动手。想通这一点，我冷静下来，重新打开刚入圈那天就收藏的《龙哥益语》。我一直相信，向已经拿到结果的人学习，是最靠谱的路径。

里面有句话深深击中了我：“弱化教程，实战下场。”成年人的世界，哪有什么“既要又要”？再完备的教程摆在面前，也得你自己动手操作。你不可能完全复刻别人的路径——你的经历、环境、思维、设备、时间，全都和别人不一样。既然这样，想再多不如赶紧下场，把手弄脏。

于是到了航海选项目的时候，我给自己定了个规矩：只选一个最合适的。有人可能会问，为什么不一次多报几个？因为那阵子我正好进了一个比较大的项目组，加班到晚上十点是常态，精力真的有限。工作是基本盘，不能本末倒置，所以必须分清主次。选👸号爆文，是因为我已经日更👸号一年多了，这个领域的流程和玩法我相对熟悉，驾驭起来更顺手。从擅长和合适的方向切入，阻力会小很多，也更容易拿到正反馈。

至于最后为什么又报了一个ChatGPT+自媒体？因为明眼人都看得出来，这俩项目能很好地结合起来——工欲善其事，必先利其器。必须承认，ChatGPT真香。

但这里必须泼一盆冷水：每一个项目都不轻松，都需要持续的精力投入，没有任何一个结果是白白掉下来的。你在圈子里看到的大多数晒成绩，其实都带着幸存者偏差——愿意发言的人，90%以上是拿到正反馈的。这会给你一种“只要下场就有收获”的错觉。我不确定星球有没有统计过失败与成功的人数，但我盲猜，失败者大概率远多于成功者。所以啊，开始之前一定要认真评估自己，选你擅长的，或者你真正热爱的，然后再想办法做出差异化，建立属于你的护城河，给更多人提供价值，成功的概率才会大一点。

接下来分享几条我这期航海的心得，希望能帮到同样是新人的你。

**一、失败了，多找自己的原因；成功了，多找外界的原因**

我自己开了两个号。一个号一周多就入池了，当时我心里飘得不行：原来就这么简单？结果五天后，池子就把它吐出来了，直到现在也没回去。另一个号坚持了32天才入池，也就是文章开头截图那个，每天几十到一百多块的收益，一直稳着。

那我算成功还是失败？很多人，包括我以前，总喜欢把成绩归功于自己的能力强。但这次航海狠狠给我上了一课：你突然没了流量，为什么别人还有流量？你突然有了流量，原来别人也有，是不是因为踩中了一个热点，运气刚好降临？

所以你看，环境好坏，都有人能持续写出爆款，也有人能持续赚到钱。竞争对手多不多、凶不凶，我们改不了；外部环境一样公平，我们也改不了。那就只能往内看：没流量，就问自己有没有按航海手册像素级执行？素材库搭了吗？每天是原创还是洗稿？8篇发满了吗？没做到的话，先去试试这些基础动作。反过来，如果你做得好拿到了流量，也别自满，认认真真复盘，把真正导致成功的那个原因找出来，复制到每一篇内容里，这样你才能持续地赢。

**二、原因很少在结果附近**

前几天圈里讨论一个问题：考985难，还是赚100万难？我不在这里下结论，就问一句：你真的相信，自己是“考上那一刻”才变优秀的吗？你是“赚到的那一刻”才配拥有那100万吗？

都不是。考985，可能是你天资聪明，再加上十几年的寒窗苦读；赚100万，可能是你选对了路，但背后一定离不开决策力和持续坚持。所以，你现在做的事情，运气好可能几天后看到成果，也可能要一个月、三个月、一年，甚至五年。你看到别人写👸号日入四位数，但你了解他们在那天之前熬过了多少个夜晚吗？

因此，一定要学会正确地归因，别忽视那条漫长又必经的路。

**三、简单一点，别把事搞得太复杂**

刘润老师有句话我很喜欢：“一切商业的本质，都是消费者获益，而赚钱从来不是商业的起点，而是终点。”说白了，极致的利他就是利己。赚钱这个社区，不就是一直在做利他的事吗？

所以我们做项目，也要想办法把复杂的事情简化，找到最本质的东西。就拿👸号爆文来说，本质就是给读者提供认知价值和情绪价值，情绪价值甚至更重要。

做产品经理久了，我养成了一个习惯：经常思考“客户为什么需要这个产品”“客户为什么现在买”“客户为什么选我们”。换成内容创作，同样适用于这三个问题——读者爱看什么？读者为什么现在要看？读者为什么看你的？把这三个问题琢磨透，再去优化你的文章，阅读量自然会追上来。

![](img/356f4ec4007395aba6c99cef8553e5ac.png)

**四、正确的事情，要反复做**

我一直记着一个公式：结果=行为×概率。很多你觉得“看运气”的事，其实是概率游戏。如果一件事的成功概率是20%，那重复做14次，至少成功一次的概率就能达到95%。所以问题很简单：这个号没入池，那就再开一个；还不行，再开一个，一直做到第14个，看看结果到底会怎样。

当然，按概率算，无论你做多少次，都不可能100%成功。但只要你确定这件事有成功的可能，那就反复做、持续做、坚持做——成功早晚会来找你。

**五、分清主次，管好你的精力**

你羡慕别人月入几万，可你知道人家每天投入多少时间吗？是全职在做，还是下班后熬夜每天肝上几个小时？这一个多月，我反复问自己三个问题：我每天投入了多少时间？我真的认真研究航海手册和高手的分享了吗？我有定期复盘吗？

正是这三个问题，回答了我开篇说的“为什么只赚几百块也在预期内”——因为我投入的精力真的不够多。

这里我也说说自己的看法，可能不一定对：如果你在职场上受领导信任、做着有挑战也有成长的事、前景也明朗，那就安心以主业为重，别本末倒置。但如果你做着不喜欢的工作、总被PUA、一眼望到头，那不妨把心思多往副业上挪一挪，学学赚钱里的高手搞钱，这何尝不是一条通往罗马的路？

**六、相信时间的力量**

我很喜欢一句话：五六月份做的事，九十月份自有答案。它和龙哥大大说的很像：“我们往往高估了一年所带来的价值，又大大低估了三年所带来的价值。”我们这一生，拼的从来不是一时的爆发力，而是永恒的耐力和终身学习的渴望。航海续航不也正是这个目的吗？不让任何人躺平，而是把自己继续“卷”起来，持续行动，做一个长期主义者。

最后想说：搞钱这件事，最慢的步伐不是跬步，而是徘徊；最快的脚步不是冲刺，而是坚持。我们只要能“会跟”，坚持做正确的事，哪怕上天不帮你，概率也会帮你。

祝大家，一起龙哥盟！
