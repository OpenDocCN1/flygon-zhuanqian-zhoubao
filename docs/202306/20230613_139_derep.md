# 从月佣 602 到 5w+,我是如何从众人口中的内卷赛道低谷爬上来的

“这行已经卷到天花板了，别往里挤了。”这类劝退的话，你是不是也听腻了？偏偏有位01年的姑娘，在大家都不看好的领域里，硬是把月佣金从三月份的602元，做到了五月份的5.1万，完成了一次漂亮的上坡路。

她叫猫嘉，目前人在广西，去年本科毕业后就全职做网络项目。五月份，她的抖音养生号创下个人新高——佣金冲到5.1万，直接刷新了她之前2.7万的月纪录。这个号没有真人露脸，内容全靠实拍素材加混剪，也不砸钱投流，就是踏踏实实吃自然推荐。


她的评论区也热闹得很。有人说“优秀”，有人说“值得反复咀嚼”，还有人直呼“猫姐太牛了”。猫嘉自己倒是很谦逊，把成绩一部分归功于路上遇到的贵人，说“非常感谢一路上有他们的帮助”。这种互相托举的氛围，大概就是赚钱圈子的魅力。

从602到5.1万，中间隔的从来不是运气，而是不认输的选择、密集的复盘，以及别人唱衰时你还能沉住气往前走的定力。如果你也正卡在某个被唱衰的赛道上，不妨去文档里找找思路，说不定下一次翻盘的就是你。
