# 说实话，很多人压根就不会赚钱

看完这篇你可能会不舒服，但比不舒服更可怕的是，继续用错误的方式把时间耗掉。

**赚钱的底层逻辑，往往藏在书里，而不是偏门里。**
经济学早就把路标画好了。微观上靠塑造需求、掌控供给；宏观上靠周期波动、顺势而为。这两者都光明正大，而且门槛很高。

**想赚钱，得先占住一头。**
产品和流量，两者缺一不可。资源有限的人，别两头抓。普通人起步最优解是先做流量。分销、短视频带货、无货源店铺，本质都是用流量去换转化，再靠转化拿佣金。

**别再当观众了，当创作者。**
刷视频、刷🧣、线上吵架，都是在消费别人的内容。消费者永远是为内容付钱的那一方。把同样的时长用来生产内容，写东西、拍视频，你才从付费者变成了获利者。

**用一对多的杠杆撬动时间。**
一对一的模式，比如电话推销，时间成本极高。今天花一小时只能服务一个人。一条短视频被百万人看到，等于同一分钟被复用百万次。让时间复制，而不是重复。

**收入是会指数级放大的。**
起步阶段赚得慢、赚得少很正常。等到临界点到来，你可能在一个月里拿到过去一年的总和。这就是复利的力量。

**赚钱这件事要一直学。**
昨天的打法今天可能就失效了。市场永远在变，所以学习力是核心资产。一个人闭门造车很难走通，找老师、交朋友、跟对圈子，是节省试错成本的捷径。

**速度比完美重要。**
看见机会就上，别磨叽。手快有，手慢无。你犹豫的功夫，别人已经分完了盘子。先入场再优化，比等到完美再出手强太多。

**收入天然有起伏。**
想要月月稳定只能去打工，稳定但天花板低。做生意是波峰波谷并存，今天大爆发明天可能平淡，这是常态，不是失败。

**分享是放大器。**
跟优秀的人同行，你会走得更快。越敢分享干货，越能吸引同频的人。利他的动作，最终反哺利己。

**赚钱不算玄学，但也不轻松。**
智商中等、有正确方法、够坚持的人，基本都能把赚钱这件事做成。最难的其实是坚持，大多数人坚持不到两个月就会被没有即时反馈打败。

希望看到这里的你，能找到属于自己的赚钱节奏，赚到心安理得的钱。
