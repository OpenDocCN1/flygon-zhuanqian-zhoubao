# 掏了六位数学费，我终于看清了副业做不起来的真相
作者：龙哥

你有没有过这样的困惑：看了无数副业攻略，收藏了一堆干货文章，付费进了不少社群，可折腾了一圈，口袋还是空空如也？

那些靠副业赚到钱的人，到底做对了什么？方法明明就摆在那里，为什么轮到自己的时候，却总是无疾而终？

我也曾经被这个问题折磨了很久。直到我花了十几万，拿我最亲的家人做了一次“残酷”的实验，才彻底想明白：问题从来不在项目本身，而在做项目的那个人。

实验对象不是别人，是我一母同胞的亲姐姐。如果不是至亲，我也不可能舍得砸这么多钱去验证一个道理——别人真的带不动一个自己不想动的人。

很多人张口就问“我要怎么做才能赚到钱”，但真正拉开差距的，压根不是技术、不是渠道、不是有没有内部消息，而是一个人到底有多想做成这件事。

我见过太多人，嘴上天天喊穷、喊想搞钱，但你让他花99块钱买门课系统学一下，他的第一反应是：还要花钱啊？

那一刻你就该明白：他不是缺方法，他是缺决心。一个连几十块钱都不舍得往自己脑子里投资的人，凭什么觉得自己能赚到别人花了好几年才积累下来的钱？

同样的项目，有人做能月入过万，有人做三个月就放弃，差别在哪儿？就在于你有没有全力以赴的劲头，有没有那种“我必须做成”的狠劲儿。事情还是那件事，人换一换，结果就天差地别。

这些年我也慢慢悟了：成年人最难改变的，不是认知，是行动。你永远叫不醒一个装睡的人，也永远带不动一个不想跑的人。

所以，别总问“为什么我还没做成副业”了，先问问自己：我真的拼命了吗？我是把副业当救命稻草，还是只是当个饭后谈资？

如果你身边也有一个愿意掏心掏肺带你搞钱的兄弟姐妹，请一定好好珍惜——那不是谁都有的运气。

点个赞再走，愿我们都能做那个主动奔跑的人，而不是等着别人来拉的人。
