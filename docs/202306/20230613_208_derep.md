# 硬核科技，如何自己手搓一个 ChatGPT

### 不靠大厂，真能“攒”出个ChatGPT？我们这次直接动手了

> 作者：闲富 | 日期：2023-05-24

大家好，我是闲富，长期在硬核科技创业这条路上折腾。今天这篇，是想聊聊我们最近正在干的一件“疯狂小事”：亲手打造一个ChatGPT3.5。

先把结论放在最前面：我判断，最多六个月之内，市面上就会出现能在本地独立部署的ChatGPT类产品，甚至可能做成类似U盘的硬件，插上就能跑。这个方向在企业服务里空间相当大，所以我和团队决定，真刀真枪去试一把。

#### 故事得从去年春天讲起

2022年2月，一位清华的哥们儿给我介绍了GPT3模型，当时我们还认真聊过它的能力和商业前景。那段对话记录我还留着：![](img/e18559d70b0d948284aeb1ff8a16b824.png)

后来时间飞快，11月GPT3.5忽然火遍全球。我之前写过一篇相关帖子：https://articles.zsxq.com/id_m35r2smop4q1.html，就是在这个节点上做的。

前几天，这位清华哥们儿又来找我，说想自己从零搭一个ChatGPT。我一开始觉得这想法有点夸张，但听完他的分析，反而觉得挺靠谱。

他给的核心理由是：Facebook把LLaMA基础模型开源了，后面又冒出一堆基于它微调的模型。其中Vicuna只用了三周，就达到了ChatGPT九成以上的水平。![](img/b198d3c68bc86ea2238fc2cfe779b01b.png)

谷歌内部的技术报告也承认，他们并没有所谓的护城河：[https://www.semianalysis.com/p/google-we-have-no-moat-and-neither](https://www.semianalysis.com/p/google-we-have-no-moat-and-neither)

更猛的是，Facebook最近还放出新招：只要1000条训练数据，就能超过GPT-3.5（DaVinci 003）。这个方法叫LIMA，也就是“Less Is More for Alignment”。![](img/5b088f70448abd497e2f815d4917f0c2.png)

这说明底层的预训练模型已经很能打了，不需要堆海量数据，只需用一批高质量数据做微调，就能逼近大厂效果。![](img/7a9d022f63ea521cf56b8301f6af0971.png)

既然Vicuna能靠ShareGPT的数据起来，那我们完全可以照做：抓取数据、清洗去噪、筛选优质语料，几千条足够。想法是够大胆，但清华兄弟说干就干，我也跟着冲。

#### 说干就干：用“套娃”的办法搞数据

为了配合他的模型训练，我继续用“ChatGPT套娃”的思路，先到sharegpt.com上爬更多语料。

数据来源有两个：
- 官网的地图文件：[https://sharegpt.com/sitemap.xml](https://sharegpt.com/sitemap.xml)
- 还有热心人存好的备份：[https://huggingface.co/datasets/philschmid/sharegpt-raw/tree/main/sharegpt_90k_raw_dataset](https://huggingface.co/datasets/philschmid/sharegpt-raw/tree/main/sharegpt_90k_raw_dataset)

好在对方在搜索功能关闭前，把这些数据存了下来。套娃流程一跑起来，真是顺滑到不行。GPT3.5对程序员来说实在太友好，我们大概花了三个小时，就把数据全部整理完了，还把其中有价值的部分单独拎出来，转成了统一格式。![](img/dbfcb0a14ebb766193b7aca72b8adc4d.png)

先留个钩子：我整理好的数据已经传到了百度网盘，需要的朋友可以私信找我拿。

后续有进度，我会继续来同步。感兴趣的朋友，也欢迎加入我们一起共创。

#### 商业场景其实很明确

在这个越来越注重数据隐私的时代，把ChatGPT做成私有化部署，会是一个长期存在的强需求。前面说的那个方案，对英文市场的公司尤其有价值，完全是一个可以出海的产品。

国内的需求当然也不小，如果能把中文支持做好，商业空间只会更大。

我会继续和清华的哥们儿一起，把“私有化手搓ChatGPT”这条路走下去。想共创的朋友，随时欢迎来聊。

#### 评论区里的几个关键问题

有人问：LLaMA不是对中文支持很差吗？微调能解决吗？
答案是不能。底模本身把中文能力裁掉了，所以现在这个方向更适合用来做海外产品。中文版本得等大佬们放出中文基础模型，才有得玩。

还有人问：要不要调一调MOSS？至少它还能商用。

另外有朋友提醒：ShareGPT的数据其实已经有洗好的版本了。我知道，但那些版本没有区分GPT3和GPT4，所以我重新洗了一遍，专门把GPT4的数据挑了出来。

最后网友们的评价也很真实：“太干了”“我仿佛走进了塔克拉玛干”“太强了”。行，硬核这条路，我们接着走。
