# 0. 背景起因

我最初是通过搜索「👸号」找到的这篇干货，https://t.zsxq.com/0e9v9T4vT，里面讲的是写作情感类内容的方法。

加入航海之前，我就照着那套思路写了几篇情感文，也是用同种打法，偶尔还会自己点赞，结果曝光还是几位数，自信直接掉线。

复盘下来发现，我一直是从转化、流量、变现去想，却忽略了当下最现实的问题——没人看。于是转换角度：能不能先借势「时事热点」自带的流量，再套进情感类表达？事实热点本身吸睛，值得一试。

下面是我完整落地的路径：找热点→找同类爆款→让 ChatGPT 拆解并生成→发布。中间有些步骤比较繁琐，新手可以适当跳过。

# 1. 找热点

赚钱站内关于找热点的关键词非常多，我挑了3个，针对🛰️生态我更推荐第3个：

1. 百度热榜 https://top.baidu.com/board?tab=homepage
2. 新榜热榜 https://www.newrank.cn/
3. 🛰️自带搜一搜的热点

注意：🛰️的热点入口就在搜索发现页，截图里排第一的那条。若没显示，点底部「页面设置」打开即可。

![](img/193685263e07e966827a94850eaaa406.png)

本次就以🛰️搜一搜的热点为例来讲解，当前热榜里出现了多条新闻，挑了第三条来写：「浙江一处长地铁猥亵他人 被拘 12 日」，这类带「性」话题的热点天然自带关注度。相关延伸可参考2023年3月航海的👸号爆文写作手册：https://search01.shengcaiyoushu.com/docx/NHgUdKMcLoPz0VxSz8LcspWqnsg

# 2. 找相关的热门文章

点进目标热点后会回到🛰️搜一搜，记得切到「文章」标签，才能看到内容类结果。在电脑端把完整关键词原封不动搜一遍，第一页基本都是通稿，往下翻就能看到10W+的文章。

![](img/99b8001168bbfbd47bbb1fe746636040.png)

多刷几分钟，3～10分钟内通常能筛出不少参考。

![](img/e038acd4a56a69c9711f61002b47c39f.png)

因为是突发新闻，往往还没形成高阅读的深度解读，这时入场反而有机会抢占10w+。把热点本身和已有的爆款内容结合起来写，胜率会更高。

动手不输。

# 3. 用 ChatGPT 拆解并生成文章

核心思路是训练两个角色协同：角色A负责模仿爆款的写作风格，角色B负责点评热点事件。A+B一起出稿，效率很高。下面是可直接复制的流程。

### 训练角色 A

先让AI学习一篇热门文章的表达方式，命名为“风格 A”，提示词如下：

请学习这篇文章的写作风格，总结这种写作风格，命名为“风格 A” :"""xxx 文章的内容””"

注意：引用内容最好用（）或“““”“”””把主体框起来，AI识别更清晰。

![](img/0257c53c171d273dab88ca2daa0bc617.png)

训练后得到的角色 A 比如「客观报道风格」，结果示例如下：

![](img/d932a73d7aaa9e3f8a534fe6c13e7327.png)

### 角色 B

再让AI扮演热点点评人，重点是分析事件、逻辑和背后问题。并非专业评论员也能借助AI补全思路和角度。

这里我用 aicosplay 生成了角色设定。https://role.aicosplay.com.cn/zh?

具体提示词信息如下：

### 开始写文章

注意字数控制在1000字左右，过长完读率会掉。

直接用组合提示词：

担任一个热门事件点评人，用“客观报道风格“来扩写一篇文章，并点评和分析，帮助观众应该注意什么，不少于 1200 字：（xxx）

括号内填入具体事件内容，把角色 A 和角色 B 的能力结合起来。下面是完整示例。

![](img/f819003a31220ff3be5b03fcc520e957.png)

文章初稿就出来了，建议按下面的Tips再过一遍。

### Tips:

* 生成中断或字数不足时，输入「继续」即可，通常1～3次就够了，别过度。
* 自己通读后做精简、增钩子、加金句，必要时引导关注和评论。
* 粥左罗老师的话：ChatGPT 写得快，我们负责把框架想好，快+好就能跑赢很多人。
* 建议控制在1200字以内，完读率更友好。用户点赞后推荐权重更高。

# 4. 配图、封面和标题

### 配图

如果是时事热点，去📕、抖音搜对应视频，下载后自行截图入文即可。

以抖音为例：

* 在抖音搜索关键词后转发复制链接
* 打开🛰️搜「抖音去水印」，随便选一个，粘贴处理后下载
* 本地视频即可截帧，iPhone直接在相册拖拽找合适画面截图，尺寸调整好就行，不用额外软件

情感、搞笑类内容可以用第三方编辑器排版，插入无版权图、加头尾签名，方便一键导入👸号。

### 封面

参考B站何同学的测评，普通号封面影响有限。我的建议：

* 情感类文章，封面选自带吸引力的美女/帅哥形象，效果更好
* 时事热点，建议直接用📕、抖音上已验证的热门封面，记住抹掉个人信息避免被举报

### 标题

标题决定点击，数据推送时没人点进来一切白搭。

爆款标题常用模板，来自航海手册截图。比如我最近用的「万万没想到，xxxx」，阅读量直接翻10几倍。

![](img/00675d5b3963c8458aebf4797bcdc829.png)

也可以让 ChatGPT 批量生成标题，提示词如下：

![](img/bc8d8a8215cf5ac6400383594558d0b6.png)

关于标题生成也可参考这篇：https://t.zsxq.com/0e4uFJKmv

把里面的「📕」替换成「👸号」，并把最后的关键点调整成更符合👸号口味的表达：

```
你写得很不错，但有几点要求需要给你做到补充，请按照下面的要求修改：
第一、控制字数在 30 字以内，更简短
第二、选取下面 36 个爆款关键词的 1-2 个，穿插到标题之中。
把下面的*号需要换的内容
你知知道**吗？
你见过**吗？
**值不值？
为什么***?
***怎么办？
**好不好？
***如何***?
```

# 5. 文章发布

### 属性设置

务必勾选原创，能提升推荐权重。

分类选准：社会→热点情感等，匹配人群画像能提高打开和完读。

赞赏功能建议打开，增加正反馈和收入来源。

### 发布时间

新号没有私域引流，主要靠推荐和搜索。

热点类越早发越好，很多爆文都是0点左右更新；情感类建议饭后时段发布。

发布时一定要选「群发」，不要选「发布」。

### 推广

有大号资源就直接用；没有也不怕。

我发现🧣带热点标签投放能带来自然流量，虽然不直接变现，但能叠加阅读量促进推荐。

时间充足的话，可以同步到知乎、百家号、头条，并在关键词里加上👸号名做引流。
