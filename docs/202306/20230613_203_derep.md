# 新手也可以快速上手的 AI 绘画：懒人简笔画及衍生动态表情包篇

有没有想过，哪怕你是零基础的小白，也能在AI绘画里轻松玩出花样？今天这篇分享，就是给你准备的“懒人友好型”上手攻略——从随手几笔的简笔画，到能逗乐全场的动态表情包，全程不需要你精通PS，甚至不用懂太多技术细节。

第三，表情包背后还藏着哪些赚钱玩法？我挖了挖，确实有不少可以尝试的方向。
