# 模仿，才是成长的真正引擎

六一到了，今天不谈别的，就聊一个被很多人误会的话题：模仿。

商业靠模仿进化，孩子靠模仿长大。两者本质上是一回事。

小孩从出生起就在复制身边的人。父母的一句话、朋友的一个动作、社会的某种习惯，全都被无意识地收进身体里。久而久之，一个群体有了共同的性格、共同的审美，这不是基因决定的，是模仿决定的。

这套逻辑，法国传播学奠基人加布里埃尔·塔尔德在《模仿律》里早已讲透。民族的文化、国家的传统，并不会通过血脉遗传，而是通过模因一代代复制下去。

模仿并不是乱抄，它有非常清晰的规律。

第一条，流向是自上而下的。模仿永远从强势端流向弱势端。下层围观上层，上层定义风向。明星怎么穿搭，街头就会怎么跟风。飞跃鞋的复兴也是这条路走出来的。先是巴黎时尚圈把它捡起来，再被全球追捧。而巴黎人最初爱上飞跃，又是因为发现了少林僧人练功时穿的那双鞋。

第二条，是几何级扩散。模仿一旦启动，就像滚雪球一样越滚越大。

第三条，顺序是先内后外。人们总先照抄自己圈子里的玩法，再去看向外部。

第四条，文化先行，商品随后。美国影响世界时，也不是先卖货，而是先输出文化立场和生活方式。当思想被接受了，产品自然会被买单。

艺术创作也逃不开这条定律。

成龙的喜剧节奏，是站在基顿的肩膀上长出来的。李安拍《卧虎藏龙》时借鉴了胡金铨的镜头调度，而胡金铨的根儿又在京剧。武侠片的打戏从胡金铨到徐克，无非是把京剧身段搬上银幕。昆汀热爱日本园林，《杀死比尔》里就有一场打斗直接放在园林里，而片中乌玛·瑟曼的造型和打法，明摆着是向李小龙致敬。

我自己的团队里，成长最快的员工，我敢说很大程度上是把我当样本在照着练。

品牌之间，更是模仿的大舞台。

中国互联网早期基本是照着美国抄，后来中国模式成熟了，变成了双向抄袭。Meta在学抖音，马斯克接手推特就是想把它打造成类似🛰️的全能入口。苹果当年把施乐的图形界面搬了家，随后整个手机行业都在抄苹果的交互逻辑。小米当年推出一个插线板造型，几年后全行业的插线板几乎长得一个样。七分甜把杨枝甘露做成杯装爆品，之后奶茶店无一例外跟进。瑞幸靠生椰拿铁打爆市场，旁边的品牌全在做作业。甚至瑞幸的定价打法，也很像当年日本doutor对星巴克的冲击。

所以一个残酷但真实的真相是：这个世界根本没有纯粹的原创，所有的创新都是在模仿的基础上做的微调。能称得上好的，不过是在模仿里多加了一点自己的东西。

苹果推动了整个手机工业设计的集体升级，索尼、无印良品、松下、保时捷都在扮演过同样的角色。未来在餐饮领域，中国很可能成为全球的风向标。

既然模仿不可避免，抱怨就没意义。你能做的只有一件事：让别人抄你变得更难。

单一的点子创新，挡不住模仿的洪水。你需要的是组合拳。戴森能撑住一段时间的领先，正是因为工业设计、技术专利、外观专利、制造工艺多条线一起做。竞争对手想完整复刻，成本极高。

喜茶的芝士奶盖、七分甜的杨枝甘露、沪上阿姨的暗夜玫瑰、茶颜悦色的中式茶饮，都只是昙花一现的领先。它们没形成壁垒，对手很快就会抄走。要想持久，要么持续不断地创新，要么直接上组合创新。

南城香就做到了。它的护城河不是一道菜，而是一整套系统：组织架构、选址逻辑、用工方式、供应链设计、利润分配机制。这些东西拼在一起，几乎没人能完全照搬。

我做咨询这件事，最开始也是照着华与华的路子走过来的。

模仿不是羞耻，模仿是人类最强大的学习机制。商业在模仿中发展，孩子在模仿中长大。

儿童节快乐。
