# 钱不分快慢，只分适不适合你

创业这件事，从来不是只有一种活法。

有人创业就是想把日子过得宽松点，够用就收手；有人则想造一艘船，一飞冲天。起点不一样，航线自然也不同。你想快速兑现一张票离场，还是想在同一个赛道深耕到天荒地老，都没有谁对谁错，关键是你愿不愿意承担那个选择带来的结果。

我见过太多带着理想主义滤镜的人，对赚快钱嗤之以鼻。说实话，我不认同这种审判。快钱是钱，慢钱也是钱，本质上就是一种取舍问题，不是道德评级。

这事儿让我想起《潜伏》里谢若林的那句话：这两根金条，到底哪根高尚，哪根龌龊？金条就是金条，价值不会因为你怎么拿到它而改变。

在环境极度不确定的时候，我反而觉得能早点落袋为安是一种智慧。把收益兑现到手里，比空谈长期主义更踏实。这不是短视，是清醒。

当然，如果你心里想的不只是填饱肚子，而是想造一家能流传几十年的公司，那也完全没问题。把时间轴拉长到十年、五十年去布局，你有可能成为行业里真正的缔造者。快慢各有各的荣耀。

说到生财，其实身边做快钱的人并不少。在抖音、小红书这类平台上，每天都有人盯着红利窗口出手。很多大号其实没什么长远规划，能薅到羊毛就薅，能赚一波是一波。平台窗口就那么几年，能赚就赚，别踩线、别作恶，跑得快也是一种能力。

我自己创业三次，体验感完全不同。前两次，如果有人来接盘我的股权，我会毫不犹豫地卖掉，先把钱拿到手。这一次不一样，我想做一家能持续经营的营销咨询机构，走得慢一点，但想走得久一点。

你身边的朋友圈里，肯定也有两种人：一种是逮着机会就变现的快钱派，一种是闷头憋大招的慢钱派。你更倾向哪一种？或者你更像哪一种？欢迎说说你的看法。
