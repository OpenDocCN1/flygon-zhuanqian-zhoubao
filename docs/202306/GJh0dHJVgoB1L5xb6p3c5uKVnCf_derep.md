# 一、账号搭建

账号资源：一个身份证最多可以认证5个🛰️号，每个🛰️号绑一个视频号。号开通后要按品类命名，最近转化比较好的方向是经文类，以及和考试相关的文昌塔类产品。

昵称和简介规则：昵称里不要带佛教、道教相关的敏感词。简介要简短直接，我做经文品类，简介就写：视频同款商品在👇🏻购买

# 二、抄对标爆款模板

以经文类内容为例，具体做法：

1.  视频里的口播文案、配的音乐、视频时长，都严格按爆款一模一样来。

2.  素材要替换，条件允许的话把后半段抄经书的场景自己拍一下，保证整体原创度在七成以上。

3.  前三秒决定能不能进流量池，尽量用有画面感的场景开场。

# 三、找素材

1.  一级来源：抖音、快手。不要直接从视频号搬。方法是带上产品名去搜抖音上的对标号，比如搜“经文”，然后挑转发量不高的作品。被反复搬运过的素材再二次搬运，基本没效果。

2.  二级来源：🧣、纪录片里的佛学内容。这些素材花时间找，但几乎没人用，过审率高，剪辑顺畅的话很容易拿到曝光。

3.  素材用完就丢。A视频用过的素材千万别放到B视频里，很容易导致账号异常。建议一开始就建一个素材库，前期测试用3到5条的量就够了。

# 四、剪辑发布

剪辑的具体操作社群里教程很多，这里重点说新人容易踩的坑。

1.  先跑通一个再扩量。我自己一个号刚有点苗头就冲动开了4个，结果第二第三个号因为素材重复直接废了两个。所以一定要等流程跑通了再复制。

2.  发布时间。工作日晚上7点之后效果最好，周末全天都可以发。

3.  心态调整。视频号的数据反馈比抖音快手慢很多，有些作品两三天才起来，有些是几分钟就有反应。数据我们控制不了，但作品质量可以把控。项目周期说不准，建议带着学习和跑通思路的心态去做，别一上来就想着赚多少钱。
