# 别再发low到爆的GPT秒出高考作文了！一文讲透AI在文字创作中的正确使用姿势

别再让GPT裸考了！AI写作的正确用法，一文讲透

每年高考作文一出来，热点就炸了。朋友圈里、各种AI社群里，全是“三秒生成高考作文”的截图。说实话，我也心动过，但看完那些“作品”，只觉得尴尬。

不是AI不行，是用法太歪了。

很多人用ChatGPT的习惯，就是把题目扔过去，坐等结果。这哪是创作？这分明是撞大运。如果你平时做事也是这种“输入—输出”的直线思维，那就算不靠AI，自己手写也写不出什么好东西。

所以这篇文章，我想借“高考作文”这个大家最熟悉的场景，把AI文字创作的底层逻辑讲透。看完你会发现，会提问、会拆解的人，才配叫“会用AI”。

先还原一下整个过程，看看小凡是怎么带AI写出一篇高考作文的。

第一步，目标要具体。不是“写一篇作文”，而是“写出一篇满分作文”。目标不同，后续动作完全不同。

第二步，把“满分”翻译成可执行的标准。小凡让GPT联网检索“中国高考满分作文的评分构成”。![](img/9a3a9f3518cc8a54fca0c67367d05d46.png) 很快得到结论：满分作文分基础等级和发展等级，各占20分。基础等级里，内容项重点看题意把握、题材是否新颖、情感是否真实、论据是否可靠；表达项则看结构、语言、文体和卷面。发展等级则看四个评分点——深刻、丰富、有文采、有创意，而且不需要四点全占，只要其中一点足够突出，就可能被评到满分。接着继续追问：“基础等级的具体评分标准是什么？”“发展等级的4个评分点分别指什么？”![](img/4208e13c6b566bd6f62b3dac85baa4a4.png)![](img/566b119fc63e8a7bb58f37d6fcdbf327.png) 把答案整理成一份“投喂资料”，让AI和自己都清楚知道要达成什么。

第三步，请AI当教练，而不是当写手。小凡先让GPT扮演一位语文特级教师，请它先学习满分规则，并回答自己接下来要做什么、准备怎么做。![](img/7b950edb22affabf4bd5b40d5154ccac.png) 然后，小凡把整理好的标准发给GPT，让它复述理解，确保双方对齐。![](img/c38103edf1f1d2a7347c63121e433751.png)![](img/77c9c7ac3068e12dd27fe8848b86f35a.png) 等它真正明白了规则，又让它总结出一套写作方法。![](img/bc959d933e13a0ad8936581821c7ed85.png) 直到这一步，才进入正式写作。

第四步，正式开工。给出写作任务，附上所有评分标准和写作手法。GPT很快写出了一篇《故事的力量》。![](img/fea91ffbbad49791cdc0fea6f6568749.png)![](img/ea0cd3ee69792798045e23c9a3b0bca3.png)

文章整体读下来，语言流畅，结构完整，像模像样。但也只是“像模像样”而已。小凡把这篇作文伪装成高二学生的练习，交给了两位高中语文老师。一位老师评价：文笔不错，能拿中等偏上，但结构和立意理解还不到位，素材积累也不够。另一位老师打了48分，说“没什么特别的亮点”。![](img/925bbaec3b5cc8ac6acf060222a04369.png)![](img/76f409e52aecc478523429c4a2a7d35d.png)![](img/401ba163c3f425313ece1aef55a53238.png)![](img/8cdaaa2b8ffd0df12ea4985beb97d97b.png)![](img/7adf18fe310bd918c0a8f1632fca6fc3.png)![](img/de86be62285105a3eb4db543c7c53ef7.png)

看出问题了吗？AI能帮你写出80分的答案，但离满分还差着“人类的判断”。两位老师不约而同地指向同一个东西：创意。戴老师甚至点破了一个残酷真相——AI看似降低了写作门槛，实际上反而把门槛抬高了。因为当人人都会用AI时，人类的独特视角、生命体验和创意能力，才是真正稀缺的。![](img/c7aa98c455bc5844af9fe6891c9aa3e5.png)![](img/e631f8d5ae8ddc35e31d2b3979d3ef31.png)

所以，别再发那些“秒出作文”了，是真的low。low的不是AI，是操作者。你直接把题目甩给GPT，是在侮辱AI，也是在侮辱十二年寒窗的考生，更是在侮辱语文教育。

我们为什么越来越浮躁？因为太爱走捷径。文章收藏了，就等于学会了；课程买了，就等于入门了；创作交给AI，就等于完成了。可是，完成一件事哪有这么容易？碎片化的输入让我们丢了耐心，习惯了即时满足，反而忘了拆解问题、追问本质才是解决问题的第一步。

其实，破解AI创作困局的钥匙，一直都在自己手里。


第二把钥匙：把AI当装备，别当NPC。玩过RPG都知道，神装需要属性匹配。你力量不够，穿着屠龙刀也发挥不出威力。AI也一样，它应该成为你大脑的延伸，负责执行性的机械工作，而不是一个帮你完成任务的“游戏角色”。你们是协作关系，不是外包关系。

第三把钥匙：尊重三者智商。尊重AI，就按步骤引导，别指望一句话封神；尊重同行，人家脚踏实地做出来的内容，不是你随手乱来的产物能比的；尊重自己，别躺平当废物，学会调教和驾驭AI，让它成为你的生产力倍增器。![](img/e5f7617de54177faa7963a59dfd0e3dc.png)

第四把钥匙：死磕创意。文字创作真正值钱的，是你对世界的理解、你的洞察、你的表达方式。这些AI替代不了，也永远不该替代。保持思考，是你作为人类最后的尊严。

可能有人会问：为了写篇作文，又是调研又是训练，花3小时值吗？太值了。要知道，考场上一篇作文的写作时间只有40到60分钟，但为了这短短几十分钟，你背后的积累和沉淀一点都省不了。而当你把调研流程跑通，沉淀下来的提示词和方法论，下次复制粘贴就行，几分钟出稿。这不是一次性的买卖，而是越滚越大的复利。

而如果你把这套逻辑搬到自媒体上，会发现每个环节都适用。所以最后，留三个问题给你，想通了，你就不会再说“AI什么都能写”：

在📕上发笔记，你的目的是什么？
想达到这个目的，笔记需要具备哪些特点？
要具备这些特点，你需要怎么做？

答案不在我这，也不在GPT那，在你自己脑子里。
