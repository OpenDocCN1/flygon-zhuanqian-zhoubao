# 致挤在星巴克的，失业的中年人

最近刷到一条挺扎心的热搜：星巴克正在变成中年人的临时避风港。

我专门去翻了翻评论区，也看了不少相关视频。隔着手机屏幕，依然能感受到那些文字里透出来的压抑和喘不过气的疲惫感。

![](img/e987c0c01085d12d40e0e2f5726425cb.png)

说实话，如果顺着这股情绪往下写，用悲观的腔调去迎合大家的不安，流量一定不会差。但我打心底里不想这么做。

我能理解，很多人眼下的日子确实不好过，而且这背后的原因错综复杂，不是个人能左右的。但我想说的是，一旦你开始把焦点全部放在那些“客观原因”上，一旦你从心里认了命，那可能就真的要在原地待很久了。

那我想聊点什么呢？聊聊我自己。

两三年前，那个坐在星巴克角落里的，是一个掏不出多少钱、整天无所适从的无业青年。而今天，我已经走出来了，有了稳定的小事业，生活也走上正轨。

希望我这点经历，能给你哪怕一丝力气。

2020年中，我的小团队解散，我的第一次“创业”以亏光积蓄收场。别把“创业”想得多玄乎，说白了就是我打了几年工，有点飘，觉得自己行了，就拿着血汗钱赌了把大的。结果不到一年，不仅老本亏完，还搭进去了父母的一点积蓄。

可那时候的我，居然还放不下架子。

一方面，我不甘心再回到格子间听人指挥。另一方面，真要重来，钱没有，方向也没有。于是开始那阵子，我硬着头皮没退租那间小办公室，每天都按时过去“上班”——准确说是在网上瞎逛，找点零成本的项目试一试。

但现实很快给我上了一课：没有收入、积蓄快见底，房租接近清零，那间两千多一个月的小办公室，突然变成了奢侈品。没办法，我退了房，开始窝在家里找活路。

居家办公的时光里，我为了掩饰心虚，每天早上还会对着出门上班的老婆开玩笑说“快赚钱养家去”。但嘴上的玩笑越轻松，心里的酸楚就越沉重。门一关，我就钻进书房，继续翻项目、找机会、试错……然而依旧颗粒无收。

家里的气压越来越低。家人虽然嘴上没说难听话，但我能察觉他们的担忧和不安。偶尔一句“要不试试考个编？”就让我溃不成军。有邻居来串门，我会下意识躲进书房，假装不在，生怕别人知道我成了“无业游民”。就连尝试的那些小项目，也怕被家人朋友撞见，怕被当成笑话。

那种心虚和压力积攒到顶点，我终于受不了了，每天背着电脑逃出家门。

就这样，我成了星巴克的常客。

一开始还挺要面子，永远只点最便宜的中杯冰美式。后来发现自带杯更省钱，果断抛弃了面子换上自带杯。再后来，我发现有人不消费也能坐着办公，于是我也学会了不点单，心安理得地蹭着空调和座位。

当兜里比脸上还干净的时候，面子真的什么都不值。

所以，你们正在经历的窘迫，那些翻来覆去睡不着的心酸，我都一一尝过。

那段在星巴克流连的日子，没过几个月，却漫长得像几年。好在那段日子虽然煎熬，我始终没有在心里承认“这辈子就这样了”，也没把一切推给“这几年大环境差，往后更难”。我一直想着，再找找，再试试看。

运气还不算太坏。后来我在“龙哥盟”里碰到一个合适的项目，也踩准了节奏，磨了整整三个月几乎没进账的冷板凳，才算把路子跑通，赚到第一笔让我喘过气来的钱。

淋过雨的人，才会想给别人递伞。

正因为经历过中年男人没钱、没方向的绝望和一个人想多赚点钱时踩过的各种坑，我在项目刚有起色的当天，做的第一件事不是放大收益，而是把每一步操作细节尽可能详尽地记录下来，分享给同样挣扎的人。

因此有了那篇《抖音小程序依旧可以稳定日入过千的玩法，实操手册》，也有了后来这个公众号，以及一群志同道合的读者和伙伴。

这两年多，我走得不算快，也绕了不少弯路，但一直在走。

“缓慢而坚定”。

大的环境好不好，没人能控制。但依然有人在这样的环境下，找到了自己的活路，对不对？

此刻在星巴克发呆的失业中年人，以及所有处境相似的你，我知道你们很难，也许你此刻正在承受的痛苦，比我当年还要沉重千万倍。

但请你务必留住“变好”的念头。

出路确实难找，但只要你没松手，就一定会找到。

路上也一定还有波折，但只要你没松手，那些坎终究都会过去。

不管什么样的战争，真正的胜负手，往往是谁先丢掉了战斗意志。

别放弃，控制好试错成本，一切都会慢慢好起来的。

祝福你们。

——来自曾经和你一样，坐在星巴克里茫然四顾的无业青年
