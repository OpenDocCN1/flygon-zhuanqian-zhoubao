# Tiktok shop 漂亮国推出新模式，小玩家该如何入场？

最近TikTok圈子里，算是扔下了一颗重磅炸弹。如果你一直盯着官方动态，应该早就嗅到风声了。我四月份就稍微透过口风，前天在聊补贴的那篇内容里也顺带说过。![](img/5d0b307852ac13e1383217189d354175.png) 没错，这次的重磅消息就是：TikTok电商在美国市场要推行“全托管模式+平台模式”双轨制。

不少大咖已经拆解过这波变化，但大多是从供应链视角切入。今天我想换个角度，专门聊聊这波调整给咱们普通玩家留了哪些口子。![](img/651e13b6c86039ddc2393a960f4c7639.png)

可能有人听到这两个词一头雾水，全托管是啥？平台模式又是啥？咱们从头捋一捋。

早在2021年，TikTok就启动了电商布局，首站放在英国。当时大家都怕进场晚了只剩下刷锅水，抢着往前冲。但坦白讲，真正靠TikTok赚到钱的跨境卖家没多少，很多人连碗都没端住。我有朋友同时给TEMU（海外版拼多多）和TikTok供货，他说TikTok这边的出货量，还不如TEMU的一个零头。注意，这里说的是跨境卖家；本土卖家其实玩得还行，尤其是东南亚的本土卖家。

平台看到这个局面肯定坐不住，跨境业务才是自家核心，怎么帮自己人卖好货才是关键。再看TEMU那套自营玩法确实有效，干脆拿过来用，全托管模式就这样落地了。![](img/523b54ac300475539b50680d24257dd0.png)

什么叫全托管？说白了，跟京东自营一个路子：你只管供货，平台负责卖货，其他事都不用操心。![](img/55cc9b0dc4a8862b6be43a7bbb283879.png)![](img/55cc9b0dc4a8862b6be43a7bbb283879.png) 平台帮你推广、帮你发货、帮你处理售后，回款也很快，等着收钱就行。![](img/b8526841b99415bf942f5ff4efd67521.png) 简化来说就是：你作为供应链把货交给官方，官方卖完后给你结算，仅此而已。![](img/d783e2cd780b27bc6a208b5c998584e5.png)

那平台模式呢？对商家就繁琐多了。商家得自己备货、自己拍短视频或开直播引流量、自己发货，平台只提供一个撮合场所，然后抽一点佣金。![](img/d924e6dd7e9b6c5b440171e5c3e1d9bd.png)

所以接下来的方向已经很清晰：两种模式并行。如果你想自己开店，当然也可以，但我个人更建议顺着平台主导的趋势走。![](img/e4589fac38eed8a7fd1738e872efefd4.png)


看到这里，你可能会感叹：全托管模式也太香了吧，我们要不要试着做呢？![](img/f592d420b8769fd13973d0917c3355a1.png)

说实话，这条赛道和咱们普通人基本不搭。想成为供应链，货本身不但要够好，价格还得非常有杀伤力；以后更要有压货、扛账期的心态和资本，这些都是绕不开的硬条件。

那普通人的机会到底在哪？两个方向值得重点关注。

第一，本土商家吃到红利。如果你人在国外，或者有办法搞定本土店，我建议认真考虑。以后大概率就是“本土店+TikTok自营店”共同存在。平台这一轮调整，相当于替你清理了一批爱搞骚操作的跨境卖家，懂的自然懂。虽然你正面跟平台自营竞争肯定打不过，但平台再强也不可能把所有品类、所有产品都包圆，这不就留下一大片空白给你折腾吗？机会就在这。

第二，达人带货是真正的超级机会。前面说的本土店，能做到的人其实也不普通了，哈哈。那真正的普通人能上手的是什么？就是短视频小黄车带货。咱们从几个维度看。

先说市场规模。据报道，TikTok电商今年的目标GMV是230亿美金。按最低10%佣金来算，也有23亿美金，折合成人民币就是百亿级盘子，还仅仅是一年。咱们去分一碗汤，难吗？

再看流量扶持。以后官方要做自营，电商类视频的比重一定会增加，不然KPI怎么完成？大家也知道，小黄车属于商业内容，推流和发布都会受到平台特殊管控。所以常有人问我：为什么同一类视频，带小黄车的流量总是干不过纯娱乐内容？因为规则不同，商业视频要过审，还要兼顾平台生态，毕竟谁也不愿意刷到满屏卖货。

接着是风险下降。以前带货最让人头疼的情况有两种：一是商家断货导致链接挂掉，二是产品质量拉胯导致店铺被封。结果就是视频还在爆，链接却没了，等于白忙一场。以后如果变成平台自营，这些坑会少很多，转化率和退货率应该也会更好看。

最后说一下收益和门槛。单看马来这一个市场，以前平均每月的GMV都能做到20到30万美金，佣金率大概在15%到20%，算下来一个月佣金就有30万人民币左右，别忘了还能拓展其他市场。![](img/882ec252f4e60faefee995bcfa6b9b26.png) 而做一条带货视频，剪辑门槛真的很低，播放量要求也不高，几百播放就能出单。这出单容易的程度，简直让人怀疑人生。![](img/058f9b540573d6e990a3107267b134cb.png)

不过最近几个月总有人跑来问，为什么小黄车没有一开始那么好做了。我自己手头的数据倒还算稳。想了下，主要两个原因：其一，电商视频多了，但平台政策还不成熟，方向摇摆，自然显得反复；等后续转向自营，应该会明显改善。其二，作品得升级，试试我上期讲的拆解玩法，素材重复和质量问题就能缓解，这里不再展开。

给几个建议吧：后续TikTok的电商大环境大概率是往好处走的，毕竟平台要冲目标、完成flag。还没动手的人，现在可以多留意。已经在做小黄车的，欧美号可以准备起来了，美区开通条件翻我上一篇就有；后续门槛肯定会降，不用太焦虑。眼下的重心还是放在东南亚，马来那边不用我多讲，菲律宾近期同样交出了不错的答卷。至于欧美全托管，我本人很看好，但毕竟才刚开始，需要一点耐心。对了，美国那边对达人带货也有补贴——只要发一条有效带货视频，就能拿到10美刀。![](img/c28c1bcbab9c49156540b54352549b02.png)![](img/4999ce15767cb5174ca480440b526619.png)

如果你发现美区账号没有TikTok Shop入口，也可以来找我帮你看看。
