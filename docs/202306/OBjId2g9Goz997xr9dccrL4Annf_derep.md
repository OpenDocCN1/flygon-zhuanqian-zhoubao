# 同城转店招商号：半个月精准获客500人、变现15万的真实玩法

最近后台总有人问我，现在做什么项目还有机会？今天分享一个我实操过的同城商业转店招商号项目。这不算什么秘密，但确实是目前竞争还不大的蓝海。从起号到成交，我们只花了500块投放成本，半个月内就拿到了15万以上的实际进账——还没算上后续陆续转化的线索。为了避免有人说我是标题党，这里先说清楚：这个数字只是已结算的部分，后续还有更多。

我叫井九，做这个领域之前也就是个不起眼的“小透明”。今天我会把这套玩法的四个关键环节全盘托出：项目逻辑、资源怎么找、账号怎么起、钱怎么赚。

先说说什么是同城转店招商号。简单讲，就是专门帮实体店主发布“店铺转让”信息，并以此吸引精准客户的同城账号。这个领域目前几乎没多少人做。我们专门查过数据，同一座城市里做这类账号的，多的也就七八个，少的只有一两个，连所谓的“十万粉大号”都还没出现。相比什么美妆、探店、情感号，这里明显还是一片蓝海。

做实体生意的人都知道，过去店铺转让主要靠三种方式：店门口贴张告示、丢给中介、或者挂同城网站。但效果嘛，大家心里有数。转不出去的话，押金打了水漂，装修费也全便宜了房东。所以，谁能帮老板们解决这个痛点，谁就能赚钱。同城商铺转让号，正好切入这个需求，前景相当可观。我们当时获取的精准客户数据，这里先放一部分：

其次是资源对接。很多人想入局，却不知道从哪下手，说白了就是手里没有“正在转让的店铺”资源。其实获取资源就两条路：

第一条，去同城网站上找。搜一下正在转让的商铺，直接联系店主，表明来意：我帮你拍视频、帮你推广。约好时间上门看店，顺手把素材拍了。我们通常头天晚上统一整理好联系名单，第二天花一两个小时，能跑五六家店，素材当天就到位了。

第二条，找中介合作。街边那些房产中介，基本都有转店服务。跟他们谈合作，拿店铺信息，资源共享。有了这两条渠道，你的视频素材就永远不缺。我们拿到的精准线索如下：

第三是起号运营。这种同城转店号，是真的好起。正常发五六条视频就能把号做起来，而且这几条视频本身就能带来客户。具体分两步：

第一步，视频制作。先找一个对标账号，照着它的风格模仿就行。这类视频基本不需要文案、不需要配音，一个标题配热门BGM，搞定。视频时长控制在12秒以内，保证完播率。

第二步，投放加速。想要快速起号、快速来客，投点钱是必须的。投放方法也简单：定位同城，范围设方圆10公里，兴趣标签选“个体创业”。正常情况下，两三百块就能把号拉起来。

这里要提醒一句：找店的人最关心的就是位置和人流。所以拍视频最好挑人流量大的时候拍，在视频里说清楚大致位置和周边有什么业态。素材好不好，直接决定起号成不成功。

最后说变现。这类账号的变现能力，比很多人想象中强得多。主要有三种方式：

第一种，广告费。号做起来之后，会有店主主动找你帮忙发转让信息。发一条收费200到500元。这个有人找过我们，但我们当时没接。

第二种，佣金。这是我们的主要收入。客户签约成功后，一般收十天到半个月的租金作为佣金。比如铺租4500，签一单就拿4500。关键是成交速度极快，一条转店信息发出去，一两天内就能成交。这种模式我们做了十几单，效果非常不错。

第三种，招商。很多商业管理公司最头疼的就是招商。我们帮他们发布商铺招商信息，客户签约后拿提成，收益相当可观。我们目前就正在和商业公司合作。合作谈法也不难：找即将开业的项目，或者去政府官网查公示，看看哪个商业地产中标了，直接上门谈，大多数公司都愿意合作。我们曾经一个星期就帮一条小吃街招满60个铺位，还帮一个超市综合体招满80多个铺位。这里的变现分两块：佣金一般是一到两个月租金，以及招商管理费——这个没有固定标准，全看你怎么谈。这部分的钱，甲方付了管理费，前期佣金也预付了十几万，但后面还有尾款没结算完，所以我就不细说了，免得又被说标题党。

其实这行还有更多变现玩法，只是对圈内老手来说，都是老生常谈罢了。
