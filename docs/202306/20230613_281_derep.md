# 《3 步用 GPT 教你轻松掌握抖音 18 个爆款密码》
作者：龙哥

作为从去年12月就尝试用GPT辅助文案创作的老司机，我见过太多人拿着半懂不懂的“干货”去训练AI，结果可想而知——自己脑子里没货，教出来的模型也就跟着“注水”。但今天想聊一个反常规的思路：与其急着让GPT给你打工，不如先让GPT当你的老师，把爆款的底层逻辑给你讲透，然后你再回头去训练它。没错，先让GPT训练你，你再训练GPT。

这个课题的缘起，要感谢刘敏老师。她给我看了一份从别处学来的“抖音18个爆款密码”清单，想让我帮忙融进GPT的训练里，但她总说GPT“理解得不到位”。我拿到手一看，这清单其实已经非常全面了：目标人群锁定、撕开认知缺口、挑衅拉情绪、自曝弱点制造优越感、直击痛点、呈现人间美好、神秘悬念、传奇故事、高浓度情绪表达、围观凑热闹、脑洞趣味、陌生化人物关系、反差与反转、唯美质感、窥探内幕、节奏押韵、视听沉浸、欲望满足……几乎把爆款视频的流量密码全都涵盖了。

按理说，这么完整的“配方”喂给GPT，应该能产出不错的内容吧？可实际效果却差强人意。问题出在哪里？其实是很多人的通病：我们以为把知识点丢给AI就算“训练”，但AI消化不了每个密码背后的语境与分寸，而喂它的人自己也是一知半解，结果自然是鸡同鸭讲。

所以，我换了一种完全不同的玩法：先让GPT当教练，反过来教我。整个过程可以分成三步：

第一步，把这份“18个爆款密码”整理成学习资料，投喂给GPT，让它扮演一位抖音爆款导师，先把每个密码拆解成能理解、能举例、能出题的知识点。

第二步，让GPT主动向我提问、设置场景、逐个考我。比如它会给我几个真实选题，问我适合用哪个密码、为什么选这个、用了之后对流量有什么影响。我答错了，它会当场纠正，再配案例讲透。几轮下来，那些原本模模糊糊的概念，就变成了我脑子里真真正正的判断力。

第三步，等我真正把这些密码“吃透”了，再回头去训练GPT。这时候我给出的提示词更精准，我对内容的审美更接近爆款逻辑，GPT在我手里写出来的文案，自然就上了一个段位。
