# 一、🛰️问一问到底是什么

有人习惯把它归到知乎类平台，我觉得更像知乎和📕的结合体，讲究用户用极短的时间就能读完一篇干货。

毕竟知乎用户整体调性偏高，门槛不低。

官方原话是：在问一问首页，用户能看到系统为你匹配的优质有趣问答。

在看他人回答时，你也可以对感兴趣的话题发表看法、输出经验，还能直接进问题广场挑自己擅长的问题作答。

优质内容不仅会在问一问首页获得推荐，还会在用户通过搜一搜找相关问题时被展示，解决更多人的困惑。用户看完可以点赞、转发或关注作者。

# 二、为什么要做问一问

这是目前视频号能拿到的快反馈流量口之一。

如果你在做视频号，想快速积累正向数据，这里很合适。

通过回答问题，能摸清🛰️用户真实在关心什么，源源不断给创作挖灵感。

比如写👸号文章时，别人问的问题、自己脑中冒出的一个点，都能直接拿来当选题，甚至用来梳理文章框架。

高质量的回答会被推到问一问首页。

同时在搜一搜结果里，相关搜索的首条位置也有机会被展示，用户看完能点赞、转发。

关键点：用视频号的视频来作答，还能给视频本身带来额外曝光，是涨粉的新渠道。

那要怎么写才能更容易过审、更受欢迎呢？
