# 选培训、知识星球还是付费群？先把这三件事想透

最近在社群里和朋友聊到一个高频问题：想做知识付费，到底该做线上课、知识星球、小报童，还是直接拉个付费群？尤其是被海参哥的那条视频推了一把之后，大家的纠结更明显了。

我自己是龙哥盟的老圈友，做社群运营七年，现在在管抖音电商和本地生活的两个垂类圈子，业余也帮几个朋友搭社群。这问题其实没有标准答案，关键看你手上的内容和你能Hold住的人群。

现在市面上常见的知识付费载体，大致就这几种：小鹅通这类平台的线上培训课、线下培训、知识星球、小报童、需要付费才能进的🛰️群。线下高客单我们先放一边，剩下四种客单价其实都在一个区间，很容易选花眼。

判断能不能选对，我通常看三点：内容垂直度、客单价与交付周期、受众画像。

**一、你的内容是垂类还是泛垂类，能不能持续产出新东西**

龙哥盟是典型的泛垂类，核心是“赚钱”，下面能塞进几十个细分项目。垂类社群像尹晨的直播带货俱乐部、刀姐的ChatGPT风向标，群里就一个主题。

这两种玩法差异很大。

垂类圈子大家都是同行，愿意分享的人只占少数，绝大多数是来吸血的。去中心化的UGC很难起来。再加上垂类主题如果已经很大，比如抖音电商，分享两三年后能说的干货就差不多了。

泛垂类就不一样。项目可以一直换，热度可以一直拉，今年ChatGPT，明年可能又是别的风口。即使老内容都被翻烂了，还是能用新赛道续命，这就是知识的可迭代性。

**二、几百块的低客单，你真的愿意交付一年吗**

很多人看到赚钱、看到粥左罗的ChatGPT星球，就觉得开个星球就能躺赚：把旧资料倒进星球，高额返佣拉新，用户自己产生内容，第二年续费滚雪球。别被表象骗了。

低客单星球最致命的问题是投产比。几百块钱要你365天日更，这件事本身就很逆人性，等于每周强制运动。内容池撑不住，星主自己先扛不住，最后无疾而终，口碑还砸了。

低客单星球真正的价值不是躺赚，而是两个作用：
1. 知识沉淀，让进群的新人能找到历史讨论和资料；
2. 大会员筛选，通过裂变拉来用户，再按活跃度和付费意愿筛选出愿意付更高价的人，进到付费群。

如果我确定这个赛道不打算做大会员，我会直接用小报童。一锤子买卖，不承诺一年交付，各取所需。

另外，话题延伸性差的内容，比如朋友圈运营、知识管理、时间管理，这种做一年星球根本撑不起来，更适合做成小鹅通的线上课程，一次交付，干净利落。

**三、客单价的高低取决于人群，不是数字**

多少钱算高客单？没有统一标准。

对学生党来说，几百块就是低客单，几千就是高客单。对企业老板来说，几千只是入场费，几万到十几万才是正常价。我朋友的一个老板群，入群除了年费，还要先发2000红包，人群定位就决定了定价逻辑。

所以入局前一定要问自己两件事：
1. 我的内容最终要卖给什么样的人？
2. 我这个人能不能Hold住这群人？

看到群响做的私董会就觉得老板群好赚钱，很容易想歪。国内很多所谓的私董会，其实是老板建联俱乐部，需要群主有强IP。真正的私董会运营难度极高，不是聊聊天就能躺赚。想了解可以去看《解码私董会》，别被表面光鲜误导。

**最后说一句**

想在培训、知识星球、付费群之间选对，先别急着开。

先想清楚：内容是否垂直，能不能迭代；客单价匹配不匹配交付周期；受众是谁，你能不能服务好。
