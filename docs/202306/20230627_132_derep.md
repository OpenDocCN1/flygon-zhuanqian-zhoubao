# 刚毕业月入5W+，我的球鞋搬砖全拆解

先交代下背景：我今年22岁，刚大学毕业。在校那会儿拉了支小团队，搞了个叫“森林”的工作室，主攻球鞋搬砖。数码、茅台、日化、美妆这些能“撸货”的赛道，我也都有涉足。凡沾上“撸货”两个字，基本都绕不开我。

这行我待了差不多3年，手里攒了完整的线报渠道社群，也有自己一套出货模式，对市场走势还算敏感。

说回球鞋搬砖。在整个撸货盘子里，它算最好上手、见效也最快的一个品类。从挑款、下单到变现，几乎都能在可信的大平台上完成，不用自己瞎折腾。当个副业做，也不会侵占多少主业时间。

我把这几年踩过的坑、摸过的门路，全部摊开写进了一份飞书文档，还额外配了一小时视频教程，相当于手把手带。眼看618就快到了，这波球鞋搬砖和撸货正处于红利期。但愿看到这里的老板，都能赶在风口上捞一笔金。

当然，丑话也得说在前头。评论区有位老哥说得挺实在：三四年前这行堪称暴利，现在大批企业和商家挤进来，得物这类平台手续费一涨再涨，加上小白卖家一批批涌进来各种砸价，个人卖家想赚差价越来越难。把选品、收货、瑕疵修复、打包、寄货、出价这些环节揉在一起，最终利润也就剩下10个点上下。

这我也认：有信息渠道的能再往上走，如果没有，搬砖的利润点差不多就是10%。而且利润和周转率是绑在一起的，周转够快，哪怕单笔利润低点，照样值得做。

还有一点很容易被忽略：时间成本和人工成本。出货也许能自动化，但出货之前的活儿可一点不省心——一箱箱快递往家里搬，拆箱、验货、查鞋盒，盒一破或者鞋有瑕疵，寄过去就是“检测不通过”顺丰到付退回。回头还得重新打包、填单、传单号，全是磨人的细节。

经常有人问我：是不是得先进群才能开搞？真没必要，我只是做信息分享。

球鞋搬砖能不能稳稳月入5W+？答案是能，但不是闭眼冲。信息、渠道、精细化运营，再加上周转效率，才是这个项目真正的护城河。
