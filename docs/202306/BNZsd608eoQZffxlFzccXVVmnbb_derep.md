# 知识星球_🛰️群消息提醒

你有没有过这种体验：白天忙得脚不沾地，晚上回家狂刷社群消息，总觉得自己错过了好几个亿？说白了，就是懒。但懒才是推动工具进步的第一生产力。

前几天航海刚满14天，我突然冒出一个想法：能不能搞个机器人，把知识星球每天的新帖子自动推到个人🛰️？说干就干。研究了一圈发现，知识星球的网页API其实挺好搞，只要带上cookie就能拿到自己加入星球的内容。一开始想用🛰️👸号做推送，结果发现只有订阅号支持，还得企业认证，太麻烦，直接放弃。后来把目光转向企业🛰️机器人和飞书机器人，轻松解决。

初版思路很简单：先做定时推送，后续再按分类过滤，最后加上订阅关键词和GPT总结。别小看这个路线，循序渐进才靠谱。

目前已经跑通的能力包括：企业🛰️机器人通知，最新消息和风向标群的实时提醒，而且Linux和Windows都能部署。放几张效果图感受一下：![](img/7a7b5fa293c29c052c364be65d7a9c19.png)

上手也很快，三步走：

第一步，注册个企业🛰️（不需要企业资质认证），随便建个群，添加机器人后拿到webhook地址，改配置的时候会用到。看图：![](img/b894494570a1622bbf75fdda105e09f0.png)![](img/f2aacab22aed51be07b9e2af6f5827e1.png)

第二步，获取知识星球cookie。暂时没做扫码登录，需要手动在电脑端网页登录知识星球，按F12打开开发者工具，切到network，随便点一个接口，把请求里的cookie复制出来就行。注意看下图圈出的位置：![](img/5f9cf0e7a3248dbefaa83d234e59c14a.png)

第三步，改配置。把刚才的webhook和cookie填进去，保存。```
[wx]
# 微信机器配置(填写webhook后的uuid)
robotKey =
[zsxq]
# 获取最新消息
# https://api.zsxq.com/v2/groups/1824528822/topics?scope=all&count=10
# 获取风向标内容风向标
url = https://api.zsxq.com/v2/hashtags/28514444451481/topics?count=1
# 知识星球cookie
cookie =
# 解析数据格式为talk内容
type = 1
[config]
# 定时消息通知频率 默认1小时发布一次
cronTab = @every 3600s
```

然后在Linux上启动就完事了。启动命令和效果看这里：```
# 假设程序部署在data/wechat 目录下，用绝对路径执行
nohup /data/wechat/wechatrobot &
# 检查服务是否存在
ps -ef |grep wechat
```![](img/c5a049b3960c4c42609d49799586372b.png)

程序下载地址也准备好，直接拿去用。工具虽小，但能把每天“错亿”的焦虑治好了，这波不亏。
