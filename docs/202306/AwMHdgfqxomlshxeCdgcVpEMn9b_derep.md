# 靠商业软文赚钱的人，都在偷偷用这套“明暗线写作法”
作者：龙哥

我是龙哥。做内容这几年，我几乎从不公开讲自己的赚钱方法。今天破例，把这套我反复迭代过的商业软文打法，从头到尾完整聊一遍。

先说我对商业软文的判断标准。在我看来，一篇真正值钱的商业软文，至少要同时做到三件事：做IP的人看了会迅速信任你；做引流的人看了会愿意成为你的粉丝；做成交的人看了会直接给你付款。说白了，读者读完了觉得有收获，你写完了有商业回报，这样的文章才是合格的商业软文。

我就是靠这套方法，一个人、不露脸、粉丝数量也谈不上多，闷声赚到了自己的第一桶金。放心，下面要讲的不是假大空理论；只要照着执行，很快就能看到结果。

很多人以为写作需要多强的天赋或文字功底。真不是。我读的是软件工程，标准的理科生，那点文学修养和大多数人都一样，基本就是义务教育给的那点底子。毕业后我直接扎进新媒体行业，一边做一边琢磨，才有了这套方法。当时我工作经验少、社会阅历也少，很多方面可能还不如现在的你。

这套方法后来我也用来带学员，最神奇的地方是它可以被快速复制：零基础的人也能在很短时间里，写出真正有商业价值的软文。

下面我分五个板块来讲：我怎么做起来的；一篇完整商业软文需要具备什么；怎么搭建写作外挂；具体的实操SOP；以及最后的心态提醒。

## 一、我怎么做起来的？五个阶段

第一个阶段：看到很多内容创业者一根网线、一台电脑在家敲键盘，觉得这行业太适合我了，结果自己照做，怎么都起不来。当时我认定：一定是因为没有爆款。于是进入第二阶段。

第二个阶段：我逼自己死磕内容，终于做出爆款。但爆款有了，钱却没来。每天盯着好看的数据，就是没人找我打广告，也不知道流量该怎么换成收入。于是进入第三阶段。

第三个阶段：我突然想明白，爆款和赚钱是两回事。想靠内容赚钱，不能只盯着内容，还得盯着商业价值。我给自己定位成“内容商人”，开始大量写商业软文。最开始我以为只要晒干货就行，于是疯狂看书、查资料，堆了一大堆专业内容进去，结果读者根本不买账，数据很难看。

第四个阶段：我意识到一个关键误区——作者觉得的干货，不一定是用户觉得的干货。尤其内行人写东西，最容易犯的错，就是没办法切换到用户视角，去看他们到底需要什么。想通这一点后，我开始研究“怎么写自带爆款潜质的商业软文”，也是从那时起，我终于能靠文字收到钱了。

这里放一下我当时的账号变化和变现情况。![](img/c759487a1deaedecf9dc47199eedf05f.png)文章发出去之后，很快就有人付款。最开始我设的价位是2999和5999，后来改成3580和6580，来报名的人里差不多80%都选了高价位，只有确实预算紧张的人，才会退而求其次选便宜那档。

其实原本效果还能更好。因为当时我没有提前设计好商业闭环——流量好不容易做起来，精准用户涌进来给我“喂饭”时，我却没有做引流，也没有准备好变现方式。所以特别提醒你：先想好靠什么赚钱，再动手做内容。不然等内容爆了，再回头搭变现路径，难度会高很多。

第五个阶段：到这一步，爆款商业软文能写了，钱也赚到了，但效率跟不上。互联网上的生意，快就是生产力。写得慢，迭代慢，赚钱自然也慢。所以我又开始研究：怎么在保持爆款属性的前提下，快速写完一篇商业软文。

结果大家看这个：知乎好物这个项目，估计很多人听过，甚至亲自做过。现在大家都在唱衰，说风口过了、知乎都是营销文、带货赚不到钱。而在我的好物矩阵里，一个变现最强的账号，三年给我带来了70多万佣金。![](img/b3aca6d2abaf5eeded1e0705b8f0a3fe.png)其中某账号的一篇文章，就单独贡献了20多万佣金。![](img/020f680726dd25785877f8b9be0d55a7.png)这还只是佣金，没算其他商业合作。![](img/dce12bcf6164ae819948c1dd2a889400.png)

我承认我确实赶上了一波风口，但如果只靠运气，撑不起这个结果。真正让成功必然到来的，是方法论。

## 二、一篇完整的商业软文，必须具备两条线

我带过的学员，凡是能靠商业软文赚到钱的，文章里一定会同时满足两个条件：明线和暗线。

“明线”这个概念是我自己定义的，不太好理解，但极好用。简单说，明线就是文章里可以被替换的知识点或观点。比如你写自媒体写作，“标题怎么写”这个知识点，从别的平台搜来一段类似的话换上，效果也没差，这就是明线。

记住：一篇文章里，凡是可被替代的信息，都叫明线。

那什么是“暗线”？暗线是影响用户决策的东西。比如你的个人人设、你的背书；比如你故意引导读者私信你、在评论区提问；这些无法用别人的内容替代的部分，就是暗线。

我放一个小片段给大家感受一下：![](img/eeeb4662f0cfc17b7512c71d17e13d7c.png)

先看第一段：![](img/e92f9d2558b5f53f6bc4d39e5cb3adf3.png)它强调“找对平台、大胆展示自己”的重要性，本质只是一个观点。你完全可以从别处找一段意思差不多的话替换掉，所以它是明线。

再看第二段：![](img/ccfc498feb8d62643e784e800859a7ff.png)这段话的意思是：如果你想去展示自己，我整理了很多渠道给你。读者看到这里，很可能想知道这些渠道到底是什么，于是跑去👸号回复“渠道”。看到没有？内容已经在影响读者的下一步动作，这就是暗线。

所以，拆解同行文章时，就用这两条线去分。把它拆成框架，明线从别处找内容替换，暗线换成自己的故事和引导方式。

自己写文章时，也可以摸着爆款过河。普通人写东西难在哪？难在想把自己的经历讲清楚却不知道怎么讲；难在想让文章既有干货又好传播，还要能引流转化。如果你非要从0到1硬憋，会很痛苦。但有了好文章做参照，你就直接跨过了最难那步。创业和输出的逻辑一样：从0到1极难，从1到100其实很轻松。

## 三、搭建属于你的“写作外挂”

听到这儿，可能会有人说：就算让我照着改，我也改不出好东西，脑子里没墨水，顶多把“被”字句改成“把”字句。

真相是，你缺的不是灵感，而是素材库。那些写得好的人，不是天赋异禀，而是背后有一个庞大的优质素材库。高手写作永远是从选题和素材开始，小白才从一张白纸开始。

所以接下来教你搭写作外挂。搭好后，你写东西的速度至少能提80%。别怕复杂，这套方法我实操过，也带学员实操过，已经简化到只剩最核心的两个动作：记录 + 搜索。

先讲记录。记什么？

一是知识点。书里、文章里、课程里看到的好内容，我会马上收进印象笔记。二是感觉。比如某句话、某个视频让我情绪被触动，我会把这种感受提炼成标签存下来。看了一篇很牛的观点文章，我可能标记“感觉牛逼”；看了一条让人很想下单的朋友圈，我会收藏并标记“产生购买欲、产生冲动”。![](img/7041b615586852939700e7d0669d89bb.png)等以后写文章想让读者冲动时，打开这个标签，一堆现成的表达就出现了。

一个垂直领域里的庞大优质素材库，是持续稳定输出的底牌。

再讲搜索。素材库不是用来收藏的，是用来“取用”的。比如我想表达某个意思，明明之前看过一句话特别精准，但就是想不起来原话，只记得大概关键词。如果当时没记，过了就很难再找到；如果记了，搜一下关键词就能立刻调出来。

那怎么确保自己“想搜就能搜到”呢？我有个习惯：记录时不仅写下原始内容，还会顺手标注“延伸”和“重点”。“延伸”是我当时联想到的东西；“重点”则是多提炼几个关键词，防止以后记忆出错搜不出来。![](img/b81b5e9ad3af3dda9ea5bb105e68d890.png)关键不在于“存完就完”，而要时不时回头把这些素材拎出来，反复检查、补充关键词，让它们真正成为你随时调用的弹药。

## 四、实操SOP：从原稿到收钱软文

上面讲了“做什么”，现在讲“怎么做”。这套SOP不是教你洗稿，我也不鼓励洗稿。它是有效借鉴。建议你先看一遍了解全流程，再看一遍照着实操。

第三、四步：动手改明线和暗线。我分别举两个例子。

**案例1：看原稿的开头。**![](img/967dd3c86fc402b4ab7435dd2cc8f8f5.png)我会怎么改？这时候靠的就是平时积累。第一步，我去印象笔记搜索“开幕雷击”——平时我遇到好的开头，就会标记这四个字，所以一搜就能搜出一批高质量开头。![](img/8df1c3db5ad8123e2a763eaaeb87f404.png)第二步，挑一个合适的开头直接套用，比如这段：

“这篇文章可以在一定程度上改变你的生活，帮你大幅度提高情商，别不信，这是有多个案例与理论，以及实验数据支持的。全程干货，建议点赞收藏，方便在动态里查看并学习。”

这个句式几乎全行业通用。做医美的，可以改成“大幅度提高颜值”；做理财的，可以改成“大幅度提高收入”；我做创业内容，就改成“大幅度提高业绩”，然后再说“全程干货，建议点赞收藏，方便需要时反复学习”。

不过这样改，我还是觉得不够扎实。因为里面有一句“别不信，有案例与理论、实验数据支持”，读者看到后会追问：证据呢？如果你没把证据拿出来，这句话就没有说服力。所以必须在后面补一个真实案例，把这话立住。我优化完的效果是这样的：![](img/cd89933281fb264f1b23cfa91d47bf0c.png)这里有个技巧：能放截图的地方一定要放截图，图片的冲击力远大于文字。

再回想一下暗线的概念。![](img/da9746b34dcda9d3d92176dc821307f6.png)你会发现，我补的这个案例，其实就是把暗线放进了文章。这个案例也是从我印象笔记里搜出来的，平时看到自己或别人那些能证明实力、显得很厉害的证据，我都会随手存下来。如果你现在没有成功案例，怎么办？那就写你做过的努力：你拆过多少篇爆款、调查过多少用户、请教过多少高手。用你做过的努力去把观点撑住。我观察过很多刚开始没成果的作者，他们就是靠这个办法获得信任；我自己起步时也这么干过，非常有用。

所以，不是你没有成功案例，而是你太不擅长发现和积累。小事只要没记下来，就相当于没发生，以后也帮不到你。

**案例2：再看文章里一个典型片段。**![](img/64920679d75c9b0ba7aedda829f28894.png)这部分本来写的是“4个优化维度，做出爆款内容”。我可以把它改成什么？核心还是“怎么做爆款内容”，于是我从外部资料里找相关观点，看到了这个。![](img/c0b9281e68668c333f2d68d180fdca2a.png)它强调的是标题对爆款的重要性。那思路就有了：做爆款的最大流量密码是标题！

内容怎么填？我去印象笔记搜“标题”，会弹出一大堆平时存好的相关干货，直接替换就行。比如这个，是我自己在实战中的感悟：![](img/5699ee1802f977383ee56c3b45c60d90.png)再比如这个，是我在课程里听到的，讲得特别好就摘了下来，这类知识点基本不用改，拿来就能用。![](img/b5d168bab4afdbacad751fafb6d7f079.png)这样，平时花那么多钱买的课，就能立即产生价值。

我建议你在摘录时，一定要在下面补上自己的理解、经历或感受，它才能真正变成你的东西。举个例子：我读《把时间当做朋友》时做过一页笔记，第一段是书中的知识点，第二段是我当时产生强烈认同后，用自己的经历做的举一反三。后来写文章，第二段直接就能用。![](img/28c8ebd6d20a1f0cb128548bf85b650f.png)

以此类推，把全篇的明线和暗线都替换完，整篇文章就像盖房子、拼积木一样立起来了。你的积累越厚，能表达的观点就越多。掌握这套方法后，写出能收钱的软文，就像算“1+1=2”一样简单。

第五步：全部改完后，把整篇从头顺一遍，调整一下语感，确保通顺。

## 五、最后，关于心态的两点提醒

第一，目的必须非常明确。做IP要有定位，写文章要有目的。别指望在网上随意说说话就有人付费。你自己都不清楚要赚谁的钱、能帮哪类人解决什么问题、想让读者看完做什么动作——是进私域，还是直接下单？你越含糊，读者越迷茫。哪怕文章写得再好，他大概率也就是点个赞、评论一句“受教了”，然后头也不回地走了，钱自然难赚到。

第二，利他。这个词虽然被说滥了，但我还是要再强调一次。想写得快、写得好，别丢掉初衷。你的初衷是真诚，是帮别人解决问题。只要时刻记得这点，思路就会清醒，文字也会自带说服力；一旦太想“镇住”读者，动作就会变形。你越拧巴，读者越能感觉到；而你越真诚，读者也越能感觉到。

这套方法我已经反复验证过很多年，从一个人闷声写，到带学员一起写，靠的就是这些笨道理和可复制的流程。如果你也想用文字赚钱，先别急着啃厚书，从今天开始，建立自己的素材库，拆一篇爆款文，走一遍这套SOP，结果慢慢就会浮现。
