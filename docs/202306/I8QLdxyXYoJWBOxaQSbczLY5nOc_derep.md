# 聊聊我对Google Cash的一点个人看法
作者：龙哥

接触Google Cash这个圈子差不多三个月了，有点个人体会想聊聊。这个行当，有人叫MediaBuy，有人叫Brand Bid，也有人干脆把它归到Affiliate Marketing的范畴里。

先说说我总结的几个感受吧。想入门的话，别指望速成，至少得给自己预留三到六个月，按每天两到四小时来算。玩法是真的多，有浅水区也有深水区，横着竖着都能走，不少大佬年入七位数，听着都挺轻松。这行其实已经存在很久了，和国内那些热门赛道相比，反而没那么卷。可惜的是，中途放弃的人很多，半桶水晃荡的人也很多，圈子并没多大。真正闷声发财的大佬，基本都很低调，不露面、不搞培训；据说有家两三个人的工作室，一年干出1.4亿纯利润，至于怎么做到的，估计只有头部玩家清楚了。而市面上做培训的，多数交付完就没了下文，不陪跑、不售后；再往前推几年，收了钱发个电子文档，剩下的就靠自己摸索了。

有对比，才有伤害。口罩那三年，多少行业被冲击，多少项目大佬从高处跌落。最近参加线下分享，台下坐着一堆各赛道的老板，台上是个有十几年互联网经验的大咖。不知道大家发现没有，这段时间赚钱也好，别的圈子也好，线下聚会越来越频繁。有人正做着手里的项目，有人到处找新项目，也有人骑驴找马，暗暗备着Plan B、Plan C。

其实不管平台怎么换、项目怎么换，底层逻辑都是相通的。但有些问题躲不开：信息差越来越小的时候，我们的核心竞争力到底在哪？流量红利消失了，手上没资源、没供应链的老板，下一步该往哪走？知识付费、项目代理，还有各种信息差认知差的收割，当镰刀越来越多，韭菜越来越精明、口袋越来越空，项目的基本盘又该怎么守？

拿我们团队自己来说，2022年辗转换了好几个项目：数字藏品、信用管理系统、美团外卖柜、芯片制造业、互联网医馆……一路跌跌撞撞。我们做流量的能力不算差，但一直缺供应链，缺一个自己的好产品，再撞上大环境，真是举步维艰。到了2022年底，团队停下来认真思考，重新找方向。

接触Google Cash，是因为身边一个做了快十年的好兄弟。以前我们各自在自己的领域里都算小有成绩，可疫情一来，我们很吃力，人家的Google Cash却越做越好。所以从2022年底到2023年初，我们一边接触各种项目，一边筛选，最后决定从零开始，深耕这个方向。

有对比才有伤害，有对比才有思考。这两三年里，见过太多做项目的朋友起起伏伏。有人感叹：当年淘宝天猫做得好的时候，自己也是风生水起，后来转京东、转拼多多，再转抖音、快手，现在又盯上📕；折腾了这么多年，赚过八位数甚至接近九位数，最后却亏得一塌糊涂。换项目、换赛道，钱是赚到过一些，沉淀也沉淀了一些，但好像最终什么都没留下。

这大概也是很多普通做项目的人的共鸣吧。能赚钱，但不太容易持续赚；能赚钱，但不太容易守得住；能赚钱，但不太容易让钱生钱。

再说说Google Cash的赚钱逻辑。前几年国内流行社交电商，像芬香、粉象日记、好省这些，靠推广各大平台商品赚佣金。但这种模式没火多久，原因无非几个：平台用户规模上来之后就开始压缩佣金，带货达人、团队长的收益跟着降，推广热情自然就凉了。说白了，国内项目特别吃平台，平台肯让利就有得玩，平台一抠门就难做；今年冒出来的美团圈圈，其实就是社交电商换了个马甲卷土重来。制度上，早期团队计酬掩盖了多层级问题，后来法规越来越完善，淘小铺这种“出头鸟”被重拳打击，行业也就没法玩了。还有短视频崛起，大家购物习惯变了，推广方式也跟着变。

我自己2017年就开始做自媒体，那时候还是图文时代，头条、👸号、百家号都挺赚钱，坚持下来能赚得盆满钵满。可互联网哪有什么“三十年河东三十年河西”，三个月就能天翻地覆。这正是我们想入局Google Cash的原因之一：国内很多赛道变得太快。像短视频平台，家家都在切蛋糕，平台在变、规则在变、用户流量都在变，不时刻学习就容易淘汰。你看2020年、2021年的很多网红，现在都快没影了，除了内卷，也是因为变化太快。

当然，Google Cash也不是一成不变，Google在变，规则在变，推广者也在变。但老外和国内搞项目的人比起来，确实没那么卷。他们整出一个东西，往往能用几十上百年，变化节奏相对慢得多。

简单说说赚钱逻辑吧。MediaBuy，字面意思就是“媒体购买”：我们花钱向Google买精准流量，然后变现。前提是，老外虽然也用APP，但很多人还是习惯用浏览器搜品牌，Google浏览器在国外的使用率能到90%以上。这些搜索用户是精准用户——本来就是冲着某个品牌去的，下单意愿很强。比如Skechers这个品牌，单月搜索量能有5.5M，也就是550万次自然搜索，都来自Google这类浏览器。![](img/5a9bc4c504d36d282d0a847a507fcaaa.png)

Skechers这样的品牌，在Rakuten等返利网都有offer，比如Rakuten上面现在是“6% Cash Back”。![](img/deea91f46086532fe47502eedd2b74cb.png) 点进去就是Skechers官网，官网常常有最新活动，比如“Up to 30% OFF”。![](img/1bab6079a6131acc35a3d0435e05d477.png) 这个牌子的商品均价大概在$100左右。![](img/f1cf2d1c3209e3dffc909467f1844ef8.png)

这是6月14日Google Ads后台的截图，总消耗Cost是$16.41，单次点击CPC只要$0.01，展示量2040次，点击数1490次。![](img/2d94729861cde45fe6b52b60d2df3fbf.png)

接下来算笔账。1490次精准点击，按100个人下单算（差不多15个人里有1个），客单价按$100算，佣金收入就是100×100×6%=$600。而投入不到$20，产出投入比超过30。返利网通常做到10以上就算正常，到20、30甚至更高也时有发生。相比之下，网盟的产出投入比还能更夸张。

不过，高回报肯定有风险。Google Cash的风险主要在几个地方。

第一，广告主通常不允许你拿他们的品牌词在Google Ads里投，但所有人都知道，品牌词搜索量最大、收益最吓人——越是不让碰的，利润空间越大。第二，如果被发现，轻则不发佣金、联盟或返利网K号，重则终止合作。所以找到稳定的网盟/返利网，跑稳定的offer，特别重要。第三，测试offer需要时间和金钱成本；很多培训机构会提供“赚钱的网盟”或卖offer，说白了，那才是别人赚钱的东西，也是课程噱头。第四，新人申请网盟账号是个坎，过去跑EMU的大佬账号很多，但EMU不好做了，他们也转型MB；新人只能花时间搭建合格的博客来提高通过率。第五，流动资金问题。网盟回款有的30天、有的60天，返利网普遍要90天。广告费投出去，回款要等一阵；资金要合法合规，还得有正规境外收款渠道，比如PayPal、空中云汇、海外公司等——这些虽然都有教程，但还是要自己研究。第六，水很深。账号、收款渠道都有专门做这门生意的人，但林子大了什么鸟都有，自己得会辨别。如果是和老外打交道，新人最好先悠着点，真出了交易问题，你可能人都找不到。

我实操大概两个月，现在每天稳定在200美金以上。这点收益在大佬面前是小巫见大巫。但我也有一点体会：不管返利网还是网盟，都得有规划，广告费怎么花、账号怎么养、offer怎么选，提前规划好；遇到问题才不慌，也才能把手上的资源真正用起来，拿到实实在在的收益。

写在最后。任何项目都有生命周期。业内大佬爱开玩笑：只要Google服务器不关，这行就能一直赚钱，再做十年二十年也没问题。但我做过的项目不少，不敢说那么绝对，只提几点看法。

第一，现在跨境项目越来越火，做TK也好，做MB也好，多半是国内太卷，想卷到海外去。但别被带节奏，学MB之前要想清楚，学了能做多久，学了之后能干什么。第二，MB关联的行业不少，比如跨境电商、海外广告优化师。沿海地区，不管你是老板还是给老板打工，想把产品卖到海外，就绕不开海外广告投放。Google、Facebook、Bing、TK都有技术门槛，要么自己懂，要么找靠谱的团队，既涉及花钱，也涉及防骗。所以学完MB，不只是每个月多赚两三万副业钱那么简单。第三，今年有的大佬在各种场合放话，说抖音电商可能很快就要落寞。我不清楚依据在哪，但一个领域一旦大批人涌入，确实容易卷起来。那么，怎么判断一个行业值不值得深耕？我看有三个标准：行业容量有多大，进场的人变多以后会不会卷起来；横向纵向的发展方向够不够多、够不够宽；能不能延伸到别的方向，带来持续稳定的效益和正向影响。

互联网变化再快，赚钱还是尽量赚稳定、长远、持续的钱。那些赚快钱的机会，最好三思而后行。这也是我们过去七八年折腾各种项目攒下的经验。

真心希望这篇文章对你有帮助，祝各位老板在赚钱路上多多发财！
