# 三分钟把高手经验搬进我的笔记：一个让我阅读提速的 GPT 插件



## 28 个赞  一个能帮你快速做结构化笔记的 GPT 插件推荐

作者：贤妹  
发布日期：2023-06-09

大家好，我是龙哥。今天想和你分享一个我最近在用的阅读提效工具，主要是用来借助 GPT 插件实现秒级笔记和摘要。

如果你像我一样，经常要刷很多文章，又希望用统一的模板来整理要点、提炼摘要，甚至从阅读内容里自动生成行动清单，把学到的东西马上落地，那这个工具真的可以试试。

我用的插件叫 HARPA AI。打开你正在看的网页，直接点一下浏览器里的插件图标就能唤起它。里面自带了一套快捷指令，一键就能跑，不需要自己写提示词也不用反复调试。

上手门槛也很低，跟着页面里的说明走几步就能用。
