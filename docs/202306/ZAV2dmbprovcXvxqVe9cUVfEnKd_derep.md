# 我让人人0成本卖洗衣家政每月多赚一万
作者：龙哥

我帮普通人零成本兼卖洗衣和家政，每月多进账一万

前阵子我分享过自己操盘互联网洗衣项目的经历，这两年陆续带了几十个老板在美团这类电商平台跑虚拟洗衣店群，核心玩法就是做电商中间商：不碰洗衣机、不租门面，接单客服自己做，洗涤部分统统外包给合作干洗店。

最近一个开社区便利店的哥们儿点醒了我。我们顺势跑通了一套更轻的“云洗衣”玩法——本地生活的老板们根本不用开网店，只靠店里自然客流就能把洗衣和家政卖出去，老板只需要胜任客服和调度这个角色。我花了3个月把便利店、复印店、餐馆、快递驿站这五种业态轮番测了一遍：每个店每月洗衣加保洁能做到1万到2.3万的销售额，利润最低也有六七千。因为不占人工、不占地方，洗衣又是超高频需求，甚至能做成无人自助下单。所以手头有客流入口的物业老板、门店老板、私域里有本地客户的生意人，都适合拿来当增收副业；普通人也能找线下商家异业合作，当个倒手赚差价的中间商。下面把整套复盘经验交个底，欢迎交流指正。

一、这门生意赚的是什么钱？怎么当中间商？

洗衣和家政行业有一个隐藏了十几年的真相：这两个行业的外包代工链条非常成熟。大量从业者根本不自己洗衣服、不自己养保洁阿姨，本质就是二道贩子，只抓客服和获客。有些洗衣店门脸看着挺像样，里面早没洗衣机了，就是个收衣点，衣服集中送到大洗护中心处理。全国差不多九成的家政公司也是派单给社会上的灵活保洁阿姨，没几个养全职员工。

年初一个名下好几家便利店的老板跑来问我，互联网洗衣能不能塞进自己的店里，让店员结账的时候顺手推一把。这个需求点醒了我：到家的生活服务其实很难拉开体验差距，谁有稳定到店客流，谁又有私域信任基础，谁就能成交。于是我们干脆合作试了试，又把街边餐饮店、复印店、快递驿站也拉进来一起跑。

1、互联网洗衣

这几年我把互联网洗衣的各种模式和流程摸了个透，还做了些微创新。过去这类玩法都要靠京东顺丰上门取送，其实用顾客楼下的丰巢柜、快递代收点也能完成收衣和送衣，快递费省下一大截。

行业里很多洗衣店老板巴不得接外包代工的活，因为集中清洗能摊薄每件衣服的水电成本。我们的做法就是找到附近靠谱的洗衣店谈代工合作。整个服务链条是：中间商当接单入口，顾客下单后把衣服放到门店前台、丰巢柜，或者让洗衣店直接上门取；洗完再由洗衣店送回门店、丰巢柜或者送上门。售后问题由代工方负责，中间商只管接单、收钱，有店员就让店员兼着做客服。一部手机挂🛰️聊单就行，人在哪儿根本无所谓。

互联网洗衣的平均客单价100元，因为没有房租人工负担，定价比实体洗衣店便宜至少四成，卖得最好的是“三件五件任意洗”这类套餐。这些年实体洗衣店的单子被大量抢走，核心就是价格。洗衣家政这行的用户对价格极其敏感，消费降级的当下更明显。我们对每个店的最低期望只是每天顺手出几单，有人流加上价格优势，百分百做得到。

成本方面，洗涤代工费占40%-50%，中间商净利率有50%-60%。实测下来，有人店员帮推的店，连人流量最小的复印店每天也能成交3单左右；不主动推销就靠进店流量，一天2单左右。具体看数据：复印店单店每天洗衣销售额约200-300元，快递驿站、便利店、超市是最能出单的业态，日销售额能冲到500-800以上。

2、云家政

测下来家政的消费频率比洗衣低太多了。洗衣频率基本跟着洗澡走，有的顾客一个月能下四五次单。那为什么还要顺带卖保洁？因为洗衣和家政的客群高度重叠。洗衣是生活服务里频率最高、覆盖人群最广的品类，和家庭保洁的消费场景高度重合——周末大扫除时，很多人习惯衣服一起洗、卫生一起搞。所以家政保洁天生适合当搭售品。

云家政的打法是混进大量本地家政派单阿姨群。中间商同样是接单收钱的客服角色，接到单就派给群里的阿姨，阿姨抢单后上门干活，完工后中间商给阿姨结钱。

云家政客单价150-200元，保洁员人工成本占50%-70%，中间商净利率约30%-50%。我们跑出来的数据是：不同业态的单店家政订单，每天平均成交1单。顾客先来咨询洗衣、再搭售保洁的成交率大约有15%。

二、落地操作流程与实操难点

1、第一步是给老板和骨干店员做培训。我把洗衣家政的售前售后客服话术、行业知识、销售SOP全部教了一遍。这两个行业客服销售和沟通是最关键的环节，因为清洗和保洁效果没有统一标准，话术能力和销售经验直接决定转化率和售后纠纷数量。特别是洗衣，衣服磨损、污渍洗不掉这类问题，没有几年经验很容易接下有风险的单子然后赔钱退款。所以“哪些衣服风险高、不能接”的甄别能力是售前培训的重中之重。差不多学一周，老板们就能成为合格的洗衣家政客服，懂得主动避开风险客户。

2、学经验的同时，带着老板们去找同城洗衣代工店。难点是挑出洗涤技术过关、承接量足够的店，以及把代工价格谈到理想位置——这是利润的关键。新手一张嘴就被洗衣店老板看出外行，报价直接拿捏。我把谈判技巧和市场价区间也一并教了。一般来说，能承接100件代工量的洗衣店，就能喂饱30多单的日单量。选人最后要看的是洗衣店老板人品是否靠谱、清洗技术行不行，以及有没有团队协作意识和沟通力，这对中间商的识人眼光有一定要求。

3、家政前期最繁重的活在加同城派的群，需要花时间坚持，善于和保洁大姐们打交道，我这边有现成的客服话术手册可以直接用。

4、打磨服务流程：要和代工洗衣店敲定取送方式，一般一天集中取送一趟就行。家政流程简单得多，把客户信息和保洁人员对接明白即可。

三、具备什么条件的老板适合做？

我觉得下面几类人都是合适人选：

1、有良好的沟通能力、情绪稳定、脑子活络。

2、有门店、社区物业、高人流量窗口位置、民宿酒店、人流进出口这类资源，可以利用进店或路过的人流做转化。也可以去找有这些资源的地方谈合作，放个广告牌就行，大部分商家都有异业合作的意识。如果你能在高人流量位置放一个X展架、广告牌，印上客服🛰️二维码和电话，就能稳定出单——这点不接受反驳。这些年大家在小区的楼大厅、楼道里，常见装修、家政、搬家开锁的X展架广告，这就是刚需生活服务的获客优势：用户不认品牌，有人流就有咨询。

比如人流进出口、小区物业中心、电梯广告、小区宣传栏、街边底商窗口等位置都可以。

3、有本地客户🛰️私域的人。

4、本身就是做本地生活生意的老板。比如外卖店、本地电商，可以随外卖订单在包装里附上推广卡片。

5、店员沟通水平在线就能做好家政洗衣客服。因为顾客98%的问题都是同一批，照着话术手册复制粘贴，越做越熟。

客服坐哪儿完全无所谓。有人流或有私域，就能搞自助线上下单，客服线上完成服务，全程不接触顾客，线下只有代工洗衣店和保洁阿姨在跑。

四、可以卖的产品

洗衣板块：1、衣物 2、鞋靴 3、家纺窗帘 4、皮具洗护

家政板块：1、家庭保洁 2、家电清洗 3、除甲醛 4、收纳整理 5、家居清洗与抛光（沙发、地毯地板、床垫等） 6、企业开荒保洁 7、保姆月嫂（都是可外包的中间商生意）

8、搬家、开锁、通下水道等（同样都是可外包的中间商生意）
