# 230513 北京生财线下局：薇姐现场笔记

上周刚开完会，脑子还热乎赶紧落笔，不然过两天细节就糊了。

**1. 宋大范儿聊了下今年生财的线下玩法**
节奏会拉满。以后北京这边的线下不是只有一次见面，而是会常态化：定期沙龙、分享私塾、家宴聚餐、项目路演、私董会、共创会、联合发售……目的就一个，让人从线上头像变成真人。深度聊完，合作、捆绑、甚至一起创业的可能性才出来。河南、深圳、北京都希望能跑出标杆项目。我已经先报了组局官，先混脸熟再说。

**2. Start9527 解读 Web3 现状**
他觉得 web3 当下本质还是逐利，金融属性摆在那，博弈感强，有赢就有输，本质带着赌性。六月香港全面开放后，国家层面的背书会更清晰。自己因 FOMO 踏进去，最后成了 Flow 中国大使，所以他一直强调别指望运气眷顾新人。
他用做书店和出版的老经验，准备出本 web3 的书。关于进入门槛，他梳理得很清晰：门槛最低的是撸空投打新；再高点是 DeFi、套保；更高的是量化、工作室。核心是认知决定钱袋子，认知外的钱谁也抓不住。下一步谁都猜不准，得靠盘感，得真下场。
另外提了个个人产品 webgoing，团队分工在投研、开发、变现、K线这些方向。

**3. 驯龙师茏姐：赔了200万的女人现在在干嘛**
海报标题是《做废八个账号让我学会了什么》，现场她改成了《赔了200个的女人，她现在在干什么》。标题功力确实在线。
别人讲项目，她讲人生。听完全程停不下来。
大意是一个自称“傻白甜”的女人，30岁前对赚钱没概念，创业亏过、来生财学搞钱、折腾过一堆项目，最后总结出一条变现进阶链：劳动力变现 < 技术变现 < 信息变现 < 认知变现 < 资源变现。
后来她选择回家接班，做实体厂二代，跟一群江湖老狐狸斗智斗勇，现在在找电商合作伙伴。
她一共抛了三句话给我印象很深：把选择题做成是非题，是在不断创造选项；看似死局，主动出击常有转机；创业的本质是修自己。
人生还在路上，挺燃的。

**4. 水果小李哥：小白做水果社群团购怎么起步**
典型的生财风格，目标明确、只讲实操。他原本在腾讯做版权保护，现在转做水果电商。
引流核心在小红书，成交放在社群和快团团私域。他分享了几个点：
小红书直播正处流量红利期；做爆款笔记，选题比套路更重要；小红书现在0粉丝也能开店先跑起来，稳定到1万粉再交保证金。
供应链上他强调水果是非标品，一分钱一分货，买贵了吃点亏，买便宜了吃大亏。线下试过去超市快递获客，粉丝质量很差，不如把精力扎进小红书做精准粉。

**5. 临场圆桌答疑 + 宋姐生日火锅局**
晚上临时加了场宋姐生日局，8个人边吃火锅边聊。印象最深的是宋姐对 C 端 B 端的判断：C 端能做很大但难啃，B 端更香，天花板可能在几千万。她自己的目标是成为数字游民。
她也提醒做管理咨询时反复看到的合伙人坑，以及早期控制成本的重要性。没成本你就有试错时间，本质就是一个人的饭钱；一旦有固定成本，心理压力上来，试错窗口就被压缩。最后她一直鼓励大家干，她说不干就不会失败，干才有成功的可能。

线下见面的意义就是开始，你才刚认识一个人。比如当天刚认识的人，后来单独约了个咖啡，聊了整整五个小时。

这次只是拣了几件印象深的，现场的信息量远比笔记大，也加了不少新好友。
