# 闷声发财，抖音图文二创带货

闷声发财的抖音图文二创带货：不露脸、不拍视频，也能跑出百万月销？

最近挖到一个特别低调的玩法：抖音图文二创带货。不用直播，不用拍原创视频，也不需要费劲去混剪。核心操作就是找产品图，把主体抠出来，换一个干净好看的背景模板，然后用抖音“图文来了”的模式发出去，挂上小黄车就能等着卖货。这套流程熟了以后，处理一张图也就一两分钟，我身边有个同事，一个人就同时打理着十个这样的账号。![](img/57b74c742dd2f626d74b0c73203ce464.png)

你要说女装退货率高？人家走的是精选联盟，压根不压货，退再多也不影响赚钱，利润照样落袋。

还有人说这肯定靠投流。真不是。上个月我还没挂车，光靠橱窗和引导加微信成交，就卖了20万，一分钱推广费都没花。最近半个月，我开始在图文里直接挂车，同样是零投放。虽然还没跑出大爆款，但单账号一天最高也有五千多进账。按我以前做视频的经验来估，这要是出个爆款，单账号卖个小几万基本没跑。关键是，这还没开直播呢。我还出过好几个百万播放、甚至一个千万播放的图文视频——那种量级要是当时直接挂车，变现几十万上百万都很正常。

我们前后统计了大概百来个号，全部没开直播，也不投钱，纯靠图文挂车。单月营业额过十万的一大把，月销百万的也扒出来好几个。你想想，如果一个人手上握着十个、二十个这样的号呢？开头提到的那个账号，没直播就卖了一百多万，要是再配上直播，简直不敢想。

而且这个模式不只是服装行，饰品、零食、童装、鞋子，我都刷到过跑出结果的账号。更猛的是，有人把这种玩法做成了矩阵，规模大到超乎我想象，GMV也到了我难以估算的级别——月销几千万打底，真正闷声发大财的那种。
