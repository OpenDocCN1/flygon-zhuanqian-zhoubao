# 达人BD实操笔记：我从五谷磨房商务岗踩坑里提炼的干货



我是宝爷，在五谷磨房做商务的这几个月，几乎把能踩的坑都踩了一遍。今天把这些避坑经验整理出来，给大家参考。

#### 一、找达人一般都从哪几个渠道入手？

1. 直接看达人主页。很多有合作意向的达人都会把联系方式公开在简介里，你直接备注品牌名和合作诉求，对方感兴趣就会回。
2. 商务群聊。品牌方和达人方都常年混迹在各种商务社群里，里面能直接对上想找的资源。小侠那边就沉淀了不少人脉，有需求可以去问问，记得顺手发个小红包表达谢意。
3. 品牌方互推。和品类相近或竞品的品牌方聊一聊，互相推荐合作效果好的达人。也可以用飞瓜查一下对方历史优质的投放案例，再做资源置换，商务之间普遍都很nice。
4. 官方小二/机构团长联动。像五谷磨房这种大牌，和平台小二关系很铁，就能直接拉群对接，效率极高。形体类达人联系方式很难找时，通过机构或团长牵线也更容易打通。

#### 二、哪种建联方式更省时间？

1. 品牌力够硬的话，找官方小二牵线是最高效的。
2. 接下来是商务群和品牌互推，触达快且成功率可观。
3. 团长机构要慎选，靠谱的比例很低。我在五谷期间对接了30多个团长，真正能用的也就2-3个，必须建立自己的筛选标准。
4. 加达人主页留的🛰️，回复率最低，可能只有5%。一天别疯狂加几十个人，容易被🛰️风控，我就是这么吃过亏的。

#### 三、达人合作现状和模式

1. 合作形式主流就两种：坑位费+纯佣，以及纯佣。季框年框也有，但不多。达人只关心一件事，直播间能不能多赚钱，利益最大化。
2. 你要是头部品牌的爆款，达人基本会抢着上，因为货带人能让他们既拿钱又增粉。
3. 你要是网红款，受众面广、直播机制友好、佣金给得高，达人也会愿意全力推。
4. 你是白牌没知名度，产品质量过关、愿意给高佣和高坑位，也能找到愿意试水的达人。但现在大主播都很爱惜羽毛，选品卡得很严，比如贾乃亮的直播间，每个细节都要过。
5. 很多老板不理解为啥自家产品好达人不带，核心就一点：你的产品给不了达人利益最大化。

#### 四、合作避坑清单

1. 明星坑位基本都是坑。十个里九个亏。过气明星涌进抖音带货，播几场数据就崩，粉丝粘性差、在线造假多。花2万到10万坑位费，卖几单就没了，补播承诺永远在拖。记住：明星首播坑位别投。
2. 夸张承诺保投产的，越热闹越危险。平时对你爱答不理的达人突然来找你，大概率是来冲KPI要坑位费。有实力的达人根本不缺品，突然搭讪基本别投。
3. 热情中间商高概率不靠谱，一上来就给你报一长串头部达人名单。常见套路是签保量协议，比如100万框架要保ROI。最后要么是骗子公司，签完款就失联；要么是拿尾部达人凑数，拖着不退。假冒品牌商务骗坑位费的也常见，对方身份一定要核实。
4. 坑位费付了，直播间带不动。主播不熟产品、不会控节奏、粉丝粘性差，一场就几单。还有就是备好货等一天，对方临时说直播节奏不对、场观不稳、品太多、时间晚了、品上不了。头部直播间最常发生这种事，工厂等着发，商家干着急。
5. 别沉迷扶持没实力的腰尾部。转岗前两个月我就是这么干的，结果精力全耗光业绩惨淡。一个有实力的头部，顶得上百个没实力的腰尾部。投入时间差不多，产出天差地别。
6. 第一次合作优先谈纯佣，佣金高点也比坑位费安全。

#### 五、怎么挑到真正高产的达人？

1. 学会看数据。用飞瓜这类工具看达人的带货数据、粉丝画像、近期涨粉和成交类目是否匹配、数据趋势是否向上，再判断值不值得投。
2. 用竞品反推。看竞品品牌产出好的达人，比如五谷磨房会对标老金磨房，同品类带得好，通常带我们也差不到哪去。
3. 找垂直类主播。养生减脂类产品和形体账号配合最好，形体主播一场只带几款，会讲得细，产出高。缺点是佣金要求普遍很高。
4. 关注潜力日播达人。减脂和生活类账号很契合，日播达人佣金低配合度高，单场产出虽低但月累计很可观。比如王些黑这种不到100万粉的博主，一个月能做到300万+产出，比头部还猛。
5. 主攻头部为主稳定基本盘，一个月锁定几个头部基本业绩就稳了；同时少量培养潜力腰尾部，刚开始带货一场几千的就别浪费时间，精力有限。
6. 维护好官方小二和商务圈的人脉，建联效率会高很多。

#### 六、达人商务日常工作链条

1. 多渠道建联。
2. 发货盘给对方选品。
3. 提交产品推广机制。
4. 寄样、过品、敲定上播时间。
5. 建直播商品链接+准备手卡。
6. 和仓库对齐库存，和达人确认库存。
7. 跟播、复盘复盘。

#### 七、群友补充的实战技巧

1. 店铺基础数据没起来就去找达人，基本没人理。先把销量、评价、体验分和新手期打好。
2. 达人每天都在看蝉妈妈、快选品、飞瓜等工具。你可以先用一点坑位费找几个中腰部带，同时后台适度补销量让转化异常好看，这样更容易吸引其他达人主动来。
3. 真正的链接靠混圈。认识一个商务，他从冬姐跳到盈公主再到衣哥，每次换主播都会主动问我有没有品要上。这种关系是长期沉淀的结果。

说白了，商务是个综合能力要求极高的岗位，要随时在线、沟通强、抗压高、复盘快。我自己做了几个月才真懂不容易，希望这份方法论能帮大家少走弯路。
