# 一段走过12年的关系，靠的不是运气，而是持续提问
作者：龙哥

原文链接：[`www.yuque.com/for_lazy/thfiu8/utw6w6w0owcn046n`](https://www.yuque.com/for_lazy/thfiu8/utw6w6w0owcn046n)

作者 Shiqin 在 2023-05-22 发了一篇被加精的分享，至今已有202个赞。

我们从18岁开始谈恋爱，22岁步入婚姻，到现在同行12年，共度婚后8年。两人是大学同班的心理学专业同学，他去年入了赚钱，我是龙哥。

正因为都学过心理学，这十多年里我们从未放下对自我和彼此关系的探寻。甚至在结婚第五年，我们意外撞见了感情的“第二增长曲线”。借着520的节点，我们重新梳理了这12年的相处轨迹，也聊了对亲密关系和对方的真实想法。最终归纳出下面8个关键自问，分享出来供大家参考：

1. 你们是如何相识的？交往过程中，哪个瞬间至今让你印象深刻？
2. 当初你考虑了哪些因素，才决定和现在的对象结婚？
3. 你心中真正想要的亲密关系长什么样？
4. 你们在相处中遇到过哪些难题？又是如何一起化解的？这些经历如何改变了你们的关系？【⭐推荐】
5. 你怎么看待恋爱里的磨合期？你们当时是怎么熬过来的？【⭐推荐】
6. 到底是什么核心力量，能让一段关系稳稳地走远？
7. 你的另一半在哪些方面推动过你的个人成长？
8. 当你们出现分歧时，具体是怎么沟通、怎么达成共识的？
