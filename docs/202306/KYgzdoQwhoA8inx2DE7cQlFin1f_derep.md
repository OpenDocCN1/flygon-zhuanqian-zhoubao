# 创业粉经验分享（视频类项目拆解）
作者：龙哥

今天想跟大家聊聊我做“视频类项目拆解”引流创业粉的一些实战心得。先简单介绍一下自己：我是龙哥，20年入学的大学生，23年6月正式毕业。这几年一直在互联网上折腾，靠“小鱼”这个IP，三个月做到了30万的变现。坐标河南，我的核心思路就一句话：追求互联网上的高收益项目，用暴力方式引流，做个发烧友。

先说说我早年的经历吧。闲鱼无货源、螺旋起号矩阵，日收益能到2000；美女号全自动变现，单号一天也能跑1000；📕虚拟资源，一天600+。单人单号暴力引流300+，平均一天一个人能引200多个。那时候我也跟很多人一样，刚进社群一脸懵，天天埋头做项目，对引流不太上心。但后来认知提升了，我才彻底想明白一个道理：做项目，永远不如卖项目赚钱！

网赚项目五花八门，看得人眼花缭乱，但底层逻辑其实都是通的。很多项目对小白不太友好，所以大家总觉得自己被割韭菜。我的建议是，小白最好从虚拟资源类项目入手，上手快、不用垫资。另外，圈内老韭菜都知道，S粉是最后一条路，谁做都能做起来——只要跟着市场需求推产品就行。S粉全网割不完，毕竟每个正常男性都算S粉。

下面是我第一次全手写分享自己跑通的项目，有不妥的地方欢迎批评指正。真的很感激能进这个社群，也谢谢大家在我网创路上给过的所有帮助和指点！

# 一、思维转变：先蹲坑看数据

大约从22年开始，我有了做创业粉的意向，那时候时间也多，可以慢慢实操和观察。有一次送对象回宿舍，坐在学校摆渡车上刷抖音，偶然刷到一个项目拆解类的视频。

![](img/fc8930e1cbebf83b733a5dc311b67334.png)

说实话，第一眼的感觉是：剪辑麻烦、上手难度大。但我实在太想搞钱了，所以还是忍不住关注。我当时的付费意识还算比较高，因为我知道，热门又暴力的引流项目和付费往往是成正比的。带着这个认知，我决定先蹲坑观察他的数据，同时混进他的粉丝群，了解他的玩法。

# 二、撸起袖子自己干

## 1. 自学剪辑

这件事让我悟出一个道理：光看没用，得自己上手。好在那会儿时间确实多。别人上课的时候，我逃课在宿舍用电脑看B站学剪辑，每天还去了解互联网最新项目，自己写稿子、做视频。

效果嘛，可想而知——慢，而且做出来的东西很粗糙。后来看到有人用PPT做项目拆解，我开始模仿学习。归根结底，我发现自学效率太低太慢了。

## 2. 开始做手绘视频

当时拆解类视频主要两种：PPT模式和手绘模式。对比了一下稳定性，我个人觉得手绘更稳。然后就开始研究怎么做。跟很多同行交流后发现，有一款叫《美册》的软件特别适合做手绘视频，功能很全，大部分素材APP里都有。

（说实话，我是因为对手绘感兴趣才选它。实际上目前效果差不多，最吃的是综合能力：稿子、关键词、封面、内容。）

前期先洗稿子，现在更简单了，直接让ChatGPT帮忙写。写完之后可以用🛰️小程序《轻抖》查违禁词——免费，看个15秒广告就能用。有违禁词就规避掉。

![](img/3d98f8346a10d546576becaed40ac7bd.png)

### 音频生成

用美册的手绘功能，可以直接把文字转成音频。

![](img/1c50fb61f873e2e874ab7b49341ebd6f.png)

### 开始制作

音频自动生成后，软件会直接进入下一步。选16:9的比例。

![](img/0f687259b6ba9c2922d5af995ff412fe.png)

然后你会发现字幕太大了，点一下字幕，选个合适的大小，再点“应用字幕”——这样能保证整条视频的字幕大小统一。

![](img/2fb7fd774df0cd7971bfbb8d6414c624.png)

之后就简单了，靠想象力填画面就行。通过搜索元素来找到想要的素材，然后一句话一句话地配上相应画面，手绘效果直接呈现，完全不用额外设置。

![](img/e4bd56a77c8429eddcdd5e2d20fbe4b7.png)

## 3. 数据效果与反思

数据嘛，一般般。发了四条作品，三条五千多，一条两千多。中间我放弃了一段时间，后来又开始反思精进。

### 发现短视频SEO

跟同行聊天时发现，短视频平台已经成了很多人的“百度”。大家遇到问题会直接在平台上搜。这就是短视频SEO。我以前做项目拆解，标题就是照抄别人的，关键词排名自然上不去。

### 优化稿子

后来我开始自己写稿子，或者精进同行的稿子，不再原样照搬。

我们初步的计划是：我出项目，他去实操，然后带着一批低门槛的学生资源去变现。后来靠着好几个项目和管道收益，确实赚了一波。

## 2. 第二次拾起项目拆解

年后实习期，我没去上班，一直在做网创项目，顺便学剪辑、写稿子。临近毕业季，跟对象分手了，心情特别低落。但沉淀了一段时间之后我想通了：与其emo，不如想办法搞钱！

分手之后精力反而更集中了。四月初闲着没事，蹲坑的时候刷到热门项目，就写了一篇稿子，晚上自己剪了一条视频。

## 重点！！！

第二次用的是剪映，软件的操作逻辑和美册一模一样——根据音频填词，每句话对应一个画面。这里就不细说了，前面已经介绍得很清楚了。

核心要点是：搜索关键词、封面要吸睛、内容要给力！

项目弊端也很明显：必须坚持。不是每号都能爆，测试下来有的号前期流量不行，但只要持续发，有点基础流量，四条视频之内肯定会爆。前提就是满足上面三个硬性条件！

## 2. 对标同行，继续精进

后来我去对标同行的作品，发现他们基本都是两天发一条。除了付费投放之外，能让项目跑通并提升的一个关键就是：模仿同行的模式！

## 3. 平台推流情况

测试中发现，抖音和快手都有一个共同规律：比如上面这个号，第一条作品直接爆了，但当你继续发新作品时，第一条的流量还没推完，它会“吃掉”你新作品的流量。道理跟美女号是一样的。等第一条的流量推送完，平台才会继续推你最近发的作品。

那这段时间怎么办？继续发！不管推不推都要发——爆款视频就在下一条！

## 4. 变现思路

做项目拆解来的粉丝只有两种：

第一种：白嫖粉。
第二种：同行（想学你视频的制作方法）。

对白嫖粉，我们要做的就是朋友圈打造、晒收益图。他们看到自然会想上车。客单价可以放低一点，我现在定的就非常低，128或299——这个价位就是针对小白的。我也试过高客单价，但转化率低得离谱，一百个粉丝才转化2到5单，不划算，还是低客单价舒服。快手上的基本都是学生粉，具体怎么操作，相信很多大佬比我懂。

对同行粉我就不多说了，很好聊。直接把视频剪辑模式复制给他就行！

# 五、工具与项目总结

## 1. 工具清单

1. 美册、必剪、剪映，三选一，入门就行，操作没难度。其他剪辑软件也可以，但更推荐这三款，自带素材多，不用自己到处找。
2. 一部手机，最好手机电脑都有。
3. 魔音工坊（配音方面，其他软件也行，但我实测魔音工坊的热门配音比较有流量）。
4. ChatGPT（帮助写稿，可以说是无脑操作，但用不用影响也不大）。
5. 灵活的思维（要时刻关注网赚行业的最新项目或者冷门项目，拿来拆解）。

## 2. 项目总结

测试下来发现，并不是你发了就能爆。网赚这类项目多少有点玄学，有的号你发什么都能爆，有的号怎么发都没量。但我们也不要迷信玄学，项目拆解的核心在于坚持。前期可能看不到效果，但我的经验是：一定要有一个相对稳定的项目在背后支撑你坚持做下去。别把全部精力都砸进来，但也别一点不学。

只要把项目拆解跑通，日进100+创业粉完全没问题。还有很多玩法，做到日均200+也挺轻松的。

我目前在用的引流方式有：
1. 项目拆解。
2. 抖音、快手、📕截流（手动脚本都有，粉偏泛）。
3. 抖音上麦（沉淀粉）。
4. SEO（有自己的网站）。
5. 学生资源裂变。
6. 直播引流（测试中）。
7. 电商平台或热门平台图文引流（电商类比图文IP更容易沉淀）。

有些引流方式对小白不太友好，但视频类项目拆解绝对友好——不管小白还是老手都能上手。

针对目前的网创环境，入局永远不会晚。

## 项目弊端

- 需要耐心。做一个几分钟的视频并不快，我现在熟练了也要一个多小时（第一条爆款视频我做了快3个小时）。
- 想更暴力引流需要更多资源。快手号好办，一人能认证3个号，但粉的质量不如抖音。
- 号有基础流量就继续发；没基础流量就注销。注销几次还没流量，要想想是不是机器被锁了，这时候可以格式化手机，或者干脆买新手机。
