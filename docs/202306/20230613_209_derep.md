# 全网都在玩“AI 燕姿”？这份保姆级实操，带你复刻同款
作者：龙哥

这几天，AI 翻唱突然刷屏，最出圈的是“AI 燕姿”——用模型还原一位歌手的音色，再让她演唱任意歌曲。很多人看完直呼神奇，也想自己跑一遍。我亲测了整个流程，把心得整理成一篇保姆级实操攻略，今天分享给你。

这篇内容覆盖两大块：
- 从零到一做出 AI 燕姿的完整闭环；
- 音色模型的训练方法。

换句话说，你不仅能复刻网上热传的“AI 燕姿”，还能用同样的方法打造一个“AI 自己”——用你的声线去演唱任何想唱的歌。文章里的每一步都尽量讲细、讲透，纯大白话，不需要你有技术背景，按顺序操作就能成功。

更贴心的是，所有需要用到的软件、现成资源包，以及对应的预训练音色模型，我都已经统一整理好，传到了网盘，直接取用即可，省去四处找资源的麻烦。
