# 《抖音图文带货非常好做，小白，想做副业的朋友可以冲》

最近刷到盗坤分享的抖音图文二创带货，发现自己做的正是这个方向。没做出什么惊天动地的成绩，但整套流程已经跑通了——只要发图文视频，基本都能出单，有时候仅仅几百播放就有成交。所以想写点东西，给正在找项目、想做副业的朋友们打打气：图文带货，真的可以直接冲！门槛低、上手快，尤其适合刚入门的小白。

![](img/becb6ae7080816db6b28e42a7cc789a7.png)

抖音图文正处风口期，平台给了不少流量倾斜，而且图文投流已经悄悄进入内测阶段了。

# 为什么我劝你做图文？

1. **流量盘子大，更容易爆**：抖音比视频号、快手、小红书的用户体量都要大，投流算法精准又稳定，能放出去的流量很猛，竞争虽然激烈，但图文这条赛道，完全有机会弯道超车。

2. **制作成本低**：图文比视频简单太多了，一部手机，十来分钟就能搞定一条图文视频。新手剪视频随便都要半小时起步，而且现在传统的视频搬运、混剪打法正被平台重点打压，图文正好成了一个突破口。

3. **选品对了，出单快**：只要选品选得好，几百播放就能出单，这个效率很多混剪视频根本做不到。

# 抖音图文带货全流程拆解

## 第一步：账号准备

做图文带货，建议最好准备3到5个号。如果前期心里没底，那先用一个号跑通流程也行，能出第一单就是胜利。

挂车的前提是开通橱窗：1000粉每天能发2条挂车图文，3000粉以上每天能发5条。如果还没到1000粉，就先去涨粉再开通。至于涨粉方法，赚钱里已经有很多文章讲过了，这里就不展开。

## 第二步：怎么选品？

1. **跟同行学**：抖音搜话题 #图文掘金计划，看看点赞高的图文笔记都在带什么货，零售、花卉、饮料、服装、百货……各种品类都有。找到对标账号后，点进主页看他最近发得最频繁的品是什么——发得多，说明这个品出单效果不错。

## 选品的底层逻辑

说白了，选品要顺着市场的需求和供给走。比如春夏秋冬各自适合卖什么，逢年过节大家有什么消费需求？也可以看看最近什么卖得好，顺着它想有没有关联产品能一起卖。比如很多人家里养绿植，天热容易发黄，那绿植营养液是不是就有需求？这种深挖思路，能挖出不少机会。

## 选品避坑指南

1. 别在一棵树上吊死，大佬们都在说“多测品”。
2. 别选特别小众的品，受众太窄不好出单。
3. 做出来的图片一定要有视觉冲击力，这点可以参考小红书。

如果你测出一个品，几百播放就能出单，那说明这个品很有潜力。多账号的话就都发它，只有单账号也可以多发几遍，直到把这个品的流量吃完为止。

# 图文爆单的核心是什么？

我还没真正爆过单，但凭自己的体感来说，核心是**图片视觉**。文案倒是简单，抄爆款的改一改，甚至直接套用都行。

# 图片怎么做？

第一步：确定好品之后，去小红书、抖音、淘宝等任何你能想到的平台找图，存到手机里，用醒图或美图秀秀处理。

出单效果最好的图是1到3张，第二三张最好做成拼图，四宫格那种。

这里直接引用赚钱圈友@逍遥的方法，跟我自己用的差不多。

##### 单图去重法

举个例子，假设对标图长这样。

![](img/2b133eb4b4908567d74ba58f2b50d4b7.png)

我会先去小红书找类似的图片，导入美图秀秀。

![](img/798457bbcdf230f110e5a908b417addd.png)

再找一张被咬开的梨子图片，在美图秀秀里抠图（苹果手机可以直接在相册长按图片抠图），然后合成到背景底图上，一张带原创感的图片就出来了。

##### 拼图去重法

打开美图秀秀，点拼图。我一般用四张拼，这种拼图比较适合零食类，中老年向的汤包之类也常用。导入四张图后，点高级编辑，选无缝模式，再调融合度，图片位置和大小都可以自由调整，按好看的排版来换位置就行。

![](img/0d82e1eb97e959e25073c42f6bd813bd.png)

![](img/7656193c6b2b8974e25ba3896554a169.png)

![](img/f918135d82cc526989efc17aea2ef9d4.png)

调整好后，依然是加滤镜、贴纸、文字，一张拼图图文就做好了。

比起单图，拼图的同质化概率更低。

# 图文发出去没流量怎么办？

我刚开始就遇到过两篇没流量的笔记，大概率是图片去重不够。我的处理方式是把图片重新处理一下：放大、加贴纸、调色，等等。
