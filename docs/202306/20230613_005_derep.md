# 公司管理这件事，软硬都走不通

做公司，真的不是有门手艺就会了。它本质上是一场跟人的博弈，而人这东西，从来挑不出完美的公司。

说到带团队，我见过两种极端，都很要命。

一种是典型的大好人老板。公司开了十几年，愣是没主动辞退过一个员工。底下的人是挺乐的，老板人好啊。但代价也很明显，混日子的人一大堆，反正最后也不会被踢掉。好在有老板运气不错，踩中了风口，业绩长得快，问题就暂时被掩盖了。

另一种则是铁血派。严到让人窒息，甚至有人因为贪污受贿被送进去。手下人每天都提心吊胆，有点本事的待不久。老板什么都亲力亲为，连行政去超市买个水果都要报备。最后整个团队没人敢拍板，所有决策都卡在老板一个人身上，累死的是老板自己。

所以你会发现，管理从来不是非黑即白。它更像一个永远调不定的动态平衡。

因为只要人还在场，变量就是无穷的。制度再全，也封不住人心的花样。你不可能把公司做到无缝，只能在裂缝出现的地方不断打补丁，再调整，再打补丁。

这就像你手里只有两只手，却要同时抛接三个球。只能不停地丢一个、接一个，像个小丑一样保持运转，停不下来，也停不稳。

做老板，不能心软成习惯，也不能把人情味丢干净。很多事，最后都要落在具体问题具体看。

而且还有个残酷的真相：麻烦守恒。公司里你刚把A个坑填平，B个坑就冒出来了。问题永远在换个名字回来找你。
