# 别再只卖时间了，你一辈子能卖的时间真的不多
作者：龙哥

最近重读李笑来老师在《罗辑思维》上的那篇演讲，被一句话点醒：时间不是消耗品，是最顶级的生产资料。

赚钱的本质是生产。能真正创造财富的生产，需要三样东西凑齐：原材料、真实的市场需求，还有时间。因为所有生产都离不开知识，而知识的获取本身就是对时间的消耗。所以时间才是撬动一切的源头。

可现实是，大多数人根本没在生产，他们的模式很粗暴：直接把自己的时间切片卖掉。相当于把原材料原价出手。

这个生意看起来简单，算下来却很残酷。你一天能投入市场的个人时间也就 8 小时，一年里双休就有 108 天，再加上各种节假日。从 22 岁入职到 65 岁退休，扣掉病假事假算下来，一辈子能用来换钱的时间，大概只占你全部生命的十分之一左右。

十分之一。想靠出卖时间躺平，数学上就不成立。所以问题的关键从来不是多忙，而是单位时间的回报率有多高。

那怎么判断一个赚钱模式值不值得做？可以用四个时间成本来衡量：生产时间成本、再生产时间成本、学习时间成本、销售时间成本。四个成本加起来越低，模型越值钱，赚钱的性价比就越高。

拿奶茶店举例。一杯奶茶要 3 到 5 分钟做出，这就是生产成本。卖一杯做一杯，下一杯还得再花 3 到 5 分钟，这就是再生产成本。想开起来，前期要培训好几周，一年后才摸清经营规律，学习成本至少一年。卖得出去还得自己跑推广，这就是销售成本。四项成本全占，时间被牢牢锁死。

再看李佳琦。他的生产、再生产、学习成本几乎可以忽略，真正存在的只有销售时间成本。一场直播的复用度极高，时间杠杆一开，财富效率自然拉开差距。

我自己的写书也算一个样本。写一本书大概半年时间成本，且一次完成，之后十年都在卖，没有再生产成本。销售主要靠出版社扛，自己投入的销售时间很少。学习成本虽然存在，但写过一本后可以复用到下一本。只要量级够大，首印不是两千本那种一次性书，写书就是一个典型的低成本高复用模型。

李笑来画的这个时间成本模型，其实就是在逼我们做一件事：把能复制、能留存、边际成本趋近于零的东西做出来。书籍、内容、代码、课程、媒体，都是这个逻辑。一次投入，长期收租，睡觉也能产生现金流。

别再迷信日入月入的热闹。我们的时间账户是有限制的，出卖时间天花板低到透明。找到那个再生产时间成本趋近于零的方向，用杠杆把时间放出来，才是你这辈子真正能积累财富的密码。
