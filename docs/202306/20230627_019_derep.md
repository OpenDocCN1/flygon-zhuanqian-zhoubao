# 用ChatGPT写文章自动发博客？我搞了个自动化工具，亲测能跑！
作者：龙哥

最近我实践了一个脑洞：让GPT帮我干活——只需丢给它一个关键词，它就能自动生成标题、写文章，然后自动发布到WordPress博客上，妥妥地实现“自动化SEO+自动发布”一条龙。

目前这套工具已经能正常运转，当然还有很多功能等着慢慢迭代。代码我已经整理好放在文末，想要拿去二次开发的兄弟直接拿就行，不用客气。

技术选型用的是Java+Vue+PHP+WordPress这套组合。具体为啥这么搭配，我在正文里都写清楚了，有兴趣的可以直接抄作业。

先交代下我的背景：我是龙哥，00后，干Java开发也就两年，经验算不上丰富，就是个爱折腾的普通人。写这篇分享不容易，觉得有用的话给点个赞就满足了。

说句实在话，把这款程序继续做深，赚钱是板上钉钉的事，一年十几万的收入机会完全有可能。

详细的方案和过程我都同步到了飞书文档，链接放在文末。里面包括项目介绍、技术实现与选型，还有我踩过的那些坑（技术、网络、数据库、Linux、发布等方面都有），以及项目思路和拓展方向、源码运行方式、最终结论，内容还挺全。

评论区里也有小伙伴给了很不错的建议，比如加上自动获取封面图的功能——其实这个我已经做了，在PHP插件里写了解析适配，有需要的可以去翻翻代码。还有人眼尖指出最后一行有错别字，哈哈，我当时说转账也行，到家就去改。

总的来说，这套自动化+SEO的思路，就是想让大家从繁琐的重复劳动里解放出来——你只负责提供想法和关键词，剩下的交给程序。想玩转的朋友，源码见文末，直接拿走！
