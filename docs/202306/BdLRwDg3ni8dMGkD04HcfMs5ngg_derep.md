# 📕做塔罗，佛系测试也能月入过万



前阵子偶然刷到一个塔罗变现的玩法，抱着试试看的心态去复刻。结果操作不到一个月，半小时私占单价99元就成交了12单。📕的群里已经积累了三四百人，从群到🛰️的转化大概是5个人里能出来1到2个付费。更夸张的是，全部素材我只花了三个小时就把一周的量做完了。

![](img/c690d6a14fb0de6c01af6cede51dd6d4.png)

我自己对塔罗是一窍不通，后面找了一个懂的朋友来负责实际解读交付。如果你本身就会占卜，那这个赛道几乎是为你量身定做的。如果不会，也完全可以换一种交付方式，用AI占卜来完成服务闭环。

# 1.先拆解，再开干

找对标不是走马观花看看别人长什么样，而是要把账号从头到尾拆透：主页包装、内容样式、引流设计、🛰️话术、产品定价结构……全部盘清楚。建议至少研究10到20个账号，拆完你就知道这条路该怎么走了。这个拆解思路放到别的项目上也通用。我的拆解表也整理好了可以参考。

![](img/741319b2800e8021602fbaf16b5af959.png)

怎么高效找到对标：

1.最笨也最有效，直接在📕搜索【塔罗】，一页页点进去看。

2.用PC端的【后羿采集器】，把【塔罗】相关话题的链接丢进去智能抓取笔记，导出表格后按数据排序，优质内容一眼就出来了。

ps：📕的头像昵称一旦定下来，🛰️上也要保持一致，不能对不上。

# 3.内容生产

目前📕图文类的塔罗笔记，主要就两种表达方式。

## 1.状态解读类

### 内容呈现：

1.拍真实的塔罗牌实物照，抽牌后直接解读。

2.不用真牌，用风景照、水晶、饰品等氛围图来代替牌面，再做解读。

### 发布节奏：

1.一条笔记把抽牌和解读一次性发完。

2.把一个测试拆成两天发，第一天只放抽牌，第二天再放解读。

![](img/80d855bb12418137ef8ef6c28256e54a.png)

图1是实拍牌面，正反都有，抽牌解读一次给全。图2是用替代图，第一天发测试，第二天发结果。我最后选的是第二种，用非真牌的图片做测试，第二天再公布答案。原因很现实：

1.真牌拍照不美观，还要强行把解读和牌义对应，素材搜集和排版都费时间，我没那么多精力。

2.拆开发布会制造悬念，用户测完没结果会在评论区催更、要编号、甚至吐槽。📕的推荐机制很吃评论，互动越高流量越好。

## 2.笔记制作流程：

我不会算牌，所以所有文案都是直接照搬同行的。完全不改也照样有流量，用PPT做完一套模板，一个下午就能攒够一周的量。具体步骤如下：

1.打开WPS新建文档，把页面比例调成30:40。

2.去百度搜【塔罗背景】，挑一张喜欢的做底图，上面固定好字体样式，做好模板，后面直接填内容复制粘贴。

3.怎么搬运文字：把对标账号的笔记图片发到🛰️聊天里，对话框就能直接复制里面的文字，不用OCR。

![](img/58a7db443b189a1813cbdc19549425e9.png)

![](img/4475036a58d598728edd0b411d615c8b.png)

补充两点：

1.底图建议固定一个风格不要老换，主页才看起来统一。百度搜塔罗关键词能出来很多素材，用AI画一张也行。数据一直不行再换也不迟。

2.我把底图的饱和度压低了很多。大部分塔罗号都用浅色系，在📕瀑布流里，深色背景配亮色字会非常跳，点进来的概率更高。

## 3.发布方式：

我是一周的量一次性做完，用PC端定时发布。实测对数据没有负面影响。

# 引流设计

我的主要承接都在群里。用户先进群，再被钩子引导到🛰️。

路径：群曝光 → 用户进群 → 发钩子 → 加🛰️

### 群曝光点：

1.主页展示群聊，等账号有点热度后，可以在简介里加一句进群引导的话。

2.把群聊和笔记关联起来，这是最大的入口。群名字很关键。很多同行直接叫【私占进群】，我拆解时发现第二天才发答案的笔记下面，评论区全是骂博主鸽人的。于是我把群名改成了【进群提前解锁答案】，进群量立刻暴涨。

3.评论区置顶进群口令，同样写【进群提前解锁答案】。发完当天的测试笔记后，直接把第二天的答案先发到群里，既兑现承诺也不影响笔记发布。

### 群内钩子

我准备了一批塔罗学习资料作为诱饵，群里统一发放，想要资料或私占就加🛰️。资料不够就去同行那里扒，或者找市面上基础塔罗书籍的电子版。

# 私域承接

## 加好友话术

刚通过就问一句：你是来领资料还是来私占？领资料就直接发资料。私占就问测哪方面的需求，然后直接甩价格表。大部分来占卜的这几步就能成交了。跟进不下来的，后续靠朋友圈种草，大概率会回来。

## 朋友圈运营

朋友圈是决定要不要付费的关键承接页。用户加进来第一件事就是划你朋友圈。除了看同行怎么发，还可以从这几个角度发：

1.晒用户的好评反馈

2.分享你对塔罗的感悟

3.发点生活日常或情绪碎片

4.发你在“努力学习塔罗”的状态

这样既显得专业，又像个真实的人。赚钱里有很多朋友圈运营的干货，我就不展开了。

# 变现方式

1.一对一咨询变现，投入精力有限，赚不了大钱，但能产生素材发朋友圈。

2.卖塔罗培训课，这是真正吸金的主线，目前同行报价600到3000不等。

3.网盘拉新佣金，资料放夸克或百度网盘，提前申请拉新授权，新用户注册能拿到3元左右佣金，属于顺带收入。

4.卖能量水晶，成本几块钱的东西，赋能后能卖几百。

# 最后想说的话

这个项目我测试完就停了，一是我真的不懂也不喜欢那些情感占卜的话题，二是手上还有其他业务忙不过来。

如果你是真的会塔罗，这个项目完全可以长期做。核心是用户最终沉淀在你的私域里，不怕平台规则变。账号做起来后同步抖音、快手，未来新平台出来继续复制，流量就不会断。最香的还是做塔罗培训卖课。

虽然说没有18岁的姑娘年年有，但18岁的姑娘每年都有，而且很多工作好几年的女性也一直在算塔罗。我成交的客户里快一半是已工作的。人群远不止学生，而是覆盖18到30岁的女性。

有条件的话直接做课程，买几个同行的课来拆解，用自己的语言重新讲出来，从小白学习到引流变现，做成一套闭环。在📕搜塔罗教学，内容和需求都非常大。
