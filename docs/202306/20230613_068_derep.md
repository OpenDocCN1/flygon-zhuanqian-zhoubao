# 想开小店？先把这5个坑避开，倒闭概率能降一大截

很多人攒了十几万，省吃俭用甚至借贷，就冲着开店去，结果没做功课直接把钱砸进去。开半年撑不住，只能低价转手；转不出去就只能关门还债，再回去上班重新攒钱。这种事在头条、🧣和身边随处可见。

我的这些经验不是凭空来的。一方面自己对小生意一直感兴趣，家里和亲戚也做着小买卖，平常逛街我习惯看招牌、看陈列、看价签；另一方面也看了不少营销书。综合下来，开店前至少把下面5件事搞清楚。

**1. 别信热闹，要数人头**
选址再好听也要实地数。租下门面前，花一个星期蹲在门口，用步数器或者人工记数，把一天从早到晚路过的人数记下来。还要分出工作日和周末的人流差异，哪个时段是高峰。
一条街看起来很旺，但过条马路可能就是另一番景象。周一到周五人挤人，周末却门可罗雀的情况太常见了。笨是笨了点，但不数你就是盲投。

**2. 先问路要不要挖，别等开业就被断路**
我来自五线小城，亲眼见过修路修半年，街两边店全关门的惨状。数完人流后，去市政官网或规划部门查一下，未来有没有道路改造计划。查不到就打12345市长热线问清楚。
确定没修路再签合同更稳妥，最好在租赁条款里加一条：若因市政施工导致客流受损，房租可适度减免。不然路一挖开，你的生意就被直接埋了。

**3. 想开什么店，先去那家店里当三个月员工**
想开奶茶店，就先去奶茶店打工三个月。拿着别人的工资，用别人的店练手。真正赚钱吗？不赚钱是为什么？日常会碰到哪些毛病？客诉集中在哪？怎么处理？
老板教你，你零成本学经验。自己开的时候心里有谱，而不是两眼一抹黑从零开始交学费。

**4. 店名是给别人记的，不是给自己爽的**
起名的核心只有一个：让别人好记、好叫、好传播，降低找你的成本。不是为了彰显你多有文化、多有格调。
看小米、京东、天猫、百度、360，哪一个用生僻字了？反观现实里很多门店，自创的拗口名字，顾客记不住也说不出来，传播就断了。招牌名只要做两件事：第一眼让路人知道你卖什么，第二容易被记住和复述。

**5. 招牌要让人远远就看见**
招牌的功能不是艺术，是识别。颜色要扎眼，字体要清晰，红底白字这类看似土的配色，大街上反而最常见，因为它最有效。
另外夜晚必须亮。灯光一打开，传播半径立刻拉远。老远就能认出你是做什么的，才有路人拐进来。招牌就是你24小时不睡觉的揽客员。

把上面这5点做到位，不代表一定能赚大钱，但至少是开店的底线。连基础功课都不做，倒闭只是时间问题。非常喜欢跟同样钻研小生意的人交流，欢迎你在评论区聊聊你的看法。
