# ('分享一个小白也可以轻松跑通的抖音蓝海无人直播', (2, 24))

最近发现一个特别适合新手尝试的抖音赛道：情商课无人直播。我自己用三个账号实测了整整一个月，累计收益差不多一万出头。最关键的是，整个直播场景的搭建门槛低到超乎想象——无非就是一段录制好的音频，再配上一张动态图，就能直接开播。

很多人可能会担心录播内容会不会被平台判违规，说句实话，这种风险没法百分百规避。所以我在原帖里特意提醒过，最好不要挂小程序或者小黄车，这样安全系数会高一些。目前平台的审核力度还不算严，我这一个月下来也没遇到封号的情况。
