# 运营全靠大学生做到了赚钱拉新 Top5 的超详细拉新教程
作者：龙哥

你敢信？一个拉新项目，运营主力几乎全是在校大学生，最后竟冲进了赚钱拉新总榜前五！随后他们把这个过程写成了一篇1.7万字的长文，在龙哥盟直接被评为精华帖，拿到127个赞。

执笔人特别有意思：不是资深运营，不是文案老手，而是三位在校生，分别读大二、大二、大一。这篇长文的干货主体，也就是那1.7万字，几乎都由这几位年轻人完成；作者七小只负责了末尾一段个人结语。真是“后生可畏”。

故事背景也带点戏剧性。当时间来到3月18日，他们这边的二轮拉新刚拉开帷幕，七小就遇上了账号受限，炮爷和刀姐两位负责人也忙得脚不沾地，根本腾不出手来坐镇一线。于是这次行动的画风，变成了“负责人远程把方向+小助手们自己商量着执行”。当时不少人心里都犯嘀咕：这次怕是要凉了吧？结果却让人意外——小朋友们不仅稳稳接住了任务，还在实战中快速成长，一边踩坑一边修正，最后把整件事办得妥妥当当。

这场经历最终凝结成了【刀姐 X 七小 X 炮爷】战队的复盘贴，它既是战队的复盘记录，又是一套现成的拉新执行SOP。里面有不少实打实的坑位预警，能帮你避开同样的弯路；也记录了小助手们从犯错到迭代的真实成长线，读起来很有代入感。评论区更是被“太牛了”“优秀”刷屏。
