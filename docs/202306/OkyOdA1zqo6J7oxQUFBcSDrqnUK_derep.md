# 二、规则设计

裂变的本质是转介绍，要调动老用户的参与感，同时让活动与用户产生符号共鸣和利益共鸣。

符号共鸣是活动调性要贴合人群风格，利益共鸣是让用户真切感受到“赚到了”。

因此我并行了两套福利机制。

![](img/41877050e0d71af0b03c3457a6612bba.png)

福利一：情人节周期内，每位群友可免费邀请一位自己的CP加入，共享社群全年权益。

福利二：情人节周期内，两人以CP名义同时入群，免单一人费用。

说明：CP定义放宽，不限情侣，可是闺蜜、挚友、亲人、搭档。

两套机制配合起来很精妙：

1、福利一本质是100% CPS，极限一换一。受梁靠谱的“会分钱才赚得到钱，进四出六，增量思维”启发，我平时群内CPS是50%，转介绍很好。但节日放出100% CPS，并冠以CP名义，会制造“不拉就亏”的紧迫感，强力推动用户在窗口期行动。

2、福利二本质是二人拼团一人免单，但加上CP叙事，就从普通团购升级为有浪漫溢价的仪式感团购，价值感完全不同。

3、单独做福利二，老用户会觉得自己之前买贵了，伤害权益；单独做福利一，只能内循环，无法破圈。所以必须双轨并行。很多节日促销只顾拉新，伤害老客口碑，导致高客单转化率下滑，这点一定要避开。

4、把CP概念泛化，能最大化参与面。不是人人都有恋人，但人人都有可共鸣的CP。这次有人带老公老婆，有人带兄弟姐妹，有人带闺蜜父母团队合伙人。泛化定义激活了符号认同感。

有认同有利益，这场裂变自然顺滑。
