# 6000个🛰️好友躺着不动？把沉默名单变成报名名单，你得先把这几层窗户纸捅破

恭喜你，已经把6000个人拉进🛰️了。对很多人来说这就是第一步，也是最后一步。朋友圈发着发着就没声了，感觉像是把课放在门口等别人自己来拣。别急，报名人数上不去，问题通常不在课程好不好，而在你对这6000个人的认知还停留在“潜在客户”这个标签上。

先说个残酷的清醒剂。

**第一，别把好友列表当成客源池。** 时间会让关系衰减，人在列表里待得久了，要么业务已经没了，要么热情已经凉了。这是一种影响力的自然损耗，拦不住。6000人里面，能动的可能只剩一小撮。

**第二，回想一下他们是怎么进来的。** 是在什么场景下加上你的？是内容吸引、活动现场、演讲、直播间，还是加群后顺带留的？有没有跨过那道信任的门槛？有没有发生过付费交易？有没有做过一次真正的情绪服务，比如你认真帮他解答过一个问题？没有这些铺垫，朋友圈再勤也只是单向广播。

**第三，承认当下环境。** 知识付费这两年不算好做，说黄昏可能夸张，但用户买课的信心在掉，信任的门槛在抬高。这不是你一个人的问题，是大盘情绪，需要你调整心态，别指望一发朋友圈就能收割。

**第四，工作号就别谈感情。** 一句话记牢：如果一个人在你的工作号里不能为你产生价值，那他对你来说就没有价值。听起来刺耳，但有效。你可以持续触达、持续营销，直到他选择拉黑为止。反正不是朋友，不掏钱，留着纪念吗？

到这里，假设你的课程交付是真的过硬，学员口碑也不错。那剩下的就是把转化做出来。

别指望朋友圈被动等。最好的抓手是直播和群直播，而且要做成可复制的流程。

**方案 A：快闪群直播。**  
先做一张让人手机上不用放大就能看清的海报。一图说清：你是谁、讲什么、听完能得到什么。利益点要一眼抓住。  
提前预告今晚八点开播，进快闪群，同步用朋友圈、🛰️群挨个提醒。  
群里全程禁言，你用图文直播的方式讲。案例要晒、后台数据要秀，情绪要拉满。金句要到位：有手就能做，你也可以。  
讲完立刻由托在群里丢一句：怎么报名？主理人马上跟一段标准话术+付款码。然后直接解散群。  
解散之后聊天记录还在，所有内容都能回翻，钩子二维码一直挂在那里。很多人不会在群里当场听，反而会等群解散后倒回去看。

**方案 B：常规直播间。**  
海报一样要漂亮，流程要固定。自己人提前准备好问题，20分钟一个提问循环。用飞书妙记记录全过程，回来就迭代话术优化套路。直播结束后的30分钟是第二波促单黄金期，截图、托、催单话术齐上阵。  
下播时在快闪群里留一句收尾语，然后解散收尾。

很多朋友会问，为什么一定要快闪群？因为可控。禁言避免了乱场，讲完即解散避免了后续闲聊稀释价值，解散后的记录成了自动播放的回放，钩子一直在线。而且直接私发信息转化率远不如一个有场景、有见证的群里现场。

海报要漂亮，不是指颜值，是阅读体验。一图概之，手机上看得清，信息层级清晰：我是谁、讲什么、你能得到什么。配色和排版是学问，看到好看的就存下来，日后复用。

你已经有6000个人在列表里了，别再让他们继续“躺平”。先筛出还能动的人，再用直播制造一次高密度信任场景，把口碑变成报名。核心就这一步。
