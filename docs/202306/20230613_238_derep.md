# Web3 新手想早点上手？先别急着 All in，跟这条路走

距离《从零开始读懂 Web3》系列目标还剩 23 篇原创，这一篇先把路打通。

我是 龙哥，一个全身心扑在 Web3 上的实践者，《从零开始读懂 Web3》的项目统筹者，也是龙哥盟 Web3 小航海的三期教练。现在我在运营一个专门服务刚入圈伙伴的实战型社群 Web3Going 新手实战营。

为了让之前在龙哥盟带小航海的经验能系统化延续，我把去年十二月那批教学内容重新整理公开。非常感谢龙哥老师、静伟老师和小霸王老师的扶持，我的目标很明确：在龙哥盟生态里，做出一个真正能把新手带进 Web3 赛道的人。

为什么敢这么说？因为已经验证过。两届 Web3 小航海加上两届 Web3Going 新手实战营的复盘反馈里，参与者普遍反映上手更快、迷茫变少、执行更有方向。如果你正卡在入圈第一步，这套梳理对你应该很有参考价值。
