# 认知觉醒是开始赚钱的第一步
作者：龙哥

你有没有想过，为什么有些人拼命努力却赚不到钱？课代表jime的故事告诉我：赚钱这件事，起点不是技术，不是资源，而是认知的觉醒。

jime在5月11日加入龙哥盟，很快写出了ChatGPT细分行业落地应用的精华帖，风向标也中标，还参加了📕、GPT+自媒体、个人优势挖掘等航海，连续两天三个航海日志被评为精选。很多人问他怎么做到的，他的回答很简单：用心，总会被看见。

真正让他改变的，是个人优势挖掘航海。他是因为靠谱老师的一篇文章《一个工具和两个贵人，让我从人缘极差的农村孩子，逆袭成赚钱拉新第一名的IP》才报的名。做完优势测试，结果很意外：他当了七八年婚礼主持人，但“取悦”和“沟通”竟然排在最后。也就是说，这些年他一直在硬补自己的短板。

而排在前三的，是“学习”“思维”“成就”。jime说，这才是他从2月进入副业圈，4个月变现10万的根本原因——他在无形中把自己的优势用对了地方。而一切改变，都始于认知觉醒，之后执行力才真正跟上。

他把这段觉醒之旅拆成五个关键点：对钱的认知、有钱人的认知、去除低认知、重新理解钱、不要节省时间。每一条都值得细品。

评论区里有人感叹：“钱不是拥有的东西，而是交换的价值。”也有人说：“做事情时，你是在积累资源，还是在消耗资源？”这两句话，其实就是认知觉醒的最好注脚。

想赚钱，先别急着学技巧，先问问自己：你的认知，醒了吗？
