# 《喜欢发一些短思考，大家对这个怎么理解的？》
作者：龙哥

你是不是也见过这种状态？有些人不爱写长篇大论，却随时随地用几句话记录自己的想法。最近刷到一个帖子，发帖人说自己“平时很喜欢把思考浓缩成简短几句话发出来，想问问大家是怎么看待这件事的？![](img/d8f4bf3a52e91b975a206707f3318ed9.png)”

底下有条评论获得认同：“人生没有白费的努力，落下的每一步都会有回响。可能当下觉得派不上用场，但将来某个时刻，这些零散的经历会自己汇成一条清晰的路。”发帖人也回了一句：“说得没错，经历多了，经验自然就越攒越多。”

我很喜欢这种态度。那些临时起意的念头、随手写下的感悟，看起来不起眼，却都在为未来积蓄能量。它们像一颗颗种子，静静埋在土里，等到合适的时机，就会长成你意想不到的风景。别再犹豫了，想写就写吧，每一次思考都在悄悄塑造更好的你。
