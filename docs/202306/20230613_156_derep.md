# 闲鱼二手书，如何让买家在众多同行当中选择你店铺购买？

闲鱼二手书为何总被同行截胡？看完这8个发布细节，你的链接也能被疯抢

你有没有发现，同样在闲鱼卖二手书，有人轻轻松松出单，有人挂了好久无人问津？区别往往不在书本身，而在发布时的那些小心思。买家在成千上万个链接里做决定，靠的就是主图、副图、标题、文案、价格、标签、地区、圈子这8个细节。把这8项打磨好，你的书被选中的概率自然会大涨。

一、主图：决定第一眼的生死

买家划到你的链接，第一眼看到的只有主图。在闲鱼，主图好不好，直接决定了点击量，进而决定出单量。电商行业有句话，“会卖货的人，其实是在卖主图”。你看服装类目，同一件衣服，漂亮模特穿上，点击率飙升；换成普通中老年人穿上，大家连看的欲望都没有。这就是人的本能，卖书也一样。而且闲鱼多是用实拍图，书还是那本书，角度不对，观感不好，买家就直接忽略了。

两种主图最伤人：
一种是画面塞得太满。整张图只看到一本书，没有任何背景来衬托，看久了都不知道该看哪里，反而等于没有亮点。![](img/5a877d6e07ce747c8cbb414bf95d4404.png)![](img/9449c090be72731a5428027c3c0ec9ac.png)
另一种是优点没有展示出来。比如书的封面有插画、有醒目标题，它天然就是最吸睛的部分，你却拍个背面，或者选个奇怪角度，等于把最大的卖点藏起来了。主图的使命，就是把书最迷人的那一面完完全全亮出来。![](img/29133ae851ddfecd2cd34a54e3f2a2b4.png)![](img/7295024a5378887f12d7ca2aec5ae44d.png)

什么样的主图容易爆款？很简单：四平八稳、干净整齐，让人一眼舒服，这就是最常见的“安全牌”。

另外，很多人不知道闲鱼币折扣还有一个隐藏玩法——可以把“想要数”遮住。打个比方，某个链接想要数1264个，浏览数8873个，看起来是爆款，但列表页上却看不到想要数，非要点进去才显示。这就是闲鱼币折扣在起作用。新链接还没什么销量的时候，你可以故意用折扣把想要数藏起来，买家看不到销量，就不会因为“没人买”而划走。只要他点进来，你的链接就多一次数据加权，点击越多人气越旺。等订单攒到几百个，再把折扣关掉，把销量亮出来，这时候就是用从众心理给链接加分了。![](img/118f20ee7d770879acf98e903e5287f2.png)

假如你卖的是套装，比如一个作者的三本书，不要只拍其中一本的封面，最好把三本都放进画面里，套装感一下就出来了。单拍一本，特点会在画面里被弱化。![](img/6efbaac1978d82dc7b62a39ebc2bf1f9.png)![](img/93e43cd91b10ee78b7a210d1d866d2a6.png)![](img/f7094100311e9c35f79859295bc1141a.png)
如果走的是杂货铺路线，书很杂，那就干脆拍一堆书堆积在一起的实拍图，书越多越像山，买家反而会觉得你家书多、实力强、价格应该也不贵。![](img/ee352783bc9b71155247d9a0400fce85.png)

主图这块能展开的还有很多，最简单的方法就是去拆解同行的爆款主图，看他们的构图、背景和角度，持续模仿优化。

二、副图：促进成交的临门一脚

主图负责把人吸引来，副图就负责真正打动他。副图可以看成主图的说明书，用一些细节实拍去展示书的内页、成色、亮点，让买家越看越放心。副图最好和主图来自同一组照片，风格统一，信任感更强。![](img/71fe0b01a50a635bbffd1eb780df6f25.png)

三、标题：既要被人搜到，也要让人心动

标题有两个功能：一是堆高频搜索词，让买家能搜到你；二是在开头制造“词眼”，比如“精装正版”“全新包邮”“亏本处理”这类词，一下子戳中买家爱捡漏的心理。闲鱼上大多数人都在等待“捡漏”的感觉，你要做的就是让他觉得在你这儿占到便宜了。一旦有了这种心理，同行再多，他也会先点你。![](img/e10337f86e58725746c5249917893d7d.png)![](img/6422e14faee2cf958dae17b1c8256f1a.png)![](img/32820cc9ee50103438b94ce3a3e4ba56.png)
比如开头直接甩出来：
【二手价甩卖】【全新包邮】【限时9.9】

四、文案：给买家一个下单的理由

文案的核心是把人留住，让看了主图点进来的买家产生购买欲。技巧是：在文案开头写清楚你的出手理由。比如“实体店合伙人撤股，经营不下去，需要资金周转，部分书籍低价亏本处理”；再比如“我参加了龙哥盟的二手书航海，教练带我们一起赚钱，你下单后我从孔夫子或拼多多填你的地址发货”。同样是卖书，理由一说，效果完全不一样。其余图书介绍类的内容，直接参考优秀同行也完全OK。

五、价格：最实在的硬武器

价格比任何技巧都更直接粗暴。仔细看那些“想要”特别多的链接，标价都低得诱人。那未必是真实成交价，而是低价钩子。但乱标低价有风险，容易被判违规。稳妥的做法是：文案里写清楚有精装版和简装版，价格按简装版标，既合规又能吸引点击；或者标一个低价，再用运费补足差价。低价引流能快速把流量做起来，缺点就是会招来一批只图便宜、不太精准的买家。

六、标签：突出图片细节的小助手

标签可以直接写在图片上，把图中最亮眼的地方标出来。比如书很新，就打个“全新”标签，让优点更直接。标签里还可以放关键词，顺带辅助搜索，多一条曝光入口。

七、地区：大城市流量更猛

人口多的大城市，流量天然更大。发布时尽量选在发货地附近的大城市，既能吃到流量红利，又不影响发货速度。

八、圈子：近在眼前的免费流量池

闲鱼首页“会玩”板块里，可以加入书籍、学习相关的圈子。发布时把宝贝同步到这些圈子里，就能多蹭一批精准流量。

这8个点前重后轻，前面的主图、副图、标题、文案尤其值得反复打磨。把发布时的细节做到位，成交率自然跟着涨。有人问货源和主图去哪搞，顺便再说一句：货源可以关注闲鱼航海；优质的主图、副图素材，去京东、淘宝、拼多多、孔夫子的评价区里找，一抓一大把。
