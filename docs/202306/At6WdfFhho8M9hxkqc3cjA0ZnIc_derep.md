# 靠AI一周写出两篇10万+情感文，我总结了一份“不踩坑”指南

如果一个月前有人跟我说，AI能帮我写出十万加的公众号情感文，我一定觉得他在开玩笑。但事实是：7天，两篇，全爆了。用的就是GPT，没烧钱、没买量。

先自我介绍一下，我是惠惠。之前主要写百家号和头条，今年4月开始尝试用GPT写情感类文章。我平时是个很典型的社恐加懒人，习惯一个人闷头做事。这次是被朋友推着才愿意出来讲的。以前我总觉得单打独斗最利索，现在慢慢想明白了：一个人可以走得快，一群人才能走得远。

这次分享不整虚的。我会把这一路踩过的坑、试出的方法都交代清楚，主要围绕四件事：题材从哪来、标题怎么起、AI稿子怎么改、没等来推荐怎么办。

### 第一关：写什么？——光坐电脑前是想不出选题的

我最初的状态：文档开一上午，一个字不出来。不是懒，是真不知道写啥；知道写啥了，又不知道去哪找；找到一篇了，还是不会用。素材库搭了，等于没搭；易撰这类工具和其他平台我翻来覆去地找素材，辛苦写完发布，后台一看，阅读量：6。

后来我采取的办法，说简单也很简单——让微信替我找题。

我手动关注了五到十个情感类公众号，平时刷一刷她们更新的文章，让系统知道我对这类内容感兴趣。过段时间再去看订阅号消息，往下划拉，看一看那一栏就会自动给我推满情感类爆文。十几篇起步，我在里面挑合适的。

![](img/5910cbd5cbde99b600f1567a70c6a56f.png)

挑也是有标准的，不是随便拿一篇就动笔。先看标题能不能勾住我；能勾住就点进去，拉到最底部看阅读数据。我一般只挑5天以内、阅读量5万以上的爆文，再用它的题材去写。为什么要盯着大爆文？因为能被市场验证过的题材，跟着写基本不会踩雷，起跑就有几千阅读保底，状态好直接冲5万、10万。同一时期能一起火起来的故事，本质上都是同一类情绪换了层皮。如果参考的文章只有一万阅读，说明这波热度本身天花板不高，你花同样力气去写，也很难有什么水花。

另外，每次写过的题材我都会顺手存进自己的素材库。

![](img/05b75bbac11285b25614c25a7e24f7f2.png)

但这里我想说个经验：素材库别急着用。至少先看完100篇情感文章，再来自由组合里面的内容，这样拼出来的题才不容易散。素材库具体怎么搭，航海课小女子老师那套方案非常实用，我就是照着做的。

### 第二关：标题怎么起？——半小时憋一个，点开率还感人

起标题曾经是我最痛苦的事。憋半小时是起步，最后起的标题自己都不想点进去。

现在我一般用两个土办法。

第一个：交给GPT。把一句现成的话丢给它，让它出标题。比如这句：“带父亲去城里看病，去上海姑姑家暂住一晚，这一晚，让我后悔终身。”发给GPT让它改写，再手动加个年龄、换个称呼，一条能打的标题就有了：“带父亲去城里就医，去上海姨妈家短暂居住，这一晚，成了我终身的遗憾。”

![](img/43b8365ed98485a40d58a1602bcf5ae4.png)

第二个：找微信搜一搜帮忙。把原始标题粘贴到搜索框里，页面会跳出大量同款标题和关键词。我要做的很简单：把最扎眼的词挑出来，重新拼一拼。同样那句话，搬个城市、换个说法，就成了：“带父亲去北京看病，到北京姑姑家住了一宿，这一晚让我后悔了半辈子！”

![](img/6757ab75de4ae11d5fe0bdcd863fd60e.png)

实在拼不出来时，就照抄关键词，但记得加年龄、改称呼、换地区。比如姑姑换成姨妈、姑妈、小姨，城市换成北京、上海、广州，标题立马就有代入感了。搜索的时候还会有意外收获：有时会刷到另一个狗血十足的十万加故事，顺手把素材也攒下了。我平时起标题，两个方法经常轮着用。

### 第三关：稿子怎么改？——AI写出来的东西，可不能直接用

我最开始也一样，一篇稿子用GPT磨了两个小时，出来的质量还没有自己手写得顺。要么字数不够，要么记流水账，要么故事假得没法看。

字数不够，两个急救包：

· 复制没写完那段，在后面补一句“这段没写完，继续写”，它一般就会接着往下写。

· 让它扩写。指令里带上关键词：具体细节、对话、动作和神态描写、情绪。把要扩写的内容贴上去，它会给你补出一大段。

稿子寡淡、像流水账怎么办？我把自己十万加爆文里的一段截出来当样本对比，发现这类文的骨架其实非常统一：语言描写、心理描写、动作神态描写，句子全是大白话，情绪要顶起来，语气得像真人在聊天。

![](img/028d1fbfcff0fa431e2a4aaaee17b6b7.png)

把这些要素变成指令发给GPT，反复练习，它的输出会越来越顺。记住一个心法：GPT只是个工具，真正起作用的是你手里那本说明书——指令写得越精准，它交出来的东西越能用。

还有一个特别常见的坑：GPT写出来的故事，总有一股“外国伦理剧”的味道。它确实不大懂中国式家庭里的家长里短，需要你来当老师。想教它，你自己心里先要有底。我前期把50篇情感爆文从头到尾看了一遍，把故事结构摸清楚了，再回头去指正它；只要它写得不对，我就让它改、给它新指令、反复训练，慢慢它就接地气了。

说句掏心窝的话：我第一次拿标题去喂它时，根本不知道它会编出个什么故事。我心里甚至在犯嘀咕：故事里的人到底折腾了些啥？反转会不会很离谱？如果你也有这种感觉，说明你看的文章还不够，心里连个故事大纲都没有——你自己都没谱，它还怎么写得出谱呢？下面这条就是我让它改大纲的指令：

### 第四关：什么时候进池？——急，是最没用的动作

我加了不少GPT写作群，经常看到有人说：日更一个月了，平台怎么还没给我流量？

我自己的情况是：同时开了5个号，10天之内全部进了流量池。但要注意，这5个号的标题风格其实都差不多，进池的速度却完全不一样——有的3天就被捞出，有的硬撑到第9天才开始有量。说白了，这就是概率问题。有些因素你控制不了，急也没用，不如把注意力放到自己能把控的地方去，比如稿子本身还能再抠点什么出来。

想研究冷启动的，可以去看5月30日Adrian老师分享的那篇文章。

没拿到推荐的号，我还有一个笨办法：拿自己的稿子跟同类型十万加爆文做1比1拆解。主人公是什么时候出场的？第一个挫折安放在哪里？第二个挫折又安排在哪个位置？标题里埋下的悬念，到底第几段才揭开？逐条摘出来比对，找出自己欠缺的环节，再回头优化。看着自己的文章一点点变好，那个过程本身就是一种成就感。努力如果能看到回响，人就不会慌。
