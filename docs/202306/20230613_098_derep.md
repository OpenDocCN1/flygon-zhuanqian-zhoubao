# 男人这辈子，基本都系在工作上

失业这件事，现在太扎眼，也太敏感。前阵子我随口泼了点冷水，发出去就完了。

可这事儿不能太轻飘。想把事业这根筋抽出来讲清楚，再把自己的经历拌进去，让大家看得见里面的逻辑和人性。

每个人都想把自己过得更好，别当loser。看这篇东西的唯一目的，就是这个。我没法保证每个人看完都能逆袭，但至少能保证一件事：看过的人，比没看过的人更知道自己卡在哪，以及该怎么破。

我愿意对你负责，把话说明白，别把自己活成失业那批人。今天你点进来、看下去这个动作本身，就已经是优势了。因为你已经在关注自己的事业了。剩下的，就是帮你把关注变成真正能用的认知。

说到职场，总结成一句话：就是做事。

有人忙活一辈子，看着回本没理过。明明每件小事都动脑子、都尽责，却多年没被看见。开始还能安慰自己，量变会质变；时间久了，预期上去了，回馈没跟上，才开始琢磨到底哪出了岔子。

**第一层，做事。把事做好，拿出专业。**

刚入行时我就是这种人。对工作极度上心，绝不摸鱼。第一份工作在新浪，我甚至要求自己别看新闻，怕一不小心就把时间耗没了。

第一年就赶上裁员。我一个共事六年的同事主动提离职，老板私下跟我说，那个人其实可以申请一个裁员名额，既不影响下一份工作履历，还能拿一笔N+1的补偿。那时两个人之间缺乏信任，就错过了一次利益最大化的机会。

很多年后复盘，我自己也是在快手那段，老板明摆着告诉我要满足他的诉求、给他想要的价值，我却总觉得要对公司负责，只要自己全身心投入，就没人能挑错。结果屡屡碰壁。

回头看，自己工作最顺的那段时间，并不是因为我做得多好，而是跟老板建立了足够的信任。创业公司，老板信任我，把他手里的项目直接交给我，我接了下来。我们之间形成了默契，但我的工作心态始终没变：一心只做事。

正因为没搞明白当时为什么顺，后来摔了跟头也不认为是我自己的问题。以前也这么干过啊，怎么这次就不行了。

本质是，我不适合走管理线。高管的核心不是你做了多少事，而是你能否对准老板的价值需求，把自己放到他的利益版图里，让他觉得你是自己人。

**第二层，为老板做事。搞清楚为谁干，他认不认你。**

这是大多数人保命的必修课。你要看懂公司的利益链是怎么串起来的。

CEO找高管，是补短板把业务盘活；高管找经理，是要有人能落地结果；经理找员工，是把事情拆细有人兜底。

每个层级的目标都不一样，唯一相近的是，都想让这份工作更稳。所以你要想活得踏实，就得弄明白你老板到底在为啥拼。

有洁癖的人很难接受，工作不只是工作，还要配合老板的需求和情绪价值。但你的岗位能存在，第一前提就是依赖老板。老板再不对，有些事再不合用户利益，你也无法否认他为自己活下去的挣扎。要是你的存在帮不到他的目标，你这个位置本身就没价值了。

我在这上面交的学费最多。之前准备了半年多融资创业没成。一个老投资人见我时说：你上进、业务理解力在线，但看不到你想赚钱的劲儿，也看不到你能给我带来什么。

说白了就是个利益问题。很多人待在良善的环境太久，连老师偏爱成绩好的都觉得不公平，更别说理解职场上“好好做事为什么没人帮”。

现实里，最底层的价值就是利益。我们非亲非故，不用用人品道德绑架彼此，能长期配合的前提是利益对齐。所以弄清楚服务对象想要什么，特别重要。上班时，你服务的就是老板，搞清他的需求是顺理成章。

明白需求只是迈出第一步。更关键的是，变成他政治生命里不可或缺的战斗力。你若可以被轻易替代，再有人情也是一刀的事。

弄懂老板要什么，下一步是成为他身边离不开的人。这个阶段要卷，但卷得有方向。你的第一层专业能力要开始定向发挥。

老板是销售出身，你的数据分析强，你就值钱。老板是技术出身，商业化弱，你的商业化能力就是他的补丁。老板管得粗，你的精细化执行和人事把控就是他的定心丸。

可老板不一定稳定，你的能力也未必在他那里最吃香。所以迟早要进入第三层。

**第三层，为自己做事。**

别把命交给别人。你选的大哥不一定靠谱，他也可能被干掉。你说要跟定他，太天真了。就像第一层你抗拒去搞懂大哥要什么一样，你现在也抗拒把命运握在自己手里。

树挪死，人挪活。人要挪一挪，是要给自己找更好的出路。你看不清自己想要什么，一味只满足老板，最后老板走下坡路，你跟着一起沉。

这个阶段的“为自己做事”，跟第一层“把事做好”是两回事。第一层做好是目的，第三层做好只是手段。你的目的更清晰：做出自己的事业，赚更多钱，养活自己的人。把事情做到极致，只是一个工具。

到了一定阶段，你就该有为自己搏一把的自觉。因为你的阅历、资源和眼界，已经很难再靠一个大哥给你一条现成的路。你得自己去闯，去独立认识这个社会，搭起自己的班子。

那时你考虑的不再是“老板要什么”，而是“怎么操盘全局”。能把一个摊子撑起来，带团队拿结果，保证自己在生态链里活下去。能到这一步的人很少。

但到了这里还不够。我认识的一些准上市公司决策层，管着几百上千人，却依然觉得付出和回报不成比例。

**第四层，做的是不是好生意。**

你可能不知道，阿里一个P9的年薪，可能顶得上传统行业上市公司CEO的收入，大概200-300万。这些年国贸旁边的房价涨不过西二旗，就是因为西二旗的互联网新贵有资本加持，能吃到红利，国贸的销售型行业，大部分人也就是多点年终奖。

当你已经能撑起一摊子事，就必须问：这件事值不值得你付出这么多，它是不是个好的商业模式。做好事的成本永远不低，有钱赚的事和没钱赚的事，成本是不一样的。

大自然有食草食肉的排序，商业社会更自由，你可以选自己的食物链位置。

黄峥说过，大象有大象的基因，老鼠有老鼠的基因。你是老鼠总想着变大象，就有问题。他这句话的意思是，他就是大象的基因，不用担心做不大。

第三层历练充分的人，接下来要做的就是做正确的事，做商业价值更大的事，让利益得到充分回报。

很多人卡在第三层，就是因为看起来管理几百人，根基稳定，自信满满，一算账却连大厂的高P都不如，心里自然失衡。

回头梳理四个层次：

1. 做事，是新人基本功，可能活不下去
2. 为老板做事，是组织生存基本功，但老板是瓶颈
3. 为自己做事，是做大事必须的能力，但可能不赚钱
4. 做正确的事，看似最对，但门槛未必你能迈

很多人以为直接冲第四层就行。我以前也幻想过直接做正确的事。可每个层次能活下来的人都是概率问题，越往下活下来的概率越大。我们回头看，靠手艺吃饭、与世无争的人和岗位永远最多。向上爬的路上总有人掉队，可幸存者总给我们希望：上去就好了。

做事要讲逻辑，也要讲现实策略。如果社会上所有人都去做正确的事，那些苦活累活、不好的生意谁来做？不是做的人不想做正确的事，是没得选、没条件选。

所以掌握这四层，不是为了死套，而是建立全局观，再根据现实操作策略。

每个人用的策略不同，也该不同。有人出身富贵，一上来就做正确的事也做成了。有人跟一个大哥走到黑也没差。但我们不能拿特例当范本。最好的策略是降维打击。

当大家靠学历技能找工作时，你能提前搞懂老板的缺口和需求，你拿第一层工作就更有优势。

当你紧跟老板时，同时想着有一天自己当老板业务怎么规划、组织怎么搭、怎么排兵布阵，等老板需要副手时你自然脱颖而出，就算老东家上去不了，你也能往高处走，你的能力不是绑定在他身上，而是你有自己的全局思考。

当身边都是小老板算盘打得精时，你时刻在问这件事对不对、未来有没有机会、我的差异化在哪，市场一变，你总能抓住新机会，手里有了资本再做转型。

四种能力是轮回。到了第四层不代表不用把事做好。等你有了财富和地位，全身心无目的做好一件事，反而是一种很珍贵的体验。

把这些能力当成工具灵活运用，看清每个层次的优势和局限，融会贯通，才能自救，也才能实现真正的人生梦想。
