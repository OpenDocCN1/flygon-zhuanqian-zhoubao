# ('HEXIN：一文讲透如何把 ChatGPT 融入工作和生活', (2, 31))

“在AI赛道深耕一年，等于传统行业打拼十年”这种说法，可能略显夸张；但换个角度看，“在传统行业熬一年，未必比得上在AI领域踏实钻研三个月”——这个结论倒是相当靠谱。

当然，这一切的前提是：你得找到真正能落地的场景，让AI切实为你提效，甚至开拓出职业发展的新空间。否则，热情很快就会耗尽，根本坚持不下去。
