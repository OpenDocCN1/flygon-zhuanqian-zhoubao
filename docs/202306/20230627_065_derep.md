# 买之前，到底是谁在替你做主？

做营销的人，永远绕不开一个问题：用户为什么买？

市面上的方法论汗牛充栋，学到老也用不完。真正管用的，是能帮你把复杂问题收成一个清晰框架，用它来拆解各种场景，再不断生长出新打法。

说到消费者怎么做出选择，有一个在业界被反复引用的模型来自《绝对价值》一书。作者伊塔尔·西蒙森是斯坦福商学院的市场营销教授，被很多人认为是研究消费者决策的权威之一。

他把影响购买的驱动力简化为三股力量，叫做 POM 模型。

第一股力量，来自消费者自己。Personal，也就是个人偏好。

一个人买茶，他最终信的是自己的味蕾。喝红茶还是绿茶，要不要普洱、要不要白茶，长期形成的口味习惯和经验判断会起主导作用。这类决策很主观，广告很难硬性改变。

第二股力量，来自品牌本身。Marketing，也就是品牌传播。

当品牌的声音足够大、足够有势能时，它会直接塑造消费选择。隅田川挂耳咖啡官宣肖战代言那天，天猫店销量直接冲上千万。瑞幸和椰树牌做联名，门店的联名款当天就被扫空。时尚潮流是什么风格，也是头部品牌在定义，普通消费者很难自己判断。

第三股力量，来自外界的人。Others，也就是第三方影响。

现实里，大多数人会去参考他人的经验。朋友一句推荐、专业博主的一条测评、KOL 的背书、评测机构的数据，都能左右最终下单。甚至有人会因为“小马宋给这个品牌做过咨询”就觉得更靠谱。买茶时听熟识的茶店老板的建议，本质上也是同理。

在这三股力量里，随着移动互联网的普及，第三方的声音越来越响，传播的路径也越来越去中心化。

那么什么情况下更听自己的，什么情况下更听品牌，或更听别人的？

关键在于三个判断维度：决策的分量、风险与不确定性，以及大众化程度。

分量重大、风险高、不确定性强的决策，比如近视手术，人们很难被品牌广告说服，会更倾向去问医生、问朋友的真实经历。

反过来，分量小、风险低的品类，比如一瓶 4 块钱的元气森林气泡水，广告一放、看到就买，品牌传播的效果就非常直接。

大众化程度也会起作用。手机这种大家都在用的品类，别人怎么选、参数口碑如何，参考价值很高。而衣服则带有强烈的个人风格，个人偏好的权重就会提升。

理解这三股力量的博弈，才能更清楚地设计沟通策略。希望这个框架对你有用，有想法欢迎继续聊。
