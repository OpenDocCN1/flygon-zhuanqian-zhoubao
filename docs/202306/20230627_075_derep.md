# 别为百分之零点零一的侥幸，赌上百分之百的全部
作者：龙哥

很多人觉得自己足够聪明，就能玩转概率。巴菲特讲过一个让他至今耿耿于怀的例子。

当年长期资本管理公司濒临崩盘，巴菲特出资三十多亿美元去托底。回头复盘时他说，这家公司根本不是一般的对手。

十六位创始人，平均身家全压进去了。队伍里还有两位诺贝尔经济学奖得主，罗伯特·默顿和迈伦·舒尔兹。智商碾压常人，履历放眼华尔街也几乎挑不出对手，一群人加起来的投资年头能堆到三四百年，早把资本市场摸了个透。

就这样的人，还是一样倒下了。

巴菲特的评价很直接：他们都是好人，我尊重他们。但为了多赚一些根本用不上的钱，把自己的身家性命搭进去，这算什么？用自己真正重要的东西，去换一个可有可无的回报，这笔账怎么算都不对。

他用了一个极端的比喻：如果有人拿一把有十万支弹仓的手枪，其中一支上膛，问你愿不愿意把枪口抵在太阳穴扣下去，输赢用钱来换。他说，给多少钱都不会答应。赢了，自己根本花不完那笔钱；输了，人没了。明明是必不划算的交易，可在金融市场里，这种事每天都在发生，而且很多人不带脑子就上了。

巴菲特还提到一本书名起得很漂亮，叫《一生只需富一次》。道理其实很简单。

年初你有一亿美金，不加杠杆稳稳赚10%，年底是1.1亿；加杠杆成功率99%，赚20%，年底是1.2亿。这两千万的差距，对你的人生体验来说几乎为零。万一那1%的尾部发生，你死了，讣告上可能都写错一个数字，多赚的钱还有什么意义？更别说你管的是别人的钱，亏了连脸都丢不起。

那帮人之前跟他说，六西格玛级别的极小概率事件伤不了他们。巴菲特认为他们想错了。过去的数据算不出未来的黑天鹅，历史的平稳并不等于未来的安全。他甚至说，贝塔系数这些数学模型，和真实的风险根本不是一回事。会算西格玛，不等于你就懂破产。

最后他归结到一个共通的人性盲区：我们总以为越懂细节越安全，结果往往把决定生死的关键忽略了。亨利·考夫曼说过，倒闭的人分两种，一种是什么都不知道，一种是什么都知道。听起来讽刺，却是最大的警示。

所以问题从来不是成功率是99.99%还是99.999%，而是万一那万分之一真的来了，你能不能承受。

评论区里几句话总结得也很好：
失败的代价如果重到无法承受，成功率再高也没意义。
上桌前先想清楚，全部输光还能不能接受。
做任何事先问自己，最坏的结果是什么，我能不能活下来。

聪明不是让你敢赌，而是让你知道哪些赌局，赢了也没用，输了就全无。
