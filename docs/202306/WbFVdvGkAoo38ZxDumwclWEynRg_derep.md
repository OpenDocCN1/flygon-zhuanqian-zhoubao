# 一、 先搞清楚什么是瞬息全宇宙

最近这波爆火的“瞬息全宇宙”，其实是有两套完全不同的玩法，大多数人分不清。

![](img/6e860b3743df37daa8906d40d72228f0.png)

![](img/be160804c920a3f2a0ef22ee6d6ac349.png)

它主要分两类：

一种叫【穿越之旅】，画面是连续变幻的场景，像在一路穿越，镜头感很强。

另一种叫【平行宇宙】，主体轮廓是固定的，比如一张人脸，风格却在不断切换，像在平行时空里换装。

“穿越之旅”靠的是 Stable Diffusion 里的 deforum 插件来做。
“平行宇宙”靠的是 runway 网站上的功能来做。

名字一样，做的事情完全不同。网上很多教程混着教，甚至用做穿越旅程的方法去做平行宇宙，最后效果差很远。所以先把概念理清很重要，有错也欢迎指正。

今天主讲“穿越之旅”的制作思路，“平行宇宙”我另写了篇专门讲。

# 二、“穿越之旅”的底层工具

穿越之旅的核心是 SD 里的 deforum 插件。用起来和 SD 出图逻辑差不多。

如果还没装 SD 或者操作不熟，可以先回顾我之前的 SD 入门。

真正做一条视频只需要两步：

1. 把插件装好
2. 把提示词写好

剩下的都是锦上添花，让成片更丝滑，比如：拉长时长、做运镜、定制第一帧、抄参数套爆款。

下面逐项展开。

# 三、第一个视频 10 分钟搞定

## 1. 一分钟装好插件

先确认 SD 已经装好。

1. 打开 SD，点状态栏里的“扩展”
2. 点“可下载”
3. 点“加载扩展列表”
4. 搜索框输入 Deforum
5. 找到 Deforum，点右侧“安装”

![](img/9a9da6bb078c92e1d45ef6322c1e126b.png)

装完后关闭 SD。

把网盘里的《1.deforum模型》下载下来，把里面的两个文件复制到 SD 目录下的 models/Deforum 文件夹里。这样能大幅减少报错。

![](img/a24e85db5866c82ea2954ef1b86c4caf.png)

重新打开 WebUI，状态栏会出现“Deforum”入口。

![](img/bd650035d6c231277736a8d70d588614.png)

如果重启后没出现，基本是版本不兼容。两个办法二选一：

1. 升级 SD 版本。打开“版本管理”，切换到新版 SD。
![](img/c9275a2785f04c9b9cae5cbe0e91bcba.png)
2. 降级 deforum 版本。版本管理 → 扩展 → 找到 deforum → 切换版本。
![](img/587761255b3b76a33eebfee56e082e73.png)

## 2. 提示词才是灵魂

做图也好做视频也好，提示词决定一切。

在 deforum 里写提示词分三步：

1. 选大模型
2. 写正向提示词
3. 写正负向提示词

### ① 选对模型定画风

模型决定视频的整体风格，是二次元、写实还是水墨。左上角切换模型即可。

我实测下来，文末提供的那款模型做这种特效最稳，效果最好。模型已放网盘，不会放可以回去看 SD 知识补课。

![](img/8dacda64cdf28f1ccd96c70cf496d35e.png)

### ② 拼提示词做过渡

做图只描述一张画面，做视频要把多张画面的描述串起来。

打开 deforum 的提示词区，默认有一段示例：

![](img/bf023bbb446d8537e8c72ce69528c12d.png)

翻译过来大致是：

{
“0”: “小巧可爱的沼泽兔，高度细致，复杂，超高清，清晰的照片，黄昏的光线，聚焦，作者 Tomasz Alen Kopera”
“30”: “拟人洁净的猫，被分形所包围，史诗的角度和姿势，对称，3D，景深，阮家和风华中”,
“60”: “一个漂亮的椰子——阴性照片，真实”
“90”: “一颗漂亮的榴莲，在艺术站上走红”
}

一行代表一帧画面描述，四行就是兔子→猫→椰子→榴莲的渐变过程。

举个例子，想做 花→美女→猫→可爱男孩，就是：

a bunch of flowers
a beautiful girl
a cat
a lovely boy

![](img/18696f7ac94b1a8227d6b0002b8ec664.png)

格式必须严格：

1. 所有提示词放在 { } 里
2. 前面的数字是帧数
3. 每行提示词用英文双引号包起来
4. 每行末尾加英文逗号，最后一行不用
5. 所有标点必须是英文输入法

![](img/ef7c669512db9b3c5a9ff85c31674dd7.png)

填好后点右侧“生成”，等出片即可。点击上方即可预览，点击右下角三个点可下载。

![](img/f5aaafbf51d10a16c94740933ba8c548.png)
![](img/bc7930962597ce3a23ff0626d2d67041.png)
![](img/9c5efba6a7a0f2f49e4fe73ecf9a97e2.png)

这就是第一条雏形。效果会比较粗糙，因为提示词太简单，而且没做运镜，后面会优化。

写提示词的通用公式：主体 + 细节 + 环境 + 画风
比如女孩：a girl, long hair, wearing a white skirt, standing on the road, the background is urban architecture, daytime, realistic style

描述越准，画面越贴近想象。

### ③ 正向负向提示词提升质感

在正负向提示词区填入通用词，能整体提质。

正向提示词：
Highest quality, masterpieces, extreme detail, 8K, HD qualit

反向提示词：
nsfw, nude,(worst quality:2), (low quality:2), (normal quality:2), lowres, ((monochrome)), ((grayscale)), bad anatomy,DeepNegative, skin spots, acnes, skin blemishes,(fat:1.2),facing away, looking away,tilted head, lowres,bad anatomy,bad hands, missing fingers,extra digit, fewer digits,bad feet,poorly drawn hands,poorly drawn face,mutation,deformed,extra fingers,extra limbs,extra arms,extra legs,malformed limbs,fused fingers,too many fingers,long neck,cross-eyed,mutated hands,polar lowres,bad body,bad proportions,gross proportions,missing arms,missing legs,extra digit, extra arms, extra leg, extra foot,teethcroppe,signature, watermark, username,blurry,cropped,jpeg artifacts,text,error

![](img/1aa53dbe472876679c452f73a059c913.png)
![](img/5185bd35c7c88dde3f5ce80bc591fc89.png)

这两个是作用整条视频的，别写进具体单帧细节。

# 四、控制时长

视频长度靠两个参数：最大帧数 和 FPS。

打开关键帧页面，最大帧数决定总照片数，200 就是生成 200 张。

![](img/10ee7653182d22eefe3b295850f7bcb0.png)

打开输出页面，FPS 决定播放速度，15 表示每秒 15 帧。

![](img/59b9c446408fdc3e0b2dea692d217003.png)

时长 = 最大帧数 ÷ FPS
比如 200 帧 ÷ 15 = 13.33 秒

日常 FPS 固定 15，只改最大帧数即可。要 30 秒左右：30×15=450 帧。

提示词前的数字对应帧数。0 是开头，30 是第 30 帧，所以 0-30 帧是花变女孩，30-60 帧是女孩变猫，以此类推。可以按总帧数自行调整节点。

![](img/3018d64418156485ed78e0a361ad0c5d.png)

# 五、加运镜，做出电影感

默认是固定视角，deforum 可以让镜头动起来。

打开关键帧页，把动画模式设为 3D，右边参数选 wrap。运动参数就是控制镜头语言的。

![](img/cab55f4c9dabef26c320875bbee2fd59.png)

以平移 X 为例：
默认 0:(0) 表示第 0 帧不动。
括号内为正值向右移，为负值向左移。

0: (2),60:(-2) 表示 0-60 帧先向右，再向左。
0: (2),60:(0) 表示前半段向右，后半段定格。

![](img/47716795af9c7690558352ede1b5cca4.png)
![](img/449aaf32d94847f158d0533d83cc7e72.png)
![](img/080940d380a7b3236483c6c1206dbc16.png)

其他参数规则一致：

|  | 平移 Y | 平移 Z | Rotation 3D X | Rotation 3D Y | Rotation 3D Z |
| 大于0 | 向上 | 放大 | 从远到近旋转 | 从右到左的旋转 | 逆时针旋转 |
| 小于0 | 向下 | 缩小 | 从近到远旋转 | 从左到右的旋转 | 顺时针旋转 |

参数可以叠加用。网盘里有现成预设，直接套用就行。

# 六、用定图开头，玩出新花样

给视频加一张固定首帧，后面再自动延展，效果更高级。

流程：导入照片 → 写提示词 → 调运镜 → 生成

拿一张熟悉的照片做首帧。

![](img/b3bd29f1d4d5e79e95146ae7348e42f1.png)

### 1. 导入照片
右键照片复制文件地址。打开 deforum 初始化页面，勾选“使用初始化”，把地址粘贴到初始化图像框里，记得删掉两边的双引号。

![](img/bbcc185e2c9fd0bb8854cc86ab41c0fd.png)

### 2. 写提示词
第 0 帧不用再描述画面，填质量词即可，比如大师杰作、高清、细节丰富、写实风格。

![](img/ab4d8dadc78de0ea4e96a18fda64c65b.png)
把正负提示词复制上去。
![](img/8d8399e8cecd39fa609cb4b60ecaff5a.png)

### 3. 设置运镜
注意冒号、括号、逗号必须是英文。
![](img/353a0e0bbe0668a2a1ae5e21ad22b853.png)

### 4. 生成视频
全部设置好点生成即可。

# 七、复刻网上的爆款结构

网上的爆款通常前面一段实拍素材卡点切入，然后接 AI 生成段。

在剪映里导入一段素材，找到想定格的那一帧，用“帧定格”功能把后面拉长。

![](img/28c2e7c7136f6712dea87cb9e41754fc.png)

选中定格段，点击播放器右上角三杠 → 导出静帧照片。

![](img/744becafa1c5304d9fd89fbc207cd30e.png)

这张照片按第六部分生成视频。生成后导入剪映，把定格段和中间多余部分删掉，只保留开头的卡点，拼接 AI 视频，加 BGM。

![](img/e52be203f0a7f74abc87e87e7f8d0778.png)
![](img/0193a0476c09b745a20b940cf69ce94e.png)

导出即成片。

# 八、补充

deforum 里还有很多可调参数，可以慢慢摸索。

如果你已经看过我们之前那篇Stable Diffusion的教程，那么这一步会非常省心——当前要讲的Deformity内容，很多操作和SD基本一致，几乎可以照搬照用。接下来直接进入核心环节。

## 一、采样器怎么选？

先看采样器，界面里被红框标出来的那个是常用选项。它的出图效果比较稳，清晰度也有保障，同时渲染速度不会让人等太久。选它基本就够了。

![](img/14e02b84903b8a8b0efdcfe386c6f77f.png)

## 二、迭代步数设置多少？

这主要看你电脑的配置。如果配置属于中低档，建议设置在20到25之间；如果配置比较给力，可以放到25到30。但有一点要记住：最好别超过30步，否则后面生成视频的时候会明显变慢，耐心会备受考验。

![](img/0284ca589aead6ed3999962c4e3f839d.png)

## 三、视频画面大小怎么调？

视频的宽高参数直接决定了最终画面的尺寸。想要正方形视频，就设成512×512；想要9:16的竖屏视频，推荐宽度576、高度1024；想要16:9的横屏视频，则可以把宽度设为1024、高度设为576。调整好这两个数值，视频比例就基本定型了。

![](img/67c5f0eeba1d4da964d463891b598cbc.png)

## 四、怎样保存预设，省掉重复设置？

DeForum里需要调整的参数实在不少，而且每次重新打开SD，之前的参数都会清空，从头再设一遍真的很费劲。比较好的办法是：第一次把所有参数调好之后，直接保存成预设，后面再用时载入即可。

具体操作是：参数设置完成后，点击右下角的“储存设置”，接着再点一下上方工具栏里的文件夹图标，就能在弹出的窗口里看到刚才保存的预设文件。

![](img/a772780a63cba85b9693dd9ea527a478.png)

打开文件夹窗口，保存好的预设就安安静静躺在那里。

![](img/bee7618fdcaa2f2017dd426eb80f283e.png)

下次想要使用这个预设时，先找到这个文件夹，在文件名上点击鼠标右键，选择复制文件地址。

![](img/1de2317864513b1ceb0a410f0de5730f.png)

然后把复制到的路径粘贴到右下角的文本框中，再点击“载入所有设置”。这样，之前调好的各种参数就会自动填回去，完全不用手动再折腾一遍。

![](img/d1015b59a74f185c5c6ba051670a13cd.png)
