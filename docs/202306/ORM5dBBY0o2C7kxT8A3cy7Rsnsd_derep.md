# MJ批量做定制手机壳

手机壳市场体量很大，老罗那句“卖手机的，不如卖手机壳”不是玩笑。

以前的定制要么是用户自带图，要么是厂商自带的几套图库。

AI绘画的出现让玩法变了：既能做有趣的大图，又能做个性化定制。

这条赛道有操作的空间。

①直接售卖成品壳，可以复用已有的头像壁纸号的私单画像。
②打包增值服务，比如高价头像定制赠送手机壳。
③转型做设计外包，帮壳厂批量生产配图，抽成赚钱。
④思路外延到其他周边：T恤、鼠标垫、帆布包、笔记本等。

# 儿童涂鸦定制

孩子总有创作冲动，但很多家庭给不出合适的正向反馈，最后热情就凉了。

贵族艺术班不是家家都能负担。

如果用AI工具给孩子一个“被看见”的瞬间呢？既增加陪伴感，又让涂鸦实体化。

①把涂鸦做成会动的，让孩子录几个动作，AI解析涂鸦骨架后套用动作。
②把涂鸦变成3D作品，或者二次元、真人风格的画面。

这个需求我还不确定大家的反馈如何，有兴趣的话后续我可以出一期实操教程。
