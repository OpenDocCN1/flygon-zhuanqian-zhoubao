# Web3 小白通过 BRC20，3 个月锁定 300 万利润
作者：龙哥

三个月，三百万，对于一个刚踏入Web3的新手来说，听起来像天方夜谭，但它真实发生了。今天不聊玄学，只聊一个普通人是如何抓住BRC20这波浪潮，并且成功把利润落袋的。

故事的主角是“路遥”，他自称是Web3生态里的“烧火工”。2023年2月7日，他通过“龙哥盟”的小航海计划正式入圈，随后一头扎进BRC20生态，短短三个月，锁定了约300万的收益。

很多人好奇，一个Web3小白凭什么能抓住这种机会？他的答案很简单：不是靠运气，而是靠一套清晰的打法和认知。这次分享，他主要想讲两件事：一是BRC20这两个多月到底经历了什么，二是现在这个阶段，新人怎样才能“轻装上阵，以小博大”。

他用一篇长文详细拆解了整个过程——《BRC20，新人现阶段如何轻装上阵，以小博大？》![](img/6ce5d93a1aff6a39cd079f1f3e544538.png)。这篇文章里没有虚头巴脑的理论，全是实操层面的思考，包括如何判断时机、如何控制风险、如何避免FOMO。

有意思的是，评论区里有人羡慕他能看懂Web3，也有人提醒大家注意风险——毕竟BRC20代币陆续上所后，FOMO到顶点就可能迎来暴跌，有人亲眼看到群里朋友拿着数十万美金的持仓，最后缩水严重。路遥自己也回应说，新赛道机会与陷阱并存，千万别上头。

但他特别强调一句话：做自己擅长的事，找到属于自己的天命。即使他自称“Web3小白”，但那份冷静和判断力，显然不是一般人能比的。这篇分享也被“龙哥”加为了精华帖，可见含金量。

如果你也想了解BRC20的底层逻辑，或者想知道新人如何在不重仓的情况下博取高赔率，不妨仔细读读他的原文。链接就在上面，拿走不谢。![](img/837ede9c1bed0c4380ea7f1df5300105.png)

记住，机会永远留给有准备的人，但更留给那些懂得“轻装上阵”的聪明人。
