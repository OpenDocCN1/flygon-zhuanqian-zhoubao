# 五年赚钱圈友成长路--之赚钱使用手册
作者：龙哥

在赚钱圈摸爬滚打的这五年，我从一个只知道刷帖看热闹的小透明，慢慢变成了写过十篇精华帖的老圈友，后来还有幸站上了线下聚会的分享台。这一路靠的不是运气，而是一套自己总结出来的“赚钱打开方式”。今天掏心窝子跟大伙儿聊聊，我是怎么用好这个圈子的。

**别只当观众，写出来才算赚到**

龙哥盟本质上是个巨大的内容池，几十万条帖子堆在那儿，光看是看不出真金白银的。很多人收藏夹塞得满满当当，聊起来天花乱坠，一动手就废——问题就出在始终站在岸上看别人游泳，自己从来没下过水。

试着去输出，至少有两层好处。一是逼自己深度思考。写一篇文章时，为了让逻辑有条理、信息有密度，你不得不把自己脑子里那些零散的东西重新拎出来捋一遍，很多以为早就搞明白的事，写着写着竟然又有了新感觉。二是吸引同频的人。你不开口，没人知道你在干嘛、你是谁。内容就是你的名片，写出来自然会有人循着味道找过来。一个人脑子再灵光也有边界，大家凑在一起聊，才是成长最快的捷径。

**大大方方分享，反而稳赚不赔**

“利他”这两个字，是我在这儿感受最深、获益最多的东西。不讲空道理，拿我自己几个例子说事。

2019年，我算是最早一批做知乎好物的。那时候圈子小，没人可请教，也打听不到谁在做。按一般人的想法，做得好肯定得闷声发大财，生怕别人来分一杯羹。我倒是没想那么多，就是有点藏不住事儿：出一单发篇文章、发现个新产品发篇文章、找到个好使的刷赞渠道也忍不住晒一晒。结果，不少同期做知乎好物的圈友跑来加我。大家手里的信息都不多，可凑一块儿交换起来，就汇成了一个大水池。我贡献出去一份情报，自己一分不少，反而收回了十倍百倍的信息量。这是我第一次尝到利他的甜头。

2020年双十一，我偶然发现一种知乎文章的格式流量特别好，顺手把它导流到淘密令，红包撒得飞快——花十来分钟写一篇文章，几千上万个红包就出去了。这方法实在不值钱，我就花几百字写了个教程，配上几张图，谁来要就免费发。双十一结束，跟着做的朋友有人赚几百、有人赚几千、还有人赚上万，不少人总共花了不到一小时就轻松落袋。我虽然没从这事儿里直接捞到钱，但很多人记住了：慧姐这人，有鬼点子。能被大家认可，这本身就是收获，何况我又没少块肉。

2021年的银发电商，更是把利他思维玩出了大动静。我自己跑通几个账号、验证数据不错之后，没去铺一堆同质化的号——说白了就是懒，懒得干重复的活儿。我索性找人一起合作，短短几个月铺了几千个号，这恰好印证了我最初的判断：这个市场的容量大得惊人。我当时就想，自己撑死做几十个号，在2亿多老人的需求面前根本不够看。只有海量账号一起涌进去，把市场轰炸开来，才有真正的效果。

经常有人问我：慧姐，你咋不自己藏着掖着呢？我说，人性都是逐利的，谁都有小九九，纯粹无私的那是圣人，我就是个普通人，也有自己的算盘。我判断一件事值不值得分享，标准特别简单：说出来，我会损失吗？既然不会，那赠人玫瑰，何乐不为？

很多人爱念叨“教会徒弟，饿死师傅”。还抱着这句话不放的人，思想怕是停留在小农经济时代。古代一个手艺人住在小镇上，服务全镇人刚好糊口，教个徒弟出来，饭就不够分了。可现在是什么年代？互联网上一个平台动辄几千万、几个亿的用户，你敞开了吃又能吃下多少？你把自己的信息递出去，几乎不影响自己，很多时候反而是双赢。大家一起把某个市场焐热，新进来的人还会带着新玩法、新角度，我坐在地上捡现成的就行，何必心里惦记着一锅自己根本吃不完的饭？

**挑软柿子捏，也是本事**

在赚钱学习，最重要的一件事是找对目标。我的做法很简单：不给自己画大饼，专挑那些容易够得着的，找比自己强一点的人去模仿。比如做抖音银发电商那会儿，短视频带货和直播带货摆在面前。

论数据，直播当然漂亮，可难度比拍视频高了何止一百倍。能对着镜头不打磕巴、流利表达的人，一百个里面不一定挑得出一个；还得控场好、亲和力强，那真是千里挑一。反观视频带货，我能把对标账号拆解个底朝天，模仿到百分之百，不光自己做得到，还能教给身边一堆人，差的无非是时间。

所以让我选，我打死不碰直播。我成不了好主播，也培养不出好主播，更管不了一个直播团队。绕来绕去，我的优势只在视频上，那就顺着自己的优势走。要是脑子一热硬冲直播，痛苦是必然的，失败也几乎跑不掉。失败多了，时间浪费了，信心也没了，信心一垮就越急，越急越容易做错决定，最后成了死循环。

**追人群，比追热点更长远**

在赚钱搞钱，说白了就是学别人怎么搞钱。很多人会有种挫败感：怎么这项目别人赚得好好的，到了我这儿就凉了？生命周期就一两个月，也太短命了。其实这很正常，本来那些见效快的项目，寿命就短。道理讲起来枯燥，我举个形象点的例子。

第一层是追热点。比如红包封面，每年春节前后必火一阵，流量短时间内冲到顶峰，然后迅速衰落。这类东西来得快去得快，见效也快，最适合新人练手、培养网感。

第二层是选平台。去📕引流、去知乎做好物、去抖音带货、去开淘宝店，这些需要投入几周甚至几个月才能见效，但一旦跑通，就能吃一阵子安生饭，只要平台规则不大改，你就能一直做。缺点就是来得慢。

第三层是盯人群。不管追热点还是做平台，绕来绕去都是在服务某一群人。热点会凉，平台规则会改，可人群是不变的啊。以前做淘客的都爱盯宝妈群体，一个宝妈身份少说能持续十年以上。你把这个人群摸透了，跟他们产生了深度连接，就能不断发现他们冒出来的新需求。平台怎么变、流量怎么涌，你只管服务好这群人，钱就断不了。你花大量时间攒下的对人群的理解，就是一条别人抄不走的护城河——产品能抄、方法能抄，唯独你对这群人的懂，抄不走。

拿我自己说，做了两年老年人群，越做越觉得这事儿能干一辈子。从大环境看，老龄化是不可逆的大趋势；往小了说，老年人网购是个全新的增量市场。所以我不绑定某个平台，抖音、快手、视频号……只要哪个平台上老年人占比高，我就能套用同一套打法去试。人群是根，追热点、换产品，不过是枝上换叶子。每一次在垂直人群里的尝试都会沉淀下来，下次换个产品，重新激活就行，不用每次从0到1，直接就是从1到100。看起来我好像老在换方向，其实根上的东西一直没变过，就像散文——形散，神不散。

**跟大众反着来，红海里也有蓝海**

逆向，字面意思就是别人朝东，你偏朝西。

举个常见的例子：带货选品时，很多人第一反应是找便宜的品——便宜好卖嘛，这几乎是大众本能。可这个逻辑只对苹果手机、茅台这类标品成立。在别的条件都差不多的前提下，价格低确实无敌。但现在是内容电商、兴趣电商的时代，产品的亮点可以从很多维度挖。图文时代想靠几张图、几行字展现一个产品的吸引力，几乎不可能；视频就不一样了，信息量大得多，新奇特的产品能被演绎得明明白白，再配上剧情和场景，简直让人不买都过意不去。

这时候，你要是还一门心思去源头厂里抠几毛钱差价，不如把这功夫花在内容上。一个好创意，能把同样的产品卖出几倍的价格，甚至冲出同行几十倍的销量。永远琢磨着跟别人玩出差异，朝反方向走，红海深处照样能挤出一片蓝海。

先聊到这儿吧，回头有了新想法，再接着唠。
