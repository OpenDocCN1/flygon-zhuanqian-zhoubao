# 一个汽修老炮儿的抖音逆袭：从一年白忙到单月十万的同城号打法
作者：龙哥

今天讲一个我合伙人亲弟弟的真实经历，亮仔，初中学历，干了19年汽车维修，一辈子都在守着实体店过日子。店里客户怎么来？靠路过的人进门，靠老客户带老客户。线下就这么干过来了。

去年他也想着赶潮流，注册了抖音号折腾了一整年，视频也发了，播放也有，可账户就是一分钱没进来。直到用了下面这套思路，第一个月营收直接干到十万。

很多人做同城号，都想搞成大号、想做爆款、想讲行业干货。亮仔这套路完全反着来，就是做一条街的生意，不是做全国的流量。核心就是把抖音当成门店的第二个门口，而不是把门店搬到网上。

他账号定位很笨但很准：只拍自己店里能立刻成交的服务，只服务方圆五公里能开车过来的用户。视频不求好看，只求让隔壁小区的人一看就懂、看完就想来。





### 同行最关心的几个质疑，我也帮他梳理清楚了

关于修理厂的流量来源问题，有人问保险公司派单占大头，个人单子撑得起来吗？ 
**便宜的车，车主更愿意自己找地方修。** 这部分需求永远存在。

有人说光拍视频能把技术搞上去，让客户复购吗？
**老板本身就是干了十几年的老师傅。** 技术是前提，内容只是放大器。

还有4S店下沉做拖车、送车、理赔一站式服务，修理厂怎么比？ 
**根本不是同一拨客户。** 一个要省心包办，一个要省钱靠谱。

保险公司压工时费还控制配件怎么办？
**那就别指望保险公司吃饭。** 自媒体的方向就是把饭碗从上游渠道，拿到终端用户手里。

最后，有人问做自媒体要不要重调利润结构？ 
**不需要。** 自媒体本质上就是一个获客工具，别把它神化成转型方案。先把人拉进来，服务和定价还是回到线下逻辑。

说到底，同城号能不能复制，不看你会不会剪辑，不看你文案多会写，就看你敢不敢把本地的真实需求，对应到真实的门店服务上。亮仔能做到，你的行业也能做到。
