# ('没有营销理论会讲回扣的事', (2, 14))

你有没有发现一个挺诡异的现象：所有营销经典、商业教科书，都从不碰“回扣”这两个字。但它们真实存在，而且几乎潜伏在每一桩生意的成交背后。

当年查理·芒格在斯坦福商学院做过一次讲座，他抛出一个问题：怎么才能既把商品价格提高，又把销量做大？在座的高材生们面面相觑。芒格自己给出了四个答案，最后一个——用多赚的那部分钱去打点关系，把货卖出去。他直言，这是自己最偏爱的答案，因为它精准地撕开了理论与实践之间的那层窗户纸。

商业实践有多野？有些事，理论从来不会写。

“回扣”这件事，几乎是全球通行的商业潜规则。有些公司给它穿上体面的外衣，叫“公关费”，叫“信息费”，但内核一点没变。欧美国家文明多了？药企赞助医生去参加学术会议，顺便周游世界几天——这到底是学术交流，还是变相输送利益？没人会写进论文里。

营销理论不会告诉你回扣的玩法。管理学著作同样讳莫如深——它不会教你提防同级同事暗地里使绊子，不会告诉你公司高层里藏着权色交易，更不会把董事会里那些血淋淋的权力斗争写进案例分析。

再看看各种细分领域的“实战指南”：开餐厅的书，不教你怎么应对地头蛇上门收保护费；做电商的运营手册，也没有哪一章教你对付职业差评师。

真实的战场远远更野。当年有个电器经销商去南京开店，脚还没站稳，同行就带人直接把店砸了。你生意做得风生水起，房东看着眼红，一句“我想收回来自己干”就能让你几年的心血付诸东流。竞争对手安插卧底混进你的团队，故意把鱼扔进垃圾桶，再偷拍视频断章取义发到网上——这套组合拳打下来，你找哪本书要答案？

现实就是这么复杂又残酷。但毛主席早就说过：与人斗，其乐无穷。既然躲不掉，不如把这当成一场成年人专属的硬核闯关游戏。

评论区里，有人的总结一针见血：酒桌上多喝的每一杯酒，都是你做产品时少流的汗。还有人说，书架上那些正经书给不了的生活经验，往往才是混江湖最值钱的底层代码。就像驾校教练最爱吐槽的那句——读书读傻了，一到路上就露馅。真正的高手，送回扣都能送出你想象不到的花样，那种“隐性营销”，早就超越了任何理论框架能覆盖的范畴。

欢迎来到这个既残酷又有趣的真实世界。
