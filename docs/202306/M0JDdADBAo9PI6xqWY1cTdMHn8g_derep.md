# 第一招：大热点 + 个人IP定位，定点狙击式选题法

### 什么时候用？

最近“孟羽童离开格力”这事，相信大家在各大平台都刷到过吧？这个瓜不仅保质期长、覆盖面广，中间居然还有反转，简直能跟五一淄博烧烤的热度打个平手（当然跟烧烤比还是稍微逊色一点）。像这类持续发酵的大热点，正是我们可以“精准借势”的好靶子。

### 难点在哪？

那问题来了——怎么蹭？

一方面，你得先搞清楚这事的来龙去脉，光吃瓜查资料就是一大工程；另一方面，还得琢磨着怎么把这么个热点，巧妙地挂钩到自己的IP定位上来。找角度、出观点、做差异化，这哪一样不费神啊？！

这时候，ChatGPT联网版就该登场了！

不清楚这件事的前因后果？小G，你赶紧给我扒清楚、总结好！

不知道怎么结合热点做选题？小G，你来帮我想！

![](img/1233ec3282251a51eff475756de7d1e9.png)

### 先理理思路

跟以往直接甩提示词的做法不同，这次我强烈建议大家先跟我一起把问题拆解一遍。说实话，以前我也嫌麻烦总是跳过这步，直到我发现——不讲清楚这个底层逻辑，大家根本学不到真本事。这，才是使用GPT的“元能力”！

就拿经典的黄金思维圈来拆解一下：

（这个模型具体是啥，大家可以自己查一查，反正我得补充一句：我写提示词快，很大程度是因为以前做投资人的经历，脑子里装满了各种思维模型，一到用的时候就自动跳出来了。所以大家平时也多积累点思维模型，真到用的时候就知道有多香了。）

**1. WHY**

我们最终想要的，是选出一个既接得上“孟羽童离职”这个热点、又符合自己IP定位的选题方向。

**2. HOW**

先把“孟羽童从格力离职”的完整来龙去脉搞清楚——这事为什么火？中间有什么起伏？为啥大家一直在聊？

然后嘛，自然得让GPT知道我们的IP定位，不然它也就只能在原地瞎猜。

**3. WHAT**

第一步提示词，目标：调查热点。让GPT自己上网弄清楚：1）事件的基本情况是什么？2）这话题为啥这么火？3）如果要讨论这个话题，什么角度最能戳中人心？

第二步提示词，目标：输入IP定位。让GPT了解：1）我们是做什么的？2）核心受众是谁？3）对方的真实需求是什么？4）我们能提供什么样的解决方案？

第三步就更简单了，把两者一对接，让GPT直接给选题方向就行。

### 实操案例（以职场号为例）

#### 第一步：让GPT调查热点

提示词：

最近网上有个很火的“孟羽童从格力离职”的话题，你帮我去网上搜一下，告诉我：

1. 这个事件的来龙去脉，到底发生了什么？
2. 这个话题为什么能火这么久？

然后请你从人性的角度出发，用逻辑推理分析一下：这话题能持续火热，究竟戳中了大家心里的哪个点？

#### 第二步：投喂IP定位

提示词：

你调查得不错，接下来请按我说的步骤来做：

1. 我是一个小红书博主，需要你先理解我的IP定位，然后帮我从刚才聊的“孟羽童从格力离职”这个热点里，挑出适合我创作的选题方向。

2. 我接下来会以“请了解”开头，把我的IP定位发给你。请认真阅读，如果你觉得信息不够全，就告诉我还需要补充什么。

3. 如果你已经完全理解我的IP定位，并且收集到了足够的信息，能够帮我结合这个热点进行选题，就回复我：“我已收集足够信息，并准备好帮小凡结合IP定位与‘孟羽童从格力离职’这个话题进行创作选题。”之后，我会回复：请帮我进行创作选题。收到这条消息后，你再开始正式帮我选题。

如果你听明白了，请回答我两个问题：1、用自己的话说一遍你要做的事；2、说说你会怎样更好地完成这件事。

# 第二招：热搜榜扫描 + 固定内容类目选题法

### 什么时候用？

有时候吧，没有什么大爆款可蹭；或者是那个大热点跟咱们的根本就不是一路人，硬蹭反而出事。

### 难处在哪？

这一招大家完全可以自己去试试。因为ChatGPT这家伙就是个“你说啥好他都说好好好”的老实人，只要没违背他所谓的“价值观”，他啥都能给你编出来。

所以哪怕你手里的热点真的切不进你的IP定位，他也会硬着头皮跟你掰扯出一个角度来。这时候你就会发现他开始一本正经胡说八道了。但真说起来，也不能全怪GPT——很多时候是这个题本身就没解，你还非逼它给个答案，那小G可不就只能给你现编了呗。

那咋整？？？？

![](img/e9c9b0a907c03ac8b22c9d7f788a9d62.png)

### 理清思路

不如换个打法——刚刚是“让热点来找你”，现在反过来了，我们“主动奔向热点”。懂我意思伐？就是让ChatGPT开着联网功能，自己在互联网的汪洋大海里瞎溜达，碰上啥好货再回来告诉我们。

黄金思维圈咱就不重复了，大家自己动动脑思考一下，对吧~

### 实操案例（以旅游号为例）

#### 第一步：先立个身份

提示词：

你好小G，我是小红书博主，想请你当我的选题创意顾问，帮我想合适的笔记选题方向。

请按下面的步骤帮我：

1. 我会先以“请了解”开头提供我的IP定位信息。请你认真阅读，如果觉得信息不够全，告诉我还需要什么。如果你完全理解了，就告诉我：“你已经完全理解我的IP定位。”然后我们进入第2步。

2. 我会接着告诉你：“请到中国热门的互联网社区去找热搜榜单，从这些近期的热聊话题中，挑出你认为适合我这个IP定位的选题方向。”并且你要告诉我：1）这个话题的热度有多高？2）大家主要都在聊什么？3）为啥你选它给我？

要是你明白了，就回答我两个问题：1、用自己的话描述你要做的事；2、你会用什么样的方法把事情做到更好？

目标人群：约30岁、想出去旅游的白领人群

人群画像：收入水平普遍不错，追求有品质的享受

人群痛点：1）工作忙成狗，时间上根本排不开，旅游成了一种奢侈；2）不少人已经拉家带口，出门一趟各种麻烦；3）觉得传统旅行社太low，想追求点更高端的感觉

# 第三招：“天时”预判流选题法

源自生财圈友@蔡文静好文静 在玩赚新媒星球分享的玩法（搁这儿套娃呢）

### 什么时候用？

除了那些冷不丁冒出来的突发热点，其实我们还可以顺着二十四节气、固定节日这些“板上钉钉”的爆款时间节点，提前把选题做起来。这里我必须感谢一下@蔡文静好文静 老师贡献的“天时地利人和”选题法。

篇幅有限（才不是因为我偷懒），提示词的构思逻辑就不过多展开了哈。

![](img/3bc420a5714fb0182520d29e42c46de3.png)

### 实操案例（以美妆号为例）：

#### 第一步：让GPT理解“天时”

提示词：

所谓“天时”是指：

固定节日（五一劳动节、母亲节、517吃货节、520情人节等）

季节天气变化（春夏秋冬、冷热交替，尤其咱们中国的二十四节气）

临时热点（热播剧、社会新闻）等

它本质上是一种社会、文化或自然层面的“时机”或者“趋势”，会悄悄影响大家的情绪、决策甚至行动。比如节日让人更愿意剁手，天气变化改变人们的出行选择，热门社会事件则会把某些话题推到聚光灯下。

如果你能理解我上面说的“天时”，就帮我去网上搜一搜，2023年5月到6月，有哪些值得关注的天时。

如果你觉得对“天时”这个概念还需要更深入的描述或解释，直接告诉我。

结果：

![](img/8af2d1999d4806f29ca7ea90ea07dce3.png)

#### 第二步：投喂IP定位

提示词：

我是小红书博主，现在想请你当我专属的选题创意顾问，帮我想合适的笔记选题方向。

请按照下面步骤来：

1. 我会以“请了解”为开头提供我的IP定位信息。请认真理解阅读，如果觉得信息不够，就告诉我还需要补充什么。如果你完全消化了，请回复：“你已经完全理解我的IP定位。”然后咱们进入第2步。

2. 我会接着告诉你：“请根据对我IP定位的理解，在中文互联网上搜索跟我相关的美妆或消费类天时，然后结合这些天时给我一些创作选题方向。”你直接照做就行。

如果你听明白了，请回答两个问题：1、用你的话复述一遍要做的事；2、你打算怎么把这件事做得漂漂亮亮？

目标人群：20岁左右、活跃在小红书上的女大学生

人群画像：还没赚钱但已经开始接触化妆，有颗爱美的心

人群痛点：1）生活费有限，太贵的化妆品根本hold不住；2）想变漂亮，却不知道从何下手；3）网上种草信息真假难辨，经常冲动消费买回一堆闲置
