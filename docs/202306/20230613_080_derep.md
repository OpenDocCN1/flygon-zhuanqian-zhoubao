# 别再神话985，赚钱远比进名校更可控

考上985和一年赚到100万，哪个更难？

先说结论：放在天平上称，年入百万的门槛明显更低。

小马宋曾用数据做过一次粗略对比。2023年全国985本科计划招生约20万人，累计下来985毕业生总数已经是几百万量级。而年收入破百万的人群，根据多方统计口径，大约在80万人左右。把电商、自媒体等难统计的隐形收入算进去，翻倍到160万人也很合理。

这160万不是一个固定的“终身会员名单”。有人今年达标了，明年可能只有50万；有人今年刚起步，明年就上去了。也就是说，每年能做到年入百万的“人次”大概有160万，而每年能考上985的新生只有20万。哪怕算上重复率，十年的累计体量里，至少做过一次年入百万的人，也远多于985毕业生。

更重要的是逻辑，而不是精确的数字。

考985，命中注定的成分太重。

你出生的城市、父母的职业与资源、读的小学初中高中、当地的师资水平和升学生态，这些决定了你起跑线的高度。十几岁的你其实没什么选择权，只能在被分配好的赛道里拼命。

我见过太多例子。一个人从小在教育资源稀缺的县城长大，老师学历不高、同学基础参差不齐，每天都在拼命学，但天花板就是天花板。同样努力的人，在教育资源好的城市，起点就高出好几个段位。高考是标准答案的战争，评价体系单一且极其残酷。行就是行，不行就是不行，多学几年也很难跳出那条概率线。学渣逆袭的概率，远低于赚钱的逆袭概率。

而工作以后，主动权几乎完全换了人。

毕业后你能选老板，能换公司，能跳城市，能换赛道。爸妈是谁你改不了，但你能自己挑领路人；上哪所中学你说了不算，但你能自己挑老师，学营销、学产品、学谈客户，不合适就换。文科理科只有两条路，但社会有365行，总有一行能发挥你的长处。

赚钱没有标准答案。高考只有一次排名，市场却是多维度的赛道。你擅长产品不行，可以靠营销；营销不行，可以抱大腿；大腿没了，可以抓红利；红利没了，可以培养新能力。公司可以换，项目可以换，人脉可以学，圈子可以进可以退。失败不是终点，只是换一个试错场。

985的录取是过去十几年的总和筛选，年入百万是成年后持续可迭代的选择权集合。前者命运锁得死，后者你可以自己开锁。
