# 两年创业后，我对付费学习这件事的重新理解

> 原文：[`www.yuque.com/for_lazy/thfiu8/ne9v8i8g9qing1ec`](https://www.yuque.com/for_lazy/thfiu8/ne9v8i8g9qing1ec)

打开星球 App，置顶的生财有术又推送新动态，熟悉的续费提醒又来了。算下来这都快第三个年头。

自我介绍下，我是老瞿 Qu，圈子里大家常开玩笑说我是生财星球里对旧书生意最上手的那个。

今天想重点聊聊我对付费获取知识这件事的看法。

先捡几个关键节点，背景接近的朋友应该能懂。

1、大学毕业后进了头部房地产系企业，干了八年，离职前是 TOP30 房企区域运营负责人，年薪过百万；
2、第一次创业，融了 100 万，占了 10% 股份，讲的是上千万估值，半年烧光收场；
3、第二次尝试，想快点回本，拉新、薅货等玩法都试过，三个月交了 20 万学费才醒神；
4、第三次扎根做旧书回收，承认自己平庸，坚持两年后拿到些许成果，年利润大概在一百到两百万之间；
5、第四次复盘，旧书的盘子已经稳了，现在在寻找上限更宽的方向。

刚进生财的第一年，情绪走过一个完整循环：

1、内容看不懂，像读论文，不知作者是谁；
2、到处都在说一年几百万、几千万，感觉在吹牛；
3、越看越迷茫，随便试了几天没挣到钱，觉得被忽悠；
4、气得把星球卸载掉；
5、焦虑又装回去继续翻项目。

现在复盘，那段懵的状态主要来自三方面。

第一，认知差距。自己出自传统地产圈，对生财里流行的线上玩法接受门槛很高。离开学校久了学新东西本就难受，但这正是改变的信号。社群如果加入进来特别舒服，往往意味着成长有限。

第二，上班太久，赚钱的肌肉退化了。多年企业生涯习惯了岗位说明书、年度季度周计划，做不好会被催会被扣分。摸鱼是常态，我当年带运营时，至少一半时间在划水，手下去执行，自己泡茶拍领导马屁。

而自己干项目，是从零到有，全靠自己把路径摸清。长期养成的懒散会让效率极低，没人盯着就根本不动。这需要很强的自我驱动。更关键的是很多人在职，拿生财当副业，正职在那吊着，执行力很难起来。没有裁员的紧迫感，很难真上心。

第三，总想把结果外包。典型的被割韭菜心态是：我照做了为什么没流量？做旧书要上架多少才能稳定过万？你付了我钱能不能保证成功？做不成怎么办？

本质是打工人思维，花几百块买内容，就觉得赚钱的责任该别人扛。实际上没人能为你的结果兜底，也没人愿意承认自己不行。要接受，任何项目在起步期，都比上班辛苦好几倍。

历经两年，我对付费学习的总结有三条。

第一，不要人云亦云，更不要盲信大佬。要先提升判断力，独立拆解一个模式：它的优势在哪，短板在哪，需要什么能力，再对照自身是否匹配。

举例来说：旧书回收，上手快，三天内出单很正常，但流程琐碎，天花板有限，单人运作月赚一两万已算极限，想放大就要团队化。而短视频带货，养号周期长，前两个月可能零收入，但上限高，走运一次就能有几万利润，而且没有客服接单的繁琐。

第二，项目有层级，要选对位。

入门级是蓝海电商，执行到位就能变现，比如闲鱼上的旧书这种小而稳的生意；
进阶级是短视频、直播，需要网感，前期慢，后期爆发力强；
高阶级是个人 IP，需要长时间沉淀，年入百万并非夸张。

只有认清自身水位，选匹配的层级才更易出结果。小白上来就做 IP，报了一堆高端训练营，结果基本为零。

第三，项目必须是自己挑的，付费只是加速器。它的核心价值是借用前人的经验帮你省一两个月试错，快速跑通流程，减少踩坑。走弯路最怕的不是花时间，而是让你直接放弃一个本可行的方向。

记住，钱赚不到，别把锅全甩给课程。类似亦仁以前提过的问题：手里只有 5 万，能不能推一个稳赚 100 万的项目。答案是显而易见的。

当你真正把责任揽到自己身上，成功的概率才会上去。

熬过第一年的懵懂，第二年的认知升级后，我真心觉得生财是我见过创业类社群里质量最高的。假如你现在仍找不到方向，大概率是参与度不够，执行没跟上。

续费时的脑内独白大概是这样的：

我坐在办公室喊：鱼丸，叫亦仁进来一下。
亦仁进来后我说：亦仁，今年给你 2000 块预算，帮我做这几件事：
1、给我持续提供最前沿的项目情报，至少领先市场一年；
2、组织十万创业者交流，把他们现在在做的事汇总给我，我有空就翻；
3、每月安排实战，我挑着参加；
4、每周给我一份精简周报，我没空刷。

听懂了吗？

希望第三年在生财里能链接更多志同道合的赚钱伙伴，一起把事做成。
