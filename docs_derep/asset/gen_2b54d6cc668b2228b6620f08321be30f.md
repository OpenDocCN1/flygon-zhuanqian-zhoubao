[PRE5]

这就是一个信息抽取的模板。

它的逻辑是告诉模型：不管原文是一篇长文、一个网页还是一份报告，都要按这几个字段整理，最后给我一份 JSON。

字段含义拆解如下：

*   "标题": ""：提取原文标题。

*   "摘要": ""：提炼或生成内容摘要。

*   "原文链接": ""：抓取文章的原始网址。

*   "来源/机构": ""：判断发布方或所属机构，比如新华网、某公司。

*   "关键词": ""：总结核心关键词。

*   "发布日期": ""：找到确切的发布时间。

*   "序号": ""：可自定义的编号或索引，由你定义规则让模型填充。

在 n8n 的结构化输出解析器里配置好这个模板后，给它一段非结构化文本，它就会自动阅读、拆解，并把结果规范填入这些字段，最后吐出干净可用的 JSON。

### 搭建中常见问题及对策

搭建过程中会碰到各种坑，这套流程里主要遇到以下几种：

#### 翻译偏差

即便用了翻译插件，也常出现功能对应不上、理解跑偏的情况。

解决办法：直接截图标注界面给 Ai 看，让它基于真实界面给出操作指引。

[PRE15]

#### 节点能力不匹配

现有节点满足不了需求，或官方节点成本过高。

这时可以走中转站的 API 路线 仅限 AI 模型调用。以云雾平台为例，中转 URL 配置如下：

*   中转地址 BASE_URL 1：https://yunwu.ai

*   中转地址 BASE_URL 2：https://yunwu.ai/v1

*   中转地址 BASE_URL 3：https://yunwu.ai/v1/chat/completions
