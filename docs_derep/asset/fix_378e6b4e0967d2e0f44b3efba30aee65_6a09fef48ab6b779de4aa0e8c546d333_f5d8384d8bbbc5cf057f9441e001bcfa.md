# 真正的被看见，是你一直没走

2023年春天，亦仁在自己的笔记里写下这个观察：一个人真正被大家注意到，往往不是在初次登场时，而是某天别人回过头，发现他已经在那里坚持了好久。

他为此感到幸运，当初选择做社群，就是选择了一件不能轻易放下的事。连续七年，起初是外部环境逼着他必须把精力收拢，后来变成他自己甘愿长期扎根。如果换作其他业务，以他对机会的敏锐度和天生的好奇心，也许会每个月都觉得新方向更好，结果大概率是不断转向、赚到一些快钱，却没有留下任何积累，于是又跑去寻找下一个机会。

前段时间，在一次资深成员的内部交流中，亦仁收集大家对于生财的思考。有人用一句话点破了关键：

“别人真正把你放在心上，不是第一次见你站在那儿，而是过了很久，居然发现你还在那儿。”

这句话在评论区引起许多人的共鸣。一个创业多年的朋友说，自己一直不被家人理解，受尽冷眼和质疑，看到这句话特别想哭，只希望今年能开花结果，对得起这些年来的不甘心。也有人聊起自己的小事：2019年建起一个知识星球，内容大多不是原创，而是从一位博主那里摘录整理。那位博主曾在他低谷时给过指导，他几乎每天都会看对方的更新，星球也跟着一直更新到现在。如今回头看，能坚持这么久，本身就很难得。

长期主义未必每一天都轰轰烈烈。它更像一场静默的信任投票。当众人的目光终于落过来，真正令人惊讶的，不是你出现过，而是你从未离开。
