# 从Boss直聘“捞”客户，一天20+高客单合作伙伴是怎么做到的？

大家好，我是亮仔。

之前我待过一家做AI的公司，产品本身不差，可流量问题一直卡脖子。那段时间我反复琢磨：目标用户到底在哪个池子里？后来我猛然想到——国内体量数一数二的招聘平台Boss直聘，上面全是招人的企业和找工作的个体，这不就是一个天然的精准流量池吗？

最开始，我的做法挺朴素：把那些可能成为合作伙伴或高客单客户的账号一个个找出来，再逐个去沟通。可试了几个之后，真心觉得人肉模式效率太低。仗着自己也算半个程序员，干脆写了一套RPA脚本，把这套沟通流程做成批量自动化操作。

跑起来之后，效果也很直接——每天能带来20多个高客单用户/合作伙伴。具体怎么设计、怎么落地，我都整理在下面的飞书文档里了，感兴趣的朋友可以直接打开看：
