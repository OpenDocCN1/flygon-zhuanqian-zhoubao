# 别再把人脉想成好友列表了，这其实是个误区

> 来源：[https://zx8am088wt.feishu.cn/docx/Icxedehb4oAbxXxJOmbcVdVFnAA](https://zx8am088wt.feishu.cn/docx/Icxedehb4oAbxXxJOmbcVdVFnAA)

人脉到底指什么？难道就是手机通讯录里那一长串名字？

在《非你莫属》里，就出现过一个年轻人，自称投资圈大半的人都在微信里，还开口要年薪160万以上，直接被现场群嘲。

[PRE0]

网络上常说一句“重要的不是你认识谁，而是谁认识你”。

说实话，这句话也没说透。真正关键的不是谁认识你，而是谁愿意为你出手。哪怕你有上万个弱联系，如果没人情愿帮你，一样等于零。

而别人愿不愿意帮你，取决于你能为他做什么。人脉的本质不是你能从谁那里得到什么，而是你能为谁创造价值。你能帮到谁，又取决于你的能力与价值。人脉的底层逻辑就是一场价值的互换，这就是我总结的人脉四步推演。

[PRE1]

# 01

在所有价值交换里，信息交换最核心。因为信息本身就是权力的来源。你在社会上能抓住多少机会，根本上由你所处的消息层级决定。

斯坦福大学的 Granovetter 也提到过，强者的社交方式，不是靠挤进某个圈子，而是能从多个不同的圈子里持续获取有效信息。

讲个李嘉诚和他的司机的旧事：

李嘉诚的司机给他开了三十多年车，临近退休准备离职。李嘉诚觉得他兢兢业业，想让退休生活更宽裕，就让秘书给了他一张200万的支票。

没料到司机婉拒了：“谢谢老板，真不用，我手上已经有一两千万了。”

李嘉诚很惊讶，问他月薪才五六千，怎么攒下这么多钱。

司机笑笑说：“您开车时在后座打电话，提到要买哪块地，我就跟着买一点；您说要买哪只股，我就照着买一点，时间一长就攒下来了。”

[PRE2]

这个故事说明：

人脉的真正价值，不在于直接给你钱，而在于给你稀缺、高质量的信息通道。

而这种信息，往往来自弱关系、来自非重复关系。

“非重复关系”这个词我是在成甲的《好好学习》里看到的。亲戚、同学、同事这类关系，彼此话题差不多，朋友圈也高度重合，信息基本是重复的，属于重复关系。

另一种关系，你和对方身处完全不同的圈层，社交网络互不相交，通过他你能触达一个陌生的世界，这种就是非重复关系。很多时候，正是非重复关系里藏着贵人。

[PRE3]

# 02

既然人脉本质是价值互换，那根基就在于你自身的能力与价值。不够硬，还想靠关系，根本站不稳。

人脉最有用的作用，是帮你把信息准确传递出去，和对的人达成共识。人脉背后还有一层意思：我只跟能听懂我的人来往。因为不同层次的人之间，沟通成本最高。同一句话，有人秒懂，有人却要愣半天。

想被听懂，就得主动升级自己。只有价值提升了，信息才流通。人脉若没有本事作为支撑去交换，最终只会沦为一个笑话。

把精力用在让自己更优秀，等你足够好，人脉自然会不请自来。

# 03

向上社交时，面对远比自己厉害的人，容易产生自卑。这里有两个实操方法，第一个是“跨界价值”。

对大咖要用跨界思维去影响他。术业有专攻，再厉害的人也不是全能的，你总有他需要、你擅长的领域。

像你是个旅游达人，他规划出行时自然会想到你。比如我现在会这样介绍自己：一个粉丝两万多的设计博主，并且坚持百天日更，分享成长与带娃经验。

给自己一个清晰的标签，最好能有数据背书，让对方一眼记住你的价值。终有一天会用得上。

# 04

第二个常被忽略的，是真诚与感恩。

《没有权威的影响力》作者艾伦·科恩说过：“很多人只盯着金钱、关系、技术、信息这些显性资源，却忽略了感恩、认可、声誉这些隐性收益。”

即使你位置更低，也能给对方带来比你想象中更多的价值。真诚的感谢本身就是一种高阶价值。

真诚没有捷径，真诚就是路。你读完牛人的书，听完讲座，认真分享你的收获和反馈，对方获得的满足感很大。很多大咖分享，本质上追求的是利他带来的成就感，像辉哥奇谈的辉哥，他自称布道者，每天日更解答问题，就是为了帮助人成长。这正印证了马斯洛理论中的尊重与自我实现需求。

情绪价值是最顶级的价值。能持续给到情绪价值，你就成了他的人。

[PRE4]

这里还有一个关键点，要注意“恩情折扣”。恩情会随着时间推移不断贬值，时间越久，打折越狠。

比如朋友帮你介绍工作，刚入职时你可能想拿一半工资报答。后来觉得能进来靠自己努力，工资也不够花，先生活，等以后升职再说。再后来，你只记得自己熬夜加班多辛苦，觉得这份工作是自己挣的。原本的恩情就被稀释成“过年拜个年”了。

如果没意识到恩情折扣，没及时回馈，一方觉得你忘恩负义，另一方觉得你小题大做。

无论对方需不需要，你的回报都应该让人惊喜愉悦。这为下一次互动埋下种子，也让你在对方心里留下“让人放心”的标签。回报之后，关系回到平等，不会再因为人情债而别扭。所以很多老江湖，临走都会让你带点东西回去。

[PRE5]

[PRE6]

总结一下：

* 人脉取决于你能帮到谁，归根结底是你的能力与价值。
* 人脉的核心是价值交换，而价值交换的核心是信息交换，尤其是稀缺的高质量信息。
* 即便你位置更低，也可以借助跨界思维和真诚感恩来经营关系，但一定要警惕恩情折扣，及时反馈与回馈。
* 最关键的，永远是让自己变得更好。

[PRE7]

最后，肯定有人会说，你又不是大咖，没什么牛人资源，凭什么讲人脉。

确实如此，我也没什么了不起。

梳理这些认知，只是想把自己和大家对人脉的理解理清，拆掉认知上的障碍。

认知决定行动，行动决定结果。人的大脑天然抗拒模糊的风险，只有当事情变得清晰、有意义时，才会主动去做。

如果这篇文章能帮你打破对人脉的误区，开始有意识地经营关系，那它就值了。

参考书目：蔡垒磊《认知突围》、张辉《人生护城河》、成甲《好好学习》等

愿你，遇见高质量的人脉。
