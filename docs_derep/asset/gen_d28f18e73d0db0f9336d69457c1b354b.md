## 5.公众号

公众号来的用户很精准，质量接近课程和投放来的用户，而且付费意愿明显。

想写出高阅读的文章，首先标题要让人有点击欲，又要贴合大众心理。很多人懒，我们可以利用这个特点。

建议重点做无人直播相关的主题。

# 五、朋友圈如何打造

## 1.朋友圈下钩子的小技巧

知识付费行业很难主动推销，如果不想干等用户上门，就要用各种理由去触达用户，但不直接卖产品，而是先给价值。
看这个朋友圈示例：
[PRE32]
这类分享都会提前预告。发朋友圈时别只发预告，可以在末尾加一句：想看的兄弟点个赞，我整理精华发大家。

一直关注你、想入局的人就会点赞，一点赞你就有理由去联系。
[PRE33]
把内容发给他，千万别推产品，而是说：兄弟我看你点赞了，这是你需要的精华，你看看有没有用。

他关注这个行业，说明有意向，后续自然会咨询。你可以闲聊共情，别提产品，一提就显得目的性强，人设会掉。

也可以把好资料更新到朋友圈，告诉用户想要的点赞我发你。用户点赞后私聊白嫖。先给后要，别总索取，要让用户感受到你的真诚。

通过点赞引流，是非常好的接触机会。记住永远别直接推产品，否则本末倒置。

不想被动等待，想主动出击，用这种方式既不掉人设，又能触达用户。只要你分享的是行业资料或精华，他点赞就说明在持续关注，想做这个行业。没兴趣的人不会要的。

以上是下钩子技巧。

# 六、关于朋友圈立人设

立人设有几个关键做法。

第一，晚上发一些对抖音、对行业的看法。发观点，不是为了100%认同，而是让用户知道你有思考、有判断。很多同行的朋友圈都是这种感悟，没灵感就搬运同行的观点。

别担心别人不认同，观点本就见仁见智，目的是展示你在思考。

第二，把别人给你发红包、夸你的截图发朋友圈。比如有人问你问题给你发红包，或在社群分享后有人拍一拍、说你牛逼，都可以晒出来。

当很多人拥护你、尊重你，用户潜意识里也会尊重你。好比你进新公司，发现全员都尊重主管，你自然也会跟着尊重。

思考+红包截图+认可截图，长期发，用户潜意识里就会觉得你很强。

人设立的好，高客单也觉得值；人设立不好，便宜也不信。知识付费没有标准定价，人设决定价格锚点。

# 七、给新人的一些建议

1.新人最焦虑流量，解决办法就是死磕内容。
2.焦虑能提升执行力，但过度焦虑会病急乱投医。
3.内容和朋友圈营销做起来，转化会慢慢提升。
4.别指望用户刚来就成交，心急吃不了热豆腐。
5.无论发生什么，心态要稳。
6.多学习，大佬也是从小白过来的。
