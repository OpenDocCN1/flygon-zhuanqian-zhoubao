# 把2024拆开来检视，用65道自问把自己过一遍

> 来源：[https://pznme756ly.feishu.cn/docx/Pk43do1PlopdqRxTqrzcVVMnnZd](https://pznme756ly.feishu.cn/docx/Pk43do1PlopdqRxTqrzcVVMnnZd)

十二月已经进入尾声，2024 快要收工，2025 正等在前面。

年末做总结，本质上是用一年为刻度做一次战略对齐。方向的选择，比单纯的努力更关键，我一直认可这一点。

回望今年，你把精力投进去了哪儿，换来怎样的产出，哪些决策值得保留，哪些需要止损。基于这些事实再去想明年想要什么，是冷静推演出来的目标，还是被焦虑裹挟的情绪冲动。怎么落地，怎么判断自己是否走在正轨上。

当选择、执行和状态都变得清晰，2025 自然会比2024 更顺畅。

《高效能人士的七个习惯》里提到，达成目标要经历两步：先在心里构建，再到现实中实现。只有先把一件事想透、想清楚，才可能逐步把想法执行到位。反之，行动很容易陷入犹豫、拖延、信心不足，最终不了了之。

做复盘时，我一直沿用一个抓手：身体、事业、关系。把这三块理顺，人生基本盘就稳了。

赚钱也绝不是只有获客、转化、笔记这些表面工作，底座是体能、关系、情绪、管理精力的综合能力。

基于这个思路，我把常用的复盘清单整理成了65个提问。每个板块我都花了一个多小时来沉淀思考，整体写下来一万多字。难度不小，但完成后的回馈感很强。

如果你也想认真做一次2024的年度盘点，可以直接沿用下面的65个提问。

# 1 2024身体回顾

1. 回顾全年，你对自身整体健康状态的满意度如何？
2. 今年是否生病？感冒发热等情况发生的次数和频率？
3. 平均多久做一次运动？每次持续多长时间？
4. 当前体重是多少？对照身高健康区间，你属于偏高、偏低还是正常？
5. 作息如何？平均几点入睡，几点起床？
6. 早上起床时，你是否感到神清气爽、精力充沛？若不是，你认为原因是什么？请至少写300字
7. 一天的饮食构成是怎样的？早餐午餐晚餐夜宵分别吃些什么？这个饮食模式对健康是助力还是拖累？为什么？写得详细一些
8. 今年是否做到每天饮水约4瓶矿泉水的量？
9. 今年情绪整体怎样？焦虑担忧愤怒挫败失落无助迷茫嫉妒内耗等负面情绪多久出现一次？通常在什么情境下被触发？
10. 情绪的好坏对健康、事业、亲密关系分别产生了哪些影响？请至少写300字

# 2 2025身体规划

1. 2025年对身体的整体期望是什么？
2. 明年是否需要调整饮食结构？如果要，如何调整？调整的理由是什么？
3. 2025年会为自己制定运动方案吗？频率、内容、时长各是多少？如何确保能坚持？
4. 明年想增重还是减重？目标体重是多少？为什么这个指标对你重要？
5. 作息需要改变吗？如果要，目标入睡和起床时间定在几点？打算用什么行动达成？
6. 怎样才能让2025每天醒来都精神饱满元气十足？请至少写300字
7. 明年打算用哪些具体做法提升饮水量？
8. 明年要做哪些调整，让情绪长期保持平稳、安宁、愉悦？

# 3 2024事业回顾

1. 今年主业发展的整体情况如何？
2. 今年收入是否达到预期？原因是什么？
3. 若未达预期，你认为最大的制约因素有哪些？请至少写500字，厘清原因才好解决问题
4. 这一年为赚钱你做了哪些具体事情？获得了哪些结果？结果不一定是现金，也可以是文章账号视频等，请至少写300字
5. 今年新掌握了哪些技能？有哪些客观事实证明你已熟练掌握，而非只了解方法？
6. 今年阅读了哪些书？
7. 今年累计输出了多少字？
8. 今年在知识付费上花费了多少钱？主要买了哪些？为什么付费？请至少写300字
9. 今年养成了哪些对赚钱有帮助的好习惯？为什么认为这些习惯关键？
10. 今年每天雷打不动坚持做的事有哪些？
11. 今年认知层面最大的突破是什么？
12. 今年行动层面最大的突破是什么？
13. 今年最大的教训是什么？
14. 今年勤奋程度自评几分？理由是什么？
15. 今年对赚钱这件事有哪些新的认识？
16. 今年对自己的信心是增强还是减弱？为什么？

# 4 2025事业规划

1. 2025年的收入目标具体定为多少？为什么定这个数字？
2. 达成目标，你觉得最大的难点在哪里？请至少写300字分析清楚
3. 你认为赚钱是单一驱动还是多维协同？为什么？
4. 影响你赚钱的因素有哪些？它们与收入的关系分别是什么？请至少写300字
5. 具备哪些知识技能习惯，就能让赚钱大概率成功？为什么？
6. 赚钱是靠长期积累还是学到方法就能快速见效？你的看法？
7. 坚持对赚钱重要吗？为什么？2025年你打算如何更好地坚持？
8. 勤奋对赚钱重要吗？为什么？2025年你打算如何做得更勤奋？
9. 情绪对赚钱重要吗？为什么？2025年你打算如何管理情绪？
10. 2025年要做哪些与2024完全不同的改变，才能得到不一样的回报？请至少写300字
11. 你相信2025年赚钱会比2024年做得更好吗？为什么？
12. 你需要做哪些事，才能对2025年的赚钱拥有120%的笃定？

# 5 2024关系回顾

1. 今年与父母视频电话沟通的频率如何？需要改变吗？为什么？
2. 今年与伴侣沟通的频率如何？需要改变吗？为什么？
3. 今年与伴侣发生过几次矛盾？起因是什么？如何化解？请至少写300字
4. 从这些矛盾中你学到了什么？请至少写300字
5. 经营好伴侣关系对你有哪些好处？请至少写300字
6. 经营不好伴侣关系会带来哪些负面影响？请至少写300字
7. 你认为经营好伴侣关系的核心是什么？
8. 今年多久拥抱一次伴侣？
9. 你是否每天会刻意赞美伴侣让他她开心？为什么？
10. 今年每周陪伴家人的时间大概有多少？
11. 今年给伴侣送了几次礼物？
12. 今年生日时，有多少人向你送上祝福？

# 6 2025关系规划

1. 2025年计划多久与父母联络一次？如何保证能做到？
2. 2025年计划多久与伴侣沟通一次？如何保证能做到？
3. 2025年计划每天赞美伴侣几次？如何保证能做到？
4. 2025年要做哪些改变，能让与伴侣的矛盾减少80%？为什么？
5. 2025年计划每天拥抱伴侣几次？分别在什么时段？
6. 2025年计划每周陪家人多久？具体安排在什么时候？
7. 2025年计划给伴侣送几次礼物？分别在什么时间点？

# 7 把复盘写成文章

把上面六个板块串联起来，就能形成一篇完整的高质量年终总结。

建议这样组织：

1. 用小标题区分六个模块
2. 写一个有代入感的开头
3. 写一个有力量的结尾
4. 给文章起一个吸引人的标题

这四项需要你自行完成。

最后祝愿大家把2024年的每一段经历沉淀为资产，助力你在2025年走得更稳、收获更多。
