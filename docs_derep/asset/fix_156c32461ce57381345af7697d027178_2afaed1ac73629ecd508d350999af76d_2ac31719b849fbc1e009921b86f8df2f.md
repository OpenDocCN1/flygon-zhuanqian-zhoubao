# 八个账号沉没后，我才看懂生财真正给了我什么

> 原文：[`www.yuque.com/for_lazy/thfiu8/fie2gzn9v7ai4rcs`](https://www.yuque.com/for_lazy/thfiu8/fie2gzn9v7ai4rcs)

新一季的小航海再度启航，又一波新手登船。海上既有好看的风景，也有让人措手不及的浪。

出发之前，我把自己把八个号全部搞垮的复盘整理出来，给后来人一份避坑记录。

阅读后大概能带走这三点体会：

1. 我几乎把初入自媒体会犯的典型错误都遍历了一遍。若你是刚入门的创作者，可以把我的经历当成反面教材，绕开这些雷区，上手概率会显著提升。
2. 明明把号做没了，我却愿意公开讲出来，还因此吃到分享带来的正向反馈，这就是生财独特的底气。希望大家对挫败更有钝感，多说出来，多参与线上线下交流。
3. 八扇门被关上后，真正契合的那扇门才被推开。经历一通磕绊后学会调频、学会敞开，愿意接纳高手的点醒，方向自然就对了。

先感谢生财里每一个陪我走过的人。

为什么连废八个号我还能继续？因为生财的创始者氛围太扎实。它拓宽了我的视野，也把格局拉开。

这篇文字能成型，要感谢 2023 年 3 月的生财全国盛会，以及之后几场线下小聚。在刘得意姐姐牵头的局里，一群价值观相近的人形成了很强的场，我才敢彻底摊开自己。讲的人和自己和解了，听的人也给了最大的托底。

聚会现场合照

盛会结束后，我又参加了一场线下交流，认识了将近百位同路创业者。

正因敢于分享，我被看见。有经验的前辈给了我最关键的提示。高翔老师帮我梳理资源后问我：你分明是韩信，为何要去当敢死队？

这一问点醒了我。在八次失败的反复里，在分享带来的贵人指点里，我终于厘清方向：帮家族的功能性食品企业做线上化。

父辈起家于实体领域，手里握着一家功能性食品相关公司。资质涵盖婴幼儿辅食、婴幼儿营养包特膳、孕妇乳母营养包特膳、固体饮料、其他饮料、方便食品等六项生产许可。厂房面积八千平米，单班产能可达四亿，获评国家级高新技术企业和江西省专精特新企业。拥有脾多肽、脑多肽生产线，可生产听装、袋装、盒装固态产品以及液体小袋装产品。

当下我的创业选型就是把家里这块业务做大做强，目前在摸索口服美容赛道，品质有保障，背书有多项国家发明专利。

若你手上有微商、直播电商等渠道，欢迎沟通。若有口服美容品、功能性食品的代工需求，例如胶原蛋白肽、补血口服液、婴幼儿米粉、婴儿或孕妇营养包等，也欢迎联系。我们曾为国药、仁和、白云山等知名品牌提供代工服务。

失败有时正是更大成功的前奏。
