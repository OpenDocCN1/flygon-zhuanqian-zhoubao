## 一、插件安装

先说说安装。常规思路：打开谷歌浏览器，点右上角的拼图图标，进入“管理扩展程序”，在菜单底部打开Chrome应用商店，然后搜索想要的插件。快捷方式：直接把插件链接复制到浏览器打开，点“添加到Chrome”。文件里已经准备了所有快速链接，复制到浏览器就能添加。[PRE5][PRE6][PRE7][PRE8]

HARPA AI打开网页后，点“添加至Chrome”即可自动安装。[PRE9]

## 二、HARPA AI插件怎么用

### 1. 唤醒插件
装好HARPA后，打开谷歌浏览器，右上角能看到它的图标。[PRE10]
点击图标，会弹出对话框。注意：需要开启全局魔法，并登录GPT账号或添加API。[PRE11]

### 2. 基础设置

#### 第一步：改语言
进入设置，在“preferred chat language”处选择custom，然后在custom language里填Chinese，这样插件回复就会变成中文。[PRE12][PRE13]

#### 第二步：选GPT模型
在“openai connection type”里选择调用方式。
如果用“Browser session 浏览器会话”选项，插件会自动识别已登录的GPT账号，并根据账号类型给出可选模型。比如Plus会员就能选GPT4。
另一个选项是“OpenAI API key”，点进去输入API密钥后就能调用。[PRE14][PRE15][PRE16]

### 3. 功能用法
唤醒后，可以调用内置的100+快捷命令。本文主要讲三个：/summary、/todo和自助问答。
/summary用于总结网页文章内容；/todo用于列出文章中的待办行动；自助问答则是基于文章内容提问，界面直接回答。[PRE17]
