# 坐在观摩席上的我，七天吸粉十万、入账五万

进生财三年，今日才动笔写下第一篇。十月将尽，别人早早上岸，我这才脚尖沾水。这一期我挑了三个任务：个人IP孵化、共读打卡、视频号带货。真到验收时才发笑——最上心的IP课，全网只有一百来个关注，带来四千收入；共读顺当；反倒是没空管的视频号，从十月廿八日启航，四路账户跑到十一月七日，利润已破五万。

说起来路，我在北京待了十年，最后坐到哪里？一座真冰场的区域负责人。冬奥吉祥物发布会的整台节目由我盯，又受奥组委之托赴美处理过归化队员的事务——我这一路负责的朱易没能闪亮，另一组带回来的谷爱凌倒是光芒耀眼。一九年来到杭州，投奔老友直浪，潜心研修电商。此后自营抖音直播，把外界传来的野路数都试了个遍，始终没打出水花。直到听了水松张阳的课，才算拨开迷雾。二〇年起自己的盘子稳定，做起了代运营和陪伴式服务，项目多到忙不过来。二一年摊子铺得太大，赔了个干净。如今这行能活的，要么握有优质货盘，要么背后站着肯分肉的金主，当年我压根没想通。眼下项目全停，回到长沙，偶尔接点代运营，寻找下一程。

登船前我把所有事务都摁了暂停，打算闭门一个月。可前二十天精力几乎被IP号吸干，视频号带货自然而然落成“围观”身份。偏偏是这个身份，让我放低了预期，反而腾挪得开。

拿到任务包后，我把群里的信息从头到尾捋了一遍，配套手册反复咀嚼，站内搜“视频号”更是翻了个底朝天。盗坤、文林等前辈的帖子，每篇都读了不下五遍。那些经验，每次重读都能咂出新味。

多方信息拼下来，一个现实浮出水面：自七月起，不少资深玩家纷纷抱怨收入缩水，搬运号被平台重点盯防。这玩意的本质，说白了就是把他处的素材搬进视频号，用流量换成交。收入下滑的原因，一是涌入者过多，带货视频泛滥；二是官方清剿搬运，不少号被判零播。顺着这个逻辑，我断定大路太挤，得找缝隙。

我们所在的视频号带货二组，赚到钱的船友不少，但多数像走了一回运，爆完就静默。大部分人都围着选品、搬运、堆量绕圈，靠数量赌概率，前期确实能见钱，后期却扎堆死掉。前辈盗坤有个比喻很扎心：都是同一个池塘捞鱼，人家在船上使大网，你还站在岸边舞竹竿。这次航海按上千人算，每人五个号、每号十条商品片，塘里就得添五万条雷同内容。这等烈度，孤胆英雄根本玩不转。所以，我换了个没人挤的方向。

我的路线是：别人拼货，我拼人群；别人硬搬，我重组素材。一共布下四路账户：A对准刚毕业的大学生和白领，二十到三十岁，爱面子却兜里紧；B喂给三十五到四十五岁，专钩八九十年代的旧时光；C锁定五十岁往上的阿姨，用亲情戳心；D是常规卖货号。A和B两天越过百万播放，七天冲到千万级，真正进账是五号六号开始，两路合计两万多；C更猛，第三天破千万，第五天单日四千万，七天破亿，六号首播，到手近三万；D发了二十多条没动静，其他号都已打通，自然被晾在一边。算下来，粉丝涨了约有十万，利润妥妥过五万，而且还在慢慢涨。

用一组代码来总结我的战果，大概是这样的：

```python
channels = {
    "A/B": {"views": 20_000_000, "profit": 20_000},
    "C":   {"views": 100_000_000, "profit": 30_000},
    "D":   {"views": 0, "profit": 0}
}
tot_views = sum(v["views"] for v in channels.values())
tot_profit = sum(v["profit"] for v in channels.values())
print(f"总播放: {tot_views:,}  总利润: {tot_profit:,}")
```

这套聚焦人群的玩法，我把内容拆成四个字：共情、有趣、有用、新奇。

共情，就是让观众看见自己。悲欢忧喜，每一种情绪都能按年龄、性别、阶层再切开：孩童的闹腾、青年的愤懑、中年的重负、老年的落寞，甚至有钱人的倦和穷人的慌，条条都够做一个号。

有趣，源于反差。白发老人板着脸讲一句俏皮话，或是本正经的实验室冒出怪诞结果，都容易让人停下手指。

有用，则是给出实实在在的价值。教人做一道菜、讲透一个Excel技巧、解一道电工迷题，时间没有白费，观众自然愿意关注。

新奇，靠的是信息差。北方的朋友认不出酸角糕，南方的花友没见过彼岸花盆栽，这些罕见货，天然自带话题。

四个维度往下蔓延，分支何止上千。新手最容易栽在“贪多”上，恨不得一个号囊括所有，结果哪个都没立住。其实，只要卯住一个分支，就能撑起一片天。

再说重组。先锚定人群，再把抖音、快手、优酷、知乎、小红书甚至海外短视频都当原料库。我手中那份课程笔记里的思维导图，刚好用上了：顺着导图拆解，爆款总归有迹可循。我们要做的并非凭空创造，而是把原料拆散，再按平台脾性重组，形成自己的调性。持续做出四五十条后，你会留意到，有些没被热门选中的片子，画面或音乐其实很出色。脑子里自动会跳出拼接方案，那便是手感。手感急不来，我在抖音踩坑多年才攒下一点。不必焦躁，每天拆一段，时间会给你答案。

案例起来后，来问方法的人不少。我却发现一个陷阱：部分人对内容理解很深，却想得太多——情感号靠什么赚钱、万一效果不好怎么办、资源如何全部押上，这些远处的困难成了心里的石头。反倒是没想那么多的朋友，干起来反而快。我赶走内耗的手段很简单：第一条，想知道赛道怎么变现，就去把对标账号的变现路径摸清，照着抄；第二条，不反复刷后台。我设的规矩是：每号每天至少十条，一天只看一次数据，用来琢磨这边观众爱什么。抖音上爆火的视频，换到视频号里未必灵光。

账号起飞后，我亲自播了三天，讲真，一坐下来就是钱，一小时几千块，很容易沉迷。但我明白，如果整天开着直播，内容就会断供，流量终将被耗尽。况且三路号同时热，我只来得及守住数据最好的那头。到第四天播放滑到两千万，我也把直播收缩到三小时。就在这时，广州一伙做直播的人找到我，他们正照着我的路子复制；长沙、北京、广州、云南都已有人动手，真够卷。我索性把模仿者都加了微信，聊着聊着就成了队友。以前想过招主播，可好主播贵、账号寿命说不准、培养周期长。碰巧基地有主播和供应链，我便提出：账号交给他们播，出货走对方的链路，我只管流量，按比例抽成。成本降下来了，我也不用绑在镜头前。试用合同第五天就签，十号已经连着播了三天，躺着进账。

今后的方向也清晰了：专注内容与流量，把号养成熟，再找同路人扩量，成熟后送到基地去通宵播。帮基地作出可复制的视频号样板，然后手拉手去找商家。当年盲目扩张代运营团队，栽得鼻青脸肿，这次绝不再犯。寒风天里，借一把力，做一个冷暖自知的个体户，挺好。

最后，给那些还在泥里挣扎的朋友一句：视频号的红利没有退潮，别急着散场。我一个坐冷板凳的都能冒出头，你也行。找到一个细分人群，沉下心拆解，哪怕只钻出一条小缝，这个冬天，也够你烤火了。
