# 三步AI流：把一首古诗变成一条有质感的短视频

作者：云珞 YunL ｜ 2025-02-28 ｜ 47赞

想做古诗词主题的视频，但卡在立意、画面和后期上？其实一套AI组合就能通关。

我最近梳理了一套从0到1的实操路径，全程只用3个工具就能跑通：

**第一步，用 DeepSeek 定调找灵感**
先把一首古诗丢进去，让它帮你提炼核心意象、意境关键词和可视觉化的画面点。拿到精准的关键词后，后续的画面创作就不会跑偏。

**第二步，用即梦一键出图出片**
把DeepSeek提炼好的关键词喂给即梦，直接生成契合诗意的AI图片和动态视频素材。山水、人物、意象都能一键成片，省去找素材的时间成本。

**第三步，用剪映做成型**
素材有了就交给剪映收尾。加上合适的古风BGM，配上拼音字幕提升可读性，再加点转场特效和氛围感调色，成片质感直接拉满。

关键词提取、画面生成、剪辑包装，三件套衔接起来，古诗词视频的整个生产链条就闭环了。
