## 2.1 先把概念搞清楚

Kimi 的输出结果

以下是飞书多维表格中相关名词的大白话解释：

数据表
数据表是飞书多维表格中用来存储数据的表格，可以理解为一个容器，用来存放各种数据。比如你有一个“任务管理”的多维表格，你可以在里面创建一个“任务详情”的数据表，用来记录每个任务的具体信息，如任务名称、负责人、截止日期等。

视图
视图是数据的展示形式，基于同一份数据可以生成不同的视图，每个视图可以有不同的展示方式和筛选条件。比如在“任务详情”数据表中，你可以创建一个“进行中任务”的视图，只显示当前正在进行的任务；还可以创建一个“已完成任务”的视图，只显示已经完成的任务。

记录
记录是多维表格中的行，每一行代表一条完整的数据。比如在“任务详情”数据表中，每一行就是一个任务的记录，包含了任务的名称、负责人、截止日期等信息。

字段
字段是多维表格中的列，每一列代表一个数据项。比如在“任务详情”数据表中，可以有“任务名称”、“负责人”、“截止日期”等字段，每个字段都有自己的数据类型，如文本、日期、人员等。

获取数据表ID
打开你的多维表格，找到数据表的链接，链接中会有一个 table= 后面跟着的一串字符，这就是数据表ID。例如，链接 https://xxxxxxxxxx.feishu.cn/base/PtRdbPjCFa5Og5sry0lcD1yPnKg?table=tblVBqxDbGXOJZPv 中的 tblVBqxDbGXOJZPv 就是数据表ID。

获取视图ID
同样打开你的多维表格，找到视图的链接，链接中会有一个 view= 后面跟着的一串字符，这就是视图ID。例如，链接 https://xxxxxxxxxx.feishu.cn/base/PtRdbPjCFa5Og5sry0lcD1yPnKg?table=tblVBqxDbGXOJZPv&view=vewjgHC22S 中的 vewjgHC22S 就是视图ID。

因为提示词里限定了来源是官方文档，所以结果很准，能直接用。

看完后我理清了：

*   数据表 ≈ Excel 的 Sheet
*   视图 ≈ 不同展示方式的页面
*   记录 ≈ Excel 的 行，但没有行号概念
*   字段 ≈ Excel 的 列

为了更清晰，我还让 Kimi 生成了一张对照表供参考：

显然我还没搞懂鉴权逻辑。

## 2.3 看影刀学习中心

影刀对官方指令都有使用说明，我点进【建立多维表格连接】看了下需要填什么。

建立多维表格连接的文档：建立表格连接 - 影刀帮助中心

[PRE14]

看完才明白：网页端直接读写和用影刀调用 API 是两回事，后者需要先拿 token 鉴权。

不同的是，飞书不是给每个表格单独配 token，而是先建一个应用，给应用统一配置权限，再把要操作的多维表格拉进这个应用里。开发者通过 API 操控表格。

[PRE15]

这就好比小区门禁：先办小区门禁卡刷进小区，再用家门钥匙开门。一个应用 = 一张能进小区的卡，配好权限后可以管理多个表格，不用每个表格单独配卡。

完整鉴权流程：

1.  创建应用
1.  申请 API 权限
1.  访问多维表格资源
1.  调试接口（影刀已包）
1.  事件订阅（影刀已包）
1.  日志检索（影刀已包）

[PRE16]

一个应用可以链接多个表格，省心很多。

## 2.4 动手配置飞书多维表格

概念捋顺、教程看完，该实操了。实践出真知，遗漏也只能动手才发现。

### 2.4.1 新建企业应用

想让影刀 RPA 操控飞书多维表格，第一步是创建企业应用，相当于去物业办门禁卡。

登陆飞书开发者后台：开发者后台 - 飞书开放平台

[PRE17]

建完应用后，影刀需要的【应用 ID】和【应用 secret】就有了，飞书里叫【app ID】和【app Secret】。

页面会提示应用未发布，目前配置不生效。

[PRE18]

[PRE19]

新建的应用默认无权限，需要先配置权限再发布才能用。相当于门禁卡还没激活。

### 2.4.2 配置应用权限

我们要的是影刀能读写多维表格，所以给应用开通【多维表格】全量权限。顺便也可以一起配上电子表格权限。

路径：【权限管理】-【开通权限】-【多维表格】-全选-【确认开通权限】

[PRE20]

### 2.4.3 发布版本

配好权限后发布应用。现在基本免审核，保存提交即可生效。

（框住处按页面提示填写）

[PRE21]

注意：这一步只是给应用配了权限，应用和目标多维表格还没关联。下一步要把表格加进应用里，才能让影刀控制它。

### 2.4.4 配置多维表格

回到要操作的多维表格，点击右上角【...】-【更多】-【添加文档应用】

[PRE22]

搜索刚建好的企业应用加入，可选【可编辑】或【可管理】。

区别是：可管理能邀请协作者，可编辑只能增删改内容。我一般选可编辑，API 权限就够了。

[PRE23]

[PRE24]

点【添加】就完成建联。

到这里你可能觉得结束了，其实还没。因为一个多维表格里可以有多个数据表，每个数据表又有多个视图。自动化时，必须让机器人准确定位到正确的数据表/视图，再去增删内容。
