# 10分钟就能搞定上万张图！一键生成4/9宫格的RPA自动化方案，效率直接翻倍

> 来源：[https://kwut14otear.feishu.cn/docx/A6BodL8NkoxMdAxgaHVcGHFcnhd](https://kwut14otear.feishu.cn/docx/A6BodL8NkoxMdAxgaHVcGHFcnhd)

**一、这个工具在做什么**

产品名称：免PS批量生成4宫格/9宫格海报的RPA自动化机器人

主要功能：

1. 从你指定的素材目录里自动随机抓取图片
2. 一键拼合成4宫格或9宫格的矩阵图，特别适合做自媒体多账号内容配图
3. 把原本需要人工PS的操作全自动化，省人工、省时间

**二、开始前需要准备什么**

核心软件：影刀RPA
官方地址：www.yingdao.com

**三、操作步骤全流程**

1. 指定好存放原图的素材文件夹路径
2. 选择想要的拼图规格，4宫格还是9宫格
3. 点击运行合成任务
4. 机器人自动完成抽图和拼接
5. 预览结果后导出成品图即可发布
