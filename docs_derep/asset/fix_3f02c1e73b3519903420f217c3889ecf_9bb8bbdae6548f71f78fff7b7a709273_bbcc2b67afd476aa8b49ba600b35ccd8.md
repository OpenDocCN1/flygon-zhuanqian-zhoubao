这期间，我和300多位伙伴不断答疑、交互，也翻了几百上千个对标文章与账号，慢慢摸出规律：那些容易爆、出单好的内容，基本都满足5个条件——

1. 首图够吸睛
2. 标题有套路
3. 正文“干湿结合”
4. 商品关联度高、满足及时需求、价格实惠
5. 排版清爽、有表情、分好段

下面挨个展开。

一、图片是门面

公众号爆文的逻辑在小绿书同样成立：在你点进内容之前，能感知到的只有图和标题。而小绿书是上图下文，图片比文字更关键，尤其第一张图。润宇老师做过一期关于“微信大力推广图文带货”的分享，里面有四个信息值得留意：

1. 小绿书可以用量对抗概率。
2. 首图要不断优化。当下机制里，一个号通常能拿到100～200的初始曝光，但这个数字不等于阅读量——头图太糊太丑，流量直接浪费。[PRE0] 我有一篇就是个反面教材：初始曝光2000多，点击只有22，问题就出在首图。[PRE1] 它清晰度不够，直接影响点击率。

3. 完读率很重要。做过公众号爆文的人都知道完读率的分量，小绿书也不例外。因为图文篇幅不长，完读率尽量做到40%～50%以上。怎么拉高？控制篇幅。如果只放一张图，正文控制在10～500字就好，最好别超过800字。它是图文，不是文章，写太长没人有耐心看完。另外，我们测试时发现，有人在正文里每隔两三段就插一个商品图，为了多卖货，结果非常影响观感，得不偿失。

4. 平均停留时长。大爆款普遍能做到平均停留1分钟以上。有个小技巧：在首图和其他图片右下角加一句“向右滑，看更多精彩内容”，用这行字引导用户不断往下翻。

这四点都做到，接下来就看发布后的互动数据。小红书目前互动数据比较透明，小绿书还没完全公开，但可以参考这个公式：评论＞分享＞点赞＞在看。

二、标题怎么起

我总结了7类容易爆的标题：

1. 干货合集类，比如《【减脂秘籍】一周不重样》；[PRE2]

2. 猎奇类，比如《我独创的拌饭，美味到让人热泪盈眶！》《👀宝子们快来看！怎么看出来一个女孩很聪明呢？》《女人非常傻的8个行为，你占了几个？》；

3. 戳痛点类，比如《让大脑变笨的行为，你中了几招？》《妈妈必看：再不追高，孩子身高就耽误了！！！》《入秋后掉发多的姐妹，试试这个！！》；

4. 符合懒人心理类，比如《5分钟搞定孩子营养早餐》《万能和面公式：有了这个，不会和面都不再是难题》《我愿称它为懒人早餐天花板！！！！》；

5. 利益挂钩类，比如《坚决不删！重度黄脸18个冷知识！不看亏大了》《长期坚持跳绳的隐性成本》《你的转运珠戴对了吗？自查❗❗别戴来霉运❗》；

6. 反差类，比如《竟然被我妈种草！！几十块就养出来初恋脸！！》；

7. 名人效应类，比如《董宇辉推荐的神奇背书7步法》。

三、正文要“干湿结合”

一篇好的小绿书笔记，需要干货和情绪兼具。对我们创作者来说，不能只赚阅读不赚钱，也不能只出单没内容。我总结了一套正文结构公式：

开头用金句、痛点或故事切入；中间给实打实的干货；结尾回到“我”的视角做走心分享，再点出产品对你的帮助。

那怎么用AI辅助写正文？

野路子版（新手推荐）：复制小红书爆款笔记的正文，丢给AI，然后下指令——“把以下内容换种风格表达出来，顺带加点表情、排版：……”（省略号就是你想让它模仿的内容）。我用文心一言免费版试过，效果长这样：[PRE4]

自用版（我用的是文心一言APP）：提示词大概是——帮我写一条卖跳绳的营销文案，切入点以用户痛点为切入口，比如减肥、瘦大腿、瘦腰，写600字左右。要求：
1. 开头用金句/故事/痛点切入；
2. 文风亲切、利他、口语化；
3. 给到具体实操性强的建议，分点说；
4. 最好有详细数据支撑；
5. 结尾以“我”的体验分享引导下单，但话术看起来要利他；
6. 不说假大空的话，用户痛点要足够真实，让人看完觉得“就是这样”“你能理解我”“这篇有收藏价值”“我需要这个商品”。

口令思路，就三个词：身份设定+字数控制+具体要求。

身份设定可以多给几个，避免它天马行空。我一般给2～3个身份，比如：假设你是一个有10年营销软文经验的大师，深谙用户心理，擅长用通俗易懂的文字写出效果很好的种草文。

字数控制是为了不让内容超篇幅或太少。小绿书我一般设在800字以内，太短它不能满足要求，太长又影响完读率。

具体要求则因需而变，要根据初版提示词生成的效果逐步迭代。一般不少于5个点，可以包括语言风格（口语化、通俗易懂、接地气）、内容风格（亲切、严谨、专业）、举例等等。

四、选品决定出单

实操下来发现，商品对出单的影响很大。满足这三点的品，出单量普遍更好：

1. 商品关联度高。我们有伙伴阅读量快上万了，一单没出；也有伙伴10个阅读就出1单。不全是运气，细节很关键。比如有伙伴写减肥、跳绳相关的内容，首图也吸引人，但带的商品是“中学生跳绳”——看文章的人根本不买账。换成成年人的跳绳，出单率可能就完全不一样。别挂羊头卖狗肉。

2. 满足及时需求。什么是及时需求？就是看完当下就想要、马上想买。比如跳绳、招财类的东西，看完觉得“我现在就需要”，于是下单。总有人问我为什么不上书籍类？书籍竞争太激烈：可替代选项多，拼多多能买、微信读书能看免费电子版；且人群不一定精准——小绿书刚出，用户画像还没稳定。爸妈那一代看到书籍类文章，很多不爱看书，远不如“红薯”“调料”这类生活品冲击大。

3. 物美价廉。越越也提过，客单价不超过100元的品比较好卖。我们自己测下来同样如此：价格便宜、东西实用，出单就是快。

五、排版是颜面

小绿书目前功能还比较粗糙，不能像长文那样加粗、改颜色、调字号。但用心的人照样能排得好看。

1. 分段：电脑上1～2行为一段，手机上1～3行为一段，顶多别超4行，不然密密麻麻，观感很差。
2. 适度加表情。不知道加什么，就让AI帮你：“帮我把这段话适当加点表情进去，好看点。”
3. 重点内容用【】框出来。

六、新人最容易踩的8个坑

真没想到，新人的踩坑方式能这么千奇百怪（笑）。下面这8个，是最近交流中高频出现的问题：

1. 为什么我的标题显示“分享图片”？[PRE7] 别人有图有标题，我的图比例不对、标题也没了。原因很简单：没填标题，图片比例也没选。怎么填？手机下载“订阅号助手”APP→发表→图片·文字→填写标题和正文。[PRE8]

2. 图片要用商品图吗？不是。小绿书带货和淘宝有本质区别——它不是直接卖产品，而是用户通过图文觉得有价值，顺手点了你带的商品。所以图片尽量用同行的图，去水印、增强清晰度；或者去小红书搜你想带商品的爆款笔记，抄爆款的图，而不是商品图。

3. 怎么开通的不是橱窗，而是开了个小店？想做带货达人，正确流程是：开通橱窗→成为达人带货→选品中心选品上架。不是自己开店！怎么看有没有开错？去创作者中心的带货中心主页看，正常状态是这样显示：[PRE9] 如果误点了开店，页面会变成这样：[PRE10] 或者这样：[PRE11] 自己开店很麻烦：首先得有货源或厂家资质才能上架商品，而且很多品类需要额外资质，更重要的是，开店和达人带货不能并存——一旦开店，就没法正常带橱窗里的货。误开了怎么办？点开小店，终止开店流程或注销店铺，或者找带货中心客服协助处理。[PRE12]

4. 手机订阅号助手里怎么找不到插入商品的地方？先把光标点到正文中间位置，点“+”，在下拉菜单里看有没有“商品”，有就能插入。没有的话，就用电脑操作：①先找到小绿书入口页面；[PRE13] ②上传好图片、标题、内容，选择微信小店；[PRE14] 然后就可以开始带货了。[PRE15]

5. 文章发出去之后需要转发引流吗？不用。看自然流就行，一般不会那么快起量。

6. 带货文章写多少字合适？800字以内都行，建议10～600字。

7. 小绿书一天发几条比较好？目前不限制发文数量。一般一天至少1篇，1～5篇比较常见。我们自己的服务号，日更20篇上下。因人而异，想爆得快就多铺几条。

8. 小绿书一直没流量怎么办？先问问自己：发了多少篇？每篇有没有做到位？愿意投入多长时间？指望发完立刻见效，不适合做小绿书，大部分副业也不适合。快的话1～2天阅读量有明显提升，慢的话可能一周甚至更久都是0。如果一直是0，大概率属于“无脑操作”——标题没改就发，正文内容自己都不知道在讲什么，图片还是商品图。记住：模仿爆款来，不要自创。重要的话重复三遍：模仿爆款来，不要自创；模仿爆款来，不要自创；模仿爆款来，不要自创。模仿爆款的图片、标题，用AI改正文，自己再手动调一调，基本不会有大问题。
