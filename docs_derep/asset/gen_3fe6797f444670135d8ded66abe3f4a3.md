# 别人的故事，别去戳破

你有没有过这样的瞬间？看到身边某个人沉浸在自己编织的叙事里，明明知道那不是事实，却忍不住想捅破那层窗户纸。

打住。

王川的一句话值得细品：**为了不成为自己鄙视的那种人，要主动丰富和纠正自身的思维模型，但不要打扰别人心中的故事。**

说白了——对自己，要狠一点，不断重构认知框架，剔除偏见，修正逻辑；对别人，要温柔一点，允许他们活在自己的剧本里。

每个人心里都有一部“人生电影”，情节未必符合现实，但那是他的精神支柱、他的意义来源。你以为你在帮他看清真相，其实你只是在拆他的台。你以为你指出了逻辑漏洞，结果只是让他更难堪。

真正的成熟，是分得清“管好自己”和“管别人”的边界。自己的思维模型，该迭代就迭代，该推翻就推翻，别怕疼；别人心中的故事，只要不伤人不害己，就静静听着，别去打扰。

这个世界不缺拿着真理大棒的人，缺的是懂得把嘴巴闭上、把道理留给自己的人。

做一个对自己严格、对他人宽容的清醒者。别人的故事，让他讲完；你自己的思维，永远别停止升级。
