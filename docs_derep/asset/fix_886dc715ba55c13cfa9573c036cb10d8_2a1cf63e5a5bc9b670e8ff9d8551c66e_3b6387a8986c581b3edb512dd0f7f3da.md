### 2. 推广大使群怎么布置
拉新不能只靠主理人一个人，关键是让愿意帮忙的人清楚“做什么”和“拿什么”。大使群的置顶消息里，要把这两件事写明白。

你要做的事情：活动期间每天在个人号状态发布活动海报、训练营群二维码和个人专属邀请码，并配合群里的统一节奏；如果用户对产品感兴趣，可以直接推荐给主理人，成交后溯源分佣。

你能拿到的回报：动态奖励、邀新奖励、成交奖励三部分。
- 动态奖励：只要发了状态并截图到群里，每条发1.88元红包，每天发3轮；
- 邀新奖励：邀请5-10人送新手课，邀请50人、100人、200人分别对应不同金额红包、课程和社群席位；
- 成交奖励：推荐3单99元红包，5单199元，10单399元加课程名额，20单699元加更多名额和一次万人名片推荐。

注意：阶梯奖励不叠加，冲到更高档位会补差价。产品资料、海报、分销流程、状态文案都放进在线文档，有疑问直接在群里@运营团队。

## 四、几点提醒

1. 信任永远排第一位。别用轰炸式营销，真实故事和过硬专业能力最能打动人。
2. 紧迫感要设计到位：倒计时、名额限制、专属权益，样样都不能少。
3. 要有全链路意识。从引流、运营到成交，让后一环自然衔接前一环。
4. 付费找大使分发是增量打法。如果自己的流量池还不够大，不建议直接找专业团队做发售。发售本质是激活存量，不能凭空创造增量；想要增量，就要借助小大使的力量，付费或资源置换都可以。
5. 每次做完活动都要沉淀复盘。既能优化自己的流程，也能把经验变成内容，帮助更多人。
6. 用社群做发售涨粉很快、变现效率高、信任价值高，建议一年做3-5次，流量池增长会非常明显。
