# 启动内容创作之前，先把这几个问题想清楚

做内容不是上来就开写，先问清楚自己想得到什么样的反馈。

影响力的方向只能选一个，别想着既在小圈子里说一不二，又要让全网都认识你，这两种目标的打法完全不同。

动手之前，先搞明白你到底在解决一个什么样的问题。问题的体量，基本就决定了能触达多少人。

急着变现和想做长期影响，内容策略要分开。想快速变现，就做关联性强的干货，比如《小红书怎么快速涨粉》。想真正影响认知，就做关联性弱但穿透力强的东西，比如介绍卡尼曼的前景理论。

做内容的终点不是把一篇文章写得更漂亮，而是把一个品类做出来。做到最后，别人一提到这个赛道就想到你，像薛兆丰代表经济学，孟岩代表价值投资。

定价别只盯着便宜。关键是用户能否感知到真实价值，投入越大的人，往往越会持续关注你。
