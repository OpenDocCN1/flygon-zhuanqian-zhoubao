# 商标注册别卡在选类上｜1~26类白话速查，建议先收藏

第一次注册商标的人，十个里有八个不是被流程劝退，而是被"该选哪个类"劝退。翻开官方类目表，密密麻麻几百行，光看名字根本不知道自己的产品该往哪儿放。

其实这套分类没有想象中复杂。上手只需要搞懂三件事，剩下的就是对号入座。

## 选类之前，先想透这三件事

**第一，你的商标到底会出现在什么场景里？** 挂在实物商品的包装上，还是用在店铺门头、App页面这类服务场合？是纯线下，还是以电商、小程序为主？把使用场景定下来，再去框选类目——可以是一个，也可以是多个。

**第二，落到实际买卖的条目上。** 大类名称只是个目录索引，真正决定能否过关的，是你从这个类目里挑出来的具体商品或服务项目。卖灯的就找"灯泡"，做餐饮的就找对应餐饮项目，而不是把"照明"或"餐饮服务"这类大帽子扣上去。

**第三，顺手做一层防御布局。** 同一大类下，有些小组眼下用不上，但以后可能延伸，或者容易被别人蹭着打擦边球。预算允许的话，提前注册下来更稳妥。

## 一个最容易踩的坑

填报的时候，千万别把大类名称或类似群组标题直接当项目填。这两层都只是"目录"，不是可选的商品/服务项目。

举个例子：第11类的大类名称是"照明、加热、冷却、蒸汽发生、烹饪、干燥、通风、供水以及卫生用装置和设备"；1101群组的名称是"照明用设备、器具（不包括汽灯、油灯）"——这两行都不能直接勾选。真正能填进申请里的，是群组下一级的细项，比如该群组下的"灯泡"。
