# 一、投放不是万能的，打脸实录

## 1. 想用聚光投课程，结果被卡死

年底的时候我整理了一套培训课，原计划走小红书聚光投放获客。对我来说这是老本行，之前还发过一篇聚光投放的精华总结，自信满满。

结果投不了。聚光对赚钱、副业、医疗、教育、法律等类目审核极严，素材根本过不了。想硬投，就得把素材做得极其隐晦，转化率也随之暴跌。

投放这条路被堵死，只能另辟蹊径。

# 三、矩阵和投放是撬动客资的杠杆

好素材做出后，要让它被更多人看到。要么花钱投放，要么用矩阵号反复分发。我当然更喜欢投放，可惜投不了。

## 1. 囤设备、囤号、囤工具

我入手了一批手机，凑齐60台设备，配了60个小红书号，优先选港新号，便宜。花小几百买了个分发工具，能给笔记做降重后批量发出去。

把验证过的模板用工具推到60个号上。结果很惨：大部分账号0播放，投不了薯条，只有少数有微弱流量，能加到点微信。

时间是2025年1月11日。

## 2. 停更几天，发现了一个规律

年关业务忙，我搁置了几天，典型的“过完年再说”。

1月18号晚上刷发现页，偶然刷到那批之前零流量、投不了薯条的号发的内容竟然出现了。以为是巧合。

第二天1月19号，发现页一下子刷出20多个账号，都是1月11号那天批量发的号。微信新增也明显变多。之前零播放，现在有流量了。

为什么隔一周突然活了？

结合过往互联网风控经验，我推测这是小红书的业务安全风控机制在起作用。7天这个数字，很可能就是风控周期。

## 3. 问DeepSeek，做了对照实验

支点没问题，杠杆被风控卡住了。如果能摸清风控逻辑，就能绕过去。

我去问了DeepSeek。

[PRE5]

它也认同这个判断，还给了些常见的防风控建议，跟市面上的打粉教程大同小异。

我不喜欢用不可控变量的偶然现象做结论，所以做了对照实验。准备30台手机、30个账号，账号全是同一批香港新号，设备型号也一致。

分成三组，每组10台设备、10个账号：

1. 第一组：登录后什么都不做
2. 第二组：按常规养号流程操作
3. 第三组：登录后直接用批量工具发内容

7天后结果：

第一组放养，有流量 8个，无流量 2个
第二组养号，有流量 7个，无流量 3个
第三组直接发，有流量 7个，无流量 3个

结论很明显：小红书对新号的风控期基本是7天，7天内没触发明显异常，之后基本恢复正常。养号与否差别不大。

## 4. 其他风控点和规避思路

设备风控：
设备指纹：小红书会通过IMEI、MAC、系统版本、是否越狱等生成唯一指纹，多号关联易被限流。可用比特浏览器给每个账号开独立窗口，随机指纹。
设备黑名单：被封号的设备指纹会被标记。可刷机或修改IMEI、序列号规避。

IP与网络风控：
IP集中度检测：同一IP短时间内登录多号、批量发帖，会被判为机器行为。可用软路由分散IP、动态切换，模拟真实分布。
基站定位与GPS：平台可判断设备是否扎堆。可关闭定位，偶尔带手机外出走动。

账号行为风控：
内容相似度检测：批量分发易因文本、图片重复被判低质。建议新号注册后先放7天过风控再操作。
互动行为异常：点赞评论频率异常会被识别。脚本养号不如不养，真人刷太耗时，不如直接放着。

# 四、获客实操SOP

## 1. 准备清单

1. 手机设备：数量按需求定，注意别买被工作室玩废的二手号。常用红米9A、10A、K40，200-500元不等。
2. 软路由多台：拼多多性价比高，具体配置咨询客服。
[PRE6]
3. 比特浏览器，注册账号
4. 矩阵分发工具：核心功能是图片去重、标题文案AI改写、批量分发。市面很多，300-500元左右，自己找。

## 2. 打磨获客模板

内容是支点，先找同行表现好的笔记，拆解它击中了用户的哪个痛点、哪个爽点，照这个思路做出来，想不打动人难。

## 3. 配置软路由和比特浏览器

软路由相当于可换全国IP的路由器，用来规避IP集中度检测。买来客服会远程教学。
我一般一台WIFI连5台设备，选广东IP，离香港近，价格20-30元/个。

比特浏览器相当于多开浏览器工具，可给每个窗口单独配IP和设备指纹。
下载：https://www.bitbrowser.cn/
创建窗口后，账号平台选“其它”，URL填创作者中心登录页，其他随意。
代理设置里填IP，可用天翼云自建或直接购买，一个IP几块钱。5-10个号共用一个IP省成本。

## 4. 边操作边囤号

小红书对异常号有7天观察期。所以我一边用一批号发内容，一边屯新号放着，防止前面被封出现断层。

# 五、总结

1. 获客本质很简单：好广告素材+让目标用户看见。看见的方式可以是投放，可以是矩阵。阻碍都是可解的，限制都能绕，流量也能买。

2. 内容能力一定要练。支点稳了，杠杆才有用。
