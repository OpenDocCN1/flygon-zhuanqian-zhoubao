## 怎么找品？

我主要跑电子教程，找品就用三个办法。

一是到电商平台搜“教程”“课程”“视频”等字眼，把结果收好。

[PRE6]

然后去Baidu查这些词，看有没有竞对在投广告。比如PLC教程，现在就有竞对在打，这种就可以记下来。继续翻，能找出很多类似的。

[PRE7]

二是看店铺里的相关品。刚才说到的PLC教程，可以点进卖家主页，看看他还有其他什么货。

[PRE8]

这家店一共53个商品，逐个去Baidu查，只要有竞对投了，就记录。

[PRE9]

三是用5118挖词。这个站要会员，搜“教程”等词，导出词表。

[PRE10]

[PRE11]

我手上这份是之前导出的。把每个词复制到Baidu里搜一遍，有竞对就记下。像“魔法剪头发接吻”这种词，直接忽略。工作量确实大，但值得做的品基本都在里面。

这三种方式，放在实体商品和本地服务上也通用。

找出品后，按以下标准筛选：

1. 必须有竞对在投。广告有成本，一直投说明有回报，没人愿意长期亏钱。
2. 单件毛利300以上。比如奥数课卖398，扣掉包装2元、存储盘20、书20、快递18，毛利338，达标。Baidu广告一单可能要两百，毛利太低会亏。
3. 电商平台销量过30。看销量排行，是为了验证需求。销量高意味着要的人多，太低的不要碰。

[PRE12]

4. Baidu内部选词工具显示，周均搜索量过30。先在Baidu营销平台装好软件，用开户账号登录。

[PRE13]

进入这个软件后，找到“关键字”和“规划师”入口。

[PRE14]

填入“奥数”查一下，按从高到低把结果排好。

[PRE15]

显示“奥数”的周均搜索量是30，达标。搜索量越高，需求就越大。

[PRE16]

5. 竞对数量少于4。在Baidu搜“奥数课”，我看到3家在投，达标。竞对越少越好做。

前两条是硬指标，后面三条可以参考。当然全中更稳。

## 上线前的准备

品选好后，要配齐这些东西。

**广告账户**：去找开户商开通，开户费2400，淘宝上有。

**云主机**：我用的是景安云，1350元三年，2核CPU、2G内存、100G硬盘、4M带宽，淘宝也能买。

[PRE17]

买好后选系统，我用的CentOS 7.4 64位。填好密码、邮箱，继续。

[PRE18]

分配一个公网地址，确认，等几分钟就自动开通。

[PRE19]

云主机的信息会发到邮件里。

[PRE20]

接着装管理面板。到宝塔官网，下载远程终端。

[PRE21]

装完终端，启动它。

[PRE22]
