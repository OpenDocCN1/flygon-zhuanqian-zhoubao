# 一、如何打造个人IP

### 1.什么是个人IP

在我眼里，个人IP就是你在别人心里的标签。提到某个人，大家立刻知道他是哪个领域的高手。

比如：
周星驰——喜剧天才
成 龙——功夫巨星
亦 仁——生财有术创始人
杨 涛——生财全能大师兄

“某个领域的高手？我这么普通，估计没戏了，放弃吧。”

别急，千万别这么早否定自己。

如果你永远不跳出舒适区，就永远不会克服恐惧。路是给有信心的人准备的，你的自我否定，只会把真正的进步挡在门外。

再说抖音本来就是去中心化的，新人永远有机会获得流量。你回想一下，那些曾经的“超级网红”，现在多久没刷到了？

只要你还有持续学习的能力，你所在的每个细分领域、每个行业，都值得用个人IP再做一遍。

我观察了上百位素人博主，总结出两个最适合普通人的IP成长路径——不需要懂运营、不需要形象好，哪怕不出镜，也能成为一个被用户喜爱的IP。

### 2.普通人适合打造什么IP

**一、有一技之长的IP**

比如你做了10年房产中介，买房避坑的门道你门儿清。这件事本身就能做成内容——怎么过户给子女最划算？怎么一眼看出小区物业品质？这些都是实实在在帮用户解决问题。

我们不讲那些虚无缥缈的宏观经济学，只讲接地气的事，讲大家普遍遇到的生活难题。因为你有10年经验背书，因为你讲的是真话、是干货，用户自然会被你圈粉。

粉丝多了之后，线下付费咨询自然跑起来。甚至开发商也会找上门，想借助你的个人品牌影响力来做销售转化。

我们总感叹人生没机会，其实很多人缺的不是机会，而是能力。尤其在自媒体时代，有一技之长远胜几套房。个人IP还会为你在领域内的发展大大加分。

你可以把国货品牌在小红书、抖音、百度等渠道都搜出来，把它们的优缺点整理到表格里，再用口播或图文的形式做对比测评。有了粉丝之后，还会有厂家寄样品给你，内容反而更真实了。抖音和小红书上这类博主非常多。

如果你不知道自己的特长是什么，那就选择帮别人节省时间、避坑避雷吧。做着做着，这个领域也会变成你的专长。偶尔出一两条爆款，就是对你善意的回馈。

因为IP最大的势能，就是降低交易的决策成本。而赚钱的前提，恰恰是交易。

# 二、运营抖音的核心秘诀

### 1.模仿低粉爆款起号效率最快

这应该是大家最关心的部分。抖音起号真的是所有平台里比较难的，没有之一。

你可能看过很多短视频课程，学了不少运营技巧，可就是打不开流量的“阀门”。

下面这个方法，是我自己总结出来的，很早就在抖音分享过。相信并照做的人，八成都能涨粉过万。

简单说，就是去找最近新起的账号，尤其是1-2万粉丝那种。

大家都是新号起步，粉丝没粘性，主页也没太多播放量，制作也不复杂，就是靠一条或几条视频突然涨了几万粉。你蹭着对方的话题再去发一条，大概率也能爆一波，顺利给账号打上标签，拿到稳定流量。

我们教不同领域的学员起号，全靠这套“低粉爆款”理论，屡试不爽。当然，前提是作品的基础质量得过关，否则再好的技巧也没用。

怎么找对标账号这里就不展开说了，抖音上教的方法基本都靠谱，无非是持续搜集、整理、分析。

一年过去，现在项目拆解类账号已经很多了。有人纯抄袭，有人在模仿，大多都是从公域转私域变现，用户也慢慢接受了这种内容形式。

但请注意，模仿的只能是展现形式。如果连内容也一起抄，那这样的IP肯定走不远，平台也不会欢迎。当粉丝刷到你时，也会刷到我们，他们完全有能力分辨高下。

只有不断创造价值、推陈出新、打出差异化，才是打造IP影响力的最佳姿势。

这就是起号的第一个核心：去行业里找“低粉爆款”账号。小成功，才是成功之母。

这世界上聪明人太多了，作为新手，没必要事事都自己创新。

### 3.私域引流与防封指南

为什么我要把用户引到私域，而不是直接在抖音卖课？

很多博主都迷信粉丝量和播放量，我不看这些。我盯的指标只有一个：私域流量的增长。

抖音的粉丝说白了不完全属于你。平台一个不小心就给你限流甚至封号，你能带走吗？我自己就曾被封过2个号。

但私域不一样，它永远是你的。很多话可以放开说，还能随时触达用户。不管你做营销还是立人设，都没有问题。只要你持续传递正确有价值的信息，用户就会跟随你很久很久。

现在我的很多资料钩子、文案内容、案例素材，都是给大家免费用的。视频从来不加水印，随便哪个平台搬运都行。

领资料也不用加客服，不用觉得不好意思，直接回复关键词就能拿走。

这么看，是不是觉得我挺大方？

理由很简单：一个赛道的生态需要大家共同来建。

一条街上要有各种各样的店，需求才会被激活，市场才会热闹，大家才能都有钱赚。

而且这类东西根本禁不住，与其费心去堵，不如打打游戏。另外，对自身也是一种赋能。

但引流确实是个大问题。相信你也试过不少办法，不是被禁言就是被封号，经常让人崩溃。

下面分享我用了一年的“稳定引流”方式，包括渠道搭建，全盘托出。

引流：找到用户最大痛点→结尾设置关键词钩子→引导公众号回复领取部分→加客服领取完整版资料。
工具：我用的是商加加，大家去官网找客服咨询就行，他们会帮你搭引流卡片，比其他方式稳得多。

举个例子：

但只给其中一部分，这里再留一句话：

“视频素材太丰富，上传后总被和谐，请添加不讲李助理领取，扫码添加再免费赠送32个小项目玩法。”

至于为什么引到公众号而不是直接加微信，这属于我的历史遗留问题。

一开始就一个人、一个微信号，添加好友很容易异常，也没想到能这么快做起来，就用公众号做了中转。时间一长，用户也习惯了，就这么一直用下来。

其实直接加微信效果更好，这点大家不用学我。但公众号有两点好处：用户领资料方便；文章比视频更容易立住私域人设。

# 三、PPT视频制作方式

抖音上总有人私信我：李哥，你的PPT是用什么软件做的？剪辑有没有秘诀？包括前面“木子田”兄弟分享时，也有人评论问这个问题。

我其实不太明白这里面难在哪。就是把PPT录下来，再配上录音解说，真的就没了。

可能是有些人办公软件不熟练，不知道PPT怎么排版。这个建议直接百度一下，很快就能解决。

下面演示一下我的视频制作顺序。

### 1.选题+文案+配音

先去抖音刷刷最近大家关注的项目，高赞的都收藏一下。但其实生财的风向标和文章才是最好的选题来源，生财里高手太多了，对赚钱项目的敏感度，远超抖音上的很多大V。

就拿之前很火的短剧推广来说。无论你在抖音还是其他平台，看到这类项目信息后，就可以吸收内化成自己的选题。内容可以直接对着PPT口播，也可以写好稿子念。

想做不出镜IP的朋友，多少都有点不适合出镜的因素。

我做“不讲李的笔记”之前，一直在教育公司负责全媒体运营，让我直接出镜口播确实难为自己。所以我习惯先把内容写出来再录音，这样也方便调整结构。

### 2.短视频万能内容框架

“视频号带货新手，7天涨粉10W实操分享”
