# 一个人带娃还想有被动收入？这位全职宝妈在闲鱼卖虚拟资料，每月稳定爆单

为什么突然想分享这个？她说得很实在：在社群里待久了你会发现，真正的新手其实非常多，很多项目看着热闹，真上手了反馈慢、见效难，做着做着人就散了。可闲鱼不一样，它对新手特别友好，门槛低、操作简单、出单快，很容易给人正反馈。

她特别建议那些刚起步的小白，想找练手项目，完全可以拿闲鱼试试。先尝到甜头，有了信心，才更有底气在副业这条路上走下去。
