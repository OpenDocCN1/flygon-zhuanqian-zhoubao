### 1、为什么做这个网站？

在出海工具站的航海过程中，我了解到了SEO获取流量的逻辑。大致思路是：先找低竞争、有搜索量的关键词，搞清楚词背后的用户需求，然后围绕这个需求建站，慢慢优化排名，最后从谷歌获取免费流量。

#### 找词

怎么找词？可以用词根去扩展。比如“generator”就是一个典型的词根，背后对应的是用户的工具需求。国外用户想生成二维码，会搜“qr code generator”；想给娃取名，会搜“name generator”。类似的词根还有Creator、Guide、Maker、Editor等等。平时可以多收集这类词根，积累自己的词库。

有了词根以后，我会去谷歌趋势里看看，哪些衍生词最近在飙升，从中挑出有潜力的词。

#### 筛词

我在“generator”词根下发现了“ai answer generator”近期流量在上涨。但拿它跟gpts对比了一下，判断这个词的日搜索量大概只有500左右，不算大。

这里分享一个判断流量的方法：在谷歌趋势里，把目标词和gpts放在一起对比。gpts的日UV大概是2500，如果目标词的趋势量级是gpts的2倍，那它的日UV大约就是5000。从截图能看到，“ai answer generator”的量级只有gpts的五分之一。

[PRE3]

虽然这个词量级不大，但当时作为新手，我的想法很简单：先找个词练手。小词竞争小，适合新手。于是我用ahrefs查了下这个词的难度，果然很低，只需要4个外链就能排到前10。

[PRE4]

工具地址放在这儿：

ahrefs：https://ahrefs.com/keyword-difficulty

这个词对新手来说简直完美。不过当时我还不知道这个词背后的需求是什么，技术实现难度大不大。

于是我去Google搜了一下这个词，发现排名前4的网站里，只有1个网站是专门用首页来做这个词的，其他几个都只是把相关功能放在子页面，并不是他们的主营业务。那我用整个站来打这个词，就很有竞争力。

接着我点开排名第一的网站，发现这个词背后的需求是帮用户解答问题，完全可以用AI实现。我去问Claude怎么在网站里集成AI问答，得到的答案是：对接API接口就行，而且有免费方案。

[PRE5]

到这里，我的判断是：这个词流量不算大，但难度低、竞争小、实现也不难，成本几乎为零。那就用它来练手吧。

### 2、找到对标并分析

#### 功能分析

我的对标就是这个词在Google搜索下排名前2的网站。就像亦仁说的，抄作业就要抄学霸的。

关于竞品分析，我有个方法分享：可以先用Cursor做初步分析。我的prompt是这样的：

我现在要基于“XXXX”这个关键词搭建网站，你先不要写代码，先和我讨论网站的框架和功能：
1、请你基于这个关键词下的主要竞争对手分析用户需求、网站需要哪些内容
网站1链接
网站2链接
2、确定网站功能，哪些功能一期做，哪些二期做
3、页面区块确定：页面区块要如何布局

然后让Cursor把回复内容保存成.md文件，放在代码文件夹里，这样后续迭代时Cursor能快速理解项目背景。

通过Cursor的分析，我了解到这个网站的核心功能就是：用户输入问题，AI生成答案。排名第一的网站akkio，主营业务是帮广告公司提升营销效率，AI问答只是他们网站里的一个子功能，面向的是营销人员，解决营销工作里的问题。

这给了我一个启发：给功能设定明确的目标人群，切一个细分市场。虽然小众，但做到细分头部，流量也不少。如果做成一个谁都能用的AI问答工具，那竞争对手就是所有AI对话产品，包括ChatGPT，竞争太大了。所以我模仿这个网站的做法，把自己的网站也包装成了营销问答工具。

### 3、如何通过Cursor开发、上线

##### 页面布局

前面我提到让Cursor帮我做了功能分析，列出了一期功能和页面布局。接下来我的prompt是：

根据上面你所说的竞品分析结果帮我搭建网站，使用Next.js框架实现。
你需要围绕着关键词“ai answer generator”去写页面内容。我希望你能够写一个SEO友好的页面，要求配色简洁清晰漂亮，有落地页的常见Section，页面整体单词数量大于1000个，核心关键词的密度在3%左右。

这里解释下为什么用Next.js：因为这个框架有非常多好看的UI库。缺点是部署时需要安装依赖，会稍微麻烦一点。

回复说需要安装依赖。可以在Cursor功能栏点击“终端”，新建终端，然后输入“npm install -g pnpm”开始安装。遇到什么报错，直接把报错信息丢给Cursor就行。

先买域名。域名尽量和关键词一致，后缀优先选.com/.org/.ai，不过这些一般比较贵。新手练手的话可以先随便买一个，所以我选了.pro后缀，价格大概2美元。

我一般在https://porkbun.com/买域名。续费价格可以暂时不管，首年网站先盈利了再说，不然第二年大概率也不会去续。

接着解析域名。推荐用cloudflare，免费使用。

cloudflare地址：https://dash.cloudflare.com/。cloudflare在独立开发者圈子里被称为“赛博菩萨”，因为它除了域名解析，还有很多免费功能，比如免费存图片。想做AI图片站的小伙伴可以试试。

最后是部署到服务器。先把代码上传到github，再到vercel上创建项目，关联github代码，最后在vercel项目里加上我的域名aianswer.pro。

### 4、如何冷启动

冷启动我一般分成常规动作和个性化动作。常规动作主要是网站收录、提交导航站、获取高权重外链；个性化动作包括跟进竞品外链、根据数据优化网站。

##### 常规动作

1. 网站收录

目的是让主流搜索引擎先收录网站，这样用户搜索关键词时才有可能看到。主流搜索引擎包括Google、Bing，还有俄罗斯的Yandex。流量最大的当然是Google。以Google为例，操作流程如下：

1、打开GSC（谷歌搜索控制台），点击左上角下拉栏的“添加资源”

[PRE19]

2、输入域名，一路填写信息，点击确认

[PRE20]

3、如果前面域名是用cloudflare解析的，直接通过cloudflare授权验证域名所有权，就完成GSC提交了。

4、验证收录情况：GSC提交后要等一段时间才会被收录。可以在Google输入“site:网址”查看。下图就是被收录了。另外，也可以用提交高权重网站的方式，加快爬虫收录。

[PRE21]

2. 提交导航站

现在不少AI工具导航站支持提交AI功能。比如亦仁提到的https://www.toolify.ai/就是一个AI工具导航站。toolify流量大权重高，但需要付费提交。这个练手项目前期我先找了免费的导航站提交，等有付费转化后再氪金。

提交之前，我会提前准备好网站介绍信息，提高效率，包括：网站链接、名称、邮箱、分类、介绍文案、网站图片。

[PRE22]

免费的导航站哪里找？我平时看到流量大、权重高的免费导航站就会收集起来，不知不觉已经积累了不少。我把它们汇集到了自己做的一个网站上，有需要的小伙伴自取：https://freelancer-tools.shop/backlinks/1

3. 获取高权重网站外链

这里有很多骚操作。比如YouTube可以创建个人频道，在频道简介里放一个链接，这样就拿到了一条YouTube外链。类似的操作还有很多。

2. 根据数据优化网站

主要通过GSC和Google Analytics来看。GSC可以看关键词排名，目标词排到多少了，有没有有潜力的长尾词可以重点做，用户地域分布如何。

[PRE25]

Google Analytics则能看用户停留时长。如果停留时间短，就要想想怎么优化功能；还能看流量主要来自哪些外链、用户常访问哪些页面、流量来源是搜索、推荐还是直接点击。

[PRE26]

通过这些分析角度，我发现网站有几个优化方向：

1. 增加多语言

网站默认是英语，但从GSC发现菲律宾、中国、日本等国家也有流量进来。于是我在顶部导航栏加了语言筛选器。因为全站翻译工作量太大，我优先翻译了首页。多语言翻译也是用Cursor实现的，prompt分享给大家：

第一句：现在我需要对网站首页进行多语言翻译，请先列出主流的语种
第二句：请你在首页导航栏增加语言筛选器，筛选器里的语言选项就是你列出的主流语种
第三句：请你来翻译首页的内容，翻译的目标语种是你上面列出的主流语种，你只需要翻译文字内容，不要改变首页的布局，网站的名称是“ai answer generator”，这个名称不需要翻译

[PRE27]

2. 增加长尾关键词

这一步其实就是把竞品在用的、且难度低的关键词慢慢加进自己的网站里，持续扩大流量入口。具体操作上文已经提到过，这里就不重复了。

回顾整个过程，你会发现零编程经验做AI出海工具站，其实没那么玄乎。核心就是：找准一个低竞争的关键词，抄好对标的作业，用AI工具把网站做出来，再老老实实做外链和收录。每一步都不难，难的是你真的动手去做。
