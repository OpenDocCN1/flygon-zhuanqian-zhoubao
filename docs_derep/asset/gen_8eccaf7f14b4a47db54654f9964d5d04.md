## 一、背景：我们是怎么闭环的

先给结论，我们的完整闭环路径是：

**小红书发图文笔记 → 矩阵多号发布 → 引流进群聊 → 小号在群里发微信号（引流&钩子） → 微信承接私聊 → 直接发快团团报名链接 → 报名成功**

背景是这样的：

我们团队有位教学老师，前几年自己开培训机构，专门做线下研学，PBL和STEAM类型的教学，加盟过系统的课程体系，也自己研发过课程。早期获客方式比较传统：发传单、开门店等客上门。但越做越吃力，最后把店关了，只保留了一批忠实客户在群里，靠复购做点小生意——有收入，但做不大。

后来发现小红书有很强的种草基因，而且现在很多家长周末都不知道带娃去哪儿。随手一搜同城亲子研学，流量非常猛。我们就想试试，能不能把这个赛道跑通。

## 二、我们走过的弯路

一开始，我们的想法是不改变老师原有节奏，只拓宽获客渠道。比如老师周六日本来就会在群里接龙组织“博物馆”“夜观昆虫”“温室植物”等活动，我们只需要在小红书上帮他把流量做大。

但发了笔记之后，流量低得可怜。

分析下来原因有三：

1. 对标账号压根没做这类选题，关键词搜索量也很低。
2. 可能市场并不需要这类活动，这类主题不受欢迎。
3. 爆款应该是可复制的，如果流量没有“可复制性”，说明这个方向不好起号。

所以换了个思路：还是要按小红书的方法论来起号。之前更多是产品思维，现在要先解决流量，必须换回流量的玩法——怎么快速在小红书起号？

小红书起号的核心就一句话：**找对标 → 模仿对标的模板和选题 → 再组合拼凑成自己的模板。**

而“怎么找模板”和“怎么模仿模板”，就是起号成败的关键。

## 三、怎么找对标模板、怎么做像素级模仿？

### 先说怎么找对标模板：

1. 在搜索栏输入关键词，搜索几次后，系统就会给你推荐最热的帖子。
2. 看首页推荐页，一般看两页，每页四个格子，能上推荐页的都是被系统默认推荐的。
3. 看笔记底部的话题栏，点进去搜索相关笔记内容。第一步做好的话，话题栏里点开的都是你想要的内容。

[PRE3]

### 对标模板的标准：

1. 发布时间越近越好，三天内最佳，如果能找到24小时内的就更完美。
2. 评论区出现大量“怎么报名”“怎么参加”等问题的笔记，转化率很高。
3. 内容作图简单，用美图秀秀随便拼几张宫格图就行。

[PRE4]

### 像素级模仿的方法：

1. 找2到4篇爆款笔记，分别提取它们的爆款元素：排版风格、图片标题、正文标题、图片素材、正文写作风格。
2. 把这些元素做组合——A笔记的排版 + B笔记的图片标题 + C笔记的正文标题 + D笔记的图片素材……以此类推。如果你有文案功底和经验，组合两个就差不多了。
3. 正文部分，可以用kimi来仿写，让它写出小红书风格。官网链接：https://kimi.moonshot.cn/ ，写完稍微改改就能发。
4. 千万不要直接抄，那样会违规。正确做法是提取每篇笔记的爆款要素再组合，这样就不会被判搬运。

[PRE5]

kimi还可以用组合提问的技巧，用不同问法反复问，把答案综合起来又是一篇新笔记。比如：

- “萤火虫活动对亲子游玩有什么好处？”
- “为什么亲子一定要玩萤火虫活动？”
- “亲子萤火虫活动有什么亮点？”
- “萤火虫活动适合什么人群游玩？”

就这样不停提问，把答案整理一下插入写作框架，一篇新正文就有了。

## 四、关键词霸屏矩阵

通过以上几步，我们能做到“霸屏关键词”——就是用户搜索相关活动时，我们的排名都靠前。虽然不同手机搜出来的展示结果会有点差异，但我们试过多台手机搜索，一个界面四个宫格，我们自己就能占3到4个笔记，往下拉还能看到其他账号的内容。

换个角度想：如果你是用户，去小红书搜相关活动，肯定也会货比三家。你加了好几个好友问来问去，结果背后的团队都是我们——这样一来，你自然就会在我们这下单。

这套策略有专业名词：**关键词霸屏、蓝海关键词**。

我们的转化率很高，因为笔记都是用户主动搜出来的。搜索意味着他们带着“需求动机”，而不是刷小红书时偶然看到的“兴趣动机”。兴趣动机只是觉得新鲜，搜索来的流量加了微信后，我们直接问几句、甩报名链接，对方就报名了。

## 五、前期的准备工作

企业号我们也测过，一个开口成本大概14块，价格还行，但转化率不太稳定。可能因为企业号放量更多是曝光，属于“兴趣动机”。这块还在磨，目前还是以个人号为主，铺更多关键词。个人号有几个操作细节：

[PRE9]

1. **一机一卡一号。** 这是老生常谈了。别问能不能一机两卡、多wifi之类的，我们没试过其他方案。前期准备工作很简单，不需要刻意尝试别的动作，只总结有效果的，大家按这个标准来做就行。

2. **先刷3天，模拟真人操作。** 有些攻略说不用养号，但我们还是坚持养了，因为有做数据对比，养过的号确实更好。尤其是早期注册过一直放着的号，养号周期更长，权重更高。

3. **开始不需要发干货攻略，直接发引流帖的对标模板就行。** 这样流量来得更精准、更快。因为引流模板的评论区互动会提升算法推荐。小红书CES评分公式：点赞×1分 + 收藏×1分 + 评论×4分 + 转发×4分 + 关注×8分。评论数越多权重越高，曝光自然越多。

4. **引流方式有很多，个人号最稳定的就是建群聊。**

4.1 笔记热度起来后，直接绑定群聊，并在评论区置顶群邀请码。
4.2 群建好后，用小号在群公告欢迎语里留下微信号。微信号不要超过8位，尽量别搞太复杂。

微信号那边的准备工作：

1. 微信号也要养：平时上下班坐车、买早餐时多刷一刷，每天去“腾讯公益”捐点钱。
2. 新号一周内不要加超过5到20个人。
3. 用快团团承接转化。用户加到微信后，直接问怎么买。后续复购群也是通过快团团在群里接龙。

## 六、两个关键转折点

我们一开始也做得不顺利，摸索了很久没出成绩。后来遇到两个转折点，非常值得复盘。

### 第一个转折点：找到那篇爆款对标

当时我们找到一款对标笔记：

[PRE13]

当时没截图，现在回看那篇笔记已经被二次编辑了，看不到原始正文。不过我们想提取的元素还在，有规律可循：

1. 评论区很多人问怎么参加、怎么咨询。
2. 笔记发布在48小时内。
3. 封面直接写活动时间。
4. 笔记思路很直接：告诉你这是来参加活动的，不是来科普萤火虫有什么好玩的。所以评论区全是“怎么参加”。

我们提取了这几个关键要素，自己做了一份差不多的笔记：

[PRE14]

从封面对比一下（左边对标，右边我们自己的）：

- “阳澄湖” → “西樵山”（地点）
- “萤火虫” → “萤火虫”（活动名）
- “探索之夜” → “奇妙之旅”（修饰词，用kimi编近义词）
- “私藏美丽露西森林” → “夏夜流萤，看小精灵的发光瞬间”（仿写其他笔记或让kimi写）
- “活动时间”在左下角 → 时间也在左下角

所以你看，对标笔记写什么，我们就跟着写什么：

- 它用两宫格拼图，我们也用两宫格拼图；
- 上面是萤火虫，我们也是萤火虫；
- 下面是发光的森林，我们也是发光的森林。

这才叫像素级模仿，这才叫有效对标。

结果是：发完马上就有人咨询，热度越滚越高。我们把这个模板复制到其他号上，也都有热度，新号老号都能跑起来。

我们虽然不是最早做的模板，但我们一定是做的最多的——矩阵思维不是人人都会玩的，用互联网思维去降维打击传统机构，效果立竿见影。我们就不断写这个关键词、不断蹭热度，做到关键词霸屏。

记住一句话：**爆款是可以重复的，重复的爆款是可以不断重复爆的。**

### 第二个转折点：从单打独斗到外部合作

流量不愁了，模板也稳定了，但新的问题来了：我们只有一个研学老师，一个人精力有限，再怎么排班，能开的班次和收入都能算出来。那能不能找研学社合作？我们负责流量，他们有成熟的后端团队，各司其职。

很快小旺季来了——端午节划龙舟。一开始谈判不太顺利，因为我们属于“草台班子”，没法保证给多少量。但先试一把的心态让我们迈出了第一步。

就是这么一个小尝试，我们发现这条路完全走得通。如果自己搭后端产品和老师团队，作为初创团队很难请到好老师，而且准备工作非常重，不是说招个人就行的。

**合作，把市场做大，最简单。**

我们再调研了一下市场，发现很多成熟机构的目标是让家长产生多次研学消费，不是只来一次。有的机构甚至第一次可以不赚钱，把价格压得超低。这类活动有个好处：只要后端靠谱，复购率极高——毕竟家长每周六日都要愁带娃去哪儿。

市面上主题非常丰富：参观大众汽车、参观牛奶店、摘草莓、特斯拉博物馆、探秘航天宇航员、星巴克小咖啡师等等。成熟机构背后往往是很多主题，而这些主题大概率也是和不同渠道合作来的。

我们团队的优势是什么？可复制的模板 + 矩阵思维。很快我们就把龙舟这个活动做起来了，甚至让古村的工作人员加班加点。其他所有渠道加起来都没我们带来的量大，工作人员非常开心，说忙得数钱数不过来。

但其实，我们这边只有一个运营在负责引流。正如最近流传的那句话：“世界就是草台班子。”我们自己也很惊讶，流量能来这么多，直接激活了一整条度假村。

[PRE16]

也是因为这个决策，我们的流量变成了“有效流量”。以前做其他活动，因为老师不够，加上为了保证服务体验，一个班会限制人数，很多人报不上名。但这次不一样，小红书主题就是划龙舟，来咨询就加微信，加微信就成交，档期排出来随时发车。成交的72小时黄金法则，最快当天来、当天发车。

通过这些积累，我们收入达到了8到12万每月，整个盘子算是跑通了。目前团队配置就是一个运营加一个老师，后面准备放大。我们知道还会遇到其他困难，也希望圈友多给建议。接下来暑假档是个小红利，我们会趁势把业务再往上推一步。

## 七、项目风险与困难

听起来是不是很“上头”？但任何项目都不可能一帆风顺，说说这个项目的风险和坑：

1. **如果你的产品不是主流热门，笔记大概率没热度。** 这是我们最早踩过的坑。我们曾经想延续自己成熟的课程，还研发了新课程，自以为“对学生更好玩”，但市场根本不接受，发帖就是没流量。所以前期一定要用“流量思维”来做，而不是“产品思维”。

2. **研学产品季节性很强，流量有波动。** 旺季做内容曝光流量巨大，比如5到6月的萤火虫、端午节、父亲节、母亲节等选题，但过了季节就得重新换包装或换课程。这对团队的课程组合能力要求比较高。

3. **竞争力来自后端产品整合，但如果产品都是外包的，服务和课程质量会影响品牌口碑。** 自研课程又会遇到第一点说的“产品思维”问题；按流量来做课就得快，因为第二点的季节性在那里。这两关都能过，你再去和那些课程内容很多的机构竞争。

4. **目前市面上单节课收费大概150到250，我们走中高端路线，卖250到400，卖得还可以。** 很多机构第一次不赚钱甚至亏钱，就是为了建立信任，靠后面的课程组合复购回本。但前期小团队我更建议先赚钱，因为我们定位未来走自己的课程，走中高端。

5. **起号率虽然高，但容易违规废号。** 不过没关系，废了再起，多起几个就行。心态上不要怕废号，要有这个预期。

6. **研学项目基本都是户外，遇到下雨天就只能延期或退款。** 算账的时候不能算所有档期都满员。
