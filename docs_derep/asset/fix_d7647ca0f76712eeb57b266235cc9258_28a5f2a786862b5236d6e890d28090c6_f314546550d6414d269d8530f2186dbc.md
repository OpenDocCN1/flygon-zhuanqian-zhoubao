# 写在前面

我叫张波，平时喜欢把看到的好内容按主题收好。上回发完文章后，这半年我一直没停过琢磨：以后的方向怎么定，还要不要继续做下去。迷茫、失落都经历过，但说到底，咱都是凡夫俗子，别把自己当神，能一直积极就不错了。

[PRE0]

有位圈友叫萝卜，他领着一帮人做了六个月，攒下两百多份思维导图。我看了之后，也翻了翻自己手里的存货，想着不如拿【新人必读100篇】来试试看，一个人到底能跑多快。实际动手只有两天，成品精致度不如萝卜他们，但该提炼的要点都提炼出来了。AI能到这个速度和完成度，我已经觉得挺惊艳。

这次的整理没有对原文做深挖，只是把各位大佬的核心观点和干货拎出来。想进一步学习的朋友，直接点原链接就好。哈哈，没打算制造焦虑，只是给自己找个方向，顺便分享出来。
