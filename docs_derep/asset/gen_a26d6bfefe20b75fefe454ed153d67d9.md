# 两天逆转！一个AI数字人，让失业幼师的绘本店铺起死回生

今年一月，我在小红书的卖家社群里认识了小美。她是宁夏人，做幼教出身，失业后把命运押在了小红书的少儿绘本推广上。

我们其实很像，都是平台上的新人，都不善言辞，都容易在镜头前怯场。那段时间我自己的店铺掉了链子，直接选择了收手，而小美不一样，她咬牙撑着。明明要和现实的残酷竞争硬碰，还要克服自己性格里那份羞怯，她却依然满眼期待。

她的韧劲打动了我。我擅长数字人制作，便想能不能把这项技术借给她一把。不出所料，她第一反应是顾虑太多：手头没钱，也怕自己上镜丢人。可最后我们还是做了尝试。一起把视频做出来后，效果直接炸开了。短短48小时内，她的内容播放量和店铺下单量同步飙升。

这件事让我想通了一件事。镜头前的紧张、创业路上的难处，并不是死路。当你换个打法，让AI来扛住表现的部分，人依然可以带着初心去做自己擅长的事。坚持给了她机会，技术给了她杠杆，两者加在一起，才有了这场小小的销售奇迹。
