# 蟹二代的逆袭笔记：把一口阳澄湖味的传统生意，搬到线上卖爆全网

> 来源：[https://mg8sdlq5qo.feishu.cn/docx/NYNcdufjro44Mzx5PQCcXkb8nAd](https://mg8sdlq5qo.feishu.cn/docx/NYNcdufjro44Mzx5PQCcXkb8nAd)

生财圈大家好，我是星球里的帅彬，现阶段在常州的国企上班。履历比较杂，工地戴白盔也戴过红盔，弱电水电都接过，南京地铁调度干过，苏宁总部做产品、跑过销售、写过代码，堪称行业跳来跳去的万金油。

[PRE1]

回老家后生活看似安稳，却一直藏着一颗搞事的心。于是把家族经营多年的大闸蟹这门老手艺，硬是拽进互联网的赛道。今天就跟大家拆解下，这门看似老掉牙的传统生意，到底还能不能玩？怎么把线下口碑和线上流量拼在一起。

我从小看着家里搞大闸蟹养殖，亲戚们跟着发了财，一个拉一个全入行了。在本地，论养蟹经验谁都绕不开我们家那帮人。

这行靠的就是复购和口碑。螃蟹非得挑到满黄满膏、个头饱满、一点水分都不含糊。回头客我自己大概核算过，长期稳定在九成以上。

刚起步时手头紧，断腿的、小只的螃蟹我都舍不得丢，送客户或者低价处理掉。客户尝到甜头，接下来自然就买礼盒了。没有利他思维，不懂拓客，这事根本做不起来。

授人以鱼不如授人以渔，下面就跟大家聊聊大闸蟹这门生意现在还能不能做、怎么起步，以及我入局生财后的一些体感。

* * *

# 一、传承之外，还得会创新

我的本名叫陈炎彬，1995年生，微信号也直接用真名。原因有二，一是用真实身份在网上更踏实；二是以前用网名加人都要反复自我介绍，太麻烦，直接换真名省事。

家里就是做大闸蟹养殖的，我从小耳濡目染，亲戚里大姨夫、表舅、二伯、三伯等一大圈都在养，整个区域基本形成了一条完整的产业链。

这些年我越来越清楚，养蟹的主力基本都是年纪大的，年轻人吃不下这份苦。不是养不动，而是养好了也扛不住随时要变现的压力，一亩两亩塘口一死就是大出血。

同龄的家族兄弟姐妹里，真正坚持养的没几个，大多都转门店或者去直播带货了。

[PRE2]

我算是地地道道的蟹二代。起步最早的是我大姨夫，在长荡湖开始养殖，后来带动了一批亲戚入行，现在他还兼做冷库批发。

本地很多学徒都是他带出来的。有人不解为啥教这么多。我也是多年前才明白，喝酒时他原话是这么说的：“蟹养这行，人家想学躲也躲不开，迟早要去别处问。养蟹投入不是几万块的事，有时就是赌上全部身家。既然来找我，说明信任我。我把手艺全教了，我也老了，希望这行能青出于蓝。况且我有冷库，冻鱼块能自给自足，他们学会后，后续买优质蛋白还是得找我。”

ps 大闸蟹养殖讲究荤素搭配，现在不少塘口混养虾蟹小鱼。蟹长大后主食仍是鱼块，不能天天猛喂荤食，隔几天用东北玉米、甜南瓜搭配投喂，蒸熟后蟹肉自带甜味，黄膏饱满不用沾醋。

养时舍得成本，上市时才能出穿心红的效果。为了省钱，他自己囤冷库，也在亲戚间卖饲料赚点差价。

我们家的蟹上市偏晚，忠实老客常常催。品质没到精品线坚决不出塘。生财的思路我一直记着，不赚快钱，用口碑养客。

有人问我为什么还在体制内还要帮家里卖蟹。原因是父母太辛苦了，作为家里男人想分担一口。每次上市，父母凌晨去批市挑蟹，有时一把秤有时两把秤，一点点捡，普货里挑精品，精品里筛穿心红。跑的不是一个市场，是好几个市场轮着赶，哪里价高去哪里，心酸看多了。

我跟父亲去过无数次夜市。晚上挑普货，凌晨才挑精品，两点左右最疯狂，真不是常人能扛的。你以为挑完能睡了？第二天塘口一堆事要处理，塌方、增氧、投喂样样要盯，养殖容不得一点马虎。

我也受不了父亲这么累。少年时吹多了寒风，尤其是十一月的西北风，过度劳累落下病根。现在腿到冬天就疼，我戏称“老寒腿”。

冬夜的蟹市有吵闹、有灯火、有因为冷和累堆起的身体疼痛。去年十二月一个凌晨三点，我在市场里困到想放弃，实在太累了，一口气喝掉一瓶金小米。

[PRE6]

可客户的一句好评，又让我重新燃起责任感。能让信我的人吃到最好吃的蟹，苦点算什么。所以我还是想把养蟹卖蟹这件事坚持下去。

也不想让父亲再这么拼了。我还年轻，经得起苦，可看着父辈一把年纪还在硬扛，眼眶总会发酸。

我也注意过，蟹贩子是论斤收，再论个卖给客人。于是我也开始在朋友圈帮父亲代销，慢慢积累了一批客户，现在回头客占比九成。我不太爱露脸，所以来的基本都是老客，挺惭愧的。

平时扎蟹刷蟹我从不戴手套，可以说手上的指纹都磨平了。偶尔被大钳子夹一下，不是破皮就是出血。

为了让家族蟹塘活得更好，我想最大化线上订单，减少进市场次数，直接从塘口到餐桌。这样既能减轻老父亲负担，也能给客户更实惠的价格，还能保证每只都是精挑细选，确实是三赢。

这两年互联网客户明显多了起来，承蒙照顾，让我更有底气去把塘口做起来。

# 二、赛道虽卷，但机会仍在

说实话，小白现在进大闸蟹，时机确实不算早，但完全没戏也不对。我把从零到一的路径整理出来供参考。

万事开头难，开头稳了，后面会顺很多。

第一手做养殖风险最大也最累，不建议新手直接下场。没有前辈经验很容易血本无归。现在很多基地已实现半自动甚至全自动化可视化养殖。

[PRE12]

[PRE13]

系统上能看到每个塘投喂量、缺口、巡查无人机飞行频次，每个区域的定时投喂量，所有数据一目了然。投入很高，但靠政府补贴，年轻人愿意做。这类智慧农场曝光高，大单机会也多。

[PRE14]

走养殖这条路太重，不如换条轻的路：做中间商，收上来再转卖。下面按步骤讲：

1.收购螃蟹：旺季去批发市场或直接找蟹农收。先看规格再称重。市场一般下午晚上先走普货，半夜才挑精品，精品里再挑穿心红。精品基本不滞留市场，早被预订了，市场流通的多是普货和次品。中秋时价格最高，有时为抢一袋精品蟹贩子都打起来。

临近中午别去采购，精品早被扫光。凌晨去认识的门店还能留货。本地主要市场有凌家塘、兴化中国河蟹第一市、南京固城湖市场等。跟靠谱蟹农对接更稳，通常前一天晚上起笼、打规格，第二天送到塘里，绑小笼吐水，去泥腥味。也可先收回暂养池养两天再出。

[PRE15]

[PRE16]

新手别碰中秋单子，螃蟹没货、挑错、客户投诉全是坑。很多人信心满满进去，灰头土脸出来。等到十月大批量上市再出手更稳。要是真想早做，可以先做蟹卡。

2.蟹卡预售：大闸蟹集中上市在十月，但九月送礼需求爆炸，尤其是中秋前后。我通常九月中旬就开始卖现货，那时候必须挑好质量。也可以做蟹卡，客户自主兑换，有效期一般两年，我这边直接设成永久有效，信任才是复购核心。

做蟹卡系统要问清楚有没有独立服务器，防火墙做好，别贪便宜。设计别花里胡哨，清爽明了即可，能找设计师最好，别直接盗图侵权。铁盒、礼盒包装要差异化，后期预算足了可以做激光雕刻、UV定制，先做出基础体验再升级。

3.螃蟹运输：线上卖需要食品经营许可证，熟醉蟹或加工产品还要食品流通许可证。办个营业执照或公司几百块搞定。私域发货时，绑扎好的蟹放泡沫箱，加冰袋或冰瓶，再装礼盒，走顺丰。远距离基本顺丰特快，月结或地区卡充值5-10万有返现。运费贵，一单有时上百，远途走空运时效优先。

包装盒、泡沫箱、扎带、吃蟹工具、老恒和醋在市场都能批发。很多中间商专门做这套供应链赚差价。我们这边盒子多从义乌进，固城湖市场二楼就能买齐。礼盒里可放湿巾、明信片、产地说明，增加仪式感。今年我也在琢磨把江苏大闸蟹和掼蛋文化结合，做社交礼赠。

[PRE19]

4.交保护费：其实就是入协会。阳澄湖、长荡湖、固城湖都有各自协会，有会长、分会长、会员体系。入会后可用官方盒子或在自有包装上贴Logo。长荡湖、固城湖几千块搞定，阳澄湖要上万，相当于拿到合规的“洗澡蟹”身份。

[PRE20]

5.注册商标：走上正轨后注册商标，大闸蟹归第31类，找第三方约500元。包装再升级，品质永远第一。等品牌和口碑起来后，可拿下大客户甚至超级大客户，一年十几个大单轻松破百万。

品牌起来后，分销自然来。利润分成、售后、客诉机制成熟，代理才敢推。分销是锦上添花，不是用来自救。

6.小结：不和生财圈友连接、不参加航海、不亲自试错，光有认知等于零。我入生财前也踩过很多坑。现在发现，即使行情差，机会依然很多。圈子里的财富浓度、人才浓度越高，搞钱的概率越大。要么跟大哥混，要么不断升级打怪。

# 三、和生财一起把事做成

我几乎每期都参加生财的航海和线下聚会。光看没用，得动手。亲手做才有体感，才能迭代。

在一次视频号航海里，我认识了做朋友圈IP的伙伴，他缺带货品，我正好有蟹，于是合作试水代理，以前没做过，也算是突破。

[PRE21]

执行中发现问题不少，比如大家对大闸蟹的知识太匮乏。很多人觉得中秋国庆才是吃蟹季，其实真正好吃的是十月中下旬。苏北蟹成熟早，受气候影响，母蟹十月中旬后最佳，且个头越大越晚熟。公蟹要等西北风起才到巅峰，圈子里叫“公蟹党”。

广州那边十一月基本吃完了，所以中秋国庆他们找我下单，我都建议买蟹卡。苏南比北方晚熟，急单只能从苏北调货。我卖蟹坚持质量不过关不发，前期主推全母礼盒，后期再公母搭配。

代理对知识点不熟会迷茫，我就建群解惑，不好意思问的私聊我，一个知识点一个知识点拆解。
