# 解散团队 —— 无条件信任自己的选择

看到这里，你可能以为我现在靠副业躺赚了，但事实不是。

我现在已经彻底离开虚拟资料赛道，为什么呢？

最初坚持，是因为有明确的驱动力：要完成自己定的任务、要证明这条路走得通、要让别人刮目相看、要变现……正是这些让我咬牙坚持。

小红书虚拟资料跑通后，我尝试放大规模，组了一个小团队。

白天上班，晚上带成员实操。

成员陆续赚到钱，我采取分成制把他们推出来。

[PRE14]

但规模越大，内心越抗拒。

每天都在问自己：“我真的愿意长期干下去吗？”

答案是否定的。

那种感觉很像当年做设计时的无力感：不是自己真正热爱的事，即便做出成绩，心里也没有满足感。

在418活动前，我做了一个外界看来不太理智的决定——解散团队。

有人觉得不该放弃，毕竟搭建团队的机会不多。

有人替我惋惜，说结果太可惜。

我自己也思考了很久，也怀疑过自己的选择。

最终，我还是选择了拒绝。

理由很简单：我不喜欢。

我不想为钱勉强自己，也不想走一条违心的路。

别人赚多少与我无关，我要做的是我真正喜欢、愿意放大的事情。

分享一句我在私域大会看见并更确定自己选择的话：

“活着的意义除了体验，就没了。所以，无所吊谓” ——云蔓

[PRE15]

于是我把重心转回到自己喜欢的领域——IP。

我喜欢教练的感觉，喜欢分享带来的力量，喜欢陪伴别人跨过卡点的满足感。

所以我开始把重心放在公众号、AI自媒体、朋友圈记录，扩大自己的影响力。

这些事让我快乐，也让我觉得值得。

它们不像是任务，更像是生活的一部分。

我走到今天，反复告诉自己一句话：“无条件信任自己的选择。”

对错要走完才知道，但只要那一刻出于真心，就是最好的决定。

我很庆幸自己敢于解散团队，因为这让我更加明确：钱不是唯一目标，热爱和长期愿意坚持的事，才是我真正要追寻的方向。
