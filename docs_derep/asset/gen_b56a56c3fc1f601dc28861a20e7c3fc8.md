创业三年，做过二十多个项目，真正能放大、能稳定赚钱的只有三个。很多人问我怎么判断一个新项目值不值得做？我的答案很简单：先算账，用财务模型算清楚它到底赚不赚钱。

先简单介绍一下自己，我是ivy，和合伙人珍妮子用1500块起步，在小红书做留学两年做到2700万营收，后来转到房产赛道，两个月卖出1个亿。我们踩过坑，也逃过了“创业公司三年必死”的魔咒。这些年我练出一个习惯：一个新项目到我面前，我会快速拆解它的商业模式和财务结构，算一算进去能赚多少钱、要付出多少努力，一旦发现不对劲，立刻止损。今天就把这套判断方法分享给大家。

先说结论：一个项目的财务模型，基本由三个要素决定——赛道、位置、战术。

**第一，选赛道，要选现金流好、高门槛、高利润的。**

赛道好不好，比创始人牛不牛更重要。好赛道里，哪怕运营能力一般，也能捡到钱；烂赛道里，你再厉害也可能是在粪坑里扑腾。

举个真实例子。有个做澳新免费留学申请的老板，主营“零押金申请”，利润全靠院校第二年返佣。他从小红书引流，每月加微信几百人，转化率3%，每月签约20个左右，一年签约200人，但最后真正入学的不到10%。按每人佣金1.5万算，一年总佣金也就30万。高峰期他养了十几个人的团队，后来解散还要赔N+1，加上投放费用，最后返佣根本覆盖不了成本，自己还倒贴。

这个模式的问题有两个：一是两层漏斗筛完，真正付费的人太少，一年加五六千个微信，签约才200人，而这200人还要免费服务一年，最后入学的不到20个，90%精力都耗在不付钱的人身上。二是现金流是“先付后收”——先付员工工资，再等学校返佣，中间隔了一年。这种商业模式，一个人做也许能优化转化率，年入几十万很舒服；一旦放大，各种不可控因素会把利润摧毁。

那什么才是好赛道？标准有三条：

- 现金流好，能“先收后付”。查理·芒格说过，他偏好能产生大量现金的生意，不需要不断追加资本就能持续产生现金流。
- 有高门槛和进入壁垒。门槛低，竞争者就多，利润会被拉回行业均值甚至更低；有门槛，竞争者少，你才有时间建护城河。就像京东花十年自建物流，因为消费者不需要第二个阿里，需要的是当日达。
- 高利润。产业链上的价值分配极不均匀，公司内部的岗位分配也不均匀。如果不想辛苦创业却给员工打工，就要选高利润的商业模式，或者坐到能拿高利润的位置。

**第二，选位置，要选产业链上最赚钱的位置或岗位。**

有个合伙人想投资一家短视频知识付费公司，对方出让50%股份。我看了过去一年半的数据：总营收200万，公司和主播三七分，公司拿30%即60万，主播拿140万。公司拿到的60万还要付房租、水电、中控、客服工资和手续费，最后老板只剩20万利润，还没主播零头多。更夸张的是，老板每月固定支出相当于两个月利润——他得赚两个月才能养得起团队亏一个月。显然，这家公司最好的位置不是老板，而是主播。老板名义上是老板，实际在给主播打工。

所以，想进入一个行业或公司前，一定要算清楚每个岗位和产业链位置分别能拿走多少钱，尽量选择拿钱多的位置。

**第三，选战术，要选有复购的商业模式。**

商业模式就是你能提供什么、怎么卖出去、怎么赚钱。商学院经典案例是雀巢的奈斯派索咖啡机。最初只卖高端咖啡机，结果市场竞争激烈、价格没优势、机器一次性销售，客户还可能去买别家的豆子，公司差点倒闭。新CEO改变玩法：把咖啡机卖得很便宜，同时研发特制胶囊，只有自家机器能用。客户买机器后，会持续复购胶囊，机器上少赚的钱，胶囊都赚回来了。这就是“剃刀+刀片”模式——用低价产品锁定客户，靠配套耗材持续赚钱。

我和珍妮从留学转行房产，也是因为留学几乎没有复购，每年都要拉新，而小红书做留学的人越来越多，获客越来越难。房产不同，高净值房东卖房后，买房、装修、贷款、落户、孩子转学都可能继续找我们，一个客户的终身价值很高。

说完财务模型的三个决定因素，再看具体判断项目时，该看哪些财务指标。小公司没有完整财务报表，不需要算太复杂，抓大放小，看三个核心指标就够了。

**第一个指标：烧钱速度。**

理想情况是每天现金流为正，但现金流为负的项目不一定都不能做，关键在于钱能烧多久，在钱烧完前能不能转正。公式是：

烧钱速度 =（经营现金流出 - 经营现金流入）/ 时间周期

比如一家西餐厅，一个月经营现金流入6万，流出12万，时间周期30天，那每天烧钱速度 =（12万-6万）/30 = 2000元/天。如果手里有30万现金储备，理论上能撑150天。如果150天内能扭亏为盈，项目还能继续；但如果调研发现当地餐厅月收入天花板就10万，怎么优化都是亏，那就该及时止损。

**第二个指标：最小单元是否赚钱。**

每个业务都由若干“最小单元”组成。网约车的最小单元是一辆车，直播平台是一个主播，留学申请可以是一个全案服务。算清楚每个最小单元的贡献利润，再看能不能覆盖固定成本。

举个例子。我早年做留学申请，和兼职交付老师合作，做一单给一单钱。客户付费后，我分50%给交付老师，剩下50%是我的利润，每单现金流都是正的。但如果想扩大规模，租办公室、雇全职员工，就产生了固定成本。假设每月固定成本4.5万（房租1万、底薪3万、投放0.5万），每单留学申请收费1.5万，拿出40%作为员工提成，那每单利润就是1.5万-0.6万=0.9万。盈亏平衡点 = 固定成本 / 单单元利润 = 4.5万/0.9万 = 5单。也就是说，每月至少签约5个学生才不亏，超过5个才有得赚。

很多小生意一开始赚钱，一扩大就亏本，就是因为加上了固定成本，盈亏平衡点一下子变高了。所以扩张前一定要先算这笔账。

**第三个指标：客户获取成本（CAC）与客户终身价值（LTV）。**

如果最小单元是赚钱的，说明每单都有利润，可以扩大业务。但扩张还涉及获客成本。

CAC = 获取新客户的总成本 / 新客户数量。比如一家留学公司在抖音投流花了1万，员工工资1万，总共2万，转化了10个客户，那每个客户获取成本是2000元。

LTV = 每个客户的平均收入 × 客户的平均生命周期。复杂版公式是：平均收入 = 总收入/总用户数，平均生命周期 = 1/客户流失率。举个例子：公司月收入30万，客户数1000人，平均收入300元/月；月流失率5%，平均生命周期20个月，LTV就是300×20=6000元。

简单来说，LTV就是一个客户这辈子会在你这里花多少钱。如果留学申请收费1.5万且基本无复购，那LTV就是1.5万。如果获客成本只有2000，那就可以疯狂扩张，因为高LTV撑得起高CAC。当LTV/CAC的比率大于1，说明获客ROI是正的，可以继续复制；这个值越高越好。

总结一下：判断一个项目值不值得做，先看赛道（现金流、门槛、利润），再看位置（产业链上哪个环节赚钱），然后看战术（有没有复购）。具体算账时，盯住烧钱速度、最小单元利润、CAC和LTV这三个指标，基本就能给项目把脉了。项目千千万，算清账再动手，别让辛苦钱打了水漂。
