109 元一年的云服务器，我搭了个“收藏夹终结者”：亦仁同款 agent 升级版实操笔记

有时候，我们收藏东西不是因为爱学习，而是为了缓解焦虑。我手机里也存了上百条“以后再看”的链接，真正回看过的，屈指可数。后来我给 iPhone 设了个“轻点背面”的快捷指令：看到好文、好视频，复制链接，敲两下手机，链接就自动丢进飞书群。我给这个动作起名叫“万物归虾”。收藏那一刻确实很爽，但紧接着问题就来了：然后呢？接下来的剧情常常是——没有然后。那些链接躺在群聊里，跟微信文件传输助手里、各 App 收藏夹里的兄弟们一起吃灰。

直到前两天刷到亦仁的直播，我才发现那个叫“小D”的音视频整理 agent 已经发布一个多月了（帖子地址：生财站内《小D 复制部署说明：音视频转录整理 Agent》https://shengcaiyoushu01.feishu.cn/wiki/VsEawZUYMi4CCxkjNEncXPJ4nsg）。我立刻跑去照着搭了一个，终于明白什么叫“河上终于有桥了”。

小D 的核心逻辑是：给它一个音视频链接，它自己负责下载、转写、去口水话、去时间戳，最后输出一份“分享式精编稿”。不是三句话结论，而是把原话、案例、关键判断全都保留的可读文稿。

不过我的收藏夹里，音视频只占一半，另一半是公众号文章、小红书笔记、抖音短视频、视频号内容。这些内容面临的不是“转写”，而是“抓取”。而且我平时做内容、盯选品，本来就需要搜笔记、翻评论区、拆对标账号。更重要的是，我之前看到好的图文教程，想让我的 Hermes 也“学”一下，但它没有眼睛，根本看不了链接。于是，这个升级版就诞生了。

我给 agent 加了个四平台采集 MCP，直连 TikHub 官方 API，一共 20 个工具，每个平台都配齐“搜索 / 内容详情 / 评论 / 博主”四类能力：

- 小红书：能搜笔记、搜博主；贴分享口令就能拿笔记详情；评论支持一级评论+二级回复；还能看博主主页和笔记列表。
- 抖音：支持关键词搜索；分享链接直接取视频数据；评论、主页、作品列表都有。
- 微信公众号：通过搜一搜能找文章、找账号；文章链接直接拉回完整正文；文章留言能抓；账号文章列表也有。
- 视频号：搜一搜能搜视频；作品详情贴分享短链就行；作品评论可抓；主页和作品列表也齐全。

更妙的是，这四个平台都支持“丢链接直接取内容”，正好接上“万物归虾”的入口——群里躺着的每一条链接，agent 都能认出平台并拉回内容。采集到的社媒笔记，我统一写进多维表格。这些字段是我拿真实数据跑过、按 TikHub 返回的共性字段整理的，这样才能很顺地写进同一张表。

于是我的流水线变成了：收藏用“万物归虾”，处理用 agent，沉淀进表格。

以前“收藏了从没看过”，现在变成了“收藏了，AI 已经替我看过并记录下来了”。

账我就不藏着掖着，明明白白给你算：

- 服务器：腾讯云轻量 4 核 4G 3M，活动价 109 元/年（前几天还涨了 10 块）。
- 大模型：用多少付多少。DeepSeek 充 10 块能用很久，性价比极高；有 ChatGPT 会员也可以接进去共享额度。
- TikHub：按次计费，不同平台价格不一样。这是我用过最稳定的采集 API，自用量级不贵。响应带 cache_url，24 小时内重复获取同一份数据免费。
- 软件：全部开源免费。

另外还有一条省钱铁律：字幕优先。大部分 B 站视频，yt-dlp 都能直接拉现成字幕，根本不用转写，成本为零；拉不到字幕才转写。短的服务器 CPU 硬跑，长的接云端语音识别按量付费。YouTube 因为机房 IP 被控，兼容性还有问题，后面再优化。

接下来是安装步骤，先准备四样：服务器、DeepSeek API Key、飞书自建应用、TikHub API Key（最后这个可选，只用采集时才需要）。具体清单和视频教程我整理成了一份“Hermes Agent 部署资料准备清单（自部署版）”，照着做就行。服务器就买腾讯云轻量 4 核 4G，买完拿到公网 IP 和登录密码；DeepSeek 去注册、创建 Key、充 10 块；飞书自建应用去开发者后台（open.feishu.cn/app）创建“企业自建应用”，复制 App ID 和 App Secret——agent 靠它在你飞书里读群、建文档、发消息。TikHub 注册入口：https://user.tikhub.io/register?ref=EJ7Ka9h8 （带我的推荐码，不加价，介意可去掉 ref 参数）。

安全提示：给 AI 的服务器密码建议用临时密码，装完就改；更稳妥的做法是配 SSH 密钥。

接下来，把准备好的信息填进一整段提示词的【】里，丢给 Codex 或 Claude Code 就能完成安装。手动教程和提优化意见的入口都在 GitHub 仓库：https://github.com/chenchen1010/hermes-media-suite

“万物归虾”快捷指令配置文档在这里（建群机器人、拿 Webhook、背板双击触发）：https://gcn6bvkburhk.feishu.cn/docx/VII1doG3DoNWCRxiphfcdjyNnAb ，配完你也能拥有“看到什么，先归虾”。

关于默认接入：飞书这边，你的自建应用本身带机器人，内容可以全转给它；你还可以把它拉到不同群里做不同的事。微信这边，Hermes 原生支持接入，安装提示词里告诉它“我需要微信接入”就行；配好后在微信聊天框里也能发消息使唤，但只支持一个聊天框。

聊完安装，再聊踩坑。这套方案我全部用真 Key 实测过，替你们填了三个坑：

- 第一个坑：403 Forbidden。第一次调 TikHub 就翻车，排查半天找到原因——是 Cloudflare 把 Python 默认 User-Agent 给封了。不解决这个，不管你照谁家的教程写，都会卡在第一步。仓库里的代码已经带了正确的 UA。
- 第二个坑：接口 404。TikHub 官方 SDK 里微信侧的接口路径全是旧版，照抄必 404。正确路径要以线上 OpenAPI 规范为准（v2 前缀）。仓库里已经全部对齐线上版本，四平台 20 个工具，主链路全部实测过。公众号那条我是拿自己的文章测的，完整正文一次拉回。
- 第三个坑：转写费钱费时。长音频扔给转写服务又慢又烧钱。解法还是“字幕优先”：先拉字幕，拉不到再转写；短的本地 CPU 硬跑，长的接云端语音识别按量付费。这条逻辑已经写死在 agent 指令里，它会自动执行。
