我是阿皓，一个00后。在这片圈子里泡了三年多，大学时就混迹互联网，算是个标准的“流量玩法爱好者”。

过去这几年，我试过不少路子——微商、头像表情包导流、小红书垂直粉、私域后端成交，都小赚过几笔。

今年4月，我开始全力投入AI写作，45天下来，净利润2万。这件事让我被迫停下来审视自己：为什么我总能看到风口、也确实挣到了钱，可每做完一件事，却什么也没积累下来？

如果你也有类似的感受：
- 项目看了无数个、也下场试了不少，但真正做透的没几个；
- 收到正反馈就火力全开，一旦没有消息就陷入自我怀疑；
- 总觉得下一个机会更好，可回头看，手里空空的；
- 渴望找伙伴、找团队、找归属感，但等着等着就停摆了；
- 赚过快钱，可模式一停，客户、话术、流程、团队啥也没留下。

那这篇内容，或许能给你带来一些启发。

这次复盘的核心，是很多普通人在做事时最容易踩的一个坑：习惯用“狩猎者心态”去做事——只追着现金流跑，却不经营资产。哪里有红利就往哪里钻，哪里见效快就扎哪里。短期来看确实灵活，可拉长到三五年，钱是赚了，但资产依然为零。

2. 直接打包卖给需要的老板，每一位微信好友大约1.2到2块钱

**怎么操作呢：**

第一，去微博或小红书扒好看的图，审美很重要——后来我招过线上助理，发现每个人的眼光差异极大，有人选的图片很土，有人选的就很高级顺眼。

第二，拿到图之后打开醒图App，找对应的模板套用，编辑好就能发。

**怎么把人导向微信？**

小红书、抖音、快手这几个端：引导用户点进主页，主页上挂公众号的名字，用户关注公众号后，后台设置好自动回复，回复中自动带出微信二维码。公众号那边就更省事，文章末尾直接嵌入公众号名片。

**复盘结论：**

前后导流了近30万粉丝，但后来因为账号被封以及个人状态的原因，没有坚持下去。

这确实算个好项目——见效极快，没有内容门槛，只要审美在线、能忍受重复性劳作就能跑通。

我那时也留了一部分人在私域，尝试做一些后端变现，比如减脂、占卜、水晶等。但这些人属于泛粉，是为了拿头像才加过来的，并非带着强需求而来。所以朋友圈一定要精心维护，不能像传统微商那样刷屏硬广，要有人设、有互动、有生活气息。

关于泛女粉减脂+占卜的变现思路，我写过一篇简单的SOP文档，感兴趣的圈友可以去翻翻，希望能激发大家一些灵感。

### 2. 小红书精准粉（24年，干了约半年）

**为什么选这个方向：**

因为做表情包时正反馈来得太猛了，现金流哗哗的。后来在知识付费圈也链接了不少做粉的人，所以就顺着老路继续走，只不过从泛粉切到了精准粉。

我打过减脂、星座、塔罗、旅游等赛道，重点在减脂。我把小红书减脂的素人分享贴打法整理成了一套SOP，感兴趣可以找我拿。

现在小红书对新号的扶持不小，很多赛道都值得尝试，包括我现在做的AI写作赛道，在上面也能刷到同类。

**复盘结论：**

当时走的是矩阵模式，手头几十台设备，每天循环做三件事——测号、发内容、盯数据。最猛的时候月入过了10w。因为这些都是高价值粉，一个能卖15到120块，减脂粉头能卖到60到90。

这个模式的反馈周期也短——只要号能跑、内容有人看，客资自然就来了。但后来平台管控收紧、流量萎缩、违规代价变高、耗号速度也快，我慢慢就撤了。

### 3. 私域后端（客服）成交

**大概做什么：**

把之前积累的泛粉和买来的精准粉拿来变现，涉及过减脂、塔罗、水晶。

**为什么要做这个：**

直白说，做流量做疲了，每天重复机械劳动，很消耗人。而且做就有、不做就没有，还得看平台脸色。

**复盘结论：**

当时做减脂粉转化，加了40多个人，成交了15个左右，首单加复购累计做到了1.5w+。

前两个阶段我都在搞前端获客，真正坐下来做转化时，我发现这件事才是我喜欢的。用户来了怎么开口、怎么判断对方需求、怎么戳痛点、怎么在朋友圈建立信任、怎么定价、怎么谈成单子，全都是边做边悟出来的。

但说到底还是离不开流量——没有新客进来，后端的成交环节就断了。当时那几个赛道的流量极不稳定，平台限制得也紧，我又开始到处看新方向、试新路子，做着做着又搁浅了。

## 二、为什么过去没留下“资产”？

只看履历的话，我确实赚到过一些钱。但回头看，这些东西都没有真正变成“资产”。

表情包累计导流了近30万粉，精准粉也打过几千个，但绝大多数都换成了现金，没有沉淀进自己的私域。现金流确实让人上头，可是号没了、粉没了，下一次还是要从零起步。

[PRE6]

我复盘了四个原因：

**1. 把现金流错当成资产**

以前只要一个事能赚钱，在我眼里就是好项目。但问题在于我的能力全凭个人经验——怎么测流量、怎么报价、怎么聊天，这些从来不落地成文字。没有话术库、没有SOP，只要我不亲自动手，别人根本接手不了。

过去我总觉得缺的是人，现在才明白：缺的不是人，是能交给人的那套流程。

**2. 平台一管就想着换路**

规则一调整、号被限制了、数据下降了，我本能地想跑，而不是想办法。当时还会编一个体面的理由：这个平台废了、规则不让做了。但现在回头看，大部分时候不是项目死了，而是我从没认真尝试解决问题。

**3. 过度依赖及时反馈**

只要有钱赚、有正反馈，我可以一直做下去。但反馈一慢下来，我就忍不住去刷别人是怎么赚钱的，脑子里装满了新花样，手上却几乎不动。以前我管这叫懒，现在想明白了，这不是懒，是焦虑——越焦虑越想，越想越不动。

**4. 总在等队友、等氛围、等确定性**

看见别人情侣档、兄弟团合伙做项目，我会很羡慕，然后不停告诉自己：一定要找到合适的人才能开始。这个执念耽误了我很久。但现在我意识到，一直等下去，就是在亲手放弃赚钱的机会。

## 三、做事的两种身份：“狩猎者”与“农耕者”

这个词我一直很偏爱。很明显，以前的我就是个典型的狩猎者——哪里有猎物就往哪里扑，哪里反应快就去哪里打两枪。短期看好像很机灵，长期看却一直在原地踏步。

我现在的理解是这样的：

狩猎者的模式：哪里有红利就冲向哪里 / 赚到钱先想着怎么放大投入 / 平台一紧换战场 / 靠即时反馈驱动 / 方法论全在脑子里 / 永远从零开始。
农耕者的模式：锁定方向后持续深耕 / 赚到钱想着先沉淀资产 / 平台变紧先判断能不能换打法 / 靠流程与复盘驱动 / 把经验变成SOP、案例库、话术库 / 让能力可复用、团队可接手。

狩猎者的素质并不差——能看见机会、敢下场、敢试错，这本身就是优势，很多人连机会都看不见，看见了也迈不开腿。

但一个人如果只有狩猎者能力，就注定漂泊不定。赚一段，换一条赛道；再赚一段，再换一条赛道。两三年下来，经历确实丰富，但真正长在自己身上的资产少得可怜。

农耕者并不是不看机会，而是看到机会之后选择留在里面慢慢耕耘。落到具体操作上，就是不停复盘流量数据、打磨转化环节、优化交付质量、沉淀SOP、攒客户攒案例，把脑子里的经验变成别人能直接拿来用的工具。

以前我嫌这种打法太磨叽，现在反而觉得，慢才意味着快。

## 四、AI写作这个局，我想用农耕者的姿态入局

AI写作我不是今年才听说的，早在24年就知道有这么个方向。当时一直追看小鹅老师和瑾糖老师的分享，心里隐隐觉得有戏。后来索性跟小鹅老师付费报名，他教得真心细——奶奶级SOP那种细，再加上我手里原有的经验，不到一周就跑通了从0到1！

说到这儿可能有人会杠：现在人人都会用AI了，还有蠢人去闲鱼找人代写？但事实是：有！而且需求量超乎你想象。

**项目逻辑：**闲鱼挂链接+付费投流+导流到微信成交+老客户复购。

我目前主要在闲鱼获客，走付费流量路线。今年4月才正式动手，一个半月净利润2w。关键是我什么专业技能都没有，在各行业里都是纯小白，连那些术语都看不懂，可照样把0到1跑通了——全靠AI帮我分析需求、解释名词、最后用它来完成交付。

说下这45天的成绩吧，和大神们比起来真的不值一提，但如果能激励到几位圈友，这波就不亏。

现在我做的是PPT代做，共运营3个账号，自己包揽前端获客+客服成交，交付环节雇佣写手来完成。写手的人力成本一般是客单价的15%到40%，只要对方接受就行。

**目前卡在哪：**

因为自己没专业功底，我一直有点迷茫，不知道该往哪个新品类延伸。PPT的天花板太明显了，客单价上限不高。

最近我开了个新号，重新测试上面那几个品类，咨询量确实回来了，但又都是预算不足、拉着比价的人，ROI依旧做不正。我打算再压1000块预算测一轮，实在不行就先冷静一下，再观察观察别的品类。

个人建议：如果你身上有专业技能，真的推荐下场闲鱼试水——确实零门槛，把链接挂出去，基本两天内就有来咨询的。（比如程序员接Java单子，老师接课件代做，做过IP的人接口播文案、短视频脚本等。）

**说回来：**

我是25年11月买的课，但直到今年4月才真正起步。为什么前两年看到机会却没动？第一，23到25年一直泡在流量项目里；第二，停了流量之后，我总想着找个合适的人一起入局。最终还是等来了一位朋友，两人搭档，十几天就把0到1跑通了，拿到了现金和正反馈。

可后来朋友因为个人原因退出了。我又陷入等待……越等越慌。换作从前，我八成又会掉进“等待→焦虑”的循环里。但这一次，我不想再等。我决定自己扛起来做获客、做成交，交付环节找外包写手顶上。

现在的状态还谈不上稳定，只能算是跑通了0到1。这个成绩不强，但对我来说意义很大——它验证了一件事：执行力在线，干起来，就一定能拿到答案！

而且这次，我不想再做一锤子买卖了。流量怎么做优、客服怎么应答、写手怎么管理、质量怎么把关，这些我都准备一点点沉淀成SOP。刚开始肯定很粗糙，但粗糙总比空想强，先完成，再追求完美！

超级航海AI大会的课程我参与之后，又蹭了瑾糖老师的AI线下生财聚会，特别感激瑾糖老师的分享，还给了我一堆业务层面的建设性建议。现在我逐渐在用Obsidian、Codex这类工具来整理流量明细、客户问题、聊天话术以及每周复盘，力求把获客SOP和转化SOP都搭起来。这不是为了显得专业才搞这些，而是我真的因为经验没沉淀吃过亏——东西不梳理成文档，它就永远只长在我自己脑子里；只长在脑子里，别人就很接手，以后想规模化也没法教给员工。这一回，我铁了心要当农耕者！

## 五、如果你总是想换方向，请先问自己5个问题

一路走到今天，我意识到普通人做事最大的障碍，往往不是项目没有红利，而是看过的信息太多——反而搞不清到底要不要坚持眼前这个。尤其当一个项目反馈变慢，你又恰好刷到别人晒新成绩，内心就开始躁动：是不是应该换个赛道了？

现在我每次萌生退意，都会先问自己几个问题：

**1. 这件事是真没救了，还是只是撞上瓶颈？**

大多数项目起步期都有红利，反馈快、数据漂亮。但只要做久一点，平台的规矩、流量成本、交付压力、团队磨合这些问题迟早会浮出水面。以前我会下意识觉得“项目不行了”，现在我先按住自己：不要急着动，先判断问题有没有解。

我自己就掉过这个坑——做表情包那阵，后期号一封再封、流量掉得厉害，我脱口而出“这条路完了”，拍拍屁股就走人了。但回头看，那时候完全可以变个分发策略、换换内容表达，甚至挪到别的平台上继续起量——明明有人在相同模式里憋得更久，还把数据做得比我好得多。我那时候逃的哪里是项目，逃的是问题本身。

**2. 我是在理性寻找机会，还是在用搜索麻痹焦虑？**

这个问题问出来挺扎心的。我以前很多所谓的“找机会”，本质上是拿翻新项目来麻痹自己。看别人赚钱、看新玩法、找新方向，短时间确实自己“还有希望”的幻觉，但只要不付出实际动作，焦虑只会越积越重。

就拿我自己说——小红书打粉遇阻之后，我一连好几个月都在刷视频、翻别人搞钱的项目，脑子转得飞快，落地动作约等于零。当时我还骗自己说这叫“找感觉”，其实就是借着输入信息来营造一种“还在努力”的假象，说白了就是瞎忙。AI写作这个事我24年就看到了，真正动手却是今年4月，中间白白浪费了两年多——大部分时间都消耗在“干着急地等”和“去找所谓更好的项目”上面了。

**3. 我在这个项目里，留下了些什么？**

如果做了一个月，到头来只剩一句“我做过了”，那就太亏了。就算项目最后做没了，也应该留下点东西：一套SOP、一份流量测试数据、一套客服话术、一批成交案例、一条交付链路、一张踩坑地图。

这些东西，才是你走到下一个项目时手里真正的筹码。如果什么都没有，那就算赚到过钱，也只是一笔暂时落袋的现金流。

我自己的案例就是典型：表情包前后导了将近30万的关注，但大部分被我直接卖了换钱，从来没想过把用户存在自己的私域里；做客服转化那阵子，我摸出一套谈单节奏，知道怎么开口、怎么给价，但全都存在脑子里，没做成话术库、没整理成SOP。结果后来合作的朋友没有办法快速顶上来，我自己也没办法把规模放大——因为我手里根本没有可以交出去的东西。

**4. 我有没有试着先换方式，而不是急着换方向？**

免费流量跑不动了，能不能试一试付费流量？一类产品不行，能不能换个品类？转化率上不去，能不能把话术重做一遍？交付太累了，能不能找外包帮你分担？

很多情况下，真正该换的不是方向，而是方法。人往往是在换方法的过程中获得成长的。

我做AI写作就是这么走过来的：最开始接剧本，咨询量看着很大，但成交稀碎，ROI怎么拉都不对。搁以前，我大概会把整个赛道都否掉。但这次我先稳住自己：是赛道有问题，还是品类选错了？随后我更换到了PPT这个细分方向，结果咨询、成交双双稳步回升。方向没变、赛道没换，只换了一个品类切口，效果判若两人。

**5. 接下来再坚持3个月，我最需要沉淀哪一项能力？**

别老想着一步到位把盘子铺大，先把问题拆解拨开：未来90天，我要沉淀的是获客能力，还是转化能力？我该打磨交付流程，还是团队管理本事？我要经营私域，还是积累案例？

一个阶段只盯一个核心能力，反而走得动。

目前我给自己划了一个特别明确的范围：这三个月就专注做两件事——第一，把投流SOP给写完整，每天用工具自动拉取数据，再基于数据反馈来迭代动作，让这套打法能复刻；第二，把客服谈单的话术沉淀成文案库，不能再凭感觉沟通。交付暂时外包给写手处理，不投过多精力。以前我总是想一口气把每条线都做到完美，结果每条线都浅尝辄止。这次我只求两条主线先立住。

## 写在最后

从狩猎者转变为农耕者，我花了整整三年才想通。以前总觉得那种玩法太慢，现在才慢慢体会到，真正的快，其实是盯住一个方向往深处打，把经验转化成资产，让一切都有迹可循、可以被传承。如果你也总是在各个方向之间反复横跳，希望这篇复盘能帮你多撑一会儿——机会永远都不缺，但最终你能带走多少，还是看你在地里耕了多深。
