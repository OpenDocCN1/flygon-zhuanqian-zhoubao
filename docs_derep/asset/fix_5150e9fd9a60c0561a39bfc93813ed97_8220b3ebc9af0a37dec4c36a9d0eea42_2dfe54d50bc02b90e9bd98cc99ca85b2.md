# 影刀 RPA 批量排程实操手册：公众号与小红书表格、账号、运行全流程

本说明面向 Windows 操作环境，演示如何借助影刀 RPA，联合 Edge / Chrome 或比特浏览器，实现公众号与小红书的内容自动化发布。

当前方案暂不支持 macOS，原生使用。Mac 用户需自行搭建 Windows 双系统或其他 Windows 运行环境。

## 2. 配置表格

建议将整表单元格格式统一设为“文本”，避免路径、数字被自动转换。

### A列 比特窗口号

用于标记比特浏览器中的窗口序号。若对窗口编号获取不熟悉，请先查阅比特浏览器插件安装说明。

[PRE12]

[PRE13]

[PRE14]

[PRE15]

### B列 sheet名称

填写文章所在 Sheet 的名称。命名规范：
- 不可用单独数字，如仅写“1”；
- 可用中文，或数字加符号组合，如“18-0”；
- “配置页”名称必须保持原样不可修改；
- 其余 Sheet 如“旺仔”“创业”等，只要配置页填写的名称与实际 Sheet 完全一致即可。

[PRE16]

### C、D列 文章处理区间

- C列：对应 Sheet 的起发行；
- D列：对应 Sheet 的止发行。

例如“旺仔” Sheet 从第2行发到第3行，则配置项填 2 与 3。

[PRE17]

[PRE18]

开始行号：从内容页面表格第几行起发布文章
结束行号：到内容页面表格第几行结束
ps：如果只发一行，如第二行，则开始与结束均填 2；若一次发两篇，则开始填 2，结束填 3，生成对应格式。单次最多可添加 8 篇，注意上限。

[PRE19]

### E列 状态

该窗口的谷歌浏览器结束后会自动记录运行结果。

## 3. 内容页字段说明

#### 2.1 原创者配置（A列）
需勾选原创时在 A 列输入姓名，不勾选则留空。

#### 2.2 标题（B列）
录入文章标题。

#### 2.3 内容地址（C列）
使用洗稿工具产出时，直接粘贴洗稿后的表格；使用自有内容时，填写存放 Word 的文件夹地址，该文件夹内仅允许一个 Word 文件。

#### 2.4 封面图地址（D列）
右键图片复制路径，得到类似：
"F:\下载文件暂存\海报中转\蓝色科技扫码关注公众号二维码.png"
填表时去掉引号：
F:\下载文件暂存\海报中转\蓝色科技扫码关注公众号二维码.png
不使用封面则留空。

#### 2.5 话题（E列）
需要话题时按格式填写：#话题，无需求则留空。

#### 2.6 原文链接（F列）
需要保留出处时粘贴链接，否则留空。

#### 2.7 创作来源（G列）
共 4 种来源，按模板写法填写，切勿改动。如选择 AI 生成，直接输入 ai；不选则留空。

#### 2.8 发布状态（H列）
文章发布后系统会自动写入状态，便于后续调整。

#### 2.9 固定开头（I列）
若需在开头插入固定内容，先建 Word 文档保存固定文本，再将文档路径填入 I 列。

[PRE20]

#### 2.10 固定结尾（J列）
若需在结尾插入固定内容，先建 Word 文档保存固定文本，再将文档路径填入 J 列。

[PRE21]

### 2 启动页面

[PRE22]

启动页的起止行指向“配置页”的行号，而非内容页文章行号。例如从第5行启动，表示从配置页第5行对应的窗口开始执行；结束同理。

## 5. 内容表字段

#### 1.1 笔记类型（A列）
选择图文或视频。

#### 1.2 保存状态（B列）
三类状态：直接发布、定时发布、存草稿。名称不可更改，按模板填写。存草稿注意：小红书仅保留最近一条草稿，存草后若继续发布会覆盖原草稿。

#### 1.3 文件存放地址（C列）
填写素材文件夹，内部仅放本次要发布的图片或视频。图文需对图片编号，首张默认为封面。

[PRE28]

视频建议一视频配一封面，格式为 mp4。

[PRE29]

#### 1.4 视频封面图地址（D列）
填写视频封面图片路径。示例：F:\旺仔\旺仔创业引流\rpa引流\自动发布工具\小红书发布\测试\视频存放\2.jpg
图文或无需封面则留空。

#### 1.5 标题（E列）

#### 1.6 正文（F列）
直接复制文案到表格，表格中的排版会同步到发布页。

#### 1.7 话题（G列）
按 #话题 格式填写，不需要则留空。

#### 1.8 地址（H列）
需要地点时填写，不需要留空。

#### 1.9 合集（I列）
从上往下依次填 1、2、3… 不选择留空。

[PRE30]

#### 1.10 群聊（J列）
从上往下依次填 1、2、3… 不选择留空。

[PRE31]

#### 1.11 定时发布（K列）
若选择定时发布，在 B 列填写“定时输出”，K 列填写时间格式如：2025-03-15 11:20。不使用则留空。

#### 1.12 状态（L列）
运行后自动写入，无需手动填写。

#### 1.13 商品id（M列）
填写商品 ID，多商品以斜杠分隔，如：67ced07a9635/671ae3e3a

### 2：启动页配置
开始行号：从表格第几行开始发布
结束行号：到表格第几行结束
发布时间间隔：默认 60 秒，过快易触发验证。

[PRE32]

完成表格后在 Edge 或 Chrome 登录小红书账号，再启动任务。
