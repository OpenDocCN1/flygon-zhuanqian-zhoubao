# 用一家店的成本跑三家店的量，实体在下行周期怎么把产能榨干

大家好，我是做奶茶的君宝。

今天聊一个我们实操下来的打法：在保留实体店的前提下，用低成本的移动摊位把门店产能拉满，实现一家店当三家店用。

我们是自有品牌，现在消费环境不好，大手笔开店风险高。上半年我们开始试水摆摊，用很小的投入把触点往外扩，效果比预期更稳。

目前单店月均营收在13万~15万之间，其中摆摊贡献了20%~30%的份额。

启动摆摊后，门店的正式员工没有增加，只额外招了摆摊兼职，且采用提成制。所以摊位带来的增量，变成纯利的比例很高。

# 一、先说结论

核心思路很简单：依托现有门店做半成品，招兼职伙伴，用电动车去人流集中处售卖，把闲置产能变成现金流。

这里说的摆摊，不是老板亲自上阵的游击战，而是可以标准化复制的轻型分销，适合规模化推。

### 私域沉淀

[PRE2]

广工9个群、华师4个群，再加上门店本身的9个群，基本每次出摊都能清空库存。我们在灯箱上印群二维码，每次出摊前在群里通知，卖完也会在群里告知，避免大家白跑。

因为摆摊受天气、人手、备货量影响，出摊信息不稳定，客户必须在群里才能第一时间获取。群里基本不做重度促销，粘性依然很高。

摆摊前门店就用企业微信做运营，后来延续到摊位上。现在企业微信从年费变成了人头费，成本上去了。想快速验证 MVP 的朋友可以先用个人微信起步，长期运营还是要回到企业微信。

### 利润模型

稳定下来后的表现：一个点位每天出摊约3小时，营收在1.5万~2万之间，毛利约75%。兼职按杯提成，提成占比约20%。

开店的人都懂，线下门店的租金、折旧是刚性成本，不管月做50万还是5万都要付。员工空闲时让他们在店里把半成品做出来，并不增加额外成本，这样摊位赚来的钱几乎都是净增益。

这套逻辑跟美团外卖早期很像：平台只抽成交，有单才收费，门店没单也不用付费，保持员工不闲置，忙的时候还能把平台关掉。理想状态是皆大欢喜，可现实大家都懂。

# 二、调研与前置准备

### 选点：合法 vs 非法

合法摆摊是有固定摊位、统一管理、通常需要交租金的模式。

好处是不会被赶，可以长期经营，能摆桌椅，部分场地方还提供电源。

坏处是租金不低，好的位置和门店租金相当，有些还要押二付一；差的位置人流和消费力一般，竞争也激烈。

非法摆摊也就是常说的走鬼，会被城管驱赶甚至扣车，但只要点位选对，就是绝对的蓝海。我们现在的几个点就属于这种，下课时段人流每分钟300+，出手快的话20分钟能出20~30杯，备货少时半小时清完，风大鱼大。

非法摆摊的优劣和合法的正好相反，不再赘述。

[PRE4]

### 产品打法

产品是门槛最高的环节，涉及半成品制作、运输、储存、售罄返店，以及摊位定价。

摊位价要比店内低，才能和周边摊位竞争，但又不能太低伤品牌。半成品做好后，还要在有限的车载设备上完成门店同质化的成品化，这点要和车辆设计一起想。

每个店的产品不一样，即便都是奶茶，豆沙牛乳和柠檬茶的摊位逻辑也有五成差异。给同行几个通用建议：

* 品类极简，挑门店里卖得最好的2~5款即可
* 选高毛利爆款，因为摊位要给兼职提成，定价弹性小
* 能共用门店产品最划算，摊位卖不完返店，店里卖不完补摊，减少损耗，也减少员工操作复杂度
* 尽量在门店做到80%，摊位只做最后20%如加热、装杯、搅拌，出杯更快
* 避免完全预制成品售卖，有现场制作感才有溢价。哪怕只是最后装杯、淋酱，也能给客户现场感

#### 车型

核心看出餐效率，三轮、四轮、两轮各有取舍。

两轮车机动性最强，基本畅通无阻，非法摆摊时城管通常睁一只眼闭一只眼。缺点是操作空间小，出杯效率受限。

小科普：城管一般开皮卡机动差，看到皮卡就撤；执勤人员只会赶人没有扣车权。两轮被查的风险远小于三轮，我们去过收缴点，被扣的车95%以上是三轮。

三轮车成本比四轮低，载货量大，焊上不锈钢台面后出餐效率接近门店，但非法属性强，交警城管都可能扣。

四轮即汽车尾箱摆摊，多是情怀玩法，不适合标准化复制，不在此讨论。

### 人员配置

除非生意爆到离谱，一般一个点位一个人就够。

现在人员成本占比20%，还不含车折旧、损耗、充电费，合法摊位还要摊位费。利润是抠出来的，能单人完成的就别加人。

抓准人流潮汐，一小时高峰顶十小时低谷。如果时段极度集中，可安排两人，采用更高底薪+更低提成。

# 三、放大与差异化

### 如何做出区隔

* 视觉统一：摊位VI和门店一致，品牌感强
* 明确告知有实体店：和纯地摊区分，主打干净健康更有说服力
* 公域私域联动：摊位和门店一起做流量
* 摊位可导流门店产品：不满足摊位品类的顾客可在小程序下单，兼职顺路自提配送

整体是降维打击：比地摊更专业、更干净、线上运营更强；比门店更便宜、曝光更好。

### 公域与私域协同

#### 公域

对我们圈子的朋友来说，公域不难。

把每个摊位做成IP矩阵，发日常出摊剪辑，标题套路：

“五线城市/00后摆摊”+“摆摊的一天”+“大几千/过万营业额”

* 提前告知出摊时间与位置

还有一个隐藏收益：兼职顺路配送外卖单。顾客想点店里没有的品，可在小程序下单备注自提，兼职出摊时带上，省下平台配送费。摊位离客户近，取件更快，兼职有提成，门店成本降，客户体验也好，实现四方共赢。

自然也能统一参与门店的节日新品折扣，摆摊履约让优惠覆盖外送，解决传统外送低价割裂忠诚用户的问题。

### 薪酬结构

最终看时薪是否匹配辛苦程度。

我们采用纯销售提成，按杯结算，兼职时薪约30元。

这个水平不算低，但外人看不到模式也会觉得不靠谱。也可以底薪+提成，但底薪不能高，否则摸鱼无法监管。

另一种是进货合伙人模式：你负责半成品生产，他来售卖，卖多少算他的，不挂你招牌。如烧烤店把腌好的鸡翅给周边摊位代卖，或直接卖给同行。模式选择看产品属性和精力。

精力足建议自营，精力有限可走供应商模式。

### 如何避城管

各地规则不同。

能稳定拿到合法摊位的当然更省心。没有的话，需要长期摸排，了解执勤规律，制定应急SOP。我们几个非法点，现在兼职上手后也能熟练应对，有一定复制性。

# 四、总结：门店加摆摊的价值点

* 人流大、租金几乎为零、时间灵活
* VI统一的车辆更有品牌力
* 微信沉淀用户，且有实体背书不易反感
* 营销与门店打通
* 不确定性带来稀缺感
* 可顺带完成团购配送
* 利用门店设备与人力做粗加工，比纯地摊成本更低
* 流程SOP化，更易区域复制
* 产品力通常强于传统地摊

最后说一句：就目前来看，摆摊的投入产出比，比美团拼好饭、抖音团购等渠道都高。平台大折扣对线下老客其实是一种伤害。

摆摊只是餐饮老板的众多招式之一，和学会外卖运营、点评维护、小红书探店、抖音团购一样，没有谁绝对优劣。知道这一招在手上，用不用怎么用，看自己。
