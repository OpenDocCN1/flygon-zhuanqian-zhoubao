# 小红书图文批量二创全自动工作流：从链接到爆款封面的保姆级实操

> 来源：[https://mcno4in90kc5.feishu.cn/docx/GtgBd8B0moVCNqxnRW0cXxJwnic](https://mcno4in90kc5.feishu.cn/docx/GtgBd8B0moVCNqxnRW0cXxJwnic)

大家好，我是甜甜。

做过电商的都知道，同行就是最好的老师，这条规律放在小红书AI虚拟电商上同样适用。抄爆款是提效最快的打法，而一篇小红书笔记由标题、正文、封面三部分构成。传统做法要切图、开修图软件、再用AI改写，一套流程下来十几二十分钟就没了。我把整个链路拆了再拼起来，用飞书多维表格+扣子工作流做自动化，丢一个链接进去就能批量产出二创图文和封面，效率直接拉满。今天这套教程就手把手带你搭起来，照着做你也能高效变现，先预览一下最终生成效果。

本次会用到：飞书多维表格、扣子工作流

# 第一步：搭建多维表格

打开飞书：https://jcnql2b38je5.feishu.cn/drive/home/

进入首页点击新建，下拉菜单里选择多维表格

[PRE0]

点击新建多维表格

[PRE1]

进入初始表格界面，鼠标悬停在第一列，点击倒三角，选择修改字段/列

[PRE2]

把列名改成“小红书链接”，确认后保存。这列用来批量粘贴笔记链接，后续所有二创都基于它触发。

[PRE3]

第二列的任务是把第一列的链接里的标题和正文抓出来。多维表格本身不具备抓取能力，需要借助扣子工作流来完成。

# 第二步：搭建提取标题正文的工作流

打开扣子：https://www.coze.cn/home

进入主页后点击资源库

[PRE4]

点右上角资源，选择工作流，进入创建工作流页面

[PRE5]

先填写工作流名称，只能用英文、数字、下划线，描述随意填，确定后进入编辑区

[PRE6]

工作流编辑界面初看有点懵，其实很简单。没有编程基础也能搭。

[PRE7]

先科普一下：工作流是由多个步骤按顺序串联的任务流，就是让AI机器人按你设定的步骤执行。节点=一个步骤，连接线=步骤间的流转方向。

初始页面只有输入节点和输出节点，我们需要中间加功能节点。点击添加节点，选择插件，找到现成工具

[PRE8]

搜索框输入“小红书提取”，右侧会出现对应插件，点击添加。插件功能说明会写明用途，确认无误后即可添加

[PRE9]

节点添加完成后，用连接线把它们串起来。节点位置可以随意拖动，只要连通就能跑通。

[PRE10]

选中小红书提取节点，变量名设为开始 input

[PRE11]

再点结束节点，默认有一个输出变量，可在右上角添加。分别新建 title 和 content 两个输出变量，对应标题和正文。若变量名仍是 output，请手动改为 title / content

试运行测试。复制一个小红书浏览器链接，注意要用带 xsec_token 的浏览器链接，不要用右下角分享链接

[PRE12]

在 input 输入链接后运行，约2秒即可返回结果，说明可用

[PRE13]

测试成功后点击右上角发布

至此提取工作流搭好，下面是完整视频操作

# 第三步：多维表格接入扣子工作流

回到多维表格，新建第二列，修改字段/列，列名改为“提取小红书链接”。字段类型选探索字段捷径，搜索“扣子”，选择扣子工作流调用

配置页面需要依次填写：

[PRE14]

## 1.认证令牌
进入扣子主页，点击API管理→授权→个人访问令牌→添加
或直接访问 https://www.coze.cn/open/oauth/pats 添加
[PRE15]

按视频指引操作，权限选 run，工作空间与工作流保持一致，确定后会生成个人令牌，复制到飞书表格配置里。注意令牌只显示一次，请保存好

## 2.工作流ID
工作流地址里能看到 workflow_id，复制数字部分填入多维表格

[PRE16]

[PRE17]

## 3.参数与输出
（1）参数字段选第一列的小红书链接
（2）参数名称填 input
（3）请求模板两种写法均可
第一种：{"input":"引用的字段"} 引用第一列链接
第二种直接粘贴：
{
"input":"[PRE18]"
}
（4）输出结果1对应 title，输出结果2对应 content
（5）获取更多信息，勾选输出结果1、2
（6）生成范围可选全列或自定义行数，默认全列即可
（7）打开自动更新，开启后第一列粘贴链接会自动触发抓取，不开需手动执行
（8）点击确定，若第一列已有链接会弹出是否生成，选择生成即可

配置完成，复制一个链接测试，输出会迅速自动更新。建议把输出列重命名为“小红书标题”“小红书正文”，更直观

# 第四步：对正文进行二创

下一步是对提取到的正文改写，选最新一列操作

把列名改为“小红书正文二创”，字段类型选探索字段捷径，搜索豆包，选择豆包1.6模型，deepseek也可自选

[PRE19]

填写提示词，引用小红书正文字段。我用的指令很简单：“这是小红书的正文，请帮我写个类似的小红书文案，意思保持不变，字数相近，标签照抄，输出可直接发布”

可根据需求自行调整提示词
是否深度思考，我选不进行，可选AI自行判断
获取更多信息勾选输出结果，打开自动更新，点击确定

[PRE21]
