# 不想打卡上班，多数人只是还没摸到自己的节奏

> 原文：[`www.yuque.com/for_lazy/zhoubao/dvqdm1q6yleyrgdt`](https://www.yuque.com/for_lazy/zhoubao/dvqdm1q6yleyrgdt)

---

大家好，我是沧海大表哥。最近参加了一次线下见面，和一批对上班这件事感到疲惫的朋友聊了很久。交流下来发现，大家的卡点出奇地一致。我自己从在职做副业，到全职自由，再到小规模创业，已经走了三年。这次碰面让我更坚定一个判断：**说不想上班，本质不是逃跑，而是还没有找到一条能够落地且能持续走下去的路。**

## 先对齐位置：你现在卡在哪一段

来的人基本分三类：还在公司里观望的、正在试水自由的、以及已经在筹备创业的。

我的路线是：**在职期间做副业验证 → 转为自由职业 → 轻量创业**。

不过这三年里，我看到更多的是反复折腾却原地踏步的案例。

有人看见小红书出单就冲进去，几个月后嫌自己不擅长或赛道太拥挤便撤了；有人沉迷工具，AI绘画、N8N之类的玩一轮新鲜感没了就换下一个；还有人一上来就想做IP做产品，忙活半天连第一笔收入都没进来。

如果你心里也冒出了离开公司的念头，别急着辞职或跟风。下面这套底层思路未必能保证成功，却能帮你少绕不少弯。

## 第一步：别先问做什么，先问能不能做很久

这三年被问最多的问题是：“现在做什么能快点脱离职场？”

但回头看，最难的从来不是找项目，而是判断这件事能不能陪你走很久。

很多人起手就错了：

- 看到小红书在变现就去注册；
- 听说AI号能赚钱就一头扎进去；
- 甚至有人想做一个能吃一辈子的产品，花三个月打磨，最后连用户在哪都不知道。

结果多半是几个月后遇到天花板，或自己先撑不住，心态崩了、钱也没了，只能换方向续命。这不叫试错，这叫一次次归零，过去的积累全被清零。

给不想上班的人一个建议：

**先锁定一件即便外部环境变化也不会消失的事，或者即便横跨多个赛道，也要让它们能够互相赋能。**

举个例子，做职场求职陪跑，简历修改和面试辅导是同一批人群、同一套交付。改简历的客户会复购面试辅导，面试辅导的客户也会介绍朋友来改简历。这种复利才是有效的。今天做AI绘画明天做母婴带货，看似很忙，回头看其实一直在原地徘徊。

当然也会有人说：“我就是喜欢新鲜，对重复的事很烦，受不了缺少0-1的刺激。”

这很正常，并不是所有人都适合把1做到10。

我见过有人几天就能跑通一个小项目赚几千上万，但让他招人、建流程、写SOP就犯怵。也有人一直追新技术，N8N、AI编程Agent换着玩，永远追热点。

如果你属于后者，别逼自己去做极致垂直，那反而是自己为难。对你而言，垂直本身就是种折磨。

更适合往资源整合的方向走。你本来就爱接触不同行业、不同信息，那就把这些信息连起来。比如帮做AI的人对接需要技术的中小商家，帮做副业的人牵线流量渠道。

在没有体系前，我曾参加过20多期不同商业项目，没有一次打卡完成，也没拿过退款。但每次都能拆出底层逻辑：项目怎么设计的？报名的人群是谁？他们为什么愿意付费？这些观察后来帮我解决了不少用户的困惑。

兴趣广泛不是缺点，关键是把“爱尝鲜”和“长期沉淀”结合起来，而不是被新鲜感牵着走。

## 第二步：0-1阶段别搞复杂，先做一步就能回血的事

如果你还在职场，想先做副业试水，没有老师带的话，千万别一上来就学别人搞闭环——做产品、定定位、做流量、做销售，新手基本会被耗光热情，最后啥都不想干。

0-1阶段核心是什么？

**快速拿到正反馈，做倒买倒卖。**

什么能让你迈一步就见钱？利差：信息差、资源差、平台差。别觉得倒买倒卖不正经。对新手来说，先赚到第一笔钱比什么都重要。

我第一次靠副业赚钱就是靠资源差。

2021年我还在公司当设计经理，手下有位同事离职后做抖音特效道具，500块一个，瞄准中老年“丑萌”风格很吃香。我一看就明白，这东西不用原创，找素材拼一拼就行。一周跑通流程后，我在QQ群、APP上找兼职，把流程免费教给他们，我负责对接平台、发工资。那段时间最忙的不是做业务，而是每天给兼职结工资。

现在我主业是带不想上班的人从0到1起步个人事业，用他们的技能爱好做产品，系统带一次商业闭环。而我现在的被动收入，主要是卖AI账号和资源变现，就是典型的倒买倒卖，吃信息差和资源差。单笔利润有时候只有几块钱，几个月下来被动卖了7000多单。

就拿AI账号举例：任何用AI的人都需要各类账号，不管是镜像还是官方。我把资源整合起来，有人买就发链接，不懂就甩教程，不用交付、不用售后，相当于被动收钱。

难吗？AI时代，找到几百上万人用AI并不难，任何平台都能触达。

我靠这个月入1-2万，4月GPT-4o出来那阵子单月冲到5万。再加上其他两个设计被动小项目——解决设计需求和业务对接，有业绩我抽成——这样月被动收入稳定在3-5万。

有了这笔钱兜底，才有心思探索更长期的方向。

很多人看不上小钱，觉得要做就做大活。但你想过吗？新人上来就做商业定位、产品、内容、销售、运营，至少是五步走完才能变现，难度极高。多少人连五步都走不完，更别说赚钱了。

反而赚利差的钱，先学会倒买倒卖，尤其在生财这类圈子，机会和信息到处都是。不需要产品，不需要会引流，发个朋友圈、对接个资源就能变现。一次赚几十，也能让你亲眼看到自己能赚钱，这种即时正反馈才是坚持的动力。

就像国庆假期Sora火了，大家都在找邀请码。邀请码本身免费，但我看到有人把邀请码挂淘宝卖50块，卖了几百单。这就是用信息差和认知差赚钱。

你可能会想，闲鱼才3-5块，他怎么敢卖50？这跟能力技能无关，只是他知道这个信息，懂得人性。

还有个误区要提醒：别以为存半年生活费就能辞职做自由职业。

我见过太多人存了几万就辞职，辞职后时间自由，想熬夜就熬夜，想几点起就几点起。几个月后焦虑，半年后钱花完，又灰溜溜回去找工作。

真正的准备，不是半年生活费，而是**1-2年生活费 + 一个能产生现金流的小项目**。有被动收入兜底，你才不慌，才不会在内耗里浪费时间。

## 选赛道不是选热点，是选你能赢的对手

当你靠小生意或倒买倒卖稳定了收入、有了一定积蓄，自然会想往更长期的方向走，这时就会碰到选赛道的问题。

很多人问：“现在什么赛道火？AI、跨境、私域，我选哪个？”

**选赛道不是选风口，而是选你能打赢的对手。**

先想清楚：这个赛道的天花板是谁？他们做了多久？资源、人脉、经验比你强多少？你进去后凭什么赚钱？遇到时你有什么优势？

我当初决定做“帮助职场人转型自由职业”，不是因为赛道火，而是我就是这么走过来的。

三年前我就相信越来越多的人会离开公司。我懂职场人的焦虑，懂自由职业的卡点，懂创业初期的坑——这些经历就是优势。每年有上千万人离开职场，如果我当时跟风做医美，哪怕赛道火，我不懂行业规则、不懂用户，大概率早回公司上班了。

选赛道还有个技巧：**别垂直行业，要垂直人群。**

我认同现在只有两类人能赚钱，一类是头部IP，一类是极度垂直的人群。

**做核心赛道的核心人群的核心需求。**

行业会变，比如去年火的数字人直播，我认识的大佬今年就转行了。

但人群需求不会变——设计师永远有“想做副业”“不想上班”的需求，职场人永远有“提升收入”“转型自由职业”的需求。

我曾把朋友圈分为设计师和非设计师，同一条文案发两次，80%的付费用户都是设计师。

后来拆解他们的需求：做AI账号、学AI绘画、找副业方向、辞职创业——覆盖了从职场到创业的全链路。

于是我针对设计师做上下游延伸：带他们做AI绘画，带他们做副业，再陪他们转型自由职业。这样用户复购率很高，很多人在我这里付费5-8次，甚至跟着做高客单项目。

反观只垂直项目的人，比如只做AI绘画教学，一旦热度降、技术迭代，用户就走。因为他们跟着项目走，不是跟着人走。

而垂直人群，用户是跟着你走的。哪怕你换项目，只要能解决他们的新需求，信任还在。

## 定位不是固定的，而是动态调整的

聊到长期发展，很多人卡在两点：一是定位太死不敢变，二是对标只抄项目没抄到根。

先说定位。很多人觉得定位定下来就不能改，其实不是。

定位是**动态的**，核心是你做这件事不累、不排斥。

我一开始定位是“教大家做AI相关项目”，后来发现很多用户学完就走了——他们跟着技能走，不是跟着我走。

于是我调整为“帮职场人解决转型问题”，从AI账号到副业规划，再到创业陪跑，只要是转型路上遇到的问题，我都解决。慢慢地，用户开始跟着我走，复购率越来越高。

## 对标不是抄项目，而是抄人

再说对标。很多人只看对方做什么项目，比如对方做小红书引流就跟着做。对方卖199的课，我也卖199。

这种对标永远只能跟在后面。

真正的对标是“抄人”——找一个和你很像、多次拿到结果的人，抄他的思维方式、路径、决策逻辑。

我之前想做高客单陪跑，就对标了一个年赚1000万的同行。

我没抄他的课程，而是花1.8万付费，还花了三个月追他的动态：看他公众号早期文章，分析标题逻辑，听直播，拆话术逐字稿。

花钱是最快的办法。我研究了他的交付流程。

最后发现，他早期卖599，后来涨到999，不是因为贪心，而是投流成本涨了，599会亏，999能打平成本，后面靠高客单赚钱——这个定价逻辑比抄课程内容有用得多。

更重要的是，找和你像的人对标。

比如你性格内向，就别对标靠直播爆火的人；你刚毕业，就别对标有十年经验的人。

我有个做广告公司的学员，线下生意下滑想转线上。我让她对标一个同样广告出身、性格内向但擅长做内容的人。她照着我的方法拆解对方，把自己的经验做成课，几个月卖了108万业绩，基本都是利润。目前她已出4门课，最近又卖掉一百多份。

**为什么抄人比抄项目靠谱？**

因为项目红利会过时，比如去年的数字人直播，今年就不火了。但人的做事逻辑不会变：怎么找用户、怎么设计产品、怎么解决问题——这些底层能力能帮你应对任何变化。

## 不想上班，不是不工作，而是选对工作方式

有人问：“什么事业能做20年、30年？”

我的答案是：“这件事老了回想起来会觉得值得，而且做的时候不排斥、不痛苦。”

比如做外贸的朋友担心AI冲击、跨境内卷，问外贸能不能做一辈子。

别先想宏观，先问自己喜不喜欢做外贸。如果你不讨厌和客户打交道，不排斥对接资源，那就先做着。1:7的汇率差摆在那里，只要找到差异化，比如擅长服务小B客户，或能帮客户解决供应链问题，就有赚不完的钱。

还有刚毕业的小伙伴想把营养健康当副业，纠结要不要专注。

我告诉他：“先别想喜欢，先看阶段。你刚工作两个月，没存款、没经验，不如先做轻量尝试——在朋友圈分享营养知识，帮身边人做简单饮食规划，先赚第一笔钱。稳定了再考虑深化。”

很多人把不想上班理解为不工作，其实不是。

我们不想的是：被打卡束缚、被KPI绑架、做不喜欢的事。

我们想要的是：能掌控时间、能赚自己认可的钱、做有积累的事。

不想上班的路径从来不是一步到位，而是**先迈小步，再迈大步**。

先靠利差赚到第一笔钱，再靠对标找到方向，最后靠积累做成长期事业。

慢慢来，不着急。让自己更靠谱，有积累，更长久。

希望你也能找到属于自己的不上班之路，既能养活自己，又能活得开心。
