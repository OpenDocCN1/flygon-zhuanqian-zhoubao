# 一、走过的路

大家好，我是王小小，在生财混了好几年，踩过的项目不少。21年那段时间跟着淘宝虚拟的帖子，把内容打印出来照着做，一次性孵化了20多家虚拟店铺。

[PRE0]

22年刷到影刀这个工具，顺着帖子里介绍和B站上几个UP的拆解视频入门，后面系统学了官方课和UP的实操，慢慢上手影刀并搭了不少小应用。

23年跟公号爆文航海一步步打法，也出了几篇爆款，那个阶段基本是在死磕公众号。

认识到B站好物是在6月，超级标里看到的提示，后面进星球拿资料，7月初就开始尝试。中间状态很摇摆，做两天停三天，想撤又觉得可惜。最后干脆加入深海圈，给自己定死一个小目标：先把报名费挣回来。结果真就靠第一笔佣金把门票回本了。

这段经历里，我的心态转折点在哪？做了哪些取舍？

# 1.从图文爆文到视频带货，心态的震荡

从公众号图文直接跳到B站视频，玩法熟但感受全变了，尤其心态被重塑。

1. 载体从文字变成镜头，对着机器说话极度别扭，画面里自己僵硬。
2. 一条成品视频，拍加剪要耗掉6个小时，体感成本很高。
3. 初期选的品客单偏低，佣金只有1%-3%，算下来根本覆盖时间投入，这点最磨人。
4. 带着公众号的播放焦虑，数据一不高就想停更。

视频播放平平、没成交或佣金少，就陷入间歇性操作。直到有一单近3000的成交，佣金大概50块，换算成公众号要1-2万阅读量。那一刻特别亢奋，突然明白B站上真有人愿意为高客单买单。明白后心态稳了，选品开始较真，行动也连贯了，不再拖延。

紧接着一周内又收了一单两千多佣金的，彻底确认这个赛道可以长期深耕。

镜头恐惧这件事，我后来给自己做过梳理：比起没钱，怕镜头、怕被熟人认出来都不值一提。用自己的双手挣钱，没什么好尴尬的，没钱才丢人。

# 2.B站好物为什么值得做下去

21年学影刀时我就已经在接触B站，和别的短视频平台比，这里娱乐内容占比低，偏知识分享调性，更像知乎。我21年也试过写知乎，入场太晚，最后退回研究淘宝虚拟。

做过爆文的人都清楚，号一旦爆发收益很高，但生命周期很短，基本是注销注册再注销的循环，久了人会麻木。

恰在此时看到B站好物，感觉空间很大。现在竞争还不算激烈，分佣机制是全额给创作者。我的视频播放量不算顶，也能出单，当下就是发出来就有变现机会。

把京粉8月的数据放上来：GMV约4万3，佣金2100。订单总量其实不多，能把深海圈费用赚回来，主要靠一笔高佣订单，后面选品部分会讲我是怎么锁定到它的。

# 二、选品决定生死

选品在电商里就是生死线。

多数人以为B站好物就是数码，对女生不友好。其实没那么绝对。

我用了一个笨办法但效率很高：先把京东排行榜的类目抓下来，拿到一二级三级类目词，用数据透视看类目活跃人数，找到可用的产品词，再放到B站看竞争热度，最终锁定适合自己的方向。

这么一捋，发现适合女生的赛道不少：零食测评、个人护理清洁、宠物用品、母婴用品、厨房小电、生活电器、床品、运动用品、家居饰品等等。

B站其实存在高付费人群，愿意在站内高消费，选品时就可以兼顾单价和佣金比例，后面我踩过一个坑会专门讲。

具体流程拆一下：

# 1.抓取京东排行榜

京东排行榜是手机端功能，纯手动找效率低。我装了雷电模拟器，用影刀的插件把手机端搬到电脑上采集。采集多了京东会触发滑块验证，后面就改用真机采。采完才发现一个现象：三级类目词不是固定的，每次采集都会产生新词。

也可以直接用影刀抓京东全站分类，内容大体一致，只是少了排行榜的一级定位判断。

[PRE4]

[PRE5]

# 2.清洗数据，定位一二三级类目

把类目人数中的“万”替换成0000，“正在逛”也统一替换，建立透视表。

透视表分三区：第一区只放一级类目降序；第二区在透视筛选器里放一级类目，比如家居家装；第三区再放二级类目，比如厨具。三级类目的数据就是清洗后的结果。

京东排行榜共32个一级类目，我先挑了7个试水。表上一看数码占大头，手机电脑为主，我不感兴趣。剩下家居家装往下钻，到厨具这个我能写的方向，再继续往下筛，最终筛出平底锅。

[PRE6]

# 3.B站查竞争，判断能不能做

把清洗后的平底锅放到B站检索，竞争不算激烈。23年、24年的内容多，25年5月、8月、9月各只有一条左右，内容也偏单薄。说明有流量空间，做进去有机会转化。

同理高压锅、砂锅、蒸锅、汤锅也能一起查，顺势拓展出4个品类。

我用同样方式筛家电里的空调，23-24年视频很少，4-6月的却扎堆，说明同行在卷，我就放弃了。

[PRE8]

# 4.查分佣，确定最终推广品

确定能做后，去京东联盟和淘宝联盟找匹配的商品链接。B站后台给的佣金比例可能有偏差，必须以联盟为准。

https://pub.alimama.com/portal/v2/pages/promo/goods/index.htm 淘宝联盟
https://union.jd.com/proManager/index?pageNo=1 京东联盟

京东选品要看自营与否。非自营出单分成60-90%，自营是100%。实际到手佣金=计佣金额×佣金比例×分成比例。

平底锅上千款，手工筛太慢。我让影刀打分，维度是佣金金额、佣金比例、好评数量，三项相加取总分再降序。

[PRE10]

深海圈里对高客单的粗略分层参考：
1. 100元以下，10%-30%
2. 500元以下，5%-8%
3. 1000元以下，3%-5%
4. 2000元以下，1-3%

分佣比例要按个人承受度来，不要盲目追高单价高比例，综合指标看。

[PRE11]

那笔两千多佣金的订单，就是按这个打法筛出来的。

最难的环节是数据清洗，需要联动三个透视表筛选一级二级类目，再一层层往下钻到三级类目。有些品词套词很像，多练几次就有手感。第一单50佣金后，我的选品耗时从3-4小时压缩到1-2小时。

# 5.备份链接防失效

品选定后链接不要删。商家销量起来可能降佣金或断货，需要备选。我习惯备份格式：A000X-商品名称。

# 三、蓝链操作细节

选品完就要挂链，B站挂链流程繁琐，细节决定转化。

# 第1个细节：投稿流程

B站上传视频的入口在投稿页，标题简介后点商业推广。没勾商业推广就违规。我的习惯是先在商品计划里建好计划组，再去投稿。

谷歌浏览器编辑蓝链偶尔会卡死，只能关掉重开。计划组相当于多了一层备份。

[PRE12]

[PRE13]

[PRE14]

# 第2个细节：排序问题

不用计划组一次性批量加20个，评论区展示顺序会倒置。建议用计划组添加，保持预期顺序。

# 第3个细节：短标题

挂链后要把长标题改成短标题，用户一眼能辨认。格式一般是品名简称+价格。改完要点空白处保存，右上角关闭会自动保存。同品只改一次即可复用。

[PRE15]

# 第4个细节：分区展示

蓝链挨在一起用户看不清，需要点一下商品中间回车隔开，并按价格或品类分区，减少挑选时间。

[PRE16]

[PRE17]

# 第5个细节：二次加链

评论区一次最多20个。想追加就去置顶评论里回复添加，不能直接在视频下留言，不然会被顶下去。

# 第6个细节：手机回链

视频发完后，如果有人留言要推荐，电脑回复会被系统删，只能用手机发链。评论区留言的用户购买意向最高，直接甩链接转化更快。

把蓝链和评论区维护好，订单自然增加。评论区有人引流踩盘，直接拉黑删评论即可。

# 四、踩过的坑

# 1.忽略金额和佣金比例

选鼠标垫时没看佣金比例，挑到0.1%的坑品。用户下5单，京东只记1单量，佣金几乎为零。白忙活一场。

[PRE20]

# 2.京粉活动没及时跟

B站带货除了商品佣金，还能拿京粉活动补贴。超级补贴奖励只能在京粉APP操作：首页-奖励活动。活动奖励在我要推广-活动奖励里，可一次性申请全部。

我踩的点是同一个类目第二天出单没补贴，后来查到是活动过期。现在每天看一次，有活动先报名再说。

[PRE21]

# 3.MCN机构申请的折腾

进深海圈前听说MCN号带货不用实名，就去申请https://mcn.bilibili.com/

第一次营业执照快满半年被拒，第二次还是不过，联系客服才知道需要法人与账号的说明材料。第三次才通过，却发现带货仍需千粉+实名认证，机构号个人号都一样。

# 五、收尾

项目切换总会消耗心态，B站目前仍是红利期，有足够时间适应。

想跟我一样卡在瓶颈的伙伴，别放弃。认真做选品、踏实做内容，几天内就能看到开单迹象。

一个人走得快，一群人走得远。感谢深海圈里的每一位伙伴！
