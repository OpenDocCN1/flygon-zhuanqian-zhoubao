## 3.2 机会是怎么来的

谁没跨平台买过东西？我家旁边就是菜鸟驿站，每次快递来都发短信通知取件码。取件时第一步要么打开淘宝/京东/抖音等 APP 一个个翻，要么打开短信在密密麻麻的广告里找码。快递多的时候更崩溃，各家发码方式还不一样。丰巢还会发公众号消息。每次都要先想想买了啥、在哪买的，再去对应 APP 踩广告。

用户路径：

1、人站在驿站 -> 回忆买了啥 -> 猜哪个平台 -> 打开 APP -> 看开屏广告 -> 一层层点进去找码

2、人站在驿站 -> 打开短信 -> 一条条翻 -> 找到短信 -> 点开看码

一件小事，路径却绕得要命，还要给各家 APP 送日活、看广告。

我当时就想，能不能有个工具把这事一次性解决了。晚上刷小红书，大数据神了，刚好给我推了 iOS 取件码快捷指令。我一看，这不就是我想要的嘛，立刻上手。

但诡异的是，这类笔记点赞收藏动辄几千，说明需求是真的大。

这个经历让我抓住两点：

1.  需求是真的旺： 快捷指令笔记热度很高。
2.  方案不友好： 配置门槛太高，大部分懒人直接劝退。

但我没放弃。把能找到的竞品都下了体验一遍，市场上就 3 个：取件了吗、取件助手、ezicode。体验完又活过来了，因为都做得一般。UI 土、交互不规范、信息架构乱。唯一能看的是取件了吗，小红书在持续做，用户也碾压另外两个，就拿它当主要对手。

需求挖掘路径：跨平台取件 -> 嫌麻烦 -> 数据推快捷指令 -> 半小时配失败 -> 产生想法 -> 调研产品 -> 凉了 -> 分析竞品 -> 还有机会

tips: 有 idea 别急着上，先调研市场。如果没人做，可能说明没人要；如果有人做且数据好，就要仔细研究他们做差在哪。

## 3.5 市场调研：从心凉到发现机会

市场需求验证，我当时问了自己三个问题：

问题 1：菜鸟裹裹都存在了，为什么这类产品还有需求？

问题 2：用户不用菜鸟裹裹，为啥愿意配快捷指令？

问题 3：市场到底多大？

问题 1：

菜鸟裹裹我之前根本没装，我靠 APP 和短信取码。我家附近就一个菜鸟驿站，所以没意识到问题。但用户评论让我发现信息差。很多人家附近不止一个驿站，可能有菜鸟、驿收发、妈妈驿站等，菜鸟解决不了全部。

[PRE4]

原因：

1、菜鸟广告多，用户嫌烦。
2、多个驿站覆盖不到。
3、菜鸟也显示不了所有平台的码。

所以对一部分人不是问题，对另一部分人就是刚需。

问题 2：

菜鸟的核心痛点还是没解决。想看码还是要打开 APP，看广告。路径不够极致。锁屏、组件、灵动岛直接展示才够快。

而且小红书用户本身就爱追求效率和体验，所以这类工具推广起来快。

问题 3：

规模 = 全国驿站数量 x 覆盖人群。

[PRE5]

除了菜鸟，还有大量其他品牌的驿站，群雄并起。就算只做菜鸟之外的用户，对我这个新手来说也够了。最初目标只是赚 1000 块。

市场足够大，各家驿站通知方式不一样，如兔喜用小程序、丰巢用服务号。

这些不足就是切入点。

#### 3.6.2 流量层

三个问题：

1、需求用户都被拿完了吗？
2、有增量，我能超过他吗？
3、能把他的存量用户抢过来吗？

问题 1：

观察“取件码快捷指令”视频，发现最近还在持续出万赞内容，说明还有用户没被触达。可能因为笔记曝光有限，也可能有新 iPhone 用户进来。

竞品近一个月笔记也在快速涨粉，说明还在增长中。

结论：用户没被收割完，有增量。

问题 2：

竞品流量起盘很素人，没参加过生财小红书航海，账号混乱，关注欲低。但数据依然好，说明需求强。

账号问题：

*   头像与产品无关
*   简介没说清是谁、做了啥
*   正文封面随意、色彩混乱
*   只有图文没有视频

所以只要我做到 70 分，就能超他。UI 不用设计师水平，封面和视频做起来就行。

结论：流量上可超。

问题 3：

从产品入口看，迁移成本高不高。

*   UI 能不能更精致
*   信息架构能不能更清晰
*   交互能不能更直觉
*   功能短期可能比不过，但可以先卖空气
*   最关键是体验差 > 迁移成本

俞军的公式：新体验 - 旧体验 > 迁移成本

功能上很难差异化，后面从定价上做差异化。

结论：竞品运营弱，用基础小红书方法就能反超。

### 3.7 打法：暗影复刻

分析完后觉得可以干。小排老师的暗影复刻：复刻头部 20% 功能，找头部没覆盖的人群和场景去解决。我就是这么干的。

# 四、增长与运营：从冷启动到闭环

亦仁说得对，先试流量。

5 月初上架 App Store，没推广，一周才个位数下载，还都是朋友。每天刷 Connect 失望透顶。后来决定学独立开发博主，在小红书发。

第一篇很随意，1 天阅读破万，评论区一堆问怎么下载。也有人说这不就是菜鸟吗？有人说伪需求。互动把笔记推上去了，第一天拿下约 1000 下载，成为种子用户。

tips:

1、2025 年了，酒香也得自己吆喝，独立开发必须会推广。
2、第一篇没技巧，需求强算法自己会推人。

# 五、社区构建与正向循环

用户用完产品，立刻引导进小红书群。高频互动，解决问题，汇报 BUG 进度。用户会觉得是活人、是身边人。信任感上来后，Pro 上线当天就有 60 人订阅。虽然 Pro 只多一个灵动岛功能，但信任让大家愿意付。

*   用户沉淀： 引导到小红书群
*   积极互动： 高频交流、解答、汇报进度
