# 那個讓人目瞪口呆的圈層

有些東西，光聽說遠遠不夠，得親眼見過才算數。

見識過，是底層認知被打開的開始。近距離見識過，才是能力真正被點亮的時刻。

我最近重刷了一遍一個特別的家族群像，說它是一個家族，是因為裡面的人彼此獨立，卻共享同一種基因：他們很早就開始做別人還在觀望的事。

這裡面有個名字被反覆提起的深度學習先行者。九十年代就已經在折騰的方向，到了今天才變成顯學。不是什麼運氣，都是長期主義的結果。

那個家族的門檻不低，但並非遙不可及。有人一語道破：先進來，群裡的精華帖全掃一遍，這就等於完成了第一次見識。想更進一步，就把自己的目標拆下來執行，做出成績，就能真正近距離地接觸到這些人，聽他們怎麼思考、怎麼決策。

見生財的，就是見高手。

這個圈子的價值，從來不在於給你標準答案，而在於讓你見識到一種活生生的可能性。有人因為見識過，才敢下注自己；有人因為近距離見識過，才知道努力的方向從來不是盲目追風。

見識，會篩選人。近距離見識，會改變人。
