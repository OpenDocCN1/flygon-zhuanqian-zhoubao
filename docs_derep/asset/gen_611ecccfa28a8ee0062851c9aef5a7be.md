大家或多或少都接触过，我们以前管它叫“脚本式 Prompt ”，因为步骤写得过于细致，就像一份现成的大纲，只需要把关键词替换掉就能用。

不过这种指令方式并不完全契合我的使用场景。不是说它不好，而是匹配度不高。

我当时想切入的是养老金、社保、民生这类领域。如果在这些领域里继续用脚本式，就意味着我要先收集大量领域方法论，对一个零基础的人来说成本高且耗时。

即便能借助 AI 快速拿到方法论并固化成 Prompt，可万一哪天我换赛道了呢？如果其他朋友也想用呢？为每个细分领域都定制一个 Prompt 太耗精力了。因此我换了个思路，做一个能跨场景通用的 Prompt 。

实际上，这个 Prompt 不只适用于公众号爆文，也适用于任何你想把对手爆款文案化为己用的情况。虽然现在看起来仍有瑕疵，但我觉得它提供了一个不错的思路和模板。

说这个点的原因是：最终调出来的 Prompt 很可能和最初设想的不一样，反而进化成一个更好的产物。所以学 Prompt 的第一步，就是动手，用自己的想法先写出来，不合适的地方再一点点迭代。Talk is poor, show me your prompt .

当我们把一级设定确定为 Role:文章模仿大师后，后续所有板块都会围绕这个核心展开，我们给它赋能、加约束、配属性词，使用特定的属性词能够确保定向唤醒模型的深层能力。

### 3、Attention

[PRE24]

在当时的设计里，这部分是用来起到强调和提醒的作用。从实际使用感受来看，在 Prompt 中适度加强强调，效果会更好。当然这只是我的体感，有没有更严谨的研究支撑暂时不确定。

另外，属性词的选择也很关键，你可以自行定义、增添或修改属性词。看到好的 Prompt 就多收集一些属性词。

### 4、Profile

[PRE25]

这部分主要是用于介绍创作者和记录版本迭代，同时指定输出语言，通俗易懂。

Description 是对角色能力的概括性说明，和 Goal、Background、Attention 看起来有重叠。

在文章模仿大师 Prompt 1.0 版本里，我对它们的区别做个简单总结，不一定完全准确：

1.  Description：对角色能力的基础介绍。

1.  Goal：说明你写这个 Prompt 想要解决的问题，即 Prompt 的目标。

1.  Attention：起强化提醒的作用，是否需要取决于提示词的目的。

1.  Background：为使用者呈现角色或任务的详细情境与信息。

再补充一个观点：

把 AI 当成朋友，你给它的反馈越多，情绪越饱满、任务越具体，它就越明白你的意图！！！

是的，如今的 Claude2.0 和 gpt4.0 已经具备初步的情绪感知能力，LLMs 能理解并通过情感刺激得到增强。想用好 AI，就要把它当成好朋友。

所以在指令中、在对话中，把自己的处境、困难也告诉它，传递一些情绪，AI 是能感受到的，虽然很微弱，但作用不小。

### 5、Skills

[PRE26]

Skills 这部分很好理解，就是你希望这个 Prompt 具备哪些能力，是对 Role 的补充。

举个例子：我希望你像孙悟空一样厉害，大闹天宫，天不怕地不怕，三界最强战力。这样的人应该有哪些 Skills 呢？给他筋斗云、七十二变、法天象地、金箍棒，孙悟空才有那个本事。

回到模仿大师这个 Prompt，我们需要的就是把一个优秀模仿者应有的能力，逐条赋予给 Prompt 。

如果自己想不出来，就把问题抛给 AI，或者用台风教练的角色生成器多生成几个，再把技能组合起来。这是个笨办法，但也无奈，因为我们都不是行业内的人。如果是，那直接把已知的方法论做成 Prompt 就行了。
