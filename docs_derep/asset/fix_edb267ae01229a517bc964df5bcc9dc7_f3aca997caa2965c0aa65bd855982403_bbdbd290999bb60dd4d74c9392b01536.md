# 1、视频号规则和起号

先把基础打牢，老手可跳过本节。

一、微信短视频的势能
抖音快手已验证图文向短视频迁移。2020年后用户习惯碎片化直观内容。微信自带14亿用户和熟人生态，视频号可挂公众号链接、可发朋友圈、可直播带货，生态仍在完善，机会明确。拿到权限就值得投入。

二、算法与审核
2.1 推荐逻辑
与抖快最大区别是分发路径。
进入默认是朋友页，且位于首页中部。点赞、看直播、动态全走社交链。
坊间说法是：好友点赞带来的社交分发约占55%，内容热推仅约15%。社交分发在视频号权重很高。

2.2 审核机制
双层审核：智能+人工。官方规则可扫码查看。

[PRE0]

智能审核：模型识别画面与关键词，判定违规会降权、删除或仅自己可见；严重违规直接删除或仅自己可见。判定不清则转人工。

人工审核：针对机器筛出的疑似违规，人工看标题、封面、关键帧。违规处理包括删视频、降权、封禁。

三、上手实操

1.1 注册与定位
微信-发现-视频号-右上头像-建立视频号，填信息通过即可发布。
名称不可重复，建议抢注。
一个微信仅可建一个视频号，企业号建议用合适号开通。可挂公众号链接导流，后续电商也有想象。
可转发好友、群、朋友圈，可点赞收藏评论。核心始终是优质原创。

定位要像开店一样垂直。
①做标签：如只做健身，后续脚本、素材、学习都集中于此，从浅到深建立专家感，用户才信任。
②精准用户：垂直带来同类人群，便于画像拆解。
③精准流量：人群越准，平台越打标签，内容越容易推送给目标客户，涨粉更快。

找垂直方向五步：
①调研、对标、结合兴趣
②复盘每次尝试
③收集外部评价
④多尝试多体验
⑤用旁观视角修正，让定位自然成形。

基础设置：
①头像、名称
一年可改名两次，头像可随时改。头像需辨识亲和，个人号可用形象照，企业号用logo。昵称简洁易传播，有名气可用真名。简介简短说明价值。背景图上下两段，下拉可做惊喜。头像昵称简介背景图避免硬引流。
②认证
兴趣认证、职业认证、企业机构认证。
路径：我的视频号-右上…-认证。
个人认证条件：近30天发过内容、粉丝100+、已填简历。
兴趣自媒体认证满足其一：该领域持续原创且视频号+公众号关注10万+；或除微信外其他平台粉丝100万+。
通过后显示金V，名称下方带身份。
企业机构认证需已认证同名公众号对接，每年两次机会，一个公众号仅认证一个视频号，通过后带蓝V。

发布要求：
路径：发现-视频号-右上相机-拍摄或相册-编辑-发布。
可多条发布，无次数限制。
封面不可选，默认首帧。内容以视频+文字为主，也可图片+文字。
视频最长1分钟最短3秒，图片最多9张。纯文字不可发，文案超三行自动折叠，上限1000字，可配话题#XXX。
横屏16:9 1080*608，竖屏9:16 1080*1920。可加公众号链接和定位。

前期曝光办法：
发布只是准备，发布后要运营。视频号是点赞才推给朋友，朋友点赞才继续扩散。
①自己点赞后发朋友圈，最基础，好友多运营好前期量不差。
②私聊推广早期有人用，现信息过载不建议。
③社群点赞群，需辨别是真实社交圈还是机器刷。真实社交链有效，机器刷无意义且易封号。

可对标账号：
读书类、健身类、生活类：行动的陈先生。
建议建账号库，收集合粉量低的爆款备查。

工具推荐：
文案灵感：梅花网、文案、金句谷
图片素材：Designspiration、Pinterest、Pexels、Unsplash
视频素材：包图网、摄图网
剪辑：剪映APP、快影APP
音频：迅捷文字转语音、音效素材站
录屏：录屏王、略格式录屏大师

常见问答：
①朋友如何找到你的视频号？无法被动看到，需主动分享名片或视频。
②谁能看到？被点赞后系统会推给点赞者的微信好友，任何人可关注。
③如何进热门？发布时带话题、配音乐、设地理位置，获得点赞后才有机会。
④鼓励什么内容？原创拍摄，搬运会被限推甚至处罚。
⑤能否换微信用？不可转移，只能用开通时的微信。
⑥为何模糊？用清晰原片，避免聊天转发的压缩片，导出建议1080p以上。

2、进阿猫《觉醒xx》内部视频号打卡群围观近百天
3、买下《梵野的xx-视频号赚大钱》，中午悄看+执行30天

前置工具：讯飞输入法+剪映VIP+美图秀秀+稿定，均有AI优化。
