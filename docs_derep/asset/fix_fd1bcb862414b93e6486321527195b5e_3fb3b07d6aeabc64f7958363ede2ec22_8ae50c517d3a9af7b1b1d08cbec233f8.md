# 为什么要做

iOS 端用户已通过快捷指令配合飞书多维表格实现了视频文案的一键获取，安卓阵营同样不该落后。本文将演示如何借助安卓平台的自动化工具，搭建一套专属的文案抓取自动化链路，让内容生产效率大幅提升。

# 你将获得

*   熟练掌握 MacroDroid 这款安卓自动化工具的搭建方式
*   学会组建 Coze 上的小红书文案抓取智能体
*   了解飞书多维表格如何调用自动化流程
*   掌握飞书机器人流程的构建技巧
*   学会使用飞书多维表格自带的 AI 插件

1.  输入令牌名称，建议与用途相关联，设置有效期、勾选【工作流】权限、选择工作流所在空间，最后点击【确定】：

[PRE33]

1.  记录生成的 API key，仅展示一次，请妥善保存：

[PRE34]

*   令牌权限范围需包含工作流操作权限
