# 商战面具背后

从小到大，我们眼里的商业传奇大多是光鲜的胜利叙事。那些灰扑扑、暗沉沉的细节，极少有人写进书里——但无论哪个国家，幕布后面的风景才是生意场的日常。

不少从大厂辞职的骨干、带着理想出来的年轻创业者，头一次撞见这些暗面时，常常觉得幻灭。他们以为自己走进了一处陌生丛林，其实不过是从温室踏进了原野。过去在大公司，难题多半被组织内部消化了，你只管把产品和服务做好；一旦自己干，一切矛头都会对准你。

接下来，各种各样的麻烦都会冒出来：有人当面耍横，有人背后使绊；同行联起手来把你挤出局；甲方伸手索要回扣；竞争对手写匿名信、打低分；媒体拿着真真假假的消息来施压；就连朝夕相处的合作者也可能因利益分配一夜翻脸。这些不是意外，不是你的命不好，而是这一行的本来面目。

遇见这些事，躲不掉就应对，但心里要有底线。损人的招数用多了，早晚会栽跟头。倒不如行得端、坐得正，踏踏实实做买卖。这并不难，只不过利润薄一些。赚得薄又怎样？至少不用整夜提心吊胆，也给自己留下了一条退路。

也别把这人间想得太过阴暗。看守书库的人，觉得来者皆读者；开设赌桌的人，觉得人人都好赌。一个人眼里有什么，往往是因为心里装着什么。你选择关注什么，目光所及就是什么风景。所谓成熟，不在于学会多少算计，而在于看透一切之后，仍然愿意守住自己的干净。
