# 数字人到底卷到什么程度？花钱越来越少，效果越来越像真人

前段时间我正琢磨 GPT 能用来干啥，因为本身是做自媒体的，数字人就自然被我盯上了。去跟投圈、科技圈和同行聊了一轮，才发现这事的门道比我想象的多，几个关键点记下来跟你分享。

第一，技术进步的速度真的有点吓人。第一次亲眼见到成品的时候，我直接愣住了，外观、表情、肢体动作，跟真人差距已经很小了，能有 99% 的相似度。

第二，别被自己的信息茧房骗了。你觉得酷炫很可能是因为你刚接触。横向聊一聊才发现，圈子里早有人把这玩意儿玩到审美疲劳了。多问几个人，避免自己当最后一个发现者。

第三，这条赛道其实不算新。17 年左右就有团队做数字人了，当时裹着元宇宙的概念讲故事，但技术没跟上就偃旗息鼓了。

第四，现在最变态的是成本。建模一次几千块搞定，算下来之后每分钟成片的费用能压到 2 块钱以内。更逗的是，很多打着自主研发旗号的公司，实则是代理商。中间再叠几层代理，价格还能再往下探。

第五，数字人再逼真也复制不了核心竞争力。它可以完美复刻你的长相和声音，但做不出真正优质的原创内容。IP 的灵魂终究是内容，不是皮囊。现在通过调教也很难超过本人，所以想靠它短期爆火成网红基本不现实。它更适合刘润、张琪这种已经站稳的头部人物来做分身增效。

第六，技术再强也怕没场景。资本现在最缺的就是落地的应用、流量的承接和能讲的故事。没有高级场景，加再多逼真算法，最后也只能沦为淘宝直播间里喊“321，上链接”的工具人，附加价值非常有限。

说到底，这事就像昨天我在 798 看到的清仓陶瓷。放到对的场景里，它就是值几百上千的艺术品；找不到位置，它就是几十块一件要赶紧清掉的库存[PRE0]
