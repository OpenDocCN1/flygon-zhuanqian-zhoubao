先从最关键的域名聊起。

**1.1 域名在谷歌眼里是什么角色**

域名是影响谷歌排名的信号之一。域名里是否含有关键词，会被当作匹配信号。所以理想状态是品牌感+关键词兼顾，比如 [calculator.net](http://calculator.net) 这种。

**1.2 选域名的注意事项**

后缀优先选：com / net / org / edu。我个人是 com 为主、net 备选。

别用连字符，域龄也要留意。

**新域名还是老域名？**

新手不建议碰二手域名，得有一定经验才能判断风险。

**1.3 域名挑选方法**

新手就记住一个核心：对标竞品的名字。

1. 用关键词调研工具深挖竞品关键词，长尾、同义词都要拿下。
2. 用 domain generator 这类在线工具碰撞灵感。

同时要兼顾几个硬指标：好记、没语法问题、品牌词和核心词能呼应。

怎么判断域名有没有“黑历史”？有黑历史会影响权重。

1. 用 [`web.archive.org/`](https://web.archive.org) 看历史快照，或国内的桔子 SEO。
2. 用 ahrefs / semrush 看外链质量，有没有垃圾外链。
3. 用 [`transparencyreport.google.com/safe-browsing/search`](https://transparencyreport.google.com/safe-browsing/search) 查是否被谷歌标记。

**1.4 去哪买**

namecheap、namesilo、godaddy 都能买，支持支付宝，记得开隐私保护。

我最常用 [`www.godaddy.com/`](https://www.godaddy.com) ，DNS 解析速度和响应都比较稳。

接下来是建站与 SEO 工具的选型思路。

### 「技术选型」

工具类网站：建议自己开发。

内容类网站：我常用的 CMS 方案有

1. Wordpress
2. Hexo
3. Nextra，支持多语言且对 SEO 友好

### 「服务器选型」

看站点类型来定。

1. 内容站或纯静态 HTML：推荐 github page、vercel ([`vercel.com/`](https://vercel.com))。
2. 工具站：主流云厂商都可以，Google Cloud、AWS、阿里云海外节点都行。

我的实操组合是：工具本身部署在云厂商服务器，对应的 /blog 内容区就用上面那套静态方案。

### 「谷歌 SEO 打法」

**技术层面：**

1. wappalyzer 插件，拆解竞品技术栈
2. GTmetrix：[`gtmetrix.com/`](https://gtmetrix.com/)
3. 谷歌官方 PageSpeed：[`developers.google.com/speed/pagespeed/insights/`](https://developers.google.com/speed/pagespeed/insights)

**内容层面：**

1. DeepL 做深度翻译
2. 原创度检测：[`www.copyscape.com/`](https://www.copyscape.com/)
3. 抄袭检查：[`www.quetext.com/plagiarism-checker`](https://www.quetext.com/plagiarism-checker)
4. 语法润色：[`app.grammarly.com/`](https://app.grammarly.com/)

**SEO 建设层面：**

1. 小排老师的 KeywordSea：[`keywordsea.com/`](https://keywordsea.com/)
2. similarweb 插件
3. Keywords Everywhere 插件
4. MozBar 插件
5. Detailed SEO Extension 插件
6. ahrefs
