# 个体户执照线上注销全记录：从卡壳到搞定

> 来源：[https://w63nbfedzw.feishu.cn/docx/SWjJdUHzloxKjCxplUsc7AYpnXc](https://w63nbfedzw.feishu.cn/docx/SWjJdUHzloxKjCxplUsc7AYpnXc)

先说下这篇记录的诞生经过：2024年12月31日就起了草，写完前半段便因审核搁置，中间还撞上元旦放假；1月2日补交完毕，随后几天没动静，1月7日登录系统一查，执照已经是注销状态。

# 为什么想注销

早先倒腾二手书，办过一张出版物经营许可证；如今这门生意不做了，证书也就没了用处。咨询一圈，代办收费在一百到三百元之间，又听说很多地方已经开通线上注销，于是决定自己动手，能省则省。

# 实操全程

## 先试渝快办，碰壁了

因为许可证是重庆发的，我先从“渝快办”App入手。没想到操作到注销那一步，系统反复提示“未查到主体信息”，可国家企业信用信息公示系统明明能查出记录，让人一头雾水。

我提交过一版资料，当时已在等审核，正好把填写流程记下来了：

① 基础信息：填执照信息、个人资料，存一下再继续。

② 经办人：补身份证信息、手机号，拍照传正反面，同样保存后前进。

③ 执照回收：在“遗失公告”“邮寄”“现场交回”里三选一。如果选邮寄，页面会给出收件地址。我为了留个纪念（bushi）选了遗失公告，需要先发布公告，再添加记录，正副本选“正副本”，副本编号必须写“1-1-1”——我之前只填了正本，就被退回了。填完保存并公示（具体按钮名记不太清，大概是这个），再保存进入下一步。

④ 材料上传：把执照正反面照片传上去即可。

⑤ 送审：确认后生成《个体工商户登记（备案）申请书（不含附表）.pdf》，有了它就不用打印签字寄复印件了，相关文件记得下载。

# 总结

眼下各地都在推线上政务，“一网通办”覆盖面越来越广，不用跑大厅就能办完不少事，确实省时省力。以上路径虽然以重庆为例，但其他省市的流程大概率大差不差，可以照着参考。
