# 一场五小时长谈，让我对创作有了新的判断

近期假期，我带小孩子去见了一位在创作领域深耕多年的导师。整整一下午的交流，信息密度极高。下面把我整理的要点抛出来，供同行参考。

**一、变现的两种格局**
一种是向金字塔顶端售卖，买家追求差异化和身份彰显，这条路通向标志性创作者的身份。另一种是面向大众市场，像连环画、商业视觉这类大众向的产品。头部市场体量小，容纳的人有限；大众赛道虽然看起来门槛低，却更稳健，成功概率更高。

**二、做创作前先补底层知识结构**
哲学、推理、语言、信息扩散、政治、社会符号、心智研究等学科都值得涉猎。补齐这些底层框架，才能看懂作品为何被市场接纳。举例来说，颜真卿的字章法严谨，为何能被推崇？因为当时儒家伦理占据主流语境，儒家强调等级与节制，反感浮夸。作品打动人，本质是撞上了时代的价值偏好。

**三、媒介决定影响范围**
他坚持让所有学员都读麦克卢汉的《理解媒介》。在他看来，创作的核心就是借助载体去影响他人。这点与传播与营销的底层逻辑高度重合，让我感到惊讶。创作从来都离不开承载它的形式。

**四、载体在变，方法就得变**
他早早就让学生用平板作画，现在又在尝试生成式绘画。传统派会觉得这是在亵渎，他却用媒介观解释：壁画要靠墙面被看见，岩画依赖洞穴，纸本依赖流通。若无法被看见，创作就失去了意义。时代的呈现方式在哪里，创作者就该用哪种方式呈现。

**五、聚焦投入能形成时间护城河**
时间是最稀缺的战略资源，也是难以复制的护城河。年轻创作者即便天赋突出，也不该贪多。先锁定一个方向，持续十年前后深耕。粗略算笔账：十岁定题，十八岁沉淀出一个类型的作品集，哪怕水平中等，申请世界顶尖艺术院校也具备竞争力。

**六、产量与质量共同构建壁垒**
单打质量，容易被淹没。影响力往往来源于持续输出。蔡志忠就是典型，西方读者认识中国传统文化，很大概率先认识他的漫画，因为他把老庄、孔孟、四书五经全都漫画化了，体量大到绕不开。如今他辅导的学生在改编知名科幻作家的文本，用生成工具提速，几天可完成一本短篇科幻绘本，等总量累积到一定程度，护城河自然形成。金庸与阿西莫夫也是靠高产建立影响。

**七、阅读需要筛选机制**
有些书看目录即可，有些书直接跳过。时间太昂贵，不值得消耗在低效信息上。

**八、个人创作者最大的不确定性是生命本身**
超个体没有组织的冗余备份，健康与意外风险必须重视。多子女家庭传承风险相对低，机构有备份机制，个人则需更自律。

本想邀请他录制节目，但他不愿公开露面。这些笔记只能先以文字形式整理，但对做内容、做品牌、做创作的人，都值得反复咀嚼。
