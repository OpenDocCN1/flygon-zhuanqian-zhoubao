# 8个月赚到40万：流水线工人转战短视频的真实复盘

我原先在昆山一家电子厂的生产线上干活，和老婆长期两地分居，去年3月实在扛不住这种日子，索性辞了工作，回老家全力研究短视频。

[PRE0]

兜兜转转试了好几个方向，最后把重心压在传统文化/健康类短视频上。深耕一整年后，今年只用了8个月，就拿到40万佣金。换做从前在工厂按部就班地攒钱，这40万我恐怕要存上八年。我从不觉得自己脑子灵光，读书时成绩也只到中游偏上，学新东西总要比别人多花时间。但我始终相信那句话——上帝会给每只笨鸟留一根够得着的树枝。我也在找那根树枝。

## 玩法核心

简单概括：在短视频平台找几位有口碑的名家（比如讲中医和国学的老师），拿他们的讲课内容做素材，剪辑后引来精准关注。粉丝够了以后开通商品橱窗，卖这些老师出的书、音频课里提到的汤料补品，甚至跟中医、国学相关的其他书籍都能带。

当时的素材多来自徐老师、张道长、曲老师、曾老、南老、倪师等人物。他们本来就有自己的观众群，讲课又含金量高，普通人刷到养生知识，不自觉就会关注收藏。当你攒够1000个关注，就能开通橱窗变现。

## 为什么要写这篇复盘

一是理清自己到底靠什么赚到钱，哪些方法能被长期复用。二是想告诉还在观望的朋友：现在的短视频生态里，依然还存在“会抄就能分到钱”的机会窗口，想干就别犹豫。

## 逐月复盘

### 3月：没品可发，把老品拿回来重做

3月的主要收入来自倪师的《经典药方》合集和艾草肚脐贴。

《经典药方》原本是去年就火过的老品，当时我实在没找到新方向，账号内容又一直围绕倪师做，索性把老品重新捡起来。意外的是，它依然出单。有人曾靠这本书做到13万佣金，我沿用了22年10月的爆款模板，换个时间点发到不同账号，照样能跑出成绩。

[PRE12]

这里验证了一件事：真正有价值的内容，过些时候再发依然有机会。如果觉得没品可跟，就回头从账号自身的属性出发——用的中医题材还是国学题材，或玄学题材？围绕这些方向去搜以前火过的大爆品，把它们的亮点重新用视频或图文讲一遍，再放到几个账号里做测试，往往能重新起量。

再说艾草肚脐贴。这个品是我今年碰到的第一个超级风口，带火它的是圈内一位女大佬，她真人出镜口播连爆了好几条。我看了看又短又简单，就跟着拍。头一次在室内录，效果一般；后来换到户外，又赶上了品大爆的当口，我一下就爆了4条。再往后我每天固定发真人出镜的口播，视频照抄那几句话，基本条条有成交。3条口播素材要录2小时，我总是来回NG，总想让镜头前的自己更自然些。

经验就是：碰上超级大爆品别想太多，闷头冲，跟上了起码能喝到汤。镜头表现力根本没那么重要——当时甚至有人戴着口罩、直接用别人的音频拍，一样能爆。我后来回看自己爆掉的那几条口播，方方面面都很业余，但这完全不影响收益，因为吃的是赛道红利，干就完了。

3月佣金合计4万。

### 4月：赚到钱反而很焦虑

4月收入构成：倪师的《人纪》五卷、艾草肚脐贴、倪师小卡片、相术书。三月亮相出镜尝到甜头，4月我继续做口播。方法依旧简单：把对标账号的热门口播文案拿过来，自己念一遍拍一遍。由于不熟练，产出效率很低，只运营了一个号，一天最多出2~3条。其中最高单条佣金是2.6万，几乎贡献了当月一半收入。

[PRE17]

到了4月中旬，赚到3.7万的我却越来越慌。我很清楚自己只是撞上了运气，根本谈不上会创作。当时的巨量后台数据赤裸裸显示：已经连续12条口播没有出单，相当于整整一星期白干。一个人硬撑项目，平时没什么人交流，每天只能看一眼大群消息，人就这样被孤独感裹住。

[PRE18]

后来4月下旬，我加入一位老师的交流群，在里面遇到一群同路人。大家每天晒单互相鼓劲，一个人撑不下去的时候还能借一借团队的力气。这个月我也经历了10个号被封8个的打击。

我的感受是：我不算内心强大的人，独自走一段路就忍不住焦虑，也接受自己能力一般。但没关系，遇到问题就找比自己厉害的人请教；没有同行的人，就主动走出去寻找、开口交流。这些真诚和利他的动作，最后都成了走得更稳的铺路石。

4月佣金合计6.1万。

### 5月：动摇、换方向、失败

5月头7天就赚了1万，主要靠那本相术题材的爆品。但这类内容太容易踩线，账号动不动就没了，我当时连续损失了不少号，心里直打鼓。

[PRE19]
[PRE20]

这时群里有人甩出一张单日GMV破55万的截图，我像抓住救命稻草一样想复制，结果什么都没做成。冷静下来才明白：我哪是换赛道，分明是想绕开封号和违规的难题。可换个角度看，封号门槛恰恰是这条赛道的护城河——愿意留下的人才能赚到长期的钱。当时有同行5月依然干了近30万。

如果看到这篇的你正在犹豫要不要换赛道，不妨先问自己几个问题：想离开的真正原因是什么？是不是为了逃避当下解决不了的困难？现在做的这个方向还有人盈利吗？如果有，我能照着做吗？我真的把能试的办法都试完了吗？我5月给出的答案是“没有”，我只是凭感觉害怕，就停下了手。

5月佣金合计1.37万。

### 6月：押上狠劲，单月12万+

6月上旬只赚了几百块钱。为了逼自己一把，我在群里立下公开flag：每天交20条挂购物车视频，少一条就罚200红包。结果这个月我一回都没拖欠。执行力差的朋友不妨试试这一招——把目标公开，让围观的人给你压力，效果立竿见影。

6月10号，另一个年度爆品出现了。我每天翻找新爆款实在耗神，索性把全部精力集中在这一个品上，每天雷打不动做20条图文内容交车。结果单是这个品，当月就带来8万佣金。

[PRE21]

同一时期，还有《黄帝内经》《图解阳宅》等几个品也让我拿到不错的成绩。这让我总结出一个实用结论：当一个品处在上升爆发期，就拼命铺内容，把数量堆上去。播放量、挂车量到了一定的量，结果会自动跑出来；风口来了，比的不是技术，是手速和执行力。

关于操作模式，我整理了三条经验：
1. 如果某个爆品在自己的账号也能出单，就停掉杂念，每天重复发、猛发。
2. 风口期间只研究这一个品的各种爆款形式，挨个放到账号里跑；跑不出新的，就把过去的老爆款重新做一轮。时间充裕再考虑微调创新。
3. 第二天在后台看前一天的跑量数据，挑表现好的内容置顶，再复制到其他账号分发，把整个矩阵都铺满。

6月佣金合计12.47万。

### 7月：正反馈让人干劲十足

6月的成果让我7月保持着极高行动力。每天持续发内容，可能当天没什么水花，过两三天才开始出单，但视频越积越多，账号就有越来越多的内容帮自己推流赚钱。

这一月的主力有几个之前爆品的余温延续，也有新入场的一款主打男性健康方向的草本茶。那个茶在中医养生的人群里转化很好，尤其是用倪师、徐老师这类中医题材养起来的号，因为粉丝本身就关注这些，推起来格外顺手。不过这类品也危险，容易触线，账号可能被关进“小黑屋”30天。奇门题材的书我做了些微创新：换背景、换贴纸、换拍摄角度、尝试不同配乐，也调整标题和文案，效果都还不错。

7月佣金合计5.76万。

### 8月：身处低谷，稳住节奏

8月热度明显退潮，收入也跟着回落。我的应对很简单：继续保持每天20条量级的更新。收益少了，就用作品数量和账号数量来补。低谷期最忌自乱阵脚，坚持执行、保持好心态，等着下一阵风来。与此同时，我也知道有的同行依然做到月入十万以上。

### 9月：埋下的种子终于开花

这个月很奇妙。7月和8月我一直默默在一个1000多粉的小号上只发某一种品的内容，当时基本没什么成交。等9月大家都不发这个品了，我回头继续发，它突然就开始稳定出单了。于是我顺着这条路线，每天怼这个单品15~20条，整月下来单品佣金4.8万，其他零散品合计1.1万，共5.94万。

## 爆品从哪里找？

1. 靠工具。核心是考古家和百应后台。前者用来搜对标账号、追踪热门口播，后者能扒数据，把同行的橱窗和内容底细查得明明白白。操作说明可以看这两篇：
- 如何用百应后台把对标账号看透：https://mp.weixin.qq.com/s/lSMqhSn7lBduneX2KxHtmA#rd
- 考古家查找对标账号教程：https://oef.xet.tech/s/gxWn3

2. 靠圈子。多和社群里的伙伴交换信息，市场足够大，一个人吃不完所有机会。你有好品分享给他人，别人发现有价值的东西也会反向分享给你，路就是这样越走越宽的。

3. 问商家。除了数据榜单能猜出爆款，货源的商家其实比谁都清楚哪些品在狂出单——打单机都快打坏了，纸都用完了。平时维护好和商家的合作关系，遇到新品上架冲量时，多问一句就可能抓到先机。当然也不能盲信，问完再用考古家和百应验证真伪。

4. 用影刀自动化盯橱窗。我平时会收集所在赛道足够多的竞争对手账号，用影刀定期跟踪他们橱窗的销量变化。比如一个号今天卖了100单，明天突然变成600单，那大概率就是爆了，赶紧去扒它昨天发了什么内容、挂了什么品，然后复刻。当你的样本足够多，赛道上哪个品在升温、到了哪一个阶段，你自然会像水里的鸭子一样最先感知到。我自用的免费脚本放在这：https://api.winrobot360.com/redirect/robot/share?inviteKey=bb634f174e80a409
