# 异常处理

## 比特浏览器没有声音

[PRE20]

在比特浏览器中安装插件后，如果始终没有声音提醒，可以按照下面的方法进行设置：

[PRE21]

进入“指纹设置”，找到“启动参数”，添加以下内容，然后点击确定保存：

`--autoplay-policy=no-user-gesture-required`

[PRE22]

保存配置后，重新打开对应的浏览器窗口，插件就可以正常播放声音了。

现在应该能够听到提醒音。

Autoplay policy in Chrome
