# 从洗头工到赚美金：一个普通人的两年“破圈”记

我是文少。若用一句话介绍，就是：没上过大学，起点是理发店学徒，如今在 YouTube 上靠内容赚钱。这篇文章想讲讲，我怎么一步步走到今天。

先更正式一点：我是生财社群的传术师，也是第七期加入的圈友。目前重点做 YouTube，手里有四个频道，其中一个已经拿下高级 YPP，另外三个还在申请流程中。加入生财这两年，我写了两篇精华帖，也把志愿者、领队、教练的角色轮了一遍。如果非要总结这段日子，那就是——成长速度快得超乎自己想象。

今天不聊项目复盘，想聊聊我这个人。起因是前几天看到曹教练和枨惘教练分享各自的经历，特别有共鸣。既然我也在 YouTube 深海社群，就顺势把自己的故事也摊开讲一讲。

我的轨迹，大致可以压缩成三句话：学历不高，从理发店打工起步；中途转去做互联网运营，下班后写公号，坚持了两年才看到光；最后辞掉工作，成了自由职业者，出海赚美金。

所以这篇文章，我会尽量还原当时的视角，讲那些选择、纠结和笨办法，也算是一次复盘。这里没有速成暴富的秘诀，只有踩坑、转型、慢慢找到节奏的过程。如果你也觉得自己学历不够、起点太低、努力了很久却看不到结果，希望我的故事能给你一点底气：他能行，那我也可以。

## 一、从月薪一千六的洗头工开始

先说读书。我从小成绩不好，职高学的是美发。所以我没有参加过高考，也没进过大学，学生时代天然缺了一块。2017年毕业后，按学校分配进理发店当学徒。每天从早上九点干到晚上九点，十二个小时，月工资大约1600，表现好也就2000。节假日恰恰最忙，想休息没门，更别提三倍工资。

现在想想，2017年还有这种待遇，挺离谱。不过店里包吃住，省了房租，又能学手艺，我就先忍着。

工作内容就是给客人洗头。普通客人洗一个5块，点名让我洗的8块。我在的店算中型偏大，小理发店提成更少，洗一个3块的都有。每天少说洗10个，多的时候20个。

[PRE0]

冬天最难熬。洗发水含碱性，手天天泡在里面，干燥开裂，后来就变成图中这样。

[PRE1]

为啥选美发？说白了，没考上好高中，我爸觉得与其进烂学校混日子，不如学门手艺，至少能糊口，万一学得好还能开店当老板。这是他给我规划的路。这张照片就是2017年上班时的我。

[PRE2]

后来身体出了大问题，头部需要手术，我在医院住了近四个月，2017年12月才出来。那段时间人生像停了摆，出院后整个人很虚，只好在家休养，每天靠健身恢复。

[PRE3]

算下来，住院加休养，小半年没有收入。我急得不行，不想再跟父母伸手。那种口袋空空的滋味，太难受了。

当时正赶上抖音爆发，但在我眼里那只是个娱乐 App，从没想过靠它赚钱。面前的路无非是：进厂打螺丝、餐馆当服务员、做房产中介、回理发店。我在心里兜了一圈：打螺丝不如卖房；卖房拉不下脸；服务员又不如继续理发，至少还能学东西。于是我又绕回理发店，找了家离家近的小店。小店容易学剪发，大店得等两三年才让你碰剪刀。

可到了2019年，我还是没掌握剪发。比我晚来的同事都能上桌了。我彻底明白自己在这行没天赋，心也倦了。某天晚上，我跟父亲说不想再干。他看得出我不是这块料，没多说什么，只让我自己想清楚。

思来想去，我又捡起之前的选项，这次决定去做房产销售。入职以后，日常就是地推、发传单、拉客户看房。第一次站在路边，我连传单都递不出，手抖，声虚，怕和路人对视。那正是重庆最热的六七月份，阳光毒辣，衣服湿透又干，干了又湿。从那时起，我特别羡慕能在办公室里吹空调的人。

吃苦也有收获——胆子练出来了。后来看到有意向的客户，我也敢凑上去聊两句。可惜三个月过去，业绩太差，被公司劝退。这段经历让我认清一个道理：靠打工翻不了身，没方向的努力只会让人在原地打转；人不可能靠重复不喜欢的事获得新生，与其硬扛，不如早点打破重建。

## 二、疫情封锁期，用下班后的时间死磕公号

2020年初，失业没多久，疫情爆发，城市封控，所有人都困在家里。我常看某个公号的文字给自己打气，也因此第一次了解到自由职业、自媒体。那个博主推荐了《认知红利》，里面说人的注意力可以变成钱。直到今年，我才知道这位博主原来也是生财圈友。

[PRE4]

那之前我还在知乎写过些回答，攒了大概几百粉。不多，但让我第一次摸到内容创作的门槛。

[PRE5]

2020年3月14日，我照着网上的教程，稀里糊涂注册了自己的公众号。那算是追梦的起点。

[PRE6]

公号注册好，我仿佛看到了出路：只要粉丝涨、阅读涨，就能接广告变现。但具体怎么做，完全没谱。那时的公众号没有公域推流，涨粉全靠外部渠道。于是我到处搜教程，知乎、百度、头条、简书、微博……凡是能想到的平台，全翻了一遍。看了好几天，才知道定位、头像、简介、自动回复、菜单栏、人设都有讲究，也第一次听说“流量主”这个变现方式。

接下来是更大的难题：写内容。粉丝来了，总不能让主页空着。可我连八百字作文都费劲，更别提一两千字的文章。那会儿 AI 还没像现在这么普及，我只能硬着头皮手写。想持续写，就得先大量读。我开始逼自己啃书，一本接一本，不知不觉攒了一大堆。

吭哧吭哧忙了一个多月，一分钱都没赚到，连流量主都没开。我心里着急，觉得一个人闷头搞不行，必须混圈子。于是我在网上东找西找，最后靠一个公众号留言小程序和几节一元公开课，挤进了几个交流群。也正是在那里，我遇见了理白，他后来成了我的贵人。

混群之后，我才知道有人通过刷粉快速开通流量主。我花了不到一百块试了试，第一次在后台看到收益时，又惊又喜。

为了保持每天有收益，我开始强迫自己日更。第一个月流量主一共带来163块。钱虽然少，但到账那一刻，我开心了很久。坚持了大约半年，接到第一条广告——某个公司的播音课，报价300。

[PRE12]

这点钱当然不足以支撑生活，但像一道光，让我觉得这条路可能走得通。那段时间，我白天做体力活，晚上死磕写作，没时间就挤时间，不会就硬学。很多人在副业上的最大卡点，往往不是缺时间，而是总想“等万事俱备再开始”。

## 三、学历被卡、公号寒冬：一次次推倒重来

公号更了快一年，阅读量终于稳定在500到1000，广告报价也升到500一条。

[PRE13]

但广告单量不稳定，好的月份能接到4条，差的时候只有一两条，完全是碰运气。这点收入当零花钱可以，但养不活自己。后来社会逐步复工，我又出去找工作。我想，自己好歹有一年公号经验，找个新媒体运营岗应该不难吧？但现实泼了一盆冷水。

投了不少简历，有的卡学历——高中学历不行，最少要大专；有的薪资太低；有的嫌我经验不足，让我等通知，然后就没下文了。我真正意识到，学历是绕不过去的短板。也是在那一年，我报考了成人自考，拿了个大专文凭。

面试屡屡碰壁后，我干脆断了上班的念头，决心把公号做出样子。为了赚零花钱，我做过各种杂活：发传单、地推、当群演，全都不挑。好在天无绝人之路，公号迎来上涨期。靠知乎、企鹅号、抖音等外部导流，一个月涨了8000粉，其中企鹅号那两篇文章，估计带来三四千。

[PRE14]

公号就此突破万粉。知乎那边也在同步，粉丝涨到2000。2021年端午，我第一次收到知乎寄来的礼盒。

[PRE15]

之后，公号广告稳定在每月四条，每条至少500，再低我不接。这种挑单的底气，很爽。

[PRE16]

可惜好景不长，2022年4月，公众号开始过冬。平台算法调整，推荐向公域倾斜，大量账号阅读暴跌。叠加双减政策，教育类客户大幅削减广告预算，接单十分艰难。圈子瞬间冷清，不少号主急着卖号。我甚至发了一条朋友圈，分析过当时的算法变化。

[PRE17]

我没有卖号，但也不敢再把所有筹码押在公众号上。于是决定再出去找一份工作。这一次倒挺顺，6月入职一家 MCN，做运营岗。主要任务是在抖音上找达人签约、谈商单，本质上接近媒介和 BD。

那阵子依旧白天上班，晚上继续写公号和知乎。加班频繁，晚上十点多才到家，选题、素材都靠临时找，写完已经快半夜。

[PRE18]

坚持一阵后，公号阅读还是起不来，商单也缩水。我干脆停更，摆烂了几个月，专心做主业。

[PRE19]

但停更不等于躺平。我始终觉得，只要还在寻找，就总会有出口。世界不会拒绝愿意尝试的人：你推倒墙，墙就变成门；你往后退，可能永远被困在原地。

## 四、加入生财、视频号爆发：正向反馈是攒出来的

主业保底，副业找出路。做公号养成的习惯，让我始终不甘心只做一份工作。公号、知乎都没起色，我得再找别的方向。

说来也巧，正好赶上生财第七年418活动，理白在帮忙拉新。其实2021年我就听群友提过生财，但不知道具体是干嘛的。在朋友圈观察了几天，加上价格只要1965，我就决定加入。之前我买过知乎课、新媒体写作课，价格大多在1000到1600。相比之下，生财这么便宜，不试白不试。

报名时工资还没发，手头紧，只好用花呗套现。我心里有数，下个月工资发了就能补上。

不过，头几个月我很焦虑。项目多到眼花缭乱，根本不知道从哪下手。后来跟着航海、做志愿者，才渐渐进入状态，认知也提高了。我明白，光看光想没有用，必须下场实操，把手弄脏。

我尝试的第一个项目是抖音养生带货。对着精华帖一步步做，花了两小时才剪出第一条视频。做了快一个月，只出了几单，佣金就几十块，因为没交押金，至今还提不出来。

[PRE26]

后来还玩过无人直播、快手磁力聚星、得物，基本都没做出成绩。无人直播不是违规就是没人看；快手聚星视频老被限流，出单很难；得物稍好，靠流量分成和优惠券提现了1000多。但因为内容是搬运，我觉得没办法提升能力，做了一段就停下了。

8月航海时，我报名视频号带货。开船第二天，视频突然爆了。我当即开了人生第一场露脸直播，播了一个多小时，GMV128，佣金80左右。那晚我几乎没睡着。

[PRE27]

那一刻我冒出一个念头：视频号也没那么高不可攀。这份及时的激励让我决定深耕。可是，当时我做的是曾仕强混剪，视频爆了后往往会触发人脸验证，结果航海期间只赚了2000，账号就废了。

不得不换赛道。不久后，视频号分成计划开航海，我有点带货经验（也开通过分成计划），觉得难度不大，就报名参加。这一次，航海期间变现了1000多，又尝到甜头。航海结束后，我坚持日更，前后爆了至少十条百万播放的视频，单条收益有的超过500。

就这样持续输出半年，2024年6月，我等来一条大爆款：单条视频播放量破3000万，收益4000多。

2024年底，亦仁老大发了一条关于 YouTube Shorts 的超级标。就是这条标，悄悄在我心里埋下种子——毕竟能赚美金，诱惑太大了。
