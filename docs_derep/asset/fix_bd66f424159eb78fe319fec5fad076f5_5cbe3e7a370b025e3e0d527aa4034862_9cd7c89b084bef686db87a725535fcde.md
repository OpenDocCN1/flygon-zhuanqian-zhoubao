# 聊几段闲话，说说我眼里的生财有术

大家好，我是大树🌳🌳，2018年就混进圈子的老面孔。昔日做设计，如今常驻杭州、义乌两头跑，主业是在抖音上卖货。圈内干货堆成山，今天不碰实操，聊点轻松的，换个角度带各位瞧瞧生财有术到底是个什么样的地方。

## 几段聊天，让我摸到了这个圈子的底色

2019年筹备生财标志那阵子，我跟亦仁来回聊了不少。他随口讲起圈友们的经历：有人在社群里学会了一门手艺，如今每月进账突破五位数；有人在这里遇上了并肩做事的搭档；有人看了别人的经验教训，绕开了本会踩中的雷；还有分享嘉宾掏心窝子讲自己的故事。这些碎片，全是在一来一往的闲谈里拼凑出来的。

还有个细节挺有意思——生财有术的背景图为何挑了张卡通画？亦仁的答案是，他不愿意让这里沾上“铜臭味”。这些闲谈里透出的东西，恰恰就是标志设计的立论根基。说到底，设计也是一种对话，一个标志承载的绝不只是图形，它要把最要紧的内核浓缩、提纯，再用视觉语言递到人眼前。

那回聊完，我替亦仁梳理了他对社群的几点理解：

1. 生财讲的“术”走的是正路，合法合规，价值观必须摆正。
2. 这是个方法密集、涉猎面宽、消息灵通、人脉能深度串联的互联网圈子。
3. 大大方方聊怎么挣钱，谈钱也不伤和气。
4. 盼着借这个圈子触及更多人，让大家都长出赚钱的脑子，把日子过得更舒坦些。

跟钱打交道不假，可亦仁更在意的，是把它办成一个有热度、有情感的集体——掏真话、结真交、换真心，别让铜臭气弥漫开来。

## 怎么想起写这些？

前阵子生财航海家的介绍材料里，好几位圈友聊到了那个标志，说看着顺眼、够耐看。我听了心里挺美，转头跟亦仁念叨：这标志算是扛住岁月了。一聊才发现，自己好久没在社群里落笔，于是就有了眼下这篇。能这样跟大家碰面，挺高兴。

## 五年翻篇，当初的设想全落地了

2019年张罗生财日历，才有了后来大家熟悉的那一整套生财视觉调性。每逢线下聚会或线上活动，瞥见那抹生财绿和各处物料，亲切感就上来了。想起当年有位圈友讲过：“咱们一起疼它，陪它一道长。”这话真应验了——生财被注入了生命，越长越壮实。大伙儿也确实一直捧着他、护着他。模样没变，只是个头高了。老圈友大概都懂这份滋味。

那年亦仁跟我谈他对生财的盘算：办一个掏真心、有热度、专聊挣钱的社群，别沾铜臭，价值观摆正，路子要多、触角要广。五年回头望，他全兑现了，还越办越红火，自己的信条和理念一天没丢。

那会儿圈里还不到六千人，眼下四万六千。当初立的那些规矩，如今已经渗进社群的骨子里，死磕长期主义，一星一点地改、一星一点地烙进每个生财人心里。这事干得漂亮。陪着生财走过六年，眼看它拔节生长，当初描绘的图景一一成了真。

当年全国聚会、城市沙龙、各式活动上结识的那批圈友，不少人如今已小有建树，瞧着他们一步步往上走，真心庆幸路上有这帮人。自然也有慢慢走散的朋友，各自安好便是。

## 白送一个标志，我到底亏没亏？

为啥分文不取给生财做标志？亦仁夸我有胸襟、看得远。其实头一条，是我打心眼里认他的为人和他践行的那套信条，他对商业的不少见解点醒过我，有时一席话就把我生意上的疙瘩解开了。能跟高人过招，本身就是长进，这交流的过程值老钱了。所以我觉着，是我占了便宜。

后来一验证，果然如此。亦仁的下午茶时光都能拍出七万多，这几年我去EFC，回回是他买单，大大小小凑起来几十顿总有了，这便宜占得够大吧？直到今天，他仍是我创业途中的引路人，浇我冷水、指我方向、陪我琢磨对策，追根溯源，都是2019年那桩合作种下的因。

## 给生财做设计，回报远超预期

替生财做的那套品牌设计，如今回头看，是我做过最划算的一笔投入，后面接连冒出的惊喜就是证明：

1. 蹭亦仁的私人饭局，我大概算蹭得最勤的那几个之一
2. 亦仁携夫人专程跑义乌，登门指点两天
3. 参加曹大的分享会，还上台讲了话
4. 赴了小马宋老师的私人饭局
5. 生财几番推荐、亦仁替我站台背书，帮我促成了五十万往上的生意
6. 结识了一批出色的创业者，生财好友占我微信通讯录的四分之一，交情从生意场延伸进日常
7. 寻到了二次创业的方向，圈友给了莫大助力，还收获一帮信得过的弟兄

在生财里搭伙的伙伴少说十个，谈起来都顺畅，有几回头次碰面就签合同打款。二次创业这一路，从挑项目到找人合作，圈友没少帮衬。同在一个圈子，彼此有信任垫底，再加上亦仁背书，效率自然高。频道对上了、想法一致了，人对路了，事就成了。

真诚这张牌最硬，揣着利他的心去办事，惊喜往往不请自来。有时不图回报地搭把手，回头收获的东西你想都想不到。

## 从设计跨到电商，生财一路没撒手

因为些缘故，2021年我从杭州挪到义乌，也从设计行当跳进电商。二次创业的营生，正是在生财项目库里淘出来的，天天泡着耳濡目染，对业务走向慢慢有了判断和手感。运气不错，碰上了当时做抖音培训的高欣，29800没跟我收，还管了我几天饭。也是沾了生财背书和信任的光，我俩很快处成铁哥们，虽说他性子偏内向。

后来又随SKY老思捣鼓了一阵TIKTOK，也做出了点名堂，一个月冲到全国第五。去年开春，亦仁带着夫人来义乌，两天一夜帮我捋工作，做战略规划、理思路，连怎么带队伍、怎么琢磨问题都倾囊相授，收获满满，也让我在这条生路上添了底气。

商家岛时明、高欣、帅张、黑小喵、直浪、玛丽阿姨、SKY老思，他们不止一趟来义乌瞧我，有时还领着团队来搭手，拿各自拿手的本事帮我队伍长本事。这帮人是我创业途中的军师团，替我理思路、补盲点、牵资源，算得上路上最贴心的伙伴，也把生财互帮互助、真诚利他的劲儿落到了实处，创业不再是一个人扛。

还有HEXIN、茄子、靠谱等等，帮过我的好朋友数不过来，根子都在生财这个圈子。我们不过是生财圈友里一个小小的切片，想来还有许许多多类似的小团体，彼此撑腰、互相打气、坦诚相待。

刷朋友圈看到圈友在某个城市张罗的活动，心里挺感慨——大家早已不止是生意上的往来，也走进了彼此的日子。我如今的社交圈大半是生财的人，处了四五年，情分一年浓过一年，创业道上不冷清，身后有支后援队撑着，办事，踏实！

## 眼下我在忙啥

义乌的直播班子，扎在丝巾、围巾这个品类，主攻50岁以上人群，抖音平台走量，视频号同步铺开。单个直播间GMV三百万，一天能出近万单。天猫渠道和产品品牌化也在铺，圈友里的私域行家黑小喵帮我搭私域这块，已经见了起色。头疼的事跟多数初创公司差不多——缺能扛事的好主播。另外我们做的香云纱、丝巾还得拓宽品类，手头有香云纱服装或配饰资源的，也欢迎来谈谈合作，先谢过了。

这两年一直在抖音直播带货里摸爬滚打，跨行创业、直播相关的事攒了些体会，一路走来，坑没少踩。直播这行诱惑多，我记得亦仁讲过，在中国把一个行当吃透，一年保底也有一千万利润，队伍还嫩，先把一桩事做精就不容易了。如今我就死磕一个品类，盼着早点做出点样子。

近来常琢磨：该做赚钱的事，还是做值钱的事？得看自己要什么，也得分阶段。每个阶段怎么走、什么节奏，都得照着队伍的本事和实情来调，拼的是综合功夫。这一年，估摸着还是先想清楚怎么靠深耕一个品类挣到钱。

这两年有踩坑也有拿结果，走的路子挺接地气。我这点经验要是对哪位圈友有用，乐意交个朋友聊聊。义乌的供应链资源我也攒了些，谁缺货源，我力所能及帮着牵个线。

要说具体干货，真没啥好献丑的，圈里实战高手一抓一把，找他们虚心讨教便是。多看、多听、多干，别浮躁别焦虑，常在生财里泡着，总归有大收获。我这人笨，进步慢，可我待得久啊，看得多、见得多，惊喜自然来。

有回约亦仁吃饭，我问他，咋对项目总有那么多思路和判断？他说：“看多了，就有感觉了，很多时候纯属本能反应。”

可不是嘛，多看看，惊喜就来了！那么多精华帖、风向标、项目库，够兄弟们翻的。你要也跟我一样笨，那就沉住气，慢慢泡着吧。
