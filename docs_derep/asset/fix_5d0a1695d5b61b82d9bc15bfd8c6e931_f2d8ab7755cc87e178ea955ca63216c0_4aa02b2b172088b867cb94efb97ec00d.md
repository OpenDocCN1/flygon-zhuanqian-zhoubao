# 从零开始做沪上存量房，两个月成交过亿，全程拆解

先自我介绍。我做电商运营六年，花过的推广预算超过五千万，最擅长的两件事：内容种草和付费流量放大。几个月前，我和两位伙伴开始操盘小红书，盯上了一个几乎没什么人系统做过的方向——魔都存量住宅。我们接手的项目，是帮一家业主委托代理公司，在两个月内从零跑通全流程，最终让成交额过了亿。

## 项目是怎么来的
这家公司有两个诉求：一是持续触达魔都有卖房计划的业主；二是招募一批愿意投身这个新职业的同行加入他们。

## 赛道风向变了
魔都这些年新楼盘持续交付，存量住宅越来越多，但购房群体没有同步扩大。房源不再稀罕，买家成了稀缺资源，二手住宅市场从卖方主导慢慢转向买方主导。从前是“一房难求”，如今是“挂牌容易出手难”。

传统经纪人的收入来自成交佣金，行情改变后，他们最理性的做法是帮买家砍价，而不是替卖家争取利益。买家少，逮住一个算一个；业主多，谈崩了再换一个就好。反过来，如果全力维护业主，买家不满意，再想找到下一个买家就非常困难。

大部分卖房业主并没有意识到自己其实没人帮，仍然按老习惯委托中介挂牌。结果只有两种：挂了很久卖不动，或者成交价远低于预期。

供求错位催生出一个新角色：只效忠于卖房人的专业经纪顾问。他会动用行业资源，从前期盘点、房屋包装、策略定价、线上推广，到价格谈判与交易操作，全程为卖房者把关，目标是让房子在合理价格下尽快脱手。

## 把经验变成内容
有了这层定位，内容弹药就有了。我整理了行家认可的几条核心经验，挑一部分分享：

1. 换房这件事，时间往往比多卖几万块更值钱。早一点拿到现金，下一轮谈判就更有底气。价格上让一个点，换几个月时间，非常划算。

2. 不必等行情回暖。真到回暖时，你想买入的那套涨幅更大，对付款节奏也更挑剔，反而吃亏。不如趁现在多谈条件、多争取时间，早换早踏实。

3. 挂牌价只信本年度的真实成交明细。让中介调出同品类房源最近一年的成交记录，楼层新旧、装潢程度、税赋结构、付款节奏、楼栋位置，每一项都牵扯最终价格。

4. 最终底线在买家坐到谈判桌前之前，一个字都不能透露。不管中介描述多么好的客户，见不到对方本人，就是不说。

5. 人越急，越要稳住挂牌价。急着出手的，比底线高出一两个点，贴近近期的价格水位，容易被平台贴上“必看”标签，中介也更愿意主推；挂牌后的两到三周是黄金期。不急卖，也不宜高出四五个点。报得太离谱，中介根本没动力推，买家也懒得来看，最后只能一步步降价，而平台上的降价记录会引来更狠的砍价。

6. 卖房人归根到底只关心两件事：卖多少钱、卖多快。有人愿意用价格换速度，也有人既要速度，又不肯牺牲太多价格，这类人往往更愿意为附加服务买单。

7. 别把房源委托给单一渠道。一旦被一家锁住，后面很容易被拿“行情差”来反复施压。

8. 把曝光拉到最大，多和经纪人走动。同样一间屋子，被带看过百回和仅仅十回，效果一定完全不同。

第一条内容就是按这套思路做的，直接炸了。之后几乎条条都能成为热门，从0到1很快跑通，进入复制放大阶段。
