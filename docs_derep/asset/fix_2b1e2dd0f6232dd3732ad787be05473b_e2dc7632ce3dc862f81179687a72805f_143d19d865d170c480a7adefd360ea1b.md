# 交付前总被质疑“不是人写的”？这份人工润色自查流程，帮你把接单率救回来

接到单子本来挺开心，结果客户甩回来一句“这稿子是机器拼的吧？”，瞬间破防。别急着怪运气，很多做了很久的写手也一样翻车。我见过几百个长期有稳定单量的同行，他们交付的内容里，照样藏着明显的“生成腔”——段落整齐得像复制粘贴，读起来全是正确的废话，翻来覆去就那么几个大词。

网上关于如何分辨“机器味”的讨论不少，但东一榔头西一棒子，始终没有一套能被多数甲方认可的验收标准。后来我索性把团队里那些复购率高、老客户愿意转介绍的高产写手实际在用的审稿规则，连同新手最容易踩的雷，整理成一份能直接照做的操作清单。

先说结论：再聪明的工具也只负责出毛坯，想不被一秒识破，必须逐段人工精修。下面就用一篇《活着》的解读稿做示范，看看怎样把“一眼假”的初稿，改成有信息量、能安心提交的成稿。

## 第一步：开头太长？砍到只剩骨架

模型给了一段五百字的开头，而我只想保留一百字左右的引子。此时不需要自己动手重写，直接给模型下压缩指令，让它“挑重点缩到130字以内”，然后附上原文。

```text
请将下方读后感的引言部分，挑重点缩减至130字以内:

"""余华的《活着》，是一部引人深思的文学之作。它以中国文化大革命时期为背景……（原文略）"""

[PRE0]
```

模型交回一百二十多字，但压缩完不能直接交差。我还会再核一遍关键信息有没有丢：作品独特的气质、福贵在特殊年代的遭遇、他身上的韧性、对生命和社会的反思、读完后对“活着”的珍惜。像“黑白交错的世界”“不屈的鲨鱼”这类看着华丽但实际不承载信息的比喻，直接剔除。这样留下的每一句都有具体指向。

## 第二步：主题分析：从700字到200字

初稿把“生命与生存”“家庭亲情”“社会变迁”三大主题各写了一整段，每段都是教科书式的展开，似乎很完整，但没有任何一句超出常识。人工处理时，只保留三类东西：一是父亲那句“人活着，总是要面对一些难以承受之事”的原话；二是妻子、儿女相继离开的具体遭遇；三是特殊年代对家庭命运的冲击。其余那些串联起全文的框架词，能删就删，让信息自己说话。原先700字，压缩后204字，反而显得更扎实。

## 第三步：文学手法：从700字到300字

讲写作手法时，初稿提了寓言、比喻、排比，但每个观点后面都拖着一大段解释，读起来非常累。改稿只留了三处硬核证据：饿到肚子鼓胀得快炸开，妻子干瘪得像放久了白薯，失去家人后心里空出一大块。这些细节比一百句“富有感染力”都管用。删掉空泛的赞美之后，字数降到350字左右，例证与观点比例刚好。

## 第四步：人物与情感：从700字到400字

初稿写福贵“坚强又脆弱”，不断重复“亲情多么厚重”“父爱多么无私”这类定论，但缺乏能让读者相信的画面。修改时只留下可感知的片段：福贵想念儿子时打的那个比方——对儿子的想念像远而亮的星光；妻子在绝境中不吭声的承担；福贵为儿女拼命活下去的执拗。这些具体动作比任何形容词都有感染力。最后458字，信息量和情绪浓度反而更高。

## 第五步：历史与社会背景：从679字到300字

这一部分初稿充斥着很多定性词，像是提前写好的结论。人工处理的方法是删掉所有空泛的定论，只保留具体事件：红卫兵逼得儿子离家，父子对话中对思想封闭的批评。背景交代点到为止，让读者自己感受那个时代的重量。最终330字收尾，干净利落。

## 第六步：作品与现实关联：从668字到400字

升华段落是最容易灌水的地方。模型初稿按三点式罗列了生命可贵、家庭温暖、社会公平，然后每个点都在重复口号。人工处理的思路是：能用现实中的例子支撑的论点就留，纯表态的句子就删。原示范文在这一步没有给出最终压缩稿，但原则已经清楚——不要“我们应该怎样”，要“我们看到了什么”。

## 交稿前通用的四个检查动作

看完案例，总结成四句可执行的话：

一查句式：连续三四个排比句同时出现，立刻拆散，长短句交替。

二查大词：类似“伟大”“深刻”“力量”“温暖”这类词出现频率过高，说明内容在偷懒，强制自己删到只剩一两个。

三查信息密度：每一段读完，能不能说出一个具体的名字、一句话或一个事实？说不出，就是空转，删。

四查结构：如果全文都是模板化的“三段式”骨架，换个顺序重新组装，哪怕从最精彩的细节开头。

说到底，客户愿意付费，是因为人能提供工具给不了的东西——判断、取舍和审美。工具负责速度，人工负责质量。下次提交前，花十分钟按这套流程过一遍，那些“不是人写的”的差评，会离你越来越远。
