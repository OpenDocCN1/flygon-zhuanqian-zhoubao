# 一、那些被生活反复捶打的日子

## 1. 折腾不止的创业前期

我今年29，出生在山河四省，家里基本全是体制内。按照正常剧本，我应该考个公务员，端着铁饭碗，在小镇过完安稳的一生。

但我从小就不太听话。一想到几十年都过同一种日子，我就觉得人生还没开始就结束了。大学期间我没闲着，做过借贷宝拉新、游戏工作室、劳务派遣这些项目，慢慢也实现了经济独立。租过小办公室，带过几十个代理，往酒店和电子厂送人，最猛的一个月赚了13万。那时候我信心满满，觉得这就是一辈子的事业。

结果天不遂人愿。上游劳务公司跑路，我没执照只能挂靠，资金链一下子断了。好在积蓄刚好补上亏空，我又回到学校，老老实实度过了最后一年。

## 2. 转身扎进互联网

毕业后，我不顾全家反对，没去参加国考省考，独自跑到上海进了一家互联网公司。学金融的我，连ctrlC、ctrlV都不熟练，只能从客服做起，一点点摸爬滚打。

那几年，同学在银行、机关的都很安稳。我走了一条没人看好的路，但我心里不慌，因为我知道那才是我想要的。

后来两年换了三个岗位，从客服转运营，再转产品经理。城市也换了三个，上海、杭州、成都。随着跳槽，工资越来越高，从只有同学一半，慢慢变成他们的两倍多。我也渐渐明白一个道理：有时慢一点，反而更快。

但工作几年后，行业越来越卷，涨薪停滞，裁员阴云不散。我不喜欢这种命运被人捏着的感觉，干脆主动离职了。在一个阳光很好的早晨，交完最后一份方案，我递了辞呈，又一次从零开始。

## 3. 交了学费，才看清现实

辞职后先躺了两个月，把之前欠的觉都补了回来。然后就是焦虑，铺天盖地的焦虑——下一步怎么办？

我开始疯狂找项目。那时还不知道生财，只能去抖音、知乎刷。结果可想而知，被割了一茬又一茬。

第一个项目是TK视频带货。交完钱拿到的是一份三百字文档、两段模糊视频，还有一台破旧的五手iPhone6。老师从付费前的秒回变成了爱答不理。我靠着执行力，一周也出了几百刀，觉得不靠公司也能活。可好景不长，按照文档里的去重方法，没几天就违规封号，佣金全锁死了。再找老师，对方已经离职，投诉到工商，公司地址都是假的。我才明白：自己成了一棵标准韭菜。

后来不死心，又试了快手无人直播。买了上千块软件，选零食赛道，播了一个月就卖出一份臭豆腐，收了3块2。那阵子我陷入深度自我怀疑：我到底行不行？也就在这时，转机出现了。

## 4. 因为一篇文章，遇见生财

去年12月，朋友分享了一篇生财的精华文章，叫《生财有术最短的一篇精华》。文章很短，但里面那句“利他是最大的利己”像一道闪电击中了我。我当时太需要一个方向了。

[PRE4]

我去问朋友，才知道他已经是两年老圈友，辞职后做小红书带货，收入远超工资。听他说得那么真诚，我既好奇又谨慎。考虑到自己半年没收入，手头紧张，我先用他的账号进去逛了一圈。进去以后直接惊了——哪怕一个免费分享的项目，也比外面付费课详细完整得多。我试着链接一些大佬，人家真的耐心解答。那一刻我信了，这里确实有股真心帮人的劲儿。

用朋友的账号翻了很多天，看哪个项目都觉得能一夜暴富。小红书、二手书、手机卡都试过，但赚个几百块就卡住了。我忍不住问自己：我辞掉月入2万的工作，就是为了每周赚几百吗？

于是我停下来，不再乱试，开始一篇篇翻精华帖。直到看到那篇关于视频号带货的文章，我眼前一亮——早期我也试着做过视频号，只是没做起来。而且今年视频号的风口确实很明显，我决定再试一次。我主动去链接了文章里的孟总，聊完以后就下定决心，只深耕这一条赛道，不再东搞西搞。宽一米，深一千米，就这么干。

## 5. 押上全部，死磕视频号

其实我很早就碰过视频号。自己做实拍，没流量；开播，卖不动。完全找不到门路，就搁置了。

[PRE6]

这次下定决心后，我花两天把手册翻了好几遍，然后一天内找亲戚朋友注册了5个视频号。报名时是2月中旬，正好过年。2月17日，我开始了第二次尝试。

那天剪视频到凌晨四点多，睡不到两小时就开播——因为中老年人醒得早，第一波流量必须抓住。运气不错，第一条视频就小爆了。看着播放量和销售额一直涨，我困意全消，爬起来继续剪。

可惜经验不足，遇到异常没及时处理，流量最好时违规下播，白白损失几千块。但那种在网上赚钱的滋味，我总算第一次尝到了。

它完美击中老年人怕灾难、爱囤货的心理，一买就是五件十件，恨不得人手一条。我半夜看到消息，立马不睡了，披上衣服就开始剪视频。爆品寿命短，时间不等人。第二天一早发出去，果然一堆视频跑得不错。

# 二、视频号口播带货的核心逻辑

实操两个多月，我自己总结成三句话：账号为基础，素材为核心，直播促转化。

## 第一，账号是弹药库

账号越多越好。一个人能实名5个微信号、2个视频号。视频号就是你打出去的子弹。每天至少5个号一起发，坚持一星期，总会爆一场。自媒体玩的就是概率。只要爆一场，就可能有过万收益。所以前期多备号、养号，比什么都重要。

## 第二，素材是发动机

素材是流量的起点，也是决定一场直播的胜负手。选对了好素材、好脚本，基本赢了一半。表现力强的实拍大佬，经常单场GMV10万+；表现力一般的，也可以做搬运去重，这是平台规则不完善时代的红利。

现在的10万+俱乐部里，搬运大佬占的比例也不小。毕竟爆过的视频一定有爆的基因。大家可以根据自己情况选路径。当然，我很鼓励原创，收益确实更高。

## 第三，直播是收割机

视频和直播是互相喂养的。平台流量进来，你接得好，它就给更多；视频数据起来，直播流量也跟着涨。链路一旦打通，就是螺旋上升。

直播只是转化的临门一脚，甚至是最轻松的一环。敢开口，对着话术一直念就行。因为点进直播间的人，早被视频洗过一遍，大部分已经有购买意愿。你要做的，就是帮那些犹豫的大妈大爷再推一把。

## 第四，几个提醒

拉时长真的有用。有流量时，千万别下播。视频号拼概率，一条视频爆不爆，看账号、看时间、看命运。既然爆了，就往死里拉时长、补视频，把流量榨干。补着补着，可能又拉起别的视频，整体GMV直接上一个台阶。

# 三、视频号带货实操入门

这部分写给刚接触视频号的朋友。已经熟悉的可以直接跳到后面的提效方法。

## 第一步：怎么选素材和对标

一场直播能不能打爆，品和素材排在前面。跟着爆品走，比自己造爆品靠谱多了。尤其是新手，别妄想自创爆品，时间、精力、金钱成本都太高。

平时多刷直播广场，看到哪个品卖得好，就去研究他的视频框架和文案。不管翻拍还是搬运，手速要快。好素材就是肉，搬得早吃肉，搬得晚吃土。

不管是抖音还是视频号，尽量选近期做起来的账号当对标。越是新号，玩法越新鲜，模仿起来越容易出结果。

## 第二步：剪辑怎么做

我现在主要用搬运混剪，也在尝试实拍。混剪不难，无非就是加画中画、变速、贴纸、镜像这些操作。工程图大家一看就懂。

但真心建议有条件的朋友尽早转实拍。平台规则越来越完善，搬运混剪的路会越走越窄，而且实拍收益确实更高。

## 第三步：直播怎么搞

口播连怼玩法的直播，反而是最不存在技术门槛的。毕竟我们不靠直播间表演吃饭，而是靠短视频往直播间导流。用户来看品，看中了就下单，直播好不好，只是转化率上下几个点的事。对着话术念，压力不用太大。

有几点要注意：直播间一定不能没人。长时间没人会被判违规下播，严重的话橱窗都会封掉。视频在跑、钱却不能赚，那种感觉真的太痛苦了。
