# 小红书法律垂类小号的隐形生意：写起诉状、陪立案，月入稳收5单+

作者：希平
日期：2025-11-14

最近刷到一类很会做生意的法律小号，专门做「代写起诉状 + 协助立案」这件事。

账号内容看上去非常朴实无华，基本上就是晒成功案例。图里是立案回执、法院盖章的材料、客户的感谢反馈，配文也都很克制。就是这种低调的展示方式，反而让评论区炸了：问价格的、问能不能帮忙的、直接私信的，络绎不绝。

这类账号瞄准的，恰好是市场里最庞大的一群沉默需求者。

房租押金被房东拖着不退、几万块的借款被朋友或前同事赖掉、网购纠纷、劳务费拖欠……类似的小额民事纠纷遍地都是。很多人一算账就犯难：请个正式律师收费动辄上万，远超标的；自己去网上找模板又看不懂、写出来也不被法院受理。

于是就有了中间地带。

这些小号提供的服务很清晰：按案情帮你把起诉状、证据清单、立案材料整理成法院能直接接收的格式，必要时还远程指导甚至陪同去立案。门槛低、交付快、价格友好。客单价普遍落在500到3000元区间，看案子的复杂程度浮动。

就拿文中观察到的这两个账号来说，近三个月的数据很稳定，每个月至少能接到5单以上，且需求是持续进来的。投入主要是内容维护和私信回复，几乎没有获客成本。
