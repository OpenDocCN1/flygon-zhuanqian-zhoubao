# 想活到 149 岁？先看看富豪们在为长生买什么单

常有人开玩笑说：“如果你每天早上对着镜子给自己来三拳，寿命能延长二十年，多半也没人愿意试。” 奇怪的是，真的有人在试，而且出手的恰恰是那些站在金字塔顶端、有钱又有脑的人。

从几百万年的进化到近两百年的医学累积，人类对活得更久这件事，似乎已经打磨得相当到位了。 但研究却指向一个反直觉的结论：你的基因对寿命的贡献，可能只有 7% 到 30% 左右，剩下的大部分，掌握在你日常的选择里。

现实也印证了这一点。 在美国，最顶层的富人平均能比最底层的人多活十几年，并且这道差距还在被主动拉大。 杰夫·贝佐斯、山姆·阿尔特曼、彼得·蒂尔等人，正把真金白银砸进抗衰老与延寿研究里。 他们不是在随性做慈善，而是在投资一种新特权：用钱买时间。

长寿，原来从来不是单纯的医学问题，它正在变成一门由财富驱动的选择权游戏。
