# 明知短剧这么难，为什么越来越多的人仍往里冲？

从七月搭起短剧社群，到九月办完第一场千人短剧大会，到现在跟上百位做短剧的创业者聊过天。我被问得最多的一句话就是：这门生意明摆着不好做，为什么还要进来？

聊下来，入场的其实分成了五种典型画像。

**1. 小说分销的老玩家，不想眼睁睁看着盘子缩水**

短剧起来后，小说分销的蛋糕被明显挤掉了。很多早年靠小说起家的团队，手里有投放能力、有渠道人脉，公司运转也离不开现金流。不往短剧上试，就意味着收入下滑、裁员潮。

起初近八成的小说分销公司都冲进了短剧分销，但玩法完全不一样。小说时代，平台的好内容会优先给分销商做推广；短剧时代，爆款基本先被平台自己吃掉，分销商能接到的份额很有限。小说投放当天回不了本，还能拖；短剧当天回不来，基本就凉了。

粗略估算，100 家小说分销入场，真正能稳定赚钱的也就十家左右。五成已经撤了，两成还在硬扛亏损，两成开始转身自拍、甚至想搞个小剧场。小说分销有投放基因，有好剧就能赚钱，关键是好剧太难拿到。拿不到一手资源，最后就两条路：退出，或自己做内容。

有趣的是，短剧亏起来其实比小说亏得少。短剧投不出去当天也能收回八成左右；小说周期长，运气不好回本一半，账号一封就血本无归。

**2. 赚到钱的大佬，都盯着天花板更高的赛道**

今年年初，私董会里的会员反复问我现在还有哪些能干的项目。站在新媒体圈里，我能看到的就剩四样：私域、快团团、视频号、短剧。结果我身边年利润几千万到几个亿的“大哥”们，几乎都往短剧平台上靠了。没人只做分销，大家都知道分销难挣，初期做分销大多是为了练兵。

私域很抗打，但门槛极高。我周围不少大哥试过，最后都觉得风险太大。快团团年初看着香，靠公众号资源还能赚，后来政策一变渠道封死，天花板又低，基本被大佬们直接否了。

视频号已经火了很久，大家都玩过，发现天花板有限。一个月能做 100-200 万利润就算很强了，虽然后续可能还有空间，但动力不足。

短剧不一样。抖音数据透明，谁赚了多少大家心里都有数。利润虽薄，但上限高。曾经一天充值 3000 万的神话，意味着一天净利 300 万。视频号和快团团加起来一个月到 300 万已是顶流。哪怕每天做到 300 万充值，也比另两个赛道强太多。于是很多人都觉得，自己也许就是下一个被选中的人。

**3. 传统影视公司，把短剧当成唯一的活路**

做完社群和大会，我经常开玩笑说自己半只脚进了影视圈。28推第一届短剧大会，来的承制方比我熟悉的平台和分销方还多。在社群里，承制老板的占比也很高。

对他们而言，短剧几乎是唯一能接手的活。老本行就是拍戏，也只会拍戏。现在很多老牌影视公司都在转身，比如陈思诚团队的副总最近也进了我们的社群，打算把《消失的她》等头部 IP 拆成短剧翻拍。香港导演王晶的短剧开机，也一度刷屏。

短剧某种程度上保住了传统影视的就业。大部分项目不赚钱，但总比以前没活干强。横店都快变竖店了，影响可见一斑。

常见的合作模式是出品方全额投资，拿几十万找承制方拍摄，承制方有保底收入，出品方赌爆款回本。业内公认爆款率不足 10%，大部分投资方注定打水漂，但从业者有了饭碗。

**4. 大环境收紧，各行各业的老板都想找个新口子**

前三类基本都是 28 推的老面孔，第四类就完全破圈了。九月大会之后，找上门的有游戏公司、做房地产工程的、山西的煤老板，甚至地方官媒。

短剧爆了，游戏公司的盘子也被分走一口。用户时间有限，广告位有限，短剧分流了游戏的用户和流量。游戏公司发现短剧的逻辑跟他们做游戏很像：找爆款、做投放、靠充值。于是也想分一杯羹。

本质上不是短剧多暴利，而是可选的项目太少。本业见顶、资金闲置、不想闲下来，于是试一次短剧，万一自己撞大运呢。

**5. 行业开始整顿，这是危机还是筛选？**

最近群里最常见的消息就是又有一批剧被禁投、下架，市场有点慌。很多人还没赚到钱，就觉得门槛越来越高。

这其实是互联网项目成熟的必经阶段。媒体把行业炒太热，监管跟上也在预期内。只要用户总盘子还在，需求就在。真正拼的是团队的硬实力。别人投不了，你能投，反而是窗口期。留下的，终究是剩者为王。
