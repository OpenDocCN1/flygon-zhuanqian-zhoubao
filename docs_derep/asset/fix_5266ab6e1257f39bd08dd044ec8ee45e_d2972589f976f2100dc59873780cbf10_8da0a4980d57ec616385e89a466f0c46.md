# 推广链接从哪拿？各平台逐个看

### 口令防折叠：一个超实用招

有些微信账号权重不高，或者发得频繁，哪怕整条口令只有一行，发出去也会被折叠。
亲身验证过的解法：借代码里的转义斜杠 /. 把口令分段，但口令的功能不会受损。
如果分段后依旧被折叠，可以试着多加两个 / ，记着得用英文半角。
这招不少老淘客都不清楚。

## 美团联盟怎么操作？

记住一个原则：先报名，再推广。
把「活动中心」里所有带奖励的项目全部报名上身。
随后点底部的「活动」标签，即可取得你的专属佣金链接去分发。
注：同一个账号自购是零佣金的，想自购拿返利，请走「美团圈圈」。
