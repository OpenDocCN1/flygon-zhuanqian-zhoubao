# 解散团队 —— 无条件信任自己的选择

看到这里，你多半会以为我现在靠副业赚得不少吧？但真不是。

我早就不做虚拟资料了，原因是什么呢？

刚开始能撑下去，是因为心里有一堆目标推着我走：完成自己的任务、证明这条路可行、让别人高看一眼、赚到钱……正是这些动力让我咬牙撑住。

等项目跑顺了，我开始想扩大规模，就组了个小团队。

白天上班，晚上带着成员一步步实操。

大家陆续赚到了钱，我也用分成的方式，把她们推到台前。

[PRE14]

但越做越大，我反而越来越抗拒。

每天都在反复问自己：“我真的想一直做这件事吗？”

答案是：不想。

这种感觉跟我当年做设计时很像：不是发自内心喜欢的东西，就算做出了成绩，内心也是空的。

418活动之前，我做了一个让很多人不理解的决定——解散团队。

有人觉得我不该放手，毕竟能拉起一支队伍不容易。

有人替我遗憾，说我放弃得太可惜。

我自己也纠结了很久，甚至怀疑过自己是不是太冲动。

但最后，我还是选了“拒绝”。

原因特别简单：我不喜欢。

我不想为了钱委屈自己，也不想硬走一条不是自己选择的路。

别人赚多少，跟我无关。我只想做我真正喜欢、愿意全力投入的事。

分享一句我在私域大会看到的、让我更坚定的话：

“活着的意义除了体验，就没了。所以，无所吊谓” ——云蔓

[PRE15]

所以我转身回到自己热爱的方向——IP。

我喜欢当教练的感觉，喜欢分享带来的力量，喜欢看到别人因为我的陪伴跨过难关的满足感。

于是我开始深耕公众号、AI自媒体、朋友圈记录这些方向，慢慢扩大自己的影响力。

做这些事，我发自内心地快乐和满足。

它们不像任务，更像是生活的一部分。

走到今天，我常常告诉自己一句话：“无条件相信自己的选择。”

一条路好不好，只有走完才知道。

但只要你做决定的那一刻是真心实意的，那就是最好的选择。

我很庆幸自己敢解散团队，因为这件事让我更清楚：钱不是终点，热爱和愿意长期投入的事，才是我真正想奔赴的方向。
