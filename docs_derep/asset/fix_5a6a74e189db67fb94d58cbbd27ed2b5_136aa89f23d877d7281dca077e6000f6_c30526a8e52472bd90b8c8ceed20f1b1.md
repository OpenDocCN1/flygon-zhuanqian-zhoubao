# 赚不回入场费的那一年，和突然翻了五倍的这两月

我在这个社群里待满一年了，第6期也快画上句号。从加入那天起，视频带货的项目我一期都没落下。但直到今年2月之前，所有入账加在一起，也够不上当初花的那个入场费。

转折就发生在最近两个月。

如今我的两条线算是跑出了形状：短视频带货的佣金，单日最高冲上过1000+；AI出图这边，每天也能有200左右的稳定进账。光算这一期实战的收益，短视频带货给我带来了差不多1.3w，AI出图也有6000多。不用说，那份3865元的入场成本早就消化掉了，整体回报大约是原来的五倍。今天想把这段经历完整摊开，聊聊我究竟做对了什么。

## 01 第一单是怎么来的

先说一个背景：我这个人特别怕在社交平台上暴露自己，私人动态一年到头也发不出几条。AIGC方向的第一笔收入，源头要归功于天辉老师的一次分享。他给了一段很有推动力的话，让我瞬间觉得“试试又不亏”。[PRE0]

正是那段话，让我鼓起勇气在个人动态上发了第一条AI出图的帖子。发完的第二天，就有人来私聊打听；到了第三天，第一位付费用户出现了。直到现在，我的客户大头仍然来自私域社交圈，以及圈内朋友牵线转介绍，最近才开始尝试往外拓展。

## 02 变现路径拆开看，就是四个动作

我的套路并不神秘，压成一句话就是：铺动态、拉社群、带学员、吃分成。

一开始，我照天辉老师给的方法，做了个“21天AI出图之旅”的付费小群。价格定得不高，但入群的到今天也只有1个人。不过这一单也算是我挖到的第一锹土。

后来我察觉到一件事：身边好像没多少人真的想“学会AI出图”。于是我换了策略，改成每天发自己跑出来的图，风格尽量杂——今天古风，明天赛博朋克，后天手绘质感，想着总有一款能戳中谁。确实陆续有人来问了，但我当时还执意把对方往那个只有1位付费用户的小群里引，效果约等于零。

再往后，我试着搞了个“评论区留言送定制图”的活动。结果评论区和我的人设一样高冷，只来了1个人参与。[PRE1]不过意外的是，有几个熟人因此私聊找我帮忙出图。都是朋友，我实在不好意思开口收钱。脸皮薄这件事，算是优点也算缺点，尤其对我这种缺钱的人，妥妥是缺点。

最后一环才是关键的转折。我发现大家不关心“AI好不好玩”，关心的是“AI能不能搞钱”。于是第二个群顺势成立，名字很直白：AI出图21天搞钱计划。响应明显不一样了，现在已经满员收队，一共20位学员。运作方式也很简单：我这边负责交付成图，把学员领进某音、某书的壁纸号赛道，组成小队一起跑；产生的收益我参与分成，他们手里的定制客户也会回流到我这里。[PRE2]

除了以上四步，我也试过把成片丢到短视频平台上，播放量只有几百，不算好。但至少有一部分熟人因此看到，后来主动找上了门。

当时群里有人问过我：你没有一手壁纸号经验，凭什么去带学员？这个问题我认真想过，底气来自三处：一是报过小说推文项目，懂某音的基础规则；二是我本来就在做内容运营，对传播不算陌生；三是社群里的资料库真的厚，翻一翻往期项目指南，把观点融一融，现阶段够用了。

这里面当然有运气成分。可运气要起效，前提是你先动起来。哪怕赚一块钱也是在让轮子转起来，后面才有优化的空间。

熟悉我的朋友都知道，我以前是个极度纠结的人。风格选不定，方向想不清，纠结了小半年也没迈出半步。后来是天辉老师那句“试试又不会亏”点醒了我。试错成本本来就低，而且好看的图我自己也愿意往动态里发，念头一松，行动就快了。

## 03 聊聊那种让人缩在壳里的“怕”

去年5月30日18:34，我付了3865元，正式入驻这个社群，正好赶上机制调整。新机制好不好？客观讲，它让更多人有机会参与进来，算是一个相对合理的状态。但对一个内心戏极重的新人来说，体验确实有些难熬。

刚进来时，我看谁都像大神，随随便便点开一个头像，都觉得对方比我强十倍。群里的自我介绍环节，更是能把我逼到脑细胞枯竭。一方面确实是性格使然，另一方面也是因为我压根不知道该怎么梳理自己手上的资源。所以一整年里，我在社群里几乎没发过帖子，回消息的次数一双手数得过来。

每次参加项目，我的理想流程是：看指南、看老师分享、看别人交流。实际流程和理想流程的区别在于——看完就没了。有问题吗？有。但我不敢问，怕暴露自己太小白，怕没人搭理，怕在人群里留下“这人不太行”的印象。所以绝大多数疑问都被我自己硬吞了，要么靠独自摸索，要么暗中盯着群聊，看看有没有人跟我踩同一个坑。能撞上的几率不大，而我也不可能一直挂着群。

这一年在项目里扑腾下来，收益自然少得可怜。赚不回入场费这件事，回头看也算是有因有果。

## 04 真正的转折：敢提问，以及一场高烧

2月，我报了AIGC方向的项目，被分到5群。那里的氛围彻底改变了我：大家都很乐意接话，任何问题丢出来，都会有人回应。我试着抛出了前两个问题，很快得到耐心的解答。从那一刻起，我胆子就大了，后面遇到不懂的全都往外倒。更让我惊喜的是，绝大多数问题都有人帮我接住。从前那个连问题都不敢打完的“透明人”，就这样完成了最重要的一次突破——敢开口了。

正当我铆足劲准备冲刺时，开营第3天，我倒下了。体温一路飙到39度，躺在床上什么都做不了：视频剪不了，跑在本地电脑上的SD也开不了，所有计划都作废。没办法，我只好临时换到MJ上。没想到，这次被迫换工具反而让我意外打开了视野。

发烧那几天，我唯一能做的就是抱着手机看群。越看越发现一件事：这个领域的新手是真的多，好多问题我自己也问过；还有好多问题，指南里明明写得很清楚，却依然被人一遍又一遍地抛出来。我都替义务带队的组长们感到心累，天天答同样的东西，脾气得多好才能扛住？

于是我开始做一件事：把自己知道答案的基础问题顺手答了，尤其是我问过、踩过坑的那些。装着装着，人也就自然了。我慢慢习惯了在群里发声，也开始在打卡日志里分享自己的学习心得。[PRE3]

## 05 把我从角落里拽出来的人

如果说“主动提问”是我自己迈出的那一步，那后面几步，几乎是被义务带队的伙伴们推着走的。

这期我一共跟了四条线。印象最深的，是负责小红书的常常。群里数他最活跃，分享欲也最强，我对他印象不差。不过按照我最初的规划，小红书只是用来摸摸底，主要精力都放在小说推文那边。所以对常常的热情，我并没有给出太多回应。现在想想有点辜负他的劲儿，在这里补一句抱歉。

但要说对我影响最大的人，还得是AIGC群那位带队组长Y024。

Y024和常常是两种风格：他很少在群里频繁刷存在感，年纪也比我大一些，但总有一种奇特的“皮”。最标志性的动作，是每次出场都带一个特摄片风格的小玩具摆件。仔细回想起来，他好像没教过我什么硬核技能……吧？但他确实在几个关键节点上，把我往前推了一大步。

我的首篇项目日志被选为精选时，随着那个小玩具“出场”，我被Y024在群里公开点名。那一刻我整个人都懵了：回吧太尬，不回吧又不礼貌。等那一波热闹过去后，Y024又半认真半玩笑地让我分享变现思路。他这个人实在太没有距离感，加上那种松弛的皮，我竟然慢慢放下了心理负担，做了人生头一回群内分享。

分享完以后，陆陆续续有人加我好友，追着问了不少细节。我尽可能耐心地讲了自己的经历，结果有个伙伴直接给我发来转账。我一边觉得“这怎么好意思”，一边发现手机上的自动收钱插件没关！各位能想象那种恨不得钻地缝的尴尬吗？现在脸皮练厚了，有红包尽管来砸我。

说到我和Y024是怎么熟起来的，我到现在也说不太清。好像一切都是自然而然发生的。后来有队友私聊问我：你是不是Y024安排的托儿？从那以后，我干脆自称“专业托”。有问题也习惯了找他和组长黑皮。一个给我提供“特别服务”，一个负责“心理按摩”，配合得相当默契。[PRE4]

黑皮，是我的组长。

好了，关于黑皮组长的话到这里——小玩笑，别当真。

黑皮组长话少得可怜，但人是真的暖。他的“皮”和Y024的“皮”完全不是一回事。据我观察，他悄悄给不少队员做过心理按摩，而且从来不让别人知道，好像生怕别人感谢他一样。[PRE5]

是Y024、黑皮这些人，让我第一次觉得这个社群不只是个资料库，而是一群活生生、会伸手拉你一把的人。

## 06 给同样慢热的后来者，四句心里话

又快到社群纳新的时间了。作为一个只“读”了一年的同届新生，想给那些和我一样容易紧张、容易退缩的伙伴几句建议：

第一，试着交一个老圈友。社群基数很大，愿意分享的人也很多。找一个性格与你合拍的，完成第一次评论、第一次请教，你会发现：所谓大神，其实也是普通人。

第二，认真参与一次实战项目。在社群里我始终怀着一点敬畏感，总觉得发帖的都是高手，与自己无关。但进了项目后你会发现，里面有一大堆和你水平差不多、甚至起步更晚的人。看到他们也能跑起来，信心自然会涨回来。

第三，主动去链接。你想要什么资源、你能提供什么资源，都要大声讲出来。你不说，资源不会自己跑到碗里；你说出口了，很多机会才会顺着找上来。

第四，不要害怕分享。哪怕问题再基础，在这个社群里也会被欢迎。只是分享之前建议先搜一搜，尽量不要重复说已经说过很多遍的内容。

最后，想认真对这次实战中给过我帮助的所有人说一声谢谢：替我答疑的，来向我咨询的，给我打鸡血灌鸡汤的，还有默默付出的义务组长们。没有你们，我大概率还在社群里当一个不敢出声的看客。
