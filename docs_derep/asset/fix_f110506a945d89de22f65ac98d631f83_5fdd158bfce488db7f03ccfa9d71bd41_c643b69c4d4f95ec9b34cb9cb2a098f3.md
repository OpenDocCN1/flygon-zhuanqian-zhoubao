# 4. 踩坑记录

## 文案问题：

### 问：脑子没灵感，AI 给的文案又干瘪没看点？
答：提前喂点故事素材，或用对话方式引导优化。

### 问：提示词出图总不准？
答：MJ 或 GPT 出图时，翻译优先用谷歌引擎，其他引擎理解偏差大。国产 AI 则多半是提示词细节不够，需要在更多维度细化。

### 问：文案工具推荐？
答：GPT = 豆包 ＞ Kimi

## 出图问题：

### 问：哪个工具更合适？
答：提示词理解能力 GPT ＞ 即梦AI ＞ Midjourney

精细度排序 Midjourney ＞ 即梦AI ＞ GPT

低成本排序 即梦AI ＞ GPT ＞ Midjourney

（仅供参考，不喜勿喷，主打任性😤）

### 问：能免费用吗？
答：能。下一个指纹浏览器，免费版一般可开 10 个窗口，再找亲友借号多注册几个账号，用每日赠送积分就够了。AI 视频也一样，前提是有网页版。目前即梦、可灵、海螺理论上都能薅。

### 问：角色一致性怎么解决？
答：解决不了~💢

短视频里最关键的就是角色一致性。你不能看十几秒主角就换人吧？下面两个方案是我实操总结的，

#### GTP - 【dall-e-3】

打开 B 族 Midjourney 提示词生成器，向下找到【命令区】，里面有个【角色一致性】图片按钮。把要固定的角色或动物图上传，记得点【提交】，再点【角色一致性】文字按钮。

操作顺序已在图上标出。
