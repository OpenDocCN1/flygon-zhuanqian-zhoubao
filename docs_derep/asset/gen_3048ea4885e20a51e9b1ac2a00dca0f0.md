我是彻易Heawcyrt，04年大学生，全网万粉博主，大二实现经济独立，自由职业搞钱玩家。

最初看到京东外卖项目，是2月12号晚上刷到一位老板的朋友圈，说京东要做外卖，问有没有认识服务商的。当时我没当回事，只是感慨天下苦美团饿了么久矣。现在复盘，为什么没第一时间嗅到商机？大概是因为“服务商”这个词，让我下意识觉得这项目不是普通人能碰的。

一周后，2月18号下午，看到有人发京东外卖风向标，说在任推邦就能做，地推一个人170块。晚上又刷到新闻号吹“一天能过千”，甚至看到生财圈友晒收入1w的截图。

# 一、地推前准备

工服、工牌、SOP手册、探店规划表、线上试水，一样都不能少。

## 1. 工服和工牌

拼多多或淘宝买一身，加起来20块左右，甚至10块也有。一定要买吗？一定要，三点理由：
- 看起来正式，身上的“京东外卖”让老板觉得专业、可信；
- 这是行走的“水印”和记忆点，有些老板正好想入驻，看到你会主动招呼你。我5天里几乎天天在马路上被叫住；
- 有个老板告诉我：“上午来了七八波小伙子，我都不太信，感觉你最专业，有工服有工牌。”

插一个同行教我的理论：如果你长得成熟、不像学生，可以只买工牌。因为穿工服戴工牌的一般是普通员工，只挂工牌的是区域经理。

## 2. 一份通俗易懂的SOP手册/打印件

我提前给商家写了一份入驻步骤说明。地推时，老板有兴趣，我就拿起平板演示。建议用电子版，纸质版容易因为下雨、手汗、皱褶、丢失等情况不好复用。

## 4. 提前线上找店家试水

这招很关键，是我对象建议的。线上跟商家聊，既能测试意愿程度，又能提前了解他们关心的问题，免得线下被问住时答不上来，降低信任度。我地推前一天（等工服快递）就在家线上聊，流程是：
- 去大众点评/美团找有线下店且做外卖的商家；
- 在美团/饿了么上找到店，一般都能私聊商家，直接要微信，很多会给；
- 不给就问你干嘛，就说要点单，先加上再说；
- 平台一般能搜到电话，复制加微信，但很多是店铺官号，不是老板个人号；
- 开门见山说推广新平台帮他们赚钱，或者直接摊牌负责京东外卖入驻；
- 实在不给就算了，总会有给的。亲测饿了么商家回复率和给微信率更高。

# 二、时间和店铺选择

## 1. 合适的时间

最推荐工作日下午。上午也可以，但很多商家10点才上班，一上班就要备中午的餐，时间不充裕。我每天下午1点半出去，5点前回来。补充一句：雨天千万不要偷懒！下雨天实体店没多少人，安静的氛围更适合和老板细聊。

## 2. 合适的店铺（血泪避雷指南😭）

- 大品牌店不要去❌（肯德基、麦当劳、袁记云饺等，基本都是总部统一安排入驻）
- 商场店能不去就不去❌（杭州这边，商场店老板要么平时根本找不到，是幕后大老板；要么是连锁店听总部；要么听商场安排。有些店看着不起眼，其实是连锁店🙃）
- 独立个体店才是最佳目标！✔（所以去商圈不是奔着商场店，而是找商圈附近的个体店）

# 三、心态与话术

## 1. 核心心态：我是来帮大家的

一开始地推我特别忐忑，上次干这种事还是三年前，不好意思开口。所以一定要暗示自己：我是来帮大家的，帮商家扩展新财路。在这种心态下，说话有底气，而且是免费帮，不要钱，更有底气。被拒绝是常事，我去第一家就被拒了，老板说外卖水深，做好堂食就够了。我没放弃，介绍京东外卖怎么好，他还是婉拒，我也没拉扯，表示理解，祝生意兴隆就走。结果刚出店门，他把我叫住，拉去旁边几家店，让其他店主加我微信，说他不做，但旁边的商家可能需要。如果我当时一听拒绝就掉头走，肯定不会有后面给周边商铺开“露天小会”介绍政策的机会。所以，礼貌、客气、有底气，别轻易放弃。

## 2. 话术建议：利他、专业

### 开场白
“老板您好，我是京东外卖的，最近在帮周边商家办理京东外卖入驻。看您家评分不错/销量挺好/好评挺多，想问下您了解过这个新平台吗？”
要说“帮周边商家”，别说“帮你”。说帮你，人家可能想哪有这种好事；说帮别人，老板会觉得别人都弄了我也要弄，不弄别人就抢先了。

### 对方想了解
“现在美团饿了么不是一般抽20%左右嘛（停顿）。京东现在刚开始做外卖，所以5月1号之前入驻的商家0抽佣，后续下一年也保证5%。”
停顿很关键。其实一般抽25-30%，故意说少点，对方会纠正：“哪有20%，都30%了！”这时就可以说：“对，可能杭州是一线城市抽得更狠。确实太多了，我们京东目前刚开始做……0抽佣，后续……5%。”这样对比冲击更强。之前有个店主完全不感兴趣，说京东没做起来，我用这招让他主动来问。

### 对方说了解过
“那挺好。我这边就是专门负责帮周边商户入驻的，免费0佣金，您只需要相关证件就行。您看下这些。”递上平板，突显专业。

### 纠结/担心没人买
“您看，反正入驻不花钱。目前京东外卖上主要是些奶茶店，我们现在主要是推商家端，先拉商家入驻，把店搞起来。后面肯定会出一系列优惠活动扩大用户群体，让年轻人用起来。京东也不是小公司小品牌，趁现在附近入驻的商家还不多，先占个位置，后续就有天然优势。”
强调京东品牌地位，让商家相信平台能做起来，现在进去占位置。如果对方问后续优惠是不是商家承担，回答：“美团饿了么这边应该是商家承担比较多吧。我昨天听一个商家说，美团10块钱优惠券商家自己要承担9块。我们这边优惠券京东承担的多，而且京东主打品质外卖，不会搞那种无底线的低成本外卖走量。”如果追问具体金额，就说每个城市消费水准不一样，动态变化。

### 实在不感兴趣
“好嘞，要不您加我个微信，后续京东做得不错，您有入驻打算再联系我。打扰了，祝老板生意兴隆。”买卖不成仁义在。

### 已经入驻了
“好嘞，您是通过什么渠道入驻的？入驻后体验怎么样？有没有遇到什么问题？”主要是积累素材，方便服务未入驻商家，显得专业。

### 老板不在
“是这样，我是京东外卖的，最近在帮周边商家办理京东外卖入驻，一般老板什么时候会来店里？”或者“您这边有老板微信吗？”很多老板不常在店，尤其不忙的时候。这时候问时间、要微信，后续再跟进。

# 四、帮商户入驻

根据我跑60多家的经验，一定要帮商户入驻。让他们自己弄，会出各种错误。京东审核特别严格，证件稍微远一点、反光就过不了，还经常有bug搞心态。之前帮一个商户入驻，花1个多小时排错，打电话给客服人工审。总之特别麻烦，最好线下协助，不行多试试。

具体步骤就不多写了，重点是一定要全程帮。

# 五、常见问题Q&A

Q1：0佣金，配送费多少？
3公里内3块，超过的，不同城市不同，浮动中。

Q2：能用美团饿了么的打印机吗？
不能，需要自己花钱买新的打印机。

Q3：开店人和法人不一致怎么办？
没办法，京东上传证件时，要保证所有涉及的人物、地址信息都统一。

Q4：明明各方面没问题，但显示信息错误？
先一遍遍检查：编号有无错误、图片是否清晰、方向要正、大众点评评分优先（美团评分要用美团美食评分，不是美团外卖评分）、评分要截图不能拍照、任何证件不要缺角反光、不要用AI美颜。还不行，隔一天试试，亲测有效。

Q5：什么时候能领钱？
规则动态调整，用任推邦就每天关注规则详情；别的服务商也要确认好。

Q6：商家订单什么时候提现？
3天后到账商家端，提现T1到账。

Q7：能校园接力送吗？
不同地区可能不同，初期大多数地区可能不支持。

Q8：同一张营业执照能注册不同分店吗？
不可以，京东外卖不允许虚拟店铺，一照一店。

总有答不上来的问题，那就硬编。一定要底气十足地硬编，或者说新平台刚运营，功能没完善，加个微信，晚上回去跟总部汇报。回去可以打400-002-0020咨询京东秒送官方客服。

# 六、最后：我不建议个人入局这个项目❌

我做了5天，每天下午1点半到5点，平均每天签一个商户。但第5天以后我就停了，因为第一天成的单一直没审核过。网上风言风语，任推邦规则还变动，说什么“测试期，结算以京东反馈为主”。我想看到钱再继续，然后就没有然后了，到现在没有一单过审核。

核心原因：赚不到钱。

不管别人吹得多好，我个人体感就是很难赚钱。我在杭州，这次地推让我明白为什么叫“美食荒漠”——到处都是品牌连锁店，这些店基本都是总部统一签约；独立个体店太少，就算有，要么幕后大老板不在，要么是苍蝇馆子、家庭店，评分和店面质量达不到京东要求。

最初入驻只要“营业”且商品≥5；后来改成要“营业”5天且商品≥15；再到现在，必须开单且商品数量比美团、饿了么多才算一单，还要商家绑定京东钱包。让人家下载“京东金融”绑钱包，开通金融业务，谁放心？

而且，商家没过审核，你要跑一趟看怎么回事；菜单没上齐，你要帮着上。忙前忙后，万一他京东一直不开单，后面不营业了，钱也没了。

其实打电话问京东官方，他们不承认这种形式的地推。害，别真给人家当免费牛马。调研全网，现在真正能提现、发钱的，要么是P图，要么是包浆网图，要么是服务商垫资。任推邦是服务商之一，目前网上没见到真实提现截图，如果有欢迎指正。

最后总结：带不走金钱，就带走经验。作为来杭州发展的大学生，地推加深了我跟这座城市的链接。跟老板聊、跟同行聊、跟美团饿了么骑手聊，甚至在公交车上被陌生爷爷奶奶搭讪，聊了一路发现住同一个小区。我也通过这次地推，找回了高考后那个暑假，孤身一人在陌生城市里想办法生活的激情，和最真实的社会互动。
