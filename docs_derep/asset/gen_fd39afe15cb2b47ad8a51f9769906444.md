# 公众号爆款写作8个月做到七位数，秘诀只有一个：先守住下限

你有没有想过，为什么同样做公众号爆款写作，有人能轻松赚到七位数，有人却每天纠结在几块钱的收益里？

我是亦小亮，一个泡在生财社群多年的老面孔，目前也是公众号爆款写作航海的教练。这个项目，我做了8个月，收益已经突破了七位数。但比收益更让我感慨的是：眼睁睁看着同船的人一个个下了船。

航海结束有一阵子了，可放弃的人数多得惊人。照这趋势，下一期还想上这艘船的人，大概率会比九月少。为什么大家会放弃？很简单，每天几块钱的收获，真的会磨掉一个人的心气。

但几块钱只是表面，真正的病根在哪？我看得很清楚：大多数人的心思压根没放在正确的地方，而是整天琢磨“找指令”。总想抄捷径，指望一条指令就让爆款自动出现。结果呢？捷径走到头，前面根本没有路，不得不掉头去找新项目。就这样，一年又一年，始终在原地打转。

他们缺的是什么？不是运气，而是对爆款逻辑的深入理解，更缺乏愿意下笨功夫的踏实。写作这件事，哪有什么一夜暴富的密码？无非是把基本功一项项砸实，把爆款案例一篇篇拆透。

所以我写这篇分享，最重要的目的就是帮所有人保住项目的“下限”。只有下限稳住了，你才能心无杂念地挑战上限；只有账户数字不再每天可怜巴巴，你才可能拥有坚持下去的底气。
