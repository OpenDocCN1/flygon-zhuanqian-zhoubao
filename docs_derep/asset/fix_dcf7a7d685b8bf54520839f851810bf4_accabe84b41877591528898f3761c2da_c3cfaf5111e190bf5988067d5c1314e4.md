# 从零起步做亲子社群，如何实现十万级收益

先聊下自己。我是一名儿科方向的医生，朋友们都叫我伊森。

很多人问过我：一个没有任何社群基础的人，凭什么能把亲子社群做到十万级收益？这篇文章就是我的完整复盘。

坐标上海，我在一家三甲医院的儿科相关科室工作，临床一线待了十八年，累计看护过的宝宝超过十万名。业余时间，我维护着一个医学主题的内容号，兼任健康类公司的顾问，也长期和母婴购物渠道有合作。

今年二月，星球组织了一场社群实战训练营，我果断申请加入。没想到，项目的组织者主动找到我，请我把当时的操作过程整理成一篇分享稿。于是就有了这篇文章。

坦白说，我在社群领域完全是个外行。能把这个小圈子从零跑通，靠的是一步步试错、观察与调整。没有什么捷径和秘密，从定位、人员筛选、内容规划到日常互动，每一步都有值得记录的细节。

这篇复盘主要适合两类朋友：一类是想认真经营自己的社群、却不知从哪下手的新手；另一类是关注亲子市场、母婴方向的从业者。希望我踩过的坑，能帮你们少走一些弯路。

也想借这个机会，特别感谢平台和那位邀请我的老师，给了我一次公开表达的机会。你们的鼓励，是我持续输出的动力。
