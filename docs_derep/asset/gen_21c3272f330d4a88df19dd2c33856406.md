#### 生图节点搭建

gpt-4o-image 走的是对话式输出，JSON 里会嵌套很多层，所以正文部分不能使用 Form-Data，必须直接写 JSON。我已经把 JSON 正文准备好了，下载后复制到 json 模块里粘贴就能用；同时把整理模块的输出内容直接拖进来就行。

这个 API 没法在参数里指定图片比例，所以需要在提示词最后加上 `ratio==3:4`，用来向模型强调生图比例。当然，模型偶尔还是会不听话，生成其他比例，如果你有更好的方法，欢迎告诉我。

另外，URL 要改成 https://yunwu.ai/v1/chat/completions，API Key 需要有下图三个分组中的任意一个。你可以跟刚才那个 API 分开，单开一个 API 填到这个分组。[PRE6][PRE7][PRE8]

#### 需要注意

gpt-4o-image 偶尔会生成失败，那样后面节点拿到的全是空返回。如果想让循环一直跑下去，最好把画图节点后面的所有节点都设置为“出错时跳过该节点，继续后续流程”，这样就不会因为某次没出图而中断整个循环。[PRE25]
