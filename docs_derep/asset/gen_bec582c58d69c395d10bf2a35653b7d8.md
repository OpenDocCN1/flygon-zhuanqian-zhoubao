# 四、账号人设搭建

肖像相关的图记得打码，避免惹麻烦。

几个要点：

1. 昵称走女性路线，头像和主页背景同样要女性化。
2. 抖音简介直接挂微信，微信号越短越好，最好别加多余文字。
3. 老号（注册超过7天）挂微信基本稳妥；新号前7天先别急着挂，先发几条风景日常养号，等正式发引流作品时再改简介。
4. 主页最多留两条引流作品，发第三条时记得把前面的隐藏或删掉，中间穿插些风景照，让号看起来像个真人号。

新号的话，前三天每天刷半小时视频、发发风景，第四五天再开始上引流视频。

# 五、简介被重置？三步解决

简介挂了微信后被系统重置，用这个流程：

第1步：先写一段个人化简介，比如“喜欢周杰伦的《晴天》，家里有猫有狗，平时打打王者”，字数多点没坏处。

隔两小时以上再改一次，在末尾多加几个字（比如“分享日常朋友圈”），让它过一遍二次审核。

第2步：第二天在简介末尾加上微信号，大概率能成功。

这套路我是反复试号试出来的，成功率还行。

# 六、发布规范

# 七、私域成交关键

主动加过来的人基本都有交友意愿，别急着推销，先正常回应着。人家一直找你聊天，你有空就陪聊几句，但敏感信息千万别碰。

成交基本靠朋友圈，大概占 98% 的成单率。刚加上的新用户，哪怕回个表情包也别晾着，不然很容易被删。

# 八、敏感规避，这些雷别踩

1. 微信里绝对不要谈交易，引导去二维码里成交。
2. 朋友圈别堆二维码，发一次删一次。
3. 保证朋友圈永远只有一张二维码，这样别人举报也难成立。
4. 美女图注意尺度，太擦边会被判色情低俗违规。
5. 售后一定要处理：盲盒搜不到、抽不到等问题得及时回应。
6. 抽中了联系方式但加不上的，让客户找客服退款。
7. 抽很多次没中的，万能回复：“都是概率性的啊，我也没办法。” 配个表情包缓和气氛。
8. 纯耍流氓的可以不理，但消费相关的问题必须处理，毕竟人家花了钱，不然容易被举报。

另外记住：绝对不要主动怂恿用户去玩，保持被动。别人问你再答，别主动推销。这是我成交量最高的一条心得。
