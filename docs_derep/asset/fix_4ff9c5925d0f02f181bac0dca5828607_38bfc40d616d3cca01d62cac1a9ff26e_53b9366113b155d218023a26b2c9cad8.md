# 讲台之外：被裁员的十八个月后，我靠陪跑家长赚了五十万

政策收紧，教培机构纷纷收缩，我也从原先的岗位上退了下来。离开新东方后，我没有急着找下一份工作，而是把目光转向家庭教育。只用了一年半，就实现了五十万的收入。

闲下来的头半年，并不好过。没有早高峰，也不用刷脸签到，日子一下子松散得让人发慌。夜里常常梦见回到办公室，醒来枕巾湿透了。家人从小就说，替别人打工终究走不远，直到那刻我才有切身体会。

为了找点事做，我盯上了当时正火的知识付费。刷着别人晒出的收益截图，听着他们的讲解，我没觉得有多专业，甚至冒出“我上我也行”的念头。后来买设备、录课、发视频，折腾了一圈，结果一单都没有。挫败感让我安静了好一阵。

转机出现在今年二月。经一位朋友引荐，我认识了生财社群。那里的人做事方式和我过往所见完全不同：先搭好产品阶梯，再经营信赖感，之后才谈成交。我照着这个逻辑重建业务。九月，我完成了月入三万的突破。

选择家庭教育，源于我在教培行业见过太多让人心疼的画面。有些孩子努力过，却得不到爸妈的认可；有些孩子遇到困难，得到的是挖苦和指责。他们的情绪淤积在心里，始终没有释放的通道。为人父母者也揣着各自的难处。嘴上喊着不能输，心里却不清楚该朝哪里努力；看别人家娃学什么就跟着学什么，从东拼西凑的内容里很难拼出完整的教育观。越发力，越感到迷茫。

深入接触后，我梳理出三类高频痛点。一是信息碎片化：学了很多，理念互相矛盾，无法落实到行动。二是转化失灵：上课听懂了，回家照做却变了形，孩子一拒绝就断掉。三是无人支援：出了状况也无人商量。尤其是涉及抑郁、被霸凌、成绩崩盘这类难堪情景，父母根本不愿对熟人启齿，只能独自煎熬。他们心底最渴望的，是一个随时在线、熟悉教育规律、能长期陪伴的人。

我的身份定位因此很明确。我的角色不是卖一单赚一单的商家，而是陪伴家庭往前走的人：能看懂各年龄段的问题，能帮家长拆解当务之急，能给出可执行的起步方案，还能在行动途中有问必答，随时纠偏。

从行业格局看，这步棋也现实。头部大V霸占了大量视野，普通个体想靠内容突围很难。而生育率逐年走低，[PRE1]意味着家长总量在缩减。与其不断寻找新客，不如把现有的家庭服务到极致。一个孩子从小学到高中的成长周期很长，信任建立后，复购和转介绍都会自然发生。

产品体系的起点，是我画的一张“育儿全景地图”。[PRE2]灵感来自某家咨询公司的管理模型。这张图把育人过程分成了几个台阶：地基是情感连接；往上是学习习惯、学习方法；再往上是升学规划；最高处是社交能力。每一门课都能在图里找到位置。「亲子修复营」应对地基，「习惯锻造营」「高效提分营」应对学习能力，「未来规划营」应对长远布局，之后又添了「青少年社交课」。家长看着这张图，就知道自己卡在哪一阶，也知道下一阶在哪。

交付时，我给的不是一套冷冰冰的视频，而是四步闭环：先做深度访谈，摸清孩子与家庭的真实状况；再开组合配方，包括课程、一对一辅导和日常练习；然后带着执行；最后继续跟踪。最受家长欢迎的是行动营设计。这个过程终于让我察觉，父母听懂了和孩子做到了之间隔着很长一段路，家人转述常常走样，还容易爆发冲突。于是我干脆略过家长，直接和孩子对接。每周一堂直播课，我教这批小孩一个学习技巧，随后让他们练习一周，隔七天再加一个新关卡。练起来之后，这些小孩的积极性比被逼着学高很多，亲子之间的催促和争吵也少了大半。喜讯不断从各家传来，这些消息又被我收集成案例，成为后续宣传的素材。

零基础做课程，我把方法拆成三步。第一步，收集高频问题确定主题。大家的疑问看似零散，其实按年龄和阶段高度重复，市场需求早被前人验证过了。我把这些待办事项按热度排列，热度最高的那个，就成了新课程的主题。

第二步，主题阅读。我买来市面上热门的书和课程，拆出目录，提取相应内容，快速拼出课程的骨架。第三步，填充血肉。在框架里按逻辑放入案例、观点和操作步骤。头几期我坚持直播，不碰录播，边讲边看家长反应。第一期结束后大幅修改，第二期继续打磨，到第三期才形成稳定的录播课。

流量端，我也走过弯路。最初接手一批被遗弃的家长群，群里的家长对我毫无认知。我从短视频和直播入口引流，送一份资料包换加微信，慢慢养出了个人私域池。

产品阶梯目前是这样：免费的学习圈用来沉淀内容；49.9元的陪伴群，每天固定输出；499元的主题课，搭配练习；99到199元的行动营，过关退还费用；1880元的年卡，涵盖全部课程；1200元一节的一对一咨询，留给问题复杂的家庭。

在朋友圈运营上，我曾经犯过错误。以前只发干货和答疑，从不提价格，结果家长私聊不是问课程，而是直接抛难题给我。我答得越到位，他们越觉得不需要买课。后来我调整策略，每天一条内容都会带上课程和价格，把权益讲透。没过多久，连抄我文案的同行都停了，因为每一条都沾满广告的痕迹。家长来私聊时，也开始自带方案来问课程，转化轻松了很多。

对于高客单的转化，我专门设计了一对一线下体验课，收费299元。见面时，我会帮家长梳理整个框架，让他们明白教育是个长线工程。随后给出两个选项：单报某个训练营，或者选择完整年度方案。有信任基础的家长往往直接选后者，即便这次只报单项，后面补差价也能升级年卡。

九月的成绩单是这样的：[PRE0]十五个一对一规划、三个年卡，合计38410元。代价是每周接待五到七组家庭，每组接近两小时，身体被掏空。十月我把重心转移到课程和年卡，收入掉到26000元，但日子轻快多了。

十月十五日，监管新规正式落地，课外补习的模糊地带被堵死。很多同行焦虑，我却暗自庆幸已经换了赛道。

下一步，我打算把手上积累的素材整理成三样引流产品：优秀案例集、教育问答手册、陪伴群精华合集，然后集中精力做公域，研究视频号和小红书。我的推进顺序始终是产品、转化、裂变、流量。靠着资源和社群的支撑，每攻下一个环节，产能都会翻倍。

这段经历对我而言，最重要的是学会把目光投向人们的真实困难，然后拿出真正有用的办法。如果你也站在转型路口，希望我的故事能提供一点点光亮。
