# 不存定期，也能把钱放在银行赚年化10%+？聊聊我在做的“银行日切”

很多人听到“银行理财”或“存款收益”，第一反应就是定期、大额存单，年化普遍两个点上下。但我今天想分享的，是我自己实操了一年多的路子——银行日切。靠着它，我们做到了年化10%以上的收益，同时白天资金完全不受影响。

先说清楚“日切”到底是个啥。很多朋友以为银行的日终结息一定发生在每天零点之后，其实并不全是。每家的系统节点不一样，有的准点，有的提前，有的滞后，还常常每天“飘”几分钟甚至半小时。既然结息点不一致，那就意味着存在一个时间窗口：你在一家银行赶在它结息前入账，拿到当天的利息，再去下一家银行赶下一波结息。只要节点接得上，一晚上可以在数家银行各吃一次利息。说得形象一点，像一场接力赛，资金在几个“口袋”之间轮转一圈，每个口袋都留下一笔利息收益。

听起来挺美，但实操还真有几个硬条件。

第一，银行里的资金不能是纯活期，而是要跟银行谈“协议存款”。这个和普通活期不同，属于银行和机构或大客户之间谈出来的利率，每家银行给的不同，大致在年化1.3%到2.8%区间。结息大多按季度来，通常每季度末20号结一次，也有少数按月结。银行会看日均余额，日均越高，越有资格谈高一点的协议档位。所以门槛主要卡在资金体量上，真不是随便几十万就能玩的。

第二，你要找得到银行愿意跟你合作。有银行资源的圈友，可以试着找客户经理甚至行长聊。如果对方明确要求资金必须过夜，那这条路可能走不通。只有愿意接受日切操作，且能谈协议存款利率的银行，才有下一步。另外，对公账户和对私账户都适用，只是日切点一样，但风控额度完全不同，后文会提到。

这里也补一句我自己操作的时间条线：白天资金正常用，我们的钱最晚在晚上八点半之前回到账户，八点半之后开始日切操作。这一点非常重要，意味着这笔钱白天完全参与正常业务运转，不占用白天的流动性。

第三，摸清每家银行的“切点”。这步是最磨人的。银行从业者普遍知道“日切”这个概念，但你要问他自家系统的具体切点在几点几分，大多数人说不出来。有些银行是零点准时切，有些在零点前，有些在零点后，有时候今天的切点和明天的切点也不一样，会浮动。所以必须实测。我们一开始的做法，是在第二天去问客户经理，看账户有没有产生当日日均。但那样效率太低，后来我们自己组建了小团队，分工负责不同银行，每天轮流盯点测试。毕竟系统切点会漂移，这是一项365天都不能停的活。

大额系统的时间线也有关键参考：一般下午5:15关闭，晚上8:30重新开启。所以日切操作基本集中在晚上8点半以后进行。遇到周末，大额出款会有所延迟。

再来说说月末存款的机会。每到月末、季末，很多银行都有存款规模考核需求。因为各家银行之间也在互相抢资金，所以愿意开出比平时更贵的价格。尤其是季末，为了保住规模，常常给出非常高的利率。我们上个季度末最多就拿到过一万块一天八块的收益，而且是叠加日切操作，利息吃得很舒服。

但要注意，日切不是躺着赚钱，它有很重的实操成本：

一是每天都要操作。365天不间断，经常要熬到凌晨一点左右。总会有出差、应酬、接待客户的时候，所以身边必须有信得过的亲戚朋友能帮忙盯操作。这么大额的资金每天在多个账户之间流转，信任成本和安全问题，只能自己衡量。

二是网银额度和“头寸”问题。晚上大额系统虽然开着，但如果当日转账额度过大，银行需要提前报头寸，不报的话，系统开了你也出不了款。网银额度目前非常难协调，尤其对私账户，能不能调到足够高的额度，很大程度上取决于你跟银行的关系。这里面有个细节：银行最高可以帮你预设7天的头寸，直接在网银里设置，不用天天打电话。但一定要注意月累计限额和年累计限额。我们自己踩过坑：月底那几天月度限额满了，钱转出去直接挂账，又赶上周末，硬等了两天，白白浪费时间。所以额度这关，一定让银行尽量开足上限。

三是风控线。对公账户每条线要控制在5000万以内，对私账户基本控制在1000万到2000万一条线，不然容易触发银行风控。

四是行口合作并不稳定。每家银行都有自己的规模上限，达到考核之后可能就不再需要这部分资金了。所以得有备用渠道，行口要持续开发新的。协议存款一般半年或一年一签，到期续约，续不续得上看银行那边情况。我目前做得还算稳定，中间也有被降过利率，但好在整体收益依然在预期范围内。

最后说一说我个人的判断：日切目前知道的人不算多，还处于相对蓝海的阶段。从资金成本角度看，能有利率不错的无风险收益，确实是个不错的选择。但对普通人来说，门槛仍然不低：启动资金量大，银行资源得够硬，网银额度要能谈下来，还要365天有人盯，缺一环都很难转起来。如果你具备这个条件，值得好好研究。
