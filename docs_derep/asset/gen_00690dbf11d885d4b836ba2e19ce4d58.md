# 美版“支付宝”Venmo 注册全攻略：自带 POS 机功能、送美国实体卡，零年费零门槛

做过跨境生意的朋友应该都听过 Venmo——它在美国的地位，差不多就相当于咱们的支付宝。跟家人朋友转个账、出去吃饭 AA 一下，甚至给客户付款，都是嗖嗖几下就搞定的事。更香的是，它不仅能转账，还能让 iPhone 秒变刷卡 POS 机，并且免费给你一张美国实体借记卡，不需要年费，也没有最低存款要求，想想是不是还挺心动？

### 为什么做跨境电商的人都在用它？

- 搞 FB 聊单的朋友，经常遇到收款难题：有些产品 Stripe 根本不让收，客户又没有 PayPal，这时候 Venmo 就是最好的突破口。
- 需要给美国本地人刷单返点？Venmo 几乎是老美的“国民钱包”，大家手机里基本都装了。
- 被 PayPal 的争议退款搞怕了？PayPal 一旦发生争议，不仅钱要退回去，还要搭上一笔争议费，严重了连账号都会被牵连。Venmo 在这方面就省心不少。
- 线下收款更是绝：装好 App，用 iPhone 就能当 POS 机使，客户的信用卡碰一下就完成支付。

### 注册步骤，一步步来

1.  **搞定苹果环境**：用苹果手机注册，需要一个美区 Apple ID。淘宝直接搜“美区苹果”，看下拉关键词就能找到，几块钱就能解决。要注意的是，搜索词可能会经常变，灵活换个词就行。

2.  **App Store 里搜“Venmo”**，放心下载安装。

3.  **重头戏：网络必须干净**。很多人卡在注册这一步，十有八九是网络的问题——需要美国住宅网络环境。不知道怎么弄的朋友，可以去我博客 amz10years.com 搜“网络环境”找答案。

4.  **创建账号**。这里有个人、青少年、商业三种身份可以选。日常就用 personal（个人账号），如果做 FB 聊单、收款量比较大，那必须走商业版。

5.  **美国号码激活**。这一步需要用美国号码来收验证码，有性价比高的美卡购买途径，我整理了一份指南，可以看这里：`https://docs.qq.com/doc/DZENab0xoV2R0TVlx`

6.  **填个人基础信息**，然后拉到底部，直接同意用户条款就行。

7.  **网络不对就会报错**。如果跳到错误页面，别折腾其他，回去解决网络本地化问题。网络正常的话，几秒钟就会进入下一个界面，选 Skip 继续。

8.  **添加付款卡**。这里也可以直接 Skip 跳过。如果后面需要绑定卡，去我博客搜“虚拟卡”会有相关教程。

9.  **隐私条款**，点 Done 过掉。

10. **账号还没完全开通**。先选 Skip，等个人信息完善后再来申请其他功能。

11. **点右下角的“ME”菜单，开始做身份验证**。这里需要准备：姓名 + ITIN + 美国地址。参考文章见：`https://articles.zsxq.com/id_w0r5cibax0qb.html` 美国地址怎么搞？博客里搜“美国私人地址”就能找到方法。

12. **进入验证阶段**。home address 那里上传 ITIN 扫描件，name and date of birth 那里提供护照件，提交后等待审核。

13. **注意去邮箱里点一下验证链接**，把邮箱地址验证掉。

14. **申请 Venmo 借记卡**。如果你有取现或日常消费需求，这张美国实体卡就非常方便了——凡是需要验证美国实体卡的场景，它都能派上用场。选好喜欢的颜色，填上邮寄地址，坐等收卡就行。

### 怎么充值？

- **朋友转账充值**：最直接，让朋友直接转给你。
- **自己充值**：选 Direct deposit，填生日 + ITIN + 地址完成验证就行。注意，这里会给你一组 Account number + routing number，这相当于一个储蓄账号的信息。别人要给你打款，让对方通过空中云汇、万里汇、华美银行等渠道转入即可。Wise 也能转，但风控太严，还是建议走华美这类实体银行。需要开户的话，可以找我助理对接美国代理。

### 怎么收付款？

输入对方的姓名 / 邮箱 / 用户名，就可以发起收款或转账。自己的收款二维码也可以直接生成，发给对方扫码付款就行。

### 商业账号怎么开？

需要准备的材料：

1.  公司注册完成
2.  公司 EIN

具体可以直接看这篇文章：`https://articles.zsxq.com/id_exggkcb30j69.html`

操作上很简单：在个人账号的通知按钮附近，一般就能找到申请商业账号的入口，选择 create。通常选第二个选项，然后按实际情况填写自己的生意信息。再设置对外展示的信息，确认没问题后点 publish，基本上又是秒开。默认都需要上传对应法人的 ITIN 信息，等审核通过就能用。

最爽的是，商业账号可以直接用 iPhone 当刷卡 POS 机，客户的卡片碰一碰就能完成支付。而且费率只有 2.29% + 0.09 刀/次，对比其他收款工具，真的挺划算。
