搜索推荐词采集与内容生成助手-chrome 插件

在读过 @沐风 大佬的一篇干货后获得灵感，并结合自己平时的实操需求，做了这么一个 Chrome 插件。它能帮你抓取搜索框的联想词，并借助 ChatGPT 批量产出内容。下面是当前版本的核心能力。

插件大致能做到这三件事：

1. 一键抓取多平台搜索联想词：输入一个核心词，插件就能自动汇总小红书、抖音、B 站、知乎、百度、Google 的推荐词。告别手工复制粘贴，采集效率直接拉满！
2. 基于 ChatGPT 的文章批量生成与发布：输入主题关键词后，插件可自动调用 ChatGPT 生成多篇文稿，并一键推送到 WordPress 站点。网站内容更新变快，产出效率明显提升！
3. 提交 URL 后自动抓取网站文章并清洗发布：先配置好需要采集的标签，再提交采集地址，插件会自动打开页面抓取正文。结合清洗规则和 ChatGPT 重写，即可实现自动净化并发布。
