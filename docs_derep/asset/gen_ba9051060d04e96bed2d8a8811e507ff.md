# 一、业务要解决什么

从整体需求来看，这个报价智能体其实要做两件事：

1、客户把需求清单以 Excel 形式上传上来，智能体基于内部知识库检索后自动出价；

—生成一份初步报价单返回给客户，同时推送到飞书做人工二次核价

2、客户通过飞书表格链接获取最终确认价进行下载；（也可以直接新建客户记录表，查完后直接下文件）

本次演示用的测试清单只有一条数据，实际代码逻辑可以根据客户上传的列格式自行扩展。
