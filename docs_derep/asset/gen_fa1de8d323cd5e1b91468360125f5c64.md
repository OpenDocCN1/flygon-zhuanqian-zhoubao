# 生财布丁：一个想帮你“榨干”生财有术的AI小工具

说实话，生财有术真的是个宝藏社群，内容和人脉的质量都高得吓人。但问题也恰恰出在这——太多，啃不动。每年花上千块进来，如果只能看着一堆干货吃灰，那也太亏了。我总在想，得有个办法，把这里的每一分价值都吸收掉，而不是眼睁睁看着金矿却挖不出来。

我相信有这种困扰的不止我一个。所以，我做了个浏览器插件，叫“生财布丁”。

## 它是干嘛的？

简单来说，当你打开生财有术（scys.com）上任意一个“中标”或“风向标”帖子时，这个插件会自动识别页面，把内容抓取出来，交给AI做结构化分析。分析结果会以Markdown格式出现在侧边栏，表格、列表、分段都安排得明明白白，看起来非常舒服。

下载地址：chromewebstore.google.com

用起来也很省心：打开中标/风向标详情页，右边侧边栏自动弹出分析入口，多标签页之间随便切换，内容会自动刷新，完全不用你手动操作。它只在scys.com的特定页面生效，也不会收集或上传任何个人隐私信息。不管你做的是JTBD分析、用户需求洞察，还是竞品拆解、案例研究，它都能当一个趁手的分析助手。

## 我为什么要做这个东西？

先说工具侧的契机。那阵子Cursor升级到了0.49.6，感觉auto model一下子聪明了不少，我一直想找个真实的小项目试试水，看到底能帮我到什么程度。

再说内容侧。生财有术的核心资产就是内容，而且这些内容是经过人工筛选的——中标的风向标和精华帖，都是被验证过的“浓缩品”。其实圈友里已经有很多人分享过应该怎么用这些内容，但我觉得再好的方法，也绕不开两个根本问题：看懂和找对。

**第一，看不懂。** 术业有专攻，自己领域内的东西好办，可遇到其他行业的内容，往往只能听个大概。更尴尬的是，因为不知道自己不知道什么，连提问都问不出来。这时候我就特别希望有个“人”能把文章从底层逻辑讲到透，把隐藏的知识点都挖出来。

**第二，找不到。** 现在生财的检索方式基本靠关键字，但它没法理解我的真实问题，更别说判断我关心的本质需求了。我希望一个工具能读懂我的问题，然后帮我把相关内容找出来。如果能把内容联动起来就更好了——中标的帖子告诉你什么有机会（What），精华帖告诉你为什么有机会（Why）、怎么落地（How）。这如果靠人肉操作，太累了。

于是，这样一个工具，就顺理成章成了我的项目。

## 从想法到产品，我只留了最小的一步

当时我就给自己定了三个目标：

1. 方便我刷生财；
2. 产品足够小，两天之内能跑起来；
3. 能发布出去给别人用。

一开始我还想过做“文章总结+内容检索”，但那个工程量大，两天根本搞不定。而“文章总结”可能一个提示词套壳就搞定了。那就先做内容分析。

为什么先拿“中标的风向标”开刀？因为生财的精华内容千差万别，讲思维方式的、讲实操落地的，一套提示词根本对付不了。但风向标聚焦多了，每一条都对应一个商业机会，特别是“中标”的，已经被验证过，有供需、有方向性，完全可以标准化分析。

技术上，爬虫没法让每个人都跑一遍，浏览器插件就合适多了——直接在用户本地抓取页面内容，然后再交给服务端处理。

第一版的需求我砍得特别狠，最后只留了两条：

- 打开中标/风向标页面，能看到AI分析；
- 能不能向它提问？——算了，问什么不知道，怎么回答也不知道，砍掉。

## 这是我一个人的自嗨，还是大家的需求？

说实话，刚开始这就是为我自己做的。但我后来找到了几个信号：

- 生财有术迎新的新人贴阅读量巨大，说明大家都挺想“用好”内容的；
- 市面上大量付费商机社群，用户都是上千人起，说明这种需求很普遍；
- 我做的插件还要下载安装，门槛不低，但依然有很多群友来点赞评论。

还有群友主动提建议，希望增加自定义提示词、支持分析精华帖等等。这让我更加确定：它也许不是一个超级大的需求，但服务一小群人，是没问题的。
