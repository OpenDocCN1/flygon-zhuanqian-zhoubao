当一个话题下聚集了大量文案风格高度趋同的笔记时，平台基本会把这个话题池里的内容整体推给用户。反之，如果某个话题下相似的内容体量不足，系统就会跨话题去寻找关键词相近的笔记来进行补充分发。

### ② 图片相似度也在起作用
图片相似度也是一个隐形推荐维度。推测的抓取逻辑是：在短期内没有关键词重合的笔记可供派发时，系统会倾向于推送图文样式、视觉风格相近的内容。这个机制只作用于图文笔记。

所以创作者一定要先研究关键词池，搞清楚该词下已有的相似笔记长什么样，争取在系统第一次冷启动测试时就拿到不错的互动表现，进而更快地进入下一轮流量分发。同时，通过拆解这些相似笔记和对应博主，可以快速勾勒出目标用户的画像，帮助账号更快调整内容定位和生产策略。

# 七、决定内容能否爆发的三项核心指标

这三项指标，基本决定了你的笔记能否出圈，以及能火到什么程度。

分别是：点击率、互动率、搜索结果点击率。

## 1、点击率
推荐逻辑一般是先窄推后放量的。平台会先把笔记推给几百人左右的初始用户，比如500人上下，观察打开内容的比例，这个比例就是点击率。专业号的初始推量会比个人号少一些，通常在500到1000之间。

点击率靠前的笔记才会获得更大的推荐量。

小红书并没有开放曝光量数据，所以我们没法直接算出点击率。

## 2、互动率
当笔记被推到相对更大的群体，例如1万人时，假设点击率均值10%，互动率均值1%，那大约会有10个人产生互动。系统会根据这一组数据判断内容是否值得继续扩量。

点击率和互动率共同决定了内容是否会被更大规模投放。

## 3、搜索结果点击率
刚发布时点击率普遍不高，难以获得大量推荐，但一旦进入搜索结果页，就更容易被精准用户点开。如果被点击的概率很高，系统就会持续向精准人群推送，并在搜索结果里给予更好的排序。

这也能解释为什么有些笔记阅读量看起来还行，互动却极低；又为什么有些笔记前期没什么量，过段时间却突然被推成爆款。

建议反复研读，把小红书的流量推送机制吃透，对账号运营和爆款笔记创作都会更有掌控力。

# 八、常见问题解答

## 1、如何判断是否被限流
1. 连续三条笔记播放量都低于200
2. 专业号标识变灰
3. 账号等级长期不提升
4. 用其他账号搜索自己的账号名搜不到

## 2、被限流后可以怎么处理
1. 暂停更新两天，两天后再连发两条测试播放量能否回到200以上
2. 提交申诉，很多专业号异常其实是前期流量过大触发风控
3. 必要时注销重开

# 九、账号注册与起号
很多号注册后迟迟起不来，有一个实操方法。

原理是让营业厅为你补卡，补卡后号码编码被更新，小红书会识别为新号，从而绕过风控，新手机起号成功率会高很多，前提是内容原创度要足够。

1. 办理补卡
2. 告诉营业厅工作人员卡片丢失，需要补办
3. 携带身份证即可办理
4. 这样就不用注销原卡了

# 十、账号基础设置
养号三天后就可以开始完善账号信息。

## 基础信息完善
优先完成头像、昵称、简介的设置。头像要与账号定位一致，突出专业感，平台不允许过于花哨或不相关的头像，也不要用纯色背景，比如纯黑。

基础信息的完善能让用户快速理解账号定位。除了昵称，建议在简介里补充文字说明，帮助用户建立认知。
