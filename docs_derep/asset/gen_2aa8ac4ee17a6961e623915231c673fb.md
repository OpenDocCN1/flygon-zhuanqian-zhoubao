# AI 零代码航海第 2 天：我用扣子+飞书，把养生图文做成了批量流水线

大家好，我是李三疯（思耿），生财传术师。

这次参加了【AI 零代码自动化】主题航海。说实话，之前我也玩过扣子这类工具，但都是东抄一个工作流、西搬一个模板，没有正经系统学过，自己动手实操的次数少得可怜。这次航海正好逼着我从头到尾梳理了一遍知识，收获真的不一样。

教练的实操文档里有一套养生图文的扣子工作流，我照着跑完之后，脑子里突然冒出一个念头：这要是能和飞书多维表格搭在一起，效率不得起飞？于是我就动手把教练的工作流做了点微调，硬是拼出了一个新版本。

做完之后我在群里随手发了一下，结果不少小伙伴都来问我怎么做。我寻思着一两句也讲不清楚，干脆直接写篇帖子，把我的实操过程完整摊开给大家看。希望能帮到更多新手朋友，在航海里也能举一反三，玩出自己的花样。
