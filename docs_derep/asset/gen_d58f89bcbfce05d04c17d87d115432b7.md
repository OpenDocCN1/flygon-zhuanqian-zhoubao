# 从10元到1000元：我在SC的第418天，终于把副业跑通了

大家好，我是一名4月加入SC的圈友，主业在国企。眼看着行业走下坡路，家里的开支却一点没少，心里的焦虑越来越重。于是7月20日，我给自己定了一个小目标：做一个低成本副业——把散落的资料重新筛选、归类，整理成能搜索、能交付的知识库，放到闲鱼上试水。

为什么选闲鱼？说实话，它是我见过门槛最低的二手交易平台，对虚拟资料的包容度比小红书高不少。我本来就有闲置物品在闲鱼上出掉的经验，而且开通鱼小铺之后平台会给不少流量，新用户甚至有一个月的扶持期。小红书则是种草逻辑，要先养内容再转化，现在对虚拟资料也查得严。相比之下，闲鱼天然就是“有需求就来搜”的成交场，更适合拿来验证想法。

从第一单10元开始，一个月下来累计赚了1000元左右。这中间因为一个客户问“能不能下载到本地”，我还做了一单100元的定制知识库。收入不算多，但对我来说，这一个月让我第一次完整体验了“发现需求—做出产品—上架—成交—按反馈迭代”的闭环。这件事带给我的价值，远不止那1000元。

这篇复盘不讲虚的，也不灌鸡汤。我只想如实记录这一个月里我做了什么、哪些判断有效、哪些地方还很粗糙，以及下一步怎么把这个小项目继续做厚。

我现在做的产品是细分领域的知识库：把分散的资料重新挑选、分类、整理，变成可以直接搜索和使用的知识库，再通过闲鱼找到那些有明确搜索意图的买家。

目前的商业模式分三层：

- 第一层：低价标准版知识库，用来测试市场反应、积累第一批客户；
- 第二层：按资料范围和使用权限划分的升级版产品；
- 第三层：根据客户具体场景做定制，比如把资料做成可下载、可本地保存的版本。

这篇重点说的是，我怎样从闲鱼第一单10元起步，靠客户反馈，把“卖资料”慢慢做成“卖整理好的知识库和定制服务”。

最直接的原因是焦虑。虽然挂着国企的牌子，但主业已经明显在走下坡路，越来越像夕阳产业，身边不少人要么转行，要么失业。可家里的经济压力一点没小。

这种情况下，我越来越明白：如果收入全靠主业，一旦主业继续衰退，我的选择空间只会越来越小。所以一开始我并不是奔着“靠副业赚多少钱”去的。我最想验证的只有一件事：

除了工资，我能不能靠自己的本事，再创造一条收入来源？这才是这个项目真正的起点。

## 二、为什么偏偏选知识库

副业选项那么多，我最后锁定知识库，理由有三个。

第一，门槛不高。不用囤货，也不用砸启动资金。

第二，成本可控。就算项目没跑通，亏的也就是一点时间。

第三，最关键的是，我自己本来就有这个需求。我不是贸然闯进一个陌生领域，我平时就会接触资料整理、AI、知识库这些工具，工作中很多资料也放在知识库里。

但我没有因为“自己觉得有需求”就直接动手。我先做的是找对标账号。进了生财之后，我感受最深的就是“找对标”这三个字。我专门去看他们的销量和咨询量，更关注最近几周是不是还在持续出单。因为历史销量再高，只能说明过去有人买。真正有参考价值的是：

最近还有没有人愿意买。

## 三、我甚至花钱买了对标的产品

光在外面看没用，我直接掏钱把同行的产品买了回来。拆解之后我发现一个机会：对方卖的本质上还是资料包，只不过换了个平台摆放。

当时我脑子里冒出一个想法：

为什么不把这些资料重新整理，做成一个真正能检索、能调用的知识库？

于是我把资料全部打散重来，放到了更适合做知识库的腾讯ima上，重新分类、重新搭建结构。这时候，我和对标产品开始出现差异：对方在卖“资料”，而我在卖“整理好的知识库”。

看起来只是载体不同，但后来我才意识到，这一步非常关键。

## 四、第一单只有10元，我却激动得不行

一开始，我最担心的不是产品，而是流量。最大的疑问是：东西做出来了，到底会不会有人来问？

所以当第一个陌生人在闲鱼上主动咨询时，我特别兴奋。后来第一单成交了，10元。现在回头看，10元几乎不算什么。但当时感觉完全不一样。因为这10元证明了一件事：真的有人愿意掏出真金白银，为我整理出来的东西买单。

从“我猜这个项目能做”，到“真的有人买了”，中间隔着一段很长的距离。第一单就是那个分界线。后来有一天流量突然爆发，一下子来了好几单。那一刻我第一次有了种感觉：这件事好像成了。

## 五、真正让我改变的，不是10元，而是客户提的一个需求

如果一直卖低价资料，这个模式的想象空间其实很有限。真正改变我思路的，是一个客户。

他说，他希望资料能下载到本地电脑里。原来的产品并不是按这个需求设计的。但我没有直接说“做不了”，而是立刻按他的要求重新做了一个可下载的定制知识库。结果，对方愿意为这个需求额外付100元。这一单对我的触动，比之前很多小单加起来都大。

我突然明白：客户愿意多掏钱，不是因为在“资料量”上有多大差别。他真正愿意付费的，是方便、省时间，是能解决他自己的具体问题。

从那以后，我越来越重视后者。我不再只想“我手里有什么”，而是开始想“客户拿到这些东西，到底能解决什么问题”。这一个月里，这是我最重要的一次认知转变。

## 六、客户反馈，就是产品方向

一开始我也没有把产品设计得多复杂。后来出现的分级付费，其实是客户一点点“逼”出来的。

有的客户想下载到本地，有的客户只要其中一部分。需求不一样，我就开始做分级方案，让每个人按自己的需要选。

这让我越来越认可一句话：好产品不是自己关起门想出来的，而是在真实反馈里长出来的。尤其是当客户提出个性化需求、而且愿意付更高价格时，我更确信：高客单价的正确方向，不是单纯卖资料，而是做定制。

## 七、一次定制，也许能卖很多次

给那个客户做完定制之后，我又想到一件事：这套知识库既然已经花时间深度整理过了，那它不一定只能卖给这一个人。以后遇到类似需求，完全可以卖给第二个、第三个，甚至更多人。

这时候，我看项目的方式就不一样了。以前是“接一单，赚一单”，现在我开始觉得：第一次把时间花在深度整理上，后面可以靠重复销售来摊薄成本。

也就是说，我做的不只是一次性交付，而是在积累可以反复卖的数字资产。正因为这样，我现在觉得最值得放大的不是铺很多账号，而是把已经验证过的知识库做得更多、附加值更高。

## 八、客户真正想买的，不是“资料”

后来有个客户告诉我，他买知识库是为了投资。具体怎么用他没细说，我也没追问，那是人家隐私。

但这个反馈让我更加确定：很多人买知识库，根本不是想“收藏资料”。他们真正要的是两样东西：

- 第一，更快地获取信息。

- 第二，让这些信息帮自己更好地赚钱。

这也是我接下来做产品最想加强的点。如果知识库只是资料堆积，那价值很有限。如果能帮客户更快筛选出有用信息、更快形成判断、更快上手使用，那产品的附加值才能真正提高。

所以我后面想增加的，不只是资料数量，更是那些能帮客户提升竞争力的内容。

## 九、这套模式目前最大的瓶颈，也藏不住了

跑了一个月，问题也越来越明显。现在最耗时间的环节是手动上传资料。这个动作没什么技术含量，但它特别吃时间。

那我真正该把时间花在哪？我觉得就两个地方：

- 一个是继续找有需求的素材；

- 另一个是推广。

也就是说，我接下来要解决的不只是“怎么卖更多”，而是怎么把重复又低价值的动作自动化，把自己从琐事里解放出来，把精力放到选品、产品和流量上。

## 十、这一个月，我真正跑通的是什么

只看收入：第一单10元，一个月累计1000元。这数字确实很小，但如果只盯着1000元，反而会错过真正重要的东西。

这一个月，我完整走了一遍流程：

找对标账号 → 判断真实需求 → 低价购买产品 → 重新整理 → 做成知识库 → 闲鱼推广 → 获得咨询 → 成交 → 根据反馈升级 → 做分级付费 → 尝试个性化定制。

更重要的是，我生出了几个自己的判断：

- 第一，选品别只看总销量，要看最近几周是否还在持续出单。

- 第二，不要一开始就把产品做得很复杂，先让市场给你反馈。

- 第三，客户抱怨和提问的地方，往往就是产品的升级方向。

- 第四，比低价资料更值钱的，是帮客户省时间、解决具体问题的个性化产品。

- 第五，一次定制如果沉淀下来，就有机会变成能重复销售的数字资产。

## 十一、下一步，我不会急着做账号矩阵

刚开始我也会想：一个闲鱼账号一个月能赚1000元，那多开几个账号、多平台分发，收入不是更高吗？

理论上成立，但现在我觉得这不是最优先的事。因为目前真正需要放大的，不是账号数，而是产品本身。

我更想把已经验证过的知识库做深，提高附加值，抬高客单价，持续根据客户需求做出更多能重复卖的定制知识库。如果单个产品的价值还没挖透，就急着铺矩阵，最后可能是把一个不成熟的模式复制很多遍。所以我下一阶段的目标是：先把“1”做厚，再考虑把“1”复制成“10”。

## 最后

一个月，1000元。这个结果离“成功”还差得远。但它至少让我确认了一件事：副业这件事，不再只是“我想试试”。

我真的收到了钱，真的遇到了客户，真的被客户提了需求，也真的靠解决需求赚到了更高的收入。

从10元到1000元，数字不大，但它让我看到了一条可以继续往下走的路。

下一阶段，我更关心的已经不是“还能不能赚钱”，而是“能不能把这套方法做成产品化、标准化、自动化，然后慢慢放大”。对我来说，这才是这个月最大的收获。
