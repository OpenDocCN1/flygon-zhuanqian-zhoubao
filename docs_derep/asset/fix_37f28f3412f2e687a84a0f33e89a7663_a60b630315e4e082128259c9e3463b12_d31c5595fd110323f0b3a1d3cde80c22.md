# 一、获客：如何找到真正有需求的人

分销的第一步不是卖，而是先锁定对社群有真实兴趣的潜在人群。

这次我跑了三条线：

* 个人朋友圈私域激活
* 跨社群合作，通过干货分享吸粉
* 使用生财有术提供的体验卡做全网投放，并搭配付费渠道放大

下面拆解每条线的关键点与落地做法。

## 社群内引流

要点： 
* 目的要前置：让对方一开始就明白你的意图，避免沟通浪费。
* 案例要落地：不讲空泛的心法，而是讲一个可复制的赚钱案例，流程越简单越有说服力。

实操： 
* 我在其他社群里用了“心理咨询细分赛道中的抑郁症方向”作为示范案例，参与者能直观感受到分享的价值。

## 朋友圈唤醒引流

要点： 
* 价值要明示：把价格、赠品、优惠力度讲清楚，给出行动理由。
* 成长要展示：晒出自己在生财有术里的变化，让潜在用户产生共鸣，看到加入后的可能性。

## 三天体验卡引流：全渠道铺量+付费放大

要点： 
* 提报曝光：体验卡能提升品牌声量，触达更广的潜在人群。
* 付费助推：借助广告等付费手段扩大触达，提升转化概率。

实操： 
* 以体验卡为钩子做多渠道分发，配合付费推广，精准触达对生财有术感兴趣的用户，形成稳定流入。

# 二、成交：把意向变成成员

## 按人群做1对1转化

当用户进入沟通视野后，核心是把生财有术的差异化价值讲透，促成决策。我采用的是1对1转化模型，将潜在用户分为三类，为每类匹配专属的话术和推进节奏。

同时结合平台实力背书，以及我个人的实战案例，增强信任，最终推动成交。

有结果就要有报喜意识，多庆祝就能多成功。

# 三、跟进：让新人加入后有粘性又有变现力

我一直认为成交只是开始。

所有通过我加入的新伙伴，我都会邀请进我的专属陪伴群。群内会定期组织活动，邀请有结果的伙伴做内部分享，营造良好的学习氛围。

后来也有伙伴在群里复盘自己的变现成果，这是很强的正向反馈。

## 群活动：营造活跃氛围
