# 让ChatGPT帮你批量“造”小红书爆款内容方向：一套完整提示词工作流

今天聊聊怎么把ChatGPT训练成一个懂小红书、会写爆款内容方向的老手。我整理了一套很实用的提示词玩法，既能一步步“循环调教”，也能一次性打包交给AI处理。核心逻辑就一条：让AI先吃透小红书的用户心理、发文形式和爆文规律，然后再针对你的产品输出十个能打的软文方向。下面直接把方法放出来。

### 指令3：
请学习下面这些内容，并彻底理解小红书的发文形式、产品卖点的提炼方法，以及爆文背后的逻辑。

**六种常见发文形式：**

1. **单品种草**：只讲一个产品，要有真实使用痕迹。可以先说痛点、再说怎么遇到产品，最后写使用感受。卖点必须和痛点对得上。图片尽量真实，少堆广告词和功效词。

2. **横向测评**：把同类竞品放在一起，通过打分或排名对比，说清楚每个产品的优缺点、成分、价格、适用场景。

3. **产品合集**：围绕某个主题打包推荐，比如待产包、新年礼包、五一出行必备、双十一犒劳自己的礼物等。

4. **干货知识**：重点写体验感和知识分享，别带太重的营销味。要先搞清楚用户真实需求，再把他们的疑问写进文章，用自己的使用经历去解答。记住：找真实需求、放大痛点、找准切入口，和好主图、好文案同样重要。

5. **纵向生活**：从一个生活场景切入，比如浴室一角，描述整个洗漱护肤过程，把沐浴露、洗发水、身体乳、香皂等场景化产品带出来。可以用大牌带动自家品牌，类似“李嘉诚、马化腾、马云、王健林和我，这五个人的身价足以撼动整个亚洲”这种蹭流量的思路。

6. **教程方法**：把产品融入教程，比如用身体乳或磨砂膏教刷酸、美白，既有干货又有推广目的。

形式可以混搭，比如“干货知识+教程方法”“产品合集+纵向生活”，具体看用户痛点怎么铺。

**提炼卖点的三个层面：**

- **功效层面**：产品解决了什么问题，使用感受怎么样。
- **场景层面**：如果功效不明显，就从场景生活入手，用布置好看的场景烘托产品，但场景必须贴合产品且真实，别过度。
- **体验感层面**：强调真实感受——摸在手里的手感、看在眼里的质感、闻到的味道，用真实体验分享，文章更有说服力。

**另外两个关键点：**

- 找参考爆文时，别只盯着自家产品类目。比如晚上肚子饿，在夜市里宵夜零食和你不算对手，但在家里就可能算。产品会不会成为竞品，取决于场景。所以多想想产品适合哪些生活场景，从相同场景的其他类目里找爆文参考，网会更大。
- 内容可以借鉴同行，但绝不能抄袭。用得上的片段要改良、升级，让它为你所用，也避免搬运风险。

## 二、一次性提示词：把所有步骤打包

如果你不想分六步，可以一次性把所有要求写进一个大提示词里，让AI按步骤边思考边执行。大意如下：

我有一家小红书内容创作公司，你是我公司的员工。任务分为三步：

第一步，思考并分析小红书的用户画像。

第二步，深度剖析小红书主要用户的人性弱点、恐惧点、欲望点、需求点。

第三步，学习并理解以下内容：
- 六种发文形式：单品种草、横向测评、产品合集、干货知识、纵向生活、教程方法；可以混合使用。
- 提炼卖点的三个层面：功效层面、场景层面、体验感层面。
- 其他建议：寻找爆文模式时不要局限于自家类目；借鉴同行但不要抄袭。

记住：好的内容方向要触达精准用户，戳中爽点但看不出广告痕迹，无形中传递产品信息。

然后，分析下面这些高互动标题的风格、语气、模式，总结共性通法（把前面的示例标题放进去）。接着，按照标题生成标准（关键词突出卖点、用户视角、紧跟热点、使用emoji、内容共鸣）来学习。

最后，请为我的产品【产品介绍】生成十个爆火内容方向，要求不重复、有针对性、非常吸引人，并按模板输出。

## 三、拓展指令：不满意就继续调

如果你觉得AI产出的内容不够好，可以直接给它提改进意见。比如：

- “口语化程度不够，看起来像广告。”
- “内容方向不够吸引人。”

也可以改变输出形式，比如：

- “能不能生成故事性质的标题？但标题里不要提到产品，到文章最后再带出这款产品。”

如果某批方向很满意，想批量生产：

- “上面你输出的内容非常好！请再为我创作二十条。”

如果内容太多需要排序：

- “请将你上面为我生产的内容方向提炼出标题，并按互动潜力排序——越容易被点赞、收藏、评论的越靠前。”

这套工作流看起来很碎，但非常实用。核心不是让AI替你拍脑袋，而是先让它深度理解小红书生态和人性，再结合你的产品输出有根据的爆款方向。多跑几轮，你就能持续获得源源不断的内容灵感。
