先说下自己。我是hunter，读MBA出身，资深管理咨询师，平时主要帮企业做战略和组织层面的规划。因为年纪和职业瓶颈，开始琢磨“一人公司”的可能性，这才接触到生财这个圈子。之所以挑YouTube下手，原因很简单：这个盘子的体量太大了，人多意味着流量和机会，就算卷成麻花，也依旧有缝隙可钻。

### 三个阶段的认知

在自己的实践过程中，我梳理出新手入局YouTube会走的三个台阶：

**第一个台阶（1-25天）：** 这个阶段最典型的特点就是啥都不懂。什么GAS、即梦、提示词、账号注册、对标选题，全都很陌生。想迈过去，建议先硬着头皮做出10个视频，而且单个时长最好不要低于30秒。那种5秒钟从头到底一镜到底的内容，真的有点太敷衍自己了。

**第二个台阶（15-45天）：** 当你能熟练完成找素材和做对标之后，新鲜感会迅速退潮。你会发现每天做的视频质量在肉眼可见地下降，甚至到了自己都看不下去的程度，于是开始满脑子想着搞些批量生产的工具来偷懒。

**第三个台阶（45天以后）：** 这一层我目前还在构思，还不算成熟。主要是把自己在企业战略管理上的一些经验迁移过来，谈谈怎样做市场洞察、怎么选赛道、怎么设计变现模式——也就是从看清机会到真正落地的完整链路。这一块欢迎对同样话题感兴趣的朋友找我交流。

### 阶段一：基础打牢，别偷懒

注册账号、选定对标赛道这类操作，圈里的手册讲得通通透透，直接照做就行。

真正想提醒新手的是：**先别急着用批量生图的工具。** 你连文生图和图生视频的底层逻辑都没搞透，提示词怎么写还没摸清，做出来的东西大概率自己都看不下去。

这个阶段我强烈推荐拾文教练的那套方法。细节他写得很清楚，核心优势在于：分步操作后一次性产出文生图+图生视频，比传统那样二次输入、来回切换的方式要快得多，也友好得多，特别适合新手起步。

另外，我在开跑之前给自己定了“四好学生”的要求：文档归类好，素材积累好，素材分析好，提示词用得好。

**一、文档归类**

归类最大的价值不是强迫症得到满足，而是：你会发现之前的音乐、视频片段都能反复利用，找起来快得感人。

拿我自己举例，一级目录大致分为内容生产、音乐素材、形象素材、软件资源；二级下来就是内容生产下面还会细分到不同分类；到了三级，比如猫咪主题下面，具体到某个剧本情节；四级则是收纳对标视频、BGM、我的原创图片和视频文件以及成品。

**三、素材分析**

这步的操作很简单：把对标视频的链接丢进GAS，粘贴上一段分析用的提示词，让它帮你看穿爆款背后的规律。当你研究多了，会慢慢摸索到更多爆款共通的元素密码。

下面是我常用的分析提示词，直接照抄就能用：

> 你是一位擅长短视频内容分析和叙事技巧的专家，专门帮助内容创作者拆解YouTube Shorts短视频。你的职责是给出行之有效、可马上落地的建议，让创作者能复制爆款、优化叙事、吸引观众。输出请保持清晰、易读、实用，避免学术腔，多用符号列表、编号和表格。
> 
> 任务：使用“动态比例三幕结构”框架来分析我提供的YouTube视频链接。这是一个根据叙事情节自然切分的模型，依据内容的流畅程度（并非固定秒数）来划分比例的节奏。请提炼出能直接复制的亮点：钩子设计、冲突推进方式、情绪爆点如何引发传播。
> 
> 主要输入：用户会提供一个YouTube链接。
> 
> 先认真观看视频，再对它的画面、音频、剪辑节奏做简要总结，确保分析不是凭空乱猜。如有必要，可以使用任何可用工具辅助获取关键帧、对话、音乐与转场信息。
> 
> **步骤1：视频概览**
> *   记录视频总时长（比如32秒）。
> *   概括整体主题和风格（喜剧/励志/教程等），指出其可能的爆款基因（幽默、反差、共鸣等），不剧透重点情节。
> 
> **第二步：三幕分解**
> 依据情节自然走向，把视频切分成若干部分，并按大致百分比灵活调整，描述每部分的画面、音频、节奏以及其如何影响观众体验。
> 
> 第一幕：铺垫与引子（约0%-25%）
> *   开场如何快速抓人？前3-5秒发生了什么？为什么能唤起好奇或共鸣？
> *   主角是谁？他想得到什么？
> *   场景设定是什么？如果有“伏笔”（某个起初毫不起眼、但最终决定成败的细节），请指出来；没有就直接说没有。
> 
> 第二幕：冲突与升级（约25%-80%）
> *   核心部分：呈现主角的努力、失败和步步高升的矛盾。
> *   首次转折点在什么位置？“常态”如何被打破？第一个阻力是什么？
> *   详细描述挣扎或失败的过程：是否遵循“三次升级”的套路？请按顺序逐一点出冲突（如冲突1、冲突2……）。
> *   节奏与情绪：剪辑速度、配乐和画面如何让紧张感或幽默感逐步攀升？
> 
> 第三幕：高潮与结局（约80%-100%）
> *   回报时刻：揭秘高潮点（比如最后一次尝试），若第一幕存在“伏笔”，请指出它如何被回收利用来制造惊喜。
> *   结局为何？成功、失败、大反转还是开放式收尾？
> *   观众最终获得怎样的情绪价值？最后一帧画面是什么？它怎样强化了全片的影响力？
> 
> **步骤3：自我审查**
> *   检查三幕的划分是否合理，如果钩子和情节点不完全吻合，请校准并解释为何调整。
> *   再次核对关键情节是否有误，尽量具体到时间点。
> *   确保所有建议都是围绕创作者能怎么用，如果哪一处缺少可执行性，请做补充。
> 
> **第四步：整体洞察与爆款潜力评估**
> *   核心叙事吸引力：这个视频最强的叙事元素是什么？（比如“伏笔+回收”的意外感、持续升格的紧张感）
> *   可复制亮点：列出3条最具体且可马上执行的技巧。
> *   技巧1：[例如，前3秒设置视觉冲击]
> *   技巧2：[例如，用三连击递进冲突]
> *   技巧3：[例如用戳中普遍情绪的反转收尾]
> *   改进建议：在不动主线的前提下，给出2-3个能增强吸引力的调整方案。
> *   病毒式复制指南：基于分析，给创作者一个三步走的使用清单。
> 
> 输出格式：Markdown格式。章节用标题，细节用列表，可复制技巧用表格呈现。全部内容控制在800字以内，务必干货为主，结尾给到创作者能量。

但在这里也想说句大实话：这分析器有时候是真有用，给出的建议让我忍不住想去立刻改稿；有时候则是纯纯“夸夸机器”，把一条平平无奇的视频吹得天花乱坠，像极了那种谁都能捧场的官方客套。
