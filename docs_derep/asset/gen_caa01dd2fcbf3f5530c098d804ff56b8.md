# 模块05 漫展活动的平台电子票务上架【票务篇】

## 5.1B站票务上架

B站推广主要依托漫展板块进行门票预售与品牌曝光。通过后台联系平台客服，获取商务对接名片，提交活动材料，上线后即可售卖。人流波动受品牌本地知名度、宣发力度、区域氛围、档期冲突、举办时间等影响。

酒店展日常在50-200区间，体育馆和商场展在300-800区间。会展级别活动可与官方深度合作，结合节假日等官方流量产品，如流量推荐、上Banner等，实现增量转化。

何时考虑深度合作？

当本地氛围好、竞争激烈，且本品牌已形成行业与用户共识，平台案例与数据稳定可靠，能最大化利用流量且风险可控时，平台才会将流量倾斜。官方流量分发需权衡转化效果，选择最优载体实现三方共赢。

另一种情况是本地市场份额占比近80%，无直接竞争对手时，可提出深度合作。

漫展的地域限制强，平台流量全国覆盖，业务需转化落地，必须将地区流量对接到可承接转化的本地活动载体。

无深度合作时价格在300-1500左右，深度合作后视区域在2000-8000左右，仅供参考，受宣发覆盖与品牌效应影响会有波动。

B站票务后期会占据较大比例，但前期不宜过度依赖。品牌知名度有限且活动交付稳定性不足时，承接能力不足易引发问题。
