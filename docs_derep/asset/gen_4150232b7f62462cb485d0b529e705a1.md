# 夜校到底是什么东西

夜校先起于上海，本质是Z府牵头的半公益兴趣培训，12节课收500块，核心卖点是便宜到离谱。打的是下班后给年轻人一个去处，丰富业余生活顺带学点技能。因为面向全城开放，票一开就跟抢高铁票一样秒空，多次冲上热搜。热度起来后北京也跟进。

北京的做法不一样。不是官方办，是民间玩家在小红书上借夜校这个话题吸粉，再把市面上现有的兴趣机构资源打包整合。说白了就是空手套白狼做中介撮合。

有流量了就去跟商家谈折扣，最后收差价，用户照常去上课。

# 夜校前期怎么赚钱

头三个月基本就是纯中介。赚差价加机构返佣。据我了解北京那边500元课抽20%，正价课抽10%。

等信任沉淀下来，私域盘子起来了，就可以做俱乐部、搞线下活动。再往后可以围绕女性用户做好物团购、旅游团。甚至能嫁接同城相亲、同城医美，变现上限最终看你自己的商业盘感。

## 交付不用自己操心

万物皆为我用。最难的是前10家机构，因为没案例。我是直接在美团大众点评上搜商家，用电话谈。核心是给商家确定性，人都吃这套。我自己的电话话术是这样的：

“你好，老板是xx机构吗？我这边是本地一家青年俱乐部，线上注册会员2000+，分布各县区。现在有十多个女生想学xxx，想问下你们有没有团课或小班。我们每月都有十多个人持续咨询，不是单次需求。”

老板一般会问怎么合作，是派老师还是我们到店。我统一回复“不需要老师过去，我们直接到店，你们团课一节多少钱”。报完价心里就有底，再甩出我们底牌500元12节课，空间靠临场谈。

# 我的四个加分动作

## 第一，先做问卷画像

进群后先让他们填问卷。90%是女性白领，薪资60%集中在4-7k，分布区域、想学的课程全摸清了，后续拓展才有方向。需要问卷的找我拿链接。

## 第二，做裂变

课程发之前是用户信任和期待最高点。群公告直接写拉5人减免多少、拉10人减免多少。时间充裕还能做裂变海报让用户转朋友圈扩大声量。做不做不影响大局，但做了是锦上添花。

## 第三，先收预收款
[PRE11]

课程一发，有人抢有人看。利用发售小高潮推预收款，先交20元定金可抵50元，还能优先抢名额并第一时间知道新课。制造稀缺感。

## 第四，用快团团收款

现在正在用。快团团能在大群里直接展示机构介绍、照片视频，转化效率高，用户点链接就能付，不用再分小群一对一转账。

# 我踩过的坑

预期没管理好。

很多人冲着官方夜校、免费学习的预期进群，看到是个中介会产生落差。人性阴暗面会觉得你把人骗进来卖给机构。所以必须在进群瞬间就把身份说清。

群公告要写清楚：我们不是企业机构，不是政府组织，也不是慈善机构。我们是一个青年俱乐部，集中大家的力量给商家砍价，拿到极致性价比课程，丰富业余生活。一定要让用户感觉我们和她是同一战线。

# 适合什么人做

适合轻创业、没那么大野心的男生，更适合活泼社牛的女生。一个月轻松赚两三万是可能的。

需要的能力：组织协调、控场、随机应变，还有服务心态。能不能打开自己、能不能热情链接陌生人，这点很重要。

# 夜校真的是好生意吗

判断好生意的维度：流量稳定、客单价高、毛利高、转化效率高、可复购。

夜校现在流量大但转化路径效率一般，客单价500块，商家分走一半后最多到手250，和北京20%10%佣金类似。复购也低，上完一个月想继续报全程班或私教时才有返利空间10%-30%。

夜校造血能力弱，得嫁接同城相亲、医美、线下俱乐部活动变现。单靠夜校天花板很低，我认为运营再强一个月也就5万利润，除非绑定其他项目。

变现取决于两点：流量大小和转化率。转化率取决于你手里有几个同城商家，商家池够大撮合才顺。

大胆预测，夜校最后会变成线下社交俱乐部，变现靠活动。算一下：周搞7场活动，场均8人，人均收150，成本50，净赚100/人，单场800，一周5600，一月22400。但边际成本和交付成本很高。

# 劝退

不适合想赚大钱的人，不适合有野心的大老板，不适合今天想变现的人，不适合只想利己没服务意识的人。变现天花板真的有限，就是有限。
