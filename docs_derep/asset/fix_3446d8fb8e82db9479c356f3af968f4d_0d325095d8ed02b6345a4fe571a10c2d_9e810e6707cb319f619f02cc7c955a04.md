# 可深度挖掘的 AI 绘画资源合集

> 溯源：[`www.yuque.com/for_lazy/thfiu8/knpet848c7370wur`](https://www.yuque.com/for_lazy/thfiu8/knpet848c7370wur)

发布者：教書将
发布时间：2023-03-22

整理了十个可供反复探索的 AI 绘画相关入口，有的偏向检索灵感，有的偏向生成提示词，有的更适配中文使用习惯。按需挑选几项体验，很可能打开新的创作思路。

1、OpenArt.ai
兼具检索与展示能力的聚合库。输入关键词即可横向对比不同模型下的呈现方式。据平台自述，收录量已超千万级，涵盖 DALL·E2、Midjourney、Stable Diffusion 等主流引擎的作品，每条条目均附带对应的提示词参数。

2、arthub.ai
相当于一座由艺术家与设计师共建的 AI 作品馆。整体配有详尽的文字说明，检索方式支持关键词直达，同时提供按类型分类的浏览入口。看到满意的案例，可直接借鉴其描述去复现风格。

3、promptomania.com
在线的提示词组装工具。内置多套模板，可适配 Midjourney、Stable Diffusion、DreamStudio 等方案。选择目标引擎后，系统会引导填写色彩基调、艺术流派、参考创作者、构图比例等要素，最后输出一段可直接使用的完整 Prompt。

4、lexica.art
以 Stable Diffusion 为主的案例库，积累了数百万组图文对照。操作门槛很低：只需在搜索框填入简短关键词，或上传一张参考图，即可获得风格迥异的结果。点开任意图片即可查看其背后完整的描述文本，一键复制即可带走。

5、MidJourney prompt Helper
聚焦 Midjourney 的轻量写作助手。当描述思路受阻时，可先生成一段可迭代的草案，再自行润色。

6、KREA.ai
汇聚了数百万张 Stable Diffusion 生成样本，支持关键词筛查。平台还提供点赞、收藏、分组归类等个人管理功能，便于后期回顾喜爱作品；项目目前已开源。

7、AI 画廊 aigallery.top/tool
对中文用户更友好。内部 Prompt 仓库覆盖面广，同时集成面向 Midjourney、Novel、Stable 的生成器，基本能一站式得到可用参数。

8、weirdwonderfulai.art
基于 Disco Diffusion 整理的艺术家风格研究集合。想验证某个创作者署名会带来怎样的视觉特征，可在此处对照查看。

9、
界面偏向中文阅读习惯，首页展示以女性头像为主。

10、词图
擅长中文提示词的工具，交互体验流畅。
