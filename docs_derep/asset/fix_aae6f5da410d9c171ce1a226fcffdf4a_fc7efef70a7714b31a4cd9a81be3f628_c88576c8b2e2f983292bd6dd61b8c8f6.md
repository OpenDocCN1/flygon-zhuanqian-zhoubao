核心战绩：

*   变现节奏： 产品上线第一个月收入就突破 1000 美元。
*   用户累积： 70 天内纯小红书冷启动，零投放拿到 10,500+ 真实用户。

5.  商业化设计： 定价背后的思考。

## 3.2 机会是怎么被发现的

谁没跨平台买过东西？我家旁边就是菜鸟驿站，每次包裹到就发取件码短信。取件时要么打开淘宝、京东、抖音等各家 APP 一层层翻，要么打开短信在广告里找码。快递一多就抓狂，各家发码方式还不一样。丰巢还会推公众号消息。每次都要回想买了啥、在哪买的，再进对应 APP 看广告。

用户路径：

1、人站在驿站 -> 回忆购买清单 -> 判断平台 -> 打开 APP -> 看开屏广告 -> 层层点击找码

2、人站在驿站 -> 打开短信 -> 在密密麻麻列表中检索 -> 点开 -> 查看码

一件小事，路径却非常绕，还要给各家 APP 贡献日活、看广告。

我当时的想法就是有没有一次性解决的工具。晚上刷小红书，算法给我推了 iOS 取件码快捷指令。一看，正中痛点，立刻试。

结果并不理想。按教程配了半小时，十几页步骤，还要学习正则去适配我家快递的短信格式，还要频繁切换手机，看起来就烦。试了几次失败就放弃了，谁愿意折腾。

但这类型笔记点赞收藏动辄几千，说明需求很强烈。

这次经历让我抓住两点：

1.  需求真实且旺盛： 快捷指令相关内容热度很高。
2.  现有方案门槛太高： 配置复杂劝退大部分懒人。

想法自然清晰：既然大家都在费劲解决，不如做一个开箱即用的 APP。

再往前想一点，我也是懒人，如果有一个不用配置就能用的方案，是不是会被抢着用？于是赶紧动手，别让别人抢先。

调研后发现并非首创。去年已有同类在做，小红书运营半年，数据尚可，我一度凉了一半。

但我继续下架体验，市场上就三家：取件了吗、取件助手、ezicode。体验完又燃起来了，因为体验都一般。UI 简陋、交互不规范、信息架构混乱。唯一能看的是取件了吗，小红书在持续更新，用户也明显领先另外两家，就把它当主要对标。

需求挖掘路径：跨平台取件 -> 嫌麻烦 -> 算法推快捷指令 -> 半小时配置失败 -> 产生想法 -> 调研产品 -> 心凉 -> 分析对手 -> 仍有机会

tips: 有感觉的好点子先放一放做调研。若市场没人做，可能说明没人要；若有人做且数据不错，就要细盯他们做差的地方。

## 3.5 市场调研：从心凉到看到机会

调研时我问了自己三个问题：

问题 1：菜鸟裹裹都存在了，为何这类产品还有空间？
问题 2：用户不用菜鸟裹裹，为何愿意折腾快捷指令？
问题 3：市场规模多大？

问题 1：

我之前根本没装菜鸟裹裹，靠 APP 和短信取码。我家附近只有一个驿站，所以没意识到问题。但用户评论让我发现信息差。很多人家附近不止一个驿站，可能有菜鸟、驿收发、妈妈驿站等，菜鸟兜不住全部。

[PRE4]

原因拆解：

1、菜鸟广告多，用户反感。
2、多个驿站无法统一查看。
3、菜鸟也显示不了全部平台的取件码。

所以对一部分人不是痛点，对另一部分人就是刚需。

问题 2：

核心是菜鸟没真正解决这批人的痛点。想看码仍要打开 APP 看广告。路径不够极致。能直接在锁屏、组件、灵动岛展示才够快。

再加上小红书用户天然追求效率与体验，这类工具转化快。

问题 3：

规模 = 全国驿站数量 × 覆盖人群。

[PRE5]

除了菜鸟，还有大量其他品牌驿站，分散竞争。哪怕只做菜鸟之外的用户，对新手来说也足够。最初目标只是赚 1000 块。

市场足够大，各家通知方式各异，如兔喜用小程序、丰巢用服务号。

## 3.5 对手分析

从产品与流量两层看。亦仁说过，先做流量，流量做不起来产品不必做。

#### 3.6.1 产品层

翻对手小红书评论与自己实测，发现作者多为素人，产品硬伤明显。

（竞品APP 首页）

主要短板：

*   UI 审美不足，但用户居然主动帮忙优化，还获千赞。
[PRE7]

（用户帮他的优化的 UI 稿）
*   信息架构不清晰

*   细节打磨不够
*   不兼容 iOS 17 以下
*   短信识别准确率不佳
*   无安卓版本

这些短板正是切入点。

#### 3.6.2 流量层

三个思考：

1、需求用户已被收割完毕吗？
2、有增量，我能超过他吗？
3、能把他的存量用户拉过来吗？

问题 1：

观察“取件码快捷指令”视频，发现近期仍有持续出万赞内容，说明仍有用户未被触达。原因可能是笔记曝光有限，也可能是新 iPhone 用户进入。

对手近一个月笔记也在快速涨粉，说明仍在增长。

结论：用户远未被收割完，仍有增量。

问题 2：

对手流量起盘很素人，没参与过生财小红书航海，账号搭建混乱，关注意愿低。但数据依然强悍，说明需求强烈。

账号问题：

*   头像与产品无关
*   简介没说明身份与产品价值
*   正文封面随意、色彩混乱
*   只有图文无视频

因此做到 70 分即可反超。UI 不需设计师水准，封面与视频做出辨识度即可。

结论：流量上可超。

问题 3：

看迁移成本。

*   UI 是否更精致
*   信息架构是否更清晰
*   交互是否更直觉
*   功能短期可能不及，但可先卖空气
*   核心是 新体验 - 旧体验 > 迁移成本

俞军公式：新体验 - 旧体验 > 迁移成本

功能差异化难，后续从定价做差异化。

结论：对手运营水平不高，用基础小红书方法就能反超。

### 3.7 打法：暗影复刻

盘完后觉得可做。小排老师的暗影复刻：复刻头部 20% 核心功能，找到头部未覆盖的人群与场景去解决。我就是这么做的。

# 四、增长与运营：冷启动到闭环

亦仁说得对，先试流量。

5 月初上架 App Store，未推广，一周下载个位数，多是朋友。每天刷 Connect 失望。后来决定在小红书发。

第一篇很随意，一天阅读破万，评论区一堆问下载方式。也有人说这不就是菜鸟吗？有人说伪需求。互动把笔记推上去了，第一天拿下约 1000 下载，成为种子用户。

tips:

1、2025 年了，酒香也得自己吆喝，独立开发必须会推广。
2、第一篇没技巧，需求强算法会自己匹配用户。

# 五、社群构建与正循环

用户尝试后，及时引导进小红书群。高频互动，解答问题，汇报 BUG 进度。用户会觉得是活人、是身边人。信任感建立后，Pro 上线当天就有 60 人订阅。Pro 只多一个灵动岛功能，但信任让大家愿意付。

*   用户沉淀： 引导至小红书群
*   积极互动： 高频交流、解答、进度汇报
