# 大三两年拿到三十万流水，我的线上实操复盘

大家好，我是行一，2002年出生，目前在读大三。接触线上变现大概两年半，首个六位数营收已经实现，正往下一阶段冲。今天把这段经历整理出来，一是感谢在路上提携过我的前辈和贵人，二是给还在探路的同龄人一点可参考的思路。翻到很久以前的QQ空间记录时，情绪还是有点波动。

起步阶段很拉胯。高中进了实验班，三年用力过猛，最后高考成绩滑到班级尾部。曾经还能排前排的我，第一次感受到了巨大的落差。上大学后彻底摆烂，整天沉迷游戏，《原神》肝到前列，常年后排上课玩游戏，逃课翻墙出校玩乐，被保安追过。暑假回家，亲戚一句“年纪不小了还在家里玩游戏”，直接点燃了赚钱的念头，也想兑现当年跟父母说过成年后能自给自足的承诺。

开始找资料了解怎么赚钱，怎么创业，越查信息越焦虑。转机是看到狗哥2021年初那篇普通人千万级营收的自述，被深深触动。狗哥和我是老乡，表达很实在。顺着线索我找到了生财有术，并加入了帅张的星球。第一次付费加入社群，当晚心疼到失眠，回头看，这笔钱花在认知升级上最值。

刚进圈时跟大多数新手一样，疯狂吸收内容，大脑装满却不会落地。真正让我动手的是@拱卒。在他的组织里，我认识了同龄的@张梦才，跟着学习快手小游戏的操作；也认识了@金成，我第一条抖音刚发就被封，他告诉我自己做了三个月抖音零收入还亏了豆荚，告诉我坚持下去总会有回报。那段时间我用搬运号测试，在结尾做引导，拿到了第一笔线上收入，约一万。心里清楚这对原创不厚道，但搬运确实来钱快。后来按师傅建议转向原创，要求自己每日更新，一个月后快手上的原创游戏素材意外破了百万播放。先抄同行拿正反馈，再慢慢加入自己的理解，这是我一直坚持的节奏。

早期也踩过坑。和学长一起做校园跑腿小程序，我负责新媒体，第一次写完整的运营方案，坚持了一个月后因和小程序表白墙冲突被恶意竞争，团队宣告解散。那次让我明白：先找一个能稳定回血的核心业务再拓展，别上来就铺多个部门。项目要先用最低成本最短周期跑通，验证后再加码，否则九成会亏。

知乎好物我做了约四个月，618期间赚了几千。第一个月几乎没有反馈，心态反复崩溃，后来被导师骂醒才开始每周稳定输出。洗稿到自我表达的过程让我明白，执行力和心态是可以训练的。先复制再超越，能用在几乎所有赛道上。

快手小游戏从每天剪一条到用模板十分钟一条，再到多设备批量生产，收益才起来。但国家推实名后，这条路迅速收窄。转做棋牌和手游依然是跟着同行走。宿舍配音是段尴尬记忆，唯一不变的是尴尬的就是听的人。抖音号再次被封，导师帮我调节情绪。团购做到四千粉时赶上封寝，只能放弃。我给项目做了周期管理：验证期、红利期、稳定期、衰退期，并提前建护城河。行动-反馈-优化-沉淀-爆发，循环走。新方向至少给自己一个月的基础周期，政策敏感类除外。

蓝海书单我定了21天目标，第17天就拿下首单。做法很简单：找头部账号拆解，一周内模仿，见效就放大，不行就换对象继续抄。批量后需要自己的视频和文案模板，前提是把专注力提上来。把干扰源列出来，切断信息洪流，专注一件事，执行力自然上来。

电商方向我小范围试了闲鱼，开通Pro后体会到动销率逻辑：成交越多权重越高，自然流量就多。未来想探索无货源或蓝海有货源，比如绿植、宠物用品。相比短视频的脉冲式收益，电商更符合我对长期稳定业务的预期。

最夸张的风口是视频号无人直播。那段时间基本躺赚，首场直播GMV就破万。

靠搬运爆款素材养号，开播后在线人数很快破万，单日GMV一度冲到五万。风口结束后平台监管收紧，同行内卷严重，硬扛只会消耗自己，我选择停手转战私域。回头看那波更多是运气，但运气来时手里要有打法才能接住。

现在的主战场是小红书。很多人只认得做小红书的行一，其实前面所有的尝试都是积累。我花了半年研究引流，整理了一份超过五万字的引流拆解文档，主攻教育私域，做高中提分、学习方法内容，后续会往考研方向延伸。团队也试了小红书电商，得益于一个朋友给的案例拆解，起量很快，现在属于头部梯队。

[PRE2]

另外，我在带一个近千人的公益实践项目，帮新人实现从零到一的闭环，做利他也做自己的复利。

[PRE3]

两年下来，我最确定的结论是：所有项目都能拆成流量-产品-转化。知乎靠搜索加投放，核心是内容模板和持续输出；抖音快手靠剪辑和模仿，但没有变现的流量不值得做。视频号的爆发期，选品和人性洞察是关键，爆款大多打的是贪小便宜、好奇和白嫖心理。直播的本质是人货场搭建，复制同行直播间是最低成本的学习法。

当下我更偏向长期主义。视频号还在，但上课期间很难深度运营，先搁置。下一步是深耕私域，聚焦小红书引流到微信沉淀，因为私域资产是自己的。流量可以买，产品可以合作，转化可以靠运营加码，但根本还是流量。跟几位千万级前辈交流后，这个认知更坚定了。

如果要总结成绩，大概三点：一是借助视频号风口拿到第一个六位数，小红书电商两个月利润稳定在八万以上；二是做过百万播放的游戏素材，单日GMV过五万的直播战绩；三是真正沉淀了一套可复用的项目方法论和SOP，第三点才是最值钱的。

给还在起步的新人一句话：别等风，先把自己磨成能接住风的形态。行动、复盘、优化、沉淀、爆发，把这套循环跑顺，你的风口会来。
