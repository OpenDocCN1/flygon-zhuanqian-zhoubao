# 我做朋友圈半年踩过的坑，避坑就这三条

原创作者只是做个参考，我是卿久，97 年中文系出身，操盘过 慕卿久、未来可期的小赵 两个公众号，全职做自媒体三年多，粉丝总量 18w+。公众号运营、个人 IP 打造、私域搭建和付费产品转化是我常做的事，自媒体变现累计 60w+，现在稳定月入 4w+。

朋友圈内容有了规划并坚持输出一段时间后，记得每隔 10-15 天做一次复盘。现在把我运营大半年以来踩过的坑整理出来，供大家参考。

**第一个坑：太自嗨，只讲自己。**

发圈不是个人展示台。

有时候更需要去看见别人、感谢别人、惦念别人。人脉里高情商的运营方式很重要。

蔡康永说过，你话说得好，别人就更开心，别人开心了更喜欢你，喜欢你的人越多，能给你的资源就越多，你也会更开心。

朋友圈同理。你越懂得在圈子里褒奖他人，读者就会感受到你的格局和温柔，觉得你是一个懂得感恩、尊重别人价值的人，自然也会尊重你的价值，并主动靠近你。

所以每周的内容里，至少安排 3-4 条去赞美学员、牵挂朋友、感谢老师的动态。

有人会问我没写过这种，会不会很生硬？怎么插进去？

举个例子。说感谢读者来信，就不要笼统带过，最好能征得对方同意后，点名道姓地公开致谢。

我意识到这个问题后，后续发圈都会更注意这一点。

比如下个月合伙人专属海报制作过程中，有两位朋友帮忙设计、整理资料，我便在前几篇动态里专门提到她们的名字，感谢她们的付出。

后来刷到合伙人的朋友圈，她们转发我的内容时，我也会在评论里完整写出每个小伙伴的笔名，给到具体肯定和赋能。

刻意留意后会发现，生活和工作里赞美他人的素材其实很多。

多夸夸自己的讲师，多夸夸自己的学员，多谢谢圈子里帮过你的朋友。这是一种向上链接、破圈的方式。

讲师被你公开认可，很可能在自己的朋友圈里 @ 你，讲师的流量池是很大的，这就等于免费给你背书和导流。用心夸学员，她们能感受到你的真诚，会更投入学习，做出成绩后还会帮你介绍新人。

**第二个坑：只记录当下，没做对比。**

很多人的朋友圈都是流水账：今天学了什么、今天吃了什么、今天发了条视频。几乎都是当下发生的，没有时间纵深感。

我建议多去回溯过去，做出前后对比。特别是做自媒体的，可以写写入局前后在能力、收入、圈层上的变化。

把曾经和现在的自己并置展示，读者才能更立体地了解你，也更容易记住你。看到你从青涩到成长，会产生向往和追随的冲动。

成长的本质就是从弱到强、从依赖到独立，用文字写出来，能让有相似经历的人瞬间代入，产生强共鸣。

拿我自己来说，以前就是个普通的电商文案打工人，天天被老板 PUA。转正时工资和面试时对不上，强制加班不给加班费，职场里的不公比比皆是。

现在呢，时间完全自主，接个广告贴一下，几分钟几千块到账，心情很爽。就是这种落差感，通过朋友圈就能很好地传递出来。

像上面这种只有当下信息的文案就比较单薄，读者能拿到的信息量很有限。

如果要优化，就要加上前后对比，形成反差。

哪怕进步很小，也要及时记录并展示出来，长期积累下来就能塑造出一种养成系的人设。

另外别有心理负担，担心晒变化会被说。真正认可你的人会欣赏你，懂得欣赏的人会跟随你。畏手畏脚，永远做不大。

**第三个坑：想发却一直拖。**

以前的我经常这样：灵感来了，素材也整理好了，结果忙别的事就忘了。等想起来，要么素材过期了，要么兴致全没了，觉得写得不好、案例不够好，就干脆不发了。

如果你也有这个问题，记住一定要即时表达。

写文章也一样，一停笔就很难找回当时的状态，第二天再写，激情大幅下降。发圈也同样。

我现在已经改掉了这个习惯。错过发圈时间，不仅打击自己的创作热情，还浪费了曝光和链接的机会。

所以学员报喜了当场写，突然有感悟了立刻发，哪怕晚点睡也别拖到明天。

以上三点，是我运营朋友圈大半年最深刻的教训，希望能帮到正在做私域和个人 IP 的你。越少踩坑，变现越快。
