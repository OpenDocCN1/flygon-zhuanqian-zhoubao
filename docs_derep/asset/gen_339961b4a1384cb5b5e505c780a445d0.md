说实话，Midjourney那套我实在吃不消，一个月30美金不说，一封号就是起码挂7天，成本和风险加在一起太高了。

权衡下来我就把主战场换到了免费的Stable Diffusion上，想靠它来做海量图的生产。但本地机器扛不住，只能上云。

最后落脚在 runware 上，搭 Flux dev 模型用，一张图只要 0.002 美元，目前我试过的里面性价比是最高的。

这里头牵扯的细节还不少。我的原始文案都是中文，但SD模型基本只认英文，所以第一步先用 GPT mini 把中文转成英文。

另外一张图的呈现时长有限，对应的文字量就不能贪多，反复测试之后，我的工作流现在是比较稳的：中文一次投喂 115 字为一组，翻译成英文后控制在 55 个单词左右一组，这个比例出图效率和可读性最好。

模式其实不止一种，我之前也试过做基督风格、纯英文版、西班牙语版，以及恐怖故事版等等，都是在这个框架下换皮。

整体流程就是按字数切片 → 翻译成英文 → 丢图生成 → 拿结果返回。标点怎么断、段落怎么合并，这些逻辑我都已经调到很顺手了，直接换个 API key 就能跑。
