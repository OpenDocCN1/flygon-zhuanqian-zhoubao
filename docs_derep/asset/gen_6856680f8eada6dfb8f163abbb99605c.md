高考卖花这个事儿，之前刷小红书也有刷到过，但说实话，那时候也就脑子里闪了一下念头，压根没觉得这事儿跟我有啥关系。思维方式还停留在“想想而已”那一步，压根没想过真去干一把。

[PRE0]

后来在社群里看到有姐妹聊起高考卖花这件事，才猛地惊觉——卧槽，高考真到了。你不得不承认，混在一个高能量的圈子里，信息差和思维认知是完全不一样的，别人能想到的事，你连门都摸不着。那一刻还真有点被推着走的感觉。

周五，也就是高考第一天，我还得搬砖打工，但脑子里那个念头已经刹不住了，午休时间直接开干，跑去知识星球和小红书狂翻攻略。还真被我翻到一篇干货，艾小飞老师的《如何利用高考2天摆摊卖花赚波快钱》，写得那叫一个详尽，处处都是实操细节，简直像给我量身定做的。那篇飞书文档我连读了好几遍，然后结合自己的情况，真的去摆了摊，也真赚到钱了。虽然不是什么大钱，但那种“学到就能赚到”的爽感，确实值得记录一下。

这里要特别感谢艾小飞老师的无私分享，我这篇文章是在他授权之后，从他飞书文档里提炼出来的，其中紫色标注的部分是他本人的观点，其余是我自己实践后的一些思考和补充。

# 1、为什么会想到去卖花？

十二年寒窗，说白了就为了这场考试。考场里面紧张的是学生，考场外面更焦虑的其实是家长。他们在外面干等两个多小时，这种情绪总得找个出口释放一下——给孩子送束花，既是一份祝福，也是一种“我陪着你”的心意。

花，就是这种情绪最好的载体。孩子出考场，看到爸妈拿着花在等自己，旁边还有一张祝福贺卡，紧张感瞬间能卸掉一半。顺手拍个照发朋友圈，也算是对这段青春岁月的一个纪念。毕竟高考一辈子就一次，能给的仪式感必须拉满。

这就是需求，有需求就有市场，有市场就会有竞争，这事儿就这么简单。

[PRE1]

我自己的补充理解：
1. 本质上，这是一次情绪消费。谁抓住家长心里的那个“梗”，谁就能赚到这笔钱。
2. 我自己也参加过高考，特别能懂那种紧张和期待交织的感觉。所以面对家长的时候，我是真的能共鸣，不是说套话。
3. 对考生来说，一束花能带来的心理暗示作用真的蛮强的，能让他们放松一点，也许就能多得两分。
4. 考场门口确实有超级多家长，但总有那种没提前准备、看到别人家孩子都有花就慌了神、然后临时起意要买一束的，这时候你要做的就是给他们递上一个台阶，给足情绪价值。

# 2、你到底在卖给谁？

你以为买花的是考生？还真不是，考生哪有心思给自己买花。主要客户其实是家长，具体来说，40到48岁这一批人。

所以你得想清楚：你服务的是谁？他们买花干什么用？只有搞懂了用户画像，才能把从进货到卖货的整个逻辑理清楚。

这一层我实践的时候感触最深。上海最后一天考的是外语听说测试，我因为之前没做过功课，对时间安排完全没概念，早上完美错过了黄金售卖期，一朵花都没卖出去。真给我狠狠上了一课：做任何事都得先摸清规则，不能想当然。

下午场倒是长记性了，可那场只有四场口语测试，家长明显少了很多，只能厚着脸皮在人群里一个个攀谈问需求。

这里还有个插曲：一开始我还是按头一天的打法，站在原地吆喝，可那天太热，我又忘带水，嗓子都喊哑了，一点用没有。旁边一位坐着休息的家长实在看不下去了，跟我说：“你得主动走到人堆里去呀，你这待着不动哪行。”我就真走过去了，但也没啥效果。结果不知道咋回事，过了一会儿突然围过来好几个家长，我心里一阵狂喜，金主来了！我抓住其中一个爸爸，因为是个女儿，我就疯狂输出情绪价值，最后成交了一单，12.11，开门红。

# 3、卖什么花最稳？

我推荐三种：
1. 向日葵——寓意“一举夺魁”
[PRE3]
2. 莲花——寓意“好运莲莲”
[PRE4]
3. 蓬莱松——寓意“放青松”
[PRE5]

但如果让我只挑一个卖，那必是向日葵。根据往年的数据，这玩意儿是绝对的爆款，其他品类真不如它好走。

如果你不想砸手里，就想安安稳稳卖完，那听我的，只卖向日葵。配花可以加一点尤加利叶、蓝星花之类的，让花束看起来有层次感。

我自己的操作就更直接了，进了货就是“一举夺魁”向日葵，配了尤加利叶、满天星和小雏菊，别的没拿。

# 4、从哪儿进货？

两个路子：

## 路子一：网上下单
美团或多多买菜就行，好处是便宜、快，基本第二天早上就能到。但是千万别去淘宝或拼多多的那种跨城店买——第一，天热运过来花很容易损坏，理赔折腾又耽误事；第二，物流基本要三天左右，高考根本等不起。

[PRE6]

## 路子二：本地找花店
一家一家跑，问价格、对比品质。

提醒一句，高考期间花的需求量大，热门花材肯定涨价，尤其是向日葵这类抢手货，前后几天很多地方都会缺货。所以问的时候，一定要多嘴问一句供货量够不够、价格稳不稳。另外，一定要多备几个供货商，防止一个中途涨价或缺货搞你一个措手不及。

不过本地花店的缺点也很明显——贵。想找更便宜的，就去花卉批发市场。有些城市没有批发市场，但会有经销商存在。

[PRE7]

那怎么找经销商？直接去花店问，多问几家，总有人会告诉你。拉不下脸也没事，网上搜搜或者朋友圈发条消息，也能问出来。

我自己是直接走了线下，货比三家，晚上就交了定金。

# 5、进多少货合适？

建议300支就差不多了，再多你摆不开，搬运也是体力活。

我第一次没经验，直接跟店里老板说“来50支”——那会儿她货也不多了。但我付了定金之后，第二天实际只拿了32支。

因为我提前到了考场三个小时，那会儿根本没什么家长，我整个人是傻的。结果到最后半小时，别家同行都收摊了，人突然哗啦啦冒出来，我这边直接被抢空了。特别有意思的是，我的第一单居然是在洗手间门口开张的。当时去的太早，找不到公厕，就跑去隔壁一家公司借，我爸（我的专属搬花工具人）还在厕所门口等我呢，我一出来就撞上一个家长，上来就是一顿砍价。还好我反应快，凭三寸不烂之舌稳稳把价格守住了，第一单成就达成。

# 6、启动成本要多少？

以广西柳州的批发价为例，拿300支向日葵的话，单支价格能压到3块左右，成本900块。包装费大概100块，水桶10个100块，杂七杂八的贺卡、喷壶、收款码这些，100块内搞定。总体预算1200左右就能开张。

# 7、怎么定价？

假设单支进货成本3块：

### 1、单支定价
9.85元。用意有二：一是当引流品，低价吸引眼球，利用从众心理引发蝴蝶效应；二是寓意好——985，懂的都懂。

### 2、两支定价
21.1元，还带配花，寓意“考上211”。

### 3、六支定价
整束+配花，98.5元。这才是你的利润款，逮着人推它就行了。

说下我当时的情况。因为时间太紧，线上平台不现实，我直接中午跑去公司附近花店询价。一共问了三家：
第一家：单支28，两枝36，三枝46——听完我人都傻了，说好的3块进货价呢？
第二家：单支8，两枝18，三枝28——还比较正常。
第三家：单支9-10，两枝14简装或25精装，三枝38。

综合下来，第二家性价比最高。然后回工位上掰着手指头算了一番成本和利润。

算了下，9.85这个价作为引流品倒是够了，但要说利润嘛……就别想了。我又去小红书上搜了一圈，重新按寓意定了一版价格。

### 我最终的定价是这样的：
单枝12.11元，寓意“一定211”；
两枝39.85元，寓意“上985”；
三枝67.80元，寓意“录取吧”。

# 8、摆哪里？

选当地有名气的中小学门口或对面马路。这里有个关键点——得提前踩点，因为高考当天会有交警和城管守着。

### 最好的策略：
多选几个备选位置，万一不让摆，能立刻转移，别耽误黄金时段的生意。还有，别选在垃圾桶边上搞，太影响画面了。

我说下我的遭遇：确实有城管来赶过人。但我货太多，根本挪不动，只能眼巴巴看着他们，结果人家巡视一圈就绕走了。最后冲刺那一小时也有城管来过，但只是让我收摊前收拾一下，没真赶我走——遇到心软的神了。不过最后一天来的两个城管就凶多了，一路盯着我走，好在那个时间点考试也差不多结束了，影响不大。

# 9、什么时候卖？

最好是早上第一场考完之后。那时候家长和考生的情绪还处于紧绷状态，出来考完第一门，看到花买个吉利，顺便拍个照发朋友圈，顺理成章。另外，有的家长来接孩子本身就带花了，你旁边那些没带花的家长多少会有点尴尬，这种“别人家孩子有的，我孩子也得有”的心理，就是现成的成交机会。

我自己实践下来的感受是：每一场考完其实都有商机，但最黄金的时段其实是每天的最后一场，尤其是三门主科都考完的那一场，家长跟潮水一样涌过来，我花几分钟就全卖完了。

[PRE11]

真的，最后半小时是全场最佳。

# 10、摆摊前要准备什么？

### ①收款码
花几块钱去文印店打印微信、支付宝的收款二维码。如果还想把你家家长沉淀到私域里，就再加一个加好友的码。别等着现场手忙脚乱翻手机，太影响成交效率。

我当时是提前做好的，做成挂牌的形式，主打一个方便。

### ②带喷壶
天热花容易蔫，小喷壶往花瓣上喷点水，立刻精神很多，也能延长花期。

### ③带剪刀
有些花枝太长或者断了，需要现场修剪。

### ④包装纸
牛皮纸或透明纸都行，花店文具店都有卖，自己包。

### ⑤花桶
去菜市场临时买几个水桶也行。花没地方放直接摆在地上确实不好看。实在不行买几个好看的垃圾桶意思一下也行，主打一个便宜。而且高考两天用完，洗干净挂闲鱼二手出掉，回一点血也是好的。

我自己是花店老板借了两个大红塑料桶，一桶能装五六束花。但花放久了容易挤变形，后面卖的时候颜值会受影响。

[PRE12]

不过你别说，那大红桶在现场还挺显眼，不算坏事。

### ⑥折叠桌
方便摆摊展示。家里有小的折叠桌就直接带。

我没车，全程公交来回，就干脆没带桌子，确实是轻装简行。

### ⑦贺卡/笔
给家长准备的，也可以自己写。如果是自己写就要提前搜集祝福语，小红书知乎上大把，一搜就是一堆。切记文案别太长。

我准备得比较敷衍，就手写了些“金榜题名”、“一举夺魁”之类的话。不过我发现，还是尽量让家长自己写更有意义，也不耽误我的时间。后来花店老板还送了带祝福语的小卡片，又给我省了一笔。

[PRE13]

### ⑧广告牌
找一块厚实点的废纸皮，干净那面用马克笔写上“鲜花 xxx元”之类的。不想标价也可以写祝福语，但简短有力最好。最好用两种不同颜色笔写，显眼又好看。

我用的是艺术生必备的速写本，简单排版了一下就直接摆上了，多少比废纸皮好看点。

[PRE14]

### ⑨透明胶
多备两个没毛病。

我在实际过程中没用到，但反正便宜，带着没坏处。

# 11、遇到砍价怎么办？

有人可能会担心：家长砍价咋办？其实你不用担心太多，因为大概率不会砍。家长们看到价格上那些985、211、录取吧之类的字眼，心里已经觉得很值了，哪里还会跟你砍价。

但如果你真的遇到了，也别慌，教你几句：

我当时就遇到了几个砍价的，但都成功守住了，关键是要淡定。

一些实操话术分享：
①“您看这寓意多好，211、985，金榜题名，这钱花得多值。”
②“这花是早上刚现包的，新鲜着呢，您看这花瓣开得多饱满。”
③“底下放了花泥的，带回家能养好几天，不会马上蔫。”
④“贺卡上的字是手工写的，非常有心意，这是买不到的。”

# 12、简单好上手的销售话术

来，我临时给你编一版，不保证适合所有人，但方向可以参考，最终你要改造成属于自己风格的话术：

——“叔叔/阿姨，这些花都是刚到的新鲜花材，现场包的，送给孩子特别合适。祝他高考一举夺‘葵’、金榜题名！您看看喜欢哪束，我帮您包起来。”

——“这个价格真不贵，98.5元代表的是您对孩子的祝福和心意。送这束花就是告诉他，爸妈相信你能考985，一举夺魁！寓意特别好，您看中哪束了，我给您打包。”

# 13、怎么和同行抢生意？

### 1、主动打招呼
看到路过的、或者一直往你这边看的家长，主动打个招呼。他们在外头等两个小时也挺无聊的，你陪他们聊聊天，聊着聊着说不定就买了。家长都是很好说话的。

### 2、嘴甜
遇到买东西的家长，礼貌一点、嘴甜一点，多说说感同身受的话。让家长觉得你是真的懂他们的心情，不是单纯为了卖货。

### 3、提前占好位置
一个黄金展位直接决定你的客流量。去晚了离校门口远了，销量是真的会被腰斩。

# 14、怎么让花损耗最小？

## 1、避开暴晒
尽量选在树荫下。花在太阳底下暴晒两个多小时，直接变干花。

## 2、做好保水
水桶里加适量水，再滴几滴84消毒液，能延长花期，保持新鲜度。

# 15、卖不完怎么办？

这个问题我倒没怎么遇到。要是剩几支，直接送朋友或带回家自己养。要是剩一大批，就朋友圈便宜出，或者挂闲鱼低价清仓，尽量回收成本，别亏太多。

但我还是要说一下我的翻车经验：因为对考试时间不敏感，我完美错过了最好的售卖窗口，最后剩了四把花。我跟花店老板确认过，人家不回收剩花，只能自己处理。没想到老板心软，看我剩了四把，说成本基础上再减30回收一把，我就给了一把给老板，也算是个祝福吧。剩下三把我自己带回家养了。所以拍合影的时候，就剩三束了。

# 16、那些容易忽略的加分项

### 1、发朋友圈预售
提前几天发，能降低损耗，还能扩散传播。万一朋友不需要，也能帮你推荐给别的朋友。

### 2、闲鱼挂链接
闲鱼流量大，提前一天选几张好看的花束照片挂上去，狠多同城的人会搜到。

### 3、抖音直播
蹭高考的热度，现场直播卖花，教人怎么选花、怎么卖花，或者就是聊聊高考那些话题，也能涨一批本地家长粉，账号后续还能变现。

### 4、发小红书
把自己从有这个想法到出去摆摊再到最后收摊的整个经历写下来发出去，尤其是女生卖花这个话题，是真的火。涨了粉，后面兼职变现的路子就多了。

### 5、线下引私域
有家长买花的时候，可以顺势提一句“加个微信吧，以后母亲节、情人节什么的也能找我订花”。或者搞个小活动，加微信送个小礼物，比如好看的笔记本、笔什么的，用户就这样沉淀下来了。

说实话，第一次摆摊，我准备得太仓促了，这些路子基本都没来得及用上。不过也算完成了一次从0到1的变现尝试，接下来想得更多的，是怎么把这件事从小规模变成更大规模。

# 最后说两句

关于赚钱：别指望着靠一次卖花就能发财，把预期的那个拉链拉低一点。
关于心态：能挣最好，挣不到也没关系，就当玩一把，没什么大不了的。千万不要因为亏了点钱，就开始怀疑自己。失败是常态，心态放平比什么都重要。

整体来说，这是一次有惊无险的摆摊经历，虽然过程有些波折，但最终的结果还是让我感到满意的。也让我更明白了一件事：机会是留给愿意立刻行动的人的。
