# 2、为什么会出现远洋捕捞？

地方执法与司法的博弈，利益是核心。刑事案件一旦沾边就可管，管辖权背后就是经济收益——罚金、罚款、罚息、追缴违法所得。地方税务有创收压力，其他检法公也有财政收入。立案、结案、定罪、量刑的考核指标是硬任务，完成得好才算尽责。

管辖口径很宽：“犯罪地”既包括犯罪行为地，也包括犯罪结果地。行为地指实施地、预备地、开始地、途经地、结束地等；结果地指犯罪对象受损地、赃款取得地、藏匿地、转移地、使用地、销售地。

# 4、丁邱洁律师团队是否办理过远洋捕捞案件？有何体会？

## 4.1 骗取出口退税罪：深圳工厂主被带至内地四线城市，获刑5年多

有。一起骗取出口退税罪的再审翻案，1月接咨询，3月正式委托，5月提交再审申请，9月收到驳回。再审被驳回后结合舆论才发现，这起案件本质是2020年典型的远洋捕捞。内地某四线城市经侦大队将深圳外贸老板带走，一审二审历经两年多，最终可能缓刑变实刑5年多。

就罪名看，当事人本身无出口退税主体资格，不具备退税条件，为何成主犯？案件里出现了威逼利诱改口供、认罪认罚时辩护律师缺席、原拟办理缓刑突然改判5年半等情节，可能还涉及权钱往来。证据部分更是让人意外。该地检察院首次办此类案，被质疑判决偏颇时，曾对外强硬表示无需参照广东有经验案例。

心得：
再审难度极高。具有骗税属性的税务类犯罪一旦定罪，基本成铁案。不同地区办案水平差异大，个案中每个证据都关键，当事人能掌控的往往是口供，本案口供改了一字，刑期就从从犯变主犯、变5年多。口供切勿轻易更改。

## 4.2 深圳跨境卖家被合作方两次民事诉讼、异地控告两项罪名

有。一起跨境卖家股权民事纠纷，前员工想分走店铺一个亿，老板强硬反击。员工先以股东身份起诉被驳回，随后在异地控告老板身边人职务侵占罪。我们在第一次传唤就成功狙击，人当天释放、未被拘留，职务侵占罪未成立。员工不罢休，又以诈骗罪继续攻打，目前在收集材料阶段。

心得：
对付恶意诉讼，民事股权战要坚决。两年打了三场官司，前员工开庭当日撤诉一次，另案一审二审败诉。刑事狙击更要快，第一时间切断涉罪风险，性价比最高。等到被拘留就晚了，每拖一步结局差很多。身边人若被拘留，后续牵连老板的难度会成倍增加，民事变刑事风险陡增。

## 5.2 事发后如何辩护

1）被传唤第一时间不是去，而是联系律师！
如果你成了当事人：先找律师评估是否构成犯罪、是否属实、举报人可能掌握什么证据，推演讯问场景，必要时做模拟。提前准备对自己有利的材料。

切记：带公章的银行材料最管用！

如果只是证人或配合调查的案外人，可电话或书面向异地办案机关说明，或要求到本地说明。

异地公安直接上门：他来了，可以报警，让本地警方介入，体面自救，避免被带走。

《公安机关办理刑事案件程序规定》第三百四十六条：异地执行传唤、拘传、拘留、逮捕等侦查活动，应向当地公安机关提出协作请求，并在当地协助下进行，或委托当地代为执行。

找律师固定证据，提前换手机、留存关键记录、做心理预警。讯问时区分定性问题与常规问题，大原则：定性问题谨慎回答。

公安让你转账说能没事？公安只能冻结，不能直接划走，划走违法。但也要沟通，避免公司账户被冻影响经营。

2）越早越好 vs 越快越好？
找律师越早越好，准备越早越好，心理建设越快越好。

但回答问题、签字笔录不是越快越好，要看清是否属实再签。

笔录不要留空！不要留空！不要留空！

3）当事人、家属、律师三方合力
当事人别作死，自以为是常导致定罪加重。
家属别不信任律师，反复试探、自行毁证，最后含泪铁窗。
律师必须与当事人家属同心，才能保住家业事业。老板要提前储备靠谱专业的法律资源。

4）不能走错一步
判决前法官让你给钱打麻将，给还是不给？给了是行贿，不给又提心吊胆。
别人找关系我不找会吃亏？找了就是行贿。
律师不行就换来换去？耽误时机神仙难救。

5）精准辩护，而非精准踩坑
看是不是归这个公安局管
看办案人员是否刑警、证件是否齐全，两人以上执行
看讯问笔录是否合规，有无先备好笔录等你签字
看什么罪名、谁举报、目的为何
看是本人责任、公司责任，还是员工个人行为
看证据是否经得起推敲，如何博弈拆解
做强大心理建设，一大家子人等你回来
看公安是否结束、是否到检察院、认罪认罚后果是否清楚
如已定罪，如何争取缓刑、减刑假释、早日回归
永不回头，如何预防

6）爱家人
老板犯罪，家人最痛。无论何时，家人是你唯一的依靠。

# 6、远洋捕捞与普通刑事案件有何不同？为何谈之色变？民企老板为何瑟瑟发抖？

三者互为因果。
刑事案件的公正需要严格程序保障，但：
1）难不代表公正
企业主要明白：办案水平因人因地因案而异，能看见的不公判决已耗费大量时间金钱，更不用说看不见的。让企业不沾边刑事风险才是关键，出事后踩坑只会人财两空。普法并非为了转化，而是为了让民企健康存活，市场健康，法律服务才有意义。
2）要防的是系统性涉罪风险
跨境出海行业涉罪风险更大更复杂。由于远洋捕捞并非为防控犯罪或维护秩序，不排除以刑事手段解决地方创收的可能，办案趋利性更强，对企业更具害性。
3）民企是重灾区
民企风控意识弱，一个贪念就葬送企业。现实是老板忙于生存，等活下来才想合规。需要补常识认知，才能活得好久稳。

# 7、丁邱洁律师首次公开呼吁：保护民企刻不容缓，必须严打远洋捕捞

发刊词：保护民营企业刻不容缓，必须严厉打击远洋捕捞 2024跨境电商太空漫游

我旗帜鲜明反对远洋捕捞。成就一家企业要万难，毁掉一家企业只需一瞬。

直到今年五月办那起骗取出口退税再审案，我才真正看到中国民营企业家、出海创业者面临怎样的风险，需要怎样的担当。

民企成长九死一生，资金信息资源竞争无处不在。对跨境电商而言，双边多边监管更加严苛。

企业要突破的不仅是别国的高墙，还有国内不当监管。

我痛心看到，一些企业还没走出国门，就在国内被远洋捕捞击倒。

作为法律人，我们更关注合规与风控。希望企业以更低成本取得更好成绩，打磨供应链，塑造品牌，形成真正的国际竞争力。

复盘案件、研读各地涉刑案例，我不得不问：这些企业有什么罪需要被刑事追究三年又三年？经营中的不合规有没有更及时的化解方式？犯错了有没有更好的成长路径？

冻结账户是最浅最暴力的手段。一纸公函，一个辖区派出所，就能让十几年企业毁于一旦。谁的权利该被关进笼子？

过去觉得辅导一家民企就能解决一大群就业、提升海外声量。现在发现，企业出现问题太容易，一纸立案也太容易。若只着眼事后辩护，刑事合规就是空谈。

我们必须让声音被看见，让民企的艰难被重视。

放眼全球，中国企业尤其是供应链出海，横在眼前最大问题已不是质量口碑，而是国内监管的源源不断，刑事化成为打压手段。国际上贸易调查、封锁、管制、禁令层出不穷，地方保护主义抬头。

普通民企哪有能力应对？

我再次声明，我旗帜鲜明反对远洋捕捞。

我坚定站在民企一边，希望为更多民企发声。只有无数民企尤其是中小微企业能站起来，市场才有市场，法律服务才有意义。
