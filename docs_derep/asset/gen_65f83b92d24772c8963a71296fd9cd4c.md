# 别再只盯着抖音了！百家号搬运带货，每天半小时，月赚几百块，新手宝妈都能做

讲到短视频带货，绝大多数人脑子里蹦出来的就是抖音、视频号，觉得只有那里流量大、机会多、能暴富。

但其实大家都忽略了一个门槛更低、操作更简单的平台——百家号。它不像抖音那么卷，用对方法，收益照样能看。不过提前说清楚，这个项目的收益天花板不高，一个月大概几百到上千块，大佬肯定看不上，但非常适合新手、小白、宝妈来练手。每天只需要抽出半个小时，一个月多赚几百块零花钱，基本没啥问题。想靠它暴富的，可以直接划走了。

玩法逻辑说白了和抖音带货一样：注册一个百家号，发带货视频，挂上小黄车。用户刷视频时，系统会根据他之前看过的产品，推送类似的带货视频给他，看到心动的，点左下角的商品卡片直接下单，成交后你就拿佣金。整个转化流程特别顺滑。

# 一、开始前的准备：电脑必须有！

先从第一步说起，一步步来，照着做基本能跑通。

**1、准备2~3个百家号（可以找家人实名）**

多号操作是拿结果最快的方式。一个号也不是不行，但多少带点概率性。如果你每个号的爆率是10%，那就准备10个号去跑，基本可以理解成每发10个视频，里面就有一个号可能爆。

**2、下载三个返佣APP：多多进宝、淘宝联盟、京粉**

这三个分别对应拼多多、淘宝、京东的官方返佣平台，也是查看佣金的后台。做过淘客的应该不陌生。应用市场直接搜就能下载，注册时建议用自己常用的手机号，方便登录，也可以设置密码。注册完记得实名、绑定银行卡，后面提现要用。

# 三、选品思路：跟着人群走

**1、先看数据，再定方向**

既然视频是从抖音、快手、视频号找，那我们在搬运之前，先来分析一下百度上的人群属性。

百度APP其实包含了好看视频、百家号等所有百度系的功能，所以好看视频基本没啥人看，流量都在百度APP上。

百家号的人群目前男性偏多，18~24岁的年轻人占比高，但这部分人不是消费主力。我们要盯的是30岁以上的购买力人群。选品的时候，就要往这个方向去思考：哪些品容易让这些人下单？

从后台的粉丝教育水平数据来看，关注我的粉丝大多是大专以下学历。百度作为老牌国民级APP，常年积累了大量依赖搜索的用户，高学历的人接收新鲜事物更快，反而用的少了。

这就决定了，留下来的人学历普遍不算高。学历不高，收入水平也跟着受限，收入不高，买东西自然追求“性价比”“便宜好用”“低价生活用品”。

**2、开始搬运**

无脑搬运法：确定好品类的类目，去抖音找5~10个对标账号，找满10个基本够你搬一年了。操作方法就是把这些博主的视频全部搬到百家号。从他最早发的视频开始搬，比如他2021年开始发视频，你就从2021年的开始搬，每天搬5个左右就行。上班族不想动脑选品的话，直接复制对方的视频去发就好。好处是无脑省时间，坏处是出单慢，不知道哪天才能爆。这个见仁见智。

选品搬运法：先去数据平台看本月、本周、本日畅销的品，选好后再去多多进宝看佣金。不要选佣金低于5%的品。因为拼多多佣金普遍偏低，太低了你自己也做着没劲。确认佣金高于5%后，找当天抖音最新发布的视频，再看发布者是不是“电商优质创作者”，不是的话就可以搬了。

混剪整体步骤总结：
1. 视频画面放大
2. 视频倍速调整（加快或减慢）
3. 视频切割，至少2~3段
4. 加贴纸、滤镜、画中画、转场、特效
5. 音频处理：文字解说想加就加，不加只放音乐也行

这些都做完，恭喜你，混剪完成了。新手第一次操作可能需要半小时才能剪好一个视频，但以上操作其实可以套用混剪模板。

**极速混剪方法：**

在第一次混剪的基础上，先把混剪完的视频导出，然后重新找视频、切割、排列组合，再把这些组合好的视频直接套入第一次做的模板，只改下音频或字幕就行。这样剪一个视频大概只要3分钟。
