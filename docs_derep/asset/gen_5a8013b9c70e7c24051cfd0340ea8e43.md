# 把过去的碎片拼起来，钱就开始滚起来了

前阵子我看到一条带货短视频，一段国外大学毕业典礼的演讲画面，配的是英文原声童书，点赞已经三万多，橱窗那几本书卖了十万多单。看完的第一反应很直接：这个我也能做，而且我知道具体怎么做。

这种一下子就能上手的感觉，不是灵光乍现，是之前攒的点被连起来了。

在我接触中老年女装短视频带货时，我学会了盯着爆款跑，模仿节奏和结构。

后来在做书单号的航海期，我摸清楚了一套打法：先用纯流量向的视频把账号养起来，再用这些流量去推付费的带货视频，也是在那段时间练熟了配音工具怎么用。

再往前，我有一段时间会刷 TED 演讲，顺手就记下了素材都从哪里能扒，哪些画面有情绪。

而参加视频号带货航海的时候，我又多了一项本事：会把已经爆过的视频拆了，再混剪重发，用来带货。

把中老年女装的爆款敏感度、书单号的涨粉带货路径、配音工具的使用习惯、TED 素材的来源渠道、视频拆解混剪的方法，这几块放一起，英文育儿演讲+童书带货的路子就自然浮现了。一眼就能看到从选题到执行的全貌。

这就是赚钱里常说的 connect the dots。点越来越多，连线就越密，盘子也就越做越大。

评论区有几个补充挺到位：

英语演讲的实际内容其实和文案几乎没关系，买单的不是能听懂英文的家长，而是被那种“国外名校、精英教育”的画面感唬住的群体，场景营造到位就够了。有人当年直接用 TED 物理演讲画面配李玫瑾的家庭教育文案，数据依然很好。

还有人点出了本质：生意能成，有时候靠的就是人性洞察。以及能力迁移，拆解才是自媒体最通用的核心技能，在哪个平台都能用。stay hungry, stay foolish，保持连接点的习惯，钱也就跟着连起来了。
