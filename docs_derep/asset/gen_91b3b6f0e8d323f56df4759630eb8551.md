# 10小时只靠“说”完成一个MVP网站：我的MCP实战全流程

大家好，我是智昊，也是这次MCP航海的教练。

最近在深海圈逛的时候，看到不少圈友用Cursor遇到报错，都是复制错误信息或者截图发给AI，来来回回效率很低。这让我想起上周加餐时给船员们演示的场景：我只对Cursor下了一句指令，它就自己完成了网页开发、测试，一直到上站。很多同学当时都觉得“这也能行？”。

其实我也刚把自己的工作流好好梳理了一遍，发现这套“让AI全包”的打法还挺值得分享的，而且星球里也没有类似的文章，所以干脆写出来冲个精华。

这次的项目，是我花10小时做的一个基于AI的待办事项管理小应用。

从灵感出现到网站落地，整个流程我全程只用“口喷”——你可以理解成一直用嘴巴和AI交流，不复制、不粘贴，AI让我做的任何操作我也一概不碰。

我觉得这才是MCP真正的魅力：人只需要表达清楚想法，剩下的跑腿活儿全交给AI。
