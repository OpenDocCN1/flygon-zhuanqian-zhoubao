# 平台栏目设计的阶段性回顾与建议

作者：孤月 | 日期：2023-03-28

作为长期泡在这里的老用户，我每天都会打开它看一会儿，内容确实帮了我很多。新一期很快要开始，平台大概率会有调整，我也趁这个机会把平时积攒的点滴想法整理出来，供大家参考。

先聊聊现有的页面框架。顶部一级菜单里排着信息流、精选栏、趋势榜、趋势雷达、收益简报、社群分栏等入口，这些都是高频访问的位置。从排列顺序也能看出，精选栏和趋势雷达的地位最高。

点进社群分栏后，还会发现更细的子类：航行日常、实操派、资源撮合、求助答疑、项目可行性、闲聊区等。其中航行日常、实操派这两个子类基本没有新内容，最近一次更新还停在2022年。

不过本期重点是实战型训练营，强调亲自上手，但相关产出在社群里展示得不多。参与过训练营的朋友应该都知道，营期里产生的资料大多以记录形式散落在各个营队内部，优质内容容易被埋没。想要翻出这些记录，步骤很多：先到实战活动主页，再点进具体某期营队，然后打开资料室，再从里面挑出精选条目，最后才看到列表。这个过程有点麻烦。

我的想法是，能否在顶部主菜单单独增加一个训练营入口，集中展示牛人拆解和精选条目。训练营进行中以及收尾之后，成员们都能在该专区发帖，及时记录自己的实战状况。平台还可以给优质复盘内容发放积分奖励。

这里要提到现有的激励设置。眼下社区主要依靠精选内容和趋势雷达来奖励优质输出，顶部菜单的显眼位置也给了这两块。精选内容以前基本都是深度长文，虽然年初主理人调整过规则，希望催生更多短小而高质量的文章，但观察下来，信息流和精选栏里仍以长篇文章为主。

于是会形成一个尴尬局面：当某个成员在信息流发了帖子，既够不上精选标准，也无法一直在信息流展示，系统会把它挪进闲聊区。可闲聊区入口很深，不在顶部菜单里，需要反复跳转才能找到，曝光自然少得可怜。

被寄予厚望的趋势雷达也有隐患。由于发帖激励很强，大家每天都会生产大量趋势内容，却没有做任何归类。刷起来常常东一句西一句，没有章法。完全不看又担心漏掉关键信息，只看筛选后的趋势榜又怕覆盖不全。趋势雷达是不是也需要做更细的归类？

设想一个场景：某个成员想写一写自己的项目复盘，但篇幅撑不起深度文章，放进闲聊区又怕沉底，发到趋势雷达也不太搭调。眼下他确实没有合适的去处。

整体来看，平台对信息归类的重视程度还不够。虽然有一个项目档案区，但其中有大量信息还停在2022年，只有少数项目收录了部分深度文章。而且需要归类的远不止深度文章，普通帖子的去向也应该更清晰。

平台的内容广度已经不错，但深度给人的感知并不强。或者说深度内容确实存在，只是用户不容易发现。因为归类不足，大量不同主题的帖子都汇入信息流、精选栏和趋势雷达，混在一起，阅读负担不小。

很多成员的参与热情还有进一步释放的空间。当下大家逛得最多的还是信息流、精选栏和趋势雷达。如果能有更聪明的激励设计，让其他子板块也分到一点关注，或许会增加整体产出，也能带动互动。

新一期的实战训练营依旧会是很重要的亮点。怎么把营队期间涌现的好内容留存下来，怎么鼓励大家亲自投入、彼此交流，这些都需要团队仔细打磨。

祝平台越办越好，我这些不成熟的建议如果有偏颇，还请各位见谅。
