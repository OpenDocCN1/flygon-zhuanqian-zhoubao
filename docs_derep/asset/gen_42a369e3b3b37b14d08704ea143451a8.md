# 视频号直播想开播带货？千粉门槛已上线，这几条路可以走

> 来源：[https://uiv0uqamjmc.feishu.cn/docx/Oyqsdiq0LotmvSx4llwc3z25nie](https://uiv0uqamjmc.feishu.cn/docx/Oyqsdiq0LotmvSx4llwc3z25nie)

大家好，我是小马哥。

最近视频号带货的风头起来了，我们团队也在积极布局这边。就在不久前传出消息说直播带货要升级到千粉要求，昨天我实测，规则已经正式生效了。

昨天一开播就撞上了这条新规：

[PRE1]

点进去看官方的提示，意思是有效粉丝数要达到1000人才有带货权限，点开查看基本就是橱窗权限能用，但直播带货权限还没解封。

不过提示里也给了另一条路：开通视频号小店。也就是说，现在可选的打法就两条主线，一边是冲有效关注到1000粉，一边是直接走小店开通。

我把目前能想到的几种操作方式做个梳理：

1、买粉 S粉
2、互相关注
3、靠内容做自然涨粉
4、走视频号小店通道

先说最省事的那个，开通小店。

这个方法适合已经有个体户或企业营业执照的伙伴，用来绕开粉丝门槛拿到直播带货资格。

开店入口在：微信-发现-视频号-右上角头像按钮-创作者中心，里面找到创作者服务里的带货中心。

还没开通橱窗的先把橱窗开了。

[PRE2]

进入带货中心后，如果橱窗里没上商品，系统会提示你去选品或开店

[PRE3]

点进去直接选就行

[PRE4]

[PRE5]

这是官方的视频号小店开店教程链接。需要重点注意的是，如果纯粹为了直播带货，类目选择尽量挑开放类目通过率高一点的。

其他资料提交就按流程填，个人身份信息和企业信息准备好就行。

电脑端也能操作：https://channels.weixin.qq.com/shop

S粉

这个不必多讲，各大平台都有对应服务商。怎么实现的，无非是任务群、互赞互粉之类，细节不透明。

好处是快，坏处是视频号要的是有效关注，买来的粉和真正有效的粉丝之间有损耗。有效关注具体怎么判定，官方没细说，所以用这招要自己掂量风险。

互关

昨天刷视频号时就看到不少账号在玩这套，评论区全是“回关”“互粉”的留言。和抖音上的玩法几乎一样，涨到1k很容易。至于对后续推流有没有负面影响，目前还不好下结论。

靠内容涨粉

这条路最正经，也最考验能力。尤其是没有营业执照，也不愿意走灰色手段的人，只能靠内容。

我们之前在抖音做中老年赛道，主要是抄爆款和做中医健康相关内容，涨粉效率很高。但搬到视频号后发现审核尺度不一样，抖音能过的在视频号可能就被限流了。

现在我们也在试水，感觉黄V蓝V的账号在做中医内容比较多，普通账号发这个要很谨慎。

另外昨天发现一个比较新的涨粉套路，是用聊天记录截图做冲突剧情。

[PRE9]

一张聊天记录配上婆媳、家庭矛盾之类的冲突话题，互动还不错。制作也简单，用聊天生成工具一键出图，想更真实就用两个小号模拟对话再截图，现在刷到好几个人都在用这个模板。

至于围绕中医个人IP的涨粉打法，目前生态还在成型，头部基本都被认证号占据，后续会不会放开还在观察。有在做这个方向的可以多交流。
