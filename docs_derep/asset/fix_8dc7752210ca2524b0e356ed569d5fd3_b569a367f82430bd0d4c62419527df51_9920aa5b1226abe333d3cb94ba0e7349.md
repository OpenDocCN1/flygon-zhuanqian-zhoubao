# 从全军覆没到月赚十万：视频号小店重来记

先交代一下来龙去脉。2025年3月入圈生财，7月首帖意外拿到精华，感谢大家的鞭策。上篇偏讲起步阶段，感兴趣可翻历史记录。之后几个月基本泡在店铺里，直到上周末才有空把这段时间梳理出来复盘。今天想聊的是：8月我的视频号店铺全部被永久封禁，到11月单月净利润再回到十万档。

成绩摆这儿：最近31天，扣掉退款后有效成交约50万，整体毛利控制在20%左右，个别爆品能到25-30%，净利润勉强突破10万。

## 一、黑八月

7月底时，店铺已进入平稳期，也和几位同路人交流过打法，得到不少建议。于是我对团队分工做了微调，又招进两名店务和一位剪辑，编制扩充到6人。当时设想是靠存量店铺的利润养内容团队，一边做短视频一边试探直播。

变故出现在8月7日。那天本打算开播，一条自制短片有起势迹象，我刚把店铺链接挂进橱窗，系统就提示无商品可售。点进去一看，公司名下5个店铺同时变灰，全部商品被下架，状态显示永久封禁。下方两张图是当年主力铺的处罚截图。

当时脑子是空白的。刷新数次确认无误：5个铺面彻底归零，新品也无法上架。联系客服登记了账号与联系邮箱，回复周期是7个工作日。另以每家店铺主体分别发了申诉邮件。可是申诉解决不了当下困局——好比整装待发，基地却被直接点掉，连敌人在哪里都搞不清。

团队瞬间闲置。下午我就通知大家先放假，按当日全勤结算，随时等召回。人都走后，我跟爱人关起门来商量。她眼眶发红说她负责的图书店每天稳赚千元，如今收入断档，直播也才刚起步。她说你现在拖家带口还带一帮人做事总是冲动，现在好了，所有人都要停摆。

我第一反应是直播违规连累。查规则后发现确有连带机制，而当时有几个直播号因低质无货展示被警告过。愧疚感很强，觉得是自己求胜心切害了大家。直到数天后官方邮件回复，原因指向图书类目的版权问题。大家当时并不知情，全把锅推给直播。运营的提成靠出单，现在没单，达人全跑光，军心彻底散了。

第二天我跑了几家同行交流，明白过来：他们的店好好的，任何经验都救不回我已归零的局面。真正的难题是重新起盘，而不是听建议。

冷静后只剩下两个选项：保留原班人马继续开店，或者砍掉所有人只剩夫妻做直播。权衡下来，店没了养人等于烧钱，双人直播体力与不确定性都太高。最终折中：裁掉一名店务和剪辑，保留两位运营，编制压缩到4人，同时维持对短视频与直播的可能性。

两天后用备用执照重新开店，一次性上线3家新铺，各自认领。此时平台已改规则，新店必须完成100单公域结算才能进入优选联盟，不然达人在广场检索不到。店铺全未进池，只能先把货上满再想办法凑单。找了几批刷单资源，都不靠谱，有的发假物流单号，资源池质量差。有一家刷了近300单，结算后仍不够100；另一家因刷单被系统连封多次。之后彻底不敢碰了，像惊弓之鸟，生怕再被全封。

无路可走，只能自己播。每家店绑定一个新号，未进池只能主号挂自家链接，主号不能违规。买样品实拍，模仿当前爆款视频一比一复刻，用直播承载短视频流量。各店产品不同，就是赌。策略很糙：播就连续播满24小时，平台强制断播前不断。夜里我顶，昼间同事顶。后来两家绑定的号自然流爆发播放几十万，转化一般但单场破百单；第三家产品不给力只能投流硬推。靠这份觉悟，三家店先后入池。之后的新店入池才找更稳妥的渠道。

八月基本没盈利。新铺商品少，成交量小。期间试过自制内容加投流，靠平台赔付勉强小赚，可赔付券的时效一个月，我忙忘了核销，全部失效。那段时间我活在自责里，连周会都停了，像个做错事的孩子不敢见人。

心态也出了问题。有次跟兄弟打台球，约五小局一大局，三盘两胜，适度下注。水平相近，我却常在领先时倒在关键球，被反杀。越打越保守，只想给对方做自由球。兄弟说你打法这么孬，跟平常完全不一样，赢你也没意思。这句话点醒我，输的不是技术，是心魔。那晚我明白：该进就进，该赢就赢，一杆一杆打好就行。接下来连续约了两周，状态回来，输赢已不重要，重要的是找回自己。

压力也在家庭。八月零收入，爱人有情绪。我说从年初到现在，除了这次封店，哪次决定走偏过？若你还信我，就再赌一把。她没再反驳。我随后梳理新作业规范，要求先保证动作质量，不盯短期结果。

## 二、重启与爆发

九月，各店慢慢回暖。其中一位入职三月几乎零产出的运营，他负责的新店在九月到国庆期间贡献约20万销售额，毛利接近30%，几乎一人提振了全队士气。

[PRE12]

起势后新问题出现。爆单店的运营开始膨胀，觉得功劳全在自己，不满既定提成，还试图拉拢另一名运营在内部分裂。她忘了公司在她长达三个月无单时仍在投入资源与鼓励。她还是我老友的配偶，人性就是如此。

我复盘后明白：七月起选品上架我已放手，只定方向处理杂事。如今有人生出不服，觉得离了她店就垮。在小团队里，资源和制度威慑不足，这种心态很常见：领底薪怕公司倒，拿提成嫌少。早年我在深圳就见过类似局面，此后再不会容忍。我的逻辑一直是：创始人先自己把路跑通，做到比多数同行更强，形成个人优势，再复制到团队。创始人必须在能力上始终压住成员，才能赋能；指望员工拉动公司太脆弱。

国庆后我跟两位运营明确：店铺能起来，是因为我把打法复制给你们。随后我亲自接手爱人负责的店，太久没选品，压力很大。从接手起，每天精挑50-80个单品，不分昼夜。电脑前直接上下架，离开时存手机，回来处理。约一周后出单并爆发。我对另一位运营说你的店停一下，直接搬我的货就能爆。近一个月，这两家店净成交接近30万。最近又新开一家店，两天卖9万，平均毛利超20%。用结果把队伍镇住了，凝聚力也回来了。创始人确实不能松懈。

再算一笔账：近一个月四家正常出单店流水50万，净利润10万以上。若没有八月的封禁，直播板块本可更早跑通，业绩至少翻倍。也正因这场劫难，我把视频号小店吃得更透。小团队抗风险弱，容错率几乎为零，每步都如履薄冰。只要方向没错，踏实走下去，答案自会到来。

## 三、可复用的打法

### 一、进优选联盟

一个执照最多开五家店，只有企业店才有资格进联盟。自己不播的话，货必须进优选选品中心，达人才看得到。现在门槛是100单公域结算，即从广场或短视频进直播间的成交。发货后买家签收或主动确认收货，10天后才算结算。

凑单两条路：一是找外部资源刷单，约15天完成，速度快但风险高，结算不到100需重来，假单还有封店风险，做单必须走真实物流。二是用主号直播出单，量过百且退货少，系统自动结算，慢但稳。我因被封过，选了直播硬扛。

入池后核心在选品。我们几乎不主动对接达人，订单靠野生达人挂链，达人极看佣金与价格，现在也关注店铺评分。选品是生死线。

### 二、商品上架流程

1. 找品，先评估售后难度。学习成本或安装成本高的品会拖累客服。确认OK后去拼多多、淘特、1688、抖音、快手找性价比好的源头。

2. 用搬运工具导入后台，按平台规则优化标题关键词与违禁词，完善SKU属性。

3. 提交审核。结合源平台评价反推成本，设定售价，预留约20%毛利，扣除平台扣点与达人佣金后再提交。

4. 审核通过后挂佣金入优选联盟。佣金一旦生效，修改需隔天才生效。

### 三、选品思路

我们现在基本手工精细选品，不搞粗放铺货。手选慢、控价佣金更精准，转化更高。批量铺货命中率低，属于大力出奇迹。

视频号广场选品：先养号。用观察号不发内容不挂橱窗，只在广场刷目标类目。刷到娱乐内容直接划走，避免点赞评论留下标签。刷到带货类目则完整观看并点赞评论，半天到一天可养出标签，一个号可养多标签。

养号后刷到合适的带货视频，判断产品竞争力，点击商品链接或橱窗保存同款图，搜拼多多找优质货源搬运上架。若橱窗里没有该商品，说明选品中心无此品，属于蓝海，需抢上架。

达人橱窗选品逻辑同上，先养号再拆解对标账号。

总结：能否进联盟决定曝光，能否挑出好品决定利润。两点通顺，剩下的就是细节执行。
