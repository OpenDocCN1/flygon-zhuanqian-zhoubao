# 一、商业本质到底是什么

我来自陕西一个18线小县城。上大学前，没坐过火车，也没坐过飞机。到了大城市以后，被眼花缭乱的物质世界狠狠刺激到了，但父母从没教过任何商业思维。

最初想赚钱，就是因为一个个落差感爆棚的瞬间。

为了攒200块，一个月省吃俭用，精打细算每一笔生活费；同学聚会时，大家聊旅游趣事，我只能沉默；600块一顿的海鲜自助，隔着玻璃看一眼就走……

这些瞬间让我上大学后只想搞钱。

我做过线上家教，一周7小时赚120；也做过视频剪辑，完全是在廉价出卖时间。折腾一圈后我发现，这些都是没有复利的，越做越辛苦，看不到更大的可能性。

我想要的是越做越赚钱、越赚越轻松的事。

当商业意识真正觉醒后，找商机反而变得容易了。

今年3月，虽然账面上已经赚到了六位数，但我对赚钱这件事还是只有模糊感。我的盖洛普“思辨”和“战略”都很靠前，如果搞不清自己为什么能赚到钱，心里就特别别扭。

越聊我越发现：健身房、剧本杀店、知识付费，行业看着毫不相关，但背后似乎有共同点。

我们都会为流量发愁——不管是大众点评、微信裂变、群发售，还是小红书引流，都很难做。我们也都会为转化发愁——海报设计要反复斟酌，健身房的体验课要精心设计，剧本杀的第一套盒装要仔细挑选，我的低价知识付费产品也要认真打磨和交付。

那一刻，我好像摸到了一些底层规律，看到了商业的本质。

## 2. 本质一：闭环就是一切

我发现的第一个本质是：

任何ToC的生意，都能拆成【流量、产品、转化、定位】这四个要素组成的闭环。

健身房如此，知识付费如此，剧本杀店也如此。

[PRE2]

这四个要素分别是什么呢？先看极简版图，然后再展开说。

定位：满足某个人群的某个需求。

健身房满足的是锻炼需求，剧本杀店满足的是娱乐放松需求，我的时间管理知识付费满足的是人们迷茫摆烂、想要自律的需求。

在我看来，定位是四要素中最重要的一环。因为只有当定位清晰，你在相关领域有知识和技能的积累，对目标客群的心理有深度把握，后面引流、交付、转化才会顺利。比如开健身房，无论带课、谈单还是宣传，都要懂健身人群的心理，也要懂健身知识。

流量：让目标人群看见你的渠道。

获取流量的方式很多，本质就是触达。我的知识付费流量来自小红书；健身房和剧本杀店靠大众点评投放；平时看到的广告牌、传单，本质上都是商家在搞流量。不管用什么方式，让感兴趣的人看到你，然后拿到电话或微信，反复触达，最终促成转化，这就是流量。

产品：为用户需求提供解决方案，也就是你拿来盈利的东西。

对健身房来说，是一节高质量的私教课；对剧本杀店来说，是一场优秀的演绎剧本；对时间管理知识付费来说，是我的课程和私教服务。只要能拿出一套东西满足用户需求，就是好产品。

转化：用各种方法让看到产品的人下单成交。

健身房会提供免费体验课；知识付费会通过朋友圈、公众号、直播引导购买。

所以最简单的商业闭环就是：定好位，做出产品，让人看见，说服成交，交付收钱。把【定位、流量、产品、转化】凑齐，就能赚到钱。

听起来有点复杂？别急，后面实操部分，我会具体演示知识付费的小闭环怎么跑通。

## 3. 本质二：只需要认知和资源

我们常听到一句话：富二代可以花天酒地，但千万别创业。因为传统创业模式太吃资源了。开健身房要买器材、付房租水电、投广告，起步就要砸不少钱。

但创业除了资源，还需要什么？需要人，需要有脑子、有认知的人。

于是你会发现，个体创业只需要两样东西：认知和资源。

怎么证明？创业里的任何一个环节——无论是引流、转化还是交付，都是认知+资源的产物。

认知是审美，是方法论，是你知道一件事应该是什么样子、为什么要这么做。

资源是一切可用的东西，包括钱、时间、精力、人脉。

举例：一节高质量健身私教课，是一个交付型产品。

资源是教练的时间、场地、器械、洗浴设施，以及购买这些的资金。
认知是如何设计一节好课，如何选购、安放器械。

认知+资源=一节高质量私教课。

再举例：一篇高质量小红书笔记，是一个引流型产品。

资源是电脑、自媒体人的时间、模板。
认知是懂选题、懂封面、懂小标题，知道怎么写才能爆。

认知+资源=一篇高质量小红书笔记。

到这里结论再次得到印证：个体创业只需要认知和资源。资源可以通过传承、购买、积累来获得；认知可以通过读书、看课、进入高质量社群来提升。

不同商业模式对认知和资源的要求完全不同。电商对资源的要求远高于知识付费，因为要囤货、交平台保证金。而知识付费几乎不需要资源，一部手机、投入时间就可以了。

既然知识付费门槛这么低，为什么成功的人那么少？

答案很可能是：知识付费对认知的要求特别高。

做了两年知识付费，我越来越认同这句话。朋友圈怎么写、一天发几条、软广怎么发、课程怎么定大纲、怎么录制，每一步都需要认知支撑。这时候光靠蛮力没用，只有去学习、去实践，才能补上认知，赚到对应认知的钱。

你赚到的钱，就是你认知的变现。

所以接下来，我把自己做自媒体月入5万的底层认知，毫无保留地分享出来。

## 2. 定位初探：成长与赚钱

刚开始做自媒体的人，很难找到特别细分的定位。因为还没经历过足够多的探索，也没拿到过外部反馈来调整。

那换个思路：不必一开始就切细分赛道。不需要具体到时间管理、学习方法、搞钱、情感、玄学；就做一个笼统定位——成长。

不需要具体到电商、小红书、视频号、爆文写作；就做一个笼统定位——赚钱。

赚钱和成长，几乎覆盖了所有人的需求。需求切得泛，收不了高价，但恰恰适合低价小陪伴群。

一切想变好的人、想赚钱的人，都能进来学习。9.9买不了吃亏，买不了上当。或者更直接一点：

你可以来投资我，我会真诚交付所见所闻，和你交换价值。

## 3. 产品初识：我们不是“卖空气”

定位定了，那卖什么？自媒体常被人吐槽是“做营销”“卖空气”，但我们不能真卖空气，我们要卖知识。

产品就叫“xxx的成长陪伴群”，xxx是你的IP名。

交付内容包括但不限于：
1. 自己成长中的所见所闻；
2. 自己报名高质量课程学到的东西；
3. 自己买或搜到的资料包；
4. 培养一个技能的心路历程；
5. 参加线下聚会的收获；
6. 读一本书的所思所想。

任何你觉得有价值的东西，都可以作为交付内容。别担心质量不够高，9.9要什么自行车？只要有一点信息增量，就很棒了。

正式运营只需要一个物料：群公告。

群公告是我们社群产品的核心，也是少数能带来强交付感的东西。可以写广告、群活动、社群介绍、群主介绍，但最关键的是两样：过往分享积累和社群介绍。

过往分享积累给一个链接就行；社群介绍要说清分享频次和内容定位。

例：欢迎加入枕棠的成长陪伴群，本群主要分享时间管理和最新赚钱知识，每周六晚八点分享。往期分享汇总：（放飞书链接）。

## 4. 流量初获：只需两步

知识付费的流量目标，就是把别人加到你微信上，然后反复触达。

思路很多：小红书、公众号、直播、公开课……但既然目标是跑通最小闭环，那怎么简单怎么来。我们从众多引流方式里挑最简单的——混社群加好友。

分两步：

第一步，加群。去加入一些爱成长、爱赚钱的社群，免费付费都行。进群后，多数社群允许发自我介绍，发完就会有同频的人来链接你；也可以主动去加好友。

第二步，私信沟通。加了好友之后，主动发自我介绍，再送一份自己整理的资料做见面礼。大多数人都是社恐，加了好友也不知道聊什么。只要你主动开口、主动送礼，就已经赢了绝大多数人。

反复循环，当私域有300人以上，流量问题就初步解决了。

## 5. 转化初逢：一张海报就够

到这里，定位、产品、流量都有了，只差最后一个要素——转化。

一开始不用学太复杂的东西，公众号、直播学习成本都比较高。我们就用最简单的方式：发朋友圈介绍产品。

当然还要做一个宣传物料：海报。

新手不用学稿定等设计工具，用手机笔记软件就行。好用的是锤子便签和苹果自带笔记，前者在应用商店直接下。

# 三、如何迈出第一步并放大

## 1. 卡点一：不敢教人，我是菜鸡

加入优质圈子后，总会看到很多前辈和大佬，他们温和又强大，文章写得特别有价值。然后你就容易自我怀疑：跟他们比，我好差，他们才配做知识付费，我只配跟着学。

但真的不是这样。知识付费圈有句名言：100分的教90分，90分教80分，60分教不及格的。

哪怕你很菜，但只要你还会读书、会写作、会表达，或者你能把这篇帖子读到这里，说明你已经及格了。你完全可以分享知识、做知识付费。

如果你还是没自信，那就先做出产品去卖，看看有没有人买。有人买，说明产品不错；没人买，再调整也来得及。

## 2. 卡点二：收钱罪恶，我不配

如果你是农村或工薪家庭出身，父母可能从小告诉你：赚钱很难，别走歪门邪道。

但父母赚钱难，大概率不是因为不努力，而是认知不够——他们没读过大学；更重要的是没选对行业。新媒体总比种地靠近时代风口，风口上猪都能飞，何况优秀的你？

还有一个传统观念：来钱快的都是歪门邪道。我们总习惯把自己理解不了的东西归结为道德败坏，比如一提互联网创业就有人说传销。

于是你心里就有了声音：收钱是罪恶的，互联网创业就是传销，我不配收钱，我应该去打工，靠双手致富。

怎么打破这个荒谬念头？几个角度：

第一，你不是在诈骗，你是在提供价值。你分享的是自己学过的、确实有用的东西，付费的人认可这些价值，你情我愿，等价交换。

第二，你们不是敌人，是朋友，是互相成就。知识付费就是一场双赢：一方提供知识，一方提供金钱；一方学到技能，另一方拿钱继续投资自己，飞速成长。
