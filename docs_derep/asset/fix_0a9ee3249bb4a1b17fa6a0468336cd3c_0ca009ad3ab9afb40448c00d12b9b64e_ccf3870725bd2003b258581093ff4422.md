# 六、投放实操

小红书是当下最易起量的平台，门槛低。但免费流量已高度内卷，平台也收紧引流，稍有动作易限流封号。

## 01 聚光本质

我们不是买流量，是帮平台卖流量。平台供量，我们供产品服务，精准客户买单。分成三七，平台七成。

把它当交保护费：轻微违规多为提醒；客资到微信可长期跟进；前期成本高，后期靠复购推荐持续增长。

## 02 核心指标

点击率 CTR：点击/展现*100%。>5%优秀，3-5%良好，1-3%及格，<1%需优化素材。

平均点击成本 CPC：总花费/点击量。竞争激烈行业1-3元，普通行业0.5-1.5元，商业计划书品类1.5内最好。

行动按钮点击率：点击咨询按钮次数/广告点击*100%。优秀>5%。

行动按钮点击量：直接点立即咨询的次数，体现转化意愿。

私信开口成本：总花费/私信咨询人数。商业计划书30元内为佳。

私信留资成本：总花费/完整留资人数。约为开口成本1.5-2倍。

私信进线成本：总花费/行动按钮点击数。最能反映获客成本，商业计划书15元内最好。
