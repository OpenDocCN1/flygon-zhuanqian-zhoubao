# 二、抱团把项目跑通

## 1、先发优势带来的市场空间

刚起步时，淘宝上就一家店在卖共享账号。我们三家一起入场，基本就分走了绝大部分流量。而且那家店的链接经常掉线，我猜测可能是刷单导致被查。【我们从未做过恶意投诉举报，不碰灰色底线。】

一旦对手掉线，基本就是我们三家在卖。当时我们默契地把价格上调了一元。别小看这一元，都是净赚。

后来有家店比我们便宜一元，我在群里通知：统一调到50元或49.9元，不要卷价格。可以用赠品、教程来提升成交，但绝对不能打价格战。

价格战一开，项目就废了。之后又进来更低价的，我们价格保持不变。买家看到前面几家价格一致，后面一家异常低价，第一反应就是不靠谱。事实上那些低价多半用了灰色支付，细节不展开。

## 2、团队配合效率更高

过程中还出现过同行低价卖 Token 账号的，晓雨先发现并发到群里。我研究完流程，发现涉及手机验证，流程繁琐，成交一单后就放弃了。

后来生财上流传的无痕模式无限刷图的玩法我们也测试过，没有卖出去。

## 3、把坑填平项目才算通

做这种生意，恶意买家不可避免。小群最大的价值就是即时预警，拉黑名单，避免损失，抱团确实省心。

起初我们用邮箱验证：给账号→客户登录→点邮箱验证邮件→登录成功。后来 Discord 加强风控，多地区登录会强制改密码，改密会踢掉所有在线设备。

我们转而研究 2FA 验证，完美解决了踢号问题。

# 四、项目停掉的原因

黄校长在帖子里也说了，现在基本停了，主要有三点：

1、价格战失控：淘宝上低价产品泛滥，利润被压到几乎为零。很多人用黑卡支付，30美金的 Standard Plan 只需50块，而我们走正常汇率要210左右，根本打不赢。

2、风控收紧：国外 AI 工具基本都用 Stripe 订阅，风控极严。国内卡大概率被拒付，供应链断了就做不了。

3、需求下滑：AI 绘画工具越来越多，Stable Diffusion 功能越来越强，Midjourney 的热度自然下降，用户减少收益也减少。

2023-7-18 更新：淘宝已禁止售卖 Midjourney 账号，违规扣12分。现在只有部分天猫店和冒险的个人还在做，大部分人已经撤离。

# 五、经验总结

### 收获

1、快型项目拼执行力。看到机会立刻上架，犹豫就错过。当时一起操作的伙伴有人因太忙没跟进，直接错过一波。
2、向做得好的人学习。别人比你强就虚心请教，脸皮比利润重要。
3、每天哪怕推进一小步，也超过90%只看不做的人。

### 反思

1、没有提前搭建自动发货。流量高峰时人工跟不上，订单大量流失。应该上自动发货工具加客服系统。
2、私域用户没做二次变现。引流来的客户没有再销售，资源浪费。可以对接付费课程或佣金产品。
3、没有及时扩量。当时手里还有其他店铺，因忙就关了，损失客户。只要自动化流程打通，多店铺同时上架完全可行。
