# 从“高认知穷人”到闲鱼月入8000：三年死磕，我把这套玩法彻底摸透了

> 如果你正在犹豫要不要做闲鱼，或者做了很久却一直不出单，那这篇或许能帮你把思路理顺。

大家好，我是陈不胖。95年生人，我从不觉得自己有多聪明，只是比别人能扛、肯干。2020年全职扎进闲鱼，到现在已经三年多，主攻户外、宠物和大百货三个类目。

说说我踩过的坑。大学毕业后，我对各种线上项目特别上头，结果因为认知不够，反复被割韭菜。17到19年，我基本困在“找项目→亏钱→付费→再亏→再找”的死循环里。直到19年我才转过弯来：错的不是项目，而是自己。一个没背景、没资源、没能力、没认知的普通人，一上来就盯年入百万，等于拿30分的本事去做100分的事，不栽跟头才怪。

那两年我也没少听各种花哨的搞钱路子，但真正沉淀下来的东西几乎为零——用现在的话说，我就是“高认知穷人”。可让我彻底放下线上这条路，又实在不甘心。想了很久，决定赌最后一把：选了互联网上看起来最基础的闲鱼电商。结果到第三个月，单账号单月赚了8000。

现在回头看，真像一场豪赌。一路走来，太多人倒在了黎明前。亏掉的钱其实是小事，真正赔进去的时间和精力才最贵。正因为自己淋过雨，才想给后来人撑把伞。这篇文章，我把三年攒下的经验、整套打法都摊开讲。我不保证你单月破万，但只要你认真读完，绝对能知道闲鱼到底该怎么玩。如果非要量化，单账号单月四千，认真点真的能做到。至于“两个月赚70万”那种神话，对不起，我确实不行。

一篇文章写不完三年的细节，如果看完还有疑问，欢迎评论区交流。

先看整体框架。任何项目拆到底，无非三步：怎么搞流量？怎么提转化？怎么选产品？下面按这条线走。闲鱼的流量来源主要就两大类：搜索流量和推荐流量。推荐流量又细分出首页推荐、详情页推荐、同城推荐。从占比看，搜索最高，然后是首页推荐、详情页推荐，最后是同城推荐。所以我们先解决流量问题，再谈转化，毕竟酒香也怕巷子深。

## 1.搜索流量：如何把产品顶到全国第一

搜索流量的机制并不复杂：用户打关键词→系统根据关键词召回商品→再按商品权重排序。想吃搜索流量，第一步是把高频关键词埋进标题。但埋词只是入场券，要吃到流量大头，还得靠人为干预把排序做上去。

提醒一句：闲鱼标题只统计前30个字。

### 1.1 标题里怎么布局关键词？

每个字都很值钱，所以先找出买家真正搜得多的词。我习惯用“店侦探”插件。先列一级词，比如月亮椅在不同地方的叫法完全不一样：户外折叠椅、写生椅、钓鱼椅……如果自己想不全，就去淘宝翻销量10万+的标题，看爆款是怎么叫的。

- 写生椅 → 写生折叠椅

标题怎么组？最前面放营销词，比如“最后二十把”“店铺倒闭”，用紧迫感逼人点击。紧接着放主词“月亮椅子折叠”，让用户一眼知道你在卖什么、在做活动。后面的词可以自由组合，最后得到：

【店铺倒闭】月亮椅子折叠户外折叠椅躺椅写生折叠椅钓鱼椅便携式

注意，前置营销词是用来承载点击的，作用非常大。

### 1.2 怎么靠人工干预把排名顶上去？

标题埋词只是入场券，但位置是第一还是倒数，流量差别巨大。买家根本没耐心翻几百条链接，所以要用人工手段把排名打进前十。

准备工作：两个闲鱼账号、两个支付宝账号、一个互刷群（QQ群或贴吧能找到，找不到也可以找我要）。

第一步，先定位自己的商品。搜标题里的主词，比如“宠物尿垫”。

[PRE3]

新上架的商品没有数据积累，直接搜可能找不到。可以用这些办法筛选：

第一，卡地区。按省、市、区一级一级缩小范围，直到在前100名里找到你的商品。这个操作叫“卡地区”。

第二，卡价格。地区已经缩到区级还是找不到，就卡价格区间，以商品规格里最低价为准。这叫“卡价格”。

第三，延长关键词。前两步都试了还是找不到，就把词加长，比如改成“宠物尿垫200片”，注意千万别加营销词，然后再重复卡地区、卡价格。

定位到自己的商品后，除了头像和主图，其他能被人认出来的信息都要打码。不然别人直接搜全标题，人工干预就等于白做。

[PRE5]

第二步，拿打码图去群里找愿意操作的人。群里主动发图的，通常就是当下有空的人。

有些人会有额外要求，比如金额、类目、账号有讲究。看仔细再加，不满足就换下一位。比如有的会写“鱼小铺账号勿扰”。

加上之后，先确认类目、金额、账号。一般同类目不互相做，账号要求是没开鱼小铺的素人。如果金额差很多，比如你卖10块他卖65，先问能不能补差价，通常刷完后支付宝转差价。

第三步：双方谈妥后，对方会发来一张图。你也要把你之前打码的商品图发给他。

[PRE9]

第四步，你拿到对方的图后，用同样的方法定位他的商品。搜图片里的关键词，比如“汉兰达三爪火花塞”，如果前100个里没有同款主图和头像，就问发布地址，一级级从省到市到区，仍然找不到就卡价格。找到后截图发给对方确认链接，然后告诉他排名情况，比如“国20”“省30”。对方也在同步操作，随时沟通。

第五步，开始真正的人工干预。双方确认好链接后，要约定具体动作：

至少要满足两点：
1. 必须货比三家，让账号带上正常浏览轨迹，不扰乱人群标签；
2. 必须深度浏览，最后发两条5秒以上的语音收尾。因为之后发货会点“无需发货”，语音是确认操作的重要信号。

第六步：拍下后，约定三天后收货并好评（群里叫“收菜”）。收货当天，把店铺名、好评文案、评价图都发给对方。评价内容可以去淘宝、拼多多找，也可以用批量采集软件抓取。

多说一句：闲鱼补数据的方法很多，比如补浏览、补想要。但我的原则是能不用就不用。任何人工痕迹都可能让人群画像跑偏。闲鱼又没有付费渠道纠正画像，一旦偏了只能等它自己走正。补数据只能给本来就有潜力的链接助攻，不能让烂链接变成爆款。爆款的核心还是内容本身。要补，也优先补数据表现好的链接，表现差的直接放弃。

最后给你一组爆款参考：曝光:浏览:想要:下单:好评=10000:100:10:3:1。记住，爆款永远在下一条链接里。

## 2.推荐流量：搞懂平台的小心思

如果你不知道自己为什么成功，成功就无法复制；如果你不知道哪里失败了，失败也没有意义。很多人做闲鱼，出单不知为何出单，没单也不知从哪优化。想拿推荐流量，先要弄懂平台算法。

### 2.1 闲鱼为什么推你流量？

平台算法再复杂，底层逻辑只有一条：流量要给最能转化的人。它把用户的每个动作都变成数据，然后放进流量池里赛马。比如一个商品推给用户，用户刷到了就是曝光；感兴趣点进来就是浏览；不喜欢划走，就只有曝光没有浏览。平台把这些数据收集起来，按转化能力分层，把表现最好的前20%送进更大的流量池。

与此同时，其他卖家不断上新，持续刷新数据，抢进下一层。所以你的链接能火多久，取决于内容能不能扛住一轮又一轮筛选。

### 2.2 我们怎么迎合平台？

平台的判定链条是：推送内容→用户反馈→抓取数据→进入赛马。数据好，平台就认定你内容好，继续给你流量。由此产生两个优化方向：

一是数据技巧流：专门对着算法做人工干预，把想要数、浏览数等指标做得漂亮，让平台误以为你的商品更受欢迎。

二是内容心法流：面向真实用户，拆解数据、研究同行，提升自己的内容表达能力。

这两种打法不是二选一，而是要结合：用数据技巧把链接推过流量圈层，用内容心法把进来的流量转化掉。

## 3.如何接住流量，让进来的人下单

想优化内容，先得读懂数据。闲鱼核心数据只有五个：曝光、浏览、想要（咨询）、下单、评价。每一步都对应买家的心理和行为。哪一步出问题，就说明哪一块内容要改。

举个例子，上架后都能拿到基础曝光，商品好，点击就多；不好，曝光再高也没用。如果曝光高、浏览低，就去改主图。浏览之后没有咨询，说明文案和图片没打动他；浏览后问东问西，说明文案信息不够；浏览后直接下单，说明详情页已经彻底打消了他的顾虑。

所以看数据就等于看商品表达。有一点特别注意：单点数据再漂亮也没用，整条链路都要健康，流量才能突破圈层。

### 3.1 曝光→浏览，用户到底在看什么？

不管商品从哪里展示，用户点进来之前只能看到五个元素：

1. 主图
2. 标题前22个字
3. 价格
4. 头像和名字
5. 想要数

#### 3.1.1 主图的两个原则

第一，信息要完整清晰。用户刷到你，扫一眼就知道卖的是什么，这样的主图才算合格。

第二，卖点要突出。光知道卖什么还不够，点进来的冲动来自卖点。

闲鱼主图常见三种玩法：
- 场景代入型：强调产品使用时的舒适感，让买家自动脑补体验。
- 文字营销型：简单直接，目前最主流，制造“捡便宜”的错觉。
- 人设/量取胜型：配合人设或堆货量，营造源头直供、没有中间商的感觉。
