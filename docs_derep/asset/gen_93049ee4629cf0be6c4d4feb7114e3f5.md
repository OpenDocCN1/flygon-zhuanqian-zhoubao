# 揭秘！那些在抖音狂赚上万的AR特效道具，究竟是怎样诞生的？

不知道你在刷抖音的时候，有没有好奇过这样一个问题：那些被明星和网红们带火、动辄收获百万甚至千万次使用的AR特效道具，到底是谁在做？又是怎么做出来的？

今天咱们就来聊聊这个新兴的职业——抖音特效师，以及他们背后鲜为人知的创作生态。说实话，这个赛道现在已经是越来越热闹了，不仅普通用户热衷于用各种特效拍视频，连李现的“哪吒”、Angelababy的“在逃公主”这些爆款效果，都能在短时间内引发全网的模仿狂潮，让人人都想上去拍个同款。与此同时，平台官方也把目光投向了这群创作者，为了让更多优质特效师涌现出来，抖音不仅在道具设计大赛里豪掷重金，专门给那些拿到大师奖和人气奖的人准备了每人整整10万元的现金奖励。

那到底什么样的手艺才能在这行里混出名堂呢？

目前，我的本职工作就是一名抖音特效师。简单来说，整个流程就是先在抖音官方开放的“特效开放平台”上制作原创道具，完成后提交上去等审核。只要审核通过，这件作品就会出现在抖音的特效库里，供所有用户去玩去拍。这里头有一个很实在的规则——你投稿的特效数量越多，拿到的现金激励就越丰厚。

当然，别以为这行非得科班出身不可。做特效确实有美术底子会更有优势，但这并不代表入了门就一定要手握画笔才行。现在有很多捷径可走，比如用AI绘画直接生成素材，或者用照片建模来构建模型。而且官方很贴心地准备了一整套新手教程，叫做“认识像塑-像塑-抖音AR特效开放平台”，哪怕你是纯零基础的小白，跟着学也能一步一步上手。等熟悉了基本的操作逻辑，找个自己感兴趣的分类下手，做个作品传上去试试水，其实真的没那么难。

就拿我自己说吧，我平时常用的工具也就是Photoshop、After Effects、C4D这些老面孔，先在软件里把图案和模型弄出来，然后拿到抖音自家的Effect Creator里把特效组合起来，最后导出，再通过“特效君”这个App上传。审核一旦通过，特效就进驻抖音的原创面板；如果运气好，使用量冲上去了，还有机会被推到热门专区。而一旦进入热门区，那曝光量简直不可同日而语，收益自然水涨船高。不过你们猜，一个特效要使用多少次才能有收入？答案可能会让你意外——**只要有10个人用过，你就有奖励拿**。就我个人的经验来说，每个作品上线个几天，赚个三位数基本没啥问题。

那么问题来了，那些炫酷的素材到底是怎么快速做出来的呢？现在圈子里玩得比较花的，主要就是两招：**AI绘画**和**照片建模**。

先讲AI绘画。像Midjourney这种工具，现在已经是不少特效师的得力帮手了。具体操作大概是这样：先去官网注册个账号，然后想清楚你要的是哪类素材——插画、矢量图形还是别的什么。接着选一个契合项目气质的风格，比如手绘感、卡通风或者写实范儿。把你想转化的照片或者草图传上去，如果题材比较复杂，还可以给AI补上一些关键说明，比如你想要的场景氛围或者要素细节。之后跑一遍算法，再根据自己的喜好微调一下——色彩、线条轻重、阴影浓淡都能调，直到满意为止。最后一步就简单了，下载导出，拿去项目里直接用。

再来看照片建模。这个概念说白了就是让电脑根据现实里的照片“捏”出一个3D模型来。听起来挺黑科技，其实步骤也没那么玄乎：第一步当然是搜集照片，而且尽量要从不同角度、不同位置多拍几张，这样AI才能更准确地理解这个物体长啥样。第二步做图像预处理，裁剪、旋转、调亮度调对比度，把噪声和干扰清干净。第三步生成点云，用立体匹配、结构光扫描这类计算机视觉技术，把平面图像换成三维空间的点。第四步建表面模型，通常用三角剖分算法搞定。第五步是纹理映射，把照片本身的颜色和质感贴到模型表面上。最后渲染、优化，让模型看起来尽量逼真。如果你想省事一点，像我一样直接用“云端地球”这类平台也行，上传一组从不同角度拍好的照片，模型就能自动生成，网址都给你备好了。

其实这中间还藏着一个更有趣的玩法——**跨技能混搭**。当你把AI绘画和照片建模串联起来，先让AI生成一套多角度的图片，再拿这些图片去建模，最终得到的模型就会是全世界独一无二的，这本身就是一种天然的差异化壁垒，别人想抄都抄不了。

说到底，AR特效这个行业已经从一个刚诞生两年多的新鲜事物，慢慢长出了商业价值的雏形。随着短视频与AR技术越走越近，越来越多的人正挤进特效师这条赛道，想在创意里淘出属于自己的机遇。未来这行能卷成什么样、走出多远，说实话，值得期待。
