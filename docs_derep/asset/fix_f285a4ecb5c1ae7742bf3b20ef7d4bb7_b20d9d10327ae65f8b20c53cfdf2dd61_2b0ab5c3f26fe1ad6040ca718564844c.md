# 上周六那场向内求局，让我从参与者变成了点亮者

文 / 欧阳 思｜Youth 在* | 2023年3月29日

上周六的全国见面会，我的角色从到场听众变成了小型局的发起人。这份转身，要感谢生财社区、亦仁老师、张潇雨老师，以及那十四位同频伙伴。正是在他们的陪伴下，我切身感受到：顺着生命自然的流动，以无我利他的姿态，带着对能量的觉知去行动，不刻意抓取，惊喜便会自行抵达。

过去我对生财的认知多停留在变现层面，这次组局彻底改写了我的成见。能够在自己使命相关的议题上发起聚会，并获得信任参与，对我而言是极大的肯定。

更令我意外的是，终于如愿拿到了张潇雨老师的亲笔签名并交换了联系方式。接触下来，他本人温暖且有力量。他的播客在无数次自我怀疑期给了我锚点，辟谷的那段时间，也是他的内容一路陪我走过。

当天的分享视野很宽。我听见几位主讲人坦诚的输出，也结识到跨界的高频个体：生财及花爷团队的核心成员、年营收数百万的创业者、心理领域的前辈，以及刚踏入身心灵与内在探索的新人。

第一次当发起人，现场肯定有疏漏。十四位伙伴的包容和补位让我很感动：人数临时超额时，克寒和 Amy 迅速帮忙寻找新场地并出主意；气氛稍显疲惫时，董硕主动引导大家做冥想放松；雅芳从头到尾默默照料着大家的体验，细腻又周到。

按座位顺序，我记住的亮点如下：

雅芳的温柔体贴与低调谦和，她说对待服务对象要像对待家人；七米目标清晰，表达干净有力；董硕觉察力敏锐，能恰时给出关怀并带领冥想；恋尧的小星球传递出强烈的助人动机，也分享了近期内在探索的体会；敏敏在完成全国见面会的主程后仍赶来参与，时间把控、执行效率与待人方式都让人佩服，还特地送来一束花；兰卡对自身保持真诚，也持续以爱给到回应，几天来大家都在感慨她的反馈；克寒具备很强的号召力，兰卡、敏敏、澜澜都因他而来，他提议轮流分享当下感受，让整个空间的频率被抬升；小 z 尽管腼腆，却很大方地分享经验与干货；🔅 散发的从容自信，是我正在学习的样本；周聪展示了向内求的另一条可行路径，让我对这一群体有了更立体的认知；玉兰总结力强，提醒到位且贴心；Amy 分享了近期的心想事成案例与实用内容，让我更愿意跟随生命本身的节奏；CRAZY 对选择的道路有坚定的愿力；澜澜的感受力与直觉很强，正是理性主导的我最需要补足的部分。

这场高频的相聚给了我继续前行的定力。接下来我想做的，是持续表达感恩，向万物学习，放下执念交托，相信修炼爱与真实自在，再把爱输送出去，让自己成为一个通透的通道。

有人可能会问，身心灵 / 向内求到底指什么？我脑中闪过的答案是：它是一条让你做回你自己，我做回我自己，在广阔天地里找到使命，在人群中遇见彼此的路。走在这条路上，你能同时活成自己、内心饱满且拥有闲暇与资源。

感谢你读到这里。

——欧阳 思 | Youth 在* 2023.3.29 玛雅流日：Kin55 红天行者 波电力的蓝鹰+蓝风暴[PRE0]
