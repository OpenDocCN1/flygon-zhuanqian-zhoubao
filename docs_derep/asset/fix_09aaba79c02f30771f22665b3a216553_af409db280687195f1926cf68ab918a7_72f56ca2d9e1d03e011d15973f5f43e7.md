# 一、从寻找方向，到决定重仓AI写作

2023年，我跟着生财航海尝试用ChatGPT批量制作视频内容。那次经历让我意识到：AI带来的生产方式变化，才刚刚开始。

但当时的我并不清楚，AI究竟应该通过什么产品赚钱。既然看不清具体形态，我就先确定一个原则：后续选择项目时，优先围绕AI寻找机会。

2024年7月，我用“AI”作为检索入口，把生财里相关主题的文章、案例和结果帖逐一看过。让我注意到的是，AI写作并非只有少数人自说自话，已经有几位操盘者拿到了实际成绩，跟随学习的人也在持续推进，而不是体验几天便放弃。

之后，我重点观察了4位业内实践者的公开动态。他们有几个共同特点：

- 持续更新方法，而非停留在早期打法；
- 长期投入同一条业务线；
- 已经出现了可参考的学员成果。

经过约30天的资料整理，我从三个角度完成判断：

**第一，方向吻合。**  
它与人工智能应用有关，符合我对未来趋势的判断。

**第二，具备复制条件。**  
案例数量足够，且经过训练后，普通参与者也有机会完成交付，说明流程并非只能依靠天赋。

**第三，投入结构相对清晰。**  
前期主要消耗时间和人工，现金成本相对可控；只要把流程跑通，后续放大的空间较大。

于是，我把这项业务定为公司重点项目，开始集中资源推进。

# 二、先把交付能力做起来

## 2.1 用低门槛订单验证基本功

通过平台内的经验分享，我很早就意识到：获客只是表面，真正决定能不能长期做下去的，是交付。

所以我没有先急着招人，而是亲自去淘宝承接订单，从最基础的需求开始训练。那时我对AI辅助写论文的具体方法还不熟，过去更多是在折腾智能体，于是继续寻找靠谱的学习材料，后来接触到苏苏老师。

她的交付资料非常实用，我消化之后，前后在淘宝完成了约10份订单，并且刻意让难度逐步上升。随着项目复杂度增加，我也逐渐掌握了长篇论文、模型分析等任务的处理方式。

淘宝订单的特点很明显：报价低、回款慢、沟通成本高。但对新人来说，它仍然是一个不错的实战场。我的做法是边做边记：

- 哪些需求最容易理解偏差；
- 哪些环节最容易返工；
- 如何拆分任务和安排进度；
- 什么样的成果才算真正达到客户要求。

期间碰到过一份特别棘手的任务，我迟迟找不到解决方案。后来我先向客户收集完整材料，再主动终止订单。订单结束后，我没有把问题放下，而是继续通过视频平台学习，最终把这类任务的处理方法补上。

前后大约花了两个月，我才敢说自己具备独立完成长篇高要求论文的能力。我的原则一直很简单：先把质量守住，再考虑提升数量。

## 2.2 初期招人：渠道便宜，风险却很贵

当流量端逐渐有起色，我也有能力检查成果后，才开始考虑扩充写作人员。

最早，我们通过贴吧、豆瓣等渠道寻找兼职和全职作者，确实快速找到几位能力不错的人。后来大量铺设账号，短时间内收集到一批潜在候选者。

表面看，这是效率很高的方式；但回头看，问题也正是从这里埋下的。

## 2.3 更稳妥的人员渠道

后来我把筛选要求重新整理成三条：

1. 能独立完成任务，且实际水平经得起测试；
2. 愿意提供必要的身份及履历信息，便于建立合作约束；
3. 候选池足够宽，不能把业务压在少数几个人身上。

综合比较后，我把招聘重心转向BOSS直聘。这个渠道更便于做身份确认、能力测试和长期沟通，也更容易持续补充候选人。

# 三、获客端的两轮试验：为什么培训没有想象中容易

## 3.1 首次招募：声势不小，结果有限

交付体系基本稳定后，我开始尝试把获客方法交给更多人执行。

一次浏览平台案例时，我想到宝妈群体可能具备时间和社交传播优势，于是联系了长期合作的圈友榴莲哥，请他协助组织首批参与者。第一期项目训练营来了70多位学员。

我通过线上会议，把账号运营、内容发布和转化步骤完整讲了一遍，按照设计，每天投入约4小时即可。

不过，当时正处于需求相对平淡的阶段，账号没有出现预期中的集中爆发，订单以小额需求为主。整体成交额不算差，但参与者实际获得的收益偏低：

- 执行较好的，每月大约一两千元；
- 普通参与者，可能只有几十元；
- 也有人长时间没有收入。

一段时间后，多数人逐渐停止更新。少数坚持的人，又受到本职工作和时间安排影响，最终也没能保持原来的节奏。

## 3.2 再测一轮：问题不在教学，而在模式

自营账号的表现后来有所改善，但距离旺季仍有差距。于是我重新思考：这种依赖自营账号、再复制给学员的模式，是否天然不适合培训？

第二期项目中，我与圈友Alex合作，由他协助招募约20位参与者。我仍然采用逐人指导的方式，把获客动作拆开演示。

结果并没有明显改变：大家能赚到一些小钱，但因为前期维护动作繁杂、持续投入要求高，执行速度很快降了下来，整体流量仍然没有形成明显突破。

这两次测试让我看清了一个矛盾：

- 如果给执行者的收益比例偏低，他们缺少持续投入的动力；
- 如果提高分成，项目又会变成高交付业务；
- 一旦发生退款，已经发出去的收益通常无法追回。

因此，问题并非单纯出在培训内容，而是合作结构本身不够适合规模化。

## 3.3 从培训转向实体团队

和搭档沟通后，我们决定不再依赖松散合作，而是建立固定团队。当时摆在面前的有两条路：

**方案一：** 延续校园和内容创业路线，在高校中筛选成员，组建学生团队。  
**方案二：** 重新租赁办公地点，招聘固定人员，按照全职模式运转。

结合前两轮测试，我判断，若要稳定放大，还是需要专门投入时间的工作人员。

学生群体里当然有非常优秀的人，但筛选往往需要较大样本，而且大学课程、考试和其他安排会明显影响稳定性。此前几位能做出高播放内容的学弟学妹，甚至需要牺牲上课时间来协助项目。

我自己读大学时也经常逃课学剪辑，如今想想，确实把这份“习惯”传给了他们。

这是我第一次真正筹建实体团队。为了少走弯路，我重新整理了几位行业实践者的公开内容，最后选择付费加入饭饭的写作分工作室。

最初只是想提前避开常见问题，没想到真正遇到复杂局面时，饭饭哥多次给出了关键判断。

### 3.3.1 场地选择：别把时间浪费在无关信息上

筹备团队之初，我把目标锁定在众创空间，几乎筛查了广州各处相关场地。由于缺乏租赁经验，我还逐一查询场地背后的企业、注册情况以及负责人名下主体。

如今看来，这些工作大多没有直接帮助，更多是第一次创业时的过度谨慎。

真正决定场地是否合适的，通常只有以下几项：

1. **通勤成本**：早期负责人很可能每天工作到深夜，交通距离会直接影响精力；
2. **综合租金**：除了租金和押付方式，还要提前确认管理、停车、能源及公共区域分摊费用；
3. **周边交通**：交通越方便，招聘时可覆盖的人群范围越大。

还有一个实用建议：租约条款看不明白时，可以在闲鱼上找专业律师协助审阅。

我在大学做项目期间，就长期联系一位线上律师。每次遇到合同或合作问题，按次付费咨询，通常比自己凭感觉签字稳妥得多。

### 3.3.2 交付事故：把业务押在单个作者身上

前面提到的人员筛选漏洞，最终造成了严重后果。

早期招聘时，我们没有完整核验学历、身份及履历，只凭几次成果判断能力，随后就把大量订单交给了某位来自豆瓣的新闻学硕士。她先后拿到两笔阶段款，后来直接失联，手上还有40多份任务。

更严重的是，事后检查发现，她此前提交的内容存在大量改写痕迹，而我当时却把她当成了非常专业的作者。由于那段时间订单集中、团队又在同步筹备办公地点，人手紧张，风险没有被及时识别。

这是我至今最深的一次教训：

**任何关键环节，都不能只依靠一名核心成员。**  
一旦这个人离开，所有未完成任务、客户关系和现金流压力，都会同时暴露。

### 3.3.3 事故处理：先承担责任，再重建流程

这类问题在早期很难被察觉，等到客户集中反馈时，影响已经扩大。

我们的处理方式是逐个联系客户，解释情况、表达歉意，并根据实际进度进行退款或重新安排。多数客户在看到我们愿意正面解决后，仍然选择继续合作。

### 3.3.4 最后的连锁结果：平台账号被处理

即便已经完成退款，仍有几位客户情绪非常激烈，转而向闲鱼投诉账号。

由于我们在投诉发生前已完成退款，平台最初判定我们没有责任。但第二天，账号仍因涉及站外导流，被直接永久限制。

那一刻才真正意识到：  
平台规则、获客方式和售后风险，必须从项目设计之初就一起考虑，不能等出事后再补救。

# 写在最后

从个人接单，到稳定交付，再到招人、搭建团队、测试培训模式，我走过的每一步都不算轻松。

这条业务线并不是“学会几个提示词就能快速赚钱”。真正决定结果的，是：

- 是否能把交付质量稳定下来；
- 是否有清晰的人员筛选标准；
- 是否建立了分散风险的协作机制；
- 是否提前设计售后和平台合规方案。
