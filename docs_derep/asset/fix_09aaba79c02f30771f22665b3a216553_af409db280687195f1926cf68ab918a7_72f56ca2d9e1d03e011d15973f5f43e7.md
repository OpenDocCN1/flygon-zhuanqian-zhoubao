# 方向怎么定的

2023年跟着生财航海，用ChatGPT批量做视频内容，认知被打开了——下一波机会一定和AI相关。但当时我也懵，AI能怎么变现说实话没头绪，只有一个原则：项目选择必须围绕AI转。

2024年7月，我把“AI”当关键词，把生财站内相关帖子和中标帖全刷了一遍，出现了一个异常现象：AI写作这个赛道，有好几位头部玩家已经跑出结果，而且他们的学员也在持续跟进，不是玩玩就撤。

于是我锁定了四位在AI写作上做得比较深的大佬，逐一加了朋友圈盯了一阵，发现迭代速度很快，且长期重仓。花了一个月做调研后，我的结论是：

- 赛道向：和AI沾边，和预期一致
- 做起来难不难：有新鲜的成功案例，学员经过培训也能放大，说明可复制
- 投入产出：主要拼人力，0到1的精力成本高，但回报比可观

判断清晰后，我就把这个赛道定为公司主线，全力押注。

# 后端先行：写作能力是地基

## 淘宝起步练手

生财精华帖里反复提到后端重要，先会写再谈别的。我直接去淘宝接单，从零开始堆手感。当时我对AI写作为零，之前研究的是智能体。于是回到生财找能教AI写作的老师，最后定了苏苏老师。她的交付手册我啃完后，连续接了十来单淘宝，难度逐级抬升，直到能稳定产出几万字博士级别的稿件。

淘宝是练功场，钱少、回款慢，但锻炼价值高。我一边写一边琢磨团队怎么管。其中一单特别难，我啃不动，就把全部材料要齐后主动退单，之后靠B站和抖音自学补齐，把那个坑填上了。

两个月后，我能独立完成几万字、细节过得去的高质量交付。

带头人必须把后端当回事，自己写不出来，售前打磨、售后安抚、写手培养管理全都会卡。说直白点，创始人要懂产品，就算产品再小。

# 正式建工作室

和合伙人聊完，决定直接建工作室放大。两个方案：

1. 延续自媒体路线，在高校建创业基地，从社团里筛人组队
2. 重新落地一个实体工作室，全职招聘规范化运营

结合前两期训练营的反馈和对学生时间的判断，我认为要放大必须招全职、走规范。

优质学生可遇不可求，几十个里出一个，但出来效果很强。现在高校课业繁重，我几个能做到几十万播放的师弟师妹，经常要逃课来帮我们。

自己摸索肯定踩坑，于是又去刷几位AI写作大佬的朋友圈，最后付费加入饭饭的分工作室系统学习建立工作室的经验。起初只是想避雷，没想到后来每次遇到大坎，饭饭哥都是指路人。

### 选址那些事

建工作室初期先定场地，我把广州的众创空间全筛了一遍。第一次租场地怕踩坑，我还把每个场地的母公司老板都查了，实缴资金、名下公司全记录。现在回头看纯属瞎忙。

租场地真正重要的就几条：

1. 通勤时长：老板时间要优先，早期经常凌晨才回
2. 费用：押二付一还是押三付一、物业、停车、能耗、均摊都要谈清楚
3. 地段交通：招聘半径和地段强相关，交通方便覆盖面就大

小提示：合同看不懂就找律师。我大学做项目时就在闲鱼绑了一个线上律师，遇到问题付费咨询，拿到的建议很实在。

### 后端炸雷

之前没深度筛选的雷终于炸了。因为只看稿件质量派单，没核实学历和身份信息。一个豆瓣来的新闻学硕士拿了二期款直接跑路，手上积压四十多单。更致命的是，她的稿件全是洗的，我当时没看出来，反而觉得她很专业。人手紧只能继续用，也尽量分散风险，但爆单期叠加工作室搭建，全线告急。

这个教训我记一辈子：别把太多期望押在一个人身上，她跑的那天就是你暴雷的日子。
