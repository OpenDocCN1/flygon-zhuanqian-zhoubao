# 插件的核心文件都干嘛的

这一部分听起来会枯燥，但它是后面排错的根基。零基础的小伙伴先抓重点看懂就好，细节点不懂可以先跳过。

## manifest.json

这是插件的配置文件，格式是 JSON，必须放在项目根目录。它相当于插件的说明书，告诉浏览器这个扩展要做什么。

里面主要定义：

*   插件的名字、简介、版本号、图标
*   需要申请的权限和调用的 API
*   关联的脚本和页面，比如后台脚本 background.js、弹窗页面 popup.html 和 popup.js 等

## background.js

后台脚本，用来监听浏览器的各种事件并做协调工作。举个例子：

*   插件安装时触发
*   新标签页打开时触发
*   新书签添加时触发
*   插件图标被点击时触发...

要点：

*   能访问所有插件 API
*   不能用页面 DOM API
*   不能直接改网页内容

## popup.html

这是点击插件图标后弹出来的交互界面，用来展示信息和操作。

它可以做：

*   列出当前标签页
*   展示当前页面的信息
*   让用户一键点击图片
*   用户切换页面后自动收起...

比如视频里的案例：自动分组浏览器标签的设置面板，或者把图片切成四份的上传窗口。

## content-script.js

这个文件可以把代码注入到指定网页里，直接操作页面内容，实现插件和网页的互动。能做的事有：

*   向页面插入新元素
*   修改页面样式
*   修改页面的 DOM 结构

## options.html

这是给用户修改插件设置的页面。比如一个开关，让用户决定某个功能是否开启。
