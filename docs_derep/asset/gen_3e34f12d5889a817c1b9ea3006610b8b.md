### 标题怎么写：先被看到再被喜欢

标题决定点不点进来，图决定会不会停留。配图号的标题公式很简单：

壁纸 | 一句有感觉的话
头像 | 一句有感觉的话

比如：
壁纸 | 心有丘壑，眼存山河
头像 | 好看的 WeChat 头像来啦
壁纸 | 懒得内耗，只想变好看
头像 | 换个头像，开始新的自己
壁纸 | 今天也要温柔地活着
头像 | 这波头像真的绝了

关键是关键词必须在。壁纸/头像、手机、苹果手机、华为手机、4K 高清、全屏，这些词要固定出现，搜一搜才吃得上。标题爆了就别浪费，间隔 3-4 天再用一次，打开率依然在线。

## AI 在开发中的具体用法

### 分工逻辑

我不懂写代码，我只提需求。整体像这样：描述需求 → AI 生成代码框架 → 我看懂逻辑 → AI 调细节 → 部署测试。

我负责产品方向、用户反馈收集、审美判断、测试和运营；
AI 负责代码实现、Bug 排查、建表、API 对接、查文档；
一起决策架构，比如用哪种数据库、怎么绕过微信限制。

一开始我会问很具体的技术问题，效率很低。后来改成用需求语言沟通：描述想要的效果，让 AI 决定实现方式。
比如不好的问法：setData 后读到的数据为什么是新的。好的问法：我有一个下载按钮，点击后先判断余额再扣费再解锁图片，现在扣费和解锁一起做，容易出现没扣费就解锁，怎么解决。后者给足上下文，AI 直接给完整方案。

### 从 Idea 到 AI 再到 Business

我把分工总结成 Idea → AI → Business。
Idea 我来找问题、提想法、做审美取舍；
AI 把需求变成代码、界面、数据结构和可测试版本；
Business 交给真实用户，用访问、留存、反馈和付费来验证。

AI 不是产品经理，也不是商业决策者，更像一支可并行的执行团队。需求拆成不冲突的小任务，同时交给不同的 Agent 查资料、改页面、测试、整理文档。我在散步通勤时电脑也在推进。

[PRE2]

这也是我能在陪妈妈姐姐逛街的间隙，仍能掌握项目进度的原因。沟通的关键是把必须由我判断的事留给我，把可异步执行的交给 Agent，这让上班族也能在碎片时间持续做产品。

### AI 的沟通记忆系统

我每天 20:00-23:00 才有 3 小时做产品，第二天很容易忘昨天做了什么。每次对话都在讲背景，效率极差。

于是让 AI 每次结束时自动生成总结：解决了什么问题、做了哪些技术决策、待办清单、注意事项。存成 Markdown 放项目文件夹。开新对话第一步先让 AI 读这个文件，直接续上进度。

举例：有天晚上处理微信第三方平台 Token 刷新，搞到 23 点没搞定，让 AI 总结了问题描述、已尝试方案、未试方向。第二天打开 Claude Code，AI 直接说昨天还有个方向没试，很快就解决了。没有记忆系统，半小时背景介绍都打水漂。

### 代码只是一人公司的六分之一

回头看，我同时在做需求、创意、设计、代码、运营、销售。AI 先补上的是代码，但把产品变成生意，需要这六件事互相连起来。

## 技术选型，只选刚好够用

数据库选 Supabase，PostgreSQL 托管，有 REST API。免费额度 500MB 存储+50MB 数据库够用，Storage Bucket 支持公开 CDN，小程序直接引用 URL，零额外费用，还能网页直接管理。

部署用 Vercel，Next.js 官方托管，push 自动部署。免费、秒级、Serverless Functions 可做 API 代理。注意 Vercel 是动态 IP，微信 API 需要白名单，我用腾讯云服务器做固定 IP 中转。偶尔不稳定，手动 vercel --prod 重部署即可。

小程序框架选微信原生。学习资料最多，AI 训练数据足，出问题好找解法，减少第三方层带来的风险，调试工具也最好。需要多端再考虑 uni-app。

实际启动成本：域名 85 元/年；小程序认证×2 约 600 元；Claude Code Pro+codex 140-280 元/月；腾讯云服务器 0 元企业赠送；企业营业执照 300 元。合计约 1125 元，其中 660 元一次性。企业认证隐形价值是打通安卓苹果支付，个人认证做不到。

## 变现路径，从 0 到稳定收入

商业模式从轻到重：先广告，再付费，最后服务。

广告验证访问，付费验证价值，服务提升客单。形成需求 → 产品 → 分发 → 交易 → 复购的信任链。

最快路：微信流量主广告。小程序累计 500 独立访客即可开。工具类小程序每天打开 2-3 次，2-3 周达成。初期日收 1-5 元，后续随日活线性增长，真实被动收入。

进阶路：付费功能解锁。核心免费，高级付费。免费要好用到离不开，付费要有明确额外价值。如基础记录免费，AI 洞察、云同步、去广告、数据导出付费。用户先沉淀数据，舍不得走自然升级。

内容驱动+图片授权+服务：审美实验室模式免费浏览付费下载高清图，1-3 元一张，周月年卡可选，商业授权贵 3-5 倍。免费内容要够香，付费要有高清、商用、独家等明确增值。

平台模式最难但潜力大：工具引流 → 创作者授权 → 平台分发 → 广告分成 → 裂变。难点是微信第三方平台审核复杂、固定 IP 要求、冷启动网络效应。需要靠第一批用户破局。

## 最重要的认知

先做能用的再迭代好用。人生脚本 v1.0 只有 3 个页面，但能用，自己用一周就开始推。完美是发布的大敌。

踩坑不可避免，但可以让 AI 预判。微信限制多，API 白名单、HTML 过滤、showModal 字数、iOS 支付限制，都做到才发现。把错误信息和上下文完整给 AI，能快速爬出来。

小程序备案和网站 ICP 备案独立，不要被吓到。

做第二个产品比第一个快 10 倍。基础设施复用，新产品一周出框架。

工具类小程序最好做，有明确使用任务，留存靠功能。

把与 AI 的沟通记忆当知识库维护。每次解决的问题沉淀下来，碎片时间才能保持连续性。

选方向看复用性。用户会反复使用或帮助你反复完成同类生产任务才有价值。低频刚需复用 = 持续价值。

所有产品先自用再他用。解决自己的真实问题，是做出好产品的起点。

## 新手常见问题

Q：完全不会代码能做吗？
能。会提需求、会审美判断、愿意搞懂基本逻辑就行。代码 AI 写，你负责要什么、测对不对、问题描述清楚。核心能力是清晰描述想要的效果。跟 AI 高频沟通句式是“我有一个想法是这样子的……”

Q：要花多少钱启动？
最低小程序个人认证 30 元。想做付费建议企业认证解决 iOS 支付。AI 工具 Claude Code 月费约 140 元，按需订阅。

Q：要花多少时间？
每天晚上 20:00-23:00，利用碎片。从 0 到上线约 3-4 周，其中一半时间在思考逻辑、测试、沟通。

Q：iOS 支付怎么解决？
小程序内不能直接买虚拟商品，需走苹果内购或合规外部支付。企业认证+合规路径设计，AI 描述场景后能给出实现思路。
