# 超线性回报

很多人做事卡在“付出多少、收获多少”的直觉里，却错过了这个世界最真实的运行规律。

回报从不是线性增长的。投入翻倍，收益往往是十倍、百倍的跃迁；一个关键节点被触达，整个局面就会指数级地被打开。如果你还用直线思维去丈量努力和结果，就会一直低估杠杆、误判时机、错过拐点。

正是这种超线性的特征，构成了机会、复利、影响力、品牌乃至人生的底层逻辑。不懂它，你看到的只是一天天的忙碌；懂了它，你才会明白为什么有些人的一次突破，就能抵过别人的十年积累。

要理解世界，先要理解超线性。
