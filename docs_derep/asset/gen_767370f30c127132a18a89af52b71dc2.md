# 给还在焦虑里的新手和老炮儿的一封话

> 原文：[`www.yuque.com/for_lazy/thfiu8/xrct1g2glu1xie0g`](https://www.yuque.com/for_lazy/thfiu8/xrct1g2glu1xie0g)

先报个备：在互联网里摸爬滚打多年，生财也待了两年多。养成的唯一习惯是每天睡前抽一小时逛生财的帖子。这里的高手很多，从零到一的案例每天都在更新，能感受到圈子里一大部分人其实是焦虑的。焦虑从哪来？

生财更像是一个兵器库，各种高效利器堆满了货架。关键不是武器多，而是挑到适合自己、能拿得起的。

我美术班时老师就常说“眼高手低”。看了太多好作品，学了太多方法，却卡在落笔那一步。想通这一步，质量自然能破局。

生财的案例也是一样，每天都有小白起步变现的故事，看完总想“我也能试试”“人家能做到，我一半也行”。互联网的本质是快准狠，最后拼的还是执行力。圈里真正跑出结果的人，执行力都令人后怕。

人精力有限，同时只做一件事。先问清楚自己：想干什么？怎么变现？最匹配的是哪个赛道？我能承受多大试错成本？

我的梳理方式是先定位：
按属性分主业副业，按规模分个人或团队。

主业个人：能承受的亏损上限是多少？可动用的资金有多少？能熬多久等到正反馈？
主业团队：团队几个人？每月固定开销多少？能空耗几个月？
副业个人：同样的亏损承受力、资金储备和回本周期问题。

跟随大佬们的经验，赚钱大致分三个阶段：
初级阶段，没多少钱没资源，只能靠蛮力+极致执行去冲；
中级阶段，有点资金和团队底子后，去做周期更长、门槛更高的项目；
高级阶段，往私域和垄断生意上走，做可长期复利的买卖。

底层逻辑其实相通。我自己常用的几个打法：

一、以平台为入口做流量红利
先读懂平台人群，再反推产品。比如选视频号，人群偏40+，需求点要一个个拆出来，用数据验证。选品时要带一点门槛，传播快的地方，门槛越高越难被抄。举个例子，当地特产实景内容，成本低、真实感强，几乎没人能复制。或者直接买产品回家实拍，投入也不大。

二、以产品为核心选平台
以前做过药酒，核心人群是40+男性。属性对上视频号，于是内容就做接地气：在缸里打酒的实拍。两天被动加微信200多人，播放动辄几十万上百万。运气成分有，但多开号去试，概率就上来了。

三、用IP沉淀做质量
我们做同城相亲，就在各平台持续输出内容，给主业务导流。哪怕你是律师，也能把过往爆款选题拿来二次创作实拍，多号矩阵去做。产品本质是解决痛点，找到痛点就是找到需求。

道理大家都懂，缺的是提前把计划钉死，然后一路做到底。我们以前的执行逻辑很简单：算清楚做三个月没收入要花多少钱，把钱备好，钱没花完项目就不停。这样执行力的问题就被财务安全感解决了。

生财项目成千上万，找准自己的位置比聪明更重要。聪明有时候会害了自己。先静下来盘一遍：我有什么优势？从优势出发选项目再去执行，能解决大部分困局。

举个身边的例子，我老家在湖北潜江，小龙虾之乡。那里家家户户都养殖。做虾类的娱乐直播可以去钓虾，做内容可以拍农民清晨下田捕虾，市场交易现场也可以直播。这种素材我几乎零成本就能拿，90%的对手根本做不到，这就是降维优势。

坤哥最近又点醒了我：要不要做品牌。去年我还觉得品牌遥不可及，现在想做私域和高复购。举个极简案例：红酒，高复购品类，单瓶成本20以内。小红书人群要调性，包装走高逼格路线，瓶子1688找，酒厂罐装，几万块一盘货。淘宝买个商标，就有了自己的品牌，毛利90%以上，付费投放怎么打怎么顺。

在生财里，不会搞流量的人大多是没有把内容吃透。可以去参加精华共读航海这类训练。

回头看两年，我本就有在跑的业务，其实没必要这么焦虑。我的性格就是爱追新，这两年跑了生财80%的项目，也有小成绩，但哪个都没做到极致。什么都想抓，最后什么都抓不住。

上个月看到梁靠谱在推生财拉新，执行力那两个字是真名副其实。我也进了群，后来和静伟说了，精力有限，这波不参与。

我写东西逻辑确实一般，四月在休整，天天琢磨接下来的一年五年十年要干嘛，然后一个人去钓鱼，挺好的。

这两年我都是在圈子里追着项目跑，累。找准定位很重要：

1. 我的核心优势是什么？做什么内容我能轻松做到高质量输出？
2. 未来一年我要赚多少钱？选的项目做到行业中游能否达成目标？
3. 执行力要拉满，管不住自己就用外部机制管。我年前做直播经常摸鱼，就招了两个员工，有人盯着就不好意思划水了。
4. 一次只做一件事，等这件事能脱手了再去碰下一个。作为个人创业者，我称不上顶尖，但也过得去，目前有两个项目稳定运营多年，已经能做到不天天盯着。

最后送一句话给焦虑的朋友：先用心把一个点做透，两耳不闻窗外事。把一件事做成，自信才会上来，后面才能游刃有余。
