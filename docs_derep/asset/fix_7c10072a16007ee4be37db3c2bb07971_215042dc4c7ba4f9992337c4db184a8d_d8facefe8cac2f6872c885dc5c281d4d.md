# 一、我为什么选得物？

先交代背景。我做内容创作已经四年了，图文、公众号、社群这些事情都折腾过，也卖过一些课。现在花时间最多的地方之一，就是得物。账号叫北樱，粉丝不算多，但累计阅读量已经超过17万，合作过多个知名美妆和珠宝品牌，也被得物的官方活动邀请去当过答疑学姐。

一开始我也没想过它能有这么多门道。接触久了才发现，这个平台对没资源、没团队的个人特别友好，主要体现在两点上。

**第一点，起步门槛极低。** 新注册的账号连一个粉丝都不用，就能参与带货分成和短视频现金激励。想开通正式的推广权限，也不需要攒到一百粉，注册后的头两个星期里，发出去的笔记有12篇阅读量超过500，权限就会自动解锁。

**第二点，对新人很宽容。** 你不需要是专家，也不需要懂什么高深的成分理论。平台真正想看到的，是你作为真实买家用过之后的感受。

这一点拿小红书来对比就特别直观。同样一款产品，如果按照小红书那种偏专业、偏种草文的套路来写，放到得物反而不讨好，品牌合作那边也过不了审。得物想要的就是那种更生活化、更有人情味的使用体验。

那什么样的人适合来玩？大学生、家里有娃的妈妈、下班比较早的上班族，都挺合适。一个推广任务通常是4到8张图片外加300字以内的文字，熟练之后，半小时就能产出一单。平时每天花一两个小时，时间久了，积累起来的数字是很可观的。

作为一个做了四年内容的人，我见过的赚钱路子无非三种：第一种，靠新媒体技能去拿一份工资；第二种，靠内容帮商家做推广，赚品牌的投放预算；第三种，靠个人品牌去影响用户，让用户愿意为你的价值付费。

这三种方式各有各的优缺点：工作变现启动最快，但收入上限有限；个人品牌前期启动不算慢，跑起来之后增速很猛；博主变现前期最熬人，可一旦数据稳定下来，长期收益是最可观的。

得物这种玩法，本质上就属于第三种。

我身边有不少深耕这个平台的朋友。大家一致的感受是：号做得越久，主动找上门的合作就越好。有一个朋友做了差不多一年，现在手里的定向邀约几乎没有断过，很多品牌还会定期复投。

# 二、在得物，钱到底从哪来？

先把底层逻辑讲清楚。

得物每个单品页都有一个“开箱精选”的区域。用户发布的使用感受、开箱实拍，只要挂上对应购买链接，就有机会被收录进去。这种内容的核心价值，是帮别的买家在付款之前，更全面地了解这款东西到底怎么样，从而做出更合适的选择。

举个例子，一款DW的粉底液，光是看官方宣传图可能看不出真实妆效，但一段几十秒的开箱视频，就能把色号、遮瑕力、持妆效果都展示得明明白白。

[PRE7]

[PRE8]

具体来说，赚钱的口子主要有四个。

**第一个口子：付费推广任务。** 这也是大部分做得物的人最主要的收入来源。普通投稿类任务，一条报酬在20到100元之间；品牌点名邀约的定向类任务，最低100元起步。平时用零碎时间就能完成，账号等级到达二级之后，接单数量不再设上限，时间充裕就多接一些。

需要注意，这个模式不是今天发明天就有钱，从零到稳定出单大约需要37天左右的沉淀期。但只要账号热度上来，粉丝多了、阅读高了，后续的单价和单量都会跟着往上涨，月入过万是完全可以实现的。

内容要求也很简单：图文类需要6到8张图加300字以内的文案；短视频类，30到60秒就够。

开通条件前面提过：注册后两周内，发布的笔记中有12篇阅读量达到500。这个功能可以理解为小红书蒲公英合作平台的低配版，但得物的门槛要柔和得多。

[PRE9]

付费推广任务又分成两种玩法。

一种叫自由投稿。创作者在后台看到公开任务池，自己挑感兴趣的任务报名，商家再从报名者中筛选。账号等级到二级后，每月不限次数，只要照片拍得好、账号热度稳定，一个月接到15到20单并不难。拿到的实物可以自己留着，也可以挂闲鱼转手。升到三级后，还能解锁达人专享的上百元任务，每天19点准时上新。这个需要自己去蹲，但账号流量好的话，数据够亮眼，就算名额满了也有机会插队进去。

[PRE10]

[PRE11]

另一种叫定向邀约，也是圈内公认最赚钱的方式。以前这个功能要500粉丝才能开通，9月份改版后不再看粉丝数，账号升到三级就会自动开放。品牌方会在商家后台看到你的公开数据，觉得合适就发来合作邀约，双方聊好之后，再由系统派发任务。定向邀约的报价是由达人自己填的，刚满一百粉的阶段，最低也能标到100元一篇。

按一个月只接10个定向邀约来算，纯现金收益至少1000元，再把品牌寄来的实物价值算上，整体月收入超过3000完全没有问题。账号等级越高、照片越出片、数据越好看，这个数字还会继续往上走。

**第二个口子：短视频播放奖励。** 平台根据视频的播放量、完播率等综合数据，给出相应的现金奖励。折算下来大概是10元/千次播放，非常适合擅长剪辑、喜欢做二创的玩家。漫剪、影视混剪、娱乐号、美食号，都能靠这个赚到钱。

这个口子最大的优点是变现周期短。头一天发出去的视频，第二天就能在收益中心看到结算，直接提现。运营上也不需要什么复杂技巧，剪好的片子直接发就行，一天保持3到5条的更新频率，一个月下来纯靠播放奖励也能攒不少。

**7月：新手期，合计316元。**

那会儿我好不容易才把粉丝磨到100，顺利开通了品牌合作权限。但账号等级只有Lv.0，每天仅有5次报名机会，结果怎么报都报不中。后来才明白，不是我不够努力，是自己的账号压根没达到品牌方的筛选标准。

新手最容易忽略的问题，其实就三个关键词：内容垂直度、照片质量、账号流量。

首先，内容垂直度很重要。做这个不需要多专业，但账号一定要有明确的定位。比如我的定位是护肤美妆，那我发的所有笔记都围绕这个方向来。这样吸引来的粉丝本身就是护肤美妆的受众，品牌方看了也会更信任你。旧版的得物创作者中心还能直接看到账号领域和垂直度，改版后虽然不展示了，但这并不代表它不重要——我专门问过合作过的美妆PR，对方明确表示，垂直依然是选人的第一标准。

[PRE24]

[PRE25]

其次，照片质量决定了第一印象。前期可以花点小钱置办一些拍摄道具，比如小摆件、托盘、背景纸、反光板，再配一盏补光灯；没有补光灯的话，用普通台灯也够用。构图不好不要紧，直接在App里搜索同类产品的热门笔记，看看别人是怎么拍的，照着模仿就行。

最后，账号流量是底层支撑。做公域内容，流量就是一切。品牌方投广告，本质上就是为了获得曝光。你可以通过近半个月的笔记阅读数据，来快速判断自己的位置：

平均阅读不到100，基本不用指望接到推广；
100到300，可以试试报名人数少的任务；
300以上，大部分投稿都能顺利通过；
500以上，恭喜你，已经有品牌开始主动来找你了；
到了1000以上，那就不用投什么稿了，坐在家里等合作找上门就好。

想提升流量，可以多参加官方的主题活动，不仅能获得额外的流量助推，还能拿到流量券和无门槛优惠券。入口在“我的-创作中心-创作灵感”里。

**8月：探索期，合计1758元。**

这个月升到了Lv.1和Lv.2，有几天流量爆棚，连中了两个百元定向邀约，自由投稿也通过了不少。但问题也随之暴露出来：我当时完全是靠流量硬撑着，账号内容混乱，一会儿接饰品一会儿接护肤品，定位一塌糊涂。

最明显的短板是拍照。拿到一个产品，总是不知道从哪里下手，构图全凭感觉，标题也要想半天。

这个月下定决心专心做护肤美妆赛道，放弃了配饰。

对于必须拍视频的任务，我也有了自己的制作流程：先写文案，再根据文案去补拍画面，最后剪辑合成。得物的视频时长只需要30到60秒，对应300字左右的文案就够了。

# 四、想少走弯路？先选对赛道

赛道选得好，至少能省掉一半力气。得物目前最热门的内容方向大致有六个，大家可以根据自己的兴趣、手上的资源和擅长的事情去挑。

女生的话，可以从手边的美妆、护肤、饰品开始；男生可以考虑数码电子方向；穿搭和家居则属于男女通用的赛道。

**第一个大类：美妆与护肤。**

得物的用户群体非常年轻，对护肤和彩妆的热情也相当高。现在越来越多人注重外在形象的维护，这类内容天然自带关注度。

[PRE45]

如果你的唇形好看，那做美妆简直开挂——随便拍几只口红试色，就是一篇完整的笔记，完全不用费心考虑选题。

[PRE46]

在这个赛道里，比较容易出爆款的内容方向有三个：

**1）新品抢先测。** 每一次新护肤、彩妆品上市，都是一波流量红利。第一时间入手并发布测评，认真记录质地、气味、涂抹后的肤感，再给出初步的效果反馈：美白、保湿、还是抗皱，总有一批人正在等着看真实评价。一些大牌产品因為自带关注度，更是天然流量入口。

**2）护肤流程教学。** 从最基础的清洁开始，把洁面、爽肤水、精华、乳液、面霜的搭配和用法一步步拆开讲清楚，再补充不同肤质的产品选择建议。这种内容收藏率极高，容易在长尾时间持续获得阅读。

**3）创意妆容教学。** 针对不同场合，给出可复制的妆容方案。日常上课上班，走自然清新的路线；派对聚会，可以更大胆张扬，突出个性和魅力；职场通勤，则以得体大方为主。把每一步、每个产品都拆解出来，让粉丝能直接照着画。
