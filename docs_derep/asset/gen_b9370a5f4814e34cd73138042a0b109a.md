大家好，我是逸尘。今天复盘一个几乎随手做的副业小实验：一个原本只是给自己用的锁屏工具，从想到收费到收到第一笔收入，撑死了不到一天。过程并不标准，甚至有点乱，但里面的验证思路，我觉得很值得拿出来聊聊。

## 一、我用的变现闭环是什么

核心很简单：把做好的安卓 APK 扔到夸克网盘，然后把网盘链接挂到小红书的个人售卖里并关联到笔记里。这样一单能吃到两层收益：小红书个人售卖的货款 + 夸克的拉新奖励。

为什么偏偏选个人售卖而不是个人店铺？

个人售卖对软件类只收 0.5% 服务费，个人店铺要收 2% 手续费。个人售卖还能开免佣自动发货，真正做到躺赚；而且不展示销量和差评，售后压力小很多。

### 这套打法的优势在哪

对比市面上常见的 AI 编程变现路子：iOS 上架要交 99 美元年费；做 Web 要买域名、等 Adsense、变现周期长；做 Web 工具还要接登录订阅，Cream、Stripe 这些接入门槛高；搞编程社群又需要大 IP 背书。

而小红书个人售卖卖安装包，门槛就是一个功能能用的软件。AI 功能可以后期再加，也可以让用户自取密钥实现买断或订阅制。整个从发笔记到出单，快的 1 小时就能变现。

我当时纯自用心态，没做其他变现分支，后续的一些延展想法我会在后面补上。

## 二、这个产品是怎么冒出来的

去年听涛哥线下分享，他提到把每日待办写在锁屏屏保上能大幅提升效率。想法很打动我，但自己画图换屏太麻烦，就先扔进了灵感库。

后来一次用 vibe coding 让 AI 跑代码的空档，我翻到这个灵感。刚好 GPT 5.1 出来，就随手把它实现了，当天就写完顺手发到了小红书。

产品名字叫“逐梦”，现在迭代到 V3.0。锁屏效果大家可以感受一下。实际上 V1.0 非常粗糙，当时我直接免费送，V2.0 才开始收费，具体原因后面讲。

## 三、从 0 到 V3 的完整走法

### 1. 选开发环境

电脑换了，原来的 Codex 对话记录找不到了，只能文字复盘。当时 GPT 已充值，Codex 免费，Antigravity 还没出来，Claude Code 又太贵，最后用 VSCode + Codex 性价比最高。

### 2. 定框架和写需求

我把功能点口述给 AI，让它判断能不能做。安卓为先，未来想桌面化。

我问能不能做，AI 推荐 Flutter 跨端。确认华为、小米、红米都能兼容后，我让它基于产品背景写一份 PRD 级别的需求文档，并用 ASCII 画原型保存成 Markdown。

AI 一口气写完，我让它按文档直接开工。起名时我给了方向，AI 给了几个备选，最后定为“逐梦”。

Codex 对于这种小项目一次就能成型，文档越清晰成品越准。后期把默认占位图换成自己想要的 Logo，没 Antigravity 的可以去图站找个 1:1 图放进去。

### 8. V3.0 迭代提价

根据用户反馈和自己的产品经理判断，我做了 V3.0。表面看功能变少了，其实是把功能下沉到二级菜单，让一级更简洁。上手更快，更干净漂亮。

这个版本主要靠 Antigravity 的 Gemini 3 Pro 做前端重构，我只给了需求：把繁琐功能合并，优化 UI。改完再让 GPT 5.2 修 Bug。

完成后单价从 8 元提到 9.99 元，出单率基本没受影响。因为这个细分赛道几乎没安卓竞品，iOS 的用户也流不进来。

## 四、如果想做大收入，可以怎么扩

### 1. 流量为王

发笔记、投流、截流、合作四种方式。发笔记最划算，找对标高赞笔记做微创新，标题保留核心关键词埋 SEO。投流不建议，赚头不多。截流就是去竞品评论区找“求安卓”的用户私信，每天有次数限制。合作是最舒服的，我就和那个 iOS 对标博主互相导流。

### 2. 升级用户画像

可以把锁屏工具做成大的时间管理 APP，但竞争会变大，周期更长，适合想拿融资的路线。

### 3. 对接后端

后续可以接订阅、AI 密钥等商业化，但我暂时没精力。
