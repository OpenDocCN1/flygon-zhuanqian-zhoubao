# 大就是底牌：当体量变成谈判筹码时，行业老大在玩什么

体量本身就能换来特权，这一逻辑在商业里反复上演。市场头部的玩家，往往不是靠产品多好赢来话语权，而是靠“我大”这件事，让整个生态被迫配合。

拿恒大在巅峰期的做法来看就很典型。彼时地产龙头，手握全国项目和海量工程量，门窗、瓷砖、建材这些上游供应商，谁都想挤进来。于是许家印直接把合作门槛抬高：想供货，先拿钱入股恒大，十亿八亿的注资成了入场券。不少行业内的龙头企业当时都是被动参股，换来的是采购名额。相比现在一些大渠道商只是被供应商追着示好，当年的恒大是明文规定，不入股就别想谈单。

钱还只是其一，更狠的是账期。作为大买家，恒大完全可以让供应商先垫资做事，工程款拖到一年后甚至房子卖完再结。这种模式本质上是把产业链的现金流和原材料都先借用过来，自己先把生意做完、利润落袋再结算。正是这种“店大欺客”的体量优势，为恒大不断输血。

类似的玩法，中国高铁在引进技术时也用过。当年铁总不允许分公司自行去欧洲谈采买，而是把所有需求汇总成一个巨型订单集中出海。订单规模足够大，法国、德国这些供应商自然不敢怠慢。于是中国不仅拿到装备采购，还把技术转让和本土工程师培训写进了合同，把集中采购的力量转化成了技术输入。

恒大的案例说明，规模一旦达到临界点，规则就可以由你来定。这种以地位换利益的操作，从纯竞争角度看理所当然，甚至是理应做的。

但同样的地位，也能走另一条路。华为曾公开表态，不能让自己的供应商赚不到钱，这已经超出了单纯的利益攫取。胖东来也说过，如果上游没挣到钱，就是自己的管理失败，得想办法帮供应商一起赚钱。

一家企业最终是选择用体量去压榨，还是用体量去共建，决定了它能走多远。
