# 亦仁提醒：收藏内容，不等于投资建议

前几天，亦仁在内容中提到 BTC，随后有圈友来询问：这是不是意味着他在推荐比特币？

对此，他专门作出说明：

收藏夹里的文章和观点，只是他筛选后认为“对自己有价值”的内容。收藏、转发或关注，并不代表对某种产品、项目或投资标的背书，更不构成任何形式的投资建议。

面对投资，最重要的不是寻找所谓的“财富密码”，而是保持独立判断。真正需要牢记的是：

**不了解，就不要轻易买入；如果赚了，是自己的判断和能力；如果亏了，也必须自己承担结果。**

他也提到，希望大家不要对收藏夹设置过高期待。若每一条内容都要反复规避风险、谨慎到失去表达空间，最后留下的可能只会是宽泛、空洞、没有实际价值的文章。

评论区里，有人表示收到，也有人开玩笑说是不是终于想起了某个密码。还有圈友感慨，投资中很多人习惯“抄作业”，不愿意自己研究，总想着听到一句提示就立刻冲进去。可如果始终缺乏独立思考，恐怕很难真正迈入投资的大门。

也有人分享了自己认识 BTC 的过程：从最初觉得它像传销，到逐渐产生疑问，再到了解主权个人、货币去中心化等概念，后来结合圈友交流和相关书文章内容，才开始尝试定投。

当然，这些都只是个人经历和看法，不代表任何投资推荐。

成年人要对自己的选择负责。别人分享的是信息，真正做决定的人，始终是自己。
