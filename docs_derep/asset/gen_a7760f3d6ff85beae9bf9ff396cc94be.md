# 别再把成功学当毒鸡汤了：一条普通人真能复制的成功路径

成功这件事，到底有没有规律可循？

那些摆在书店显眼位置的成功学书籍、那些被反复传颂的名人传记，我们读了一本又一本，可日子还是原来的日子，处境还是原来的处境，生活连一丝波纹都没泛起。于是很多人心里悄悄刻下一句话：成功学就是骗人的，是已经上岸的人编出来糊弄后来者的，谁当真谁就输了。

说句实在话，我对成功学同样抱有偏见，也不太爱看这类东西。正因为如此，我才想给它换一套标准，重新定义什么才配叫成功学。

在我看来，一套成功法则要过两道关，才有资格被称作成功学。

**第一道关：任何时代都能复制。**

如果一条法则高度依赖运气，得靠天时地利人和凑齐了才灵验，那它本质上就复制不了——你学了也白学。我要找的是那种放之四海皆准的法则，不奢求百分之百照搬，但至少多数人照着做，就能一步步靠近成功。就像一本靠谱的菜谱，你按着步骤来，手艺练熟了，端上桌的菜差不到哪去。

**第二道关：普通人也能复制。**

如果一条法则对能力、对认知的要求高得离谱，那它同样不在我的考虑范围内。比如孙宇晨那类人，天资聪颖、擅长投机，你要是也有那份脑子和认知，确实能折腾出不少名堂。可门槛太高，普通人根本学不来。这就像开飞机能脱贫，但你得先当上飞行员——而绝大多数人压根不具备飞行员的素质，这就很尴尬了。

天赋平平、资源有限的人也能照着做，这才算得上好的成功法则。两条标准都占齐了，基本就靠谱了。

那这样的法则，到底存不存在？

这一年我边学边想边试，还真摸到了一条简单、能落地的路子。它来自营销学和网络科学，不是拍脑袋的经验之谈，而是契合这个世界运转方式的规律。自从弄懂它，我就一直在用，效果确实奇妙：短短半年，一个原本只有两千五百粉丝的公众号被救活了，一路涨到三万；知乎、今日头条、简书也接连给我正反馈，仿佛在告诉我——这条路走对了。

这个思维模型，叫**“成为第一”**。到目前为止，我认为它是最好的成功法则。

**为什么非得争第一**

“成为第一”听着挺玄乎，好像落不了地，它真有那么神？具体怎么操作，我打算另开几期细讲，这一期先聊聊它神在哪、背后藏着什么规律、本质又是什么。

**①强者愈强，赢家通吃**

“强者愈强”绝不是一句空话，它背后有事物运行的道理。有一门新兴学科叫**网络科学**，说的就是我们每个人都活在一张巨网里，而在这张网中，强者比弱者占的优势更多；网越铺越大，强者的优势就越滚越强。

美国物理学家巴拉巴西做过一个实验，把人与人之间的连接抽象成小球构成的网状结构。他先用计算机随机生成一批大小不一的小球，再模拟人际连接写了一套复杂算法，这里可以简化成“偏好选择”——每生成一个新小球，它会随机连上网络里任意一个球，但连上大球的概率更高。这就像现实里我们谁都能遇见，可一旦遇上问题，总更愿意去找那些厉害的人请教、合作、交朋友。

巴拉巴西不断往网络里扔新小球，渐渐地出现一个现象：最大的那个球越滚越大，开始把第二名甩在身后；小球数量越多，差距拉得越开，直到它一骑绝尘、一家独大。这就是“强者愈强，赢家通吃”的本质。

当然，这是理想模型，好比经济学里的假设，只用来解释现象，不等于现实本身。现实中强者也会倒下，原因五花八门：组织臃肿、故步自封、缺乏创新、时代浪潮翻涌等等。但这套底层逻辑值得借鉴——当你成了第一，认识你的人越多，你就越强；你越强，认识你的人就越多……如此循环叠加，最终强者愈强，赢家通吃。

拿我自己举例：我在知乎写的那篇《费曼学习法》，因为比别人写得好，点赞的人多，被顶到搜索榜第一；又因为排在第一，每次有人搜“费曼学习法”都会看到它，于是带来更多点赞……循环往复，强者愈强。今天的腾讯和阿里也是如此，只要不出大的变故，它们只会越来越强。

**②权威思维**

成为第一还有第二个好处，这跟人性有关。当你成了第一、成了专家，就能赢得更多人的信任和支持。我们的大脑天生不爱独立思考，一旦有位权威人士站出来指路，我们简直求之不得。

生活里常有这样的场景：一群人忙完事凑在一起准备吃饭，问题来了——去哪吃？回答多半是“随便”“都行”“只要别吃某某就行”。可要是这时有个资深吃货跳出来说：“我知道有家店，他家的某某特别好吃，好多富豪不远千里就为这一口，还不贵，走走走，我带你们去。”除非有特殊情况，大多数人都会放下自己的主意，跟着这位吃货走。

我们天性里就需要一个权威来引领，只要他够牛、能带我们走向成功，我们就愿意追随。我作为表达者，深知权威思维有多强大：你寂寂无名时，话说得再对也没人信；可一旦成了某个领域的专家，哪怕随口一句，也会被人反复琢磨、奉为至宝。所以，想让你说的话有分量、想赢得别人的支持与信任，成为专家、成为第一，几乎是必需的。

**③心智容量有限，人们只记得第一名**

第三个理由来自营销学，你很难抗拒。知名品牌战略公司华与华有句经典的话：“在一个行业里，用户只能记住那么一两个品牌，第一名赢家通吃，第二名勉强分一杯羹，第三名基本盈亏持平，剩下的全是陪跑。”

为什么会这样？跟我们的心智有关。有本书被誉为“商业人士必读书”“美国营销行业有史以来影响最大的书”“美国史上百本最佳商业经典第一名”“美国CEO最怕被竞争对手读到的商界奇书”，它叫《定位》。顺便说一句，上面这串头衔本身就是在活用权威思维——它是当之无愧的第一，拿来当论据自然有说服力。

《定位》告诉我们一个叫**心智**的东西：每个人的心智容量都有限，对同一类事物只留很少几个名额，其中第一名占去大部分，剩下的只能分到一点点。电商行业第一是谁？淘宝（天猫）；第二是谁？京东；第三是谁？不知道。第一个登上月球的是谁？阿姆斯特朗；第二个是谁？不知道。世界第一高峰是哪座？珠穆朗玛峰；第二高峰是哪座？不知道。

人的心智有限，第一名占去大半，第一名之下默默无闻。想成功，就努力让你做的事成为别人心智里的第一，这样人们才记得住你。

**④成为第一，你的价值将无人能及**

我上一周的文章里提过，成功的本质，是你的存在本身能给很多人带来巨大价值。投机倒把也能成事，但终究不长久；想一直成功下去，就得守商业的规矩——源源不断地给别人提供价值。也就是说，所谓成功，其实是你比竞争对手提供的价值更多。他能给用户十块钱的价值，你能给一百块，用户就选你。用户不傻，谁给的价值多，他们就选谁。

那怎样才能比对手提供更多价值？经济学里有个理论叫**规模效应**：如果你是行业老大，就具备规模优势，边际成本比别人低、质量比别人好、效率比别人高，你就再没有敌人。别忘了，强者愈强，赢家通吃。

可惜很多人不懂这个道理。我看到的景象是：大多数人不知道自己这辈子要干什么，频繁换跑道，一年换四份工作。听人说这行前景好，就去做这行；过阵子听说某某工作工资高，又跳过去；干一阵不适应，再跳槽……他从来没在一个行业里深耕，做到第一。没有第一就很难形成规模优势，没有规模优势价值就不大，谁都能替代你。所以你不成功很正常，成功了才不正常。

再举个例子。经常有人向我请教自媒体的问题，我发现他们做不起来，最大的原因不是写作能力差，而是定位出了问题。他们写得太杂，什么都写：一会儿追热点，一会儿记日记，一会儿发感悟，一会儿写书评，一会儿聊职场，一会儿谈情感……这会导致什么？每个领域他都成不了第一。写热点，你写得过专业追热点的人吗？写情感，你写得过咪蒙吗？写日记、写感悟，你写得过一本经典书籍吗？

读者凭什么选你？看情感，我为什么不看王泽鹏而看你？看职场，我为什么不看插座学院而看你？看认知，我为什么不看经典而看你？如果人家样样比你强，你存在的价值就体现不出来。道理再简单不过：任何一篇文章都有人写得比你好，我为什么要看你的？除非我不认识那些巨人，只认识你——在我的心智里你是第一，这时我才会看。

所以想成功，你就必须比对手提供更多价值。什么情况下才能做到？靠不断深耕，直到有一天你的成本最低、质量最好、效益最高，你成了第一，这时你就再没有敌人。

**“成为第一”到底指什么**

看到这里你也许还有点懵，似懂非懂，没关系，我们再往深里说一说。

**①心智第一**

第一不是你自己说了算，而是用户说了算。在用户心智里你是第一，你就是第一。比如你的文章本来写得一般，但你的读者没读过比你更牛的文章，那在他的心智里你就是第一。所以别灰心，任何时候你都可以成为第一。区别只在于：一开始你是少数人心智里的第一，继续深耕，你会成为更多人心智里的第一。

**②价值第一**

你能给用户提供的价值比别人高，成本比别人低，质量比别人好，效率比别人高。到了这个状态，你就再没有敌人。当然，你还得宣传，让更多人知道你最能提供价值——酒再香，也怕巷子深。

曾有人跟我讲过一个挺有意思的理论：爱情其实也是这样，我们永远在选择一个价值更高的人。所以你要做的就两件事：第一，提升自己的价值，成为对方心智里的第一；第二，让更多人知道你，俗称流量。

**怎么成为第一**

我给三个方法：**深耕细作、与众不同、阶梯攀升**。具体下次文章再聊，其中深耕细作和与众不同是两个极重要的思维模型，值得单独拿出来讲。

**经典案例**

最后分享一位我很敬佩的巨人——蔡志忠先生。我能悟到这条法则，要多谢他，他本人就是“成为第一”的忠实践行者。

蔡志忠先生说，他四岁半就认定要画画，十五岁成为职业漫画家，第一本《庄子说》连续十个月拿下金石堂畅销书榜首，也是第一个用漫画形式向世界分享庄子、老子、孔子等思想的漫画家。2011年，他获“金漫奖”终身成就奖，一生都在这一个领域里深耕细作。

最后，把蔡志忠先生的一句话送给大家：

老师说“努力就会成功”，其实那是善意的谎言，没有人不努力。努力没法让你走到成功，更重要的是选择——选自己最拿手、最喜欢的，把它做到极致，无论做什么，没有不成功的。
