# 一、笔记该怎么呈现

定位已经定在“自媒体”后，最关键的是选对呈现形式。我把这套摸索总结成三步：先收集、再归类、后判断。

## 🔴收集

起步先拿3-5天，把同行笔记通吃一遍。乔布斯说创新是旧元素的重组，脑子里没素材就组合不了。

常用四种做法

#### 关键词搜

关键词是入口。搜到别人内容，也方便别人搜到你。

自媒体相关词：自媒体运营、小红书运营、发帖时间、Vlog选题、脚本、新人博主、人设、赛道、账号搭建、拍摄技巧、剪辑工具、定位、爆款标题、爆款关键词、怎么做内容、下班后做自媒体、自媒体人常用网站、黄金发布时间……

起初抓5-6个核心词就够了，靠小红书的下拉推荐和笔记标题里继续挖词，滚雪球一样越挖越多，像玩密室逃脱。

#### 话题蹲

看同行笔记下挂了哪些话题，把相关标签一并收藏。像仓鼠囤粮一样攒着，每天刷一刷。

建议先把关键词和首页法跑通再用话题法，不然推荐会跑偏。

#### 首页刷

大数据比你更懂你。看完相关笔记后回到首页，出现的推荐号就是新线索。

刷的时候要明确：点图文不点视频、点自媒体不点娱乐、点想学的别点想看的。杨幂比基尼、蔡徐坤王俊凯、辣火锅、婆婆语录、单位八卦、线性代数、八段锦、凡人修仙传……这些能忍就别点。

运气也很重要。首页恰好推给你一个低粉高赞的对标号，等于平台在给你投赞成票。为此我常换三个手机同时刷，声源多方向来，更清晰。

#### 工具查

想快就用蝉妈妈、新红的“低粉高赞”功能，按赛道或关键词筛，数据还能导出。短期会员去闲鱼拼夕夕找优惠。

手动刷能练网感，工具党效率高，各凭喜好。

刷完一轮，你对爆款选题和呈现风格会形成直观画面。下一步是把画面量化。

## 🔴判断

选形式起号看两点：A.这个形式长期有流量；B.最近流量在涨。

平台会推内容，推了才有量。

我的观察：

1. 备忘录在自媒体领域一直稳定吃香，两三年都有长尾号，这条适合打持久战。
2. 3月“开局一张图”火爆，5-6月又转回图文为主。

3. 平台推法会变，起号前必须观察。
4. 流量会衰减，风格要跟。看似选题不变，实则形式要换，四个字：跟随潮流！

先整理出10种可做的笔记形式，再筛出当前平台在力推的2-3种，用几个号同时赛马。数据好的形式再集中投放。调研完才是开始，选对了形式，后续选题自然顺水推舟。

直觉是可以练出来的，刚开始靠理性分析，后面会变成网感，像考驾照一样练出来。

# 二、爆款选题怎么找

形式定了，就找选题。说个现象：自媒体圈都在聊“香积寺之战”，发这个基本有量。唐朝两军互砍，盛唐拐点，情绪上意难平。像张小凡碧瑶的爱情也一样，情绪点被戳中就传播。

核心是找到你领域里的30个“香积寺之战”。

找法：确定形式后账号推荐已经刷熟练了，用首页、关键词、话题法把同行数据抓出来分析。

把过程游戏化比较好，受反馈不确定，游戏化能降低焦虑。投入越多越想回报，当成游戏反而更轻松。

## 常见爆款类型

#### 问题类
技能类永恒的话题：怎么做、怎样做。自媒体怎么定位、怎么找对标、怎么变现；做饭怎么买菜怎么切菜。关键词“如何”“怎样”就是选题矿。

#### 工具类
人对工具有迷信。自媒体文案排版工具、做图工具、剪辑工具，搜一搜流量巨大。

#### 书单类
互联网之前，解决问题靠看书和问人。亲子育儿书单、女性成长书单、创业书单，在小红书一直有量。

#### 娱乐类
减肥账号用“秦昊减肥法”出圈；过年期间“热辣滚烫”把减肥和贾玲绑定；杨幂同款、王一博同款DUNK……情绪和热梗永远有用。

起号前几篇一定要放王炸。选题也带周期感。去年春节前发《2024上半年自媒体风口》，大爆却没持续跟进，白白错过。

私域账号也在商家节日节点冲：五一发的5.1活动笔记爆了，春节也一样。顺风时出海省力很多。

# 三、内容怎么讲

“七分选题三分内容”没错，但我曾以为内容不重要，错了。选题解决能不能被看见，内容解决看完后会不会加你。心脏和大脑重要，不代表手脚胃脾不重要。

内容类型举例：涨粉型、引导型、干货型、互动型……

#### 涨粉型内容
粉丝=权威光环。互联网嘴替就是一种：用电影《年会不能停》讲打工人的无奈，对宝妈说鸡汤，站在用户角度共情。

关键两点：关爱+重视。大部分人幼年缺失这两种情绪，博主如果能给到，用户会本能靠近。

还有故事连载型、挑战100天xxx、娱乐八卦型，都是天性喜欢的甜食。

#### 引导性内容
有目的的行动指令：引流、下单。像讲武侠故事：我有一招过目不忘法，能打败考研怪兽，成为武林高手，从此升职加薪。你就会喊着求求求，然后来个“V我50”式引导。
