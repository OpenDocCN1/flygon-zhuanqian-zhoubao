## (21 赞)五分钟就能搞定一张信息卡片，我试了下 AI 做信息可视化的玩法

作者： 高岛岛

日期：2025-04-16

最近在琢磨 AI 辅助设计的可能性，碰巧看到朋友发来的《黄帝内经》解读笔记，就突发奇想，能不能把她的文字解读转化成一张视觉卡片，于是就有了下面这张图。

最初的版本其实很尴尬，基本没法看。调了好几次都跑偏，效果不理想，最后只能一遍遍地打磨提示词。

为此我挨个实测了几款模型：GPT、Claude、豆包、DeepSeek、秘塔 AI 搜索。综合体验下来，DeepSeek 的深度思考模式最对味，就是服务器偶尔会挤爆，多试几次、反复微调才能拿到满意的结果。

具体操作其实很简单，就是把下面的提示词完整丢给 AI： [让我看看]那么，什么是 tml 和 css 代码呢？ 对于我这个非科班出身的人来说，AI 给出的解释是这样的：

网页的骨架和皮肤，主要就靠 HTML 和 CSS 来实现，组合起来就能做出结构清晰、样式好看的页面。

- HTML：超文本标记语言，相当于搭房子时的承重结构，决定了网页里有什么，比如标题、段落、图片和链接。
- CSS：层叠样式表，相当于房子的装修风格，负责文字的颜色大小、元素的背景边框、整体排版等。

把提示词发送出去后，AI 会直接返回一段代码。

如果你用的是 DeepSeek，可以直接点运行 HTML 的按钮，瞬间就会得到一个网页。再配合截图工具保存一下，这张卡片就完成了。
