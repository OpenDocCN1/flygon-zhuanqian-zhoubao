# 公众号爆文新手复盘：25天5篇10W+，副业月入5000+，我是怎么做到的？

> 来源：一个普通女孩的实战分享

大家好，我是安七。一个靠文字吃饭、也靠文字疗愈自己的姑娘。大学期间实现了经济独立，毕业后也链接到了百亿集团的股东，做过天使投资人。23岁那年，我创办了自己的公司，主营代运营业务。今年9月，我开始带着学员做公众号爆文变现，拿到了这些成绩：

有零基础的小白学员，25天写出5篇10W+，副业收入一个月冲到5000+；
有人更文7篇，3篇破万，其中一篇达到39W阅读，还有2篇上千；
单篇阅读量最高46W+；
单篇文章变现1950+……

说实话，加入生财也有两三年了，之前一直觉得自己在大佬面前拿不出手，默默围观。前段时间报名了公众号和视频号航海，因为时间冲突没能跟完，但在船上遇到了人生中的第一位客户，也是我的贵人。航海本身就已经超值了！

新的月份刚开始，我想给自己和同样在暗中围观的伙伴打点鸡血：有希望，就有盼头。

## 为什么我盯上了公众号爆文？

其实早在去年就听说有人做这个项目，但我真正接触是在今年7月，完全是偶然。那时候我大学毕业不久，辞了兼职，没有收入，整个人陷在内耗和迷茫里。闲着没事，我就拿朋友的公众号练手，想看看能不能把那个半死不活的号“救回来”。

写什么好呢？琢磨了一圈，决定写情感文。

原因有两个：之前有老师说我写情感类内容有天赋，而且我投稿情感类也过了两次稿，算是有底气；另一个是我观察到一个原本写成长文的号主，转型写情感文后基本篇篇阅读过万。我想：人家行，我为啥不行？

朋友的号当时只有144个粉丝，阅读量在20-50徘徊。

第一个月还在试验阶段，朋友的号就赚了差不多3000块。对当时的我来说，这3000块比任何数字都让人踏实。

为什么选公众号爆文？因为它有三个硬核优势：

**一、不看你粉丝多少，低粉也能拿高收益。** 只要满500粉丝开通流量主，写文章就能赚钱。阅读量跟粉丝数真没多大关系，关键看你懂不懂爆款逻辑。

**二、门槛低。** 有公众号、有500粉、会写字，基本就能起步。

**三、变现轻松。** 开通流量主后，发文就有钱。我最早一批爆文学员，全部实现了变现，没有一个挂零的。目前变现最高的月入5000+，单篇最高1900+。虽然跟生财圈友比起来不算多，但对零基础学员来说已经是很不错的开始了。

## 从0到1，该怎么开始写爆文？

生财里关于公众号爆文的干货很多，我就用纯小白的视角来写，希望能帮到真正的新手。如果有不对的地方，欢迎同行指正。

### 工具准备

**①注册至少1个公众号。** 一个身份证对应一个公众号。官方有注册教程，照着做就行。提醒一下：如果你希望多开几个账号，可以找信得过的家人朋友借身份证，一定要提前谈好利益分配，最好白纸黑字，免得后续为钱闹矛盾。单个账号变现上限有限，多开几个，东边不亮西边亮。

取名字时如果没灵感，可以试试“是XXX呀”这种格式，比如“是安七呀”。看不出领域，但哪个领域都能用，还能全网同名。小红书、抖音、快手都用同一个名字，简介里写一句“全网同名”，别人就能顺着找到你，方便引流。公众号一年只能改两次名字，且用且珍惜。

**②完善简介和自动回复。** 去参考同行的做法，照葫芦画瓢。

**③攒到500粉，开通流量主。** 100粉只是开通广告主，广告主和流量主两码事。想要流量主，至少500粉，一点都不能少。不想花钱买粉的话，可以试试通过问一问等方式涨粉。

### 方法核心

写爆文之前，先记住三个原则。

**原则一：爆款都是重复的。** 重要的事情说三遍。我以前也瞧不起那些同质化的标题和内容，总想玩点自己的独创，结果文章写出来没啥反响。说白了，那就是自嗨，市场和读者根本不买账。现在我学乖了——先去看看哪些爆款是不同人、不同时间写出来都爆了的。比如我刚开始写情感号时，有篇文章叫“xx恋爱周期表”，正文就100来字配一张表。别人写，10W+；另一个号写，也是好几万；我也跟着写了，当时不温不火，后来涨到了7.2W。就一张表+100来字，比苦哈哈写的干货还猛。你说，是不是得反思？

**原则二：优先对标低粉爆款。** 别一上来就盯着做了很久的大号，人家粉丝基数摆在那，写啥都容易爆。那怎么看对方的号是不是“低粉爆款”？有两个简单判断标准：一是看号是不是今年新建的，今年的新号大部分粉丝不多；[PRE6]二是对比它之前的阅读量和爆款文章阅读量。如果平时只有20、50，突然有一篇上万，而且后面还持续有远超平时的爆款，那这就是典型的低粉爆款号。

**原则三：一定找近期爆款。** 爆款找不对，努力全白费。所谓“近期”，最好是1-3天内的，3-5天次之，超过7天的就别用了。所谓“爆款”，阅读量优先10W+，其次5-10W，再次1-5W。

怎么找近期爆款？三个入口很管用：

1. 看完文章往下拉，系统会推荐一批同类型文章。[PRE7]
2. 看完文章点赞、在看之后，下面也会出现系统推荐的相关文章。别舍不得点赞，你点得越多，系统越知道你的喜好，省去自己大海捞针的功夫。
3. 微信首页“发现”-“看一看”-“热点”，里面也有系统推荐的文章。记得把“个性化推荐”打开，系统才会精准投喂。

前期你要做的就是大量刷同行文章，把爆款都收集起来，建一个对标选题库，方便后面拆解。

### 实操模板

分享一个超级适合小白的爆款写作模板，我的学员就是靠它在一个月里写出了5篇10W+。

模板 = 开头 + 段落 + 结尾

开头：用故事、金句、热点或场景描写引出，然后快速点题。

段落：每段按这个公式来——
小标题
名人名言/金句
相关例子
自己的观点
金句
一句话总结

结尾：名人名言/金句 + 回扣上面的3个小标题 + 一句话总结。

## 我踩过的那些坑

**坑1：没有坚持。** 一般一个号要获得推荐，至少需要写7-21天，但很多人卡在半路就放弃了。公众号是目前新手最快的变现方式之一，门槛低、回报快。只要你方法对，坚持写，结果一定会来。我有个学员是老号，权重不错，写了3篇原创，第2篇就破万了，结果他写到第3篇跑去玩了，完美错过爆款后的流量。所以一定要坚持，一天至少1篇，有条件的话2-5篇更好。

**坑2：自己给自己点广告。** 流量主收益一部分看广告展示量，一部分看点击量。有人想钻空子自己点广告，结果系统一检测到，轻则警告重则判罚。千万别干这事。

**坑3：总是转发社群和朋友圈。** 固定就那么几个IP在看，系统很容易识别，同样会判断为异常。

**坑4：快捷转载键没关。** 发布前一定检查一下“快捷转载”是否取消勾选。如果开着，别人就能快速转载你的文章，你的流量就被分走了。

## 最后说点心里话

生财里项目和内容很多，就像亦仁老师说的，在任何一个细分领域做到极致，赚到100W都不难。我目前还没赚到100W，但经常泡在生财里，感受思维和行为模式的冲击，收获已经很大了。更重要的是，我在这里遇到了几位贵人。

这背后还有我的启蒙贵人@明白，大二时带我进入生财有术，从此命运的齿轮开始转动；成长贵人@阿猫，让我误打误撞接触自媒体，看到了人生更多可能；人生贵人@张昭，在我毕业迷茫时指点迷津；事业贵人@金杜—故里小姐，给了我代运营旗下公众号的机会，也是我的第一位代运营客户。大家都说我自带贵人运，我也这么觉得。好的圈子和社群，真的有“改命”的力量。

我这个人，既胆大又胆小。胆大是因为敢为知识付费，说干就干；胆小是因为在大佬圈里总习惯缩起来，不敢展示自己。今天，就打破它。

第一次认真写帖，有点紧张，也有点期待。写得不好的地方，欢迎各位圈友多指点，感激不尽。欢迎大家链接我，一起走得更远。
