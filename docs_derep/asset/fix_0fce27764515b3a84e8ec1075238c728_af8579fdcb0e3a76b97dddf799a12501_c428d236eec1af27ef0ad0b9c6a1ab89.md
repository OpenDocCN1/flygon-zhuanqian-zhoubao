## 前言

此次共创的缘起，是生财组织了两期思维导图航海。想着把圈里伙伴拉来日常演练，精进制图功底，就在群里发出邀请，没想到响应者超过二十人。于是给出留群标准：每月至少产出两张精华帖思维导图。

后续过程不再赘述，下面直接看成果汇总。

我看着大家一张张分享导图，从最初对思维导图感兴趣的爱好者，到自己后来担任两期航海的导图教练，我越来越清晰地意识到，思维导图的价值远不止整理笔记。它可以成为对外发声的载体，成为个人展示的窗口，甚至能被更优秀的经营者看见，进而实现变现与个人影响力的构建。

常说“欧·亨利《最后一片藤叶》：自己淋过雨，总想为别人撑把伞”，这份心意推动了本次共创的启动。

## 做图感悟

*   掌握一项技能到熟练运用，关键在于刻意重复。感觉自己仍不足时，多半是作品数量尚未累积。
*   从不知如何下手，到能独立完成并加以创新，再到能引领他人，多半源于持续利他。
*   一张思维导图既是对自身认知的梳理，也是为阅读者节省时间精力的工具。
*   以图结友，不仅是主动分享，更是主动了解项目与作者。作品累计到一定量级，思维方式与行动模式会发生质变。
*   制图时反复自问：这句话是否能用更合适的表达替代？这样修改是否更贴近原意？这种推敲本身就是写作与思考能力的训练。

本档不会手把手教项目操作，更侧重呈现如何将数千字到数万字的精华帖，提炼成思维导图。

3.  同一篇文章出现多张不同版本导图属正常现象，体现的是不同视角的解读。
4.  发现错误或问题，欢迎 @罗卜 及时修正。
5.  点击任意导图，使用 🔍 可自由缩放至合适的阅读视角。
