这里值得划重点：这家店（Thienduong dientu VN）是一个典型的越南本土品牌店。它基本不做付费投放，吃的是品牌自然流。但有意思的是，它的成交结构非常依赖达人——每个月新增合作达人600多个，相当于背后至少要养2-3个达人运营专员。整个团队的重心非常明确：以达人合作为主轴。

整体来看，达人贡献了51%的销量和56%的销售额。商品卡作为自然流入口，贡献了48%的销量和44%的销售额。自营号销量和销售额占比均为0%。

把流量结构做成一道加法题就是：投流1% + 达人55% + 商品卡自然流44% + 自营号0% = 100%。

所以，这家店本质上是靠“达人种草+商品卡承接”双轮驱动，投放几乎没有，自营号也没有发力，纯自然流+达人分销就能做到这样的盘子。

再算一遍前五单品的整体毛利：

销售额合计：150360 + 50820 + 13200 + 6144 + 1430 = 221954元。
毛利合计：87710 + 18150 + 6600 + 1344 + 704 = 114508元。

如果配置一个3人小团队——2-3个达人运营按6000元/人，加1个店铺运营6000元——人力成本约24000元。

纯利润约：221954 - 114508 - 24000 = 90508元，净利率约40%。

这就是一个典型的“自然流+本土店+达人建联”模型：3-5人小团队、低成本、高回报，只要有商标就能跑起来。

## 三、越南风扇品类竞争分析：谁在吃肉，谁在喝汤？

老话说，知己知彼，百战不殆。要制定打法，先得看清对手的位置和手感。

先说头部品牌GOOJODOQ。坦率讲，这个月它几乎没有盈利，但它的牌局不在这一个月，而在于明年3月之后的旺季总攻。现在它做的事很简单：疯狂种草、广告加直播收割。等明年旺季一到，集中火力一把打穿。它之所以敢这么打，是因为底牌够硬——有品牌、有达人团队、有投流团队，产品性价比高，店铺权重高，隐性品牌人群资产厚。唯一不确定的是5A人群的水位到底蓄了多少。

这个团队的格局也体现在节奏上：越南风扇的旺季集中在3-8月，那才是大利润期。对普通人来说，这个阶段跑品打白牌就够了——投入门槛低，利润来得快。但从终局看，3-8月品牌利润一定会爆掉，而白牌的生命周期永远只有3个月。

打法层面，GOOJODOQ的模式是：本土备货 + 达人分销 + 达人投流（商品卡和自营号是否投流未知）。

结果就是：GOOJODOQ已经锁死了越南风扇品类高客单价的头部位置，销售额和第二名之间是断崖式差距。2022年8月进场，两年做到5200万销售额（单地区），月销超过500万。而Thiên Đường Điện Tử在2023年6月进场，目前是第二，累计做了550万销售额，月销21万左右。第一和第二之间差了23倍。

再看我们自己的风扇团队，目前处于第三梯队，月销不到10万。之前因为体验分问题受了一些影响，现在和第二梯队还差3倍左右。这次我们选择的是错位竞争——因为条件有限，我们把同行爆款直接拉到最低价，切的是低价人群。代价是毛利比较低。但现阶段的战略目标很清晰：风扇团队的首要任务，是想办法打进前三。

种草力方面，同样的产品、同样的价格，种草力决定胜负。等品牌体系完善之后，达人团队的建设必须被提到最高优先级。

投放力方面，看下来第一名在双11到双12期间最大的短板就是投流——其他都做对了，唯独投放出了问题，费比过高。看起来是直接在达人账号里投流，或是直接投放达人素材，而且和自营直播之间的衔接也比较割裂。核心矛盾在于没搞明白竞价在整盘里的意义——竞价的核心价值是收割达人在A1-A3人群里的蓄水。如果整体利润是这样一个水平，前十位的ROAS表现大概率不乐观。需要调节的地方有三个：

1. 投放策略要清晰：达人素材、买量素材、原创素材各司其职，不能混用。
2. 达人素材的ROAS要调：不要大范围铺开投，100块预算里50块测试、50块放大。
3. 短视频直投和引流直播要区分：直投和引流素材的逻辑不同，先调研清楚再投放。

这三个问题，我们内部要明确清楚，不要再踩同样的坑。

## 五、内部问题诊断和作战计划：先把三个矛盾解决掉

过去两个月，班子没拿出大结果。我认为团队内部有三个矛盾没解决，其中第一个是现阶段的主要矛盾：

矛盾一，知己不知彼。风扇团队的同事们分析对手情况时经常看不懂。不知道自己在哪里，不知道对手在干什么，更不知道自己要怎么干、怎么才能赢。犯错不可怕，怕的是犯了错还不知道错在哪。

矛盾二，缺乏“有解思维”。风扇团队组建不到两个月，很多同事遇到问题容易退缩，怕做错、怕花错钱、怕办错事、怕担责任，最后干脆不做了。必须切换到“有解思维”——积极、主动、有创造性地面对问题，以目标为导向。

矛盾三，团队效率和工作方法不到位。很多同事不理解人群是有限的，也没有对应季的感知。因为缺少丰富的作战经验，感受不到周期；因为缺少大胜的经验，感受不到节奏和规律。一定要通过调研报告来制定打法。不要觉得公司账上有钱就可以一直烧。牧野之战、彭城之战、赤壁之战，以弱胜强的例子太多了。越是弹药充足，越要如履薄冰。赢不在我，赢在敌。按部就班，把小事做好。

## 六、朋友和敌人：下一步的关键判断

谁是我们的敌人？如果顺利的话，明年6月我们这支团队有很大机会做到品类第一。目前调研的竞争对手有两家，但我认为真正有资格跟我们过招的只有一个——就是品类第一。

GOOJODOQ前期投入不少，这次没打赢也得调整内部问题。我们要在四力维度上率先突破产品力和价格力。目前风扇单店铺一个月大约1-2万单。年前就要完成品牌注册流程和价格力突破，之后完成投放基本盘从0到1的建设；3-4月重点建设达人队伍。

谁是我们的朋友？现阶段我们的优势有三：团队、现金流、基本盘。

团队：虽然还在品类20名开外，但团队在快速进步。从0到1建立起来的风扇团队已经找到了突破口，完成了基本盘。团队是下个阶段的关键，所以必须注重班子培养，还要用制度保证班子的收入高于市场水平。

现金流：我们最难的阶段已经过去了，手里的子弹足够支撑打到第一。其他板块也已经完成了本土化部署。直播经验充足，很快会在本土直播上产出更好的效果。

基本盘：我们对本土的情况和SOP已经非常熟悉，上月团队已全面进入本土化战场。同时高度注重平台规则和供应商管理，月过万单为团队基础做了很好的沉淀。

## 七、持久战三个阶段与六个月战略部署

现阶段团队必须坚持持久战思想：一方面积极勇敢作战，另一方面纵观全局，抓住业务关键节点。

持久战三个阶段：

- 第一阶段：敌之战略进攻，我之战略防御。运动为主，游击为辅。
- 第二阶段：敌之战略保守，我之准备进攻。游击为主，运动为辅。
- 第三阶段：我之战略反攻，敌之战略退却。运动为主，阵地游击为辅。

战术方针也要明确：

- 游击战：敌退我进，敌驻我扰，敌疲我打，敌退我追。
- 运动战：快速退进，抓大放小，集中兵力，取得胜利。

对应六个月战略安排：

**第一阶段：2024.12.15 - 2025.3.1前，目标：完成基础建设。**

1. 高度统一班子意识形态。
2. 完成商标注册并投入市场。
3. 完成产品建设，针对价格力、产品力、投流力进行突破。
4. 分别做好海外仓、供应商、物流商储备，效果分层与分流。

**第二阶段：2025.3.1 - 2025.6.1前，目标：进入头部前三。**

1. 测品、广告、本土团队采用运动战部署；达人团队打游击战；完成广告三源合并。
2. 确保四力在市场保持头部水准。
3. 完成本土化部署，开展直播与达人专项合作。
4. 完成泰越马菲印尼市场的复制。

**第三阶段：2025.6.1 - 2025.9.1前。**

1. 在四力上下功夫，拉开与第二的差距，保持第一水平。
2. 依托基本盘优势，开展第二曲线，打3C配件类其他品类与品牌部署。
3. 针对组织模式做更多调整。
4. 依托基本盘、文化与制度优势，完成东南亚团队大的从0到1。

**第一阶段执行战术：**

目标：5个人完成300万销售额，完成基础建设，单月突破100万。

时间：2024.12.15 - 2025.3.1。

1. 跨境团队、本土团队、广告团队统一目标与KPI，责任到人。跨境完成30万，本土+投流完成70万。
2. 完成商标注册并投入市场。
3. 价格力方面，根据包材整体成本做第一轮错位价格；产品力方面，做前五产品的review调研，抓主要矛盾，打穿一个卖点。

## 八、送给所有入局者的TikTok东南亚电商攻略（认知篇）

最后，把这套打法放回更大的坐标系里看。这篇数万字的TikTok东南亚电商实战攻略，核心是给想要进入东南亚带货的团队提供一份可落地的实操指南。按执行顺序，从认知、赛道、算法、商家、团队、货品、场景、店铺、运营、人设、玩法、话术、数据、工具、深化、复盘、分享到总结，一共18个篇章，由浅入深展开。

先说认知篇——不同角色的变现模式。

认知上的改变是第一步，选对赛道是第二步。目前TikTok东南亚跨境电商，绝对是最稳定、门槛最低、最适合中国人去做的地区，没有之一。无论你是新手小白、跨境电商卖家、品牌操盘手，还是在东南亚做生意的华人，都可以入局。

无论你是中国发货到海外，还是本土建团队，东南亚市场现在都处于政策稳定、没到红海阶段的窗口期。TikTok东南亚电商在未来3-5年仍然有不少机会，但关键在于：你选了什么品类赛道，能不能以更低成本、更轻的模式挤掉对手。

本质上，整个TikTok电商链条——供应链、海外仓、团队、账号、人设、话术、玩法、付费——都是基于产品打造的。品类选择错一步，后面全盘皆输。

目前切入TikTok的玩家大概有六类：

1. 土生土长的本地华人电商老板。
2. 在东南亚经营多年的华人。
3. 有国内电商经验、初入东南亚的操盘手。
4. 在东南亚长期生活、做本地电商或零售的操盘手。
5. 没做过跨境电商、第一次发货的电商小白。
6. 有国内外集团背景的高管或CEO。

这两年在东南亚操盘下来——跨境一年、本土一年——我见过所有玩家的属性。每个人的切入点完全不同，一旦姿势没对，干了比不干还难受。我在这上面踩过天大的坑，浪费了大量的钱和时间。

重点说说第一类：本地华人电商老板。

这类玩家通常有Shopee/Lazada加线下零售的基本盘。切入TikTok最常见的姿势是：搭个直播间，把基本盘的品直接拿来直播，挖一个别的行业的leader来管，天天播。结果就是没什么效果，投入一直在烧，老板难受又内耗。泰国、马来、菲律宾都有这样的案例。

正确的姿势是什么？华人老板从TikTok Shop本土店切入没有问题，因为你本来就有供应链优势。但很多本地老板不懂起店的逻辑，直接把原有价格原封不动搬到TikTok，再开个直播间播，这种是不可能有效果的。

我们的常规操作是：卡低价亏品 + 补单，基本一周就能起店。但这里面还是会牵扯到品类——品类决定了团队能力、决定了打法、决定了你玩什么流量渠道。

店铺切入之后，品类清晰了，就开始补团队。流量渠道这个环节，要么挖一个中国运营——一个好的运营负责人基本能带好N多个本地leader——要么去补课，要么把这篇攻略看完。

总结一下华人老板的切入路径：分析基本盘品类优势 → 确定品类 → 清晰打法 → 螺旋起店 + 补流量渠道团队。

再说第二类：在东南亚经营生意多年的中国老铁。

这类玩家的局面更复杂，因为生意涉猎范围太广，从衣食住行到当地特色产业都有。要么自己干，要么找人干。自己干的话，跟华人老板没太大区别，唯一差别是你要自己找供应链。

最关键的是找到自己的独特资源。举个例子，我在马来认识一位朋友，之前在中国工作过，回国后手握大量娱乐场所资源。他招人只需要打一个电话，20个高颜值姑娘就来面试了，价格还便宜，空姐、模特都有。这种资源禀赋就是核心优势——有这类优势，就切直播；没有这种优势，就切店铺；再或者有钱就收购/投资一个现成团队。

但有一个建议：不要投0到1的团队，风险太大。核心就看你先有“人”还是先有“货”。但所有老板都该抓紧入场，再晚两年，没有资源就很难启动0到1的盘了——就像今天的抖音，不给达人垫款、没有流量规模，根本进不了场。
