- 总销量：4095单

## 结论：Thienduong dientu VN这个本土店到底怎么跑的？

**店铺模式**：本土店，品牌是Thienduong dientu VN。

**打法画像**：几乎不怎么投广告，吃的就是品牌自然流量。51.68%的销量来自达人分销，每个月能新增600多个合作达人，这意味着背后至少要有2-3个专门负责达人对接的运营。整个团队的资源配置，重心明显压在达人侧。

**流量结构拆解**：
- 达人销量占整体51%，达人带来的销售额21.9万，占比约55%
- 商品卡销量占比48%，商品卡销售额占比44%
- 自营号销量占比0%，销售额也是0%
- 投流占比只有1%

所以最终流量结构就是：投流1% + 达人55% + 商品卡自然流44% + 自营号0% = 100%。

**前五单品整体利润预估**：
- 总销售额：150,360 + 50,820 + 13,200 + 6,144 + 1,430 = 221,954元
- 总毛利：87,710 + 18,150 + 6,600 + 1,344 + 704 = 114,508元
- 预估人力成本：按2-3个达人运营（6000元/人）+ 1个店铺运营（6000元/人），3人团队总成本约2.4万元
- 减去人力后的纯利润：221,954 - 114,508 - 24,000 = 90,508元，纯利率约40%

**一句话总结这家店的打法**：自然流跑通店铺模型，转成本土店后靠达人建联放大。3-5个人的小团队，成本低但回报可观，只要把商标注册好，这个模式就能转起来。

## 再看越南风扇品类的竞争战局

先记住一句话：知己知彼，百战不殆。这个品类的竞争情报，要从两个标杆说起。

### 标杆一：GOOJODOQ（类目第一）

这个品牌目前处于什么阶段？基本上这个月是没怎么盈利的，但他们的牌局根本不在现在。品牌整体规划瞄准的是明年3月份。现阶段做的事就两个字：种草。通过广告和直播疯狂收割用户心智，等到明年旺季来临时一举打穿市场。

他们的团队优势很清晰：有品牌沉淀、有达人团队、有投流团队，产品性价比高，店铺权重高，隐性品牌人群资产厚。不过也有一个未知数——不清楚A5人群到底蓄了多少水。

团队格局很大。明年3月到8月是越南风扇的超级旺季，也是利润爆发期。对于普通卖家来说，跑白牌就够了——投入低、来钱快。但从终局来看，品牌在3-8月利润必然爆发，而白牌的寿命只有3个月。

GOOJODOQ的打法是：本土备货 + 达人分销 + 达人投流。目前他们已经锁死了越南风扇品类高客单价的头部位置，销售额和第二名是断崖式差距。从2022年8月开始做，两年时间做了5200万销售额（单地区），月销超过500万。

### 标杆二：Thiên Đường Điện Tử（类目第二）

2023年6月开始入场，目前累计550万销售额，月销21万。但第一和第二之间的差距，整整差了23倍。

### 我们的位置

目前这支风扇团队在第三梯队，月销售额不到10万。之前因为体验分的问题拖了后腿，和第二梯队的差距在3倍左右。这次做了一次错位竞争——由于资源条件限制，我们把同行爆款的价格直接压到了最低，切入低价人群。但代价是毛利偏低。这个阶段的作战目标很简单：打进前三。

## 四力竞争维度拆解

**商品维度**：
- GOOJODOQ：店铺平均客单价23.5万越南盾，约67元。爆款1是429,000-469,000越南盾，一支装防摔壳+风扇；爆款2是129,000-469,000越南盾，分SKU内嵌两支装。
- Thiên Đường Điện Tử：平均客单价40.5越南盾，约14万越南盾。

**产品力**：从产品维度看，第二名并不占优。在这个位置要做的，是向第一名学习。

**包材**：设计和logo要统一。
**配套**：比如挂绳，可以增加防摔功能或其他价值点。核心是根据用户反馈，用户到底要什么，我们就力出一孔。

**产品外观与商标**：还要考虑如何防止同行抄袭。

**价格力**：GOOJODOQ爆品1的两个SKU策略很清晰——不带壳429,000，带壳469,000。爆品2则是129,000-469,000的区间覆盖。

**种草力**：同样的产品价格，种草力决定胜负。达人团队在品牌完善之后，必须被提到最高优先级。

**投放力**：目前看下来，双11到双12期间，投流是他们最大的短板。其他环节都做对了，就是投流出问题了——费比过高。大概率是直接在达人账号投流，或者直接投流达人素材，而且跟自营直播割裂得比较严重。核心矛盾在于：没搞清楚竞价在整盘中的意义。竞价的真正价值是收割达人所积累的A1-A3人群。以这样的利润表现来看，前十位的ROAS应该不太乐观。

需要调整的方向有三个：
1. 投放策略上，要分清达人素材、买量素材、原创素材各自的作用
2. 达人素材ROAS要精准调控，不要大范围铺达人。100块预算，50块测试，50块放大
3. 短视频直投和引流直播要明确区分，调研清楚再投放

这三个问题必须想明白，不要再犯同样的错误。

## TikTok风扇团队作战计划

### 内部团队三大矛盾

过去两个月团队没拿到大结果，核心是三个矛盾没解决，其中第一个是现阶段的主要矛盾。

**第一，知己不知彼。** 分析对手情况时经常看不懂——不知道自己在哪里，不知道对手在干什么，更不知道怎么干才能赢。犯错不可怕，可怕的是不知道错在哪里。

**第二，缺乏“有解思维”。** 团队组建不到两个月，很多人面对问题习惯性退缩。怕做错、怕花错钱、怕担责任，然后干脆就不做了。必须建立有解思维，积极主动面对问题，更开放更有创造力，以目标为导向。

**第三，团队效率和工作方法没跟上。** 很多同事没有意识到人群是有限的，也不理解应季产品的时间窗口有多重要。因为缺乏丰富作战经验，感受不到周期；因为没打过胜仗，感受不到节奏和规律。要通过调研报告制定计划和策略，不要觉得公司账上有钱就可以一直烧。古今中外以弱胜强的战例太多——牧野之战、彭城之战、赤壁之战——越是弹药充足越要如履薄冰。赢不在我，赢在敌。按部就班，把小事做到极致。

### 谁是朋友，谁是敌人

**敌人是谁？** 顺利的话，明年6月这支团队有很大机会做到品类第一。目前调研中看到了两家竞争对手，但真正能一战的，其实只有类目第一那一家。

GOOJODOQ前期投入并不少。我们这次就算没打赢，也要把内部问题调整好。在四力维度上，要率先在产品力和价格力上突破。风扇单店铺目前一个月大概1-2万单，年前要完成品牌注册和价格力突破。突破之后，在投放基本盘上完成从0到1的搭建，3-4月份花大量精力建设达人队伍。

**朋友是谁？** 现阶段的核心优势有三个：团队、现金流、基本盘。

**团队**：虽然还在品类20名开外，但团队在快速进步。从0到1，这支风扇团队找到突破口，完成了基本盘的从无到有。团队是下一阶段的关键，所以必须重视班子培养，更要重视制度设计——让班子的收入高于市场水平。

**现金流**：最难熬的阶段已经过去了。现在的弹药非常充足，完全足够支撑打到第一。其他板块已经完成本土化部署，直播经验丰富，很快会在本土直播上做出更好的效果。

**基本盘**：对本土情况和SOP已经很熟悉。上个月团队就已全面进入本土化战场，高度注重平台规则和供应商管理。月销过万单，为团队打下了扎实的基础。

### 作战方针：持久战

现阶段必须坚持持久战思想。一方面要积极勇敢作战，另一方面要纵观全局，理解业务关键节点。

持久战分三个阶段：
- **第一阶段**：敌之战略进攻，我之战略防御。以运动为主，游击为辅。
- **第二阶段**：敌之战略保守，我之准备进攻。以游击为主，运动为辅。
- **第三阶段**：我之战略反攻，敌之战略退却。以运动为主，阵地游击为辅。

战术方针：
- **游击战**：敌退我进，敌驻我扰，敌疲我打，敌退我追。
- **运动战**：快速退进，抓大放小，集中兵力，取得胜利。

### 六个月战略部署

**第一阶段（2024.12.15 - 2025.3.1）目标：完成基础建设**
1. 高度统一班子意识形态
2. 完成商标注册并投入市场
3. 完成产品建设，在价格力、产品力、投流力上实现突破
4. 分别做好海外仓、供应商、物流商储备，做好效果分层与分流

**第二阶段（2025.3.1 - 6.1）目标：打入头部前三**
1. 测品、广告、本土团队采用运动战部署，达人团队打游击战，完成广告三源合并
2. 确保四力在市场中保持头部水准
3. 完成本土化部署，包括直播和达人专项合作
4. 完成泰国、越南、马来、菲律宾、印尼市场的复制

**第三阶段（2025.6.1 - 9.1）目标：战略反攻**
1. 在四力上下功夫，拉开与第二名的差距，保持第一水平
2. 依托基本盘优势，开展第二曲线，打3C配件类其他品类与品牌部署
3. 针对组织模式做更多调整
4. 依托基本盘、文化、制度优势，完成东南亚团队大的0到1

### 第一阶段执行战术

目标：5个人完成300万销售额，完成基础建设，单月突破100万（2024.12.15 - 2025.3.1）。
1. 跨境团队、本土团队、广告团队统一目标和KPI，责任到人。跨境完成30万，本土+投流完成70万。
2. 完成商标注册并投入市场。
3. 价格力根据包材整体成本，预计进行第一轮错位定价。产品力要做前五产品的review调研，抓住主要矛盾，提炼一个卖点，把卖点打穿。
4. 针对产品、原创素材、达人素材、买量素材，做好投放素材的划分与测试，完成第一轮素材测试。同时完成本土店铺GMV MAX与一品多仓的短视频投放，达到ROAS预期。
5. 储备三个仓库和物流商，筛选出3-5家能贡献月产能5万单以上的工厂（重点管好质检和开品）。
