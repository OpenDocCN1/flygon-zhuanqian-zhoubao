# 500小时，从零到一：我的第一个网站终于上线了

作者：一生荣禄  
日期：2025-08-17

见字如面。

转眼间，从决定南下杭州到真正落地，已经过去了一个半月。这段时间里发生了什么、收获了什么、踩了什么坑，我想认真记录下来，写给关心我的朋友们，也写给正在路上的自己。

## 为什么来杭州，为什么住在公司隔壁

来杭州的原因，上一篇已经讲过。找房子的时候，我原本打算选在地铁3-5站的距离，把生活和工作的边界划清楚。最后却直接租在了公司隔壁，步行10分钟就到。为什么？就一条：省钱，省时间。

这个决定，后来被证明太对了。因为——说实话，我哪有什么生活可言？媳妇带着孩子来住了一个礼拜就回去了。

## 初到生财SCAI实验室：像开荒一样

太久没在大城市生活了，刚来的头半个月，说实话有点懵。新环境、新面孔、新的协作方式，一切像刚格式化的硬盘，等着重新装载。

那种感觉就像进了个新副本：开局赤手空拳，装备全靠捡。这时候最怕的点错技能树，每一分加点，都决定将来能不能扛过最终BOSS。而摆在面前最大的敌人，不是怪物，是时间。

刚到SCAI实验室的头两周，我整个人是好奇、混沌、迷茫、无力、自卑的。我努力观察、拼命融入，但有一个硬伤：我不懂英语。聊天时连个网站名、工具名都说不好，那种尴尬让人心里发堵。

身边的伙伴们呢？大多是大厂出身——不是前后端工程师，就是产品经理，履历亮眼，年龄还比我小5到10岁。大家都拼得很：凌晨5点还有人发复盘，两天上线一个站的也大有人在。来了一两个月的，有人已经跑通闭环，有人还在摸索。但所有人的共识是：流量，是最大的瓶颈。

要说基础，我可能是这帮人里最差的，以前连代码都没碰过。照正常节奏学下去，最好的情况，也不过是两个月后勉强跟上大家现在的速度。以我的底子，做产品很难卷赢别人，但即便做出来，还是绕不开流量这座山。

所以我的破局思路逐渐清晰了：技术是我的弱点，那就把产品交给合适的伙伴一起搞；但需求判断和流量获取，是所有人都缺的东西。那几天，我翻来覆去在想，怎么破局？答案还没冒出来，但我很清楚，这件事值得押上全部注意力。

## 找亦仁哥聊：先搞定流量，再做产品

开局的第二周，我就去找亦仁哥聊了。我说得很直白：我在办公室里能力垫底，就算硬挤出个产品，也会撞上流量问题。然后问了个狠问题：“我要在100天内赚到1万刀，该怎么破局？”

其实在我去杭州之前，他就给过方向：先搞定流量，再做产品，建立自己的流量范式。而圈子里的那些能拿大结果的人，无一例外都有自己的流量打法。

他问了我的经历和擅长之后，想了一下，说：“这事我留意一下。”

结果第二天，他真的来找我了。他直接坐我工位边上，给了我一个方向——基于过去的经历，他建议我去研究TikTok AI短视频带货。他说：“这是你在短时间内，拿到结果概率最高的方向。”

我听得热血沸腾，回去就开始研究。买手机、注册账号、搭环境，折腾了一大圈。但一个星期过去了，一条视频都没发出来。

原因是方法错了：我一直在想的是怎么用工作流拆解对标、批量生成视频，甚至还想顺便做个工具来卖。结果净在研究工具和流程，产出为零。

后来回头算账：用VEO3生成一条1分钟的视频，抽卡不算，成本就得上百块。10条里能不能出一条爆款？变现逻辑又还没摸清。这个成本我扛不住，又开始找平替模型，绕来绕去，越绕越怀疑：这真是我想干的事吗？还是我太菜了？

## 重新定位：做AI自媒体IP

这时候，好朋友艾伯特拉了我几把。他建议我做集合站：每天上新，社交媒体持续有内容可发。我一听，对路——社媒本来就是我向往的方向。

其实来杭州之后，最开心的一天，是7月10日围观群的复盘分享那天。因为我想通了一些事。

我真正擅长的，是分享、运营、共情力、洞察需求、总结分析。产品技术不是我的强项，那我就去做AI自媒体IP：在国内外全网分享自己和朋友们的好产品，接AI商单。

技术要不要学？要学。每天上站、加新功能、分享AI工具。这行日新月异，热点天天变，什么才是那个不变的东西？只有变化本身。那就拥抱变化吧，让热点给我提供创作素材，让变化成为增长的引擎。

也只有这样，百天万刀才可能不是白日梦。

那天在SCAI实验室，悦己邀请我做了个分享。讲的是5年前做TK百万粉的经历——说实话有点不好意思，都是过时的东西。思来想去，最后我选了“获取流量”这个角度来分享。底层的逻辑没变过，也正是大家最缺的。

原计划二十分钟，结果讲了一个小时。直播回放之后会发到群里，有兴趣的可以去看看。

分享完，方向初步成型了。但还不够清晰，于是我去找了两个好朋友，各自给了我很具体的建议和路径。越分享越幸运，那天链接了好几个新的朋友。其中一个北京来的朋友，跟我聊了一个小时，把自己的几个正在赚钱的网站、规划、想法全盘托出。他在大厂待过很多年，技术产品双强。

我问他为什么对我这么坦诚。他说：“今天听了你全程的分享，我非常喜欢你。你的能力跟我互补，希望以后有机会深度合作。”

那一刻，我被看见了。

关于合伙人，我仍然想谨慎一些。人品、能力、相处，都需要时间的检验，不轻易下注，对双方都是负责。

## 身体先垮了：跑步跑出了血尿

办公室对面坐着一个精神小伙康昊，身材好得像双开门冰箱。身体是革命的本钱，我决定动起来。

一星期5次无氧，用力过猛，第二周全身酸痛。跟教练说实在扛不住了，改成去跑步——结果跑完6公里，尿血了。

去医院检查，医生排除了所有其他原因，给出诊断：运动过度导致横纹肌溶解。严重的话肾扛不住会休克。我这才明白，身体这东西，急不得。尤其是我这种莽的人，更需要循序渐进。

方向前后定了两个星期。我知道这条路未必走得通，但已经是当下最优解。说干就干，其余的都先放一边。

后面又冒出来不少“机会”，我全屏蔽了。90%的群聊都不再关注，所有精力只干一件事——做我的第一个AI工具集合站。

## 从0到1：500小时做个网站

6月我跟着小排老师的AI编程课学了半个月，算是对代码有了个模糊的框架。

7月20号左右，我开始从零搭站。基础太差，每一步都费老劲了，每天十几个小时砸进去。

到上线那天，一共砸了350多个小时，加上之前学习的半个月，合计500多个小时。韩道友一路升级打怪，最后到我面前的时候，他哭了，我也红了眼眶。

lwu.ai，我的第一个网站，终于上线了。

SEO不会做，热词卷不过别人，技术又是弱项——那好，我就做一个AI工具集合站，在我能力范围内做到极致，用社媒流量来推。

网站现在还很基础：功能少，手机端都还没适配。但没关系，我会一直迭代下去。集中所有资源做这一件事，就是我当下的最优选。

## 那些避不开的坑

首先是代码保存。我习惯极差，一天只推1-2次代码，常常几十上百个文件一起存。一是没那习惯，二是同时开好几个窗口，很难有空档好好保存。结果就是经常半天白干。

还有项目基础框架的认知缺失，一改就推倒重来。光是积分系统、登录系统、支付系统、数据库，加上各种硬编码的坑，来来回回重构了十几次，该踩的不该踩的，一个没少踩。

完美主义也没放过我。直角图片我看不顺眼，想改圆角，结果上面代码全是硬编码，根本定位不到元素。为了这一个细节，我磨了五个多小时，最后还是没搞定。后来找了专业前端涛哥，他看完我的“屎山”代码头大如斗，半小时帮我搞定了。

再有就是畏难情绪。不懂的东西不好意思问人，大脑自动屏蔽复杂方案，一个人陷在死循环里空耗时间。好多时候，高手已经给了答案，我却听不进去。

比如亦仁哥一个月前就跟我说：先搞定流量再做产品。有道理吗？有。认同吗？极度认同。听进去了吗？听进去了。但执行了吗？没有。

为什么呢？

因为大脑在偷懒，自动选择最简单的路。学习是世界上最简单的事，照着教程123往下做就行。但流量和赚钱，没有标准答案。面对未知市场，你得自己去试错，而我的大脑，悄悄避开了那条难的路。

后来我逼自己：前辈给的绝对正确的建议，必须带耳朵听话照做。

Vercel这类平台，一键部署是真方便，但限制也不少。比如免费用户传图超过3M就用不了。我试过压缩功能，不行。我也不想牺牲用户效果图的品质。

群里问，大黄哥和小辉教练异口同声：自建服务器，啥都解决了。我一听，工程肯定巨大，果断没接茬，回了句“先放放再说”。

大黄哥回：不要放，要立刻。自从自建了服务器，血压都平稳了。

等他第二次撂下这句话，我才意识到——这应该就是当下最优解。好，马上学。

然后在大师姐推荐下，我不内耗了。找彩笺教练帮忙，他直接推荐了服务器，用一条docker命令，十几分钟，迁移部署全搞定。

我甚至想过自己先琢磨几天，遇到卡点再浅浅问一句，再自己研究。这一来一回，怕不是要耗掉几天外加无数个坑。

新站一直延期，每天到公司都有人问：今天上线吗？前一周我说没问题，一周后，我都不好意思回答了。

甚至水都不敢多喝——怕上厕所，怕被催。亦仁哥工位又在男厕门口，每次路过压力山大。

## 40个小时，拿下

上线的最后两天，我下了死命令：今天不上线，不睡觉。

结果呢，BUG如约而至。无数次想清空重来，但我知道，以我的能力，重来一遍大概率还是一样。只能咬碎牙往里吞，一次次跟AI沟通、梳理逻辑、修改、调试。

48小时没合眼，网站终于上线了。第一时间申请了支付，12小时不到，凌晨4点通过通知就到了。这一步，比我预想得顺利——最怕卡在支付上，时间是真耗不起了。

但我也清楚，这不过是万里长征第一步。接下来真正的战场，是社媒短视频获客。怎么拼刺刀，还没想明白？那就边做边学吧。光想不打，必输无疑。

## 我用的工具：极简但够用

我是真小白，命令记不住三条。下面分享的不一定对，但我确实是这么干的。

工具就三个：20元的Cursor + 265刀的Claude Code + 20元的ChatGPT。其他没了。

今年最高性价比的投资，是1.35万买的MacBook Pro，每天都在享受它的效率和便捷。

AI编程工具这块，一开始白嫖Curser免费额度，后来上闲鱼买无限换号脚本，月付30。为了用Claude Code，买了20刀/月，省着问，干半小时歇半天，实在受不了，准备换200刀。

听说淘宝拼车只要420块，上去后发现白天也是干两小时歇三小时。只好把活挪到凌晨三点拼车伙伴睡了再干。结果有天发现，有个哥儿们也凌晨三点在干活——流量不够用了。

痛下决心：一定要搞200刀独享号。没有海外信用卡，试遍了所有办法，最后通过谷歌商店付了265刀，终于用上了独享Claude Code账号。

再也不用盯着tokens焦虑了，Opus随便用。一个月2000块请个超级程序员，没有比这更值的事了。

## 那些让我脱胎换骨的经验

**数据库MCP**：装好之后，Cursor和CC都能直接操作数据库，增删改查全自动，不用再手动复制SQL去数据库注入，报错循环，浪费时间。但一定要给它规则限制，效率是高了，删库跑路的概率也大了。这技能是邬轼教的。

**RPC函数**：把数据库里的活提前写成一堆函数，存好，起名。以后直接喊名字，它就自己把活干完。后端的积分交互逻辑不要写死在代码里，而是放数据库里，用统一的RPC函数系统来管理，不容易乱。这技能是康昊教的。

**npm run build**：推代码前先在本地构建一次，有错直接终端报出来。或者让Claude Code干，它会一边构建一边修，直到全过。然后再推Github-Vercel，基本一次就过。还有，找不到localhost:3000端口时，一条`pnpm kill-dev`全清。

后端靠逻辑，跟做数学题一样，对就是对，错就是错，急不得。前端看审美，要多花时间雕花——那是用户能看见的脸。

**多语言文字变量**：项目建好规则，所有文字用变量替代，对应不同的语言文件。加语言只加JS文件就行，增删改都方便。邬轼教的。

但慢慢提醒我：新站前期别急着做多语言，容易频繁报错，等稳定了再一次性加上。我修语言硬编码的bug修到吐，这句话简直是真理。

**浏览器定位元素**：如何在浏览器里捕获元素，在代码里快速找到并修改，避免硬编码操作容器。涛哥教的。

## 写在最后

我不懂英语、没碰过代码，干了十年餐饮，为什么选一条这么难的路？

因为这条路的杠杆足够大：AI+短视频+美刀=700倍杠杆。我要打造一个自运转的系统，一个24小时能赚美刀的系统。

为了快速验证闭环，哪个工具最趁手就用哪个。这场赌博最大的赌注是时间，我每天都在跟时间赛跑。

最近一个月，睡觉时间从晚上11点挪到2点、4点，再到通宵第二天继续deBug，无数次重构。但我明白：如果无法变现，这一切努力都只是自我感动罢了。

回头看这一程，那些所谓的“懂”，很多只是“听过”。真正经历过之后，才发现：说得再有道理，不如“太他妈正确了”。

做事就是在赌博，最大的赌注，永远是时间。选择这条路，就意味着放弃其他所有的路。也只有这样，才有机会在这件事上拿到一点结果。想提高赢面，就必须在开始时尽可能想清楚。新手下一步看一步，高手下之前想三步，大师想N步。

系统的意义在于：哪怕它再简陋，只要能在你睡觉时也自动运转，持续创造价值，它就是一个好系统。长期看价值，短期看利益。很多人和我一样，看不上短期的钱，但其实短期的钱也不好赚。没有长期主义的耐心和坚定，只会在短期和长期之间反复摇摆，最后蹉跎时间，一无所获。

网站虽然已经上线，但我知道这只是一个极其粗陋的起点。从社媒获客、从内容引流，是一场更硬的仗。方向也许还没完全清晰，但，先跑起来吧。

新的一天，继续加油。

争取今天，也上线一个新东西。
