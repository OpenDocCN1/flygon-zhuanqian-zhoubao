# 澳门印象（二）：赌博这回事，我劝你别碰

澳门最出名的标签就是博彩，说白了，整座城市就是靠“赌”撑起来的。

放眼全球，赌也不是澳门独有的产物。拉斯维加斯、澳门是专业赌城，英国威廉希尔这种公司也是靠足球博彩吃饭。可什么是赌？我的理解是，一件事情的收益完全靠运气、靠概率，你压根没法靠自己的本事去控制结果。

这么一看，德州扑克其实不太算赌博。它虽然有运气的成分，但更多靠计算、读人和策略，属于竞技与智力对抗，玩家有很大的主动操作空间。反观老虎机、百家乐、二十一点，运气占主导；足球彩票也很大程度是赌；俄罗斯轮盘赌就更不用说了，完全是赌徒的亡命游戏。另外，如果你靠出老千赢钱，那也不叫赌，那叫骗，靠的是手法和欺诈。

有人会说，国内不是有合法的彩票吗？福利彩票、体育彩票，本质上也是赌。开奖结果完全随机，福彩还要先抽走35%的流水，虽然说是做公益，但站在参与者的角度，这钱几乎等同于交智商税。说穿了，就是一群人自愿捐出35%做福利，然后抽个签，把剩下的钱送给一个幸运儿。偏偏还有人坚信彩票有规律、赌球被庄家操纵，这类阴谋论听多了，真容易走火入魔。

我在澳门只住了一夜，行程仓促，逛了两家赌场，之前也去过吉隆坡云顶。始终只看不赌，提不起兴致。但必须承认，澳门赌场的氛围比云顶热烈太多，而且24小时灯火通明。赌场大门敞开，入口处却专门做了遮挡，不让外面的人看见里面谁在赌。场内氧气足、灯光亮、没有窗户，据说设计初衷就是让你忘记时间，一直玩下去。

赌场在吃喝上相当大方。饮料、奶茶、鲜榨果汁、水、小吃、蛋糕、冰淇淋，统统随意取用，不赌也一样。小红书上的各种蹭吃攻略，早就把这儿当成了打卡地。我自己尝了一杯黑糖珍珠鲜奶，味道确实好，店员特意说，这款奶的蛋白含量在4%以上，已经是最高的那一档了；黑糖珍珠则由台湾一家供应商独家提供。

澳门几乎没有独立商场，购物中心就是赌场本身，娱乐、购物、酒店、餐饮全在一栋楼里。荷官多是澳门本地人，服务员则以内地人为主，因为八成赌客来自内地，其余来自东南亚、港台和日韩等地。支付方式上对内地人很友好，微信、支付宝畅通无阻，这一点比香港方便很多。

赌场舍得花钱，因为来钱太容易。国内五星酒店的建安成本大概每平米1万到1.5万元，赌场酒店直接飙到7万起步。我从关口出来就有人专车接送，服务员的专业素养甚至超过内地五星酒店——高薪自然能吸引高素质的人。

在澳门有个说法，无论输赢，钱都留在澳门。输了不必讲，赢了也很难带走。钱来得太轻松，花起来就大手大脚，赌场里外的酒店、奢侈品店、名表店，全是冲赌客钱包来的。普通客房平日两三千一晚，节假日更贵。

国内那些身家几十亿的老板，因为赌博一夜返贫的例子也不少，金立手机老板就是其中一个。

我对赌是真的没兴趣，理性想想，这大概是最糟糕的爱好。我无法与赌徒共情，因为一旦陷进去，毁掉的就是一生。正规赌场尚且如此，那些地下赌场更是陷阱密布、骗局连环，沾上就很难脱身。

评论区里也是感慨万千。有人哀叹，身边好几个小老板在澳门赌完就跳了楼；一位澳门本地的朋友则说，21点里赌场优势最小，关键还是看心态，小赌怡情；还有网友补充，小老板去澳门是真赌，但大老板不是——比如国美黄老板、金立刘老板，输掉几十上百亿，其实是借着赌局把钱“润”出去，并不是真输。
