# 发光发簪

### 1. 成本与利润
货源是我一手谈好的源头工厂，一次性下单了1000支。拿到手的进价比全网同款都要低，大概是4块多一支。零售价我定在20元，基本没人砍价。真要讲价的情况，只要买两支以上，我最多让2元。所以一支净赚在16元左右。

不过前期没少走弯路，拼多多上找了好几家，质量都拉胯。要么掉漆，要么灯不亮，要么质感很廉价。

[PRE0]
刚开始在拼多多试了169支，有两家算下来5.7元一支，品控极差直接退货了。后来又陆续找了七八家店铺，其中一家勉强能用，价格也在5.5元左右。

[PRE1]
这家店真是踩大坑了，一共只买了20支，发簪七八支都有问题。价格还卖到5.7元。细节做得很粗糙，甚至有掉色，珍珠也老掉。最后只能全部退掉。

来回换货退了三次，全是质量问题，搞得我焦头烂额。于是连夜去找厂家，最终才找到靠谱的源头。产品质感和成色都完全不一样，我也拍了实拍对比图，一眼就能看出差别。不仅做工提升了，价格也便宜了不少。

### 2. 发簪款式
现在工厂出的这些款，我都是用原相机在摆摊现场拍的。整体风格古典华丽，拿在手里像一件有文化底蕴的小艺术品，戴上去很显东方韵味。夜间点亮后，氛围感直接拉满，仙气从灯光里透出来。

[PRE2]
如果中秋夜穿着汉服，手戴发光发簪在街上走，限定版嫦娥就是你本人了。不仅是汉服，穿优雅小裙子或新中式穿搭都能驾驭，日常也能戴。

随身自带一个迷你补光神器，拍照基本不会糊。

[PRE3]
珍珠兔子款特别适合兔年佩戴。金属镂空小兔子精致可爱又不失气场，身上刻了福字，下坠几串珍珠灵动感十足。金色兔子配白珍珠像月宫玉兔，配红珍珠就是喜庆富贵兔，中秋佩戴再合适不过。

[PRE4]
珍珠凉亭款灵感来自古建筑飞檐翘角的凉亭。虽小却玲珑有致，很有神韵。配不同颜色珍珠气质也不同，白珍珠仙气，红珍珠显富贵吉祥。

[PRE5]
珍珠灯笼款可以用古典大气来概括，金属镂空圆灯笼古韵十足。金灯笼配白珍珠雅致，配红珍珠吸睛。还有一点很特别，这款走路会响，有轻微风铃声。

[PRE6]
宝莲灯款也很有看点，几乎就是把中秋花灯做了发簪。圆形灯框里盛开一朵金色莲花，下坠红流苏，点亮后像一盏团圆和美的莲花灯，戴上很有韵味。

[PRE7]
而且所有款式都有一个统一的巧思：簪杆与吊坠连接处做了手捏莲花的造型，莲花下方垂着灯笼形吊坠，视觉上就像一双纤美的手提着中秋花灯。

材质是合金加亮面珍珠，光泽度和颜色都很好，戴一个或者叠戴都好看。发光靠簪顶的灯珠，拔出插片就亮，插入就不亮。灯珠亮度能稳定保持4-5小时，之后会慢慢变暗。想要佩戴时间更长，可选配备用灯珠版本。

# 潮汕竹编灯笼

成本利润和发簪同理，进价大概四块多，零售价15元一个。

别看它是个竹编小灯笼，设计源自潮汕传统竹灯笼。潮汕话里“灯”同“丁”，“竹”同“德”，所以它有“财丁兴旺”“德泽绵长”的寓意。即使现在新式灯笼很多，潮汕人在节庆时仍会挂上传统竹灯笼祈福。

[PRE8]
其中木簪款做得特别精致。黑色提杆一端是幻彩珠和中国结花牌，竹编灯笼用金属丝悬在祥云花牌上，灯笼下还坠着一枚白玉质感的莲花。整体古朴大气，像神女木簪。

灯笼光是柔和的暖光，夜里点亮，周身仿佛被镀上一层仙气柔光，氛围感很强。

[PRE9]
它能用的场景有：
1. 寓意好
2. 可当挂件或摆件，放车内、摆桌面，随手一放都是景
3. 拍照打卡
4. 可当婚嫁装饰，订婚、领证、婚礼上都能用，挂在手捧花上也很出彩

# 摆摊地点
我主打大学城，人流足。周边有学校、大学、公园、夜市都很好卖，景区就更好了。人一聚拢，全都会围过来看。

# 摆摊时段
我一般是晚上8点出摊，10点收摊。白天还要练车、管理闲鱼团队、写稿，所以只做晚场，每天两个小时，稳定收入在300元左右。

[PRE10]
最火的是19:00～20:30。因为产品自带灯光，夜里一亮特别吸睛，路过逛街的人都会停下来看。

另外我还放了两个8元和10元的小玩意儿在测试，卖得好的话再补充。

# 摆摊陈列
很简单，买个竹编手提篮，里面铺泡沫就能插灯笼和发簪。用纸箱或泡沫箱太丑，本来就是卖颜值和氛围。像这种提篮放着不累、好收拾、还好看。

[PRE12]
[PRE13]
我自己用的是提篮加一个背篓，再配一顶草帽盖。货多的时候可以背着、提着，到点再放下。

# 注意事项
1. 地区
一定要先考察，不然像小红书上那么多踩坑的，进场发现卖不出去。
2. 消费水平
消费低的城市，灯笼可能只能卖10元，发簪卖15元。我在的大学城消费还行，一杯奶茶20元，提拉米苏二三十，普通不发光发簪都卖25-30，所以15-20元基本直接成交，砍价很少。
3. 选位
十字路口、夜市、景区、公园、大学城附近都比较吃香。我这边大学城发簪更受欢迎，有次搬到公园门口，灯笼反而比发簪好卖。公园小孩多，灯笼更受青睐，得看人群。
4. 要会沟通
多摆多练，话术慢慢就有了。

之所以小红书上很多人说摆摊踩坑，大多是没提前调研、没经验，大家多留个心眼。
