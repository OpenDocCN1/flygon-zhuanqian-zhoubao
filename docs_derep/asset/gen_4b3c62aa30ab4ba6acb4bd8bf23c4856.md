# 普通人打造个人 IP，先把“摊”摆起来

今天和一位老师交流，我提到他做 IP 最让我佩服的地方，不是某条视频突然爆红，而是这些年一直在稳定更新：视频号、公众号、朋友圈，几乎每天都能看到他的身影。

润宇是视频号商业领域颇有影响力的 IP，也是得到、罗振宇和刘润老师的顾问，还是大型直播活动的操盘专家。但他说，自己并不是那种靠一两次爆款就能迅速出圈的人。

既然没有持续制造爆款的本事，那就换一种打法：持续出现。

当别人一次次刷到你，过了两三年，发现你还在认真分享同一套理念，信任也就慢慢建立起来。看起来不够“聪明”，甚至有些笨，却可能是大多数普通人都能坚持的路。

爆款不是人人都能复制，但稳定更新是自己可以掌控的。每天进步一点，持续把内容送到别人面前，时间久了，自然更容易被记住、被信任。

润宇早期的公众号文章，阅读量只有两三百。他坚持了整整一年半，天天更新，直到某年春节，一篇文章意外走红，也因此进入刘润的视野。

刘润后来回忆，自己起初以为润宇只是个短暂冒头、擅长追流量的年轻人；但长期稳定的输出，加上那篇春节期间的文章，让他对润宇有了新的认识，也逐渐建立起信任，之后双方才有了合作。

在集中发力的阶段，润宇每周直播四场，每天发布一到两条短视频、一篇公众号文章，还会更新五条朋友圈。参加 0607 航海家大会时，他说：“做 IP 没那么高大上，本质上就是民工行业。”

触达足够多，成交才有机会发生；视频拍到一万条，市场上自然少有对手。很多顶尖玩家反复强调的，其实是同一件事：持续做、反复做。于是，关键词确定了，就沿着流程不断拍摄。他目前还有一万多条视频库存没有发布。

最近我也开始做短视频和直播，和她聊过之后，才意识到自己又掉进了一个熟悉的陷阱：总觉得应该先花很多时间学习，准备好了再开始。

但这种想法，更多来自传统教育的习惯。先从头学一大堆知识，几个月后再通过考试检验掌握程度。因为学校里的许多内容有标准答案，学习的目标往往是复现确定的结果。

商业却不是这样。商业机会常常来自未知，也来自信息与认知的差异；恰恰是这些差异，可能带来机会和收益。若等到所有人都学明白了、答案都变得确定，原本的空间也可能不复存在。

所以，从零开始最要紧的，往往不是继续囤知识，而是先迈出第一步。想做，就先做起来；别总研究该怎么入场，先走到场上再说。

创业像推着巨石上坡。刚开始格外费劲，甚至常常前进一点又退回来，但每一次发力都不是白费，它们都在积累势能。只要不轻易停下，推过某个临界点，眼前就会打开新的局面。

说到底，还是那句老话：先干起来。再添上一句——准时出摊，日复一日。
