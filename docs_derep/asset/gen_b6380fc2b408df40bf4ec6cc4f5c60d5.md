花了一个星期，光生图就出了小两千张，我终于做出了一条AI短片《AI在武汉》。

大家好，我是西风残雪，在影视后期这个圈子里待了8年。前段时间刷到央视《爱我中华》的AI宣传片，心里一下子被点着了：AI视频这波浪潮，看来是真来了。于是我把每天除了吃饭之外的时间，几乎全砸在生图上，硬是折腾出了一个短片。

这七天，我先是懵，然后迷茫、焦虑，中途好几次都动了放弃的念头，直到成片出来的那一刻才算松了一口气。我虽然做过不少传统视频，但AI视频对那时的我来说，完完全全是空白。没有捷径，只能去B站、YouTube翻教程，一步一步跟着做。有时候真想摔键盘了，但总觉得AI视频是个不容错过的大机会，最后还是咬咬牙坚持了下来。当然，成片远谈不上完美，人物的脸、腿这些细节还是有不少bug。

视频先放这儿，下面聊聊制作流程。

工具方面，我用的是ChatGPT 4.0、Midjourney和Runway，剪辑由PR完成。整个流程我走的是：文案 → 画面提示词 → 图片 → 视频 → 剪辑。这个顺序只代表我个人习惯，可能和别人不一样，但核心链路应该差不离。

# 总结

这次最大的感受有三个。

第一，我在出图阶段烧了差不多2000张图，绝大多数最后都成了废片，时间白费了不少。尤其是抗战场景，Midjourney死活生成不出我党的军装，出来的一会是苏联红军，一会是德军，偶尔还蹦出国军，垫图、改提示词都没用，最后只能拿雕像顶上。

第二，我的电脑显存太小，带不动Stable Diffusion，所以“图片里插文字”和“全息宇宙”这两个效果都没能做。再加上对SD本来也不熟，真要搞还得先学习，时间成本太大，这次就先放弃了。

第三，先把它做出来，再去谈完美。动手之前，我觉得AI视频难出了天际，Midjourney不会，Runway也不会，可等成片做出来一看，好像也没想象中那么玄。别想太多，先干起来再说。
