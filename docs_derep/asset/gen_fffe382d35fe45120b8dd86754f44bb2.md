# 图生视频

Prompt 精准公式 = 主表现物 + 空间场景 + 动作变化 + 镜头运动 + 美感氛围

举例：
一对情侣坐在公园长椅上交谈，镜头固定拍摄两人，色调偏暖，氛围温馨
一只小羊在草地上低头吃草，镜头缓缓推进，色调自然写实
一位身穿西装的男子面色凝重在面馆吃面，镜头逐渐拉远展现面馆喧闹环境，色调自然
