# 从“伸手要钱”的日子里走出来

生完孩子后我宅家带娃整整四年，生活就是典型的手心朝上。

2021年我回了职场，却只是进了老公的公司打杂。老公外人面前大方，对我却抠得很。

每个月固定领5000块，嘴上说着感恩有饭吃，心里却憋屈。他私底下总瞧不上我，动不动就拿他婶婶在职场多厉害来刺我。

想跟他要点钱都得看脸色，那种不甘心把我推上了寻觅副业的路。

之前踩过不少坑，花过不少冤枉钱，一个钱都没赚回来。是不是脑子笨，是不是运气差，我一度怀疑自己。

# 公众号这条路，我差点就放弃了

去年我正式入了公众号的局。看着一个同行看着平平无奇却能月入好几万，我心动了，直接掏了1299报了课。

结果整整一年，公众号不仅没赚到钱，还倒贴。梦想第二次碎了。

我特别不服气，凭什么别人能我就不行？难道我真的不行？

就带着这股不甘，我硬是咬牙撑了下来。好在撑下来了，今年开始慢慢打开局面，不断突破。

月入过万、日入过万的日子来了。努力没有白费，这个结果值得。

## 头条的教训让我明白流量主有多香

真正让我炸裂的是8月份，流量主直接大爆发，日入五位数了。

这要从头条说起。我很早就注册了头条，以前硬着头皮一天发10篇，想着总能中一篇。一个月下来累得不行，最后还是放弃了。我不擅长写，写10篇根本坚持不住，也没搞懂爆文的底层逻辑。

年初我又买了799的头条课，跟着学，认真写。好不容易来一篇200万阅读，收益200多，心里还有点窃喜。结果下一篇100万阅读，收益只有50多，单价掉得太狠，我有点泄气。

课结束了也不好意思再去请教老师。后来看到亮子老师的课才199一年，我死磕的心又上来了，马上报名。

亮子老师的课让我换了思路，我直接注销了老号。新号在平台的扶持下，发第一篇文章一个晚上就3万阅读，500粉到手，顺利开通了收益。

后来我把头条的内容同步到公众号和百家，东边不行西边补。

很多人吐槽头条单价越来越低，想转视频。公众号如果进不了流量池就等于白发。没有收益谁能坚持？

我去年整年公众号入不敷出都能坚持下来，简直是奇迹。当时一起的姐妹大多悄悄退了，最后剩我们几个。

按课程教的标题规律、爆文机制，再加上AI写作辅助，效率大幅提升，坚持下去的底气也足了。

没多久我进了流量池，一篇文章20万阅读，收益1100多。对我来说已经是超级大爆了。之后就进入了机械化操作，日入几百，偶尔破千。一个月下来轻松过万，我很满意。

我开始更系统地找爆点，让AI写稿，认真排版发布。

惊喜来了，有天早上打开后台，阅读200万+，收益6000+。第二天更夸张，阅读400万+，收益1.7万！

公众号流量主太香了，长尾和爆款双丰收。

之后我持续输出，收益基本每天上千。8月结束月收益8万整。

# 为什么这些文章会爆？我总结了找素材的方法

## 一、爆文到底是什么

说白了就是你写能爆，别人抄也可能爆。它一定会引发大量转发、点赞、评论。

为什么会有人转发？因为触动了情绪。愤怒、认同、好感、共鸣，喜怒哀乐都能成为引爆点。

## 二、怎么判断一个素材能不能爆

## 1、先看是谁写的

复制标题去搜，如果除了大V，还有大量新人也在写并且也爆了，这条素材就值得拿。

大V容易爆不代表你能爆。重点看新人能不能带飞。刷足够多的文章，拆解琢磨，网感慢慢就有了。我报了这么多课，网感就是这么一点点攒出来的。

所以爆文需要持续刷、拆、积累。

## 2、看评论区情绪

以头条为例，公众号留言不一定开。观察读者情绪指数，看三点：

a、有没有正反两派在吵
b、情绪是否统一，比如“太棒了”“就该这样”“中国牛逼”“祖国万岁”这类
c、有没有人讲自己的经历，“我也遇到过”“我朋友就是这样”

占到两条以上，就有爆款潜质。

## 3、看生命周期

社会新闻、娱乐新闻的黄金期大概只有6天，过期就没流量了。事件发生后要立刻写。

不过也要看账号定位，我的号偏娱乐情感，追热点不一定爆。

#### 4、评估对标号

第一，粉丝3万以下且没认证的。说明是新号，更容易复刻。大号随便发都有阅读，不适合参考。

第二，更新频率高。每天都有新文章，等于源源不断给你供弹药。

第三，爆文率超过20%。10篇里能有1-2篇爆就很强。跟上这种号的爆文改编，素材库很快就能建起来。

## 写爆文的心态要放平

别被数据绑架。

当时很多人跟我诉苦，天天发没数据，什么时候进流量池。我当时发头条同步公众号，根本没想进池子，只是先把东西发出去。

赛道也一直在换，社会、情感、娱乐，我最后转娱乐才进池子。

发完我就去忙别的了，早上起来瞄一眼就够了。越在乎越焦虑，放开了反而更好。

现在我就是早上看一眼阅读。没数据就继续发，别人能进我也能进，自信点。

# 最后想说的话

在老马推荐下我加入了生财有术，又加入了航海学习更多内容，想把爆文这件事做大，也想带着更多人一起赚钱。

以前我走得歪歪扭扭，没找对方向，一点成绩都没有。现在回头看，居然坚持下来了，还真有点不可思议。

前阵子有人说我是“二”，我懂，是二八定律里的那20%。终于成了那一小撮。

我庆幸没半途而废。一起起步的姐妹，放弃的太多，做得好的也不少，我是走得慢的那个，最后死磕到底迎来了正反馈。
