嗨，我是安七。毕业一年，我靠“AI+公众号爆文写作”这条路，做到了年入七位数。最近一头扎进了小绿书带货，这也是我在生财写的“AI小绿书”系列第一篇。

先交代一下来龙去脉：9月27日，我和生财10X孵化的@许老师见面聊天，第一次听他说起“小绿书带货”。9月29日，团队伙伴开始准备；10月4日，小绿书带货小分队正式开跑；到今天10月12日，接触这个项目刚好半个月，实操8天。团队里最快出结果的是一个新手伙伴，2天时间就在订阅号卖了50多单，营业额1700+。

这半个月里，我和300多位伙伴反复答疑、交流，又刷了上千个对标账号和文章，慢慢发现：那些容易爆、出单好的小绿书，几乎都符合5个特点——

1. 首图足够吸引人  
2. 标题踩中爆款套路  
3. 正文“干湿结合”  
4. 商品关联度高、满足及时需求、价格又不贵  
5. 排版清爽，有表情、有分段

下面一条条拆开讲。

先说图片。公众号爆文的逻辑在小绿书照样适用：用户没点进来看内容之前，能看到的只有图和标题。小绿书是上图下文，图片的分量更重，尤其是第一张。润宇老师专门分享过“微信大力推广图文带货”，里面有几个关键信息：

1. 小绿书靠“量”对抗概率。  
2. 首图必须打磨。现在的机制下，一个号一般能拿到100～200的初始曝光，但这个曝光量不等于阅读量，因为头图太烂的话，流量就白白浪费了。[PRE0]我有一篇笔记就是活生生的例子：初始曝光2000多，点击只有22，问题就出在首图上。[PRE1]那张图清晰度不够，直接影响了点击。

3. 完读率很重要。之前做公众号爆文就讲究完读率，没想到小绿书也看这个。因为图文本身不长，完读率基本要做到40%～50%以上。怎么提完读率？控制篇幅。如果只配一张图，正文别超过800字，建议10～500字就很好。它是图文，不是文章，别写成大长文，真没几个人有耐心看完。另外，我们测试中发现，有人为了多卖货，在正文里每隔两三段就插一个商品图，非常影响观感。

4. 平均停留时长。真正的大爆款，平均停留时长往往能达到1分钟甚至更多。想拉长？有个小技巧：在第一张图和其他图片的右下角加上一句“向右滑，看更多精彩内容”，引导读者往下翻。

这几点都做到位后，就看发布后的“互动”情况。小红书那边互动数据很透明，小绿书暂时还没公开，但可以参考一个公式：评论＞分享＞点赞＞在看。

再看标题。什么样的标题容易爆？我总结了7类：

干货合集类，比如《【减脂秘籍】一周不重样》[PRE2]。

猎奇类，比如《我独创的拌饭，美味到让人热泪盈眶！》《👀宝子们快来看！怎么看出来一个女孩很聪明呢？》《女人非常傻的8个行为，你占了几个？》。

戳痛点类，比如《让大脑变笨的行为，你中了几招？》《妈妈必看：再不追高，孩子身高就耽误了！！！》《入秋后掉发多的姐妹，试试这个！！》。

符合懒人心理类，比如《5分钟搞定孩子营养早餐》《万能和面公式：有了这个，不会和面都不再是难题》《我愿称它为懒人早餐天花板！！！！》。

利益挂钩类，比如《坚决不删！重度黄脸18个冷知识！不看亏大了》《长期坚持跳绳的隐性成本》《你的转运珠戴对了吗？自查❗❗别戴来霉运❗》。

反差类，比如《竟然被我妈种草！！几十块就养出来初恋脸！！》。

名人效应类，比如《董宇辉推荐的神奇背书7步法》。

接下来是正文。一篇好的小绿书笔记，是“干湿结合”的。对我们创作者来说，不能只爆文不出单，也不能只出单不爆文。我总结了一个正文结构公式：

开头用金句、痛点或故事抓人；中间给干货；结尾换回“我”的视角，走心分享，再说产品对“你”有什么帮助。

自用版，我用的是文心一言APP，提示词大概是：帮我写一条卖跳绳的营销文案，从用户痛点切入，比如想减肥、瘦大腿、瘦腰，写600字左右。

要求：
1. 开头用金句/故事/痛点切入；
2. 文风亲切、利他、口语化；
3. 给具体、实操性强的建议，并分点；
4. 最好有详细数据支撑；
5. 结尾以“我”的体验分享来引导下单，但话术要显得利他；
6. 不说假大空的话，用户痛点要足够真实，让人看完觉得“你懂我”“这篇有收藏价值”“我现在就需要它”。

口令思路就三个词：身份设定+字数控制+具体要求。

身份设定可以多给几个，让它别天马行空。我一般给2～3个，比如：假设你是一个有10年营销软文经验的大师，深谙用户心理，擅长用通俗易懂的文字写出效果很好的种草文。

字数控制是为了让它别超篇幅也别太短。小绿书我一般控制在800字以内，太少满足不了内容需求，太多又影响完读率。

具体要求就得根据你的需求去调，通常不少于5个点，可以包括语言、风格、举例等等。而且往往要根据初版生成的效果，才知道后续要改哪里。

再说选品。根据我们实操，商品对出单影响也很大。满足这三个条件的商品，出单量一般更好：

第一，商品关联度高。我们有伙伴阅读量快上万了，一单没出；也有伙伴10个阅读就出1单。不全是运气，细节很关键。比如有人写减肥跳绳，首图也吸引人，带的商品却是“中学生跳绳”，这和看文章的人完全不匹配。换成成年人的跳绳，出单率可能就高了。不能挂羊头卖狗肉。

第二，及时需求。什么叫及时需求？就是我当下就想要、需要。比如跳绳、招财的东西，看完就想马上下单。经常有人问我为什么不上书籍类的品？因为书籍类竞争大、出单慢。买书渠道太多了，我可以用拼多多买，也可以用微信读书看免费电子版；而且小绿书刚出来，用户人群还没那么精准。如果是爸妈那一代看到书籍类文章，大部分人不爱看书，远不如“红薯”“调料”这类生活用品冲击大。

第三，物美价廉。上次越越也提到过，客单价不超过100元的比较好卖。我们自己测下来也是如此，价格不贵、东西又实用，出单就是更快。

最后说排版。小绿书目前还很粗糙，不能像文章那样加粗、换颜色、调字体大小。但有心的伙伴照样能把它打扮得很好看。怎么排？

1. 分段。电脑上1～2行为一段，手机上1～3行为一段，尽量不要超过4行，不然看起来密密麻麻。
2. 适当加表情。不知道怎么加，就让AI帮忙：“帮我把这段话适当加点表情进去，好看点。”
3. 重点内容用【】标出来。

再送大家一份避坑指南，是小绿书小白最容易踩的8个坑。

1. 为什么我的标题是“分享图片”？别人有图有标题，我的图比例不对、标题也没了？[PRE7]原因很简单：没有填标题，图片比例也没选对。怎么填？手机下载“订阅号助手”APP，点“发表-图片·文字”，然后在里面填写标题和正文。[PRE8]

2. 图片要用商品图吗？不是。小绿书虽然带货，但它不是淘宝，不是直接卖产品。用户是看完你的图文觉得有价值，正好你带了相关商品，才下单。所以图片要么用同行的图，去水印、增强清晰度；要么去小红书搜你想带商品的爆款笔记，抄爆款的图，而不是商品图。

3. 我怎么开通的不是橱窗，而是开了个小店？如果你想做带货达人，正确流程是：开通橱窗→成为达人→在选品中心上架商品。不是自己开店！怎么判断有没有开错？去创作者中心-带货中心主页看，正常（未开店）是这样显示：[PRE9] 误点了开店，是这样显示：[PRE10] 或者这样：[PRE11] 自己开店很麻烦：首先你得有货源/厂家，很多品类还需要资质；而且一旦开店，就不能和达人带货方式并存，没法正常带橱窗里的货。万一误开了，点进小店，终止开店流程或注销店铺，解决不了就找带货中心客服协助处理。[PRE12]

4. 手机订阅号助手里找不到插入商品的地方？把光标点到正文位置，点“＋”，下拉菜单里看有没有“商品”。有就能插。没有，就用电脑：①先找到小绿书的入口页面；[PRE13] ②上传好图片、标题和内容，选择微信小店；[PRE14] 然后就可以开始带货了。[PRE15]

5. 文章发表后需要转发引流吗？不用，看自然流量就行，一般不会那么快。

6. 带货文章多少字合适？800字以内都还行，建议10～600字。

7. 小绿书一天发几条比较好？目前不限制。一般一天最少1篇，1～5篇比较常见。我们自己的服务号，一天发20篇上下。因人而异，想快点爆就多发一点。

8. 小绿书一直没流量怎么办？先问自己：发了多少篇？每篇都做到位了吗？愿意花多久去做？想发一两篇马上就见效，小绿书不适合你，大部分副业也不适合。快的话一两天阅读量就有明显提升，慢的话可能一周甚至更久还是0。如果阅读量一直是0，我怀疑是不是“无脑操作”：标题没改、正文不知道写了啥、图片还是商品图。记住：模仿爆款来，不要自创。重要的事说三遍——模仿爆款来，不要自创；模仿爆款来，不要自创；模仿爆款来，不要自创。模仿爆款的图片和标题，用AI改正文，自己再手动调一调，一般都不会差。
