# 拼尽全力不如选对战场

很多人把成功归结为投入了多少时间与汗水，却忽略了一个更关键的前提：你的力气到底用在了哪里。

战略思维的价值，就在于帮你看清方向。懂得战略的人，会明白该在哪个赛道去较劲，该在哪个环节集中发力，也懂得什么时候该沉默以稳，什么时候该抽身而退。不是不努力，而是把努力放在最能产生杠杆效应的地方。

当你清楚了该争、该止、该发声、该隐退的边界，行动就不再盲目。取舍有了依据，节奏有了分寸，于是可以在复杂局面中从容应对，甚至化被动为主动，实现真正的破局。

努力决定上限，战略决定效率。比起一味地死撑，学会思考“往哪里使劲”，才是更聪明的长期主义。
