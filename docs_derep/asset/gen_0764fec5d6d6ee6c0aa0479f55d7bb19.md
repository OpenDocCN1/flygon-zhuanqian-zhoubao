# 梦想让人抬头，坚持有进成长

很多人都说，人之所以能被记住，往往是因为他曾有一个不小的梦想；而当这个梦想被一点点兑现时，真正的成长才在路上开始。

今天看到的这篇笔记，作者是亦仁的收藏夹，发布于2023-09-01，核心就围绕这句话展开：人因梦想而伟大，又因坚持梦想而成长。

笔记里提到，最近雷军围绕“成长”这个关键词做了一次新的分享。他把自己过往的人生拆解成几个关键节点，讲了几次让他完成跃迁的重要经历，以及在那些节点上产生的体悟。和以往相比，这次的回顾时间线拉得更长，讲的故事也明显变多，信息量与纵深感都有提升。
