以前做连锁店铺装修，行业里的通用打法就是靠项目经理一对一盯场。全国铺开，项目经理就得成倍往上加，人力成本、差旅成本和交付风险全堆在一个人身上，明显跑不通。

我们换了个思路，把装修交付拆成产品研发的协作机制来做。订单管理、专业支持、现场施工三条线分开跑，协同起来。

说白了，就是把过去一个项目经理管1-2个工地的模式，改成1个订单管理员+1个技术支持+若干工长去并行推进N个工地。

现在3个技术支持配3个订单管理员，联动30多个工长，每月稳定推进40多个店铺的装修，同时还能并行管90多个店铺的广告道具下单工作。人效是按几何级数在往上走。

现场管控怎么做到可视化？【今日水印相机】做了品牌定制水印，每张施工照片都带店铺和班组信息，作业状态实时可追溯。和企业微信打通后，现场照片自动云端归档的同时，直接推送到指定施工汇总群。电脑、手机随时就能做全国巡检，跨区域巡检的差旅和时效问题基本被解决。

**能力复用怎么快？**

我们用互联网的沉淀打法做组织进化：共创、分享、学习、改善闭环跑起来。飞书知识库成了核心载体，每周复盘、案例分享、反复实操，知识快速沉淀下来。

内部推学习型组织，目标就是把隐性技能变成显性标准。每个伙伴都有全员开放的个人知识库，也有按环节划分的共创库。好的方法当天就能被全员对齐，新人进来也能通过知识库快速拉齐基准线。

员工手册、作业手册、业务资料全放在知识库里，随拿随用，培训准备效率明显提升。

**（9）客户体验的反响**

交付效率上去了，客户感受更直接。他们开始觉得我们很专业、有方法论，甚至主动邀请我们去给他们的其他服务商做赋能培训。订单开始自带复购属性。

用互联网思维搭起来的管理体系，既把批量交付做通了，也带来了超出预期的服务体验，客户持续下单的信心更足了。20个月的积累下来，在同行里已经形成了明显的差异化，口碑开始自传播。

# 三、回顾

先是锁定细分赛道的增量，从0到1拿下第一个精准客户。随后用互联网思维和工具给团队赋能，接着就是不断重复、梳理知识、持续迭代，把每个项目当成案例沉淀回知识库，再放大。

工具组合主要是飞书的多维表格、知识库、云文档、视频会议、任务、日历等，搭配今日水印相机、企业微信等，实现团队赋能、业务效率提升和客户体验改善的统一。

# 四、总结

**选项目的一些个人思考：**

1. 市场是否有机会，增量空间是否足够大？
2. 行业内有无巨头压制，是否存在成长周期红利？
3. 需求是否持续，痛点是否真实？
4. 如何在同类中快速建立竞争壁垒？
5. 能力能否累积复用，助力业务自然生长？
6. 互联网思维和工具能否实现数据驱动业务发展？

题外话，补充一下我们的背景便于理解。

2022年初我们切入：为连锁企业提供店铺装修标准化服务，同时做招牌广告道具的模块化优化、量产、批量交付。

同年开始搭建数字化管理系统，解决少人化团队完成全国多区域交付、降本增效的问题。最终选择了飞书作为底座。

现在高频使用多维表格、知识库、云文档、审批、视频会议、任务、日历等。我们基于多维表格自建了业务系统，实现全国施工信息在线同步、进度同步、视频验收、费用审批结算、班组管理、组织学习等。

过去月均交付30家店需要15个以上项目经理驻场，还要承担大量差旅。现在3名订单管理员+3名技术人员就能轻松承接，熟练后还有更大提升空间。

飞书这类互联网工具正在重塑传统生意。更高阶的应用我们还在持续探索，希望未来支撑年交付数千家店的目标。
