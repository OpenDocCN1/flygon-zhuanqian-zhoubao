# 《如何体面地收钱》

> 原文：[`www.yuque.com/for_lazy/thfiu8/dko0z5lsifkrxvgs`](https://www.yuque.com/for_lazy/thfiu8/dko0z5lsifkrxvgs)

标签：(149 赞)《如何有礼貌的收钱？》

作者：徐宿

日期：2023-03-31

做内容输出、同时也做创业的人，几乎都会撞到同一个尴尬：

隔段时间就有陌生人来私信求解，问题五花八门，有困惑、有难题，有时甚至连问题本身都说不清。他们觉得你能帮上忙，却忘了你的时间本身就是商品，而且来者往往还没准备好为自己的求助买单。

怎么办？

我把这个困扰拆解后，发现核心不是防白嫖，而是设计一套筛选机制。

先想清楚第一性原理。

**第一条底线：求助者要下注。**

塔勒布提出的 Skin in the Game 很说明问题。没有成本绑定的评价都是空话。你把作品拿给人看，对方说好听，那只是口头客气。因为他没掏钱，也不承担后果。

判断一个难题是否真实，就看对方愿不愿意为解决问题付出代价。若提及投入就退缩，基本说明痛点不够痛。

**第二条底线：我方成本要降到最低。**

时间即货币，赚钱的本质是低买高卖。对方向你索取的其实是你的时间。凡是曾经反复解答过、已经沉淀为文章、视频、文档的内容，就直接复用，别再为零成本的询问手工定制答案。用存量资料应对免费咨询，才能把精力留给高价值合作。

**第三条底线：求助与能力要对齐。**

我长期写个人成长类思考，因而会收到大量生活困局的求助。但很多问题超出了我的研究范围，也没有对应的产品承接。硬接等于用铅笔刀挖隧道，费力且失信。明确告知我的服务边界，比假装全能更能守住专业口碑。

三条边界划定后，实操流程就清晰了。

1、厘清需求。对方一上来就问，先别答。追问他具体卡在哪一步、希望得到什么结果。语言的二次分析往往能让问题自己浮出水面。

2、快速定级。听完描述后判断：属于可直接用公开资料自助的类型、需要一对一有偿深聊的类型、还是不在服务范围的类型。

3、轻问题给存量。第一类直接丢链接、笔记、过往文章，让对方自行消化。

4、重问题导向有偿。预计需要二三十分钟以上才能讲清，就说明：这个问题在聊天框里说不完，建议进入正式的有偿沟通环节，我会给出针对性方案。

5、先谈价值后谈价格。先问：若问题得到解决，对你意味着什么？省了多少钱、花了多少时间？让他自己算出收益，再谈投入是否合理。

如何辨别一个问题是不是真问题？看五个信号。

针对性。问题是否具体到可操作层面，而非笼统抱怨。
态度。沟通中是否尊重、感恩，还是命令式索取。
认知度。是否了解你的背景、案例、过往输出。
主动性。是否主动提及愿意为专业建议支出费用。
紧迫性。是否在某个时间窗口内必须解决。

如何让对方认识到问题的严重性？用提问逼他自证。

"你想通过这次沟通达成什么？" "目前最大的拦路石是什么？" "如果三个月后还没解决，会损失什么？" 一连串追问会让他自己丈量缺口。

再具象化收益："解决了，你的工作效率会怎样变化？收入会不会提升？心情会不会变好？" 当画面清晰了，付费的意愿才起来。

最后把回报量化："一次系统指导，能帮你避开半年的试错，省下的时间成本远超费用本身。" 账目算明白了，决策就自然了。

至于如何让人愉快地买单，关键在于提前布局。你的履历、成果、客户反馈，应该在对方第一次看到你的那一刻就已就位，而不是等到私信阶段才临时展示。

礼貌的本质是什么？

动气通常意味着准备不足。提前把各种越界场景写成话术，流程化处理，情绪就不容易被带跑。

把每次对话看作匹配而非讨债。来访者可能只是想确认你是不是对的人，就像逛店看菜单一样正常。允许对方先观察，是基本的商业体面。

边界清晰也是一种尊重。你可以尊重他人求助的权利，同时坚守自己的服务流程和原则。契合的人会顺着规则进来，不契合的人也能体面离场。

说到底，礼貌不是无底线的包容，而是温暖且有分寸的专业。你的困惑我听得见，我的规则我守得住。若方向一致，我们就一起走一段；若不合适，也祝好。

点赞和打赏是我持续输出的动力。
