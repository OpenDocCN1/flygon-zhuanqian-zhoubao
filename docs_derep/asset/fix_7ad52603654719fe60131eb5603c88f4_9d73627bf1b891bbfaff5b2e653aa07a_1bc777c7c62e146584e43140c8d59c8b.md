# 混群这么久，这些潜规则你真的吃透了吗

有没有这种经历？刚进一个看起来挺活跃的圈子，迫不及待想表现一下，直接把自己的推广链接丢进去，然后就石沉大海了，连句招呼都没等到就被请出去了。

其实混圈子和认识新人一个道理，先把分寸感拿捏住，后续的链接和信任才有可能发生。

社群的本质，是理念相近的人聚在一起交换信息、互通资源、共同进步。把它当成自家广告牌来用，本质上已经跑偏了。

我曾翻过一份社群运营提炼的笔记，里面点破了一件事：管理者最希望看到的，是一个能持续深度对话的生态，而不是营销轰炸区。只可惜总有人不自觉，把讨论区硬生生改造成了推销展台，这就很尴尬。

真正有认知的人，判断的标准从来不是谁刷屏更勤快，而是谁的表达有分量，谁的分享有体感。我见过不少人，动态里全是产品信息，久而久之没人互动，还招人反感。你以为是勤奋，旁人眼里就是典型的营销号，人设自然立不住。

微信互加这件事，情商就藏在细节里。主动递出邀请时，把来意、身份、想对接的内容写清楚，对方一眼就能判断值不值得通过，也显得体面。被动接收邀请时也别来者不拒，先搞明白对方为何来，省得自己被信息干扰。

更忌讳的就是在群里群发低质量广告。你连招呼都不打，也不先判断是否相关，直接甩链接，这已经不是推广，是打扰。想表达诉求，至少先做个人介绍：先致谢，再说明身份和现状，最后点出需求。哪怕配一点小小心意，也比冷冰冰的二维码更容易被接受。

像生财有术这类成熟圈子，规矩写得很清楚：进群要改称呼，链接资源先自我说明，推广信息要走流程，乱加人、撕扯的直接移除。有人觉得门槛高，可正因为有边界，真正想学习和交流的人才有安静的空间。无规矩不成圈，这话在任何社群都成立。

换个视角想，如果你分享的内容能让别人有所得，你提供的帮助被群体认可，资源自然会主动靠近你。这比在群里喊一百次“联系我”都有效。

所以别再把社群当菜市场了。尊重规则，也尊重他人的注意力。你是什么样子，群友心知肚明。你能提供怎样的价值，就能链接到怎样的资源。

这个世界很公平，靠心意经营关系的人，永远比乱抛链接的人走得更远。
