# 大三两年变现三十万，我的互联网实战笔记

嗨，我是行一，2002年生，目前读大三。入行互联网大概两年半，第一个六位数收入已经到手，正在向下一个台阶冲。今天把经历摊开讲，主要想完成两件事：感谢那些在路上拉我一把的前辈和贵人，也给现在还在摸索项目的同龄人一些可供参考的路径。翻到旧QQ空间的动态时，情绪有点上头。

我起步并不顺利。高中被分进重点班，三年下来耗尽心力，最终高考成绩掉到班级末尾。曾经还能排前列的我，第一次体会到落差的滋味。上大学后直接摆烂，每天泡在游戏里，玩《原神》打到段位前段，还逃课爬墙出去闲逛，差点被保安逮住。暑假回家，亲戚一句“都工作年龄了还宅家打游戏”，一下子把我点醒了。赚钱的冲动那时特别强烈，也想证明自己说过的“成年后养活自己”不是空话。

开始搜攻略，看怎么赚钱怎么创业，结果信息过载更焦虑。转折点是看到狗哥2021年那篇关于普通人千万营收的自述，被狠狠击中。狗哥和我是同乡，文字特别接地气。跟着他的线索，我认识了生财有术，也加入了帅张的星球。第一次交知识付费，晚上心疼到失眠，现在回头看，买成长是最划算的投资。

刚进圈子我跟大多数新人一样，疯狂刷内容，大脑被塞满却不知道怎么落地。真正让我开工的贵人是@拱卒。在他的社群里，我认识了同龄的@张梦才，跟着他学快手小游戏；也认识了@金成，我首条抖音刚发就被封，他跟我说自己折腾三个月抖音零收入还亏了豆荚，告诉我坚持才有回报。那段时间我做搬运号，在视频结尾做引导，赚到第一笔线上收入，一万左右。心里清楚对原创不地道，但搬运确实来钱快。后来听师傅建议转原创，要求自己每天发条内容，一个月后，快手上的一条原创游戏素材爆到百万播放。抄同行拿正反馈，再慢慢加入自己的思考，这是我一直信的节奏。

早期也踩过坑。跟学长做校园跑腿小程序，我负责新媒体，第一次系统写运营方案，干了一个月后因和表白墙小程序冲突被恶意竞争，团队解散。那次让我明白：先定一个能稳定回本的核心业务再扩，别上来就铺一堆部门。项目要先用最小成本最短周期跑通，验证后再放大，否则九成会亏。

知乎好物我坚持了四个月，618期间赚了几千。第一月几乎零反馈，心态反复崩盘，后来被老师骂醒，才开始每周稳定更新。洗稿到自我模仿的过程让我悟到，执行力和心态是能练出来的。先复制再超越，适用于几乎所有赛道。

快手小游戏从一天剪一条到套模板十分钟一条，再到多机批量生产，收益才起来。可国家推实名后，这条路迅速变窄。转做棋牌和手游依然是抄同行。宿舍配音是段尴尬回忆，只要我不尴尬尴尬的就是听的人。抖音号再一次被封，幸好有导师帮我稳定情绪。团购探索到四千粉时遇到封寝，只能放弃。现在我给项目做周期管理：验证、爆发、稳定、衰退，还要提前搭护城河，行动-反馈-优化-沉淀-爆发，循环走。原则上一个新方向至少给自己一个月打底，政策敏感类项目除外。

蓝海书单我给自己设了21天目标，第17天就出了单。做法没什么高深：找到头部账号拆解，一周内模仿，见效就放大，不行就换对象抄。批量后需要自己的视频和文案模板，但前提是把专注力提上来。把干扰源列出来，切断信息洪流，专注在一件事上，执行力自然提升。

电商方向我小范围试了闲鱼，开通Pro后体会到动销率逻辑：成交越多权重越高，自然流量就多。未来想探索无货源或蓝海有货源，比如绿植、宠物用品类。相比短视频的脉冲式收益，电商更符合我对长期稳定业务的预期。

最夸张的风口是视频号无人直播。那段时间基本躺赚，我的首场直播GMV就过万。

靠搬运爆款素材养号，开播后观看人数很快上万，单日GMV一度冲到五万。风口结束后平台监管收紧，同行内卷严重，硬扛只会消耗自己，我选择停手转战私域。回头看那波更多是运气，但运气来时手里要有打法才能接住。

目前的主战场是小红书。很多人只认得做小红书的行一，其实前面所有的尝试都是积累。我花了半年研究引流，整理了一份超过五万字的引流拆解文档，主攻教育私域，做高中提分、学习方法内容，后续会往考研方向延伸。团队也试了小红书电商，得益于一个朋友给的案例拆解，起量很快，现在属于头部梯队。

另外，我在带一个近千人的公益实践项目，帮新人实现从零到一的闭环，做利他也做自己的复利。

两年下来，我最确定的结论是：所有项目都能拆成流量-产品-转化。知乎靠搜索+投放，核心是内容模板和持续输出；抖音快手靠剪辑和模仿，但无变现的流量不值得做。视频号的爆发期，选品和人性洞察是关键，爆款大多打的是贪小便宜、好奇和白嫖心理。直播的本质是人货场搭建，复制同行直播间是最低成本的学习法。

当下我更偏向长期主义。视频号还在，但上课期间很难深度运营，先搁置。下一步是深耕私域，聚焦小红书引流到微信沉淀，因为私域资产是自己的。流量可以买，产品可以合作，转化可以靠运营加码，但根本还是流量。跟几位千万级前辈交流后，这个认知更坚定了。

如果要总结成绩，大概三点：一是借助视频号风口拿到第一个六位数，小红书电商两个月利润稳定在八万以上；二是做过百万播放的游戏素材，单日GMV过五万的直播战绩；三是真正沉淀了一套可复用的项目方法论和SOP，第三点才是最值钱的。

给还在起步的新人一句话：别等风，先把自己磨成能接住风的形态。行动、复盘、优化、沉淀、爆发，把这套循环跑顺，你的风口会来。
