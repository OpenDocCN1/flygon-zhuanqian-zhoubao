# 一、为什么我会放下商业咨询，转身做身心灵

很多人好奇，我在商业圈做得风生水起，为什么要空降到身心灵？B端生意那么稳，为什么说走就走？

你可能会有同感。我当年在创业服务领域摸出来一套打法，政府孵化器、同行都在点赞，客户巴结着合作。我的公司曾是国内最大语言大数据服务商的核心供应商，做了七八年硬核乙方。要是继续深耕，商业赛道我依然能大杀四方。为什么要从零起步，去搭新系统？

听我讲个故事。

我从小就是那种成绩爆表的孩子。中考本想混个中专，结果临时决定冲大学，最后九八五毕业，还进校志领了全校最高奖学金，去人民大会堂领奖。

职业经历也跨得很开：开过淘宝、做过地推、写过纲要、做过编辑、管过团队、上过天入过地，然后一头扎进创业深水区，回不了头。现在我做成长陪跑，做的是跟生命质量直接挂钩的事。

[PRE2]

创业那七八年，我的定位很清晰：帮企业赚钱，陪跑CEO。我就是大佬背后的那个女人，商业咨询的尖刀手。

那几年我们服务过几乎所有品类项目，经历过一个又一个风口：互联网+、大数据、AI、VR/AR、机器人、临近空间、操作系统……黑科技见过无数，Hadoop、知识图谱、影像识别、脑机接口，都是常客。

我们陪跑的CEO里，海归、千人计划、海聚专家、行业龙头、名校天才、大厂出身、科学家、U30新锐都有。不少人一年两年就冲成独角兽。

我也因此认识了知果果集团的刘思思。

我是浪潮的参与者、见证者、观察者和亲历者。大部分项目最后失败了，被政策收了，或者艰难苟活。但也有人成了行业标杆、技术先锋、独角兽、万人计划、国字号案例。

转头我还在做跟科技强相关的工作，只是从商业咨询转向神经科学、心理学和量子物理。从陪跑创业到陪跑生命成长营，这个转变看似突兀，其实有内在逻辑。

我的学业事业一路顺风顺水，要什么有什么。然而婚姻给我狠狠上了一课。那段有硬伤的婚姻差点把我压垮，抑郁到想放弃。就是这场至暗时刻，把我推向心理学自我成长，也打开了身心灵的大门。

在学习里我逐渐明白自己的天命：帮人走出痛苦，过上自由丰盛喜悦的生活。过去的使命是点亮商业梦想，现在是点亮生命本身。很久以前我就有个念头：哪里有苦难，我就去哪里。我天生想做一个卸下他人痛苦的人。

[PRE3]

于是我砸了近百万跟国内外顶级大师系统学习理论和技术。

在这个过程中我看到，人类的痛苦实在太多。大多数人并不快乐。真正轻盈富足的人是少数。爱与光、有意义、有钱有闲有自由，这种状态是需要学习和刻意修炼的。

所以40岁我彻底从零开始创办树叶有光，用五年时间完成从商业到身心灵的穿越。

一年多前，我开始探索自我成长、亲子教育等方向。冥冥中被指引到了更细的切口：金钱关系。

1、金钱关系是核心卡点。我顿悟到，钱的关系没理顺，人生哪里都不完整，也谈不上真正的富足。可它被大部分人忽略了，包括曾经的我。很多同修先修内在，后来才发现绕不开钱。

2、95%以上的人都有金钱困扰。有学员连年增收10万都觉得像天方夜谭。

3、我很早就感知到钱有流动规律。想流就流，想回就回。后来系统学习后才知道，这是吸金体底层逻辑在起作用。

4、十多年我一直站在离钱最近的位置。帮企业开源节流，撬动的资金过亿。客户都说我是福星，七年几乎没请过创始人吃饭，都是他们请我，还常发大红包。48小时交付百万结果，群里讲一小时就能带来十几万成交。当时不知道叫群发售，已经在做了。

5、我赚钱相对容易，跟两个信念有关。第一，二十多岁跟闺蜜说会花钱的人才赚得到钱，钱是赚出来的不是攒出来的。第二，妈妈嫌我对象没啥，我说我这辈子不会缺钱，五年后就应验了。

翻手吸金不是运气，是规律。我的工作模式也很自由，一年工作3-10个月，想躺就躺，想去拍照就走。

所以我问自己：我对金钱是否有某种使命？

2021年我就提出：引领更多人活出有爱有光有意义、有钱有闲有自由的六有人生。

2022年10月路径清晰：以金钱关系疗愈为切口，助力六有人生。

现在产品的自动化成交已经跑通：财富体验课&公益金钱关系疗愈个案；六有人生初阶课金钱关系疗愈师师资课；六有人生合伙人创富系统。

# 二、我又一次踩中风口

2014年我入创业圈，那叫创业元年。现在我们迎来疗愈元年。

经济下行期，精神消费在上升。

未来二十年是知识付费也是疗愈时代。70后到90后原生家庭的卡点需要被处理，00后青少年心理疾病发病率已达25%。三年特殊时期更是制造了大量心理问题和负债人群。

焦虑、抑郁、迷茫、崩溃的边缘，是来找我的人的常态。他们说老师我快撑不住了。

社会情绪内耗成为主流。关系、经济、健康、事业的堵点，让疗愈需求爆炸。

潜力赛道供不应求。金钱关系疗愈更是早期蓝海。用金钱这个小切口做疗愈门槛低，新手也能上手。大家都在为钱忙，却没意识到金钱关系本身需要疗愈。

科学也在加持。神经科学、量子研究，尤其是量子纠缠的理念，让改变内在就改变外在变得可落地，反馈很快。

# 三、小红书我走了三步

1.0阶段：当朋友圈发。无知乱发，不涨粉没互动。说明能力背景不重要，懂平台底层逻辑才重要。

2.0阶段：开始学习。去年上半年报了行动营，定位校准后，从0到1，点赞收藏过百，涨粉百余。于我而言是质变。

回看当时的笔记：选题有感觉了，封面难看，图文质感差，几乎不做爆款对标。后来因没时间搁置。中途跟过生财航海，囤了一堆资料，后来回头看视频课操作指南，成了第三阶段的底座。

3.0阶段：闭环打通。我本想外包，发现创始人IP前期必须自己上手。跟合伙人依辰商量后决定自己跑通，再带团队复用。

从想法到执行到结果，我的速度很快。结果证明影响力+引流+变现的闭环跑通了。

# 四、转折点：账号升级后一个月变现3万+
