五、笔记发布规范
（一）标题
1. 借势同领域爆款标题：从之前沉淀的标题库里找对标，结合本次选题方向做微调。标题至少要埋两个搜索关键词，这样系统收录和曝光的机会更大。
2. 标题里加emoji：平台用户偏爱这种轻快画风，带表情的标题在信息流里更跳脱，也更容易被目光锁定。
3. 标题里放数字：数字能提供明确参照，比如“3步”“5个坑”，用户一眼就能判断内容值不值得点。

（二）正文
输出原则：
1. 铺关键词：围绕文章方向尽量多铺关联搜索词，提升被搜到的概率。
2. 用分享口吻写：可以收集抖音、B站同主题视频里的口播，用语音转文字工具把底稿扒下来，再改写成自己的表达。
3. 按结构写：要么走“痛点—场景—方案”的路径，要么直接给可落地的干货清单。

（三）标签
按“通用标签+垂直标签”组合。

（四）发布时间
跟着平台流量波段走，也要看目标人群作息。可用时段：
早上6:30~7:30
中午11:30~12:30
下午4:30~6:00
晚上7:00~9:00是全天最高峰
夜里11:00~凌晨1:00也有流量，但超过1点就不要再发。

六、风险管理
风险意识是账号续命的根基，运营者必须把它刻进日常。

（一）笔记侧风险
图片重复、带水印、洗稿，或文案踩到敏感词，都可能被系统判违规或推进“待优化”池。
[PRE3]
平台的敏感词很多：像“最”“第一”“国家级”“人民”“检查”“党政”“发票”等，出现即限流概率极高。所以每篇笔记发布前都要检查一遍。
限流通常有两种表现：一是后台给“待优化”提示；二是没有任何提示，但笔记发出去24小时浏览量不到100。
处理办法：先查稿子有没有高危敏感词，再用查词工具过一遍。把敏感词删掉或换掉后继续观察，如果流量重新开始推，就说明恢复了。遇到这种情况要立刻上报。

（二）账号侧风险
账号风险主要有两类：禁言和导流。

1. 禁言
禁言多半是评论区踩雷，被系统抓到后封禁。分有提示和无提示：
有提示的禁言会告知解封时间，到期自动恢复；
无提示的禁言需要运营在发完笔记后自己留条评论并置顶，通过这条置顶评论能否被其他人看到来判断账号是否被禁。
无论哪一种，都要马上上报。

2. 导流
导流会由后台直接弹窗提醒。
[PRE4]
收到导流提醒，说明最近做引导的动作没有避开敏感词。
引流时绝不能碰的四条：
（1）任何能看出“我想把人带走”的话；
（2）以任何形式露联系方式和账号信息——不放微信，放微博名也不行；
（3）金融类词汇；
（4）笔记里用“关注领奖”“点赞抽奖”诱导用户，平台对此零容忍。
处罚梯度：
第一次出现导流：7天内不许回复私信，每天正常发一篇，但结尾不留钩子；
第二次出现：14天内不许回复私信，每天发一篇，也不留钩子；
第三次出现：账号基本废了。
一旦发现导流，立即上报，停掉所有引流和发文动作。

3. 限流
限流分两类：
一类是被导流连累，后台弹导流提示后账号往往已经限流，处理思路同导流；
另一类是隐形限流，后台没提醒，运营要主动发现。
判断方法有三：
连续3天发布的笔记浏览量不过百，必限；
创作中心首页“推荐”入口消失，大概一周后就会限流，需及时报备；
连续7天没有任何一篇笔记浏览量破200，大概率也限了。
出现上述情况，马上报备并暂停发文引流，运营要持续盯账号动态。

（三）平台违规红线
笔记层面：留联系方式、非原创、带水印、涉黄涉恐、刷阅读/点赞/收藏、诱导分享。
账号层面：昵称违规、签名挂广告、导流到站外、一机多号、放二维码。
商品层面：偷拍、炒作、违规宣传、谩骂、低俗、涉政、涉赌等。

七、新人入职七天培训安排
前1-2天：
1. 读内部资料，建立基本认知，包括：养号逻辑、运营底层逻辑、导流链路、起号方法。
2. 读完资料后立即尝试发文和导流，熟悉发文要求、平台规定、话术模板（维权通用话术、四大类退费回复案例）。
第3-5天：
在发文导流不踩雷的前提下，开始试写文章。不求量，求跑通流程。先学维权内容的写作要求，再尝试电话卡、租房、驾校这类泛领域内容。
第6-7天：
流程和方法熟练后，开始写精准获客类笔记，比如教育机构、健身房、美容院、情感咨询等垂直方向。
注意事项：
每天还要完成《维权运营岗位流程以及7天工作安排》里的任务；七天结束后按完成情况决定试岗是否转正。

八、2024策划项目工作框架
（一）向外看
1. 拆解同行博主：分同期对标、近期对标、远期对标、终极对标四类。逐个研究他们每篇笔记，把选题全部归类，并列出哪些选题我们也能用。
2. 拆解同行爆款笔记：先分干货型、热点型、营销型，再判断爆点来自哪里——选题、标题、首图、图文内容、文案，还是评论区。内容部、设计部分别要从哪些维度去借鉴。同时记录每篇爆款的发布时间，精确到天和时段，例如“2023.12.3 开题报告 8:00”。
3. 拆解同行营销型笔记：列出所有玩法类型，再按新号、老号分别规划营销笔记布局。整理我们已经用过的首图风格和选题，按50赞以上、50赞以下分开；找出还没用过的类型，规划好未来投放时间和节奏。
（二）向内看
1. 每天分析流量好的笔记：是长尾流量还是短尾流量？属于什么选题？这个新增量能撑多久？其他账号要不要跟进？跟进后如何差异化布局？
2. 每天分析流量差的笔记：内容质量、首图排版、核心词和长尾词铺设、正文、评论互动、选题方向，六个维度逐条排查。
（三）向上看
1. 把团队潜力榨干后，账号上限在哪里？
2. 预判同行账号上限在哪里？
3. 双方上限的差距是什么造成的？
4. 2023年我们所有账号的月均、年均流量是多少？
5. 2024年合理目标是多少，按月、按年倒推。
（四）向下看
每天沉到账号数据里找共性规律，并组织一次复盘会：策划组牵头，内容组、设计组参加，输出会议纪要。必须通过单个账号暴露的问题，预判出所有账号的共性隐患。这件事雷打不动每天做，发现问题立刻给方案、立刻执行，执行后跟踪效果，还要观察问题是否变形、是否有新问题冒出来。
（五）账号冷启动
新账号一个月内怎么快速跑完冷启动，建立自己的护城河？核心看四件事：粉丝量级、点赞收藏数、7日内容配比、30日内容配比。同时要思考：热点型笔记爆了之后，要不要马上追精准型笔记？
（六）部门执行落地
明确各部门输出物、考核方式、关键结果，以及可量化和不可量化指标。
策划组：定选题、定首图和内页排版、定笔记类型、建模型；
内容组：文章数量、文章质量；
设计组：图片数量、图片质量。
策划组还要盯平台流量趋势、行业热点、爆款写作逻辑；内容组看爆文数量；设计组看封面审美；每月还要看咨询量。
策划组每天对设计组、内容组、运营组的工作做抽样检查，并出一份抽样结果表。
