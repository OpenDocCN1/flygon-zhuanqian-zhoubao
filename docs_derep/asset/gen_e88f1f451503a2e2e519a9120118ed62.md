# 一、“我的” 页面要做什么

[PRE0]

说白了，这个tab就是给用户看历史。把之前生成过的海报一条条列出来，方便回溯和复用。

要做到这一点，首先得能把数据取出来展示。但现在的问题是，历史数据根本不存在。

所以必须先解决存储：每次成功生成海报时，就把相关信息即时写入数据库，后续再从数据库里拉取展示。这样“我的”页面才有内容可填。
