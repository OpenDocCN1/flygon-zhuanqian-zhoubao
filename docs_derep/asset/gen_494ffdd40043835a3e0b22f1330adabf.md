# 一、养号+申请激励计划的前期操作

我让一个小伙伴注册了20个号。先在抖音上找对标账号，把名字、头像、简介都包装好，每个号发5-7个视频，每天盯着播放量。第三天开始，就把播放量破千的号拿来查漏补缺——粉丝不够10个的，用其他号随便关注一下就行。

这里有个关键点：激励计划的达标数据是第二天更新前一天的情况。也就是说，你当天播放量到了1000，凌晨12点前赶紧看下粉丝数，不够就补够，第二天数据刷新后基本都能达标，然后直接提交申请就行。审核时间不一定，一般2-7天出结果。这段时间别断更，每天保持1-2条即可。

# 二、开通激励计划之后怎么放大

激励一开通，就可以正式起量了。重点提醒：搞笑、影视、生活这几个方向很有潜力。之前审核用的对标作者作品可以继续搬运。但如果那个作者作品太少，建议直接把账号名字头像全部换掉，重新开号做。因为之前那套操作主要是为了过审核——个人特色鲜明的账号更容易被通过。

重新开号的话，我强烈建议找“二剪搞笑合集”或者生活类热门新闻的账号。这类账号素材多，混着发根本看不出是不是同一个人。每天每个号发20条以上，抽帧、加片头这些去原创手法，生财里讲过很多，我就不重复了。

玩法就是堆量。实测下来，热门新闻类的号播放量最容易爆，但找素材确实更费精力。我们20个号里面，1个冻结、4个审核没过、2个流量太差只有几分钱，换了素材也救不回来——剩下的13个都做起来了。
