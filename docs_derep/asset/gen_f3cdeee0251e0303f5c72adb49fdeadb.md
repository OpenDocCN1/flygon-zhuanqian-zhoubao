# 🔥一键跑通：从爆款视频素材到AI视频成片的工作流

> 资料来源：[飞书文档](https://r0rel9lqdms.feishu.cn/docx/ApaJdYIkcohPKXxgVXLchBoSnwf)

最近把@super 黄和@一泽分享的工具串联起来，搭了一套自动化视频制作流程：点击一次，就能生成一条 AI 视频。

目前实际跑起来还算稳定，首条视频大约需要 5 分钟。它的价值不只在于省时间，更在于可以迁移到其他标准化内容场景。只要内容流程有规律，就有机会通过工作流提升产出效率。把搭建过程分享出来，也欢迎对定制流程、效果优化感兴趣的朋友一起交流。👏🌹

## 一、流程效果

整条链路完成后，可以从素材采集一路处理到视频生成。示例视频主要用于展示工作流，并非实际运营案例。

## 二、需要准备的工具

- Chrome 浏览器
- trae、Windsurf 或 Cursor
- Coze 账号
- 飞书多维表格账号
- 剪映小助手（可通过“剪映小助手下载地址（请点击）”获取）
- 电脑端剪映专业版

## 三、搭建步骤

### 第一步：准备 Chrome 插件

需要分别配置抖音和小红书相关插件。

**抖音插件：**可以从@Super 黄的精华帖中获取，插件来源为@Super 黄。

**小红书插件：**我是在抖音插件基础上，用 trae 改写脚本制作的。可以参照@Super 黄的教程自行开发，也可以联系我获取。

#### 配置时别漏掉这些细节

首先，按要求填写飞书多维表格的相关参数：

[PRE0]

- **APP ID、App Secret：**在飞书开发者后台查询。
- **Base ID、Table ID：**从飞书多维表格链接中提取。

具体获取方式可参考@Super 黄前面提到的教程。

此外，多维表格需要预先建立以下字段：

[PRE1]

- **标题：**设置为文本类型
- **链接：**设置为超链接类型
- **点赞数：**设置为数字类型

这几项如果配置不对，可能导致视频链接无法批量写入飞书表格。这个坑我也踩过😅

### 第二步：搭建文生视频 Coze 智能体

操作方法可以参考我之前发布的内容。智能体工作流来自@一泽。

创建并发布时，有几个关键设置：

- 发布时选择“飞书多维表”选项，才能让智能体调用飞书多维表中的字段捷径。
- 发布前进入“配置”，将“控件”设为“字段选择器”，并勾选所有选项。
- 提交发布后需要等待审核，通常约半小时。

### 第三步：配置视频转文案能力

这部分可以选用两种方案：

1. **自行搭建智能体：**按照@Super 黄的教程制作，无需额外付费，但文案提取效果可能不够稳定。
2. **调用字段捷径：**直接在飞书多维表中调用“视频转文案”捷径，提取效果相对稳定，不过需要登录 API 账号并购买 Token。

| 方案 | 优势 | 不足 | 更适合 |
|---|---|---|---|
| 自建智能体 | 免费 | 提取效果可能不稳定 | 个人使用 |
| 调用字段捷径 | 效果较稳定 | 需要付费 | 商业场景 |

### 第四步：配置飞书多维表格

打开前面设置 Chrome 插件时使用的那张表格，按流程添加字段捷径：

- **标题、链接、点赞数：**作为基础字段固定设置。
- **文案提取：**添加字段捷径，选择你创建的视频转文案 Coze 智能体。
- **风格分析：**添加 DeepSeek 字段捷径，根据需求编写指令，并引用“文案提取”字段。
- **改写文案：**同样调用 DeepSeek，按需要设置提示词，并引用“文案提取”内容。
- **火柴人视频：**选择自定义的文生视频 Coze 智能体，并让它读取“改写文案”字段。

表格的基础设置可以参考相关教程。配置字段时记得拉到页面底部，打开“自动更新”。

## 四、这套流程能带来什么

### 从辅助提效，走向直接产出

把两个工作流组合起来，本质上是尝试打通内容生产的多个环节：爆款选题、生成大纲、撰写口播稿、录制、剪辑、制作封面标题与图片、发布运营，以及后续的数据复盘。

其中部分步骤还可以继续通过脚本或智能体自动化。AI不再只是帮忙加快某一项任务，而是能够参与生产一套可复用的内容结果。

### 不只适用于一种视频类型

这套流程大致可以概括为：

**输入：**采集热门内容数据  
**处理：**链接转文本、分析内容、提炼重点、改写，并生成图片、语音或视频  
**输出：**图文或视频内容

工作流的框架搭好后，可以根据最终想要的内容形式，反向调整每一步的执行标准和提示词。对于模板化程度较高的内容，都有机会迁移使用。除了常规产出，AI在内容拆解和视觉呈现上也可能带来意料之外的结果。

例如，可以尝试：

- 结构化故事：[PRE8]
- 养生主题：[PRE9]
- 食物科普：[PRE10]
- 育儿知识：[PRE11]

还可以接入即梦、可灵等工具，按需生成 3D、超现实、赛博朋克或极简等不同风格的画面；语音也能通过工作流插件切换不同类型的 TTS。之后如果再接入 https://www.lovart.ai/，或许还能拓展出更多玩法。

### 效果稳定性取决于工具与配置

理论上，使用的插件越稳定，整条链路的输出就越可控。如果遇到效果或运行问题，也可以视实际需求增加平台 Token，或替换更合适的工具。

## 五、搭建过程中的一些体会

第一次把脑海里的想法真正做成“一键运行”的流程，确实很有成就感。过去人工完成选题、制作一条视频，往往要花上几个小时；现在看到自动化链路跑通，会忍不住感叹：AI还能这样用。值得继续探索它带来的各种可能。

当然，当前成片还有不少粗糙之处。这次先记录并分享出来，后续主要可以从两方面迭代：

1. **筛选工具：**寻找运行更快、稳定性更好的插件。
2. **持续优化提示词：**搭建过程中最花时间的往往是调试输出结果。尤其设计智能体人设时，限制条件写得越清楚，回答越不容易偏离预期。

至于商业化能不能跑通，还需要放到真实场景里持续验证。可以先选一个方向做长期实验，再根据实际反馈调整。

最后补充一句：这套流程是由一位技术小白搭建出来的。只要愿意动手拆解和尝试，很多想法都可以从设想变成可运行的工作流。
