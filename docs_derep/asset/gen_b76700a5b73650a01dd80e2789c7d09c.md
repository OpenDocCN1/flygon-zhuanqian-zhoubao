# 为什么要使用指纹浏览器？

做跨境电商运营时，经常会遇到这几类情况：

1. 单台电脑需要登录同一平台的多个店铺，比如同时运营多个亚马逊店铺。
2. 单台电脑需要登录不同平台的店铺，比如既有亚马逊又有速卖通。
3. 单台电脑需要登录同一个社交平台的多个账号，比如多个 Facebook 账号。
4. 单台电脑需要登录多个不同社交平台的多个账号，比如 Facebook、Instagram、Twitter 并用。

在这些场景里，风险最高、必须重点防范的是第1种和第3种，也就是在同一台电脑上操作同平台下的不同账号。

因为绝大多数平台都不允许一人多号，所以我们要做到平台检测不到是同一个人操作的多个账号。这一点对国外平台同样适用，国内平台也一样需要警惕。

那怎么解决呢？

核心思路就是给同平台的不同账号做环境隔离，用不同的浏览器环境+不同的IP，也就是不同宽带网络，来实现账号隔离。

给每个账号分配一个独立的浏览器环境，再给每个浏览器环境分配一条专属的IP。这样账号之间就互相独立了，平台就难以识别这些账号来自同一台电脑或同一条网线。

# 有哪些账号隔离方案？

举个例子说明。

假设我有两家亚马逊店铺，想避免店铺关联。传统做法是：买两台电脑 A 和 B，拉两条宽带 C 和 D。A电脑配C宽带登录第一个店铺，B电脑配D宽带登录第二个店铺。

这样确实能隔离，但成本高、操作繁琐，要在多台设备间来回切换。

目前行业里主流的替代方案有两种。

第一种是 VPS。租用云服务商的 Windows 服务器，比如阿里云、腾讯云，通过远程桌面操控。浏览器环境和IP都不一样，也能隔离。但远程操控卡顿明显，使用体验较差。

第二种是紫鸟浏览器这类指纹浏览器软件。可以在同一软件里开出无数个相互隔离的浏览器环境，再为每个环境绑定一条独立IP。

优点是流畅不卡顿，IP可以直接在软件内购买，搭配过程简单，价格相对 VPS 便宜，且支持设置账号权限，方便团队协作。

现在业内普遍采用的就是第二种方案。

不过要注意，紫鸟浏览器因政策限制，无法访问 Facebook、谷歌等国内屏蔽的平台。

# 什么是浏览器的指纹？指纹浏览器有什么用？

浏览器指纹是一种识别技术，通过浏览器各种配置和参数来辨别用户身份。比如 UA、时区、地理位置、IP、语言等。就像人的指纹能区分个体，浏览器指纹也能区分不同的浏览器。

它有什么用？可以记录用户的UA、时区、地理位置、IP、语言等信息，帮助网站精准识别和标记用户，从而实现个性化推送和广告定向。

简单说，如果你在同一个浏览器里登录同平台的多个账号，比如同时登录两个亚马逊店铺，亚马逊完全可以通过浏览器指纹和IP信息判断出这两个店铺出自同一台电脑，很容易判定关联进而封店。

指纹浏览器可以同时开启多个独立浏览器环境，并自定义修改指纹参数。这样就在同一设备上安全使用多个账号，降低关联风险。

另外，指纹浏览器也便于团队协作：同一个浏览器环境可以被不同电脑的多人同时打开，账号信息保存在环境内部。

需要强调的是，不同平台的安全风控强度不同。即便做好环境和IP隔离，也不能 100% 杜绝关联，但这是实现账号隔离最基础的要求。

# 什么是住宅 IP？什么是服务器 IP？什么是动态 IP？什么是动态住宅 IP？什么是手机 IP？

为了后面内容更好理解，先普及几个IP概念。

住宅IP也就是家庭宽带IP，说法不同而已。住宅IP是由运营商ISP分配给家庭用户的地址。

住宅IP带有地理位置属性，但并非固定不变。多数情况下运营商会动态分配，路由器重启或网络变动后IP可能更换。而且分配的IP不一定在你实际所在地区，因为IP资源有限，可能给你分配其他区域的地址。

因此，家庭宽带IP本质上是不固定的，随着时间地域轮转变化，所以也叫做动态住宅IP。

数据中心IP也叫机房IP或服务器IP，本质相同。由IDC机房、企业专线、云服务器提供。

数据中心IP特点是固定、稳定在线，但号段多为连号，难以灵活更换，在业务风控中易被识别。

静态住宅IP是固定不变的住宅IP，需向运营商单独申请，企业用户为主，价格昂贵，个人使用不划算。

动态住宅IP的安全可信度高于静态住宅IP，因为它就是真实家庭宽带，更贴近真人环境。

手机IP是质量最高的IP，来自真实手机和基站，更接近自然真人上网。动态手机IP则会自动变化。

综合安全性排序大致为：

手机IP > 住宅IP > 服务器IP

日常运营中，住宅IP或服务器IP已足够。服务器IP最便宜，动态住宅IP价格更高，静态住宅IP最贵。

选择哪种IP要根据业务场景和平台风控强度来定。

另外提醒一个避坑点：市面上很多号称静态住宅IP的，其实是服务器IP冒充。真正的静态住宅IP供应很少且价格高。

# 不同的 IP 是怎么收费的？

各服务商收费标准不一，下面是常见情况举例。

静态服务器IP一般按月收，一个月几美元到几十美元不等。

动态住宅IP一般按流量消耗计费，比如1G流量约10美元。

静态住宅IP一般按月+流量双收费，比如月费20美元，另加1G流量25美元。
