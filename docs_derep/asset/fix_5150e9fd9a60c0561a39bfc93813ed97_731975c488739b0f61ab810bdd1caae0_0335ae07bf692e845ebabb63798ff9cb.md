# 影刀批量发布配置指南：公众号与小红书的表格、账号及运行设置

这是一份面向 Windows 用户的操作说明，适用于通过影刀 RPA，配合 Edge、Chrome 或比特浏览器，完成公众号和小红书的内容发布。

目前这些应用无法在 macOS 环境下直接使用。Mac 用户需要自行准备 Windows 双系统或其他 Windows 运行环境。

---

首次运行前，还要完成浏览器插件部署。插件范围包括 Edge、Chrome 和比特浏览器，具体安装步骤请参考对应的内部配置说明。

# 二、公众号自动发布

## 1. 发布前的账号准备

先在 Edge 中打开墨滴编辑器：

https://editor.mdnice.com/

再分别进入各个浏览器用户配置，登录相应的公众号后台：

https://mp.weixin.qq.com/

第一次使用墨滴时，需要先建立一个文件夹，并在其中新建一篇文章标题，作为后续内容处理的基础。

公众号模板地址：

我用夸克网盘分享了「公众号自动发布模板」，点击链接即可保存。打开「夸克APP」，无需下载在线播放视频，畅享原画5倍速，支持电视投屏。

链接：https://pan.quark.cn/s/bd20a449f085

模板下载完成后，可以配合洗稿工具生成的内容一起使用。

## 2. 配置工作表

建议先把整张表的单元格格式改成“文本”，这样能够避免数字、路径和特殊字符被表格软件自动处理。

### A：浏览器窗口编号

这一栏用于标记比特浏览器中的窗口序号。

如果还不清楚如何取得窗口编号，请先查看比特浏览器插件的配置教程。

[PRE12]

[PRE13]

[PRE14]

[PRE15]

### B：内容工作表名称

这里要填写文章所在 Sheet 的名称。

不要使用单独的数字作为名称，例如只写“1”。可以使用中文，也可以采用“数字+连接符”的形式，例如“18-0”。

需要特别留意：

- “配置页”这个工作表名称必须原样保留；
- 其余 Sheet 可以命名为“旺仔”“创业”等，但配置页中填写的名称必须与实际工作表完全对应。

[PRE16]

### C、D：文章处理区间

这两栏用于确定某个内容 Sheet 的处理范围：

- C栏记录起始行；
- D栏记录终止行。

例如，“旺仔”工作表从第2行处理到第3行，则对应配置项应填写2和3。

[PRE17]

[PRE18]

启动页中的起始与结束行，和这里的文章行号不是同一个概念。内容表的行号只负责界定该账号要处理哪些文章。

单次最多配置8篇内容，请提前确认范围不要超出限制。

[PRE19]

### E：运行结果

该栏通常无需手动操作。对应 Chrome 窗口结束运行后，系统会将执行结果写入此处。

---

## 3. 文章内容表字段

### A：原创声明

需要声明原创时，填写原创作者名称；不启用该选项时，不填写任何内容。

### B：标题

录入文章标题。

### C：正文来源

可以采用两种方式：

1. 使用洗稿工具处理过的内容，直接复制生成后的表格；
2. 使用自有文章时，填写文章所在文件夹的地址。

第二种方式下，文件夹中只能放置一份 Word 文件。

### D：封面文件位置

在图片上点击右键并复制路径，可能得到类似下面的结果：

"F:\下载文件暂存\海报中转\蓝色科技扫码关注公众号二维码.png"

填入表格时，去掉前后的引号，变为：

F:\下载文件暂存\海报中转\蓝色科技扫码关注公众号二维码.png

不使用封面时，该格不填写。

### E：话题标签

需要添加话题时，直接使用井号格式，例如：

#话题

没有话题时不填写。

### F：原始文章链接

需要保留出处时，将网址粘贴到此栏；没有链接则不填。

### G：内容来源类型

模板预置了4类来源，必须按照模板中的写法填写，不要自行改动。

例如选择 AI 来源时，输入：

ai

无需标注来源时，不填写。

### H：发布反馈

文章处理完成后，系统会自动记录状态，方便后续核对。

### I：统一开场内容

如果每篇文章开头都要插入同一段文字，先建立一个 Word 文档，把这段文字保存进去，再将该文档的完整路径填入 I 栏。

[PRE20]

### J：统一收尾内容

需要在文章末尾追加固定文字时，操作方式与开头相同：新建 Word 文档，写入固定结尾，再把文件位置填写到 J 栏。

[PRE21]

---

## 4. 启动页的行号含义

启动页面的起止行，指向的是“配置页”中的行，而不是内容工作表中的文章行。

例如，从第5行启动，表示从配置页第5行对应的账号窗口开始执行；结束行也是按配置页位置判断。

运行口令：

生财有术

# 三、公众号：比特浏览器多账号方案

## 1. 登录账号

在 Edge 中打开墨滴编辑器，并在不同的比特浏览器用户中登录各自对应的公众号后台。

首次使用墨滴时，仍需提前建立文件夹，并在其中设置文章标题。

[PRE24]

## 2. 表格填写逻辑

多账号模式的配置方式与前面的公众号设置相同：

- A栏记录比特浏览器窗口编号；
- B栏填写对应内容 Sheet；
- C栏指定内容起点；
- D栏指定内容终点；
- E栏查看运行结果。

文章页中的作者、标题、正文来源、封面、话题、链接、创作来源以及统一开头和结尾等信息，也按照公众号内容页规则录入。

## 5. 小红书内容表填写

### A：笔记类别

在此处指定发布形式：

- 图文；
- 视频。

### B：处理方式

模板预设了三项：

- 立即发布；
- 定时发布；
- 保存为草稿。

这些选项名称应保持模板原样，不要自行替换。

草稿功能需要特别注意：平台只保留最近一次草稿记录。保存草稿后继续执行发布任务，原来的草稿可能被新内容替换。

### C：素材目录

填写素材所在文件夹，并确认其中只放本次要上传的图片或视频。

图文内容需要先给图片编号或排序，排在首位的图片默认作为封面。

[PRE28]

视频内容建议将视频和对应封面放在一起，视频采用 MP4 格式。

[PRE29]

### D：视频封面位置

发布视频时，在这里填写封面图片的完整路径。

示例：

F:\旺仔\旺仔创业引流\rpa引流\自动发布工具\小红书发布\测试\视频存放\2.jpg

如果是图文笔记，或者视频没有单独封面，这一格不填写。

### E：标题

填写笔记标题。

### F：正文文本

把准备好的文案粘贴进表格即可。表格中的换行与排版会同步到发布页面。

### G：话题标签

需要添加话题时使用：

#话题

没有话题则不填写。

### H：地点

需要展示地点时，填写具体位置；不使用地点功能时保持空白。

### I：合集序号

按照合集列表的排列顺序填写编号：

- 排在最前的合集填1；
- 后续合集依次递增。

未选择合集时不填写。

### J：群聊序号

群聊编号的规则与合集一致，按列表顺序填写1、2、3……；没有群聊则不填写。

[PRE30]

[PRE31]

### K：定时执行时间

需要预约发布时间时：

1. 先在 B 栏选择定时发布；
2. 再在 K 栏填入时间。

格式示例：

2025-03-15 11:20

不使用预约功能时，K栏不填写。

### L：执行状态

这栏由程序在运行后写入，无需人工录入。

### M：商品编号

如需挂载商品，将商品 ID 填入此栏。

同时挂载多个商品时，使用斜杠分隔，例如：

67ced07a9635/671ae3e3a

## 6. 启动参数

启动界面需要设置：

- 起始位置：内容表的第一条处理行；
- 结束位置：内容表的最后一条处理行；
- 间隔时长：建议使用60秒。

间隔太短可能触发平台验证，因此不建议为了追求速度而压缩等待时间。

[PRE32]

## 7. 登录小红书账号

完成表格后，在 Edge 或 Chrome 中登录需要发布的小红书账号，再启动影刀任务。

## 5. 小红书内容页

多账号模式下，内容页的字段含义与 Chrome / Edge 单账号方案相同：

- A栏：图文或视频；
- B栏：立即发布、定时发布或保存草稿；
- C栏：图片或视频所在目录；
- D栏：视频封面地址；
- E栏：标题；
- F栏：正文；
- G栏：话题；
- H栏：地点；
- I栏：合集序号；
- J栏：群聊序号；
- K栏：预约时间；
- L栏：运行结果；
- M栏：商品编号。

图文素材应提前排序，第一张图片会被视为封面；视频建议使用 MP4，并根据需要额外指定封面。

草稿模式只保留最新的一条记录，继续执行其他任务时，原草稿可能被覆盖。

[PRE44]

## 6. 启动运行

多账号方案的启动行，指的是账号配置页的行位置，而不是内容表中的文章编号。

例如，配置页第5行对应某个账号，那么起始行填写5，就会从该账号开始执行；结束位置同理。

[PRE45]

最后检查以下项目：

- 浏览器账号是否登录正确；
- 内容 Sheet 名称是否匹配；
- 文件夹与图片、视频路径是否有效；
- 起始行和结束行是否填写准确；
- 发布间隔是否合理。

确认无误后即可启动影刀。
