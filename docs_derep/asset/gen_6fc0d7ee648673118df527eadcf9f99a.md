# 7年课程制作经验，知识付费怎么做？这套方法请收好

大家好，我是大卷。这些年我一直在做知识付费课程，算是专业选手。趁着最近稍微空一点，赶紧把立过的 flag 兑现了。

现在很多人想搞副业，第一反应就是去做知识博主、做爆款课。但动手之前，有没有认真想过：我们到底为什么做课？

想赚钱？

再往深一步问：真的只是为了赚钱？

说实话，大多数人对“知识变现”的理解太窄了。觉得知识付费就是拿内容换钱。可只要把时间线拉长就会发现，从古至今，人们一直在用知识换价值。知识变现不是一个新鲜概念，而是早就存在的一种方式。

所以，先把做课的目的想透，再想怎么做课，顺序不能反。
