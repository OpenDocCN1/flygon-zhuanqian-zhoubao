# 入局小红书做上海房产，两个月卖掉一个小目标，这个冷门赛道怎么被我跑通的？

大家好，我还是那个做小红书运营的老兵。

之前我一直在电商行业摸爬滚打，烧过几千万广告费，擅长的事说白了就两件：做爆款内容和用聚光放大流量。去年底，我和珍妮子、陈铭Ivy开始合伙搞事，我们盯上了一个几乎没被小红书玩家认真做过的赛道——上海房产。准确说，是二手房单边代理。

当时接到这个项目的时候，客户的需求非常直接：他们是一家上海的房产单边代理公司，希望我帮他们做两件事，第一，找到更多正在卖房的上海房东；第二，帮他们招募房产单边代理人。

说实话，刚接到这个需求的时候，我们心里也没底。因为我们对房地产这个赛道，几乎是从零开始。但我觉得，小红书的核心逻辑是通用的，不管你是卖课、卖旅游、还是卖房，只要你搞清楚用户的痛点和内容的表现形式，就有机会用极低的成本撬动流量。

从接手到跑通，我们大概花了两个月的时间，最终的成绩是——两个小目标可能说得有点夸张，但1个亿是实打实的成交额。今天不吹不黑，我把这个项目的0到1完整拆解给你看，尤其是前端流量怎么打、后端筛选怎么做，以及单边代理人这个听起来很陌生的职业，是怎么被我们重新定义的。


先交代一下背景。

上海的新楼盘越盖越多，二手的存量房自然也跟着越堆越多。但问题是，买房的群体并没有同步变大。房源多、买家少，这个天平一旦倾斜，二手房的玩法就彻底变了。

以前是“买房难”，房东握着房源不愁卖；现在是“卖房难”，房子挂出去几个月连个带看的都没有。

传统的房产中介靠什么赚钱？成交佣金。所以在这种行情下，中介最理性的选择是什么？是帮买家去砍房东的价格。为什么？因为买家少，砍到一个是一个；房东多，你砍跑了这个，还有下一个。

如果中介反过来帮房东，买家这边就不乐意了，那他就得重新去找买家，而买家是稀缺资源。所以你去看，现在市场上的中介，几乎没有人真心实意站在房东这边。

大部分房东根本意识不到这件事。他们还是像十年前一样，把房子丢给中介，然后等消息。结果就是：房子卖不掉，或者卖亏了。

这个供需错位催生了一个新物种——房产单边代理人。

什么是单边代理人？就是专门站在房东这一边，用专业能力帮房东把房子卖出去的人。从定价、推广、包装到谈判、成交，全程帮房东把关，目标是让房东在合理的价格下，尽可能快地卖掉房子。

客户的需求不难理解，难的是流量从哪里来。


接手项目后，我们做的第一件事，不是马上写笔记，而是先花了一两周时间，拼命补课。

我们把上海房产圈几个头部公众号、视频号近半年的内容全部刷了一遍，又把得到上的房产经纪课听完了，贝壳经济学堂也过了一遍。说实话，网上大部分大V的观点都是片面的，真正能用的可能只有一两成。后期在地产合作方的纠偏下，我们才慢慢筛出了相对靠谱的打法。

但说到小红书上的行业现状，我们有点傻眼——这个赛道，在小红书居然没有一个像样的对标账号！

这意味着什么？意味着所有爆款套路都要我们自己从零开始试。

我们的第一步，是先分析这赛道的常见错误打法。我总结了三种典型的“死法”：

第一种，送卖房宝典。这种玩法引来的全是想自己DIY卖房的人，真正愿意为单边代理付费的客户少得可怜，甚至还会混进来一堆同行中介。

第二种，拆解自己如何快速卖房。这种内容发出来确实有流量，但评论区全是“接好运”“沾沾喜气”的，来的人根本不是目标客户。

第三种，直接科普“房产单边代理”。结果就是，除了同行，没有一个真实业主看得懂你在说什么。

所以我们面临的核心问题，就是重新定义“房产单边代理”这个听起来太专业的词。

后来我们找到了一个词：卖房管家。

“管家”这个词，业主一看就懂，而且天然会让人觉得：这好像和中介不太一样。就这么一个简单的替换，内容就有了被真实业主点击的理由。

有了这层定位，我开始梳理行业内的正确观点，整理成笔记素材。有几个观点，当时给了我们很大的启发，这里简单分享几条：

第一，卖房的周期比价格更重要。如果你要换房，时间就是金钱。少卖1%，用来换更快的周期，绝对划算，因为你先拿到钱，去买下一套的时候，砍价也更从容。

第二，不要等市场好了再卖。多数人总觉得行情不好先不卖，问题是行情好的时候，你要买的房子涨得更多、周期要求更短，你反而更亏。还不如趁市场冷，把价砍狠一点，把周期拉长一点。

第三，一定要拿到今年的成交数据来做定价参考。不要拿去年甚至前年的价格锚定自己，同户型、同楼层、装修、税费、周期，每一项都在影响最终的成交价。

第四，底价绝对不能提前亮给中介。不管中介跟你说有个客户多么靠谱，只要没见到买家本人，底价一个数字都不能透露。真正的底价，只应该在谈判桌上释放。

第五，报价不能虚高，越想卖高价，越不能报高价。着急出手的，报价不要超过底价的2%，贴着成交价走，反而能被打上“必看好房”的标签；中介愿意推，前两三周的黄金成交期就能抓住。不着急卖的，报价也最好控制在底价的4%以内。报得太高，中介根本懒得推你，因为推不动的房源等于无效房源。

第六，不要签独家代理。一旦签了独家，你就被中介锁死了，后面中介为了成交，会反过来PUA你降价。

第七，想办法加大房源曝光。跟中介搞好关系，多让他们带看。一套房被带看100次和10次，结果是完全不一样的。

按这个思路，我写的第一篇笔记，直接爆了。后续在这个打法的加持下，我们几乎做到了每篇都是爆款。

这个阶段跑通了以后，我马上做了三件事：

第一步，梳理SOP流程，培训小助理。我把打法写成傻瓜版操作指南，每一步都附上示范案例，然后拉到群里分章节拆解，强调按自己时间交稿就好，遇到卡住的再拉小群单独辅导。目的就是让他们先把最基础的事情做起来，不要一上来就问问题。

第二步，注册多个蓝V账号，做矩阵号布局，同时配合聚光投流放大。我自己是电商出身，投流这块算是老本行。这个行业平均点击单价0.7元，我硬是压到了0.2元。不算不知道，一算吓一跳：我们投了2.4万元广告费，加了1175个精准微信。上海房子均价500万起，哪怕只成交一单，5万佣金就把投流成本全覆盖了——实际成交了11套。

第三步，跟后端老板不断开会打磨话术，几十场腾讯会议下来，终于建立了一套完整的房东筛选机制。加了微信的房东质量参差不齐，我们通过一套话术快速甄别出真实卖房意愿强、房子有竞争力的房东，然后引导到线下见面，由老板团队负责签约交付。


跑通了房东端的流量，第二步就是招募房产单边代理人。

这一步我决定还是从小红书下手。很多人问为什么小红书能做这么多高客单行业？答案很简单：小红书的底层逻辑，本质上就是“精准关键词 + 人群痛点 + 爆款封面”。这套东西不管放在旅游、教育还是房产赛道，都有效。

我先去小红书上搜“创业”和“转行”这两个关键词，然后找到了一篇近期刚爆的笔记，大概内容是讲一个人怎么转行做某件事、年入多少万。我参考了它的封面设计，重新做了一版类似的封面，标题也套了个相似的句式：“一人干房产代理人，去年赚了124w”。

结果第一条笔记就爆了。

爆了之后我干了一件事，很多人可能想不到：我把自己那条爆款笔记的标题和正文小改一下，又发了一遍。依然爆。

爆款都是重复的，不爆的才需要重新设计。第一篇不行就换第二个封面，数据下滑了就重新去搜对标爆款，不断重复这个过程。

半个月，我发了20条笔记，微信加了400多个人，而且到现在每天还有人来加。小红书的推荐机制决定了，一篇爆文的生命周期可以持续很久。这就是长尾效应的价值。

珍妮是我见过最厉害的小红书操盘手，没有之一。她每天会拆解40多个赛道的打法，我所有的爆款笔记，都是在她指导下做出来的。陈铭Ivy在商业模式和项目统筹上的功力，也是让我佩服的。这个项目的0到1，就是她一手策划出来的。

还有我们的合作方老板，他是我见过格局最大、最智慧的人。
