要点提示：

带货视频在总视频中的占比很有参考价值。占比高说明达人对商业化路径很熟，基本是专业带货号；占比低可能是刚试水带货，或本身比较注重内容调性，带货发布较克制。

反过来，结合粉丝量一起看带货视频的播放与互动数据做初筛也很重要。若长期出现粉丝高但播放低的情况，需要警惕账号健康度。

产品熟悉度是前提，集中火力打造热销爆款。

| 产品阶段 | 建议达人类型 | 作用 |
| 新品上市 以预热曝光为主 | 以传播型为主 | 多圈层种草、造势、全面覆盖 |
| 带货转化 以结果为准 | 以垂类为主、跨圈为辅 | 精准人群种草、拿转化数据 |

红人沟通小贴士

1. 确认地址后，请达人给出计划的视频发布时间，达人自己承诺的时间兑现率更高。
2. 如达人说一周后发布，确认合作brief时要二次强调具体截止日期，例如1月23日前发布，用不同方式重复时间。
3. 尽量把交付时间控制在2周内，最好1周，周期越长履约率越低。
4. 与达人沟通内容重点只定一个点，便于执行，也更有利于内容集中爆发。
5. 后台私聊即可初步看数据，铺量时先联系，有回复再精挑。测试期若达人表示sample request已用完，则排期会很久，合作后容易流产。

红人约束要点

交付不达标、失联、无发布怎么办？

规避与约束并用。

规避：对已有一定带货量的达人，基本具备合作信誉，骗样品的概率低。建联过程中重点判断其对项目的兴趣度和沟通积极性。

约束：尽量走官方平台建联。
