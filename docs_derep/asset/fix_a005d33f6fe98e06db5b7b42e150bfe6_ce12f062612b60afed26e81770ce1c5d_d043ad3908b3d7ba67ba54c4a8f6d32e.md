先说说目前的进展。我接触 Shorts 还没多久，谈不上方法论，离 YPP 变现资格也还差着十万八千里。

背景交代一下：
完全零起点，YouTube 是头一回碰，Cursor 更是第一次听说。
账号 A：投放了 11 个片子，累计播放约 20 万，拿到 177 个订阅，最突出的一条已经跑到 11 万播放。
账号 B：只发了 6 个，播放量 3.5 万左右，订阅仅 20 个，还有个片子直接挂零。两个号差距悬殊，说不好是养号差异、内容不对路，还是纯粹运气问题。

# 科普类内容是怎么定下来的

最初启动，是因为看到亦仁在动态里反复推荐这件事，说是能长期经营的赛道，加上 AI 确实是未来方向，本来打算做 AI 生成内容相关的短剧。

但后来在航海里听了教练的拆解，也把圈友分享的 Shorts 实战帖翻了个遍，最后还是转向了科普讲解。原因不外乎两点：

1. 自己有多少创造力心里有数。AI 内容涨得快，同质化也快，没有足够的天赋很难卷出来，而且抽卡环节特别多，新手前期要耗费大量精力。既然这项目被反复强调是长跑，前期又大概率拿不到收益入口，选择门槛较低的 AI 方向反而更容易半途而废。
2. 科普解说对我来说不算枯燥，做起来有动力坚持。老马教练把流程梳理得很透明，按步骤执行就行，非常适合我这种零基础的人。

# 对标账号去哪找

一开始确实连门都摸不着。
后来靠着教练分享的清单里提到的几个账号，去站内搜索、关注、点赞。再往后首页开始给我推解说类内容，我见到就点赞、就订阅，慢慢地首页信息流越养越精准。

# 早期的手工制作方式

整个流程就是照着老马的方法走，本质是拿热门视频出来混剪。

每一步大概是：
先去找播放不错的科普讲解片源，下载用的是社群里出现的第三方 YouTube 下载站点，把字幕和语音转成文字用的是飞书妙记，再用 ChatGPT 免费版提炼关键词，拿关键词去四处翻素材，确认能凑齐材料再敲定这条片子的制作。随后把原版解说词改写一遍，放到 ElevenLabs 生成配音，剪辑素材和音效是分开找的，音效包是在闲鱼上淘的，里面挑了几个勉强能用的。最后全部丢进 CapCut 拼装——CapCut 也是闲鱼上搞来的非正版授权，一开始用着还行，后来就开始弹会员提醒、限功能，反复重装也很折磨。

# 心力被一点点耗尽

这种模式撑了大约十天，两个号加起来做了 15 条。能明显感到热乎劲儿在消退，剪一条片子就是一大块时间被吞掉，看到有些视频播放量平平常常会烦躁，再看看 YPP 的进度，整个人更不好了。

更麻烦的是，大量工作都是重复劳动，工具又卡效率又低，再次面对同样的环节时心理会明显抗拒。当时就觉得，必须找个外力帮自己把这口气续上。

# 用 Cursor 尝试破局

照着航海手册把 Cursor 装好，然后就不管三七二十一开写了，前后折腾了一整宿。

细节现在已经记不清了。反正产出的都是一些很粗糙又简陋的小东西，小毛病也不少，但初期能用就行，后面有需要再说。从头到尾体验下来，最直观的感受是：想在一个界面里集成所有东西，对于 Cursor 来说难度太高，写着写着容易把原来好用的功能改崩，卡住时也容易陷进某个局部出不来回。

说到底还是自己水平不够、技巧太生疏、时间投入也不足。所以最后拆成了 4 个子工具，并给它们排了序号，做片子的顺序感一下就出来了。比如那个标着 2.5 的文件夹始终空着，因为那一环得我这个“人肉工序”亲自上阵。

[PRE2]

每个子目录里就是源码文件配上可执行的启动入口。最初那版是用 Python 写的桌面程序，有点像 PyQt 那类，结果跑起来卡、开发效率也低，弃了。后面的工具全部改用网页模式，底层是 S 字母开头的一个 Python 库，直接问 Cursor 它就能明白。这种方案跑起来飞快，Cursor 生成的速度也让人满意。

以后只在闲暇时刷一刷 YouTube，把认可的对标号收集起来就行。还有一个想法是，利用这个工具的频道信息采集能力，继续扩充账号数据库，后续往数据中心方向发展，甚至估算一下各个频道的收入情况，给自己添点信念。

## 三号工具：YouTube 视频批量拾取工具

以前用的是网页版免费下载通道，下载时不得不一个一个复制粘贴链接，偶尔还得跳转几次页面，遇到批量下载的平台又要花钱，想了想不划算。

干脆自己动手写了个批量下载器。操作方式很简单：在搜集画面的过程中把合适的页面网址丢进去，攒够一定数量点统一拉取就行。唯一遗憾的是下载速率一般，稍微多几段片子就得等几分钟，也可以趁机先把音频按句切割。

其实音频切分这个事我尝试过交给 Cursor 解决，它也确实做出了可用的版本，只是输出的是一堆零散音频文件，不合我意，后面就没用上。现在回过头想想，未必不能接受。

在这里面还附带了一个小功能：对成片做轻微锐化、高光增强之类的参数调节，这样就不必再到 CapCut 里一遍遍手动调试了。虽然教练说 YouTube 这边的滤镜倾向没有国内平台那么明显，但我之前每部片子都习惯性微修一下。如今这步被直接封装进去，下载完就是调过参数的版本。当时我还专门问了一下 Cursor，它给出的说法是这些操作已经对视频指纹产生了根本性改变。是真是假？暂时存疑。

## 末号工具：CapCut

最后一步必须交给 CapCut 来收尾。我也曾琢磨过要不要直接给 CapCut 写个插件，还专门向 Cursor 求证。得到的答复是：官方要求企业开发者认证，外加学习 API 接入文档，不是一下子能搞定的，加上目前还没到非做不可的程度，就搁置了。

现在的情况是，一号、二号、四号工具可以串成一条流水线，空的时候一次性处理多条爆款视频，把文案、关键词、音频都备好。之后每天的核心任务就剩：收集素材，然后拿着现成的音频进 CapCut 完成拼接即可。时间成本确实降下来了，虽然距离理想状态还差一截，但至少后续做数据归集和分析有了抓手。

# 这一路攒下的几点感受

1. YouTube 在流量分配上并不吝啬，用户也乐于点赞和互动。但二号账号的成绩确实让人发慌，那个 0 播放的存在始终是个阴影，也怕后期好不容易起来一个号又遇到封禁，撑不到“上岸”的日子。
2. 视频的前几秒定生死，什么都能拖，开头不能。
3. 主题尽量选择阳光、正向的。
4. Cursor 做单一且边界清晰的小工具，完成度明显更高。
5. 网页形态的界面开发速度远胜 PyQt 那类桌面方案。
6. 做这个项目要有打持久战的准备，路上必然绕不开各种想不到的坎。这时候一位引路人、一群同频的伙伴，大家互相打气、彼此看着对方的坚持，才更有可能熬到天亮。

希望这一篇絮絮叨叨的记录能给你带来一点点参考，也期待路上大家能彼此照亮——毕竟，我也需要被看见。
