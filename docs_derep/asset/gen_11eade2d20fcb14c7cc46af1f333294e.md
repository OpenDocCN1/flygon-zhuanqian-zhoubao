# 97年裸辞做宠物定制，年销200万后我为什么选择放手？

生财有术的圈友大家好，我是洛更。加入生财后，芷蓝的创业心法让我很多之前的困惑一下子通了。回看上一段创业，真是把所有坑都踩了个遍，今天把它掰开揉碎聊聊，希望对还在路上的朋友有用。

先说说我：97年，24岁在头部互联网公司做商业产品经理，年薪60多万，从0到1做过年营收破10亿的广告产品。22年末我裸辞了，想自己干点事。

辞职的导火索是20年疫情。一位研究生同窗在闲鱼卖二手笔记本，趁着居家办公需求爆发做到Top3，一年利润几百万，给当时的我巨大冲击。同时我负责的应用DAU腰斩，更加笃定互联网进入存量时代，大厂里没有业绩谁都动不了。修桥要一万人，维护桥只要一个人，早晚会有一批人失业，所以我决定先走一步。

关于合伙，我先后经历过两位合伙人，第一位散伙主要因为股权。第一次创业没经验，哥们义气抹不开面子，直接五五分。后来发现这是大忌。想创业就别怕谈钱，否则生意没了，兄弟也没了。

项目选的是宠物定制工艺品，具体是香薰宠物头像。客户发来宠物多角度照片，我们从几百个脸型库中挑最相似的，再由受过专门培训的画师手绘，相似度通常能做到九成以上。除了做冰箱贴、车载香薰，我还加了高客单的磁吸相框套装，可做摆件和墙画，一单多赚50元，直播时有40%的订单都会选这个组合。

这款产品能跑出来，一开始是运气。我和合伙人都养猫，两个大男人看到它瞬间上头，愿意掏钱买；加上我们都有美术底子，说干就干。没日没夜研究两个月工艺，在北京、广州、江门都招过人，最终储备了大约6位画师。渠道上靠本科舍友介绍了一位宠物博主，帮忙拍了条带货视频，视频一发，咨询量瞬间爆掉，两个人同时接都忙不过来。因为回复不及时，还是丢了一些客户。当时只有89元一个SKU，第一天就卖了2万多GMV，特别感动，觉得付出值了。

话说回来，89元定价利润真的很薄。不少人劝我涨价，但我心里很虚，觉得这产品只有5-7厘米，跟人家大件比卖不上价。这个认知困了我很久。后来遇到一个有女装直播经验的合作伙伴，建议打付费短视频引流直播间。我以前也试过直播，但从不投流，内心不看好，还是决定再试一次。结果话术、场景跟我之前几乎一样，只是加了付费引流，ROI直接到10，价格从89提到138起，最高做到238，以前求而不得的“高客单+不愁卖”一下就来了。我悟出两点：一，什么价格都有买家，要敢于定价，别被自己的经验锁死；二，保持极度开放，很多事就差一层窗户纸，试了才知道，坚持很值。

到了暑假，兼职画师多了，订单上涨，市面上突然冒出很多模仿者，还有恶意差评。一开始很在意，后来就麻了。做60分的产品不难，很多人觉得可以抄就进场，但一天画一颗螺丝和一天产十万颗螺丝完全是两码事。我在大厂浸染多年，标准化、流程化、SOP这些管理基本功反而成了优势，一批又一批模仿者熬黄了，我们活了下来。

表面风光，底下其实问题很大。最头疼的是供需平衡：要么爆单了生产跟不上，店铺分和口碑往下掉，被罚款；要么流量起不来，招来的画师空转，固定成本像石头压胸口。所以新手创业，能力有限时最好先专心搞流量，用别人的产品和服务跑起来，别一开始就搞重生产，否则两头烧。

另一个死结是产能。定制宠物头像必须一只一画，交付模式分两档：一是从脸型库匹配再手绘，客单100-200；二是3D建模捏脸，客单1000左右。熟练画师一天最多画5-8个，产能天花板太明显。培养画师也难，我平均面5个试稿才过1个，过了还得练两周才能发货。试过找外包，手艺好的要价太高，便宜的根本没法看；也扶持过两个团队（我表哥在湖南，旧同事父母在辽宁）专门做交付，结果质量参差，有些头像改好多次都不敢交付，甚至直接报废。最后只能暂停合作，还是自己招人自己带。这样的产能模型，根本没法快速复制放大。

我尝试过很多次放大，都失败了，反复在绝望中挣扎。恰巧一位长期合作、找我下过海外单的哥们想收购这个项目。纠结、不舍过后，我决定放手。有人问我，不能留着它、分点精力做新项目吗？答案是不能。至少在这个作坊阶段，必须有一个全职Owner死盯，流量、交付、培养人，环环相扣，谁分心谁崩。

现在回头看，创业最深的体会是：正确的选择，比盲目的努力重要得多。我重新定义了好项目：受众要够广，宠物头像太小众；复购周期要短、最好是高频刚需，这个产品不是刚需，粘性弱，复购率不高；业务结构要简单、可快速复制，把复杂的事做简单，简单的事流程化，流程化的事系统化。而宠物头像恰恰产能端太重，没法快速复制，所以我选择参加6月的视频号带货航海，这个方向更符合我的判断标准。更重要的是，我想先链接这个赛道里做出成绩的人，付费或合作，找人领路。创业好比36位组合密码，知道密码的人一分钟就开了，不知道的人一辈子打不开。别闭门造车，别重复造轮子，站在巨人肩膀上才可能成功。希望和大家在生财路上相逢，也欢迎随时找我交流。
