# 一个上班族的副业实操笔记：两个月内搭建创业主题知识圈层，吸纳两百余名付费成员，营收破九千九

> 原文：[`www.yuque.com/for_lazy/thfiu8/figdg922l2hncw5q`](https://www.yuque.com/for_lazy/thfiu8/figdg922l2hncw5q)

作者：新侠  
发布：2023-04-10

先做个自我介绍。本职工作在苹果生态上游的一家上市公司担任中层，日常带两支队伍，一边是二十余人的技术研发小组，一边是五十余人的生产一线人员，主要负责数据复盘与组织协同。业余我喜欢在网络上尝试各种轻量级尝试。

今年年初我正式启动了网络副业的摸索期。起初大量借鉴外界已有的做法，随后逐步加入个人判断进行改良，最终成型了一个围绕网络创业方向的知识付费圈子。

这个圈子的变化很快。起步价仅19.9元，后续根据反馈与价值逐步提升至199元，人Crash count 两个月后成员规模超过200人，累计流水达到9900元以上。
