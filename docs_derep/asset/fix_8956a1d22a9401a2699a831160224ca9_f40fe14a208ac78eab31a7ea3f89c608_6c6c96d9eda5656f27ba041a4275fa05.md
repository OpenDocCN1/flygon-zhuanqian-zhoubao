# 把 YouTube Shorts 变成可复制的自动化生产线

> 来源：[https://ia0969wpr2.feishu.cn/docx/ELcgdUKJToK95YxuoCUc33XVnzh](https://ia0969wpr2.feishu.cn/docx/ELcgdUKJToK95YxuoCUc33XVnzh)

各位好，我是钱塘江鲤。受亦仁的超级标点醒，最近我开始研究 YouTube Shorts 的 AI 化运营。经过一段时间的摸索，整套作业链路已被我逐步固化成流水线。起初我觉得这条赛道技术门槛不高，且起步阶段也没跑出漂亮的数据，便一直没对外分享。直到两天前和@土豆君 聊起此事，被他鼓励后才决定把当下的做法整理出来，供同样在探索该方向的朋友参考。

本文主要讲我如何借助 Cursor 配合大模型实现 Shorts 的高效运转。现在除了对画面和成片的挑选仍需人工把关，从素材采集、竞品复刻、创意扩增，到图生、生成、剪辑打包，再到多账号矩阵投放，基本都已跑通自动化。早期我也尝试过完全无人值守的模式，但成品质量不理想，后来在图生成与视频生成的环节加入了人工反向筛选节点，采用先饱和式产出再精筛的策略，效果才明显提升。

单条成品的成本取决于所用图像模型，大致在几分钱到数毛之间。成本还能进一步压缩，但质量会同步下降。在兼顾质量的前提下，目前的投入仍在可承受范围。

当前在用的工具组合：

提示词逆向：midjourney describe 与 gpt4o-mini
图像合成：flux+comfy / midjourney
视频合成：即梦 / 可灵 / 海螺

先交代下背景。这篇文章诞生于我自建号的期间，顺带搭建了一个内容管理与发布中台。全部工程代码由 Cursor 协助生成。考虑到篇幅限制，历史完整的 Prompt 无法全部列出，而且现阶段模型能力已很强，不必依赖花里胡哨的“封神级”提示技巧，表达清楚需求就能把产品搭起来，上手并不复杂。

文中我会把部分需要多轮调试才能落地的高复杂度模块的核心代码贴出来，例如场景切分、视频批量生成、Discord 或即梦无水印下载的油猴脚本等。其余内容更多需要你自行尝试与调优。

另外由于涉及的细节碎片较多，篇幅受限难以展开，阅读时可能会感觉脉络跳跃、比较抽象。若你已经把基础流程跑通，目前正处于规模化放大的阶段，这份梳理应该能提供一些参考。当然仍有诸多不足，欢迎在星球里交流探讨。

下面讲整体落地路径。

## 竞品视频的自动拆解与复刻

先从竞品视频的像素级拆解和自动复刻说起。

一套完整的复刻链路大致为：视频获取 → 场景切分 → 提示词逆向 → 新图生成 → 动态生成 → 剪辑拼接 → 配乐 → 输出

理论上整条链都能自动化，但为保质，我在画面生成与视频生成的两个关键节点保留了人工筛选，其余环节全交给机器。我能分给 YouTube 的时间有限，所以最初的目标设定为：输入一个竞品链接，机器自动产出复刻分镜的片段，我只需用鼠标点选筛选，其余切片、重绘、剪辑、上传、数据统计全部自动完成。

要实现这一点，第一步是先搭建自己的素材中枢，用于创建草案项目、管理视频、管理代理信息和矩阵账号等。
