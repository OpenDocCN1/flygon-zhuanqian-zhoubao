# 案例1：用“免费算药方价格”做钩子，把中医求价粉拉到私域卖药材

### 1.1 笔记现状

近期刷到不少中医相关内容，其中一条《发方子免费估价》很典型

[PRE0]

本身在吃中药的我直接点进去看，博主让大家把方子丢评论区帮忙估价，点赞收藏平平无奇，评论却爆了，300多条全是求报价的截图

[PRE1]

### 1.2 怎么把人引走

博主当然不会在小红书上直接给价，私信回复话术是“平台有敏感词，我们移步聊”，顺势让用户报微信号

[PRE2]

[PRE3]

进到私域后，朋友圈一看就是在做中药微商，我把医院开好的方子照发过去，对方秒回价格，确实比医院便宜不少。中药是长期消耗品，一副省一点，算下来差距很可观，不成交都难

[PRE4]

[PRE5]

做微商的人常常想在公域里突出价格或品质优势，其实可以绕个弯。用“免费帮你算/查/看”的方式做诱饵更有效。

用户未必想买新东西，但对已经在花的钱非常敏感，有损失厌恶。免费帮他核对价格和真伪，给他吃颗定心丸，比硬推产品更有吸引力。中药、珠宝这类复购强的品类，一次信任建立，后面复购自然找你。

### 1.3 怎么拍内容

#### ①药房实拍

实拍、Live图或网上找图都行，Live图更有现货感，容易让人信你有货源

[PRE6]

#### ②文字封面

四个字就够了，“中药算价”

[PRE7]

[PRE8]

找个干净底图，或者直接用小红书自带编辑器打字就行

[PRE9]

故事很真，走心，数据都很漂亮。评论区全在刷“求中介”“求联系方式”

[PRE10]

[PRE11]

引流路径是评论引导私信，私信再给微信，最后推中介名片

[PRE12]

[PRE13]

你只负责把人拉过来，不用自己谈单，门槛很低。

### 2.3 引流技巧

评论区有人问中介，作者会回复引导私信，减少主动寒暄。
[PRE24]

私信里一般让对方主动发微信，降低违规风险，也防止跑单。
[PRE25]

[PRE26]

[PRE27]

[PRE28]

加微信后的朋友圈要做信任背书：定位放名校城市，真人头像，封面和日常展示大学生活。

# 案例3：反向吐槽机构截留留学粉，高客单截流玩法

### 3.1 笔记现状

留学圈有个“借鸡生蛋”的截流法，不用立人设发笔记，直接蹭热度引流。

下面这篇表面是学生吐槽作品集机构的帖子，语气朴实
[PRE30]

点进主页全是学生和机构互怼的剧情，明显是同一个人设在操作。

中介假扮学生吐槽自己同行，为什么新颖？因为2024年小红书留学中介口碑已经崩了，大家默认学长学姐都是托。与其正向打广告，不如跟风骂，反而能吸到最精准的留学生

⚠看评论区——
[PRE32]

[PRE33]

评论区成了免费的广告位，自己安排小号在下面给合作机构打广告，还很自然。

### 3.2 内容制作

直接用小号和大号聊天的截图，剧本通常是机构老师语气难听地怼学生没钱没实力。
[PRE34]

[PRE35]

正文就是“我和中介的battle经历”，细节越具体越能共鸣。结尾可以安排拉踩几家机构。
[PRE36]

### 3.3 引流方式

第一步：安排小号留言“看完博主吐槽的机构我太有感触了，当时也被坑，后来换家靠谱的上岸了，我不是广告别都来问我”
[PRE37]

[PRE38]

第二步：等真实用户来问“在哪家办的”，没人问就用另一个小号自己问“求推荐”，带起节奏。引导私信后用语音条报微信，再把机构名片推过去。核心是要把评论人设做扎实。

# 案例4：正念金句+图书内页，引流显化粉卖千元产品

### 4.1 笔记现状

一批用财富显化书籍做封面的笔记，标题全和钱有关
[PRE39]

点开正文是在介绍封面那本书，说能帮人显化金钱。博主置顶评论“对书籍感兴趣回666”
[PRE40]

评论区很热，有人接好运、求发财，明显是负债或想变现的人群

[PRE41]

这和之前火的正念金句笔记思路一样，纯色底+一句暗示语，制作简单，评论区自带祝福氛围，涨粉快。但大部分只涨粉不赚钱。这个案例加了后端，我加了微信，朋友圈产品是：
[PRE43]

[PRE44]

398元的社群已招满500人，一个产品变现20w+

### 4.2 内容制作

内页五张图，制作很简单
[PRE45]

在作图工具建1242*1660px画布，把实拍的书页拖入，红框箭头在素材库找，文字调好颜色大小即可。当然产品是书，家里得有一本
[PRE46]

[PRE47]

正文写作用“结果前置”法：先说翻完书后的进账结果，用数字量化，再描述使用感受，结尾种草《精准显化》。语气要真诚。

### 4.3 引流方式

第一种：笔记关联群聊，群公告写隐晦联系方式如“身高XXX体重XXXXXX”
[PRE48]

[PRE49]

第二种：引导私信，发语音或图片报微信
