# Coze 零代码实战（二）：让 workflow 与前端页面真正联动

上一期，我们把海报创建页的静态骨架搭了出来。今天继续完成后续部分：用户在前端填好信息，点击按钮之后，后台流程能自动跑起来，并回传一张合成好的成品。全程依然不需要手写代码，靠 Coze 的编排能力就能完成。

## 一、先拆解功能需求

先把上一版的页面设计放在这里，方便对照：

[PRE0]

从这个界面可以看出，用户只需提供三项内容：

- 节气名
- 想要的画面描述
- 风格选项（目前仅内置一种，后续可扩展）

考虑到后续还会做产出记录，因此每次运行后，前端至少要拿回三样数据：

- 合成完成的成品图片
- 节气名
- 记录时间

放一张理想中的成品效果，便于后面理解 workflow 的各个步骤：

[PRE1]

对照这张成品，我规划的 workflow 处理链路如下：

1. 根据节气名和画面描述，生成绘图用的 prompt；
2. 根据节气名写出一首诗词；
3. 将诗词、节气名叠到铺底图上，得到最终成品。

流程本身不复杂，真正的重点在于 workflow 和页面之间的数据传递。现在进入搭建环节。
