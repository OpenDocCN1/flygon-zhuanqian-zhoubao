**主张：把资料一次打包，减少用户找寻时间**

| 宝藏 | 平台高频词，暗示高价值 | 宝藏书单、宝藏工具 |
| 合集 | 内容体量感强 | 英语学习合集、理财合集 |
| 清单 | 突出条理与可执行 | 书单、影单、工具清单 |
| 工具箱 | 针对特定场景的工具集合 | 打工人工具箱、学生工具箱 |
| 大全 | 强调覆盖全面 | 简历模板大全、表情包大全 |

## 📈 落地策略

### 1. 组合公式
[PRE0]

常用范式：
*   职场 + 知识库 + 干货满满
*   理财 + 入门指南 + 保姆级
*   设计 + 素材库 + 宝藏

### 2. 检索路径建议
1. 先用大众热词，摸清整体盘面
2. 再切细分垂直词，寻找差异化空间
3. 最后下探长尾词，发掘低竞争蓝海

### 3. 对标账号分析要点
*   人设定位与专业背景
*   内容形态配比：图文/视频/合集
*   更新节奏与内容规划
*   互动表现：赞藏评比例
*   变现路径：私域引流、付费课、广告合作

### 4. 用词技巧
*   标题前置，提升检索权重
*   正文自然穿插，避免堆砌
*   话题标签配合，扩大曝光
*   评论区引导互动，提升账号活跃度

* * *

## 🎯 最后提醒

1. 词要与内容匹配：标题承诺需兑现，避免空洞标题党
2. 词库需迭代：平台热词会变化，要定期更新
3. 多组测试：不同组合效果差异大，建议A/B测
4. 看竞争度：优先选择竞争适中但需求真实的词切入
