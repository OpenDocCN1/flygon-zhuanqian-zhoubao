# 薄利之下藏大钱：外贸里把三分利润做到百万的打法

很多人听到利润只有三厘、毛利薄得像纸，第一个反应就是不值得碰。但在To B外贸里，利润率低不代表赚不到钱，关键看量、看卡位、看上游掌控力。

先讲两个我身边看到的极端量级案例。楼上那家公司的头部业务员，五六年前靠卖味精就把年收入推到了百万级，主攻的是印度市场。同行一次下单十几吨、凑一个柜就算大单，他经常一谈就是一百四五十吨起步。味精是典型的低价普货，常规毛利也就三厘左右，按这个体量算下来实际到手利润甚至被稀释到三厘以下。他们的结算方式是30%定金、70%离港前结清。印度市场确实有机会，但风险同样突出，去年就有印度买家在自己要破产的情况下，卷走了中国十几家供应商的货物，最严重的一笔货值超三百万元。

类似的量级打法在麦芽糖糊精上也能看到。青岛某大公司早年销冠年收入也过了二百万元，核心逻辑还是走到量。同行的优势在于老板的父亲本身就是工厂，成本和资质上天然有加成。

我们自己的路径则更偏向产业链上移。公司起初是纯贸易，客户主要集中在欧美，做的是保健品成品及原料。有一个长期走货的品种A，每年对欧出口大几十吨，客户群稳定。后来客户陆续提出要A的提取物B，作为贸易商，客户的需求就是生意机会，我们便开始全球找货。调研后发现，B在全球范围内只有一家日企和一家中企在量产，属于很新、很小众但有真实需求的品类。老板本身是医药背景，很快算清了多少吨A能提多少吨B以及对应的毛利空间。这个发现直接改变了方向，团队决定自建产线往上游走。

建厂的技术门槛并不高，流程和常规植物提取厂类似。产能释放后，我们快速参加FIA、CPHI等国际展，同时把官网和谷歌投放做起来。随着内容沉淀，精准询盘不断增加。由于品类小众，全球范围内的大客户覆盖率很快达到七八成，工厂长期处于供不应求的状态。

B的定价变化也很有代表性。初期工厂给到业务的底价是500元每公斤，市场售价能在千元以上。两三年后，相似产能逐步出现，价格内卷到700-800元每公斤，利润依然健康。部分美国老客户至今仍按千元以上拿货，每月固定500公斤；另一些客户虽然价格谈下来了，但单量上来，一次一两吨按700元每公斤算，一票毛利就能到二十万左右。公司业务提成是毛利的20%再加额外奖励，一票到手约五万。若是做有机的并拿到有机认证，利润还能再提升30%-50%。还有一些国际集团旗下美国、欧洲多家分公司都在持续采购，一年多次下单。加上公司本身有外贸底子，老客户盘子厚，即使不加班，成熟业务也常忙不过来。

关于低毛利的核算方式，这里给一个实操参考：进价扣掉13%退税后加上运费，总价乘以1.03；如果不含运费，直接进价扣退税后乘以1.1。具体的系数要看你对产品、市场和客户的熟悉度来灵活调整。

给想入行的年轻人一点方向。假发、假睫毛这两个品类在外贸里非常吃香。化纤类拼走量，真发类靠利润率，天然貂毛假睫毛进价十元一双，外售能到十美元。正是由于这两个品类利润诱人，亚马逊近期还上调了入驻和投放的门槛。

再看其他行业。做机械的普遍是一年不开单，开单吃一年；有个只出口不内销的圣诞拉炮，利润率能做到70%，一年只做半年，专供英国圣诞市场，小团队就能年入百万。南方外贸以电子和高科技为主，北方则以食品、保健品原料等基础品为主。无论哪个赛道，都是有人赚得多有人赚得少，关键看玩法。不要小看味精、甜味剂这类基础品，朋友公司业务员十几个，新人年入十几万，老员工普遍年薪五十万起，就是靠量胜出。

### 主流的To B获客方式

**1. 展会**
壳聚糖这类原料主要应用于食品、保健品、化妆品，前两者占比更高。优先选食品展、保健品展、原料展，比如FIA、CPHI。工厂多自带展位，参展既能发名片也能收名片。

**2. 专业官网**
官网是标配，域名可以用产品或公司名。起盘期没有流量，可以从三方面启动：投谷歌广告抢关键词；写企业博客沉淀专业内容等待收录；把官网链接分发到领英、油管、tiktok做冷启动。站建好后来的询盘精准度高。

**3. 海关数据**
这是找精准客户最直接的手段。通过品名或HS编码检索，也能找到常年出口该品的工厂，进而扒取其客户资源。

**4. 外贸平台**
阿里巴巴的RFQ偶尔能出单，但询盘质量参差不齐；中国制造网的RFQ表现一般，询盘量相对多一点。

**5. 谷歌主动开发**
要求能科学上网，用关键词检索客户。比如搜索“chitosan inc”“chitosan ingredients”，或用应用场景检索如“chitosan for agriculture”。加双引号提高精准度。公司容易找，联系方式难找，这时领英就很重要。注册领英完善公司、职位、产品信息后，在谷歌搜“公司全称 LinkedIn purchasing”即可定位到采购负责人页面。

拿到邮箱后，开发信建议做成系列。第一封不要报价，不要带链接图片附件，先介绍自己看了对方官网、了解其业务和经验。第二封补充产品特性、对目标国家市场的理解，可配发货实拍。第三封提供ISO9001、有机、HALAL、Kosher等认证背书。第四封发工厂照片和验厂报告。术很重要，但道在产品。想做外贸，无论是从业还是自立，先在靠谱公司沉淀，学流程更要学品类认知。

**找工作的建议**

新人：英语听说读写要能支撑工作；优先选择有培训机制的公司；避开阿里系创业老板的公司，这是多位前辈的共识。

有经验者跳槽：看老员工存续率，老员工多公司通常更稳定；看销冠天花板；尽量选增量市场而非存量红海。

**两次面试体悟**

第一次从教培转行，外语功底临时准备，口语和开发信被老板认可。第二家公司给了完善培训。第二次跳槽，是因为原公司阿里系管理严苛、提成不透明、制度繁琐。面试时强调过往业绩、客户开发方法、电话跟进习惯，最终进入一家提成20%毛利且结算透明、老员工离职率近零、销冠年入二百的团队。

最后是汇率和海运的波动。入行时汇率7，后来跌到6.3，现在又回到7.3左右，微小波动对报价影响巨大。我的做法是顺趋势留缓冲，比如汇率7.2时按7.1报，避免被汇率反噬。海运在紧张期，一柜难求时转手倒卖就能赚三四万元。

总结下来，外贸的赚钱逻辑分两条：一条是把低毛利做到极致的大量级运营，另一条是通过上游掌控和信息差把利润做厚。方向选对，方法对了，年入百万并非遥不可及。
