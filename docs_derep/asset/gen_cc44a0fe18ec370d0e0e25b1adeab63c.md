# 新手做抖音团长，怎么才能真正跑出结果

作者王舒林，重庆人常驻成都，抖店自营月销已过两千万，商品卡自然流量占比长期稳定在五成以上。

此前我发过两篇关于抖店实操的干货，分别聊过日销两百万的打法以及月销两千万背后的经营思路，有兴趣的可以自行回顾。

一直想找一个不离开主业、又能持续变现的副线。盘点下来，我手上既有商家资源，也有达人资源，对这两端的需求和玩法都很熟。于是切入了抖音团长这条线，自今年6月起正式启动，到现在每月服务费稳定在5万左右。

很多人看到抖店的销售额就以为团长也赚销售额，其实要先把认知厘清：团长模式下，我的收入来源就是服务费，这笔钱就是全部利润。抖店本身的利润率我之前测算过，大概在9%上下，那是店铺端的逻辑，这篇只聊团长。

做团长能起量，核心就在于我过去几年积累的两类资产：
一是对商家端需求的理解，能快速判断什么品类适合上团、什么价格带能成交；
二是对达人端的熟悉，知道达人要的是什么内容素材、什么佣金结构和什么出单保障。

新手想在抖音团长上拿到结果，别一上来就追求大盘和成交额，先把服务费模型跑通。先用自己熟悉的商家和达人做小闭环，跑通选品-投放-结算的标准流程，再逐步扩大资源池。资源对位准了，复利才会起来。
