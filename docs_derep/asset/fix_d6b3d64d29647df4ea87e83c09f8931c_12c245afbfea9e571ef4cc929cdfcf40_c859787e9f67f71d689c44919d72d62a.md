# 我把艺术细胞外包给了 AI，单句描述就能出电影感作品，连设计师朋友都傻眼了

> 来源：[https://t16jzwqrzjx.feishu.cn/docx/JdZCdoJrMoWisix2owHcOA84n2f](https://t16jzwqrzjx.feishu.cn/docx/JdZCdoJrMoWisix2owHcOA84n2f)

22 年底 Stable Diffusion 爆火时我也冲了第一波。那会儿我对画面语言的理解大概停留在幼儿园水平。想做一张猫狗互殴的图，我的描述词库只能挤出：猫狗打架。

[PRE0]

能生出图，勉强能看，但离审美差得有点远。这种落差让人挺想挠头的。

我以为问题在描述太粗，就改成：猫爪在狗脸上留下抓痕，狗毛和猫毛满天飞

[PRE1]

从满腔热情到心灰意冷，有时真的只需要一次失败的生成。

转机来自 4o。那阵子我用它拼了不少漫画，忽然开窍：创作灵感我不擅长，但让模型替我可视化却是可行的。想清楚就等于能大量产出。

说走就走，成年人总不走。周末本想先玩两局骑马与砍杀，下周再搞。结果下周 MCP 又更新了，画图要串好几个工具还要攒额度，又被我搁置。

拖延意外成了好事。之前写的 MCP 观察贴被推流了，纳米 AI 的朋友约我去参加内部体验会，还顺带吃到周老板的羊肉串，手艺确实在线。席间大家都在聊 MCP 的玩法，纳米表示想招一批人内测找场景。周一拿到码后，我一边拉朋友一起试用，一边刷有哪些高效用法。

刷到即梦海报 3 的 MCP 连接时，大脑直接报警：拖了整整一周的 AI 绘图，现在就是上场时机。

3.切到绘画模式，把脑中的画面丢进去就行。

有人会说，单句描述也不好想，这不就成了新门槛。

没关系，可以让模型先帮你发散。我再做了一个创意孵化提示词。

[PRE29]

把这段发给智能体，告诉它想要的主题，它会给出可用的描述方向。

[PRE30]

把这段指令喂给刚才建好的智能体，就能得到一张很顺眼的成片：

一只橘猫蜷缩在毛线球堆里,露出半张睡眼惺忪的脸

[PRE31]

到这一步就结束啦。期待大家秀作品，记得把成果扔给我看看。

写提示词前我也忐忑，审美平平的我能写出好用的词吗？

第一张成品出现时我发现没那么难。模型相当于我的视觉手脚，把模糊想法讲清楚，它就能把缺口补上。

所以别担心。感兴趣就拉上你的 AI 伙伴一起试，一起摸索出自己的调性。过程的乐趣往往比成品更大。

每一棵大树，起步都只是发芽扎根。
