## 《越是推进，阻碍越是密集》

撰稿：亦仁
发表于：2023-03-28

真正开工之后，新的问题根本停不下来。规模越大，卡住你的点就越棘手，甚至有些难题压根没有标准答案。

最近在为社群新一轮招新的事忙活，预约人数硬是堆到了六千多人规模，偏偏前一天撞上了微信的安全限制，辛苦搭起的讨论组一夜之间全被判定异常。

同期负责运营的鱼丸也倒霉，几组账号被系统永久限制，好几万的联系人瞬间丢失。

看到这些操作成本和损失，反而更能体会马云这类创业者当年扛过多少非人力所能控制的打击。

别把精力浪费在自我怀疑、反复权衡和无谓的消耗上，定好方向就继续往前走，往前冲。[PRE0]
