# 别再只盯着组织架构图了，决定成败的是谁在干

> 原文：[`www.yuque.com/for_lazy/zhoubao/wm5hraogah2gqmgs`](https://www.yuque.com/for_lazy/zhoubao/wm5hraogah2gqmgs)

组织到底是什么？不是一张看起来很合理的架构图，而是真实落地的执行力。而这份执行力，最终都落在人身上。说白了，大多数组织变革翻车，最致命的坑都出在对人、对能力的判断上。

说到组织发展，这在人力资源里本就是个很考验功力的活儿。过去阿里借中台声名鹊起，华为靠流程设计成为标杆，无数公司都想抄作业。但容易被集体忽略的，是组织里最真实的节点——人。人决定能力，能力决定结果。

现在太多企业谈组织，谈的其实只是“样子”。这个样子大概由三块拼出来：

●  角色，画出谁管谁、谁背锅、谁负责；
●  规则，定下制度、标准和做事的套路；
●  日常流程，也就是大家习惯的工作方式和办公室氛围。

就靠这三板斧，这些年改结构的声音此起彼伏：裁撤增员、拆分合并、扁平化、流程再造。看起来很热闹，但放到未来的组织里，这套设计撑死只是入门级。结构会越来越轻，人会越来越重，甚至组织的边界本身都在被打破。

为什么非要放大“人”这一点？因为能力不是制度长出来的，是人创造出来的。我们早已过了靠流水线复制就能赢的工业时代。今天的竞争节奏太快，照搬别人的规则和流程，最多只能追到及格线。真正拉开差距的是人本身，90分的人去执行和70分的人去执行，出来的结果会越走越远。

组织要变，先看人。能力要强，先看人。
