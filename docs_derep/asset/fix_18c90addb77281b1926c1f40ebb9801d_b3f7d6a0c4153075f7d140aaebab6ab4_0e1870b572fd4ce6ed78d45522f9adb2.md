# 从早期虚拟形象到智能分身：一文看懂数字人演进

凌晨四点半开始整理这份时间线，才发现，数字人的变化远不只是“长得越来越像真人”。从手工制作，到动作采集，再到模型自主生成和实时交流，它经历的是一场由工具、算法与应用共同推动的产业升级。把案例逐一串联起来，也让我重新认识了这个领域。

# 五个阶段，看清数字人如何走向成熟

## 第一阶段：虚拟形象的实验期（20世纪70年代—2010年代初）

这一时期，核心能力来自计算机影像技术。创作者需要亲自完成角色设计、三维塑造和动画制作，画面可以很精细，但角色本身几乎不会回应外界。

早期代表包括1973年的《西部世界》，影片曾尝试使用电脑生成画面。

[PRE1]

2001年的《最终幻想：灵魂深处》，则进一步展示了三维虚拟人物的表现力。

[PRE2]

当时的成果主要服务于电影特效、游戏人物和商业广告。2007年出现的日本虚拟歌手初音未来，也让“虚拟偶像”开始进入大众视野。

但这套生产方式高度依靠人工，制作时间长、投入高，最终呈现往往偏卡通，或距离真实质感仍有明显差距。

# 第二阶段：动作与声音让角色“活”起来（2010年代—2020年代初）

随着动作采集、语音合成和深度学习逐步结合，虚拟人物开始拥有可变化的表情、动作和基础回应能力。

2009年上映的《阿凡达》推动了动作采集技术的普及；2014年，微软小冰借助自然语言处理，已经能够完成相对简单的对话。

这一时期的应用开始增多：

- 虚拟主播，例如绊爱；
- 智能语音助手，例如Siri；
- 游戏中的非玩家角色；
- 面向企业的基础咨询与服务系统。

按照商汤的分级思路，这一阶段大致对应L1和L2。

### L1：纯人工制作

L1形态依靠设计师完成角色绘制、三维塑形和关键帧编排，本质上仍是“提前做好的展示内容”。它适合电影特效、平面广告、预渲染动画等对画面精度要求高、但无需即时交流的项目。

它的明显问题是：一旦内容需要改变，就必须重新制作；角色无法根据现场信息实时回应。

### L2：真人动作采集

L2将真人演员的面部表情、身体姿态和口部运动记录下来，再传递给虚拟角色。常见设备包括光学采集系统和面部捕捉装置，采集完成后通常还需要人工清理与修正。

这种方式可用于录制型虚拟节目、游戏动画和其他强调动态表现的内容。但它仍受制于设备价格、操作门槛和后期流程，实时响应能力有限，也离不开真人演员，因而很难快速复制。

# 第三阶段：算法接管部分制作，行业进入垂类应用（2020—2023年）

这是变化速度非常快的一段时期。

生成对抗网络改善了人物的视觉质感，自然语言技术让角色能够进行连续交流，数字人由此进入L3和L4阶段：

- L3：系统根据声音和文本自动完成嘴部、表情等同步；
- L4：角色具备特定行业的知识和服务能力，例如客服、教师或理财顾问。

应用也开始从展示型内容走向真实业务：

- 直播平台上的虚拟带货主播；
- 教育场景中的线上讲解者；
- 金融领域的智能咨询角色。

## 2023年之后：生成式模型带来行业重排

ChatGPT的走红，让更多企业看到了大模型在对话、内容撰写和多模态协同方面的价值。数字人的研发和制作门槛快速下降，市场也经历了一次强烈筛选：相关企业数量据称由约60万家减少到6000家，竞争从“数量扩张”转向“能力比拼”。

### 1. 对话能力明显提升

大语言模型让角色不再只能按照固定脚本回答。以京东LiveHuman为例，它通过GPT能力完成文字、语义和视觉信息之间的配合，使角色更容易理解复杂要求并给出连贯回应。

京东言犀的案例显示，用户输入一段自然语言，或提供一秒左右的视频素材，就能生成4K级人物形象，嘴部运动与声音的对应度可达到100%，传统的繁琐建模流程被大幅压缩。

### 2. 内容生产速度加快

过去需要数周完成的脚本、台词和视频配套内容，如今可以借助模型在几分钟内完成初稿。光线传媒曾披露，相关技术应用使动画电影制作效率提升约30%。

### 3. 工具生态逐渐成熟

百度、阿里等公司陆续开放文心一言、通义千问等模型能力，中小团队和独立开发者可以通过接口快速搭建应用。

闪剪等产品甚至能够根据一段文字直接生成视频，让相关项目的制作投入进入千元范围。

与此同时，云计算和芯片性能进步也降低了训练与部署门槛。魔珐科技通过流程和算法优化，把虚拟人物项目的周期从三个月缩短到一周，人力投入减少约70%。

### 4. 传统高成本环节被替换

过去做一个数字角色，往往需要三维设计、真人采集、配音和大量后期处理，预算可能达到数十万元。如今，扩散模型和零样本语音技术可以减少真人录制及后期加工环节。

据相关案例，虚拟主播项目的投入从2022年的数万美元降到2023年的千元级；百度的数字人物制作费用，也从2018年的500万元降至2023年的千元水平。

当流程被标准化、工具可以批量调用后，单个角色的新增制作成本持续下降，数字人逐渐具备工业化生产条件。

# 第四阶段：高拟真形象与沉浸式空间结合（2023—2025年）

这一阶段的重点，是让虚拟人物在外观、动作和情绪表达上更接近真人，同时进入更加立体的数字空间。

主要技术方向包括：

- 通过三维云阵扫描还原真人外形；
- 将语音、视觉信息和情绪判断放在同一套系统中处理；
- 借助生成式模型，在较短时间内完成高真实感人物创建。

应用范围也开始延展到：

- 元宇宙中的会议、社交和虚拟身份；
- Meta相关项目中的VR人物形象；
- MetaHuman等高拟真建模工具；
- 非侵入式神经接口探索；
- 博物馆、景区和历史文化展示；
- 故宫数字讲解角色；
- 历史人物的动态再现。

政策层面同样在持续加码。北京市发布了促进数字人产业创新发展的行动计划，提出到2025年相关产业规模超过500亿元的目标。

# 第五阶段：从专用角色走向通用智能（2026年及以后）

未来的目标，是让数字人达到L5级别：不仅能听懂指令、完成问答，还能理解上下文、识别情绪，并根据不同场合调整自己的行为方式。

推动这一阶段的力量主要包括：

- 更强的大语言模型，例如GPT-5；
- 量子计算等新型算力方向；
- 实时画面生成技术；
- 语音、表情、动作和环境反馈的协同处理。

## 可能出现的应用图景

### 每个人都拥有自己的数字分身

用户可以定制外貌、声音、性格和表达方式，让专属数字角色参与政务办理、社交沟通、医疗咨询和学习辅导等活动。

### 数字人成为新的工作接口

在制造业、远程医疗、培训和协作办公等领域，数字人可能不再只是展示对象，而会成为连接知识、流程与用户的生产工具。

## 市场展望

预计到2026年，中国相关市场规模将达到102.4亿元，全球市场则有望迈入万亿级别。

从最初只能播放预设动画，到如今能够理解语言、生成内容并参与业务流程，数字人的真正变化，不只是形象更逼真，而是它正在从“被观看的角色”逐步转变为“能够协助完成任务的智能伙伴”。
