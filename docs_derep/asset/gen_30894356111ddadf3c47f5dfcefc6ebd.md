新版用的是按钮识别技术，需要动的地方其实不多：
1. 浏览器页面必须露出上传按钮，看不到就把页面缩放到75%；

# 一、为什么突然开始做POST?

在拓跋勇群里，勇哥亲口告诉我，他大约两三分钟就能发一条。听到这我就放心大批量发了，本来还打算等发完再看效果。

现在付费广告流量太贵了，POST完全免费，而且用的人还不多，算是小众洼地。

卖家在站内能做的事确实很少：早期评论人关闭，免费送样品也没了，VINE费用高昂，而且来领的人寥寥无几，于是大家都在广告上烧钱。

我觉得亚马逊完全可以给卖家开放视频发布功能。淘宝、拼多多都被抖音、快手逼得改版，照这个趋势，亚马逊早晚也得被TikTok逼着进化。

# 二、POST是什么？

Amazon POST是去年亚马逊推出的测试计划，仅限美国站有活跃店铺的品牌注册卖家使用。目前免费，但前提是完成店铺创建并上传链接。

这种靠海量产品图薅站内免费流量的玩法，我早就听说过。只是一直没亲手试：上班那会儿公司不上心，店铺和素材都没有；后来带团队，又被成本和时间绑住。眼下时间充裕，认知也基本达标，才终于能把批量发布跑起来。

# 五、图片素材从哪里来？

你是不是觉得我漏说了：那么多图片素材，哪来的？

其实很简单，你不需要真的去拍摄或精修产品图，只要找到产品同类的场景和对应受众就行。

比如我在《蓝海产品方法论》里写过的教师、司机、护士、父母等几大人群。

顾小北那篇《亚马逊如何巧用post，让新店0-1》也给了我不小启发。这个打法跟潮汕牛肉丸的抖音策略如出一辙：批量发布产品相关内容，只要有免费流量就露出产品链接，受众越精准越好。

我一开始想做定时发布，但算下来太折腾，不如直接延时。代码里我把延时设成200000毫秒，也就是两分钟。

大批量获取图片的方法：
第一步，用谷歌浏览器打开google.com；
第二步，搜索无版权图片网站；
第三步，在这些网站搜你的产品关键词；
第四步，装好插件后，在页面右键单击，会出现按钮。

# 六、注意事项

Amazon POST的图片标准：
- 尺寸：640 x 320 px 或更大
- 宽高比：1:2 到 2:1
- 格式：JPG 或 PNG
- 色彩：RGB

最好不要在图片上添加文字。
记得去亚马逊官方把POST规则从头到尾读一遍。
