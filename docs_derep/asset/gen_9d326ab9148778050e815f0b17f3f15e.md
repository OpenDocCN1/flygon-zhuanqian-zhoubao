# 不废话，直接上操作流程

第一步，准备公众号。老号最好，新号也能用，头像简介其实没太多讲究。但有一点，千万别有违规记录，否则会比新号难搞，真想省事就直接新注册一个。

第二步，随便挑一个AI绘画的工具，我用的是无界AI，口号是“人人都是艺术家”那个。

第三步，生成图片

我一般习惯先找别人画好的成套风格图，然后在那一套的基础上点“同款重绘”，效率很高。

第四步，配文案。这个交给ChatGPT就行，让它根据图片生成对应的文字内容。标题可以直接套用下面的格式来写：

性感魅力的少女：一副绝美的AI绘画
穿短裙的双胞胎姐妹花：AI绘画的杰作

冒号前面写描述，后面标明是AI创作的，这样的标题比较容易吸引点击，流量表现不错。
