#### 2.公开接口 

随着微信开放能力逐步增强，小程序板块先后开放了URL Link、URL Scheme、Short Link等能力，用来在微信外或微信内直接跳转小程序；另外在微信内网页Jssdk里也提供开放标签，用于H5跳转小程序；开放平台移动应用的支持还提供移动端SDK用于App拉起小程序；其中我觉得最值得说的还是微信客服能力在这条线上的应用，下面逐项拆解

##### URL Link/URL Scheme/Short Link 

三者的功能和适用场景各不相同，具体技术细节看官方文档很清楚，这里只简单说下使用场景和限制

值得一提的是，URL Link和URL Scheme的能力在年初被大幅削弱，核心调整有：

1. 每个URL Scheme或URL Link有效期最长30天，不再支持永久有效，也不再区分短期和长期；
2. 链接生成后，若在微信外打开，用户可在浏览器点击进入小程序。每个独立链接被用户访问后，仅该用户可再次访问并打开对应小程序，其他用户无法通过相同链接打开；
3. 单个小程序每天生成链接数上限为50万条。

调整主要因为开发者滥用这两项开放能力，产生大量以私域转化为主的小程序，专门承接外部流量跳转，此后微信持续整顿，大批相关小程序被封，[我也写过相关文章](http://mp.weixin.qq.com/s?__biz=MzA4NjU0NTAzNw==&mid=2447674373&idx=1&sn=45ddea6a0b39378f5a87bdf5b2d34a4c&chksm=8bd72be7bca0a2f17f2b4b0cc6e53696a16f4dd51fd8d392086620c84eea123a00b44a8416d9&scene=21#wechat_redirect)

##### 开放标签 

开放标签是微信内H5页面提供的跳转到小程序或App的能力，不过本章重点讨论从外域进入微信域，开放标签单独看主要是提供从微信域到外域、以及微信H5到小程序的能力

所以开放标签在私域转化中的体现多见于微信内H5裂变流量落地到小程序做私域转化，或H5增加能力比如拉起小程序申请获取手机号等场景

##### App唤起小程序 

该能力主要面向开放平台的移动应用，经认证的账号应用可跳转至任意小程序且无数量限制

这个开放能力带来的商业价值非常大，一个典型场景是大型流量平台的广告落地页，比如抖音、快手等广告平台，广告主投放广告，内容是微信小游戏，就需要广告平台客户端调用该能力，直接从抖音、快手跳到微信小游戏完成变现

此外，自有App产品若需要与用户建立直接触达渠道，这个能力也是首选，直接跳到微信小程序带二维码的落地页，用户扫码进私域，持续运营、持续变现，毕竟微信私域的精髓之一就是用户常在线且能长期免费无限触达，当然只是理论上的无限，风控不可忽视，否则“养号”教程也不会那么多，这里暂不展开

##### 微信客服 

微信客服几乎是王炸级别的存在，微信客服与企业微信强关联，从产品域名看应属企业微信旗下团队的产品，近年来微信生态对企业微信资源的倾斜明显高于其他产品线

个人经验加不负责猜测，微信客服的风控相对更宽松一些

上文提到大量利用URL link接收外域流量落地微信的小程序被封禁后，剩下的合规解法基本就是微信客服，无论抖音快手、小红书微博知乎手百，只要移动端能联网且未做白名单限制，几乎都能直达微信域内，进入微信客服聊天界面

再利用微信客服的欢迎语功能，可自动推送给用户所需信息，配合菜单消息，无论是给用户二维码加好友，还是导入小程序或付费链接，都非常顺滑

所以现在抖音直播的小风车、知乎答题的小卡片等，点击后都能直接打开微信导入微信客服，进而完成私域转化

类似视频号小店这类爆款产品，也把客服渠道默认接入微信客服，可见该产品的重要性，我早年在生财有术社群提过“腾讯云智服”等早期产品，目前虽已用在微信mp等内部产品线，但在腾讯内部资源倾斜有限，唯一遗憾是微信客服接入暂不支持桌面端，否则企业QQ的戏份就更少了

另外，如果你有一定开发能力，通过微信客服提供的API，也能做到关键词自动回复等功能，那么在视频号、视频号小店等入口，就能在客户互动中提供更强能力，比如推送订单、打标签，甚至接入这几天爆火的ChatGPT机器人，下期我来聊聊ChatGPT全网火爆后我做了什么，更进一步，利用垂直行业语料训练专属行业模型接入微信客服打造真正的AI智能客服

## YigeSB2.不能直达终点，曲径通幽依然有技巧可循 

上一章讲了直达私域终点的路径，虽然门槛不低，至少让大家知道原来可以这么做，这一章聊聊非直达的方式

先定义一下非直达，上面的直达是微信外自动唤起微信并进入特定页面，非直达则是手动唤起微信，手动输入内容后进入特定页面，对引导进私域而言，这个动作本质就是加好友

站在用户角度，微信外想加个好友有哪些路径？

1.  搜索手机号
2.  搜索微信号
3.  搜索QQ号
4.  扫描二维码
5.  摇一摇
6.  ...

目前主流是前四种，共同点是先在微信外记录信息，再手动打开微信把信息输入进去，到达用户页提交加好友申请

这些操作不必多说，中国十几亿微信用户，至少十亿人都能熟练操作

当前中文互联网各大超级App之间依然各自封闭，你在抖音简介留微信号，在知乎简介留手机号，小红书私信回二维码，都可能违规，所以市面上出现了各种巧妙留下线索让用户去加微信的做法，比如抖音合集名称、小红书置顶笔记、知乎私信图片水印，甚至藏头诗都流行起来，看得人叹为观止，这些传统非直达手段都会遇到的问题就不赘述了

在域外非直达微信的方式里，我想重点分享活码思维

众所周知微信好友有上限，如果你在微信外流量平台留下的手机号、微信号、QQ号等钩子对应的微信号好友已满，新用户想加却加不上，流量就白浪费了

有没有办法让一个号满了自动切到下一个号？很简单，好友满后把留下的钩子重新绑定到新微信号即可

对比手机号、微信号、QQ号这三种钩子，手机号通常最难留；微信号一年只能改一次；QQ号相对更优，最短QQ号仅5位，记忆成本更低，只要注意2016年6月17日后注册的QQ号不支持绑定微信即可

至于二维码钩子，市面上解决方案更多，比如我常用的草料二维码

有了活码思维，就不会在流量爆发时眼睁睁看着流量来却接不住，早期流行的群裂变就是活码思维的绝佳体现

最后说一句，如果一个用户愿意从别的平台手动复制你留的钩子，手动切换到微信，点了七八十次操作才加上你，这样的流量有多精准，一定要好好珍惜
