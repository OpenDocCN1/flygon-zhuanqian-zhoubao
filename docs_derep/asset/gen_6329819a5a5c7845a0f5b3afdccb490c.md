# 中美“必有一战”？这个被反复引用的概念，可能一开始就站错了脚

如今只要翻开任何关于中美关系走向的讨论，几乎绕不开那个著名的“修昔底德陷阱”。从学术会议到自媒体热文，“如何跳出陷阱”几乎成了国际关系领域最炙手可热的头号课题。

但如果我们愿意稍微静下心，翻开古希腊的历史册页，研究一番那场真实发生过的伯罗奔尼撒战争，恐怕会发现一个不太一样的结论：这个被无数人挂在嘴边的“陷阱”，在很大程度上更像是后世学者在转述、包装过程中出现偏差而炮制出来的假命题。说得直白些，它很可能根本称不上什么铁律，更像一个被过度简化的概念讹误。

拿着这样一个根基不稳的标签，硬往今天的中美关系上套，期望着用它来预言冲突、框定未来，结果可想而知——越解释越跑偏，越套用越失真，最终离真实的世界格局越来越远。

真正值得追问的，不是怎么“跳出陷阱”，而是这个陷阱本身是否真实存在。
