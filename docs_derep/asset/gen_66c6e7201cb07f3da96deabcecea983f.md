# 1 长视频的道

## 1.1 你想做成什么样的长视频创作者？

把这个问题放最前面，是想先把我当前频道的阶段说清楚，方便你按需取用；同时也给你一个可以追的衡量标尺。因为无论做哪种内容，起点的定位和终点的规划永远是第一位的。

按长视频的维度看，我现在属于小号阶段。点明这个很重要，因为我相信头部博主的玩法未来可能会跳出我现在总结的规律。但对大多数人来说，小号是必经之路。

小号阶段通俗讲就是完成了长视频的0到1，以及1到10这两个小台阶。

[PRE0]

### 1.1.1 什么叫0到1，怎么判断达标？

结论：靠自然外推的播放量稳定破千。

关键在于两个词：自然外推、稳定。自然外推意味着不是靠短视频带流，短带长如果真的带起来，后续的长视频也会被归入自然外推，所以要认准自然外推。自然外推主要靠浏览页推荐和视频播放页右侧的相关推荐。浏览页就是首页推荐，相关推荐就是看完一个视频后的右侧栏。随着粉丝增多，频道页的推荐也会慢慢起来。

[PRE1]

稳定指的是不是在几十上百条视频里偶然蹦出一支破千，而是进入一个状态：长视频一上线，就能在赛道内的推荐窗口期里迅速过千。我们还在0到1阶段，过千后推流很可能就停了，哪怕数据看起来还行，也常卡在五千以内上不去。

[PRE2]

### 1.1.2 什么叫1到10，怎么判断达标？

结论：靠自然外推的播放量稳定过万。

关键词没变，这一阶段的区别在于可能会出现十几万、几十万的爆款，但还没出现百万级内容。当然赛道差异存在，但没有短视频那么夸张。

[PRE3]

### 1.1.3 10到50、50到100是什么样？

很抱歉，这两段我还没到。但可以推演：10到50阶段应该拥有多条百万爆款，新视频上线基本能直接冲到十万以上。50到100阶段应该是靠长视频运营起来几十万到百万粉丝的账号，具备IP属性，换创意、换形式都能保持不错表现。这时衡量标准不再是播放量，而是粉丝量和商业价值。

如今大号随处可见，平台的头部效应很明显。只看中长视频，剔除短视频的干扰，你给自己列一个对标清单，再筛一遍，马上回去做。

看到这里我问你：入行之前，你想好要走多远了吗？

## 1.2 长视频到底能赚多少钱？

你可能短视频已经很能打，爆款不断，长视频只是顺手尝试。

你可能一开始就只想做长视频，找一个稳固的基本盘。

你也可能像我一样做长短结合。

我属于第三种。以下是我5月、6月的长视频收益，基数不高但在抬头，6月翻倍主要是5月有几条爆款，正好对应我说的1到10阶段。

[PRE5]

无论如何，我们都要算一笔性价比，量化金钱和精力。时间是固定且稀缺的，你可以用单位时间收益来评估，优先选择投入小产出大的方向。

严格说，我算的不是单时长视频的钱，而是整个频道的钱。

### 1.2.1 内容的收益对比

* 单价对比：长视频RPM : 短视频RPM = 0.92 : 0.06 = 15.33倍

* 假如一条内容想赚100美金：

* 长视频需要播放量：10万

* 短视频需要互动播放量：166万，注意互动二字，如果互动播放只占总播放的1/3，那需要500万播放

* 到底选长还是短，核心变量是难度。难度如何判断，得加上时间成本。

* 现在：做一条166万的短视频和一条10万的长视频，哪个投入更大？哪个当下更赚钱？

* 长期：持续做多条166万短视频和多条10万长视频，哪个投入更大？哪个睡后收益更高？

[PRE6]

### 1.2.2 频道的收益规划

频道月收入 = 长视频月收入 + 短视频月收入
= 长视频总播放量*RPM + 短视频总互动播放量*RPM
= 长视频条数*平均播放量*RPM + 短视频条数*平均互动播放量*RPM

设定一个合理的月收入目标，就能倒推需要做多少条长短视频，以及要达到什么播放标准。唯一变量是所在赛道长短视频的推流时长，也就是内容时效，比的是时间维度的收益。

举例想月入千刀：

* 只做短视频，假设RPM0.06、30条/月，约需1667万互动播放/月，对应约5000万播放/月，平均单条互动播放55万，对应平均单条约165万播放。

* 只做长视频，假设RPM1、12条/月，约需100万播放/月，平均单条8.3万播放。

* 长加短可按公式自行假设，粗算即可。

### 1.2.3 时间维度的收益怎么比？

敏感的人应该也注意到了，我上面提到要比较推流时长，且难度和投入时长有关，那具体怎么衡量？

这是我播放前四的长视频推流曲线，你能看出什么？

* 第1条42万播放，发布至今61天仍在推

* 第2条26万播放，发布至今46天仍在推

* 第3条22万播放，发布至今59天仍在推，发布后第21天、第33天出现两次二次推流，想了解原因看3.2.2

* 第4条13万播放，发布至今48天仍在推

这种一直推的感觉是不是很舒服？关于时间收益你应该有体感了，目前结论是，只要内容没有强时效，长视频的推流时长理论上没有上限，而短视频大家都知道，大概一周，基本不超过一个月。

现在回头看看自己的频道和赛道，你该怎么规划内容生产了。

# 2 长视频的法

## 2.1 赛道怎么选？

这部分想提醒大家做长视频一开始就要有缜密布局，因为长视频投入周期长、见效慢、试错成本高。当你发现没东西做、赛道太窄、赛道太卷、赛道死了的时候怎么办？

机会只会给有准备的人。

### 2.1.1 你适合什么赛道？

我问你10个问题：

* 你平时刷小红书、抖音、快手、视频号都在看什么内容？看下订阅和点赞列表

* 抛开赚钱，你自己刷YouTube订阅了谁？

* 你刷到的YouTube视频，哪些会忍不住分享出去？

* 哪些视频一看就觉得厉害，再一看我也能做，再一看我能做得更好？

* 除了衣食住行，你在哪些爱好兴趣上持续花了时间和钱？找出来

* 你想在YouTube做个人色彩吗？

* 你感受到的赛道有哪些，是单选题还是多选题？

* 你打算做3个月、半年还是更久？短中长期目标是什么？

* 你过往的工作经历是什么？策划、带货、测评...来时路每一步都算数

* 用一个大博主的简介做最后一个问题：你想不想做自己想做的东西？

现在闭眼自问，答案是不是已经在《答案之书》里了。

### 2.1.2 你真的了解自己的赛道吗？

也许你已经有赛道了，但你真的懂它吗？我以名人搞笑举例，这个赛道属于细分赛道，shorts大几千万停顶，上亿很少见。长视频百万算天花板，十几万就算很爆。

但赛道真的这么小吗？拆开看：

* 名人

除了特朗普等政界人物，体育界的C罗、梅西，娱乐界的小李子，科技界的马斯克，还有太多太多，可做的范围还小吗？

* 搞笑

搞笑是一个很成熟的娱乐赛道。打进海外文化圈，搞笑也是一种桥接方式，不然梗没法产生共鸣。生活苦，谁不想笑。大量搞笑内容都可以成为创意来源。无语言的默剧也有穿透力。

* 拓展方向

轻喜剧、语言类搞笑如宝宝播客、外语脱口秀、MV讽喻搞笑、名人搞笑电影、风格化戏仿...

说实话，可做的太多了，现在拿起小本本，把赛道的延展方向画出来。别打一枪换一个地方，先守好你的村，再谈包围城市。

### 2.1.3 如果要换赛道呢？

假如流量下滑...

假如名人IP违规...

假如赛道没了...

假如流量下滑，前面说的延展方向是不是可以试了。假如名人IP违规，把“刻板印象”留着，形象动漫化，大家一样能认出来，是不是就解决了。假如出现新赛道，你现在做的能否迁移，比如宝宝播客。

## 2.2 有短视频频道，想转长视频怎么办？

### 2.2.1 短视频和长视频到底是什么关系？

你心里是不是也问过这些问题：

* 短视频有千万爆款甚至上亿，长视频怎么没流量？

* 短带长为什么带不起长视频的稳定流量？

* 短视频爆了对长视频有没有帮助？

我也是做名人搞笑，长短视频的观众其实不一样。没错，长短是分开推的，等频道起来后，它们唯一的共同点是发布时都会优先推给你的频道粉丝，粉丝的偏好甚至决定了你的推流。所以粉丝最重要，没有粉丝，最重要的是你的目标观众，你的任务就是把目标观众变成频道粉丝。

3. 长视频对内容质量和创意要求更高

* 短视频有多条千万爆款甚至上亿，长视频怎么没流量？

* 短带长为什么带不起长视频的稳定流量？

这两个问题上面已经回答了一半，因为观众不一样。你做的是泛娱乐内容，可能完全重合，应该多试几种，如果试了还做不起来，那可能就是长视频在该赛道的内容质量不够，我们这时不能按shorts的标准衡量了。
