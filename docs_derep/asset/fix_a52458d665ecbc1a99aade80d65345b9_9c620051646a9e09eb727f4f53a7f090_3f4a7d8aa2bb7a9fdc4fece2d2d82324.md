# 一、摆摊缘起

1，摊位免费拿。

为了逼自己精进AI绘图手艺，我报名了一个AI技术切磋市集，选了上手指标相对友好的“人像定制”赛道。登记下基本信息就拿到了摊位。那时离市集正式开幕只有不到一周，时间相当紧。

2，纯纯技术小白，ComfyUI零基础。

报名之后我抱着教程硬啃了三天ComfyUI，根本啃不下来——三天速成是骗人的，到摆摊时一个节点都没用上。

3，绝处逢生，抓到一条信息差。

折腾无果后，我转投即梦AI做人物肖像出图，效果意外地好，几乎一键出片。我花了一天熟练操作，第二天就上场营业了。

## 1、用即梦产出定制人物肖像，怎么操作

a.先进入即梦官网：https://jimeng.jianying.com/ai-tool/home/?utm_medium=baiduads

b.在首页里找到“写实肖像”这一栏，点进去。

[PRE0]

c.在模板库里挑一张合眼缘的，比如“人鱼风”那张，直接点“做同款”。

[PRE1]

d.想要定制人脸，千万别漏掉“导入参考图”这个选项。

[PRE2]

e.然后选中“人物长相”，往上传一张目标人物的正面照。这里我拿希拉里的照片做了演示。

注意：不少公众人物的人脸会被AI拒之门外。我之前试着拿特朗普的照片去生成，直接被拦下，失败了。

## 4、积分消耗情况说明

文生图一次划走2积分，垫图生图一次也是2积分。

即梦每天登录送66积分，核算下来每天能做33次定制人像。单次出4张，33次就是132张图。如果额度不够用，换一个手机号再注册新账号就行，反正免费额度能续上。

基础会员的核心卖点是去水印，比免费版多这个功能。

[PRE17]

我平时也用第三方免费去水印工具，比如https://www.apeaksoft.com/zh-CN/watermark-remover/

# 三、不吐不快的几句真话

1，入场越容易，内卷越快。

结合我有限的摆摊观察，AI人像这个品类短期还冻得动，但风口收得极快。

我那天的定价是9块9做体验，能开单，有询价，但利润很薄。

同一个市集有位女摊主卖同样的品，她要价88元一张，图质感差不多，她那多了更多模板和工具，现场还能把照片打印装相框，外加一个拼多多买来的小徽章。结果可想而知，门可罗雀，比我的摊还冷清。

2，精细化、流程化才是方向。

还是那个市集，另一个摊位也在做AI人像定制，但他们的SKU更丰富，加了冰箱贴、徽章这类实体衍生品，肉眼可见地畅销不少。

再往上是玩升级版的摊主，有把ComfyUI打磨得非常溜的，有叠了最新技术的。AI搭台摆摊，果然是八仙过海，遍地神仙。

# 四、25年1月补充更新

这行热度掉得快。现在AI写真的门槛，几乎已经成了0门槛——美图秀秀、抖音这些日常App都内置了AI风格转绘。年轻人对AI写真的付费意愿，比早前低很多。

给准备入场的你一点建议：

1，别在硬件上下重本。照片打印机不用买，闲鱼能按天租；相框去拼多多、1688批发就能解决；摆摊能蹭免费或低租就尽量蹭。

2，出图流程想办法提速。即梦出图有随机性，需要反复抽，等待超过一分钟客人就没耐心了。会Liblib的同学可以直接套用别人的ComfyUI工作流，上面很多会员免费解锁的写真工作流，人物、宠物题材很全。

3，选址真的重要。摊位摆在哪儿，决定了你面对的是什么人群，也决定了这次出摊是赚是亏。

4，躬身入局永远是最好的老师。同一个摊，一百个摊主能玩出一百种样子，欢迎评论区聊聊你的摆摊故事。
