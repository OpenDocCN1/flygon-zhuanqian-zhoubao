# 半年做到五十万，我做的 FDE 产品叫 CEO 外脑：把专家手里精细度要求极高的活交出去

一位律所合伙人收到客户寄来的合作协议，把文本丢给大模型几分钟就过完了，标出十几处风险，每条都有法条依据，看起来很完美。合伙人实际只改了其中两处，其余原样通过。旁人追问原因，他说如果把模型指出的所有点全堵死，这份协议就更难谈成。哪些风险必须守住、哪些可以让步，什么时候该硬什么时候该软，这个分寸，模型给不出。

这正是绝大多数高精度从业者对大模型失望的根源。过去五个多月，我围绕这个痛点做了套 FDE 服务，名字叫 CEO 外脑，累计服务十六家公司，单笔签约两到五万，整体营收超过五十万。下面把思路摊开讲。

**先亮立场，再决定是否继续**

这套打法适合已经在做或打算进入企业侧 AI 服务的人，也适合律师、财税等对个人判断依赖很重的专业人群做自检。如果期待开箱即用、不愿反复和客户深度沟通，那不太匹配。最值得借鉴的是那张分业务、客户、自身三个维度拆解的信息采集框架，配合正版盖洛普测评约三百元，把隐性判断挖出来。提醒一下，这个模式周期偏长，需要客户持续配合，前期十几小时的访谈核对如果没计入报价，很容易亏本。

我是袁欣，大学时教新媒体、写过教材，近十年一直在自媒体相关领域，中间还折腾过线下装修公司。今年春节前我只是大模型的小白用户，用国产工具和 GPT 写文案做 PPT。3 月以后开始系统使用，并为十六家企业做定制化交付。客户主要是国际金融财税顾问、律所合伙人、知识付费的专业 IP，都是对产出精度要求极高的群体。

我的做法是先把靠归档拿不到的经验和判断提炼出来，再搭一套信息流动机制，让模型按专家的判断标准，结合业务每天的变化，去承接原本只能由本人完成的专业操作。

**成交记录部分**

五个多月内签了十六家，客单价集中在两到五万，累计超过五十万。这些客户都有成熟的产品和稳定客源，瓶颈不在来客，而在个人产能。小团队或助理能接的是标准化的杂活，一旦涉及具体问题拆解、方案对比、对客户给建议，模型直接生成的结论往往不到位，最后仍要本人重做。他们真正想省的是自己的时间，而不是助理的时间。

要让模型真正顶上，需要打通两个卡点。第一，值钱的信息模型拿不到。面对一个具体客户、一个具体场景，专家会先看什么、依据什么取舍、为什么选 A 不选 B，这些很少写在资料里，有时连当事人自己也说不清，需要专门的采集方法。第二，信息更新太快模型跟不上。上周成立的判断这周就可能失效，模型若一直按旧档案工作，结论会越来越偏；可若每次都靠人工重新整理，省下的时间又被耗回去了。

因此提升落地精度，既要喂进有价值的信息，也要让信息在工作中被正确检索和调用。接下来先讲提取部分：把专家自己都说不清的隐性判断挖出来。流转部分我会另文展开。

**阅读说明**

这套方法不用写代码，核心是拆解、追问和业务理解，正好是我做老师、做生意练出来的能力。所以技术背景不是门槛。

谁会受益？正在做或准备做 FDE 的人想提升模型产出贴合度会用得上。即便不做 FDE，只是想让模型承接目前必须自己做的精细活，思路也一样适用。

文章偏细，核心方法论和落地细节都会讲清。

**为什么专家总说不够劲**

回到律师的例子。模型逐条审阅协议，风险点都对，但合伙人只改两处，因为他清楚全部改动会让谈判破裂。他结合法条和业务情境判断哪些是底线风险，哪些可以容忍。这种争与放的权衡，是十几年实践形成的，写不到任何文档里。

显性知识是可以写下来、查得到的东西，规则、流程、条款等。隐性判断是长期实践形成的识别方式、经验、取舍和行动习惯，在专家业务里往往是价值核心。只让模型掌握显性知识，只能做辅助；只有理解判断标准，才能参与分析、取舍和推进。

让专家口述判断往往空泛，老手带不出新手，销冠教不出销冠，就是因为“感觉”很难言说。所以不能靠问，要靠流程设计来挖掘。市面上很多知识库搭建是从已有资料出发，而我的前置动作是先解决信息怎么采出来。

**先建采集框架**

想让模型承接工作，先要明确喂什么。服务的多家公司后发现，不同业务在采集维度上高度重合，于是整理成一张框架，之后就能对照检查缺口。

信息分三块：商业运作层、服务对象层、个人层。

商业层要看卖什么、卖给谁、交付形态、周期；定价策略、付款方式、加价条件；主要成本、最耗时的环节；获客路径、成交方式、常见顾虑；交付启动条件、关键节点、所需材料、验收标准；团队分工、拍板人、常回流老板的事；成员优劣势、典型案例；工具模板位置；近期目标和痛点。

客户侧要看联系人、使用者、付费方、决策方的关系；表面诉求和真实诉求；犹豫点、追问点；对什么敏感、信任度变化；购买范围、承诺事项；沟通历史、分歧点；预算、时间、配合能力；当前进度和下一步。

个人侧是重点，分为底盘和打法。底盘是思维惯性和认知方式：才干结构、思维偏好、决策风格、重复模式、心力消耗、自我认知、优势短板、表达习惯、与模型的协作偏好等。这些特征在任何事情上都会起作用，采集后要落成“是什么、表现在哪、因此模型该怎么配合”的三句式。

打法是做事的固定路径。先确定客户想交出的具体工作，再围绕每项工作采集信号、节奏、决策规则、分型、复盘五个维度。回到律师案例，关键不是改了哪两条，而是他为何先看这些风险、为何有的争有的放、何时改变策略。

**怎么用这张框架**

框架是共性模板，特殊行业可在对应维度加细项。也可用提示词让模型先细化清单，再据已有材料整理、列出需确认项。

整体采集分成四步：盖洛普测评+业务访谈梳理缺口；围绕缺口做分批深度对话；回收对话回真实业务核对；整理成模型可用的依据并新任务测试。

第一步永远是人+事双线并行：用测评摸清思维底色，用访谈厘清业务现状和信息缺口。有了入场券，后续对话和结构化才能展开。
