## 一篇文章教你高效调用 DeepSeek、Claude 以及市面主流大模型

作者：侠狼

日期：2025-02-18

网上关于怎么用 DeepSeek 的教程不少，但大多要你东奔西跑换平台，卡顿也多。想要 DeepSeek 和 Claude 甚至更多模型一起协同办公时，跳转成本就更高了。

今天这篇就把问题一次性解决，教你用一套通用工具，完成 DeepSeek、Claude、GPT-4o 等几乎所有主流大模型的集中调用。

响应速度表现在线，具体效果可以看动图演示，非加速状态下的返回。

[PRE1]

提醒一下：这个方案是基于付费 APIkey 的，并非免费资源。

**1、整体使用思路**

我们采用的是**API 中转站**的方式来接入模型。

目前市面上提供这类中转服务的平台很多，稳定性如何、体验怎样，最终还是要自己多试。给大家推荐一个我长期在用的渠道。

下面是我个人的使用记录，充值 620 元可得 300 美元额度，正常使用能撑很久。只有在需要批量处理大量长文本、图片或压缩包时，额度消耗才会明显变快。

完整的软件操作细节在后面会详细展开。

[PRE2]

**2、申请账号并生成 API 秘钥**

先打开这个中转平台官网：[`api.v3.cm/`](https://api.v3.cm/register?aff=RSeH)

完成注册登录后，进入钱包页面进行充值。建议首次先充 10 美元，约 20 元人民币左右，用完再续。

[PRE3]

充值成功后，进入令牌管理页面，新建一个 Token。名称可以随便起，额度设置成 10 美元即可，数量填 1 个，不要开无限额度。

[PRE4]

[PRE5]

创建完后，在下方的列表里就能看到刚生成的令牌，直接点击复制保存。

[PRE6]

这串 APIkey 是后面配置的核心，一定要妥善保存。

**3、客户端准备**

首先要装一个统一的聊天客户端：ChatBox

官网地址：[`chatboxai.app/zh`](https://chatboxai.app/zh)

进入官网后下载匹配自己系统的版本，Windows、Mac、安卓、iOS 都有。

[PRE7]

为了演示方便，以下以电脑版为例。

安装打开后，进入设置页面，选择添加自定义模型。

[PRE8]

下面的配置说明供参考，基础参数不懂的话保持默认就行，不建议乱改。

[PRE9]

[PRE10]

新建模型时，建议直接用模型本身的名字命名，这样在切换时一目了然。

API 地址可以从我上面分享的中转控制台首页获取。

[PRE11]

模型名称则去中转平台后台查看，对应模型的价格列表，点击名称即可自动复制，粘贴到 ChatBox 的对应位置。

[PRE12]

目前我常用的三款模型是：

GPT-4 系列：gpt-4o-2024-11-20

Claude 3.5 系列：claude-3-5-haiku-20241022

DeepSeek：deepseek-r1-search

每个模型在平台上都有详细介绍，我个人最推荐上面这三款，基本能满足日常办公需求。模型版本会跟随官方同步，效果有保障。

**4、配置与验证**

各项参数填完后，进入对话界面，点新建对话，打开模型设置检查一下是否生效。
