# 用 n8n 搭了一套焦点新闻自动采集管道：从需求到落地全复盘

我是越越。这篇文章记录的是我用 n8n 完成新闻采集小项目的过程，从零开始到跑通大约花了半天。先感谢星球里的教练和作者们，你们的教程和实战经验让我学到很多。

## 起因与目标

有圈友在做垂直小号矩阵，需要稳定获得焦点资讯。我的想法是：让系统每天自动访问若干资讯源，抓取全球范围内的重点报道，再写入飞书 Base。因为后续要给矩阵工具用，这套程序得能承受较大的并发访问量，还要有不错的容错能力和长期稳定性。

说实话，我在接触 n8n 前没有任何流程编排经验，编程也是零基础。能这么快跑通，主要靠 n8n 航海期间的材料和 Youtube 深海圈的氛围。我现在已经能通过 Youtube 月入 5000 美元，学 n8n 是想给圈友做点工具，也想继续拓宽收入来源。

## 熟悉 n8n 基础操作

我的 n8n 实例部署在 yuetool.cn 的 n8n 子域名。如果你已经部署好，可以直接跳到下一节。

第一次打开站点，需要注册 owner account，也就是管理员身份。注册前准备好邮箱和密码：邮箱可以用 Google 邮箱或 QQ 的邮箱服务；密码需要同时包含大写字母、小写字母和数字。

注册完成并刷新页面后，就可以登录。建议把站点加入浏览器书签，后续进入更方便。

## 动工之前，把四件事想明白

### 目标定义

以前我每天都要在多个新闻站点和搜索引擎之间人工检索关键词，又慢又容易遗漏。我希望做到：早晨六点系统自动启动，访问预设的资讯源，抓取与关键词相关的报道，把标题、简介、原始链接整理成简报，再推送到飞书 Base。这样我一到公司，就能直接看到当天的信息摘要。

### 人工环节有哪些

把一切交给机器并不等于不用管。我梳理出三个必须人工处理的点：
- 搜索关键词，需要结合业务方向来定。
- Base 中的字段结构，比如标题、来源、发布时间、链接。
- 自定义代码的格式，如果流程里要写代码，我会先用 Gemini 定好逻辑。

### 新闻接口调用说明

GNews 的搜索类接口是 GET 方式，主要传两个参数：关键词 q 和密钥 apikey。具体域名、路径和申请方式可以看官方文档，我这边就不重复贴完整地址了。

NewsAPI 同样是 GET，参数包括 q、from、sortBy、apikey。from 表示起始日期，把 sortBy 设为 popularity 就可以按热度排序。

[PRE26]

流程里还需要接入一个 AI 节点，所以还要准备模型接口的 Key。我选了第三方中转，到中转平台申请 Key 后，填进 n8n 的 AI 节点即可。

各节点的作用：
1. 入口节点：先用表单提交做手动验证，之后换成时间计划节点，就能让它每天自己运行。
2. 并行抓取：同时向两个资讯接口发出请求，分别拉取不同关键词或不同来源的内容，缩短等待时间。
3. 字段整合：把返回的标题、链接、简介统一格式，为写入 Base 做好准备。

这次复盘让我更深地体会到：把模糊需求拆成具体节点，再逐个实现，新手也能搭出能用的工具。希望这篇记录能给你一些参考。
