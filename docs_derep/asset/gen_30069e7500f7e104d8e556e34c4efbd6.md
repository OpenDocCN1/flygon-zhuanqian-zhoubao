## 小红书店播从零搭建到付费投放的实战避坑笔记

作者：李谢谢

日期：2024-10-29

大家好，我是李谢谢，目前在做品牌自播。

今年6月和朋友喝茶聊天，他提到他们团队在做小红书和抖音双平台直播，小红书的表现甚至比抖音还好，退货率也更低，最近准备把小红书单独拆出来做。我听完直接心动了，一方面觉得自己也能上手，另一方面也觉得之前低估了小红书直播的潜力。

我们其实是去年11月就开始在小红书做内容了，一直在做图文笔记带货和达人对接，直播这一块完全没碰。当时觉得直播麻烦，也怀疑小红书的直播量级。

聊完那次后，我顺势就开启了尝试，到现在大概3个多月。最直观的感受是，比起抖音，小红书直播真的轻松很多。底层打法大差不差，只要做过抖音直播，上手小红书会很快。现在回头看，真的后悔没早点入局，白白浪费了不少流量。直播作为整个电商链路里转化率最高的环节，能带来很明显的增量。

我这边是做品牌高客单女鞋的，不同品类玩法差异会很大。本文会把直播间搭建到乘风付费投流的完整过程都讲清楚，希望对大家有帮助。

# 一、直播间基础设备配置

灯光：主灯+辅灯用 Amaran 200XS+光罩，一大一小一组；环境氛围灯用球形灯金贝 EF160 + Amaran 100d S，再加一个环形补光灯。灯光是重中之重，可以请专业人员上门调一次参数，后续固定使用即可。

相机：主机位索尼 A7M3 + 适马 24-70

大屏：小米电视

收音：罗德无线一拖二，体验很好很推荐

采集：圆钢 GC553

背景：自家装修，按售卖风格找专业设计即可

整体搭配要让产品看起来高级、舒服，尤其小红书是个重审美的平台。直播设备可以丰俭由人，但呈现质感不同，最终转化也会不一样。尤其是卖服装的，对细节成像要求更高。直播本质是做减法，花钱把画面稳定了，转化不好就不会去怪设备。

# 二、直播间流量来源拆解

## 2.1 笔记

进入方式：呼吸灯 / 购物车
人群标签：A3

笔记来的用户可以类比抖音千川短视频来的用户，精准度高，付费投放也主要跑笔记。进来的入口有呼吸灯和购物车，如果是投买手笔记，基本是购物车为主。

不过它没有千川视频那么精准，千川视频多为强营销垂类内容，笔记更偏种草，营销是辅助。所以进直播间需要二次转化，很多用户有想法还是习惯去淘宝下单。

很多人提到直播撬动自然流，笔直联动确实是双向的。笔记用户进直播间产生数据和成交，会反哺笔记的持续推流。

笔记渠道非常重要，建议先把笔记流量跑起来，再开播。

## 2.2 发现

进入方式：直播卡 / 呼吸灯
人群标签：A1 / A2

[PRE3] images.zsxq.com/FgTKk_lnzXRgp0GQKunznPUsozqn)[PRE4] images.zsxq.com/Fpi1LxSdM3vrC3qtSAy9GIm1xdHH)

这个渠道的核心指标是**封面点击率**，可在直播大屏查看。

比如曝光1万次，点击率1%只有100人进，点击率4%就有400人进，转化空间直接拉大，而且只是换一张图的事。直播封面可在电脑直播助手随时修改，不像抖音要等下播。

但点击率高不等于有效。卖鞋的直播间放美食、宠物封面，虽然点击高，进来的人不匹配，转化差还会污染标签。

封面会做动态展示，会实时截取直播画面，所以场景感、主播状态和妆造都要在线。

测试方法：
1）直播中实时换封面，对比不同场次的数据。没头绪时先用爆款笔记封面，再看同行优秀案例做优化。
2）通过付费测试。起初我用直投测封面，发现跑不动、数据太少。问了小二，说小红书用户对直播接受度没抖音高，直投难跑。后来改在投笔记时挂不同直播封面，比如20个计划对应20个封面，以周为单位对比更换。

## 2.3 直播间上下滑

进入方式：直接进入直播间
人群标签：A1 / A2

刷到直播间的泛流量，自然流重要来源之一。用户刷着直播间突然刷到你，缺乏铺垫，留存靠人货场和主播能力。初期流量很泛，数据起来后推送会逐渐精准，对主播和货品要求较高。

## 2.4 群聊

进入方式：群内推送
人群标签：A4 / A5

群聊天花板较低，需要长期经营，属于增值项。我们客单价高，鞋子几百块不能天天买，所以没太重仓群聊，更看重拉新。

群聊玩法多样：售后答疑促进转化、群内专属券、内测新款、直播预告等。进群本身也是数据行为。

# 三、直播间三大玩法

小红书直播是赛马机制，数据好才能上层级。做数据的核心就是憋单。

很多商家对憋单有抵触，觉得是套路。小红书是种草平台，平台也强调体验。但赛马的核心就是数据比别人好。如果不做套路也能赢当然好，但多数人做不到。

秒杀也是一种塑品+开价玩法，只是工具换了。本质不变。9月份有人靠憋单起号，中秋一天卖37万。抖音播法迁移过来的商家也表现很好。

适合自己的才是最好的。

**3.1 纯自然流玩法**

分两种：
第一种是内容强，笔记经常爆，像买手那样靠笔记引流转化。这种新手容易尝试，笔记爆了随便找个人拉满时长当客服，但不持久。主播话术、节奏、播时不稳定，流量会掉，最后不了了之。

第二种是主播和货品强，靠直播间数据自增长。双开的商家在小红书基本不发笔记。需要强主播，憋单演不好像个小丑。

憋单节奏可参考10分钟憋单+5分钟开价，场场递增。我们把秒杀改成憋单下架，秒杀有固定时效，容易断单。下架更灵活，可根据流速调整。秒杀带来的关注，可通过话术引导补充。

纯自然流要求高、稳定性差，不太适合普通玩家。但利润可观。建议叠加少量付费来稳定。

**3.2 纯付费玩法**

算清投产比，直接投放。底层依然需要内容，内容差投不动。本质是塑品+促单，不需要憋单。

如果不会做内容，可以走买手+直播联动。小红书蒲公英合作笔记可投放。买手内容质量高，投产往往比自产好。弊端是合作成本、买手人群是否精准、会不会跑偏。建议配合淘宝店做好承接，避免浪费流量。

**3.3 微付费玩法**

既要稳定又要利润，微付费更通用。纯自然流靠直投，量非常少；纯付费会挤占自然流。

建议节奏：半小时内，10分钟憋单做数据，20分钟开价做成交，给自然流留空间。很多商家品类多，笔记爆的不只是主推款，自然流空间能承接长尾咨询。既能拉数据，又不极端，以自然流为主，付费补成交。

微付费的缺点是利润相对低，优点是门槛低，适合主播不强的团队。三种玩法各有利弊，核心是找补短板。直播是整体，数据决定有没有人，转化决定人是否精准。

买手直播多为聊天式塑品，** *但我认为憋单直播的流量利用效率更高*** ，平台允许双开，也是在推动商业化加速。

平台希望商家有主理人形象拉近距离，建议主播参与日常笔记拍摄，提升信任感和转化，笔记也更容易爆。

话术不会写就去抄抖音同行的前几名，1:1抄再改，抖音活到现在的博主都很强。

# 四、直播间从0到1的关键

## 4.1 直播时长

推荐拉长时长，但前提是能稳定出单。几个小时一单且无推流，不建议硬拉。

主播数据做不好，拉时长是最省力的办法。平台活动如流量卡，都和时长挂钩。

前期多测试上午、下午、晚上的流量，找到合适时段后**固定开播时间、固定播时长**，每场数据递增，就能起量。

[PRE5]

## 4.2 开播

开播流量一定要接。接不住也没关系，但数据要到位。哪怕没成交也要把停留、互动做到位。

开播进来的都是泛流量，平台根据画像粗推。发过笔记的会好一点，纯直播起号更泛。这个阶段难转化，重点是浅层数据，为后续打标签做准备。成交模型决定推流模型，数据起来直播间才有人。

建议设计开播话术憋10分钟配合流速，开播能成交对后续推流非常有利。纯付费玩家后续开播流会消失，自然流玩家做好递增，开播流会越来越多。

## 4.3 笔直人群一致

我现在就遇到这个问题。笔记一直吸的是18-24岁人群，直播推送也是这批人，但高客单鞋子消费力不足，转化上不去，后期很难清洗。

起号期笔记不要做泛流，要垂直。先想清楚人群再做内容。

这里有个代偿原理：想练二头肌却用斜方肌代偿，看似举起来了，实际没练到。笔记花里胡哨吸来大量非目标人群，看似有流量，实际转化逻辑全错。前期垂直很重要。

# 五、乘风付费搭建要点

免费的东西最贵也最不稳定，笔记不能保证天天爆，付费能让营业额稳定。但**直播基础转化没跑通前不要付费，投的越多亏的越多**。

主播话术不熟就上计划，问题是主播还是投放？很多人把希望全寄托付费不现实，**付费是锦上添花，不是雪中送炭**。

我实操乘风一个月，对比千川落差很大。抖音很多人说乘风好，我有不同感受。

**5.1 操作流程**
相对聚光简化很多，页面跳转少，效率更高。聚光关联商品还要关联具体码数，看不懂。简化体验更好。

**5.2 投产下降 / 空跑**
乘风是商业化关键一步，投产下降很正常。
第一，用户习惯还在养成，小红书看淘宝买的习惯需要时间培养。站内闭环需要一轮轮洗用户。
第二，乘风产品不成熟，空跑严重，更像在采集数据训练算法。聚光成熟稳定，但更像卖流量的工具。乘风更像电商闭环工具，是完成站内转化的重要环节。

**5.3 笔记投放**
投产下降建议试定向人群，差别不大。能跑的笔记还是能跑，不能跑的还是不行。核心在内容和产品。视频比笔记更好跑，生命周期也短。

**5.4 投放策略**
付费撬动自然，本质是直播间数据好带动自然流。客单价高决策周期长，看全店投产调整。

测试出来的主计划持续跑，可以带动自然增长，主计划不要乱动，预算充足即可。投放核心还是笔记。

不知道核心人群，先托管跑，用结果倒推人群。乘风-数据-人群分析-人群洞察，有了数据可建人群包测素材，很好用。
