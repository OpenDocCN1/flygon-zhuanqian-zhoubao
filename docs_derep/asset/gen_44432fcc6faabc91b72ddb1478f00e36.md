如果你人在深圳，千万别只报周末的活动。深圳人的副业能量是真的卷，工作日的局里坐着的，往往都不是单纯的上班族。深圳的白天场子特别多，什么社群操盘手、保险合伙人、管着几家美团便利店的老板、在公众号上一个月变现几十万的内容玩家，林林总总，让人开了眼界，原来赚钱的路子可以这么野。

# 📝 一个月把生财门票赚了回来

我每天泡在风向标里刷信息，总想捡到一个能赚钱的点子，结果刷得越多越慌，越不知道该往哪跳。亦仁那句话一直在耳边——想继续买课，得先把10倍赚回来。这话一说，我更急了。焦虑了好久也没找到合适的突破口，后来瞎逛的时候看到有人在讲证券薅羊毛的玩法。回想一下，前几年算年化的时候，我也是拼命在主业之外找增收，做过这些套路，我清楚哪些是相对稳的。眼下也没啥好方向，但钱必须得进账，于是硬是靠这个在一个月内把生财的票钱给回来了。我把这个操作分享给苏苏，她也跟进了一波，她之前拉我进生财，我也算回点人情了。单说证券薅羊毛这件事，从头算下来，我赚的都已经好几倍于票价了。有人问我现金不够怎么办，我当时手头的活钱也不多，全压在投资里，朋友教我用信用卡做闭环套利，收益稳定所以风险可控。信用卡这招别乱用，高风险项目千万别碰。私域如果够厚，也可以自己拿佣金放单出去。我自己没深度参与这些，只是把这个捡鸡腿的机会告诉大家。

# 🚀 意外中了风向标

有一次和苏苏随口聊，她说你去小红书发条想找投资的帖子，保证有人来撩我。本来我也是想探探市场，看看现在大家都在搞什么。于是用一个粉丝就几百的小号去做了一次投石问路，点开率直接冲到一千多，评论私信不断，真的有种风口的感觉。因为定位在北京，来的项目大多集中在影视、车电、新能源、火锅、面馆这些方向，看下来挺有意思的，就是对我胃口的没有。聊了几轮也就作罢，没多久账号就收到违规警告。为了凑够三条内容，我把这次经历整理成风向标投稿，没想到真的中了。群里有人反馈说合伙人看了后很有启发，能帮到人那种感觉挺奇妙的，原本只是随手一发，没想到歪打正着。

# 🔍 收束一下

最近听到的一个段子是，以前靠港股打新赚了几百万的人，后来转战 A 股，直接亏光了。靠运气赚来的，迟早会还回去。这篇东西不算投资建议，我的底线是绝不拉人一起投钱，在我看来拉人投资跟放火差不多。我也曾踩中过小风口的人，起起落落，基本算是平平无奇但特想搞钱的女生，瞎忙活了不少，成事的寥寥无几。现在我还在到处找项目，就不想回办公室打卡了。做了个盖洛普测评，沟通和人际排得比较靠前，这才明白为什么我面试总能过。但过去的打工经历里，基本没让我发挥这方面的长处。上周北京线下聚会，有圈友说我讲自己瞎折腾和吐槽的过程挺有意思。那是不是该往我擅长的表达层去深耕？最近也在看播客和访谈，但为爱发电对我现在来说太难了，还是想要正反馈快、变现快的赛道。说实话现在正处在迷茫期，很希望能遇到已经跑通的大佬带一下。我可能不是最聪明的，但执行力绝对在线，听话照做没问题。知识付费这块我绝对是老用户，不会白嫖。最后祝刷到这条的靓仔靓妹都能日进斗金！
