# 二、课程大纲制作的“3大原则”

那么【大模块+小问题】+【AI】+【对标同行大纲】这三者怎么整合？——遵循“3大原则”⬇️

## <1> 使尽浑身解数，把课程最闪亮的卖点，都在大纲中凸显出来
学员买课之前，主要就是通过课程海报了解你的课。海报就是门面，课程大纲又是海报中的核心。最闪亮的卖点不在大纲里体现，还能在哪体现？课程正文里吗？讲课过程中吗？
酒香也怕巷子深，更何况你还不是什么名酒的时候……
所以，第一原则就是：课程卖点，想尽办法也要在大纲里亮出来。

## <2> 分模块，课程大纲最好分若干模块，若干模块下再分小节课
