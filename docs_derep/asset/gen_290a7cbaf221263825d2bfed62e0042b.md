# 互联网人的颈椎自救手册 兼 生财人精力回血笔记

> 来源：[https://giwb0zv0cv.feishu.cn/docx/C5YOdSCh3oMzEVxAYZCcEKbTn8c](https://giwb0zv0cv.feishu.cn/docx/C5YOdSCh3oMzEVxAYZCcEKbTn8c)

和生财的老铁们打个招呼，这篇是我亲身踩坑的颈椎病发作、康复全过程的复盘。

如果你每天对着屏幕、刷手机低头、肩颈僵硬、有富贵包、脖子转不动、呼吸变浅、下午就掉电、处于亚健康状态，那这篇可以看看。

本不想写，自我剖析挺难的。但前段时间看完明白老师的文章，我直接破防了。问自己能给朋友们带来什么帮助，答案是能。

第一，这段经历算是创业路上的一次大绕路，能少走弯路就少花钱少受罪。

第二，康复的节奏和做项目很像。

第三，搞钱的前提是身体在。颈椎问题解决后，我感觉精力直接回升了三分之一，赚钱效率才上去。

第四，大多数人现在还在无症状或轻微期，这个窗口期干预性价比最高。

第五，康复路上坑多，且都是深坑。

第六，搞互联网的，手机电脑比媳妇亲，颈肩腰问题泛滥。

身体不垮，才能持续变现。想通这一点，就更像生财的主题了。不好意思地讲，我还是写了。

## 前言

先说个真实场景。六月份和山西生财的几位大佬吃饭@胖大玲 @奇杰 @张集慧 @李 司令。山哥、龙哥还有我，一共八个人。聊到健康，三哥腰椎开了刀，我和司令去年也因为颈椎、腰椎突出各躺了半年。饭后去慧姐公司，我顺手摸了摸慧姐和杰哥的肩膀，硬得像块板，一大片。没敢摸大玲，单身妹子不好下手。

结论是：七个人里，三个人颈椎腰椎已经严重影响工作生活，三个人亚健康，一个未知。真的吓人。

这段时间我一直在想创业到底换来什么？有多少人钱没赚到身体先废了，有多少人公司要扩张时人先倒了，有多少人赚到钱也享受不了？

后来才明白，对创业者来说，健康必须排第一。创业一到三年可能感觉不到，五年以上，尤其是久坐、重度用机的人，颈椎腰椎几乎十有八九会中招。

# 引子 背景可跳过

从去年三月杭州生财大会开始说起。

当时和慧姐、杰哥一起去的，第一面还有点拘谨，我是新人，他们是分享嘉宾，现在已经能直接勾肩搭背了，时间挺神奇。

刚到杭州下毛毛雨，湿润的空气带着甜味，和北方的大雨完全不一样，一切都挺美的。

会场里见到谱姐，第一面就被震撼到：小个子，大能量。她坐在第一排，几秒钟拍一下，发几十个拉新群，朋友圈两三篇拉新文案还成交了客户，又回陪伴群分享，又认真听涛哥分享。我心里只有服字。

听老大开场热血沸腾，想加入生财，结果已经在里面了，气得发了条朋友圈。回家后我老婆也被拉进来，一开始抗拒，后来说真香。去年她看航海资料做抖音直播变现了三万多，门票赚了十几倍，后来因为要晚上直播伤身体又要带娃就停了。

印象最深的是涛哥的四字生财咒语，一口气飙几十个词，听得我都忘了呼吸。佩服文采也佩服肺活量。

会议回来像打了鸡血，准备大干一场。

回太原后忙着做项目、做矩阵、认识朋友。司令、大玲、虾总、新亮、小妖、船长、一休、正记录、龙哥……一切都在变好，那大概是去年最美好的阶段。

写这段引子像在给自己放电影，就当背景交代了。

# 康复时间线

## 第一阶段：忽视

某天早上低头突然剧痛，当时没当回事，就像小说里说的，最初大家都以为只是场普通暴雨。

后来演变成肩膀发硬、活动受限、抬头低头困难，还是没放在心上。事实上半年前就有征兆，下午五六点就没电，七八点必须躺床，完全不像三十岁左右的人，像电池漏电。后来才懂是颈部肌肉持续紧张导致供血供氧不足，之前还以为是肾虚。

现在早上六点起，中午眯半小时，晚上精神还能玩闹，吃饭也干脆。

当时想着随便按按，找了个盲人按摩，结果更严重了。这里有个大误区：觉得只有大病才要去医院。其实专业康复按摩价格和外面差不多，更科学。现在想起来后怕，颈部高位神经密集，一步走错可能后悔终生。专业理疗都是轻柔按压穴位，还会教日常体态调整和力量训练。

以后约朋友做康复按摩的次数，应该超过约8号技师了。

## 第二阶段：轻视

盲人按摩把我送进医院了，还是不重视。去年六月去家门口医院中医康复科理疗，做十多天中频脉冲。医生让我回去做颈椎操，具体做哪套他也不清，回家跟着B站周六野、范里猿等人乱拉伸，效果微乎其微。芷蓝姐提醒我一定要拍核磁，去三甲专业医生做康复。我却觉得问题不大，又多交了学费。这里学到：要多找几位医生，不同科室视角完全不同。骨科只看骨头没事就算没事，中医说得含糊，就像芒格说的，拿锤子的人看什么都是钉子。

医生让我回家做颈椎操和拉伸，怎么做也不知道。回家瞎练，大概率拉伤。

今年在运动康复师指导下才明白，每个动作都要正确姿势，需要人纠正。

先放松肌肉，再拉伸，再练力量。动作要根据肌肉紧张程度、力量水平和体态来定，每周计划都不一样。网上很难得到正确方案，每个人情况都不同。

康复期我见过很多刚做完手术不做康复的人，最后瘸、痛、活动受限，都是术后医生说多活动多锻炼，病人不会动，动过头或动不到位，最后才来康复，已经晚了。

最大的认知是：一个人如果只在单一学科里深耕，必然有局限。问题是系统性的，但医生、教练、咨询师大多只从自己懂的角度给方案。好的人才需要T型或π型，懂专业也懂关联领域。

## 第三阶段：摆烂

治疗效果不好，加上医生消极说法，这个病只能养，多躺着。急性期我每天躺床上，转头低头都疼，焦虑、恐慌、无助，还经常哭。【独白：我才三十岁就废了，家里还有七十岁的老妈、上幼儿园的孩子，还拖累老婆，我是个废物】状态很消极，觉得自己在物理层面垮了。

不展开心理部分，直接说收获：深刻体会到身心相互作用。医院里几乎每个身体有症状的患者都伴随不同程度抑郁。反过来，身体变好，心理也会变好。

“生命若海洋，躯体以为岸”这句话在我身上应验了。创业焦虑时，最直接有效的解法是把身体养好，多运动，性价比最高。

随着肌肉紧张缓解，精力回升，斗志也回来了。天晴了雨停了，我又觉得我行了。怪不得说身弱不担财。

摆烂期我在小红书刷遍评论区，记了两大张纸的偏方。试了个遍，有点用，也有差点把自己废了的。

比如吊单杠，肌肉太紧没弹性，直接加重。游泳、羽毛球在严重期也会加重。晒背、八段锦、膏药……基本都试过。

这些方法不是全错，只是对轻度人群有效，不能生搬硬套。彼之蜜糖，汝之砒霜。

这个阶段最大的教训：不懂乱搞不如不搞，没有认知的大量尝试，基本是原地踏步甚至倒退。网上牵引器我也差点下单，拼多多销量吓人，后来才知道操作不当可能导致瘫痪。

和创业一样，一上来猛操作，最后负债累累。雷军那句找个懂的人问问，要用上。难点在于柠檬市场里怎么找到真正懂行的人。

## 第四阶段：消极

后来去找针灸，针灸师很专业，六个疗程半个月，症状去了七八成，一度以为好了。半年后反复，才承认针灸去的是症状不是根源。姿势问题还在，问题只是藏起来了。

针灸师给的建议很全面：别熬夜、别受凉、注意情绪、注意姿势、锻炼、拉伸。可情绪管理、拉伸、体态、锻炼没有人带，自己做不了，还容易伤。

很多地方只告诉你是什么：你有认知问题、情绪问题、执行力问题……于是产生错觉，懂了就等于会了。其实没有how只有what，很多正确的废话并不能落地。

## 第五阶段：积极

折腾一年受够了，下定决心彻底把身体搞好。

先去骨科拍核磁，医生说突出、曲度变直，不算严重，开药让你躺着养。对骨科来说，不手术就不算严重。

我心里有数了，骨头问题不大，是筋膜和肌肉。

查到康复科，同时付费咨询十几个医生，中医康复和运动康复各有。筛出三个能多角度思考、能给出明确方案的。

六月遇到一位不错的运动康复师。

诊断是颈型颈椎病。手法、牵引、理疗、康复训练组合拳。

一开始我还在跟着周六野拉伸，他直接叫停，说肌肉太紧不能拉。

第一步放松肌肉，五天。第二步练颈部力量。第三步加拉伸。第四步加背部训练。第五步核心训练，平板支撑不到三十秒，被实习小姑娘惊讶了。

五次回血，十次重生。速度很快，选择比努力重要。

现在锻炼后基本和正常人没区别。

# 总结

额外几点。

1.养着等于拖着
卧床一年没用，康复需要主动干预。很多术后病人被告知回家养，结果终身受损。医生没责任，只会说你没养好。需要去魅，行业里大部分人都局限在自己领域。

2.枕头不是越低越好
我换了十多个枕头，最后睡毛巾。坊间说越低越好，骨科也这么说。根源是头前伸、下巴外凸，枕后肌群长期缩短。我就是萎缩后才睡不了高枕。肌肉松开后拉伸十多天，现在能睡正常枕头了。

[PRE3]

3.头疼医头脚疼医脚
去魅。骨科看骨头，康复看功能，针灸看疼痛。要逐一排除，对应找专家。

4.网上信息质量参差
互联网看病能找到点有用信息，但一句话解决不了问题。拉伸、力量训练即使是对的，也要看适不适合你现在阶段、几组怎么练、动作如何纠正、下一步怎么衔接。大多数是屎里淘金，十条八条错，两条对，分辨不出。

5.掩盖问题 vs 解决问题
针灸半年缓解疼痛，但姿势习惯没改，病根还在，会更严重。

6.让你舒服的不等于变好
低枕头舒服，但代表病情更重。康复训练很累很枯燥，但每天都在变好。

7.身体是第一位
这次算是顿悟。身体归零，一切归零。以后所有决策都以健康为前提。

8.焦虑期少聊病友
和重症病友聊天只有互相吓唬，没有互相鼓励。古代叫炸营。

9.治未病，康复科yyds
有没有症状都要做运动康复理疗，提前纠正不平衡，防患未然。

10.一定要借助朋友的力量
去年山西生财群很活跃，线下聚会多。再严重时基本都参加，郊游、撸串、露营、台球、夜话，都是续命良药。

对照自己阶段，大多数人还在轻症或无症期，少量投入就能重获健康。后期心态更重要。治疗要去正规大医院，多找不同科室医生和康复师带。

PS：以上仅个人经历，非常主观不专业，具体以医生为准！

# 结尾

呼吸、体态、康复、柔韧与力量，结束了么？没有，才刚开始。

卡尔·李维特说：“呼吸不好的人，做什么都做不好。”

我们出生时都是腹式呼吸，后来变成胸式呼吸，导致斜方肌代偿、胸肌紧张、全身发紧，很多颈肩腰腿痛由此而来。调整呼吸要学。

体态涉及走路坐立和身体结构，要重新塑形要学。

柔韧性，古人说筋长一寸延寿十年，柔则生刚则死。瑜伽拉伸要学。

力量不足支撑不了骨骼体重，健身要学。

别忘了心理学，身心互相影响。

还有正念、冥想、营养学……

我了解到：
1.康复体系庞大复杂
2.穷文富武有道理，武道需要投入

上帝给万物标了价，得来太易的不会珍惜。出生时我们最健康，想要复归婴儿状态，需要自己付出。第一次是天赐，第二次要争取。

感谢生财平台和认识的伙伴，希望我们都能拥有：

婴儿般的呼吸和睡眠
婴儿般的体力和精力
婴儿般的生命力和生机
婴儿般的好奇心、想象力和求知欲

如果每个人都有一棵生财之树，方法技巧思维是茎叶，睡眠、精力、好奇心、想象力不正是根吗？
