# 延伸2

另一种更省事的做法，是把自己亲手写爆过的文章直接喂给模型，让它照着你的语气复刻一版同款风格。这样就能把写作效率拉满，初稿出来后再由你人工把多余的部分精简一下，整体的脑力消耗会小很多。

# 注意

这个思路只适用于文学类的创作，也就是非事实性的内容输出。要是想写时效性、数据类文章，就得自己参照上面的逻辑去定制提示词，最好拿同类型账号的稿件来当模板来构建。

# 结尾

说实话，用AI去模仿对标公众号的风格写文章，本质上并不复杂，难的是你愿不愿意踏出这一步。毕竟能真正变现的，还是那些本身有积淀的人。现阶段的AI在归纳、拆解、逆向推导上已经非常强了。

如果第一次生成的提示词没达到预期，别着急，多和它聊几轮，把你想要的样例不断喂进去，让模型明白你的标准。它会越改越贴。最好是拿生成的提示词去跑几个标题，看看实文章的效果，再针对性地打磨。

等到模仿度稳定在90到95分左右，就算是及格线了，接下来就靠持续出文去测数据，看有没有流量反馈。
