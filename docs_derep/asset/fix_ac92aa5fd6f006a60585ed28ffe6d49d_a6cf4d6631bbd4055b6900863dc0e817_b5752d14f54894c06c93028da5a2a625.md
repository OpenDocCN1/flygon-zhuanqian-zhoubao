我今年二十六岁，婚龄两年。爱人小龙在制造企业担任技术岗，经常要上夜班。我在城里的一家公司做白班，我们俩都在市里工作。

丈夫是乡下来的，父母仍在老家种地为生，日子过得紧巴。岳父为人沉默寡言，却待我们十分厚道。岳母经常过来帮忙做家务，和我们相处融洽。

新婚时，岳父母还帮我们承担了一部分彩礼和首付。如今每月房贷在还，生活压力不小。但我觉得夫妻要相互体谅，一起扛过去。

某天夜里，丈夫刚去上夜班，大约晚上十一点左右。我把孩子哄好，正准备休息，忽然听见敲门声。

大半夜谁会来敲门？我赶紧披上外套去开门，门口站着的是公公。

公公面色为难，说有事想和我谈谈。我让他进屋坐下，询问缘由。他支支吾吾讲不清楚，只是问我手头最近是否有些闲余资金。

我一头雾水，不明白公公深夜登门是何意。正说着，婆婆也随后赶来，把事情原委讲了清楚。

公公一直说不出口，这时候婆婆赶到，直接把来龙去脉摊开了。

婆婆说，今晚她侄儿的孩子打来电话，称其父亲突发急症，必须马上手术，需要一笔很大开销。

他们家经济条件一般，只能先找亲友凑点住院垫付。公婆也想帮一把，可手上也不宽松。

婆婆接着讲，以前那位外甥对我们家多有支持，现在遇到困难，我们也应该尽力。公公才深夜过来找我，希望我能出一份力，但他性格内向，难以启齿。

我立刻表示理解，说会想办法筹措资金帮忙。婆婆连连道谢，公公也松了一口气。

听完婆婆的讲述，我马上理解了他们的难处。外甥突发疾病需要用钱，我们家理应伸手相助。

我告诉婆婆，我自己现金不多，但会打电话联系弟弟，看能否先凑个一到两万元，其余部分我再慢慢想办法补上。

次日清晨我就联系到弟弟，他同意借给我一万元。随后我又从个人存款中取出三千元。凑到一万三千元，我交给了婆婆。

婆婆十分感激，说我是他们家的恩人。我说都是自家人，无需如此客气。公公也连声致谢。

后来丈夫下夜班回来，听我说了经过，很受感动。他称赞我处理事情果断，关键时刻能为家人顶上。

他说像我这样贤良的妻子和媳妇，是全家的骄傲。从今往后，无论遇到何种困难，我们夫妻都会互相扶持，共度难关。

此后公婆在熟人面前也常夸我是个勤快能干的好儿媳。每当提及此事，公婆都会毫不吝啬地表达谢意。

我却说，这本就是应该做的。夫妻之间本就该互相支撑，这点小事算不上什么。

# 更好的使用说明手册 补充 必看

1、prompt 任意板块都可以用你喜欢的内容更改，但最好不要大改

2、workflow 可以按照你喜欢的操作流程来设计

3、没有好的优化建议的时候，可以让 AI 替你提意见，而后直接让它帮你优化，如果有，就直接提。

eg:

[PRE8]

[PRE9]

4、生成的内容不满意，你可以让它使用各种风格润色，幽默、大白话、鲁迅、王小波都可以……如果生成内容还不满意，可在 prompt 中增加小样本训练，即样本演示。

5、AI 生成内容还是会胡编乱造，如果对真实性有严格要求，一定要手动检查

6、AI 只是工具，可以把你从 0 分的水平，提到 50-60 分，偶尔会有 80 分的表现，但如果再进阶，只能靠自身修炼了。

7、有朋友说，一发 prompt 给它，没有按照要求输出，那就强调它按照指令输出，让它进入初始模式。每一个步骤都可以强调的，提醒它，让它修正。

[PRE10]

比如像上面这张图片，gpt3.5 直接开叉了，没有遵照指令，强调它：<请你遵守指令>便可修正（大多数情况下都可以，目前还没有看到例外，但不排除会出现意外）

也可以像下面图片展示，直接复制 workflow 流程给它，会重新唤醒 gpt。

https://chat.openai.com/share/1a883177-2eb2-411e-be29-fc56fe976f9c 前面发的这个操作演示基本涵盖了所有使用技巧，注意看流程和方法。

[PRE11]

8、结构化 prompt 是比较稳定，但是它本质上还是一个“文字接龙机器”，用久了会“不听话”，这时候要适当强调它或者提醒它，比如增加在对话框输入“请保持重复率低于 30%”，“字数要 1200 字”，“请遵守指令”等等。

9、当不确定 ai 生成文章的重复率合不合格的时候，建议还是去第三方查重网站测一测
