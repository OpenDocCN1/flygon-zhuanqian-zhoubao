# 直接上手

起号
优先找存量号使用，新注册的也能跑。封面图和自我介绍无硬性要求，关键是不要有违规历史，有黑点的话不如直接开新号省事。

选工具
找一个在线AIGC绘画平台即可，我当时用的是无界AI，主打口号是人人都是艺术家。

批量
按上述节奏循环，每天产出3-5篇足够。

发布
发文时挑一张吸睛封面，摘要区别留空，用AI生成的文字填充即可。文章底部的原生广告建议关闭，体验更好。

收钱
次日就能看到广告分成到账。起初可能只有几分钱，但已经算正式入场，算是薅到第一波羊毛。

进阶
一旦捕捉到热点，就重复选题-找图-写文-定标题的闭环。越熟练耗时越短，收益反而累积更快，还能做矩阵带小号。我当时用主号导流，把三个副号都推到了500粉门槛。
