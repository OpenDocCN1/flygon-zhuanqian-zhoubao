# 天没亮就生火做饭，这个乡镇包工头的一天比你想的难

前些日子我回鲁地办点私事，趁机跟表弟聊了聊他这些年折腾的行当。

最早的时候，他跟人搭伙做焊接挖沙船的买卖，行情好的那几年攒下了一些家底，可后来市场一冷，挣的钱又全搭进去了。我们这儿是出了名的花木之乡，他索性掉头扎进绿化施工分包这一块，说白了就是大家常讲的“包工头”——项目自己跑下来，人手从周边村子里临时招呼，领着一帮乡亲去栽花种树。

活儿大多在省内兜圈子，偶尔也伸到邻省的地界。按棵算账，甲方给到一毛多，发到工人手上只剩七分，他赚的就是这点中间差价。真正让人头疼的是回款：工钱必须当天结清，可甲方的款子常常压着，碰上好说话的先给一半，剩下的只能赊着——这笔垫出去的钱，就是他心里最放不下的一块石头。

工人吃住行也都压在他肩上。为了多省几个子儿，饭得亲自做，天还没亮就蹲在工棚边上支锅烧火。要是赶上近处的工地，凌晨四点就得摸黑发动车子把大伙拉过去；为了抠成本，他添了一辆面包车，坐不下也得硬塞——真按规矩跑根本拉不完一趟，可要是雇个司机，那点血汗钱就全没了。四点钟爬起来，路上再颠两三个小时才到地方。

收工回来杂事一堆，能睡上五小时都算烧高香了。

搁山东乡下，一年挣个几十万，搁当地绝对算体面。可这钱是拿命换的：垫款的风险自己扛，一天十几个小时泡在工地，全年连个喘气的日子都没有；跑业务是他，握方向盘是他，掌勺是他，端茶递水还是他。

报纸上和小说里写的包工头，多半一副奸猾嘴脸。可像我表弟这样的人才，才是这行当里最常见的样子。

国内劳动力大军里，还藏着无数这样的小包工头、打工人。他们换来的报酬，说到底还是超负荷体力付出的折现——况且我家乡那一片的底子，在全国已经算殷实了。

能发声的人，大多扎堆在省会与一线城市。可他们眼里装的是写字楼里的剧本，嘴里讲的也只是少数人的切片。而像我表弟这样的角色，恐怕才是那部分被折叠起来的真实乡土。
