# 复制即存灵感：用 n8n 工作流 + 快捷指令，把笔记直接丢进飞书

> 来源：[https://oet21ud8a2.feishu.cn/docx/DYrDd6QPooYWP2xTYmQcHqrZnTf](https://oet21ud8a2.feishu.cn/docx/DYrDd6QPooYWP2xTYmQcHqrZnTf)

大家好，我是富百。现在在生财联合办公，YouTube深海圈的教练，专攻自动化流。我一向不碰无意义的重复劳动。

亦仁刚丢出 n8n 超级标，凑巧我正被记笔记这件事困住。我的困扰很典型：

在公众号里刷到一句金句，在小红书、即刻、X 上看到段好文案，想留存，要么切到笔记 App，要么退回微信发给自己。

灵感一闪而过，写在 A 里一点，B 里一点，最后自己都找不回来了。

最早靠笔记软件，问题是来回切换成本高。iOS 还会杀后台，切一下卡十几秒，等打开了，记笔记的冲动已经凉了。

后来改成发微信小群自用，用着用着发现更糟：小群里东西堆成坨，没法改、没法勾、没法归档。

作为创作者，我要的只是一个摩擦最小的通道，让创作的热情不被流程磨掉。我不想折腾，只想留住。我要的体验是：复制，扔进一个我熟悉的统一入口。等有空再批量整理。

于是我搭了一套不切窗口、秒进飞书多维表格的 n8n 工作流。

复制后一键收纳，所有灵感汇到同一张表。逻辑很简洁，体验很顺滑，而且可玩性很高，可以按个人口味继续魔改。

## 它现在是什么体验

只要框选一段文字，唤起快捷指令，这段内容就直接落进你的飞书多维表格里。

不管当前在哪个 App，任何选中复制的操作都能走通，完全不用离开当前页面。这是典型懒人式的挑剔方案。

## 怎么搭起来

### 整体流程

手机已复制内容 → 触发快捷指令 → 调用 n8n 工作流 → 写入飞书。整套链路很短，上手门槛低。

### 前置准备

*   能正常访问的 n8n，云版或自建都行
*   飞书开放平台账号：拿到 app_id / app_secret、表格的 app_id / table_id，并给应用授权写入权限

### 节点一：Webhook 触发

这是接收快捷指令信号的入口，所以放最前面。

Webhook 简单说就是一种被动 API。某个事件发生时，A 系统会主动“打电话”给 B 系统，相当于一个自动触发的信号。

[PRE7]

参数要点

记住生成的 POST 地址，后面要在快捷指令里填上。

HTTP Method 选 POST

Path 可自定义，方便辨识用途

Authentication 选最简单的 Basic Auth，自己设定账号密码并记下，快捷指令会用到

Respond 选 Using 'Respond to Webhook' Node，这样最后一步可以把写入结果回传给手机，让你知道是否成功写进飞书

### 节点二：获取飞书票据

[PRE9]

[PRE10]

配置方式

Method: POST

URL：https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal

打开 Send Headers，选择 Using Fields Below

Header Parameters：Name = Content-Type，Value = application/json; charset=utf-8

打开 Send Body，Body Content Type 选 Form Urlencoded

Specify Body 选 Using Fields Below

Body Parameters：Name 填飞书应用的 app_id，Value 填 app_secret
