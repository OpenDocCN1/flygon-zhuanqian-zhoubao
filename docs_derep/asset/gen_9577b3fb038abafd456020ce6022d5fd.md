# 六. 规划与赛道认知

## 规划：

一、推进部分环节自动化。现在我的图生视频流程已经很固定，重复度高，我准备用影刀搭建一个图生视频机器人，目标一周内上线。每条视频至少能省出一小时，后续效率提升是确定的。

二、再开一个副号继续深耕当前赛道。如果能在一个月内达到YPP标准，就能验证这个赛道具备快速起号的能力。

三、只做对标学习，不做硬原创。持续去挖掘这个赛道以及周边赛道的优质对标，爆款脚本都是被市场验证过的，直接拿来复用效率更高。

## 对赛道的理解：

我目前对这个赛道是看好的。现阶段我的YPP数量还比较少，所以我的打法是先用这个赛道快速拿到YPP资格，拿到变现能力后再回头评估赛道本身的盈利性。

赛道细分方向目前主要有：

1. 屌丝逆袭类。核心是贫穷被嘲讽、被抛弃后靠努力翻身致富，或是身材困境被嘲笑后通过健身逆袭。
2. 家庭伦理类。比如孩子被遗弃后被普通人家收养并逆袭，或是儿媳嫌弃老人后被抛弃，儿子良心发现重新接回老人。
3. 出轨类。丈夫或妻子外出期间另一方搞外遇，最后被当场捉住。
4. 救援类。男性拯救女性，或动物拯救人类的桥段。

你会发现这些剧情和过去的达人秀、猫狗故事在内核上高度重合，都是在复用最原始的人性冲突。所以印度故事赛道很难没有流量，人性是恒定的。而且对标的范围不必局限于印度故事，任何故事类赛道都可以作为参照。

当然，这个赛道会是逐步进化的，内容形态会越来越精致丰富，目前已经能看到这种趋势，主要体现在：

1. 分镜数量在增加，时长也在拉长。我刚开始做时大概12个分镜，时长40秒左右，现在主流已经是20个分镜左右，时长一分钟。
2. 制作手法不再局限于pixverse的简单转场，开始大量混剪可灵出品的画面，后期质感越来越接近我之前做的达人秀变身视频，衔接更丝滑。
3. 配音和音效更立体。早期主要靠一首背景音乐，现在逐渐加入环境音、动作音效等细节。

最后是性价比的考量。如果未来视频制作难度持续提升，耗时耗力增加，但收益水平不变，毕竟印度流量的RPM是偏低的，那可能就需要考虑换赛道了。反过来说，难度提升也是一件好事，能倒逼制作能力升级，这些底层技能是通用型的，以后即便转赛道上手也会更快。
