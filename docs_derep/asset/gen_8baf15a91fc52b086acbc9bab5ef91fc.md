# 靠Notion模板年入百万美元？拆解之后，我才发现自己漏了最关键的一环

你可能很难想象，把资料整理做到极致，居然能开辟一条年收入破百万美元的路子。在“第3期选题9”里，拆解的主角正是凭借Notion模板实现了年入100万美元的成绩。

作者猫叔坦言，这次复盘让他看清了自己与前辈们的明显差距。最让他警醒的是“核算”这个环节——过去他几乎从未认真关注过，可以说是完全空白的一块；数据维度上的表现也远谈不上理想。他真诚感谢“生财”提供了这次机会，并表示今后会在这块多放一些注意力。

说到底，单纯整理信息并不构成真正的护城河，能把每一笔投入、每一分收益都算明白，才是拉开差距的核心所在。
