我是Viola，之前是大厂Web3业务负责人。23岁时拿过500万融资，后来在公司内部作为合伙人推动新业务分拆，融过数千万。这几年大部分时间在海外做AI和Web3项目。

去年我离开大厂，带团队去海外融资，结果不顺利，项目停了下来。之后半年，我边旅行边给朋友做市场顾问，表面自由，内心迷茫。每天和AI聊自我发现，还约了盖洛普测评。老师说我有带兵打仗的天赋，我也信，但我手上没有兵，内耗反而更重。

直到10月，我才想明白：与其赌一个还没做成的事，不如把过去几年自己做得最多、也最顺手的事捡起来——帮创业者把他们的故事讲清楚。

方向定了以后，90天内我签下几位付费企业，单笔合同都是十几万。最近几条代表作在海外也有十几万到二十万以上的曝光。业务刚起步，但从怎么定位、怎么报价到怎么落地，这条链已经走通。

这次经历给我两个很深的感受：

- 做企业级业务比做消费级产品轻松。消费级产品要同时扛获客贵、转化慢、留存难三座山；企业级业务只要让老板算清ROI，决策链就很短。个人创业初期，不要一上来做产品，先用服务跑案例，更理性。

- 创业者的个人品牌是杠杆，不是流量。你要的不是粉丝总量，而是对的人看到你——投资人、关键客户、潜在用户。所以别沉迷热门模板，先搭一套稳定体系，热门内容是水到渠成的事。

这篇分享会给你四样东西：

1. 一条真实的企业级业务从0到1验证路径：怎么选方向、怎么谈下第一位十几万的付费企业、交付包怎么长出来、落地时到底给什么、这个价格为什么成立。
2. 一套我对外开源的长文创作方法论。
3. Compound，我用它做自我交付、也给客户交付的同一套Claude Code Skills，可直接安装。
4. 一次换链接的机会：业务还在0到1，我很想认识同样做企业服务的人，或者需要打造个人品牌的创业者。

一、为什么是这个方向

离开大厂后，我带着团队拼了半年融资，没拿到钱。那段时间非常挫败。过去我是带队打仗的人，一旦资本这条路走不通，我根本不知道自己还能做什么。接下来几个月，给朋友当顾问、到处走，内心一直焦虑。每天跟AI对话找天赋，还找老师做盖洛普测评。她说我适合带队，我也认可，但我没有队伍，所以越探索越卡住。

10月，我开始回顾过往：跟我背景相近的人，他们有什么困惑是我能解的？后来想到，我或许可以帮AI或出海创业者解决增长和影响力问题。

为什么是这个方向？两个原因。

第一，那些创业的痛我全经历过。23岁拿融资、在大厂推动业务拆分融资、海外做项目，让我知道创业者不同阶段卡在哪里。自己下场融资失败后更确定：小团队能撬动局面的核心杠杆，是让市场先听见你。

第二，AI时代，差异化比优秀更重要。塞斯·高汀有个奶牛理论：几百头普通奶牛站在路边，刚开始会觉得新鲜，20分钟后就不想看了；如果出现一头紫色奶牛，你会一直记住。AI让生产变得很便宜，将来会有无数相似的产品和内容冒出来，大家很快就会看腻。想被人记住，不一定要更好，但要与众不同。

所以我认为创业者的个人品牌会变得前所未有地重要。以后所有科技创业者也都要亲自下场，面对用户。

选择企业级业务，还因为启动更快。消费级产品是注意力战争，要和所有App抢用户时间，获客贵、转化慢、留存难。企业级业务不一样：你帮我赚到的或省下的钱比付给你的多，我就买。ROI算得清，决策反而更快。

所以我的路线是：先靠企业业务积累真实案例，验证方法论，想清楚了再产品化。

二、这个需求为什么真实存在

徐沪生有一句话我很认同：创业者做个人品牌，最大的坑就是学上一代娱乐网红。

两者的底层逻辑完全不同。网红追求绝对流量，再把流量卖给广告主；创业者要的是让精准人群看到自己的产品和服务。

创业者的优势也不是表演，而是专业积累。AI创业者最懂AI，Web3创业者最懂链上叙事。离开专业，创业者就是普通人。

所以创业者做创作，关键是如何呈现专业深度、思考能力和人格魅力。

创业者有什么痛点？他们每天的信息密度极高，决策复杂度、行业洞察都远超普通内容作者，但写出来的东西很少有人看。

原因有三个：
- 太忙：公司业务缠身，花一小时写深度稿，时间成本太高。
- 怕丢脸：怕没阅读量，怕同行觉得水平一般。
- 不知道怎么把输出变成商业价值：写得好、有人看、还能让人对产品感兴趣，三件事同时做到很难。

而且不同创业者的目标完全不同：有人要融资，有人做消费者社群，有人要触达企业开发者。不可能用一个模板套所有人，这也是市面上大多数个人品牌服务对创业者不够用的原因。

我的切入点，是我完整经历过从0到1到增长的各个阶段，清楚不同时期的营销需求。所以我做的是定制化的创作工作台+咨询+营销服务：

- 从你的定位和阶段性商业目标出发，明确表达策略。
- 基于此搭一个可复制、可生长、可更新的工作流程。
- 再陪你产出代表作品，并精准分发给你想影响的人。

三、第一个付费企业为什么买单

有想法之后，我没有急着开发产品，而是先列了一份交付范围，定了一个自己觉得合适的价格，然后去找一个真实的人聊。

我找到一位认识多年的创业者朋友。我认可他做的产品，也觉得他是长期主义者。沟通之前，我做了个关键动作：把他过去所有推文翻了一遍，做了一份创作诊断：哪些表达是到位的、哪些点明明有深度却没讲透、他的关注者与真实客户画像怎样错位、下一轮融资该讲什么故事。

我们聊了不到一小时，他当场付钱。

事后看，这笔订单能成是三个原因：他认识我多年，信任成本很低；我不是去推销，而是直接把问题摆给他看——创业者最认“你懂我的业务”这句话。

但我很清楚，朋友的信任能带来第一单，只有结果能带来第十单。所以从第一单开始，我就把“可复制性”排在“成交”前面。

四、交付包是怎么一步步成形的

说实话，这份交付范围不是一开始就设计好的，而是做了几单之后慢慢长出来的。

最早定价时，我只想了两件事：帮他梳理战略，帮他写几篇深度文章。真正开始交付才发现，客户对结果确定性的要求更高。

第一，他需要有人帮他想清楚“该讲什么”。多数创业者不是不会写，而是不知道写什么。我会先帮他梳理现在的商业目标——是要融资、拿下企业客户，还是做消费者社群？目标不同，受众不同，表达方式完全不一样。这一步不做扎实，后面写再多都是浪费。

第二，他需要一套低成本产出文章的工作流。我给的是装在他电脑上的Claude Code系统，包含个人定位、经历素材、文风档案、话题引擎、深化工具、题目生成器。交付后，他或他的助理就能自己跑。

第三，他要看到明确结果。所以整个项目期，我会陪他一起产出3到5篇深度长文或推特长篇，并负责把内容推给他想触达的人——投资人、KOL、潜在客户。结果型交付，是客户最在意的地方。

五、整个过程，我到底交付了什么

先澄清一下：客户付钱后收到的，是一整套为他定制的创作者工作台，里面包括战略诊断、行业知识库、分发网络、个人资产沉淀，以及我全程陪跑。

落地过程大致分三步。但要说明：这是我这类客户的样板，不是标准SOP；不同阶段、不同行业的创业者，节奏肯定不一样。

第一步，搞清楚他到底是谁。几次深度访谈，聊他真正想做成什么、哪些经历把他带到今天、他想在行业里成为什么角色。做完这一步，创业者通常会突然发现自己身上有太多可以讲的东西。

第二步，把工作台真正跑起来。把定制好的工具装到他本地，手把手带他产出第一批代表作品。我负责结构、深度、打磨、题目方向；他提供观点和真实素材。这个阶段最大的变化是“写作没那么重了”——以前写一篇深度长文要拖两天，现在几十分钟就能出初稿。

第三步，让作品被对的人看见。按名单推给投资人、KOL、目标客户。每篇发完，一起做一次总结，把“每次都要改的点”沉淀回工作流里。越往后，他自己跑这套流程的效率越高。

六、真实存在过的结果

最近帮客户在海外拿到了一些还不错的数字。但说实话，单篇热门从来不是目标，数据只是策略对了之后的副产品。

举个例子：4月9日上午11点09分，一条推文有20.65万次浏览，37条评论，47次转发，135个赞，138个收藏。同一天11点24分，另一条推文有9.94万次浏览，8条评论，73次转发，313个赞，510个收藏。

七、十几万的价格为何能站住

答案很实在：你花这笔钱买的不是一套工具加几篇文章，而是我过去几年在真实商业增长里攒下来的判断力。这个能力没法单独标价，但它直接决定三件事：

1. 你这家公司到底该做什么。
2. 这个阶段该做什么、不该做什么。
3. 用什么节奏做，投产比最高。

这三件事如果没人帮你想清楚，你会一直在“这篇发不发”“方向对不对”“现在做是不是太早”上来回内耗，消耗的时间和机会成本，比十几万大得多。

工具和流程很容易被复制，真正稀缺的是带客户拿到结果的确定性。能理解这一点的创业者，不会在价格上纠结；纠结价格的，大概率也不是我想合作的人。

八、Compound：我开源出来的部分

前面说到的交付核心，是一整套创作者工作台：从战略诊断、个人定位、话题、深化、写作、分发、总结，到个人资产沉淀，全链路覆盖。每个客户的版本都会重做一遍，按行业、受众、商业目标、语言习惯重新搭。

今天分享的Compound，是这套工作台里“长文创作”层的通用版。我觉得它对所有想认真写作的人都有用。

设计逻辑是：先弄懂你是谁，再动笔。

市面上多数AI写作工具是打开就让你写——给个模板，填空，出稿。Compound正好反过来：

- 不是“帮你写一篇文章”，而是先让系统知道你是谁、你怎么思考、你怎么说话。
- 不是“给你一个热门模板”，而是让系统学会判断什么对你来说算热门。
- 不是“一次性出稿”，而是每次使用都在训练系统更懂你。

Compound这个名字本身就是复利。每发布一篇内容，系统会对你的了解多一层。

为什么越用越聪明？因为三件事在同时发生：

- Personal OS是底座：先建立个人定位、经历素材库和文风档案，后续所有创作都基于这个底座，而不是每次都从零开始。
- 知识库是活的：每次发布后的总结数据、收集的素材、AI记者挖出来的洞察，都在持续进入知识库。用得越久，匹配越准。
- Skills会进化：同一类修改出现三次以上，就会自动更新进对应Skill，你不需要重复交代同样的事。

整个工作台分三层：

- Personal OS：回答你是谁、你经历过什么、你怎么说话。下面有个人定位、经历素材库（用“英雄之旅”12步挖掘故事）、文风提取（提供几篇文章，AI自动分析）。只需初始化一次，后面随时补充。
- 9个Skills：覆盖从话题到总结的完整创作链路。每个Skill独立，可单独调用，也可组合使用。工作台会在每个阶段推荐下一步，你只需选A/B/C。
- Knowledge Base：你的素材仓库。Claude Code直接读取本地知识库，创作时自动调用相关素材，不需要手动复制粘贴。首次使用时自动创建。

一篇文章是怎么写出来的？这是一张地图，不是固定路线，可以从任意节点进入，也可以跳过某些步骤。

首次使用：建立Personal OS（一次性，5-30分钟）

- 个人定位（5分钟）：一次性告诉系统你是谁、你的产品、你的目标读者。Claude会自动整理成结构化档案。
- 经历素材库（15-30分钟，可跳过）：Claude用“英雄之旅”12个问题采访你，把人生经历变成可反复调用的素材。完成后会自动提炼“人生三部曲”和素材标签。
- 文风提取（5分钟）：提供3-5篇你觉得“最像自己”的文章，Claude会自动分析你的思维和语言习惯。

全部跳过也能开始，工作台会用通用风格，随时可以回来补建。

Phase 0：自由探索（可选热身）
把脑子里冒出来的想法全部倒出来，先不考虑结构，和Claude Code自由聊天。聊完再进入正式流程。

Phase 1：话题选择
topic-engine做两件事：
- 没想法时：基于你的定位和近期热点，从7个来源推荐3-5个话题方向，并给热门潜力评级。
- 有想法时：用独特性、冲突感、实用性、时效性、传播性五个维度打分，总分50。S级直接写，C级建议换方向。

触发词：“帮我找话题”“这个想法行不行”“给话题打分”。

Phase 2：选结构
调用content-structure，根据长文/短文推荐高效结构（短文S1-S4，长文A-D），并说明推荐理由。
触发词：“帮我选结构”“写长还是写短”“这个用什么结构写”。

Phase 3：深化（可选）
两个独立工具：
- 工具A：思想升华（thought-elevation），适合有观点但还停留在描述现象的情况。三种深化方式：跨学科升华，连接到历史、科学、哲学中的普遍原则；理论透镜，用尼采、福柯、海德格尔、荣格等视角重新解读；奥派辩论，经济/商业话题，用哈耶克和米塞斯的视角对话。
  触发词：“升华一下”“更深一层”“让文章更有深度”。
- 工具B：素材挖掘（AI记者），适合有判断但缺支撑材料的情况。先诊断想法完整度，再用三轮结构化提问，把你没讲出来的东西挖出来；之后输出SCQA框架；初稿完成后提供质量雷达图。
  触发词：“采访我”“深化话题”“帮我把想法说清楚”。

Phase 4：出初稿
基于话题、结构和文风生成第一版。初稿不是终点，而是给你一副骨架，你在上面修改，比从零开始快很多。

Phase 5：人工打磨
由你主导，多轮修改。直接说“第三条改成XXX”“开头不够抓人”“压缩到300字”。

Phase 6：题目、钩子与封面文案
- 钩子优化：检查当前开头，生成10-15个替代方案。
- 封面文案：负责打情绪，拿自然流量。
- 搜索型题目：负责放关键词，拿搜索流量。

核心理念：封面文案和搜索型题目必须写得不一样。

发布后：数据回看 → 反哺工作流
记录核心数据，回答：哪个结构最有效？什么开头能留住人？哪类话题最共鸣？把优质段落沉淀进知识库。

体系如何自我进化：
- Skills迭代：同一类改动出现三次以上，自动升级进Skill。
- 知识库扩充：每2-4周，把优质内容加入knowledge-base。
