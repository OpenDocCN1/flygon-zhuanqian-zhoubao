### 每天吃啥小程序

看起来不少朋友对小程序都感兴趣，那就把教程补上。

#### 下载微信官方 IDE

先启动 Cursor，输入下面这段请求：

我想做一个微信上的小程序，但我完全不懂编程，Windows 机器上只有 Cursor 这个代码工具，其他环境都没配。请把流程讲得细一点，我完成一步就回来同步一次，你判断后续该怎么走。

[PRE13]

流程我当然也能水一篇，但交给 Cursor 亲手带你，效果会更好。

Windows 版的下载入口不太起眼，我单独标出来，其余按它的提示走就行。

#### 把需求聊透

切回 Cursor，用它打开刚才的项目。

用相同的话术：请把当前项目当作模板，于项目最外层生成 design.md，将文件结构、关键实现点都写进去，方便之后和你对需求时翻看。

[PRE20]

再开一个新会话。

输入：我要做一款“每天吃啥”小程序，用户能在里面随机抽一样吃的。它一共两个页面：主页面负责随机抽取，个人中心用来维护用户自己想吃的东西。我们先聊主页面怎么设计，把结论记到 design.md 里。现在先别写代码，请指出有哪些点需要斟酌，这样我才清楚该和你聊什么。
