# 小红书引流再也不愁，这套万能公式值得所有人收藏

说到获客引流，不管你是做副业搞钱，还是公司创业拓客，谁都不敢说“我客户已经够多了”。公域流量的大池子，人人都想从里面舀一瓢。

关于抖音和小红书怎么导流、怎么设计引路路径，这套方法我在前年和去年就陆陆续续在线下分享过。当时那个版本，算是1.0吧，靠着这套打法，帮不少朋友拿到了结果。后来连我的分享PPT都被人搬到了海外去卖，可见确实有料。
