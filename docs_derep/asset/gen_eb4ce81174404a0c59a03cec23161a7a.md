# 为什么有人越赚越轻松，有人越忙越穷？看懂这三类人的思维分水岭

作者：亦仁 2024-04-24

最近在聊一个很有意思的话题：普通人、创业者、投资人到底差在哪。

答案不是勤奋程度，而是底层思维的用法。

越是到最后能赚到大钱的人，几个特质会越来越明显：

**第一，对不确定性的态度完全不同。**
普通人想把所有风险都规避掉，大钱的人则不一样。他们能扛住模糊和未知，甚至会主动去制造不确定性，把不确定变成机会。

**第二，开放心态和学习姿态。**
他们对外界的接纳度极高，喜欢快速学习也愿意分享。与其花时间去自证“我是对的”，不如去认可一个更好的想法。承认别人，比证明自己重要得多。

**第三，对时间价值有清醒的定价。**
他们对自己的时间极其珍惜。能用钱买到的时间绝不自己硬扛，不会在纠结省钱上浪费精力。很多事情哪怕自己会做，也会直接交给更专业的人来处理。

**第四，用拼图和整合来做事。**
他们很少执着于自己亲手从0到1。他们更擅长把别人从0到1的成果拼起来，把分散的资源重新组合，创造出新的增量价值。同时他们也乐于扶持更多人去做从0到1的事。

**第五，合作共赢是默认选项。**
他们更倾向于组局，而不是单打独斗。分钱毫不吝啬，不担心被占点便宜，也敢于吃点亏。反观很多刚起步的人，最怕的就是合作，总想着自己和团队什么都包揽下来，最后什么都做不透，规模也越做越小。

简单说，普通人拼的是自己，创业者拼的是执行，真正的大钱思维拼的是整合、信任和时间杠杆。
