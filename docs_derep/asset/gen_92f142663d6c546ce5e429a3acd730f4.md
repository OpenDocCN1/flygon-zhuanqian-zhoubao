# 二、AI写真怎么做

实操前先大概了解流程，建立基本认知

第一步是根据人物的照片炼一个专属模型，这个模型叫Lora

[PRE20]

第二步是找一张喜欢的底图，不管是网上找的还是自己用AI生成的都可以

[PRE21]

第三步是用刚才炼好的模型把人脸替换上去

出来的效果在光影和融合度上都很完美

[PRE22]

网上流传的AI写真做法很多，有人教你用

换脸插件：roop、rope等插件直接换脸

抠图重绘：把人物抠出来保留，让AI重新生成背景

目前来看效果都一般，前者换出来的脸不像，后者色调不统一，需要很强的PS调色能力

[PRE23]

[PRE24]

而用炼人脸模型再换脸，就能生成更多场景的照片，而且各种角度都能很好适配

[PRE25]

[PRE26]

# 三、炼Lora模型

炼Lora可以拆成三步

准备素材、打标签、训练模型

## 1.准备素材

需要准备20~30张照片

只需要上半身或大头特写即可，关键是五官要清晰

[PRE27]

## 2.打标签

就是用文字描述图片内容

打标签用的是秋叶整合包

双击打开文件夹里的“A启动脚本”

[PRE28]

然后用里面的“标签器”自动打标签

[PRE29]

处理完后，图片文件夹里每张照片旁边都会多一个文本文件，里面就是标签

[PRE30]

标签处理完就可以开始训练模型了

## 3.炼模型

在文件夹里找到“train”文件夹，新建一个文件夹

把要训练的照片和对应的标签全部复制进去

[PRE31]

然后打开训练界面

用“新手”模式即可

除了图片里红色框标注的参数需要自己改，其他参数保持默认

[PRE32]

最后点页面右下角开始训练

[PRE33]

看后台黑色窗口，大概20分钟左右，出现“训练完成”模型就好了

[PRE34]

在“output”文件夹里能看到炼好的10个模型，需要挑一个出来

[PRE35]

可以直接在SD里用这个模型出图，看看哪个效果最好，选一个就行

[PRE36]

# 四、出图+换脸

模型炼好后就可以开始出图了

图的来源有三个

1.网上图片
2.SD出图
3.MJ出图

操作方式不同，分别来看

## 1.网上图片+换脸

第一种是你在网上看到喜欢的写真照，直接保存下来换上自己的脸

注意版权问题

[PRE37]

[PRE38]

制作方法：

打开SD图生图里的局部重绘，把图片上传

把人物脸部涂白

[PRE39]

再用adetailer插件，在里面加入我们炼好的专属Lora

[PRE40]

最后点生成即可

[PRE41]

[PRE42]

如果你经常线下拍写真，就可以用这种方法，先找到喜欢的风格，把自己的脸换上去试试合适不合适，再去线下拍，这样能很大程度减少踩雷

[PRE43]

[PRE44]

## 2.SD文生图出图+换脸

如果你不想和网图完全一样，但又想要同款风格，就用这个方法

[PRE45]

首先是关键词，直接把照片上传到“标签器”

检查一下反推出来的关键词，没问题就复制到关键词框

[PRE46]

然后打开SD的“文生图”，把参考照片上传到controlnet，控制类型选“reference”

[PRE47]

再打开Adetailer，在关键词部分加上我们的人物Lora

[PRE48]

最后点生成

这样一张SD生成的AI写真就完成了

[PRE49]

如果还想做更特别好玩的图片，就加上风格Lora

像和龙合影、一些奇特场景，都是加了其他风格Lora的效果

[PRE50]

[PRE51]

[PRE52]

再用SD局部重绘换脸
