# 别再拿国内那套玩法硬套 YouTube 了

做 YouTube 的人，十有八九会不自觉地把国内平台的经验搬过来。用我自己的话说，这就是典型的刻舟求剑。真想把账号做起来，先把 YouTube 到底想要什么搞清楚，少一点自我感觉，才少走弯路。

YouTube 的底层目标就两条：

1、猜准观众想看什么
2、把观众的长期停留和满意度拉到最高

整 个平台就是围绕这两个目标在运转。

猜准观众想看什么，就是当你打开 YouTube 时，系统会根据你的历史行为喂给你内容，目的只有一个，让你尽可能长时间不离开。

把满意度拉满再离开，则是靠一套推荐机制完成， 后面会细说。

怎么做到的？

1、疯狂收集和使用数据
2、用一组算法去匹配

实现路径其实很简洁：先知己知彼，再撮合。既要吃透用户在干嘛，也要吃透视频本身长什么样，然后把两者凑在一起。市面上很多所谓的养号，本质上只养用户端，对你自己上传的视频制作端基本没影响，这个误区很多人一直没跳出来。

数据有了以后，YouTube 就靠一组算法群，而不是单一算法，来完成上述目标。

YouTube 每天从用户行为里收集 800 亿个数据点

1、用户看了哪些视频
2、哪些视频被跳过了
3、每个视频看了多久
4、是否点赞或点踩
5、是否点“不感兴趣”
6、看完后的反馈问卷
7、是否重播、是否续播、是否收入稍后观看

【YouTube 每天从用户行为中收集800 亿个数据点】 这个数字是过去公开过的，到 2025 年只会更多，具体数就不纠结了。

数据量大到夸张。它不只记你一个人的操作，还在吸纳全站所有人的行为信号。

比如你看过什么，跳过什么，看了多长时间，有没有给差评，甚至你有没有明确告诉系统不要再推某类内容或某频道。

你会发现看完视频后经常会蹦出一个小问卷，问你对刚才的视频感受如何，这就是看后调查。系统还会留意你会不会重看，会不会看一半去上班，晚上回来继续看。

“稍后观看”也很关键。看到想看但没时间，就先收藏起来。YouTube 会追踪你到底有没有真的回去看，还是存了就忘了。所有这些行为，都在被持续记录和分析。

我自己的感受是，长时间刷某个垂类内容，首页就会被同类内容塞满。养号能让你刷到你想看的内容，却并不会让你的视频因此获得播放，这两者没有直接因果关系。

收集视频元数据

1、封面/缩略图：cloud vision 图像识别/安全评级，可单独使用
2、视频本身：扫描每一帧，抓取关键信息
3、字幕：自动/手动，可能不是人声，能辅助理解内容
4、语音：不一定和字幕同步
5、标题/说明：说明很多人根本没重视

上面说的只是用户行为的一部分，视频端的数据采集其实更细。

视频有个概念叫元数据，即描述数据的数据。最典型的元数据就是封面、标题、说明、字幕等，这些信息决定了系统如何理解你的视频。

先说封面或缩略图。

这里用到了 Cloud Vision 这项技术，大致可理解为云端视觉识别。它能扫描图片，识别出低俗、仇恨、枪支、烟酒等敏感元素，并给出安全评分。

Cloud Vision 可以脱离 YouTube 单独使用。比如你对自己的封面不放心，怕被黄标或限广告，可以先单独上传到 Cloud Vision 做安全评估。YouTube 后台也正是用这套打分机制来判断封面风险。

具体来看，Cloud Vision 会把图片里的元素拆开识别。

这项技术能独立运行。如果你担心视频上传后被限流，原因可能出在标题、封面或画面。就可以先把疑似有问题的画面截图，用 Cloud Vision 测一下。因为 YouTube 后台判断逻辑跟这个基本一致。

YouTube 还能扫描视频每一帧。导出时我们常看到 24、25、30、60 帧，平台技术上具备逐帧扫描能力。只是量太大，不会每个视频都全扫。

这里得说一句食色，性也。播放量很低时，平台基本不会细抠。一旦视频开始起量、要爆了，审查就会变严，类似国内很多平台的策略：小量不管，超过阈值就人工+智能复核，比如 5 万、10 万播放这个阈值只有平台知道。毕竟一个视频一夜几百万播放却出问题，负责人是要担责的。

所以某些视频在敏感内容上被黄标，本质就是系统能读到画面。只要画面违反社区规范，就会被识别并处理。

建议提前翻官方文档，别等频道被封才后悔：

YouTube 的《社区准则》
YouTube 政策
举报和违规处置
YouTube 社区准则警示基础知识

这世上没有后悔药吃的，不要等你频道被封了才想起要看官方文档，要提前就留意关注平台的一个政策，避免违规，上传一些不该上传的视频。

平台会把这些关键信息抽出来，和封面、字幕一起综合判断。

字幕可以是手动上，也可以是自动生成的。自动字幕目前支持英语、法语、韩语、西班牙语等，中文还不支持。

有字幕其实是加分项。官方能读到你视频里的字幕，更准确地理解内容，从而把视频推给更匹配的观众。

比如画面里有一把枪，字幕里明确写了是玩具枪，系统就结合字幕判定为假枪，不会因此误判。

语音和字幕也不总是一致。字幕可人工加，但语音识别靠的是听写技术。即便字幕干净，你口头爆粗，系统也能通过语音识别抓出来，给视频打黄标。

再说标题和说明。封面和标题的重要性不用赘述，标题里别太惊悚，观众先看封面，再靠标题关键词确认内容。

很多人忽视说明，其实说明很重要。有字幕文件的话，可以让 ChatGPT 帮你写一份简介，塞满关键词和长尾词，虽然不一定完美，但能显著提升搜索匹配度。

举个 Cloud Vision 的例子：上传一张照片，它能识别人脸、物体并自动打标签。封面上有文字，也能通过 OCR 识别出来。一张图的信息密度远比你想象的高。

你可以看到，系统识别出霍金以及他身边三位合影者，还判断出图片可能与黑洞相关，准确率 80%。人物穿着衬衫，背景有电脑和黑板上的方程式，黑板上的公式都被框出来了。这就是云视觉的威力，不仅能认人，还能认公式。

我们做封面常加文字，只要不是手写体，基本都能被准确识别。手写体只要不潦草也能认。安全性方面，如果封面超标，系统会亮红灯提示。

最后，如果封面很吸睛但内容对不上，系统会判定为封面党。所有信息都会被整合做综合判断。

人工智能使用多个系统/算法

1、浏览功能：首页 个性化推荐 新旧内容 和订阅页
2、推荐视频：“接下来播放”，同类或相关
3、趋势视频：区域/社群的热点
4、通知：小铃铛
5、搜索：依赖元数据、观众反馈和新鲜度

用户信息和视频信息如何匹配？YouTube 的推荐是一个复杂的人工智能体系，由多个子系统组成。

1、浏览功能：首页 个性化推荐 新旧内容 和订阅页

浏览算法主要管首页和订阅页。YouTube 未来更倾向弱化订阅页，因为大家很少专门去订阅页看更新。

也就是说，你没订阅的博主，只要系统判定你喜欢，照样会把他的新视频推到你的首页。订阅页唯一的价值是铁粉第一时间知道更新。

首页的推荐是完全个性化的，会混搭新旧内容。旧内容是你订阅或常看的频道，新内容是你从未表达过兴趣但可能相关的。

比如你昨天连刷三个频道，今天首页顶部就可能出现该频道的新视频。系统不断试探你的喜好，保持新鲜感的同时避免信息茧房。

看视频时右侧会出现相关视频，这其实就是找对标账号最直接的方法：你正在看的视频右侧，就是你的对标。

2、推荐视频：“接下来播放”，同类或相关

这是核心中的核心。首页视频很多，你挑一个看完，如果下一个推荐不合适，你就走了。

推荐分两类：

同类推荐。比如你看了一个 NB 频道的视频，系统会接着推 NB 频道的第二个、第三个视频，让你深挖频道。或者你看哪吒 2，系统会推同品类里的大号内容。

相关推荐。看累了就换个相关的，比如国内流行歌曲后推国外流行歌曲，国内票房高的电影后推国外票房高的电影。系统通过层层递进帮你破圈。

之前我一段时间沉迷美剧，系统就不断推给我越狱、毒枭、权力的游戏这类内容。同类是“你可能还没看够”，相关是“换个口味继续看”。目的都是让你停留。

3、趋势视频：区域/社群当下关心的热点

趋势视频出现在首页，展示正在形成的热点，不一定是已经爆量的。

推荐会根据你的 IP 区域来定。YouTube 不同地区站点推荐不同，你的频道定位在哪里，节点就最好选对应地区。

趋势不一定是最大流量，而是该区域正在被关注的话题。当某个事件在 X 或 Google 上被大量搜索，系统会判定为区域热点，提前放进趋势里。这就是趋势算法的工作。

4、通知：打开小铃铛

只有打开小铃铛的用户才会收到通知。通知渠道包括小铃铛和小邮件。

理论上粉丝开铃铛就会被通知，但实际会做频率优化。如果你一天发 15 条，系统最多通知 2-3 条，或折叠处理，避免过度打扰导致取关。

5、搜索：依赖元数据，观众反馈和新鲜度

搜索主要靠元数据。频道名、视频标题包含关键词，就更容易被搜到。SEO 小技巧：关键词尽量前置，标题可用 | 分隔多个标题。

说明也能提供关键词。类似公众号爆文，封面+标题带来的流量逻辑在这里同样适用，标题党和封面党套路 YouTube 很熟悉，一直在对抗。

光靠元数据不够，还要看观众反馈。点赞只是基础，评论权重更高，因为要打字、停留更久。转发也算信号。

目前 YouTube 推荐体系里，完播率仍是最大指标。观众喜欢才转发，愿意评论才代表深度认可。

搞懂这套机制，你就不会再盲目养号，也不会再用国内那套刻舟求剑的思路硬套了。
