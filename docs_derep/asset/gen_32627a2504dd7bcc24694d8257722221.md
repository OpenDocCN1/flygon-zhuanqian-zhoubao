# 一、我的经历

大家好，我是王小小，在生财混了几年，项目做过不少。21年那会儿跟着淘宝虚拟的帖子，把资料打印出来，一口气开了二十多家虚拟店。

[PRE0]

22年刷到影刀这个工具，后来跟着官方课程和B站几个UP的视频入门，慢慢把影刀玩明白了，也用它搭了不少自动化流程。

23年跟着公号爆文航海一步步实操，也做出了几个爆款，那一年基本就是死磕公众号。

B站好物是我6月在超级标里看到的，后面靠星球里的资料开始学习，7月初就上手试了。中间心态很不稳，做做停停，想放弃又不甘心。后来我干脆入了深海圈，给自己立了个flag：先把门票钱赚回来。结果没想到，第一单佣金就把门票给挣回来了。

这一路我错在哪、心态怎么变的？

# 1.从公号爆文到B站带货，心态的落差

我原本是公号爆文做起来的，玩法熟门熟路。一到B站就各种不顺，尤其心态被打得七零八落。

1. 载体从图文变视频，对着镜头拍和剪辑特别抗拒，自己在画面里显得很僵。
2. 一条视频从拍摄到剪辑下来要6个小时，投入感很重。
3. 选的品客单价低，佣金只有1%-3%，根本覆盖不了时间成本，这点最难受。
4. 患了播放量强迫症，这是公号养成的老毛病。

播放不高、没成交或者佣金少，就更想停更。直到有一单将近3000的成交，佣金大概50块，相当于公号1-2万阅读的收益。那一刻特别兴奋，才意识到B站用户是真的会为高客单买单。想明白后，心态立刻稳住，开始认真选品，行动也顺了，再也不拖延。

那之后一周就出了两千多佣金的一单，更坚定了要把B站做下去的决心。

对镜头恐惧这事，我给自己做心理建设：与其穷得不敢露脸，不如先把钱挣了。被认出来又怎样？怕丢人不如怕没钱。挣到钱就自在了。

# 2.为什么B站好物值得长期做

21年学影刀的时候我就认识B站了。对比其他短视频平台，B站娱乐内容少，知识和干货氛围更浓，跟知乎有点像。21年我也试过写知乎，结果入场晚了，最后转做淘宝虚拟。

爆文项目大家都懂，号爆了收益高，但生命周期短，基本就是注销-注册-再注销的循环，久了人会疲。

正好看到B站好物，感觉机会很大。现在竞争还没起来，分佣是全给创作者。我自己的视频播放量不算高，也能出单。现在就是发出来就有机会变现。

上个月京粉数据，GMV4万3，佣金2100。订单量其实不多，能把深海圈门票挣回来主要靠一单高佣，后面会讲我是怎么选到这个品的。

# 二、选品才是生死线

选品是电商的命根子。

很多人觉得B站就是数码，女生做不了。其实不是。

我找了个笨办法但很管用：先用京东排行榜把类目抓下来，拿到一二三级类目词，用数据透视表看类目人数，找到产品词，再放到B站查竞争度，最后锁定适合自己的赛道。

这么一筛，发现女生能做的品不少：零食测评、个护清洁、宠物用品、母婴用品、厨房小电、生活电器、床品、运动用品、家居饰品等等。

B站也有不少高付费人群，选品时就要兼顾客单价和佣金比例，前面我踩过坑，后面细说。

具体操作流程：

# 1.采集京东排行榜

京东排行榜是手机端功能，手动找太慢。我装了雷电模拟器，用影刀插件把手机端搬到电脑上采集。采多了京东会滑块验证，后面就用真机采集。得到一批数据后发现一个bug：三级类目词不固定，每次采集都会有新词。

也可以直接用影刀抓京东分类，内容大差不差，只是少了一级定位的判断。

[PRE4]

[PRE5]

# 2.清洗数据，确定一二三级类目

把类目人数里的“万”换成0000，“正在逛”也替换掉，建立透视表。

透视表分三块：第一块放一级类目降序；第二块筛选一级类目，比如家居家装；第三块再筛选二级类目，比如厨具。三级类目就是清洗后的结果。

京东排行榜有32个一级类目，我挑了7个试水。表上一看数码居多，手机电脑为主，我不感兴趣。剩下家居家装，就往下钻到厨具，慢慢筛选到具体品。这一轮已经完成三分之一的选品，我筛出平底锅。

[PRE6]

# 3.B站查竞争度

把平底锅丢到B站一搜，发现竞争不强。23年、24年的视频多，25年5、8、9月才各一两条，内容也不饱满。说明有流量空间，值得做。

同理高压锅、砂锅、蒸锅、汤锅也能放一起查，拓展出4个品类。

我用同样方法筛家电里的空调，23-24年视频很少，4-6月却很多，说明同行在卷，我就不做了。

# 4.查佣金比例，定最终带货品

确定能做后，要去京东联盟和淘宝联盟找对应的商品链接。B站后台显示的佣金比例可能有出入，必须以联盟为准。

https://pub.alimama.com/portal/v2/pages/promo/goods/index.htm 淘宝联盟
https://union.jd.com/proManager/index?pageNo=1 京东联盟

京东选品要注意自营还是非自营。非自营出单分成60-90%，自营是100%。实际佣金=计佣金额*佣金比例*分成比例。

平底锅上千款，手筛太慢。我让影刀打分，标准是佣金金额+佣金比例+好评数，总分降序选。

深海圈里对高客单的划分参考：
1. 100以下，10%-30%
2. 500以下，5%-8%
3. 1000以下，3%-5%
4. 2000以下，1-3%

别盲目追高单价高佣，要综合看。

那笔2000多佣金的单子，就是按这个方法筛出来的。

清洗数据是最难的部分，要联动三个透视表，一层层钻取。三级类目里很多小词套词，多练几次就有手感。第一单50佣金后，我选品时间从3-4小时压缩到1-2小时。

# 5.链接备份防失联

品选好后链接别删。商家销量起来会降佣金或断货，要有备选。我习惯备份成 A000X-商品名称 的格式。

# 三、蓝链细节操作

选品完就要挂链，B站挂链流程绕，越是麻烦的地方越要抠细节。

# 第1个细节：视频投稿

投稿路径：上传视频-标题-简介-商业推广。没勾商业推广就违规。我的习惯是先去商品计划里建好计划组，再投稿。

谷歌浏览器编辑蓝链会卡BUG，只能关重开。用计划组相当于备了一份链接。

[PRE13]

# 第2个细节：商品排序

不用计划组一次性批量加20个，评论区顺序会反。推荐用计划组添加，保持顺序一致。

# 第3个细节：短标题

长标题改成短标题，用户看得懂。格式一般是品名简称+价格。改完要点空白保存，右上角关闭自动保存。同款只改一次，后面复用直接沿用。

[PRE15]

# 第4个细节：蓝链分区

蓝链挨一起用户看不清。点开商品中间回车隔开，并按价格或类型分区，减少挑选成本。

[PRE16]

[PRE17]

# 第5个细节：二次加链

评论区一次最多20个。想再加就去置顶评论里回复加，不能在视频下直接留言，不然会被挤下去。

# 第6个细节：手机发链

有人评论要链接，电脑回复会被系统删，只能用手机发。评论区的用户购买意向最高，直接甩链接过去转化快。

蓝链维护好了，佣金自然涨。评论区有人引流踩品，直接拉黑删评论就行。

# 四、踩过的坑

# 1.忽视金额和佣金比例

选鼠标垫时没看佣金比例，选到0.1%的坑品。用户买了5单，京东只记1单量，佣金也几乎为零。白忙活一场。

[PRE20]

# 2.京粉活动没盯上

B站带货还能拿京粉活动补贴。超级补贴奖励只能在京粉APP操作：首页-奖励活动。活动奖励在我要推广-活动奖励里，可把所有活动都申请上。

我踩坑是同一个类目，第二天出单没了补贴。后来发现是活动过期了。现在每天看一次，有活动就先报名。

[PRE21]

# 3.MCN机构申请折腾

没进深海圈前听说MCN号带货不用实名，就去申请了https://mcn.bilibili.com/
第一次营业执照快满半年，被拒。第二次还是过不了，问客服才知道需要法人与账号的说明材料。第三次才过，结果带货发现还是要千粉+实名认证，不管机构号还是个人号。

# 五、小结

项目切换总会消耗心态，B站现在仍是红利期，有缓冲空间给我们适应。

想跟我一样卡在瓶颈的伙伴，别放弃。认真选品、踏实做内容，两三天就可能开单。

一个人快，一群人远。感谢深海圈的伙伴们！
