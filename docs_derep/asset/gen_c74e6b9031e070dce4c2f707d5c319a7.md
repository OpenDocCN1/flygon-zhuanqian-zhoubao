# 官方 DeepSeek 用起来更顺手，我找到一个可以稳定白嫖...不对，是超划算无限聊的小路子

> 原文：[`www.yuque.com/for_lazy/zhoubao/rltnipv2xxvbi6im`](https://www.yuque.com/for_lazy/zhoubao/rltnipv2xxvbi6im)

## 很多人反馈官方版的 DeepSeek 质量更靠谱，这里把我实测能持续用的低成本玩法整理出来了

作者： 平子

日期：2025-02-26

1、首先进入 DeepSeek 官方的开放平台，地址是 [`platform.deepseek.com/`](https://platform.deepseek.com/)

[PRE0]

2、进去后先注册一个可用的账号

[PRE1]

3、进入充值中心，先小额试水，比如充 10 元就够了，注意需要完成实名

[PRE2]

4、生成一个专属 API Key，后续要用到它

[PRE3]

5、再去装一个第三方客户端，名字叫 CherryAI，官网是 [`cherry-ai.com/`](https://cherry-ai.com/)

[PRE4]

6、在 CherryAI 界面左下角能找到设置入口，进入配置页

[PRE5]

7、进入模型服务的配置区，这里基本集齐了市面上主流的模型接入

[PRE6]

8、在列表里定位到 深度求索

[PRE7]

9、将刚才在开放平台创建的 API Key 填入对应的 API 密钥栏位

[PRE8]

10、把该模型的开关打开

[PRE9]

11、返回主界面，点击左上角切换到聊天窗口

[PRE10]

12、在聊天框上方找到模型选择区，把模型切到 deepseek reasoner，也就是大家说的推理版 R1

[PRE11]

13、就可以开始正常对话了

[PRE12]
