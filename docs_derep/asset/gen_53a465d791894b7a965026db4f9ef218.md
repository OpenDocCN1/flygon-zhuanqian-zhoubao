# 用 ComfyUI 一键跑出可商用的原创无缝纹理

作者：Lemon  
发布：2025-03-27

最近在参与 AI 赋能电商的航海训练营，直播前大家在工作流问题接龙里热议批量产图技巧。来来教练随手丢出一个需求：怎么快速做一批无缝图案。我手上正好有之前调试好的 ComfyUI 方案，就把思路和成品拿出来跟大家同步一下。

做无缝贴图的关键就一句话：怎么拼都看不出断点。实现逻辑是把一张基础图切成四份并重新分散排列，再借助采样模型对边缘区域做局部修复和融合，让四周的纹理在拼接时自然衔接。

具体搭建步骤和参数设置我整理到了飞书文档里，顺手把可直接运行的工作流文件也打包放上来了，有需要的朋友可以直接下载试用。
