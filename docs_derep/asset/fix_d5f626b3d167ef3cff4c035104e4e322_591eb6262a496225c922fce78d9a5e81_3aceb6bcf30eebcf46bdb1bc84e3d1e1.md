# 第三关：让静图开口

这里用到D-ID官网 https://studio.d-id.com/ 。该平台按积分计费，每个账号初始额度有限，所以需要准备2925无限邮箱来轮换。

2925入口 https://2925.com/login/

[PRE20]

登录D-ID后默认是游客状态，需点左下角注册。

[PRE21]

注册时用2925邮箱，注意在邮箱名后加任意数字作后缀，这样同一体系下可无限创建新号。额度用完就换一组数字重来。

[PRE22]

注册成功后点左上角新建项目，上传人像图，再在音频区指定文件。

[PRE23]

随后把刚生成的旁白上传。

[PRE24]

点击生成，系统会提示本次消耗2积分。完成后直接下载成片。

要点是选一张正面清晰五官完整的头像，质量稳定口型才自然。

# 第四关：最终包装

到这一步很简单，用剪映上字幕，调字体大小与颜色，加一段符合情绪的配乐即可。这里不细讲。

整体流程就这些，最耗精力的是第一步的稿件打磨和第二步的声线调试。只要沉下心把这两个环节跑通，后续批量产出会非常顺滑。

PS：熟练后外星人系列几乎是流水线作业，固定人设+固定声线，每期换文案配字幕即可。有兴趣的可以交流。
