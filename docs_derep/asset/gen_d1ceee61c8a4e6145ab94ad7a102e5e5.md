# 如何使用？

## 方案一：直接使用已经上线的RPA应用

目前平台已经提供现成工作流，限时可以免费体验。

⏬RPA应用下载链接：小红书-RPA AI 批量图文排版-[Lisa] | 八爪鱼RPA官网（限时免费使用）

在运行之前，需要准备以下内容：

### 1. Excel文案文件

例如：

`E:\卡片文本.xlsx`

Excel中可以提前整理好需要生成的卡片内容。

⚠️当前工作流适用于两行文字排版。如果需要处理多行文字，需要另外定制工作流。

[PRE42]

### 2. 字体文件

例如：

`E:\shoushuti.ttf`

字体可以根据账号风格自行更换。

[PRE43]

### 3. 背景图片

例如：

`E:\template.jpg`

图片内容与文件名称可以自行准备。

### 4. 输出目录

例如：

`E:\output`

保存图片的文件夹需要提前创建。

准备好以上文件和路径后，根据工作流弹窗提示依次填写即可。

## 第一步：建立输入变量

由于这套流程运行在用户自己的电脑上，因此需要让用户自行填写四项信息：

1. Excel卡片内容文件路径，例如：  
   `E:\卡片文本.xlsx`

2. 字体文件路径，例如：  
   `E:\shoushuti.ttf`

3. 背景图片文件路径，例如：  
   `E:\template.jpg`

4. 图片输出文件夹路径，例如：  
   `E:\output`

在左侧指令栏中找到：

**其他 → 文本输入对话框**

[PRE47]

依次创建4个文本输入框，对应填写上述四个变量。

[PRE48]

[PRE49]

## 第二步：配置Python运行环境

这套流程会使用到Pillow、PIL等图像处理模块。

在八爪鱼RPA中，可以通过：

**其他 → 执行Python代码**

来完成相关环境部署。

由于RPA在相对独立的运行环境中执行，第一次启动时可能会自动安装所需模块。如果电脑中已经安装过，系统通常会自动跳过。

[PRE50]

如果自动安装失败，可以将错误提示复制给GPT，让GPT根据报错内容提供安装方法。随后打开电脑命令窗口，按照对应指令手动执行即可。

[PRE51]

[PRE52]

## 第三步：打开Excel文件

在左侧指令栏选择：

**Excel → 启动Excel**

打开文件路径时，点击变量按钮，选择第一步创建的“Excel卡片内容文件路径”。

这里要注意，应当选择路径对应的文本值，否则系统可能无法正确识别。

[PRE53]

## 第四步：读取Excel数据区域

Excel成功打开后，还需要指定需要读取的数据范围。

进入：

**Excel → 读取Excel内容**

此前启动Excel时保存的对象变量，需要在这里继续调用。

由于示例中的表格包含两列数据，因此读取方式选择“区域”。

[PRE54]

参数含义如下：

- `1`：从第一行或第一列开始
- `-1`：读取到最后一行或最后一列

读取完成后，将遍历结果保存为变量，例如“excel区域”。

[PRE55]

为了确认数据是否读取成功，可以增加“打印日志”步骤，检查读取到的内容。

[PRE56]

## 第五步：循环读取每一行内容

获得Excel数据后，需要逐行处理。

每循环一次，就读取当前行中的文案和作者信息，之后再将这些内容放入对应图片中。

[PRE57]

## 第六步：执行图片排版

接下来，通过Python代码将读取到的文字放置在背景图指定位置。

在左侧指令栏中选择：

**其他 → 执行Python代码**

代码的主要作用，就是循环获取Excel中的内容，并按照预设坐标完成图片排版。

[PRE58]

需要注意：

文案和作者字段，要分别从第一行的第一个单元格、第二个单元格开始读取。操作时，需要点击对应行的内容，确保正确选中变量。

# 八爪鱼RPA和Canva，应该怎么选？

两者更适合不同的使用需求。

如果你的工作需要结合Excel数据、爬虫内容或其他自动化流程，同时还要一次生成大量图片，那么八爪鱼RPA会更合适，特别适用于批量生产和自动化场景。

如果你更看重设计效果，希望快速套用精美模板，而且制作数量并不大，那么Canva操作会更轻松。

简单来说：

- 重视数据连接、自动化和批量生成：选择八爪鱼RPA
- 重视视觉设计、模板丰富和快速出图：选择Canva
