# 一、生意的底层逻辑

我出生在陕西一个非常小的县城，考上大学之前，连火车和飞机都没亲眼见过。刚到大城市时，商场的橱窗、同学的谈吐、街头的新鲜事物，都让我感到巨大的落差。家里人从来没有教过我任何关于赚钱的方法，于是“想搞钱”成了我进入大学后最强烈的念头。

那些让人难堪的时刻，我到现在都记得：为了省下200块，一个月吃饭都要精打细算；朋友聊起旅行的趣闻，我只能坐在旁边沉默；路过600块一位的海鲜自助，只敢隔着玻璃看两眼。种种经历让我明白，我想要的不是靠体力换钱的零工，而是一条能做时间朋友的复利之路。

后来我试过线上家教，一周上7小时课，到手只有120元；也接过视频剪辑的散单，本质上就是廉价卖时间。这些事做得越久，越觉得天花板太低。于是我开始琢磨：有没有什么方式，越做积累越深，越做收入越高？当这个念头变成主动思考时，商机反而一件件浮现出来了。

## 1. 一次摔伤，让我看清了生意的底牌

[PRE1]

今年3月，我的账户里其实已经有了六位数存款，但对“钱是怎么赚来的”这件事还是缺乏体系化的理解。我的盖洛普测评里，“思辨”和“战略”两项得分非常高，这让我有个毛病：如果搞不清自己成功的原因，我会浑身不自在。为了找到答案，我专门参加了生财的线下聚会，又啃了不少商业书籍，却始终差一点融会贯通。

突破来得毫无预兆。那是一个天气不错的午后，我去健身房锻炼，结果在用爬楼机时不小心把腿伤了。简单消毒后，我坐在休息区，和健身房老板以及另一位会员闲聊。那位会员刚好经营着一家剧本杀店，于是三个人你一句我一句，话题从健身动作滑到了开店、获客和成交。

聊得越多，我越发现，三家看似完全不同的生意，其实都卡在同一类问题上：健身房发愁无人到店，剧本杀店发愁难以复购，我则发愁小红书笔记没有转化。我们也都花了很多心思设计“第一次体验”——健身房的体验课、剧本杀的第一套盒装、我的低价课程，目的都是让用户愿意迈出付费的第一步。

那一刻，我突然觉得自己摸到了生意的底牌：无论行业看起来多不一样，背后的赚钱逻辑其实高度相通。

## 2. 第一个底层规律：完整的循环比单点能力更重要

我总结出的第一条规律：任何面向个人的生意，都可以看成一个由四个环节构成的循环——找准人群、做出产品、吸引关注、促成成交。健身房、知识付费、剧本杀店，不外如此。

[PRE2]

这四个环节拆开来看，并没有多高深。

第一环是“服务谁”，也就是找准目标人群。健身房解决的是变强壮、变健康的需求，剧本杀店提供的是解压和娱乐，我的时间管理训练则对应那种“想努力却总在拖延”的焦虑。在我眼里，这一环是整条循环的地基。只有把服务对象和核心问题想清楚，后面做内容、做筛选、做成交才会有方向。一个健身房里，无论教练带课还是销售谈单，都得先理解学员的处境，否则处处容易跑偏。

第二环是“被看见”，也就是获取流量。渠道可以五花八门，本质却只有一个：触达。我做知识付费，主要靠小红书上的内容吸引关注；健身房和剧本杀店，通常会投大众点评的广告；街边的海报、传单，本质上也是在触达。只要能让潜在客户找到你，再拿到微信或电话，后续就能持续沟通。

第三环是“交付什么”，也就是产品。健身房拿出来的是一节私教课，剧本杀店拿出来的是一套完整的角色体验，我拿出来的则是课程和一对一服务。产品不一定昂贵，关键在于能不能真正解决用户的问题。只要能做到这一点，哪怕形式简单，也有了售卖的价值。

第四环是“让用户买单”，也就是转化。健身房用体验课引导开卡，知识付费从业者靠朋友圈、公众号、直播推动下单。这环节看似套路多，但核心无非是打消顾虑、给出值得付费的理由。

当这四个环节首尾相连，一个生意就算真正成立了。先明确方向，再准备交付，随后让自己暴露在目标用户面前，最后推动成交、完成服务。哪怕规模很小，只要循环完整，就能产生收入。听起来有点绕？别急，后面我会用一个具体例子，带你一步一步跑通一整套循环。

## 3. 第二个底层规律：创业者只需要认知和资源

市面上有种说法，劝富二代别创业，因为传统生意实在太“烧钱”了。想开健身房，器械、房租、水电、广告费，每一项都是沉甸甸的资本压力。但创业真的只需要钱吗？可能还需要一个关键条件：一个有判断力、懂方法的人。

于是我把个人创业的条件压缩成两条：认知与资源。资源，是你能调动的所有东西，包括资金、时间、体力、人脉；认知，则是审美、方法论、对目标的理解，知道一件事应该做成什么样、为什么这样做。任何环节的落地动作，其实都是这两者的乘积。

拿一节高质量健身私教课来说，教练的工时、场地、器械、洗浴设施，以及购买这些设备的钱，都是资源；而如何设计训练动作、如何安排课程节奏、如何挑选器械，则是认知。两者合在一起，才会呈现出一节好课。小红书笔记也是如此——电脑、制图模板、创作时间属于资源，选题能力、封面审美、标题技巧属于认知，二者缺一，都无法产生有效流量。

由此可以推演：不同行业对认知和资源的需求比例不一样。相比知识付费，电商更吃资源，因为它要压货、要交保证金、要租仓库。而知识付费的启动成本很低，一台手机、一点点时间就能开工。为什么做着容易，能做成的人却那么少？因为知识付费对认知的要求极为苛刻。

做了两年知识付费，我越来越理解这句话。你写朋友圈要考虑发几条、怎么埋钩子；你卖课程要考虑大纲怎么搭、视频怎么录、价格怎么定。这些细碎问题背后，全都是认知在支撑。没有认知，再努力也只是原地打转；认知到位，赚钱就会成为顺带的结果。说到底，一个人的收入，很难超过他对这个世界的理解程度。所以我后来想明白了——想要赚到对应的钱，先得补上对应的认知。

# 二、新手做知识付费的全流程

[PRE3]

先看下方的思维导图，它列出了知识付费常见的获客渠道、交付形态和成交方式。你不需要现在记住，只需要对大框架有个印象，后面每一项都会讲到。

## 1. 何以解忧，唯有闭环

圈子里的人常说：“何以解忧，唯有实战。”但如果你问刚入门做什么效率最高，我会把这句话改一下：“何以解忧，唯有闭环。”对新手来说，第一目标不是学会多少理论，而是尽快跑通第一个商业循环，切身体验从引流、成交到交付的完整链条。

当你在网上赚到第一块钱，你的心态会立刻发生转变：从一个围观别人怎么做的人，变成一个真正下场做事的创业者。哪怕那笔钱只有9块9，也足够帮你跨过内心的门槛。

我见过最快上手的路径，就是卖一个9块9的陪跑群。这个产品足够轻，能逼着你把方向、获客、成交、交付全都走一遍。做得粗糙不要紧，只要循环能转起来，你已经领先很多空想家。

## 2. 方向怎么定：先做“成长”和“赚钱”

很多人一上来就到处找细分赛道，这其实难为自己。因为新人对自己的优势、用户的需求都还没有足够感知，硬要选一个小切口，很容易卡在第一步。不如换个思路：既然暂时看不准，就先选两个大方向——成长与赚钱。

这两个词几乎覆盖了所有人的隐性需求。想变好、想提升、想搞钱的人，都有理由来你的群里看看。方向太宽，确实做不了高客单价，但正好适合用来跑低价社群。一杯奶茶钱的门槛，用户不需要纠结太久，你也不需要太重的交付。

你甚至不需要把话说得太复杂，完全可以坦诚地告诉别人：“如果你愿意花9块9支持我，我会把自己学到、看到、想到的东西毫无保留地同步给你，大家交换价值。”这比包装成高大上的课程更真诚，也更容易迈出第一步。

## 3. 产品怎么搭：一个陪跑群就够了

方向定好之后，就该想交付什么。很多人觉得自媒体是“空手套白狼”，但你自己心里要清楚：我们不是卖空气，而是实实在在卖信息增量。

产品可以叫“某某的成长陪跑群”。某某是你的个人品牌名，群内的交付内容可以很丰富：今天自己学到一个新认知，明天整理了一份资料包，后天记录一次技能学习的复盘，或者分享参加线下聚会、阅读一本书的体会。只要是真实且有启发的内容，都可以发到群里。

别总担心自己水平不够，9块9的定价意味着用户期待并不高。你能提供一点别人不知道的信息，就已经值回票价。真正重要的不是内容多深，而是你愿意持续输出。

运营所需的物料也很少，核心是写好群公告。群公告是用户进群第一眼看到的东西，直接决定整个社群的调性。你可以在里面写清楚三个信息：这个群分享什么、多久分享一次、过去有哪些干货。比如：“欢迎加入枕棠的成长陪跑群，群内主要分享时间管理心得和副业赚钱方法，每周六晚八点固定直播分享，往期精华内容见文末链接。”

## 4. 流量怎么来：先混群，再加人

知识付费的流量目标其实很简单：把目标用户加到微信里，然后慢慢培养信任。获客方式有很多，小红书、公众号、直播、公开课，但对新手而言，最快的路径是混别人的社群。

第一步，找到一些成长类、副业类的社群，不管免费还是付费，先进去。进群后看规则，允许做自我介绍的话，就认真写一段自己的经历与价值，自然会有人对你产生兴趣；你也能主动添加那些感觉同频的人。

第二步，加了好友之后，不要干等对方开口。第一时间发一段真诚的自我介绍，再送一份自己整理的资料包当见面礼。大多数人加了微信后都会陷入“不知道说什么”的尴尬，你只要主动破冰，就已经赢了绝大多数人。

每天都重复这个动作，微信里慢慢积累出300个目标用户时，你的流量池就初步建成了。这些人未必马上付费，但他们会看到你的朋友圈、见证你的成长，后续转化只是时间问题。

## 5. 转化怎么练：海报加上朋友圈

产品、流量都备齐后，就差“成交”这块拼图。我不建议新手一开始就学公众号、直播这些重技能，最简单也最有效的动作，是发朋友圈。

不过，发之前最好先准备一张简单的宣传海报。不用学专业设计软件，用手机里的备忘录就能做。我用过最好上手的是锤子便签和iPhone自带的备忘录，前者在应用商店就能下载。海报也不需要花哨，写清楚两件事就行：你提供什么服务、价格是多少。

至此，一个最小化的商业循环就算完整了：有方向、有产品、有流量、有成交。当然，这只是最基础的版本，如果你想看更多玩法，可以到朋友圈搜索“陪跑群”，参考别人是怎么做海报、写文案的。不过，技术上的问题解决了，心理上的关卡才是更常见的拦路虎。

# 三、上路之后如何放大

## 1. 卡点一：觉得自己太菜，不敢教人

混进优秀的圈子之后，很容易产生自我怀疑：看到那些前辈写的干货、做的分享，会觉得自己根本不配做知识付费，只配当观众。

但请记住一个事实：100分的人可以教90分的人，90分的人可以教80分的人，60分的人教30分的人也绰绰有余。只要你会读书、会写作、会表达，甚至只要你能耐着性子读完这篇文章，就已经具备了输出的资格。你不需要成为大神，你只需要比你的用户多懂一点点。

如果你还是心里没底，就把选择权交给市场：先做出一个产品，拿出来卖。有人愿意买，说明你的内容对别人有用；没人买，也没关系，正好可以借此调整方向。成功和失败都是反馈，永远不要提前给自己判死刑，让结果来告诉你答案。

## 2. 卡点二：觉得收钱丢人，不配赚钱

很多普通家庭长大的孩子，从小的教育是“赚钱很苦，别走歪门邪道”。这种观念本身没错，但它会让人对线上收费产生一种莫名的羞耻感：总觉得自己不配收钱，只有去上班拿工资才理直气壮。

其实，父母那一辈赚钱难，往往不是因为不够努力，而是因为当时的认知和机会都有限。他们没有上大学，也不了解互联网和新媒体的红利，所以只能在传统行业里用体力换钱。但现在不一样，内容创业离风口更近，普通人也有机会借助杠杆放大自己的价值。

有人可能会说：“来钱快的都是骗人的，互联网创业不就是传销吗？”这是一种思维惯性。我们习惯把看不懂的事情归为不道德，但知识付费本质上只是交易：你提供自己验证过的方法，对方为此付费，双方都从中获取价值。这不是你骗别人，而是你帮别人省了时间，别人为你的时间付钱。更何况，付费用户通常也会因为你的内容而成长，而你又用收入继续学习，双方都在受益，何乐而不为？

## 3. 突破之后，收入如何放量

到这里，最小循环怎么建、心态坎怎么迈，已经全部讲透了。接下来，是继续留在原地，还是把收入往上冲一冲？

[PRE6]

首先要明确一点：不要试图同时升级四个环节，精力根本不够。这四个要素里，只要有一个环节出现明显突破，整体收入就会上一个台阶。

我见过很多人做完低价群就停下来了，原因很简单——路径依赖。他们一直重复最初成功的方法：继续混群、继续发朋友圈、继续卖9块9。刚开始还能赚点零花钱，时间长了内容开始重复，用户开始疲劳，自己越来越少分享，收入自然下滑，最后只能灰心收场。

想突破到月入过万，关键不是更努力地重复，而是选择一个薄弱环节做单点突破。要么把产品体系拉深，从低价社群延伸到几百块的训练营或一对一服务；要么把流量渠道打开，从混群升级到小红书、公众号、视频号等可沉淀的平台；要么优化成交场景，增加直播、公开课等高转化动作；要么把定位收窄，从“成长和赚钱”变成某个具体人群的具体问题，提高客单价。

知道怎么做能入门，是第一阶段；知道怎么放大，才是真正的分水岭。我把这套进阶经验交到你手里，接下来，就轮到你去实战了。
