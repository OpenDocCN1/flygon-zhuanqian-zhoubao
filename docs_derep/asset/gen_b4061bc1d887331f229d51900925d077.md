# 别再手动扒文案了！我用Coze智能体，一分钟把抖音爆款视频变成公众号文章

你是否还在为公众号选题绞尽脑汁？是否还在抖音和公众号之间来回切换，复制、提取、排版，忙得晕头转向？更头疼的是，费了半天劲，改出来的文章质量还不一定理想。

其实，这些繁琐步骤完全可以交给AI智能体。最近我发现一个超好用的方法：通过Coze平台搭建一个专属Bot，它能在不到一分钟的时间里，把抖音热门视频的文案自动改写成一篇高质量的公众号文章。省时省力，还能保证内容水准，简直是自媒体人的福音。

先说说什么叫AI Agent。简单来说，它是一种能理解任务、拆解流程、自动执行指令的智能系统。它的最大亮点，就是能把复杂的工作步骤逻辑化、自动化，从而帮我们搞定那些重复性高、又费人力的活儿。比如自动处理数据、生成报告、做决策分析、个性化推荐，甚至自动驾驶和机器人服务背后都有它的影子。说白了，AI Agent就是帮你“跑流程”的智能助手。

下面分享我的实际操作步骤。你只需照着做，就能快速拥有一个属于自己的抖音转文章Bot。

第一步，打开Coze的国内官网，用你的抖音账号或者手机号注册登录，进入主页面。

[PRE0]

在主页面找到“创建Bot”的按钮，点击后会弹出对话框，需要你选择一个工作空间。接下来，给Bot起一个朗朗上口的名字，再配一张吸睛的图标。如果你懒得选图，也可以让AI帮你自动生成一张专属图标，非常省心。

[PRE1]

基本信息填好之后，点右下角的“确认”，就会进入Bot的编排页面。在这里，你可以对Bot的响应逻辑进行详细设定。

[PRE2]

我们看看整个工作流是如何运转的：用户先输入一个搜索关键词，比如“西班牙欧洲杯夺冠”，Bot会自动调用抖音视频插件，去检索相关的热门视频。这里还可以自由设置发布时间、排序方式等筛选条件。拿到视频后，Bot通过读取链接插件提取视频的原始文案内容。接下来，大模型会对文案进行智能改写，让它更有吸引力、更贴合公众号读者的阅读习惯。最后一步，通过排版插件把内容整理得干净美观，一篇可直接发布的文章就诞生了。

[PRE3]

接下来，我们就要动手创建这个工作流了。点击页面上的“添加工作流”按钮。

[PRE4]

在弹出的对话框里，继续点击“创建工作流”。然后给工作流起个名字，写好描述，点击“确认”即可完成创建。

[PRE5]

进入工作流编排页面后，你会看到系统默认生成了两个节点：“开始”和“结束”。它们分别对应工作流的输入和输出内容。我们要做的，就是在它们之间插入插件和大模型节点，对输入内容进行处理，最终输出结果。

[PRE6]

按照前面的流程设计，我们首先添加抖音视频读取插件。点击左侧的“添加插件”按钮，在弹出的搜索框中输入“抖音视频插件”。

[PRE7]

选中抖音视频插件，一键添加到工作流中。这个插件有几个常用参数需要了解一下：
- count：返回视频数量，可选，默认是5条，这个工作流只需要用到1条视频进行处理。
- keyword：搜索关键词，必填项。
- sort_type：排序方式，非常实用，比如你可以设置为“按最多点赞排序”。
- search_id：用于维护搜索连续性的参数。
- publish_time：发布时间范围，可以限定多少天内发布的视频。

[PRE8]

点击界面右侧“添加”按钮，把所需插件添加到工作流中，然后逐个配置好参数，确保每个环节都符合你的需求。

[PRE9]

接下来，需要把节点用箭头连接起来。方法很简单：把鼠标移动到节点连接点，拖动箭头到另一个节点即可。注意，keyword参数的值要选择上一个节点的input值，其他参数可以根据实际需求自行设置。

[PRE10]

同样地，把读取链接的插件LinkReaderPlugin也加到工作流中。这里要特别提醒：Url参数一定要设置成get_video返回的link值，否则无法读取到链接数据。

[PRE11]

接下来要添加两个大模型节点：一个用来生成标题，另一个用来生成文章内容。点击“添加大模型”按钮两次，将两个节点加到工作流里。然后分别设置好输入参数，比如LinkReaderPlugin返回的content内容，再输入对应的提示词。提示词不是本文重点，你可以根据自己的风格编写能生成优质改写内容的提示词。

[PRE12]

接着，用排版插件对生成的内容进行美化排版。需要注意，选择输入参数时要看清楚大模型输出的数据参数，别选错了。

[PRE13]

最后，把文章标题模型的输出指向结束节点，同时把排版节点的输出也指向结束节点。注意这里输出的是两个数据：标题和正文内容，选择输出参数时也要格外留心。

[PRE14]

一切连接完毕后，点击工作流编排页面右上角的“试运行”按钮，开始测试整个流程。

[PRE15]

在弹出的对话框中输入搜索关键字，比如“西班牙欧洲杯冠军”，然后点击运行。你可以实时观察工作流的运行状态，如果有设置错误的地方，系统会明确提示，方便你逐个修正。

[PRE16]

运行完成后，可以看到每个节点的处理结果和数据详情。确认无误后，点击右上角“发布”按钮，发布工作流。

把这个工作流应用到Bot中，然后输入尽可能详细的提示词要求，点击右上角“优化”按钮，系统会自动帮你优化提示词。

[PRE17]

优化完成后，点击“使用”即可应用。当然，你也可以继续手动调整。不过，既然工作流里已经详细设置了流程和内容要求，这里的提示词更多是起到锦上添花的作用，对最终输出内容做一些微调。

[PRE18]

最后，在右侧调试框里输入搜索关键字进行测试。

[PRE19]

调试无误后，就可以把Bot发布到相应平台了。如果是未授权的平台，授权流程也很简单快捷。
