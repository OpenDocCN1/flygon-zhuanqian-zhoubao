# 手把手：从零开始把N8N部署到云服务器，域名+HTTPS证书全搞定（新手也能一次成功）

很多朋友在尝试自己部署N8N自动化工作流的时候，总会被各种看似复杂的步骤劝退。其实这件事远没有想象中那么难，只要跟着下面的路线走，一台境外云服务器、一个域名、一张SSL证书，通通都能顺利拿下。

## 一、选服务器：这一步千万别踩坑

### 第一个大坑：千万别买境内的服务器！

这是很多人第一次部署时最容易踩的坑。按照国内法规，所有使用境内服务器的网站都必须完成ICP备案。备案流程动辄一两周起步，而且备案期间网站完全无法访问，备案通过后还可能接到各种核实电话，非常折腾。

所以，建议直接选择香港、日本或新加坡等境外节点的服务器。虽然境外服务器也有一些不便，比如无法直接接入微信支付、支付宝、公众号扫码登录等，但这些其实都有替代方案，比如用公众号验证码登录、接入第三方发卡平台。至于网速问题，只要不选太远的节点，体感上几乎没有差别。

另外强烈提醒一句：有些云厂商经常推出超低价服务器活动，看起来非常诱人，但那些低价套餐通常只允许选择国内区域，而且可选地区被限制得很死。别贪这点便宜，否则后续备案会把你磨到怀疑人生。

### 阿里云购买流程

1. 打开阿里云官网并登录账号
2. 进入轻量应用服务器的购买页面
3. 配置选择上，内存至少2G起步，太小的配置连部署都会困难。新手上路买最基础的套餐就够用了，没必要一步到位直接上高配
4. 地域推荐优先考虑香港，离大陆近、延迟低，速度上也更有优势
5. 购买时长建议先买一个月，跑通了再按月续费，别一上来就买三年

买完之后，到控制台等待服务器初始化。等状态变为“运行中”，就可以开始操作了。别忘了先给你的服务器设置一个登录密码，设置完会触发重启，等重启完成就绪之后继续下一步。

## 二、安装N8N：不搞花哨操作，直击核心

不需要宝塔面板，不需要Docker容器。你只是要跑工作流，又不是做网站，完全没必要把环境搞复杂。直接在服务器上像本地一样安装即可。

### 第一步：连接你的云服务器

1. 在本地电脑按 `Win + R`，输入 `CMD` 打开命令行
2. 执行命令：`ssh root@你的服务器公网IP`（这里的IP在你的云控制台可以看到）
3. 首次连接时系统会询问是否确认连接，输入 `yes` 回车
4. 接着会让你输入服务器密码——注意！输入密码时屏幕上是没有任何显示的，属于正常现象，别慌，输入完直接回车就行
5. 看到欢迎页面和 `root@你的主机名` 提示符，就说明连接成功了

如果密码错了，会提示认证失败，重新输入即可。要是忘了密码，回控制台去重置。

### 第二步：安装Node.js环境

先安装NVM（Node版本管理器），执行下面这行命令：

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
```

安装完成后输入 `exit` 断开连接，重新登录服务器，然后检查NVM是否装好：

```
nvm -v
```

能看到版本号就是成功了。接着安装最新版Node.js：

```
nvm install --lts
```

安装完成后切换版本：

```
nvm use --lts
```

### 第三步：全局安装N8N

执行：

```
npm install n8n -g
```

这个过程可能要等一会儿，如果在执行过程中卡住不动，可以直接关闭命令行窗口，重新连接服务器后再执行一次安装命令。耐心等它跑完，看到成功提示就说明安装好了。

说到这，公布一个隐藏福利：因为服务器在境外，很多国外服务不再需要额外工具就能直接访问，也不需要配代理或者换国内镜像源，用起来就是四个字——畅通无阻。

### 第四步：启动N8N并开放端口

输入 `n8n` 启动服务，看到启动日志后，在浏览器里访问 `你的服务器IP:5678`。

不过在这之前，一定要先去阿里云控制台，找到你的服务器，点击“防火墙” → “添加规则”，放行 `5678` 端口。不开放端口的话，外部是访问不了的。

### 第五步：跳过安全检查直接进入

首次访问时N8N会提示未配置SSL证书或域名，出于安全考虑拒绝访问。最快的解决方式是暂时绕过这个安全限制（后续配置了域名和证书后就恢复正常了）：

1. 先杀掉当前运行的N8N服务：`ps aux | grep n8n` 找到进程ID，然后 `kill -9 进程ID` 结束它
2. 用以下命令重启N8N，绕过安全校验：

```
N8N_SECURE_COOKIE=false n8n
```

再打开浏览器，输入 `你的IP:5678`，这次就能顺利进入N8N界面了。

本地部署过N8N的朋友注意：云服务器和本地的数据是不互通的，即使使用同一个账号也需要在云端重新激活一次密钥。

## 三、重要补充：用PM2让服务永不掉线

如果直接在命令行里运行N8N，一旦关掉命令行窗口或者SSH断线，服务就跟着挂了。为了防止辛辛苦苦搭好的工作流消失，我们需要额外装一个进程守护工具：

```
npm install -g pm2
```

先杀掉之前的N8N进程，然后用PM2重新启动：

```
N8N_SECURE_COOKIE=false pm2 start n8n --name my-n8n
```

`my-n8n` 是你给这个任务起的名字，可以随意改成自己的命名，只是后续操作命令中保持一致即可。

日常管理命令：

- 查看运行状态：`pm2 list`
- 停止服务：`pm2 stop my-n8n`
- 再次启动：`pm2 start my-n8n`
- 重启服务：`pm2 restart my-n8n`

今天用的服务器操作方式同样适用于阿里云自带的网页终端，如果觉得本地CMD连接麻烦，试试网页版终端会更直观，对新手也比较友好。

## 四、买域名 + 绑定证书，完整闭环

### 域名购买推荐平台

推荐在 NameSilo 购买域名，原因很简单：

- 国外平台，规则简单不折腾
- 支持支付宝付款
- 价格便宜，性价比高

购买流程：

1. 注册并登录账号
2. 在搜索框输入你想要的域名，回车搜一下
3. 挑选合适的后缀，加到购物车（做工作流的话买便宜的就行）
4. 下单时盯紧金额，只买域名本体，其他附加服务一律不勾选
5. 支付方式选择“see more”，找到支付宝扫码完成支付
6. 地址随便填，不知道写什么就搜一下“美国地址生成”
7. 付款后回到账户后台 → MY Account → Manage，就能看到你名下所有的域名

### 域名解析到服务器

这里我们要用到 Cloudflare（简称CF），免费又好用：

1. 注册/登录 Cloudflare，可以把语言切换成中文
2. 添加你的域名，选择免费计划
3. 按照指引添加DNS记录，把域名解析到你的服务器IP地址
4. 完成之后，CF会提示你前往域名注册商处修改NameServer

回到NameSilo的域名管理页面，点击“Change Nameservers”，把原来的DNS服务器全部删掉，填入CF提供的两个NameServer地址，点击提交。

等待DNS生效的时间不固定，快的话十来分钟，慢的话半小时到一小时内。

生效之后，直接访问你的域名，大概率还是打不开N8N页面。别慌，原因很简单：N8N默认跑在5678端口，而域名默认走的是80/443端口，相当于你想从大门进屋子，但门还没开。

解决方式：去你的云服务商控制台，在防火墙规则里放行80和443端口，同时给你的N8N加上SSL证书配置，通过Nginx或Caddy做一层反向代理，把域名流量引导到localhost:5678就搞定了。

## 五、最后的一些贴心提醒

- 云端服务器更容易被扫描和攻击，有条件一定要配域名 + HTTPS证书，安全等级完全不同
- 所有命令不要手打，直接复制粘贴执行，一个空格错误都可能导致报错
- 每一步都不要跳过，按部就班操作，很多报错都是因为中途跳了步骤
- 执行命令没有报错返回，通常就意味着操作成功，这算是命令行世界的一条潜规则

至此，你的N8N云服务器部署、域名绑定和安全配置就全部完成了。打开浏览器，输入你的域名，就能随时随地访问自己的自动化工作流，再也不用担心本地电脑关机导致任务中断了。
