# 专访 23 岁 00 后创业者乔合：七年深耕学生私域的实战心法

> 原文：[`www.yuque.com/for_lazy/thfiu8/nig2tp0ibo2m49mp`](https://www.yuque.com/for_lazy/thfiu8/nig2tp0ibo2m49mp)

亦仁对生财有术项目精选分销榜前三的成员做了系列访谈。今天的第一位，是分销榜首的乔合。

乔合是 00 后实体创业者，互联网里折腾了八年，物联卡、扩列、薅羊毛、淘客、潮牌等多个圈层都留过他的足迹。生财上他发过《年轻的实体店创业者，如何用互联网思维破局疫情影响》，把 QQ 空间沉淀的资源迁移到私域联盟，并实现线上线下联动。

下面是对话精要。

**一、为何锁定学生群体**

亦仁：你阅历丰富，为什么最后把焦点放在学生私域上？

乔合：其实源于 16 岁那年的兴趣。最初是做软件游戏分享，吸引来的一水的同龄人。因为自身体验过学生的兴趣点，所以判断更准。后来公司业务方向就围绕学生需求来布局。

亦仁：外界常说割韭菜，尤其未成年群体，你怎么看？

乔合：对他而言，韭菜的核心是投入产出严重失衡。他给学子做的课程普遍走轻量化、低门槛路线。定价主要集中在 188 到 388 之间。比如 188 元带做闲鱼，学习能力强的用户十天内能回本。第一次轻松见到收益，信任自然沉淀，后期再引导到 2588、5888 的高客单产品，转化就顺了。

他甚至把学员群戏称为韭菜大队，但从未被学员指责。原因也很简单：一上来就收高价，回本周期拖长，一个月都看不到效果，很容易放弃，最后把不满归到带头人身上。

因此他的策略是先用低价建立信任，再逐步提升产品价格。目前在售的课单价梯度为 188、288、388、588、2588、5888。

亦仁：会长期经营这个人群 IP 吗？

乔合：已坚持七年，并打算继续。学生知识付费赛道目前几乎没有头部玩家入场，外人普遍认为学生没付费能力、太抠。事实并非如此，只是需要激发内部的赚钱动机。连幼儿园孩子都明白钱能换来喜欢的东西，人人都有获利欲，关键在于点燃方式。

亦仁：做学生变现最自豪的是什么？

乔合：不是资产炫耀，而是看到大量学子用项目解决了每月零花钱的困扰。对老师来说，最希望看到学生能赚钱，这份成就感很难替代。

亦仁：过程中有怀疑过吗？

乔合：有。做学生的信任型 IP 需要极强的人格背书。很多付费用户从初中就追随他，他也在看着粉丝成长。所以进入这个赛道就得准备好至少一年无法盈利，做好持续塑造个人标签的准备。这个模式和引流手法很多人听过，但复制不出第二个乔合，因为根基是不可复制的 IP。

亦仁：如果弟弟妹妹加入这类社群，你会怎么提醒？

乔合：“在自己现有的能力边界里，多出去看看，你会发现另一片天地。”

**二、项目筛选与运营**

亦仁：挑选付费项目时看哪些指标？

乔合：主要看操作复杂度、平台政策、是否合规、可否规模化、周期与收益。以去年做的百度答题项目为例，招了近千名学员。原因：操作就是机器人答案稍作润色后回复，复制改写即可；平台欢迎专业答主；完全合规；可借助模拟器多开解决实名限制；依托百度大平台稳定性强。实测一小时可完成约 30 题，单号时薪约 20 多元，188 元课程一周左右回本。

亦仁：粉丝来自哪些渠道？差异大吗？

乔合：三大来源：扩列圈用户、QQ 游戏软件用户、薅羊毛线报用户。画像高度重合，基本是 15 至 20 岁的在校人群。共同特点是社会经验不足，容易跟随，简单说就是心思相对单纯。

亦仁：学生赚钱和学习会不会冲突？有没有其他延展？

乔合：知识付费本身就是引导副业。起初主攻淘客导流，后来围绕该群体做流量卡、知识付费、潮牌等刚需生意。劳务和求职曾考虑过，但用户并未全部进入就业期，会造成流量浪费。不如做普适刚需变现。哪怕学生不做项目，也可能通过链接赚取分销，或找他购买潮牌单品，比如现在流行的 AJ。

**三、与生财的交集**

亦仁：生财对你帮助大吗？

乔合：很大。能获得新信息和新方向并整理给学员；结识了不少同行，有人反向付费；还对接了大佬合作了两项业务，变现超 30 万。

亦仁：对生财有什么建议？

乔合：没有特别建议。能想到的生财早已做到，想不到的也做到了。生财看到的视野，比我宽得多。[https://t.zsxq.com/0bi29mUqG](https://t.zsxq.com/0bi29mUqG)

23 岁，他已经在别人看不上的一片水域里游了七年。机会永远留给持续折腾、并且愿意长期主义的人。
