### 我做了什么、经历了什么

去年底我离开大厂，带着团队冲海外融资。结果不理想，项目被迫叫停。接下来大半年我基本在旅行，偶尔给朋友当营销顾问，状态是典型的迷茫+试错。

直到十月我才想通：与其再去赌一个还没验证的事情，不如回到自己过去几年做得最顺手、复用性最强的能力。想明白后答案很清晰：帮创始人把自己讲明白。

厘清方向后三个月，我签下了好几位付费客户，客单在十几万级别，最近几条主打内容在海外也都冲到十几万甚至 20 万+ 阅读。业务才刚起步，但从定位、定价到交付闭环，这条线已经跑通。

这次复盘给我的两点最大体感：

- To B 服务比做 To C 产品要轻很多。To C 要同时扛获客、转化、留存三座山，To B 只要算清 ROI，决策链极短。早期单人创业，先拿服务做案例验证，比直接做产品更理性。

- 创始人 IP 的本质是杠杆，不是流量。创始人不需要粉丝量最大，只需要对的人能看见你——投资人、核心客户、关键用户。核心不是套模板做爆款，而是先搭一套稳定可复用的系统，爆款是副产物。

### A. 为什么锁定这个赛道

年初离职创业后，我和团队硬扛了半年海外融资，最终没融到。那段时间很失落。习惯了带团队，突然没有资本化路径时，我完全不知道自己能做什么。后面几个月给朋友做顾问、到处走，表面松弛内心极度焦虑。每天跟 AI 对话找天赋，找人做盖洛普解读。她说我最强的是领兵打仗，我认同，但当时手上没兵，于是各种内耗。

直到十月，我开始回望过往经历：跟我背景相似的人，卡在哪里是我能解的？最终指向同一件事：帮 AI 或出海创始人解决增长与影响力问题。

选这个方向有两个底气：

- 第一，我吃过创始人的苦。23 岁拿融资、大厂联合创始人带分拆融资、海外多个项目经历，让我对创始人各阶段的痛点非常敏感。自己融资失败那段也更确认：对小团队来说，能撬动局面的核心杠杆，就是让市场先看见你。

- 第二，AI 时代的竞争是差异化。塞思·戈丁的紫牛理论我一直有感触：数百头奶牛一起看很快就无感，一头紫牛会让人记住。现在 AI 让内容生产成本暴跌，开始新鲜很快就审美疲劳。要突围，不一定是更好，而是更不同。

也正因如此，我认为创始人 IP 会变得前所未有的重要，未来几乎所有科技创始人都必须亲自面向用户。

另外我刻意选择从 To B 服务起步。To C 是注意力消耗战，获客贵、转化慢、留存难。To B 的付费逻辑很直接：你帮我赚的钱或省的成本大于我付你的钱，就买。算得清，决策快。先用服务攒案例验证方法论，再考虑产品化，是更稳的路径。

### B. 这个需求为什么成立

#### 创始人 IP 和网红 IP 是两回事

徐沪生说过，创始人做 IP 最大的误区是照抄娱乐网红打法。底层逻辑完全不同：网红做的是泛流量变现广告，创始人要的是精准用户触达产品。

创始人的核心资产也不是段子能力，是专业深度。AI 创始人的优势是懂 AI，Web3 创始人的优势是懂链上叙事。脱离专业，创始人没有说服力。

所以创始人做内容，关键是呈现专业深度、思考深度和个人魅力。

#### 创始人真实的痛点

创业者脑子里信息密度极高，决策复杂度远超一般内容创作者，但输出的内容却很难有人看。主要有三点：

- **太忙**：公司事太多，花一小时写深度稿成本太高
- **怕丢人**：担心没人看、担心同行觉得掉价
- **不会把内容变现**：不知道好内容如何导向融资、客户或用户

而且不同创始人的目标差异很大：有人要融资，有人要 C 端社区，有人要触达开发者。用一套模板套所有人，根本不成立。这也是市面上通用 IP 服务对创始人效果有限的原因。

#### 我的切入角度

我完整经历过项目 0-1 和增长阶段，清楚不同阶段的需求。

因此我的服务是定制化的创作操作系统 + 战略咨询 + 营销投放：

- 基于创始人当前阶段和商业目标，明确 IP 定位与营销策略
- 搭建可复制、可生长、可迭代的内容生产系统
- 共同产出旗舰内容并精准分发到投资人、KOL、潜在客户手里

### C. 如何验证市场与交付

从 0 到 1 的判断，最值得复盘。

#### 1. 首单为何能成交

有想法后我没有急着造系统，而是先列一个服务清单，给出自己觉得合理的价格，去找一个真实客户验证。

我挑了一位认识多年的创始人朋友，产品我认可，风格是长期主义。沟通前我做了功课：把他过去所有推特梳理一遍，做内容诊断，标出表达到位的点、明明有深度没讲出来的点、粉丝画像与真实客户的错位，以及下一轮融资该讲的故事。

聊了不到一小时，他直接付费了。

复盘下来是三重叠加：多年信任基础，不用从零建信任；我不是推销服务，而是先展示问题，创始人对这种「你懂我业务」的感触最深。

但我很清楚，靠朋友信任能拿第一单，只有结果能带来第十单。所以从第一单开始，我就把可复制性放在成交前面。

#### 2. 服务清单是如何长出来的

坦白说，清单不是一开始就设计的，是做下来后逐步补全的。

最初我只想着梳理战略+写几篇旗舰稿。真正交付后才发现，客户对结果确定性要求更高。

第一，他需要有人帮他理清「写什么」。

多数创始人不是不会写，是不知道写什么。我会先复盘他的阶段性商业目标：现在是融资期、拿 B 端客户、还是做 C 端社区？不同目标叙事完全不同，方向不清再写都是浪费。

### 3、交付到底交付了什么

先说清楚：客户买到的是为他定制的创始人创作系统，包含战略诊断、行业知识库、分发网络、IP 资产沉淀，以及我的陪跑。

交付大致分三步，样本仅供参考，不同赛道创始人节奏会不同。

- **第一步：搞清楚他是谁。** 多轮深度访谈，聊目标、关键转折、他在行业想扮演的角色。聊完后，创始人会惊讶自己能讲的东西原来这么多。

- **第二步：搭一套能跑的系统。** 把定制系统装到本地，手把手产出第一批旗舰内容。我负责结构、深化、打磨、标题判断，他负责观点和真实素材。这个阶段最大体感是写作不重了，过去写一篇深度文要拖两天，现在几十分钟出初稿。

- **第三步：让内容被对的人看见。** 精准投递给投资人、KOL、目标客户。发完一起复盘，把共性改动沉淀回系统。越往后，他自运行的效率越高。

#### 5. 十几万的价格为什么能成立

核心在于你买的不只是系统和几篇文章，而是我过去几年在真实商业增长里沉淀的判断力。它决定了三个关键问题：

1. 你这家公司现在到底该做什么
2. 这个阶段该做、该不该做的边界
3. 什么节奏投产比最高

这些问题没人帮你理清时，你会在「发不发」「方向对不对」「是不是太早」上反复内耗，机会成本远超十几万。

系统可以被复制，真正稀缺的是带来结果的确定性。能理解这点的创始人不会纠结价格；纠结价格的，大概率也不是我想要的合作对象。

### D. Compound：我开源的部分

交付系统最核心的资产是整套创始人创作系统，覆盖战略诊断、定位、选题、深化、写作、分发、复盘、IP 沉淀。每个客户版本都会重做一遍，按行业、受众、商业目标、语言习惯定制。

今天分享的 Compound，是其中深度写作层的通用版，适合所有想认真写作的人。

**设计逻辑：先认清自己，再开始写**

大多数 AI 写作工具是上来就让你写：套模板、填空、出稿。

Compound 反其道而行：

- 不是帮你写一篇文章，而是先让系统认识你、你的思考方式、你的表达习惯
- 不是给你爆款模板，而是让系统学会判断什么对你算爆款
- 不是一次性出稿，而是每次使用都在训练系统更懂你

Compound 名字的含义是复利。每发一篇，系统就更懂你一点。

**为何越用越聪明**

三件事在持续发生：

- **Personal OS** 是底座：建立个人定位、经历素材库、文风档案，后续创作基于此，而不是从零开始。
- **知识库是活的**：发布复盘、收集素材、AI 记者洞察都在持续喂养系统。
- **Skills 会进化**：同一类修改出现三次以上会自动沉淀进 Skill，不用重复沟通。

#### 一篇文章的生成路径

这是一张地图，可从任意节点进入。

**首次使用：建立 Personal OS〔一次性 5-30 分钟〕**

- 4、个人定位〔5 分钟〕：一次性输入你是谁、产品、目标读者，自动整理成档案。
- 5、经历素材库〔15-30 分钟，可跳过〕：通过英雄之旅 12 问访谈提炼人生素材，自动生成「人生三部曲」与素材标签。
- 6、文风提取〔5 分钟〕：提供 3-5 篇代表作，自动分析思维与语言习惯。

可跳过直接写，系统用通用风格，随时补建。

**Phase 0：自由探索〔可选热身〕**

把想法倒出来，和 Claude Code 自由聊，再进入系统。

**Phase I：选题**

topic-engine 两大功能：

- 没想法时：基于定位与热点推荐 3-5 个方向并带爆款潜力评级
- 有想法时：五维打分〔独特性/冲突感/实用性/时效性/传播性〕，总分 50，S 级直接写，C 级建议换

触发词：「帮我找选题」「这个选题行不行」「选题打分」

**Phase 2：选结构**

content-structure Skill 根据长短文推荐爆款结构〔短文 S1-S4 / 长文 A-D〕并说明理由。

触发词：「帮我选结构」「写长还是写短」「这个用什么结构写」

**Phase 3：深化内容〔可选〕**

- **工具 A — 思想升华 thought-elevation Skill**
  适合有观点但停留在现象。三种模式：跨学科升华、理论透镜〔尼采、福柯、海德格尔、荣格等〕、奥派辩论〔哈耶克与米塞斯视角〕。
  触发词：「升华一下」「更深一层」「让文章更有深度」

- **工具 B — 素材挖掘 AI 记者 Skill**
  适合有判断缺支撑。诊断想法完整度、三轮结构化提问、输出 SCQA 框架、初稿后给质量雷达图。
  触发词：「采访我」「深化选题」「帮我把想法说清楚」

**Phase 4：出初稿**

基于内容+结构+文风生成第一版，骨架齐全后修改比从零写快。

**Phase 5：人工打磨**

你主导多轮修改：「第 3 条改成 XXX」「开头不够抓人」「压缩到 300 字」

**Phase 6：标题、钩子与封面文案**

- 7. 钩子优化：诊断开头并生成 10-15 条方案
- 8. 封面文案：打情绪，拿自然流量
- 9. 内容标题：打关键词，拿搜索流量

核心理念：封面文案与内容标题要不一样。

**发布后：数据复盘 → 反哺系统**

记录核心数据，回答什么结构有效、什么开头留人、哪类话题共鸣。高效段落沉淀进知识库。

**系统如何自我进化**

- Skills 迭代：同一类改动出现 3 次以上自动升级进 Skill
- 知识库扩充：每 2-4 周把高效内容加入 knowledge-base
