# 账号冷启动与权重养成

赚钱心急容易翻车，必须按流程走，不可能速成。

核心纪律：单设备单账号单号码。同一部手机只装一个小红书只登一个号，避免频繁切换。我八月份就因为切换被封五个号。有人说能多开，别走捷径，血的教训。

设备多了可以去闲鱼、二手平台找便宜苹果机。700元左右的iPhone X就够用，系统流畅，安卓暂不推荐。500元的iPhone 8P也能用。我手上十台机都是苹果。去通讯城买时说明是工作室用机，老板会给低价。注意必须有人脸识别摄像头，后续实名要用。

注册时年龄填30岁，性别选女性。ID要提前查重，小红书搜一下看是否重复，重复会让店铺审核不过。为方便被搜索到，取一个独一无二的名字更有利。

注册完别马上实名，先去养号。找对标账号，持续点赞、收藏、评论、转发。很多人只知道动作，不知道原理。小红书有等级体系，编辑资料往下拉就能看到等级，最初是“尿布薯”。升级需要完成互动四要素。

加速激活的办法：发一篇图文，用醒图做白底图配文字“30岁了，快劝我不要生二胎”，字体排版调好。带话题 #该不该要二胎# #二胎# #生孩子# 。通常能引来上千女性评论，同时带来点赞、粉丝、曝光，账号就启动了。女性用户购买力强，这招效果很猛。

笔记播放量突破1000，爆款可到5000左右，再去实名。一个手机号只能实名一个号，多开需要找亲友的手机号配合注册实名。

# 店铺类型与开通路径

小红书店铺分个人店、个体店、专业号、企业号。

个人店只需身份证；个体店需个体工商户执照；专业号在个体户基础上交600元可开三个子账号，子账号可售卖主账号商品；企业号需缴纳2万元保证金。

小白建议先做个人店。开店前先按平台要求提交申诉，审核正常再正式开店。

一个实名账号仅能开一家个人店。

# 上架工具：妙手

插件环境不稳定，多个工具轮换使用更稳妥。

开通店铺后在店铺页下方服务入口进服务市场，找到妙手商品上架。获取后进入商品上货，先设置上架参数。类目手动设置，品牌留空或选默认，货号留空。价格系数我一般设200%，即赚一半。市场价必须高于售价才能过审。运费模板选非偏远地区包邮，物流填发货地址。预售选项必须选非预售，发货时效48小时，保存后即可发布。

# 如何获取同款链接

在小红书找低分高赞爆款，截图后用拼多多识图功能定位同款，挑销量高评价多的复制链接导入上架工具。1688可在页面右上角使用转发复制链接，注意找源头厂家，辨别牛头标识。

拼多多操作：打开APP点左上角拍照上传截图，即可搜到同款。1688操作：点右上角放大镜一键识图找对应商品。淘宝抖音逻辑相近，不再赘述。

# 审核不过的排查

提交后若未通过，先去千帆-商品-编辑查看提示。常见原因：类目未开通，需在店铺设置里申请类目，审核需2-3工作日，建议提前多申请。图文内容不能出现淘宝、抖音、1688、拼多多字样。图片不能有白边。修复后重新提交。
