# 从世界记忆大师到地推狂人：这个冷门教育赛道，藏着最野的赚钱逻辑

很多人问我，做教育到底靠什么赚钱？我入行六年多，栽过跟头，也见过各种模式，最后让我真正赚到钱的，不是课程研发，不是口碑运营，而是一支又土又狠的地推团队。靠着它，我做出了相当于十家直营校的利润。

先说我怎么进这行的。大学还没毕业，我迷上了《最强大脑》，跑去参加各种脑力大赛，2017年拿下了世界记忆大师证书，后来又进了银鹰高智商俱乐部。原本只是上个电视、登个报纸，没想到有培训机构辗转找到我，请我去给学生做辅导。那是我第一次意识到，脑力训练不只是比赛，它还能卖钱。

但教育这碗饭，远没有想象中好吃。

人人都说直营校一本万利：除了房租、水电、老师工资，剩下的全是利润。可真相是，处处都要钱，你招满100个学员，可能才刚够付老师工资。课程做得再好，续费率照样难看；靠口碑转介绍，最多让校区“活着”，根本谈不上发展。说白了，课程就是你要卖的产品，盈利的核心不是产品本身有多好，而是你怎么把客户带进来。

我在北京入股过一家教育公司，最多时管着四家直营校。表面风光，实则每天都像在走钢丝。素质类课程不是K12，没有必须学的压力，家长很难年年续费。老师好不容易带出来，转头就走。退费更是常态，哪怕是签了协议，对方往教育局一坐，你就得乖乖吐钱。最坑的是分红机制：校区为了现金流，拼命推全年课程，这个月收的学费，其实是十二个月后的收入。股东们三个月一分红，等于提前分未来的钱。等招生一卡壳，工资都发不出；真要退费，谁愿意把吃进嘴里的钱吐出来？我们的四家校区，最后在疫情里倒掉了三家。

这件事让我彻底想明白：续费、转介绍都是锦上添花，拓客才是那个“锦”。没有新客源，一切都是空转。

在北京时，我们试过电销、地推、办活动，都只够让机构喘口气，赚不到大钱。后来我们玩起了“家长合伙人”：常规班结束后，我们借家长会展示教学成果，顺势让家长报名“弟子班”，一报名就自动获得合伙人资格。合伙人可以帮我们办观摩会，用自己的人脉渠道邀约家长来现场听课，成交率最高能做到四成。比如有位家长开儿童口腔诊所，手里有上百个客户，我们找个酒店会场，一套流程走下来，现场成交率直接到40%。想玩更大的，还可以参股加盟校：两三个家长拿钱出来，总部出品牌和教学支持，家长占49%，总部占51%，一起分校区收益。这套打法在短时间内带来了大量现金流，如果不是疫情退了太多费，还能一直转下去。

离开北京，我一路去了青岛、东莞，直营校、线上直播、加盟都试过。到头来发现，所有模式都卡在同一关：获客。所以我就想，与其自己一家家校区去折腾，不如专门帮校区获客。市场早就有人这么干了，而且干得简单粗暴。

他们的方法就是地推。一队人，拎着传单，堵在学校门口、公园和街上，目标只有一个：劝家长花9.9元听一节学习公开课。话术是提前磨好的，大部分家长都愿意掏这九块九。20个人的队伍，一周能攒下600个邀约，到场率大概七成，现场成交率在三到五成。算下来，一周就是一百二三十个学生。

校区一听就心动：你只需要提供会场，其他全包，七天之內就能往你校区送进一百个新生，直接带给你几十万现金流。80%的校区都不会拒绝。利润怎么分？学费55分成，按最低4000元客单价算，团队一单拿走2000。销售拿1200，讲师拿300，落回团队长手里500。一周100单，团队长进账5万，整个盘子就是四十万流水，校区拿走一半。有本事的团队长一人同时盯着近10支队伍，一周50万到手。2019年前后，厉害的团队长一年赚上千万不稀奇，讲师年薪几百万也常见，就连普通销售，一年也能奔着百万去。现在行情弱了点，但依然有的赚。

这套模式最厉害的地方在于：整个团队没有一分钱底薪，吃住路费全是自己出。凭什么？凭高提成、高成交率。销售一周约来二三十个家长，有八个人交钱，一单1200，周薪就逼近一万。讲师更爽，20人团队按40%成交率算，300个到访家长能成交120人，一单提300，周入三万六。为了保证成交率，每周从周五晚到周日排七场会，同时养着两个讲师，谁状态好谁上。这样一来，所有人的利益都被死死绑在一起。

现在我已经改了玩法：不再只是帮校区招生，而是自己招、自己交付。同样的地推套路，引流目标换成了冬夏令营，学生招来后由我们自己集中交付。优势很明显：交付周期短了，退费风险低了，也不再看校长脸色。目前每周能稳定进二三十个新生源，利润比之前薄，但胜在省心和可控。我现在一年大约交付2000多名学生。

做了这么多年，我的核心感受就一句话：你能赚多少钱的上限，由获客能力决定；你能在这个行业走多远，才看交付质量。很多人把课程质量当成增收核心，这个思维在非刚需培训里是站不住的——家长不会因为课好就永远买单。你真正要练的，是一套把面前的人“现场拿下”的本事。渠道只是入口，成交流程才是生死线。我们现在的团队，手里就握着一套成熟的会销系统：课件、讲师、话术，缺一不可。靠着高成交率，我们甚至能和线下教育综合体、学校公益讲座之类的渠道合作，把他们的流量转化成我们的学员。

如果正在做校区的你也想抄作业，我建议分两步走。

第一步，先练出一支能打公开课的队伍。新招的课程顾问不用急着考核成交，改考核到访。每周定好精准客户的到访数量，把人和客户约进校区后，由有潜力的老师上公开课。不管是两个人的小场还是十个人的大场，统一用“公开课+谈单”的流程。公开课要设计得非常细：课程讲什么、体系怎么搭、能解决家长的什么焦虑、对孩子有什么实际帮助，以及怎么把家长的顾虑一一打消。销售在旁边旁听，跟讲师打配合，每场结束马上复盘。一般来说，五场之后，整个团队的能力就会有质变。

第二步，对外合作时，只认成交率说话。等公开课体系跑顺了，你可以去试“会销+营地交付”的模式，但前提是有资源。怎么攒资源？先找教育行业里还没跑通的同行，带团队上门，谈内部生源转化。这个谈判不需要你有太多背景，只需要一套高成交率的打法。你会发现，推开一扇门，里面坐着一群人，总有一个人会领着你走向下一扇门，那扇门里又是一群新的人。当你能持续帮别人变现，资源就会主动往你手里涌。

最后说说赛道。很多看起来冷门的领域，都有过清晰的爆发窗口。魔方刚火的时候，相关产品一夜卖爆；十年前记忆、专注、思维类课程刚进国内，大家觉得新鲜，又能解决背书记不住的问题，立即成了爆款；前几年编程课，同样在大城市卖得风生水起。一个教育产品，只要同时具备这四点：解决学生的真实痛点，提供可感知的价值，对学习或未来成长有帮助，而且还有新鲜感，它就具备成为暴利爆款的潜质。你要是发现了，别犹豫，拼命往里面钻，趁它还没普及，先把第一桶金赚到手。

冷门不是坏事，它只是还没被多数人看见。等你看见了，故事就不一样了。
