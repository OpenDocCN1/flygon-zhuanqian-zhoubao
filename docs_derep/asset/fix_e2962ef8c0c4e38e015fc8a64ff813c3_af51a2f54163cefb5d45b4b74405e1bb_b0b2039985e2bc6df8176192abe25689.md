# 聊聊机器人流程自动化：一个程序员的经验与免费工具

土豆是我的代号，主业写代码，今年四月份开始尝试独立接单。有意思的是，早在那之前，我已经做过不少能自动运行的脚本，只是不知道业内管这叫“RPA”。早年我沉迷游戏外挂，就用按键脚本工具写自动操作；后来在单位成天和表格打交道，接触了VBA，搞出一套自动出文书的系统；再往后，我开始使用 Python。从那时起，很多实用小软件都被我逐个写了出来。

## RPA 能做什么，现在处于什么状况

所谓流程自动化，通俗说，就是让电脑或手机按照预先写好的规则，代替人去点击、填写、滚动页面。可选的实现方案不少：影刀、UiBot、自己写代码等都是常见路线。如果你是编程新手，影刀的可视化操作显然更友好；但对我来说，直接写代码往往更加高效、更整洁。

移动端也有不少自动化路子，比如一个叫 uiautomator2 的库，能通过电脑向多台手机同时派发任务，而且识别控件的能力很强；影刀自己也提供手机自动化方案；安卓系统原生也有 Accessibility 服务，此外还可以用 adb 指令。这里不展开讲。

影刀和 Python 的关系很特殊——影刀的内核是 Python，因此两者能互相借用能力：影刀里可以新建 Python 扩展模块来调用外部库；反过来，把 Python 写好的功能封装好，也能拿给影刀使用。不过兼容性是有边界的——标准库通常没事，自定义库往往不行；封装好的模块在影刀里运行时，也时有遇到路径报错。

## 怎么在日常中把自动化用到极致

先回答一个问题：RPA 就一定要全自动吗？我觉得未必。拿抓取小红书笔记来说，你可以设计一套循环流程，让程序在后台不停采集；也可以自己在屏幕上浏览，看到满意的就按一个快捷键，立刻保存下笔记和作者的完整资料。第一种当然省事，可是遇到主观判断很强的需求，固定条件很难做到那么贴切；第二种虽然要人工介入，但更灵活，而且效率一点不差——真正浪费时间的是复制粘贴、汇总整理，随手保存把这些琐碎动作全干掉了。

再一个问题：是不是只有重复、枯燥的工作才用得上自动化？不是。直接录屏并收音、拿走素材、给文件加密或解密，这些都可以算作广义的自动化。而且这样做不用安装第三方工具（很多还收费），不用担心数据传出去，又能随时按自己的需求加新功能。

说一个看起来很鸡肋的例子：导出微信群全部成员昵称。假设你为了推广业务拉了个群，其中一部分人是某付费流量渠道A带来的，你很想知道除了A渠道之外，有多少人是通过分享推荐进来的，具体是哪些人——这关系到你还要不要继续在A上花钱，以及要不要给额外的人群提供针对性服务。这时，只要把全部群成员名单拿出来，再和A渠道的名单做个对比，答案马上就能看出来。这其实已经算是一次运营数据分析。

## 怎么才能成为这个领域的高手

所谓高手，没有统一标准。眼下用RPA的人很多，水平差异挺大。入门一些的人，连条件判断、循环、变量都还没用熟；中等水平的人能熟练使用图形化界面拼出简单脚本；再往上，就能自己写代码、做复杂流程封装、引入第三方开源框架、把程序打包成exe文件到处分发。不同段位的人，能做的事情完全不一样。

以影刀为例，有几个功能你可能不知道。比如，你的脚本其实可以使用语音来播报运行进度，这样程序出错时你能第一时间知道，不用一直盯着屏幕。前提是你知道这个工具的扩展模块里能调用系统声音接口（winsound），也愿意用剪映把文字变成音频。如果没人提醒，自己摸索通常要花很久；但知道了以后，照着做就很快。新建一个名为 PlaySound 的模块，然后在主流程里调用就行，效果见图：

所以说，高手是长期磨练出来的，得靠不断学习来消除信息差。具体怎么学？如果影刀或UiBot已经能覆盖你九成的需求，而且你出脚本的速度也够快，那专心把其中一个玩熟就足够了，这类工具内置了大量常用组件，基本拿来就能用。但如果你想突破工具本身的限制——比如绕过它的一些复制约束、实现更个性化的界面、把脚本打包成自己的exe去对外售卖——那就得学编程语言。

首选就是 Python。原因有三点：

1. 能力强。在自动化这个圈子里，它基本上是天花板，硬要抬杠的话，也只有C语言这类底层语言能争一下。而且它不只玩转自动化，像聊天机器人、AI绘画、视频处理等热门方向，都有对应的库可用。

2. 够主流。它是全球流行度最高的编程语言之一，如果只看自动化、人工智能、辅助工具这几个细分领域，甚至可以把“之一”去掉。UiBot内置的是VBA，这比不上 Python，其他小众语言更不推荐。它的语法干净、容易上手，这是我学过Java、VBA和C之后的切身体会。

3. 和影刀的契合度高。这个工具本身就是用这门语言开发的，所以原则上你写的代码都能搬进去用。把这门编程语文学透，等于是把影刀也吃透了；之后再去看其他自动化产品，基本都能举一反三。

自学渠道也很成熟：官方文档里关于影刀的内容值得通读，菜鸟教程的 Python3 专题也合适初学者。平时可以多逛技术论坛、加几个开发者群，别自己闷头造车。有时候一个卡了很久的问题，别人一句话就点通了。

   - 提取页面元素的XPath
