# 操盘超两百个 ChatGPT 实例后，我的实战复盘

> 原文：[`www.yuque.com/for_lazy/thfiu8/owlwlozaiqmxqgfn`](https://www.yuque.com/for_lazy/thfiu8/owlwlozaiqmxqgfn)

认识一下，我是云飞，深度参与生财社区将近四年，现带一个十五六人的创业小组在运作。ChatGPT 的应用探索我从去年十二月就开始推进，算下来已经摸索了四个月有余。

在我看来，随着接入成本越来越低，能否真正把模型变成可用的工作利器，归根结底取决于指令打磨的细致程度。

本次梳理分两大部分。第一部分，把先前在社群里提及过的 ChatGPT 训练三大杠杆展开讲透。第二部分，直接给出六条可落地的实操做法。

先聊三大杠杆的底层判断，本质是三组取向差异：

1. 系统能理解口语化逻辑描述，但对程序化逻辑描述的响应更稳定；
2. 系统可以读懂通俗表达，却对行业专业用语的指令更遵从；
3. 系统支持中文输入，但英文输入的命中率更高。

最终输出的质量与准确性，高度取决于这三点取向的拿捏。
