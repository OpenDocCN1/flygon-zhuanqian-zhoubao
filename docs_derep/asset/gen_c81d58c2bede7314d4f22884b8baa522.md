# 0 基础起步，两周做出网站：一个普通人的 AI 编程成长记录

作者：李澹归  
日期：2025-06-08

如果一个完全不会编程的人，开始尝试用 AI 做网站，两周时间能走到哪一步？

最近我跟着小排老师学习网站开发，虽然起点几乎是零基础，但这段经历让我对“如何做产品”“怎样和 AI 沟通完成编程任务”有了不少新的认识，也遇到了一些很有意思的问题。

这篇内容主要复盘几个方面：

- 一个普通人学习产品和编程时，成长路径应该如何规划；
- 怎样通过更有效的人机交互，让 AI 真正帮助自己完成开发；
- 如何借助 Cursor 复刻网站、定位问题并逐步修复 Bug；
- Cursor 暴露出的系统提示词，究竟能带来哪些启发；
- MCP 是否可能成为下一阶段值得关注的方向。

如果你正在学习 AI，或者也在尝试做网站，欢迎一起交流。对很多人来说，这或许不只是一个工具升级，而可能是一场新的技术变革。

**刘小排：**

**李澹归：**

感谢老师回复。

确实，不是所有人都需要直接接触 MCP。他们真正需要的，是一个能够帮自己解决问题、操作足够简单的工具。

比如豆包、DeepSeek 在国内的普及度已经很高，但很多人可能还没用过 Claude 或 GPT。假如能把 MCP 封装成更直观的前端页面，再配合一套完善的系统提示词，让模型自动理解需求、调用工具，就有机会把复杂流程变成普通人也能使用的产品。

有点像是在扣子空间的基础上，再增加一步大模型分析，让 AI 先判断目标，再推导出具体的执行路径，进一步实现 A2A。
