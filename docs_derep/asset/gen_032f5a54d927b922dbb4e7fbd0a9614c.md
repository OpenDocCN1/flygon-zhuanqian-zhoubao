# 一年前，我还在原地打转；一年后，我成了教练、有了IP：哪有什么逆袭，不过是把每一步都走成了路

> 去年七月，我还是一名设计师，如今我多了一串身份：运营、副业跑通者、mini航海教练、IP主理人。这几个词连起来，像是一条精心规划的进阶路线。可回头看，我哪有什么高瞻远瞩，只不过是在被生活推着走的过程中，每一次都没有放手罢了。

我统称它为“普通女孩的波折成长史”。

这不是一份成功学案例，更不是用来证明谁有多光鲜。我只想借这段经历说一句掏心窝子的实话：赚钱从来不应该是答案本身，真正值得奔赴的，是用你看到的、学到的一切，让自己活得更接近喜欢的样子。

**从浏阳到杭州：逃离，是挣脱束缚的第一步**

我从来不是什么热血青年，逃去大城市，一开始纯粹是被“不甘心”逼出来的。

我出生在不算穷、却让人极其压抑的家庭。父亲脾气像火药桶，重男轻女藏在日常细节里。初三那年，他告诉我，以后要招婿入赘，延续族谱。那一刻我浑身冰凉：我的人生，原来早就不属于我。

连婚姻、生孩子都不由自己做主，我怎么可能认命？就算毛没长齐，我也知道一定要跑出去。

其实经济账也是明摆着的。浏阳的工资低得可怜，平面设计拼死拼活也就四五千；长沙好一点，顶天六七千，可两地的消费水平都是“一线”。我想赚钱、想独立、想成长、想自由，于是把目光投向了杭州。这里有熟人，有补贴，当时电商设计的势头也算热闹。我像所有背井离乡的人一样，满怀憧憬地冲了过去。

[PRE1]

现实当头一棒。杭州的电商设计早就挤上了末班车。

上百份简历石沉大海，从刚开始喊出6-8k的底气，到后来磨得只剩妥协。最后我进了一家阿里外包公司，月薪四千，通勤来回四小时。

但即便只是外包，大厂的设计项目还是让我扎扎实实感受到了小城市永远给不了的视野。

[PRE2]

屋漏偏逢连夜雨。刚入职，医保还没生效，我因为喂流浪猫被抓去打狂犬疫苗，五针花了800块——对当时的我来说，那几乎是半个月工资。日子紧巴得让人发笑。

[PRE3] [PRE4]

带我的是个脾气火爆的女生，每次问点什么都像点炸药包。公司上下都觉得我撑不过一周，结果我硬是把她熬走了。后来有人跟我说：“没想到你能坚持这么久。”那一刻，我心里特别爽。

可代价也是实打实的：设计稿改到凌晨两三点是家常便饭；深夜加班完没有地铁，只能自费打车回家；没有加班费，也没有报销。父母什么都不知道，我只报喜不报忧。我受不了那句“早就告诉过你，撑不住的”——我想证明给他们看，只要我想站住脚，我就能站住脚。

我笃定，更大的城市、更高的信息密度，才有机会真正改变命运。

**从设计到运营：没有白走的路，每一步都算数**

毕业第二年，我在生财做着品牌设计，却陷入了一场旷日持久的自我怀疑。

设计曾是我的热爱，每个作品都像我的孩子。但现实很骨感：审美这东西太主观，客户一句“不喜欢”就能推翻你一周的心血；做了图有没有价值，还要看运营、看流量、看推广；至于职业天花板，想想也知道，到头来不过是开个乙方公司，继续循环重复。

无力感像潮水，一天天上涨。我开始想：也许靠设计，永远到不了我想要的生活。

那个帮我开口的人是我的上司小花。她问我：“要不要试试运营？”

就这五个字，像火柴划亮了困住我的黑屋子。其实我早就想转，只是害怕。害怕丢掉学了几年的专业，害怕从零开始，害怕万一失败怎么办。

[PRE6]

可小花替我说出了那句话，还替我争取机会。那一刻我突然松了一口气，心里浮现四个字：破釜沉舟。与其被恐惧困在原地，不如背水一战，试一试才知道自己行不行。

刚转岗时，我就像掉进外星世界。私域、陪跑、转化、引流、客单……每个词都听不懂。第一次写复盘，磨了整整三天，盯着“提交”按钮始终按不下去。第一次开会，全桌人侃侃而谈，我一句插不上，只能拼命记笔记。还有一次整理数据报表，研究了两天交上去，同事温柔地提醒：“很认真，但逻辑不太对。”那一刻我仿佛回到刚实习时的窘迫。

但玩命学的同时，我也慢慢发现：设计经验并没有作废，反而成了我的秘密武器。

做活动时我天然带着“用户体验”思维，会想用户第一眼看到什么、流程卡在哪里；我对版式色彩敏感，对接宣传物料得心应手，有些活儿干脆自己上手搞定；我有耐心死磕细节，这在运营执行里成了闪光点。

我忽然懂了：过去的经历，从来不会辜负你。它们只是换个姿势，在未来的某个节点悄悄帮你。

转岗不是职业的断裂，而是一次重启。它让我明白：不必害怕推翻重来，新能力会慢慢长出来；过去的积累不是负担，它会变成隐形优势；命运偶尔会借着别人的手推你一下，你要做的就是——等机会来的时候，死死抓住它。

**破局唯一的方法，是把执行力当成信仰**

转岗后我发现，光当运营还不够。生财的土壤太肥沃了，身边所有人都在往前跑，我不想只当一个观众。毕业第三年，我给自己下了死命令：四个月内必须跑通一个项目，干不成，就滚回老家。

如果拿不出成绩，父母只会说我瞎折腾。与其听那些冷言冷语，不如逼自己一把。我把这个想法告诉了直属上司纪钟，他没有笑话我，还帮我把目标拆得更细了。

刚开始我试小红书商单、百货电商，整整折腾了一个半月。要么跑得太慢，要么毫无起色。投入的时间成本太高，根本不适合我“快速跑通”的预期。那段日子，白天工作晚上副业，手机刷到麻木，笔记发到崩溃，反馈却是零星半点，焦虑攒到几乎要压垮我。

[PRE8] [PRE9] [PRE10] [PRE11] [PRE12]

转机发生在小红书虚拟资料航海。

报名后我提前抢跑了一周，每天发十几篇笔记，仍然石沉大海。心态摇摇欲坠时，我抱着死马当活马医的想法，把我的卡点发给群里答疑的教练希平。结果他直接给我打来电话。

我在地铁上，手机震起来的时候整个人都愣住了。电话那头他说的第一句话是：“你的执行力特别强。”

我呆住了。我一直以为全力以赴是理所当然的事，怎么到他嘴里就成了难得的品质？那通电话让我忽然觉得：也许我没有自己想象中那么差。

随后他给了我一份调研表，让我别再闭门造车。当天回家，我加同行进私域、翻朋友圈、拆解话术，一项项填进去，差不多把全部精力都砸了进去。做完提交后，指导越来越清晰，方向感终于冒出了头。

[PRE13] [PRE14]

我决定不再广撒网，把重心聚焦到“教师端班主任资料”这个细分领域。理由很朴素：这种资料成交路径短。之前我也做过小红书电商卖红包封面，对“站内成交”有体感，知道这条路轻便高效。于是开了第三个号，把笔记逻辑迁移过去，放弃引流转做电商模式。开店上品，笔记不再是搬运截图，而是实拍、P图、打磨真实感的文案。

[PRE15] [PRE16]

然后，我的笔记爆了。

第一篇爆的时候，手机震到发麻，私信红点密密麻麻，我回消息回到手指抽筋，可心里是甜的。接着是第二篇、第三篇、第四篇，发一篇爆一篇，像拿到了流量密码。那一阵子我经常想哭：原来之前所有的坚持，都没有白费。

那些经验后来都沉淀在一篇精华帖里。但很想说的是，那三个月的心理压力，只有一个词能形容：煎熬。每天早上睁眼就在想今天能不能出单，白天机械刷图发笔记，晚上翻来覆去睡不着。怀疑，坚持，再怀疑，再坚持，一遍遍循环。

有人问我怎么熬下来的。答案仔细想想就一句话：执行力就是副业最大的门槛。副业的本质也不是赚快钱，而是学习、实践、复盘、积累商业认知的全过程。那些多出来的投入，最终都会变成你的底气。坚持下去，才等得到自己的转折点。

这段路我踩过很多坑，特别想把两条方法论送给仍然在摸索的人：

第一，初期做项目，一定要允许自己多做、多试。别怕试错，你踩过的每一个坑，未来都可能成为帮别人避坑的经验。

第二，更要紧的是懂得选择。怎么判断选的对不对？从变现周期就能摸出大体轮廓。要是你急需正反馈，一定给自己设一个期限。像小红书商单要涨到1000粉才开放变现，我试了快一个月粉丝才两位数，果断换。百货电商选品靠运气，也与我八字不合。记住：当你强烈需要结果时，给项目一个期限，干不出来就换。

还有人总会问，做副业会不会影响主业？我的逻辑很简单：公司额外给了我资源，我白天高效干完手头的工作，抽空再搞副业，干不完就晚上熬夜补。在外头混，人情世故总得懂，“江湖仗义”这四个字，我爹还是教过我的。

**当教练，是我从“自救”走向“助人”的时刻**

跟钟哥聊项目规划时，他说过一句话：等你了，你就可以像希平帮你一样，去帮其他圈友了。

我的眼睛是瞬间亮起来的。因为自己是新手走过来的，我太知道那些最初始的卡点是什么：方向没定、账号没建、第一篇笔记从哪里开始都摸不着头脑。那种无力感，我比谁都熟悉。

8月5日，我写下一个目标：跑通项目，去做航海教练。9月7日，亦仁和钟哥悄悄建了demo群聊规划，我浑然不知，还在一个人死磕项目，一单未出。

9月20日，志愿者杜阿寻找到鱼丸，说有的圈友执行力拉不起来，需要官方协助。钟哥在那个时候推荐了我。我心里还很慌——毕竟我还没真正出单。可三天后，9月23日，我接到了第一单！

那一刻压在心口的石头落了地，我终于有了底气往前走一步。

可我仍然紧张：我真的能帮到人吗？后来我去调研船员们的卡点，发现99%的问题都集中在那些位置上：方向没定、账号没建、笔记没发、想得多做得少。

钟哥跟我说：“你看他们，是不是跟你刚起步的时候一模一样？但你已经从那个阶段走过来了，你就有能力帮他们了。”

就这么一句话，让我彻底放下了心结。于是，我成了mini航海的第一位教练。上岗后我做了三件事：经验加餐——把踩过的坑整合成方法论，把群里高频问题集中解答，尽量让后来者少走弯路。

因为我比谁都清楚，这条路上最珍贵的，不是结果，是有人愿意拉你一把。
