# 包租婆副业起号笔记：从中介到月入近2万的二房东实操

> 来源：[https://wq71epaod4q.feishu.cn/docx/DvzYduRlVot6DdxNVImcGVWPnvc](https://wq71epaod4q.feishu.cn/docx/DvzYduRlVot6DdxNVImcGVWPnvc)

大家好，我是金珠，目前在浙江嘉兴嘉善的小镇上做二房东，今天聊聊我这条副业是怎么跑起来的。

上个月我分享过我老公开炸鸡店月入10万的经验，感兴趣的可以回看。

上期也提过我兼做二房东的事，评论区有不少朋友追问门道，今天就系统讲一遍。

二房东是我现在的主业之外的延伸收入。

我的本职是房产中介。

那为什么会选择做这条副业？

归根结底因为我是中介出身。

副业最好是主业的自然延伸。

很多朋友不知道副业从哪找，我的思路很简单：看看主业能往外延伸出什么。

比如我把客户带到二房东的房源成交，能收中介费，这是主业本身。自己当二房东，就是把客户带进自己名下的房源成交，同时收中介费再加租金。主业+副业，等于收入翻倍。

* * *

# 一、先有认知，再谈入局

我先说个前提。

主业得先稳。

主业是基本盘，是最主要的现金流。千万别为了搞副业把本职丢了，得不偿失。

副业是加分项，不是必选项。它能帮你增收、让你成长，但如果你连主业都养不活自己，就先别碰。

如果你已经在工作，只想多一份进账，可以先自问三个问题：你愿意每天花多少时间在副业上？愿意投多少钱进去？万一失败，会不会拖累主业？

想清楚了再往下看。

# 二、做得早的二房东，之前大多是这些身份

换个问法：哪类人入行二房东上手最快？

## 1. 装修工

他们给二房东做过改造，房源怎么改收益最大、租客喜欢什么风格、什么价位拿房划算、怎么把房子稳定运营，都门儿清。后续小修小补也能自己省下来。复制前辈的套路就行。

## 2. 中介

和我一样。每天接触房东和租客，二房东本质就是拿别人的房子做差价。拿房、出租全流程都离不开中介。中介清楚什么价格能谈下来、怎么装修、怎么才能租出去。我身边的同事都是先做中介摸清市场，再自己拿房。我也是。

## 3. 身边有做二房东的人

家里人、村里有人在做，直接问就能拿到第一手情报：去哪找房、哪个片区好出租、什么价位有利润、怎么装修好租、什么价格成交快、怎么维系租客不轻易搬走。很多地方做二房东是家族化、村落化操作。相当于开超市时爸就懂，你问一句就通了。有师傅带，成功率比瞎摸索高很多。

## 4. 物业从业者

除了中介，物业也是拿房的重要渠道。物业是小区的管家，知道业主想卖想租、毛坯还是精装。物业手里有一手房源信息，装修动工也得物业批。巴结好物业，天时地利人和基本都在手里。

总结：装修师傅、中介、身边有师傅、物业，这四类人都能直接触达二房东这个人群，流程熟，上手自然快。

# 四、小白适合直接上吗？

说实话，如果你不是上面四种身份，我不建议一上来就冲。

但如果你很想试，可以这样过渡：先去中介公司或物业公司上班，把赛道摸熟，降低试错成本。了解越深，后期越可控。

然后先调研本地是否适合做。

本地能做，你就变身包租婆。条件不匹配硬上，钱和你无缘。

# 五、二线小镇单间租金 realities

生财圈看到云飞大哥1800套年入2000万，那是大盘玩法。

我讲的是小镇入局。

我第一套房是2023年1月15日拿的，8间单间，8×900=7200元/月。

2023年3月4日第二套，7间，7×900=6300元/月。

2023年3月8日第三套，5间，5×800=4000元/月。

三套合计17500元/月，加上电费差价2000+，总收入约1.95万/月。

我拿的是拆迁房，政府赔的老百姓的5层别墅，没房产证。大房东自住，拆迁房拿来出租。

托管比散租更稳。大房东把房子整体托管给中介或二房东，收租金、水电就找一个人。散租的话8间房要对接8个租客，还要处理流动、维修等麻烦。

所以大房东愿意把房子托管出去。

备注：签约5年以上且租金低于市场价的叫托管。签约≤3年、租金为市场价的是散租。

我们小镇单间租金500-1200元，根据配置、装修、位置浮动。

# 六、从0到1的实操纠偏

做中介时就发现二房东总来公司吹牛，又让我帮忙出租。他们时间挺闲，但收入稳定，睡后收入的模式确实吸引人。

作为新人我当时有这些疑问：小镇客源从哪来？怎么拿房？拿什么类型？投多少钱？回报率多少？风险大不大？做单间还是两房？

我特意在淘宝买了几本二房东书，基本是盗版，但有干货就行。

[PRE1]

一周看完，书里说的和我实际操作的差异总结如下：

## 1. 理论：就住处方圆3-5公里找房

实际：租客半夜丢钥匙让我送，夏天跳闸我骑三轮15分钟就到。距离近，打理方便。

## 2. 理论：单间利润>套房

实际：120平3房2卫，装修4万，月租1600，租客自缴水电。6年租金收入115200-40000=75200。

改成5间单间，装修5万，单间800。6年租金288000-50000=238000。电费差价再加2.7万。合计26.5万。

同样房子，产出天差地别。

空置风险怎么解？收违约金，签合同时谈1年免租期，避开春节签约。租房一般一年一签，违约就扣押金。合同在手，租客理亏。

比如800元/月，押一付一，违约押金就没了。签约避开1-2月，可以让租客3月再退，押金已扣，租客不会为1-2个月较真。即便闹事，合同为证。

## 3. 理论：单间配置齐全，最好独立洗衣机

实际：客户入住后才发现要共用洗衣机，觉得不卫生，想换房。但前期没预留管道，改不了。租客体验要提前想到。

## 4. 理论：装修要温馨

实际：刚入行时单间少，差的也能租。后来竞争加剧，装修卷起来了。差的房子空置，温馨的秒租。后期翻新成本翻倍，前期就要做好。

## 5. 理论：一定要搞好中介关系，给点红包

实际：中介就是财神爷，拿房少不了他们。

按书里做，直接拿装修好的单间配独立洗衣机，一步到位，省掉冤枉钱。我是中介，知道价位，拿房价格比别人低，还拿的是原房东装修好的房。

# 七、多少钱能启动？

第一套房是同行老中介给的线索。我跟老前辈说有便宜房源记得通知我，中介费不会少。结果来真的。

别人拿房520元/间，我450元/间，房东全配，免租期6个月，白嫖。

押一付三：450×8×4=14400。

手里只有1.5万，给了大房东1.44万，剩600。但缺洗衣机冰箱。

我先出租变现，签押一付一：8×900=7200租金+7200押金=14400。边收钱边配设备。

洗衣机在二手群里200元/个，冰箱陆续补齐。新的洗衣机600元一个，二手150-300，还被租客糟蹋，不划算。

复盘：同行是最好的老师，资源也是。不是中介的，也务必交好中介。6个月免租期，太香了。

# 八、拿房操作手册

## 1. 选址

生活区3-5公里内有大片厂区

生活区有大学城

生活区周边有大商圈

地铁口、车站周边

人多的地方才有钱，人口流动大的地方就是核心逻辑。北上广起步早也是因为这个。

## 2. 选房型

单间>两房>三房>四房

单间600-900，抗风险强

两房1100-1600，抗风险弱

单间一人住两人住三人住都能接受，两房基本是合租或家庭，这类客户少。

套房和单间租金差距不大，对租客划算，对二房东不划算。

熟手阶段单间套房比例约5:1

新手建议优先免租期长的房源。付不起全款，可以谈押三付一、半年付、年付。手头紧就少付、多要免租期。

新手拿简装，不要毛坯。可以拿原房东装修好的房，自己只补洗衣机就能上。

## 签约年限

6年/8年/10年都可以

有人担心中期不赚钱怎么办？合同写违约金5-8万，但有人直接跑路不赔，最后把房退给房东就算了。合同更多是约束大房东，不是限制自己。

不签长约怎么回本？遇到毛坯房，自己装修，前1-2年回本，后面全是利润。时间越长越赚。

## 客源怎么来

多家联动中介撒网

贴广告、抖音、58端口

给保安门卫红包介绍

物业

## 怎么快回本

免租期拉长，拿装修好的房别拿毛坯

我拿到6个月免租，房子装修好，改造1个月不到，剩下5个月净赚。投入5000改造，租金800，一个月回本。

## 维修

拿房时就加装修师傅微信，后续维修直接找。市场价150，自己给200，后续好办事。自己会修的就更省。

## 合同要点

写清免租期

违约赔偿金

允许自由装修群租房

# 十、最后的话

二房东是细水长流的生意，不是暴富项目。投入多，收入就高，有人50多套年入180万。

我最初目标2间，最后做到20间，裂变很快。

先调研本地能不能做，流程搞明白，有点启动资金就能上。希望这份笔记能帮到想入局的朋友。
