# 大学生用「床品+校园表白墙」半年做到10万+利润，我的0到1复盘

大家好，我是涛，目前在读大二，毕业于一所普通本科院校。可能很多人和我刚上大学时一样，觉得未来会很平淡，但我选择从现在就开始试错。

改变不需要等到新年、新学期，它可以从今天这一步开始。今天就把我过去半年里，用寝室床品三件套搭配校园表白墙实现10万+利润的完整路径拆解出来，也顺便讲讲我是怎么一步步踏上网络创业这条路的，以及加入学习社群一年里对我的影响。

先说下这篇文章会讲到哪几个点：
1. 我从第一次做副业到现在赚到钱的经历线
2. 新生季最吃香的引流、选品、营销到变现全流程拆解
3. 校园表白墙账号从零粉丝到起号，再到后续商业化变现的操作
4. 我对自己未来在校园市场和个人IP方向的规划

整体脉络很简单，就是一个在校生的真实创业样本：抓住开学季新生刚需的床上用品需求，用表白墙这种高信任、高曝光的校园载体做冷启动和信任背书，最终把流量转化成订单，实现10万+的收益。
