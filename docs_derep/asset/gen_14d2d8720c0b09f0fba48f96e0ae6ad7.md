# 一、项目逻辑

整个模式的核心是二次创作。将别的平台的热门视频经过去重处理后发布到小红书，积累到1000粉后通过渠道承接广告变现。品牌方提供成套文案，博主只需按要求发布笔记即可，完全不用原创。合作形式是固定报价，一单多少钱，发了就有钱，不看后续数据结算。有些广告主看效果好还会额外发红包。

经过实地调研和两个月的跑量，这个赛道目前相当空旷。经常出现品牌广告需求排期排满，发不完的情况，市场需求远大于供给。

接商单一直是小红书创作者的痛点：报价低、要求高，还要自己写脚本，收益没有保障。[PRE0]

因此我们花了大量时间去对接各大品牌的投放方，并自建MCN机构。小红书用户以年轻女性为主，付费能力强，对品牌方极具吸引力。有广告主反馈其投流回报比能做到20倍，可见其投放热情。

相比其他项目，小红书接商单上手快、逻辑直白、起号迅速、变现稳定，放大也容易。新手也能快速获得正反馈，内测成员普遍反馈“有手就能做”。普通人完全可以通过此路径实现广告变现。

# 四、项目实操篇

## 1.养号要做足

小红书在公域平台里审核偏严，别用其他平台的养号思路硬套。养号做扎实，后续涨粉会事半功倍。

（1）养号周期三天
（2）前两天每天刷约一小时同领域内容，点赞、评论、收藏、关注比例大致10:3:5:3，模拟真实用户行为，别过度操作
（3）判断标准：进入编辑资料往下看账号等级，若按任务完成仍升不到“北鼻薯”，说明养号失败或账号资质差，基本无流量
（4）第三天再修改简介、昵称、性别、头像、地区、背景图
（5）一个WiFi下最多养三个号
（6）不要用“黑设备”，即曾频繁注销登录或被重度封禁过的设备

## 2.起号方法

起号前先明确可接商单的标准：

（1）粉丝1000+
（2）单条播放稳定破2000
（3）未限流且专业号正常

### 1、影视搬运号

素材来源：挑选其他平台100万粉以下的原创博主，且该博主在小红书无账号。通过名字、头像、作品三重核对。

核对后需确认作品未被搬运过。小红书检索标题，多换关键词搜索。发现同款直接放弃。若视频含淡水印无法去除，也直接放弃。优先选择数据高于账号平均值的作品。

获取同类博主的技巧：抖音快手主页关注页会推荐同领域创作者。

[PRE6]

选材方向：内测最快一天起千粉的账号共性是话题极易引发女性共鸣，评论区活跃。婆媳矛盾、家暴、男女歧视、下头男、出轨、屌丝逆袭、言情、爱国、热播剧等题材效果最佳。选材大于剪辑。

去重手法：
1.增加空镜头覆盖画面，不透明度调至10%，关闭声音
2.添加滤镜，清晰度70-100
3.叠加扫光素材，9:16比例，不透明度10%，声音关闭
4.原视频变速1.1，变调处理，音色音调强度调至10左右，保证不违和
5.覆盖全程BGM，关闭原声
注意剪映素材库素材的声音要关掉，带logo部分裁剪

发布频率：千粉前每天3-5条，千粉后1-2条。最佳时段中午12点左右，傍晚5-8点。

方向：明星综艺+新闻八卦
关键词：明星综艺、明星娱乐、综艺八卦、综艺吃瓜

### 3、盘点类账号，强推

这类属于伪原创，能规避原创度低的问题。由多段小片段组成，通过截取重排、改写开头实现高原创度，操作稍繁琐但效果稳。

剪辑步骤：
1.导入背景图至主轨道
2.背景图加特效如落叶星星，美观不遮挡主体

### 4、泥巴看剧

影视/综艺+解压视频，玩法可延展为解说、搞笑梗等。

原理：寻找无声玩泥巴/史莱姆解压视频，与主领域视频拼接实现95%去重。

操作：抖音搜解压素材，提前设为9:16，上半屏放主内容，下半屏放解压视频。确保解压视频无声。

### 5、星座图文号

数据稳定、原创度高，缺点是涨粉慢需长期坚持。

建议：固定一个星座系列，保证每条都能激活老粉。

组成：抖音快手文案+备忘录排版

实操：
1.多平台搜星座图文/视频素材
2.提取文字
3.用备忘录做背景模板粘贴文字
4.注意排版美观和星座标签突出
5.加滤镜特效、温柔BGM、表情包，发布时间同上
6.优先选评论高赞的素材，重评论区

# 五、接广告的流程：

达标后需满足：
1.粉丝1000+
2.开通蒲公英合作平台两天以上
3.近三天单条播放2000+
4.无断更，续更播放维持2000+
5.账号无限流

步骤一：开通蒲公英，实名认证-选个人-填报价-填微信手机号-选人设标签
步骤二：与广告商前一日沟通好，广告商发邀约，博主在入口提交笔记，审核通过后发布。广告商后台确认订单，未确认订单7天自动确认。发布当天不发其他内容，隐藏低播放笔记。

账号做起来后广告商会主动找上门。也可加入MCN获取更多资源。

# 八、疑难解答

判断限流：
1.连发三条播放均低于200
2.专业号变灰：主页-三条杠-创作中心-更多服务-开通专业号，查看状态
3.账号等级不涨
4.其他账号搜不到你

限流处理：
1.停更两天后试发两条测试播放
2.申诉，部分掉号为流量异常误判
3.注销重建，注意频率和注销次数

报价修改：每月一次，1-25号可修改下月报价

账号注册卡死解决：去营业厅补卡，补卡后编码更新可绕过风控，新手机起号更快。带身份证告知补卡即可。
