# 一、获客：锁定真正有意向的人群

分销第一步不是硬推，而是先找到对社群有真实兴趣的潜在用户。

这次我跑了三条路：

* 私域朋友圈激活
* 跨社群合作，借干货分享引流
* 用官方提供的三天体验卡做全网分发，并搭配付费投放放大

下面拆解每条路的关键和落地方式。

## 社群内引流

要点：
* 意图前置：让对方一开始就清楚你的目的，减少无效沟通。
* 案例落地：不讲虚的认知，而是讲一个可复用的赚钱案例，流程越简单说服力越强。

实操：
* 我在外部社群分享了“心理咨询细分赛道里的抑郁症方向”这个案例，听众能直观感受到价值。

## 朋友圈唤醒

要点：
* 价值具象：把价格、赠品、优惠力度讲透，给出行动理由。
* 成长具象化：晒出自己在「生财有术」里的变化，让潜在用户产生共鸣，看到加入后的可能性。

## 三天体验卡引流：全网铺量+付费放大

要点：
* 提升声量：体验卡能扩大品牌曝光，触达更广人群。
* 付费助推：借助广告等付费渠道扩大触达，提升转化概率。

实操：
* 以体验卡为钩子做多渠道分发，配合付费推广，精准触达对「生财有术」感兴趣的用户，形成稳定流入。

# 二、成交：把意向转化为成员

## 人群分层做1对1转化

当用户进入沟通视野后，核心是把「生财有术」的差异化价值讲透并促成决策。我采用1对1转化模型，把意向用户分为三类，为每类匹配专属话术和推进节奏。

同时结合平台实力背书，以及我个人的实战案例，增强信任感，最终推动成交。

## 成交后做成果报喜

有结果就要有报喜意识，多庆祝才能多成功。

官方为分销成功的种草官设立了种草官俱乐部。我经常在群里同步进展，俱乐部里一位伙伴反馈，正是我持续报喜，给了他信心，他的拉新从十几人提升到了26人。

如果你也完成了分销，记得联系官方加入俱乐部交流经验。

# 三、跟进：让新人加入后有粘性又有变现力

我一直认为成交只是开始。

所有通过我加入的新伙伴，我都会邀请进我的专属陪伴群。群内会定期组织活动，邀请有结果的伙伴做内部分享，营造良好的学习氛围。

后来也有伙伴在群里复盘自己的变现成果，这是很强的正向反馈。

## 群活动：营造活跃氛围

活跃度靠活动维持。我会设计激励性活动，提升成员参与度。

比如“送龙珠碎片”活动，就用奖励机制带动大家参与航海实战。
