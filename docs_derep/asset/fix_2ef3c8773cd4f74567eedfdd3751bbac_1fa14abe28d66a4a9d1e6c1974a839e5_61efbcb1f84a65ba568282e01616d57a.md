# 管理时间的底层逻辑与实操心得

分享者：Erik | 2023.03.28

关于“怎样把日子过得有效率”，我们心里都清楚它有多要紧，可真到执行时，又往往把这一课抛在脑后。

为什么要紧？因为每天可用的时长就那么多，同样的半天，有人能完成好几件事，有人却一直在原地打转，差距就出在利用时间的水平上。

为什么容易忽略？因为市面上有太多听起来头头是道的时间方案，讲起来一套一套的，临到自己安排时，依旧不知从何入手。

我从十几年前起，就在琢磨一件事：怎样建立一套适合自己的节拍，让工作不被拖延，让生活不被侵蚀。  
后来读到 Ray Dalio 的一本书，书里反复强调“先定原则，再优化实践”，这让我一下子找到了方向。  
我的做法很简单：先把少数几条底线定清楚，然后根据真实反馈不断调整动作。久而久之，这套思路被磨得越来越顺手，也形成了一套非常简单、可持续的操作习惯。
