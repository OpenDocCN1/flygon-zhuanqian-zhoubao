# 二、AI代写怎么做出差异化？

进入这个行业，先问自己三个问题：

（1）我们到底能写什么？

（2）写什么最赚钱？

（3）客户从哪里来？

听起来基础，但没入行的人确实不知道能写什么赚钱，入了行的人又常常找不到客户。我下面展开讲讲，看完基本能精准找到突破口。

## 1. 能写什么？

AI代写覆盖的类型太广了，实操中会遇到这些常见方向：

（1）给学生、企业人员、老师写演讲稿、新闻稿、读后感、征文、发言稿、报告总结；

（2）给学生写情书、道歉信、感谢信、节日祝福、诗歌、作业；

（3）在小红书、闲鱼接广告策划、宣传软文、短视频文案、笔记文案；

（4）在BOSS直聘、小红书上接详情页文案、剧本、脚本、影视解说。

这些都是小营收点。利润更高的有学术类，比如论文、文献综述、开题报告、研究报告，以及商业类的回忆录、公文、会议纪要、思想汇报、商业计划书。

看起来范围已经很广了，但这还只是大方向。真正赚钱的，是继续往下切细分赛道。

## 3. 客户在哪里？

哪里有文字需求，哪里就有市场。互联网就是流量洼地。接单类型大概分两类：

**一级市场，被动接单。** 擅长运营的圈友，建议去能接到一手单的平台，客户直接咨询成交，利润更大。我们开店的经历中，能随时接一手单的平台有淘宝、拼多多、闲鱼、小红书、抖音、视频号、校园贴吧、校园表白墙等。这些在航海手册里都有。

**二级市场，主动接单。** 找机构或文案公司合作，稳定接他们派下来的单子。平台也不少，比如天猫店、拼多多店、百度、抖音、BOSS直聘、智联招聘等。操作思路是一样的：去平台应聘，接他们的单。
