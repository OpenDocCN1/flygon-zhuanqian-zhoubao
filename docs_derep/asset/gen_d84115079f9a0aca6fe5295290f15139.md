# 一、遇到盖洛普前的我

我的童年在南方大山里度过，是个地地道道的山里姑娘。小时候最爱往自然里钻，漫山遍野地寻宝：跟着哥哥姐姐摘野果，给兔子拔野菜，再挖几根鲜笋。[PRE2]

虽然父母就在身边，但我们一直住在他们工作的工厂宿舍里。他们忙于谋生，我很早就学会了独立。虽然羡慕别人有父母陪，但我从未抱怨。身边人让我懂得生活不易，尤其是那些条件不好的人。所以我的体谅和积极才干会这么靠前，也就不奇怪了。[PRE3]

那在遇到盖洛普之前，我究竟是什么样的呢？

**第一，没有目标，拧巴，想赚钱，也想实现自我价值，却找不到抓手。** 只能靠适应才干硬扛，选择（被迫）躺平，再自我安慰。2022到2023年，盖洛普还没出现，我的世界一片灰暗，又跌进人生低谷。工作不像样的，感情连续两次落空，良人难遇。对关系建立靠前的我来说，情伤打击特别大，一度陷入自我怀疑。加上30岁门槛逼近，压力压得我喘不过气，却又逃不掉。我想多赚点钱，让家人和自己过得更好，还想还清欠爸妈的钱，更想给自己一个有趣自在的人生。有很长一段时间，我甚至觉得，自己只配浑浑噩噩过一辈子吧。

**第二，主业和我的靠前才干完全反着来，痛苦却躲不开。** 我热爱旅行，喜欢和不同背景的人打交道，但赚钱能力不够，只能按部就班打卡上班，拿固定工资，还不敢辞职。我的主业是天天写报告，这对关系建立靠前的人来说，真的特别难熬。下班后也没特别的爱好缓解，只能靠电视剧麻痹自己。每天做着一份高度耗能的工作，又不敢再任性地辞职，因为家里几乎都是老弱病残，全家就我一个劳动力。

**第三，作为小白，两个月换了三个定位，没结果，只剩下焦虑和内耗。** 作为关系建立靠前的人，没有教练的宏观视角，又不够了解自己，真的很容易在商业路上迷失，乱付费，越学越乱，越学越没结果，我就是活生生的例子。加上完美才干被过度发挥，在知识付费上越走越远。我买了不少高客单产品，虽然进了高能量圈子，但以我当时的需求和能力，这并不理智。因为我是纯小白，没有专业技能，智商也就平均水平，根本没法立刻用好那些资源。那时候情绪也不稳，经常自我感动、内心戏多，陷入严重内耗。

去年9月起，短短两个月我换了三次定位：从留学IP到小红书自媒体IP运营，再到儿童英语启蒙。每次我都果断开始，乐观启动，然后很快坚持不下去。我知道坚持很重要，但就是做不到。身边有贵人能告诉我怎么赚钱，可他们不懂我的内心；连我自己都不知道自己真正渴望什么。后来才明白，是因为我的自我认知和商业认知都不够，哪怕我经常自省，哪怕我是商科本硕。

2023年我确实有过变现，但都不稳定，更多靠运气和别人的光环。所以我常感到焦虑，因为不知道下一步该做什么、怎么做。我意识到，我需要有人手把手引导我，给我保姆级支持，否则就会迷失、内耗。我渴望早日实现自我价值，为自己和家人提供物质和精神支持。但那时候，我根本不知道从哪里开始。

直到我遇到优势导师，系统学习了盖洛普公开课后，才终于看到一束光，找到了那只“抓手”。

其实我很早就听说过盖洛普，刚开始还很抵触，觉得和MBTI差不多，测了也没用。当时也自以为挺了解自己，不需要再做测评。很多人都会陷入这样的僵化思维：觉得盖洛普这类优势测评没用，心里想“做了又能怎样？认识自己然后呢？我更关心解决方案”“不想被测评定义”。[PRE4]

但后来我懂了：对自己看得越透，行动就会越稳。现在我可以很坦然地说，是盖洛普拯救了我。当然，一路上也少不了贵人的托举。

# 二、盖洛普的核心理念

你可能也会有这种感觉：不满足现状，想改变却不知从哪开始；羡慕别人成功，明明自己条件也不差，怎么就不顺呢？其实这很正常，尤其到了30到50岁，社会对我们期望更高，犯错代价也更大。我们有时候连自己擅长什么、想要什么都不知道，自然很难找到合适的工作和生活。

心理学家卡尔·罗杰斯说：“人的一切问题，都在于不了解怎样看待自己。”荣格也说：“潜意识正在操控你的人生，你却称之为命运。”

性格决定命运。你的性格塑造你的选择，选择决定行动，行动决定结果，结果决定命运。想掌控命运，就得从了解自己开始。

盖洛普优势测评，就是帮你更好地看清自己、发现和培养优势的工具。它源自美国盖洛普公司，基于积极心理学，经过多年研究和数百万人的调查，在2001年发布，所以也被称为“科学算命”。全球已有超过3000万人做过测评，两个人前五才干完全相同的概率只有3300万分之一。这样的颗粒度和信效度，真不是其他测评能比的。

成功的道路千千万，但成功者有个共同点：扬长避短。不了解自己，就像捧着金饭碗，却做着乞丐的营生。

测评报告会告诉你独有的四大才干领域和34项才干的排序。[PRE5]

“才干”就是我们自然而然的思维、感受和行为方式，是我们的个人特质，是本色。我们每天的选择和对外界的反应，大多出于习惯，也就是“才干”的作用。简单来说：

执行力强的人，像“紫衣侠”，擅长把想法落地，在具体事务和执行上有很大潜力。  
影响力强的人，像“橙贵人”，存在感强，天生喜欢C位，让人无法忽视。  
关系建立强的人，像“蓝精灵”，擅长建立牢固关系，把团队凝聚起来。  
战略思维强的人，像“绿巨人”，善于收集和分析信息，挖掘本质规律，做出明智决策。

性格背后就是才干。比如有人从小独来独往、爱思考，很可能战略思维靠前。满足前十才干，会让人觉得激励和充电；一旦不满足，就痛苦耗能。所谓“成也才干，败也才干”：发挥好了，才干变成优势——也就是“持续保持近乎完美表现的能力”，成为个人核心竞争力；发挥不好，才干就成了弱点，变成绊脚石。

这是我的盖洛普才干图，大家能清楚看到，我是关系建立+影响力才干领域比较突出的。[PRE6]

很多学员会问我：“花花，我前15才干里没有销冠三件套——取悦、沟通、个别，是不是就当不了好销售？”答案真不一定。哪怕你有销冠三件套，如果没有发挥好、把它们变成优势，照样成不了销冠。当我们不了解自己时，看到别人行为不符合期待，容易责怪对方；其实对方可能只是有不同的想法和能力。了解别人的内心需求，沟通和达成目标都会更容易。如果彼此需要都能被满足，很多矛盾自然就消解了。知己知彼，百战百胜。

# 三、优势聚焦，快速跑通0-1三步曲

测评报告里的才干是中性的，它们未必已经是你的优势，因为优势=才干×投入。所谓优势，就是保持近乎完美表现的能力，也就是大家常说的核心竞争力。

拿优势教练这个赛道举例，我的学员普遍能在2到6个月内跑通商业闭环。我为什么能1个月左右就快速跑通？因为我把自己的成就、完美、行动和积极发挥到了极致。[PRE7]

**第一步，用2到3周时间，系统学完一项可直接变现的专业技能。** 那段时间我不管多忙多累，都全身心扑在学习上。我把每天的碎片时间全用上：上下班路上、午休、睡前，还有周末。我不刷社交媒体，每天至少发三条朋友圈，哪怕没人看也照发。整个过程安排得满满当当，身体虽然累，精神却特别充实，一点不焦虑。每完成一个学习目标，都有满满的成就感。越学越被每个人的不同才干吸引。

**第二步，不会咨询怎么办？疯狂听前辈的咨询督导录音，再对照导师给的SOP和话术，慢慢摸索出适合自己的咨询风格。** 我先找了三个志愿者练手，后来又去朋友圈招募公益咨询对象。终于，1月23号我迎来了第一个付费咨询，收入9.9元。现在我的咨询费已经涨到499元每小时。到目前为止，我已经为近50人提供了咨询，累计花了100多小时在这件事上。我只要一有机会，就主动向优势导师申请录音拆解，想尽办法快速提升专业能力。现在，只要涉及专业领域，我都充满自信和自豪。

**第三步，通过参加每月的商业行动营，主动给自己创造适合持续行动的环境。** 每天跟着行动营的优势教练们一起实践专业知识和商业知识，慢慢把商业闭环四大环节——产品、流量、成交、交付——的SOP都内化了，正反馈也越来越多。我也第一时间申请1v1成交拆解，让拿到结果的人帮我看思维bug，然后复盘、再练。

就这样，我用1个月+跑通闭环，差不多3个月+就实打实赚回了2万学费。

所以“投入”真的非常重要。才干是你的潜力所在，前十才干是你的十把宝剑，决定你的优势或劣势。但如果没有足够的投入，不学习、不练习、不实践，十把宝剑也会变成废铁。盖洛普可以帮你找到根本问题，但了解问题不等于解决问题。你要做的是：通过测评了解自己、接纳自己和他人、管理情绪、投入改变，打造核心优势。

如果你没有决心改变命运，没有想成为更高版本自己的渴望，那真的不必继续看下去。承认自己想要的，为此投入时间和精力，这才是靠谱的做法。

正如我的贵人梁靠谱所说：“有条件作恶但从不作恶，有条件放纵也极少放纵，斯人若彩虹，遇上方知有。”她还说：“一个人的幡然醒悟，1%靠别人的劝说，99%靠千刀万剐。”而通过了解和实践盖洛普，你起码能少被剐几刀。

盖洛普测评码，官网价格445元，找教练购买410元。越早完成测评，越早培养自我认知和接纳他人的能力，就能越早打造核心竞争力，早一点打开财富之门。

# 四、选行业赛道的三点心法

如果你是小白，尽量选择蓝海赛道。但选了行业赛道不代表你已经定了定位。想成功，最好先选一个你热爱的行业；如果没有热爱的，就选喜欢的，而不是只看钱。

以下三点很关键：

第一，行业趋势要和你的优势匹配。找到适合你的行业，再结合你擅长的东西。

第二，注意行业的长期前景、是否符合道德标准、社会认可度和门槛。确保你能长期坚持下去，不会轻易放弃。

第三，选一个需要跟人打交道、难以被AI取代的方向。比如咨询师、护理、养老院、保险等领域就不错，因为它们需要人的情感和管理能力。对普通人来说，AI更适合做提效工具，而不是副业基本盘。

# 五、副业定位的两个五部曲

做副业，光知道优势定位还不够，商业认知同样重要。副业或创业都需要个人定位，因为它能帮你明确自己的独特优势和价值，从而在市场上找到位置。

如果用一场戏来比喻人生，前半场是打工攒钱，后半场就是用自己的方式实现自我价值。通过副业或创业，你可以做自己擅长、热爱、对他人有用的事情来赚钱，优势才能更好地发挥出来。

个人IP不是单纯的立人设或贴标签，而是你的优势和天赋的映射。做个人IP就是做自己。当你有了个人IP，别人就是在为“你这个人”买单。定位就像你存在的根基和自信的来源，没有定位就会失焦。如果不明确自己的位置，就会随波逐流，长期下去一定出问题。所以，明确个人定位很重要，它能让你更专注、更自信地追目标。

## 你对定位感到困惑的真相

90%的人卡在定位上，但你可能不知道：你缺的不是定位，而是基于自身优势的商业模式。

人们都在找定位，到底在找什么？又在怕什么？其实，找的是“一定能成的路”，怕的是“付出没有回报”。而高手，既能接纳外界的不确定，也对自己的价值非常笃定。我在系统学习盖洛普教练技术之前，自我价值感几乎为零，因为我没有一项专业技能傍身。

那么，定位应该从两个角度切入：商业角度和优势角度。

## 商业化的个人定位怎么做？

简单，回答五个问题：

Who：为谁？客户画像要垂直，还要有付费能力。  
What：提供什么产品/服务？记住：少则精，多则惑，创业=取舍。你得有一门主打产品，不能什么都做、什么都卖，那样只会让人觉得你不专业。就像开店，必须有个明星产品让人记住你，否则就像泥牛入海。好产品是可以卖10年的长销品，比如可乐、老干妈、肯德基、iPhone、茅台。如果一个产品不赚钱就直接换产品，那你的底层商业逻辑就搞错了。  
What：解决什么问题？什么客户需求/痛点？兴趣vs刚需？要记住，只有刚需才能带来高客单成交。  
Why：客户为什么选你？看你的IP、印象、背书（职业/学历/认证/成就事件）、案例、差异化、客户痛点和方案的契合度。  
How：如何赚钱？怎么离钱更近？离钱最近的就是销售环节。

## 优势化的个人定位怎么做？

无论你擅长什么，活出自己，就能产生影响力。影响力会给你带来贵人和财富。要注意表里如一，生活=创业，做个人IP=做自己。

同一个教练，也可以有不同的优势定位；每个人还可以有多个优势：

战略思维靠前：专业能力者，靠逻辑、专业、认知；  
关系建立靠前：人际链接者，靠敏感、温暖、情绪价值；  
执行力靠前：高效执行者，靠计划、执行、推动；  
影响力靠前：扩大影响者，靠带领、影响、改变。

定位，就是把你的优势最大化。那短板怎么办？可以通过优势互补（合作），或者付费解决。

很多人问我：“花花老师，我是xx才干类型，适合做什么工作/赛道？”优势不能100%解决这个问题，我们需要看整体。但盖洛普一定能帮你避坑！才干/才干类型能告诉你：你不适合做哪些事，因为内心难受、不擅长，所以会坚持不下来，半途而废，“天生不爱干”。
