# 十日冲刺：从冷启动到日入六千，直播间同时在线破万，我踩的点

来源：https://fgsd3oxjki.feishu.cn/docx/Lg2vd5GWHoqhBbxuT5LcThEpncb

打招呼，我是姚麻。好一阵子没在生财社区做正经复盘了。刚把多多短视频的盘子收掉，就把重心挪到了视频号上来做验证。念头产生在15号，17号首条内容正式上线，算到27号晚上，累计佣金到手6201元，单条峰值播放达到310万，首场直播同时在线也冲破一万。

今天发的素材全在审核、直播间也空了，正好收到上船通知，就把过去十天的操作路径和思考沉淀一下。先公开感谢李诚老师，上一期航海我没跟上，但老师依旧抽时间帮我厘清了不少细节，等款项到账一定重谢。

一、启动阶段做了哪些事

15号萌生想法时，我刚处理完手头的多多账号，接下来测什么还没定，备选里有短视频平台、AI绘图引流、书单号、闲鱼。那天我母亲跟我说她在直播间下单买锅，我下意识以为是抖音，确认后才知道是视频号。家里长辈都已经在往这儿迁移，我就顺势入场。

先花了大概两天时间，把生财航海手册中关于该平台的章节全部过了一遍，把商业闭环理清楚。大致判断是：内容带动主页成交、内容挂车、直播成交、私域承接。闭环里效率最高的是挂车，但需要千粉权限，而且挂车内容的自然展现普遍偏弱。私域导流操作门槛高，对新手不友好。所以我给自己的路径定为：先靠投放内容抢曝光，再靠开播做转化。

选这个阵地有三点考量。其一，新账号有冷启动扶持，对起号很关键。其二，用户画像偏年长、下沉，相比抖音、快手信息污染少，决策更直接，客单也更好看。其三，我之前做阿胶和多多视频积累的核心人群一直是中老年，这算我的经验优势。

品类选择和对标账号筛选很顺手，直接沿用多多时期沉淀的货盘和号池，简单筛选后就确定了。

我的选品逻辑是先锁定人群再找痛点。人群标签就是年长用户+下沉市场。痛点集中在健康和年轻化，所以运动康复和保养品类更契合。选品前我会先去抖音、快手、拼多多看热度，再回站内看同类内容的饱和度。两边都高度拥挤的直接放弃，完全没人做的也不碰，那不叫蓝海，叫死海。服装、零食等通用需求不是不能做，但属于全人群需求，聚焦性不足，优先级靠后。

最终锁定三条线：一条运动类，两条偏保养的美妆。

找对标我习惯去快手，方法很笨但有效：搜索品名，挑真人出镜的主页进入看细节。关注粉丝量级、视频总数、是否长期聚焦固定货品、画面是否素净、时长、是否有生活类内容、是否持续更新。粉丝五万以内、视频两百条以上、垂直带固定品、画面干净、有少量非带货内容且保持更新的，会进入观察清单。明显混剪搬运或反复裁剪实拍的直接排除。

素材加工是固定SOP：放大、镜像、换底乐、加字。纯音乐无解说的换一首更抓耳的底乐，有解说缺音乐的补一层背景音，有解说也有音乐的做微调速1.1到1.2倍。字幕全部重识别，原字幕遮挡处理。最后加一句抓人文字，围绕功效、场景、情绪写，放在显眼位置。多多时期子浅就提醒过，转化有时靠的不是视频本身，而是字幕里的钩子。比如卖拖把，可以写“惹伴侣生气罚我打扫一天，还好有这把”，或“退休后太闲每天搞卫生，多亏孩子买的这款”。也可以直接写使用效果。这种二次加工也解释了为何要选画面干净的源素材，花哨的源素材不好二次创作。

17号下午首发，三条账号都在当晚破万，其中一条冲到三万多。睡前补发一条，依旧破万，印证了新号扶持的存在。发布节奏我控制在两三小时一条，同时完成实名和橱窗挂链。

真正逼我开播的是出现一次14万播放零成交。内容在跑却没引导，于是先在简介埋橱窗关键词，又在评论区自补引导语，仍无转化。群里经验是破万就播，我便尝试了。

第一次直播和想象差距很大，两小时里同时在线只在一百出头，全程无人互动，无样品，手持另一部手机念商品页。尽管只卖出1单，但佣金让我惊讶，单价29.9抽12元，接近五成。以前多多视频20%就心满意足，这里利润确实厚。下播后猛灌三杯750ml的水，口干到不行，但0到1通了。

回看原因，缺话术缺样品。站内找不到同品类直播，我去抖音看，连续观察两小时，两个风格迥异的主播，一个手机看直播、一个手机录音、电脑打字记录要点。回来筛选改写，变成自己的口播。样品也下单了。

第三天直播，停留时长明显提升，首小时卖出6单。之后分段播，播一小时休一会，全天播了5小时，合计20单。身体扛不住持续输出。

期间出现过一次橱窗与直播被封一天，提示无意义直播。至今没完全搞清是中途离镜还是缺样品展示，之后未再出现。另外两个账号尝试开播，视频未跑的情况下同时在线只有十几人，很快明白直播流量必须由内容带进来，无播放不进人。

之后十天动作高度重复：发片、查播放、有跑的开播、无单或无流下播。循环到27号，主账号当晚播三个半小时，同时在线1.1万，成交200多单，佣金近三千。

其他账号情况：一个换品换内容后基本废掉，删重发最高播放300+，准备再观察两天无起色就注销，保证金不要了。另一个坚持老品，该品在我多多时期曾爆过，最近出现80万和30万播放的小爆发，转化一般，合计佣金700多，仍在观察。另新开两号做内容形式测试，一号用抖音热门语录替换BGM加字，一号用跳广场舞素人账号先做纯内容后混带货。思路是用内容换稳定流量，精准度不足就靠量补。目前8条内容下午统计全部破万，但后续变现待验证。

流量券方面，新人成长计划会送加热额度，完成新手任务送100点，相当于100元。第一次直播次日有专属限时任务，错过就没了，我主号因封禁错过，至今耿耿于怀。我自己测试过100点投观众、500点投点击、下单，单次加热期间几乎无转化。最好的情况是500点投点击带来1300同时在线。投完后配合发福袋，关注与互动明显提升。经验是攒到500再用，配合福袋能把同时在线稳定在较高水平，我那天就从投放后熬到同时在线过万。

未解的问题两个：

第一，人脸认证。三个开播账号基本每次开播都要扫脸，连刚关闭不久再开也要重新验证。只有日播的主账号近期偶尔免掉了。想问下这是机制演进还是偶发？若使用他人实名微信，人脸验证是否每次都要本人到场，若扫完脸后是否可由他人播？

第二，商品上架。主号带的是爱逛的链接，在优选联盟里找不到该品，听说下月第三方链接要停用，该如何承接？想测的其他品在优选联盟也找不到，微店有但要交3万保证金，成本过高。

十天摸到一点门槛，也踩了不少坑，后续有新进展再来更新。
