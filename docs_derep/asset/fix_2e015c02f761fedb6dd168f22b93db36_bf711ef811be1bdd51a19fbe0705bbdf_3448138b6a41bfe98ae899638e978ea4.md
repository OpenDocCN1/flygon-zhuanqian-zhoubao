# 新手闯生财的第一周：跌跌撞撞，也算摸到了门道

写下这篇分享的人，叫壹千。

坦白说，动笔时距离我踏进生财这个圈子，才刚满七天。这一周过得像坐过山车——起初热血上头，接着一阵晕头转向，稀里糊涂走了不少弯路。多亏 @IDO 老徐给我点拨方向，我按他说的动手试了几回，陆续尝到一点甜头，才渐渐摸清哪条路更合自己的步调。

同样是新人的你，要是能从这些还不算老练的体会里捡到一星半点启发，我就很满足了。
