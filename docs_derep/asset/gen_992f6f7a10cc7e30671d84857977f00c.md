喜欢可以换成【愿意持续投入】 = 这件事你不抗拒，花时间在上面是心甘情愿的；最好还能沉迷进去，做到忘我。是否喜欢一件事情，有时很难说清。但有没有耐心把它做下去，是不是几分钟就走神烦躁，还是能一口气啃好几个小时，这个就很直观。回想下，有哪些事是你能一天投入4到8小时去钻研，并且能保持两三年不掉链子的？

擅长可以换成【具备相对优势】 = 在这个领域，你要么专业水准显著高于均值、要么履历背书远超同行、要么手上客户和资源的数量质量都明显领先。

市场可以换成【价值好把握】 = 这份价值的好处好讲出来；可以用数据、对比图、一段简短的描述，让人乍一看就觉得靠谱有用，你也很容易写出客户案例。它绝不能是那种：确实有用，却说不清、没法量化、不可视化，让人听完只觉得模糊。

如果当初就是用这三条来过滤，我会立刻看清：

其实我手上有一大堆事，大概率竞争不过别人，干是能干，但没有可比的优势；

要么价值感知太弱，有用但讲不明白，看完介绍也很难产生购买冲动，转化率自然上不去；

还有不少事是我硬撑着做的，其实压根没热情，也并不想长期把时间耗在上面；

聪明有时候会反被聪明误。对脑子快、觉得什么都能上手两下的人来说，用更严苛的标准去找清自己不该碰什么，反而很重要。觉得啥都能干、啥都想试，最终往往会把自己耗空。

5）学会独立判断机会

今年我走出去，换个圈子看机会，感触很深，也再次验证了【小马过河】这个故事有多经典。

我考察过朋友的中医理疗按摩馆，体验下来效果是真的不错，也亲眼看到客户花几万块买高配服务。我判断这种模式完全可以做全国加盟。结果和朋友一聊，他们直接泼冷水：按摩现在卷死了，前期投入高，搞不好就亏，你别碰。

要不是我亲眼看到朋友的店经营得不错，我肯定会被他们的说法带偏，觉得这是红海、风险大、不该入局。

后来我也去看了房产。只要一提房地产，大部分人第一反应都是：下行、夕阳、不值得碰。连我认识的两位身价过亿的大佬都劝我别碰。但有意思的是，我那个做房产的朋友，就在这个所谓的下行周期里，每年依然稳赚几百万，而且业务还在缓慢增长。

那到底该听谁的？

这就回到【小马过河】。每个人从自己的体感出发，说的都自以为是对的。但适不适合你，是另一回事。

松鼠觉得河深过不去，牛觉得很浅，都是对的。对小马来说，河不深也不浅，刚好能过。

同理，一个项目能不能做，关键看你能不能做，而不是别人能不能做。

3）内心强大是坚守道心，独立判断

以前每次听到“真正的强大是内心的强大”这种话，我都觉得：鸡汤吧，谁信啊。读的书多了，做营销多了，发现这玩意还真不是鸡汤。

人活着，每天都在发信息，也在刷信息接受信息。互动过程中，我们不是在影响别人，就是被别人影响。言语之间刀光剑影，每天如此。

什么叫内心强大？我的定义是：在你接收到外界对你质疑、反对、攻击、压迫的信息时，你能坚持自己的意志，不被外界改变态度，并且不对内产生过多负面情绪。

举几个例子：

有人评价你长得不好看，太胖了，这样肯定没人喜欢你，找不到对象的。

有人质疑你的想法规划不通，你说按我的推算没问题，人家说：你是对的，那你赚了几个子呀？一句话堵死你。

有人说你性格不对，说你野心勃勃攻击性太强，会让很多人讨厌，要收敛不要树敌！

有的说你性格不好，说你唯唯诺诺太弱，这样下去以后肯定会被人欺负，你得凶点，得支棱起来！

有人说你交付不行，你纯纯割韭菜。

有人说，看你兜兜转转，东搞搞西搞搞，啥成绩也没干出来。瞎忙，你这样以后肯定要废掉了。

.......

样貌身材性格人品能力赚钱水平生活方式服务质量... 我们身上的很多点，都会被拿来议论吐槽批评嘲笑攻击。

面对这一堆负面信息，你是会自我怀疑陷入内耗？还是能爽快地说：

嗯，你说的都是屁话，我选择不听，气死你略略略。

嗯，你说的确实对，但你让我改我就改，那我岂不是很没面子？我就不改。

嗯，骂完了笑完了？随意你们怎么说都行，我专心干好自己的事就好了。
