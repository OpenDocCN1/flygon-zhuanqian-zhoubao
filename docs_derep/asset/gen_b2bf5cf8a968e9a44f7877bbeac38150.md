# 数字人口播自动化实战：扣子+多维表格+蝉镜，零基础也能批量生成视频

最近整理后台时，发现手头的蝉豆快过期了。想起之前研究数字人视频生成时踩过不少坑，也积累了一套可以跑通的方法，就趁着这个机会整理成教程，分享给有需要的朋友。这套方案的核心是用扣子工作流 + 飞书多维表格 + 蝉镜数字人平台，构建一个“文案进、视频出”的自动化生产系统。无论你是做读书带货、知识分享还是IP口播，都能用上。（先看两张整体效果图：[PRE0][PRE1]）

## 为什么大家都开始用数字人做口播？

先聊聊痛点。短视频运营最怕的就是日更：每天要产出5到20条真人口播视频，读书带货、读书日记实拍、IP形象口播、人生感悟……种类又多又杂。真人录制一条视频，从化妆、布景、录制到剪辑，没有一两个小时下不来，而且状态不好还得重录。批量制作一个月的素材，简直能把人累垮。更别提多平台适配：横屏、竖屏、多语言，同一内容往往要录好几遍。而数字人恰好能解决这些问题：生成速度快，一分钟左右的文案，大约三分钟就能合成一条视频；支持多任务并行，同时跑多个生成任务也没问题；语音干净，没有“嗯啊”之类的语气词，省去了大量剪辑工作。常见场景参考下面的截图：[PRE2][PRE3][PRE4][PRE5][PRE6][PRE7][PRE8][PRE9][PRE10][PRE11][PRE12][PRE13][PRE14]

除了效率，数字人还有几个让人无法拒绝的优势：

- **成本低**：真人出镜意味着场地、设备、摄影棚、剪辑师……每一项都要花钱。数字人直接省掉这些投入。
- **好管理**：所有脚本、状态、输出链接都能汇总到多维表格，团队协作一目了然。生成结果还能转存到OSS长期保存。
- **一致性强**：数字人形象固定，语音风格统一，特别适合打造个人IP，不会因为状态或环境导致声音不一致。

## 开干前要做哪些准备？

你需要准备以下账号：蝉镜数字人账号（用于生成视频）、扣子账号（用于搭工作流）、飞书账号（用于建多维表格），以及一个可选的阿里云OSS存储桶（用来存素材和成片）。具体怎么注册就不展开说了，官网都有指引。

## 扣子工作流怎么搭？

整体设计分为两大块：扣子工作流设计和多维表格设计。我们先说扣子这边，重点是“数字人克隆”和“视频生成”两条流程。数字人克隆又包含形象克隆和声音克隆。

**形象克隆**：你可以直接用AI生成一张照片，再通过图生视频把它变成动态素材。当然，有条件的话自己录制一段真人视频效果更好。这里我以AI生成为例，先用即梦生图，再借助即梦把图片转成视频。注意，漫画风格的人物生成视频后口型容易变形，建议换成真人形象。生成好之后，用猫抓工具下载无水印版本。相关过程如图所示：[PRE15][PRE16][PRE17][PRE18][PRE19][PRE20][PRE21][PRE22][PRE23][PRE24][PRE25]

**声音克隆**：录制一段一分钟左右干净的人声，最好没有环境噪音。如果不想露脸，可以在剪映里输入文字，选一个喜欢的音色朗读，最后只导出音频。想仿对标的视频，也可以用剪映的音频提取功能，把目标视频的声音抽出来再用。步骤参考：[PRE26][PRE27][PRE28][PRE29][PRE30]

素材准备好之后，就开始配置扣子工作流。我们新建一个名为 `create_customised_person` 的工作流，开始节点里定义两个字符串变量：`material_video`（形象视频链接）和 `name`（数字人名称）。因为飞书多维表格的附件链接太复杂，这里需要先用信息提取插件把真实链接取出来，再用选择器判断是否提取成功。接着调用蝉镜的 `getAccessToken` 接口，拿到访问令牌；之后设置视频名称，把视频传到阿里云OSS（蝉镜无法直接识别飞书附件的临时链接，必须转存到OSS，且文件后缀名要为 `.mp4`，这样才能被正确识别）。完成上传后，调用 `create_customised_person` 接口创建数字人，`code` 返回0代表成功。由于克隆需要一点时间，最后用一个“无限循环”节点持续查询任务状态，直到返回最终的 `id`、`preview_url` 等结果。整个流程的示意图如下：[PRE31][PRE32][PRE33][PRE34][PRE35][PRE36][PRE37][PRE38][PRE39][PRE40][PRE41][PRE42][PRE43][PRE44][PRE45][PRE46][PRE47][PRE48][PRE49][PRE50][PRE51]

这里有个坑要提醒大家：API 接口和 Web 端克隆出来的数字人资产并不互通，在网页上克隆的数字人 API 是调不到的，所有克隆操作都要通过 API 完成。另外，如果你不想自己从零搭，完全可以复制我的多维表格模板，公共数字人和字体列表都已经帮你弄好了，省心不少。

## 多维表格怎么用？

多维表格的主要作用是承载文案管理、任务分发和结果存储。你需要设计几张数据表，比如“克隆数字人”表、“克隆声音”表和“生成视频”表。把每一条任务当成一行记录，运行时由工作流自动读取表格内容并触发视频生成，最终把生成结果和状态回填到表里。这样就可以批量管理所有内容，再也不用一个个手动操作了。

数字人口播自动化的核心思路，就是“一次搭建、长期复用”。把流程跑通之后，每天要做的只是填好文案，剩下的都交给工作流去处理。不管是做书籍带货、人生感悟还是IP口播，效率都能翻好几倍。希望这篇教程对你有所帮助，有问题欢迎在评论区交流。
