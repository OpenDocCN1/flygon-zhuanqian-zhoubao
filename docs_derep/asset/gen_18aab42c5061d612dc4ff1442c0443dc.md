# 00后实拍做小红书，3个月打出5个20W+爆款

大家好，我是小新，一个普通的00后。

我做小红书开店已经两年，做知识付费也有一年了。今天想把自己在“实拍爆单”这件事上的一些经验，尽可能完整地分享出来。

很多人做小红书店铺，首先想到的是混剪。但对我来说，实拍同样是一个非常重要的方向。我不仅做实拍图文，也做实拍视频，而且都曾经拿到过比较好的结果。

简单复盘了一下，连续做实拍的3个月里，大约有5个商品成功跑出爆款，单品销量都超过20万。整个过程从配音、脚本到拍摄，都是自己原创完成的，小红书店铺也没有进行任何投流，最终单品销量突破100万，做到类目销量Top 1。

现在，只要是我正在测试的产品，即使竞争很激烈，也能通过实拍内容找到突破口。我的感受是，想把小红书店铺真正做起来，混剪可以作为入门方式，但实拍很可能会成为接下来更重要的趋势。

我们实际测试下来，视频在出单之后，如果加入一小段真实拍摄内容，爆单概率往往会有所提升；而当整条视频都采用实拍形式时，商品更容易被进一步放大，销量也会明显加速。

为什么实拍更容易跑出来？

一方面，真实场景和真实展示能够增强用户信任；另一方面，相比大量同质化的混剪内容，原创实拍更容易形成差异，让产品在竞争激烈的环境中被注意到。
