# 2.公众号爆文赚钱的逻辑是什么

有同学问得特别到位：公众号发文章为什么能赚钱？原理是什么？

我们做的公众号爆文，绝大多数变现来源是流量主收益。也有接广告的，但比例很小，这里就不展开了。

可以这样理解：

各大平台都在抢用户，都想把用户留在自己平台内，公众号同理。

过去，公众号对新人很不友好，属于封闭系统，粉丝有多少，阅读量就基本到顶，不会推给陌生用户。

后来平台发现这样不行，中小号主没有流量就做不下去，很多号主流失了，留下的也不活跃，平台的留存就出问题了。

于是规则改了：

对新人也给推荐，只要文章有爆款潜质，就先给一点流量，表现好就往前跑。

这就是爆文流量来的地方。

【变现闭环】

平台：为了留住用户，给流量、挂广告

你：做出好内容，承接流量

读者：内容有价值，就愿意在公众号多停留

平台、你、读者，形成正向循环。

平台是否给推不可控，读者是否喜欢不可控。

我们能控制的是提升内容质量，掌握爆款规律，写出爆款。

阅读量越高，文中广告曝光越多，平台为了感谢你帮它留住人，会自动加大推荐和流量主收益。

这样说清楚了吗？

# 8.如何判断找的爆款文章适不适合自己的赛道？【爆款标题如何改写？】

和学员交流发现，大家对判断爆款是否匹配赛道，以及标题如何借鉴，有点模糊。

统一说下判断方法：

1.先判断爆款文章的领域是否和自己一致

比如学员找的爆文标题是：“6大方法，让你睡眠质量越来越好【亲测有效】”

她自己的赛道是“极简”类，生活极简或存钱极简都不符。

这个属于生活习惯类，和她的调性不搭。

如果想尝试，可以放出两条去市场测反馈。

2.爆款标题怎么改写？

最简单是改数字

数字一定要改，改完后务必复制粘贴去搜索是否有完全重复的标题，有就继续改。

ps：

改写有技巧，想让标题更像自己的话，一定不要改掉【爆款关键词】！

什么是爆款关键词？

就是标题里的人性词、痛点词、好奇词、暗示词等。

例如：

1、“6大方法，让你的睡眠质量越来越好【亲测有效】”

爆款关键词：睡眠质量

吸引力词：【亲测有效】

很多人有睡眠痛点，刷到这个标题再看到亲测有效，大概率会点。

你把“睡眠质量”删了，别人看什么？

2、“男生把持不住的23句睡前小情话”

爆款词：把持不住、情话

有若有若无的性暗示，很有吸引力

3、“一本改变命运的奇书，央视强烈推荐！”

爆款关键词：改变命运、奇书

吸引力词：央视【强背书】

改写示例：

“吹爆这本改变人命运的奇/好书，央妈强烈推荐！”【举例】

# 9.爆款关键词如何分析？

建议建一个“爆款标题库”，把同行的爆款标题都扒下来，再把里面的爆款关键词提取出来做分析。

分析多了就有感觉了。

比如读书类关键词，无非就是人生低谷、好书、强烈推荐等这类人性词。

# 10.公众号文章字数多少合适？

一篇最少900字，1200字比较稳，最多别超1500字。

900字：可插1条文中广告

1200字：可插2条文中广告【前提文章中无插画】

1500字：偏多但还能接受，再多就长且密，完读率下降。

总结：1200-1500字最佳，不要超过2000字。太长没耐心，太短广告位不够收益下降。

# 11.发文时间段有讲究吗？

没有绝对时间，只要不太早也不太晚就行。

不要太早：早上五六点发，很多人还没起床。

不要太晚：超过晚上11点或11:30发，太晚用户爱看擦边内容，正经文章关注度低。

# 12.公众号配图去哪找？

文档里有写，但很多同学没找到，再统一说下，适用于任何赛道。

1.小红书搜

想要什么效果就搜什么效果，比如极简类同行用温馨治愈风，就搜“治愈动漫图”

‼️博主简介没写“禁止二改二创、严禁搬运”等限制词就可以用。

‼️带水印的建议换掉，或自己去水印。

极简类常用：“魔女宅急便”、“哈尔的移动城堡”、“千与千寻”等

2.同行公众号盗图

如果文章里写“图片来源于网络”，大概率是可以用的。

注意别把同一篇的图文全抄，图换另一篇的，文模仿这篇，减少撞车举报风险。

3.百度

版权纠纷少，注意水印。

4.堆糖

壁纸资源多，很多小红书博主背景图来自这里。

# 13.私信需要回吗？

有同学爆文后私信暴涨，有好有坏，不知道回不回。

建议：不回。

时间精力有限，说好的看着乐一下就好。专门来骂你的，有的人关注完就骂，犯不着计较。

如果后台评论留言想合作，建议在公众号菜单栏放上联系方式。

真正想合作的人会主动加你。只是私信问问的，没必要理，我们核心还是靠爆文赚钱。

私信只有你能看到，不用担心形象问题。

# 1.为什么不要轻易暴露公众号名字？

从第一期训练营我就一直强调：

别轻易把公众号名字公开；

爆文号尽量别发朋友圈【IP号除外】；

晒收益图一定要马赛克公众号名字

原因很简单：人性。

爆了之后，总有人故意找茬举报，举报成功会被判定违规，流量骤减，号可能就废了。

还有人会洗你的稿子【你做大了总会被模仿抄袭】。稿子被洗多了，系统会误判你自己的号。

误伤友军。

# 3.文章被举报了怎么办？

有学员第一篇就对标前几天10W+，发出去没多久3个阅读就被举报了。

原因是“滥用原创”，别人觉得内容像，直接举报。

举报成本太低，一键的事儿，写作者或多或少都遇到过。

还有标题一模一样的被举报，限制原创一天。写得太好被同行嫉妒反手举报……

举报很正常。

放平心态：“不被嫉妒是庸才”

常见问题：

1.被举报账号还能用吗？

能用。但别频繁违规，轻则限制发文，重则封号。

2.如何规避？

无法100%避免，但可以尽量降低风险。

①标题不要完全一样

看到有些标题一模一样也能过，但别去赌概率。

我一般的做法是：

a.找到近期爆款，对标题做删减和改动，但保留爆款关键词

b.把改好的标题填入AI调教指令，让AI重新生成内容

c.如果AI生成的内容还是太像，我会让它换角度重写

d.AI内容达到80%需求后，我再做点微调，有时甚至不用改可直接发

我手里一个号从未被举报过，因为除标题有相似度外，其余都是原创。反而有很多人抄我，被我朋友举报多次。

②内容框架不要一模一样

不只是换说法意思不变，里面的要点也要换。

素材可以去小红书搜，有很多来源。

# 4.快捷转载键绝对不要开！

很多同学写完拉到底部会看到“快捷转载”选项，在标原创那里。

要不要勾选？

答案：不要！！！

一键转载会分走你的流量。

# 5.发文前注意错别字、别转发朋友圈/社群

再强调一次。

发文后用自己微信预览一遍，检查错别字。

【公众号文章修改只能改20个字符，且只能改一次，标题不可改】

可以给自己点赞、在看。但不要点广告，更不要转发朋友圈和群，也别让朋友帮忙点广告。

如果同一批用户反复给你点赞点广告，账号很容易进入死区，进不了流量池。

ps：

尤其是用大小号轮流切换给自己点赞再看，更容易死号。

所以别自作聪明刷阅读量，也别总让固定朋友帮忙看。

发完就放着，顺其自然。
