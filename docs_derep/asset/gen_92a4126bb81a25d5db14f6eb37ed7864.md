# 咨询公司到底该怎么定价？

不同咨询公司的报价差得能吓人。

就拿营销咨询来说吧，低的项目几万块就能启动，高的动辄一年一两千万，跨度非常大。

这生意本质上是一种专家生意。门槛很高，专业壁垒很厚，但很难规模化复制，所以大多数咨询公司都做不大。

因为整个行业严重依赖核心专家，人是最稀缺的资源。虽然可以通过方法论、模块化、标准作业来提升一点效率，但供应链依然很短。

我们现在给到市场上的价格是 180 万一单，全年深度陪跑。有人会觉得小马宋已经不便宜了，但国内定价最顶尖的营销咨询公司，要比我们贵十倍。

真不是不想多赚钱，而是我们想服务的是主流企业，十倍的价格根本放不下大多数客户。

说到底，咨询的定价要综合看四个维度。

第一，看同行，也就是竞争视角。

服务水准相近的情况下，同行的报价就是你的天花板。这是一种很现实的市场锚定。能力差不多，价格却比别人高，客户凭什么选你？

小马宋算是行业里的后起之秀，我们的定价大概只在传统头部公司的四分之一左右，这个区间对我们来说是合理且可持续的。

第二，看业务体量，也就是规模视角。

价格定得越高，能买得起的客户就越少。

高价确实有好处。利润率漂亮，而且天然做了客户筛选，能筛掉预算不足、决心不够的客户。付出一两千万的客户，通常本身就有投放能力，项目更容易做出漂亮结果，案例自然好看。

但问题是，市场容量太小。每年能接的单子就那么几笔。

我更希望客户基数大一点，一年能多做几单，这对团队是实打实的磨练。团队需要不断实战才能保持手感，像美军的战斗力强，是因为常年在实战中打磨出来的。业务做少了，能力也会退化。

把价格压到行业顶端的 20%-30%，潜在客户量至少能放大上百倍。

第三，看成本。

咨询公司的商业模式决定了它不适合走性价比路线。规模天花板摆在那里，做不大就只能靠单价来保证利润。成本不是定价的核心依据。

第四，看客户能获得的价值。

归根结底，值不值由客户说了算。值了，自然会帮你口碑传播；不值了，投诉骂名也会传开，后续获客就会变得很难。

客户价值本身也有分层。帮一家奶茶店把营收翻一倍，和帮一个百亿体量的企业提升 1%，投入的精力可能差不多，但带来的商业结果差了千万倍。服务高价值客户，也是咨询公司长期追求的方向。

本质上还是价值与价格是否匹配。只要你把报价控制在自身服务能力之下，客户的满意度通常会更高。

咨询服务的交付很难标准化，效果也无法提前证明，所以甲方挑选乙方的难度极大。昨天来公司拜访的客户就吐槽，他们已经先后被两家咨询公司坑过，大几百万花掉毫无效果，但还是在寻找下一家。

所以我常说，甲方找到靠谱的乙方，比乙方找到甲方要难得多。

想深入聊定价逻辑，可以去读我的《营销笔记》，里面用了上万字专门拆解这个问题。
