# 二、新手从0开始：账号准备与养号细节

**注册账号的注意事项**

主号建议用移动、电信、联通三大运营商的号码。之前有团队成员反馈，用广电号码会被系统提示有风险。一个手机、一张卡、一个账号，不要多开，不要用微信分身，不要来回切换账号。全程用手机流量操作，别用WiFi。

小号可以用微博、QQ号注册，也可以用注册卡。必须提前接受一点：小红平台现在管得越来越严，小号要做好随时被废的心理准备。

千万不要在同一部手机上登录多个账号，包括双开。同设备多账号同时在线，很容易被关进小黑屋。而且一旦某个账号出现违规，系统会抓取你的网络、手机信息和号码，其他账号也连坐受影响。之后发笔记时，系统可能会自动拦截，造成隐性限流，后续操作就难了。

因为小号操作动作多、经常废号，建议大家用低成本的注册卡来运营，损失小。

**四件套怎么搭：头像、昵称、简介、背景图**

头像，我们基本都用自己跟孩子的合照，这样用户天然会产生信任感。大家都是宝妈，戒备心会低很多。不想出镜的话，可以拍侧面或背影，也可以去淘宝画一张亲子手绘头像。

昵称，要简单直接，别用生僻字，不好记。可以参考“XX妈妈说育儿”“XX妈妈懂调理”，用宝宝的小名就挺好。

简介，新号养号期间不要留任何联系方式，也不要有引流动作，积极阳光一点就行，否则容易被限流。记住通用公式：我是谁＋我擅长什么＋我的信任背书＋我能为你提供什么价值。初期阶段可以写：“我是在家带娃的全职妈妈，喜欢研究育儿知识，希望能帮到大家。”后期账号权重起来了，再在简介里埋钩子。但起步阶段，还是要猥琐发育。

背景图，颜色单一就好，别花里胡哨。也不要把微信号放在背景图里，系统检测到会强制让你重置。放一张和宝宝的合照，很合适，能加强信任度。

**养号的基础操作**

长时间不用的老号、刚刚注册的新号，都建议先养一养，一般3-5天就够了。每天刷一些赛道相关笔记，比如搜“育儿知识”“脾胃调理”这些关键词，浏览速度正常就行。看到数据好的笔记就点赞、收藏、评论，每次半小时左右，分时间段刷也可以。

养号期间，不要发布任何第三方信息，比如邮箱、小号、公众号、微信等。养完之后发了新笔记，如果流量很差（只有1-200)，可以重复上面的动作再多养几天。老号太久没激活的，建议直接注销重来。

# 三、对标笔记这样找，新手也能快速上手

新手不要对标大博主，人家本身粉丝基数很高，学不来。要多刷近期的低粉爆款，也就是笔记数据明显高于账号粉丝量的内容，这才是优质的模仿对象。因为时间近，你还能吃到这篇笔记的长尾流量，自己再出爆款的概率也会增大。此外，一定要擅长用关键词，找到近期优质笔记，然后做像素级模仿。

**找对标的具体方法**

1.  关键词搜索。比如我想做育儿知识，就搜相应关键词，先大致扫一遍，看哪些笔记热度高、制作起来又比较简单，先收藏到选题库，再做进一步筛选。
2.  用平台自带的指引工具。筛选“图文”，先看“最热”，因为火过的还会再火；再看“最新”，多刷一会儿，近一个月内比较热门的话题就一目了然了。

**封面对标**

小红书封面很大程度上决定了笔记的点击率，所以前期要多花时间打磨。我们选封面的标准是：三个月内出现过5次以上万赞数据、制作成本又低的图片，就可以拿来一比一像素级模仿。

具体操作：搜索赛道关键词，多刷笔记，每4个笔记为1组，截图第一眼最想点开的那一组。选够5组以上，再筛出一个最吸引你的封面，就是我们要的。也可以直接对标近期出过低粉爆款的同行，她们的封面已经经过平台验证。一个账号通常会有多篇爆款，直接模仿她们的封面就行。

比如我搜“育儿知识”，图1是三天前的笔记，点赞已经将近800，那她的封面和标题就是好对标。图2是四宫格布局，白底红字，一眼就能被吸引，数据果然也是最好。这就是同关键词下，干掉对手的流量密码。

多找对标，坚持找几十篇以上，你会发现很多爆款的封面都是相似的，这说明直接拿来用就好。

**安全引流的方法**

目前我们最常用的，是通过群聊引流，然后由小助理发微信号。这也90%的人都在用的方式。如果做引流账号，直接进群免确认，再用小号发布各种引流信息。但有的号运气不好，容易招黑，如果群聊被关进小黑屋，主号也会被限流。

怕黑粉和同行举报的话，可以开启群审核。先让进群的粉丝晾几天，看她的头像有没有变成“小萝卜”，有没有显示“账号已注销”。如果变了，说明这个号是营销号，已经被官方关进了小黑屋。这个办法，既能让官方帮我们筛同行，也能保护群聊安全。

# 六、发布节奏与数据复盘

我们前期不熟练的时候，基本保持日更，没有特别固定的时间。等作图上手以后，就一天早、中、晚更新3篇，每篇间隔4小时以上。等到跑出一个小爆款，就开始开第二个账号做矩阵。经过多个账号测试，一个账号出第一个爆款的周期基本在15天左右。

发完笔记后，我们会等48小时再看浏览量和点赞藏数。如果低于100，直接隐藏掉这篇笔记，再发新的。一周后，回到创作中心看单篇数据。如果出现了爆款，就趁热打铁，稍作修改再发一遍——火过的内容还会再火，爆款一定要重复利用。

**设计钩子，加深用户印象**

发完自我介绍后，我们会问粉丝：需要育儿资料、电子书，还是预约1V1舌诊？差不多给3个选项就好，不要太多，否则加重选择困难。

这三个福利各有什么好处？

-   **育儿资料**：可以了解孩子的基本信息，比如月龄、现在进入什么发育阶段，然后给她一些建议。我们还可以看看妈妈的朋友圈，夸夸孩子可爱。大部分用户都会很开心，对我们的第一印象也会变好，后续邀约进群就容易了。
-   **电子书**：用户多少是在带娃过程中遇到了问题，才需要专业知识。我们可以通过礼貌询问来安慰她，提供情绪价值。妈妈的共情能力非常强，如果有人说到了她心坎里，替她说一句话，她会特别感动，对后期转化也很有帮助。
-   **1V1舌诊**：这个可以直接精准掌握用户信息，并给出实质性建议。我们不会一上来就推产品——妈妈们对一上来就卖东西的人，戒备心很强。我们通常都是给饮食调整的参考，让她先试试，两三天后再回访。有效果的妈妈，再给她软植入一些产品。我们常用的说法是：“饮食是最需要注意的地方，慢慢有好转以后，可以搭配一些去火或者健脾的药浴，帮助孩子胃口更好。”大部分妈妈都会问是什么，我们发给她看。因为药浴客单价很低，所以非常好出单。

**精心回访，逐个提升客户好感**

-   **育儿资料用户**：我们大概3天回访一次，开头会说：“宝，XX资料看了吗？你觉得怎么样呀？”等她回复。如果她看了并跟你说了感受，你就可以说：“上次有个妈妈孩子也是这样的情况，后来她在群里说孩子现在好多了。正好我们过两天还有一次XX分享，我邀请你进群呀。”顺势邀约，愿意回复你的妈妈，基本都不会拒绝。
