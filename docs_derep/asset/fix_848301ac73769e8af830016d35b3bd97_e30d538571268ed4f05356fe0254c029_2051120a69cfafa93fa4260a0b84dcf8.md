# 山城首场圈友面基会，圆满落幕！

文 | 辰奚（2023年4月14日）

山城的伙伴们，看过来！

我们搞成了一件大事——把常年在网上聊天的朋友，拉到了同一张桌子前。重庆生财社群的首场线下聚会，已经顺利办完。

事情起源于3月25日的全国性聚会。那天之后，各地同城小队纷纷冒头。我们这边也没落下：从最初5个人，发展到41人，组建了专属社群。大家越聊越热，干脆约定：线下碰一面。

于是，我着手张罗4月9日的聚会，希望本地伙伴从屏幕后走出来，也为了往后能常有这种面对面的交流。
