# 三个人，两年半，100W：这段路我一步一步拆给你看

> 没有一夜暴富，没有风口起飞，只是三个普通人，在互联网世界里蹚出了一条自己的路。

大家好，我是苗子，一个在创业路上反复折腾的人。

今天想把一件事彻底讲清楚：我是怎么带着一个只有三个人的小队伍，从零做到第一个100W的。这段路，我走了整整两年半。这篇文章对我自己意义很大，因为它记录了我从互联网小白到拥有自己工作室的全过程。如果你正想入局线上生意，希望能从我的经历里找到一些参考坐标。

有时候，人不该只顾着低头往前冲。偶尔停下来，回头看看来时的路，反而能看清自己走到了哪里。

我的履历其实挺普通：

2015年，我正式踏入社会。
2016年，和朋友合伙开了家装修公司，做到2018年9月退出。
2019年，开始自己摸索互联网，一直做到现在，全职干这行。

相比于很多圈内人，我的创业故事没什么惊天动地的转折，也没经历过什么大起大落。用两个词就能概括：平淡、平凡。这些年我深耕过两个赛道——线下的装修和线上的网创。但这两块领域里装的东西，足够我消化很久了。

圈子待久了，前前后后算了算，我正式做互联网已经四年多了。但真正开始有进账，是从第二年开始的，准确说是后三年。至于第一个100W，我花了足足两年半才达成。第一年可以说颗粒无收，全靠吃老本撑着。

下面，是我从2019年到今天的一份完整复盘，也是我在网上摸爬滚打攒下的一点真实心得。希望我的故事能给想入行的朋友一点勇气，也能让已经跑在前面的大佬们，回忆起自己曾经灰头土脸的日子。


## 2019年：没赚钱的一年，却是我最值钱的一年

那年的网创圈子，远没有现在规范。各种千奇百怪的项目满地跑，什么养龙、养猫、养狗、养猪能日赚斗金的，还有什么卷轴模式的，稍不留神，投进去的时间和钱就全打了水漂。

我站在那片迷雾里，不知道该往哪儿走。于是我做了一个很笨的决定：找对标。花了两天多时间，把各个平台翻了个底朝天，反复筛查、去重（有些账号背后其实是同一个人孵化的），最后精选了10个看起来还算靠谱的网创博主。

选定了，接下来就是一步步“靠近”他们：

1. 先关注；
2. 没有公众号的，一律不关注；
3. 加私人微信，长期观察；
4. 看看他们运营什么付费圈子；
5. 给自己定个预算上限，然后直接进。

那一年，我陆陆续续进了十多个付费社群。踩坑是必然的——但对我来说，真正的坑不是项目没赚到钱，而是里头什么服务都没提供，纯属“花钱买了个寂寞”。

第一批进的10个社群，花了大约4000块。

顺便说一句，我对“付费”这件事，从来都是认可的。这不是因为我如今在做知识付费才这么说——当年搞装修那会儿，我也经常跑去上装企培训班、总裁班。

枭哥有句话我特别认同：赚钱就是为了进高层的圈子，然后去赚更多的钱，再拿这些钱去够更高层的圈子，去赚更多更多的钱。听着像段子，但现实就是如此。想在一个行业里把盘子做大，最快最直接的路，就是找高人指路、花钱买认知。

我进那些社群，目的很明确，就两个：

1. 第一时间了解行业里最真实的动态；
2. 看那些跑在前面的人，是怎么搭模式的。

直到现在，我遇到很厉害的人，还是忍不住去“拆”他的玩法。现在信息足够透明，无非就是那几个平台——抖音、快手、小红书、知乎、微博，全搜一遍，再看他的公众号。如果还觉得不够透，我会做一个可能不太厚道但很有效的动作：去盗版课程网站上搜他的名字，看看他都出过什么课。到这一步，这个人的玩法基本就摊在眼前了。至于后续是继续观察，还是主动去勾搭，就看我自己怎么权衡了。

有价值的模式，能抄就抄，抄不了就换下一个。最不济，还能变成我的谈资——比如“我有个朋友，一年赚了5000W”，这朋友嘛，你懂的。

2019年我真没赚到什么钱。印象最深的一次，是带一个闲鱼的课，定价9.9元，一下午进账了一千多，给我高兴坏了。除此之外，基本就是边吃老本，边攒资源，边盯着同行的一举一动。

因为我张罗这件事的初衷，本来就不是为了跑通某个单点项目，而是想凑齐一个自己的班底，搞一个小工作室出来。我的终极目标很简单：当个小老板。

那年为了这个目标，我做了很多“看不见”的功课。到了年底一盘点，我发现自己攒下了这些家底：

1. 加了十几个社群，和群主们处得都不错，像战劲、王一书、九京这些圈内朋友，到现在还保持着联系；
2. 练就了随手写出千把字文章的能力，这个本事后来帮我大忙；
3. 做到了任何项目拿过来，研究几小时就能看懂它的底层逻辑——那些技术壁垒太高的除外；
4. 学会了跑一个项目，一周内大概率能判断出它有没有戏；
5. 拥有了能给别人提供价值的能力；
6. 获得了以前只能仰望的大佬的认可，能和他们平起平坐地交流了；
7. 链接了各行各业的人脉资源；
8. 攒下了人生中第一波私域流量：2500+微信好友，公众号接近4000粉丝。

剩下的收获，是眼界、打法、对风口的直觉。这些东西，钱买不来，只能用时间去熬。

如果非要问我后来为什么能赚钱，我的答案是：2019年那一年，我什么都没赚到，但我赚到了一条很深的护城河。


## 2020年：机会没来之前，我一直在等

第二年，我的关键词依然是“花钱”。现在回头看，我特别庆幸那年花出去的两笔钱——它们把我送上了和很多前辈并排奔跑的赛道。

因为第一年没进账，2020年我不能再啃老本了。攒了一年，也该往外掏点东西了。所以我那年的目标很直接：空手套白狼。方式也很朴素——边赚、边花。

我在等一个机会，整整等了8个月。8月初，我遇到了墨羽，后来成了我的合伙人。事情的起头很偶然：一个项目，我们打了两小时电话，然后我直接买了票跑过去找他。第三天，他就被我连哄带“忽悠”拉来一起干了。

总有人问我，怎么找到靠谱的合伙人？说实话，我也没什么标准答案，这玩意儿看缘分。但有一条我很坚持：既然合伙，就必须在同个屋檐下干活。什么“线上先协作”，真搞下去大概率会崩盘，撑不了太久。

墨羽当时也问能不能先线上，我一口回绝：要么线下干，要么各干各的，以后有项目再碰。我的强势，加上他敢闯的性子，我们才凑到了一起。

人到齐了，我们就地成立了第一个工作室。我们最初的三人小分队，也在这时候正式落定——我、墨羽，外加他爱人。

当时的年度目标，简单得有点可爱：从8月算起到过年，一共6个月，赚10万块，三个人能过个好年就行。

我们的办公室是一间次卧，两张电脑桌，三把椅子，十几部手机，还有一张喝茶的小桌板。干累了就喝茶，有一搭没一搭地聊理想，时不时吐槽哪个外卖平台难吃得要命。

半年后，我们交出的成绩是50W，是原定目标的5倍。

也是那时候，我们做了第一个线上的付费圈子——思维社。第一波招了差不多100人，定价365块，没花几天就招满了。那几天，我第一次深切感受到线上赚钱的魔力，还有被人信任的那种踏实感。

一晚上进账小3万。3万是什么概念？直接干掉了我们原定半年的目标的三分之一。当晚我们开了荤，花了200多块吃了一顿小龙虾庆祝。

社群有了，项目也得跟上。一开始，我们带群友做豆瓣引流。做着做着，一个致命的问题冒了出来：引来的流量到底用来干嘛？当时90%的人没有后端变现的出口，大多是来白嫖的，根本产生不了什么价值。

就在我们卡在这个关卡上的时候，一个项目撞了上来——小红书的起号卖号。那时候这个项目算得上独家，也成了我们第一张真正的王牌。

这个项目到现在还一直在跑，只是没再花大力气去重仓。也是从它开始，我第一次在线下花钱去专门学一个项目。

所以我说，2020年的关键词是：敢在线下花钱。

那趟出去，前前后后跑了两个地方，吃住行学加在一块儿，花了差不多7000块。出发前我们就预料到这笔开销了，说实话挺肉疼。但正是因为这笔钱砸下去了，我们半年才有底气赚回那50W。

那时的收入结构，基本是三条线：

1. 社群收费，从365一路涨到了1980；
2. 自己做号——手机规模加到了50部，每个月能起万粉号大概二三十个，一个月利润有好几万；
3. 学员出号，我们从中拿差价，每个月也有一万左右的进账。

能赚到这些钱，靠的是两件扎扎实实的事：一是把项目做到了极致；二是把项目后端的销路完全打通。

记得有一期打卡营，200多个社群成员和我们一起做号。我们统计了一下，一共起了将近6000个账号。你可能没概念：我们做号是一机一号，也就是说，那阵子相当于有6000部手机同时在跑。当时主攻游戏、动漫、音乐三个领域，你在小红书上刷这三个赛道的内容，10条视频里至少有4到6条是我们出的。

至于后端的销路，我们跑遍了北京、广州、佛山、济南、南京，对接了6家MCN机构和大量小红书个人博主，才把几千个账号的出口给稳定住。

那半年，我们的日常就是：收人、做号、卖号、找渠道，无限循环。

这一年，我拿走了四样东西：

1. 第一次尝到了“有壁垒”的项目带来的甜头；
2. 第一次搭建起了一个小规模的基本盘；
3. 再一次深刻体会到社群能把人聚得多紧；
4. 第一次意识到，人脉和资源，本身就是生产力。


## 2021年：三人小分队，拿下第一个100W

到了这个阶段，说句有点凡尔赛的话：我已经不缺项目了。

我每天琢磨最多的问题，是怎么把这三个人的小队伍，榨出最大的效能。

那年我的创业方法论，凝成四个词：纯线上、轻资产、自动化、可放大。

纯线上：坚决不碰需要重运营的自营项目；
轻资产：不搞重投入；
自动化：打磨出一套完整的成交转化体系；
可放大：一个人也能矩阵化运作。

说实话，2021年刚开始时，我挺焦虑的。我太清楚2020年那50W里有多少运气成分。虽然势头还在，但心里始终悬着一块石头。正因为这份不安，我才给自己定下了那四条铁律。

我们一边谨慎，一边发狠往前跑。到年底，全年干到了90W的小目标。

那年我只做了两件事：抓团队、抓模式。

先说抓团队。
我的管理方法，说穿了就六个字：定时、定量、定人。定好时间节点，分好工作量，把责任落实到具体的人头上。这套最小化的协作模型，我叫它“增长小组”。

这种小团队的作战方式，应用场景非常多：测一个新项目、验证一个渠道的转化数据、优化某个环节的转化率，都很合适。直到现在，我的工作室内部跑新东西，用的还是这套打法。

再说抓模式。
一个跑通了的模式，能帮你省下大量的人力、物力和心力。我的最小模式很简单，但足够让我不用再单独养一个客服，把省下来的精力拿去做别的事。

剩下的工作只有一件：围着基本盘转动，搞流量、跑数据、晒成果。

说到晒成果，我以前也不太理解这个动作。后来某个瞬间，我突然想通了：晒数据不是炫富，它只是把实力可视化而已。你可以晒收入，也可以晒团队人数、社群规模、公司体量、人脉厚度，甚至晒车晒房。只要是能证明你实力的东西，都值得拿出来晒——因为这是一个“酒香也怕巷子深”的时代。

理解了这个逻辑，很多事就通了。

到了2021年年中，我们仨的第一个100W，正式落袋。算下来，从2019年起步，刚好两年半。

但要让我总结这一年做了什么了不起的调整，其实没有。我只是把前两年学到的东西，用更多的心思和更长的时间，往下深挖了一遍。

后来我的工作室能长出完整的运营架构，靠的正是那套最基本的逻辑。


## 写在最后：我为什么讲过程，不拆项目？

总有人问我：你为什么不直接拆解一个赚钱的项目？

因为我心里一直有一句话：

项目不会永远赚钱，永远赚钱的，是我们自己。

两年半赚到100W，在那些真正的牛人眼里可能算不上什么。但对我们这个小团队来说，这个节奏，我们已经很满意了。因为真正让人走得更远的，永远是自己的本事变大了、认知变深了、视野变广了——这才是赚钱这件事的根。

从2021年到2023年，我的模式又迭代了一轮。那是另一个很长的故事，下次找机会再聊。

一句话总结我的感悟：

在对的时间干对的事，在合适的阶段赚合适的钱。

最后，想送给大家一句陪伴了我很久的话，也是我的座右铭：

博观而约取，厚积而薄发。

这句话出自苏轼的《稼说送张琥》。大意是：见识广博了，才知道该取什么；积累深厚了，才能真正为我所用。

放在创业路上，同样是这个理。先沉住气，把自己攒厚，再谈爆发。共勉。
