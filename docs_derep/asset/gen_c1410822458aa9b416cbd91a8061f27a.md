# 一个资质普通的女生，用三件成功的尝试，30岁前收割了第一个100万

> 来源：[https://e1lvpjb5e3.feishu.cn/docx/SBODdEmmBobPzsxQd35c46Qunie](https://e1lvpjb5e3.feishu.cn/docx/SBODdEmmBobPzsxQd35c46Qunie)

先做个简单的自我介绍。

大家好，我是跟着，有尔。江苏一个四线小城出来的女生，现在在北京。警校毕业后爱打拳击，后来做了服装设计师。现阶段的身份是前服装设计师、前企划部经理。业余时间在研究港美股打新、可转债、web3、跨境电商。

手头能用的资源有：服装圈的人脉、紫砂壶、0-6岁托幼、电缆。当前的状态是刚到北京，想找大佬取经，同时在寻找更合适的创业方向。

性格上测出来沟通交际比较靠前。家里在华东做教育产业，有连锁早教和幼儿园。我本可以一辈子安稳上班，但我耐不住折腾。自由行过十个国家，国内大部分热门地方也都跑遍了，上班会把我困住。

我的基本盘很清晰：资质属于真普通，月薪几千的那种普通人，不是主业就天花板、副业还比主业高的那类普通。但认准的事情执行力极强。

下面这10件事，就是我这几年为了赚钱踩过的坑。

普通女孩的试错清单：

一、甜品店
二、A股
三、基金
四、港股打新【成功】
五、可转债【成功】
六、币圈【成功】
七、跨境电商
八、服装创业
九、小红书博主
十、券商撸羊毛【成功】

# 第一桶创业的教训

毕业后在公安局待过一段，后来进了家族企业做企业规划。日子稳定但一眼望到头。亲戚想开甜品店，我也想摆脱打工人的标签，就合伙开了。

撑了几个月就关门了。

复盘优点：
开业初期，我联系了本地最大的微信公众号投放软文。冰淇淋是夏季产品，公众号老板搞了个“宝塔镇河妖”的噱头，堆满冰淇淋拍照，还去麦当劳打卡做免费赠送活动，开业期人流量还不错。
还没有私域概念时，我就让顾客扫码加微信送“眼镜吸管”，积累了第一批私域。每次上新发朋友圈，老顾客还会回流。

复盘缺点：
和亲戚合伙是第一个坑。后期转凉，我提议增加品类，他觉得对标大城市的冰淇淋店一年四季只卖冰淇淋就能活。最后还是我擅自加了果蔬芋圆才勉强撑过。
人工成本没控制好。亲戚有主业，开店后一直请人看店，其实规模不大，两人就能顾过来。
典型的女孩创业三件套：奶茶、花店、甜品店。我中招了。刚出象牙塔，没有商业思维，只觉得自己也爱吃，赚不到钱就自己吃。完全没调研小城市冰淇淋这种季节性品类能不能活，有没有竞争。冷门的东西往往是别人试过了走不通才冷门的。没调研、没思维、一头热，只能感动自己。

# 搞钱意识的觉醒

回城里继续打工，四线城市几千块的月薪。2018年状态很差，看了长投的9.9元理财入门课，虽然忘了具体内容，但却是我理财意识的启蒙。后来报了线下交流会、基金课、股票课，认识了一批谈钱不尴尬的人。被推着买了基金和白马股，多年后回头看还在原点，幸好没死磕在A股。

# 贵人指路

上基金课时老师加餐分享了港股打新。我对新鲜事物好奇，就顺着PDF水印找到相关公众号，打开了新世界。老师把我们拉进私域，说去人少的地方先攒本金再回A股。我金融非科班，对数字头疼，也不看K线，在A股赚钱太难，不如去人少的赛道试试。想着工资亏了爸妈还能养我，就行动了。先给江苏各省行打电话办港卡被拒，后来听说杭州银行相对方便，第二天就跑去办，被要求买金项链，觉得不值但为了港卡忍了。总比飞香港便宜。

# 抓住第一个风口

2019年是港股打新的高峰期。我一开始只开了一个户，吃到几只肉票后才意识到这事能做。后来多开户撸券商开户奖励，还加了雪球的大V。有人把券商开户返现给我全返，那段时间我算过年化，最好的时候到150%左右。上市当天翻倍是常态。当时很多人抵押房产去搞，我身边就有，部分人收益不错。

复盘：
好奇心让我打开新世界。
盲从也有效。基金老师那句要么有慧根要么会跟，让我选择跟懂的人走，知识付费换时间。
执行力强，决定就立刻办港卡、立刻开户。
大钱要赚，小钱也要捡。券商羊毛有几百块的，我都认真撸，积少成多。
不懂就混圈子。我在港股打新群里潜水、提问、连结大佬，大大拓宽了视野。
每次打新前我会看各路大V观点、群内情绪，形成自己的判断再复盘。
胆子大。在信息闭塞的小城，一个在A股亏钱的人敢冲港股。
风口来了猪都会飞。
理财要早，小钱也要理。
必须用闲钱投资。听过有人拿老公看病钱去打新，卡没办好钱回不来。

# 本金放大

带我的大佬说港股进入鱼尾，大家转去比特币。我当时觉得比特币是骗局泡沫。但出于信任，想着小额定投试试。进场时价格6000多。大佬说几年后再看会觉得很便宜。我半信半疑开始定投，很快有正反馈。之后把港股攒的第一桶金转入币圈。BNB当时几十，后来到几百。还玩了打新、山寨币，第一桶金就这样被放大，拿到了人生第一个100万。

复盘：
胆子大、盲从大佬，也获得了回报。
运气有时大于努力。
选择大于努力。
能沉住气。我在港股赚到钱时朋友说要立马花，我没动，鹅才越滚越大。
高手才适合短线，我这种还是长期持有靠时间复利。
节点上要杀伐果断，犹豫就错过。

# 币圈低谷

后来被割了一波，币价回到低点，心痛到不再关注币圈。
复盘：币圈骗子多。别搞不懂的项目。币圈一天A股一年，不学习就掉队。止盈止损都重要，落袋为安才是真金钱。

# 跨境电商的试水

在小红书看到跨境电商，觉得又是人少的地方，就入场了。最后选了Coupang，比亚马逊竞争小。风风火火注册公司，还把过程发上小红书。每天上架十几个小时，半个月出第一单。小红书也意外火了，100粉涨到1000，阅读破万。几百人加我微信问ERP、怎么注册公司，我拉群分享踩坑经验。但我不懂转化，守着清高羽毛，不想割人，把想合作的ERP销售都踢了。后来给过500元转化费的机会，我也拒绝了。店铺后期有单但体量起不来，非常消耗。最后把文章都设成仅自己可见，没抓住风口。

复盘：
听课选了非标品家居。
选品还是盲上架，量大概率大，但太累，精细度更重要。
新手出单跟爆款最快，赔本赚吆喝。
发散思维做高复购品。
一件代发从某多多开始，1688也能谈一件发。
爆品是露营灯，撞款但价格差百倍，疫情期间户外需求旺。
墙面贴纸也爆过。
小红书上没及时变现是最大遗憾。赚钱先养活自己，再谈理想。

# 回到服装梦

痛定思痛去学服装设计，面试坎坷，最后进了行业。老板和设计师都很厉害，我想在底层多了解创业会遇到的坑。同时报了小红书割韭菜课想做穿搭博主，后来又觉得硬背书不行太费时间。坚持一个月阅读量几十，期间阳了就停了。身边同事都是打工思维，吐槽老板，和我不在一个频道。合伙人候选人说我不适合打工，会降维。

复盘：
定位不清晰。可以做设计师日常、展会切片、面料市场。
可以连麦给素人出图。
定位要精准，比如给年营收XX万女老板做服装。
素材要提前备一个月。
保证每周2-3更。
最重要的是坚持。

# 差点合伙的服装品牌

离开公司后认识一个有工厂的女老板，想重新做小红书服装品牌。她邀请我聊很多次，感觉很真诚。她柔软怕做决定，我杀伐果断，互补。后来她条款全偏向自己，要求我全职无薪还投钱，我就清醒了。朋友提醒我看得见的账目都是对方想让你看的。黄大仙和室内设计师都说我不适合合伙，我选择自己干。

# 生财改变视角

今年5月参加深圳线下活动认识苏苏，进了生财。之前被知识付费割怕了，这次像海绵一样疯狂吸收。好久没这么专注，上次是2018年。认识了组局大佬叶子、瓜藤大佬等。大佬说赚到钱要回馈社会，格局一下被拉高。后来到北京遇到宋大、start，生财让我这个小透明能和他们对话。

复盘：
生财给了大量无形资产。
多参加线下，每个城市搞钱风格不同，线下干货线上没有。
圈内人坦诚，数字细节都愿意分享。
网球教练说你以为学不会，但一次次修正就会回到正轨。生财大佬的分享也是潜移默化的修正。
新手去线下要多听多看，深圳大佬身怀绝技，听他们讲故事就很提神。
