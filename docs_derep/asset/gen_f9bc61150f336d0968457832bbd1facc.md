# 磁力聚星到底是什么？

说人话，就是快手版的星图接单。别人通过你发的视频或直播间点进去下载、点击使用，你就能拿到佣金提成。

再通俗点，跟直播带货一个逻辑，你负责推，成交了你分钱。

这是快手官方长期在做的任务，佣金看着不高，但量起来了就是稳定现金流。市面上百万粉丝的大号都在做，培训课也卖到398到2980不等，就是因为好上手、好交付。

下面我把从0到开单的流程掰开揉碎讲清。

## 第一步：先把号搭起来

1. 账号准备

### 注册小细节

设备：别用自己日常用的私人手机，换一台别的手机先刷机再上号。
网络：无所谓。之前没做过这块，Wi-Fi还是移动数据都没影响，直接注册就行。

实名和手机号绑定。

一个人最多实名两个快手号，前期完全够用。后期想扩量，就找亲戚朋友实名，或者直接买号。没有渠道的我可以帮忙，这点卡住的人很多。

我这边跑出来的是美女号，直接抄我这套，别发散。

# 第三步：作品发布与开通聚星

前三天，每天发3条。条件允许的话，三天后挑播放过5000的作品，各投10块钱粉条。

播放一般也别慌，该投也投。素材没问题的话，基本3天就能涨到100粉以上，我强调这个是因为磁力聚星开通门槛是100粉。

新手不建议刷粉，正常做基本3天就能破千粉。
