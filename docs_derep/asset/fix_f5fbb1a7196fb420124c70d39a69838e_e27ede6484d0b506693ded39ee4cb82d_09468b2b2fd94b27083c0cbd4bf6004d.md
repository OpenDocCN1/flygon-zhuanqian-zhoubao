# 五小时长谈后，我对创作判断的几次修正

清明假期带孩子去拜访一位长期从事艺术教学的老师，聊了整整一个下午。他的视野很开，谈的内容很扎实，我整理成下面几条和大家交换。

**1、变现逻辑分两条线**
一条是把作品卖向高端收藏圈，买家更看重稀缺感和身份区隔，这条路容易造就符号化的名家；另一条是面向大众市场，比如连环漫画、商业视觉设计之类。顶层市场容量小，能容纳的人不多；大众赛道虽然竞争显性，却更稳、概率更高。

**2、创作之前先补底层学识**
哲学、推理、语言学、传播学、政治学、符号学、心理学，这些领域都值得系统触碰。补齐了这些底层框架，才看得懂一件作品为何能够被群体接受。颜真卿的字法规整，为何长期被推崇？因为当时儒家话语占据主导，儒家强调等级与克制，对张扬格外排斥。作品的共鸣，往往是价值观的共振。

**3、媒介是影响的通道**
他要求所有学生必读马歇尔·麦克卢汉的《理解媒介》。在他看来，艺术创作的本质就是借助载体去影响他人。这一观点和传播、营销的底层逻辑高度契合，也让我很意外，艺术家和传播人其实在谈同一件事。

**4、载体迁移，手法必须跟上**
他很早便让学生用iPad作画，最近又在尝试AI绘画。传统画家会觉得这是对艺术的冒犯，他却用媒介观来解释：壁画离不开墙面被观看，岩画依赖洞穴的空间，纸本作品依赖流通。看不见，作品就不成立。时代的呈现形态在什么地方，创作者就该用什么形态去呈现。

**5、聚焦才能把时间变成护城河**
时间既稀缺也是难以复制的壁垒。年轻创作者哪怕天赋很高，也不要面面俱到。先锁定一个方向，用十年左右的时间反复深耕。粗略算一下：十岁定题，到十八岁已经积累一个类型的作品集，哪怕水准只是中等，申请全球知名艺术院校也具备说服力。

**6、产量和品质共同筑墙**
单靠品质容易被稀释，影响力多半来自持续的输出。蔡志忠是典型案例，西方读者初识中国传统文化，十有八九先看到他的漫画，因为他把老庄、孔孟、四书五经几乎全套漫画化，体量大到无法绕开。现在他带的学员在改编知名科幻作家的文本，用生成工具加速，几天就能完成一本短篇科幻绘本，等总量累积到阈值，壁垒自然形成。金庸、阿西莫夫的高产也是同样的道理。

**7、阅读要有筛选标准**
有些书翻目录就够了，有些书直接略过。时间成本太高，不值得耗在低效信息上。

**8、个体创作者最大的脆弱点是生命本身**
对个人而言，风险集中在生命终止。注重健康与意外防范是基本功。大家庭传承风险相对分散，机构组织有冗余备份，个人则需要更高的自律。

本想请他做一期播客，但他不愿意抛头露面，只能先以文字记录。这些笔记对做内容、做品牌、做创作的人，或许能提供一些参考。
