# 当团队走到绝境，如何让人心不散？上甘岭坑道里藏着的4个组织硬道理

作为创始人或团队负责人，你一定有过这样的焦虑：怎么让成员真心愿意为你冲锋？当公司遭遇至暗时刻，团队开始出现畏难、看不到意义时，又该如何把人心凝住？今天这期内容，不聊鸡汤，聊一场硬仗。

我是小光，之前做过媒体记者和编辑，今天想用我最熟悉的红色战史，来和你聊聊组织管理。最近越看创业，就越像在打没有硝烟的持久战。太阳底下没有新鲜事，正如当年读毛选悟出“蓝海”一般，马云在低谷跑到延安取经，任正非出身部队，华为身上也流着浓浓的军旅基因。今天就从上甘岭战役里，最出名的“一个苹果”连队原型——上甘岭特功八连的14昼夜坑道守御，来拆解极端困境下如何稳住士气。

先给你一张商业对照表，先对齐视角：

1. 战场上的溃兵感≈员工觉得自己在做无用功
2. 战时鼓舞士气的“算账”≈用清晰的逻辑和硬数据告诉团队，这件事的价值在哪
3. 立功马上请功≈阶段性成果出现时，立刻给予认可和激励，让价值被看见
4. 官兵同甘共苦≈攻坚期领导不缺席，带头扛事，和一线同在

上甘岭，你可能只记得黄继光堵枪眼、一个苹果的故事。但这场战斗的残酷程度远超想象。1952年10月，美军为换取停战谈判筹码，发动“金化攻势”，围攻597.9和537.7高地。仅3.7平方公里的区域，美军投入6万余人，300余门105口径以上火炮、120辆坦克、3000余架次飞机，43天内发射炮弹170余万发，炸弹把主峰削低2米。

战役伊始，十五军四十五师的连队伤亡过半。10月17日，134团8连奉命进驻597.9高地一号坑道。八连进坑时，坑道已几乎被毁，出口朝天成“天窗”，手榴弹能直接从上往下扔。空气浑浊到窒息，士气跌到谷底。

[PRE1]

坑道战是志愿军的智慧。我军在山体正反斜面挖通，炮火来时撤到反斜面，敌人进攻时再从坑道杀出。但坑道一旦被控制入口，就等于被卡住脖子。597.9高地共三条大坑道、八条小坑道，八连进驻的是一号主坑道，呈F形，长近80米，顶部有35米石灰岩覆盖。

[PRE2]

10月18日夜，八连摸进坑道。第一件事不是打仗，是人心散了。表面阵地全失，补给断绝，战士们怀疑战斗意义。连队立刻做思想动员并民主表决，结论只有一个：必须夺回坑道口上的阵地，局面才能扭转。

19日反击夺回1号、3号、9号阵地。赖发均掩护爆破时人枪俱伤，匍匐到地堡前引爆；龙世昌左腿被炸断，仍用胸膛顶住爆破筒炸毁主地堡。但20日美军30架次B-26地毯式轰炸，300余门重炮齐射，八连伤亡惨重，被迫退守坑道，仅剩15人。

至此进入第二阶段：守坑道。

坑道里重伤员多过能打的，遗体、硫磺、血腥、粪尿混杂，空气污浊。缺纱布缺酒精，伤员自咬床单止疼。阵地守不住的挫败感，让人怀疑意义。士气跌至冰点。

**第一个硬道理：先把组织架子搭起来，人不会觉得自己是溃兵。**

八连把来自11个单位的70多名能行动战士重新编成一连，重新划班排、任命班长排长，党员团员组成临时党支部团支部，卫生救护组、军械组、伙食统一管理。指挥链顺了，保障有了，战士不再觉得自己是散兵。

**第二个硬道理：算账，把“我们输了吗”变成“我们还在赢”。**

总结战果：两天损失123人，但指引炮火歼敌650人，高地未被推进一步。任务是阻敌、杀敌、拖住敌人——我们没失败。算账运动让大家重新看见价值。

**第三个硬道理：立功立刻请功，让价值被看见、被奖励。**

立刻上报崔汉弼带伤指挥、赖发均龙世昌同归于尽的战功，火线入党。随后下达新任务：守住坑道口，只要坑道在，敌人就过不去。这套“算账+认可+新目标”的组合拳，让士气迅速回升。

坑道口被炸被堵一次挖开一次。敌人用手榴弹炸、用汽油烧、用土石堵、用硫磺熏、甚至放毒气。战士们在外修简易堡垒，借夜色出冷枪。3排长杜天胜一天毙敌32人，三天全连毙敌115人无一伤亡。

**第四个硬道理：领导共苦，真相比安慰更有力量。**

粮食断了，水断了。战士抱怨后方不送。党支部把真相摊开：后方送物资的伤亡率高达90%，军长秦基伟组织火线运输，物资在路上就被炸毁。不是不送，是敌人封锁。困难被解释清楚，反而变成斗志。

10月28日夜，宋德兴冒死送进三袋萝卜，是那晚最盛大的“节日”。萝卜上火，后方连夜采购三万公斤苹果。送上去的几乎全没了，规定送一筐记二等功，仍无一筐完整送达。运输员刘明生途中捡到一个苹果，带回坑道，大家传着吃完。重伤员最后吃到。这个故事，后来成了全国教材。

四、绝地反击

16天消耗战后，志愿军发动反攻。15军133门大口径火炮炮击四小时，虚实结合，打乱韩军部署。火箭炮压制纵深炮兵，八连首先恢复1号3号阵地，歼敌200余名，并将穿381个弹孔的战旗插回主峰。

11月1日八连轮换修整。14昼夜里，45师向一号坑道补充800余人，八连原有138人，伤亡254人，伤亡率183%，却无一人投降溃逃。

[PRE4]

回看那一次次重建，10月18日投入138人，19日晚只剩15人。坑道内72名重伤员、粮弹不足、零下20度却汗流浃背、空气令人窒息，战士埋怨、怀疑、觉得丢脸。就是在这种情况下，他们挺住了。

把这套搬到商业里想一想：公司快倒闭、发不出工资、团队想跑的时候，你能不能做到：

把散乱的人重新组织起来，让每个人知道自己在哪一班哪一排；
用数据和逻辑算清账，让大家看见现在的付出到底换来了什么；
把阶段性成绩立刻兑现成认可和奖励；
困难时领导不躲，带头在一线，和员工一起扛。

上甘岭没有硝烟的创业版每天都在上演。人心不散，才是硬仗能打赢的前提。
