# 大三两年线上变现之路，我的复盘笔记

我是行一，2002年生，目前仍在读大三。接触线上生意差不多两年多，首个六位数营收已跑通，现在在往下一个台阶走。今天把这段经历整理出来，一方面是向一路帮助过我的前辈致谢，另一方面也想给还在摸索的同龄人提供一些实操参考。翻开很久以前QQ空间的旧记录，情绪还是会有些波动。

[PRE0]

高中时期我进的是重点实验班，前三年拼得很凶，最后高考成绩却跌到班里后段。从能排前列到垫底，那种落差让我第一次真正体会到挫败。进入大学后我彻底放纵，几乎每天泡在游戏里，《原神》肝到段位靠前，上课常坐后排开黑，逃课翻墙外出玩耍，甚至被保安追过。假期回到家中，亲戚一句调侃点醒了我，也让我想兑现早年对父母承诺的能自立的想法。

我开始在网上找变现方法和创业案例，信息越多越容易迷茫焦虑。转折点是读到狗哥2021年初那篇普通人实现千万营收的自述，文字很朴实，他还是我的老乡。顺着线索我接触到生财有术，并加入了帅张的星球。那次第一次为社群付费，当晚心里其实很肉疼，事后回看，那笔投入换来的是认知层面的跃迁。

刚加入时我像多数新人一样只会海量输入，输出几乎为零。真正推动我动手的贵人是@拱卒。在他的体系里认识了同龄人@张梦才，跟他学快手小游戏的打法；也认识了@金成，我首条抖音刚上线就被封，他告诉我自己连发三个月抖音没赚到钱还亏了豆荚，坚持就会有结果。那段时间我用搬运号做测试，在结尾做引导，拿到第一笔线上收入约一万元。对原创不尊重这点我很清楚，但搬运确实见效快。后来按师傅建议转做原创，强制每日更新，一个月后快手上的原创游戏片段意外破了百万播放。抄同行拿正反馈，再逐步加入自己的理解，是我一直坚持的节奏。

早期也吃过亏。和学长一起做校园跑腿小程序，我负责新媒体内容，第一次写完整的运营方案，坚持了一个月后因和表白墙小程序冲突被恶意竞争，团队最终解散。那次让我明白先找一个能持续回血的核心业务再扩张，别一上来就铺开多个部门。项目先用最小投入最短周期跑通验证再放大，盲目扩张九成会亏。

知乎好物我做了约四个月，618期间赚了几千。头一个月几乎没反馈，心态反复崩盘，后来被导师一顿批评才开始稳定输出。从洗稿到能自己写，这个过程让我认识到心态和执行都可以被训练，先模仿再超越适用于几乎所有赛道。

快手小游戏我从每天剪一条到用模板十来分钟一条，再到多设备批量生产，收益才起来。但国家推游戏实名后，这条路迅速收窄。转做棋牌和手游依然是跟同行走。宿舍配音是一段尴尬的经历，尴尬的永远是听的人。抖音号再次被封，导师帮我稳定情绪。团购做到四千粉时赶上封寝，只能放弃。我给项目做了阶段划分：验证期、红利期、平稳期、衰退期，并提前构建护城河。行动-反馈-优化-沉淀-爆发，循环走。新的方向至少给自己一个月的投入周期，政策敏感类除外。

蓝海书单我给自己订了21天目标，第17天就拿到首单。做法很简单：找头部账号拆解，一周内模仿，有效就放大，无效就换对象继续抄。批量后需要自己的视频和文案模板，前提是把专注力提上来。把会分心的因素全部写出来，切断信息洪流，专注一件事，执行力自然提升。

电商方向我小范围试了闲鱼，开通Pro后体会到动销率逻辑：成交越多权重越高，自然流量就多。未来想探索无货源或蓝海有货源，比如绿植、宠物用品。相比短视频的脉冲式收益，电商更符合我对长期稳定业务的预期。

最夸张的风口是视频号无人直播。那段时间基本躺赚，首场直播GMV就破万。

[PRE1]

靠搬运爆款素材养号，开播后在线人数很快破万，单日GMV一度冲到五万。风口结束后平台监管收紧，同行内卷严重，硬扛只会消耗自己，我选择停手转战私域。回头看那波更多是运气，但运气来时手里要有打法才能接住。

现在的主战场是小红书。很多人只认得做小红书的行一，其实前面所有的尝试都是积累。我花了半年研究引流，整理了一份超过五万字的引流拆解文档，主攻教育私域，做高中提分、学习方法内容，后续会往考研方向延伸。团队也试了小红书电商，得益于一个朋友给的案例拆解，起量很快，现在属于头部梯队。

[PRE2]

另外，我在带一个近千人的公益实践项目，帮新人实现从零到一的闭环，做利他也做自己的复利。

[PRE3]

两年下来，我最确定的结论是：所有项目都能拆成流量-产品-转化。知乎靠搜索加投放，核心是内容模板和持续输出；抖音快手靠剪辑和模仿，但没有变现的流量不值得做。视频号的爆发期，选品和人性洞察是关键，爆款大多打的是贪小便宜、好奇和白嫖心理。直播的本质是人货场搭建，复制同行直播间是最低成本的学习法。

当下我更偏向长期主义。视频号还在，但上课期间很难深度运营，先搁置。下一步是深耕私域，聚焦小红书引流到微信沉淀，因为私域资产是自己的。流量可以买，产品可以合作，转化可以靠运营加码，但根本还是流量。跟几位千万级前辈交流后，这个认知更坚定了。

如果要总结成绩，大概三点：一是借助视频号风口拿到第一个六位数，小红书电商两个月利润稳定在八万以上；二是做过百万播放的游戏素材，单日GMV过五万的直播战绩；三是真正沉淀了一套可复用的项目方法论和SOP，第三点才是最值钱的。

给还在起步的新人一句话：别等风，先把自己磨成能接住风的形态。行动、复盘、优化、沉淀、爆发，把这套循环跑顺，你的风口会来。
