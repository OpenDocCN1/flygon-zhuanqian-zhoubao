# 一、模式拆解

核心思路是二次创作搬运。将其他平台的热门短视频做去重处理后分发到小红书，积累到一千粉丝后通过渠道对接广告变现。品牌方会提供成片文案，创作者只需按规范发布笔记即可，无需自研内容。合作方式为一口价，发布即结算，不看投放后数据。部分甲方在效果好时会额外给奖励。

我们实地调研并跑了两个月，当前这个赛道供给明显不足。经常出现品牌方的投放需求积压，钱花不出去的情况。

接广告一直是小红书创作者的痛点：单价低、门槛高，还要自己写脚本，收益不确定。[PRE0]

基于此我们花费大量精力对接各大品牌的投放负责人，并自建MCN团队。小红书用户以年轻女性为主，消费力强，对广告主很有吸引力。跟投放方交流得知其常见投产比可达20倍，这就是双方互惠的逻辑。

相较其他项目，小红书接单上手门槛低、逻辑清晰、上号快、变现稳、易于规模化。新手也能迅速看到正向反馈，内测成员普遍表示操作简单，普通人也能通过这一路径实现广告变现。

# 四、项目实操篇

## 1.养号

小红书在公域里审核相对严格，不要照搬其他平台的养号习惯。养号扎实，后续涨粉会事半功倍。

（1）养号周期三天
（2）头两天每天刷一小时同赛道内容，点赞评论收藏关注比例约10:3:5:3，模拟真实用户，别操作夸张
（3）判断依据：进入个人资料往下拉看账号等级，若完成任务仍升不到北鼻薯，说明养号失败或号胚差，基本没流量
（4）第三天再改简介、昵称、性别、头像、地区、背景
（5）同一网络下最多养三个号
（6）别用黑设备，曾频繁注销或被重罚过的设备尽量不用

## 2.起号标准

可接商单的账号需满足：

（1）粉丝破千
（2）单条播放稳定过两千
（3）未被限流且专业号正常

### 1、影视搬运号

素材筛选：在其他平台找百万粉以下的原创作者，并确认该作者在小红书无账号。通过名称、头像、作品三重核对。

核对后要确认作品未被搬运。小红书内多关键词检索标题，检索到同款直接放弃。若视频里有淡水印难以清除，也直接放弃。优先选数据高于账号平均值的作品。

找同类创作者的小技巧：抖音快手的关注页会推荐同领域账号。

[PRE6]

起号方向：内测最快一天冲千粉的号共性是话题极易引发女性共鸣，评论区热闹。婆媳矛盾、家暴、性别歧视、下头男、出轨、逆袭、言情、爱国、热播剧等方向表现最好。选材重于剪辑。

去重方式：
1.加空镜头覆盖画面，不透明度调10%，关闭原声
2.加滤镜，清晰度70-100
3.叠加扫光素材，9:16比例，不透明度10%，关闭声音
4.原视频变速1.1，变调处理，音色音调强度调到10左右，避免违和
5.全程覆盖BGM，关闭原声
注意剪映素材库素材的声音要关掉，带logo部分裁掉

更新频率：千粉前每日3-5条，千粉后1-2条。最佳时段午间12点左右，傍晚5-8点

### 4、泥巴看剧

影视剧+解压视频，可延展为综艺、解说、搞笑梗等。

原理：寻找无声的玩泥巴/史莱姆解压视频，与主领域视频拼接实现95%去重。

操作：抖音搜解压素材，提前设9:16，上半屏放主内容，下半屏放解压视频。确保解压视频无声。

### 5、星座图文号

数据平稳且原创度高，缺点是涨粉慢需长期坚持。

建议：固定一个星座系列，保证每条都能激活存量粉丝。

构成：抖音快手文案+备忘录排版

实操：
1.多平台搜星座图文/视频
2.提取文字
3.用备忘录做背景模板粘贴文字
4.注意排版美观和星座标签突出
5.加滤镜特效、温柔BGM、表情包，发布时间同上
6.优先选评论高赞的素材，重看评论区

# 五、接广告流程

达标条件：
1.粉丝1000+
2.开通蒲公英合作平台超两天
3.近三天单条播放2000+
4.无断更，续更播放维持2000+
5.账号无限流

步骤一：开通蒲公英，实名认证-选个人-填报价-填微信手机号-选人设标签
步骤二：与广告商前一日沟通好，广告商发邀约，博主在入口提交笔记，审核通过后发布。广告商后台确认订单，未确认订单7天自动确认。发布当天不发其他内容，隐藏低播放笔记。

账号做起来后广告商会主动找上门，也可加入MCN获取更多资源。

# 八、疑难解答

判断是否限流：
1.连发三条播放均低于200
2.专业号变灰：主页-三条杠-创作中心-更多服务-开通专业号，查看状态
3.账号等级不涨
4.其他账号搜不到你

限流处理：
1.停更两天后试发两条测播放
2.申诉，部分掉号为流量异常误判
3.注销重建，注意频率和注销次数

报价修改：每月一次，1-25号可修改下月报价

账号注册卡死解决：去营业厅补卡，补卡后编码更新可绕过风控，新手机起号更快。带身份证告知补卡即可。
