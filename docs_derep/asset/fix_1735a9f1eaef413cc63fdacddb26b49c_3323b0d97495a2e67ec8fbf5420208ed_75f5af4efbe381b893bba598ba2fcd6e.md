## 一场公益赠书活动引流 1000-2000+人，后续如何转型带货社群变现？

作者： 落落

日期：2023-09-07

公益赠书表面看是做慈善不赚钱，我为什么能坚持做了一年半？

这次就以公益赠书为案例，把我的实操经验拆开来讲。

# 一、自我介绍

大家好，我是落落，一名零销售背景的造价工程师，副业做了一年半，月收益稳定在3-4万。

本职是工程造价师，每天和数字打交道，主业收入不错，一直比较安稳，从未想过搞副业，也没有带货经验。

我本就爱网购，孩子出生后购物欲更强了。偶然了解到私域玩法，觉得反正要花钱，不如自己参与，既能省钱或许还能赚点零花钱，就此开启副业。

做了一年左右，副业月入过万；一年半后稳定在3-4万。

半年内收入涨了3-4倍，核心是摸透了图书引流的流量打法。每月能持续拉新1000-2000人。

# 二、赠书的底层逻辑

光做赠书本身是没有直接利润的。为什么每个月还要花一周时间去折腾？

原因在于赠书带来的增粉体量巨大。互联网时代，流量就是生命线。

公益赠书的核心逻辑是以公益名义向大家免费发放图书。书本本身免费，但仓储、打包、快递、人工等成本是实打实的，所以会收取15元/套的邮费。每月赠送一套，数量从1本到十几本不等，全国统一15元运费。

领书的主力是0-12岁孩子家长，特别是宝妈。因为宝妈是家庭消费的操盘手，一家人的吃穿用行都由她决定。

这种引流方式和受众，与社群带货衔接得非常顺滑。

# 三、做赠书能得到什么

1、用最低的时间成本，最快拿下精准增粉。

2、配合正确方法能和家长建立联系，积累信任，为后期成交打基础。

3、线下去仓库挑书、线上为家长推荐好书，再加上社群日常资料输出，很容易塑造专业形象，有助个人IP打造。

4、模式跑通后还能开引流课，做知识付费。

总结：借图书链接家长做朋友，建立信任，形成引流→服务→成交→复购的持续增长闭环。

# 四、赠书具体怎么做

**1、供应链必须稳定，图书品质和售后要过关**

我2021年开始接触赠书。最早的平台要交3999元入场费，还要囤一批叫不上名字的小护肤品才能拿入场券。

最致命的是发货极慢，平均7天起，慢的要20天，售后流程长，家长体验差，很容易被骂骗子。

后来我多次筛选测试，最终选定现在的图书供应商。

先后实地去了印刷厂和各大图书仓，从品类、品质、物流、售后多维度对比，最终锁定合作对象。

今年已是合作第三年，我们在品类、价格、口碑、售后上都领先同行。

**2、如何用图书拿流量**

我试过4种引流方式，最成功的是图书引流。

第一种：产品地推，自己囤货去卖，然后拉人进群。精准但累，进货到回款周期长，人力资金成本高，吸粉量有限。

第二种：老客裂变，用红包或礼品激励老客户拉新。精准度低，大多是来薅羊毛的，领完就退。

第三种：线上引流，利用公众号、视频号、小红书、抖音等第三方平台引流，对非全职来说精力有限，建议聚焦1-2个平台。

第四种：图书裂变引流，线上裂变转介绍。目前成本最低、效果最好的方式。我现在每月带家长领一次书，相当于每月做一次流量收割。月均增粉1000+，高峰期2000+。

**3、具体操作流程**

1、先确定当月领书日期。领书前几天去图书仓库挑书拍照，自己去不了就用团队资料。

正式领书前两天在朋友圈、社群预热宣导，介绍活动。

我们每月一次，每次约200种不同品类可选，覆盖科普教育、名人传记、学前早教、绘本、中小学课外阅读、工具书、校规必读书目、教育部推荐书目，部分成人书籍。

每人每月领一套，数量从1本到几十本不等，每月书单更新，不会因领几次就没得选。

无论多少本，全国统一只收15元邮费，含内蒙、新疆等偏远地区。全部是各大出版社正版，性价比极高，售后给力，漏发错发有瑕疵可补发或退款。

物流稳定，一般3天左右到货，这是很多平台比不了的。

2、社群介绍完活动后，让家长发领书朋友圈，文案我提供模板：高转化文案+微信二维码+吸睛书本图。

# 五、获取到的流量如何变现

**1、为已有社群导流宝妈粉，比如亲子项目、线下培训机构等。**

我目前有4个500+的带货社群，直接承接。

做赠书前我就有关注好物社群，但一年时间群里只有200人左右。

通过赠书裂变，不到一年裂到5个400+的群，收入翻了6-7倍。

产品类目覆盖吃穿用行，从平价到高端都有，童装占比很大，和图书引流来的家长人群完美匹配。

因为大部分产品源头把控，质量有保障，价格有优势，加上图书建立的信任，复购率很高。

如果你是零基础、启动资金少、愿意投入时间，图书引流+社群带货是绝佳副业选择，建议试试。

零基础新手直接抄作业，抄对作业永远是成本最低、成功率最高的做法。不偷懒，照做即可。

当然也可以成为公益赠书合伙人。很多全职宝妈一手带娃一手副业实现经济独立，上班族利用碎片时间副业变现，赚到人生第一个百万。

**2、招收公益赠书合伙人**

如何成为合伙人，享受精准裂变引流？

只需388元即可终身加盟，无二次收费。

有专属图书合伙人群，团队每月组织领书活动，手把手教学。提供引流培训，群内答疑陪伴，定期有引流高手分享经验。

素材群每日提供朋友圈素材，助力打造人设。每月领书无套数限制。有些平台一次收费3999元，或399元只管一年，售后跟不上甚至要求囤货。

我们的合伙人无以上问题，学会方法后还能招募合伙人，收到的费用100%归自己。

招到一个合伙人就回本，后续全是净赚。更重要的是学会这套方法后，不管做什么创业项目，你都拥有了流量。

**3、合适人群**

1. 想引流但没有方法
2. 做微商没客户或客户没粘性
3. 做活动成本高
4. 想做副业没项目
5. 需要带娃的全职宝妈

**4、成为合伙人能获得什么**

1. 每月不限量领书
2. 每月获取全国各地流量裂变
3. 每月可卖一次福利图书，获取佣金
4. 提供可落地的副业变现方法
5. 可招募合作人

**5、除了导流到现有社群或招代理，还有一种变现方式是招收陪跑学员。**

很多想做副业却无货源、启动资金有限的新手和宝妈群体，适合用公益赠书积累流量，再用社群承接变现。

但他们在社群带货上缺乏概念，这时可以用陪跑模式手把手教学。

我此前主要自己操作，今年4月加入生财后认识到模式单一，后调整方向。

除了招图书代理，我和朋友配合，从6月开始陪跑了7位学员，从零搭建公益赠书社群和带货社群。

从建群、发公告、邀请好友，到店铺APP使用、选品、筛选素材，全程手把手教。后期建立了图书和卖货素材库、朋友圈素材群。

目前经过两次领书活动，学员已积累种子家长，带货业绩不错。平均首月纯收入600+，7月1200+，8月前10天800+。

虽然和生财高手没法比，但这几位都是没互联网基础、在家带娃的宝妈，连朋友圈都很少发，也一点点带了起来。

为方便抄作业，群里每天提供3条以上朋友圈素材供改编打造人设。

现在朋友负责公众号精准引流和小红书引流，进一步为学员增加初始种子家长。我也在考虑后期为陪跑学员分流50-100位种子家长，帮助更快起步。

**6、注意事项**

领书活动每月一次，根据引流进度再做图书变现。我刚开始做时有引流意识，但并未急于变现。

全身心服务家长约一年后，通过图书群抽奖的方式导流到卖货社群。现在每月转化一次，有需求的家长进购物群，没需求的继续留在图书群领书。

因为信任度高，导流到卖货社群后业绩倍增。即便家长不进群，朋友圈看到产品照样会下单。

我们的产品多为吃穿用行的消耗品，复购率高。现在每月从图书群获客一次，客流稳定。

关键点：所有成绩都基于真诚利他，前期用心服务好家长，后续才有回报。

逻辑很简单：引流→服务→转化→复购，每月一次即可。

我本人有主业，模式稳定后，除了赠书期忙一点，其余时间很清闲，能兼顾工作和家庭，对兼职或宝妈非常友好，一部手机搞定。

最后分享一个小故事。很多人想做副业，但对普通人而言，能落地且赚钱的副业并不多。

今年小红书店铺被很多人提及，我尝试了两个多月，身心俱疲却看不到结果。

无货源模式需要自己选品、找素材、剪视频、发笔记，每天至少发8条以上，我每天投入4小时以上，再加上本职工作和社群卖货，根本兼顾不过来，最终因账号违规结束。

我并非否定小红书，很多人在上面赚钱，主要是矩阵号、足够时间和精力或有一技之长的人。我后续会继续探索小红书的精准引流，以引流和轻创业为方向。
