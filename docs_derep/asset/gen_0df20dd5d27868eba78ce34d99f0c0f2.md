# 摸鱼不如摸技巧：我的YouTube效率工具箱

在视频创作这条路上折腾久了，总会积累一些“早知道就好了”的实用小招。最近在超级标上反复试错，终于整理出了一套能提升效率的野路子，不敢私藏，今天全部分享出来。

**【一、想下载视频？给网址加个“9x”就行】**

这个法子是我目前见过最省事的：在YouTube网址的“www.”后面手动加上“9x”，页面就会直接跳转到一个下载工具界面。MP3、各清晰度的MP4，甚至GIF动图都能一次搞定，而且页面干净无广告。别再找那些动不动就弹窗的下载站了，这个是真的省心。

**【二、订阅列表太乱？用分组管理来“断舍离”】**

如果你和我一样关注了几百个频道，那这个扩展你一定需要。在Chrome浏览器装上PocketTube之后，YouTube首页左侧栏就会自动多出一个“订阅分组”模块。你可以按主题建组，比如把需要拆解学习的对标账号单独放在一个分组里，全部收纳得明明白白，找起来效率翻倍。

**【三、想要高质量截图？装个插件就够了】**

做视频解读或对标分析的时候，截图是刚需。推荐给Chrome装上Screenshot YouTube这个扩展，装好后视频播放条下方会多出一个“Screenshot”按钮，点一下就自动下载当前帧画面。重点是，截图清晰度和播放时的画质完全一致，原汁原味。不过实测下来，Shorts短视频好像不支持这个功能，有点可惜。

**【四、Midjourney角色总是变脸？试试这套“一劳永逸”方案】**

做故事类视频最崩溃的瞬间，就是角色形象前后不统一，用了cref指令也偶尔“翻车”。翻遍教程后我终于找到一个靠谱思路：前期多花一点功夫，后面就能稳定出图——简单说就是先把角色定下来，再生成它的“多面”素材库，之后画分镜时全靠它来垫底。

**第3步：从生成结果中挑一套最满意的，放大保存**

\[PRE8\]

**第4步：用photopea（一个在线修图工具）里的裁剪工具或者套索工具，把不需要的背景清理掉，把角色一个个单独抠出来保存成小图**

\[PRE9\]

**第5步：把这几张小图分别生成链接，之后生成分镜时一起粘贴到提示词后面，作为稳定角色的垫图库**

完成这一步，之后再出图，角色的形象就能一直保持一致，基本不会跑偏了。
