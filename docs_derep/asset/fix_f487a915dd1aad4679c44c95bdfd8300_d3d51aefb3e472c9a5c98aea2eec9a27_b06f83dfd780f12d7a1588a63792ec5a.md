# 从50万负债到月销200万：我用三年把多多无货源店群扛回来的故事

大家好，我是锦李，天津人。大学毕业后我在国内一家上市女装公司做督导，2018年选择出来创业，到现在一直在多多无货源店群这条路上。

这三年经历过顶峰时近五百家店铺，同时也被合作方卷走全部资金，今年才重新打回来。说到底，我只做了一件事：坚持。

**无货源店群的底层逻辑**

多多无货源的本质就是大规模开店，然后从淘宝、抖音、拼多多等渠道下单发货，用店铺体量和SKU体量去摊薄成本赚差价。2021年正是野蛮生长期，公司手上的营业执照和开店SIM卡都数不过来。

**第一波红利：大额券的末班车**

当年最火的打法是把商品标价拉到1000+，再通过工具批量上架限时折扣，配合平台大额满减券吃流量。这一波确实带很多人翻身，我们进场偏晚，只捞到尾段。但即便如此，单店周利润也能冲到2万以上，当时留下的截图就是证明。

22年春节后，原计划继续扩招铺店，结果平台政策急转直下：店铺进小黑屋限流、二次单号管控推广。收益断崖式下跌。我记得很清楚，正月初八那天，团队初六上班，初七定目标，初八聚餐大家还在展望未来。晚上运营告诉我全店断流。连夜开会、同行求助，几天后还是没办法。多多店群的黄金期就这么结束了。

**至暗时刻：合伙人跑路，负债50万**

坏事扎堆来。分公司的合伙人卷款消失，我被牵连背上几张银行贷款，共计50万。公司停摆，正逢疫情，跟了我多年的员工没法丢，我一个人硬撑几个月，刷爆六张信用卡，把最后一个月工资发完后关掉公司。那段时间整夜失眠，朋友见面都问我是不是生病了。

三月我找到合伙人，当晚对视几十分钟没说话。后来才知道他钱拿去还高利贷，赌博输了几百万。追回无望，我选择让步：店留下，钱慢慢还，其他不追究。这个决定让我沉沌了很久。

22年4月18日，我加入生财。那时脑子很乱，失败、负债、疲惫。但看到群里的人一个比一个卷，认知被打开。想明白了，暂时的跌倒不算什么，反转才算本事。

当时就剩我和一个兄弟，两个人扛运营、设计、财务。测试全站推广叠加大额券，以及全站推广的投产薅法，收入勉强覆盖日常开销。

**在生财里试错的项目**

视频号航海我也冲过，最后失败。原因很简单：准备仓促，选品数量少没出爆款；出小爆款后直播时间太短接不住；最致命的是心态。刚赚到第一笔钱就想放大，负债压力下没法延迟满足，大量开号、选品经验不足，正反馈延迟太久。

美团电商是我在十一月从圈友刘家齐的帖子《同行一句话让我抓住美团电商红利狂开30家店》里得到的灵感。当晚看完第二天就去比价验证，确认可行后直接开三家店。创业就是遇到问题就解决，想到就干。最后项目跑通，利润率超50%，整体赚了20万+。

做小红书前我用两天把生财相关内容刷完，精华帖读三遍做笔记。我的流程：先定账号定位人设变现内容三位一体；找30个对标账号，扒近一个月爆款选题记50条以上；以选题反推标题和内容，每条选题整理3种写法，共150条素材，拆解文案结构；最后统一封面风格，用PS定好文字和图片比例。笔记自然就成了。建议新人下场前多看生财的老文章，能少走很多弯路。

**多多店群的新打法**

从疯狂铺货到精细选品，再到大额券、全站薅投产，到今年的强付费店群，三年心血都在这里。今年月销售额突破200万，净利30万+。

现在大家都在聊小红书电商、抖店卡、视频号投流，多多则被调侃狗都不碰。确实，仅退款和无故罚款很折磨。但换个角度，这也是机会：头部不屑做，新手做不了，腰部玩家正好有空间。旧思路走不通的时候，反着来往往有收获。

很多项目像挖矿，挖完换地方。只想挖矿的人，忍受不了播种的等待，最后矿没了，种子也没发芽。这不是坏事，矿里没有果子，另一个矿也可能没有，只要心里有果，总会等来合适的矿。

**精神不死，奇迹不止**

现在多多免费流量枯竭，平台推出全站推广就是为了引导高客单、高质量。上半年我验证的强付费模型，就是靠全站推广实现盈利。

原理是广告换订单，用持续付费产生利润，必须形成平台-卖家-买家三赢的闭环。

几种推广形式：
1. 搜索自定义，关键词竞价，流量偏泛
2. 搜索OCPX，按成交扣费，精准人找货
3. 场景OCPX，按成交扣费，曝光高，货找人，偏泛
4. 全站推广，按ROI或成交扣费，集合搜索OCPX、场景OCPX及各类资源位，是综合形态

起店四步：选品-上架-改销量-开推广

选品三要素：热度、竞争、畅销榜

方法一：畅销榜热词法。去店尊官网找榜单产品的引流关键词，用长尾词去淘宝找货。标准：月销500+、动态评分4.8+、48小时发货。每个长尾词配3个链接即可。

以麻将机通用电源线为例，找价格明显高于同类的链接，再去淘宝找源算利润。

上架用上货工具统一2.2倍加价。改销量通过电商服务渠道完成。

推广核心：全部打开全站推广，ROI设5起跑。分两个阶段，第一阶段平台扶持极速起量积累数据，第二阶段智能期逐渐贴近设定ROI。

[PRE16]

举例，ROI设5，第一阶段可能跑到2.3-2.5，完成约10单进入第二阶段。此时分两种结果：产品竞争力弱，花费归零推不动；竞争力够，花费带来成交。2.2倍加价毛利约55%，保本ROI约1.8。花费1000元，投产3，销售额3000，利润约650元。

付费推广是双刃剑，能放大利润加速增长，也会亏损。必须精细化运营管控投产比。

目前平台对新店有扶持，起店快但不建议小白盲干，没选品经验容易亏。无货源不稳怎么办？我的做法是先用店群测品，跑通后转为自发货，解决拍单、售后、评分问题。强付费本身比较稳，核心是不对抗平台。现在我们和厂家合作小爆款测品，多店铺多产品多链接对冲不确定性。
