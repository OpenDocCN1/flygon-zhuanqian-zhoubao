# 一个“没学历”的人，折腾半辈子，终于明白了一件事

如果说这世上有什么事比做生意还让我发怵，那大概就是提笔写东西了。我连初中毕业证都没摸着，高中也读了个半截。过去这十年，只要碰到书面表达就浑身不自在，总觉得自己肚子里没墨水，话都理不顺，更别说写出什么像样的内容。来生财圈子整整七天，脑子里塞了不少信息，可真要我说出个所以然，又好像啥也没留下。不过总得迈出一步吧。纪钟老师反复强调要“输出”，我琢磨着，那就拿我自个儿这半辈子的经历开刀——别人的故事我不敢说，自己的事儿我总归比谁都清楚吧？

我出生在一个乡镇家庭，条件不算差。父亲是电工，性子热心，邻里谁家有事他都愿意搭把手。这份热心肠影响了我很久。最神奇的是，后来我到了县城，经常碰到一些看似毫无关联的人，却都认识我父亲，而且还不是一次两次。那时我心里就埋了个念头：将来也要成为父亲这样被人记住的人。可惜命运没给我太多时间——我22岁那年，一场意外夺走了他。母亲走得更早，我八岁时她就因故离世，我对她的记忆已经很淡，只隐约记得她是个能干又本分的传统女人。她走后两年，父亲重组了家庭，继母又给我添了个弟弟。如今回头想，我身上很多性格和处事方式，其实都是从继母那里学来的。说这些，无非想表达父亲对我的影响有多深，可一旦铺开讲，又怕变成一堆冗长的家族流水账……

小学三年级以前，我几乎年年拿奖状。后来被送去寄宿学校——那时候刚流行起来——却成了我一段灰色记忆。我从小有尿床的毛病，住校后每天都活在惊恐里，怕被人发现、被嘲笑。该来的还是来了，不过后来这毛病自己慢慢好了，也算因祸得福。除了这件事，当时最让我不安的，是担心父亲带着继母和弟弟远走高飞，扔下我不管。这样的心理包袱压在头顶，成绩自然一落千丈，奖状再没沾过边。后来上初中，因为一次打架被劝退。初三寒假，我跟着村里一位师傅去太原贴墙纸；来年三月，家里又托关系把我塞回高中。可那时候网瘾早已扎根，天天半夜翻墙去网吧，白天迷迷糊糊，书压根读不进去，撑了一年又退了学。

那段时间家里开着饭店，我便在那打杂混日子。父亲看着着急，说总得学门手艺，要么开挖掘机，要么学修车。说心里话，这两样我到现在依然毫无兴趣。后来大伯一句话点醒我：“你既然那么爱折腾电脑，除了打游戏还会弄点啥？”我说我能自己做小动画，其实是照着网上的教程，一帧一帧地画了台风扇，还做了个按钮开关。现在回看，那会儿还挺有成就感。大伯建议我去学游戏开发。我乐坏了，父亲陪着我去学校咨询。记得老师问我颜色有几种，我绞尽脑汁说了个“画笔箱里36色”，他笑了笑没说话。后面一连串问题我都支支吾吾答不上来。最终结论是：没有美术功底，别碰游戏动漫设计，倒可以学编程。就这样，我进了一家没有学历的培训班，学的是Java。

我心里清楚，这大概是我人生最后一次当学生的机会了。所以那段时间格外拼命，听课、预习、复习、写作业，样样都不含糊。刚开始步履维艰，渐渐发现学习也没那么可怕。三个学期，每学期都做项目，拿过第一名一次、第二名两次，优秀学生连续两年上榜，据说毕业后老师还把我当案例展示了好几年。

13年底我北漂到北京。那会儿我的年龄和简历完全对不上，想虚报也没用，毕竟身份证一亮就露馅。不过运气不错，不到一个月便找到工作，月薪四千。面试时他们问我多大，我随口说91年——其实我是94年的。接着又问“属什么”，我脱口而出“属狗”。全场一下笑翻了，我还没反应过来。缓过神后，我硬着头皮圆场：“我爸想让我大学毕业后参军，故意把岁数改小了。”最后甚至豁出去说，给我一周试用期，不行我转身就走，工资分文不取。那位经理好心放了我一马。我当时参与做的产品，类似后来的“饿了么”，可惜没等到春天，来年四月公司就解散了，我只好打包回郑州。

回郑州后没找到合适工作，草草上了两个月班，又被世界杯那场德国7:1巴西的比赛牵动——一个朋友赌球，我也鬼使神差地跟着下了注，输得心情郁郁。七月，我干脆去上海投奔老同学。

九月，我在上海落了脚。公司不小，部门却只有三四人，日常就是维护那套CRM系统，活儿不多。我有个习惯，老盯着领导看他什么时候去抽烟，估摸半分钟再跟出去。日子一久，领导也开始主动招呼我。聊得深入后他透露过，心里不甘于现状，等一个合适的契机，眼下只要做好手上的事就行。我每天就跟吃了他画的大饼似的，一口一个香。

到了15年初，他说的机会真的来了——公司要上马一款P2P理财APP。我跟着领导跑前跑后，调研、定需求、梳理业务逻辑、写文档……一切看起来都在正轨上。等真正开发时，才傻了眼：技术栈选的是领导擅长的.NET，而不是Java。我当时整个人都慌了，回去写了封邮件，主动提出辞职，还话里话外表示对公司不舍、对自己无用武之地的遗憾。第二天领导把我叫进办公室，说选.NET并非要丢下我，公司要往前走，需要更多人支撑。他让我转做项目经理，一起把产品做出来。那之后整整一年，几乎三天两头被骂，团队里也有人不配合。最极端的是一个上海姑娘放话说，如果继续按我的方式管，她就辞职，要么她走要么我走。领导知道后只回了一句：“你没做错，她走就走，心态放平。”那一年我没上过任何管理课，全靠第一个到、最后一个走，在实际工作中一点点试错、纠偏，最后竟也把项目理顺了。事后我总结出一句话：管理管的是过程，不是结果。

16年我们换了阵地，从陆家嘴搬到徐汇，成立了分公司，我也有了独立办公室，最高峰管着三十多号人。名义上是产品经理兼项目经理，职位却挂着总裁助理——小公司嘛，一切都挺混乱。那会儿我开始有点感觉了，偶尔把员工叫进来，让人倒杯水，说几句有的没的鼓励话，大家也乐呵。那一年我们累计交易流水做到1.4亿。领导把我叫去说要升职加薪，还透露自己可能调回集团，这里需要人来接手，他属意于我。但因为没法向集团交代，他提议让我接下法人的身份，顺便把职位升成总裁。我犹豫再三，还是答应了。现在看，纯粹是出于信任。可变更完法人后，工资涨了，职位却没动，老板也没调走。我忍着没多问。年底领导开始玩虚拟货币，拉着我投以太坊挖矿。我对那东西一窍不通，但他叫干就干。

17年政策突变，产品再没升级过，公司也停滞不前。这一年除了跟着领导挖矿，我私下也去二级市场买币、投项目。那半年堪称魔幻：十万本金，六个月浮盈膨胀到350万。没错，是三百五十万。我取现20万回家过年，整个人飘到了天上。抽支烟的功夫，账户就能波动几千块；睡一觉多出三五万也习以为常。那时候你要是跑来跟我讲什么“生财之道”，我恐怕白眼都懒得翻：你算老几？哈哈哈，真就是那种心态。可好景不长，下半年公司被集团收回，领导和我都不愿回去，就临时在他家别墅里搞新项目。当时大家都靠币赚了钱，心思早已不在创业上，项目自然推不动。一直到元旦那天，聊起矿机的收益分配，矛盾彻底爆发。另一个投资矿机的同事指望算账分钱，领导却觉得挖矿本就是带我们入行，我们已经凭这个赚够了，不该再惦记其他。我侧面了解到，领导自己始终在加设备，没怎么买币，看到二级市场价格疯涨，心里不平衡。按最初投入，同事至少能拿15万，若算上复投可能到45万，我情况也差不多。结果我们只各得了大概5万块加两台旧机器。那天之后，我和这位亦师亦友的领导彻底断了联系。至今我还会梦到他，他对我的影响太大，我依然想念他，只是那道裂缝已经无法弥合，不知该怎么面对了。

18年一过完年，我从上海回了老家。手里有钱，父亲却不在了，心里只想着离家近些，顺便照看家庭。老家有个牛场——父亲生前租地盖起来的，我非要给它重新盘活。不少人都劝我，隔行如隔山，想清楚再说。可惜我当时膨胀得很，觉得自己又有钱又有经历，别人能养牛我凭什么不行？我甚至设计了一套互联网众筹养牛的商业模式：进场五十头牛，先给牛上保险，再众筹出去，养成了利润抽25%作为管理费；钱回来继续买牛，滚到三百头规模，再去政府那边申请补贴，怎么想怎么美。牛死了有保险兜底，牛养成了大家分钱，积累够客户还能按部位冷链分割卖肉，利润更高。可牛一到场，保险公司却说两周后才能来看牛签合同。后来才明白，牛长途运输后会有应激反应，得观察稳定下来再说。我那个亲戚虽然号称养了十几年牛，可从来没伺候过五十头的规模，一下子全乱了套。牛群应激反应很大，我四处请专家、找教授，花钱如流水，自己还学会了配药、打针、输液，基本就住在牛棚里。两周内还是死了18头。等好不容易稳住，有老师傅说其实牛没想象中那么脆弱，是我前期处置失当。保险后来我也没有再买。除了最初那批损失，后面只有一头牛体质弱，一直病恹恹，其余倒还算平安。可老天爷似乎嫌我不够惨，我装修好的两间办公室一天都没坐，被一场大风刮断的树压塌了。

养牛时我从投资里抽了一部分钱，又找朋友借了三十万——为什么不全用自己的？因为我还舍不得卖币，觉得还能涨。结果18年熊市如期而至，账户天天缩水，越缩我越心慌，加上手上瞎操作，350万变110万，110万变70万。再到后来忍不住碰了合约这种高杠杆的玩法，八月份全没了。钱没了，养牛的债还压在身上三十万。

我终于承认，自己并不是什么料，只是站在风口上的猪。风停了，猪还以为自己会飞，一脚踩空摔死在地上。

人可以忍饥挨饿，牛不行。育肥阶段一个月就要吃掉一万块精饲料。没办法，我回头找到前公司的总监，18年底再次去上海，拿两万五月薪，项目总监的头衔。表面风光，实际内心已经掏空了，纯粹硬扛。倒不是说日子过不下去，除去牛饲料和日常开销，工资还有富余；那些欠账也不急，牛一出栏就能补上。但我的几百万永远回不来了。我每天都在懊恼和不甘中煎熬，总觉得不该这样，又觉得是自己心太野，看不上这种按部就班的日子。那种复杂的滋味，我不确定现在能讲明白。大约撑了三个月又离职了，跑去贷款，又投区块链项目。命运总算眷顾一次，年底拿回来14万，我立刻提现，然后再次想回家。

19年牛卖出去了，债务清零，我回到郑州。2014年认识的那位老板有个“云桌面”项目，让我跑跑业务。我觉得沟通是自己的强项，公司还在起步，好好经营总有机会。但心里始终被过去搅得不得安宁，跑了几个月市场便放弃了。后来也零零散散换过几份工作，不提也罢，基本都是混日子，毫无成就。

2020年疫情来袭，我终于静下来认真考虑未来要怎么走。当时报了“人人都是产品经理”的90天课程，老老实实学完，虽然吸收有限，但好歹算系统入了门。在郑州换了一份新工作，做了半年，公司团队解散。后来去了一家软件公司做项目经理，带了十来个人。年底又投了一个项目，本金39万，到年底回本。不过这种广撒网式的投资风险极大，现在回想起来仍然后怕。

2021年初我盘了下账，没有负债，又嫌打工薪水太低，还是想再去上海闯一次。这一次职位仍然是产品经理，月薪两万五。但明显能感觉到自己在人才市场里不太吃得开了，面试能过已是侥幸。工作中屡屡碰壁，撑到五月，之前投的项目又暴雷跑路。好在我这个人谨慎，算下来总账还赚了些，加上存款大约25万。手里一有余钱，创业的火苗便蹭蹭往上蹿。七月我回到老家县城，开了家公司，加盟本地信息平台，做招聘和抖音探店，自己拍拍剪剪，日子倒也充实，一个月能赚万把块，在县里过得很满足。十月，本地一个广告公司老板找上门来谈合并，答应给我15%股份，让我当总经理。十二月份谈妥，一直做到现在。

2022年初两家正式合并。我开始放开手脚大干，一年做了150万业绩，比前一年最高60多万翻了一倍多。合伙人高兴得不行，我也觉得这才是我这几年最投入的一件事。可心里那股不安分又冒了出来。下半年我做了中医带货的短视频，第一个月就赚了14万。合伙人提起他朋友单干一个月收入更高，我便跟着研究，没想到自己上阵后第一个月也有两万三的带货量，赚了一万多。这种回报率太诱人，我当即复制模式，拉了那位朋友入伙。三个月后新公司成立，第一个月赚了14万，后面继续扩张团队，却连续三个月亏损，坚持到第六个月撑不住解散了。原因挺讽刺：第一个月赚钱后，负责技术的那位朋友觉得他自己干就行，没必要带我们分钱。其实我开给的条件真的不差，甚至比我自己当总经理拿的还好。我一直想不通，后来才知道他没有说出的另一层原因——整个中医带货赛道在那段时间遭遇大规模封号，行情已然转冷。我自己再试怎么都做不起来，还被合伙人埋怨，一度自责不已；后来打听，那位朋友同样金盆洗手了。

说起来，那大概是我这些年来最接近“翻身”的一次机会，可惜错过了。

2023年业务开始走下坡路。我有些心不在焉，觉得好多事不一定要亲力亲为，放手让团队去干就行。结果年底一算账，业绩滑到90万，也可能有疫情余波的因素。这一年我还做了好几笔投资：买了辆网约车，到现在每月租金三千，开到报废才勉强回本；和朋友做抖音电商，年初年末各赔一次，合计15万；跟一个合伙人投了10万开餐饮店，倒是十个月回了本；还有美团成人外卖店，月入四五千，投入不大也还凑合；另一个人投了区块链游戏打金的项目，是上海朋友推介的。我不甘心之前亏的那些，又去尝试小红书电商，结果依然没能翻身，时间和钱都交了学费。

2024年我对公司的事越来越提不起劲，抖音本地生活也试过，没成气候，业务还是单一的社区广告，业绩平平。年初那晚我特别庆幸——打金项目刚赚到四十万，我当场决定撤出，结果停止操作才一周，整个盘面便崩得稀碎，我算是踩着点逃出来，还落袋三四十万。餐饮店那边因为和掌勺师傅一直合作得不痛快，最终转让了，算下来回本后盈利6万，我分了2.4万。后来我们又投了一个加盟餐饮品牌，本想着做成旗舰店再开分店，但出于对厨师的阴影，只好放弃直营，选了个省心的加盟模式。成人用品业务也慢慢收缩，外卖店交给小弟打理，还加过体验馆和无人售货机，如今只留下无人售货机还在运转，其他都关了。

写到这里，我已经没什么耐心了。说实话，这篇东西能不能发出去，我都无所谓。过去我常常回想自己的经历，但从来没像这样白纸黑字地写出来过，写完之后的感觉完全不一样。这些年我一直在折腾，如今却还背着六七十万的债。好在压力并不算大，每个月流水能稳定撑起一万多的还款。我自己买了房，自己动手装修，在朋友眼里日子其实还挺体面。公司里我有15%的股份，算是有个身份和落脚地；餐饮店占四成，每月能带来六千左右的分红；无人售货机每月一千出头；网约车租出去月入三千。如果只看这些，生活会很滋润。但恰恰是今年，我陷入了从未有过的焦虑。说不忙吧，一天到晚被细碎琐事填满；说在忙吧，又感觉一事无成。我试着把很多生意都停掉了，但这并不是我想要的终点。我特别想打破现状，重启一次。前两天去参加同学孩子的满月酒，遇见一位老同学，深受刺激。那件事其实我早有认知，只是一直没行动。现在我很想认真去做，却不知道入口在哪。

说说我姐夫吧。他从大专室内设计专业出身，最开始做家装量房的业务员，后来转到家具建材销售，一步步做到某大型家具的销售总监，再后来自己做了高端家具品牌。如今一年收入轻松过百万，家庭幸福，时不时出去旅游，整个人从容得像下棋的人。我当初刚认识他时完全没料到他能到今天，不得不承认，他让我羡慕。

另一个例子是我表哥。初中没读完就出外打苦工，后来开始带队，再后来跟随一位领导做工程，天南海北跑，做的都是同一种业务。等到领导升迁，他便垫资接项目，一个工程能赚几十万，手上同时开工的有四五个。有次我好奇问他哥你赚多少？他轻描淡写：还有五百万在别人手里没结回来，自己垫资就有三百万。听得我哑口无言。其实我一直没觉得表哥多厉害，他实在太低调了，低调到从不显摆。

可回头看我自己的路，跌宕起伏，折腾半生，有过高光也有至暗，到最后仍处在迷雾里。也许写下来，才是真正的开始。
