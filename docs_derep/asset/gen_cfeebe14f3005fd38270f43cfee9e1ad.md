# 一、我为什么选AI知识付费？

今年“AI”这个词，简直在我生活里刷屏了。

### 1、学员给我的反馈

在做AI之前，我做的是美术赛道的知识付费，卖工具+卖课程。学员在学画的过程中，反复跟我提到“AI绘画”这个词。而且我在做美术直播时，也看到同行直播间经常用“AI”来吸引家长注意。

[PRE5]

### 2、朋友圈、公众号、社群都在聊AI

微信里到处都在聊AI，朋友圈、公众号、聊天群、短视频平台，还有曹大的知识星球里，都反复出现AI相关的内容。我基本判断：AI是一次大机会。加上我本身好奇心强，就主动去搜索学习，第一时间在电脑上装了ChatGPT体验。不过一直到9月，我其实还在做美术直播。

### 3、放弃旧项目时，偶然刷到卖AI课的直播间

美术知识付费这个项目，我最终决定放弃，得找新方向。印象最深的是9月份刷到一些大博主的直播间，一场直播卖AI课能出500单，我真的被震撼到了。

然后我就赶紧深挖，找到更多同行，发现很多博主都在抖音卖AI课，头部博主一天能卖1000单199元的课，一天就是20万，累计几万单。这个数据是我做直播以来很少见的，我当时就断定：这个项目天花板很高，比美术赛道高太多了。

### 4、观察不同平台对AI的需求

除了抖音，我还看了视频号和小红书。小红书没看到卖得很好的案例。但视频号有很多小博主卖得不错，一天两场直播能出300单。还有刚做视频号不久的博主，三个月也累计了3000单。

到这里，我已经确定要做AI知识付费了。为什么我觉得自己能做？因为我体验过ChatGPT，发现它并不难用。而且像那些以前卖短视频课、从没接触过AI的博主，都能来卖AI课，说明门槛不高——说白了就是60分的人教别人做到20分的事。

我还观察了各大博主的直播，发现直播卖课的核心本质，并不在于你拿AI做出多牛的东西，而是靠嘴去塑造AI的价值，同时建立自己的人设。这个逻辑，和我之前做美术知识付费是一样的，所以我一定干得了。

那选抖音还是视频号？我的答案非常坚定：必须是视频号。之前做美术项目时，我就深刻体会到：视频号卖课比抖音好卖一百倍。当时就是在抖音卖不动，被迫转到视频号，才起死回生的。

视频号的用户大多是宝妈和中老年群体，人很单纯，没被直播电商“教育”过，成交容易得多。而且视频号用户很包容，只要你敢表现自己，就能拿到流量。哪怕是真人出镜照稿念，没有任何感情，都能卖出课。

在抖音就不一样了。就算你有大流量、大投流、成熟的主播经验，也不一定卖得动课。现在抖音卖课多数要公域转私域再成交。

我举一个例子：很多博主在抖音拍AI视频火了，流量巨大，但一开播，直播间也就几个人，根本卖不动。那些直播间里有上百人的AI卖课主播，基本都是付费投流出来的。

而视频号呢？只要你的视频有流量，攒一波预约再开播，随随便便就能出几十单，一点都不夸张。

所以说，视频号就是红利，就是小白的机遇。我毫不犹豫选了视频号，而且我的视频也不发其他平台。赛道选好之后，第一件事就是快速找对标账号，像素级模仿。

找对标是超级重要的能力。好的对标能让你思路清晰，知道该做什么、往哪走。而且不能只找一个，得多找几个账号，从多个维度去模仿，才能把这件事做好。

# 二、我是怎么找对标账号的？

像知识付费这类项目，我需要三套对标：课程对标、视频素材对标、直播对标。

如果你只模仿一个人，大概率做不好。

我看到很多同行只模仿头部主播，结果没一个做得好的。原因有两个：一是大博主积累了很久的IP势能，小白很难模仿；二是他们的流量大多靠付费，没钱根本跑不通。

那小白刚入场，应该怎么找对标？我的做法是：找AI行业的大、中、小博主，不同平台、不同板块拆开来学习。

我把它们分成三个独立板块：课程对标（交付）、视频素材对标（流量）、直播对标（转化），然后基于低成本创业的理念，同时推进。

## 1、课程对标（交付）

我先去买各大博主的AI课，自己全部看一遍，结合他们的课程整理出目录。用飞书妙计把文字稿转出来，做PPT，再用直播伴侣录课。因为我以前当过老师，讲课这块我很擅长。把流程优化后，从开始到上架初版课程，前后只用了5天。

[PRE8]

这里要提醒一个误区：不要等课程全部做完再卖，也不要等你觉得“课程够好了”才开卖。你要做的，是边修窗户边补轮胎。项目初期的录课，非常消耗心力，而且没有任何正反馈。

所以先把初版上架，等有爆发的迹象再持续更新就行。对用户来说，持续更新本身也是重要交付。如果非要等课全部录完再卖，黄花菜都凉了。

交付过程中，我遇到的最大难题是：AI工具怎么持续提供给用户？我不懂研发，甚至AI也是现学现用。我看了大博主的做法，他们是自研AI工具。我也去问了自研成本：套壳2万，每月还要维护费。对我来说，这个方案直接否掉。

刚开始创业，低成本绝对是最重要的。一开始就背负太大压力，只会影响发挥。而且2万对于当时的我来说，真的是一笔巨款。

那就不能看大博主的交付，得看中小博主怎么做。我发现他们很简单：用国内免费的AI工具，比如文心一言、讯飞星火、度加剪辑，在课程里一步步教用户下载，就能让用户用上AI。这本质就是信息差，但帮我省下了巨额成本。

有没有自研AI工具根本不重要，直播卖课时把话术改一改，效果完全一样，但成本能省上万元。

[PRE9]

我选择的是轻交付：一门199元的课，学员拍完加微信，我本人一对一指导，这也能让学员更安心下单。别担心一对一指导会花很多时间——实际上，99%的问题学员看课就能解决，真正来问的很少。

我每天固定三个时间段统一回复消息。现在有2000名学员，每天一对一答疑加起来也就半小时。

交付做轻了，我就能把重心放在流量和直播转化上，专心搞流量、搞成交、搞利润。

课程搞定后，核心问题就是：流量从哪来？

## 2、视频素材对标（流量）

我认为，做知识付费，不管你是自然流还是付费投流，视频素材绝对是核心中的核心。没有素材，就没有流量，投流也投不出去。而我获取流量的核心就一个：找对标，像素级模仿，永远别自己造轮子。

AI在今年3月份已经在短视频爆发过一轮，市面上有大量被验证过的爆款文案。到10月份我开始做的时候，素材已经多到可以随便模仿。

我要做的，就是把各大平台关于AI的文案全部扒下来，只要是点赞过千的，有一个算一个，扒下来自己真人出镜口播。抖音的文案用轻抖小程序转文字，视频号的视频就先录屏，再用轻抖识别文案。我一天能拍十几条视频。

前期我都是去出租屋旁边的河边拍摄，回来自己剪，一条大概40分钟，一天产出3条素材，基础流量就有了。

[PRE10]

如果能真人出镜，一定要真人出镜口播，这是为后面的直播转化做铺垫。真人出镜的转化率绝对非常高。不要担心自己表现力弱，这都是练出来的。等你拍了上百条素材，面对镜头自然会变得很自然。

对视频号来说，面对中老年群体，不需要多专业的拍摄技巧，反而是越接地气越好。我前期所有视频都是用苹果11前置摄像头拍的，在剪映里打开提词器，直接怼脸拍。

讲话语速一定要慢一点，搭配手势和眼神会更自然，不要一直盯着屏幕。总之，先拍起来。只要你照稿子念完，视频就会有流量，因为内容本身是火过的。别担心抄袭，你一字不差地念出来，也是自己的原创。

拒绝花里胡哨的剪辑和高大上的场景，一定要简单明了：语速慢、声音大、字幕大、画面清晰。不需要转场、音效、重点文字变色这些花样。因为你会发现，很多在抖音爆火的AI视频，在视频号根本火不起来，原因就是中老年人不爱看。

一定要坚持拍素材，不断优化拍摄和剪辑。直到现在，我每天还会花一小时刷视频找素材。没有素材就没有流量，就算花钱投流也没用。

对新手小白来说，最好的方式就是拍素材、拿自然流。

同时一定要打开直播预约，这点非常重要！直播预约就是用户在看视频时，视频下方会出现预约条。他们如果感兴趣，就会点预约，开播时会收到微信直播通知。预约进入率一般有50%左右。黄金时间是晚上7点半到9点。

PS：直播时发的视频不会显示预约条，但会出现直播入口，引导用户直接进直播间。

[PRE11]

前期预约可以放到3到5天后，每天发3条素材，就算播放量一般，也能攒出预约来开播。如果视频爆了，就临时加一场预约在当天。预约积累能撬动直播推荐，也能让你在开播第一波就有足够多的听众来成交。我自己卖课的主要成交，都发生在第一波。

前期我先运营一个账号，每天发3条素材，两天开一次播。在视频没火的情况下，有一场直播总共有202人看过，但就是那天，我照着稿子读，卖出了4单199元的课。如图：

[PRE12]

当时我真的惊叹：这就是趋势的魅力吗？对比之前做美术类目，一天播三场，卖课难如登天。视频号上很多直播间上万场观，一单都卖不出去，都太常见了。这也验证了我的想法：选择大于努力。同样的努力放在不同类目上，结果完全不同。

## 3、直播对标（转化）

那我是怎么把转化率做到这么高的？平均50个人看直播，就有1个人下单。这在前期的直播里基本是常态。接下来分享我的直播转化流程。

想要直播转化好，你得先搞清楚你的客户是哪个年龄段、什么身份，然后对症下药。

比如我做AI知识付费，我的客户绝大多数是中老年人：50岁以上，有钱有闲，对新事物好奇。所以直播话术一定要按这群人的需求来设计。

核心是“抄”。第一步，先整理直播话术稿。我会蹲守录制各大博主的直播间，反复听，以头部主播的话术为主，分析他们的话术结构是怎么促单的。

一定是多个主播、多份话术结合，不要全盘照搬。结合视频号的调性，整理出我自己的话术。包含：实操讲解、课程钩子、憋单话术、逼单话术。

[PRE13]

比如A博主直播话术以讲解为主，很少实操，但成交部分做得特别好，我就把他的成交话术全盘抄下。

B博主则注重实操，对中老年人特别合适，能直观感受到AI的强大。但他的实操主要面向年轻人、打工群体，比如写表格、做PPT，老年人用不上，不过我可以借鉴思路做修改。

最后，我结合视频号中层博主的实操案例，改成健康问题演示、风景视频制作，成交部分用A博主的话术为主，拼在一起就成了一份转化率极高的话术稿。字数12000字，读完需要40分钟。

[PRE14]

初期可以照稿念，一样能出单。但最关键的是把它背下来，以理解为主，全部背熟之后，你就能演好一场又一场的“好戏”。

为什么说是好戏？因为我认为这种直播本质上就是一场演出。你把台词背熟，每句话对应的语气、动作、眼神都排练好，直播时就是现场表演。每场都演同一出戏，一场直播演3轮，总共两小时。公屏上的互动问题交给运营处理，你只管表演。

直播形象上，因为我是00后，上镜显得嫩，所以我特意打扮老成一点：梳大背头，戴金丝框眼镜，穿黑色西装衬衫。夏天短袖、冬天长袖，各买了四件，固定穿搭。背景就直接买了一张书房背景贴纸，没什么讲究，就这么开干了，到现在还是同一套形象。

只要有流量，就能咔咔出单。我用这套话术逻辑，最高记录在10月31号连续播了6小时。当天两个号的视频都爆了，小号单场出了104单，大号2小时出了43单，一天8小时卖了将近150单199元的课程。后面还有好几场直播破万，朋友圈也专门记录过。

正是前面有了大量的直播练习，视频爆的时候，我能马上开播接住流量做转化，终于尝到了一波大单的滋味。而这一整套流程，全靠我一个人摸索出来的。后来配了一个运营，两个人就这么干起来了。

有一天，我刷到之前关注的视频号情感号博主，发现他们有很多矩阵号，而且能同时开多场直播。素材稍微改一改，发几个号都有流量。这让我坚定要做矩阵。因为单个账号的价值太有限了，流量积累要靠时间和概率。

简单算笔账：一个号一天发3条视频，没爆的情况下每条流量1000，攒两天预约就能开一场播。那如果我有两个号，就相当于每天都能直播，每天都有收入，而且爆的概率翻倍。再往后类推，数量越多越好。正是这个决定，给我带来了巨大的效益。

我马上又注册了一个新号，每个号一天怼3条视频，早中晚固定发。结果新号一周后，一条视频爆了20万播放，来的流量非常精准。中午醒来直接开播，一场干了6小时，话术循环了10次，出了104单，这也是目前单场最高纪录。

老号也在同一天爆了，我错开预约时间，先播完新号的6小时，简单休息一下，继续开播老号，又出了43单。一天营业额差不多3万。10月整体做到了8万营业额，这基本就是利润。

为什么那天能疯了一样干6小时？而且不是划水的直播。知识付费直播需要一直保持亢奋情绪来带动成交。6小时里我不休息、不上厕所，只是趁展示工具的间隙，用30秒塞点面包和水，一直保持状态。

原因很简单：被同行刺激到了。就在我视频爆的前一两天，好几个同行一场直播能出100单、200多单。他们也是视频火了马上开播，不用预约，视频就能源源不断把人带进直播间。我明白这个底层逻辑后，就懂了：只要视频火了，就可以立刻开播，播到流量耗尽为止。

还有一个原因：大家都是一起起步的，凭什么我不行？我不服！

我一直憋着一股劲。也正是这股劲，让我中午刚睡醒、没吃饭，看到视频爆了3万播放，立刻开播。当时没想过能出多少单，就是不服。没想到每循环一次话术就能出单，我循环了10遍，突破100单！目标达成，那股劲才松了下来。

我特别感谢同行。如果不是他们视频爆单让我发现这个规律，我也不可能做到单场百单。但说实话，直到现在，我再也没有当时的勇气连播6小时了。现在播3小时，心力就耗尽。

到了这个阶段，我明显感觉精力不够用。视频火的时候我得直播，就没时间产出新素材。我的事情太多：找素材、拍摄、剪辑、客服、直播，几乎全是我一个人。一个人运营两个号已经到极限，后面还要做更多矩阵，所以当下最重要的是招一个剪辑来分担视频工作量，保证每天有素材产出，同时我才能把精力放到流量和转化上。

这里分享一点个体招人的心得：

要求很简单：会剪辑，为人坦诚，工资管够。

第一，有经验，就不需要培养剪辑技巧。我把剪辑流程和要求优化好后，员工上来就能直接干。剪辑只需要专注剪辑，其他什么都不用管。每天6小时在工位高效产出，做完就下班。

第二，为人真诚，不绕弯不矫情。我招人，先看人品再看能力。有事直说，你对视频有好想法就提出来，用案例说服我。我有要求也直接提，同样用案例说服你。你嫌工资低，也直接说，我们根据你产出的价值来商量。

跟这样的人共事，沟通效率极高，做事干脆利落。这些也是我在《不拘一格：网飞的自由与工作责任法》这本书里学到的，里面还有很多好方法，推荐大家看看。真诚，是最好的沟通方式。

# 三、售后踩坑

做知识付费，售后是非常关键的一环。你不能永远拒绝用户退货，不然平台客服介入，售后纠纷率会飙升。

11月底，平台突然给我发了一条消息：老号店铺永久封禁，资金冻结一个月，账号永久无法带货。没有任何提醒，直接永封，而且官方一旦判罚，基本申诉无望。这个项目里，我算是遇到了一个小挫折。

[PRE19]

更巧的是，封号那天，老号正好有一条精准视频爆了200多万播放。我只能眼睁睁看着流量流失，无法变现。按以往的经验来算，这条视频最低也能出500单以上的199课程。

[PRE20]

换成以前，我可能好几天吃不下饭。但这次，我的状态没受影响，只是觉得有点可惜。因为我知道，我有能力再做出很多个同样的号，还有其他号能兜底。早点遇到这种事反而是好事，逼我及时调整。
