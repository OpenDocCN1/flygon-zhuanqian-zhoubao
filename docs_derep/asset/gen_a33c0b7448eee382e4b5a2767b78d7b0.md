# 三、套一层智能体外壳

只靠工作流的话，后面操作起来还是会有点麻烦，所以咱们一开始创建的智能体现在派上用场了。注意：一定要等上一步成功跑通之后再做这一步。

[PRE53]

直接就上最终效果吧，这样就是一个完整的智能体了。提示词可以直接用我的这套：

无论用户输入什么，始终调用工作流

需要选择上工作流的时候，按住shift+{ 注意这个括号得是英文的状态

当客户输入无关内容时，提醒客户“请戳下方【点我开始】”开启工作流

这样一来，用户只需要把想仿写的小红书链接发给智能体，系统就会自动跑工作流，结果统一汇总到飞书多维表格里。

当然，这只是个很轻量的智能体，没办法解析视频文案，图文博主用起来比较合适。如果你通过这次实操，对智能体产生了更多兴趣，后面也可以再安排进阶学习。
