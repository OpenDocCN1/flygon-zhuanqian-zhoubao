# 本地实体店，内容只要循环拍三类

人设类、破圈吸粉类、客户评价类。

为什么就这三类？

人设类负责攒信任。

破圈吸粉类负责让同城推流，给账号打本地标签。

客户评价类让看到的人明白你服务是什么样的，专业、划算、效果好。

一般节奏是四条客户评价+一条人设+一条流量，然后循环。

想在抖音小红书把本地内容做起来，核心就两点：产出要快，要持续。

「生意需要源源不断的进店客流，绝不是拍一条爆款就能吃几个月甚至几年」

所以必须套框架填东西，把素材往里一塞就行。

## 人设类还能再拆

第一人称口播的人设，第三人称素材拼贴的人设。

## 流量类还能再拆

第三人称正能量素材、第一人称正能量口播、第一人称蹭热点的口播。

## 客户评价类还能再拆

第一人称口播展示服务过程、第三人称口播展示服务过程、第三人称纯素材展示客户评价。

细分到这层就够用了。

眼镜店这么拍，餐饮美业零售基本上逻辑都一样。最省事的办法，就是一比一复制同行，别自己瞎琢磨。
