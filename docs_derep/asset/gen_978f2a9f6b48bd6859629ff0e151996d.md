华为云联合硅基流动上线的满血 DeepSeek R1，现在注册就送 2000 万 Token 起步。

[PRE1]

Token 到底是个啥？之前文章里反复说过简单概念：它能是一段文字、一个标点、一个汉字，模型处理时就靠它把文本拆成最小单元。

2000 万 Token 听起来玄乎，换算一下就懂了：

一本普通小说每页约 300 汉字/单词，2000 万 Token 大约等于 6.6 万页。按 300 页一本算，就是 220 多本书，堆起来能占满一个大书架。

## 十、本地部署搭建个人知识库

常有人问：怎么本地部署 DeepSeek 建个人知识库。

坦白说，除非你要做技术研究或数据必须离线，我不建议普通人折腾。

现在 Ollama 上 1.5B~70B 都是 R1 能力蒸馏到 Qwen/Llama 的学生模型，性能提升明显，但和原版 671B 比仍有差距。

官方满血 671B 要的算力成本对个人来说太高。

不过我找到一个折中办法：能用上 R1 本体，还能拿到免费额度。下面分三块讲。

本章收获：

### 三）本地部署建知识库

想简单体验或保护数据，用本地方案。

1、去 Ollama 官网下载：https://ollama.com/download，建议装最新版。旧版装 R1 可能用不了。
