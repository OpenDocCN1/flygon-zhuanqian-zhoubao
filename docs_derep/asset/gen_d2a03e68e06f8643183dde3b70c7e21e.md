# 刀乐哥火了之后，我用一周时间狂发6条视频，流量和变现一起收割

> 来源：[https://vow6kdbiak.feishu.cn/docx/RwAZdouj1ozbv6xa7D7cy3mCnhg](https://vow6kdbiak.feishu.cn/docx/RwAZdouj1ozbv6xa7D7cy3mCnhg)

说实话，我这种ENFP的冲劲自己都怕了，一现热点脑子立刻转起来，手也停不下来。

把当时刀乐哥爆了之后我到底干了什么、拿到了什么结果，今天一次性摊开了讲。省得下次再碰到同级别的爆点，你们还能照着这个节奏快速上车。

结论先放前面：围绕这个事件我总共出了6条视频。B站和抖音直接干到一年以来的最高播放，B站30万，抖音190万；小红书也是近三个月点赞最高的帖子，800+。流量有了，粉丝涨了，钱也到账了。人在义乌，真是天时地利人和全齐活。

这个复盘拿去用，下回遇到现象级内容，按这个套路先把脚迈出去，流量和收益就能双收。

# 我是怎么察觉到刀乐哥要爆的

## 抖音上被刷到怀疑人生

最近被刀乐哥的片段洗版了，根本停不下来。

刀乐哥绝对不是新手小号，从ID到头像到简介，全是精心设计的记忆点。视频里反复出现的“刀乐”梗、头像上的刀乐元素，说明这波出圈是提前布局好的自带传播点。

他就是在纽约时代广场背着黑包卖义乌小商品的外贸人，因为英语词汇有限反而形成了独特的反差感，这也是他迅速破圈的原因。

[PRE0]

## 眼神盯住了同款产品

他手上不止有数据线和发光小猫，开箱第一眼出现的就是那个解压玩具。

看到这里我就大概猜到这款要起量了，脑子里立刻在盘：怎么借势、怎么吃这波红利。

流量和金钱至少要抓住一个，两个一起最好。

当时我老公和一个做这行的哥们在打台球，我也是顺口跟他们说了这个事，感觉热度正在往义乌集中。大哥直接说：别聊了，拉车去找货。

# 马上启动备战计划

## 先冲供应链

我常年混义乌，接产品比别人快一步。大哥立刻带着我杀到CBD那边的玩具供应链，一进门就把视频亮出来。对方第一反应：是不是That Dollar的那个？我说是，但他们现在没样板在手，现货也很紧缺。

经验告诉我，短视频一旦爆了就得立刻开直播把流量变现。所以当天晚上我就播了。场观直接冲到一万，卖了过万。惊到我了，毕竟我们已经快一年没直播了还能有这种体量，相当于一场小型演唱会。

来看直播的大多是来玩梗、搞抽象、整活的，转化率只有不到1%，正常应该在3%左右。就算投流也能更高，但考虑到这是我一年多以来的首播，这个尝试已经很值了。

## 公众号同步分发

我把视频的精华整理成文字发到了公众号，那条公众号也一周没更了。正好借这个爆点做测试，后端还有资料包和星球承接，进来几个也是纯赚。也就花了五分钟，连排版都没做。

这也是我最近流量主收入最高的一次。

# 给下一次风口留一个方法论

很多人会说，这就是一阵风，很快就凉了。但互联网不就是由一波波风组成的吗？风能吹过你身边，你至少得感受到它。

无论是对内容运营还是商业嗅觉，这次经历都挺有启发的。我们做内容一直在思考怎么蹭上热点，怎么用自己的赛道分一杯羹。这次就是一次很实用的追风练习。
