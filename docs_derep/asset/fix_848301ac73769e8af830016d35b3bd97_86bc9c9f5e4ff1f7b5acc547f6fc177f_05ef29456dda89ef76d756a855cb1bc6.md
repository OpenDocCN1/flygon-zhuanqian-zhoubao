# 山城首场圈友面基会，圆满落幕！

文 | 辰奚 · 2023年4月14号

重庆的圈友，有个好消息要告诉大家：咱们生财在山城的首次线下碰头会，顺顺利利办完了。我们终于把那些天天在群里热聊的人，拉到了同一张桌子前。

事情的引子，是3月25号那场全国性的大聚会。散场后，各地圈友都忙着找同城组织，重庆这边也没拖后腿——一个群从最初的5人，一点点扩充到41人，速度相当可观。群一热闹，想法自然就来了。大家七嘴八舌一合计，不如咱也线下来一场？于是我把日期敲定在4月9号，想让更多本地伙伴从屏幕后走到桌子前，也为以后的山城局开个好头。

全程的记录和一些有用的资料，我集中归置到了飞书文档里，想回顾的可以直接点开：

能攒成这场局，功劳不能只记在我头上。糖糖家和zhaostu，作为幕后操持的两位主理人，把流程安排得明明白白；波叔直接把物料揽了过去，省了我不少心；小凌州跑前跑后，又是引导又是照应，忙得脚不沾地；包子则端着相机走全场，给大伙留下了珍贵的影像；吴维（圈友们习惯喊他吴总）爽快地腾出了场地，让聚会有了落脚点。当然，更少不了每一位到场的伙伴——你们贡献的观点和热情，才是整场活动最值钱的部分。

对了，黄东山在分享里的干货，我也收进了那份飞书文档，没来得及细看的朋友，回头记得翻一翻。

还有个有意思的巧合：吴维、包子和我，居然都置身于同一期大航海的队伍里。线上是圈友，线下又添了一层同行情谊。

最后，请允许我把谢意也送给生财有术这个平台。它把天南地北、各个行业的能人连接起来，让我们得以互相激发、一起成长，也一起琢磨更多搞钱的门路。

重庆的故事才写了个开头。下一场，山城再见。
