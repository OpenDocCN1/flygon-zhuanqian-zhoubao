# 别再只靠免费流量：口腔门诊付费投放实战拆解

实体店做线上获客，很多人以为只能发发内容、做做团购，其实另一条绕不开的路是付费投放。我做口腔线上运营8年，操盘过的月预算从三五万到一两百万都有，靠投放就能把单月到店客户稳定在200人以上。方法并不复杂：选对渠道，把曝光规模化；持续调整竞品、销售和投放策略，把成本降下来，把客资做得更精准。

先把最重要的话说在前面：所有医疗营销都只是流量放大器，最多是锦上添花。真正决定一家门诊能走多远的，还是治疗效果和服务体验，这才是医疗的本质。口腔是重资产行业，转化链条很长；普通打工人做运营没问题，但没资本、没资源的人要自己当老板，我劝你谨慎。种植、矫正、美白修复这类消费医疗，都可以参考下面的打法。

口腔市场早就饱和了，不管城市大小，门诊密度都很高。但“酒香也怕巷子深”，再大的机构也会遇到到店顾客不够的情况。地铁语音、户外门禁、电梯框架、市场义诊，本质都是“品牌走出去，顾客请进来”。其中付费投放最直接的优势是数据可查：曝光、点击、咨询、留联、到院、成交，每一环都有数字，方便复盘和优化。每家门诊的主投方向，要结合自己的接诊能力、产品组合和渠道人群来决定。

## 一、本地生活平台：人气和口碑的基本盘

代表性平台有美团点评、高德、支付宝口碑。这类平台基于商圈展示，门槛低，后台容易上手，还能和顾客实时互动。不管是做洁牙、补牙、口腔检查这些基础人气项目，还是积累品牌口碑，都非常合适；获客成本也低，大小门诊都适合做。

不过别指望新店靠团购直接成交种植牙、正畸。人气平台的核心产品一定是基础病种，价格要有吸引力，比如工作日58元洗牙，还能一拖一；只要服务好，顾客愿意给五星好评，口碑就能慢慢滚起来。再配合适当的付费推广，销量和评价上来后，店铺权重会更高，被用户选中的概率也更大。

只做首次核销，基本是亏钱生意。要让顾客在到店体验时埋下二次消费的种子：告诉顾客他有哪些口腔问题，问他想不想处理；不想处理，就问问顾虑；顾客不愿说，也不要硬推，后续回访跟上。回访节奏可以参考术后第1天、第3天、第7天、1个月、3个月。每一次沟通都要记录，抓住他最关心的点。比如在意价格，大促时提醒；担心技术，发类似案例。

本地生活平台本质是电商，想拿平台额外流量，就得完成考核。上个月的得分决定下个月的店铺等级，所以所有工作都要前置，目标要提前一个月落定。

## 二、搜索竞价：精准但需要抠关键词

代表平台是百度、搜狗、360。搜索竞价流量极其精准，但早年百度口碑太差，现在已经没落。一二线城市基本被大型连锁机构的年框合同占着，中小门诊参与很少；三四线城市竞争小一点，产出也比较稳定，仍然是个不错的渠道。

搜索竞价的核心是关键词。虽然现在很多平台都切到OCPC自动出价，但底层逻辑还是要懂。拿种植牙搜索词举例：

牙齿脱落 → 缺牙怎么办 → 种牙好还是镶牙好 → 种植牙费用 → 种植牙医院 → XX医院种牙怎么样

从左到右，顾客意向越来越精确，所以不同关键词要匹配不同落地页，或者在同一页面做针对性引导。关键词背后是需求和商机，这个逻辑放到任何行业都成立。

## 三、信息流：量大、杂、卷，但能出业绩

几乎所有有流量的平台都在卖信息流广告位：头条抖音、百度、小红书、广点通、新浪网易、vivo/oppo、知乎快手等。口腔行业从19年开始大规模做信息流，主要是种植、正畸这类高客单项目的获客主力，也是能创造业绩的渠道，竞争自然最激烈。

信息流的特点是量很大但人群很杂，用户爱比价。前端口子常用两类素材：一类是特价活动类，让用户填表申请优惠名额；另一类是报价测评类，让用户填表获取报价。

运营重点是AB测试。一条计划由“创意标题+图片/视频+落地页”组成；人群定向和标签相对固定，适合做控制变量。从曝光、点击、点击率、转化、转化率去判断效果。计划衰退很快，必须不停测试，记录最好用的创意、素材和页面。新手想快速上手，可以“先抄后超”，竞品就是最好的老师。

一线城市做到月百万投放级别，投产比能到1:3.5以上，已经算优秀；二三四线城市一般能有1:6以上，具体看当地竞争。我之前在深圳一家头部口腔做操盘，投放规模一度占深圳市场份额一半以上，最高月份投产比做到1:5。

三个平台到底怎么选？答案不是固定的，最终看门诊接得住多少顾客。没有好不好的渠道，只有做不做得好的门诊。

## 四、新手运营最容易遇到的两个问题

第一，账户波动大，心理压力大。这太正常了。以前我带过的运营，账户表现不好时连饭都吃不下，恨不得24小时盯着。完全没必要。运营是长期工作，出现波动就回去看每一环数据，找异常点，检查创意和页面是否匹配。我一般会观察一两天，如果确实持续变差，再替换创意或页面。大多数运营都会做到市场平均值，只有少数人能更好；平时多想多分析，你才会慢慢靠近那少数人。

第二，新项目刚启动，先堆量还是先保投产？主要看预算。大机构预算充足，可以先用钱换量，量变引发质变，用足够多的客户把团队磨合出来；小门诊预算有限，我建议先把投放压一压，来的每个顾客都珍惜，逐个分析没成交的原因，有了正反馈再逐步放量。

## 五、想更进一步，运营要有两种思维

别只把自己当执行者。如果你只想做基础运营，把成本优化好就够了；但如果你想在部门里挑大梁，要思考两件事：

1. 资源整合：向上争取领导支持，包括价格政策、预算和人员；向下和电网咨询、现场咨询打通，用数据评估政策效果，把投放、到院、业绩这条漏斗跑通；还要让兄弟部门配合做市场调研、针对性策略和物料设计。跨部门推动确实难，学会借力领导会省力很多。

2. 转化策略：盯住竞品的主推活动和定价；定好自己的引流品和产品线价格；规划活动类和报价类投放的比例。这些只能给大方向，每个市场和机构情况不同，要结合自己的实际情况去试错、去复盘。

## 六、转化路径与团队配置

口腔的获客转化分三段：运营端做付费投放，电网咨询负责跟进和邀约，门诊现场咨询负责促成交和后续维护。

策划运营岗位职责：
- 做竞品调研、月度推广计划、活动政策申请；
- 根据不同渠道属性，策划和替换推广页面、物料；
- 整理分析推广数据，优化效果和转化率；
- 对接电网咨询的跟进情况，灵活调整投放策略。

电网咨询必备：
- 熟悉口腔专业知识，判断顾客初步需求，讲清门诊优势，邀约上门；
- 定期回访，做满意度调查，建立客户关系；
- 与现场咨询及时同步顾客需求和顾虑，辅助成交。

现场咨询必备：
- 完成初诊宣教，推荐治疗方案；
- 协助医生沟通治疗计划；
- 做好治疗前咨询和治疗后回访；
- 管理患者关系，维护老带新口碑；
- 配合经营主任制定周、月、季度计划。

总结一句话：口腔付费推广转化路径很长，非常考验团队协作。想做好，就要从选渠道那一刻开始，把平台属性、人群属性、投放策略、产品策略都想到；执行中主动找其他部门联动。团队磨顺了，投放的正反馈才会来得更快。

最后，除了付费推广，口腔门诊普遍还缺三类资源：

1. 达人资源：探店既能做品牌，也能带顾客。粉丝1万以内的达人，300字文案加3张以上图片，报价在200-600元/条；1万粉丝以上报价在2000到5000不等，还要看粉丝属性；视频类更贵，大机构用得多。

2. 顾客资源：手里有客户资源的个人或平台，可以和门诊谈合作，业绩提成通常在15%-25%；合作机构多了，就能挑成交率更高的机构。

3. 资深销售：很多小门诊对顾客心理把握不够，急需提高成交率；有销售经验、懂顾客心理的人，去做培训也很有市场。
