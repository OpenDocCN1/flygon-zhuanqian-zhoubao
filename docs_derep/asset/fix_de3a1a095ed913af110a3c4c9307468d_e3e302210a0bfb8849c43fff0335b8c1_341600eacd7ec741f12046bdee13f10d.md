# 资金在本人账户里过一夜，也能产生不小的利润

每到考核节点，不少银行网点负责人都会为存款指标焦虑。缺口的数字补不上，就要找同业朋友周转救急，并付出一笔资金使用费。有人看准了这个需求：在节点前把自己的大笔现金放进银行，帮对方把指标填平，再拿走这笔使用费。当然，这事的本金门槛不低，想博到单日六位数的收益，手上至少要有千万级别的本钱。

[PRE0]

这项操作的本质，是帮银行做月底冲量，可以理解为一笔隔夜资金周转。全程都在本人银行账户内完成，钱不会经过任何外人。

这个玩法是怎么传到我这里的？其实是聊天聊来的。我原本做传统门店生意，身边一直有银行条线的熟人。去年底，我和其中一位一起参与过新债申购，拿过一点甜头。我们名下的网络店铺多，执照也多，以企业身份申购时，感觉命中率更高；有兴趣的圈友可以自行验证。

[PRE1]

有了那次合作，双方就熟了。今年2月我换了办公场地，请他过来喝茶。聊天中他知道我在线上业务这块做了多年，就托我从内容平台上引导一些用户，做正规的证券账户业务。话题转到他的日常工作，他才把这个套利路径讲给我听。

[PRE2]

这种事的成因是什么？主要有三点：  
一是银行基层负责人的考核里包含存款任务，完不成会影响业绩；临到节点，只能找外援，所以愿意支付利息。  
二是这种需求往往只持续一两天，多集中在月底前后。  
三是它属于圈子里的私下操作，不会公开吆喝。哪天你被银行熟人问及“手头是否放着短期闲钱”，多半就是这类需求。

[PRE3]

具体怎么操作？现在不少银行支持在手机端开通虚拟子账户，并挂到本人主账户名下。把银行员工给的编号填进去，系统会分配一个卡号；把主账户里的钱划进去，就算完成了任务。节点过后，再把这笔钱转回主账户，把子账户销掉即可。整个过程中，所有动作都是本人操作，资金路径非常透明。

[PRE4]

以工商银行为例：在存款专区找到按日计息的通知储蓄，选一天期，填上编号和金额，把到期日调到次日，确认后就能在存款列表里看到这笔资金。  
农业银行的路径也接近：先开通电子子账户，填写其他银行卡的资料，再把绑定对象换成农行卡，转入资金，过一夜转出，接着销户。

剩下几家大型国有银行大同小异，只有一家的流程稍显繁琐。填错也不用紧张，注销账户重新来一遍就好。

实操层面，我先去了解行情和报价，把自有本钱备好。如果资金能放得稍微久一点，还可以叠加理财收益。彼时理财产品收益大约2.2%，活期还有0.25%的利息，我用了一款年化4%的产品，中间能多赚将近2个点的利差。这轮策略执行下来，正好撞上季末收尾的隔夜单，折合收益相当可观。

最初谈定的费率是：一千万本金过一夜，给一万以上。我拿出500万本钱，再做一单季末任务，合计利润两万左右。

[PRE7]

更大的收获还在后面。一位老友是一家企业的股东，我随口问他所在的企业是否愿意参与冲量。他一开始没明白，我解释说，企业用账面闲钱，在自家银行账户里完成冲量，本金安全。他答应回去和股东商量。我也问了另外几个熟人，对方都说先看看。我帮他们算了笔账：平时做理财，一千万本金过一夜，收益不过几百块；冲量这边，一千万本金过一夜，保底超过一万。差距接近十倍。

过了一段时间，那位老友来电，说企业账上刚好有三个亿闲置，下月才用，不如让资金活动一下。我马上对接合作方，最后按“一个亿过一夜、总费用十一万”谈成。合作方最初给出保底方案：一个亿的额度，过夜费一万二；如果行情上涨，再商量分成。我选了稳妥的保底，结果行情果然上涨。企业资金早早备齐，开好子账户，把钱存了进去。节点一过，对方如约结清余款，我再把本金归还企业，这单净赚六万。

另一位炒股的老兄，账户里常年趴着大笔闲钱，也帮忙做了些日切和节点单子，又带来两万余元进账。几笔加起来，单日收益突破六位数是真实发生过的。

下面把大家常问的问题整理一遍：

**安全系数有多高？**  
我反复操作过，资金始终由我本人掌控，而且只跟头部国有机构合作，钱仅在本人账户之间移动，不存在被第三方挪用的路径。

**收益什么时候结算？**  
付钱的是银行职员，他们很在意投诉，所以基本隔天就会结清。中间商也是当下两清。万一某一单收益没兑现，最多损失一点理财收益，本金依然安全。

**这个玩法能持续多久？**  
银行的需求很稳定，每周每月都有节点，只是报价高高低低不一样。能接受就接，不能接受就让资金躺在理财里。这个玩法不欠款、不费精力，还能攒下人脉。

**报价怎么会有高有低？**  
银行不一样、时点不一样，行情自然不同。事先会把价格谈清楚，划算就做，不划算也不勉强，反正是零成本。

**普通人能直接参与吗？**  
能接触到银行内部资源的话，可以尝试沟通。但个人如果无法持续提供大笔资金，对方多半没有合作动力。

**最大的短板是什么？**  
资金门槛高，通常要一百万元起，太少没有操作意义。

最后多说一句：有朋友在留言中也提醒过，小型金融机构要谨慎。我做这个只认头部国有银行，钱始终不出本人户头，即使银行层面有极端问题，也有制度托底。行业很垂直，知道的人不多，但只要记住一条——让钱始终留在本人名下，就不会翻车。
