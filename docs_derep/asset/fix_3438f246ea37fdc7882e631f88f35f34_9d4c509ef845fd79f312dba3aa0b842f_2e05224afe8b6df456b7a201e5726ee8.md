## 精华帖 77赞 《听取一个良好的忠告也许就是赚几百万》

作者：老吴说投资
日期：2023-05-18

1. 大家好，我是老吴，长期在金融行业工作，熟悉银行存款、理财等各类业务。2017年开始做副业，第一份副业就是做股票经纪人，目前仍在坚持。入市十年，整体战绩为盈利，股票累计收益超两百万。
2. 这篇文章并非要鼓吹跟随我操作能赚多少，而是想提醒你参与交易可能面临的亏损规模。
3. 此前我写过一篇《从年负债19万，到眼光敏锐投资年净收益近百万》，分享了自己在股市获利的经历，发出来后不少读者来咨询如何入市。我的第一反应始终是：普通人致富的第一条原则是远离投机，远离股市。
4. 想要亏本的路子有很多，最容易让家产清零的工具就是博彩和炒股。
5. 当我劝人不要碰股票时，常有人质疑：你是不是亏怕了才劝人？恰好相反，正因为我自己赚到了钱，才更想劝大家远离。我亲眼见过太多人把本金赔光，所以有盈利经验的我才更强调避险。
