大家好，我是逸尘。今天复盘一个纯兴趣起步的小实验：一个原本只为自用设计的锁屏小工具，从开始考虑收费到收下第一笔订单，间隔不到一天。走的并不是教科书式的产品路径，思路有点散，但验证逻辑很清晰，拿出来分享。

## 一、变现闭环怎么搭

核心做法是：把编译好的安卓安装包放到夸克网盘，再把网盘地址挂到小红书个人售卖，并关联到对应笔记。一笔成交能同步拿到两份收益：小红书个人售卖的货款，以及夸克的拉新分成。

为什么用个人售卖而不是个人店铺？

个人售卖对软件类只抽 0.5% 佣金，个人店铺要抽 2%。个人售卖自带免打扰自动发货，可以真正做睡后；同时不展示销量和评价，售后干扰小。

### 这套打法的对比优势

市场上常见的 AI 编程变现：上架 iOS 要交 99 美元年费；做 Web 需要域名、等 AdSense，周期长；做 Web 工具要接入登录订阅，Cream、Stripe 接入门槛高；搞社区又需要头部账号背书。

小红书个人售卖卖安装包，只要有一个能用的功能即可。AI 相关能力可以后加，也可以让用户自行导入秘钥实现买断或订阅。笔记发出后一小时内就能有反馈，验证速度极快。

当时只是自用心态，没铺开其他变现口，后续的一些延伸思考会在后面说。

## 三、从 0 到 V3 的推进顺序

### 1. 选环境

换电脑后原来的 Codex 记录丢了，只能凭记忆整理。当时 GPT 已付费，Codex 可白嫖，Antigravity 还没出，Claude Code 太贵，综合下来 VSCode + Codex 最划算。

### 2. 定技术栈和需求

我把想做的功能点口述给 AI，让它判断可行性。先做安卓，未来想做桌面。

我问能否实现，AI 推荐 Flutter 跨端。确认华为、小米、红米都能跑后，我让它基于背景写一份接近 PRD 的需求文档，并用 ASCII 画原型保存为 Markdown。

AI 一次性成稿，我让它按文档开工。命名时我给方向，AI 给出备选，最终定名“逐梦”。

Codex 做这种小项目一次就能成型，文档越清晰成品越准。后期把默认占位图换成自制 Logo，没有 Antigravity 的可以用图站找一张 1:1 的放进去。

## 四、想做大怎么扩量

### 1. 流量为王

发笔记、投流、截流、合作四种方式。发笔记最划算，找对标高赞笔记做微创新，标题保留核心关键词做 SEO。投流不建议，赚头不多。截流就是去竞品评论区找“求安卓”的用户私信，每天有次数限制。合作最舒服，我就和那个 iOS 标杆博主互相导流。

### 2. 升级用户画像

可以把锁屏工具做成大的时间管理 App，但竞争会变大，周期更长，适合想拿融资的路线。

### 3. 对接后端

后续可以接订阅、AI 秘钥等商业化，但我暂时没精力。

以上就是从灵感验证到迭代的完整闭环。核心就一句话：用小红书个人售卖 + 夸克网盘做最轻的 MVP 验证，快速试错，快速变现。
