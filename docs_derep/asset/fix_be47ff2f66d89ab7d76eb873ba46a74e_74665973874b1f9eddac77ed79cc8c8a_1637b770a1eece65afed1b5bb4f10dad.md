先用钢笔路径圈出需要提亮的范围，稍微向下拉动对位。打开遮罩设置，加大羽化程度，使光晕柔和散开。将色调调成目标灯光色，若是太亮，就下调透明度。夜景灯光不宜过强，只需一丝光感就好，太亮会失真。灯光处理的要点就这么多。

[PRE2][PRE3][PRE4]
关于AE夜景调色，这里给出两个方向。

方向一：精细校色
取一段素材，在效果面板的“颜色校正”组里打开Lumetri Color。左侧切到基本校正，参数为：色温20、曝光-2、对比40、高光-80。

[PRE5]
接着在效果面板的Digital分类下使用Sharpen，提升画面清晰度，强度设为150。

方向二：预设调色
把房子所在的层单独挑出来，再按以下顺序操作。

1. 进入“效果-实用工具-Apply Color LUT”，套用“清晰滤镜”。
2. 再次进入同项，选择“爆款黑夜”。
3. 搜索Hue/Saturation，双击打开，在左侧通道控制中把蓝色、青色、红色、黄色的饱和值往下拉，画面就不会整片发暗或过亮。
4. 再叠一层精细校色：在效果面板找到synthetic下的SA Color，左侧简易控制滚动到HSL，对比设为0.5，RGB增益降到0.4-0.8，伽马控制在1以内，具体按画面微调。
5. 亮度提升：在右侧搜索Curves，双击激活，先选中中间线上的四个节点，把整体亮度微微上拉。

[PRE6]
6. 清晰化：在Digital分类下使用Sharpen，数量130-150即可。

地面亮光反射：新建调整层，用钢笔勾出需要发光的位置。右侧搜索Curves，打开后把最右侧的白线向左拖，地面便亮起来。边缘生硬时，展开调整层的遮罩，把羽化值调到90-110。

接下来演示怎样用一张图片做出简单动态视频，包含天空、云朵与背景，很有乡村夜晚的味道。

先在PS中打开房子图片。图片底部带一点蓝色，把它向下拖动遮盖住。

[PRE7]
按Ctrl+J复制新层，准备在新层上抠图。先将下一层的眼睛图标关闭，再新建一层，前景色设成醒目的绿色，便于看清抠图边界。用油漆桶工具把这一层填绿。

[PRE8][PRE9]
切回最上层，用多边形套索仔细勾选房子轮廓。先将视图放大，沿着外墙一步步描，电线杆这类不需要的元素直接排除。框中多余范围后按Delete删除，再取消选择继续处理。

[PRE10][PRE11][PRE12]
抠完后整体高度偏高。构图按三等分：天空一层、房子一层、地面一层，现在房子比例过大。选中该层，按住Shift键把它往下压一点，观感立刻平衡。

[PRE13][PRE14]
上方空出的地方要补上。先用多边形套索选中电线杆，把它复制出来：选中该层按Ctrl+J，然后按住Shift键拉高并放大，边缘用橡皮擦修干净。

[PRE15][PRE16]
接着也把电线杆加长：圈选后按Ctrl+J复制，再按住Shift键拉升。电线杆和柱子就位后，把这两层一起Ctrl+E合并。

[PRE17]
开始修补房子细节。用仿制图章工具，按住Alt键在干净位置取样，松开后在脏乱处涂抹。操作前记得先选中目标层。太严重的地方盖掉即可，老屋原本有斑驳，不需要修得全新。

[PRE18][PRE19][PRE20]
点亮窗户的做法：
用多边形套索粗略框出窗框位置，新建一层，前景色设为暖黄灯光色，使用油漆桶填充。接着选渐变工具（点左边第二个图标），从窗顶到窗底拖出光晕，另一扇窗也透出一点光，更生动。

[PRE21][PRE22][PRE23][PRE24]
混合模式可挑“灯光效果”“颜色减淡”或“叠加”，效果都不错。将窗户层再复制一份，用来做窗棂。

[PRE25][PRE26]
选中复制层，在左上角菜单执行“选择-反选”，即选中窗户以外的所有内容，按Delete删除。窗户就变成单独一层。把上下两层按Ctrl+E合并，右键重命名为“窗户”，下方那层保持“房子”。

[PRE27][PRE28][PRE29]
完成后，下方两个辅助层可以删掉。保存房子文件：文件-存储为，格式选PSD，命名后确认。

[PRE30][PRE31][PRE32]
把做好的房子PSD拖进AE。导入类型务必选择“合成”，窗户和房子才有办法分开调节。点击“可编辑图层”确定，右键执行“变换-适合复合宽度”。

[PRE33][PRE34]
添加星星：把星星素材拖进来，用钢笔圈出轮廓，在左上角效果菜单选择“抠像-Linear Color Key”。纯色背景用线性色键足够，用吸管点掉天空色，星星即被分离，拖到月亮旁。

[PRE35][PRE36][PRE37]
星星放好后拖入一棵树。使用“抠像-Color Range”进行抠取：上方吸管先吸取要移除的颜色，下方带加号的吸管继续补取。有残留白色可先重置再吸取白；颜色杂就吸天蓝、白两个样本。树抠好放至房子后方。

[PRE38][PRE39][PRE40]
放进总合成前，先修剪树周围多余边缘：双击树的层，用钢笔路径去掉多余部分，返回总合成后缩小，放房子后面，层的顺序置于房子下侧即可。

[PRE41][PRE42][PRE43]
接着丰富场景结构。可以在房屋尽头放一座小山或其他物体，拖到房子后方，做出小路延伸的效果。小路用Color Range抠出，如果太亮，就用右侧Curves压暗，使其与周围融合。

[PRE44][PRE45][PRE46][PRE47]
云朵也能加进去：拿天空素材拖进来，右键“变换-适合复合宽度”，放大后置于树和小路后方，月亮放在合适位置。天空亮度过高则稍压暗，更接近夜晚。

[PRE48][PRE49][PRE50]
开始制作夜景色调。先打开房子层，窗户保持不动，只对房子操作。夜景灯光分为六步：

第一步：进入“效果-实用工具-Apply Color”，选“清晰滤镜”。
第二步：再次进入“Apply Color”，选“爆款黑夜”。

[PRE51][PRE52][PRE53]
第三步：打开Hue/Saturation，在主控制通道里将青色、红色、黄色、蓝色、洋红色的饱和值都降一点。数值随意，按画面状态来。

[PRE54]
第四步：精细校色。从效果面板找到S开头的synthetic，进入SA Color。左侧简易控制中向下找到HSL，范围设为全局，对比调到0.49，增益略减，高光也降一些，边缘光就不会发硬。

[PRE55][PRE56][PRE57]
再提亮：双击Curves，选择中间线上的四个节点，把亮度稍微上推。

[PRE58]
第六步：清晰化。在D开头的效果分组中启用Sharpen，强度150，画面更锐利。将这些参数全部选起来，按住Shift键复制，回到总合成一次贴到其他层上。先展开树的层，在空白处粘贴。

[PRE59][PRE60][PRE61][PRE62]
所有层都粘贴完毕后，关闭带声音的层，加入背景音乐。把时间线尾端拉长，与整个画面时长对齐，不然音乐没播完画面已经结束。

[PRE63]
再调地面月光：新建调整层，用钢笔勾出地面范围，通过右侧Curves将这片区域提亮，模拟月光落在路上的效果。

[PRE64][PRE65][PRE66]
接着塑造窗户光晕：新建调整层，框选窗户照亮到的区域，微微提亮。打开遮罩的羽化，数值拉到100左右，边缘就会相当柔和。

[PRE67][PRE68][PRE69]
窗户此刻是白色光，我们需要黄色光。新建纯色层，选一个接近灯光的黄，用钢笔工具勾出一部分，拖到适当位置，有一点色彩即可。然后打开该层的遮罩，羽化也调到100左右，再把透明度略微调低，黄色光更自然。

[PRE70][PRE71][PRE72][PRE73][PRE74]
全部完成后还能在房顶加烟囱。把烟囱素材拖上去，太亮便压暗。底部衔接不够自然时，用钢笔勾一下边缘，开启遮罩羽化优化。再用Curves把亮度调低，烟囱在夜间不会那么亮。

[PRE75][PRE76]
最后放烟雾。用Linear Color Key吸取背景色，将烟雾分离出来，拖至烟囱上方缩小。烟雾层放在烟囱后面。风向左吹，若烟流动方向和树不一致，就执行水平翻转。太亮时同样用Curves压暗，夜晚烟雾自然发暗。

[PRE77][PRE78][PRE79][PRE80][PRE81][PRE82]
所有环节完成，作品就结束了。关掉烟雾音轨，只留背景音乐，点“全部”播放缓存，然后导出：加入渲染队列，无损格式选MP4，确定，重命名后存到桌面，点击渲染输出。
