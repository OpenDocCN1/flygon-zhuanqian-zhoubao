# 新手做YouTube，第一步不是学剪辑，而是想清楚这件事

前两天有位圈友问我一个问题，我觉得挺有代表性的，三言两语讲不清，干脆写篇文章好好聊一聊。

她问的是：YouTube赚钱，我到底该做什么？赛道怎么选？

说实话，问这个问题的人特别多，但大多数人其实都搞反了一个顺序。你真正应该先解决的，不是做什么内容，而是一些更底层的认知问题。

这里我先放一张图，你把它牢牢记在脑子里。这是一个三脚凳的模型，三条腿分别是：你、你的选题、你的观众。

一个凳子为什么是三条腿？因为一条腿坐不住，两条腿像拄拐杖，三条腿才能稳稳当当。这三条腿一样长，代表这三件事同等重要。

先聊选题。

**在热点里做选题，最大的好处是观众天然的关注度已经被你借来了，基础播放量就有了保障。**

什么是热点？大家真正关心的事就是热点。

说个大家熟悉的品牌，某杜，他家营销做得好，在自己的领域里能站稳脚跟，真心不奇怪。

再举个更高级的例子。美国卡中国芯片脖子那阵子，李永乐老师就从这个国际博弈的大热点切入，做了一期节目讲芯片为什么难做、人家为什么能卡我们。他展示的是专业知识，但蹭的中美关系这个大热点。

但热点是热点，你是你。热点跟你有没有关系，得看你自己本身有没有东西。这就是为什么“你”这么重要。

世界再大，作为个体的你，才是你体验这个世界的圆心。

**所以，你想做什么方向、用什么形式，都可以。关键是，兴趣是第一位的。**

你可以逼自己去追热点、去解决观众的疑问，做一个能养活自己的号，但代价是你越做越不开心，越做越痛苦。

**一定要做自己真正感兴趣的事。如果还不知道自己的兴趣是什么，那就铁了心去找，哪怕花一年、三年、五年。从你找到它的那一刻起，你做的每一件事都是兴趣。**

注意，兴趣不是说你找到了就得干一辈子。你今天对这个事有兴趣，那就认认真真开开心心干一年。明年兴趣变了，那就换个方向做，完全没问题。

兴趣解决了，持续输出的问题自然就解决了。

有了兴趣，接着要看观众。你不能自己嗨，自己做独角戏。

这里有个很经典的理解方式：一位诺贝尔级别的物理学家，如果给初中生讲课，他一定比初中物理老师讲得好。为啥？因为他不会觉得“我讲的东西必须博导才配听”。他尊重观众，知道面对的是初中生，就用初中生听得懂的方式讲，不摆架子、不炫技。

**你得清楚自己在给谁讲，然后尽最大努力让这群目标观众听得清、听得懂，还觉得有意思。**

费曼学习法也是这么说的：把最复杂的东西讲到外行也能听明白。网上有各种版本，量子物理讲给五岁小孩听、讲给初中生听、讲给家庭主妇听，都能讲。

但有个点要警惕：**做观众喜欢的没错，可一旦做过了，就变成迎合观众，被观众绑架了。**

所以你要守住自己的兴趣，别堕落到只去取悦观众的猎奇心理。要义正词严、光明正大地蹭热点，同时坚持你的个性、你的三观。你要做到跟谁都能唠两句，了解核心观众在想什么，把视频最精华的部分用他们最乐意看的方式端出来。

如果从立体角度看，这三条腿里哪条最根本？

**是你。**

你是一切的基础，没有你，这个项目根本不存在。

**所以一个新手刚开始做的时候，一定是先从自己的兴趣出发。这时候，忘记观众，别看涨粉，别看播放量。这些都不用考虑。**

等到你的兴趣、你的内容形式、你的大方向都定了，再花心思研究怎么让观众愿意看你的视频。

你做视频，就站在这个中心区域里。有没有蹭到热点？是不是自己感兴趣的东西？要用专业自媒体人的标准来要求自己。

既然出来做了，就把它做好，让看你视频的人感觉逻辑清晰、内容生动，看完要么有收获，要么至少是一段开心的陪伴时光。

拿我自己举例。我去年开始写YouTube相关的内容，那时候没人要求我写什么，写了也不会有精华帖，我为啥还写？

因为我在做这件事，就顺手写了。写这些帖子，纯粹是出于我的兴趣。

我是程序员，看最新技术文档基本都是英文的，这就逼着我天天上网，上网就会顺手点开YouTube，看着看着，就顺手自己做了YouTube。

至于蹭热点，真的是碰巧。去年我发的帖子根本没人看，现在有人看了，说明有热点嘛——生财在推YouTube，我在生财发YouTube相关的内容，其实就是间接蹭上了。

小结一下我的故事：

1、先有兴趣，做自己喜欢的事，分享自己喜欢的内容。
2、恰好踩在生财推YouTube的节点上，帖子顺手蹭了波热点，才有了阅读量。

还有件事必须提醒你。很多常识，你是要长期泡在一个领域里才能知道的。比如IP的问题，我不说海外住宅IP，外行人根本不知道这玩意儿这么重要。

你说你要上矩阵、多账号、疯狂加杠杆，但是你的IP是坑的，有人甚至图省事用免费节点，吭哧吭哧干了大半年，回头才发现全白做了。为什么？因为免费节点可能被用来干过坏事，早被平台标记成风险IP了。你在这个风险IP上猛干、特干，做着赚钱的美梦，我这儿只能给你泼盆冷水——你就是在做梦，做的一切全是白费功夫。

我写这些帖子，你能耐着性子看完，是真的想让你少走弯路。我之前发的帖子都整理到了飞书文档里，就是想着你翻起来更方便，这也是从观众的角度出发，给你们行个方便。
