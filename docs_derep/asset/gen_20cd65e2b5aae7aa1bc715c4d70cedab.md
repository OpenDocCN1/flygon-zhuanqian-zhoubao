# 从十年金融分析师到Web3创业者：我的转型实录

大家好，我是久富。曾经在金融圈做了十年分析师，2021年正式转型做Web3创业。第一次在生财和大家分享，请多关照。这篇内容会从我的背景、探索、未来展望三个维度，聊聊我看到的Web3。

（声明：本次分享涉及到的任何东西，均不构成投资建议。投资有风险，入市需谨慎！）

去年6月，我放下十年的金融分析师身份，开始全力投入Web3。那时中概股还没暴跌，港股离2008年的底部还很远，日元汇率也还没回到几十年前的低位；元宇宙的概念依旧朦胧，NFT也还不是年度热词。

我原来的公司做传统金融、风险投资和前沿科技创业。疫情爆发后，业务急速萎缩，客户对整个市场的流动性普遍失去信心，宁愿死死握住现金，也不愿把钱扔进熊市。也正是因为有金融和科技两边的经验，2021年上半年起，我对行业风向和热门概念保持高度敏感，几乎天天看研报，观察不同行业的真实需求。

### 先说几个大热方向

**跨境电商**：今年就一个字——卷。亚马逊大批封店，Shopee裁撤校招生，TikTok陷入价格战，这些信号都表明，2019年那种红利期已经彻底过去了。商家随便运营就能赚钱的时代结束，现在拼的是精品和品牌。但也有正面案例，SHEIN这家独角兽，靠强大的供应链能力赢得大量海外用户。我认为，中国品牌出海将会成为趋势。

**VR/AR**：谷歌、腾讯这些互联网巨头都在砸重金搞VR，为什么突然火？因为2021年元宇宙概念起来，VR被视为进入虚拟世界的交互入口。谁能更快突破技术壁垒，谁就能更早拿下Web3的布局优势。但技术还没成熟，设备重量、体验感这些老问题没解决，目前只能说前景可期。结合元宇宙的热度，VR/AR、虚拟人、数字人这类赛道大概率会爆发。

**新能源**：今年新能源汽车也彻底出圈了。马斯克靠特斯拉冲上全球首富，蔚来、小鹏在纽交所上市。随着新能源普及率提升和国家政策倾斜，这个市场长期向好，对我们，尤其是有技术背景的朋友，是一波顺风车红利。

**Web3**：什么是Web3？说白了，它是建立在区块链技术之上的一套网络生态，而且能够跟现实世界发生互动。元宇宙、NFT、DeFi这些关键词在2021年刷遍全网，国内外都掀起了热潮。马斯克买下推特要做Web3社区，Meta等巨头也在布局元宇宙。这些信号都在告诉我：虚拟与现实交互会成为大趋势，也会催生更多就业机会。

### 探索：传统金融退潮，我转身寻找新大陆

传统金融业务持续下滑，团队不得不另寻出路，否则只有被清算一条路。而Web3，给了我一线曙光。

2020年货币宽松之后，一级市场因缺乏流动性，好项目很难出现；资本难募、烧钱太快，成了企业的普遍困境。二级市场更难看，2022年3月加息之后，无论你在互联网大厂拿期权，还是持有中概股，估值普遍蒸发了八成，公司只能裁员、节流来过冬。看看今年秋招的惨烈，就知道什么叫“卷”了。

除了关注这些赛道，我自己也下过水，试过TikTok跨境电商（GB站）。TikTok直播一出来，不少VC觉得可以把国内直播那套搬到欧美去，但大家都忽略了语言环境差异、人力成本高、同行压价这些麻烦。最后的结果就是：烧钱快、客单价低，盈亏算不过来。如今TikTok把重心转向东南亚，我还是先保持观望。

2020年以后，传统金融低迷，客户大量流失，公司必须开拓新赛道。其实我早在2015年就接触过Crypto，当时只是关注区块链技术，Web3概念还没有成形，我也一直认为早期泡沫不小。后来，一位分析师老友跟我聊起去中心化金融DeFi，我顿时觉得这东西和我的金融背景高度相关。再看每季度的研报，Web3、元宇宙、NFT层出不穷，我开始重新审视Web3，兴趣也越来越浓。

我把想法告诉两个合伙人，决定单独去开辟Web3赛道。靠金融圈的人脉，我找到了一些国内Web3初创团队，以学习者的身份加入。只有亲自下场，才能快速摸透这门生意的可行性。同时，我积极参加线上线下的Web3分享会，认识了不少行业VC。从他们那里了解到，很多企业已经在尝试Web3，国内的配套设施也在慢慢跟上。

[PRE2]

不过整体市场仍在收缩，更多企业开始琢磨NFT与营销、社交、众创经济的结合方式。大厂们也在推出自己的NFT，并尝试与线下实体结合，这正好符合国内“以虚促实”的经济方向。也正是这些变化，让我更加确信Web3就是未来的方向。

### 展望未来：资本涌入，熊市生存

公司走到今天，也等于被逼着转型Web3创业。我凭过去的金融背景很快拿到了启动资金，但新的问题随之而来：Web3的战略方向怎么定？团队架构怎么搭？有一句老话：选择比努力更重要。但选赛道之前，先要看你手里的资金规模有多大，能支撑你看哪条赛道。尽管我在传统金融也经历了两轮牛熊，没有人能保证自己的判断永远正确，无非是用前沿眼光去博一个概率。

现在Web3融资市场的状态是：市场上并不缺资金，缺的是值得投的好标的；而真正的优质项目，也从来不愁钱。过去十年，Web3市场创造了约3万亿美元的流动性，这个规模已经能和传统基金投出的初创公司总价值匹敌。大量专注Web3的基金在数量和增幅上都创下纪录，有些甚至弯道超车，例如Multicoin，表现超过了很多传奇老牌基金，手里握着充沛的现金。

[PRE4]

要知道，2015年DCG募资2500万美元，当时已经是Web3行业比较大的募资案例。如今再看，私募基金的体量已经强到难以想象：Polychain、Paradigm、a16z、Multicoin、3AC等专业玩家，各自管着几十亿甚至几百亿美元。红杉、软银、Coatue、老虎、光速这些老牌传统基金和创投机构也早就杀进市场。全球大量对冲基金正计划五年内把7%的资产投向Web3，养老基金这种庞然大物也开始筹备直投。无论新钱老钱，都在加码资产配置，这个市场没人敢忽视。

讲了这么多光鲜面，接下来必须泼盆冷水：Web3有红利，也有致命的另一面。熊市在任何市场都不可能消失，2022年初，整个行业又在全球加息和战火中迎来寒冬。但经历过2014、2018年的两轮深熊，以及2021年的疯狂牛市之后，整个市场的心理承受力已经比当年成熟很多。

[PRE5]

大家面对利好利空时，不再歇斯底里。大量资金进场、流动性池加深，也让涨跌曲线变得相对平缓。可即便如此，市场仍出现了超过40%的持续暴跌。被称为“超级蓝筹”的ETH，在2021年12月24日到2022年1月24日这一个月里，市值就跌掉了46%。任何刚入场的新人看到这个数字，大概都会心惊肉跳。但老鸟们呢？基本该干嘛干嘛。比起他们以前经历的熊市——一周跌掉80%-90%都屡见不鲜——现在的行情真是“温柔”多了。

当然，熊市依然会击穿很多人。那些借钱、加杠杆的，真的会破产、崩溃，甚至放弃其他有前景的项目，彻底失去长期预期。这个市场人来人往，有人痛骂离场，也有人踩着前人的教训进场，幻想自己能在底部买入，然后等来一场冲天牛市。但现实真的有这么简单吗？市场像汪洋大海，温柔时能托起你，狂暴时也能吞噬你。真正穿越牛熊的老鸟，都知道一句话：敬畏它，并与它共舞。

如果你是初次涉足Web3的年轻团队领袖，请一定要保护好你的团队，别让市场崩塌的连锁反应伤到每一个人，尤其是近期FTX暴雷引发的一系列问题。现在不少团队乱用弹药，核心工作却一塌糊涂。真的想提醒各位Web3从业人员：不要浪费弹药。如果你想去一家有野心的Web3公司，签约之前，建议先问清楚他们的赛道和现金状况。在一个弹药充足的“基建型”公司里工作，熊市中一定是个更好的选择。只要能熬过漫漫长夜，等到太阳升起，你终会拿到想要的结果。

### 最后

如今的Web3风险投资，已经不像传统VC那样只出钱就完了，而是“钱＋孵化＋资源对接”的全方位价值系统。熊市里，我的公司前期既做VC，也做项目方。从金融风控的角度看，要给自己留足容错率，早期如果只ALL IN一个方向，风险很难控制。如果你需要Web3.0资源对接，或者想找相关岗位，欢迎随时来找我交流。
