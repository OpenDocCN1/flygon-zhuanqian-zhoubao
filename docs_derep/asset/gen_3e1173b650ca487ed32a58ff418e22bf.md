# 一、我为什么要做AI写作变现？

加入这个项目有两个核心驱动。第一，想把AI写作学会，用来提升我本职工作的效率；第二，想把自己的能力通过AI写作卖出去。

我本身就做文案，也会做PPT。以前只敢接自己专业领域内的公众号稿、策划案这类单子，量很不稳定，有时一个月都接不到一单。接触到AI写作后，我最大的顾虑被解决了：遇到不熟悉的领域该怎么快速上手。过去得自己翻资料研究，现在直接让AI去搜集、整合，快速出初稿。

所以在我看来，代写是最直接把现有能力变现的方式之一。

看完航海手册才发现，AI写作的底层逻辑跟我们平时的工作套路是一样的，就五步走：

找对标学思路——检索资料补知识——指挥AI干活——产出初稿——人工精修。

思路清晰后我就直接开干了，用实战来学方法。

下面就以小白视角，分享从接单到交付的全过程，其中会重点拆解教案设计的实操，希望对刚起步的同学有用。

# 二、新手怎么拿到第一单？

先行动起来就对了！

前期别想太多困难，问题出来了再解决，这些经验以后都是你的底气。

做不成也没损失，不做就一直卡在原地。

### 1.首战在哪打：淘宝/天猫海投

直接去淘宝、天猫私信客服就行，别怕被拒。一家不行还有下一家。

我就是批量投递，一共联系了40多家店铺，最终进群成功大概15家。

这个环节有两点必须记住：

*   做好表格追踪。面试群里很多店铺都要下单好评，单号钱都会退。如果同时面好几家，很容易搞混谁下过单。建议先加客服微信留存，再下单。因为很多店铺最后都是同一个客服，重复下单很浪费。

*   面试没那么可怕。面试基本就问你擅长写什么，可以写擅长的方向，也写喜欢的类型，写得越全越好。作品集不是硬性要求，被问到就把以前做的项目截图发过去，大多不会深究。

### 2.怎么选第一单？

##### 2.1 基本接单流程

很简单：看群里派单消息——看到合适的单子加微信了解——确认接单——拉群对接。拉群成功基本就算接成了。

##### 2.2 选择原则

*   别碰急单。新手做第一单最怕来不及，选一个时间宽裕的单，给自己留出学习和打磨的时间。

*   选自己能看懂的。第一次跑流程，本来就需要摸索期，选一个大概能理解的主体，交付会安心很多。

我第一单一开始看群里全是教学设计的单，我没碰过。后来看到一个土布创意课程的设计单，正好对这个方向有点概念，而且交付周期不紧，就接下了。

# 三、交付怎么搞定？以教学设计为例

接单第一件事，搞清楚客户要什么！

要明确做什么、要达到什么质量和字数标准、用什么格式输出、什么时候交。

我的第一单就是土布创意制作的教学设计，包含教学设计方案+说课稿+讲课PPT。以下就以这单为例子展开。

### 教学设计

我第一次做教学设计，连基本框架都不清楚。于是先去网上搜了一下教学设计的标准模板和包含内容，再开始用AI来做。

*   1.1 先告诉GPT你的需求，让它给出可以扮演的专业角色

*   1.2 让它扮演指定角色，按照要求出一份教学设计方案，可以补充更具体的细节让任务更准

[PRE4]

*   1.3 找一个参考模板，对照模板手动调整格式和顺序。

到这一步，教学设计就完成了。

人工润色要点

· 给课程起一个亮眼的标题，增强独特性，我这单就叫《土布的新生》，也可以让AI先出10个标题供选择。
· 把AI输出的冗长过程提炼成短句，形成清晰的逻辑链。比如引入部分提炼为：故事引入→材料认知→兴趣激发。这样整体会更清晰有力。

### 说课稿

我是严格按照航海手册里的任务拆解法一步步完成的。

*   2.1 让AI先学习刚才定好的教学设计方案
*   2.2 用“角色+任务+要求”的方式，让GPT先出说课稿的大纲

[PRE5]

*   2.3 手动梳理大纲后，再让GPT分段生成，最后汇总成初稿

[PRE6]

*   2.4 人工通读，把语句理顺，控制到目标字数。

小提示：第一次写说课稿不知道篇幅，可以先不设字数限制，让AI多写一点，后期删减比补字更省事。

人工润色要点

· 删除AI分段时产生的重复开头，保持整体连贯。
· 说课稿要口语化，加一些过渡词和口语表达，比如“课程伊始、接下来我们、最后进入”等。

# 四、交付环节怎么走？

初稿完成后先加上水印，WPS里可以直接加。加完水印再发给客户确认。

客户满意就直接交付，需要改就按反馈修改。这单客户后来要求PPT里增加实操内容，我按意见调整后就顺利交付了。

# 五、踩坑记录分享

经过这段实操，我总结了两个大坑：

##### 事前沟通好需求，避免碰到难搞客户；

新手群里订单要么急单，要么客户难沟通。我接过一个单子，客户要求很高却不愿意讲清楚需求，觉得付钱就应该我们全包，最后交付还要退一半钱。这种单新手最好避开，接了就当练手，别太在意。

##### 管理好预期，提前谈质量标准，及时止损；

有一次客户前期说要求很简单，实际做的时候却不断追加需求，初稿出来又要大改。判断自己做不到位时，就要及时沟通止损，明确告知达不到预期，不要反复内耗。
