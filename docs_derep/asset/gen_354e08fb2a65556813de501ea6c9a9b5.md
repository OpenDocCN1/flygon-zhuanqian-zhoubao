# 实证分析

## 4.1 实证分析是什么

实证分析 Empirical Analysis 指通过收集真实数据，用科学方法去研究，从而得出结论或验证理论假设。它强调数据驱动，借助统计、计量经济学、社会学等方法对现实现象进行分析和解释。

常规流程：

1. 研究问题提出：定好研究对象和问题，明确假设或目标。
2. 数据收集：问卷、实验、公开数据等途径获取数据。
3. 理论框架与假设：基于已有理论提出假设和框架。
4. 数据分析：用统计或计量方法分析，比如回归、方差分析等。
5. 结论与解释：根据结果验证假设并解释发现。

实证分析常用在经济、社会学、医学、心理学等领域，跟纯理论分析不同，它更依赖真实世界的数据来检验理论。

在AI写作里，单独做实证分析这个赛道在闲鱼也能变现，一单客单价在1K到2K左右。

### 4.3.1 描述性统计分析

概念：描述性统计用来总结数据特征，快速了解数据全貌。主要包括：

1. 集中趋势：均值、中位数、众数
2. 离散程度：标准差、方差、极差
3. 数据分布：偏度、峰度
4. 图形展示：直方图、箱线图等

为后续分析打基础，广泛用于市场研究、社会科学等。

评估两个或多个变量间关系强弱和方向。常用方法：

1. 皮尔逊相关系数 Pearson

### 4.3.6 中介分析

检验中介变量在自变量和因变量间的作用。路径包括：

1. 路径a：自变量对中介的影响
2. 路径b：中介对因变量的影响
3. 路径ab：中介效应
4. 路径c'：自变量直接效应

常用 Baron-Kenny 和 Bootstrap。
