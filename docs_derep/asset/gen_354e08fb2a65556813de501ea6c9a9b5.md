# 实证分析

## 4.1 实证分析概念

实证分析Empirical Analysis，是指通过收集真实数据，用科学的方法去研究，从而得出结论或验证理论假设。它强调经验数据为基础，用统计、计量经济学、社会学等方法去解析现实现象。

实证分析通常包含以下流程：

1. 研究问题提出：定对象、定问题，明确假设或目标。
2. 数据收集：通过问卷、实验、公开数据等方式获取数据。
3. 理论框架与假设：基于已有理论提出假设和框架。
4. 数据分析：用统计或计量方法分析，比如回归、方差分析等。
5. 结论与解释：基于结果验证假设，得出结论并解释。

实证分析在经济、社会、医学、心理学等领域很常见。它跟理论分析不同，更依赖真实数据来检验理论是否成立。

实证分析单独作为AI写作的品类，在闲鱼也能稳定变现，一单客单价在1K-2K之间。

1. 集中趋势：均值、中位数、众数
2. 离散程度：标准差、方差、极差
3. 数据分布：偏度、峰度
4. 图形展示：直方图、箱线图等

为后续分析打基础，广泛用于市场研究、社会科学、医学、教育等。
