# 岗位设计，建议先从业务流程切入

企业日常运转中的流程，大体上可以分为两类：核心流程与支持性流程。

核心流程，指的是为广义顾客创造价值的过程。这里的“广义顾客”，不仅指外部消费者，也包括企业内部的下游工序。换句话说，核心流程通常会成为企业的价值链。

支持性流程，主要服务于核心流程，往往需要跨部门、跨职能协同完成作业。

可见，两类流程的定位并不相同：前者负责创造价值，后者负责保障前者顺畅运转。
