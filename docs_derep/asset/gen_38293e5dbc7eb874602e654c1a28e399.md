# 两个月死磕AI提示词，我终于摸到了门道

330大会结束那会儿，我天真地以为一个星期就能收工。结果一头扎进去，整整磨了将近六十天。

那段时间的日常特别单调：不停地产出新提示词，再把小排老师的稿子丢进去，让它吐出HTML版本的PPT。按一天五十份的节奏算，[PRE0][PRE1][PRE2][PRE3][PRE4][PRE5][PRE6][PRE7][PRE8]

评论区里，鲈鱼🐟第一时间赶到：“先赞后看，势在必得 666”；龙对调研方法很感兴趣，说想听；WILL留下了两个字：“专注”；瓜斯跟上队形：“先赞后看+1”；折腾 boy 程泽感慨“先赞后看，势在必得。泪目了”；Quintalynn直呼“教练太牛了”。

向上的塔皮那段话我印象最深——他当时正守着教练的直播，直呼内容量大到消化不完。他说自己终于明白：AI创作绝不是一键出稿的偷懒神器，它更像写作，需要反复琢磨、不断推翻重来。你得知道毛病出在哪，得清楚自己到底要什么效果，还得想明白怎么把它讲出来。他也感谢了这份文字版整理，坦言目前还没完全吃透，但一定会找时间认真补课。
