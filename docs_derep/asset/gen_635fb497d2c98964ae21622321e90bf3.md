AI 写出来的东西为什么总能一眼看出来？无非就几样毛病改不掉：短句堆砌、破折号乱用、段落切得太碎。只要这三样出现，AI 感就藏不住了。

所以我直接把规矩写死：禁止连续短句、禁止破折号、禁止过度分段。就这么几条管控，出来的内容 AI 痕迹直接砍掉一大半。

你看到的这些条条框框，其实就是我日常写作的底线。不是抄的套路，是我亲手一篇篇打磨出来的手感。把这套标准封进 Skill 之后，AI 写的笔记才真正有了“是我写的”那种味道，而不是“又一个 AI 写的”。

## 6.4 关键词布局 Skill：把流量提前埋好

文案定稿只是半程，后面还有关键词的布局。

很多人写完就直接发了，这块我一直当成战略工事。小红书的流量分两路：一种是系统推，量大但不精准；一种是用户搜，量小却极准。我两边都要。

于是我建了一套核心搜索词库，再配了一份落地方案，明确告诉 AI 正文、封面、标题、开头、结尾、话题、评论区各自该放什么词、密度如何。相当于给词库配了个指挥官，把词精准投放到笔记的每个角落。

这套机制的好处是长效。即使我某段时间不发新内容，过去埋下的关键词依然在持续带来搜索订单。这词库是活的，我每周都会从后台捞取成交好、点击高的词补充进去，并按转化效果重新排序。

## 6.5 串成一条线：一条指令跑完整条流水线

把前面几个 Skill 串起来，就是我现在用的生产线。

一套小红书内容在我这等于 1 篇文案 + 6 张封面图。固定流程是：选方向 → 写稿 → 人设图 → 做封面 → 截图出图 → 发布。

现在我只要一句指令就能点燃整条线，发完指令自己去喝杯咖啡，回来活儿已完成，基本半自动化，错了它会自动回滚修正。

有人会问，这样的初稿能直接用吗？

实话是：我只改 10% 以内。

改哪儿？基本就 P1 封面和正文标题。其他地方我很少动。

因为这两处决定点击，是第一道门槛。AI 的标题看结构都对：痛点点到了、方案给了、数字有了、公式感也有了。可全对不等于好，还得拿在手里感受一下，有没有情绪，能不能把人勾住。同样的意思，有情绪和没情绪，点击率能差一倍。AI 能把“对”做到位，“感觉”这块还得人来补。

正文结尾的转化引导我扫一眼，模板在托底基本没问题。关键词、话题、评论区文案直接用就行。

所以分工很清晰：AI 负责把 90% 的“正确”做完，我负责往剩下的 10% 里注入感觉。很舒服。

我的周节奏是：周一做关键词和竞品调研，周二出文案，周三做封面，周四同步飞书，周末逐篇润色发布。4 个账号稳定周更，我的精力只集中在最后的润色上，其他交给系统。

核心逻辑其实就一个：把我十年积累的经验，变成可反复调用的工具，而不是每次都从零向 AI 解释我是谁、要什么。这些 Skill 没有一个是网上下载的，全是我业务里长出来的。

## 七、换个赛道，Skill 的长相完全不同

讲完小红书，你可能会觉得 Skill 不就是知识库 + 选题 + 写稿的组合，换个业务照搬不就完了。

完全不行。用我的公众号举例，同一个人、同一套底层系统，换个业务长出来的 Skill 完全是另一副模样。

公众号的内容是个人成长、创业复盘、AI 方法论，跟小红书的干货设计是两回事。底层依然是 Obsidian + Claude Code/Codex，但喂进去的内容和长出的 Skill 都变了。

### 7.1 同样的系统，两份「我是谁」

这里有个关键细节要单独说。

我的 Obsidian 里放着两份自我定位：

[PRE1]

一份是 Leo 的 IP 档案，给小红书用的人设。里面是我是博主 Leo，专做设计审美、服务中高端设计师。另一份是我真实的个人档案，35 岁、创业 8 次、屡败屡起、性格热血，这份给公众号、朋友圈、社群用。

我还专门写了规则：小红书内容禁止调用真实档案，公众号和个人品牌的內容才用它。

为什么要分开？因为场景不同，“我”也不同。

小红书用户要的是干货和解决方案，他们认“设计专家 Leo”。公众号读者想看一个真人，想看简哥是怎么摔倒又爬起来的。档案混用就会精神分裂：小红书笔记冒出创业失败的苦情，公众号文章却全是冷冰冰的设计术语。

所以让 AI 认识你，也要先分清是哪个场景的你。同一个人不同业务有不同身份，要用不同角色去做不同项目的工作。这就是 CLAUDE.md 越做越细的原因。

### 7.2 公众号的王牌 Skill：一鱼多吃

小红书的核心是选题 + 创作 + 关键词，公众号的扛把子是“一鱼多吃”。

它解决我一个老大难：原始素材太多、散着、懒得整理。

我常有长语音、开车时口述的灵感、跟朋友 1v1 交流的录音、社群分享的片段。信息密度高，全是真思考，却一直吃灰，因为整理成本太高。

一鱼多吃 Skill 就是干这个的。丢一段录音稿进去，它能拆成：

- 一篇公众号长文初稿
- 几条朋友圈文案
- 一个小红书笔记角度
- 再把里面的金句和观点提炼出来

一场 1-2 小时的直播或分享，加工后够我用半个月。

### 7.3 长文 Skill：把反 AI 味推到极致

公众号写长文，最怕 AI 味。个人成长类文章一旦被识破，信任感瞬间归零。

所以我的长文 Skill 里，反 AI 规则比小红书更严：

禁止连续短句、禁止滥用破折号、禁止过度碎段、禁止“首先其次最后”这类八股、禁止正确的废话。都是我自己写作时的真实忌讳，一条条抠出来塞进去的。

你正在看的这篇文章，本质就是在长文 Skill 辅助下一段段磨出来的。它了解我是谁、我的经历、我的语气、我讨厌的表达方式。所以递上来的初稿已经有七八分“简哥味”，我再改、调、加料，效率提升太多。

### 7.4 两个案例对照，结论就出来了

小红书和公众号放一起看，得出的结论很清晰：Skill 不能通用。

它长什么样，取决于你的业务任务和你是谁。

同样是我，同样用 Obsidian + Claude Code。小红书要高频、标准化、搜索导向的短笔记，就长出“选题 + 创作 + 关键词”这套。公众号要真实感、观点、传播力的长内容，就长出“一鱼多吃 + 长文”这套。土壤不同、任务不同，种子自然长成不同形态。

这也是为什么别人的 Skill 你抄不走。不是技术抄不走，是土壤、真人、业务场景抄不走。

## 八、从零造一个属于你的 Skill 怎么做

听完可能你也手痒了，想动手。

先说清楚：原创 Skill 不需要会写代码。难的是想清楚你的重复任务是什么。

我总结成三步走。

### 8.1 第一步：找准高频重复任务

拿个本子，把你每周都在循环做的事情列出来。

核心看两个字：高频、重复。偶尔做一次的不算，做法每次都不一样的不算。要找那种“这周做、下周还做、做法大差不差”的活儿。

比如我的笔记审稿，客服的重复回复，知识付费的写稿选题目。按频率排序，越靠前的越优先。

很多人卡在这儿，觉得自己做的事“没技术含量”“不值得做成 Skill”。后面会专门说心态，先记住：越是你闭着眼都能做的活儿，越值得 Skill 化。

### 8.2 第二步：把判断标准挖出来

这是最核心也最难的一步。

找到高频任务后问自己：我做这件事时脑子里到底按什么标准在过？

审稿时我会看：标题行不行、开头能不能抓人、逻辑顺不顺、有没有硬伤。这些就是判断标准。

把隐性知识变成显性规则，写清楚。写得越细，Skill 越像你。我那个创作 Skill 里塞了几十条标准：标题字数、思维方式、归因逻辑、禁用词，全是我掏出来的。

小技巧：想不起标准就回想“上次我为什么毙掉一稿”。你的否定理由，就是最真实的标准。

### 8.3 第三步：让 AI 造第一版，然后死磕迭代

标准理清后，把任务和标准丢给 Claude Code 或你用的 AI，让它出第一版。肯定不完美，拿真实任务去测，不对就改：规则没写清就补，理解跑偏就说明白，漏了标准就加进去。测、改、再测，直到满意。

[PRE5]

这里有我踩过的坑：别想着一个 Skill 干所有事。

我早期想做全能 Skill，一次性搞定对标、选题、写稿、配图。结果一塌糊涂。没人能一步到位，贪快反而更慢。因为一个 Skill 干三件事，就要做三次独立判断，每次都可能偏离标准，三次相乘早就飞了。

正确做法是拆。选题 Skill 只管选题，创作 Skill 只管创作，关键词 Skill 只管布局。每个 Skill 只做一件事、只做一次判断，结果更稳也更好维护。记住：专而精，不贪大。

维护方面：骨架不动，微调常做。

框架不能乱动，因为 Skill 间强关联，一个变整条线都要调。所以主体定下来后我很少动。

但小修小补每周都有：按数据新增规范、更新关键词、给封面 P1-P5 加引导词、调字体规则，几分钟搞定。

何时大改？我定的信号是：封面点击率持续下滑，或阅读量连续 2-3 个月下降。那就说明底层规范过时，需要重改设计规范和关键词策略。

一句话：数据不报警就小保养，报警了再大手术。

## 九、最后两句心里话

方法讲完了，最后说两句更重要的。

我这半年接触不少想用 AI 的朋友，发现卡住他们的不是技术，是心结。我自己也曾被困住，现在一起说破。

第一个心结：“我的工作没价值，不值得做成 Skill”

太多人这么想，觉得自己每天做的事平平无奇，谁都会。

恰恰相反。你“看一眼就知道行不行”的直觉、你没意识到的操作流程、你踩坑换来的标准，对你来说是日常，对 AI 和别人来说是稀缺资源。

我做 567 篇笔记才磨出的标题手感，拆 25 个品牌才沉淀的审美判断，对我只是习惯，却让我的 Skill 长出了别人复制不了的模样。

Skill 的价值不在于技术复杂度，而在于你的隐性知识密度。你觉得不值钱的日常，一旦固化成可运转的系统，就值钱了。别瞧不起自己的活儿，你的“习以为常”才是金子。

第二个心结：“我的方法论不够高级，拿不出手”

也有人觉得自己的东西太土，不够高级。

想通一个点：专业是相对的。60 分的人能教 40 分，40 分能教 20 分。你不需要是行业顶尖，只需要比你的用户多走几步就够了。

我在真大神面前不算什么，但对还在为“高级感”发愁的 3-5 年设计师，我的经验就是解药。你的方法论不需要惊天动地，只要真实、来自实战、能解决具体人群的具体问题，就够了。

## 写在最后

回到最初的问题：为什么别人的 Skill 到你手里就废了？

答案现在清楚了。不是 AI 不够强，是 AI 不认识你。不是 Skill 不好，是它没在你的土壤里长出来。

我用 AI 最大的体会是：AI 只是放大器，放大的是你自己。

你是谁、你有多少真东西、你愿不愿意把自己完整喂给它，决定了它能帮你长出什么。所以别到处搬运，先回头写好一份“我是谁”，把这些年攒下的真东西一点点喂进去。

种子可以借，土壤必须是你的。

我还在路上，还没单飞，但方向已定。如果这篇文章能让你搭系统时少走弯路，我就很欣慰了。
