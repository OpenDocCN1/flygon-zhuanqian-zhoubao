# 从产品经理到公众号爆文副业：一个人闷头干，靠流量主赚了18万

大家好，我是ph。今年四月才加入生财，算是个新人。之前刷到不少圈友分享公众号爆文的项目经历，感触挺深，所以也决定把自己在加入生财前那几个月实操这个项目的思考写出来，给想上车的朋友一点参考。

## 一、从迷茫到入局：一次朋友介绍带来的转机

去年之前，我是一名产品经理。后来公司项目停了，我一直在家待业，整个人挺迷茫的。经朋友推荐，认识了公众号爆文这个项目。想着反正闲着也是闲着，不如试一试。毕竟做过产品，公众号也算老本行；那阵子刚好也在研究GPT，感觉能结合，于是当晚就翻出一个以前注册的旧号，改了名，发了第一篇文章。

## 二、整个过程的起落：我踩过的四个阶段

### 1. 初试阶段：老号给了我惊喜，也让我怀疑

可能是早年注册的老号有一定权重，加上选的是当时正火的情感领域，日更了十来篇后，竟然跑出第一篇10w+。我当时信心爆棚，一口气凑了4个号继续写情感，可结果很打脸——除了那个老号，其他几个新号更新了30、40篇都没能入池。

我开始怀疑项目本身。后来刷了一圈同领域账号才发现，大家的数据其实都在下滑。原来是领域太热了，流量被稀释了。心态稍微放平，那两个月也赚了几千块。

### 2. 扩大规模：多点测试终于让我日入过千

发现问题就解决问题。既然情感领域不行，那就多个领域一起试。

趁着国庆回家，我把亲戚们的微信都借来注册了公众号，又攒了10个号。平时刷“看一看”时，看到什么爆文就往对应领域的微信群丢，相当于建了一个选题素材库，写的时候直接去里面挑。

这次除了情感，新号被分散到地理、民生、养老金、创业、交通、军事、娱乐等方向测。因为不同领域需要不同的表达，我开始积累不同的prompt，也咬牙升级了GPT4。升级之后对我帮助最大的是webpilot联网功能——写科普性质的内容简直如虎添翼（虽然现在webpilot不能用了，但可以直接让GPT4或kimi搜索来写）。

最后，这批新号有一半入池了，我也第一次体会到日入过千的爽感。到10月底，公众号累计收入将近2万。

当然，问题也不少：
- 文章爆了之后没有及时重复发，白白浪费流量；
- 某领域入池后，没立刻开更多新号跟进去；
- 没有明确的停更标准，把时间浪费在没入池的号上。

### 3. 发现宝藏领域：单号写出百万阅读

11月开始，10月那批号陆续入池又出池。其中一个10月中旬起的新号，让我意外发现了一个新领域——职场体制。

起初也是照旧策略：看到新领域、有空号，就写写看。但很快我发现这个号太猛了。前面虽然也写过10w+，但顶多也就二三十万阅读。这个职场号突然来了一篇，直接冲到上百万播放。那几天我几乎啥都干不了，一直盯着后台刷新，生怕出问题。

中间还出了个小插曲：有篇10w+被人投诉抄袭。我慌得不行，到处找办法。其实那篇只是标题类似，内容是自己写的，不算洗稿。一开始想硬刚，后来想想还是以和为贵，就加了对方微信，真诚道歉，表示愿意删文。对方大哥也算仁慈，放了我一马，真的很感激。

### 4. 垂直深耕：把大领域切成小领域，收入迎来巅峰

总结前几个阶段的坑，我决定死磕已经爆了的职场体制。但刷对标时发现，同样叫职场体制，不同账号的写法、切入点完全不同，各有各的爆法。关键是要垂直。

比如“职场”这个号不垂直，但“职场里的人情世故”就垂直；“剧评”不垂直，但“专门写《三十而已》”就垂直。我把市面上收集到的对标账号，按更细的领域做了分类。

不仅内容要垂直，标题也要垂直。最好垂直到某些特定关键词上，因为这一阶段公众号推荐算法非常吃标题里的关键词。这也是为什么很多爆文总是长这样：“单位里，xxxx”“莫言说：xxxx”“《三十而已》：xxxx”“xxx退休金，xxxx”。

有了对标账号和文章，我又厚着脸皮找亲朋好友注册了一堆新号。这次全部砸向职场和体制的各个细分赛道。结果确实赌对了，这批新号更新10～30篇后陆续入池，12月到过年这段时间，我每天都挺滋润，不同号轮番给我惊喜。这是整个项目收益最好的阶段。

### 5. 自动化：尝试RPA，可惜入场太晚

到这个阶段，瓶颈很明显——纯靠我自己用AI写，产量受精力和账号数量限制。尤其是刷脸借号已经差不多到极限了。

当时关注很多公众号，发现有人用RPA做自动写作。我觉得好，于是花了一星期学习，跑通流程。

我搭了两条工作流：

- 改写文章流：先用易攥找头条对标账号，再用八爪鱼/后裔采集器采集标题和正文，放进Excel；最后用影刀RPA批量提交给ChatGPT改写，自动保存。
- 原创文流：收集爆款标题，然后搭建原创写作对话，再用RPA批量生成并保存。

## 四、经验教训：最大的坑是闭门造车

回顾整个项目，我踩了很多坑。比如没在红利期用更多方式扩大账号规模，也没更早去做自动化。但最重要的教训是，我太“闭门造车”了。

从头到尾都是一个人琢磨，遇到问题就自己搜。坏处很明显——消息太闭塞。加入生财后每天翻圈友帖子，经常惊觉“原来还能这么做”“为什么我不早点看到”。

如果早一点加入生财、多链接朋友、主动请教、多合作，这个项目收益应该还能更高。当然，这些都是后话了。

## 五、这个项目现在还能做吗？

现在问我，我的答案是：它已经不是随手写写就能轻松赚钱的项目了，但依然有机会。

为什么不再轻松？因为平台算法一直在迭代。早期推荐算法不成熟，只要会选热门标题，在热门领域蹭一下，文章很容易爆。现在算法优化了，平台一定会限制标题党，越来越看重内容质量。单靠一个prompt生成的文章，越来越难拿到流量。

同时，一个领域火了大家都在进场，同质化严重，每个号分到的推荐量都在减少。同质化内容一多，平台也会限制。

至于AI内容，我认为平台不会专门针对AI去打击，它限制的是低质和虚假内容。只是AI很容易生成这类内容罢了。所以不管用不用AI，最关键的还是把文章质量做上去。

**后续机会点，主要在两个方向：**

选题上：
1. 往更细分、更蓝海的领域去试；
2. 火过的领域、文章或选题，可以换个角度、换个领域再写，常常还能再火一次。

[PRE16]

文章质量上：
1. 有能力原创出高质量内容的，可以尝试原创（但不适合矩阵玩家）。最近很多爆文里，原创占比明显变高；
2. 用AI的话，要继续打磨prompt，调出更少“AI味”、质量更高的内容。

## 六、一些实操技巧分享

**1. 怎么让AI写的文章没“AI味”？**

- 思路一：用更聪明的大模型。更高级模型+简单prompt，效果通常优于普通模型+复杂prompt。
- 思路二：AI文章味重，是因为默认情况下它会用概率最高的表达，比如“首先、其次、另外、总的来说、想象一下”等。直接在prompt里禁止这些句式，再调一下temperature参数控制输出多样性，就能改善很多。

[PRE17]

- 思路三：让AI直接学习你想要的文风。星球和网上有很多教程，比如这个B站UP主的视频：https://www.bilibili.com/video/BV1rt421W7r2/?share_source=copy_web&vd_source=fcec28f89881477399bf778508bb6e89
- 思路四：最根本的办法，还是提升自己的写作能力，把AI当辅助。自己总结观点、给出案例，让AI帮你把杂乱思路整理成大纲，再按大纲写作。换句话说，要把AI当成一支更快的笔，而不是指望它替你搞定一切。

**2. 从微信里找选题的方法**

几个月前，最直接的是抄最近爆文标题去跟写。跟得够快，有机会拿10w+；跟慢一点，也有几万阅读。但现在微信对重复内容的限制明显更严了，短期内一模一样或高度相似的标题，很难再拿到推荐。

换个思路：我们可以不追近期爆文，而是选几个月前火过的文章。找到后搜一下标题近期竞争情况，如果大家都写过了就pass；如果近期没什么人写，那就可以试试。
