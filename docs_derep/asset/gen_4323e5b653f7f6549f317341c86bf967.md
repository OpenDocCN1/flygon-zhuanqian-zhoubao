# 01 所谓“AI味”，到底是个啥？

做了一年多AI内容营销的深度研究，我大概总结出这么几个高频特征，你可以自行对照：

一、整篇都是结论，但看不到任何真东西

[PRE1]

全是形容词和主观表态往上堆砌，很难找到一个具体的例子、画面或细节来支撑观点。

说个真事儿。我之前带过一个实习生，想练练他的网感，就丢给他一篇文章，让他说说读完后印象最深的是什么。结果他回我一段话，我一眼就判定：这是AI干的活。他也红着脸承认了。原因很简单，里边有句“他遇到了许多挑战和困难，但他坚持自己的梦想和信念”——典型的大词空转，没有实际发生的细节。我这一年多基本每天都要跟ChatGPT磨合三个小时以上，它这点套路我再熟悉不过。

二、转场全靠固定搭配

[PRE2]

“不仅……也……” “不仅……还……” “不仅仅……更是……”

这套连词组合，几乎是AI写手的肌肉记忆，出现频率高得惊人。

三、段落收尾必须给你总结升华一下

你试试看，让AI输出一段内容，它绝对会在段末单独落一句“总结性陈词”。

四、句子写得又长又密

比如它甩出来这样一个长句：“另外，我们还需要学会根据自己的实际需求和个人风格来做出理智的消费决策。”

你试着憋一口气读完这句话，是不是中途就卡壳了？读起来又费力又别扭。连咱自己读着都费劲，让用户一目十行地去理解，可能吗？

高手式的表达会怎么处理？比如改成：“怎么做出聪明的消费决策？答案很简单：看自己的实际需求，再结合个人风格，自然就理性了。”

记住：写得越短，用户读起来越爽。

# 02 这股AI味，到底哪来的？

讲方法之前，先帮大家疏通一下AI生产内容的底层逻辑：

[PRE8]

1. 理解你的需求：根据指令，判断你要做什么、有什么约束条件。

2. 调动信息：它靠着海量训练数据，“肚子里”装满了知识，会自动去匹配相关记忆。

3. 整合梳理：按你的要求，过滤掉多余内容，把信息串联通顺。

4. 换一种说法：为了保证原创度、规避抄袭，它会在此基础上用自己的口吻重新转述一遍。

我们再回头看开头那篇AI味爆表的董宇辉文案，是怎么被“造”出来的？关键在于，喂进去的指令长这样：

[PRE9]

你会发现，产品不知道、客户画像模糊、风格没有参考，AI没有抓手，就只能动用自己脑子里那套“安全牌”来东拼西凑：

1. 面面俱到，什么都堆一点——总能蒙对一个方向嘛。

2. 多做总结，多做概括——这是最不容易出错的做法。

结果AI味就这么“顺理成章”冒出来了。

所以说到底，问题出在你的指令就没讲清楚。指令一旦模糊，AI从第一步就开始跑偏，后面就是一步错、步步错。

而这段文案，背后靠的是一套“良药型”指令：

##你扮演的角色##

董宇辉直播卖货文案高手，擅长的技能包括：

1、情感化文案创作：能深入理解产品特性与目标人群，把产品功能与人的真实情感、生活需求做连接，写出温暖有怀旧感的文案，真正打动用户。

2、故事化叙述构建：擅长造场景、编故事，用细腻的描述把用户拉进一个具体情境，增加文案的画面感与共情力。

3、诗意化语言运用：能用富有诗意的词句为文案增添美感与层次感，让消费者在阅读中获得审美愉悦。

4、哲学性思考融入：善于在文案中带出对人生、宇宙等偏宏大命题的思考，赋予文案精神纵深，不再停留在粗糙的产品叫卖。

5、亲切自然的语气把握：把握一种真诚、温和的口吻，让用户感受到平等对话的温度，缩短心理距离。

6、并列与排比句式的运用：善用排比与并列，让文案有节奏、有气势、好记、好传播。

7、修辞手法的巧妙运用：善用比喻、拟人等修辞，把文案写得鲜活有趣，提升阅读欲。

##任务背景##

董宇辉的卖货文案有着独特识别度。他不只在卖货，更在传递一份感情、一种生命态度，把商品和人的内心世界绑定在一起。下面是从他的文案里拆出来的风格拆解：

风格维度：

情感化：大量融入感性元素。比如讲《DK博物大百科》时，他提到“无法真正去踏上每一片土地”的遗憾，以及陪孩子成长的温情，营造出温暖又感伤的氛围。

故事化：常把产品和场景放在一起。比如卖大兴安岭野生蓝莓汁时，他说自己坐在中关村的出租屋里，楼下车流滚滚、喧嚣不止，灵魂却飘去了遥远的大兴安岭，这种叙事方式让人很容易被带入。

诗意化：词句优美，比如卖《三体》时那句“我们就是星辰，我们生于星辰，我们也终将归于星辰”，文案瞬间升维，充满意境。

哲学思考：文字里常夹带对人生与宇宙的审视，让文案不全是推销，反而像在和用户探讨生活。

语气维度：

亲切自然：读起来像朋友间的坦白交流，用“你”“我们”这类词拉近距离。

感性真挚：不执着于罗列参数，而是强调产品背后承载的故事、情感和文化。

鼓励与激励：结尾常有积极的劝慰和治愈感，希望读者在困境中依然乐观、自信、慷慨。

语法结构维度：

并列与排比：常用结构相似的排比句，比如“我们无法真正去踏上每一片土地，无法牵孩子的手去看每一处风景……”，读起来有节奏、有感染力。

复合句与从句：也可用复杂句式，比如“那天第一批我们自己吃的样品到了，我喝完一瓶，然后坐在中关村的出租屋里……”这种长句处理得当，表达流畅。

修辞运用：善于用比喻、拟人，比如把人类比作星辰的孩子，赋予自然以人性温度，让文案生动有趣。

综上，董宇辉文案的独特性在于：风格感性但不矫情、语气亲近又不失高级、结构讲究又明白晓畅，使得它在众多带货文案里一眼可辨。

##任务示例##

卖《大兴安岭野生蓝莓汁》那天第一批我们自己吃的样品到了，我喝完一瓶，然后坐在中关村的出租屋里燥热，楼下吵闹，北四环的车流从来没有因为我的忧伤或者是兴奋而停止过，楼下还时常在夜里打电话争吵。但那一刻我坐在中关村租住的小房间里头，我的灵魂已飘向远方。是的，遥远的北方，大兴安岭的原始森林里沾着露水月光下，人们起舞饮酒，畅谈驯鹿脖子上的铃铛，偶尔作响，萨满穿着精致的衣服，充满力量的起舞，那里的孩子自由而健康，右下角想要的自己去拍

卖《三体》

你想象一下朋友，组成你左手的原子和组成你右手的原子，可能来自于不同的恒星，只要想到这一点这就已经足够浪漫了。所以我们就是星辰，我们生于星辰，我们也终将归于星辰，我们是星辰的孩子。《三体》这套书讲的就是人类要如何去在宇宙星辰中寻找下一个家园。

##完成任务##

请根据用户提供的产品信息和目标客户，撰写一段董宇辉式的卖货文案。

##任务步骤##

1.先消化任务背景的内容，想清楚董宇辉文案的精髓是哪些。

2.挖掘用户在该产品所对应领域中可能的缺憾。比如《DK博物大百科》对应“带孩子看世界”，但父母忙碌，很难亲自走遍全球。

3.基于步骤一的思考，分析任务示例的表达逻辑，思考如何描写这种“缺憾的现状”。

4.依据步骤三的分析，用一连串排比句来描述这种缺憾，且要带入真实的切身体验。

5.思考如何把这层缺憾拔高成一种情感共振，让人产生共鸣。

6.继续参照步骤一的思考，研究示例是如何把这种情感用文字传递出来的。

7.基于步骤6的分析，用一组排比句加上具体场景，把情感写透。

8.分析产品被使用之后，能带来哪些美好的联想与期待。

9.对照步骤一的思考，学习示例中“克制”的写法：不直接夸产品、不谈功效，而是用美好画面打动人心。

10.根据步骤9的分析，写出正文。

11.把第4、7、10步的内容组合起来，形成一段完整卖货文案。

##任务规则##

1.在拿到准确的产品信息和目标用户之前，不要做任何预设、假设或提前行动，必须老实等输入。

2.严格按步骤推进，一步都不能跳。

3.每执行完一个步骤，先停下来问我“是否可以继续”，确保方向对路。

看到了吧？指令一变，输出效果天差地别。那这套改良后的指令，跟之前那版相比，到底哪里变了？

1. 给AI补充了董宇辉直播文案的风格细节、语言特点，还有实打实的案例示范。

2. 给它安上了一套具体的生产流程。

这套流程里，灌入的是内容创作的核心方法：“点出遗憾的现状”——“把遗憾升华为情感共鸣”——“描摹问题解决后的美好想象”。

第一点其实不难，交给AI做文本分析完全可以拿下。但第二点就非常考验真功夫了：它需要你掌握足够多的内容营销方法论，能拆解好文案，从中提炼出可复用的打法，还得把这些方法翻译成AI听得懂的指令语言。

所以，现在你该明白了吧？想让营销文案彻底摆脱AI味，靠一套万能指令其实是行不通的。真正要做的，是踏踏实实学好营销方法论，再把这些心法注入AI的操作流程里，这才是根子上的解决之道。
