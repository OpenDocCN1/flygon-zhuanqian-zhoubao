## 一、如何装上这款助手

常规流程是打开Chrome浏览器，点击右上角拼图样式的扩展图标，进入扩展管理，再点底部的Chrome网上应用商店搜索目标工具。更省事的做法是直接复制官方安装链接到浏览器打开，点击加入Chrome即可。文档里已贴好快捷地址，可直接拿来用。[PRE5]

## 二、HARPA AI 的具体操作

### 1. 启动工具
安装完成后在Chrome右上角会出现其图标。[PRE10]
点一下会弹出操作框。提示：需要开启网络环境，并完成GPT账号登录或填入API密钥。[PRE11]

### 2. 初始配置

#### 语言切换
进入设置，找到 preferred chat language，改成 custom，然后在 custom language 栏填入 Chinese，回复就会用中文呈现。[PRE12]

[PRE13]

#### 模型选择
在 openai connection type 中挑选接入方式。
选 Browser session 会自动读取已登录的GPT账号，并按账号等级展示可用的模型，Plus用户可选用GPT4。
另外一种是 OpenAI API key，填入密钥后即可调用。[PRE14]

[PRE15]

[PRE16]

### 3. 常用功能
唤起后能调用内置的一百多个快捷指令。本篇重点用三个：/summary、/todo 以及基于页面的问答。/summary 负责压缩网页正文要点，/todo 负责提取文中待办事项，问答则基于当前页面内容即时响应。[PRE17]

## 四、延伸玩法思考

上面属于基础用法。实际上该工具支持自定义指令，把个人专属的指令存进去，就能像 /summary 一样一键触发。
