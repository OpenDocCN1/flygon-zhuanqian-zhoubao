## 聊一聊抖音、小红书等未来的破局之路……

作者：白杨私人号
日期：2023-03-20

上周与一位操盘过四百万粉商业号的负责人共进晚餐，席间进行了长达数小时的头脑风暴。话题从短视频平台跨到问答社区，再到种草笔记生态，随后延伸到商业模型与未来走向。把当晚的要点整理出来，供大家参考。

1. 做内容的路径其实有两条分叉。一条是亲自下场经营人设，把自己打造成内容输出口；另一条是做幕后搭建者，寻找合适的人选赋能。今天交流的对象属于第二类，更像伯乐式的发掘者，专门去寻找具备真实人生阅历的候选人。把握时机的关键在于往往在对方状态不佳时伸出援手，才更容易建立深度连接。

2. 如何维系合作？核心在于持续创造价值。先在对方处境艰难时介入，这本身就种下了信任的基础。后续当人设遇到瓶颈时，能调动人脉与资源给出解决方案，并在每个关键时刻提供精准支持，关系自然会稳固。简单说，就是持续给予，而非单向索取。

3. 先厘清自身的定位，到底擅长拍板决策，还是擅长落地执行。角色认清了，后续便不会出现内耗。

4. 公司的业务特质会直接塑造组织的气质。创始人主推何种项目，员工的状态往往会同步迁移。比如偏向快周期的项目，团队心态是完成一轮就盯下一轮，容易出现浮躁与不安。每个人都想着迅速变现、快速回本，爽完一波后进入空窗期就会出现集体焦虑。所以选赛道时务必意识到，赛道气质会反向影响到全体人员。

5. 保持对外走动与学习交流，这点极为关键。以本团队的实践为例，最大的增益永远是走出去看看，回来后务必落地。仅仅享受出行的那种向上感，却不做落地执行，本质上是在助长自负。

以上五点先抛出来与大家共勉。后续会持续把与优秀同行碰撞后的心得与方法沉淀分享。

……近期收到了花爷寄来的《开眼内刊》，看到亦仁老师的前半段观点。通过付费获取多元优质的信息源并真正沉浸其中，我已加入生财有术的社群，正在吸收各位前辈的精华内容。随后看到亦仁老师的后半段观点，鼓励大家通过不同渠道将自己的思考对外输出。结合昨日看到亦仁老师提到新人入圈后容易放不开，今天就决定勇敢迈出第一步。勇于融入，敢于迸发。[胜利][PRE0]
