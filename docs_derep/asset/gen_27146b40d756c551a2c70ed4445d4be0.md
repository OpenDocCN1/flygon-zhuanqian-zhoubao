### 1 先把需求想清楚

本质就是在一张巨图里定位一个小头像。

大图找小图天然是图像匹配的活，Python 生态做这个最顺手。于是我直接让 Cursor 用 Python 写个匹配脚本。

我跟它描述的需求是：大图尺寸大概 14173 x 3701，里面密密麻麻排满头像，每个约 64x64。我会丢一张不同分辨率的个人头像进去，让它在大图里搜出来，找到就把对应区域裁剪返回。行不行？

把大图拉下来确认尺寸后，就开始和 Cursor 对话。
