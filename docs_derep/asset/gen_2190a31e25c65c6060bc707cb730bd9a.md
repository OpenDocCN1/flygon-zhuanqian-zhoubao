# 出差第二天醒来一脸懵？恭喜你，可能睡到头了

作者：小马宋
日期：2025-07-07

最近我给自己整了个很野的睡眠自检法，专门用在出差这种环境陌生的场景。

清晨睁眼的第一件事，别急着摸手机，先在脑子里问自己一句：我现在在哪间房？这座城市叫什么？

要是脑子一片空白，想不起来酒店名甚至城市名，反而是好事。说明昨晚真的断片了，睡得够沉。

像今天早上就是这种状态。眼睛刚睁开，对住址完全没概念，城市感也掉了。拿起手机看数据才发现：Deep Sleep 2小时46分，Light Sleep 2小时43分。深睡时长直接反超浅睡，最长的一段深睡更是干到了51分钟。
