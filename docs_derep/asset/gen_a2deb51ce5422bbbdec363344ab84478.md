# 年入千万的秘密：把信息差变成钱，把一套模式复制一千遍

很多人问我：普通人在这个时代，到底靠什么翻盘？

先交代一下我的背景：一个在家创业十年的奶爸超级个体户，混生财圈子两年，发的帖子不算多，但有两篇被加精。我每天雷打不动翻帖子，这对我来说价值无限。要是你现在还没有项目，别犹豫，赶紧去参加各种航海打卡——先让自己赚到钱比什么都重要；要是你已经有方向了，那就把精力放到找合作、找高手取经、挖高价值信息差上面。

上一篇聊了中介思维，承蒙亦仁老大加精，这篇追更一个配套打法：**模式复制**。

我朋友圈里有个做培训的狠人，收学员一个5万到10万，妥妥的网赚培训天花板。他玩的叫“传帮带”：你交钱进来，老学员带新学员四个月。前两个月你跟着老学员干活儿、顺便学东西，赚到的利润分老学员一半；两个月后你出师了，老学员撤场，你顶上变成老学员，再带新学员。

什么叫模式？这就是一套跑得通的、牛逼的落地培训模式。

我一直反复强调两句话：
**赚100万，只需要一个自己实操成功过的案例，拿去卖！**
**年入100万，只需要一套跑通了的模式，拿去复制！**

先看第一个：网创IP中介操盘手。

网创IP这个圈子，说白了就是个大染缸。新人看着啥都眼红，个个蠢蠢欲动想下场——从这一刻起，你就成了别人镰刀下的目标。当你加满了3000个创业老师，手上就握着超过30万条信息，背后站着超过3000万粉丝。一手抓信息差，一手抓流量：会用就是印钞机，不会用就是一堆垃圾。

网创IP中介的本质，就是吃信息差这碗饭。信息差管够之后，剩下的难题就是搞定流量。做内容根本不需要绞尽脑汁，一套公式全解决：

**这个项目月入5万+拆解方法+找我来获取**

把公式套进不同的信息差里，反复用500次，创业粉自然就来了。

我有个学员，做了5个小红书账号，把公式改成针对找不到工作的姐妹们的版本，7个月时间攒了1万私域好友。之后我给她对接了100个实操项目老师，花5000块买了个深度链接的资格。跟这100位老师谈成了两个合作：一是拿到了他们的文案复制权，二是借他们的老学员帮着培训项目。后面5个月，她赚了16万。这就是爆发力。

说实话，我现在已经不太写项目拆解了——教项目的人太多了，我朋友圈躺着4000多个。我只需要玩他们就行。那4000多人都是我精挑细选的优质项目老师，人家专注做项目，我何必费那个劲？想做什么项目，花钱买一个就完事儿了。

我习惯赚“玩人”的钱，你习惯赚卖货的钱，完全不冲突：你卖得好，我付费链接你、向你请教，再给你组个100人的局来跟你学习。你既收了学费，又顺带卖了货，你看行不行？

再聊第二个：当个大姐大，搞带娃Vlog同城联盟。

“宝妈副业”这四个字，历来都是热门关键词，也让宝妈群体成了弱势方——韭菜重灾区。真正能长起来的比例少得可怜，但凡是长出来的，一个比一个生猛。

我不写那些煽情的宝妈人性分析，直接上结论：我一直强推**自媒体Vlog形式的短视频创业**。这玩意儿太适合宝妈了——记录生活、记录夫妻、记录幼崽、记录美食、记录购物、记录心情、记录焦虑……拿手机把这一切都拍下来就行。你只需要两样核心技能：一是不断精进讲故事的能力，二是提升拍摄剪辑的水平。

你想给观众呈现什么干货，一点都不重要。重要的是生活的真实感，以及你能不能调动观众的情绪——好奇、羡慕、感同身受、同情。村头大妈为什么爱嚼舌根？女性关注的点天生就跟男人不一样。微商时代宝妈为什么像蝗虫一样扑上来？说到底还是羡慕和向往别人家的好。

只要你把短视频拍好了，拍出让人羡慕的人设，你就拥有了超强带货能力，成功率比微商猛得多。

搞钱最好的商业逻辑是：
**找一堆代理帮你卖货，你只管做好人设、管好代理。**

你把短视频做成了，就能教别人做；她做成了，会对你死心塌地。三年下来你教了100个人拿到结果，这就是100个死忠门徒。有了这100个，就不愁没有1000个——这就是商业模式的设计。

作为中国人我们很幸福：全世界就数咱这儿商品消费最便宜，渠道商根本不缺。你要琢磨的只有一件事：怎么让人心甘情愿跟着你干。
