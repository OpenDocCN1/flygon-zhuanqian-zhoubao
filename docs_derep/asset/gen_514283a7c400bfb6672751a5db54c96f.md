可能有些朋友还没听说过n8n，但Coze、Dify这类工作流平台你应该不陌生吧？n8n就相当于它们的“威力加强版”——内置了400多款工具，社区生态开放，各种好玩好用的社区节点特别丰富；就算这些还不够，一个HTTP请求节点，基本能通过配置搞定你所有需求。最关键的是，它是开源项目，本地部署完全免费。

# 二、本地部署其实很简单

n8n一共有三种玩法：

1.  官方云服务：要充会员，功能最全；
2.  本地部署：支持npm和docker两种方式；
3.  自己的服务器部署。

虽然官方服务功能最全面，但对于我们大多数人来说，部署一个社区版已经完全够用了。考虑到不是每个人都买了服务器，这次咱们就挑最简单的Docker方式来讲。用Docker部署的好处也显而易见：

*   能在干净的环境里装n8n，不污染系统；
*   更方便配置你自己喜欢的数据库；
*   避免因为操作系统不同产生的各种疑难杂症——Docker提供了一套完全一致的环境；
*   以后要迁移到新主机，也非常省事。

# 三、搭建你的生图工作流

## 1、先拆解工作流

[PRE7]

大家看这个工作流，它主要由这么几个模块组成：

| 开始模块 | 每个工作流都必须有的起点节点 |
|---|---|
| 改图提示词生成模块 | 负责生成图片提示词，并整理提示词格式 |
| 出图模块 | 今天讲两种出图方式，各有利弊 |
| 上传网盘 | 把生成好的图自动传到谷歌网盘 |
| 循环 | 加上循环体，就能连续出图，实现批量生产 |

这两种出图方式，简单对比一下：

**第一种（gpt-image-1）**
- 出图速度快且稳定；
- 可设置的参数多；
- 输出格式规整，后续基本不用加工。
- 但按token收费，相对贵一些。

**第二种（另一种API方式）**
- 按调用次数收费，价格相对便宜；
- 但API输出的JSON包含信息特别多，需要自己额外提取需要的内容；
- 没有单独调整图片长宽比的参数，只能靠提示词控制，有时候会失控；
- 还有一定概率生图失败。

以上就是整个工作流的基本模块。接下来一步步实操。
