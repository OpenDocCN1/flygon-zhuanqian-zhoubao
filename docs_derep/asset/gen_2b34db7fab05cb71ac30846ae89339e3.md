# 别再把ChatGPT当搜索框：一个AI小白的“上船前自救指南”

如果你还没有真正用过ChatGPT，或者每次让它帮忙，结果都像是在给自己添乱，那么这篇内容或许适合你。

至于已经把AI用得很熟练的朋友，就不占用大家时间了——这只是一份写给新手的入门记录，目的只有一个：帮你撕开AI使用中的那层“看不懂、不会用”的薄膜。

## 一次次错过，让我决定先把自己“武装”起来

9月初，我因为一次偶然的机会认识了“生财”。最初加入，是冲着航海项目来的。

可刚加入就发现，很多机会已经错过了。10月航海需要脱产参加，我犹豫了几天，等终于下定决心报名时，名额已经满了。

前几天又看到杭州有航海家见面会，我花了两个多小时查看行程、搜索机票、协调时间，反复纠结。等我再一次鼓起勇气准备出发时，结果又被现实泼了一盆冷水。

后来我才知道，原来“航海家”并不是一个普通称呼，而是对那些已经在生财圈子里取得成绩、达到较高阶段的人的一种形容。

平时阅读社区文章时，总觉得这里高手云集。真正接触后才发现，厉害的人不仅有能力，而且始终保持着学习和行动的状态。

一个原本有些松散、缺少动力的人，置身在这样的环境里，很容易被周围的氛围推着往前走。

赚钱的方法、机会和教程，从来都不算少。普通人真正缺的，往往不是又一个秘籍，而是一个能持续自我更新、不断实践和复盘的环境。

只有经过训练，才有可能逐步拥有识别机会、整合资源、把普通信息变成实际结果的能力。

# AI时代，先给自己找个“助理”

我报名了12月的航海和志愿者项目，想着既然要参加，总得提前做点准备。

这种感觉，就像考试前临时抱佛脚。哪怕没完全准备好，至少先拿本书挡一挡，也能让自己没那么慌。

既然同时参加两个项目，还要做志愿者，接下来的任务量应该不会小。那就先给自己找个AI助理，提高一点效率。

我打开了航海板块，开始翻找那些能够快速上手的AI教程。

## 老师越认真，我越能感受到自己的差距

不知道有没有人和我一样：教程写得越细，越觉得自己基础薄弱。

我泡了杯浓茶，硬着头皮继续看。

读到“项目实操：写好提示词，让GPT高效工作”这一部分时，我开始认真琢磨，为什么别人一句话就能让ChatGPT产出高质量内容，而我写了半天，得到的结果却总是不对劲。

[PRE2]

教程给出的提示词结构，大致可以理解为：

- 交代任务背景；
- 赋予AI合适角色；
- 明确具体任务；
- 补充输出要求。

这个框架我以前其实见过，但一直没有真正掌握。看起来懂了，实际一用，结果却不尽人意。

直到教程用一个完整案例，把从需求拆解到提示词编写的过程展示出来，我才意识到，问题不在于自己缺少几个模板，而在于根本没有学会如何从零开始构建一个有效任务。

原来，高手和小白之间，差的不是几条现成指令，而是把模糊想法变成清晰目标的能力。

拿着成熟案例照抄，当然容易得到不错的结果。可一旦换成自己的任务，我就暴露出问题：

- 不知道自己真正想要什么；
- 不会把复杂需求拆开；
- 不清楚最终交付标准；
- 也不知道怎样判断AI的结果是否合格。

ChatGPT的能力可能相当于一个大学生，甚至是某个领域的专业助手。

但如果使用者只是一个刚入职场、经验有限，甚至基础水平并不高的人，又该如何指导这个“大学生”完成实际工作呢？

如果自己只能给出含糊、零散的指令，那么AI再强，也很难直接交出让老板满意的成果。

这就像看真人秀时，嘉宾们把问题分析得清清楚楚，旁观者也觉得自己懂了；可真轮到自己上场，才发现“看懂”和“做出来”完全是两回事。

# 难道只能等高手手把手带我吗？

刚开始我觉得，教程已经写得够详细了，自己还不会，是不是只能等航海开始，等教练或高手现场辅导？

但转念一想，这其实很正常。

AI、ChatGPT相关航海已经持续了很多期，每一期都有大量内容。一个航海项目通常只有21天，还要依靠大佬、教练、志愿者和优秀同学一起参与，才会有一部分人真正完成从学习到结果的转化。

这本来就不是一个随便看两眼教程，就能立刻掌握的东西。

## 如果真有一个人，愿意一直教我就好了

我脑海里突然冒出一个有些天真的想法：

如果有一个高手，可以不厌其烦地教我，从最基础的地方开始，一步一步带着我做，那该多好。

很快，我又觉得这个想法有点可笑。现实里谁会有这么多时间，专门陪一个小白反复练习？

但我想起曾经读过的一篇文章，作者对“小白”的定义非常彻底：

会用键盘打字，会使用鼠标打开软件。

这几乎已经是最低起点了。

## 谁会比自己的“亲爹”更有耐心？

既然现实中很难找到一个随时陪伴的老师，那我为什么不直接让ChatGPT来扮演这个角色？

它本身拥有大量知识，甚至可以让我同时调用老师、顾问、老板、编辑和行业专家的思路。

我可能不懂如何正确引导它，但它知道怎样引导我完成任务。

那就先把它当成一个非常有耐心的教练：

不会的地方就继续问，问到自己真正理解为止；不知道下一步怎么办，就让它告诉我下一步怎么做。

我只需要先搭好最基础的“台阶”，再一步一步向上走。

## 原来“当领导”的感觉这么好

我继续坚持一个原则：

先说出来，再逐步优化。

反正提出要求不需要额外成本，先把方向讲清楚，再让AI帮忙补全逻辑。

[PRE12]

没想到最后整理出的提示词，竟然真的有点像一个领导布置工作时的样子。

论结构、逻辑、表达和任务安排，都开始有了模样。

那一刻我甚至产生了一种错觉：如果有人愿意花8000块钱，请我用几天时间专门设计这套提示词，我好像也能认真完成。

当然，我也知道自己并不是真正的领导。

看起来写得不错，不代表一定有效。要是没有经过验证，直接把结果交给“老领导”，一旦效果不行，最后尴尬的还是自己。

# 既然要交付，就先安排一次调研

电视剧里经常有这样的场景：

“你们两个下去做深度调研，明天上午把一万字报告交给我。”

那我也照着这个思路来。

继续动嘴，不急着自己动手。

[PRE13]

## 一个“领导”最重要的任务，是让流程持续推进

有了调研和分析结果之后，不能停在报告本身，还要根据报告继续修改工作方案。

这样一来，我好像真的开始具备了一个领导应该有的样子：

- 能提出目标；
- 能安排调研；
- 能查看分析；
- 能发现问题；
- 能推动修改；
- 能让整个流程继续运转。

[PRE14]

# 不验证，永远不知道到底行不行

提示词来回完善了这么久，我以为它应该已经没问题了。

但如果不实际测试，直接交付给别人，万一结果不符合要求，自己就要承担后果。

所以我重新开启了一个聊天窗口，按照这套提示词完整测试了一次。

果然，结果并没有达到预期。

仔细检查后发现，原来的要求实在太多：字数要求、结构要求、表达要求、内容要求全部堆在一起，任务总量超过2000字，对AI来说本身就不容易一次完成。

## 体谅“下属”，把复杂任务拆开

既然我是“领导”，就不能只会发号施令，也要考虑执行难度。

那就把整个任务拆成几个阶段，让ChatGPT分步骤完成。

对我来说，不过是多复制粘贴几次；但对AI来说，却能大幅降低一次性处理大量要求的压力。

[PRE15]

最终，我把完整任务拆成了5个阶段，用5条提示词共同完成整篇内容。

这次写作让我第一次真正体验到“费曼学习法”：

为了把过程讲给别人听，我必须重新梳理自己的思路；为了把操作写清楚，我不得不重新检查每一步；为了让别人看懂，我也再次完成了一次自我理解和优化。

同时，这也是我第一次使用飞书进行完整写作。把自己与ChatGPT协作的过程整理出来，像是对大脑做了一次系统清理，收获比单纯得到一份结果更大。

这次使用的提示词，主要参考了手册中的案例，所以文章完成后，我没有保留太多内容。真正留下来的，是一套新的思考方式：

不要期待自己一开始就会写出完美提示词；

先把模糊想法说出来；

让AI帮助拆解目标；

再通过调研、测试、分阶段执行和持续优化，逐步得到结果。
