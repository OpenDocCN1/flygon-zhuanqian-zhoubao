## 我亲历的辅助编程演进线

### 2019年 代码补全与代码检索

那时候的基础形态是补全加搜索。

补全：体验上偶尔会比 IDEA 自带的更顺手。

搜索：丢一个关键词进去，能在 GitHub、Stack Overflow 等地方扒出相关片段和讨论。

### 2021 年 6 月 GitHub Copilot 技术预览

GitHub 与 OpenAI 联合推出的编程搭档，通过机器学习模型给开发者实时出代码建议，提升效率。

底层模型：OpenAI 当时面向编程的专用模型 Codex。

### 2022 年 11 月 ChatGPT 浪潮

技术主线转向 LLM。代码补全和对话开始都靠大语言模型驱动，工具井喷。

### 2024年中 成熟爆发期

出现了价位、速度、能力三者兼顾的甜点模型：Claude 3.5 Sonnet，正好推了 Agent 和 Flow 的落地。

综合处理复杂任务，目前最强的仍是 OpenAI 的 o1，只是慢，比如要思考一分钟才一次性把结果吐出来，而不是逐字逐句流式输出。

举例来说，让 AI 直接写单元测试，出来的东西基本不可用。拆成两步会好很多：先设计测试思路，再写测试代码。

再延伸一下，为何很多 AI 商业化项目始终上不了线：顶级模型太贵，能扛复杂任务；弱一点的模型得把任务切得很碎才能完成。切得越碎，通用性就越差。

## AI 辅助编程的四种形态

### Copilot 副驾 / 高级代码补全

* 定义：基于上下文实时补全和提示代码的工具
* 代表：GitHub Copilot
* 特点：
* 根据当前上下文即时给出代码建议
* 原生嵌入 IDE
* 聚焦在代码层面的微操作
* 使用场景：
* 代码补全
* 根据注释生成方法
* 根据方法生成注释
* 新增类属性后同步更新构造方法
* 产品差异点：
* 是否会主动给出提示
* 提示的响应速度
* 上下文理解能力差异。比如提到端口，它能否理解为 IOPort
* 支持单行改还是多行改。多行改的例子：
* 是否具备光标预测。预测你下一个光标落点，方便无缝跳转
* 提示出现的时机。比如能否在新行末尾补全，能否在行中任意位置插入

补充：
GPT 系列基于 Transformer，自回归生成，擅长根据前文推导后文续写，架构上不天然支持“完形填空”。完形填空的效果，更多看各家的工程化能力。

### AI Chat 对话式助手

* 定义：用自然语言对话来解决编程问题的工具
* 代表：ChatGPT、Claude
* 特点：
* 自然语言交互
* 能解释代码和概念
* 给出更宽泛的编程建议
* 使用场景：
* 各种编程问题的对话
* 代码解读与调试
* 架构设计讨论
* 产品差异点：
* 是否支持语音交互
* 自动上下文感知能力。根据鼠标位置、当前文件、历史浏览、工作区等收集上下文
* 是否支持指定上下文。案例：
* 是否支持图像输入。点击聊天下方的图像按钮或拖入图片，把视觉信息带入对话。比如给一张网页截图让它实现
* 是否可联网提问。从互联网获取最新信息并据此回答
* 是否可引用文档。引用流行库，或用 @Docs 添加自有库
* 是否能一键落码。例如 ChatGPT 网页版生成后需手动复制，部分工具可在 Chat 框内以 Git Diff 方式预览修改并一键应用或拒绝

### AI Agent 智能代理

* 定义：具备一定自主决策能力的 AI 助手，是 Chat 的增强版
* 代表：Cursor agent
* 特点：
* 能主动执行任务
* 理解项目级上下文
* 具备工具调用能力
* 使用场景：
* 根据需求自建一个小产品或小工具，自选语言、设计排版、建文件、写代码
* 写文档、建立多文件的小型知识库

### AI Flow 工作流

* 定义：把 AI 能力嵌入到开发工作流里
* 代表：Windsurf、Devin
* 特点：
* 更强的上下文感知
* 多工具协同
* 自动化工作流
* 更像是人来辅助 AI，AI 执行任务遇到需要人工确认或操作时，会主动询问人类

# 大模型能力盘点

* 最强的推理模型 o1
* 代码能力最强 Claude 3.5 Sonnet
* 多模态输入最强 Gemini flash 2.0
* 生产环境性价比最高 现在是 gpt-4o-mini
* 最强开源模型可能是 qwen 2.5 72B，至少中文英文表现如此，但仍有差距。国内一线顶尖模型基本也在 qwen 72B 这个水平，包括阿里自家的 qwen-max
* 国内基础模型、高性价比模型、推理模型都还需要继续迭代
* 国产之光 DeepSeek 便宜、能力在线，AI 界的拼多多
* VS Code 的 cline 插件 + DeepSeek，据说体验还能看，差距主要在能力上限和流畅度
* kimi：国产总结能力最强
* 秘塔：智能搜索+知识库，可用来交叉验证 AI 幻觉，像中国的 Perplexity AI
