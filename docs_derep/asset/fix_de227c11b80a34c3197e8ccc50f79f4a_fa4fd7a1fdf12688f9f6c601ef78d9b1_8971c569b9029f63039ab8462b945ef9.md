# 一、先把海报生成的需求拆清楚

先回顾一下上期做的页面原型：

[PRE0]

从这个原型能拆出用户需要提供的三项输入：

1、节气名称
2、画面描述要求
3、风格偏好，这里先只做一种，后续方便扩展

考虑到后续要在「我的」里展示历史记录，最终要返回给页面的结果有三部分：

1、一张完整的海报图
2、对应的节气名称
3、生成的具体时间

为了让工作流的思路更清晰，先看下我最终跑出来的效果：

[PRE1]

对照效果，我规划的工作流执行顺序如下：

1、结合节气名称和画面描述，生成可用的图像提示词
2、基于节气名称生成一段配套的诗词文案
3、把诗词文案和节气名称渲染到背景图上，完成合成

整体逻辑并不复杂，重点在于让工作流和页面能够顺畅对话。下面正式进入搭建。
