# 一、市场摸底

### 1. 这个盘子有多大

- 用户体量：国内第三方输入法坐拥约7.83亿用户（数据来自36氪，2023年）。
- 商业规模：动态皮肤及桌面宠物类产品，一年可产生3亿至5亿元的营收（Statista，2022年）。
- 上升势头：动态皮肤用户的付费比例正以每年12%的速度递增；桌宠类皮肤已占全部皮肤下载量的15%。

### 2. 为什么说此刻进场正当时

行业正处于转型节点，2025年有几股力量值得盯紧：

1. 技术侧：
- AR眼镜放量：苹果Vision Pro、华为VR Glass合计出货量预计突破2000万台，3D桌宠需求将被点燃；
- 确权机制：平台或会引入NFT，桌宠顺势升级为用户的数字资产，衍生出二手流转交易。

2. 竞争侧：
- 微信输入法、抖音输入工具等大厂产品陆续下场，桌宠形态需要适配弹幕互动等更多场景。

3. 用户侧：
- 社交货币属性增强，大家愿意为“绝版/限量款桌宠”付出更高预算。

# 二、第一条变现路：上架官方商城，赚搜索流量与长尾分成

#### 申请流程

1. 投递：做好桌宠后，发至官方邮箱等待审核，通常耗时2-5个工作日。
2. 上架：通过后入驻皮肤商店，用户即可下载使用。
3. 迭代：根据用户反馈持续优化，例如增加互动特效。

#### 收入模型

- 分成比例：创作者可分得用户付费金额的30%-50%，按作品热度浮动。
- 真实案例：
- 爆款IP联名（如“阴阳师”）：单款收入可达10万元，但个人玩家基本够不着；
- 普通款皮肤：单款1万次下载、单价2元时，创作者到手约6000-10000元。

# 2. 动手制作

## 2.1 先搞懂设计规范

### 皮肤规范要点

- 手机端皮肤由候选栏、拼音区、云候选区、键盘大背景、9键键盘、26键键盘、弹泡等模块拼合而成。功能键上的前景文字支持自定义贴图，但中英切换、分隔符、大小写切换键只能改字体和颜色；字母键文字不能贴图，同样只能调整字体与颜色。
- PC端皮肤涵盖四种模式的输入框和状态栏。两者都支持PNG图片；注意标注好的尺寸，可适度微调；背景图最好选纯色或预留可拉伸区域；输入框、状态栏上的主体形象不宜过大，否则会干扰输入。

# 六、项目的长板与短板

优势：
- 底层逻辑和红包封面、表情包项目几乎同源，但竞争烈度远低于这两者；
- 制作门槛不高，新手也能上手；
- 市场盘面大、受众基数广；
- 天然适合定制化。
短板：
- 收入的天花板偏低。
