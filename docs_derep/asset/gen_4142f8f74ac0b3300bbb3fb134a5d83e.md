# 先来个自我介绍

嗨，我是大卫。生财是个新人，但在互联网圈子里已经摸爬滚打很多年了。北漂十年，待过百度、京东物流这些大厂，干过产品和市场运营，年轻时还做过百度 BU 里最年轻的 P7。去年我从北京落回合肥，自己从无到有搭起了一家猎头团队。公司体量不大，但完全是我跨界摸索出来的成果。今天把这段经历拆开讲，希望对想入行的朋友有参考价值。

# 猎头到底是什么

通俗讲就是高端人力资源的撮合中介。企业有高端人才的需求，自己一家家去找效率太低，而且招人招完岗位就关，积累就浪费了。于是就出现了猎头这个角色，替企业去市场里定向挖掘人才，让同行业多家公司都能 pick。

说到底，猎头的工作内核仍是销售，是把岗位这边的需求和候选人那边的供给连起来的信息连接工作。

# 为什么我会选择猎头这条路

*   先说个人缘分。我在互联网待了这么多年，和各路猎头打交道很多，其中不少成了朋友，我的太太本身也是猎头，后来被我挖了过来。
*   猎头这个赛道很抗周期。人力的需求永远会转移，某个行业会下坡，另一个行业就会起来。只要经济在运转，就永远有新的上升行业需要人，所以职业天花板不高。
*   做人力等于提前读懂行业风向。哪行景气哪行冷，基本能在我们做行业公司调研、做交付难易度上最先感知到。比如过去互联网红火，后来无人驾驶火过，接着半导体成了香饽饽，那段日子金主手里有钱，人合适了还主动加薪；反过来有些行业或公司明显不行，职位要求明明写好了，面试临门就各种推脱、加新条件，摆明了不想成单。

# 猎头的工作拆解

猎头的核心是做两端的信息撮合，一边是企业用人方，一边是候选人求职者。

[PRE1]
先聊企业端。

## 岗位从哪来

传统猎头公司里会有一支 BD 团队做行业研究，主动去拜访企业、挖掘招聘需求，也就是找职位。流程听起来挺重，后面我会讲个人怎么绕开这部分成本。

## 候选人怎么找

最基础的是把职位挂出去，从主动投递的简历里筛。大家都能理解。

高端人才还有个更专业的动作叫寻访。按照企业给的画像，定向去找人，甚至可以点名要挖哪家公司的哪类人才，这是猎头和普通招聘的最大区别。

# 个人如何快速切入

上面那套是公司的打法，单干的人不用非得先进公司。

## 先找单

现在市面上有很多平台汇聚了企业的招聘需求，个人猎头可以直接接单做交付，比如猎上网、禾蛙、智乐聘等，不同平台赛道和佣金制度各有侧重，各自取舍就行。

## 再找人

*   招聘型渠道：BOSS 直聘、前程无忧这类平台挂职位，热岗能收到大量主动投递。我当年在百度、京东时发岗，基本靠主动简历就能填满池子，也从中切身体会到竞争有多激烈。
*   社交型渠道：脉脉、领英这种职场社交，以及现在的小红书等，都能用来做被动寻访和人脉触达。

# 做起来要注意哪些细节

*   先把需求读懂。岗位背后的行业所处阶段、企业在这个时间点开这个岗的真实动机，是补人还是新业务，是能力难找还是预算有问题，这些直接决定你这个单的难度和匹配策略。

[PRE5]

*   候选人全程陪跑。确定了合适人选后，要持续沟通，解答对岗位和公司的疑问，评估意向，帮他做面试准备，比如直属领导的风格、关键 Decision Maker 的关注点，确保能顺利走到终面。
*   最后一公里是薪资博弈。需要给候选人做谈薪辅导，同时在企业和候选人之间做平衡和协调。
*   交付之外还有回款节奏、回款方式等运营问题，时间允许可以再展开讲。
*   当下 SOHO 猎头很常见。有些人原本在公司里就是年成交百万级别的头部猎头，出来单干接平台单，在自由度提升的同时收入也不错。

整体框架大概就是这样，细节想聊可以再细聊。我现在主营的方向已经跑通稳定，精力出来后也在探索新赛道，有搞钱思路欢迎交流。
