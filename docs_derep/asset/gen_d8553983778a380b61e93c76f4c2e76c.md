在 Midjourney 的创作世界里，纵横比决定了画面最终的“骨架”与视觉结构。分辨率上升时，部分宽高比例可能会发生细微变化。开始之前，先把各类模型支持的纵横比范围看清楚，心里有数。[PRE0] 想要直观看懂纵横比，一张示意图就足够了。[PRE1] 实际操作也很简单：在描述词末尾加上相应后缀，例如 `--ar 2:3` 即可生效。[PRE2]

接着聊聊 chaos 参数，它控制的是初始图像网格的变异强度。数值拉得越高，结果往往越出人意料，构图也更天马行空；数值偏低时，出图则更稳定、更可控。默认情况下 chaos 的取值为 0，可设定范围是 0 到 100。比如 `--chao 24`，输入“西瓜猫头鹰杂合”这类描述，就能感受到它的作用。低 chaos 数值下的表现为：[PRE3][PRE4]；高 chaos 数值下的表现为：[PRE5][PRE6]；而当 chaos 调高到极端值时：[PRE7][PRE8]。使用方法很简单，`--chaos` 和缩写 `--c` 皆可。[PRE9]

关于质量参数 q 值，它直接决定了出图所投入的计算时间。质量调高，耗时更久，细节也更丰富，同时会增加 GPU 算力消耗；但质量设置不会影响分辨率本身。别以为高品质就一定是最好的，有时候为了适配特定画面，低质量反而能带来惊喜。比如追求手绘的抽象感时，低质量可能更合适；而建筑类的表现，往往高品质能够呈现更多结构与纹理细节。建议多试试不同的档位，找到最适合的组合。v4 版本的木森林测试效果可见：[PRE10][PRE11]；v5 版本的牡丹花测试效果可见：[PRE12]；不同模型与参数兼容性的测试结果参考：[PRE13]。使用方式有两个：其一，直接在聊天框里加后缀，比如 `--q 0.25`、`--q 0.5`、`--q 1`、`--q 2`。[PRE14] 其二，用 `/settings` 设置默认为 Half、Base 或 High quality。[PRE15][PRE16]

关于种子参数，Midjourney 会用一个随机数值生成类似电视雪花般的视觉噪声场，作为出图的起始点。这个种子号可以自定义，通过 `--seed` 或 `--sameseed` 指定。当提示词和种子号完全相同时，生成的图像往往是相似的。seed 可填写的整数范围是 0 到 4294967295，且种子值只影响初始生成的网格。需要注意的是，v1、v2、v3、test 和 testp 版本存在随机性，只能生成相似但不完全相同的图；而 v4、v5 与 niji 模型在提示词、种子和参数固定的时候，可以完全重写出一样的画面。看下面这个例子：“青瓷猫头鹰水罐”。如果保持随机种子，即使其他条件不变，三次生成的结果也会截然不同：[PRE17][PRE18]。如果要固定画面，只需把 seed 设为定值，比如 `--seed 123`，在 v4、v5 和 niji 模型下，无论重复多少次，图像都会一模一样：[PRE19]。sameseed 与 seed 的差异在于，seed 只影响网格中第一张图的出生，而 sameseed 会让四张图全部统一遵循同一个起点。sameseed 同样取值 0 到 4294967295，但只兼容 v1、v2、v3、test 和 testp 模型。固定 sameseed 前后的对比如下：[PRE20]；固定 seed 前后的对比如下：[PRE21]。想要寻找某个图片对应的种子值，只需要在目标图片上添加一个✉表情反应即可，操作细节可参照前文 4.4.4 章节。[PRE22] 在聊天框中输入 `--seed 12345` 就可以直接套用这个种子。[PRE23]

stop 参数的用途很直白——它允许你提前终止生图过程，用百分比来控制工作停止的节点。设定值越靠前，图像往往越模糊、细节越少。stop 的默认值是 100，可调整范围是 10 到 100。但这个参数只对初始生成过程有效，放大阶段不会响应它。举个例子：“橡子飞溅艺术画”。基础用法效果展示：[PRE24][PRE25]。进阶玩法是：即便放大时 stop 不再生效，但如果初始图像停止在更柔和、更不精细的状态，最终放大结果的细节程度也会受影响。这里展示的是使用 Beta Upscale 的效果：[PRE26]。具体使用方式，同样是在聊天框加后缀，比如 `--stop 90`。[PRE27]

风格参数 stylize（或缩写 s）决定了 Midjourney Bot 在艺术性方面的训练强度。数值低时，画面紧紧贴合你的文字描述，但艺术感较弱；数值越高，画面越富有艺术表现力，却可能偏离提示词本身。不同模型对于 stylize 的默认值和可调范围各有不同，具体可以看这里：[PRE28]。在 v4 模型上的效果，以“无花果插图”为例：[PRE29][PRE30]；在 v5 模型上的效果，以“无花果的彩色等线图”为例：[PRE31]。使用方式也有两种，一是直接在聊天框加后缀，如 `--s 1000`：[PRE32]；二是通过 `/settings` 设定默认风格，比如 Style low、Style med、Style high 或 Style very high：[PRE33][PRE34]。

tile 平铺参数生成的图像能够作为重复瓷砖使用，常用于制作无缝织物、壁纸或纹理图案。tile 在 v1、v2、v3 和 v5 模型中均可使用，每次只生成一张独立贴图。想要得到多张拼贴在一起的完整效果，可以借助 pycheung 等人的在线工具：[链接](https://www.pycheung.com/checker/)。来看在 test 和 testp 模型上的表现，彩色虎纹与破碎的纸板玫瑰：[PRE35]。在 v5 模型上，苔藓涂鸦与水彩锦鲤的效果如下：[PRE36]。使用时，只需在描述词后加上 `--tile`：[PRE37]。

版本参数可以通过 `--v` 或 `--version` 来指定模型。Midjourney 会不断迭代模型以提升出图的效率、一致性和整体质量。默认情况下会使用最新版本——但测试版除外，比如虽然 v5 已发布，理论上目前主流仍是 v4。每个模型各有长处，word 中选择 `--v 5` 就能切换新模型。不同模型间的对比，已经在 3.1 章节中详细展示过。具体操作：在聊天框后缀中加入 `--v` 参数并跟上编号，例如 `--v 4`。[PRE38]

video 参数允许你保存生成四张初始图像的进度短视频。操作方式同样是通过添加✉️表情来触发，它会同步生成并发送视频。注意，这只适用于初始生成阶段，无法记录放大过程；并且目前只有 v1、v2、v3、test 和 testp 这几个模型支持。举例来说，“充满活力的加州花”和“奇异蕨类植物素描”的视频效果都非常不错：[PRE39][PRE40]。具体获取流程为：第一步给描述词末尾加上 `--video`；第二步等待图像生成结束；第三步在目标图上添加信封反应（操作同 4.4.4 章节）；[PRE41] 之后就能拿到下载链接了。[PRE42]

再往前走一步，进阶图生图可以说是创作中极其好用的玩法。你可以把图像当作提示词的一部分，用它来引导画面的结构、风格或配色。图像提示可以单独使用，也可以与文本描述混合，甚至可以把不同风格的图片组合在一起，获得意想不到的效果。更高级的玩法，还能叠加多个图像 URL、多段文本以及多个参数。基础操作流程是：先上传一张图片，然后在 prompt 输入框出现后，把上传好的图像拖拽进聊天框，系统会自动生成对应图片链接；你可以同时添加多张参考图。接着在链接后面继续写描述词和参数，确认后发送即可开始生成。[PRE44]

比如在 v4 和 v5 模型下，图生图的表现各有千秋。这些新模型会把图像当作生图的起点，因此结构、配色和构图上都更贴近参考素材——但有时候也会显得有些刻板，各有利弊。以下面这些基础素材为例：阿波罗雕像、复古花卉插图、恩斯特·海克尔的水母与地衣、北斋的《巨浪》。[PRE45] 在 v4 模式下尝试雕像与花、水母的组合：[PRE46]；雕像配苔藓、雕像配波浪：[PRE47]；甚至雕像加苔藓再加花的叠加：[PRE48]。切到 v5 模式后，同样的组合呈现出更细腻的质感：[PRE49][PRE50][PRE51]。

而在更早期 v3 模型中，图生图更偏向抽象精神，图像更多是视觉灵感参考，并非严格的出发点。这里便涉及“图像权重”的概念。权重越高，参考图对成图的影响力也越大。`--iw` 专门用于调节这一权重。早期的 Midjourney 版本就用它来控制图像 URL 的强度，默认值是 0.25，可变范围从 -10000 到 10000；数值越大，参考图的存在感越强。举个例子，当你输入“图像链接 + vibrant California poppies --v 3 --iw <数值>”时，iw 数值的不同会呈现完全不同的风格。左上角是上传的参考图，右侧是不同权重下的生成结果：[PRE52]。另一组向日葵测试也类似，左上角仍然为参考原图：[PRE53]。

最后是 Remix 修图参数。启用 Remix 后，用户可以随时更改提示词、参数、模型版本等，它会借助初始图像的整体组成，作为新 Job 的一部分继续演化。这在改变光影、变换环境或重塑主题时特别有效。Remix 目前是实验性功能，未来可能被调整或移除，但目前可以正常使用。打开方式一：直接在聊天框调用 `/prefer remix`；[PRE54] 方式二：在 `/settings` 中找到 Remix mode 并点击开启，变绿后就意味着成功启用。[PRE55][PRE56] 启用后，涉及 V1 到 V4 以及 Make Variations 操作时，系统都会先弹出文本框，允许你基于原有描述进行调整修改。
