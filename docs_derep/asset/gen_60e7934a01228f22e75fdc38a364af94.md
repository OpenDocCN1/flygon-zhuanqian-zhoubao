## 先摸清客户要什么

客户是肖像美学馆，给消费者拍形象照、写真和视频。他们最初的诉求很简单：要一个能对外展示作品的窗口，让更多人看到以往拍摄成果，也给门店增加一个流量入口。顾客能浏览作品、了解品牌和门店、提交预约，之后还能查看自己的预约和订单。门店端则需要一个管理后台，用来发布作品、管理分类、查看客户资料、处理预约和订单。

复杂点在渠道佣金。客户有很多合作渠道，靠他们介绍客户。以前要搞清一个顾客是谁带来的、该结算多少佣金，只能靠微信沟通和表格。我们的方案是给每个渠道生成专属小程序码，用户扫了谁的码就归到谁的名下。之后顾客到店消费，总部在后台录入金额和时间，系统按预设比例自动算佣金。渠道方打开小程序，就能看到自己带来了多少用户、产生了多少消费、累计多少佣金。钱不走线上，没有在线支付，也没做自动打款和提现，核心只是把账记清楚，让总部和渠道看同一份数据。

需求不少，但我没有马上做页面，而是先把业务抽象成三条流程：

- 顾客侧：看作品 → 看详情 → 提交预约 → 查看结果。
- 门店侧：发布作品 → 看预约 → 联系顾客 → 录入消费 → 查看各渠道带来的用户与佣金。
- 渠道侧：用专属码推广 → 查看名下用户、消费和佣金。

三条流程能跑通，小程序就有价值。在线支付、自动打款、复杂排班、会员积分都可以往后放。14天交付的项目，先做最重要的事。真正让项目变快的，不只是AI写代码快，更关键的是在前面就把做什么、不做什么讲清楚了。

## 需求对齐和基础建设

[PRE4]

第一次完整需求沟通是在腾讯会议上进行的，42分钟就确认了范围，形成必做功能清单。我和客户逐项过了一遍：哪些功能首版必须上，哪些以后再加，哪些这次不做。最终首期锁定作品展示、简单预约、渠道绑定、消费记录、佣金计算和后台处理。

客户不需要准备技术材料。她要做的只有三件事：把需求讲清楚、把展示素材准备好、配合第三方完成域名和小程序备案。页面最终怎么呈现，也由她确认。域名注册、备案这些事，花几百元交给第三方代办，客户只需要提供资料，就不会被手续卡住进度。隐私协议可以请AI配合模板起草，再根据小程序实际采集的数据、用到的权限和业务流程逐项核对修改。域名、配置和上线相关事项由我负责。我买好了阿里云的基础服务器和OSS，注册了域名，也让第三方开始备案，与开发同步推进，前后约一周。

实际费用如下：阿里云基础服务器199元/年，OSS约170多元/年，域名85元/年，第三方备案代办约200元/次，微信年审300元/年。客户只关注业务，不需要研究备案和审核知识，这正是项目能快速推进的原因之一。需求会议结束后，我让ChatGPT参考客户提供的对标界面，生成了第一版4个入口页面设计，后续的UI实现也基本贴近设计稿。

## 10天时间线

先说明一下：这条时间线按项目提交记录和阶段整理，实际开发中页面、后台、服务器、备案和素材准备是高度交叉的，不是每天只做一件事。小程序备案和域名备案，从项目启动那天就交给第三方同步办理了。

**第1～2天：搭骨架，建数据关系。** 因为有前两个内部项目的积累，我直接迁移了现有架构，同时设计数据库和接口。用户、渠道、作品、预约、消费记录、佣金，都要想清楚怎么存、怎么关联。不能只盯着页面，因为渠道方要看到名下的用户和佣金，总部要录入消费，关系不理顺，后面会疯狂返工。

## AI在其中做了什么

我没有把整个项目一句话丢给AI。先是把需求和边界确认清楚，然后把大任务拆成明确的小任务，逐个交给AI。页面设计也直接从需求出发：告诉ChatGPT客户要展示什么、用户如何浏览，让它先生成第一版设计稿，再交给Claude Code继续实现，用微信开发者工具反复预览调整。后来在更复杂的项目里，我总结出一套Codex + Figma MCP流程：先让Codex通过Figma MCP在Figma里完成第一版设计，不满意就继续调，直到确认后再让Codex读取设计稿，完成代码实现。

[PRE17]

图片上传用的是阿里云OSS，存放位置、访问地址、上传权限都需要配套配置。遇到报错，我把报错信息和相关代码一起交给AI分析。作品列表、详情、点赞、收藏这类相似功能，AI可以先生成重复部分，我再按真实使用场景检查修改。AI还帮我整理了测试用例：登录、预约、订单、图片上传，都要用真实流程走一遍。比如用户换了手机，点赞和收藏还在不在？图片上传失败，页面有没有提示？预约提交后，门店能否马上看到？

不过有几件事AI替代不了：客户到底要解决什么问题？首期上线做哪些功能？哪些功能可以暂缓？顾客资料谁可以看？做到什么程度才算完成？这些必须由我和客户一起拍板。AI能帮我们把决定写成程序，但不能替我们做决定。

## 最后几天的检查重点

最后阶段的重心是验收和上线准备，很多事依然并行。我测试时只盯一件事：分别站在顾客、店员、渠道方的视角，把完整流程走通。

客户准备素材和我搭建页面同步进行。我先根据作品展示需求把管理页面做出来，客户只要上传图片素材，小程序里就能看到对应内容，不需要学复杂的后台操作。客户需要准备品牌Logo、介绍文案、作品分类、官方样片、客片和渠道名单。名单里要有联系人和佣金比例。素材不必等全部备齐再开工，客户交一部分，我就接一部分；管理页面一旦就绪，客户自己上传，前端立即展示。

**客户素材与页面同步搭建**

不等素材全部到齐，边整理边搭后台与前台，客户传一部分，我接一部分，上传后即可看到样片和客片。
