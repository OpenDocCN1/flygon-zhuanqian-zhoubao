# 裸辞半年试了三条路，我靠视频号电商做到单日GMV 3w+

三月份的时候，我正式告别了互联网大厂，成为一名裸辞的自由职业者。这半年里，我碰过短剧CPS、试过小红书无货源，也做了视频号带货，最终在视频号电商这条路上跑出了单日GMV 3w+的成绩。

说不辛苦是假的。虽然没有颠沛流离，但确实经历过很多个失眠的夜晚。如今回头看去，我不敢说已经站稳脚跟，但至少找到了一个值得继续深耕的方向。作为一个视频号新手，我的做法很简单：边做边调、持续迭代。详细心得整理在了飞书文档里，感兴趣的圈友可以直接点开看看：https://vxqm3o3stzd.feishu.cn/wiki/Kl0jw32x8i6uA9kgxbmc9DzWnce?from=from_copylink

趁着这个机会，我也把评论区里大家常问的问题统一作答一下：

短剧CPS到底行不行？我在4月份试过一段时间，没做起来。每天就是对着各种素材混剪，剪到后来脑子实在难受，就放弃了。

小红书无货源呢？当初我也心动过，可外面课程动不动要五千多学费，实在有点贵。如果想低成本试试，建议等航海的时候参与一次，看看自己是不是真的适合。

还有圈友提到国内短剧政策，没错，现在这块限制和打压比较多，入场要谨慎。

关于视频号直播的模式：我是不露脸的，直接让摄像头对着商品，不过手要保持动作，不然容易被判定违规。开通小店后就不再要求千粉了，办个体户执照后，一个执照最多可以开5家小店，门槛真的不高。
