# 一、为什么现在才开始刷 POST？

在拓跋勇拉的那个群里，他亲口说，自己发一条大概耗时 2 到 3 分钟。听到这话我就彻底安心开始铺量，本来还准备等跑出数据再观望。

如今付费广告成本高得离谱，而 POST 完全不花钱，又没多少玩家在抢，属于一块小众红利。

卖家在站内能操作的招数太稀缺：早年间流行的评论人玩法早就下线，免费给样品的路子也被堵死，Vine 昂贵还难拉到人，逼得大家只能往广告里猛撒钱。

其实我很早就认为，Amazon 应当把发视频的入口交给卖家。淘系平台和拼团电商都被抖音、快手逼到改版，按这个势头，Amazon 早晚要吃 TikTok 的亏。

# 二、POST 是什么来头？

Amazon POST 是去年上线的测试功能，仅面向美国站拥有正常运转店面的品牌备案卖家。现在不收钱，但前提是店铺已开好，商品链接也已经传上去。

依靠海量产品图换取站内自然曝光，这个玩法我早就听说过。之所以始终没试，一是上班时公司不重视，既没开店也没有素材；二是后来组团队，预算与时间都排不开。眼下我相对有余力，认知也补齐了，这才能够把大量发布真正执行起来。

# 五、图片资源去哪里搞

是不是漏讲了一块：成百上千张图，总不能凭空变出来吧？

其实你没必要专门去影棚实拍，也不用把产品图磨得很精细，只要找到同类型的应用场景和对应受众即可。

按我在《蓝海产品方法论》里的人群标签，可以围绕老师、货运司机、医护人员、宝妈宝爸这些群体去想。

顾小北那篇《Amazon如何巧用post，让新店0-1》也让我开窍。这个玩法和潮汕牛肉丸的抖音策略本质相同：批量堆内容，哪里有免费曝光就往哪里挂商品购买入口，受众越准越好。

最初我考虑过定时推送，算来算去太折腾，倒不如用最朴素的延时方案。你在脚本里会看到我把等待间隔设成了 200000 毫秒，也就是 2 分钟。

# 六、几条重要的要求

Amazon POST 对图片的规格有硬性要求：

- 尺寸：640 x 320 px 或以上
- 宽高比：1:2 至 2:1
- 格式：JPG 或 PNG
- 色彩模式：RGB

另要注意，不要在画面里加文字。

动手之前最好把 Amazon 官方关于 POST 的规则从头到尾读一遍。
