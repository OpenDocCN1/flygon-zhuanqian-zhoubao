# 原视频拆解

①、先从抖音扒素材，我用IDM下载，追求的就是所见即所得

[PRE3]

②、素材导入剪映，建议充个会员，镜头智能分割、文本导出、超清导出、变老这些功能挺好用

[PRE4]

我们要提取三样东西

1、口播稿：把语音转文字
2、纯人像镜头
3、产品特写切片

③、人像抠出，建议逐个镜头处理，剪映里镜头一跳就容易报错

[PRE5]

④、换脸处理，记得把高清模式打开

[PRE6]

# 文本转音频

①、先把口播稿过一遍洗稿，最近被新说唱洗脑，我让GPT改写成短句带押韵

②、找一个自己喜欢的声线大模型，最好是熟悉的腔调

[PRE7]

③、挑一段有感觉的音频当语气参考

④、把模型和参考语气导入，输入自己要的文案

[PRE8]

⑤、再把自己的声音文件导入，用声音转声音模式去套④的音频，最终效果就是：你的声音，用她的情绪说你的文案

[PRE9]

# 生成最终口播视频

①、把抠好的人像视频和音轨放回剪映，需要换背景就换

对口型是关键，听着音频手动对齐，一个技巧是把手指举起的动作卡在关键词上，感觉会很到位

②、根据 MuseTalk 的特性，建议用短片段小步快跑

哪段口型不对就单独重跑

剪映里的“按时间区域导出视频”可以用来切段

[PRE10]

③、先用几秒音频做测试，看嘴型张合够不够

不够就调参数

之后配合 PRA 分段投喂，晚上丢任务跑通宵，第二天就有素材

[PRE11]

④、所有片段回炉剪映，叠超清、加字幕、加变老特效，再把火车头和产品切片拼接起来，一个带货视频就完成了

[PRE12]
