# 同一个项目，两种身份：从船员到教练，我重新理解了视频号带货

你有没有想过，同样一件事，站在不同位置去看，感受能差出十万八千里？

我算是亲身体验了一把。去年12月，我以教练身份带了一期数字人视频号带货航海；而再往前，5月和7月，我是视频号口播航海的普通船员。同一个方向，两种角色，收获完全不一样。今天想跟你聊聊这两次“航海”带给我的真实感悟。

先说说这一期的成绩单：近1000名船员参与，上岸率79.65%，变现率21.56%，爆款率22.79%。跟我5月份那次口播航海比，上岸率接近98%，但当时保证金是1000到2000元，这次只要200元。门槛低了，反而更能看出谁是真心想干的——说实话，逼自己一把，真的很管用。

第一次参加航海时，我拿到手册的第一反应是：这手册也太好了吧！每一步该怎么做、路上有哪些坑，写得明明白白，照着抄就行。但同时我也慌：手册这么长，光通读一遍就得两三个小时，真要做起来，100个小时可能都不够。我当时心里直打鼓：这项目真能跑出结果吗？赚钱也太难了。

等自己真正上手做，才发现手册里写的坑只是冰山一角，现实里的突发情况要多得多。能把手册完整执行下来，只能说刚摸到门，离真正跑通还差着一段路。比如剪映里抠像到底怎么抠？开播时该说点什么？这些问题刚起步时我全是一头雾水。只能自己找剪辑教程补课，跑到视频号广场蹲别人直播，把话术抄下来再改，一点一点磨，全是额外的功夫。

等到12月自己当教练，要写手册了。一开始觉得：核心环节就那么几个，能写啥？可真动笔才发现，可写的东西太多了。每个核心环节下面全是小环节，小环节下面还埋着各种坑。就拿混剪带货视频来说，无非是把数字人口播和商品视频剪到一块，看着简单，可你得让画面和声音对上，处理字幕，搞画中画，做去重，还得自己找商品素材。每个小细节都要亲手做一遍才懂。更别提素材或文案触发违规这种意外，真的不轻松。

生财对航海手册的打磨也特别较真。这次对接的内容开发是瓜斯老师，他不仅逐字逐句把关，确保小白也能看懂，还真的自己上手实操验证，比如开通原创功能，他就是按手册里的步骤一步步试出来的。受他启发，我也开始全局思考：先梳理大纲和核心环节，再拆解小环节，最后把常见问题、容易踩的坑都附上。尽量把动作细化到最小颗粒度，做成那种“傻瓜式”的自助手册，能上视频就不用图片，能截图就不用文字。说实话，我报过不少知识付费课，能把项目手册做到这么细的，真不多见。

所以新朋友看到这么长的手册，真不用怕，也别急。把它当成一路上的执行地图，一步步来。别人几个月甚至几年的经验沉淀，怎么可能几天就全装进脑子？慢慢啃，日拱一卒，总能往前走。

再聊聊航海本身。大家的目标其实一样：让更多人赚到更多钱。但做成一个项目太难了，环节多、坑也多，还得看当下市场阶段。这次航海有个大变化：手册提前开放了。很多人拿到就能先动起来，也确实有人早早得了先手。当年我做船员时，想快也快不了，不知道该干嘛，只能乖乖按准备指引去弄设备和账号。这次提前开放，方向一下就清楚了，还能顺便判断这项目适不适合自己——不行就换艘船呗。

而当教练时，我更多在想：怎么帮大家拿结果？我的思路是，能替大家多做一点，就多做一点。动作越少，越不容易走样，成功率越高。所以我反复审视每个流程，看还有什么能提前准备的。比如开通原创功能的口播素材，我干脆写好几份爆款短文案文档，大家直接拿去用；用即创做数字人需要投放广告，我既做了铲子教程，又让大家直接进我的组织创作；高佣供应链也备好了，还是次日结算，给人底气。这次除了手册，前后还弄了6个在线文档，萌虎老师都说头一回见航海需要这么多文档。不过大家有共识：只要对结果有利，麻烦点也值得。我还有个理想化的目标：如果一个项目拆成100个动作，一开始船员只要做1个动作，其他我全准备好；等拿到正反馈、有了信心，再慢慢加到2个、3个。听起来有点理想，但我觉得值得朝这个方向努力。

航海有两个群：交流群用来提问答疑，禁言群专门发重要信息。视频号是个信息孤岛，没有第三方工具查爆款数据，一个人找素材特别费时间。所以一方面我在禁言群轮播正在爆的素材，另一方面也建议官方开一个视频号细分赛道风向标板块。这里特别感谢孟总团队的素材和供应链支持。

交流群的教练们真的给力，船员问题基本都是秒回，几分钟内肯定有人接。我自己5月份当船员那会儿，特别怕提问，怕问题太小白丢人，也怕没人理卡住进度。后来有船员私聊我说同样的话：群里有大神，不敢问。其实真没必要，大家起点不一样，资源也不一样，别跟别人比，跟昨天的自己比就好。微信群还沉淀了大量一线实战资料，比如看视频每分钟流速的小工具，这些都是最新最鲜的实战反馈。我当船员的时候，会把所有聊天记录翻一遍，看别人遇到什么问题、教练怎么答的、有没有新工具新玩法。手册写得再细，也没法实时更新，但市场一直在变，一群人走，总比一个人走更容易赢。这次当教练，我也觉得很多回答很有价值，就建议把群聊内容记录下来开放给大家，后来这个建议也被采纳了。

说到心力、坚持和正反馈，这三件事其实是连在一起的。有了正反馈，人才愿意坚持；坚持久了，才可能等到正反馈；要是两边都没有，就只能靠强大的心力硬撑。以前我连续三个月日更公众号爆文，总有人问怎么做到的？我说，当你确定今天花一小时写文章能赚千八百的时候，你也能坚持。这就是确定性的力量。所以这次手册里特意加了情绪和激励的部分，把之前百人实战里没变现的人的共性原因拿出来分析，方便大家对照着修正自己。跑通项目的人各有各的高招，没跑通的人，原因却大多相似——甚至不止这个项目，很多项目都一样。归根结底，就是执行力不够，或者今天做了明天就想看到结果。

最后说说为什么我觉得生财航海是入门项目的最佳路径。第一，项目靠谱。选项目是第一步，选错方向就是白跑。生财会做考核筛选和内部立项，不是随便什么项目都能拿来航海，一定是当下普通人相对容易变现的。这也是为什么航海项目一直在换——有的越来越难，有的正是红利期。对小白来说，选项目比做项目更难，所以如果你不知道做什么，随便上一个航海，都是相对靠谱的选择。第二，手册详细。我报过很多课，生财的手册真是最细的，有术也有道，底层逻辑、市场分析、手把手操作全都有。我的闲鱼二手书、公众号爆文、视频号带货，全是从航海手册里选的。专业内容开发老师反复打磨，从小白和老师不同角度雕琢，还亲自实操测试，这些人身经百战，最后呈现的自然全是干货。第三，教练答疑到位。毫不夸张，生财教练的答疑比外面很多付费课程还积极专业。教练都是官方筛选过的，在一线实战，拿的是最新一手信息。而且生财的共创体系让教练的付出和回报直接挂钩——大家是一个团队，目标是一起变现，自然更用心。航海期间可以不限次数提问，平时你去私聊一个大佬，人家哪有时间事无巨细给你解答？顶多客气几句。第四，试错成本低。没有项目适合所有人，也没有人适合所有项目，你不需要跑通每一个，十个里跑通一两个再放大，就足够了。但公域里那些招生的人，动不动就P图吹嘘，项目本身就不行，做不出结果还打击自信。生财航海免费，只收保证金，还有一群人同行，互相鼓励。做成一个项目很难，但当你看到身边有人做成了，就是最大的激励——至少证明这条路走得通。出结果的群会互相带动，形成正向循环。

感谢生财这片土壤，也感谢一路同行的圈友战友。2025年，风来了，该扬帆了。
