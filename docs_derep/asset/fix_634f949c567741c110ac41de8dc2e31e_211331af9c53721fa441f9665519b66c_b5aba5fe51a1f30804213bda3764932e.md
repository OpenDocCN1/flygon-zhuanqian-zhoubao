# 承载与防封

自动化公转私跳微信，承载主体通常为抖音号与微信两端。

所有防封措施必须同步兼顾两端，否则任一端出问题均会导致转化路径中断。

## 抖音端防封

抖音转化通道主要为人工转发或接口（含官方产品及官方接口），风险最高的是前者。

1. 提升账号安全，减少私信频率，用群互动替代一对一人工私信
2. 提升账号安全，人工转发抖音卡片等动作由小号承担
3. 提升域名安全，使用白名单域名替代第三方域名，否则会不定期出现安全提示，影响转化

[PRE24]

解决方案：借助抖链转换工具，将目标地址转为抖音域名网址，如 https://v.douyin.com/XXX

最高级别防护：
1. 认证蓝V/半蓝（推荐，因不影响昵称）
2. 若有矩阵号，使用员工号
3. 通过进阶玩法生成卡片与自动回复，避免人工限制

防封建议：
1. 确保小程序具备一定自然流量，避免全部为跳转来源
2. 页面内容不建议直接放小程序码，改用跳转至公众号文章或第三方小程序展示
3. 让服务商为自己开通独立小程序，不要共用，一旦他人项目出问题，你的跳转也会受影响；同时用注册工具多备几个小程序，一个出问题即可立刻切换
4. 购买小程序或跳转服务时，与服务商沟通清楚：若小程序出问题是否负责更新，以及后续更新费用

最高级别防护：
