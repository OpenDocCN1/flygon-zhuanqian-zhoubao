# 二、我的AI绘画怎么一路磕磕绊绊过来的

其实一开始我压根没想做宠物。我中间换了好几个方向，这个号在航海前就开了，坑踩得不少。下面按时间把转折讲清楚，每个节点都有当时的判断和复盘。

## 1.1 起点：婚纱照

5月初在生财看到有人用AI做定制头像变现，AI+宝宝、AI+头像这类分享很多。我没急着冲，只是记下了。

恰好那阵子在拍婚纱照，选图时刷到一条AI+婚纱照的笔记，泡泡玛特风格，赞藏挺高，评论都在问怎么做。博主还是个素人，不是婚纱机构。

我搜了下AI婚纱，发现基本是空白区。所以把图发给未婚妻问：要是我们婚纱照做成这样，你愿意付费吗？大概多少钱？

她回：效果不错的话一张一两百可以接受。

于是我决定先试婚纱照，除了这个反馈，还有4个判断：

（1）客单价高且刚需。结婚是大事儿，女生付费意愿强。婚纱套系几千上万，再加一两百做AI图放迎宾或视频里不贵。年轻人追新，规模起来会很快。
（2）市场体量大。每年700万对新人*100元客单*20%渗透率，保守也有1.4亿规模。
（3）窗口期。AI头像定制门槛低，本质是时间差。绘图工具普及后，一年后可能人人一键生成，定制需求会消失。
（4）源图质量。Midjourney对底图要求高，婚纱照成片质量高，理应出图更好。但后面我判断错了。

定好方向后我就开号了，笔记定位婚纱照+女生头像。

## 1.2 信心受挫，卡在几个点上

小红书号直接开更，没养号。5月14号发第一篇，头像和婚纱发了一周左右，数据惨淡，曝光基本在100上下。

第一篇后期反而半个月后慢慢涨赞，说明内容本身没问题，是账号权重问题。复盘发现起步踩了几个坑：

[PRE5]

（1）没养号。号没热身就发，推荐权重低。第一篇前七天曝光不到200，之后持续涨，典型权重问题。
（2）没蹭热点也没抄热题。520那波我没提前发。小红书是复刻机制，别人验证过的选题再发大概率也能吃到流量，我当时太随性，起号慢。
（3）Midjourney多人物精度不行，这是放弃婚纱最致命的原因。一开始以为婚纱图会更好，其实双人绘画体验很差，女生好男生崩，表情怪，越调越丑。用自己的图试了多遍都不满意。SD也问过大佬，当前模型单人强多人弱。PS：只有双美男美女时成功率会高点，一方普通就容易崩。
（4）发布时间晚。基本10点到12点发，流程慢，下班回家才出图写文案。应该选用户空闲时段。

这里也印证一句话：没人跑通的模式，大概率有坑。几亿人里凭什么就你想到？

## 1.3 转向AI绘画+猫猫

婚纱技术不成熟，头像赛道已红海。我观察身边和刷到的内容发现AI+猫咪图数据也不错，自己家刚好养猫，未婚妻爱猫，后续想把号交给她运营，于是定下AI+猫咪。

当时几个核心判断：

（1）中国宠物市场足够大

[PRE6]

（2）铆主宠溺，付费意愿强。AI宝宝能做，AI猫咪一样能做。未婚妻把猫当儿子养，进进口猫粮都不眨眼。单身年轻群体把猫当精神寄托。
（3）粉丝价值高，变现方式多。网上流传消费力排序：女人>孩子>老人>狗>男人。养猫的大多是高净值女性，抓住了女人+宠物两个点。即使不做前端变现，涨粉后接广告也有价值。

[PRE7]

实际粉丝画像男女比2:8，高价值女粉为主，验证了猜想。
（4）自养猫增加信任度。家里本身有宠物，后续变现更顺。外部条件好，但不养猫的不建议入场。未来若出现稳定宠物换脸，虚拟宠物博主会很猛。
（5）宠物号易出效果。AI前就有大号，AI后可玩性被放大。猫坐地铁、猫送外卖、猫搬砖，这些在AI前看不到，灵感不缺。配合ChatGPT工作流，10分钟能出1篇。

### （1）坑1：评论没及时回，没引导互动

第一篇没及时回，权重上不去。评论别回哈哈谢谢，要用疑问句引发对线，5分钟内回效果最好。第四篇吸取教训，评论互动做起来了，曝光反而超过第一篇。

### （2）坑2：涨粉路径不对

路径：笔记里引导看主页，顺势引流到下一条。

个人介绍：改成“每日分享猫猫的奇幻冒险”，简介更短，加素质三连。

### （3）坑3：有流量没变现

变现想得晚。后续做了：介绍栏写业务，置顶案例，热度期内发客单展示效果。改晚了，私信才慢慢多。

其实还有几条路：神图君取图、引流到群/公众号/网盘、卖猫咪制作课。

### （4）没做多平台分发

只做小红书，后来才知道微博抖音也有转发。爆了的内容一定要一鱼多吃。
