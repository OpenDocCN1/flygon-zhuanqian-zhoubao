说到底，市场从来不缺活得滋润却完全不卷的案例。

就拿我们合作的琉璃瓦供货商来说吧，日常就是人字拖配宝马车，去趟仓库，几通电话就把发货和进货的事儿全敲定了。抖音、视频号这些新渠道，他压根就没碰过，照样日子过得安稳，因为订单已经吃饱了。

所以回头看，对于一个刚起步的新人而言，哪怕你玩转了更新的传播方式，依然会有人愿意把生意分给你做。

# 总结：

1. 做对标研究时要往深里挖，浅尝辄止的观察很容易误导判断；
2. 在评估同行玩法时，必须对照自身现状，挑出当下阶段真正能复刻的打法；
3. 抖音的底层逻辑大约是七成靠选题，两成靠呈现，一成靠运气；
4. 平台的放大效应会让优质内容迅速被看见、被推起。
