# 陪诊这门生意，到底能怎么赚钱？

大家好，我是静水，生财有术第四期圈友。深耕陪诊行业已经快一年了，眼下这份职业热度越来越高，身边也有不少圈友开始感兴趣。借这个机会，我把这一年里实操下来，以及对行业观察到的陪诊变现路径，整理出来供大家参考。

这篇分享主要想做到三件事：

第一，给刚想入行的朋友一些视角上的启发和决策参考；
第二，广州是华南的医疗枢纽，我把过去一年跑遍各大医院的实战经验打包出来，方便在广州看病的朋友少走弯路。详细资料我放在了附件里；
第三，遇到挂号难、号源紧张的情况，其实有几种可以尝试的解决办法，我也会一并说清楚。
