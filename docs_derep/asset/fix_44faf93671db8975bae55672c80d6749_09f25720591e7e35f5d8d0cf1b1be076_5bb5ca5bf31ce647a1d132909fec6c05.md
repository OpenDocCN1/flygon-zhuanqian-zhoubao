# 十天从零到变现六千多，场观破万，我到底做了哪几件事

来源：https://fgsd3oxjki.feishu.cn/docx/Lg2vd5GWHoqhBbxuT5LcThEpncb

大家好，我是姚麻。许久没在生财认认真真写复盘了，最近刚结束多多视频的项目，便把重心挪到视频号来测试。想法萌芽于15号，17号首条内容上线，截止27号晚，累计佣金6201元，单条最高播放310万，直播首秀场观也突破一万。

趁着今天发什么都没动静、直播间也无人问津，正好收到上船通知，就把这十天踩过的坑和走通的路梳理一下。先致谢一下李诚老师，上一期航海我没随队，但老师依旧耐心解答了大量细节，感激之情记下了，等结算到账一定重谢。

一、起步做了什么

15号产生意向时，我刚结束手头的多多账号，正犹豫下一步测哪个赛道：短视频平台、AI绘画导流、书单号、闲鱼都在考虑范围。那天我母亲跟我说她在直播间买了个锅，我先入为主以为是抖音，问清楚竟是视频号。我妈这批用户都已经从抖音往这块走，我自然也跟上做了尝试。

先花了两天把生财航海手册里关于该平台的资料通读一遍，把商业闭环想通。总体理解是：内容带动主页下单、内容挂车、直播成交、导流私域成交。效率最高的是挂车，但需要一千粉门槛，且挂车内容的自然曝光普遍不佳。导流私域操作重，对小白不友好。于是我的路径定了下来：靠发片抓曝光，靠开播做转化。

选择这个平台有三点理由。第一，起号阶段有扶持流量，对冷启动很关键。第二，用户结构偏成熟、下沉，相对抖音、快手更少被信息轰炸，消费决策更直接，客单也更可观。第三，我此前服务阿胶和多多时积累的用户画像正好是中老年群体，这算个人优势。

选品和找参考号这块其实很顺手，直接复用此前多多时期沉淀的品类和账号池，稍微筛选后便确定。

选品思路是先定人群再找痛点。目标人群标签是中老年+下沉。痛点集中在健康、焕发活力，所以运动康复类与保养类更容易契合。选品前我会先去抖音、快手、拼多多看热度，再回到站内检查同类内容饱和度。两端都极度拥挤的直接放弃，完全没人做的也不碰，那不是蓝海，只是没人做的死海。衣物、零食等泛需求不是不能做，但属于普适性需求，不够聚焦，优先级靠后。

我最终锁定3个方向：1个运动、2个偏保养的美妆。

找参考号我习惯去快手，操作很笨但有效：搜品名，挑真人出镜的账号进主页看细节。关注粉丝规模、视频总量、是否长期聚焦固定品、画面是否干净、时长、是否存在生活类内容、是否持续更新。粉丝5万以内、视频200条以上、垂直带固定品、画面素净、有少量非带货内容且保持更新的，会进入观察清单。明显混剪搬运或反复裁剪实拍的直接剔除。

素材加工是固定流程：裁切、翻转、换底音、加字。纯音乐无解说的换首更抓耳的底乐，有解说缺音乐的补一层背景音，有解说也有音乐的做微调速1.1~1.2倍。字幕全部重新识别，原字幕遮挡处理。最后加一句抓人文字，围绕功效、场景、情绪写，放在显眼位置。多多时期子浅就提醒过，转化有时靠的不是视频本身，而是字幕上的钩子。举例卖拖把，可以写“惹老伴生气被罚拖地，还好有这把”，或“退休太闲每天打扫，多亏儿子买的这款”。也可以直接写使用效果。这种二次加工也解释了为何要选画面干净的源素材，花哨的源素材不好二次创作。

17号下午首发，三条账号都在当晚破万，其中一条直冲3万+。睡前补发一条，依旧破万，印证了新号扶持的存在。发布节奏我控制在两三小时一条，同时完成实名和橱窗挂链。

真正逼我开播的是出现一次14万播放零成交。内容在跑却没引导，于是先在简介埋橱窗关键词，又在评论区自补引导语，仍无转化。群里经验是破万就播，我便尝试了。

第一次直播和想象差距很大，两小时里场观只在一百出头，全程无人互动，无样品，手持另一部手机念商品页。尽管只卖出1单，但佣金让我惊讶，单价29.9抽12元，接近五成。以前多多视频20%就心满意足，这里利润确实厚。下播后猛灌三杯750ml的水，口干到不行，但0到1通了。

回看原因，缺话术缺样品。视频号站内找不到同品类直播，我去抖音看，连续观察两小时，两个风格迥异的主播，一个手机看直播、一个手机录音、电脑打字记录要点。回来筛选改写，变成自己的口播。样品也下单了。

第三天直播，停留时长明显提升，首小时卖出6单。之后分段播，播一小时休一会，全天播了5小时，合计20单。身体扛不住持续输出。

期间出现过一次橱窗与直播被封一天，提示无意义直播。至今没完全搞清是中途离镜还是缺样品展示，之后未再出现。另外两个账号尝试开播，视频未跑的情况下场观只有十几人，很快明白直播流量必须由内容带进来，无播放不进人。

之后十天动作高度重复：发片、查播放、有跑的开播、无单或无流下播。循环到27号，主账号当晚播三个半小时，场观1.1万，成交200多单，佣金近三千。

其他账号情况：一个换品换内容后基本废掉，删重发最高播放300+，准备再观察两天无起色就注销，保证金不要了。另一个坚持老品，该品在我多多时期曾爆过，最近出现80万和30万播放的小爆发，转化一般，合计佣金700多，仍在观察。另新开两号做内容形式测试，一号用抖音热门语录替换BGM加字，一号用跳广场舞素人账号先做纯内容后混带货。思路是用内容换稳定流量，精准度不足就靠量补。目前8条内容下午统计全部破万，但后续变现待验证。

流量券方面，新人成长计划会送加热额度，完成新手任务送100点，相当于100元。第一次直播次日有专属限时任务，错过就没了，我主号因封禁错过，至今耿耿于怀。我自己测试过100点投观众、500点投点击、下单，单次加热期间几乎无转化。最好的情况是500点投点击带来1300场观。投完后配合发福袋，关注与互动明显提升。经验是攒到500再用，配合福袋能把场观稳定在较高水平，我那天就从投放后熬到场观过万。

未解的问题两个：

第一，人脸认证。三个开播账号基本每次开播都要扫脸，连刚关闭不久再开也要重新验证。只有日播的主账号近期偶尔免掉了。想问下这是机制演进还是偶发？若使用他人实名微信，人脸验证是否每次都要本人到场，若扫完脸后是否可由他人播？

第二，商品上架。主号带的是爱逛的链接，优选联盟里找不到该品，听说下月第三方链接要停用，该如何承接？想测的其他品在优选联盟也找不到，微店有但要交3万保证金，成本过高。

十天摸到一点门槛，也踩了不少坑，后续有新进展再来更新。
