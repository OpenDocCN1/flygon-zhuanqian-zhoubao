# 用 7 颗龙珠换 150 分钟，我把创业卡点全摊给亦仁了

> 原文：[`www.yuque.com/for_lazy/zhoubao/ntrua3mlsrth2tpu`](https://www.yuque.com/for_lazy/zhoubao/ntrua3mlsrth2tpu)

大家好，我是书豪，一个在龙珠圈里一直琢磨怎么把利润做高的玩家，也是运营着小红书店铺和直播航海的教练。

11 月 7 号，我拿出 7 颗龙珠，约到亦仁做了一场深度商业对谈，全程 150 分钟。

掏钱买认知，本质上是买视野。这次聊主要有两个诉求：一是解决当下创业的卡点，找点能落地的增长抓手；二是希望少走弯路，借个更高维度的商业视角。

刚好是我创业第五年，到杭州创业满两年的节点。

**一、现有生意怎么破千万**

亦仁说，我现在做的两条线，小红书店铺搞标品卷店群，还有抖音短剧 CPS，都是红利期项目。

方向确实赚钱，但本质是信息差，门槛低，生命周期短，天花板看得见。卷的越久越难做。

我也承认，这两项生意团队扩不起来，利润很难倍增，收入波动大，体感上很难爽性翻倍。

亦仁给的方向很清晰：往 付费投放 + 私域 + IP + 非标品 + 复购 + 高客单 这个组合去靠拢。

标品赛道会越卷越死，无货源电商的上限本就有限。要真正冲破千万，就得去普通人轻易进不来的赛道。

付费投放是拿资金换位置，非标品是拿稀缺换壁垒。

**二、创业粉知识付费能不能做**

我问创业类知识付费算不算好赛道。

亦仁的判断很直接：不算顶级。赛道体量小、玩家太拥挤，而且结果太显性，交付难度高。

反观身心灵、家庭教育这类赛道，结果偏隐性，用户更愿意为长期陪伴付费，容错空间更大。

**三、关于投资**

投资这块比较私密，涉及个人情况，我就不展开了。

只说一句话亦仁点醒我：投资极度反人性，比创业还要难走。

**四、团队管理是隐形门槛**

我问怎么理解管理优势。

亦仁说，十人以内的团队谈不上管理优势，真正有感觉是带过二三十人规模之后。

团队规模上去，管理能力就是创业者需要交的学费。生财有术每年光人力成本就两三千万，这笔钱是用来建壁垒的。

**五、为什么生财要涨价**

我从 2020 年不到两千块入的生财，现在涨到 3365 元。问他大环境这么难，为什么还要涨。

他说价格就是客户画像。苹果也是这个逻辑。

生财的内容、航海、风向标、线下聚会、超级标等一整套服务体系在升级，价值在涨，价格自然要跟上。未来只会更贵。

很多人觉得生财门票便宜，其实是还没看清服务层级在提高。价格本身也是一道筛选机制，客户越高端，交付越顺畅。

**六、私董会要报遍吗**

我最近报了几个私董会，想问是否要把市面上的都走一遍。

亦仁说没必要。他基本都体验过，报私董会对他来说是去做产品体验，保持信息开放。

但真正好复制的蓝海生意，没人会在公开场合说。尤其是他提到的那种 付费投放 + 非标品 + 高客单 + 复购 + IP 的模式，本质是闷声发财，没人会主动暴露。

**七、焦虑和壁垒**

我问他会不会焦虑，会怕有人复制出第二个生财吗。

他说不焦虑。想复制生财，先准备好 1000 万启动资金。

能轻松拿出 1000 万现金的人，本身就有自己的主业，很少会再拿这么多钱去从零搭建一个社区。生财的内容沉淀、体系化运营、以及他在圈内的 IP 信任度，都是复制不了的。

**八、给我的个人复盘**

亦仁说，这个阶段他走过。你现在能白手起家 30 岁前攒下几百万，在中国已经是头部少数了，先稳住情绪，再冲 1000 万。

保持现有现金流的前提下，去找一个具备 付费投放 + 私域 + 高客单 + 复购 的生意组合，这是他见过大部分千万级案例的共性公式。

别总做从 0 到 1 的短线项目，要找能深耕三年的赛道，天花板必须够高。小红书店铺、抖音短剧 CPS、创业知识付费，这些都不够高。

格局要再打开，钱往往三年后才开始爆发。赚大钱拼的不是操作细节，是趋势判断。你能解决的行业问题越大，能赚的钱越多。

他最后说，你愿意花 7 颗龙珠来做一次深度咨询，这件事本身就很珍贵，也许就是你商业新天花板的起点。

聊完我问他值不值。

值，太值了，绕过的弯路比 7 颗龙珠贵多了。

我找亦仁，是因为身边的人赚得跟我差不多，给不了我想听的答案。找一个十倍于自己的对话者，帮我跳出自己的窄视野，看见更大的世界，这个钱必须花。

和亦仁的交流远不止这些公开部分，很多是私人化的就不对外了。唯一深的体会是，一个人的格局和修养，真的远比想象中重要。这次深度对话下来，亦仁比我预想的更平和、更清晰。

感谢亦仁。
