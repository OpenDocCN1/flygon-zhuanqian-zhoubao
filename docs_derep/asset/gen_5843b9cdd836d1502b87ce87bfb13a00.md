# 高价服务老被退款？换个思路，退费率能降一大截

做知识付费和私域的人，几乎都遇到过这种场景：

客户/学员付了钱，过几天跑来说“这个课程跟我预想的不一样”。有的是直接要求退款，还有的只是反复说“课程好像没啥用”，其实心里就等着你主动提出退钱。

你我都清楚，他们绕来绕去，最终目的就是拿回那笔钱。可问题在于，他们不说破，我们也不点破，结果两双眼睛干瞪眼，气氛很微妙。尤其是高客单产品，一旦闹到这一步，损失的往往不只是几千上万块，还可能赔上口碑。

我入行两年多，跟明白老师、陈雪一起做俱乐部，会员净增长和复购率一直都比较稳。正是因为见过太多“退款异议”的拉扯，我总结出了一些自己的处理心得。这些经验不一定能平息所有人的火气，但确实能帮高客单产品把退费率实打实地压下去。
