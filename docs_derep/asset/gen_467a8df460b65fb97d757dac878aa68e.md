# 图文采集教程 iOS 版

整体思路很简单：用 iPhone 快捷指令去调用 Coze API 触发工作流，核心参数就是 Coze 的 token 和 workflowid。

第一步 Coze 工作流会先把 App 的短链还原成长链，或直接接收长链，然后去请求小红书接口。
第二步 把返回的数据通过 JavaScript 脚本整合成 JSON 保存变量，再调用飞书表格 API 写入。
第三步 飞书表格接口需要先授权，并填上表格的 base 路径和表格 id。
第四步 我分享的模板会自动把图片链接转成附件，并展示封面。
第五步 基于分享的模板，标题和文案会自动走 DeepSeek 生成新内容。

最终体验就是在苹果手机上点开小红书笔记链接，一键同步到飞书多维表格。教程刚成型，后续还能拓展，比如直接拆解爆款视频、爆款图文做二创，结合对比生成词云等，持续完善中。

## DeepSeek 数据分析用法

1. 用电脑浏览器打开 DeepSeek 官网 [`www.deepseek.com/`](https://www.deepseek.com)
2. 点击「开始对话」，未登录会自动跳转注册。注意先注册才能用。

[PRE46]

3. 登录后会进入对话窗口

[PRE47]

4. 打开飞书多维表格，点击右上角「...」，选择「导出」- Excel/CSV 文件

[PRE48]

5. 默认 CSV，点击「下载」

[PRE49]

6. 下载后重命名为 one.csv，方便上传

[PRE50]

7. 在 DeepSeek 对话框点击「大头针」图标上传 one.csv

[PRE51]

[PRE52]

8. 把下方提示词复制到对话框发送，DeepSeek 会自动分析笔记

**提示词模板：↓↓↓**

根据 one.csv 文件是小红书笔记内容，请分析出笔记的内容结构、标题公式、情感分析、关键词，标签分布、智能打标签、笔记内容结构。

1.标题公式：根据笔记标题划分笔记类型，分析标题特点和结构，最好能总结出公式、常用的关键词

2.情感分析：哪些关键词或内容能调动用户情绪、吸引用户

3.关键词体系：关键词类型、关键词出现次数、关键词在标题、笔记内容中出现频率

4.笔记标签：标签类型、统计重要标签

5.笔记内容结构：分析内容的结构内容并统计归类，优缺点等

6.根据数据详细说说：用户核心需求、内容优化建议等

7.分析完内容后，统计你分析的数据和结论，写十个标题、写十遍笔记内容、写十个标签。
