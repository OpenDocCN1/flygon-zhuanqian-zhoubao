## 第4步：开启沟通并提高通过率

找到招聘中的公司后就主动私信，等待对方回复。

沟通时礼貌是第一位。我们投递时发现很多人因为细节翻车：打招呼没礼貌、提问随意、简历缺照、简历空白、简历与岗位不匹配等。

先规避这些雷区，回复率会提升不少。BOSS上的HR不是人人都会回，保持平常心就好，能有15%的回复率就已经算优秀。

一旦对方对你简历感兴趣，就会加你微信沟通试稿。试稿一般是免费的，前期用来考察质量，部分公司会付费，大部分是无偿的。

一个提升回复的话术框架：礼貌开场 + 精简自我介绍 + 感谢收尾

投递时可直接用这套话术：
您好，看到贵司在招兼职写手。我本科毕业，目前做自由撰稿，之前做过短视频脚本、口播稿、头条号、公众号商业文案，文字功底还算扎实。

当然也会有试稿失败的情况。失败通常只有两种原因：稿子不符合要求，或者同批试稿里有人更合适。别放弃，保持礼貌争取下次机会即可。

# 三、实操中容易踩的坑

1. 甲方拖款跑路
实操至今遇到两家公司到结算期失联。这种情况直接在BOSS上举报该账号即可。

2. 账号被风控锁定
不要频繁切换IP登录，也不要在聊天里大量出现“论文代写”“发微信”等敏感词。联系方式的交换统一走平台自带的“交换微信”功能。

3. 反复被要求修改
定制型文案被退回修改很常见。解决方法就是审题。把甲方需求逐条梳理清楚，不确定的点提前沟通，能大幅减少返工。

# 四、AI代写实战方法

熟练掌握AI的指令逻辑，选择合适的模型，学会调参和提问，就能把产出质量和效率拉满。这里以GPT-3.5为例演示，也可以换其他工具。

1. 准备好ChatGPT账号
星球里已有大量关于ChatGPT注册和使用的教程，有需要的圈友可自行查阅。

访问官网 https://www.openai.com/
没有账号点注册，按提示填写信息即可；已有账号直接登录。

2. 常用指令模板：角色设定 + 标题 + 关键词 + 大纲 + 客户要求 + 改稿

设定角色：让模型扮演特定身份
标题：明确写什么类型、什么主题，没标题就把需求大白话丢进去让它总结
关键词：客户要求的关键词先列出，让模型围绕这些词展开
大纲：先出骨架，再写肉身，逻辑更清晰
客户要求：把甲方的点整理成指令，先扩量再精修
改稿：分轮次改，每轮聚焦一个点，比如结构、资料补充、风格统一、金句植入、错别字检查

AI本质是语言工具，文案不能直接搬运，要人工润色口语化。

指令细化技巧
例如客户只要说“希望文章阅读量高”，这就是模糊需求。要自己把需求翻译成可执行的指令：去搜索同类自媒体招商号的爆款逻辑，标题吸睛、场景有趣、有真实案例、有实操方法等，再喂给模型。

工具推荐
BestPrompts 是一个指令参考库，遇到陌生领域可以直接借用。
注册地址：https://bestprompts.cn/#/index

3. 实操演示思路

示例流程：
角色设定：你是一位叫小明的内容创作者，擅长各类型文章写作，善于和ChatGPT协作。
标题：未来科技：人工智能与人类共生之道

改稿：第一轮调结构、第二轮补案例、第三轮改风格、最后一轮精修错别字和金句

指令模板通用：【设定角色+文章标题+关键词+大纲+客户要求+改稿】
