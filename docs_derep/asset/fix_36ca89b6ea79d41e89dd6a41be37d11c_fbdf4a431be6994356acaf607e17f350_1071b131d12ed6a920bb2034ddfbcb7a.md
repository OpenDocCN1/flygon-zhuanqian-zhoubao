# 从三人起步到首个一百万元：我的两年半拆解笔记

> 来源：[https://mv61xmj001b.feishu.cn/docx/WBsWdTm7uoOXICxiHDncFMdDnvb](https://mv61xmj001b.feishu.cn/docx/WBsWdTm7uoOXICxiHDncFMdDnvb)

各位好，我是苗子，一名一直在创业路上试错的人。

今天想把【三个人如何拿到第一笔一百万元】这件事摊开来讲。就是我从零到一搭建互联网起盘的完整过程，也是对自己的一次粗暴复盘。很有分量，对我自己也很重要。

有时候我们总是一头扎进往前冲，偶尔回头看一看已经走过的路，看看途中的风景，也能让内心沉淀下来，得到一点警醒。

先交代一下我的经历脉络：

2015年步入社会。
2016年和朋友一起做装修业务，到2018年9月退出。
2019年开始接触并全职投入互联网，一直做到现在。

和圈里不少人比起来，我的创业轨迹并不刺激，没有大起大落。用两个词形容：平淡，普通。

入行到现在，就换过两类赛道，线下与线上，但这两条线涵盖的内容非常广。

算下来，我在网创行业摸爬滚打约四年，真正产生现金流的是后三年。而第一笔一百万元，我整整花了两年半才实现。第一年基本零收入，第二年才开始有回款。

接下来是我从19年至今的复盘，也是这几年来我踩出来的一些做法。希望对准备入局的朋友有参考，也让老玩家能想起当年艰难起步的模样。

# 2019年：互联网元年，零收入却最值钱

[PRE0]

当年网创圈子还很野，各种离谱项目满天飞。养龙养猫养狗养猪能赚钱，卷轴模式层出不穷，稍不注意时间金钱就打水漂。

我当时很迷惘，不知道该信谁、该做啥。于是选择一个笨办法：找标杆。我花了两天多时间，在各大平台上搜人、筛人、去重，有些IP背后其实是同一批人运营，最后锁定十位相对靠谱的互联网创业者。

## 锁定这十位后，我正式开启网络创业。

[PRE1]

1，找博主。
2，没公众号的一律取关。
3，加个人微信，保持关注。
4，看付费社群。
5，给自己定个付费上限，然后无脑冲。

这一年我累计进了十多个付费群，其中不乏踩坑的。坑不在于项目造假，而在于进去后服务几乎为零。

第一波十个社群，花掉我大概四千块。

插一句，我对付费的态度一直是认同的。这不是因为现在做培训才这么说，以前做线下装修时，我也常去参加装企培训班、总裁班。

借枭哥一句玩笑：赚钱是为了进入更高阶的圈子，再用圈子里的资源赚更多钱，再用更多钱进入更上一层的圈子。听上去像段子，其实就是现实规则。想把盘子做大，最快的方式就是花钱买认知，跟高手同行。

我加入社群有两个目标：

1，第一时间捕捉行业实时动向。
2，第一时间对标和模仿前辈的操作方式。

到现在我依然保持一个习惯：遇到厉害的大佬，就去扒他的打法。信息很透明，抖音快手小红书、知乎微博全搜一遍，再看公众号。还不够的话，就去一些资源站搜他的课程，从头到尾过一遍。这才算真正拆干净。至于要不要跟进，看情况。

能抄的就抄，抄不了就换下一个。最差也能当成谈资：我有个朋友一年五千万，朋友嘛，自己体会。

2019年我真的没赚到什么钱。最开心的事是带了一个闲鱼项目，卖九块九，一下午收了一千多，把我乐坏了。其他时间基本在吃老本、攒资源、盯同行。

因为我的初衷从来就不是做一个快钱项目，而是想组建自己的小工作室，最终成为一个小老板。

## 为达成这个目标，2019年我具体做了什么？

[PRE2]

一共五点，我一直在做。做完这一年，我收获了：

1，和十几个社群群主都保持不错关系，比如战劲、王一书、九京，到现在偶尔还交流。
2，随手能写一两千字文章的能力，后来帮上大忙。
3，任何项目研究几小时就能看懂底层逻辑，非高壁垒项目都行。
4，跑一个项目一周左右基本能判断成败。
5，能给别人提供价值的能力。
6，获得曾经仰望的大佬的认可，可以同频交流。
7，链接到各行各业的资源。
8，积累了首批私域：两千五百多个微信好友，公众号近四千粉。

还有眼界、模式、风口嗅觉，这些是用钱买不来的，只能时间沉淀。

总结一句，后来能赚钱，靠的就是2019年一整年的积累。

# 2020年：第二年，关键词是花钱

[PRE3]

同样，第二年核心也是支出。现在回头看，我特别感谢自己当时砸的两笔钱，它们让我后来能和一群前辈并肩走。

前年没收入，今年不能再靠老本。攒了一年，该变现了。2020年的目标我给自己定的很直白：空手套白狼。

我和大多数创业者一样，走边赚边花的路线。

我在等一个机会，等了整整八个月。八月初，遇到了合伙人墨羽，机会来了。

和合伙人走到一起很偶然，一个项目聊了两小时电话，我直接买票去找他，第三天就把他“说服”一起创业了。

很多人问我怎么找合伙人，我说看缘分。第二点很关键：想一起做事，必须同地点办公。线上先合作，后面必然矛盾，大概率撑不住。

墨羽当时问能不能线上，我直接拒绝：要么线下，要么各玩各的，以后可以项目合作。我的强势，加上他的敢试，我们才走到一起。

落地后，我们成立了第一个工作室，我的第一支三人小团队成型：我、墨羽、他的妻子。

当时定下的小目标很简单：从八月到年底，六个月赚十万，过年每人分五万。

[PRE4]

我们当时的办公环境：一间次卧，两台电脑，三个人，十几部手机，还买了个泡茶的小玩意。累了就喝茶，聊理想吐槽外卖。

就为这个十万的小目标，我们拼了半年，最后赚了五十万，是目标的五倍。

也是从这里，我们的第一百万元开始起航。

同时第一个线上社群【思维社】成立，第一批招了一百人左右，定价365。用了几天完成首轮招募，也是我第一次切身体会到线上卖信任的快感。

一晚上收入近三万，相当于原定半年目标的三分之一。当晚我们花了两百多吃了一顿小龙虾庆祝，这笔钱成了团队第一笔启动资金。

有了社群就要有项目。当时还在项目带人的阶段，先带成员做豆瓣引流。做着做着就发现问题：引来的人干嘛？九成没有后端变现，大多数是白嫖。

卡在这里时，碰到一个转折项目，也是后来出圈的独家项目。

## 小红书起号卖号

这个项目到现在还在做，只是没以前重了。也正因它，我第一次线下去花钱学项目。

所以2020年的关键词是：线下敢花钱。

前后跑了两个地方，吃喝住学加起来花了七千。出发前就估算到这个数，心疼但还是花了。正是这笔钱，让我们半年能赚到五十万。

收入主要来自三块：

1，社群收费，从365涨到1980。
2，自己做号，手机扩到五十部，每月能起万粉号二三十个，利润好几万。
3，学员出号我们拿差价，每月也有万把块。

能赚到钱靠两点：一是把项目做到极致，二是把后端资源打通。

当时做过一个打卡营，社群两百多人一起做号。统计下来账号总量六千多。一机一号，相当于六千部手机在同时运作。当时主做游戏、动漫、音乐三个赛道，在小红书刷这三个领域，十条视频里至少四到六条是我们出的。

资源方面，我们跑了北京、广州、佛山、济南、南京，对接了六家MCN机构和大量个人博主，才能把账号稳定出手。

那半年循环就是：收人、做号、卖号、接资源。

[PRE5]

2020年这一年我学到的：

1，第一次尝到有壁垒项目带来的甜头。
2，第一次搭起一个小规模的基本盘。
3，再一次感受到社群的力量。
4，第一次意识到人脉资源的重要性。

# 2021年：关键词是团队与模式

到这阶段，说句凡尔赛，我已经不缺项目。

我每天思考的是如何让三人团队效率最大化。

那年的方法论有四个：纯线上、轻资产、自动化、可放大。

模式纯线上：坚决不做重运营自营项目。
投入轻资产：不碰重资金投入。
人员自动化：打磨完整成交体系。
项目可放大：单人可矩阵化作业。

2021年初我其实很焦虑，我清楚2020年五十万里有运气成分。势头虽好，心里悬着。正因为不安，才定下这四条铁律。

我们小心翼翼又干劲十足，到年底完成了九十万的目标。

[PRE6]

2021年主抓两件事。

## 抓团队

我的管理方法只有三点：定时、定量、定人。时间节点、任务量、责任人，对应到个人。称之为最小三人模型，叫增长小组。

这套打法适用很多场景：测项目、跑渠道数据、提升转化率。现在工作室依然在用。

## 抓模式

好模式能省大量人力物力。我的最小模型很简单，但省掉了单独配客服的时间，可以做更多事。

[PRE7]

剩下的就是围绕基本盘：引流、跑数、晒成果。

说个题外话，晒数据。很多人反感晒数据。后来我想明白，晒数据就是展示实力。可以晒收入，也可以晒团队人数、社群规模、公司体量、人脉、甚至车房。只要能证明你强大的，都可以晒。因为这是一个酒香也怕巷子深的时代。

有实力就晒。

今天分享的是我如何赚到第一个一百万元。为什么讲过程而不是拆一个项目？

因为我一直相信：

项目不会永远赚钱，

一直赚钱的永远是我们自己。

两年半赚到一百万元，对大佬来说不算快，但对我们这个小团队已经很满足。因为本事变大、认知变深、视野变开，这才是根。

从21年到23年的模式转变，也是同样的逻辑。
