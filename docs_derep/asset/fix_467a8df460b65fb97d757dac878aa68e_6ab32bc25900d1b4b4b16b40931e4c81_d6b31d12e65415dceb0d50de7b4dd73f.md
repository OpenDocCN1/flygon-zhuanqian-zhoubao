# 苹果手机图文采集配置

整体逻辑：借助快捷指令调用 Coze API 来触发工作流，关键凭证为 Coze 的 token 加上 workflowid。

第一步 Coze 工作流会先把笔记短链解析为长链，或直接接收长链，随后调取小红书接口。
第二步 将回传的数据经 JavaScript 脚本整理为 JSON 并保存变量，再调用飞书表格接口写入。
第三步 飞书表格接口需先完成授权，并填写表格的 base 路径和表格 id。
第四步 我提供的模板会自动把图片链接转为附件并展示封面。
第五步 基于该模板，标题与文案会走 DeepSeek 自动生成。

最终使用感受是：在 iPhone 上打开小红书笔记链接，即可一键同步至飞书多维表格。教程刚上线，后续还能扩展更多场景，例如一键拆解爆款视频、爆款图文做二次创作，并结合对比生成词云等，持续完善。

## DeepSeek 数据分析用法

1. 用电脑浏览器打开 DeepSeek 官网 [`www.deepseek.com/`](https://www.deepseek.com)
2. 点击“开始对话”，未登录会自动跳转注册。注意先注册才能使用。

[PRE46]

3. 登录后进入对话窗口

[PRE47]

4. 打开飞书多维表格，点击右上角“...”，选择“导出”- Excel/CSV 文件

[PRE48]

5. 默认 CSV，点击“下载”

[PRE49]

6. 下载后把文件名改为 one.csv，方便上传

[PRE50]

7. 在 DeepSeek 对话框点击“大头针”图标上传 one.csv

[PRE51]

[PRE52]

8. 将下方提示词复制到对话框发送，DeepSeek 会自动分析笔记

**提示词模板：↓↓↓**

根据 one.csv 文件是小红书笔记内容，请分析出笔记的内容结构、标题公式、情感分析、关键词，标签分布、智能打标签、笔记内容结构。

1.标题公式：根据笔记标题划分笔记类型，分析标题特点和结构，最好能总结出公式、常用的关键词

2.情感分析：哪些关键词或内容能调动用户情绪、吸引用户

3.关键词体系：关键词类型、关键词出现次数、关键词在标题、笔记内容中出现频率

4.笔记标签：标签类型、统计重要标签

5.笔记内容结构：分析内容的结构内容并统计归类，优缺点等

6.根据数据详细说说：用户核心需求、内容优化建议等

7.分析完内容后，统计你分析的数据和结论，写十个标题、写十遍笔记内容、写十个标签。
