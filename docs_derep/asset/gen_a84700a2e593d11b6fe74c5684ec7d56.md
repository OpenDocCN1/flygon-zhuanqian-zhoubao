# 手把手教学：多维表格+Deepseek进阶玩法

## 第一步：脑暴，先有个点子

别急着建表，先想清楚你要做“好玩的”“有流量的”还是“能变现的”。我习惯先用秘塔搜索去挖爆款思路，比如搜小红书、知乎热词，看看年轻人吐槽“玄学测试”的痛点。用秘塔帮我整理玩法和高频词，思路一下子就打开了。

[PRE7]

我摘录了一些感兴趣的关键词：挖宝玄学、祈福水晶、功德电子木鱼、好运壁纸、八字、姻缘、面相、摇签、紫微斗数、甲子易道、神算喵、乾坤爻。最后我选了“挖宝”“水晶”“神算喵”“乾坤爻”四个词来延展方案。

看到“水晶”和“挖宝”，我立刻想到之前很火的玩法：用Deepseek根据出生日期和性别生成运势报告，再推荐黑曜石、海蓝宝、黄水晶等来提升能量。当时还有人说“Deepseek把命理师干失业了，把1688水晶卖断货了”。我决定结合水晶，做一个飞书多维表格测试产品。接下来，我用元宝Deepseek的深度思考+联网功能，让它输出一个方案。

方案出来后，我选了其中可用的内容，人工拼成了《神算水晶喵》方案：一款融合AI技术与玄学创意的轻量化运势产品。用户输入性别和生辰后，系统用DeepSeek定制prompt解析八字五行，从财运、事业、感情三大维度生成2025年运势报告（含暴击月份预警），并根据命理特征推荐一款能量水晶。全程用“神算喵”的毒舌人设输出，把“赛博算命+玄学玩梗”结合起来，满足年轻人对运势探索的娱乐需求，实现从传统占卜到社交裂变的趣味设计。

## 第二步：AI梳理，把天马行空变成工作流

把刚才的发散结果扔回Deepseek，让它提取关键词、变成多维表格工作流：每个流程就是表格的一列，每个节点就是一行。这里水晶相关节点可以简化：我先确定几种水晶样式，用AI生成固定图库，上传到水晶节点，最后让输出端调取，就能保证质量。之所以做信息提取、提示词生成、AI生图这些节点，是为了让大家熟悉字段捷径更多场景。

## 第三步：建表，一步步搭出《神算水晶喵》

建议现在打开多维表格跟我一起操作。

写产品前，先准备好提示词：把前面方案简介改成初稿，例如：“你是一只喵喵，因修成正果得道成仙，现在叫做神算喵……以毒舌人设输出结果。”然后交给“Prompt优解”做优化。这是我目前用过最好用的提示词优化工具，也是字节的产品，在火山引擎上免费使用。

### 设置各列字段

第一列：序号。改标题为“序号”，字段类型选“自动编号”。

[PRE15]

第二列：姓名。双击列标题改成“姓名”，字段类型可以按需调整。

[PRE16]

第三列：性别。标题“性别”，类型选“多选”，添加选项“男生”“女生”。

[PRE18]

第四列：生辰。标题“生辰”，类型选“日期”，格式选带时间的，如2025-01-30 14:00。

[PRE19]

第五列：提示词生成拼接。这是重点：用“公式”字段，点击“编辑公式”。如果你和我一样不擅长公式也没关系，飞书多维表格内置AI生成公式功能，只要用自然语言描述需求，AI会自动转换成可用公式。我输入一个指令，让它把姓名、性别、生辰拼成一句话，再拼上之前优化好的Prompt，整个提示词就在这一列自动生成了。

[PRE21]

具体公式逻辑大概是：CONCATENATE("你将扮演……", "用户名字是：",[姓名], "，用户性别是：",[性别], "，用户生辰是：",TEXT([生辰],"YYYY/MM/DD"), "……具体任务……")。当然，你也可以直接用AI指令生成，不用自己写。

第六列：提示词。新建一列，标题“提示词”，字段类型选“文本”。这一步是为Deepseek提取和后面的提醒工作流做准备。

[PRE23]

第七列：Deepseek。新建列，标题“Deepseek”，在字段捷径里搜索“Deepseek”，选Deepseek R1。配置指令选“提示词”字段，打开输出结果和自动更新，保存配置。这时系统会自动生成“Deepseek输出结果”列。

[PRE25]

第九列：水晶种类提取。新建列，标题“水晶种类提取”，字段捷径选“信息提取”，字段选“Deepseek输出结果”，提取信息输入“仅提取信息中水晶品种”，确定并保存。

[PRE26]

第十列：水晶提示词。新建列，标题“水晶提示词”，字段捷径选Deepseek R1，指令选“水晶种类提取”，自定义要求里写Prompt，打开输出结果和自动更新，保存配置。
