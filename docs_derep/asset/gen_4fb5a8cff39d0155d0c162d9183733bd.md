# 聪明自媒体人，都把时间交给工具去跑

> 来源：[https://uh4tzunhi6.feishu.cn/docx/NlN7d1NWdomGubxhHcNc2jEpnje](https://uh4tzunhi6.feishu.cn/docx/NlN7d1NWdomGubxhHcNc2jEpnje)

这套我实战验证过的省时工具包，基本是我内容工作流的底层操作系统。全部亲测可用，整合起来用，信息抓取和整理效率至少能拉升数十倍，弯道超车的感觉非常明显。

先说视频批量抓取这块，核心选手是【江湖】。小红书、抖音、快手都吃得住，以小红书为例，它的用法我拆开讲，其他平台逻辑一样。

我在文末会集中放出所有工具的获取方式，先看怎么用。

流程很简单：装好软件，跟着教程视频跑一遍就能开干。

[PRE0]

打开后的界面长这样。按教程指引进入【浏览器】模块，登录好小红书账号后，就能自由操作了。看到想拿的账号，直接“捉拿”就行，作品就被批量取出来了。

[PRE1]

[PRE2]

小提示：下载设置里选【普通下载器】就够用了，速度很快，没必要花钱升级。

常用的几个入口我基本就围着转：【主页提取】【单作品提取】【关键词提取】，偶尔会用到【我的主页提取】。下面就按这四个点展开，已经用过的小伙伴可以直接跳过。

## 【主页提取】

把目标作者的小红书链接粘到输入框，点【开始添加主页】即可。机器会自动抓取该作者的作品，我最高一次同时丢进去10个号，一下就读出上千条视频，完全不用手点，心态直接起飞，体力活瞬间没了。

有人会问上千条怎么看？当然要筛，我的做法后面会讲到，是有条件的筛选。

[PRE3]

## 【单作品提取】

名字很直白，就是指定某一个或几个视频来下。设置区可以控制每次取几个，频率别太猛，我一般是每次10个，休息30秒，让机器缓一缓。

下面这个例子是我一次抓5个视频的效果，列表里就已经归位了。

[PRE4]

## 【关键词提取】

按主题去全网搜素材。想找治愈向内容，就输入“治愈视频”等关键词，点击【开始提取关键词】，软件会自动在小红书里检索相关作品。

还能设定时间范围，【发布开始时间】和【发布截止时间】都能限定，精准度很高。

[PRE5]

## 【下载&筛选作品】

### 不做筛选直接下

无论主页提取还是关键词提取，成果都在【作品列表】里。什么条件都不加，直接点【开始下载作品】即可。

[PRE6]

### 加条件先过滤再下

比如我只想要爆款，就在点赞量里填【10000】，并打开【启用筛选显示】。原本抓到的5条里可能只剩1条达标。原本上千条的池子，筛完可能只剩几百条高质量的，效率感拉满。

[PRE7]

#### 如何限定发布时间区间

[PRE8]

也很简单：在【主页提取】里把作者链接加进去后，设定好【发布开始日期】和【发布截止日期】再执行提取即可。

看到这儿，应该能感同身受，以前一件件扒视频太费劲了。接下来还有文案批量提取，也是完全免费的。

# 2. 一次性搞定50条短视频文案

主力工具是通义千问

https://tongyi.aliyun.com/qianwen/ 国内就能用，注册登录即可。

[PRE9]

我现在库里已经攒了245条文案。上家公司老板让我一周内凑100条大健康脚本，我靠江湖+这个工具3天就交差了，不然真得干到“牛马”级别。

[PRE10]

重点功能在【上传音视频】这里。

[PRE11]

### 简称：太强了

单次最多投50个视频，单个文件支持到6小时。把需要拆文案的视频全放一个文件夹，一次拖进去就行，坐等解析。

解析结果在 效率-我的记录-默认文件夹-新建 中查看。

[PRE12]

小技巧：需要批量导出时点右侧批量，勾选想要的文稿，一次最多导出12条，相当于一页量。

追求清晰管理的人可以在导入通义前先把视频文件名改好，这样解析出来的文稿名字一目了然。

[PRE13]

不然100篇混在一起，脑子容易炸。

## 下载时的小细节

导出前记得把【发言人】【时间戳】的勾取消掉，不然下载后还要手动删掉这些标记，很麻烦。

[PRE14]

### 不取消勾选的话就是这样，得手工清

[PRE15]

通义本身还有不少隐藏用法，比如实时记录。开会时开着录，最长6小时，自动转文字，还能按单人/双人/多人区分并生成全文大纲，值得多玩。

到这里，视频批量抓取和文案批量提取的核心链路已经闭环。

# 3. 批量转格式

做小红书治愈类账号的朋友经常需要别人的音频素材。视频抓完后打开【格式工厂】，把视频批量转成音频即可。电脑端软件，自行搜索下载。
