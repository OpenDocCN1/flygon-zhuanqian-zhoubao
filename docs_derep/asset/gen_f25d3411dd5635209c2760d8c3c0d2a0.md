# 项目选择的底层认知

见过那种做什么都赚钱的创业者吧？我刚起步时特别羡慕。为什么我做项目只能赚点零花钱？根子就在选择和判断上。我们对项目的判断力、选择力不一样，结果自然天差地别。运营技巧可以快速学会，有道无术，术尚可求，有术无道，止于术。在讲具体做法前，先把对项目的底层逻辑搞清楚。

1、项目能成，先看赛道本身有没有真实市场和盈利空间，再看自己能否胜过现有竞争对手，最后看有没有机会冲进行业前三。进不了前三，只能赚快钱，最终会被淘汰。

2、别空想。当前竞争已经很卷了，聪明又努力的人太多了，空白越来越少。不要为了避开竞争去编造新产品、新玩法。除非你是天才，否则老老实实找已有成功案例的项目进去做。普通人创业就是复制，赚钱的就跟。创新是资本和大公司干的事，二八定律，九死一生。

3、复制的前提是充分调研。项目成败80%取决于调研阶段。选一个高手云集、自己又没优势的赛道注定失败。要找的是仍在成长期的赛道，对手比自己弱的赛道。你是小学水平去打幼儿园，胜算才大。

4、调研的终点是找到对标。有赚钱的对标，就说明赛道本身没问题。

5、对标是最好的老师。对标能告诉你天花板在哪、用户是谁、产品怎么组合、对手水准如何，甚至到话术、养号细节都帮你试好了。有对标就是开卷考试，直接照抄。

6、胜算的唯一提升方式就是没把握不做。找到对标后还是容易做不成，往往是因为资金、资源、技术等关键要素不具备，复制不了。差距太大就换项目，别硬上。猎豹也是潜伏久了才出手。时间、精力、资金都有限，必须在有胜算时出手。

7、一个项目就是一个系统。再小的项目都有自己的方法和经验曲线，所以从0到1需要时间沉淀。决定做项目，就要给自己足够的测试和迭代周期，猴子捡西瓜是做不出结果的。

8、判断力是选项目的难点。市场环境、对手实力、未来风险这些客观因素我们控制不了，准确判断很难，这靠经验积累。大脑很容易高估自己、低估对手，真正开战才发现人狠话不多。

9、用数量提高命中率。是从3个项目里挑一个更容易，还是从300个里挑一个更容易？世界发展不均衡，赛道也一样，总会有处于成长期、竞争弱的项目。想要找到，就得多看多听多搜集信息，再按方法论分析。

10、项目选择必须按流程走：先粗选赛道→调研赛道→找到对标→分析敌我→确认有优势有胜算→组团队→MVP测试→抠细节→持续迭代→成功或放弃。顺序不要乱。实操中后一个环节出问题，可以回退前一个环节修正。比如赛道没问题但测试做不起来，可能是团队问题，换人就行。但赛道本身有问题，换人也没用。人和赛道都对了，就死磕细节。

# 粗选赛道方向

## 一、什么是赛道

1、赛道就是一个具体行业或项目的称呼。做电商卖女装、男装、玩具就是不同赛道。赛道可以继续拆分，比如女装可按风格、年龄、价格、人群细分，如大码女装、通勤风、汉服等，越细分越聚焦。

[PRE0]

2、那什么不是赛道呢？大健康产业、旅游产业这类大类概念统称就不是赛道。选赛道时不要选过大、概念级的。比如达人领域里的很多大分类就不是赛道。

[PRE1]

## 二、如何粗选赛道

1、当对多个赛道都不熟时，不要盲目下手，先盘点自己的优势，把明显没优势的赛道剔除，再从可行的里挑3个左右进入调研。

以内容型直播间为例，项目成功的前提是资源和能力匹配，选择赛道时要先对照所需资源和能力。

[PRE2]

2、项目能否赚钱，关键是自身优势和项目需求是否契合，别只追风口。机会永远留给有准备的人。首先做自我剖析。不同的人生经历、生活方式、家庭资源、地域环境都会给你独有的优势。

[PRE3]

3、优先从已有优势的赛道里选。因为优势是长期积累来的，从零学成本很高，从已有优势出发胜算更大。

4、从客观角度看，项目做成需要多方面匹配，所以在盘点优势时，也要评估自身整体优势和赛道的契合度。

[PRE4]

5、先把自己想做且有优势的赛道列出来，挑出3个左右开始调研。

## 三、常见问题

1、很多人听到一个信息差就冲进去，完全不看自己能不能做。盲目追风口，大多拿不到结果；

2、这个阶段要保持开放心态，除了肯定干不了的，其它都先放下判断，避免确认偏误导致决策片面。没看到全貌前别下结论。

3、找不到优势怎么办？绝大多数人都有优势，只是没发现。实在找不到，就先选一个上手容易的赛道做起来，在过程中挖掘优势。生财航海很适合。

# 调研阶段

这才是真正的调研开始。调研就是收集信息、判断信息、不断筛选的过程。你觉得选择很多，但把敌我形势分析完后，最优解往往只有一两条。这就是调研的价值。

## 一、确定平台

1、做业务的平台很多，抖音、视频号、小红书、美团、百度、虾皮、亚马逊等。首先定平台。每个平台调性、人群、内容风格不同，同一赛道在不同平台的人群画像也不同。调研前先锁定平台。比如内容型直播间，可在抖音、快手、视频号、小红书操作。

2、各平台现状小结

（1）快手红利期已小，人群增长乏力，付费高，部分类目管控松；
（2）抖音是最大内容平台，人群广、细分多，但竞争激烈，高客单难，付费占比升高，今年内容型直播间、真人短视频带货仍是不错方向；
（3）视频号相对蓝海，对普通人友好，人群偏大龄下沉，付费低，免费流大，很多抖音做不下去的都在转视频号，新手建议入；
（4）小红书也偏蓝海，对素人友好，UGC生态，用户层次高，高客单转化好，管控松，大健康类违规词可直接说。

3、客观上新手建议视频号、小红书，其次抖音，最后快手。

4、主观上你常用哪个、喜欢哪个，就可以优先考虑。

5、个人或小团队想年入几十万，这几个平台都能实现。若追求爆发大流量，只有抖音。

总结：按个人习惯和平台红利选，先做一个平台跑通再扩展。实在定不了，可多平台同步调研。

## 二、确定赛道形式

1、同一赛道内部有不同变现方式，先确定方向。抖音可开店做商品卡、对接达人、短视频带货、直播带货、图文带货，先选一个方向再找对标。

2、从利润看，做流量端比做供应链高。有流量能力做流量，有供应链资源做供应链。

3、从内容难度看，真人出镜＞非真人＞半无人，直播＞短视频＞图文。

难度排序：真人出镜直播＞非真人出镜直播＞真人出镜短视频＞半无人直播＞非真人出镜短视频＞真人出镜图文＞非真人出镜图文。

## 三、找到赛道里的全部账号

### 1、底层认知

（1）调研第一步是看到赛道全貌，收集足够信息，信息越全决策越准；
（2）账号是项目载体，找到足够账号数据就能看到项目全貌；
（3）只看几个账号就定对标，容易陷入确认偏误；
（4）数量越多理解越深。我们调研常看上千上万个账号，别用战术勤奋掩盖战略懒惰。

# 分析数据

找到赛道大部分账号后，要总结分析，判断能不能做、天花板多高、竞争对手如何、是否匹配自身。

## 一、项目整体判断

### 1、项目存活周期多久

看赛道里干最久、粉丝最大的账号来判断周期。若有干超1年的账号，说明赛道能长期存活，但竞争在加剧。若全是新号，需分析账号易死的asinya。如健身赛道，前几大号都从19、20年起步。具体用蝉妈妈。

较好情况是头部1-3个十几万到几十万粉丝，中间一堆几千几万的。

无第三方平台就看第一个短视频发布时间、第一场直播时间。

[PRE23]

### 2、项目天花板多高

赛道里营收最大的号≈天花板。如健身直播间最高约1000-2500W。新手进入天花板约行业老大的1/3，即100-300W，再差一点几十W。看统计数据。

[PRE24]

### 3、项目所处阶段

判断是否在红利期，看两点：

（1）行业大佬是靠免费流还是付费流，若都付费，红利期至少中后期；
（2）新起的几千几万粉账号是免费流还是付费流，若新账号付费占比超50%，基本没红利期。如护肤带货赛道，除教程类直播间外，其他带货直播间基本全靠付费。

注意：无流量红利的赛道新手别进，竞争白热化，存量市场很累，失败率高。

## 二、项目竞争分析

做对手分析，综合判断竞争难度。

1、近3个月有没有新号起？行业无新号代表竞争很大。较好情况是近1个月有几千几万粉账号带货做到几十万且有多个案例。如有氧减脂赛道，几万粉账号销量和自然流都很低，一个月不过30W。

2、新号流量规模和头部差距大不大。若新号能接近头部，竞争不大；若明显分层，粉丝多时间久的流量大，新号小很多，就是竞争大，对起号要求高。

3、新号付费占比超50%，大号自然流，新号需付费，说明内容同质化严重，新号难拿流量，不建议新手做。

4、近1个月新号起号数量很多，超5个起来且还有一堆在起，说明进场的人多，竞争在加剧，需快速进入抢先发优势。

5、同一赛道有非真人、真人、IP，看近1个月成功账号比例。若非真人已起不来，说明非真人竞争激烈，需做真人内容。

6、看粉丝增长情况。若大号和新号涨粉速度相近，说明赛道还有流量未挖掘，竞争不大。若大号停止涨粉甚至掉粉，新号大量涨粉流量大，说明新号挖掘了新人群，直接对标新号。若全赛道涨粉都慢，就是竞争大。

总结：竞争分析后，要找到近1个月、免费流起号、稳定盈利的新号作为对标，深入分析。对标可选几个，但必须是同赛道同人群画像。

## 三、项目财务分析

找到对标后按以下维度分析，确定成功概率。

### 1、项目盈利能力分析

看对标主推产品、价格、来源、单日销售额、退货率，算利润。

销售额 = 产品价格 * 成交人数

退货率 = 退货金额/销售额

利润率 = 佣金率*0.9（10%技术服务费）=产品成本/销售额

成本 = 人员成本 + 场地成本 + 损耗成本 + 投流成本
