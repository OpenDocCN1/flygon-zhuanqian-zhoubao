# 写给小白：轻松看懂 web3.0 的赚钱门道

大家好，我是乔橘。

混迹 web3 圈子也有几年了，平时自己也带着一个 web3 社区，这几年基本是风口在哪，我就往哪跑。

最近在生财里翻了不少讲 web3 的帖子，翻完最大的感受就是：对新人太不友好了。满屏的专业名词，什么公链、layer2、流动性挖矿……看完跟没看差不多，整个人直接懵掉。

所以今天我不整那些高深术语，专门挑几个目前比较热门的赛道，用大白话给圈友们做个入门扫盲。内容不多，但保证你读完能摸到门道。

这篇发出来后，已经有不少圈友跟我说“终于能看懂一点术语了”“总算有一篇通俗易懂的文章了”，听他们这么说，我也挺开心的，算是没白写。

希望能帮你把 web3 这扇门推开一条缝，剩下的路，咱们慢慢走。
