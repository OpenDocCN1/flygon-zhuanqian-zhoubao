# AI短视频新手掘金：两个冷门赛道拆解

做AI内容，最现实的问题还是成本。自己的设备算力不够，再怎么也拼不过大厂现成模型的便捷。所以我就挑了眼下两个最具代表性的赛道，把实操思路掰开讲。原本准备了三条，实在精力有限，先聊两条。大家完全可以按这些方向，先跑通一个成品，再顺着灵感做出更多有巧思的作品。

# 一、萌宠剧情流

## 先看清这类内容的本质

这一路基本就靠“萌”起家。最早是猫meme带起来的，后来延伸到小兔子、小老虎等方向。但猫的受众盘子最大，延展性也最强。它抓人的点不只是可爱，还藏着一层教育意义。

正因为这样，猫的故事才能长出那么多分支。下面就用猫做例子，各位可以自己发散，也可以先拿它练手。

常见的套路是：猫崽被欺负，历经波折后收获成长；或者猫家突起变故，猫妈离世，猫爸独自拉扯孩子。这类作品都有很强的画面感。

所以做这个方向，除了逆向拆解爆款，更要琢磨一件事：这部短片到底想传递什么感觉？

现在猫类剧情卷得厉害，后期申请YPP有风险。要么往其他萌宠拓展，要么转做图片转视频。先来感受一下这类作品的样子：

三个典型剧情：

**之一**：猫妈推着购物车带猫崽逛商超，猫崽在前面蹦蹦跳跳。猫妈突然肚子疼，“喵喵”直叫。猫崽赶紧跑回来，发现妈妈肚子鼓了起来，反应过来是要生了，顿时慌了神，四处找人帮忙。它拨通急救电话，猫妈被抬上急救车。猫爸接到消息后冲到诊所，在过道里来回踱步。最后猫妈平安生下六只幼崽，猫崽笑得很开心。

（用简洁画面和猫叫音效，把迎接新生命的喜悦演了出来，满满的家庭暖意。）

**之二**：猫妈带猫崽逛街，猫崽想买苞谷花。它揣着钱凑到摊前，摊主却说猫不能进去。猫崽蔫了，猫妈赶紧安慰。猫妈灵机一动：换上一身黑色夜行衣，潜进苞谷地，顺了一袋苞谷。回家后亲手做成苞谷花，猫崽吃得一脸满足。

（讲的是母爱和智慧。猫妈为满足孩子的心愿敢冒险，最后靠脑子搞定问题。）

**之三**：猫崽同样想买苞谷花，但摊主立了块“猫咪禁止入内”的牌子，直接拒绝。猫崽很委屈，猫妈安慰后想出一个点子：扮成夜行特工进苞谷地偷苞谷。这次可不顺——田主带着狗一路狂追。但猫妈最后还是扛着苞谷跑回家，做成苞谷花，和猫崽一起吃了个痛快。

（内核还是母爱和智慧。猫妈为了孩子的心愿，闯过重重阻碍，目标达成，猫崽开心。）

看出门道了吗？第一条是纯图片加转场；第二条和第三条，工作流相同，剧情几乎同款。所以这类作品拼的不只是出图技术，更是底层的表达。故事足够好，才可能爆。

### 优势：

对新人格外友好，上手轻松，逻辑直白，不需要复杂流程，耗时也短。赛道里高播放量的同行账号一大把，照着模仿就能快速起步。

### 短板：

太卷了，做的人多，申请YPP的难度直线上升（同一个类目里YPP通过太多，后续可能被拒）。而且需要预算，比如订阅GPT账号、支付图片转视频的费用。

### 应对：

短板并非无解。图片申请难，就转做图片转视频；成本被抬高，就想办法压缩——但想零投入是不现实的。

# 具体怎么操作

比较省力的打法是“逆向反推”：把对标的爆款拆成一帧帧图片，还原完整剧情线，然后重新绘图、组装（要么图片加转场，要么图片转视频）。

这类画风是有讲究的，包括后面要聊的搞笑段子，都得靠DALL·E 3。拿MJ、SD、Flux来对比，DALL·E 3在完成度、风格和价格上都更有优势。

DALL·E 3就是ChatGPT自带的画图能力。动手之前，先搞懂画风，别拿着图瞎反推。画风不对，老外不认，视频的连贯感也会崩塌。

## 画风怎么定

欧美观众从小被Disney、Pixar这类动画厂牌包围，这种画风更容易让他们沉浸进去。Pixar动画风、Disney动画风、超现实感……Prompt里都要带上这些关键词。

## 手动流程

这里主要讲逆向反推，不谈原创。原创要收集大量剧情、做风格转写、拆脚本分镜、反复打磨，实在太琐碎，讲起来也没头没尾。反推又快又稳，而且这个领域新素材源源不断，真没必要硬原创——AI写出来的剧情真的很尬。

总共分三个阶段：拆解画面、生成图片、筛图/图片转视频、后期加工（配乐和音效）。

## 阶段一：拆解画面

先把视频切成一个个画面，再反推出提示词和完整剧情线，这样后续出图才有抓手。

**（1）手工截图**

每个短片的底层都是几张图串起来的，图片转视频也一样。最省事的方法就是逐张截图，一个视频顶多十来张。

**（2）代码自动拆帧**

不想写代码？我打包了一个小工具，纯代码打包，无任何附加绑定，可以放心用。原理是调用OpenCV，比较相邻画面的灰度分布，检测镜头切换，再用Bhattacharyya距离衡量两个分布有多像。流程是先把彩色画面转成黑白灰度，再算灰度分布差异：

- threshold：镜头切换阈值，数值越小检测越灵敏
- video_path：输入视频路径
- output_dir：输出帧存放路径

## 阶段二：生成图片

前面说了用DALL·E 3，对新手更友好的方式就是直接用ChatGPT。只要根据图片反推画面，合成剧情，再做二次创作。

**（1）用Prompt批量提取剧情描述**

**Prompt：**

把拆好的图一次丢给ChatGPT，让它这样描述：“请告诉我这组图讲的什么。这些是从视频里拆出来的画面，背后是一段完整剧情。请逐一描述对应画面，并把剧情串起来。描述时按镜头、景别、动作、角色来写，给出中英文对照。”

[PRE10]

每次最多传10张图，所以继续发：“剧情还没结束，我接着给你，请继续描述，并衔接到前面的内容。”

18. 画面十八：结尾，母子俩坐在起居室地板上，分享一桶苞谷花，脸上全是满足，故事圆满落幕。

**剧情总结：**

猫崽因为买不到苞谷花而失落，猫妈为了让猫崽解馋，冒险去苞谷地“借”了一袋苞谷。经历一番追赶后成功带着苞谷回家，亲手做成了苞谷花。过程虽然意外不断，但最终母子俩一起开心享用，温馨圆满。

这样捋下来，主线没有走样，想传达的情绪价值也不偏。如果某些描写跟原片有出入，自己动手微调就行。

**（2）设定人物**

要让剧情统一，人物形象得尽量保持一致。现阶段AI绘图、AI视频都像“抽卡”，只能从外形、物种、性别、服装、动作、画风几个维度去做锁定。只要做到大概一致，观众一般不会挑剔。

**Prompt：**

“请重新指定形象。首先说明：整体画风是Pixar动画、超现实感，动物全部人格化，不要保留爬行等原始习性，而要像人一样直立行走。先别急着画，我们先敲定这两个角色的具体长相，再优化Prompt。”

**人物一：猫妈**

- 外形：人格化的白色长毛猫，毛发蓬松柔软，头部、耳后和尾巴尤其突出，气质温柔大方。
- 眼睛：大眼睛，绿色瞳孔，既透着温柔，又藏着坚定。
- 神情与姿态：平时温婉慈爱，嘴角带浅浅笑意；行动时冷静果敢。
- 服装：
  - 日常装：一条简洁的粉色连衣裙，暖色调衬出母性温柔。
  - 任务装：黑色夜行特工服，配腰带和工具袋。即使穿着夜行衣，那身白毛和蓬松尾巴依然醒目，辨识度极高。
- 性格：柔软又果决，为了猫崽肯豁出去。日常体贴，执行任务时干净利落。

**人物二：猫崽**

- 外形：人格化的粉色短毛猫，天生一副惹人怜爱的模样，皮肤粉粉嫩嫩，透着天真。
- 眼睛：又大又圆的亮黄色（或金色）眸子，满是好奇和向往，看到新鲜东西时尤其亮晶晶。
- 神情与姿态：总是一脸期待和好奇，瞅见猫妈或者心动的小物件，眼睛立刻发亮，带着大大的孩子气。
