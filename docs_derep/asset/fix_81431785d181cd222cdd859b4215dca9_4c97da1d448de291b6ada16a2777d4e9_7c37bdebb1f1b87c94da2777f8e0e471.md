# 一个Coze AI代理，自动产出线条小人风格的心理知识短片

最近，极简手绘小人讲心理知识的短视频越来越常见。画面不复杂，但内容往往能戳中观众。很多人好奇：这种视频是不是需要专业的绘画和剪辑能力？其实，用Coze就能把整个流程自动化。

最初看到有人分享了一套Coze流程，用来配合剪映批量制作这类短片，思路很巧妙。可惜个人账号没有团队协作区，跑通的流程文件没办法直接分享给朋友。于是换了个思路：干脆把整套流程封装成一个AI代理。别人拿到链接，认证后就能直接用，省去了自己复制节点、配置环境的环节。

试着提问：“睡前总忍不住翻看手机，这背后是什么心理？”它会自动完成三件事：拆解行为背后的心理机制；编写中英文对照的台词；为每句台词绘制线条小人画面。最后合成一个剪映草稿项目，打开后能看到带图像和音频的完整素材。

目前产出的内容已经可以直接使用。若想更进一步，可以从几个方向优化：
- 在短片开场与收尾加入固定的品牌片段；
- 绘图时去掉画面中的字符，保持干净；
- 后期统一铺背景音乐；
- 调用扩展组件，把静态画面变成动态影像。
提醒一个容易踩坑的点：“剪映配套工具”个人面板中指定的目录，必须与“剪映”主程序里的草稿存放路径设置保持一致。否则贴入链接后，剪映可能找不到项目。

整个构建过程可以拆成两大步——先做流程编排，再做AI代理配置。

**一、流程编排（我给流程取名为 huochairendemo）**

原流程的入口可参考那位创作者的分享帖，这里只说我优化后的调整：
- 重写了镜头描述的指令文本，让画面产出更稳定；
- 重新调整了 zimu、zimu1、wenshengtu 三个节点的参数，并给短片开场与过渡语句增加了约束。

在角色设定上，AI代理被塑造成“深研心理机制的极简手绘内容创作者”，它需要遵循以下规则：
- 先把输入内容拆成若干段台词，每段台词都要对应一句英文翻译；
- 解释完原因后，必须追加一句“XX的应对方案是”，再给出具体策略（XX为主题变量）；
- 为每句台词编写画面描述，要求风格统一：线条小人为主角，背景留白，画面不出现任何字符；
- 短片开场固定出现“今天要聊的心理知识点是：XX”这样的句式。

绘图模型方面，换成“通用-pro”后出图明显更稳定。

**二、AI代理配置**

该环节包含三件事：

1. 设置人设描述文本
给AI代理设定身份为“用通俗语言讲心理知识的博主型教授”，工作步骤依次为：从提问内容中提炼核心心理概念并进行解释；请提问者选定一个概念作为主题；将主题传给 huochairendemo 流程，返回短片链接和剪映配套工具的获取地址。
同时要加入一条限制：一旦提问者选定主题，必须立即进入对应流程，不能停留在解释阶段，也不能回答无关问题。

配置完成后，就可以直接测试了。经过多次调校，产出结果已经足够稳定。

这套模式的底层逻辑很清晰：把内容结构做成标准模板，再让AI按模板批量产出文字、画面和声音。因此它完全可以迁移到其他领域。只要改动流程里的镜头描述、绘图模型、配音环节等节点，其他部分基本不用动，就能做出养生、健身、宠物、女性成长等各类短片。
甚至可以不依赖AI绘图，单独跑一个“文字描述+配音”流程，先把文字与音频准备好，再去摄制实拍画面，效果同样好。

实践体会：
1. 流程要稳定，指令文本必须反复打磨，有自己的判断标准，不达标就一直调；
2. 框架化内容最适合做成短片模板；
3. 结合扩展组件可以做出动态画面，具体看内容需要；
4. AI代理的构建并不复杂，难的是让流程保持稳定，这非常考验人的耐心。
