别急着装一堆插件，先把手头的笔记写起来。Obsidian 的门槛其实就一条：用 **\[\[词\]\]** 把关键词括起来，就相当于给它建了一座桥。笔记还没创建，点一下它会自动生成。

概念四：插件怎么分
核心插件是官方自带的，在设置里就能开关；社区插件是第三方做的，得去插件市场下载。
第一天千万别碰社区插件。先把核心插件里常用的几个激活，摸熟一两周后再去找能补短板的东西。

第 4 章 写第一篇笔记
创建笔记
按 Ctrl/Cmd + N，或者在左侧文件列表右键新建。标题随意，比如「今天的想法」「读书笔记」，无所谓完美，先写下来再说。
Markdown 速查

三种编辑模式
实时预览是默认推荐，输入时标记会立刻渲染成样式。
源码模式会把所有原代码符号暴露给你。
阅读模式只能看不能改，Ctrl/Cmd + E 在实时预览和阅读之间切换。
标签和属性
标签直接在正文写 #读书笔记、#习惯，点击就能把相关笔记聚拢。
属性也就是 YAML Frontmatter，放在笔记最顶部用三个减号包起来，用来存结构化元数据。新手可以先不管，等需要做汇总时再回来补。

第 5 章 必学的高频功能
文件、搜索、书签
文件列表在左侧，可以右键新建笔记或文件夹，拖拽调整位置，双击打开。别一上来花两小时搭目录，先写。
搜索就是那个放大镜，在全库里找关键词，是以后最常用的功能之一。
书签用星标，把每天要回看的笔记钉住，不然在文件树里找会疯。
两个肌肉记忆
Ctrl/Cmd + P 命令面板，是万能入口。找不到的功能在这搜，创建、设置、导出、跑插件都能搜到。
Ctrl/Cmd + O 快速打开，输入笔记名称就能秒开，比鼠标点快十倍。
关系图谱
能把所有笔记的链接可视化。笔记少的时候就是几个孤点，等到几百篇后会很震撼。新手瞄一眼就行，别钻研。
必调的几个设置
编辑器默认模式改成实时预览。
文件与链接里把新建笔记存放位置指定到一个收集箱文件夹，不然会乱跑。
附件默认路径也指定，比如“附件”，粘贴或拖入的图片 PDF 全进这里。
核心插件里确认打开日记、大纲、书签、标签、模板。
高频快捷键
更多可以在设置 → 快捷键里看和自定义。

第 6 章 笔记组织的三种思路
核心原则是文件夹保持浅层，别超过 1-2 层，靠链接和标签来组织。没写够笔记就去设计完美分类，基本都会翻车。
MOC 内容地图
建一篇目录笔记，不写正文，只把同主题的笔记按结构罗列出来。
[PRE3]
适合做主题入口，还可以再建一篇 Home 笔记，把所有 MOC 列进去，形成地图的地图。Obsidian 里最受欢迎的就是这种方式。
[PRE4]
PARA
按用途和状态分四类：
Projects 项目：正在进行、有终点，比如“装修房子”。
Areas 领域：长期经营、无终点，比如“健康”“理财”。
Resources 资源：兴趣素材库，比如“摄影”“Python”。
Archives 归档：已结束、不活跃。
搬家技巧：从别的工具搬过来，先把旧笔记全扔进 Archives，桌面立刻干净，历史也还在。
Zettelkasten 卡片盒
三条核心：每篇只写一个想法、用自己的话复述、主动建立链接。流程是随手记 → 定期整理 → 重写并链接。适合爱写作做研究的人。这不是分类法，是写作法。
怎么选
想看清主题结构 → MOC
想按正在做的事组织 → PARA
想沉淀写作素材 → Zettelkasten
最好先无脑写半个月，等真实需求冒出来再有意识地用对应方法。

第 7 章 必装的 10 个社区插件
7.1 通用安装方法
设置 → 社区插件 → 关闭受限模式 → 浏览打开插件市场 → 搜索 → 安装 → 记得点启用，很多新手忘了启用以为坏了。
市场打不开就换网络或加速，或去 PKMer 等镜像站手动下载，放到仓库路径/.obsidian/plugins/插件名/ 下重启即可。
下面 10 个按推荐顺序列。Templater、Tasks、QuickAdd、Dataview 配置稍复杂，其余装上就能用。

7.2 第一批立刻装
Calendar 日历 —— 右侧多一个月历，一眼看出哪天写了日记。点日期能跳转或新建。必须配合核心插件日记，把面板钉在右侧，每天第一件事点今天写日记。
Templater 高级模板 —— 重点
比核心模板强很多，能自动填日期、标题、星期，还能弹窗让你选择。
怎么用：
1. 设置 → Templater → Template folder location，填模板文件夹名比如“模板”。
2. 在模板文件夹里新建笔记当模板，比如“日记模板”，内容：

新建笔记后按 Ctrl/Cmd + P 搜「Templater: Insert template」→ 选模板，内容自动填入，日期会变成今天。
常用变量自行探索。建议给日记、读书笔记、会议记录、项目笔记各做一个模板。
Image Toolkit 图片工具箱 —— 点图片可全屏预览，滚轮缩放、拖拽移动、左右切换、Esc 退出。装完即用，爱贴截图的人必备，看图体验直接正常化。

QuickAdd 快速添加 —— 重点
把灵感闪现到记录的摩擦降到最低。一个快捷键 → 弹输入框 → 回车 → 自动追加到指定笔记，3 秒搞定。
典型配置捕捉灵感：
1. 仓库里建一篇「灵感收集箱」
2. 设置 → QuickAdd，顶部输入“捕捉灵感”，类型选 Capture，点 Add Choice
3. 点齿轮配置：File Name 填灵感收集箱；Capture format 填 `- {{VALUE}} ({{DATE:YYYY-MM-DD HH:mm}})`
4. 回到首页点闪电图标注册命令
5. 设置 → 快捷键，搜「QuickAdd 捕捉灵感」绑定快捷键比如 Ctrl/Cmd + Shift + I
以后有想法按快捷键输入回车，灵感就躺进收集箱了。
Periodic Notes 周期笔记 —— 补齐周记、月记、季记、年记。设置里开启 Weekly Notes，格式设 YYYY-[W]ww，指定模板和文件夹。配合 Calendar 可直接点周数建周记。每周日花 15-20 分钟复盘，坚持一个月会发现自己做了很多事。

7.4 第三批用了两周后装
Kanban 看板 —— 命令面板搜「Kanban: Create new board」创建，添加列如「灵感池 → 写作中 → 已完成 → 已发布」，添加卡片拖拽。卡片里写 `[[笔记标题]]` 可跳转，看板和笔记联动。

Excalidraw 白板绘图 —— 手绘风格，画思维导图、流程图很顺手。命令面板搜「Excalidraw: Create new drawing」创建。图形文字里也能放 `[[笔记标题]]` 双链，Ctrl/Cmd 点击跳转。

7.5 安装节奏建议
第一周：Calendar + Templater + Image Toolkit，覆盖看日历、用模板、看图片。
第二周：Tasks + QuickAdd + Periodic Notes，任务管理、快速捕捉、周回顾。
第三周起：Kanban + Dataview + Excalidraw + Various Complements，功能强学习成本也高，等基础熟了再装。
插件不是越多越好。很多人装二三十个，结果启动慢、界面乱，大部分没用。正确思路是先遇到问题再装插件解决，而不是先装再找用途。工具为你服务，别为工具打工，先把笔记写起来。

第 9 章 导入外部资料
Word
装 Importer 插件 → 命令面板搜「Importer: Import data」→ 选 Microsoft Word → 选文件导入。少量文档可直接复制粘贴到 Obsidian，新建笔记粘贴，标题加粗列表会自动转 Markdown。
飞书文档
打开文档 → 右上角「⋯」→ 导出 → 优先选 Markdown，没有就选 Word。Markdown 文件拖进仓库即可。批量导出时勾选多个文件 → 导出为 Word → 解压后用 Importer 批量导入。
PDF
设置 → 文件与链接 → 附件默认存放路径指定文件夹。然后直接拖 PDF 进编辑区，自动入库并生成链接。文件列表双击可阅读。笔记里嵌入写 `![[文件名.pdf]]`。
音频与视频
支持 mp3/wav/m4a、mp4/webm，其他格式先转码。放进仓库后笔记写 `![[录音.mp3]]` 或 `![[演示.mp4]]`，阅读模式会出现播放器。注意视频体积大，仓库会膨胀，大视频放网盘只记链接。

第 10 章 同步与备份
笔记越攒越值钱，一定要备份。
Obsidian Sync 官方付费，端到端加密、有版本历史、跨设备无缝，最省心。
坚果云 / iCloud，把仓库放在同步目录，简单但 iCloud 仅限苹果。
Obsidian Git 插件 + 私有 GitHub，同步加完整版本历史，可回滚，适合愿意折腾的人。
Syncthing 免费开源点对点，配置稍麻烦但不依赖云厂商。
底线：至少保留一份本地独立备份，比如每周同步到移动硬盘。
别贪快。Obsidian 的价值随时间累积。一周写 10 篇没感觉，坚持一个月三个月，你会得到真正的第二大脑。
22. 先写再整理。别先花两小时设计文件夹分类，写多了自然知道怎么整理。
23. 不要追求完美笔记。一行字也值得记。笔记是给自己看的，不是作品。
