# 你的行动，其实是你认知的投射

很多人以为人是冲动做事的动物，恰恰相反，人是一个被信念牵着走的系统。

我们从不会无缘由地行动，每一个决定背后，都藏着一句没说出口的解释：这件事对我来说算什么？它有没有价值？值得我投入吗？

换句话说，行为从来不是凭空产生的，它是“意义判断”做完后才推出的结果。你看待世界是什么样子，你把哪些东西排在前面，你的价值观长什么阶梯，你的日常选择就会长成什么模样。

所以与其纠结“我为什么总做不到”，不如先审视“我到底相信什么”。因为认知在前，行动在后。先有意义框架，后有行为轨迹。
