# 在 Web3 里，普通人到底能怎么找机会？

> 参考来源：[`www.yuque.com/for_lazy/thfiu8/tps0nir9mwnbaxr6`](https://www.yuque.com/for_lazy/thfiu8/tps0nir9mwnbaxr6)

最近又被邀请去聊 Web3，这次的主题是《如何在 web3 领域寻找我们的机会？》。

我是可达 Koda，一名深耕 Web3.0 的创业者，同时也在做加密资产投资。也是生财有术的航海家，负责 Web3 航海板块的内容输出和教练工作。

大概三个月前，我在 Web3 主题航海里第一次分享过《我们在 web3 的赚钱机会》。三个月过去，自己在这个赛道里有了不少新的体悟和认知升级，也实操出了一些小成绩。这次重新梳理，我更想强调的是：当 AI 让生产力被指数级放大时，下一步真正值得普通人卡位的，很可能不是生产工具本身，而是随之而来的生产关系变革。

**评论区精华整理**

来说 Web3：Web3 范围听起来很大，币圈、NFT、DeFi、GameFi、投研、VC 等等，你主要聚焦在哪一块？

可达 Koda：从体量看其实并不大。以国内为例，真正活跃的核心人群大概也就一万左右。我这里说的活跃人群是指那些懂公链、会研究项目、会参与建设的人，单纯的交易盘人群不算在内。

来说 Web3：我说的多是指赛道分支多，人群规模确实差不多，把炒币的剔除后就剩这些了。你看起来更偏社区，DeBox 和 RichDAO 都有关联？

可达 Koda：对，可以这么理解，我既接触项目方也做社区运营。不过人本来就这么点，分得太细也没必要，说白了现阶段国内活跃的 Web3 领域，本质上都还是在区块链金融的范畴里。
