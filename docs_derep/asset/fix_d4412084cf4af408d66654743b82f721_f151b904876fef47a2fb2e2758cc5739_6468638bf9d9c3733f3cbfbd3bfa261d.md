# 现象级 MMORPG 刷屏时，普通人从哪里找赚钱机会？

文 / 姚麻
2023年3月21日

生财的伙伴们，好久没在社群里冒泡了。眼看杭州线下聚会就要开始，我也想趁这个节点出来刷个脸。今天这期聊一个很应景的话题：当一款现象级大型多人在线角色扮演游戏杀到眼前，比如网易那款即将开测的国风武侠开放世界手游，普通创作者、服务商和玩家能抓住哪些变现口子？

这篇内容我越写越长，最后收成了一万多字。详细的场景拆解、可复制玩法和真实案例都放在飞书文档里了，大家去原文里找链接即可。另外，这篇稿子还有一个调皮的名字，大意是“再活一次，我还是那个爱打游戏的家伙”，和正文的严肃画风形成了一点反差。

留言区里有位朋友补充了一个重要观察：暑期档国服版《命运方舟》也有动静，他身边的几个代打已经准备转战，觉得是下一波红利。我很认同，Steam 国际服目前依旧活跃，一旦国服开启，很大概率会带起新的陪玩、代练、账号服务等需求。

说到底，现象级游戏本身就是流量池，能不能吃到肉，关键看从哪个角度切入。完整版万字拆解可以去原文里找飞书链接。
