# 一、备餐到底是啥？两种流派，两种活法

MealPrep（简称MP）这个概念，最早是从欧美健身圈火起来的。核心操作很简单：找个空闲时间，一口气做出一周甚至几天的饭，然后分装进饭盒，冰箱里一存，工作日拿出来热一热就开吃。

美式备餐的标配通常是三件套：主食（碳水）+ 肉类（蛋白质）+ 耐储存的蔬菜（比如根茎类、菌菇类）。吃的时候再顺手配点新鲜绿叶菜或者可以直接啃的蔬果，方便是方便了，营养也能兼顾。

但说实话，这种吃法有个硬伤——太单调了。天天一模一样的搭配，用不了几天你就想掀桌。所以它更适合两类人：一类是有严格饮食计划的健身党，另一类是想快速入门、提高效率的备餐新手。

那有没有更友好的选择？有，就是日式家庭常备菜。

日式流派更像是“预制菜”的思路：把不同的食材分类处理好，分装进保鲜盒、保鲜袋，用冷藏、冷冻、真空、厨房纸+保鲜袋等方法来保鲜。吃的时候随吃随做，既满足口味需求，又能大幅缩短每天做饭的时间。

日式备餐一般围绕主食、主菜、配菜来准备，唯一的“缺点”是吃的时候需要自己组合搭配，做完还要洗锅。但即便如此，比起每天从头开始做，节省的时间还是相当可观的。

说到底，日式备餐基本上适合所有人——上班族、宝妈、学生党、家庭主妇，都能用得上。我个人也更偏爱这个路子，但我真正在用的，是把两种流派揉在一起、再升级过的版本。

那么问题来了：具体怎么操作？怎么根据自己的情况来制定备餐计划？下面我就把这些年摸爬滚打总结出来的经验，毫无保留地分享给大家。

# 二、健身党专属：美式备餐实操全流程

先别被“健身专属”四个字吓到，其实只要学会算数、懂得搭配、掌握储存，你就能立刻上手。这个部分我先讲美式备餐，因为它相对简单，思路一通，后面进阶版就更好理解了。

## 1. 你首先得知道：你一天到底该吃多少？

第一步，搞清楚自己的基础代谢——也就是你一天躺平不动会消耗的热量。

但不建议你去用网上那种通用公式硬套。为啥？因为每个人的代谢水平差异太大了。同样体重的人，健身人群、肥胖人群、普通人群的代谢水平是完全不一样的。健身人群如果套用传统公式，误差会非常大。

那怎么办？健身圈早就总结出了一套经验化的分配方法——按体重来分配三大营养素。定下了三大营养素，就等于定下了总能量：

- 碳水：4.1kcal/g
- 蛋白质：4.1kcal/g
- 脂肪：9kcal/g

**减脂期怎么吃：**
- 新手：碳水每公斤3.5g，蛋白质每公斤1.5g，脂肪每公斤0.8g
- 有训练史：碳水3.5g，蛋白质2g，脂肪0.8g
- 建议减重速度：每月2-5斤，防止反弹

体重降下来后，要定期调整碳水量，让身体适应新的代谢水平。

**增肌期怎么吃：**
- 新手：碳水3.5g，蛋白质1.5g，脂肪1g
- 有训练史：碳水4g，蛋白质2g，脂肪1g
- 建议增重速度：每月1-3斤
- 调整逻辑：蛋白质和脂肪不变，只调碳水

**举个例子：**
我75kg，有训练底子，想增肌。套公式：
- 碳水：75×4=300g
- 蛋白质：75×2=150g
- 脂肪：75×1=75g

总能量 = 300×4.1 + 150×4.1 + 75×9 = 2520kcal

当然，网上关于分配比例的算法有很多，核心逻辑都一样：增肌就多给蛋白质，减脂就少给碳水，脂肪基本维持不变。

实操建议：先用体重代入算一遍，然后通过一周的体重变化来反复“AB测试”，找到自己的真实平衡点。体重不变，说明刚好在热量平衡点；有变化，就按上面的方法微调。同时要考虑每周运动消耗，尽量减少误差。

知道了单日总量，一周备餐总量就是单日×天数。

## 2. 食材怎么选？怎么算？

**先说一个新手最容易踩的坑——可食用重量：**

- 500g的苹果，去核后大概只有380g能吃
- 蔬菜瓜果要去皮、去壳、去叶
- 生熟差距很大：生米100g含70g碳水，但煮熟后，同样100g熟米只有20多g碳水

加工方式也影响热量：蒸煮 < 炒制 < 油炸。还有包装食品、糖油混合物，新手一开始不会算，特别容易吃亏。

## 3. 实操环节：一天到底怎么搭配？

备餐时，我的顺序是：先搞定蛋白质，再安排碳水，最后用其他食材补足脂肪。

你可能会问：为什么要先定蛋白质，再定碳水？接着往下看，用实例一演示你就明白了。

还是用75kg增肌的例子：每天需要碳水300g、蛋白质150g、脂肪75g。

[PRE3]

**第一步：蛋白质。**
选鸡胸肉作为主要来源。每150g鸡胸含24.6g蛋白质，要满足全天150g蛋白质，需要609g鸡胸。
注意！609g鸡胸里还藏着约11.6g脂肪，这个必须算进总脂肪里，不能漏掉。

**第二步：碳水。**
300g碳水约等于389g生米（每100g生米含77.2g碳水），同时这里面还有3.5g脂肪，也得算上。

**第三步：脂肪。**
全天需要75g脂肪，前面已经分配了15g（11.6g+3.5g），还能再吃60g脂肪，换算成肥肉大约68g。

**第四步：确定采购清单。**
假设备餐5天，一次性采购：3kg鸡胸、1.945kg生米、340g肥肉，再搭配新鲜蔬菜水果，材料环节就搞定了。

> 补充说明：这里用肥肉举例纯粹是为了方便计算，别当真去顿顿吃肥肉啊！

坦白讲，上面这套搭配逻辑没毛病，但美式备餐的通病也暴露出来了：种类太少、微量元素不均衡。真要是天天只吃鸡胸+米饭+肥肉，过段时间身体就该抗议了。

所以我个人备餐时会刻意留出一些热量“空档”，分给水果、坚果，甚至偶尔来点糖油混合物。再配合当日饮食计划调整运动量，比如做20分钟有氧。

**增肌期有氧安排：**
- 每周两次短有氧（不超过20分钟），或一次长有氧（40分钟）
- 有氧的主要作用是提升心肺、消耗多余热量
- 避免长时间有氧，以免掉肌肉（前提是蛋白质给够）

**单日三大营养素怎么分配？**
蛋白质和脂肪均匀分配到每顿，碳水在训练后多安排一些。这样能降低入门难度，让你更好地坚持备餐。

## 4. 加工与保存：一切井井有条

有经验的备餐者，都会做多线程操作。

拿米饭举例，它是所有烹饪里最耗时的。那就先把它煮上，等别的菜做完，饭也好了。

**米饭加工小贴士：**

01. 白米饭可以和糙米、藜麦米、燕麦米混着煮，热量不变但营养更丰富、膳食纤维更多。蒸煮时，加1.2倍体积的水，口感更好。
02. 生米和熟米的转换系数约2.3倍（实测），也就是100g生米≈230g熟米。但反过来不成立，所以我都会在煮好后称一下总重量，然后按“能量守恒”除以备餐天数，精准分配。

**肉类处理：**
- 跟米饭同步进行或提前腌制
- 推荐鸡胸肉、牛肉、虾肉（海鲜类不容易保存，要安排在前面几天吃）
- 注意生熟比：比如鸡胸肉煮熟后重量会变成原来的80%，但热量还是按照生肉来算，避免蛋白质摄入超标

**但别太纠结精确度：**
每个人的吸收率、运动消耗都有波动，食物之间的差异是客观存在的。我们能做的只是尽可能接近，永远做不到绝对精确。所以，数据更多是指导性作用，帮我们建立感知，而不是人生的全部。

**蔬菜怎么挑？**
适合一起备餐的：莴苣、山药、西兰花、胡萝卜、西芹、芦笋、笋、豆角、香菇、杏鲍菇、彩椒等——这类富含纤维、水分少的蔬菜，复热后口感依然在线。

**额外补充的生鲜蔬菜：**
黄瓜、番茄、生菜、紫甘蓝、芝麻菜、甜椒、洋葱、卷心菜、牛油果、紫苏叶等。每天随餐安排350g左右（生重），减少加工环节，保留更多营养。

**怕蔬菜热量超标？**
完全不用担心！大部分蔬菜100g才几g碳水，但要注意——土豆、玉米、黄豆、豌豆这类淀粉含量高的，必须当主食算，不能当蔬菜。

## 5. 保存：让美味多活几天

假设你一次备5天餐：

- 准备几个密封性好的餐盒（防串味、锁水分）
- 一个小型电子秤，把做好的食物均匀分成5份
- 前几天吃的放冷藏，吃的时候微波炉热2分半
- 后面几天放冷冻，提前一晚拿到冷藏解冻，第二天加热就能吃

一次性饭盒虽然便宜省事，但不环保，就不推荐了。

## 6. 你关心的几个问题，一次说清

**Q1：一次性准备这么多天，要花多久？**
一般来说2-3小时。

**Q2：肉没问题，但蔬菜隔夜不会不健康吗？**
蔬菜确实会随着时间流失营养，但备餐里加的蔬菜主要作用是丰富口感和搭配，真正的蔬菜营养来源还是在生食果蔬。另外，网上流传的“隔夜亚硝酸盐超标”其实有点吓唬人了，冷藏条件下远低于危险值，不用焦虑。

**Q3：备餐成本高吗？**
不高。我现在每周备5天餐，控制在150元以内，平均一顿只要10块钱，比外卖健康，也比外卖便宜。

# 三、进阶版：日式+膳食指南改良方案

美式备餐虽好，但对非健身人群来说门槛还是偏高。我后来发现，大多数人真正的痛点不是“不会吃”，而是“不知道该怎么吃”——知道要清淡、少油少盐，但一落到具体方案上就懵了。

所以我干脆把《中国居民膳食指南》里的每日推荐量和饮食建议，跟日式家庭备餐的做法结合起来，做成了这套“改良版”。

好处很明显：一方面食材量更好把握了，另一方面更贴近咱们的饮食习惯，操作起来也更快更顺。

## 2. 代谢的真相：你可能只算对了70%

如果你担心公式不够普适，别怕，接着说清楚。

我们每天消耗的总能量由三块组成：

**基础代谢**：占总消耗的60-70%
**身体活动**：占15-30%
**食物热效应**：占5-10%

[PRE10]

也就是说，公式算出来的那个数值，其实只覆盖了总消耗的70%左右，还有约30%的“隐形消耗”没算进去。这也是为什么我一直强调：数据是参考，不是教条。真正的智慧，是在参考的基础上，根据自己的身体反馈不断微调。
