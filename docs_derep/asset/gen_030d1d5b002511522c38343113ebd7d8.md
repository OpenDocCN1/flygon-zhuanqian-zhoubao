# 想坚持每天更新？别急着逼自己，先搞懂这套“内功+外术”

你身边有没有这样的人：年初立誓“我要日更”，结果三周后账号停更；办了张2000块的年卡，去过三次就再没现身；买了几本书，包书皮都还没拆……

其实，把一件事坚持到“不做就浑身难受”的地步，完全可行。就像每天吃饭、刷牙一样，哪需要靠毅力？关键是你有没有找对方法。

我曾问过自己社群里的老板学员：“你们觉得，开机构当老板，最有可能通向成功的习惯是什么？”

答案五花八门：

“每天招生，坚持两年，一定能成。”
“每天加10个家长私域好友，加到一万个。”
“每天发6条朋友圈。”
“每天拍一个视频。”
“每天写一篇好文章。”
“每天用心维护一个家长。”

还有人说要每天学习一小时，让自己变得更专业。

你说得都对。只要真能日拱一卒，坚持到底，时间自然会给你交代。可现实是——几乎没人能做到。

后来我又在群里抛出过一道填空题：世上____最容易，____最难？

大家的答案千奇百怪，而我的看法始终是：

我从7月3号起给自己下了道死命令：到今年12月31日前，每逢周一到周六，都要练一篇文案，把文案功夫磨出来。到写下这篇时，我已经连续练到第29篇。我非常有信心完成它，甚至到明年此刻，我依然在练。

7月22号，我又发愿：12月31日前，周一到周六，公众号日更。到今天已经写了13篇。

再往前，我去年起日更视频号，已经录了接近300条。

几乎每一个我公开说出去的“愿”，最后都稳稳落地了。

现在我每天“日拱三卒”：

1）千金文案，每日一练；
2）公众号文章，每天一篇；
3）视频号，每天一个。

这三件事做完，我才会去做别的工作。慢慢成了肌肉记忆。

我还有一些别的坚持：微信读书的365天阅读挑战，一天没落。最近又在超慢跑，每天45分钟，已经跑了30多天，不过还没固定成稳定习惯，所以暂时没对外讲。

那到底怎么才能做到真正的“日拱一卒”？我琢磨了一套方法，分“内功”和“外术”，分享给你。

**一、内功**

**1. 发自内心认为这件事重要、有意义、值得沉淀**

这是所有坚持的地基。

我为什么能维持三个日更？因为我想打造个人IP，这需要持续对外输出，而文章和视频就是最好的窗口。

我为什么死磕文案？文案是键盘背后的销售员，是一人可敌千军马的那枚炸弹。它表面是文字，骨子里是心理学、营销学、人性洞察和语言提炼。一个好的变现文案，一字千金不是夸张——我就见过朋友写200字，收了一百多万。

所以我下了决心，日日练，不敢断。

**2. 给自己一个强烈的身份感**

我会给自己一种人设：我是一个负责任的人，一个说到做到的人，一个不是半途而废的废物。

这一点太关键了。

日拱一卒到后面，其实就是自己跟自己交代。你不是为了做给别人看，不是为点赞和评论。你自己下的指令，自己许的承诺，自己来兑现。

我观察身边太多人，放弃就是因为太在意别人的反馈：阅读量好少，点赞好少，直播间在线好少，互动好少……把心力全耗在外界评价上。

如果你只是在跟自己较劲，就能完全无视这些。有，是惊喜；没有，也无所谓。我只要做到，我只要对自己说话算数。

当你真的用心输出，那些早晚会来的。

上面两点，是很多人默默放弃的根源——尤其是对自我身份的不认同。

**二、外术**

**1. 付费：让自己付出足够多的沉没成本**

想坚持一件事？最简单的办法就是花钱，而且花得越多，越不舍得停。

健身房里，花2000块买年卡的人，基本去三五次就消失了；但花200块上一节私教课的人，一周能来两三回。

我打匹克球也有同样体会。借教练的拍子练，三天打鱼两天晒网；后来自己买了好拍子、球网，还请私教，前后砸了几千块——那一阵我一周练三次，进步飞快。

练文案也一样。我付过五位数以上的学费，买了很多文案书，港台版也没放过，还加了各种付费社群。

投入够痛，才会真正死磕。

**2. 收费：把责任背到自己身上**

除了自己花钱，还可以收别人的钱。

比如我的“千金文案”每日一练，收了七八位校长每人365元，大家一起练。收了钱，我就有了责任，我会告诉自己：我是负责任的人，不能辜负。

有两回我差点破功。周六在外面玩，到睡前才想起今天的练习还没写，马上打开电脑，硬是写完才睡。

要是没这份责任在身上，我肯定就算了。

所以，收别人的费，也是倒逼自己不放弃的好招。

**3. 公众承诺：让全世界来监督你**

我日更公众号时，在社群和朋友圈公开承诺：周一到周六，只要有一天没更新，任何人可以来找我领一个不低于8.88元的红包。

我朋友圈几千人。要真断更一天，光是发红包就亏大了。

所以，把话说出去，就是把自己推向墙角，只能往前。

**4. 组队：一群人才能走得更远**

找同伴互相监督，也是好办法。最好还是付费组队——免费的打卡群，大多死得快。

**5. 给日拱一卒留够时间**

我现在有三件日拱任务，所以每天早上9点到办公室，先做这三件事：

第一件，完成每日一练；
第二件，写完公众号文章；
第三件，写好视频脚本。

我把精力最旺盛的时间段，留给我最看重的事。这本身就代表了优先级。

如果你觉得日拱一卒真的重要，就专门腾出时间给它。否则，你只是嘴上说说而已。

**6. 跟“赚钱”挂钩**

最好能把这件事和收入直接连起来，你每做一点，就有正反馈进来。

比如我练完文案，把海报发到朋友圈，就有客户直接付费进来，这就是正反馈。

比如我的公众号文章，文末挂了社群海报，有人读完就付费加入，我很爽。

比如我的视频，要么挂车，要么引导私域。

当我看到每一个动作都有真金白银的回应时，坚持的动力自然越来越猛。直到它变成一个像吃饭喝水一样自然的习惯。

到那时候，再去谈“坚持”，已经毫无意义了。
