# 1/做免费的抽奖群的好处

01造势成交。

“从众心理”大家应该都不陌生。

比如你路过一家店，看到一群人围着某个产品看，你也会忍不住凑过去瞧一瞧。

但旁边另一家店冷冷清清，一个人都没有，你大概率也不想进去。

做免费抽奖群，本质上就是制造这种“很多人关注”的氛围，把势能拉起来。

还有个关键点：用户第一次看到你的产品可能无感，第二次也无感，但看得多了，就会慢慢心动……

这就是从“发现”到“关注”，最后促成“消费”的完整链路。

02营销素材。

当大家纷纷把你的海报转发到自己朋友圈时，你就可以反复截图发在自己的朋友圈，让人觉得你很厉害。

毕竟“王婆卖瓜，自卖自夸”不太好，但借别人的嘴夸自己，效果就完全不一样了。

# 2/奖品设计和抽奖软件

01奖品设计

可能有人会问：我也想做一个免费抽奖群，但奖品该怎么设计？

接下来就说说我的思路。

一句话总结：

有关联、有实用、有种子、低成本、好交付

（不需要五个全占，但至少要有两三个以上）

奖品一定要跟你卖的产品有关联，同时要有实用性，或者具备“种子效应”，并且成本低、方便交付。

拿我这次手机摄影训练营来举例：

*   一等奖：免费的手机摄影课程名额✘2（关联性强、成本低）

*   二等奖：海盐同款手机拍照支架✘3（实用、好交付）

*   三等奖：手机摄影小白速成大师内部秘籍✘n份（种子效应、低成本、好交付）

# 8/哪些人合适做免费抽奖群

01新产品发售。

比如我们这次30天手机摄影训练营，算是第一次正式发售，属于新产品，所以非常适合用这种形式。

02获取新流量。

获取新流量有个前提：进来的门槛要低，出去的门槛要高。

什么意思呢？

比如低门槛：我们的手机摄影抽奖，每个人都可以参与。

高门槛：但兑奖的前提是必须转发朋友圈、集满8个赞截图，还要找我登记，否则中奖了也不给兑。

这一点要在抽奖链接里写清楚，并且在抽奖开始时就说明，否则等中奖了才说，别人会觉得你在扯皮、没信用。

03增加营销素材。

有人说过：如果你想去某个地方，不要急着造船，先找到一群也想去那里的人，然后一起出发。

我们这次有57个人参与，真正转发朋友圈的差不多有30多个，大概一半。这样一来，我发朋友圈的素材就很多了，再怎么也比我自己一个人在那儿埋头发强吧。

# 9/做免费抽奖群的注意事项

01不需要做什么创新，只要动作执行到位。

很多时候做事别总想创新，前期最重要的就是把别人的步骤执行到位，这样你就能达到70%以上的效果。

02每个社群都有自己的生命周期和使命。

免费抽奖群一般维持3～7天，如果任务完成、使命达成，就可以解散了，留着也没用，还会影响后续体验感。

[PRE19]

03群公告声明写好：不能互加好友，否则永久拉黑或踢出社群。

这个动作不可能保证每个人都遵守，但至少能保证90%的人不乱来；如果没有这条声明，可能连这个比例都达不到。

免费群一般不给加好友，付费群才可以。

这就好比开车时看到栏杆上写着“撞坏需赔多少钱”，司机看到就会更谨慎，因为明确知道要付出的代价。所以这一步就是把代价明码标价标出来。

04前期每天引导一次大家发圈，后期每天引导三次。

前期可以中午或晚上发1～2次，引导大家发朋友圈就够了。

到了最后两天，要增加频率，大概3～5次以上。
