# 五、实操拆解

从开始做到赚钱，一共五步：注册账号、账号包装、内容制作、上架课程、开始赚钱。每一步都可以流程化，最重要是内容制作，但按方法学，1-2小时内能掌握。

## 1. 注册账号

没啥难度。可以直接注册新号，也可以用老号开个子账号。这个方向挂课不要求实名认证，所以新号老号都无所谓。[PRE16][PRE17][PRE18]

## 2. 账号包装

在DY搜“天选之人”，找一个近期还在更新的账号，看他的首页介绍、头像和背景图，照葫芦画瓢改成自己的。头像和背景图可以用MJ生成，昵称取个跟觉醒有关或看起来像大师的，简介就让GPT写。最好各平台都注册起来。[PRE19][PRE20][PRE21]

## 3. 内容制作

分为五个小环节：找参考、提取文案、GPT改写、机器配音、剪映合成。

先搜“天选之人”，找点赞过千的视频。然后提取文案。我们本来想买轻抖的企业版，因为可以批量提取，但价格太贵，就没买。朋友强强自己开发了批量提取工具，之前还有批量加好友的工具，自己用很顺手。有需要的圈友找我拿就行。

接着交给GPT改写，注意：只改中间部分，开头第1、2句和末尾2句都不要动。全改会丢掉免费流量，不改又容易被判抄袭。GPT给的内容可以直接用。[PRE22][PRE23]

然后配音，微信搜配音小程序，随便开一个，把文案粘进去。这类视频常用的音色是“麦克阿瑟”或“云泽”，不同小程序叫法不同，自己试听就好。[PRE24][PRE25]

最后用剪映合成，记得加BGM，纯音乐、热门都行，或者直接学参考视频用什么音乐，但注意音量别盖过配音。

## 4. 上架课程

这步很简单。去搜“易知课堂”官网，注册讲师账号，绑定你的DY、KS、视频号，设置提现账户，添加课程，就完成了。不会的话直接问客服，也可以把问题列出来找我。快速入驻链接：https://author.yizhiknow.com/login/register?up_agent_id=53922 记得和商务说是樾樾老师介绍来的，我来安排。[PRE26][PRE27][PRE28]

## 5. 开始赚钱

在这个平台挂课不需要实名认证，这点对铺号非常友好。一个领域想赚得更多，一定要铺号，一定要能复制。

先在DY搜“易知课堂”小程序，搜不到就多搜几次，比如搜“易知课堂小程序入口”，偶尔会有bug。[PRE29]

进小程序后点“个人中心”。如果第四步注册和绑定都完成了，这里会出现“我的讲师”入口。没有的话，回官网重新绑定课程。[PRE30]

然后进入“我的讲师”，点“分销课程”，配置好挂载货架，再挂载课程。以99元课为例，点进课程详情页，右上角三个点“...”，点开后有“拍DY”入口。选择制作好的视频，进入发布界面，会自动带上这个小程序。加上话题标签，比如觉醒开悟、认知觉醒、认知提升，写个标题直接发布。熟练后，一条视频从剪辑到发布10分钟能搞定。[PRE31][PRE32][PRE33]

发完几分钟后，用抖加测试一下能不能投。不用真投，只看能不能过审。能加热就是过审了，不能加热会提示原因，那就隐藏或删掉，重新改文案或换素材。[PRE34][PRE35][PRE36][PRE37]

最后还有一个提升出单的小动作：在评论区发一条置顶评论。把买课入口截图做成表情包，在评论里发这个表情包再加一句话，然后置顶。很多人刷到视频后不知道哪里买课，这个提醒我们试过，不会被限制。细节做到位，出单量差很多。[PRE38]
