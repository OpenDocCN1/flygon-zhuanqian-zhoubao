## 全流程拆解：从0到1的六步闭环

整个流程其实不复杂，一共六步：测号 → 开店 → 选品 → 上架商品 → 制作笔记 → 发布笔记，后面还有一些必做的设置选项。

### 第一步：测号，别急着上手

先说几个硬性规则：

一个身份证只能开通一个专业号（个人身份）和一个个人店。一个营业执照可以开2个专业号（企业专业号600一年）加2个店铺。多说一句，一个人名下的执照好像最多能搞5个执照、开10家店。

个人身份只能开一家店。想开个体店的话，得先把个人店转成个体店。个人店和自己的个体店不能同时存在。

专业号需要实名，普通号不用。小红书店铺必须绑定一个专业号，所以开店之前，你手上得先有个正常的小红书账号。

什么叫正常账号？两点：一是注册手机卡得是正规运营商的，三大营业厅的厅卡最稳，其次是有通话功能的大流量卡（物联卡别碰），0月租卡千万别用。二是账号没有违规记录。

检测方法很简单：我 → 创作者中心 → 左上角我的账号 → 账号诊断，按流程走一遍就行。

老号无违规基本都能测。还不放心的话，就发几个容易引发互动的日常帖子试试水，比如问“放假去哪儿玩”“最近有什么好电影推荐”，连续发个几条，观察数据和互动情况。

再教大家一招：随便发一篇笔记，看能不能进薯条投放页面。能进去就是正常号。要是笔记内容和别人重复度过高，也会显示无法投放，平台不会告诉你原因，这个我自己踩过坑。

还有一个批量查询方法：创作者中心 → 全部服务 → 薯条推广 → 选择笔记或滑动笔记。不在列表里的笔记，就是没法投放的。

新号注册好就能直接测试，没有“养号”那套玄学。但注意，测号很重要——做虚拟电商第一步就是测号，这步出了问题，后面全白搭。

### 第二步：开店流程

**手机端操作路径：** 创作者中心 → 全部服务 → 开通店铺，按提示来。

**电脑端操作路径：** 搜索“小红书千帆”，或者直接通过官方链接登录。

**注意这三点：**

选“个人身份”入驻，提交资料后基本秒过审核。但选账号时一定要慎重——一个人只能认证一个个人店，随便拿个账号去申请，浪费了名额就可惜了。

如果你是开个体店，店铺名称默认跟着专业号走，格式是“昵称+的店”。想改名？可以，重新交600。所以起名前想清楚。个人店反而能改，一周一次，改了昵称店名也跟着变。

店铺公示信息里，地址写附近就行，不用写真地址。经营资质选“个人从事零星小额交易活动”。物流信息随便填一个就行。

类目选“电子资料包”，后续单个商品也要设置独立类目，不影响。

小提醒：有些类目需要额外资质才能选，市场上有人花几十到100块代开，但我目前没这个需求，前期大家也暂时不用考虑。

**开店之后必做动作：**

支付方式一定要去开通，支付宝、微信能开都开。开通后不会有任何弹窗提醒，需要你自己去后台手动点击确认才会生效。

路径：小红书千帆后台 → 店铺 → 店铺管理 → 支付方式 → 去开通。微信支付的主营类目选“零售批发/生活娱乐/其他”。

### 第三步：选品，别想太多，怼就完了

很多人一听虚拟电商就问“选品教不教”。我们不选蓝海品——我们靠大量上品，找出真正适合自己账号的那个“天命真品”。

我们总结了一套四阶段打法，客单价9.9：

**第一阶段：大量上品（预期7天左右出效果）**
铺大量不同类型的品上去测试，总有一些会出单。转化率不错、持续出单的，就是你的天命真品。

**第二阶段：聚焦垂直品（预期7-15天）**
其他品不再管，只做那个验证过能持续出单的品。可以是一类，也可以是几类。

**第三阶段：优化垂直品（预期30-60天）**
把垂直品铺到极限，不出单的品继续发笔记。

**第四阶段：彻底放手（预期30-60天）**
店铺 + 账号完全脱手，每天自动出单。

这套玩法对新手老手都友好：新手一个店可以狂铺笔记，每天30个以内没问题；老手可以多店铺放大操作。

**核心就一句话：多店铺多上品多发笔记，吃小红书的长尾搜索流量。**

注意，我们这一套是做**搜索流量**，不是推荐流量。推荐流量10%的人能跑出结果就算不错了，但搜索流量只要照做，90%的人能起来。

我自己账号的流量来源，全部都是搜索。上图中能看到基本产出都来自搜索，而且几个月前发的笔记还在稳定出单。

这正好说明了小红书虚拟电商和淘宝、拼多多最大的区别：这里主要靠**笔记带动销量**，而不是商品页。笔记在小红书的搜索占比极高——这也就是为什么我们做SEO的宁愿死磕笔记而不是视频。

顺便说一句，新手发笔记一周就有几千曝光，笔记中心的“成长任务”一定要去领取。

### 第四步：词根找品 + AI筛选

SEO玩法的第一步，是找到合适的词根。比如“模板”“合同”“PPT”这些。然后顺着这些词去挖掘相关虚拟产品。

**注意：尽量不碰版权风险高的词根，比如“教程”“课程”、人名、机构名这些。**

我们整理出了几类词根：

- 一类词根：课件、资料、话术、策划、方案、协议范本、劳动合同、报表、白皮书、各类报告、实操手册、活动策划、展板、流程图、开业创业、门店运营、充卡活动、员工招聘等等（基本都是日常商业场景需要的内容）
- 二类词根：配方、软件、课程、考试、小吃、编程、炒股、摄影、造价、烘焙、瑜伽、PLC、数控、游戏、少儿、绘画、健身、心得体会等等
- 三类词根：制作、装修、制图、设计、模板、素材、剪辑、短视频、简历、PPT、企业培训、商业计划书、画册、标书、插画、建模、特效、BGM等

给大家的建议：用AI做初筛。我用的是DeepSeek做演示，实际自己用的是Claude或GPT。提示词别照抄我的，我那是随手写的，根据自己的理解详细描述需求就行。AI非常好用，后面写笔记文案也要靠它。

### 第五步：注意虚拟资料的时效性

有些品是有“保质期”的。比如暑假老师放假了，班会课件、家长会PPT的需求会大幅下降；年终总结一定是年底才有人找。

不知道怎么判断？直接复制商品信息问AI：“这类商品现在（2025年7月）还有需求吗？好卖吗？”让AI帮你判断。

### 第六步：词根挖词根

**方法一：通过商品进店铺**

搜索“模板”，不看代做的，点进一个商品 → 进入店铺 → 你能看到大量带着关键词的商品标题。淘宝本身就是吃搜索流的平台，所以商品标题里一定有词根。多复制几个店铺的页面截图，发给AI让它帮你筛选。

**方法二：直接进店铺**

直接在搜索结果页点“店铺”，会列出很多相关店铺。点进去，左侧就是商品分类，一眼扫过去，全是虚拟品分类，灵感就这么来了。
