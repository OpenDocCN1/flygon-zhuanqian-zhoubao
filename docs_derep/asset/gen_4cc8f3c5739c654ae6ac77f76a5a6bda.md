# 商标注册别再乱选类目了！这份1-26类分类速览请收好

很多朋友在申请商标时，最头疼的就是“该选哪个类别”“商品项目怎么填”。其实只要搞懂分类表的逻辑，这事儿一点儿也不难。今天咱们就用大白话，把商标分类里的门道讲清楚，再附上1-26类的核心覆盖范围，让你一次看明白。

## 挑选类别前，先记住这三个原则

**第一，想清楚你的商标到底用在哪。** 是卖产品还是做服务？是实体商品还是线上平台？先锁定核心使用场景，再对应到具体类别（可以同时选多个类）。

**第二，落到具体的商品/服务项目上。** 别只盯着大类名称，要看你实际销售的商品或提供的服务，属于哪个分类下的细分项目。

**第三，别忘了“防御性保护”。** 在同一大类里，如果有些群组虽然你现在用不到，但可能被他人“蹭车”，也可以一并注册，防止被抢注。

## 一个特别提醒：别用类名或群组名代替具体项目

比如第十一类的大类名叫“照明、加热、冷却、蒸汽发生、烹饪、干燥、通风、供水以及卫生用装置和设备”，但你注册时不能直接填这个，也不能写“1101照明用设备、器具”这个群组标题，而是要选群组下面的具体商品，像“灯泡”这种。
