做这几款小产品的过程里，我踩了不少坑，也慢慢跑通了一些事。先说第一个产品遇到的几个问题。小程序想直连后端却被白名单卡住，我的解决方案是加一层中转：请求先打到 Vercel，由 Vercel 再去访问 Supabase，这样就把限制绕开了。第二个坑是登录状态不稳定，早期 Token 有效期设得太短，用户隔几天就发现数据对不上，还以为是产品出了 bug，其实是会话过期。后来我补上了自动续期，让用户在毫无感知的情况下完成刷新。第三个坑是自定义标签不保存，用户设置好的时间块标签，下次打开就没了，直到好几个用户反馈我才发现，原来是本地缓存没有做持久化。

再说说这款产品的付费转化。逻辑其实很简单：免费体验的时间越长，用户积累的数据就越深，自然会需要云同步、去广告、AI 洞察、数据分析这些高级能力。这些功能免费用户用不了，但一旦用顺了就会想解锁，所以转化不需要刻意推销。这也是一款有复利效应的产品，我只要持续分享时间管理方法，就会不断有人发现它、成为用户、再到付费。最初做它的时候完全没想过赚钱，只是自己缺一个顺手的工具。后来它还成了工作台和 Obsidian 插件里很重要的一环，承担起了时间可视化的功能。

### 3.2 审美实验室：原创治愈头像壁纸

这个产品属于内容型，2026 年 4 月上线，变现来源是图片下载授权费、广告和创作者分成。

起因是我有点“懒”。之前运营治愈系爷爷奶奶赛道时，我给自己开了个小号“周小白审美实验室”，专门发自己喜欢的原创 AI 插画——不是老爷爷老奶奶那种，而是更个人化的风格，比如治愈系女孩、油画感、日系氛围。慢慢就有粉丝来要图。刚开始我还一张张认真找，后来发现翻图太消耗时间和心情。我本质上喜欢艺术、安静、思考、创造，很讨厌商务沟通和反复回消息。于是干脆想：不如做一个小程序，让粉丝自己来找图、选图、下载，不用再来找我。另一个原因是过去的商业授权流程太麻烦：合作方发需求、我找图、截图确认、转账，一圈圈来回沟通，效率极低。

[PRE3]

有了小程序之后，逻辑就变了：我直接发链接过去，对方自己看、自己选，商用就付商用的价格，全程不需要找我。处理“求图”这件事的时间成本一下子降了下来。

[PRE4]

核心功能包括：精选插画图库，可以按女生头像、治愈风景、油画感等分类浏览；多维度筛选，快速找到想要的风格；解锁下载，免费图直接下，付费图要购买或开会员；商业授权区分个人和商用，价格不同。技术栈是微信原生小程序加 Supabase，最大的设计决策是把图片 URL 存在 Supabase，小程序只做纯展示，零存储成本。图片放在 Storage Bucket 里走公开 CDN，小程序直接引用 URL，完全免费。

但这里也有一个让我调了很久的 bug：setData 的顺序错了，扣费逻辑就会失效。用户点击下载，应该先判断余额够不够、扣费、再标记这张图已解锁。我当时的代码是先 setData 标记图片状态，再读取状态做判断。可 setData 是同步的，调用完立刻生效，后面读到的已经是新值，逻辑判断就出错了，扣费也就没生效。正确做法是先读旧值完成判断和业务处理，最后再 setData 标记状态。顺序这件事，踩过一次就印象深刻。

#### 商业模式升级：从创作者到平台运营者

这是审美实验室里最有想象力、也是最有含金量的一部分。很多 AI 插画博主有内容、有粉丝群体，但不会做小程序，或者觉得做起来复杂、学起来慢。她们缺的只是一个能帮自己变现的基础设施。我的计划是：把小程序变成创作平台和变现平台。逻辑是：创作者入驻后把自己的 AI 插画上传到图库，用户付费下载或购买商业授权，创作者拿 70%，平台拿 30%，再邀请更多创作者进来，慢慢形成网络效应。简单说，就是从“一个人做内容”变成“帮一群人变现”。

目前第一批创作者已经有 20 人入驻，入驻费 99 元一次性，包含排版工具使用权和图库上传资格，审核通过后永久有效。这不是课程也不是培训，本质上是“工具使用费 + 创作者身份”。如果发现做不下去，工具随时可以不用，也没有后续费用。结合我的 AI 治愈系插画课程，整个逻辑可以从教生图开始，到培养学员，再到帮学员实现小程序和公众号流量主的双重收益。过程不痛苦，工具也容易操作，一个人运营几个甚至几十个账号都很轻松。

### 3.3 周小白创作助手：内容生产与分发工具

这是一个内容生产与分发工具，核心价值是：选文案、选图片，一键生成治愈图文和视频。它不是那种通用的公众号排版工具，而是从我的“治愈系汤婆婆”账号里自然长出来的一套自动化生产工具。那个账号有 3 万多粉丝，我每天真正重复的动作不是写一篇文章，而是从文案、IP、图片风格一路生成可以直接发布的治愈图文和视频。

为什么会有这个工具？做了审美实验室之后，我遇到了新的问题：流量从哪里来？喜欢我图的用户都在小红书和公众号里，所以我需要持续更新公众号，把读者引到小程序。但我当时有 7 个公众号。传统的更新流程是：打开电脑、登录后台、上传图片、手动排版、想标题、存草稿、再打开下一个公众号重复一遍。7 个号更新一轮，一下午就没了。而且我不想两头维护：文章里的图如果小程序里没有，用户点了跳不过去，又会来找我要图。于是我冒出一个想法：能不能做一个工具，我只要点点点，就可以排版并发送到所有公众号草稿箱，同时把图片同步到小程序图库？这个需求，直接推动我开发了第三个产品。

核心功能有：一键排版公众号文章，支持图文模式和文章模式；内置 90 多个爆款标题库，一键“换一批”；图片自动裁切成正方形，版式统一；推送草稿到多个授权账号；图片自动绑定小程序跳转链接；还能上传图片到审美实验室图库。技术栈是 Next.js 16、TypeScript、Tailwind CSS、Supabase、Vercel，再加上微信第三方平台。

这里要解释一下“微信第三方平台”。普通的公众号工具，只能操作自己的账号。想帮其他人的公众号推送草稿，就需要申请微信第三方平台资质——相当于拿到一种“代理权”，用户授权之后，工具可以代为操作他们的公众号。这个资质只有企业能申请。我为此注册了企业营业执照，审核流程很复杂，提交了 3 次才过。但企业资质也顺带解决了一个大问题：打通了安卓和苹果的支付。个人认证的小程序，在 iOS 端的虚拟商品支付限制很多；企业认证之后走合规支付路径，安卓和苹果都能正常付款。这是企业认证最重要的隐形价值。

[PRE11]

现在我更新 7 个公众号的流程是这样的：手机打开排版工具，从审美实验室图库选一张图，或者自己上传一张；点“换一批”选一个标题；选一个模板；图片自动裁切并绑定小程序链接；然后推送到草稿箱；再切换下一个账号继续。全程不需要写任何一个字。标题是“换一批”换来的，文案是“换一批”换来的，图片直接从图库里点选。整个过程 10 到 15 分钟，7 个号全部推完。

这个产品踩的坑也最多。第一个坑：微信 API 需要固定 IP 白名单，但 Vercel 是动态 IP。Vercel 的 Serverless Functions 每次请求的 IP 都不一样，微信 API 又不认。解决方案是买一台腾讯云服务器做中转，请求先打到固定 IP 的服务器，再转发给微信 API。多了一层中转，但问题解决了。第二个坑：wx.showModal 的按钮文字超过 4 个字，在 iOS 上会静默失败。安卓一切正常，iOS 却完全没有反应，也没有任何报错。排查了很久才发现，解决方案是把所有按钮文字严格控制在 4 个字以内。第三个坑：微信邮件的 HTML 会过滤 position: absolute。我做了一个叠层效果，本地预览一切正常，推到公众号之后层却消失了。后来改用负 margin 实现叠层，这才绕过过滤。这三个坑都属于“做到那里才发现”的，事先完全不知道，但每次把问题描述给 AI，基本都能很快找到解法。

把整个商业闭环串起来看就是：创作者把公众号授权给排版工具，用工具一键更新所有账号，文章里的图片自动绑定审美实验室链接，读者看文章点图跳进小程序，在小程序里浏览、下载、付费，广告收益和授权收益再按比例分成。全程自动化，零人工干预。这就是我想做的事：从“一个人做内容”变成“一套系统自动跑”。

## 四、壁纸号 + 小程序：上班族最省力的变现组合

[PRE13]

这一章我选择单独拆开讲，因为不是所有人都想做小程序。做小程序确实有门槛、有成本、有学习曲线。但如果你只是想找一个能稳定产生收入的副业，在我看来，上班族最容易跑通的组合就是“壁纸号 + 小程序”，没有之一。而且这两件事不需要同时做，你可以先把壁纸号跑起来，等它有起色了，再考虑入驻图库或者自己搭小程序。

### 4.1 为什么壁纸号特别适合上班族

先理清逻辑：公众号流量主就是拿阅读量换钱。壁纸号的特别之处在于，用户通常会在图片之间来回滑动，待的时间越长，广告曝光就越充分，eCPM 也就越高。根据公开资料，壁纸号平均 CPM 在 20 元左右，做得好的账号，单篇 5000 阅读收益能到数百元。

和文章号相比，壁纸号的优势很明显：创作成本低，只是选图加标题，不需要写作能力；起号速度快；日更压力小，图片可以批量备好；粉丝黏性靠审美和风格，而不是 IP 和观点；单篇爆款空间属于稳定型，不容易爆但也很难崩；特别适合碎片时间。对上班族来说，最大的优势就是时间成本低。选好图、配个标题，10 分钟就能发出去。通勤路上能做，午休能做，睡前也能做，一部手机就足够。我有个朋友的真实数据是：开号半个月开通流量主，3 个月累计收入 1556 元。

### 4.2 壁纸图从哪里来

这是被问到最多的问题。图片来源有三种，推荐程度完全不同。

最推荐的是 AI 自生图。工具可以用 Midjourney、即梦、豆包等，优势是版权清晰、风格可控、能长期做。用 MJ 批量出图非常快，点一下就能生成 4 张。我移动硬盘里现在存了 4000 多张，够更新一整年，还能持续变现。我日常就是手机点点点，批量生成，挑出质量好的存起来，攒到 200 张再开始发号。这个“弹药库”的思路很重要，起号之前先备好 200 张，就不会因为图不够而中途断更。

次选是自己找图，主要用来纯养号。在微博、小红书搜关键词收藏就可以。但要注意，后期如果要做商业变现，比如接广告、卖账号、卖图片版权，这类图会有版权风险，比较适合先用它把流程跑通。

最不推荐的是搬运其他账号的图。平台识别出重复图会限流，严重的会封号。有人把我小红书的图搬到公众号去发，后来我就关了下设置。这件事也让我有另一个思考：与其被人复制搬运，不如我自己主动把图铺到更多平台，扩大影响力。你看 HelloKitty、机器猫、米老鼠，哪个 IP 的图不是被传来传去的？被搬运，其实也是一种审美的认可。

### 4.3 风格选择：起号最关键的一步

这一步比选图、写标题都重要。风格定不下来，后面所有动作都白费。原因是微信推荐算法是看内容标签的：你每次发的内容风格一致，平台打的标签就准确，推给对的人，点击率就高，然后继续推荐。反过来，今天治愈、明天国风、后天暗黑，标签混乱，平台不知道推给谁，流量自然就卡住了。所以，账号必须咬死一种风格，这是铁律。

主流风格可以参考这些：治愈系插画，面向 20-30 岁女性，柔和色调、花朵植物、女孩形象，推荐度两星；国风水墨，面向文艺青年，中式元素、山水、汉服，三星；暗黑系，面向年轻男性，高饱和、赛博朋克、动漫，三星；极简纯色，通用型，单色或渐变加简约文字，一星；萌宠治愈，面向养宠群体，猫狗拟人化、温馨日常，两星；星空宇宙，面向学生和泛人群，星辰、银河、月亮，两星；氛围感风景，面向文艺青年，清晨、夕阳、咖啡馆，两星。

选风格有三条原则。第一，选你自己也喜欢的，那种能刷图刷一下午都不累的风格。做壁纸号是长期主义，不喜欢的话连 3 个月都撑不过去。第二，选有持续产出空间的。你选“梵高向日葵同款”，图库很快就会枯竭；选“治愈插画女孩”，AI 却能给你生出无限张。第三，选目标人群清晰的，越垂直越有利。“女生头像”比“好看的图”定位更准，而“古典女孩油画风”又比“女生头像”还要精细。

#### 不确定选哪种怎么办？
