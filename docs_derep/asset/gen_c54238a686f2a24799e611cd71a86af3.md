普通社恐女孩也能无压力参加生财见面会？我的复盘与实操建议

说实话，这篇总结直到现在才动笔。周六的活动已经过去，但我迟迟没写。

不是没时间，而是担心自己写的东西对多数人没参考价值——毕竟不少人都已经走得很远了。假如你是位大佬，看到这里可以直接滑到最下面点个赞，内容可以略过。

但如果你也和我一样，可能连起点都还没踩上，那我的经历也许能给你一点参考。

我也信“越分享越幸运”，但总不能光写流水账，该争取的还得争取。所以我坦白，写这篇有三个目的：第一，想碰碰运气拿龙珠；第二，想攒个碎片；第三，想攒到100个赞——要是做到了，下篇主题都已经想好。

之前读过很多大佬的见面会复盘，篇篇精细，角度也高。只是，那些内容并不像一个普通人的视角。我没有耀眼的成绩，没有影响力，还是个妥妥的社恐。

当然我也懂，提前做好功课、熟悉背景、准备话题、列好问题、再好好打扮，见面会的收获一定更大。可如果我就是普通、就是社恐，也完全不知道聊什么，那又该怎么办？

# 一、普通人为什么非去不可？

如果你看过足够多的复盘，会发现大家参加见面会的理由其实就两种：要么是受邀嘉宾，答应别人了不好意思不去；要么是有明确目的，想链接大佬、学习或扩大自己的影响力。

但如果你既不是嘉宾也不是大V，没钱没人脉，人还特别怕社交，是不是就没必要去了？

不，恰恰因为你的普通、不起眼、什么都没有，你才更该去。

因为你需要给生活找一点刺激。这就像很多关系变得乏味，是因为旧有的刺激已经不起作用了。你必须主动寻找新的感受，才可能重新体会那种心动的瞬间。

见面会，就是很好的刺激。哪怕只是安静地坐在一边，看着现场的帅哥美女，心情也会变好，说不定还能延年益寿。

靠近美，欣赏美，你才可能成为美。

相信我。

# 二、普通人能收获什么？

目标模糊也没关系，情绪普通也无所谓。你不会准备问题，不了解参会人画像，也不擅长分享，但你完全可以“看”。

无论聚会规模大小，你都可以看看一场成功的见面会是怎么组织起来的：需要哪些人？流程如何推进？主持人准备了什么？时间怎么控制？有多少人留到最后？这些问题，只有去了现场才有答案。听别人讲和自己找答案，完全是两个难度。

这就像听别人创业和自己创业，差的不是一点半点。你完全可以把一次见面会当成最小成本的创业尝试。

自信从哪来？就是从一次次微小的成功里攒出来的。我第一次参加龙珠见面会时，全程都在看，很多地方不懂，但内心深受震撼。这次线下活动，主持人准备了一个计时沙漏，既解决了超时问题又不会让分享者难堪——我看到时整个人都服了。

而且，作为一个社恐，你一定能发现别人参加聚会的方式和自己不一样。他们的收获远远不止吃顿饭、发个朋友圈。也许你一时改不了，但没关系，你这次的目标是寻找刺激，不是逼自己改变。当刺激足够强烈，改变自然会找上门。

# 三、社恐如何轻松参与？

**第一，提前半小时到场。**
为什么把它放在第一位？因为它实在太重要了。
提前到，你可以先熟悉环境，看看周围有哪些物品和路线，找到能让自己放松的角落。还能提前认识主持人和小伙伴：如果主持也早到，你就有机会先聊几句，就当暖场；如果主持迟到，你反而能收获他的歉意。提前到也可能会给主持人带来一点小“麻烦”，但放心，对方不会介意。
最重要的是，见面会正式开始时，你已经不觉得陌生了。
另外，提前到场也不会因为迟到而尴尬，特别在小局里，迟到真的很明显。如果你是路痴，这半小时更是救命的缓冲。

**第二，准备一份小礼物。**
不用贵重，能力范围内就可以。小局可以人手一份，大局可以在道谢时送出。
选择可以很丰富：小多肉，好看好养又容易带；一支有特色的笔，预算够可以送钢笔；一本书，适合小局；一枚书签，附上手写寄语和签名；油画贺卡；护手霜；手账本；小挂件；家乡特产……
核心原则很简单：东西要小巧精致、轻便易带，最关键的是有心意。
你们大概率第一次见，别给彼此太大负担。小东西能体现你的审美或个性，最好还容易常被看到，这样对方用着用着就想起你。

**第三，提前准备一份个人信息。**
名片也好，简短的自我介绍也好。加了微信或换联系方式时，别人能立刻知道你是谁，你也不会慌乱。

# 四、这次4人小局的收获

这次我特意选了一个人少的局，结果刚好4个人。特别感谢肉壹组局——是一位年轻、善谈、优秀又帅气的小哥哥。英语口语流利到让我惊讶，还手握一堆英语专业类证书，事业上也称得上多面手。听说他两分钟就能加到陌生男生的微信，真是又准又猛，我当场就服了。

阿葵，就是传说中的“别人家的女朋友”。像电视剧里走出来的角色，漂亮、温柔、大方、得体。站在她身边，你会觉得自己就像路灯，她像月亮，连说话都不敢太大声，怕暴露自己的粗心。

苏菲，英文名Sophie，寓意智慧。她本人也确实是智慧担当：活力四射、思路清晰、从容不迫，聊起来让人特别舒服。

8个人可能会嫌多，但4个人刚刚好。每个人都沉浸其中，能感受到真诚和开放，也能看到未来的各种可能。

见面会虽然结束，我们的新故事，才刚刚开始。
