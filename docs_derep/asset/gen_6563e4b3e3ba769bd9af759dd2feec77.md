# 到底什么样的事情，才值得我们投入时间？

很多时候，我们并不是不努力，而是把精力用在了不够重要的地方。

每天不妨留出一点时间，反复问自己几个问题：

我正在做的事，真的有价值吗？  
它会对结果产生关键影响吗？  
这是当下最重要的事情吗？  
它背后的底层规律是什么？  
如果回到第一性原理，这件事还成立吗？  
它是否符合最基本、最朴素的常识？

这些问题看似简单，却能帮助我们从忙碌中抽离出来，重新判断方向。

真正重要的选择，往往伴随着取舍。

当你决定把时间投入一个目标，就意味着必须放下另一些事情：无效社交、低价值忙碌、暂时的娱乐，甚至是那些看起来不错、但与核心目标无关的机会。

所以还要继续追问：

为了做成真正重要的事，我已经放弃了什么？  
这些舍弃，究竟够不够彻底？

选择通常比努力更重要。每天做与目标直接相关的事，少一些徒劳的勤奋，多一些清醒的判断，才更有可能走到真正想去的地方。

把这段话留给自己，忙碌之前，先确认方向；行动之前，先确认价值。
