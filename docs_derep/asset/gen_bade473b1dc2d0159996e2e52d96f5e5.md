# 一场和陌生人的晨间复盘，持续了540天，给了我上千万的体感价值

> 原文：[`www.yuque.com/for_lazy/thfiu8/icgtn0rysn2gg894`](https://www.yuque.com/for_lazy/thfiu8/icgtn0rysn2gg894)

刚从西藏回来，身体还在高反里犯困，闹钟却准时叫我上线。今天又赶完了一次每周的早会。我算了下，从2022年7月算起，这个和陌生伙伴一起的晨间分享复盘，已经雷打不动地开了五百多天。

凌晨两点结束爬宠直播，六点半准时亮灯开会。大年初一也在线上打卡报到。每天和几个人互道早安，把过去一周的得失掰开揉碎讲一遍。听起来很日常，但就是这件小事，慢慢把我脑子里乱成一团的想法理顺了。我开始真正拥有了“自己的时间”，生活不再被纯粹的赚钱绑架，反而打开了更多意想不到的突破口。

今天想聊的，就是这场早会这些年对我的改变。表面上看和变现没太大关联，实则牵扯极深，一环扣一环。

如果跟生财里的大多数人比，我的赛道真的土得掉渣，传统行业里摸爬滚打。正是这场晨间复盘，把我一点点推向了互联网转型。要是按爆款写法，我得堆一堆数字来证明，但说真的，过去一年多的收获已经不是钱能简单量化的了。赶时间的朋友直接看我加粗标红的部分就够了，剩下的都当闲聊。

这条路一点也不浪漫。五百多天里，我烦躁过、发火过、想直接消失不参加的次数数不清。可坚持本身就是一种力量。相信我，任何一件看似微不足道的小事，咬牙做到位，都会变得很不凡。连每天按时吃饭这种事，都能成为自律的开始。
