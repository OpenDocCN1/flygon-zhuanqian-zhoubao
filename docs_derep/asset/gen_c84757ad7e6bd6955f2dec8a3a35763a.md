# 五、具体操作

从开始到变现，分成五步：注册账号、账号包装、内容制作、上架课程、开始赚钱。全部可以流程化，最重要的是内容制作，但按方法最多1-2小时就能掌握。

## 1. 注册账号

直接注册新抖音号，或者用老号创建辅助账号。这个赛道挂课变现不需要实名认证，所以老号、新号都可以。 [PRE16][PRE17][PRE18]

## 2. 账号包装

在抖音搜“天选之人”，找一个近期更新的账号，看它的首页介绍、头像、背景图，照着改成自己的。头像和背景图可以用MJ生成，昵称取一个跟觉醒有关或“看起来像大师”的，简介交给GPT。最好多平台一起注册，抖、视、快、红都弄起来。 [PRE19][PRE20][PRE21]

## 3. 内容制作

流程是对标搜集、内容处理、视频素材、AI配音、合成剪辑。具体如下：

1. 搜“天选之人”，找点赞过千的对标视频。
2. 提取文案。我们本来想买轻抖企业版批量提取，但太贵。伙伴强强自己开发了批量提取文案的工具，之前还有批量加好友工具，自用非常丝滑，需要的可以找我。
3. 交给GPT仿写。注意只改写中间部分，开头第1、2句和末尾2句不要改，否则容易被判抄袭，但全改又会失去自然流量效果。GPT生成后可直接用。 [PRE22][PRE23]
4. 在微信搜配音小程序，把文案粘贴进去。常用音色是“麦克阿瑟”或“云泽”，不同小程序叫法不同，可以试听。 [PRE24][PRE25]
5. 用剪映合成素材，别忘了加背景音乐，用纯音乐、热门BGM或对标视频同款音乐，但不要盖过人声。

## 4. 上架课程

搜“易知课堂”官网，注册讲师账号，绑定抖音、快手、视频号，设置提现账户，添加课程即可。不懂的直接问客服，也可以列出问题来找我。快速入驻链接：https://author.yizhiknow.com/login/register?up_agent_id=53922 告知商务是樾樾老师来的，我帮安排好一切。 [PRE26][PRE27][PRE28]

## 5. 开始赚钱

上架后就可以挂课了。易知课堂挂课不需要实名认证，这对矩阵放大非常友好。一个赛道想做出更高变现，就一定要做矩阵，能复制。

1. 在抖音搜“易知课堂”小程序，搜不到就多搜几次“易知课堂小程序入口”，有时有bug。 [PRE29]
2. 进入小程序，点个人中心。如果第四步注册和绑定都完成了，这里会出现“我的讲师”入口。没有的话，回易知课堂重新绑定课程。 [PRE30]
3. 进入“我的讲师”，点“分销课程”，配置挂载货架，然后挂载课程，以99元课为例。点进去后点右上角三个点“...”，会出现“拍抖音”入口，选择做好的视频，进入发布界面，会带上易知课堂小程序。加话题标签，如觉醒开悟、认知觉醒、认知提升，写标题直接发布。熟练后，一条视频从剪辑到发布10分钟搞定。 [PRE31][PRE32][PRE33]
4. 发布几分钟后，用抖加加热检查能否投出去。不用真投，只测试是否过审。能加热就是过审了，不能加热会给出原因，隐藏或删掉这条视频重做。按提示改文案或换素材。 [PRE34][PRE35][PRE36][PRE37]
5. 引导出单。发布后可以写一条置顶评论，把买课入口截图做成抖音表情包，在评论区用表情包加一句话，然后置顶。很多刷到视频的人不知道如何买课，这个提醒不受抖音限制。细节做到位，出单量会明显增加。 [PRE38]

# 六、项目复盘
