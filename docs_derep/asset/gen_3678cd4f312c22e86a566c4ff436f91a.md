# 大跌也挡不住！“木头姐”两天猛掏超5000万美元抄底特斯拉

5月13日的市场消息显示，凯茜·伍德领衔的ARKK旗舰基金在特斯拉股价承压下跌之际，并未选择撤退，反而在短短两个交易日内再度增持，累计买入金额超过5000万美元。

这种逆势的操作风格，再次印证了伍德对特斯拉长线逻辑的坚定。截至最新披露，特斯拉已稳居ARKK前十大持仓的第二位，基金持仓市值约6.77亿美元，配置比例高达8.93%，是基金的核心抓手之一。

从数据来看，即便短期波动剧烈，“木头姐”依然把特斯拉视作创新赛道里的核心标的并持续加码。
