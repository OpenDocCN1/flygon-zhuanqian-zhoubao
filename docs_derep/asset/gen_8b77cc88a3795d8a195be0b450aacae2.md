# 用一条「逻辑线」串起朋友圈，让人忍不住刷下去

哈喽，我是思念。

做了 9 年创业，踩过坑也试过路，长期在心金文案、私域自动化成交和小红书创业 IP 打造这几个赛道里打磨方法论。我的信条很简单：持续迭代，才有持续的结果。

这次很荣幸受邀成为 2 月份朋友圈运营航海的教练，在训练营里把我自己沉淀出来的「逻辑线」发圈法拆开了讲。分享完后反响出乎意料，船员们纷纷反馈说这是第一次听到朋友圈可以用逻辑线来构建，“视角被打开了，原来朋友圈可以这么玩”。

其实这套打法最初是我的一节付费课。看到大家的热情和学习劲头，我决定把它搬到生财星球公开出来，让更多同行一起拆解、复用、进化。

核心就一句话：围绕一个主题或一个核心观点，用不同的切口去延展呈现，把同一件事的多面性讲透。用户看第一条有兴趣，看第二条有共鸣，看第三条想收藏，自然就被带进来了。
