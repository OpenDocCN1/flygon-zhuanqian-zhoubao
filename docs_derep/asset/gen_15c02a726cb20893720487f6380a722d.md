# 它又涨了，可你越是看不懂，它越是疯狂

比特币又涨了，这轮涨势让人目瞪口呆。但对我来说，它从来不是一串加密货币代码，也不是今天大家口中的“暴富机会”，而是一类现象的代表。

这类现象背后，藏着同一个规律：它们刚出现时，几乎所有人都看不懂，越琢磨越觉得没道理，甚至有人会当场宣判：“这玩意儿根本没有未来，不可能活得下去。”可结果呢？它们偏偏活了下来，而且以一种完全超出预想的速度，野蛮生长，直到你再也无法忽视。

比特币只是其中最显眼的一个。它像一面镜子，照出我们认知的边界：我们太习惯用“看得懂”作为判断价值的标准，可世界从来不是这样运转的。有些东西，正是因为超出了你现有的理解框架，才拥有颠覆一切的可能。

就像当年很多人看不起的充电宝生意，如今不但活得风生水起，收费标准还比原来看起来贵得多。所谓的“存在即合理”，往往不是事后安慰，而是对现实最诚实的描述。

所以，下一次当你听到某个新事物，第一反应是“这怎么可能”时，不妨多问一句：会不会是我自己，还没读懂这个世界？
