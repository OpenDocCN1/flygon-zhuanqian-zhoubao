第一，个人副业合适。正反馈来得快，容易坚持；门槛低，单人就能跑，操作门槛就是会发抖音即可。我的音乐启蒙课还在孵化期，需要一个能抗住停工停课风险的副业来维系现金流。

# 一、好的 IP 变现不应该受限

我的变现分三块：业务端为主，带货、课程为辅。
因为要养团队，业务转化是重心，后面带货和课程是粉丝催生的。

业务端的核心逻辑是：用干货换业务。
关键点在于，成交业务的干货不是设计本身，而是设计带来的商业价值。

如果内容全是纯设计技巧，吸引来的都是设计师，和 B 端成交就没关系了。
我会从设计的商业表现切入吸引 B 端，比如：
1）这么设计，点击率蹭蹭涨
2）请到这样的设计师，客单价翻 10 倍
3）同款产品，不同设计风格卖给不同的人

把设计和商业价值挂钩，B 端会认为你是懂数据、懂运营、懂商业的设计师，才愿意成交。

带货和课程是意外。刚开始带货粉丝很反感，但因为我是知识博主，经常被问书单，就试了几次。其中一条视频卖了两千本，单价 130 多，佣金近 9w。其他书销量一般。

课程起初不重视，因为项目占时间，有运营一直劝我做套课。我的内容同时适合 B 端和 C 端，所以一门课卖给了两类人群。课程偏 C 端，技术实操为主，课时多、看起来也更充实。变现逻辑就是输出干货技能卖课。

# 二、如何通过内容打开 B 端 C 端市场

有人说我内容不够垂直，流量不精准。我始终认为好内容应该适合大部分人，账号是个人特色，不必照搬。

核心是：从设计师视角看世界，设计就成了社交工具。

如果你只认为自己是设计师，你就只是做好看的东西。
我定位自己是懂互联网、懂营销、略懂商业的设计师。在运营和创业者圈子里分享设计的价值，一个好设计带来的商业意义，这时候设计就是社交货币。

比如一个运营每天调数据、抢 ROI，你给他一套好视觉，就能形成行业壁垒，花更少钱拿同样结果。
我见过很多老派运营，宁可多花 10 块付费也不愿花 1 万在视觉上，这是典型的认知洼地。

再比如同一件商品能卖出千千万万种价格，靠的就是视觉定位和视觉营销。不懂这个只能去卷价格战。

B 端需要的设计：能产生商业价值、赋能商品、帮助转化的设计。内容接入这个点，拿 B 端客户会容易很多。关键是用 B 端用户听得懂的语言讲设计。

C 端需要的设计：技法类。设计师先是技术工种，再谈审美思维。技法类容易在屏幕上演示，收藏点赞率高。思维类多为口播。
