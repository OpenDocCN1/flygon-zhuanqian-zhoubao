# 靠人脉起家，到底值不值得学？

前几天在外地客户现场做调研，更新晚了。

一个人想在社会上立足，真正能调用的资源无非三种：第一，自身的能力；第二，兜里的资本；第三，也是很多人容易忽视的——社会关系资源。

更直白点说，有人就是专门靠“倒腾”社会关系来赚钱的。

美国华盛顿有条著名的“K街”，外号“游说一条街”。那里挤满了智库、公关公司和各类游说集团。他们的核心客户是美国国会和联邦政府，尤其是那些手握选票的议员。议员们谁也不听谁的，各有各的利益关切，信息也高度分散。于是说客就充当中间人，在他们之间牵线搭桥、调停斡旋。

别小看这个角色，一名普通说客的年薪就能到百万美元级别。美国政要一卸任，往往就会转战K街。自1998年起，43%告别国会的议员最终都投身游说行业。K街也因此被称作仅次于行政、立法、司法之外的“第四权力中心”。

很多人一提“靠关系拿业务”就一脸不屑。但现实是，这是全球通行的商业规则，古今中外概莫能外。

所以，很多人的创业起点就是积累社会资源，等资源攒够了，再拿它作为筹码去开公司、做经营。

这里有个经典的“结构洞”逻辑：当一群人互不相识，但一旦联手就能产生巨大协同效应时，那个恰好认识双方的人，就填补了结构上的空白。这个关键联络人，自然能赚取超额回报。

投资人和项目之间存在信息不对称，FA（财务顾问）就是那个关键的牵线人；哪怕是同一行当的群体，彼此也未必互信，黑社会闹矛盾，也得找个中间人来调停。

说白了，大量商业公司的业务拓展依赖人脉关系，至少在一定程度上是这样。

而那些看似高端的社群、俱乐部、微信群、商学院，本质上也像一个“社会资源批发交易中心”。

退一步说，就算你压根不想靠人脉发财，只要你的社会关系网络足够大，你做事的赢面也会明显变大。因为你接触到的每一个人、每一个机构，都在不断向你输送信息和机会。

说到底，经营人脉本身就是一种成功的路数。才华是资源，金钱是资源，人脉同样也是资源。
