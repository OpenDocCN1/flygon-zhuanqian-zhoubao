# 法律咨询项目实操拆解：5人小团队三个月从0到50万的完整路径

5个人，跑了3个月，从零起步做到月入50万。结果不算顶尖，但思路足够清晰，拿去复制到自己的项目里应该能少走弯路。

# 一、这个赛道的底层逻辑在哪

法律咨询这个赛道一点都不新，但能一直做下去。需求面覆盖全国，几乎每个行业都会产生纠纷。卖的是专业知识加服务，看似门槛有点高，没有律师资源或带教很难上手。可实际上竞争并不激烈，全国的案子根本打不完。

凭什么能和律所抢客户？核心是获客渠道变了。

传统律师找案子主要靠熟人介绍、混圈子、地推。短视频和直播的出现直接把用户需求引爆了。以前打一个官司律师费三五千起步，太多小额纠纷、小矛盾被直接劝退，因为当事人觉得不划算。而这类经济纠纷恰恰是最多的。

我们的打法很简单：图文+短视频+直播在公域收资，通过电销拉微信，再在私域完成转化，最后交付给合作律所执行。

# 二、上手前的准备清单

一个人做，前期可以自己扛流量和转化，后端直接外包给律所。

三人小团队，可以两人做内容引流，一人负责私域跟进转化。

我们五人组是这样的分工：2人负责流量，2人负责销售，1个主管负责对接律所和统筹团队。成交后非诉类由主管直接收尾，诉讼类直接移交给律所。

跟律所谈合作其实不难，资源方掌握流量就掌握主动权。我后面会把和律所律师沟通的关键点和合作细节补上。

非诉业务后期能完全自己做，因为大部分就是起诉指导，流程简单。

硬件要求很低：苹果7级别的手机+一台能剪辑的电脑。能拍能剪发图就够了。

资质方面建议办几张个体户执照，海南办理比较方便。

设备和账号：一个手机配一张流量卡，小红书严格执行一机一卡一号。起步阶段一个人准备3-5部手机就够，看执行力。

日常执行节奏如下：

* 上午十点开工，先看微信。昨晚约好的待付款、着急联系的客户优先回复，先把能成交的促成。其他消息先放，准备早会。
* 早会由主管带队，学习新知识，复盘各自遇到的问题，确保每天都有进步。会后集中激活私域，回复新委托人消息。
* 合理安排时间去拍摄和分发素材视频。
* 每晚提交工作日报，复盘当日完成项。
* 朋友圈每日至少更新5条。
* 企业微信群发每日必须执行一条，以原创视频为主。
* 每个客户必须录入《客户信息统计表》。
* 每天拍摄引流用的普法素材或图文不低于5条，剪完后分发到各平台。
* 每天搜集10条以上精准爆款文案存表备用，便于二次改写。

# 三、流量具体怎么拿

## 1、平台选择思路

经过大量测试，获取案源的核心平台是抖音和小红书，其次是视频号，适合真人出镜口播。快手可以直接搬运抖音和视频号的作品。

如果主做维权退费，精力集中在小红书，客群付费意愿强，年轻女性为主，好成交。

如果主做经济纠纷、民间借贷，那就以抖音为主。虽然流量偏泛，但体量最大。

# 四、转化怎么闭环

## 1、转化底层逻辑

所有技巧都是为成交服务。成交前提是信任，多站在客户角度思考。最好的套路就是没有套路。

#### 1. 客户关系定位

先厘清客户在案件中的身份：原告还是被告，借款人还是出借人，甲方还是乙方。

#### 2. 案件属性判断

民事还是刑事，执行还是诉讼。不同属性沟通思路完全不同。

执行案：重点在被执行人财产信息，问客户掌握多少财产线索，可通过中国裁判文书网和执行信息公开网查询。

诉讼案：收集证据，问客户手上有哪些材料，同样可通过两大网站查询被告信息，为二次沟通做准备。

可根据客户身份和案件属性判断是否可推非诉，降成本、省律师费，达到相似效果，额外增加价值。

#### 3. 案件核心内容

标的额：赔偿或起诉金额，借贷金额含利息。

纠纷类型：欠款、合同纠纷、侵权等，每种证据标准不同。

欠款：证明借贷关系成立及内容。

合同纠纷：判断是否存在违约及责任划分。

侵权：工伤、医疗等，需建立过失关系及损失范围。

#### 4. 证据评估

根据诉讼阶段判断所需证据，养成让客户拍照发微信的习惯。判断证据能否立案，不足的在二次沟通时补齐。

#### 5. 报价策略

诉讼案：按标的额3%-5%收费，标的小的最低5000。跨省出庭需实报差旅。

执行案：标的3%-5%作为委托及办案费，最低4000。回款后另收执行回款15%左右，可协商。

报价以成交为目的，可适当偏高留谈判空间。

#### 6. 说理思路

1. 省内客户可邀约见面，以建立信任理由见面沟通，提升成交率。
例：看您也是河南，我们在郑州，案子也不小，建议您来一趟，我们在高铁站旁边，约主任给您方案。即使不委托，也能心里有数。
2. 省外客户以线上签约为主，强化律所实力信心，邀请主管二次沟通，用相似案例讲故事塑造信任。可提视频见面、部分定金先走流程，降低客户疑虑。
例：
1.我跟主任沟通过了，您的案子基本没问题，接受报价就可以线上签约。
2.您是省外的，没见过面，咱们开个视频见一下，了解环境，更放心。
3.考虑到路远经济压力，律师费可分期，先付定金启动流程，立案后再补尾款，您也不用担心收钱不办事。

注：全程不要做保证性承诺，不要自称律师，可提前引入主管协助。

## 2、电话沟通参考话术

1. 开场白自我介绍
①你好，这里是***法律咨询/律所，我是***主任助理，通过X主任了解到您有欠款追回的问题，对吧？
②你好，这里是***法律咨询/律所***主任，看到您通过客服通道咨询债务问题，对吧？

2. 给客户陈述时间，2-5分钟为宜
①请您说下案件具体情况
②请您详细描述过程，我稍后帮您梳理
注意：非必要不打断，让当事人倾诉。

3. 停止陈述，快速分析并提问
①我打断一下，大致情况我了解了，我问几个具体问题
②欠款金额具体多少？
③手上有什么证据？借条、聊天记录等
④欠款人姓名、电话、身份证、地址？
⑤是否起诉过？
⑥欠款多久了？是否过诉讼时效？
顺序可灵活调整。

4. 拉微信看证据
①您先加我微信，把证据发过来，我看下是否具备法律效力，确定能否接案。看完再回电给方案。

5. 回电反馈并共情
①告知证据问题，如有问题说明
②了解欠款人态度：现在什么态度？打算不还了吗？是否失联？
③适度挑起矛盾：不负责、人品、失联等。注意适可而止，避免反感。

6. 建立信心促成交
①给予肯定但不保证
②强调优势：法院公正公开、团队专业、司法局监管
③给出专业处理方案，直接询问是否委托，引导客户主动问价格。
