最近我们做了一份关于设计行业的小调研，爬了三百多家公司、十四个设计类岗位的招聘信息，也翻了不少资深从业者的经验分享。信息量挺大，正好整理成一篇给想入行或正在进阶的小伙伴做参考。

先说个整体感知：设计行业是个相当看作品、看能力的领域，学历门槛相对温和。真正让设计师走得远的核心素养，集中在审美、沟通、创新和协作这几点上。无论你打算做室内、平面、游戏、产品还是UI/UX，这几项都是底层能力。

市面上的设计岗位名称五花八门，我们大致归成五类，方便大家看清楚每类到底是做什么的、要什么本事、能拿多少钱。

**一、室内设计 / 家居设计**

这类岗位主要做什么？概括起来就是：跟客户深度沟通，实地量房，做方案、出图纸和效果图；同时要负责室内物理环境、空间分隔、软装搭配和视觉风格的设计；还要陪客户选主材、挑软装、协调施工队，甚至全程监督装修品质。

能力上，审美、谈单沟通、施工工艺知识一个都不能少。薪资中位数大概在9200元每月。

**二、平面设计 / 视觉设计 / 广告设计**

这类的日常工作内容：用PS、AI、AE、C4D等工具做各种平面作品，像插画、广告、网页、APP界面、H5等；跟团队配合输出创意，提供专业审美意见；还要参与品牌IP衍生品、文创产品、礼品的设计研发；以及跟需求方反复沟通，调整草稿和样品。

能力要求上，审美和沟通是基础，项目管理能力和团队协作也很重要。薪资中位数约为8453元每月。

**四、产品设计 / 工业设计**

这类设计师的工作链条比较长：先读懂用户需求，研究使用场景、产品定位和用户画像，洞察市场趋势；然后做外观设计和CMF（工艺、材料、色彩）设计，用手绘、平面软件和三维建模渲染等工具画草图、出效果图、建3D模型；随后要出完整方案并向客户演示；还要做原型、估成本；最后跟生产部门一起评估可行性、安全性、外观和功能，跟进量产，解决CMF相关的问题。

能力层面，产品思维、用户思维、市场嗅觉、审美、沟通和团队协作都很重要。薪资中位数在9600元每月。

**五、UI/UX设计 / 服务设计 / 体验设计**

这个方向分两块。UI偏界面：结合产品需求完成各类视觉和图像设计，制定设计规范，定义标准样式、图标、基础元素和配色；跟产品经理、前端工程师配合验收实现效果；并持续研究趋势和用户审美，打磨体验。

UX偏体验：做产品前期的用户研究，挖掘需求，定义产品雏形或迭代方向；根据公司战略输出设计文档，跟踪开发并对体验负责；通过可用性测试、A/B测试收集反馈，优化业务流程；梳理核心流程和设计规范；用体验度量指标持续做迭代。

要求上，产品思维、审美、创意、设计思维、沟通协作都跑不掉，懂点代码是加分项。薪资中位数：UI岗约11323元/月，UX岗约16526元/月。

关于设计行业，有三点值得拎出来强调：

一是作品和能力的分量远大于学历。你拿出来的东西，比你的毕业证更有说服力。

二是审美、沟通、创新、团队协作，是贯穿所有设计岗位的底层能力，越早刻意培养越好。

三是腾讯那份《2022年互联网新兴设计人才白皮书》里，从工作现状、岗位需求、教育培养三个角度给了很多有价值的信息，值得找来看看。

说完岗位，再看看一个设计师的职场升级打怪路径，当然薪资会因地域波动，仅供参考：

- 初级设计师，月薪约5K。基本要求是熟练操作设计软件、理解设计原理；多参与小项目攒经验，逐步提升水平。
- 中级设计师，月薪6-7K。开始碰复杂项目，要提升创意能力，同时学习团队合作和沟通技巧。
- 资深设计师，月薪8-12K。要有全局设计思维，能带团队完成项目，参与公司重要项目，提升影响力。
- 美术指导，月薪10-15K。负责指导团队设计方向，做创意领导；直接跟客户沟通需求、提供方案。
- 设计总监，月薪20-30K。统筹整体设计战略和团队管理，制定设计标准，推动公司整体设计水平提升。

接下来，我们整理了四位设计圈前辈的经验之谈，每一条都挺扎心，但也很真实。

**第一位，一位有10年设计经验的创业者。**

他说，设计只是商业的一块拼图，别只盯着设计本身，要跳出专业看全局。30岁之前拼专业，30岁之后拼思维和资源。人脉不是认识谁，而是你帮过谁、成就过谁。选工作，比起工资，更值得看重的是跟谁一起、做什么事。多接触厉害的人，格局和思维都会被打开。选择一家有潜力的公司，跟着它成长，比眼前那点得失重要。判断公司好坏，看社会价值和商业模式。战略没搞对，战术再好也白搭。30岁以后，要保持竞争力就得聚焦且不断突破。

他还提醒，互联网内卷时代，专业和业务理解一个不能少，还要懂数据。写作是建立专业壁垒的好方法，能帮你梳理知识、养成输入输出习惯。做T型人才：一门深入，再横向拓宽。团队初期靠长板，后期要补短板。学习的反馈慢，游戏的反馈快，但长期积累才能赢。审美这件事，在文案、内容、选品里都是核心竞争力。

关于品牌，他的比喻很妙：品牌就像内衣，看不见但很重要。好的品牌能影响生活，比如苹果。设计应该忠于品牌风格，而不是追着流行跑。品牌还要对内容负责，内容本身也是品牌的一部分。年纪越大，越倾向选择那些用科技改变生活的品牌。品牌能简化用户的选择，让人少纠结。选品牌也要看它的社会价值和影响。

关于成长：每个人成功都不可复制，因为经历和性格不同。少跟别人比，多跟自己比，痛苦会少很多。读书就是和作者灵魂对话。持续提升认知，才能赚到认知以外的钱。成功不只靠能力，还靠人脉和贵人的帮助。承认自己是普通人，接受失败，放下执念。

关于创业：从拿工资到发工资，是责任和压力的本质转变。创业者要自己做决策、扛压力，还要激励团队、服务会员。做关键决策时，把时间维度加进去，想想长期影响。如果需要别人鼓励才敢创业，那可能不适合创业。运营不只是执行，要洞察用户需求、平衡商业价值。真正好的运营是提供超预期的服务，没有套路。社群运营的本质是把优秀的人组织起来，产生化学反应。写作找不到思路？可以去微博热搜找话题角度练手。最后，主动做事，持续挖掘成长点；追求持续进步，而不是短期的完美；公司只提供平台，学习不学习，是自己的事。

**第二位，聊了品牌设计的"术"。**

品牌形象设计是企业的地基，每个创业者都得重视。它不只是外在形象，更是内在文化和价值的传递工具。品牌是消费者对企业产品和服务的整体印象，能帮企业建立认知，提高信任和忠诚度。强品牌让产品有溢价能力，比如耐克，大家买单的不只是质量，更是它的文化和价值。

消费者第一眼印象非常重要，决定了要不要深入了解你。在陌生环境里，人倾向于选择熟悉的品牌，这种习惯降低了沟通成本，提高了交易效率。品牌是无形资产，哪怕物质资产没了，强大的品牌依然能东山再起。

初创企业预算有限时，可以去淘宝、猪八戒、一品威客等平台找基础设计服务，成本低，能满足基本需求。但品牌不是设计个logo就完了，需要长期维护和优化，渗透到日常运营的每个环节。他建议创业者别做全案，要聚焦核心：logo和一套VI。设计要与品牌策略结合，从商业角度做方案，而不是纯玩视觉。拥有视觉系统只是第一步，更重要的是运营和维护。设计要落地到实际场景，好的设计能帮企业省钱省力，提高品牌价值。

**第三位，讲了小众产品的需求挖掘。**

做小众产品，起点是需求。具体怎么挖？先选一个用户量足够的平台，比如全球排名前200的网站，或者垂直领域前10的平台。有用户基数，哪怕只解决少数人的问题，也能活。然后注册体验，把明显的按钮都点一遍，熟悉主要流程，搞清楚这个平台解决的核心问题。如果没发现明显问题，就主动找：用半个关键词搜一下，用26个字母做各种组合搜，用工具配合好奇心去发现，把感兴趣的问题和数据记录下来。

找到问题后，看看用户给的可行的答案，那些答案通常是现有产品。去分析这些产品解决了什么核心问题、有哪些主要功能模块、哪些收费哪些免费、定价策略是什么，再用SimilarWeb查一下官网流量。然后做竞品分析，区分通用免费功能和差异收费功能。通用免费功能解决基本需求，用来引流；差异收费功能解决特定问题，可能是创新点。数据上，要记录工具数据和Quora、Reddit、Medium等问答网站的回复、点赞、浏览、评论，尤其关注长回复里的用户意见，那是改进方向。

把前六步的数据整理成评分表，根据需求方向、开发评分、运营评分、竞争可能、搜索评分、价格分数等维度打分，选总分最高的需求方向产品化。产品设计时，最重要的是做减法。MVP最小可行产品，比如自动化工具只需要开始和结束按钮；电商店铺分析工具只展示最核心的数据。需求挖掘需要多练，带着好奇心，按步骤实践，慢慢就能形成习惯，做出成功产品。

**第四位，是一位35岁设计师的思考。**

关于设计师的差异：同样时间内，不同能力的设计师解决同一个问题，产出差很多。高级设计师手法更强，还能提供附加价值，比如引导式提问、诊断公司愿景、讨论目标人群。他们综合素质高，能理解商业目的，用设计解决商业问题。好的设计还能制造话题性，比如那个因为设计拿了红点奖的"29cm"电商App，靠奖杯引来大量自发传播；设计也能提升效率，比如那本服务设计书，用服务设计的方法组织内容，读者查找起来很方便。

那怎么省钱省心找设计师？第一，明确预期。搞清楚产品定位和竞品，明确设计需求。如果需求很清晰，只需找视觉设计就行，省时省钱。复杂的需求需要复合型能力，周期长费用高。第二，选团队。了解市场价格，看作品和试稿，问他们解决问题的思路，就能知道工作态度。第三，签好合同。常见分期付款方式是4/3/3或5/5，分阶段付钱降低风险；每个付款周期设置验收标准，减少换团队损失；违约责任和售后机制也要写清楚。第四，沟通协作。初始阶段就明确需求，细节阶段给真实反馈，同时要理解设计师的逻辑，别鸡同鸭讲。第五，别太早陷入细节。先出草稿，再一步步细化，草稿阶段纠结细节是浪费时间。

最后提醒自己：每完成一个项目，都要做复盘，把经验和教训沉淀下来，持续优化工作流程；同时利用碎片时间自由创作练习，创作水平才能稳步提升。设计师这条路上没有捷径，但方向对了，方法对了，每一步都不会白走。
