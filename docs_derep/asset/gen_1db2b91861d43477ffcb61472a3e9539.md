# 三年小红书创业复盘：我不教你如何暴富，只分享怎样少走弯路

大家好，我是七天假，一名生财航海家。

2018 年，我进入互联网行业，做过产品经理，也曾负责过一款拥有百万流量的产品。2022 年，我选择裸辞，开始全职创业，把主要精力放在小红书平台上。

过去几年，我曾通过小红书实现半年盈利 20w+，也做过帮助中小品牌增长的种草业务，单月销售额最高达到 80w+。

这些成绩看起来不错，但如果只看结果，很容易忽略过程中付出的代价。

创业三年，我踩过不少坑：方向判断失误、业务模式反复调整、过度埋头执行、缺少及时复盘……有些问题，只有真正经历过，才知道它们会带来多大的成本。

所以这一次，我没有再分享“如何快速赚钱”的方法，而是把自己的经历、教训和思考全部整理出来。

这篇复盘可能无法直接告诉你怎样成功，但它至少可以提醒你：

- 哪些事情值得提前验证；
- 哪些错误尽量不要重复；
- 创业过程中，为什么要不断调整方向；
- 为什么“归零”和重新开始，反而是非常重要的能力；
- 如何在行动之外，保留足够的思考与复盘。

创业不是一条只要努力就一定能赢的路。很多时候，减少一次错误决策、避免一笔无效投入，本身就是一种收获。

从代运营到亲自下场，从把业务交出去到重新收回来，从只顾着做事到开始认真判断方向，这些经历都构成了我这三年的成长。

我分享这些，不是为了证明自己走得多好，而是希望你在做选择时，能够少付一些不必要的学费。

它不一定能让你立刻赚到钱，但或许能帮你少亏一点；不一定保证你成功，但可以让你在遇到问题时，更快找到调整的方向。
