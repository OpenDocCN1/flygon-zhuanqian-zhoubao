做私域的人都知道，小红书和抖音的引流，是绕不过去的两大难题。特别是小红书，群聊和私信里直接甩网站链接，像 www.baidu.com 这种，用户根本点不开，点击没有任何反应。

但有个有意思的点：小红书的官方域名 www.xiaohongshu.com，在私信或群聊里是可以正常打开的。也就是说，只要链接长成小红书的“自己人”，平台就不拦着。

于是就有了一个超级顺滑、几乎不怕封号的玩法：在小红书的群聊或私信里，先发一个小红书官方域名形式的链接，点开后其实是跳转到微信小程序，小程序里放着自己的二维码或引导图。

小红书不认根域名，只认“包含”www.xiaohongshu.com 的二级域名。也就是说，用一个带备案的自己的域名，解析出一个包含小红书域名的二级地址，这个链接就能被小红书放行，点开还能跳到自己的页面。

整个玩法的前置准备工作很简单：一个备案域名 + 一台服务器（阿里云或腾讯云都有卖）。

假设你的域名是 baidu.com，解析出一个二级域名 www.xiaohongshu.com.baidu.com，再申请一个 SSL 证书，得到 https 开头的地址，域名部分就搞定了。

到这里就可以测试了。在小红书里发一个类似 https://www.xiaohongshu.com.xxx.xxx/123333.html 的链接（xxx.xxx 替换成你自己的域名），用户点开后，就能跳转到微信，看到你的二维码。

不过这里有个坑：微信最新政策规定，一个 URL Scheme 只能被一个人打开，第二个人点就会提示“无法访问”。这显然不是我们想要的效果。[PRE12]

解决办法是：每次有新人点击时，系统自动获取一个新的 URL Scheme，替换到 html 里，再跳转。这就要再次用 GPT3.5 帮我们改代码。[PRE13] [PRE14]

然后把 GPT 生成好的代码存成文本文件，改名为 url.php，上传到宝塔面板。[PRE18]

最后，在小红书 APP 里发链接：https://www.xiaohongshu.com.xxx.xxx/url.php，用户直接点击，就能实现无限次跳转微信并展示二维码，畅通无阻。
