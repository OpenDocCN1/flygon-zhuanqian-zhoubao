# 离开讲台之后，我成了别人的家庭教育顾问

我过去在新东方待了整整五年，临走前已经是校区主管。2021年那场行业地震砸下来，我所在的赛道一夜之间没了。但回头看，那次被裁员反而把我从一条狭窄的路上推了出来。

转型做家庭教育，前前后后用了一年，营收做到五十万。这是我以前坐在工位前不敢想的数字。

## 一、从迷茫到重新出发

说实话，刚被裁的那段日子特别灰暗。不用打卡了，不用早出晚归了，可心里空落落的。最离谱的是，我连着好几个晚上梦见自己回公司上班，醒来发现是梦，眼泪就止不住往下掉。那种没有组织兜底、没人给你撑腰的感觉，真的能把人压垮。

家里人一直跟我说“打工没出路”，以前觉得是唠叨，真到了失业那一刻才品出味来。我也不想过那种只有工作、没有生活的日子——朋友的人生大事我总缺席，连日出日落都好久没认真看过了。

于是我开始折腾。那会儿抖音知识付费正火热，我看着别人晒流水，动辄几万几十万，觉得他们讲得也就那样，凭什么我不行？买了设备、上了镜头、发了视频，结果呢？一节课都没卖出去。

转机出现在今年春天。经人引荐我进了一个商业社群，头一回见识到原来生意可以这么做——先搭建产品阶梯，再做信任铺垫，最后用一对一的沟通促成成交。我像海绵一样吸收这些思路，重新设计了自己的产品框架和转化路径。到了9月，终于迎来了第一个爆发月，单月入账三万多。

## 二、为什么是“顾问”而不是“卖课的”

在新东方那几年，我接触过太多孩子了。

有些孩子明明很努力，却得不到父母的理解，遇事想找人聊聊，等来的不是支持而是冷话。他们的情绪没地方倒，越攒越多，最后变成心理问题，甚至影响一辈子的性格底色。

同时我也见了太多家长：不甘心孩子输在起跑线上，拼命想“卷”，可问他们从哪开始、每个年龄段的重点是什么、怎么用力才能不伤孩子根本——十有八九答不上来。他们通常的做法，是看别人家孩子学什么就跟着学，或者从不同博主那里各取一瓢，拼出来的教育理念自相矛盾，越学越焦虑。

深入接触后我才意识到，父母这个群体有三大困境：

**第一，理念碎片化，无法自洽。**东学一点西学一点，听得越多越不知道信谁，做了很多努力却收效甚微，最后陷入自我怀疑。

**第二，理论学完，落地无门。**有觉悟的父母会囤很多课，笔记记了一本又一本，可回到家面对真实的孩子，依然不知道第一步该迈哪条腿。咬牙试了两次，孩子不配合，方法也被理解偏了，最后只能拿“儿孙自有儿孙福”来安慰自己。

**第三，出问题时，身边没人能救命。**教育大V的课只管卖，即使提供答疑也限时限量。孩子的成长是动态的，问题每天都不一样，同一个问题放在不同年级、不同性格的孩子身上，解法千差万别，套模板根本不灵。更别提抑郁、霸凌、成绩垫底这种事，哪家父母好意思四处问人？

所以我给自己定的身份，不是“又一位卖课的老师”，而是家庭教育私人顾问。家长需要的不是一节课，而是一个有全学段经验的伙伴，能帮你把当下最要紧的问题找出来，给出能落地的方案，还能在你执行的时候随时拉你一把。

从市场端来看，这个定位也站得住。

行业里大V太多，普通人想靠流量杀出重围很难，每个家长资源都格外金贵。而出生人口逐年下滑，新生家长总量在缩减，靠不断拉新来维持生意越来越不现实。与其追着流量跑，不如深耕存量客户，服务好每一个家庭，靠口碑和复购做长久的生意。

所以我的关键词就三个：解决问题、深度陪伴、让普通家庭也能在教育上有底气。

## 三、一张图长出一套产品体系

很多朋友问：你这套打法，专业小白能复制吗？

能，因为我就是从零开始的。我唯一的底牌，是我真心喜欢教育这件事，所以有足够的动力去钻研。

我的产品体系，源于一个很偶然的启发。参照创业酵母的那套企业管理模型，我梳理出了一张“家庭教育天地图”，把家长培养孩子从下到上需要经历的内容和顺序全部标了出来。这张图，就是我整个产品线的骨架。

最底层的根基是亲子关系。亲子关系稳了，后面的教育才有可能发生——所以我的第一门课是「亲子关系提升营」。

往上走，孩子日常花精力最多的是学习，这需要拆成学习流程和学科方法两个层面，于是就有了「学习力基本功训练营」和「学习力高效提分营」。

下面两层夯实之后，家庭才有余力考虑长远规划，比如哪些学科适合提前接触、小学阶段做什么能给初高中减负——这就是「学习规划营」。

后来我发现同辈人际交往也在深刻影响着孩子的状态，就又补了一门「青少年人际关系课」。

每门课都在天地图上有明确的位置，家长看一眼就知道：自己孩子卡在哪一层，下一个台阶该往哪走。不少理念一致的父母干脆直接锁定年卡，把所有课程系统学一遍。

交付的时候，我提供的是一套组合方案：先用一对一沟通做全面诊断，找出核心矛盾的起点；再开出“配方”——课程好比药方，单独辅导好比手术，行动营相当于保健；最后持续跟进落实情况，过程中随时候命，及时纠偏。

其中最让我惊喜的，是行动营这个创新。过去大家以为教育产品就是把课做好、让家长去学，后来我意识到，很多家长自己学完也教不会孩子，甚至因为教不会引发亲子冲突。于是我们绕开父母这道“中间商”，直接面向孩子开口：每周围绕一个学习技能开直播课，讲完就带练一周，下周再叠一个新技能。孩子们自己参与进来，积极性高涨，从“被动听讲”变成了“主动想练”。家长的负担轻了，亲子关系也缓和了。

每天都有好消息。家长报喜的聊天记录被我发到社交动态上，又引来一批处境相似的父母。

## 四、零基础做课程的笨办法

我其实没有多少一线教学经验，也没有自己的孩子，对当父母的感觉很难完全感同身受。但我很清楚我想要培养出的孩子长什么样。

刚开始做第一门课时，我真的不知道课程该装什么、要解决什么。后来想通了：**好的产品不是憋出来的，是调研出来的。**

我用的方法很笨，但有奇效。

先把家长反复问的问题全部收集起来。你会发现，家长群体的问题像有规律似的，同一年龄段的父母的困惑高度重合。市场需求早已被人摸透，你不需要重新发明，只需要把散落的信息收集起来、按热度排序，课程主题自然就有了。

[PRE3]

然后是主题阅读。定下要解决的问题，就去翻市面上卖得最好的书和课，看它们的目录结构，把主流框架撷取出来，稍加整合，课程大纲就有了。我研究学习方法时，就是把销量靠前的书全买回来，对着目录快速抓取我需要的东西。

最后是备课。有了框架，往里填充案例和观点，按逻辑次序排好，一节课就有了雏形。

第一期我没做录播，而是直播。有互动、有实时反馈，状态比面对镜头好太多。我给自己定的节奏是讲一节备一节，压力小，节奏也稳，不知不觉一期训练营就上完了。等到第二期，根据学员反馈做了迭代；到第三期，内容趋于成熟，口碑起来了，才沉淀成录播课反复售卖。

## 五、从每月零收入到月入三万，我做对了什么

有个细节值得说：我能跑通这条路，离不开一批“没人要”的家长群。那些群里的父母没加过我微信、不认识我、更谈不上信任，全靠我一点一点重新建立连接。我通过投放直播链接和短视频引流，引导加微信领资料，把这些人慢慢变成了真正的私域流量。

目前的产品阶梯是这样的：

**① 新父母学习圈（免费）**
沉淀内容用的。我把自己总结的教育心得、月度教育风向、优秀家长的分享稿放进去，每周更新两三次。目的不复杂——立人设、攒信任。

**② 365天教育陪伴群（阶梯价，目前49.9元）**
今年上半年我一直做免费社群，整日忙得脚不沾地，每周两场直播加一次文字分享。可我心里发虚——那么多群，谁真的在听？听了有什么感受？完全不知道。免费意味着鱼龙混杂，也筛不出真正有意向的人。后来模仿我敬佩的几个社群运营者，开了付费陪伴群。9月初起步，19.9元入群，三天涌进一百位家长；三个月后，群里有226人。

**③ 主题训练营（499元）**
下面设了几个不同主题。早期是每个月带一期、一学期带完四期的模式；后来单营报名人数下滑，就改成了录播课配打卡练习加两次单独辅导的结构。

**④ 行动营（99-199元，全勤退押金）**
这是今年最有价值的尝试。市面上录播课太多，大家早就“免疫”了，光输入不输出没效果。行动营的核心就一句话：让老师直接陪孩子练。每周一节直播课，讲完方法就练一周，逐项叠加。孩子们学得积极，家长也不再因为“教不会”而焦虑。老会员可以免费参加，维系关系；新家长则在这里建立起信任，再往高客单产品转化，顺理成章。目前有古诗词背默、作业管理、英语单词和寒假新增的突破数学四个方向。

**⑤ 年卡会员（1880元）**
一个打包产品：所有线上课敞开学，送一次单独的学习规划，全年行动营免费参加。想系统学习家庭教育又不想反复选择的家长，大多会直接锁定年卡。

**⑥ 一对一私教（1200元/节）**
专门面向问题比较棘手的家庭。分“家庭系统规划”和“学习规划”两种面谈方案，当面聊、当面定计划、跟踪执行。这也是目前利润率较高的一块。

产品之外，有两个动作是转化链条的关键。

**第一个关键动作，是把朋友圈当成货架。**这我是交了学费的。以前我发圈很认真，干货、痛点、好评一样不少，可就是不出单。后来想明白了：家长来私聊，问我的是具体问题，我倾囊相授、答得特别痛快，对方的痛点已经被我免费解决了，凭什么再为课程买单？而且我的朋友圈从头到尾没出现过价格，人家当然只把你当“答疑机器”。

调整之后，我每天至少发一条“干货+课程+价格”的内容，晒报喜一定会写明对方学的是什么课、什么身份。没过多久就出现了一个特别有意思的现象——原来有个同行天天照搬我的文案，后来她不抄了，因为抄来的全是广告的味道。而来私聊的家长也变了一个画风：先描述孩子的情况，再问我该报哪个课，转化难度一下子降了大半。最近甚至开始有人看完朋友圈直接转账，数额还不大，但方向对了。

**第二个关键动作，是线下体验课做高客单转化。**做家庭教育跟做知识付费不一样，来访的父母很少会为了“提升自己”主动学习，通常都是孩子的问题已经火烧眉毛了才来找你——休学、抑郁、成绩断崖式下跌。他们是救火型的，不是防火型的。

所以我设了299元的线下一对一体验课。坐下来，把孩子的真实问题从头到尾捋一遍，给出整体解决思路，让父母明白教育是一场持久战。产品端给两个选项：要么报单个训练营，要么直接上长期方案（年卡加规划）。大部分人选前者，可因为有了整体方案的铺垫，后期补差价升年卡的非常多。设置了这个前置门槛之后，我既不愁短期出单，也能稳稳赚长期的钱。

9月，我转化了15个一对一规划的客户、3个年卡会员，总营收38410元。代价也很明显：每个一对一聊两小时，每周排了五到七组，剩不下一点精力做别的事。所以10月我调整了策略，把重心放到边际成本更低的课程和年卡上，当月进账26000元——收入少了一些，但整个人轻松多了。

## 六、下一步往哪走

眼下我还没有余力去做大规模的引流裂变，这是接下来的重点。

前期攒了大量素材，我打算把它们整理成方便传播的“引流品”：精选过的成功案例、父母常问的100个教育问题解答手册、陪伴群的精华内容合集。再往后，主攻公域平台，视频号和小红书都会陆续做起来。

我的打法和很多同行不太一样——手里有一批初始流量，所以走的顺序是：**先把产品做到位，再打通转化，然后做裂变，最后才去解决流量问题。**

每打通一个环节，产能都会往上跳一大截。加上身后有社群和前辈们的资源支持，我心里不慌，知道自己只要一个个去攻就好了。

现在，这就是我的主线业务，也是我的主阵地。

回头看这两年，裁员那天我哭过，录课卖不出去的时候我也怀疑过自己，但只要方向对了、方法对了，普通人也能在存量时代里活出自己的样子。愿每一个正在转型路上挣扎的人，都能找到属于自己的那张“教育地图”。
