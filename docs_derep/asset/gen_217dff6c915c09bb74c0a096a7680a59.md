# 从月薪四五千到存款300万，我的第一个100万是这样来的

> 大家好，我是书豪。今天想和你们聊聊，一个普通人是如何一步步攒下人生第一个100万的。

这个目标，其实在2020年就实现了——那年我25岁。如今28岁的我，账户资产已经超过了300万。

关于创业这件事，我有些自己的想法，不一定对，但希望对你们有参考价值。

[PRE0]

1. 普通人别头脑一热就辞职创业。最稳妥的路径是：先上班，利用业余时间把副业养起来，等到副业收入能和工资打平，甚至超过工资，再考虑全职出来干。

2. 如果你只是个普通人，想在年纪轻轻时就攒到100万，大概率要靠踩中某波流量红利——比如公众号、淘宝、抖音、快手、小红书、视频号这些大平台的风口。遇到风口，最关键的只有一点：先入场，先干起来。站在岸上观望，永远学不会游泳。

3. 如果你从来没有完整走通过“获取流量→变现流量”这条链路，那流量红利来了，也基本跟你没关系。

4. 大多数人30岁前赚到第一个100万，绝不是靠工作第一年就一步到位。前面通常会有第一个10万、第一个30万、第一个50万，然后才慢慢滚到100万。

5. 30岁前，一定要给自己定下“攒到100万”这个目标，但实现的过程是循序渐进的。这就好比跑马拉松，终点就在前方，但你只需要盯住下一小段距离，跑完一段，再跑下一段，坚持下去总会冲线。比如先搞定第一个10万，再冲第一个30万，当你的存款达到30万时，那种积少成多的信心自然就来了。

[PRE1]

我是2016年大学毕业的，当时在上海闵行区一家世界五百强公司上班，月薪四五千。拿着这个工资，看着上海这座繁华都市，心里真的很不是滋味——想买双耐克都要纠结半天。

后来我了解到，做大数据分析、干IT，工资高。于是我果断转行，自学编程。随后薪资一点点往上涨：从四五千涨到七八千，2018年达到月薪1.6万，2019年直接冲到了1.8万。

这些年里，我没停下过折腾。一边上班，一边做了很多副业。2017年我主动找网站合作，录制数据分析课程，赚了几万块。2018年机械工业出版社找我写书，书名叫《R数据科学实战：工具详解与案例分析》，到如今在京东还能买到，卖了差不多6000本，又赚了几万。

[PRE2]

2018到2019年间，我做微商，不赚不亏。因为做微商的原因，2018年国庆节我在福建旅游时，顺手注册了一个公众号。从那一刻起，命运开始悄悄转向。不少朋友知道，我的第一桶金就是公众号贡献的——这个业务给我带来了超过300万的收入。

但你们不知道的是，从2018年10月到2019年4月，整整7个月，公众号一毛钱都没赚到。之后才开始慢慢起飞。2019年还在上班的时候，光靠公众号就赚了10万以上。2020年1月我出来创业，公众号业务直接帮我赚了80万，再加上之前上班和副业攒下的30万，人生第一个100万就这样达成了。

这就是我赚到第一个100万的全过程。听起来好像云淡风轻，但中间有多少焦虑和咬牙坚持，只有走过的人才会懂。

[PRE3]

那么，当你决定要创业时，到底该做什么，怎么做？

我觉得最关键的就三点：赚钱欲望、敏锐度和执行力。

赚钱欲望，是你最底层的发动机；敏锐度，帮你发现机会；执行力，帮你把机会拿住。

先说赚钱欲望。我以前以为谁都想赚钱，后来接触的人多了才发现，并不是所有人都有强烈的赚钱欲望。但如果你想在30岁前攒到100万，没有这股欲望，过程会很煎熬。只有让赚钱欲望驱动自己，财富积累才有可能发生。

我自己的欲望从哪里来？就是想在深圳、杭州这样的大城市买房，却发现自己根本买不起。2016年毕业那会儿房价涨得厉害，可我没钱上车。等工作后想找个女朋友，发现更难——在杭州深圳没有房，底气就少了一半，很多女生优先考虑有房一族。那种被现实扇耳光的感觉让我明白：至少先攒到100万，把首付准备好。

[PRE4]

接着说敏锐度。不知道你们发现没有，敏锐度高的人，通常有两个共同点：信息输入量很大，而且特别会“挖”。

你去观察身边那些你觉得很牛的人，是不是这样？输入的信息量大，你才能站在更高的维度看问题。多数赚钱的方法是什么？就是信息差。你只有知道得够多，在新风口出现时才不会手足无措，才不会因为觉得“难以上手”而白白错过机会。

“会挖”更好理解，就是能看透一件事背后的本质和商机。比如ChatGPT，真的是今年三月才火的吗？其实去年年中、年末就已经在圈内传开了，只不过还没像现在这么破圈。如果去年你就敏锐意识到AIGC时代要来了，哪怕不躬身入局去研究AI，当时随便买点AI相关的股票基金，现在是不是早就赚翻了呢？

所以，一定要大量输入信息，同时善于挖掘机会。这样你能制造很多属于自己的信息差，然后用信息差去变现。

当然，这一切的前提是：敢于尝试。这可能是老司机和新手最大的分水岭。新手总想等一切想周全了再动手，结果迟迟迈不出第一步。这在创业里是大忌。没有实践的想法，永远是想法，变不成赚钱的工具。当你勇敢跨出第一步后，还有一点很重要，就是主动分享和交流。说出来你可能不信，我抓到的几次大流量机会，都是跟人聊出来的。线下聚会时，我认识了很多做公众号的朋友，大家互相分享变现的方法和渠道，一起把盘子做大。所以跟人打交道，真诚点、主动点，你会得到很多意想不到的好信息。

[PRE5]

最后说说执行力。如果一个项目带有红利，机会往往转瞬即逝，执行力就变得至关重要。

执行力看两个词：快、狠。

就拿今年小红书电商来说，去年年底我们得知小红书要做电商转型，立刻投人快速测试，今年已经在小红书上赚到了不错的利润，接下来准备全力投入。当你发现红利期项目时，“快”是第一要义。

这里再重申我前面提到的：如果你从没完整经历过从流量获取到流量变现，红利来了也跟你无关。

所以，没做过小红书的同学，今年一定要试试。哪怕只赚到第一个100块、第一个1000块，赚多赚少不是重点，重点是入局、亲自下场。只有你亲身去实践了，才会懂整个市场的规则，才能更稳地接住随时可能降临的商业机会。

而且，当你找到变现方向，在一个号上跑通了赚钱模式后，就要立刻放大——做矩阵，尽快走向规模化和自动化。我大学毕业后五年内赚到第一个100万，靠的就是公众号矩阵。我还有些朋友，当年批量做头条号、百家号，月入百万。在他们面前，我这点成绩确实是小巫见大巫。

[PRE6]

所以我真的非常建议大家：一旦发现商机，立刻投身去做。别怕做不出成绩——你换个逻辑想想，如果你不去做，本来也不会有什么成绩；但你投入进去，说不定就能做出点什么。这波买卖，怎么算都不亏。

以上就是我关于如何赚到人生第一个100万的分享，希望对你们有帮助。
