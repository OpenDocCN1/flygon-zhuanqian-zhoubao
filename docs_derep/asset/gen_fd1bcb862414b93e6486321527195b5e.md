# 为什么要做

iOS用户早就靠快捷指令+飞书多维表格实现视频文案一键抓取，安卓阵营同样不能落下。本教程教你用安卓自动化工具搭出专属的文案提取工作流，让创作效率直接拉满。

# 你能得到什么

*   熟练掌握安卓自动化神器 MacroDroid 的配置方法
*   会搭建扣子 Coze 的小红书文案提取智能体
*   学会把工作流接入飞书多维表格进行调用
*   掌握飞书机器人流程的设计思路
*   学会使用飞书多维表格的AI插件功能

[PRE32]

1.  输入令牌名称，建议与用途相关联，设置有效期、勾选【工作流】权限、选择工作流所在空间，最后点击【确定】：

[PRE33]

1.  记录生成的API key，仅展示一次，请妥善保存：

[PRE34]

*   令牌权限范围需包含工作流操作权限
