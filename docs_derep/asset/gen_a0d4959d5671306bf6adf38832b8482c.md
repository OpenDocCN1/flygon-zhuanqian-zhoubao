# 借款前不知道这5条，小心利息翻十倍

前阵子，一个圈友急匆匆找我：手头资金倒不开，看到抖音上极融、度小满这类平台的广告，利率写的是7.2%，能借吗？

我第一反应就是：那行大字旁边，肯定还藏着个“起”字。跑官网一查，果然——7.2%后面跟着“至23.4%”。一字之差，利息成本可能差出好几倍。

这种坑，说穿了都是信息差。我在金融圈摸爬滚打了十五年，从给大行做核心系统，到后来搞风控、做业务咨询，国内银行、消费金融、小贷、汽车金融的路数基本都门儿清。自己也实操过贷款、信用卡、转贷这些事。所以今天不整虚的，给你五个关键点，加三个实用建议，看完能少走不少弯路。

**第一条，先看“渠道”是不是真合法。**

先讲个结论：你在主流大厂App里刷到的贷款广告，背后大多是有牌照的正规机构，这点倒不用太害怕。真正的风险，往往出在你自己身上——手机越狱或者root过，又装了个来路不明的应用，里面可能藏着后门；或者在哪个不正经的网页上，稀里糊涂就把银行卡号、密码填了进去。结果人在家中坐，钱从卡里飞，这种事我们小区周边每周都在发生，少则几万，多则几十万。

所以记住两条底线：第一，除了银行自家的App，任何地方都别输入你的转账密码；第二，要查存款账户，必须从银行官方App的入口进去，别从其他页面跳转登录。

顺手提醒一句：那种主动打电话说“我是XX银行信贷中心”的，基本全是骗子。银行客户经理没闲工夫打电话拉业务，除非是信用卡中心，而且都是机器人。

**第二条，搞清楚“放款方”到底是谁。**

借钱和你做电商选品一个道理——选错供货商，定生死。你在银行App里借，年化利率可能5%上下；换个平台，比如度小满这种，实际年化冲到15%、25%、甚至36%都很正常。千万别觉得夸张，线下这样的骚操作我见得太多。

一句话总结：网贷机构的利率，几乎永远高过银行；消费金融公司的利率，也几乎永远高过银行；甚至股份制银行，都可能贵过你老家巷子口的农商行。银行和银行之间，差距同样大得离谱。

**第三条，确认你买的是哪个“产品”。**

很多人以为银行只卖一种贷款。其实同一家银行，信用卡中心给你的利率，和客户经理给你的利率，能差出一大截。信用卡中心推销的产品，普遍都不便宜。你去网点谈的时候，你的单位性质、学历、有没有抵押物、工资卡是不是在这家银行开的，都会影响最终定价。

大致规律是：分期利率最高，消费贷款适中，有抵押物的房贷最低。如果你名下有家小公司，还能申请经营贷，那就直接解锁高级玩法了。

**第四条，合同比广告诚实一万倍。**

但凡广告写“利率7.2%起”，那个“起”字就是最大的猫腻。别盯着前面的数字看，后面的23.4%才是你真实该担心的。就像招聘广告写“月薪5千到1万”，你心里就该清楚，HR实际预算就是5千。

更绝的是线下操作。很多业务员给你算出来的利率，可能比上限还高，而且他算的公式本身就是错的。你以为他是数学不好？大概率是公司培训就这么教的，话术把销售自己都说服了。但你也别慌，他们不敢在合同上造假——监管部门手握“吊销执照”这把刀，合同要在内部被专家逐条审，还要留档备查。所以，签合同的时候，盯紧白纸黑字上那个年化利率，那就是你最后保命的数字。

顺便说个经验：我这么多年，没见过一个4S店销售能把车贷实际利息算对过。买过车的朋友，不妨翻翻当时的合同，对比下销售当初跟你说的话。

**第五条，留好证据，永远不吃亏。**

办网贷，银行流水一定要截屏保存；条件允许，全程录屏。因为你永远不知道哪天打开App，发现当初的合同不见了。这些记录，就是你日后和机构谈判、甚至去监管投诉的筹码。机构宁可把你那点利息吐出来，也不愿意被央妈罚一笔大的。

另外劝你一句：除非征信已经花得不能再花，否则离小贷远一点。现在能稳定带来20%以上收益的项目，比大熊猫还稀有。你凭什么觉得借一笔网贷就能翻身？大概率是窟窿越补越大，逾期罚息压得你喘不过气。

**最后三条建议，请收好：**

第一，征信没花的话，直接去银行借。招商、邮储、农行这类资金来源成本低，利率往往最友好。别嫌大行流程麻烦、服务不够甜——便宜是有原因的。那些对你嘘寒问暖、态度亲得像亲哥亲姐的机构，利率多半能让你后背发凉。

第二，征信花了还非借不可，先想想亲人朋友。主动说好利率，现在低利率环境下，拉你一把的人还是有的。如果朋友手里也紧，可以让他从银行低息借出来，再加一点点转给你，成本照样比网贷低一截。当然，如果所有人都不愿意借你，那你也该反思下自己为人了。

第三，生财圈里注册过公司的朋友，好好珍惜你的那张营业执照。用公司名义去谈经营贷，撬动的资金量绝对超乎你的想象，关键时候能成为你生意的强力杠杆。

金融这工具，人人都绕不开。用好了，它是你放大营收、跨越阶层的杠杆；用不好，就是越陷越深的泥潭。今天这些常识，希望你能记在心里，也顺手转给身边需要的人。我是逍遥，欢迎来聊，愿我们都少踩坑，多生财。
