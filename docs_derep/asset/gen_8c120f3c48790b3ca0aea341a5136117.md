2.  硬件投入别抠门，能上更好的就上更好的，像爱图仕这个级别的。

**（8）主播流水线化批量复制的打法**

**1、视频号里主播大致分哪几类？**

**①稳播型主播：**

1.  语速偏慢，直播节奏平稳，更多是推品过款；
2.  常见于品牌直播间、短视频直播间以及高客单价的直播间；
3.  对稳播型主播的核心要求是拆解商品能力和带转化能力。

**②节奏型主播：**

1.  说话快、节奏明快、调动氛围的能力强；
2.  懂用户心理，能依托活动策划直播氛围；
3.  主要集中在低价、促销、清仓类直播间；
4.  节奏型主播要会玩气氛、会拉流量，人选很关键。

**③运营型主播：**

1.  兼具稳播与节奏的特质，更偏运营思维；
2.  大多数时候主播就是操盘手，能独立完成起号；
3.  运营型主播靠内驱力驱动，可遇不可求，是典型的创业者气质。

**2、主播如何提炼产品卖点？**

本质上就是训练主播对产品建立认知，思考方向如下：

①谁会用我的产品？年龄、性别、角色、兴趣标签。
②会在什么场景地点用？家里、办公室、车上、街上。
③在什么场合用？同学聚会、婚礼、见客户、讲方案、面试、相亲、孩子毕业。
④使用时关联到什么人际关系？子女、父母、夫妻、婆媳、上下级、朋友。
⑤什么时间段会用？一天24小时、季节节点、人生阶段。
⑥使用时的情绪状态？喜怒哀乐。

**3、新手主播话术的八步拆解法**

1.  **先学话术，最笨的路最管用：牢记皮皮鑫的三条铁律**

①别原创，别高估新手的能力；
②别生搬硬套模仿，模仿会让嘴巴发硬；
③授人以渔比授人以鱼重要，让主播用脑子去播。

2.  **八步打造属于自己的话术体系：**

①找对标：让主播找产品相似的直播间，满足高人气、高转化、高互动三要素；
②录对标：主播观看同时自行录制两小时话术，看一遍加深记忆，录满两小时保证完整；
③抄话术：用笔或电脑直接抄下来，抄就是反复看，抄就是记忆，必须亲手抄；
④拆话术：用Excel表格把话术拆解，拆解的过程就是思考，训练模块化思维；
⑤融合话术：结合自家产品与人设，把别人的话术替换成自己的产品话术，按人设重新编排风格；
⑥话术训练：让主播倒背如流，前期铺垫后记忆更轻松，只有倒背如流才能临场不乱，模仿对标账号的风格停顿、节奏、抑扬顿挫，录屏由负责人验收；
⑦上战场：先小号试播，再大号实战，小号与运营场控磨合流程与默契，上大号先做副播，练一段时间再转主播；
⑧迭代创新：创新是在倒背如流后自然产生的，主播会主动调整内容，长期坚持就具备了编写话术的能力。

**4、七天把新手培养成S级主播的SOP**

**第一天：认识行业、认识直播**

①先别动手，给主播10个竞品直播间；
②要求上午10点看到中午12点，期间不打扰；
③下午2点复盘提问：记住了哪些直播间名字？播了什么品、什么价位？主播说了什么、怎么说的？如何引导下单？记住了哪些场景？看到了什么？
④临时提问的目的：筛掉偷懒没看的，筛掉不爱思考嘴张不开的，判断可培养度，决定是否重点培养。好主播一定是主动+会思考+会总结；
⑤再让主播看10个正在播的直播间2小时，到点继续提问，目的只有一个：连直播都不会看就不适合做主播；
⑥下班前教正确的直播间分析方法：账号信息看橱窗商品；前端短视频看作品形式、播放量与优点；场景端看直播间搭建、主播台、背景、道具；直播端看主卖商品、价位、卖点、主播形象、话术、节奏、活动、卷法、促销；购物车看商品品类、价位、销量；
⑦必做功课：用手机刷成同品类推荐流，每天至少关注5个账号，每天至少看2小时，保持眼睛浸泡在竞品里。

**第二天：定行业认知、定直播认知、定产品认知**

①让主播陈列直播间商品并自行分析，下午午休后询问对产品属性和卖点的分析。多数主播提炼不出系统化卖点，因缺乏读品能力，教会读品模型；
②挖掘场景是卖点的必经之路：
谁会用？年龄性别角色兴趣；
在哪用？家、办公室、车上、街上；
什么场合用？聚会、婚礼、见客户、讲方案、面试、相亲、毕业；
使用涉及什么关系？子女父母夫妻婆媳上下级朋友；
什么时间用？24小时、季节、阶段；
什么心情用？喜怒哀乐。
③卖点提炼维度：
外观：最大广告，差异化最直接，外包装创意、颜色寓意、形象创意、风格引领；
材质：拆解材质原料，差异化提升信任，材质讲究、组合、创意、独特性、级别；
工艺：虚实结合加背书突出独家，独家工艺、原理工艺、配方工艺、大师工艺；
数字：越具体越真实，次数、个数、时间、流程数；
地域：难以复制的品质背书，气候、地区、地理、地形、地貌；
人群：细分需求，性别、年龄、地域、职业、肤质定制；
背书：权威认可，设计师、研发者、工程师、教授、检测机构、学术观点、新闻报道、科研成果、明星达人；
理念：借用已有消费理念，设计理念、使用理念、品牌理念、行业理念；
概念：唯一不可复制实现差异化，解决痛点；
情怀：引发共鸣，创始人苛刻、对立坚持、极端定位、颠覆行业、纯手工。
④下班前交作业：提交卖点提炼文档并背熟。

**第三天：培养模块化话术能力**

①模块化好处：拆整体成部分记忆效果更好，便于针对性提升；
②负责人现场讲一段脚本，主播读两遍，手把手教各模块特点；
③活动话术：活动是什么？为什么做？今天怎么做？粉丝怎么做？
④互动话术：放诱饵、给规则、下指令。

**第4-5天：培养话术创作能力**

①找对标，满足高人气高转化高互动；
②录制两小时对标话术；
③亲手抄写话术；
④Excel拆解话术；
⑤融合人设与自家产品替换重排；
⑥倒背如流训练，模仿风格节奏录屏考核；
⑦先小号试播再大号实战，先副播后主播；
⑧倒背如流后自然创新，长期坚持形成编写能力。

**第6-7天：实战试播**

①先小号试镜再大号实战，小号与场控磨合，上大号先副播，负责人每日复盘带教；
②创新是倒背如流后的自发调整，长期坚持即可编纂话术。

**皮皮鑫给老板的招聘建议**

1.  面试多提问，多做背景调研，降低跳槽风险；
2.  采用3+7+30模式，3天无薪试岗+7天带薪试岗+30天带薪试用；
3.  对主播坦诚，不画大饼，避免预期落差；
4.  让主播了解新号常态，如冷启动；
5.  除了业务技能培训，建立合理绩效体系；
6.  孤立无圈子是打工人跳槽的核心精神原因。

# 八、短视频内容创作

**（1）什么才是视频号合格的带货视频？**

①效益对比：
短视频为涨粉：考核播放量、点赞率、互动率、转发率、完播率。
带货短视频为成交：直播间曝光次数、进入次数、点击率、引流金额。
②及格线标准：
优劣看能否把精准流量导入直播间并规模成交。
爆量带货作品特征：简单粗暴突出商品、讲清是什么、针对谁、解决什么痛点，卖点即爆点，创意加持弱化营销，赋予符合视频号算法的呈现形式，结合目标受众与当下爆款元素。

**（2）优秀带货视频的底层逻辑**

1.  内容垂直，围绕产品；
2.  画面直白，直击卖点；
3.  界面干净，时长5-20秒；
4.  视觉>文案，视觉>口播；
5.  效果对比，痛点鲜明；
6.  配乐用大数据；
7.  树立人设，情感认同；
8.  能碰到审核红线就是爆量的上限；
9.  卖点提炼难，要给产品赋予它本没有的卖点；
10.  抓住前2秒，后续再展开；
11.  剧情演绎带动产品；
12.  抄=超=钞。

**（3）可否模仿同行素材？**

①看品类：同品类最佳，其次同类不同品；
②看时间：近两周爆大并形成规模效应；
③看点赞；
④看评论区：评论数量与相关性比点赞更重要。

**（4）如何找到对标作品？**

视频号搜索栏检索，或借助第三方工具。

**爆量视频复刻与裂变**

1.  第一原则：1:1直接复刻，二进制修改重复；
2.  第二原则：场景找类似，音乐不变，文案沿用前三秒结合卖点改写，人物尽量接近，配音非侵权可直接引用；
3.  第三原则：模式沿用，场景类似，设备可变特殊类目除外，画面尽量模仿，音乐不变，卖点借鉴形式融合自身，文案沿用前3秒改写，人物接近，配音引用或自主配音。

**爆量带货短视频实操总结**

①画面有美感，开门见山，前3秒抓人；
②时长集中在5-20秒，视觉化表达；
③利益点不硬推，置后或轻点带过；
④文案重要，但视觉永远优先；
⑤标签精准，直给直卖；
⑥电商短视频：产品>形式>内容。

# 九、微信豆投放方法

投放问题多源于投放量不足，没底就放弃。核心是整体投放规划。

初期多投微信豆，ADQ暂缓。我们高峰期微信豆消耗达千万级别，实操经验总结如下：

**微信豆投放SOP**

**（1）微信豆放大自然流，基础承载力不足别指望付费拯救**

判断是否该投：
看播放量12小时内是否陡增；
看点赞评论占比，评论是否强相关；
看直播间产品是否同行爆款，是潜力品。
潜力品投法：
小额投放：单次200元起，效果好再追加；
多批次：分批投放降低试错；
转化目标：系统推荐/达人相似；
投放时长：建议6小时以上，越久越精准。
总结：前期追时机，中期追叠投，后期追数据。

**（2）微信豆测款测品**

测款发布规则：多账号测试，每账号不同风格，每天发3-5条，不同产品分开测。
投放规则：每个视频投500豆，看评论相关性判断产品可行性。

**（3）账号打标签建模型**

新号先发垂直作品，每天1-3条，权重积累后逐步加量。
打标签时走短视频带货就投关注数涨粉/点赞数+定向人群+6-12小时投放，连续7天。

**（4）破冷启动**

弊端：开播在线低、互动少、测款难。
解决：开播即刻投直达直播间，连投1-3笔，单笔100-300，新号投到限额；选自定义人群；目标成交。
目的：解决初始流量、制造羊群效应、配合福利品拉口碑分、提升成交密度建权重。

**（5）纠正标签**

方法：拿出往期或同行爆款做成交密度；拍爆款带货视频打标；直接微信豆付费建模，开场即投、直投直播间、小额多笔叠投、自定义人群、直播成交。

**视频号投放九大核心技巧**

1.  素材决定消耗，投前优化直播间、视频素材、封面背景商品图，确保DSR高；
2.  小额多投，单账号建4条以上计划，同一时段至少2个包同时跑；
3.  投放时长单条≥6小时，观察0.5-1小时测试，投产高叠投，投产低调整；
4.  组合策略：通投+高价抢精准，先跑量再提精准度；
5.  小额多笔订单+长时间投放+达人相似定向；
6.  预算根据客单价和毛利率测试不同出价，找到合适ROI，客单低出价低；
7.  出价技巧：先低价试跑，跑不动再提价，保持稳定进量，转化好再抢量；
8.  推广目标调整出价，按客单价毛利率测试ROI；
9.  复投逻辑：复盘历史数据，优质计划复投，出价提高30%以上易起量。

# 十、主流起号方式的直播打法拆解

**视频号常见起号方式：**

1.  IP起号：知识付费或人设博主，通过短视频打造IP积累高净值粉丝，短视频到直播转化可达60%；
2.  私域起号：把存量私域导进视频号快速冷启动，通过社群朋友圈宣导利益点，直播引导加企业微信公转私；
3.  直播自然流起号：薅平台免费流量，坚持日更拉时长，主播匹配风格，定时开播培养习惯，用爆款承接流量难度高，需强人货场与节奏把控；
4.  付费起号：依画像投微信豆或ADQ获新流，前期做成交密度提升层级，通过引流款、福利款、利润款、形象款组合提销量；
5.  短视频起号：纯靠发布视频涨粉种草再成交，周期长，依赖创作能力。
