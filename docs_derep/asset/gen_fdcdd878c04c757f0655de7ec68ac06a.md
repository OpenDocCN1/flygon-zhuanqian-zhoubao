# 半年烧掉8万，只换来7个用户？中老年知识付费的血泪复盘

上一次小红书女装电商的复盘刚发完，我们又在那个200平、月租两万的“豪华办公室”里死撑了一个多月，最后还是灰溜溜撤退了。合同没满一年，两个月押金四万块直接打水漂。房东可能也看出行情不好，没揪着“必须提前一个月通知”的条款，算是给我们留了一点体面。

为了省钱，我们搬进一个回迁改造的居民楼，月租几千块，总算能喘口气，也觉得自己能苟得更久一点。

最大教训是什么？新人做项目，千万别一上来就高举高打、搞豪华配置。当初想着办公室体面才好招人，结果呢？纯粹是烧钱买教训。

女装项目失败后，我彻底认清：能力圈以外的事，真的一件都干不了。可又没有别的项目可做，打工吧，性格和年龄都不合适。于是决定，还是靠实操项目来磨炼自己。

# 为什么选择中老年培训？

其实在做女装之前，我就看过不少银发经济相关的文章，心里一直对这块有想法，尤其看中中老年兴趣类线上培训这个细分。但当时天真地以为，这种培训项目前期要砸很多钱，而女装电商似乎来钱更快，还幻想过等电商跑起来，用它的现金流给老年项目“供血”。

女装关掉后，我把生财上所有银发经济的文章翻了一遍。我朋友更狠，整整花了三天，把老年人相关的项目、知识点全部整理成一本手册，几乎没漏掉任何碎片。

这朋友之前完整跑通过小红书数码产品的闭环，会做内容、会投流，但电商也做腻了。我们俩坐下来聊了很久，两家人还一起吃过饭，深度沟通后都认可同一个结论：一起干银发经济。

电商绝对不碰了。其他方向没经验。但我俩都做过培训，所以银发知识付费成了最后也最自然的选择。

当时我为什么觉得它全在能力圈里？理由还挺多：

第一，我做过知识付费，搞过群裂变和公开群发售，走完过完整的交付闭环。那是我从职场出来后的第一个完整项目，从0到1，靠模仿、请教、硬扛拿下来的。可惜后来躺平没写复盘，特别后悔。

第二，老年人喜欢的书法国画、养生中医、国学，恰好也是我的兴趣。我在求医问药过程中对传统文化产生了兴趣，虽然不懂，但愿意了解。我甚至想过，财务自由了就去专门研究这些。

第三，老年人对审美要求不高，而我的审美约等于零。女装让我明白了没有穿搭审美、不会拍摄构图就别碰那行，现在总算找到自己的“舒适圈”。

第四，课程产品很轻，不用操心供应链。老师生产一次，永远不用改，也没时效，再过500年知识点还是那些。

第五，我特别愿意帮人。做电商毫无尊严，用户是上帝，你是孙子；做培训，你是老师，用户是来学习进步的。你赚到钱，用户获得成长，双赢。尤其是看到老大爷老太太因为我的课，晚年有了精神享受，还能认识兴趣一致的朋友，光想想就觉得美好。

第六，朋友喜欢研究流量，我喜欢迭代产品和服务，正好互补。以前一个人要搞定全链条，太辛苦；这次终于找到伴了。

再加上生财3月份刚开过中老年培训航海，手册极其详实，基本是保姆级喂饭。我一度觉得天时地利人和。

一开始我们决定从书法切入。先分销财友渔火老师的书法课，跑通小闭环再做自己的产品。可视频号数据特别差，播放七八百，没有互动；朋友有个视频跑出几万播放，来的却都是看热闹的，转私域太难。我们完全搞不懂视频号推荐机制，跟小红书完全是两套逻辑。

眼看同行越来越多，我们却原地踏步。我有点急了：流量端跑不通，那就先把产品端做扎实，等有了产品，再用朋友的流量能力投流，快速抢用户。我想，就算获客成本高一点，后续复购和长期价值也能覆盖回来。

朋友也说可以。于是我们兵分两路：我负责产品端，他负责流量端。

# 创业以来最大的坑：流量没跑通，先去做产品

后来才知道，这个决定，是我创业以来最大最大的坑。

首先，产品端根本没那么容易。真做起来才发现，看起来简单的事，执行起来全是细节：课程体系怎么设计？差异化怎么做？价格体系怎么设？免费体验课录什么？社群转付费时定价多少？复购课定哪门？录制成本怎么控？一套体系课50-80节，成本不小。上哪找会教又会讲的专业老师？怎么辨别？合同怎么写？配套的礼品包供应商怎么找？怎么录？双机位还是多机位？版权归谁？

还有一堆数不清的细节。

实在没办法，我硬着头皮去请教渔火老师，发红包提问。当时已经做好被拒绝的准备，毕竟我要跟人家做同行了。但渔火老师人特别好，没因为这件事就藏着掖着，给了我很多非常有用、有价值的信息。他一直强调：一定要多调研市场、调研用户，看用户喜欢什么课程，绝对不能听书法老师们的。因为书法老师根本不懂营销、不懂用户、不懂市场。

他还说，市面上书法课程体系非常混乱，课程太多，连小白消费者都会觉得犯难。这点我很佩服渔火，他在什么都不懂的时候，仅靠用户调研就能开发出这么多课。

但说实话，我最不擅长的就是用户调研，我不知道那群老年用户到底在哪，也看不到他们的需求。没办法，只能上课程平台看书法课的销量，上电商平台看哪些字帖卖得火，来补一补行业认知。还特意买了很多书法相关书籍，看他们怎么给小白设置目录。

期间，我潜伏到几个同行的免费群里，看他们怎么做免费课、怎么转化，留意他们的课程安排、话术和一对一私聊。

最让我受不了的是，有些机构简直是在骚扰用户。早中晚、开课前五小时、三小时、一小时、半小时、十分钟、五分钟，一直给你发信息。我统计过，光私信一天就有二十多条。你要是不点链接，他们还会直接打语音电话，说检测到你不在直播间。要不是为了观察同行，我真的分分钟忍不下去。

可神奇的是，那些大爷大妈在群里超级配合，让签到就签到，让晒作业就晒作业，指哪打哪。这种配合度让我震惊，我朋友甚至怀疑群里全是托。

这些同行确实抓住了书法爱好者的痛点——他们反复强调“只要跟我们学，很快就能出效果”。但我也发现，很多主讲老师的水平很一般，笔划都是描出来的，不是一笔写成。因为我买书、看资料，已经知道这是误人子弟。

这就引出核心矛盾：做销售、搞流量需要考虑人性，可书法学习本身是反人性的。谁不想快速看到反馈？目标用户都是大爷大妈了，谁还有耐心慢慢磨？快餐式教学能活下来，但时间长了口碑必崩；认真打磨基本功，又可能招不到认可这种理念的用户，连活到口碑起来的日子都撑不到。

那段时间我看了《小米创业思考》，书里说：忘记同行，一切从用户需求出发。我就问自己：如果你是一个想学书法的小白，或者你的孩子朋友想学书法找你推荐，你最希望对方提供什么样的课程？什么样的体系和服务？

一句话，我想做长远的事，我要口碑传播。为了用户，也为了自己的良心。我不希望看到用户花了很多钱学几年，最后进步很慢甚至没效果。

所以我真的沉下心来找老师。通过朋友介绍、群推荐、BOSS直聘等各种方式，花了一个月时间，前后沟通了大约400人。里面有美院专业的，有自学的，也有中书协、省书协的。

一开始我只看头衔，以为头衔越高、学校越好，教学能力肯定没问题。后来发现书法圈水太深。小白想找个好老师，真的非常难。于是我不断迭代筛选标准：专业背景、头衔、教学经验、作品，还找专业顾问交叉验证，再到笔法理论、试讲视频、系统教学规划、作业批改……整了一大堆流程。

最后，从400人里挑出了8个左右。顾问告诉我，这个配置比很多线下艺考机构都要高。

我当时想：用户想学书法，我就一定要给最好的、最专业的课程。后来证明，这个想法又错了。

从5月到8月，我一直在闷头做产品、研发书法课程。我花了大量时间去验证老师录的视频讲得细不细，如果讲得不细，我或者同事作为小白听不懂，那就pass。

不管怎样，总算克服重重困难，做出了能推的初步产品。

但那段时间，我基本没管流量。心想，朋友那边会研究，我不需要操心。

# 说好一起干的朋友，半路去学习了

刚开始弄产品时，朋友一直怕我三分钟热度，担心我突然换赛道。我明确说这次会沉下心认真干。

后来，他觉得视频号机制跟小红书完全不同，有点水土不服，决定不研究视频号了，还是回去研究小红书。同时建议我有精力也自己研究下视频号。

然后，我们的联系越来越少。从零散互动里，我大概拼凑出：他似乎没在弄书法了。

到了8月，我告诉他产品初步成型，合作老师都定了，可以推广。他说他很忙，在一个很远的地方跟一位“有结果的人”学习怎么做流量，帮别人搭建团队，细节我不太了解。

期间我特意把他请到我办公室，给他看了整个产品体系规划、录好的课程视频、合作老师，只是想证明我一直在认真做产品。我还当面问了一句：还要不要一起做书法？他点了点头，说学完手上事情会联系我。

但我心里已经凉了半截。

我自己有个全职小伙伴，也是转行来的，什么都不会。既然朋友不想研究视频号，那就让小伙伴去研究，按手册操作，效果很差。当时我还想，朋友在弄流量，我把产品做好，到时候整合一下就行。

可时间一点点过去，我终于意识到：我不该把希望寄托在别人身上。我明明没什么主动获取流量的经验，却天真地以为可以不碰流量，把时间全砸在产品研发上。

朋友不知道什么时候才能腾出手，我也不可能一直等他，我还要养活团队。

最后，只能自己亲自上。等我真正去做流量，才知道自己错得有多离谱。

# 普通人想搞钱，一定要先搞流量

[PRE0]

“先搞流量，不要先做产品”这个忠告，亦仁讲过，其他人也反复讲过。我甚至在开工之前，还看过一个程序员独自研发半年抖音小程序、最后发现没用户的复盘。但以前看这些，真的一点感觉都没有，印象不深刻。只有自己亲自踩一遍，才明白这些话句句是良言。

可我明明看过，还是自己跳了进去。哪怕当初朋友铁了心一起干，也应该两个人先把流量跑通再做产品。更别说如果一个人干，更应该先搞流量。

因为不管卖什么产品，你都需要用户，需要获客。而我偏偏没有流量经验，只能硬着头皮一点点试。

8月下旬，我先模仿那些做得大的同行，招书法主播做直播，卖1元体验课。之前为了选合作录课老师，我储备了大量人选，但这时才发现，同行已经把直播价格卷起来了。他们给主播的待遇是一小时40-100元不等，还有提成。同时还会跟书法达人合作，获取一个用户名片给20-30元。按5%的转化率算，单个付费用户的获取成本高达600元！而且这种合作模式漏洞很大——推来的用户不精准、可能是水军，甚至可能是专门薅羊毛的。

当时我还笑同行傻，这么高的获客成本怎么赚钱？
等自己做的时候，才知道小丑竟是我自己。我们认为这种成本太高，于是自己招主播实际播。我们换了好几个主播，王牌主播给到一小时100元，场观能到1500-2000；其他主播平均只有200-400场观。转化率嘛，提都不用提。

分销团队也找了8个人，搞了半个月，一个用户都没转化。最后一算账，折腾半个月，只加了13个用户微信，引流成本一个用户就高达300元，而同行只要20-30元。

除了认栽还能怎样？于是我把所有分销兼职和主播全部停了。

请主播贵、成本高，那自己试吧。虽然不懂书法，但可以照着航海手册，打印一些作品和资料直接介绍。结果基本是秒进秒出。手机是几百块的安卓机，灯光不行，画面也模糊，场景更是糟糕。公司其他项目小伙伴看了一眼说：你这直播看起来就像骗子在直播。

这时候根本顾不上紧张，满脑子想的都是：到底要说些什么，才能让一个个活生生的用户愿意停下来听我讲？

总之，不管自己直播、招兼职主播、还是私信话术，没有一样数据是理想状态。

回头再看那段研究产品的时间——纠结定价、纠结课程体系、做各种成本测算，真的太滑稽了。
没有流量，一切都是0！

当初我还花了大量时间去研究书法具体笔法、产品细节，现在想想，完全是本末倒置。只要我找的老师足够专业、内容没有硬伤、不是糊弄人的垃圾产品、能好好交付就行了。产品优化和迭代，应该等有了大量用户之后，再请一个专业课程研发来搞。

我真的不该在那些细节上浪费那么多时间。

我总算认清现实：做这个项目，自己完全就是个草台班子。算了，还是老老实实研究短视频引流吧。

# 最后，数字人也救不了我

这时候，我刚好看到数字人训练营的推送。一听AI数字人，就觉得这或许是我们项目的希望，果断报名，还拉着同事一起学。

但群里同学和教练都没做过书法，给不了什么建议。甚至有个教练听到我在做书法，第一反应就让我换赛道。

我说：我已经在这个事上投入了几个月、砸了很多钱做产品，换赛道是不可能的。

半年，近8万，只换回来7个用户。但也许，这些用户就是我重新认识“流量为王”的最贵学费。
