**🍌案例 4**：毕业设计用书城小程序

- 来自哪里：小红书接单
- 用户想要什么：只做个能跑的书城小程序用于毕业设计，不上线正式环境，体验版能演示就行
- 我是怎么做的：
1. 随便找一个图书网站，把截图丢给 GPT，让它先出套 UI 方案。
2. 基于这套 UI 写出 PRD 文档。
3. 把 PRD 直接交给 CodeX 生成代码。

- 做的时候要特别注意：
1. 体验版小程序只用注册一个邮箱账号即可，无需走完整的备案与认证，发布后扫码就能在微信里正常打开，体验权限最多给 15 个人。
2. 这类项目会用到图片素材和后台管理功能，要注意小程序单文件上限 200k、整体包体上限 2M，超了就上传不上去。可以申请「小程序成长计划」领半年的免费云开发环境，把素材迁移到云存储，后台用静态网页托管实现网址登录。
3. 后端对接不用自己动手，直接让 CodeX 调用 cloudbase cli，整套对接它会自动完成，基本不用登录云后台，有问题直接把截图丢给 CodeX 让它修。

**🍌案例 5**：英语公开课用的 AI 对话智能体

- 来自哪里：闲鱼
- 用户需求变化：先想把《小麦不同生长阶段》的 PPT 整理成带交互的 HTML 网页，这个很简单，直接把 PPT 扔给 CodeX 生成 HTML 课件即可。交付后又追加需求，要基于他自己做的卡通小麦形象做一个英语对话 AI 智能体。

- 执行路径：
1. 先让 CodeX 依据用户提供的卡通形象搭出前端页面。
2. 去火山引擎申请豆包端到端语音大模型 API，免费额度有 100 万 token。
3. 在本地把 API 和网页连通调试效果。
4. 免费上线：代码推到 GitHub 仓库，再用 Cloudflare 的 Pages 功能关联仓库部署，拿到访问链接即可。

- 关键提醒：
1. 豆包的端到端语音模型调用成本不低，免费额度也消耗得快，因为它集成了语音识别、语音合成和大模型推理。给客户做项目时建议让客户自己注册账号用自己的额度；本案例只是给用户做单次公开课演示，我才用了自己的额度。
2. 网页部署我常用的两种做法：
- **GitHub Pages**：只适合纯静态页面 HTML/CSS/JS。好处是免费又简单，能绑定域名；坏处是仓库必须公开，代码结构一览无余，而且不支持后端逻辑，API 只能写在前端很容易暴露。
- **Cloudflare Pages**：适合 React、Vue 或纯静态站点。优点是全球 CDN 加速、自动 HTTPS、支持私有 GitHub 仓库自动部署，稳定性不错；API 可以放在 Cloudflare 后台配置，不会暴露在前端代码里。

六、底层逻辑 & 普通人怎么起步

**🍌🍌**拿结果的底层逻辑是什么

本质上是在赚认知差和执行差的钱。代码门槛已经被 AI 拉平了，真正值钱的不是会写代码，而是：

- 知道这件事能做，大多数人还在认为编程是程序员的专属；
- 愿意亲自把流程走一遍，先做出第一个作品，把上线、部署、交付的闭环摸熟；
- 能把用户的模糊需求整理清楚，再翻译成 CodeX 能执行的指令。

先跨过这三关，就能在当下的窗口期吃到需求。

**🍌🍌**普通人入场需要什么

- 来得及，而且正处在信息差红利期。现在是期末季和就业季，毕业设计、课程作业的需求非常集中，哪怕七月份还有大量学生没交作业，都是最后一刻才找人帮忙。除了学生群体，公司官网、老师公开课智能体、事业单位的知识库智能体、个人作品集主页的需求也在快速增长。

- 模型会越来越强，信息差会慢慢缩小，但认知差还会存在很久。生财就是你最好的知识库，没有理由不试。

- 现在马上开始，就是最好的时机。

[从 0-1 的实操路径](https://my.feishu.cn/wiki/SeAew1ABvisOo7kqoxicKRdInmc#share-DvJEddEc7oXgZlx8VqOczyPFn1d) 🍌🍌具体可参考前面的内容，这里把它压缩成一条可直接照抄的路线：

1. 准备：科学上网 → 充值 CodeX，官方订阅约 110 元/月，成品号十几到几十不等但易封号，建议参加线下聚会快速解决。
2. 练手：在 CodeX 里加装 product-design 插件，结合 sceneai.art、guizang-ppt-skill、gsap-skills、ECharts 等资源，让 CodeX 复刻 2-3 个网页或做 1 个小程序，把“生成 → 截图标注 → 修改”的循环跑通，形成自己的案例库。
3. 铺渠道：在闲鱼上架服务，参考同行页面，用 GPT 生成商品图，优化关键词避开违禁词；同时在小红书、抖音发作品笔记引流。
4. 冷启动：靠亲友凑单 + 超级擦亮，或直接投 29.9 的咨询量套餐，快速拿到曝光和评价。可多账号运营，一个人可注册 3 个闲鱼号。
5. 接单交付：接住咨询 → 先整理需求并用 GPT 做预览图给用户确认 → 发案例 → 报价 → 交给 CodeX 开发 → 截图迭代优化 → 交付。
6. 沉淀放大：把每个项目的插件、坑点、部署方式记录下来，从学生作业逐步扩展到商家小程序、企业官网、智能体等高客单业务。

遇到任何问题，直接用大白话问 CodeX，不要给自己设限。
