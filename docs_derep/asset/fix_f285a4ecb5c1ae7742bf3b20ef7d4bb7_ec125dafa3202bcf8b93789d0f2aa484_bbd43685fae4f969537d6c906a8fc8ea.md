# 从听众到发起人：一场聚会后的真实感受

上个周末，我参加了一场大型线下聚会。和以前不同的是，这次我不仅到了场，还亲自发起了一个小型讨论局。从普通听众到召集人的身份变化，使我对很多东西有了全新的理解。

我要感谢这个平台，感谢创始人亦仁，也感谢张老师，以及那14位愿意陪我一起探索的伙伴。那天的体验让我真正明白：顺着生命本来的方向走，放下目的性，多一些利他和觉察，结果往往比刻意安排更惊喜。

过去我总觉得这类社群主要谈赚钱，但这次作为发起人站在中间，才意识到它远不止如此。能够在自己关心的领域召集同好，本身就是一种很深的信任。

更幸运的是，我有幸获得了张老师的亲笔签名，也加上了他的微信。他本人温暖又平和。他的音频节目在我最犹豫的时候给过我很多支撑，前几天尝试轻断食时，那些声音也一直陪伴着我。

那天的分享阵容很丰富。我听到了多段真诚的讲述，也认识了不少气场相近的人：有生财、花爷两边团队的核心人物，有年收入数百万的老板，有心理学背景的专家，还有刚刚开始做心性探索的年轻人。

头一回组织活动，难免有疏漏。但14位伙伴都很包容，也主动补位。人数超额时，克寒和Amy一起帮忙另找地方；大家有些疲惫时，董硕带我们做静心练习；雅芳则一直细心照顾到了所有人。这些细节我都记得。

如果按那天的座位顺序回忆，每一位伙伴都给了我独特的启发：

雅芳的体贴和谦逊——她说，把用户当作家人；
七米的目标感和清晰表达；
董硕的敏锐和温柔（他发现气氛沉重，主动带大家静心）；
恋尧谈到想帮人的初心，也分享了她近期在内在探索中的体会；
敏敏对时间的掌控力令人佩服，忙完一整天还赶到现场，并带了一束花给我；
兰卡始终真诚，也总在给别人正向回应；
克寒的号召力把兰卡、敏敏、澜澜都带到了现场，他提议所有人都说说各自的体会，使整个房间的氛围更强了；
小Z虽然害羞，却愿意打开自己，把经验和思考讲给大家听；
🔅身上那份从容笃定，正是我最想学习的；
周聪让我看到心性成长的另一条路，也使我对这一群体有了更多理解；
玉兰善于归纳，也不断提醒大家各种事项；
Amy讲了她近期的“愿景成真”和不少实用方法，也使我更愿意跟随生命的节奏；
CRAZY对所走方向的坚信让我动容；
澜澜那份感知力和直觉力，让我这个逻辑脑自愧不如。

这场相遇给了我很多向前的定力。往后，我只想继续心怀感谢，向一切人和事学习，放下控制，练习信任，好好爱自己、修自己，再把善意传递出去。简单说，就是让自己做一条管道。

也许有人想问，所谓“内在探索”到底是什么？这个问题时常被问起，我也一直不知道如何说清楚。今天脑海里忽然冒出一句话：它是一条让人找到自己的路——在广袤的世界里确认使命，在茫茫人海中认出彼此。沿着这个方向走下去，希望我们都能成为自己，也都能拥有内心丰盈、时间自由、财务自由的生活。

谢谢你的时间。愿我们都在各自的路上，活得越来越像自己。
