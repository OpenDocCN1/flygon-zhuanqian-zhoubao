**1、我为什么有资格聊 TOB 和 TOC 的推广选择？**

很多人对我的第一印象就是做 SEO 的，甚至以为我只会刷网站排名。实际上 SEO 只是我工具箱里的一件工具。

从十年前入行开始，我就一直横跨 TOB 和 TOC 业务。先做销售，后转网络推广，做外链、做网站 SEO、做淘宝 SEO，做到项目主管。2014 年加入王氏大闸蟹做运营经理。

即使现在做了近四年自由职业，本质上就是一人公司，每周都要给不同类型的 TOB、TOC 业务做精准流量的诊断。不管是理论沉淀还是实战经验，都够说两句。

不管你是企业员工、自由创业者还是老板，都可以参考一下。

**2、企业 TOB 与 TOC 业务有什么区别？**

先说 TOB。

TOB 的核心含义是你的客户是企业，是企业为你买单。

举个例子，我早期在维库做电子市场金牌会员、钻石会员销售，后来在日贸通卖会员，这些都是典型的 TOB。现阶段很多代运营公司，为百度、抖音等平台做推广投放服务，白杨 SEO 为企业做流量顾问，都属于 TOB 服务。

TOB 和 B2B 有关系吗？B2B 主要是电子商务平台的概念，比如阿里巴巴、维库电子市场。TOB 只是业务属性。很多做 TOB 的公司会选择去 B2B 平台拿线索，比如在阿里巴巴开店，因为下游采购商习惯去那里找货。

再说 TOC。

TOC 就是企业面向个人，是个人为你付钱。

比如我之前在王氏卖大闸蟹，天猫、官网销售，都是个人用户在中秋国庆时买礼品。后来在登虹做【和目】APP 运营，买云存储看视频的都是 C 端用户。白杨 SEO 自己运营了近七年的 SEO 流量圈付费社群，里面大部分也是个人用户。

一家企业只能做一种吗？完全不是。BAT、华为都是双栖。百度既有面向企业的百度推广，也有面向个人的文库会员。华为既卖手机给个人，也有庞大的企业服务业务。

只要摸清楚自家产品是卖给谁，就知道属于 TOB、TOC 还是两者兼顾。

**3、TOB 与 TOC 客户各自关注重点有哪些？**

[PRE5]

TOB 客户做选择时，核心看的是你值不值得信赖。看重团队实力、过往案例、能带来的实际价值、价格和服务是否匹配。归根结底就是：别人用过没？效果怎么样？

TOC 客户则分两层。追求品质和品牌的会看重价值感和调性，普通大众更敏感的是价格、优惠、划不划算。比如京东用户和拼多多用户的决策逻辑就明显不同。

而且 TOC 的消费心智更感性。直播带货火爆，除了价格锚点外，更重要的是情绪价值和即时感。

额外补充一点：**TOB 的成交周期更长、决策更理性**。企业每一笔支出都需要合理依据，涉及多层审批，钱花出去必须能回本。而 TOC 的消费更冲动、门槛更低。

**4、TOB 与 TOC 客户流量增长区别有哪些？（重点）**

TOB 客户流量获取方法：

线上来看，商品类 TOB 可以优先考虑阿里巴巴等传统 B2B 平台开店；服务类 TOB 百度推广是基本盘，付费也好自然排名也好都要做。抖音对于 TOB 服务更是不能忽视。

线下则要深耕行业展会和线下会议。

最传统但依然有效的是电销，现在很多公司已经用 AI 外呼来筛选。老客户转介绍、老带新也是稳定来源。

从组织上说，企业最好内部有懂推广的人。我徒弟就在温州一家游乐设备公司负责全案推广，投放和 SEO 都能上手。没有的话，要么招人，要么培养人，外包只能解燃眉之急。

TOC 客户流量获取方法：

最直接的就是花钱买量，投信息流、投搜索关键词。

目前 C 端主力阵地主要是微信、抖音、小红书。微信可以投广点通、朋友圈、公众号底部广告、搜一搜广告；抖音和小红书同样有信息流和关键词投放。

投信息流的核心是素材和文案是否打动人；投搜索的核心是选对关键词和保证落地页匹配度。前者更依赖投放师+设计师，后者更需要懂搜索逻辑的人。

不想花钱也可以做免费增长，比如搜索优化、内容推荐、直播带货。玩法上分搜索流量和推荐流量，具体怎么选可参考我之前的文章，如图。

有人问社群裂变行不行？当然行，但前提是种子用户从哪来，最终还是要回流到推广。

总结下来，TOB 与 TOC 最大的差异就在平台选择上。TOB 更集中在百度和抖音；TOC 更集中在微信、抖音、小红书。若业务是双轨制，抖音、知乎都是兼顾的渠道。最终判断标准只有一个：你的目标客户平常都在哪个平台出现？
