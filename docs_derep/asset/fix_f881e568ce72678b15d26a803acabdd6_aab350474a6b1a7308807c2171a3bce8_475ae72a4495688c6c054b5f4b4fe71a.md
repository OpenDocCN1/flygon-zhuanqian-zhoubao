# 创建扣子工作流

先说明，这个流程想解决什么？

把原本的：

*   看到目标视频 -
*   复制链接 -
*   打开小程序 -
*   粘贴链接 -
*   等待识别 -
*   复制文案 -
*   打开网页 -
*   打开飞书 -
*   新建文档 -
*   粘贴内容

十步操作，压缩成一步：

看到视频直接转发给飞书机器人。

这就是工作流的核心价值：

用五分钟搭建，换来之后每次三十秒的效率。

## 参数配置

先确认全流程的进出关系：

*   上一节点的输出 = 下一节点的输入
*   下一节点的输入也可引用更前的节点输出

起始节点保持默认。

### 配置视频文案提取节点

【视频文案提取节点】：提取视频文字并输出

[PRE17]

需填两个输入：

*   ali_bailian_api_key
*   douyin_url

含义直观：

ali_bailian_api_key 为阿里百炼的 API 密钥，去阿里百炼平台免费注册登录即可。

[PRE18]

有百万 Token 免费额度，具体申请方式篇幅受限，可用元宝、豆包、千问、秘塔搜索。

[PRE19]

第二个参数 douyin_url，

不用每次手动填链接，点输入框右侧⚙️，选择起始节点的 input 即可。

# 逻辑比工具更重要

首个工作流跑通后，你就理解了 AI 自动化的核心：

从起点到终点，由不同功能节点串联组合。

掌握这点，再复杂的流程也不怕。

别嫌它简陋，我后来的「Claude 文案导入飞书自动写入公众号」流程，就是从这四节点演化来的，目前部分自动化：

我的长期观点：

工具本身不重要，关键在怎么用。

*   再强，用不好就是累赘；
*   再普通，用对了就是利器。

所以不必焦虑，目前 AI 仍是工具。

能用就用，不能用就放。

行动建议：

1.  先从今天这个简单流程起步
1.  熟悉逻辑后再尝试更复杂自动化
1.  工具会过时，思维不会

先试试，搭建好后看到好文案，发个链接就搞定。

再考虑更高阶玩法，比如：自动抓取网页内容，整理改写，配图发公众号？
