### 步骤三：把自动推送脚本放到 GitHub

脚本的核心逻辑是云端定时运行：每天执行一次 → 调热榜 API 拉最新数据 → 调用 WxPusher API 推到微信。

代码已上传，需要就自取

1️⃣ Fork 仓库

访问：https://github.com/nancy4567891011/wechat-hotlist-pusher-public

点 “Fork”

[PRE26]

Fork 到自己账号下，才能在你的云端定时推送

### 步骤四：设置定时任务

2️⃣ 配置 Secrets

进入已 Fork 的仓库

Settings → Secrets and variables → Actions

逐条添加以下 Secrets：

[PRE27]

注意要一条条单独添加

*   WXPUSHER_APP_TOKEN ： WxPusher 应用令牌
*   WXPUSHER_UID ： WxPusher 用户 UID
*   TIANAPI_KEY ： 天行 API 密钥

配置完记得把仓库设为私有，防止密钥泄露

[PRE28]

添加完成后状态如下

[PRE29]

进入 ACTIONS 标签页，点击绿色按钮，选择测试模式 true，然后点 RUN WORKFLOWS，这是试跑；若要正式每日推送就选 false

[PRE30]

点击 Run workflow 开始测试

[PRE31]

运行日志会多出一行记录。若微信绑定无误，应能收到推送。

[PRE32]

手机端也会收到一条
