## 跑图避坑指南

### 图片存储

#### 预览图怎么留存

想留预览图的话，不建议直接按保存。更稳的方式是：在预览图上点右键，选择“另存为”或在新标签页打开后手动保存。

[PRE6]

#### 额外接入一个存储节点

预览图节点只负责展示，并不会真正把文件写入硬盘。想要保存成果，必须再挂一个存储节点。

具体操作：双击画布空白处，搜索 Save Image，点选结果即可把该节点加入工作区。

[PRE7]

把两个同为图像类型的蓝色端口连接起来，图片就能正常保存了。顺带一提，“土豆”这个前缀在节点上可作为输入内容，也可以变成连线口。右键选择转成输入模式，就能随意切换。

[PRE8]

### 报错排查

#### 缺组件

[PRE9]

如果图里出现找不到某节点的警告，用自动补装功能把依赖装好就行。

[PRE10]

[PRE11]

完成之后再重启一次，整个流程就能继续跑。

要是接下来还提示没有模型，就得把对应模型文件下载下来，再传到云平台。操作细节参考官方的模型导入教程。

官方文档在模型安装部分推荐用百度网盘传文件，开通会员能达到最高速度。

[PRE13]

#### 一运行就报错

如果导入一切正常，运行却中断，一般是模型的命名和实际文件不一致。检查平台上是否有同名权重；有就手动换过来，没有就重新下载再导入。

[PRE14]

例如截图里的报错，就是因为模型文件名不同。把选项改成和实际文件一致即可。

[PRE15]

而 LoRA 模块报错，则说明缺少对应的 LoRA 文件，补齐后即可正常运行。

[PRE16]

#### 释放显存

别忘了在跑图前释放一下显存，很多错误都是显存占用过高引发的。

[PRE17]

[PRE18]

#### 重启试试

如果显存爆掉或浏览器开的页面太多，运行过程也可能突然失败。只要看到屏幕上出现具体错误信息，不妨先重启一次。

比如 "allocation on device" 报错，按下重启按钮，等一分钟左右刷新浏览器即可。
