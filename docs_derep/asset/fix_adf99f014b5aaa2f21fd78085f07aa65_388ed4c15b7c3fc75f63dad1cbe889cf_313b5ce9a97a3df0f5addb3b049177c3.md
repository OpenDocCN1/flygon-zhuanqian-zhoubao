# 解散团队 —— 无条件信任自己的选择

看到这里，你或许以为我现在靠副业躺赚了，但事实并非。

我现在已彻底离开虚拟资料赛道，为什么呢？

最初坚持，是因为有明确的驱动：完成既定目标、验证模式可行、获得外界认可、实现变现……正是这些让我咬牙坚持。

小红书虚拟资料跑通后，我尝试放大规模，组了一个小团队。

白天在职，晚上带成员实操。

团队成员陆续实现收入，我采用分成机制把他们推向前。

[PRE14]

但规模越大，内心越抗拒。

每天都在问自己：“我愿意一直做下去吗？”

答案是否定的。

那种感觉很像当年做设计的无力感：并非发自内心的事，即便达成绩效，也提不起满足感。

在418活动之前，我做了一个外界看来不太理智的决定——解散团队。

有人觉得不该放手，毕竟组建团队的机会不多。

有人感叹可惜。

我自己也反复权衡、自我怀疑。

最终，我依然选择了说不。

理由很简单：我不喜欢。

我不想为钱逼自己，也不想走一条违心的路。

别人赚多少与我无关，我要做的是我真正热爱并愿意放大的事。

分享一句我在私域大会上听到的、让我更坚定的话：

“活着的意义除了体验，就没了。所以，无所吊谓” ——云蔓

[PRE15]

于是我把重心收回到自己喜欢的领域——IP。

我喜欢教练的状态，喜欢分享带来的回响，喜欢陪伴他人突破瓶颈后的踏实感。

所以我开始聚焦公众号、AI自媒体、朋友圈的日常记录，来扩大影响半径。

这些事让我快乐，也觉得有意义。

它们更像生活的一部分，而非待办事项。

至今我仍提醒自己：“无条件信任自己的判断。”

对错要走完才知，但只要此刻出于真心，就是最好的选择。

我庆幸自己敢于解散团队，因为它让我更清晰：

金钱不是终极目标，能长期热爱并坚持下去的事，才是我要追寻的方向。
