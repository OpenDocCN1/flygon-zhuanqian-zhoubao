一条视频从立项到发布，从最初磨一个月，到熟练后缩到一两周，再到如今稳定一周一条、每天只需工作半天——这中间最大的变量，就是我把AI接入了B站好物项目的每个环节。选品、制作、发布，所有能自动化的工作都尽量交给AI，顺手也让过程中的数据沉淀成了可复用的资产，而且后期还能更快。

大家好，我是拿铁。曾经是UI设计师，现在自由职业。作为B站好物深海圈二期学员兼志愿者，我赶在618期间跑通了项目的0-1验证。坦白说，因为产能限制，并没有拿到特别亮眼的结果，目前正处在提效放大的阶段。

在我看来，B站好物本质上就是CPS加内容，要靠数量去对抗概率。想要放大，要么提效，要么矩阵化。观察下来，那些成绩不错的圈友教练几乎都走了这两条路。这也促使我下定决心用AI来提效。这里要感谢Lynn、葱哥和书野，我的很多思路都受到他们启发。

[PRE0]

先说最实际的，你能直接拿走什么：几个现成的Skill（项目归档、参数采集、选品规则、素材整理等），用知识库调教AI生成内容的思路，本地可用的PPT批量套版工具（附带PPT图片转HTML的Skill和PPT制作规范Skill），用自然语言剪辑A-roll的思路，以及发布前的物料准备提示词（标题、简介、标签）。

这次分享更侧重思路层面。我是以一个AI小白的身份，深度使用了一个月AI，在项目实操里积累的经验。如果你Agent用得还不多，或者还没把AI接进自己的业务，又不知道怎么做Skill或Agent，那应该会有收获。我平时用得多的是Codex，偶尔也用CC外接国产大模型。说白了，就是把AI当成一个项目助手，让它处理自动化的重复操作，好把精力集中在决策上。

AI现在主要帮我做三件事：第一，完成重复性劳动；第二，把零散信息整理成能直接用的资产；第三，把每次过程中的内容沉淀下来，变成下次可以复用的数据资产。下面的分享以Codex为例，但提示词投喂给各种Agent都适用。另外，目前所有Skill都是基础版，需要你结合自己的真实场景去迭代。

项目大纲包括：项目规划助手、建立项目文件、内容提取与改写、获取产品参数、制作PPT与参数批量替换、素材制作与整理、A-roll剪辑思路，以及视频标题、简介、标签的制作。

先说项目规划助手。做项目时，我遇到的最大困扰不是难题太多，而是常常不知道每天的工作目标是什么。尤其是刚起步的时候，怎么确定每天的目标和产出？怎么把一个项目拆解成SOP？这些事特别容易卡住。我本身是个P人，天生不擅长规划，所以第一个做的工具就是项目规划助手，灵感部分来自书野教练分享的生产计划。

[PRE1]

我先把整个生产计划按照自己的项目流程细化，从开始到结束需要产出哪些物料，把所有动作尽量拆小。这个过程能帮你发现哪些环节值得提效、哪些环节最耗时、哪些流程比较混乱。迭代之后，整体效率会明显提升。

之后我开始和AI亦仁聊项目。最初只是想聊聊心力和生活上的问题，后来发现它给的内容比市面上很多AI更实际、更有参考价值，于是试着把项目问题也拿过去聊。结果它不仅能指出很多我没注意到的点，还会给出即刻就能落地的动作规划，建议非常接地气。

[PRE2]

使用上我有几个心得：一是尽可能把遇到的问题、手头的资产和实际涉及的东西都喂给它，信息越全回答越有效；二是聊完后建议多花几个小时去拆解对话，把全部内容复制下来，让AI整理成Markdown文档，再投喂给AI；三是可以搭一个Skill，让Codex直接访问网页端的AI亦仁。

因为我实在不擅长项目规划和日程规划，所以会把和亦仁聊的所有内容都投给AI，让它帮我拆解每周、每日的任务。这个Agent的提示词就是“工作规划秘书Agent”。如果你是Mac系统，还可以让AI自动把任务同步到提醒事项或日历里；Windows用户也可以试试常用的日程或待办软件，让AI帮忙打通。总之，技术层面的东西全部交给AI就好。

[PRE3][PRE4]

接下来是建立项目文件。做视频会产生大量素材，包括素材包、表格、成品等，电脑里很容易堆得乱七八糟。为了以后能复用，我参考了“影视飓风”的视频项目生产框架，搭了自己的项目文件夹。方法很简单：把他们的层级截图发给AI，让它帮忙建立同样的框架，并记住文件结构。如果你有自己的调整，调整完把整个项目文件夹扔给它，让它记住结构。之后每次只要输入项目名称，AI就能自动生成项目文件夹，对应的提示词是“素材归档命名Agent”。

选品环节，京东联盟支持一键导出选品车里的所有链接信息，生成Excel表。拿到表格后，直接导入AI，再设定一套预设的选品规则。

[PRE5]

规则可以包括佣金、销量、品牌等关联维度，每次筛选多少款也由你自己定。AI筛完之后，让它总结整个选品过程的优先级顺序，它就会自动生成选品SOP——我这边有一份自己的示例，大家可以根据自己的选品要求去生成专属版本。虽然AI选品不算完美，但第一轮能帮你筛掉绝大多数产品。如果筛完还有一两款不合适，可以这样处理：让AI做二次筛选，提供更多替换选择；或者直接在表格里按价格、品牌排序，自己手动调整。

[PRE6][PRE7]

用这套方法，从几十款产品里快速选出10到20款并不难。我自己有点选择困难症，以前总在选品上纠结太久，现在让AI按规则做取舍，时间省下了一大截。相关提示词详见附件。

选完品后，把最终结果整合到飞书文档或本地知识库，也可以直接让它生成Excel。接下来就是很多人问的“获取产品参数”。我最早让AI爬取时，不小心触发了京东风控，账号被停用一天，之后所有页面都变成风控界面，无法识别参数，效率很受影响。后来和AI反复沟通，分了三轮解决：第一轮，让它模仿人工操作的方式去避开风控验证，同时让AI到后台运行，不要抢占屏幕焦点，这样我还能同时干别的事；第二轮，因为每类产品的参数不一样，我先把需要哪几个参数规范好，提前告诉它；第三轮，京东页面上的参数经常缺失，其实很多藏在详情页图片里，于是让AI提取图片内容来补全参数。最后用本地OCR，基本一轮就能获取完，少量手动补或者直接留空都行。如果Codex直接操作浏览器效果不好，Windows用户还可以试试opencli方案，让AI通过视觉方式操作浏览器。官网是https://opencli.info/download，Google浏览器插件在https://github.com/jackwener/opencli/releases，本地安装执行npm install -g @jackwener/opencli，然后opencli doctor。提示词对应的是“商品详情页参数采集Agent工作说明”。

素材整理同样可以交给AI。每批产品有十几二十款，从网上下载的压缩包、视频和图片非常多，而且文件夹都带产品标题。我一般会提前把选品表投喂给AI，告诉它下载文件在哪里，让它按照命名规则自动分类整理到项目文件夹里，省去了手动拖拽的麻烦。提示词是“素材归类整理”。

内容生产这块，最棘手的是AI写出来的东西“AI味”很重。我的解决办法是沉淀本地内容知识库。具体分几步：第一步，先在知乎或B站找一些科普类知识存下来；第二步，针对产品详情页的内容，按自己的口播逻辑录一遍口述素材。有了这些输入后，我先让AI生成一版完整口播稿，这套流程也能同步产出蓝链文案。虽然初稿通常不能用，但能帮我把整体逻辑架构搭起来。然后我会在它的基础上手动改写，调整产品点的结构，形成一篇真正有个人风格的口播稿。接下来，我建立一个本地知识库，让AI对比“我改好的稿子”和“它给我的初稿”，找出结构、节奏、口语化表达上的差异，生成一份报告。多做几次这样的对比，基础资料会越来越全，AI也能基于多份“人改稿”和“AI稿”的对比，生成你的专属写作Skill。平时还能微调，比如如果它总用“不要怎样，而要怎样”这种书面化AI腔，就明确告诉它禁用；也可以给它一个固定的产品讲解结构，写进Prompt。核心就是通过人机对比，让AI越来越懂你的表达习惯。

PPT和参数批量替换这块，我最早做的是Figma插件。当时书野在直播里分享了“稿定设计”的会员功能，能批量替换画板中的文字参数和样式，但Figma插件中心没有现成的免费工具。考虑到Figma的功能和流畅度更好，我就决定用AI自己写一个插件。以前没AI，我不会开发，只能等别人现成的插件；现在不一样了，我可以把功能需求、操作逻辑和预期效果一点点描述给AI。第一版基本能达到可用状态，后续修了几个小bug。不过插件用起来还是有点繁琐，要手动建画板、替换产品图、调整大小，但至少省去了大量无脑复制粘贴的时间。

后来看到“星空海绵”分享的用HTML做PPT的方法，虽然能在网页上改文字，但版式不够美观，而且每张都要截图，不太方便。于是我在这个基础上做了“二开”：先做了个MVP，把HTML代码投喂给AI，告诉它我提供固定版式和Excel表格，让它自动替换文字字段和图片，并帮我批量重命名。界面虽然粗糙，但核心流程跑通了。最终版是在真实使用中不断迭代，修掉了图片导出不达标、文字段遗漏这些细节问题。

[PRE8]

在流程化和规范化上，我定了两个规则。首先是HTML写入格式规则，这是为了让AI生成的HTML能满足网站导入要求。模板生成方面，我懒得手做，直接把布局需求和以前手搓的模板发给GPT，让它生成SVG图片；再把SVG拖入Figma，用Codex插件读取Figma画板内容，转换成HTML版PPT模板。然后是Excel导入规则：表格要求每行一个产品。

[PRE9]

第一行或自动识别到的表头作为字段名；第一列默认当作产品名，也可以在前端选择图片匹配字段；模板字段和表头完全同名时会自动匹配；如果不同名，就在“字段映射”区域手动选择对应表头。图片的导入规则是：从本地文件夹上传图片，不放进Excel。匹配方式上，默认优先选择类似“型号简写、产品型号、型号、产品名”的字段；也可以手动选择匹配字段；图片文件名需要和该字段内容标准化后精确匹配。这就是我的PPT制作思路，你也可以按自己的逻辑把这些AI工具串联起来，打造专属工作流。相关提示词的源码下载地址是https://pan.quark.cn/s/5639a3e3a013，把文件发给你的Agent工具后，可以输入以下提示词：“请读取我上传的完整HTML-PPT-Batch-Workbench-Delivery交付包，帮我在本机解压、检查Node.js LTS、启动html-ppt-workbench-local本地工具并确认浏览器可打开；同时把html-ppt-workbench-local/docs/HTML-PPT批量套版工具使用说明.md、PPT-Figma转HTML模板Skill说明.md、好物PPT制作规则总结.md作为当前项目的长期规则/Skill知识学习并保存，之后凡是帮我生成、转换、检查HTML PPT模板或好物PPT，都必须遵守这些规则，最后告诉我本地启动方式、访问地址、安装结果和规则保存位置。”
