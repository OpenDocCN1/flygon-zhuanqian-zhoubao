# 群买买停运内幕：一位服务商两年沉浮手记，8点教训给社交电商人提个醒

4月4日，群买买的官方公众号发布了终止运营服务的公告。这则信息，等于是给项目正式画上了句号。

实际上风声更早。3月22日左右，拼多多要关掉群买买的消息就在小圈子里暗传。官方一直没有正式回复，我也就按老规矩对外说“以官方为准，我这边没有确切消息”。直到3月26日上午，群买买的运营负责人专程来杭州当面告知关停计划，我才确认下来。说实话，我自己并不意外，只是底下的团队长被打了个措手不及。

我从入场到现在将近两年。团队累计成交1.5亿GMV，给下面团队长结算佣金超过2400万，而我们自己在这盘里落袋的只有几百万，远低于预期。表面看收益约730万，其中大团队的大部分收入是由我们代发，再扣除税费和人力成本，净利其实很薄。

两年间经历太多，趁这次收尾做个总结，也算是给自己一个交代，同时希望做社交电商的创业者和团队长能借鉴，避免踩坑。

**先说立场：下面全是事实陈述，不夹带情绪。**

## 先试水，后重仓

2021年5月，我们在找新赛道。我同时看了快团团和群买买，都是拼多多系产品。

先测快团团。拿朋友那边一个无线耳机试水，上架后发朋友圈，单条带来1.7万成交，毛利近7000元，看起来很可观。但快团团需要自己扛售后，我们过去只给淘宝京东导流，从来没做过备货、对接供应链、处理售后，感觉负担太重，于是停了。

6月，群买买的负责人找到我，聊了他们的规划。我再做一次测试，从群买买挑一款女士腕表发朋友圈，一条卖出1.5万，佣金约5000元，且售后由平台承担。

两者一比，群买买参与成本更低，更适合我们这批导购背景的人。为此我专门去上海总部谈过几次。最初谈的是付费推广，后来了解运营机制后，我决定深度绑定，而不是做一次性广告。

2021年7月，我没做大规模推广，只靠朋友圈招募团队长，自己带点量，首月就做到500万GMV。同月我发了一篇公众号《群买买，拼多多的社交电商野心有多大？》，被28家自媒体转载，全网阅读超30万。那段时间群买买在微信的搜索热度一度超过其他社交电商平台之和。

借着这波热度，我们的代理店主数冲到35万，业绩从每月500万攀升到2021年11月的1800万/月，正冲着月亿级目标走。

## 政策一改，盘子崩了

2021年11月29日，官方通知12月1日起调整代理政策，只给了两天传达时间，直接导致盘子崩盘。

改动核心是分佣规则。原来店主累计消费满298元，可长期拿直推一级15%佣金；累计满1000元，可长期拿25%。12月1日起改为按月清零：当月要卖298元才能拿15%，要卖3000元才能拿25%，每月归零重算。

这一改，店主流失超六成。那阵子分销商骂声一片，认为平台野蛮粗暴，先拉人进来做起来再收割，完全失信。

经历12月大调整后，业绩从1800万/月跌到1000万/月，过完年到2022年初回落到800万/月，跌幅超50%。

即便如此，我们仍维持合作，周会月会照开。直到2022年4月的另一件事，让我基本不再主推群买买。

## 从1%到0.1%的失信

合作之初约定，每月从总GMV中提取1%作为服务商额外激励，前几个月都正常发放。1800万/月时我们可拿到18万。但2022年4月，群买买未沟通就把比例调成0.1%，几乎砍掉。

我去沟通，对方说1%本就有浮动，降到0.8、0.9、0.7都可接受，但前提要提前说。结果一声不吭直接砍到0.1%，我付给第三方的手续费都不够，还要倒贴。

沟通中官方态度强硬，永远那句话“领导安排，我们只能执行”。那种人为刀俎我为鱼肉的感觉很真实。

我直接告知不再重点投入。官方随后开始联系我下面的团队长，在团队内部制造对立，鼓动他们脱离出去。这种操作让我至今反感。

## 经销商返点内幕

这段我本不想提，但很多人一直疑惑。项目结束后再说也无妨。

当初我们以经销商身份合作，每月按销售额返1.5%-3%给公司利润，对方要求保密。2021年4月后，官方认定我们不愿继续，就暗中向下面放风，说我们每月拿返点。

后来团队长借机闹事，要求分返点。此前我们是按业绩给额外奖励，这次他们要求按比例直接分，不考核。只要不同意，官方就怂恿团队长独立出去。

社交电商的核心是关系链绑定，如果平台可以随意拆散关系，谁还敢做。2022年4-5月那两个月我被折磨得很痛苦，感觉被算计。从那以后我几乎不再推广，只安排同事例行维护。

最终我们与闹独立的团队长达成妥协，每月分出一部分经销商返点给他们，如何分配不管，至今仍在执行。

## 收尾：合并迁移形同虚设

官方善后方案是把群买买运营并入快团团，把用户迁过去。但两者模式不同。快团团是二级帮卖，群买买是多级分销裂变，硬合并基本无效果。

现在愿意跟进新平台的，我们引荐到别的社交电商；不少人已经流失。

## 两年沉淀的八点判断

1. 社交电商立项时就要把代理分销机制想清楚。不能为冲短期业绩大补贴，回头亏了就立刻改，这会重创团队信任，甚至导致盘崩。
2. 大公司和上市公司谨慎碰社交电商。这类业务法律风险多，大公司操盘者是打工的，不愿也不敢担责。创业公司敢做是创始人扛风险，大公司内耗严重，项目容易流产。
3. 操盘团队需要老兵。成熟的团队懂节奏，不会为短期KPI乱改规则。年轻操盘手经验不足，打法随意，最终把项目拖死，自己拍拍手走人，受损的是团队长。
4. 政策调整要循序渐进。别今天猛激励明天就停，政策反复会让所有人没安全感。调整要提前沟通，给足过渡期。
5. 即便要关停，也要体面善后。别强行快速关闭，要给团队长一个可行的出口，最好支持关系链平移。江湖口碑比短期利益重要，未来可能还需这些伙伴。
6. 官方要听得进反馈。不要闭门造车。最好让自己家人也实际体验，才能更客观理解团队长的痛点。
7. 团队长选平台要擦亮眼。别轻易加入大公司试水的社交电商项目，主业不在此，关闭概率高。进去即陪太子读书，投入产出严重失衡。
8. 社交电商坑很深，进易出难。没进场前你是甲方，进去后是乙方。团队带进去很难带出来，平台想怎么调就怎么调，话语权几乎为零。

这篇复盘一是为了给自己过去两年一个交代，二是希望正在或准备做社交电商的朋友能有所参考。

评论区有人说写得好，想当初眼光超前，没想到背后这么多辛酸。我回：很多没写出来，给了对方面子。也有人提到之前生鲜社交电商每日一淘也是年轻团队乱改政策后迅速衰落。亦仁总结：躺赚的只有定规则的人，做题家别幻想躺赚。IDO老徐点赞“江湖口碑比什么都重要”。我认同，还是要有自己的基本盘才可靠。
