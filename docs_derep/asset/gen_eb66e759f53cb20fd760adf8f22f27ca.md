# 《线下小聚复盘笔记：想持续赚钱，先看懂这份不变的个人核心竞争力》

大家好，我是丽丽，营销背景转运营。

这篇是我在全国见面会结束后，和小组伙伴一起做的线下小范围复盘整理。

为什么会选「赚钱的个人核心竞争力」这个话题来拆？

因为项目会过时，风口会轮转，红利永远在变。真正能让我们长期吃上饭的，不是追逐下一个机会，而是抓住那些几乎不会变的底层能力。核心竞争力就是其中最关键的那一部分。

当你手里握住了真正属于自己的核心竞争力，你就能做到三件事：

一是项目切换不掉队，能力可以平移到新赛道；
二是周期来了也能稳住，具备穿越波动的能力；
三是即使大盘下行，你仍然能在自己的小范围里活下来、甚至赚钱。

所以，与其每天焦虑下一个风口，不如把时间用在把不变的本事做扎实。
