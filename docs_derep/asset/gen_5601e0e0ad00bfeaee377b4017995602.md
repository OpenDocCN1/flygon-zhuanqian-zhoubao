# 遇到的困境

作为新人，我一直奉行少说话多做事。首次接触这个品类，面对海量素材完全无从下手。做一条 1-2 分钟的视频往往要花三四个小时以上，再加上对品类认知不足，违规、反复修改的情况非常多，焦虑感在入职一周后就开始指数级放大。

眼看快要撑不下去时，恰好刷到亦仁的小灯塔《如何提升自己的心力》。看完后我告诉自己再扛一扛，也许能闯过去。

# 转机

# 经验总结

目前信息流广告素材大致可分为几种：

1. 纯数字人素材/数字人+产品素材
2. 纯真人口播/真人口播+产品素材
3. 吸睛开头+数字人产品上下分屏+产品介绍+背书+活动优惠

中段顺序可灵活调整，例如数字人开头+产品上下分屏介绍+数字人促销+反馈+数字人收尾。

再分享几条我总结的爆款思路：

一、多看同行，持续吸灵感
日常要大量浏览朋友圈、公众号广告、视频号的同行素材。最省事的起量方式就是复制 TOP 榜的爆款。挑选贴合自家产品的素材拆解开头、中段、结尾，分析画面构成和大字标题位置。我一般直接结构化拆解。

数字人视频可直接下载，用剪映导出字幕，改成自家产品，保留 85%-95% 的内容。产品画面按需增减，然后在即创里用同样的数字人和配音生成，最后导入剪映一比一复刻细节即可投放。

二、优先用已被验证的形象
制作数字人时，优先选用跑量过的形象，别凭个人喜好乱选。我早期复刻时用非爆款形象也还行，第二天换成与对标完全一致的形象后直接起量。

也可以先用对标形象测试，若效果不佳再换同类型热门形象。经过市场验证的形象和声音，起量概率更高。

三、二次利用爆款
已有爆款可以换同气质数字人继续投放，或只改第一句开头，变成全新素材，经常会成为隐藏爆款。

四、封面和开头决定生死
开头封面至关重要。抖音的逻辑同样适用，第一眼必须抓人。新奇、夸张、反常识的标题配合人物形象，会大幅提升完播。标题要与人物匹配，否则用户会快速划走。

五、深挖产品和人群痛点
一定要吃透产品，抓住目标人群的痛点。改写文案时要把爆款的表达迁移到自家产品上，越贴合越容易出效果。当感觉“对味”时，爆款往往就诞生了。

# 结语

目前广告素材里用数字人的比例非常高，且数据表现稳定。我一个同事回老家，家里老人刷到的视频声音全是我们常用的爆款数字人。AI 数字人在广告起量上的效率已经得到验证，未来空间很大。
