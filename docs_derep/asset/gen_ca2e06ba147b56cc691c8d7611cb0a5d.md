# 一、项目背景

该品牌由微商转型而来，自有代理过万，2015年成立至今已有8年历史，全国直营店数百家，主营艾灸及周边养生品类。

疫情后门店客流锐减，线上获客成本走高，动销与招商双双受阻，代理商大量沉寂。

我们需要用国庆节点激活代理商，打爆百店联动。这就是百店同庆的价值所在。
