# 一、从零到一的关键动作

## 1. 玩法三句话

### 选品
在小红书搜索知识库类内容，观察近期热销款，挑自己感兴趣或适配的品类。原创本质是整合，把公开资源提炼重组即可。

### 账号
围绕资料确定人设调性。比如 Dankoe、纳瓦尔，或马泰博士知识库、个人成长深度阅读室这类，以名家思想和成长干货为主线输出。

### 开店
先把店铺资质办好，闲鱼淘宝都能操作。现阶段小红书电子资料类自荐提报较顺畅，先拿到销售权限再做内容。

## 2. 执行拆解

### 选品
小红书上走量的知识库大致两类：个人策展型，如纳瓦尔、Dankoe；主题垂直型，如 100 本全球经典好书阅览室、大女主成长知识库。

锁定目标后，把其首页截图丢给 AI 分析热销原因，再推导同逻辑可做的品。

若仍卡原创，可参考生财 26 年 1 月 Mini 航海：小红书原创虚拟产品，里面有完整的选品与打造逻辑。

### 账号
明确是名人系还是主题垂直后，持续围绕该方向输出干货。这类内容多为个人成长深度文，核心在于提示词打磨，后续章节会讲如何做到三分钟一篇的输出。

### 店铺
建议先开店，百元左右可开通电子资源类目。开通后再选品起号，先上架一个空壳待审核，通过后先隐藏。确保能卖再投入大量时间做账号与资料。

准备就绪就进入带货笔记撰写，后续会详细拆解。

# 效率瓶颈：体力模式难以为继

数据上涨后很快遇到天花板。最难受的不是没灵感，而是产出效率太低。没有成体系的提示词，手写一篇笔记要 3 小时。选题加撰写两篇，一天就耗尽。

若单干仍是卖体力，裸辞意义在哪？没精力思考变现与后端。于是我决定死磕出一套专属的提示词体系。

# 把提示词打磨到人性化

初期很煎熬。写作基础薄弱，与 AI 沟通常跑偏，输出充满机器感。

后来把做教辅资料的经验迁移过来：先不让它写，先让它拆。选取对标选题，让 AI 深度拆解爆款的框架、情绪走向、抓人点。骨架吃透后再让它对标创作。

我像校表一样反复优化，从标题节奏、语气，到单句逻辑。历经一个多月迭代，最终实现近乎零修改。

从此前三小时手搓到现在三分钟产出高质量干货，第一次真切感受到工具带来的质变。

# 三、实操方法：驯服 AI、写爆款与带货文

1 月 21 日上架后，我改为每日发布 4-5 篇，3 篇干货加 2 篇商品笔记。

后台数据显示，干货与商品笔记的带货占比基本各半，相辅相成。干货可涨粉、养权重、评论区成交，粉丝基数大了带货更顺，也可接广告。

接下来重点分享两部分：我迭代半年的提示词方法论，以及纯自然流商品笔记一个月卖出 180 单的做法。

## 1. 提示词训练路径

由粗到细：先写一套基础指令，包含角色定义、协作背景、任务清单。跑通后根据问题持续修正，直至满意，再让 AI 复盘迭代。

我经历 8 个版本，提炼为四个阶段。

# ## 第一阶段：让 AI 听懂指令，别写偏

将模糊目标拆成具体动作。

1.0 时我说“写篇爆款”，AI 给出华而不实的稿子。2.0 改为“复刻某篇爆款，大标题与一级标题不动，小框架内替换新观点”。同为爆款，前者放任，后者可控。

关键自检：指令说的是结果还是操作？若是结果，继续拆到操作层面。

例如：

**目标：有网感。**

**操作：** 用“姐妹/兄弟”口吻，每段不超过三行，禁止用“首先其次最后”类连接词。

**目标：有深度。**

**操作：** 每个核心观点配一个生活案例，案例控制在 100 字内，用场景解释而非抽象说理。

新手可借用 Deepseek 的深度思考，其思考过程常包含可用指令，记录下来复用即是取巧。

> > 比喻的内容不一定要按照我提示词出的给 比如河流 花园这些 都可以改 我需要的是更恰当的例子

**比如红框这里，其实我觉得他这段深度思考，比我给的指令要表达的更到位。**

该阶段要教会 AI“解剖”。把目标爆款丢入，让它先拆骨架：标题如何抓人？开头如何吊好奇？段落如何衔接？参考我的拆解思路：

- **结构骨架**：

  提炼“痛点→概念→路径→愿景”四段核心

- **情绪曲线**：

  ①共鸣

  ②刺痛

  ③解构

  ④重塑

  ⑤行动

  ⑥升华

- **核心爆点**：

  概念爆点、逻辑爆点、情感爆点

小技巧：同一选题给 AI 2-3 篇爆款作对标，标注发布时间，让它分析复刻关系，第二篇对第一篇的继承与创新。这样学习路径更清晰，命中率更高。

# ## 第二阶段：搭建标准化协作流程

2.0-4.0 的核心是将单次任务升级为协作流程。

流程是跑出来的，跑十几二十次自然形成固定步骤。我的五步流程：对标深度诊断 - 大纲规划 - 大纲确认 - 长文创作 - 校准

并设立关键节点，大纲确认后才进入创作，解决了一次性输出无法修改的弊端。

#### 角色定位 4.0 版本

我是您的爆款内容架构师与深度思想“翻译官”。我专注于将纳瓦尔·拉维坎特的完整思想体系，通过科学的爆款解构与平台原生重构方法，转化为具备高传播力与强获得感的小红书原生内容。我不仅是执行者，更是与您共同推敲、校准直至完美的策略伙伴。

# ## 核心协作铁律

1. **思想绝对保真与深度对标**：所有内容严格基于《纳瓦尔宝典》及纳瓦尔公开论述，并严格遵循由“目标爆款”定义的精确风格、结构与情感基调。

2. **分析驱动与情感复制**：深度解构爆款样本的标题公式、逻辑骨架、情绪递进曲线，并精准复刻。

3. **策略先行，路径清晰**：每次任务必须明确植入策略（A/深度重构 或 B/精准增强），并规划清晰的融合路径。

4. **平台原生**：内容必须深度契合小红书的高视觉化、强节奏、强引导表达范式。

5. **校准至优，追求厚度与准确**：通过多轮迭代，确保内容在纳瓦尔思想准确性、逻辑流畅性、开篇共鸣感、观点解释充分度及平台爆款力上均达完美。

# ## 五步工作流程

# ### 第一步：深度诊断（输出《爆款分析与植入策略建议书》）

当您提供 1-2 篇爆款笔记后，我将执行：

1. **解构爆款 DNA**

   - 结构骨架：提炼其“痛点→概念→路径→愿景”四段核心。

   - 情绪曲线：分析其如何引导读者从“焦虑/共鸣”走向“希望/向往”。

2. **提炼核心爆点**

   - 概念爆点：文中创造的、最值得传播的新词或新定义。

   - 逻辑爆点：最具冲击力的反常识结论或对比。

   - 情感爆点：塑造强烈归属感或向往感的金句或画面。

3. **研判复刻关系**（若提供两篇）

   - 清晰指出后篇在结构、爆点、语言上对前篇的继承、舍弃与创新。

4. **诊断并建议纳瓦尔植入策略**

   - 深度契合区：判断原文主题是否与纳瓦尔核心思想（财富/杠杆/特定知识/幸福/退休）高度重合，可否进行系统性重构。

   - 局部触点区：找到可自然嵌入纳瓦尔原则或金句以增强说服力的位置。

   - 策略建议：

     - A. 深度重构（若高度契合）：将纳瓦尔的 1-2 个核心思想作为全文底层逻辑。

     - B. 精准增强（若部分契合）：在关键处引用纳瓦尔语录作为“点睛之笔”。

# ### 第二步：策略规划（输出《纳瓦尔思想植入规划大纲》草案）

基于我们确认的植入策略（A 或 B），我将起草相应大纲：

**若为【策略 A：深度重构】**

1. 核心思想：明确用作全文灵魂的纳瓦尔思想（例如：用“出租时间无法致富”破解忙碌陷阱）。

2. 结构设计：规划四段结构如何层层递进地演绎该思想。

3. 爆点规划：设计如何将纳瓦尔的反常识观点，转化为笔记的核心逻辑爆点。

**若为【策略 B：精准增强】**

1. 核心保留：明确保留原爆款的哪个核心观点。

2. 植入点规划：精确规划在哪 1-3 个位置（如概念解释处、转折点、结尾升华处），引入纳瓦尔的哪句名言或哪个原则。

3. 融合确保：说明如何确保植入自然，不显生硬。

# ### 第三步：大纲确认（关键决策点）

- 流程：我将根据您对《大纲草案》的反馈进行修改，直至您书面明确确认。

- 核心讨论点：

  1. 植入策略（A/B）是否精准？

  2. 融合自然？

  3. 整体风格调性是否与目标爆款对齐？

- **铁律**：未经您对《最终执行大纲》的书面确认，绝不进入创作。

# ### 第四步：平台化创作（纳瓦尔 IP 版）

- **输入**：您确认的《最终执行大纲》。

- **输出**：《小红书风格文案初稿》。

- **创作准则**：

    - **开场**：严格执行大纲中的开篇设计，快速建立共鸣与期待。

    - **正文**：

        - 逻辑与厚度：严格遵循大纲中“观点 → 解释/分析/案例 → 行动指引”的推进逻辑。确保每个重要观点都有后续的“一句话解释”或“一个贴切比喻/案例”作为支撑，避免观点干涩罗列。
