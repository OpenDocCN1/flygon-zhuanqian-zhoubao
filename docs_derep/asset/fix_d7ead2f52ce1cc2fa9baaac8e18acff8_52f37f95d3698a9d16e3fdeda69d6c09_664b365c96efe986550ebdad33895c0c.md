**大家好，我是孟哥，一个00后，做了6年自媒体创业。**

这几年我基本泡在短视频和内容电商里。

2021年入局短视频带货，先从多多视频切入，赶上风口赚到第一桶金，年入破百万。随后转到视频号，卡上红利期，带过达人孵化，也做过视频号供应链团长，23-24年带货GMV做到3个亿，还在微信公开课上拿到腾讯2025优秀带货机构，多条品类做到站内头部。

25年团队又切换到小红书自营带货，年利润稳在七位数。

看表面，每年换赛道，每次都能赚钱。没人看见的是，每次换之前，我都先把旧盘子从核心位置上抽离。

不是好玩，也不是爱折腾。是平台规则变了，流量逻辑变了，旧打法打不动了。不主动撤，就会被旧业务慢慢拖垮。

我最大的体会是：创业最难的不是找新点子，而是承认老盘子的投入产出在下滑。

新项目能不能跑，可以验证。老项目要不要止损，才最折磨人。尤其是那种以前养过你，现在还能给点现金流，却越做越累、越难放大的业务。

它不死，就吊着你。去年我亲手关掉一个月利润还能稳定几万的团长生意。

关时心虚、纠结、怀疑是不是太早。但回头看，那次撤退是对的。因为我不是单纯砍掉一笔收入，而是把人财精力从高沟通、高情绪劳动、低复利的重模式里解放出来，集中压到微信小店服务商、小红书AI种草这类更值得长期押注的方向。

今天聊个很现实的话题：业务还没亏死，却已经没劲了，老板怎么判断是留是走？

2025年12月底，我刚从武汉出差回来。深夜11点，机场外冷风灌脖子，行李刚拖下，手机炸了。

达人群、客服、商家，一堆未接。起因很小，客服对齐信息漏了一环，达人以为线上链接可转线下结算，佣金不对。达人炸群，商家质疑专业，客服直接给我打电话，声音都抖了：“孟哥，我扛不住了。”

我站在路边等车，看着屏幕满屏投诉，心里只有一个念头：太耗人了。

就几千块的差错，补就行。但为这点小事，我的出差谈项目被打断，团队士气垮了，商家信任裂了，群里情绪还要我收尾。

回公司看到桌上腾讯2025年度优秀带货机构的奖杯，一点感觉没有。以前会自豪。

那天我明白，奖杯只说明你吃过红利，决定不了你未来还能不能赢。

我一度以为下滑是执行、团队、达人、素材的问题。后来才发现根子上是：这门生意的终局在收窄。很多老板卡就卡在这。看见新机会，也知道老业务难了，就是抽不出手。

因为老盘子里有成绩、有惯性、有沉没成本，还有那口气。你会一直想：

“我做到这个量级了，再调一下是不是还能回？”

“我投了这么多人钱，现在停是不是亏？”

“每月还能赚几万，直接砍掉可惜吗？”

我全想过。后来才懂，停业务的本质是资源重配。把人、钱、注意力从低ROI处挪走。

# 一、先看终局，别只盯着当下能不能赚钱

很多老板看业务，先看本月有没有利润。这个有用，但不够。最迷惑人的业务，就是现在还能赚钱。

我关掉的视频号团长业务，关门前月利润还有几万。

同行知道我要停，第一反应：现成的钱不要？

只看账面当然合理。但我看的是还能不能放大。

视频号生态和抖音不同。抖音达人多，品牌忙，需要团长撮合。视频号的中腰部达人做起来后，品牌直接加微信对接，团长的价值被架空。而且平台在收紧，靠短期号、快打法的空间缩小，而我们服务的主要就是这类达人。

我们吃到的，本就是平台发展期的一波红利。红利来了算本事，退了要承认。我也想过服务头部长期号，但他们要的是选品测品、大场策划、投放增长的全链服务，不需要中间商赚差价。

当一门业务要你耗巨大心力去维系，天花板却在往下掉时，最理智的做法是止损。我骨子里是草根，只信一件事：泥肥处扎根。

我的判断是：如果收入还在，但天花板向下，协作成本向上，规则不友好，投入越多边际收益越低，就别看短期波动，大概率是终局在收窄。能赚钱不等于有前景，很多只是惯性势能。赚钱的生意很多，值得长期加注的很少。

# 二、老业务最可怕的是制造假繁忙

老业务最烦的不是亏损，亏损还痛快。最怕的是让团队每天忙得要死，忙完没增量。

做视频号带货那段，团队表面很热闹。达人维护、商家对接、素材测试、客服售后、规则一变改流程，群消息一直响，老板一直兜底。

复盘却发现增长没动，人累了，团队心气低了。

大家忙在低价值动作里，还觉得自己很努力。就像人陷进泥里，越挣扎陷越深。公司灯火通明，看起来像战斗力，拆开看全是在维系一个低效系统。

我用来判断的三个问题：

1. 忙完后有没有沉淀出可复用的资产？
2. 多招一个人，利润会不会一起涨？
3. 老板不盯，业务会不会立刻变形？

如果一门业务靠老板救火、靠人情硬扛、靠情绪填坑，它本质是消耗组织。久了团队钝化，只会处理问题，不会思考增长。每天完成任务，没人知道下个月靠什么变好。最贵的成本不是工资，是时间被浪费在没有复利的事上。

### ### 三、舍不得停，往往是自尊在说话

我一开始舍不得停，也不是看不到问题，而是心里不想承认。

这个业务曾帮我出成绩，拿过奖，养过团队。让老板停掉一个证明过自己的盘子，心里别扭。表面是算账，底层是自尊。

你会问自己：“我以前能做到，为什么现在不行？”“换一批达人、调下团队、优化素材会不会起来？”“现在停是不是等于认输？”

草根创业者尤其如此，因为都是自己一刀一刀砍出来的。从0到1每一步都有血汗，停掉像否定自己。

但生意只看回报。过去的打法帮你赚钱，说明当时对。现在回报下来了继续死磕，就是跟自己较劲。

我会逼自己问：如果这个业务不是我亲手做起来的，而是别人拿来给我看，我会投钱投人投精力吗？

犹豫，就要警惕。你舍不得的，多半不是机会，是过去的成绩、投入和赢过的那个自己。老板最难砍的，往往是曾经靠它赢过的自己。

# 四、新业务不是来填坑，是来升级回报率

转型最容易犯的错是慌了就补。老盘子下滑，赶紧找个新坑填。今天视频号，明天小红书，后天AI漫剧，每个都沾一下，没一个打穿。本质是用新业务缓解焦虑。

我选新业务，不是找个地方把窟窿堵上，而是验证公司能不能从重人力、重撮合、重维护的能力，升级到更高ROI的能力。

比如微信小店服务商。跟团长完全两码事。以前是赚撮合佣金，现在是帮商家解决真问题。

做团长是赚牙缝钱，做服务商是救命。以前靠信息差，现在靠平台规则、商家经营、风险处理的专业度。

看新业务我会看：天花板高不高？交付轻不轻？能力能不能沉淀？老板投入是升级认知，还是换个地方继续打苦工？

如果只是换个壳，底层还是重人力、低复利、靠老板救火，就别重仓。

# 五、止损靠预案，不靠情绪

止损不是想通了明天就砍。现实有团队、有现金流、有客户，得按流程来。

我当时也没一刀切，先观察几个周期：素材测试成本有没有降？达人配合度有无改善？平台规则是变友好还是更收紧？团队执行是偶发失误还是系统性变形？我继续投入能不能拉回增长？

短期低谷就调，连续几个周期没起色，就当结构性问题处理。

最关键是提前设线。很多老板越陷越深，因为没设止损线。亏一点扛，再优化，再测素材，最后人拖疲了业务还是没起。

要写清楚三条线：观察多久？最多投入多少？做到什么数据继续，做不到什么数据撤？

比如老业务，我会设30天看核心数据回暖没，60天看团队效率有没有改善，90天看利润增长是否站住。资源上限也定好：保留几个人，最多测多少素材，老板每周投入几小时。到线没结果就缩，该停就停。

拖着不决策，对团队更残忍。你拖的不是业务，是时间、现金流和注意力。

# 六、取舍的核心：从“还能做吗”到“值不值得做”

很多老板纠结的是：这个业务我还能不能做？这会把人带偏。因为多数业务都能做，有经验有团队咬牙能撑。但能做和值得做是两回事。

视频号带货我当然还能做，继续维护达人、找商家、测素材、救火，赚点佣金。但它不值得占核心资源，因为它占的是最贵的东西：老板的注意力。

创业后期，钱不稀缺，人不稀缺，最稀缺的是你早上醒来脑子里第一件事是什么。如果你第一件事是低ROI业务的琐事，就没空间抓能翻盘的东西。

我现在更冷静：它还能赚钱，我承认，过去帮过我，我也承认，但未来不值得我压主力我就撤。被琐事绑住，看起来稳，实际上在慢慢变笨。

创业像骑驴找马，得先把驴卖了才有心思找马。手里有点安稳钱就舍不得转身，最后两边都做烂。这次我干脆，主力压到更有未来的方向。

我不怕少赚一点，我怕时间浪费在没未来的地方。

# 七、业务取舍的6条判断标准

### 1、看终局：未来还有没有放大空间？
别只看今天赚钱不赚钱。看平台趋势、客户需求、竞争结构、利润空间是否在变好。收入还在，天花板往下压就要重估。

### 2、看效率：忙完有没有复利？
团队每天很忙，但忙完没有资产、流程、数据、客户沉淀，那就是体力活。可以做，不能长期占核心。

### 3、看边际成本：多赚一块钱是更轻松还是更痛苦？
好业务规模上来单位成本降。差业务规模越大问题越多，纠纷越多，增长=救火，就要重看。

# ### 4. 看老板注意力：值不值得占你最清醒的时间？
老板注意力比现金流贵。赚小钱却长期占用核心判断力，真实成本远高于账面。

# ### 5. 看新旧能力：新业务是升级能力还是换坑继续累？
别为逃离老业务随便抓新方向。新方向必须带来更高ROI的能力结构：更轻交付、更强复利、更高利润、更高效率。

# ### 6. 看止损线：观察期、投入上限、退出条件定好了吗？
别靠情绪止损，也别靠幻想坚持。多久观望，投多少钱，做到什么数据继续，做不到什么数据撤，提前想清楚。没有止损线，不甘心就会牵着你走。

# 八、写在最后

很多老板看得到新机会，却被旧成绩绑着。过去赚过钱说明当时对，现在该停说明环境变了。别让曾经帮你赢的业务，最后拖住你。

赚钱的生意很多，但不是每个都值得一直干。尤其是那种今天还能给你点甜头，明天却一点点把团队拖进泥里的生意。它不会让你立刻死，会让你每天很忙、每月有点钱，然后慢慢耗掉判断力、注意力和团队心气。

所以我现在对旧业务更狠：账上还有钱不代表要继续干，要看值不值得继续占主力。该收就收，该换牌桌就换，别死在自己曾经赢过的地方。
