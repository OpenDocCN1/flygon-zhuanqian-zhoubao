# 烧掉八个账号后，我才真正读懂了生财的意义

> 原文：[`www.yuque.com/for_lazy/thfiu8/fie2gzn9v7ai4rcs`](https://www.yuque.com/for_lazy/thfiu8/fie2gzn9v7ai4rcs)

新一轮的小航海又开船了，又有一批新朋友踏上甲板。远行既有辽阔的海景，也有突如其来的风浪。

临上路前，我想把自己做废八个号的复盘摊开，算是交一份学费笔记。

看完这篇，你大概能带走这三件事：

1. 我把新手做自媒体账号时几乎会踩的坑，基本都踩遍了。现在的你如果刚起步，可以把我当成反面案例参考，绕开这些坑，成功的概率会高出很多。
2. 八个号做没了，我却能坦然拿出来讲，还因此吃到了分享的红利，这就是生财给我带来的底气。希望大家都能对失败脱敏一些，多开口分享，多参与线上线下的交流。
3. 八扇门关上，换来的是真正对的那扇门被打开。在磕绊中学会灵活、学会敞开，愿意接受牛人的点拨，这条路就对了。

最后先说声谢谢生财的每一位朋友。

为什么我能连做八个号还不垮？因为生财的创业氛围太好了。它让我见识变广，也让我格局被拉高。

这篇文章能成型，多亏了 2023 年 3 月的生财全国大会，以及之后的一些线下小聚。在得意姐姐组织的局里，同频的人搭起了一个很强的能量场，我才敢彻底打开自己。说的人跟自己和解了，听的人也给了满满的支持。

聚会现场合照

大会之后，我又参加了一场线下分享，一次性认识了近百位志同道合的创业者。

因为敢分享，我被看见。高手们给了我最及时的指引。高翔老师帮我梳理优势，问了我一句：你明明是韩信，为什么要去当敢死队？

被点醒了。在八个号的失败里，在分享带来的贵人指路里，我终于找到方向：帮家族的功能性食品企业做线上生意。

父辈是做实体起家的，手里有家功能性食品相关企业。资质方面有婴幼儿辅食、婴幼儿营养包特膳、孕妇乳母营养包特膳、固体饮料、其他饮料、方便食品等六项生产许可。厂房八千平，单班产能可达四亿，是国家级高新技术企业和江西省专精特新企业。有脾多肽、脑多肽生产线，能做听装、袋装、盒装固态产品以及液体小袋装。

现在我的选择就是把家里这盘业务做起来，目前在探索口服美容品赛道，品质有保障，背靠多项国家发明专利。

如果你有微商、直播电商等销售渠道，欢迎聊。如果有口服美容品、功能性食品的代工需求，比如胶原蛋白肽、补血口服液、婴儿米粉、婴儿或孕妇营养包等，也欢迎联系。我们以前给国药、仁和、白云山等知名企业做过代工。

失败，有时候只是为更大的成功热身。
