## Claude2.0 生成结果

我今年26岁，和丈夫结了两年。丈夫叫小龙，在一家制造厂做技术，经常要排夜班。我自己在市里的一家公司做白天班，两个人都在城区上班。

老公是农村长大的，父母还在老家务农，生活比较紧凑。公公为人沉默寡言，却待我们很不薄。婆婆时常过来帮忙打理家务，我们一家相处得挺和睦。

刚成婚那会儿，公婆还出了一笔彩礼和首付的钱帮衬。如今家里每个月要还房贷，经济上有些吃紧。好在我觉得婚姻里最重要的是体谅和并肩。

那天夜里，丈夫刚去上夜班，大约是晚上十一点左右。我把孩子安顿睡下，正准备休息，忽闻门外有敲门声。

大半夜是谁来访？我赶紧披上外套去开门，门口站着的是我的公公。

他神色有些尴尬，说有件私事想和我聊聊。我请他进屋坐下，问他究竟怎么了。他吞吞吐吐说不出重点，只是问我最近手边有没有点闲钱。

我一时没反应过来，不明白大半夜找我借钱是什么意思。说话间，婆婆也赶了过来，当场把来意说明白了。

公公一直不好意思开口，婆婆随后赶到，直接把前因后果全摊开了。

婆婆说，当晚她外甥的孩子从老家打来电话，说孩子他爸突发急病，必须马上做手术，需要一大笔费用。

他们家条件有限，只能先向亲友借垫住院费。公婆也想伸手，可手头也并不宽裕。

婆婆接着说，以前那位外甥对我们家帮过不少忙，现在人家有难，我们也应该尽力相助。公公才半夜跑来找我，希望我能搭把手，只是他性格太腼腆开不了口。

我马上表示理解，说会想办法筹钱。婆婆连声致谢，公公也松了口气。

听完婆婆的讲述，我很快明白了他们的困境。外甥突发重病要用钱，理应我们伸一把力。

我跟婆婆说，我手上现金不多，但会先打电话问问我弟弟，看能不能先周转一到两万，余下的我再慢慢凑。

第二天一早，我就联系了弟弟，他答应借我一万块。随后我又从自己的存款里拿了三千。凑齐一万三千元，我就交给婆婆了。

婆婆感动不已，说我是他们家的贵人。我说都是一家人，别这么客气。公公也感激地连连道谢。

等老公下夜班回来，听我说了这件事，很受触动。他夸我办事果断，关键时候能顶上。

他说像我这样的妻子和媳妇，是他们全家的骄傲。以往以后无论碰上什么难处，夫妻都会互相支持，共同面对。

此后，公婆在熟人面前也常常夸我勤快能干是个好媳妇。每每提到这件事，公婆都对我表示由衷的感谢。

我总说，这都是分内之事。夫妻本就该相互扶持，这点忙不算什么。

# 更好的使用说明手册 补充 必看

1、prompt 任意板块都可以用你喜欢的内容更改，但最好不要大改

2、workflow 可以按照你喜欢的操作流程来设计

3、没有好的优化建议的时候，可以让 AI 替你提意见，而后直接让它帮你优化，如果有，就直接提。

eg:

[PRE8]

[PRE9]

4、生成的内容不满意，你可以让它使用各种风格润色，幽默、大白话、鲁迅、王小波都可以……如果生成内容还不满意，可在 prompt 中增加小样本训练，即样本演示。

5、AI 生成内容还是会胡编乱造，如果对真实性有严格要求，一定要手动检查

6、AI 只是工具，可以把你从 0 分的水平，提到 50-60 分，偶尔会有 80 分的表现，但如果再进阶，只能靠自身修炼了。

7、有朋友说，一发 prompt 给它，没有按照要求输出，那就强调它按照指令输出，让它进入初始模式。每一个步骤都可以强调的，提醒它，让它修正。

[PRE10]

比如像上面这张图片，gpt3.5 直接开叉了，没有遵照指令，强调它：<请你遵守指令>便可修正（大多数情况下都可以，目前还没有看到例外，但不排除会出现意外）

也可以像下面图片展示，直接复制 workflow 流程给它，会重新唤醒 gpt。

https://chat.openai.com/share/1a883177-2eb2-411e-be29-fc56fe976f9c 前面发的这个操作演示基本涵盖了所有使用技巧，注意看流程和方法。

[PRE11]

8、结构化 prompt 是比较稳定，但是它本质上还是一个“文字接龙机器”，用久了会“不听话”，这时候要适当强调它或者提醒它，比如增加在对话框输入“请保持重复率低于 30%”，“字数要 1200 字”，“请遵守指令”等等。

9、当不确定 ai 生成文章的重复率合不合格的时候，建议还是去第三方查重网站测一测
