# 京东外卖地推项目：每单170元，趁蓝海期赶紧上车

最近京东外卖正式杀入本地生活赛道，最狠的一招就是对商家实行0佣金政策，平台一分钱抽成都不收。与此同时，平台正在大力招募推广员，每成功搞定一家餐饮商家入驻，就能拿到170元奖励。目前这个项目知道的人还不多，属于典型的信息差机会，也是妥妥的蓝海市场。

**2月20日官方答疑整理**

Q1：这个项目是全国都能做，还是只有39个城市能跑？
A：39个城市是重点区域，但全国范围内都可以推广。

Q2：怎么判断商家有没有资格？
A：打开大众点评APP，只看评分在3.8及以上的餐饮店，低于3.8的果断放弃。

Q3：用户从哪里进京东外卖？
A：在京东APP首页最上方点“秒送”入口。

Q4：商家入驻后要上架商品吗？
A：要，至少上传5个商品。

Q5：必须要有对公账户吗？
A：是的，但个体商家如果没有对公账户，用法人本人的银行卡也可以。

Q6：有些城市点了进不去是什么情况？
A：大概率是商家的操作流程出了问题，检查一下步骤。

Q7：基础配送费怎么收？
A：3公里以内收3元，这笔钱可以由商家承担，也可以由用户承担。

Q8：商家提现和到账时间怎么算？
A：采用3+1模式，即下单后3天钱到商家端，提现到账再等T1。

Q9：资料提交后审核要多久？
A：京东是人工审核，前期时间不固定。建议加商家微信，审核通过后提醒他们，第二次回店帮助上架商品和营业。

Q10：做到哪一步才算有效推广？
A：商家完成入驻，上传至少5个商品，并且开启营业状态，才算有效数据。

Q11：商家愿意配合吗？
A：从市场反馈看，大部分商家都愿意入驻。因为其他外卖平台抽成高、服务费贵，京东现在0佣金，推起来很容易打动老板。

Q12：店铺装修和菜单上传需要推广员帮忙操作吗？
A：不需要。

Q13：推广员有独立后台吗？
A：没有，目前没有也不一定会有。交单还是要回到“任推邦”平台的京东外卖项目详情页去提交。

Q14：连锁店怎么计算佣金？
A：按门店数量算，比如一家连锁品牌有10家门店，佣金就是10倍。同一品牌连锁店最高可以算到100家门店的推广佣金。

Q15：商家端后台从哪里进？
A：手机下载【京东秒送商家】APP，电脑端访问 store.jddj.com。

**几点补充**

评论区有人问了几个关键问题，作者也回复了：

- 整个结算周期大概7天，如果审核失败，需要重新提交资料。
- 纯外卖档口（没有堂食）也可以申请入驻。
- 小城市暂时没开放京东外卖，也能做吗？——能，全国都能推。
- 京东审核比较严，所以尽量去找有实体店铺的商家，不知道找谁的话，打开美团外卖，看哪些店开了，直接上门谈就行。
