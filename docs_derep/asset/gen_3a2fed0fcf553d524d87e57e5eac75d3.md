# 新手也能上手的两个AI短视频赛道，拆给你看

做AI内容，绕不开一个现实问题——成本。自己的电脑算力跟不上是一方面，跟大厂现成模型的便利程度比又是另一方面。所以这里挑两个眼下最有代表性的赛道，把实操思路摊开讲。原本准备了三条，实在肝不动了，先聊这两条。大家完全可以在这些方向上先做出成品，再顺着脑洞往外扩，玩出更多有意思的小花样。

# 一、萌宠故事流

## 先看懂它在讲什么

这类内容基本吃的是“萌系流量”。最早是猫meme带起来的，后面又长出了小兔子、小老虎等分支。但猫的受众盘子最大、延展性也最强。它的底层逻辑除了萌，更重要的是一层带教育意味的表达。

也正因为如此，猫的故事衍生品类才最多。所以下面就拿猫的故事当样本，各位可以自己举一反三，也可以先拿它练手找感觉。

套路大致是：小猫被欺负了，经历一番波折，最后收获什么；又或者小猫家里出了变故，猫妈妈意外离世，猫爸爸辛苦拉扯小猫长大……共同点是画面感足够强。

所以做这类赛道时，除了反推爆款，还有一件更要紧的事要想清楚——这条视频到底想传递什么情绪？

目前这个赛道整体上猫的故事已经比较拥挤，后期开通YPP的难度不小。要么往其他萌宠故事上拓，要么考虑图转视频。先看看这类视频长什么样：

三个典型故事是这样的——

**故事一**：猫妈妈推着购物车带小猫逛超市，小猫在前面蹦跶。忽然猫妈妈肚子疼，痛苦地“喵喵”叫。小猫听到呼喊赶紧跑回来，发现妈妈肚子越来越大，明白她要生了，慌慌张张四处求助。它打了急救电话，猫妈妈被抬上救护车。猫爸爸接到电话匆匆赶到医院，在走廊里焦急踱步。最后猫妈妈顺利生下六只小猫，小猫开心地笑了。

（用简洁画面加猫叫音效，讲了一家人迎接新生命的喜悦，传递出家庭的温暖与幸福。）

**故事二**：猫妈妈带小猫上街，一只橘色小猫想买爆米花。它揣着钱跑到爆米花摊前，摊主却说这里不让猫进。小猫很难过，大猫安慰它，随后灵机一动：把自己打扮成黑衣女特工，潜进玉米田偷了一袋玉米。回家后把玉米做成爆米花，小猫开开心心地和它一起吃。

（这个故事讲的是母爱与智慧。大猫为了满足孩子的心愿不惜冒险，最后靠脑子解决问题，让小猫乐开了花。）

**故事三**：小猫同样想买爆米花，可摊主立了个“猫咪禁止入内”的牌子，明确拒绝。小猫伤心，大猫安慰后想出计划：扮成黑衣女特工进玉米田偷玉米。但这次遇到阻碍——田主和他的狗一路追赶。最终它还是成功偷到玉米，回家做成爆米花，和小猫一起享用。

（还是母爱与智慧。大猫为了孩子的愿望克服困难，最终达成目标，让小猫快乐。）

看出来了吧：

第一条视频是纯图片加转场；

第二条和第三条，工作流风格一样、情节也几乎一样。

所以这类内容拼的不只是出图技巧，更在于底层想表达的东西。故事够好，才炸得起来。

### 优点：

适合新人，操作门槛低，好理解，不需要太复杂的工作流，花的时间也少。赛道上高爆的对标账号一大把，可以快速模仿上路。

### 缺点：

赛道拥挤，做的人太多，导致YPP开通难度加大（同一赛道YPP通过太多，后期容易被拒），还需要一些资金投入（买GPT账户、图生视频的费用）。

### 特点：

缺点是可以想办法绕开的。图片开通难，就图转视频；成本拉高了，就想办法压成本——但不可能做到零成本。

## 实操拆解

更省事的做法是“逆练九阴真经”：把对标爆款反推成图片，还原完整故事线，再重新画图、组合（要么图片加转场特效，要么图转视频）。

这类绘画风格是有讲究的，包括后面要讲的搞笑段子，用的都是dall-e-3模型——只有这个模型出来的图和语境能力撑得住。

大家可以拿MJ、SD、Flux等分别对比，完善度、风格都不如dall-e-3优秀，而且它成本更低。

dall-e-3就是ChatGPT的画图功能。动手前要先弄明白画风是什么，而不是拿图反推瞎画——画风不对，老外接受度低，视频的连贯度也容易出戏。

### 画风：

皮克斯动画风格。欧美观众从小被迪士尼、皮克斯这类动画公司熏陶，这种风格更容易让他们代入。皮克斯风、迪士尼风、超现实主义等等，提示词里都要带上这类词。

**（1）用提示词批量提取故事描述**

**提示词：**

可以把图批量丢给ChatGPT描述画面：

“帮我描述一下这几张图讲的是什么，它是根据视频拆解出来的图片，其实是一个完整的故事，你挨个描述一下对应画面，然后根据图片把这个故事连贯在一起。你需要分别根据场景、景别、动作、角色来描述，要给到中英文对照。”

**（2）设定身份**

为了故事统一，角色需要保持一致。尽量一致即可，毕竟AI绘图也好、视频也好，目前还处在抽卡阶段。那怎么让它保持一致？角色、物种、性别、服装、动作、画风，尽量统一到大概一致。只要做到这点，观众一般是不挑的。

**提示词：**

“我想让你重新作图，角色要重新设定。首先我需要告知的是，风格是皮克斯的动画风格、超现实主义，这些动物是拟人化的展现形式，所以不需要之前的生物习惯，比如爬行，而是像人类一样行走。先不要做图，我们先来聊一聊，这两个角色的固定设定，长什么样子，然后再优化提示词的部分。”

*   外貌：拟人化的白色长毛猫，拥有柔软蓬松的长毛，尤其在头部、耳边和尾巴处更突出，展现温柔优雅的气质。

*   表情与姿态：平时表情温柔慈爱，带轻微微笑线条；行动时则表现出坚定、沉着的神情。

*   服装：

*   日常穿着：简洁优雅的粉色连衣裙，温暖色调衬托出她的母性与温柔。

*   性格：母性温柔且富有决心，为了小猫不惜冒险。平时温柔体贴，执行任务时敏捷果断。

### 角色二：小猫

*   表情与姿态：总是带着期待和好奇的表情，看到母猫或心仪物品时眼睛会亮起，有一种天然的孩子气。
