# 别把时代的电梯，当成自己的肌肉

你有没有发现，人有一个奇特的自我保护机制：

顺风顺水时，总觉得自己英明神武、能力出众、拼得够狠；一旦倒了霉，却觉得全是别人拖后腿、大环境不给力。

心理学管这叫“自利偏差”：成功归自己，失败怪别人。它让我们心里好受，但也正因为太好受了，我们常常看不清一件事的真实分量——时代趋势带来的红利，其实远超个人努力。

卢尔辰的观点，正是看穿了这一点。

举个好懂的例子：假定一部电梯正往 100 层上升。甲进电梯后疯狂原地跳跃，乙进电梯后闭眼休息。到达顶楼后，甲一边喘气一边想：“能上 100 层，完全是因为我一路跳到这的。”可真正的答案很简单：无论跳不跳，电梯都会上去。

电梯，就是时代趋势；跳跃，才是个人努力。

当然，这不是说努力不重要。没有努力，你连上电梯的资格都未必有，上了电梯也可能走错出口。但努力的作用是放大结果，而不是决定方向。站在一个快速上升的赛道里，普通努力也能被时代托举起来；站在一个持续下沉的赛道里，再拼命也只能熬进去。同样是十年光阴，选择的“水位”不同，结局会拉开巨大剪刀差。

更值得警惕的是归因的连锁反应。

成功时过度归功于自己，你会把运气当实力，把红利当本事。一旦风向变了，你还会固执地加大筹码，试图用战术上的勤奋掩盖战略上的误判。

失败时过度归咎于环境，你会错过自我审视的机会。下一次同样级别的浪潮打过来，你还是没有接住的能力。

真正的聪明人，不会和趋势较劲，而是主动站到趋势里。个人努力决定你在浪里能游多快，时代趋势却决定这池水是上涨还是下落。与其在电梯里满头大汗地证明自己，不如先抬头确认：这趟电梯，是不是正在通往高处。

把时代的赠予记在时代名下，把自己能掌控的那部分留给努力。这样，你的成功会更踏实，失败也会更有价值。
