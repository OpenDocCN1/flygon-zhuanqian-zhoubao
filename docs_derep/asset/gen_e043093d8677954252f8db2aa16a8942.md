# 热点来得快，内容更要跟得上：用ChatGPT做热点联动的实操打法

刷信息流的你肯定有这种感受：只要微博热搜一动，明星塌房、公司翻车、奇怪社会新闻刚冒头，立刻就有大批自媒体和品牌冲上去吃肉。杜蕾斯、瑞幸这类玩家，更是把热点玩成了常态。

关键不在于你想不想追，而在于怎么追才不尴尬。硬蹭只会让品牌显得low。真正难的是，从海量信息里快速筛出能和你家产品搭上边的那个点。

下面这套我一直在用的流程，核心就是让ChatGPT帮你做筛选和联想。

**第一步，先把当天的热搜抓全**

我常用的是今日热榜 https://tophub.today/ ，它把微博热搜集中起来，一眼能看全。把当天的条目全部复制下来备用。

素材越多，后面匹配面越广。

**第二步，把你的产品拆成关键词**

想让热点自然嫁接，先把自己和产品的核心词列清楚。不是写广告语，是把用户会搜、会关心的点全部摊开。

比如做数字化管理软件的，关联词就是员工管理、绩效、降本增效、业绩、利润……列得越细，后面交叉的可能性越大。

把这些关键词和刚才的热搜清单做交叉比对，就能看出哪些点能讲、哪些点不能讲。

**第三步，给ChatGPT一个结构化指令**

思路有了，就开始训练模型。提示词框架我固定用这套：

我是做XXX的，我的目标人群是XXX，我这个产品的关键词是：XXX、我想写一篇结合热点的文章，发到我的公众号上，我看到今天微博的热点是：（把复制好的热搜粘贴进去）你是一个善于做热点结合的文案高手，你写过1000篇热点结合产品的文章，你来给我做热点的结合，以推广我的XXX产品。

任务步骤：1.先了解我的产品关键词，分析下这些关键词，和哪些热点可以匹配起来，并说明理由；2.从步骤一种分析出一个最适合的热点，并说明理由；3.分析这个热点可以如何融入我的产品；4.写一段开头，结合热点融入产品。
