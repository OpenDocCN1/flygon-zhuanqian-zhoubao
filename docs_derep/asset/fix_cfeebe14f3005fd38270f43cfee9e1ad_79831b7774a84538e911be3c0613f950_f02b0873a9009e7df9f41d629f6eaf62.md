# 一、为何锁定AI知识付费这条赛道

今年身边到处都在聊AI，这个词出现的密度非常高。

### 1. 学员口中不断出现
在接触AI之前，我在做美术方向的知识付费，同时卖工具和课程。学习绘画的学生经常跟我提AI绘画的需求，咨询量在上升。同时我观察同行直播，发现AI被大量用来做引流钩子，吸引家长进来看。

[PRE5]

### 2. 信息环境高度一致
朋友圈、公众号、社群、短视频平台，甚至一些付费知识圈都在集中讨论AI相关内容。综合来看，这不是短期热点，而是一次结构性变化。出于好奇我自己装了ChatGPT体验了一下，操作门槛没有想象中高。但到9月，我依旧还在做美术直播。

### 3. 一个直播间彻底改变判断
美术项目后期增长乏力，我决定换方向。那段时间刷到一个主播的直播间，一场卖AI课卖出500单，这个数字直接刷新了我对单场转化的认知。

随后我开始系统调研，发现抖音上头部账号每天能卖出约1000单199的课程，日流水20万，累计已经上万单。美术赛道里我几乎没见过这种体量，判断AI赛道的上限明显更高。

### 4. 跨平台对比后的取舍
除抖音外，我也看了小红书和视频号。小红书几乎没有成体系的卖课案例；视频号上已有不少中小账号跑通了玩法，一天两播能做300单，也有人三个月累计3000单左右。

[PRE7]

综合来看，我决定做AI知识付费。自己体验过ChatGPT后觉得上手不难，连原本做短视频课、从未接触过AI的人都能做AI课，说明门槛不高，本质是稍微懂的人教几乎不懂的人。

更关键的是，我看过很多直播，卖课的本质不在于你能用AI做出多惊艳的效果，而在于你能否讲清楚AI的价值并塑造个人信任感。这和我做美术时的方法逻辑一致，所以我觉得可以做。

平台选择上，我坚定选视频号。之前美术项目在抖音几乎卖不动，转到视频号才起死回生。视频号的核心用户是宝妈和中老年，环境相对干净，没有被直播电商深度训练过，下单阻力小。平台对真人出镜很友好，哪怕照着提词器平铺直叙，也能产生成交。

抖音则不同，即便有流量、有投放、有经验的主播，课程转化也未必好。如今抖音卖课更多是公域导私域再成交。比如很多博主的AI视频在抖音播放很高，开播却寥寥无几，几百人的直播间大多靠付费投流堆出来。

而视频号只要内容有播放，提前做预约，开播时就有稳定的人流，几十单的成交非常常见。所以视频号对新人很友好，我的所有内容都只发在视频号。方向确定后，第一步就是快速找标做像素级拆解。

找标是核心能力，好的参照能让方向不跑偏。但只抄一个人很难成功，必须多角度、多账号组合学习。

# 二、标品拆解的具体做法

知识付费项目我拆成三部分对标：交付内容、流量内容、直播转化。

只模仿头部很难起量。一方面头部积累了很久的人设势能，另一方面他们的流量依赖付费投放，普通人烧不起。

我的打法是把AI领域的大中小号按平台拆开，分三块独立学习：交付、素材、直播，始终围绕低成本起盘。

## 1. 课程对标与轻交付

我先购买多位主播的AI课程通听一遍，结合目录整理出自己的框架。用飞书妙计转文字，搭PPT，再用直播伴侣录制。因为本身有教学经验，流程梳理顺畅后，五天内就把初版课程上线了。

[PRE8]

这里要强调一个误区：不要等课程完全做好才开始卖。初期录课费时费力又没有即时反馈，应该先把初版放出去，有市场反应后再持续迭代。持续更新本身就是交付的一部分，等做完美再开卖，市场窗口就错过了。

交付最大难题是工具的持续供给。我不会开发，AI也是现学现用。头部主播多为自研工具，听说套壳开发要2万起步，还要月度维护。对我而言成本太高。

于是我转向研究中小主播的方案，发现他们主要用国内免费工具：文心一言、讯飞星火、度加剪辑等，课程里直接带学员下载使用。本质是信息差，省了大笔开销，直播话术上做一点调整，效果几乎一致。

[PRE9]

最终我选择轻交付：仅有一门199元课程，学员购课后拉群，我本人做一对一答疑。这样学员更安心，时间成本也可控。2000名学员里，99%的问题看课程就能解决，我每天固定三个时段集中回复，合计花费约半小时。轻交付让我把精力集中在获客和转化上。

## 2. 素材对标与流量获取

在知识付费里，素材就是流量。没有可复制的内容，既做不起自然流，也投不出去。我坚持找标、像素级模仿，不自己造轮子。

AI在3月就开始在短视频爆发，到10月入场时，市面上已经有大量验证过的文案。我把各平台点赞过千的AI相关文案全部收集，自己真人出镜口播。抖音的文案用轻抖小程序转写，视频号的视频录屏后同样转写。那段时间每天能拍十几条，前期在出租屋附近河边拍，回家自己剪，一条约40分钟，一天稳定产出三条。

[PRE10]

真人出镜是必须的。真人口播的直播转化明显更高。别怕镜头表现力不足，多拍自然就熟练，前期我用iPhone 11前置镜头，剪映打开提词器怼脸拍。语速放慢，配合手势和眼神即可，只要把稿子完整说完，内容本身就具备传播力，一字不改说出来也算原创。

剪辑要极简。声音大、字幕大、画面清晰即可。转场、特效、重点变色都不需要。中老年用户不喜欢花哨，抖音上火的样式在视频号往往不吃香。我至今每天花一小时刷视频找素材，没有素材就等于没有流量。

预约功能非常关键。用户看视频时下方会出现预约入口，点完后开播会收到微信提醒，约一半会进入直播间。最佳时段是19:30-21:00。直播时发的视频不会显示预约条，会直接引导进直播间。

[PRE11]

前期我把预约设置在3-5天后，每天发三条内容，基础播放也能积累预约。若某条视频突然爆发，就临时加一条当日预约。预约池既能撬动直播推荐，也能保证开播首波人气，而我的成交主要集中在首波。

举例：初期单号运营，每天三条视频，隔天一播。有一场直播观看人数仅202，开着稿子念出了4单199的课程。

[PRE12]

那次让我深感趋势的力量。美术时期一天三播也难以出单，视频号上很多上万观看的直播间也一单不出。这验证了选择的重要性，同样投入，赛道不同结果迥异。

## 3. 直播对标与转化打法

前期平均50个观看带来1单成交。核心是清晰认知客户画像。

我的用户以50岁以上中老年人为主，有消费能力、时间充裕、对新事物好奇。话术必须围绕他们的关注点设计。

直播话术核心是多源整合。先录屏蹲守多位主播，反复听，拆解成交结构。不能全盘照抄，要结合视频号调性重组，包含实操演示、课程钩子、憋单和逼单环节。

[PRE13]

比如某位主播以讲解为主，实操少，但成交话术极强，我直接沿用其成交段落。另一位主播实操做得好，对中老年很有说服力，但案例偏职场，比如表格、PPT，对老年人不适用，于是我保留其演示思路，改成健康话题、风景视频等更贴近的场景。最终融合视频号中层主播的案例，形成约12000字的完整稿，念完约40分钟。

[PRE14]

前期可照稿念，已能出单。后期需要背熟，把语气、动作、眼神排练好，把直播当成一场固定表演。每场两小时，循环演绎，公屏互动由运营处理。形象上我做成年长感：大背头、金丝框眼镜、黑西装衬衫，夏天短袖冬天长袖，每款备四件。背景是网上购买的书房贴纸，保持统一。

这套打法在10月31日达到高峰：两个号同时爆发，小号单场104单，大号2小时43单，当天累计近150单，后续还有多场破万。

能接住爆发，靠的是前期大量直播练习积累的手感。视频一火就立刻开播，把流量接住。矩阵的想法源于一个情感类IP博主，他的多账号矩阵让我意识到单账号天花板有限，得靠概率做放大。我算过：一个号每天三条视频，每条1000播放，攒两天预约就能开播。若有两号，则能做到日日开播，爆款概率翻倍。

于是我再开一个新号，每个号每天三条早中晚发。新号上线约一周，一条视频爆到20万播放。中午看到数据后直接开播，持续6小时，话术循环十遍，出单104单，成为个人单场最高纪录。老号当天也爆，错峰开播再出43单，当天流水约3万。10月单月做到8万流水，成本极低，基本等同利润。

为何敢播六小时？知识付费直播需要保持高能量，期间不摸鱼，只在演示空档喝水吃面包。同行刺激是动力，前几日看到同行因视频爆发一场出百单、两百单，我理解到只要视频火，直播就能持续收人，不需预约。加上不服输的心态，睡醒看到视频3万播放就直接开播，循环十次破百单。至今我已不具备当时那种耐力，三小时已是极限。

到这阶段精力明显不足，爆视频时需直播，就顾不上出素材。找素材、拍摄、剪辑、客服、直播全部由我一人承担，两个号已到极限。于是招募剪辑分担工作。

招人标准：会剪辑、为人坦诚、薪酬到位。

第一，有经验，能快速上手，我已把流程和要求标准化，只需专心剪辑，日产稳步完成。第二，人品可靠，沟通直接，有想法用案例说服我，有要求直接提，效率高。这套用人理念参考自《不拘一格：网飞的自由与工作责任法》，真诚是最好的沟通方式。

# 三、售后与平台风险

知识付费必须重视售后，拒绝退款会导致纠纷率升高，平台介入后问题更难处理。

11月底，平台无预警封禁了老号店铺，资金冻结一个月，账号永久失去带货权限，无法申诉。

封禁当天，老号一条精准视频爆到200多万播放，眼睁睁看着流量无法变现，按常规转化至少可卖500单。

过去我可能难以接受，但这次影响不大。原因是我知道号可以再造，手里还有其他账号兜底。提前遇到风险反而是好事，逼我分散风险、调整心态。
