# 71条赚钱干货，被我重新分成了13个变现方向

“2毛钱一斤收上来的旧衣服，凭什么能做出75%的利润？”

这句话，是我最近在一堆收藏夹里翻到的第一篇。原本以为只是普通的回收生意经，没想到往下翻，越看越不对劲——播客、二手电脑、快手蓝海、同城相亲、货拉拉、小说推文、AI绘画、拼多多、亚马逊……71条内容，覆盖的副业和赚钱路子比我想象中宽得多。

更值钱的是，每一篇背后几乎都藏着一条“需求链条”。我把它们一条条拉出来，重新按变现逻辑归类，得到了下面这13个方向。无论你是正在找副业的人、内容创作者、创业者，还是手里有技能不知道该怎么产品化的职场人，都能从里面找到自己的位置。

- 《旧衣服回收，2 毛一斤的回收价怎么做到 75%以上利润？》（20230926_62.md）

写在最后：这71条内容，其实是一面镜子。
