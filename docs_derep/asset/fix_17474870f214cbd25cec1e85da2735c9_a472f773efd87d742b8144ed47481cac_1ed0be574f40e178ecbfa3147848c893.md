# 一、你被困住，不是你的错

先讲一个判断：大部分职场人的瓶颈，并不是个人能力的问题。是系统性的环境问题。换一家公司，大概率不会更好，甚至是一样的剧本。

如果归因错了，就会一直在原地打转。你越努力，越无力。

我2019年校招进大厂当产品经理。前半年觉得什么都是新的，再往后就发现不对劲了：业务没有增量，做的都是维护型的事，写文档、开会、对齐、撕需求，周而复始。

后来我尝试换岗，换公司，换一条业务线，甚至去面所谓的创新项目。面试聊十几分钟我就知道，那层“创新”的皮下面，还是那套旧的逻辑。

这不是我一个人的错觉。跟几十个学员聊完，发现大厂里大多数人都卡在同一堵墙面前。

再说说打工的疲惫感从哪里来。你花三个月做的一个需求可能静悄悄地上线，平台一个资源位就能让KPI瞬间达标。你开始想：离开这个工牌，我到底是谁？

做的事好像谁都能做，甚至新来的实习生半年就能上手。周报、月报、年终总结，每次写的时候都很慌。身边人都在“成长”，只有自己在原地转。

下班明明很累，回忆一下又觉得自己什么也没干。时间被切碎，精力被耗干，换来的只是更深的迷茫。在公司接触不到真实的用户，你做的功能离具体的人很远，自然也收不到正向反馈。于是越来越不想动，越来越自我怀疑。

我说这些不是为了抱怨大厂，领导们也很难，行业整体都在降速。

但有一点我希望你看到：大增长消失了，不代表没有局部机会。小而美的事情，一直在发生。

# 二、破局第一步：先搞清楚自己要去哪

我见过太多人，焦虑了就猛学，学完更焦虑。本质是因为方向没想清楚就开始跑。

破解迷茫，靠的不是不停尝试新东西，恰恰相反，是停下来，把“我到底要什么”这个问题想透。

构建竞争力这事也一样。真正的壁垒不是从别处学来的，是从你已有的经历里挖出来的。你身上那些你觉得没什么的东西，很可能就是别人拿不走的资产。

怎么挖？分两步。

**第一步：把视野撑开**

很多职场人觉得搞副业就是创业，一想到创业就觉得要投入很大、周期很长，于是被吓住了。还有人看到大环境收紧，觉得红利没了、路径断了，索性躺平。

但事实是，现在有无数很小的切口可以切入。你看不见路，是因为你身边没有走通的人。

所以最开始，我花了很长的时间去混圈子、去见人、去了解市面上到底有哪些模式。特别重要的一点是：找到那些起点跟你差不多、但已经拿到结果的人。他们能告诉你，这条路是真的走得通的。

**第二步：用三个标准做筛选**

等你见得够多了，信息摄入的边际收益会开始递减。这时候要收敛，选几个方向下场试。

怎么判断哪个方向值得做？我自己做选择以及帮学员做判断时，会用三条标准：

第一个标准，投入轻。在职状态下，你没有太多资金和业余时间可以往里填。最好是能快速跑通一个小闭环，得到反馈。

第二个标准，雪道长。每次从零开始是普通人耗不起的。方向应当能积累复利，不能做一个项目换一个行业，而且这件事最好和你的主业有呼应，就算失败了也不亏。

第三个标准，跟你的优势匹配。你想在一个领域做到头部，要么这事你比别人做得好，要么这事你比别人坚持得久。

我最终选了个人IP。因为它完全符合这三条：不需要什么成本就可以开始，就算做不成，过程中沉淀的内容、人脉和信任，对自己的职业生涯也是加分的；做成了就是长期资产，可以越滚越大。

# 三、平凡人怎么挖出独家优势

很多人在启动的时候会跟我说同一句话：“我太平凡了，没什么可说的。”

我自己当年也一样。表达能力一般，没有资源，微信好友少，职场表现也不算突出。身边不少人都觉得我不是做IP的料。但结果我们都跑出来了。

原因是：做成一件事从来不存在一个固定的“成功模板”。这个时代确实卷，但它也足够宽容，只要你肯用正确的方法努力，总能找到属于你的位置。

关键一步，是把你的特质翻译成市场能听懂的价值。

一个有效的定位公式是：你的独特优势 × 市场需要 = 你的IP价值。市场需要什么？无非两种：实用价值，或者情绪价值。

拆解一个我的学员案例。她原先是某大厂程序员，来找我的时候，同样觉得自己特别普通。

而且最关键的是：这套故事，没有第二个人能复制。这就是她的护城河。

很多人找优势时，总想找一个“全世界没人比我强”的点，那当然找不到。但如果你把参照系缩小，只需要在小圈子里做到相对突出，再把它打磨成绝对优势，就已经足够。

你觉得自己普通，是因为你在用别人的尺子量自己。换一把尺子，你的经历会发光。

# 四、让IP被看见：个人形象设计

找到优势只是起点。更重要的问题：怎么让别人相信你、记住你、为你付费？

一个好的IP形象，背后一定是有设计的。要让别人在不跟你聊天的时候，也能被你的内容打动。

# 五、一个人的公司：IP商业闭环

说到商业设计，我见过太多人一上来就踩坑：第一种是天天发内容，发了几百条没一分钱进账；第二种是先做账号，涨了粉不知道怎么变现；第三种是先做课程，做完发现根本卖不动；第四种是先去考证，考完还是不会做；第五种更夸张，一上来就招人、搭班子。

这些玩法的共同问题是：没有设计好一个完整的商业闭环。结果就是瞎忙。

我自己对IP的定义是：做IP不需要养团队，一个人就能成为一家公司。唯一的前提是——把模式想清楚。

任何一个IP商业模式，都要回答四个问题：

1. 谁是你的用户？
2. 你从哪里找到他们？
3. 你凭什么获得信任？
4. 你用什么产品完成变现？

这四个问题，市面上有很多标准答案。但我要说一个反常识的结论：**大部分标准答案，你可能都做不出来。**

很典型的例子是传统微商玩法：到处参加活动、疯狂加好友、群发私聊、一对一维护关系。这套流程很成熟，但对一个不爱社交、不想陷在碎片化聊天里的普通人来说，就完全行不通。而且效率太低，也谈不上自由。

个体商业最大的优势，恰恰是你可以为自己量身定制一套打法。你的性格、你的时间、你的长处，全部都可以设计进模式里。

我给自己设计的模式是十六个字：**内容获客，产品建信，活动促单，被动成交。**

我不主动跟人聊天，但我让内容替我说话。我只写一次，但会有无数人看到。

我最近成交的几个五位数订单，用户的路径高度一致——

比如用户A：

认识：4月份一次线下分享，她加了我的微信，之后偶尔看我朋友圈；
信任：连续一个月看我公众号和朋友圈的内容，慢慢建立认知；
转化：5月份再次参加我的线下活动，活动结束第二天直接打款。

整个过程，我和她私下讲话不超过十句。

这就是被动成交的魔力。你不需要很会说，你只需要把内容、产品、活动三板斧搭好，让系统替你完成销售。

最后说一句：这条路不需要你辞职才能开始。我在职的时候就开始探索，一个月内完成了第一笔变现，半年后跑通了整套模式，才选择裸辞。一年后，各平台跑通，单日变现过五位数，逐步覆盖了原来的工资。

普通人逆袭的故事从来不是传奇，它只是正确的方法+持续的迭代。希望这篇长文，能成为你开始行动的第一块垫脚石。
