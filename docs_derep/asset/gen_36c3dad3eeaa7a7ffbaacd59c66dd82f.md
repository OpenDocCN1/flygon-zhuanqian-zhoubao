# 二、抱团作战把项目跑通

## 1、早就是最大优势

刚开始切入时，淘宝上就一家店铺在卖共享账号。我们三个人进来，基本就吃掉了大部分市场。而且那家店的链接时不时还会掉线，我推测可能是刷单被查了。【我们从不恶意投诉举报，底线是绝不作恶。】

一旦对手掉线，基本就是我们三家垄断同款。当时我们默契地把价格上调了1块。别小看这1块，纯赚。

后来出现一家比我们便宜1块的，我在群里立刻喊话：统一定在50元或49.9元，不要卷价格。可以用福利、教程来提升转化，但绝不打价格战。

价格战打起来项目就废了。后面进来更低价的，我们价格纹丝不动。买家看到前面几家价格一致，后面一家异常低价，第一反应就是有问题。事实上，那些低价基本都涉及灰色支付渠道，细节就不展开了。

## 2、组队打配合更有效率

期间还出现过同行用低价 Token 账号来抢流量的，晓雨第一个发现并丢到群里。我研究了一遍流程，发现手机验证太麻烦，容错率低，卖了一单就放弃了。

后来生财上流传的无限刷图骚操作我们也试过，没成交。

## 3、把一堆坑都填平，项目才算通

做这种项目，恶意买家是常态。小群最大的作用就是实时拉黑预警，避免被坑，抱团确实能省很多损失。

初期我们用的是邮箱验证：发账号给客户→客户登录→点邮箱验证→登录成功。后来 Discord 收紧风控，多地区登录会强制改密，改密等于踢掉所有在线设备。

我们又去摸索 2FA 验证的方案，完美绕开改密踢人问题。

# 四、项目最终停掉的原因

老黄在帖子里也提到现在基本停了，主要有三点：

1、价格战失控：低价产品太多，利润被压缩到几乎为零。很多人用黑卡支付，30美金的 Standard Plan 只需50块人民币，而我们正规汇率要210左右，根本打不赢。

2、风控收紧：国外 AI 工具基本都走 Stripe 订阅，风控极严。国内卡大概率被拒付，供应断了就做不了。

3、流量见顶：AI 绘画同质化严重，SD 越来越强，Midjourney 的热度自然下滑，用户减少收益也减少。

2023-7-18 更新：淘宝已禁止售卖 Midjourney 账号，违规扣12分。现在只有部分天猫店和冒险的个体还在做，大部分人都撤了。

# 五、复盘得与失

### 收获

1、短平快项目看执行力。看到机会就立刻上架，犹豫就错过。当时一起操作的伙伴有人因太忙没跟进，直接错过一波。
2、愿意思考就问。别人做得好就虚心学，脸皮比利润重要。
3、每天哪怕只推进一步，也超过90%只看不做的人。

### 反思

1、没提前做自动发货。流量高峰时人工跟不上，订单大量流失。应该上自动发货工具+客服系统。
2、私域沉淀没变现。引流来的用户没有做二次售卖，资源浪费。可以接付费课程或佣金产品。
3、未及时扩量。当时还有闲置店铺因忙就关了，损失一波客户。只要自动化流程打通，多店铺同时上架完全可行。
