# 开场话

大家好，我是大麦，一个90后快手玩家。今天把自己在快手上摸索出来的经验整理出来，希望能帮到还在迷路的伙伴。

快手作为三大短视频平台之一，流量依然很猛，却常被低估。和抖音相比，快手挂车没有粉丝门槛，也不用交保证金，上手门槛更低；和视频号相比，快手对内容更包容，账号存活率高，不容易被废号。做过视频号的人应该都懂那种频繁被封的无力感。

下面我结合自己跑通的两个口播方向，从零开始拆解两种可复制的赛道玩法，适合不同基础的创作者自选。内容比较细，建议对照目录看。

做项目最少给自己两个月沉淀期，无论是老手还是新手，先把0到1跑通，再去冲100。一步一个脚印，心态稳住，别急躁。

# 一、快手口播带货的两种形态

## 1. 我主要分享的两种口播类型

### 第一种：好物分享混剪口播，简称快手好物分享，详细在第八节

这个赛道和抖音好物逻辑类似，靠短视频挂车变现，可出镜可不出镜，数字人也能用。

快手好物分享的第一个特点：素材门槛低，重在堆量。很多朋友看到那些封面泛滥的视频会怀疑真的有人看吗？流量真的有吗？答案是肯定的，看的人很多，破百万播放的池子也不在少数。所以做快手好物，核心就是在保证基础质量的前提下走量，在没出结果前都是苦活，就是疯狂上品、疯狂剪。

[PRE0]

快手好物分享的第二个特点：单件佣金偏低。相比视频号动不动50%+的佣金，快手这一单可能只有几毛钱，看着不起眼，但平台玩法是走量。客单价低、佣金薄，只要量起来，整体收益并不差。

[PRE1]

### 第二种：偏中长视频的故事化口播，简称快手口播，详细在第九节

这种更接近视频号风格的口播，以故事、描述、方法类为主，有真人也有数字人，时长一般在三五分钟左右，叙事完整。内容形态和视频号口播很像，但实操思路完全不同。

起初是看到视频号的素材在快手也爆了，才开始尝试。快手对文案的容忍度明显更高，视频号一小时内就被限流的内容，在快手能正常推送，还能持续推流很久。

[PRE2]

当然也会收到作品优化提醒，严重时也会限流，总体来看，长期做号的容错率更高，流量有起伏很正常，保持平常心即可。

比如我一个同行，三天佣金就破了14.6万。这种口播的品类佣金比例比好物要高，和视频号接近。但它很吃文案功底，写作能力强的朋友更适合尝试。

# 四、如何找对标账号

对标号就是风向标，别人什么爆了就跟什么，借鉴更直接。

1. 在快手搜索框输入商品名+口播，比如爆氧粉口播、小炒酱汁口播、发面王口播，注意区分两种口播形态

第一种口播的对标号如：淼*严选好物、兜*优选、沐*工厂直发、梦*好物优选、燕*清货等

第二种口播的对标号如：李师*优选、宝*爱做菜、七*甄选、刘*师、万*团圆等

2. 刷3-5个视频后刷新发现页

3. 新人找粉丝低于3万，月销量几千上万的号模仿，关注10-20个左右。发现页多点赞量高的爆款，点赞过千的作品，系统会推送更多同类爆款

4. 关注对标号，主页所有点赞超500的作品拆解文案框架、钩子、逼单话术

5. 打标签：平时刷什么内容平台就推什么，搜索口播，只刷对标号，刷3-5条作品后点赞评论完播，再回发现页，推荐内容会高度同质化，说明标签已打好

# 五、文案素材获取与处理，及违禁词

### 5.1 文案来源与处理

文案可以原创也可以搬运，素材多来自抖音、快手、视频号等。快手用户以中老年为主，二三线城市和农村用户多，和视频号、拼多多人群高度重合。视频号的爆款文案搬到快手，只需做去重处理，可用豆包改写

### 5.2 去水印提取文案和视频

微信搜去水印小程序，如轻抖、功夫去水印，或用快影APP

### 5.3 文案修改要点

主要为提升原创度并剔除违禁词。抖音视频号搬运的文案无需大改，保证无违规词，替换部分词汇，调整语序即可

### 5.4 违禁词

[PRE17]

平台对违规内容管控严格，各平台规则相近但容忍度不同。快手违禁词也很严，如“买到就是赚到”、极限词“世界第一”、“全行业第一”、“国际驰名商标”、“史无前例”、“绝无仅有”等，均属高危，附违禁词清单供参考

目前以全品类为主，可细分美食、服饰、母婴、养生等。一个账号可带百货、吃用穿戴，如防晒帽、大豆皮、腰带、抹布、抽纸、海带等。全品类优势是热点来了能快速测品，测出后再跟进

更细分的情况：吃货号就多选吃类，裤子出单多就多选裤类

这30单选低价优质品提升信用

① 低客单价全网爆品，谁发谁火，新号老号通用

② 破价品

③ 三天内爆品

④ 受众广

一周后破播放，可将低客单价与中高客单价穿插投放，低价品易拉低信用分且佣金低

## 8.5 选品思路

常用方法：刷推荐页+快分销榜单

* 易消耗品：百货、服装、鞋、生鲜、短裤、冰丝裤、短袖、裙子、老北京布鞋、凉鞋、抽纸、钢丝抹布、保鲜膜等低价爆品
* 人群覆盖广：日用百货、日用家清、美食零食、应季服装、鞋帽、餐厨用品
* 应季爆款：秋季换季、夏季冰丝凉席、防晒驱蚊、茶类、开学季、春节等
* 蹭热度：抖音、快手、视频号、拼多多榜单爆品

## 8.6 测品与跟品

跟三天内的爆品，特别是低粉爆款，第一波流量最大。目的就是吃第一波，成为被别人跟的对象

全品类排测，例如一天5条，发食品、百货、服装各一条

第二天看数据，流量好的品再补2-3条新素材，继续上新品。如防晒帽和冰丝裤数据好，第二天再发2条同款+3个新品

持续追踪前两天数据，某个品出单量持续上涨就多补视频接流

单品热度一般维持3-7天，不要死磕一个品，防止账号偏科。可短期集中投放

## 8.8 如何补视频

快手是量大出奇迹，视频越多测品越多爆单概率越高。出单品要及时补视频。文案开头结尾改一改，素材换新的，降低同质化
