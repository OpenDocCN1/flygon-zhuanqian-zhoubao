# 5分钟带你搞定满血 DeepSeek R1 个人知识库，本地也能跑

> 来源：[https://zzi7a49xoa.feishu.cn/docx/DZ0ydDEkgohZqXx5GgocReSLnLf](https://zzi7a49xoa.feishu.cn/docx/DZ0ydDEkgohZqXx5GgocReSLnLf)

近期私信里反复被问到同一个问题：DeepSeek 怎么本地搭一个属于自己的知识库。

[PRE0]

说实话，除非你是技术研究者，或者对数据保密有硬性要求，我不建议普通人去折腾纯本地部署。

原因很简单。

目前 Ollama 上从 1.5B 到 70B 的版本，本质上都是把 R1 的推理能力蒸馏到了 Qwen、Llama 等学生模型上。

虽然体验比起过去有明显提升，但和原版 R1 对比，还是能感觉到差距。

官方完整版 R1 参数量高达 671B，以个人条件去本地跑，门槛和成本都太高了。

不过最近我找到一个变通方案，既能用上真正的 R1 全血版，又有免费额度可以用。

同时，为了算力充足又想自托管的朋友，我也整理了一套本地部署的实操路径。

看完这篇，你大概能得到两件事：

1.  用满血 DeepSeek R1 API 搭建个人知识库
2.  用本地部署的 DeepSeek R1 搭建个人知识库

## 一、满血版知识库的实际效果

先来看下知识库在实战里到底能干嘛？怎么把文件当外脑，用方法论来指导行动？

DeepSeek 很强，前提是你会问。

提问不对，模型再强也发挥不出来。

与其花大量时间钻研提示词，不如在本地放一份提问指南，让 AI 先教你怎么问，效率会高很多。

[PRE1]

当 AI 接入了知识库里的《DeepSeek 指导手册》后，它会主动预判你的意图，并给出标准的提问模板。

从输出就能看出来，回答并非来自模型的通用语料，而是严格基于知识库文件的内容。

当然也可以直接检索知识库的原始片段，快速定位信息。

## 二、走 API 路线，拿下满血 R1

如果你的数据不涉及机密，又想追求最佳体验，那 API 方案无疑是首选，我们要用的就是 671B 的完整 R1。

具体怎么搭：

1、先装一个客户端，叫 Cherry Studio。
地址： https://cherry-ai.com/download

[PRE4]

2、去「硅基流动」注册登录，新账号会送 2000万 Token 额度。
地址：https://cloud.siliconflow.cn/i/TAAOvaXg

[PRE5]

3、进入 API Key 页面，生成或复制已有密钥。

[PRE6]

4、回到 Cherry Studio，填入 API Key 进行配置。

[PRE7]

5、在模型广场里，前两名就是「硅基流动」联合「华为云」上线的 DeepSeek R1 / V3。
需要推理时，记得把 R1 的模型名称复制下来。

[PRE8]

6、在硅基流动的模型服务里，手动添加 R1 模型。

[PRE9]

7、点一下检查，确认 API 能正常连通。

[PRE10]

8、对话模型有了，还差一个嵌入模型。
嵌入模型的作用，是把本地文档转成向量存进数据库，问答时用 RAG 去匹配相似内容再生成回复。

这里推荐 BAAI/bge-m3，需要更高召回率就选 Pro/BAAI/bge-m3。

[PRE11]

按同样流程在 Cherry Studio 配置好，这一步不用点检查。

[PRE12]

9、在 Cherry Studio 新建知识库，并指定刚才的嵌入模型，系统会自动完成向量化。

[PRE13]

10、把本地文件上传做向量化。
注意，如果 PDF 是扫描件、手写件，或包含复杂表格、公式，解析效果会很差甚至失败。
遇到这种情况，建议先用我之前分享过的 PDF 转结构化方案处理：
追求性价比选 Doc2x：https://doc2x.noedgeai.com?inviteCode=4A6KOD
追求稳定性选 Textin：https://www.textin.com/market/detail/pdf_to_markdown

上传成功后，界面指示图标会变成完成状态，说明向量化 OK。

[PRE14]

11、创建助手并绑定刚才的满血 R1 模型进行测试。

[PRE15]

也可以把它设为默认模型，免得每次都要手动切换。

[PRE16]

测试时能明显看到 DeepSeek 进入深度思考模式。

## 三、本地部署路线

如果你只是想体验一下，或者算力足够且对数据安全极度敏感，那可以走本地部署。

1、去 Ollama 官网下载客户端：https://ollama.com/download，务必用最新版。
我踩过坑，旧版装 R1 后会出现各种异常。

[PRE20]

2、安装完成后打开命令行，执行拉取指令安装模型。参数越大，显存需求越高。
模型列表：https://ollama.com/library/deepseek-r1

[PRE21]

没 GPU 的话建议从 1.5B 开始。我这 4G 显存勉强跑 8B，速度很慢。
有朋友用 RTX 4090 跑 32B，效果和流畅度都很可以。大家根据自己硬件对号入座。

模型拉取成功后就能直接对话了。

[PRE22]

也可以用 Cherry Studio 作为本地模型的图形界面。配置里选择 Ollama，在管理里加载你本地的模型。找不到就手动添加，API Key 可填可不填。

[PRE23]

最后点检查，显示连接成功即可。

[PRE24]

之后新建助手时就能选用本地部署的 R1 模型了。

[PRE25]

再测一次，答案依旧和原文一致，搞定。

[PRE26]

我这边只在 Mac 上实测过，Windows 大同小异，大家自行尝试即可。
