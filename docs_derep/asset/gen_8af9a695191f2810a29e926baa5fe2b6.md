# 四/如何快速听完直播制作出导图（独家方法）

【嘉宾分享后快速出图的实战打法】

1. 无论是图文还是直播，认真听是基础。为了提速，我会全程用电脑同步绘制，听与做同时进行。
2. 开场前先搭好竖屏框架，基本用总分总逻辑，每个大章节预留三个小点位，方便现场填内容。
3. 直播时抓关键词、关键句和高频问答，同时扫评论区热词；如果是社群图文分享，就直接定位标题，用自己的话提炼段落要点。
4. 分享结束后做一次归纳：过长的句子拆分，同类信息合并，空洞处配上表情或配图做补充，每个小块用外框区分层次。
5. 收尾加上来源署名，标注分享嘉宾和制图人，注意版权规范。配色尽量对齐嘉宾和主办方过往风格，必要时加金句点缀，外框统一修饰，提升视觉吸引力。

# 六/航海导图制作的核心

1. 招人要快，同时做好前置培训，制作过程中给出具体优化建议。
2. 分工清晰不重叠，制作前确认名单，制作中实时跟进进度。
3. 分发渠道集中在航海群/志愿者群/生财研学社群/部分同城群。
4. 靠教练助力传播，船员认可后在朋友圈扩散。
5. 从制作到发布全流程：审稿、修改、确认、发布。
6. 成员朋友圈同步分享，带话题#生财朋友圈分享扩大曝光。
7. 提前定好模板、样式、配色、字体规范。
8. 锁定分享场次，提前排班，边听边画。
