# 1.先把信息与知识拆开看

过去我和很多人一样，认为知识就是精华帖、干货分享、书里的概念原理案例观点。读了它们就等于摄取了知识。

后来才明白，无论刷多少精华帖、读多少书、记多少方法论、划多少重点，这些都只能算信息。

我也曾用各种工具搭建体系，里面装的都是原汁原味的文章搬运。

再后来才发现，那根本不算知识体系或知识库，最多算信息库资料库。

要摆脱记不住用不上学了等于白学的循环，前置动作一定是先把信息和知识分清。

知识管理里有经典的DIKW模型，是数据、信息、知识、智慧逐层递进的金字塔。

[PRE0]

内化知识的过程，正是沿着金字塔逐级跃迁——手里是数据，眼里是信息，脑中是知识，口中是智慧。

信息由数据而来，解决了不确定。

比如「CES评分」，以前只认识字，不知道含义，这就是数据。

后来看了延伸阅读才知道，CES评分是小红书对笔记的评分体系，公式是点赞*1+收藏*1+评论*4+转发*4+关注*8，分数决定是否继续推流。

这时数据变成了信息，能看懂字义了。

但知道意思我依然不知怎么做，几分钟就会忘掉。

这是很多人卡住的坎，以为学到知识，其实还停在信息层，不做深度加工就会成为过眼云烟。

需要继续转化。

比如我明白CES评分后就推导出：想把小红书笔记推到更大流量池，就要主动引导点赞收藏评论转发关注。

这时我不仅知道它是什么，还知道怎么用，怎么行动，这才是知识。

所以信息和知识的核心差别是——能否与自己建立关联，能否指导行为。

看精华帖看书听分享没变化，往往是因为只是眼睛扫了一遍，被动接受作者观点方法，没有用复述思考等主动加工去吃透，自然不知如何运用，现状无法改变。

# 2.怎样把各平台内容统一收拢到一个地方？

我曾被这三件事困扰很久：

1.看到好文章没时间就丢微信传输助手，等空了再翻。结果再也没翻过第二遍，因为新信息源源不断把它顶到云霄外了。很多学员也有同样问题，有人用传输助手囤信息，我让他往上拉，根本拉不到底，生财多少年他就囤了多少年的信息，非常可怕。

2.用各平台收藏夹收藏知乎、B站、简书等内容。同样再也没看第二次，因为信息被不同客户端割裂，想找一篇也不知道扔哪了。

3.后来用笔记软件剪藏搬运，看起来集中整齐。但日积月累输入输出混在一起，臃肿混乱，最后弃用。

后来才发现，这些工具本身就不擅长采集。用它们采集就像用剃须刀切菜，用错了场景效果自然差。

直到三年前找到真正为采集而生的工具——稍后阅读器。

稍后阅读概念十年前就有了，催生出Pocket、Instapaper、Readability等经典产品。

核心逻辑是：在任意平台看到好内容，都能先统一收拢到一个地方，有空再读。

我深度对比过Pocket、Instapaper、Again、Twilar和Cubox，最终主力用Cubox。

最大优势是跨平台统一采集归档，后面集中阅读管理。比如生财精华帖、公众号文章、简书、知乎专栏、B站视频、小红书笔记都能All in One到Cubox。

不用再在传输助手各平台收藏夹里翻找，彻底解决吃灰找不到的问题。

[PRE1]

它还支持文件夹分类打标、多层级嵌套。文章视图支持高亮和笔记，体验不错。

唯一限制是来源平台有登录门槛时采集会受阻，比如生财精华帖，具体问题后文会说。

# 4.怎样把生财精华帖统一采集？

采集的目的，是建立自己的资料库，有序聚合高价值信息以便复习。精华帖价值高，更需要分类归纳。

但精华帖在星球内有登录门槛，Cubox可能无法采集。

先理清生财帖的内容形态，共四类：

1.星球文章
如芷蓝姐的《全职自媒体5年，我沉淀下了一张个人IP经营图谱》，用星球自带写文章功能生成，样式丰富支持内嵌图。

[PRE15]

2.星球主题
如明白老师的《信息整合：一个可复用、低门槛的成熟商业模式》，直接在星球编辑器编辑，主题上限1w字。

[PRE16]

3.索引站内文章
如肖肖老师的《视频号单品直播打法拆解及60分主播养成》，从域名水印看属于索引站站内文章，由官方约稿上传。如航海手册、高手分享多属此类。

[PRE17]

4.飞书文章
如靠谱的《四年发了八千条朋友圈，销冠的成交心法》，在飞书编辑后发布，此类占比最大。

所以用Cubox采集难以全覆盖。精华帖形式多样，遇到星球主题或索引站内文章就会受限。

较理想的兼顾方案是采集精华帖链接，再结合元数据整合成一页文档。

我用Notion建了生财精华帖资料库，表格灵感来自轩辕老师的《生财精华帖阅读法》。除链接外还记录作者、进度、关键词、星级、行动清单等。

[PRE24]

该库实现三个场景：

1.有地方可存
无论何时何地看到长帖，不用担心丢，复制链接整合到资料库即可。

2.快速查找阅读
过去很多人把帖子收藏在星球或传输助手，再也没看过。即便想看也要在大堆里找。
现在可在资料库中快速定位，按关键词分类主题阅读。如想看定位相关，筛选关键词即可，帖子是我在生财筛选过的高质量内容。

3.知道该怎么行动
听一百节杀猪课不等于会杀猪，看一百个段子不等于会写段子。
看一千篇精华帖不实践，什么都不会发生。
我喜欢航海那句「把手弄脏」。哪怕只看一篇精华帖，实操一小步，远胜于看一百篇无动于衷。

比如参加5月航海志愿者，我通过主题阅读志愿者相关精华帖，得知可花式催打卡、做问卷定制化督促、群内公开表扬、写航海日报等。第一次做志愿者就实现全员上岸，组内术值最多。

不行动，一切无用。如何确定做什么，后文会讲。

# 5.精华帖太多无从下手焦虑怎么办？

这是圈友的共性反馈：

*信息量太大，看完就焦虑，长期不打开星球
*信息焦虑，庞大难分辨好坏
*精华太多不知道从何下手
*刚进群时漫无目的浏览，易信息过载找不到方向

本质是面对海量信息时的失控感，大脑超负荷。

失控感根源是被动阅读。七小老师在《我分析了40W评论数据！挖掘出了生财小白的7个痛点问题！》、星辰老师在《谈谈我对生财这个宝库的使用心得》中都谈到过。

被动阅读就是不带动机地获取信息。如各应用推送不屏蔽，70%以上信息被主导。

[PRE25]

打开生财从首页第一篇往下硬看，也是被动阅读。

解法：以问题为导向，以主动搜索为策略。

生财精华帖目前4000多篇，很快破5000。但你不必有看完所有的执念。

先弄清自己想提升什么、解决什么问题，再去主动搜索相关内容学习，而不是生财推什么看什么。

比如我在小红书引流卡点，就在索引站做主题搜索，而不是把4000篇都刷一遍。

况且没接触过的赛道大概率看不懂。

新手还没想清楚，先看鱼丸第七期开学发的《新人指南🧭新圈友必看，根据自己所处的定位来探索》，每个定位都有对应精华合集。

问题又来了，找到帖子后还是太长看不完看不动。
