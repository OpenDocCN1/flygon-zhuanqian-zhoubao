# 二手奢侈品C端回收&寄卖，避坑全流程拆解

做包包回收和寄卖，最核心的是两个字：信任。信任搭不起来，后面所有流程都会卡壳。

信任怎么建立？三点必须要有。第一，做平台的要有正规公司主体和担保机制，别搞野路子。第二，最好有线下门店实体，能上门收，能让人找得到。第三，主理人要有个人IP和口碑，客户愿意把手上的爱马仕、LV交给你，靠的就是人设和安全感。正因为我们现在走的是平台模式，所以暂时不做定金预收这套玩法。

## 一、包包回收是怎样的走法

**1. 线上先估价**

客户不会直接把包寄过来，先会要一张图一句话。拍图有讲究，不是随便一拍。正面全貌、材质细节、鉴定关键点必须清晰，不同品牌重点不一样，去小红书搜一下就知道，比如LV老花款要看老花、五金、年份标，LV现代款要看五金、产地标，古驰黑标款也有自己的看点。

客户经常会问现在的行情。影响价格的五个核心维度是品牌、款式、尺寸、颜色、材质。估价速度一般在一天内能给到回复。注意，线上只能按图预估，准确度有限，所以我们通常给的是一个价格区间。

报价是个技术活。报太高，客户把包寄来后实物复检砍价就难收场；报太低，客户直接pass你去找别人。实操原则是报高不报低，因为同款客户会多家比价，低的就是直接被筛掉。

**2. 钱怎么先给到**

能不能先付点定金？可以商量，看客户意愿。第一次合作为了安全，我们走闲鱼链接做担保交易，后续熟了就公对私打银行卡。C对C之间也可以用支付宝、微信。

**3. 包寄过来**

运费原则上由寄方承担，我们不接受到付，到付直接拒收。包裹一到，拆箱必须录视频全程留证，避免后续退回时客户不认货扯皮。

**4. 实物鉴定**

自己hold不住鉴定怎么办？找中检机构背书，或者找圈内靠谱的朋友帮忙。鉴定不通过，大概率是真假问题或者品相太差。跟客户沟通时统一口径：不符合我们的收货标准即可。

**5. 实物定价参考哪些**

品牌、款式这些基础条件之外，还会看：
尺寸：小号更吃香，更符合亚洲女性体型
颜色：除老花特殊款外，黑色绝对是硬通货，无敌之王，五彩的颜色基本不值钱
材质、年份：越新越好卖
护理情况：动过皮、换过配皮、重做过油边都会掉价
配件完整度：盒子、小票、防尘袋，有比没有贵
使用成色分级：
全新：有吊牌，零痕迹
99新：近全新，无吊牌，几乎看不出使用
98新：品相优秀，轻微使用或氧化
95新：少量使用痕迹，整体状态好
90新：正常使用痕迹，不影响使用
85新：明显使用痕迹，但功能完好
再细分破损污渍，四角、五金、油边是否完好，拉链拉杆是否顺畅，包身是否发粘，配件是否缺失。

定价逻辑怎么来？先看闲鱼、得物、95分、抖音上的市场成交价。回收价一般是市场价的6折左右，寄卖能做到8折左右，仅供参考。回收价格看起来低，是因为商家要承担压货风险和行情下跌风险。买时几万现在只值几千，就是市场如此，价格随行情走。

市场上常见的砍价套路你得有数：先线上报虚高到手刀；挑瑕疵继续砍；说发票配件不全再砍；先问你心理价位，报高了说你不懂行情，报低了正中下怀；拿年份说事，说久了不值钱，最好两年内的款；问你是从哪里买的，二手渠道来的直接再砍；看你急不急用钱，越急越能砍。

**6. 款项结清**

收包完成需要客户提供本人身份证复印件，银行卡号必须和身份证一致。双方签一个简单协议，写清身份、物品信息、成交金额、约定事项、免责条款，最后转账打款完成闭环。

## 二、包包寄卖的差别

寄卖为什么报价会比回收高？因为是先卖后结算，平台只赚服务费，不需要自己压货，客户能拿到更高价格，就是时间上会拉长。

卖掉需要多久？没有死线，完全看款式热度有没有买家看上眼，通常是1到3个月。如果到时没卖掉，客户可以申请召回。

成色会不会变差？肯定会有一点自然损耗，但不会故意降级。出现重大瑕疵我们会承担责任。

利润对比，寄卖肯定高于回收，最终看成交价。
打款时间是卖出发货后14天，款项同样是公对私打银行卡，或私对私走支付宝微信。

寄卖卖不掉能不能直接转回收？我们只回收自家卖出去的货。
想原价寄卖？基本不现实。

## 三、手表相关说明

目前我们只做手表寄卖，不做回收，回收坑太多，风险不可控。而且手表寄卖只接受自家渠道的货。

卖奢侈品是信息游戏，懂流程、懂价格锚点、懂信任搭建，才能把坑踩到最小。
