有的号能扛大盘，有的号只能做试水。有的号最近点播很漂亮，卖货却平平；有的号出单很稳，却经不起硬风险的内容。刚出爆款的号，极有可能在吃窗口期，这时最怕乱投。

于是我让 Codex 结合账号池近况、文案风险等级、商品类型，先跑出一张发布分配表。我审过一遍觉得合理，才往下走。后来我越来越认同一个判断：**账号分配不是排班，它其实是最后一次创作。**同样的稿子，放在不同号上，效果会完全不一样。

### 6. 发稿复制台：把最后一公里的摩擦抹掉

发布本身就是一堆碎活：标题、文号、正文、配音、账号，隔着几个界面来回搬。只要有一处复制错，整条就废了。所以我让 Codex 把当天计划发的内容，包成一个本地 HTML 复制面板。

里面放着：

1. 文号+标题一键复制。
2. 正文一键复制。
3. 标题+正文合在一键复制。
4. 对应配音人。
5. 每条文案绑定的账号。
6. 发前风险提示。

它本身不直接赚钱，但它把发布的噪音降到最低。很多项目不是死在战略上，而是死在每天那些重复、琐碎、极易出错的小动作里。

## 05 系统如何真正提升文案质量：核心是判断，不是优化

我以前常对 AI 说：帮我把开头优化一下。后来发现这句话基本等于没说。AI 不知道什么是好。

它可能会加几个修饰词，可能把句子拗得更顺，可能补一句“你有没有想过”。可短视频文案要解决的从来不是顺不顺，而是人为什么愿意停留。所以我改了做法，让系统去做判断，而不是做润色。

### 1. 开头：砍掉低价值铺垫，把高冲突资产往前顶

最典型的例子是《逻辑哲学论：叫取消思考》这条。原开头大概是：

> 昨晚翻来覆去睡不着，我突然琢磨一个挺有意思的悖论。咱们总说统一思想又要实事求是。这两句话搁一块逻辑上真的能自洽吗？

能看，但问题明显：像作者在自言自语。观众不关心你昨晚睡得好不好，关心的是这件事跟我有没有关系，有没有张力，为什么要继续听。

拆完后我才看清，真正有杀伤力的不是“我睡不着”，不是“我想到个悖论”，而是那两个词：**统一思想、实事求是**。

单独看都站得住脚，一放一起就炸。思想统一了，事实还怎么实？事实和预设打架时，到底信事实还是修事实？

于是开头被改成：

> 统一思想，实事求是。这两句话你听了多少年，有没有认真想过，它们放在一起，方向根本是反的。

这不是把话说得更狠，而是系统在做取舍：哪些是无效铺垫，哪些是冲突资产，该删的删，该前置的前置。

配图*21*：开头改写前后对比

### 2. 中段：长文案要会续命，不能平推

很多长稿就是开头还行，讲到中间人就没了。为什么？因为平铺直叙：第一件事，第二件事，第三件事，听着就累。观众不会坐着听课，随时划走。所以中段必须重新给一个留下的理由。

我后来要求系统必须给长文案加上续钩子。

[PRE2]

比如：真正要命的，还在后面。或者：接下来这件事，才让人说不出话。

不是为了装逼，是在中途再拉一次注意力。

光加一句钩子也不够，故事顺序要重排。哪个故事开场，哪个建立信任，哪个做情绪抬升，哪个给产品铺路，都得判断。把素材堆在一起，信息越多越散。

配图*22*：长文案中段留人结构图

### 3. 转品：产品要从前文长出来，不能硬塞

转品是翻车重灾区。前面聊得挺顺，一到产品，观众立刻察觉：来了，卖货了。

根源是：

[PRE3]

产品和前面讲的内容不是一个东西，是被硬插进来的。

所以我加了一个判断标准：**产品和前文是不是同内核？**

前面讲认真、讲标准、讲时间检验，产品就得承接认真、标准、时间检验。前面讲家庭责任，产品也要落在家庭责任上。前面讲普通人的小痛点，产品就得解决普通人的小痛点。

前面讲 A，后面卖 B，观众一定觉得违和。

配图*23*：硬转品 vs 自然转品

### 4. 产品段：写身体感受，别写说明书

产品段写崩的原因，往往是说明书体。原装进口、品质可靠、很多人回购、口碑很好……有那么点用，但远远不够，因为没感觉。

[PRE4]

拿德国马膏来说，不能只写德国原装进口、品质很好。我会写：

> 涂上去先凉。过一会儿热感从皮肤里面慢慢冒上来，像把紧绷的肌肉一点点揉开。久坐脖子僵，久站腿脚酸沉，运动后肌肉紧。

为什么好用？因为观众能在身体里模拟。他会想：我脖子是不是也僵？我爸妈站一天腿是不是也酸？我运动完是不是也紧？产品这才靠近他。

后来我给系统的规则就是：产品段不写属性，写体感；不写卖点，写场景；不只说好用，让人能想象自己在什么时刻用。

配图*24*：说明书式产品段 vs 体感式产品段

## 06 这条文案为什么转化高

我们完整拆一下德国马膏这条。它播放不算顶，但转化极典型，因为它根本不是硬广。

前文的骨架是：真正有价值的东西，不靠别人保护自己，而是靠自己反复证明自己。GPS 是这样，Linux 是这样，阿司匹林是这样，德国马膏也该是这样。

配图*25*：德国马膏文案信任链路

开头先用 Windows 段子把人抓进来，接下来我把它落地到生活：我爸手机广告隔几分钟弹一次，叉号小得像针尖，我研究半天最后只能卸载才消停。这一步让段子落地。

观众会想：我家也这样。然后中段讲 GPS、Linux、阿司匹林。为什么选阿司匹林收尾？因为阿司匹林是德国药，德国马膏也是德国货，阿司匹林讲时间检验，正好能借给产品。

[PRE5]

转品的时候我没写：给大家推荐德国马膏。而是写：

> 这套标准，我没想到会有一天用到自己身上。一个学体育的朋友给我带了罐东西，说德国运动员都在用。我当时没当回事。打开涂在脖子上那一秒，我愣了。

产品不是我掏出来的，是朋友带进来的，有背书。我一开始没当回事，降低推销感。涂上去那一秒愣了，制造体验反差。

最后补一句：我脑子里就冒出霍夫曼那个白色粉末。这东西，绝对有人认认真真死磕过。把阿司匹林的信任，直接平移到马膏上。

整条文案的转化，不靠一句话的卖点，而靠整条信任链路的铺设。

这就是系统能做的事：判断开头怎么留人，中段怎么递进，最后一个案例怎么借势，转品怎么软着陆，产品段怎么写体感。都做对了，转化自然上来。

配图*26*：德国马膏高转化案例卡

## 07 爆一条后，怎么继续爆

文案写完不是终点，发给谁更关键。我之前有过一次体验。

《取消思考》那条冲到4万多播放后，带动同号一条旧稿从1000多播放冲到40多万。那一刻我意识到：账号被一条内容点亮后，会进入一段短期权重期。号“活”了。

这时候不能乱发，要喂一条稳的。德国马膏同理。6月4日一条视频一路爬到6月11日的30.5万播放，我判断号权重被拉起来了。这时不该发高风险或没验证的测试稿，而该上低风险、路径清晰、转化潜力大的稿。

于是6月12日我追投了德国马膏，随后拿到4.6万级播放，成交金额11,985。

[PRE6]

配图*27*：账号权重窗口示意图

我不敢说百分百算准，平台始终有随机性。但这个动作提升了概率。更关键的是，我把这个经验固化成规则：**账号刚出爆款后会进入短期权重窗口，窗口期下一条优先喂低风险、高质量、高转化文案。**

之后 Codex 做分配时会自动读取这条规则。一次经验不再是经验，而是可复用的动作标准。

## 08 Codex 在我这负责什么

Claude Code 管文案本身：拆稿、定开头、完稿、质检。Codex 管流程和文件：归档、读取完稿、读取账号池、生成发布分配表、生成发稿复制台、把复盘写回规则库。

比如给它账号数据，它会判断：哪个号有爆款记忆，哪个号播放低但出单强，哪个号适合拉量，哪个号适合接转化，哪个号风险高不适合压主力稿。

再结合当天文案：这条是成熟转化型，这条是流量测试型，这条风险偏高，这条产品路径清晰。然后给出分配建议。

但我不会完全自动化。凡是需要判断的，AI 先出方案，人拍板；凡是确认后的重复动作，再让 AI 自动跑。

这就是我用 AI 的原则：AI 不替我负责，而是把我验证过的经验，放大成稳定的动作。

卡在提示词？直接让 AI 回顾你们过去的对话：

你是我的短视频带货文案二创搭档，不是一次性写稿机。

情绪保真第一，逻辑升级第二，表达重写第三，字句润色最后。

第一步：只拆解+搜素材，不写稿。
第二步：只定框架+给开头，不完稿。
第三步：才完稿+质检+起标题。

- 禁止同义改写。
- 禁止把有刺的话改成温吞。
- 禁止把核心传播词换成同义词。
- 情绪资产第一步标出，二创后变弱即算失败。

## 核心原则

原文不是资产，拆出的情绪结构和规律才是。

存到 Obsidian `01_核心规则/`，Claude Code 开工先读它。

然后按这条流程走。
