# 舒丽年度复盘 | 毕业九年，两度转行都成了，我的八条成事心法

> 来源：[https://bd5shvz1qn.feishu.cn/docx/YTiHdPjjPodk0JxZd48cFkxDnwf](https://bd5shvz1qn.feishu.cn/docx/YTiHdPjjPodk0JxZd48cFkxDnwf)

各位好，我是舒丽，一个带着三岁宝宝的90后妈妈，同时也是心理作家、心理咨询师和心理学创业者。不同的身份对我而言，都是独特的生命体验。

九年前，2014年的我才24岁，刚从一所二本院校毕业，入职做财务。那时的状态是迷茫、焦虑、自卑、拮据、内耗，每天都在做自己不喜欢的工作，日子过得并不快乐。九年后的今天，我32岁，和先生一起创立了丽明教育，团队有八个人，我们一起经营着一件热爱的事业。已有上百名学生与我同行，在路上活出自我。

我是典型的INFP，对自由极度渴望，如今我真正拥有了时间自由、地点自由与精神自由，起床带着希望，入睡带着喜悦。

每天做着与天命契合的事，从不觉得疲惫，生命的热情一直在绽放。

这九年里，我做了两次重大的职业转向，都实现了漂亮的转身。这样的结果背后，藏着我总结出的八大成事心法。

今天第一次把这些公开讲出来，我坚信我能做到，你也一定能做到。只要你足够渴望内心深处的愿望，宇宙早已为你准备好一切资源。你要相信，每个人生来就自带圆满，你完全可以创造想要的人生。

# 说到我身上最强的特质，那一定是极致的专注。

# 

这种专注近乎本能，凡是我认定要干的事，就能全神贯注把它做到极致。大学备考时，我能一整天泡在图书馆，只为达成目标。所以成绩常年名列前茅，拿到国家励志奖学金。这既是对自己的高标准，也是对自己的负责。

[PRE2]

毕业后即便从事不喜欢的财务岗位，工作时我依然高效投入。

领导们都放心把事交给我，从不担心延误，因为我总能第一时间交付。五年前我一边上班一边写稿，更是将专注发挥到了极致。每晚下班回家七点就坐到书桌前，常写到凌晨，几乎每日都有产出。最猛的一个月写了30篇，上了25篇，发在有书、才储、潘幸知、樊登读书等平台。稿费收入也让我实现了月入过万。

[PRE3]

印象最深的几笔约稿：有一次喜马拉雅平台约写人物热点，我两小时内完成并发布。还有一次王耳朵先生约稿，我在三小时内高浓度完成，数据很漂亮。潘幸知也约过我很多篇热点稿，我基本都在三四小时内完成，多次获得10W+。短时间内产出高质量热点文，没有极致的专注根本做不到。我能屏蔽干扰，沉下心在键盘上敲出文字。自己写的文章我会反复读十遍以上，校对错字，增添删减，精修字句。也能连续四小时读完一本书并写读书笔记，深入咀嚼。正因如此，我每年能读30多本，写出50多万字。

[PRE4]

今年切入心理赛道，专注很快带来了成果。我能一天连做五个咨询个案，也能连续四小时为书写疗愈营学员做集体疗愈，状态依旧高度集中。因此五个月内就积累了200多个个案。学员感受到我的真诚与专注，收货很大，认可度很高，60%的学员升级为合伙人，长期与我同行。给合伙人上课时，我能专注讲满两小时，全程高能量，她们都被感染，每天期待开课。

[PRE5]

当你把百分之百的注意力放在一件事上，效果立刻显现，你想要的东西会不期而至。

全力以赴地投入，总会在不经意间遇见更好的自己。专注就是认真做事，一心一意把事情做好。

专注是一种修行，能释放巨大能量，让一个人把一件事做到极致，创造奇迹。在专注稀缺的当下，保持专注，你就会成为稀缺品，世界都会为你让路。

[PRE6]

这个世界上不缺三分钟热度的人，只有全力以赴，理想才可能照进现实。拿写作来说，我见过太多起步时意气风发，最后半途而废的人。和我同期开始写作的人，80%都已放弃，少数还在断断续续。差距的根本原因不是天赋，而是持续坚持。

[PRE7]

“这九年里，我从未停止写作。

别人午休时我在写，别人聚餐时我在写，别人闲聊时我仍在写。坐在书桌前用电脑写，出门办事时抱着手机写。清醒时大脑无时无刻在构思，睡着时大脑依旧在写。我曾为赶热点在公交车上写稿，甚至一个热点从三个角度切入，写出三篇成稿，分发到三个大号。”

[PRE8]

两代一姐罕见同台，董卿一番话，倪萍瞬间泪奔……（有书）倪萍董卿罕见同台：都说岁月不饶人，而她们也未曾饶过岁（国学精粹与生活艺术）两代央视一姐罕见同台，董卿一句话令倪萍瞬间泪崩...（喜马拉雅）我也曾看了一部电视剧《都挺好()》，从不同角度写了4篇文章，发在三个不同的大平台。《都挺好》姚晨暴露的4个职场真相（插座学院）姚晨《都挺好》：“原生家庭欠你的，你可以自己赢回来”（婚姻与家庭杂志）从“海藻”到“朱丽”， 从无戏可拍到事业翻红，34岁的她都挺好！（婚姻与家庭杂志）ENTJ女王姚晨（才储）

[PRE9]

“2019年春节大家都在团聚，我在写稿。那一个月上稿20多篇，月入过万。

和财务工作时的内耗不同，写作时我常进入忘我的心流。文章发表后看到读者被打动，快乐会加倍。大量输出也让我灵感不断。读完《高敏感是种天赋》后大受触动，第二天午休时灵感爆发，在仓库趴着一口气写下《高敏感，其实是一种天赋》。”

“这篇文不符合当时新媒体的表达习惯，我先发在自己的公众号。没想到十几个公众号来申请转载，其中包括壹心理矩阵号。同篇文章发在知乎后爆了，阅读量至今超88万，收藏3.4万，评论1600+。”

[PRE10]

正是这篇文章让我被编辑看见，圆了我出书的梦。

[PRE11]

“事实上，好内容终会自传播。我的第一篇爆文《为什么越内向的人越厉害》也是源于一次自发表达，那时刚入门新媒体，却一经发布就引发刷屏，被全网300多个大号转载，单篇阅读破亿。出稿快、质量稳，我的稿件基本不用改，这让我成为编辑眼中的宠儿。约稿不断，我成为【喜马拉雅】、【有书】【读者】、【樊登读书】、【潘幸知】、【才储】等平台的签约作者，文章被人民日报、新华社、民生周刊等官媒转载。”写作是投入就有回报，但要看你能坚持多久。十年如一日，写作已像吃饭睡觉一样自然。不仅写作坚持了14年，我与心理学的缘分也是14年。我的爆文多与心理学相关。大量输出离不开输入。

[PRE12]

我从大学起就读心理学书籍，在图书馆泡了整整四年，读了上百本心理学著作。

这为我打下了扎实的基础。从二十岁接触心理学，用心理学分析问题，写心理学文章，出书，做咨询，开发课程，一路深耕，心理学已成为我生命中不可分割的部分，我的存在似乎就是为了探索它。这份使命感越来越强，促使我不断学习扎根，再用公开表达释放它的价值。每个人成长都会遇到诱惑，容易迷失初心，放弃梦想。但梦想之路注定荆棘丛生，成为自己会遭受非议和不理解，甚至需要放弃很多。成功路上不拥挤，因为坚持的人很少。只有秉持长期主义，才能收获果实。成事都需要长时间积累和投入，能耐得住孤独的人，才能等到想要的一切。

人生不过三万天，要取悦自己，过独一无二的人生。我是理想主义的INFP，十四年向内探索，一直在寻找真正热爱的事。从未放弃。做财务五年，我裸辞四次，换了四家公司，尝试不同岗位，只为找到自己真正想要的。最后确定财务不适合我，及时止损，2018年走上自由职业。

只有充分了解自己，才能做出最适合的选择。选对了，努力就会事半功倍，才能全情投入，活出最好。《她力量》里提到“内心导师”的概念。我虽此前不知此名，却发现人生的选择一直被内心导师的声音引导。它为我描绘出未来愿景：一个伏案写作的中年女人，被书本环绕，过着自由简约的生活，看上去有些孤独却眼里温柔，内心安静而丰盈。我当时甚至想落泪，仿佛看清了内心最深的渴望，那是我梦想的样子。

[PRE13]

若不是长期向内探索，我也不会遇见内心导师，它总是指引方向，让我朝着期待的样子成长。你可以把内心导师看作更完整、更清晰的自己，她是你对未来的愿景，你会因此更完整、更成熟，她是你精神和灵魂的声音。不断尝试、不断行动，这样美好才会不期而遇。进窄门，走远路，见微光。在这个浮躁的时代，做难而正确的事很难。你要抵御诱惑，面对质疑和不确定，内心充满恐惧，因为怕付出很多却一无所获，还失去很多。难而正确的事需要漫长验证和探索。大多数人等不了，也没有定力和耐心，于是选择看似容易的捷径。五年前裸辞写作，就是选择难而正确。我好不容易进入世界500强企业任财务主管，公司离家两公里，不加班，工作清闲，仿佛实现了理想。但公开写作点燃了生命的热情，我知道写作才是我要做的事。遇见真正热爱的事，怎能不抓住机会改变现状？

[PRE14]

想从财务转型为专业写作者，必然要付出大量时间和精力。我的第一个孩子在我拼命写作初期胎停了。

三年时间我写出200多篇10w+爆文，名字遍布各大平台，登上官媒，成为爆文作者。但随后遇到瓶颈，我不想再为平台写，我想为自己写。于是我再次选择难而正确。停止投稿，在各大自媒体平台持续写作，直到写出第一本书。

同样，做写作导师四年，我手把手带了1000+写作者走上写作变现，培养了众多爆文作者。也做过一年写作IP私教，帮助很多人弯道超车。

很多人找到了定位并拿到结果。

有人拿到公费出书机会，实现了出书梦；
有人成为IP故事导师，帮助创始人梳理人生故事，放大品牌影响力；
有人成为作协会员，作品上樊登读书，约稿不断，副业稳定；
有人成为文案导师，开设爆款文案课，开启知识变现；
有人成为读书营领读，成为樊登读书常驻作者，一篇书评横扫各大平台；
有人拿下为创始人打造IP的全年文案项目，服务费超3w；
有人在我的指导下，从零做小红书，三月涨到近万粉；
还有人仅靠小红书图文接广告，月变现稳定四位数以上。

[PRE15]

尽管成绩不少，今年我仍选择转战心理赛道，再做一件难而正确的事，只因听见使命的召唤。这是当下我最想做的事。这条路艰难却正确，因为一步步在实现内心期待的样子，也在听从内心的真实声音。那些无人敢走的泥泞之路，走起来虽苦，却通向难以想象的光明。只做更难走的路，更难的事，才更有可能走远，看到更好的风景。

笃定目标，聚焦当下热爱，每一天都能量满满。很多学员常说自己焦虑、迷茫、没动力。其实是你没想清楚要什么，对目标不够笃定，对要做的事缺乏使命感和强大愿力，对自己也不够自信。我无论处于什么阶段，只要想明白要干什么，就能一往无前，拼尽全力实现可能性。进入新赛道新行业并不难，只要有持续学习的能力和行动力，很快就能上路。人生是一场体验，放松心态，笃定前行即可。

[PRE16]

可以说，每一次选择都有从0到1的过程，会有积累沉淀期，也会面对不确定性和风险。但我做决定只为自己负责，不受任何声音干扰，因为外面没有别人，只有你自己。是否开心、有没有热情、有没有内在动力，只有你自己知道。承担结果的也只有你自己。选择之后，所有经历、体验、成长都由你自己承受。旁人只是看客，哪怕父母也是如此。

[PRE17]

不要让他人的声音干扰你的选择，你的人生只能由你定义，你是主角。学会课题分离，分清自己的事和别人的事，你才能主宰人生。做真正热爱的事，你才能绽放无限热情，拥有满满能量。我的人类图显示我能量非常充沛，高能量容易吸引人。我喜欢新鲜事物，创造力很强，这注定我会不断折腾，去探索更多可能。

[PRE18]

转型心理赛道半年，营收突破90w，吸引100多个学员同行，加入“丽行者”。与舒丽同行，在这个时代逆流而上，坚定做自己。财富是能量和认知的变现，内在能量足了，财富自然而来。

白岩松说过：

“阅读带你面对内心，面对人性，面对生命。在你行走艰难之时，为无门之处开门，让无光之处有光。”喜欢某些作者并非偶然，而是一种必然。因为他们的书里蕴藏着你所期待的自己，能帮助你更好地塑造和完善自己。通过阅读，认知提升，眼界开阔，人生体验不断丰富。

有时候一本书或一套思想体系，就能改变命运。阅读让你对任何人和事保持敬畏，不人云亦云，不随波逐流。你会有自己的判断和思考，保持独立思考的能力，在任何境遇下都能清醒面对自己和世界。你会建立稳定的价值评价体系，不易被外界影响，保持节奏稳步前行。我每天都有读书习惯，再忙也会保持半小时。读好书等于和高人对话，收获高维智慧。

除了读好书，还要真正付费向高人学习，一年顶十年成长。

从2022年开始，我投入10万进入各类知识IP圈子，比如菁凌私董会()、不晚轻创合伙人、玩赚合伙人、书香学舍私董会等，了解了很多商业模式和玩法。今年又投入10w学习疗愈技术和教练技术，还花19800学习心理咨询式成交之道。很多人知道，我还付费12万成为伍老师的私教学员，也就是《1000个铁粉》作者伍越歌老师。

在他的课堂上听到，做个人IP就是要活出真我，真实是最好的定位。这与我的价值观高度契合。当我告诉他，我想从写作IP转做心理IP，因为内心最想传播的是心理学，而写作是对外表达的渠道，是传播心理学()的手段，也是我与世界链接的方式。他说我很适合，我的写作好、文字入心，正因心理学功底深厚，洞察力和共情力强，并非写作技巧多厉害。我不该以写作变现，而应把写作当作表达工具，做更大的事业。

[PRE19]

正是心理学成就了我的写作，心理学是根，写作是技能，是心理IP的放大器。他说，做个人IP要有增量思维而非存量思维，基于未来想活成什么样，活出天命，就去做。

[PRE20]

遇到对的老师，会唤醒生命潜能，点燃灵魂，让你看到无限可能。如果你和老师价值观高度同频，他能看见你、激发你、给你能量，就一定要深度链接，他一定是你生命里的贵人，是来成就你的。你想成为什么样的人，就去靠近什么样的人。每个人都有自己的能量场，选择老师更多看的是场域，同频才相吸。毕竟和谁在一起真的很重要。与对的老师在一起，你会被激发出对生命的热情，发现人生的美好，进而找到使命，不断努力前行。

[PRE21]

很多伙伴选择加入丽行者，其实是看中这样一个正心正念正能量的场域。

选择老师不一定选最好，但一定要选最适合的。有些老师看起来很好，但与你不同频、能量不契合，可能并不真正帮助你。相信直觉，遇见适合自己的老师，一定要紧紧追随。
