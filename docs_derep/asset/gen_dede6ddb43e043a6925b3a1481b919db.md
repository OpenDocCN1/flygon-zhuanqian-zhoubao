# 这些效率工具，一次打包给你

工作越忙，越需要趁手的工具。这些年因为工作接触过不少软件，好用的很多，鸡肋的也不少。正好借这次龙珠悬赏活动，我把它们整理出来分享给大家，希望其中几个能帮到你。

## 网页复制、收藏：这两个小插件很省心

你是不是也遇到过这种情况？在百度文库或 CSDN 上看到一段想复制的资料，结果页面弹出提示：请登录或开通会员。Simple Allow Copy 这个浏览器插件就是来解决这个烦心事的，装上之后不用注册、不用开通会员，也不花钱，网页上的任意文字都能直接复制，学习办公的效率一下子就上来了。

网页内容想收藏？试试飞书剪存。点一下插件按钮，当前网页正文就会自动保存到飞书云文档，省去手动复制粘贴的麻烦。它还自带“净网”能力，能智能识别并去掉悬浮或嵌在网页里的广告，让保存下来的内容清清爽爽。之后想加标签分类、分享给别人，或者导出成 PDF 都随你。

## 无代码爬虫和 macOS 截图录屏，安排

EasySpider 是一款可视化爬虫工具。不需要写代码，打开图形界面，在网页上点选你想抓的内容，再根据提示框操作，爬虫任务就搭好了。如果你有更复杂的需求，它也能用命令行方式执行，方便嵌入到已有的系统流程中。

如果你用的是 Mac，iShot 可以称得上一个很全面的截图录屏工具。普通截图、长截图、多窗口截图、延迟截图，以及标注、贴图、取色、录屏……日常需要的功能基本都齐了。

## 用 RSSHub 把信息流驯服

在信息爆发的时代，我们总是被各种推送被动投喂，本想找一根绳子，结果牵出一头牛。RSSHub 是一个开源项目，用起来简单，扩展也方便。你完全可以根据自己关心的板块，去订阅优质信息源，然后在 RSS 阅读器里集中查看。这样一来，时间和精力都省下来了，关注的内容也能高质量获取。

## 顺手分享一个拉新平台

还有个网赚项目的拉新平台，里面项目不少，涵盖网盘拉新、信用卡拉新、号卡分销、应用拉新等等（懂的都懂），个人和团队都能参与。不过要提醒一下：最好自己注册，不要轻信别人的邀请码，我这边也不分享自己的邀请码。

## 压轴：PDF 骑缝章工具 PDFQFZ

最后把这个“走心”的小工具放上：PDFQFZ。如果你经常要给 PDF 文件加盖骑缝章，用它就很省事。操作流程是这样的：先选择要盖章的 PDF 文件（或整个文件夹），再指定一个保存输出目录；然后导入完整的印章图片，它会根据 PDF 页数自动把印章随机分割；接下来调整好印章大小、骑缝章位置和印章位置；点击“盖章”，稍等片刻，在输出目录里就能看到已经盖好骑缝章的 PDF 了。

另外，PDF 的用途不止盖章，如果你要阅读、编辑、转换、合并或者在不同设备上签署文件，也有免注册的工具可用，需要的朋友可以备着。
