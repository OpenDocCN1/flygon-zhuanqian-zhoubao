# 素材从哪里找更安全

很多人卡在第一步：素材去哪找。抖音？小红书？淘宝？别的平台？

其实我最推荐的，还是直接在小红书内部找。

你可能会问：在小红书搬小红书的内容，不更容易被查吗？

直接搬肯定会踩雷，但用对方法是可以绕开的。

举个例子，我当时想做大闸蟹，人在广西，手上根本没有江苏的货源，也不可能飞过去拍。怎么办？

我就直接在小红书搜索“大闸蟹”。

[PRE1]

找到一个用户视角分享吃蟹体验的笔记。

[PRE2]

然后我会去翻这个博主的评论区，专门找那些点赞高、颜值高的用户晒图，只要是我自己看了也会心动想下单的图，我就截图保存。连续找20个同类账号逛评论区，素材库就能撑好几天。

为什么偏找评论区？

因为评论区里的图基本都是真实买家晒的反馈图，更有代入感、更像真实口碑，更容易让人快速信任。而且这些图基本没有被系统收录，判定为搬运的风险很低，所以是我囤素材的核心渠道。

同样思路，其他品类找不到素材时，也可以试试这个方法。记住一点，务必截图。

# 搬运过来后怎么去重

素材收集齐只是开始，后续怎么处理决定你会不会被限流。

很多号主就是不会去重，走了一点流量又被压，刚看到希望又被浇灭。

我的做法如下：

素材攒够一批后，先筛掉10%-20%质感差、颜值低的图片，留下能用的。剩下的每一张都裁剪成3:4的比例。

# 被提示了怎么办，怎么降风险

做搬运，被提示警告其实很常见，常在河边走哪有不湿鞋。

关键是被提示后怎么处理。

还是以我的螃蟹案例来说。当时平台让我优化笔记内容，我纳闷了，图片是我从评论区截的，全站搜了也没见过这张图，怎么就非原创了？

我猜大概率是被同行恶意举报，平台没有确凿证据，只能先给我一个警告。于是我什么都不改，直接重新编辑后重发了一遍。

结果半小时后，警告没了，流量反而比之前那篇还好。

说实话这个操作我到现在也没完全搞懂原理，但每次遇到轻度提示，我都这么处理，基本都能恢复，还能小幅涨量。你们如果遇到类似情况，可以试试。

不过有一种提示就不能乱来。

[PRE7]

如果你收到的是这种违规提示，基本可以判断账号已经被同行盯上，很可能是被举报了，同时你已经被平台重点关注了。

这时候的处理要分两步：

第一步，立刻删掉被判违规的笔记，回头复盘这张图是不是带水印、是不是下载自站外、去重步骤是不是没做全。平台能抓到你，说明问题出在细节上，这张图就不要再用了。换一张全网没发过的图，多做几轮处理后再发，持续稳定输出几篇，权重就会慢慢回升。

第二步，提高警惕，筛掉同行。

笔记被判搬运，大概率是举报。谁举报的平台不会告诉你，只能自己排查。私信和评论区里，留意近期行为异常的人。

比如我昨天遇到一个典型，刚开始正常问价格，我给他发了价目表，他上来就说“加个微信吧”。立刻觉得不对劲，我马上撤回了之前的回复和价目表。

ps：价目表里带了违禁词，容易踩雷

真正有需求的客户，不会上来就索要微信。他们对你不熟，通常会先问细节，确认产品后才会聊联系方式。所以一旦对方行为反常，就要多留个心眼，别留下把柄，否则被举报成功率很高。

评论区有恶意评论、恶意引流的，马上删掉。自己也不能在评论区留下违规话术，公开的评论区就是同行举报你的入口，非常方便。

给大家一个简单的同行过滤小技巧，仅供参考：

别人来问你时，别急着发资料，先聊起来，多问他几个问题。

如果对方很急、很催，就冷处理一下。如果是真心想买的，自然会继续聊。有明确下单意向时，让他主动留微信号，自己去加。

千万不要主动留自己的微信，这是引流的大忌。

说了这么多，其实搬运并不难，难的是把细节抠到位，多实操几次，问题自然迎刃而解。
