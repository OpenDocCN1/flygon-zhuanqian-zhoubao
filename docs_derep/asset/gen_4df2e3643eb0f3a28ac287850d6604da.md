# 靠个人 IP 在小红书宠物圈立足，我做对了这几件事

> 原文指路：[`www.yuque.com/for_lazy/thfiu8/zwtkv8lfas23ypyy`](https://www.yuque.com/for_lazy/thfiu8/zwtkv8lfas23ypyy)

哈喽，生财的朋友们，我是虾饼，一个专注宠物科普的小红书博主。

2021 年底，我决定裸辞，全身心投入自媒体。到现在为止，合作过的品牌已经超过了 200 家，像雀巢、皇家、百利这些国际大牌都在其中，单个平台、单个账号的累计变现也已达到 100 万人民币。

之前在生财分享过这个账号从 0 到 1 是怎么跑起来的，当时就有不少人跟我说对宠物赛道很感兴趣。这次受生财团队邀请，我打算接着聊一聊：账号起步之后，还有哪些方向可以持续打磨。

回顾我冷启动阶段的做法，核心就是把重心放在宠物科普类的图文内容上，靠成熟的爆款套路实现快速引流涨粉。这套打法的有效性如今依然没有过时，现在才进场的朋友照样能参考。不过有一点需要提醒：起号之后想和其他账号拉开差距，保住自己的独特优势，真正把这碗自媒体饭长久吃下去，就得在内容壁垒上多下功夫。
