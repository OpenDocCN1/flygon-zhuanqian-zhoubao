### 二、一句话心法：先跑通再精致

[PRE3]

全程我反复强调的一句话，也是现场共鸣最高的一句：

完成比完美重要，走得慢也比原地纠结好。普通人做产品最大的敌人就三个：想太大、怕不完美、不知道怎么开局。对应就有三条对策：

- 先通路，再美化。先把“上传→点一下→出结果”主线打通，哪怕用假数据、样式粗糙，再谈美化。别一开始就纠结配色、商业闭环。
- 能砍就砍，能假就假，能晚就晚。现场手册里印的就是这句砍需求口诀。今天只做“可演示的最小版”。登录、支付、后端、数据库、账号，全部砍掉。想法再大，今天只做最小可行的一块。
- 不会下手就先动。不会就问 AI，和它对话。先跑起来，项目报错不要怕，把报错丢给 AI 让它修并解释原因。聊得多，你就会有驾驭 AI 的手感。动起来总比反复犹豫强。

当天做得快的，都是舍得砍功能、敢先试的人，技术好坏反而在其次。

### 三、没思路怎么办：先把想法聊成型再动

现场有人工具都装好了，也学了 Codex 做产品，却卡在第一步：不知道做什么。这部分就是给他们的。

- 最省力的一招，把下面这段万能开场丢给 AI，填上你的想法，哪怕很模糊：

你是一名资深产品经理 + 全栈工程师,擅长把模糊想法变成"今天就能做出来的小工具"。我想做一个小产品,主要靠你帮我写代码。我现在的想法(哪怕很模糊都行):\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_先别写任何代码,按下面来:1. 如果我的想法有不清楚的地方,先【一次性】问我 3-5 个最关键的问题, 等我回答后再继续,不要自己瞎猜。2. 帮我把想法收敛成一个"输入 → 处理 → 输出"的单页小工具; 如果想法太大,帮我砍到里面最小的那一个工具。3. 然后输出一份大白话的需求文档(PRD), 并给一份验收标准(最多 5 条,让我能自己检查做没做对)。

它会反过来问你三五个关键问题，你认真答，想法就会快速清晰，比自己空想效率高。

- 更懒一点，装一个 superpowers 的 brainstorming skill，让 AI 采访你，把想法梳理清楚。它在 superpowers 集合里，装好后它不会直接写代码，会先问：给谁用？解决什么？最小长什么样？安装方法见第五章。

- 最好的点子往往是自己的痛点，你最清楚自己想要什么结果。所以从工作中的重复性低难度任务出发，比如报表整理。

- 实在想不出，直接从这张表里挑一个，降低行动阻力：

| 选题 | 输入 → 输出 |
| --- | --- |
| 文案/标题改写器 | 一段话 → 多个吸睛版本 |
| 宝宝/网名取名器 | 姓氏/喜好 → 一批名字 + 寓意 |
| 塔罗/每日运势 H5 | 一键 → 翻牌解读 |
| 简历润色器 | 粘贴简历 → 优化版 |
| 单词卡/字帖生成 | 词表 → 可打印卡片 |
| 报价/行程单生成 | 填几个数 → 整齐单据 |

### 四、保姆级 SOP：从想法到可售产品

下面是我做拾光肖像馆时，对 AI 说的核心步骤，从需求到上线再横向复用。换个产品，把“证件照”换成你的关键词即可。坑我也一起标出来了。

没装工具的，先花五分钟：Codex 去官网下载，用 ChatGPT 账号登录；Claude Code 在终端执行 `npm install -g @anthropic-ai/claude-code`。

装完后新建空文件夹启动，所有文件集中管理，干净整洁。接下来你只需要做三件事：说清需求、看结果挑问题、报错丢回给 AI。

#### 第 0 步 · 选题：先问能不能卖，再问能不能做

很多人先问 AI 能不能实现，顺序错了。先问：现在有人付钱买这个吗？有人在卖、有销量，说明需求已被验证。

证件照、AI 写真、宝宝入园照、求职头像，这类照相馆一次几百起，小红书 9.9 的 AI 写真卖得火，都是真实付费刚需。我做的就是用一个生图能力把这些需求打包。

需求一直都在，变的是门槛。去年不会代码的人遇到第一个报错就停了；现在 Codex / Claude Code 能做到你说人话它干活。需求没变，代码门槛消失了，现在是最好的下场时机。

注意：想法太大，比如“做个像小红书的平台”，只做平台里最小的一个工具，比如我这个垂直小工具。一句话说不清需求，就继续砍。

#### 第 1 步 · 需求：先把话说清楚，别急着写代码

> 我要做一个能在小红书卖的「AI 证件照生成器」网页工具,目标用户是求职者和宝宝家长。先别写任何代码,先帮我把需求理清楚:1. 核心功能有哪些?2. 用户从打开到拿到证件照,操作流程怎样?3. 哪些是今天 3 小时能做完、能现场演示的最小版本(MVP)?哪些先砍掉?4. 靠什么卖钱?用一份大白话的需求文档(PRD)回答我。

让它先出文档、先提问，确认后再继续。

常见跑偏与纠偏话术，直接抄：

- 它没提问直接写代码，回它：“先别写代码，先按要求出 PRD。”
- PRD 里出现登录/数据库，回它：“这些今天不做，删掉，只留最小版。”
- MVP 列了七八个功能，砍它：“只留 1 个核心功能，其余标‘以后做’。”

#### 第 2 步 · 计划：先把技术方案定下来，别让它乱选

> 基于上面需求,技术栈:纯前端单页 HTML(一个 index.html,内联 CSS 和 JS),不要后端、不要框架、不要构建工具,浏览器双击就能打开。先别写代码,先给我:写技术文档、项目结构。

零基础最怕 AI 自行其是装高级框架，需要配环境、构建，一看不懂就劝退。用最简单的 HTML，双击就能跑，减少启动阻力。

技术文档出来后，后续选型不会跑偏。项目结构和分步开发计划你能看懂，比如图放哪、生成图放哪。分步计划其实就是个开发清单，避免上下文太长 AI 掉线。

#### 第 3 步 · MVP：先跑通一条能用的最小流程

> 根据技术文档、项目结构、分步开发计划，开始写第一版 index.html。要求:能上传照片、能选规格(一寸/二寸)和底色、点生成后可以裁成证件照尺寸并拼成 A4 一版多张、预览加水印。这一版先用上传的原图占位(还不接 AI),把整条流程跑通就行,样式朴素没关系。

第一版丑没关系，关键是上传、生成、出结果这条线打通了。这一步只求跑通，不求好看。

[PRE6]

#### 第 4 步 · 核心：AI 出图 + 代码做裁剪

先准备一个图像 AI 接口，比如 gpt-image 类，需要申请 key，可能要少量费用。比如 apimart.ai 的中转站申请，或阿里云通义万相、火山豆包、即梦，去控制台开通 API。不会申请就把“协助我申请 xxx 平台图像模型 key”这个任务丢给 AI，让它一步步带你注册。

有 key 后正式接入：

> 把上传的照片生成成"正装、正面免冠的专业证件照,人脸保持不变,背景按需要直接出纯白/纯蓝/纯红底色"。裁标准尺寸、A4 拼版、水印这些用代码做。注意:底色通过 prompt 让 AI 直接生成对应底色(干净不改脸);用 apimart.ai 的 GPT-Image-2 图生图能力, 生图模型API 的接入文档是：https://docs.apimart.ai/en/api-reference/images/gpt-image-2/generation，api key 是：xxxxxxxxx

这一步我踩的坑最多，整理给你：

- 坑 1，生图是抽卡。第一版蓝底发灰，脸也变了。解法是加英文约束：底色用 solid pure blue，保脸用 keep the person clearly recognizable as the same individual。直接抄，不满意就重抽。
- 坑 2，图生图要传原图。光靠 prompt 描述没用，原图必须作为输入传进去。各家接口传法不同，让 AI 查文档实现，别自己啃文档。
- 坑 3，出图需要 10-50 秒。第一次我以为卡死，后来让 AI 加等待提示：“AI 正在分析五官、换正装、打光、精修”，等待感就变期待感。

⚠⚠ 报错高频处理：把报错原文整段复制回去，说一句：这是报错,帮我看看怎么修:<贴报错>。一般是参数尺寸写错，一分钟就能修好。

三步法：复制报错→丢给 AI→再跑一遍。

实话说：图生得好看不值 9.9。你的工具要能稳定出图、精准裁剪、免费预览但加水印，想下载高清就付费，一步步引导用户付费。

图片生成交给 AI，精确裁剪交给代码。

#### 第 5 步 · 美化：把指令说具体，它才改得准

> 把界面美化成能直接发小红书的专业风格:渐变标题、卡片式布局、上传/选模板/选底色分成清晰三步、生成按钮有质感、点下去有"生成中"转圈动画、出结果时淡入揭晓、证件照带相框阴影、手机上也好看。

按这段跑一版，但别停在此。继续打磨几版才拿得出手。

挑毛病要具体：

- 不行：“再好看点”“有点丑”，AI 不知道丑在哪。
- 行：“标题太小，放大学一倍”“主按钮太灰，换暖橙色”“结果卡片太挤，加间距”“手机上按钮被挤出屏了”。

说清三件事：哪一块、什么问题、想要什么样。

再上一层。上面 prompt 改完后，界面整齐了，但蓝紫渐变加系统字体，一眼 AI 味。想拿得出手，我重做了一轮，prompt 明确写：风格是“数字摄影工作室，编辑杂志感，暖纸色背景 + 墨绿赭金配色 + 衬线大标题”，“避免蓝紫色渐变和系统字体那种 AI 味”，再加一句：“所有现有功能不能丢”。这一轮用 frontend-design skill 优化的，约 5 分钟。
