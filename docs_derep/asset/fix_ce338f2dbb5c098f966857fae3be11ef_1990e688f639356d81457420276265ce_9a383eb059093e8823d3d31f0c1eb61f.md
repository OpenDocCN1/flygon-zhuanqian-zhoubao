# 从19.9到199：普通人做创业类付费社群，2个月吸引200+会员、变现近万元

我是新侠。白天在苹果供应链体系内一家头部企业做中层，管着一支20多人的工程师团队，也带一支50多人的产线团队，日常主要跟数据分析和组织协同打交道。下班之后，我喜欢在互联网上折腾各种小项目。

今年年初，我把副业探索正式提上日程。一开始算不上原创，大量参考别人的玩法，再结合自己的情况反复调整，最后慢慢做出一个围绕“互联网创业”的付费社群。

这个社群的价格变化很快：刚起步时只收19.9元，之后随着内容和交付不断升级，一路提到199元。前后运营差不多两个月，付费会员超过200人，累计收入来到9900元以上。

更能说明这套打法学得会、也用得上的是另一个案例。4月2日，我把整套项目逻辑拆解成可执行的步骤，交给我妻子的弟弟——一位从未接触过互联网的新手。他在4月6日完成首单，从学习到成交只用了4天，整个闭环顺利跑通。

回头看，这段探索的路不算顺，绕了不少弯、踩了不少坑，好在最后蹚出了一条普通人都能上手的互联网路径。更让我有信心的是，这套方法不仅在我自己身上有效，在完全零基础的人那里也验证通过了。

所以，我把启动以来遇到的问题、应对策略以及个人心得整理成一份完整复盘，放在飞书文档里。想参考详细过程的朋友，可以直接去飞书阅读。

评论区也有人问我“还收人吗”。我的初衷不是拉新，这次更多是想把经验和踩坑过程沉淀出来，给同样在副业路上摸索的人一点参考。
