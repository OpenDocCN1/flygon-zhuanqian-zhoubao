# 一、先把“二奢”这回事搞清楚

**（1）二奢到底是什么？**

说白了，就是别人用过的奢侈品。但请注意，核心不在“二手”，而在“性价比”——用更少的钱，拿到更高级的货，让虚荣的门槛降低。这才是它真正的吸引力。

**（2）市面上都在卖啥？**

品类挺多：箱包、腕表、配饰、服饰、鞋……不过主流是箱包，也有专门盯腕表的。

**（3）全局图：二奢产业链的上中下游**

[PRE0]

**上游：**
- C端：纯个人卖家，偶尔出点货回回血，不稳定；
- 小B：一部分是个体户，一部分本质还是个人，没有营业执照，但手里有货，把这当门生意做。

**中游：**
- 机构：小型直播机构，手上有几个主播能销货；
- 平台：可以理解为“仓库+大型机构”，我们目前就是这角色——有自己的物理仓储和系统，把货品标准化管理；货主要来自小B，也有自采团队供自营；还有自己的销售团队。
- 销售模式：寄卖为主（先卖货再结钱，就像出了本书，别人帮你卖，你躺着分钱），包括卖家定价（平台抽成，利润薄）和平台定价（平台说了算，只给卖家结算供货价）；采购和回收为辅（采购是toB，回收是toC）。

**下游：**
- C端买家：消费者；
- 同行：除了C，还有同行，比如帮帮虎、奢当家、段小狸。

**（1）为什么非说直播？**

因为二奢是**非标品**，和标品直播逻辑完全不同。标品是流量越多卖得越多；二奢件件孤品，好卖的瞬间抢光，剩下都是难卖的，流量越大，成本反而越高。

那为什么还要直播？
- **新鲜**：每天上新，让人忍不住天天来逛，比逛实体店还上头；
- **直观**：主播专业讲解、细节展示，建立信任，主播就是导购；
- **互动**：有疑问实时问；
- **氛围**：直播间的气氛，特别容易让人冲动下单。

销售场景主要在抖音——高客单、非标的玩法，下面讲的主要就是孤品流程。

**（2）货的生命周期**

一句话概括：BD从商家拿货→仓库入库→到指定日期配给主播→开播售卖。但中间细节多着呢。

**先看主播和排期：**
- 主播看两维：**专业度**（懂不懂包，强的专门卖包，弱的是泛品类主播如服饰珠宝、明星达人）；**大小**（大主播单场GMV百万到千万级，小主播几十万以下）。
- 排期：就是主播的开播日程，一般提前一个月安排，因为每人偏好不同。

**再看商家（小B）：**
- 小B就是手里有批货的商家。
- 他们从哪些渠道收货？① C端用户（有线下门店的，周边用户拿来卖）；② 闲鱼（直接回收C端，也有小B的货）；③ 包展（主要是LGE，报名就能参加，常在沪杭）；④ 同行（目前主要走帮帮虎，B2B交易）；⑤ 买手（日本、美国的二奢流通比我们早，流转率高，国外朋友可以倒一手，比如日本中古交易所）；⑥ BD（找到一个靠谱BD，货基本稳了，BD手里大把商家资源）。
- 管理方式：没系统的用Excel；有系统的用【奢当家】【段小狸】做货品管理。
- 小B关心两个指标：**货品动销**（谁销货快给谁，动销高的能到80%）；**货品结算**（谁结钱快跟谁玩）。
- 小B还关心这些问题：寄卖货品管理、动销、价格动态调整、商品召回、结算售后、货损瑕疵处理、养护服务等。

**（3）然后是供货**

BD会提前找商家协商配货计划。假设一只包被看中，就进了供货名单。开播前4~5天，BD催商家发货，包就坐上快递来到平台仓库。

入库要经过：**录入→鉴定→养护→定价→选品→拍摄→上架**。
- 录入：记商家信息、图片信息、供货价；
- 鉴定：真假+残次判定。真且良品直接过；假货驳回；真但次品，太次的退回，一般的养护后再卖。
- 养护：看情况清洗、轻度护理；
- 定价：分系统定价（根据期望利润率+市场价动态算，公式复杂）和人工定价（商品运营实物判断）。
- 选品：主要针对抖音，因为上架抖店要填商品信息；
- 拍摄：精拍，包括封面图+细节图；
- 上架：放到对应库区库位，准备卖。

还有个“专场供货”：一批货专项供给某个主播，两种情况——商家信任某个主播（动销快），或内部BD给专有主播供特定货。

**（4）接着，配货**

配货就是给直播团队配开播要卖的货。谁来配更合理？三个角色：BD（一手拿货，懂主播销售逻辑）、商品运营（中心化部门，懂货懂主播）、直播组（直接销售方，更懂货）。更合理分工：BD拿货、商品运营定价、直播组配货销货。

开播节奏：因为孤品，不能像标品批量过，必须一个包一个包过，链接一个一个上。快的1分钟一个包，稀缺品，基本每次都是秒杀。货盘节奏嘛，自己跟几场直播就明白了。

**（6）卖掉了，怎么履约？**

仓库打包发货，客服处理售出和售后。

常见售出/售后问题：
- 客户要看更多细节图；
- 客户要求保养再发货；
- 主播虚假承诺（比如去污、粘皮处理、免费打孔等口头承诺实现不了）；
- 主播没提瑕疵（客户收货一周内反馈与直播间介绍不符）；
- 鉴定问题（手表、饰品、围巾等过不了检，年份标模糊、镭射标模糊）；
- 质量问题（拉链卡住、手提变形、划痕去不掉、表针卡住、老化掉皮断裂）；
- 味道（有些因为养护有霉味，其实不是发霉）；
- 色差（颜色与图不符）；
- 缺货问题（孤品，死活不退）。

三个核心问题：
- **超拍**：秒杀时库存只有一个，但买家付了N>1的订单。抖音一直没修的漏洞（估计故意的），对客服很棘手，孤品没货只能一个个劝退，多的时候上百单。
- **中检**：抖音有个BTAS质检仓，跟中检合作。二奢订单几乎98%会被抽中，抽中的必须先发到BTAS质检仓鉴定一遍再发给客户。低于300元的一般不抽，也算不上奢侈品了。
- **退货**：二奢退货率高，高的时候能到70%。

关于中检和中溯：都是国家认证的奢侈品鉴定中心。中检全称“中国检验认证集团奢侈品鉴定中心”，英文CCIC；中溯全称“中溯检验检测认证中心”，英文COIC。

**（7）货没卖掉呢？**

**（9）资金运转逻辑**

两个账期：
- 应收：抖音跟我们结算，目前T+4或T+10，T从买家确认收货起算；
- 应付：我们跟商家结算，按商家分层，一般T+9+7，T是发货时间，结算期9天，售后期7天。结算期一到就可以结钱；售后期是结算后7天内若退款，已结款可追回。

提前结算：没到结算期就提前结，两种情况——和商家绝对信任，或包展特殊模式。

异常赔付场景：成色降级（保管中降成色）、丢失赔付、降价回收（协商低于供货价吃进）、超时吃进（已结算货发生售后但商家不退钱，只能自己吃进）。

**（10）展开聊聊**

- 一只包到消费者手上就结束了吗？没有。梅特卡夫效应说买卖双方可互换身份。二奢就是这样——包到了你手里，你完全可以再转手寄卖，供应链从头循环。
- 衍生玩法：私域会员积分成长体系。买家变卖家给积分，下次消费抵扣；促复购；积分分等级，不同等级不同服务。

# 三、行业常见问题&解答

**（1）二奢还有哪些业务？**
寄售+同行（拿上游寄售的货出给同行，再跟上游结算）、私域直接面向C端、AI智能鉴定+款式库、多平台销售（小红书、95分、淘宝直播等）。

**（2）买家都是什么人？**
主要是白领，其次是学生党、名媛、时尚工作者。需求多是满足虚荣心和社会价值观。款式偏好：Gucci、LV、YSL等经典款。

**（3）二奢真的只卖二手吗？**
业内都说二奢就是孤品，其实不对。做二奢的基本也做标品，只是定位不同。纯二奢利润做到15%已经不错了，标品更灵活，既能冲利润也能冲气氛。

**（4）流量从哪来？免费还是付费？**
看定位。如果你是商家，一般不直接找C端买家，更愿意找平台或直播机构寄售，坐等收钱，要么同行直接出掉（比如帮帮虎）。如果你是机构，C端用户主要来自抖音、淘宝，也有些直播机构私域攒客源。

**（5）抖音直播怎么做？投流还是免费？**
抖音一般做矩阵、做规模，非IP化，主播要去IP化。要投流，但要看店铺情况——店铺评分低，投流只会废掉整个店。

**（6）GMV和毛利能有多少？**
孤品毛利一般10个点左右，标品可以做到30-50。GMV方面，大主播单场可以做到千万。

**（7）客单价多少？**
4~5k、7~8k都有，看平台。

**（8）新人如何入局？**
机会和风险并存。

先说机会：二奢起源于日本和美国，国外流通率比国内高很多，有报告说国外30%，国内只有5%，国内还处于早期。加上中国是奢侈品消费大国，客单价高，存量价值大，机会不小。

再说门槛：说实话不低。要懂货、懂业务、有资金、有资源；硬门槛是真假鉴定，箱包还好，钟表水太深。

最后说新人切入点，供应链每个环节都有机会：
1. 有人、有精准买家，可以去找货，做私域；
2. 有资金，建议从小B入，通过上面提到的渠道进圈子拿货，好货不愁卖；
3. 有直播资源，可以从机构切入，或者买个女粉号，找个合适主播，投投流也能搞个小机构。不一定非要二奢主播，女性相关的泛品类主播也成——我们已经跟外部非二奢达人主播合作过，模式可行；
4. 货品周边：比如养护服务；
5. 开线下实体店或工作室。

入行资金预估：
- 从朋友圈做起，主要走回收，然后去平台寄卖（也可以找我），准备2万~5万，前期别投太多，先小生意跑起来，不囤货，快进快出，目标跑周转；
- 资金充足点，10万~20万起步，上不封顶，越多赚越多；
- 开实体店，差不多80万以上。
