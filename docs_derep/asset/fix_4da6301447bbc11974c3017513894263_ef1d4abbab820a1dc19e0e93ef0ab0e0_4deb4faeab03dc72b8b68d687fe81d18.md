# 视频号【出镜人身份验证】卡住了？搬运混剪博主的自救笔记

> 来源：[https://dls8hvx5jh.feishu.cn/docx/TlHXdlcKOo1gQwxkeqscB8GfnXe](https://dls8hvx5jh.feishu.cn/docx/TlHXdlcKOo1gQwxkeqscB8GfnXe)

大家好，我是阿橘。最近整理了一套关于出镜人身份验证的实操经验，亲测可行，我手上8个账号全部成功解开限制，朋友圈里不少同行也靠这招把号救了回来。

当前做视频号的同学里，碰到【出镜人身份验证】提示的概率很高。早期靠卖惨话术还能蒙混，现在审核对这类套路已经形成抗体，哭诉基本通不过了。

搬运他人出镜素材的账号，常常会收到系统发来的私信：

[PRE0]

一旦没通过审核，账号会被限流整整180天，私信功能也会被关闭，等同于账号作废。注销重开的等待周期长，还耽误运营节奏。

如何提高通过率？下面按实际情况拆解应对思路。先说个前提：以下方案主要面向视频号已经完成实名认证的用户，请先核对自己的认证状态：

[PRE1]

若从未完成实名，且橱窗保证金也未缴纳，可以尝试直接注销账号再重新注册。

若从未实名但已缴纳橱窗保证金，情况就棘手一些，因为无法立即注销。更麻烦的是，平台会要求填写视频里出镜者的身份证信息并配合人脸核验，这对搬运内容创作者几乎无法完成。现阶段可行的思路是先更换微信实名主体，再返回视频号认证页重新走一遍流程。这一招我本人尚未实践，是从社群里收集的案例，暂列为待验证方案，后续会补充更新。

未实名的情况属于少数，多数用户已完成实名认证，下面两类情况为重点。

小技巧：让出镜者当下穿着与视频中一致的服装，过审几率明显提升，这样“2”项补充材料往往可以省略。即使服装有差异，也无大碍，人脸匹配度达标即可。材料提交后等待系统通知，收到提示即代表账号恢复正常。关于审核时长：审核团队夜间休息，若晚间提交，通常次日上午10点左右收到结果；白天提交最快半小时，慢的话需要数小时，请耐心等待。

### 情况B：搬运的素材出镜者是你不认识的陌生人

第一步是先将账号内所有存在侵权的视频全部删除。随后在百度或小红书检索正能量语录、老人金句等内容，随意挑选一条，或自行撰写一段祝福词均可。

[PRE6]

打开前置摄像头录制1-2条口播，每条控制在10-15秒。录制完毕后通过视频号从本地相册发布。

### 其他补充

若按上述流程申诉未通过，建议检查提交的材料是否模糊不清、文字是否难以辨认，重新梳理表述后再提交。目前该方案仍具有效性。

#### 申诉入口消失怎么办

部分同学反馈曾申诉失败后入口不可再次点击。可先发布一条新的正能量口播视频，非特效自拍类型，发布后系统大概率会再次推送私信提醒处理真人验证。若仍无入口，可前往创作者中心-帮助与反馈-最底部-问题咨询-账号、认证，将准备好的截图与说明粘贴提交。也可发送邮件至腾讯：channels_consult@tencent.com
