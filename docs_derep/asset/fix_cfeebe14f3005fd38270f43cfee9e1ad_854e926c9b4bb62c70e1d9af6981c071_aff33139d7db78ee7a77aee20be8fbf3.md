# 一、为什么会盯上AI卖课这个方向？

说白了，今年“AI”这两个字，在我身边出现的频率高到无法忽略。

### 1. 学员反复提起

在转做AI之前，我做的是美术类知识付费，一边卖工具，一边卖课。很有意思的是，学画画的学生老跟我聊“AI绘画”，问的人越来越多。我去看同行的直播间，也发现好多人用AI当钩子来吸引家长。

[PRE5]

### 2. 所有信息渠道都在聊AI

朋友圈、公众号、社群、短视频平台，甚至曹大的知识星球，反复出现AI相关内容。到了那个节点，我已经比较确定：这不是一阵风，AI会带来一次大变化。我也因为好奇，自己装了ChatGPT去体验。但说真的，直到9月，我还在老老实实做美术直播。

### 3. 真正让我下决心的，是偶然刷到一个直播间

美术项目做到后面实在做不动了，我打算放弃，那时候正在找新方向。某天刷到一个博主的直播，一场AI课卖出500单，我整个人被震住了。在那之前，我根本不敢想象一场直播能出这么多单。

然后我立刻开始深挖，到处找同类账号。发现抖音那边更夸张：几个头部博主每天能卖1000单199元的AI课，一天就是20万流水，累计好几万单。这个量级，在我做美术直播的时候想都不敢想。那一刻我判断，AI课的天花板，比美术项目高太多了。

### 4. 各平台对比下来，视频号明显有机会

我还专门去看了小红书和视频号的情况。小红书基本没看到做得特别好的案例；但视频号这边，已经有好几个中小博主卖得相当好，一天开两场直播，能走300单。也有刚入场不久的新号，三个月攒了3000单。

看到这些，我已经确定要做AI知识付费了。我为什么觉得自己能做？因为我亲手玩过ChatGPT，发现真没那么难。再说，连以前卖短视频课、完全没碰过AI的人都能卖AI课，说明这行门槛不高——说白了，就是60分的人教别人做到20分的事。而且我蹲了不少博主的直播间，发现卖课这件事的核心不在于你拿AI做出了什么多牛的作品，而在于你能不能用嘴，把AI的价值和自己的专业感讲出来。这套逻辑跟我之前做美术类目的时候一模一样，所以我有底气。

那选抖音还是视频号？我想都没想就选视频号。原因特别朴素：我以前做美术项目的时候，在抖音完全卖不动课，后来转去做视频号才缓和过来。视频号的用户结构主要是宝妈和中老年，人群很朴实，没被直播带货那套反复轰炸过，下单决策很轻松。而且平台氛围很包容，只要你敢露脸讲话，就算照着稿子不带感情地念，也能卖出课去。抖音那就不一样了，就算你有大流量、有大投放、有成熟主播，课也未必卖得动。现在很多抖音卖课的，其实都是把公域流量导到私域再成交。我举一个对比特别明显的例子：不少博主在抖音发AI视频火了，流量巨大，可一开播，直播间就几个人，根本转化不动。那些在线几百人的AI卖课直播间，大部分都是付费投流砸出来的。

视频号呢，只要视频有播放，攒好预约再开播，随随便便卖几十单，一点不夸张。所以我说视频号是红利，是普通人的窗口。我毫不犹豫选了视频号，而且做的内容完全没有同步到别的平台。方向一定，我马上去找对标账号，准备像素级模仿。

# 二、怎么找对标？

找对标是一项很关键的能力。好的对标能让你思路清晰，知道该做什么、往哪儿使劲。但只盯着一个账号是不够的，得从多个维度找多个参考，才能保证做得起来。

像知识付费这类项目，我需要找三个维度的对标：课程对标、内容对标、直播对标。

如果只抄一个人，大概率做不好。我见过不少同行，只盯着头部主播模仿，有一个算一个，几乎没人做得好。原因有两个：一是头部大V积累了多年的IP势能，普通人很难复刻；二是他们的流量来源大多是付费投放，你钱包里那点钱根本烧不起。

那新人怎么入手？我的做法是：把AI行业里的大中小博主都看一遍，按平台和板块拆开来学。具体分三块——课程对标（交付）、内容对标（流量）、直播对标（转化）——分别找做得最好的人来模仿。整个过程，我一直坚持低成本创业的思路。

## 1、课程对标：怎么把课做出来？

我先买了一批博主的AI课，自己从头到尾听一遍，吸取各家课程的长处，整理出目录结构。然后用飞书妙计把音频转成文字稿，做PPT，再用直播伴侣录课。因为我以前当过老师，讲课这事我还算熟练。整个流程理顺之后，从零到课程上架，只花了五天。

[PRE8]

这里必须提一个坑：千万别等把课全录完了才开始卖，也别等“你觉得课程能卖了”再上架。一定要边卖边补。项目初期录课极其消耗心力，而且没有正反馈。正确做法是先把初版甩出去，有爆的苗头再持续更新。其实对于用户来说，持续更新本身就是一种交付。非要等课全部录完再开卖，黄花菜都凉了。

交付这块，我遇到最大难题是：学员怎么持续用上AI工具？我不会研发，甚至AI自己都是现学现卖的。你去看头部博主，基本都是自研AI工具。我也打听过自研成本，套壳要2万，每个月还有维护费。对我这种刚起步的人来说，这个方案直接排除。刚开始做项目，低成本才是最重要的，一上来背太多包袱，只会影响你的发挥。而且2万块，对我来说真的是一笔大钱。

所以我不看大博主的交付方式，转去看中小博主怎么做。一看就懂了：国内有免费的AI工具，比如文心一言、讯飞星火、度加剪辑，课里详细教用户怎么下载怎么用就行。这本质赚的是信息差，但帮我省下了一大笔开销。有没有自研工具，真的不重要。直播卖课的时候把话术稍微改一改，效果没什么差别，成本却少了好几万。

[PRE9]

我的方案是轻交付：就一门199的课，用户买完加微信，我本人一对一指导。这样反而让学员更安心下单。你可能会担心一对一很耗时间，其实不会——99%的问题学员看课就能解决，真正来问的很少。我每天固定三个时间段统一回复，现在2000个学员，每天答疑加起来也就半小时。交付做得轻，我就能把精力全放在搞流量、搞成交、搞利润上。

课搞定，就到了核心问题：流量怎么来？

## 2、内容对标：流量从哪来？

我认为知识付费这个赛道，不管你是做自然流还是投流，内容永远是最核心的。没有内容就没有流量，内容不行，你连投流都投不出去。我获取流量的方法也很简单：找对标，像素级模仿，永远别想着自己造轮子。

AI这个主题，3月份就在短视频平台爆过一轮，市面上大量验证过的爆款文案，到10月我进场的时候，素材已经多到抄不完。我要做的，就是把各大平台上点赞超过一千的AI文案全扒下来，然后自己真人出镜口播。抖音的文案我用轻抖小程序转写，视频号的内容就录屏下来，再丢进轻抖识别。那段时间我一天能拍十几条视频。前期都是在出租屋旁边的河边拍，拍完回去自己剪，一条要剪四十分钟左右，一天稳定产出三条素材。

[PRE10]

我特别建议：能真人出镜就一定要真人出镜。真人出镜的口播，转化率比起其他形式高出很多。别担心自己表现力不行，这种东西就是练出来的，你拍到一百多条之后，面对镜头就跟聊天一样自然。在视频号面对中老年群体，我觉得根本不需要多专业的拍摄技巧，反而是越接地气越好。我前期的视频全是用苹果11前置镜头拍的，在剪映开提词器，怼脸就拍。语速一定要放慢，搭配点手势和眼神，别一直盯着屏幕。其实只要你照着稿子念完，视频就会有流量，因为这些内容本身已经火过一遍了。一字不差地念出来，它也是你的原创。

剪辑上我拒绝花活。画面简单、声音大、字幕大、素材清楚就够了。转场、音效、关键词变色，统统不需要。你会发现一个现象：很多在抖音火过的AI视频，发到视频号就是火不起来，原因是中老年用户不爱看那种炫技风格。我到现在还保持每天花一小时刷视频找灵感的习惯。没有内容等于没有流量，就算你花钱投流也投不出去。

还有一个特别重要的动作：开播预约。用户在看你视频的时候，视频下方会出现预约条，他点了预约，开播时微信会给他推送通知。正常情况下，大概50%的预约用户会点进来。黄金时间是晚上七点半到九点。PS：你正在直播的时候发的视频，不会显示预约条，视频上会直接出现直播入口。

[PRE11]

前期我会把预约定在三到五天之后。每天坚持发三条素材，哪怕播放量很普通，攒几天也能攒出预约。要是某条视频突然爆了，就临时加一条当天的预约。预约积累可以撬动直播推荐，更重要的是，你开播第一波就有足够多的观众可以成交。我自己卖课，主要成交就发生在第一波。

讲个具体的例子。初期我只运营一个号，每天发三条视频，隔一天开一次播。在视频没有爆的情况下，有一场直播总共202个人看，就那场直播，我照着稿子念，卖出了4单199的课。

[PRE12]

那天我真的特别震惊，忍不住感叹：这就是趋势的威力吗？要知道我之前做美术类目，一天播三场，课怎么都卖不动。视频号上甚至很多直播间上万场观，一个单都出不了的情况也很常见。这件事验证了我的判断：选择比努力更重要。同样的力气，花在不同的类目上，结果完全不一样。

## 3、直播对标：怎么把货卖出去？

先说我前期的数据：平均50个人看过直播，就有1个人下单。这个转化是怎么做到的？关键在于搞清楚你的客户是谁。

我卖的AI课，用户群体大部分是50岁以上的中老年人。有钱有闲，对新东西有好奇心。所以我的直播话术，就专门往这个人群的偏好上去设计。

直播话术的核心是“抄”，但要有方法地抄。第一步，去蹲守各大博主的直播间，录屏，反复听。以头部博主的话术为主要参考，分析他们的成交结构。注意一定要多方组合，别盯着一个人照抄。结合视频号的调性，整理出一份完整话术，包含实操讲解、课程钩子、憋单话术、逼单话术。

[PRE13]

具体怎么组合？比如A博主直播以讲解为主，基本不实操，但成交部分做得极好，那我就在成交环节把他的话术整段照搬。B博主很重视实操，对中老年用户来说，能亲眼看到AI的效果是很强的吸引点。不过他演示的内容偏年轻职场风格，比如写表格、做PPT，老年人用不上。所以我只借鉴他的思路，把案例换成健康咨询、风景视频这类中老年感兴趣的方向。最后我结合视频号中层博主的实操案例，把成交部分用A博主的话术，拼成了一套转化效果很好的直播稿。稿子总共12000字，从头到尾念完要40分钟。

[PRE14]

前期你可以照着稿子念，也能出单。但真正稳定出单，靠的是背下来。以理解为主，把整篇稿子背熟，你就能一场接一场地把戏演好。因为在我看来，这类直播本质上就是一场个人演出：台词背熟了，每句话配什么语气、动作、眼神，全部排练好，你上场就是表演。每场直播就是那几轮，一遍一遍演，总共两小时。公屏上的互动，交给运营去回，你只管演好自己的部分。

关于形象，因为我是00后，看起来太嫩，所以刻意把自己往成熟里收拾：大背头、金丝边框眼镜、黑色西装衬衫。夏天穿短袖款，冬天穿长袖款，一个款式买四件换着穿。背景是网上买的书房贴纸，随便一贴就开始播，一直用到现在。

这套思路跑通之后，最能打的一场是10月31日：两个号同时爆了视频，小号单场出了104单，大号播了2小时出了43单，一天加起来差不多150单。再往后我还有好几场直播流水破了万。

能接住这波爆发，靠的是前面无数次直播练习积累下来的手感。视频一火，马上开播，把流量稳稳接住。这些流程我一个人就全跑通了，后来配了一个运营帮手，两个人就能搞定。

做矩阵的想法，其实是受一个情感号博主启发的。我刷到他同时运营好几个账号，内容稍微变一变，多个号一起发，每场都有流量。这让我想明白一个道理：单账号的价值太有限了，流量还得靠概率。我简单算了一下：一个号一天发三条视频，每条就算只有1000播放，攒两天预约就能播一场。如果两个号这么操作，那就等于天天都能开播，天天有进账，而且爆款概率翻了一倍。这个决定后来给我带来了很大的收益。

我接着注册了一个新号，每个号每天三条，早中晚准时发。结果新号开了大概八天，一条视频突然爆了20多万播放，进来的人全是精准用户。那天中午我睡醒看到数据，直接开播，一口气播了六个小时，话术循环了十遍，出了104单，到现在也是我的单场最高纪录。巧的是，老号同一天也爆了视频。我把预约错开，新号播完六个小时后，休息了一会儿，又上老号播了一场，再出43单。那一天做了差不多3万营业额。整个10月，做出8万营业额。因为成本极低，这8万几乎等于利润。

这里得说一下那天为什么能撑六个小时。知识付费直播是需要持续亢奋来带动成交的，不可能摸鱼。那六个小时我不休息，不上厕所，顶多在展示工具的间隙30秒塞几口面包和水，然后继续激情输出。动力是什么？是同行刺激。在我视频爆掉之前的一两天，好几个同行同样是因为视频爆了就是开播，一场能出100多单、200多单。这让我明白了一个底层逻辑：视频一旦爆了，根本不需要预约，一条视频就能一直往直播间里送人，你能播多久就能卖多久。

还有一个原因是我不服。大家都是差不多时间起步做这件事的，别人可以，我为什么不行？那天中午我睡醒，饭都没吃，看到视频已经跑到3万播放，毫不犹豫就开播了。当时真没想着要出多少单，就是憋着一股劲儿。结果每次循环话术都能出单，循环了10遍，破百单，目标达成，那股劲儿才松下来。说来也挺感谢那些同行的，没有他们在前面爆单，我也发现不了这个规律，就不会有后面那场百单直播。不过说实话，我现在没有再敢播6小时的勇气了，播3小时心力就耗光了。

到了这个阶段，我明显觉得自己精力不够用了。视频爆了就得直播，一直播就顾不上拍素材。我还要同时负责找素材、拍摄、剪辑、客服、直播，基本全包。一个人搞两个号已经是极限。后面我还想铺矩阵，所以当务之急是招人。我决定招一个剪辑，把内容产出的担子分出去。

关于个体户招人，我分享一点心得：我的要求很简单——会剪辑，为人坦诚，工资管够。

第一，有经验。我不需要教你剪辑技巧，我把流程和要求优化好，你上来就能干活。你只管剪视频，其他都不用操心。每天六个小时，到点高效产出，剪完下班。第二，为人真诚。我招人先看人品，再看能力。有事直说，你对视频有想法，拿出案例说服我；我有要求也一样，用案例说服你。你觉得自己工资拿低了，直接说出来，我们按你的产出价值来重新谈。跟这样的人合作效率特别高，做事很利落。这套思路是从《不拘一格：网飞的自由与责任工作法》里学到的，这本书我挺推荐。真诚是最好的沟通方式。

# 三、售后和那次封号

知识付费这个行业，售后是绕不开的坎。你不能永远拒绝用户退款，否则等平台介入，售后纠纷率高了会很难收场。

11月底，平台没有任何预兆，直接给老号发通知：店铺永久封禁，资金冻结一个月，账号永久失去带货资格。没有提醒，没有申诉入口。官方一旦判定，基本等于无法翻盘。这件事，算是这个项目里我遇到的一个不大不小的挫折。
