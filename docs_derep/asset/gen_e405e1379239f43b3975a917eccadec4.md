想做成一个项目，折腾是少不了的。好在这个被大多数人忽略的平台上，我们终于扑腾出了一些浪花。

## 三、项目全貌

整个模式的链路是：短视频做流量 → 直播间承接 → 磁力聚星变现。

快手磁力聚星很适合新手，坑少，只要不碰违规内容就行。在我眼里，这算是今年少有的正规且相对暴利的项目了。

简单介绍一下磁力聚星：它前身叫快接单，是快手主流的变现入口之一。2022年快手开始大力推广，开通门槛从原来的10万粉降到了1万粉，现在通过一些渠道甚至0粉也能开通。对新人来说非常友好，可以说是零门槛，基本不用专业技能。

目前进场的人还不算多，平台还在疯狂生长阶段，玩法也很多样。

我们重点做的是“快手短视频 + 无人语音直播 + 磁力聚星”这个组合，优势很明显：
1. 快手语音直播只要不是特别过分的诱导，基本不违规，配合下载任务即可。
2. 短视频不带任何外部链接，推流非常大。
3. 直播间挂磁力聚星变现链接，几乎不审核。
4. 磁力聚星操作简单，视频和直播挂链接都很方便。
5. 不用交保证金和其他杂费，一部手机就能跑起来。

我们做短视频的核心原则就是：素材一定要受众大。怎么判断？播放量基本要在8000到1万以上，才算合格。比如AI美女动图这类，随手一发就是上万播放。当然我不只做这个类型，目前跑出高流量、高转化的有6个类型，后面会分享更多案例。

短视频有流量后，就用直播间来承接转化。我跑了4个月，不断优化，最后选定语音室直播，这个方法非常稳，只遇到过几次6小时违规提醒。

有一点必须提醒：千万不要做视频直播，尤其是搬运录播！一旦被系统查到或被举报，很容易进小黑屋、封号。

## 四、实操步骤

### 1. 账号注册

- 一个手机号能注册1个快手号 + 1个极速版；绑定1个微信可再登录1个快手号；绑定5个QQ可登录5个快手号，一共8个号。
- 设备：如果手机之前违规过，必须刷机再注册。
- 实名：一个身份证可以实名2个号。
- 网络：必须一机一号一卡，这是硬性条件。
- 包装：注册完马上改资料，对标同行改就行，不用花心思从头想。

注意：快手不用养号，注册当天就能发作品。违规过的手机注册前要刷机。如果发了一周播放量还不到100，直接注销换号。

### 3. 磁力聚星变现

如果是美女类素材，可以挂聚星的直播、应用下载、交友类任务。

结算方式一般有两种：安装计费和转化计费。

安装计费：用户安装App就算一个有效单，交友类安装单价佣金在4-5元。
转化计费：用户安装后还要充值或触发有效动作，才算一单，佣金一般在几十元不等。

两种方式各有优劣。直播间套路深就用转化计费，套路浅就用安装计费。不过我这个类目实测下来，转化计费收益更高。

需要留意的是，转化计费任务通常要求出镜，但我们的号基本不出镜。如果担心这一点，就选安装计费的任务。

[PRE23][PRE24][PRE25]

选任务App也有技巧：一定要选结束时间最晚的，而且任务时间不要超过30天。不要光看哪家收益高，要看哪个任务剩余总预算多，就挂哪个。

### 4. 直播承接流量

确定好视频素材和聚星任务后，视频播放量达到1000，就可以开播了。我们采用的是语音厅直播模式。

开播前一定要检查“赚钱”里的“我的任务”是否为“已激活”状态，确认激活再开播。

直播可以24小时不停，只要平台不倒，直播间就不下播。

### 5. 磁力聚星开通方法

目前有三种开通方式：
1. 快手账号达到1万粉，自己申请开通。
2. 加入公会开通，但平台要扣20%-30%收益。
3. 通过0粉/百粉渠道开通。市面上很多这种渠道，但有的开完一个任务都不显示，非常坑。大家一定注意规避，不要轻信拍单前的承诺，一旦任务不显示，短期内就成了死局。如果你没有靠谱渠道，也可以找我推荐（V：aaxiaoxue987）。

### 1. 认识聚星

### 3. 结算方式

- 星任务：每月1号结算上个月11号到25号的收益；每月16号结算上个月16号到这个月11号的收益。
- 星视频：平台在视频发布后7天结算。
- 星直播：达人和商户确认直播场次后；如果没有确认，按订单结束时间结算。

### 4. 对公与对私

- 对私提现上限为80万。
- 对公由平台每月与机构结算。

### 5. 费率

- 提现时收取4%服务费（不可退税）。
- 另一种是收个人所得税，但第二年可以申请退税。

不管做什么项目，尽量把税务问题处理好。
