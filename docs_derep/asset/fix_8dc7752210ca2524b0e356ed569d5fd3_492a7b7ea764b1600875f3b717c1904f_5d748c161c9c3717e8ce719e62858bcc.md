# 从团灭到月利十万：我的微信电商翻身路

先说下背景。今年三月份进的生财，七月头一回发帖居然拿到精华，感谢各位鼓励。之前那篇主要讲早期摸索，有兴致的朋友可以翻我历史帖。这阵子成天忙于开店，拖到周末才码字，顺便把这段日子捋一遍。主题是：8月我的店被平台全部关停，到11月单月净利恢复到十万上下。

看下成绩单：过去三十天，有效流水扣掉退款后约50万，毛利率大概两成，部分单品能到25到30个点，净赚勉强破十万。

## 一、一夜团灭：八月给我的暴击

七月底，店里的收入已相对稳固，也和几位圈友交换过思路，吸收了一些建议。我把人员架构和职责重新划了划，并新增两名运营加一名剪辑，团队凑到六人。当时计划很明确：靠现有多家店的营收养着内容团队，同步推进短片与直播。

变故发生在8月7号。当天原本要启动直播，一条自制的短片隐隐有爆量苗头，我正打算把它挂进商品车，后台却提示“暂无可售商品”。察觉到不对，我立刻检查主账号，发现公司主体下的五间铺子齐齐变灰，全部商品被清除，页面显示为永久封禁。这两张截图就是当时主力店的处罚记录。

那一刻，我整个人都懵了。反复刷新后确认，五间铺子确确实实全部归零，提交新品也被拦截。联系官方客服，对方只让我登记ID和邮箱，答复是七个工作日内等待。我不死心，又以这五间铺子的主体各发了一封申诉邮件。然而流程上的努力救不了眼前的死局——好比正准备开团，自家水晶忽然被点掉，基地彻底瘫痪，却连攻击者是谁都不知道。一屋子伙伴全成了闲人。下午我便让他们先回家，按全勤结算当日工资，何时复工等通知。人走光后，我和妻子关上门商量对策。

她开口时眼圈通红：我分管的那家图书店每天还能赚近千，如今唯一的进项也断了，直播刚做起来，还没站稳。她说：“你现在有老婆孩子，身后还有一个团队要吃饭。你总是把事做绝，不留余地。这下好了，大家一起喝西北风。”这句训斥，我至今没忘。

我认定祸根出在直播上。后头查阅官方条款，确实存在连带责任规则，而那时我们有多个直播账号因“镜头前无商品展示”的低质内容被警告过。愧疚感一下吞没了我，觉得都是自己图快闯的祸，对不起全队。直到几天后官方用邮件回复才真相大白：封店导火索是图书板块的版权争议。然而当时大家一概不知，全部以为是我直播惹的祸。运营们靠着带货单量拿提成，现在无单可出，合作达人相继流失，队伍士气跌落谷底。

第二天我约了同行打听情况，还去别家办公地点取经。问了一圈就明白过来：他们的店安然无恙，再多的方法论也换不回我失去的东西。我面前的真正问题是归零，店没有解封余地，必须想办法走出新路。与其四处讨安慰，不如抓紧破局。

冷静下来，摆在眼前无非两条路。其一是继续开店，保留原班人马；其二是转型做直播，裁光员工，只留夫妻档。我盘了盘：店既然没了，养一堆人纯属烧钱；两人家庭作坊式直播，体力精神和不确定性都吃不消。最后选了个折中方案——保留两名运营，砍掉一名运营和剪辑，队伍压成四人，新店照开，同时给将来的短片与直播留着火种。

## 二、从谷底往上爬

两天后，我拿来备用的营业执照，一口气注册三间新店，并通知全员返岗，各自认领一家。不巧官方调整了准入门槛，新店必须率先凑齐100单公域成交，不然达人在广场根本搜不到你。新店全都不满足，但团队不能空转，只好硬着头皮传商品，与此同时去找人做单。中间接连换过几拨中间人，均靠不住：有人为了吃差价，填的是假快递单号；底层账号资源也脏。有一家店刷了近300单，结算依旧离100差得远；另一家店更惨，因为做单动作被系统识别，反复封了解除又封。这一通折腾后，我彻底缩手，再乱试下去，余下几家店也可能一起陪葬。那段日子，我既痛恨这个生态，又离不开它，还怕它再发难。

实在没辙，只能亲自上阵播。每个店配一个崭新的内容账号，由于未进入达人库，系统只允许主号挂自家商品，主号不能出任何岔子。我依样画葫芦，买样品回来实拍短片，对标热门视频一比一复刻，再用直播去接短片带来的流量。各店准备的品类各不相同，就是博概率。打法很简单：开播就不关镜头，平台限定24小时，那就播满到尾。夜里我守，白天伙伴轮。后来两家店的内容账号自然流量冲到了几十万次播放，转化虽普通，每场也能出超过100单；剩余那家选的品实在起不了量，我换成付费投流硬灌。靠着这股劲，三家店终于逐一拿到达人库入场券。再往后新店冲库，就找相对可信赖的外包操作。随着店铺杂务激增，我们至今竟再没正经碰过直播。这张截图是当时连续播了24小时的记录，我一个人顶了12小时以上，完全是意志力在撑。

整个8月基本没有利润。新店上架商品少，单量又小，期间我试过自拍内容搭配付费流量，靠平台赔偿金才勉强小赚，但那笔赔偿券有使用期限，我忙到忘记核销，一个月后全部作废。那段日子，我背着沉重的负罪感，除了布置选品任务，连每周例会都停了——像一个犯了错的孩子，不敢与团队对视。与此同时，心态也开始走样。一次和球友切磋，我们约定每一大场拆成五小盘、三盘两胜，外加一点小彩头。技术相近，可我总在大好领先时倒在了黑八，然后被他反超；越到后头越缩手缩脚，只想着给他做障碍球。球友骂了句：你打法这么鳖，跟过去判若两人，今天若是赢你，我也觉得屈辱。这话像一记耳光。我才意识到，哪里是对手厉害，分明是我心里的阴影在作祟。那晚我想通一个道理：该攻的时候别缩，该赢的时候要敢赢，一杆一杆打，一步步走，结局不在你手里。此后我天天约他，头一个星期过后他就极少赢我了。输赢后来也看淡了，关键是那个曾经果断的我回来了。

压力的另一头来自家庭。八月没有进账，妻子难免有情绪。我对她说：从开年至今，除了这次关店，我做的哪次决定出过大错？若你还愿意信我，咱们就重来一回。她没有再说话，算是默认了。我随后静心整理出一套新流程，要求所有人先别盯结果，把每天该做的动作做扎实。

## 三、转折：从单店爆发到队伍归心

九月，各店开始陆续回血。其中一位来了近三个月、此前一单没跑的运营，他名下那家店在九月至国庆间贡献了约20万成交额，毛利逼近三成，几乎以一己之力点燃了整个团队。

[PRE12]

销量回暖后，新麻烦跟着浮现。这家爆单店的运营开始飘飘然，自认功劳最大，对事先讲好的提成比例不满意，把成绩全算在自己头上，还隐约怂恿另一位运营在内部搞分裂。她似乎忘了，公司在她整整三个月没出单、差点撑不住的时候，仍然发着工资，供着资源，给着鼓励。更何况，她还是我多年好友的太太。人性的贪婪，往往藏在这些时候。

我冷静复盘：7月之后，选品上架的事我已全部交出，只负责定框架和处理杂务，把日常运行托付给他们。如今有人不服，恐怕也正常——她或许觉得比老板更强，离了她店就垮。在微型团队里，资源优势不明显、制度威慑不充分的时候，这种心态尤其常见：领着底薪时怕公司倒，拿提成时又嫌赚得少。早年我在深圳创业就见过类似案例，如今绝不会重蹈覆辙。我的处事原则始终没变：创始人先自己跑通全流程，做出比绝大多数同行更漂亮的成绩单，形成打法优势，再把这套优势复制给团队，变成集体的竞争力。这就要求老板必须在业务水平上始终压过成员，才有资格赋能；指望员工反向带动公司，实在太脆弱，微型团队一定要靠创始人拉车。

国庆后，我找两位运营把话挑明：店能做起来，不是你们的本事，而是我把自己跑通的套路交到了你们手上。这话虽然直接，但必须说。随后我赌上头，亲自接管了妻子名下的那家店——太久没选品，压力极大。从接手那天起，我每天精挑细选50到80个品，不分昼夜。守着电脑时就当场传，离开工位就存入手机，回来再统一处理。大约过了一个星期，店里开始出单，很快爆了。我对另一位运营说：你手上那家不用忙了，直接抄我店的商品，马上能爆。到最近三十天，两家店的净成交合计接近30万。前不久我还注册了家新店，开张48小时卖掉了9万，毛利均值过两成。我用结果把场面稳住了。全队重新服气，向心力回到高点。看来老板这角色，一天都不能躺平。

再报一次总账：近30天四家正常出单的店流水合计50万，净利润过10万。诚然，如果8月那场劫难没发生，直播板块现在应该已经跑顺，整体业绩至少翻一番。但恰恰因为这一劫，我把这个平台的玩法学得更透，也算被迫打怪升级。小团队在创业初期的确抗灾能力很弱，没有容错空间，每一步都像踩雷。可路总是人走出来的，只要方向没错，闷头往前走，时间自会回答。

## 四、可复用的操作手法

### （一）拿到达人库门票

一张执照名额内最多能注册五间店，但只有公司身份够格进达人库。平时我们不开播，就得把品放进达人可以直接挂的商品库，否则没人替你卖。当前门槛是凑满100单公域成交——特指从广场推荐位或者短片进镜头前成交的订单。买家付款后，我们安排发货，等对方签收；如果买家手动确认，再等10天，这笔钱才算结算。

怎么凑够这100单？两条路。其一，找外部机构做单，约15天可完成结算，速度快，但机构必须极其可靠。遇到靠不住的，结算不够又要重来，浪费时间事小，店铺因此被封才真亏。做单务必用真快递单号发货，即便评价被平台吞掉，真实轨迹的包裹仍能正常入账。其二，利用主号开播攒单量，只要单量过百、退货又少，等系统自动结算就行。慢一些，但干净安全。我当时因为被关怕了，又赶上机构不给力，所以选了最硬的直播硬扛。

入场券到手后，核心就是选品。像我们这种不开播、极少主动联络达人的店，订单全靠散客达人在广场顺手挂，他们对分成、价格超敏感，如今还会看门店评分。挑品选品，就是生死线。

### （二）商品上架的规范流程

第一，物色产品，先估算售后成本。需要学习或安装代价太高的品，后面客服会被烦死。各方面觉得可以，就到批发站、1688、抖音、快手等渠道找物美价廉的源头货。

第二，用外部搬运工具把同类商品搬进后台，再根据机制优化标题里的关键词、清理敏感词组，改好规格参数。

第三，提交审核。结合货源信息和源头平台的买家评论反推成本，设定售价，预留20%上下毛利，把平台抽成与给达人的分成都算进去，再提交审。

第四，审核过了，按预先设定的比例挂进达人库。这里要提醒，分成一旦定下来就不能随意动，想调整，隔天才会生效。

### （三）选品哲学：宁精勿滥

选品分两条线：手选和工具批量化。手选要人工一件一件过，速度慢，但价格、佣金可控，成交率高。工具批量化则快得多，早前平台对上架数没有限制，一天能铺上千款商品，价格佣金全走统一配置，命中率就明显下降，属于大力出奇迹。我们现在已经基本抛弃海量铺货，以手选精品为主，把每个品当爆款来调，把成功率往上提——暴力铺货既没有含金量，也不会留下内功。

### （四）在平台里挖品

先说养号。准备一个纯观察号，不挂货架、不发布内容。每天在广场刷想做的垂直类目，要懂推荐机制：刷到和卖货没关联的娱乐、搞笑内容，直接划走，不要点赞、评论或看完，否则账号会被贴娱乐标签，之后极难洗回来。刷到带商品的短片，就看完整，再点赞、留评。通常半天或一天能养出对应标签；一个号还能同时挂多个偏好，比如图书、百货、饰品、茶叶等，没有固定限制，取决于你熟哪个方向。

标签养好后，系统就会推荐合适的品类视频。看到一支带货短片，先分析它挂的品有无价格或佣金优势，值得做，就点进商品入口或作者橱窗，找到对应商品链接，存一张图，再打开拼多多搜同款，找质量最好、价格最低的货源搬回店里上架。如果橱窗里根本找不到这款货，说明系统库里还没有，属于蓝海商机，必须立刻组同款抢时间。

达人橱窗选品的逻辑也一致：先养好观察号，再拆解对标账号的橱窗，注意哪些品类在平台跑得动、分成可观，结合自身货源决定是否跟进。

总结来说，这盘生意的两个胜负手：第一，能否拿下达人库资格，决定曝光；第二，能否挑出能打的商品，决定利润。这两点打通，后面拼的就是一连串细节和日复一日的执行力。
