正式敲定投放之前，还有一轮“尽调”要做。我习惯打开西瓜的数据面板，把账号背景逐项核对：先辨别它是不是矩阵式批量运作的号——归属方名下如果一口气养了好几个公众号，多半是流水线起号，数据水分偏高，前期宁缺毋滥。

正常的阅读曲线长这样：整体平滑爬坡，发文后的两三个小时内，会被核心订阅者的即时打开顶出一段陡峭的小高峰，随后热情消退，阅读增速慢下来，曲线开始走平并维持在一个稳定水位。要是深夜发文，凌晨十二点后会出现一段短暂的停顿，次日早上再小幅回弹。屏幕右上的增量面板可以看到夜间时段的阅读细节。

反过来，如果阅读曲线在几分钟内近乎垂直冲顶，随后突然断掉变成一条水平线；或是在已经走平之后又出现一波无来由的猛涨；又或者凌晨等非高峰时段冒出脉冲式暴涨——这些异常形态，指向刷量的概率都很高。

账号底子没问题，接着就衡量它的商业价值：看一看该号头条位置的平均阅读量，再翻翻它过往接过的商务推文，表现怎么样？有没有老客户回来追投？这套历史记录，会直接成为你出价谈判时的底稿。

### 第四步：价格博弈

公众号广告的计费方式，目前绕不开两种：CPT 和 CPS。

CPT 是买断制：双方约定一个总额，再商量好保留周期（1天、3天、7天或永久），文章发出去之后不论数据好坏，钱都按约定付清。

CPS 是效果制：按推广链接实际带来的成交额抽成。愿意接这种模式的号主不多；如果你的产品在公众号上已经验证出稳定的付费路径、又急着放量，可以把媒介和投手发展成代理，用CPS来结算和让利，大家利益绑定，量跑起来会很快。

实际投放中，CPT 仍是绝对的成交主力。号主和媒介通常会先报一个价；值得注意的是，有些流量主既接私单，也挂在腾讯互选平台，这种账号通常会有两套报价——平台单明显比私单便宜。到底能不能投，还得回到你自己的产品毛利率、投放经验和预期回报上来做判断。

还有一类头部账号为了规避平台风险，只接腾讯互选平台的单。官方渠道对素材审核卡得严：文案必须规范、脱敏，派单流程也更繁琐。所以早期测试阶段，直接走私单就行；等产品验证完毕、需要加量时，再补上互选平台注册和专用文案测试的功课。

控制预算这件事，我的习惯是能砍则砍。媒介报过来的号，我选中后还会让他们回头找号主压一轮价。压价之前先给自己定两个底：一个看粉丝总量，一个看近期头条均阅，结合两者算出心目中的目标价，再找些说得出口的理由去争取——比如粉丝量不够硬、阅读量不稳定、公司这轮额度有限、效果好后面一定多次追投。

目标价位没有标准答案，因人而异、因账号而异。经验是：IP味很正的优质号，博主通常咬价很死，我们抱着成交的心态小刀即可；没有IP光环的号，可以用两个粗糙模子去套——每万粉折价100元、或头条均阅×0.5。我的口径偏严，不同行业需要自己重新校参。预算前段要拧紧、后面再慢慢放开，测试期本来就是用来摸手感的，把预算卡得紧一点，起码能排掉一堆不值当的号。

下面是我投放AI产品时的单次阅读成本估算，供参考：

| 账号类型 | 单次阅读成本（元） | 判断逻辑 |
| :--- | :--- | :--- |
| 垂类必投账号 | 0.6-0.8 | 赛道和用户画像高度匹配，且经测试转化确实好；这类号溢价高一点也值得。 |
| 职场/技能/副业账号 | 0.4-0.6 | 不属于垂类，但测试中回购和转化都不错，可以作为稳定备选。 |
| 泛生活/情感/娱乐/资讯账号 | 0.3-0.4 | 流量盘子大，人群不精准，粉丝对产品的付费意愿测了才知道。 |

一个省钱小技巧：不必急着成交。对号主保持“若即若离”的姿态，很多以接单为生的账号最怕档期空转。你抛出的低价，对面当时一口回绝；等到了没单可接的淡季，对方也许会主动找你松口。我就碰到过一次：原来报价1.5万，号主被前一个客户放了鸽子，主动降到1.2万，最后1万成交。

### 第五步：预览确认 + 定时群发

价格和排期谈拢，下一步就做预览。我通常会在发布日前一晚把号主约出来，一起过预览，留出足够时间微调文案。

所谓预览，就是把标题、封面、正文、植入的营销素材整理好交给号主，由号主在公众号后台生成预览链接，再转发回来给你把关。

核对的要点主要包括：发文账号是否和敲定时一致、排版有没有错乱、文中的二维码是否能正常识别、购买路径是否顺畅；发文设置上，通常要求关闭所有广告位，评论区设置为作者精选后再呈现，以免负面留言影响转化。

确认无误后，就请对方设好定时群发。具体发什么时间，取决于内容和产品调性。IP属性强的号大多有固定发文习惯，粉丝也形成了阅读生物钟，尽量顺着号主的时间走。还有一条一定要核对：是否群发“全部用户”，防止对方分组群发坑了你的预期效果。

### 第六步：费用结算

和号主的结算，主流有三种节奏：预览通过并完成定时后一次性打款 > 发文前1小时打款 > 定时后先付定金、发布后再付尾款（少数号主能接受）。和媒介的结算相对简单，通常两种：签完合同按周/月结算 > 定时后付定金、发文3天后结尾款。

因为发文后还需要媒介和号主配合做维护，我从不建议在发文前把全款付掉。给媒介的约束可以明确写进合作协议：

- 1. 若正文、关键词或留言区出现任何形式的广告，每发现一条未关闭，按效力金额的20%扣款。
- 2. 发文后10分钟到15分钟之间，需手动精选并放出首批留言；后续优质留言在2小时内分批放出；延迟操作扣尾款的40%。
- 3. 发文后30分钟内一条留言都没放，扣效力金额的80%；发文2小时后仍未放出，扣80%并追加发布价20%的罚款。

无论对接号主还是媒介，款项能走公司账户就尽量走公司账户。这样税务流程更干净，也能顺带筛掉一部分不靠谱的合作方。

### 第七步：发文后的维护

账号一旦多起来，就必须有排期表。到点发文时，人要在现场：检查文内二维码/链接是否可用，最好再安排一些正面留言带节奏，帮犹豫的用户下决心。走媒介渠道的，要让对方把发文后的界面原样转发过来，便于你核对、截图和复盘。

### 第八步：投后复盘

发出后的第二天，把前一天每个账号的阅读量、加微/进线数、实际成交数拉出来，填进统一的表格里，日积月累就是你的投放数据库。投手盯盘盯得久了，会慢慢建立“号感”，看到新号，心里自动就会浮现出它大概的ROI范围。

以AI产品为例，现在主要靠订阅费变现，投放节奏上要克制：同一个优质号，最好隔至少30天再续约；其他品类按自身节奏走，数据好的号可以乘胜追击——比如工作日表现好的号，周末补一次；上午跑得好的，隔几天挑晚上再试一次。如果赛道竞争很激烈，复投间隔就要主动缩短，否则容易被竞品截胡。

### 原则二：坚持数据复盘

投得多了，心态往往在两个极端间横跳：要么觉得自己已经“号感附体”，看哪个号都稳；要么越看数据越心虚，觉得分析根本赶不上变化。不用焦虑，这就是概率游戏的正常现象。能做的只有持续把数据存下来、定期复盘，让长期统计帮我们赚钱；对团队来说，也是在沉淀公司的投放库，培养新的投手。

### 原则三：选账号就是选人群

不要被历史战绩带偏。你只能看到前台阅读量，看不到后台真实成交；何况AI在公众号投流里还属于新物种，一个号接过再多广告，也不代表它的粉丝会买你的东西。先把自己的用户画像画准，这件事想不透，后面每一步都是在猜。

### 原则四：评论区是转化的“第二战场”

评论区是天然的二次转化场。推文发出后不理评论区，等于把到手的流量白白丢掉。AI这种新东西，用户会有一连串疑问：是不是噱头？怎么操作？能解决我的问题吗？这时候既需要提前铺一些引导性评论，也要认真接住真实用户的反馈。让号主把产品相关留言导给你，你出好回复话术，再让他发出去，最省力也最可控。

### 原则五：素材是撬动流量的最大杠杆

投放一旦上量，素材必须成组地备好。一方面防止短时间反复投放触发风控，另一方面不同气质的号也吃不同口味的文案。优质内容自带筛选功能，能把目标人群精准筛出来；反过来，一篇平庸的稿子投在再准的号上也只会沉底。每一个转化触点都要站在用户立场反复打磨，所谓高转化，其实都是大量“换位推演”堆出来的。

## 第五章：这个看似“弯腰就能捡到钱”的窗口，你真的适合入场吗？

这套逻辑放诸公众号而皆准，也适配不少产品。看到“7天42万”的战绩，热血沸腾很正常，但它不是从零一步到位的。真决定下场之前，先对号入座。

### 一类人适合：产品成熟 + 流量嗅觉

- 自己的产品已经过市场验证，眼下缺的是增量渠道。你清楚知道付费用户长什么样，也判断公众号能装下这个品，就快点找几个目标号试水。
- 做过淘客、外卖红包或任何CPS业务，对流量套利有本能反应。这类人做AI公众号投放，几乎就是降维打击——手机一转，黄金万两。

CPS的底层是帮卖逻辑，所以不怕没产品。我自己还在持续测试新产品线。如果判断自己能干，直接去找那些你用过、或者正在其他平台投放的产品谈代理。

ps：比如咱们圈友@玉伯老师的“YouMind”，我没细聊，但看着很适配公众号。连广告物料都可以用 YouMind 生成，这本身就是最有说服力的广告。

### 二类人慎入：想“一劳永逸”或“暴力收割”

- 风险承受能力太弱的人。公众号投流没有稳赚这回事，前期测试就是要交学费的。我前面表格里就躺着一个 ROI 只有0.23 的反面案例。文章被删、号主放鸽子、风控莫名拦截，这些都不能接受的话，这个赛道只会让你心力交瘁。
- 做交付没有底线的人。“割一波就走”的心态在这里行不通。产品翻车，粉丝单个维权可能很难，但号主和媒介都有公司背景，会帮着粉丝走法律渠道；博主圈子的口碑传播又快，你的品一夜之间就会上黑名单。
