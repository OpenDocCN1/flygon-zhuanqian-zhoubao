# 二、对 Cursor 的初步认知

## 1、Cursor 是什么
Cursor 是一款基于大语言模型的智能编程编辑器，本身就是一套完整的开发环境。它让写代码的过程变成与 AI 实时协作，支持补全、报错提示和自动修正。

传统编辑器里的 AI 功能多是外挂，Cursor 则把 AI 融进编辑器的核心流程里。AI 不再是辅助插件，而是贯穿编码体验的主线，使用感更像和同事 pair programming。

## 2、相比 Copilot 的差异点
和 GitHub Copilot 等同类助手对比，Cursor 的侧重点更全面：

### 1.多模型可用且可自定
可切换不同大模型，并能根据个人习惯微调输出风格。上一次翻红很大程度上是因为接入了 Claude Sonnet 3.5，生成质量和一次通过率明显提升。

### 2.全项目上下文感知
传统工具只看当前文件，Cursor 会读取整个仓库的上下文，给出更贴合项目的联想。

### 3.即时诊断与修复
编码过程中实时扫描错误并给出修复建议，准确率和开发节奏都更快。

### 4.自然语言交互
可以用中文直接提问、调整需求、重构逻辑，对代码理解和迭代很友好。

### 5.Tab 预测与批量编辑
能预判下一步光标落点，并支持多行同时修改，在大面积排版调整时效率很高。

### 6.安全与隐私
提供隐私模式，已获 SOC2 认证，支持选择不把代码上传到服务器。

# 九、使用感悟

把需求整理清晰交给 Cursor，预览结果后针对局部继续追问修改，完全可以用中文指令完成前端开发，不必手写代码。

我本身有程序员背景，后台系统可直接复用，所以本次只用 Cursor 负责前端。当然 Cursor 也能生成后端代码，只是环境搭建成本更高。用于官网、谷歌插件、微信小程序、轻量 App 都很合适。开发者用它提效，非技术角色也能参与编程。

近期我已用 Cursor 完成插件、小程序、站点等项目，并开始录制实战课程系列，计划 100 个项目，已完成 10 个，完善后会继续分享。有兴趣的朋友可交流。
