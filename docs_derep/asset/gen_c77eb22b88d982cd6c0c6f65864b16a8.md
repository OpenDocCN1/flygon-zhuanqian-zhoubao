# 小红书选题总枯竭？这套我在新号上验证过的找题方法，分享给你

> 原文：[`www.yuque.com/for_lazy/thfiu8/ep26rzghi9my6yc8`](https://www.yuque.com/for_lazy/thfiu8/ep26rzghi9my6yc8)

大家好，我是93年的王卷卷，全职妈妈一枚。去年靠自媒体做到了10万+的变现，过去的都翻篇了，希望新的一年我们都能更上一层楼。

去年复盘的时候我给自己立了个Flag，今年要产出100篇原创，说实话立flag那会儿我心里是打鼓的。第一怕时间不够用。

我现在一边带小红书的学员，一边还要兼顾直播，恨不得把一天掰成两天用。

第二怕脑子空了。一直以来我都是靠灵感写东西，灵感来了能一口气写完，至今我写过一篇游记，隔段时间回头看都怀疑是不是别人代笔了，文采好到我自己都不敢认。

最近我又开了一个小红书新号，需要持续稳定地输出文案。逼不得已，只能逼自己把“找选题”这件事练成肌肉记忆。今天就把我这段时间在站内挖题的实操经验，整理出来给你参考，方法拿去用在其他平台也一样好使。

**一、去热搜那儿蹲点找灵感**

小红书的热搜榜，功能上跟微博热搜差不多。有空就刷一下，看到跟自己赛道沾边的热搜词，直接点进去看哪些笔记在爆、大家都在聊什么话题。别人的火点就是你的启发点，看多了自然就有东西可写了。

[PRE1]

**二、爆款笔记的评论区，才是真正的选题矿**

评论区真的太有料了。你会发现别人的经历跟你的用户惊人地像，比如被渣男PUA的剧情，两个人细节都对得上，然后在评论区隔空互相抱抱、互相安慰。

再聊自律、职场、育儿，每个人的看法都不一样，每一条不同的观点都能拆成一个独立的内容角度。我们做内容又不是真去吃瓜，是在替用户把痛点、共鸣、争议点都收进来存着。

评论区里随便一句吐槽，都可能是明天笔记的标题。

[PRE2]

**三、找个对标账号，跟着抄作业就行**

对标账号就两类：一类是做你这个垂类的头部博主，一类是跟你身份、风格很像的创作者。先观察她们的爆款都在写什么，选题方向、表达方式先模仿一轮。

框架其实就那么几套。我从粥佐罗的《学会写作》里提炼出来这几招，特别好用：

01、干货三件套：2W1H
02、观点三步法：总分总
03、同纬度并列拆分
04、逻辑递进拆分
05、不同维度罗列拆分
06、同一点不同案例罗列法
07、时间顺序法

《学会写作》-粥佐罗

先抄框架，再填自己的血肉，选题自然就有了。

**四、选题一定要提前囤着，至少囤一周**

这次起新号给我最大的教训就是：必须提前攒选题。理想状态是攒满一个月，至少也要有接下来一周的库存。

写作这件事需要进入心流状态，你要是写着写着停下来去搜题，思路就断了。我就有过这种经历，好不容易挤出一大块安静时间坐到电脑前，结果因为没选题，盯着屏幕发呆半小时，一个字没动，这不是纯浪费时间吗？

[PRE3]

选题提前规划好了，你才能真正做到下笔即顺。

以上就是我最近实操后总结出来的找选题心法，希望能帮到正在为灵感发愁的你。
