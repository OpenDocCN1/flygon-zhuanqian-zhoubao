## 4、积分消耗情况

文生图每次消耗2积分，垫图生图每次消耗2积分。

即梦每日登录送66积分，相当于可免费做33次定制化人像写真。一次4张，33×4=132张。若不够，可用新手机号再注册一个即梦账号，免费额度足够用。

基础会员比免费版多了去水印功能。

# 三、摊位上的一些感悟

1，门槛越低，短时间内涌入的人越多，后期赚钱越难。

就我有限的摆摊经验，AI人像写真短期内仍能成交。

但风口在迅速收窄。

当时我卖的是九块九体验价。可以开张，有人买，但利润不多。

同一市集里，有位女生卖的是同类产品，报价88元一张，画面差不多，差别在于模板更多、工具更多，还能现场打印装框并附赠拼夕夕买的徽章。结果生意明显门可罗雀。

# 四、2025年1月更新

AI人像写真技术的门槛很低，如今已卷成红海。尤其是现在美图秀秀、抖音等App也能做风格迁移，年轻人对AI写真的付费意愿并不高了。

几点建议：

1，不要投入太多硬成本。照片打印机可在闲鱼按天租，相框在拼夕夕和1688很便宜。摊位尽量找免费或低价的。

2，准备快速出图的工作流。即梦的写真出图有抽卡概率，可能需多试几次，等待会导致客流流失。会用liblib跑comfyUI工作流的同学，可以多用liblib，上面有很多可免费使用的写真工作流，人物和宠物的都有。

3，花时间挑选摆摊地点。地点决定人流，人流很大程度上决定成败。

4，实践出真理。一千个摊主有一千种做法，欢迎分享你的摆摊经历。
