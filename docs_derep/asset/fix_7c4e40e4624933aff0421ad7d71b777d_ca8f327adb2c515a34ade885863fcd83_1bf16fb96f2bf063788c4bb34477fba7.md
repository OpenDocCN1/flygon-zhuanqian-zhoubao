# 四、搭建后端服务 Supabase 并建库【免费】

非常适合敏捷开发，自带安全、认证、注册登录、数据库等能力。

Supabase 免费版为开发者提供了基础却够用的支持，适合个人项目或初期验证。以下信息综合多源整理，截至 2025 年 6 月：

### 1. 基础资源配额

*   数据库空间：500MB 的 PostgreSQL 存储，支持完整 SQL
*   内存与 CPU：共享 CPU，500MB RAM，满足轻量应用
*   带宽：月出口流量 5GB，超量需升级
*   文件存储：1GB 存储空间，如 R2 类存储
*   API 调用：API 请求次数无限

### 2. 功能限制

*   月活用户：最高 50,000 MAU，含身份验证
*   实时连接：200 个并发实时连接，适合小型实时场景
*   边缘函数：每月 50 万次调用，适合轻量无服务器逻辑

### 3. 项目限制

*   活跃项目数：同时最多运行 2 个免费项目，超额需停用或删除
*   休眠机制：免费项目闲置 1 周后自动休眠，需手动唤醒

### 4. 与其他免费服务的对比

*   与 Firebase 对比：Supabase 基于开源 PostgreSQL，灵活性更强，但免费额度下 Firebase 的 NoSQL 在部分场景更友好
*   与 CMS 对比：Supabase 聚焦后端能力如数据库与认证，CMS 更偏内容管理，定位不同

### 5. 注意事项

*   监控与升级：可通过 Supabase 控制台跟踪用量，临近上限会提醒。免费版无专属客服，主要靠社区论坛
*   数据备份：免费版仅基础备份，需要每日备份或更久保留需升级至 Pro 版，起价 $25/月

### 总结

Supabase 免费计划适合原型验证、个人练习或学习用途。若需要更高性能如独享 CPU、更大存储或团队协作功能，可考虑付费方案，如 Pro 版提供 8GB 存储和 25 万 MAU。国内用户使用全球节点如日韩时延迟可能偏高，但服务可用。

# 五、用 Vercel 部署上线【免费】

非常契合 Next.js 项目的快速发布

官网还提供大量免费开源模板

官方🔗：https://vercel.com/

用 GitHub 账号登录后绑定仓库

即可实现 Git 仓库的自动部署

代码提交到 GitHub 后自动触发构建发布

Vercel 免费 Hobby 计划面向个人开发者和小项目，提供基础但实用的额度，具体要点如下：

### 1. 基础资源配额

*   部署次数：每月最多 1000 次部署，含自动触发的 Git 提交
*   流量与时长：每月 100GB 带宽和 100GB-Hrs Serverless 函数运行时长，适用于无服务器 API 或后端逻辑
*   无服务器函数：支持 Node.js、Python 等语言部署，免费计划有执行时长限制，具体见官网

### 2. 功能限制

*   GitHub 组织项目：免费计划不支持托管于 GitHub 组织的项目，需升级至 Pro 计划 $20/月/成员。可通过 Vercel CLI 新建独立项目绕开限制
*   Docker 支持：不支持 Docker 容器化部署
*   自定义域名：支持绑定自定义域名，并免费提供 SSL 证书

### 3. 自动化与集成

*   Git 集成：支持 GitHub、GitLab、Bitbucket 自动部署，代码推送即触发构建
*   CDN 加速：全球 CDN 网络提升访问速度，适合静态站和轻量 API

### 4. 适用场景

*   个人项目：如作品集、博客、小型前端应用
*   开发测试：适合原型验证或临时演示，生产级应用建议升级

### 5. 与其他平台对比

*   优势：部署流程简洁，对 Next.js 优化友好，适合 Jamstack 架构
*   劣势：资源限制较严，团队协作需付费，且不支持 Docker

如需更详细的技术限制如函数超时、并发数等，建议查阅 Vercel 官方文档。若需更宽松的免费额度，可考虑 Netlify 或 Cloudflare Pages 等替代方案。
